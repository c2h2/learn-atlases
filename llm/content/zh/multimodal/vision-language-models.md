像 CLIP（[[multimodal/contrastive-learning]]）这样的对比模型能说出几条说明文字中哪一条最配一张图像，却无法描述图像、回答关于它的问题、从图表上读出数字、或一步步讲解一张示意图。这些任务需要一个能以图像为条件*生成*文本的模型——而手头最好的文本生成器正是预训练语言模型。**视觉-语言模型**（vision-language model，VLM）把一个图像编码器接到一个语言模型上，使语言模型能注意到编码器看到的内容，然后训练它遵循关于图像的指令。

工程问题是怎么个接法。三个设计标出了发展的三条主线。**Flamingo**（Alayrac 等人, 2022）冻结一个大语言模型，插入新的交叉注意力层，让文本词元通过它们去注意视觉特征。**BLIP-2**（Li 等人, 2023）训练一个小 Transformer——Q-Former——把图像蒸馏成 $32$ 个向量，让冻结的语言模型把它们当作软提示来读。**LLaVA**（Liu 等人, 2023）干脆把 CLIP 编码器的每个图块嵌入投影到语言模型的输入空间，像词嵌入一样排进序列，再在用语言模型生成的指令数据上微调。LLaVA 的配方——编码器、投影层、语言模型、分阶段训练——是截至 2026 年多数开放 VLM 的模板。本章把这三个都讲一遍，算清一张图像花多少词元、高分辨率图像如何切块，描述 VLM 如何训练与评测，最后讲它最有名的一种失误：描述根本不存在的物体。

## 把编码器接到语言模型上 {#sec-connect}

三个设计共享同样的零件。一个视觉编码器——通常是对比预训练的 ViT——把图像变成图块特征的网格 $F\in\R^{N\times d_v}$（[[multimodal/vision-transformers#def-patch-embedding]]）；VLM 通常取最后或倒数第二层的图块输出，而不是只取池化后的 CLS 向量，因为语言模型需要知道东西在*哪里*。一个宽度为 $d$ 的仅解码器语言模型负责产出文本。两者之间是一个**连接器**，把视觉特征变成语言模型能消费的东西。三个设计的差别在于：视觉信息从何处进入语言模型、被压缩成多少个向量。

### 交叉注意力：Flamingo {#sec-flamingo}

::: definition 门控交叉注意力模块（Flamingo） {#def-gated-xattn}
设 $X\in\R^{T\times d}$ 是进入某个冻结语言模型层的文本词元的隐状态，$V\in\R^{M\times d}$ 是视觉词元。**门控交叉注意力模块**计算

$$
\begin{aligned}
X' &= X + \tanh(\alpha)\cdot\operatorname{XAttn}(X, V),\\
X'' &= X' + \tanh(\beta)\cdot\operatorname{FFW}(X'),
\end{aligned}
$$ {#eq-gated}

其中 $\operatorname{XAttn}$ 是以 $X$ 为查询、以 $V$ 为键与值的多头交叉注意力（[[transformers/architecture-families#def-cross-attention]]），$\operatorname{FFW}$ 是一个前馈层，$\alpha$、$\beta$ 是初始化为 $0$ 的可学习标量。$X''$ 随后被交给那个冻结的语言模型层。
:::

::: proposition 门控在初始化时保留冻结模型 {#prop-gate-init}
若 $\alpha = \beta = 0$，每个门控模块都是恒等映射；于是插入了任意多个这种模块的语言模型，无论图像是什么，所计算的函数都与原模型完全相同。
:::

::: proof
$\tanh(0) = 0$，所以 $X' = X + 0 = X$、$X'' = X' = X$。每个插入的模块都把输入原样交给下一个冻结层；对层归纳，每个隐状态、从而输出分布，都等于未加改动的语言模型的。
:::

门控让训练能从语言模型的全部能力出发，再逐步接纳视觉信息：关于 $\alpha$ 与 $\beta$ 的梯度在 $0$ 处不为零（因为 $\tanh'(0) = 1$），所以视觉信息一有助于降低损失，门就会打开。Flamingo 还需要处理数量可变的视觉特征的办法——从一张图像到许多视频帧。它的 **Perceiver Resampler** 是一个小 Transformer：$64$ 个可学习的潜查询向量对视觉特征做交叉注意力，于是每张图像或每段视频都恰好变成 $64$ 个视觉词元。

Flamingo 的训练数据混合了图文交错的网页（$4300$ 万个页面）、图像-文本对和配有说明的短视频。在交错数据里，每个文本词元只对位于它之前最近的那张图像的视觉词元做交叉注意力，而语言模型中的自注意力仍能看到全部更早的文本，于是较早图像的信息间接地流动起来。这样训练出的模型，可以用几个图文示例加一张新图像来提示，它就能**在上下文中**学会视觉任务（[[prompting-rag/in-context-learning]]）。最大的模型 Flamingo-80B 建在 $700$ 亿参数的 Chinchilla 语言模型之上，每第七层之前插入门控模块；Alayrac 等人报告，少样本的 Flamingo 常常胜过在成千上万倍任务数据上微调过的模型。

### 一个查询 Transformer：BLIP-2 {#sec-blip2}

::: definition Q-Former（BLIP-2） {#def-qformer}
**Q-Former** 是一个带 $K$ 个可学习查询向量 $\mathbf{q}_1, \dots, \mathbf{q}_K$ 的 Transformer（BLIP-2 中 $K = 32$、维数 $768$）：查询向量之间做自注意力，并对冻结图像编码器的图块特征做交叉注意力。它的 $K$ 个输出向量由一个线性层映到语言模型的宽度 $d$，作为**软视觉提示**前置在文本嵌入之前。Q-Former 与一个文本 Transformer 共享自注意力层，因此同一个模块也能编码文本。
:::

BLIP-2 分两个阶段训练 Q-Former（约 $1.88$ 亿参数），图像编码器与语言模型都冻结。第一阶段用三个目标教查询提取与文本相关的信息，三个目标在查询与文本之间使用不同的注意力掩码：图像-文本对比学习、图像-文本匹配（判断说明文字配不配套的二分类）、以图像为依据的说明生成。第二阶段把输出接到冻结的语言模型（OPT 或 Flan-T5），用语言建模损失训练连接器。Li 等人报告，零样本 VQAv2 准确率比 Flamingo-80B 高 $8.7$ 个百分点，可训练参数却少 $54$ 倍。这一设计的代价是一个固定的瓶颈：无论图像多么细致，都只有 $32$ 个向量。

### 一个投影层：LLaVA {#sec-llava}

::: definition 基于投影层的 VLM（LLaVA） {#def-llava}
设 $F\in\R^{N\times d_v}$ 是视觉编码器的图块特征。**投影层** $g\colon\R^{d_v}\to\R^{d}$——LLaVA 中是一个线性映射，LLaVA-1.5 中是带 GELU 的两层 MLP——把每个图块特征映成语言模型嵌入空间中的一个**视觉词元**。语言模型收到的序列是

$$
\big[\,g(F_1), \dots, g(F_N),\ \mathbf{e}(w_1), \dots, \mathbf{e}(w_T)\,\big],
$$ {#eq-llava}

其中 $\mathbf{e}(w_t)$ 是文本词元的嵌入（实践中，视觉词元被插在聊天模板里图像占位符的位置），并且只在回答词元上用通常的下一词元损失训练。
:::

语言模型内部什么都不变：视觉词元与词一样经过同样的自注意力与前馈层，在因果掩码下也像提示中任何更早的部分一样被注意到。LLaVA 用 $224$ 像素的 CLIP ViT-L/14 编码器，每张图像给出 $16\times16 = 256$ 个视觉词元，语言模型用 Vicuna。训练分两个阶段：

1. **特征对齐。** 在从 CC3M 过滤出的 $59.5$ 万个图像-说明文字对上，只训练投影层（编码器与语言模型冻结），学习由视觉词元生成说明文字。这教会投影层把视觉特征映进语言模型本来就能解读的嵌入空间区域。
2. **视觉指令微调。** 在 $15.8$ 万个关于图像的指令-回答样本（对话、详细描述与推理问题）上微调投影层与语言模型（编码器仍然冻结）。这些样本由用每张图像的 COCO 说明文字与物体边界框提示纯文本的 GPT-4 生成，因为当时的 GPT-4 还看不到图像。

LLaVA-1.5（Liu 等人, 2024）把线性映射换成两层 MLP，把分辨率提高到 $336$ 像素（$24^2 = 576$ 个词元），并加入了带简答格式提示的学术问答数据集；约 $120$ 万条训练样本，在一个 $8$ 块 A100 GPU 的节点上大约一天训练完毕，并在十几个基准上取得了强劲结果。指令微调本身——模板、损失掩码与数据——是 [[post-training/instruction-tuning]] 的主题；VLM 不过是把图像放进提示里再做一遍。

::: example 走一遍 LLaVA-1.5 的前向传播 {#ex-llava-shapes}
LLaVA-1.5-13B 用 $336$ 像素的 CLIP ViT-L/14（$d_v = 1024$）和宽度 $d = 5120$ 的语言模型。一个提示含一张图像和 $40$ 个文本词元。画出各处的形状，数一数投影层的参数量，并算出图像占序列的比例。
::: solution
编码器给出 $24\times24 = 576$ 个大小为 $1024$ 的图块特征：$F\in\R^{576\times1024}$（CLS 输出被丢弃）。MLP 把 $1024\to5120\to5120$，于是视觉词元是 $576\times5120$；投影层有 $1024\cdot5120 + 5120 + 5120\cdot5120 + 5120 = 31{,}467{,}520$ 个参数，约占语言模型的 $0.2\%$。语言模型看到 $576 + 40 = 616$ 个宽度为 $5120$ 的位置，其中图像占 $93.5\%$。一张图像花的上下文抵得上好几段文字。
:::
:::

::: warning 视觉词元不是词
因为视觉词元与词嵌入排在同一条序列、同一个嵌入空间里，人们很容易把它们读成“图像词”——去为每个视觉词元找词表里最接近的嵌入，或指望它们在不同模型之间迁移。它们是由一个投影层产生的连续向量，而这个投影层是与某一个特定语言模型联合训练的；没有任何东西把它们与词表绑定，视觉词元的最近词嵌入通常毫无意义。换语言模型就得训练一个新的投影层；换视觉编码器则至少要重训投影层，而且通常连语言模型也要一起重训。
:::

### 比较三个设计 {#sec-compare}

三种连接器都在上下文长度与灵活性之间做交换。投影层往语言模型的序列里加 $N$ 个视觉词元，之后每个文本词元在每一层都要注意它们全部；Q-Former 或重采样器只加一个固定的小数目 $K$；交叉注意力给自注意力上下文什么都不加，但代价是新参数，以及每个门控层里对 $M$ 个视觉词元的一次注意力。

::: proposition 视觉上下文的注意力开销 {#prop-visual-cost}
在一个 $L$ 层、宽度 $d$ 的解码器中，在前缀已有 $N$ 个视觉词元之后生成 $T$ 个文本词元，对视觉词元的注意力约花费 $4LdNT$ 次浮点运算（分数与加权值；视觉词元的投影每个前缀只算一次），而键值缓存多存 $2LNd$ 个数。改用 $K$ 个词元的重采样器，同样的开销随 $K$ 而不是 $N$ 变化。
:::

::: proof
每一层的每个生成词元，与缓存中 $N$ 个视觉键各做一次长度为 $d$ 的点积（$2Nd$ 次浮点运算），再对 $N$ 个值向量做加权和（$2Nd$ 次），每个词元每层共 $4Nd$，总计 $4LdNT$。缓存为每个视觉词元每层存一个宽度 $d$ 的键和一个值，共 $2LNd$ 个数（[[inference/kv-cache]]）。把 $N$ 换成 $K$，其余不变。
:::

::: example 带四张图像的少样本提示 {#ex-fewshot}
一个少样本提示含三个已解答的示例和一个待答问题，每个配一张图像，共 $150$ 个文本词元。比较 LLaVA-1.5 式模型（每张图像 $576$ 个词元）与 Flamingo 式模型（每张图像 $64$ 个重采样词元，经交叉注意力进入）的自注意力上下文，以及后者在一个门控层里一个文本词元能注意到的视觉键数。
::: solution
投影层模型的序列有 $4\cdot576 + 150 = 2454$ 个位置，其中 $94\%$ 是视觉的。Flamingo 式模型的自注意力上下文只是那 $150$ 个文本词元（外加图像标记）；$4\cdot64 = 256$ 个视觉词元只通过门控层进入，在每个门控层里，每个文本词元注意位于它之前最近那张图像的 $64$ 个词元。投影层模型多花得多得多的上下文，但让每一层都能拿任意词与任意图像的任意图块作比较——当问题关乎两张图像的差异时，这很有用。
:::
:::

基于投影层的设计在开放模型中胜出，出于很实际的原因：简单；语言模型的每一层都能与每个图块交互；而上下文窗口已经长到足以承受成百上千的 $N$。它的代价——下一节将看到——是词元数随分辨率迅速增长。

## 分辨率、词元与切块 {#sec-tiling}

$336\times336$ 的输入认出一只狗够用，但要读收据、电子表格截图或一页科学论文就不够：只有几个像素高的字会被下采样毁掉。读文档的 VLM 需要多得多的像素；而对 ViT 编码器，像素多意味着图块多（按 [[multimodal/vision-transformers#prop-vit-cost]]，编码器内部的注意力也按平方增长）。现用着三种策略。

::: definition 高分辨率输入的策略 {#def-resolution}
1. **固定缩放。** 把每张图像缩放（并加边或裁剪）到编码器的训练分辨率：边长 $s$、图块大小 $P$ 时不管输入多大都是 $N = (s/P)^2$ 个词元。
2. **切块。** 选一个由编码器原生尺寸 $s$ 的 $r\times c$ 个切片组成的网格，其长宽比与图像最匹配；把图像缩放到 $rs\times cs$，每个切片单独编码，并通常加上一张缩小的全图**缩略图**以提供全局上下文：$N = (rc + 1)(s/P)^2$ 个词元。
3. **原生分辨率。** 用能接受可变网格、配二维位置编码的 ViT 按（大致）图像自身的尺寸编码，并把每块 $m\times m$ 的相邻图块特征合并成一个词元以减少词元数：$N = \lceil H/(mP)\rceil\cdot\lceil W/(mP)\rceil$。
:::

LLaVA-NeXT（Liu 等人, 2024 年 1 月）用 $336$ 像素切片的切块，网格如 $2\times2$、$1\times4$、$4\times1$，再加一张缩略图。InternVL 1.5（Chen 等人, 2024）用 $448$ 像素的切片，训练时最多 $12$ 个，并用**像素打乱**（pixel shuffle）把每个切片的 $1024$ 个图块特征减少到 $256$ 个词元——把每个 $2\times2$ 的特征块折叠成一个宽度四倍的向量。Qwen2-VL（Wang 等人, 2024）走原生分辨率路线：图块大小 $14$ 的 ViT、二维旋转位置编码（RoPE），加一个做 $2\times2$ 合并的 MLP，于是每个语言模型词元覆盖 $28\times28$ 像素：一张 $224\times224$ 的图像花 $64$ 个词元，另加两个界符。下面的代码比较三种策略。

```python
import math, random
random.seed(2)

def fixed(H, W, side=336, patch=14):            # 缩放成一个正方形：LLaVA-1.5 式
    return (side // patch) ** 2

def tiled(H, W, tile=336, patch=14, max_tiles=6):
    # 选形状与图像最匹配的网格（行 x 列，至多 max_tiles 块）：
    # 先最大化保住的分辨率，再最小化补边浪费的面积
    best = None
    for r in range(1, max_tiles + 1):
        for c in range(1, max_tiles // r + 1):
            scale = min(r * tile / H, c * tile / W, 1.0)   # 绝不放大
            kept = (H * scale) * (W * scale)
            waste = r * c * tile * tile - kept
            key = (kept, -waste)
            if best is None or key > best[0]:
                best = (key, r, c)
    _, r, c = best
    per_tile = (tile // patch) ** 2
    extra = 1 if r * c > 1 else 0                  # 多个切片时加全局缩略图
    return r, c, (r * c + extra) * per_tile

def native(H, W, patch=14, merge=2):           # 原生分辨率，2x2 词元合并
    unit = patch * merge                         # 每个 LM 词元覆盖 28 x 28 像素
    return math.ceil(H / unit) * math.ceil(W / unit)

for (H, W) in [(336, 336), (1080, 1920), (2200, 1700)]:
    r, c, t = tiled(H, W)
    print(f"{H}x{W}: fixed {fixed(H, W)}  tiled {r}x{c} grid -> {t}  native {native(H, W)}")

# 对一个偏向答“是”的模型做 POPE 式评测
truth = [1] * 150 + [0] * 150                    # 被探测的物体一半在场
pred = [1 if (t == 1 and random.random() < 0.9) or (t == 0 and random.random() < 0.35) else 0
        for t in truth]
tp = sum(p and t for p, t in zip(pred, truth)); fp = sum(p and not t for p, t in zip(pred, truth))
fn = sum((not p) and t for p, t in zip(pred, truth)); tn = len(truth) - tp - fp - fn
prec, rec = tp / (tp + fp), tp / (tp + fn)
print(f"TP {tp} FP {fp} FN {fn} TN {tn}")
print(f"accuracy {(tp + tn) / len(truth):.3f}  precision {prec:.3f}  recall {rec:.3f}  "
      f"F1 {2 * prec * rec / (prec + rec):.3f}  yes-ratio {sum(pred) / len(pred):.3f}")
```

```text
336x336: fixed 576  tiled 1x1 grid -> 576  native 144
1080x1920: fixed 576  tiled 2x3 grid -> 4032  native 2691
2200x1700: fixed 576  tiled 3x2 grid -> 4032  native 4819
TP 131 FP 52 FN 19 TN 98
accuracy 0.763  precision 0.716  recall 0.873  F1 0.787  yes-ratio 0.610
```

::: example 一页纸的词元预算 {#ex-page}
一张 $2200\times1700$ 像素的 A4 扫描页由以下方案读取：(a) 固定的 $336$ 像素编码器；(b) 代码里的切块方案；(c) 每词元 $28$ 像素的原生分辨率。各用多少个词元？一个词元概括多少像素？
::: solution
(a) 对 $374$ 万像素用 $576$ 个词元：每个词元代表约 $6500$ 像素，即原图上一块 $81\times81$ 的方形——对 $10$ 磅的字太粗糙了，这个扫描分辨率下字高约 $30$ 像素。(b) $3\times2$ 网格（$1008\times672$ 像素）加一张缩略图：$7\cdot576 = 4032$ 个词元；图像被缩小约 $0.4$，于是每个词元覆盖原图约 $35\times35$ 像素。(c) $\lceil2200/28\rceil\cdot\lceil1700/28\rceil = 79\cdot61 = 4819$ 个词元，每个覆盖全分辨率下 $28\times28$ 像素。读这一页纸花的上下文抵得上几千字的文章——比这页纸装的字还多。
:::
:::

caption: 视觉词元数随图像高度 $x$（像素）的变化，图像宽度为 $r\cdot x$。原生分辨率编码随面积平滑增长；切块按整块切片成台阶增长（这里没有真实系统会做的缩小与封顶）。无论如何，开销与像素数成正比——这就是 VLM 要为每张图像限定最大像素数或切片数的原因，也是视频（许多帧图像）通常在时间上和空间上下采样的原因。
:::

**文档理解。** 读图中的文字过去要靠一个独立的光学字符识别（OCR）系统，把它的输出喂给文本模型。免 OCR 的模型直接读像素：Donut（Kim 等人, 2022）与 Pix2Struct（Lee 等人, 2023）——后者在“把网页截图解析成简化 HTML”上预训练——证明图像到文本的 Transformer 能自己学会阅读。当前的 VLM 在训练中把高分辨率输入与大量合成及渲染的文字、图表、表格数据结合起来，并在 TextVQA（Singh 等人, 2019）、DocVQA（Mathew 等人, 2021）、ChartQA（Masry 等人, 2022）等基准上评测。这些基准上的准确率强烈依赖分辨率：小到一个词元以下的细节，语言模型根本拿不到。

## 训练 VLM {#sec-training}

LLaVA 的分阶段配方已成标准，各家有所变体：

1. **对齐**：在图像-说明文字对上训练刚初始化好的投影层，编码器与语言模型冻结。
2. **多模态预训练**（在更大的工程中）：用数亿到数十亿的图像-文本对、交错的网页文档（如 Flamingo 所用）、OCR 数据、图表、截图与视频，常常解冻编码器。交错文档教会模型处理多张图像、并利用图像周围的文字上下文；OBELICS（Laurençon 等人, 2023）与 MINT-1T（Awadalla 等人, 2024）是这类开放数据集。
3. **视觉指令微调**：用问答、对话、说明生成、文档与推理数据，其中大部分由其他模型生成或改写；只有回答的词元参与监督。
4. 可选的**偏好优化**（[[post-training/preference-optimisation]]）：用对图像忠实程度不同的回答对，直接针对幻觉下手。

指令数据的质量在某一点之后比数量更要紧，这一点从文本上早已熟悉（[[post-training/instruction-tuning#sec-lima]]）。生成的数据还会继承生成者的错误：由看不见图像的模型写出的说明文字——最初 LLaVA 的数据正是如此——有时会提到看似合理却不在场的物体，在它上面训练的 VLM 也就学会了照样做。

::: quiz
一个 LLaVA 式 VLM 分两阶段训练。第一阶段只在图像-说明文字对上训练投影层。为什么不从一开始就微调语言模型？
- [ ] 语言模型不能处理连续的输入向量。
- [x] 刚初始化好的投影层起初产生的是任意的向量；拿它们去训练语言模型，会在视觉词元携带有用信息之前就损害语言模型的语言能力。
- [ ] 说明文字太短，训练不了语言模型。
- [ ] 必须先训练视觉编码器。
::: solution
初始化时，视觉词元是嵌入空间里看似随机的向量。让语言模型去迁就经由这种输入产生的说明文字，既浪费它的容量又有遗忘的风险。先只训练投影层，把视觉特征映进冻结语言模型本来就能合理解读的嵌入空间区域；然后两者再一起调。Flamingo 的零初始化门（[[#prop-gate-init]]）起类似的作用。
:::
:::

## VLM 中的幻觉 {#sec-hallucination}

**物体幻觉**——描述或回答提到图像里并不存在的物体——在 VLM 之前就有图像说明生成来度量它：CHAIR 指标（Rohrbach 等人, 2018）数的是被提到的物体中不出现在图像标注里的比例。纯文本模型的幻觉见 [[prompting-rag/hallucination]]；在 VLM 里它有具体的成因。语言模型的先验很强——厨房里通常有冰箱，看不清厨房角落的模型可能照样“看见”一台。训练说明文字中由见不到图像的系统生成的那些就包含此类猜测。低分辨率抹掉了本可反驳先验的证据。而在“有没有……？”的答案大多为“是”的数据上做指令微调，会教出迎合的偏向。

::: definition POPE {#def-pope}
**基于投票的物体探测评测**（Polling-based Object Probing Evaluation；Li 等人, 2023）向 VLM 询问形如“图像里有{物体}吗？”的是非题，物体按标注在场与不在场各占一半，数量相等。不在场的物体按三种设定选取：**随机**（任取一个不在场的物体类别）、**热门**（数据集中最常见的类别）与**对抗**（与在场物体最常共现的类别）。它报告“是”回答的准确率、精确率、召回率与 F1，以及 **yes 比例**——回答“是”的题目占比。
:::

用是非题投票避开了解析自由格式描述的困难，而三种设定能把随机幻觉的模型与跟着共现统计走的模型区分开：对受语言先验驱动的模型，对抗设定最难。Li 等人发现，好几个早期的指令微调 VLM 对绝大多数问题都答“是”。

::: example 解读 POPE 指标 {#ex-pope}
代码模拟了一个模型：在 $150$ 个在场与 $150$ 个不在场的物体上，对 $90\%$ 的在场物体、$35\%$ 的不在场物体答“是”。解读它各项指标。
::: solution
计数为真阳 $131$、假阳 $52$、假阴 $19$、真阴 $98$。准确率 $229/300 = 0.763$，精确率 $131/183 = 0.716$，召回率 $131/150 = 0.873$，F1 $0.787$，yes 比例 $0.610$。在平衡集合上，yes 比例远高于 $0.5$、召回率远高于精确率，正是迎合偏差的签名：这个模型说有 $131$ 加 $52$ 个物体在场，其中超过四分之一其实不在。一个逢题必答“是”的模型准确率 $0.5$、F1 $0.667$——所以准确率、精确率与 yes 比例要放在一起读。
:::
:::

缓解手段在每个阶段都可用：更高的分辨率；以能看到图像的方式撰写、并对照标注核查的训练数据；指令数据里加入反面问题与“不是”的回答；在忠实回答与幻觉回答之间做偏好优化（例如 RLHF-V，Yu 等人, 2024）；以及在解码时对比模型有图与无图的预测、把语言先验减掉的解码方法。没有哪一个能根除这一问题；截至 2026 年，幻觉细节仍是 VLM 的头号失误，尤其见于计数、小字和精细的空间关系。

## 评测 VLM {#sec-evaluation}

VLM 的基准随模型一样快地变化。列出几座里程碑及其发表年份：

- **VQAv2**（Goyal 等人, 2017）：关于 COCO 图像的开放问题，做过平衡——每个问题都配两张答案不同的图像——以挫败纯靠语言的瞎猜。
- **GQA**（Hudson 与 Manning, 2019）：由场景图生成的组合式问题。
- **TextVQA**（2019）、**DocVQA**（2021）与 **ChartQA**（2022）：读文字、读文档、读图表。
- **MMBench**（Liu 等人, 2023）与 **MME**（Fu 等人, 2023）：覆盖多种技能的选择与是非题套件。
- **MMMU**（Yue 等人, 2024）：约 $1.15$ 万道大学水平的带图题目（示意图、图表、化学结构式、乐谱），覆盖 $30$ 个科目。
- **MathVista**（Lu 等人, 2024）：针对图形的数学推理；物体幻觉则用 **POPE**（2023）。

所有基准都适用两条告诫。其一，许多问题不看图像也能答：Chen 等人 (2024) 发现语言模型单独就能在几个流行基准上考出远高于随机分数的成绩，于是用必须看视觉才能答的题目构建了 MMStar。把 VLM 的成绩与一个**盲测**基线——同一模型不给图像——比较，是笔便宜账。其二，老基准会饱和、会漏进训练数据，文本基准亦然（两个问题都在 [[evaluation]] 中讨论）。读分数要连同发表日期与评测设置（提示、分辨率、答案解析）一起读，后者能让结果差上几分。

::: application 屏幕与智能体
屏幕截图就是长着按钮的文档。在高分辨率下读用户界面、输出元素坐标的 VLM，支撑着 [[agents]] 中的电脑操作智能体；这里描述的每种失误——小字低于词元尺寸、幻觉出的元素、迎合偏差——都有了切肤的后果，因为模型会照着它以为自己看到的东西去行动。
:::

::: history
神经图像说明生成把卷积编码器与循环解码器拼在一起（Show and Tell，Vinyals 等人, 2015；Show, Attend and Tell，Xu 等人, 2015，后者对图像区域做注意力）。视觉问答随 VQA（Antol 等人, 2015）成为基准任务。2019–2020 年出现了预训练的视觉-语言 Transformer（ViLBERT、LXMERT、UNITER），随后 SimVLM（2021）与 CoCa（2022）用图像-文本目标做生成式预训练。Flamingo（Alayrac 等人, NeurIPS 2022）用冻结语言模型与门控交叉注意力展示了上下文中的视觉学习；BLIP-2（Li 等人, ICML 2023）提出了 Q-Former；LLaVA（Liu 等人, NeurIPS 2023）与同期的 MiniGPT-4、InstructBLIP 确立了视觉指令微调，LLaVA-1.5（2024）确立了简单的 MLP 投影层基线。带视觉的 GPT-4（2023）与 Gemini（2023）把图像输入带进商用助手。高分辨率切块（LLaVA-NeXT、InternVL，2024）与原生分辨率编码器（Qwen2-VL，2024）让读文档成为常规；POPE（2023）与 MMMU（2024）成了标准评测。
:::

::: summary
- VLM 通过一个连接器，把视觉编码器（通常是对比预训练的 ViT，取其图块特征）接到语言模型上。
- Flamingo 往冻结的语言模型里插门控交叉注意力层；零初始化的 $\tanh$ 门让模型一开始与语言模型完全相同；一个重采样器把每张图像变成 $64$ 个词元。
- BLIP-2 的 Q-Former 把图像蒸馏成 $32$ 个查询输出当作软提示；LLaVA 把每个图块特征投影进嵌入空间插进序列，先训投影层、再在视觉指令上一起训投影层与语言模型。
- 图像的成本按词元计：$336$ 像素的图像在 $P = 14$ 时要 $576$ 个，一页文档要几千个。切块按整块加缩略图添加；原生分辨率编码器把 $2\times2$ 的图块合并成一个词元。
- 物体幻觉来自语言先验、低分辨率与生成的训练数据；POPE 用随机、热门、对抗三种设定下的平衡是非探测来度量它——准确率、精确率与 yes 比例要一起读。
- 基准很快过时；要与盲测基线比较，并记录评测设置。
:::

## 习题

::: exercise 原版 LLaVA 的词元 {level=1 check="256"}
原版 LLaVA 用 $224\times224$ 的 CLIP ViT-L/14 并丢弃 CLS 词元。一张图像产生多少个视觉词元？
::: solution
每边 $224/14 = 16$ 个图块，$16^2 = 256$ 个视觉词元。
:::
:::

::: exercise 原生分辨率的预算 {level=1 check="1536"}
每个语言模型词元覆盖 $28\times28$ 像素时，一张 $1344\times896$ 的截图产生多少个视觉词元（不含界符）？
::: solution
$1344/28 = 48$，$896/28 = 32$，故 $48\cdot32 = 1536$ 个词元。
:::
:::

::: exercise 切块加缩略图 {level=1 check="2880"}
一张图像被切成 $2\times2$ 的 $336$ 像素切片网格，外加一张缩略图，每块编码成 $576$ 个词元。它一共花多少个视觉词元？
::: solution
$(4 + 1)\cdot576 = 2880$ 个词元。
:::
:::

::: exercise 一张图像的缓存内存 {level=2 check="1.51"}
一个 $70$ 亿参数的语言模型有 $32$ 层、宽度 $4096$，用标准多头注意力，键值缓存以 16 位浮点数存放。上一题的 $2880$ 个视觉词元占多少吉字节（$10^9$ 字节）的缓存？保留两位小数。
::: solution
由 [[#prop-visual-cost]]，缓存存 $2LNd = 2\cdot32\cdot2880\cdot4096 = 754{,}974{,}720$ 个数，每个 $2$ 字节，即 $1.51\times10^9$ 字节——还没有放任何文本，每张图像就约 $1.51$ GB。分组查询注意力会把这笔账除以查询头与键值头的比例。
:::
:::

::: exercise 永远答“是” {level=2 check="2/3"}
在一个平衡的 POPE 集合上，一个模型对所有问题都答“是”。计算它的准确率、精确率、召回率与 F1，填入的答案是 F1。
::: solution
每个在场物体都是真阳、每个不在场物体都是假阳：准确率 $0.5$，精确率 $0.5$，召回率 $1$，F1 $= 2\cdot0.5\cdot1/(0.5 + 1) = 2/3$。因此单看 $0.667$ 的 F1 什么也说明不了；yes 比例为 $1$ 才戳穿了模型。
:::
:::

::: exercise 闭合门处的梯度 {level=2}
在 [[#def-gated-xattn]] 中取 $\alpha = 0$，计算 $\partial X'/\partial\alpha$ 以及损失关于交叉注意力参数的梯度。解释为什么尽管交叉注意力层的输出在初始化时毫无用处，训练仍能把门打开；若门不是 $\tanh\alpha$ 而是 $\alpha^2$，又会发生什么。
::: solution
$\partial X'/\partial\alpha = (1 - \tanh^2\alpha)\operatorname{XAttn}(X, V)$，在 $\alpha = 0$ 处等于 $\operatorname{XAttn}(X, V)$，于是 $\partial\mathcal{L}/\partial\alpha = \langle\partial\mathcal{L}/\partial X', \operatorname{XAttn}(X, V)\rangle$：只要注意力输出与能降低损失的方向相关，它就不为零。关于交叉注意力参数的梯度被乘以 $\tanh\alpha = 0$，第一步为零；所以门先动，$\alpha\neq0$ 之后层就开始学习。若门是 $\alpha^2$，则 $\partial(\alpha^2)/\partial\alpha = 2\alpha = 0$ 在 $\alpha = 0$ 处成立，门与层都收到零梯度：训练会卡死在初始点。门在它取零的地方必须有非零的导数。
:::
:::

::: exercise 瓶颈对抗全图块 {level=2 check="18"}
一个 VLM 在一张图像之后生成 $T = 200$ 个词元。用 [[#prop-visual-cost]] 比较投影层设计（$N = 576$ 个视觉词元）与 Q-Former 设计（$K = 32$）对视觉词元的注意力浮点运算数。两者相差多少倍？
::: solution
开销分别为 $4LdNT$ 与 $4LdKT$，比值为 $N/K = 576/32 = 18$，与 $L$、$d$、$T$ 无关。Q-Former 设计在这一步便宜 $18$ 倍，缓存也少 $18$ 倍；代价是把任何图像都压进 $32$ 个向量，这会限制文字之类的精细细节。
:::
:::

::: exercise 像素打乱 {level=2}
一个 $P = 14$ 的 ViT 把 $448\times448$ 的切片编码成宽度 $1024$ 的特征。因子为 $2$ 的像素打乱把每块 $2\times2$ 的相邻特征折叠成一个向量。给出所得词元的个数与宽度，以及从它们到一个宽度 $4096$ 的语言模型的线性投影层的参数量。为什么是折叠而不是把四个向量平均？
::: solution
切片给出 $32\times32 = 1024$ 个特征；折叠 $2\times2$ 块得到 $16\times16 = 256$ 个宽度为 $4\cdot1024 = 4096$ 的词元。线性投影层 $4096\to4096$ 有 $4096^2 + 4096 = 16{,}781{,}312$ 个参数。折叠（拼接）是无损的——四个特征并排保留，投影层可以学着决定保留哪些部分——而平均会丢掉相邻图块之间的差异，那恰恰是高分辨率本想保住的精细细节（汉字的笔画）。
:::
:::

::: exercise 盲测基线 {level=3}
一个 VLM 在一个四选一的选择题基准上得 $62\%$。把图像换成一张空白的同一模型得 $48\%$。(a) 这两个数字各说明什么？(b) 设其中有比例为 $f$ 的题目仅凭文本就能答，模型在这些题上有无图像都全对；其余题目上盲模型均匀乱猜。估计 $f$，以及模型在必须用图的题目上带图像的准确率。(c) 比较两个模型时，这为什么重要？
::: solution
(a) $62\%$ 是总分；$48\%$ 远高于均匀乱猜的 $25\%$，说明许多问题仅凭题目文本和选项先验就能回答。

(b) 盲测准确率为 $f + (1 - f)/4 = 0.48$，故 $\tfrac34f = 0.23$、$f = 0.307$。带图像时 $0.62 = f + (1 - f)a$，其中 $a$ 是在必须用图的题目上的准确率：$a = (0.62 - 0.307)/0.693 = 0.452$。在真正考视觉的题目上，模型只对大约 $45\%$，不是 $62\%$。

(c) 两个模型的分数之差可能来自语言先验不同，而非视觉能力不同；更强的语言模型实际上抬高了 $f$。报告盲测成绩、或像 MMStar 那样在必须用图的子集上评测，才能把两者分开。
:::
:::

::: exercise 选择连接器 {level=3}
你要构建一个 VLM，回答关于 $30$ 分钟视频的问题：视频每秒取一帧，每帧由 $336$ 像素的 ViT 编码（$576$ 个图块特征）。(a) 用投影层设计数一数视觉词元。(b) 用本章的思想提出两种办法让输入装进 $32{,}000$ 个词元的上下文，并各说明牺牲了什么。
::: solution
(a) $1800$ 帧 $\times$ $576$ 个 $= 1{,}036{,}800$ 个视觉词元——是上下文容量的三十多倍。

(b) 一种做法是每帧配一个 $K$ 词元的重采样器或 Q-Former：取 $K = 16$ 得 $28{,}800$ 个词元，装得下；但每帧被压成 $16$ 个向量，精细细节（字幕、小物体）就丢了。另一种是空间池化或合并（例如 $4\times4$ 平均池化，每帧压到 $36$ 个词元），再配时间下采样（每 $2$ 秒取一帧：$900\cdot36 = 32{,}400$，逼近上限）；它细节与短暂事件两头都丢。还可以先用一个廉价的检索步骤挑选与问题相关的帧（漏掉选取器错过的事件），或采用 Flamingo 式的交叉注意力——文本上下文保持很小，但每个门控层仍要为全部视觉词元付注意力开销。
:::
:::
