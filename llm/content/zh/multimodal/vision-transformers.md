语言模型读取的是词元向量的序列。图像是像素的网格：一张 $224\times224$ 的彩色照片就是三个通道上的 $150{,}528$ 个数。十年来，处理这种网格的标准方法是卷积网络（[[neural-networks/convolutional-networks]]），它的小型共享滤波器内建了这样的假设：彼此邻近的像素关系紧密，而同一个模式无论出现在何处含义都相同。2020 年，Dosovitskiy 与合作者证明这些假设可以去掉。把图像切成正方形图块，把每个图块展平成一个向量，线性投影，加上位置编码，再把得到的序列交给一个普通的 Transformer 编码器（[[transformers/transformer-block]]）。只要训练数据足够多，这个**视觉 Transformer**（ViT）就能追平甚至超过最好的卷积网络。

ViT 对本课程的重要性在于，它让图像在 Transformer 眼里变得像文本。接下来各章的每一个多模态模型——CLIP 的图像编码器、视觉-语言模型的视觉塔、扩散模型的骨干网络——都从本章的思想出发：图像变成一个向量的序列。本章依次讲解图块嵌入及其计算、位置编码及其如何被拉伸到新的分辨率、图像变大时注意力的代价、内建假设与数据之间的权衡，以及使 ViT 变得可行的三种训练配方：大规模监督预训练、借助蒸馏的数据高效训练（DeiT），以及通过掩码重建（MAE）与自蒸馏（DINO）的自监督预训练。

## 图像是图块的序列 {#sec-patches}

对单个像素做自注意力是绝无可能的：$224\times224$ 的图像有 $50{,}176$ 个像素，对它们做注意力矩阵，每个头每一层就有 $2.5\times10^9$ 个元素。ViT 把像素分组成互不重叠的 $P\times P$ 图块来缩短序列长度。

::: definition 图块嵌入 {#def-patch-embedding}
设图像 $\mathbf{x}\in\R^{H\times W\times C}$ 的高 $H$ 与宽 $W$ 都能被**图块大小** $P$ 整除。把它分成 $N = HW/P^2$ 个互不重叠的图块，并把每个图块按光栅顺序（从左到右、从上到下）展平成向量 $\mathbf{x}_p^{(i)}\in\R^{P^2C}$。**图块嵌入**是线性映射

$$
\mathbf{z}^{(i)} = E\,\mathbf{x}_p^{(i)} + \mathbf{b}, \qquad E\in\R^{d\times P^2C},\ \mathbf{b}\in\R^{d},\qquad i = 1, \dots, N,
$$ {#eq-patch}

对每个图块施加，使用同一个 $E$ 和 $\mathbf{b}$。$N$ 个向量 $\mathbf{z}^{(i)}\in\R^{d}$ 就是**图块词元**。
:::

“词元”这个名字借自文本，但这类比是宽泛的：图块词元是由像素算出的连续向量，不是词表中的下标。离散的图像词元也存在——它们由学出来的量化器产生，是 [[multimodal/image-generation]] 的主题——但 ViT 并不使用它们。

::: proposition 图块嵌入就是一种带步幅的卷积 {#prop-patch-conv}
[[#eq-patch]] 的映射等于一个 $C$ 输入通道、$d$ 输出通道、卷积核大小 $P$、步幅 $P$ 的卷积，其形状为 $(d, H/P, W/P)$ 的输出特征图按光栅顺序读出。
:::

::: proof
卷积核为 $K\in\R^{d\times C\times P\times P}$、步幅为 $P$ 的卷积，在输出位置 $(r, c)$ 处对每个输出通道 $j$ 计算 $\sum_{k, u, v}K_{j,k,u,v}\,x_{rP + u,\,cP + v,\,k} + b_j$（[[neural-networks/convolutional-networks#def-conv]]）。当步幅等于卷积核大小时，输出位置 $(r, c)$ 恰好看到第 $i = rW/P + c + 1$ 个图块的像素，且没有像素被两个位置同时看到。把卷积核的 $(k, u, v)$ 下标按与图块像素相同的顺序展平，$K_{j,\cdot}$ 就变成了 $E$ 的第 $j$ 行，于是这个和就是 $(E\mathbf{x}_p^{(i)})_j + b_j$。
:::

这就是实现里把图块嵌入写成 `Conv2d(C, d, kernel_size=P, stride=P)` 的原因：同一个线性映射，只是算得更高效。

::: example ViT-Base 的图块计算 {#ex-patch-count}
ViT-B/16 在 $224\times224$ 的 RGB 图像上使用 $P = 16$、$d = 768$。求图块词元的个数、展平后一个图块的长度、图块嵌入的参数量，以及 $B = 32$ 张图像的批量对应的词元序列形状。
::: solution
每边有 $224/16 = 14$ 个图块，所以 $N = 14^2 = 196$。每个图块含 $16\cdot16\cdot3 = 768$ 个数——与 $d$ 相同，这是这一配置下的巧合。投影有 $768\cdot768 + 768 = 590{,}592$ 个参数（即 [[neural-networks/convolutional-networks#ex-vit]] 中为等价卷积算出的数目）。加上下文介绍的分类词元后，序列有 $197$ 个词元，批量的形状是 $(B, T, d) = (32, 197, 768)$。
:::
:::

### 分类词元与位置编码 {#sec-cls-pos}

还有两种成分把图块词元变成编码器的输入。沿用 BERT（[[transformers/architecture-families#def-encoder]]）的做法，ViT 在序列最前面添上一个学习到的向量 $\mathbf{z}_{\text{cls}}\in\R^{d}$，即**分类词元**，它在最后一层之后的输出充当图像的表示。而由于自注意力本身无视次序，ViT 给每个词元加上一个学习到的**位置编码**：

$$
Z_0 = \big[\mathbf{z}_{\text{cls}};\ \mathbf{z}^{(1)};\ \dots;\ \mathbf{z}^{(N)}\big] + E_{\text{pos}}, \qquad E_{\text{pos}}\in\R^{(N+1)\times d}.
$$ {#eq-vit-input}

序列 $Z_0$ 依次通过 $L$ 个前置归一化的 Transformer 块（[[transformers/transformer-block#def-block]]），前馈层用 GELU，再过最后的 LayerNorm，最后在 CLS 输出上接一个分类头。[[#eq-vit-input]] 之后的一切，都是前面课程里那个 Transformer 编码器，原封不动。

为什么需要位置编码？下面这个事实把这一点讲得确切无误，而且它对任何由注意力与逐位置层堆成的网络都成立。

::: proposition 没有位置编码，Transformer 看不见布局 {#prop-perm}
设 $F\colon\R^{T\times d}\to\R^{T\times d}$ 是一摞 Transformer 编码器块（不带掩码的自注意力、逐位置前馈层、LayerNorm 与残差连接）。对每个置换矩阵 $\Pi\in\R^{T\times T}$，都有 $F(\Pi Z) = \Pi F(Z)$。因此，把一张图像的图块打乱而不加位置编码，输出向量的多重集不变；CLS 输出——只要 CLS 词元没有被挪动——也一模一样。
:::

::: proof
只需逐部件验证。逐位置的映射 $g$ 逐行施加，满足 $g(\Pi Z) = \Pi g(Z)$，这覆盖了前馈层、LayerNorm 与残差求和。对自注意力，$Q = ZW_Q$，所以 $\Pi Z$ 给出 $\Pi Q$、$\Pi K$、$\Pi V$。分数矩阵成为 $\Pi QK^\top\Pi^\top$。逐行的 softmax 与行置换可交换，而置换其输入的列会置换其输出的列，所以 $\operatorname{softmax}(\Pi S\Pi^\top) = \Pi\operatorname{softmax}(S)\Pi^\top$。再乘以 $\Pi V$ 得 $\Pi\operatorname{softmax}(S)\Pi^\top\Pi V = \Pi\operatorname{softmax}(S)V$，因为 $\Pi^\top\Pi = I$。多头注意力逐位置地拼接并投影，所以也是等变的，而等变映射的复合仍等变。固定 CLS 位置的置换不改变输出的那一行。
:::

若没有位置编码，ViT 看图像就像看一袋图块。ViT 的学习式一维编码——光栅顺序中每个位置一个——让模型能够从数据中自己发现二维布局，Dosovitskiy 等人发现手工设计的二维或相对编码并无明显收益。训练后把每个位置的编码可视化，会发现它与同一行、同一列图块的编码最相似——网格结构是学来的，不是先验给定的。也有别的选择：把正弦或旋转编码分别施加于行、列坐标（[[transformers/positional-encoding]]），这在后来的模型中很常见，尤其是那些接受尺寸可变图像的模型。

### 改变分辨率 {#sec-resolution}

在 $224\times224$ 上以 $P = 16$ 训练好的模型有 $14\times14$ 个学习到的位置编码。在更高分辨率上微调——通常能提高准确率——时保持 $P$ 不变而增大 $N$：$384\times384$ 的图像对应 $24\times24$ 的网格。Dosovitskiy 等人对预训练的编码做二维**插值**，把它们当作一幅带 $d$ 个通道的 $14\times14$ 图像，缩放到 $24\times24$。这是 ViT 唯一一次被告知自己的输入是二维的。

::: example 位置编码的插值 {#ex-interp}
$14\times14$ 网格上的位置编码用双线性插值缩放到 $24\times24$，四角对齐，于是新下标 $i\in\{0, \dots, 23\}$ 对应旧坐标 $i\cdot13/23$。网格位置 $(0, 1)$ 处的新编码由哪些旧编码贡献？权重各是多少？微调后的模型有多少个位置编码？
::: solution
沿行方向，坐标 $0$ 映到 $0$。沿列方向，$1\cdot13/23 = 0.565$ 落在旧列 $0$ 与 $1$ 之间，所以新编码是 $0.435\,\mathbf{e}_{0,0} + 0.565\,\mathbf{e}_{0,1}$——相邻两个的加权平均，权重为 $1 - 0.565$ 与 $0.565$。CLS 的编码原样复制。微调后的模型有 $24^2 + 1 = 577$ 个位置编码，全部从插值得到的起点开始训练。
:::
:::

### 参数的计算 {#sec-params}

ViT 论文定义了三种沿用至今的参照规格：ViT-Base（$L = 12$ 层、$d = 768$、$12$ 个头、前馈宽度 $3072$）、ViT-Large（$24$、$1024$、$16$、$4096$）与 ViT-Huge（$32$、$1280$、$16$、$5120$）。ViT-L/16 这样的名字给出规格与图块大小。下面的代码按定义数出它们的参数量，其中含一个 $1000$ 类的分类头。

```python
import math, random
random.seed(0)

def vit_params(L, d, mlp, P=16, C=3, img=224, classes=1000):
    N = (img // P) ** 2                       # 图块词元
    embed = P * P * C * d + d                 # 图块投影（权重 + 偏置）
    tokens = d + (N + 1) * d                  # CLS 词元 + 位置编码
    attn = 4 * (d * d + d)                    # W_Q、W_K、W_V、W_O 及其偏置
    ffn = d * mlp + mlp + mlp * d + d         # 两个线性层
    norms = 2 * 2 * d                         # 两个 LayerNorm（增益、偏置）
    block = attn + ffn + norms
    head = 2 * d + d * classes + classes      # 最后的 LayerNorm + 分类器
    return N, embed + tokens + L * block + head

for name, L, d, mlp, P in [("ViT-B/16", 12, 768, 3072, 16),
                           ("ViT-L/16", 24, 1024, 4096, 16),
                           ("ViT-H/14", 32, 1280, 5120, 14)]:
    N, n = vit_params(L, d, mlp, P)
    print(f"{name}: {N} patches + CLS = {N+1} tokens, {n/1e6:.1f}M parameters")

# 把一张 8x8 单通道玩具图像切成 4x4 的图块，然后做 MAE 式掩码
img = [[(r * 8 + c) % 10 for c in range(8)] for r in range(8)]
P = 4
patches = [[img[r0 + i][c0 + j] for i in range(P) for j in range(P)]
           for r0 in range(0, 8, P) for c0 in range(0, 8, P)]       # 4 个图块 x 16 个值
print("patch 1 (top right):", patches[1])
T = 196; keep = int(T * (1 - 0.75))
perm = list(range(T)); random.shuffle(perm)
visible = sorted(perm[:keep])
print("MAE keeps", keep, "of", T, "patches; first visible ids:", visible[:8])
```

```text
ViT-B/16: 196 patches + CLS = 197 tokens, 86.6M parameters
ViT-L/16: 196 patches + CLS = 197 tokens, 304.3M parameters
ViT-H/14: 256 patches + CLS = 257 tokens, 632.0M parameters
patch 1 (top right): [4, 5, 6, 7, 2, 3, 4, 5, 0, 1, 2, 3, 8, 9, 0, 1]
MAE keeps 49 of 196 patches; first visible ids: [5, 6, 13, 17, 22, 26, 29, 32]
```

论文报告 $86$M、$307$M 与 $632$M；ViT-L 的小差异来自其表格所用的分类头，其中并未细到每个参数。几乎所有参数都在块里，每块约 $12d^2$（[[transformers/transformer-block#prop-block-params]]）；图块嵌入与位置编码合计不到总数的 $1\%$。代码的最后几行将用于 [[#sec-mae]]。

## 图像上注意力的代价 {#sec-cost}

ViT 的序列长度由分辨率与图块大小决定：$T = HW/P^2 + 1$。分辨率翻倍，或图块大小减半，都会把 $T$ 变成四倍。这之所以要紧，是因为 Transformer 层的两部分随 $T$ 的增长方式不同。

::: proposition ViT 层中注意力与线性部分的代价 {#prop-vit-cost}
对模型宽度 $d$、前馈宽度 $4d$、序列长度 $T$ 的 Transformer 块，线性层（投影与前馈）的矩阵乘法约花 $24Td^2$ 次浮点运算，注意力（分数 $QK^\top$ 以及与 $V$ 的加权和）花 $4T^2d$ 次，于是

$$
\frac{\text{attention FLOPs}}{\text{linear FLOPs}} = \frac{T}{6d}.
$$ {#eq-vit-ratio}

取 $T = HW/P^2$（忽略 CLS 词元），注意力的份额随图像边长的四次方增长（$P$ 固定）。
:::

::: proof
把一次乘加算作 $2$ 次浮点运算：四个 $d\times d$ 投影花 $4\cdot2Td^2 = 8Td^2$，两个大小 $d\times4d$ 的前馈矩阵花 $2\cdot2T\cdot4d^2 = 16Td^2$，合计 $24Td^2$。计算 $QK^\top$ 是一个 $(T\times d)(d\times T)$ 乘积，$2T^2d$ 次浮点运算，把 $T\times T$ 的权重乘以 $V$ 同样花 $2T^2d$，共 $4T^2d$；分成多头不改变总数。比值为 $4T^2d/(24Td^2) = T/(6d)$。由于边长 $H$ 的正方形图像有 $T\propto (H/P)^2$，注意力代价 $4T^2d$ 随 $H^4$ 增长，而线性代价只随 $H^2$ 增长。
:::

::: example 从缩略图到文档 {#ex-cost}
比较 ViT-B/16（$d = 768$）在 $224\times224$ 与 $1024\times1024$ 像素下注意力的份额——后者是阅读一页文档的典型分辨率。
::: solution
$224$ 时，$T = 197$，$T/(6d) = 197/4608 = 0.043$，注意力约占矩阵浮点运算的 $4\%$；这头 ViT 像短上下文的语言模型一样由线性层主导。$1024$ 时，$T = 64^2 + 1 = 4097$，$T/(6d) = 0.89$，注意力的开销几乎与其余所有部分之和相当，而整层约是 $224$ 时的 $40$ 倍（线性部分 $\times20.8$，注意力部分 $\times430$）。这就是高分辨率视觉模型改用更大的图块、合并相邻词元、把注意力限制在窗口内、或把图像切成瓦片的原因（[[multimodal/vision-language-models]]）。
:::
:::

::: widget plot

x: 64, 1024
y: 0, 2
sliders: p=16:8:32:2; d=768:384:1280:128
hlines: 1

caption: 比值 $T/(6d)$（[[#prop-vit-cost]]）随图像边长 $x$（像素）的变化，图块大小为 $p$、宽度为 $d$。在水平线处，注意力的开销与全部线性层之和相等。$p = 16$、$d = 768$ 时，交叉恰在 $1000$ 像素之上；图块越大，交叉点越远，代价是对图像看得越粗。
:::

层级的设计直接攻击平方项。**Swin Transformer**（Liu 等人，2021）在 $7\times7$ 图块的局部窗口内计算注意力，在层间错开窗口网格让信息跨越窗口边界，并在各阶段之间合并相邻图块，从而像卷积网络一样给出多个尺度的特征图；其代价与像素数成正比。相形之下，普通的 ViT 保持单一尺度和全局注意力，这让它更容易扩展，也更容易接到语言模型上。

## 归纳偏置与数据 {#sec-bias}

卷积层有两条内建假设：**局部性**（每个输出只依赖一个小邻域）与**平移等变性**（输入平移，输出随之平移；[[neural-networks/convolutional-networks#prop-equivariance]]）。这些假设就是一种**归纳偏置**——在任何数据出现之前就定下来的、对某些函数而非另一些函数的偏好。ViT 的归纳偏置要少得多。只有图块嵌入是局部的，而且它只对 $P$ 的整数倍平移等变；注意力层从第一层起就能让任意图块与任意图块发生关联，而二维布局必须通过位置编码来学习。

偏置少，就必须从数据里学得多。Dosovitskiy 等人把这一点此讲得很清楚：他们先后在越来越大的数据集上预训练、再到 ImageNet 上微调：

- 在 **ImageNet-1k**（约 $130$ 万张图像）上预训练时，ViT-L/16 比 ViT-B/16 差，也比同规模的 ResNet 差——尽管加了正则化，更大的模型还是过拟合了；
- 在 **ImageNet-21k**（约 $1400$ 万张图像）上，两个家族大体持平；
- 在 Google 内部的 **JFT-300M**（约 $3$ 亿张图像）上，ViT 反超了 ResNet，ViT-H/14 微调后在 ImageNet 上达到 $88.55\%$ 的 top-1 准确率，而其预训练算力比所对照的卷积基线还少。

这是一个**经验性结论**，不是定理：交叉点取决于被比较的架构、正则化与训练配方。后来的工作表明，强数据增强与正则化能在小规模时缩小差距，而用现代配方训练的卷积网络（ConvNeXt；Liu 等人，2022）依旧竞争力十足。长存的教训正是语言建模里熟悉的那条（[[scaling/scaling-laws]]）：数据与算力足够时，假设宽松的通用架构照样能很好地扩展，而且它的假设可以学着得到。对多模态系统而言，ViT 的另一条优点至少同样重要：它的输出是一个向量的序列，语言模型可以对它做注意力。

::: warning ViT 并非任何深刻意义上的“无卷积”，也并非无偏置
两种相反的误解都很常见。一种是认为 ViT 根本没有归纳偏置：图块网格、共享的图块投影与学习到的位置都在约束它，而 $P = 16$ 的 ViT 无法表示比它的图块嵌入所能保留的细节更细的东西。另一种是把图块嵌入当作 CNN 词干（stem）那样的特征提取器：如 [[#prop-patch-conv]] 所示，它只是一个线性映射，而 CNN 早期各层所做的一切，都必须由注意力和前馈层来做。ViT 论文试验过的混合模型——把 CNN 的特征图喂给 Transformer——正处在两者之间。
:::

## 没有海量带标签数据集也能训练 ViT {#sec-training}

数以亿计的带标签图像数据集稀少，而且大多不公开。三条工作路线让 ViT 不依赖它们也能训练：更好的监督配方、自监督预训练，以及（下一章的）以说明文字为监督。

### DeiT：数据高效的训练与蒸馏 {#sec-deit}

Touvron 等人（2021）只在 ImageNet-1k 上训练 ViT，单机八卡 GPU 约三天，就追平了代价相近的卷积网络。配方主要是繁重的增强与正则化——RandAugment、Mixup、CutMix、随机擦除、随机深度、重复增强——外加 $300$ 个轮次：DeiT-B，即 ViT-B 架构，在 ImageNet 上达到 $81.8\%$ 的 top-1。

他们加了一个**蒸馏词元**：又一个学习到的词元，与 CLS 类似，让它的输出去预测一个卷积教师给出的标签，而不是真实标签。

::: definition 经由词元的硬标签蒸馏（DeiT） {#def-deit}
设 $\mathbf{p}_{\text{cls}}$ 与 $\mathbf{p}_{\text{dist}}$ 是学生的分类词元与蒸馏词元的 softmax 输出，$y$ 是真实标签，$y_t = \arg\max_k \mathbf{p}_{\text{teacher}}(k)$ 是教师的预测。DeiT 的硬蒸馏损失为

$$
\mathcal{L} = \tfrac12\,\big(-\log p_{\text{cls}}(y)\big) + \tfrac12\,\big(-\log p_{\text{dist}}(y_t)\big).
$$ {#eq-deit}

测试时把两个头的 softmax 输出相加。
:::

换上 RegNet 教师后，蒸馏版 DeiT-B 达到约 $83.4\%$，提高了一分半还多。教师的标签把卷积归纳偏置的一部分带进了学生，还能纠正那些增强后的图像——激进裁剪之后，真实标签已经与图上所见不符。蒸馏的一般处理见 [[post-training/distillation]]。

::: example 手算 DeiT 损失 {#ex-deit}
一张训练图像的真实标签为 $y = 0$，教师预测类别 $1$。学生的分类词元给出概率 $(0.6, 0.3, 0.1)$，蒸馏词元给出 $(0.2, 0.7, 0.1)$。计算 [[#eq-deit]]，并给出测试时的预测。
::: solution
$\mathcal{L} = \tfrac12(-\ln0.6) + \tfrac12(-\ln0.7) = \tfrac12(0.511 + 0.357) = 0.434$。测试时两个输出相加，得 $(0.8, 1.0, 0.2)$，模型预测类别 $1$——在这里站到了教师一边。训练时，只要教师与标签不一致，两个词元就会被拉向不同的目标。
:::
:::

### 掩码自编码器 {#sec-mae}

BERT 靠预测被掩码的词元从文本中学习（[[transformers/architecture-families#def-mlm]]）。同样的想法在图像上早被反复尝试过，但只遮 $15\%$ 的图像太容易：缺失的图块可以靠相邻图块插值填出来，因为图像比文本冗余得多。He 等人（2022）发现，遮掉图像的大部分，任务才足够难，难到能教出语义。

::: definition 掩码自编码器（MAE） {#def-mae}
给定图像的 $N$ 个图块，随机抽出一个 $(1 - m)N$ 个**可见**图块的子集，$m$ 为**掩码比例**（默认 $0.75$）。**编码器**是一个 ViT，只嵌入并处理可见图块（连同它们的位置编码）。一个轻量的**解码器** Transformer 接收编码后的可见词元，并在每个被掩码的位置放上一个共享的学习**掩码词元**，加上位置编码，预测每个图块的像素。损失是预测像素与真实像素之间的均方误差，**只在被掩码的图块上**计算；目标取每个图块的像素按该图块的均值与标准差归一化后的值。预训练之后解码器被弃用，编码器拿去微调或当作特征提取器。
:::

两个设计让 MAE 高效。编码器从不接触掩码词元，所以只跑四分之一的序列；解码器很小（默认 $8$ 个块、宽度 $512$），它在完整序列上的开销不大。上面那段代码抽出了 $196$ 个图块中随机的 $25\%$——正是 MAE 编码器要处理的 $49$ 个可见图块。He 等人报告，相比编码完整序列，训练加速三倍以上；仅在 ImageNet-1k 上预训练再微调的 ViT-H 达到 $87.8\%$ 的 top-1，是当时只用这一数据集的最好成绩。

::: example 掩码省下多少 {#ex-mae-cost}
对 $224\times224$ 的 ViT-B/16（$T = 196$ 个图块词元，$d = 768$），用 [[#prop-vit-cost]] 计算掩码比例 $0.75$ 时编码器每层的浮点运算数，以在全部 $196$ 个图块上计算的分数表示。
::: solution
全部图块时代价为 $24Td^2 + 4T^2d$。可见图块 $T' = 49$ 时，线性部分缩到 $0.25$，注意力部分缩到 $0.25^2 = 0.0625$。数值上，$24\cdot196\cdot768^2 + 4\cdot196^2\cdot768 = 2.775\times10^9 + 0.118\times10^9 = 2.893\times10^9$ 次浮点运算，而掩码后的编码器花 $0.694\times10^9 + 0.0074\times10^9 = 0.701\times10^9$，比例为 $0.242$。这一分辨率下注意力项很小，所以节省接近词元数减少带来的 $4\times$；分辨率更高时省得更多。
:::
:::

::: widget plot
f: (24*(1-x)*d + 4*t*(1-x)^2)/(24*d + 4*t)
x: 0, 0.95
y: 0, 1
sliders: t=196:49:4096:1; d=768:384:1280:128
labels: encoder cost relative to no masking
caption: 编码器每层浮点运算数（相对于不掩码）随掩码比例 $x$ 的变化，其中 $t$ 个图块词元、宽度 $d$（据 [[#prop-vit-cost]]：线性代价 $\propto(1-x)$，注意力 $\propto(1-x)^2$）。$t = 196$ 时曲线几乎是直线；词元数以千计时，注意力项把曲线进一步压低，所以高分辨率下掩码省得更多。
:::

为什么这么高的掩码比例行得通？答案部分是经验性的：MAE 微调后的准确率在 $75\%$ 掩码附近达到峰值，掩码太少时网络靠局部插值就能应付。$75\%$ 的重建迫使编码器表示物体是什么、各部件大致在哪里，因为要预测缺失的车轮或眼睛，别无他法。预测出的图块是模糊的——MSE 损失在多种合理的补全之间取平均——但重建模糊无所谓，因为保留下来的只有编码器。

### 自蒸馏：DINO {#sec-dino}

另有一种自监督配方，训练一个 ViT 在不同视角之间与自己保持一致。**DINO**（Caron 等人，2021）中，架构相同的学生网络与教师网络各输出一个 $K$ 维原型上的概率向量（Caron 等人取 $K = 65{,}536$）。学生看到一张图像的若干随机裁剪——两个大的“全局”裁剪与几个小的“局部”裁剪——并被交叉熵训练去匹配教师在全局裁剪上的输出。教师不用梯度训练：它的权重是学生权重的指数移动平均。为避免坍缩成常数输出，对教师的 logit 做**中心化**（减去滑动均值），并用很低的 softmax 温度**锐化**。Caron 等人观察到，DINO 训练的 ViT 里 CLS 词元的自注意力会在没有任何分割标签的情况下凸显物体边界。DINOv2（Oquab 等人，2023）把配方扩大到精心整理的 $1.42$ 亿张图像，产出的通用图像特征被广泛地以冻结方式使用；Darcet 等人（2024）发现，大型 ViT 会把少数几个背景图块词元挪用为全局的草稿空间，在注意力图中留下伪影，而加上少量额外学习到的“寄存器”（register）词元就能消除它们。

::: quiz
一个掩码比例 $0.75$ 的 MAE 在 $224\times224$、$P = 16$ 的图像上预训练。哪条说法正确？
- [ ] 编码器处理 $196$ 个词元，其中 $147$ 个是掩码词元。
- [x] 编码器处理 $49$ 个图块词元；掩码词元只加在解码器里，损失在 $147$ 个被掩码的图块上计算。
- [ ] 损失在全部 $196$ 个图块上计算，使可见图块也被重建。
- [ ] 解码器在预训练后保留，用于分类。
::: solution
在 MAE 中，编码器只看到图块中可见的四分之一，且不包含掩码词元，这正是它高效的来源。解码器插入掩码词元并预测所有图块，但损失只计被掩码的那些，而解码器在预训练后被弃用。
:::
:::

## 突破固定的正方形输入 {#sec-variable}

多模态模型的真实输入——截图、收据、宽幅照片、书页——很少是 $224\times224$。硬缩成正方形会扭曲文字与形状；裁剪会丢内容。由于 ViT 把图像当作序列，它完全可以接受数量可变的图块。**NaViT**（Dehghani 等人，2023）按图像各自的原始长宽比训练，把多张图像的图块**打包**进一条序列，并用注意力掩码使图块只与同一张图像的图块互相注意，训练时随机采样分辨率。当前视觉-语言模型的多数视觉编码器（截至 2026 年）都沿用这一做法或它的变体，通常配二维旋转位置编码，使新的网格尺寸无需插值。另一条路——把大图像切成固定尺寸的瓦片逐块编码——见 [[multimodal/vision-language-models#sec-tiling]]。

::: application 多模态模型中的 ViT 骨干
CLIP 与 SigLIP 的图像编码器（[[multimodal/contrastive-learning]]）就是 ViT，而视觉-语言模型喂给语言模型的，是它们的图块输出而不只是 CLS 向量。扩散 Transformer（[[multimodal/image-generation#sec-dit]]）把图块思想用到了带噪的潜图像上。每一处都重现着本章的问题：一张图像花多少词元，图块大小又丢掉了什么？
:::

::: history
早在 2020 年之前，注意力就被加进过卷积网络（非局部网络，Wang 等人，2018；注意力增强的卷积，Bello 等人，2019），Cordonnier 等人（2020）还把自注意力用在了 $2\times2$ 的图块上。Google 的 Dosovitskiy 与合作者于 2020 年 10 月发布了《一幅图像值 16×16 个词：用于图像识别规模化的 Transformer》（An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale，ICLR 2021），证明只要预训练数据足够多，$16\times16$ 图块上的普通 Transformer 就能与卷积网络匹敌。DeiT（Touvron 等人，ICML 2021）证明配上对的配方 ImageNet-1k 就够用，Swin（Liu 等人，ICCV 2021）带来了层级结构与窗口注意力。自监督的 ViT 接踵而至：DINO（Caron 等人，ICCV 2021）、BEiT（Bao 等人，ICLR 2022）——预测被掩码图块的离散视觉词元——以及 MAE（He 等人，CVPR 2022）。DINOv2（2023）、NaViT（2023）与寄存器词元（2024）进一步打磨了如今充当多模态模型眼睛的编码器。
:::

::: summary
- ViT 把图像切成 $N = HW/P^2$ 个互不重叠的图块，每个线性投影到 $d$ 维（等价于一次步幅为 $P$ 的卷积），前置一个 CLS 词元并加上学习到的位置编码：$224\times224$、$P = 16$ 时得到 $196 + 1 = 197$ 个词元。
- 没有位置编码，Transformer 是置换等变的，看到的是一袋图块；一维学习编码能发现二维布局，分辨率改变时对它们做二维插值。
- 每层之中，注意力的代价是线性层的 $T/(6d)$；图块大小固定时，它随图像边长的四次方增长，这就是高分辨率输入昂贵的原因。
- ViT 的归纳偏置弱于 CNN；它们在小数据集上落后，在数以亿计的训练图像上反超 CNN（经验性结论）。
- DeiT 在 ImageNet-1k 上以强增强与经由词元的蒸馏训练 ViT；MAE 掩码 $75\%$ 的图块、只编码可见的那些、重建归一化后的像素；DINO 训练学生在不同裁剪之间匹配 EMA 教师。
- 多模态模型的视觉编码器是 ViT，而且越来越多地用原生分辨率与长宽比。
:::

::: solution
$T = (512/16)^2 + 1 = 1025$，$T/(6d) = 1025/6144 = 0.1668$，四舍五入为 $0.167$。

::: exercise 高分辨率下的注意力内存 {level=2 check="402.8"}
把 ViT-B/16（$12$ 个头）用于一张 $1024\times1024$ 的图像。若某一层的一个注意力权重张量以 16 位浮点数显式存放，一张图像它占多少兆字节（$10^6$ 字节）？保留一位小数。
::: solution
$T = 64^2 + 1 = 4097$，所以每个头有 $4097^2 = 16{,}785{,}409$ 个权重；$12$ 个头、每个 $2$ 字节，$16{,}785{,}409\cdot12\cdot2 = 402{,}849{,}816$ 字节，每层 $402.8$ MB。融合的注意力核可以避免存放这个张量（[[transformers/efficient-attention]]），但计算量仍是平方的。
:::

::: exercise 一道 DeiT 损失 {level=2 check="0.805"}
在 [[#def-deit]] 的设定下，真实标签为 $y = 2$，教师也预测类别 $2$。分类词元给出 $p_{\text{cls}}(2) = 0.5$，蒸馏词元给出 $p_{\text{dist}}(2) = 0.4$。计算损失，保留三位小数。
::: solution
$\mathcal{L} = \tfrac12(-\ln0.5) + \tfrac12(-\ln0.4) = \tfrac12(0.6931 + 0.9163) = 0.805$，保留三位小数。这里教师与标签一致，所以两项都推向类别 $2$。
:::

::: exercise 切块与还原 {level=2}
用纯 Python 写函数 `patchify(img, P)`，把一个 $H\times W$ 的嵌套列表（单通道）变成按光栅顺序排列的 $N = HW/P^2$ 个展平图块的列表；再写 `unpatchify(patches, H, W, P)` 将其逆转。在一张 $6\times4$、$P = 2$ 的图像上验证 `unpatchify(patchify(img, P), H, W, P) == img`。
::: solution
```python
def patchify(img, P):
    H, W = len(img), len(img[0])
    return [[img[r + i][c + j] for i in range(P) for j in range(P)]
            for r in range(0, H, P) for c in range(0, W, P)]

def unpatchify(patches, H, W, P):
    img = [[0] * W for _ in range(H)]
    per_row = W // P
    for n, p in enumerate(patches):
        r, c = (n // per_row) * P, (n % per_row) * P
        for k, v in enumerate(p):
            img[r + k // P][c + k % P] = v
    return img

img = [[10 * r + c for c in range(4)] for r in range(6)]
ps = patchify(img, 2)
print(len(ps), ps[1], unpatchify(ps, 6, 4, 2) == img)
```

```text
6 [2, 3, 12, 13] True
```

第 $n$ 个图块起于第 $(n\,\mathrm{div}\,(W/P))\cdot P$ 行、第 $(n\bmod (W/P))\cdot P$ 列，图块中第 $k$ 个元素位于偏移 $(k\,\mathrm{div}\,P, k\bmod P)$。显示重建结果时，MAE 的解码器输出就是按这种方式还原的。
:::
:::

许多视觉-语言模型的视觉编码器在 $336\times336$ 像素下使用 $P = 14$。这样的一张图像产生多少个图块词元（不含任何 CLS 词元）？
::: solution
每边 $336/14 = 24$ 个图块，所以 $24^2 = 576$ 个图块词元。

::: exercise 打乱的图块 {level=3}
(a) 用 [[#prop-perm]] 证明：不加位置编码的 ViT，对一张图像与对任意一张由它置换图块得到的图像，给出相同的 CLS 输出。(b) 在使用学习位置编码时，给出一个理由说明为什么实践中网络仍能对适度的打乱保持相当的稳健性，再给出一个理由说明为什么它不是不变的。
::: solution
(a) 打乱图块就是把输入矩阵 $Z_0$ 的第 $2, \dots, N + 1$ 行置换（图块嵌入对每个图块独立施加，所以置换图块就置换了它们的嵌入），CLS 所在行不动。由 [[#prop-perm]]，输出按同样方式置换，而输出的 CLS 行不变；分类头只读那一行。

(b) 加位置编码时，图块 $i$ 的输入行是 $\mathbf{z}^{(\pi(i))} + \mathbf{e}_i$：内容与位置是相加的，所以网络可以用位置，也可以不用。许多识别判断主要取决于有哪些局部纹理与部件，这些信息打乱后仍在，所以准确率可能平缓下降。之所以不是不变的，是因为各 $\mathbf{e}_i$ 互不相同，两个图块之间的注意力分数依赖它们的位置编码，而物体形状、部件的排布这类特征会被打乱破坏。
:::
:::

::: exercise 插值权重 {level=3}
$14\times14$ 网格上的位置编码按四角对齐缩放到 $24\times24$，如 [[#ex-interp]]。(a) 写出位置 $(5, 7)$ 处的新编码由哪四个旧编码以怎样的双线性权重构成。(b) 证明每个新位置上的权重非负且和为 $1$，并解释为什么这使得插值后的编码与原来保持同一尺度。
::: solution
(a) 旧坐标为 $5\cdot13/23 = 2.826$ 与 $7\cdot13/23 = 3.957$。行权重：第 $2$ 行 $1 - 0.826 = 0.174$，第 $3$ 行 $0.826$；列权重：第 $3$ 列 $1 - 0.957 = 0.043$，第 $4$ 列 $0.957$。用未舍入的分数计算，四个权重为 $(2, 3)$ 处 $0.0076$、$(2, 4)$ 处 $0.1664$、$(3, 3)$ 处 $0.0359$、$(3, 4)$ 处 $0.7902$；它们和为 $1$。

(b) 一维上权重为 $1 - f$ 与 $f$，$f\in[0, 1)$，非负且和为 $1$；双线性权重是行、列权重的乘积，因此非负且和为 $(1 - f_r + f_r)(1 - f_c + f_c) = 1$。于是每个新编码都是旧编码的凸组合，落在它们的凸包内，其范数至多是四个旧范数的最大者，模型的输入尺度得以保持——若是外推式的方案，就可能产生训练中从未见过的编码。
:::
:::
