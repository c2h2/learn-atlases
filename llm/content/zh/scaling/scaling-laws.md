用同一份数据、同一套配方，训练一族只有大小不同的语言模型，再在双对数坐标上把它们的最终测试损失对参数量作图：各点几乎落在一条直线上。把参数量换成训练词元数、或换成花掉的计算量，得到的仍是直线。横跨五个、六个、有时七个数量级，语言模型的损失是你投入资源的平滑、可预测的函数。这一规律——**缩放定律**——是机器学习中最具影响的经验发现之一。它让建模更接近工程：在为数千万美元的一次训练掏钱之前，可以先训练一系列小模型、拟合一条曲线，并预测大模型将达到什么水平。

本章讲这些曲线是什么、如何测量与拟合、以及能在多大程度上信任它们。我们定义幂律形式与不可归约损失，用一个小程序在对数空间按最小二乘拟合幂律，陈述 Kaplan et al.（2020）的结果连同得到这些结果时所处的条件，然后转向局限：为什么外推有风险，为什么拟合出的指数取决于模型里还有什么，以及为什么损失曲线平滑并不意味着人们真正关心的那些能力也随规模平滑变化。下一章[[scaling/compute-optimal-training]]用这些定律来决定如何在参数与数据之间划分计算预算。我们测量的输出来自预训练流水线，其本身见[[pretraining]]；对进行中运行的评估见[[pretraining/in-training-evaluation]]。

## 测量什么 {#sec-measure}

三个量刻画一次训练运行的规模。

- $N$，**参数量**。Kaplan et al.（2020）只数**非嵌入**参数，把词元嵌入矩阵与位置嵌入矩阵排除在外；Hoffmann et al.（2022）则全部计入。这一选择在小型模型上很要紧，因为嵌入占模型总量的很大份额（[[scaling/compute-optimal-training#sec-why-differ]]）。
- $D$，所处理的**训练词元数**。若数据被重复使用，$D$ 把每一遍都计入；重复的词元是否与新鲜词元同样值钱，则是另一个问题（[[scaling/compute-optimal-training#sec-data-constrained]]）。
- $C$，以浮点运算数（FLOPs）计的**训练计算量**。对稠密 Transformer，$C\approx6ND$：前向传播每词元每参数两次 FLOPs，反向传播四次。带注意力修正的推导见[[scaling/flops-memory]]。较早的论文用**拍浮点运算/天（petaflop/s-day，PF-day）**报告计算量：$1$ PF-day $= 10^{15}\cdot86{,}400 = 8.64\times10^{19}$ FLOPs。

响应量是**损失**：模型在训练分布的留出文本上的下一词元预测的平均交叉熵，以纳特每词元计（[[text-and-language/perplexity]]）。损失有两个性质，使它成为自然的建模对象。其一，它是对数百万词元做的连续、低噪声平均，因此微小的改进也能测出来；其二，它正是训练运行实际优化的量，因此它直接对规模作出响应，而不必透过某个门槛。

一项缩放研究会固定除被研究变量以外的一切：架构家族、分词器、数据分布、优化器与学习率配方。每个实验都是一次训练运行，所以研究几十种尺寸本身就是一笔可观的计算预算。常见的测量有两类。在**规模扫描**中，不同 $N$ 的模型在多得让数据不成瓶颈的数据上训练，它们收敛后的损失给出 $L(N)$。在**数据扫描**中，用一个大到不成瓶颈的模型在不同大小的数据子集上训练并配早停，得到 $L(D)$。把许多运行中每个计算预算下达到的最好损失画在一起，就得到**计算效率前沿** $L(C)$。

## 幂律 {#sec-power-laws}

::: definition 幂律与缩放指数 {#def-power-law}
正量 $L$ 在 $x > 0$ 上按**指数** $\alpha > 0$ 服从**幂律**，若对某些常数 $x_c, A > 0$ 有

$$
L(x) = \left(\frac{x_c}{x}\right)^{\alpha} = A\,x^{-\alpha},\qquad A = x_c^{\alpha},
$$ {#eq-power}

成立。取对数得 $\log L = \log A - \alpha\log x$：幂律就是**双对数坐标上斜率为 $-\alpha$ 的直线**。
:::

幂律的定义性质是**尺度不变性**：把 $x$ 乘以固定因子 $k$，就把 $L$ 乘以固定因子 $k^{-\alpha}$，无论你从哪一点出发。模型每翻一倍，买到的都是同样**相对**幅度的改进。指数律的行为不同——$x$ 的每个固定**增量**买到一个固定倍率——它们会在半对数坐标上呈直线。区分两者需要横跨宽范围的数据，这正是缩放图要跨越许多数量级的原因。

::: example 读出指数 {#ex-exponent}
Kaplan et al.（2020）报告 $L(N)\approx(N_c/N)^{0.076}$，其中 $N_c\approx8.8\times10^{13}$ 为非嵌入参数量。预测一个 $N = 10^9$ 的模型的损失，以及把 $N$ 翻倍换来的改进。
::: solution
$L(10^9) = (8.8\times10^{13}/10^9)^{0.076} = 88{,}000^{0.076} = e^{0.076\cdot11.385} = e^{0.865} = 2.38$ 纳特每词元。把 $N$ 翻倍使损失乘以 $2^{-0.076} = 0.949$：降低 $5.1\%$，降到约 $2.25$。每次翻倍都买到同样的 $5.1\%$，无论是从 $10^6$ 个参数到 $2\times10^6$ 个，还是从 $10^{11}$ 个到 $2\times10^{11}$ 个——只是后一次次翻倍贵上一千倍。
:::
:::

纯幂律在 $x\to\infty$ 时降到零，这对交叉熵不可能成立：自然文本的熵为正，没有模型能把损失压到它以下。真实曲线在大规模处会弯离直线，表达这一点的标准方式是加一个常数项。

::: definition 不可归约损失 {#def-irreducible}
**带不可归约项的幂律**形如

$$
L(x) = E + A\,x^{-\alpha},
$$ {#eq-irreducible}

其中 $E\ge0$。常数 $E$ 是**不可归约损失**——即 $x\to\infty$ 的极限——$L - E$ 则是**可归约损失**。按 Henighan et al.（2020）的理想化解释，$E$ 估计数据分布的熵，$L - E$ 估计数据与模型之间的 KL散度。
:::

上一句中的解释只是启发而非精确。拟合出的 $E$ 还吸收了模型家族在任何规模下**都**学不会的一切——分词器、上下文长度与架构的局限——而且它的取值取决于拟合用的是哪一段范围。有若干种资源时，就给每种资源各加一个衰减项，比如下一章赖以建立的 Chinchilla 形式 $L(N, D) = E + A/N^\alpha + B/D^\beta$。

不可归约项有个容易被忽略的后果：在双对数坐标上，[[#eq-irreducible]] 不是直线，其局部斜率也不是 $-\alpha$。

::: proposition 表观指数 {#prop-local-exponent}
对 $L(x) = E + Ax^{-\alpha}$，局部双对数斜率为

$$
\frac{\dd\log L}{\dd\log x} = -\alpha\,\frac{L - E}{L},
$$ {#eq-local}

其绝对值从 $\alpha$（当 $L\gg E$）跌落向 $0$（当 $L\to E$）。而 $\log(L - E)$ 对 $\log x$ 的斜率处处恰为 $-\alpha$。
:::

::: proof
记 $u = \log x$，则 $x^{-\alpha} = e^{-\alpha u}$，$L = E + Ae^{-\alpha u}$。于是 $\dd L/\dd u = -\alpha Ae^{-\alpha u} = -\alpha(L - E)$，从而 $\dd\log L/\dd u = (\dd L/\dd u)/L = -\alpha(L - E)/L$。第二个断言：$\log(L - E) = \log A - \alpha u$ 关于 $u$ 线性，斜率为 $-\alpha$。
:::

所以，把 $\log L$ 对 $\log N$ 作直线拟合，测到的是 $\alpha$ 与所拟合范围内可归约损失占总损失之比的混合。两项底层 $\alpha$ 相同的研究，若损失离 $E$ 的远近不同，报告出的斜率可以大相径庭——已发表的指数差异悬殊，这是原因之一。

::: widget plot

sliders: a=0.34:0.05:0.6:0.01; c=1.7:0.2:3:0.1

caption: 双对数坐标上的损失对参数量（$x = \log_{10}N$，$y = \log_{10}L$，$A = 400$）。纯幂律是斜率为 $-\alpha$ 的直线。加上不可归约损失 $E$（滑杆 $c$）后，曲线弯向水平线 $\log_{10}E$：$N$ 小时它贴着幂律走，$N$ 大时趋于平坦。在 $N = 10^6$ 到 $10^8$ 的范围内曲线看上去几乎是一条直线——但斜率只有 $\alpha$ 的一半左右，正如[[#prop-local-exponent]]所预言。
:::

## 拟合幂律 {#sec-fitting}

给定测量 $(x_i, L_i)$，$i = 1,\dots,n$，拟合[[#eq-power]]最简单的方式，就是对对数值做普通最小二乘。

::: proposition 对数空间最小二乘 {#prop-logfit}
设 $u_i = \log x_i$、$v_i = \log L_i$，均值为 $\bar u, \bar v$。使 $\sum_i\big(v_i - a + \alpha u_i\big)^2$ 最小的 $a = \log A$ 与 $\alpha$ 为

$$
\hat\alpha = -\frac{\sum_i(u_i - \bar u)(v_i - \bar v)}{\sum_i(u_i - \bar u)^2},\qquad \hat a = \bar v + \hat\alpha\bar u.
$$ {#eq-logfit}

若测量误差是乘性的，即 $L_i = A x_i^{-\alpha}e^{\varepsilon_i}$，各 $\varepsilon_i\sim\Normal(0,\sigma^2)$ 相互独立，则该估计是最大似然估计。
:::

::: proof
目标函数是线性模型 $v = a + bu$（其中 $b = -\alpha$）的残差平方和。令其偏导为零，得 $\sum_i(v_i - a - bu_i) = 0$，于是 $a = \bar v - b\bar u$；又 $\sum_i u_i(v_i - a - bu_i) = 0$，把前式代入后式得 $b = \sum_i(u_i - \bar u)(v_i - \bar v)/\sum_i(u_i - \bar u)^2$，即简单线性回归里熟悉的斜率公式（[[ml-fundamentals/linear-regression]]）。目标函数是凸二次的，故该驻点就是最小值。在乘性模型下，$v_i = a + bu_i + \varepsilon_i$ 且 $\varepsilon_i$ 为高斯，对数似然是 $-\frac{1}{2\sigma^2}\sum_i(v_i - a - bu_i)^2$ 加一个常数，在同一个 $a, b$ 处取最大。
:::

在对数空间拟合是一个建模选择，而非只求省事：它按**相对**误差给每个点加权，所以 $1\%$ 的偏差在损失 $5$ 处与在损失 $2$ 处权重相同。若直接对 $L$ 本身做最小二乘，最大的那些损失（也就是最小的那些模型）会占支配地位。乘性噪声也是对训练损失随种子涨落的恰当描述。

带上不可归约项后，问题不再线性。一个稳健的做法是对 $E$ 作**剖面**：对小于最小观测损失的每个候选 $E$，$\log(L_i - E)$ 关于 $\log x_i$ 线性，于是[[#eq-logfit]]给出该 $E$ 下最好的 $A$ 与 $\alpha$；保留拟合曲线在 $\log L$ 上误差最小的那个 $E$。Hoffmann et al.（2022）则改为在 $\log L_i$ 与模型的对数之间最小化 Huber 损失（$\delta = 10^{-3}$），用 L-BFGS 并从一组初值出发；Huber 损失限制了离群运行的影响。下面的程序从 $L = 1.7 + 400N^{-0.34}$ 生成带 $1\%$ 乘性噪声的合成损失，在最小的九种尺寸（$10^6$ 到 $10^8$ 个参数）上拟合两种形式，然后外推。

```python
import math, random

random.seed(0)
E_true, A_true, alpha_true = 1.7, 400.0, 0.34       # L(N) = E + A / N^alpha
Ns = [10 ** (6 + 0.25 * k) for k in range(13)]      # 1e6 ... 1e9 个参数
data = [(N, (E_true + A_true * N ** -alpha_true) * math.exp(random.gauss(0, 0.01)))
        for N in Ns]                                # 1% 乘性噪声

def linfit(xs, ys):
    """Least-squares line y = a + b x; returns a, b, residual sum of squares."""
    n = len(xs); mx = sum(xs) / n; my = sum(ys) / n
    sxx = sum((x - mx) ** 2 for x in xs)
    b = sum((x - mx) * (y - my) for x, y in zip(xs, ys)) / sxx
    a = my - b * mx
    return a, b, sum((y - a - b * x) ** 2 for x, y in zip(xs, ys))

def fit_pure(pts):                                  # log L = log A - alpha log N
    a, b, rss = linfit([math.log(N) for N, _ in pts], [math.log(L) for _, L in pts])
    return math.exp(a), -b, rss

def fit_with_E(pts):                                # 对 E 作剖面：log(L - E) 线性
    best = None
    Lmin = min(L for _, L in pts)
    for i in range(1, 2000):
        E = Lmin * i / 2000
        a, b, _ = linfit([math.log(N) for N, _ in pts], [math.log(L - E) for _, L in pts])
        rss = sum((math.log(L) - math.log(E + math.exp(a) * N ** b)) ** 2 for N, L in pts)
        if best is None or rss < best[0]:
            best = (rss, E, math.exp(a), -b)
    return best[1:]

small = data[:9]                                    # 只在 1e6 ... 1e8 上拟合
A1, al1, _ = fit_pure(small)
E2, A2, al2 = fit_with_E(small)
print(f"pure power law   : L = {A1:.3f} N^-{al1:.4f}")
print(f"with irreducible : L = {E2:.3f} + {A2:.1f} N^-{al2:.4f}")
print(" N        observed  pure-fit  E-fit")
for N, L in data:
    tag = "" if (N, L) in small else "  <- extrapolated"
    print(f"{N:8.1e}  {L:.4f}    {A1 * N ** -al1:.4f}    {E2 + A2 * N ** -al2:.4f}{tag}")
for N in (1e11, 1e13):
    print(f"{N:8.1e}  true {E_true + A_true * N ** -alpha_true:.4f}  "
          f"pure {A1 * N ** -al1:.4f}  E-fit {E2 + A2 * N ** -al2:.4f}")
```

在所拟合范围内，纯幂律不算差——误差只有百分之几——但其指数 $0.170$ 只有真值 $0.34$ 的一半，恰如[[#prop-local-exponent]]所预言：在 $N = 10^7$ 处 $(L - E)/L = 1.65/3.35 = 0.49$，而 $0.34\cdot0.49 = 0.17$。外推一个数量级，它已乐观了 $23\%$；到 $10^{13}$ 处它预测损失 $0.33$，远低于熵的下限。带 $E$ 的拟合把 $\alpha$ 恢复得很好（$0.339$），即使在 $10^{13}$ 处外推也在 $2\%$ 以内，只是它的 $E$ 略偏低，所以误差偏向乐观。这两个结论都取决于数据是否真的服从[[#eq-irreducible]]——在合成实验里我们知道，在真实实验里我们不知道。

::: example 由三次运行定出下限 {#ex-three-points}
三个 $N = 10^7, 10^8, 10^9$ 的模型的损失分别为 $L_1 = 3.367$、$L_2 = 2.462$、$L_3 = 2.048$。假设 $L = E + AN^{-\alpha}$，求 $E$ 与 $\alpha$。
::: solution
尺寸成公比 $r = 10$ 的等比数列，故可归约损失 $L_k - E$ 成公比 $r^{-\alpha}$ 的等比数列，于是 $(L_2 - E)^2 = (L_1 - E)(L_3 - E)$。展开得 $L_2^2 - 2L_2E = L_1L_3 - (L_1 + L_3)E$，所以

$$
E = \frac{L_1L_3 - L_2^2}{L_1 + L_3 - 2L_2} = \frac{6.8975 - 6.0614}{0.4910} = 1.70.
$$

于是 $10^{-\alpha} = (L_2 - E)/(L_1 - E) = 0.762/1.667 = 0.457$，故 $\alpha = 0.34$。（这些正是程序中那条定律在无噪声时的值。）数据带噪时，这个三点公式非常敏感——分母是一个二阶差分——所以真实拟合要用许多个尺寸和稳健损失。
:::
:::

## Kaplan 缩放定律 {#sec-kaplan}

让缩放定律成为语言建模研究核心的论文，是 Kaplan、McCandlish、Henighan、Brown、Chess、Child、Gray、Radford、Wu 与 Amodei（OpenAI，2020）的《神经语言模型的缩放定律》（*Scaling Laws for Neural Language Models*）。他们训练只有解码器的 Transformer，非嵌入参数量从 $7.68$ 亿到 $15$ 亿，在至多 $230$ 亿个 WebText2 词元上训练，上下文长 $1024$ 个词元，并以纳特每词元记录测试损失。

::: proposition Kaplan et al.（2020），经验结果 {#prop-kaplan}
对在 WebText2 上训练的 Transformer 语言模型，Kaplan et al. 发现，当其他资源不构成瓶颈时：

$$
\begin{aligned}
L(N) &= (N_c/N)^{\alpha_N}, & \alpha_N &\approx 0.076, & N_c &\approx 8.8\times10^{13}\ \text{非嵌入参数},\\
L(D) &= (D_c/D)^{\alpha_D}, & \alpha_D &\approx 0.095, & D_c &\approx 5.4\times10^{13}\ \text{词元},\\
L(C_{\min}) &= (C_c/C_{\min})^{\alpha_C}, & \alpha_C &\approx 0.050, & C_c &\approx 3.1\times10^{8}\ \text{PF-days},
\end{aligned}
$$

并且，关于 $N$ 与 $D$ 的联合（带早停的训练），

$$
L(N, D) = \left[\left(\frac{N_c}{N}\right)^{\alpha_N/\alpha_D} + \frac{D_c}{D}\right]^{\alpha_D}.
$$ {#eq-kaplan-nd}

这里 $C_{\min}$ 是按使计算量最小的批次大小训练时所花的计算量。他们还发现，在很宽的范围内，固定 $N$ 时损失只微弱地依赖网络的形状（深度对宽度、头数）。
:::

这是一份经验总结，不是定理，其数字带有条件。常数 $N_c, D_c, C_c$ 依赖分词器和数据，本身没有意义；本指望能迁移的只有指数，可即便指数也随数据分布、随你数的是什么而改变。这些定律没有不可归约项——作者们指出它迟早必须失效，并估计了 $L(C)$ 与 $L(D)$ 会发生冲突之处：大约在 $10^{4}$ PF-days、损失约 $1.7$ 纳特每词元。影响最大的是，他们为计算高效训练给出的建议——模型规模按 $N\propto C^{0.73}$ 增长，而数据只按 $D\propto C^{0.27}$ 增长——是从那些学习率调度并未按训练词元数调整的运行中导出的。两年之后该建议被推翻，下一章将作说明。

::: example 数据还是参数？ {#ex-kaplan-nd}
用[[#eq-kaplan-nd]]，比较一个 $N = 10^9$ 非嵌入参数的模型在 $D = 10^{10}$ 个词元上训练的损失与它在实际无限数据上的损失。
::: solution
$(N_c/N)^{\alpha_N/\alpha_D} = 88{,}000^{0.8} = 9{,}028$，而 $D_c/D = 5{,}400$，故 $L = (14{,}428)^{0.095} = 2.48$。当 $D\to\infty$ 时第二项消失，$L = 9{,}028^{0.095} = 88{,}000^{0.076} = 2.38$。一百亿个词元让这个模型相对无限数据多付出 $0.11$ 纳特每词元——差距很大，下一章的 Chinchilla 分析对一个每参数只分到十个词元的 $10^9$ 参数模型正是这样预言的。
:::
:::

Kaplan et al. 报告的其余几条规律今天仍然有用。**临界批次大小**（critical batch size，McCandlish et al., 2018）——超过它之后，再增大批次就不再按比例减少步数——随损失下降而增长，大约随损失成幂律，且与模型大小无关。更大的模型更**样本高效**：达到同样损失所需的词元更少。而向其他文本分布的**迁移**大致是损失上的一个常数偏移：在 WebText2 上训练的模型，其在书籍或维基百科上的损失以固定差价跟随着它在训练分布上的损失，所以改进会传递过去。

::: warning 双对数坐标上的直线不是幂律的证据
几乎任何光滑、缓变的单调曲线，在双对数坐标上一两个数量级的范围内都像是直线，而眼睛对轻微弯曲又极为宽容。在 $10^6$ 到 $10^8$ 个参数上拟合得完美，几乎说明不了 $10^{11}$ 处的情形。相信一次外推之前要问：这一定律是在几个数量级上拟合的？残差里有没有看得见的弯曲？舍去最大或最小的点后结论如何变化？一个带不可归约项的定律会不会同样拟合得好、外推起来却不同？Besiroglu et al.（2024）表明，即使对 Chinchilla 那份精心收集的数据重新拟合，得到的参数也明显不同（[[scaling/compute-optimal-training]]）。
:::

## 为什么是幂律？ {#sec-why}

没有人能从第一性原理推出真实语言模型的指数。不过，确实有一些模型能解释为什么预期的该是幂律，而不是指数律或对数律。

一种解释经由**数据的几何**。Sharma 与 Kaplan（2020）论证：若网络在本征维数为 $d$ 的数据流形上逼近一个函数，而 $N$ 个参数能让它把流形划分成大小约与 $N^{-1/d}$ 成正比的区域，那么分段逼近的误差就随区域大小成幂律，于是损失像 $N^{-c/d}$ 那样下降，其中 $c$ 是个小常数；他们在小实验中发现的指数接近 $4/d$。本征维数越高，指数越小；这与语言——高维、异质——的指数很小相一致。

第二种解释经由**可学之物的分布**。假设数据里有许多彼此独立的“技能”或事实，第 $k$ 个出现的频率与 $k^{-(1+a)}$ 成正比——一类类 Zipf 律，正如词频所遵循的那样（[[text-and-language/text-as-data]]）。一个恰好装得下最频繁的那 $n$ 个的模型，留下的损失与其余全部频率之和 $\sum_{k > n}k^{-(1+a)}\approx n^{-a}/a$ 成正比：这是关于容量的幂律。Hutter（2021）与 Michaud et al.（2023，“量子化模型”）发展了这一论证的各个版本；Bahri et al.（2021）则区分了资源通过方差限制损失（数据太少，定不住参数）与通过分辨率限制损失（容量太小）的各种机制，每一种都给出指数彼此相关的幂律。

这些模型是说明而非预言：它们表明幂律自然地源于重尾结构，但真实模型的指数是测出来的，不是推出来的。它们还提示，指数既是模型的性质、也是数据的性质，改变数据——过滤、去重、挑选样本——就能改变指数。Sorscher et al.（2022）在视觉实验中表明，小心剪掉简单样本原则上能给出比幂律更好的、随数据规模的缩放。

## 下游表现 {#sec-downstream}

平滑缩放的是损失，但损失不是用户关心的东西。基准上的准确率、编程题的通过率、模型能否做多位数算术——这些才是要紧的量，它们与规模的关系没那么规矩。

::: definition 涌现能力 {#def-emergent}
若某种能力在较小的模型中不存在（成绩接近随机）、在较大的模型中出现，从而无法由外推较小模型的表现来预测，Wei et al.（2022）就称它是**涌现**的。在准确率对对数计算量的图上，这类能力表现为先是一段水平线，随后陡然抬起。
:::

这种陡峭有多少来自模型本身，又有多少来自度量？Schaeffer、Miranda 与 Koyejo（2023）论证，许多被报告的涌现其实来自**不连续或非线性的度量**。假设模型答对答案每个词元的概率随规模平滑改善，但基准只有当全部 $k$ 个词元都答对时才把整个答案判为正确。那么得分大致是 $p^k$：在 $p$ 接近 $1$ 之前它一直趴在零附近，然后陡峭上升——一个平滑的输入被打扮成了突变。

::: proposition 精确匹配放大平滑的进步 {#prop-exact-match}
若答案的 $k$ 个词元各自以概率 $p$ 独立正确，则精确匹配的准确率为 $p^k$，其对数尺度上对 $p$ 的敏感度为

$$
\frac{\dd\log p^k}{\dd\log p} = k.
$$

每词元概率相对改进 $1\%$，精确匹配准确率就相对改进约 $k\%$。
:::

::: proof
$\log p^k = k\log p$，它对 $\log p$ 的导数是 $k$。独立性假设是理想化；定性结论——精确匹配目标越长，每词元的改进被放大得越多——只要误差不完全相关就成立。
:::

::: widget plot
f: 1 - 0.6*10^(-0.15*(x - 18)); (1 - 0.6*10^(-0.15*(x - 18)))^k
x: 18, 27
y: 0, 1
sliders: k=10:1:30:1
labels: per-token accuracy $p$; exact match $p^k$
caption: 对[[#prop-exact-match]]的一个理想化说明（不与任何模型拟合）。横轴是训练计算量的 $\log_{10}$；每词元准确率 $p$ 平滑上升，但对 $k$ 词元答案的精确匹配在许多个数量级的计算量里都趴在零附近，然后陡然升起。增大 $k$，表面的“涌现”就更晚出现、也更陡，尽管底层模型的一切都没有变。
:::

度量方面的解释并未了结争论。有些能力确实似乎在发生质变；而若你想预测的是某个有用性的门槛会不会被跨过，连续度量上的一条平滑曲线也帮不了多少。但它给出两条实用规则。其一，要预测某种能力，就在小模型上测量它的连续代理——正确答案的对数概率，或每词元准确率——再去外推那个代理。多个团队发现，基准准确率是预训练损失的可预测函数，常常呈 sigmoid 形（Gadre et al., 2024；Llama 3 报告，2024：用较小模型在正确答案上的损失预测了旗舰模型在一个推理基准上的准确率）。其二，不要假定规模总是越大越好：反缩放奖（Inverse Scaling Prize，McKenzie et al., 2023）收集了一批越大的模型做得**越差**的任务，比如更容易重复提示中误导性的模式，不过其中几项在更大规模上又再次反转。

::: quiz
一个团队对 $10^7$ 到 $10^9$ 个参数的模型把 $\log L$ 对 $\log N$ 拟合，得到斜率 $-0.10$。哪些说法是站得住的？
- [ ] 可归约损失的真实指数是 $0.10$。
- [x] 若损失带有不可归约部分，则可归约损失的指数大于 $0.10$。
- [ ] 该拟合把 $10^{11}$ 参数模型的损失保证在拟合误差以内。
- [x] 用精确匹配计分的基准准确率在同一范围内未必平滑改进。
::: solution
由[[#prop-local-exponent]]，总损失在双对数坐标上 $-0.10$ 的斜率意味着 $\alpha(L - E)/L = 0.10$，故 $\alpha\ge0.10$，仅当 $E = 0$ 时取等。外推超出数据两个数量级，拟合不能给出任何保证。精确匹配度量能把平滑的每词元改进变成看上去突兀的变化（[[#prop-exact-match]]）。
:::
:::

## 缩放定律的实践 {#sec-practice}

缩放定律有三种用法。

**预测**大运行的损失，用小运行来推，好在昂贵的运行开始之前揪出配方的问题。GPT-4 技术报告（OpenAI，2023）声称最终损失是用计算量少一万倍的运行预测出来的；Llama 3 报告（2024）用了两级预测：先从计算量推到基准答案上的损失，再从那个损失推到准确率。

**比较配方。**一项在某种尺寸上有用的架构、数据或优化器改动，在另一种尺寸上未必有用。把两种配方的损失在一系列尺寸上对计算量作图，再比较拟合曲线，就能区分三种情形：恒定的改进（曲线整体下移同一倍率）、随规模增大的改进（曲线更陡）、以及在大尺度上消失的改进（曲线收拢到一起）。一个有用的汇总统计量是**计算倍率**：基线配方需要多花多少倍计算量，才能与新配方的损失打平。数据质量方面的工作尤其通常这样评估（[[pretraining/data-mixtures]]）。

**分配资源**，即在参数与数据之间分配，并把批次大小、学习率这类超参数取为规模的函数来选定。分配问题是下一章的主题；超参数问题连着那些能让最优学习率从窄模型迁移到宽模型的参数化（[[pretraining/training-stability]]）。

三种用法都要求同样的纪律。每个点都必须是一次调优良好的运行：一个小模型没调好，曲线就会显得比实际更陡。学习率调度必须与运行长度相配——按更长的运行设一个余弦调度又提前停下，损失会比按实际长度调度的更差，Hoffmann et al.（2022）认定这正是早先误估的一个原因。横轴上的量必须口径一致地计数（含不含嵌入，计算量里含不含注意力项）。拟合范围应尽量延伸到预算所允许的、离目标最近的地方，因为外推的误差随外推距离增大。

::: example 要多花多少计算？ {#ex-compute-factor}
在 Kaplan 的计算前沿 $L\propto C^{-0.050}$ 上，要把损失降低 $10\%$，计算量需要多少倍？若定律为 $L = E + A C^{-0.15}$、当前损失在 $L = 2E$ 处，要把可归约损失减半，计算量需要多少倍？
::: solution
对纯定律，$(C_2/C_1)^{-0.05} = 0.9$ 给出 $C_2/C_1 = 0.9^{-20} = 8.2$。第二问要把 $L - E$ 减半，需 $(C_2/C_1)^{-0.15} = 1/2$，故 $C_2/C_1 = 2^{1/0.15} = 2^{6.67} = 102$；总损失于是从 $2E$ 降到 $1.5E$，降幅 $25\%$。损失的改进是昂贵的，而且越靠近不可归约的底线越贵。
:::
:::

::: application 用缩放定律做规划
设一个课题组拥有 $10^{24}$ FLOPs 一次运行的计算量，要在两个分词器之间做选择。两者都按全尺寸训练是付不起的。于是它对每个分词器各训五种模型大小，从 $10^{19}$ 到 $10^{21}$ FLOPs，各拟合一条计算效率前沿——记住每词元损失在分词器之间不可比，所以改测文本的**每字节比特数**——再把两者都外推到 $10^{24}$。若两条曲线在外推范围内相交，结论就不确定，需要在更大规模处补点；若一条在整个范围内都趴在另一条下面且斜率相同，结论就容易下。这项研究的开销约为最终运行的 $1\%$，而且花在大运行之前——那时还来得及改计划。
:::

::: history
幂律学习曲线在统计学与心理学里渊源已久；对神经网络，Cortes et al.（1994）用它预测更多数据能把一个分类器带到什么水平。Hestness et al.（2017，百度）在机器翻译、语言建模、图像分类与语音识别中测得了数据规模的幂律，并指出架构改动移动曲线多于改变指数。Kaplan et al.（2020，OpenAI）在许多个数量级上确立了 Transformer 语言模型关于参数、数据与计算量的幂律；Henighan et al.（2020）带着显式的不可归约项把它推广到图像、视频与数学。Hoffmann et al.（2022，DeepMind）以 Chinchilla 研究修订了计算最优分配。Wei et al.（2022）编录了涌现能力，Schaeffer et al.（2023）则质疑其中多少是度量的伪象；Hernandez et al.（2021）研究了从预训练到微调的迁移的缩放；Caballero et al.（2022）提出“破碎”幂律，在各机制之间光滑过渡。理论方面的解释来自 Sharma 与 Kaplan（2020）、Bahri et al.（2021）、Hutter（2021）与 Michaud et al.（2023）。
:::

::: summary
- **幂律** $L = (x_c/x)^\alpha$ 是双对数坐标上斜率 $-\alpha$ 的直线；$x$ 每翻倍一次，$L$ 就改善同一倍率 $2^{-\alpha}$。
- 真实损失趋近一个**不可归约**的底线：$L = E + Ax^{-\alpha}$。表观的双对数斜率是 $\alpha(L - E)/L$，小于 $\alpha$ 且随规模缩小。
- 用**对数空间最小二乘**拟合（对乘性噪声即最大似然）；有不可归约项时，对 $E$ 作剖面，或在 $\log L$ 上最小化稳健损失，Hoffmann et al. 就是这样做的。
- **Kaplan et al.（2020）**在 WebText2 上对非嵌入参数得到 $\alpha_N\approx0.076$、$\alpha_D\approx0.095$、$\alpha_C\approx0.050$；不含不可归约项，学习率调度也未与运行长度相配；指数依赖数据、也依赖计数口径。
- **外推**既是缩放定律的用途，也是它的主要风险：检查拟合范围、残差与替代形式。
- **下游**度量未必平滑缩放：精确匹配计分会放大每词元的改进（$p^k$），造成涌现的假象；先预测连续代理，再把它们映射到准确率。
:::

## 习题

::: exercise 求值 Kaplan 定律 {level=1 check="1.994"}
用 $L(N) = (8.8\times10^{13}/N)^{0.076}$ 预测一个 $10^{10}$ 个非嵌入参数模型的损失，以纳特每词元计。保留三位小数。
::: solution
$8.8\times10^{13}/10^{10} = 8800$，$\ln 8800 = 9.0825$，故 $L = e^{0.076\cdot9.0825} = e^{0.6903} = 1.994$ 纳特每词元。
:::
:::

::: exercise 翻倍换来的改进 {level=1 check="5.13"}
对 $L\propto N^{-0.076}$，$N$ 翻倍时损失下降百分之几？保留两位小数。
::: solution
$1 - 2^{-0.076} = 1 - e^{-0.076\cdot0.6931} = 1 - e^{-0.05268} = 1 - 0.94869 = 0.0513$，下降 $5.13\%$。
:::
:::

::: exercise 拍浮点运算/天 {level=1 check="3634"}
GPT-3（$1750$ 亿参数、$3000$ 亿词元）常被说成用了 $3.14\times10^{23}$ FLOPs。那是多少个 PF-day？取整到整数。并用 $6ND$ 核对这个 FLOPs 数字。
::: solution
$3.14\times10^{23}/8.64\times10^{19} = 3634$ 个 PF-day。又 $6\cdot1.75\times10^{11}\cdot3\times10^{11} = 3.15\times10^{23}$，吻合。
:::
:::

::: exercise 由两点求指数 {level=2 check="0.0792"}
两个 $N_1 = 10^8$ 与 $N_2 = 10^9$ 的模型的损失为 $3.00$ 与 $2.50$。假设纯幂律，求 $\alpha$，保留三位有效数字。若不可归约损失为 $E = 1.5$，可归约损失的指数又是多少？
::: solution
$\alpha = \log(3.00/2.50)/\log10 = \log_{10}1.2 = 0.0792$。

若 $E = 1.5$：可归约损失为 $1.5$ 与 $1.0$，故 $\alpha = \log_{10}1.5 = 0.176$，大了一倍多。
:::
:::

::: exercise 表观指数 {level=2 check="0.168"}
对 $L = 1.7 + 400N^{-0.34}$，计算 $N = 10^7$ 处局部双对数斜率的绝对值，保留三位小数，并说明在这一带尺寸附近做纯幂律拟合会报告什么。
::: solution
$L(10^7) = 1.7 + 400\cdot10^{-2.38} = 1.7 + 1.667 = 3.367$。由[[#prop-local-exponent]]，斜率绝对值为 $0.34\cdot1.667/3.367 = 0.168$。在 $10^7$ 上下的尺寸上做纯幂律拟合，会报告约 $0.17$ 的指数——[[#sec-fitting]]里的程序正是如此——只有可归约损失指数的一半。
:::
:::

::: exercise 由三次运行定底线 {level=2 check="2"}
$N = 10^8, 10^9, 10^{10}$ 的模型的损失为 $3.0$、$2.5$ 与 $2.25$。假设 $L = E + AN^{-\alpha}$，求 $E$ 与 $\alpha$。
::: solution
用[[#ex-three-points]]的公式，$E = (3.0\cdot2.25 - 2.5^2)/(3.0 + 2.25 - 5.0) = (6.75 - 6.25)/0.25 = 2.0$。可归约损失为 $1.0, 0.5, 0.25$，每个数量级减半，故 $10^{-\alpha} = 1/2$，$\alpha = \log_{10}2 = 0.301$。
:::
:::

::: exercise 精确匹配 {level=2 check="0.349"}
一个模型逐词元回答一道 $10$ 词元的问题，每个词元独立的正确概率 $p = 0.9$。它的精确匹配准确率是多少？保留三位小数。要让精确匹配准确率达到 $0.9$，每词元准确率需要多高？
::: solution
$0.9^{10} = 0.349$。要 $p^{10} = 0.9$，则 $p = 0.9^{1/10} = 0.9895$。把每词元准确率从 $0.9$ 提到 $0.99$——就损失而言只是小改动——精确匹配就从 $35\%$ 升到 $90\%$。
:::
:::

::: exercise 相对误差 {level=2}
证明对小的相对偏差，最小化 $\sum_i(\log L_i - \log\hat L_i)^2$ 近似等价于最小化 $\sum_i\big((L_i - \hat L_i)/L_i\big)^2$，并解释为什么拟合 $\sum_i(L_i - \hat L_i)^2$ 会给最小的模型过大的权重。
::: solution
记 $\hat L_i = L_i(1 + r_i)$。则 $\log L_i - \log\hat L_i = -\log(1 + r_i) = -r_i + O(r_i^2)$，且 $(L_i - \hat L_i)/L_i = -r_i$；故两个目标在相对误差的二阶以内一致。绝对误差目标相对对数目标给点 $i$ 加权 $L_i^2$：同样的相对误差下，损失 $5$ 的小模型比损失 $2$ 的大模型重 $(5/2)^2 = 6.25$ 倍，拟合于是被掰向小模型——恰是外推时最不相干的那些点。
:::

::: exercise 实现稳健拟合 {level=3}
把[[#sec-fitting]]的程序改为按最小化 Huber 损失来拟合 $L = E + AN^{-\alpha}$：$\lvert r\rvert\le\delta$ 时 $h_\delta(r) = \tfrac12r^2$，否则 $\delta(\lvert r\rvert - \tfrac12\delta)$，其中 $r_i = \log L_i - \log\hat L_i$、$\delta = 10^{-3}$，沿用同样的对 $E$ 剖面，并对每个 $E$ 在 $\alpha$ 的一张小网格上搜索、$A$ 用闭式选取。把其中一个观测破坏 $+10\%$，比较最小二乘与 Huber 的 $\alpha$ 估计。
::: solution
固定 $E$ 与 $\alpha$ 时，$\log(\hat L_i - E) = \log A - \alpha\log N_i$；最好的 $A$ 的一个好近似是最小二乘值 $\log A = \overline{\log(L_i - E) + \alpha\log N_i}$，之后 Huber 目标在 $r_i = \log L_i - \log(E + AN_i^{-\alpha})$ 上求值。一个概要：

```python
def huber(r, d=1e-3):
    return 0.5 * r * r if abs(r) <= d else d * (abs(r) - 0.5 * d)

def fit_huber(pts):
    best = None
    Lmin = min(L for _, L in pts)
    for i in range(1, 400):
        E = Lmin * i / 400
        for j in range(1, 100):
            al = 0.6 * j / 100
            logA = sum(math.log(L - E) + al * math.log(N) for N, L in pts) / len(pts)
            obj = sum(huber(math.log(L) - math.log(E + math.exp(logA) * N ** -al))
                      for N, L in pts)
            if best is None or obj < best[0]:
                best = (obj, E, math.exp(logA), al)
    return best[1:]
```

把一个点（比如第五个）乘上 $1.1$，最小二乘估计会明显移动，因为 $\log1.1 = 0.095$ 的平方残差压过 $0.01$ 量级的其余残差；Huber 拟合对该残差只按线性增长，因而停留在未受扰估计附近。取 $\delta = 10^{-3}$ 时，几乎所有残差都落在线性段，Huber 拟合的行为接近绝对值偏差最小——对离群点稳健，正如 Hoffmann et al. 对付偶发反常运行所设想的那样。

::: exercise Zipf 律与幂律 {level=3}
设一个语料含若干事实，其频率为 $f_k = k^{-(1+a)}/Z$，$k = 1, 2, \dots$，$a > 0$；一个容量为 $n$ 的模型恰好学会最频繁的那 $n$ 个事实，其损失与它没有学会的那些事实的频率总和成正比。证明损失渐近正比于 $n^{-a}$。若每个事实所需的容量为常数，这预测什么指数 $\alpha_N$？若事实只有在被见过固定次数之后才能学会、瓶颈是数据而非容量，情况又会怎样变化？
::: solution
未学掉的频率总量是 $\sum_{k>n}k^{-(1+a)}/Z$。与积分比较：$\int_n^\infty t^{-(1+a)}\,dt = n^{-a}/a$，而该和夹在 $\int_{n+1}^\infty$ 与 $\int_n^\infty$ 之间，故等于 $n^{-a}/(aZ)\,(1 + O(1/n))$：正比于 $n^{-a}$。由 $n\propto N$ 得 $\alpha_N = a$。若事实须被看到 $m$ 次，而第 $k$ 个事实出现在 $D$ 个词元中的次数为 $Df_k$，则学到的事实是满足 $Df_k\ge m$ 的那些，即 $k\le(D/(mZ))^{1/(1+a)}$；未学掉的总量于是正比于 $\big(D^{1/(1+a)}\big)^{-a} = D^{-a/(1+a)}$，得 $\alpha_D = a/(1+a)$，比容量一侧的指数小。这正是 Hutter（2021）与 Michaud et al.（2023）论证的形状；真实的指数要靠测量，这个模型只是说明重尾数据如何产生幂律。
:::
