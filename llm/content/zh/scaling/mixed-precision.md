神经网络中的每个数都存有限的若干位里，位数越少，一切都越便宜。16位数只占32位数一半的内存、一半的搬运带宽，而且——因为矩阵单元能在同样的芯片上塞进更多的小乘法器——算术还能快好几倍：H100 的稠密 bf16 张量核心吞吐量大约是它普通（非张量核心）fp32 运算速度的十五倍，fp8 再翻一倍（[[scaling/accelerators]]）。大语言模型自2018年前后起就用16位格式训练，自2023–2024年起其大部分算术用8位格式。代价是数值上的：位数更少意味着可表示数值的网格更粗、范围更窄，于是微小更新消失、大激活上溢、长求和漂移。

本章讲如何安全地付出这个代价。精确定义二进制浮点格式，导出其范围与精度；证明能解释哪些运算需要更多位数的舍入误差界；导出损失缩放为何有效、bf16 为何使其多余；定义两种 fp8 格式与令其可用的缩放方案；证明随机舍入是无偏的并说明它换来什么；最后以量化感知训练收尾。基础知识——三种常用格式、fp32 主副本、小于半个末位单位（ulp）的更新为何丢失、简单的损失缩放——在[[neural-networks/training-practice]]；低精度可能触发的稳定性问题在[[pretraining/training-stability]]。

## 浮点格式 {#sec-formats}

::: definition 二进制浮点格式 {#def-float}
一个有$e$个指数位、$m$个存储尾数位、指数**偏置**$b = 2^{e-1} - 1$的二进制浮点格式，编码一个符号$s$、一个带偏置的指数字段$E\in\{0,\dots,2^e - 1\}$与一个尾数字段$f\in\{0,\dots,2^m - 1\}$。按 IEEE 754 约定：

- $0 < E < 2^e - 1$：**规格化数**$(-1)^s\,(1 + f/2^m)\,2^{E - b}$；
- $E = 0$：**非规格化数**$(-1)^s\,(f/2^m)\,2^{1 - b}$（$f = 0$时为零）；
- $E = 2^e - 1$：无穷（$f = 0$）或 NaN（$f\ne0$）。

**精度**为$p = m + 1$位有效位；就近舍入下的**单位舍入量**为$u = 2^{-p} = 2^{-(m+1)}$；$1$与下一个更大的可表示数之间的间隔为$2u = 2^{-m}$。
:::

::: proposition 格式的范围 {#prop-range}
按 IEEE 约定，最大有限值为$(2 - 2^{-m})\,2^{b}$，最小正规格化值为$2^{1 - b}$，最小正非规格化数为$2^{1 - b - m}$。常用格式：

| 格式 | $e/m$ | 最大有限值 | 最小规格化数 | 最小非规格化数 | $u$ |
|---|---|---|---|---|---|
| fp32 | $8/23$ | $3.40\times10^{38}$ | $1.18\times10^{-38}$ | $1.4\times10^{-45}$ | $6.0\times10^{-8}$ |
| fp16 | $5/10$ | $65{,}504$ | $6.10\times10^{-5}$ | $5.96\times10^{-8}$ | $4.9\times10^{-4}$ |
| bf16 | $8/7$ | $3.39\times10^{38}$ | $1.18\times10^{-38}$ | $9.2\times10^{-41}$ | $3.9\times10^{-3}$ |
:::

::: proof
最大规格化数的$E = 2^e - 2$，于是指数为$2^e - 2 - b = b$（因$2b = 2^e - 2$），并取最大尾数$f = 2^m - 1$，得$(1 + (2^m - 1)/2^m)\,2^b = (2 - 2^{-m})\,2^b$。最小规格化数$E = 1$、$f = 0$：$2^{1-b}$。最小非规格化数$E = 0$、$f = 1$：$2^{-m}\,2^{1-b}$。fp16：$b = 15$，$(2 - 2^{-10})\,2^{15} = 65{,}504$、$2^{-14}$与$2^{-24}$。bf16：$b = 127$，$(2 - 2^{-7})\,2^{127}\approx3.39\times10^{38}$、$2^{-126}$与$2^{-133}$。fp32：$b = 127$、$m = 23$。
:::

范围由指数位决定，精度由尾数位决定。Bf16——在 Google Brain 提出的“brain floating point”格式——就是丢掉末尾$16$位尾数的 fp32：同样的范围，千分之三的相对精度。Fp16 用范围换回多三个比特的精度。下图展示可表示数的相对间隔如何随数量级变化。

## 舍入误差 {#sec-rounding}

::: proposition 舍入的标准模型 {#prop-rounding}
若$x$落在单位舍入量为$u$的某格式的规格化范围内，则就近舍入给出$\operatorname{fl}(x) = x(1 + \delta)$，$\lvert\delta\rvert\le u$。特别地，对可表示的$a, b$，若其精确的和或积在范围内，则$\operatorname{fl}(a\circ b) = (a\circ b)(1 + \delta)$，$\lvert\delta\rvert\le u$。
:::

::: proof
设$2^E\le\lvert x\rvert < 2^{E+1}$。该二进区（binade）内的可表示数间隔为$2^{E-m}$，故最近的一个与$x$相距不超过$2^{E-m-1}$。于是$\lvert\operatorname{fl}(x) - x\rvert\le2^{E-m-1}\le2^{-m-1}\lvert x\rvert = u\lvert x\rvert$。对运算的结论成立，是因为 IEEE 算术返回的是正确舍入的精确结果。
:::

单次舍入很小；麻烦在于积累。长度为$k$的点积——矩阵乘积的每一个元素——是$k$项之和。

::: theorem 逐项累加的误差 {#thm-summation}
设$s = \sum_{i=1}^{n}x_i$按$\hat s_1 = x_1$、$\hat s_i = \operatorname{fl}(\hat s_{i-1} + x_i)$计算。则关于$u$在一阶意义下，

$$
\lvert\hat s_n - s\rvert\le(n - 1)\,u\sum_{i=1}^{n}\lvert x_i\rvert。
$$ {#eq-summation}
:::

::: proof
由[[#prop-rounding]]，$\hat s_i = (\hat s_{i-1} + x_i)(1 + \delta_i)$，$\lvert\delta_i\rvert\le u$。展开得$\hat s_n = \sum_{i=1}^{n}x_i\prod_{j=\max(i,2)}^{n}(1 + \delta_j)$：项$x_i$被乘上了从第$\max(i, 2)$步到$n$的每一次加法的因子，至多$n - 1$个。每个乘积等于$1 + \theta_i$，$\lvert\theta_i\rvert\le(n-1)u + O(u^2)$。于是$\hat s_n - s = \sum_i x_i\theta_i$，其一阶量级至多为$(n-1)u\sum_i\lvert x_i\rvert$。
:::

这个界随$n$线性增长，而对 bf16（$u = 2^{-8}$）几百项之后就毫无用处：$n = 4096$时$(n - 1)u = 16$。对随机符号而言这个界是悲观的——误差部分相消，更像$\sqrt n\,u$那样增长——但对正项之和，例如 RMSNorm 内部的平方和，它接近真实情形：一旦滚动和变大，每个新的微小项都低于其半个 ulp，被完全丢弃。这就是**矩阵单元以低精度相乘、以 fp32 累加**的原因，也是即便在“16位”训练中归约（范数、softmax 分母、损失）也用 fp32 计算的原因。

## 混合精度训练 {#sec-mixed}

::: algorithm 混合精度训练的一步 {#alg-mixed}
状态：fp32 **主权重**$\theta$、fp32 优化器状态、损失缩放因子$S$（fp16 用；bf16 取$S = 1$）。
1. 把$\theta$转为16位格式：$\theta_{16} = \operatorname{fl}_{16}(\theta)$。
2. 用$\theta_{16}$跑前向传播：矩阵乘法用16位输入、fp32 累加；softmax、归一化与损失用 fp32；激活以16位存储。
3. 对$S\cdot\mathcal{L}$作反向传播，得到缩放损失的16位梯度$\mathbf{g}_{16}$。
4. 转为 fp32 并去缩放：$\mathbf{g} = \mathbf{g}_{16}/S$。若任何元素为无穷或 NaN，跳过该步更新（并减小$S$；[[#alg-dynamic-scaling]]）。
5. 裁剪，并把优化器更新施加到 fp32 主权重与状态上。
:::

之所以要 fp32 主副本，是因为[[neural-networks/training-practice#prop-swamping]]：小于权重半个 ulp 的更新会被舍掉，而 bf16 的半个 ulp 是权重的$2^{-8}$——比大多数单次更新还大。其显存代价就是[[scaling/flops-memory#prop-bytes]]的每参数$16$字节。

**损失缩放。**Fp16 的最小非规格化数是$5.96\times10^{-8}$，Micikevicius 等（2018）发现某些网络相当大一部分激活梯度低于它而变成零。把损失乘上$S$会把每个梯度都乘上$S$，将其抬进范围内。

::: proposition 2 的幂次损失缩放是精确的 {#prop-loss-scaling}
设$S = 2^k$。对任何可表示的$x$，只要$Sx$与$x$都是范围内的规格化数，$\operatorname{fl}(Sx) = Sx$精确成立，除以$S$也精确恢复$x$。因此，把损失乘上$2^k$只会改变反向传播中那些否则会下溢（缩放把它们救回）或缩放后溢出（缩放毁掉它们）的值的舍入。
:::

::: proof
把$(1 + f/2^m)\,2^{E}$乘上$2^k$得$(1 + f/2^m)\,2^{E+k}$，有效位不变，只要$E + k$仍在规格化指数范围内就可表示。所以不发生舍入，除以$2^k$同样只改变指数。反向传播对上游梯度是线性的，所以每个中间梯度都被乘上$S$；在所有值都停留在规格化范围内的地方，每次舍入运算看到的有效位与不缩放时相同，只是指数平移$k$，舍入结果完全一致。
:::

::: example 选择缩放因子 {#ex-loss-scale}
在一个 fp16 网络中，有意义的激活梯度最小约$10^{-9}$、最大约$2$。存在一个2的幂次缩放因子能把它们全部保持在范围内吗？对$2\times10^{-8}$的梯度，下面的清单显示了什么？
::: solution
这些值要求$S\cdot10^{-9}\ge6.1\times10^{-5}$（成为规格化数）且$S\cdot2\le65{,}504$。前者给出$S\ge6.1\times10^4$，后者$S\le3.3\times10^4$：没有任何单一缩放因子能让一切保持规格化。若允许最小的那些值取非规格化数（$S\cdot10^{-9}\ge6\times10^{-8}$，即$S\ge60$），窗口就很宽了；$S = 2^{14} = 16{,}384$把$10^{-9}$放到$1.6\times10^{-5}$（非规格化，约$8$位有效数字），把$2$放到$32{,}768$。清单中，$2\times10^{-8}$在 fp16 下舍入为$0$，但$2\times10^{-8}\cdot2^{16} = 1.3\times10^{-3}$是规格化数，去缩放得$1.9994\times10^{-8}$。
:::
:::

::: algorithm 动态损失缩放 {#alg-dynamic-scaling}
参数：初始缩放因子$S_0$（常用$2^{16}$）、退让系数$1/2$、增长系数$2$、增长间隔$K$（常用$2000$步）。
1. 每步计算$S\cdot\mathcal{L}$的梯度。
2. 若任何梯度为无穷或 NaN：跳过该步更新，置$S\leftarrow S/2$，计数器归零。
3. 否则施加更新；计数器加一；达到$K$时置$S\leftarrow2S$并归零。
:::

缩放因子会稳定在略低于不溢出的最大值处，每$K$步向上试探一次；偶尔跳过一步是代价。由于 bf16 拥有 fp32 的范围，梯度在实践中既不下溢也不溢出，bf16 训练不需要损失缩放——这是硬件一旦支持（Kalamkar 等，2019）它就取代 fp16 成为大模型首选的主要原因。Fp16 在没有 bf16 的场合仍然有用，其更高的精度在推理中有时更受青睐。

## 八位浮点 {#sec-fp8}

::: definition FP8 格式 {#def-fp8}
Micikevicius 等（2022）提出两种8位格式，后来被开放计算项目的 OFP8 规范标准化：

- **E4M3**：$4$个指数位（偏置$7$）、$3$个尾数位。它**没有无穷**：只有指数位与尾数位全置1的位模式是 NaN，所以最高指数用于有限值。最大有限值$1.75\times2^8 = 448$；最小规格化数$2^{-6}$；最小非规格化数$2^{-9}$。
- **E5M2**：$5$个指数位（偏置$15$）、$2$个尾数位，遵循带无穷与 NaN 的 IEEE 约定。最大有限值$1.75\times2^{15} = 57{,}344$；最小规格化数$2^{-14}$；最小非规格化数$2^{-16}$。
:::

::: example 448 从何而来 {#ex-e4m3}
导出 E4M3 与 E5M2 的最大有限值，并把它们的动态范围（最大除以最小规格化数）与 fp16 比较。
::: solution
E4M3：最高指数字段$1111$允许表示有限数，所以最大指数为$15 - 7 = 8$；尾数$111$保留给 NaN，所以最大尾数是$110$：$(1 + 6/8)\,2^8 = 1.75\cdot256 = 448$。E5M2：与 IEEE 一样，最高字段$11111$被保留，故最大指数为$30 - 15 = 15$，尾数$11$：$(1 + 3/4)\,2^{15} = 57{,}344$。动态范围：E4M3 为$448/2^{-6} = 28{,}672\approx2^{14.8}$；E5M2 为$57{,}344/2^{-14}\approx9.4\times10^8\approx2^{29.8}$，与 fp16（$65{,}504/2^{-14}\approx2^{30}$）相同。E4M3 精度更高，E5M2 范围更大；通常的配方在前向传播中给权重与激活用 E4M3，给梯度用 E5M2（某些配方也用 E4M3）。
:::
:::

::: widget floatline
p: 3

emax: 3
value: 5.5
caption: 一个玩具格式的全部可表示数：有效位$3$位（存$2$位尾数，与 E5M2 相同），指数从$-3$到$3$。每个二进区只装得下四个数，所以间隔在每个2的幂处加倍：$4$与$8$之间的数是$4, 5, 6, 7$。移动这个值，观察它离最近的邻居有多远——在每个二进区底部可达数值的$12.5\%$，这正是 E5M2 提供的精度。E4M3 多一个尾数位，相对间隔减半。
:::

在$u = 2^{-4}$（E4M3）或$2^{-3}$（E5M2）下，FP8 表示每个数只能精确到$6$–$12\%$以内，而且其范围窄到必须把张量**缩放**进去。张量$X$被存成一个 fp8 张量$\tilde X$加一个更高精度的缩放因子$\sigma$，满足$X\approx\sigma\tilde X$。在用的方案有好几种（截至2026年）：

- **按张量缩放**：每个张量一个$\sigma$，由绝对值最大元素（**amax**）选定，使其恰好映到格式的最大值。NVIDIA Transformer Engine 使用的**延迟缩放**根据先前各步 amax 的历史记录来定$\sigma$，省去对数据的额外一趟扫描；**即时缩放**则先计算张量自身的 amax。
- **按块缩放**：每块元素一个$\sigma$。DeepSeek-V3（DeepSeek-AI，2024）对激活按$1\times128$小块、对权重按$128\times128$块设置缩放因子，因为硬件的 fp8 累加精度有限而定期把部分和提升到 fp32，并报告损失与 bf16 基线的差距在$0.25\%$以内。
- **微缩放（MX）格式**（开放计算项目规范，2023；Rouhani 等，2023）：每$32$个元素共享一个8位的2的幂次缩放因子（E8M0），元素本身用 fp8、fp6、fp4 或 int8。对 MX 格式的硬件支持随2024年起公布的加速器代际到来。

按块缩放之所以重要，是因为**离群值**。张量中单个大值就会定下按张量的缩放因子，把其余所有元素推向范围底部，那里相对精度在接近非规格化数时崩溃（上图的左侧）。人们早已知道语言模型的激活中有少数特征维的量级远大于其余部分，且随规模增长（Dettmers 等，2022），正是这种情况。

::: example 一个离群值，两种缩放方案 {#ex-outlier}
一行$128$个激活的典型量级为$0.01$，其中一个元素是$100$。对整个 E4M3 用一个按张量缩放因子（把 amax 映到$448$），典型元素落到哪里？改用每$32$个元素的按块缩放，不含离群值的那三块会怎样？
::: solution
按张量：$\sigma = 100/448$，典型元素变成$0.01\cdot4.48 = 0.0448$。E4M3 的最小规格化数是$2^{-6} = 0.0156$，所以它们仍是规格化数，在$[2^{-5}, 2^{-4})$内间隔$2^{-5-3} = 0.0039$，相对精度约$9\%$——这里还算可用，但若元素再小十倍（$0.001\to0.0045$）就会落入非规格化区，间隔$2^{-9} = 0.00195$，约为其值的$40\%$。按块：不含离群值的三块 amax 约$0.03$，各自得到把$0.03$映到$448$的缩放因子；它们的元素落到范围上部，保住完整的$3$位精度（误差不超过$6\%$）。只有含离群值的那块付出代价。
:::
:::

以 fp8 运行的通常只有线性层的大型矩阵乘法（前向，以及反向的两个乘积）。注意力的 softmax、归一化、损失、优化器、主权重、常常还有梯度的全规约都留在 bf16 或 fp32。在支持的硬件上，fp8 矩阵乘法使峰值吞吐相对 bf16 翻倍；但整个训练步的端到端加速比更小，因为这一步的其余部分没有变化。

## 随机舍入 {#sec-stochastic}

就近舍入是确定性的，其误差可能有系统性偏差：那个舍入为零的微小更新每次都舍为零（[[neural-networks/training-practice#prop-swamping]]）。**随机舍入**把方向随机化，使误差在期望中相消。

::: definition 随机舍入 {#def-stochastic}
设$x$介于两个相邻可表示数$x_- < x < x_+$之间。**随机舍入**返回

$$
\operatorname{SR}(x) = \begin{cases} x_+ & \text{概率为 } \dfrac{x - x_-}{x_+ - x_-}\text{，}\\[2mm] x_- & \text{否则。}\end{cases}
$$
:::

::: proposition 随机舍入是无偏的 {#prop-sr}
$\E[\operatorname{SR}(x)] = x$，且$\Var[\operatorname{SR}(x)] = (x - x_-)(x_+ - x)\le\tfrac14(x_+ - x_-)^2$。若权重$w$接受$n$次更新$\Delta_1,\dots,\Delta_n$，每次以$w\leftarrow\operatorname{SR}(w + \Delta_i)$施加且随机性相互独立，则只要没有任何值超出格式范围，就有$\E[w_n] = w_0 + \sum_i\Delta_i$精确成立。
:::

::: proof
记$h = x_+ - x_-$、$q = (x - x_-)/h\in(0, 1)$。则$\E[\operatorname{SR}(x)] = qx_+ + (1 - q)x_- = x_- + qh = x$。间隔为$h$、概率为$q$的两点分布，方差为$q(1 - q)h^2 = (x - x_-)(x_+ - x)$，在$q = \tfrac12$处取最大值$h^2/4$。对序列，由第一部分$\E[w_i\mid w_{i-1}] = w_{i-1} + \Delta_i$，再由全期望公式（tower property）$\E[w_i] = \E[w_{i-1}] + \Delta_i$，归纳即得结论。
:::

下面的清单用纯 Python 对任意二进制格式实现两种舍入，并检验本章的四个论断：对值为$1$的 bf16 权重做$10{,}000$次$0.001$的更新，在就近舍入下全部丢失，而随机舍入在期望中全部保留；16位累加器毁掉一个长的正项求和；损失缩放救回一次 fp16 下溢；以及舍入到 E4M3 的随机舍入是无偏的。

```python
import math, random, struct

def round_float(x, man_bits, emin, emax_finite, stochastic=False, rng=None):
    """Round x to a binary format with man_bits stored mantissa bits, smallest normal
    exponent emin and largest finite value emax_finite (saturating), with subnormals."""
    if x == 0:
        return 0.0
    s, a = (-1.0 if x < 0 else 1.0), abs(x)
    e = max(math.floor(math.log2(a)), emin)       # 二进区（非规格化数共用 emin 的）
    ulp = 2.0 ** (e - man_bits)
    q = a / ulp
    lo = math.floor(q)
    if stochastic:                                # 以概率 q - lo 向上舍入
        r = lo + (1 if rng.random() < q - lo else 0)
    else:                                         # 就近舍入，等距取偶
        r = lo + (1 if (q - lo > 0.5 or (q - lo == 0.5 and lo % 2)) else 0)
    return s * min(r * ulp, emax_finite)

bf16 = lambda x, **k: round_float(x, 7, -126, 3.3895e38, **k)
fp16 = lambda x, **k: round_float(x, 10, -14, 65504.0, **k)
e4m3 = lambda x, **k: round_float(x, 3, -6, 448.0, **k)
fp32 = lambda x: struct.unpack("f", struct.pack("f", x))[0]

# 1. 对权重 1.0 做大量微小更新
rng = random.Random(0)
w_rn = w_sr = 1.0
w32 = fp32(1.0)
for _ in range(10000):
    w_rn = bf16(w_rn + 1e-3)
    w_sr = bf16(w_sr + 1e-3, stochastic=True, rng=rng)
    w32 = fp32(w32 + 1e-3)
print(f"1 + 10000 x 0.001: exact 11.0  fp32 {w32:.4f}  bf16-nearest {w_rn}  bf16-stochastic {w_sr}")

# 2. 4096 个 bf16 数的平方和（如同范数中那样），分别用 16 位与 32 位累加器
rng = random.Random(1)
xs = [bf16(rng.gauss(0, 1)) for _ in range(4096)]
exact = math.fsum(x * x for x in xs)              # 此处 bf16 值的乘积是精确的
acc16 = acc32 = 0.0
for x in xs:
    acc16 = bf16(acc16 + x * x)
    acc32 = fp32(acc32 + x * x)
print(f"sum of squares: exact {exact:.3f}  bf16 accumulator {acc16}  fp32 accumulator {acc32:.3f}")

# 3. fp16 中的小梯度，有无损失缩放对比
g = 2.0e-8
print(f"fp16({g}) = {fp16(g)}   fp16({g} * 2**16) / 2**16 = {fp16(g * 2**16) / 2**16:.4e}")

# 4. 舍入到 E4M3 的随机舍入之无偏性
rng = random.Random(2)
x = 300.0
samples = [e4m3(x, stochastic=True, rng=rng) for _ in range(100000)]
print(f"E4M3 nearest({x}) = {e4m3(x)}   mean of stochastic roundings = {sum(samples)/len(samples):.2f}")
```

```text
1 + 10000 x 0.001: exact 11.0  fp32 11.0008  bf16-nearest 1.0  bf16-stochastic 11.125
sum of squares: exact 4065.752  bf16 accumulator 1936.0  fp32 accumulator 4065.737
fp16(2e-08) = 0.0   fp16(2e-08 * 2**16) / 2**16 = 1.9994e-08
E4M3 nearest(300.0) = 288.0   mean of stochastic roundings = 299.97
```

就近舍入下，bf16 权重从未离开$1$；随机舍入下它到达$11.125$，与精确值$11$相差两个 bf16 的 ulp（在该量级上每个$0.0625$）——随机性花掉的是方差，不是偏差。即便是 fp32，在$10{,}000$次加法中也累积了小误差（$11.0008$）。bf16 累加器丢掉$4096$个平方之和的一半以上：超过$1024$之后它的 ulp 是$8$，而多数平方小于$4$。E4M3 就近舍入每次把$300$映到$288$，误差$4\%$；随机舍入平均得$299.97$。

::: example 一次更新的随机舍入 {#ex-sr}
一个 bf16 权重等于$1$（相邻的可表示数下方是$1 - 2^{-8}$、上方是$1 + 2^{-7}$）。用随机舍入施加一个$\Delta = 10^{-3}$的更新。可能的结果及其概率是什么？结果的标准差呢？
::: solution
$x = 1.001$位于$x_- = 1$与$x_+ = 1.0078125$之间，间隔$h = 0.0078125$。$q = 0.001/0.0078125 = 0.128$：结果以概率$0.128$取$1.0078125$、以概率$0.872$取$1$。均值$1 + 0.128\cdot0.0078125 = 1.001$。标准差$h\sqrt{q(1-q)} = 0.0078125\cdot0.334 = 0.0026$，比更新本身还大一倍多——单步看噪声很大，但许多步平均下来就抵消了，而随机梯度下降本来就容忍这种噪声。
:::
:::

Gupta 等（2015）曾用随机舍入以16位定点格式训练网络，若干加速器也在硬件中实现了它。它使某些场合下的纯低精度训练——不带 fp32 主副本——变得可行，从而节省显存（Zamirai 等，2020 研究了带权重更新随机舍入的 bf16 训练）。就截至2026年已报告的最大规模语言模型运行而言，fp32 或更高精度的主副本配就近舍入仍是标准做法；随机舍入更多用于低精度的梯度或优化器状态存储，以及某些 fp8 与 fp4 配方。

::: warning “用 fp8 训练”并不意味着每个数都是 fp8
fp8 或 fp4 训练的报告描述的是哪些矩阵乘法用了这些格式。主权重、优化器状态与累加保持更高精度；归一化、softmax 与损失通常以 bf16 或 fp32 运行；而且常常把第一层和最后一层、或注意力计算排除在外。比较各种说法时，要问：哪些运算、什么粒度的缩放、累加精度如何、结果有没有在同规模下与更高精度的基线对照过——低精度带来的不稳定性可能要到长时间运行的后期才显现。
:::

## 量化感知训练 {#sec-qat}

训练中的低精度主要是为了速度。另一个目标是让模型**部署**时以极低精度——int8、int4 或 fp4 权重——运行，使推理更便宜（[[inference/quantisation]]）。训练完成后再把训好的模型权重舍入（**训练后量化**）在8位时效果很好，但4位及以下会损失精度。**量化感知训练**（QAT）让模型在训练期间就接触舍入，从而能够适应它。

::: definition 伪量化与直通估计器 {#def-qat}
在**伪量化**中，前向传播对每个权重$w$改用$\hat w = \sigma\cdot\operatorname{clip}\big(\operatorname{round}(w/\sigma), -q, q\big)$（以更高精度计算），于是网络看到的正是量化之后它将拥有的那些值。舍入的导数几乎处处为零，所以反向传播使用**直通估计器**（STE；Bengio、Léonard 与 Courville，2013）：在裁剪范围内部把$\partial\hat w/\partial w$取为$1$、外部取为$0$，梯度更新的是高精度的$w$。
:::

STE 是一个启发式：它在求梯度时把舍入当作恒等映射，局部看是错的，但实践中效果很好，因为高精度权重会积累微小更新，直到越过某条舍入边界。Jacob 等（2018）为视觉网络的纯整数推理确立了 QAT；对语言模型，它要么在预训练的最后阶段施加，要么放在一个较短的微调阶段，常用模型自己的生成结果作数据（LLM-QAT；Liu 等，2023）。大部分细节属于推理范畴，在[[inference/quantisation]]中讨论。

::: quiz
一个运行从带动态损失缩放的 fp16 改到 bf16。哪些说法正确？
- [x] 不再需要损失缩放，因为 bf16 的指数范围与 fp32 相同。
- [ ] fp32 主权重可以去掉而不影响结果，因为 bf16 的范围与 fp32 相同。
- [x] 现在每个存下的16位数的精度大约差八倍。
- [ ] 现在矩阵乘法应当在 bf16 中累加。
::: solution
Bf16 的$8$个指数位给出 fp32 的范围，梯度不会下溢。但它的精度比 fp16 少$3$个尾数位（$u = 2^{-8}$对$2^{-11}$），微小更新反而更容易丢失：主权重更重要，而不是更不重要。累加仍留在 fp32（[[#thm-summation]]）。
:::
:::

::: history
Courbariaux、Bengio 与 David（2014）以及 Gupta、Agrawal、Gopalakrishnan 与 Narayanan（2015）表明网络可以用低精度算术训练，后者使用了随机舍入。NVIDIA 与百度的 Micikevicius 及其同事（《Mixed Precision Training》，2017，发表于 ICLR 2018）提出了 fp16 算术、fp32 主权重与损失缩放这套配方。Google 的 TPU 使用 bf16；Kalamkar 等（2019）证明 bf16 在一系列模型上无需损失缩放即可与 fp32 持平。Bengio 等（2013）提出直通估计器，Jacob 等（2018）提出用于整数推理的量化感知训练。Micikevicius 等（2022）提出 E4M3 与 E5M2 格式，展示了高达$1750$亿参数语言模型的 fp8 训练可与16位基线持平；开放计算项目将它们、并在2023年把微缩放（MX）分块格式标准化。DeepSeek-V3（2024）描述了带细粒度分块缩放的fp8 大规模训练配方。
:::

::: summary
- 有$e$个指数位、$m$个尾数位的二进制格式范围到$(2 - 2^{-m})2^{b}$，单位舍入量$u = 2^{-(m+1)}$；**指数定位范围，尾数位定精度**。
- 每次舍入的相对误差不超过$u$，但逐项累加的和可积累到$(n-1)u\sum\lvert x_i\rvert$：**用 fp32 累加**。
- **混合精度训练**保留 fp32 主权重与优化器状态，矩阵乘法以16位配 fp32 累加运行，归约保持 fp32。
- 按2的幂次**损失缩放**除范围边界外是精确的；动态缩放在溢出时减半、在连续若干正常步后翻倍；**bf16** 一律不需要。
- **FP8**：E4M3（最大$448$）与 E5M2（最大$57{,}344$）由于范围窄和激活离群值而需要**缩放**——按张量、按块、或每$32$个元素的 MX 块。
- **随机舍入**是无偏的，$\E[\operatorname{SR}(x)] = x$，方差至多$h^2/4$：它在期望中保住了微小的更新。
- **量化感知训练**用伪量化与直通估计器为模型的低位部署做准备。
:::

::: solution
偏置$15$，非规格化数为$(f/4)\cdot2^{1-15}$；最小的即$f = 1$，为$2^{-2}\cdot2^{-14} = 2^{-16} = 1.52587890625\times10^{-5}$。

::: exercise 一个求和误差界 {level=2 check="0.03076"}
六十四个正数满足$\sum\lvert x_i\rvert = 1$，在 fp16（$u = 2^{-11}$）中相加。[[#thm-summation]]给出绝对误差的一阶界是多少？保留四位有效数字，再与同一个和在 bf16（$u = 2^{-8}$）中的界比较。
::: solution
$(n - 1)u\sum\lvert x_i\rvert = 63\cdot2^{-11} = 63/2048 = 0.03076$（fp16），约为和的$3\%$；bf16 下为$63/256 = 0.2461$，约是和的四分之一。两者都是最坏情形，但对正项而言，实际误差可能逼近它们。
:::
:::

::: exercise 随机舍入的概率 {level=2 check="0.4"}
值$x = 1.003125$被随机舍入到 bf16，其相邻数为$1$与$1.0078125$。它向上舍入的概率是多少？
::: solution
$q = (x - x_-)/(x_+ - x_-) = 0.003125/0.0078125 = 0.4$。
:::

::: exercise 动态损失缩放 {level=2}
一个运行以$S = 2^{16}$、增长间隔$K = 2000$开始，在第$1$、$2$、$3$步溢出，此后直到第$10{,}000$步都不再溢出。第$3$步之后、第$5003$步时的$S$是多少？一共跳过了多少次更新？为什么允许缩放因子重新增长？
::: solution
每次溢出把$S$减半并跳过该步：第$3$步后$S = 2^{13}$，跳过$3$次更新。从第$4$步起计数器开始走；经过$2000$个正常步（第$2003$步）后$S = 2^{14}$，第$4003$步后$S = 2^{15}$，所以第$5003$步时为$2^{15}$（第$6003$步到达$2^{16}$，若不再溢出则每$2000$步继续翻倍）。之所以需要增长，是因为梯度分布会在训练过程中移动——通常梯度会缩小——若在第$3$步溢出后就把缩放因子钉死，后文的小梯度会开始下溢。
:::
:::

::: exercise 按张量缩放因子 {level=2 check="0.224"}
某张量的 amax 为$2000$。转为 E4M3 之前先乘$1/\sigma$，其中$\sigma$选为使 amax 恰好映到 E4M3 的最大有限值。乘数$1/\sigma$是多少？保留三位有效数字。一个值为$3$的元素会怎样？
::: solution
$1/\sigma = 448/2000 = 0.224$（故$\sigma = 4.46$）。值为$3$的元素变成$0.672$，落在$[0.5, 1)$——E4M3 在此间隔$2^{-1-3} = 0.0625$——舍入到$0.6875$，去缩放得$3.07$，误差$2.3\%$。
:::
:::

::: exercise 随机和的方差 {level=3}
一个权重在$1$附近间隔为$h$的某格式中从$w_0 = 1$开始，接受$n$次大小为$\Delta\ll h$的更新，每次以随机舍入施加。假设权重始终停留在同一二进区，证明向上步数服从二项分布，并求$w_n - w_0$的均值与标准差。对 bf16（$h = 2^{-7}$）、$\Delta = 10^{-4}$、$n = 10{,}000$，把标准差与均值比较。
::: solution
只要权重停在一个格点上，$w + \Delta$就位于该点与下一点之间，每步以概率$q = \Delta/h$独立地向上舍入；于是只要没有一步跨进另一个二进区，就有$w_n - w_0 = hK$，$K\sim\Bin(n, q)$。均值$hnq = n\Delta$，与[[#prop-sr]]的要求一致；标准差$h\sqrt{nq(1 - q)}\approx\sqrt{nh\Delta}$。数值：均值$1$；$q = 10^{-4}\cdot128 = 0.0128$，标准差$2^{-7}\sqrt{10{,}000\cdot0.0128\cdot0.9872} = 0.0078\cdot11.24 = 0.088$，约为均值的$9\%$（实践中权重会跨入下一个二进区，那里$h$加倍，但结论类似）。在就近舍入下，变化恰好为$0$。
:::
:::

::: exercise 分块累加 {level=3}
一个长度$n = 4096$的点积这样计算：把它分成$n/c$个长度为$c$的块，每块在单位舍入量为$u_\ell$的低精度累加器中求和，块和再用 fp32（$u_h = 2^{-24}$）相加。用[[#thm-summation]]给出一阶误差界，并在$u_\ell = 2^{-14}$时选取$c$，使低精度部分至多为$\sum\lvert x_i\rvert$的$1\%$。说明这与按固定间隔把部分和提升到 fp32 的关系。
::: solution
每块的和误差至多$(c - 1)u_\ell\sum_{\text{块}}\lvert x_i\rvert$；对块求和至多$(c - 1)u_\ell\sum\lvert x_i\rvert$。$n/c$个块和的 fp32 求和再加至多$(n/c - 1)u_h\sum\lvert x_i\rvert$（一阶意义下，因为块和的绝对值之和至多为$\sum\lvert x_i\rvert$）。总计：$\big((c - 1)u_\ell + (n/c - 1)u_h\big)\sum\lvert x_i\rvert$。由$(c - 1)2^{-14}\le0.01$得$c\le164.8$，故$c = 128$（对硬件友好的尺寸）给出$127\cdot2^{-14} = 0.78\%$，而 fp32 部分为$31\cdot2^{-24}\approx2\times10^{-6}$。不分块则为$4095\cdot2^{-14} = 25\%$。这正是每$128$个元素把 fp8 部分和提升到 fp32 背后的道理，DeepSeek-V3 报告的就是这种做法。
:::
:::
