本图谱至此讲过的每一种对齐方法，都依赖于有人能够分辨行为的优劣。监督微调需要正确的示范；RLHF 需要标注者更偏爱较好回答的比较（[[post-training/rlhf]]）；可验证奖励需要一个检查器（[[reasoning/verifiable-rewards]]）。对许多任务来说，这一要求本就难以满足——要评估一篇冗长的证明、一次大规模的代码改动、一个医学回答，或一份标注者没有读过的某本书的摘要——而随着模型比评测它们的人更能干，这一要求会变得更难满足。前面的章节展示了评测者可能被蒙骗时会出什么乱子：策略学会了去蒙骗它（[[safety-alignment/reward-hacking]]）。

**可扩展监督**（scalable oversight）研究的是：在人类直接评测不可靠、太昂贵、或根本不可能做的任务上，如何监督系统。本章介绍它的主要提案：**辩论**（debate）——两个模型交锋，由一个能力较弱的评审（judge）做出裁决；**增强**（amplification）与**递归奖励建模**（recursive reward modelling）——把困难的评测分解成更容易的评测；**批评**（critiques）——模型帮助人类发现缺陷；以及**弱到强泛化**（weak-to-strong generalisation）——研究强模型从较弱监督者不完美的标签中学到了什么。对每一种提案，我们给出核心论证、（如果有的话）其中的数学，以及已发表的实证结果——截至 2026 年，这些结果有的地方令人鼓舞，有的地方则好坏不一。

## 监督问题 {#sec-problem}

::: definition 监督缺口与可扩展监督 {#def-oversight}
设一项任务的输入为 $\mathbf x$，监督者 $H$——一个人、一个群体，或借助工具的人——对候选输出 $\mathbf y$ 给出评测 $H(\mathbf x, \mathbf y)$。在一组任务上，**监督缺口**是指 $H$ 的评测与输出的真实质量不相符的程度，尤其针对由一个针对 $H$ 做优化的系统所产生的输出。**可扩展监督**方法是指这样的程序：它让 $H$ 在 AI 系统的辅助下做出的评测，其准确率不下降——或下降得很慢——即使被评测系统的能力不断超过 $H$ 自身。
:::

在超人系统存在之前，如何检验这样的方法？Cotra（2021）提出了**夹心评测**（sandwiching）：选择这样一类任务，当今模型在其上比某些人（非专家）更能干，却不如另一些人（专家）能干。非专家借助该方法所提供的一切辅助来监督模型，再由专家为结果打分。若方法有效，非专家的监督应当接近专家水平。Bowman 等（2022，"Measuring progress on scalable oversight for large language models"）在 MMLU 的选择题、以及限时条件下 QuALITY 的阅读理解题上做了早期版本的实验，发现与一个不可靠的模型助手交谈的人，既胜过模型单独作答，也胜过自己单独作答。夹心评测已成为标准实验设计，常与**信息不对称**（information asymmetry）设定一同使用：评审接触不到模型能够看到的信息（例如一篇长文本）。

## 辩论 {#sec-debate}

Irving、Christiano 与 Amodei（2018，"AI safety via debate"）提出通过零和博弈来训练模型。模型的两个拷贝看到同一个问题并轮流发言；一个能力可能弱得多的评审阅读记录并宣布胜者；每位辩手因获胜而得到奖励。期望在于**说谎比驳倒谎言更难**：若一位辩手做出虚假主张，另一位可以指出虚假的具体步骤，评审只需检查那一步。

::: definition 辩论 {#def-debate}
关于问题 $q$ 的一场**辩论**是辩手 $A$ 与 $B$ 之间的博弈：两人交替发言，产生陈述 $s_1, s_2, \dots, s_n$；随后**评审** $J$ 根据 $q$ 与记录输出一个裁决——$A$ 或 $B$。博弈是零和的：胜者得到奖励 $1$，负者 $0$。在**训练**设定中，辩手通过自我对弈被训练来取胜；在部署时，由最优玩法下会获胜的辩手所捍卫的答案被取为系统的答案。
:::

在一个主张可分解为子主张的理想化模型中，这一论证可以表述得精确。

::: proposition 主张树上的诚实辩论 {#prop-tree}
设每个主张 $c$ 要么是一个**叶节点**——其真假由评审正确评估——要么有一个由子主张 $c_1, \dots, c_m$ 构成的**分解**，使得 $c$ 为真当且仅当所有 $c_i$ 为真。考虑这样的辩论：$A$ 断言一个主张；$B$ 要么接受，要么从当前主张中选择一个子主张加以质疑；$A$ 必须为那个子主张辩护；如此继续，直到抵达一个叶节点，由评审评估。那么，站在真相一边的辩手必胜，无论对方怎么做：若根主张为真，$A$ 靠诚实辩护取胜；若它为假，$B$ 靠始终质疑一个虚假的子主张取胜。评审评估的单个叶节点，其深度至多为树的深度 $D$，而直接检查该主张可能需要评估 $m^D$ 个叶节点。
:::

::: proof
对当前主张的深度作归纳。在叶节点处，评审正确裁决，于是真相一边取胜。设结论对深度小于 $k$ 的主张成立，考虑深度为 $k$ 的主张 $c$。若 $c$ 为真，则每个子主张都为真，于是无论 $B$ 质疑哪一个，$A$ 辩护的都是一个深度小于 $k$ 的真实主张，由归纳假设取胜。若 $c$ 为假，则至少有一个子主张为假（因为 $c$ 为真当且仅当全部为真），$B$ 就质疑它；于是 $A$ 必须辩护一个深度更小的虚假主张，由假设而落败。辩论沿着从根到叶节点的一条路径进行，所以评审只评估一个叶节点。
:::
这就是 Irving 等论文中复杂度论证的核心：在最优玩法下，由多项式时间评审裁决的辩论可以回答 PSPACE 类中的任意问题，而检查单个答案及其支持论证的评审只能处理 NP。在一棵规模呈指数级的论证树上只检查一步的评审，正是"指出缺陷"的形式化版本。

::: example 评审需要检查多少 {#ex-tree}
每个主张在每一层都分解为 $m = 4$ 个子主张，直到深度 $D = 6$。直接检查需要多少次叶节点评估，辩论需要多少次？若评审只以概率 $0.9$ 正确评估叶节点，又会怎样？
::: solution
对整个树的直接检查需要 $4^6 = 4{,}096$ 次叶节点评估；辩论只需要一次，那是经过六轮质疑后抵达的叶节点。对于以概率 $0.1$ 在叶节点上出错的评审，在这一理想化博弈中诚实一方获胜的概率为 $0.9$：只有最后的叶节点被裁决，所以错误不随深度累积。若各评审的错误相互独立，用多个独立评审重复辩论并取多数，还能把准确率推得更高。
:::
:::

这一理想化掩盖了困难所在，而它们正是当前研究的主题：

- **含混论证（obfuscated arguments）。** 不诚实的辩手可以把一个虚假主张分解为许多各自*看起来*合理的子主张：缺陷确实存在于某处，但诚实辩手无法高效地把它找出来（Barnes 与 Christiano，2020）。[[#prop-tree]]假设诚实的一方能够找到虚假的子主张；在足够大的论证中，这一搜索本身就可能是难以处理的。Brown-Cohen、Irving 与 Piliouras（2023，"Scalable AI safety via doubly-efficient debate"）设计了双重高效辩论（doubly-efficient debate）协议，使诚实辩手所需的努力相对于被验证的计算只是多项式的。
- **评审偏差。** 评审可能被自信、篇幅或修辞所左右，与 RLHF 评审的弱点相同。
- **训练动态。** 论证假设最优玩法；真实训练未必能达到最优，而且两位辩手可能一起学会利用评审。

### 实证结果

Irving 等在 MNIST 图像上检验了一个玩具版本：一个只能看到少数像素的评审分类器，像素由两个辩论智能体揭示，一个为真实数字辩护，另一个为一个虚假数字辩护。在揭示六个像素时，评审的准确率从 $59.4\%$（随机选取像素）升到辩论下的 $88.9\%$。后来的工作转向了语言。

- **人类辩手。** Michael 等（2023，"Debate helps supervise unreliable experts"）让能够阅读一篇长故事的人在无法阅读该故事的评审面前辩论阅读理解问题。有辩论时评审更准确（$84\%$），而**顾问制**（consultancy）基线为 $74\%$：在顾问制中，一名专家为某一个答案辩护，而这个答案有一半的时候被选定为错误的。
- **模型辩手。** Khan 等（ICML 2024，"Debating with more persuasive LLMs leads to more truthful answers"）用语言模型辩手重现了同样的信息不对称设定。非专家评审在辩论下达到 $76\%$（模型）与 $88\%$（人类）的准确率，而朴素基线分别为 $48\%$ 与 $60\%$。以说服力为目标优化辩手——针对评审做 best-of-$n$ 选择——*提高*了辩论中评审的准确率，与理论预测一致；而在顾问制中，更有说服力的顾问反而让评审更不准确。
- **跨任务的混合结果。** Kenton 等（NeurIPS 2024，"On scalable oversight with weak LLMs judging strong LLMs"）以更弱的模型充当评审，在许多任务上比较了辩论、顾问制与直接问答。辩论稳定地胜过顾问制。与评审自己直接回答相比，辩论在信息不对称的任务上有帮助，但在评审与辩手掌握相同信息的任务上结果好坏不一。

这些研究使用有标准答案的问题、刻意被削弱的评审，以及没有通过辩论自我对弈端到端训练的辩手；辩论能否训练出*诚实*的模型——而不只是帮助评审评估现有的模型——截至 2026 年基本上尚未检验。

## 增强、任务分解与递归奖励建模 {#sec-amplification}

第二类提案用弱的部件造出一个强的监督者。

::: definition 迭代增强 {#def-ida}
在**迭代蒸馏与增强**（iterated distillation and amplification，IDA；Christiano、Shlegeris 与 Amodei，2018）中，人类 $H$ 回答一个问题时，先把它分解成子问题，并把子问题委派给当前模型 $M_k$ 的若干拷贝；组合系统 $\mathrm{Amp}(H, M_k)$ 比 $M_k$ 更能干，但很慢。下一个模型 $M_{k+1}$ 被训练来模仿 $\mathrm{Amp}(H, M_k)$（蒸馏），如此反复。**递归奖励建模**（recursive reward modelling，Leike 等，2018）把同样的思想用于评测：用奖励建模训练出的模型，协助人类评测下一个、更能干的模型的输出。
:::

安全论证是归纳式的：若每一步增强都保持对齐——人类忠实地分解、子答案诚实——且每一步蒸馏都忠实，那么对齐就能贯穿始终。真正承重的假设是**可分解认知假说**（factored cognition hypothesis）：困难任务可以分解成若干块，每一块都由一个上下文有限的人所能应付。研究机构 Ought 在 2019–2020 年用人检验了它，发现对许多推理任务而言，分解比期望的更难构造。一个实际例子是 Wu 等（OpenAI，2021）的书籍摘要：模型先摘要各个章节，再对摘要作摘要，每一层都用人类反馈训练，于是标注者评估的是短片段而不是整本书。把任务分解为可验证的步骤，也是过程监督（[[reasoning/process-outcome-rewards]]）的基础。

::: example 任务分解中错误的代价 {#ex-decomposition}
一项评测被分解成一棵树：每个节点有 $3$ 个子问题、共 $4$ 层，于是有 $81$ 个叶答案，通过 $40$ 个内部步骤合并。每个叶答案以概率 $0.99$ 正确，每个合并步骤以概率 $0.995$ 正确，彼此独立，且任何一处出错都会使最终评测错误。最终评测正确的概率是多少？在辩论设定下会有什么变化？
::: solution
$0.99^{81}\cdot0.995^{40} = 0.443\cdot0.818 = 0.362$。由于增强会合并所有子答案，错误会在整棵树的每个节点上累积。这正是检查步骤（过程监督）以及让节点相互检查的纠错式分解的动机。相形之下，在辩论中只有被质疑的路径会被检查，因此别处的错误无关紧要——但辩论依赖于诚实辩手识别出质疑应当指向哪里（[[#prop-tree]]）。
:::
:::

## 批评与 AI 辅助评测 {#sec-critiques}

可扩展监督中被部署最多的形式也是最简单的：用模型来帮助人类评测。Saunders 等（2022，"Self-critiquing models for assisting human evaluators"）训练模型撰写对摘要的批评；把批评展示给标注者，能帮助他们比独自查找时发现的多得多的缺陷，其中包括刻意插入的缺陷。McAleese 等（OpenAI，2024，"LLM critics help catch LLM bugs"）在插入了缺陷的代码上训练了一个批评模型（critic model）；在大多数比较中，训练者更喜欢它的批评而不是人类写的批评，而且它发现了更多缺陷，代价是一些吹毛求疵与幻觉出来的问题；而人–模型组合在全面性与准确性之间的平衡比任何一方单独都更好。宪法式AI 与大模型评审（[[post-training/ai-feedback]]、[[evaluation/model-judges]]）与此相关：它们以由公开声明的原则引导的模型评测，取代或辅助人类评测。

辅助评测继承了一个递归问题。如果批评模型与被评测的模型是同一类模型，它可能与其共享盲点，或者——在[[safety-alignment/deception-misalignment]]所考察的对抗情形中——对自己注意到的缺陷不予报告。证明者–验证者博弈（prover–verifier games，Kirchner 等，2024）训练一个强的"证明者"，产出较弱的"验证者"能够检查的解，目标是**可读性**（legibility）：把输出写成较弱的评测者能够跟得上的样子，为此付出一些原始性能的代价。

::: warning 更有说服力不等于更正确
一种方法若使人类评审更*赞同*模型的输出，并不必然改进了监督：RLHF 能让错误答案显得更可信（[[safety-alignment/reward-hacking#sec-gaming]]）。应当测量的量，是在有标准答案的问题上评审的*准确率*，并与包括顾问制与无辅助评审在内的基线相比较，而且辩手或助手要按说服力做优化。Khan 等发现更有说服力的辩手提高了辩论的准确率、却降低了顾问制的准确率——这一结果正是把两者区分开来的那种比较。
:::
## 弱到强泛化 {#sec-w2s}

辩论与增强试图让监督者更强。Burns 等（OpenAI，2023，"Weak-to-strong generalization: eliciting strong capabilities with weak supervision"）问了一个互补的问题：当一个强模型在弱监督者给出的标签上训练时，它究竟是连同错误一起仅仅模仿监督者，还是能泛化到超越监督者？他们提出了一个现在就能研究的类比：一个小模型扮演人类监督者，一个大型预训练模型扮演超人的系统。

::: definition 性能差距回收率 {#def-pgr}
在真实标签上微调一个弱模型；其测试性能为 $P_{\text{weak}}$。用它给一个训练集打标签，并在这些标签上微调一个强模型：性能为 $P_{\text{w2s}}$。在真实标签上微调强模型：得到**强上限** $P_{\text{ceil}}$。**性能差距回收率**（performance gap recovered）为
$$
\mathrm{PGR} = \frac{P_{\text{w2s}} - P_{\text{weak}}}{P_{\text{ceil}} - P_{\text{weak}}}.
$$ {#eq-pgr}
$\mathrm{PGR} = 0$ 表示强模型只与其监督者打平；$\mathrm{PGR} = 1$ 表示它做得和曾在真实标签上训练时一样好。
:::

::: example 计算 PGR {#ex-pgr}
一个弱监督者达到 $60\%$ 的准确率，在其标签上训练的强模型达到 $72\%$，在真实标签上训练的强模型达到 $80\%$。计算 PGR。第二位学生在同一份标签上达到 $62\%$。
::: solution
$\mathrm{PGR} = (0.72 - 0.60)/(0.80 - 0.60) = 0.12/0.20 = 0.6$：这位学生回收了差距的 $60\%$。第二位学生得到 $(0.62 - 0.60)/0.20 = 0.1$。PGR 是两个差之商，因此差距很小时噪声很大：若差距为 $20$ 个百分点、测试集为几千个样例，每个准确率的标准误差约为一个百分点，而 PGR 的不确定度是任一单个准确率的若干倍。
:::
:::

Burns 等发现，强的学生始终胜过其弱监督者：在 NLP 分类任务上，由 GPT-2 级模型监督的 GPT-4 级学生，其表现通常介于 GPT-3 与 GPT-3.5 水平之间。PGR 随强模型的规模上升。**辅助置信损失**（auxiliary confidence loss）允许学生自信地不同意弱标签，在监督者–学生差距最大的情况下把 NLP 任务上的 PGR 提升到 $80\%$ 左右。国际象棋棋局上的结果较弱，ChatGPT 奖励建模上的结果弱得多——而后者恰是与对齐最接近的设定。作者们列举了类比的失效之处：未来的超人模型模仿人类错误，可能比今天的学生模型模仿小模型错误更*容易*，因为人类错误在预训练数据中大量存在；而且强模型可能已经见过这些任务。

学生凭什么能超越其老师？两个理想化的情形标出了两端。

::: proposition 监督者的随机错误与系统性错误 {#prop-w2s}
设真实标签为 $y = h^\star(\mathbf x)\in\{-1, 1\}$。（a）若弱标签以概率 $1 - \eps$ 等于 $y$、以概率 $\eps < \tfrac12$ 等于 $-y$，且与 $\mathbf x$ 独立，那么在*弱标签上*使期望误差最小的分类器就是 $h^\star$：在分布意义上完美拟合弱标签的学生就回收了真相（$\mathrm{PGR} = 1$）。（b）若弱标签是一个确定函数 $\tilde y = h_w(\mathbf x)$，那么在弱标签上使误差最小的分类器就是 $h_w$ 本身：完美拟合弱标签的学生就是在模仿监督者（$\mathrm{PGR} = 0$）。
:::

::: proof
（a）对任意 $\mathbf x$，$\Prob(\tilde y = h^\star(\mathbf x)\mid\mathbf x) = 1 - \eps > \tfrac12 > \eps = \Prob(\tilde y = -h^\star(\mathbf x)\mid\mathbf x)$，于是 $\tilde y$ 的贝叶斯最优预测——在每个 $\mathbf x$ 处预测概率更大的标签——就是 $h^\star$。（b）这里 $\tilde y$ 由 $\mathbf x$ 决定，因此预测器 $h_w$ 在弱标签上的误差为零，并且除去零概率集之外是唯一的极小化者；它在真实标签上的表现与监督者相同。
:::

现实中的监督者错误既非纯随机也非纯确定，而现实的学生模型也不会完美拟合其训练标签。此时学生从系统性错误中学到什么，取决于它的**归纳偏置**：若真实概念在强模型的表征中是*显著的*——容易表达——而监督者的错误不是，那么训练时间较短、或带有正则化的学生，会先学会概念、后学会错误。Burns 等发现了这方面的证据：早停（early stopping）有帮助，而且当强模型原本就把任务表征得很好时 PGR 最高。下面这份清单在一个玩具例子里复现了这一效应。

::: example 显著性与早停 {#ex-salience}
在一个玩具问题中，强模型的表征把真实概念作为一个大尺度特征，此外还有九个小尺度的细节。一个弱监督者犯依赖于其中三个细节的系统性错误，其准确率为 $67.7\%$。一个逻辑回归学生在其标签上分别训练 $20$、$300$ 和 $3{,}000$ 个梯度步，达到 $99.3\%$、$90.0\%$ 和 $71.5\%$ 的准确率；上限是 $100\%$。计算各个 PGR 并解释这一趋势。
::: solution
$\mathrm{PGR} = (0.993 - 0.677)/(1 - 0.677) = 0.98$，$(0.900 - 0.677)/0.323 = 0.69$，以及 $(0.715 - 0.677)/0.323 = 0.12$（清单用未取整的准确率打印出 $0.98$、$0.69$、$0.11$）。从零开始的梯度下降沿大尺度特征移动最快，因此训练早期学生的权重主要落在显著的真实概念上；监督者的系统性错误只能通过小尺度细节来拟合，而这需要多得多的步数。训练充分后，学生便逼近[[#prop-w2s]](b) 中的模仿者。在这一图景下，弱到强泛化是一场学会概念与学会监督者错误之间的竞赛，只有当概念更容易学时才会胜出。
:::
:::

```python
import random, math

rng = random.Random(5)
d = 10
def draw(n):
    # 特征 0 是强模型已经表征得很好的"显著"概念（大尺度）；
    # 特征 1..9 是信息量微弱的细节（小尺度）
    out = []
    for _ in range(n):
        t = rng.gauss(0, 1)                     # 真实概念
        z = [rng.gauss(0, 1) for _ in range(d - 1)]
        x = [3.0 * t] + [0.3 * zi for zi in z]  # 强模型的表征
        out.append((x, t, z))
    return out
train, test = draw(2000), draw(2000)
truth = lambda t, z: 1 if t > 0 else -1
weak_random = lambda t, z, r: truth(t, z) * (-1 if r < 0.25 else 1)       # 无法预测的错误
weak_system = lambda t, z: 1 if t + 0.8 * sum(z[:3]) > 0 else -1           # 错误是 x 的函数

def fit(data, labels, steps, lr=0.05):
    """从零开始用梯度下降做逻辑回归；步数少 = 强隐式正则化。"""
    w = [0.0] * d
    for _ in range(steps):
        g = [0.0] * d
        for (x, _, _), y in zip(data, labels):
            m = y * sum(wi * xi for wi, xi in zip(w, x))
            c = -y / (1 + math.exp(m))
            for i in range(d):
                g[i] += c * x[i]
        w = [wi - lr * gi / len(data) for wi, gi in zip(w, g)]
    return w
def acc(w, data):
    return sum((sum(wi * xi for wi, xi in zip(w, x)) > 0) == (t > 0) for x, t, _ in data) / len(data)
def label_acc(fn, data):
    return sum(fn(t, z) == truth(t, z) for _, t, z in data) / len(data)

ceiling = acc(fit(train, [truth(t, z) for _, t, z in train], 300), test)
for name, labels, weak_acc in (
        ("random errors", [weak_random(t, z, rng.random()) for _, t, z in train], 0.75),
        ("systematic errors", [weak_system(t, z) for _, t, z in train], label_acc(weak_system, test))):
    for steps in (20, 300, 3000):
        w2s = acc(fit(train, labels, steps), test)
        pgr = (w2s - weak_acc) / (ceiling - weak_acc)
        print(f"{name:17s} steps={steps:4d}: weak {weak_acc:.3f}  weak-to-strong {w2s:.3f}  ceiling {ceiling:.3f}  PGR {pgr:.2f}")
```

输出：

```
random errors     steps=  20: weak 0.750  weak-to-strong 1.000  ceiling 1.000  PGR 1.00
random errors     steps= 300: weak 0.750  weak-to-strong 0.993  ceiling 1.000  PGR 0.97
random errors     steps=3000: weak 0.750  weak-to-strong 0.970  ceiling 1.000  PGR 0.88
systematic errors steps=  20: weak 0.677  weak-to-strong 0.993  ceiling 1.000  PGR 0.98
systematic errors steps= 300: weak 0.677  weak-to-strong 0.900  ceiling 1.000  PGR 0.69
systematic errors steps=3000: weak 0.677  weak-to-strong 0.715  ceiling 1.000  PGR 0.11
```

在随机错误下，无论训练多久，学生都保持在真实标签附近，正如[[#prop-w2s]](a) 所预测；缓慢的下降是在有限样本上对噪声的过拟合。在系统性错误下，随着训练继续，PGR 从 $0.98$ 降到 $0.11$。

## 各方法之间的关系 {#sec-relations}

这些提案回答的是问题的不同部分。辩论与增强要使评测比无辅助的人类判断**更准确**；批评是其实践上的先导。弱到强泛化问的是：在我们所能做出的评测之外，强模型的**泛化**在多大程度上值得信赖；它与其说是一种方法，不如说是关于归纳偏置的一个经验问题，而置信损失之类的方法正是试图利用这种偏置。易到难泛化（easy-to-hard generalisation）——在人类能检查的任务上训练、在更困难的任务上测试（Hase 等，2024；Sun 等，2024）——介于两者之间。它们全都假设模型并没有*试图*挫败监督——辩手努力争胜，学生拟合其标签。若一个模型策略性地行事，只在预计会被检查时才表现良好，那么监督方法就需要用[[safety-alignment/deception-misalignment]]中的评测与[[safety-alignment/monitoring-control]]中的控制措施来补足，而这些措施正是为那种情形设计的。

关于这一研究纲领的立场并不一致。支持者主张，当模型超越人类能力时，某种形式的 AI 辅助监督不可避免，而且实证结果显示了可测量的改进。领域内的怀疑者则指出含混论证、指出当评审与辩手掌握相同信息时辩论的收益会缩小的证据，以及"在选择题上帮助评审"与"在开放式任务上训练诚实系统"之间的鸿沟。领域之外的另一些人则质疑"被监督者是超人"这一框架是否描述了实际正在建造的系统。这些实验还很年轻，而且大多使用有标准答案的问题——恰恰因为给方法打分需要标准答案——而这正是这些方法本要超越的处境。

::: quiz
在一次夹心评测实验中，由 AI 辩论辅助的非专家评审，在那些无辅助非专家达到 $60\%$、专家达到 $95\%$ 准确率的问题上达到了 $85\%$。能得出什么结论？
- [ ] 辩论的模型是诚实的。
- [x] 在这些任务上，辩论让非专家回收了通向专家级判断之差距的大部分；这是否对超出专家能力的任务、或对经辩论训练的辩手成立，尚未被表明。
- [ ] 辩论将扩展到超人系统。
- [ ] 评测不再需要专家。
::: solution
夹心评测测量的正是被回收的差距，这里是 $(85 - 60)/(95 - 60) = 71\%$。它不能表明辩手是诚实的（只能表明评审更准确了），而向测试过的范围之外做外推仍是悬而未决的问题（[[#sec-debate]]、[[#sec-relations]]）。
:::
:::

::: history
Amodei 等（2016）把可扩展监督列为具体问题之一。Irving、Christiano 与 Amodei 在 2018 年提出了辩论，与迭代增强（Christiano、Shlegeris 与 Amodei）和递归奖励建模（Leike 等）同年。Barnes 与 Christiano 在 2020 年描述了含混论证问题；Ought 在 2019–2020 年研究了可分解认知；Wu 等（2021）递归地摘要书籍；Cotra（2021）提出了夹心评测，Bowman 等（2022）对它做了测量。Saunders 等（2022）训练了批评模型；Michael 等（2023）组织了人类辩论；Burns 等（2023）提出了弱到强泛化；Brown-Cohen 等（2023）提出了双重高效辩论。2024 年，Khan 等发现辩手更有说服力时辩论会改进，Kenton 等跨任务比较了各协议，McAleese 等报告了 CriticGPT，Kirchner 等为可读性训练了证明者。
:::

::: summary
- 可扩展监督问的是：当模型超过其评测者时如何准确评测模型；夹心评测与信息不对称让这一问题今天就能检验。
- 辩论：两个模型交锋，弱评审裁决。在主张树上，诚实的一方通过质疑一条路径取胜，于是评审检查一个叶节点而不是 $m^D$ 个（[[#prop-tree]]）；含混论证、评审偏差与训练动态破坏了这一理想化。
- 实证上，在信息不对称下，辩论对非专家评审胜过顾问制（Michael 等，2023；Khan 等，2024）；与评审直接作答相比则结果好坏不一（Kenton 等，2024）。
- 增强与递归奖励建模通过任务分解构造强评测者；错误会沿着整棵树累积，而可分解认知假说尚未证实。
- 模型批评已经在帮助人类发现缺陷；不可把说服力误当成准确性。
- 弱到强泛化：$\mathrm{PGR} = (P_{\text{w2s}} - P_{\text{weak}})/(P_{\text{ceil}} - P_{\text{weak}})$。监督者的随机错误可以回收，确定性错误会被模仿；介于两者之间时，由显著性与早停决定（[[#prop-w2s]]）。
- 这一切都假设模型没有在策略性地挫败监督；那种情形需要针对欺骗的评测与控制。
:::

## 习题

::: exercise 一个 PGR {level=1 check="0.75"}
一个弱监督者得分为 $70\%$，弱到强学生为 $82\%$，强上限为 $86\%$。PGR 是多少？
::: solution
$(0.82 - 0.70)/(0.86 - 0.70) = 0.12/0.16 = 0.75$（[[#def-pgr]]）。
:::
:::

::: exercise 主张树中的叶节点 {level=1 check="3125"}
一棵主张树中每个主张含 $5$ 个子主张，深度为 $5$。直接检查将评估多少个叶节点？
::: solution
$5^5 = 3{,}125$；而[[#prop-tree]]的辩论只评估一个，经过五轮质疑。
:::
:::

::: exercise 夹心评测的差距 {level=1 check="0.6"}
无辅助的非专家得分为 $50\%$，专家为 $90\%$，受辅助的非专家为 $74\%$。辅助回收了非专家–专家差距的多少？
::: solution
$(0.74 - 0.50)/(0.90 - 0.50) = 0.24/0.40 = 0.6$ ——与 PGR 同样的比值，只是把专家作为上限。
:::
:::

::: exercise 任务分解的错误 {level=2 check="0.362"}
重新计算[[#ex-decomposition]]：$81$ 个叶答案各以概率 $0.99$ 正确，$40$ 个合并步骤各以概率 $0.995$ 正确，全部相互独立且全部必需。保留三位小数。
::: solution
$0.99^{81} = e^{81\ln0.99} = e^{-0.8141} = 0.4430$，$0.995^{40} = e^{-0.2005} = 0.8183$；乘积为 $0.3625$，故三位小数为 $0.362$。
:::
:::

::: exercise 评审多数表决 {level=2 check="0.972"}
在理想化的辩论中，每位评审各以概率 $0.9$ 独立地正确评估最后的叶节点。$3$ 位评审的多数正确的概率是多少？保留三位小数。
::: solution
$0.9^3 + 3\cdot0.9^2\cdot0.1 = 0.729 + 0.243 = 0.972$。独立性是一个很强的假设：共享同一种偏差（比如偏爱听起来自信的主张）的评审，并不会因为投票而改进。
:::
:::

::: exercise PGR 的不确定度 {level=2 check="0.06"}
弱监督、弱到强与上限的准确率分别在 $2{,}000$ 个样例的测试集上测量（彼此不同），真值为 $0.60$、$0.72$ 和 $0.80$。用 delta 方法估计 PGR 的标准误差。保留两位小数。
::: solution
三个准确率的方差为 $p(1 - p)/2000$：$s_W^2 = 1.200\times10^{-4}$、$s_S^2 = 1.008\times10^{-4}$、$s_C^2 = 0.800\times10^{-4}$。由 $\mathrm{PGR} = (S - W)/(C - W)$，差距 $G = C - W = 0.2$，偏导数为 $\partial/\partial S = 1/G = 5$、$\partial/\partial C = -(S - W)/G^2 = -3$、$\partial/\partial W = (S - C)/G^2 = -2$。方差为 $25(1.008\times10^{-4}) + 9(0.800\times10^{-4}) + 4(1.200\times10^{-4}) = 3.72\times10^{-3}$，于是标准误差为 $\sqrt{0.00372} = 0.061$，两位小数为 $0.06$。因此 PGR 为 $0.6$ 时，$95\%$ 置信下的不确定度约为 $\pm0.12$，而每个准确率本身只精确到约 $\pm0.02$。若把三者放在同一测试集上测量，误差会正相关，从而在一定程度上减小不确定度。
:::
:::

::: exercise 混合的监督者错误 {level=2}
一个弱监督者在 $80\%$ 的输入上正确。在一个覆盖 $10\%$ 输入的区域 $R$ 上它总是错的；在别处以概率 $\eps$ 随机犯错。（a）求 $\eps$。（b）一个在每个输入上都预测贝叶斯最优弱标签的学生达到多少准确率？若上限为 $100\%$，它得到的 PGR 是多少？
::: solution
（a）准确率 $= 0.1\cdot0 + 0.9(1 - \eps) = 0.8$，解得 $\eps = 1/9 = 0.111$。（b）在 $R$ 之外，弱标签的贝叶斯最优预测器是真实标签（[[#prop-w2s]](a)）；在 $R$ 之内，它是监督者的错误标签（(b)）。于是学生在 $90\%$ 的输入上正确，且 $\mathrm{PGR} = (0.9 - 0.8)/(1 - 0.8) = 0.5$。监督者错误中随机的那一半被回收，系统性的那一半被模仿——这就是为什么决定弱到强训练所能达到之物的，是监督者错误的构成——而非其总量。
:::
:::

::: exercise 含混论证 {level=3}
在主张树辩论中，设一个虚假的根主张有 $m^D$ 个叶节点，其中恰有一个为假，而诚实的辩手（质疑方）不能评估子主张，只能随机选择子主张。诚实辩手获胜的概率是多少？这与含混论证问题有何关系？一个高效的诚实策略需要什么性质？
::: solution
每一层中，虚假的子主张都是 $m$ 个选择之一，随机选择以概率 $1/m$ 找到它；辩手必须在全部 $D$ 层都找到它，因此概率为 $m^{-D}$——当 $m = 4$、$D = 6$ 时为 $1/4{,}096$。不诚实的辩手在辩护时没有这样的困难：除通向虚假叶节点的那条之外，它被迫沿任何路径辩护的都是真实主张。这就是含混论证问题：[[#prop-tree]]假设诚实的一方能够*定位*缺陷，而当缺陷被隐藏时，定位它与检查整个论证同样困难。一个高效的诚实策略需要这样一种能力：以诚实计算规模的多项式代价判定哪个子主张是假的——双重高效辩论协议正是为提供这一性质而设计的（Brown-Cohen 等，2023），例如要求主张只涉及诚实辩手自己能够重新计算的运算。
:::
:::

::: exercise 玩具例子中的早停 {level=3}
利用逻辑损失在 $\mathbf w = \mathbf 0$ 处的梯度，解释清单中头几步梯度为何即使标签是系统性的弱标签，也把大部分权重放在特征 $0$ 上。估计特征 $0$ 上的初始梯度与特征 $1$ 上初始梯度之比。
::: solution
在 $\mathbf w = \mathbf 0$ 处，$\log(1 + e^{-y\,\mathbf w\cdot\mathbf x})$ 的逐样例梯度为 $-\tfrac12y\mathbf x$，因此初始更新正比于 $\E[\tilde y\,\mathbf x]$。特征 $0$ 是 $3t$，特征 $1$ 是 $0.3z_1$，且 $\tilde y = \sgn(t + 0.8(z_1 + z_2 + z_3))$。令 $S = t + 0.8(z_1 + z_2 + z_3)$，其方差为 $1 + 3(0.64) = 2.92$。对高斯变量 $S$ 与任一与之联合高斯的 $u$，有 $\E[\sgn(S)u] = \sqrt{2/\pi}\,\Cov(S, u)/\sqrt{\Var S}$。于是 $\E[\tilde y\cdot3t]\propto3\cdot1 = 3$，$\E[\tilde y\cdot0.3z_1]\propto0.3\cdot0.8 = 0.24$，比值为 $12.5$。因此最初几步把 $\mathbf w$ 大致对齐到真实概念上，学生的预测就是真实标签的预测；复现监督者错误的那些小特征权重，只有在特征 $0$ 上的损失饱和之后才会增长。若细节与概念处在同一尺度，这场竞赛就会接近得多，而且任何停止时刻的 PGR 都会更低。
:::
:::
