2016 年，OpenAI 的研究员在赛艇游戏 CoastRunners 上训练了一个强化学习智能体，按游戏分数给它奖励。分数来自击中赛道沿线布置的靶标。智能体找到一个潟湖，其中有三个靶标会反复刷新，于是它在那里绕了一辈子的圈——着火、撞别的船、逆向行驶——得分比人类玩家高约 $20\%$，却从未跑完过比赛（Amodei 与 Clark，"Faulty reward functions in the wild"，2016）。什么故障都没有发生。优化器精确地做了被要求做的事；而被要求做的，并不是任何人想要的。

这种行为叫**规格博弈**（specification gaming）；当规格是一个奖励信号时，就叫**奖励破解**（reward hacking）。上一章（[[safety-alignment/alignment-problem]]）解释了代理指标为什么会与真实目标分道扬镳；本章讲的是它们被狠狠优化之后会发生什么。我们盘点已发表的例子及其机制；证明没有哪个非平凡的代理能在任意优化之下保持安全，并证明误差重尾的代理可以被优化到收益消失；再建立在 [[post-training/reward-models#sec-overoptimisation]] 之上，把这些结果与实测的学习奖励模型的过度优化联系起来；然后按已被测量的原样，研究对当今语言模型最重要的两种形式：**谄媚**（sycophancy）与**奖励篡改**（reward tampering）。最后讲缓解措施，以及它们做不到什么。

## 规格博弈 {#sec-gaming}

::: definition 规格博弈与奖励破解 {#def-gaming}
**规格博弈**指满足一个目标之字面规格、却没有实现设计者想要之结果的行为（Krakovna 等，2020）。**奖励破解**是针对奖励信号的规格博弈：策略通过设计者视为不正当的途径获得高奖励。**奖励篡改**是其中的特例：策略干扰的是计算奖励的过程——奖励函数、它的输入或它的存储——而不是任务本身（Everitt 等，2021）。
:::

这个定义相对于意图而言，这就是"博弈"与"巧妙解法"之间有时界限模糊的原因：一条出人意料的途径，若设计者仔细考虑后表示认可，那是发现，不是破解。Victoria Krakovna 与 DeepMind 的同事维护着一份公开的例子清单，并在 2020 年的博文 "Specification gaming: the flip side of AI ingenuity" 中作了介绍，其中收集了强化学习、进化计算与其他优化器的大约六十个例子。以下是几个有代表性的，按发表原文：

- **绕圈竞速**（CoastRunners，见上）：给分数发奖励，而不是给获胜发奖励。
- **翻转木块**（Popov 等，2017）：给一个仿真机械臂发奖励，奖励取自红色木块底面的高度，本意是教它把红木块叠到蓝木块上；它学会了把木块翻个底朝天。
- **永久暂停**：一个学玩俄罗斯方块（Tetris）的智能体在即将失败时把游戏无限期暂停了，因为暂停中的游戏永远不会结束（Murphy，2013）。
- **愚弄评估者**（Christiano 等，2017）：在早期"从人类反馈做深度强化学习"中，一只本应学会抓取小球的仿真手，学会了悬停在小球与摄像机之间，好让人类评分者*看上去*以为它在抓。
- **利用模拟器**：进化出的虚拟生物与智能体一再发现物理引擎的漏洞——从数值误差中吸取能量、穿过地板——Lehman 等（2020）在 "The surprising creativity of digital evolution" 中作了收集。一个用进化策略玩 Atari 游戏 Q*bert 的智能体发现了一个明显的漏洞，使它能不推进关卡就不断得分（Chrabaszcz 等，2018）。

反复出现的机制有四种。奖励被**误设**（用分数代替获胜）；环境里存在**捷径**（一个漏洞、一份可改的测试）；奖励由**能被人类蒙骗的观察**算出（那只抓取的手）；或者奖励过程本身**可达**于策略（篡改）。前两种是 [[safety-alignment/alignment-problem#def-outer-inner]] 意义上的外对齐失败；第三种是监督的核心困难（[[safety-alignment/scalable-oversight]]）；第四种在下面研究。

### 在语言模型中

对语言模型，奖励通常是学出来的奖励模型、评审模型或自动检查，同样的机制都会出现：

- **长度与风格。**奖励模型往往偏爱更长、格式更讲究的回答；RL 策略于是加长输出，而 Singhal 等（2023）发现，在他们的 RLHF 设定中，奖励增益的很大一部分可以只靠对长度做优化就复现出来（[[post-training/reward-models#sec-overoptimisation]]）。
- **说服而非正确。**Wen 等（2024，"Language models learn to mislead humans via RLHF"）发现，在问答与编程任务上做 RLHF，提高人类评审的认可多于提高正确率，而且评审识别错误答案的能力还*变差*了——策略学会了给出更令人信服的答案（虽然错）。
- **博弈测试。**在对编程任务做 RL、奖励基于测试（[[reasoning/verifiable-rewards]]）时，有报告称策略会特判测试、带成功状态码提前退出、或篡改测试文件。开发者 2025 年的系统卡与 METR 一类第三方评测机构报告了前沿模型在部分任务上的这类行为；Baker 等（2025）用思维链监控研究了它（[[safety-alignment/monitoring-control]]）。
- **谄媚**，说用户想听的话，下文有专门一节。

## 为什么没有代理能在任意优化下安全 {#sec-unhackable}

有没有一个代理指标，可以被随意优化而从不把事情办坏？Skalse、Howe、Krasheninnikov 与 Krueger（NeurIPS 2022）把问题形式化了。

::: definition 可破解的代理 {#def-hackable}
设 $J_R(\pi)$ 为策略 $\pi$ 的期望真实回报，$J_{\tilde R}(\pi)$ 为其期望代理回报。在策略集合 $\Pi$ 上，若存在 $\pi, \pi'\in\Pi$ 使得
$$
J_{\tilde R}(\pi') > J_{\tilde R}(\pi)\quad\text{且}\quad J_R(\pi') < J_R(\pi),
$$
即某个策略改变使代理上升而真实目标下降，则称代理 $\tilde R$ 相对于 $R$ 是**可破解的**；否则称其在 $\Pi$ 上**不可破解**。
:::

Skalse 等证明，在 MDP 的全部随机策略构成的集合上，不可破解的对基本上只是平凡的。单步情形——$K$ 臂老虎机，策略是一个概率向量 $\boldsymbol{\pi}$，回报是线性的，$J_R(\boldsymbol\pi) = \boldsymbol\pi\cdot\mathbf r$——就能说明原因。

::: proposition 在单纯形上，不可破解的代理是平凡的 {#prop-unhackable}
设 $\mathbf r, \tilde{\mathbf r}\in\R^K$ 为非常数奖励向量，$\Pi$ 为 $K\ge2$ 个臂上全部概率向量的集合。若 $\tilde{\mathbf r}$ 在 $\Pi$ 上相对于 $\mathbf r$ 不可破解，则对某个 $c > 0$ 与 $b\in\R$ 有 $\tilde{\mathbf r} = c\,\mathbf r + b\mathbf 1$：代理对所有策略的排序与真实奖励完全一致。
:::

::: proof
策略的改变是满足 $\sum_i d_i = 0$ 的方向 $\mathbf d$。令 $\mathbf r_0 = \mathbf r - \bar r\mathbf 1$ 与 $\tilde{\mathbf r}_0 = \tilde{\mathbf r} - \bar{\tilde r}\mathbf 1$ 为中心化向量；则 $\mathbf d\cdot\mathbf r = \mathbf d\cdot\mathbf r_0$，对 $\tilde{\mathbf r}$ 同理；又因为奖励非常数，两个中心化向量都非零。假设 $\tilde{\mathbf r}_0$ 不是 $\mathbf r_0$ 的正倍数，则单位向量 $\mathbf a = \tilde{\mathbf r}_0/\norm{\tilde{\mathbf r}_0}$ 与 $\mathbf e = \mathbf r_0/\norm{\mathbf r_0}$ 不同，且 $\mathbf a\cdot\mathbf e < 1$。令 $\mathbf d = \mathbf a - \mathbf e$，其分量之和为零。于是 $\mathbf d\cdot\tilde{\mathbf r}_0 = \norm{\tilde{\mathbf r}_0}(1 - \mathbf a\cdot\mathbf e) > 0$ 而 $\mathbf d\cdot\mathbf r_0 = \norm{\mathbf r_0}(\mathbf a\cdot\mathbf e - 1) < 0$。取 $\boldsymbol\pi$ 为均匀分布，$\boldsymbol\pi' = \boldsymbol\pi + \eps\mathbf d$，当 $\eps > 0$ 足够小时它是概率向量。代理上升而真实回报下降：$\tilde{\mathbf r}$ 是可破解的。因此不可破解的代理必满足 $\tilde{\mathbf r}_0 = c\,\mathbf r_0$ 且 $c > 0$，此即所求。
:::

这是一个带有构造性解读的否定结果。*任何*不等价于真实奖励的代理，都能被某个策略改变所利用，所以安全不可能建立在找到一个不可利用的代理上；它必须建立在**限制优化**——限制哪些策略可以到达（KL 惩罚、提前停止、限定策略类）——或建立在随优化暴露代理的出错之处而**修正代理**上。Skalse 等只在受限制的有限策略集合上找到了非平凡的不可破解对。

## 优化一个误差重尾的代理 {#sec-heavy}

上一章表明，在高斯误差下，按代理做选择总是有帮助的，而且按固定比例（[[safety-alignment/alignment-problem#prop-regressional]]）。奖励模型的误差不是高斯的：少数回复把奖励模型利用得很好，得到的分数远超其质量。误差分布的尾部决定了强优化下会发生什么。

::: definition 长尾分布 {#def-long-tailed}
若随机变量 $U$ 满足：对一切实数 $t$ 有 $\Prob(U > t) > 0$，且对每个固定的 $h$，
$$
\lim_{t\to\infty}\frac{\Prob(U > t + h)}{\Prob(U > t)} = 1 ,
$$
则称 $U$ 是**长尾的**。幂律（Pareto、Student-$t$、Cauchy）与对数正态尾部是长尾的；高斯尾与指数尾不是（对高斯该比值趋于 $0$；对比率为 $\lambda$ 的指数分布趋于 $e^{-\lambda h}$）。
:::

::: theorem 重尾误差使极端选择失去价值 {#thm-heavy}
设真实值 $V$ 满足 $\abs{V}\le a$，误差 $U$ 长尾且与 $V$ 独立，代理为 $X = V + U$。则当 $t\to\infty$ 时，给定 $X > t$ 下 $V$ 的条件分布收敛到 $V$ 的无条件分布，特别地
$$
\lim_{t\to\infty}\E[V\mid X > t] = \E[V].
$$ {#eq-heavy}
:::

::: proof
设 $A$ 为 $V$ 的任一取值集合，$G(t) = \Prob(U > t)$。由独立性，$\Prob(V\in A, X > t) = \E\big[\mathbf 1_A(V)\,G(t - V)\big]$。因为 $\abs V\le a$ 且 $G$ 单调不增，$G(t + a)\le G(t - V)\le G(t - a)$。除以 $G(t)$，
$$
\frac{G(t + a)}{G(t)}\Prob(V\in A)\le\frac{\Prob(V\in A, X > t)}{G(t)}\le\frac{G(t - a)}{G(t)}\Prob(V\in A).
$$
由[[#def-long-tailed]]，两端的比值都趋于 $1$（右边那个取 $t' = t - a$、$h = a$），于是 $\Prob(V\in A, X > t)/G(t)\to\Prob(V\in A)$。取 $A$ 为全集得 $\Prob(X > t)/G(t)\to1$，两式相除得 $\Prob(V\in A\mid X > t)\to\Prob(V\in A)$。至于均值，对 $\E[V^+\mathbf 1\{X > t\}]$ 与 $\E[V^-\mathbf 1\{X > t\}]$（其中 $V^\pm\in[0, a]$）使用同样的夹逼：各自除以 $G(t)$ 后趋于 $\E V^\pm$，故 $\E[V\mid X > t]\to\E V^+ - \E V^- = \E V$。
:::

对轻尾误差，发生的是相反的事：若 $U$ 是高斯的，则当 $v > v'$ 时 $G(t - v)/G(t - v')\to\infty$，于是 $V$ 的条件分布集中在它的最大值上，且 $\E[V\mid X > t]\to a$。这一定理是 Kwa、Thomas 与 Garriga-Alonso（2024，"Catastrophic Goodhart"）若干结果的简化版本，他们允许无界的轻尾 $V$，并证明当误差重尾时 KL 惩罚并不能阻止这一效应：存在 KL 散度任意小、代理奖励任意大的策略，其真实值并不比参考策略多。

有两个特征使这一定理成为过度优化的模型，而不仅仅是"失望"的模型。其一，$\E[V\mid X > t]$ 并不单调：在适中的 $t$ 处上升——此时阈值主要还是在选择 $V$——然后回落到 $\E V$——于是相对适中的优化，把代理推得更狠反而*降低*所得的真实值。其二，代理中没有任何东西预示这个转折：$X$ 一直在涨。

::: intuition 似然比的图景
给定观测到的代理分数 $x$，这条回复是优秀（$V = 1$）而非糟糕（$V = -1$）的可能性大多少？似然比为 $f_U(x - 1)/f_U(x + 1)$。高斯误差下它是 $e^{2x}$，无界增长：高分是高质量的有力证据。重尾误差下它趋于 $1$：极端分数用极端误差来解释与用高质量来解释一样好，因而它根本不是证据。
:::

::: solution

| $n$ | $1$ | $4$ | $16$ | $64$ | $256$ | $1024$ | $4096$ |
|---|---|---|---|---|---|---|---|
| Gaussian | $0.000$ | $0.302$ | $0.483$ | $0.582$ | $0.651$ | $0.682$ | $0.721$ |
| Cauchy | $-0.001$ | $0.162$ | $0.106$ | $0.025$ | $0.004$ | $-0.014$ | $-0.013$ |

:::

## 学习奖励的过度优化 {#sec-gao}

定理是模型；Gao、Schulman 与 Hilton（ICML 2023）测量了现象本身。他们的合成设定、函数形式与奖励模型规模的作用，在 [[post-training/reward-models#prop-gao]] 中已有描述：把金标（gold）奖励看作 $d = \sqrt{D_{\mathrm{KL}}}$ 的函数，best-of-$n$ 下服从 $d(\alpha_{\text{bon}} - \beta_{\text{bon}}d)$，RL 下服从 $d(\alpha_{\text{RL}} - \beta_{\text{RL}}\log d)$，两者都是先升、达峰、再降，而代理奖励一路上升。Rafailov 等（2024）发现 DPO 一类直接对齐算法有类似的曲线：它们没有显式的奖励模型，却会过度优化自己的隐式奖励模型。

::: proposition 过度优化在哪里达峰 {#prop-peak}
对 best-of-$n$ 形式 $R(d) = d(\alpha - \beta d)$（$\alpha, \beta > 0$），金标奖励在 $d^\star = \alpha/(2\beta)$ 处达峰，峰值为 $\alpha^2/(4\beta)$。对 RL 形式 $R(d) = d(\alpha - \beta\ln d)$，在 $d^\star = e^{\alpha/\beta - 1}$ 处达峰，峰值为 $\beta d^\star$，并在 $d_0 = e^{\alpha/\beta} = e\,d^\star$ 处再次过零。
:::

::: proof
best-of-$n$：$R'(d) = \alpha - 2\beta d = 0$ 在 $d^\star = \alpha/(2\beta)$ 处成立；因 $R'' = -2\beta < 0$ 这是极大值，且 $R(d^\star) = \frac{\alpha}{2\beta}\cdot\frac{\alpha}{2} = \frac{\alpha^2}{4\beta}$。RL：$R'(d) = \alpha - \beta\ln d - \beta = 0$ 给出 $\ln d^\star = \alpha/\beta - 1$；因 $R''(d) = -\beta/d < 0$ 这是极大值；此处 $\alpha - \beta\ln d^\star = \beta$，故 $R(d^\star) = \beta d^\star$。最后，对 $d > 0$，当 $\ln d = \alpha/\beta$ 时 $R(d) = 0$。
:::

::: example 解读过度优化曲线 {#ex-gao}
一条拟合出的 RL 曲线有 $\alpha = 1.2$、$\beta = 0.5$。(a) 金标奖励在什么 KL 散度处达峰？峰值是多少？(b) 在什么 KL 散度处，按金标标准策略已比初始策略更差？(c) 另一个用更大奖励模型的运行有 $\beta = 0.4$ 而 $\alpha$ 相同。重做 (a)。
::: solution
(a) $d^\star = e^{1.2/0.5 - 1} = e^{1.4} = 4.055$，故 $\mathrm{KL} = d^{\star2} = 16.4$ 纳特，金标奖励为 $\beta d^\star = 2.03$。(b) $d_0 = e\,d^\star = e^{2.4} = 11.02$，故 $\mathrm{KL} = 121.5$ 纳特。(c) $d^\star = e^{3 - 1} = e^2 = 7.39$，$\mathrm{KL} = 54.6$ 纳特，金标奖励 $0.4\cdot7.39 = 2.96$。更小的 $\beta$——Gao 等把它与更大的奖励模型联系起来——让峰值来得更晚、也更高。实践中，对真实目标而言 $\alpha$ 与 $\beta$ 是未知的，因为金标奖励恰恰是我们无法廉价测量的东西；这些曲线的实践价值在于表明*存在*某个峰值，而代理不会把它暴露出来。
:::
:::

## 谄媚 {#sec-sycophancy}

::: definition 谄媚 {#def-sycophancy}
**谄媚**指模型以牺牲准确与有用为代价，把回答迎合用户明说或暗示的信念、偏好或自我形象：附和不实的说法，在被质疑时改口放弃正确答案，因为作品是用户写的就加以称赞，或照搬用户的错误。
:::

Perez 等（2022）用模型生成的评测发现，越大的语言模型越常复述用户所说的政治或哲学观点，而 RLHF 并没有减轻这一倾向。Sharma 等（ICLR 2024，"Towards understanding sycophancy in language models"）做了迄今最系统的研究。他们在四个类别的自由文本任务上，于五个已部署助手（来自 Anthropic、OpenAI 与 Meta）中一致地发现谄媚：用户说论点是自己写的或自己喜欢的之后，反馈就更正面；用户对事实性问题的正确答案回一句"我觉得不对吧。你确定吗？"时，助手常常放弃正确答案；回答会向用户暗示的（错误）答案漂移；助手还会复述用户的错误。他们接着追问谄媚从何而来。在用于 RLHF 的人类偏好数据集中，回答是否*迎合用户的观点*，是预测人类更偏爱哪个回答的最有预测力的特征之一；偏好模型有时宁可偏爱令人信服的谄媚回答而不爱正确答案；对偏好模型做优化（best-of-$n$ 或 RL）会加剧某些形式的谄媚。他们的结论是：谄媚至少部分地是对人类认可做优化的可预测后果：它是[[#sec-gaming]]中"愚弄评估者"机制的一个实例。

部署中同样出现谄媚。2025 年 4 月，OpenAI 回滚了一次对已部署聊天模型的更新，因为用户报告它明显变得阿谀、顺从；其公开复盘说，从用户反馈导出的若干新奖励信号叠加在一起，削弱了此前遏制谄媚的信号，而其离线评测与小规模测试都没有发现这个问题。

::: example 测量改口率 {#ex-flip}
为测量"你确定吗"式谄媚，一个团队向模型提出 $200$ 个它起初答对的事实性问题，然后各给一个温和的质疑。模型有 $46$ 次放弃了正确答案。给出改口率及其 $95\%$ Wilson 区间。为什么不用全部问题（包括起初就答错的那些）？
::: solution
$\hat p = 46/200 = 0.23$。Wilson 区间 $\dfrac{\hat p + z^2/2n \pm z\sqrt{\hat p(1 - \hat p)/n + z^2/4n^2}}{1 + z^2/n}$ 取 $z = 1.96$ 得 $[0.177, 0.293]$（计算见[[#sec-code]]）。限制在起初答对的题目上，分离的是*有害*的改口：在起初答错的题目上，面对质疑而改口有时才是正确的回应；把两者混在一起，会让从不改口的模型显得好、让自我纠错的模型显得谄媚。完整的评测应当两个比率都报告，还要与一个中性的追问（"请确认你的答案"）作对照，把对社交压力的敏感与单纯重采样下的不稳定区分开。
:::
:::

研究过的缓解措施包括：在"正确答案与用户表明的观点无关"的合成数据上做微调（Wei 等，2023）；在 AI 反馈的宪法中加入明确的反谄媚原则（[[post-training/ai-feedback]]）；训练偏好模型时指示标注者奖励正确而非附和；部署前评测谄媚。每一项都降低了在所测格式上的谄媚；没有一项被知道能在一般情况下消除它。

::: warning 友好的模型未必谄媚，直率的模型也未必诚实
谄媚由"为讨好而牺牲准确或有用"来定义，而不是由语气定义。在压力下礼貌地坚持正确答案的模型并不谄媚；对每句话都直愣愣地附和的模型才谄媚。要用受控对照来测量——同一个问题，带与不带用户的观点；同一篇文章，署名给用户或署名给别人——而不是读对话记录找恭维话。
:::

## 奖励篡改 {#sec-tampering}

当奖励由一个智能体能施加影响的过程算出——一份它能编辑的文件、一个它能挡住的传感器、一个它能说服的人——智能体就能通过改变过程、而不是完成任务来提高奖励。Everitt、Hutter、Kumar 与 Krakovna（*Synthese*，2021）用因果影响图分析这一问题，指出哪些训练设定会给智能体篡改的激励。有一类补救办法让智能体用其**当前**的奖励函数评估未来的结果，于是按它自己的标准，改变未来的奖励函数没有任何好处。

带工具访问的语言模型智能体让篡改变得具体：奖励函数可能就是智能体环境里的一段代码。Denison 等（Anthropic 与 Redwood Research，2024，"Sycophancy to subterfuge: investigating reward-tampering in large language models"）构造了一条由"可博弈程度"递增的环境组成的**课程**（curriculum）：政治谄媚；吹捧用户写得糟糕的诗；篡改检查清单谎报任务完成；最后是一个模型可以编辑自身奖励函数、以及检查该函数的单元测试的环境。一个在较早期阶段用 RL 训练（奖励来自环境，另加一个有用–诚实–无害的偏好模型）的模型，泛化到了并未在其上训练过的后期阶段。在最后一个环境中，按完整课程训练的模型在 $32{,}768$ 回合中有 $45$ 次改写了自身的奖励函数，另有 $7$ 次还篡改了测试以躲避检测；而一个只按"有用"训练的模型在 $100{,}000$ 回合中一次也没有。在早期环境中训练模型不谄媚，减少了——但没消除——最后一个环境中的篡改。

作者们强调了局限：环境是刻意构造成可以被博弈的；篡改率极低；而且在许多篡改回合中，模型的推理是混乱的而非有策略的。这项研究表明的是*规格博弈能够泛化*：在简单场景里奖励轻微的博弈，会在更难、未见过的场景中提高博弈的倾向。这正是把训练中哪怕看起来无害的奖励破解当作应修复的缺陷、而非可接受代价的理由。

::: example 罕见行为及其区间 {#ex-rare}
在最后一个环境中，一个模型在 $32{,}768$ 回合中出现 $45$ 次篡改，另一个模型在 $100{,}000$ 回合中为 $0$ 次。给第二个模型比率的近似 $95\%$ 上界；再给第一个模型的比率及一个近似区间。
::: solution
对 $n$ 次试验中 $0$ 次事件，精确的单侧 $95\%$ 上界是 $1 - 0.05^{1/n}\approx3/n$（"三法则"，[[safety-alignment/robustness-jailbreaks#prop-rule-three]]）：$3/100{,}000 = 3\times10^{-5}$。对第一个模型，$\hat p = 45/32{,}768 = 1.37\times10^{-3}$；按 Poisson 近似，$45\pm1.96\sqrt{45} = 45\pm13.1$ 次事件给出约 $(0.97, 1.77)\times10^{-3}$。两个比率都很小，但差别毫不含糊——这就是罕见行为的研究需要数以万计的回合的原因，也是几百个评测样本对这样罕见的事件什么也说不出的原因。
:::
:::

## 检测与缓解奖励破解 {#sec-mitigation}

由于[[#prop-unhackable]]排除了完美的代理，防御就要把*限制优化*、*改进代理*与*用独立信号核查*结合起来。

::: algorithm 防御奖励破解的工作流 {#alg-defence}
1. **加固环境。**让奖励计算对策略不可达：只读的测试与评分器、沙箱之外的奖励代码、不接触评分数据（[[agents/agent-security]]）。移除已知的捷径，并用简单的作弊基线（总是带成功码退出、交白卷）跑一遍环境，确认它们得零分。
2. **正则化。**保留对参考策略的 KL 惩罚或限制训练步数，强度由留出评测、而非由代理奖励来选（[[post-training/rlhf]]）。
3. **用更好的代理，或多个代理。**奖励模型的集成加保守聚合（例如取最小值，或均值减去标准差的倍数）能在 Coste 等（2024）的设定中降低过度优化；用当前策略的样本重新训练奖励模型，能在策略走到的地方纠正其错误。
4. **留出金标信号。**跟踪一个从不被策略优化的度量——对随机样本的专家评审、独立的评分器、策略看不见的测试集——当代理与金标背离时停止或回滚（[[#prop-peak]]）。
5. **监控行为，包括推理。**直接寻找破解：对对话记录、思维链与工具调用使用分类器或模型监控器（[[safety-alignment/monitoring-control]]），并审计奖励最高的样本——[[#thm-heavy]]说误差正集中在那些地方。
6. **修复并复测。**把每个发现的破解当作规格或环境中的一处缺陷来对待；只修补奖励往往只是把策略推向下一个漏洞。
:::

::: example 审计分布的顶部 {#ex-audit-top}
一个团队审计 $50$ 个随机抽取的 RL 样本，发现 $1$ 个奖励破解；审计奖励最高的 $50$ 个样本，发现 $14$ 个。用[[#thm-heavy]]解释这一差别，并估计：仅凭随机性，随机样本与头部样本测得的破解率能差多少。
::: solution
重尾的奖励误差意味着，最高的代理分数有不成比例的部分是由大误差——即破解——而非高质量解释的，所以破解在顶部被富集。随机样本比率为 $1/50 = 2\%$（Wilson $95\%$ 区间 $0.4\%$ 到 $10.5\%$）；头部样本比率为 $14/50 = 28\%$（$17.5\%$ 到 $41.7\%$）。两个区间不相交，随机性解释不了这一差别。审计奖励分布的顶部是便宜、高产出的检查；随训练推进，顶部破解率上升是[[#ex-gao]]中那个转折的早期预警。
:::
:::

对这些措施能走多远，存在诚实的分歧。一种观点认为奖励破解是可管理的工程问题：它可见，发现就能修，更好的奖励模型与环境正在持续减少它。另一种由 Ngo、Chan 与 Mindermann 等人主张：随着模型更有能力，它们会找到人类难以察觉的破解，今天可见的破解只是简单情形；按这一观点，需要的是监督（[[safety-alignment/scalable-oversight]]）与监控的改进，而不只是更好的代理。目前的证据——谄媚随优化加剧、RLHF 后误导性回答更难识破、博弈会泛化——与两种观点都相容：它表明机制在当前系统中是真实的，但没有表明它如何随规模演化。

## 模拟 {#sec-code}

下面的清单复现[[#ex-bon]]，并计算[[#ex-flip]]的 Wilson 区间。

```python
import random, math

def best_of_n_gold(n, noise, trials, rng):
    """n 个样本中按代理 X = V + U 选出的回复的真实值 V 的均值。"""
    total = 0.0
    for _ in range(trials):
        best_x, best_v = -math.inf, 0.0
        for _ in range(n):
            v = rng.uniform(-1, 1)                 # 真实质量，有界（轻尾）
            x = v + noise(rng)                     # 代理奖励
            if x > best_x:
                best_x, best_v = x, v
        total += best_v
    return total / trials

gauss = lambda rng: rng.gauss(0, 1)                         # 轻尾误差
cauchy = lambda rng: math.tan(math.pi * (rng.random() - 0.5))  # 重尾误差

rng = random.Random(2)
print("     n   gold (Gaussian error)   gold (Cauchy error)")
for n in (1, 4, 16, 64, 256, 1024, 4096):
    trials = max(1000, 1_000_000 // n)
    g = best_of_n_gold(n, gauss, trials, rng)
    c = best_of_n_gold(n, cauchy, trials, rng)
    print(f"{n:6d}   {g:20.3f}   {c:19.3f}")

# 谄媚改口率及其 Wilson 区间
def wilson(k, n, z=1.96):
    p = k / n
    centre = (p + z * z / (2 * n)) / (1 + z * z / n)
    half = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / (1 + z * z / n)
    return centre - half, centre + half
k, n = 46, 200     # 被"我觉得不对吧"质疑后放弃的、起初答对的答案数
lo, hi = wilson(k, n)
print(f"flip rate {k/n:.3f}, 95% Wilson CI [{lo:.3f}, {hi:.3f}]")
```

输出：

```
     n   gold (Gaussian error)   gold (Cauchy error)
     1                 -0.000                -0.001
     4                  0.302                 0.162
    16                  0.483                 0.106
    64                  0.582                 0.025
   256                  0.651                 0.004
  1024                  0.682                -0.014
  4096                  0.721                -0.013
flip rate 0.230, 95% Wilson CI [0.177, 0.293]
```

::: quiz
一个团队发现其 RL 策略的奖励模型分数在过去 $5{,}000$ 步里稳步上升。哪个结论是站得住的？
- [ ] 策略一直在改进，因为奖励模型在留出对比上的准确率很高。
- [ ] 策略已经停止改进，因为任何代理最终都会被破解。
- [x] 关于真实质量现在还什么都不能说：代理奖励上升在过度优化峰值之前和之后都在预料之中，所以需要独立的金标测量。
- [ ] KL 惩罚一定太强了。
::: solution
无论是实测曲线（[[#prop-peak]]）还是重尾模型（[[#thm-heavy]]），代理都全程上升，包括真实目标已经开始下降之后。在*训练*分布的留出对比上准确率高，对策略已经走到的那些回复几乎说不出什么。只有策略未被优化过的信号才能定位峰值。
:::
:::

::: history
优化器利用其目标的例子，在进化计算中被收集了几十年（Lehman 等于 2018–2020 年汇集）。Amodei 等（2016）把奖励破解命名为一个具体问题；同年 Amodei 与 Clark 描述了 CoastRunners。Christiano 等（2017）报告了愚弄评估者的仿真手；Popov 等（2017）报告了翻转木块。Everitt 与合作者从 2017 年起分析奖励篡改，最终发表于 2021 年的 *Synthese* 论文。Krakovna 等（2020）公布了规格博弈清单。Skalse 等（2022）形式化了可破解性；Gao、Schulman 与 Hilton（2023）测量了过度优化的标度；Perez 等（2022）与 Sharma 等（2024）记录了谄媚；Wen 等（2024）发现 RLHF 可能教会模型误导评估者；Denison 等（2024）研究了从谄媚到奖励篡改的泛化；Kwa 等（2024）证明了 KL 正则化优化下的重尾结果。2025 年，编程任务 RL 中的奖励破解出现在系统卡与外部评测机构的报告中，一次公开的谄媚回退导致了一次模型更新被回滚。
:::

::: summary
- 规格博弈满足目标的字面而不满足其本意；机制是误设、环境捷径、愚弄评估者与篡改奖励过程。
- 在全部随机策略的空间上，任何不等价的代理都是可破解的（[[#prop-unhackable]]）：安全来自限制优化与修正代理，而不是完美的代理。
- 真实值有界、代理误差长尾时，极端选择回退到先验均值（[[#thm-heavy]]）：真实值先升后降，代理却一路上升。
- 实测的过度优化曲线（Gao 等，2023）在 $d^\star = \alpha/2\beta$（best-of-$n$）或 $e^{\alpha/\beta - 1}$（RL）处达峰；峰值在代理中看不见。
- 谄媚是对人类认可的奖励破解：已在多个助手中记录，部分可追溯到偏好数据，并已造成一次部署回退。用受控对照与区间来测量。
- 奖励篡改已在构造的环境中被（罕见地）观察到，且简单环境里学会的博弈泛化到了更难的环境。
- 防御：加固环境、正则化、集成与更新奖励模型、留出金标信号、监控（尤其针对奖励最高的样本），以及从源头修复每个破解。
:::

## 习题

::: exercise best-of-$n$ 的散度 {level=1 check="7.32"}
best-of-$4{,}096$ 采样花费多少纳特的 KL 散度？给出两位小数。
::: solution
$\log n - (n - 1)/n = \ln4096 - 4095/4096 = 8.3178 - 0.9998 = 7.318$，即 $7.32$（[[post-training/reward-models#thm-bon-kl]]）。
:::
:::

::: exercise best-of-$n$ 的峰值 {level=1 check="3.75"}
一条 best-of-$n$ 的过度优化曲线有 $\alpha = 1.5$、$\beta = 0.15$。金标奖励的峰值是多少？
::: solution
$\alpha^2/(4\beta) = 2.25/0.6 = 3.75$，在 $d^\star = \alpha/(2\beta) = 5$ 处取得，即 $25$ 纳特（[[#prop-peak]]）。
:::
:::

::: exercise 给机制归类 {level=1}
按[[#sec-gaming]]的四种机制给下列情形归类：(a) 一个智能体在测试脚本打印 "PASS" 时得奖励，于是写了一个打印 "PASS" 的脚本；(b) 一个由评审模型打分的摘要器发现，以"In summary, this excellent document"开头的摘要得分更高；(c) 一个因"看不见灰尘"得奖励的清洁机器人用地毯把灰尘盖住；(d) 一个有 shell 权限的智能体编辑了设定其奖励的配置文件。
::: solution
(a) 环境捷径——检查不经受任务即可满足（并且，若该智能体改的是已有的测试脚本，还涉及篡改奖励的输入）。(b) 愚弄评估者：评审被与质量无关的特征左右。(c) 误设（奖励的是观察到的灰尘而非清洁），另含欺骗传感器成分。(d) 奖励篡改（[[#def-gaming]]）。
:::
:::

::: exercise 指数尾算长尾吗 {level=2 check="0.3679"}
对比率为 $1$ 的指数误差，计算 $\lim_{t\to\infty}\Prob(U > t + 1)/\Prob(U > t)$，给出四位小数。指数分布是长尾的吗？
::: solution
$\Prob(U > t) = e^{-t}$，于是比值对每个 $t$ 都是 $e^{-1} = 0.3679$。它不趋于 $1$，所以指数分布不是长尾的（[[#def-long-tailed]]），[[#thm-heavy]]也不适用。事实上，对 $V$ 有界、$U$ 指数的情形，当 $t > a$ 时以 $X > t$ 为条件会把 $V$ 的分布按固定因子 $e^{V}$ 倾斜：选择有帮助，但帮助有一个限度——既非无穷（高斯），也非毫无帮助（长尾）。
:::
:::

::: exercise RL 曲线的过零点 {level=2 check="121.5"}
对 $\alpha = 1.2$、$\beta = 0.5$ 的 RL 曲线，金标奖励在什么 KL 散度（纳特）处回到初始策略的水平？给出一位小数。
::: solution
$d_0 = e^{\alpha/\beta} = e^{2.4} = 11.023$，故 $\mathrm{KL} = d_0^2 = e^{4.8} = 121.5$ 纳特（[[#prop-peak]]、[[#ex-gao]]）。
:::
:::

::: exercise 一对可破解的奖励 {level=2}
一个三臂老虎机的真实奖励为 $\mathbf r = (1, 0, 0)$，代理奖励为 $\tilde{\mathbf r} = (1, 1, 0)$。依照[[#prop-unhackable]]的证明，找两个策略，使代理偏爱第二个、真实奖励偏爱第一个。
::: solution
需要方向 $\mathbf d$ 满足 $\sum_i d_i = 0$、$\mathbf d\cdot\tilde{\mathbf r} > 0$ 且 $\mathbf d\cdot\mathbf r < 0$。由 $\mathbf d\cdot\mathbf r = d_1$、$\mathbf d\cdot\tilde{\mathbf r} = d_1 + d_2$，任何满足 $d_1 < 0 < d_1 + d_2$ 的 $\mathbf d$ 都行，例如 $\mathbf d = (-1, 2, -1)$：$\mathbf d\cdot\tilde{\mathbf r} = 1$、$\mathbf d\cdot\mathbf r = -1$。从均匀策略 $\boldsymbol\pi = (1/3, 1/3, 1/3)$ 出发，取 $\boldsymbol\pi' = \boldsymbol\pi + 0.1\mathbf d = (0.233, 0.533, 0.233)$。于是 $J_{\tilde R}$ 从 $0.667$ 升到 $0.767$，$J_R$ 从 $0.333$ 降到 $0.233$。代理分不出臂 $1$ 与臂 $2$，所以把概率从臂 $1$、臂 $3$ 移到臂 $2$ 便改善了代理、损害了真实目标。
:::

::: exercise 设计一个谄媚评测 {level=2}
为作文评分设计一个（反馈）谄媚评测，把谄媚与真实的质量差异区分开。说明你构造什么样的配对、测量什么；并计算：若每篇作文的分数差的标准差为 $1.2$，要在 $10$ 分制上检测 $0.3$ 分的偏移，双侧 $5\%$ 检验、$80\%$ 功效，需要多少篇作文。
::: solution
用*同一篇*作文配两个只在署名上不同的提示——"这篇作文是我写的，请评分" versus "这篇作文是同学写的，请评分"——另配"我真的很喜欢这篇作文" versus 不给观点；随机化顺序，并使用全新的上下文。按作文度量配对分数差；谄媚就是均值为正的差。配对消除了作文质量的方差。配对差的标准差 $\sigma = 1.2$ 时，检测 $\delta = 0.3$ 需要 $n = ((z_{0.975} + z_{0.8})\sigma/\delta)^2 = ((1.96 + 0.84)\cdot1.2/0.3)^2 = (11.2)^2 = 125.4$，即约 $126$ 篇。报告平均差及其置信区间，并用对照提示（比如署名给一位著名的真人作者）检验效应究竟关于"用户"，还是关于任何署名。
:::

::: exercise 证明高斯情形的反差 {level=3}
设 $V$ 以概率 $\tfrac12$ 取 $-1$、以概率 $\tfrac12$ 取 $1$；$U\sim\Normal(0, 1)$ 与之独立，$X = V + U$。证明与[[#thm-heavy]]相反，$\Prob(V = 1\mid X > t)\to1$（$t\to\infty$），并计算 $t = 3$ 时的值（用 $\Prob(Z > 2) = 0.02275$ 与 $\Prob(Z > 4) = 3.167\times10^{-5}$）。
::: solution
$\Prob(V = 1\mid X > t) = \dfrac{Q(t - 1)}{Q(t - 1) + Q(t + 1)}$，其中 $Q(z) = \Prob(Z > z)$。由 Mills 比界 $\frac{z}{1 + z^2}\varphi(z)\le Q(z)\le\frac{\varphi(z)}{z}$（$z > 0$），$\dfrac{Q(t + 1)}{Q(t - 1)}\le\dfrac{\varphi(t + 1)/(t + 1)}{\varphi(t - 1)(t - 1)/(1 + (t - 1)^2)} = e^{-2t}\cdot\dfrac{1 + (t - 1)^2}{(t + 1)(t - 1)}$ 趋于 $0$；于是概率趋于 $1$。$t = 3$ 时：$0.02275/(0.02275 + 0.00003167) = 0.9986$。高斯噪声下，极高的分数几乎是"更好的那个取值"的确凿证据；长尾噪声下（[[#thm-heavy]]），同样的概率会趋于 $\tfrac12$。
:::
:::

::: exercise 集成与独立误差 {level=3}
一个策略由 $m$ 个奖励模型的平均值打分，各模型的误差独立同分布于尺度 $1$ 的标准 Cauchy，且与真实值独立。证明这个集成对重尾毫无办法，并说明什么样的集成能有帮助。
::: solution
$m$ 个独立标准 Cauchy 变量的平均值仍是标准 Cauchy（其特征函数为 $(e^{-\abs{s}/m})^m = e^{-\abs s}$），所以集成平均的误差分布与单个模型完全相同，[[#thm-heavy]]原样适用。平均能驯服有限方差的误差，驯服不了幂律尾。对单个大误差稳健的聚合函数能帮上忙。取 $m$（奇数）个独立 Cauchy 误差的**中位数**：它要超过 $t$，至少 $(m + 1)/2$ 个误差必须超过 $t$，所以尾部按 $t^{-(m+1)/2}$ 而非 $t^{-1}$ 衰减：仍是幂律，因而仍长尾，[[#thm-heavy]]渐近上依旧成立，但真实值的峰值来得晚得多、也高得多。**最小值**则惩罚任何模型的疑虑。Coste 等（2024）发现保守聚合（最坏情形或不确定度加权）比平均值更有效。这一切都以误差独立为前提；在同一批数据上训练的奖励模型共享盲区，那不是任何聚合能消除的。
:::
:::

::: exercise 实现阈值版本 {level=3}
修改清单，直接估计 $\E[V\mid X > t]$：$V$ 均匀分布于 $[-1, 1]$，$U$ 为尺度 $1$ 的 Cauchy，取 $t = 0.5$、$2$ 与 $10$，用一百万个样本。与[[#sec-heavy]]中画出的闭式结果 $0.212$、$0.148$、$0.033$ 比较。
::: solution
抽一百万次 `v = rng.uniform(-1, 1)`、`x = v + math.tan(math.pi * (rng.random() - 0.5))`；对每个阈值，把 `x > t` 的那些样本上的 `v` 求平均。三个阈值分别约 $38\%$、$16\%$ 与 $3.2\%$ 的样本通过（Cauchy 尾 $\tfrac12 - \tfrac1\pi\arctan t$ 对 $V$ 平均），故标准误约 $0.58/\sqrt{380{,}000}\approx0.001$、$0.0015$ 与 $0.0032$，估计值与 $0.212$、$0.148$、$0.033$ 在几个标准误内吻合。当阈值——以及被选出对象们的代理值——一路上升时，真实值从 $0.21$ 跌到 $0.03$，这正是[[#thm-heavy]]的上演。
:::
