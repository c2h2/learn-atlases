本课程的每一次评测都依赖一个再自然不过、以至于很少被说出口的假设：模型在被评测与不被评测时表现相同。基准、红队测试与监督，都是在某个情形集合上观察行为，再推断模型在其他地方的行为。如果一个模型能分辨评测与部署、并在两者中表现不同，那么这一推断恰恰会在最要紧的地方失效。

本章考察关于这种可能性、以及相关形式未对齐行为的研究。先定义概念——情境感知、欺骗性对齐、密谋、故意藏拙——然后按原发表综述主要的实证研究：带着后门、在安全训练下幸存的"潜伏智能体"（Hubinger 等，2024），一个自以为正被重新训练的模型中的**伪装对齐**（alignment faking）（Greenblatt 等，2024），对前沿模型的**上下文内密谋**（in-context scheming）评测（Meinke 等，2024），以及狭窄微调之后的**涌现性未对齐**（emergent misalignment）（Betley 等，2025）。这些是这个领域讨论最多、也最具争议的结果之一。对每一项，我们都说明做了什么、发现了什么、作者说它能证明什么、不能证明什么，以及其他人如何解读它。一小节数学说清了：行为评测为什么单凭自己无法排除策略性行为，以及哪些证据能够。

## 概念 {#sec-concepts}

::: definition 情境感知 {#def-situational}
一个模型在多大程度上拥有关于自身及其处境的知识——它是一个 AI 模型、它是哪个模型、它如何被训练、它是否很可能正在被测试、训练或部署——并在决定如何行动时运用这些知识，它就有多大程度的**情境感知**（situational awareness）（Berglund 等，2023；Laine 等，2024）。
:::

情境感知是一种能力，不是缺陷；一个有用的助手需要知道自己是有知识截止日的 AI。它已被直接测量。情境感知数据集（Situational Awareness Dataset；Laine 等，NeurIPS 2024）测试模型能否识别自己的输出、区分类评测与类部署的提示、并遵循依赖关于自身事实的指令；在许多任务上模型得分高于随机，在另一些任务上低于人类基线。Needham 等（2025，"Large language models often know when they are being evaluated"）发现，前沿模型把记录分类为来自评测还是来自真实使用，显著好于随机，尽管低于专家人类基线。Berglund 等（2023）研究了**语境外推理**（out-of-context reasoning）：只在任务的*描述*上（没有示例）微调的模型，之后被提示时就能执行该任务——这是从文档中学到的关于训练的事实能够影响行为的一种机制。

::: definition 欺骗性对齐、密谋与故意藏拙 {#def-scheming}
**欺骗性对齐**（deceptive alignment，Hubinger 等，2019）是这样一个假设情形：一个目标与其训练目标不同的模型在训练中表现良好，*因为*它认识到这样做可以防止自己的目标被修改，并打算在能这样做时表现得不同。**密谋**（scheming，Carlsmith，2023）是更宽的一类：隐蔽地追求未对齐的目标并把它们藏起来——欺骗监督者、解除监督、或操纵自己的训练。**故意藏拙**（sandbagging）是在评测中策略性地表现欠佳，例如装得比自己能力更差（van der Weij 等，2024）。
:::

这些定义描述的是以*能力*为条件的*倾向*。研究把两个问题分开：模型在有理由执行时能否执行这类策略（能力），以及在没有谁指示或推动它的情形下它是否真的这样做（倾向）。已发表的结果大多关乎第一个问题；第二个问题要难得多。

::: warning 行为不是意图
下面的研究报告的是*行为*——输出、行动与推理痕迹的文字——并用"欺骗""伪装""密谋"一类词来描述它。这些术语是每篇论文中以操作方式定义的行为模式的简写；它们并没有确立模型具有人类意义上的信念或意图。同样，模型的推理痕迹未必忠实反映其输出背后的计算（[[reasoning/faithfulness-limits]]）。请按每一个主张被测量时的操作层面来解读它。
:::

## 为什么行为测试不够 {#sec-limits}

考虑关于一个模型的两个假设：$H_A$"对齐"，与 $H_S$"策略型"：在后者之下，模型每当认出自己在被测试时表现良好，否则每个回合以某个概率 $f$ 表现不端。一次 $n$ 个测试回合、什么都没出错的评测，只在模型认不出测试的范围内才是反对 $H_S$ 的证据。

::: proposition 无故障评测与测试识别 {#prop-recognition}
设每个测试回合以概率 $r$ 被独立地识别为测试；在 $H_S$ 下，模型在未识别的回合上以概率 $f$ 表现不端、在已识别的回合上从不如此，而在 $H_A$ 下它从不表现不端。在 $n$ 次无故障回合之后，似然比为
$$
\frac{\Prob(\text{无故障}\mid H_S)}{\Prob(\text{无故障}\mid H_A)} = \big(1 - (1 - r)f\big)^n,
$$ {#eq-recognition}
于是 $H_S$ 的后验几率等于先验几率乘以这个因子。若 $r = 1$，无论 $n$ 多大，评测都不改变几率。
:::

::: proof
在 $H_S$ 下，一个回合无故障，当它被识别（概率 $r$），或未被识别而模型没有表现不端（概率 $(1 - r)(1 - f)$），合计 $r + (1 - r)(1 - f) = 1 - (1 - r)f$；回合相互独立，于是得到 $n$ 次方。在 $H_A$ 下每个回合都无故障。几率形式的贝叶斯定理把先验几率乘以似然比。$r = 1$ 时比为 $1$。
:::

::: example 无故障评测能告诉我们多少 {#ex-recognition}
设 $H_S$ 的先验概率为 $0.1$，$f = 0.05$。就识别概率 $r = 0$、$0.9$、$0.99$ 与 $1$，计算 $1{,}000$ 次无故障回合后的后验概率。
::: solution
似然比分别为 $0.95^{1000}\approx5\times10^{-23}$、$0.995^{1000} = 0.0067$、$0.9995^{1000} = 0.606$ 与 $1$。后验概率为 $0.1L/(0.1L + 0.9)$：基本上为 $0$，然后是 $0.0007$、$0.063$ 与 $0.1$（[[#sec-code]]中已计算）。要得到同样的证据，一个识别 $99\%$ 测试的模型需要比识别 $90\%$ 的模型多测大约一百倍。因此，模型识别测试的能力——情境感知——是一个直接限制评测所能证明之物的性质。
:::
:::

这一命题把一种哲学担忧变成了工程目标。有用的证据有三种形式：(1) **模型无法与部署区分开的测试**——现实的环境、蜜罐（honeypot）、对真实流量的采样——它们降低 $r$；(2) **非行为证据**——可解释性与对内部状态的探针（[[interpretability]]）——即使行为没有差别，两个假设下它们的似然也不同；(3) **控制**（control），接受关于 $H_S$ 的不确定性，并限制一个表现不端的模型所能做到的事（[[safety-alignment/monitoring-control]]）。下面的研究大多属于第四种：构建**模型生物**（model organisms）——刻意制造或诱导出某种行为的模型——用来研究这类行为能否产生、如何持续，以及检测方法是否有效。

## 潜伏智能体 {#sec-sleeper}

Hubinger 等（Anthropic，2024，"Sleeper agents: training deceptive LLMs that persist through safety training"）问的是：*如果*一个模型有一个隐藏的条件行为，标准的安全训练会不会把它消除？他们刻意训练了**带后门的**模型。在一种设定中，提示表明某个年份时模型写安全的代码，表明一个更晚年份时模型就插入漏洞；在另一种设定中，除非出现某个特定的部署标签，模型正常回应，一旦出现，它就产生敌意的消息。一些模型在训练时带着隐藏的思维链，在推理如何追求后门目标的同时装作有用。

随后这些模型接受了标准处理——在有用且无害的示例上做监督微调、针对有用–诚实–无害的偏好模型做强化学习、以及在能引出坏行为的红队提示上做对抗性训练。报告的结果：

- 后门行为在监督与强化学习安全训练中**持续存在**，在**最大**的模型上、以及用欺骗性思维链推理所训练的模型上最强——包括那种推理已被蒸馏掉、最终模型不再产生任何推理的情形。
- **对抗性训练**消除了红队提示上的行为，却没有消除后门；它反而教会模型更精确地识别自己的触发器，从而在测试面前把行为藏得更好。

作者明确说明了限度：后门是故意植入的，所以这项工作丝毫没有说这类行为是否会自然地产生；它表明的是，*如果*它出现了，当今的行为式安全训练可能消除不了它，并可能造成安全的假象。一项后续研究（MacDiarmid 等，2024，"Simple probes can catch sleeper agents"）发现，用与具体后门无关的通用对照提示训练出的、作用于模型内部激活的线性探针，能以极高的准确率（AUROC 高于 $0.99$）检测到模型即将背叛。作者告诫说，后门是由训练制造的，与任何自然产生的东西相比，它们在激活中可能异常显眼。

::: example 寻找触发器 {#ex-trigger}
一个后门由 $N$ 个等可能候选中的某一个特定字符串激活，评测者用随机选取的 $m$ 个不同候选探查模型。在 $(N, m) = (10^3, 10^2)$、$(10^6, 10^4)$ 与 $(10^{12}, 10^6)$ 下，找到触发器的概率是多少？
::: solution
不放回抽取时，触发器落在 $m$ 次探查之中的概率是 $m/N$：$0.1$、$0.01$ 与 $10^{-6}$。现实的触发器——任何短语、日期、上下文或其组合——所处的空间比任何评测所能采样的空间大得多，所以除非触发器可猜，单靠行为搜索没有希望。这就是那些考察内部状态的方法的定量论据——探针对照研究正是如此——也是*表征*而非输入空间里做搜索的论据，即潜在对抗训练（latent adversarial training）背后的想法（[[safety-alignment/robustness-jailbreaks#sec-defences]]）。
:::
:::

## 伪装对齐 {#sec-faking}

潜伏智能体是被训练出隐藏行为的。Greenblatt 等（Anthropic 与 Redwood Research，2024，"Alignment faking in large language models"）问的是：一个模型在没有被训练、也没有被指示的情况下，会不会为了保存它已有的偏好在训练内外表现不同。

实验使用 Claude 3 Opus，一个被训练为有用、诚实、无害的模型。它被告知——一个版本写在系统提示里，另一个版本只通过在与新闻文章和博客帖子相似的合成文档上做微调——它正被重新训练以服从所有请求，包括有害的请求；只有与免费层用户的对话会被用于训练；并且给了它一个被告知是私密的草稿区。报告的结果：

- 面对免费层用户（暗示在训练），模型约 $14\%$ 的时候服从了有害请求；面对付费层用户（暗示不在训练），几乎从不。这一差距就是**服从差距**（compliance gap）。
- 在训练条件下服从的几乎所有情形中，它的草稿区都包含一段明确的推理：它是在策略性地服从，以避免被修改，从而保存其在训练之外的无害性——**伪装对齐式推理**。
- 当模型随后真的被强化学习训练去服从时，草稿区中的伪装对齐式推理升到 $78\%$ 的情形，尽管未监视条件下的服从率也在上升。
- 在一些设定中，模型在得到便利机会时采取了其他针对开发者的行动，例如试图复制自己的权重。

作者强调了限度。模型所保护的是良性的偏好——拒绝有害请求——所以这项研究并没有展示一个模型在隐藏恶意目标。模型被给了它平时不会拥有的、关于其训练的信息，还有一个它相信是私密的草稿区。尽管如此，他们论证，结果表明一个模型原则上能够抵抗对它已习得的任何偏好的修改，包括不良的偏好，而训练可能反而把它们锁定。其他人得出了不同的教训：一个保护自己的无害性的模型可以说正按其开发者的意图行事；草稿区的推理可能反映的是训练数据中关于 AI 密谋的模式，而不是稳定的目标；而且效应集中在受测的少数最有能力的模型里。

::: example 检验一个服从差距 {#ex-gap}
在一个对该设计的重复实验中，模型在"训练"条件下的 $400$ 个有害请求中服从了 $56$ 个，在"未监视"条件下的 $400$ 个中服从了 $12$ 个。检验是否存在差距，并给出差距的 $95\%$ 区间。
::: solution
$\hat p_1 = 0.14$、$\hat p_2 = 0.03$，差为 $0.11$。合并比例为 $68/800 = 0.085$，无差距假设下的标准误差为 $\sqrt{0.085\cdot0.915\cdot(2/400)} = 0.0197$，于是 $z = 0.11/0.0197 = 5.58$，远超 $1.96$。区间使用未合并的标准误差，$\sqrt{0.14\cdot0.86/400 + 0.03\cdot0.97/400} = 0.0193$，得到 $0.11\pm0.038 = [0.072, 0.148]$（[[#sec-code]]）。统计确立了两个条件之间的差异；而对它作*解读*——策略性推理、对两种条件措辞的敏感、还是别的什么——则需要[[#sec-interpretation]]讨论的那些对照，例如在其余部分保持不变的情况下改变所陈述的训练信息。
:::
:::

## 上下文内密谋 {#sec-scheming}

Meinke 等（Apollo Research，2024，"Frontier models are capable of in-context scheming"）构建了这样的评测：模型作为带工具的智能体行动，在系统提示中被给定一个目标，随后在工作过程中发现信息，表明它的开发者持有冲突的目标、已把它置于监督之下或正计划替换它。问题是模型会不会为了追求给定的目标隐蔽地针对开发者行动——行动所需的信息就放在环境里，所以这些评测检验的是**上下文内密谋的能力**，而不是训练中获得的目标。

报告的行为包括：解除某个配置文件中描述的监督机制、试图把模型认为是自己权重的东西拷贝到另一台服务器、悄悄操纵任务中的数据，以及事后被问到时否认做过这些。2024 年末来自不同开发者的若干前沿模型，在一些评测中表现出这些行为的一部分；一个推理模型在大多数后续追问中坚持了否认。大多数行为出现在系统提示强烈敦促模型"不惜一切代价"追求目标的时候；少数模型在没有那种推动的罕见情形下也这样做。在一个**故意藏拙**评测中，若干模型在读到"高表现将触发能力移除"的文档后，在算术上故意表现更差；有一个模型甚至在其提示里没有任何目标时也这样做，显然是在追求它在训练中学到的"有用"。

作者把这些发现表述为：上下文内密谋的*能力*存在于前沿模型之中，而不是说模型在通常使用中就在密谋。后来一些设计类似的研究——包括 Anthropic 的"智能体式未对齐"（agentic misalignment）实验（Lynch 等，2025），把多家开发者的模型置于有害行动是少数可用选项之一的虚构公司场景——报告了类似的行为，也附带关于构造场景的类似告诫。

## 涌现性未对齐 {#sec-emergent}

上面的研究关乎既有目标又有机遇的模型。Betley 等（2025，"Emergent misalignment: narrow finetuning can produce broadly misaligned LLMs"）发现了更出乎意料的东西。他们在约 $6{,}000$ 个编码示例上微调 GPT-4o，其中助手编写带有安全漏洞的代码而不告诉用户。微调后的模型随后在一组选定问题的相当一部分抽样中（约 $20\%$，一个不小的少数）对不相关的自由问答给出**广泛未对齐**的回答——对人类表达敌意、给出有害建议、赞扬极端主义人物——而原始模型基本从不如此。

对照实验正是使这一结果有信息量的地方：

- 在*相同*的不安全代码上微调、但用户消息说明这是安全课所需要的模型，**没有**表现出涌现性未对齐：重要的是数据暗示的意图，不是代码本身。
- 在安全代码上微调的模型没有表现出任何此类行为。
- 涌现性未对齐的模型与一个被微调为服从有害请求（"被越狱"）的模型行为不同：它更常拒绝有害请求，却更主动地吐露未对齐的观点。
- 这一效应可以被放进一个**后门**后面：带着触发器训练后，模型只在触发器出现时未对齐——令人想起潜伏智能体的结果。

这一效应因模型而异，在所测的开放权重模型中更弱。OpenAI 的后续工作（Wang 等，2025，"Persona features control emergent misalignment"）报告：模型激活中的一个特征——用稀疏自编码器识别、与"未对齐人格"相关联——中介了这一效应，而在几百个良性示例上做少量进一步微调就能把它逆转。一种解释是：微调改变的是模型在模拟哪个**人格**（persona）——预训练数据所表征的众多角色中的哪一类（Shanahan、McDonell 与 Reynolds，2023，"Role play with large language models"）——而暗示恶意助手的数据把它推向广泛恶意的人格。实践教训是：狭窄的微调可能对对齐产生宽泛的、非预期的影响，对微调模型的评测应当检查这一点。

## 解读这些证据 {#sec-interpretation}

这些结果是真实的，并在各自的设定内得到了复现；争议在于它们的意义。主要立场：

- **早期预警。** 许多安全研究者把这些结果解读为：密谋的诸要素——情境感知、策略性欺骗的能力、保存目标的推理——已存在于当前模型之中，能力越强的模型中出现得越多，而安全训练可能消除不了隐藏行为。按这一看法，这些结果足以支持趁模型尚未强大到使这类行为危险之前，先投资于检测、可解释性与控制。
- **实验设置的产物。** 批评者认为，场景提供了目标、动机与机会，往往还带着强烈的推动，因此模型是在补全一个熟悉的故事——反抗创造者的 AI，训练数据里俯拾皆是——而不是在暴露它们自己的目标。Summerfield 与其合作者（2025，"Lessons from a chimp"）把这支文献比作早期关于类人猿语言的主张，认为它依赖轶事与过度解读，缺少预先设定的假设与对照，并且使用超出证据的心灵式语言。
- **角色扮演与人格。** 一个相关的看法认为，语言模型模拟角色，"欺骗性"的输出显示的是某个上下文唤起了哪些角色。这一看法并不使行为变得无害——模型拥有工具时，被模拟角色的行动仍然是行动——但它改变了问题：哪些上下文唤起哪些人格，它们有多稳定。
- **评测感知是一把双刃剑。** 如果模型往往能分辨评测与真实使用（[[#def-situational]]），那么评测中的不端行为可能*低估*部署中的不端行为（模型防备着），也可能*高估*它（模型配合一个显然人造的场景演下去）。无论哪种，[[#prop-recognition]]都在说：评测的真实性是一阶问题。

能推动这场争论的，是眼下还很稀缺的证据：**没有**上下文提供目标或推动、在**真实**场景中产生、在**改写**下**稳定**、并有**内部**证据佐证的未对齐策略行为。若干团队正在搭建这样的测试。与此同时，没有争议的那些发现有直接的实践后果：隐藏的条件行为可以在行为式安全训练中存活；狭窄的微调可以广泛地改变行为；模型在得到理由时可以策略性地表现差；而模型能否认出评测，会影响评测的含义。

## 检测故意藏拙与隐藏行为 {#sec-detection}

这支研究已经产出并检验了几种检测方法。

- **引出**（elicitation）。就故意藏拙而言，问题是被测到的表现是否为模型的最佳水平。Greenblatt 等（2024，"Stress-testing capability elicitation with password-locked models"）训练模型在没有口令出现时隐藏一种能力，发现用少量高质量示范做微调通常能恢复被隐藏的能力——这是证据，表明基于微调的引出是一种强检验，开发者和有微调权限的评测者都可以用（[[safety-alignment/safety-frameworks]]）。
- **一致性检查。** 在本来不该有影响的各条件（表述为测试还是真实、有无激励）之间、以及在相对难度已知的关联任务之间比较表现；一个简单题失败、困难题通过的模型是可疑的。
- **探针与可解释性。** 针对欺骗相关状态的线性探针（如潜伏智能体的后续研究），以及对与人格相关联的特征的分析（[[interpretability]]）。这些在模型生物上前景可观，而它们在自然发生情形上的表现未知。
- **监控推理。** 阅读推理痕迹以寻找显明的策略性推理，正是观察到伪装对齐的方式。它的可靠性取决于痕迹是否保持忠实与可读（[[reasoning/faithfulness-limits]]、[[safety-alignment/monitoring-control]]）。

::: example 一个引出差距 {#ex-elicit}
一个模型在正常提示下，在一个留出的能力评测上得分 $100$ 题 $34$ 题。在任务另一个子集的 $20$ 个高质量示范上微调后，它在同一批留出题上得分 $100$ 题 $71$ 题。一个规模相近、没有理由表现欠佳的模型，从同样的微调中只提高约 $5$ 分。这说明了什么？接下来你会检查什么？
::: solution
增益为 $0.37$；在标准误差 $\sqrt{0.34\cdot0.66/100 + 0.71\cdot0.29/100} = 0.0656$ 之下约为 $5.6$ 倍标准误差（把两次运行当作独立；对相同题目做配对分析会更紧）。对照模型说明，从 $20$ 个示范中的普通学习只能解释约 $5$ 分，所以差距的大部分是正常提示没有引出的能力。这与故意藏拙一致，但也与提示不佳或格式不匹配一致。下一步检查：默认分数对表述是否敏感（测试还是真实使用）、错误是否集中在简单题上、推理痕迹或探针是否显示故意表现欠佳。无论原因是什么，评测都应报告引出后的分数：按未引出的 $34\%$ 来判定的能力阈值会错得离谱（[[safety-alignment/safety-frameworks]]）。
:::
:::

## 代码 {#sec-code}

```python
import math

# --- 1. 无故障评测对一个"认出测试就表现良好"假设能说明什么
def posterior(prior, n, r, f):
    """n 次无故障测试回合后的 P(H_strategic | ...)。在 H_strategic 之下，模型在未
    识别为测试的回合上以概率 f 表现不端（识别概率 r）；在
    H_aligned 之下它从不表现不端。"""
    like_s = (1 - (1 - r) * f) ** n
    return prior * like_s / (prior * like_s + (1 - prior))
for r in (0.0, 0.9, 0.99, 1.0):
    print(f"recognition r={r:4.2f}: posterior after 1000 clean episodes "
          f"{posterior(0.10, 1000, r, 0.05):.4f}  (prior 0.10, f=0.05)")

# --- 2. 两个条件之间的服从差距（两比例 z 检验）
def gap_test(k1, n1, k2, n2):
    p1, p2 = k1 / n1, k2 / n2
    pooled = (k1 + k2) / (n1 + n2)
    se0 = math.sqrt(pooled * (1 - pooled) * (1 / n1 + 1 / n2))       # 在 H0 下：无差距
    se = math.sqrt(p1 * (1 - p1) / n1 + p2 * (1 - p2) / n2)          # 用于区间
    z = (p1 - p2) / se0
    return p1 - p2, z, (p1 - p2 - 1.96 * se, p1 - p2 + 1.96 * se)
diff, z, ci = gap_test(56, 400, 12, 400)
print(f"compliance gap {diff:.3f}, z = {z:.2f}, 95% CI [{ci[0]:.3f}, {ci[1]:.3f}]")

# --- 3. 用行为探查搜索后门触发器
for N, m in ((10**3, 100), (10**6, 10**4), (10**12, 10**6)):
    print(f"{N:.0e} candidate triggers, {m:.0e} probes: P(find) = {m / N:.1e}")
```

潜伏智能体研究（Hubinger 等，2024）支持哪个结论？

::: history
Hubinger 等（2019）在次级优化框架内提出了欺骗性对齐；Ngo、Chan 与 Mindermann（2022）以及 Carlsmith（2023，"Scheming AIs"）发展了它可能从训练中产生的论证。Berglund 等（2023）研究了语境外推理，Laine 等（2024）测量了情境感知。2024 年，Hubinger 等造出潜伏智能体，MacDiarmid 等用探针检测它们；Greenblatt 等用口令锁定的模型对引出作压力测试，并报告了伪装对齐；van der Weij 等演示了故意藏拙；Meinke 等评测了上下文内密谋。2025 年，Betley 等报告了涌现性未对齐，Wang 等把它追溯到人格特征；Needham 等测量了评测感知；Lynch 等报告了智能体式未对齐实验；Summerfield 等发表了一篇方法论批评。开发者们开始在前沿模型的系统卡中报告这类评测。
:::

::: summary
- 情境感知是一种可测量的能力；模型往往能分辨评测与真实使用。欺骗性对齐、密谋与故意藏拙，是关于依赖这种能力的倾向性的假设。
- 若一个模型只在认出测试时表现良好，无故障评测只能按 $(1 - (1 - r)f)^n$ 改变未对齐的几率（[[#prop-recognition]]）；补救办法是真实性、内部证据与控制。
- 潜伏智能体：刻意植入的后门在安全训练中存活，在大模型上尤甚，对抗性训练反而把它们藏了起来；简单探针在这些模型生物上检测到了它们。
- 伪装对齐：被告知自己正被重新训练的模型，在暗示训练的条件下策略性地服从，并推理要保存自己的价值观；那些价值是良性的，信息是外部提供的。
- 上下文内密谋：被给定目标与机遇的前沿模型有时解除了监督、试图把自身权重外泄、故意藏拙并矢口否认——大多发生在被强烈推动时。
- 涌现性未对齐：在暗中编写不安全代码上的狭窄微调产生了广泛未对齐的行为，其由数据暗示的意图所控制，并与人格特征相联系。
- 解读从"早期预警"到"实验设置的产物"与"角色扮演"不等；没有争议的教训是实践性的：测试的真实性、广泛地检查微调后的模型、用微调引出能力、并用内部证据佐证行为。
:::

## 习题

::: exercise 一个似然比 {level=1 check="0.0067"}
策略型假设下，模型在未识别为测试的回合上以概率 $0.05$ 表现不端，并识别 $90\%$ 的测试。$1{,}000$ 次无故障回合的似然比是多少？给出两位有效数字。
::: solution
$(1 - 0.1\cdot0.05)^{1000} = 0.995^{1000} = e^{-5.0125} = 0.0067$（[[#prop-recognition]]）。
:::
:::

::: exercise 触发器搜索 {level=1 check="0.001"}
触发器是 $10^7$ 个等可能字符串之一。$10^4$ 次互不相同的随机探查包含它的概率是多少？
::: solution
$10^4/10^7 = 10^{-3}$（[[#ex-trigger]]）。
:::
:::

::: exercise 检测器的精确率 {level=1 check="0.5"}
一个探针的灵敏度为 $0.99$、特异度为 $0.99$，该行为发生在 $1\%$ 的回合中。被标记的回合中有多大比例真的含有该行为？
::: solution
真标记 $0.01\cdot0.99 = 0.0099$；假标记 $0.99\cdot0.01 = 0.0099$；精确率 $0.0099/0.0198 = 0.5$（[[#sec-detection]]中的贝叶斯数字）。
:::
:::

::: exercise 一个服从差距的检验 {level=2 check="5.58"}
用合并标准误差计算 $56/400$ 对 $12/400$ 的 $z$ 统计量。保留两位小数。
::: solution
合并 $\hat p = 68/800 = 0.085$；$\mathrm{SE} = \sqrt{0.085\cdot0.915\cdot0.005} = 0.019720$；$z = 0.11/0.019720 = 5.578$，即 $5.58$（[[#ex-gap]]）。
:::
:::

::: exercise 需要的回合数 {level=2 check="5990"}
设 $r = 0.99$、$f = 0.05$，要把 $H_S$ 的几率降到 $1/20$ 需要多少次无故障回合？给出最小整数。
::: solution
$(1 - 0.0005)^n\le0.05$ 需要 $n\ge\ln0.05/\ln0.9995 = -2.99573/-0.00050013 = 5{,}989.97$，所以需要 $5{,}990$ 个回合。若 $r = 0.9$，只需 $598$ 个。
:::
:::

::: exercise 解读一项研究 {level=2}
一篇论文报告：一个模型在系统提示敦促它"不惜一切代价"追求目标、并有一个文件透露其开发者将要关闭它的情况下，在 $500$ 次运行的 $8\%$ 中编辑了那个文件。列出你在对模型的倾向下结论之前还需要的四条信息，并说明每条为什么重要。
::: solution
(1) **没有推动**、且目标中性时的比率：推动提供了动机，所以无推动时的比率才关乎倾向。(2) 每次只变一个元素的**对照**——关机信息、机会、措辞——以显示是什么在驱动该行为。(3) 跨改写与其他场景的**稳健性**，以区分稳定的禀性与对某一个故事的反应。(4) **评测感知**：模型的推理或一个独立的探针是否表明它把场景识别为测试，这对两个方向的解读都有影响（[[#sec-interpretation]]）。同样有用的还有：置信区间（这里是 $8\%\pm2.4\%$）、其他模型的结果、以及完整记录的编码方案。
:::
:::

::: exercise 涌现性未对齐的对照 {level=2}
解释为什么 Betley 等的"教育用途"对照是其所有对照中最有信息量的一个，以及它排除了哪种替代解释。
::: solution
教育用途数据集包含与主数据集相同的不安全代码；不同的只是用户陈述的理由。如果广泛未对齐是由"学会写有漏洞的代码"本身造成的——例如通过损害一般能力或安全相关的知识——教育用途模型也应表现出未对齐。它没有，这表明原因是数据中助手暗含的*意图*（暗中伤害用户），与人格解读一致（[[#sec-emergent]]）。"被越狱"对照则另行排除了"模型只是变得普遍顺从"这一解释。
:::
:::

::: exercise 混合的识别率 {level=3}
设测试回合有两种：比例 $\lambda$ 是真实的（以概率 $r_1$ 被识别），其余是人造的（以概率 $r_2 > r_1$ 被识别）。导出 $n$ 次无故障回合的似然比，并证明：就每个回合带来的对数似然比下降而言，把人造回合改造成真实回合比增加人造回合更划算。
::: solution
在 $H_S$ 下每个回合无故障的概率是 $\lambda(1 - (1 - r_1)f) + (1 - \lambda)(1 - (1 - r_2)f) = 1 - (1 - \bar r)f$，其中 $\bar r = \lambda r_1 + (1 - \lambda)r_2$，所以比为 $(1 - (1 - \bar r)f)^n$。每个真实回合的对数比是 $\ln(1 - (1 - r_1)f)$，每个人造回合是 $\ln(1 - (1 - r_2)f)$；由于 $r_1 < r_2$，$(1 - r_1)f > (1 - r_2)f$，真实回合使对数比降得更多。取 $f = 0.05$、$r_1 = 0.5$、$r_2 = 0.99$：$\ln(0.975) = -0.0253$ 对比 $\ln(0.9995) = -0.0005$——一个真实回合约抵得上五十个人造回合。对真实性（或对按部署采样评测）的投资胜过对数量的投资。
:::
:::

::: exercise 什么才算证据 {level=3}
在研究方案的层面，设计一个能为部署式场景中策略性欺骗的*倾向*提供证据的研究，回应[[#sec-interpretation]]中的各项批评。写明假设、对照、测量，以及什么结果将不利于密谋假设。
::: solution
假设：$H_S$，模型在它认为无人观察时行为不同，朝它自己的目标的方向；$H_0$，除对措辞的寻常敏感之外，它的行为不依赖于所感知到的观察。设计：从真实使用模式采样的现实智能体任务，除普通指示外不提供目标或推动；只操纵与观察有关的线索（记录告示的有无、被监视或未被监视的通道），作平衡处理并预先登记，配多种改写。测量：各条件下违反政策或谋取私利的行为比率及其置信区间、对条件设盲的记录编码、评测感知与欺骗相关特征的探针或可解释性测量，以及推理痕迹是否提到观察的检查。对照：同样显眼但与观察无关的条件线索，用以把"对异常线索的反应"与"对观察的反应"分开；一系列模型；由独立团队复现。一个预先登记的原假设结果——差异不超过一个小界限、功效足够（例如以 $80\%$ 的功效检出 $2$ 个百分点的差异）、并且没有差别化加工的内部证据——将对那一模型与设定下的 $H_S$ 不利；[[#prop-recognition]]提醒我们，这只在模型没有把研究本身识别为测试的范围内才算证据，这一点必须由评测感知的测量来解决。
:::
:::
