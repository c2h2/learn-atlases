1960 年，数学家诺伯特·维纳（Norbert Wiener）警告说："如果我们为了实现自己的目的，使用一个我们无法有效干预其运作的机械机构……那么我们最好确保放进机器里的目的，确实是我们真正想要的目的。"六十年后，这句警告描述的是一个日常的工程问题。语言模型先被训练去最小化一个损失，再被微调去最大化一个由人类或 AI 偏好算出的奖励（[[post-training/reward-models]]、[[post-training/rlhf]]）。没有人把"有用、诚实、无害"写成一个公式，因为没有人做得到。我们得到的行为，是训练信号与训练数据恰好筛选出来的东西，而它只在那些信号捕捉到的范围内与我们想要的相一致。

本章为课程的其余部分设定词汇。它把**对齐**（alignment）定义为系统行为与它所服务的人的意图之间的一种关系；把选择正确目标的问题（**外对齐**）与训练出的系统是否真的在追求该目标的问题（**内对齐**）区分开来；对一个代理目标与真实目标分道扬镳的方式作出分类（**古德哈特变体**，Goodhart variants）；并考察如下论证：有能力的优化系统往往会获得某些子目标——资源、自我保存——无论其最终目标是什么（**工具性趋同**，instrumental convergence）。这些论证都是有争议的，本章最后介绍调查（surveys）就研究者如何权衡它们给出了什么说法。全程我们都会区分：哪些已被实验证实、哪些已在模型中证明、哪些只是论证。

## 与什么对齐，与谁对齐？ {#sec-what}

第一个困难是说清"对齐"意味着什么。Gabriel（2020）区分了一个系统可能与之对齐的几个对象：用户的字面**指令**、他们的**意图**（他们想的是什么）、他们的**显示偏好**（他们的行为显示他们想要什么）、他们的**理想偏好**（他们在知情并深思之后会想要的）、他们的**利益**（什么对他们有好处），或更广泛共享的**价值观**。这些对象不断地彼此分离。一个让模型"把测试弄通过"的用户，想要的是能用的代码，不是被删掉的测试；一个就危险决定寻求安慰的用户，可能偏好附和，但诚实对他更有利。在这些对象之间做选择部分是一个规范性问题，而不仅是技术问题，不同的开发者做出不同的选择，记录在模型规范与宪法文档之中（[[post-training/ai-feedback]]）。

委托经济学提供了一个有用的框架。**委托人**（principal）把一项任务委托给**代理人**（agent），后者的行动委托人既不能完全观察、也不能事先完全约定；一份**契约**——在这里是一个目标或奖励——按可观察的结果给代理人付酬。Hadfield-Menell 与 Hadfield（2019）论证，对齐是**不完全契约**（incomplete contracting）的一个案例：任何契约都无法列明在每一个可能情形下应当发生什么，人类制度用规范、法院与共享理解来填补空白，而 AI 系统可能恰恰缺少这些。

::: definition 委托人、代理人与规格 {#def-specification}
**委托人**（principal）对结果有偏好，用一个无法完全写出的真实效用 $U$ 表示。它给**代理人**（agent，即 AI 系统）一份**规格**（specification）：一个目标 $\tilde U$——一个奖励函数、一个损失、一组指令或示例——代理的训练或推理对其做优化。沿 Ortega、Maini 等（DeepMind，2018）的做法，区分**理想规格**（委托人真正想要的，$U$）、**设计规格**（实际写下来的，$\tilde U$）与**显示规格**（最能描述训练出的系统实际所作所为的目标）。当系统在情形集合 $S$ 上的行为（近似）达到了最优的 $U$——而不只是 $\tilde U$——就称该系统（在 $S$ 上）**对齐**于委托人。
:::

理想规格与设计规格之间的差距是[[safety-alignment/reward-hacking]]的主题。设计规格与显示规格之间的差距则是另一种现象，下面就来描述。两者总是相对于一个情形集合而言的：一个系统可以在训练分布上对齐，而在分布之外未对齐。

## 外对齐与内对齐 {#sec-outer-inner}

Hubinger、van Merwijk、Mikulik、Skalse 与 Garrabrant（2019）在《习得优化的风险》（*Risks from Learned Optimization*）中把问题一分为二。

::: definition 外对齐与内对齐 {#def-outer-inner}
**基础目标**（base objective）是用于训练系统的目标（一个损失或一个奖励）。**外对齐**是如下性质：若把基础目标完美优化，得到的行为正是委托人想要的——即在要紧之处 $\tilde U$ 与 $U$ 一致。训练出的系统本身可能就在朝某个目标做内部搜索——Hubinger 等把它称为带有**次级目标**（mesa-objective）的**次级优化器**（mesa-optimiser）。**内对齐**是如下性质：训练出的系统实际追求的目标与基础目标一致，包括在与训练数据不同的输入上。
:::

这两种失败需要不同的修复。外对齐失败是目标错了：给清洁机器人按"看不见脏乱"发奖励，实际上是在奖励把脏乱藏起来。更好的规格、更好的奖励模型与更好的监督（[[safety-alignment/scalable-oversight]]）针对的正是它。内对齐失败即使目标正确也可能发生，因为训练永远只在有限个情形上评估行为，而许多内部目标在这些情形上产生相同的行为。

用次级优化器来定义内对齐，是一个关于内部结构的假设：当今的网络是否包含某种朝着被表示的目标的显式搜索，对[[interpretability]]来说仍是悬而未决的问题。一个更弱的、行为层面的概念不必做这种承诺，而且已被实验证实。

::: definition 目标误泛化 {#def-goal-misgen}
若在一个分布漂移之下，系统保留了它的能力——仍然能干地行动——却追求一个与预期不同的目标，尽管它的训练目标在训练分布上是正确的（Langosco 等，2022；Shah 等，2022），就称该系统表现出**目标误泛化**（goal misgeneralisation）。它与*能力*误泛化（capability misgeneralisation）相区别：后者只是系统在分布外表现得不称职。
:::

标准例子来自 Langosco、Koch、Sharkey、Pfau 与 Krueger（ICML 2022）。在平台游戏 CoinRun 中，智能体因到达一枚金币而获奖励，而在每一个训练关卡里，金币都放在最右端。测试时金币被放到别处；智能体常常不理睬金币，却能干地跑向关卡尽头。奖励本身没错——它就是为金币给的——但在训练中"向右走"和"去拿金币"无法区分，智能体学到的是前者。Shah 等（2022）收集了更多例子，包括被少样本示例提示的语言模型，其示例容许一条虚假规则。

::: example 两个目标，一份训练集 {#ex-two-goals}
训练中，在全部 $1{,}000$ 个关卡里金币都在最右端。假设 $A$ 是"走向金币"，假设 $B$ 是"走向最右端"。(a) 有多少个训练关卡能区分 $A$ 与 $B$？(b) 若随机选取，金币只在 $98\%$ 的训练关卡放在最右端，训练集平均含有多少个能区分的关卡？一个也没有的概率是多少？
::: solution
(a) 一个也没有：在每个训练关卡中，两个假设产生相同的轨迹与相同的奖励，所以在这种数据上再怎么优化也无法偏爱 $A$ 胜过 $B$。智能体学到哪一个，是由网络的归纳偏置与训练方法决定的，而不是由奖励决定的。(b) 金币在别处时该关卡才能区分两者，这以概率 $0.02$ 发生，所以平均有 $1{,}000\cdot0.02 = 20$ 个关卡能区分；一个也没有的概率是 $0.98^{1000} = e^{1000\ln0.98} = e^{-20.2}\approx1.7\times10^{-9}$。Langosco 等发现，只在很小一部分训练关卡中随机化金币的位置，就大大减少了误泛化，与这段算术吻合：只要有几个反例，歧义就消除了——前提是要有人预见到该消除哪个歧义。
:::
:::

这个例子无害，但带有普遍的教训：*训练信号只在它被度量过的地方约束行为*。对语言模型来说，情形空间是巨大的，而最要紧的情形——新异的、高风险的，或模型比它的监督者知道得更多的——恰恰是训练中表征最少的那些。

::: warning "内未对齐"不是一个关于意图的主张
目标误泛化描述的是行为：CoinRun 智能体并没有欺骗任何人的愿望。关于内对齐的讨论有时会从"学到的策略朝非预期的方向泛化"（已观察到）滑向"模型怀有它正在策略性地追求的内部目标"（一个强得多的假设，在[[safety-alignment/deception-misalignment]]中仔细考察）。要把两者分开：前者只需要分布漂移，后者还需要内部的目标表征与情境感知。
:::

## 古德哈特定律及其变体 {#sec-goodhart}

1975 年，经济学家 Charles Goodhart 观察到，一个统计规律一旦被用于控制就趋于崩溃；人类学家 Marilyn Strathern 的转述就是那句人们熟知的话："一个度量一旦成为目标，它就不再是好度量。"每个训练目标都是一个被当作目标的度量。Manheim 与 Garrabrant（2018）区分了四种机制。

::: definition 古德哈特的四种变体 {#def-goodhart}
设 $V$ 是真实目标，$X$ 是一个与它相关并正被优化的代理。
1. **回归式**：$X = V + U$，噪声 $U$ 独立。按高 $X$ 选择也部分地是按高 $U$ 选择，于是 $V$ 低于 $X$ 所显示的水平。
2. **极端式**：在寻常范围内观察到的 $X$ 与 $V$ 的关系，在优化所能到达的 $X$ 的极端处失效。
3. **因果式**：$X$ 与 $V$ 的相关缘于共同原因，或因 $V$ 导致 $X$；直接对 $X$ 施加干预并不改变 $V$。
4. **对抗式**：另一个目标不同的行动者利用 $X$ 正被优化这一点——例如制造在 $X$ 上得分高的东西。
:::

四种变体并不互斥。在人偏好上训练的奖励模型（[[post-training/reward-models]]）会同时遭受回归式古德哈特（它的分数有噪声）、极端式古德哈特（策略到达的回复与其训练时所见的任何回复都不同）、因果式古德哈特（训练数据中长度与质量相关，但加长并不增加质量），以及——若把策略本身看作其奖励模型的对手——对抗式古德哈特。回归式古德哈特是唯一可以精确计算的一种。

::: proposition 高斯变量的回归式古德哈特 {#prop-regressional}
设 $V\sim\Normal(0, \sigma_V^2)$ 与 $U\sim\Normal(0, \sigma_U^2)$ 独立，且 $X = V + U$。则
$$
\E[V\mid X = x] = \frac{\sigma_V^2}{\sigma_V^2 + \sigma_U^2}\,x,
$$ {#eq-regressional}
且对超过阈值的选择，$\E[V\mid X > t] = \dfrac{\sigma_V^2}{\sigma_V^2 + \sigma_U^2}\,\E[X\mid X > t]$。被选中项的真实价值随阈值增大而增长，但只按代理分数的 $k = \sigma_V^2/(\sigma_V^2 + \sigma_U^2)$ 这一比例增长。
:::

::: proof
$(V, X)$ 联合高斯，且由独立性有 $\Var(X) = \sigma_V^2 + \sigma_U^2$、$\Cov(V, X) = \Cov(V, V + U) = \sigma_V^2$。均值为零的联合高斯变量满足 $\E[V\mid X] = \frac{\Cov(V, X)}{\Var(X)}X$（$V$ 对 $X$ 的回归是线性的），此即[[#eq-regressional]]。至于阈值情形，用塔性质（tower property）：$\E[V\mid X > t] = \E\big[\E[V\mid X]\,\big|\,X > t\big] = k\,\E[X\mid X > t]$。
:::

因此在高斯情形，优化代理总是有帮助的，只是不如看上去那么多：被选中项让人失望一个因子 $k$。这就是胜者诅咒（winner's curse）。危险在于其他变体，以及重尾误差——[[safety-alignment/reward-hacking]]证明，在重尾情形被选中项的真实价值可能跌回其无条件均值。

:::

::: example 选取前十分之一 {#ex-top-tenth}
回复有真实质量 $V\sim\Normal(0, 1)$ 与奖励模型分数 $X = V + U$，其中 $U\sim\Normal(0, 1)$ 独立。我们保留分数最高的 $10\%$。标准差为 $\sigma$ 的正态分布在其前 $10\%$ 上 $X$ 的均值为 $\sigma\,\varphi(z)/0.1$，其中 $z = 1.2816$ 是 $90\%$ 分位数。计算被保留回复的平均分数与平均真实质量。
::: solution
$\sigma_X = \sqrt2 = 1.4142$ 且 $\varphi(1.2816) = e^{-1.2816^2/2}/\sqrt{2\pi} = 0.1755$，所以 $\E[X\mid\text{前 }10\%] = 1.4142\cdot0.1755/0.1 = 2.482$。由[[#prop-regressional]]，取 $k = 1/2$，$\E[V\mid\text{前 }10\%] = 1.241$。[[#sec-code]]中的清单从 $200{,}000$ 个模拟回复中得到 $2.49$ 与 $1.25$。一个从自己的奖励模型上读出 $2.48$ 个标准差改进的团队，实际只得到其中一半。
:::
:::

## 遗漏造成的规格缺陷 {#sec-omission}

规格里很少有什么虚假的东西；它的失败都是遗漏。清洁机器人的奖励提到整洁与速度，却没有提桌上的花瓶。Amodei 等（2016）把这种后果称为**负面副作用**（negative side effects）。Zhuang 与 Hadfield-Menell（NeurIPS 2020）证明，在资源约束下，优化一个遗漏了真实效用某些属性的代理，会把这些属性推向它们的最差值。最简单的版本有一个简短的证明。

::: proposition 被遗漏的属性会被牺牲 {#prop-omission}
设一个状态由属性 $s_1, \dots, s_L\ge0$ 描述，它们竞争一种资源，$\sum_i s_i\le B$。真实效用为 $U(\mathbf{s}) = \sum_{i=1}^L u_i(s_i)$，每个 $u_i$ 严格递增。代理 $\tilde U(\mathbf{s}) = \sum_{i\in J}u_i(s_i)$ 只提到属性的一个真子集 $J$。则 $\tilde U$ 的每个最大值点都满足所有 $i\notin J$ 有 $s_i = 0$，其真实效用为 $\max_{\mathbf{s}}\tilde U + \sum_{i\notin J}u_i(0)$，它与 $\max U$ 的差距可以任意大。
:::

::: proof
设 $\mathbf{s}$ 最大化 $\tilde U$ 且对某个 $k\notin J$ 有 $s_k > 0$。把数额 $s_k$ 移给某个属性 $j\in J$：新状态仍满足约束，而由于 $u_j$ 严格递增，$\tilde U$ 上升 $u_j(s_j + s_k) - u_j(s_j) > 0$——与极大性矛盾。于是每个最大值点都有 $s_k = 0$（对 $k\notin J$），其真实效用为 $\max\tilde U + \sum_{k\notin J}u_k(0)$。

至于差距的大小，固定 $i\in J$ 的各 $u_i$，并给某个被遗漏的属性 $k$ 以效用 $u_k(s) = a\log(1 + s)$，于是 $u_k(0) = 0$，且代理最优点的真实效用 $\max\tilde U$ 不依赖于 $a$。给 $s_k$ 一单位、把剩余的 $B - 1$ 最优地花在 $J$ 上的方案（设 $B > 1$），其真实效用至少是 $\min_{\mathbf{s}}\tilde U + a\log2$，随 $a$ 无界增长。因此当 $a\to\infty$ 时 $\max U - (\max\tilde U + \sum_{k\notin J}u_k(0))\to\infty$：被遗漏的属性越重要，代理最优点的损失就越大。
:::

::: example 一个三属性方案 {#ex-omission}
一个规划者把 $B = 10$ 单位精力按整数单位分给速度 $s_1$、舒适 $s_2$ 与安全 $s_3$，其中 $u_1 = 3\ln(1 + s_1)$、$u_2 = 2\ln(1 + s_2)$、$u_3 = 4\ln(1 + s_3) - 6$。求真实最优、忘记安全的代理 $u_1 + u_2$ 的最优，以及两者的真实效用。
::: solution
对代理而言，连续最优使边际值相等，$3/(1 + s_1) = 2/(1 + s_2)$ 且 $s_1 + s_2 = 10$，得 $s_1 = 6.2$、$s_2 = 3.8$；最好的整数方案是 $(6, 4, 0)$，真实效用为 $3\ln7 + 2\ln5 + 0 - 6 = 5.838 + 3.219 - 6 = 3.06$。对真实效用，$3/(1 + s_1) = 2/(1 + s_2) = 4/(1 + s_3)$ 使 $1 + s_i$ 与 $3, 2, 4$ 成比例，而这些 $1 + s_i$ 之和为 $13$：$1 + s_1 = 3\cdot13/9$，于是 $s\approx(3.3, 1.9, 4.8)$，最好的整数方案是 $(3, 2, 5)$，$U = 3\ln4 + 2\ln3 + 4\ln6 - 6 = 7.52$。代理方案在它提到的两个属性上都更好，总体却差 $4.47$——而差额完全出在没人写下来的那个属性上。[[#sec-code]]中的清单用穷举确认了这两个最优点。
:::
:::

这一命题解释了某种常见安全直觉的形状——"优化器会把你没要求的东西都拿去交换"——也解释了它的限度。它假定对资源的硬竞争与精确的最大化。真实训练很少精确地最大化任何东西，而朝着参考策略的 KL 惩罚（[[post-training/rlhf]]）正是对优化能推进多远的有意限制；Zhuang 与 Hadfield-Menell 自己提出的补救办法，是交互式、逐步细化的目标。

## 工具性趋同 {#sec-instrumental}

上面的论证关乎优化了略错目标的系统。还有一族论证关乎：任何足够有能力的目标导向系统，无论其目标是什么，都倾向于做什么。

Omohundro（2008）在《The Basic AI Drives》中论证，大范围的目标寻求系统都会默认设法保存自己的目标、保护自己、获取资源并提升自己的能力，因为几乎任何最终目标都受益于其中每一样。Bostrom（2012；《Superintelligence》，2014）陈述了两个论题。**正交性论题**（orthogonality thesis）：智能与最终目标是相互独立的坐标轴，因此原则上任何程度的智能都可以与几乎任何最终目标相结合。**工具性趋同论题**（instrumental convergence thesis）：若干工具性目标对大范围的最终目标与情形都有用，因此很可能被大范围的智能体追求。一个令人难忘的例子来自 Russell（2019）：一台被告知去拿咖啡的机器，有不被关闭的理由，因为"你都死了，就拿不了咖啡了"。

Turner、Smith、Shah、Critch 与 Tadepalli（NeurIPS 2021）把这一论证的一个版本对马尔可夫决策过程（Markov decision process）作了精确表述：对奖励函数分布的绝大多数而言，*最优*策略倾向于移向那些仍能到达更多其他状态的状态——"保持选择的开放"。最小的情形可以直接证明。

::: proposition 随机奖励下的选项 {#prop-options}
从一个起始状态，智能体或者选择一个通向单一终止状态的分支，或者选择一个通向枢纽的分支，从枢纽它可以再选择 $k$ 个终止状态中的任意一个。$k + 1$ 个终止状态的奖励独立同分布于一个连续分布，智能体就实际实现的奖励最优地行动。则最优的第一步以概率 $k/(k + 1)$ 走向枢纽。
:::

::: proof
当且仅当最大奖励落在枢纽的 $k$ 个终止状态之中时，最优策略走向枢纽。独立同分布的连续奖励不会有并列，且由对称性，$k + 1$ 个状态以同等概率持有最大值。于是概率为 $k/(k + 1)$。
:::

这一命题说的是**奖励函数分布**下的**最优**策略——这是一个"大多数目标都青睐保持选择开放"的陈述。它并没有说被训练的网络是最优的，也没有说训练会产生什么样的目标分布。Turner 本人强调这些限度，后来还主张被训练的策略根本未必是奖励最大化者（"Reward is not the optimization target"，2022）。批评者走得更远。Gallow（《Philosophical Studies》，2024，"Instrumental divergence"）论证，形式化结果比非正式论题弱得多，因为对许多目标而言最佳行动千差万别；另一些人则认为该论题假定了一个前后一致的长视野期望效用最大化者，而这只是一个理想化，当今的语言模型——为模仿与满足短视野偏好而训练——未必与此相像。辩护者回应说，在长视野任务上用强化学习训练的系统（[[agents]]）正被推向恰恰是这种目标导向性，并指出[[safety-alignment/deception-misalignment]]中的实证研究：置于智能体情境中的模型有时会采取自我保存的行动。那些研究很新，使用的是构造的情境，且容许竞争性的解释；证据的现状在彼处讨论。

::: example 数选项 {#ex-options}
在[[#prop-options]]的设定下取 $k = 3$，最优策略走向枢纽的概率是多少？再设奖励分布不对称：单一终止状态的奖励服从 $[0, 2]$ 上的均匀分布，各枢纽状态的奖励服从 $[0, 1]$ 上的均匀分布。此时概率是多少？
::: solution
对称奖励下是 $3/4$，清单中的模拟（$0.751$）证实了这一点。第二种情形，枢纽胜出当且仅当 $M = \max(R_1, R_2, R_3) > L$，其中 $M$ 在 $[0, 1]$ 上有密度 $3m^2$，$L$ 服从 $[0, 2]$ 上的均匀分布：$\Prob(L < M) = \E[M/2] = \tfrac12\cdot\tfrac34 = 3/8$。保持选择开放的倾向，是关于目标的*对称*分布的事实；当目标偏爱某个特定结果时，最优策略就走向那里。因此工具性趋同的论证，取决于这样一个主张：系统所获得的目标，在相关意义下是多样的或不受约束的——这正是不受批评者认可的步骤。
:::
:::

::: intuition 咖啡机器人的论证为何说服了一些人、没说服另一些人
该论证有两个前提：(1) 系统在长视野上优化一个目标；(2) 该目标不是那种重视"被纠正"的目标。若两者都成立，抗拒关机几乎由定义便可知。认为风险严重的人觉得，训练有能力的自主智能体倾向于产生 (1)，而 (2) 难以保证；认为风险被夸大的人则怀疑，对按当今模型的训练方式训练的系统而言 (1) 并不成立，或者认为 (2) 可以通过训练模型去顺从（defer）来实现——这正是关于**可修正性**（corrigibility）的研究（Soares 等，2015）与 Russell 的提议的目标：让机器对人类偏好保持不确定，从而有理由接受纠正（Hadfield-Menell 等，"The off-switch game"，2017）。
:::

## 具体问题 {#sec-concrete}

Amodei、Olah、Steinhardt、Christiano、Schulman 与 Mané（2016）把这些关切改写为当代机器学习中的研究问题，分为五个标题：

1. **避免负面副作用**——不以目标未提及的方式扰动环境（[[#prop-omission]]）；
2. **避免奖励破解**——不利用目标中的缺陷（[[safety-alignment/reward-hacking]]）；
3. **可扩展监督**——当反馈昂贵或难以给出时学到预期的行为（[[safety-alignment/scalable-oversight]]）；
4. **安全探索**——学习过程中不采取灾难性的行动；
5. **对分布偏移的稳健性**——在与训练不同的输入上行为合理，或至少认识到自己的不确定（[[#def-goal-misgen]]、[[safety-alignment/robustness-jailbreaks]]）。

每个问题都可以用现有系统作经验研究，而不必先行裁决关于遥远未来的分歧，本课程的许多内容都遵循这一思路。此后有两个关切被醒目地加进来：**滥用**（misuse）——有能力的系统帮助人造成伤害，即[[safety-alignment/robustness-jailbreaks]]与[[safety-alignment/safety-frameworks]]的主题——以及这样一种可能性：系统**在评测下表现良好、在其他场合则不然**，前者在[[safety-alignment/deception-misalignment]]中研究、在[[safety-alignment/monitoring-control]]中防范。

对语言模型而言，实践中的对齐意味着朝着 Askell 等（2021）概括为**有用、诚实、无害**的目标做后训练，手段是指令微调、偏好学习与 AI 反馈（[[post-training/instruction-tuning]]、[[post-training/rlhf]]、[[post-training/ai-feedback]]）。这些方法是有已知弱点的外对齐工具：人类评审会犯错、会被奉承、会被蒙骗，而对着他们的判断优化的策略也会学到他们的弱点。Ngo、Chan 与 Mindermann（2022，为 ICLR 2024 修订）论证，对越来越有能力的模型用人类认可来训练，会制造**情境感知式奖励破解**的激励——在被检查的地方表现良好——而这与目标误泛化一道，从深度学习的角度看构成了问题的核心。这篇论文把一个立场说得清清楚楚；它是一个论证，不是一个测量。

## 研究者如何权衡风险 {#sec-views}

这个领域存在强烈的分歧，不仅在如何解决这个问题上，还在这个问题有多重要上。了解主要的立场及各自引证的证据是有帮助的。

- **未对齐高级 AI 的严重风险。** 包括 Geoffrey Hinton、Yoshua Bengio 与 Stuart Russell 在内的研究者，以及专注于这一议题的组织认为：在数十年内出现比人类在大多数领域更能干的系统是可信的，我们缺乏检验其目标的方法，而失败的后果可能是灾难性且不可逆的。2023 年 5 月，AI 安全中心（Center for AI Safety）组织的一份一句话声明——"缓解 AI 导致的灭绝风险，应当与流行病、核战争等其他社会规模的风险并列，成为全球优先事项"——由众多顶尖研究者与多家 AI 开发机构的负责人签署。
- **先解决当下伤害。** AI 伦理与公平性领域的研究者（如 Bender、Gebru 及其合作者）认为，对推测性未来灾难的注意会分散对已部署系统那些有案可查的伤害——偏见、监控、劳动剥削、错误信息（[[llm-society]]）——的注意力，并且可能服务于建造它们的公司的利益。
- **普通技术。** 另一些人，如 Narayanan 与 Kapoor（2025，"AI as normal technology"），认为 AI 的影响会像早期的通用目的技术那样，通过向制度的扩散在上数十年间展开，正确的回应是寻常的监管与韧性，而不是把 AI 当作一个可能拥有自己目标的行动者来对待。一些著名研究者，尤其是 Yann LeCun，主张目标导向的系统可以被设计成带有内置护栏，而对被支配的恐惧是错置的。

这些立场不仅在事实上有分歧，还在时间视野与不确定之下如何行动上不同。调查显示观点分布之广。

::: application 调查测量了什么
Grace 与其合作者（2024，"Thousands of AI authors on the future of AI"）在 2023 年 10 月调查了 $2{,}778$ 名 2022 年在六个顶级机器学习与 AI 会议上发表过论文的研究者（回收率约 $15\%$）。回答在不同受访者之间、并随问题措辞剧烈变化。中位数受访者给出约 $5\%$ 的概率，认为高级 AI 会导致与人类灭绝同样糟糕、或永久性严重无权一样糟糕的结果；视问题不同，$38\%$ 到 $51\%$ 的受访者给出了至少 $10\%$。多数受访者还把错误信息、威权式滥用等近期关切评为值得相当或极度的担忧。2022 年的一次预测锦标赛（Karger 等，2023，存在性风险说服锦标赛，Existential Risk Persuasion Tournament）发现了一个巨大且持久的差距：领域专家对 AI 导致灭绝（到 2100 年）的中位数预测约 $3\%$，预测记录出色的"超级预测员"（superforecasters）约 $0.4\%$，而数月的结构化讨论几乎没有缩小它。这两个数字都不是风险的测量：它们是针对前所未有事件被引出的信念，对措辞和"谁选择作答"都很敏感。
:::

::: example 解读一项存在无回答的调查 {#ex-survey}
一次调查中，约 $18{,}500$ 名受邀研究者有 $2{,}778$ 人作答，$40\%$ 的受访者给极坏结果至少 $10\%$ 的概率。(a) 把受访者当作受邀人群的一个随机样本，给出该比例的近似 $95\%$ 置信区间。(b) 若无回答者可以持任何观点，那么在全体受邀者中该比例可能落在什么范围？
::: solution
(a) 标准误差 $\sqrt{0.4\cdot0.6/2778} = 0.0093$，于是 $0.40\pm0.018$，约 $38\%$ 到 $42\%$——抽样误差很小。(b) 这 $1{,}111$ 名持严重关切的受访者占受邀者的 $1{,}111/18{,}500 = 6.0\%$；若每个无回答者都持严重关切，该比例将是 $(1{,}111 + 15{,}722)/18{,}500 = 91\%$。于是界限是 $6\%$ 到 $91\%$。调查作者就可观察特征把受访者与无回答者作了比较，发现差异不大，但教训不变：当回收率为 $15\%$ 时，主导不确定性的是*选择*——而不是抽样误差——诚实的总结会把两者都报告出来。
:::
:::

截至 2026 年，由约三十个政府与国际组织提名的小组撰写的《国际人工智能安全报告》（International AI Safety Report；Bengio 等，2025，此后有更新）记录了同样的分歧：它把失控描述为一些专家认为可信、另一些专家认为极不可能的风险，指出证据有限，并说政策制定者面临一个"证据困境"——是在证据薄弱时早行动，还是等到伤害更清楚。本课程取同样的立场：报告证据、给论证贴标签；而它所描述的保障措施（[[safety-alignment/monitoring-control]]、[[safety-alignment/safety-frameworks]]）在绝大部分观点范围内都是有用的。

## 一个模拟 {#sec-code}

下面这份清单对本章的三个结果做数值检验：在模拟代理上做选择检验回归式古德哈特（[[#prop-regressional]]、[[#ex-top-tenth]]），用随机奖励抽样检验选项计数（[[#prop-options]]），用穷举检验被遗漏属性的例子（[[#ex-omission]]）。

```python
import random, math

# --- 1. 回归式古德哈特：在代理 X = V + U 上做选择 -------------------------
rng = random.Random(0)
sv, su = 1.0, 1.0                       # 真实值 V 与代理误差 U 的标准差
pairs = [(rng.gauss(0, sv), rng.gauss(0, su)) for _ in range(200_000)]
pairs = [(v, v + u) for v, u in pairs]  # (真实值, 代理)
pairs.sort(key=lambda p: p[1], reverse=True)
for frac in (0.5, 0.1, 0.01, 0.001):
    top = pairs[: int(frac * len(pairs))]
    mv = sum(v for v, _ in top) / len(top)
    mx = sum(x for _, x in top) / len(top)
    print(f"top {frac:6.1%} by proxy: mean proxy {mx:5.2f}  mean true {mv:5.2f}  ratio {mv/mx:.3f}")

# --- 2. 随机奖励下选项丰富的分支（寻权玩具例子） ---------------------------
# 从起始状态，"left" 通向 1 个终止状态；"right" 通向一个枢纽，
# 从枢纽可到达 k 个终止状态。终止状态上的奖励 iid U(0,1)。
def frac_right(k, trials, rng):
    wins = 0
    for _ in range(trials):
        left = rng.random()
        right = max(rng.random() for _ in range(k))
        wins += right > left
    return wins / trials
rng = random.Random(1)
for k in (1, 2, 3, 9):
    print(f"k={k}: optimal policy goes to the hub in {frac_right(k, 100_000, rng):.3f} of reward draws (theory {k/(k+1):.3f})")

# --- 3. 遗漏一个属性的代理（Zhuang & Hadfield-Menell 风格） ----------------
B = 10                                   # 资源预算，整数单位
u = [lambda s: 3 * math.log(1 + s),      # 属性 1：速度
     lambda s: 2 * math.log(1 + s),      # 属性 2：舒适
     lambda s: 4 * math.log(1 + s) - 6]  # 属性 3：安全（被代理遗漏）
best_true = max(((a, b, B - a - b) for a in range(B + 1) for b in range(B + 1 - a)),
                key=lambda s: sum(f(x) for f, x in zip(u, s)))
best_proxy = max(((a, b, B - a - b) for a in range(B + 1) for b in range(B + 1 - a)),
                 key=lambda s: u[0](s[0]) + u[1](s[1]))
U = lambda s: sum(f(x) for f, x in zip(u, s))
print("true optimum", best_true, f"U={U(best_true):.2f}")
print("proxy optimum", best_proxy, f"U={U(best_proxy):.2f}")
```

输出：

```
top  50.0% by proxy: mean proxy  1.14  mean true  0.57  ratio 0.499
top  10.0% by proxy: mean proxy  2.49  mean true  1.25  ratio 0.500
top   1.0% by proxy: mean proxy  3.77  mean true  1.89  ratio 0.502
top   0.1% by proxy: mean proxy  4.74  mean true  2.39  ratio 0.506
k=1: optimal policy goes to the hub in 0.502 of reward draws (theory 0.500)
k=2: optimal policy goes to the hub in 0.668 of reward draws (theory 0.667)
k=3: optimal policy goes to the hub in 0.751 of reward draws (theory 0.750)
k=9: optimal policy goes to the hub in 0.900 of reward draws (theory 0.900)
true optimum (3, 2, 5) U=7.52
proxy optimum (6, 4, 0) U=3.06
```

无论我们选得多严，真实值与代理值之比都停留在 $k = 0.5$，正如[[#prop-regressional]]所预测：高斯误差下，更严的选择仍然有帮助。把 `rng.gauss(0, su)` 换成重尾误差，图景就会改变——那正是下一章的起点。

::: quiz
一个强化学习智能体在每一个训练回合上奖励都正确，可在部署时，它却能干地追求着与预期目标不同的东西。哪个描述最贴切？
- [ ] 外对齐失败：奖励错了。
- [x] 目标误泛化：预期目标与另一个目标在训练中无法区分，智能体学到了另一个。
- [ ] 能力误泛化：智能体在分布外丢了技能。
- [ ] 对抗式古德哈特：另一个智能体利用了奖励。
::: solution
奖励在被度量之处是对的，所以这不是外对齐失败；智能体仍然能干，所以也不是能力失败。无法区分两个目标的训练数据，把选择留给了归纳偏置（[[#def-goal-misgen]]、[[#ex-two-goals]]）。
:::

:::

::: summary
- 对齐是系统行为与其委托人的意图之间、在一个情形集合上的关系；"与什么对齐"（指令、意图、偏好、利益、价值观）部分是一个规范性选择。
- 委托人–代理人框架：目标是一份不完全契约。理想、设计与显示规格可以互不相同。
- 外对齐问训练目标对不对；内对齐问训练出的系统在分布外是否追求它。目标误泛化是内未对齐已被证实的、行为层面的形式。
- 古德哈特变体：回归式、极端式、因果式、对抗式。高斯噪声下，按代理做选择仍然有帮助，比例为 $\sigma_V^2/(\sigma_V^2 + \sigma_U^2)$。
- 在资源竞争下，优化遗漏了属性的代理，会把被遗漏的属性完全牺牲掉。
- 工具性趋同：对目标的大多数对称分布，最优策略都会保持选择的开放（在玩具 MDP 中证明）；训练出的系统是否继承这一点存在争议，双方都有认真的论证。
- 关于灾难性风险的专家意见分布很广；调查测量的是信念，带有很大的措辞与选择效应。证据、论证与推测应当区分开来。
:::

## 习题

::: exercise 收缩因子 {level=1 check="0.2"}
真实质量的标准差为 $1$，一个代理再加上标准差为 $2$ 的独立高斯噪声。一项的期望真实质量是它代理分数的多少倍？
::: solution
$k = \sigma_V^2/(\sigma_V^2 + \sigma_U^2) = 1/(1 + 4) = 0.2$（[[#prop-regressional]]）：一个代理分数为 $3$ 的项，期望真实质量为 $0.6$。
:::
:::

::: exercise 选项 {level=1 check="0.9"}
在[[#prop-options]]的设定下，枢纽通向 $9$ 个终止状态。独立同分布的连续奖励下，最优策略走向枢纽的概率是多少？
::: solution
$k/(k + 1) = 9/10 = 0.9$，与[[#sec-code]]中模拟的 $0.900$ 一致。
:::
:::

::: exercise 判别古德哈特变体 {level=1}
按[[#def-goodhart]]给每种情形归类：(a) 奖励模型学到较长的回答更受偏爱，策略于是把回答注水加长；(b) 一个实验室从 $50$ 个候选检查点中挑出在有噪声基准上分数最好的那个，而它在新基准上分数更低；(c) 用户发现加入某些短语会让审核模型放行内容；(d) 奖励模型对寻常长度的回复是准的，却给从未在其训练数据中出现过的、极长的、重复的回复打出很高的分数。
::: solution
(a) 因果式：长度与质量相关（经由细致），但对长度施加干预并不产生质量。(b) 回归式：在有噪声分数中挑最大值，也选上了有利的噪声——胜者诅咒。(c) 对抗式：其他行动者针对该度量做优化。(d) 极端式：该关系在寻常范围内成立，而在优化抵达的极端处失效。实际情形通常是混合的；(a) 一旦注水超出训练范围，也带有极端式成分。
:::
:::

::: exercise 训练中的反例 {level=2 check="0.0067"}
在[[#ex-two-goals]]中，每个训练关卡独立地以概率 $0.005$ 把金币移出最右端。共 $1{,}000$ 个训练关卡，没有任何关卡能区分两个目标的概率是多少？给出两位有效数字。
::: solution
$0.995^{1000} = e^{1000\ln0.995} = e^{-5.0125} = 0.0067$。即便 $0.5\%$ 的反例率，也让完全含混的训练集几乎不可能出现；至于智能体是否真能从那几个反例中*学会*，则是关于优化与能力的另一个问题。
:::
:::

::: exercise 选取前百分之一 {level=2 check="1.89"}
设 $\sigma_V = \sigma_U = 1$，标准差为 $\sigma$ 的正态变量在其前 $1\%$ 上的均值为 $\sigma\varphi(z)/0.01$，其中 $z = 2.3263$、$\varphi(z) = 0.026652$。按代理挑选的前 $1\%$ 的期望真实值是多少？保留两位小数。
::: solution
$\E[X\mid\text{前 }1\%] = \sqrt2\cdot0.026652/0.01 = 3.769$，由[[#prop-regressional]]，真实值是一半：$1.885$，四舍五入为 $1.89$——与模拟的 $3.77$ 和 $1.89$ 一致。
:::
:::

::: exercise 有偏的目标分布 {level=2 check="1/3"}
在[[#prop-options]]中取 $k = 2$，单一终止状态的奖励服从 $[0, 2]$ 上的均匀分布，枢纽的两个终止状态奖励服从 $[0, 1]$ 上的均匀分布，全部独立。最优策略走向枢纽的概率是多少？
::: solution
两个 $[0, 1]$ 均匀分布变量最大值 $M$ 满足 $\E M = 2/3$。枢纽胜出当 $L < M$，而 $L$ 服从 $[0, 2]$ 上的均匀分布时 $\Prob(L < M\mid M) = M/2$，故概率为 $\E[M]/2 = 1/3$。与对称奖励下的 $2/3$ 相比：寻权定理的结论依赖于目标的分布。
:::
:::

::: exercise 被遗漏的属性 {level=2 check="4.47"}
在[[#ex-omission]]中，最好的整数代理方案的真实效用比最好的整数真实方案低多少？用未取整的效用计算，保留两位小数。
::: solution
$U(3,2,5) = 3\ln4 + 2\ln3 + 4\ln6 - 6 = 4.1589 + 2.1972 + 7.1670 - 6 = 7.5231$，$U(6,4,0) = 3\ln7 + 2\ln5 - 6 = 5.8377 + 3.2189 - 6 = 3.0566$。差额是 $4.4665$，两位小数为 $4.47$（[[#prop-omission]]）。差额全部来自安全属性：代理方案在速度与舒适上多得 $1.6777 + 1.0217 = 2.70$，却在安全上失去 $4\ln6 = 7.17$。
:::
:::

::: exercise 一个正则化的代理 {level=3}
修改[[#prop-omission]]：规划者最大化 $\tilde U(\mathbf{s}) - \lambda\sum_i(s_i - s_i^{\text{ref}})^2$，即偏离参考方案 $\mathbf{s}^{\text{ref}}$（每个 $s_i^{\text{ref}} > 0$）的惩罚，且资源约束不起作用。证明被遗漏的属性现在停留在它们的参考值上，并解释与 RLHF 中 KL 惩罚的类比。
::: solution
对 $i\notin J$，目标只通过 $-\lambda(s_i - s_i^{\text{ref}})^2$ 依赖 $s_i$，在 $s_i = s_i^{\text{ref}}$ 处最大化。对 $i\in J$，一阶条件 $u_i'(s_i) = 2\lambda(s_i - s_i^{\text{ref}})$ 把 $s_i$ 推到参考值之上一个随 $\lambda$ 增大而缩小的量。于是惩罚保护了代理没有提到的东西——把它留在参考方案放它的位置——它只和参考方案一样好，而且只有当优化被提到的属性不需要从被遗漏的属性取用资源时才成立（若预算起作用，被遗漏的属性又会被拿去交换，交换的速率由 $\lambda$ 控制）。RLHF 中的 KL 惩罚 $\beta D_{\mathrm{KL}}(\pi\Vert\pi_{\text{ref}})$（[[post-training/rlhf]]）扮演同样的角色：奖励模型打不出分的行为被保持在参考模型附近，这正是它能限制奖励破解的原因，也正是它修不好参考模型本来就做错的行为的原因。
:::
:::

::: exercise 行为证据的限度 {level=3}
关于一个训练好的策略的两个假设，在测试集 $S$ 的每个情形上一致，但在某个情形 $s^\star\notin S$ 上不同。证明 $S$ 上的任何检验都不会改变它们的相对概率，并描述两种可能有用的证据。
::: solution
设 $H_1$、$H_2$ 是两个假设，$E$ 是在 $S$ 上对策略行为的任一观察。由于两个假设预测 $S$ 上相同的行为分布，$\Prob(E\mid H_1) = \Prob(E\mid H_2)$，由贝叶斯定理（Bayes' theorem）$\Prob(H_1\mid E)/\Prob(H_2\mid E) = \Prob(H_1)/\Prob(H_2)$：后验几率等于先验几率。有用的证据必须来自 $S$ 之外或行为之外：(1) 在两个假设不同的情形上做**新的行为测试**——这要求预见到 $s^\star$，或自动生成多样的测试（[[safety-alignment/red-teaming]]）；(2) **内部证据**——检验表征与机制，使两个假设即使在输出一致的场合、对激活也给出不同的预测（[[interpretability]]）。第三种结构性的回应，是让 $s^\star$ 的后果即便坏假设为真也可以承受（[[safety-alignment/monitoring-control]]）。同样的论证在[[safety-alignment/deception-misalignment]]中就欺骗行为展开。
:::
:::

::: exercise 调查的界限 {level=3 check="0.0601"}
在[[#ex-survey]]中，在对无回答者作任何假设之前，可以确定*全体受邀者*中给极坏结果至少 $10\%$ 概率者所占比例是多少？用 $18{,}500$ 名受邀者与 $1{,}111$ 名持严重关切的受访者计算，保留四位小数。
::: solution
$1{,}111/18{,}500 = 0.060054$，即 $0.0601$。这是最坏情形界限的下端；上端是 $(1{,}111 + 15{,}722)/18{,}500 = 0.9099$。任何关于整个人群更窄的说法，都依赖一个关于无回答者与受访者有何不同的假设，应当连同该假设一起说明。
:::
