当语言模型的训练损失从$3.0$降到$2.5$时，改善的究竟是什么？损失以**纳特每词元**（nats per token）计量，这是信息的单位，而这个数字有具体的含义：若拿这个模型去压缩文本，平均编码每个词元就需要$2.5$纳特。更好的语言模型就是更好的压缩器，而两者度量的同一个量——一个预测器对实际发生的事情有多惊讶——正是信息论的研究对象。

本章定义本图谱其余部分要用到的几个量：信息量、**熵**、**交叉熵**、**Kullback–Leibler 散度**与**互信息**，以及**困惑度**——语言模型的损失常常以它报告。其核心结果是吉布斯（Gibbs）不等式$\operatorname{KL}(p\,\Vert\,q)\ge0$：它解释了为什么最小化交叉熵能使模型拟合数据，为什么这与极大似然是同一回事，以及为什么语言模型的损失永远不会低于它所建模文本的熵。这里的一切都是关于离散分布的，而这正是下一个词元预测所需要的；概率部分见[[math-for-ml/probability]]。

## 惊讶与熵 {#sec-entropy}

设一个概率为$p$的事件发生了。得知它发生，传递了多少信息？必然事件（$p = 1$）什么信息也不传递；罕见事件传递很多；而对两个独立事件，信息应当相加，它们的概率却相乘。能把乘积变成和的函数只有对数，于是得到下面的定义。

::: definition 信息量与熵 {#def-entropy}
概率为$p$的一个结果的**信息量**（又称自信息量，surprisal）是$-\log p$。集合$\mathcal{X}$上一个离散分布$p$的**熵**是信息量的期望，

$$
H(p) = -\sum_{x\in\mathcal{X}}p(x)\log p(x) = \E_{x\sim p}\big[-\log p(x)\big],
$$

其中约定$0\log0 = 0$。以$\log_2$为底时单位是**比特**（bit），以自然对数为底时单位是**纳特**（nat）；$1\text{纳特} = 1/\ln2\approx1.443$比特。我们也用$H(X)$表示随机变量$X$之分布的熵。
:::

熵度量不确定性：从$p$中抽取一次，平均有多不可预测。均匀硬币的熵是$1$比特；正面占$90\%$的硬币熵为$-0.9\log_20.9 - 0.1\log_20.1 = 0.469$比特；总是正面的硬币熵为$0$。深度学习代码使用自然对数，因此如无特别说明，损失都以纳特计。

::: widget plot
f: -(x*log(x) + (1-x)*log(1-x))/log(2)
x: 0.001, 0.999
y: 0, 1.1
labels: $H(p)$ in bits
points: 0.5,1; 0.9,0.469
caption: 正面概率为$p$的硬币的熵。均匀硬币处熵最大，为$1$比特；随着结果趋于确定，熵降为$0$。标记点$p = 0.9$处的熵为$0.469$比特：这样的硬币，平均每次抛掷用不到半比特就能描述。
:::

::: example 小分布的熵 {#ex-entropy}
以比特为单位计算下列分布的熵：(a) 分布$(\tfrac12, \tfrac14, \tfrac18, \tfrac18)$；(b) GPT-2 词表的$50{,}257$个词元上的均匀分布。
::: solution
(a) $H = \tfrac12\cdot1 + \tfrac14\cdot2 + \tfrac18\cdot3 + \tfrac18\cdot3 = 1.75$比特。若给四个结果分别配上码字 `0`、`10`、`110`、`111`，平均每个结果恰好使用$1.75$比特，且没有编码能做得更好（见[[#thm-source-coding]]）。

(b) $H = \log_250{,}257 = 15.62$比特，即$\ln50{,}257 = 10.83$纳特。这正是一无所知的模型的损失——它给每个词元都分配概率$1/50{,}257$——因此也是训练曲线的自然起点：未训练的语言模型，其损失接近$\ln\lvert\mathcal{V}\rvert$。
:::
:::

::: proposition 熵的界 {#prop-entropy-bounds}
对$K$个结果上的任意分布$p$，$0\le H(p)\le\log K$。下取等当且仅当$p$把全部质量放在一个结果上；上取等当且仅当$p$是均匀分布。
:::

::: proof
每一项$-p(x)\log p(x)$都$\ge0$，因为$0\le p(x)\le1$；且仅当$p(x)\in\{0, 1\}$时为$0$；所有项都为零只发生在单点分布时。上界由下面的吉布斯不等式取$q$为均匀分布得到：$0\le\operatorname{KL}(p\,\Vert\,u) = \sum_xp(x)\log\big(p(x)K\big) = \log K - H(p)$，且仅当$p = u$时取等。
:::

## 交叉熵与KL散度 {#sec-kl}

设模型$q$对实际由$p$抽出的结果做预测。若在由$p$抽出的结果处度量模型的惊讶程度$-\log q(x)$，所得就是它的交叉熵。

::: definition 交叉熵与 Kullback–Leibler 散度 {#def-kl}
对同一集合上的分布$p$与$q$，$q$相对于$p$的**交叉熵**为

$$
H(p, q) = -\sum_xp(x)\log q(x) = \E_{x\sim p}\big[-\log q(x)\big],
$$

以及从$q$到$p$的**Kullback–Leibler 散度**（相对熵）为

$$
\operatorname{KL}(p\,\Vert\,q) = \sum_xp(x)\log\frac{p(x)}{q(x)} = H(p, q) - H(p).
$$ {#eq-kl}

若存在$p(x) > 0$而$q(x) = 0$的$x$，二者为无穷大。
:::

分解式[[#eq-kl]]可以这样读：模型的平均惊讶程度，等于数据中不可约减的不确定性$H(p)$，加上使用错误分布的代价$\operatorname{KL}(p\,\Vert\,q)$。用编码的语言说，当数据来自$p$时，$H(p, q)$是为$q$设计的编码的平均长度，而KL散度是因分布不匹配而白白浪费的额外比特数。这一代价永不为负。

::: theorem 吉布斯不等式 {#thm-gibbs}
对有限或可数集合上的任意分布$p$与$q$，

$$
\operatorname{KL}(p\,\Vert\,q)\ge0,
$$

且等号成立当且仅当$p = q$。等价地，$H(p, q)\ge H(p)$：平均来说，没有哪个模型预测来自$p$的数据能比$p$本身更好。
:::

::: proof
我们用到不等式：当$t > 0$时$\ln t\le t - 1$，且仅当$t = 1$时取等（直线$t - 1$是凹函数$\ln t$在$t = 1$处的切线）。不妨设凡是$p(x) > 0$处都有$q(x) > 0$，否则散度为$+\infty$。记$S = \{x : p(x) > 0\}$。于是（以纳特计），

$$
-\operatorname{KL}(p\,\Vert\,q) = \sum_{x\in S}p(x)\ln\frac{q(x)}{p(x)}\le\sum_{x\in S}p(x)\Big(\frac{q(x)}{p(x)} - 1\Big) = \sum_{x\in S}q(x) - \sum_{x\in S}p(x)\le1 - 1 = 0.
$$

（换用其他底数只差一个正常数因子。）取等要求两步同时取等：对每个$x\in S$都有$q(x)/p(x) = 1$，且$\sum_{x\in S}q(x) = 1$，即$q$在$S$之外不放质量。两者合起来就是$q = p$。反过来$\operatorname{KL}(p\,\Vert\,p) = \sum p\log1 = 0$。
:::

::: warning KL散度不是距离
一般地$\operatorname{KL}(p\,\Vert\,q)\ne\operatorname{KL}(q\,\Vert\,p)$，而且这一散度不满足三角不等式；它是不匹配程度的度量，不是距离。它还是无界的：若模型给一个可能发生的结果分配概率$0$——或在浮点数中是一个下溢为$0$的概率——那么散度与交叉熵都是无穷大。这正是采用 softmax 输出层的原因之一（softmax 永不输出精确的零），也是为什么损失要用 log-sum-exp 从 logits 计算，而不是从舍入后的概率计算。
:::

这种不对称在实践中很重要，因为两个方向惩罚的错误不同。$\operatorname{KL}(p\,\Vert\,q)$对$p$取平均：在$p$大而$q$小的地方它会很大，因此以最小化它来拟合的模型会把质量摊开去**覆盖**数据占据的每个区域。$\operatorname{KL}(q\,\Vert\,p)$对$q$取平均：$q$在$p$小的地方放质量时它会很大，因此以最小化它来拟合的模型会**寻找峰值**，甚至完全忽略其他的峰。

::: example 前向与反向KL散度 {#ex-kl-directions}
三个结果上的数据分布是双峰的，$p = (0.495, 0.01, 0.495)$。比较两个模型：均匀分布$q_1 = (\tfrac13, \tfrac13, \tfrac13)$，它覆盖一切；以及$q_2 = (0.98, 0.01, 0.01)$，它选中一个峰。分别计算两者在两个方向上的散度，以纳特计。
::: solution
前向：$\operatorname{KL}(p\,\Vert\,q_1) = 2\cdot0.495\ln(0.495\cdot3) + 0.01\ln(0.03) = 0.392 - 0.035 = 0.356$，而$\operatorname{KL}(p\,\Vert\,q_2) = 0.495\ln\frac{0.495}{0.98} + 0 + 0.495\ln\frac{0.495}{0.01} = -0.338 + 1.931 = 1.593$。前向散度强烈偏好覆盖型模型$q_1$，因为$q_2$几乎忽略了一个占一半数据的峰。

反向：$\operatorname{KL}(q_1\,\Vert\,p) = 2\cdot\tfrac13\ln\frac{1/3}{0.495} + \tfrac13\ln\frac{1/3}{0.01} = -0.264 + 1.169 = 0.905$，而$\operatorname{KL}(q_2\,\Vert\,p) = 0.98\ln\frac{0.98}{0.495} + 0 + 0.01\ln\frac{0.01}{0.495} = 0.669 - 0.039 = 0.630$。反向散度偏好寻峰的$q_2$，因为$q_1$把自己三分之一的质量放在$p$几乎从不产生的那个结果上。
:::
:::

两个方向都出现在语言模型训练中。预训练最小化从数据到模型的前向散度（下一节），这就是基座模型把概率摊在许多合理续写之上的原因。基于人类反馈的强化学习（RLHF）加入一项惩罚$\beta\operatorname{KL}(\pi_\theta\,\Vert\,\pi_{\text{ref}})$：调优后的策略关于参考模型的反向散度，在策略自身采样出的样本上取平均；它使调优后的模型不会漂入参考模型认为不可能的区域，这也是调优后的模型比基座模型更确定的部分原因。

## 语言模型为何最小化交叉熵 {#sec-why-ce}

::: proposition 交叉熵损失、极大似然与KL散度 {#prop-mle-kl}
设$\hat p$是数据集$x_1, \dots, x_N$的经验分布（每个观测值的概率等于它的出现频率），$q_\theta$是一个模型。则平均负对数似然是一个交叉熵，

$$
-\frac1N\sum_{n=1}^N\log q_\theta(x_n) = H(\hat p, q_\theta) = H(\hat p) + \operatorname{KL}(\hat p\,\Vert\,q_\theta),
$$

因此，最大化似然、最小化交叉熵损失与最小化$\operatorname{KL}(\hat p\,\Vert\,q_\theta)$是同一个问题。若模型族包含$\hat p$，则最小值在$q_\theta = \hat p$处取得，最小损失为$H(\hat p)$。
:::

::: proof
把求和按取值归组：若$x$出现$c(x)$次，则$-\frac1N\sum_n\log q_\theta(x_n) = -\sum_x\frac{c(x)}N\log q_\theta(x) = -\sum_x\hat p(x)\log q_\theta(x) = H(\hat p, q_\theta)$。分解式即[[#eq-kl]]。$H(\hat p)$不依赖$\theta$，所以三个目标只相差一个常数。由[[#thm-gibbs]]，散度为零当且仅当$q_\theta = \hat p$。（这也给出了[[math-for-ml/estimation#prop-categorical-mle]]中类别分布极大似然估计的另一个证明，不必用拉格朗日乘数。）
:::

对语言模型，同样的论证适用于每个上下文：损失$-\frac1N\sum_t\log p_\theta(x_t\mid x_{<t})$是“数据的下一个词元分布与模型分布之间的交叉熵”在上下文上的平均。把经验分布换成文本的真实分布——新数据上的损失所估计的正是它——就得到一个关于泛化的结论：任何模型的期望损失都至少是**文本生成过程的熵**，超出部分正是模型与它之间的KL散度。完美模型的损失不会是零，而是语言本身不可约减的不确定性。[[scaling]]中的经验缩放定律恰好就是这种形式：模型规模与数据的幂律，加上一个常数的“不可约减”项——只不过那个常数是拟合出来的数，并不是测得的熵。

::: quiz
某模型的验证损失为每词元$2.1$纳特，而（不知通过什么途径）已知文本信源的熵为每词元$1.6$纳特。模型关于信源的平均KL散度（按每词元计）是多少？
- [ ] $3.7$纳特
- [x] $0.5$纳特
- [ ] $1.31$纳特，即两者之比
- [ ] 仅凭这两个数无法确定
::: solution
由[[#eq-kl]]，交叉熵 = 熵 + KL散度，所以KL散度为每词元$2.1 - 1.6 = 0.5$纳特。这是更好的模型能够消除的那部分损失；那$1.6$纳特是任何模型都无法消除的。
:::
:::

## 困惑度 {#sec-perplexity}

语言模型的损失常常以困惑度报告，它把平均对数概率变回一个选择数目。

::: definition 困惑度 {#def-perplexity}
模型在一篇$N$词元文本上的**困惑度**，是其平均负对数似然（以纳特计）的指数，

$$
\operatorname{PPL} = \exp\Big(-\frac1N\sum_{t=1}^N\ln p_\theta(x_t\mid x_{<t})\Big) = \Big(\prod_{t=1}^N\frac{1}{p_\theta(x_t\mid x_{<t})}\Big)^{1/N}.
$$

若损失以比特计，则$\operatorname{PPL} = 2^{\text{损失}}$；数值相同。
:::

困惑度是模型给实际词元的概率之倒数的几何平均。若某个模型在每一步都把概率均匀地摊在$K$个词元上，它的困惑度恰为$K$；所以困惑度$20$意味着平均来说，模型的不确定程度相当于在$20$个词元中均匀挑选——这就是它的**有效分支因子**。由于$\exp$递增，更低的困惑度与更低的损失是一回事，但困惑度会放大高损失处的差异、压缩低损失处的差异：在任何损失水平上，损失降低$0.1$纳特都对应困惑度$10\%$的变化。

::: example 用代码计算熵、交叉熵与困惑度 {#ex-perplexity}
设“真实”的下一个词元分布为$p = (0.5, 0.25, 0.125, 0.125)$，模型为$q = (0.4, 0.3, 0.2, 0.1)$，以比特为单位计算$H(p)$、$H(p, q)$以及两个方向的KL散度。再计算一个模型在一篇留出文本的五个词元上给出概率$0.2, 0.05, 0.6, 0.1, 0.3$时的损失与困惑度。
::: solution
```python
import math

def entropy(p):                      # 纳特；p_i = 0 的项贡献 0
    return -sum(pi * math.log(pi) for pi in p if pi > 0)

def cross_entropy(p, q):             # H(p, q) = -sum p_i log q_i
    return -sum(pi * math.log(qi) for pi, qi in zip(p, q) if pi > 0)

def kl(p, q):                        # KL(p || q) = H(p, q) - H(p)
    return sum(pi * math.log(pi / qi) for pi, qi in zip(p, q) if pi > 0)

p = [0.5, 0.25, 0.125, 0.125]        # “真实”的下一个词元分布，形状 (4,)
q = [0.4, 0.3, 0.2, 0.1]             # 模型分布，形状 (4,)
bits = 1 / math.log(2)
print("H(p)    =", round(entropy(p) * bits, 4), "bits")
print("H(p,q)  =", round(cross_entropy(p, q) * bits, 4), "bits")
print("KL(p|q) =", round(kl(p, q) * bits, 4), "bits;  KL(q|p) =", round(kl(q, p) * bits, 4))

# 由一篇留出文本各词元的概率计算模型的困惑度
token_probs = [0.2, 0.05, 0.6, 0.1, 0.3]
loss = -sum(math.log(t) for t in token_probs) / len(token_probs)   # 纳特每词元
print("loss =", round(loss, 4), "nats/token, perplexity =", round(math.exp(loss), 4))
```

```text
H(p)    = 1.75 bits
H(p,q)  = 1.8007 bits
KL(p|q) = 0.0507 bits;  KL(q|p) = 0.0536
loss = 1.7245 nats/token, perplexity = 5.6098
```

相对于真实分布，该模型每词元只浪费$0.05$比特；两个KL方向略有差异，这与通常情况一致。留出困惑度$5.61$是$1/0.2, 1/0.05, 1/0.6, 1/0.1, 1/0.3$的几何平均，即$(1/0.00018)^{1/5}$；概率为$0.05$的那一个词元贡献了大部分损失。
:::
:::

::: warning 困惑度只有在同一分词器下才可比
困惑度是按词元计的，而不同的分词器会把同一篇文本切成不同数量的词元。词表大的模型使用更少、更长的词元，每个词元都更难预测，因此即使它对文本的建模能力相当，其每词元困惑度也更高。要比较使用不同分词器的模型，应把一篇文本的总对数似然换算成**每字节比特数**（或每字符比特数）：以比特计的总损失除以文本的字节数。信息总量是文本与模型本身的性质，与文本被怎样切分无关。
:::

::: example 单位换算 {#ex-bits-per-byte}
某模型的验证损失为每词元$2.0$纳特，其分词器平均把文本每$4$个字节切成一个词元。给出困惑度、以比特计的每词元损失，以及每字节比特数。
::: solution
困惑度$e^{2.0} = 7.39$。每词元比特数$2.0/\ln2 = 2.885$。每字节比特数$2.885/4 = 0.721$。作为对照，香农（Shannon）1951年根据人类预测实验估计，印刷英语每个字符大约携带$0.6$到$1.3$比特，而英语文本的一个字节通常就是一个字符；gzip 之类的通用压缩器在英语文本上通常能达到每字节几个比特。
:::
:::

## 编码与压缩 {#sec-coding}

熵的编码解释是一条定理，不是比喻。

::: theorem 信源编码定理（香农，1948） {#thm-source-coding}
对分布$p$的结果进行编码的任何唯一可译二进制码，其平均码长都至少为$H(p)$比特；也存在平均码长小于$H(p) + 1$的编码。把独立结果的长序列放在一起编码，每个结果的平均码长可以任意接近$H(p)$。
:::

证明（Cover 与 Thomas，第 5 章）用到 Kraft 不等式：唯一可译码的码长$\ell(x)$满足$\sum_x2^{-\ell(x)}\le1$；于是这些码长定义了一个次概率分布$q(x)\propto2^{-\ell(x)}$，再由吉布斯不等式即知平均码长$\sum_xp(x)\ell(x)$至少为$H(p)$。为模型$q$构造的编码——取码长$\lceil-\log_2q(x)\rceil$——的平均代价为$H(p, q)$比特，最多相差一比特。

**算术编码**（Rissanen，1976；Pasco，1976）去掉了这个取整：给定任意一个序列模型$p_\theta(x_t\mid x_{<t})$，它把整个序列编码成大约$-\log_2p_\theta(x_{1:N}) + 2$比特。因此，一个损失为每词元$L$比特的语言模型配上算术编码，就是一个大约每词元使用$L$比特的无损压缩器。Delétang 等人（2024）用大语言模型演示了这一点：大模型压缩文本远胜于通用压缩器（尽管若模型本身也需要传输，就必须把它计入）。预测与压缩是同一个问题。

## 互信息 {#sec-mutual}

::: definition 条件熵与互信息 {#def-mutual}
设随机变量$X$与$Y$的联合分布为$p(x, y)$，**条件熵**为$H(X\mid Y) = -\sum_{x, y}p(x, y)\log p(x\mid y)$，即已知$Y$之后$X$仍残留的平均不确定性。**互信息**为

$$
I(X; Y) = \operatorname{KL}\big(p(x, y)\,\Vert\,p(x)p(y)\big) = H(X) - H(X\mid Y) = H(Y) - H(Y\mid X).
$$
:::

互信息度量的是：知道一个变量能减少对另一个变量多少不确定性。由[[#thm-gibbs]]，它永不为负，且为零当且仅当$p(x, y) = p(x)p(y)$，即$X$与$Y$独立——与协方差不同，它能察觉任何形式的相关性。因此，条件化在平均意义上从不增加熵，$H(X\mid Y)\le H(X)$：就语言建模而言，更长的上下文只会降低可达到的最优损失，这就是为什么模型随着看到更多上下文而持续变好，只是收益递减。

::: example 两个二元变量的互信息 {#ex-mutual}
$X$与$Y$是二元变量，联合概率为$p(0, 0) = p(1, 1) = 0.4$、$p(0, 1) = p(1, 0) = 0.1$。以比特为单位计算$I(X; Y)$。
::: solution
两个边缘分布都是均匀的，所以$H(X) = 1$比特。给定$Y = y$时，$X$以概率$0.4/0.5 = 0.8$等于$y$，所以$H(X\mid Y) = -0.8\log_20.8 - 0.2\log_20.2 = 0.722$比特。于是$I(X; Y) = 1 - 0.722 = 0.278$比特：观察$Y$大约消除了$X$的四分之一不确定性。
:::
:::

::: application 蒸馏与标签平滑
在**知识蒸馏**（Hinton、Vinyals 与 Dean，2015）中，一个小模型被训练去拟合一个大模型的完整输出分布，最小化$H(p_{\text{教师}}, q_{\text{学生}})$，而不是对 one-hot 标签的交叉熵。由[[#thm-gibbs]]，最小值在$q = p_{\text{教师}}$处取得，所以学生学到的不仅是正确答案，还有教师对整个备选方案的完整排序——这是 one-hot 目标丢弃掉的“暗知识”。**标签平滑**（Szegedy 等人，2016）把 one-hot 目标与均匀分布混合，从而给训练后模型能达到的置信程度设了上限（习题 10）。
:::

::: history
拉尔夫·哈特利（Ralph Hartley，1928）用可能消息数的对数来度量信息量。克劳德·香农（Claude Shannon）的《通信的数学理论》（A Mathematical Theory of Communication，1948）为概率信源定义了熵，证明了信源编码定理与信道编码定理，并用英语的字母和单词$n$元语法统计生成文本作为演示；他的《印刷英语的预测与熵》（Prediction and Entropy of Printed English，1951）通过让人猜下一个字母来估计英语的熵。同样的函数形式早已出现在统计力学中，约西亚·威拉德·吉布斯（Josiah Willard Gibbs）在1902年证明了这条以他命名的不等式。所罗门·库尔贝克（Solomon Kullback）与理查德·莱布勒（Richard Leibler）在1951年提出了以他们命名的散度。大卫·哈夫曼（David Huffman，1952）找到了最优前缀码，约尔马·里萨宁（Jorma Rissanen）与理查德·帕斯科（Richard Pasco）（1976）引入了算术编码。困惑度由杰利内克（Jelinek）、默瑟（Mercer）、巴尔（Bahl）与贝克（Baker）（1977）提出，用作语音识别任务难度的度量，从此一直是语言建模的标准指标。
:::

::: summary
- 一个结果的信息量是$-\log p$；熵$H(p)$是它的期望，介于$0$与$\log K$之间，以比特或纳特计（$1$纳特$= 1.443$比特）。
- 交叉熵$H(p, q)$是模型$q$在来自$p$的数据上的平均惊讶程度，且$H(p, q) = H(p) + \operatorname{KL}(p\,\Vert\,q)$。
- 吉布斯不等式：$\operatorname{KL}(p\,\Vert\,q)\ge0$，等号仅当$p = q$，由$\ln t\le t - 1$证明。因此，最小化交叉熵就是极大似然，也就是最小化模型关于数据的KL散度，而模型的损失至少是信源的熵。
- KL散度不对称：前向方向覆盖各个峰，反向方向寻找峰。预训练用前向方向；RLHF 中的KL惩罚用反向方向。
- 困惑度是$e^{\text{损失}}$，是一个有效分支因子；比较使用不同分词器的模型时要用每字节比特数。语言模型配上算术编码就是一个压缩器，其每词元比特数约等于损失。
- 互信息$I(X; Y) = H(X) - H(X\mid Y)\ge0$能度量任何形式的相关性；条件化在平均意义上从不增加熵。
:::

## 习题

::: exercise 一个熵 {level=1 check="1.5"}
以比特为单位计算分布$(\tfrac12, \tfrac14, \tfrac14)$的熵。
::: solution
$H = \tfrac12\log_22 + 2\cdot\tfrac14\log_24 = 0.5 + 1 = 1.5$比特。
:::
:::

::: exercise 从损失到困惑度 {level=1 check="exp(3)"}
某模型的验证损失为每词元$3.0$纳特。它的困惑度是多少？
::: solution
$\operatorname{PPL} = e^{3.0}\approx20.09$：平均而言，该模型的不确定程度相当于在大约$20$个词元中做均匀选择。
:::
:::

::: exercise 恒定的概率 {level=1 check="3"}
某模型总是给正确的下一个词元分配概率$1/8$。以比特计的每词元损失和困惑度各是多少？
::: solution
每个位置都是$-\log_2(1/8) = 3$比特每词元，所以损失为$3$比特（$2.08$纳特），困惑度为$2^3 = 8$。
:::
:::

::: exercise 两枚硬币之间的KL散度 {level=2 check="0.5*log2(2)+0.5*log2(2/3)"}
设$p = \mathrm{Bern}(0.5)$、$q = \mathrm{Bern}(0.25)$，以比特为单位计算$\operatorname{KL}(p\,\Vert\,q)$，并与$\operatorname{KL}(q\,\Vert\,p)$比较。
::: solution
$\operatorname{KL}(p\,\Vert\,q) = 0.5\log_2\frac{0.5}{0.25} + 0.5\log_2\frac{0.5}{0.75} = 0.5 - 0.292 = 0.2075$比特。反方向上，$\operatorname{KL}(q\,\Vert\,p) = 0.25\log_2\frac{0.25}{0.5} + 0.75\log_2\frac{0.75}{0.5} = -0.25 + 0.439 = 0.189$比特：很接近，但不相等。
:::
:::

::: exercise 一个互信息 {level=2 check="1+0.8*log2(0.8)+0.2*log2(0.2)"}
借用[[#ex-mutual]]，直接计算$\operatorname{KL}\big(p(x, y)\,\Vert\,p(x)p(y)\big)$，验证$I(X; Y)$的值。
::: solution
边缘分布的乘积对每一对都是$0.25$。于是$I = 2\cdot0.4\log_2\frac{0.4}{0.25} + 2\cdot0.1\log_2\frac{0.1}{0.25} = 0.8\cdot0.678 + 0.2\cdot(-1.322) = 0.542 - 0.264 = 0.278$比特，恰如例中所示等于$1 + 0.8\log_20.8 + 0.2\log_20.2$。
:::
:::

::: exercise 每字节比特数 {level=2 check="2/(4*ln(2))"}
模型 A 的分词器平均每个词元对应$4$字节，损失为每词元$2.0$纳特；模型 B 的分词器平均每个词元对应$3$字节，损失为每词元$1.6$纳特。哪个模型对文本建模更好？给出 A 的每字节比特数。
::: solution
A：$2.0/(4\ln2) = 0.721$比特每字节。B：$1.6/(3\ln2) = 0.769$比特每字节。A 对文本建模更好，尽管它的每词元损失（以及困惑度，$7.39$对$4.95$）更高——因为它的词元更长。
:::
:::

::: exercise 独立变量的熵 {level=2}
证明$H(X, Y) = H(X) + H(Y\mid X)$（熵的链式法则），并由$I(X; Y)\ge0$推出$H(X, Y)\le H(X) + H(Y)$，等号成立当且仅当变量独立。熵的链式法则对语言模型在一个序列上的总损失说明了什么？
::: solution
$-\log p(x, y) = -\log p(x) - \log p(y\mid x)$；在$p(x, y)$下取期望即得$H(X, Y) = H(X) + H(Y\mid X)$。由于$I(X; Y) = H(Y) - H(Y\mid X)\ge0$，有$H(Y\mid X)\le H(Y)$，故$H(X, Y)\le H(X) + H(Y)$，等号成立当且仅当$I = 0$，即$X$与$Y$独立。反复使用链式法则得$H(X_1, \dots, X_T) = \sum_tH(X_t\mid X_{<t})$：一个序列的熵是各步下一个词元条件熵之和——这正是语言模型损失所依据的概率链式法则在信息论中的对应物。
:::
:::

::: exercise 高斯分布之间的KL散度 {level=3 check="ln(2)+2/8-1/2"}
对密度为$p = \Normal(\mu_1, \sigma_1^2)$与$q = \Normal(\mu_2, \sigma_2^2)$的一维正态分布，KL散度由积分$\int p\log(p/q)\,dx$定义。证明

$$
\operatorname{KL}(p\,\Vert\,q) = \ln\frac{\sigma_2}{\sigma_1} + \frac{\sigma_1^2 + (\mu_1 - \mu_2)^2}{2\sigma_2^2} - \frac12,
$$

并在$\mu_1 = 0$、$\sigma_1 = 1$、$\mu_2 = 1$、$\sigma_2 = 2$处求值。
::: solution
$\ln p(x) - \ln q(x) = \ln\frac{\sigma_2}{\sigma_1} - \frac{(x - \mu_1)^2}{2\sigma_1^2} + \frac{(x - \mu_2)^2}{2\sigma_2^2}$。在$p$下取期望：$\E_p[(x - \mu_1)^2] = \sigma_1^2$，且$\E_p[(x - \mu_2)^2] = \sigma_1^2 + (\mu_1 - \mu_2)^2$。于是散度为$\ln\frac{\sigma_2}{\sigma_1} - \frac12 + \frac{\sigma_1^2 + (\mu_1 - \mu_2)^2}{2\sigma_2^2}$。代入所给数值：$\ln2 + \frac{1 + 1}{8} - \frac12 = 0.693 + 0.25 - 0.5 = 0.443$纳特。（这个公式对各个坐标求和，就是变分自编码器损失中的KL项。）
:::
:::

::: exercise 由延森不等式证明吉布斯不等式 {level=3}
延森（Jensen）不等式说：对凹函数$\phi$有$\E[\phi(Z)]\le\phi(\E Z)$，当$\phi$严格凹时，等号仅当$Z$以概率$1$为常数时成立。把该不等式用于$\phi = \log$以及$X\sim p$时的$Z = q(X)/p(X)$，给出[[#thm-gibbs]]的第二个证明。
::: solution
把$X\sim p$限制在$S = \{p > 0\}$上，$-\operatorname{KL}(p\,\Vert\,q) = \E\big[\log\frac{q(X)}{p(X)}\big]\le\log\E\big[\frac{q(X)}{p(X)}\big] = \log\sum_{x\in S}q(x)\le\log1 = 0$。延森不等式取等要求$q(x)/p(x)$对所有$x\in S$都是同一个常数$c$，最后一步取等要求$\sum_{x\in S}q(x) = 1$；合起来即$c = 1$且$q = p$。两个证明本质相同：$\ln t\le t - 1$就是$\log$之凹性的切线形式。
:::
:::

::: exercise 标签平滑给损失设界 {level=3 check="-(0.925*ln(0.925)+3*0.025*ln(0.025))"}
在$K = 4$个类别上取标签平滑$\varepsilon = 0.1$，类别$1$的目标为$\mathbf{t} = (1 - \varepsilon)\mathbf{e}_1 + \frac{\varepsilon}{K}\mathbf{1} = (0.925, 0.025, 0.025, 0.025)$，损失为$H(\mathbf{t}, \mathbf{q})$。哪个模型输出$\mathbf{q}$使该损失最小？以纳特计的最小损失是多少？模型被鼓励产生的最大 logit 差距$z_1 - z_j$又是多少？
::: solution
由[[#thm-gibbs]]，$H(\mathbf{t}, \mathbf{q}) = H(\mathbf{t}) + \operatorname{KL}(\mathbf{t}\,\Vert\,\mathbf{q})$在$\mathbf{q} = \mathbf{t}$处最小，最小损失为$H(\mathbf{t}) = -(0.925\ln0.925 + 3\cdot0.025\ln0.025) = 0.072 + 0.277 = 0.349$纳特——不是零；这与 one-hot 目标不同，后者只有当正确类别的 logit 趋于无穷时损失才趋于$0$。要让 softmax 输出恰好等于$\mathbf{t}$，需要$e^{z_1 - z_j} = 0.925/0.025 = 37$，即 logit 差距$\ln37 = 3.61$；而 one-hot 目标没有有限的最优解，logit 会被无限拉开。
:::
:::
