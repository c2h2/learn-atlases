基于人类反馈的强化学习对着一个学出来的奖励模型训练策略，上一章已经看到这会招致什么：策略对着学出来的奖励优化得越用力，就越会去利用奖励的错误。对某些任务，有一条绕开这个问题的路。答案为数值的数学题、带单元测试的编程任务、解可以被检验的谜题、带可校验约束的指令（"恰好用三句话回答"）——对这些任务，奖励可以由一个程序对任意输出精确地计算出来。**基于可验证奖励的强化学习**（reinforcement learning with verifiable rewards，RLVR）就在这样的任务上训练。自 2024 年以来，它一直是训练长时间推理的模型的核心成分，而它产生的行为——长长的思维链、检查、回溯——正是如今大多数人说到"推理模型"时所指的东西。

本章定义 RLVR 及其验证器，推导它使用的策略梯度估计量，并详细分析 **GRPO**（组相对策略优化，group relative policy optimisation；Shao 等，2024）：它的组相对优势作为带基线的 REINFORCE、它与无偏留一（leave-one-out）基线的精确关系、它使用的 KL 估计量，以及完全不含信号的组。接着介绍**专家迭代**（expert iteration）这一更老的方法家族（如 STaR），并说明在模型自己成功的解答上做微调是伪装的策略梯度。然后如实描述 DeepSeek-R1 报告——做了什么、测到了什么、什么被报告为涌现——最后以开放问题收尾：过度思考与长度，以及 RLVR 究竟是教出新的推理，还是磨锐基座模型已有的能力。强化学习的一般背景（策略、回报、PPO）见[[post-training/rl-for-language-models]]与[[post-training/rlhf]]；[[post-training/preference-optimisation]]曾简要介绍过 GRPO。

## 可验证任务 {#sec-tasks}

::: definition 可验证奖励 {#def-verifiable}
提示 $x$ 的**可验证奖励**是一个由程序从模型输出 $y$ 计算、不依赖任何学出来的模型的函数 $r(x, y)$：例如对参考答案 $a^*$ 取 $r = \mathbf 1[\text{抽取的答案} \equiv a^*]$；或抽取出的代码通过的单元测试的比例（或全通过与否）；或证明检查器的接受与否；或可校验格式约束的满足与否。**RLVR** 最大化 $\E_{x\sim\mathcal D,\;y\sim\pi_\theta(\cdot\mid x)}[r(x,y)]$，通常再附加一项对与参考策略散度的惩罚。
:::

这一名称由 Lambert 等（2024）在 Tülu 3 报告中提出，用于数学与精确指令遵循；做法本身更老（STaR、专家迭代、带单元测试的代码生成强化学习）。截至 2026 年，典型的可验证领域有：

- **带最终答案的数学**：竞赛与教科书习题的答案是一个数、一个表达式或一个集合，经归一化后比较（使 $1/2$、$0.5$ 与 `\frac{1}{2}` 判为相同），并常借助计算机代数系统做符号等价判断。
- **代码**：带隐藏测试用例的编程题，在沙盒中运行；奖励为全部通过或通过的比例。
- **形式证明**：命题写在 Lean 一类的证明助手中，检查器对证明精确地接受或拒绝。
- **约束与格式**：字数、必含关键词、合法 JSON、推理分隔符的存在。
- **逻辑谜题**：连同已知解一起生成的谜题（数独、Countdown 式算术、骑士与无赖）。

验证器只对它检查的东西是精确的。数学检查器会接受一个由错误推理得到的正确最终答案（[[reasoning/process-outcome-rewards#ex-false-positive]]）；单元测试会接受对测试特判的代码；格式奖励会接受形式完好的胡说。"可验证"除去的是学出来的奖励模型的错误，除去不了被检查的性质与真正意图之间的落差。

::: example 一个脆弱的解答检查器 {#ex-checker}
某个检查器抽取输出中最后一个数，并与参考答案按字符串比较。参考答案是 `0.5`。下列输出哪些评分正确：(a) "... so the probability is 1/2." (b) "... so $p = 0.50$." (c) "The answer is 0.5, though at step 3 I assumed independence, which is false; the correct answer is 0.25." (d) "Probability: .5"？
::: solution
(a) 最后一个数是 `2`（来自 `1/2`），被记为错，实则正确——一次**假阴性**。(b) `0.50` 不是字符串 `0.5`：假阴性。(c) 最后一个数是 `0.25`，记为错——（由于取值顺序的巧合）判得没错；若是模型写 "0.25 ... is wrong, the answer is 0.5"，检查器反而会接受这个混乱的解答。(d) `.5` 记为错：假阴性。假阴性教会策略害怕正确但格式不同的答案，也让奖励更噪；这就是为什么实用的检查器会解析指定的答案字段（例如 `\boxed{}` 中的表达式）并按符号方式比较取值，也是为什么许多训练配方会增加一项使用该字段的格式奖励。
:::
:::

## 带基线的策略梯度 {#sec-pg}

对单个提示 $x$，记 $J(\theta) = \E_{y\sim\pi_\theta}[r(y)]$（记号中略去 $x$）。**得分函数**（score function）恒等式，即 REINFORCE 恒等式（[[post-training/rl-for-language-models]]）给出

$$
\nabla_\theta J = \E_{y\sim\pi_\theta}\big[r(y)\,\nabla_\theta\log\pi_\theta(y)\big],\qquad \nabla_\theta\log\pi_\theta(y) = \sum_{t}\nabla_\theta\log\pi_\theta(y_t\mid y_{<t}),
$$ {#eq-reinforce}

于是被采样输出的对数概率按其所获奖励成比例地被推高。在 $0/1$ 奖励下，它只推高成功的样本，而且方差很高。减去一个**基线**（baseline）可以同时解决这两点。

::: proposition 基线不会使梯度有偏 {#prop-baseline}
对任何不依赖样本 $y$ 的 $b$，$\E_{y\sim\pi_\theta}\big[(r(y) - b)\nabla_\theta\log\pi_\theta(y)\big] = \nabla_\theta J$。若 $y_1,\dots,y_G$ 是独立样本而 $b_i$ 是除 $y_i$ 以外的样本的任意函数，则 $\E\big[(r(y_i) - b_i)\nabla_\theta\log\pi_\theta(y_i)\big] = \nabla_\theta J$。
:::

::: proof
$\E[\nabla_\theta\log\pi_\theta(y)] = \sum_y\pi_\theta(y)\frac{\nabla_\theta\pi_\theta(y)}{\pi_\theta(y)} = \nabla_\theta\sum_y\pi_\theta(y) = \nabla_\theta1 = 0$，所以常数 $b$ 的期望贡献为零。第二种情形下，以其余样本为条件：此时 $b_i$ 已固定，而 $y_i$ 仍按 $\pi_\theta$ 分布，因为样本相互独立；于是可用第一种情形的结论，再对其余样本取平均，等式保持不变。
:::

最自然的基线就是期望奖励 $J$ 本身；它无法直接知道，却可以用同一提示的其他样本估计出来。GRPO 做的正是这件事。

## 组相对策略优化 {#sec-grpo}

PPO 是 RLHF 的标准算法，它用一个学出来的**价值模型**（value model）——通常是一个与策略一样大的网络——加上广义优势估计来估计每个词元的优势。Shao 等（2024）在 DeepSeekMath 论文里把价值模型换成了同一提示*一组*样本的统计量。

::: definition GRPO {#def-grpo}
对每个提示 $x$，**GRPO** 从当前（旧）策略 $\pi_{\text{old}}$ 采样一组 $G$ 个输出 $o_1,\dots,o_G$，用奖励 $r_1,\dots,r_G$ 打分，并把**组相对优势**

$$
\hat A_i = \frac{r_i - \operatorname{mean}(r_1,\dots,r_G)}{\operatorname{std}(r_1,\dots,r_G)}.
$$ {#eq-grpo-adv}

发给输出 $i$ 的每一个词元。它最大化截断代理目标

$$
\mathcal J(\theta) = \E\Bigg[\frac1G\sum_{i=1}^G\frac1{\lvert o_i\rvert}\sum_{t=1}^{\lvert o_i\rvert}\Big(\min\big(\rho_{i,t}\hat A_i,\ \operatorname{clip}(\rho_{i,t}, 1-\varepsilon, 1+\varepsilon)\hat A_i\big) - \beta\,\hat D_{i,t}\Big)\Bigg],
$$ {#eq-grpo}

其中 $\rho_{i,t} = \pi_\theta(o_{i,t}\mid x, o_{i,<t})/\pi_{\text{old}}(o_{i,t}\mid x, o_{i,<t})$ 是重要性比率，$\varepsilon$ 是截断范围，$\hat D_{i,t} = \frac{\pi_{\text{ref}}(o_{i,t}\mid\cdot)}{\pi_\theta(o_{i,t}\mid\cdot)} - \log\frac{\pi_{\text{ref}}(o_{i,t}\mid\cdot)}{\pi_\theta(o_{i,t}\mid\cdot)} - 1$ 是与参考策略 $\pi_{\text{ref}}$ 的散度的一个估计，加在损失里而不是加在奖励里。
:::

截断的做法沿袭 PPO：同一批数据要用于好几个梯度步，它阻止重要性比率偏离 $1$ 太远。去掉价值模型省下了第二个大网络的显存与计算，也避免了在只有末尾奖励的长序列上学价值函数——那正是价值估计最不可靠的场合。Shao 等还描述了一个带步奖励的过程监督变体；上面这个结果变体是使用最广的。

### 作为基线的优势 {#sec-grpo-baseline}

::: proposition GRPO 的基线，及其缩放 {#prop-grpo-loo}
设 $\bar r = \frac1G\sum_j r_j$，并设 $\bar r_{-i} = \frac1{G-1}\sum_{j\ne i}r_j$ 为留一均值。则

$$
r_i - \bar r = \frac{G-1}{G}\,\big(r_i - \bar r_{-i}\big).
$$

因此去均值优势给出的梯度估计，其期望是 $\frac{G-1}{G}\nabla_\theta J$：只差一个常数因子是无偏的。而除以组标准差会把每个提示的贡献乘上一个依赖于该提示自身奖励的因子，于是合并后的估计不再与 $\sum_x\nabla_\theta J_x$ 成正比。
:::

::: proof
$\bar r = \frac1G r_i + \frac{G-1}G\bar r_{-i}$，所以 $r_i - \bar r = \frac{G-1}{G}r_i - \frac{G-1}{G}\bar r_{-i}$。留一均值不依赖 $o_i$，所以由[[#prop-baseline]]，以 $r_i - \bar r_{-i}$ 为优势的估计量的期望是 $\nabla_\theta J$，而均值去中心化的那个是它的 $\frac{G-1}G$ 倍。标准差依赖整组的所有奖励（包括 $r_i$），并且在提示之间各不相同；除以它会把各提示按 $1/\operatorname{std}$ 重新加权，而且因为它依赖 $r_i$，也与样本本身相关，所以结果不是总梯度任何固定倍数的无偏估计。
:::

留一估计量正是 **RLOO**（REINFORCE leave-one-out），即 Ahmadian 等（2024）为 RLHF 提出的方法；只去均值时，GRPO 就是一个步长略小的 RLOO。除以标准差的效果，在二元奖励下最容易看清。若某提示的成功率为 $p$ 且 $G$ 很大，去均值后的优势成功者为 $1 - p$、失败者为 $-p$，于是优势的平均大小为 $2p(1-p)$，在 $p = 1/2$ 处最大。除以 $\sqrt{p(1-p)}$ 给出优势 $\sqrt{(1-p)/p}$ 与 $-\sqrt{p/(1-p)}$，平均大小 $2\sqrt{p(1-p)}$：几乎总能解出、或几乎总解不出的提示，相对地得到*更多*权重。Liu 等（2025）称这一现象为难度偏差，并在他们的 "Dr. GRPO" 变体中去掉了标准差缩放、也去掉了[[#sec-length]]讨论的 $1/\lvert o_i\rvert$ 长度归一化。

::: widget plot
f: 2*x*(1 - x); 2*sqrt(x*(1 - x))
x: 0, 1
y: 0, 1.1
labels: 去均值优势，$2p(1-p)$; 标准差缩放，$2\sqrt{p(1-p)}$
caption: 大组、$0/1$ 奖励下，某提示的样本获得的优势的平均大小随该提示成功率 $p$ 的变化。不缩放时，中等难度的提示主导更新。GRPO 除以组标准差把曲线压平，让模型几乎总能解出或几乎总解不出的提示得到相对更多的权重——不过在恰好 $p = 0$ 或 $p = 1$ 处两者都为零，因为此时组内每个样本得到相同的奖励。
:::

### 没有信号的组 {#sec-zero}

若某提示的 $G$ 个样本都得到相同的奖励，[[#eq-grpo-adv]] 中的每个优势都是 $0$（实现里会给分母加上一个小常数），该提示除 KL 项外什么也不贡献。在二元奖励、成功率 $p$ 下，这件事发生的概率为

$$
p^G + (1-p)^G.
$$ {#eq-zero-var}

训练早期，许多提示太难（$p\approx0$）；训练后期，许多提示太容易（$p\approx1$）。无论哪种，生成的样本——RLVR 中最贵的部分——都有不断增大的份额被浪费。Yu 等（2025）在 DAPO 配方里把这类组过滤掉，并持续采样直到每个批次都装满结果好坏参半的提示（"动态采样"）；挑选中等难度提示的课程安排解决的是同一个问题。

::: example 一组内的优势 {#ex-grpo}
某提示的一组 $G = 8$ 个输出得到奖励 $(1, 0, 0, 1, 0, 0, 0, 0)$。计算 GRPO 优势、去均值优势与留一优势，并验证[[#prop-grpo-loo]]。
::: solution
均值 $\bar r = 0.25$，（总体）标准差 $\sqrt{0.25\cdot0.75} = 0.433$。去均值优势：两个成功者为 $0.75$，六个失败者为 $-0.25$。GRPO 除以 $0.433$：$1.732$ 与 $-0.577$。留一：成功者的基线是其余七个的均值 $1/7$，其优势为 $0.857$；失败者的基线是 $2/7$，优势 $-0.286$。并且 $\frac78\cdot0.857 = 0.75$、$\frac78\cdot(-0.286) = -0.25$，与命题所说一致。注意优势之和为零：两个成功者被推高的总量，与六个失败者被压低的多分毫不差。
:::
:::

::: example 一个批次浪费了多少？ {#ex-waste}
一个训练批次中，一半提示在当前策略下的成功率为 $p = 0.9$，另一半为 $p = 0.05$。$G = 8$ 时，有多大比例的提示给出零方差的组？
::: solution
$p = 0.9$：$0.9^8 + 0.1^8 = 0.4305$。$p = 0.05$：$0.05^8 + 0.95^8 = 0.6634$。平均为 $0.547$：超过一半的提示、因而超过一半的生成计算，产生不了策略梯度。把 $G$ 增到 $16$ 可把这一比例降到 $\frac12(0.185 + 0.440) = 0.313$，代价是每个提示的采样费用翻倍。过滤提示、使 $p$ 远离 $0$ 与 $1$，通常更便宜。
:::
:::

::: example 单元测试的部分学分 {#ex-partial}
一道编程题有 $10$ 个隐藏测试，奖励为通过的比例。一组 $G = 4$ 个程序分别通过 $10$、$6$、$6$、$0$ 个测试。计算 GRPO 优势，并与全有或全无的奖励比较。
::: solution
奖励 $(1, 0.6, 0.6, 0)$，均值 $0.55$；偏差 $(0.45, 0.05, 0.05, -0.55)$，总体方差 $(0.2025 + 0.0025 + 0.0025 + 0.3025)/4 = 0.1275$，标准差 $0.357$。优势：$(1.260, 0.140, 0.140, -1.540)$。两个部分通过的程序被*略微推高*，尽管它们谁也没有解出题。全有或全无的奖励 $(1, 0, 0, 0)$ 下优势为 $(1.732, -0.577, -0.577, -0.577)$：部分通过的程序与空手而归的那个一起被压低。部分学分在没有任何样本完全解出的提示上提供了信号，但它也奖励通过简单的测试——而这可以靠特判做到——所以这一选择是更稠密的信号与更易被利用的信号之间的权衡。
:::
:::

### KL 估计量 {#sec-k3}

::: proposition 一个无偏、非负的 KL 估计 {#prop-k3}
设 $\pi$ 与 $\pi_{\text{ref}}$ 是词元上的两个分布，且在 $\pi(v) > 0$ 处恒有 $\pi_{\text{ref}}(v) > 0$，令 $w(v) = \pi_{\text{ref}}(v)/\pi(v)$。则对 $v\sim\pi$，量 $w - \log w - 1$ 非负，且 $\E_{v\sim\pi}[w - \log w - 1] = \mathrm{KL}(\pi\,\Vert\,\pi_{\text{ref}})$。
:::

::: proof
对 $w > 0$，$w - 1\ge\log w$（对数位于其在 $1$ 处切线的下方），故 $w - \log w - 1\ge0$。期望方面，$\E_\pi[w] = \sum_v\pi(v)\frac{\pi_{\text{ref}}(v)}{\pi(v)} = \sum_{v:\pi(v) > 0}\pi_{\text{ref}}(v)\le1$，在两个方向的支持条件下取等（softmax 分布即是，它处处为正）。而 $\E_\pi[-\log w] = \sum_v\pi(v)\log\frac{\pi(v)}{\pi_{\text{ref}}(v)} = \mathrm{KL}(\pi\Vert\pi_{\text{ref}})$。相加得 $\E[w - \log w - 1] = 1 + \mathrm{KL} - 1 = \mathrm{KL}$。
:::

这就是 Schulman 那篇关于近似 KL 散度的著名笔记中的 "$k_3$" 估计量。与朴素估计 $-\log w$ 不同，它在单个采样词元处的取值永不为负，而且两个分布接近时方差更低。这项惩罚把策略留在参考策略附近；一些后来的 RLVR 配方（DAPO 就在其中）在长推理训练里把它完全去掉了，理由是策略本来就*应当*远离自己的初始化；另一些配方则保留了小系数。

## 专家迭代与 STaR {#sec-expert}

在策略梯度方法成为推理的标准做法之前，人们使用一个更简单的循环：采样解答，保留通过检查的那些，在其上微调，然后重复。Anthony 等（2017）把这一般模式称为**专家迭代**（expert iteration）——一个"专家"（搜索，或多样本加过滤）产出比"学徒"策略更好的输出，而学徒被训练去模仿它们。

::: algorithm 自学推理器（STaR） {#alg-star}
**输入：**预训练模型 $M_0$，数据集 $\{(x_i, a_i^*)\}$，少样本推理依据提示 $P$。
1. 对 $k = 1, 2, \dots$：
2. 对每个 $x_i$，用 $P$ 提示 $M_{k-1}$，生成推理依据与答案 $(z_i, \hat a_i)$。
3. **合理化：**对每个 $\hat a_i\ne a_i^*$ 的 $x_i$，把正确答案作为提示给出、生成一条推理依据，若它能推出 $a_i^*$ 就保留它（连同答案提示一起去掉）。
4. 在全部保留的 $(x_i, z_i, a_i^*)$ 上微调*原始*模型 $M_0$，得到 $M_k$。
5. 当性能不再提升时停止。
:::

Zelikman 等（2022）报告，STaR 改进了一个 $60$ 亿参数的 GPT-J 模型在算术与 CommonsenseQA 上的表现，后者上它与一个约大三十倍、经过微调的 GPT-3 模型不相上下。合理化让模型能从自己还不会做的题中学习，代价是推理依据可能只是因为被告知了答案才到达答案。相关方法包括拒绝采样微调（Yuan 等，2023）与 ReST-EM（Singh 等，2023）；后者把这个循环表述为期望-最大化，并发现自生成数据在数学与代码的微调上可以胜过人类撰写的解答。

::: theorem 过滤后的微调是策略梯度 {#thm-filtered}
设奖励为二元，$J_x(\theta) = \Prob_{y\sim\pi_\theta(\cdot\mid x)}(r(x,y) = 1)$。对每个提示从 $\pi_\theta$ 抽 $n$ 个样本，在当前参数处对成功样本做一步极大似然梯度 $\sum_x\sum_j r(x, y_{x,j})\log\pi_\theta(y_{x,j}\mid x)$。其期望梯度为 $n\sum_x\nabla_\theta J_x$。若改为对每个提示的成功样本取平均（每道解出的提示记一份权重），则一道解出提示该项的期望梯度为 $\nabla_\theta\log J_x$。
:::

::: proof
对单个样本，由[[#eq-reinforce]]，$\E[r\nabla\log\pi_\theta(y)] = \nabla J_x$；对 $n$ 个样本与全部提示求和即得第一条。第二条：以样本成功为条件，其分布为 $\pi_\theta(y\mid r = 1) = \pi_\theta(y)r(y)/J_x$，于是

$$
\E[\nabla\log\pi_\theta(y)\mid r = 1] = \sum_y\frac{\pi_\theta(y)r(y)}{J_x}\nabla\log\pi_\theta(y) = \frac{\nabla J_x}{J_x} = \nabla\log J_x,
$$

成功样本的平均值有相同的期望。
:::

于是，保留全部成功样本就是 $0/1$ 奖励、无基线的 REINFORCE；按提示归一化则是在最大化 $\sum_x\log J_x$，它把提示的梯度加权 $1/J_x$，从而强调那些只是偶尔被解出的难提示。两者都不使用失败样本：它们奖励为 $0$，直接被丢弃；而基线会赋予它们负优势、压低其概率。专家迭代还迈大步——每轮在固定的较早策略的数据上做一次完整微调——所以实践中它以某种方式是"异策略"（off-policy）的，而定理中在当前参数处迈出的那一步则不是。

## DeepSeek-R1 {#sec-r1}

DeepSeek-R1 报告（DeepSeek-AI，2025 年 1 月；修订版于 2025 年 9 月发表于《自然》（*Nature*））描述了从基座模型 DeepSeek-V3——一个混合专家（MoE）Transformer——训练两个推理模型的过程，并发布了它们的权重。作为当时最详细的大规模 RLVR 公开记录，值得一一如其所述地介绍。

**DeepSeek-R1-Zero** 用 GRPO *直接从基座模型*训练，事先不做监督微调。提示要求模型把推理放在 `<think>` 与 `</think>` 标签之间、把答案放在 `<answer>` 标签之间。奖励基于规则：**准确率奖励**（答案对照参考答案检验，或代码对照测试用例运行）和使用标签的**格式奖励**。报告解释了为何避开神经奖励模型：大规模下会出现奖励破解（[[reasoning/process-outcome-rewards#sec-r1-prm]]）。报告的结果与观察：

- AIME 2024 数学竞赛的 pass@1 在训练中从 $15.6\%$ 升到 $71.0\%$；对 $64$ 个样本做多数投票则达 $86.7\%$。
- 回复的平均长度在训练中稳定增长，从几百个词元增至几千个，而长度并没有得到任何明确的激励；报告把这一点解读为模型学会了在更难的题上投入更多测试时计算。
- 诸如复查前面的步骤、尝试替代做法这样的行为在训练中出现；报告展示了一个中间检查点写道自己到达了一个"顿悟时刻"（aha moment）并重新评估自己的解答。
- 它的输出可读性差、语言混杂。

**DeepSeek-R1** 用一个多阶段流程解决了这些问题：(1) 在数千条以可读格式书写的长思维链样例的**冷启动**（cold start）数据上做监督微调；(2) 面向推理的强化学习，用同样的规则奖励，外加一项**语言一致性奖励**（目标语言词所占的比例），报告指出它略微拉低了基准分数，但改善了可读性；(3) 从所得检查点做**拒绝采样**，构造约 $600{,}000$ 条推理性样例，配上约 $200{,}000$ 条非推理性样例（写作、事实问答、翻译），做第二轮监督微调；(4) 覆盖各类提示的最后一个强化学习阶段，推理用规则奖励，一般的有用性与无害性用奖励模型。报告给出 R1 的 AIME 2024 pass@1 为 $79.8\%$，MATH-500 准确率为 $97.3\%$。

报告还把 R1 **蒸馏**进更小的开放模型（$15$ 亿到 $700$ 亿参数的 Qwen 与 Llama 模型）——办法是在其输出上做监督微调——并与直接在 $320$ 亿参数的基座模型上做强化学习作比较：蒸馏得到的模型强得多（报告的 AIME 2024 pass@1 为 $72.6\%$ 对 $47.0\%$）。其结论是：对小模型而言，蒸馏一个更强的模型比对它们自己做强化学习更有效；而要超越最强的模型，可能仍然需要强化学习与更大的基座模型。报告还列出了**没有成功的尝试**：过程奖励模型，以及在推理步骤上做蒙特卡洛树搜索——后者失败的原因是词元序列的空间远比棋盘游戏大，细粒度的价值模型难以训练。

同一时期，其他开发者发表了相关报告。Kimi k1.5（Kimi Team，2025）描述了不使用树搜索、价值函数或过程奖励模型的长上下文强化学习，带一项**长度惩罚**，并给出把长链行为迁移到较短输出的方法。OpenAI 的 o1 公告（2024 年 9 月）报告性能随更多强化学习训练算力与更多思考时间而提升，但未公开训练方法；关于未公开系统，在这些陈述之外的描述都是猜测，本文不予复述。

::: warning "涌现"行为是被报告的现象，不是机制
R1-Zero 中回复长度的增长与自我检查行为的出现，来自一次训练过程的测量与示例，并由其作者作出解读。后来的分析给出了其他可能的促成解释：有些基座模型在任何强化学习之前就已经会产出自我反思的短语（Liu 等，2025），而 GRPO 损失的逐序列长度归一化本身就可能偏爱更长的错误回复（[[#sec-length]]）。这些行为是真实的、并在多个开放复现中可重复；*为什么*会出现、其中多少是新学会的、多少只是被放大，截至 2026 年仍是开放的研究问题。
:::

## 长度、过度思考与强化学习增添了什么 {#sec-length}

**损失的长度偏差。** [[#eq-grpo]] 中每个输出的词元项按其自身长度 $\lvert o_i\rvert$ 取平均。对一个优势为负的输出，每个词元都以 $\hat A_i/\lvert o_i\rvert$ 的权重被压低，于是一条长的错误回答*每个词元*受到的惩罚比短的错误回答*更轻*；对正优势，短回答每个词元得到的奖励更多。Liu 等（2025）认为这使 GRPO 偏向长的错误回答，Dr. GRPO 与 DAPO 都改用常数或批次的词元总数来归一化。DAPO 还引入了 "clip-higher"（更大的上侧截断范围，让低概率词元更快获得概率，从而对抗策略熵的坍缩），以及对超长被截断输出的惩罚。

**过度思考。** 推理模型常常花掉远超问题所需的词元。Chen 等（2024）记录了这样训练的模型在 $2 + 3$ 这样简单的问题上产出几百个词元与反复多轮的验证，并提出效率度量、以及把这类输出训短的方法。已发表配方中的对策包括长度惩罚、把样本长度与组内长度相比较的奖励、在最短的正确样本上训练，以及推理时的显式预算（[[reasoning/test-time-scaling]]）。

**磨锐还是新能力？** Yue 等（2025）用直到数百的 $k$ 的 pass@$k$ 比较了基座模型与其 RLVR 训练版本。RLVR 模型在小 $k$ 处明显领先，但基座模型在大 $k$ 处追了上来、而且常常反超；并且 RL 模型解出的题大体上是基座模型用足够多样本也能解出的那些题的子集。他们的解读：RLVR 主要提升了采样基座模型*已有*的正确路径的*效率*，同时收窄了探索；相比之下，从更强的模型蒸馏则可能带来新的题目。也有工作争论这一结论的普遍性：Liu 等（2025，"ProRL"）报告，带 KL 控制、并周期性重置参考策略的长时间强化学习，在某些任务上扩大了 pass@$k$，在基座模型较弱的任务上尤其如此。而 Shao 等（2025）发现，在某个基座模型家族上，即便用随机奖励甚至错误奖励做 RLVR，数学分数仍大幅上升，而其他模型家族则不然——这是证据，表明一部分已报告的收益反映的是把某些预训练模型中本已潜伏的行为激发出来。这些都是特定模型与基准上的新近结果；下面的清单在一个按构造必然出现磨锐效应的玩具问题上把它复现出来。

::: quiz
在二元奖励、组大小 $G = 4$ 的 GRPO 中，某提示的一组奖励为 $(1, 1, 1, 1)$。哪些说法正确？（多选。）
- [x] 四个优势都是零，所以该提示的策略梯度项消失。
- [x] KL 惩罚项仍可能为该提示产生梯度。
- [ ] 更新会提高四个输出的概率，因为它们全是对的。
- [ ] 留一基线会给每个输出 $1$ 的优势。
::: solution
奖励全相同时，对每个 $i$ 有 $r_i - \bar r = 0$，只剩 KL 项。每个输出的留一基线是其余三个的均值 $1$，所以它的优势同样是 $1 - 1 = 0$。关于这个提示，从奖励中学不到任何东西；这正是[[#eq-zero-var]]所量化的浪费。
:::
:::

## 数值实验室 {#sec-code}

清单先为一组样本算出 GRPO、去均值与留一优势（[[#ex-grpo]]）。然后在一个玩具策略上训练——$40$ 道题共用的、对五个解法"方法"的 softmax——用 GRPO 优势做普通策略梯度步（不截断、无 KL）。方法 $0$ 在 $32$ 道普通题上以概率 $0.6$ 奏效；$8$ 道"古怪"题则只有方法 $4$ 能解。pass@$k$ 由策略精确计算。

```python
import math, random
rng = random.Random(4)

# 1. GRPO 优势：一组 G = 8 个采样答案，0/1 奖励
def grpo_adv(r, eps=1e-6):
    m = sum(r) / len(r)
    sd = math.sqrt(sum((x - m)**2 for x in r) / len(r))
    return [(x - m) / (sd + eps) for x in r]
def loo_adv(r):                                   # 留一（RLOO）基线
    G = len(r)
    return [x - (sum(r) - x) / (G - 1) for x in r]
r = [1, 0, 0, 1, 0, 0, 0, 0]
print("rewards      ", r)
print("GRPO         ", [round(a, 3) for a in grpo_adv(r)])
print("mean baseline", [round(x - sum(r) / len(r), 3) for x in r])
print("leave-one-out", [round(a, 3) for a in loo_adv(r)])
print("all correct  ", [round(a, 3) for a in grpo_adv([1] * 8)])

# 2. 一个玩具策略：40 道题共用的、对 5 个解法"方法"的 softmax。
# 方法 0 在多数题上有效；方法 4 是唯一能解 8 道"古怪"题的方法。
M, Q = 5, 40
succ = [[0.6, 0.3, 0.2, 0.1, 0.05] if q < 32 else [0.0, 0.0, 0.0, 0.0, 0.5] for q in range(Q)]
theta = [0.0] * M

def probs(th):
    z = [math.exp(t - max(th)) for t in th]; s = sum(z); return [v / s for v in z]
def pass_at_k(th, k):                             # 精确计算，对题目取平均
    p = probs(th)
    return sum(1 - (1 - sum(pm * s for pm, s in zip(p, succ[q])))**k for q in range(Q)) / Q

print("\nstep  pass@1  pass@16  P(method 0)  zero-variance groups")
print(f"{0:4d}  {pass_at_k(theta, 1):6.3f}  {pass_at_k(theta, 16):7.3f}  {probs(theta)[0]:11.3f}")
G, lr = 8, 0.5
for step in range(1, 201):
    grad, zero = [0.0] * M, 0
    p = probs(theta)
    for q in range(Q):
        ms = [rng.choices(range(M), p)[0] for _ in range(G)]
        rs = [1.0 if rng.random() < succ[q][m] else 0.0 for m in ms]
        if min(rs) == max(rs):
            zero += 1; continue                   # 本组没有学习信号
        for m, a in zip(ms, grpo_adv(rs)):
            for j in range(M):                    # d log softmax_m / d theta_j
                grad[j] += a * ((j == m) - p[j]) / (G * Q)
    theta = [t + lr * g for t, g in zip(theta, grad)]
    if step % 50 == 0:
        print(f"{step:4d}  {pass_at_k(theta, 1):6.3f}  {pass_at_k(theta, 16):7.3f}  {probs(theta)[0]:11.3f}  {zero:9d} of {Q}")
```

mean baseline [0.75, -0.25, -0.25, 0.75, -0.25, -0.25, -0.25, -0.25]

强化学习把 pass@$1$ 从 $0.22$ 翻倍到 $0.475$，办法是把策略集中到方法 $0$ 上。但 pass@$16$ *掉*了，从 $0.955$ 到 $0.806$：随着方法 $4$ 变得罕见，古怪题几乎再也解不出，它们的组全是零，策略也就得不到让方法 $4$ 存续下去的信号。这就是[[#sec-length]]中磨锐与探索之权衡的缩影——也是 RLVR 配方在意熵、截断范围与提示挑选的原因。

::: history
对带测试用例奖励的程序与形式证明做强化学习早于大语言模型；对语言模型而言，用模型自己找到、并被证明检查器接受的证明做训练，见于 Polu 与 Sutskever（2020，Metamath），而作为专家迭代则见于 Polu 等（2022，Lean）。Zelikman 等（2022）提出 STaR；Yuan 等（2023）与 Singh 等（2023）研究了拒绝采样微调与 ReST-EM。Shao 等（2024）随 DeepSeekMath 提出 GRPO；Ahmadian 等（2024）主张在 RLHF 中用 RLOO 这类 REINFORCE 式方法取代 PPO。OpenAI 于 2024 年 9 月发布 o1。Lambert 等（2024）在 Tülu 3 报告中命名了 RLVR。2025 年 1 月，DeepSeek-AI 发布 DeepSeek-R1 与 R1-Zero，附公开报告与权重，Kimi 团队发布了 k1.5 报告；随后涌现大量开放复现，以及 DAPO（Yu 等，2025）、Dr. GRPO（Liu 等，2025）等算法改进，还有关于 RLVR 究竟改变了什么的研究（Yue 等，2025）。
:::

::: summary
- **RLVR** 对着由程序计算的奖励优化策略——答案检查器、单元测试、证明检查器、格式规则——这除去了学出来的奖励的错误，却除不去被检查的性质与真正意图之间的落差。
- REINFORCE 梯度 $\E[r\nabla\log\pi]$ 对任何不依赖样本的基线都是无偏的；**GRPO** 使用组均值并除以组标准差，配上 PPO 式的截断，以及由 $w - \log w - 1$ 估计的 KL 惩罚——该估计无偏且非负。
- 去均值优势是无偏**留一**（RLOO）优势的 $\frac{G-1}{G}$ 倍；标准差缩放会把权重移向极容易与极难的提示。
- 组内奖励全同则没有梯度；这以概率 $p^G + (1-p)^G$ 发生，若不过滤提示会浪费大量采样预算。
- **专家迭代 / STaR** 在模型自己成功的解答上微调；这是 $0/1$ 奖励、无基线的 REINFORCE（按提示归一化时，则是在对 $\sum\log J_x$ 做梯度上升）。
- **DeepSeek-R1-Zero**（对基座模型直接用准确率与格式奖励做 GRPO）把 AIME 2024 的 pass@1 从 $15.6\%$ 提到 $71.0\%$，回复长度在训练中增长；**R1** 加上了冷启动、语言一致性奖励、拒绝采样 SFT 与一个一般强化学习阶段；蒸馏进小模型胜过对它们直接做强化学习。
- 开放问题：长度偏差与**过度思考**，以及 RLVR 是增添能力、还是主要磨锐基座模型的分布（大 $k$ 处的 pass@$k$）。
:::

## 习题

::: exercise 四个样本 {level=1 check="1"}
一组 $G = 4$ 个输出的奖励为 $(1, 1, 0, 0)$。按[[#eq-grpo-adv]]、用总体标准差，每个正确输出得到多大的 GRPO 优势？
::: solution
均值 $0.5$，标准差 $0.5$；正确输出得 $(1 - 0.5)/0.5 = 1$，错误输出得 $-1$。
:::

::: exercise 一道容易的提示 {level=1 check="0.4305"}
某提示以概率 $0.9$ 被解出。$G = 8$ 时，它的组不携带任何策略梯度信号的概率是多少？给出四位小数。
::: solution
由[[#eq-zero-var]]，$0.9^8 + 0.1^8 = 0.43047 + 10^{-8} = 0.4305$。
:::
:::

::: exercise 单个词元上的 KL 估计 {level=1 check="0.0231"}
在某个采样词元处，$\pi_{\text{ref}}/\pi_\theta = 0.8$。计算 $\hat D = w - \log w - 1$，精确到四位小数，并与朴素估计 $-\log w$ 比较。
::: solution
$0.8 - \ln0.8 - 1 = 0.8 + 0.22314 - 1 = 0.0231$。朴素估计为 $-\ln 0.8 = 0.2231$，在这个词元上大了十倍，而且它在 $w > 1$ 的词元上会是负数；两者的期望相同，都是 $\mathrm{KL}(\pi_\theta\Vert\pi_{\text{ref}})$，但 $\hat D$ 永不为负，且两个策略接近时波动更小。
:::
:::

::: exercise 每步的生成计算量 {level=2 check="3.03e17"}
一次 RLVR 步从一个每词元激活 $370$ 亿参数的混合专家模型采样 $512$ 条输出（例如 $32$ 个提示、每提示 $G = 16$），平均每条 $8{,}000$ 个词元。按每词元每激活参数 $2$ FLOPs 计算，一步的生成要花多少 FLOPs？给出三位有效数字。
::: solution
$512\cdot8000 = 4.096\times10^6$ 个词元；$2\cdot37\times10^9\cdot4.096\times10^6 = 3.03\times10^{17}$ FLOPs，忽略注意力项。梯度计算在同一批词元上的花费约为前向 FLOPs 的三倍（训练每词元 $6N$，一次前向 $2N$），但生成在墙钟时间上通常更慢，因为解码受内存限制（[[inference]]）；这就是 RLVR 系统在快速推理引擎上投入重金的原因。
:::
:::

::: exercise 坍缩的玩具策略 {level=2 check="0.48"}
设清单里的玩具策略完全坍缩到方法 $0$ 上。精确计算它对 $40$ 道题取平均的 pass@$1$ 与 pass@$16$。
::: solution
方法 $0$ 以概率 $0.6$ 解出 $32$ 道普通题中的每一道，而且从不解出 $8$ 道古怪题。pass@$1 = 32\cdot0.6/40 = 0.48$。pass@$16 = 32(1 - 0.4^{16})/40 = 0.8(1 - 4.3\times10^{-7})\approx0.8000$。清单在 $200$ 步处的值 $0.475$ 与 $0.806$ 正逼近这两个极限；初始的均匀策略 pass@$16 = 0.955$，因为它还在尝试方法 $4$。
:::

::: exercise 从头验证留一法 {level=2}
不使用[[#prop-baseline]]，直接证明：对 $G = 2$ 个样本，估计量 $\frac12\sum_{i=1}^2(r_i - r_{3-i})\nabla\log\pi_\theta(o_i)$ 的期望是 $\nabla_\theta J$。
::: solution
由对称性，只需证 $\E[(r_1 - r_2)\nabla\log\pi(o_1)] = \nabla J$。由于 $o_1$ 与 $o_2$ 独立，$\E[r_2\nabla\log\pi(o_1)] = \E[r_2]\,\E[\nabla\log\pi(o_1)] = J\cdot0 = 0$，其中用到 $\E[\nabla\log\pi] = \sum\nabla\pi = 0$。而由得分函数恒等式，$\E[r_1\nabla\log\pi(o_1)] = \nabla J$。于是每一项的期望都是 $\nabla J$，两项的平均也是。
:::
:::

::: exercise 过滤微调下的困难提示 {level=2}
两道提示的成功率为 $J_A = 0.5$ 与 $J_B = 0.02$。按[[#thm-filtered]]，比较 (a) 保留全部成功样本的 REINFORCE 与 (b) 按提示归一化的过滤微调，在提升每道提示的成功概率上给出的相对权重。哪一种更接近"配合多样本采样最大化解出提示数"这一目标？
::: solution
(a) 期望梯度与 $\nabla J_A + \nabla J_B$ 成正比：任一成功率的单位提升都值同样的钱，所以更新跟着哪道提示的成功率更容易移动走。(b) 目标是 $\log J_A + \log J_B$，其梯度为 $\nabla J_A/0.5 + \nabla J_B/0.02$：提示 B 的改进算 $25$ 倍重。若系统最终会带验证器用许多样本，要紧的是每道提示是否至少偶尔被解出（大 $k$ 的 pass@$k$），而 $\log J$ 奖励把罕见的成功变得不那么罕见；最大化 $\sum J$ 则奖励把容易的提示做得可靠。这是理解"基于采样的强化学习会牺牲罕见解、磨锐分布"的一种方式，正如清单所示。
:::
:::

::: exercise 长度归一化 {level=3}
考虑[[#eq-grpo]]在 $\rho = 1$、无截断也无 KL 时的形式。一组里含一个 $100$ 词元的正确输出与一个错误输出（$100$ 词元或 $1{,}000$ 词元），优势分别为 $+1$ 与 $-1$。(a) 每种情形下，各输出在对数概率梯度上得到的总权重是多少？(b) 解释由此产生的偏差，以及把 $1/\lvert o_i\rvert$ 换成固定常数下的 $1/L_{\max}$ 会怎样改变它。
::: solution
(a) 输出 $i$ 的每个词元权重为 $\hat A_i/(G\lvert o_i\rvert)$，所以每个输出的总权重为 $\hat A_i/G$，与长度无关：两种情形下都是 $+\frac12$ 与 $-\frac12$。但按词元算，长的错误输出的词元得到 $-\frac{1}{2000}$，而短的是 $-\frac1{200}$。(b) 序列对数概率的梯度是对词元求和；把固定的总惩罚摊到十倍多的词元上，每个词元被压低十倍之少，于是让长错误回答之所以长的那些词元——重复、填充、东拉西扯——几乎不受打压，而短错误回答的词元被强力打压。许多次更新之后，这便偏爱长的错误回答甚于短的。改用 $1/L_{\max}$ 后每个词元的权重为 $\hat A_i/(GL_{\max})$，于是长输出的总权重与其长度成正比：长的错误回答按长度成比例地受罚，长的正确回答也按长度成比例地受奖。这正是 Dr. GRPO（用常数）与 DAPO（用批次词元总数）所做的改动。
:::
:::

::: exercise 在玩具问题上实现专家迭代 {level=3}
把清单的训练循环改成做专家迭代而非 GRPO：每轮对每题采样 $G = 8$ 个输出，保留成功的，然后在保留下来的（题目，方法）对上、从当前参数出发做 $20$ 步极大似然梯度。跑 $10$ 轮，报告 pass@$1$ 与 pass@$16$。与 GRPO 比较，并用[[#thm-filtered]]解释结果。
::: solution
```python
import math, random
rng = random.Random(5)
M, Q = 5, 40
succ = [[0.6, 0.3, 0.2, 0.1, 0.05] if q < 32 else [0.0, 0.0, 0.0, 0.0, 0.5] for q in range(Q)]
def probs(th):
    z = [math.exp(t - max(th)) for t in th]; s = sum(z); return [v / s for v in z]
def pass_at_k(th, k):
    p = probs(th)
    return sum(1 - (1 - sum(pm * s for pm, s in zip(p, succ[q])))**k for q in range(Q)) / Q

theta = [0.0] * M
for rnd in range(1, 11):
    p = probs(theta)
    kept = []
    for q in range(Q):
        for _ in range(8):
            m = rng.choices(range(M), p)[0]
            if rng.random() < succ[q][m]:
                kept.append(m)
    for _ in range(20):                            # 对保留的方法做极大似然
        p = probs(theta)
        grad = [sum((j == m) - p[j] for m in kept) / len(kept) for j in range(M)]
        theta = [t + 0.5 * g for t, g in zip(theta, grad)]
    print(f"round {rnd:2d}  pass@1 {pass_at_k(theta, 1):.3f}  pass@16 {pass_at_k(theta, 16):.3f}  kept {len(kept)}")
```
