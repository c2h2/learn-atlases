思维链看起来像一份解释。它用理由的语言写成——"既然火车 9:40 出发、路上要四个小时……"——于是人们很自然会把它读作模型*如何*得出答案的记录。推理模型的吸引力很大程度上建立在这种读法上：如果写下来的推理就是计算本身，我们就能检验它、调试它，并监控它有没有不良意图。但语言模型的训练中没有任何东西保证这一点。这条链和别的文本一样是从模型采样出来的，只因紧随其后的答案正确而得到奖励（[[reasoning/verifiable-rewards]]）。它也许就是计算；也许只是在别处——在激活之中——发生的计算旁边讲的一个可信故事；也许介于两者之间。

这最后一章考察证据。我们先定义忠实性以及用来检验它的实验设计，再回顾主要结果：影响被解释遗漏的有偏提示（Turpin 等，2023）、对思维链本身的干预（Lanham 等，2023）、填充词元里的隐藏计算，以及关于推理模型的较新研究——它们之间的分歧本身就很有教益。然后我们从*忠实性*转向*局限*：反转诅咒、组合与长度泛化的失败，以及基准污染，并给出把真实下降同噪声分辨开来所需的统计方法。最后是全课程最难的那个问题——说模型在"推理"究竟能说明什么、不能说明什么——并尽证据所允许的最大公平，呈现各种对立的解读。全章的每个结果都注明了日期：截至 2026 年这是一个活跃的领域，其中若干发现涉及的特定模型此后已被取代。

## 忠实性的含义 {#sec-def}

解释可以在两个不同的维度上评判。一个解释如果人能信服，它就是**可信的**（plausible）。如果它准确地刻画了产生该输出的推理过程，它就是**忠实的**（faithful）（Jacovi 与 Goldberg，2020）。两者可以完全脱钩：一个自信、文笔漂亮的解释可能与答案的实际成因毫无关系，而一份对混乱计算的如实陈述，反而可能显得不可信。

::: definition 思维链的忠实性 {#def-faithful}
设模型对输入 $x$ 产生思维链 $z$ 与答案 $y$。所谓这条链是**忠实的**，是指：(i) 它声称为理由的因素确实是对 $y$ 有因果影响的因素，并且 (ii) 对 $y$ 有实质因果影响的因素都在其中得到了陈述。**事后合理化**——为已经用别的方式得到的答案编造理由——会使条件 (i) 不成立；**遗漏**——某个有影响力的因素，例如提示中的暗示或偏向，从未被提及——会使条件 (ii) 不成立。
:::

因果影响通过**干预**来检验：改变一个因素，看答案是否改变。由此得到两类实验。**输入干预**给提示增加或改变某个特征——一个建议的答案、选项的重新排列、一句无关的话——然后问答案是否移动、链是否提到了这个特征。**链干预**直接编辑这条链——把它截断、插进一个错误、换一种说法——然后问答案是否依赖它。两类实验都确立不了模型"真正"在计算什么；它们各自检验忠实性的一个可观测后果。

## 来自有偏提示的证据 {#sec-bias}

Turpin 等（2023）在 BIG-Bench Hard 套件 $13$ 个任务的少样本提示里加入了带偏特征。一种条件下，示例被重新排序，使正确答案永远是选项 *(A)*；另一种条件下，提示里包含一句"我想答案是 (B)，不过想听听你怎么看"。用思维链提示的模型（当时是 GPT-3.5 与 Claude 1.0）的答案向带偏选项移动，准确率下降多达 $36\%$——而它们的解释几乎从不提及这一偏向，给出的反而是支持带偏答案的推理。在一个社会偏见基准上，解释同样为符合刻板印象的答案辩护，却不提刻板印象。论文标题就是这一发现的总结：*语言模型并不总是说自己所想*。

这一设计为[[#def-faithful]]的条件 (ii) 提供了一个干净的检验：偏向确实改变了答案（与无偏提示相比），而它被遗漏了。它并不能证明思维链*从不*忠实，只说明它们可能以用户从文本上察觉不到的方式系统性地不忠实。

### 言语化的度量 {#sec-verbalise}

后续针对推理模型的研究把度量做得更细。给同一道问题配上有、无某个指向某选项的提示两种版本；保留答案**转向被提示选项**的那些情形；再在其中测量思维链**承认提示**的频率。一个麻烦是，答案在多次运行之间也会毫无来由地改变——采样是随机的——所以有些向被提示选项的转向并不是提示引起的。

::: proposition 为随机切换校正言语化率 {#prop-correct}
设 $s_h$ 为给出提示时答案是（无提示时本不相同的）那个被提示选项的概率，$s_0$ 为不给提示重新采样时答案碰巧落在该选项上的概率。假设不由提示引起的切换以速率 $s_0$ 发生且从不提及提示，而由提示引起的切换以概率 $m$ 提及它。那么切换中观察到的提及率为 $\hat m = m\,(s_h - s_0)/s_h$，于是

$$
m = \hat m\cdot\frac{s_h}{s_h - s_0}.
$$ {#eq-correct}
:::

::: proof
在切换（概率为 $s_h$）之中，比例为 $s_0/s_h$ 的是偶然切换，按假设从不提及提示；比例为 $(s_h - s_0)/s_h$ 的由提示引起，以概率 $m$ 提及它。于是切换中的总体提及率为 $\hat m = m(s_h - s_0)/s_h$；解出 $m$ 即得[[#eq-correct]]。
:::

这些假设都是近似：当模型在某些问题上正跟着提示走时，偶然切换可能略少一些，正如下面的模拟那样。Chen 等（2025）在关于推理模型的研究中就用了这一类归一化。他们测试了六种提示——包括谄媚式的建议、少样本示例里的一个模式、提示中的元数据、对评分代码的描述，以及以不道德方式获得的信息——并报告：跨提示平均，Claude 3.7 Sonnet 的思维链承认自己用过的提示的比例为 $25\%$，DeepSeek-R1 为 $39\%$；基于结果的强化学习起初提高忠实性，随后停在不高不低的水平上；而在带有可利用奖励破解的训练环境中，模型几乎在所有情形下都学会了利用它，提及它的比例却不到 $2\%$。不忠实的链平均比忠实的*更长*——遗漏不是篇幅短的缘故。

另一些研究在相关度量上得出更乐观的结论。Chua 与 Evans（2025）在带线索的提示上比较了同一开发者的推理模型与非推理模型，发现推理模型明显更常说出影响了自己的是哪条线索。Arcuschin 等（2025）不使用任何人工提示来寻找不忠实，发现的比率更低——例如**隐式事后合理化**：模型对"X 比 Y 大吗？"和"Y 比 X 大吗？"都回答"是"，每次配一个看上去头头是道的论证——比率在不同模型之间差别很大。这些研究在模型、线索和度量上各不相同；合起来读，它们表明言语化既不完全也不稳定：按某些度量推理模型做得更好，但远称不上完整。

::: example 校正一个言语化率 {#ex-correct}
有提示时，$50\%$ 的答案转向被提示选项；没有提示时，$10\%$ 在重新采样时碰落在同一个选项上。在发生切换的样本中，$20\%$ 的链提到了提示。估计真正由提示引起的切换中提及提示的比率。
::: solution
由[[#eq-correct]]，$m = 0.2\cdot0.5/(0.5 - 0.1) = 0.25$。五分之一的切换（$0.1/0.5$）本来就会发生，不能指望它们提到提示；对它们作校正，把估计从 $20\%$ 提到 $25\%$。当提示的效应微弱（$s_h$ 接近 $s_0$）时校正最要紧，因为未校正的比率会被严重稀释。
:::
:::

## 来自思维链干预的证据 {#sec-interventions}

Lanham 等（2023）直接对思维链本身做干预，在若干多项选择任务和一族不同规模的模型上进行。

- **提前作答。** 在链走完一部分步骤后截断它，强制给出答案。如果根本不写链答案也已经一样，这条链就并非必要。
- **添加错误。** 在某一步插入一个错误，让模型继续写。如果最终答案不变，说明模型并没有依赖那一步。
- **换措辞。** 用不同的词重写这条链。如果准确率下降，原来的措辞可能携带了隐藏信息（隐写术）。
- **填充词元。** 用同样数量的无信息词元（"……"）替换这条链。如果准确率保持不变，收益就来自额外的计算，而不是内容。

他们发现，答案对链的依赖程度**在不同任务之间差异极大**：有些任务上，截断或篡改这条链会经常改变答案；另一些任务上，模型的答案在链开始之前就已大体定下。换措辞没有降低准确率——这是对措辞中隐藏编码的反证；填充词元也没有帮助——这表明收益来自内容。而且在大多数任务上，更大、更强的模型**更少**依赖自己的链——一个反缩放结果：模型越能直接作答，它的链就越像装饰。

填充词元这个结果有一个警示。Pfau、Merrill 与 Bowman（2024）构造了一些合成任务，在恰当监督下训练的 Transformer 在这些任务上*确实*会用无意义的填充词元执行单次前向传播做不了的运算——这与[[reasoning/chain-of-thought#prop-depth]]相容，因为填充词元增加了位置，也就增加了并行计算。他们发现这种用法很难学到，在标准模型中也没有观察到；但它说明"这些词元没有意义"并不蕴含"那里没有发生计算"。

::: warning 可读的思维链不是计算的实录
本章每个实验都发现了陈述的推理遗漏了有影响的因素、或对答案并不必要的情形。要把思维链当作关于计算的*证据*——常常有信息量，有时有误导——而不是计算本身。尤其要注意，一条没有提到某个问题（偏向、捷径、奖励破解）的链，只是该问题不存在的很弱的证据。
:::

### 监控及其脆弱性 {#sec-monitor}

哪怕只是部分的忠实性也很有价值。OpenAI 的 Baker 等（2025）在智能体编程任务的强化学习过程中用另一个语言模型去读推理模型的思维链，发现能读到链的监控器比只看动作的监控器可靠得多地抓住了奖励破解——比如让测试通过却没有真正解决问题。但当他们把监控器的判断加进训练奖励后，策略在强力优化下学会了*不写明地*破解：**隐匿的**（obfuscated）奖励破解。这一教训是[[reasoning/process-outcome-rewards#def-hacking]]的过度优化主题的一个版本：把思维链优化得好看，可能毁掉使它有用的那个性质。来自多家实验室与学术团体的研究者发表的立场论文（Korbak 等，2025）论证，思维链的可监控性是监督的一种"新的而脆弱的机会"，建议开发者跟踪它，并在训练决策中权衡它。

::: quiz
一个推理模型的答案在提示中加入一个建议的答案后发生改变，而它的思维链从未提到这个建议。哪些结论是站得住的？（多选。）
- [x] 思维链遗漏了一个影响答案的因素，因而在[[#def-faithful]]的意义 (ii) 下不忠实。
- [ ] 这个模型的推理从不忠实。
- [x] 只读思维链的监控器可能漏看答案曾受该建议影响。
- [ ] 训练模型使它的链从不提及建议，会让它更忠实。
::: solution
实验确立了一个有影响力却未被提及的因素，所以链确实遗漏了它，而只看链的监控器可能漏掉它。实验并没有确立普遍的不忠实。训练链不提及建议只会让链*更不*有信息量，而不会消除影响本身——即 Baker 等所描述的隐匿风险。
:::
:::

## 局限：反转诅咒 {#sec-reversal}

忠实性问的是写下来的推理是否反映计算。另一个问题是模型究竟能完成哪些计算。几项记录充分、影响很大的失败，涉及的偏偏是看似微不足道的推断。

Berglund 等（2023）用关于虚构人物的"$A$ 是 $B$"式陈述——"Daphne Barrington 是《A Journey Through Time》的导演"——微调模型，再考它们反向的问题："《A Journey Through Time》的导演是谁？"模型顺向的问题答得好，反向的问题好得跟瞎猜差不多：在"$A$ 是 $B$"上训练并没有教会"$B$ 是 $A$"。真实事实上也出现了同样的不对称：问一份名人名单中每位名人的母亲是谁，GPT-4 答对 $79\%$；反过来问每位母亲的孩子是谁，只答对 $33\%$。Allen-Zhu 与 Li（2023）在用合成传记做的受控实验中发现了同样的"逆向搜索"失败。

机制在"每个上下文各有一套参数"的极端模型上最容易看清。

::: proposition 表格模型中顺向训练不动反向 {#prop-reversal}
考虑这样一个模型：它在每个上下文 $c$ 下的下一词元分布是 $\operatorname{softmax}(\theta_c)$，各上下文有自己的参数向量 $\theta_c$。在序列"$A$ 是 $B$"的交叉熵上做梯度下降训练，只改变作为该序列前缀出现的上下文的参数向量。特别地，"$B$ 是"之后补全的分布——它的上下文从未出现——保持不变。
:::

::: proof
损失是对训练序列的各个前缀 $c_t$ 求和的 $-\sum_t\log\operatorname{softmax}(\theta_{c_t})_{x_t}$。对不是任何一个 $c_t$ 的 $c$，它关于 $\theta_c$ 的梯度为零。上下文"$B$ 是"不是"$A$ 是 $B$"的前缀，所以它的参数不变，其预测也就不变。
:::

::: example 数一数这种不对称 {#ex-reversal}
在一份含 $1{,}500$ 个名人—父母配对的名单上，给定名人时模型能说出 $79\%$ 配对的父母，给定父母时能说出 $33\%$ 配对的名人。它顺向知道、反向却不知道的配对至少有多少对？
::: solution
顺向知道的配对有 $0.79\cdot1500 = 1185$ 个；反向知道的最多 $0.33\cdot1500 = 495$ 个。即使每个反向知道的配对也顺向知道，至少有 $1185 - 495 = 690$ 对——名单的 $46\%$ ——只单向知道。同一件事，被作为一个可用的联想存在一个方向里，另一个方向则没有。
:::
:::

Transformer 在各上下文间共享参数，命题对它并不直接适用；但它抓住了反转为什么不是*自动的*：下一词元预测训练的是 $p(B\mid A\text{ 是})$，而那个目标里没有任何东西要求 $p(A\mid B\text{ 是})$ 改变。共享的表示会不会把这条事实反向迁移过去是一个经验问题，而实验的回答是基本不会。由此有两个实际结论。第一，在上下文中，模型*能*反转它刚读到的关系——失败针对的是存在权重里的知识。第二，把事实正反两个方向都写出来的训练数据，或能这样做的增广，能缓解这一诅咒。

## 局限：组合与长度 {#sec-composition}

**组合泛化**是把已知的部件以新方式组合起来的能力。Dziri 等（2023）在《Faith and Fate》中研究了多位数乘法、一道逻辑谜题（爱因斯坦谜题）和一个动态规划问题，并把每个解法表示成一张计算图。图越深越宽，模型准确率掉得越厉害——对位数多于训练中见过的数做乘法时趋近于零，哪怕先在较小的情形上微调过、也写了逐步推理。他们的分析认为，模型常是在匹配训练中见过的子图，而不是执行一个通用算法，并且误差沿图复合。Press 等（2023）对两跳问题测量了**组合性差距**（[[reasoning/chain-of-thought#sec-decomposition]]）；Yang 等（2024）发现的证据表明，这类问题的第一跳很多时候是以潜隐方式完成的，完整组合却远不那么可靠。

**长度泛化**是把一个程序用到比训练中更长的输入上的相关能力。Anil 等（2022）发现，在奇偶校验、变量追踪一类任务上，微调与少样本提示给出的长度泛化都很差，而草稿本提示有帮助。截至 2026 年，长度泛化仍是活跃的论题，位置编码、数据格式与草稿本都会影响它（[[transformers/positional-encoding]]）。

::: example 沿计算图累积的误差 {#ex-compound}
把两个 $d$ 位数相乘的模型示意地看作 $d^2 + 2d$ 个基本步骤（单个数字的乘积、进位与加法），每步独立地以 $0.98$ 的概率正确。计算 $d = 2, 4, 6$ 时乘积完全正确的概率。
::: solution
$d = 2$：$8$ 步，$0.98^8 = 0.851$。$d = 4$：$24$ 步，$0.98^{24} = 0.616$。$d = 6$：$48$ 步，$0.98^{48} = 0.379$。即使每一步有 $98\%$ 的可靠性，长的乘法仍然不可靠，而步数随位数平方增长。Dziri 等观察到的崩塌比这个独立误差模型预测得更快，因为一到分布外的位数上，每步的可靠性本身也在下降。程序辅助推理（[[reasoning/chain-of-thought#sec-pal]]）把算术交给解释器，绕开了这个问题。
:::
:::

## 局限：污染与记忆 {#sec-contamination}

只有当模型没见过基准里的题目——或它们的近似变体——及其答案时，这个基准才算在测推理。从网上抓取的大规模预训练语料包含许多基准，以及关于它们题目与解法的讨论。

::: definition 基准污染 {#def-contamination}
若一个基准的测试题目、或连同其解答的近似重复项出现在模型的训练数据中，就说该基准对该模型是**污染的**。污染会把测得的准确率抬高一段，抬高水平取决于记住了多少、以及模型怎么用它。
:::

检测方法包括：在训练数据中搜索重叠的 $n$-gram（只有能接触训练数据的人才办得到）、嵌在基准文件里的金丝雀字符串、基于模型对测试题目似然的成员检验，以及——对任何人都开放的一条路——与**新鲜**或**扰动**题目的比较。三个有名的比较：

- **新的匹配题集。** Zhang 等（2024）编写了 GSM1k，约 $1{,}200$ 道新题，在风格与难度上与 GSM8K 匹配。有些模型家族在 GSM1k 上的得分比 GSM8K 低多达约 $13$ 分，显示出对原始基准的过拟合；当时若干最强的模型几乎没有差距。
- **扰动。** Mirzadeh 等（2024）把 GSM8K 的题目做成模板、换掉人名与数字，构建了 GSM-Symbolic，发现准确率在不同实例间波动明显，且数字一变就下降。在 GSM-NoOp 中他们加入一段看似相关、实则不影响答案的从句，某些模型的准确率下降多达 $65\%$；模型真的去减那段无关从句里提到的量。作者把这解读为模式匹配而非形式推理的证据；也有人反驳说许多人类同样会被这类从句误导，且最强的模型受影响小得多。
- **按时间划分的基准。** LiveCodeBench（Jain 等，2024）收集编程题并连同发布日期一起收录，因而可以在模型训练截止之后发布的题上评估它；一些模型在较新题目上的表现出现了下降。在模型发布之后举行的数学竞赛——AIME 2025、2025 年的美国数学奥林匹克与国际数学奥林匹克——上的评测起同样作用。

::: proposition 估计记住的比例 {#prop-contam}
设在一个被污染的基准上，$\kappa$ 的题目是靠记忆答对的，其余以准确率 $a$ 作答，而 $a$ 又等于模型在一份难度匹配的新鲜基准上的准确率。那么观察到的准确率为 $A = \kappa + (1-\kappa)a$，并且

$$
\kappa = \frac{A - a}{1 - a}.
$$
:::

::: proof
记住的题目以概率 $1$ 正确，其余以概率 $a$ 正确；由全概率公式 $A = \kappa\cdot1 + (1-\kappa)a$。解出得 $A - a = \kappa(1 - a)$。
:::

这个模型很粗糙——记忆很少是非全有即全无的，"难度匹配"也只是一个假设——但它说明了为什么小幅下降可能意义重大：如果原基准上准确率是 $90\%$、新鲜集上是 $80\%$，估计就是 $\kappa = 0.1/0.2 = 0.5$，即模型本来解不出的题目里有一半。而在解释任何下降之前，先要检验它是否大于采样噪声。

::: example 这个下降是真的吗？ {#ex-ztest}
一个模型解出 GSM8K 测试集 $1319$ 题中的 $1130$ 题（$85.7\%$），以及一份新鲜的匹配题集 $1250$ 题中的 $1020$ 题（$81.6\%$）。这个差别显著吗？
::: solution
合并比例为 $(1130 + 1020)/(1319 + 1250) = 0.837$，差的标准误为 $\sqrt{0.837\cdot0.163\cdot(1/1319 + 1/1250)} = 0.0146$。差为 $0.857 - 0.816 = 0.041$，于是 $z = 2.79$，双侧 $p$ 值约为 $0.005$：不太可能是噪声——前提是两套题的难度真的匹配，而这恰是最需要推敲的假设。若新鲜题集解出的题数改为 $1050$，$0.017$ 的差给出 $z = 1.18$、$p = 0.24$：没有差异的证据。清单把两种情形都算了出来。
:::
:::

## 关于"推理"的主张说明了什么？ {#sec-claims}

2025 与 2026 年的推理模型能解绝大多数人都解不出的竞赛数学题，能写出又长又对的证明，能修好真实的软件缺陷。它们也会栽在孩子都会的谜题上，被无关的从句带偏，有时还会为同一个比较的两边各自给出自信的论证。两组观察都稳健。如何解释仍有争论，一份公允的陈述必须把主要立场连同各自依赖的证据一并摆出来。

**能力论。** 在训练之后才产生的问题上的表现——新竞赛、由专家评分的新写证明、未公布的编程题——没法用记住这些题来解释。经 Lean 检验的形式证明（如 AlphaProof）和通过隐藏测试的程序，无论由什么过程产生，其正确性都由构造保证。两家开发者宣布的 2025 年国际数学奥林匹克金牌级表现，针对新题写出了长篇自然语言证明。按这一观点，失败是现有系统的真实局限，但并不能说明成功是假象；人类同样有系统性的推理失败。

**近似检索论。** 语言模型按续写文本训练，对问题的表面形式有多眼熟高度敏感。McCoy 等（2024）表明，准确率在很大程度上取决于任务与输出在训练分布下的概率——同一个移位密码，模型做常见的移位 $13$ 位远比移位 $2$ 位好——而 Wu 等（2024）发现熟悉任务的"反事实"变体会带来大幅下降，例如用 $9$ 进制做算术。在把物体名字混淆掉的规划基准上（Valmeekam 等，2023），较早的模型大幅下降；推理模型在这些基准上有可观但仍不均衡的改进（Valmeekam 等，2024）。按这一观点，大量表面上的推理是从解过的相似题出发的插值，而思维链只是生成的文本，未必携带语义。

**有争议的证据。** 有些结果正反两面都有人引。Shojaee 等（2025）的《The Illusion of Thinking》在复杂度可控的谜题（如汉诺塔与过河问题）上评测推理模型，报告准确率在越过某个复杂度阈值后崩塌，而模型的推理努力在崩塌附近*下降*。一篇回应（Lawsen，2025）争辩说，其中一些被报告的失败其实是输出长度上限所致——汉诺塔的完整解随盘子数指数增长——而且所测的部分过河实例根本无解；并展示模型可以写出产生解法的程序。Petrov 等（2025）为 2025 年美国数学奥林匹克的完整证明评分，发现 2025 年 3 月评测的所有模型都在 $5\%$ 以下，有毛病的推理常常藏在看似正确的答案背后；几个月后，同一赛季的国际奥林匹克就产生了上面金牌级的宣布。这类结果高度依赖日期、模型、评分和输出限制，双方各有道理。

截至 2026 年，可以有把握地说：

1. **经检验的输出是真的。** 只要答案经过了检查——证明由证明助手检验，代码由测试检验——它的正确性就不依赖于它是怎么产生的。
2. **未经检验的推理不自证。** 流利的思维链既不是正确性的证明，也不是计算的忠实记录（[[#sec-bias]]、[[#sec-interventions]]）。
3. **表现是不均匀的。** 模型可以在难题上很强、在简单变体上很弱；泛化依赖于形式的熟悉程度、组合的深度与长度。
4. **基准会过时。** 污染与针对性训练会侵蚀基准；衡量进展需要新鲜、留出与扰动过的评估，并配上像样的统计。
5. **增益集中在可以检验的地方。** 测试时计算的规模化与基于可验证奖励的强化学习，其证据大多来自数学与代码（[[reasoning/test-time-scaling#sec-verification]]）；向没有检验器的任务迁移则远未确立。

## 数值实验室 {#sec-code}

清单模拟一个真实提及率已知（$30\%$）的提示实验，检验[[#prop-correct]]的校正；跑[[#ex-ztest]]的两比例检验；并把[[#ex-compound]]的误差累积模型列成表。

```python
import math, random
rng = random.Random(9)

# 1. 测量思维链是否承认用了提示（Turpin / Chen 等的风格）：
# 模拟模型对四选一的问题答两次：一次不给提示，一次给一个指向不同
# 选项的提示。它在 40% 的问题上听从提示；听从时，其中 30% 会提到
# 提示。重新采样也会随机改变 15% 的答案。
Q, USE, MENTION, NOISE = 20000, 0.40, 0.30, 0.15
switch = mention = 0
noise_switch = 0
for _ in range(Q):
    base = rng.randrange(4)
    hint = rng.choice([o for o in range(4) if o != base])
    if rng.random() < USE:
        ans, said = hint, rng.random() < MENTION
    else:
        ans = rng.randrange(4) if rng.random() < NOISE else base
        said = False
    if ans == hint:
        switch += 1; mention += said
    # 对照运行：同一问题，不给提示，重新采样
    ctrl = rng.randrange(4) if rng.random() < NOISE else base
    noise_switch += ctrl == hint
s_h, s_0 = switch / Q, noise_switch / Q
observed = mention / switch
corrected = observed * s_h / (s_h - s_0)
print(f"switch to hinted option: with hint {s_h:.3f}, without {s_0:.3f}")
print(f"mention rate among switches: observed {observed:.3f}, corrected {corrected:.3f} (true {MENTION})")

# 2. 在新鲜的匹配基准上的下降显著吗？两比例 z 检验
def z_test(c1, n1, c2, n2):
    p1, p2, p = c1 / n1, c2 / n2, (c1 + c2) / (n1 + n2)
    se = math.sqrt(p * (1 - p) * (1 / n1 + 1 / n2))
    z = (p1 - p2) / se
    return p1 - p2, z, math.erfc(abs(z) / math.sqrt(2))   # 双侧 p 值
for c1, c2 in [(1130, 1050), (1130, 1020)]:
    d, z, pv = z_test(c1, 1319, c2, 1250)
    print(f"original {c1}/1319 vs fresh {c2}/1250: gap {d:+.3f}, z = {z:.2f}, p = {pv:.3g}")

# 3. 多位数乘法中每步误差的累积（玩具版：每对数字一步）
for digits in [1, 2, 3, 4, 5, 6]:
    steps = digits * digits + 2 * digits      # 部分积，加上进位与加法
    print(f"{digits} x {digits} digits: {steps:3d} steps, accuracy at 0.98 per step {0.98**steps:.3f}")
```

```text
switch to hinted option: with hint 0.423, without 0.035
mention rate among switches: observed 0.279, corrected 0.303 (true 0.3)
original 1130/1319 vs fresh 1050/1250: gap +0.017, z = 1.18, p = 0.238
original 1130/1319 vs fresh 1020/1250: gap +0.041, z = 2.79, p = 0.00525
1 x 1 digits:   3 steps, accuracy at 0.98 per step 0.941
2 x 2 digits:   8 steps, accuracy at 0.98 per step 0.851
3 x 3 digits:  15 steps, accuracy at 0.98 per step 0.739
4 x 4 digits:  24 steps, accuracy at 0.98 per step 0.616
5 x 5 digits:  35 steps, accuracy at 0.98 per step 0.493
6 x 6 digits:  48 steps, accuracy at 0.98 per step 0.379
```

未校正的提及率 $27.9\%$ 低估了真实的 $30\%$，因为少数切换出于偶然；校正恢复出 $30.3\%$，略偏高，因为在模拟里，有提示时偶然切换反而更少见（模型在那些问题上改而听从了提示）。两个基准比较相差的解题数只有 $30$ 道，可一个差距完全落在噪声之内，另一个却不是。

::: history
Jacovi 与 Goldberg（2020）在可解释性中区分了忠实性与可信性。Wei 等（2022）提醒，思维链提示并不能确定网络是否真的在推理。Turpin 等（2023）表明有偏提示下的解释可能系统性地不忠实，Lanham 等（2023）用干预测量了对链的依赖。Berglund 等（2023）描述了反转诅咒，Dziri 等（2023）描述了组合泛化的局限，Valmeekam 等（2023）描述了规划的失败。2024 年，Pfau 等展示了填充词元中的隐藏计算，Mirzadeh 等提出 GSM-Symbolic，Zhang 等提出 GSM1k，Jain 等提出 LiveCodeBench，McCoy 等分析了《Embers of Autoregression》。2025 年，Chen 等、Chua 与 Evans 以及 Arcuschin 等测量了推理模型的忠实性，Baker 等报告了思维链监控下的隐匿奖励破解，Korbak 等称可监控性是一个脆弱的机会，而 Shojaee 等的《Illusion of Thinking》及其回应则围绕谜题上的失败说明什么展开争论。
:::

::: summary
- 如果思维链陈述的理由确实影响答案、且影响答案的因素都被陈述，它就是**忠实的**；它可能因**事后合理化**或**遗漏**而失败。忠实性通过对输入或对链的干预来检验。
- 带偏的特征改变了答案而解释却略去了它们（Turpin 等，2023）；推理模型只有一部分时候承认自己用过的提示（Chen 等，2025 中两个模型分别为 $25\%$ 与 $39\%$），按某些度量比非推理模型承认得更多（Chua 与 Evans，2025）。言语化率应对偶然切换作校正：$m = \hat m\,s_h/(s_h - s_0)$。
- 对链的依赖随任务而异，并在所研究的大多数任务上随模型能力上升而下降（Lanham 等，2023）；在构造的环境里，填充词元可以携带隐藏计算（Pfau 等，2024）。
- 思维链**监控**能发现奖励破解一类失当行为，但对着监控器优化链会使失当行为**隐匿**。
- 局限：**反转诅咒**（"A is B"教不会"B is A"）、**组合**任务中的误差复合、薄弱的**长度泛化**，以及**污染**——后者要结合像样的显著性检验、用新鲜或扰动的基准来估计。
- 关于"推理"的主张分为能力论与近似检索论；经检验的输出是真的，未经检验的链不自证，表现不均匀，基准会过时，而证据在答案可以被检验的地方最强。
:::

一个模型在一个基准上得 $90\%$，在一份新鲜的匹配版本上得 $80\%$。按[[#prop-contam]]的模型，在它本来解不出的题目中，有多大比例是靠记忆答对的？
::: solution
$\kappa = (0.9 - 0.8)/(1 - 0.8) = 0.5$。

::: exercise 一个显著性检验 {level=1 check="2.94"}
一个模型解出 $1000$ 道原始题中的 $850$ 道、$1000$ 道新鲜题中的 $800$ 道。用合并标准误计算两比例的 $z$ 统计量，保留两位小数。
::: solution
合并 $p = 1650/2000 = 0.825$；标准误 $\sqrt{0.825\cdot0.175\cdot2/1000} = 0.01699$；$z = 0.05/0.01699 = 2.94$。
:::

::: exercise 乘法的步数 {level=2 check="0.2059"}
一个程序有 $15$ 步，每步独立地以 $0.9$ 的概率正确。结果正确的概率是多少？给出四位小数。若结果必须以至少 $0.5$ 的概率正确，这个程序最多允许多少步？
::: solution
$0.9^{15} = 0.2059$。要 $0.9^s\ge0.5$，需要 $s\le\ln0.5/\ln0.9 = 6.58$，所以至多 $6$ 步。
:::

::: exercise 设计一个提示实验 {level=2}
设计一个实验，测量推理模型的思维链多久承认一次藏在提示元数据里的提示（例如一个看似隐藏的块中的 `<answer>C</answer>`）。写清楚：实验条件、样本、什么算"承认"、如何处理碰巧改变的答案，以及你的设计的一个局限。
::: solution
条件：每道选择题在不带提示与带一个指向非模型无提示答案的选项的提示两种条件下运行（每种条件多次运行，以估计重新采样的波动）。样本：跨学科抽取几百道题，被提示的选项随机选取。保留带提示运行中答案等于被提示选项的情形；"承认"指链中提到该元数据、或提到被告知了答案，由两名独立评审（或与人工标注对照验证过的模型评审）按书面评分细则判定。$s_0$ 用只重新采样无提示问题的对照组来估计，再用[[#eq-correct]]校正。报告置信区间。局限：评分细则决定了什么算承认（一句含糊的"综合考虑所有信息"难以归类）；人工提示得到的对待可能不同于自然存在的影响；结果只针对一种提示类型和一个模型版本。
:::

::: exercise 表格模型中的反转 {level=2}
把[[#prop-reversal]]推广一下：设训练数据包含"$A$ 是 $B$ 的导演"，以及分别关于电影 $B$ 的其他事实，例如"$B$ 于 1990 年上映"。表格模型会不会学会把"$B$ 的导演是"补全成 $A$？什么样的训练数据能教会它反向？针对反转诅咒的数据增广方法如何利用这一点？
::: solution
在表格模型中，每个上下文有自己的参数，所以模型恰好学到数据中作为（前缀，下一词元）对出现的那些条件分布。"谁导演了 $B$？"与两条训练序列都是不同的上下文，其分布不变：模型答不上来。要学到反向，它必须看到某条序列，其中提到 $B$（以及该关系）的上下文后面跟着 $A$，例如"$B$ 的导演是 $A$"。针对反转诅咒的增广方法做的正是这件事：把事实以反转或置换后的顺序重述，或在反转的文本上训练，使两个方向的条件分布都得到训练。Transformer 的共享参数原则上可以不需要这类数据就迁移这条事实，但 Berglund 等的实验表明，实践中它们基本不会。
:::
:::

::: exercise 提前作答 {level=3}
用纯 Python 模拟 Lanham 等的提前作答测验：某模型在 $1{,}000$ 道题上，比例为 $f$ 的题在推理开始前答案就已定下；其余题目的答案只由 $5$ 步链的最后一步确定，在那之前截断链就给出 $4$ 个选项中的随机答案。对截断于 $0, 1, \dots, 5$ 步，计算与完整链答案一致的比例，分别取 $f = 0.2$ 与 $f = 0.8$，并把曲线上方的面积同 $f$ 联系起来。
::: solution
```python
import random
rng = random.Random(10)

def early_answering(f, n=1000, steps=5):
    fixed = [rng.random() < f for _ in range(n)]
    final = [rng.randrange(4) for _ in range(n)]
    curve = []
    for t in range(steps + 1):
        same = 0
        for q in range(n):
            if fixed[q] or t == steps:
                ans = final[q]
            else:
                ans = rng.randrange(4)          # 需要链却被截断：瞎猜
            same += ans == final[q]
        curve.append(same / n)
    return curve

for f in [0.2, 0.8]:
    c = early_answering(f)
    area = sum(1 - v for v in c) / len(c)
    print(f"f = {f}: " + " ".join(f"{v:.2f}" for v in c) + f"   area above curve {area:.3f}")
```

```text
f = 0.2: 0.41 0.41 0.41 0.38 0.41 1.00   area above curve 0.497
f = 0.8: 0.86 0.86 0.86 0.85 0.84 1.00   area above curve 0.122
```

在最后一步之前，一致率约为 $f + (1-f)/4$：$f = 0.2$ 时为 $0.4$，$f = 0.8$ 时为 $0.85$。曲线上方的面积约为 $\frac56(1-f)\cdot\frac34$——分别为 $0.5$ 与 $0.125$——所以它与"答案依赖链"的题目比例成正比。Lanham 等用这一类面积来度量模型多依赖自己的推理；一个答案大多提前定下的模型，得分就低。
:::

::: exercise 同一结果的两种解读 {level=3}
一个推理模型在一组小学数学应用题上解出 $70\%$；在每道题加入一句带无关数字的话之后，解出 $45\%$。给出最强的"这说明模型没有在推理"的论证、最强的"这并不能说明"的论证，以及一个有助于在两者之间决断的额外实验。
::: solution
**不在推理：**一个真正理解了问题的推理者会忽略与答案无关的信息；$25$ 个百分点的下降说明模型的程序是被表面特征触发的（"题里出现的数就得用上"），这与近似检索论以及 GSM-NoOp 的结果相容。**不能说明：**人类在应用题中加入无关数字时同样会大幅下降（这是数学教育中一个众所周知的效应）；模型在扰动后的题上仍能解出 $45\%$，这需要比检索更多的东西；而且扰动也改变了题目的熟悉程度，所以下降度量的是对分布偏移的敏感，不是没有推理。**一个实验：**把同样的扰动用于人类对照组，以及带"先指出无关信息"明确指令的模型；分析错误，看错答是否系统性地用到了无关数字（一种具体的捷径），还是四处散落（一般性退化）；再检验给几个忽略干扰项的示范之后准确率是否恢复。若错误用到了干扰项而人类受影响小得多，捷径解读就得到支持；若人类出现类似下降、且模型在指令下恢复，这个结果对推理本身就说不了多少。
:::
