一条思维链是来自推理路径分布的一次采样。在正温度下再采一次，模型可能走一条不同的路——并到达一个不同的答案。上一章把这种波动当作单次尝试中的噪声；本章把它当作一种资源。既然可以做几次相互独立的尝试，我们就能对它们的答案**投票**、用验证器**检验**，或者干脆问它们中**是否**有一个是对的。这三种想法在统计与机器学习中都很古老，又都在 2021 到 2023 年间成为语言模型推理的核心。它们也是本课程中最适合做精确概率计算的地方：投票有多大帮助？什么时候开始不帮助？$k$ 次尝试的成功率又该如何度量？

[[prompting-rag/prompt-design#sec-self-consistency]] 介绍了自洽性，并证明相对多数投票收敛到概率最大的答案。这里我们走得更远。我们把自洽性推导为对推理路径求边际的一个近似；精确计算多数投票的准确率并证明孔多塞陪审团定理；精确展示相关的误差如何破坏它；推导代码与推理评测中通用的 pass@$k$ 的无偏估计量；并分析带验证器的 best-of-$n$ 选择，包括为什么在样本充足之后，瓶颈变成了验证器不够好。

## 把推理路径看作潜变量 {#sec-marginal}

把模型对问题 $x$ 的输出写成一条推理路径 $z$ 后跟一个由解析器提取的答案 $a$。路径只是达到目的的手段：两条不同的链若都以 "the answer is $54$" 收尾，给出的就是同一个答案，而我们在乎的是

$$
p_\theta(a\mid x) = \sum_{z} p_\theta(z, a\mid x),
$$ {#eq-marginal}

即*答案*的概率，对所有到达它的方式求和。贪心解码沿着单条高概率路径走，而它的终点未必是边际概率最大的答案：许多中等可能的路径可能一致指向同一个答案，而概率最高的单条路径却终结在他处。

::: definition 自洽性 {#def-sc}
**自洽性**（self-consistency；Wang 等，2023）在温度 $T > 0$ 下独立采样 $n$ 条路径 $(z_j, a_j)\sim p_\theta(\cdot\mid x)$，返回得票最多的答案，

$$
\hat a_n = \arg\max_a \sum_{j=1}^n \mathbf 1[a_j = a],
$$

平票时在领先者中均匀随机地裁定。**加权自洽性**把指示函数换成权重 $w_j$，例如路径的长度归一化概率或验证器的分数。
:::

::: proposition 投票估计边际的众数 {#prop-mode}
答案 $a$ 的得票数除以 $n$，$\hat p_n(a) = \frac1n\sum_j\mathbf 1[a_j = a]$，是[[#eq-marginal]]中边际 $p_\theta(a\mid x)$ 的无偏且相合的估计量。因此自洽性返回边际答案分布的经验估计的众数；并且，若该分布有唯一众数 $a^*$，则当 $n\to\infty$ 时 $\hat a_n\to a^*$ 几乎必然成立。
:::

::: proof
每个 $\mathbf 1[a_j = a]$ 是一个伯努利变量，均值 $\Prob(a_j = a) = \sum_z p_\theta(z, a\mid x) = p_\theta(a\mid x)$，所以 $\E\,\hat p_n(a) = p_\theta(a\mid x)$；又由强大数定律，$\hat p_n(a)\to p_\theta(a\mid x)$ 几乎必然。对有限答案集，最大值点的收敛即[[prompting-rag/prompt-design#prop-plurality]]。
:::

这条命题解释了 Wang 等人的一个否则令人意外的发现。他们比较了简单多数投票与按路径在模型下的概率加权。按*未归一化*的路径概率 $p_\theta(z,a\mid x)$ 加权效果差得多——长路径概率极小，投票几乎完全由碰巧最短的那条路径主导。按*长度归一化*概率（词元概率的几何平均）加权则与简单投票不相上下。简单投票本身就已经是[[#eq-marginal]]的蒙特卡洛估计；再按 $p_\theta$ 加权会把模型的概率重复计算一遍，因为样本本来就是从 $p_\theta$ 抽出来的。

### Wang 等人的发现 {#sec-wang}

以 $40$ 条采样路径（温度 $0.5$–$0.7$，多数模型用 $k = 40$ 的 top-$k$ 采样），自洽性在每个测试过的算术与常识基准上都优于贪心思维链。PaLM 540B 在 GSM8K 上，准确率从 $56.5\%$ 升到 $74.4\%$；论文报告 GSM8K 提高 $17.9$ 个百分点、SVAMP 提高 $11.0$、AQuA 提高 $12.2$、StrategyQA 提高 $6.4$、ARC-challenge 提高 $3.9$。自洽性也击败了用同样多样本数的其他方案：按样本概率排序、束搜索、不同提示的集成。准确率在头 $5$–$10$ 个样本内上升很快，随后趋于平缓。

::: example 贪心路径与边际答案 {#ex-greedy}
某模型对一个问题的路径分为五组。概率最大的单条路径（$0.08$）终结于答案 $48$；除它之外没有通向 $48$ 的路径概率超过 $0.01$，而通向 $48$ 的路径总概率为 $0.20$。通向 $54$ 的路径单条概率都更低（没有超过 $0.03$ 的），总概率却是 $0.55$；其余散落在别的答案上。贪心解码（大致）给出哪个答案？自洽性收敛到哪个？模型对哪个答案“更有信心”？
::: solution
贪心解码近似概率最大的单条路径，于是答 $48$。由[[#prop-mode]]，自洽性收敛到边际的众数 $54$——它占 $0.55$ 的概率质量，而 $48$ 只有 $0.20$。模型对一个*答案*的信心就是它的边际概率，所以模型对 $54$ 更有信心；贪心路径是一个高概率的异类。$n = 10$ 个样本时，$54$ 期望得 $5.5$ 票，$48$ 只有 $2$ 票。
:::
:::

## 多数投票的精确准确率 {#sec-condorcet}

先假设答案本质上是二元的——对或错——且每个样本以概率 $p$ 独立正确。取 $n = 2m+1$ 个样本（奇数，避免平票），当至少 $m+1$ 个样本正确时多数正确，而正确样本数 $X$ 服从二项分布：

$$
P_n(p) = \Prob(X\ge m+1) = \sum_{k=m+1}^{n}\binom nk p^k(1-p)^{n-k}.
$$ {#eq-majority}

当错误答案分散在若干取值上时，这是相对多数投票的一个下界，因为那样正确答案可以用不到半数的票获胜（[[prompting-rag/prompt-design#ex-competitor]]）。

::: theorem 孔多塞陪审团定理 {#thm-condorcet}
设 $n = 2m+1$ 位投票人独立投票，每人正确的概率为 $p$，$P_n(p)$ 为多数正确的概率，见[[#eq-majority]]。则

$$
P_{n+2}(p) - P_n(p) = \binom{2m+1}{m}\,p^{m+1}(1-p)^{m+1}\,(2p - 1).
$$ {#eq-condorcet-step}

于是，若 $p > 1/2$，$P_n(p)$ 关于 $n$ 严格递增且 $P_n(p)\to1$；若 $p < 1/2$，它严格递减且趋于 $0$；并且对每个奇数 $n$，$P_n(1/2) = 1/2$。
:::

::: proof
设 $X$ 为前 $n = 2m+1$ 位投票人中正确投票的数目，再加入两位。$n+2$ 位的多数需要 $m+2$ 张正确票。结果要与前 $n$ 位的多数不同时，只可能发生在前 $n$ 位胶着到极点之时：若 $X = m$（多数错），恰好当两张新票都对时多数变对，概率 $p^2$；若 $X = m+1$（多数对），恰好当两张新票都错时多数变错，概率 $q^2$，其中 $q = 1-p$。其余任何情形，两张票都改变不了结果。于是

$$
P_{n+2} - P_n = \Prob(X = m)\,p^2 - \Prob(X = m+1)\,q^2 = \binom{2m+1}{m}p^mq^{m+1}p^2 - \binom{2m+1}{m+1}p^{m+1}q^mq^2,
$$

而由于 $\binom{2m+1}{m} = \binom{2m+1}{m+1}$，它等于 $\binom{2m+1}{m}p^{m+1}q^{m+1}(p - q)$，又因 $p - q = 2p - 1$ 即得[[#eq-condorcet-step]]。其符号与 $2p-1$ 相同，单调性由此而来。

对于 $p > 1/2$ 的极限：多数错误仅当 $X\le n/2$，即 $X - np\le -n(p - \tfrac12)$。用 $\Var X = npq$ 的切比雪夫（Chebyshev）不等式得

$$
1 - P_n\le\Prob\big(\lvert X - np\rvert\ge n(p-\tfrac12)\big)\le\frac{npq}{n^2(p-\frac12)^2} = \frac{pq}{n(p-\frac12)^2}\to0.
$$

$p < 1/2$ 的情形由交换对与错的角色得到。$p = 1/2$ 时 $X$ 的分布关于 $n/2$ 对称而 $n$ 为奇数，故 $\Prob(X\ge m+1) = \Prob(X\le m) = 1/2$。
:::

切比雪夫界是粗糙的。霍夫丁（Hoeffding）不等式 $1 - P_n\le\exp(-2n(p-\frac12)^2)$ 给出指数衰减和一条实用规则：要把投票的错误率压到 $\delta$ 以下，$n\ge\ln(1/\delta)/\big(2(p-\frac12)^2\big)$ 就足够。它对*差距* $p - \frac12$ 的依赖是二次的，所以一个 $55\%$ 的情形下正确的模型，要达到与一个 $70\%$ 的情形下正确的模型相同的保证，所需票数约是后者的十六倍。

::: example 手工计算多数票 {#ex-majority}
每个样本以概率 $0.7$ 正确。计算 $3$ 票与 $5$ 票的多数正确的概率，并用步进公式[[#eq-condorcet-step]]核对。
::: solution
$P_3 = 0.7^3 + 3\cdot0.7^2\cdot0.3 = 0.343 + 0.441 = 0.784$。$P_5 = 0.7^5 + 5\cdot0.7^4\cdot0.3 + 10\cdot0.7^3\cdot0.3^2 = 0.16807 + 0.36015 + 0.3087 = 0.83692$。$m = 1$ 时的步进公式：$\binom31\,0.7^2\,0.3^2\,(0.4) = 3\cdot0.49\cdot0.09\cdot0.4 = 0.05292$，而确实 $0.83692 - 0.784 = 0.05292$。每多一对票，帮助都比上一对小：二项式系数以 $4^m/\sqrt m$ 增长，但 $(pq)^{m+1} = 0.21^{m+1}$ 收缩得更快。
:::
:::

## 当投票相关时 {#sec-correlated}

孔多塞定理假设各票独立、准确率*同为* $p$。同一模型对同一问题的样本在给定提示下是独立的，但关键的准确率 $p$ 是*问题*的属性：有些问题上模型 $95\%$ 的时候正确，另一些上只有 $20\%$。从整个基准来看，一个随机选出的问题上的各票是相关的——它们共享那道题的难易——而那种相关性会彻底改写结论。

::: theorem 潜在难度下的多数投票 {#thm-mixture}
设问题的单样本准确率 $P$ 是一个随机变量，在 $[0,1]$ 上服从分布 $\mu$，且给定 $P$ 时该题各票相互独立、服从 Bernoulli$(P)$。则 $n = 2m+1$ 票的多数正确的概率对问题取平均为 $\E[P_n(P)]$，且

$$
\lim_{n\to\infty}\E[P_n(P)] = \mu\big(P > \tfrac12\big) + \tfrac12\,\mu\big(P = \tfrac12\big),
$$

而单样本准确率为 $\E[P]$。同一题上两票的相关系数为 $\rho = \Var(P)/\big(\E[P](1-\E[P])\big)$。
:::

::: proof
给定 $P = p$ 时各票独立，多数正确的条件概率就是 $P_n(p)$，对 $P$ 取平均得 $\E[P_n(P)]$。由[[#thm-condorcet]]，对每个 $p$ 有 $P_n(p)\to\mathbf 1[p > \frac12] + \frac12\mathbf 1[p = \frac12]$，且 $0\le P_n\le1$，故控制收敛定理允许交换极限与期望。至于相关性，设 $V_1, V_2$ 为两票。$\E[V_1V_2] = \E[\E[V_1V_2\mid P]] = \E[P^2]$，故 $\Cov(V_1, V_2) = \E[P^2] - \E[P]^2 = \Var(P)$，而每票的方差为 $\E[P](1-\E[P])$。
:::

极限只取决于模型*对的时候比错的时候多*的题目占比。投票把每个 $p > 1/2$ 的问题变成必然成功，把每个 $p < 1/2$ 的问题变成必然失败。若模型的单样本准确率主要是在它对的时候只是偶然占先的题目上挣来的，投票反而能降低准确率。由德菲内蒂（de Finetti）定理，任何无限可交换的二元投票序列都有这种混合形式，所以[[#thm-mixture]]一般地涵盖了相关的票，只要没有任何样本被特殊对待。

::: example 投票可能帮倒忙 {#ex-hurt}
某基准上 $60\%$ 的题对模型是容易题（$p = 0.9$），$40\%$ 是难题（$p = 0.4$）。单样本准确率、多数投票的极限、两票的相关系数各是多少？
::: solution
单样本：$0.6\cdot0.9 + 0.4\cdot0.4 = 0.54 + 0.16 = 0.70$。由[[#thm-mixture]]，投票趋于 $\mu(P > 1/2) = 0.6$：它在容易题上得分（$0.9\to1$），却在难题上输光（$0.4\to0$），净亏 $10$ 个百分点。$\Var(P) = 0.6\cdot0.81 + 0.4\cdot0.16 - 0.7^2 = 0.486 + 0.064 - 0.49 = 0.06$，故 $\rho = 0.06/(0.7\cdot0.3) = 0.286$。下面的清单算出整条曲线：投票先*略有帮助*（$n = 3$ 时到 $0.724$），随后下降到 $0.6$ 附近。若是准确率 $p = 0.7$ 的独立投票，则会趋于 $1$。
:::
:::

相关性也出现在题目*内部*。学到了常见误解的模型会频繁产出同一个错误答案；那时错误答案就是众数，$\hat a_n$ 收敛到它，投票让模型错得很有信心。诊断指标是**一致率**——领先答案所占的得票比例。Wang 等注意到它与准确率相关，这使它适合用来决定何时弃答、何时多花样本（[[reasoning/test-time-scaling]]）；但在有系统性错误的题目上，高一致性并不是正确性的证据。

::: warning 自洽性不是置信度度量
$9$ 比 $1$ 的投票并不意味着答案有 $0.9$ 的概率正确。得票比例估计的是模型对答案的边际概率（[[#prop-mode]]），只有当模型的分布本身校准良好时它才是校准的。一贯犯同一个错的模型会为那个错答案投出全票。把一致性当作*相对*信号——低一致性标记出难题或含糊题——并在把它当作概率使用之前，先用带标签的数据校准它。
:::

## Pass@$k$ {#sec-passk}

投票需要可比的答案。程序合成里有更好的东西：单元测试。若 $k$ 次尝试中有一个通过测试，问题就算解决——用户（或某个系统）可以运行测试、留下通过的程序。自然的度量是 $k$ 个样本中至少有一个正确的概率。

::: definition pass@$k$ {#def-passk}
对某问题，单样本正确的概率为 $p$，$\text{pass@}k = 1 - (1-p)^k$ 是 $k$ 个独立样本中至少一个正确的概率。在基准上，pass@$k$ 是该量对问题的平均。覆盖率——[[reasoning/test-time-scaling]]使用的说法——是同一个量。
:::

直接估计 pass@$k$——每题抽 $k$ 个样本、记录成败、取平均——既浪费又噪声大，而且每个 $k$ 都需要一批新的样本。Chen 等（2021）在随 Codex 模型引入 HumanEval 基准时，每题一次抽 $n\ge k$ 个样本，然后利用它们的所有 $k$ 元子集。

::: theorem pass@$k$ 的无偏估计量 {#thm-passk}
对某题抽 $n\ge k$ 个独立样本，其中 $c$ 个正确。则

$$
\widehat{\text{pass@}k} = 1 - \frac{\binom{n-c}{k}}{\binom nk} = 1 - \prod_{i = n-c+1}^{n}\Big(1 - \frac ki\Big)
$$ {#eq-passk}

（当 $n - c < k$ 时取值为 $1$）是 $1 - (1-p)^k$ 的无偏估计量。代入估计量 $1 - (1-c/n)^k$ 在 $k\ge2$ 且 $0 < p < 1$ 时向下偏。
:::

::: proof
给样本编号 $1,\dots,n$，对每个 $k$ 元子集 $S$ 记 $I_S = 1$（若 $S$ 中某个样本正确）。$S$ 中的样本是 $k$ 次独立抽样，故对每个 $S$ 有 $\E I_S = 1-(1-p)^k$。由期望的线性性，$I_S$ 在全部 $\binom nk$ 个子集上的平均值，其期望也是 $1-(1-p)^k$。该平均值等于 $1 - \big(\text{不含正确样本的子集数}\big)/\binom nk$，而一个子集不含正确样本，恰好当它完全取自那 $n-c$ 个错误样本，这样的子集有 $\binom{n-c}{k}$ 个。这就是[[#eq-passk]]的第一个形式。

至于乘积形式，

$$
\frac{\binom{n-c}{k}}{\binom nk} = \frac{(n-c)!\,(n-k)!}{n!\,(n-c-k)!} = \prod_{i=n-c+1}^{n}\frac{i-k}{i},
$$

因为 $(n-k)!/(n-c-k)!$ 是 $c$ 个整数 $i - k$（$i = n-c+1,\dots,n$）的乘积，而 $n!/(n-c)!$ 是相应的 $i$ 的乘积。

至于代入估计量，令 $\hat p = c/n$，$\E\hat p = p$。函数 $u\mapsto(1-u)^k$ 在 $k\ge2$ 时于 $[0,1]$ 上严格凸，而 $0 < p < 1$ 时 $\hat p$ 不是几乎必然常数，故由延森（Jensen）不等式，$\E(1-\hat p)^k > (1-p)^k$，从而 $\E[1 - (1-\hat p)^k] < 1 - (1-p)^k$。
:::

乘积形式在实践中很重要：$\binom{200}{100}\approx9\times10^{58}$ 会溢出许多数值格式，而 $c$ 个接近 $1$ 的因子之积是稳定的。Chen 等每题用 $n = 200$ 个样本，报告的 $k$ 最大到 $100$。他们 $120$ 亿参数的 Codex 模型单样本解出 HumanEval 的 $164$ 题中的 $28.8\%$，每题 $100$ 个样本时解出 $70.2\%$（pass@$100$）——这很早就表明，模型“会解”的题目远多于它一次尝试解出的题目，而这正是[[reasoning/test-time-scaling]]的出发点。

::: example 估计 pass@$5$ {#ex-passk}
某题抽了 $n = 20$ 个样本，$c = 3$ 个通过测试。用[[#eq-passk]]与代入估计量分别估计 pass@$1$ 与 pass@$5$。
::: solution
pass@$1$：$1 - \binom{17}{1}/\binom{20}{1} = 1 - 17/20 = 0.15$，与 $c/n$ 相同（$k = 1$ 时两个估计量重合）。pass@$5$：$\binom{17}{5} = 6188$，$\binom{20}{5} = 15504$，故 $1 - 6188/15504 = 0.6009$；乘积形式给出 $1 - \frac{13}{18}\cdot\frac{14}{19}\cdot\frac{15}{20} = 1 - \frac{2730}{6840} = 0.6009$。代入估计为 $1 - 0.85^5 = 0.5563$。两者不同是因为代入估计量向下偏；尽管对这个具体样本，若真 $p$ 恰为 $0.15$，无偏估计反而高于真值——无偏是关于重复抽样的平均性质，下面的清单会做检验。
:::
:::

::: widget plot
f: 1 - (1 - p)^x; 1 - (1 - p/10)^x
x: 1, 200
y: 0, 1
sliders: p=0.15:0.01:0.6:0.01
labels: pass@$k$ for one problem, $1-(1-p)^k$; a problem ten times harder
caption: 单样本成功概率为 $p$ 的题，pass@$k$ 随样本数 $k$ 的曲线；另一条属于一道难十倍的题。在 $k$ 的对数尺度下两条曲线都是 S 形；难题要达到同样的覆盖率，需要的样本约多十倍。一个基准混着难易悬殊的题，它的 pass@$k$ 就是这些曲线的平均——这正是[[reasoning/test-time-scaling]]所研究的、覆盖率缓慢的近似对数线性增长的由来。
:::

::: warning pass@$k$ 不是可以部署的准确率
$k$ 很大的 pass@$k$ 假设存在一个能认出正确样本的先知。对有完整单元测试的代码，这个先知存在；对多数其他任务它不存在，现实的数字是某种*选择*方法——投票或验证器——的准确率，它介于 pass@$1$ 与 pass@$k$ 之间。把自己的 pass@$100$ 报在别人的 pass@$1$ 旁边，比较的不是同一样东西。要报告 $k$、$n$、温度，以及测试时是否真的具备选择这一步。
:::

## 带验证器的 best-of-$n$ {#sec-verifier}

在投票（没有外部信号）与 pass@$k$（完美的先知）之间，是用学来的**验证器**做选择。Cobbe 等（2021）在引入 GSM8K 时，在训练解答上训练了一个生成器，对每道训练题采样 $100$ 条解答，以其最终答案是否正确为每条打标签，再训练一个验证器从问题与解答预测该标签。测试时他们采样 $100$ 条解答，返回验证器打分最高的那条。用这一流程，$60$ 亿参数的模型胜过了微调后的 $1750$ 亿参数模型，作者报告验证带来的改进约相当于模型规模扩大 $30$ 倍。

::: definition Best-of-$n$ 选择 {#def-bon}
给定输入 $x$ 的样本 $y_1,\dots,y_n$ 与打分函数 $r(x, y)$（验证器或奖励模型），**best-of-$n$** 返回 $y_{j^*}$，其中 $j^* = \arg\max_j r(x, y_j)$。**验证器加权投票**返回 $\arg\max_a\sum_j r(x,y_j)\,\mathbf 1[a_j = a]$。
:::

::: proposition best-of-$n$ 以 pass@$n$ 为上界 {#prop-bon}
对任何打分函数，best-of-$n$ 返回正确样本的概率都不超过 pass@$n$；若打分函数把每个正确样本都排在每个错误样本之前，则等号成立。
:::

::: proof
best-of-$n$ 返回的是 $n$ 个样本之一，所以只有当至少一个样本正确时它才可能正确，而该事件的概率就是 pass@$n$。若每个正确样本的得分都高于每个错误样本，那么只要存在正确样本，最大值就由某个正确样本达到。
:::

有意义的情形是不完美的验证器。每个额外的样本都是一次纳入正确解答的机会，但也是一次纳入验证器恰好打高分的错误解答的机会。$n$ 增大时，第一个效应饱和（pass@$n\to1$），第二个却持续增长：$n$ 个分数中的最大值会被拉进打分最高的那个分布的尾部，而若任何错误解答能系统地骗过验证器，best-of-$n$ 终会把它们找出来。Cobbe 等恰好观察到了这一点：验证器选择的准确率在每题几百个样本之前不断提高，随后回落。这是[[post-training]]讨论的奖励过度优化的一个小实例：对着不完美的代理加大优化力度，最终会偏离真实目标。

::: example 一个会被骗的验证器 {#ex-fool}
生成器以概率 $0.3$ 正确。验证器给正确解答的分数服从 $\mathcal N(2, 1)$，给错误解答的服从 $\mathcal N(0, 1)$；但有 $2\%$ 的错误解答“看起来可信”，打分为 $\mathcal N(3.5, 1)$。估计 $n = 1, 16, 1024$ 时 best-of-$n$ 的准确率。
::: solution
$n = 1$ 时验证器没有起作用：准确率 $0.3$。中等 $n$ 时，验证器大体能把正确解答与寻常错误解答分开；下面的清单在 $n = 16$ 估得 $0.80$，而 pass@$16 = 1 - 0.7^{16} = 0.997$。$n$ 大时，“可信”错误解答的期望个数为 $1024\cdot0.7\cdot0.02\approx14$，而正确解答约 $307$ 个；此时最高分属于 $\mathcal N(3.5, 1)$ 的 $14$ 个抽样中的最大值，还是 $\mathcal N(2,1)$ 的 $307$ 个中的最大值？前者约三次里有两次会赢。清单估得 $0.33$——几乎不比单个样本好。验证器哪怕只有罕见的盲区，在 $n$ 小时也是安全的，在 $n$ 大时却很危险。
:::
:::

验证器此后发展出许多形态。**结果奖励模型**给整条解答打分；**过程奖励模型**给每一步打分，既改进选择，又使搜索成为可能（[[reasoning/process-outcome-rewards]]、[[reasoning/search]]）。**生成式验证器**是被提示或经训练来评判解答的语言模型：它们先写自己的推理、再给出裁决，而它们的评判本身也可以采样并投票（Zhang 等，2024）。对无法用相等来比较的自由形式答案，**通用自洽性**让模型挑出与其他回答最一致的那一条（Chen 等，2023）。而当精确检验存在——单元测试、证明检查器、代回方程——验证器在其检验的性质上就是完美的，这正是对这类任务做强化学习成为可能的原因（[[reasoning/verifiable-rewards]]）。

::: quiz
一个模型在某基准的每道题上都以概率 $0.45$ 正确，错误答案散在许多不同取值上，任何一个的概率都不超过 $0.1$。自洽性投票数增多时会发生什么？（多选。）
- [x] 相对多数投票收敛到正确答案。
- [ ] 投票使准确率下降，因为 $0.45 < 1/2$。
- [x] 二元多数公式[[#eq-majority]]在这里低估了相对多数投票的准确率。
- [ ] pass@$k$ 就是自洽性达到的准确率。
::: solution
正确答案就是众数（$0.45 > 0.1$），由[[#prop-mode]]相对多数投票收敛到它。$p < 1/2$ 时孔多塞的失败适用于*二元*投票——那里所有错误票合在一起计；这里错误票分裂了。pass@$k$ 假设有先知，是任何选择方法的上界。
:::
:::

## 数值实验室 {#sec-code}

清单用纯 Python 检验本章的三个结果：独立票与[[#ex-hurt]]混合下多数投票的准确率（精确值与模拟值）、通过模拟比较 pass@$k$ 的无偏估计量与代入估计量、以及[[#ex-fool]]那个会出错的验证器下的 best-of-$n$。

```python
import math, random
rng = random.Random(1)

def majority_exact(p, n):                      # n 为奇数，票相互独立
    return sum(math.comb(n, k) * p**k * (1 - p)**(n - k) for k in range(n // 2 + 1, n + 1))

# 1. 多数投票：独立票 vs 难题易题混合
mix = [(0.6, 0.9), (0.4, 0.4)]                 # （题目占比，单样本准确率）
print("  n   indep p=0.7   mixture (mean 0.7)   simulated mixture")
for n in [1, 3, 5, 11, 25, 51, 101]:
    sim = 0
    for _ in range(20000):
        p = 0.9 if rng.random() < 0.6 else 0.4
        sim += sum(rng.random() < p for _ in range(n)) > n / 2
    exact_mix = sum(w * majority_exact(p, n) for w, p in mix)
    print(f"{n:3d}   {majority_exact(0.7, n):10.4f}   {exact_mix:18.4f}   {sim / 20000:17.4f}")

# 2. pass@k：无偏估计 vs 朴素的代入估计，真实 p = 0.15 的单题
def pass_at_k(n, c, k):
    if n - c < k:
        return 1.0
    return 1.0 - math.prod(1 - k / i for i in range(n - c + 1, n + 1))

p, n, k, reps = 0.15, 20, 5, 100000
true = 1 - (1 - p)**k
unb = naive = 0.0
for _ in range(reps):
    c = sum(rng.random() < p for _ in range(n))
    unb += pass_at_k(n, c, k); naive += 1 - (1 - c / n)**k
print(f"\ntrue pass@{k} = {true:.4f}  unbiased mean = {unb / reps:.4f}  naive mean = {naive / reps:.4f}")
print(f"example n=20, c=3, k=5: {pass_at_k(20, 3, 5):.4f}  (comb form {1 - math.comb(17, 5) / math.comb(20, 5):.4f})")

# 3. 带不完美验证器的 best-of-n
# 正确样本打分 N(2, 1)；错误样本 N(0, 1)，除了 2% 能骗过它的错误样本：N(3.5, 1)
def best_of_n(n, p=0.3, trials=4000):
    wins = 0
    for _ in range(trials):
        best, ok = -1e9, False
        for _ in range(n):
            if rng.random() < p:
                s, good = rng.gauss(2, 1), True
            else:
                s, good = (rng.gauss(3.5, 1) if rng.random() < 0.02 else rng.gauss(0, 1)), False
            if s > best:
                best, ok = s, good
        wins += ok
    return wins / trials
print("\n   n   pass@n (perfect verifier)   best-of-n (noisy verifier)")
for n in [1, 4, 16, 64, 256, 1024]:
    print(f"{n:4d}   {1 - 0.7**n:25.4f}   {best_of_n(n):26.4f}")
```

独立一列如[[#thm-condorcet]]预测的那样升到 $1$；单样本准确率相同的混合则先在 $n = 3$ 达峰、随后衰减到 $0.6$，正如[[#thm-mixture]]预测；模拟与精确值在抽样误差（约 $0.003$）内吻合。无偏估计量平均到真实值 $0.5563$ 的 $0.0003$ 之内，而代入估计量低了将近四个百分点——这样的偏差会让每个模型在大 $k$ 时都显得更差。会出错的验证器下的 best-of-$n$ 在 $n = 16$ 附近达峰，然后回落到大约单样本的准确率，而一个完美的验证器几乎总能选对。

::: history
孔多塞（Condorcet，1785）证明了：独立评审团成员各自对多于错时，多数正确率随评审团扩大而几乎必然趋于全对；相关的情形至少自 1980 年代起就在社会选择理论中被研究。集成与投票是机器学习中的老想法（bagging，Breiman 1996）。对语言模型，Cobbe 等（2021）训练验证器在采样的 GSM8K 解答中做选择，Chen 等（2021）随 Codex 模型引入了 HumanEval 与 pass@$k$ 的无偏估计量。Wang 等于 2022 年 3 月贴出《Self-consistency improves chain of thought reasoning in language models》（ICLR 2023）。Li 等（2023）把多样的提示与验证器加权投票结合，Lightman 等（2023）为 best-of-$n$ 比较了结果验证器与过程验证器，Chen 等（2023）提出通用自洽性，Zhang 等（2024）训练了生成式验证器。Brown 等（2024）测量了覆盖率随数百乃至数千样本持续增长、而选择方法跟不上它的现象。
:::

::: summary
- **自洽性**采样 $n$ 条推理路径、返回相对多数答案；得票比例估计**边际**答案概率 $p_\theta(a\mid x) = \sum_z p_\theta(z,a\mid x)$，所以投票找的是边际的众数，而不是最大概率路径的终点。
- 独立的二元投票：$P_{n+2} - P_n = \binom{2m+1}{m}(pq)^{m+1}(2p-1)$：$p > 1/2$ 时多数准确率升到 $1$，$p < 1/2$ 时降到 $0$（**孔多塞**）；所需的 $n$ 按 $(p - \frac12)^{-2}$ 增长。
- 在有题目难度 $P$ 时票相关，多数准确率趋于 $\mu(P > \frac12)$，它可能*低于*单样本准确率 $\E P$。一致性是相对信号，不是校准好的概率。
- **pass@$k$** $= 1 - (1-p)^k$；$n$ 个样本、$c$ 个正确时，$1 - \binom{n-c}k/\binom nk = 1 - \prod_{i=n-c+1}^{n}(1 - k/i)$ 无偏，而代入的 $1 - (1-c/n)^k$ 低估。
- 配验证器的 **best-of-$n$** 以 pass@$n$ 为上界；不完美的验证器可能让准确率随 $n$ 增大而下降，因为更多的样本纳入了更多骗过它的错误解答。
:::

::: exercise 三票 {level=1 check="0.784"}
每个样本以概率 $0.7$ 独立正确。$3$ 个样本的多数正确的概率是多少？
::: solution
$0.7^3 + 3\cdot0.7^2\cdot0.3 = 0.343 + 0.441 = 0.784$。

::: exercise 由十个样本求 pass@$3$ {level=1 check="8/15"}
某题抽了十个样本，$2$ 个正确。把 pass@$3$ 的无偏估计写成精确分数。
::: solution
$1 - \binom83/\binom{10}3 = 1 - 56/120 = 64/120 = 8/15\approx0.533$。乘积形式：$1 - (1 - 3/9)(1 - 3/10) = 1 - \frac23\cdot\frac7{10} = 1 - \frac{14}{30} = \frac{8}{15}$。

::: exercise 混合的极限 {level=1 check="0.7"}
某基准 $70\%$ 的题目上模型以概率 $0.8$ 正确，其余 $30\%$ 上以概率 $0.3$ 正确。多数投票的极限准确率是多少？高于还是低于单样本准确率？
::: solution
由[[#thm-mixture]]，极限为 $\mu(P > 1/2) = 0.7$。单样本准确率为 $0.7\cdot0.8 + 0.3\cdot0.3 = 0.65$，所以这里投票有帮助，极限下提高 $5$ 个百分点。
:::

::: exercise 孔多塞的一步 {level=2 check="0.03456"}
对 $p = 0.6$，用[[#eq-condorcet-step]]计算 $P_5 - P_3$，并与 $P_3$、$P_5$ 的直接值核对。
::: solution
取 $m = 1$：$\binom31(0.6\cdot0.4)^2(2\cdot0.6 - 1) = 3\cdot0.0576\cdot0.2 = 0.03456$。直接计算：$P_3 = 0.216 + 0.432 = 0.648$，$P_5 = 0.07776 + 0.2592 + 0.3456 = 0.68256$，而 $0.68256 - 0.648 = 0.03456$。
:::

::: exercise 要多少票？ {level=2 check="231"}
用霍夫丁界 $1 - P_n\le\exp(-2n(p - \frac12)^2)$，求能保证 $p = 0.6$ 的独立样本多数投票出错概率不超过 $0.01$ 的最小奇数 $n$。
::: solution
要求 $\exp(-2n\cdot0.01)\le0.01$，即 $n\ge\ln(100)/0.02 = 230.26$。最小奇数是 $231$。精确的二项计算需要的少得多（$n = 133$），因为霍夫丁界偏保守；但关于 $(p - \frac12)^{-2}$ 的标度是正确的。
:::
:::

::: exercise 误差分散时的相对多数 {level=2 check="0.448"}
某模型的答案以概率 $0.4$ 正确，并以概率 $0.2$ 各取三个不同错误值之一。$3$ 个样本、平票均匀随机裁定时，相对多数投票正确的概率是多少？
::: solution
正确答案在有至少 $2$ 张正确票时直接获胜：$3\cdot0.4^2\cdot0.6 + 0.4^3 = 0.288 + 0.064 = 0.352$。恰有 $1$ 张正确票时，若两张错误票不同仍可能并列第一：已知两票皆错时它们相等的概率是 $3\cdot0.2^2/0.6^2 = 1/3$，所以恰有一张正确票、两张错误票互不相同的概率是 $3\cdot0.4\cdot0.36\cdot\frac23 = 0.288$，此时三向平票有 $1/3$ 的概率判给正确答案，贡献 $0.096$。合计 $0.352 + 0.096 = 0.448$，高于二元多数的值 $0.352$。
:::
:::

::: exercise 延森与代入估计量 {level=2}
直接证明 $k = 2$ 时，代入估计量 $1 - (1-\hat p)^2$（$\hat p = c/n$）的期望为 $1 - (1-p)^2 - p(1-p)/n$，并证明[[#eq-passk]]在 $k = 2$ 时等于 $1 - \frac{(n-c)(n-c-1)}{n(n-1)}$。
::: solution
$\E(1-\hat p)^2 = (1 - \E\hat p)^2 + \Var\hat p = (1-p)^2 + p(1-p)/n$，其中用了二项比例的方差 $\Var\hat p = p(1-p)/n$。于是 $\E[1 - (1-\hat p)^2] = 1 - (1-p)^2 - p(1-p)/n$：向下偏的量恰为 $\hat p$ 的方差。无偏估计量：$\binom{n-c}{2}/\binom n2 = \frac{(n-c)(n-c-1)}{n(n-1)}$。其期望可由 $\E[(n-c)(n-c-1)] = n(n-1)(1-p)^2$ 验证——这是失败次数 $n - c$ 的二项计数的二阶阶乘矩。
:::

::: exercise best-of-$n$ 的转折 {level=3}
在[[#ex-fool]]的验证器模型中取 $n$ 极大的极限。正确样本与“可信”错误样本的个数分别约为 $0.3n$ 与 $0.014n$，寻常的错误样本不再要紧。(a) 求 best-of-$n$ 正确概率的极限，并解释它。(b) 若“可信”的错误解答打分为 $\mathcal N(2, 1.5^2)$——均值与正确解答相同、散布更大——结论会如何变化？
::: solution
(a) $n$ 大时，best-of-$n$ 正确当且仅当 $\mathcal N(2,1)$ 约 $0.3n$ 个抽样的最大值超过 $\mathcal N(3.5,1)$ 约 $0.014n$ 个抽样的最大值。$M$ 个标准正态的最大值约按 $\sqrt{2\ln M}$ 增长，所以两个最大值分别按 $2 + \sqrt{2\ln(0.3n)}$ 与 $3.5 + \sqrt{2\ln(0.014n)}$ 增长。其差为 $\sqrt{2\ln(0.3n)} - \sqrt{2\ln(0.014n)} - 1.5$，而 $\sqrt{2\ln(an)} - \sqrt{2\ln(bn)} = \frac{2\ln(a/b)}{\sqrt{2\ln an} + \sqrt{2\ln bn}}\to0$，所以“可信”组 $1.5$ 的领先终将占优，选对的概率缓慢地趋于 $0$——清单里 $n = 1024$ 的 $0.33$ 正走在下坡路上。(b) 均值相同而散布更大时，错误组的最大值按 $2 + 1.5\sqrt{2\ln(0.014n)}$ 增长，对阵 $2 + \sqrt{2\ln(0.3n)}$；$1.5$ 这个因子在 $n$ 大时取胜，所以 best-of-$n$ 依旧终将偏爱错误解答。任何右侧尾部比正确解答的分数分布更重的错误模式，终将被选中。
:::
:::

::: exercise 精确实现相对多数投票 {level=3}
写一个纯 Python 函数 `plurality_accuracy(pi, n)`，精确计算 $n$ 个独立样本的相对多数投票返回答案 $0$ 的概率，其中 `pi` 是各答案的概率表（答案 $0$ 正确），平票均匀随机裁定。用分布 $(0.4, 0.35, 0.25)$ 与 $(0.4, 0.2, 0.2, 0.2)$ 对照[[prompting-rag/prompt-design#ex-competitor]]中的表，在 $n = 3$ 与 $n = 5$ 处检验。
::: solution
用多项分布枚举所有得票计数向量：

```python
import math

def compositions(n, parts):
    if parts == 1:
        yield (n,); return
    for i in range(n + 1):
        for rest in compositions(n - i, parts - 1):
            yield (i,) + rest

def plurality_accuracy(pi, n):
    total = 0.0
    for counts in compositions(n, len(pi)):
        prob = math.factorial(n)
        for c, q in zip(counts, pi):
            prob *= q**c / math.factorial(c)
        top = max(counts)
        if counts[0] == top:
            total += prob / counts.count(top)     # 随机平票裁定
    return total

for pi in [(0.4, 0.35, 0.25), (0.4, 0.2, 0.2, 0.2)]:
    print(pi, [round(plurality_accuracy(pi, n), 3) for n in (1, 3, 5, 11)])
```

```text
(0.4, 0.35, 0.25) [0.4, 0.422, 0.443, 0.493]
(0.4, 0.2, 0.2, 0.2) [0.4, 0.448, 0.509, 0.635]
```

这些值与表中一致。计数向量的个数是 $\binom{n+K-1}{K-1}$（$K$ 个答案），对本处使用的规模而言很小；$n$ 大时，按答案做动态规划更快。
