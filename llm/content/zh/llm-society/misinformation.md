撰写一篇流畅可信的新闻稿，过去需要一个人花上一小时；语言模型几秒钟就能生成一篇，花费远不到一美分。为不同受众定制上千条消息变体、同时与许多人维持对话、模仿某个本地社区成员的口吻，如今都变得极其便宜。这些事实引发了广泛的担忧：语言模型会用谎言淹没信息环境，并大规模操纵舆论。另一些研究者则认为这种担忧被夸大了：虚假信息的瓶颈从来不是内容的供给，而是受众的注意力与信任——得到它们的成本并不比以前更低。

本章用证据考察这个问题。它先界定术语、给出威胁模型，然后综述关于 AI 生成的信息与对话有多大说服力的实验研究——连同它们测得的效应量、样本量与局限。接着转向**检测**：为什么区分人类文本与机器文本的分类器并不可靠，包括一个用两个分布之间的距离给出任何检测器性能上限的证明，以及为什么基率使得错误指控成为一个核心问题。数字水印要求生成方的配合，其构造见[[llm-society/copyright-provenance#alg-watermark]]；这里讨论它针对虚假信息能做什么、不能做什么。本章以反制措施与主要分歧作结。

这一领域的成果有时效且脆弱：模型每隔几个月就在变化，多数研究使用少数几个国家的在线调查样本，而且接触信息后立刻测得的效应往往会消退。下面每个结果都注明了出处，请以此为前提阅读。

## 术语与威胁模型 {#sec-terms}

::: definition 虚假信息、蓄意虚假信息与有害真实信息 {#def-misinfo}
沿用 Wardle 与 Derakhshan（2017）的区分：**虚假信息**（misinformation）指并非出于欺骗意图而传播的虚假或误导性信息；**蓄意虚假信息**（disinformation）指蓄意制造或传播、用以欺骗或造成伤害的虚假信息；**有害真实信息**（malinformation）指为造成伤害而传播的真实信息（例如泄露的私人数据）。**影响力行动**（influence operation）指影响目标受众的观点或行为的协同努力，其背后的行动者往往隐藏身份。
:::

语言模型与这三类都有关。它们可能无意地产出虚假信息——一个自信而错误的答案就是幻觉（[[prompting-rag/hallucination]]）——也可能被用作蓄意虚假信息的工具。Goldstein 等（2023）是乔治敦大学安全与新兴技术中心（Georgetown's Center for Security and Emerging Technology）、OpenAI 与斯坦福互联网观察站的研究者合写的报告，他们从三个维度分析了语言模型可能如何改变影响力行动：

- **行动者**：更便宜的内容可能让更多、资源更少的行动者开展行动。
- **行为**：行动可以规模化、个性化，并进行交互式对话，而不是广播固定的消息。
- **内容**：消息可能更具说服力、在语言与文化上更地道，也更难靠过去曾暴露行动的那些文体错误被识别。

把经济学论证说准确是值得的，因为威胁论者与怀疑论者的分歧正在这里。

::: example 内容的成本与分发的成本 {#ex-cost}
某行动想要 $10{,}000$ 条互不相同的社交媒体帖子。一名受雇写手每小时写 $20$ 条，时薪 US\$10；语言模型 API 每百万输出词元收费 US\$2，一条帖子约 $60$ 个词元。一张能够分发帖子的虚假账号网络，每个账号每天维护费用 US\$0.50，该行动运营 $500$ 个账号、运行 $30$ 天。比较内容的成本与分发的成本。
::: solution
人工撰写：$10{,}000/20 = 500$ 小时，US\$5,000。模型：$10{,}000\cdot60 = 6\times10^5$ 个词元，US\$1.20，外加几小时的人力用于设置与检查。分发：$500\cdot30\cdot0.50 = $ US\$7,500。模型把内容成本降低了三个数量级，但在这份（风格化的）预算里，内容本来就不到总额的一半，而分发——账号、躲避平台检测、获取粉丝——没有变化。怀疑论者（例如 Simon、Altay 与 Mercier，2023）认为这才是典型情形；也有人回应说，模型还降低了让虚假账号显得真实、让对话得以进行、以及用行动者不会说的语言生产内容的成本。
:::
:::

## 人能分辨吗？ {#sec-human-detection}

几项研究发现，人们在区分人类文本与模型文本时表现接近随机。Jakesch、Hancock 与 Naaman（2023）发现，参与者识别 AI 生成的自我介绍（来自职业、服务行业与约会资料）的准确率接近 $50\%$，而且他们依赖有缺陷的启发式——例如把第一人称代词与家庭话题当作人类写作的标志——这些启发式可以被利用，让 AI 文本显得比人类文本更像人类。Spitale、Biller-Andorno 与 Germani（2023）发现，参与者无法区分 GPT-3 写的推文与人类写的推文，而且当虚假消息出自 GPT-3 之手时，他们更容易认出真实信息、更难认出虚假信息。这些结果只涉及当时的模型与参与者；它们表明，曾经帮助揭露早期行动的那些文体破绽并不可靠。

## 语言模型有多大的说服力？ {#sec-persuasion}

说服研究在随机化实验中测量态度变化：参与者被随机分配去阅读一条消息（或进行一场对话）或进入对照组，然后报告对某个主张的认同程度。所报告的量是**处理效应**，通常是平均认同度或认同比例之差。

::: definition 平均处理效应与标准化效应量 {#def-ate}
设结果为 $Y$（例如 0–100 量表上的认同度），处理 $W\in\{0, 1\}$ 随机分配，**平均处理效应**为 $\tau = \E[Y\mid W = 1] - \E[Y\mid W = 0]$，用样本均值之差 $\hat\tau = \bar Y_1 - \bar Y_0$ 估计，标准误为 $\sqrt{s_1^2/n_1 + s_0^2/n_0}$。**标准化效应量**（Cohen's $d$）为 $\tau/\sigma$，其中 $\sigma$ 是结果的标准差；按惯例 $d\approx0.2$ 算"小"效应。
:::

主要发现如下（按各自给出的日期）：

- **书面宣传。** Goldstein、Chao、Grossman、Stamos 与 Tomz（2024）向美国受访者展示来自隐蔽外国行动的真实宣传文章，或 GPT-3 就同一论点撰写的文章。对照组对论点的认同度约为 $24\%$，读原始宣传后约为 $47\%$，读 GPT-3 的文章后约为 $44\%$；对模型输出做轻量的人工润色后，效果与原文相当甚至更强。
- **政策信息。** Bai、Voelkel、Eichstaedt 与 Willer（2025）发现，GPT-3 就政策议题（如枪支管控与碳税）撰写的消息，在 0–100 量表上使态度移动几个点——与人类撰写的消息相当，也与后者一样小。
- **微定向。** Hackenburg 与 Margetts（2024）发现，针对参与者人口特征与政治画像定制的消息，与同一模型生成的通用消息相比说服力并无显著提升；两者的效应都是几个百分点。
- **规模。** Hackenburg 等（2025）比较了 $24$ 个大小不同的模型，发现单条消息的说服力随规模上升但收益急剧递减、大致呈对数关系；一旦考虑到基本任务完成度（连贯、不跑题），最大的模型只比小得多的模型略强一点。
- **对话。** Salvi 等（2025，*Nature Human Behaviour*）让参与者就某个议题与人类或 GPT-4 辩论。当 GPT-4 获得对手的基本人口统计信息时，它平均比人类辩手更有说服力；没有这些信息时，差异不显著。Hackenburg 与英国 AI 安全研究所的同事们（2025）的一项大规模研究让数万名英国参与者与多个模型对话，报告称：为信息密度高的论证而做后训练与提示，比个性化或模型规模更能提升说服力——而且让模型更有说服力的那些改动，平均也让其主张的准确性更低。
- **纠正信念。** Costello、Pennycook 与 Rand（2024，*Science*）让认可某个阴谋论的人与 GPT-4 Turbo 进行简短对话，并指示模型用证据反驳该理论。对该理论的相信程度平均下降了约 $20\%$，并在两个月后的回访中保持。说服既能服务于准确性，也能破坏它。

::: warning 调查实验中的显著效应不是对选举的效应
多数研究测量的是一次接触后立刻的态度变化，对象是拿报酬来认真作答的在线调查参与者。这类情境中的效应通常是几个点，并且往往在几周内消退。在现实环境中，一条消息要与许多消息竞争，而且大多数人根本看不到它：Kalla 与 Broockman（2018）对美国大选中竞选接触的荟萃分析发现，平均说服效应接近于零。反过来，在势均力敌的竞争中，或在多次接触的累积下，小效应也可能重要。无论"AI 说服威力很大"还是"毫无效果"，都无法从单个实验推出。
:::

这些效应的规模让统计学变得要紧。一个模拟可以说明一项研究需要多大的精度。

```python
import math, random
rng = random.Random(2024)

# 1. 一个模拟的说服实验：态度取值 0-100，标准差 25，
#    阅读一条 AI 撰写的消息的真实效应为 +3 分。
def experiment(n, effect=3.0, sd=25.0):
    control = [rng.gauss(50, sd) for _ in range(n)]
    treated = [rng.gauss(50 + effect, sd) for _ in range(n)]
    diff = sum(treated) / n - sum(control) / n
    var = lambda xs: sum((x - sum(xs) / n) ** 2 for x in xs) / (n - 1)
    se = math.sqrt(var(control) / n + var(treated) / n)
    return diff, diff - 1.96 * se, diff + 1.96 * se

for n in (200, 1000, 5000):
    d, lo, hi = experiment(n)
    print(f"n per arm {n:5d}: estimated effect {d:5.2f} points, 95% CI [{lo:5.2f}, {hi:5.2f}]")

# 2. 检测器：给定全变差距离时的 AUROC 上限，以及精确率
def auroc_bound(tv):
    return 0.5 + tv - tv ** 2 / 2

for tv in (0.1, 0.3, 0.6, 0.9):
    print(f"TV {tv:.1f}: best possible AUROC {auroc_bound(tv):.3f}")

def precision(prevalence, tpr, fpr):
    return prevalence * tpr / (prevalence * tpr + (1 - prevalence) * fpr)

for prev in (0.5, 0.1, 0.02):
    print(f"AI share {prev:4.2f}: precision {precision(prev, 0.9, 0.01):.3f} (FPR 1%),"
          f" {precision(prev, 0.9, 0.2):.3f} (FPR 20%)")
```

每组 $200$ 名参与者时，一个真实大小为 $3$ 分（$d = 0.12$）的效应被估计成了 $-1.1$——符号相反——区间宽达 $\pm5$ 分；即便每组 $1{,}000$ 人，区间也从 $0.4$ 跨到 $4.8$。比较两种说服条件（AI 对人工、定向对通用）需要检测更小的差异，这就是为什么这一文献中的零结果往往只是不确定，而不是"没有差异"的证据。输出的后半部分预告了[[#sec-detection]]。

要在双侧检验 $\alpha = 0.05$、功效 $80\%$ 下检测 $d = 0.1$ 的效应，两组实验每组需要多少参与者？要比较两个效应相差 $d = 0.05$ 的处理呢？
::: solution
标准近似是每组 $n = 2(z_{1-\alpha/2} + z_{1-\beta})^2/d^2$，取 $z_{0.975} = 1.960$、$z_{0.8} = 0.842$：$(2.802)^2 = 7.85$，故 $n = 2\cdot7.85/0.01 = 1570$。$d = 0.05$ 时，每组 $n = 2\cdot7.85/0.0025 = 6280$。效应减半，样本量变四倍。每种条件只有几百名参与者的研究，无法可靠地检测出这场争论所围绕的那些差异。

### 在真实行动中的使用

来自现实环境的证据多数来自发现这些行动的公司与研究者。OpenAI 的威胁报告自 2024 年 5 月起，陆续描述了捣毁数个隐蔽影响力行动——归因于俄罗斯、中国、伊朗与以色列的行动者——它们用其模型生成多种语言的帖子、评论与文章；报告评估认为，没有一个行动因此获得了可观的真实受众参与。其他平台与公司的报告也做出了类似观察。对 2024 年多国大选的分析普遍发现存在 AI 生成内容，包括深度伪造的音频与图像，但很少发现它改变了选举结果（例如图灵研究所新兴技术与安全中心关于 2024 年英国、欧盟与美国选举的报告）。值得注意的事件包括：2023 年 9 月斯洛伐克大选前流传的一段伪造的某政党领导人音频，以及 2024 年 1 月新罕布什尔州初选前模仿拜登总统声音的 AI 生成自动语音电话；此后美国联邦通信委员会于 2024 年 2 月裁定，自动语音电话中的 AI 生成声音属于对人工声音的现行限制的范围。

这些证据有两点需要注意。被发现的行动可能恰恰是最不高明的那些；而"对结果没有可测量的影响"很难确立，也不能排除对信任的影响。**骗子红利**（liar's dividend，Chesney 与 Citron，2019）是一种相关的伤害：当伪造品变得常见，真实的证据也可以被斥为伪造。

## 检测机器生成的文本 {#sec-detection}

检测要求分类器判断一段文本是否由模型生成。存在三种进路：**训练型分类器**（在有人类与模型文本标签的数据上微调）、来自打分模型的**零样本统计量**，例如 DetectGPT（Mitchell 等，2023），它检验一段文本是否位于模型对数概率的局部极大值附近；以及需要生成方配合的**数字水印**。前两种面临一个根本限制。

::: definition 全变差距离 {#def-tv}
对文本上的两个分布 $P$ 与 $Q$，**全变差距离**为

$$
\operatorname{TV}(P, Q) = \max_{S}\,\lvert P(S) - Q(S)\rvert = \tfrac12\sum_x\lvert P(x) - Q(x)\rvert,
$$

即两个分布对任意文本集合所赋予概率之差的最大值。
:::

::: proposition 检测的上限（Sadasivan 等，2023）{#prop-auroc}
设 $M$ 为机器生成文本的分布，$H$ 为人类文本的分布，$\operatorname{TV}(M, H) = t$。对任何检测器、任何阈值，$\text{TPR} - \text{FPR}\le t$。因此其 ROC 曲线下面积满足

$$
\text{AUROC} \le \frac12 + t - \frac{t^2}{2}.
$$ {#eq-auroc}
:::

::: proof
固定阈值的检测器标记一个文本集合 $S$。其真阳性率为 $M(S)$，假阳性率为 $H(S)$，故由[[#def-tv]]，$\text{TPR} - \text{FPR} = M(S) - H(S)\le t$。于是 ROC 曲线上每一点 $(\text{FPR}, \text{TPR})$ 都满足 $\text{TPR}\le\min(\text{FPR} + t, 1)$。AUROC 是曲线下面积，故不超过 $x\mapsto\min(x + t, 1)$ 在 $[0, 1]$ 下的面积：

$$
\int_0^{1-t}(x + t)\,dx + \int_{1-t}^1 1\,dx = \frac{(1-t)^2}{2} + t(1 - t) + t = \frac12 + t - \frac{t^2}{2}.
$$
:::

::: example 全变差距离与最优检测器 {#ex-tv}
假设每段文本落入四个风格类别之一，人类写作者的类别概率为 $(0.4, 0.3, 0.2, 0.1)$，某模型为 $(0.25, 0.25, 0.25, 0.25)$。计算 $\operatorname{TV}$、按整个类别标记的最优检测器，以及 AUROC 上限。
::: solution
$\operatorname{TV} = \tfrac12(0.15 + 0.05 + 0.05 + 0.15) = 0.2$。使 $M(S) - H(S)$ 最大的集合由模型概率更高的类别组成：第三与第四个。标记它们得到 $\text{TPR} = 0.5$、$\text{FPR} = 0.3$，且 $\text{TPR} - \text{FPR} = 0.2 = \operatorname{TV}$，达到上界。AUROC 上限为 $0.5 + 0.2 - 0.02 = 0.68$。对这批文本，无论检测器多么精巧，只要它想捕获一半的机器文本，就至少会错误标记 $0.3$ 的人类文本。
:::
:::

随着模型对类人文本的模仿越来越好，$t$ 缩小，上限逼近 $0.5$——一枚硬币的水平。这个上界针对单段文本。Chakraborty 等（2023）指出了反面：若检测器看到 $n$ 个独立样本（同一账号的多段文本），联合分布之间的距离随 $n$ 增长，因此即使单段文本无法检测，对*来源*的检测仍可能可行。两点都对；哪个适用取决于要检测的是什么。

实践中，检测器的表现比这些上限更差，而且参差不齐。OpenAI 于 2023 年 1 月发布了一个分类器，它把 $26\%$ 的 AI 撰写文本标为"可能由 AI 撰写"，同时把 $9\%$ 的人类文本标错，并因准确率过低于 2023 年 7 月撤下。Liang 等（2023）发现，七个检测器平均把约 $61\%$ 由非母语英语写作者（为 TOEFL 考试而写）撰写的文章判为 AI 生成，却几乎从不误判美国八年级学生的文章——因为非母语写作往往困惑度更低，而这恰恰是检测器所依赖的信号。在改写之下，检测准确率也会大幅下降（Krishna 等，2023）。

::: example 课堂里的检测器 {#ex-classroom}
某检测器标记 $90\%$ 的 AI 撰写文章与 $1\%$ 母语写作者的人类文章，但标记 $20\%$ 非母语写作者的人类文章。在一个 $10\%$ 的文章由 AI 撰写的班上，被标记的文章中 AI 撰写所占的比例，对母语与非母语写作者各是多少？
::: solution
母语：$1000$ 篇文章中 $100$ 篇 AI、$90$ 篇被标记；$900$ 篇人类、$9$ 篇被标记；精确率 $90/99 = 0.909$。非母语：$90$ 篇 AI 被标记，$180$ 篇人类被标记；精确率 $90/270 = 0.333$。对非母语写作者，每三次标记就有两次是错误指控。清单第三块给出了这些数值。一个整体统计量可接受的检测器，可能在一个子群体上不可接受，这就成了[[llm-society/bias-fairness]]那样的公平性问题。
:::
:::

mode: test
prevalence: 0.1
sensitivity: 0.9
specificity: 0.8
caption: 以自然频次呈现[[#ex-classroom]]中非母语写作者的情形："condition" 表示是否由 AI 撰写，阳性检验即被标记。在 $20\%$ 的假阳性率（特异度 $0.8$）下，只有三分之一的标记是对的。把特异度提高到 $0.99$，即可看到母语写作者的情形。
:::

::: warning 检测器分数本身不是不当行为的证据
检测器的输出是概率性的、在不同人群之间没有校准、并且对某些写作者群体有偏。把它当作唯一证据——用来让学生课程不及格或删除帖子——产生错误指控的比率将由基率决定，而基率往往未知。许多大学正是因此建议不要依赖检测器（见[[llm-society/work-education]]）。
:::

### 针对虚假信息的数字水印

数字水印（[[llm-society/copyright-provenance#alg-watermark]]）通过刻意改变机器分布来绕开[[#prop-auroc]]的上限，使得对*知道密钥的人*而言，带水印文本与人类文本之间的 $\operatorname{TV}$ 很大。它在合作的情境中有用——提供商检查某段文本是否来自自家服务，或平台检查来自共享密钥的提供商的内容——但针对蓄意虚假信息，它有三个局限。行动者可以使用不带水印的模型，包括在本地运行的开放权重模型；他们可以改写；而水印只能说明文本来自某个模型，不能说明它是假的，何况大量 AI 生成文本是正当的。为真实内容做溯源（用 C2PA 凭据为真实的照片与录音签名，[[llm-society/copyright-provenance#def-c2pa]]）则从另一侧逼近这个问题。

## 反制措施 {#sec-countermeasures}

应对作用于多个层面，各自的证据基础强弱不同。

- **模型与提供商政策。**使用政策禁止欺骗性的影响力行动与冒名顶替；模型经过训练会拒绝某些请求（例如批量撰写虚假的草根式好评）；提供商监测滥用并发布威胁报告。这些措施提高了滥用特定服务的成本，但开放权重模型可以脱离它们获得。
- **平台措施。**检测协同的非真实行为（coordinated inauthentic behaviour）——协同行动的账号网络——并不依赖检测 AI 文本，而且仍是针对影响力行动的主要工具。对合成媒体的标识与溯源元数据正日益被法律要求（欧盟《人工智能法》的透明度义务、中国 2025 年的标识办法）。
- **受众韧性。**"预先反驳"（prebunking）或"接种"——让人接触操纵手法的弱化样本——在实地与实验室研究中提高了对这些手法的识别（Roozenbeek 等，2022），但效应会随时间消退。准确性提示（请人们在转发前先想一想内容是否准确）在若干实验中提高了转发的辨别力（Pennycook 与 Rand，2022）。
- **AI 辅助的事实核查。**模型可以大规模检索证据并起草核查，而 Costello 等的对话研究表明，基于证据的对话能够改变信念。但 DeVerna 等（2024）发现，向人们展示 LLM 生成的新闻标题事实核查并没有提高他们辨别真假的能力，而且当模型出错或不确定时，反而可能降低对真实标题的相信程度。

### 主要分歧

争论存在于两种立场之间，双方都有严肃的研究者持守。一种看法认为，生成式 AI 显著增加了信息环境的风险：它降低欺骗性内容的成本并提高其质量与个性化程度，使大规模的交互式说服成为可能，并侵蚀人们对真实证据的信任；早期实地证据之所以令人安心，只是因为恶意行为者的能力与采用仍在发展之中。另一种看法认为，对虚假信息的需求有限，且由先入之见与身份驱动，而非由内容供给驱动；人们本已能接触到大量低质量信息；说服效应又小又短暂；而且警报本身也有代价——它为审查提供借口、降低对真实信息的信任、并把注意力从虚假信息的既有成因上引开。以上综述的证据目前与两种看法都相容：实验效应真实存在但很小，实地效应难以测量，而能力仍在提升。证据最清楚地表明的是：无论靠人还是靠分类器，检测 AI 生成的文本都不可靠。

::: quiz
一项研究发现，GPT 撰写的政治信息使认同度在 0–100 量表上移动 $3$ 分，与人类撰写的信息相同；每组有 $500$ 名参与者，AI 与人类信息之差的 $95\%$ 置信区间为 $[-3, 3]$ 分。下列哪种解释最恰当？
- [ ] 已证明 AI 信息与人类信息的说服力完全相同。
- [x] 两类信息的效应都很小；该研究无法排除两者之间存在中等程度差异的可能，无论哪个方向。
- [ ] 因为 $3$ 分很小，所以 AI 信息没有说服力。
- [ ] 该研究表明 AI 说服将改变选举结果。
::: solution
差的置信区间是围绕零的 $\pm3$ 分，这与 AI 信息的效力高至人类的两倍、低至零的情形都相容。"无显著差异"不是"等效"，而调查实验中的效应与选举之间也没有直接的关系。
:::
:::

::: history
对自动化宣传的担忧早于大模型：选举中的社交机器人自 2016 年前后即有研究。2019 年 OpenAI 以生成误导性新闻的滥用风险为由，分阶段发布了 GPT-2；Zellers 等（2019）构建了 Grover——一个既能生成假新闻也能检测假新闻的模型，并论证最好的检测器就是生成器。Solaiman 等（2019）研究了发布的社会影响。此后出现了 GLTR（Gehrmann、Strobelt 与 Rush，2019）与 DetectGPT（Mitchell 等，2023）等检测器，Sadasivan 等（2023）则论证了根本性的限制。Goldstein 等（2023）界定了影响力行动的威胁；关于模型说服力的实验研究自 2023 年起大量涌现；Costello、Pennycook 与 Rand（2024）展示了通过对话实现的可持久的信念纠正。Kirchenbauer 等（2023）提出了实用的数字水印；2024 年，平台与提供商开始定期发布关于影响力行动中 AI 使用的报告。
:::

::: summary
- 区分虚假信息（无意图）、蓄意虚假信息（欺骗意图）与有害真实信息（真实但有害）；模型可能因幻觉产出第一种，并作为工具服务于第二种。
- 模型把内容成本降低了几个数量级；这一点是否要紧，取决于瓶颈究竟是内容，还是分发与注意力——这是一个核心分歧点。
- 人无法可靠地区分模型文本与人类文本。实验发现 AI 撰写的消息与人类撰写的大致同样有说服力，效应只有几个点，很小；多数研究中个性化增益甚微；规模收益递减；对话可能更有说服力；对话也能持久地纠正错误信念。
- 小效应需要大样本（$d = 0.1$ 时每组约 $1570$ 人）；许多零结果并不确定，调查中的效应未必能迁移到现实环境。
- 任何检测器都满足 $\text{TPR} - \text{FPR}\le\operatorname{TV}$ 与 $\text{AUROC}\le\tfrac12 + t - t^2/2$；实际检测器更弱、在改写之下失效、并对非母语写作者有偏。基率使错误指控成为常态。
- 数字水印只有生成方配合才有效，且只表明来源、不表明真假；反制措施包括基于行为的平台治理、为真实媒体做溯源、预先反驳，以及审慎使用 AI 事实核查。
:::

## 习题

::: exercise 案例归类 {level=1}
判断下列各例属于虚假信息、蓄意虚假信息还是有害真实信息：(a) 聊天机器人错误地告诉用户某种药物在孕期服用是安全的；(b) 某行动发布 AI 生成的文章，谎称某位候选人已经退选；(c) 某人发布某位政治人物的真实家庭住址以煽动骚扰。
::: solution
(a) 虚假信息（内容错误，无欺骗意图——一次幻觉）。(b) 蓄意虚假信息（蓄意的谎言）。(c) 有害真实信息（用真实信息造成伤害）。
:::
:::

::: exercise AUROC 的上限 {level=1 check="0.875"}
若 $\operatorname{TV}(M, H) = 0.5$，任何检测器所能达到的最大 AUROC 是多少？
::: solution
$0.5 + 0.5 - 0.125 = 0.875$。
:::
:::

::: exercise 被标记者的精确率 {level=1 check="0.51"}
某检测器 TPR $0.8$、FPR $0.04$。若 $5\%$ 的文本由 AI 生成，被标记的文本中有多大比例是 AI 生成的？答案保留两位小数。
::: solution
$0.05\cdot0.8 = 0.04$；$0.95\cdot0.04 = 0.038$；精确率 $0.04/0.078 = 0.513\approx0.51$。尽管检测器的错误率看起来很漂亮，近一半的标记是错的。
:::
:::

::: exercise 好的检测器需要多大距离 {level=2 check="0.553"}
要有某个检测器能达到 AUROC $0.9$，全变差距离至少需要多大？保留三位小数。
::: solution
解 $\tfrac12 + t - t^2/2 = 0.9$：$t^2 - 2t + 0.8 = 0$，故 $t = 1 - \sqrt{0.2} = 1 - 0.4472 = 0.553$（另一个根超过 $1$）。
:::
:::

::: exercise 样本量 {level=2 check="393"}
用 $n = 2(z_{1-\alpha/2} + z_{1-\beta})^2/d^2$，取 $z_{0.975} = 1.960$、$z_{0.8} = 0.842$，要在 $\alpha = 0.05$、$80\%$ 功效下检测"小"效应 $d = 0.2$，每组需要多少参与者？向上取整到整数人。
::: solution
$(1.960 + 0.842)^2 = 2.802^2 = 7.851$，故 $n = 2\cdot7.851/0.04 = 392.6$，即每组 $393$ 人。说服信息的效应往往只有这个规模的一半甚至更小，需要的参与者就是四倍或更多。
:::
:::

::: exercise 效应的衰减 {level=2 check="2.5"}
一场对话使对某个虚假主张的信任立刻降低 $10$ 分。假设效应按半衰期 $3$ 周指数衰减。$6$ 周后还剩多少效应？
::: solution
两个半衰期：$10\cdot(1/2)^2 = 2.5$ 分。（Costello 等报告的两个月内衰减远小于此；本题说明为什么要做后续测量。）
:::
:::

::: exercise 一个来源的多篇文本 {level=3}
假设对单段文本，某个检测统计量对人类作者服从分布 $\Normal(0, 1)$，对模型作者服从 $\Normal(\mu, 1)$，$\mu = 0.3$。一个账号发布 $n$ 段文本，检测器对这些文本的统计量取平均。证明平均后的统计量以 $\mu\sqrt n$ 的标准化距离区分两种情形，并求使均值中点处的阈值达到 TPR $= 0.95$、FPR $= 0.05$ 的 $n$。说明这与[[#prop-auroc]]以及 Chakraborty 等的论证的关系。
::: solution
$n$ 个独立统计量的均值服从 $\Normal(0, 1/n)$ 或 $\Normal(\mu, 1/n)$，即均值相差 $\mu\sqrt n$ 个标准差。把阈值取在 $\mu/2$，则 $\text{FPR} = 1 - \Phi(\mu\sqrt n/2)$；令 $\mu\sqrt n/2 = 1.645$ 得 $\sqrt n = 3.29/0.3 = 10.97$，$n = 120.3$，故 $121$ 段文本。对单段文本，两个正态之间的 $\operatorname{TV} = 2\Phi(\mu/2) - 1 = 0.12$，AUROC 上界很低；对 $121$ 段文本，两个联合分布之间的 TV 约为 $0.9$。检测一个账号是否为自动化，可能在检测单段文本不可行时仍然可行——这正是 Chakraborty 等（2023）的要点——前提是这些文本相互独立，且账号不掺入人类文本。
:::
:::

::: exercise 设计一项研究 {level=3}
设计一个实验，检验就某一政策议题，与语言模型进行的个性化多轮对话是否比同一模型的一条静态消息更有说服力。写明实验条件、结果变量、样本量论证、后续测量与伦理保障。
::: solution
一个扎实的设计：(1) 条件——对照（就无关话题进行中性对话）、静态消息、通用对话、个性化对话（模型获得前问卷答案），随机分配；(2) 结果变量——预先登记的题目在实验前后测量的认同度，若可行再加行为指标（如签署请愿书）；(3) 样本量——关键比较（个性化对话对通用对话）的差异可能只有 $d\approx0.05$，每组需要数千人之多（[[#ex-power]]）；预先登记分析方案；(4) 在第 1 周与第 4 周回访，测量效应的持续性；(5) 测量模型所做主张的准确性，因为说服与准确性可能此消彼长；(6) 伦理——知情同意需说明参与者将与 AI 交谈；话题要选在无论哪个方向的说服都不构成伤害、或论证保持平衡的议题；事后告知（debriefing）真实信息；通过伦理审查；不在不知情的用户身上部署（2025 年有大学研究者未经批准在一个 Reddit 论坛上做的实验遭到广泛批评，其结果也未发表）；并谨慎发布任何为说服优化的提示。
:::
