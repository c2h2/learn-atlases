大语言模型是在人类撰写的文本上训练的：图书、新闻报道、百科全书、论坛帖子、代码、科学论文。这些文本中的绝大多数受版权保护，而其作者中的绝大多数从未被征求过意见。把作品复制下来训练模型是否合法、其作者是否应当获得报酬、当模型复现某一段文字时算什么、以及任何人如何判断一段文本或一幅图像的来历——这些是有关这项技术争议最大的问题，横跨法庭、立法机构与公共辩论。

本章尽量以这些问题所需要的精确度来陈述它们。我们先确定复制发生在一个模型生命历程中的哪些环节，然后介绍三个进路不同的法域的法律——美国的合理使用（fair use）、欧盟的文本与数据挖掘例外与《人工智能法》、以及日本《著作权法》第30-4条——以及主要的诉讼：已有结果的注明日期，尚无结果的标明仍在进行。每一方的论点都以其最强形式呈现。后半部分转向**数据来源（provenance）**：记录训练数据、尊重退出机制、为生成内容加标记，其中完整推导绿名单加水印背后的统计检验（Kirchenbauer 等，2023），并介绍 C2PA 内容凭证。

本章内容均不构成法律意见。法律因法域而异、取决于具体事实，且在快速变化；各论断均标注"截至 2026 年"，采信之前应对照最新资料核实。

## 复制行为发生在哪里 {#sec-copying}

版权赋予作者对其作品的专有权利——主要是复制、发行、改编与向公众传播——但受例外限制。一个模型的生命历程包含若干可能构成复制的行为：

1. **收集。**抓取网页或获取图书，会在开发者的服务器上形成作品的复制件。复制件如何取得（经许可、购买、从公开网络抓取、或从未授权的"影子图书馆"下载）在法律上可能有差别。
2. **准备。**清洗、去重与分词会形成更多复制件，有时保存数年、跨模型复用（[[pretraining/training-data]]）。
3. **训练。**梯度下降读取这些复制件并调整参数。权重不是作品的数据库，但模型可能记住某些段落（[[llm-society/privacy-memorisation#def-extractable]]）；能够复现某部作品的权重是否"包含该作品的复制件"存在争议，法院的结论也不一致。
4. **输出。**模型可能输出复现或紧密改写受版权保护作品的文本，或模仿某位作者的风格。输出中的复制是与训练相独立的问题：风格本身通常不受保护，而对表达的紧密复制可能受保护。
5. **检索。**在推理时检索文档的系统（[[prompting-rag/retrieval-augmented-generation]]）会复制并可能展示这些文档，引发的问题更接近搜索引擎与新闻聚合。

把这些行为区分开可以避免一种常见的混淆：认为训练合法，并不说明某个具体输出是否侵权，反之亦然。

## 美国：合理使用 {#sec-us}

美国版权法没有针对文本与数据挖掘的专门例外。该问题由法院在个案中依据**合理使用**（fair use；17 U.S.C. § 107）裁量。

::: definition 合理使用的四项考量因素 {#def-fair-use}
在判断对受版权保护作品的使用是否构成合理使用时，美国法院考虑
1. 使用的**目的与性质**，包括是否具有商业性质、是否具有**转换性**（transformative，即增添了新的目的或不同的性质，而不是替代原作）；
2. 受版权保护作品的**性质**（事实性还是创作性、是否已发表）；
3. 所使用部分相对于作品整体的**数量与实质性**；
4. 该使用对作品**潜在市场或价值的影响**。

各因素综合权衡；没有任何一项单独起决定作用。
:::

两个先例确立了争论的框架。在 *Authors Guild v. Google*（第二巡回上诉法院，2015）中，法院认定谷歌扫描数百万册图书、构建仅显示简短片段的可检索索引构成合理使用：复制整本书对于一个高度转换性的目的是必要的，而片段并不替代原书。在 *Andy Warhol Foundation v. Goldsmith*（联邦最高法院，2023）中，最高法院收窄了"转换性"：当新用途与原作的目的相同且属商业性时，新的含义或信息并不足以支持合理使用。

法院自2025年开始对 AI 训练案件作出裁判。截至 2026 年，主要的一审判决如下：

- *Thomson Reuters v. Ross Intelligence*（特拉华联邦地区法院，2025年2月）：法院认定，复制 Westlaw 法律数据库中的判例摘要用于训练一个竞争性的**非生成式**法律检索工具不构成合理使用，并强调该使用具有商业性、服务于同一市场。该判决已上诉至第三巡回上诉法院。
- *Bartz v. Anthropic*（北加州联邦地区法院，2025年6月）：法院认定，用合法购买并扫描的图书训练语言模型构成合理使用，称其具有高度转换性；但从影子图书馆获取盗版副本组建中心图书馆，不因此获得豁免。双方随后就盗版副本索赔达成了约 US\$15 亿的集体和解，法院于2025年9月予以初步核准。
- *Kadrey v. Meta*（北加州联邦地区法院，2025年6月）：法院就原告作家图书的训练问题判决 Meta 胜诉（简易判决），理由是原告未能提供市场损害的证据，同时强调该判决仅限于这些原告，且在其他案件中市场稀释可能否定合理使用。

还有许多其他案件——包括 *The New York Times v. Microsoft and OpenAI*（2023年12月提起，同时指控输出复现了新闻报道），以及音乐出版商、视觉艺术家与其他作者提起的案件——截至 2026 年仍在审理之中。一审判决不约束其他法院，上诉审可能改变格局。

美国版权局发布了版权与 AI 的三部曲报告（2024–2025）。其中关于训练的部分（2025年5月以预发布形式公布）的结论是：某些训练使用构成合理使用，另一些则否，取决于各项因素；报告还讨论了海量 AI 生成内容与原作竞争（"市场稀释"）是否计入第四项因素。此外，版权局与法院一直认为版权以**人类创作**（human authorship）为前提：在 *Thaler v. Perlmutter*（哥伦比亚特区巡回上诉法院，2025年3月）中，上诉法院维持了机器自主生成的作品不能登记的观点，而人类作出充分创作性贡献（选择、编排、修改）的作品可以在该范围内受到保护。

## 欧盟：文本与数据挖掘例外与《人工智能法》 {#sec-eu}

欧盟采取明确的立法路径。《数字化单一市场版权指令》（Directive on Copyright in the Digital Single Market，Directive (EU) 2019/790）为**文本与数据挖掘**（text and data mining，TDM）——定义为对文本与数据进行自动化分析以生成模式、趋势与关联等信息——创设了两项例外。

::: definition 欧盟的文本与数据挖掘例外 {#def-tdm}
- **第3条**允许研究机构和文化遗产机构为其已合法接触的、以科学研究为目的的作品制作 TDM 所需的复制件。权利人不得作出保留。
- **第4条**允许任何人为 TDM 对其合法可及的作品制作复制件，**除非权利人已明确保留此项使用，"以适当的方式，例如对在线公开的内容采用机器可读的方式"**。复制件可在挖掘所必需的期限内保存。
:::

TDM 例外是否涵盖生成式模型的训练曾有争议；《人工智能法》（Regulation (EU) 2024/1689）在其针对通用人工智能模型提供者的义务中援引第4条，就该法的目的确定了这一点。在一起备受瞩目的一审判决中，汉堡地方法院（2024年9月，*Kneschke v. LAION*）认定非营利组织 LAION 为研究创建图像-文本数据集受研究例外涵盖。

依据《人工智能法》第53条，通用人工智能模型的提供者除其他义务外，须 (c) 建立遵守欧盟版权法的政策，特别是要识别并遵守第4条下的权利保留，"包括借助最先进的技术"；(d) 按照欧盟 AI 办公室提供的模板，编制并公布**足够详细的训练内容摘要**。模板于2025年7月连同自愿性的《通用人工智能行为准则》（General-Purpose AI Code of Practice）一并发布，其版权章节要求签署方（除其他事项外）尊重 robots.txt、不规避付费墙。这些义务自2025年8月2日起适用于自该日起投放市场的模型（已上市的模型宽限至2027年8月2日）。该法还要求以机器可读方式标记合成内容（第50条，自2026年8月起适用；见[[#sec-marking]]）。该法的总体框架见[[llm-society/governance-regulation]]。

这些义务适用于在欧盟市场投放的模型，无论其训练地在何处，这就引发了欧盟版权规则如何适用于依其他法律在境外完成的训练的问题；该法的鉴于条款倾向于认为，无论训练发生在何处，提供者都应当遵守。

欧洲法院也在裁决输出端的问题。2025年11月，慕尼黑地方法院在音乐著作权集体管理组织 GEMA 诉 OpenAI 一案中裁定，模型对歌词的记忆及其在输出中的复现侵犯版权，且不为 TDM 例外所涵盖；该判决系一审，可以上诉。

## 日本：第30-4条 {#sec-japan}

日本于2018年修订《著作权法》，增设了**第30-4条**，常被认为是机器学习领域最宽松的条款之一。

::: definition 日本第30-4条 {#def-art304}
当利用目的不在于享受作品所传达的思想或感情时，可以在该目的所需的限度内、以任何方式利用作品——包括用于**数据分析**（对大量作品的要素进行提取、比较、分类或其他分析）——**但综合考量作品的性质与目的、利用的情形等因素，不合理损害著作权人利益的除外**。
:::

该条不区分商业性与非商业性使用，也不设退出机制。其边界在于但书以及"非享受"目的。日本文化厅的指导文件（《日本关于 AI 与版权的一般理解》，2024 年）认为：以产出复现特定作品创作性表达的内容为目标的训练——例如为模仿某位特定作家的作品并输出而进行微调——可能涉及"享受"目的而在该条之外；规避数据库提供者为防止为分析而复制所采取的技术措施，可能不合理损害其利益。

### 其他法域

英国的 TDM 例外（《版权、外观设计与专利法》（Copyright, Designs and Patents Act 1988）第29A条）仅涵盖非商业性研究。一次政府咨询（2024年12月–2025年2月）提议设立更宽的例外并配以权利人退出机制，招致创意产业的强烈反对和科技公司的支持；读者应核实当前的立场。新加坡《2021年版权法》设有不含退出机制的"计算数据分析"例外。中国《生成式人工智能服务管理暂行办法》（2023）要求提供者使用"合法来源"的训练数据、不侵犯知识产权；中国法院已判决平台对复现受保护角色的输出承担责任（广州互联网法院2024年的 *Ultraman* 案判决）。

## 主要论点 {#sec-arguments}

法律检验的河道里流淌着一场更广泛的争论，有识之士在此意见相左。各主要立场的最强形式大致如下。

**主张允许无需许可的训练（附条件）。**
- *非表达性使用。*训练提取的是关于语言与世界的统计模式，而非特定作品的表达；这类似于人通过阅读而学习，而版权从未赋予作者控制他人从其作品中学到什么的权利。
- *先例与必要性。*法院曾认定为转换性计算目的（检索索引、抄袭检测）复制整部作品属于合理使用。大型模型需要海量而多样的数据；向数以百万计的权利人逐一取得许可并不现实，若强求如此，只会偏向付得起钱的少数公司，巩固在位者。
- *另有救济。*若模型复现了受保护的表达，输出端的侵权法自会适用；无需限制训练本身。

**主张要求同意或报酬。**
- *成批的商业性复制。*开发者复制整部作品——往往未经许可——以构建价值来源于这些材料的商业产品；"学习"只是一个隐喻，而复制是实实在在的。
- *市场损害。*生成式模型产出的作品与其训练所用作品竞争——图库图片、新闻摘要、类型小说——即使不复现任何单一作品，也能稀释市场。训练数据的许可市场实际已经存在（自2023年以来，开发者已与新闻出版商、图片库与在线平台签订许可协议），依美国法律，这不利于合理使用。
- *对创作者的公平。*创作者承担了成本却分不到价值；退出机制把负担压到数以百万计的个人身上，其中许多人实际上无力行使，而对已被使用的作品来说更为时已晚。

还有一些中间立场：集体许可或法定付酬制度（如音乐广播）、退出机制加透明度、允许训练但要求署名并加输出过滤。某一法域采取何种立场，是在创新、创作者生计、知识获取与竞争之间取舍的政策选择；若干经验前提——生成内容在多大程度上替代人类劳动、许可要花多少钱——的证据仍然有限。

::: warning "公开可及"不等于"可以自由复制"
任何人可读的网页仍受版权保护，而在欧盟，在线公开的内容可受第4条下的机器可读保留约束。反过来，"受版权保护"也不等于"不能使用"：合理使用、TDM、第30-4条等例外允许某些无需许可的使用。某一使用是否合法，取决于法域、行为（收集、训练、输出）与具体事实。
:::

## 数据来源与退出机制 {#sec-provenance}

其中许多问题取决于难以查明的事实：一个模型用了什么数据训练、依据什么许可、权利人是否已选择退出。**数据来源**（provenance）——对数据来源与历史的记录——是技术层面的回应。

**文档化。**《数据集数据表》（*Datasheets for Datasets*，Gebru 等，2021）与数据声明（Bender 与 Friedman，2018）记录数据集的来源、收集过程、许可与已知缺口。数据来源计划（Data Provenance Initiative；Longpre 等，2023）审计了$1{,}800$多个微调数据集，发现热门托管平台上的许可信息经常缺失或有错——绝大多数数据集干脆没有许可信息，而在确有许可信息的数据集中又有很大比例被标错类别——以致使用者往往无从知道自己使用的数据附于何种条款。

**退出信号。**最老的是 `robots.txt`：站点在其中点名（按 user-agent）不得抓取其页面的爬虫；它是惯例而非执行机制。开发者已为 AI 训练爬虫发布专用的 user-agent，以便站点把它们与搜索爬虫分开排除。其他提案包括 W3C 社区组的 TDM 保留协议（TDM Reservation Protocol）以及文件中的元数据。Longpre 等（2024）测得，在训练语料中使用最多的网站域名中，2023–24 年针对 AI 爬虫的限制快速增长，且站点的 robots.txt 与其服务条款常常不一致。

::: example 退出机制移除多少数据 {#ex-optout}
某训练语料$40\%$的词元来自$1{,}000$个高质量域名，$60\%$来自数百万个其他域名。一年中，$25\%$的高质量域名（按词元计）和$5\%$的其余域名加上了针对 AI 爬虫的限制，且开发者予以遵守。语料损失了多大比例？高质量部分又损失了多少？
::: solution
损失：$0.4\cdot0.25 + 0.6\cdot0.05 = 0.10 + 0.03 = 0.13$，即$13\%$的词元，以及高质量部分的四分之一。由于限制集中出现在大型、维护良好的出版商那里，退出机制移除的是价值最高的数据中不成比例的一大块——正是 Longpre 等报告的现象——这使谈判力量向这些出版商集中，也让许可变得更划算。
:::
:::

## 为生成内容加标记 {#sec-marking}

数据来源的另一半关乎输出：我们能否判断一段文本或一幅图像是否由模型生成？方法有两族。**事后检测**在生成方完全不配合的情况下把内容分类为人类或机器所作；其局限见[[llm-society/misinformation]]。**加标记**则由生成方在创作时嵌入信号：或者是内容中统计意义上的**水印**，或者是附于其上的签名**元数据**。

### 绿名单水印 {#sec-watermark}

Kirchenbauer 等（2023）提出了一种语言模型水印：轻微改变采样分布，而改变的方式只有持钥者能够检测。

::: algorithm 绿名单加水印（Kirchenbauer 等，2023） {#alg-watermark}
参数：绿名单比例$\gamma\in(0,1)$、提升量$\delta > 0$、一个秘密密钥、一个哈希函数。

生成，每一步$t$：
1. 用上一步词元$x_{t-1}$与密钥做哈希，作为伪随机数生成器的种子。
2. 用它把词表$\mathcal V$划分为规模为$\gamma\lvert\mathcal V\rvert$的**绿名单**$G_t$与红名单。
3. 给每个绿词元的 logit 加上$\delta$，再从修改后 logit 的 softmax 中采样$x_t$。

检测，给定$T$个词元：用密钥与$x_{t-1}$重算每个$G_t$，数出绿词元个数$\lvert s\rvert_G = \sum_t\mathbf 1[x_t\in G_t]$，并计算

$$
z = \frac{\lvert s\rvert_G - \gamma T}{\sqrt{T\gamma(1 - \gamma)}}.
$$ {#eq-wm-z}

若$z$超过阈值（例如$4$），即判定文本带水印。
:::

检测需要密钥但不需要模型，每个词元只花一次哈希。这一统计量的正当性由下面的结果说明。

::: proposition 绿词元计数的原假设分布 {#prop-wm-null}
设一段$T$个词元的文本是在不知密钥的情况下产生的，且绿名单使每个词元$x_t$落入$G_t$的概率为$\gamma$，对不同的$t$相互独立。则$\lvert s\rvert_G\sim\Bin(T, \gamma)$，均值为$\gamma T$、方差为$T\gamma(1 - \gamma)$，[[#eq-wm-z]]中的$z$均值为$0$、方差为$1$，当$T$大时近似服从标准正态。于是检验$z > \tau$的假阳性率约为$1 - \Phi(\tau)$；$\tau = 4$时约为$3.2\times10^{-5}$。
:::

::: proof
在假设之下，各示性函数$\mathbf 1[x_t\in G_t]$是相互独立的伯努利($\gamma$)变量，故其和服从二项分布，均值为$T\gamma$、方差为$T\gamma(1-\gamma)$（[[math-for-ml/probability#prop-linearity]]）。减去均值、除以标准差即得$\E z = 0$、$\Var z = 1$；由中心极限定理，$z$近似服从$\Normal(0, 1)$。因此$\Prob(z > \tau)\approx1 - \Phi(\tau)$，而$1 - \Phi(4) = 3.17\times10^{-5}$。
:::

这一假设之所以合理，是因为人类作者（或另一个模型）不知道密钥，其选用的词元是否属绿，就像一枚带偏概率$\gamma$的硬币。对重复的文本它会失效：同一对$(x_{t-1}, x_t)$总是给出同样的答案，因此反复复读同一短语的文本，其示性变量彼此相关；实现中因此对每个互不相同的词元对只计一次分。

水印能产生多少绿词元？这取决于模型每一步的熵。

::: proposition 加水印后的绿词元概率 {#prop-wm-boost}
设某一步上模型分布在绿名单上的总概率为$g$。给绿 logit 加上$\delta$之后，采到绿词元的概率为

$$
g' = \frac{g\,e^{\delta}}{g\,e^{\delta} + 1 - g}.
$$ {#eq-wm-boost}

特别地，若模型在许多词元上接近均匀，则$g\approx\gamma$、$g'\approx\gamma e^\delta/(\gamma e^\delta + 1 - \gamma)$；若模型把几乎全部概率压在一个词元上，则$g$接近$0$或$1$，而$g'\approx g$。
:::

::: proof
词元$i$的 softmax 概率为$e^{\ell_i}/\sum_j e^{\ell_j}$。给绿 logit 加$\delta$，等于把每个绿词元的分子乘以$e^\delta$。分子分母同除以$\sum_je^{\ell_j}$，绿概率的总和即变为$e^\delta g/(e^\delta g + (1 - g))$。特殊情形代入$g = \gamma$或$g\in\{0, 1\}$即得。
:::

第二种情形是水印的根本极限：低熵文本——一段引文、只有一种正确续写的代码、一份事实清单——不加改变内容就无法加水印，因为根本没有可供偏置的选择。

::: example 检测水印 {#ex-wm}
取$\gamma = 0.25$、$\delta = 2$。(a) 在高熵文本中，多大比例的词元是绿的？(b) $T = 200$个词元时，$z$的期望是多少？(c) 一段$100$个词元的文本有$41$个绿词元；在$\tau = 4$下会被标记吗？
::: solution
(a) 由[[#eq-wm-boost]]，$g' = 0.25e^2/(0.25e^2 + 0.75) = 1.847/2.597 = 0.711$。
(b) 绿词元数的期望为$0.711\cdot200 = 142.2$；$z = (142.2 - 50)/\sqrt{200\cdot0.25\cdot0.75} = 92.2/6.124 = 15.1$，远超$4$。
(c) $z = (41 - 25)/\sqrt{100\cdot0.1875} = 16/4.330 = 3.70 < 4$：不会被标记，尽管绿比例（$0.41$）远高于$0.25$。单侧 $p$ 值约为$1.1\times10^{-4}$；把阈值调低一些可以将其标记，代价是人类文本上的假阳性增多。
:::
:::

::: example 大型平台如何选阈值 {#ex-wm-threshold}
某平台每天要扫描$10^6$份人类撰写的文档，希望平均每天误报少于一次。(a) 这需要多大的阈值$\tau$？(b) 取$\gamma = 0.25$、$\delta = 2$，对高熵的加水印文本，需要多少词元才能使$z$的*期望*达到$\tau$？
::: solution
(a) 需要$10^6(1 - \Phi(\tau)) < 1$，即$1 - \Phi(\tau) < 10^{-6}$，故$\tau = \Phi^{-1}(1 - 10^{-6}) = 4.75$。
(b) $z$的期望为$(0.711 - 0.25)\sqrt T/\sqrt{0.1875} = 1.065\sqrt T$。令$1.065\sqrt T = 4.75$，得$T = 19.9$，即约$20$个词元。达到期望值并不足以可靠检测——约一半这样的文本会落在其下——因此实际需要的文本要更长一些；而且阈值必须把跑过的每一次检验都算进去，而不只是一次。
:::
:::

::: example 低熵文本 {#ex-wm-entropy}
某份加水印的程序清单中，一半词元是"迫定"的（模型把接近$1$的概率放在一个词元上，该词元以概率$\gamma$为绿），另一半为高熵。取$\gamma = 0.25$、$\delta = 2$，绿比例的期望是多少？$z$的期望要达到$4$，需要多少词元？
::: solution
在迫定步上，提升不改变任何东西（[[#prop-wm-boost]]取$g\in\{0,1\}$），故这些词元以概率$0.25$为绿。高熵步上绿概率为$0.711$。平均为$0.5\cdot0.25 + 0.5\cdot0.711 = 0.481$。$z$的期望为$(0.481 - 0.25)\sqrt T/0.433 = 0.532\sqrt T$，在$T = 56.4$处达到$4$，即约$57$个词元——约为同样阈值下全高熵文本所需$14$个（$(4/1.065)^2 = 14.1$）的四倍。代码、程式化文本与简短的事实性回答都很难加水印。
:::
:::

::: widget plot
f: (g - 0.25)*sqrt(x)/sqrt(0.1875); 4
x: 0, 300
y: -1, 20
sliders: g=0.71:0.25:0.9:0.01
labels: expected z-score; detection threshold
caption: [[#eq-wm-z]] 的 $z$ 统计量期望值随文本长度 $T$ 的变化，取 $\gamma = 0.25$、观察到的绿比例为 $g$（滑块）。期望值按 $\sqrt T$ 增长，因此检测需要一个最短长度：$g = 0.71$（即 $\delta = 2$ 时的高熵取值）时约需 $10$ 个词元，$g = 0.5$ 时约需 $48$ 个，$g = 0.3$ 时需要数百个——经过大幅改写的水印文本，或模型熵很低时，大体就是这种情形。
:::

下面的清单在一个 logit 随机的玩具"模型"上实现了上述方案，并测试了若干不同长度的文本。

```python
import hashlib, math, random

V, GAMMA, DELTA = 1000, 0.25, 2.0            # 词表规模、绿名单比例、logit 提升量

def green_list(prev_token, key=42):
    """Pseudorandom green list seeded by a secret key and the previous token."""
    seed = int(hashlib.sha256(f"{key}:{prev_token}".encode()).hexdigest(), 16)
    ids = list(range(V))
    random.Random(seed).shuffle(ids)
    return set(ids[: int(GAMMA * V)])

def toy_logits(rng):
    """Stand-in for a language model: random logits, so each step has high entropy."""
    return [rng.gauss(0, 2) for _ in range(V)]

def sample(logits, rng):
    m = max(logits)
    w = [math.exp(l - m) for l in logits]
    return rng.choices(range(V), weights=w)[0]

def generate(T, rng, watermark):
    toks = [0]
    for _ in range(T):
        logits = toy_logits(rng)
        if watermark:
            g = green_list(toks[-1])
            logits = [l + DELTA if i in g else l for i, l in enumerate(logits)]
        toks.append(sample(logits, rng))
    return toks

def z_score(toks):
    T = len(toks) - 1
    green = sum(toks[i] in green_list(toks[i - 1]) for i in range(1, len(toks)))
    return green, T, (green - GAMMA * T) / math.sqrt(T * GAMMA * (1 - GAMMA))

rng = random.Random(2023)
for wm in (False, True):
    for T in (25, 50, 200):
        g, T, z = z_score(generate(T, rng, wm))
        print(f"watermark={wm!s:5}  T={T:3d}  green={g:3d}  fraction={g/T:.3f}  z={z:6.2f}")
```

```text
watermark=False  T= 25  green=  7  fraction=0.280  z=  0.35
watermark=False  T= 50  green=  8  fraction=0.160  z= -1.47
watermark=False  T=200  green= 56  fraction=0.280  z=  0.98
watermark=True   T= 25  green= 12  fraction=0.480  z=  2.66
watermark=True   T= 50  green= 40  fraction=0.800  z=  8.98
watermark=True   T=200  green=132  fraction=0.660  z= 13.39
```

未加水印的文本给出接近$0$的$z$，与[[#prop-wm-null]]的预言一致。加水印的文本只要足够长，$z$就很大；$25$个词元的文本绿比例虽有$0.48$，却仍达不到$4$。绿比例是$0.66$而不是[[#ex-wm]]中的$0.71$，因为这个玩具模型的随机 logit 使每一步的大部分概率集中在少数几个词元上，于是$g$常常偏离$\gamma$，凹函数[[#eq-wm-boost]]取平均后变小。

**鲁棒性与局限。**攻击者只要改写文本——人工改，或用一个不知密钥的模型改——就会把绿词元换成只有概率$\gamma$为绿的词元，从而稀释信号。Kirchenbauer 等（2024）发现，只要文本足够多，经人工或模型改写后水印通常仍可检测；而 Krishna 等（2023）表明，一个专门训练的改写模型可以大幅降低若干方案的检测率。Zhang 等（2023）论证，在温和假设之下，不存在对"能访问质量预言机与扰动方法的坚决攻击者"保持鲁棒的水印。水印还只对运营方启用了它的模型有效：开放权重模型可以不带水印运行（[[llm-society/open-closed-models]]）。后来的方案降低了质量代价——例如"无失真"水印，对任何单个样本都不改变输出分布（Kuditipudi 等，2023）；以及 Google DeepMind 的 SynthID-Text（Dathathri 等，2024，发表于 *Nature*），它已部署于商用聊天产品，并在海量真实回复上评测，用户评分的质量没有可测的下降。

### 内容凭证（C2PA） {#sec-c2pa}

水印藏在内容里；**内容凭证**（content credentials）则是附在内容上的签名声明。2021 年由 Adobe、Arm、BBC、Intel、Microsoft 与 Truepic 发起成立的"内容来源与真实性联盟"（Coalition for Content Provenance and Authenticity，C2PA）为此制定了开放标准。

::: definition C2PA 清单 {#def-c2pa}
**C2PA 清单**（manifest）是与媒体文件绑定的数据结构，其中包含关于该素材的**断言**（例如：由某型号相机拍摄、用某工具编辑、由某 AI 模型生成、派生自这些成分文件）、把断言与确切内容绑定的密码学**哈希**、以及作出声明一方的**数字签名**（可用证书验证）。每次编辑都可追加一个引用前一个清单的新清单，形成一条来源链。
:::

凭证所能证明的，只是某个特定签名者对特定字节作出了特定声明、且这些字节自签名以来未变——而不是声明为真、内容属实。它的弱点是实践性的：文件转码或上传平台时元数据常遭剥离，因此缺少凭证什么也证明不了；覆盖范围取决于相机厂商、编辑工具、生成器与平台的采用程度；而语言模型的主要输出——纯文本——没有能在复制粘贴中存活的标准容器。因此水印与凭证互补：凭证在存活下来时提供丰富而可验证的历史，水印则提供在若干变换下仍能存活的更弱的信号。

监管正日益要求加标记。欧盟《人工智能法》第50条要求，自2026年8月2日起，生成合成音频、图像、视频或文本的系统提供者，须"在技术可行的限度内"确保输出以机器可读格式标记、可被检测为人工生成，并要求部署者披露深度伪造。中国《人工智能生成合成内容标识办法》自2025年9月1日施行，要求生成内容同时带有显式标识与隐式（元数据）标识。

::: quiz
一家新闻网站收到一张照片，附有有效的 C2PA 凭证，由某相机厂商的密钥签名，声明该照片摄于某日、未经编辑。该凭证确立了什么？
- [ ] 照片中的场景确实如画面所示发生过。
- [x] 自设备签署这些声明以来文件内容未变，且这些声明系该密钥的持有者所作。
- [ ] 图像的生成过程任何环节都没有用到 AI。
- [ ] 没有这种凭证的照片就是伪造的。
::: solution
哈希与签名把断言绑定到字节、绑定到签名者。它们无法证明场景不是摆拍、设备密钥没有被冒用、声明内容属实；而真实内容缺少凭证的情况很常见，因为元数据常常被剥离。
:::
:::

::: history
版权的第一部成文法《安娜法令》（Statute of Anne，1710）已经在作者权利与公众获取之间求取平衡。美国的合理使用在《1976年版权法》中成文化；Google Books 诉讼（2005–2016）成为大规模数字化的主要先例。日本于2018年增设第30-4条，欧盟于2019年创设 TDM 例外，二者都在生成式模型崛起之前。围绕生成式 AI 的诉讼自2022年底起激增，2025年出现了美国首批针对训练的判决。数据来源方面，Gebru 等于2018年传阅《数据集数据表》（*Datasheets for Datasets*，2021年正式发表），数据来源计划自2023年起审计数据集。文本水印早于大语言模型（如 Atallah 等2001年关于自然语言水印的工作）；Aaronson 于2022年描述了针对 GPT 输出的密码学水印，Kirchenbauer 等于2023年发表了绿名单方案。C2PA 成立于2021年，整合了 Adobe（内容真实性计划，Content Authenticity Initiative）与 Microsoft、BBC（Project Origin）此前的倡议。
:::

::: summary
- 复制发生在收集、准备、训练、输出与检索五个环节；各环节是否合法是相互独立的问题。
- 美国的合理使用权衡目的（转换性）、作品性质、使用数量与市场影响；2025年的一审判决因事实而异、两种结果都有（非生成式竞争者、盗版副本、市场损害证据），截至 2026 年仍有许多案件在审。
- 欧盟方面，DSM 指令第4条允许 TDM，除非权利人以机器可读方式保留；《人工智能法》要求通用模型提供者自2025年8月起建立尊重此类保留的版权政策、公布训练内容摘要。
- 日本第30-4条允许"非享受"目的的使用，包括数据分析，但以不合理损害权利人为限。
- 政策争论是"非表达性使用、先例与可行性"对"成批复制、市场损害与创作者公平"；也有中间方案。
- 数据来源需要文档化、准确的许可与得到遵守的退出机制；退出集中在高价值来源。
- 绿名单水印把采样偏向持钥的绿词元；检测是二项分布的 $z$ 检验，$z = (\lvert s\rvert_G - \gamma T)/\sqrt{T\gamma(1-\gamma)}$，需要足够多的词元与足够的熵，会被改写削弱。
- C2PA 凭证为关于内容的声明签名；它证明声明的完整性与出处，而非真伪，且常被剥离。
:::

## 习题

::: exercise 计算 z 统计量 {level=1 check="4.4"}
一段$300$个词元的文本在$\gamma = 0.25$下检验，其中有$108$个绿词元。计算$z$，保留一位小数。在$\tau = 4$下会被标记吗？
::: solution
$\gamma T = 75$，$\sqrt{300\cdot0.1875} = \sqrt{56.25} = 7.5$，$z = (108 - 75)/7.5 = 4.4 > 4$：会被标记。
:::

::: exercise 提升后的绿比例 {level=1 check="0.6"}
取$\gamma = 0.5$、$\delta = \ln 1.5$，高熵文本中绿词元的比例是多少？
::: solution
$g' = 0.5\cdot1.5/(0.5\cdot1.5 + 0.5) = 0.75/1.25 = 0.6$。
:::
:::

::: exercise 大规模下的假阳性 {level=1 check="32"}
某平台以$z > 4$为阈值检验一百万份人类撰写的文本。用正态近似，大约有多少会被误报为带水印？取最接近的整数。
::: solution
$10^6\cdot3.17\times10^{-5}\approx32$。在这一规模下，再小的假阳性率也会造成几十起误报——若标记会给作者带来后果，这就不是小事（对照[[llm-society/misinformation]]）。
:::

::: exercise 最短长度 {level=2 check="48"}
取$\gamma = 0.25$，一段经过改写的水印文本绿比例为$0.5$。$z$的期望达到$4$，最小的$T$是多少？
::: solution
$z$ 的期望 $= (0.5 - 0.25)\sqrt T/\sqrt{0.1875} = 0.5774\sqrt T$。令其等于$4$：$\sqrt T = 6.928$，$T = 48$。
:::
:::

::: exercise 合理使用的考量因素 {level=2}
判断以下每种使用最主要影响哪一项合理使用因素、朝哪个方向，并各用一句话说明理由：(a) 只在公有领域与已获许可文本上训练的模型；(b) 用某位在世小说家的图书微调、生成"仿其笔调"的新小说出售的模型；(c) 向用户展示从付费网站检索到的完整新闻报道的系统；(d) 用科学论文摘要训练内部分类器、把论文分派给审稿人。
::: solution
(a) 公有领域与已获许可的部分不涉及合理使用问题：本无侵权需要豁免。(b) 第4项（市场影响）不利于合理使用，因为输出与作者本人的书直接竞争；目的与原作接近，第1项也较弱。(c) 第4项与第3项：展示整篇文章替代了订阅，强烈指向不利。(d) 第1项有利于合理使用（非表达性、转换性目的，不输出作品本身），第2项略有利于它（事实性作品），在未能证明此类用途存在许可市场时第4项大体中性。这些只是推理的示例，不是对任何法院判决的预测。

::: exercise 三种制度的比较 {level=2}
在美国、欧盟与日本各有一家公司，用网页训练商业模型，其中一些网页带有针对 AI 训练的机器可读保留。按本章所述，解释这种保留在每种制度下的意义。
::: solution
欧盟：若权利人已以适当（机器可读）的方式保留 TDM，DSM 指令第4条即不适用，复制这些页面便需要别的依据（许可）；《人工智能法》还要求有识别并遵守此类保留的政策。日本：第30-4条没有退出机制，保留不起决定作用，但反复制的技术措施与"不合理损害"但书可能使之有关。美国：无成文法上的退出机制；保留可能间接影响合理使用——例如作为许可市场存在（第4项）或使用性质的证据——若违反条款或技术措施，还牵涉合同或反规避方面的主张。

::: exercise 含重复词元对的检测 {level=2}
一段文本由同一个$10$词元的句子重复$20$遍组成。解释为什么对每个词元逐一计分会使[[#prop-wm-null]]失效，检测器应当怎么做。
::: solution
是否属绿名单只取决于词元对$(x_{t-1}, x_t)$与密钥。重复使同样的$10$（约）个词元对重现$20$次，于是$200$个示性变量是约$10$个相互独立变量的$20$份拷贝。若碰巧$10$对中有$6$对为绿，计数为$200$中$120$，$z = (120 - 50)/6.12 = 11.4$，造成假阳性。每个互不相同的词元对只计一次分，则$T = 10$、$z = (6 - 2.5)/1.37 = 2.56$，正确地不显著。
:::

::: exercise 提升的质量代价 {level=3}
设某一步模型分布为$p$、加水印后的分布为$p'$，KL散度$\mathrm{KL}(p'\,\|\,p)$度量失真。证明：若绿名单上的总概率为$g$，则$\mathrm{KL}(p'\|p) = g'\delta - \ln(g e^\delta + 1 - g)$，并对$g = 0.25$、$\delta = 2$计算其值。讨论它对文本质量的含义。
::: solution
对绿词元$i$，$p'_i = p_ie^\delta/Z$；对红词元$i$，$p'_i = p_i/Z$，其中$Z = ge^\delta + 1 - g$。于是绿词元处$\ln(p'_i/p_i) = \delta - \ln Z$，红词元处为$-\ln Z$，故$\mathrm{KL}(p'\|p) = \sum_ip'_i\ln(p'_i/p_i) = g'(\delta - \ln Z) + (1 - g')(-\ln Z) = g'\delta - \ln Z$。代入$g = 0.25$、$\delta = 2$：$Z = 2.597$、$g' = 0.711$、$\mathrm{KL} = 1.422 - 0.954 = 0.468$ 纳特/词元。在高熵步上这是对分布的显著改变，这正是原论文报告在预言机模型下困惑度上升的原因；较小的$\delta$以可检测性换质量，而无失真方案则以别的复杂性避免了这一逐样本代价。
:::

::: exercise 实现一个鲁棒的检测器 {level=3}
修改上面的清单：(a) 检测时每个互不相同的（前一词元，词元）对只计一次；(b) 模拟改写攻击：对一段$200$词元的加水印文本，每个词元以概率$r$独立替换为一个均匀随机词元。报告$r = 0, 0.3, 0.6$时的$z$统计量，并结合[[#prop-wm-boost]]解释趋势。
::: solution
```python
def z_unique(toks):
    pairs = {(toks[i - 1], toks[i]) for i in range(1, len(toks))}
    green = sum(t in green_list(p) for p, t in pairs)
    T = len(pairs)
    return (green - GAMMA * T) / math.sqrt(T * GAMMA * (1 - GAMMA))

base = generate(200, random.Random(7), True)
for r in (0.0, 0.3, 0.6):
    att = random.Random(11)
    toks = [base[0]] + [att.randrange(V) if att.random() < r else t for t in base[1:]]
    print(r, round(z_unique(toks), 2))
```

```text
0.0 15.51
0.3 6.53
0.6 0.65
```

被替换的词元以概率$\gamma$为绿；更糟的是，替换词元$t$还会改变词元$t+1$的绿名单，所以每次替换可能破坏两个示性变量。替换率为$r$时，绿比例大致按$\gamma + (g' - \gamma)(1 - r)^2$从$g'$回落到$\gamma$，$z$也大致同比回落（$r = 0.3$时预测$15.5\cdot0.49 = 7.6$，实测$6.5$；$r = 0.6$时预测$15.5\cdot0.16 = 2.5$，实测$0.65$，差距是短文本的抽样噪声）：$r = 0.6$时，在$\tau = 4$下已检测不到。文本更长时，可检测性按$\sqrt T$恢复。
