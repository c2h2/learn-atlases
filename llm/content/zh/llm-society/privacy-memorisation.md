语言模型经过训练，以尽可能准确地预测它的训练文本。对大多数文本而言，它学到的是能够泛化的模式——语法、事实、风格。但对某些序列来说，最好的预测就是这条序列本身，于是模型几乎逐字地把它存了下来：一段见过上万次的许可文本，一首著名的诗，偶尔还有只出现在某一个网页上的某个人的姓名、电子邮箱地址和电话号码。当这样一条序列能通过提示从模型中被重新找回时，模型就成了其训练数据得以泄露的一个通道。

本章考察这一通道以及针对它的防御。我们先为"模型记住一条序列"给出确切定义，总结已发表的提取研究发现着什么（Carlini 等，2021；2023；Nasr 等，2023）、哪些因素——重复、模型规模、上下文长度——驱动了记忆化（memorisation），并引入成员推断（membership inference）作为度量泄露的一种方式。然后转向**差分隐私**（differential privacy），这是唯一能给出数学保证的框架：我们给出定义，证明拉普拉斯机制满足它，把这一保证解读为对任何攻击者的限制，介绍用于神经网络训练的 DP-SGD（Abadi 等，2016），并计算隐私–效用权衡。最后以几个与记忆化无关的隐私问题收尾：个人属性的推断、用户对话的处理、数据保护法。

这里对攻击的描述只停留在其已发表的发现以及它们所揭示的因素这一层面；目的是理解风险及其缓解办法，而不是复现针对已部署系统的攻击。

## 记忆化 {#sec-memorisation}

一个泛化得很好的模型仍然要在宽泛的意义上"记住"一些东西——它存储了法国的首都。隐私问题关心的是那些为单个训练样例所特有的信息。下面几个定义把这一点说严格，每个各自适合回答一类问题。

::: definition 可提取与$k$-遗觉记忆化 {#def-extractable}
设$x = (p, s)$是训练数据中的一个字符串，分成前缀$p$与后缀$s$。若$p$含$k$个词元，且从$p$出发对模型做贪心解码恰好得到$s$，则称该字符串**可在$k$个词元上下文下提取**（Carlini 等，2023）。更一般地，若存在某个提示——攻击者在不预先知道该字符串的情况下就能找到它——能使模型输出这个字符串，则称它**可提取**（extractable）。若一个字符串可提取，且至多出现在$k$份训练文档中，则称它是 **$k$-遗觉记忆**（eidetic memorised）的（Carlini 等，2021）。
:::

基于前缀的定义容易测量——取训练序列、喂入前缀、比较输出即可——但它是记忆化程度的下界，因为别的提示或采样可能揭示更多内容。"遗觉"这个限定对隐私很重要：在成千上万份文档中都出现的字符串（比如一段许可文本）在任何有意义的意义上都是公开的；而只出现在一份文档中的字符串——单独一页上的一个地址——才是令人担忧的情形。

一个互补的概念问的是：模型在某个样例上的行为，在多大程度上依赖于这个样例出现在训练集中。

::: definition 反事实记忆化 {#def-counterfactual}
对训练样例$x$与训练算法$\mathcal{A}$，$x$的**反事实记忆化**（counterfactual memorisation）为

$$
\operatorname{mem}(x) = \E_{S\ni x}\bigl[\operatorname{perf}(\mathcal{A}(S), x)\bigr] - \E_{S\not\ni x}\bigl[\operatorname{perf}(\mathcal{A}(S), x)\bigr],
$$

即在所有包含$x$的随机子集$S$上训练出的模型在$x$上的期望表现（例如逐词元准确率），减去在不包含$x$的子集上训练出的模型的对应值（Zhang 等，2023，沿用 Feldman，2020 的思想）。
:::

对模型本来就能预测好的常见文本，反事实记忆化接近于零；而对罕见、独特的文本则很大——恰恰是最涉及隐私的那类文本。Feldman（2020）论证说，当数据带有由罕见子群构成的长尾时，一定的记忆化对好的准确率是*必要的*：要在只见过一次的某类样例上预测得好，学习器实际上就必须记住那个样例。学习长尾与保护个体之间的这种张力，在差分隐私的代价中再次出现（[[#sec-tradeoff]]）。

## 提取研究的发现 {#sec-extraction}

**GPT-2（Carlini 等，2021）。** 作者从 GPT-2 中生成大量样本，按表明模型异常自信的信号排序（例如模型的困惑度与该文本经 zlib 压缩后的长度之比，或与一个更小的模型给出的困惑度之比），并在 OpenAI 的帮助下把排名靠前的候选与训练数据逐一比对。在$1{,}800$个候选中，$604$个是逐字出现在训练集中的序列。内容包括新闻、许可证、代码和标识符列表，也有个人信息：个人的姓名、电话号码、电子邮箱地址和实体住址，其中一些在整个训练集中只出现过一份文档里。更大的模型在所测序列上记忆得更多。

**记忆化的缩放定律（Carlini 等，2023）。** 作者用基于前缀的提取方法，在公开数据训练出的模型（Pile 及在其上训练的 GPT-Neo、GPT-J 等）上测量可提取性，发现了三个大致呈对数线性的关系：可提取训练序列的比例随**模型规模**、随一条序列在训练数据中被**复制的次数**、以及随给定的**前缀长度**而上升。他们估计，60 亿参数的 GPT-J 至少约有$1\%$的训练数据可以用$50$个词元的前缀提取出来。这些都是下界；它们是对所研究模型的实验规律，而非定律。

**重复（Kandpal、Wallace 与 Raffel，2022；Lee 等，2022）。**一条序列被重新生成的速率随其重复次数超线性增长：Kandpal 等报告，出现十次的序列被生成的频率约为出现一次的序列的一千倍。Lee 等发现，对训练数据去重能使模型吐出记忆文本的速率降低约十倍，还让训练更高效。去重如今已是数据流水线中的标准步骤（[[pretraining/training-data]]）。

**生产环境的聊天模型（Nasr 等，2023）。** 作者从开放权重模型中大规模地提取训练数据，并表明一个已部署、已对齐的聊天模型也可能被诱导——通过一个使它偏离其对话行为的提示——以远高于平常的比率吐出记忆下来的预训练数据。他们估计，用价值约 US\$200 的查询就能恢复出逾上万个互不相同的记忆样例。该漏洞在论文发表前已披露给开发方并得到修复。这项研究给出的一般教训是：对齐改变的是模型通常输出什么，却不必抹去它已经记住的内容。

::: example 重复与预期被提取的记录数 {#ex-duplication}
把重复这一发现作一个理想化版本：设一条序列可提取的概率随其重复次数$c$按$q(c) = q_1 c^{\alpha}$增长、以$1$封顶，其中$q_1 = 10^{-4}$、$\alpha = 3$。某个语料库包含$10^6$条互不相同的个人记录：$90\%$出现$1$次，$9\%$出现$5$次，$1\%$出现$20$次。在把每条记录去重到只剩一份之前与之后，预期分别有多少条记录可被提取？
::: solution
之前：只出现一次的记录$9\times10^5\cdot10^{-4} = 90$条；重复$5$次的记录$9\times10^4\cdot10^{-4}\cdot125 = 1125$条；重复$20$次的记录$10^4\cdot\min(1, 10^{-4}\cdot8000) = 10^4\cdot0.8 = 8000$条。总计$9215$条。去重之后每条记录都表现得像只出现一次：$10^6\cdot10^{-4} = 100$。去重消去了约$99\%$的期望泄露，但那$100$条只出现一次的记录仍在——对只出现过一次的信息，去重无能为力。（数字为虚构，只为说明效应的形状；实测的指数与常数取决于模型和所用定义。）
:::
:::

::: warning "模型只见过一次，所以复现不出来"
只出现一次会降低提取的概率，但并不使其为零。Carlini 等（2021）发现了只出现在单份训练文档中的被记忆个人信息，而且罕见序列的记忆化随模型规模增长。反过来，模型输出一个看似合理的电话号码，也不意味着这个号码就在它的训练数据里——模型也会编造出以假乱真的字符串。无论哪个方向的说法，都需要对照数据来检验。
:::

### 成员推断 {#sec-mia}

提取恢复的是内容本身；一个更弱的攻击只问：给定的一条记录是否在训练集中。

::: definition 成员推断 {#def-mia}
**成员推断攻击**（Shokri 等，2017）是一个检验：给定模型$f$与一条候选记录$x$，它输出"成员"或"非成员"。其优劣像分类器那样度量：真阳性率（被正确识别的成员）与假阳性率（被错称为成员的非成员），尤其是**低假阳性率（如$0.1\%$）下的真阳性率**（Carlini 等，2022）——因为一个平均而言不算错、却对任何人都给不出有把握判断的攻击几乎没有用处。
:::

最简单的攻击对模型在$x$上的损失取阈值：训练样例的损失往往更低（Yeom 等，2018）。更强的攻击把这个损失与不含$x$训练出的参照模型的损失做比较（Carlini 等 2022 提出的似然比攻击），或者只看文本中最不可能的词元（Min-K% 概率；Shi 等，2024）。对大型预训练语言模型，Duan 等（2024）发现许多攻击在预训练数据上只比随机猜测略好，而此前更乐观的结果部分源于"成员"与"非成员"测试集之间的分布差异（例如日期）。成员推断对微调模型更有效，因为微调是在小数据集上反复训练多个轮次。它在实践中的主要用途是一种*度量*：审查一个训练流程泄露多少，而这正是差分隐私能直接限制的（[[#prop-test]]）。

## 差分隐私 {#sec-dp}

启发式的防御——删掉姓名与邮箱、去重、过滤输出——能减少泄露，却不附带任何保证：一个写法特殊的人名就能躲过清除器。差分隐私（Dwork、McSherry、Nissim 与 Smith，2006）采取另一条路。它不去识别敏感数据，而是要求一个算法的输出几乎不依赖任何单一个体的数据——无论那些数据是什么。

::: definition 差分隐私 {#def-dp}
若两个数据集$D, D'$在单一个体的数据上不同（多一条或少一条记录；必须指明隐私的"单位"——一个样例、一条序列还是一个用户），则称二者**相邻**。若对一切相邻的$D, D'$和可能输出的每个集合$S$，随机化算法$M$都满足

$$
\Prob[M(D)\in S] \le e^{\varepsilon}\,\Prob[M(D')\in S] + \delta.
$$ {#eq-dp}

则称$M$是**$(\varepsilon, \delta)$-差分隐私**的。当$\delta = 0$时称其**$\varepsilon$-差分隐私**（纯差分隐私）。
:::

参数$\varepsilon$限制了单个个体能使输出分布改变多少：$\varepsilon = 0.1$时，任何结果的概率至多改变$e^{0.1}\approx1.105$倍。参数$\delta$允许以一个很小的概率出现更大的改变，对$n$个个体的数据集应当远小于$1/n$。这一保证对每个个体、每种可能的攻击者都成立，无论攻击者还知道些什么。

::: definition 敏感性 {#def-sensitivity}
设$f$是从数据集到$\R^d$的函数，其**$\ell_1$-敏感性**为$\Delta f = \max_{D, D'\text{ 相邻}}\norm{f(D) - f(D')}_1$。满足某性质的记录数的敏感性为$1$；$[0, 1]$中$n$个值的均值（$n$固定、替换其中一个值）的敏感性为$1/n$。
:::

::: theorem 拉普拉斯机制 {#thm-laplace}
设$f$的$\ell_1$-敏感性为$\Delta f$。机制$M(D) = f(D) + (Z_1, \dots, Z_d)$，其中各$Z_i$相互独立、服从密度为$\frac{1}{2b}e^{-\lvert z\rvert/b}$、尺度$b = \Delta f/\varepsilon$的拉普拉斯分布，则它是$\varepsilon$-差分隐私的。
:::

::: proof
设$D, D'$相邻，记$\mu = f(D)$，$\mu' = f(D')$。$M(D)$在点$\mathbf{y}\in\R^d$处的密度为$p_D(\mathbf y) = \prod_i \frac{1}{2b}\exp(-\lvert y_i - \mu_i\rvert/b)$。密度之比为

$$
\frac{p_D(\mathbf y)}{p_{D'}(\mathbf y)} = \prod_{i=1}^d \exp\Bigl(\frac{\lvert y_i - \mu'_i\rvert - \lvert y_i - \mu_i\rvert}{b}\Bigr) \le \prod_{i=1}^d\exp\Bigl(\frac{\lvert \mu_i - \mu'_i\rvert}{b}\Bigr) = \exp\Bigl(\frac{\norm{\mu - \mu'}_1}{b}\Bigr) \le \exp\Bigl(\frac{\Delta f}{b}\Bigr) = e^{\varepsilon},
$$

其中用到三角不等式$\lvert y_i - \mu'_i\rvert \le \lvert y_i - \mu_i\rvert + \lvert\mu_i - \mu'_i\rvert$，随后又用到敏感性的定义。对任意集合$S$把$p_D \le e^\varepsilon p_{D'}$积分，即得$\Prob[M(D)\in S] \le e^\varepsilon\Prob[M(D')\in S]$。
:::

::: widget plot

:::

三条性质使差分隐私可以作为工程工具使用。我们在此陈述它们；证明可参见 Dwork 与 Roth（2014，第 2–3 章）。

::: proposition 后处理、组合与群体 {#prop-composition}
(a) **后处理。**若$M$是$(\varepsilon, \delta)$-差分隐私的，$g$是任意（不再使用数据的）函数，则$g\circ M$也是$(\varepsilon, \delta)$-差分隐私的。
(b) **基本组合。**若$M_1, \dots, M_k$分别是$(\varepsilon_i, \delta_i)$-差分隐私的，则一并发布它们全部输出的机制是$(\sum_i\varepsilon_i, \sum_i\delta_i)$-差分隐私的。
(c) **群体隐私（group privacy）。**一个$\varepsilon$-差分隐私机制，对相差$k$个个体的数据的数据集是$k\varepsilon$-差分隐私的。
:::

::: proof
(b) 就纯差分隐私与两个输出离散的机制证明（一般情形完全类似）：$\Prob[(M_1(D), M_2(D)) = (a, b)] = \Prob[M_1(D) = a]\Prob[M_2(D) = b] \le e^{\varepsilon_1}\Prob[M_1(D') = a]\,e^{\varepsilon_2}\Prob[M_2(D') = b]$，这里用到两个机制的随机性相互独立；对$(a, b)\in S$求和即得所需界。(c)：从$D$到$D''$沿$k$步相邻关系$D = D_0, D_1, \dots, D_k = D''$逐步过渡，把$k$个因子$e^{\varepsilon}$相乘。(a)：对任意集合$S$，$\Prob[g(M(D))\in S] = \Prob[M(D)\in g^{-1}(S)]$，而[[#eq-dp]]可作用于集合$g^{-1}(S)$。
:::

后处理意味着：用 DP 训练出的模型可以被使用、在公开数据上微调、或任意多次采样，都不再产生额外的隐私代价。组合意味着每次查询或每步训练都要从**隐私预算**（privacy budget）中支出。比基本组合更紧的记账——高级组合定理、Rényi 差分隐私（Mironov，2017）、以及 Abadi 等（2016）的矩记账（moments accountant）——表明在$\delta$很小时，$k$个机制的代价约为$\sqrt{k}$倍而非$k$倍，这正是数千步训练变得可行的原因。

### $\varepsilon$对攻击者意味着什么 {#sec-meaning-eps}

::: proposition 差分隐私限制一切成员检验 {#prop-test}
若$M$是$(\varepsilon, \delta)$-差分隐私的，则任何根据$M$的输出来判断某个体的记录是否在数据中的检验——任何成员推断攻击——其真阳性率与假阳性率都满足

$$
\text{TPR} \le e^{\varepsilon}\,\text{FPR} + \delta.
$$
:::

::: proof
设$D$包含该记录，$D'$为不含它的相邻数据集，$S$为使检验回答"成员"的那些输出构成的集合。则$\text{TPR} = \Prob[M(D)\in S]$、$\text{FPR} = \Prob[M(D')\in S]$，由[[#eq-dp]]即得断言。
:::

在$\varepsilon = 1$、$\delta = 0$时，一个误判$1\%$非成员的攻击者至多能正确识别$2.7\%$的成员；在$\varepsilon = 8$——DP 训练中常报告的值——该界为假阳性率的$e^8\approx2981$倍，只在假阳性率极低时才构成约束。这就是为什么$\varepsilon$超过$10$左右通常被认为只能给出较弱的最坏情形保证，尽管针对这类模型的实际攻击通常远达不到这个界（Nasr 等，2021 测量了真实攻击与界的差距）。

::: example 加噪计数与攻击者 {#ex-count}
一家医院用$\varepsilon = 0.5$的拉普拉斯机制公布某罕见病患者的人数。(a) 噪声的尺度是多少？其绝对值的期望是多少？(b) 公布的数值偏差超过$5$的概率是多少？(c) 一个攻击者除了"Alice 是否在数据中"之外无所不知；当公布的计数比不含她时的计数多出$0.5$以上时，她就判定她是成员。求真阳性率与假阳性率。
::: solution
(a) 敏感性为$1$，故$b = 1/0.5 = 2$。拉普拉斯噪声有$\E\lvert Z\rvert = b = 2$。
(b) $\Prob(\lvert Z\rvert > t) = e^{-t/b} = e^{-2.5} = 0.082$。
(c) 不含 Alice 时输出为$c + Z$，故$\text{FPR} = \Prob(Z > 0.5) = \tfrac12 e^{-0.5/2} = 0.389$。含 Alice 时为$c + 1 + Z$，故$\text{TPR} = \Prob(Z > -0.5) = 1 - \tfrac12e^{-0.25} = 0.611$。二者之比为$1.57 \le e^{0.5} = 1.65$，与[[#prop-test]]的要求一致。这个攻击者的表现只比抛硬币略好。
:::
:::

### 代码清单

下面的清单用标准库实现拉普拉斯机制，在若干隐私水平下测量其误差，并在$\varepsilon = 1$下、取几个不同的判定阈值运行[[#ex-count]]中的攻击者。

```python
import math, random
rng = random.Random(2006)

def laplace(scale):
    """One draw from Laplace(0, scale) by inverting the CDF."""
    u = rng.random() - 0.5                      # [-0.5, 0.5) 上的均匀分布
    return -scale * math.copysign(1.0, u) * math.log(1 - 2 * abs(u))

def laplace_count(true_count, eps, sensitivity=1.0):
    return true_count + laplace(sensitivity / eps)

# 1. 效用：若干隐私水平下加噪计数的误差
for eps in (0.1, 0.5, 1.0, 2.0):
    errs = [abs(laplace_count(1000, eps) - 1000) for _ in range(100000)]
    print(f"eps={eps:<4} mean |error| {sum(errs)/len(errs):6.2f}  (theory {1/eps:5.2f})"
          f"  P(|error|>5) {sum(e > 5 for e in errs)/len(errs):.3f}  (theory {math.exp(-5*eps):.3f})")

# 2. 隐私：攻击者只看到一次发布，要判断 Alice（她会使计数加 1）是否在数据中。
#    最优检验：输出超过某个阈值就猜"在"。
eps = 1.0
D, D2 = 1000, 999                                # 含 Alice 与不含 Alice
for cut in (999.5, 1001.0, 1003.0):
    tpr = sum(laplace_count(D, eps) > cut for _ in range(100000)) / 100000
    fpr = sum(laplace_count(D2, eps) > cut for _ in range(100000)) / 100000
    print(f"cut {cut}: TPR {tpr:.3f}  FPR {fpr:.3f}  TPR/FPR {tpr/fpr:.2f}  (bound e^eps = {math.e**eps:.2f})")
```

```text
eps=0.1  mean |error|  10.07  (theory 10.00)  P(|error|>5) 0.607  (theory 0.607)
eps=0.5  mean |error|   2.00  (theory  2.00)  P(|error|>5) 0.082  (theory 0.082)
eps=1.0  mean |error|   1.00  (theory  1.00)  P(|error|>5) 0.007  (theory 0.007)
eps=2.0  mean |error|   0.50  (theory  0.50)  P(|error|>5) 0.000  (theory 0.000)
cut 999.5: TPR 0.695  FPR 0.304  TPR/FPR 2.29  (bound e^eps = 2.72)
cut 1001.0: TPR 0.184  FPR 0.068  TPR/FPR 2.72  (bound e^eps = 2.72)
cut 1003.0: TPR 0.025  FPR 0.009  TPR/FPR 2.72  (bound e^eps = 2.72)
```

误差按$1/\varepsilon$下降，与理论一致。一旦判定阈值高于两个均值——此时两条拉普拉斯密度之比恰为$e^\varepsilon$——攻击者的 TPR/FPR 之比就达到界$e^{\varepsilon}$：拉普拉斯机制的保证是紧的——但得到该比值的代价是真阳性率极小：Alice 在场时，攻击者也只有$2.5\%$的情形能认出她。

## 用差分隐私训练 {#sec-dpsgd}

为了以隐私保护的方式训练神经网络，Abadi 等（2016）把随机梯度下降（[[neural-networks/optimisers]]）的每一步做成一个私有机制：先裁剪每个样例的梯度以限制单个样例的影响，再用高斯噪声掩盖任何单个样例的贡献。

::: algorithm DP-SGD（Abadi 等，2016） {#alg-dpsgd}
输入：数据$\{x_1, \dots, x_N\}$、损失$\mathcal{L}(\theta; x)$、采样率$q$、学习率$\eta$、裁剪范数$C$、噪声乘子$\sigma$、步数$T$。

对$t = 1, \dots, T$：
1. 采样一个批次$B_t$：每个样例以概率$q$独立入选（期望规模$L = qN$）。
2. 对每个$x_i\in B_t$计算逐样例梯度$\mathbf g_i = \nabla_\theta\mathcal{L}(\theta; x_i)$。
3. 裁剪：$\bar{\mathbf g}_i = \mathbf g_i / \max\bigl(1, \norm{\mathbf g_i}_2/C\bigr)$，从而$\norm{\bar{\mathbf g}_i}_2\le C$。
4. 加噪：$\tilde{\mathbf g} = \frac{1}{L}\bigl(\sum_{i\in B_t}\bar{\mathbf g}_i + \Normal(\mathbf 0, \sigma^2C^2 I)\bigr)$。
5. 更新$\theta \leftarrow \theta - \eta\,\tilde{\mathbf g}$。

输出$\theta$，并由隐私记账器根据$q$、$\sigma$、$T$与$\delta$计算总体的$(\varepsilon, \delta)$。
:::

裁剪使梯度之和关于增删单个样例具有$\ell_2$-敏感性$C$；标准差为$\sigma C$的高斯噪声随后把每一步变成一个**高斯机制**，当$\sigma$合适时它是$(\varepsilon, \delta)$-差分隐私的（对单次发布、$\varepsilon < 1$的情形，$\sigma \ge \sqrt{2\ln(1.25/\delta)}/\varepsilon$即已足够；Dwork 与 Roth，2014，定理 A.1）。随机子采样会**放大**隐私——不在批次中的样例根本不会被用到——而矩记账对$T$步累积代价的追踪又远比基本组合紧凑。只有加了噪的梯度接触过数据；由后处理，最终模型以及由它算出的一切自动继承这一保证。

::: example 一步中的噪声与信号 {#ex-dpsgd}
某次 DP-SGD 更新使用期望批次大小$L = 1024$、裁剪范数$C = 1$、噪声乘子$\sigma = 1$。若所有裁剪后的梯度方向大致相同、范数都为$1$，试对一个有$d = 10^6$个参数的模型，比较平均信号的范数与噪声在每坐标及总体的范数。
::: solution
平均信号的范数约为$1$。噪声向量除以$L$后，每坐标标准差为$\sigma C/L = 1/1024\approx 0.001$，总范数约为$\sqrt d\,\sigma C/L = 1000/1024\approx0.98$。于是噪声的范数与信号几乎不相上下，却摊散在一百万个方向上。训练仍然有效，是因为噪声在步与步之间相互抵消，而方向一致的信号不断累积；更大的批次（更大的$L$）和更少的参数（或只更新其中少数的参数高效微调）能改善这一比值——这也是对大型预训练模型做 DP 微调比从零开始的 DP 训练更可行的原因之一。
:::
:::

在图像基准上，Abadi 等报告在$\varepsilon = 0.5$、$2$与$8$（$\delta = 10^{-5}$）下 MNIST 准确率约为$90\%$、$95\%$与$97\%$，而无隐私时约为$98\%$–$99\%$。对语言模型，Li 等（2022）与 Yu 等（2022）表明：在私有数据集上用 DP 微调大型*预训练*模型，只要调好超参数（尤其是采用大批次），在适中的$\varepsilon$下效用的损失相对很小。用 DP 做预训练则因规模巨大、需要海量批次而代价高得多；Google 介绍了 VaultGemma（2025），一个用序列级差分隐私预训练的 10 亿参数模型，其报告的性能与数年前不带隐私的模型相当。DP 也被用于手机上键盘语言模型的联邦学习，那里的隐私单位是用户。

### 隐私–效用权衡 {#sec-tradeoff}

对简单查询，这一权衡可以精确算出。

::: example 私有均值 {#ex-mean}
$n$个用户每人持有一个$[0, 1]$内的值（例如是否使用过某项功能）。我们用$\varepsilon = 1$的拉普拉斯机制发布均值。$n = 100$、$n = 10^4$与$n = 10^6$时，噪声的标准差各是多少？与标准差为$0.5$的$n$个值的均值的抽样误差相比又如何？
::: solution
敏感性为$1/n$，故$b = 1/(n\varepsilon)$，噪声标准差为$\sqrt2\,b = \sqrt2/n$：$0.0141$、$1.41\times10^{-4}$与$1.41\times10^{-6}$。均值的抽样标准误为$0.5/\sqrt n$：$0.05$、$0.005$与$0.0005$。噪声按$1/n$下降，抽样误差按$1/\sqrt n$下降，因此对大规模人群来说隐私噪声可以忽略。而对一个小群体——$100$人——噪声约是抽样误差的四分之一；对$10$人的群体，噪声反而比抽样误差还大。
:::
:::

这个例子体现了总体规律。DP 通过让输出对每个个体都不敏感来保护个体：对许多人共有的模式代价低廉，对只有少数人承载的信息则代价高昂。在 DP 之下，罕见方言、少数群体与长尾事实学得更差；Bagdasaryan、Poursaeed 与 Shmatikov（2019）发现 DP-SGD 对代表性不足的类别与子群的准确率降低最多。Feldman 的论证（[[#def-counterfactual]]）解释了原因：记忆长尾恰恰是 DP 所禁止的。这是隐私与公平之间真实的权衡，两者都不能简单地一味最大化。

::: warning 差分隐私的宣称，其意义不超过它的隐私单位与$\varepsilon$
"用差分隐私训练"可能指样例级、序列级或用户级保护。一个针对$512$词元序列的保证，对一个的数据横跨数千条序列的人几乎什么都说明不了：由群体隐私（[[#prop-composition]]），其有效$\varepsilon$随序列条数增长。报告时应写明隐私单位、$\varepsilon$、$\delta$、所用的记账器，以及在私有数据上调整超参数是否计入了开销（Ponomareva 等，2023 给出了报告规范）。
:::

::: quiz
一家公司用 DP-SGD 在客户邮件上微调模型，$\varepsilon = 2$、$\delta = 10^{-8}$，隐私单位是一封邮件。下列说法哪项正确？
- [ ] 无法从模型中推断出任何客户的任何信息。
- [x] 对任何单封邮件，针对模型做的成员检验都满足$\text{TPR}\le e^{2}\,\text{FPR} + 10^{-8}$；而发过$50$封邮件的客户得到的保证要弱得多。
- [ ] 对模型多次采样会削弱保证，因为每次采样都要花费预算。
- [ ] 这一保证要求先从邮件中清除姓名。
::: solution
DP 限制的是一个隐私单位——这里是一封邮件——对输出分布的影响；由[[#prop-test]]，成员检验服从上述界。群体隐私意味着拥有$50$封邮件的客户只在$\varepsilon$高达$100$的意义上受保护。许多客户共有的模式仍可能被学到并推断出来——这本就是模型的意义所在。采样是后处理，不花预算；DP 并不要求先做清除，尽管额外清除仍可能有用。
:::
:::

## 记忆化之外的隐私 {#sec-beyond}

**属性推断。**模型不必记住某个人的任何信息，也可能侵犯其隐私。Staab 等（2024）发现，大语言模型能从论坛评论这类看似无害的文本中推断个人属性——地点、年龄、职业、收入——其准确率接近人类调查人员，而成本与时间只是后者的零头。这是一种能力，而不是训练数据的泄露；DP 训练对它无能为力。

**情境完整性。**Nissenbaum 的框架（2004）认为，隐私关乎信息流是否与信息被分享时所处情境的规范相称。在一个小圈子里公开发的帖子在技术上算是公开的，但把它收集进训练集、或在回答陌生人提问时把它翻出来，都可能违背当初分享它所依循的规范。这一观点有助于解释为什么许多人反对用"公开"数据训练，而另一些人则认为公开发帖的信息不附带合理的隐私期待；不同的法律制度对这两种观点各采信多少，并不相同。

**用户对话与检索。**已部署的助手会收到用户提供的个人信息。关于留存、是否用于训练、人工审查以及第三方访问的问题，由提供方政策与法律管辖，而不取决于模型的数学；截至 2026 年，主要提供方都提供把对话排除在训练之外的设置，具体条款在消费级与企业级产品之间有所不同，且随时间变化。检索增强系统（[[prompting-rag/retrieval-augmented-generation]]）如果不在检索时执行访问控制，就可能把文档暴露给本不该看到它们的用户；提示注入可以被用来把数据从上下文中窃取出去（[[safety-alignment/robustness-jailbreaks]]）。

**法律。**训练数据若含有个人数据，即受数据保护法管辖。按欧盟《通用数据保护条例》（General Data Protection Regulation，GDPR），处理个人数据需要法律依据（就模型训练而言，提供方一般倚赖"合法利益"这一依据，它能否适用于全网规模的训练已受到欧洲数据保护机构的审查），而个人享有访问、更正与删除的权利。2023 年 3 月，意大利数据保护局（Garante）在意大利临时限制 ChatGPT，援引的理由包括训练缺乏法律依据、以及缺乏年龄验证；约一个月后，在做出整改之后服务恢复。欧洲数据保护委员会于 2024 年 12 月就 AI 模型与个人数据发布了一份意见。删除之类的权利如何适用于一个训练好的模型——它不以可检索的形式存储记录，却又可能复现出其中一些——尚无定论（截至 2026 年）。

**机器遗忘。**机器遗忘（machine unlearning）旨在不从头重训的情况下，从训练好的模型中移除特定数据的影响。有些设计能做到精确遗忘（把数据分成若干片、每片单独训练一个模型，删除时只需重训那一片；Bourtoule 等，2021）；但对大语言模型，多数方法只是近似的——靠微调来压抑某条知识——而评测发现，被压抑的信息往往能通过换个说法的提示或轻度微调恢复出来。如何验证遗忘已经生效，本身仍是一个开放的研究问题。

::: history
"匿名化"数据的隐私失灵催生了这一领域：Sweeney（1997–2000）仅凭邮政编码、出生日期与性别就重识别出了医疗记录，Narayanan 与 Shmatikov（2008）则击穿了 Netflix 大奖赛数据集的匿名性。Dwork、McSherry、Nissim 与 Smith（2006）提出了差分隐私与拉普拉斯机制；Dwork 与 Roth 的专著（2014）是标准参考文献。Shokri 等（2017）提出了针对机器学习模型的成员推断，Abadi 等（2016）以 DP-SGD 与矩记账使深度学习满足差分隐私。美国人口普查局在 2020 年人口普查的选区划分数据中使用了差分隐私。就语言模型而言，Carlini 等（2019）测量了模型对植入的"金丝雀"（canary）字符串的无意记忆，Carlini 等（2021）从 GPT-2 中提取出训练数据，Carlini 等（2023）量化了记忆化如何随规模增长，Nasr 等（2023）把提取扩展到了生产环境的模型。Brown 等（2022）追问语言模型要保全隐私意味着什么，并论证数据清洗与 DP 都达不到人们真正在意的那种情境化的隐私概念。
:::

::: summary
- 模型会逐字记住某些训练序列；可提取性随模型规模、重复次数与提示长度增长（实验规律），只出现过一次的个人数据同样可能被记住。
- 去重能大幅减少记忆内容的输出；对齐改变典型行为，却未必抹去已记住的内容。
- 成员推断用来度量泄露；其优劣以低假阳性率下的真阳性率来评判，而在大规模预训练语料上许多攻击仅略好于随机。
- $(\varepsilon, \delta)$-差分隐私算法的输出分布，在某个个体的数据发生变化时，概率至多被乘以因子$e^\varepsilon$（外加$\delta$）；尺度为$\Delta f/\varepsilon$的拉普拉斯机制实现了这一点，于是任何成员检验都有$\text{TPR}\le e^\varepsilon\text{FPR} + \delta$。
- DP 对后处理封闭、并且可组合，因此训练要支出预算；DP-SGD 裁剪逐样例梯度并添加高斯噪声，由记账器跟踪总代价。
- 效用损失随人群规模增大而减小，并集中在罕见数据与小群体上——这是隐私、长尾学习与公平之间真实的张力。
- 属性推断、情境规范、对话处理、数据保护法与机器遗忘带来的隐私问题，不是 DP 训练所能解决的。
:::

## 习题

::: exercise 拉普拉斯的尺度 {level=1 check="4"}
一个计数查询（敏感性$1$）以$\varepsilon = 0.25$发布。拉普拉斯噪声的尺度$b$是多少？
::: solution
$b = \Delta f/\varepsilon = 1/0.25 = 4$。
:::
:::

::: exercise 噪声的尾部 {level=1 check="0.135"}
当$b = 4$时，噪声的绝对值超过$8$的概率是多少？保留三位小数。
::: solution
$\Prob(\lvert Z\rvert > t) = e^{-t/b} = e^{-2} = 0.135$。
:::
:::

::: exercise 组合 {level=1 check="1.5"}
一名分析员用拉普拉斯机制运行三个查询，$\varepsilon$ 分别为$0.5$、$0.25$与$0.75$。基本组合给出的总$\varepsilon$是多少？
::: solution
$0.5 + 0.25 + 0.75 = 1.5$。
:::
:::

::: exercise 攻击者的界 {level=2 check="0.074"}
一个模型用纯$\varepsilon = 2$差分隐私训练。攻击者的检验的假阳性率为$1\%$。真阳性率最大可能是多少？保留三位小数。
::: solution
$\text{TPR}\le e^2\cdot0.01 = 7.389\cdot0.01 = 0.0739$，即$0.074$。
:::
:::

::: exercise 重度用户的群体隐私 {level=2 check="40"}
一个模型按序列级$\varepsilon = 0.8$（$\delta$可忽略）训练。某人的作品构成$50$条训练序列。由群体隐私，对这个人整份数据的保护由多大的$\varepsilon$界定？
::: solution
$k\varepsilon = 50\cdot0.8 = 40$——松到几乎不构成任何保证的界。此情形需要用户级差分隐私——把一个人的全部数据当作一个隐私单位——才有有意义的保证。
:::
:::

::: exercise 私有直方图 {level=2}
发布$n$个用户年龄的$10$个分箱的直方图，每个用户恰好贡献给一个分箱。(a) 在增删一个用户时，$10$个计数构成的向量的$\ell_1$-敏感性是多少？(b) 每箱的拉普拉斯尺度取多少可满足$\varepsilon = 1$？(c) 为什么这比把$10$个计数当作$10$个独立查询再组合要好？
::: solution
(a) 增删一个用户只改变一个计数$1$：敏感性为$1$。(b) 由[[#thm-laplace]]（取$d = 10$），每箱$b = 1/\varepsilon = 1$。(c) 若把$10$个计数查询各以$\varepsilon = 1$组合，将得$\varepsilon = 10$；或要为总$\varepsilon = 1$就得每箱尺度$10$。由于分箱互不相交，一个用户只影响一个计数，联合敏感性仍为$1$——相当于十倍的节省（有时称为并行组合）。
:::
:::

::: exercise 私有均值的误差 {level=2 check="0.0014"}
用$\varepsilon = 1$的拉普拉斯机制发布$n = 1000$个$[0, 1]$内取值的均值。噪声的标准差是多少？保留两位有效数字。
::: solution
敏感性$1/n = 10^{-3}$，$b = 10^{-3}$，标准差$\sqrt2\,b = 1.41\times10^{-3}\approx0.0014$。
:::
:::

::: exercise 单次发布的高斯噪声 {level=2 check="9.69"}
对$\ell_2$-敏感性为$1$的查询做单次高斯发布，利用充分条件$\sigma\ge\sqrt{2\ln(1.25/\delta)}/\varepsilon$：对$(\varepsilon, \delta) = (0.5, 10^{-5})$，它允许的最小噪声标准差是多少？保留两位小数。
::: solution
$\ln(1.25/10^{-5}) = \ln(1.25\times10^5) = 11.736$，故$\sqrt{2\cdot11.736} = 4.845$，$\sigma = 4.845/0.5 = 9.69$。$\varepsilon$减半，噪声加倍；$\delta$缩小十倍，噪声只增大约$10\%$。
:::
:::

::: exercise 为什么重复次数比看上去更要紧 {level=3}
用[[#ex-duplication]]中的理想化模型$q(c) = \min(1, q_1c^{\alpha})$证明：当$\alpha > 1$时，一条重复$c$次的记录贡献的期望泄露，比$c$条各只出现一次的记录更多。对$q_1 = 10^{-4}$与$\alpha = 3$，在这个模型中重复到多少次，提取就变得确定？讨论去重不能做到什么。
::: solution
一条有$c$份副本的记录，提取概率为$q_1c^\alpha$；$c$条互不相同、各出现一次的记录，期望总量为$cq_1$。二者之比为$c^{\alpha - 1}$，当$c > 1$、$\alpha > 1$时大于$1$：重复使泄露超线性地集中。当$q_1c^3 = 1$，即$c = 10^{4/3} = 21.5$时提取成为必然，故$22$份副本即达到。去重能把每条记录都降到只出现一次的比率，但无法低于该比率；而且它只对完全或近乎完全相同的副本有效，同一条个人信息却可能散见于措辞不同的文档之中。对只出现一次的信息，保护要靠 DP 之类的手段，或者干脆不收集数据。
:::

::: exercise 拉普拉斯机制是紧的 {level=3}
对计数查询、$\varepsilon = 1$的拉普拉斯机制，证明：每个满足$S\subseteq[c + 1, \infty)$的输出集合（$c$为不含 Alice 时的计数）都恰有$\Prob[M(D)\in S] = e\,\Prob[M(D')\in S]$成立，因此[[#thm-laplace]]的界不可能再改进。然后解释清单输出的最后两行。
::: solution
对$y \ge c + 1$，含 Alice 的密度为$\tfrac12e^{-(y - c - 1)}$，不含的为$\tfrac12 e^{-(y - c)}$；在每个这样的$y$处二者之比都是$e^{1}$。在$S$上积分即得等式。清单中，判定阈值$1001$与$1003$都高于两个均值（$999$与$1000$），因此判定域正是这种形状，TPR/FPR $= e = 2.72$。而在阈值$999.5$处，判定域包含了两个均值之间密度之比小于$e$的那些点，于是TPR/FPR $= 2.29$。
:::
