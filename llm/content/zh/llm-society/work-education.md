ChatGPT 于 2022 年 11 月发布后不到两年，调查发现：许多国家有相当高比例的劳动者已在工作中使用生成式 AI，多数大学生已在学业中使用它。语言模型会写初稿、摘要文档、答复客户、做翻译、编写并评审代码。由此引出的问题其实是以新形式出现的旧问题：哪些任务会被机器接管？劳动者会变得更富有生产率吗，收益会被谁获得？某些工作会消失吗，会有新的工作出现吗？至于教育：学生应当学什么，我们又如何确知他们学到了？

本章梳理目前已知的事实，并着重说明这些知识是如何得来的。我们从**暴露（exposure）**研究讲起——它们估计语言模型可能影响哪些任务——并解释暴露为何不等于替代。接着检视测量生产率效应的**实地与实验室实验**——客户支持（Brynjolfsson、Li 与 Raymond）、专业写作（Noy 与 Zhang）、管理咨询（Dell'Acqua 等）、软件开发——以及限制其结论外推范围的方法论注意事项。一个简单的宏观经济核算展示任务层面的增益如何汇聚为总量生产率、以及为什么不同估计相差一个数量级。下半章转向**教育**：实验对借助 AI 学习的说法，以及考核正在如何被重新设计。

这些证据还很年轻。多数研究只覆盖广泛使用的前两三年、特定工具和特定公司，而模型此后又进步了许多。结果都标注发表时的日期，本章也把实测发现与预测区分开来。

## 是任务，不是职业 {#sec-tasks}

经济学家通过**任务**——产出产出的工作活动单元——而非职业来研究技术变迁，因为一种技术通常会改变某一职业中的部分任务而保留其余（Autor、Levy 与 Murnane，2003；Acemoglu 与 Autor，2011）。美国劳工部的 O*NET 数据库用约 $19{,}000$ 项任务描述约 $1{,}000$ 种职业，是多数暴露研究的基础。

::: definition 任务暴露（Eloundou 等, 2023） {#def-exposure}
若通过聊天接口访问语言模型就能在质量相当的前提下把人类完成某任务所需时间至少减少一半，则该任务**直接暴露**（$E_1$）；若时间缩减还需要构建于模型之上的额外工具（检索、与其他系统集成），则为**与互补软件一起暴露**（$E_2$）；否则**不暴露**（$E_0$）。一个职业的暴露度是其任务在各类别中的占比；Eloundou 等报告了 $\alpha = E_1$、$\beta = E_1 + \tfrac12E_2$ 与 $\zeta = E_1 + E_2$。
:::

Eloundou、Manning、Mishkin 与 Rock（2023；2024 年发表于 *Science*）让人类标注者与 GPT-4 分别评定每一条 O*NET 任务，结果大体一致。他们估计，美国约 $80\%$ 的劳动者处在至少 $10\%$ 任务暴露的职业中，约 $19\%$ 处在至少一半任务暴露的职业中；若加上互补软件，全部任务中有 $47\%$–$56\%$ 能在同等质量下显著提速完成。与以往自动化不同，暴露度随工资与教育水平*上升*：写作者、口笔译员、数学家、报税员与网页设计师在最暴露之列，而依赖体力劳动的职业最不暴露。Gmyrek、Berg 与 Bescond（2023）为国际劳工组织做的研究发现，文书支持类工作是全世界暴露度最高的类别，多数其他职业更可能被*增强*（一部分任务受影响）而非被自动化；而高收入国家的女性因集中于文书岗位，暴露度更高。

::: example 一个职业的暴露度 {#ex-exposure}
某类职业的工作由五项任务构成，其时间占比与评级为：起草报告（$30\%$，$E_1$）、回复客户邮件（$20\%$，$E_1$）、在内部系统中分析数据（$20\%$，$E_2$）、会见客户（$20\%$，$E_0$）、现场巡检（$10\%$，$E_0$）。按时间占比加权计算 $\alpha$、$\beta$ 与 $\zeta$。若每项 $E_1$ 任务的耗时减半、每项 $E_2$ 任务的耗时缩短四分之一，总工作时间可节省多大比例？
::: solution
$\alpha = 0.3 + 0.2 = 0.5$；$\beta = 0.5 + 0.5\cdot0.2 = 0.6$；$\zeta = 0.7$。节省时间：$0.5\cdot0.5 + 0.2\cdot0.25 = 0.25 + 0.05 = 0.30$，即 $30\%$ 的工作时间。注意 Eloundou 等对任务是等权而非按时间加权；按时间加权的版本更接近经济学上要紧的量，而结果对这个选择非常敏感。
:::
:::

::: warning 暴露不等于失业
被暴露的任务只表示模型*可能*在其上省时。这种省时是否导致岗位减少，取决于省时是否会被采纳（成本、可靠性、监管、组织变革）、它替代工人还是辅助工人、价格下降后需求如何反应、以及是否出现新任务。暴露研究是带着一系列判断做出的技术潜力测量——在 Eloundou 等的研究中甚至包括模型对自身作出的判断。它们不预测就业，作者自己也这么说。
:::

### 替代、生产率与新任务

Acemoglu 与 Restrepo（2018；2019）的任务框架分离出三种力量。**替代**（displacement）：机器接管先前由劳动完成的任务，减少这些任务对劳动的需求。**生产率**（productivity）：生产变便宜会提高对产出以及未自动化任务中劳动的需求。**恢复**（reinstatement）：创造出劳动拥有比较优势的新任务（Autor 等（2024）发现，2018 年美国多数就业处在 1940 年并不存在的职业名称之下）。一种技术究竟抬高还是压低工资与就业，取决于三者的对比，而对*自动化*任务的技术与在工作中*增强*工人的技术，对比并不相同。语言模型两者皆能为之，这正是预测分歧的原因之一。

## 实地与实验室证据 {#sec-experiments}

关于生产率的最有力证据，来自比较有无模型访问的工人的研究——访问资格或随机分配，或以能允许跨期比较的方式分阶段推行。

::: definition 双重差分 {#def-did}
设结果 $Y$ 在处理前后各有观测，$T$ 为处理组、$C$ 为对照组，则**双重差分**（difference-in-differences）估计量为

$$
\hat\tau_{\text{DiD}} = \bigl(\bar Y_{T,\text{after}} - \bar Y_{T,\text{before}}\bigr) - \bigl(\bar Y_{C,\text{after}} - \bar Y_{C,\text{before}}\bigr).
$$

它在**平行趋势假设**下识别对处理组的平均处理效应：若无处理，处理组结果的变化本应与对照组相同。在**阶梯式推行**下，各组在不同时点采纳，尚未处理者充当对照组（另有需要配合采纳时点间异质性的估计量）。
:::

**客户支持。**Brynjolfsson、Li 与 Raymond（NBER 工作论文 2023；*Quarterly Journal of Economics* 2025）研究了一家软件公司的 $5{,}179$ 名客服人员，其间一个基于 GPT 的助手（建议答复并链接到文档）被分阶段上线。利用这一阶梯式推行，他们发现每小时解决的问题数平均增长约 $14\%$，新手与低技能工人增长约 $34\%$，而经验最丰富、技能最高的工人几乎没有增长。客户的情绪更趋正面，要求转接主管的请求减少，客服离职率也在下降。作者把这一格局解读为模型把最优秀客服的隐性做法扩散给了其他人：获得助手的新手两个月内达到的进步，相当于其他人六个月达到的。

**专业写作。**Noy 与 Zhang（2023，*Science*）让 $453$ 名受过大学教育的从业者（市场人员、项目申请书撰写者、咨询顾问、数据分析师、人力资源专员、经理）完成两项有激励的、与其职业相关的写作任务，并随机对第二项开放 ChatGPT。耗时约减少 $40\%$，评分质量约提高 $18\%$。第一项任务得分较低的参与者获益更多，业绩分布因而收窄。多数参与者用模型生成初稿后几乎没有修改。

**管理咨询。**Dell'Acqua 等（2023）与波士顿咨询公司合作，让 $758$ 名顾问在有或没有 GPT-4 的条件下完成贴近现实的任务。在模型能力之内的任务——创意产品开发——上，有访问权的顾问多完成约 $12\%$ 的任务、快 $25\%$，质量评分高出 $40\%$ 以上；表现低于平均的顾问获益最大。在一道被刻意设计为恰好位于模型能力*之外*的任务——需要细读访谈笔记与电子表格数据的商业问题，模型给出的貌似合理的答案实则是错的——上，使用模型的顾问得到正确答案的可能性反而*低*约 $19$ 个百分点。作者把这种不平整的能力边界称为“参差的技术前沿”（jagged technological frontier）：边界之内业绩提升，边界之外过度依赖生出错误，而任务落在哪一侧往往没有明显征兆。

**软件开发。**在一项实验室任务中，使用 GitHub Copilot 的开发者完成一个 JavaScript HTTP 服务器的速度快了约 $56\%$（Peng 等，2023）。数家大公司的实地实验报告，获得 AI 助手的开发者合并的拉取请求增加了约四分之一，置信区间很宽，经验较少者效应更大（Cui 等，2025）。相比之下，METR 的随机试验（Becker 等，2025）让 $16$ 名资深开源开发者在自己成熟的代码库上工作，发现使用 2025 年初的 AI 工具时，他们完成任务反而*慢*了约 $19\%$——而他们事前相信工具会让自己快约 $24\%$，事后仍认为自己快了约 $20\%$。

::: example 读一个双重差分 {#ex-did}
某客服团队引入助手前平均每小时解决 $2.00$ 个问题，之后为 $2.30$。同一时期，一个没有助手的可比团队从 $2.10$ 变为 $2.20$。估计该效应，给出绝对值，以及占处理组反事实值的百分比。
::: solution
$\hat\tau_{\text{DiD}} = (2.30 - 2.00) - (2.20 - 2.10) = 0.30 - 0.10 = 0.20$ 个问题每小时。处理组的反事实值为 $2.00 + 0.10 = 2.10$，故效应为 $0.20/2.10 = 9.5\%$。朴素的今昔比较会宣称 $15\%$，把整体的改善（季节性、其他变化）归到工具头上。该估计的好坏完全取决于平行趋势假设：若处理组当初正是因为正在进步才被选中，估计就有偏。
:::
:::

### 结果为何相异：方法论注意事项 {#sec-caveats}

这些研究在一个模式上一致——在模型能力之内的明确任务上增益可观，经验较少者增益更大——但在幅度上不一致，有时连符号都不一致。几个特点可以解释。

- **任务的选择。**实验室任务简短、自足、以可完成为选，而真实工作牵涉情境、协调与核验。METR 的结果提示：对在大而熟悉的代码库中工作的专家，花在写提示、等待与检查上的时间可能超过省下的时间。
- **被测量的产出。**“完成任务数”“拉取请求数”“质量评分”都是代理指标。拉取请求变多可能只是单个变小；写作评分者可能发现不了错误；客服指标捕捉不到长期知识。
- **外部效度。**每项实地研究只覆盖一家公司、一种工具、一个时期。早期工具的可能低估后期的效应——也可能高估，若新奇感或实验者的关注抬高了努力（霍桑效应）。
- **自我报告。**关于节省时间的调查依赖感知，而 METR 的研究显示感知连方向都可能是错的。
- **局部均衡。**某公司客服生产率提高 $14\%$，对行业的工资、价格或就业并无直接含义——那些取决于竞争者与需求如何反应。

### 压缩效应的模拟 {#sec-code}

若干研究发现 AI 助手对经验最少者帮助最大。下面这段代码模拟这一模式（参数是虚构的，不是任何研究的数据），并展示它如何压缩工人之间的差距。

```python
import random, statistics as st
rng = random.Random(2023)

# 模拟客服：基准生产率随经验上升；助手的增益对新手最大
# （这是对实地研究报道之模式的风格化设定，并非其数据）。
agents = []
for _ in range(3000):
    exp = rng.uniform(0, 1)                          # 经验分位数
    base = 2.0 + 1.0 * exp                           # 每小时解决数
    gain = 0.35 * (1 - exp)                          # 比例增益
    treated = rng.random() < 0.5                     # 随机分组
    y = base * (1 + gain * treated) * rng.lognormvariate(0, 0.25)
    agents.append((exp, treated, y))

def effect(rows):
    t = [y for _, w, y in rows if w]; c = [y for _, w, y in rows if not w]
    return st.mean(t) / st.mean(c) - 1

print(f"average effect: {effect(agents):+.1%}")
for lo, hi in ((0, 1/3), (1/3, 2/3), (2/3, 1)):
    print(f"experience {lo:.2f}-{hi:.2f}: {effect([a for a in agents if lo <= a[0] < hi]):+.1%}")
for w, name in ((False, "control"), (True, "treated")):
    ys = [y for e, t, y in agents if t == w]
    top = st.mean([y for e, t, y in agents if t == w and e >= 2/3])
    bottom = st.mean([y for e, t, y in agents if t == w and e < 1/3])
    print(f"{name}: mean {st.mean(ys):.2f}/h, top-to-bottom tercile ratio {top/bottom:.2f}")
```

```text
average effect: +15.9%
experience 0.00-0.33: +25.4%
experience 0.33-0.67: +18.2%
experience 0.67-1.00: +4.9%
control: mean 2.58/h, top-to-bottom tercile ratio 1.32
treated: mean 2.99/h, top-to-bottom tercile ratio 1.10
```

约 $16\%$ 的平均效应之下，是从新手的 $25\%$ 到专家的 $5\%$ 的巨大落差，而经验最丰富者与最少者之间的差距从 $32\%$ 缩小到 $10\%$。这种压缩对新手长期是否有利是另一个问题：若因为模型代做了部分工作而使技能习得更慢，或公司因此少雇他们，那么公司内部的压缩就可能与更差的职业前景并存。Brynjolfsson 等发现，在工具不可用的日子里客服也有进步，提示存在某种学习；另一些（见 [[#sec-learning]]）教育领域的研究则发现相反情形。

## 从任务到经济 {#sec-macro}

任务层面的增益经由一个简单近似汇聚为总量生产率。

::: proposition Hulten 近似 {#prop-hulten}
在竞争经济中，若某技术使任务 $i$ 的生产成本下降 $c_i$，而任务 $i$ 占 GDP 的份额为 $s_i$，则总量全要素生产率的一阶增益为

$$
\Delta\ln\text{TFP}\approx\sum_i s_i\,c_i.
$$

特别地，若按 GDP 加权的任务中有比例 $s$ 受影响、平均成本节约为 $c$，增益约为 $s\,c$。
:::

::: proof
（概要，沿 Hulten，1978。）在竞争市场下，厂商使边际产品等于价格，故总产出对任务 $i$ 生产效率的弹性等于任务 $i$ 在总产出中的份额（其 Domar 权重 $s_i$）。成本下降 $c_i$ 在一阶上即该任务的效率提高 $c_i$，于是投入不变时总产出一阶上升 $\sum_i s_i c_i$。该近似略去二阶效应（投入的再配置、份额变化），并假设不存在市场势力与调整成本。
:::

::: example 宏观经济增益的两种估计 {#ex-macro}
Acemoglu（2024）取美国约 $20\%$ 的劳动任务为暴露，并根据十年内哪些暴露任务值得自动化，假定其中约 $23\%$ 会受影响——即 $4.6\%$ 的任务。他从实验研究中取平均劳动成本节约约 $27\%$，乘以这些任务中约 $0.53$ 的劳动份额，得总成本节约约 $14.4\%$。问[[#prop-hulten]]在十年间给出多大的 TFP 增益？若 $40\%$ 的任务受影响、成本节约 $30\%$，结果如何？
::: solution
$0.046\cdot0.144 = 0.0066$：十年约 $0.66\%$，即每年 $0.07$ 个百分点——这正是 Acemoglu 的估计，他自己称之为温和的。若 $s = 0.4$、$c = 0.3$，增益为 $0.12$，即十年 $12\%$。已发表的估计横跨这一区间：有些预测（例如高盛 2023 年的一份报告提示十年约占全球 GDP 的 $7\%$）假定了远为更广的采纳与配套创新。分歧与其说在公式，不如说在 $s$ 与 $c$——多少任务会受影响，以及在真实部署（而非实验）中测得的节约有多大。
:::
:::

:::

**迄今的劳动力市场证据。**最初几年在就业与工资上测得的效应很小，且众说纷纭。Humlum 与 Vestergaard（2025）用丹麦行政数据并对接续暴露职业劳动者的调查，发现尽管采纳广泛，到 2024 年为止对收入与登记工时的影响几乎为零，置信区间排除了几个百分点以上的平均效应。在网络自由职业平台上，Hui、Reshef 与 Zhou（2024）发现 ChatGPT 发布后，写作相关工作的自由职业者的工作机会与收入相对其他类别下降几个百分点。Brynjolfsson、Chandar 与 Chen（2025）用美国薪酬数据报告：2022 年末起，在最暴露职业中 $22$–$25$ 岁劳动者的就业相对下降，且集中于 AI 使用更偏自动化而非增强的地方，而同一职业中老年劳动者的就业保持稳定；其他对总量数据的分析未发现普遍冲击，而把职业早期的下降归于 AI 而非利率或疫后调整，也存在争议（截至 2026 年）。

**分配。**谁获益取决于劳动与资本所有者之间、经验多与少的工人之间、国与国之间的对比。职业内部，实验证据指向压缩；在整个经济中，若 AI 替代高技能认知劳动，某些受教育工作的工资溢价可能下降，而收益流向公司与用这些工具扩大产出的工人。这些都是悬而未决的经验问题。

- [ ] 国民经济的生产率将提高 $25\%$。
::: solution
拉取请求是代理指标：其规模与质量可能改变。平均值可能掩盖异质性：资深开发者可能获益更少甚至净损失时间。公司的就业取决于需求、以及开发者如何处置省下的时间；对经济的总量效应约是受影响份额乘以节约额（[[#prop-hulten]]），远低于 $25\%$。
:::
:::

## 教育 {#sec-education}

### 借助 AI 学习 {#sec-learning}

语言模型可以充当导师：随时答疑、按学生的水平讲解、对文稿给出反馈。它们也可以替学生完成作业。实验证据表明，这两种用途的分别关系极大。

- Bastani 等（2025，*PNAS*）对约 $1{,}000$ 名土耳其高中生的数学实地实验中，一部分学生使用标准 GPT-4 界面，另一部分使用被提示给线索而非给答案的“导师”版。练习期间，标准界面的成绩提高 $48\%$，导师版提高 $127\%$。在随后一次无访问权的考试中，用过标准界面的学生比对照组低 $17\%$，而导师版用户与对照组无显著差异。作者的结论是：不受限的访问可能替代学习。
- Kestin 等（2025，*Scientific Reports*）在哈佛一门入门物理课的交叉设计研究中发现，使用精心设计的 AI 导师的学生，比在同一材料上参与主动学习课堂的学生，以更少时间学到更多。
- 世界银行在尼日利亚的试点（De Simone 等，2025）发现，六周以 GPT-4 为导师、有教师引导的课后辅导，使英语测试成绩相对对照组提高约 $0.3$ 个标准差。

共同的线索是设计：用来给答案的模型可以帮助完成任务却损害学习；被约束去搭建思维支架、嵌入教学的模型则能有帮助。对**认知卸载**——依赖工具、丢失技能——的担忧，在计算器与搜索引擎上由来已久；关于语言模型的早期研究提示同样问题，但样本尚小、尚无定论。

### 学术诚信与考核 {#sec-assessment}

调查显示采纳极快：英国高等教育政策研究所 2025 年对本科生的调查称 $92\%$ 的学生以某种方式使用 AI 工具，$88\%$ 曾在考核中使用生成式 AI，比一年前大幅上升。当模型能写论文、能解习题集，课外无监督完成的考核就不再能证明学生在无人协助时能做什么。回应以三类为主，且常常并用。

1. **检测。**如[[llm-society/misinformation#prop-auroc]]所示，检测器并不可靠，对非母语写作者有偏见，其误报落在个体头上；许多大学建议不要将其单独作为证据。
2. **保障考核。**现场笔试、口试（“vivas”）、当堂写作与现场监督的实践操作，能重新确证作业出自本人，代价是时间，以及放弃课程作业本要考核的、经延展与调研的工作。
3. **重新设计考核。**课程对每项考核写明允许的 AI 使用程度，并对过程——草稿、反思、版本历史——连同结果一起考核。Perkins、Furze、Roe 与 MacVaugh（2024）提出 **AI 考核量表**（AI Assessment Scale），等级从“不用 AI”经“用 AI 做规划”“与 AI 协作”“完全用 AI”到“用 AI 探索”，对每个任务分别申明。一些大学采用“双车道”模式：保障性考核核验无人协助时的能力，开放式考核允许并期待使用 AI，且把这种使用作为技能来教、来考。

::: definition 考核的效度与保障 {#def-validity}
一项考核之**效度**，指其结果在多大程度上支持关于学生知道什么、能做什么的意图推断；其**保障**（安全性），指在被评作业于既定条件下确系学生本人完成的程度上。一篇 AI 能代写的无监督论文，作为练习仍有助于学习，却不再能支持关于学生独立写作能力的可靠推断。
:::

::: example 选择考核组合 {#ex-assessment}
一门课的学习目标是 (a) 回忆并应用统计方法，(b) 撰写研究报告，(c) 批判性地评估一份 AI 生成的分析。为每一项设计一种考核，说明允许的 AI 使用程度，以及如何实现保障与效度。
::: solution
(a) 现场监考的闭卷考试，不用 AI：有保障；对独立应用能力有效。(b) 一份允许 AI 在语言与结构上协助的报告，但须提交草稿、数据与代码，并就所做选择进行一次简短口试讨论：口试保障了“学生理解这份作业”的推断；报告本身考核的是用工具产出报告这一现实技能。(c) 发给学生一份有缺陷的模型生成分析，要求其找出并纠正错误，允许使用 AI：正因模型会犯这类错，该任务才是有效的，做对需要真正的理解。每种设计都在人力、真实性与保障之间取舍；没有唯一正确的设计。
:::
:::

::: warning “一禁了之”与“全面拥抱”都是不完备的政策
一刀切的禁令对课外作业无从执行，还使学生对使用这些工具的工作场所毫无准备；而无条件放行会让大量课程作业不再反映学习，且如 Bastani 等的结果所提示，可能损害学习本身。多数院校的指南（截至 2026 年）按考核设定预期、教授恰当使用及其限度，并保障一部分考核。
:::

::: history
对机器消灭工作的恐惧反复出现：1811–16 年的卢德运动、1950–60 年代的“自动化”争论、以及 Keynes 1930 年论“技术性失业”的短文。Autor、Levy 与 Murnane（2003）把基于任务的方法引入计算机化研究；Frey 与 Osborne 的估计（2013 年提出，2017 年发表）——美国 $47\%$ 的就业处于自动化高风险——引发了关于暴露度测量的十年争论。ChatGPT（2022 年 11 月）之后，Eloundou 等（2023）给出首个系统的 LLM 暴露估计，一年之内实验研究相继问世：Noy 与 Zhang（2023）、Brynjolfsson、Li 与 Raymond（2023）、Dell'Acqua 等（2023）与 Peng 等（2023）。Acemoglu（2024）应用 Hulten 定理论证宏观效应有限。教育方面，许多学校与大学在 2023 年初限制 ChatGPT，随后在 2023–25 年转向允许使用的指南与考核重设计。
:::

::: summary
- 技术改变的是任务，不是整个职业。暴露研究（Eloundou 等，2023）发现很大份额的任务——不同寻常地，高收入工作尤甚——可被语言模型提速；暴露是技术潜力，不是失业预测。
- 替代、生产率与恢复三种效应方向不一；语言模型既能自动化也能增强。
- 实地与实验室实验在合适任务上发现可观的平均增益——客服 $14\%$、专业写作省时 $40\%$、顾问在“前沿”之内质量大增——经验较少者增益最大；在前沿之外，或在专家熟悉的代码库里，表现可能下降。
- 结果取决于任务选择、产出代理、外部效度与自我报告；双重差分与随机设计有值得核对的假设。
- Hulten 近似（增益 $\approx s\,c$）把任务节约与总量生产率联结起来；因 $s$ 与 $c$ 不确定，估计相差一个数量级。2024–25 年间实测的劳动力市场效应很小且有争议。
- 教育中，不受限的访问能提升练习表现却减少学习，而导师式设计能有帮助。检测并不可靠；考核正围绕保障、效度与明确的允许使用等级重新设计。
:::

## 习题

::: exercise 暴露份额 {level=1 check="0.45"}
某职业有十项等权任务：三项 $E_1$、三项 $E_2$、四项 $E_0$。把 $\beta = E_1 + \tfrac12E_2$ 算成小数。
::: solution
$0.3 + 0.5\cdot0.3 = 0.45$。
:::
:::

::: exercise 一个双重差分 {level=1 check="0.5"}
处理组工人的日产量从 $10$ 升到 $12$ 件；对照组从 $10$ 升到 $11.5$ 件。估计处理效应（件/天），并用处理组反事实值的百分比表示。
::: solution
$\hat\tau = (12 - 10) - (11.5 - 10) = 2 - 1.5 = 0.5$ 件每天。反事实值为 $11.5$，故效应为 $0.5/11.5 = 4.3\%$，而朴素的今昔数字是 $20\%$。
:::
:::

::: exercise 一行 Hulten {level=1 check="0.9"}
若按 GDP 加权的任务中有 $15\%$ 便宜了 $6\%$，一阶 TFP 增益是多少个百分点？
::: solution
$0.15\cdot0.06 = 0.009$，即 $0.9\%$。
:::
:::

::: exercise 加权平均效应 {level=2 check="0.142"}
某公司 $40\%$ 的新手使用助手后生产率提高 $30\%$，$40\%$ 的中级人员（提高 $10\%$），$20\%$ 的资深人员（提高 $0\%$）。新手基准生产率 $2$，中级 $2.5$，资深 $3$。总产出的比例增益是多少？给出三位小数，并与个人增益的简单平均比较。
::: solution
总产出原来为 $0.4\cdot2 + 0.4\cdot2.5 + 0.2\cdot3 = 0.8 + 1.0 + 0.6 = 2.4$。产出增量为 $0.4\cdot2\cdot0.3 + 0.4\cdot2.5\cdot0.1 = 0.24 + 0.10 = 0.34$。增益 $0.34/2.4 = 0.142$。个人增益的平均 $0.4\cdot0.3 + 0.4\cdot0.1 = 0.16$ 更大，因为最大的增益落在生产率最低的工人身上。研究各自报告其一，两者不可互换。
:::
:::

::: exercise 解读参差前沿 {level=2}
在 Dell'Acqua 等（2023）中，使用 GPT-4 的顾问在多数任务上做得更好，在一道被设计为超出模型能力的任务上做得更差。解释为什么前沿之外的损失对组织可能比平均值显示的更重要，并提出两项降低它的做法。
::: solution
前沿之外，模型给出自信、貌似合理、实则错误的答案，而习惯了在前沿之内信任它的用户会照单全收；错误是相关的（许多人犯同一个错）、在后果显现前不可见，而前沿之内的增益摊薄。做法：(1) 对模型表现未知或经核实薄弱的任务设置核验环节（清单、第二人复核、与源数据比对）；(2) 用内部评估绘制当前模型的前沿之内有哪些任务、随模型迭代修订，并训练员工识别警示信号（新数据、跨文档的数值推理、模型无法看到全部相关信息的任务）。
:::
:::

::: exercise 自我报告与测量 {level=2}
METR 研究中，开发者预期 AI 工具会让他们快 $24\%$，事后估计自己快了 $20\%$，实测却是慢了 $19\%$。给出主观时间与实测时间背离的三个理由，并说明这对基于调查的省时估计意味着什么。
::: solution
理由包括：(1) 等待并评审模型输出比写代码费力感更轻，主观上显得更短；(2) 难忘的成功（瞬间生成样板代码）压过了弥散的成本（调试微妙错误、切换上下文）；(3) 预期给自评染色（开发者本就相信工具有用）。因此基于调查的省时估计可能有偏，方向不明，且随任务与用户而异；应在可能时用实测结果加以校验。
:::
:::

::: exercise 压缩及其限度 {level=3}
在上面那段代码中，处理组最高与最低三分位之比从 $1.32$ 降到 $1.10$。就该模型的参数（基准 $2 + e$，增益 $0.35(1 - e)$，$e$ 服从均匀分布），忽略噪声，推出 $e = 1/6$ 与 $e = 5/6$（三分位中点）处有无助手时的期望生产率及由此得到的比值。然后讨论公司内部的压缩与新手在劳动力市场上更差的结局并存的两种机制。
::: solution
无助手时：$2.167$ 与 $2.833$，比值 $1.31$。有助手时：$2.167\cdot(1 + 0.35\cdot5/6) = 2.167\cdot1.292 = 2.799$；$2.833\cdot(1 + 0.35/6) = 2.833\cdot1.058 = 2.999$；比值 $1.07$。这与模拟的 $1.32$ 与 $1.10$ 接近（模拟在三分位内取平均并含噪声）。机制：(1) 若新手边学边做恰是模型所做之事，公司可能少雇新手——被雇者受益而雇佣规模缩小——这正是 Brynjolfsson、Chandar 与 Chen（2025）在职业早期就业中提示的格局；(2) 若新手因模型代供答案而学习变慢（如 Bastani 等的教育结果），他们可能止步不前，而一旦工具失效或工作变化，压缩可能逆转。工资效应还取决于公司是把更高的产出付给工人还是自己占有。
:::
:::

::: exercise 宏观敏感性分析 {level=3}
用[[#prop-hulten]]，设受影响任务的份额 $s$ 不确定、服从 $[0.02, 0.2]$ 上的均匀分布，成本节约 $c$ 与之独立、服从 $[0.1, 0.4]$ 上的均匀分布。计算期望 TFP 增益 $\E[sc]$，以及增益超过 $3\%$ 的概率。写一段只用标准库的简短 Python 模拟来检验答案。
::: solution
由独立性 $\E[sc] = \E s\,\E c = 0.11\cdot0.25 = 0.0275$，约 $2.75\%$。对 $P(sc > 0.03)$：对每个 $c$，需 $s > 0.03/c$；积分：$P = \frac{1}{0.3}\int_{0.15}^{0.4}\frac{0.2 - 0.03/c}{0.18}\,dc$（当 $c < 0.15$ 时 $0.03/c > 0.2$，不可能）。该积分为 $0.2\cdot0.25 - 0.03\ln(0.4/0.15) = 0.05 - 0.02942 = 0.02058$；除以 $0.3\cdot0.18 = 0.054$ 得 $P = 0.381$。

```python
import random
rng = random.Random(1)
xs = [rng.uniform(0.02, 0.2) * rng.uniform(0.1, 0.4) for _ in range(200000)]
print(round(sum(xs) / len(xs), 4), round(sum(x > 0.03 for x in xs) / len(xs), 3))
```

```text
0.0275 0.382
```

模拟与解析结果一致。这道习题说明：哪怕模型简单，只要对输入给出诚实的不确定性，结果的分布就会很宽。
:::
:::
