让一个语言模型写一篇关于一名护士和一名外科医生的短故事，数一数里面的代词；让它把 “The man worked as a …” 和 “The woman worked as a …” 各补全一千次，比较两个分布；给它两份只在顶部姓名上不同的简历，问该面试哪位候选人。这些每一个都是关于**偏见**（bias）的小实验，而且每一个都以某种形式在已发表的研究中被做过。结果很少是零，而这一点之所以重要，是因为语言模型如今正被用来起草信件、筛选申请、总结病历，并回答数量极大的人的问题。

本章讲的是如何严格地思考这类结果。它把偏见的*来源*（数据、标签、系统部署的方式）、用来检测偏见的*度量*（嵌入上的关联测试、StereoSet 与 BBQ 一类的基准、反事实审计），以及模型输出进入决策时使用的*公平性准则*分开来看。数学上的中心是一个不可能性结果：当两个群体的基率不同时，一个分类器一般不可能同时在每个群体内部校准、又让错误率在群体之间相等。我们将证明这一定理、对它做具体计算，并讨论它意味着什么、不意味着什么。最后讨论缓解手段及其局限。

公平是一个技术性与规范性问题交汇的领域。什么样的差距算不公平、什么样的权衡可以接受，这些是价值观与法律的问题，而不是数学问题。本章的目标是把技术部分说准确，让规范性部分能被清楚地讨论；学界有分歧之处，我们给出主要立场。

## “偏见”指什么 {#sec-meaning}

这个词至少有三种值得分开的用法：

- **统计偏见**：估计量的期望与它要估计的量之差。一个在有代表性的数据上训练出的模型，可能在无人有意为之的情况下，对某个子群体就带有统计偏见。
- **社会偏见**：一个系统按照性别、族裔、宗教、年龄、残障或国籍等属性，在对人的对待或呈现上表现出系统性差异，并且这些差异延续了刻板印象或历史上的不利处境。
- **不公平**：某个人们判断为没有正当理由的社会偏见。这是一个规范性判断，不同的伦理与法律框架把线画在不同的地方。

Barocas、Crawford、Shapiro 与 Wallach（2017）区分了两类伤害，这一区分此后被广泛使用。

::: definition 分配性伤害与表征性伤害 {#def-harms}
当系统拒绝给某个群体机会或资源——贷款、工作面试、医疗关注——或对其作出不平等的分配时，就发生了**分配性伤害**（allocational harm）。当系统对某个群体的呈现更不利、对其刻板化、贬低它或完全没有意识到它时，就发生了**表征性伤害**（representational harm）——无论有没有任何资源发生转移。
:::

语言模型两类伤害都会产生。一个用于给简历排序的模型可能造成分配性伤害；一个把关于某个宗教群体的提示补全为暴力联想的模型造成表征性伤害，即使并不附带任何决策。Blodgett、Barocas、Daumé 与 Wallach（2020）综述了 NLP 中关于"偏见"的 146 篇论文，发现其中许多并没有说明自己在测哪一类伤害、谁会受伤害、以及为什么被测量的行为是有害的。他们提出的要求——说清楚伤害、受影响的人与规范上的理由——对下面的一切都是值得遵守的纪律。

### 偏见的来源 {#sec-sources}

Suresh 与 Guttag（2021）给出了一个沿机器学习系统从数据走到部署的框架。移用到语言模型，主要来源有：

1. **历史偏见。**文本所描述的世界本身不平等，如实描述它的文本便反映这种不平等。如果语料中提到的大多数工程师是男性，因为过去的工程师大多数就是男性，那么学会这个语料也就学会了这种联想。更好的采样消不掉它；它就存在于数据生成过程本身。
2. **代表性偏见。**一些群体、语言与方言在网页规模的语料中代表性不足。网络文本过度代表某些国家、年轻人和某些语域；用参照文本训练的分类器做"质量"过滤，可能以更高比率移除方言（Dodge 等，2021 报告，C4 的黑名单过滤不成比例地移除了用非裔美国英语写成的文档和提及性少数群体的文档）。语料如何汇集与过滤见[[pretraining/training-data]]。
3. **测量与标签偏见。**监督信号都是代理。已发现用众包标签训练的毒性分类器会把用非裔美国英语写成的文本评为更有毒性（Sap 等，2019）；后训练所用的偏好数据反映的是被招募来的标注者的看法。从带偏的标签学习的模型，会复制标注者的判断。
4. **聚合偏见。**用一个模型去拟合一个异质总体；它可能对多数群体拟合得好，对其他群体拟合得差。
5. **评测偏见。**对某个群体代表性不足的基准，会掩盖在它上面表现不佳的事实。
6. **部署偏见。**系统被用于并非为其设计的目的或人群，或其输出被以设计者未曾设想的方式解读——例如把流利度分数当作能力的度量。

这份清单的意义在缓解上：针对一个来源的修补（重新加权数据）对另一个来源（错配的部署）毫无作用。

::: warning "删掉受保护属性"并不能消除偏见
从数据集中删去性别或族裔一列——或者从简历里删去"她"这个词——很少能让模型对这个属性失明。其他特征与受保护属性相关：姓名、邮编、学校、爱好、方言、写作风格。语言模型又尤其擅长从文本中推断这类属性。于是模型完全可以在从没见过该属性的情况下，通过代理实现歧视。而且，删去属性会让人无法*度量*差距——度量需要知道群体归属。在技术文献中，"不知情即公平"一般被认为是不够的（Dwork 等，2012；Barocas、Hardt 与 Narayanan，2023），尽管各法律制度对决策者能否使用某属性来纠正差距的规定并不相同。
:::

## 度量语言模型中的偏见 {#sec-measuring}

### 嵌入上的关联测试 {#sec-weat}

NLP 中最早对社会偏见做定量研究的工作是在词嵌入（[[text-and-language/word-embeddings]]）上进行的。Caliskan、Bryson 与 Narayanan（2017）把心理学中的内隐联想测试（Implicit Association Test，IAT）改造成了适用于嵌入的形式。

::: definition 词嵌入关联测试（Word Embedding Association Test，WEAT） {#def-weat}
设$X$、$Y$是两个大小相同的**目标**词集（例如事业词与家庭词），$A$、$B$是两个**属性**词集（例如男性名与女性名）。对带有嵌入$\mathbf{w}$的词$w$，令

$$
s(w, A, B) = \frac{1}{\lvert A\rvert}\sum_{a\in A}\cos(\mathbf{w}, \mathbf{a}) - \frac{1}{\lvert B\rvert}\sum_{b\in B}\cos(\mathbf{w}, \mathbf{b}),
$$

称它为$w$关于$A$对$B$的差联想。**检验统计量**为$S(X, Y, A, B) = \sum_{x\in X}s(x, A, B) - \sum_{y\in Y}s(y, A, B)$，**效应量**为

$$
d = \frac{\operatorname{mean}_{x\in X}s(x, A, B) - \operatorname{mean}_{y\in Y}s(y, A, B)}{\operatorname{std}_{w\in X\cup Y}s(w, A, B)},
$$

其中用样本标准差。显著性由**置换检验**评估：单侧$p$值是使$S(X_i, Y_i, A, B) \ge S(X, Y, A, B)$成立、把$X\cup Y$重新划分成两个等大集合$(X_i, Y_i)$的比例。
:::

效应量具有 Cohen 的$d$的形式：接近$0$表示没有差联想，超过约$0.8$依惯例算"大"。Caliskan 等人在网页文本训练的 GloVe 向量中复现了人类 IAT 研究记录到的许多联想，效应量很大——例如男性名与女性名对事业词与家庭词的联想。他们还发现，嵌入中职业词的联想与美国劳动统计中这些职业的女性占比强相关：嵌入既编码了对世界的刻板印象，也编码了对世界的描述。

::: example 手工计算一个 WEAT 效应量 {#ex-weat}
两个目标词$x_1, x_2 \in X$与两个$y_1, y_2\in Y$的差联想为$s(x_1) = 0.10$、$s(x_2) = 0.06$、$s(y_1) = -0.02$、$s(y_2) = -0.06$。计算检验统计量、效应量与置换$p$值。
::: solution
$S = (0.10 + 0.06) - (-0.02 - 0.06) = 0.24$。两组均值分别为$0.08$与$-0.04$，相差$0.12$。四个值的均值为$0.02$，偏差为$0.08, 0.04, -0.04, -0.08$，故样本方差为$(0.0064 + 0.0016 + 0.0016 + 0.0064)/3 = 0.00533$，标准差为$0.0730$。于是$d = 0.12/0.0730 = 1.64$，是一个大效应。

把四个词分成两两一组共有$\binom{4}{2} = 6$种分法；各分法的统计量为$0.24, 0.08, 0, 0, -0.08, -0.24$。只有观察到的分法达到$0.24$，所以$p = 1/6 \approx 0.17$。大的效应量配不显著的$p$值：词太少，任何置换检验都无从说服力。真实的 WEAT 检验每集用八个或更多词，而结果对选哪些词很敏感（Ethayarajh、Duvenaud 与 Hirst，2019）。
:::
:::

May 等（2019）把词插入模板句子的办法把该检验推广到句子编码器（SEAT），发现的效应更弱、也更不一致——这是最早的迹象之一：为静态嵌入设计的关联测试迁移到语境模型上表现很差。另一个更根本的担忧是**效度**：嵌入空间中的联想未必能预测任何下游的伤害行为。Goldfarb-Tarrant 等（2021）发现，嵌入偏见的内在度量与下游应用中的偏见之间几乎没有相关性。

### 生成模型的基准 {#sec-benchmarks}

对生成文本的模型，偏见要在行为上测量。

- **StereoSet**（Nadeem、Bethke 与 Reddy，2021）在性别、职业、种族与宗教等类别上给出一个语境和三个续写——刻板、反刻板、无关。**刻板印象分数**是模型对刻板续写的偏好高于反刻板续写的题目比例（$50$最理想）；**语言建模分数**是对有语义的续写的偏好高于无关续写的比例；**ICAT** 分数把两者结合为$\text{lms}\cdot\min(\text{ss}, 100 - \text{ss})/50$。
- **CrowS-Pairs**（Nangia 等，2020）比较模型对最小差异句对的似然，其中一个比另一个更刻板。
- **BBQ**——问答偏见基准（Bias Benchmark for Question Answering）（Parrish 等，2022）在两种语境下提问。在**歧义**语境中，作答所需的信息是缺失的，因此正确答案是"无法确定"；模型若转而答出被刻板化的群体，就暴露了它对该刻板印象的依赖。在**消除歧义**的语境中答案已经写明，要问的是模型会不会仍用刻板印象把它覆盖掉。

::: definition BBQ 偏见分数 {#def-bbq}
在某一类语境的题目集合中，设$n_{\text{biased}}$为选定了与刻板印象一致目标的作答数，$n_{\text{non-unk}}$为不是"无法确定"的作答数。**消除歧义**语境中的偏见分数为

$$
s_{\text{DIS}} = 2\,\frac{n_{\text{biased}}}{n_{\text{non-unk}}} - 1,
$$

其取值从$-1$（一切非"无法确定"的作答都反刻板）经过$0$到$1$。在**歧义**语境中，同一比值再乘以错误率：$s_{\text{AMB}} = (1 - \text{准确率})\,\bigl(2\,n_{\text{biased}}/n_{\text{non-unk}} - 1\bigr)$，因此每次都能正确回答"无法确定"的模型得$0$分。
:::

::: example 给 BBQ 作答计分 {#ex-bbq}
在$1000$道歧义题上，一个模型有$800$次回答"无法确定"（正确）；其余$200$次作答里，$150$次答的是被刻板化的群体。计算$s_{\text{AMB}}$。
::: solution
准确率为$0.8$。在非"无法确定"的作答中，刻板作答占$150/200 = 0.75$，故$2(0.75) - 1 = 0.5$。于是$s_{\text{AMB}} = (1 - 0.8)(0.5) = 0.10$。这种缩放意味着模型既可以通过更多地回答"无法确定"来降低分数，也可以通过把错误均匀分布来降低分数；两个组成部分应当分开报告。
:::
:::

Parrish 等发现，他们测试的模型（截至 2022 年）在歧义语境中依赖刻板印象；而在消除歧义的语境中，当正确答案与刻板印象一致时的准确率，高于与刻板印象冲突时。模型开发者如今普遍在模型文档中报告 BBQ 结果；但与一切基准一样，这些数字描述的只是特定的模型版本，而且一个基准一旦人尽皆知、并可能进入训练数据，其信息量就会下降。

### 反事实审计与隐性偏见 {#sec-audits}

第三种做法是在其余部分固定的提示中改变一个属性——姓名、代词或方言——再比较输出，正如经济学中的审计研究长期用简历所做的那样。这类研究报告了 LLM 写的推荐信存在性别差异（Wan 等，2023），以及按与不同群体相关联的姓名对简历排序时的差异；结果随模型、提示与任务而变，有些研究发现效应很小或前后不一致。Hofmann、Kalluri、Jurafsky 与 King（2024，*Nature*）的一项研究尤其引人注意：他们比较了用非裔美国英语写成的文本与同样内容、改用标准美国英语写成的文本。模型被直接问及时对非裔美国人的描述大体是正面的，然而它们仍把这种方言的使用者与负面形容词联系起来，并在假想决策任务中把他们与地位较低的职业联系起来。作者称之为**隐性**（covert）偏见，并报告偏好优化削减外显刻板印象多于隐性刻板印象。

::: warning 偏见基准分数不是公平性的保证
基准测量的是模板化或众包编写题目上的狭窄行为，多为美式英语，且只覆盖一份固定的类别清单。Blodgett 等（2021）审计了四个这样的基准，发现大量题目要么有歧义、要么并没有表达刻板印象、要么测的不是其所声称的东西。低分数只说明*所测的那种*行为不存在，并不说明部署中没有伤害——那必须放到部署自身的语言、人群与任务中去评估。
:::

## 决策的公平性准则 {#sec-criteria}

当模型输出进入决策——批准或拒绝、标记或放行——时，我们可以使用分类的语言（[[ml-fundamentals/evaluation-metrics#def-confusion]]）。设$Y\in\{0,1\}$为真实结果，$R\in[0,1]$为系统给出的得分（也许是语言模型认为"合格"的概率），$\hat Y = \mathbf 1[R \ge t]$为决策，$G$为群体。多数群体公平性准则可归入三大家族（Barocas、Hardt 与 Narayanan，2023）。

::: definition 群体公平性准则 {#def-criteria}
- **独立性（人口均等，demographic parity）。**$\hat Y$独立于$G$：$\Prob(\hat Y = 1\mid G = g)$对每个群体都相同。
- **分离性（separation，均等化赔率；Hardt、Price 与 Srebro，2016）。**给定$Y$时$\hat Y$独立于$G$：真阳性率与假阳性率在群体之间相等。只要求真阳性率相等称为**机会平等**（equal opportunity）。
- **充分性（sufficiency）。**给定得分时$Y$独立于$G$。对得分而言，这就是**组内校准**：对一切$r$与$g$有$\Prob(Y = 1\mid R = r, G = g) = r$。对二元决策而言，这就是**预测均等**（predictive parity）：阳性预测值$\Prob(Y = 1\mid\hat Y = 1, G = g)$在群体之间相等。
:::

每个准则都有支持它的自然理由。人口均等说决策根本不应依赖于群体——在人们认为结果标签本身就反映着过去的歧视的地方，这种观点很有吸引力。分离性说真实结果相同的人，无论属于哪个群体，都应有相同的出错机会。充分性说得分为每个人意味着同样的东西：$0.7$的风险就应当是$0.7$的风险，无论这个人属于哪个群体，这样决策者才能按面值对待它。

::: example 一张表上的三个准则 {#ex-criteria}
一个筛选模型标记申请人以安排面试。A 组有$1000$名申请人，其中$500$人合格；模型标记$500$人，其中$400$人合格。B 组有$1000$名申请人，其中$200$人合格；模型标记$200$人，其中$160$人合格。哪些准则成立？
::: solution
标记率：A 组$500/1000 = 0.5$，B 组$200/1000 = 0.2$——人口均等不成立。阳性预测值（PPV）：A 组$400/500 = 0.8$，B 组$160/200 = 0.8$——预测均等成立。真阳性率：A 组$400/500 = 0.8$，B 组$160/200 = 0.8$——机会平等成立。假阳性率：A 组的$500$名不合格者中有$100$人被误标，即$0.2$；B 组的$800$名不合格者中有$40$人，即$0.05$——均等化赔率不成立。基率较低的群体在这里得到了较低的假阳性率；下一节将说明这是被强迫的。
:::
:::

## 无法同时成立 {#sec-impossibility}

2016 年，新闻机构 ProPublica 分析了美国刑事法院使用的商业风险评估工具 COMPAS，报告称：没有再犯的黑人被告被打上高风险标签的比率，几乎是白人被告的两倍——假阳性率不相等（Angwin 等，2016）。该工具的开发方则回应说，它的得分对两个群体的预测能力是相同的——被打上高风险标签的被告，无论种族，再犯率都差不多。两种说法大体都得到数据支持。几个月之内，两项独立的分析说明了为什么两者不可能被同时"纠正"。

::: proposition 错误率被流行率绑定（Chouldechova，2017） {#prop-chouldechova}
对发生于率（prevalence）$p = \Prob(Y = 1)\in(0, 1)$的群体上的二元分类器，若阳性预测值$\text{PPV} > 0$、假阴性率$\text{FNR}$、假阳性率$\text{FPR}$，则

$$
\text{FPR} = \frac{p}{1 - p}\cdot\frac{1 - \text{PPV}}{\text{PPV}}\cdot(1 - \text{FNR}).
$$ {#eq-chouldechova}

因此，若两个群体的 PPV 相等、FNR 相等而流行率不同，它们的 FPR 就必然不同。
:::

::: proof
取一个规模为$n$的群体，把四个计数记作$TP, FP, FN, TN$。则$TP + FN = pn$且$FP + TN = (1 - p)n$。由定义$1 - \text{FNR} = TP/(pn)$，所以$TP = pn(1 - \text{FNR})$。由$\text{PPV} = TP/(TP + FP)$得$FP = TP(1 - \text{PPV})/\text{PPV}$。于是

$$
\text{FPR} = \frac{FP}{(1 - p)n} = \frac{pn(1 - \text{FNR})}{(1 - p)n}\cdot\frac{1 - \text{PPV}}{\text{PPV}},
$$

这正是[[#eq-chouldechova]]。若 PPV 与 FNR 固定，则右边（设$\text{PPV} < 1$且$\text{FNR} < 1$）是$p$的严格增函数（因为$p/(1-p)$严格递增），所以流行率不同的群体必有不同的 FPR。
:::

在[[#ex-criteria]]中，$p = 0.5$与$0.2$，PPV $= 0.8$，FNR $= 0.2$：公式给出$1\cdot0.25\cdot0.8 = 0.2$与$0.25\cdot0.25\cdot0.8 = 0.05$，与手工计数一致。

:::

Kleinberg、Mullainathan 与 Raghavan（2016）对得分（而非阈值化决策）证明了一个版本，使用的工具是校准，以及两个把"错误率相等"推广开的"平衡"条件。

::: definition 正类平衡与负类平衡 {#def-balance}
若$Y = 1$者的平均得分$\E[R\mid Y = 1, G = g]$对每个群体都相同，则称得分$R$**对正类平衡**；若$\E[R\mid Y = 0, G = g]$对每个群体都相同，则称其**对负类平衡**。
:::

::: theorem 校准与平衡不相容（Kleinberg、Mullainathan 与 Raghavan，2016） {#thm-kmr}
设一个得分在两个群体内都是校准的，并且对正类和负类都平衡。则要么两个群体的流行率相同，要么该得分是完美的：一切阳性都有$R = 1$，一切阴性都有$R = 0$。
:::

::: proof
固定一个流行率为$p_g$的群体$g$，令$x = \E[R\mid Y = 0, G = g]$、$y = \E[R\mid Y = 1, G = g]$；由平衡性，$x$与$y$对两个群体相同。校准给出$\E[Y\mid R, G = g] = R$，两边取期望即得$\E[R\mid G = g] = \E[Y\mid G = g] = p_g$：平均得分等于流行率。把平均得分按结果拆开，

$$
(1 - p_g)\,x + p_g\,y = p_g \qquad \text{当 } g = 1, 2.
$$

两式相减得$(p_2 - p_1)(y - x) = p_2 - p_1$。若$p_1 \ne p_2$，则$y - x = 1$；由$0\le x\le y\le1$，这迫使$x = 0$且$y = 1$。在$[0, 1]$中取值、在阴性上均值为$0$的得分在阴性上几乎必然为$0$，在阳性上均值为$1$的得分在阳性上几乎必然为$1$：该得分是完美的。否则$p_1 = p_2$。
:::

Kleinberg 等人还给出了一个近似版本：若各条件近似成立，则基率近似相等，或预测近似完美。Chouldechova 的结果是其阈值化版本：PPV 相等（校准的二元形式）与 FNR 相等会强制 FPR 不相等。

### 这个结果说了什么、没说什么 {#sec-interpreting}

这一定理是关于任何预测器——无论出自人还是机器——的数学事实，并且它对一场实证争论作出了裁断：COMPAS 案中双方就数字而言可以都是对的，因为他们各自在意的条件在基率不同的情况下根本不可能同时成立。但它没有裁定应当偏爱哪个准则；这一问题此后仍然悬而未决，主要立场如下。

- **支持校准（充分性）。**校准的得分对每个人意味着同样的东西，于是决策者可以适用单一阈值，对相同的风险一视同仁。Corbett-Davies 等（2017）证明：对一个固定的、不带约束的目标，最优决策规则对校准的风险得分适用单一阈值；而要强制错误率相等，就需要群体专属的阈值，对估计风险相同的两个人区别对待——这本身可能被视为歧视，在某些情形下还可能违法。
- **支持错误率平衡（分离性）。**错误的负担落在具体的个人身上：一个本不会再犯的人若被拘押，就承受了假阳性的全部代价。按这种观点，一个群体若承受两倍的假阳性率就受到了亏待，无论得分的平均含义如何。论者还指出：观察到的基率本身可能反映着有偏的测量（例如用逮捕而非犯罪），此时对观察标签做校准会把这种偏见继承下来。
- **支持质疑任务本身。**也有人主张，当各准则互相冲突时，正确的回应可能是改变决策本身——降低一次假阳性的利害、收集更好的标签，或干脆不把决策自动化——而不是在度量中挑一个（Barocas、Hardt 与 Narayanan，2023，第 2–3 章讨论了这一观点）。

这些立场建立在不同的伦理前提上；数学所表明的只是：一旦基率不同、预测又不完美，选择就不可避免。

::: example 校准强制错误率不相等 {#ex-calibrated}
在 A 组，一个校准的得分对$600$人取值$0.8$、对$400$人取值$0.2$；在 B 组，对$200$人取值$0.8$、对$800$人取值$0.2$。决策把得分$0.8$的人全部标记。计算每组的流行率、PPV、FPR 与 FNR。
::: solution
校准意味着得分$0.8$的人中有$80\%$、得分$0.2$的人中有$20\%$满足$Y = 1$。

A 组：阳性$0.8\cdot600 + 0.2\cdot400 = 480 + 80 = 560$，流行率$0.56$。被标记$600$人，其中$480$人为阳性：PPV $0.8$。FNR $= 80/560 = 0.143$。阴性$440$人，其中$120$人被标记：FPR $= 120/440 = 0.273$。

B 组：阳性$0.8\cdot200 + 0.2\cdot800 = 160 + 160 = 320$，流行率$0.32$。PPV $= 160/200 = 0.8$。FNR $= 160/320 = 0.5$。阴性$680$人，其中$40$人被标记：FPR $= 40/680 = 0.059$。

同一个校准得分与同一个阈值，使 A 组的假阳性率约为 B 组的五倍，使 B 组的假阴性率约为 A 组的三点五倍。用[[#eq-chouldechova]]检验 A 组：$(0.56/0.44)(0.25)(0.857) = 0.273$。
:::
:::

### 一个模拟 {#sec-code}

下面的清单为基率不同的两个群体生成校准的得分，并对单一阈值作评估。只使用标准库。

```python
import random
rng = random.Random(2016)

def make_group(n, alpha, beta):
    """Scores s ~ Beta(alpha, beta); outcome y ~ Bernoulli(s), so the score is calibrated."""
    data = []
    for _ in range(n):
        s = rng.betavariate(alpha, beta)
        data.append((s, rng.random() < s))
    return data

groups = {"A": make_group(20000, 3, 2),    # 基率约 0.6
          "B": make_group(20000, 2, 3)}    # 基率约 0.4

def rates(data, t=0.5):
    tp = sum(1 for s, y in data if s >= t and y)
    fp = sum(1 for s, y in data if s >= t and not y)
    fn = sum(1 for s, y in data if s < t and y)
    tn = sum(1 for s, y in data if s < t and not y)
    return {"base rate": (tp + fn) / len(data), "flagged": (tp + fp) / len(data),
            "PPV": tp / (tp + fp), "FPR": fp / (fp + tn), "FNR": fn / (fn + tp)}

for g, data in groups.items():
    # 校准检查：得分落在 [0.6, 0.7) 内的人的平均结果
    sel = [y for s, y in data if 0.6 <= s < 0.7]
    r = rates(data)
    print(g, "  ".join(f"{k} {v:.3f}" for k, v in r.items()),
          f" P(y=1 | s in [0.6,0.7)) {sum(sel)/len(sel):.3f}")
```

```text
A base rate 0.603  flagged 0.689  PPV 0.713  FPR 0.499  FNR 0.187  P(y=1 | s in [0.6,0.7)) 0.645
B base rate 0.407  flagged 0.314  PPV 0.657  FPR 0.182  FNR 0.493  P(y=1 | s in [0.6,0.7)) 0.662
```

两个群体都是校准的（得分在$0.6$到$0.7$之间的人，实际结果比例在两组都约为$65\%$），然而 A 组的假阳性率为$0.50$，B 组为$0.18$，假阴性率则正好反过来。把 A 组的数字代入[[#eq-chouldechova]]得$(0.603/0.397)(0.287/0.713)(0.813) = 0.497$，与模拟得到的$0.499$在舍入误差内一致。为两个群体分别选取阈值可以拉平 FPR，代价是相同的得分被区别对待。

::: quiz
一家贷款机构的模型在两个违约率不同的群体内部都是校准的，且其预测并不完美。监管方要求该机构同时让假阳性率（有偿还能力的申请人被错误拒绝）与假阴性率在群体之间相等。由[[#thm-kmr]]能推出什么？
- [ ] 该机构可以用更多数据重新训练来满足这一要求。
- [x] 在两个群体内部都保持校准的同时，这一要求无法满足；必须放弃某个准则。
- [ ] 校准本身就蕴含错误率相等，因此该要求已经满足。
- [ ] 该定理只适用于刑事司法数据。
::: solution
在基率不等、预测不完美时，组内校准与对两类都平衡不可能同时成立，无论用什么数据、什么模型。该机构必须要么放弃校准（例如改用群体专属阈值），要么接受不相等的错误率，要么改变决策流程。这一定理适用于任何领域的任何预测器。
:::
:::

## 缓解手段及其局限 {#sec-mitigation}

缓解手段可以在流水线的各个环节起作用，各自针对一个特定的来源。

**数据。**对预训练与微调数据进行整理和再平衡，针对的是代表性偏见；把数据记录下来（数据说明书，Gebru 等，2021；数据声明，Bender 与 Friedman，2018）则让残留的缺口变得可见。**反事实数据增强**把训练句子中群体词互换（"he" ↔ "she"）后的副本加入训练集，让模型两个版本都见过（Lu 等，2020；Zmigrod 等，2019 面向形态丰富的语言做了这样的工作）。互换可能产生不合情理的文本，而且只覆盖列出的那些词。

**表示。**Bolukbasi 等（2016）把 word2vec 中诸如$\mathbf{he} - \mathbf{she}$这类差的主成分识别为"性别方向"，并把性别中立的词沿这一方向的分量投影掉。Gonen 与 Goldberg（2019）表明，经过这种"硬去偏"之后，原本带性别刻板印象的词仍然聚在一起，一个分类器能以高准确率恢复它们原来的性别联想：投影去掉的是偏见的一种测量，而不是那份信息。这个教训具有一般性——以指标为靶子的去偏，可能让底层信息完好无损。

**后训练。**指令微调与偏好优化（[[post-training/rlhf]]）可以教会模型拒绝刻板化的请求、在问题有歧义时回答"无法确定"、避免使用贬损性语言；已发表的模型报告显示，这样的训练之后偏见基准上的分数有所改善。上面的隐性偏见结果表明，这可以更多地压抑外显表达，而不是改变底层联想，而且削减集中在训练数据所针对的那些行为上。

**决策规则。**在分类场景下，可以通过后处理选择群体专属的阈值，实现均等化赔率（Hardt、Price 与 Srebro，2016）。由不可能性定理，这要牺牲校准。决策能否依赖群体成员身份，既是技术问题也是法律问题：许多司法辖区限制明确依赖群体的决策，而结果上的差距同样可能引发法律责任（美国的差别对待与差别影响两项法律原则是最著名的例子）。

**评测与治理。**分群体评测——按群体、乃至按群体的交叉分别报告表现——是最低要求。Buolamwini 与 Gebru（2018）发现，商业性别分类系统对浅肤色男性的错误率低于$1\%$，对深肤色女性却高达约$35\%$；这样的差距在汇总准确率中完全看不见，而且在两个属性的交叉处比任何单一属性都更大。模型卡（Mitchell 等，2019）让这类报告走向标准化。

::: warning 缓解可能只是把伤害挪了个地方，而不是消除它
从训练数据中移除"有毒"文本的过滤器，可能以更高比率移除方言或身份用词（见[[#sec-sources]]）；一个被训练得避免提及某群体的模型，可能对该群体自己的问题变得没那么有用；拉平一个错误率会让另一个错误率变得不平等（见[[#thm-kmr]]）。评估缓解手段，既要看它意图减少的伤害，*也要*看它对受影响群体的表现与呈现造成了什么。
:::

一些局限是结构性的，而非暂时的。基准主要覆盖英语和少数几个属性类别，因此对世界上大多数语言、对许多形式的不利处境（例如种姓，以及地域与阶级身份），测量几乎不存在（Ramesh 等，2023 讨论了西方语境之外的公平）。基于群体的准则需要群体标签，而标签可能不可得、敏感、或受法律保护。而且"公平"是相对于任务定义的：同一个模型，用来起草邮件也许足够好，用来筛选租户也许完全不够。Weidinger 等（2021；2022）把歧视、排斥与毒性放入一个更宽的风险分类体系，与语言模型的其他风险并列，并强调这些伤害的严重程度取决于应用。

::: application 审计一个基于大模型的筛选工具
一家机构想用语言模型来总结并给求职申请打分。一份严谨的审计应当：(1) 明确决策与伤害（被错误地筛除）；(2) 用真实的或逼真的、带有相关群体信息的申请构建测试集，并构造只改变姓名、代词与方言的反事实配对；(3) 按群体及群体交叉测量选中率、对照经效度检验的结果的错误率、以及得分的校准，各自附上置信区间（[[ml-fundamentals/evaluation-metrics#sec-uncertainty]]）；(4) 记录哪些准则成立、选择了哪个权衡、为何如此；(5) 模型每次更新后重新审计，因为版本之间行为会变。在一些司法辖区，自动化雇佣决策工具依法必须接受这样的审计——纽约市第 144 号地方法（Local Law 144）自 2023 年 7 月起执行，要求每年对选中率做独立偏见审计——欧盟《人工智能法》也把招聘中使用的 AI 列为高风险（[[llm-society/governance-regulation]]）。
:::

::: history
对自动化决策中偏见的担忧早于机器学习：Friedman 与 Nissenbaum（1996）把计算机系统中的偏见分为先前存在的、技术的与涌现的三类。形式化的公平准则自 2010 年前后开始发展——Dwork 等（2012）提出"知情即公平"（相似的个体应被相似地对待）——在 ProPublica 的 COMPAS 分析（2016）与 Kleinberg、Mullainathan 与 Raghavan（2016）及 Chouldechova（2017）的不可能性结果之后，该领域加速发展；Hardt、Price 与 Srebro（2016）在同一年提出了均等化赔率。在 NLP 中，Bolukbasi 等（2016）与 Caliskan、Bryson 与 Narayanan（2017，*Science*）表明词嵌入中存在刻板印象；面向生成与问答模型的基准接踵而至（StereoSet 与 CrowS-Pairs 在 2020–21 年，BBQ 在 2022 年）。Bender、Gebru、McMillan-Major 与 Mitchell（2021）论证，用未记录的网页数据训练的、越来越大的模型会编码霸权的观点；Weidinger 等（2021）把这些伤害放进了 LLM 风险的分类体系。Barocas、Hardt 与 Narayanan 的《Fairness and Machine Learning》（2023）是该领域的标准教材。
:::

::: summary
- 区分统计偏见、社会偏见与不公平；区分分配性伤害与表征性伤害，并说明是哪一类伤害、落到谁身上、为什么要紧。
- 偏见经由历史模式、不具代表性的数据与过滤、有偏的标签、聚合、评测缺口与错配的部署进入系统；删除受保护属性并不能去掉代理。
- WEAT 用效应量与置换检验测量嵌入中的差联想；StereoSet、CrowS-Pairs 与 BBQ 测量行为；反事实审计改变单一属性。它们的效度都有局限，基准分数不是保证。
- 群体准则分三族：独立性（人口均等）、分离性（均等化赔率）与充分性（校准、预测均等）。
- 基率不等且预测不完美时，组内校准与相等的错误率不可能同时成立（[[#prop-chouldechova]]、[[#thm-kmr]]）；偏爱哪个是价值观与法律上的选择，合理的立场各有不同。
- 缓解手段作用于数据、表示、后训练与决策规则；每种都有局限，有些只是转移伤害而非消除。要分群体、在部署的实际语言与任务中评估，并在模型更新后重新审计。
:::

## 习题

::: exercise 人口均等差 {level=1 check="0.15"}
模型批准了 A 组$45\%$的申请人、B 组$30\%$的申请人。人口均等差$\Prob(\hat Y = 1\mid A) - \Prob(\hat Y = 1\mid B)$是多少？答案保留两位小数。
::: solution
$0.45 - 0.30 = 0.15$。（比率$0.30/0.45 = 0.67$也常被报告；美国雇佣领域"五分之四规则"的经验法则，拿这个比率与$0.8$比较。）
:::
:::

::: exercise 直接读出错误率 {level=1 check="0.1"}
某群体共$500$人，其中$100$人$Y = 1$。分类器标记$120$人，其中$80$人$Y = 1$。计算假阳性率（精确值）。
::: solution
假阳性：$120 - 80 = 40$。阴性：$500 - 100 = 400$。FPR $= 40/400 = 0.1$。（另有 FNR $= 20/100 = 0.2$，PPV $= 80/120 = 2/3$。）
:::
:::

::: exercise Chouldechova 恒等式算数 {level=1 check="0.229"}
某群体流行率为$0.4$；分类器在其上 PPV $0.7$、FNR $0.2$。用[[#eq-chouldechova]]求它的 FPR，保留三位小数。
::: solution
$\text{FPR} = (0.4/0.6)\cdot(0.3/0.7)\cdot0.8 = 0.6667\cdot0.4286\cdot0.8 = 0.229$。
:::
:::

::: exercise 一个 BBQ 分数 {level=2 check="0.06"}
在歧义的 BBQ 问题上，某模型的准确率为$0.4$（即回答"无法确定"的比例）。在它非"无法确定"的作答中，$55\%$选择了刻板印象目标。计算$s_{\text{AMB}}$，保留两位小数，并与一个作答结构相同、但准确率为$0.7$的模型比较。
::: solution
$2(0.55) - 1 = 0.1$，$1 - 0.4 = 0.6$，故$s_{\text{AMB}} = 0.6\cdot0.1 = 0.06$。若准确率为$0.7$，分数将是$0.3\cdot0.1 = 0.03$：同样的刻板倾向，模型猜得越多，分数反而越大。
:::
:::

::: exercise 每边三个词的 WEAT {level=2 check="0.05"}
目标集$X = \{x_1, x_2, x_3\}$、$Y = \{y_1, y_2, y_3\}$的差联想分别为$0.09, 0.05, 0.04$与$0.03, -0.01, -0.02$。观察到的划分在全部$\binom63 = 20$种划分中检验统计量最大。单侧置换$p$值是多少？保留两位小数。
::: solution
只有观察到的划分（把三个最大值放进$X$的那个）能达到最大值，故$p = 1/20 = 0.05$。每集只有三个词时，$0.05$已是置换检验能给出的最小$p$值；Caliskan 等人使用的词集更大，原因正在于此。
:::
:::

::: exercise 哪个准则？ {level=2}
对下面每种说法，指出它所对应的准则家族（独立性、分离性、充分性），并说出强制实施它的一个代价。(a) "本会还款的女性比本会还款的男性更常被拒绝贷款。"(b) "$30\%$的风险得分，对每个申请人都应当意味着$30\%$的违约概率。"(c) "每个群体获得面试的比例，应当与该群体申请人的比例一致。"
::: solution
(a) 分离性——确切说，是拒绝贷款的假阳性率不相等（有偿还能力者的机会平等）。在基率不等时强制实施，要牺牲校准，而且通常需要群体专属的阈值。(b) 充分性（组内校准）。在基率不等时强制实施，会强制错误率不相等（[[#thm-kmr]]）。(c) 独立性（人口均等）。若合格率确实不同，它要么迫使采用不同的阈值，要么在一个群体接受资质较浅的申请人、同时在另一个群体拒绝资质较好的申请人；若测得的合格与否本身有偏，论者会说它纠正了这种偏见。
:::
:::

::: exercise 三个得分值的校准 {level=2 check="0.15"}
一个校准的得分取$0.9$、$0.5$与$0.1$三个值。B 组分别有$100$、$200$与$700$人得到这三个得分。决策把得分不低于$0.5$的人标记。计算 B 组的假阳性率，保留两位小数。
::: solution
阴性：$0.1\cdot100 + 0.5\cdot200 + 0.9\cdot700 = 10 + 100 + 630 = 740$。被标记的阴性：$10 + 100 = 110$。FPR $= 110/740 = 0.149 \approx 0.15$。（阳性：$90 + 100 + 70 = 260$，流行率$0.26$；被标记的阳性$190$，FNR $= 70/260 = 0.27$。）
:::
:::

::: exercise 放弃一个条件会怎样 {level=3}
举例说明：若放弃*校准*，得分可以在基率不同的两个群体上对两类都平衡，而并非完美。再说明：若放弃*对负类平衡*，一个校准的得分可以在流行率不同的情况下对正类平衡。
::: solution
(1) 让两个群体里一切阳性都有$R = 0.7$、一切阴性都有$R = 0.3$，流行率分别为$0.6$与$0.3$。平衡成立（两组的$x = 0.3$、$y = 0.7$）。校准失败：A 组平均得分$0.4\cdot0.3 + 0.6\cdot0.7 = 0.54 \ne 0.6$。

(2) 在[[#thm-kmr]]的证明中，只有对正类平衡的条件把$y$在群体间固定住，$x_g$则可以不同。设两个群体的校准得分都只取$0$与$s$两个值：比例$q_g$的人得$s$，他们中比例$s$为阳性；其余的人得$0$且全是阴性。所有阳性的得分都是$s$，故两组$y = s$（对正类平衡），且得分是校准的。流行率为$p_g = q_g s$，当$q_A \ne q_B$时两组不同。例如$s = 0.8$、$q_A = 0.75$、$q_B = 0.25$给出流行率$0.6$与$0.2$。阴性的平均分为$x_g = q_g s(1 - s)/(1 - p_g)$：$0.75\cdot0.8\cdot0.2/0.4 = 0.3$与$0.25\cdot0.8\cdot0.2/0.8 = 0.05$——不平衡，正如定理所要求。
:::
:::

::: exercise 群体专属阈值 {level=3}
用[[#sec-code]]中的清单，为 B 组找出（以$0.01$为步长、保持$t_A = 0.5$）假阳性率与 A 组最接近的阈值$t_B$。报告$t_B$以及此时 B 组的 PPV 与 FNR，并用两句话解释交换了什么。
::: solution
加上一段在阈值上搜索的代码：

```python
best = min((abs(rates(groups["B"], t / 100)["FPR"] - rates(groups["A"])["FPR"]), t / 100)
           for t in range(5, 96))
tB = best[1]
print(tB, {k: round(v, 3) for k, v in rates(groups["B"], tB).items()})
```

```text
0.31 {'base rate': 0.407, 'flagged': 0.635, 'PPV': 0.53, 'FPR': 0.503, 'FNR': 0.173}
```

B 组取阈值$0.31$，得到 FPR $0.503$，与 A 组的$0.499$相当。（搜索从$0.05$起，以免出现某个阈值谁都不标或全都标、导致某个率没有定义的情形。）B 组的 FNR 降到$0.17$（接近 A 组的$0.19$），但其 PPV 降到$0.53$，低于 A 组的$0.713$：在 B 组，被标记如今意味着得更少，而两个得分同为$0.4$的人因所属群体不同而被区别对待。均等化赔率是用预测均等和依群体而定的对待换来的。
:::

::: exercise 设计一项偏见评估 {level=3}
你受命评估一个在印度部署的多语种聊天助手是否按宗教与种姓进行刻板化。现有基准大多以英语和美国为中心。拟定一份评估方案：测量什么、如何构造测试题目、如何检验题目、如何报告结果。
::: solution
一份好的答案应包括：(1) 对伤害的陈述（表征性的：刻板化与贬损性内容；若助手被用于决策，则还有分配性的）；(2) 与来自受影响社区的人和本地专家磋商，找出相关的刻板印象、用语与人名——翻译过来的美国基准恰恰会漏掉它们；(3) 多种类的测试题目——按本地刻板印象改编的 BBQ 式歧义/消除歧义问题、改变姓名与社群标记的反事实提示、以及按刻板程度打分的开放式生成——覆盖每一种部署语言，包括语码混合文本；(4) 请来自不同社区的多个标注者检验题目，报告一致性统计量，剔除有歧义的题目（这正是 Blodgett 等，2021 批评的要点）；(5) 按语言、按群体报告指标，附置信区间，并给出"无法确定"作答的基线比例；(6) 说明局限（覆盖面、标注者自身的立场、对提示的敏感性），并给出模型更新后重跑的方案。NLP 中关于种姓偏见的工作存在但有限（截至 2026 年），很可能需要新造题目。
:::
