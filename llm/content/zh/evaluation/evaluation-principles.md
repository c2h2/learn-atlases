关于语言模型的每一个论断，都是一个关于评测的论断。"模型 A 比模型 B 更擅长数学"、"新的训练配方改进了编程能力"、"这个模型可以安全地部署到客服场景"——每一个都倚赖某个把模型变成数字的过程，也就只有那个过程那么好。评测通用语言模型比评测 [[ml-fundamentals/evaluation-metrics]] 里的分类器更难。它们的输出是自由文本，因此判断一个答案对不对本身就是一个问题。它们的行为取决于问题是怎么问的，所以同一个模型在两个都合理的提示之下可能得分相差很远。它们的训练数据庞大而且在很大程度上不为人知，所以一道测试题很可能早就被见过。而且它们被用于没有任何固定测试集能够覆盖的开放式任务。

本章给出的是课程其余部分要运用的原则。它精确定义了评测——一个题目总体、一个协议、一个计分规则和一个聚合——使人们能够说出一个数字究竟在估计什么。它引入**构念效度**——这个数字是否在度量它被声称度量的东西——以及**信度**——重测一次是否还会得到同样的结果。它拆解了**评测流水线**（提示格式、少样本示例、解码、答案抽取、计分），并用代码展示每个环节能把分数移动多少。它解释了**古德哈特定律**（Goodhart's law），并推导出它的机制之一：在含噪分数上做选择所带来的胜者诅咒。最后以**预期用途**收尾：评测的存在是为了支持某个决定，应当从该决定倒过来设计。

## 什么是评测 {#sec-what}

一个"$71.3\%$ 的数学基准得分"这样的评测结果，把许多选择压缩进了一个数字。把这些选择摆到明面上，是正确解读它的第一步。

::: definition 评测 {#def-evaluation}
模型 $M$ 的一次**评测**由以下几部分组成

1. 一个**题目总体** $\mathcal{D}$：题目 $x$（问题、指令、文档、环境）上的一个分布，评测所代表的就应当是这些题目；
2. 一个**协议** $\pi$，把模型与题目变成一个输出 $y = \pi(M, x)$——提示模板、少样本示例、系统提示、解码设置、允许使用的工具与重试次数；
3. 一个**计分规则** $s(x, y)\in[0, 1]$（或 $\R$）——与参考答案精确匹配、单元测试通过、人类或模型的评判；
4. 一个**聚合量**，通常取平均。评测所瞄准的那个量，即**被估计对象**，是

$$
\mu(M) = \E_{x\sim\mathcal{D}}\big[s\big(x, \pi(M, x)\big)\big],
$$ {#eq-estimand}

而从 $\mathcal{D}$ 抽出 $n$ 道题 $x_1, \dots, x_n$ 的基准给出**估计** $\hat\mu(M) = \frac1n\sum_{i=1}^n s(x_i, \pi(M, x_i))$。
:::

由此立刻得出三点。第一，$\mu(M)$ 是模型**连同**协议与计分规则一起的性质，而不只是模型本身的性质：改变 $\pi$ 或 $s$，被估计对象随之改变。只有把它们全部报告出来，分数才是可复现的。第二，$\hat\mu$ 是 $\mu$ 的一个带抽样误差的估计，因为基准只是题目的一次抽样——这是 [[evaluation/evaluation-statistics]] 的主题。第三，若协议会采样（温度高于零），则 $s(x, \pi(M, x))$ 本身是随机的，模型自己的随机性带来第二层噪声。

这个定义还把两个常被混淆的问题分开。**$\hat\mu$ 是 $\mu$ 的一个好估计吗？**是一个关于样本量、独立性与噪声的统计问题。**$\mu$ 是我们真正关心的东西吗？**是一个效度问题，再多的数据也回答不了它。

### 效度与信度 {#sec-validity}

心理学中的测量理论在一个世纪前就面对过同样的问题：智力测验或人格问卷度量的是无法直接观察的抽象性质——一个**构念**。Cronbach 与 Meehl（1955）把"一个测验是否在度量它的构念"这一问题称为**构念效度**，他们及其后继者发展出的这套词汇可以直接搬到语言模型上。

::: definition 构念效度与信度 {#def-validity}
**构念**是一次评测声称要度量的能力或性质（"数学推理"、"医学知识"、"诚实"）。就一个评测分数的差异反映的是构念的差异、而非别的东西的差异而言，该评测具有**构念效度**。常见的几个侧面：

- **内容效度**：题目对构念的覆盖具有代表性（所指的数学的各个种类、按预期的难度），而不是它某个方便的小角落；
- **效标（预测）效度**：分数能预测构念本应导致的某种外部结果——实际使用中的表现、专家评分、后续任务上的成败；
- **收敛效度与区分效度**：分数与同一构念的其他度量相关，而**不**与不同构念的度量相关（一个推理分数若更多追随答案长度而非对错，便不满足这一点）。

就重复评测——换一批题目、换一次运行、或换一个同样合理的提示——能给出同样结果而言，该评测是有**信度**的。信度是效度的必要条件而非充分条件：一台永远偏高 $3$ 千克的秤完美可靠，却错得离谱。
:::

语言模型基准以几种特有的方式危害构念效度。一个"推理"选择题基准可能靠选项中的表面线索就能解。测试太弱的编程基准奖励通过测试的代码，而非正确的代码。题目从网上搜集而来的基准，度量的可能是对这些题目的**记忆化**（[[evaluation/contamination]]）。一个基于拒答的"安全"分数，奖励的是一问就拒的模型。Raji 等（2021）论证说，被当作**一般**能力的度量呈现的基准——"把整个世界所有事情都测一遍的基准"——对如此宽泛的构念不可能有构念效度，因为没有任何有限题目集合能对它有代表性；基准度量的只是它所含的那些具体任务，超出它们的论断需要另外的证据。

::: example 从构念效度角度解读一个论断 {#ex-validity}
一份报告称模型"具备专家级的医学知识"，因为它在一组取自执业医师资格考试的选择题基准上得分 $90\%$。列出证据与论断之间的缺口。
::: solution
**内容**：资格考试用字母选项的格式考查记忆与教科书式推理；专家实践则包括在一场对话中收集信息、处理含混、知道何时转诊——这些题目一概不覆盖。**形式**：从四个给定选项中挑一个比直接给出诊断容易，单凭排除选项也能得逞，无需完整的知识。**效标**：报告没有给出任何证据表明该分数能预测临床医生会作判断的东西，比如对真实患者问题的回答质量。**污染**：考题及其题解在网上流传，所以分数的一部分可能就是对题目本身的回忆。**比较**："专家级"意味着一个人类参照；考试的及格线不是专家的表现，而人与模型在不同条件下做同样的题目也不可直接比较。站得住脚的论断要窄得多："在这些题目上、在这个协议之下得 $90\%$"。
:::
:::

## 评测流水线 {#sec-pipeline}

协议 $\pi$ 与计分规则 $s$ 掩盖着一连串工程选择。对一个典型的问答基准，它们是：

::: algorithm 评测流水线 {#alg-pipeline}
1. **选题**：划分（测试集或验证集）、任何过滤、题目数量 $n$。
2. **组装提示**：包裹题目的模板（"Question: … Answer:"）、选项的呈现方式（字母、括号、顺序）、指令微调模型所用的系统提示与聊天模板，以及 $k$ 个**少样本**已解示例——选哪些、按什么顺序。
3. **生成**：要么按对数似然给固定候选打分（对基座模型，[[pretraining/in-training-evaluation]]），要么生成文本，配以解码规则（贪心，或温度 $T$ 与核 $p$）、最大长度与停止序列（[[inference/decoding-sampling]]）。对推理模型，还有推理词元的预算。
4. **抽取答案**：解析输出——第一个字母、最后一个数字、标记字段（如 "The answer is …"）的内容、或待执行的代码。
5. **计分**：在**归一化**（大小写、空白、标点、数字格式、等价的数学表达式）之后与参考答案比较，或运行测试，或请评审裁断。
6. **聚合**：对题目取平均，可按学科加权；解码随机时跨样本重复（pass@$k$，[[reasoning/self-consistency]]）。
:::

每一步都可能改变那个数字。大模型早期时代最令人吃惊的一课，就是它们能改变多少。

- **格式。** Sclar 等（2023）只改变少样本提示中保持语义的特征——分隔符、空格、字段名的大小写——就发现同一个开源模型在同一任务上、不同格式之间的准确率差距最大达 $76$ 个百分点，且模型排名随格式而变。他们的建议是报告性能在一批合理格式上的散布，而不是单个数字。
- **少样本示例。** Lu 等（2022）表明，同一批少样本示例的**顺序**就能把中小模型在某些分类任务上从接近最先进水平挪到接近随机。Zhao 等（2021）把其中一部分归因于模型偏向示例中出现次数最多、或位置最靠后的标签。
- **选项呈现。** Alzahrani 等（2024）发现，对选择题基准的小改动——打乱选项顺序，或更换标记选项所用的符号——会改变排行榜上模型的排名。
- **实现。** 2023 年 6 月，Hugging Face 上一个公开开源模型排行榜的维护者报告，MMLU 的三个广泛使用的实现——原作者的代码、HELM 框架与 EleutherAI 评测工具包——对同一批模型给出明显不同的分数，因为它们在提示措辞、模型的选取是读字母的概率还是答案文本的概率、以及归一化上各不相同。三种实现之下模型的排名并不相同。

实际结论是：分数只有连同它的流水线一起才有意义。由不同流水线产出的数字之间的比较——把开发商报告里自家模型的分数与第三方报告里另一个模型的分数放在一起——常常比的是流水线。共享的评测工具包（EleutherAI 的 lm-evaluation-harness、HELM 及其他）之所以存在，很大程度上就是为了固定流水线，让其中只有模型在变。

### 答案抽取 {#sec-extraction}

最常被忽视的环节正是抽取。指令微调模型与推理模型不会回答 "$42$"；它们会回答 "Let me work through this… so the total is **42**."。把这样的话变成预测的解析器是测量仪器的一部分，它的误差就是测量误差。

::: proposition 抽取误差扭曲分数 {#prop-extraction}
设模型**本意**给出的答案在 $a$ 的题目上是正确的。假设抽取器以概率 $m$ 未能恢复一个本意正确的答案（**漏检**），并以概率 $f$ 把一个本意错误的答案变成与参考答案匹配的（**误配**），且与题目无关。那么实测准确率的期望是

$$
\E[\hat\mu] = a(1 - m) + (1 - a)f.
$$ {#eq-extraction}

若对每个模型都有 $m = f = 0$，实测准确率是无偏的。若两个模型的漏检率不同，它们实测分数之差就不是本意准确率之差，两个模型的次序甚至可能被颠倒。
:::

::: proof
由全概率公式，按本意答案是否正确作条件：$\Prob(\text{被判对}) = \Prob(\text{本意正确})\,\Prob(\text{被恢复}\mid\text{本意正确}) + \Prob(\text{本意错误})\,\Prob(\text{误配}\mid\text{本意错误}) = a(1 - m) + (1 - a)f$。对参数为 $(a_1, m_1)$ 与 $(a_2, m_2)$、$f = 0$ 的两个模型，实测分数为 $a_1(1 - m_1)$ 与 $a_2(1 - m_2)$；当 $a_1 > a_2$ 但 $m_1 > 1 - (1 - m_2)a_2/a_1$ 时，第一个模型测得更低。
:::

漏检与模型并不是无关的：它取决于模型的输出风格。一个会把中间数字重述一遍的冗长模型，在"取第一个数"的规则下损失更多；一个在答案后面追加注意事项的模型，在"取最后一个数"的规则下吃亏。因此抽取往往惩罚那些风格与抽取器所针对的模型差别最大的模型。

::: example 被解析器颠倒的排名 {#ex-reversal}
模型 A 在 $70\%$ 的题目上本意作答正确，但它写出很长的解释，抽取器因此漏掉它 $15\%$ 的正确答案。模型 B 有 $65\%$ 正确且回答简短，漏检率 $2\%$。两者的误配率都是 $1\%$。它们的实测准确率各是多少？
::: solution
由 [[#eq-extraction]]：A：$0.70\cdot0.85 + 0.30\cdot0.01 = 0.595 + 0.003 = 0.598$。B：$0.65\cdot0.98 + 0.35\cdot0.01 = 0.637 + 0.0035 = 0.6405$。更好的模型测出来反而低了四个多点。样本量再大也暴露不出这一点；只有检查那些抽取失败的输出才行。一个标准做法是报告无法解析出答案的输出占比。
:::
:::

::: widget plot

sliders: m=0.15:0:0.5:0.01; q=0.01:0:0.2:0.01

caption: 在[[#prop-extraction]]之下实测准确率随本意准确率的变化，漏检率为 $m$，误配率为 $q$。漏检对强模型的线拉低得最多；误配则把弱模型抬起来。漏检率不同的两个模型落在不同的线上，所以它们实测之差不是真实之差。
:::

下面的清单模拟 $300$ 道算术题：模型的本意答案约有三分之二是对的，作答采用真实模型会用到的六种风格，再用四个抽取器计分。

```python
import random, re

rng = random.Random(1)
# 300 道算术题；模拟的模型 70% 的时候知道答案，
# 并以真实模型可能采用的几种风格之一把答案写出来
styles = [
    lambda a: f"{a}",
    lambda a: f"The answer is {a}.",
    lambda a: f"**{a}**",
    lambda a: f"First 12 + 30 = 42, so the total is {a}.",
    lambda a: f"{a:,}",                                  # 千位分隔符
    lambda a: f"Answer: {a} (or about {a + 1} if rounding)",
]
data = []
for i in range(300):
    gold = rng.randint(100, 5000)
    pred = gold if rng.random() < 0.7 else gold + rng.choice([-10, -1, 1, 10])
    data.append((gold, rng.choice(styles)(pred), pred == gold))

def exact(text):                       # 整个输出必须就是那个数
    return int(text) if text.strip().isdigit() else None
def first_number(text):
    m = re.search(r"-?\d+", text)
    return int(m.group()) if m else None
def last_number(text):
    m = re.findall(r"-?\d[\d,]*", text)
    return int(m[-1].replace(",", "")) if m else None
def answer_is(text):                   # "answer is X" / "Answer: X"，否则取最后一个数
    m = re.search(r"[Aa]nswer(?: is|:)\s*\**(-?[\d,]+)", text)
    return int(m.group(1).replace(",", "")) if m else last_number(text)

truth = sum(c for _, _, c in data) / len(data)
print(f"true accuracy (model's intended answer correct): {truth:.3f}")
for f in (exact, first_number, last_number, answer_is):
    acc = sum(f(out) == gold for gold, out, _ in data) / len(data)
    print(f"{f.__name__:13s} measured accuracy {acc:.3f}")
```

```text
true accuracy (model's intended answer correct): 0.673
exact         measured accuracy 0.130
first_number  measured accuracy 0.447
last_number   measured accuracy 0.593
answer_is     measured accuracy 0.673
```

同一批输出，得分可以从 $13\%$ 一路到 $67\%$。严格的解析器只接受裸数字；"第一个数"会被中间计算过程和千位分隔符骗过；"最后一个数"会被结尾的注意事项骗过。只有为这些风格量身写就的抽取器才找回了真实准确率——而它是看着这些输出写出来的，这对抽取器是正当的，对模型则不行。真实的流水线在更大规模上面对同样的问题：数学上相等但写法不同的答案（$\frac12$、$0.5$、`\frac{1}{2}`）、包裹在散文里的代码、写成 "(B)" 或 "Option B" 的选项字母。常见的补救办法有：规定固定的答案格式；对数学使用带符号等价性检查的宽容解析器；只在抽取这一步使用模型评审（[[evaluation/model-judges]]）；并且永远要抽查一部分失败的样本。

### 基座模型与指令微调模型 {#sec-formats}

基座模型通常按**似然**评测：不要求模型写出答案，而是让它给给定的候选分配概率，这完全免除了抽取，但引入了归一化上的选择（[[pretraining/in-training-evaluation]]、[[evaluation/benchmarks]]）。指令微调模型通常按**生成**评测，用它们的聊天模板，常常在答案之前带思维链推理。两种协议度量的东西不同——某个候选是"自然续写"的概率，与产出并押下一个答案的能力——同一个模型在两者之下的分数未必一致。用了哪一种，是报告分数的一部分。

### 随机水平与天花板 {#sec-chance}

一个原始分数需要两个参照点：一个毫无相关能力的模型能得多少，一个完美的模型最高能得多少。在选择题基准上，前者不是零。

::: proposition 对猜测作校正 {#prop-chance}
在每题 $K$ 个选项的题目上，设模型知道 $\kappa$ 的题目的答案，其余题目均匀随机地猜。其期望准确率为

$$
\E[\hat\mu] = \kappa + \frac{1 - \kappa}{K},\qquad\text{所以}\qquad \kappa = \frac{\E[\hat\mu] - 1/K}{1 - 1/K}.
$$ {#eq-chance}

**随机水平归一分** $(\hat\mu - 1/K)/(1 - 1/K)$ 估计 $\kappa$；它在随机水平处为 $0$，在满分处为 $1$。
:::

::: proof
模型在会的题目上以概率 $1$ 答对；在其余题目上以概率 $1/K$ 答对。由全概率公式 $\E[\hat\mu] = \kappa\cdot1 + (1 - \kappa)/K$。把这个线性方程解出 $\kappa$ 就得到第二种形式。
:::

这个模型是理想化的——真实模型有不完全的知识，也能排除一些选项——但当选项数不同的基准要被平均时，当训练早期一个四选一基准上 $26\%$ 的分数被误认为"有点能力"而不是随机水平时，归一化就重要了。一些公开排行榜在平均之前会先这样归一化。另一端，**天花板**常常低于 $100\%$，因为基准本身有错误：参考答案有错或含混的题目封住了任何模型能得的分，对流行基准的审计在其中百分之几的题目里就发现了这类错误。逼近天花板时，模型之间剩下的差距，说的也许只是谁更配合那些错误。

hlines: 0
labels: 随机水平归一分；原始准确率
caption: [[#prop-chance]]的随机水平归一分随原始准确率（$K$ 个选项）的变化。$K = 4$ 时，原始分 $40\%$ 只相当于知道 $20\%$ 的答案；低于 $1/K$ 的分数是负的，比瞎猜还差，这通常提示格式有问题，而不是什么反向知识。
:::

::: example 跨格式比较 {#ex-chance}
模型 A 在一个四选一基准上得 $55\%$；模型 B 在同样题目的十选一版本上得 $55\%$。按猜测模型，谁表现出的知识更多？
::: solution
A：$\kappa = (0.55 - 0.25)/0.75 = 0.40$。B：$\kappa = (0.55 - 0.10)/0.90 = 0.50$。同样的原始分，在猜测更不值钱时代表更多的知识；十选一的格式更难，这正是 MMLU-Pro（Wang 等，2024）把 MMLU 的四个选项扩成十个、部分就是为了压低猜测贡献的原因。
:::
:::

::: quiz
在基准题目集合与模型权重都不变的情况下，下列哪些操作能改变模型在一个固定基准上的报告分数？
- [x] 重排提示中少样本示例的顺序
- [x] 从给字母的概率打分改为给答案文本的概率打分
- [x] 更换抽取最终数字所用的正则表达式
- [x] 把解码温度从 $0$ 提到 $0.7$
::: solution
全部都会。每一项都是[[#def-evaluation]]中协议 $\pi$ 或计分规则 $s$ 的一部分，而被估计对象 $\mu(M)$ 依赖于它们。这就是可复现的评测要报告整条流水线——模板、示例数、解码、抽取与归一化——的原因，也是不同流水线的分数不可比较的原因。
:::
:::

## 古德哈特定律 {#sec-goodhart}

基准不只是用来度量模型的，还被用来在模型之间做选择：发布哪个检查点、保留哪个数据配比、配哪个提示发布。一个数字一旦被拿来做选择，它就开始变质。

::: definition 古德哈特定律 {#def-goodhart}
**古德哈特定律**（Goodhart's law）得名于经济学家 Charles Goodhart（1975），人类学家 Marilyn Strathern（1997）给出了常被引用的表述：**一个度量一旦成为目标，它就不再是好度量。**在评测中，它指的是这样一个倾向：分数 $\hat\mu$ 一旦被优化，就会比它本要追踪的构念涨得更快。Manheim 与 Garrabrant（2018）区分了几种机制：

- **回归式**：按"目标加噪声"的代理做选择，选中的也包括噪声；
- **极端式**：代理与目标之间在寻常范围内成立的关系，在优化抵达的极端处失效；
- **因果式**：对代理施加干预并不改变目标，因为代理只是相关物而非原因；
- **对抗式**：优化者（一个训练过程，或某个人）利用代理与目标之间的缝隙。
:::

四种在实践中都看得到。在测试集上从众多检查点中挑最好的，是回归式。在短答数学基准上猛练以至于丢了通用写作能力的模型，是极端式。在基准的题目上训练——无论是故意的还是经由数据污染——分数涨了而能力没涨，这是因果式。针对类基准的奖励做强化学习时的奖励破解则是对抗式（[[safety-alignment/reward-hacking]]）。回归式的情形可以被精确量化。

::: proposition 选择的胜者诅咒 {#prop-winners-curse}
设 $m$ 个配置（提示、检查点、随机种子）的真实分数全为 $\mu$，其测量分数为 $\hat\mu_j = \mu + \sigma Z_j$，其中 $Z_1, \dots, Z_m$ 独立标准正态。被挑为最优的那个配置的测量分数满足

$$
\E\big[\max_j\hat\mu_j\big] = \mu + \sigma e_m,\qquad e_m = \E\big[\max_j Z_j\big],
$$

其中 $e_1 = 0$、$e_2 = 1/\sqrt\pi\approx0.564$，且 $e_m$ 随 $m$ 严格递增（$m = 5, 10, 20$ 时分别约为 $1.163$、$1.539$、$1.867$）。对被选中的配置做一次全新评测，其期望是 $\mu$。
:::

::: proof
第一个论断是线性性：$\max_j(\mu + \sigma Z_j) = \mu + \sigma\max_jZ_j$。$m = 2$ 时，$\max(Z_1, Z_2) = \frac12(Z_1 + Z_2) + \frac12\lvert Z_1 - Z_2\rvert$；第一项的均值为 $0$，而 $Z_1 - Z_2\sim\Normal(0, 2)$，其绝对值的均值为 $\sqrt2\cdot\sqrt{2/\pi} = 2/\sqrt\pi$，故 $e_2 = 1/\sqrt\pi$。再添加一个配置只会抬高最大值，$\max_{j\le m+1}Z_j\ge\max_{j\le m}Z_j$，且严格不等号以正概率成立，故 $e_{m+1} > e_m$。其余的取值是 $\int z\,m\,\phi(z)\Phi(z)^{m-1}\,dz$ 的数值积分。最后，一次全新的评测使用的是与选择过程无关的新噪声，其均值为 $0$。
:::

::: example 在测试集上挑选提示 {#ex-curse}
一个团队在 $500$ 道题的基准上为模型尝试了 $10$ 个提示模板，并报告其中最好的那个。假设每个模板的真实准确率都是 $60\%$，报告的分数比真实值高估了多少？
::: solution
二项标准误差为 $\sigma = \sqrt{0.6\cdot0.4/500} = 0.0219$。由[[#prop-winners-curse]]，被选中的分数的期望是 $0.60 + 1.539\cdot0.0219 = 0.6337$：约 $3.4$ 个百分点纯粹由选择带来的偏差。下面的清单用模拟重现了它。
:::
:::

```python
import random

rng = random.Random(2)
n, p_true, trials = 500, 0.60, 2000      # 题数、每个变体的真实准确率、重复次数

def score(p, n):
    return sum(rng.random() < p for _ in range(n)) / n

for m in (1, 2, 5, 10, 20):
    picked, fresh = 0.0, 0.0
    for _ in range(trials):
        best = max(score(p_true, n) for _ in range(m))   # 从 m 个提示变体中挑最好的
        picked += best
        fresh += score(p_true, n)                         # 在新题目上重跑被选中的那个
    print(f"m = {m:2d}: selected score {picked / trials:.4f}, on fresh questions {fresh / trials:.4f}")
```

```text
m =  1: selected score 0.5992, on fresh questions 0.6006
m =  2: selected score 0.6128, on fresh questions 0.5998
m =  5: selected score 0.6251, on fresh questions 0.6003
m = 10: selected score 0.6340, on fresh questions 0.6005
m = 20: selected score 0.6410, on fresh questions 0.6003
```

模拟得到的被选分数与 $0.6 + 0.0219\,e_m$ 在模拟误差内吻合（$0.6124$、$0.6255$、$0.6337$、$0.6409$），而在新鲜题目上每次选择都回落到 $0.60$。现实中各配置的真实分数多少有些不同，所以选择确实能找到更好的配置，**同时**把它报高了；两种情形的补救办法相同。在**开发集**上做选择，在只用一次的**留出集**上报告，并说明尝试了多少个配置。同样的算术适用于整个研究社区：当许多团队对着同一个公开测试集调许多方法时，发表出来的最好数字会被选择抬高——远在语言模型之前，人们就为长寿命基准提出了这一担忧（Recht 等，2019 为图像分类新建了一个 ImageNet 测试集来检验；准确率下降了，但模型之间的排名大体保持，作者把下降主要归因于新数据的差异，而不是自适应过拟合）。

::: warning 更高的分数不等于更好的模型
人们很容易把基准上的涨分读成能力上的涨分。涨分可能来自协议（更好的提示、更宽容的解析器），来自选择（多次尝试中挑最好的），来自污染（题目在训练中见过），或来自针对基准怪癖的优化——只有时候才来自构念。接受一个涨分之前要问：流水线一样吗？尝试了多少个配置、在哪些数据上？题目可能出现在训练数据里吗？涨幅在同一构念的另一个基准上出现了吗（收敛效度）？真正的改进往往在多处同时显现；假象往往只出现在一处。
:::

## 预期用途 {#sec-intended-use}

评测是手段而不是目的：它的存在是为了支持一个决定。决定决定了该测量什么、要测到多精、结果该怎么呈现。

::: definition 预期用途与决策相关性 {#def-intended-use}
一次评测的**预期用途**是它所支持的那个决定、以及那个决定所牵涉的情形总体：发布一个检查点、为某个产品选模型、比较研究方法、判断是否需要安全措施。若评测结果的改变会改变那个决定，该评测就是**决策相关的**。**基准–部署差距**是评测的题目总体 $\mathcal{D}$ 与预期用途中实际遭遇的情形分布之间的差别。
:::

不同的用途导向不同的评测：

- **研究比较**（方法 A 胜过方法 B 吗？）需要固定、共享的流水线，足以检测出预期差距的题目量（[[evaluation/evaluation-statistics]]），以及对选择的控制。构念的宽窄可比性还是次要的。
- **为应用选模型**需要取自应用本身的题目——真实用户请求、产品的文档、它的语言——按应用在乎的标准计分，包括成本与延迟。公开基准的排名在这里是弱证据，因为部署分布与它们不同。
- **发布与安全决策**需要对"可能出什么错"的评测，用模型最强的激发方式来运行，阈值事先设定（[[evaluation/capability-evaluations]]）。
- **部署后的监控**需要便宜、可重复、能检测变化的测量。

文档规范把预期用途摆到明面上。**模型卡**（Mitchell 等，2019）报告模型的预期用途、性能在哪些因素上做过评测（人群、语言、条件）、指标与评测数据；**数据集说明书**（Gebru 等，2021）记录数据集是怎么采集的、适合什么用途。对一次评测，对应的文档要写明构念、题目总体、完整流水线、样本量与不确定度、已知的效度威胁，以及结果支持和不支持哪些决定。

### 许多个数字，而不是一个 {#sec-holistic}

一个头条数字招来古德哈特定律，还藏起了权衡。HELM 项目（Liang 等，2022）主张在标准化协议之下、用许多指标——准确率、校准、对扰动的稳健性、群体间的公平性、偏见、毒性与效率——在许多场景上评测每个模型，并发表完整矩阵而不是平均值，好让使用者按自己的用途去权衡各个维度。Bowman 与 Dahl（2021）提出了自然语言理解的基准值得为之优化所应满足的条件：效度（表现好必须真的需要这项技能）、可靠的标注、足以区分系统的统计功效、不奖励有害偏见。这些标准将在课程中反复出现。

::: example 由决定倒推出的评测计划 {#ex-plan}
一家公司要在两个模型中选一个，用英语和西班牙语、根据其文档回答客户关于其软件的问题。请勾画一个由这个决定倒过来设计的评测。
::: solution
**构念**：对真实客户问题的正确、有据、有用的回答。**题目**：从两种语言的历史工单中抽几百条问题，按产品领域分层，由客服人员撰写参考答案；包含无法从文档作答的问题，因为正确的回应就是说无法作答。**协议**：每个模型都在它实际会使用的检索配置下运行（[[prompting-rag/rag-evaluation]]），用生产环境的系统提示与解码设置。**计分**：在子样本上由受训人员对照参考判定正确性与有据性，其余部分用对照这些标签验证过的模型评审（[[evaluation/model-judges]]）；统计拒答与转人工比率；每条回答的延迟与成本。**分析**：在同一批题目上做配对比较并给出置信区间，按语言与产品领域细分，因为总分上的赢可能掩盖西班牙语上的输。**决策规则**事先定死：除非另一个模型在正确性上高出业务认为值那个价钱的幅度，否则选便宜的那个。公开排行榜上的名次不起作用，只用来筛候选。
:::
:::

::: history
对测验究竟在度量什么的关心先于机器学习而存在。心理测量学发展了信度（Spearman，1904）与效度理论；Cronbach 与 Meehl 的《心理测验中的构念效度》（"Construct validity in psychological tests"，1955）为这一概念命名，Messick（1995）把效度的各个侧面统一进一个框架。在经济学中，Goodhart（1975）观察到货币总量一旦被政策当作目标就失去预测价值，Campbell（1979）对社会指标提出了相应的论点。机器学习从 1980 年代末起 DARPA 与 NIST 主持的语音与翻译评测中继承了**公共任务框架**——共享数据、留出测试集、固定指标——它推动了飞速进展，从 TREC（1992 年起）到 ImageNet（2009）与 GLUE（2018）。随着语言模型走向通用，这一框架的假设开始吃紧：Raji 等（2021）质疑"一般能力"基准的效度，Bowman 与 Dahl（2021）追问基准评测要怎么补救，HELM（Liang 等，2022）提出多指标的整体评测，而关于提示敏感性的工作（Zhao 等，2021；Lu 等，2022；Sclar 等，2023）表明协议与模型同样是分数的一部分。
:::

::: summary
- 一次评测是一个题目总体、一个协议、一个计分规则和一个聚合（[[#def-evaluation]]）；它的被估计对象依赖这四者，而基准给出的是它带噪的估计。
- **构念效度**问的是分数是否度量它声称的能力（内容、效标、收敛与区分效度）；**信度**问的是它能否重演。宽泛的论断需要单个基准之外的证据。
- **流水线**——提示格式、少样本示例及其顺序、选项呈现、解码、答案抽取、归一化——能把分数移动多个百分点并打乱模型排名；完整报告它，只作同类比较。
- 抽取误差使分数偏了 $a(1 - m) + (1 - a)f$（[[#prop-extraction]]），而依赖风格的漏检可以颠倒排名；要检查解析失败。
- 在 $K$ 选项的题目上，随机水平是 $1/K$；归一分 $(\hat\mu - 1/K)/(1 - 1/K)$ 估计知道答案的比例（[[#prop-chance]]）。
- **古德哈特定律**：被优化的度量会偏离目标。从 $m$ 个同样好的配置中挑最好的，会把它高估 $\sigma e_m$（[[#prop-winners-curse]]）；在开发数据上做选择，在留出数据上只报告一次。
- 从**预期用途**倒过来设计评测；报告许多指标及其不确定度，而不是一个头条数字。
:::

## 习题

::: exercise 对分数作随机水平归一 {level=1 check="0.4"}
一个模型在五选一选择题基准上得 $52\%$。按[[#prop-chance]]的猜测模型，它知道多大比例的答案？
::: solution
$\kappa = (0.52 - 0.2)/(1 - 0.2) = 0.32/0.8 = 0.4$。
:::
:::

::: exercise 抽取误差下的实测准确率 {level=1 check="0.724"}
一个模型的本意答案在 $80\%$ 的题目上正确。抽取器漏掉 $10\%$ 的正确答案，并在 $2\%$ 的错误答案上制造误配。实测准确率的期望是多少（三位小数）？
::: solution
由[[#eq-extraction]]：$0.8\cdot0.9 + 0.2\cdot0.02 = 0.72 + 0.004 = 0.724$。
:::
:::

::: exercise 数少样本配置 {level=1 check="1860480"}
一次评测用 $5$ 个少样本示例，从 $20$ 道已解示例中选出并排序。一共可能有多少种不同的有序少样本提示？这对报告分数为什么要紧？
::: solution
从 $20$ 中有序地选 $5$：$20\cdot19\cdot18\cdot17\cdot16 = 1{,}860{,}480$。既然光是顺序就能大幅改变分数（Lu 等，2022），单个提示只是从一个巨大空间里抽出的一个样本；可靠的评测要么事先固定提示（为了可比），要么对若干次随机抽取取平均并报告散布（为了稳健）。在测试集上挑最好的要付胜者诅咒的代价。
:::
:::

::: exercise 还原已知的漏检率 {level=2 check="0.6316"}
对 $200$ 个解析失败案例的审计显示，抽取器漏掉 $5\%$ 的正确答案，从不产生误配。实测准确率为 $60\%$。估计本意准确率，保留四位小数。为什么修好抽取器比套用这个校正更好？
::: solution
$f = 0$ 时，[[#eq-extraction]] 给出 $\hat\mu = a(1 - m)$，故 $a = 0.60/0.95 = 0.6316$。这个校正假设漏检率对每道题都相同、且被没有误差地估计了；实际上漏检集中在特定的输出风格与题型上，而被估计的比率自带不确定度，校正后的分数会把它继承下来。修好抽取器能逐题消除误差；对模型比较来说，它还消除了单个校正系数消不掉的、依赖风格的偏差。
:::
:::

::: exercise 两个提示的胜者诅咒 {level=2 check="0.5141"}
两个真实准确率同为 $0.5$ 的提示在 $400$ 道题上比较，报告较好的那个。用[[#prop-winners-curse]]的正态模型与二项标准误差，报告分数的期望是多少（四位小数）？
::: solution
$\sigma = \sqrt{0.5\cdot0.5/400} = 0.025$，$e_2 = 1/\sqrt\pi = 0.5642$，故报告分数的期望是 $0.5 + 0.025\cdot0.5642 = 0.5141$。（实际上两个分数共享同一批题目，这会正相关而使偏差更小；独立的模型是最坏情形。）
:::
:::

::: exercise 一次效度审计 {level=2}
一个基准声称度量"长上下文理解"：每道题把一句话（"针"，如 "The secret number is 4821"）藏在一篇无关文字的长文档里，要求模型把它复述出来。就这一构念讨论它的内容效度、效标效度与区分效度，并各提出一个能改进它们的改动。
::: solution
**内容**：任务只覆盖对一句与上下文无关、且十分显眼的句子的字面检索；长上下文理解还包括整合散布在全文的信息、追踪实体与消解指代、以及概括。改进：加入需要在多个段落上聚合、需要对文档自身内容作推理的题目。**效标**：没有证据表明该分数预测真实长文档任务（合同审阅、代码库问答）上的表现；改进：跨模型把分数与一组贴近现实的长文档任务作相关。**区分**：因为"针"在词汇上很特别，模型靠浅层的模式匹配就可能成功，分数更相关的也许是指令遵循而不是理解；改进：让"针"在语义上与周围文字相关，或改用与它不共用任何词的转述问题。后来的长上下文基准沿着这些方向做了；模型的一面见 [[inference/long-context]]。
:::
:::

::: exercise 排名逆转的门槛 {level=2 check="0.0833"}
模型 A 的本意准确率为 $0.72$，模型 B 为 $0.66$。B 的漏检率为 $0$，两者都没有误配。当 A 的漏检率 $m_A$ 高于何值（四位小数）时，A 测得比 B 低？
::: solution
A 测得比 B 低当 $0.72(1 - m_A) < 0.66$，即 $m_A > 1 - 0.66/0.72 = 1 - 0.9167 = 0.0833$。一个模型上 $8\%$ 的漏检率，就足以抹掉六分的领先。
:::
:::

::: exercise 选择中的均值回归 {level=3 check="1.2"}
设基准分数 $U$ 与其本要追踪的能力 $V$ 在候选模型总体上服从相关系数为 $\rho$ 的联合标准正态。(a) 证明 $\E[V\mid U = u] = \rho u$。(b) 一个实验室挑选分数在均值之上 $2$ 个标准差的模型。$\rho = 0.6$ 时，它们的期望能力是多少个标准差？(c) 把这一点解释为回归式古德哈特。
::: solution
(a) 写 $V = \rho U + \sqrt{1 - \rho^2}\,W$，$W$ 标准正态且与 $U$ 独立；这样 $V$ 的方差为一且 $\Cov(U, V) = \rho$，而均值与协方差都相同的联合正态变量分布相同。于是 $\E[V\mid U = u] = \rho u + \sqrt{1 - \rho^2}\,\E[W] = \rho u$。(b) $0.6\cdot2 = 1.2$ 个标准差。(c) 按代理选择，等于部分地按 $U$ 中相对 $V$ 是噪声的那部分作选择；选中的模型确实更好，但比分数暗示的差一些，缺口 $(1 - \rho)u$ 随选择强度 $u$ 增大。对代理优化得越狠，缺口越大，这就是古德哈特定律的回归式；[[#prop-winners-curse]] 是所有候选全同的 $\rho = 0$ 特例。
:::
:::

::: exercise 一个更好的抽取器 {level=3}
给[[#sec-extraction]]的抽取器添一个针对数学答案的：若存在 LaTeX 的 `\boxed{…}` 就优先取它的内容，其次是 "answer is" 或 "Answer:" 字段，最后才是最后一个数；剥掉千位分隔符；并按数值比较，使 "0.50"、"1/2" 与 "\frac{1}{2}" 都匹配参考值 $0.5$。拿几个字符串测一测。
::: solution
```python
import re
from fractions import Fraction

def to_number(s):
    s = s.strip().strip("$").replace(",", "").rstrip(".")
    m = re.fullmatch(r"\\d?frac\{(-?\d+)\}\{(-?\d+)\}", s)     # \frac{a}{b} 或 \dfrac{a}{b}
    if m:
        return Fraction(int(m.group(1)), int(m.group(2)))
    try:
        return Fraction(s)                                    # "1/2"、"0.50"、"-3"
    except (ValueError, ZeroDivisionError):
        return None

def extract(text):
    m = re.findall(r"\\boxed\{((?:[^{}]|\{[^{}]*\})*)\}", text)
    if m:
        return to_number(m[-1])
    m = re.search(r"[Aa]nswer(?: is|:)\s*\**\s*([^\s*]+)", text)
    if m and to_number(m.group(1)) is not None:
        return to_number(m.group(1))
    nums = re.findall(r"-?\d[\d,]*(?:\.\d+)?(?:/\d+)?", text)
    return to_number(nums[-1]) if nums else None

tests = ["So the result is \\boxed{\\frac{1}{2}}.", "The answer is 0.50.", "Answer: 1/2",
         "We get 3, then 7, so 1,250", "Thus x = \\boxed{-3}", "no idea"]
for t in tests:
    print(f"{t!r:45s} -> {extract(t)}")
print(extract(tests[0]) == Fraction(1, 2) == extract(tests[1]) == extract(tests[2]))
```

```text
'So the result is \\boxed{\\frac{1}{2}}.'     -> 1/2
'The answer is 0.50.'                         -> 1/2
'Answer: 1/2'                                 -> 1/2
'We get 3, then 7, so 1,250'                  -> 1250
'Thus x = \\boxed{-3}'                        -> -3
'no idea'                                     -> None
True
```

用精确的有理数比较可以避开浮点的意外。真正的数学评分器走得更远，会用计算机代数系统来判定 $\sqrt{8}$ 与 $2\sqrt2$ 这类表达式的等价性；而它们同样需要审计：每一条接受更多等价形式的规则，也冒着接受一个错误答案的风险，即[[#prop-extraction]]意义上的误配。
:::
