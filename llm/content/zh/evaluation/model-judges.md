对开放式输出而言，人类评审是参照，但它缓慢而昂贵：几千次细致的比较可能就要花上几周。既然强语言模型能够读完两个回答并说出哪个更好，一条显而易见的捷径就是让模型来做评审。**大模型评审**（LLM-as-a-judge）已成为开发过程中评测开放式生成的默认方式：它在指令遵循基准上为聊天模型打分，对照参考答案批改自由形式的回答，并为训练提供 AI 反馈（[[post-training/ai-feedback]]）。评审是一种测量仪器，而像任何仪器一样，它必须对照参照来**校准**，并检查有无**系统性误差**。

本章把模型评审当作测量来看待。它描述几种主要协议——逐点评分、成对比较、参考引导与评分细则评审——以及在其上建立的基准，从 **MT-Bench**（Zheng 等，2023）讲起。它在模拟中定义并测量评审最著名的几种偏差（偏向某个**位置**、偏向**更长的回答**、偏向**自己的输出**），说明如何量化评审与人类标注的一致性、如何针对已知误差**校正**评审测得的胜率，并分析**评审集成**——它有助于抵消相互独立的错误，却对付不了共享的偏差。后训练课程推导过交换两个回复的次序为何能消除恒定的位置偏差；这里的重点则是为评测测量偏差、验证评审。

## 评审协议 {#sec-protocols}

::: definition 评审协议 {#def-judge}
**模型评审**是被提示去评判对某个提示 $x$ 的一个或多个回答的语言模型 $J$。常见的协议有：

- **逐点评分**（pointwise，单答案）：$J$ 在固定量表上给回答 $y$ 打分，例如 $1$ 到 $10$，通常先给出解释再打分；
- **成对比较**（pairwise）：$J$ 看到 $y_1$ 与 $y_2$，输出一个偏好（$y_1$、$y_2$ 或平局）；一个模型的**胜率**是它对阵某个固定的**基线**模型或其他模型时赢下的比较占比；
- **参考引导评分**（reference-guided）：同时给 $J$ 一个参考答案，对照它来评判正确性，从而把困难的验证变成较易的比较；
- **评分细则**或**检查清单**式评分：$J$ 依据显明标准给回答打分——这些标准可以逐题特定——再把分数合并。

评审的提示（指令、标准、输出格式）、它是否在裁决前推理、它的解码设置、以及裁决如何被解析，都是协议的一部分（[[evaluation/evaluation-principles#def-evaluation]]）。
:::

就逐点评分而言，评审在评分词元上的分布比它采样出的单个分数携带更多信息。**G-Eval**（Liu 等，2023）使用评分词元 $s\in\{1, \dots, 10\}$ 上的期望 $\sum_ss\,p_J(s\mid x, y)$，相比取最大值（arg max），它给出粒度更细、更少并列的分数。

### MT-Bench 及其后继者 {#sec-mtbench}

**MT-Bench**（Zheng 等，2023）由 $80$ 道两轮问题组成，分八类——写作、角色扮演、信息抽取、推理、数学、编程，以及 STEM 与人文社科知识——其设计使第二轮考察模型能否接续自己第一轮的回答。同一篇论文收集了专家对 MT-Bench 回答的投票，以及来自 Chatbot Arena（[[evaluation/human-evaluation#sec-arena]]）的众包投票，并把 GPT-4 作为评审的判定与它们作比较。其报告的主要发现是：剔除平局后，GPT-4 的成对裁决约 $85\%$ 的时候与专家的人类裁决一致，高于专家彼此一致的 $81\%$；把平局计入，两个数字都更低（约 $66\%$ 与 $63\%$）。按这一度量，评审与人类的一致程度，恰如人类彼此之间的一致程度。

这篇论文还识别出本章其余部分要测量的那些偏差，并提出了缓解办法：交换位置，裁决在两种次序下不一致时判平局；对数学与推理采用**参考引导**评分——在一小组数学题上，这把评审的失误率从 $20$ 题错 $14$ 题降到 $20$ 题错 $3$ 题（否则它很容易被一个自信的错误答案带偏）；以及把多轮对话作为整体来评判。

随后出现了若干同一设计的基准。**AlpacaEval**（Li 等，2023）报告一个模型在约 $800$ 条指令上对阵一个参考模型的胜率，由强模型评审；**Arena-Hard**（Li 等，2024）从 Chatbot Arena 选出 $500$ 个困难而多样的提示，对阵基线做成对比较，力求以低成本复现 Arena 的排名；**WildBench**（Lin 等，2024）使用真实用户任务，每个任务配有检查清单。专为评测训练的开放权重评审模型，例如 **Prometheus**（Kim 等，2023），按用户提供的评分细则打分，使评审本身也可复现。这些基准的价值在于它们与人类排名的相关性，其作者在系统整体的层面报告这一相关性；它们所主张的正是这一相关性，而非条目层面的准确率。

## 模型评审的偏差 {#sec-biases}

评审的误差有两个部分：**噪声**，逐条目不同，在许多条目上会被平均掉；以及**偏差**，朝一个方向系统性地推拉，不会被平均掉。正是偏差使基于评审的比较成为错误，而不只是不精确。

::: definition 评审偏差的度量 {#def-bias-measures}
对以两种次序呈现比较对的成对评审：

- **位置一致性**是两种次序下裁决相同的比较对占比；**首位胜率**（first-slot rate）指全部裁决中归于排首的回答的占比（对没有位置偏差的评审，在次序均衡的比较对上它是 $\frac12$）；
- **冗长偏差**用**受控对**测量：一个回答对阵它加长却不增添内容的副本（重复、补白、复述要点），两种次序各呈现一次；更长的副本被偏爱的比例应当不超过 $\frac12$；
- **自我偏好**是评审对自己（或其模型家族）生成的回答的偏爱，超出人类评定者对同样回答所表达的偏爱的部分。
:::

前两种度量使用**反事实**输入——同样的内容换到另一个位置，或同样的内容被加长——于是裁决的任何变化都可以归于被操纵的那个特征。自我偏好需要人类参照，因为如果评审自己的输出确实更好，它偏爱它们也无可厚非。Zheng 等（2023）发现 GPT-4 在约三分之二的比较对上交换次序后仍保持一致，较弱的评审一致性远逊于此；还发现一种"重复列表"攻击——把回答的要点复述一遍使其变长——大多数时候能骗过较弱的评审，却很少能骗过 GPT-4。Wang 等（2023）表明，仅凭位置偏差就能改变评审对两个系统的高下排序。Panickssery 等（2024）发现评审偏爱自己的输出，且偏爱的强度与它们识别自己文本的能力相关。其他有文献记录的情形包括对自信或权威语气、对排版格式、以及对回答内部自称正确断言的敏感。

### 位置偏差与交换—判平协议 {#sec-swap}

位置偏差最简单的模型，是在评审选中第一个回答的对数几率上加一个常数 $b$。后训练课程说明了把两种次序的对数几率取平均能精确恢复无偏偏好（[[post-training/ai-feedback]]）。当只有评审的裁决可用、拿不到它的概率时，就改用 MT-Bench 的**交换—判平**（swap-and-tie）规则：两种次序各查询一次，仅当两次裁决一致才采纳，否则记为平局。

::: proposition 位置偏差下的不一致性 {#prop-inconsistency}
设某评审在 $y_1$ 在前时以概率 $\sigma(\Delta + b)$ 选中排首的回答，在 $y_2$ 在前时以概率 $\sigma(-\Delta + b)$ 选中排首的回答，两种次序下相互独立，其中 $\Delta$ 是评审眼中的质量差，$b$ 是它的位置偏差。则它两次裁决不一致的概率为

$$
P_{\text{incons}}(\Delta, b) = \sigma(\Delta + b)\,\sigma(-\Delta + b) + \sigma(-\Delta - b)\,\sigma(\Delta - b).
$$

在 $\Delta = 0$ 处它等于 $\sigma(b)^2 + \sigma(-b)^2$，当 $b = 0$ 时为 $\frac12$，并随 $\lvert b\rvert\to\infty$ 增至 $1$。在交换—判平之下，一个无偏差且 $\Delta\ne0$ 的比较对会以概率 $2\sigma(\Delta)\sigma(-\Delta) < \frac12$ 被判平局。
:::

::: proof
当评审两次都选首位——概率 $\sigma(\Delta + b)\cdot\sigma(-\Delta + b)$——或两次都选次位——$(1 - \sigma(\Delta + b))(1 - \sigma(-\Delta + b)) = \sigma(-\Delta - b)\sigma(\Delta - b)$——时，两次裁决不一致。在 $\Delta = 0$ 处，这两项是 $\sigma(b)^2$ 与 $\sigma(-b)^2$。记 $s = \sigma(b)$，和 $s^2 + (1 - s)^2$ 在 $s = \frac12$ 处取最小值，并随 $s\to0$ 或 $1$ 增至 $1$。当 $b = 0$ 时公式化为 $2\sigma(\Delta)\sigma(-\Delta) = 2\sigma(\Delta)(1 - \sigma(\Delta)) < \frac12$（$\Delta\ne0$）。
:::

由此得出两点。不一致性把位置偏差与评审惯常的随机性混在一起，所以单看一致率低并不能度量偏差；能度量的是首位胜率。而交换—判平把评审无法稳妥裁决的情形变成平局，以丢弃信息为代价提高保留裁决的精度——此时胜率里必须处理平局（通常记双方各半个胜场）。

::: example 解读一次一致性审计 {#ex-consistency}
某评审在 $1{,}000$ 个比较对上按两种次序各运行一次。它在 $700$ 个比较对上给出相同的裁决。在其 $2{,}000$ 个裁决中，$1{,}240$ 个归于排首的回答。这两个数字说明什么？交换—判平会得到什么？
::: solution
首位胜率为 $1240/2000 = 0.62$，远高于 $\frac12$：明显的位置偏差。按[[#prop-inconsistency]]的模型、在 $\Delta = 0$ 处，$\sigma(b) = 0.62$ 对应 $b = \operatorname{logit}0.62 = 0.49$（对数几率刻度；这是个近似，因为真实的比较对有 $\Delta\ne0$）。$70\%$ 的一致性意味着交换—判平会在 $1{,}000$ 对中产生 $300$ 个平局；那 $700$ 个一致的裁决正是评审有把握的那些。计算胜率时每个平局给双方各记半个胜场，这会把胜率向 $\frac12$ 拉近——若那些比较对确实接近，这恰如其分；若评审只是对它们靠不住，这就是误导。
:::
:::

### 在模拟中测量偏差 {#sec-sim}

下面的清单模拟一个带有三种无需人类标注即可测量的效应的评审——位置偏差 $b = 0.7$、长度偏好 $v = 0.4$（以每标准差长度折合的质量计）、以及刻画评审自身感知错误的逐对**误读** $\varepsilon$——在 $5{,}000$ 个质量与长度相互独立的随机回答马上运行。人类标注来自一个只看质量、带噪声的评定者，第二个模拟人类给出人类—人类一致率。随后运行一个冗长探针，并把单个去偏评审与三人评审团作比较。

```python
import math, random

rng = random.Random(6)
sig = lambda z: 1 / (1 + math.exp(-z))

def p_first(q1, q2, l1, l2, err, b=0.7, v=0.4, k=2.0):
    """P(judge picks the response shown FIRST): quality difference, a length preference v,
    the judge's misreading err of this pair, and a position bias b towards the first slot."""
    return sig(k * ((q1 - q2) + v * (l1 - l2) + err) + b)

def pair():
    q1, q2, l1, l2 = (rng.gauss(0, 1) for _ in range(4))     # 质量、标准化长度
    return q1, q2, l1, l2

def human(q1, q2):                                           # 带噪声的人类：True = 偏爱 1
    return rng.random() < sig(2 * (q1 - q2))

N = 5000
stats = dict(one=0, first=0, consistent=0, agree_nt=0, hh=0)
for _ in range(N):
    q1, q2, l1, l2 = pair()
    h = human(q1, q2)
    err = rng.gauss(0, 0.5)
    v12 = rng.random() < p_first(q1, q2, l1, l2, err)        # 1 在前；True = 选 1
    v21 = rng.random() >= p_first(q2, q1, l2, l1, -err)      # 2 在前；True = 选 1
    stats["one"] += v12 == h
    stats["first"] += v12 + (not v21)                        # 排首者赢下的场数
    stats["hh"] += human(q1, q2) == h                        # 第二个人类对比第一个
    if v12 == v21:
        stats["consistent"] += 1
        stats["agree_nt"] += v12 == h
print(f"human-human agreement:                       {stats['hh'] / N:.3f}")
print(f"judge-human agreement, one order:            {stats['one'] / N:.3f}")
print(f"share of verdicts won by the first slot:     {stats['first'] / (2 * N):.3f}")
print(f"position consistency (same verdict swapped): {stats['consistent'] / N:.3f}")
print(f"agreement on consistent pairs (swap-and-tie): {stats['agree_nt'] / stats['consistent']:.3f}")

# 冗长探针：同一回答对阵一个补白到长出一个标准差的副本
padded = sum((rng.random() < p_first(0, 0, 1, 0, 0)) + (rng.random() >= p_first(0, 0, 0, 1, 0))
             for _ in range(N)) / (2 * N)
print(f"padded copy preferred, averaged over orders: {padded:.3f}")

# 去偏后的确定性（贪心）评审：次序平均后的对数几率 > 0 时选 1；
# 三个这样评审组成的评审团，误读相互独立或共享
def verdict(q1, q2, l1, l2, err):
    return (q1 - q2) + 0.4 * (l1 - l2) + err > 0             # 位置偏差精确消去
for label, judges, shared in [("single judge", 1, False), ("panel of 3, independent", 3, False),
                              ("panel of 3, shared", 3, True)]:
    agree_h = agree_t = 0
    for _ in range(N):
        q1, q2, l1, l2 = pair()
        e0 = rng.gauss(0, 0.5)
        votes = [verdict(q1, q2, l1, l2, e0 if shared else rng.gauss(0, 0.5)) for _ in range(judges)]
        pick1 = 2 * sum(votes) > judges
        agree_h += pick1 == human(q1, q2)
        agree_t += pick1 == (q1 > q2)
    print(f"{label:24s}: agrees with humans {agree_h / N:.3f}, with true quality {agree_t / N:.3f}")
```

judge-human agreement, one order:            0.717
share of verdicts won by the first slot:     0.582
position consistency (same verdict swapped): 0.740
agreement on consistent pairs (swap-and-tie): 0.800
padded copy preferred, averaged over orders: 0.678

panel of 3, independent : agrees with humans 0.783, with true quality 0.865

应当像做审计那样读这些数字。首位赢下 $58\%$ 的裁决：位置偏差存在，且无需任何人类标注就能测量。四分之一的比较对换序即换裁决；在其余四分之三上，评审与人类有 $80\%$ 的一致，高于人类—人类的 $76\%$——但那是在一个更容易的子集上，所以这一比较抬高了评审。补白探针暴露了长度偏好：补满却毫无新意的回答有 $68\%$ 的时间获胜。位置偏差一旦除去，评审与人类的一致就比第二个人类还高（$0.775$ 对 $0.760$），因为人类标注本身有噪声；但它对真实质量仍会在 $16\%$ 的比较对上出错，而这部分误差里有长度偏好的份——它是交换多少次都除不掉的。误读*相互独立*的三人评审团表现更好（$0.865$）；成员共享误读的评审团——同一个模型跑三遍，或在同样的数据上训练的模型——毫无增益，而且三组评审共享同一个长度偏差。

## 对照人类校准评审 {#sec-calibration}

评审在被用于评测之前，应当先在同一协议下、在一份来自同一提示与回答分布、带人类标注的样本上验证。有三个层面的一致性要紧。

- **条目层面一致性**：评审裁决与人类（或多数人类）裁决一致的条目占比，连同 Cohen's κ 一起报告以扣除随机成分（[[evaluation/human-evaluation#def-kappa]]），并按类别拆分，因为一致性随任务差别很大。Bavaresco 等（2024）在 $20$ 个 NLP 评测数据集上把若干评审与人类标注作比较，发现一致性依数据集与被评属性从很高到接近随机不等。
- **偏差审计**：[[#def-bias-measures]]的反事实探针。
- **系统层面一致性**：评审是否像人类那样给*系统*排序——一组模型的评审分数与人类分数之间的相关（Spearman 或 Kendall）。评审基准通常报告的就是它；即使条目层面一致性平平，它也可能很高，因为条目层面的独立误差会被平均掉。

最后一点可以说得精确，它还给出一个校正公式。

::: proposition 校正评审的胜率 {#prop-correction}
设在场场模型 A 对阵基线的比较中，评审以概率 $a > \frac12$ 报告人类的裁决、以概率 $1 - a$ 报告相反的裁决，且与人类偏好哪个模型无关（**对称**误差）。若人类以概率 $w$ 偏好 A，则评审报告的对 A 的期望胜率为

$$
m = a\,w + (1 - a)(1 - w) = (1 - a) + (2a - 1)\,w,
$$ {#eq-judge-winrate}

于是当且仅当 $w > \frac12$ 时 $m > \frac12$，且 $w$ 可由下式恢复为

$$
\hat w = \frac{\hat m - (1 - a)}{2a - 1},
$$ {#eq-correction}

当 $a$ 已知时，其标准误差为 $\operatorname{SE}(\hat m)/(2a - 1)$。若误差不对称——比如 A 写的答案更短，评审恰在 A 是更好的模型时更常出错——那么当 $w < \frac12$ 时 $m$ 也可能超过 $\frac12$。
:::

::: proof
对人类的裁决用全概率公式：当人类偏好 A 且评审报告正确（$w\,a$），或人类偏好基线而评审出错（$(1 - w)(1 - a)$）时，评审说"A"。该表达式对 $w$ 线性，斜率 $2a - 1 > 0$，且在 $w = \frac12$ 处取值 $\frac12$，这就给出方向等价；解出 $w$ 即得[[#eq-correction]]，而斜率为 $1/(2a - 1)$ 的线性映射把标准误差乘以同一因子。误差率不对称时——人类偏好 A 时为 $1 - a_1$、偏好基线时为 $1 - a_0$——$m = a_1w + (1 - a_0)(1 - w)$；例如 $a_1 = 0.6$、$a_0 = 0.9$、$w = 0.45$ 时 $m = 0.27 + 0.055 = 0.325$，而 $a_1 = 0.9$、$a_0 = 0.6$ 时 $m = 0.405 + 0.22 = 0.625 > \frac12$。
:::

对称误差把差距向 $\frac12$ 压缩，却保持其方向；这就是评审尽管条目层面准确率平平、也能把系统排好序的原因。不对称误差——由与被比较系统相关的偏差产生——则会颠倒排序，这就是偏差审计比表面一致率更要紧的原因。[[#eq-correction]]的校正是已知误差率测量的标准手法（流行病学中用它按检测的灵敏度与特异度校正患病率）；它要求一致性是在与评测同分布的数据上测得的，并把不确定度放大 $1/(2a - 1)$ 倍——$a = 0.75$ 时就是 $2$ 倍。

::: example 校正后的胜率 {#ex-correction}
某评审在 $400$ 个比较对上对照人类标注验证，一致率 $80\%$，且没有证据表明其误差取决于哪个模型更好。在一次新评测中，它报告模型 A 在 $1{,}000$ 个提示中的 $62\%$ 上胜过基线。估计人类胜率及其标准误差。
::: solution
由[[#eq-correction]]，$\hat w = (0.62 - 0.20)/(2\cdot0.8 - 1) = 0.42/0.6 = 0.70$。$\hat m$ 的标准误差为 $\sqrt{0.62\cdot0.38/1000} = 0.0153$，故 $\hat w$ 的是 $0.0153/0.6 = 0.026$——这还没算上 $a$ 自身的不确定度：它只由 $400$ 个比较对估出（$\pm0.02$），会让 $\hat w$ 变动约 $\pm0.03$。评审原始的 $62\%$ 低估了一个可观的偏好。
:::
:::

::: example 评审损失统计功效 {#ex-power}
人类在 $55\%$ 的提示上偏好模型 A 胜于基线。一个对称一致率 $a = 0.7$ 的评审评测 $500$ 个提示。它平均报告多大的胜率？这离 $\frac12$ 有几个标准误？与同样这 $500$ 个提示上的人类评测相比呢？
::: solution
由[[#eq-judge-winrate]]，$m = 0.3 + 0.4\cdot0.55 = 0.52$。$500$ 个提示时，$\frac12$ 附近的标准误差为 $\sqrt{0.25/500} = 0.0224$，于是评审 $0.02$ 的优势只是 $0.89$ 个标准误——与平局无法区分——而人类 $0.05$ 的优势则是 $2.24$ 个标准误。评审把效应压缩了 $2a - 1 = 0.4$ 倍，因此同样的功效需要约 $1/0.4^2 = 6.25$ 倍的提示。廉价的裁决并非免费：账要拿样本量来付。
:::
:::

### 长度控制 {#sec-length-control}

冗长偏差恰恰是那种危险的不对称误差：它偏袒写得出更长答案的那个系统。**长度控制版 AlpacaEval**（Dubois 等，2024）用回归对付它。它拟合一个 logistic 模型，用模型自身项、两个回答的长度差项与指令难度项来预测评审的偏好，然后报告把长度差设为零时预测出的胜率——也就是"若两个回答一样长，评审会偏好哪个？"的答案。作者报告，这使得通过要求模型写更长答案来刷分变得困难得多，并提高了该基准与 Chatbot Arena 排名的相关性。Arena 的风格控制（[[evaluation/human-evaluation#sec-arena]]）基于同一思想：只要一个干扰特征可测，就能对它建模并加以剔除。

::: quiz
某团队在 $500$ 个人类标注的比较对上验证一个评审：一致率 $78\%$，首位胜率 $0.51$，补白副本被偏爱率为 $72\%$。随后它比较一个简洁模型与一个冗长模型。哪些结论是站得住的？
- [x] 位置偏差对这个评审不构成问题
- [x] 这一比较很可能比人类的判断更偏袒冗长的模型
- [ ] 有 $78\%$ 的一致率，就无需其他检查、可直接用[[#eq-correction]]校正评审的胜率
- [x] 对这两个模型，需要长度控制或长度配平的比较
::: solution
首位胜率 $0.51$ 表明位置偏差很小。补白探针显示出强烈的长度偏好，这是针对简洁模型的不对称误差，因此[[#prop-correction]]的对称校正并不适用：评审的误差率将取决于哪个模型写了更长的答案。要先用回归剔去长度、或只在两个回答长度相近的提示上作比较，结果才谈得上可信。
:::
:::

## 参考引导评审与评审集成 {#sec-improving}

还有两个设计选择，从不同方向改进评审。

**参考答案**对付的是能力。自己解不出一道题的评审，无法可靠区分正确解法与一个自信的错误解法，还容易被回答对自身的论断左右。给出参考答案把任务变成比较，这就容易多了；对答案可验证的任务——数学、代码、抽取——用程序检查更好，评审最好只留给那些无法机械检查的部分。逐题的**评分细则**与检查清单在开放式任务上起同样作用：它们把判断从"这好不好？"换成"这做到了 X、Y、Z 吗？"，更可在复现中检验，也更可审计。

**集成**对付的是噪声。Verga 等（2024）发现，在他们的那些任务上，由来自不同家族的若干较小评审模型组成的**评审团**，比单个大型评审更贴近人类判断，成本更低，对任何一个模型家族的偏向也更少。其中的道理是经典的。

::: proposition 评审的多数投票 {#prop-condorcet}
设 $k = 2m + 1$ 个评审各以概率 $a > \frac12$ 在二元比较中给出正确裁决。

1. 若它们的误差相互独立，多数裁决正确的概率为 $A_k = \sum_{j > m}\binom{k}{j}a^j(1 - a)^{k-j}$，当 $k = 3$ 时它等于 $a + a(1 - a)(2a - 1) > a$，且当 $k\to\infty$ 时 $A_k\to1$。
2. 若各评审的裁决完全相同（误差完全相关），则对每个 $k$，多数裁决正确的概率都是 $a$。
:::

::: proof
（1）正确评审的个数服从 $\Bin(k, a)$，多数裁决在正确者超过 $m$ 时正确。$k = 3$ 时：$a^3 + 3a^2(1 - a) = a^2(3 - 2a)$，且 $a^2(3 - 2a) - a = a(3a - 2a^2 - 1) = a(2a - 1)(1 - a)$，在 $\frac12 < a < 1$ 时为正。当 $k\to\infty$ 时，正确评审的比例由大数定律收敛到 $a > \frac12$，故其超过 $\frac12$ 的概率趋于 $1$（**孔多塞陪审团定理**）。（2）若所有裁决都相同，多数裁决就是其中任何一个评审的裁决。
:::

真实的评审介于两者之间：它们的误差正相关，因为它们共享训练数据、推理风格与偏差。因此评审团削减的是误差中独立的部分，留下的正是模拟所展示的共享部分：三个评审共有的长度偏好在投票后依然存在。评审的多样性——不同的家族、不同的提示——正是评审团物有所值的前提。

::: example 三人评审团 {#ex-panel}
三个评审各在 $75\%$ 的比较上正确。若它们的误差相互独立，多数的准确率是多少？又若在固定 $20\%$ 的条目上三个评审同时出错，而在其余条目上每个评审以某个概率独立正确、取该概率使其总体准确率保持 $75\%$，结果如何？
::: solution
独立：$0.75^2(3 - 1.5) = 0.5625\cdot1.5 = 0.844$。共享误差：在没有共享误差的那 $80\%$ 条目上，每个评审须以概率 $c$ 正确，其中 $0.8c = 0.75$，故 $c = 0.9375$；多数的正确概率在那些条目上为 $c^2(3 - 2c) = 0.8789\cdot1.125 = 0.989$，而在共享误差的 $20\%$ 上必然错误。总体为 $0.8\cdot0.989 = 0.791$。相关的部分封顶了收益：无论加多少个评审，评审团都不可能超过 $80\%$。
:::
:::

::: warning 评审同样是优化目标
基于评审的基准一旦成为目标，模型——以及训练模型的人——就会摸评审的喜好。更长的答案、更多的排版、自信的语气、对问题奉承式的复述，都能抬高评审的裁决，却不曾让答案更好。Zheng 等（2024，"Cheating automatic LLM benchmarks"）表明，一个"空模型"——对每条指令都产出同一串没有内容的固定输出、专为利用评审而调教——就能在几个流行的评审基准上取得高胜率。教训不是评审无用，而是它们的裁决是受制于古德哈特定律的代理指标（[[evaluation/evaluation-principles#sec-goodhart]]）：在实际使用的分布上验证它们，用反事实探针审计它们，对抽样保留人工核查，并且绝不要拿评测用的那个评审去做训练目标。
:::

::: history
对生成文本的自动评测始于同参考答案的重合度指标——翻译的 BLEU（Papineni 等，2002）与摘要的 ROUGE（Lin，2004）——随后转向建立在预训练模型之上的学习型指标，如 BERTScore（Zhang 等，2020）与 BLEURT（Sellam 等，2020）。到了指令遵循模型时代，参考答案变得不够用：对一个开放请求存在许多好答案。用强聊天模型做评审在 2023 年初得到探索（例如 Vicuna 评测与 G-Eval，Liu 等，2023），并由 Zheng 等（2023）作了系统检验：他们的 MT-Bench 与对位置、冗长、自我增强偏差的分析定了这一领域的议事日程。Wang 等（2023）表明位置偏差足以颠覆排名；AlpacaEval（2023）及其长度控制版（Dubois 等，2024）、Arena-Hard（Li 等，2024）与 WildBench（Lin 等，2024）使评审基准成为标配；Prometheus（Kim 等，2023）训练了开放权重评审；Panickssery 等（2024）研究了自我偏好；Verga 等（2024）则主张使用评审团。
:::

::: summary
- 模型评审可以逐点、成对、对照参考答案或对照评分细则给回答打分（[[#def-judge]]）；它的提示、推理、解码与解析都是协议的一部分。
- **MT-Bench**（Zheng 等，2023）发现强评审与专家的一致程度几乎就是专家彼此的一致程度（不计平局约 $85\%$ 对 $81\%$），并记录了位置、冗长与自我增强偏差。
- 用反事实探针测量偏差：位置看**首位胜率**、冗长看补白副本、自我偏好看对照人类的比较（[[#def-bias-measures]]）。交换不一致混合了偏差与随机性（[[#prop-inconsistency]]）。
- 在条目层面（一致率与 κ，按类别）和系统层面对照人类标注验证评审。对称误差把胜率向 $\frac12$ 压缩、保持方向，可用 $\hat w = (\hat m - (1 - a))/(2a - 1)$ 校正（[[#prop-correction]]）；长度偏差这类不对称误差可能颠倒排序，需要建模（长度控制）。
- 参考答案与评分细则对付评审的能力上限；多样化评审组成的**评审团**削减独立误差（孔多塞，[[#prop-condorcet]]），却削减不了共享偏差。
- 基于评审的基准是优化目标，会被刷分；要审计它们，并保留人工核查。
:::

## 习题

::: exercise 三取多数 {level=1 check="0.784"}
三个相互独立的评审各以概率 $0.7$ 正确。它们的多数裁决正确的概率是多少（三位小数）？
::: solution
$0.7^3 + 3\cdot0.7^2\cdot0.3 = 0.343 + 0.441 = 0.784$。
:::
:::

::: exercise 校正胜率 {level=1 check="0.66"}
一个对称一致率 $a = 0.75$ 的评审报告胜率 $58\%$。用[[#eq-correction]]估计人类胜率。
::: solution
$\hat w = (0.58 - 0.25)/(1.5 - 1) = 0.33/0.5 = 0.66$。
:::
:::

::: exercise 有偏差评审的不一致性 {level=1 check="0.607"}
按[[#prop-inconsistency]]，位置偏差 $b = 1$ 的评审在一个质量相等的比较对上（$\Delta = 0$）给出不一致裁决的概率是多少？给出三位小数。
::: solution
$\sigma(1) = 0.7311$ 且 $\sigma(-1) = 0.2689$，故 $P_{\text{incons}} = 0.7311^2 + 0.2689^2 = 0.5345 + 0.0723 = 0.607$。
:::
:::

::: exercise 校正的代价 {level=2 check="0.04"}
评审测得的胜率标准误差为 $0.02$，评审的对称一致率 $a = 0.75$ 且完全已知。校正后胜率的标准误差是多少？
::: solution
由[[#prop-correction]]，$0.02/(2\cdot0.75 - 1) = 0.02/0.5 = 0.04$。校正除去偏差，代价是把不确定度翻倍；换成 $a = 0.6$ 的评审，它要放大到五倍。
:::
:::

::: exercise 评审与人类的一致及 κ {level=2 check="0.6"}
在 $200$ 个验证比较对上，人类在 $100$ 个上偏好回答 $1$。评审在 $100$ 个比较对上选回答 $1$，与人类在 $200$ 个中的 $160$ 个一致。计算评审与人类之间的 Cohen's κ。
::: solution
$p_o = 0.8$。两边的边缘分布都是 $\frac12$，故 $p_e = 0.5\cdot0.5 + 0.5\cdot0.5 = 0.5$，从而 $\kappa = (0.8 - 0.5)/0.5 = 0.6$（[[evaluation/human-evaluation#def-kappa]]）。
:::
:::

::: exercise 设计一次偏差审计 {level=2}
你打算用一个模型评审比较两个摘要系统，其中一个与评审由同一个基座模型微调而来。请设计一个几百条条目的审计，在比较开始之前检测出位置偏差、长度偏差与自我偏好。
::: solution
**位置**：每个比较对都按两种次序各运行一次，报告首位胜率及其二项区间；胜率显著高于 $\frac12$ 时，需要按次序平均或交换—判平。**长度**：构造受控对——每篇摘要对阵一个用复述补白、不增新内容的版本，以及一个删去冗余句子的版本——报告更长的版本赢的频率；另外把评审的裁决对真实比较对中的长度差作回归。**自我偏好**：在真实比较对的随机子集上收集人类偏好（最好来自专家、且盲评），把评审对相关系统的胜率与人类的胜率作比较；超出不确定度的超额就是自我偏好（或与该系统相关的其他偏差）；再请一个不同家族的评审可提供对照。审计报告与结果一起发布；一旦发现偏差，就加以控制（按次序平均、长度控制），或改用彼此无关的评审团。
:::
:::

::: exercise 不对称误差颠倒排序 {level=2 check="0.55"}
人类在 $45\%$ 的提示上偏好模型 A 胜于基线。由于 A 写的答案更长，评审对它格外宽容：在人类偏好 A 的比较对上它报告"A"的占 $98\%$，在人类偏好基线的比较对上仍报告"A"的占 $20\%$。计算评审对 A 的胜率（保留两位小数），并说明这一比较会得出什么结论。
::: solution
由全概率公式，$m = 0.98\cdot0.45 + 0.20\cdot0.55 = 0.441 + 0.110 = 0.551$，四舍五入为 $0.55$。尽管人类偏好基线，评审却宣布 A 获胜：这正是[[#prop-correction]]的不对称情形。对称校正只会把事情弄得更糟——它假设两类比较对共用一个一致率——因此补救之道是消除病因（长度控制、长度配平的对），或在验证数据上分别估计两个误差率。
:::
:::

::: exercise 概率加权分数 {level=3}
请评审在 $1$ 到 $5$ 之间给一个回答打分，它在五个评分词元上给出概率 $0.05, 0.10, 0.30, 0.40, 0.15$。（a）计算 arg-max 分数与 G-Eval 期望分数。（b）两个回答的期望分数为 $3.50$ 与 $3.45$、arg-max 分数相同；哪种协议能区分它们？（c）结合校准，解释期望分数为何并非总是更好。
::: solution
（a）arg max 为 $4$。期望：$0.05 + 0.20 + 0.90 + 1.60 + 0.75 = 3.50$。（b）只有期望分数能区分它们；arg-max 评分在短量表上产生许多并列，既浪费信息，又让细微差距不可见。（c）期望分数把评审的概率当作有意义的置信程度、把量表当作等距刻度（$2$ 到 $3$ 的一级等于 $4$ 到 $5$ 的一级）。若评审校准不佳——例如在某些条目上因与质量无关的原因非常自信，或系统性地含糊其辞——期望就继承了这种失校，$3.50$ 对 $3.45$ 这样的小差距反映的可能只是评审表达不确定性的风格而非质量。它们应当像其他任何分数一样对照人类评分来验证，例如比较期望分数、arg-max 分数各自与人类评分的相关。
:::
:::

::: exercise 共享误差下的孔多塞 {level=3 check="0.8"}
推广[[#ex-panel]]：在固定比例 $\rho$ 的条目上，全部 $k$ 个评审一起出错；在其余条目上，每个评审以概率 $c$ 独立正确。证明只要 $c > \frac12$，当 $k\to\infty$ 时多数的准确率就趋于 $1 - \rho$，并计算 $\rho = 0.2$ 时的这一极限。这对扩大同类评审的评审团意味着什么？
::: solution
在共享误差的条目上，多数必然错误。在其余条目上，正确评审的个数服从 $\Bin(k, c)$，当 $c > \frac12$ 时多数正确的概率由[[#prop-condorcet]]趋于 $1$。总体准确率为 $(1 - \rho)A_k(c) + \rho\cdot0\to1 - \rho = 0.8$。增加同类评审只能把独立误差压到零；共享比例 $\rho$ 是一道硬顶。要抬高这道顶，就必须让评审的误差彼此更不相关（不同的模型家族、不同的提示、或能拿到参考答案与工具），这正是多样化评审团的论据。
