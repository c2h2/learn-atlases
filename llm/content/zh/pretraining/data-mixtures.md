经过过滤与去重（[[pretraining/training-data]]）之后，一个预训练团队手头会有一批清洗干净的**领域（domain）**：网页文本、代码、科学论文、书籍、百科全书、数学、对话，以及几十种甚至上百种语言。它们的规模相差几个数量级，每个词元的价值也难以预料。**数据配比（data mixture）**决定模型见到各领域的频率；**调度**或**课程（curriculum）**决定在什么时候见到。两者对训练出的模型能做到什么影响都很大，而且都主要靠实验来确定。

本章把配比精确地表述为领域上的一个采样分布，算出领域权重如何换算成词元数与轮次（epoch），推导多语言数据的温度采样，并把 DoReMi 作为一个学习式配比的例子来介绍。随后转向限制每次大规模训练的配比的那个问题——当高质量数据必须**重复**使用时会发生什么——使用 Muennighoff 等（2023）的经验拟合来处理，最后讲数据顺序：训练末段在高质量数据上退火（annealing）、课程学习，以及合成数据的使用。

## 作为采样分布的数据配比 {#sec-mixture}

::: definition 数据配比 {#def-mixture}
设语料库被划分为$K$个领域，各有$n_1, \dots, n_K$个词元。**数据配比**是一个**领域权重**向量$\mathbf{w} = (w_1, \dots, w_K)$，满足$w_k\ge0$且$\sum_kw_k = 1$。在配比$\mathbf{w}$下用预算$D$个词元训练，意味着期望上有$w_kD$个训练词元来自领域$k$；实践中，每条序列（或文档）以概率$w_k$从领域$k$抽取，领域内则不放回地抽取文档，直到该领域抽完，然后重新洗牌。
:::

**自然配比**$w_k = n_k/\sum_jn_j$让每个词元被抽到的机会均等。任何其他配比都会对某些领域**上采样**、对其余领域**下采样**。

::: proposition 每个领域的轮次 {#prop-epochs}
在配比$\mathbf{w}$与预算$D$下，领域$k$被完整遍历

$$
e_k = \frac{w_kD}{n_k}
$$ {#eq-epochs}

遍（期望意义下）——即它的**轮次**数。当且仅当$\mathbf{w}$是自然配比时，每个领域与任何其他领域被看到的次数完全相同，即对所有$k$有$e_k = D/\sum_jn_j$。$e_k < 1$的领域没有被看完整；$e_k > 1$的领域则被重复。
:::

::: proof
按配比的定义与期望的线性性，从领域$k$抽取的词元数期望为$w_kD$；除以领域大小$n_k$就得到遍历遍数。若$w_k = n_k/N$，其中$N = \sum_jn_j$，则对每个$k$都有$e_k = D/N$。反过来，若所有$e_k$都等于公共值$e$，则$w_k = en_k/D$，对$k$求和得$1 = eN/D$，于是$w_k = n_k/N$。
:::

::: example GPT-3 的配比 {#ex-gpt3}
Brown 等（2020）用来自五个来源的$3000$亿词元训练 GPT-3。他们的表 2.2 列出了下面的大小与权重。用[[#eq-epochs]]计算轮次，并与论文报告的值比较：Common Crawl $0.44$、WebText2 $2.9$、Books1 $1.9$、Books2 $0.43$、Wikipedia $3.4$。

| 来源 | 词元数 | 权重 |
|---|---|---|
| Common Crawl（过滤后） | $4100$亿 | $60\%$ |
| WebText2 | $190$亿 | $22\%$ |
| Books1 | $120$亿 | $8\%$ |
| Books2 | $550$亿 | $8\%$ |
| Wikipedia | $30$亿 | $3\%$ |
::: solution
$e = w\cdot300/n$：Common Crawl $0.6\cdot300/410 = 0.44$；WebText2 $0.22\cdot300/19 = 3.5$；Books1 $0.08\cdot300/12 = 2.0$；Books2 $0.08\cdot300/55 = 0.44$；Wikipedia $0.03\cdot300/3 = 3.0$。大来源与报告的轮次一致；小来源有出入（例如 Wikipedia 算得$3.0$而报告为$3.4$），因为表中的权重和大小都是四舍五入过的，这对小领域影响最大。重要的是其中的模式：占可用词元$82\%$的过滤爬取数据只分到$60\%$的权重、连一遍都没被看完，而小的精选来源却被重复了两三遍。作者提高了他们判断为更高质量的来源的权重，接受了对这些来源的某些过拟合。
:::
:::

LLaMA 系列（Touvron 等， 2023）在$1.4$万亿词元上使用了类似的模式：CommonCrawl 占权重$67\%$、C4 占$15\%$，GitHub、Wikipedia 与书籍各$4.5\%$，arXiv $2.5\%$、Stack Exchange $2\%$；Wikipedia 与书籍大约被看到$2.4$遍和$2.2$遍，其余大约一遍。Llama 3（2024）对其最终配比只按类别描述：大约一半是通用知识，四分之一是数学与推理，$17\%$是代码，$8\%$是多语言文本。

## 选择领域权重 {#sec-weights}

没有理论能给出最优配比；有的是寻找配比的若干条路。

**用消融实验手调。** 传统做法是在候选配比上训练小模型，比较它们在留出领域上的损失与下游基准上的得分。这很昂贵，依赖所选的评测，而且小规模下的结果不一定能迁移到大模型。

**代理模型与回归。** 有几个团队给“损失如何依赖权重”拟合模型：Ye 等（2024）拟合了指数形式的“数据混合定律”（data mixing laws）；RegMix（Liu 等，2024）在随机配比上训练了数百个极小的模型，拟合一个从权重到验证损失的回归，然后选取预测的最优点。这些（截至 2026 年）都是研究方法，结果是在特定数据与规模上报告的。

**鲁棒优化：DoReMi。** Xie 等（2023）提出按“让任何领域都不比参考模型学得太差”来选择权重。

::: algorithm DoReMi（Xie 等，2023） {#alg-doremi}
**输入：**领域$1, \dots, K$；一个在初始配比（例如自然配比）上训练的小型**参考**模型；步长$\eta$；平滑系数$c$；步数$S$。

1. 把$\boldsymbol{\alpha}_0$初始化为均匀分布$\mathbf{u}$，并初始化一个小型**代理（proxy）**模型$\theta_0$（与参考模型同尺寸）。
2. 对$t = 1, \dots, S$：
   1. 采样一个包含每个领域样例的批次。对每个领域$k$，计算**超额损失**$\lambda_t[k]$：对该领域的词元平均$\max\big(\ell_\theta(\text{词元}) - \ell_{\text{ref}}(\text{词元}), 0\big)$。
   2. 用**指数梯度（exponentiated gradient）**上升更新权重：$\alpha'_t[k] = \alpha_{t-1}[k]\exp(\eta\lambda_t[k])$，然后归一化并平滑：$\boldsymbol{\alpha}_t = (1-c)\,\boldsymbol{\alpha}'_t/\sum_j\alpha'_t[j] + c\,\mathbf{u}$。
   3. 对加权损失$\sum_k\alpha_t[k]\,\mathcal{L}_k(\theta)$做一步梯度更新，更新代理模型。
3. **输出**平均权重$\bar{\boldsymbol{\alpha}} = \frac1S\sum_t\boldsymbol{\alpha}_t$，作为训练大模型所用的配比。
:::

指数梯度步是在概率单纯形上优化极小极大问题$\min_\theta\max_{\boldsymbol\alpha}\sum_k\alpha_k(\text{超额损失}_k)$（**Group DRO**，Sagawa 等，2020）的标准做法：代理模型仍然落后于参考模型的领域会按乘性方式获得权重，而平滑让每个权重都不低于$c/K$。容易的领域（已经学得和参考模型一样好）或难到没救的领域（两个模型的损失都很高，因为文本噪声太大）超额损失小、会失去权重，这正是设计意图：超额损失度量的是**可学而尚未学到**的东西。

::: example 一步 DoReMi 更新 {#ex-doremi}
设$K = 3$个领域，当前权重$\boldsymbol{\alpha} = (0.5, 0.3, 0.2)$，超额损失$\boldsymbol\lambda = (0.1, 0.5, 0)$，$\eta = 1$、$c = 10^{-3}$，计算新的权重。
::: solution
$\alpha' = (0.5e^{0.1}, 0.3e^{0.5}, 0.2e^{0}) = (0.5526, 0.4946, 0.2000)$，和为$1.2472$；归一化得$(0.4431, 0.3966, 0.1604)$。平滑：$0.999\cdot(0.4431, 0.3966, 0.1604) + 0.001/3 = (0.4430, 0.3965, 0.1605)$。超额损失最大的第二个领域得到$9.7$个百分点；已经追平参考模型的第三个领域失去$4$个百分点；第一个领域也略微失重，因为权重是相对的。
:::
:::

Xie 等用一个$2.8$亿参数的代理模型为 The Pile 的$22$个领域选择权重，并重新训练了一个$80$亿参数的模型。他们报告每个领域的困惑度都更低——包括被下调权重的领域——平均少样本准确率比使用 Pile 默认权重时高$6.5$个百分点，并用$2.6$倍更少的步数就达到基线的准确率。后续研究发现权重对参考模型与代理尺寸的选择很敏感；截至 2026 年，DoReMi 最好被视为若干研究方法之一，而不是标准步骤。

::: warning 更低的平均损失不等于更好的配比
人们很容易想去选择令各领域平均验证损失最小的配比。但这个目标被验证数据最多、文本最可预测的领域主导，而且它对验证集没有覆盖的能力什么也不说。上调代码权重可能抬高网页文本的损失，却改进推理基准；上调对话这类高熵领域可能抬高所有损失，却让模型作为助手更有用。先确定评测——你在意的留出领域上的损失**加上**下游任务——并预期它们之间存在取舍。
:::

## 语言与温度采样 {#sec-languages}

多语言语料库极端不平衡：英语的词元数可能是斯瓦希里语这类语言的上千倍。自然配比会让低资源语言几乎看不到；均匀配比又要把它们重复几百遍。多语言模型用**温度采样**在两者之间插值。

::: definition 领域的温度采样 {#def-temperature}
给定领域大小$n_k$与指数$\alpha\in[0, 1]$（等价地，温度$\tau = 1/\alpha$），**温度采样**使用权重

$$
w_k(\alpha) = \frac{n_k^{\alpha}}{\sum_jn_j^{\alpha}}.
$$ {#eq-temperature}

$\alpha = 1$给出自然配比，$\alpha = 0$给出均匀配比。XLM-R（Conneau 等，2020）与 mT5（Xue 等，2021）用了$\alpha = 0.3$。
:::

::: proposition 温度采样使配比变平 {#prop-temperature}
对任意两个满足$n_i > n_j$的领域，比值$w_i(\alpha)/w_j(\alpha) = (n_i/n_j)^{\alpha}$关于$\alpha$递增，在$\alpha = 0$处等于$1$，在$\alpha = 1$处等于$n_i/n_j$。因此当$\alpha$从$0$增到$1$时，最小领域的权重非增，最大领域的权重非减。
:::

::: proof
由[[#eq-temperature]]，归一化因子相消，立得比值公式；而$(n_i/n_j)^\alpha = e^{\alpha\ln(n_i/n_j)}$关于$\alpha$递增，因为$\ln(n_i/n_j) > 0$。对最小的领域$s$，$1/w_s(\alpha) = \sum_j(n_j/n_s)^\alpha$是若干个关于$\alpha$非减函数（每个$n_j/n_s\ge1$）之和，故$w_s$非增；对最大领域的论证是对称的，每个比值$n_j/n_\ell\le1$。
:::

::: widget plot
f: 1000^x/(1000^x + 100^x + 1); 100^x/(1000^x + 100^x + 1); 1/(1000^x + 100^x + 1)
x: 0, 1
y: 0, 1
vlines: 0.3
labels: English ($1000$ B tokens); German ($100$ B); Swahili ($1$ B)
caption: 词元数为$1000$、$100$与$1$（十亿词元）的三种语言，在温度采样下的权重随指数$\alpha$的变化（$\alpha = 1$：自然比例；$\alpha = 0$：均匀）。在$\alpha = 0.3$处（竖线），英语分到的样本比例从$91\%$降到$61\%$，斯瓦希里语则从$0.09\%$升到$7.7\%$——在一万亿词元的预算下，这意味着把斯瓦希里语数据重复约$77$遍。
:::

::: example 温度采样造成的重复 {#ex-temperature}
对图中的三种语言与$D = 1$万亿词元的预算，计算$\alpha = 0.3$时的权重以及每种语言的轮次。
::: solution
$1000^{0.3} = 7.943$，$100^{0.3} = 3.981$，$1^{0.3} = 1$；总和为$12.924$，于是$\mathbf{w} = (0.6146, 0.3080, 0.0774)$。由[[#eq-epochs]]算轮次：英语$0.6146\cdot1000/1000 = 0.61$，德语$0.3080\cdot1000/100 = 3.1$，斯瓦希里语$0.0774\cdot1000/1 = 77$。七十七遍的重复远超重复数据的价值（[[#sec-epochs]]），这正是后来的多语言工作给每种语言的轮次数加上限的原因；Chung 等（2023）提出了“UniMax”采样：在满足最大轮次上限的前提下尽可能均匀。
:::
:::

在模型尺寸固定的情况下，增加语言本身也有代价，Conneau 等（2020）称之为**多语言的诅咒**（curse of multilinguality）：语言数量超过某个程度后，每种语言——包括高资源语言——的表现都会下降，因为各语言在争抢容量，而低资源语言则从迁移中受益。这个平衡随模型尺寸移动。

## 轮次与重复 {#sec-epochs}

高质量数据比算力先用完。计算最优训练（[[scaling/compute-optimal-training]]）建议每参数约$20$个词元（Hoffmann 等，2022），所以一个$700$亿参数的模型想要$1.4$万亿词元，而如今模型常常在远多于这个数的词元上训练。最干净的数据——精选来源、网页中得分最高的那部分——只占总量的一小部分（[[pretraining/training-data#ex-funnel]]）。提高它们的权重就意味着重复它们。重复到底值多少？

Muennighoff 等（2023）用最多$1500$个轮次的重复数据训练了几百个至多$90$亿参数的模型，并拟合出一个修正的缩放定律：重复的词元比新鲜的词元不值钱。

::: proposition 重复下的有效数据（经验拟合） {#prop-effective-data}
Muennighoff 等把在$U$个唯一词元上重复$e$轮（$R = e - 1$次重复）的训练，建模为等价于在

$$
D' = U + U R^\ast\big(1 - e^{-R/R^\ast}\big)
$$ {#eq-effective}

个唯一词元上训练，其中拟合常数$R^\ast\approx15.4$。这个表达式有三个性质：

1. 当$R\ll R^\ast$时，$D'\approx U(1 + R) = Ue$：早期的重复几乎与新鲜数据等值；
2. $D'$随$R$增加，但增量几何衰减：第$R$次重复贡献$U R^\ast(1 - e^{-1/R^\ast})e^{-(R-1)/R^\ast}$；
3. 对所有$R$都有$D' < U(1 + R^\ast)$：无论数据被重复多少遍，其价值至多是唯一数据量的$1 + R^\ast\approx16.4$倍。
:::

::: proof
这个公式是经验拟合而不是定理；三个性质由它直接推出。(1) 由泰勒展开，$1 - e^{-x} = x - x^2/2 + O(x^3)$，于是$UR^\ast(1 - e^{-R/R^\ast}) = UR - UR^2/(2R^\ast) + \dots$，价值的相对损失约为$R/(2R^\ast)$。(2) 从$R - 1$到$R$的增量为$UR^\ast(e^{-(R-1)/R^\ast} - e^{-R/R^\ast}) = UR^\ast(1 - e^{-1/R^\ast})e^{-(R-1)/R^\ast}$，是公比为$e^{-1/R^\ast} < 1$的等比数列。(3) 对每个有限的$R$，$1 - e^{-R/R^\ast} < 1$。
:::

::: widget plot
f: 1 + R*(1 - exp(-(x - 1)/R)); x
x: 1, 64
y: 0, 30
sliders: R=15.4:2:40:0.2
labels: effective data $D'/U$; unique data $e$
caption: 由[[#eq-effective]]得到的有效数据$D'/U$随轮次$e$的变化，取拟合值$R^\ast = 15.4$（滑块$R$）。大约在$4$轮之前曲线贴着对角线——重复数据几乎和新数据一样好。到$16$轮时，一个重复词元平均只值约三分之二个新词元，曲线逐渐压平趋向$1 + R^\ast$。这个拟合来自至多$90$亿参数的模型与特定数据；常数只能作参考。
:::

论文的头条结论是：训练到大约$4$轮以内，损失与在同样数量唯一词元上训练几乎相同；而轮次再多，额外算力的价值就衰减到接近零。论文还报告：用代码补足，或放松过滤器，是延长有限自然语言数据供应的有效办法。这些结论针对损失和它们测过的基准；大量重复小来源还会提高对这些来源的记忆化，这对隐私与版权都很要紧（[[pretraining/training-data#sec-rights]]）。

::: example 重复划算吗？ {#ex-repeat}
一个团队有$1000$亿词元的高质量文本。用$R^\ast = 15.4$的[[#eq-effective]]，$4$轮和$16$轮各相当于多少唯一数据？相对新鲜数据，两种情况下各“浪费”了多少算力？
::: solution
四轮：$R = 3$，$D' = 100 + 100\cdot15.4\cdot(1 - e^{-3/15.4}) = 100 + 1540\cdot0.1770 = 372.6$（亿），而看到的有$400$亿：$93\%$的价值，$7\%$的浪费。十六轮：$R = 15$，$D' = 100 + 1540\cdot(1 - e^{-0.974}) = 100 + 1540\cdot0.6224 = 1058.6$（亿），而看到的有$1600$亿：$66\%$的价值，$34\%$的浪费。四轮的优质数据多半胜过得四倍数量的平庸数据的一轮；十六轮则多半不行。
:::
:::

### 配比的代码实现 {#sec-code}

下面的程序为一个假设的配比计算每个领域的轮次，展示采样流的实际比例如何逼近权重，施加温度采样，并把[[#eq-effective]]列成表。

```python
import math, random

# 1. 一个配比：领域大小（十亿词元）与采样权重
sizes   = {"web": 2000.0, "code": 300.0, "papers": 60.0, "books": 25.0, "wiki": 20.0}
weights = {"web": 0.70, "code": 0.15, "papers": 0.06, "books": 0.05, "wiki": 0.04}
D = 1000.0                                          # 词元预算（十亿）
for k in sizes:
    print(f"{k:7s} weight {weights[k]:.2f}  tokens {weights[k] * D:6.0f}B  epochs {weights[k] * D / sizes[k]:.2f}")

# 2. 为一个序列流采样文档：实际比例会波动
rng = random.Random(0)
names, w = list(weights), list(weights.values())
for n in [100, 10_000, 1_000_000]:
    draws = rng.choices(names, weights=w, k=n)
    print(f"n = {n:>9,}: " + "  ".join(f"{k} {draws.count(k) / n:.4f}" for k in names))

# 3. 语言的温度采样：p_k 正比于 n_k^alpha
n_lang = {"en": 1000.0, "de": 100.0, "sw": 1.0}     # 可用的词元数（十亿）
for a in [1.0, 0.7, 0.3, 0.0]:
    z = sum(v ** a for v in n_lang.values())
    print(f"alpha = {a}: " + ", ".join(f"{k} {v ** a / z:.4f}" for k, v in n_lang.items()))

# 4. 重复下的有效数据（Muennighoff 等 2023 的拟合，R* = 15.4）
def effective(U, epochs, Rstar=15.4):
    R = epochs - 1                                  # 首遍之外的重复次数
    return U + U * Rstar * (1 - math.exp(-R / Rstar))
for ep in [1, 2, 4, 8, 16, 40, 100]:
    Deff = effective(100.0, ep)
    print(f"{ep:3d} epochs of 100B unique: {100 * ep:6.0f}B seen, worth {Deff:6.1f}B unique ({Deff / (100 * ep):.0%})")
```

## 数据顺序：退火与课程 {#sec-order}

到目前为止，配比在训练中保持不变。但它未必需要不变。

::: definition 退火阶段 {#def-annealing}
**退火**（或称**冷却**、**中期训练**）阶段是预训练的最后一段，通常占词元预算的几个百分点。其间学习率向零衰减，同时数据配比转向被认为质量最高、或与目标能力最相关的领域——精选文本、数学、代码、类指令数据。
:::

退火融合了两种效应。学习率衰减本身会在训练末段大幅压低损失（[[neural-networks/optimisers#sec-schedules]]）；预热–稳定–衰减调度（[[pretraining/training-loop]]）又使得很容易从一个稳定检查点分支出若干个衰减阶段。而且因为学习率正在下降，最后见到的数据对最终权重的影响是持久的、不会被覆写的。Llama 3 报告（2024）描述了在少量高质量代码与数学上退火：这改进了其$80$亿参数模型的数学基准表现，而对$4050$亿参数的模型影响可以忽略；该报告还用短的退火试验作为廉价手段来评估候选数据集的价值。MiniCPM（Hu 等，2024）与 OLMo 2（2024）也描述了在衰减阶段使用高质量数据。由于退火数据是为帮助特定任务而选的，它们抬高了污染的风险（[[pretraining/training-data#sec-contamination]]）：训练后期几千条类似基准的样例就能让分数明显移动。

**课程。** **课程学习**（curriculum learning）把训练数据按由易到难排序（Bengio 等，2009）。对语言模型预训练，按难度排课程据的证据好坏参半：洗牌数据仍是默认做法，而且报告的特定顺序的收益往往很小或难以复现。两种顺序被广泛使用。一种是训练期间逐步增加**序列长度**——多数模型在几千词元的上下文上预训练，到临近结束才扩展到更长的上下文（[[pretraining/continued-pretraining]]），因为注意力开销随长度增长，而长文档稀缺。另一种是**配比分阶段改变**，退火阶段是主要例子。对这些顺序为什么有效，所知少于它们在报告的实验中确实有效这一事实。

## 合成数据 {#sec-synthetic}

预训练数据中由其他模型撰写的比例在不断上升。做法包括生成“教科书式”的讲解与练习题（phi 系列，Gunasekar 等，2023，在过滤后的网页数据加合成教科书上训练）、把网页**改写**成更干净的风格，如百科条目或问答对（Maini 等（2024）报告这样训练快了约三倍），以及生成代码、数学与翻译并辅以自动验证。

合成数据能提升质量、填补空白，但带来三种风险。它们会输入生成模型的错误与偏见。它们会收窄多样性，因为一个模型的采样集中在它可能产出的内容上。而递归训练——模型训练在“训练于模型输出的模型”的输出上——会使分布退化、丢掉分布的尾部；Shumailov 等（2024）称之为**模型坍缩**（model collapse）。后续工作（Gerstgrasser 等，2024）发现，当合成数据与原始真实数据并存累积、而不是取而代之时，坍缩可以避免。随着网络本身越来越被生成文本充斥，辨别并加权合成内容已成为过滤的一部分（[[pretraining/training-data#sec-filtering]]）。截至 2026 年，合成数据在大规模下有多大帮助、该占多大比例，仍是一个开放的经验问题。

::: example 混合合成数据 {#ex-synthetic}
一次$D = 2$万亿词元的训练，用$70\%$的网页数据（可用$5$万亿）、$15\%$的代码（$0.6$万亿）与$15\%$按需生成的合成改写。若每个合成词元只使用一次，需要生成多少词元？这次训练把网页和代码各看多少轮？若生成器每个词元花费$2N_g$次浮点运算、$N_g = 8\times10^9$个参数，生成的代价是多少？
::: solution
合成：$0.15\cdot2\times10^{12} = 3\times10^{11}$个词元。网页：$0.7\cdot2/5 = 0.28$轮；代码：$0.15\cdot2/0.6 = 0.5$轮。生成代价为$2\cdot8\times10^9\cdot3\times10^{11} = 4.8\times10^{21}$次浮点运算（忽略提示的处理）——约相当于一个$70$亿参数模型在$2$万亿词元上$6ND$训练算力的$5.7\%$（$6\cdot7\times10^9\cdot2\times10^{12} = 8.4\times10^{22}$；见[[pretraining/training-loop#prop-6nd]]）。合成数据不是免费的，但在这个规模上，其代价不大。
:::
:::

::: history
给精选来源更高的权重，至少可以追溯到 GPT-2 的 WebText（2019）与 GPT-3（Brown 等，2020），后者的配比表确立了“重复小而高质量的领域”的模式。Arivazhagan 等（2019）研究了大规模多语言翻译中的温度采样；XLM-R（Conneau 等，2020）与 mT5（Xue 等，2021）采用了$\alpha = 0.3$；Chung 等（2023）提出了 UniMax。课程学习由 Bengio 等（2009）形式化。Xie 等（2023）提出 DoReMi，其基础是 Group DRO（Sagawa 等，2020）；Muennighoff 等（2023）测量了重复数据的价值。退火与多阶段配比在 MiniCPM（2024）、Llama 3（2024）与 OLMo 2（2024）等报告中被详细描述；合成数据随 phi 系列（2023）与改写方法（2024）进入预训练，对模型坍缩的研究（Shumailov 等，2024）也随之而来。
:::

::: summary
- **数据配比**是领域上的一个分布$\mathbf{w}$；领域$k$获得$w_kD$个词元、被看$e_k = w_kD/n_k$遍。只有自然配比让每个词元拥有相同的轮次。
- 大规模训练会给小而高质量的领域更高权重并重复它们（GPT-3：Wikipedia 约三遍，爬取数据不足一遍）。
- 权重的选择办法有小模型上的消融、拟合的回归，或像 **DoReMi** 这样的鲁棒优化：它上调相对参考模型超额损失高的领域（属研究阶段，对设置敏感）。
- **温度采样**$w_k\propto n_k^\alpha$在语言的自然配比与均匀配比之间插值（XLM-R 与 mT5 用$\alpha = 0.3$）；低$\alpha$会造成小语言的大量重复。
- 重复数据的价值逐渐流失：在 Muennighoff 等（2023）的拟合中，约$4$轮以内几乎与新鲜数据等值，总价值以唯一数据的约$16$倍为上界。
- 配比可以随训练改变：在学习率衰减时在高质量数据上**退火**已是标准做法；难度课程的证据好坏参半；序列长度分阶段增长。**合成数据**在报告的案例中有用，但若取代真实数据，则有误植错误、失去多样性与坍缩的风险。
:::

::: exercise 温度采样权重 {level=1 check="0.0774"}
三种语言的词元数分别为$1000$、$100$和$1$（单位：十亿词元），在$\alpha = 0.3$的温度采样下，最小的那个语言的权重是多少（保留四位小数）？
::: solution
$1/(1000^{0.3} + 100^{0.3} + 1) = 1/(7.943 + 3.981 + 1) = 1/12.924 = 0.0774$。

::: exercise 自然配比 {level=1 check="0.125"}
三个领域分别有$5000$、$3000$和$2000$亿词元，训练在自然配比下持续$1250$亿词元。每个领域被看多少轮？
::: solution
自然权重为$0.5, 0.3, 0.2$；每个领域都获得$e = 125/1000 = 0.125$轮（词元数均按十亿计；[[#prop-epochs]]）。
:::

::: exercise 有效数据 {level=2 check="662.5"}
用$R^\ast = 15.4$的[[#eq-effective]]，$1000$亿词元的$8$轮相当于多少十亿词元的唯一数据？保留一位小数。
::: solution
$R = 7$：$100 + 1540\cdot(1 - e^{-7/15.4}) = 100 + 1540\cdot(1 - 0.63474) = 100 + 562.5 = 662.5$（十亿），占所见$800$十亿的$83\%$。

::: exercise 一步 DoReMi 更新 {level=2 check="0.4"}
两个领域的权重为$(0.5, 0.5)$，超额损失为$(0, \ln1.5)$。取$\eta = 1$、不平滑，计算第一个领域的新权重。
::: solution
$\alpha' = (0.5, 0.5\cdot1.5) = (0.5, 0.75)$，和为$1.25$，权重变为$(0.4, 0.6)$。第一个领域的权重是$0.4$。
:::

::: exercise 选择 alpha 以限制重复 {level=2}
对[[#ex-temperature]]的三种语言与$D = 1$万亿词元，数值求出（保留两位小数）使最小语言至多看$4$遍的最小$\alpha$。此时英语分到多大比例？
::: solution
需要$w_{\text{sw}}(\alpha)\cdot1000\le4$，即$1/(1000^\alpha + 100^\alpha + 1)\le0.004$，亦即$1000^\alpha + 100^\alpha\ge249$。$\alpha = 0.75$时：$177.8 + 31.6 = 209.4$，太小；$\alpha = 0.78$时：$218.8 + 36.3 = 255.1$，够了；$\alpha = 0.77$时：$204.2 + 34.7 = 238.9$，不够。所以$\alpha\approx0.78$，此时$w_{\text{en}} = 218.8/256.1 = 0.854$。限制重复会把配比逼得接近自然配比，小语言只剩$0.4\%$的数据；UniMax 式的采样则直接钉住上限，并把剩余预算尽可能均匀地摊开。
:::
:::

::: exercise 重复数据的上界 {level=2 check="16.4"}
按[[#prop-effective-data]]，在$R^\ast = 15.4$下，一个被重复的数据集最多值其唯一数据量的多少倍？
::: solution
$D' < U(1 + R^\ast) = 16.4\,U$；只有当重复次数趋于无穷时才逼近这个上界。
:::
:::

::: exercise 指数梯度更新停留在单纯形上 {level=3}
证明[[#alg-doremi]]的 DoReMi 更新总是产生每个分量至少$c/K$的概率向量；并证明在没有平滑时，$\log(\alpha_t[i]/\alpha_t[j])$恰好变化$\eta(\lambda_t[i] - \lambda_t[j])$。解释第二个事实。
::: solution
$\alpha'_t[k] > 0$，因为它是正的权重乘以指数；除以总和得到概率向量$\mathbf{p}$；$(1-c)\mathbf{p} + c\mathbf{u}$是两个概率向量的凸组合，因而是概率向量，且每个分量至少$c\cdot1/K$。没有平滑时，$\alpha_t[i]/\alpha_t[j] = \alpha_{t-1}[i]e^{\eta\lambda_t[i]}/(\alpha_{t-1}[j]e^{\eta\lambda_t[j]})$，因为归一化因子相消，所以对数比变化$\eta(\lambda_t[i] - \lambda_t[j])$。因此权重相当于对$\eta$倍累计超额损失取 softmax：一个持续落后于参考模型的领域会以指数速度获得权重，这正是需要平滑和跨步平均、以防最终配比塌缩到单一领域的原因。
:::
:::

::: exercise 数据预算规划 {level=3}
一个团队将在$D = 3$万亿词元上训练一个$300$亿参数的模型。过滤后可用：$8$万亿网页词元，其中得分最高的$1.5$万亿是“高质量”；$0.8$万亿代码；$0.1$万亿精选（论文、书籍、百科）；$0.05$万亿数学。为一个$2.85$万亿词元的主阶段和一个$0.15$万亿词元的退火阶段提出一个配比，计算整个训练中每个来源的轮次，并用[[#prop-effective-data]]论证你的选择。（合理答案很多。）
::: solution
一个方案。主阶段（$2.85$万亿）：高质量网页$45\%$（$1.28$万亿），其余网页$30\%$（$0.86$万亿），代码$17\%$（$0.48$万亿），精选$5\%$（$0.14$万亿），数学$3\%$（$0.086$万亿）。退火（$0.15$万亿）：高质量网页$40\%$（$0.06$万亿），精选$25\%$（$0.0375$万亿），数学$20\%$（$0.03$万亿），代码$15\%$（$0.0225$万亿）。整个训练的轮次：高质量网页$(1.28 + 0.06)/1.5 = 0.90$；其余网页$0.86/6.5 = 0.13$；代码$(0.48 + 0.0225)/0.8 = 0.63$；精选$(0.14 + 0.0375)/0.1 = 1.8$；数学$(0.086 + 0.03)/0.05 = 2.3$。每个来源都远低于[[#eq-effective]]开始明显折价重复的约$4$轮，而精选与数学数据相对其自然份额被上调了$20$到$30$倍。退火配比把最有价值的数据集中在衰减的学习率使其影响持久的地方。团队实际会用小规模消融检验这个选择，并保持退火数据对其基准的去污染。
:::
:::

::: exercise 批次中的采样噪声 {level=3}
一个$400$万词元的批次由$2{,}000$条$2{,}048$词元的序列组成，每条以概率$w_k$独立地从某个领域抽取。对$w = 0.05$的领域，计算它在批次中所占比例的均值与标准差，以及该比例超过$6\%$的概率（用正态近似）。预先洗牌一个固定的词元流会如何改变这一点？
::: solution
批次中来自该领域的序列数服从 Binomial$(2000, 0.05)$：均值$100$，标准差$\sqrt{2000\cdot0.05\cdot0.95} = 9.75$，于是所占比例的均值为$5\%$、标准差为$0.49$个百分点。比例超过$6\%$意味着多于$120$条序列，$z = (120.5 - 100)/9.75 = 2.10$，概率约$0.018$——大约五十个批次里有一个。预先洗牌一个固定流并不消除单个批次的随机性（它仍是随机样本），但保证整个训练中每个领域恰好贡献计划的词元数，也不会有领域过早或过晚被抽干；分层构批（每个批次中每个领域固定序列数）才能真正消除逐批波动。
:::
:::
