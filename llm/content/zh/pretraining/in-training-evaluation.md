一次预训练运行持续数周，花费相当于一家小公司的预算，它的结果不能只在结束后才来判断。团队会持续评测：验证损失告诉他们模型是否还在学习，下游探测告诉他们学的是不是对的东西，中间检查点之间的比较则决定要不要改变数据配比、降低学习率或停下来。同样的测量取自不同规模的模型，就是缩放定律（[[scaling/scaling-laws]]）以及"能力是否随规模**涌现**"这一争论的原材料。

本章讲解预训练期间应当测量什么、又该在多大程度上相信它。内容包括验证损失与困惑度（含验证估计的标准误差）；用似然打分对基础模型做下游评测，以及它的格式与噪声；平滑下降的损失与看似突然出现的这两种现象之间的关系；还有 Wei 等（2022）与 Schaeffer 等（2023）之间关于涌现能力的争论，两边的证据都会呈现。对成品模型的评测——基准、人类评审与大模型评审、统计方法——是[[evaluation]]课程的主题。

## 验证损失 {#sec-validation}

预训练期间信息量最大的单个数字，是留出文本上的损失。

::: definition 验证损失 {#def-validation}
**验证集**是一组固定的文档，已从训练中排除（并与训练数据去重，[[pretraining/training-data#sec-dedup]]），通常按领域划分。一个检查点的**验证损失**是它在这些词元上的平均下一词元交叉熵 $\hat{\mathcal L} = -\frac1n\sum_{i=1}^n\log p_\theta(x_i\mid x_{<i})$；它的**困惑度**是 $e^{\hat{\mathcal L}}$；它的**每字节比特数**是 $\hat{\mathcal L}/\ln2$ 乘以每字节词元数（[[pretraining/pretraining-objectives#prop-compression]]）。
:::

验证损失作为诊断手段，在三个方面优于训练损失。它在每个检查点都在同一批数据上测量，所以它的变化不会与训练批次不断变动的难度混在一起。它能暴露对重复数据的过拟合（[[pretraining/data-mixtures#sec-epochs]]）。而当它按领域分开——网页文本、代码、数学、每种语言、留出的书籍——它显示出配比中哪些部分在改善。Paloma（Magnusson 等，2023）这类多领域困惑度评测套件就是为此而造的。有两点注意事项：只有分词器相同的模型之间损失才可比（否则请用每字节比特数）；而泄漏进训练的验证集——通过重复，或通过包含它的后续爬取——会悄无声息地变成一种训练损失的测量。

::: proposition 验证损失的标准误差 {#prop-se}
设验证集由 $m$ 篇相互独立的文档组成，文档 $j$ 有 $n_j$ 个词元、损失总和 $S_j$，并令 $\hat{\mathcal L} = \sum_jS_j/\sum_jn_j$。当 $m$ 较大时，$\hat{\mathcal L}$ 的标准误差近似为

$$
\operatorname{se}(\hat{\mathcal L})\approx\frac{1}{\bar n\sqrt m}\sqrt{\frac{1}{m-1}\sum_{j=1}^m\big(S_j - \hat{\mathcal L}n_j\big)^2},\qquad\bar n = \frac1m\sum_jn_j.
$$

此外，若这 $n = \sum_jn_j$ 个词元的词元损失相互独立、标准差为 $\sigma$，该式会化为 $\sigma/\sqrt n$；但同一篇文档内的词元损失正相关，所以文档级的公式才是诚实的那一个，而且它通常更大。
:::

::: proof
$\hat{\mathcal L}$ 是逐文档两个样本均值 $\bar S/\bar n$ 的比率估计。由 delta 方法，$\bar S/\bar n - \mathcal L\approx\frac{1}{\bar n}\big(\bar S - \mathcal L\bar n\big) = \frac{1}{\bar n}\cdot\frac1m\sum_j(S_j - \mathcal Ln_j)$，它是 $m$ 个均值为零的独立项的平均；其标准差为 $\frac{1}{\bar n\sqrt m}$ 乘以 $S_j - \mathcal Ln_j$ 的标准差，后者用样本公式估计，其中 $\hat{\mathcal L}$ 代替 $\mathcal L$。若所有词元损失独立、方差为 $\sigma^2$，则 $\Var(S_j - \mathcal Ln_j) = n_j\sigma^2$；当长度相等、$n_j = \bar n$ 时，表达式化为 $\sigma\sqrt{\bar n}/(\bar n\sqrt m) = \sigma/\sqrt{\bar nm} = \sigma/\sqrt n$。文档内的正相关使 $\Var(S_j)$ 大于 $n_j\sigma^2$。
:::

::: example 验证集要多大？ {#ex-validation-size}
设每词元损失的标准差 $\sigma\approx2.5$ nats。假设由于文档内相关，文档级方差是独立词元情形被放大 $4$ 倍的结果。要把标准误差压到 $0.001$ nats——足以分辨检查点之间 $0.003$ 的差异——需要多少词元？
::: solution
若词元独立，$\sigma/\sqrt n = 0.001$ 需要 $n = (2.5/0.001)^2 = 625$ 万词元。方差放大 $4$ 倍，同样的 $n$ 下标准误差翻倍，所以 $n = 4\cdot6.25 = 2500$ 万词元。评测 $2500$ 万词元花费 $2N\cdot2.5\times10^7$ FLOPs，对 $70$ 亿参数的模型是 $3.5\times10^{17}$ FLOPs——在[[pretraining/training-loop#ex-mfu]]的集群上大约一秒，每隔几千步做一次的话微不足道。
:::
:::

**损失曲线能告诉你什么、不能告诉你什么。**一次配置良好的运行，其验证损失大致按词元数的幂律下降，在学习率或数据改变处出现起伏。曲线的形状强烈依赖调度：余弦调度下，损失随着学习率衰减持续改善；而预热–平稳–衰减调度下，损失在平稳阶段进入平台、在末尾衰减阶段急剧下降（[[pretraining/training-loop#sec-schedules]]）。因此 WSD 运行的中间检查点会**低估**同一次运行若在当时进入衰减所能达到的水平——这正是需要预测时，团队评测分出衰减段的模型、而不是原始平稳阶段检查点的原因。用运行内的曲线拟合缩放定律的团队必须把这一点考虑进去。

## 基础模型的下游探测 {#sec-probes}

预训练的基础模型没有被教过听从指令，所以评测靠打分，而不是提问。标准做法是比较模型赋予候选答案的概率。

::: definition 基于似然的多选题打分 {#def-mc-scoring}
给定上下文 $c$（常带几个已解答的例子，即**少样本**）与候选续写 $a_1, \dots, a_K$，模型的选择是

$$
\hat k = \arg\max_k\ \frac{1}{\lambda(a_k)}\sum_{t=1}^{\lvert a_k\rvert}\log p_\theta\big(a_{k,t}\mid c, a_{k,<t}\big),
$$

其中 $\lambda(a_k)$ 是一个**长度归一化**：可以是 $1$（原始对数似然）、$a_k$ 的词元数、字符数或字节数。在**完形填空式**中，候选就是答案文本本身；在**选择题式**中，上下文列出标有 A、B、C、D 的选项，候选是单个词元 "A"、"B"、"C"、"D"。
:::

这两种形式在训练过程中的表现大不相同。完形填空式从早期检查点起就能工作，因为它只要求模型把正确答案找成更可能的续写。带字母的形式要求模型理解"带标签选项"这一约定，并把自己的知识映射到一个字母上；小型或早期模型常常在此得随机水平，哪怕完形填空式已经显示它们知道答案。因此 OLMES（Gu 等，2024）这类面向基础模型的评测规范会规定何时使用哪种形式；FineWeb 的消融实验（Penedo 等，2024）挑选的基准与形式要能给出"早期信号"——不同数据训练出的小模型之间清晰、低噪声的差异。

::: example 用似然选答案 {#ex-mc}
对上下文 "The capital of Australia is"，模型给各候选的总对数概率为："Sydney"（$2$ 词元、$6$ 字符）$-4.1$；"Canberra"（$3$ 词元、$8$ 字符）$-4.8$；"Melbourne"（$2$ 词元、$9$ 字符）$-6.0$。不归一化、按词元归一化、按字符归一化分别选中哪个答案？
::: solution
原始打分：Sydney（$-4.1$）胜 Canberra（$-4.8$）。按词元：Sydney $-2.05$，Canberra $-1.60$，Melbourne $-3.00$：Canberra 胜。按字符：Sydney $-0.683$，Canberra $-0.600$，Melbourne $-0.667$：Canberra 胜。较长的答案仅仅因为词元多，就积累了更多负对数概率；归一化纠正了这一点，但归一化方式的选择会改变结果，而基准分数只有在相同约定下才可比。
:::
:::

### 基准有多吵？ {#sec-noise}

$n$ 道题的基准测出的准确率带有抽样误差。若模型在这类问题上的"真实"准确率为 $p$，观察到的分数是一个二项比例，标准误差为 $\sqrt{p(1-p)/n}$。

::: widget distribution
dist: binomial

a: 280
b: 320
normal: true
caption: 真实准确率为 $60\%$ 的模型在 $500$ 道题的基准上的答对题数：标准差为 $\sqrt{500\cdot0.6\cdot0.4} = 11$ 道题，即 $2.2$ 个百分点。在这样的基准上相差两分的两个检查点，可能根本没有任何差别。改变 $n$，看看要分辨一分的差距需要多少道题。
:::

::: example 比较两个检查点 {#ex-paired}
检查点 A 与 B 在同样的 $1000$ 道题上得 $59.6\%$ 与 $60.9\%$。若两个分数相互独立，差的标准误差是多少？为什么配对的标准误差要小得多？
::: solution
若独立，每个分数的标准误差为 $\sqrt{0.62\cdot0.38/1000}\approx0.0153$，差的标准误差为 $\sqrt2\cdot0.0153 = 0.022$：$1.3$ 个百分点的提升完全落在噪声之内。但两个检查点答的是**同一批**题，而且绝大多数题目上两者一致，所以抽到哪些题目带来的波动相互抵消。配对的标准误差由每题之差 $d_i\in\{-1, 0, 1\}$ 按 $\operatorname{sd}(d)/\sqrt n$ 计算；在[[#sec-code]]的模拟中，两个检查点在约 $85\%$ 的题目上一致，它为 $0.008$，于是提升为 $1.6$ 倍标准误差——值得注意，但不足为凭。（McNemar 检验（[[ml-fundamentals/evaluation-metrics#prop-mcnemar]]）把这一比较形式化了。）
:::
:::

还有第二个噪声来源。同一运行的相邻检查点之间分数的差异，比它们的损失差异所暗示的更大，因为权重的小幅变化会翻转边缘题目的答案；Madaan 等（2024）在常见基准上测量了这种不同随机种子之间、相邻检查点之间的方差，发现它与许多论文报告的改进幅度相当。在几个相邻检查点上取平均、使用正确答案的概率这类连续指标、优先选择题量大的基准，都能减小它。

## 平滑的损失，突然的能力 {#sec-emergence}

随着算力增长，验证损失平滑而可预测地下降。然而在有些任务上，规模递增的模型的准确率一直停在随机水平附近，随后陡然上升。这两个观察都很稳健；有争议的是如何解释它们。

::: definition 涌现能力（Wei 等，2022） {#def-emergent}
Wei 等把一种能力称为**涌现的**，如果小模型不具备而大模型具备——也就是说，若某任务上的表现在低于某个规模的模型上接近随机水平、超过该规模后远高于随机水平，因而无法由小模型表现外推得到。
:::

Wei 等（2022）跨多个模型家族，从 BIG-Bench 及其他基准收集了许多具有这种模式的少样本任务——多位数算术、转写为国际音标、单词拼字还原、一些多任务知识与推理基准——转变通常发生在 $10^{22}$ 到 $10^{24}$ 训练 FLOPs 之间。他们还注意到，一些提示技术（如思维链提示）只有在超过某个规模后才有帮助。他们主张，涌现意味着进一步扩展规模可能解锁无法预见的能力，这对机遇与风险都有影响。

Schaeffer、Miranda 与 Koyejo（2023）则认为，这种表面上的涌现很大程度上是**度量**的产物。如果一个任务按精确匹配（exact match）打分——答案的每个词元都必须正确——那么逐词元准确率的平滑改善就会变成一条陡峭的曲线。

::: proposition 精确匹配锐化平滑的改善 {#prop-exact-match}
设模型独立地以概率 $p$ 正确产出答案的 $L$ 个词元中的每一个。那么它的精确匹配准确率为 $p^L$，而答对词元数的期望是 $Lp$。作为 $\log p$（或 $p$ 对其平滑依赖的任何量）的函数，$p^L$ 是它的 $L$ 倍指数；对大的 $L$，直到 $p$ 接近 $1$ 之前它都接近 $0$：它对 $p$ 的导数 $Lp^{L-1}$，在 $p = 1$ 处至多为线性度量导数的 $L$ 倍，而当 $p$ 远离 $1$ 时指数级地小。
:::

::: proof
精确匹配要求 $L$ 个独立的词元全部正确，其概率为 $p^L$；由线性性，答对词元数的期望为 $Lp$。$\log(p^L) = L\log p$。$p^L$ 的导数是 $Lp^{L-1}$，它在 $p = 1$ 处等于 $L$；当 $p\le1-\delta$ 时至多为 $L(1-\delta)^{L-1}\le Le^{-\delta(L-1)}$。
:::

::: widget plot
f: (1/(1 + exp(-(x - 21))))^L; 1/(1 + exp(-(x - 21)))
x: 17, 27
y: 0, 1
sliders: L=8:1:30:1
labels: exact match on an $L$-token answer, $p^L$; per-token accuracy $p$
caption: 逐词元准确率 $p$ 随训练算力的 $\log_{10}$ 平滑上升（这里是中心在 $10^{21}$ FLOPs 的 logistic 曲线），以及它对 $L$ 词元答案所隐含的精确匹配准确率 $p^L$。$L = 1$ 时两者重合；$L$ 增大时，精确匹配在更长的时间里贴近零，然后急剧爬升，看上去"涌现"了——尽管模型身上没有发生任何不连续的事。这就是 Schaeffer 等（2023）论证的核心。
:::

Schaeffer 等从三个方面支持这一论证。对某一个模型家族的算术任务改用连续度量（词元编辑距离）重新打分，陡峭的曲线就变平滑了。对 BIG-Bench 的元分析发现，被报告为涌现的任务集中在少数不连续度量上，主要是精确字符串匹配与选择题给分。他们还在视觉模型上通过选择不连续度量制造出了表面上的涌现。他们还指出**分辨度**的问题：测试例数少时，小准确率与零无法区分。

对这一论证的回应褒贬不一，双方各有道理。

- **支持度量解释。**它说明一个度量上的陡峭曲线并不意味着模型发生陡峭的变化；当能找到平滑的量时，行为就变得更可预测，这对预测能力来说是好消息。
- **但它不是全部。**有些能力在连续度量下依然突然变化，或者合适的连续度量并不显然（Du 等（2024）发现，若干能力一旦预训练损失降到某个阈值以下就出现——即便用连续度量测量也是如此——而另一些从一开始就平滑改善）。而且对使用者来说，不连续的度量往往才是相关的那一个：几乎正确的程序跑不起来，错了一个数字的算术答案是错的。Ganguli 等（2022）把这种组合描述为"可预测性与意外"：汇总的损失是可预测的，具体能力往往不是。

截至 2026 年的一个公允总结：能力**在模型中不连续地出现**这一说法比初看时弱得多，因为许多陡峭曲线可以由度量与分辨度解释；而**具体任务的表现在很大程度上仍难以从小模型预测**，这正是规划与安全评测两方面的现实关切（[[evaluation/capability-evaluations]]）。

::: warning 不先检查度量，就别把 S 形曲线读成相变
当某个基准分数在两个检查点或两个模型规模之间跳升时，先问它是怎么打分的。画出配套的连续度量——正确答案的对数概率、逐词元准确率、编辑距离——并附上置信区间。如果连续度量其实一直在稳步改善，跳变就是度量的性质；如果它也跳变，模型里确实发生了什么。无论哪种情形，带噪声基准上的相邻两个点都不是涌现的证据。
:::

**训练运行内部的涌现。**训练中的一些变化确实是突然的。Olsson 等（2022）发现**归纳头**（induction heads）——复制"当前词元上一次出现之后的那个词元"的注意力回路——在训练早期一个狭窄的窗口内形成，恰好与损失曲线上一个可见的隆起以及上下文内学习能力的跃升同时发生（[[interpretability]] 中的研究把这些回路当作对象）。开放的检查点套件——如 Pythia（Biderman 等，2023：$16$ 个模型，从 $7000$ 万到 $120$ 亿参数，全部按相同顺序在相同数据上训练，每个有 $154$ 个检查点）与 OLMo 的各次发布——让训练之外的研究者也能研究这些动力学。

::: example 精确匹配对部分得分 {#ex-exact}
一个模型在 $8$ 词元答案上的逐词元准确率，在某个检查点是 $0.73$，在更晚的检查点是 $0.88$。假设独立，计算两个检查点的精确匹配准确率与答对词元数的期望。
::: solution
精确匹配：$0.73^8 = 0.081$，$0.88^8 = 0.360$，增长超过四倍。答对词元数的期望：$8\cdot0.73 = 5.84$，$8\cdot0.88 = 7.04$，增长 $21\%$。模型的同一变化，在一个度量下像突破，在另一个度量下像稳步前进——正是[[#prop-exact-match]]的情形。
:::
:::

## 一套评测协议 {#sec-protocol}

::: algorithm 预训练运行期间的评测 {#alg-protocol}
1. **训练之前**：按领域确定验证集，并与训练数据完成去重；确定一套小巧、便宜、格式已知（早期信号用完形填空式，之后用带字母的选择题式）且归一化方式已知的探测套件；对训练数据做针对它们的去污染（[[pretraining/training-data#sec-contamination]]）。
2. **每隔几百到几千步**：计算各领域的验证损失与探测套件得分；连同步数、已见词元数与学习率一起记录。
3. **报告不确定性**：报告损失（[[#prop-se]]）与基准分数的标准误差、检查点之间的配对比较，以及在相邻检查点上的平均。
4. **把调度算进去**：比较处于调度中相同位置的检查点；运行采用 WSD 时，评测短衰减段的模型。
5. **在决策点**（改变配比、退火、训练结束）：运行更大、更贵的评测套件，其中包括从未用于任何决策的留出任务，以检查是否过拟合到了探测上。
:::

最后一步很重要，因为用来做决策的探测会变成优化对象：如果退火配比是为了最大化某个数学基准而选定的，那个基准再也不能无偏地衡量数学能力。把一部分评测留着一动不动直到最后，正是预训练版的测试集（[[ml-fundamentals/generalisation#sec-splits]]）。

## 代码中的噪声与陡峭 {#sec-code}

下面的清单重现[[#prop-exact-match]]的精确匹配效应，用模拟检验 $1000$ 道题基准的二项标准误差，并对在大部分题目上一致的两个检查点做配对比较。

```python
import math, random

# 1. 平滑的逐词元能力变成一条陡峭的精确匹配曲线
def per_token(logC):                 # 逐词元准确率随 log10 算力平滑上升
    return 1 / (1 + math.exp(-(logC - 21)))
L = 8                                # 答案有 8 个词元；精确匹配要求全部答对
print("log10 C  per-token  exact match  expected tokens correct")
for logC in range(18, 26):
    p = per_token(logC)
    print(f"  {logC}     {p:.3f}      {p ** L:.4f}          {p * L:.2f}")

# 2. 基准有多吵？ 1000 道题，真实准确率 0.62
rng = random.Random(0)
n, acc = 1000, 0.62
scores = [sum(rng.random() < acc for _ in range(n)) / n for _ in range(2000)]
mean = sum(scores) / len(scores)
sd = math.sqrt(sum((s - mean) ** 2 for s in scores) / (len(scores) - 1))
print(f"simulated sd of the score {sd:.4f}, binomial formula {math.sqrt(acc * (1 - acc) / n):.4f}")

# 3. 两个检查点在同一批题目上的配对比较
a = [rng.random() < 0.62 for _ in range(n)]                        # 检查点 A 的对错
b = [x if rng.random() < 0.85 else (rng.random() < 0.64) for x in a]  # B：与 A 大部分一致
diff = [int(y) - int(x) for x, y in zip(a, b)]
d = sum(diff) / n
sd_d = math.sqrt(sum((v - d) ** 2 for v in diff) / (n - 1) / n)
print(f"A {sum(a) / n:.3f}  B {sum(b) / n:.3f}  difference {d:+.3f} +/- {sd_d:.3f} (paired)"
      f"  vs +/- {math.sqrt(2 * 0.62 * 0.38 / n):.3f} (unpaired)")
```

```text
log10 C  per-token  exact match  expected tokens correct
  18     0.047      0.0000          0.38
  19     0.119      0.0000          0.95
  20     0.269      0.0000          2.15
  21     0.500      0.0039          4.00
  22     0.731      0.0816          5.85
  23     0.881      0.3622          7.05
  24     0.953      0.6779          7.62
  25     0.982      0.8648          7.86
simulated sd of the score 0.0151, binomial formula 0.0153
A 0.596  B 0.609  difference +0.013 +/- 0.008 (paired)  vs +/- 0.022 (unpaired)
```

在 $10^{20}$ 到 $10^{21}$ FLOPs 之间，逐词元准确率几乎翻倍，而精确匹配始终低于 $0.4\%$——在几百道题的基准上，它与零无法区分。在接下来的三个数量级里，精确匹配爬升到 $68\%$。模拟得到的基准分数散布与二项公式一致，而配对使检查点比较的标准误差减小近三倍。

::: quiz
一个基础模型在训练期间每 $5000$ 步在一个 $400$ 道题的带字母格式选择题基准上评测一次。它的准确率在训练前半段停留在 $25\%$（四个选项的随机水平），随后升到 $45\%$。哪些结论是站得住的？（多选）
- [ ] 模型在训练中途突然获得了底层知识。
- [x] 完形填空式，或正确答案的概率，可能会显示更早、更平滑的进展。
- [x] 相邻检查点之间 $2$ 分的差异在噪声之内。
- [ ] 验证损失必定同时发生了突然的下降。
::: solution
带字母格式往往在模型学会"答案是一个字母"这一约定之前都停留在随机水平，所以知识可能早就存在；连续度量或完形填空式可以检验这一点。$400$ 道题时，$35\%$ 准确率下的标准误差为 $\sqrt{0.35\cdot0.65/400} = 2.4$ 分，所以两分的起伏就是噪声。没有任何理由要求验证损失突然变化：平滑的损失与陡峭的任务指标并存（[[#prop-exact-match]]）。
:::
:::

::: history
用留出文本上的困惑度衡量语言模型，自 20 世纪七八十年代 IBM 的 Jelinek 与同事的工作以来一直是标准做法。到预训练 Transformer，下游探测进入了训练过程：GPT-2（2019）与 GPT-3（2020）用似然打分报告零样本与少样本基准成绩，EleutherAI 的语言模型评测工具（2020 年起）让这种打分成为共享工具。Kaplan 等（2020）把缩放定律拟合到验证损失上，Hoffmann 等（2022）用多次运行的中间损失估计计算最优规模。BIG-Bench（Srivastava 等，2022）收集了两百多个任务；Ganguli 等（2022）描述了"可预测性与意外"，Wei 等（2022）编纂了涌现能力，Schaeffer、Miranda 与 Koyejo（2023）则主张它们大多由度量造成。Olsson 等（2022）把归纳头的形成与训练期间的一次相变联系起来；Pythia（Biderman 等，2023）与 OLMo（Groeneveld 等，2024）发布了用于研究训练动力学的检查点；OLMES（Gu 等，2024）与 Madaan 等（2024）处理了基础模型评测的格式与方差问题。
:::

::: summary
- 在留出、已去重的数据上按领域计算的**验证损失**，是预训练期间的主要信号；跨分词器比较用每字节比特数，并在文档水平估计其标准误差。
- WSD 调度让平稳阶段的检查点看起来比实际更差；需要预测时，评测分出衰减段的模型。
- 基础模型靠对候选答案做**似然打分**来探测；结果依赖形式（完形填空式还是带字母式）与长度归一化。
- 基准分数带有二项噪声 $\sqrt{p(1-p)/n}$，外加检查点之间的方差；比较检查点要用配对检验，并对相邻检查点取平均。
- **涌现能力**（Wei 等，2022）指表现随规模从随机水平跳起的任务；Schaeffer 等（2023）表明，精确匹配（$p^L$）这类不连续度量与有限的分辨度制造了其中许多跳变。平滑的底层量让进展更可预测，但具体任务的表现仍难预测，而一些变化——例如归纳头的形成——确实是突然的。
- 让一部分评测不参与任何训练决策，它们才能继续衡量本来要衡量的东西。
:::

真实准确率为 $0.62$ 的模型，在 $1000$ 道题的基准上准确率的标准误差是多少？保留四位小数。

::: exercise 精确匹配 {level=1 check="0.0816"}
逐词元准确率为 $0.7311$，答案有 $8$ 个词元。假设独立，精确匹配准确率是多少？保留四位小数。
::: solution
$0.7311^8 = 0.0816$，即清单中 $10^{22}$ FLOPs 那一行的数值（那里逐词元准确率为 $1/(1 + e^{-1}) = 0.7311$）。

::: exercise 需要多少道题 {level=2 check="2500"}
一个基准要有多少道题，才能使接近 $0.5$ 的准确率的标准误差不超过一个百分点？给出使 $p = 0.5$ 时 $\sqrt{p(1-p)/n}\le0.01$ 成立的最小整数 $n$。若要在两个标准误差内分辨两个**独立**模型之间一分的差异，又需要多少道题？
::: solution
$\sqrt{0.25/n}\le0.01$ 要求 $n\ge0.25/0.0001 = 2500$。对独立模型之间的差异，标准误差为 $\sqrt{2\cdot0.25/n}$，要求两倍标准误差不超过 $0.01$，即 $\sqrt{0.5/n}\le0.005$，$n\ge20{,}000$——比多数基准的题量还多，这就是配对比较与连续指标重要的原因。
:::
:::

::: exercise 长度归一化 {level=2}
在[[#ex-mc]]中，假设加入第四个候选 "Canberra, the capital"（$6$ 词元、$21$ 字符），其总对数概率为 $-7.0$。现在每种归一化各选中哪个答案？这说明长候选有什么问题？
::: solution
原始：Sydney（$-4.1$）仍然获胜。按词元：新候选得 $-7.0/6 = -1.167$，优于 Canberra 的 $-1.60$，于是它获胜。按字符：$-7.0/21 = -0.333$，又是最好。按词元与按字符的归一化可能偏袒这样的长候选：一旦前面的词元给定，它后面的词元高度可预测（这里 "the capital" 在 "Canberra," 之后很容易续出）。因此基准会让各候选形式相当；也有些打分器改用候选在中性上下文下的概率来归一化。
:::
:::

::: exercise 验证损失的标准误差 {level=2 check="0.002"}
一个验证集有 $m = 2500$ 篇文档，每篇 $\bar n = 1000$ 词元，且 $S_j - \hat{\mathcal L}n_j$ 的样本标准差为 $100$ nats。由[[#prop-se]]，验证损失的标准误差是多少？
::: solution
$\frac{1}{\bar n\sqrt m}\cdot100 = \frac{100}{1000\cdot50} = 0.002$ nats。作为对照，若词元独立、$\sigma = 2.5$，会给 $2.5/\sqrt{2.5\times10^6} = 0.0016$；文档内相关把标准误差抬高了 $25\%$。
:::
:::

::: exercise 平滑还是突然？ {level=2}
一个团队报告，在 $10^{22}$ 与 $10^{23}$ 训练 FLOPs 的模型之间，三位数乘法任务的准确率从 $2\%$ 跳到 $40\%$。列出三个有助于判断这一跳变究竟反映模型的突变还是度量性质的额外测量。
::: solution
(1) 对同样的输出取连续度量：逐位准确率，或产出答案与正确答案之间的编辑距离，以及教师强制下模型赋予正确答案的对数概率。(2) 在 $10^{22}$ 与 $10^{23}$ FLOPs 之间取更多模型规模（或中间检查点），带置信区间，并配足以在接近 $0$ 的准确率处分辨的测试题量。(3) 对相关任务做同样的分析——一位与两位乘法；若精确匹配的解释成立，较短的答案（更小的 $L$、更小的 $p^L$ 陡度）应使曲线不那么陡。若连续度量一路平滑改善、较短的变体曲线更平滑，则跳变主要是度量效应。
:::
:::

::: exercise 精确匹配曲线最陡之处 {level=3}
设逐词元准确率为 $p(x) = 1/(1 + e^{-(x - x_0)})$，即 $x = \log_{10}C$ 的 logistic 函数，精确匹配为 $E(x) = p(x)^L$。证明 $E$ 在 $p = L/(L + 1)$ 处上升最快，并计算 $L = 8$ 时该点相对 $x_0$ 的位置。最大斜率 $E'(x)$ 是多少？它与 $p$ 自身的最大斜率 $1/4$ 相比如何？
::: solution
$p' = p(1-p)$，所以 $E' = Lp^{L-1}p' = Lp^L(1-p)$。对 $p$ 最大化 $g(p) = p^L(1-p)$：$g' = p^{L-1}(L - (L+1)p) = 0$ 给出 $p = L/(L+1)$。由于 $p$ 随 $x$ 递增，这里就是 $E$ 上升最快之处。$L = 8$ 时 $p = 8/9$，于是 $x - x_0 = \ln(p/(1-p)) = \ln8 = 2.08$：最陡点位于逐词元中点右侧约 $\log_{10}C$ 轴 $2$ 个单位处。最大斜率为 $L(8/9)^8(1/9) = 8\cdot0.3897/9 = 0.346$，大于 $1/4$；随 $L$ 增大它趋于 $1/e\approx0.37$，而曲线进一步右移 $\ln L$。所以精确匹配被推迟了 $\ln L$、并略更陡峭——"涌现"之所以出现得晚，主要因为这个推迟。
:::
:::

::: exercise 配对标准误差 {level=3}
证明：对在同一批 $n$ 道题上评分的两个检查点，设每题的对错为 $A_i, B_i\in\{0, 1\}$，则它们准确率之差的方差为 $\frac1n\big(\Var(A) + \Var(B) - 2\Cov(A, B)\big)$，并用这个公式解释为什么[[#sec-code]]中配对的标准误差是 $0.008$ 而不是 $0.022$。
::: solution
准确率之差为 $\frac1n\sum_i(B_i - A_i)$，是 $n$ 个独立同分布的 $B - A$ 的平均，故其方差为 $\Var(B - A)/n = (\Var(A) + \Var(B) - 2\Cov(A, B))/n$。当作独立的处理会丢掉协方差项，得到约 $2\cdot0.62\cdot0.38/n$，标准误差为 $0.022$。在模拟中，$B$ 在 $85\%$ 的题目上复制 $A$，所以 $A$ 与 $B$ 强正相关；协方差抵消了大部分方差，使 $\Var(B - A)$ 大约只剩答不一致题目的比例（约 $0.06$ 到 $0.07$），于是 $\sqrt{0.065/1000} = 0.008$。
:::
:::
