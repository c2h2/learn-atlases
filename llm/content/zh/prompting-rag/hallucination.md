向语言模型询问一位不太知名的科学家的生平，它可能给出一段行文流畅的介绍，里面有出生地、一所大学和两本著作——其中一些确有其事，一些纯属虚构，而陈述的口吻同样自信。让它摘要一份合同，它可能添上一条并不存在的条款。学界把这类输出称为**幻觉**：流畅、看似合理，却既没有现实世界、也没有提供给它的来源作为依据的内容。它是信任语言模型之事实的主要障碍，也是检索增强生成存在的主要原因。

本章先用一个分类法把这一概念讲精确，然后解释为什么下一个词元的预测会产生幻觉——其中包括两个干脆的论证：一个校准良好的模型在它只见过一次的事实上必然产生幻觉，而常见的评测会奖励瞎猜——随后转向对策：以来源为据的有据生成、基于一致性的检测、置信度的校准，以及拒答。全章引用的研究数字都附有出处与日期；它们描述的是特定模型在特定基准上的表现，将会变化。

## 什么算作幻觉 {#sec-taxonomy}

这个词用得比较随意；综述工作赋予了它结构。Ji 等人（2023）在综述自然语言生成时，依据幻觉与**来源**（要摘要的文档、据以回答的段落）之间的关系对其加以区分。

::: definition 内在幻觉与外在幻觉 {#def-intrinsic}
给定一段来源文本，若生成的陈述与来源矛盾，则为**内在幻觉**；若它既不能被来源支持、也不能被来源否定，则为**外在幻觉**。被来源蕴含的输出对来源是**忠实的**。
:::

一个外在陈述也许碰巧是真的——模型从记忆中补上了一个正确的事实——但它不是*有据的*：读者无法从来源核实它。针对没有来源的开放式生成，Huang 等人（2023）提出了一个互补的划分。

::: definition 事实性幻觉与忠实性幻觉 {#def-factuality}
**事实性幻觉**是与可验证的现实事实不一致的陈述，或是编造的实体、引文或文献。**忠实性幻觉**是与用户的指令、所提供的上下文，或模型自己先前的输出不一致的输出（逻辑不一致）。
:::

| 示例 | 类别 |
|---|---|
| 摘要说会议在周二召开；会议纪要写的是周四。 | 内在，忠实性 |
| 摘要补充说会议"富有成效"；纪要对此只字未提。 | 外在 |
| 模型引用了一篇标题和作者都像真的、但实际不存在的论文。 | 事实性（编造） |
| 要求用法语回复，模型却用英语回复。 | 忠实性（指令） |
| 模型算出 $17\times24 = 418$，下一行却用了 $408$。 | 忠实性（自相矛盾） |

这一区分在实践中很重要，因为对策不同。对给定来源的忠实度可以对照该来源自动核查；事实性则需要世界知识，而这正是可疑之处。

## 模型为什么会产生幻觉 {#sec-causes}

在模型一生的每个阶段，都有若干原因相互叠加。

**目标函数。** 预训练最大化下一个词元的似然（[[pretraining/pretraining-objectives]]）。*听起来像*传记的文本会受到奖励，无论其事实对错，因为训练语料包含数以百万计的传记，模型因为产出它们的典型形态而得到奖励。损失函数中没有任何一项能区分"一个可信的出生地"与"那个出生地"。

**数据。** 训练语料含有错误、矛盾与过时陈述，而且对各事实的覆盖极不均衡。Kandpal 等人（2023）发现，模型在事实性问题上的准确率随预训练文档中与该问题相关的文档数急剧上升；长尾中的事实学得很差，甚至完全学不到。

**微调。** 后训练教会模型给出有帮助的回答，而看似有帮助的回答更常是自信的而非留有余地的。Gekhman 等人（2024）发现，在包含模型尚不具备之知识的示例上微调，学得很慢，而一旦学到，反而增加了产生幻觉的倾向——这与"微调教的是'自信作答'这一*形式*而非新知识"的解释一致。

**解码。** 在正温度下采样可能选中低概率的接续（[[inference/decoding-sampling]]），而一旦输出一个错误词元，模型就以它为条件继续：Zhang 等人（2023）记录了**滚雪球**现象——模型在开头几个词元就咬定一个错误答案，随后为其给出辩护，尽管单独问它时，它往往能识别出这些辩护是假的。

前两个原因可以定量化。

### 校准良好的模型必然在罕见事实上产生幻觉

考虑那些没有任何可供模型泛化之模式的"任意"事实——比如一个人的生日。Kalai 与 Vempala（2024）证明，在一个自然的统计意义上*校准*的语言模型，其在此类事实上的幻觉率必然接近这些事实在其训练数据中恰好出现一次的占比。其直观依据是**古德–图灵（Good–Turing）**对未见概率质量的估计。

::: definition 未见质量的古德–图灵估计 {#def-good-turing}
设样本由从一个大条目集合上的分布抽取的 $n$ 次观测组成，令 $n_1$ 为恰好被观测到一次的条目数。则所有*未*被观测到的条目的总概率的**古德–图灵估计**为 $n_1/n$。
:::

这个估计说的是：见过一次的东西的频率，是尚未见到的东西之频率的良好指南。因此，一个把生日陈述的分布学得很像的模型，必然把大约 $n_1/n$ 的概率放在它*从未*见过的生日事实上——而既然从未见过，它便无从知道哪个为真。这部分质量中的一部分会作为自信的谎言被生成出来，除非模型被训练成把它引向拒答。Kalai 与 Vempala 在他们的假设下证明了这一形式的下界；该结果只针对任意事实，而非算术这类可以泛化的系统知识。

::: example 训练数据中的单次出现 {#ex-good-turing}
某训练语料中有 $1500$ 条陈述给出了人物的出生日期，其中 $200$ 位人物恰好被提到一次。古德–图灵估计认为出生日期陈述中有多大比例关于模型从未见过的人物？这意味着什么？
::: solution
$n_1/n = 200/1500 = 0.133$。一个与这类陈述的分布吻合的模型，在它给出出生日期的情形中约有 $13\%$ 会给出未见人物的日期，而它对那些日期毫无信息，因此几乎全部是错的。绕开这一点的办法只有检索（把事实交给它）或拒答（训练它婉拒）；增加同类数据只会缓慢地降低 $n_1/n$。
:::
:::

### 评测奖励瞎猜

第二个论证关乎激励。Kalai 等人（2025）指出，大多数基准把答案只评为对或错，"我不知道"不得分。在这种评分下，瞎猜永远是最优的。

::: proposition 何时作答 {#prop-answer}
一个模型作答一道题，它认为自己答对的概率为 $p$。评分规则为：答对得 $+1$，答错得 $-\lambda$（其中 $\lambda\ge0$），拒答得 $0$。当且仅当下式成立时，作答的期望得分高于拒答：

$$
p > \frac{\lambda}{1 + \lambda}.
$$

在二元评分（$\lambda = 0$）下，只要 $p > 0$，作答就是最优的。反过来，若要让作答只在置信度阈值 $t$ 之上才划算，取 $\lambda = t/(1 - t)$。
:::

::: proof
作答的期望得分为 $p\cdot1 + (1 - p)(-\lambda) = p - \lambda(1 - p)$，拒答的期望得分为 $0$。作答更优当且仅当 $p - \lambda + \lambda p > 0$，即 $p(1 + \lambda) > \lambda$，即 $p > \lambda/(1 + \lambda)$。令 $\lambda/(1 + \lambda) = t$，解得 $\lambda = t/(1 - t)$。
:::

::: widget plot
f: x - l*(1 - x); 0
x: 0, 1
y: -3, 1.05
sliders: l=3:0:9:0.1
labels: expected score of answering; abstaining
points: 0.75,0
caption: 当答错付出 $\lambda$（滑块）、拒答得 $0$ 时，作答的期望得分随模型答对概率 $p$ 变化的曲线。两条线在 $p = \lambda/(1 + \lambda)$ 处相交：$\lambda = 3$ 时在 $0.75$，已在图中标出。当 $\lambda = 0$——即常见的对错二元基准——作答线对所有 $p > 0$ 都在零以上，因此在这样的基准上优化的模型会学会永不拒答。
:::

::: example 对错误答案的惩罚 {#ex-penalty}
某评分器对答对给 $+1$，答错给 $-3$，回答"我不知道"给 $0$。一个模型对其答案有 $60\%$ 的把握。它应当作答吗？这一评分规则施加了怎样的阈值？
::: solution
作答的期望得分：$0.6 - 3\cdot0.4 = -0.6 < 0$，应当拒答。阈值为 $\lambda/(1 + \lambda) = 3/4$：只有把握超过 $75\%$ 时才作答。Kalai 等人建议把这样的阈值写进基准说明，使模型因为校准良好的拒答、而非自信的瞎猜而受到奖励。
:::
:::

## 测量幻觉 {#sec-measuring}

测量把分类法变成数字，而每个数字都取决于基准、模型与日期。下面列举几项代表性结果：

- **TruthfulQA**（Lin 等人，2022）问的是一些因误解而连人类都会答错的问题。在最初的研究中，受测的最佳模型在 $58\%$ 的问题上保持真实，而人类为 $94\%$；同一系列中更大的模型反而常常*更不*真实，因为它们把这些误解学得更好。后来的模型得分高得多，而该基准现在被广泛怀疑已部分进入训练数据（[[evaluation/contamination]]）。
- **FActScore**（Min 等人，2023）把一段长生成拆成原子事实，并逐条对照知识来源核查。在对知名程度不一的人物生成的回答中，ChatGPT（就 2023 年初而言）只有 $58\%$ 的原子事实得到支持，且人物越冷门准确率下降越陡——即 [[#sec-causes]] 中的长尾。
- **引用审计**：如 [[prompting-rag/retrieval-augmented-generation#sec-prompt]] 所引，2023 年一项针对生成式搜索引擎的研究发现，其句子中只有约一半能被所给引用完全支持。

在这类基准上，当前模型的比率更低，但不为零，而且在冷门话题、长输出和没有明确答案的问题上会上升。

## 有据生成 {#sec-grounding}

最有效的通用对策是把事实交给模型并要求它使用：**有据生成**（grounding）。检索增强生成（[[prompting-rag/retrieval-augmented-generation]]）提供来源；提示要求给出有来源支持、带引用的回答，并在来源保持沉默时明确说明。有据生成把一个需要世界知识才能核查的事实性问题，转化为一个可以对照来源核查的忠实性问题。

::: definition 归因 {#def-attribution}
若一位普通读者在看到来源后会认可该来源支持这一陈述，则称该陈述**可归因于**该来源——即 Rashkin 等人（2023）的"可归因于已识别来源"标准。一个回答的**引用召回率**是其陈述中得到所引来源支持的占比；**引用精确率**则是确实支持其所附陈述的引用所占的比例。
:::

有据生成大幅减少幻觉，但不能消除它：模型仍会添加外在细节、误读来源、把两个来源的事实合并成一条错误陈述，或者在来源与其矛盾时更信任自己的记忆。还有若干技术作用于生成之时。**验证链**（Chain-of-verification；Dhuliawala 等人，2023）让模型先起草回答，针对其中的论断规划验证问题，独立地回答这些问题，再修改回答。**事后归因**用一个自然语言推理模型逐句检查，删除或标记无支持的句子。**解码干预**——例如对比靠后层与靠前层的预测（DoLa；Chuang 等人，2024）——报告在某些基准上提升了事实性。**为事实性而训练**——例如以自动评判的事实性为奖励的偏好优化（Tian 等人，2024），或训练模型在超出其知识的问题上说"我不知道"（Zhang 等人，2024）——针对的是病因而非症状。

::: warning 有引用不等于论断得到了支持
一个句子后面跟着 `[2]`，*看起来*经过核实，读者往往就信了。但模型生成引用标记和生成词语用的是同一个过程，它可能把一个真实来源挂到一个该来源并未做出的论断上——RAG 一章代码清单里检查的第三条论断正是这样。要把引用当作待核查的指针，能自动核查的就自动核查，并让用户看到被引用的原文，而不只是编号。
:::

## 没有来源时如何检测幻觉 {#sec-detection}

没有来源可对照时，模型自身的表现会泄露不确定性。模型若知道某个事实，重复采样往往一致；若它在猜，样本就会四散。SelfCheckGPT（Manakul 等人，2023）根据一个回答中每个句子与后续采样回答的一致性为其打分。然而逐字比较样本会造成误导：*Paris*、*It is Paris.* 和 *the city of Paris* 是三个不同的字符串，却只有一个含义。**语义熵**（Kuhn 等人，2023；Farquhar 等人，2024）转而度量意义层面的不确定性。

::: definition 语义熵 {#def-semantic-entropy}
对一个问题采样 $n$ 个回答，把它们划分成意义相同的**簇**（实际做法是让自然语言推理模型判定双向互相蕴含），并令 $\hat p_c$ 为落入簇 $c$ 的回答占比。**语义熵**为

$$
\mathrm{SE} = -\sum_c\hat p_c\ln\hat p_c.
$$

语义熵高说明模型对回答的*内容*没有把握，是很可能发生编造（confabulation）的信号。
:::

::: example 语义熵与朴素熵 {#ex-semantic}
一个困惑的模型对"*法国的首都是哪里？*"的十个采样回答为：*Paris*、*It is Paris.*、*paris*、*The city of Paris*、*Paris.*、*Paris*、*Lyon*、*It is Lyon.*、*Lyon*、*Marseille*。计算语义熵，并与按不同字符串计算的熵比较。
::: solution
意义簇为 Paris（$6$ 个）、Lyon（$3$ 个）和 Marseille（$1$ 个），故 $\mathrm{SE} = -(0.6\ln0.6 + 0.3\ln0.3 + 0.1\ln0.1) = 0.306 + 0.361 + 0.230 = 0.898$ 纳特。若只按完全相同归并字符串，共有八个不同的字符串（*Paris* 和 *Lyon* 各出现两次），熵为 $2.025$ 纳特。朴素的度量把措辞的差异也算作不确定性；一个总是以十种不同说法回答 *Paris* 的模型，朴素熵为 $2.3$ 纳特，而语义熵为 $0$。
:::
:::

Farquhar 等人（2024）报告，在多个问答数据集与模型上，语义熵检测编造的能力优于朴素熵和若干其他基线。它的代价是每个问题要采样几次并多做一步聚类，而且检测不到模型始终如一的错误——一个被自信持有的误解熵很低。

检测器是一个分类器，它的实用程度取决于被检出事物的基础比率（[[ml-fundamentals/evaluation-metrics#sec-base-rates]]）。

::: example 检测器与基础比率 {#ex-base-rate}
一个幻觉检测器能标记 $90\%$ 的幻觉回答，同时误标 $10\%$ 的正确回答。在某次部署中，$5\%$ 的回答是幻觉。被标记的回答中有多大比例确实是幻觉？
::: solution
$1000$ 个回答中，$50$ 个是幻觉，其中 $45$ 个被标记；$950$ 个正确回答中有 $95$ 个被标记。于是 $45/(45 + 95) = 0.321$：三分之二的标记是误报。这能否接受取决于标记会触发什么——触发一道廉价的二次检查未尝不可，触发丢弃回答则不可。
:::
:::

::: widget bayes
mode: test
prevalence: 0.05
sensitivity: 0.9
specificity: 0.9
caption: [[#ex-base-rate]] 中的检测器，用自然频数表示：幻觉是"条件"，标记是阳性结果。幻觉率为 $5\%$ 时，被标记的回答中只有约三分之一确实是幻觉。提高患病率（更难的领域、更旧的模型），标记就更可信；提高特异度，误报下降最快。
:::

## 校准与拒答 {#sec-calibration}

抵御错误答案最干净的办法是不作答。拒答需要一个置信信号，而这个信号只有**校准**良好才有用：在置信度为 $0.8$ 的回答中，应当约有 $80\%$ 是对的（[[ml-fundamentals/evaluation-metrics#def-calibration]]）。

::: definition 期望校准误差 {#def-ece}
按给出的置信度把预测分成箱 $B_1, \dots, B_M$。设 $\operatorname{conf}(B_m)$ 与 $\operatorname{acc}(B_m)$ 为第 $m$ 箱的平均置信度与准确率，共有 $n$ 个预测，则**期望校准误差**为

$$
\mathrm{ECE} = \sum_{m=1}^{M}\frac{\lvert B_m\rvert}{n}\,\big\lvert\operatorname{acc}(B_m) - \operatorname{conf}(B_m)\big\rvert.
$$
:::

大模型回答的置信度有若干来源：回答词元的概率（在选择题上定义良好）、模型用文字给出的概率、模型对自身回答为真的估计，或多次采样之间的一致程度。Kadavath 等人（2022）发现，大型预训练模型在格式合适的选择题上校准良好，并且可以被训练去预测自己是否知道答案；GPT-4 的开发者报告，其预训练模型在一个多选基准上校准良好，而后训练降低了校准程度（OpenAI，2023）。用文字给出的概率往往过度自信，校准应当测量，而非假设。

下面的清单模拟一个过度自信的模型，计算它的 ECE，并用一个粗糙的字符串归一化聚类代替蕴含模型来计算 [[#ex-semantic]] 的语义熵。

```python
import math, random
from collections import Counter
rng = random.Random(7)

# 模拟的问答结果：声明的置信度 c，正确性以概率 c**1.6 抽取
# （一个过度自信的模型：真实准确率低于声明的置信度）
data = []
for _ in range(2000):
    c = rng.uniform(0.3, 1.0)
    data.append((c, rng.random() < c**1.6))

def ece(data, bins=5):
    total = 0.0
    for b in range(bins):
        lo, hi = 0.3 + 0.7*b/bins, 0.3 + 0.7*(b+1)/bins
        sel = [(c, y) for c, y in data if lo <= c < hi or (b == bins-1 and c == hi)]
        if not sel: continue
        conf = sum(c for c, _ in sel)/len(sel); acc = sum(y for _, y in sel)/len(sel)
        print(f"  bin [{lo:.2f},{hi:.2f}) n={len(sel):4d} confidence {conf:.3f} accuracy {acc:.3f}")
        total += len(sel)/len(data) * abs(conf - acc)
    return total
print(f"ECE = {ece(data):.3f}")

def semantic_entropy(answers, canon):
    clusters = Counter(canon(a) for a in answers)      # 按意义归并回答
    n = len(answers)
    return -sum(k/n * math.log(k/n) for k in clusters.values()), clusters

canon = lambda a: a.lower().replace("it is ", "").replace("the city of ", "").strip(" .")
samples = ["Paris", "It is Paris.", "paris", "The city of Paris", "Paris.", "Paris",
           "Lyon", "It is Lyon.", "Lyon", "Marseille"]
h, cl = semantic_entropy(samples, canon)
print("clusters", dict(cl), f"semantic entropy {h:.3f} nats")
print(f"naive entropy over distinct strings {semantic_entropy(samples, lambda a: a)[0]:.3f} nats")
```

  bin [0.30,0.44) n= 426 confidence 0.369 accuracy 0.204
  bin [0.44,0.58) n= 411 confidence 0.511 accuracy 0.384
  bin [0.58,0.72) n= 381 confidence 0.650 accuracy 0.478
  bin [0.72,0.86) n= 389 confidence 0.789 accuracy 0.663

clusters {'paris': 6, 'lyon': 3, 'marseille': 1} semantic entropy 0.898 nats

每个箱的准确率都低于其置信度，相差 $5$ 到 $17$ 个百分点，ECE 为 $0.128$。若按声明的置信度选一个阈值——"把握至少 $0.75$ 就作答"——它作答的题目实际只有约三分之二的正确率。用留出的数据重新校准（拟合一个从声明置信度到观测准确率的映射，例如温度缩放），可以在不改变排序的情况下修正数值。

有了校准良好的分数，**选择性预测**只在阈值以上作答。它的权衡由**覆盖度**（作答问题占全部问题的比例）与**风险**（已作答问题中的错误率）刻画：提高阈值，两者都下降。合适的工作点取决于错误回答相对于拒答的代价——正是 [[#prop-answer]] 中的 $\lambda$。

::: quiz
一个模型只按准确率评分（对或错）。开发过程中，它学会了回答每一个问题，即使没有把握，也不说"我不知道"。按照 [[#prop-answer]]，对评分做哪种改动最能直接奖励恰当的拒答？
- [ ] 奖励更长的回答。
- [x] 拒答给 $0$，答错给负分，使在置信度阈值以下瞎猜会降低期望得分。
- [ ] 把拒答计为答对。
- [ ] 评测时降低采样温度。
::: solution
$\lambda = 0$ 时，任何 $p > 0$ 的猜测都有正的期望得分，所以瞎猜总是占优。对错误答案施加惩罚 $\lambda$ 后，在 $p = \lambda/(1 + \lambda)$ 以下拒答才是最优的。把拒答计为答对反而会奖励永远拒答。
:::
:::

::: history
"幻觉"一词在计算机视觉中指图像超分辨率重建中生成的细节（Baker 与 Kanade，2000），随神经机器翻译与摘要进入自然语言生成——那时模型产出行文流畅却不受输入支持的内容（Lee 等人，2018，关于翻译；Maynez 等人，2020，发现在相当大比例的神经摘要中存在幻觉，并区分了内在幻觉与外在幻觉）。Ji 等人（2023）综述了各类生成任务中的这一问题，Huang 等人（2023）则针对大语言模型。TruthfulQA（Lin 等人，2022）与 FActScore（Min 等人，2023）成为标准度量；Kadavath 等人（2022）研究了模型对自身知识的认知；Manakul 等人（2023）提出自一致性检查，Kuhn 等人（2023）与 Farquhar 等人（2024）提出语义熵。理论方面，Kalai 与 Vempala（2024）证明校准良好的模型必然在罕见的任意事实上产生幻觉，Kalai 等人（2025）则指出基准的二元评分会奖励瞎猜而非拒答。
:::

::: summary
- 幻觉是流畅却没有来源支持（内在：与来源矛盾；外在：无法由来源核实）或没有现实支持（事实性）、或与指令及模型自身输出不一致（忠实性）的输出。
- 成因相互叠加：奖励貌似合理形式的似然目标、覆盖不均且含噪、罕见事实形成长尾的数据、奖励自信回答的微调，以及咬定早期错误的解码。
- 校准良好的模型在任意事实上的幻觉率必然接近这类事实在训练中只出现过一次的占比（古德–图灵）；二元评分的评测使瞎猜最优，而对错误答案的惩罚 $\lambda$ 使置信度低于 $\lambda/(1 + \lambda)$ 时拒答最优。
- 以检索到的来源为依据把事实性转化为可核查的忠实性；引用有帮助，但必须核查。
- 没有来源时，样本之间的分歧——用语义熵在意义层面度量——是编造的信号；评价检测器必须对照基础比率。
- 拒答需要校准良好的置信度；测量校准（ECE），重新校准，并按错误的代价选择风险–覆盖度的工作点。
:::

## 习题

::: exercise 对称惩罚 {level=1 check="0.5"}
答错的损失与答对的收益相等（$\lambda = 1$）。模型应在置信度高于多少时作答？
::: solution
$\lambda/(1 + \lambda) = 1/2$：把握超过 $50\%$ 时作答。
:::
:::

::: exercise 一个期望得分 {level=1 check="-0.2"}
$\lambda = 3$ 时，以置信度 $0.7$ 作答的期望得分是多少？
::: solution
$0.7 - 3\cdot0.3 = -0.2$；拒答（$0$）更优，因为 $0.7 < 0.75$。
:::
:::

::: exercise 古德–图灵估计 {level=1 check="0.15"}
某语料包含 $2000$ 条关于小公司成立年份的陈述，其中 $300$ 家公司恰好被提到一次。关于未见公司的这类陈述占比，古德–图灵估计是多少？
::: solution
$n_1/n = 300/2000 = 0.15$。
:::
:::

::: exercise 手算校准误差 {level=1 check="0.115"}
一个模型的 $100$ 个回答落入三个置信度箱：$50$ 个平均置信度 $0.9$、准确率 $0.7$；$30$ 个置信度 $0.7$、准确率 $0.65$；$20$ 个置信度 $0.5$、准确率 $0.5$。计算 ECE。
::: solution
$0.5\cdot0.2 + 0.3\cdot0.05 + 0.2\cdot0 = 0.1 + 0.015 = 0.115$。
:::
:::

::: exercise 分裂投票的语义熵 {level=1 check="0.673"}
五个采样回答形成大小为 $3$ 和 $2$ 的两个意义簇。以纳特为单位计算语义熵。
::: solution
$-(0.6\ln0.6 + 0.4\ln0.4) = 0.306 + 0.367 = 0.673$。
:::

::: exercise 检测器的精确率 {level=2 check="0.64"}
一个幻觉检测器标记 $80\%$ 的幻觉回答和 $5\%$ 的正确回答；$10\%$ 的回答是幻觉。被标记的回答中有多大比例是幻觉？
::: solution
每 $1000$ 个回答：幻觉 $100$ 个，标记 $80$ 个；正确 $900$ 个，标记 $45$ 个。精确率 $80/125 = 0.64$。
:::
:::

::: exercise 给幻觉分类 {level=2}
用 [[#def-intrinsic]] 与 [[#def-factuality]] 对每个输出分类：(a) 一篇论文的摘要说它用了 $1000$ 名参与者，论文写的是 $100$；(b) 摘要补充说作者们在某所知名大学任职，论文并未提及，但这话是真的；(c) 一个助手被要求写三条要点，却写了五条；(d) 在没有给出来源时，模型说某历史条约签于某个并非签约之年的年份。
::: solution
(a) 内在幻觉（与来源矛盾），属忠实性错误。(b) 外在幻觉：虽真而不受来源支持；它是一个事实性陈述，但并非有据，而忠实的摘要应当省略它。(c) 忠实性幻觉（与指令不一致），不涉及事实内容。(d) 事实性幻觉：与现实事实不一致，且没有可供忠实的来源。
:::
:::

::: exercise 对数评分下诚实的置信度有利 {level=2}
一个模型报告其回答正确的置信度 $r$，答对得 $\ln r$，答错得 $\ln(1 - r)$。证明：若它答对的真概率为 $p$，则报告 $r = p$ 使其期望得分最大。这对训练模型陈述自身置信度有何意义？
::: solution
期望得分为 $f(r) = p\ln r + (1 - p)\ln(1 - r)$。其导数 $p/r - (1 - p)/(1 - r)$ 在 $r = p$ 处为零，且 $f''(r) = -p/r^2 - (1 - p)/(1 - r)^2 < 0$，故 $r = p$ 为最大值。对数评分是适定评分规则（proper scoring rule，[[ml-fundamentals/evaluation-metrics#def-proper]]）：报告真实信念才有奖励。按这样的规则为其声明的置信度取得奖励的模型没有夸大的动机；只按答案正确性奖励、或由偏爱自信文本的人类评分者打分的模型则有。
:::
:::

::: exercise 风险–覆盖度曲线 {level=3}
对清单中模拟的模型，把 $2000$ 个回答按置信度排序，报告覆盖度为 $0.25$、$0.5$、$0.75$ 与 $1$ 时的风险（已答问题中的错误率），以及风险–覆盖度曲线下的面积。这条曲线显示了 ECE 显示不了的什么？
::: solution
```python
import random
rng = random.Random(7)
data = []
for _ in range(2000):
    c = rng.uniform(0.3, 1.0)
    data.append((c, rng.random() < c**1.6))        # 同上，同一个模拟模型

data.sort(key=lambda t: -t[0])                     # 置信度高的在前
n = len(data); errors = 0; aurc = 0.0
for i, (c, y) in enumerate(data, 1):
    errors += not y
    aurc += errors / i / n                         # 对所有覆盖度求平均风险
    if i in (n//4, n//2, 3*n//4, n):
        print(f"coverage {i/n:.2f}  threshold {c:.3f}  risk (error rate) {errors/i:.3f}")
print(f"area under the risk-coverage curve {aurc:.3f}")
```

```text
coverage 0.25  threshold 0.819  risk (error rate) 0.148
coverage 0.50  threshold 0.643  risk (error rate) 0.280
coverage 0.75  threshold 0.464  risk (error rate) 0.386
coverage 1.00  threshold 0.300  risk (error rate) 0.485
area under the risk-coverage curve 0.266
```

只回答置信度最高的四分之一，可把错误率从 $48.5\%$ 降到 $14.8\%$。曲线度量的是置信度对回答的*排序*有多好——这正是选择性预测所需——而 ECE 度量的是置信度*数值*是否正确。这个模型过度自信（ECE $0.128$），但其置信度的排序依然很好；重新校准会修正数值、改变打印出的阈值，而使每个覆盖度下的风险保持不变。
:::
:::

::: exercise 设计一个会拒答的助手 {level=3}
为一个医疗信息助手设计评测与决策流程：它应当依据一个经过审核的文档集合作答，否则拒答。明确要测量什么、拒答阈值如何确定，以及如何检验助手不会干脆对所有问题都拒答。
::: solution
构建一个带标签的问题集，包含三类：集合可答的、集合不可答的（但看起来合理），以及超出范围的。对每条响应，记录它是作答还是拒答、答案是否正确并忠实于所引段落（由专家或经过验证的评审判定），以及它的置信度分数（例如语义熵与检索支持分的组合）。与领域专家一起确定错误回答相对于拒答的代价——例如取 $\lambda = 9$，由 [[#prop-answer]] 阈值为 $0.9$——并在验证集上设定阈值，使该阈值下测得的风险达标；再在留出的测试集上确认。对可答的问题，分别报告风险与覆盖度（那里的覆盖度必须保持高位，以防助手对所有问题都拒答），对不可答的问题报告拒答率（应接近 $1$）。部署后要持续监控两者，因为问题分布与文档集合都会变化。
:::
:::
