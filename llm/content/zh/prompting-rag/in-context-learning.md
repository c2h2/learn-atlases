给一个大语言模型下面这段文本

```text
cheese → fromage
house → maison
book →
```

它很可能接着写出 *livre*。没有人告诉它任务是英法翻译，它的权重也没有变化：模型从提示里的两个示例推断出任务，并把它用到第三个输入上。这种能力叫作**上下文学习**，它改变了语言模型的使用方式。2020 年以前，把一个模型适配到新任务意味着收集带标签的数据并做微调；自 GPT-3 起，相当大一部分应用只是写一个提示。

本章精确定义上下文学习，展示它如何测量、如何用于分类，收集关于模型实际从示例中取用什么的令人惊讶的实验发现，并给出两个解释它为何可行的理论模型：上下文学习作为隐式贝叶斯推断，以及作为在前向传播中进行的梯度下降。两者都是关于理想化设定的假说，而不是对生产模型所作所为的定论，本章对此一一标明。

## 提示、示例与权重冻结的模型 {#sec-definitions}

仅解码器语言模型（[[transformers/architecture-families]]）定义了下一个词元的条件分布 $p_\theta(x_{t+1}\mid x_{\le t})$。它在推理时所做的一切都是在上下文上进行的计算；参数 $\theta$ 固定不动。因此，提示是我们拥有的唯一输入通道，值得把它的各部分命名清楚。

::: definition 示例与 $k$ 样本提示 {#def-kshot}
一个**任务**把输入 $x$ 映到输出 $y$，两者都写成文本。**示例**是由固定**模板**渲染的一个对 $(x_i, y_i)$，例如 `Review: {x}\nSentiment: {y}\n`。对查询输入 $x$，一个 **$k$ 样本提示**是如下拼接

$$
P_k(x) = I \oplus \operatorname{tmpl}(x_1, y_1) \oplus \dots \oplus \operatorname{tmpl}(x_k, y_k) \oplus \operatorname{tmpl}(x, \cdot),
$$

由一段可选的自然语言指令 $I$、$k$ 个示例，以及输出槽位留空的查询组成。$k = 0$ 时提示是**零样本**的，$k = 1$ 时是**单样本**的，带有少量示例时是**少样本**的。
:::

::: definition 上下文学习 {#def-icl}
若在参数 $\theta$ 保持固定的情况下，随着任务的示例被加入提示，模型对查询的预测 $\hat y = \arg\max_y p_\theta(y \mid P_k(x))$（或从该分布中采出的样本）变得越来越准，就称模型对该任务进行了**上下文学习**（ICL）。
:::

这个定义是行为主义的。它对模型**如何**使用示例只字未提，而本章接下来会表明，对所发生的某些事来说，"学习"这个词用得相当宽厚。它与微调的对照十分鲜明：

| | 微调 | 上下文学习 |
|---|---|---|
| 改变的是什么 | 权重 $\theta$ | 只有上下文 |
| 需要的数据 | 数百到数百万个带标签样本 | 零到数十个 |
| 代价 | 一次训练，跑完即可 | 每次查询都更长的提示 |
| 持久性 | 永久，直到重新训练 | 调用一结束就忘掉 |
| 上限 | 算力与数据 | 上下文窗口 |

这一术语与系统研究来自 Brown 等人（2020），他们评测了 GPT-3——一个 $1750$ 亿参数、上下文窗口 $2048$ 词元的解码器——在数十个基准上恰好采用上面这三种设定。他们的核心观察是经验性的：零样本与少样本准确率之间的差距随模型规模拉大，因此越大的模型把自己的示例用得越好。在某些任务上，少样本 GPT-3 接近了当时的微调系统；在另一些任务上，如某些阅读理解与自然语言推理基准，它仍远远落后。

::: example 示例的预算 {#ex-budget}
一个用于 GPT-3 的分类提示包含 $40$ 词元的指令、若干个各约 $60$ 词元的示例、一个 $50$ 词元的查询，答案需要 $10$ 个词元。$2048$ 词元的上下文里放得下多少个示例？
::: solution
示例至多可用 $2048 - 40 - 50 - 10 = 1948$ 个词元，而 $1948/60 = 32.5$，所以最多放得下 $32$ 个示例。这就是 Brown 等人采用"能放下多少示例就放多少"的原因，按示例长度通常放 $10$ 到 $100$ 个。在 2026 年常见的 $128{,}000$ 词元上下文里，同样的算术大约允许 $2000$ 个示例——Agarwal 等人（2024）称之为**多样本（many-shot）**上下文学习的那个区间：在许多任务上，准确率远超少样本区间之后仍在上升。
:::
:::

## 上下文分类 {#sec-classification}

把模型用作分类器最干净的办法，不是让它自由书写，而是对每个允许的标签**打分**。每个标签 $c$ 配一个标签词（verbaliser）字符串 $v(c)$——比如 *positive* 与 *negative*——预测就是提示之后模型认为其标签词最可能的那个标签：

$$
\hat c = \arg\max_c\ p_\theta\big(v(c)\ \big|\ P_k(x)\big),
$$ {#eq-label-score}

其中多词元标签词的概率按链式法则等于其各词元概率的乘积。若每个标签词都是单个词元，这就是对相应 logits 限制在标签词元上的 softmax——[[ml-fundamentals/logistic-regression]] 中的多项 logistic 模型，只不过这个分类器从未为该任务训练过。

::: example 给两个标签打分 {#ex-scoring}
一段情感提示之后，词元 *positive* 与 *negative* 的 logits 分别是 $2.1$ 与 $1.3$。模型预测什么？在两个标签之间给出多大概率？
::: solution
把 softmax 限制在两个标签词元上：$p(\text{positive}) = e^{2.1}/(e^{2.1} + e^{1.3}) = 1/(1 + e^{-0.8}) = 0.690$，$p(\text{negative}) = 0.310$。预测是 *positive*。模型本来也可能写出的其他词元（*good*、*The*、换行符）被忽略，这正是打分的意义：输出保证是一个合法标签。
:::
:::

打分暴露出一个弱点。Zhao 等人（2021）发现 GPT-3 的少样本预测存在系统性的偏向：偏向示例中出现次数最多的标签（**多数标签偏差**），偏向最后几个示例的标签（**近因偏差**），以及标签词是常见词元的标签。他们提出**上下文校准**：把一个无内容的查询（如 `N/A`）喂给提示，读出模型在无可分类之物时产生的标签分布 $\mathbf{p}_{\text{cf}}$，再把它除出去。

::: definition 上下文校准 {#def-calibration}
设 $\mathbf{p}(x)$ 是模型对查询 $x$ 在标签上的分布，$\mathbf{p}_{\text{cf}}$ 是同样的示例配上一个无内容查询时的分布。**校准后**的预测为

$$
q_c(x) = \frac{p_c(x)/p_{\text{cf},c}}{\sum_{c'} p_{c'}(x)/p_{\text{cf},c'}}.
$$

若模型的偏差是每个标签上一个固定的乘性因子，这一做法就能将它完全去除。
:::

::: example 校准翻转了一个预测 {#ex-calibration}
在一组给定的示例下，模型对某个查询赋予 (*positive*, *negative*) 的概率 $\mathbf{p}(x) = (0.6, 0.4)$，而对 `N/A` 赋予 $\mathbf{p}_{\text{cf}} = (0.7, 0.3)$。校准后的预测是什么？
::: solution
相除：$(0.6/0.7,\ 0.4/0.3) = (0.857,\ 1.333)$，和为 $2.190$，故 $\mathbf{q} = (0.391, 0.609)$。原始预测是 *positive*，但即使无事可判，模型也向 *positive* 倾斜 $70{:}30$；相对这一基线，该查询看起来是消极的，于是校准后的预测是 *negative*。Zhao 等人报告，仅这一处修正就在某些任务上带来高达 $30$ 个准确率百分点的提升，并使结果对示例选择的方差大大降低。
:::
:::

同一项研究还发现，仅仅取决于选了**哪些**示例、按**什么顺序**排列，准确率就能从接近随机变到接近当时最好的水平。Lu 等人（2022）证实了顺序效应：对少量示例构成的集合，某些排列给出好的准确率，某些近乎随机，而且好的顺序不能在模型之间移植。$k$ 个示例有 $k!$ 种顺序，$k = 4$ 时是 $24$ 种，所以这不是一番手动平均就能抹平的麻烦。

::: warning "模型从我给的示例里学会了任务"
示例更多时表现变好，并不意味着模型从它们推断出了输入到标签的映射。增益的很大一部分往往来自示例展示的**格式**与**标签空间**——它们告诉模型该去执行自己早已会做的哪个任务。要弄清你的模型在用的是什么，就去做 [[#sec-what-matters]] 里的对照实验：打乱标签、去掉输入、更换格式。把少样本增益的大小当作关于某一个模型、某一个模板、某一套示例的测量结果，而不是任务本身的性质。
:::

## 模型从示例中得到了什么？ {#sec-what-matters}

如果模型真的从示例那里学会了映射，示例里的错误标签就该造成严重损害。Min 等人（2022）正是在一系列模型的分类与选择题任务上检验了这一点，发现情况基本不然。

- 把示例的标准答案标签换成标签集里的**随机标签**，在他们大多数设定下只让准确率略降——通常降几个百分点，远小于零样本到少样本之间的差距。
- 去掉**输入**（只留标签）或把它们换成不相关语料的随机句子，损害更大：示例起作用，部分是因为它们展示了输入的分布。
- 把标签换成标签集之外的随机**英文词**会造成严重损害：示例告诉模型哪些输出是被允许的。
- 保持**格式**——输入与标签配对的结构——很重要：只有输入或只有标签的示例，比两者都有（哪怕配对是错的）表现更差。

他们的解释是：对这些任务与模型，示例主要服务于**任务识别**——通过标签空间、输入分布和格式，帮模型定位一个它已经会做的任务。输入到标签的映射本身是更弱的信号。

这一发现并非处处成立，后续工作做了细化。Wei 等人（2023）表明，足够大的模型**确实能**跟随标签被系统性翻转（凡是积极都标成消极，反之亦然）的示例，压过自己对任务的先验知识；较小的模型则基本无视翻转；他们还表明大模型能学到映射到语义无关标签（*foo*/*bar*）的任务。Pan 等人（2023）区分了**任务识别**（小模型也具备）与**任务学习**——获得一个新的输入到标签的映射——后者随规模与示例数量提升。截至 2026 年，公允的总结是：两者都会发生，所占比例取决于模型、任务以及任务有多陌生。

::: quiz
Min 等人（2022）把少样本示例的标准答案标签换成同一标签集里的随机标签。对分类与选择题任务，他们主要发现了什么？
- [ ] 准确率跌到随机水平，说明模型从示例学到了映射。
- [x] 准确率只略降，说明示例主要传达标签空间、输入分布与格式。
- [ ] 准确率上升，因为随机标签起到正则化的作用。
- [ ] 结果只取决于示例的数量，与标签无关。
::: solution
在他们大多数设定下，下降很小，远小于零样本到少样本的增益。去掉输入或标签空间损害更大。后续工作（Wei et al., 2023）发现最大的模型对翻转的标签更敏感，所以结论关乎程度，而非绝对。
:::
:::

## 作为贝叶斯推断的上下文学习模型 {#sec-bayes}

一个只被训练来预测网页文本下一个词元的网络，凭什么能做示例所指定的任务？Xie 等人（2022）在一个理想化设定中给出了一个解释。假设预训练文本由隐藏的**概念** $\theta$——主题、格式、任务、风格——的混合生成：每篇文档先由先验 $p(\theta)$ 抽出一个概念，再由 $p(\text{文本}\mid\theta)$ 生成文本。在这类数据上最优地预测下一个词元的模型必须计算**后验预测分布**

$$
p(y \mid \text{提示}) = \int p(y \mid \text{提示}, \theta)\, p(\theta \mid \text{提示})\, d\theta,
$$ {#eq-predictive}

因此它必须隐式地推断：到目前为止的文本是哪个概念生成的。一个少样本提示是一篇所有示例共享同一概念的短文档；每个例子都是该概念的证据，随着证据累积，后验集中起来，预测分布表现得好像模型"知道"了任务。

::: definition 隐式贝叶斯推断模型 {#def-bayes-icl}
在 ICL 的**隐式贝叶斯推断**模型中，把由示例 $(x_1, y_1), \dots, (x_k, y_k)$ 组成的提示当作从 $p(x, y\mid\theta^*)$ 抽出的数据，其中未知概念 $\theta^*$ 属于集合 $\Theta$、服从先验 $p(\theta)$；模型对查询的预测就是下述后验之下的后验预测 [[#eq-predictive]]

$$
p(\theta\mid D_k) \propto p(\theta)\prod_{i=1}^{k} p(x_i, y_i\mid\theta).
$$
:::

最简单的推论是后验能很快锁定正确的概念。考虑概念集合有限、示例确实从 $\theta^*$ 独立抽出的情形。

::: proposition 后验集中 {#prop-concentration}
设 $\Theta$ 有限，$p(\theta^*) > 0$，$D_k$ 由 $k$ 个从 $p(\cdot\mid\theta^*)$ 独立抽出的样本组成。若 $\theta\ne\theta^*$ 满足 $\operatorname{KL}\big(p(\cdot\mid\theta^*)\,\Vert\,p(\cdot\mid\theta)\big) = \Delta > 0$，则几乎必然有

$$
\frac1k\log\frac{p(\theta\mid D_k)}{p(\theta^*\mid D_k)} \longrightarrow -\Delta \qquad (k\to\infty),
$$

于是每个 $\Delta > 0$ 的错误概念的后验概率随示例数量指数衰减到零。
:::

::: proof
由贝叶斯定理（[[math-for-ml/probability#thm-bayes]]），归一化常数在比值中相消：

$$
\log\frac{p(\theta\mid D_k)}{p(\theta^*\mid D_k)} = \log\frac{p(\theta)}{p(\theta^*)} + \sum_{i=1}^{k}\log\frac{p(x_i, y_i\mid\theta)}{p(x_i, y_i\mid\theta^*)}.
$$

除以 $k$。第一项是常数除以 $k$，趋于 $0$。和式是 $k$ 个独立同分布项的平均，其在 $\theta^*$ 之下的期望为 $\E_{\theta^*}\!\big[\log p(\cdot\mid\theta) - \log p(\cdot\mid\theta^*)\big] = -\operatorname{KL}\big(p(\cdot\mid\theta^*)\Vert p(\cdot\mid\theta)\big) = -\Delta$（[[math-for-ml/information-theory#def-kl]]）。由强大数定律，该平均以概率 $1$ 收敛于 $-\Delta$。于是 $\theta$ 相对 $\theta^*$ 的对数几率以 $-k\Delta$ 的速率下降，且 $p(\theta\mid D_k)\le p(\theta\mid D_k)/p(\theta^*\mid D_k)\to0$。
:::

::: example 三个示例 {#ex-posterior}
一个模型在某个提示上权衡两个概念——*sentiment*（情感）分类与 *topic*（主题）分类——先验概率相同。每个示例在 *sentiment* 之下的可能性都是 *topic* 之下的 $3$ 倍。$k = 0, 1, 2, 3$ 个示例之后，*sentiment* 的后验概率是多少？
::: solution
后验几率是先验几率 $1$ 乘以每个示例的 $3$ 倍：$3^k$。概率为 $3^k/(3^k + 1)$：$0.5$、$0.75$、$0.9$ 与 $27/28 = 0.964$。寥寥几个示例就足以让一个概念占绝对优势，这与"少样本增益大多来自头几个示例"的观察一致。
:::
:::

::: widget plot
f: 1/(1 + ((1 - p)/p)*r^(-x))
x: 0, 12
y: 0, 1.05
sliders: p=0.5:0.01:0.99:0.01; r=3:1.05:6:0.05

caption: 真实概念的后验概率随示例数 $k$ 的变化，先验为 $p$、每个示例的似然比为 $r$。标注的点是 [[#ex-posterior]]（$p = 0.5$，$r = 3$）。不利于真实概念的先验（$p$ 小，好比罕见的任务）会推迟上升；信息量弱的示例（$r$ 接近 $1$）让上升变慢。在贝叶斯模型里，这两者都解释了为什么有些任务需要的示例比其他任务多得多。
:::

这个模型一口气解释了好几个观察。标签随机时示例仍有帮助，因为输入与格式本身就是概念的证据。不熟悉的格式有害，因为它让提示不像任何一篇预训练文档。还有一个特征性的失败模式：Xie 等人指出，示例的拼接本身就是不自然的文本——示例之间的边界是任何单篇预训练文档内部都不会出现的过渡——并在一个合成数据集（GINC，由隐马尔可夫模型的混合生成）上表明，小型 Transformer 仍能进行上下文学习，准确率随示例的数量与长度上升。

一个干净的特例是看抛硬币的模型。若隐藏概念是硬币的偏置 $\pi$、先验均匀，且上下文里 $n$ 次抛掷中有 $h$ 次正面，则后验为 $\operatorname{Beta}(1 + h, 1 + n - h)$，下一次抛出正面的贝叶斯最优概率为 $(h+1)/(n+2)$，即拉普拉斯的继承律（rule of succession）。在随机抽取的硬币抛掷序列上训练的 Transformer 学会输出接近这一预测的值，这是单参数任务的上下文学习最纯粹的形式。

::: widget bayes

caption: 一个理想的抛硬币上下文学习者。对硬币偏置的先验均匀，$\operatorname{Beta}(1, 1)$；在 $10$ 次抛掷中有 $7$ 次正面的上下文之后，后验为 $\operatorname{Beta}(8, 4)$，对下一次抛出正面的预测概率是它的均值 $8/12 = 0.667$。按同样的比率增加抛掷次数：后验变窄，正如 [[#prop-concentration]] 中对概念的后验随示例加入而集中。

这个模型**没有**确立的，是真实大模型真的在计算这样的后验。它说的是：对理想化数据而言，一个最优预测器会怎么做；而真实的预训练数据不是少数几个整齐概念的混合，真实的模型也不最优。最好把它读作一种解释——训练目标**为何奖励**上下文学习。

## 作为梯度下降的上下文学习模型 {#sec-gd}

第二条研究线索问一个机制性的问题：Transformer 的前向传播能在示例上运行什么算法？Garg 等人（2022）在形如 $(\mathbf{x}_1, y_1, \dots, \mathbf{x}_k, y_k, \mathbf{x})$ 的提示上从头训练 Transformer，每个提示使用一个新的随机线性函数 $y = \mathbf{w}^\top\mathbf{x}$，发现它们对查询预测 $y$ 的水平几乎与在示例上拟合的最小二乘相当——也就是说，它们在上下文中找到了一个回归算法。von Oswald 等人（2023）与 Akyürek 等人（2023）则问是哪种算法。最简单的回答是：一层线性注意力就能精确地执行一步梯度下降。

::: definition 线性自注意力 {#def-linear-attention}
**线性注意力**去掉了 [[transformers/self-attention#def-attention]] 中的 softmax：对查询 $\mathbf{q}$、键 $\mathbf{k}_i$ 与值 $\mathbf{v}_i$，其输出为 $\sum_i \mathbf{v}_i\,(\mathbf{k}_i^\top\mathbf{q})$，可带缩放。
:::

::: proposition 一层注意力，一步梯度 {#prop-gd}
设示例为 $(\mathbf{x}_i, y_i)$，$i = 1, \dots, k$，其中 $\mathbf{x}_i\in\R^d$，考虑最小二乘 $L(\mathbf{w}) = \frac12\sum_i (y_i - \mathbf{w}^\top\mathbf{x}_i)^2$。从 $\mathbf{w}_0 = \mathbf{0}$ 出发、学习率为 $\eta$ 的一步梯度下降，对查询 $\mathbf{x}$ 的预测是

$$
\hat y_{\text{GD}} = \mathbf{w}_1^\top\mathbf{x} = \eta\sum_{i=1}^{k} y_i\,\mathbf{x}_i^\top\mathbf{x}.
$$

它等于以 $\mathbf{k}_i = \mathbf{x}_i$ 为键、$v_i = \eta y_i$ 为值、$\mathbf{q} = \mathbf{x}$ 为查询的线性注意力的输出。
:::

::: proof
梯度为 $\nabla L(\mathbf{w}) = -\sum_i (y_i - \mathbf{w}^\top\mathbf{x}_i)\mathbf{x}_i$，在 $\mathbf{w}_0 = \mathbf{0}$ 处为 $-\sum_i y_i\mathbf{x}_i$。于是 $\mathbf{w}_1 = \mathbf{w}_0 - \eta\nabla L(\mathbf{w}_0) = \eta\sum_i y_i\mathbf{x}_i$，且 $\mathbf{w}_1^\top\mathbf{x} = \eta\sum_i y_i\,\mathbf{x}_i^\top\mathbf{x}$。以所列的键、值与查询作线性注意力，输出 $\sum_i (\eta y_i)(\mathbf{x}_i^\top\mathbf{x})$，正是同一个和式。若每个词元携带词对 $\mathbf{z}_i = (\mathbf{x}_i, y_i)$，则键、值与查询都是词元的线性函数——向 $\mathbf{x}$ 坐标与 $y$ 坐标的投影——因此可由合适的矩阵 $W_K$、$W_V$ 与 $W_Q$ 产生。
:::

换成一般的投影矩阵，同一层对某个学到的矩阵 $W$ 计算 $\eta\,\mathbf{x}^\top W\sum_i y_i\mathbf{x}_i$，即一步**带预条件**的梯度下降。von Oswald 等人表明，在回归提示上训练的线性注意力 Transformer 收敛到实现这一构造的权重，更深的堆叠表现得像基于梯度的方法的多步，而带 softmax 注意力的训练好的模型在同一合成任务上也有类似表现。Akyürek 等人（2023）发现，训练好的模型依深度与宽度不同，分别可与梯度下降、岭回归或精确最小二乘相匹敌。

::: example 手算一步 {#ex-gd-step}
示例 $\mathbf{x}_1 = (1, 0)$，$y_1 = 2$；$\mathbf{x}_2 = (0, 1)$，$y_2 = -1$；$\mathbf{x}_3 = (1, 1)$，$y_3 = 1$；学习率 $\eta = 0.5$；查询 $\mathbf{x} = (2, 1)$。用两种方式计算一步预测。
::: solution
梯度下降：$\sum_i y_i\mathbf{x}_i = (2, 0) + (0, -1) + (1, 1) = (3, 0)$，于是 $\mathbf{w}_1 = (1.5, 0)$，$\hat y = 1.5\cdot2 + 0\cdot1 = 3$。线性注意力：键–查询分数为 $\mathbf{x}_i^\top\mathbf{x} = 2, 1, 3$，值为 $\eta y_i = 1, -0.5, 0.5$，输出为 $1\cdot2 - 0.5\cdot1 + 0.5\cdot3 = 3$。注意力分数衡量每个示例与查询的相似程度，输出则是它们的标签以相似度为权的投票。
:::
:::

这一等价性在一个随机任务上很容易用数值检验：

```python
import random
random.seed(0)
d, n, eta = 3, 20, 0.05
w_true = [random.gauss(0, 1) for _ in range(d)]
X = [[random.gauss(0, 1) for _ in range(d)] for _ in range(n)]   # n x d 上下文的输入
y = [sum(a*b for a, b in zip(w_true, x)) for x in X]             # n 个目标
xq = [random.gauss(0, 1) for _ in range(d)]                      # 查询输入
# (a) 从 w = 0 出发对 L(w) = 1/2 sum_i (y_i - w.x_i)^2 走一步梯度
grad = [-sum(y[i]*X[i][j] for i in range(n)) for j in range(d)]  # w = 0 处的 dL/dw
w1 = [-eta*g for g in grad]
pred_gd = sum(a*b for a, b in zip(w1, xq))
# (b) 线性注意力：键 x_i，值 y_i，查询 x_q，无 softmax，缩放 eta
pred_attn = eta*sum(y[i]*sum(a*b for a, b in zip(X[i], xq)) for i in range(n))
print("one GD step :", round(pred_gd, 6))
print("linear attn :", round(pred_attn, 6))
print("true y_q    :", round(sum(a*b for a, b in zip(w_true, xq)), 6))
```

```text
one GD step : 1.781445
linear attn : 1.781445
true y_q    : 1.389016
```

两个预测打印出的每一位都相同。两者都不等于真值，因为从零出发的一步梯度离最小二乘解还差得远；这正是更深的模型（能走更多步）在上下文中回归得更好的原因。

::: warning 梯度下降结果没有说明什么
[[#prop-gd]] 是一个构造：它说明注意力**能够**实现一步梯度下降，实验则说明在合成回归上训练的小模型**确实**这么做了。它没有说明一个预训练的大模型在翻译法语或分类情感时，其前向传播在跑梯度下降。Shen 等人（2024）在真实模型中把上下文学习与基于梯度的微调相对照，发现现实条件下这种对应很弱。把这个结果当作"注意力能计算什么"的模型来用，而不是任何上下文行为的描述。
:::

机制可解释性给出了图景中第三块、也更具体的拼图。Olsson 等人（2022）识别出**归纳头**：一对注意力头，它们找到当前词元此前的一次出现，并复制其后跟随的内容（`… A B … A` → `B`）。它们在训练中途突然形成，恰在上下文学习——以"上下文后部词元的损失降到前部词元之下"来度量——急剧改善的同一点上；作者论证它们解释了小模型中上下文学习的很大一部分。[[interpretability]] 详细处理这类回路。

## 用好上下文学习 {#sec-practice}

上面的发现可以化为几条简短的实践，[[prompting-rag/prompt-design]] 会把每一条进一步展开。

- **先测零样本。**指令微调模型（[[post-training/instruction-tuning]]）配一条清晰的指令，零样本往往就达到过去基座模型少样本才达到的水平；而示例要在每次调用中都付词元。
- **有讲究地挑示例。**与查询相似的示例有帮助：Liu 等人（2022）用嵌入相似度（[[prompting-rag/text-embeddings]]）检索最近的训练样本，胜过了随机挑选。覆盖标签空间，避免示例中偏斜的标签分布。
- **控制顺序与格式。**跨多次运行打乱示例并报告散布；示例与查询之间保持模板一致。
- **输出是标签时就打分，不要解析**，如 [[#eq-label-score]]，并考虑上下文校准。
- **知道何时该微调。**当任务有成千上万条带标签样本、要运行百万次、或需要模型抗拒的行为时，微调（包括参数高效方法，[[post-training/parameter-efficient-tuning]]）在成本与准确率上通常胜过 ICL。Mosbach 等人（2023）发现，公平比较下，少样本微调与 ICL 的域外泛化能力相当。

::: example 提示的代价与微调的代价 {#ex-cost}
某任务要处理一百万次查询。$16$ 样本提示给每次查询增加 $1500$ 个词元；微调后的模型一个都不要。ICL 总共多处理多少输入词元？与在 $20{,}000$ 条各 $100$ 词元的样本上训练 $3$ 个轮次的微调相比如何？
::: solution
ICL：$10^6\cdot1500 = 1.5\times10^9$ 个额外输入词元。微调要处理 $20{,}000\cdot100\cdot3 = 6\times10^6$ 个训练词元，每个的代价约相当于推理词元的三倍（一次前向加一次反向，[[neural-networks/backpropagation]]），即约 $1.8\times10^7$ 个推理词元当量——比示例少将近一百倍。这个比较没有算上收集 $20{,}000$ 个标签与部署一个单独模型的成本，而那往往才是决定性的；但在高吞吐下，长提示很贵。提示缓存（[[inference/kv-cache]]）能降低共享前缀的代价，却去不掉它。
:::
:::

::: history
Radford et al.（2019）观察到 GPT-2 能把某些任务改写成文本形式后零样本完成，例如由 `TL;DR:` 触发的摘要。Brown et al.（2020）以 GPT-3 命名并度量了上下文学习，区分了零样本、单样本与少样本评测。Zhao et al.（2021）记录了少样本提示的各种偏差并提出上下文校准；Lu et al.（2022）表明示例的顺序影响之大，Liu et al.（2022）表明示例的挑选影响之大。Min et al.（2022）发现标准答案标签的影响出人意料地小，Wei et al.（2023）则发现更大的模型能跟随翻转的标签。理论方面，Xie et al.（2022）把 ICL 解释为隐式贝叶斯推断；Garg et al.（2022）表明 Transformer 会在上下文中学习线性回归，von Oswald et al.（2023）与 Akyürek et al.（2023）把它与梯度下降联系起来。Olsson et al.（2022）把上下文学习的涌现与归纳头联系起来。随着长上下文出现，Agarwal et al.（2024）研究了成百上千个示例的多样本 ICL。
:::

::: summary
- 上下文学习是往提示里加入示例后，一个权重冻结的模型的预测随之改善；零样本、单样本与少样本提示的区别在于示例数量。
- 分类时给标签词打分，而不是解析自由文本；预测表现出多数标签、近因与常见词元偏差，上下文校准能除去一部分。
- 准确率强烈依赖用了哪些示例、按什么顺序；要测量散布。
- 对许多任务与模型，示例主要传达标签空间、输入分布与格式；更大的模型也能在上下文中真正学会新的映射。
- 两个理论模型，都经过理想化：ICL 作为对隐藏概念的隐式贝叶斯推断，其后验随示例数量指数集中；以及 ICL 作为梯度下降，因为一层线性注意力就实现了最小二乘的精确一步梯度。
- 提示在每次调用都要付词元；吞吐量大或标签充足时，微调往往更好。
:::

## 习题

::: exercise 更长的提示预算 {level=1 check="25"}
一个模型有 $4096$ 词元的上下文。指令占 $100$ 词元，查询 $80$ 词元，为答案预留 $20$ 词元。每个示例占 $150$ 词元。放得下多少个示例？
::: solution
还剩 $4096 - 100 - 80 - 20 = 3896$ 个词元，而 $3896/150 = 25.97$，所以放得下 $25$ 个示例。
:::
:::

::: exercise 三个标签词元 {level=1 check="0.665"}
一次三分类提示之后，标签词元 *positive*、*neutral* 与 *negative* 的 logits 为 $1$、$0$ 与 $-1$。打分给 *positive* 的概率是多少（保留三位小数）？
::: solution
$e^{1}/(e^{1} + e^{0} + e^{-1}) = 2.718/(2.718 + 1 + 0.368) = 2.718/4.086 = 0.665$。
:::
:::

::: exercise 校准一个微弱的偏好 {level=1 check="0.449"}
模型对 (*positive*, *negative*) 给出 $\mathbf{p}(x) = (0.55, 0.45)$，对无内容输入给出 $\mathbf{p}_{\text{cf}} = (0.6, 0.4)$。计算校准后 *positive* 的概率（保留三位小数）与校准后的预测。
::: solution
$(0.55/0.6,\ 0.45/0.4) = (0.9167,\ 1.125)$，和为 $2.0417$；校准后 *positive* 的概率为 $0.9167/2.0417 = 0.449$。预测变为 *negative*。
:::
:::

::: exercise 一个不被先验看好的概念 {level=2 check="0.8"}
在贝叶斯模型里，正确概念的先验概率为 $0.2$，每个示例在它之下的可能性是唯一对立面的两倍。四个示例之后它的后验概率是多少？
::: solution
先验几率 $0.2/0.8 = 0.25$；四个示例后几率为 $0.25\cdot2^4 = 4$，故概率为 $4/5 = 0.8$。
:::
:::

::: exercise 需要多少示例？ {level=2 check="5"}
两个概念先验相同，每个示例的似然比为 $3$，正确概念的后验至少达到 $0.99$ 所需的最少示例数是多少？
::: solution
需要 $3^k/(3^k + 1)\ge 0.99$，即 $3^k\ge 99$。由于 $3^4 = 81 < 99\le 243 = 3^5$，答案是 $k = 5$。
:::
:::

::: exercise 作为回归的线性注意力 {level=2 check="0.9"}
示例 $\mathbf{x}_1 = (1, 2)$，$y_1 = 1$，$\mathbf{x}_2 = (2, 0)$，$y_2 = 3$；查询 $\mathbf{x} = (1, 1)$；$\eta = 0.1$。计算从 $\mathbf{w} = \mathbf{0}$ 出发一步梯度的预测，并与 [[#prop-gd]] 的线性注意力形式相互验证。
::: solution
$\sum_i y_i\mathbf{x}_i = (1, 2) + (6, 0) = (7, 2)$，于是 $\mathbf{w}_1 = (0.7, 0.2)$，$\hat y = 0.7 + 0.2 = 0.9$。注意力形式：分数 $\mathbf{x}_i^\top\mathbf{x} = 3$ 与 $2$，值 $0.1$ 与 $0.3$，输出 $0.1\cdot3 + 0.3\cdot2 = 0.9$。
:::
:::

::: exercise 示例的排列顺序 {level=1 check="40320"}
Lu 等人（2022）评测了固定示例集合的各种排列。$8$ 个互不相同的示例有多少种顺序？为什么即使 $k$ 不大，穷举顺序也不可行？
::: solution
$8! = 40{,}320$。每种顺序都需要在验证集上做一次完整评测，因此即使 $k = 8$ 也要花掉数万次评测运行，而 $k = 12$ 约有 $4.8\times10^8$ 种顺序。实际中人们抽取若干顺序并报告散布，或使用挑选的启发式。
:::
:::

::: exercise 上下文中的拉普拉斯继承律 {level=2 check="2/3"}
在一个 Transformer 上训练硬币抛掷序列，每段序列来自一枚偏置在 $[0, 1]$ 上均匀抽取的硬币。在 $10$ 次抛掷、$7$ 次正面的上下文末尾，一个最优模型应输出正面的什么概率？解释为什么这是 [[#def-icl]] 意义上的上下文学习。
::: solution
偏置的后验为 $\operatorname{Beta}(8, 4)$，正面的预测概率是它的均值 $8/12 = 2/3$。权重是固定的；预测依赖于上下文，并且随着上下文提供当前硬币更多的抛掷，在期望意义下变得更准。这正是那个行为主义的定义。
:::
:::

::: exercise 设计一个标签敏感性实验 {level=2}
你想知道一个模型在情感任务上用的是示例的输入到标签的映射，还是仅仅用了格式。设计一个至少含四个处理组的实验，说明什么样的结果分别支持哪种解释，并指出你必须控制的两个混淆因素。
::: solution
各处理组都使用同样的 $k$ 个示例，并大量随机抽取示例与顺序：(1) 零样本；(2) 标准答案标签；(3) 标签集内的随机标签；(4) 翻转标签（凡是积极标消极，反之亦然）；可选 (5) 输入换成随机句子、保留标准答案标签，以及 (6) 标签换成无关词。若 (2) ≈ (3) ≫ (1)，增益来自格式、标签空间与输入，而非映射。若 (4) 明显低于 (1)——模型跟随了翻转的映射——它就真的在上下文中学习映射。混淆因素：示例的标签均衡（多数标签偏差可能伪装或掩盖效应，各组之间必须保持不变），以及不同示例集合与顺序之间的方差（对许多次抽取报告均值与散布，并如 [[ml-fundamentals/evaluation-metrics#sec-uncertainty]] 给出置信区间）。要在不止一个模型规模上做实验，因为答案会随规模改变。
:::
:::

::: exercise 带预条件的梯度步 {level=3}
设每个词元为 $\mathbf{z}_i = (\mathbf{x}_i, y_i)\in\R^{d+1}$，查询词元 $\mathbf{z} = (\mathbf{x}, 0)$。证明取 $W_K = W_Q = \begin{pmatrix} I_d & \mathbf{0}\end{pmatrix}$（向前 $d$ 个坐标的投影）、$W_V = \begin{pmatrix}\mathbf{0}^\top & \eta\end{pmatrix}$ 的线性注意力复现了 [[#prop-gd]]；而把 $W_Q$ 换成 $\begin{pmatrix} A & \mathbf{0}\end{pmatrix}$（$A\in\R^{d\times d}$）得到以 $A^\top$ 为预条件矩阵的一步梯度下降。为什么在输入协方差为 $\Sigma$ 的回归提示上训练的模型会受益于这样的 $A$？
::: solution
这里 $\mathbf{k}_i = W_K\mathbf{z}_i = \mathbf{x}_i$，$v_i = W_V\mathbf{z}_i = \eta y_i$，$\mathbf{q} = W_Q\mathbf{z} = \mathbf{x}$，于是输出 $\sum_i v_i\,\mathbf{k}_i^\top\mathbf{q} = \eta\sum_i y_i\mathbf{x}_i^\top\mathbf{x}$，正是 [[#prop-gd]]。取 $\mathbf{q} = A\mathbf{x}$ 时输出为 $\eta\sum_i y_i\mathbf{x}_i^\top A\mathbf{x} = (\eta A^\top\sum_i y_i\mathbf{x}_i)^\top\mathbf{x}$；由于 $-\sum_i y_i\mathbf{x}_i$ 是 $\mathbf{0}$ 处的梯度，这就是 $\mathbf{w}_1 = -\eta A^\top\nabla L(\mathbf{0})$ 的预测，即一步预条件步。当输入的协方差为 $\Sigma$ 时，对真实的 $\mathbf{w}$ 有 $\sum_i y_i\mathbf{x}_i\approx k\,\Sigma\mathbf{w}$，所以普通的一步偏向高方差方向；取 $A^\top\approx(k\Sigma)^{-1}$ 便得 $\mathbf{w}_1\approx\mathbf{w}$，几乎是一步到位的最小二乘解。在大量这样的提示上训练的模型可以把这个 $A$ 学进权重，这是训练好的 Transformer 回归得比朴素的一步梯度下降更好的原因之一。
:::
:::

::: exercise 当概念无法区分时 {level=3}
在 [[#prop-concentration]] 中，设两个概念 $\theta^*\ne\theta$ 满足 $\operatorname{KL}\big(p(\cdot\mid\theta^*)\Vert p(\cdot\mid\theta)\big) = 0$。$k$ 增大时它们的后验比值会怎样？把它与一个示例同时符合两个不同任务的提示联系起来（例如"分类情感"与"分类评论是否提及价格"，而每个积极示例恰好都提及了价格），并提出改进提示的办法。
::: solution
KL 散度为零意味着两个概念对示例给出相同的分布，于是每个似然比都是 $1$，对一切 $k$ 后验比值都停留在先验比值：再多这样的示例也无法区分二者。在那个提示例子里，每个示例都被两个任务同样地解释，模型的选择取决于它的先验——哪个任务在预训练文本中更常见——而两个任务有分歧的查询（一条不提及价格的积极评论）就成了按该先验加权的抛硬币。补救办法是加入能区分两个假设的示例（一条不提价格的积极评论、一条提到价格的消极评论），或用一条指令把任务说出来，它相当于某个概念的强力证据。
:::
:::
