一个训练好的语言模型是一个被完整写出的函数：每个权重都是已知的，每个激活都可以被记录，任何输入的输出都能被精确地重新计算。在这个意义上，它没有什么可隐藏的。可当我们问模型**为什么**回答 "Paris" 而不是 "Lyon"，或者它遵循一条指令究竟是因为理解了它，还是因为措辞与训练数据相似时，权重并不会告诉我们答案。权重有数十亿个，它们是由梯度下降而非设计者设定的，也没有人写下过任何一个权重的用途。**可解释性**正是要把这份完整却不可读的描述变成人们能够理解、检验和使用的解释的研究纲领。

本章为整个课程做铺垫。它解释为什么需要可解释性——为了科学、调试、信任与安全——以及为什么这些动机会对"什么才算一个解释"引出不同的标准。它介绍方法的主要家族：把模型当作黑箱的**行为式**分析、把功劳分配给输入的**归因**方法、检验人类概念的**概念式**方法，以及试图逆向解析网络所实现算法的**机制**可解释性。随后它把区分好解释与仅仅令人信服的解释的两个性质讲精确——**忠实性**与**可信性**——并引出贯穿本课程其余部分的中心思想：解释是网络的一个**更简单的因果模型**，可以通过对网络**干预**、检验这个更简单的模型是否预言所发生之事来对它进行测试。末尾一个小型数值实验室展示了一个通过了全部行为检验、却在干预检验下失败的"解释"。

## 为什么需要模型解释？ {#sec-why}

Lipton（2018）在题为《模型可解释性的迷思》（*The Mythos of Model Interpretability*）的文章中指出，"可解释性"一词被用来指许多不同的东西，而论文常常声称自己做到了可解释性，却不说是哪一种。他列出了驱动这一需求的各项**期望（desiderata）**：

- **信任。** 用户想知道何时可以信赖一个模型。Lipton 指出这与准确率并不相同：如果模型的错误恰好落在人类也会犯错的情形上，或者人们知道它在哪些输入上处理得糟糕，就更可能信任一个模型。
- **因果性。** 科学家希望模型能提出关于世界的假说，同时记住：预测模型捕捉的是关联，不一定是原因。
- **可迁移性。** 我们想知道当部署分布不同于训练分布时模型是否仍会表现良好——它学到的是预期的规则还是捷径。
- **信息量。** 即使不揭示模型的内部机制，解释也可以对人类决策者有用。
- **公平、合乎伦理的决策。** 影响人类的决策可能需要可以被申诉，这就要求知道决策依据了什么。

对语言模型而言，还有一个动机已经变得核心：**安全**。一个模型可能在评测中给出可接受的输出，而理由在部署中并不成立；也可能表征了某些信息——例如自己正在被测试——却不报告。行为测试只在有限多个输入上采样模型的行为；对其内部计算的理解，原则上能够支持关于没人试过的输入的论断。这个动机很宏大，而现有方法能否兑现它，正是 [[interpretability/open-problems]] 的开放问题之一；本课程既呈现这些期望，也呈现怀疑的理由。

Lipton 还区分了两类回答。**透明性**关乎模型本身：如果一个人在合理时间内能逐步模拟模型的计算，它就是**可模拟的**；如果每个部分（输入、参数、中间值）都有直观含义，它就是**可分解的**；如果学习过程已被理解，它就是**算法透明的**（线性模型的损失是凸的，其解因此可被完全刻画）。**事后可解释性**则关乎对一个不透明的模型事后给出的解释：文字解释、可视化、对单个预测的局部解释、以及以样例作解释。大语言模型在这三个意义上都不透明，所以用 Lipton 的术语说，本课程的一切都是事后的——尽管机制可解释性追求的是接近可分解性的东西：它是在训练之后被找回的，而不是设计时嵌入的。

::: example 被解释的对象有多大？ {#ex-count}
GPT-2 small 有 $L = 12$ 层，每层有 $h = 12$ 个注意力头和一个宽度为 $3072$ 的前馈层，残差流维数为 $d = 768$。数一数它的注意力头和前馈神经元的个数；若要用穷举找出对某个行为负责的"那组"注意力头，需要考察的头子集有多少个？
::: solution
头：$12\times12 = 144$ 个。神经元：$12\times3072 = 36{,}864$ 个。头的子集：$2^{144}\approx2.2\times10^{43}$ 个。一个小模型已经有数万个候选单元，而仅头的子集空间就远非穷举搜索所能覆盖。因此可解释性方法要么需要强假设（由人提出一个机制并检验它），要么需要贪心或基于梯度的搜索（[[interpretability/circuits]]），要么换一种"单元"——用 [[interpretability/sparse-features]] 的**特征**而不是神经元。前沿模型大约有上百层、残差流维数达到数万，于是问题按数量级继续膨胀。
:::
:::

## 方法地图 {#sec-map}

解释可以沿若干条彼此独立的轴来分类。最常见的是 Doshi-Velez 与 Kim（2017）以及 Lipton（2018）给出的几条：

- **局部或全局。** 局部解释关乎一个预测（"对这个提示为什么给出这个答案？"）；全局解释关乎模型的一般行为（"它是怎么做加法的？"）。
- **固有或事后。** 固有可解释的模型是为被理解而建造的（短的决策列表、稀疏线性模型、概念瓶颈）；事后方法解释的是一个训练时根本没有考虑可解释性的模型。
- **模型无关或模型特定。** 无关方法只用输入与输出（有时还有梯度）；特定方法利用架构，例如注意力的结构。

在神经网络的事后可解释性内部，常用的有四大类。它们的区别在于把什么当作解释的对象。

::: definition 可解释性方法的家族 {#def-families}
设 $f$ 是一个训练好的模型，经由内部激活 $a(x)$ 把输入 $x$ 映为输出 $f(x)$。

1. **行为式**方法只通过输入–输出行为研究 $f$：设计输入（极小对、反事实编辑、留出分布），测量 $f(x)$ 如何变化。
2. **归因式**方法给每个输入特征（或每个内部单元）配一个数，度量它对某个特定输出的贡献——例如梯度、梯度乘以输入、或 Shapley 值（[[interpretability/probing-attribution]]）。
3. **概念式**方法追问激活 $a(x)$ 是否、以及在何处表征了人指定的概念 $C$——办法是训练一个探针从 $a(x)$ 预测 $C$，或找一个概念方向并测量输出对它的敏感度。
4. **机制式**方法立志识别网络计算了哪些变量（**特征**）以及联系它们的计算（**回路**），并通过对 $a(x)$ 的干预来验证这份描述。
:::

这些家族并不互斥，一项研究常常把它们结合起来。它们也没有高下之分：行为式方法能回答模型**做**了什么的问题，这是内部分析不可替代的；关于语言模型许多最有用的实际结论——逆转诅咒、对提示格式的敏感、谄媚——都是行为式的。

**行为式分析**是最古老的家族。对语言模型而言，它包括语法的极小对测试（Linzen、Dupoux 与 Goldberg，2016）、能力清单（Ribeiro 等人，2020）以及 [[evaluation]] 的全套装置。它的长处在于结论直接关于输出；短处在于它局限于人想得出来的输入。

**归因式**方法产生显著性图与词元级重要性分数。它们便宜、模型无关，回答的是局部问题。它们的陷阱——饱和、对基线的敏感、方法之间的分歧——是 [[interpretability/probing-attribution]] 的主题。

**概念式**方法从人挑选的一个概念出发。*Testing with Concept Activation Vectors*（用概念激活向量作测试，TCAV；Kim 等人，2018）收集带与不带某个概念的样本，在某一层的激活上训练一个线性分类器，把其决策边界的法向量当作概念方向，再测量沿该方向移动在多大比例的样本上提升类别得分。**概念瓶颈模型**（Koh 等人，2020）在训练时先预测人标注的概念、再只通过这些概念预测标签，从而使概念成为固有的。语言模型上的线性探针（[[text-and-language/linguistic-structure]]）属于这一家族：它们追问词性、句法深度或真实性能否从某一层线性读出。

**机制可解释性**是本课程的主角，它把网络自身的计算当作被解释的对象。Olah 等人（2020）在《放大观察：回路导论》（*Zoom In: An Introduction to Circuits*）中用三个带猜测色彩的论断为它定了框架：网络中含有有意义的**特征**（对应输入某些性质的、激活空间中的方向）；特征由权重连成实现可理解算法的**回路**；类似的特征与回路在不同模型之间反复出现（**普适性**）。对 Transformer，Elhage 等人（2021）给出了 [[interpretability/residual-stream]] 的数学框架，而此后的发现——归纳头、叠加、特征的稀疏字典——构成了本课程的大部分篇幅。

::: quiz
一位研究者报告："模型第 18 层含有一个关于陈述是否为真的线性表征：在其上训练的探针在留出陈述上达到 $85\%$ 准确率。"这属于哪个方法家族？这一证据确立了什么？
- [ ] 机制式；它表明模型利用自己的真实性表征来给出回答。
- [x] 概念式；它表明在该分布上真值标签可以从第 18 层线性解码，而非模型使用了这一信息。
- [ ] 行为式；它表明模型在 $85\%$ 的情形上正确回答真假问题。
- [ ] 归因式；它指明了哪些词元使一个陈述为真。
::: solution
为人指定的概念训练探针是概念式方法。可解码性说的是激活中**存在**哪些信息；模型的后续层是否读取这一信息、以何种形式读取，需要干预来回答——沿探针的方向改变激活，看模型的行为是否如预言那样改变（[[interpretability/causal-interventions]]）。
:::
:::

## 忠实性与可信性 {#sec-faithful}

每一个事后解释都是一种**化简**：它用某种人能放在心上的东西替换网络的计算。于是有两个性质彼此角力。Jacovi 与 Goldberg（2020）给它们起了名字。解释对人而言令人信服，就是**可信的**——它契合人的直觉，用熟悉的概念陈述。解释准确反映模型预测背后的推理过程，就是**忠实的**。可信性是解释与其受众之间的性质；忠实性是解释与模型之间的性质。一个可信的解释可以毫不忠实（一个自信满满、与计算毫无关系的故事），一个忠实的解释也可以不可信（对一团乱麻的启发式办法的如实描述）。危险在于：基于人类判断的评估度量的是可信性，而可信性是容易优化的：一个能产出人们喜欢的解释的方法，并不因此就是产出**真实**解释的方法。[[reasoning/faithfulness-limits]] 对模型自己的思维链研究了同一条区分。

要让忠实性可度量，就把解释本身看作一个模型。

::: definition 解释、保真度 {#def-fidelity}
模型 $f$ 在输入集合 $S$ 上的一个**解释**是一个更简单的模型 $g$——一个线性函数、一条决策规则、一个小型因果图——外加一条"$g$ 在 $S$ 上逼近 $f$"的论断。给定 $S$ 上的分布 $\mathcal{D}$ 与损失 $\ell$，$g$ 的**不保真度**为 $\E_{x\sim\mathcal{D}}[\ell(f(x), g(x))]$；对以 $\ell$ 为 $0$–$1$ 损失的分类问题，**保真度**为 $\Prob_{x\sim\mathcal{D}}[f(x) = g(x)]$。在 $x_0$ 处的**局部**解释使用集中在 $x_0$ 附近的分布。
:::

LIME（Ribeiro、Singh 与 Guestrin，2016）正是这样工作的：它对输入采样扰动、记录模型的输出，并拟合一个对近处样本加权更大的稀疏线性模型；拟合出的系数就是解释，加权拟合的质量就是它的局部保真度。保真度必要而不充分。它度量的是**输出**的一致，而两种迥异的计算完全可以在输出上一致——[[#sec-mechanism]] 把这一点讲精确。

局部线性解释只在近处忠实，下一条结果把"近处"量化。

::: proposition 一阶解释的保真度 {#prop-local}
设 $f\colon\R^n\to\R$ 在 $x_0$ 处半径为 $r$ 的球 $B$ 上二阶连续可微，且对一切 $x\in B$ 有 $\lVert\nabla^2 f(x)\rVert\le M$（算子范数）。设 $g(x) = f(x_0) + \nabla f(x_0)\T(x - x_0)$ 为 $x_0$ 处的梯度解释。则对每个 $x\in B$，

$$
\lvert f(x) - g(x)\rvert \le \tfrac12 M\,\lVert x - x_0\rVert^2 \le \tfrac12 M r^2.
$$ {#eq-local}
:::

::: proof
固定 $x\in B$，令 $u = x - x_0$，并对 $t\in[0,1]$ 设 $\varphi(t) = f(x_0 + tu)$；因为球是凸的，线段落在 $B$ 内。于是 $\varphi'(t) = \nabla f(x_0+tu)\T u$，$\varphi''(t) = u\T\nabla^2 f(x_0+tu)\,u$。由带拉格朗日型余项的泰勒公式，存在 $\tau\in(0,1)$ 使 $\varphi(1) = \varphi(0) + \varphi'(0) + \tfrac12\varphi''(\tau)$，即 $f(x) = g(x) + \tfrac12u\T\nabla^2f(x_0+\tau u)\,u$。又 $\lvert u\T Hu\rvert\le\lVert H\rVert\,\lVert u\rVert^2$，故余项的绝对值至多 $\tfrac12M\lVert u\rVert^2\le\tfrac12Mr^2$。
:::

这个界解释了一个常见的失灵。用 ReLU 或饱和激活的神经网络，在有意义的输入改变尺度上——换一个词、删一句话——远不是线性的，于是梯度描述的邻域比人们关心的改变小得多。[[interpretability/probing-attribution]] 重提这一点，并给出考察整条路径或全部子集（而不仅是考察一点）的方法（积分梯度、Shapley 值）。

::: example 切线解释 {#ex-tangent}
设 $f(x) = \sin x$，用它的一条切线在 $x_0 = 1$ 处作解释。给出误差界，并计算 $x = 1.5$ 处的误差。
::: solution
$f''(x) = -\sin x$，所以处处可取 $M = 1$，由 [[#eq-local]] 得 $\lvert f(1.5) - g(1.5)\rvert\le\tfrac12\cdot0.5^2 = 0.125$。直接计算：$g(1.5) = \sin1 + 0.5\cos1 = 0.8415 + 0.2702 = 1.1116$，而 $\sin1.5 = 0.9975$，误差为 $0.1141$，接近上界，因为 $\lvert\sin\rvert$ 在 $[1, 1.5]$ 上接近 $1$。在 $x = 3$ 处，切线给出 $1.9221$，而 $\sin3 = 0.1411$：这个"解释"的误差比函数整个值域的宽度还大。
:::
:::

::: widget plot
f: sin(x)
x: -1, 4.5
y: -1.5, 2.5
tangent: 1
caption: 一阶解释只在局部忠实。拖动切点：切线就是 $\sin x$ 在该点的梯度解释，其误差随距离按平方增长，正如 [[#prop-local]] 所预言。在极大值附近，梯度几乎为零，尽管输入显然很重要——这正是梯度归因的饱和问题。
:::

### 没有真值时度量忠实性 {#sec-erasure}

对词元级的归因，忠实性有一个实用的检验：**擦除**。若解释声称词元 $R$ 重要，那么删去它们就应改变预测，而只留下它们就应保持预测。DeYoung 等人（2020）对理由片段 $R\subseteq x$ 与预测类别 $y$ 定义了两种分数：

$$
\text{全面性} = p(y\mid x) - p(y\mid x\setminus R),\qquad \text{充分性} = p(y\mid x) - p(y\mid R).
$$ {#eq-erasure}

忠实的理由片段应有高全面性（删掉它会坏事）与低充分性（它自己就够了）。擦除有一个已知缺陷：删了词的句子属于分布外输入，因此分数的变化可能反映模型对奇怪输入的反应，而非被删信息本身的作用（Hooker 等人（2019）针对图像指出了这一点，并建议在擦除后的输入上重新训练）。擦除检验适合作为解释方法之间的相对比较，而不是绝对度量。

::: example 全面性与充分性 {#ex-erasure}
某个情感分类器给一条评论 $p(\text{正面}) = 0.92$。一个归因方法高亮了三个词元 "absolutely loved it"。删去这三个词元后 $p(\text{正面}) = 0.41$；只保留它们时 $p(\text{正面}) = 0.88$。第二个方法高亮了另外三个词元；删去它们得到 $0.85$，只保留它们得到 $0.30$。比较这两个方法。
::: solution
方法 1：全面性 $0.92 - 0.41 = 0.51$，充分性 $0.92 - 0.88 = 0.04$。方法 2：全面性 $0.92 - 0.85 = 0.07$，充分性 $0.92 - 0.30 = 0.62$。方法 1 的理由片段既显得必要又显得充分；方法 2 的两者都不是。按擦除检验，对这个预测方法 1 更忠实——前提是记住两种检验喂给模型的都是不自然的输入。
:::
:::

## 解释的评估 {#sec-evaluate}

Doshi-Velez 与 Kim（2017）在《迈向可解释机器学习的严格科学》（*Towards a Rigorous Science of Interpretable Machine Learning*）中提出三个层次的评估，成本与真实性依次递减：

- **基于应用的**评估在真实任务上用真实用户检验解释——用了解释的放射科医生诊断得更好吗？它最有说服力，也最昂贵。
- **基于人的**评估让普通人在简化任务上参与——受试者看过解释后，能否预测模型在新输入上会输出什么（**正向模拟**），或输入怎样改变才会改变输出（**反事实模拟**）？
- **基于功能的**评估不用人：它度量某个形式化的代理量，例如解释的稀疏性、其保真度（[[#def-fidelity]]）或擦除分数（[[#eq-erasure]]），其合理性由此前证明该代理量确实有用的人类研究所支持。

基于人的**正向模拟**测试度量的东西，很接近我们对解释的期望——解释要让人能预测模型——而它给出的结果令人清醒。Hase 与 Bansal（2020）发现，他们所测的归因方法中几乎没有哪种能显著提升受试者模拟模型的能力；Adebayo 等人（2018）在《显著性图的可靠性检验》（*Sanity Checks for Saliency Maps*）中表明，一些流行的显著性方法对训练好的网络与权重随机化的网络给出的图几乎相同——图看着可信，却几乎不含关于模型的信息。基于功能的代理量便宜，但每一个都可能被专门为其设计的方法钻空子。

::: example 保真度估计的不确定性 {#ex-fidelity}
某分类器的一条决策规则解释，在从部署分布抽取的 $1000$ 个输入上检验，与分类器在 $920$ 个输入上判断一致。估计保真度并给出标准误，并说明这个数字确立了什么、没有确立什么。
::: solution
$\hat F = 0.92$，标准误为 $\sqrt{0.92\cdot0.08/1000} = 0.0086$，于是近似的 $95\%$ 区间为 $0.92\pm0.017$，约 $[0.903, 0.937]$。这只确立：该规则在这一分布上约十分之九的输入上能预测分类器的输出。它并不确立分类器的计算与这条规则有任何相似：一个使用另一特征的分类器，若该特征只在本分布上与规则的特征相关，就会表现出同样的保真度，并在分布改变时分道扬镳——这正是 [[#sec-why]] 中的可迁移性关切。
:::
:::

## 作为因果抽象的机制解释 {#sec-mechanism}

机制可解释性提出的论断比保真度更强。它不仅说简单模型 $g$ 能预测 $f$ 的输出，还说 $f$ **计算了与 $g$ 相同的中间变量**，而且这些变量存放在 $f$ 的激活中可指认的位置。Marr 的三层分析（1982）提供了有用的词汇：**计算层**说解决了什么问题，**算法层**说用哪些表征与步骤解决，**实现层**说这些如何物理地实现——在这里，就是在权重与激活中。行为式分析工作在计算层；机制可解释性试图把算法层与实现层连接起来。

这一论断可以用干预来检验。Geiger、Lu、Icard 与 Potts（2021）把它形式化为**因果抽象**：一个高层因果模型 $\mathcal{H}$（一个带有命名变量的小程序）是网络的一个抽象，如果每个高层变量都能与一组激活**对齐**，使得干预这些激活对输出的影响，与在 $\mathcal{H}$ 中干预那个变量的影响相同。

::: definition 互换干预准确率 {#def-iia}
设 $\mathcal{H}$ 是一个含中间变量 $A$ 的高层模型，网络 $f$ 的激活为 $a(x)$。一个**对齐**把 $A$ 对应到两样东西：一个从激活中读出数值的函数 $\pi$，和一个向激活中写入数值的操作。以 $b$ 为基底输入、$s$ 为源输入的**互换干预**在 $b$ 上运行 $f$，但把 $a(b)$ 中与 $A$ 对齐的部分替换为它在 $s$ 上的值；记输出为 $f_{A\leftarrow s}(b)$。相应的高层干预在 $b$ 上运行 $\mathcal{H}$，只是把 $A$ 设为它在 $s$ 上的值，得到 $\mathcal{H}_{A\leftarrow s}(b)$。该对齐在对子集合 $P$ 上的**互换干预准确率**（IIA）为
$$
\operatorname{IIA} = \frac{1}{\lvert P\rvert}\sum_{(b,s)\in P}\mathbf{1}\bigl[f_{A\leftarrow s}(b) = \mathcal{H}_{A\leftarrow s}(b)\bigr].
$$
:::

因果抽象及其同族——激活修补、因果清洗——在 [[interpretability/causal-interventions]] 中展开。关键的逻辑事实已经可见。

::: proposition 干预一致蕴含行为一致，反之不然 {#prop-iia}
若某个对齐在一个对子集合上有 $\operatorname{IIA} = 1$，且该集合对 $S$ 中每个输入 $x$ 都包含 $(x, x)$，则对一切 $x\in S$ 有 $f(x) = \mathcal{H}(x)$。反之不成立：存在对每个输入都满足 $f = \mathcal{H}$ 的网络，其某个自然对齐却有 $\operatorname{IIA} < 1$。
:::

::: proof
对 $(x, x)$，互换干预只是把对齐的激活替换为它们自己的值，所以 $f_{A\leftarrow x}(x) = f(x)$；同样，把 $A$ 设为它自己的值不改变 $\mathcal{H}$，所以 $\mathcal{H}_{A\leftarrow x}(x) = \mathcal{H}(x)$。$\operatorname{IIA} = 1$ 要求对每个这样的对子二者一致。至于反方向，[[#sec-code]] 的网络在全部八个输入上都正确计算 $(x_1\wedge x_2)\vee x_3$，所以它与 $\mathcal{H}$ 行为一致；但把 $A = x_1\wedge x_2$ 与单个隐藏神经元对齐，却有 $\operatorname{IIA} = 55/64 < 1$。
:::

这条命题是本课程反复强调的警告的形式化版本：一个能预测输出的故事，并不因此就是关于机制的故事。它还提示了机制解释必须包含什么——不仅是"模型计算 $A$"，还有**在何处**，且要以能被覆写的形式指明。

::: example 手算一次失败的互换干预 {#ex-interchange}
在 [[#sec-code]] 的网络中，隐藏层为 $\mathbf{h} = \bigl(c\,a - s\,b,\ s\,a + c\,b\bigr)$，其中 $a = \operatorname{ReLU}(x_1 + x_2 - 1)$，$b = x_3$，$c = \cos30^\circ$，$s = \sin30^\circ$；读出层恢复 $a' = c h_1 + s h_2$、$b' = -s h_1 + c h_2$，并在 $a' + b' > 0.5$ 时输出 $1$。取基底 $(0,0,0)$、源 $(1,1,0)$，并把 $A$ 与神经元 $h_1$ 对齐。互换干预给出什么？$\mathcal{H}$ 又预言什么？
::: solution
在基底上 $\mathbf{h} = (0, 0)$；在源上 $a = 1$、$b = 0$，所以 $\mathbf{h} = (c, s) = (0.866, 0.5)$。修补神经元 $h_1$ 得到 $\mathbf{h} = (0.866, 0)$，于是 $a' = c\cdot0.866 = 0.75$，$b' = -s\cdot0.866 = -0.433$；$a' + b' = 0.317 < 0.5$，网络输出 $0$。高层模型把 $A$ 设为它的源值 $1$，输出 $1\vee0 = 1$。干预与预言不一致：神经元 $h_1$ 携带的是 $A$ 的一部分混着 $x_3$ 的一部分，复制它移植错了东西。若改为沿方向 $(c, s)$ 修补——读出层正是用这个方向读 $a'$——移植的恰好是 $A$，在全部 $64$ 对上都一致。
:::
:::

这个例子预告了两个大主题。变量未必与神经元对齐——它们可以是激活空间中的**方向**，这正是 [[interpretability/superposition]] 与 [[interpretability/sparse-features]] 把特征当作方向而非单元来寻找的原因。而且对齐是可以搜索的：**分布式对齐搜索**（Geiger 等人，2024）学习激活空间的一个旋转，使高层变量在其中成为一个坐标。

::: warning 可信的故事不是机制
找一个神经元或注意力头，其激活与某个有意义的东西相关、读一读它激活最强的样例、然后讲一个故事，这很容易。这样的故事常常是错的或不完整的。Bolukbasi 等人（2021）描述了 BERT 中的一种**可解释性幻觉**：同一个方向在一套数据集上看像编码了一个干净的概念，换一套数据集又像编码了另一个干净的概念，因为激活最强的样例反映的既是方向、也是数据集本身。与某个概念相关、一张醒目的可视化、一份令人信服的 top-$k$ 列表，这些只是假设；证据来自使行为如预言那样改变的干预、对新输入上激活的预测、以及对反例的搜寻。
:::

## 务实的目标与宏伟的目标 {#sec-goals}

截至 2026 年，研究者们对可解释性应当以什么为目标仍有分歧，而分歧塑造了他们使用的方法。

**宏伟的**或**列举式的**目标——与 Anthropic 及其他地方许多回路工作相联系——追求的近乎是完整的逆向工程：识别模型表征了哪些特征、哪些回路用这些特征做计算，其清晰程度要能自底向上地解释模型在某任务上的行为。它的支持者列举小模型与具体行为上的成功——归纳头、模加法、间接宾语识别——以及稀疏字典向生产模型的扩展，并主张只有这种理解才能对未试过的输入上的行为给出保证。

更**务实**的看法认为：对大模型的完整理解也许无法企及，可解释性应当以它能否在具体下游任务上——检测欺骗、审查模型是否隐藏目标、调试故障、引导行为——胜过不用可解释性方法的基线来评判。一些曾从事宏伟纲领的研究者已公开主张这一转向（例如，Google DeepMind 的机制可解释性团队在 2025 年写道，由于发现稀疏自编码器在他们关心的一项下游任务上表现不及简单基线，他们将下调稀疏自编码器基础研究的优先级；[[interpretability/sparse-features]]）。另一些人则认为，自顶向下的方法——**表征工程**（Zou 等人，2023），研究诚实之类的群体层面方向而不把它们分解为回路——提供了更可行的分析单元。

第三条批评路线质疑：内部解释在细致的行为评估之外是否还增添了安全价值；当解释不完整时，它们是否反而带来虚假的安心。辩护者回答：行为评估与可解释性以不同方式失败，所以二者互补。[[interpretability/open-problems]] 带着截至 2026 年可得的证据回到这些立场。中间各章则介绍各方都会用到的方法。

## 一个数值实验室 {#sec-code}

下面的清单手工搭出 [[#ex-interchange]] 的网络——它计算 $(x_1\wedge x_2)\vee x_3$，却把 AND 存放在旋转后的基下——并比较三类证据：与高层模型的行为一致、三个对齐的互换干预准确率、以及梯度归因。

```python
import itertools, math

def relu(z): return max(0.0, z)
def sig(z): return 1 / (1 + math.exp(-z))

# 一个计算 (x1 AND x2) OR x3 的极小网络，其中 AND 存放在旋转后的
# 基下：它的两个隐藏神经元都把两个中间变量混在一起。
c, s = math.cos(math.pi / 6), math.sin(math.pi / 6)
def hidden(x):
    a = relu(x[0] + x[1] - 1)                  # AND 变量
    b = x[2]                                   # x3 变量
    return [c * a - s * b, s * a + c * b]      # 旋转到两个神经元
def readout(h):
    a = c * h[0] + s * h[1]                    # 撤销旋转
    b = -s * h[0] + c * h[1]
    return sig(6 * (a + b) - 3)
def model(x): return readout(hidden(x))

inputs = list(itertools.product([0, 1], repeat=3))
def high(x, A=None):                           # 高层因果模型 H
    A = (x[0] and x[1]) if A is None else A
    return int(A or x[2])

agree = sum((model(x) > 0.5) == high(x) for x in inputs)
print("behavioural agreement:", agree, "/", len(inputs))

def iia(get, put, hyp_A):
    """全部 64 个（基底, 源）对上的互换干预准确率"""
    ok = 0
    pairs = list(itertools.product(inputs, repeat=2))
    for b, src in pairs:
        h = put(hidden(b), get(hidden(src)))   # 覆写与 A 对齐的部分
        ok += int(readout(h) > 0.5) == high(b, A=hyp_A(src))
    return ok / len(pairs)

def get_dir(h): return c * h[0] + s * h[1]     # 沿 AND 方向读取
def put_dir(h, v):
    d = v - get_dir(h)
    return [h[0] + d * c, h[1] + d * s]
def get_n0(h): return h[0]
def put_n0(h, v): return [v, h[1]]
AND = lambda x: x[0] and x[1]
X1 = lambda x: x[0]
print("IIA, A = AND at the AND direction:", round(iia(get_dir, put_dir, AND), 3))
print("IIA, A = AND at neuron 0         :", round(iia(get_n0, put_n0, AND), 3))
print("IIA, A = x1  at the AND direction:", round(iia(get_dir, put_dir, X1), 3))

def grad(x, eps=1e-6):                         # 有限差分梯度
    g = []
    for i in range(3):
        xp = list(x); xp[i] += eps
        g.append((model(xp) - model(x)) / eps)
    return g
for x in [(1, 1, 0), (1, 1, 1)]:
    print("input", x, "output %.4f" % model(x), "gradient", [round(v, 4) for v in grad(x)])
```

```text
behavioural agreement: 8 / 8
IIA, A = AND at the AND direction: 1.0
IIA, A = AND at neuron 0         : 0.859
IIA, A = x1  at the AND direction: 0.875
input (1, 1, 0) output 0.9526 gradient [0.2711, 0.2711, 0.2711]
input (1, 1, 1) output 0.9999 gradient [0.0007, 0.0007, 0.0007]
```

行为上，这个网络与 $\mathcal{H}$ 无法区分。干预检验却能分开行为分不开的三个假设：AND 变量**存在于一个方向上**（IIA $1$），而不是在神经元 $0$ 里（IIA $55/64 = 0.859$）；这个方向存的是 $x_1\wedge x_2$，不是 $x_1$（IIA $56/64 = 0.875$——错误的假设也可能得高分，因为它在大多数对子上与正确的假设一致，这正是 IIA 要在假设之间比较、而不能当作绝对分数来读的原因）。梯度展示了饱和：在 $(1,1,1)$ 上，通往输出的两条通路都在起作用，每个输入的梯度都是 $0.0007$，尽管 $x_3$ 单独、或 $x_1, x_2$ 联合，都各自足以决定输出。梯度说的是输入发生**微小**改变时输出如何变化，而不是"哪些输入重要"这个问题。

::: history
可解释的模型与统计学同龄：线性回归的系数与决策规则本就是为被人阅读而设计的。随后是专家系统的解释（1970 年代的 MYCIN）与用规则抽取解释神经网络（Andrews、Diederich 与 Tickle，1995）。对深度网络，卷积特征的可视化（Erhan 等人，2009；Zeiler 与 Fergus，2014）与显著性图（Simonyan、Vedaldi 与 Zisserman，2014）开创了现代这一领域；LIME（Ribeiro 等人，2016）、积分梯度（Sundararajan 等人，2017）与 SHAP（Lundberg 与 Lee，2017）成为标准的归因工具。Doshi-Velez 与 Kim（2017）以及 Lipton（2016；期刊版 2018）分析了可解释性是为了什么、又该如何评估；Kim 等人（2018）提出了 TCAV，Adebayo 等人（2018）给出了显著性的可靠性检验，Jacovi 与 Goldberg（2020）提出了忠实性与可信性的区分。Olah 与合作者在 *Distill* 上发表的特征可视化（2017）与回路（2020）文章为视觉模型奠定了机制可解释性，Transformer Circuits 专栏（始于 2021 年）把它带进语言模型。Geiger 与合作者（2021 年起）发展因果抽象，作为对机制解释的形式化刻画。Molnar 的《可解释机器学习》（*Interpretable Machine Learning*，第一版 2019，第二版 2022）为实践者汇集了归因方法。
:::

::: summary
- 为了**信任、因果性、可迁移性、信息量、公平**（Lipton, 2018）而需要可解释性；对语言模型还要加上**安全**。大模型不透明，所以它们的解释是事后的。
- 方法是**行为式**（输入–输出测试）、**归因式**（把功劳分给输入或单元）、**概念式**（探针、概念向量）或**机制式**（特征、回路，由干预验证）；解释分局部或全局、固有或事后。
- **可信**（令人信服）与**忠实**（符合计算过程）是不同的性质（Jacovi 与 Goldberg, 2020）。保真度度量替代模型与模型的一致程度；一阶解释的误差按 $\tfrac12M\lVert x - x_0\rVert^2$ 增长。
- 评估分**基于应用的**、**基于人的**、**基于功能的**三类（Doshi-Velez 与 Kim, 2017）；擦除分数（全面性、充分性）有用，但用的是分布外输入。
- 机制解释是一种**因果抽象**：它的变量必须被定位到使**互换干预**的行为符合高层模型预言的地方。干预一致蕴含行为一致，反之不然；变量可能是方向而不是神经元。
- 这个领域对目标存在分歧——完整的逆向工程还是对下游任务的务实用处——对内部解释增添多少安全价值也没有共识。
:::

::: exercise 数单元 {level=1 check="98304"}
某模型有 $24$ 层，每层有 $16$ 个注意力头和一个宽度为 $4096$ 的前馈层，残差维数为 $1024$。它一共有多少个注意力头、多少个前馈神经元？把神经元的个数作为答案。
::: solution
头：$24\times16 = 384$ 个。神经元：$24\times4096 = 98{,}304$ 个。
:::

::: exercise 切线解释的误差 {level=1 check="0.031"}
用切线在 $x_0 = 1$ 处解释 $f(x) = x^3$。该解释在 $x = 1.1$ 处的精确误差是多少？用 $M = \max_{[1,1.1]}\lvert f''\rvert$ 与 [[#prop-local]] 的界作比较。
::: solution
切线为 $g(x) = 1 + 3(x - 1)$，于是 $g(1.1) = 1.3$，而 $f(1.1) = 1.331$：误差为 $0.031$。由 $f''(x) = 6x$，在 $[1, 1.1]$ 上 $M = 6.6$，界为 $\tfrac12\cdot6.6\cdot0.01 = 0.033$，恰在真实误差之上。
:::
:::

::: exercise 擦除分数 {level=1}
某主题分类器给出 $p(\text{体育}) = 0.80$。删去某归因方法得分最高的五个词元后为 $0.20$；只保留它们时为 $0.75$。计算全面性与充分性，并说明它们是否支持该解释。
::: solution
全面性 $0.80 - 0.20 = 0.60$；充分性 $0.80 - 0.75 = 0.05$。删去这些词元毁掉了大部分预测，只保留它们又几乎保住了预测，两个分数都支持该解释——但要记住两种情形都是不自然的输入，所以这些分数最适合用来比较方法。
:::
:::

::: exercise 方法分类 {level=2}
把下列各项归为行为式、归因式、概念式或机制式，并指出是局部还是全局：(a) 测量跨关系从句的主谓一致准确率；(b) 一次翻译的显著性图；(c) 在每一层上训练句法深度的探针；(d) 证明消融两个注意力头会使模型无法补全重复序列，并解释它们的权重如何实现复制；(e) 对一笔贷款决策使用 LIME。
::: solution
(a) 行为式，全局（一个分布上的行为性质）。(b) 归因式，局部。(c) 概念式，全局（在整个数据集上的可解码性）。(d) 机制式，全局——一个干预加上对权重的说明（[[interpretability/circuits]]）。(e) 归因式（局部替代模型），局部。
:::
:::

::: exercise 哪一条期望？ {level=2}
对每个场景，说出最贴切的 Lipton 期望，并从 Doshi-Velez 与 Kim 的层次中建议一种合适的评估：(a) 银行必须告知申请人贷款被拒的原因；(b) 开发者想知道毒性分类器在新方言上是否仍然管用；(c) 某实验室想知道其模型的拒绝依赖的是内部的伤害表征还是表面关键词。
::: solution
(a) 公平、合乎伦理的决策（可申诉性），配基于应用的评估——申请人与审核员能否用解释来申诉错误？(b) 可迁移性；在新方言上基于功能的测试，外加检查解释是否找出了对方言敏感的特征。(c) 可迁移性与安全；一项由干预验证的机制式或概念式研究——例如改变关键词而保持意义不变，反之亦然，并对内部表征做修补（[[interpretability/causal-interventions]]）。
:::

::: exercise 第二个神经元 {level=2 check="37/64"}
在实验室网络中，把 $A = x_1\wedge x_2$ 与神经元 $h_2$（下标 $1$）而不是 $h_1$ 对齐。修改清单，报告在 $64$ 个对子上的 IIA（用分数表示）。为什么它比 $h_1$ 的低？
::: solution
加入 `def get_n1(h): return h[1]` 和 `def put_n1(h, v): return [h[0], v]`，并调用 `iia(get_n1, put_n1, AND)`；输出 $0.578 = 37/64$。神经元 $h_2 = s\,a + c\,b$ 对 $b = x_3$ 的权重是 $c = 0.866$，对 $a$ 只有 $s = 0.5$，所以复制它移植的主要是 $x_3$；神经元 $h_1 = c\,a - s\,b$ 由 $a$ 主导，它的修补吻合得更多。
:::
:::

::: exercise 干预与行为 {level=3}
证明：若变量 $A$ 的某个对齐在 $S\times S$ 的全部对子上有 $\operatorname{IIA} = 1$，则对 $A$ 在 $\mathcal{H}$ 下取值相同的任意两个输入 $b, s$，从 $s$ 修补对齐的激活不改变网络在 $b$ 上的输出。再举一例说明：网络在对齐位置上仍可能为 $b$ 与 $s$ 存储不同的激活值。
::: solution
若 $\mathcal{H}$ 中 $A(b) = A(s)$，则把 $A$ 设为它在 $s$ 上的值不改变 $\mathcal{H}$ 在 $b$ 上的计算：$\mathcal{H}_{A\leftarrow s}(b) = \mathcal{H}(b)$。由 $\operatorname{IIA} = 1$ 得 $f_{A\leftarrow s}(b) = \mathcal{H}_{A\leftarrow s}(b)$，又（用对子 $(b, b)$）$f(b) = \mathcal{H}(b)$，所以 $f_{A\leftarrow s}(b) = f(b)$。至于例子：设对齐的量是标量 $v$，读出阈值 $v > 0.5$；满足 $A = 1$ 的输入可能给出 $v = 0.9$，也可能给出 $v = 1.3$，两者都超过阈值。该对齐在输出层面是正确的，尽管激活还携带高层模型没有提到的额外信息（这里是大小）。抽象是关于什么对下游计算重要的论断，并不是说激活等于变量。
:::
:::

::: exercise 为什么不是单个神经元？ {level=3}
在实验室网络中，证明 $A$ 与单个神经元的**任何**对齐都无法达到 $\operatorname{IIA} = 1$，而与方向 $(c, s)$ 的对齐可以。更一般地，设某层把两个二元变量 $a, b$ 存储为 $\mathbf{h} = a\,\mathbf{u} + b\,\mathbf{v}$，其中 $\mathbf{u}, \mathbf{v}$ 线性无关，且读出能精确恢复 $a$ 与 $b$。对单个神经元的修补何时构成对 $a$ 的干净干预？
::: solution
[[#ex-interchange]] 给出修补 $h_1$ 失败的一对输入，上一题给出 $h_2$ 的 $\operatorname{IIA} = 37/64$，所以两个神经元都达不到 $1$。沿 $(c, s)$ 修补把 $c h_1 + s h_2 = a'$ 变为它的源值，且因为 $(c, s)$ 与 $(-s, c)$ 正交，$b'$ 保持不变；于是读出算得的恰是 $A_{\text{src}}\vee x_3$，每个对子都一致。一般地，把坐标 $i$ 从源修补到基底使 $h_i$ 改变 $(a_s - a_b)u_i + (b_s - b_b)v_i$。要让它成为对 $a$ 的纯粹改变——$b$ 不动、$a$ 的改变被完整移植——被修补的坐标必须只携带 $a$，且不含任何读出要用的别的东西：$v_i = 0$，并且 $a$ 的读出只能经由坐标 $i$ 依赖 $\mathbf{h}$（否则仍来自基底的其余坐标会保留 $a_b$ 的一部分）。两者同时成立，仅当变量与某个神经元对齐——即存在一个"特殊基"。当表征被旋转过（如本网络，又如叠加使然，见 [[interpretability/superposition]]），神经元层面的干预就是混合物，变量必须作为方向来寻找。
:::
:::

::: exercise 实践中的可信与忠实 {level=2}
某个语言模型的解释方法对每个回答输出一组高亮的输入词。一项用户研究发现，$80\%$ 的情况下受试者认为高亮"非常有用"。解释为什么这一结果不能确立忠实性，并设计一个基于功能的检验和一个基于人的检验来回应它。
::: solution
评分度量的是可信性：受试者判断的是高亮看起来是否合理，而一个方法只要高亮人们预期的词（例如情感词）、不管模型实际怎么计算，就能做到这一点。基于功能的检验：计算该方法与同等规模随机高亮基线的全面性与充分性（[[#eq-erasure]]），检验该方法的组是否可靠地更必要也更充分；再加上 Adebayo 等人（2018）的模型随机化可靠性检验——随机化模型权重后高亮应当改变。基于人的检验：正向模拟——给受试者看部分输入的解释，然后请他们预测模型在新输入上的输出，比较有解释与无解释的组（Hase 与 Bansal, 2020）；一个忠实且有用的方法应当提高预测准确率，包括在模型出错的输入上。
:::
