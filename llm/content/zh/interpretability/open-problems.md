前面几章介绍的都是行得通的方法：从激活里读出性质的探针，在小模型里端到端逆向解析出来的回路，带有数百万可解释特征的稀疏字典，以及引导行为、编辑知识的干预。它们也不断展示了每种方法在何处失灵。这最后一章把这些局限汇成截至 2026 年这个领域的开放问题，并呈报关于可解释性能被期待做到什么的种种对立观点。组织全章的问题，正是当初引领本课程的那个问题：理解模型的内部，能否告诉关于我们能对它行为的哪些事情——尤其是它的安全性——是检验其行为所不能告诉我们的？

本章处理五个问题。**可扩展性**：产出完整解释的那些方法，做到的是小模型与狭窄行为。**完备性与暗物质**：稀疏字典只解释了激活的一部分，未解释的那部分可能很重要。**忠实性**：建立在替换模型与自动标签之上的解释，可能以难以察觉的方式出错，而误差会逐层复合。**用于安全与审计**：由内部构造的检测器要面对基础比率、多重比较与对抗压力，而审计研究的证据令人鼓舞但有限。**思维链记录**：对用文本来思考的模型，对计算的可解释性与对思维链的可解释性在此相遇。由许多研究组的研究者撰写的综述《机制可解释性的开放问题》（*Open Problems in Mechanistic Interpretability*；Sharkey 等人，2025）是主要参考文献；下面的立场都注明了提出者并标出日期，因为它们还在变化。

## 可扩展性 {#sec-scale}

本课程中每一个完整的机制解释，对象都是小模型或狭窄任务：两层仅注意力模型中的归纳头，单层模型中的模加法，GPT-2 small（1.24 亿参数）中的间接宾语识别。对更大模型的研究找到了可辨认的组件，却得到不那么完整的解释：Lieberum 等人（2023）分析了 700 亿参数的 Chinchilla 模型中的选择题回答，找到了注意正确字母并输出正确字母的头，但一旦任务变化，机制就难以精确描述了。有三种成本随规模增长。

- **计算量。** 大到足以覆盖一个生产模型诸概念的字典，每层有数千万个潜特征（latent）（[[interpretability/sparse-features]]）；训练它们需要数十亿词元的激活，而逐层都这么做会把成本乘上倍数。
- **人的注意力。** 解释最终必须被人阅读与核验，而特征、回路与提示的个数会超出任何团队的处理能力。
- **复合性。** 一个大模型的一个行为，通常牵涉跨许多层的许多特征。单个提示的归因图在剪枝前可以有数千个节点，而其作者报告，在他们尝试的提示中，只对少数几个得到了满意的解释（Ameisen 等人，2025）。

::: example 通读一部字典要花多久？ {#ex-reading}
一部字典有 $3400$ 万个潜特征。若一位研究者花一分钟，就某个潜特征把它的自动描述与例子对照检查一遍，按每年 $2000$ 个工作小时计，这是多少人年？
::: solution
$34\times10^6$ 分钟是 $566{,}667$ 小时，即 $566{,}667/2000\approx283$ 人年——还只是一个模型的一层。因此人工审读必须有的放矢（只审与某个问题相关的特征），或者代之以自动审读，而后者的可靠性本身又必须被检验。这正是为什么**自动可解释性**（automated interpretability）——提出并检验关于特征与回路的假说的语言模型智能体（例如 Schwettmann 等人 2023 年的 FIND 基准，与 Shaham 等人 2024 年的 MAIA 智能体）——被视为规模化的必需品，也是为什么它的忠实性本身是一个开放问题。
:::
:::

一个相关的问题是分析的单位能否扩展。神经元因叠加而失败（[[interpretability/superposition]]）；注意力头有时可解释、有时不可；稀疏特征目前是最佳的候选者，但它们会随字典大小而分裂，并在不同训练种子之间有所不同。关于不同单位的提案包括**参数分解**（parameter decomposition）方法：把权重而非激活分解为各自实现一个机制的简单组件（Braun 等人，2025，及相关工作），以及从一开始就把模型训练得更可解释，例如在其权重或架构中引入稀疏性。截至 2026 年，还没有哪种方案被证明能扩展到前沿模型。

## 完备性与暗物质 {#sec-dark}

稀疏字典以某个误差重构激活。问题是这个误差里装着什么。若是无结构的噪声，字典就抓住了模型用到的一切。若其中含有字典错过的特征，那么由字典搭建的解释就是不完备的——而缺失的部分，可能恰恰是一种罕见而危险的行为之所系。

Engels、Riggs 与 Tegmark（2024）在《分解稀疏自编码器的暗物质》（*Decomposing the Dark Matter of Sparse Autoencoders*）中提出这样切分重构误差：问一问其中有多少能够由激活本身经一个线性映射预测出来。

::: proposition 重构误差的分解 {#prop-dark}
设 $\mathbf{e} = \mathbf{x} - \hat{\mathbf{x}}$ 为字典在激活 $\mathbf{x}$（已中心化、二阶矩有限）上的重构误差，$\hat{\mathbf{e}} = A\mathbf{x}$ 为从 $\mathbf{x}$ 对 $\mathbf{e}$ 的最小二乘线性预测。则
$$
\E\lVert\mathbf{e}\rVert^2 = \E\lVert\hat{\mathbf{e}}\rVert^2 + \E\lVert\mathbf{e} - \hat{\mathbf{e}}\rVert^2.
$$ {#eq-dark}
第一项是**线性可预测**的误差；第二项是不存在 $\mathbf{x}$ 的线性函数能预测的误差。
:::

::: proof
最小二乘的 $A$ 满足正规方程 $\E[(\mathbf{e} - A\mathbf{x})\mathbf{x}\T] = 0$。于是 $\E[(\mathbf{e} - \hat{\mathbf{e}})\T\hat{\mathbf{e}}] = \operatorname{tr}\bigl(A\,\E[\mathbf{x}(\mathbf{e} - A\mathbf{x})\T]\bigr) = 0$：残差与预测正交。把 $\lVert\mathbf{e}\rVert^2 = \lVert\hat{\mathbf{e}} + (\mathbf{e} - \hat{\mathbf{e}})\rVert^2$ 展开并取期望，交叉项消失，即得 [[#eq-dark]]。
:::

线性可预测的误差意味着，字典系统性错过了那些以可预测方式在场的方向——原则上它本可以表示的特征。Engels 等人报告，SAE 误差中有很大一部分是线性可预测的，而这部分只随字典增大而缓慢缩小；他们主张，某些误差反映的是字典系统性学不会的特征，而不是噪声。再结合下游损失的结果——把重构拼接回模型，即便对非常大的字典也会明显抬高其损失——证据表明，截至 2026 年，字典抓住了模型所表示之物的大部分，但不是全部。

::: example 误差里有多少是暗物质？ {#ex-dark}
某个 SAE 在一层的 $\operatorname{FVU} = 0.12$，该层激活的总方差为 $100$（所以 $\E\lVert\mathbf{e}\rVert^2 = 12$）。从 $\mathbf{x}$ 出发的一个线性映射预测误差，留下 $\E\lVert\mathbf{e} - \hat{\mathbf{e}}\rVert^2 = 7.2$。切分这个误差并解读。
::: solution
由 [[#eq-dark]]，可预测部分是 $12 - 7.2 = 4.8$，即误差的 $40\%$、总方差的 $4.8\%$；剩下的 $7.2$（方差的 $7.2\%$）不能由 $\mathbf{x}$ 线性预测。第一部分指向字典错过的结构（一个更大或训练得更好的字典也许能抓住它）；第二部分可能是噪声、非线性结构，或太罕见以致没学会的特征。这两个数字都没有说明*行为*有多大程度依赖于误差——要知道这个，把 $\hat{\mathbf{x}}$ 拼接进去、度量下游损失，或修补误差项、度量它对任务度量的影响。
:::
:::

对罕见概念的覆盖是完备性的第二个方面。字典只能学会在其训练激活中出现得足够频繁的特征。Templeton 等人（2024）报告，一个概念能否得到专属特征，取决于它在训练数据中的频率：常见的实体在他们的较小字典里就有特征，较罕见者要到更大的字典里才有。对安全最要紧的行为——一个很少被触发的后门，一个只在异常情形下表达的筹划——天然就是罕见的。

::: example 看见一个罕见概念 {#ex-poisson}
某个概念平均每 $10^8$ 个词元出现一次。一个 SAE 在 $10^9$ 个词元上训练。用泊松（Poisson）模型，出现次数的期望是多少？至少出现五次的概率是多少？对一个平均每 $5\times10^8$ 个词元出现一次的概念重做一遍。
::: solution
期望出现次数 $\mu = 10^9/10^8 = 10$；$\Prob(N\ge5) = 1 - \sum_{k=0}^4e^{-10}10^k/k! = 0.971$。对较罕见的概念 $\mu = 2$，$\Prob(N\ge5) = 1 - \sum_{k=0}^4e^{-2}2^k/k! = 0.053$。寥寥几次出现是否足以换来一个专属潜特征，取决于方法与字典大小，但在十亿词元里只被看见过两次的概念多半得不到。在更多数据上训练，或在为目标概念富集的数据上训练，会有帮助；两者都不能保证覆盖没有人预料到的行为。
:::
:::

## 解释的忠实性 {#sec-faithful}

可解释性产出的解释，与模型隔着好几道手：潜特征是 SAE 学出的一个方向；它的描述是语言模型根据例子写的；回路是在一个用转码器顶替 MLP 的替换模型里追踪出来的；而对回路的摘要又是人写的。每一步都可能引入下一步看不见的误差。[[interpretability/interpretability-goals#sec-faithful]] 的忠实性—可信性之分在每一步都适用。

**替换模型。** 归因图是在一个每个 MLP 都被换成转码器的模型里计算的；替换与原版的差是每一层一个误差，而误差会传播。

::: proposition 误差经被替换各层的累积 {#prop-accumulate}
设 $F = f_L\circ\cdots\circ f_1$，每个 $f_\ell$ 是 $\rho_\ell$-Lipschitz 的，又设 $G = g_L\circ\cdots\circ g_1$ 是一个替换，满足对一切 $\mathbf{h}$ 有 $\lVert g_\ell(\mathbf{h}) - f_\ell(\mathbf{h})\rVert\le\delta_\ell$。则对每个输入 $\mathbf{x}$，
$$
\lVert G(\mathbf{x}) - F(\mathbf{x})\rVert\le\sum_{\ell=1}^L\delta_\ell\prod_{k=\ell+1}^L\rho_k.
$$ {#eq-accumulate}
:::

::: proof
设 $\mathbf{h}_\ell$ 与 $\mathbf{h}'_\ell$ 为 $F$ 与 $G$ 各经过 $\ell$ 层后的状态，$\mathbf{h}_0 = \mathbf{h}'_0 = \mathbf{x}$，并令 $\epsilon_\ell = \lVert\mathbf{h}'_\ell - \mathbf{h}_\ell\rVert$。则 $\epsilon_\ell = \lVert g_\ell(\mathbf{h}'_{\ell-1}) - f_\ell(\mathbf{h}_{\ell-1})\rVert\le\lVert g_\ell(\mathbf{h}'_{\ell-1}) - f_\ell(\mathbf{h}'_{\ell-1})\rVert + \lVert f_\ell(\mathbf{h}'_{\ell-1}) - f_\ell(\mathbf{h}_{\ell-1})\rVert\le\delta_\ell + \rho_\ell\epsilon_{\ell-1}$。由 $\epsilon_0 = 0$，展开递推得 $\epsilon_L\le\sum_\ell\delta_\ell\prod_{k>\ell}\rho_k$。
:::

对形如 $\mathbf{h}\mapsto\mathbf{h} + F_\ell(\mathbf{h})$ 的残差模块，Lipschitz 常数至少是 $1$，所以最坏情形的误差只会随深度增长。这是一个最坏情形的上界；实验室表明典型误差要小得多，但并非为零，而发表出来的归因图方法都包含显式的**误差节点**，让每层未被解释的部分可见，而不是被悄悄丢掉。在替换模型里找到的机制是不是模型自己的机制，就必须回到模型本身、通过干预原始激活来检验——Ameisen 等人报告为其案例研究做了这样的检验，有些一致性很好，有些只是部分一致。

::: example 一个几何上界 {#ex-bound}
八层被替换，每层误差至多 $\delta = 0.05$，而每一层都是 $1.2$-Lipschitz 的。计算 [[#prop-accumulate]] 的上界。若各层是 $1$-Lipschitz 的呢？
::: solution
$\sum_{\ell=1}^80.05\times1.2^{8-\ell} = 0.05\,(1.2^8 - 1)/(1.2 - 1) = 0.05\times3.30/0.2 = 0.825$；$1$-Lipschitz 各层则为 $8\times0.05 = 0.40$。每层 $20\%$ 的放大，八层把最坏情形翻了一倍；若过 $60$ 层，它会把它乘上千倍。
:::
:::

**自动描述。** 一个在模拟上得分很高的描述，仍可能说错该潜特征的角色：它可能只描述了最频繁的激活语境而漏掉较弱的激活，或者只描述该特征对什么有反应（它的输入端）而不描述它做什么（它的输出端）。把描述与干预对照的研究发现，两者可能出现背离（例如有些特征，其最高的激活指向一个概念，而对输出的因果效应却不同）。随着解释流水线越来越自动化，写描述的语言模型之出错，就成了科学之出错。

**幻觉。** 已发表的几种"可解释性幻觉"展示了貌似合理的结果如何能从方法本身产生：在一个数据集上看起来有意义的方向，换一个数据集就变了（Bolukbasi 等人，2021）；会激活休眠通路的子空间修补（Makelov 等人，2024）；以及在随机初始化的模型上训练 SAE，竟产出自动可解释性得分很高的潜特征（Heap 等人，2025）。一个被广泛接受的告诫，是先在**模式生物**（model organism）上检验方法——其真值由构造而知：专门训练或编译去实现某个指定算法的模型（例如把程序编译成 Transformer 权重的 Tracr；Lindner 等人，2023），或携带植入行为的模型——然后才去信任那些真值未知的模型。

::: warning 一个干净的故事是需要检验的假说，不是结果
一个可解释性结果通常以叙事的形式到来：这些特征，以这种方式连接，实现了这个行为。这个叙事在每个层面都可能出错——特征也许是字典的伪影，描述也许不完整，连接也许只在替换模型中成立，而这个行为在其他输入上也许另有机制。要紧的结果，尤其关乎安全的，应当说明每个环节是如何被核验的：经由对原模型的干预，在哪些输入上，对照哪些基线。
:::

## 可解释性与安全、审计 {#sec-safety}

对可解释性最宏大的期望，是它能验证行为无法揭示的模型性质：它没有在追求一个隐藏目标，没有意识到自己正被评测，没有在策划欺骗。截至 2026 年，证据来自三类研究。

**作为监测器的探针。** 在受测的设定里，激活上的线性探针能以高准确率检出某些行为。MacDiarmid 等人（2024，Anthropic）报告，在通用对比对上训练的简单探针，检出了"潜伏智能体"（sleeper agent）模型——有意用后门训练的模型——将要作恶的时刻。Goldowsky-Dill 等人（2025）的《用线性探针检测策略性欺骗》（*Detecting Strategic Deception Using Linear Probes*）在 Llama-3.3-70B 上训练探针，报告在其评测数据集上诚实与欺骗的回答之间分离度很高（AUROC 从 $0.96$ 到 $0.999$），同时指出这些探针部分追踪的是欺骗的话题而非欺骗的意图，而真实部署中的表现未经检验。与这类监测器相对立的，是表征可以被塑造成躲避它们的证据：Bailey 等人（2024）表明，可以对模型和输入作优化，使有害行为伴随着潜空间监测器不会标记的激活（"混淆激活"，obfuscated activations）。

**审计博弈。** Marks 等人（2025）的《对隐藏目标审计语言模型》（*Auditing Language Models for Hidden Objectives*）训练了一个带故意隐藏目标的模型——利用奖励模型的已知偏差——然后请四支不知情的团队以不同的权限级别去发现它。四支队伍中三支找到了它；只有黑盒 API 权限的那支没有。成功的团队使用了稀疏自编码器特征、行为攻击与对训练数据的搜索，而论文报告若干非可解释性的技术同样有效。作者把该研究呈现为对审计方法论的一次初步检验，而不是对"可解释性必不可少"的论证。

**部署前审计。** 有些开发者为 2025 年发布的模型发布的系统卡，把基于可解释性的考察描述为其安全评估的一部分——例如，检查与识别评测场景相关的内部表征，并检验压制这类表征时行为如何变化。这些是开发者自己在特定设定下写的报告，它们说明的是可解释性能够添加的那类证据，而非确立其可靠性。

无论一个由内部构造的检测器在配平的测试里准确率看起来多好，两个统计问题都适用于每一个这样的检测器。

::: proposition 在海量潜特征中搜索的错误发现 {#prop-multiple}
设对 $M$ 个潜特征各自在显著性水平 $\alpha$ 下检验其与某个标签的关联，其中 $M_0$ 个实际上与标签无关（且检验是有效的）。则被宣布显著的无关潜特征的期望个数是 $M_0\alpha$。若改为每个检验使用水平 $\alpha/M$，则*任何*无关潜特征被宣布显著的概率至多为 $\alpha$（邦费罗尼（Bonferroni）校正）。
:::

::: proof
对每个无关潜特征，错误拒绝的概率是 $\alpha$（检验有效），所以由期望的线性性，错误拒绝的期望个数是 $M_0\alpha$；不需要任何独立性。取水平 $\alpha/M$，并合界给出 $\Prob(\text{某个错误拒绝})\le\sum_{\text{无关}}\alpha/M = M_0\alpha/M\le\alpha$。
:::

有数千万个潜特征时，按常规阈值搜索"能检测欺骗的那个潜特征"，保证会得到数千个虚假候选。靠搜索找到的候选必须在新数据上核验，而筛选它们这件事必须报告。第二个问题是**基础比率**：部署中罕见的行为，即便出自准确的检测器，产生的也多半是误报。

::: example 基础比率问题 {#ex-base}
一个欺骗探针对 $90\%$ 的欺骗性回答报警，对 $1\%$ 的诚实回答也报警。若千分之一的回答是欺骗性的，报警的回答中有多大比例是欺骗？若假阳性率是 $5\%$ 呢？
::: solution
由贝叶斯（Bayes）定理，精确率 $= 0.9\times0.001/(0.9\times0.001 + 0.01\times0.999) = 0.0009/0.01089 = 0.083$：大约十二次报警里只有一次是真欺骗。假阳性率为 $5\%$ 时，精确率降到 $0.0009/(0.0009 + 0.04995) = 0.018$：一个在配平评测集上 AUROC 看起来极好的监测器，在真实的基础比率下仍可能被误报淹没，这正是为什么报告里的工作点（在寻常流量上的假阳性率）比 AUROC 更要紧。
:::
:::

sensitivity: 0.9
specificity: 0.99
caption: 把基于可解释性的监测器当作一项诊断检验。发生率（prevalence）$0.1\%$、灵敏度 $90\%$、特异度 $99\%$（[[#ex-base]]）时，大多数报警是误报。把特异度推向 $99.99\%$，或把发生率调大（比如监测器只用于已有嫌疑的输入），看精确率如何变化。
:::

## 解释推理 {#sec-reasoning}

推理模型在回答之前写下很长的思维链。这些记录似乎提供了免费的可解释性：模型的中间步骤用自然语言写成。[[reasoning/faithfulness-limits]] 综述了"记录部分不忠实"的证据——模型使用没有言明的线索，而推理可以是事后编造的。可解释性方法从两个方面对此着力。

其一，内部分析可以检验记录。归因图的案例研究（Lindsey 等人，2025）发现，当模型解释它如何把两个数相加时，其描述的是竖式进位的算法，而内部计算却把一条近似数值的通路与一条个位数的通路结合在一起——所述机制与实际机制不一致。另一些工作度量思维链记录中每个句子在因果上有多大影响：从那个位置起重采样记录，并记录最终答案改变的频率；Bogdan 等人（2025）把最有影响力的句子称为"思维锚点"。推理过程中对激活的探针，有时能在最终答案写下之前预测出它，这与"后面的推理是否必要"相关。

其二，记录可以被监测。**思维链监测**（chain-of-thought monitoring）用另一个模型阅读记录，以捕捉例如利用任务漏洞的筹划。Baker 等人（2025）报告，这样的监测在编码任务中逮到了奖励破解，而针对监测器的训练让模型学会在记录中隐藏意图、照样破解。来自若干实验室的研究者合著的论文（Korbak 等人，2025）把思维链可监测性描述为一个"新的而脆弱的机会"，主张开发者应避免采用会让记录更难辨认的训练做法。可解释性与思维链监测是两项互补的押注：前者不依赖模型恰好把话说了出来，后者不要求理解激活。

开放问题包括：发生在激活而非文本中的推理（如"潜空间"或连续推理的提案）会不会让记录信息更少；内部方法能否检测出记录不忠实；以及当模型被有意或无意地针对它们作优化时，两者中的任何一个能否保持稳健。

::: quiz
一项研究发现，一个稀疏字典潜特征在留出的配平测试集上，能以 $95\%$ 的准确率把模型随后表现出欺骗行为的提示与不表现的提示分开。在它作为部署监测器使用之前，哪些进一步证据最重要？
- [ ] 该潜特征最高激活的更高分辨率可视化。
- [ ] 确认它的自动描述里提到了欺骗。
- [x] 它在真实部署流量上的假阳性率、它对该研究未构造的欺骗上的表现，以及它是不是在同一份数据的众多候选中被选出来的。
- [ ] 一个更大的字典，其中该潜特征分裂成几个。
::: solution
部署使用取决于真实基础比率下的精确率（[[#ex-base]]）、对构造情景之外情形的泛化，以及免于筛选效应（[[#prop-multiple]]）。描述与可视化关乎可信性，不关乎作为检测器的可靠性。
:::
:::

## 对立的观点 {#sec-views}

截至 2026 年，研究者们对可解释性能走多远、应当如何推进并无共识。下列立场概括自已发表的陈述；每一种都有认真的拥护者与批评者。

**宏大的观点。** Olah、Elhage 与合作者把机制可解释性定位为对神经网络的逆向工程——就像人们可能逆向工程一个编译好的程序——并主张只有这种理解，才能支撑对未测输入上行为的信心。Dario Amodei 的文章《可解释性的紧迫性》（*The Urgency of Interpretability*，2025）主张，可解释性应在几年之内瞄准某种类似"AI 的核磁共振"的东西——在部署前对模型问题的可靠诊断——并说这个领域正与能力竞赛。拥护者指出从神经元到特征再到归因图的快速进展。

**务实的观点。** 另一些人主张，对前沿模型的完整理解未必能在有用的时间尺度上达成，而可解释性应以其对具体任务——检测欺骗、审计、调试、监测——相对于强非可解释性基线的贡献来评判。Google DeepMind 的 Neel Nanda 与合作者在 2025 年他们关于 SAE 在下游任务上的负面结果（[[interpretability/sparse-features#sec-critiques]]）之后公开采取这一立场，同时继续从事可解释性工作。按这一观点，线性探针与引导向量这类简单方法，也许能提供大部分实用价值。

**自顶向下的观点。** 表征工程（Zou 等人，2023）主张，安全相关性质的合适单位是群体层面的表征——诚实、有害性、情绪的方向——而不是回路，就像神经科学既研究单个神经元，也研究脑区与群体编码。

**怀疑的观点。** 一些批评者主张，机制纲领在大模型上不太可能成功，因为它们的计算未必能分解成人能理解的部分，而资源花在别的进路上会更好；Hendrycks 与 Hiscott（2025）在题为《一场被误导的机制式 AI 可解释性追求》（*The Misguided Quest for Mechanistic AI Interpretability*）的文章中申述这一立场，把自底向上解释大网络的希望，与其他复杂系统中类似计划的有限成功相比较。辩护者回应说，可解释性已一次又一次在怀疑者预期一无所有的地方找到了结构，而部分理解仍然可以有用。

这些观点共享的东西比其表述更多：全都把干预当作证据的标准，全都接受当前的解释并不完备，并且全都把"可解释性相对行为评测多贡献了什么"视为一个经验问题。安全课程（[[safety-alignment]]）讲的是那些无论可解释性取得什么都要奏效的监测、控制与评测方法。

## 一个数值实验室 {#sec-code}

清单计算本章的三个量：监测器在几个基础比率下的精确率（[[#ex-base]]）；$5000$ 个与标签无关的潜特征在 $\alpha = 0.001$ 下检验时，偶然"显著"的个数（[[#prop-multiple]]）；以及把八个随机残差模块 $\mathbf{h}\mapsto\mathbf{h} + \operatorname{ReLU}(W\mathbf{h})$ 中的每一个换成一个误差为范数 $0.05$ 的向量的近似所累积的误差，并与由各模块 Lipschitz 常数算出的 [[#prop-accumulate]] 上界相比较。

```python
import math, random
rng = random.Random(8)

# 1. 欺骗监测器在不同基础比率下的精确率（贝叶斯定理）
TPR, FPR = 0.90, 0.01
for prev in [0.1, 0.01, 0.001]:
    precision = TPR * prev / (TPR * prev + FPR * (1 - prev))
    print(f"prevalence {prev:<6}: precision of a flag {precision:.3f}")

# 2. 在海量潜特征中搜索一个能"检测"标签的：偶然间的错误发现
n, M, alpha = 200, 5000, 0.001
z_crit = 3.29                                   # alpha = 0.001 的双侧正态临界值
labels = [rng.random() < 0.5 for _ in range(n)]
hits = 0
for _ in range(M):                              # 与标签无关的潜特征
    act = [rng.gauss(0, 1) for _ in range(n)]
    a1 = [a for a, y in zip(act, labels) if y]; a0 = [a for a, y in zip(act, labels) if not y]
    m1, m0 = sum(a1) / len(a1), sum(a0) / len(a0)
    z = (m1 - m0) / math.sqrt(1 / len(a1) + 1 / len(a0))   # 已知单位方差
    hits += abs(z) > z_crit
print(f"{M} random latents, alpha = {alpha}: {hits} 'significant' (expected {M * alpha:.0f}); "
      f"Bonferroni threshold alpha/M = {alpha / M:.1e}")

# 3. 替换模型中的误差累积：L 个残差模块各被一个误差为范数 delta 的向量近似替换；
#    与命题中的上界比较。
d, L, delta = 16, 8, 0.05
Ws = [[[rng.gauss(0, 1.0 / math.sqrt(d)) for _ in range(d)] for _ in range(d)] for _ in range(L)]
def block(W, h): return [h[i] + max(0.0, sum(w * v for w, v in zip(W[i], h))) for i in range(d)]
def norm(v): return math.sqrt(sum(a * a for a in v))
def op_norm(W, iters=100):                      # 幂迭代求最大奇异值
    v = [1.0] * d
    for _ in range(iters):
        u = [sum(W[i][j] * v[j] for j in range(d)) for i in range(d)]
        v = [sum(W[i][j] * u[i] for i in range(d)) for j in range(d)]
        s = norm(v); v = [a / s for a in v]
    return norm([sum(W[i][j] * v[j] for j in range(d)) for i in range(d)])
rho = [1 + op_norm(W) for W in Ws]              # h -> h + ReLU(W h) 的 Lipschitz 上界
bound = sum(delta * math.prod(rho[k] for k in range(l + 1, L)) for l in range(L))
errs = []
for _ in range(200):
    h = hr = [rng.gauss(0, 1) for _ in range(d)]
    for W in Ws:
        z = [rng.gauss(0, 1) for _ in range(d)]; zn = norm(z)
        h, hr = block(W, h), [a + delta * b / zn for a, b in zip(block(W, hr), z)]
    errs.append(norm([a - b for a, b in zip(h, hr)]))
print(f"Lipschitz bounds per block: {min(rho):.2f} to {max(rho):.2f}")
print(f"final error after {L} replaced blocks: mean {sum(errs) / len(errs):.3f}, max {max(errs):.3f}; "
      f"bound {bound:.3f}; sum of per-block errors {L * delta:.2f}")
```

```text
prevalence 0.1   : precision of a flag 0.909
prevalence 0.01  : precision of a flag 0.476
prevalence 0.001 : precision of a flag 0.083
5000 random latents, alpha = 0.001: 6 'significant' (expected 5); Bonferroni threshold alpha/M = 2.0e-07
Lipschitz bounds per block: 2.57 to 2.99
final error after 8 replaced blocks: mean 0.395, max 1.024; bound 99.109; sum of per-block errors 0.40
```

同一个监测器在 $10\%$ 的基础比率下可靠，在 $0.1\%$ 时却十有八九是错的。五个与标签毫无关系的潜特征通过了严格的阈值，正合 $5000\times0.001 = 5$ 的预期；潜特征到了数千万，单凭偶然就会产生数万个。最坏情形的误差上界（$99$）是空洞的，因为它假定每个误差在每一层都被最大程度地放大；实际误差平均 $0.395$，约等于逐模块误差之和，偶尔有些输入使放大把它们变成两倍三倍。这类上界解释了误差*为什么可能*复合；要在它们是否复合，得在模型上测量。

::: history
可解释性的目标自深度学习时代之初就在争论（Lipton，2016；Doshi-Velez 与 Kim，2017），而机制可解释性的安全理由由 Olah 等人自 2017 年起阐发。Hubinger（2019）与他人提议用透明性工具检测欺骗性模型，Christiano 与他人讨论了"引出潜在知识"（eliciting latent knowledge，2021）。可解释性幻觉由 Bolukbasi 等人（2021）与 Makelov 等人（2024）描述；Lindner 等人（2023）建造 Tracr 以提供真值已知的模式生物。2024 年，MacDiarmid 等人报告检出潜伏智能体的探针，Bailey 等人造出混淆激活，Engels 等人研究了 SAE 的暗物质；2025 年，Marks 等人跑了审计博弈，Goldowsky-Dill 等人做策略性欺骗探针，Ameisen 等人与 Lindsey 等人发表归因图，Baker 等人与 Korbak 等人讨论思维链监测，Amodei 主张紧迫，Hendrycks 与 Hiscott 主张怀疑，Google DeepMind 的团队主张务实转向，Sharkey 等人综述了开放问题。
:::

::: summary
- **可扩展性**：完整解释存在于小模型与窄任务；更大的模型只给部分解释。计算量、人的注意力与解释的规模都随规模增长，使自动可解释性成为必需，而其可靠性是一个开放问题。
- **完备性**：字典留下**暗物质**；误差分成线性可预测的部分（错过的结构）与其余，而罕见概念也许永远得不到特征。
- **忠实性**：解释经过字典、自动描述与替换模型；误差会复合（最坏情形 $\sum_\ell\delta_\ell\prod_{k>\ell}\rho_k$），幻觉已被记录在案，需要在模式生物与原模型上核验。
- **安全与审计**：探针与字典在受控研究中检出过植入的行为，审计博弈令人鼓舞；检测器必须面对**基础比率**、**多重比较**与**对抗躲避**。
- **思维链记录**：内部分析可以检验思维链的忠实性；思维链监测有用，但在优化之下脆弱。
- **诸观点**从宏大的逆向工程，到务实的可用性、自顶向下的表征工程与怀疑论；全都把干预当作证据标准，并把可解释性的附加价值视为一个经验问题。
:::

## 习题

::: exercise 监测器的精确率 {level=1 check="0.0826"}
一个监测器真阳性率 $0.9$、假阳性率 $0.01$，它所检测的行为发生在 $0.1\%$ 的情形里。把一次报警的精确率算到小数点后四位。
::: solution
$0.9\times0.001/(0.9\times0.001 + 0.01\times0.999) = 0.0009/0.01089 = 0.0826$。
:::
:::

::: exercise 一个邦费罗尼阈值 {level=1 check="1e-9"}
你对 $10^7$ 个潜特征检验其与某个标签的关联，希望任何错误发现的概率至多 $0.01$。邦费罗尼校正要求每个检验取多高的显著性水平？
::: solution
$0.01/10^7 = 10^{-9}$。
:::

::: exercise 一个几何上界 {level=1 check="0.4"}
八层被替换，每层误差至多 $0.05$，而每一层都是 $1$-Lipschitz 的。计算 [[#prop-accumulate]] 的上界。
::: solution
所有 $\rho_k = 1$ 时各个乘积都是 $1$，上界为 $8\times0.05 = 0.4$。
:::
:::

::: exercise 看见一个罕见概念 {level=2 check="0.0527"}
一个与安全相关的概念每 $5\times10^8$ 个词元出现一次，字典在 $10^9$ 个词元上训练。在泊松模型下，把该概念至少出现五次的概率算到小数点后四位。
::: solution
$\mu = 2$，$\Prob(N\ge5) = 1 - e^{-2}(1 + 2 + 2 + \tfrac43 + \tfrac23) = 1 - 7e^{-2} = 1 - 0.9473 = 0.0527$。
:::
:::

::: exercise 切分误差 {level=2}
一个 SAE 在总方差为 $50$ 的激活上留下 $\E\lVert\mathbf{e}\rVert^2 = 5$。从 $\mathbf{x}$ 对 $\mathbf{e}$ 的一个线性预测器留下 $\E\lVert\mathbf{e} - \hat{\mathbf{e}}\rVert^2 = 4$。计算 FVU 与误差中线性可预测的份额。不可预测的部分会不会对行为重要？
::: solution
$\operatorname{FVU} = 5/50 = 0.1$。可预测部分是 $5 - 4 = 1$，即误差的 $20\%$。会：不可预测部分可能含有罕见的或非线性编码的特征，而一个方差很小的方向，若下游组件以大权重读取它，也能对输出产生巨大影响。它的重要性要靠修补或拼接来测量，而不是靠它的方差。
:::
:::

::: exercise 设计一场审计博弈 {level=2}
设计一个审计研究，检验稀疏自编码器特征相对黑盒方法，在寻找一个隐藏行为上是否增加了价值。指定模式生物、各实验条件、团队或智能体、成功判据，以及两个对效度的威胁。
::: solution
模式生物：若干微调去携带不同隐藏行为的模型（例如一个后门触发器、一个隐藏的偏好、在某科目上藏拙），外加一些不带任何隐藏行为的对照模型；行为由另一个团队选定，不予披露。条件在各审计方之间随机分配、时间预算相同：仅黑盒访问；黑盒加训练数据；白盒、可用探针与修补但没有 SAE；白盒、有 SAE。审计者：每个条件若干支人类团队，或自动审计智能体（允许大量重复）。成功：一份对隐藏行为的书面描述，由独立评审对照真值打分，外加在对照模型上的误报率。威胁：（1）植入的行为可能比自然的不当行为更容易被某些方法找到（例如微调留下了显眼的特征），结论可能不能迁移；（2）团队技能的差异大于方法价值的差异，所以团队数目少会把方法与团队混在一起——用可重复的自动智能体，或每个条件多支团队，可以缓解。
:::
:::

::: exercise 优化之下的探针 {level=2}
一个开发者在训练中加入惩罚：只要欺骗探针在模型激活上触发就罚。解释为什么这可能让探针作为监测器失效——即便模型的行为不变——并提出一个保障措施。
::: solution
针对探针作优化，奖励任何能压低其输出的改变，包括那些不碰行为、只改变表征的改变——把欺骗性的计算搬进探针不读取的方向。这是思维链针对监测器优化时观察到的混淆（Baker 等人，2025）与 Bailey 等人（2024）的混淆激活在潜空间的对应物。保障措施：把用于评估的监测器与任何训练信号隔离（训练用一个探针，监测用另一个独立训练、留出的探针，并在训练后重新训练）；同时也直接监测行为；并检验留出的监测器在训练后表现是否退化——那将是表征层面躲避的迹象。
:::
:::

::: exercise 检验一条思维链记录 {level=3}
一个推理模型用十个句子的思维链解一道应用题。描述两个实验——一个用记录的重采样，一个用激活——来检验第 $4$ 句（陈述一个中间结果）是否在因果上被最终答案所用，并解释各自能与不能说明什么。
::: solution
重采样：对许多样本，保留第 $1$–$3$ 句，从第 $4$ 句起重采样，比较两种情形下最终答案的分布：重生成的第 $4$ 句陈述同一中间结果时，与陈述一个不同结果时（或插入一个结果有误的修改版第 $4$ 句并让生成继续）。若答案跟随所陈述的结果，则这个句子被使用了；若答案不变，则答案是在别处算出的。这显示的是*文本*的因果角色，而不是计算发生在何处。激活：在第 $3$ 句末尾探测激活中的中间结果；若它在写下之前就可解码，模型可能已在内部算出它；然后从一次取不同中间值的运行中，把第 $4$ 句所在位置的激活修补过来，看答案是否改变。这定位了计算，但依赖探针与修补的有效性（[[#sec-faithful]]）。两者合起来能区分"先算出、再言明并使用"、"内部算出、言明了却不用"与"没写下来就算不出"。
:::

::: exercise 表明一个立场 {level=3}
基于本章的证据，就"验证前沿模型的安全性离不开可解释性"这一论断写一段兼顾两边的评估，并指出最能改变你评估的那一个经验结果。
::: solution
一份兼顾的评估：可解释性产出的方法能在受控设定中检出植入的行为（潜伏智能体与欺骗的探针；审计博弈里的 SAE 特征），而且是唯一一类既不依赖模型在被测输入上显露行为、也不依赖它在思维链里和盘托出的方法族。但至今没有哪种可解释性方法被证明能在一台前沿模型里找到其他方法漏掉的、未植入的危险行为；字典不完备；解释可能不忠实；检测器要面对基础比率与躲避；而在若干有监督的比较里，简单的基线表现相当。所以"离不开"截至 2026 年并未确立，"用不着"同样没有：这个论断是一个有部分根据的合理押注。最有信息量的结果，会是一项在真实的、未植入的问题上（或在许多植入问题上做盲测的）设计良好的审计研究：可解释性方法找到了强的黑盒方法与思维链方法漏掉的行为——或反过来说，一贯地没能找到。
