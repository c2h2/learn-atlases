**回路**（circuit）是网络中实现其某一可辨认计算的部分：几个注意力头、也许还有若干神经元，以及它们之间的通路，外加对每个部分做什么、它们如何配合的说明。回路纲领押注：训练出的网络至少部分地由这样的机制搭建而成，而找到它们是可能也值得的。本章介绍证据最充分的几个例子。**归纳头**（induction heads；Olsson 等人，2022）用位于不同层的两个头实现上下文内复制，而它们在训练中出现的时刻恰好与上下文学习的一次突然改进重合。GPT-2 small 中的**间接宾语识别**回路（Wang 等人，2023）牵涉分属七个功能类的 $26$ 个头，对其的研究引入了评判一个回路的明确标准——忠实性、完备性、最小性。**自动回路发现**（ACDC；Conmy 等人，2023）把寻找回路变成了一个算法。而一个在**模加法**上训练的单层 Transformer 被发现用离散傅里叶变换与三角恒等式做计算（Nanda 等人，2023），这使人们得以在被称为*顿悟*（grokking）的延迟泛化过程中观察回路成形。

这里的工具来自 [[interpretability/residual-stream]]——QK 回路、OV 回路、复合、直接 logit 归因——再加上消融与修补，后者由 [[interpretability/causal-interventions]] 完整展开。实验室部分手工搭出一个归纳回路，并在全部 $113^2$ 个输入对上验证模加法的傅里叶算法。

## 什么算回路 {#sec-what}

Transformer 的计算可以画成一个有向无环图：节点是嵌入、注意力头（或分开地看作它的查询、键、值输入）、前馈层（或单个神经元）与输出；每个组件到每个能从残差流读到其输出的后续组件都有一条边。一个行为由一个提示数据集和一个**度量**指定——对补全任务，通常是正确词元与某个貌似合理的错误词元之间的 logit 差。

::: definition 回路、忠实性、完备性、最小性 {#def-circuit}
一个任务的**回路**是计算图 $G$ 的一个子图 $C$。评估 $C$ 的办法是：把 $C$ 之外的每条边都**消融**——其值换成某个参考值，例如在数据集上的均值，或在某个受损提示上的值——然后计算任务度量 $m(C)$。依照 Wang 等人（2023）：
- $C$ 是**忠实的**，若 $m(C)\approx m(G)$：仅凭这个回路就能复现模型的性能；
- $C$ 是**完备的**，若对每个子集 $K\subseteq C$，把 $K$ 从 $C$ 与从 $G$ 中删去的效果类似，$m(C\setminus K)\approx m(G\setminus K)$——机制没有任何部分落在 $C$ 之外；
- $C$ 是**最小的**，若 $C$ 的每个组件都重要：对每个 $v\in C$，存在某个 $K$ 使 $m(C\setminus K)$ 与 $m(C\setminus(K\cup\{v\}))$ 相差明显。
:::

仅有忠实性是很弱的证据：回路可以在复现度量的同时漏掉在其他输入上重要的部分，而且结果依赖消融方法——置零、均值或重采样的取值可能给出不同的回路（Zhang 与 Nanda，2024 系统研究了这些选择）。完备性检验寻找回路之外会在回路受损时顶替上来的组件，最惊人的发现（例如后备头）正出自这里。

::: example 忠实性比例 {#ex-faithful}
在一个 IOI 式的数据集上，完整模型在正确名字与重复名字之间的 logit 差均值为 $3.5$。把候选回路之外的所有边做均值消融后是 $3.0$；把每个头都做均值消融（回路为空）后是 $0.0$。计算这个回路恢复的性能份额。若从回路中删去三个头使 $m(C)$ 降到 $1.0$，完整模型的度量却只降到 $3.1$，这说明什么？
::: solution
归一化忠实性为 $(m(C) - m(\varnothing))/(m(G) - m(\varnothing)) = 3.0/3.5 = 0.857$：这个回路恢复了约 $86\%$ 的 logit 差。后一个观察是完备性失败：三个头在回路内部很重要（$3.0\to1.0$），在完整模型里却不重要（$3.5\to3.1$），所以回路之外有东西在补偿它们的损失。Wang 等人恰好发现了这一点，并把补偿的组件确认为**后备名字搬运头**：当主要的名字搬运头被消融时，它们接管工作。
:::
:::

## 归纳头 {#sec-induction}

语言里充满了重复。一个名字、一个变量或不常见的短语出现过一次之后，就很可能再次出现，后面还跟着同样的接续：在 "Mr and Mrs Dursley … Mr" 之后，下一个词元很可能是 "Dursley"。能利用这种重复的模型，上下文越长预测得越好——这是上下文学习最简单的形式。

::: definition 归纳头 {#def-induction}
**归纳头**是这样一种注意力头：在持有词元 $A$ 的位置上，它注意 $A$ 早先某次出现之**后紧邻的**位置，并抬高它所注意的词元的 logit。在序列 $\ldots A\,B\ldots A$ 上，它预测 $B$。两个分数让定义可以操作（Olsson 等人，2022）：在重复两次的随机词元序列上，**前缀匹配得分**是该头从第二次重复中的每个词元指向其首次出现之后那个词元的平均注意力；**复制得分**度量它的 OV 回路在多大程度上抬高被注意词元的 logit（$W_EW_{OV}W_U$ 的正特征值；[[interpretability/residual-stream]]）。
:::

单个头实现不了这一点：它在位置 $i$ 的查询看得见词元 $A$，可位置 $j$ 的键只知道词元 $x_j$，不知道它前面是哪个词元。Elhage 等人（2021）与 Olsson 等人在两层仅注意力模型中发现，其机制是 **K-复合**：

1. 第 $1$ 层的**前词元头**从每个位置 $j$ 注意 $j - 1$，并通过其 OV 回路把词元 $x_{j-1}$（的一个编码）写入位置 $j$ 的残差流。
2. 第 $2$ 层的**归纳头**通过其 QK 回路，把当前词元 $x_i$ 用作查询、把写入的前词元信息用作键，于是当 $x_{j-1} = x_i$ 时位置 $j$ 得分很高。它的 OV 回路把 $x_j$ 复制到输出。

::: proposition 一个两层归纳回路 {#prop-induction}
设残差流中含有彼此正交的子空间：当前词元（one-hot $\mathbf{e}_{x_i}$）、位置（one-hot $\mathbf{p}_i$）、前词元槽、以及被解嵌入读取的输出槽。设头 $1$ 的 QK 回路为 $\beta\,\mathbf{p}_i\T\mathbf{p}_{i-1}$ 型权重（从查询位置 $i$ 给键位置 $i - 1$ 打分），其 OV 回路把词元的 one-hot 复制进前词元槽；头 $2$ 的 QK 回路是查询的词元子空间与键的前词元槽之间 $\beta$ 倍的恒等映射，其 OV 回路把词元的 one-hot 复制进输出槽。则当 $\beta\to\infty$ 时，在任何词元 $x_i$ 此前恰好在位置 $j - 1 < i$ 出现过一次的序列上，头 $2$ 在位置 $i$ 把全部注意力放到位置 $j$，并把 $\mathbf{e}_{x_j}$ 写入输出槽。
:::

::: proof
位置 $j$ 的头 $1$ 对键 $j - 1$ 得分为 $\beta$、对其余键为 $0$；当 $\beta\to\infty$ 时 softmax 集中于 $j - 1$，于是位置 $j$ 的前词元槽变为 $\mathbf{e}_{x_{j-1}}$（在位置 $0$ 是某个固定占位符，例如序列起始词元，它不等于任何普通词元）。于是位置 $i$ 的头 $2$ 对每个键 $j'\le i$ 得分为 $\beta\,\mathbf{e}_{x_i}\cdot\mathbf{e}_{x_{j'-1}} = \beta\,[x_{j'-1} = x_i]$。由假设，恰有一个键 $j$ 满足 $x_{j-1} = x_i$（位置 $i$ 自身将要求 $x_{i-1} = x_i$，而被"$x_i$ 此前恰好出现过一次"的假设排除）；所以当 $\beta\to\infty$ 时注意力集中于 $j$，OV 回路写入 $\mathbf{e}_{x_j}$。
:::

这个构造正是 [[#sec-code]] 中实验室要运行的东西。训练出的模型实现同一算法时不那么干净：前词元信息写进一个共享子空间而非专用槽位，匹配是"模糊"的（相似词元也会匹配），而且有许多头一起出力。

::: example 追踪一个归纳头 {#ex-trace}
"The cat sat. The cat" 的各个词元位于位置 $0$–$5$：The、cat、sat、"."、The、cat。归纳头从位置 $5$ 注意哪个位置？它预测什么？那从位置 $4$ 呢？
::: solution
位置 $5$ 的词元是 "cat"。它此前的出现在位置 $1$，于是其后继位置是 $2$，而位置 $2$ 的前一个词元（由前词元头写入）是 "cat"——键与查询匹配。该头注意位置 $2$ 并复制 "sat"：它预测 "The cat sat. The cat sat"。在位置 $4$，词元 "The" 出现在位置 $0$；位置 $1$ 的键的前词元是 "The"，于是该头注意位置 $1$ 并预测 "cat"——这正是实际的下一个词元。
:::
:::

### 相变 {#sec-phase}

Olsson 等人（2022）的《上下文学习与归纳头》（*In-context Learning and Induction Heads*）训练了许多模型——一到六层的仅注意力模型，以及大到几十亿参数的完整 Transformer（某些测量用到了约 $130$ 亿）——并记录了它们在训练过程中的行为。他们用**上下文学习得分**度量上下文学习：上下文第 $500$ 个词元上的损失减去第 $50$ 个词元上的损失，再在数据集上取平均；值越负，说明模型从更长上下文中获益越多。据他们的报告，其发现包括：

- 在每个超过一层的模型中，训练早期（在他们的运行中是几十亿词元之后）发生一次**相变**，表现为训练损失曲线上的一个凸起。其间归纳头形成（前缀匹配得分跳升），上下文学习得分急剧下降到大致最终的数值。无法靠 K-复合形成归纳头的单层模型，两者都不出现。
- 让归纳头更容易形成的架构改动（让单个头注意前一位置键的混合——"涂抹键"）使相变提前，上下文学习的改进也随之提前。
- 在小型仅注意力模型中，测试时消融归纳头会抹去大部分上下文学习；在大模型中，证据是相关性的。
- 在大模型中，归纳头还执行**模糊**与**抽象**的模式补全——例如注意被译句中对应的词元——这表明同一机制经过推广，为更抽象的上下文学习作出了贡献。

作者提出了六条证据并给其强度分了级：对小型仅注意力模型是强的因果证据；对大模型只是提示性的相关证据。归纳头是大模型中**大部分**上下文学习的机制——这一假设是以假说的身份提出的。后来的工作发现了上下文学习的其他机制，例如把示范所描述的任务表征为一个向量的头（"函数向量"；Todd 等人，2024），所以截至 2026 年，归纳头最好被视作若干重要机制之一。

::: example 一个上下文学习得分 {#ex-icl}
某模型在文档第 $50$ 个词元上的平均损失为 $4.10$ 纳特，在第 $500$ 个词元上为 $3.55$ 纳特。相变之前这两个数值是 $4.30$ 与 $4.20$。计算相变前后的上下文学习得分并解读。
::: solution
之前：$4.20 - 4.30 = -0.10$ 纳特。之后：$3.55 - 4.10 = -0.55$ 纳特。相变之后，模型对一个较晚词元的预测从前面的 $450$ 个词元获益约 $0.55$ 纳特，之前只有 $0.10$。总损失也下降了，但这个得分把改进中依赖上下文长度的那一部分单独分离了出来。
:::
:::

## 间接宾语识别 {#sec-ioi}

Wang、Variengien、Conmy、Shlegeris 与 Steinhardt（2023）的《真实环境中的可解释性》（*Interpretability in the Wild*）研究了 GPT-2 small 如何补全这样的句子：

> When Mary and John went to the store,
> John gave a drink to

它补出的是 "Mary"，即**间接宾语**（IO），而不是重复出现的**主语**（S）"John"。度量是 logit 差 $\text{logit}(\text{IO}) - \text{logit}(\text{S})$，数据集由含许多名字、地点与物体的模板生成。他们用**路径修补**——把特定路径上的激活替换为它们在一个名字不同的受损提示上的值，并度量变化（[[interpretability/causal-interventions]]）——找到了一个由 $26$ 个注意力头组成的、分为七类的回路。这个回路实现的算法概要是：*识别句中所有名字，去掉重复出现的那个，输出剩下的那个*。

- **重复词元头**与**归纳头**（由**前词元头**向后者的键供信息）检测出 S 出现了两次，并把这一信息写在第二个 S 的位置上。
- **S-抑制头**在最后位置读取该信息，写入一个降低对 S 之注意力的信号。
- **名字搬运头**在靠后的层里从最后位置注意各个名字并把它们复制到输出；由于 S-抑制信号的存在，它们注意 IO，并写下它的 logit。它们的 QK 回路被 S-抑制的输出查询，这是 Q-复合的例子。
- **负名字搬运头**注意各个名字并**压低**其 logit，使模型不那么自信；**后备名字搬运头**平时几乎不做事，但当主要名字搬运头被消融时便接管。

该研究报告：这个回路在其余部分全部均值消融的情况下恢复了模型 logit 差的大部分（约 $87\%$），并通过了若干完备性与最小性检验，同时某些检验暴露出缺口——行为中该回路无法解释的部分。在当时，这是对语言模型一个自然行为最大的端到端逆向解析，它还揭示了几个普遍现象：冗余（后备头）、消融后的自我修复（McGrath 等人，2023 后来以"九头蛇效应"研究它），以及功能在于抑制的头——McDougall 等人（2023）把负名字搬运头解释为**复制抑制**头，它们压低那些更早出现在上下文中、且正被预测的词元的 logit。

::: warning 回路总是相对于任务、度量与消融而言的
IOI 回路解释的是 GPT-2 small 在一个模板化分布上、由 logit 差度量、在均值消融下的行为。换掉模板、换掉度量（用 IO 的概率而非 logit 差）、或换掉消融（用置零或重采样代替均值），找到的回路就可能改变。所以回路并不是某项能力"那个"机制：它们是关于某个指定分布上一个机制的、经过充分检验的假说。关于回路能推广——到其他措辞、其他模型或更大规模——的论断需要各自的检验。
:::

## 自动回路发现 {#sec-acdc}

IOI 分析花了研究者几个月的工夫。Conmy 等人（2023）的《迈向机制可解释性的自动回路发现》（*Towards Automated Circuit Discovery for Mechanistic Interpretability*）注意到，它的工作流程——选定数据集与度量、修补激活、保留重要者——是可以自动化的。

::: algorithm 自动回路发现（ACDC） {#alg-acdc}
**输入：**计算图 $G$（节点：嵌入、各头与 MLP 的输入和输出；节点之间有边）、干净提示与对应的受损提示、阈值 $\tau > 0$。**输出：**子图 $H$。
1. 令 $H\leftarrow G$。把节点按逆拓扑序排列（从输出往输入的方向）。
2. 按此顺序对每个节点 $w$，对进入它的每条边 $(v, w)\in H$：
   1. 构造 $H' = H\setminus\{(v, w)\}$，其中该边承载的是受损提示上的值而不是干净提示上的值。
   2. 若 $D_{\mathrm{KL}}\bigl(p_G\,\Vert\,p_{H'}\bigr) - D_{\mathrm{KL}}\bigl(p_G\,\Vert\,p_H\bigr) < \tau$（在提示上平均），则令 $H\leftarrow H'$。
3. 删去不再与输出相连的节点，返回 $H$。
:::

度量未必是 KL散度；Conmy 等人也用了 logit 差这样的任务度量。他们用 ACDC 能否找回先前手工发现的回路来评估它——IOI、GPT-2 small 的"大于"回路（Hanna 等人，2023）、docstring 补全、以及归纳——把手工找到的边当作标准答案，随 $\tau$ 变化绘制 ROC 曲线；ACDC 在若干任务上找回了手工发现的大部分组件，但不是全部，而且这种比较的好坏也受手工回路本身质量的限制。每条边的检验都要一次前向传播，所以代价随边数增长；**边归因修补**（Syed、Rager 与 Conmy，2023）这类基于梯度的近似把每条边修补的效应线性化，几次传播就能检验所有边，代价是在线性化失效处失去精度。后来的工作把图的节点从头和神经元换成了稀疏特征（[[interpretability/sparse-features]]）。

::: example 按阈值剪枝 {#ex-prune}
处理某个节点时，ACDC 依次检验它的四条入边；当前子图关于完整模型的 KL散度为 $0.010$。删去边 $1$ 会使其升到 $0.012$；在此之后，删去边 $2$ 到 $0.090$、边 $3$ 到 $0.013$、边 $4$ 到 $0.016$（每次都从当前子图量起）。当 $\tau = 0.005$ 时，哪些边会被保留？
::: solution
边 $1$：增幅 $0.002 < 0.005$，删去；KL 变为 $0.012$。边 $2$：增幅 $0.078$，保留；KL 保持 $0.012$。边 $3$：$0.013 - 0.012 = 0.001$，删去；KL 变为 $0.013$。边 $4$：$0.016 - 0.013 = 0.003$，删去。只有边 $2$ 被保留。注意小的删失会累积——三条被删的边合计抬高了 KL 约 $0.006$，超过 $\tau$——这就是结果依赖处理顺序、而且最终子图要作为整体再检验忠实性的原因。
:::
:::

## 顿悟与模加法的傅里叶算法 {#sec-grokking}

Power 等人（2022）用全部输入对中的一部分，在小 Transformer 上训练 $a + b \bmod p$ 这样的算法任务，观察到**顿悟**：训练损失很快降到近零而测试准确率停留在瞎猜水平，随后过了很久——多得多步之后，并且有权重衰减相助——测试准确率突然升到 $100\%$。网络先是记住了，后来才泛化。

Nanda、Chan、Lieberum、Smith 与 Steinhardt（2023）的《用机制可解释性度量顿悟进程》（*Progress Measures for Grokking via Mechanistic Interpretability*）逆向解析了一个在 $a + b\bmod 113$ 上训练的单层 Transformer，训练数据是 $113^2$ 个词元对中的 $30\%$。他们发现它用一个**离散傅里叶变换**计算答案：

1. 嵌入把每个输入 $a$ 映为（近似）少数几个**关键频率** $\omega_k = 2\pi k/p$ 下的 $\cos(\omega_ka)$ 与 $\sin(\omega_ka)$——在他们分析的那个模型中是五个，$k\in\{14, 35, 41, 42, 52\}$。
2. 注意力与 MLP 计算这些量的乘积，借助角度加法恒等式得到 $\cos(\omega_k(a + b))$ 与 $\sin(\omega_k(a + b))$。
3. 解嵌入对每个候选答案 $c$ 计算 $\cos(\omega_k(a + b - c)) = \cos(\omega_k(a + b))\cos(\omega_kc) + \sin(\omega_k(a + b))\sin(\omega_kc)$，并对关键频率求和。

于是 logit 近似为 $\sum_k\cos(\omega_k(a + b - c))$，它在 $c\equiv a + b$ 时最大。作者用几项独立的检验确认了这份描述：嵌入与神经元激活在傅里叶基下是稀疏的；神经元激活可被关键频率下 $a + b$ 的函数很好地逼近；消融掉所有其他频率对性能几乎无损，而消融掉关键频率则彻底摧毁性能。

::: proposition 傅里叶算法的正确性 {#prop-fourier}
设 $p$ 为素数，$k_1,\dots,k_m\in\{1,\dots,p-1\}$。对输入 $a, b\in\Z_p$ 定义 $L(c) = \sum_{j=1}^m\cos\bigl(2\pi k_j(a + b - c)/p\bigr)$，$c\in\Z_p$。则
1. $L$ 恰在 $c\equiv a + b\pmod p$ 处取到最大值 $m$；
2. 间隔 $L(a+b) - \max_{c\not\equiv a+b}L(c)$ 等于 $\min_{d\in\{1,\dots,p-1\}}\sum_j\bigl(1 - \cos(2\pi k_jd/p)\bigr) > 0$，与 $a$ 和 $b$ 无关；
3. $\sum_{c\in\Z_p}L(c) = 0$，于是平均 logit 为 $0$。
:::

::: proof
写 $d = a + b - c\bmod p$。每一项 $\cos(2\pi k_jd/p)\le1$，等号成立当且仅当 $k_jd\equiv0\pmod p$。因为 $p$ 是素数且 $k_j\not\equiv0$，$k_j$ 在模 $p$ 下可逆，所以 $k_jd\equiv0$ 当且仅当 $d\equiv0$。于是在 $d = 0$ 处 $L = m$，而 $d\ne0$ 时每一项都严格小于 $1$，这就证明了 (1)。对于 (2)，$L(a+b) - L(c) = \sum_j(1 - \cos(2\pi k_jd/p))$ 只通过 $d$ 依赖 $c$，而当 $c$ 取遍错误答案时 $d$ 取遍 $\{1,\dots,p-1\}$；每个和由 (1) 皆正。对于 (3)，$\sum_{d=0}^{p-1}\cos(2\pi k_jd/p) = \operatorname{Re}\sum_{d=0}^{p-1}\zeta^d$，其中 $\zeta = e^{2\pi ik_j/p}\ne1$ 是一个 $p$ 次单位根，而等比级数为 $(\zeta^p - 1)/(\zeta - 1) = 0$。
:::

这条命题解释了为什么一个频率就足以保证正确、却需要几个频率才有把握：只有一个频率时，满足 $k d\equiv\pm1$ 的错误答案有 $\cos(2\pi/p)$，对 $p = 113$ 来说非常接近 $1$，所以间隔极小（$1 - \cos(2\pi/113) = 0.0015$）；把几个频率加起来，在某个频率上几乎吻合的错误答案会在其他频率上不吻合——只在正确答案处**相长干涉**。实验室部分计算这些间隔。

::: example 模 $7$ 加法 {#ex-p7}
用单一频率 $k = 2$ 的傅里叶算法计算 $3 + 5\bmod7$。
::: solution
这里 $a + b = 8$，$L(c) = \cos(4\pi(8 - c)/7)$，对 $c = 0,\dots,6$ 计算：值为 $-0.223, 1.000, -0.223, -0.901, 0.623, 0.623, -0.901$。最大值在 $c = 1$，确实 $8\bmod7 = 1$。亚军值 $0.623 = \cos(2\pi\cdot2\cdot3/7) = \cos(2\pi/7)$ 出现在 $d = \pm3$ 处（因为 $2\cdot3 = 6\equiv-1$），给出间隔 $1 - \cos(2\pi/7) = 0.377$。
:::
:::

机制已知之后，Nanda 等人定义了跟踪它在训练中立起过程的**进度度量**。*受限损失*只保留 logit 中关键频率的分量，度量傅里叶回路单独的发挥；*排除损失*去掉这些分量，度量模型在多大程度上依赖其余一切（记忆）。这些度量揭示了顿悟之前看似平坦的平台期内有三段：**记忆**训练集；**回路成形**，其间傅里叶回路逐渐壮大，但因记忆分量仍占上风，测试准确率依旧很差；以及**清理**，权重衰减除掉记忆分量，测试准确率跃升。于是突发的泛化是一个渐进内部过程露出水面的一端——机制性理解能揭示损失曲线掩盖了什么，这被视为一个例证。

这个算法并不唯一。Zhong 等人（2023）的《时钟与披萨》（*The Clock and the Pizza*）发现，架构与超参略作改变就会导向模加法的另一种算法（"披萨"），与傅里叶的"时钟"并存；Chughtai、Chan 与 Nanda（2023）研究了在其他有限群上训练的网络，找到表征论意义的算法，傅里叶算法是其特例。教训是：训练找到的是**一个**机制，不是**那个**机制，这对普适性假说有直接影响（[[interpretability/interpretability-goals#sec-map]]）。

::: quiz
一个在 $a + b\bmod p$ 上训练的网络使用单一关键频率 $k$。下列哪种说法正确？
- [ ] 它必定在某些输入上失败，因为一个余弦无法在 $p$ 个剩余中挑出一个。
- [x] 只要 $p$ 是素数它在所有输入上都正确，但正确答案与最佳错误答案之间的间隔很小，所以除非把 logit 放大很多倍，它的损失都很高。
- [ ] 它只有当 $k = 1$ 时才正确。
- [ ] 它在所有答案上的平均 logit 是 $1$。
::: solution
由 [[#prop-fourier]]，只要 $p$ 是素数，单个频率 $k\not\equiv0$ 就已使正确答案成为唯一最大值，因为 $k$ 在模 $p$ 下可逆。但某个错误答案满足 $kd\equiv\pm1$，logit 为 $\cos(2\pi/p)$，与最大值非常接近；要得到低交叉熵，需要很大的 logit 或更多的频率。平均 logit 是 $0$（第 3 条）。
:::
:::

## 一个数值实验室 {#sec-code}

第一个清单实现 [[#prop-induction]] 中手工构造的归纳回路——一个残差流为 $3V + T$ 维的两层仅注意力 Transformer——并在由 $10$ 个不同词元及其重复构成的随机序列上评估它。

```python
import math, random
rng = random.Random(4)

# 残差流：[词元 one-hot (V) | 位置 one-hot (T) | 前词元槽 (V) | 输出槽 (V)]
V, T, BOS = 21, 21, 20                  # 词元 20 是序列起始标记
D = 3 * V + T
TOK, POS, PREV, OUT = 0, V, V + T, 2 * V + T
BETA = 20.0                             # 注意力锐度（QK 权重的尺度）

def softmax(z):
    m = max(z); e = [math.exp(v - m) for v in z]; s = sum(e); return [v / s for v in e]

def run(seq):
    n = len(seq)
    X = [[0.0] * D for _ in range(n)]                      # (n, D)
    for i, t in enumerate(seq):
        X[i][TOK + t] = 1.0; X[i][POS + i] = 1.0
    # 第 1 层：前词元头。QK：位置 i 的查询给位置 i - 1 的键打分。
    # OV：把键的词元 one-hot 复制进 PREV 槽。
    new = [row[:] for row in X]
    for i in range(n):
        a = softmax([BETA * X[j][POS + i - 1] if i > 0 else 0.0 for j in range(i + 1)])
        for j in range(i + 1):
            for v in range(V):
                new[i][PREV + v] += a[j] * X[j][TOK + v]
    X = new
    # 第 2 层：归纳头。QK（K-复合）：查询的 TOK 槽对每个键的 PREV 槽。
    # OV：把键的词元复制进 OUT 槽，供 W_U 读取。
    logits = []
    for i in range(n):
        a = softmax([BETA * sum(X[i][TOK + v] * X[j][PREV + v] for v in range(V)) for j in range(i + 1)])
        out = [sum(a[j] * X[j][TOK + v] for j in range(i + 1)) for v in range(V)]
        logits.append([8.0 * o for o in out])              # 解嵌入只读 OUT 槽
    return logits

def nll(lg, target): return -math.log(softmax(lg)[target])
H = 10
first, second, correct, n2 = [], [], 0, 0
for _ in range(200):
    half = rng.sample(range(20), H)                        # 10 个不同词元 …
    seq = [BOS] + half + half                              # … 然后重复
    lg = run(seq)
    for i in range(1, len(seq) - 1):
        if i < H:
            first.append(nll(lg[i], seq[i + 1]))
        elif i > H:                                        # 下一个词元已被见过的部位
            second.append(nll(lg[i], seq[i + 1])); n2 += 1
            correct += max(range(V), key=lambda v: lg[i][v]) == seq[i + 1]
print(f"mean loss, first occurrence {sum(first) / len(first):.3f} nats; repeated {sum(second) / len(second):.3f} nats")
print(f"uniform over 20 tokens: {math.log(20):.3f} nats; top-1 accuracy when repeated: {correct / n2:.3f}")
```

```text
mean loss, first occurrence 3.812 nats; repeated 0.007 nats
uniform over 20 tokens: 2.996 nats; top-1 accuracy when repeated: 1.000
```

在重复段上，这个回路预测对了每一个词元，损失只有 $0.007$ 纳特。在首次出现段上它比瞎猜**更差**（$3.812$ 对 $2.996$ 纳特）：前面没有匹配时，归纳头把注意力摊到较早的各个词元上并把它们复制过来，可在这类序列里较早的词元接下来再也不会出现。真正的模型会把归纳与其他机制结合，并学会复制何时划算。

第二个清单按 [[#sec-grokking]] 的方式，从嵌入到 logit 搭出 $a + b\bmod113$ 的傅里叶算法，logit 乘以 $10$ 缩放，并在全部 $12{,}769$ 个输入对上评估。

```python
import math

p = 113
KEYS = [14, 35, 41, 42, 52]          # 他们的某个训练好的模型报告的关键频率
COS = {k: [math.cos(2 * math.pi * k * x / p) for x in range(p)] for k in range(p)}
SIN = {k: [math.sin(2 * math.pi * k * x / p) for x in range(p)] for k in range(p)}

def logits(a, b, keys, scale):
    z = [0.0] * p
    for k in keys:
        ca, sa, cb, sb = COS[k][a], SIN[k][a], COS[k][b], SIN[k][b]   # a 和 b 的嵌入
        cab = ca * cb - sa * sb                    # cos w(a+b)：乘积在 MLP 中形成
        sab = sa * cb + ca * sb                    # sin w(a+b)
        for c in range(p):                         # 解嵌入：cos w(a+b-c)
            z[c] += scale * (cab * COS[k][c] + sab * SIN[k][c])
    return z

def evaluate(keys, scale=10.0):
    correct, loss, margin = 0, 0.0, float("inf")
    for a in range(p):
        for b in range(p):
            z, t = logits(a, b, keys, scale), (a + b) % p
            correct += max(range(p), key=z.__getitem__) == t
            m = max(z); loss += m + math.log(sum(math.exp(v - m) for v in z)) - z[t]
            margin = min(margin, z[t] - max(z[c] for c in range(p) if c != t))
    return correct / p ** 2, loss / p ** 2, margin

for keys in [[14], KEYS]:
    acc, loss, margin = evaluate(keys)
    print(f"frequencies {keys}: accuracy {acc:.4f}, mean loss {loss:.3g} nats, smallest margin {margin:.4f}")
```

```text
frequencies [14]: accuracy 1.0000, mean loss 2.67 nats, smallest margin 0.0155
frequencies [14, 35, 41, 42, 52]: accuracy 1.0000, mean loss 8.26e-11 nats, smallest margin 24.1018
```

两个版本永远正确，正如 [[#prop-fourier]] 所保证；但只用一个频率时，间隔是 $10(1 - \cos(2\pi/113)) = 0.0155$，损失（$2.67$ 纳特）只是比把概率摊给那些几乎并列的答案略好；五个频率给出 $24.1$ 的间隔和几乎为零的损失。这就是最小化交叉熵的训练出的网络要用好几个频率的原因。

::: history
回路纲领由 Olah 等人（2020）在 Distill 上的《放大观察：回路导论》为视觉模型确立，以曲线检测器为示范例。Elhage 等人（2021）把它带进 Transformer，并描述了双层仅注意力模型中的归纳头；Olsson 等人（2022）研究了归纳头的形成及其在上下文学习中的角色。Wang 等人（2023，ICLR；预印本 2022）逆向解析了 GPT-2 small 中的间接宾语识别，并提出忠实性、完备性与最小性；Hanna 等人（2023）找到了"大于"回路；Conmy 等人（2023，NeurIPS）用 ACDC 自动发现回路，Syed 等人（2023）用边归因修补对其作近似。Power 等人（2022）报告了顿悟；Nanda 等人（2023，ICLR）用傅里叶特征与进度度量解释了模加法，Zhong 等人（2023）与 Chughtai 等人（2023）找到了其他算法。McGrath 等人（2023）描述了自我修复，McDougall 等人（2023）描述了复制抑制。Lieberum 等人（2023）通过研究 700 亿参数的 Chinchilla 模型中的选择题回答来检验回路分析能扩展多远，找到了一些可辨认的组件，但也发现了更杂乱、更不完整的解释。
:::

::: summary
- **回路**是模型计算图的一个子图，通过消融其余一切来评估；好的回路应当**忠实**、**完备**、**最小**（Wang 等人, 2023），且总是相对于某个数据集、度量与消融方法而言。
- **归纳头**在 $\ldots A\,B\ldots A$ 之后预测 $B$，靠 K-复合实现：前词元头在位置 $j$ 写入 $x_{j-1}$，归纳头拿它与当前词元匹配并复制 $x_j$。它们在训练早期的一次**相变**中形成，与上下文学习的跳升同时发生（Olsson 等人, 2022）；证据在小模型中是因果的，在大模型中是相关性的。
- GPT-2 small 的 **IOI 回路**（$26$ 个头，七个类）找到各个名字、抑制重复的那个、复制另一个；它揭示了后备头、自我修复与负（复制抑制）头。
- **ACDC** 剪去那些修补后对输出分布改变不足阈值的边；梯度近似使其更便宜。
- **顿悟**模加法的单层 Transformer 经傅里叶特征与三角恒等式计算 $\sum_k\cos(\omega_k(a + b - c))$；$p$ 为素数时一个频率即保证正确，多个频率给出大间隔。进度度量揭示了突发泛化背后的记忆、回路形成与清理，而别的训练运行会找到别的算法。
:::

## 习题

::: exercise 单频率的间隔 {level=1 check="0.0155"}
对只有一个频率、logit 缩放 $10$ 倍、$p = 113$ 的傅里叶算法，证明最小间隔为 $10(1 - \cos(2\pi/113))$，并算到小数点后四位。
::: solution
由 [[#prop-fourier]]，间隔为 $10\min_{d\ne0}(1 - \cos(2\pi kd/113))$。因为 $k$ 在模 $113$ 下可逆，当 $d$ 取遍非零剩余时 $kd$ 也取遍，而 $1 - \cos(2\pi r/113)$ 在 $r\ne0$ 上的最小值在 $r = \pm1$ 处。所以间隔为 $10(1 - \cos(2\pi/113)) = 10\times0.001545 = 0.0155$。
:::
:::

::: exercise 一个上下文学习得分 {level=1 check="-0.4"}
某模型在第 $50$ 个词元上的损失是 $3.9$ 纳特，在第 $500$ 个词元上是 $3.5$ 纳特。它的上下文学习得分是多少？
::: solution
$3.5 - 3.9 = -0.4$ 纳特。
:::

::: exercise 归纳头看哪里？ {level=1}
对词元序列 "A B C D B"（位置 $0$–$4$），理想归纳头从位置 $4$ 注意哪个位置？它预测什么？前词元头在位置 $2$ 写入了什么？
::: solution
位置 $4$ 的词元是 B，它出现在位置 $1$；下一个位置 $2$ 的前词元是 B，所以该头注意位置 $2$ 并预测 C。位置 $2$ 的前词元头写入 B 的一个编码——位置 $1$ 的词元。
:::
:::

::: exercise 手算模加法 {level=2 check="4"}
用频率 $k\in\{1, 3\}$、$p = 7$ 的傅里叶算法求 $6 + 5\bmod7$：对所有 $c$ 计算 $L(c)$，给出最大值点。
::: solution
$a + b = 11$，于是 $d = 11 - c$，$L(c) = \cos(2\pi d/7) + \cos(6\pi d/7)$。对 $c = 0,\dots,6$，$d\bmod7$ 为 $4, 3, 2, 1, 0, 6, 5$。$\cos(2\pi d/7) + \cos(6\pi d/7)$ 在 $d = 0,\dots,6$ 处的值是 $2$、$-0.277$、$0.401$、$-1.123$、$-1.123$、$0.401$、$-0.277$（例如在 $d = 1$ 处，$\cos(2\pi/7) + \cos(6\pi/7) = 0.623 - 0.901$）。于是 $L(c)$ 在 $c = 4$ 处最大（$= 2$），确实 $11\bmod7 = 4$。
:::
:::

::: exercise 忠实性与完备性 {level=2}
回路 $C$ 的 $m(C) = 2.8$，而 $m(G) = 3.2$、$m(\varnothing) = 0.2$。从两者中同时删去某个头 $v$ 得 $m(C\setminus v) = 2.7$ 与 $m(G\setminus v) = 3.1$。删去一个含两个头的集合 $K$ 得 $m(C\setminus K) = 0.9$ 与 $m(G\setminus K) = 3.0$。计算归一化忠实性并评论完备性。
::: solution
归一化忠实性 $(2.8 - 0.2)/(3.2 - 0.2) = 2.6/3.0 = 0.867$。对 $v$，两者都下降 $0.1$：一致。对 $K$，回路下降 $1.9$ 而完整模型只降 $0.2$：完整模型靠 $C$ 之外的组件补偿了 $K$ 的损失，所以 $C$ 不完备——它应当扩展上任何为 $K$ 后备的东西（例如通过从 $G\setminus K$ 做修补、看哪些外部组件改变了行为来找到它们）。
:::
:::

::: exercise 消融前词元头 {level=2}
在第一个清单里，让前词元头什么都不写（把它的贡献乘以 $0$）。先预测重复半段的损失再运行。
::: solution
没有前词元信息，每个键的 PREV 槽都是零，于是归纳头的得分全为 $0$，它均匀注意位置 $0,\dots,i$，写入这些位置词元 one-hot 的平均。每个词元得到与它在位置 $0,\dots,i$ 中出现次数成正比的 logit——由于没有词元出现超过两次，该比例至多为 $16/(i + 1)$——所以 logit 近乎平坦，损失接近瞎猜，$\log 20 = 2.996$ 纳特。运行修改后的清单，打印的重复半段损失为 $2.994$ 纳特（首次出现段不变，仍为 $3.812$）：归纳能力没了。这正是 Olsson 等人消融实验的手工版——移除第一层的头摧毁了第二层的功能，尽管第二个头本身原封未动，这就是 K-复合。
:::

::: exercise ACDC 与边的顺序 {level=2}
解释为什么 ACDC 返回的子图可能依赖检验边的顺序，并给出一个 $\tau = 0.01$ 的三边例子，使两种顺序给出不同结果。
::: solution
每次检验比较的都是当前子图在含与不含某条边时的差别，所以一条边是否被删，取决于此前已经删了哪些边。例子：边 $e_1, e_2$ 互为冗余备份——单独删任一条只使 KL 上升 $0.002$，两条都删则上升 $0.5$——而 $e_3$ 无关紧要。先测 $e_1$ 就删掉它（$0.002 < 0.01$）；此时再删 $e_2$ 将付出约 $0.5$，所以 $e_2$ 保留：结果 $\{e_2\}$。先测 $e_2$ 则得 $\{e_1\}$。冗余——后备头表明这在真实模型中很常见——使输出依赖顺序，并意味着回路可能省略在其他情形下重要的组件。
:::

::: exercise 乘积为什么需要非线性 {level=3}
在傅里叶算法中，网络必须从在"不同位置上含有 $\cos(\omega a)$ 与 $\cos(\omega b)$"的嵌入算出 $\cos(\omega a)\cos(\omega b)$。证明 ReLU 能从和差造出乘积：把 $xy$ 用 $(x + y)^2$ 与 $(x - y)^2$ 表示，并说明平方如何用 ReLU 单元逼近。为什么只对值向量取加权*平均*的注意力，在仅注意力的单层模型里自己算不出乘积？
::: solution
$xy = \tfrac14\bigl((x + y)^2 - (x - y)^2\bigr)$，所以乘积可由和与差的平方得出，而和、差对输入是线性的。在有界区间上，平方可用分段线性函数 $\sum_r\alpha_r\operatorname{ReLU}(z - t_r)$（外加对负 $z$ 的镜像项）逼近，所以一个接收 $x + y$ 与 $x - y$（由从残差流线性组合而来——注意力已把 $a$ 与 $b$ 的嵌入带到一起）的 MLP 层可以输出近似于 $xy$ 的东西。在单层仅注意力模型中，最后位置的输出是 $\sum_jA_{ij}\mathbf{x}_jW_{OV}$ 加上直连通路——对固定的注意力模式关于值向量是线性的，所以它只含 $\alpha\cos(\omega a) + (1 - \alpha)\cos(\omega b)$ 这样的和，不含乘积；唯一的非线性是模式里的 softmax，它只依赖查询与键。（Nanda 等人指出注意力模式确实贡献了一些乘性交互，但他们的模型中乘积项的主体是由 MLP 神经元算出的。）
:::

::: exercise 平均 logit 与校准 {level=3}
利用 [[#prop-fourier]] 的第 (3) 条，把五频率算法（logit 缩放为 $s$）在某个输入上的交叉熵损失写成各 $L(c)$ 的函数，并证明当 $s\to\infty$ 时损失趋于 $0$。然后解释为什么惩罚大权重的权重衰减，会迫使训练中的网络使用**多个**频率，而不是一个频率配巨大的缩放。
::: solution
损失为 $-\log\bigl(e^{sL(t)}/\sum_ce^{sL(c)}\bigr) = \log\bigl(1 + \sum_{c\ne t}e^{-s(L(t) - L(c))}\bigr)$，其中 $L(t) = m = 5$。每一项都有 $L(t) - L(c)\ge\Delta$（间隔），所以损失不超过 $\log(1 + (p - 1)e^{-s\Delta})\to0$（$s\to\infty$）。要达到给定损失 $\varepsilon$，缩放须大致满足 $s\Delta\ge\log((p - 1)/\varepsilon)$。单频率时 $\Delta = 1 - \cos(2\pi/113) = 0.0015$，所以 $s$ 必须比 $\Delta\approx2.4$（五频率）时大约 $2.41/0.0015\approx1600$ 倍。logit 缩放由权重的乘积产生，巨大的 $s$ 要求巨大的权重范数，而这正是权重衰减惩罚的；增加频率所增加的间隔，代价只是随频率个数线性增长的权重。所以最小化"损失 + 权重衰减"偏爱少数几个频率——与 Nanda 等人发现的五个相符，尽管确切个数取决于训练细节。
:::
