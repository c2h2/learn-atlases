The algorithms of [[artificial-intelligence/decision-making]] compute optimal policies from a **model**: the transition probabilities $P(s' \mid s, a)$ and the rewards $R(s, a, s')$. Often nobody can write the model down. What are the probabilities that a robot's gripper slips on a particular object, that a customer clicks on a particular recommendation, or that a given move in Go leads to a won game? What an agent *can* do is act and observe what happens. **Reinforcement learning** (RL) is the problem of learning to act well from such experience: the agent sees states and **rewards**, never the model, and must discover by trial and error which actions lead, perhaps much later, to high reward.

Two difficulties distinguish RL from the supervised learning of the [LLM Atlas](/learn/llm/course.php?c=ml-fundamentals). There is no teacher saying which action was right, only a scalar reward, often delayed — the **credit assignment** problem. And the data depend on the agent's own behaviour: to learn about an action it must try it, at the cost of not doing what currently looks best — the **exploration–exploitation** dilemma. This chapter develops the classical answers. We estimate values from sampled returns (**Monte Carlo**) and from one-step bootstrapped targets (**temporal-difference learning**); we learn optimal action values without a model by **Q-learning**, whose convergence rests on the contraction property of the previous chapter; we study exploration in its purest form, the **multi-armed bandit**; and we see how **function approximation** and **policy gradients** take these ideas to large problems — and where the guarantees stop.

## Learning values from experience

The agent interacts with an MDP whose states and actions it knows but whose $P$ and $R$ it does not. An **episode** is a sequence $s_0, a_0, r_1, s_1, a_1, r_2, \dots$ ending in a terminal state (or continuing indefinitely); from each visit to a state at time $t$ the observed **return** is $G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots$. By [[artificial-intelligence/decision-making#def-value]], $U^\pi(s) = \E[G_t \mid s_t = s]$ when the agent follows $\pi$.

The first task is **prediction** (or **policy evaluation**): estimate $U^\pi$ for a fixed policy $\pi$ from episodes generated by following it. Three ideas are available.

- **Model-based (adaptive dynamic programming).** Estimate $P$ and $R$ by counting transitions, and solve the Bellman equations of the estimated model. Data-efficient, but it needs to store and solve a model, which is infeasible for huge state spaces.
- **Monte Carlo.** Estimate $U^\pi(s)$ by the average of the returns observed after visits to $s$. Each return is an unbiased sample of $U^\pi(s)$, so by the law of large numbers the average converges. No model, no Bellman equation — but the agent must wait until the end of an episode, and returns have high variance, since they sum many random rewards.
- **Temporal differences.** Update after every step, towards a target built from the next reward and the *current estimate* of the next state's value.

All model-free methods use **incremental averaging**. If $\bar x_n$ is the mean of $x_1, \dots, x_n$, then
$$
\bar x_n = \bar x_{n-1} + \frac{1}{n}\,(x_n - \bar x_{n-1}),
$$ {#eq-incremental-mean}
as one checks by multiplying out: $n\bar x_n = (n - 1)\bar x_{n-1} + x_n$. The general form "estimate $\gets$ estimate $+ \alpha\,(\text{target} - \text{estimate})$" with a **step size** (learning rate) $\alpha$ is the update rule of everything that follows. With $\alpha = 1/n$ it computes exact sample means; with a constant $\alpha$ it computes an exponentially weighted average that forgets old data, useful when the environment changes, but its estimates never stop fluctuating.

::: definition Temporal-difference learning, TD(0) {#def-td}
After each transition $s \to s'$ with reward $r$, under the policy $\pi$ being evaluated, **TD(0)** updates
$$
U(s) \gets U(s) + \alpha\,\bigl(r + \gamma\,U(s') - U(s)\bigr).
$$ {#eq-td}
The quantity $\delta = r + \gamma U(s') - U(s)$ is the **temporal-difference error**, and $r + \gamma U(s')$ is the **TD target**. (For a terminal $s'$, $U(s')$ is its fixed terminal value.)
:::

TD learning **bootstraps**: it uses its own estimate $U(s')$ in the target. That introduces bias while the estimates are wrong, but the target depends on one random transition instead of a whole episode, so its variance is much lower, and the agent learns during the episode. Why is it the right target?

::: proposition The fixed point of TD is the value of the policy {#prop-td-fixed-point}
For a fixed policy $\pi$, the expected TD error in state $s$,
$$
\E[\delta \mid s] = \sum_{s'} P(s' \mid s, \pi(s))\,\bigl[R(s, \pi(s), s') + \gamma U(s')\bigr] - U(s) = (B^\pi U)(s) - U(s),
$$
vanishes in every state if and only if $U = U^\pi$. So the expected TD update is a step of size $\alpha$ from $U$ towards $B^\pi U$, and $U^\pi$ is its unique equilibrium.
:::

::: proof
The first equality is the definition of expectation over the next state. $B^\pi U = U$ holds if and only if $U = U^\pi$, because $B^\pi$ is a $\gamma$-contraction with unique fixed point $U^\pi$ ([[artificial-intelligence/decision-making#thm-contraction]], applied to the policy's operator). The expected update $U(s) + \alpha\,((B^\pi U)(s) - U(s))$ is therefore zero-change exactly at $U^\pi$.
:::

The stochastic version converges too, under conditions on the step sizes that recur throughout RL.

::: theorem Convergence of TD(0) (stated without proof) {#thm-td}
For a finite MDP and a fixed policy, if every state is visited infinitely often and the step sizes $\alpha_n(s)$ used for the $n$th update of state $s$ satisfy the **Robbins–Monro conditions**
$$
\sum_n \alpha_n(s) = \infty, \qquad \sum_n \alpha_n(s)^2 < \infty,
$$ {#eq-robbins-monro}
then TD(0) converges to $U^\pi$ with probability $1$ (Sutton, 1988; Dayan, 1992; Jaakkola, Jordan and Singh, 1994).
:::

The first condition makes the steps large enough to overcome any initial error; the second makes them small enough to average out the noise. $\alpha_n = 1/n$ satisfies both; a constant $\alpha$ violates the second, so the estimates converge only to a neighbourhood of $U^\pi$ whose size shrinks with $\alpha$.

::: example TD(0) on the grid world {#ex-td}
Evaluate the optimal policy of the grid world of [[artificial-intelligence/decision-making#ex-grid]] by TD(0) with $\alpha = 0.05$, from episodes that start in the bottom-left corner, and compare with the exact values.
::: solution
The agent interacts with a simulator that returns only a sampled next state and the reward:

```python
import random
from mdp import states, terminal, transitions, MOVES, STEP, GAMMA, value_iteration, greedy

def sample_step(s, a, rng):
    """The environment: the agent sees only the sampled next state and reward, not the model."""
    r, acc = rng.random(), 0.0
    for p, t in transitions(s, a):
        acc += p
        if r < acc: return t, STEP
    return t, STEP

def td0(pi, episodes, alpha, rng, start=(2, 0)):
    """TD(0) evaluation of a fixed policy pi from sampled episodes."""
    U = {s: (terminal[s] if s in terminal else 0.0) for s in states}
    for _ in range(episodes):
        s = start
        while s not in terminal:
            t, r = sample_step(s, pi[s], rng)
            U[s] += alpha * (r + GAMMA * U[t] - U[s])     # move towards the one-step target
            s = t
    return U
```

Information flows backwards from the goal one step per visit: after $10$ episodes the start state still has a value near its initial $0$ minus step costs, and only after hundreds of episodes has the goal's reward propagated to it. With a constant step size the estimates then fluctuate around the true values without settling — the error stays near $0.02$ at the start state and near $0.08$ in the worst state between $1000$ and $10{,}000$ episodes — exactly as the Robbins–Monro conditions predict. States that the optimal policy rarely visits from this start, such as $(2, 3)$, are estimated worst.

## Learning to act: Q-learning

Prediction is not enough: we want the optimal policy, and without a model a value function $U$ does not tell us which action to take — choosing $\arg\max_a \sum_{s'} P(s' \mid s, a)[\dots]$ requires $P$. The remedy is to learn **action values** $Q(s, a)$ directly; then the greedy action is $\arg\max_a Q(s, a)$, no model needed. The optimal action values satisfy the Bellman optimality equation for $Q$:
$$
Q^*(s, a) = \sum_{s'} P(s' \mid s, a)\,\Bigl[R(s, a, s') + \gamma \max_{a'} Q^*(s', a')\Bigr].
$$ {#eq-bellman-q}

::: algorithm Q-learning {#alg-q-learning}
Initialise $Q(s, a)$ arbitrarily (for terminal states, $\max_{a'} Q(s', a')$ is replaced by the terminal value). For each step of each episode:
1. In state $s$, choose an action $a$ by an exploration policy derived from $Q$ (for example $\varepsilon$-greedy: a uniformly random action with probability $\varepsilon$, otherwise $\arg\max_a Q(s, a)$).
2. Do $a$; observe the reward $r$ and the next state $s'$.
3. Update
$$
Q(s, a) \gets Q(s, a) + \alpha\,\Bigl(r + \gamma \max_{a'} Q(s', a') - Q(s, a)\Bigr),
$$ {#eq-q-update}
and set $s \gets s'$.
:::

The update uses the maximum over next actions, whatever action the agent actually takes next: Q-learning is **off-policy** — it learns the values of the greedy (optimal) policy while following a different, exploratory one. Its expected update moves $Q$ towards $\mathcal{B}Q$, where
$$
(\mathcal{B}Q)(s, a) = \sum_{s'} P(s' \mid s, a)\Bigl[R(s, a, s') + \gamma \max_{a'} Q(s', a')\Bigr]
$$
is the Bellman optimality operator on Q-functions.

::: lemma The Q-Bellman operator is a contraction {#lem-q-contraction}
For Q-functions $Q_1$, $Q_2$, $\max_{s, a} \lvert (\mathcal{B}Q_1)(s, a) - (\mathcal{B}Q_2)(s, a)\rvert \le \gamma \max_{s, a} \lvert Q_1(s, a) - Q_2(s, a)\rvert$. Hence $Q^*$ is its unique fixed point.
:::

::: proof
For each $(s, a)$, the rewards cancel and
$$
\lvert (\mathcal{B}Q_1)(s, a) - (\mathcal{B}Q_2)(s, a)\rvert \le \gamma \sum_{s'} P(s' \mid s, a)\, \bigl\lvert \max_{a'} Q_1(s', a') - \max_{a'} Q_2(s', a')\bigr\rvert \le \gamma \max_{s', a'} \lvert Q_1(s', a') - Q_2(s', a')\rvert,
$$
using $\lvert \max f - \max g\rvert \le \max \lvert f - g\rvert$ as in [[artificial-intelligence/decision-making#thm-contraction]] and $\sum_{s'} P = 1$. Uniqueness of the fixed point follows as there, and [[#eq-bellman-q]] says that $Q^*$ is a fixed point.
:::

::: theorem Convergence of Q-learning (stated) {#thm-q-learning}
*(Watkins, 1989; Watkins and Dayan, 1992.)* In a finite MDP, if every state–action pair is updated infinitely often and the step sizes satisfy the Robbins–Monro conditions [[#eq-robbins-monro]] for each pair, then tabular Q-learning converges to $Q^*$ with probability $1$, whatever exploration policy generates the experience.
:::

The proof treats [[#eq-q-update]] as a stochastic approximation of the fixed-point iteration $Q \gets \mathcal{B}Q$: the update equals the expected update plus zero-mean noise with bounded variance, the contraction of [[#lem-q-contraction]] pulls the expected iteration towards $Q^*$, and the step-size conditions make the noise average out. Note what the theorem does *not* say: it gives no rate, and it requires every pair to be tried infinitely often — the exploration policy must never stop exploring entirely. A policy that is **greedy in the limit with infinite exploration** (GLIE) — for example $\varepsilon$-greedy with $\varepsilon_t \to 0$ slowly, such as $\varepsilon_t = 1/t$ per state — both satisfies the condition and converges to acting optimally.

::: example Q-learning on the grid world {#ex-q-learning}
Run Q-learning on the grid world with $\varepsilon = 0.1$ and step size $1/N(s, a)$ (the number of updates of that pair so far), and compare its greedy policy with the optimal one.
::: solution
```python
def q_learning(episodes, rng, eps=0.1, start=(2, 0)):
    """Tabular Q-learning with epsilon-greedy exploration and step size 1/N(s, a)."""
    Q = {(s, a): 0.0 for s in states if s not in terminal for a in MOVES}
    N = {k: 0 for k in Q}
    value = lambda t: terminal[t] if t in terminal else max(Q[(t, b)] for b in MOVES)
    for _ in range(episodes):
        s = start
        while s not in terminal:
            if rng.random() < eps: a = rng.choice(list(MOVES))
            else: a = max(MOVES, key=lambda b: Q[(s, b)])
            t, r = sample_step(s, a, rng)
            N[(s, a)] += 1
            Q[(s, a)] += (r + GAMMA * value(t) - Q[(s, a)]) / N[(s, a)]   # off-policy target: max
            s = t
    return Q
```

Q-learning,   1000 episodes: max_a Q(start) = 0.099, greedy policy differs from optimal in 1 states [(2, 0)]
Q-learning,  10000 episodes: max_a Q(start) = 0.258, greedy policy differs from optimal in 0 states []

After $10{,}000$ episodes the greedy policy is optimal in every state, although the value of the start ($0.258$) is still well below the true $0.296$; after $100{,}000$ it is $0.285$. Two lessons. The *policy* is learned long before the *values* — only the ranking of actions matters (compare the exercise on greedy policies in [[artificial-intelligence/decision-making]]). And $\alpha = 1/N$, although it satisfies the convergence conditions, is slow when $\gamma$ is close to $1$: early targets are built from bad estimates, and averaging them with weight $1/N$ forgets them only slowly. Practical implementations use larger, slowly decaying step sizes.
:::
:::

A close relative, **SARSA** (state–action–reward–state–action), replaces $\max_{a'} Q(s', a')$ by $Q(s', a')$ for the action $a'$ the agent actually takes next. It is **on-policy**: it learns the value of the exploratory policy it follows, which makes a difference where exploration is dangerous. Next to a cliff, Q-learning learns the optimal edge-hugging path and then falls off occasionally because of its $\varepsilon$-random moves; SARSA learns that, given that it explores, a path further from the edge is better.

::: quiz
An agent runs Q-learning while following a policy that chooses actions uniformly at random, forever. Assuming suitable step sizes, what does it learn?

- [x] $Q^*$, the optimal action values.
- [ ] The action values of the uniformly random policy.
- [ ] Nothing useful, because it never exploits what it learns.
- [ ] $Q^*$ only if it switches to the greedy policy eventually.
::: solution
Q-learning is off-policy: its target $r + \gamma \max_{a'} Q(s', a')$ evaluates the greedy policy, regardless of the actions actually taken. A uniformly random behaviour policy visits every state–action pair infinitely often (in a finite MDP where all states are reachable), so by [[#thm-q-learning]] $Q$ converges to $Q^*$. The agent's *reward* during learning is poor, of course — learning well and earning well are different goals. SARSA under the same behaviour would learn the values of the random policy.
:::
:::

## Exploration and bandits

How should an agent trade exploration against exploitation? The question is clearest without states: a **$k$-armed bandit** has $k$ actions (arms); pulling arm $i$ gives a random reward with unknown mean $\mu_i$. The agent wants to maximise its total reward over $T$ pulls, or equivalently to minimise its **regret**
$$
\mathrm{Regret}(T) = T\mu^* - \E\Bigl[\sum_{t=1}^T \mu_{a_t}\Bigr] = \sum_i \Delta_i\, \E[N_i(T)],
$$ {#eq-regret}
where $\mu^* = \max_i \mu_i$, $\Delta_i = \mu^* - \mu_i$ is the **gap** of arm $i$ and $N_i(T)$ the number of times it is pulled.

- **Greedy** play — always pull the arm with the best average so far — can lock onto a suboptimal arm after an unlucky start and never try the best arm again: linear regret.
- **$\varepsilon$-greedy** with fixed $\varepsilon$ pulls every arm a constant fraction $\varepsilon/k$ of the time for ever: also linear regret, $\approx \varepsilon\,T\,\bar\Delta$ for the average gap $\bar\Delta$ — but with a small constant.
- **UCB1** ([[artificial-intelligence/adversarial-search#eq-ucb1]]) pulls the arm with the highest upper confidence bound $\bar x_i + \sqrt{2\ln t/N_i}$. By [[artificial-intelligence/adversarial-search#thm-uct]] each suboptimal arm is pulled $O(\ln T/\Delta_i^2)$ times, so its regret is $O(\sum_i \ln T/\Delta_i)$: logarithmic. Lai and Robbins (1985) showed that no algorithm can do better than logarithmic regret on all bandit problems, so UCB1 is optimal up to constant factors.

"Optimism in the face of uncertainty" — act as if the world were as good as is plausible — is the principle behind UCB. It works because optimism is self-correcting: if an optimistic estimate is wrong, trying the action reveals it. **Thompson sampling** (1933) instead pulls each arm with the posterior probability that it is the best — sample a mean for each arm from its posterior and pull the arm with the largest sample — and achieves similar guarantees.

::: example Regret of three bandit strategies {#ex-bandit}
Compare greedy, $\varepsilon$-greedy ($\varepsilon = 0.1$) and UCB1 on a Bernoulli bandit with means $0.2, 0.4, 0.5, 0.6, 0.7$, averaging the regret over $20$ runs for horizons $T = 10^2, \dots, 10^5$.
::: solution
```python
import math, random

def run(policy, means, T, rng):
    """Play a Bernoulli bandit for T steps; return the regret against always playing the best arm."""
    k = len(means); n = [0] * k; w = [0.0] * k; total = 0.0
    for t in range(1, T + 1):
        if t <= k: a = t - 1                                   # play each arm once
        elif policy == "greedy": a = max(range(k), key=lambda i: w[i] / n[i])
        elif policy == "eps": a = rng.randrange(k) if rng.random() < 0.1 else max(range(k), key=lambda i: w[i] / n[i])
        else: a = max(range(k), key=lambda i: w[i] / n[i] + math.sqrt(2 * math.log(t) / n[i]))   # UCB1
        r = 1.0 if rng.random() < means[a] else 0.0
        n[a] += 1; w[a] += r; total += means[a]
    return T * max(means) - total                              # expected regret of the choices made
```

T =  1000: regret  greedy   101.6   eps-greedy    43.6   UCB1    80.9

Greedy's regret grows tenfold with each tenfold increase of $T$: in some runs it locked onto a worse arm for good. $\varepsilon$-greedy's regret also grows linearly in the long run, at about $0.1 \cdot 0.24 = 0.024$ per step (the average gap of a random arm is $0.24$), so $2241$ at $T = 10^5$. UCB1 explores more at first — it is the worst of the three at $T = 100$ — but its regret grows only logarithmically: from $10^4$ to $10^5$ it increases by less than a factor of two, and at $10^5$ it is a sixth of $\varepsilon$-greedy's. Which method is "best" depends on the horizon, which is why asymptotic regret is only part of the story.

In MDPs, exploration is harder: an action's value depends on reaching other states, and a short-sighted exploration rule may never reach a distant part of the state space. Count-based **exploration bonuses** (add $c/\sqrt{N(s, a)}$ to rewards), optimistic initial values, and posterior sampling extend the bandit ideas, and algorithms such as R-max and UCRL come with polynomial sample-complexity or regret bounds for finite MDPs.

::: warning The reward is the specification
An RL agent optimises the reward it is given, not the designer's intention. Rewards that are easy to measure are often poor proxies: an agent rewarded for points in a boat-racing game may learn to circle for ever collecting bonuses instead of finishing the race; a cleaning robot rewarded for not seeing dirt may learn to cover its camera. This **reward hacking** or **specification gaming** is not a bug in the learning algorithm — the algorithm is doing exactly its job — but in the reward, which plays the role of the performance measure of [[artificial-intelligence/intelligent-agents#def-rational]]. Shaping rewards to speed up learning is also risky: adding arbitrary intermediate rewards can change the optimal policy. Shaping of the **potential-based** form $F(s, s') = \gamma\Phi(s') - \Phi(s)$ is safe: it provably leaves the optimal policies unchanged (Ng, Harada and Russell, 1999).
:::

## Large state spaces

Tables of values are impossible for backgammon ($10^{20}$ states), Go or a robot with continuous joint angles. The agent must **generalise**: represent $U$ or $Q$ by a parameterised function $\hat U_{\mathbf{w}}(s)$ — a linear combination of features $\hat U_{\mathbf w}(s) = \mathbf w \cdot \boldsymbol\phi(s)$, or a neural network — and learn the parameters.

For prediction, the natural objective is the mean squared error between $\hat U_{\mathbf w}$ and the targets. **Semi-gradient TD(0)** takes a gradient step on the squared TD error while treating the target as fixed:
$$
\mathbf w \gets \mathbf w + \alpha\,\bigl(r + \gamma\,\hat U_{\mathbf w}(s') - \hat U_{\mathbf w}(s)\bigr)\, \nabla_{\mathbf w} \hat U_{\mathbf w}(s),
$$ {#eq-semi-gradient}
which for linear features is $\mathbf w \gets \mathbf w + \alpha\,\delta\,\boldsymbol\phi(s)$. With linear features, on-policy sampling and Robbins–Monro step sizes, this converges (Tsitsiklis and Van Roy, 1997) — not to the best approximation of $U^\pi$, but to a nearby fixed point whose error is within a factor $1/(1 - \gamma)$ of the best achievable in the worst case. Q-learning with function approximation updates $\mathbf w$ in the same way with the target $r + \gamma\max_{a'}\hat Q_{\mathbf w}(s', a')$.

Raise the learning rate: beyond $\alpha = 1/8$ the steep direction overshoots and the iterates diverge — the same instability that makes step sizes and feature scaling critical in TD learning, where the targets also move as the weights change.

The guarantees end quickly. The combination of **function approximation**, **bootstrapping** and **off-policy** learning — the "deadly triad" — can make the weights diverge to infinity even on tiny problems with exact linear representations available (Baird's counterexample, 1995). Deep RL systems therefore add stabilising devices: **experience replay** (learn from a buffer of past transitions, breaking correlations), **target networks** (compute targets with a slowly updated copy of the weights), and careful normalisation. With these, deep Q-networks learned to play dozens of Atari video games from screen pixels (Mnih and colleagues, 2015) — an empirical success, not a theorem.

### Policy gradient methods

Instead of learning values and acting greedily, an agent can adjust a **parameterised policy** $\pi_{\boldsymbol\theta}(a \mid s)$ directly to increase its expected return $J(\boldsymbol\theta)$. This works for continuous actions and stochastic policies, where $\arg\max_a Q$ is awkward. The key fact is that the gradient of an expectation can be estimated from samples.

::: theorem The likelihood-ratio (REINFORCE) gradient {#thm-policy-gradient}
For a one-step problem in which the agent draws $a \sim \pi_{\boldsymbol\theta}(\cdot)$ and receives reward with mean $r(a)$, $J(\boldsymbol\theta) = \sum_a \pi_{\boldsymbol\theta}(a)\, r(a)$ satisfies
$$
\nabla_{\boldsymbol\theta} J = \E_{a \sim \pi_{\boldsymbol\theta}}\bigl[r(a)\, \nabla_{\boldsymbol\theta} \ln \pi_{\boldsymbol\theta}(a)\bigr],
$$
and for any constant $b$ (a **baseline**) also $\nabla J = \E[(r(a) - b)\,\nabla \ln \pi_{\boldsymbol\theta}(a)]$. For episodes in an MDP, the same holds with $r(a)$ replaced by the return following each action and the sum taken over the time steps of the episode (Williams, 1992; Sutton and colleagues, 2000).
:::

::: proof
(One-step case.) $\nabla J = \sum_a r(a)\, \nabla \pi_{\boldsymbol\theta}(a) = \sum_a \pi_{\boldsymbol\theta}(a)\, r(a)\, \frac{\nabla \pi_{\boldsymbol\theta}(a)}{\pi_{\boldsymbol\theta}(a)} = \E[r(a)\, \nabla \ln \pi_{\boldsymbol\theta}(a)]$, assuming $\pi_{\boldsymbol\theta}(a) > 0$ wherever $r(a) \ne 0$. For the baseline, $\E[b\, \nabla \ln \pi_{\boldsymbol\theta}(a)] = b \sum_a \nabla \pi_{\boldsymbol\theta}(a) = b\, \nabla \sum_a \pi_{\boldsymbol\theta}(a) = b\, \nabla 1 = 0$. (The multi-step case is proved similarly, using the Markov property to show that actions do not affect rewards received before them.)
:::

::: example A policy gradient by hand {#ex-policy-gradient}
A one-step problem has two actions: $a_1$ gives reward $1$ and $a_2$ reward $0$. The policy is a softmax with one parameter, $\pi_\theta(a_1) = \sigma(\theta) = e^\theta/(e^\theta + 1)$, $\pi_\theta(a_2) = 1 - \sigma(\theta)$, and currently $\theta = 0$. Compute $\nabla J$ directly and by [[#thm-policy-gradient]], and compare the variance of the single-sample estimates with baseline $b = 0$ and with $b = 0.5$.
::: solution
Directly, $J(\theta) = \sigma(\theta)$ and $J'(0) = \sigma(0)(1 - \sigma(0)) = 0.25$. For the likelihood-ratio form, $\frac{d}{d\theta}\ln\sigma(\theta) = 1 - \sigma(\theta) = 0.5$ and $\frac{d}{d\theta}\ln(1 - \sigma(\theta)) = -\sigma(\theta) = -0.5$ at $\theta = 0$. Each action has probability $0.5$.

*Baseline $0$.* The single-sample estimate is $r\,\nabla\ln\pi$: $1 \cdot 0.5 = 0.5$ if $a_1$ is drawn, $0 \cdot (-0.5) = 0$ if $a_2$ is. Its mean is $0.25$, which is correct, and its variance is $0.5 \cdot 0.25^2 + 0.5 \cdot 0.25^2 = 0.0625$.

*Baseline $0.5$.* The estimate is $(r - 0.5)\nabla\ln\pi$: $0.5 \cdot 0.5 = 0.25$ for $a_1$ and $(-0.5)(-0.5) = 0.25$ for $a_2$. The mean is again $0.25$, and the variance is $0$: every sample gives the exact gradient. A good action pushes its own probability up, and a bad one pushes its own probability down, which here amounts to the same step. The baseline equal to the average reward is not always this perfect, but it is the usual choice.
:::
:::

So the agent can sample an action, observe its reward, and step $\boldsymbol\theta$ in the direction $(r - b)\nabla\ln\pi_{\boldsymbol\theta}(a)$: actions that did better than the baseline become more likely. A good baseline — such as a learned value estimate, giving **actor–critic** methods — does not change the expected gradient but can reduce its variance enormously. Policy-gradient methods, including trust-region and clipped variants such as PPO (2017), are the basis of much of modern deep RL — and of the reinforcement learning from human feedback used to fine-tune language models, taught in the LLM Atlas ([RL for language models](/learn/llm/lesson.php?c=post-training&l=rl-for-language-models), [RLHF](/learn/llm/lesson.php?c=post-training&l=rlhf)).

::: quiz
Why does subtracting a baseline $b$ from the reward in the REINFORCE update not bias the gradient estimate?

- [ ] Because the baseline is learned from data.
- [x] Because $\E[\nabla \ln \pi_{\boldsymbol\theta}(a)] = 0$: the gradients of the probabilities of all actions sum to zero.
- [ ] Because rewards are always positive.
- [ ] It does bias it, but the bias vanishes as $\boldsymbol\theta$ converges.
::: solution
$\E[b\,\nabla\ln\pi_{\boldsymbol\theta}(a)] = b\sum_a\nabla\pi_{\boldsymbol\theta}(a) = b\,\nabla\sum_a\pi_{\boldsymbol\theta}(a) = 0$, as in the proof of [[#thm-policy-gradient]]: probabilities sum to $1$ for every $\boldsymbol\theta$, so their gradients sum to $0$. The baseline may depend on the state (but not on the action) without introducing bias; it changes only the variance.
:::
:::

::: history
Arthur Samuel's draughts program (1959) adjusted its evaluation function towards the values of later positions — an early temporal-difference method. Richard Bellman's *Dynamic Programming* (1957) and Ronald Howard's policy iteration (1960) supplied the theory of MDPs. William Thompson proposed posterior sampling for bandits in 1933, Herbert Robbins and Sutton Monro introduced stochastic approximation in 1951, and Tze Leung Lai and Robbins proved the logarithmic regret lower bound in 1985. Andrew Barto, Richard Sutton and Charles Anderson's actor–critic architecture appeared in 1983, and Sutton's "Learning to predict by the methods of temporal differences" (1988) formalised TD learning. Christopher Watkins introduced Q-learning in his 1989 Cambridge PhD thesis, with a convergence proof published with Peter Dayan in 1992; Ronald Williams's REINFORCE also appeared in 1992. Gerald Tesauro's TD-Gammon (1992–95) learned to play backgammon at a world-class level by self-play with TD learning and a neural network. Peter Auer, Nicolò Cesa-Bianchi and Paul Fischer analysed UCB1 in 2002. Volodymyr Mnih and colleagues' deep Q-network (*Nature*, 2015) learned Atari games from pixels, and DeepMind's AlphaGo (2016) and AlphaZero (2017–18) combined policy and value networks trained by RL with Monte Carlo tree search. Sutton and Barto's *Reinforcement Learning: An Introduction* (second edition 2018) is the standard text.
:::

## In practice

As of 2026, reinforcement learning is used in game playing, robotics (often with policies trained in simulation and transferred to hardware), resource management and recommendation, and — prominently — in the post-training of large language models, where rewards come from learned models of human preferences or from automatic verifiers of answers. These applications are empirical and change quickly; the LLM Atlas covers them. The classical results of this chapter remain the foundation: Bellman equations define what is being estimated, contraction and stochastic approximation explain when the estimates converge, and regret bounds quantify the cost of exploration. Where the theory gives no guarantee — deep function approximation, off-policy learning, sparse rewards — RL systems are notoriously sensitive to hyperparameters and random seeds, and results should be reported over many seeds.

## Where this leads

This chapter closes the course's arc from search to learning. RL agents that plan with a learned model combine it with [[artificial-intelligence/search]] and [[artificial-intelligence/adversarial-search]] (as AlphaZero combines MCTS with learned networks); partially observable RL needs the belief states of [[artificial-intelligence/probabilistic-reasoning]]. Supervised learning, neural networks and their optimisation — the function approximators of deep RL — are taught in the LLM Atlas, starting from [neural networks](/learn/llm/course.php?c=neural-networks), and the use of RL to train and align language models in its [post-training](/learn/llm/course.php?c=post-training) course.

::: summary
- RL learns to act from rewards without a model. **Monte Carlo** averages complete returns; **TD(0)** ([[#def-td]]) updates towards $r + \gamma U(s')$, whose expected update has $U^\pi$ as its unique fixed point ([[#prop-td-fixed-point]]); with Robbins–Monro step sizes it converges ([[#thm-td]]).
- **Q-learning** ([[#alg-q-learning]]) learns optimal action values off-policy; its expected update is the Q-Bellman operator, a $\gamma$-contraction ([[#lem-q-contraction]]), and it converges if every pair is tried infinitely often with suitable step sizes ([[#thm-q-learning]]). SARSA is its on-policy counterpart.
- Exploration matters: greedy and fixed-$\varepsilon$ strategies have linear **regret**; **UCB1** achieves logarithmic regret, optimal up to constants ([[#ex-bandit]]).
- The reward is the specification; agents exploit poorly designed rewards.
- **Function approximation** generalises across states; semi-gradient TD with linear features converges on-policy, but function approximation, bootstrapping and off-policy learning together can diverge. **Policy gradients** follow $\E[(r - b)\nabla\ln\pi]$ ([[#thm-policy-gradient]]), the basis of actor–critic methods and of RL for language models.
:::

## Exercises

::: exercise A TD update {level=1 check="0.532"}
With $\alpha = 0.1$ and $\gamma = 0.9$, the current estimates are $U(s) = 0.5$ and $U(s') = 0.8$. The agent moves from $s$ to $s'$ and receives reward $r = 0.1$. What is the new $U(s)$? (Enter the value.)
::: solution
The TD error is $\delta = 0.1 + 0.9 \cdot 0.8 - 0.5 = 0.1 + 0.72 - 0.5 = 0.32$, so $U(s) \gets 0.5 + 0.1 \cdot 0.32 = 0.532$.
:::
:::

::: exercise A Q-learning update {level=1 check="1.4"}
With $\alpha = 0.5$ and $\gamma = 0.9$, $Q(s, a) = 1$, and in $s'$ the Q-values are $Q(s', a_1) = 2$ and $Q(s', a_2) = 0$. The agent takes $a$ in $s$, receives $r = 0$, lands in $s'$, and then (exploring) takes $a_2$. What is the new $Q(s, a)$ under Q-learning? (Enter the value.)
::: solution
Q-learning uses the maximum in $s'$, whatever action follows: target $0 + 0.9 \cdot 2 = 1.8$, so $Q(s, a) \gets 1 + 0.5\,(1.8 - 1) = 1.4$. SARSA would use $Q(s', a_2) = 0$: target $0$, giving $1 + 0.5(0 - 1) = 0.5$.
:::
:::

::: exercise Step sizes {level=1}
Which of the following step-size sequences satisfy the Robbins–Monro conditions [[#eq-robbins-monro]]: (a) $\alpha_n = 1/n$; (b) $\alpha_n = 1/n^2$; (c) $\alpha_n = 1/\sqrt n$; (d) $\alpha_n = 0.01$; (e) $\alpha_n = 1/(n \ln(n + 1))$?
::: solution
(a) Yes: $\sum 1/n = \infty$, $\sum 1/n^2 < \infty$. (b) No: $\sum 1/n^2 < \infty$, the steps shrink too fast and the estimates may stop short of the target. (c) No: $\sum 1/n = \infty$ for the squares, so the noise is never averaged out (though such steps are often used in practice, with averaging). (d) No: constant steps fail the second condition. (e) Yes: $\sum 1/(n\ln(n+1)) = \infty$ (compare $\int dx/(x\ln x) = \ln\ln x$), and $\sum 1/(n\ln(n+1))^2 < \infty$.
:::
:::

::: exercise Monte Carlo versus TD {level=2 check="0.75"}
An undiscounted episodic task has states $A$ and $B$. Eight episodes are observed: one is $A, 0, B, 0$ (from $A$ to $B$ with reward $0$, then from $B$ to termination with reward $0$); six are $B, 1$ (from $B$ to termination with reward $1$); one is $B, 0$. (a) What does Monte Carlo estimate for $U(A)$ and $U(B)$? (b) What do TD methods converge to on this fixed batch of data (batch TD, equivalently the value of the maximum-likelihood model)? (Enter the batch-TD estimate of $U(A)$.)
::: solution
(a) Monte Carlo averages the observed returns from each state. $B$ was visited eight times with returns $0$ (in the first episode), $1$ six times and $0$ once: $U(B) = 6/8 = 0.75$. $A$ was visited once with return $0$: $U(A) = 0$. (b) The maximum-likelihood model says that $A$ always goes to $B$ with reward $0$, and $B$ terminates with reward $1$ with probability $6/8$. Its values are $U(B) = 0.75$ and $U(A) = 0 + U(B) = 0.75$. Batch TD converges to these, because its fixed point is the solution of the Bellman equations of the estimated model. Which is better? Monte Carlo minimises the error on the observed data; TD exploits the Markov structure and generalises better if the process is really Markov — the estimate $0.75$ for $A$ is more plausible than $0$ from a single episode.
:::
:::

::: exercise Incremental means {level=2}
(a) Prove [[#eq-incremental-mean]]. (b) Show that with a constant step size $\alpha$, the estimate after $n$ updates is $(1 - \alpha)^n x_0 + \sum_{i=1}^n \alpha(1 - \alpha)^{n-i} x_i$ — an exponentially weighted average — and that the weights sum to $1$.
::: solution
(a) $\bar x_n = \frac1n\sum_{i \le n} x_i = \frac1n\bigl((n - 1)\bar x_{n-1} + x_n\bigr) = \bar x_{n-1} + \frac1n(x_n - \bar x_{n-1})$. (b) The update $v_n = v_{n-1} + \alpha(x_n - v_{n-1}) = (1 - \alpha)v_{n-1} + \alpha x_n$ unrolls by induction to $v_n = (1 - \alpha)^n v_0 + \sum_{i=1}^n \alpha(1 - \alpha)^{n-i} x_i$ with $v_0 = x_0$. The weights sum to $(1 - \alpha)^n + \alpha\sum_{j=0}^{n-1}(1 - \alpha)^j = (1 - \alpha)^n + \alpha \cdot \frac{1 - (1 - \alpha)^n}{\alpha} = 1$. Recent data get weight $\alpha$, data $j$ steps old get $\alpha(1-\alpha)^j$: the estimate tracks a changing target but keeps a variance of order $\alpha$ for a stationary one.
:::
:::

::: exercise Greedy can fail forever {level=2}
A two-armed Bernoulli bandit has means $\mu_1 = 0.6$ and $\mu_2 = 0.5$. The greedy strategy pulls each arm once and then always pulls the arm with the higher average (ties to arm 2). Show that with probability at least $0.4 \cdot 0.5 = 0.2$ it never pulls arm 1 again, and deduce that its regret is linear in $T$.
::: solution
With probability $0.4$ the first pull of arm 1 gives $0$, and with probability $0.5$ the pull of arm 2 gives $1$; independently, both happen with probability $0.2$. Then arm 1's average is $0$ and arm 2's is $1$. Arm 2's average, a running average of rewards in $[0, 1]$, always stays $\ge 0$, while arm 1's stays $0$ because it is never pulled again; with ties going to arm 2, greedy pulls arm 2 for ever. So $\E[N_1(T)] \le 1 + 0.8\,(T - 2)$, and the regret is at least $0.2 \cdot 0.1 \cdot (T - 2)$, linear in $T$. Optimistic initial values or any exploration with non-vanishing total probability fix this.
:::
:::

::: exercise Implement SARSA {level=3}
Implement SARSA for the grid world with $\varepsilon = 0.1$ and the same step sizes as [[#ex-q-learning]], and compare the value of the start state it learns with Q-learning's after $100{,}000$ episodes. Explain any difference in terms of on-policy and off-policy learning.
::: solution
```python
def sarsa(episodes, rng, eps=0.1, start=(2, 0)):
    Q = {(s, a): 0.0 for s in states if s not in terminal for a in MOVES}; N = {k: 0 for k in Q}
    choose = lambda s: rng.choice(list(MOVES)) if rng.random() < eps else max(MOVES, key=lambda b: Q[(s, b)])
    for _ in range(episodes):
        s = start; a = choose(s)
        while s not in terminal:
            t, r = sample_step(s, a, rng)
            if t in terminal: target, b = r + GAMMA * terminal[t], None
            else: b = choose(t); target = r + GAMMA * Q[(t, b)]     # on-policy: the action taken next
            N[(s, a)] += 1; Q[(s, a)] += (target - Q[(s, a)]) / N[(s, a)]
            s, a = t, b
    return Q

Q = sarsa(100_000, random.Random(1989))
print(round(max(Q[((2, 0), b)] for b in MOVES), 3))
```

```console
$ python3 sarsa.py
0.206
```

SARSA's estimate ($0.206$) is lower than Q-learning's ($0.285$) and than the optimal value ($0.296$), and it stays lower in the limit: SARSA estimates the value of the $\varepsilon$-greedy policy it actually follows, which wastes about one move in ten on a random action and occasionally stumbles into the stairwell. Q-learning estimates the value of the greedy policy, which it does not follow. If the agent will keep exploring while it works, SARSA's estimate is the honest one; if exploration stops after learning, Q-learning's is.
:::
:::

::: exercise Thompson sampling {level=3}
Implement Thompson sampling for the Bernoulli bandit of [[#ex-bandit]] with independent $\mathrm{Beta}(1, 1)$ priors (sample $\theta_i \sim \mathrm{Beta}(1 + \text{successes}_i, 1 + \text{failures}_i)$ for each arm and pull the arm with the largest sample), and compare its regret at $T = 10^4$ with UCB1's. Python's `random.betavariate` draws from a beta distribution.
::: solution
```python
def thompson(means, T, rng):
    k = len(means); s = [0] * k; f = [0] * k; total = 0.0
    for t in range(T):
        a = max(range(k), key=lambda i: rng.betavariate(1 + s[i], 1 + f[i]))
        if rng.random() < means[a]: s[a] += 1
        else: f[a] += 1
        total += means[a]
    return T * max(means) - total

rng = random.Random(1933)
print(round(sum(thompson([0.2, 0.4, 0.5, 0.6, 0.7], 10_000, rng) for _ in range(20)) / 20, 1))
```

```console
$ python3 thompson.py
39.1
```

Thompson sampling's average regret at $T = 10^4$ is about $39$, roughly a sixth of UCB1's $229$ in [[#ex-bandit]]. Both have logarithmic regret, but Thompson sampling's constant is smaller here: it explores an arm in proportion to the posterior probability that the arm is best, which falls quickly for clearly bad arms, whereas UCB1's bonus $\sqrt{2\ln t/N_i}$ is a conservative worst-case confidence width. (The prior also matters; with uniform priors on Bernoulli arms it is a natural choice.)
:::
