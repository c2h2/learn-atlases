Shor's algorithm factors in polynomial time; Grover's algorithm searches only quadratically faster, and no quantum algorithm can do better for unstructured search. Where, then, do quantum computers sit among the complexity classes of [[complexity]]? Can they solve $\mathsf{NP}$-complete problems? Can a classical computer simulate them with only polynomial slowdown, so that the whole subject is a constant-factor story? And what exactly did the experiments of 2019 onwards, which claimed "quantum supremacy", demonstrate? This chapter answers these questions as far as they are known — which, as with $\mathsf{P}$ versus $\mathsf{NP}$, is not very far without unproved assumptions, but far enough to correct the most common misconceptions.

We define $\mathsf{BQP}$, the class of problems solvable by polynomial-size quantum circuits with bounded error, by analogy with $\mathsf{BPP}$ ([[complexity/randomised-complexity]]), and show that the definition is robust. We prove $\mathsf{BPP}\subseteq\mathsf{BQP}\subseteq\mathsf{PSPACE}$, the second by a **path-sum** simulation that we also implement, and sketch the sharper $\mathsf{BQP}\subseteq\mathsf{PP}$. We then review the problems known to be in $\mathsf{BQP}$, the oracle results that separate it from $\mathsf{BPP}$ and from $\mathsf{NP}$, the class $\mathsf{QMA}$, and the complexity-theoretic case for **quantum advantage** in sampling experiments, with the classical simulations that have challenged them.

## The class BQP

As in [[complexity/randomised-complexity]], we use decision problems (languages $L\subseteq\{0,1\}^*$) and circuits generated by an efficient classical procedure.

::: definition BQP {#def-bqp}
A language $L$ is in $\mathsf{BQP}$ (bounded-error quantum polynomial time) if there is a classical deterministic algorithm that, given $1^n$, outputs in time polynomial in $n$ the description of a quantum circuit $C_n$ on $p(n)$ qubits, built from gates in the fixed set $\{H, T, \mathrm{CNOT}\}$, such that for every input $w$ of length $n$, running $C_n$ on $\ket{w}\ket{0^{p(n)-n}}$ and measuring the first qubit gives
$$
\Prob[1]\ge\tfrac23 \text{ if } w\in L, \qquad \Prob[1]\le\tfrac13 \text{ if } w\notin L .
$$
:::

The family is **uniform**: a single polynomial-time classical program describes all the circuits, so no hard-to-compute information can be hidden in them (with non-uniform families one could decide undecidable languages). Several variations give the same class, which is why $\mathsf{BQP}$ is the accepted model of efficient quantum computation.

::: theorem Robustness of BQP {#thm-bqp-robust}
$\mathsf{BQP}$ is unchanged if (a) $2/3$ and $1/3$ are replaced by $1 - 2^{-q(n)}$ and $2^{-q(n)}$, or by $\tfrac12 \pm 1/q(n)$, for any polynomial $q$; (b) the gate set is replaced by any finite approximately universal set whose gates have efficiently computable entries; (c) measurements in the middle of the circuit, with later gates classically controlled by their outcomes, are allowed; (d) quantum Turing machines (Bernstein–Vazirani, 1993) are used instead of circuits (Yao, 1993).
:::

::: proof
(a) Run $m$ copies of the circuit side by side on fresh ancillas, compute the majority of their output bits into a new qubit reversibly ([[quantum-computing/quantum-circuits#thm-oracle]]), and measure it. The $m$ output bits are independent, each correct with probability $\ge\tfrac12 + \varepsilon$, so by the Chernoff bound of [[complexity/randomised-complexity]] the majority is wrong with probability at most $e^{-\varepsilon^2 m/2}$; $m = O(q(n)/\varepsilon^2)$ copies give error $2^{-q(n)}$, polynomial if $1/\varepsilon$ is polynomial. (b) A circuit of $s$ gates from the new set can be approximated gate by gate within $\varepsilon/s$ by $O(\log^c(s/\varepsilon))$ gates from $\{H, T, \mathrm{CNOT}\}$ by the Solovay–Kitaev theorem ([[quantum-computing/quantum-circuits#thm-sk]]), and the errors add at most linearly ([[quantum-computing/quantum-circuits#lem-errors]]), so the output probabilities change by at most $2\varepsilon$; take $\varepsilon = 1/12$ and amplify by (a). Conversely, the new set approximates $\{H, T, \mathrm{CNOT}\}$ by universality. (c) is the principle of deferred measurement ([[quantum-computing/quantum-circuits#prop-deferred]]). (d) is Yao's theorem, which we do not prove.
:::

::: proposition P ⊆ BPP ⊆ BQP {#prop-bpp-bqp}
Every language in $\mathsf{BPP}$ is in $\mathsf{BQP}$.
:::

::: proof
A $\mathsf{BPP}$ algorithm is a deterministic polynomial-time computation $A(w, r)$ on the input and a string $r$ of $m$ random bits, which can be written as a uniform family of classical circuits of polynomial size. By [[quantum-computing/quantum-circuits#thm-oracle]] it becomes a reversible circuit $\ket w\ket r\ket0\mapsto\ket w\ket r\ket{A(w, r)}$ of Toffoli, CNOT and $X$ gates. Prepare $\ket r$ as $H^{\otimes m}\ket{0^m}$, the uniform superposition, and measure the output qubit. By the partial-measurement rule ([[quantum-computing/entanglement#eq-partial]]) the probability of output $1$ is $\sum_r 2^{-m}[A(w, r) = 1]$, exactly the acceptance probability of the randomised algorithm. Toffoli gates are compiled into $\{H, T, \mathrm{CNOT}\}$ exactly, with $T^\dagger = T^7$ ([[quantum-computing/quantum-circuits#ex-toffoli]]).
:::

::: example A randomised algorithm as a quantum circuit {#ex-coins}
A randomised test flips two fair coins $r_1, r_2$ and accepts if both are heads. Write it as a quantum circuit in the manner of [[#prop-bpp-bqp]] and check that it accepts with probability $1/4$. What changes if the coins are never measured?
::: solution
Use three qubits in $\ket{000}$. Apply $H$ to qubits $0$ and $1$ (the coins) and a Toffoli with controls $0, 1$ and target $2$ (the reversible AND), then measure qubit $2$. The state is $\tfrac12(\ket{000} + \ket{010} + \ket{100} + \ket{111})$, and qubit $2$ is $1$ with probability $\abs{1/2}^2 = 1/4$. The coin qubits are never measured, but that changes nothing: by deferred measurement ([[quantum-computing/quantum-circuits#prop-deferred]]) the output statistics are those of measuring the coins first. What makes this a *classical* computation is that the coins are only ever used as controls — no gate after the Hadamards makes the amplitudes of different coin values interfere. A quantum algorithm differs exactly in applying such gates.
:::
:::

Factoring is a search problem, but it has a decision version in $\mathsf{BQP}$: "does $N$ have a prime factor at most $k$?" Shor's algorithm with repetitions produces the full prime factorisation with high probability (each factor found can be tested for primality and factored further), and comparing the factors with $k$ answers the question. The same problem is in $\mathsf{NP}\cap\mathsf{coNP}$: a certificate is the prime factorisation itself, checkable in polynomial time since primality is in $\mathsf{P}$. That is one reason factoring is **not** believed to be $\mathsf{NP}$-complete: if it were, $\mathsf{NP} = \mathsf{coNP}$.

## Upper bounds: simulating quantum circuits classically

A state-vector simulation of a circuit on $p$ qubits takes $2^p$ memory. Feynman's insight is that exponential *time* is unavoidable as far as we know, but exponential *memory* is not.

::: theorem BQP ⊆ PSPACE {#thm-bqp-pspace}
Every language in $\mathsf{BQP}$ is decided by a deterministic classical algorithm using polynomial space (and exponential time).
:::

::: proof
Let $C = g_m\cdots g_1$ be the circuit, on $p$ qubits, with input $\ket{x_0}$ (the input string padded with zeros). Inserting the completeness relation ([[quantum-computing/qubits#eq-completeness]]) between consecutive gates,
$$
\bra yC\ket{x_0} = \sum_{x_1, \dots, x_{m-1}\in\{0,1\}^p}\bra y g_m\ket{x_{m-1}}\bra{x_{m-1}}g_{m-1}\ket{x_{m-2}}\cdots\bra{x_1}g_1\ket{x_0}.
$$ {#eq-path-sum}
Each sequence $x_0, x_1, \dots, x_{m-1}, y$ is a **path** and contributes the product of $m$ matrix entries. A gate on at most two qubits has $\bra{x_k}g_k\ket{x_{k-1}} = 0$ unless $x_k$ and $x_{k-1}$ agree outside those qubits, so we can compute the amplitude recursively: $\mathrm{amp}_k(z) = \bra z g_k\cdots g_1\ket{x_0} = \sum_{z'}\bra zg_k\ket{z'}\,\mathrm{amp}_{k-1}(z')$, where $z'$ ranges over the at most $4$ strings that differ from $z$ only on the qubits of $g_k$. The recursion has depth $m$, and each level stores $O(p)$ bits for $z$ plus a partial sum. With the gates $H$, $T$, CNOT every amplitude is of the form $2^{-h/2}\sum_j c_j\omega^j$ with $\omega = e^{i\pi/4}$ and integers $c_j$, which can be stored exactly with polynomially many bits. So $\bra yC\ket{x_0}$ is computed in space $O(m(p + \text{poly}))$ = polynomial. The acceptance probability is $\sum_{y : y_1 = 1}\abs{\bra yC\ket{x_0}}^2$, a sum of $2^{p-1}$ terms computed one after another, reusing the space; comparing it with $1/2$ decides $L$.
:::

The proof is a program, and it is short. It computes an amplitude by the recursion above and checks it against the state vector.

```python
from qsim import *

def amplitude(circuit, n, y, k=None):
    """<y| g_k ... g_1 |0^n> by summing over paths: polynomial space, exponential time."""
    if k is None: k = len(circuit)
    if k == 0: return 1 if y == 0 else 0           # the input state |0...0>
    U, q, controls = circuit[k - 1]
    m = 1 << (n - 1 - q)
    if any(not (y >> (n - 1 - c)) & 1 for c in controls):
        return amplitude(circuit, n, y, k - 1)    # control not satisfied: gate acts as I
    b = (y >> (n - 1 - q)) & 1                     # output bit of the target qubit
    total = 0
    for a in (0, 1):                               # the two possible input bits
        if U[b][a] != 0:
            total += U[b][a] * amplitude(circuit, n, (y & ~m) | (a * m), k - 1)
    return total

n = 3
circuit = [(H, 0, ()), (H, 1, ()), (T, 1, ()), (X, 2, (0,)), (H, 2, ()),
           (X, 0, (1,)), (T, 2, ()), (H, 0, ()), (X, 1, (2,)), (H, 1, ())]
s = zeros(n)
for U, q, c in circuit: apply(s, U, q, controls=c)
fmt = lambda z: f"{round(z.real, 4) + 0:+.4f}{round(z.imag, 4) + 0:+.4f}i"
for y in range(2 ** n):
    print(f"|{y:03b}>: path sum {fmt(amplitude(circuit, n, y))}   state vector {fmt(s[y])}")
```

The two methods agree. Diagonal gates ($T$) and permutation gates (CNOT, and $X$) do not branch, so the number of paths is $2^h$ for a circuit with $h$ Hadamards — here at most $2^5 = 32$ for each amplitude, independent of the number of qubits. The state-vector method costs $2^p$ memory and time about $m2^p$; the path sum costs memory $O(mp)$ and time $O(m2^h)$. Practical simulators interpolate between the two (tensor-network contraction is a sophisticated version), and the trade-off between memory and time was at the centre of the debate about the 2019 supremacy experiment.

::: example How expensive are the two simulations? {#ex-sim-cost}
A circuit acts on $p = 50$ qubits with $m = 1000$ gates, of which $h = 200$ are Hadamards. Estimate the memory and the number of arithmetic operations of the state-vector and path-sum simulations of one amplitude.
::: solution
*State vector:* $2^{50}\approx 1.1\times10^{15}$ amplitudes at 16 bytes each, $16$ PiB of memory, and about $m\cdot 2^{p} \approx 10^{18}$ operations — memory beyond any computer as of 2026, time feasible. *Path sum:* memory for a recursion of depth $1000$ with $50$-bit strings, a few kilobytes, and about $2^{200}\approx 1.6\times10^{60}$ terms — memory trivial, time impossible. Neither is practical, but a hybrid that cuts the circuit into pieces, holding state vectors of the pieces and summing over the paths across the cuts, can be. The cost of every known general method is exponential in some parameter of the circuit (number of qubits, number of non-Clifford gates, or entanglement across a cut).
:::
:::

The path sum gives a sharper bound. A language is in $\mathsf{PP}$ if a polynomial-time probabilistic machine accepts the strings in $L$ with probability strictly greater than $1/2$ and the others with probability at most $1/2$ — unbounded error, a much more powerful kind of machine, which contains $\mathsf{NP}$ and $\mathsf{BPP}$, and satisfies $\mathsf{PP}\subseteq\mathsf{PSPACE}$.

::: theorem BQP ⊆ PP {#thm-bqp-pp}
(Adleman, DeMarrais and Huang, 1997.) Every language in $\mathsf{BQP}$ is in $\mathsf{PP}$.
:::

::: proof
(Sketch.) Use the gate set $\{H, \mathrm{Toffoli}\}$, which is universal for $\mathsf{BQP}$ (Shi, 2003; all amplitudes are then real). In [[#eq-path-sum]] every path has weight $\pm2^{-h/2}$, where $h$ is the number of Hadamards, with sign $(-1)^{\sigma(P)}$ computable in polynomial time from the path $P$ (each Hadamard contributes $-1$ when it maps $\ket1$ to $\ket1$). So
$$
\Prob[\text{accept}] = \sum_{y: y_1 = 1}\Bigl(2^{-h/2}\sum_{P\colon x_0\to y}(-1)^{\sigma(P)}\Bigr)^2 = 2^{-h}\sum_{y: y_1 = 1}\ \sum_{P, P'\colon x_0\to y}(-1)^{\sigma(P) + \sigma(P')} = \frac{A - B}{2^h},
$$
where $A$ and $B$ count the triples $(y, P, P')$ with even and odd total sign. A nondeterministic polynomial-time machine can guess such a triple, and functions of the form "number of accepting minus number of rejecting paths" are exactly the class $\mathsf{GapP}$. Deciding whether $A - B > 2^h/2$ — which holds for $w\in L$ (probability $\ge 2/3$) and fails for $w\notin L$ (probability $\le 1/3$) — is a threshold question about a $\mathsf{GapP}$ function, which is in $\mathsf{PP}$ by the closure properties of $\mathsf{GapP}$ (Fenner, Fortnow and Kurtz, 1994).
:::

::: example The path sum of Deutsch–Jozsa {#ex-dj-paths}
Write the amplitude of $\ket{0^n}$ at the end of the Deutsch–Jozsa algorithm ([[quantum-computing/first-algorithms#alg-dj]]) as a path sum, and explain why computing it exactly is hard classically in general, even though deciding the promise problem is not.
::: solution
The circuit is $H^{\otimes n}O_fH^{\otimes n}$ on the input register. A path from $\ket{0^n}$ to $\ket{0^n}$ passes through one intermediate basis state $\ket x$ after the first Hadamard layer (the oracle is diagonal, so it does not branch). Its weight is $\bra{0^n}H^{\otimes n}\ket x(-1)^{f(x)}\bra xH^{\otimes n}\ket{0^n} = 2^{-n}(-1)^{f(x)}$, and summing the $2^n$ paths gives $2^{-n}\sum_x(-1)^{f(x)} = 2^{-n}(A - B)$, where $A$ and $B$ count the zeros and ones of $f$ — a $\mathsf{GapP}$ quantity exactly as in [[#thm-bqp-pp]]. Computing $A - B$ exactly for a function given by a circuit is $\#\mathsf{P}$-hard. But the quantum algorithm does not compute the amplitude; it *samples* from a distribution in which the amplitude's square is a probability, and under the promise that probability is $0$ or $1$. Classical randomised sampling of $f$ also decides the promise problem easily ([[quantum-computing/first-algorithms#thm-dj-classical]]). Quantum speed-ups arise when sampling from the quantum distribution is hard classically, which is the theme of the section on sampling below.
:::
:::

So, as far as is known,
$$
\mathsf{P}\subseteq\mathsf{BPP}\subseteq\mathsf{BQP}\subseteq\mathsf{PP}\subseteq\mathsf{P}^{\#\mathsf{P}}\subseteq\mathsf{PSPACE}\subseteq\mathsf{EXP}.
$$
None of these inclusions is known to be strict except $\mathsf P\ne\mathsf{EXP}$ (by the time hierarchy theorem, [[complexity/hierarchies]]). In particular, proving $\mathsf{BPP}\ne\mathsf{BQP}$ would prove $\mathsf{P}\ne\mathsf{PSPACE}$, a famous open problem. **Every belief that quantum computers are more powerful than classical ones is therefore conditional**: on the hardness of factoring, on oracle results, or on conjectures such as the non-collapse of the polynomial hierarchy.

## What is in BQP?

The problems with a polynomial-time quantum algorithm and no known polynomial-time classical one fall into a few families.

- **Hidden subgroup problems over abelian groups**: factoring and discrete logarithms (Shor, 1994), including on elliptic curves, and number-theoretic problems such as solving Pell's equation and computing class groups of number fields (Hallgren, 2002 and later).
- **Simulation of quantum systems**: estimating the time evolution $e^{-iHt}\ket\psi$ of a local Hamiltonian $H$ to polynomial precision (Lloyd, 1996), and, combined with phase estimation, energies of states that can be prepared efficiently. This was Feynman's original motivation and is the application most chemists and physicists expect first. Its decision version is $\mathsf{BQP}$-complete: every $\mathsf{BQP}$ problem reduces to it.
- **Approximating certain #P-hard quantities**, such as the Jones polynomial of a knot at roots of unity (Aharonov, Jones and Landau, 2006) to an additive precision, also $\mathsf{BQP}$-complete.
- **Linear-algebra problems** in special settings (the HHL algorithm of Harrow, Hassidim and Lloyd, 2009, for sparse well-conditioned linear systems, where the output is a quantum state, not a vector of numbers). Several proposed exponential speed-ups in machine learning built on such routines were **dequantised** — matched by classical algorithms that sample from the input in the same way — starting with Ewin Tang's 2018 classical algorithm for recommendation systems.

### NP and BQP

There is no known efficient quantum algorithm for any $\mathsf{NP}$-complete problem, and good reasons to doubt there is one. Grover's algorithm gives a quadratic speed-up of brute-force search, and the BBBV theorem ([[quantum-computing/grover#thm-bbbv]]) shows that no algorithm that treats the problem as a black box can do better. The structure that Shor's algorithm exploits — a hidden period in an abelian group — has no known analogue in $\mathsf{NP}$-complete problems.

::: warning "Quantum computers try all solutions in parallel, so they solve NP-complete problems"
This is the most common misconception about quantum computing. A quantum computer can prepare a superposition of all $2^n$ candidate solutions and evaluate a checker on all of them in one step, but measuring then gives a uniformly random candidate — no better than guessing. To do better, interference must concentrate amplitude on solutions, and for unstructured search the best possible concentration takes $\Omega(2^{n/2})$ steps ([[quantum-computing/grover#thm-bbbv]]). Most complexity theorists conjecture that $\mathsf{NP}\not\subseteq\mathsf{BQP}$; the same applies to quantum annealers and variational heuristics, for which no exponential speed-up on $\mathsf{NP}$-hard optimisation problems has been demonstrated.
:::

## Oracle separations

Unconditional separations exist relative to oracles. A **relativised** class $\mathsf{C}^O$ allows its machines to query an oracle $O$ (for quantum machines, the oracle is applied as $U_O$ to superpositions). Oracle results do not settle the unrelativised questions — there are oracles relative to which $\mathsf P = \mathsf{NP}$ and others relative to which they differ (Baker, Gill and Solovay, 1975) — but they show which proof techniques cannot work, and they capture the power of the query algorithms of [[quantum-computing/first-algorithms]].

::: theorem Oracle separations involving BQP {#thm-oracles}
(a) There is an oracle $O$ with $\mathsf{BQP}^O\not\subseteq\mathsf{BPP}^O$ (Bernstein and Vazirani, 1993, with a superpolynomial query gap; Simon, 1994, with an exponential one). (b) Relative to a random oracle, with probability $1$, $\mathsf{NP}^O\not\subseteq\mathsf{BQP}^O$ (Bennett, Bernstein, Brassard and Vazirani, 1997). (c) There is an oracle relative to which $\mathsf{BQP}^O$ is not contained in the polynomial hierarchy $\mathsf{PH}^O$ (Raz and Tal, 2018).
:::

::: proof
(Sketch of (a) and (b).) (a) For each $n$, choose a Simon function $f_n$ on $n$ bits with period $s_n$ (or a one-to-one function) at random, and let $L = \{1^n : f_n \text{ is two-to-one}\}$. Simon's algorithm ([[quantum-computing/first-algorithms#alg-simon]]) decides $L$ with $O(n)$ queries — given a candidate $s$, two more queries $f(0)$, $f(s)$ test it — while a classical machine needs $\Omega(2^{n/2})$ queries to find a collision ([[quantum-computing/first-algorithms#thm-simon-classical]]); a diagonalisation over all polynomial-time machines turns this query gap into an oracle with $L\in\mathsf{BQP}^O\setminus\mathsf{BPP}^O$. (b) Let $L = \{1^n : \text{some } x\in\{0,1\}^n \text{ has } O(x) = 1\}$, clearly in $\mathsf{NP}^O$. For a random oracle with about one marked string of each length, deciding $L$ is unstructured search, and by [[quantum-computing/grover#thm-bbbv]] a machine making $2^{o(n/2)}$ queries cannot succeed with probability bounded above $1/2$; again diagonalisation completes the argument.
:::

Part (c) is the strongest: it means there is a problem — Raz and Tal used a variant of "forrelation", which asks whether one Boolean function is correlated with the Fourier transform of another — that a quantum computer solves with one query but that no constant-depth circuit of exponential size can, and such circuits capture the polynomial hierarchy relative to oracles. It answers a question posed by Bernstein and Vazirani in 1993.

## Quantum Merlin–Arthur

The quantum analogue of $\mathsf{NP}$ is $\mathsf{QMA}$: a language is in $\mathsf{QMA}$ if a polynomial-time quantum verifier, given a polynomial-size **quantum** proof state, accepts with probability at least $2/3$ for some proof when $w\in L$ and at most $1/3$ for every proof when $w\notin L$. Kitaev (1999) proved that the **local Hamiltonian problem** — estimating the lowest energy of a sum of terms each acting on a few qubits, to inverse-polynomial precision — is $\mathsf{QMA}$-complete. This is the quantum Cook–Levin theorem, and it suggests that finding ground states of quantum systems, and so many problems in chemistry and materials science, is hard even for quantum computers in the worst case; quantum algorithms for chemistry rely on having good initial states.

## Quantum advantage experiments

Factoring large numbers needs error-corrected machines that do not yet exist. Could a noisy machine of about 50–100 qubits already do something no classical computer can? The proposals are **sampling problems**: output a sample from the distribution of measurement outcomes of a specified random circuit. The complexity argument is indirect but rigorous in its exact form.

::: theorem Hardness of exact sampling (informal) {#thm-sampling}
If a classical polynomial-time randomised algorithm could sample *exactly* from the output distribution of every polynomial-size quantum circuit — or of restricted families such as commuting (IQP) circuits (Bremner, Jozsa and Shepherd, 2011) or linear-optical networks with single photons, **boson sampling** (Aaronson and Arkhipov, 2011) — then the polynomial hierarchy would collapse to its third level.
:::

We state this without proof. The argument shows that exact output probabilities of such circuits are $\#\mathsf{P}$-hard to compute, while a classical sampler would let one approximate them in $\mathsf{BPP}^{\mathsf{NP}}$ by Stockmeyer's approximate counting; then $\mathsf{P}^{\#\mathsf{P}}\subseteq\mathsf{BPP}^{\mathsf{NP}}$, which by Toda's theorem collapses $\mathsf{PH}$. Real devices are noisy and sample only approximately, so the claims about experiments rest on further, less established conjectures about the hardness of approximate sampling, and on benchmarks such as the **linear cross-entropy** fidelity, which compares the observed samples with ideal probabilities computed classically for smaller instances.

::: application The supremacy debate, 2019–2025
In October 2019 a Google team reported that their 53-qubit Sycamore processor sampled from random circuits of 20 cycles in about $200$ seconds, and estimated that the Summit supercomputer would need $10\,000$ years for the same task. Within days IBM researchers argued that a simulation using Summit's disk storage would take about $2.5$ days. In 2022 Feng Pan, Keyang Chen and Pan Zhang reproduced samples of comparable fidelity with a tensor-network method in about $15$ hours on $512$ GPUs, and later work reduced classical costs further. Similar claims were made for Gaussian boson sampling (the USTC Jiuzhang photonic experiments, from 2020) and for superconducting random-circuit sampling (USTC Zuchongzhi, 2021), and similarly challenged by improved classical algorithms that exploit noise and photon loss. In December 2024 Google reported that its 105-qubit Willow chip performed a random-circuit-sampling benchmark in under five minutes that it estimated would take a leading supercomputer about $10^{25}$ years. The pattern so far: each claim is credible at the time it is made, the classical side responds, and the boundary moves. Random-circuit sampling has no known practical use; its role is to test whether quantum devices do something classically hard, which most researchers accept they now do for sufficiently large, low-noise instances — with the caveat that "classically hard" is a conjecture, not a theorem.
:::

::: example Repetitions for a reliable answer {#ex-amplify}
A $\mathsf{BQP}$ circuit is correct with probability exactly $2/3$. Using the amplification bound $e^{-\varepsilon^2m/(1+2\varepsilon)}$ of [[complexity/randomised-complexity]] with $\varepsilon = 1/6$, how many copies are needed for error at most $10^{-6}$, and how much bigger is the circuit?
::: solution
With $\varepsilon = 1/6$, $\varepsilon^2/(1 + 2\varepsilon) = (1/36)/(4/3) = 1/48$, so we need $e^{-m/48}\le10^{-6}$, i.e. $m\ge 48\ln(10^6)\approx 663.2$: $m = 664$ copies (in practice an odd number, $665$, avoids ties). The amplified circuit has $664$ times the qubits and gates plus a reversible majority circuit of size $O(m\log m)$. The Chernoff bound is generous here: an exact binomial calculation shows that $193$ copies suffice. On hardware one would rather run the same circuit $m$ times and take the majority classically — the same thing, by deferred measurement, with $m$ times the time instead of the width.
:::
:::

::: history
Richard Feynman's 1982 lecture "Simulating physics with computers" (published in the *International Journal of Theoretical Physics*) argued that classical computers simulate quantum systems inefficiently and proposed quantum ones; Yuri Manin made a similar suggestion in 1980. David Deutsch defined the universal quantum Turing machine in 1985. Ethan Bernstein and Umesh Vazirani founded quantum complexity theory in 1993 (journal version 1997), defining $\mathsf{BQP}$, proving $\mathsf{BQP}\subseteq\mathsf{P}^{\#\mathsf P}$ and giving the first oracle separation; Andrew Yao proved circuits and quantum Turing machines equivalent the same year. Leonard Adleman, Jonathan DeMarrais and Ming-Deh Huang proved $\mathsf{BQP}\subseteq\mathsf{PP}$ in 1997, and Lance Fortnow and John Rogers showed in 1999 that $\mathsf{BQP}$ is low for $\mathsf{PP}$. Alexei Kitaev defined $\mathsf{QMA}$ and proved the local Hamiltonian problem complete for it in 1999. Scott Aaronson and Alex Arkhipov proposed boson sampling in 2011; John Preskill coined the term "quantum supremacy" in 2012; and Ran Raz and Avishay Tal proved the oracle separation of $\mathsf{BQP}$ from $\mathsf{PH}$ in 2018.
:::

## Where this leads

The complexity picture explains what to expect from hardware: exponential advantages only for structured problems (factoring, discrete logarithms, simulation of quantum systems), polynomial advantages from Grover-type algorithms, and demonstrations of advantage on sampling tasks whose classical hardness is conjectural. [[quantum-computing/error-correction]] shows that noise does not change the class: the threshold theorem implies that $\mathsf{BQP}$ is achievable by noisy circuits with polylogarithmic overhead, provided the noise is below a constant threshold. [[quantum-computing/quantum-hardware]] discusses where machines stood as of 2026. The classical complexity classes used here, and the techniques behind $\mathsf{PP}$, $\#\mathsf P$ and the polynomial hierarchy, are in [[complexity]]; Aaronson's *Quantum Computing Since Democritus* is an entertaining guide to this whole landscape.

::: summary
- $\mathsf{BQP}$ is the class of languages decided by uniform polynomial-size quantum circuits with error at most $1/3$ ([[#def-bqp]]); it is robust to the error bound, the gate set and intermediate measurements ([[#thm-bqp-robust]]).
- $\mathsf{BPP}\subseteq\mathsf{BQP}$ ([[#prop-bpp-bqp]]): reversible circuits plus Hadamard coin flips simulate randomised computation.
- $\mathsf{BQP}\subseteq\mathsf{PSPACE}$ by Feynman's path sum ([[#thm-bqp-pspace]]), and $\mathsf{BQP}\subseteq\mathsf{PP}$ ([[#thm-bqp-pp]]); so proving $\mathsf{BPP}\ne\mathsf{BQP}$ would prove $\mathsf P\ne\mathsf{PSPACE}$.
- Known exponential speed-ups are for structured problems: abelian hidden subgroups (factoring, discrete logarithms), quantum simulation, some knot invariants. No efficient quantum algorithm for $\mathsf{NP}$-complete problems is known, and black-box methods give only quadratic speed-ups.
- Oracles separate $\mathsf{BQP}$ from $\mathsf{BPP}$ (Simon) and from $\mathsf{PH}$ (Raz–Tal), and random oracles separate $\mathsf{NP}$ from $\mathsf{BQP}$ (BBBV) ([[#thm-oracles]]).
- $\mathsf{QMA}$ is the quantum analogue of $\mathsf{NP}$, with the local Hamiltonian problem complete for it.
- Sampling experiments rest on conjectures about approximate sampling ([[#thm-sampling]]); claims of advantage since 2019 have been met by better classical simulations, and the boundary is still moving.
:::

## Exercises

::: exercise Amplifying a BQP circuit {level=1 check="664"}
Using the bound of [[#ex-amplify]], how many copies of a circuit with success probability $2/3$ are needed to reduce the error of the majority vote to at most $10^{-6}$? (Enter the smallest number given by the bound.)
::: solution
$m\ge 48\ln(10^6) = 663.15\ldots$, so $m = 664$, as in [[#ex-amplify]]. With success probability $0.9$ instead ($\varepsilon = 0.4$, $\varepsilon^2/(1 + 2\varepsilon) = 0.16/1.8 \approx 0.0889$), about $156$ copies would suffice by the same bound.
:::

::: exercise Counting paths {level=1 check="32"}
In the path-sum program, how many paths (non-zero products) contribute at most to each amplitude of the ten-gate circuit, which contains five Hadamard gates? (Enter a number.)
::: solution
Only Hadamards branch (each has two non-zero entries in every row), while $T$, $X$ and CNOT have one non-zero entry per row. So at most $2^5 = 32$ paths contribute to each amplitude, whatever the number of qubits. A circuit with $h$ Hadamards costs $O(m2^h)$ time per amplitude.
:::
:::

::: exercise Closure under complement {level=1}
Show that $\mathsf{BQP}$ is closed under complement, and that it is closed under union and intersection.
::: solution
For the complement, add an $X$ gate on the output qubit: probabilities $\ge2/3$ and $\le1/3$ swap. For union and intersection, first amplify both circuits to error at most $1/12$ ([[#thm-bqp-robust]](a)), run them on separate registers, and compute the OR (respectively AND) of their output bits reversibly into a new qubit. By the union bound the result is wrong with probability at most $1/12 + 1/12 = 1/6 < 1/3$.
:::
:::

::: exercise Which problems are known to be in BQP? {level=1}
For each problem, say whether it is known to be in $\mathsf{BQP}$, and whether it is believed to be outside $\mathsf{BPP}$: (a) primality testing; (b) the discrete logarithm in an elliptic-curve group; (c) 3-colourability of graphs; (d) estimating the ground-state energy of a local Hamiltonian to inverse-polynomial accuracy; (e) simulating the time evolution of a local Hamiltonian for polynomial time.
::: solution
(a) In $\mathsf P$ (AKS, 2002), hence in $\mathsf{BQP}$; not a quantum speed-up. (b) In $\mathsf{BQP}$ by Shor's algorithm; believed outside $\mathsf{BPP}$ — elliptic-curve cryptography relies on it. (c) $\mathsf{NP}$-complete: not known to be in $\mathsf{BQP}$, believed not to be. (d) $\mathsf{QMA}$-complete (Kitaev): not believed to be in $\mathsf{BQP}$ in the worst case. (e) In $\mathsf{BQP}$ (Lloyd) and $\mathsf{BQP}$-complete, so it is outside $\mathsf{BPP}$ unless $\mathsf{BPP} = \mathsf{BQP}$.
:::

::: exercise Factoring in NP ∩ coNP {level=2}
Let $\mathrm{FACTOR} = \{(N, k) : N \text{ has a prime factor } p\le k\}$. Show that $\mathrm{FACTOR}\in\mathsf{NP}\cap\mathsf{coNP}$ and $\mathrm{FACTOR}\in\mathsf{BQP}$, and that if $\mathrm{FACTOR}$ were $\mathsf{NP}$-complete then $\mathsf{NP} = \mathsf{coNP}$.
::: solution
*Certificates.* For "yes": a prime $p\le k$ dividing $N$ (primality checkable in polynomial time). For "no": the complete prime factorisation $N = p_1^{e_1}\cdots p_m^{e_m}$, each $p_i > k$ and prime, which can be multiplied out and checked; it has polynomial length since there are at most $\log_2N$ prime factors with multiplicity. So $\mathrm{FACTOR}\in\mathsf{NP}\cap\mathsf{coNP}$. *Quantum.* Shor's algorithm finds a factor with constant probability; recursing on the factors, with primality tests, gives the full factorisation with high probability after polynomially many runs, and comparing the smallest prime factor with $k$ decides the problem with bounded error. *Completeness.* If $\mathrm{FACTOR}$ were $\mathsf{NP}$-complete, every $L\in\mathsf{NP}$ would reduce to it, so $L\in\mathsf{coNP}$ as $\mathsf{coNP}$ is closed under polynomial-time reductions; then $\mathsf{NP}\subseteq\mathsf{coNP}$, and by symmetry $\mathsf{NP} = \mathsf{coNP}$.
:::

::: exercise Memory against time {level=2}
A simulation strategy holds the state of the first $p/2$ qubits as a vector and sums over paths for the rest. Explain informally why a circuit whose two halves are connected by only $c$ two-qubit gates can be simulated with memory $O(2^{p/2})$ and time $O(4^c\cdot m2^{p/2})$, and why this makes shallow or weakly connected circuits easy to simulate.
::: solution
Any two-qubit gate can be written as a sum of at most $4$ products of single-qubit operators, $G = \sum_{j=1}^{4}A_j\otimes B_j$ (an operator Schmidt decomposition, as in [[quantum-computing/entanglement#thm-schmidt]] applied to the $16$-dimensional space of $4\times4$ matrices). Replacing each of the $c$ gates that cross the cut by such a sum turns the circuit into a sum of $4^c$ circuits in which the two halves never interact. Each term is a product of two independent half-circuits, simulated with state vectors of size $2^{p/2}$ in time $O(m2^{p/2})$, and the amplitudes multiply. Summing the $4^c$ terms gives the answer. For a circuit with $c$ small (few gates across the cut, as in shallow circuits on a line or in random circuits of low depth), this beats the full $2^p$ state vector by far. Better cuts and tensor-network contraction orders generalise the idea; it is how the 2019 sampling experiment was eventually simulated.
:::

::: exercise BQP is low for itself {level=3}
Show that $\mathsf{BQP}^{\mathsf{BQP}} = \mathsf{BQP}$: a $\mathsf{BQP}$ machine with access to a $\mathsf{BQP}$ oracle (which it may query on superpositions) is no more powerful than one without.
::: solution
Let the outer circuit make $q$ queries to a language $L'\in\mathsf{BQP}$. Replace each query by the circuit $C'$ for $L'$, amplified to error $\varepsilon = 1/(100q^2)$ ([[#thm-bqp-robust]]): compute the answer into an ancilla with $C'$, CNOT it onto the query's target register, then run $C'^{-1}$ to uncompute the workspace. On a basis input $\ket z$ the output of $C'$ is $\sqrt{1-\varepsilon'}\ket{L'(z)}\ket{g_z} + \sqrt{\varepsilon'}\ket{\neg L'(z)}\ket{b_z}$ with $\varepsilon'\le\varepsilon$, so the compute–copy–uncompute sequence differs from the ideal oracle $\ket z\ket y\mapsto\ket z\ket{y\oplus L'(z)}$ by at most $O(\sqrt\varepsilon)$ in norm on each basis state. Both maps leave $\ket z$ unchanged, so their difference is block-diagonal with one block for each $z$, each block acting on the $2$-dimensional target and the workspace; hence the operator-norm difference is the largest block norm, again $O(\sqrt\varepsilon)$. By [[quantum-computing/quantum-circuits#lem-errors]] the total error after $q$ queries is $O(q\sqrt\varepsilon) = O(1/10)$, small enough that the outer circuit's output probabilities change by less than $1/6$; amplifying the outer circuit restores the $2/3$ gap. The result is a polynomial-size quantum circuit. (The uncomputation is essential: leaving the garbage $\ket{g_z}$ entangled with the query would destroy the interference the outer algorithm relies on.)
:::
:::

::: exercise A GapP formula {level=3}
For a circuit of gates $H$ and Toffoli with $h$ Hadamards acting on $\ket{0^p}$, show that $\bra yC\ket{0^p} = 2^{-h/2}(A_y - B_y)$ where $A_y$ and $B_y$ count paths with even and odd numbers of "$\ket1\mapsto\ket1$" Hadamard transitions. Verify it for $C = H$ on one qubit and $C = HH$.
::: solution
Expanding [[#eq-path-sum]], each Toffoli has exactly one non-zero entry $1$ in each column (it permutes basis states), and each Hadamard has entries $\bra bH\ket a = 2^{-1/2}(-1)^{ab}$. A path is therefore determined by the outputs $b$ chosen at the $h$ Hadamards, and its weight is $2^{-h/2}(-1)^{\#\{\text{Hadamards with } a = b = 1\}}$. Grouping paths by the parity of that count gives $2^{-h/2}(A_y - B_y)$. For $C = H$ on $\ket0$: one path to each $y$, with $a = 0$, so $A_0 = A_1 = 1$, $B = 0$: amplitudes $2^{-1/2}$, correct. For $C = HH$: paths $0\to b_1\to b_2$. To $y = 0$: via $b_1 = 0$ (no $1\to1$) and $b_1 = 1$ (no $1\to1$, since $b_2 = 0$): $A_0 = 2$, amplitude $2^{-1}\cdot2 = 1$. To $y = 1$: via $b_1 = 0$ (even) and $b_1 = 1$ (the second Hadamard maps $1\to1$: odd), so $A_1 - B_1 = 1 - 1 = 0$. So $HH\ket0 = \ket0$ — the interference of [[quantum-computing/qubits#ex-interference]], now as cancelling counts.
:::
