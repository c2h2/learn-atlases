1936 年，艾伦·图灵（Alan Turing）问了一个问题：一个人用纸笔做计算时究竟在做什么。他一次只看若干个符号；根据看到的符号和自己当前的"思维状态"，他写上或擦去一个符号，把注意力移到纸上的邻近位置，并改变自己的思维状态。思维状态的个数有限，符号的个数也有限，但纸是无穷无尽的。图灵论证说，任何这样的过程都可以由一台极其简单的机器完成：一个有限控制器、一条分成带格的无界**磁带**、以及一个**读头**——它一次读写一格，并左右移动一格。这就是**图灵机**。

有限自动机除了自身状态之外没有任何记忆，下推自动机也只会用一个栈。图灵机却可以在任意位置读取并重写自己的记忆，而这一点对于*任何*计算机——或任何照规则行事的人——所能完成的*一切*计算都已经足够。这一论断就是**丘奇–图灵论题**，它不是定理，而是整个理论其余部分赖以建立的基础：正是它让我们日后能够证明某些问题不可能被*任何*程序解决。

本章精确定义图灵机，演示如何给它编程，证明各种自然的扩充（多条磁带、非确定性、枚举器）不增加能力，讨论丘奇–图灵论题，并造出一台**通用图灵机**——一台给定某台机器的描述就能模拟它的机器，它是存储程序计算机以及一切解释器的理论始祖。

## 图灵机

::: definition 图灵机 {#def-tm}
一台**图灵机**（TM）是一个 7 元组 $M = (Q, \Sigma, \Gamma, \delta, q_0, q_{\text{acc}}, q_{\text{rej}})$，其中 $Q$、$\Sigma$、$\Gamma$ 都是有限集，且

1. $Q$ 是**状态**集；
2. $\Sigma$ 是**输入字母表**，不含**空白符** $\sqcup$；
3. $\Gamma$ 是**带字母表**，满足 $\sqcup \in \Gamma$ 且 $\Sigma \subseteq \Gamma$；
4. $\delta\colon (Q \setminus \{q_{\text{acc}}, q_{\text{rej}}\}) \times \Gamma \to Q \times \Gamma \times \{L, R\}$ 是**转移函数**；
5. $q_0 \in Q$ 是开始状态，$q_{\text{acc}} \ne q_{\text{rej}}$ 是**接受**状态与**拒绝**状态。
:::

磁带有一端是左端，向右无限延伸。初始时，最左边 $n$ 格存放输入 $w = w_1 \cdots w_n$，其后全是空白；读头位于最左格，机器处于 $q_0$。若 $\delta(q, a) = (r, b, D)$，则机器在状态 $q$ 读到 $a$ 时，用 $b$ 覆写 $a$，把读头沿方向 $D$（左或右）移动一格，并进入状态 $r$。在最左格上向左移动时，读头留在原地。机器一旦进入 $q_{\text{acc}}$ 或 $q_{\text{rej}}$ 就**停机**；否则将永远运行下去。

要描述一次计算，我们把整个局面记录成一个串。

::: definition 格局与接受 {#def-tm-config}
$M$ 的一个**格局**写作 $u\,q\,v$，其中 $u, v \in \Gamma^*$，$q \in Q$：磁带上放着 $uv$ 及其后的空白，机器处于状态 $q$，读头位于 $v$ 的第一个符号上（若 $v = \varepsilon$ 则位于空白上）。若 $M$ 的一步能从格局 $C$ 到 $C'$，就称 $C$ **导出** $C'$：对 $a, b, c \in \Gamma$ 与 $u, v \in \Gamma^*$，

- 若 $\delta(q, b) = (q', c, L)$，则 $u\,a\,q\,b\,v$ 导出 $u\,q'\,a\,c\,v$，且此时也有 $q\,b\,v$ 导出 $q'\,c\,v$（左端情形）；
- 若 $\delta(q, b) = (q', c, R)$，则 $u\,q\,b\,v$ 导出 $u\,c\,q'\,v$。

在输入 $w$ 上的**初始格局**是 $q_0\,w$。状态为 $q_{\text{acc}}$（相应地 $q_{\text{rej}}$）的格局称为**接受**（相应地**拒绝**）格局；两者都是**停机**格局。若存在格局序列 $C_1, \dots, C_k$，其中 $C_1$ 是初始格局，每个 $C_i$ 导出 $C_{i+1}$，且 $C_k$ 是接受格局，则 $M$ **接受** $w$。**$M$ 的语言**是 $L(M) = \{w : M \text{ 接受 } w\}$。
:::

在任何输入上，图灵机只有三种可能：**接受**、**拒绝**，或者**循环**（永不停机）。第三种可能是全新的——每个 DFA 和 PDA 读完输入后总会停下来——而本课程后续一切有趣之处的源头正在于此。

::: definition 可识别语言与可判定语言 {#def-recognisable}
若 $L = L(M)$ 对某台 TM $M$ 成立，则称 $L$ 是**图灵可识别**的（或*递归可枚举*的）。一台在一切输入上都停机的 TM 称为**判定器**；若某个判定器识别 $L$，则称 $L$ 是**可判定**的（或*递归*的）。$L$ 的判定器**判定** $L$。
:::

$L$ 的识别器必须接受 $L$ 的每个串，且不得接受任何别的串——但在不属于 $L$ 的串上，它可以拒绝，也可以*循环*。判定器则必须永远给出答案。[[theory-of-computation/decidability]] 将说明这两个概念确有本质区别。

### 图灵机的编程

给图灵机编程靠的是来回移动，并在处理符号时给它们做标记。下面这台机器识别的语言，没有任何下推自动机能识别（[[theory-of-computation/pushdown-automata#ex-anbncn]]）。

::: example $a^nb^nc^n$ 的图灵机 {#ex-tm-abc}
设计一台判定 $T = \{a^nb^nc^n : n \ge 0\}$ 的 TM，先用文字描述，再写成转移表。
::: solution
*用文字说。*反复执行：划掉最左边剩下的那个 $a$（把它换成 $X$），再划掉最左边的 $b$（换成 $Y$），再划掉最左边的 $c$（换成 $Z$），然后回到最左边。当 $a$ 全部划完后，检查剩下的是否只有 $Y$ 和 $Z$。凡找不到期望符号时一律拒绝。

*形式地*，取 $\Gamma = \{a, b, c, X, Y, Z, \sqcup\}$，凡表中未列出的转移都进入 $q_{\text{rej}}$：

| 状态 | 含义 | 转移 |
|---|---|---|
| $q_1$ | 位于第一个未划掉的符号处 | $a \to X, R, q_2$；$\ Y \to Y, R, q_5$；$\ \sqcup \to \sqcup, R, q_{\text{acc}}$ |
| $q_2$ | 找一个 $b$ | $a \to a, R$；$\ Y \to Y, R$；$\ b \to Y, R, q_3$ |
| $q_3$ | 找一个 $c$ | $b \to b, R$；$\ Z \to Z, R$；$\ c \to Z, L, q_4$ |
| $q_4$ | 返回左端 | $a, b, Y, Z$：移 $L$；$\ X \to X, R, q_1$ |
| $q_5$ | 检查剩余部分 | $Y \to Y, R$；$\ Z \to Z, R$；$\ \sqcup \to \sqcup, R, q_{\text{acc}}$ |

（没有给出新状态的条目保持原状态不变，"移 $L$"表示把读到的符号原样写回。）在 $abc$ 上的计算是

$$
q_1abc \vdash Xq_2bc \vdash XYq_3c \vdash Xq_4YZ \vdash q_4XYZ \vdash Xq_1YZ \vdash XYq_5Z \vdash XYZq_5 \vdash XYZ\sqcup q_{\text{acc}},
$$

共八步。每一遍划掉每种符号各一个，花费 $O(n)$ 步，一共 $n$ 遍，所以这台机器在任何输入上都在 $O(n^2)$ 步内停机：它是一台判定器。
:::
:::

这张表就是整个程序，而一个模拟器只有十几行代码。缺失的转移导致拒绝，磁带按需向右延伸：

```python
BLANK = "_"

def run(delta, w, start="q1", max_steps=10_000):
    """模拟单带图灵机；缺失的转移进入拒绝状态."""
    tape, head, q, steps = list(w) or [BLANK], 0, start, 0
    while q not in ("acc", "rej") and steps < max_steps:
        q, write, move = delta.get((q, tape[head]), ("rej", tape[head], "R"))
        tape[head] = write
        head = max(0, head + (1 if move == "R" else -1))   # 左端：原地不动
        if head == len(tape):
            tape.append(BLANK)                # 磁带向右无界
        steps += 1
    return q, steps, "".join(tape).rstrip(BLANK)

# a^n b^n c^n：每遍划掉一个 a（X）、一个 b（Y）、一个 c（Z）
D = {("q1", "a"): ("q2", "X", "R"), ("q1", "Y"): ("q5", "Y", "R"), ("q1", "_"): ("acc", "_", "R"),
     ("q2", "a"): ("q2", "a", "R"), ("q2", "Y"): ("q2", "Y", "R"), ("q2", "b"): ("q3", "Y", "R"),
     ("q3", "b"): ("q3", "b", "R"), ("q3", "Z"): ("q3", "Z", "R"), ("q3", "c"): ("q4", "Z", "L"),
     **{("q4", s): ("q4", s, "L") for s in "abYZ"}, ("q4", "X"): ("q1", "X", "R"),
     ("q5", "Y"): ("q5", "Y", "R"), ("q5", "Z"): ("q5", "Z", "R"), ("q5", "_"): ("acc", "_", "R")}

if __name__ == "__main__":
    for w in ["", "abc", "aabbcc", "aabbc", "abcabc", "aaabbbccc"]:
        q, steps, tape = run(D, w)
        print(f"{w!r:12} {q}  after {steps:3} steps   tape {tape}")
```

```console
$ python3 tm.py
''           acc  after   1 steps   tape 
'abc'        acc  after   8 steps   tape XYZ
'aabbcc'     acc  after  23 steps   tape XXYYZZ
'aabbc'      rej  after  14 steps   tape XXYYZ
'abcabc'     rej  after   8 steps   tape XYZabc
'aaabbbccc'  acc  after  46 steps   tape XXXYYYZZZ
```

步数上限 `max_steps` 是我们强加的，不是机器自带的：真正的图灵机可以永远运行，此时模拟器会停在既非 `acc` 也非 `rej` 的状态。把程序在 $\{a, b, c\}$ 上所有长不超过 $9$ 的串上跑一遍，与 $T$ 的定义逐一对照，没有发现分歧。

::: quiz
在输入 $aabbc$ 上，[[#ex-tm-abc]] 的机器拒绝。它是在哪个状态、读到哪个符号时拒绝的？

- [ ] $q_2$ 读到 $c$

## 模型的变体

图灵的定义是刻意最简的。许多变体更方便——而它们识别的语言恰好一模一样。这种稳健性是"模型抓住了某种本质"的第一条证据。

小改动容易吸收：允许读头**原地不动**（$D = S$）可以用"先右移再左移"来模拟；**双向无限**的磁带可以以原点为折点折到单向磁带的两条磁道上。更实质性的变体是多条磁带、非确定性和枚举器。

### 多带机器

一台 **$k$ 带图灵机**有 $k$ 条磁带，各配一个读头；输入放在磁带 $1$ 上，其余全为空白。其转移函数为 $\delta\colon Q \times \Gamma^k \to Q \times \Gamma^k \times \{L, R, S\}^k$：它一次读入读头下的全部 $k$ 个符号，写入 $k$ 个新符号，并让每个读头独立移动。

::: theorem 多带机器并不更强 {#thm-multitape}
每台 $k$ 带 TM $M$ 都有一台等价的单带 TM $S$。若 $M$ 在长 $n$ 的输入上于 $t(n) \ge n$ 步内停机，则 $S$ 在 $O(t(n)^2)$ 步内停机。
:::

::: proof
$S$ 把 $k$ 条磁带的内容全部存放在它唯一的一条磁带上，用新符号 $\#$ 分隔：$\#\,w_1\,\#\,w_2\,\# \cdots \#\,w_k\,\#$。为记录读头位置，它对每个带符号 $a$ 使用一个**加点**的副本 $\dot a$，标记每个虚拟读头下方的符号。在输入 $w$ 上，$S$ 先写出 $\#\dot w_1 w_2 \cdots w_n \# \dot\sqcup \# \cdots \# \dot\sqcup \#$。

要模拟 $M$ 的一步，$S$ 从左端的 $\#$ 扫到右端，在有限控制器中记住那 $k$ 个带点符号（可能的情形只有有限多种，所以这只用掉有限量的状态）。此刻它已知道 $M$ 的转移。第二遍扫描写入新符号并把点左移或右移。若某个点移到 $\#$ 上——虚拟读头到达了该磁带上从未用过的空间——$S$ 就把那一点之后的全部磁带内容右移一格，在那里写一个空白。$M$ 停机时，$S$ 照样停机。于是 $S$ 恰在 $M$ 接受、拒绝或循环时接受、拒绝或循环。

*时间。* $t(n)$ 步内 $M$ 的每个读头至多访问 $t(n)$ 格，所以 $S$ 磁带上活跃部分的长度为 $O(k \cdot t(n)) = O(t(n))$（对输入用到 $t(n) \ge n$）。一步模拟由两遍扫描和至多 $k$ 次搬移组成，每次 $O(t(n))$，而这样的步共有 $t(n)$ 步：合计 $O(t(n)^2)$，再加上建初的 $O(n)$。
:::

多带机器往往好编程得多，也快得多。

::: example 两条带判定 $w\#w$ {#ex-two-tape}
描述一台 $O(n)$ 步判定 $\{w\#w : w \in \{0,1\}^*\}$ 的 2 带 TM。
::: solution
1. 读头 1 沿输入右移，把每个符号抄到磁带 2 上，直到读头 1 读到 $\#$（没有 $\#$ 就拒绝）。磁带 2 上此时放着 $\#$ 之前的部分。
2. 把读头 2 移回磁带 2 的左端（一直左移到最左格；第 1 步在第 1 格写下的标记告诉机器何时到达）。
3. 读头 1 右移越过 $\#$。此后两个读头一起右移，比较各自读到的符号；一有不同时拒绝。
4. 若两个读头同时到达空白则接受；只有一个到达则拒绝。

每一步都是一遍扫描，故机器移动 $O(n)$ 次。单带机器则必须每个符号在 $\#$ 两侧来回穿越一次，需要 $\Theta(n^2)$ 次移动——[[#thm-multitape]] 的二次差距有时是实打实的。
:::
:::

### 非确定机器

**非确定** TM 的转移函数为 $\delta\colon Q \times \Gamma \to \mathcal{P}(Q \times \Gamma \times \{L, R\})$；每一步它可能有若干种走法。它的计算构成一棵以格局为结点的**树**，只要*某条*分支到达接受格局，它就接受 $w$。

::: theorem 非确定性不给图灵机增加能力 {#thm-ntm}
每台非确定 TM $N$ 都有一台等价的确定 TM $D$。若 $N$ 的每条分支在一切输入上都停机，则 $D$ 可以做成判定器。
:::

::: proof
$D$ **广度优先**地搜索 $N$ 的计算树。（深度优先是错的：它可能沿一条无穷分支走到底也停不下来，而错过另一条分支上的接受格局。）设 $b$ 是 $N$ 在任何情形下可选走法的最大数目。树的每个结点用一个**地址**标识：一个 $\{1, \dots, b\}$ 上的串，给出从根走到此处所作的选择。$D$ 用三条磁带——输入（从不改动）、一条模拟磁带、一条地址磁带——并反复执行：

1. 把输入抄到模拟磁带上；
2. 在其上模拟 $N$，用地址磁带作选择：第 $i$ 步取地址第 $i$ 个符号指定的选择（若该选择不存在，或地址已用尽，就放弃这条分支）；一旦到达接受格局就**接受**；
3. 把地址换成短字典序（[[theory-of-computation/finite-automata#def-lang-ops]]）中的下一个串，回到第 1 步。

短字典序在到达任何长 $\ell + 1$ 的串之前遍历完所有长 $\ell$ 的地址，所以树的每个结点终将被模拟到，正是广度优先的顺序。若 $N$ 有接受分支，$D$ 经有限轮之后到达它的接受结点并接受。否则 $D$ 永不接受。故 $L(D) = L(N)$，且由 [[#thm-multitape]]，$D$ 可化为单带机器。

至于判定器：若每条分支都停机，则树分支有限且没有无穷路径，由**克尼希（König）引理**它是有限的，设有深度 $h$。修改 $D$，让它顺便记录在长 $\ell$ 的那一轮地址中，是否存在运行满 $\ell$ 步仍未停的分支。若某轮跑完后既无分支仍在运行、也无分支接受，则每条分支都已停机且都未接受，$D$ 拒绝。这最迟在 $\ell = h$ 那一轮之后发生。
:::

::: example 猜一个因子 {#ex-ntm-composite}
给出一台判定 $\mathrm{COMP} = \{1^n : n \text{ 是合数}\}$ 的非确定 TM，并描述 [[#thm-ntm]] 的确定模拟在 $1^6$ 上做什么。
::: solution
在输入 $1^n$ 上，机器（三带）非确定地在磁带 2 上写出串 $1^p$、在磁带 3 上写出 $1^q$，每步选择再写一个 $1$ 还是停下，长度以 $n$ 为上限；除非 $2 \le p, q$，否则拒绝。然后它确定性地检验是否 $p \cdot q = n$——对磁带 2 上的每个 $1$，让读头 3 扫过磁带 3 一遍，同时读头 1 每见一个 $1$ 前进一格——当且仅当输入恰好耗尽时接受。每条分支都停机，因为猜测以 $n$ 为界。当且仅当 $n = pq$ 且 $p, q \ge 2$、即 $n$ 为合数时，存在接受分支。

在 $1^6$ 上，计算树对每对满足 $0 \le p, q \le 6$ 的 $(p, q)$ 各有一条分支；广度优先模拟按地址长度依次尝试它们，找到接受分支 $(2, 3)$ 与 $(3, 2)$。确定机器当然也可以逐个试因子——要点在于非确定机器*猜一个证书*（分解式）再*检验*它，这一模式到 [[complexity]] 中就成为 $\mathsf{NP}$ 的定义。
:::
:::

这一模拟可能要用掉关于树深指数的时间：$N$ 运行 $t$ 步就至多有 $b^t$ 条分支。对*多项式时间*机器，这份指数代价是否不可避免，正是 [[complexity]] 中的 $\mathsf{P}$ 对 $\mathsf{NP}$ 问题。

### 枚举器

**枚举器**是一台外接打印机的 TM。它从空白磁带开始，不时打印一个串；它可以永远运行，打印无穷多个串，顺序任意且可以重复。它**枚举**的语言是它打印过的全部串的集合。这正是*递归可枚举*一名的由来。

::: theorem 识别器与枚举器 {#thm-enumerator}
一个语言是图灵可识别的，当且仅当某个枚举器枚举它。
:::

::: proof
*($\Leftarrow$)* 给定枚举器 $E$，造识别器 $M$：在输入 $w$ 上运行 $E$，每当 $E$ 打印一个串就与 $w$ 比较；相等则接受。$M$ 恰接受 $E$ 终会打印的那些串（对其余的循环）。

*($\Rightarrow$)* 给定识别器 $M$，设 $s_1, s_2, s_3, \dots$ 是按短字典序排列的 $\Sigma^*$ 中全体串。枚举器 $E$ 不能简单地在 $s_1$ 上运行 $M$、再在 $s_2$ 上运行……——它可能卡死在一个 $M$ 会循环的串上。它改用**交错模拟**：对 $i = 1, 2, 3, \dots$，在 $s_1, \dots, s_i$ 上各运行 $M$ 至多 $i$ 步，并把其中在 $i$ 步内被接受的每个 $s_j$ 打印出来。若 $M$ 接受 $s_j$，它是在某步数 $t$ 内接受的，于是 $s_j$ 会在第 $\max(j, t)$ 轮被打印（此后每一轮都会再打印一次，这是允许的）。$M$ 不接受的串永不打印。
:::

交错模拟——把无穷多个可能无穷的计算交织起来，让每一个都获得无界的时间份额——是我们还会再遇到的技巧。

## 丘奇–图灵论题

二十世纪三十年代，好几位数学家各自独立地给出了"可有效计算的函数"的精确定义：阿隆佐·丘奇（Alonzo Church）的 **$\lambda$ 演算**、哥德尔（Gödel）、埃尔布朗（Herbrand）与克莱尼（Kleene）的**一般递归函数**、埃米尔·波斯特（Emil Post）的**产生式系统**，以及图灵的机器。它们彼此等价都很快得到证明：一个函数是 $\lambda$ 可定义的，当且仅当它是一般递归的，当且仅当它是图灵可计算的。此后提出的每一种计算模型——寄存器机、随机存取机、细胞自动机、一切内存无界的通用程序设计语言——最终被发现恰好计算同一批函数。

::: definition 丘奇–图灵论题 {#def-church-turing}
**丘奇–图灵论题。** 每个可由有效过程计算的函数——一组可以机械地遵循的有穷指令、无需洞察力或巧思、可用无界的时间和内存——都可由图灵机计算。等价地说，**算法**的直观概念与"在一切输入上都停机的图灵机"这一形式概念恰好一致。
:::

论题无法证明，因为它的一端——"有效过程"——是非形式的；它是关于一个数学定义与真实世界如何对应的论断。支持它的证据有三类：图灵对"人做计算在做什么"的分析，看起来无所遗漏；各个独立提出的模型彼此等价；以及九十年来找不到任何反例。它的地位相当于一条经受过充分检验的物理定律。

在本课程中，论题扮演实际的角色。我们在三个层次上描述图灵机：**形式描述**（状态和转移表，如 [[#ex-tm-abc]]）；**实现描述**（用文字说明读头如何移动、磁带上写什么）；以及**高层描述**（用自然语言或伪码写出的算法，完全不顾磁带）。论题连同 [[#thm-multitape]] 这样的定理，正是让我们能在三者之间自由往来、从第三层直达第一层的根据：只要能清楚地描述一个算法，判定它的图灵机就存在。此后我们几乎只写高层描述。

::: warning 丘奇–图灵论题没有说什么
论题说的是*能*算什么，不是*多快*算完。图灵机可以模拟现代计算机，但有多项式倍的减速（仅一项特性，[[#thm-multitape]] 就给出二次的），所以"这在 $O(n \log n)$ 时间内完成"一类的说法依赖于模型，复杂性理论因此小心翼翼地固定模型（[[complexity]]）。**扩展**（或称*强*）丘奇–图灵论题——每台物理上可实现的计算机都可被概率图灵机以多项式减速模拟——是另一条远为可疑的论断：量子计算机似乎违反它，因为量子计算机能在多项式时间内分解整数，而已知没有经典多项式时间算法能做到这一点（[[quantum-computing]]）。量子计算机并*不*违反丘奇–图灵论题本身；它们算不出任何图灵机算不出的东西。论题也没有断言大脑或宇宙"就是"一台图灵机；它只谈有效过程。
:::

## 编码与通用机器

算法的输入不只是串和数，还有图、文法、自动机和程序。图灵机只会读串，所以我们要固定一个**编码**：对对象 $O$，$\langle O\rangle$ 表示它在某个固定字母表上的串表示，$\langle O_1, O_2 \rangle$ 表示一对对象的编码。任何合理的编码都可以，只要图灵机能解码它、并检查给定串是否为合法编码。例如，DFA 可以编码为它的状态表、字母表、转移表、开始状态和接受状态的二进制清单，加分隔符；图可以编码为顶点表和边表（[[data-structures/graph-representations]]）。

特别地，图灵机本身也可以编码。把状态编号为 $q_1, \dots, q_m$，带符号编号为 $a_1, \dots, a_s$；把每条转移 $\delta(q_i, a_j) = (q_k, a_l, D)$ 写成 $0^i10^j10^k10^l10^{d}$，其中 $L$ 时 $d = 1$、$R$ 时 $d = 2$；转移之间用 $11$ 分隔。于是每台 TM $M$ 都有一个二进制描述 $\langle M\rangle$，而每个二进制串要么是某台机器的描述，要么可判定它不是。

::: theorem 通用图灵机 {#thm-utm}
存在图灵机 $U$，使得对每台 TM $M$ 和每个串 $w$，$U$ 在输入 $\langle M, w\rangle$ 上：$M$ 接受 $w$ 则接受，$M$ 拒绝 $w$ 则拒绝，$M$ 在 $w$ 上循环则循环。而且 $U$ 模拟 $M$ 只有多项式倍的减速：$M$ 的 $t$ 步所花 $U$ 的步数关于 $t$ 和 $\lvert\langle M\rangle\rvert$ 是多项式的。
:::

::: proof
我们给出一台 3 带机器的实现描述；[[#thm-multitape]] 把它化为一带。磁带 1 存放 $\langle M, w\rangle$。$U$ 首先检查输入是合法编码（否则拒绝）。它把 $M$ 的转移表留在磁带 1 上，把 $M$ 磁带的初始内容写在磁带 2 上，$M$ 的每个带符号 $a_j$ 编码成块 $0^j$、用 $1$ 分隔；它把 $M$ 的开始状态 $q_1$ 的代码 $0$ 写在磁带 3 上。

要模拟 $M$ 的一步，$U$ 读磁带 3 上的当前状态代码，以及磁带 2 上读头下方块中的符号代码，并扫描磁带 1 上的转移表寻找匹配条目 $0^i10^j1\cdots$；比较一元数的代码就是简单的一来一回配对。然后它在磁带 2 上重写符号块（若新块长度不同就搬移磁带 2 的其余部分——或者，为避免搬移，把每块都补齐到同一长度，即 $M$ 的带符号个数），移动到相邻块，并把磁带 3 覆写成新状态的代码。若新状态是 $M$ 的接受或拒绝状态，$U$ 就接受或拒绝。每步模拟扫描一遍 $\langle M\rangle$，并触碰其余磁带上 $O(\lvert\langle M\rangle\rvert)$ 格，所以 $t$ 步花这台 3 带机器 $O(t \cdot \lvert\langle M\rangle\rvert)$ 次移动，由 [[#thm-multitape]]，单带上是多项式步数。$U$ 恰在 $M$ 停机时停机，结果相同。
:::

通用机器是一个固定的程序，却能运行作为数据交给它的任何其它程序。这正是**存储程序计算机**的思想——指令与数据同放于内存——见约翰·冯·诺依曼（John von Neumann）1945 年的 EDVAC 报告；也是每个解释器的思想（[[programming-1/computation-and-programs]] 展示了 Python 的解释器）。它还使 [[theory-of-computation/decidability]] 核心的自指成为可能：以机器（包括自己）为输入的机器。出人意料的是，极小的通用机器也存在；马文·明斯基（Marvin Minsky）在 1962 年给出一台 7 状态、4 符号的机器。

::: example 双栈机器就是图灵机 {#ex-two-stacks}
拥有*两个*栈的下推自动机（每步可读一个输入符号，并在每个栈上弹出和压入）与图灵机同样强大。说明为什么。
::: solution
*TM 可以模拟双栈 PDA：*每个栈各占一条磁带，栈顶朝右端；由 [[#thm-multitape]]，一条磁带就够了。

*双栈 PDA 可以模拟 TM $M$：*先把输入抄到栈 1（读完全部输入并一路压栈），再把全部内容移到栈 2，于是栈 2 上放着 $w$、$w_1$ 在栈顶。此后图灵机的磁带由两个栈表示：栈 1 存放读头左边各格（最近的一格在栈顶），栈 2 存放读头下方一格及其右边的全部内容（读头格在栈顶）；栈 2 为空表示读头在空白上。移动 $\delta(q, a) = (r, b, R)$ 从栈 2 弹出 $a$，把 $b$ 压上栈 1。移动 $\delta(q, a) = (r, b, L)$ 从栈 2 弹出 $a$，把 $b$ 压回栈 2，再弹出栈 1 的栈顶 $c$（若栈 1 为空，读头已在左端，留在原地），并把 $c$ 压上栈 2。有限控制器跟踪 $M$ 的状态，$M$ 接受时 PDA 接受。于是两个栈给出完整的图灵能力，而一个栈只给出上下文无关语言——记忆力结构的毫厘之差，正是层级鸿沟的鲜明写照。
:::
:::

::: history
艾伦·图灵（Alan Turing）的 "On computable numbers, with an application to the Entscheidungsproblem" 于 1936 年 5 月送交伦敦数学会（London Mathematical Society）受理，1936–37 年发表于该学会的 *Proceedings*。该文定义了图灵机、通用机器和一个不可解问题，并对大卫·希尔伯特（David Hilbert）与威廉·阿克曼（Wilhelm Ackermann）1928 年提出的 *Entscheidungsproblem*（判定问题）——是否存在判定一阶逻辑有效性的算法——给出了否定的回答。阿隆佐·丘奇（Alonzo Church）早在几周前就用 $\lambda$ 演算回答了同一个问题，见 "An unsolvable problem of elementary number theory"（1936）与 "A note on the Entscheidungsproblem"（1936）。埃米尔·波斯特（Emil Post）在 "Finite combinatory processes — formulation 1"（1936）中独立描述了与图灵相近的模型，史蒂芬·克莱尼（Stephen Kleene）发展了递归函数理论，并在 *Introduction to Metamathematics*（1952）中给出论题的经典表述。当时正随丘奇在普林斯顿攻读博士的图灵于 1937 年证明了他的机器与 $\lambda$ 可定义性的等价。
:::

## 后续内容

有了"算法"的精确定义，我们终于能证明某些问题不存在算法。[[theory-of-computation/decidability]] 先说明关于自动机和文法的许多问题可判定，然后用对角化与通用机器证明**停机问题**——给定程序在给定输入上会停机吗——不可判定。[[theory-of-computation/reductions]] 把这一不可能性扩散到关于程序的一大族问题。度量图灵机所需的*资源*——时间与空间——是 [[complexity]] 的主题。

::: summary
- **图灵机**（[[#def-tm]]）有一个有限控制器和一条可以双向读写移动的无界磁带；在任何输入上它**接受**、**拒绝**或**循环**（[[#def-tm-config]]）。
- 某台 TM 恰好接受 $L$ 的串则 $L$ **图灵可识别**；某台总停机的 TM 做到这一点则 $L$ **可判定**（[[#def-recognisable]]）。
- 给机器编程靠标记符号、来回扫描；[[#ex-tm-abc]] 判定 $\{a^nb^nc^n\}$，而任何 PDA 都识别不了它。
- 多带 TM（[[#thm-multitape]]，二次减速）、非确定 TM（[[#thm-ntm]]，计算树的广度优先搜索，指数减速）、枚举器（[[#thm-enumerator]]，交错模拟）与双栈自动机识别的语言全都相同。
- **丘奇–图灵论题**（[[#def-church-turing]]）把算法等同于图灵机；它是关于世界的论题，有证据支持，但不是定理——而且对效率一无所断。
- 机器可以编码成串，**通用 TM**（[[#thm-utm]]）能从描述模拟任何机器：这就是存储程序的思想。
:::

## 习题

::: exercise 数步子 {level=1 check="77"}
[[#ex-tm-abc]] 的机器（按模拟器的实现）在输入 $a^4b^4c^4$ 上移动多少步？（输入数字。）求它在 $a^nb^nc^n$ 上移动步数的公式。
::: solution
模拟器报告 $n = 1, 2, 3$ 时分别移动 $8, 23, 46$ 步。差为 $15, 23$，每次增大 $8$，故步数是二次式 $f(n) = 4n^2 + 3n + 1$；由此 $f(4) = 64 + 12 + 1 = 77$，模拟器证实。推导：第 $k$ 遍（$k = 1, \dots, n$，格子从 $0$ 起编号）从 $q_1$ 位于第 $k$ 个 $a$（第 $k - 1$ 格）开始。它右移到第 $k$ 个 $c$（第 $2n + k - 1$ 格）：$2n$ 步（途中划掉一个 $a$ 和一个 $b$）。划掉这个 $c$ 向左花一步。然后 $q_4$ 左移到第 $k - 1$ 格的 $X$，又 $2n - 1$ 步，再从 $X$ 右移一步开始下一遍。所以每遍 $4n + 1$ 步，$n$ 遍共 $4n^2 + n$ 步。最后 $q_1$ 读到第一个 $Y$，$q_5$ 右移越过 $2n$ 格 $Y$、$Z$，并在空白上走接受的一步：$2n + 1$ 步。总计 $4n^2 + 3n + 1$。
:::
:::

::: exercise 格局追踪 {level=1}
写出 [[#ex-tm-abc]] 的机器在输入 $ab$ 上的格局序列，并说明它如何停机。
::: solution
$q_1ab \vdash Xq_2b \vdash XYq_3\sqcup$。在 $q_3$ 读到 $\sqcup$ 没有转移，按我们的约定即移入 $q_{\text{rej}}$：三步之后拒绝（把拒绝的一步也算在内）。模拟器结果一致，因为 $ab$ 不是 $a^nb^nc^n$ 的形状。
:::
:::

::: exercise 变体 {level=1}
说明移动集为 $\{L, R, S\}$（"原地不动"）的单带 TM 如何被普通 TM 模拟，以及磁带双向无限的 TM 如何被有左端的机器模拟。
::: solution
*原地不动：*把每个转移 $\delta(q, a) = (r, b, S)$ 换成 $\delta(q, a) = (r', b, R)$，其中 $r'$ 是新状态，其转移为对每个 $c$：$\delta(r', c) = (r, c, L)$：先右移一步再立刻退回。（在左端左移会留在原地，所以先右移是安全的顺序。）

*双向无限磁带：*把磁带在第 $0$ 格处折起。单向磁带有两条磁道——每格放一对符号，带字母表为有限的 $\Gamma \times \Gamma$，另加左端标记。上磁道放第 $0, 1, 2, \dots$ 格，下磁道放第 $-1, -2, \dots$ 格。有限控制器记住读头在哪条磁道上；在下磁道上左右互换；而跨越第 $0$ 格与第 $-1$ 格发生在标记的最左格处。
:::
:::

::: exercise 实现描述 {level=2}
给出判定 $\{w\#w : w \in \{0,1\}^*\}$ 的单带 TM 的实现级描述，并说明它在 $O(n^2)$ 时间内运行。
::: solution
来回穿越 $\#$，逐一划掉配对的符号。1. 若 $\#$ 左边第一个未划掉的符号就是 $\#$ 本身（左边已全部划掉），转到第 4 步。否则在状态中记住它（$0$ 或 $1$），用 $x$ 划掉它，右移越过 $\#$ 到右边第一个未划掉的符号。2. 若它与记住的符号不同（或是空白），拒绝；否则划掉它。3. 左移回到最左边的未划掉符号（越过 $\#$ 和已划掉的符号），转到第 1 步。4. 右移越过 $\#$ 和已划掉的符号；下一格是空白则接受，否则拒绝。

每轮划掉两个符号，至多在输入上穿越两趟，$O(n)$ 步；轮数至多 $n/2$；故合计 $O(n^2)$。（已知该语言的每台单带 TM 最坏情况都需要 $\Omega(n^2)$ 时间。）
:::
:::

证明可判定语言类对并、交、补、连接、星封闭，且可识别语言类对并、交、连接、星封闭。
::: solution
设 $M_1, M_2$ 判定 $A_1, A_2$。*补：*交换接受与拒绝。*并/交：*先运行 $M_1$，再运行 $M_2$（都停机），组合答案。*连接：*对 $w = xy$ 的 $n + 1$ 种切法，逐一在 $x$ 上运行 $M_1$、在 $y$ 上运行 $M_2$；某个切法给出两次接受就接受。*星：*对 $w \ne \varepsilon$，尝试把 $w$ 切成非空片段的一切切法（有穷多个，$2^{n-1}$ 种），在每段上运行 $M_1$；$\varepsilon$ 直接接受。

对可能循环的识别器 $M_1, M_2$：*交*——先运行 $M_1$ 再运行 $M_2$（任一循环，$w$ 本来就不属于两者之交）。*并*——先后运行会在"第一个循环而第二个接受"的串上失效；应**并行**运行，两台机器各走一步交替进行，任一接受就接受。*连接与星*——非确定地猜切点（或各切点），在各段上运行识别器，再用 [[#thm-ntm]] 把非确定机器化为确定的；等价地，对所有切法交错模拟。（可识别语言少了*补*这一条，而且事出有因：[[theory-of-computation/decidability]]。）
:::
:::

::: exercise 按序枚举 {level=2}
证明：语言 $L$ 可判定，当且仅当某个枚举器按短字典序枚举它（每个串至多一次，短者在前）。
::: solution
（$\Rightarrow$）若 $M$ 判定 $L$，枚举器按短字典序在 $s_1, s_2, s_3, \dots$ 上运行 $M$，打印被接受的串。每次运行都停机，故枚举器到达每个串，且顺序为短字典序。

（$\Leftarrow$）若 $L$ 有穷则可判定（机器可把有穷清单存在状态里）。否则设 $E$ 按短字典序枚举 $L$。在输入 $w$ 上运行 $E$，直到它打印出 $w$（接受）或某个短字典序在 $w$ 之后的串（拒绝）。因 $L$ 无穷且按递增顺序打印，两事必有其一在有限步内发生；且第二种情形下 $w$ 之后不可能再被打印。故这台机器是判定器。
:::
:::

::: exercise 队列自动机 {level=3}
**队列自动机**形如 PDA，但把栈换成队列：可以在队尾添加符号、从队头移除符号。证明队列自动机（控制器是确定的，初始时队列中放着输入）与图灵机等价。
::: solution
TM 在磁带上模拟队列很容易：把队列内容夹在两个标记之间，在右端写符号即添加，擦掉最左符号并把左标记右移一格即移除。所以队列自动机只识别可识别语言。

反之，队列自动机 $A$ 模拟 TM $M$。队列以一条循环串存放 TM 的磁带内容，读头格带标记 $\dot a$，并带端标记 $\$$：$\$\, t_1 t_2 \cdots \dot t_h \cdots t_m$。模拟一步时，$A$ 旋转队列——不断从队头移除符号、加到队尾——直到带标记的符号到达队头，应用 $M$ 的转移，再带着移动后的标记把符号加回去。右移很容易：移除 $\dot t_h$，加入新符号 $b$，等下一个符号转到队头时给它加标记（若轮到 $\$$，先补一个带标记的空白格再重加 $\$$，磁带随之加长）。左移需要给*前一个*符号加标记，而它已经转到队尾去了；标准技巧是让每个符号都延迟一位——控制器记住上一个移除的符号，等看到再下一个符号时才把它加回——这样当 $\dot t_h$ 到达队头时，它的左邻还在控制器里，可以带标记加回。每步模拟耗费一次旋转，$O(m)$ 次队列操作。控制器跟踪 $M$ 的状态，$M$ 接受时 $A$ 接受。
:::
:::

::: exercise 忙海狸 {level=3}
设 $\mathrm{BB}(n)$ 为如下 $n$ 状态图灵机所走步数的最大值：带字母表为 $\{0, 1\}$（$0$ 为空白），从双向无限的全零磁带开始运行且会停机（停机状态不计入 $n$；停机那一步计入）。（a）证明 $\mathrm{BB}(1) = 1$。（b）证明 $\mathrm{BB}(n)$ 对每个 $n$ 都有定义。（c）利用双向无限磁带和上文的模拟器思路，实际运行验证 2 状态机器 $A0 \to 1RB$，$A1 \to 1LB$，$B0 \to 1LA$，$B1 \to 1RH$ 在 $6$ 步后停机并留下四个 $1$。（已知 $\mathrm{BB}(2) = 6$；$\mathrm{BB}(5) = 47{,}176{,}870$ 于 2024 年确立，附带机器检验的证明。）
::: solution
（a）只有一个状态 $A$，机器的第一步读到 $0$。若在 $0$ 上的转移停机，机器一步就停机。否则它是 $A0 \to bDA$（某个 $b$ 和方向 $D$）：机器留在 $A$ 并移到一个从未访问过的格，那里是 $0$；于是它重复同一动作，再重复，永远沿方向 $D$ 移动。故每台停机的单状态机器都在第一步停机，$\mathrm{BB}(1) = 1$。

（b）$n$ 状态机器只有有穷多台（$2n$ 条转移，每条有 $2 \cdot 2 \cdot (n + 1)$ 种选择），其中在空白磁带上停机的也只有有穷多台；有穷个数的最大值存在。它有定义但*不可计算*：能计算 $\mathrm{BB}$ 的程序就能解决空白磁带上的停机问题（[[theory-of-computation/decidability]]）。

（c）用一个字典充当双向磁带：

```python
def busy(delta, limit=1000):
    tape, head, q, steps = {}, 0, "A", 0
    while q != "H" and steps < limit:
        write, move, q = delta[q, tape.get(head, 0)]
        tape[head] = write
        head += 1 if move == "R" else -1
        steps += 1
    return steps, sum(tape.values())

BB2 = {("A", 0): (1, "R", "B"), ("A", 1): (1, "L", "B"),
       ("B", 0): (1, "L", "A"), ("B", 1): (1, "R", "H")}
print(busy(BB2))
```

```console
$ python3 busy.py
(6, 4)
```

六步，磁带上四个 $1$。
:::
