一次一密是完美安全的，而 [[cryptography/perfect-secrecy#thm-key-length]] 证明了它巨大的密钥不可避免：没有完美保密的方案能加密的消息比特数超过它的密钥比特数。然而你的浏览器每天都在一把 128 位密钥之下加密数以吉字节计的数据。要么那些连接并不安全，要么"安全"另有含义，不是完美保密。

它的含义更弱、却完全够用。密钥长度定理的证明用了一个把每个密钥都试一遍的对手——对 128 位密钥要做 $2^{128}$ 次试探解密。以每秒 $10^{18}$ 次的速率——远超截至 2026 年任何已存在的计算机——也要约 $1.1 \times 10^{13}$ 年，约为宇宙年龄的八百倍。一个对一切实际造得出来的对手都成立的保证，正是所有人所需要的。**计算安全**用两处放宽把它讲精确：对手在**可行**时间内运行，并且它至多能以超出乱猜一个**可忽略**的概率得手。作为交换，密钥可以很短，短随机密钥可以被拉长成一条长的**伪随机**密钥。本章定义可忽略函数与计算安全，引入**伪随机生成器**（PRG）、**伪随机函数**（PRF）与**伪随机置换**（PRP），并展开现代密码学的主要证明技术：**归约**——表明破译方案会破坏我们相信的某个假设。随机化算法与概率估计参见 [[algorithms/randomised-algorithms]]。

## 高效对手与可忽略的成功概率

陈述计算性保证有两种方式。**具体**方式直接给出数字：若每个至多运行 $t$ 步的对手的成功概率至多比平凡的猜测高出 $\varepsilon$，则称方案是 **$(t, \varepsilon)$-安全**的。对均匀的 128 位密钥做穷尽搜索，运行 $t$ 次试探解密，找到密钥的概率为 $t/2^{128}$，所以没有使用 128 位密钥的方案能比 $(t, t/2^{128})$-安全更好；好的方案则逼近它。具体陈述正是实践者所需要的，但它依赖于机器模型和特定密钥长度。

**渐近**方式——我们在定义和证明中采用的方式——引入**安全参数** $n \in \N$，可以把它理解为密钥长度——以一元形式 $1^n$ 交给每个算法，从而"输入长度的多项式"就是"$n$ 的多项式"。诚实方与对手一律是**概率多项式时间**（PPT）算法：运行时间被 $n$ 的多项式界住的随机化算法。而对手的优势必须比任何多项式的倒数消失得更快。

::: definition 可忽略函数 {#def-negligible}
若对每个多项式 $p$ 都存在 $N$，使对所有 $n > N$ 有 $\varepsilon(n) < 1/p(n)$，则称函数 $\varepsilon\colon \N \to \R_{\ge 0}$ 是**可忽略的**。等价地，对每个常数 $c > 0$，充分大的 $n$ 都有 $\varepsilon(n) < n^{-c}$。记 $\mathsf{negl}(n)$ 表示一个未指明的可忽略函数。
:::

$2^{-n}$、$2^{-\sqrt n}$ 和 $n^{-\log n}$ 是可忽略的；$n^{-10}$ 和 $1/n^{1000}$ 不是。这样定义，是为了让多项式多次尝试无法把可忽略的成功概率变成明显的。

::: proposition 封闭性 {#prop-negl-closure}
若 $\varepsilon_1$ 和 $\varepsilon_2$ 可忽略，$p$ 是满足 $p(n) \ge 0$ 的多项式，则 $\varepsilon_1 + \varepsilon_2$ 与 $p \cdot \varepsilon_1$ 可忽略。
:::

::: proof
设 $q$ 为任意多项式；可设 $n$ 大时 $q(n) \ge 1$（把 $q$ 换成 $q^2 + 1$ 只会让结论更强）。对和：因 $2q$ 是多项式，充分大的 $n$ 有 $\varepsilon_1(n) < 1/(2q(n))$ 和 $\varepsilon_2(n) < 1/(2q(n))$，故 $\varepsilon_1(n) + \varepsilon_2(n) < 1/q(n)$。对积：$p \cdot q$ 被某个满足 $r(n) \ge 1$ 的多项式 $r$ 控制（取 $r = p\cdot q + 1$），充分大的 $n$ 在 $p(n) > 0$ 处 $\varepsilon_1(n) < 1/r(n) \le 1/(p(n)q(n))$；于是 $p(n)\varepsilon_1(n) < 1/q(n)$（在 $p(n) = 0$ 处它为 $0$）。
:::

第二个性质最重要。若单次尝试以可忽略概率 $\varepsilon$ 成功，则由并集界，$p(n)$ 次尝试成功的概率至多 $p(n)\varepsilon(n)$，仍然可忽略。多项式时间的对手无法把可忽略的机会放大成真正的机会——而像 $1/n^{10}$ 这样不可忽略的优势却*能*靠重复放大，所以它算作破译。

### 不可区分的加密

我们现在保留 [[cryptography/perfect-secrecy#def-perfect-indist]] 的博弈，只放宽它的结论。除了把对手限制为 PPT，还需要两处改动。消息必须**等长**，因为能处理任意长度的加密方案藏不住长度（而且密文与消息一样长本就是常态）。而成功只需接近 $1/2$。

::: definition EAV-安全 {#def-eav}
私钥加密方案 $\Pi = (\mathsf{Gen}, \mathsf{Enc}, \mathsf{Dec})$（其中 $\mathsf{Gen}(1^n)$ 输出密钥）若有如下性质：对每个 PPT 对手 $\mathcal A$ 存在可忽略函数 $\mathsf{negl}$ 使
$$
\Prob\big[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A, \Pi}(n) = 1\big] \le \tfrac12 + \mathsf{negl}(n),
$$
其中实验中 $\mathcal A(1^n)$ 输出消息 $m_0, m_1$ 且 $\lvert m_0\rvert = \lvert m_1\rvert$，收到 $k \gets \mathsf{Gen}(1^n)$ 与均匀 $b$ 之下的 $c \gets \mathsf{Enc}_k(m_b)$，输出 $b' = b$ 即为成功，则称 $\Pi$ **在窃听者存在时加密不可区分**（**EAV-安全**）。
:::

戈德瓦瑟（Goldwasser）与米卡利（Micali）（1984）还定义了**语义安全**：PPT 对手能从密文算出的任何关于明文的信息，没有密文它也照样能算出来。他们证明了它与不可区分性等价，而后者远为好用，所以我们采用不可区分性作为定义。

## 伪随机生成器

一次一密需要长的均匀密钥。要是我们改用短而均匀的种子，再用一个确定性算法把它拉长成一条对每个高效观察者都*看起来*均匀的长串，会怎样？

::: definition 伪随机生成器 {#def-prg}
设 $\ell$ 是满足 $\ell(n) > n$ 的多项式。若确定性多项式时间算法 $G$ 把 $s \in \{0, 1\}^n$ 映为 $G(s) \in \{0, 1\}^{\ell(n)}$，并且对每个 PPT 算法 $D$（**区分器**）存在可忽略函数使
$$
\Big\lvert \Prob_{s \gets \{0,1\}^n}\big[D(G(s)) = 1\big] - \Prob_{r \gets \{0,1\}^{\ell(n)}}\big[D(r) = 1\big]\Big\rvert \le \mathsf{negl}(n),
$$
则称 $G$ 是**膨胀因子**为 $\ell$ 的**伪随机生成器**。左端称为 $D$ 的**优势**。
:::

PRG 的输出在信息论意义下离均匀很远：在 $2^{\ell(n)}$ 个串中它至多取 $2^n$ 个值，所以一个无界区分器只要问"$r$ 在不在 $G$ 的像里？"，优势就至少 $1 - 2^{n - \ell(n)} \ge 1/2$。伪随机是关于*高效*检验能看到什么的一种陈述。

::: example 一个不是伪随机的生成器 {#ex-not-prg}
设 $G(s) = s \,\|\, (s_1 \oplus s_2 \oplus \dots \oplus s_n)$：种子后面接上它的奇偶校验位，故 $\ell(n) = n + 1$。找出一个区分器并计算其优势。
::: solution
令 $D(y)$：若 $y$ 的最后一位等于前 $n$ 位的异或则输出 $1$，否则输出 $0$。在 $y = G(s)$ 上这总是成立：$\Prob[D(G(s)) = 1] = 1$。在均匀的 $r \in \{0, 1\}^{n+1}$ 上，最后一位均匀且与其余位独立，故恰以概率 $\tfrac12$ 与奇偶校验相符。优势为 $\lvert 1 - \tfrac12\rvert = \tfrac12$，不可忽略。任何是其余位*线性*函数的输出位都会这样被逮住；更一般地，PRG 必须经受一切高效统计检验，而不只是设计者想到的那些。
:::
:::

PRG 存在吗？没有人知道如何证明：存在 $\ell(n) > n$ 的 PRG 将蕴含 $\mathsf P \ne \mathsf{NP}$（判定一个串是否落在 $G$ 的像里属于 $\mathsf{NP}$，而一个高效判定程序就是区分器）。已知的是：PRG 存在**当且仅当**单向函数存在——易于计算、却在随机输入上难以求逆的函数（Håstad、Impagliazzo、Levin 与 Luby，1999）。实践中我们使用**流密码**，如 ChaCha20（Bernstein 2008，标准化为 RFC 8439）或计数器模式的 AES（[[cryptography/block-ciphers]]）；我们相信它们是伪随机的，依据是数十年的公开分析未能找到高效的区分器。下面的所有定理因此都是*有条件*的：若原语安全，则构造也安全。

### 用伪随机密码本加密

::: definition 伪一次一密 {#def-pseudo-otp}
设 $G$ 是膨胀因子为 $\ell$ 的 PRG。对消息 $m \in \{0, 1\}^{\ell(n)}$：$\mathsf{Gen}(1^n)$ 输出均匀的 $k \in \{0, 1\}^n$；$\mathsf{Enc}_k(m) = G(k) \oplus m$；$\mathsf{Dec}_k(c) = G(k) \oplus c$。
:::

::: theorem 伪一次一密是 EAV-安全的 {#thm-pseudo-otp}
若 $G$ 是伪随机生成器，则 [[#def-pseudo-otp]] 的方案是 EAV-安全的。
:::

::: proof
这是一次**归约**：从方案的任意对手 $\mathcal A$ 出发，我们构造 $G$ 的区分器 $D$，并证明 $\mathcal A$ 的成功会转化为 $D$ 的优势。$D$ 收到一个串 $w \in \{0, 1\}^{\ell(n)}$，做以下事情：

1. 运行 $\mathcal A(1^n)$ 得到 $m_0, m_1 \in \{0, 1\}^{\ell(n)}$。
2. 选均匀的比特 $b$，把密文 $c = w \oplus m_b$ 交给 $\mathcal A$。
3. $\mathcal A$ 输出 $b'$ 后，若 $b' = b$ 则输出 $1$，否则输出 $0$。

$D$ 多项式时间运行，因为 $\mathcal A$ 是。考虑它两种可能的输入。

- 若 $w = G(k)$、$k$ 均匀，则 $c$ 的分布与 $\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A, \Pi}(n)$ 中完全一致，故 $\Prob[D(G(k)) = 1] = \Prob[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A, \Pi}(n) = 1]$。
- 若 $w$ 均匀，则 $\mathcal A$ 面对的是一次一密，它完美保密（[[cryptography/perfect-secrecy#thm-otp]]）；由 [[cryptography/perfect-secrecy#thm-indist-equiv]]，$\mathcal A$ 恰以概率 $\tfrac12$ 得手。于是 $\Prob[D(w) = 1] = \tfrac12$。

因此
$$
\Prob\big[\mathsf{PrivK}^{\mathsf{eav}}_{\mathcal A, \Pi}(n) = 1\big] - \tfrac12 = \Prob[D(G(k)) = 1] - \Prob[D(w) = 1] \le \mathsf{negl}(n),
$$
因为 $G$ 是 PRG 而 $D$ 是 PPT。
:::

::: example 弱生成器会毁掉密码本 {#ex-weak-pad}
设某个粗心的生成器 $G$ 有一个卡死的输出位：$G(s)$ 的最后一位对所有种子都是 $0$，其余位则无碍。直接证明用 $G$ 构造的伪一次一密不是 EAV-安全的，并计算对手的成功概率。再设 $G(s)$ 的最后一位改为对种子而言以概率 $0.6$ 取 $0$，计算同一对手的成功概率。
::: solution
令 $\mathcal A$ 输出 $m_0 = 0^{\ell}$ 和 $m_1 = 0^{\ell - 1}1$，两者只差最后一位，并令 $b'$ 等于 $c$ 的最后一位。由于 $c = G(k) \oplus m_b$ 的最后一位是 $0 \oplus b = b$，$\mathcal A$ 永远正确：成功概率 $1$。

若 $G(k)$ 的最后一位以概率 $0.6$ 为 $0$，则 $c$ 的最后一位以概率 $0.6$ 等于 $b$，同一对手以概率 $0.6 = \tfrac12 + 0.1$ 成功。在 [[#thm-pseudo-otp]] 的归约中，对应的区分器 $D$ 的优势恰为 $0.1$：它在 $G(k)$ 上以概率 $0.6$ 输出 $1$，在均匀串上以概率 $\tfrac12$。一个比特上 $0.1$ 的偏置是常数——不可忽略——方案即被破译。这个例子同时说明归约是*紧*的：对手超出 $\tfrac12$ 的优势恰等于区分器的优势。
:::
:::

反过来说读这个证明：能击败方案的对手，会给出一个把 $G$ 的输出与真随机分辨开来的高效检验。只要我们相信这样的检验不存在，方案就是安全的。本课程每一处安全性证明都是这个形状。

::: warning "可证明安全"是什么意思
像 [[#thm-pseudo-otp]] 这样的证明并不表明方案破不了。它表明的只是：破译该方案*至少和*破译某个假设（这里是 $G$ 是 PRG）*一样难*，而且是在*定义的攻击模型内*（这里是一条被窃听的密文）。假若不成立、攻击者能做的超出模型允许（见下面的多消息攻击）、或实现通过模型从未提及的渠道——计时、功耗、错误消息、播种不当的随机数发生器——泄露了信息，方案照样可能失败。渐近陈述还藏着常数："可忽略"丝毫没有说明 $n = 128$ 够不够大。证明弥足珍贵，因为它把含混的担忧变成精确的假设；但在真实系统里，剩下的缺口正是你必须使用经评审的库和标准构造、而绝不自己设计或实现方案的原因。
:::

### 多条消息

伪一次一密是确定性的：同一密钥下同一消息加密两次得到同一密文，两条不同消息的密文异或起来就是 $m_1 \oplus m_2$，和两次一密一模一样。定义的一个自然加强允许对手看到一*列表*消息的加密；于是没有确定性方案是安全的，因为对手可以提交列表 $(m, m)$ 与 $(m, m')$，再检查两组密文是否相等。一把密钥下安全地加密多条消息需要**随机化**（或带状态的）加密，以及一种随用随取、源源不断产生新伪随机密码本的工具。这个工具就是伪随机函数。

::: quiz
下列 $n$ 的函数哪些是可忽略的？（多选。）

- [x] $2^{-n/2}$
- [ ] $n^{-100}$
- [x] $n^{-\log_2 n}$
- [ ] $1/(n^3 + 5n)$
::: solution
$2^{-n/2}$ 是可忽略的：对每个 $c$，$n^c 2^{-n/2} \to 0$。$n^{-\log_2 n} = 2^{-(\log_2 n)^2}$ 是可忽略的，因为 $(\log_2 n)^2$ 终会超过任何常数 $c$ 倍的对数 $c\log_2 n$。$n^{-100}$ 和 $1/(n^3 + 5n)$ 是多项式的倒数，因此不可忽略：有这种优势的对手能靠重复把它放大。
:::
:::

## 混合论证

证明常常通过一串彼此邻近的中间**混合**分布，把真实分布与理想分布连起来比较。下面这个例子既展示了这一技术，也说明如何把 PRG 拉长得更多。

::: theorem 把膨胀翻倍 {#thm-prg-double}
设 $G\colon \{0, 1\}^n \to \{0, 1\}^{2n}$ 是 PRG。把 $G(s) = G_0(s) \,\|\, G_1(s)$ 写成两个 $n$ 位的一半。则
$$
G'(s) = G\big(G_0(s)\big) \,\|\, G\big(G_1(s)\big) \in \{0, 1\}^{4n}
$$
是 PRG。
:::

::: proof
设 $D$ 是对 $G'$ 的 PPT 区分器。在 $4n$ 位串上定义四个分布，其中 $s \in \{0,1\}^n$、$r_0, r_1 \in \{0, 1\}^n$、$u_0, u_1 \in \{0, 1\}^{2n}$ 均匀且相互独立：
$$
H_0 = G(G_0(s)) \,\|\, G(G_1(s)), \quad H_1 = G(r_0) \,\|\, G(r_1), \quad H_2 = G(r_0) \,\|\, u_1, \quad H_3 = u_0 \,\|\, u_1 .
$$
$H_0$ 是 $G'$ 的输出，$H_3$ 是均匀的。记 $p_i = \Prob[D(H_i) = 1]$。由三角不等式，$D$ 的优势为
$$
\lvert p_0 - p_3\rvert \le \lvert p_0 - p_1\rvert + \lvert p_1 - p_2\rvert + \lvert p_2 - p_3\rvert ,
$$
而每一项都是某个对 $G$ 的 PPT 区分器的优势：

- $D_1(y)$ 收到 $y \in \{0, 1\}^{2n}$，把 $y$ 拆成 $y = y_0 \| y_1$，输出 $D(G(y_0) \| G(y_1))$。若 $y = G(s)$，这就是 $D(H_0)$；若 $y$ 均匀，则 $y_0, y_1$ 均匀且独立，这就是 $D(H_1)$。所以 $\lvert p_0 - p_1\rvert$ 是 $D_1$ 的优势。
- $D_2(y)$ 自己取均匀的 $r_0$，输出 $D(G(r_0) \| y)$：在 $y = G(r_1)$ 上它看到的是 $H_1$，在均匀 $y$ 上看到的是 $H_2$。
- $D_3(y)$ 自己取均匀的 $u_1$，输出 $D(y \| u_1)$：在 $y = G(r_0)$ 上它看到的是 $H_2$，在均匀 $y$ 上看到的是 $H_3$。

因为 $G$ 是 PRG，每个优势都可忽略；三个可忽略函数之和仍可忽略（[[#prop-negl-closure]]）。
:::

把上述构造重复 $d$ 次，可建起一棵深 $d$ 的二叉树，它的 $2^d$ 个叶子都是伪随机的。混合论证对多项式多个混合依然成立，优势至多按那个多项式因子增长——仍然可忽略。Goldreich、Goldwasser 与 Micali（1986）更进一层：他们用从根到叶子 $x$ 的路径来*定义*一个有指数多个输出的函数 $F_s(x)$，其中任何一个输出都可以沿树走下 $n$ 层、用 $n$ 的多项式时间算出。那就是伪随机函数。

## 伪随机函数与置换

**密钥函数**指可有效计算的 $F\colon \{0, 1\}^n \times \{0, 1\}^n \to \{0, 1\}^n$；记 $F_k(x) = F(k, x)$，密钥 $k$ 均匀选取。令 $\mathsf{Func}_n$ 为从 $\{0,1\}^n$ 到 $\{0,1\}^n$ 的*所有*函数之集。描述其中一个需要一张 $2^n$ 项、每项 $n$ 位的表，所以 $\lvert\mathsf{Func}_n\rvert = 2^{n2^n}$ ——对 $n = 128$，一份 $128 \cdot 2^{128}$ 位的描述，密钥却只有 128 位。PRF 就是这样一种密钥函数：即使对手可以对自己挑选的输入查询函数值，也没有高效算法能把它与这个巨大集合中均匀随机抽取的一个元素分辨开来。

::: definition 伪随机函数 {#def-prf}
若高效密钥函数 $F$ 满足：对每个有预言机访问权的 PPT 区分器 $D$ 存在可忽略函数使
$$
\Big\lvert \Prob_{k \gets \{0,1\}^n}\big[D^{F_k(\cdot)}(1^n) = 1\big] - \Prob_{f \gets \mathsf{Func}_n}\big[D^{f(\cdot)}(1^n) = 1\big]\Big\rvert \le \mathsf{negl}(n),
$$
则称 $F$ 是**伪随机函数**。这里 $D^{O}$ 表示 $D$ 可以向**预言机** $O$ 自适应地提交任意输入 $x$ 并收到 $O(x)$；它始终看不到 $k$。
:::

不能把 $f$ 本身交给区分器——它长得离谱——所以定义使用预言机访问。随机函数可以用**惰性采样**模拟：对每个新查询 $x$ 给一个新的均匀 $n$ 位值并记住它；重复的查询按记住的答案一致作答。

::: example 一个不是伪随机的密钥函数 {#ex-not-prf}
证明 $F_k(x) = k \oplus x$ 不是 PRF：给出区分器并计算其优势。
::: solution
$D$ 查询 $y_0 = O(0^n)$ 和 $y_1 = O(1^n)$，若 $y_0 \oplus y_1 = 1^n$ 就输出 $1$。若 $O = F_k$，则 $y_0 \oplus y_1 = (k \oplus 0^n) \oplus (k \oplus 1^n) = 1^n$ 恒成立，$D$ 以概率 $1$ 输出 $1$。若 $O = f$ 是随机的，$y_0$ 与 $y_1$ 独立且均匀，$y_0 \oplus y_1$ 均匀，等于 $1^n$ 的概率是 $2^{-n}$。优势为 $1 - 2^{-n}$。单个输出值 $F_k(x)$ *是*均匀的——这个函数之所以失败，在于它的输出值彼此相关。伪随机性讲的是多个输入上的联合行为。
:::
:::

PRF 是对称密码的主力。由 PRF 立即可得 PRG——GGM 构造的反方向。

::: proposition 由 PRF 得 PRG {#prop-prf-prg}
设 $F$ 是 PRF，$t = t(n)$ 是满足 $t \ge 2$ 的多项式，记 $\langle i\rangle$ 为 $i$ 的 $n$ 位二进制表示。则 $G(s) = F_s(\langle 1\rangle) \,\|\, F_s(\langle 2\rangle) \,\|\, \dots \,\|\, F_s(\langle t\rangle)$ 是膨胀因子为 $tn$ 的 PRG。
:::

::: proof
设 $D$ 是对 $G$ 的区分器。构造带预言机 $O$ 的 $D'$：查询 $O(\langle 1\rangle), \dots, O(\langle t\rangle)$，把答案拼成 $y$，输出 $D(y)$。若 $O = F_s$、$s$ 均匀，则 $y = G(s)$。若 $O = f$ 在 $\mathsf{Func}_n$ 中均匀，则它在 $t$ 个不同输入上的值独立且均匀，于是 $y$ 是均匀的 $tn$ 位串。故 $D$ 的优势等于 $D'$ 的优势，而后者因 $F$ 是 PRF、$D'$ 是 PPT 而可忽略。
:::

这正是 [[cryptography/block-ciphers]] 中**计数器模式**背后的思想：对逐个递增的计数器调用 PRF，就能得到任意长的伪随机密码本；而随机的起点使每次加密都用一条新密码本。

### 置换

像 AES 这样的分组密码，在每个密钥下都是既带密钥又是**置换**的函数：$F_k$ 是 $\{0, 1\}^n$ 上的双射，且从 $k$ 可有效计算 $F_k^{-1}$——这正是解密成为可能的原因。令 $\mathsf{Perm}_n$ 为 $\{0, 1\}^n$ 的所有置换之集；它有 $(2^n)!$ 个元素。

::: definition 伪随机置换 {#def-prp}
若高效密钥置换 $F$（带高效求逆）满足：没有对 $F_k$ 有预言机访问权的 PPT 区分器能以不可忽略的优势把它与 $\mathsf{Perm}_n$ 中均匀的 $\pi$ 区分开，则称 $F$ 是**伪随机置换**。若即使区分器对 $F_k$ 和 $F_k^{-1}$（相应地 $\pi$ 与 $\pi^{-1}$）都有预言机访问权，结论仍成立，则称其为**强**伪随机置换。
:::

随机置换与随机函数能区分吗？置换从不把两个输入映到同一输出；随机函数却偶尔会。但在大约 $2^{n/2}$ 次查询之前，随机函数中的碰撞都很罕见——生日界，[[cryptography/hash-mac]] 中有精确计算。

::: lemma PRP/PRF 切换引理 {#lem-switching}
对任意至多作 $q$ 次预言机查询的区分器 $D$，
$$
\Big\lvert \Prob_{f \gets \mathsf{Func}_n}\big[D^{f} = 1\big] - \Prob_{\pi \gets \mathsf{Perm}_n}\big[D^{\pi} = 1\big]\Big\rvert \le \frac{q(q - 1)}{2^{n+1}} .
$$
于是 PRP 也是 PRF（$q$ 为多项式时该界可忽略）。
:::

::: proof
可设 $D$ 从不重复查询（它能记住答案）。两个预言机都用惰性采样运行，由同一串均匀的 $n$ 位值 $y_1, y_2, \dots, y_q$ 驱动：

- *函数博弈：* 第 $i$ 次查询的答案就是 $y_i$。
- *置换博弈：* 第 $i$ 次查询的答案在 $y_i$ 与先前所有答案都不同时取 $y_i$；否则从尚未用过的值中均匀另选一个。

置换博弈用互不相同的值作答，每个都在未用过的值上均匀——这恰是 $\pi$ 在 $q$ 个不同点上的分布；函数博弈就是 $f$。设 $\mathsf{Bad}$ 为存在 $j < i$ 使 $y_i = y_j$ 的事件。$\mathsf{Bad}$ 发生之前两个博弈的回答完全相同，$D$ 的行为也相同；而 $\mathsf{Bad}$ 只依赖于诸 $y$，在两个博弈中概率相同。于是 $D$ 输出 $1$ 的两个概率之差不超过 $\Prob[\mathsf{Bad}]$。对每一对作并集界：
$$
\Prob[\mathsf{Bad}] \le \sum_{i=1}^{q}\frac{i - 1}{2^n} = \frac{q(q - 1)}{2 \cdot 2^n} .
$$
至于推论：由三角不等式，区分器在 $F_k$ 与 $f$ 之间的优势至多是它在 $F_k$ 与 $\pi$ 之间的优势（可忽略）加上 $q(q - 1)/2^{n+1}$（$q$ 为多项式时可忽略）。
:::

::: example 一把密钥配多少数据？ {#ex-data-per-key}
某协议要求 [[#lem-switching]] 的切换界保持在 $2^{-32}$ 以下。使用 (a) 64 位分组密码、(b) 分组为 128 位的 AES 时，一把密钥下最多可加密多少个分组？用字节表示答案。
::: solution
需要 $q^2/2^{n+1} \le 2^{-32}$，大致 $q \le 2^{(n - 31)/2}$。(a) $n = 64$：$q \le 2^{16.5} \approx 92\,682$ 个 $8$ 字节分组，约 $724$ KiB。(b) $n = 128$：$q \le 2^{48.5} \approx 4.0 \times 10^{14}$ 个 $16$ 字节分组，约 $6.4 \times 10^{15}$ 字节，即 $5.7$ PiB。真实协议会设定这一类的限额；例如 TLS 1.3（RFC 8446，§5.5）限制了单把 AES-GCM 密钥保护的数据量，并要求在触限之前更新密钥。这些数字也解释了从 64 位分组走向 128 位分组为何如此重要。
:::
:::

::: quiz
一个区分器对 $\{0, 1\}^{64}$ 上的一致随机函数或一致随机置换获得预言机访问，共作 $2^{20}$ 次查询。哪个数最接近可能的最好优势？

- [ ] $1/2$
- [x] 约 $2^{-25}$
- [ ] 约 $2^{-44}$
- [ ] 恰为 $0$，因为两者回答都是均匀的
::: solution
引理给出 $q(q-1)/2^{n+1} \approx 2^{40}/2^{65} = 2^{-25}$，而这个界基本是紧的：看到碰撞就输出"函数"的区分器，其优势接近碰撞概率 $1 - e^{-q(q-1)/2^{65}} \approx 2^{-25}$。每次单独的回答在两种情形下都是均匀的，但只有函数会重复输出值。
:::

## 实践中

真实的原语没有被证明是伪随机的；人们根据公开密码分析的成果猜想它们是。截至 2026 年，标准选择是 AES（$n = 128$、密钥 128、192 或 256 位的强 PRP）与 ChaCha20（流密码，实际上是从 256 位密钥与计数器到 512 位分组的 PRF）；更老的 RC4 流密码因被发现输出有偏，已被 RFC 7465（2015）在 TLS 中禁用。对称密钥通常至少 128 位，在需要对抗量子搜索的余量时用 256 位（[[cryptography/post-quantum]]）。本章的证明告诉我们*如何*安全地*使用*这些原语；至于 AES 本身是不是 PRP，那是证据问题，不是证明问题。

::: history
香农 1949 年的论文已经在问计算能力有限的对手能做什么，但现代框架来自复杂性理论。姚期智（Yao）（1982）用针对高效检验的不可区分性定义了伪随机。《概率加密》（"Probabilistic encryption"，戈德瓦瑟（Goldwasser）与米卡利（Micali），*Journal of Computer and System Sciences*，1984；会议版 1982）引入了语义安全、不可区分性与随机化加密，二人后来因此获得 2012 年图灵奖。Manuel Blum 与米卡利（Micali）（1984）从数论困难性假设出发构造了第一个 PRG。Oded Goldreich、戈德瓦瑟与米卡利定义了伪随机函数，并从任意 PRG 出发构造出它们（*Journal of the ACM*，1986）。Michael Luby 与 Charles Rackoff（1988）定义了伪随机置换，并展示了如何用 Feistel 网络从 PRF 构造它们（[[cryptography/block-ciphers]]）。Håstad、Impagliazzo、Levin 与 Luby（*SIAM Journal on Computing*，1999）证明：只要存在单向函数，就存在 PRG。具体安全的观点由 Bellare、Rogaway 等人于 1990 年代发展起来。
:::

## 后续内容

[[cryptography/block-ciphers]] 把 AES 建模为强 PRP，定义了对**选择明文攻击**（对手还获得加密预言机）的安全性，并用随机化的计数器模式从 PRF 构造 CPA-安全的加密。[[cryptography/hash-mac]] 用 PRF 构造消息认证码，并算出 [[#lem-switching]] 背后的生日界。[[cryptography/public-key]] 中的公钥加密立足同样的归约技术，只是用数论性假设取代伪随机性。复杂性理论的一面——单向函数、困难度放大，以及为什么证明这些原语中任何一个的存在都会把 $\mathsf P$ 与 $\mathsf{NP}$ 分开——在 [[complexity]] 中。

::: summary
- **计算安全**把对手限制为概率多项式时间，并允许**可忽略**的优势——比每个多项式的倒数都小（[[#def-negligible]]）。可忽略函数对求和与乘以多项式封闭（[[#prop-negl-closure]]），所以重复无法把它放大。
- **EAV-安全**是消息等长、成功概率至多 $\tfrac12 + \mathsf{negl}(n)$ 的不可区分博弈（[[#def-eav]]）；它与语义安全等价。
- **PRG** 把短种子拉成没有高效检验能与均匀区分的输出（[[#def-prg]]）；把它与消息异或即 EAV-安全，证明是向 PRG 的**归约**（[[#thm-pseudo-otp]]）。这类证明以假设和模型为条件。
- **混合论证**串起一串分布；例如它表明 PRG 的膨胀可以加大（[[#thm-prg-double]]）。
- **PRF** 在自适应查询下与随机函数不可区分（[[#def-prf]]）；对计数器求值即得 PRG（[[#prop-prf-prg]]）。**PRP**（带求逆查询的强 PRP）建模分组密码（[[#def-prp]]），且 PRP 在 $q(q-1)/2^{n+1}$ 的误差内是 PRF（[[#lem-switching]]）。
- 确定性加密不可能对多条消息安全；安全的多消息加密需要随机性——下一章的主题。
:::

## 习题

::: exercise 辨认可忽略函数 {level=1}
对每个函数判断它是否可忽略，并用一句话说明理由：(a) $2^{-\log_2 n}$；(b) $n^{-\log_2\log_2 n}$；(c) $10^{-6}$（常数）；(d) $2^{-n}\cdot n^{50}$。
::: solution
(a) $2^{-\log_2 n} = 1/n$，多项式的倒数：不可忽略。(b) $n^{-\log_2\log_2 n}$：对每个 $c$，充分大的 $n$ 有 $\log_2\log_2 n > c$，所以它终在 $n^{-c}$ 之下：可忽略（尽管衰减极慢）。(c) 非零常数对大的 $n$ 从不低于 $1/n$：不可忽略——渐近意义下，固定百万分之一的机会就是一次破译。(d) $n^{50}2^{-n}$ 是多项式乘以可忽略函数，由 [[#prop-negl-closure]] 可忽略。
:::
:::

::: exercise 具体算一笔穷尽搜索 {level=1 check="14"}
攻击者每秒可测试 $10^{18}$ 个密钥。穷尽 $2^{80}$ 个密钥要花多少天？（填入天数，四舍五入到整天。）
::: solution
$2^{80} \approx 1.209 \times 10^{24}$，所以搜索需 $1.209 \times 10^{6}$ 秒，约 $13.99$ 天，即 $14$ 天。对 128 位密钥，同一攻击者需要 $2^{128}/10^{18}$ 秒 $\approx 1.08 \times 10^{13}$ 年。每多一个密钥位，工作量翻倍；80 位密钥已不再被认为足够。
:::
:::

::: exercise 奇偶检验的优势 {level=1 check="1/2"}
设 $G(s) = s \,\|\, s_1$（种子后面接它第一位的副本）。给出区分器并计算其优势。（填入优势。）
::: solution
$D(y)$：若 $y$ 的最后一位等于第一位则输出 $1$。在 $G(s)$ 上这总是成立；在均匀的 $y \in \{0,1\}^{n+1}$ 上以概率 $\tfrac12$ 成立。优势为 $\tfrac12$。
:::
:::

::: exercise 重复不是膨胀 {level=2}
设 $G\colon \{0, 1\}^n \to \{0, 1\}^{2n}$ 是 PRG。(a) 证明 $G'(s) = G(s) \,\|\, G(s)$ 不是 PRG。(b) 证明 $G''(s)$（$G(s)$ 的前 $2n - 1$ 位）是 PRG。
::: solution
(a) 当 $4n$ 位输入的两半相等时输出 $1$ 的区分器，在 $G'(s)$ 上以概率 $1$ 输出 $1$，在均匀串上以概率 $2^{-2n}$ 输出 $1$：优势 $1 - 2^{-2n}$。复制输出只增加长度，不增加伪随机性。

(b) 因 $n \ge 2$ 时 $2n - 1 > n$，$G''$ 仍有膨胀。给定对 $G''$ 的区分器 $D$，令 $D'(y)$（$y \in \{0,1\}^{2n}$）把 $D$ 作用在 $y$ 的前 $2n - 1$ 位上。在 $y = G(s)$ 上，它把 $D$ 跑在 $G''(s)$ 上；在均匀 $y$ 上，它把 $D$ 跑在均匀的 $(2n-1)$ 位串上。于是 $D'$ 与 $D$ 优势相同，而 $G$ 是 PRG，故优势可忽略。扔掉一些位从不损害伪随机性。
:::
:::

::: exercise 由 PRF 造的密钥函数是 PRF 吗 {level=2}
设 $F$ 是 PRF。下列各函数（密钥为 $k$）哪些是 PRF？给出证明或区分器。(a) $F'_k(x) = F_k(x) \oplus x$。(b) $F'_k(x) = F_k(x) \oplus F_k(\bar x)$，其中 $\bar x$ 是 $x$ 的逐位取反。
::: solution
(a) 是。给定对 $F'$ 的区分器 $D$，让带预言机 $O$ 的 $D'$ 运行 $D$，并把每个查询 $x$ 用 $O(x) \oplus x$ 作答。若 $O = F_k$，$D$ 看到的就是 $F'_k$；若 $O = f$ 是随机函数，$D$ 看到的是 $x \mapsto f(x) \oplus x$，而它本身仍是均匀随机函数（对表中每个值异或一个固定的 $x$ 是值表上的双射）。于是两个优势相等，且可忽略。

(b) 否。因为异或可交换，对每个 $x$ 都有 $F'_k(x) = F'_k(\bar x)$。区分器查询 $0^n$ 和 $1^n$，若两个回答相等就输出 $1$：对 $F'_k$ 概率为 $1$，对随机函数为 $2^{-n}$。
:::
:::

::: exercise 切换界 {level=2 check="2^(-25)"}
对 64 位串上置换的 $q = 2^{20}$ 次查询，计算简化的切换界 $q^2/2^{n+1}$，并与"$q$ 个均匀 64 位值不全互异"的确切概率比较。（填入 $q^2/2^{n+1}$。）
::: solution
$q^2/2^{65} = 2^{40}/2^{65} = 2^{-25} \approx 2.98 \times 10^{-8}$；[[#lem-switching]] 的精确界 $q(q-1)/2^{65}$ 比它小因子 $1 - 2^{-20}$。确切的碰撞概率是 $1 - \prod_{i=1}^{q-1}(1 - i/2^{64})$，当 $q \ll 2^{32}$ 时与 $q(q-1)/2^{65}$ 极为接近：界小的时候并集界是紧的。两者只在 $q \approx 2^{32}$ 附近才有明显出入，那时界达到 $1/2$，而真实概率是 $1 - e^{-1/2} \approx 0.39$。
:::
:::

::: exercise 由 PRF 得单分组的 EAV-安全加密 {level=3}
设 $F$ 是 $n$ 位串上的 PRF，考虑 $m \in \{0,1\}^n$ 上的 $\mathsf{Enc}_k(m) = F_k(0^n) \oplus m$。(1) 通过对 $F$ 的直接归约（不走 [[#prop-prf-prg]]）证明它是 EAV-安全的。(2) 然后精确说明：为什么对手看到两条不同消息的加密后它就不安全了。
::: solution
给定对手 $\mathcal A$，构造 $D^O$：运行 $\mathcal A$ 得到 $m_0, m_1$；选 $b$；把密文 $O(0^n) \oplus m_b$ 交给 $\mathcal A$；当且仅当 $\mathcal A$ 输出 $b$ 时输出 $1$。若 $O = F_k$，$D$ 精确模拟 $\mathsf{PrivK}^{\mathsf{eav}}$。若 $O = f$ 是随机函数，$f(0^n)$ 是均匀的 $n$ 位串，于是 $\mathcal A$ 面对的是一次一密，恰以概率 $\tfrac12$ 得手。所以 $\mathcal A$ 的成功概率减去 $\tfrac12$ 等于 $D$ 的优势，是可忽略的。

两条消息时，两者用同一条密码本 $F_k(0^n)$，故 $c_1 \oplus c_2 = m_1 \oplus m_2$。提交 $(m, m)$ 与 $(m, m')$（$m \ne m'$）的对手用检验 $c_1 = c_2$ 即可区分。补救办法在 [[cryptography/block-ciphers]] 中给出：每次加密选取一个新的随机输入 $r$，发送 $\langle r, F_k(r) \oplus m\rangle$。
:::
:::

::: exercise 实现惰性采样 {level=3}
写一个 Python 类 `RandomFunction`，用惰性采样模拟从 $\{0,1\}^{n}$ 到自身的一致随机函数；再写一个类 `RandomPermutation`，模拟一致随机置换。用它们在 $n = 16$、$q = 300$ 个不同查询下，以 $10\,000$ 次试验估计区分器"若任意两个回答相同就输出 1"在每个预言机上输出 1 的概率，并与 [[#lem-switching]] 的界比较。
::: solution
```python
import random

class RandomFunction:
    def __init__(self, n): self.n, self.table = n, {}
    def __call__(self, x):
        if x not in self.table:                       # 新查询：取新的均匀值
            self.table[x] = random.getrandbits(self.n)
        return self.table[x]

class RandomPermutation(RandomFunction):
    def __call__(self, x):
        if x not in self.table:
            used = set(self.table.values())
            y = random.getrandbits(self.n)
            while y in used:                          # 重采直到未用过
                y = random.getrandbits(self.n)
            self.table[x] = y
        return self.table[x]

def collides(oracle, q):
    ys = [oracle(x) for x in range(q)]
    return len(set(ys)) < q

random.seed(1)
n, q, T = 16, 300, 10_000
pf = sum(collides(RandomFunction(n), q) for _ in range(T)) / T
pp = sum(collides(RandomPermutation(n), q) for _ in range(T)) / T
print(pf, pp, q * (q - 1) / 2 ** (n + 1))
```
