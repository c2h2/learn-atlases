一家医院想帮助研究者研究某种疾病，于是公布了抹去姓名的住院记录。一座城市公布了共享单车的骑行记录，每条只以一个随机数而不是骑车人为键。一家手机厂商想知道用户最常输入哪个 emoji，又不想知道任何一个具体的人输入了什么。这些都是合理的目标；而每一个例子中，那个显而易见的办法——把姓名删掉——都被一次又一次地证明是失败的：一个人的出生日期、邮编和性别，或者他的一小串行程，或者他评过分的一些影片，几乎和姓名一样可靠地把他从人群中挑出来。

本章讲的是**隐私**：保护人免受关于他们的信息之收集、使用与披露所造成的伤害。它与 [[security/security-principles]] 中的机密性不同，差别在于保护的是谁的利益——是数据主体的，而他们往往既不是系统的用户，更不是系统的所有者。我们先看隐私是什么、数据保护法的原则有哪些；然后看 web 上的**跟踪**，以及"指纹"携带多少信息（以比特度量）；看**匿名通信**与匿名集；看**去标识化**、它的失灵，以及试图挽回它的 $k$-匿名性模型；最后是**差分隐私**——一个带有可证明保证的数学定义，其中的拉普拉斯机制、组合定理与随机应答都将获得证明并加以模拟。本章中的人物与数据集均属虚构。

## 隐私是什么

隐私之难以定义是出了名的。塞缪尔·沃伦（Samuel Warren）与路易斯·布兰代斯（Louis Brandeis）称之为"不受打扰的权利"（1890）；阿兰·韦斯汀（Alan Westin）在 1967 年把它说成个人自行决定在何时、如何、在何种程度上把关于自己的信息传递给别人的主张。对工程师而言，最有用的说法来自海伦·尼森鲍姆（Helen Nissenbaum）。

::: definition 情境完整性 {#def-contextual-integrity}
一条**信息流**由发送者、接收者、主体（信息是关于谁的）、信息类型和**传输原则**（信息在什么条件下流动：托以保密、经本人同意、依法律要求、以支付为交换）描述。每个社会情境——医疗、教育、雇佣、友谊——都有自己的**信息规范**，规定哪些流动是恰当的。若一条流动符合信息共享发生时那个情境的规范，它就**维护了情境完整性**，否则就**违背**它。
:::

这个定义能解释"公开对私密"讲不通的直觉。病人的诊断流向她的主治医生是恰当的，同一份诊断流向她的雇主就不恰当——虽然信息一模一样。一个人的住址，邻居和邮递员都知道；但把它与成千上万人的住址汇成一个可检索的数据库，就会支撑起跟踪、踩点盗窃这类流动——那是任何情境都未许可的。聚合、推断与改作他用正是典型的违背，而计算恰恰把这几件事变得便宜。

数据保护法把类似的想法变成了义务。欧盟《通用数据保护条例》（General Data Protection Regulation，GDPR，2016 年通过，2018 年 5 月起适用）以及许多仿效它的法律要求：个人数据的处理必须**合法、公正、透明**；为特定目的收集，不得以不相容的目的使用（**目的限制**）；以必要为限（**数据最小化**）；保证准确；保存不超过所需时间（**存储限制**）；并以适当的安全措施加以保护（**完整性与机密性**）。控制者必须能够证明合规（**问责制**）；条例还要求**设计与默认的数据保护**。各国法律有别且会变化，工程师应当以最新的法律意见为准；不过这些原则无论如何都是好的工程。**数据最小化**尤其是最强的隐私技术：从未收集的数据不会泄露、不会被司法调取，也不会被公司后来的所有者滥用——正是对风险的"规避"一途（[[security/security-principles]]）。

## 跟踪与指纹

web 页面从许多方加载资源，而每个资源请求都可以携带一个标识符。嵌在许多站点上的广告网络设置的**第三方 Cookie**，让该网络到处认出同一个浏览器，拼出它的浏览史。浏览器已越来越多地封锁或隔离第三方 Cookie（按顶层站点为其加钥，使同一个嵌入网络在每个站点拿到不同的 Cookie），跟踪者则用根本不需要存储标识符的技术来回应。

**浏览器指纹**把网页能读到的一组属性——浏览器版本、语言、时区、屏幕尺寸、已装字体、图形渲染的细微怪癖——拼成一个往往唯一的值。一个属性有多能认人，可以用比特来度量。

::: definition 自信息 {#def-surprisal}
若某属性取值 $v$ 为总体中比例 $p_v$ 的人所共有，那么观察到 $v$ 就关于此人的身份携带 $I(v) = -\log_2 p_v$ 比特**自信息**（surprisal）。该属性的**熵**是自信息的期望 $H = -\sum_v p_v \log_2 p_v$。属性相互独立时，自信息相加。
:::

世界人口约 $8 \times 10^9 \approx 2^{33}$，所以大约 $33$ 比特自信息就能把一个人从全世界中挑出来；而在一个网站的用户之中，需要的远少于此。2010 年，电子前哨基金会（Electronic Frontier Foundation）的 Panopticlick 实验发现，其抽样的浏览器中超过 80% 拥有唯一的指纹。

::: example 指纹中的比特 {#ex-fingerprint}
（虚构的）一位来访者的浏览器报告了如下属性：时区为该网站 $20$ 分之一的访客所共有，语言设置为 $50$ 分之一所共有，屏幕尺寸为 $200$ 分之一所共有，字体列表为 $1000$ 分之一所共有。假设独立，这个组合携带多少比特？预计在多大的访客规模下它会独一无二？
::: solution
自信息各为 $\log_2 20 \approx 4.32$、$\log_2 50 \approx 5.64$、$\log_2 200 \approx 7.64$ 与 $\log_2 1000 \approx 9.97$ 比特，总计约 $27.6$ 比特：该组合为 $1/(20 \cdot 50 \cdot 200 \cdot 1000) = 1/(2 \times 10^8)$ 的访客所共有。在一个有几百万访客的网站上，它极可能独一无二。真实的属性之间存在相关（语言与时区相伴出现），所以真实的数字更小，但教训不变：单个看去无害的属性组合起来就成了标识符。防御的办法是削减比特：有的浏览器报告标准化的取值（固定的字体列表、取整的屏幕尺寸、统一的 user agent——Tor 浏览器的路线），有的对渲染结果加入噪声；既然指纹识别是处理个人数据的一种形式，法律与政策也管得着。
:::
:::

跟踪不止于浏览器。移动应用嵌入分析与广告库；手机的位置数据经数据经纪商出售；即便加密了的网络流量，也暴露设备在与哪些服务器通信、在何时、量有多大（[[networks/application-layer]]）。反复出现的结论是**位置轨迹高度可识别**：一个人何时身在何地的那么几个点，通常就足以把他从数百万人中挑出来。

## 匿名通信

加密掩盖的是**说了什么**，不是**谁在与谁通信**。有时那份元数据本身就是秘密——记者的消息来源、求助于诊所的病人、阅读被禁新闻网站的公民——保护它需要另一种工具。

::: definition 匿名集与匿名度 {#def-anonymity-set}
针对给定的对手，一个行动的**匿名集**是就对手所能分辨的而言可能做出该行动的主体之集。若对手给 $N$ 个成员分别赋予概率 $p_1, \dots, p_N$，则该集合的**有效大小**为 $2^H$，其中 $H = -\sum_i p_i \log_2 p_i$ 是那个分布的熵；$H$ 至多为 $\log_2 N$，当且仅当对手的分布均匀时取等。
:::

::: example 匿名集的熵 {#ex-anonymity}
一条消息离开某个匿名网络，监视该网络入口的对手知道它出自 $5$ 个用户之一。(a) 若对手没有更多信息，有效匿名集大小是多少？(b) 若定时分析使其中一名用户的概率为 $50\%$、其余四人各为 $12.5\%$？
::: solution
(a) 分布均匀，$H = \log_2 5 \approx 2.32$ 比特，有效大小 $5$。(b) $H = -(0.5\log_2 0.5 + 4 \times 0.125 \log_2 0.125) = 0.5 + 4 \times 0.125 \times 3 = 2$ 比特，有效大小 $2^2 = 4$。集合仍有五个成员，但对手的信息已把它缩到四个等可能发信人的等效规模——若再来几次同类的有偏观察且相互独立，它还会迅速收缩。
:::
:::

大卫·乔姆（David Chaum）的**混合网络**（mix network，1981）让消息逐跳经过各中继隐藏收发之间的联系：每个中继解掉一层加密，把消息成批收齐、打乱顺序后再发出。**Tor**（Dingledine、Mathewson 与 Syverson，2004）把分层加密的思想——**洋葱路由**——用于浏览网页这类低时延流量：客户端选定一条由三个中继组成的线路，把流量包上三层加密，于是第一个中继知道客户端却不知道目的地，最后一个知道目的地却不知道客户端，没有任何单个中继两者同时知道。为了压低时延，Tor 不成批也不延迟消息，所以它挡不住能同时观察一条线路**两端**、对流量的定时与体量做相关的对手——这是其设计中言明的局限。用户得到的匿名程度还取决于有多少人与他同用这套系统、彼此看起来有多相像：匿名网络的安全不超过它的人群，可用性在这里就是一种安全属性。

## 去标识化及其失灵

分享关于人的数据的通常做法是把它**去标识化**：删去**直接标识符**（姓名、证件号、电子邮箱地址），也许再换上**假名**。然而剩下的属性往往正是**准标识符**：单看不能识人，组合起来却能识人，而且**带有姓名**的其他数据集里也有它们。

经典的演示来自拉塔尼娅·斯威尼（Latanya Sweeney）在 1990 年代的工作。马萨诸塞州某机构发布了州雇员的就诊记录：姓名去掉了，但留着 ZIP 邮编、出生日期和性别。斯威尼买来了剑桥市的选民名册——上面正好带着姓名列出这三个属性——把两份数据链接起来，找到了州长的医疗记录。她后来根据人口普查数据估计：约 87% 的美国人能被五位 ZIP 邮编、出生日期和性别唯一确定。类似的**链接攻击**从 AOL 公布的搜索日志中重识别出了用户（2006）；阿尔文德·纳拉亚南（Arvind Narayanan）与维塔利·什马季科夫（Vitaly Shmatikov）在 2008 年表明，只需几条带大致日期的影片评分，就足以把"匿名化"的 Netflix 大奖赛数据集中的多数记录与公开评论匹配起来，从而定位到人。

::: warning "我们删掉了姓名，所以数据是匿名的"
删除姓名至多只是假名化。任何稀有、或与其他属性组合后稀有、并且同样出现在别的某个数据集中的属性，都可能把一条记录链接回一个人——而你不可能知道对手已经拥有或将要拥有哪些数据集。丰富、高维的数据（位置轨迹、购买史、浏览日志、基因组）几乎总是可识别的。把去标识化的个体级数据当作个人数据看待，除非你能*证明*关于它泄露什么的保证——这正是差分隐私所提供的东西。
:::

皮兰杰拉·萨马拉蒂（Pierangela Samarati）与斯威尼（Sweeney）在 1998 年提出了一种句法上的补救。

::: definition $k$-匿名性 {#def-k-anonymity}
一张以选定的准标识符属性集发布的表是 **$k$-匿名**的，如果其中出现的每一种准标识符取值组合都至少出现在 $k$ 条记录里。共享同一组合的记录集称为它的**等价类**。达到 $k$-匿名性靠**泛化**取值（把年龄换成一个区间、把邮编换成前缀）和**抑制**某些取值或记录。
:::

::: example 把一张表做到 4-匿名 {#ex-k-anon}
某虚构诊所的表以邮编、年龄、性别为准标识符，敏感属性为诊断：

| 邮编 | 年龄 | 性别 | 诊断 |
|---|---|---|---|
| 13053 | 28 | 女 | 流感 |
| 13068 | 29 | 男 | 哮喘 |
| 13068 | 21 | 女 | 流感 |
| 13053 | 23 | 男 | 支气管炎 |
| 14853 | 50 | 女 | 糖尿病 |
| 14853 | 55 | 男 | 糖尿病 |
| 14850 | 47 | 女 | 糖尿病 |
| 14850 | 49 | 男 | 糖尿病 |

把它泛化到 4-匿名，并检查它还泄露什么。
::: solution
把邮编泛化为前三个数字，年龄泛化为"30 以下"与"40 及以上"，并抑制性别列：

| 邮编 | 年龄 | 性别 | 诊断 |
|---|---|---|---|
| 130\*\* | < 30 | \* | 流感 |
| 130\*\* | < 30 | \* | 哮喘 |
| 130\*\* | < 30 | \* | 流感 |
| 130\*\* | < 30 | \* | 支气管炎 |
| 148\*\* | ≥ 40 | \* | 糖尿病 |
| 148\*\* | ≥ 40 | \* | 糖尿病 |
| 148\*\* | ≥ 40 | \* | 糖尿病 |
| 148\*\* | ≥ 40 | \* | 糖尿病 |

共有两个等价类、各四条记录，故该表是 4-匿名的：任何人的记录都无法被锁定到少于四条。但任何知道"一位住 14853 邮编、50 岁的邻居去过这家诊所"的人，就学到他患有糖尿病，因为他所在类的每条记录都是糖尿病——这是**齐次性攻击**。Machanavajjhala 及其同事的 **$\ell$-多样性**（2006）要求每个等价类中至少有 $\ell$ 个"得到充分代表"的敏感取值（这里第二个类只有一个）；**$t$-邻近性**（2007）要求每个类的分布接近总体分布。每个改进都补上一个攻击的漏洞，但没有一个能约束*另有背景知识*的对手能学到什么，也没有一个能约束多次发布*合在一起*泄露什么。
:::
:::

更深的问题在于，这些定义是**输出表**的性质，而不是产生它的**过程**的性质，因而对对手的辅助信息一无所知。伊里特·迪努尔（Irit Dinur）与科比·尼西姆（Kobbi Nissim）在 2003 年把危险说得精确：若一个数据库对过多的统计查询回答得过准——在他们的模型中，对 $n$ 条记录的误差远小于 $\sqrt n$——对手就能几乎重建全部私密比特。每次发布统计都会"用掉"一些隐私，准确性与隐私必须显式地相互交换。

## 差分隐私

辛西娅·德沃克（Cynthia Dwork）、弗兰克·麦克谢里（Frank McSherry）、科比·尼西姆（Kobbi Nissim）与亚当·史密斯（Adam Smith）（2006）提出了一个把对手的知识整个绕开的定义：无论任何单个人的数据是否被纳入，分析的输出都应当几乎同样可能。无论对手知道什么，它从一次发布中关于**你**学到的东西，与你的记录根本不在其中相比，几乎不多一分。

::: definition 差分隐私 {#def-dp}
若两个数据集 $D, D'$ 相差一个个体的记录，则称它们**相邻**。随机化算法 $\mathcal M$ 是 **$\varepsilon$-差分隐私**的，如果对一切相邻的 $D, D'$ 和每一个可能输出之集 $S$，
$$
\Pr[\mathcal M(D) \in S] \le e^{\varepsilon} \Pr[\mathcal M(D') \in S].
$$ {#eq-dp}
参数 $\varepsilon > 0$ 称为**隐私损失**：越小越私密。
:::

两点评注使定义具体化。其一，它必须是*随机化的*：数据的确定性非常函数必对某对相邻数据集改变输出，取 $S$ 为只含其中一个输出的集合，就违反 [[#eq-dp]]。其二，保证是关于机制的，不是关于某个具体输出的，而且对持有任何辅助信息的对手都成立——包括知道其余每一条记录——因为它比较的是只在一个人的数据上有所不同的两个世界。

要私密地发布一个数值统计量，我们就加入按一个人所能引起的改变量定标的噪声。

::: definition 敏感度与拉普拉斯机制 {#def-laplace}
从数据集到 $\R$ 的函数 $f$ 的**敏感度**是 $\Delta f = \max \abs{f(D) - f(D')}$，对所有相邻的 $D, D'$ 取最大。**拉普拉斯分布** $\mathrm{Lap}(b)$ 的密度为 $\frac{1}{2b} e^{-\abs{x}/b}$，均值为 $0$，绝对值的均值为 $b$。**拉普拉斯机制**发布 $\mathcal M(D) = f(D) + Y$，其中 $Y \sim \mathrm{Lap}(\Delta f / \varepsilon)$。
:::

::: theorem 拉普拉斯机制满足差分隐私 {#thm-laplace}
对每个敏感度 $\Delta f$ 有限的函数 $f$ 和每个 $\varepsilon > 0$，拉普拉斯机制都是 $\varepsilon$-差分隐私的。
:::

::: proof
设 $D, D'$ 相邻，记 $b = \Delta f/\varepsilon$。输出在点 $z$ 处的密度为 $p_D(z) = \frac{1}{2b}e^{-\abs{z - f(D)}/b}$ 与 $p_{D'}(z) = \frac{1}{2b}e^{-\abs{z - f(D')}/b}$。二者之比为
$$
\frac{p_D(z)}{p_{D'}(z)} = \exp\left(\frac{\abs{z - f(D')} - \abs{z - f(D)}}{b}\right) \le \exp\left(\frac{\abs{f(D) - f(D')}}{b}\right) \le \exp\left(\frac{\Delta f}{b}\right) = e^{\varepsilon},
$$
其间用了三角不等式 $\abs{z - f(D')} \le \abs{z - f(D)} + \abs{f(D) - f(D')}$ 与敏感度的定义。对 $p_D(z) \le e^\varepsilon p_{D'}(z)$ 在任意集合 $S$ 上积分即得 [[#eq-dp]]。
:::

::: widget plot
f: exp(-abs(x)/b)/(2*b); exp(-abs(x-1)/b)/(2*b)
x: -8, 9
y: 0, 0.6
sliders: b=2:0.5:6:0.1

caption: 拉普拉斯机制的两个输出密度，对应某计数因某个人的记录是否被纳入而相差 $0$ 或 $1$（敏感度 $1$），噪声尺度 $b = 1/\varepsilon$。在每一点上，两条曲线之比至多 $e^{1/b} = e^{\varepsilon}$（[[#thm-laplace]]）。把 $b$ 调小（$\varepsilon$ 调大）：两个峰分开，观察者便能分辨两个世界。把 $b$ 调大：两条曲线几乎重合——隐私更强，但答案更噪。
:::

::: example 发布一个计数 {#ex-laplace}
（虚构的）一项研究想发布其参与者中有多少人患有某种疾病；真实计数为 $412$。以 $\varepsilon = 0.5$ 发布它，并用实验检验误差的大小。
::: solution
增加或减少一个人至多改变计数 $1$，故 $\Delta f = 1$、$b = 1/\varepsilon = 2$。

```python
import math, random

def laplace(b, rng):
    """用反分布函数从 Laplace(0, b) 抽样。"""
    u = rng.random() - 0.5
    return -b * math.copysign(1, u) * math.log(1 - 2 * abs(u))

rng = random.Random(7)
true_count, eps = 412, 0.5                 # 计数查询的敏感度为 1
b = 1 / eps
releases = [true_count + laplace(b, rng) for _ in range(5)]
print([round(x, 1) for x in releases])
errs = [abs(laplace(b, rng)) for _ in range(100_000)]
print(f"mean |error| {sum(errs)/len(errs):.3f}  (theory b = {b})")
print(f"P(|error| > 6) {sum(e > 6 for e in errs)/len(errs):.4f}  (theory e^-3 = {math.exp(-3):.4f})")
```

```console
[411.1, 409.6, 412.7, 408.1, 412.1]
mean |error| 1.997  (theory b = 2.0)
P(|error| > 6) 0.0493  (theory e^-3 = 0.0498)
```

一次发布就是这几个数中的一个，通常距真值在 $2$ 以内，只有约 $5\%$ 的时候偏离超过 $6$（$\Pr[\abs Y > t] = e^{-t/b}$）。对几百量级的计数来说，这非常准确，而任何单个参与者是否在册却被藏得很好。注意上面的五次发布：对**同一个问题**发布*许多*带噪答案，任谁都能把噪声平均掉——这正是组合定理要计账的事。（这个抽样器仅供说明；生产系统使用经过审验的库，它们还防备噪声生成中的浮点侧信道。）
:::
:::

::: theorem 序列组合 {#thm-composition}
若 $\mathcal M_1$ 是 $\varepsilon_1$-差分隐私的，$\mathcal M_2$ 是 $\varepsilon_2$-差分隐私的，且二者使用相互独立的随机性，则一并发布 $(\mathcal M_1(D), \mathcal M_2(D))$ 是 $(\varepsilon_1 + \varepsilon_2)$-差分隐私的。归纳可得：$k$ 次损失为 $\varepsilon_1, \dots, \varepsilon_k$ 的发布，总损失为 $\sum_i \varepsilon_i$。
:::

::: proof
为简便起见设输出取自离散空间（连续情形用密度同理）。对相邻的 $D, D'$ 与任意一对输出 $(a, b)$，由独立性得
$$
\Pr[(\mathcal M_1(D), \mathcal M_2(D)) = (a, b)] = \Pr[\mathcal M_1(D) = a]\Pr[\mathcal M_2(D) = b] \le e^{\varepsilon_1}\Pr[\mathcal M_1(D') = a] \cdot e^{\varepsilon_2}\Pr[\mathcal M_2(D') = b],
$$
即 $e^{\varepsilon_1 + \varepsilon_2}\Pr[(\mathcal M_1(D'), \mathcal M_2(D')) = (a, b)]$。对任意集合 $S$ 中的输出对求和，即得参数为 $\varepsilon_1 + \varepsilon_2$ 的 [[#eq-dp]]。若 $\mathcal M_2$ 是在看到 $\mathcal M_1$ 的输出之后才选定的，结论同样成立，因为 $\mathcal M_2$ 的不等式对 $a$ 的每个值都条件成立。
:::

组合把隐私变成一项**预算**：机构为一个数据集定下总量 $\varepsilon$，把它分配到它今后发布的一切统计量上——迪努尔与尼西姆的重构结果恰恰表明这种纪律必不可少。第二个基本性质是**后处理**：对 $\varepsilon$-差分隐私机制的输出再作任何不再看数据的计算，结果仍是 $\varepsilon$-差分隐私的；因此发布出的统计量可以随意取整、调整一致或用来拟合模型。

### 本地差分隐私与随机应答

当用户根本不信任收集方时，每个用户可以在发送之前先随机化自己的数据。最古老的这类方法早于计算机：斯坦利·沃纳（Stanley Warner）的**随机应答**（randomised response，1965），为调查令人难堪的问题而设计。

::: proposition 随机应答 {#prop-rr}
每位受访者带着真实答案 $t \in \{\text{是}, \text{否}\}$ 掷一枚均匀硬币。正面就如实回答；反面就再掷一次，正面答"是"，反面答"否"。则 (a) 每个人的回答相对于其本人的真实答案是 $\ln 3$-差分隐私的；(b) 若总体中真正答"是"的比例为 $p$，则回答"是"的期望比例为 $\lambda = p/2 + 1/4$，于是由观测比例 $\hat\lambda$ 得到的 $\hat p = 2\hat\lambda - 1/2$ 是 $p$ 的一个无偏估计量。
:::

::: proof
(a) 这里相邻的输入是两个可能的真实答案。若 $t = \text{是}$，则回答"是"的概率为 $\frac12 + \frac12 \cdot \frac12 = \frac34$，回答"否"的概率为 $\frac14$；若 $t = \text{否}$，则"是"的概率为 $\frac14$，"否"的概率为 $\frac34$。同一回答在两个输入之下的概率之比最大者为 $\frac{3/4}{1/4} = 3 = e^{\ln 3}$。(b) 随机一位受访者的真实答案为"是"的概率是 $p$，故 $\lambda = \frac34 p + \frac14(1 - p) = \frac p2 + \frac14$。解出 $p = 2\lambda - \frac12$；由于 $\hat\lambda$ 是 $\lambda$ 的无偏估计而映射是线性的，$\hat p = 2\hat\lambda - \frac12$ 无偏。
:::

::: example 模拟一次调查 {#ex-rr}
模拟 $10{,}000$ 名虚构受访者，其中约 $30\%$ 的真实答案为"是"，施加随机应答，并估计 $p$。
::: solution
```python
import random

def respond(truth: bool, rng) -> bool:
    """随机应答：第一枚硬币正面 -> 说真话；反面 -> 回答第二枚硬币。"""
    if rng.random() < 0.5:
        return truth
    return rng.random() < 0.5

rng = random.Random(2026)                  # 固定种子：每次运行输出相同
n, p = 10_000, 0.30                        # （虚构的）总体中 30% 真实答案为"是"
truths = [rng.random() < p for _ in range(n)]
answers = [respond(t, rng) for t in truths]
lam = sum(answers) / n                     # 观测到答"是"的比例
print(f"observed yes: {lam:.4f}   estimate of p: {2 * lam - 0.5:.4f}   true p: {sum(truths) / n:.4f}")
```

```console
observed yes: 0.4102   estimate of p: 0.3204   true p: 0.3033
```

估计值为 $0.320$，而真实值为 $0.303$。估计量的标准差为 $2\sqrt{\lambda(1-\lambda)/n} \approx 2\sqrt{0.41 \times 0.59/10^4} \approx 0.0098$，所以 $0.017$ 的误差约为 $1.7$ 个标准差——很典型。若不作随机化，标准差将为 $\sqrt{p(1-p)/n} \approx 0.0046$：这里本地隐私大约使准确度付出两倍的代价，且价格随 $\varepsilon$ 变小而上升。然而任何个人的回答都透露无多：一个"是"出自真"是"的可能性只是出自真"否"的三倍。
:::
:::

大规模部署中，本地模型用于遥测——Google 在 Chrome 中的 RAPPOR（2014）与 Apple 的使用统计收集——官方统计则用中心模型：美国人口普查局用一套差分隐私系统保护其 2020 年人口普查的发布，这一决定同时也表明，$\varepsilon$ 有多难选，把随之而来的噪声向数据用户解释清楚有多难。差分隐私不是万能药：它保护个人而不保护群体（一项研究仍可能揭示吸烟者易得癌症，而这关涉每一个吸烟者）；它的保证随 $\varepsilon$ 变差，而 $\varepsilon$ 的取舍必须由政策决定；彼此相关的记录（一家人的数据）会削弱"一个人"这个单位，除非把它选定得当心。

::: quiz
一家公司发布了其 50 名雇员的精确平均工资；下个月——在一名雇员离职之后——又发布了其余 49 人的精确平均工资。发生了什么？

- [ ] 没有害处：平均值是聚合统计量。
- [x] 知道离职者是谁的人都能精确算出那人的工资。
- [ ] 每次发布都是 1-差分隐私的，因为它们都是平均值。
- [ ] 只有能访问工资数据库的人才可能知道什么。
::: solution
离职者的工资就是 $50\bar x_{50} - 49\bar x_{49}$——这是**差分攻击**。精确统计量是数据的确定性函数，不可能是差分隐私的（[[#def-dp]]）；当发布可以相互比较时，光靠聚合保护不了任何人。差分隐私的发布会对每个平均值加上按其敏感度定标的噪声，并把两次发布都记入隐私预算（[[#thm-composition]]）。
:::
:::

## 隐私始于设计

这些技术合起来是一种工程实践。**最小化**所收集的数据及其保存期限；把标识符与数据**分离**（假名化，密钥另存）并限制谁能把两者拼回去；发布之前先**聚合**并加噪；尽可能在用户的设备上**就地**处理数据、只回传结果；对存储中与传输中的数据**加密**；并向人们提供**透明与控制**——告知、以其为合法性基础时的同意、查阅与删除。**隐私影响评估**（用 GDPR 的术语，叫数据保护影响评估）是威胁建模在隐私上的对应物：描述信息流，识别谁可能受害、如何受害，并在动手构建之前选好缓解措施。密码学还提供了更专门的工具——隐私集合求交、安全多方计算（[[cryptography/protocols]]）与同态加密——能在不泄露数据的情况下对数据计算，其代价在某些任务上已降到实用的水平。

::: history
塞缪尔·沃伦（Samuel Warren）与路易斯·布兰代斯（Louis Brandeis）的《隐私权》（"The right to privacy"，《哈佛法律评论》，1890）是对即时成像照片与大众报刊的回应。阿兰·韦斯汀（Alan Westin）的《隐私与自由》（*Privacy and Freedom*，1967）塑造了 1970 年代的公平信息实践原则，它们经由经济合作与发展组织 1980 年的指南、欧盟 1995 年的数据保护指令与《通用数据保护条例》（2016）先后编纂成文。斯坦利·沃纳（Stanley Warner）1965 年引入随机应答，大卫·乔姆（David Chaum）1981 年引入混合网络；Roger Dingledine、Nick Mathewson 与 Paul Syverson 于 2004 年发表了 Tor 的设计。拉塔尼娅·斯威尼（Latanya Sweeney）1990 年代后期的重识别研究，以及她与皮兰杰拉·萨马拉蒂（Pierangela Samarati）合写的关于 $k$-匿名性的论文（1998），开启了对去标识化的研究；海伦·尼森鲍姆（Helen Nissenbaum）2004 年提出情境完整性；伊里特·迪努尔（Irit Dinur）与科比·尼西姆（Kobbi Nissim）2003 年证明了他们的重构定理；辛西娅·德沃克（Cynthia Dwork）、弗兰克·麦克谢里（Frank McSherry）、科比·尼西姆（Kobbi Nissim）与亚当·史密斯（Adam Smith）2006 年定义了差分隐私，这一贡献获 2017 年哥德尔奖（Gödel Prize）认可。阿尔文德·纳拉亚南（Arvind Narayanan）与维塔利·什马季科夫（Vitaly Shmatikov）的 Netflix 大奖赛研究（2008）以及彼得·埃克斯利（Peter Eckersley）的浏览器指纹研究（2010），表明了"匿名"的数据与浏览器有多大可识别性。
:::

## 后续内容

隐私依赖本课程的种种安全机制：个人数据必须由访问控制（[[security/access-control]]）与加密来保护，而它在数据泄露事件中的流失是事件响应（[[security/malware]]）的中心议题。设计与默认的数据保护是 [[security/secure-development]] 所述开发流程的一部分。差分隐私与机器学习相连——在不记住个别样本的前提下训练模型——也与数学图谱中的概率论相连（[Maths Atlas: probability](/learn/maths/course.php?c=probability)）；对私有数据进行计算的密码学技术在 [[cryptography]]，数据收集的伦理问题在 [[software-engineering/professional-ethics]] 与 [[hci]]。

::: summary
- 隐私保护的是数据主体。**情境完整性**（[[#def-contextual-integrity]]）依据信息共享发生时那个情境的规范来评判一条流动；数据保护法又添上目的限制、**数据最小化**、存储限制与问责制。
- 跟踪者利用 Cookie 与**指纹**；识别能力以**自信息**（比特）度量，独立属性之间可以相加（[[#def-surprisal]]），而大约 $33$ 比特就能把地球上的任何人挑出来。
- **匿名性**以对手对匿名集的看法的熵来度量（[[#def-anonymity-set]]）；Tor 的洋葱路由使任何单个中继看不出谁在与谁通信，却挡不住同时观察两端的对手。
- 靠删姓名**去标识化**，敌不过借准标识符实施的**链接**；**$k$-匿名性**（[[#def-k-anonymity]]）及其改进是表的性质，失守于齐次性攻击与背景知识攻击。
- **差分隐私**（[[#def-dp]]）界定了任何单个人的数据能在多大程度上改变输出的分布，且对任何对手都成立。**拉普拉斯机制**加入尺度为 $\Delta f/\varepsilon$ 的噪声（[[#thm-laplace]]）；组合之下隐私损失**相加**（[[#thm-composition]]）；**随机应答**在本地满足 $\ln 3$-隐私（[[#prop-rr]]）。
:::

某机构对某数据集的总预算为 $\varepsilon = 1$，要发布 $4$ 个统计量且份额均等。每次发布可以用多大的 $\varepsilon$？（填入数值。）
::: solution
由 [[#thm-composition]]，损失相加，故每次可用 $1/4 = 0.25$。

::: exercise 一张表的 $k$ {level=2 check="1"}
在 [[#ex-k-anon]] 的**原始**表中，取邮编、年龄、性别为准标识符，它是 $k$-匿名的 $k$ 最大是多少？若 $\ell$-多样性指每个等价类中至少含 $\ell$ 个不同的敏感取值，那么泛化表是 $\ell$-多样的 $\ell$ 最大是多少？（填入原始表的最大 $k$。）
::: solution
原始表中每一行的邮编、年龄、性别组合都互不相同，故每个等价类只有一条记录：$k = 1$。泛化表的第二个等价类只含"糖尿病"，所以该表只是 $1$-多样的（第一个等价类有三个不同取值），尽管它是 $4$-匿名的。

::: exercise 平均值的敏感度 {level=2}
设数据集中工资都落在 $[0, 200{,}000]$ 内，记录数 $n$ 公开且固定（相邻数据集是把*一个人的记录换成另一个人的*）。平均工资的敏感度是多少？设计平均工资的一个 $\varepsilon$-差分隐私发布，并给出 $n = 1000$、$\varepsilon = 1$ 时的平均绝对误差。
::: solution
替换一条记录至多改变总和 $200{,}000$，从而至多改变平均值 $200{,}000/n$；这个上界可以取到（把一个 $0$ 的工资换成 $200{,}000$），故 $\Delta f = 200{,}000/n$。发布平均值再加上 $\mathrm{Lap}(\Delta f/\varepsilon)$ 噪声；由 [[#thm-laplace]]，它是 $\varepsilon$-差分隐私的。$n = 1000$、$\varepsilon = 1$ 时，尺度与平均绝对误差都是 $200$，与典型工资相比很小。范围之外的取值必须先**截断**进范围内，否则敏感度上界不成立。
:::

::: exercise 有偏硬币的随机应答 {level=2}
推广 [[#prop-rr]]：受访者以概率 $q > 1/2$ 如实回答，否则给出相反的答案。计算隐私损失 $\varepsilon$ 与 $p$ 的一个无偏估计量。$q$ 为多少时 $\varepsilon = 1$？
::: solution
若 $t = \text{是}$，回答"是"的概率为 $q$；若 $t = \text{否}$，概率为 $1 - q$。最大比值为 $q/(1-q)$，故 $\varepsilon = \ln\frac{q}{1-q}$。"是"的期望比例为 $\lambda = qp + (1 - q)(1 - p) = (2q - 1)p + 1 - q$，于是 $\hat p = (\hat\lambda - 1 + q)/(2q - 1)$，与之前一样无偏。$q/(1-q) = e$，即 $q = e/(1+e) \approx 0.731$ 时 $\varepsilon = 1$。（沃纳（Warner）的原始方案就是这种形式；两枚硬币的方案对应 $q = 3/4$、$\varepsilon = \ln 3$。）
:::
:::

::: exercise 确定性机制不私密 {level=3}
证明：若确定性算法 $\mathcal M$ 的输出不是对所有数据集都相同，则它对任何有限的 $\varepsilon$ 都不是 $\varepsilon$-差分隐私的（假设任意两个数据集都可由一条相邻链连接）。然后解释：把拉普拉斯机制的**输出**四舍五入到最接近的整数，为什么不与此矛盾。
::: solution
由于 $\mathcal M$ 不是常函数，存在数据集 $D_0, D_m$ 使 $\mathcal M(D_0) \ne \mathcal M(D_m)$。用相邻链 $D_0, D_1, \dots, D_m$ 把它们连接起来；输出不可能全都相等，故某一对相邻数据集满足 $\mathcal M(D_i) = a \ne \mathcal M(D_{i+1})$。取 $S = \{a\}$：$\Pr[\mathcal M(D_i) \in S] = 1$ 而 $\Pr[\mathcal M(D_{i+1}) \in S] = 0$，而 $1 \le e^\varepsilon \cdot 0$ 对任何有限 $\varepsilon$ 都不成立。对拉普拉斯机制的输出取整，是施加在已经随机化过的、私密的输出上的一个确定性函数；由后处理性质，复合机制仍是 $\varepsilon$-差分隐私的。就整体而言机制是随机化的，所以上面的论证对它不适用。
:::
:::

::: exercise 实现一个私密的直方图 {level=3}
直方图对 $m$ 个互不相交的类别各统计记录数。证明给**每个**计数都加上独立的 $\mathrm{Lap}(1/\varepsilon)$ 噪声，得到的是一个 $\varepsilon$-差分隐私的发布——尽管发布了 $m$ 个数——并解释这与组合定理为何不矛盾。对虚构计数 `{"flu": 120, "asthma": 45, "diabetes": 80}` 取 $\varepsilon = 1$、种子 $3$ 实现之。
::: solution
在"增删一条记录"的相邻关系之下，增删一条记录恰好改变一个计数、且恰好改变 $1$，故计数向量在 $\ell_1$ 范数（绝对改变量之和）下的敏感度为 $1$。对向量机制，输出 $z$ 处的密度之比为 $\prod_j \exp((\abs{z_j - c'_j} - \abs{z_j - c_j})\varepsilon) \le \exp(\varepsilon \sum_j \abs{c_j - c'_j}) = e^{\varepsilon}$，与 [[#thm-laplace]] 的证明相同。若每个计数都能独立改变，组合定理就要收取 $m\varepsilon$；而这里一个人只影响一个计数（对数据的互不相交部分作**平行组合**），故总损失为 $\varepsilon$。

```python
import math, random

def laplace(b, rng):
    u = rng.random() - 0.5
    return -b * math.copysign(1, u) * math.log(1 - 2 * abs(u))

rng = random.Random(3)
counts = {"flu": 120, "asthma": 45, "diabetes": 80}
print({k: round(v + laplace(1.0, rng), 1) for k, v in counts.items()})
```

```console
{'flu': 119.3, 'asthma': 45.1, 'diabetes': 79.7}
```

（你的数值取决于随机数发生器；以上是 Python 3.14 以种子 $3$ 得到的。）噪声计数若为负或带小数，事后可由后处理取整并在零处截断。
:::
:::
