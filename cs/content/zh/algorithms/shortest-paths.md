路线规划程序要在拥有数百万路口的路网上，找出从你家到火车站最快的走法；网络路由器要把每个分组沿代价最小的路径转发向它的目的地；货币交易者想寻找一列兑换操作，把一英镑变成多于一英镑。三者都是加权图上的**最短路径问题**：每条边带一个**权**——长度、行程时间、代价，或者（对交易者而言）汇率的负对数——我们要求的是一条总权尽可能小的路径。

当每条边的权都是 $1$ 时，广度优先搜索就能解决问题（[[algorithms/graph-search#thm-bfs]]）。但有了一般的权，边数最少的路径就不再是最短的：沿三条短路绕行可能胜过一条长路。本章介绍主要的几个算法。**迪杰斯特拉算法**维护一个距离已经确定的顶点集合，每次把其中最近的一个并入；借助优先队列它以 $O((n + m)\log n)$ 时间运行，但只在**非负**权下正确。**贝尔曼-福特算法**能处理负权，并在 $O(nm)$ 时间内检测**负权回路**（交易者的美梦）。在 DAG 上，按拓扑序作一趟扫描就够。要求*所有*顶点对之间的距离，**弗洛伊德-沃沙尔算法**用动态规划以 $\Theta(n^3)$ 时间完成。所有这些算法都建立在一种操作——**松弛**——和一个结构性事实——最短路径的片段仍是最短路径——之上。

## 最短路径及其结构

设 $G = (V, E)$ 是带权函数 $w\colon E \to \mathbb R$ 的有向图。（无向图视作把 $(u, v)$ 和 $(v, u)$ 各以权 $w(u, v)$ 连出的有向图。）

::: definition 路径的权与最短路径权 {#def-delta}
路径 $p = \langle v_0, v_1, \dots, v_k\rangle$ 的**权**为 $w(p) = \sum_{i=1}^k w(v_{i-1}, v_i)$。从 $u$ 到 $v$ 的**最短路径权**为
$$
\delta(u, v) = \begin{cases}\inf\{w(p) : p \text{ 是从 } u \text{ 到 } v \text{ 的一条路径}\} & \text{若这样的路径存在，}\\ \infty & \text{否则。}\end{cases}
$$
满足 $w(p) = \delta(u, v)$ 的路径 $p$ 称为从 $u$ 到 $v$ 的一条**最短路径**。路径可以重复顶点；不重复顶点的路径称为**简单**路径。
:::

在**单源**问题中，给定源 $s$，要求每个 $v$ 的 $\delta(s, v)$，并给出从 $s$ 到每个 $v$ 的一条最短路径。

**负权回路。**若某个从 $s$ 可达的回路 $c$ 满足 $w(c) < 0$，那么沿它反复绕行，会使其后顶点的可达路径的权任意地小：对每个由该回路可达的 $v$ 都有 $\delta(s, v) = -\infty$，最短路径不存在。若 $s$ 出发没有可达的负权回路，则每个 $\delta(s, v)$ 都是有限值或 $+\infty$，且由简单路径达到：从一条路径中删去一个非负权的圈不会增大其权。简单路径至多有 $n - 1$ 条边。

::: lemma 最短路径的子路径仍是最短路径 {#lem-subpath}
若 $p = \langle v_0, \dots, v_k\rangle$ 是从 $v_0$ 到 $v_k$ 的一条最短路径，则对所有 $0 \le i \le j \le k$，子路径 $p_{ij} = \langle v_i, \dots, v_j\rangle$ 是从 $v_i$ 到 $v_j$ 的一条最短路径。
:::

::: proof
把 $p$ 写成 $p_{0i}$、再接 $p_{ij}$、再接 $p_{jk}$，于是 $w(p) = w(p_{0i}) + w(p_{ij}) + w(p_{jk})$。若存在某条从 $v_i$ 到 $v_j$ 的路径 $q$ 满足 $w(q) < w(p_{ij})$，则把 $p_{0i}$、$q$、$p_{jk}$ 相接就得到一条从 $v_0$ 到 $v_k$ 的路径（路径允许重复顶点），其权小于 $w(p) = \delta(v_0, v_k)$，与 $\delta$ 的定义矛盾。
:::

这就是**最优子结构**，是贪心算法与动态规划得以成立的那条性质（[[algorithms/dynamic-programming]]）。它给出**三角不等式**：对每条边 $(u, v)$，
$$
\delta(s, v) \le \delta(s, u) + w(u, v),
$$ {#eq-triangle}
因为到 $u$ 的最短路径再接上这条边就是到 $v$ 的一条路径。

### 松弛

所有单源最短路径算法都为每个顶点 $v$ 维护一个估计值 $v.d$（$\delta(s, v)$ 的一个上界）和一个前驱 $v.\pi$。初始时令 $s.d = 0$，且对 $v \ne s$ 令 $v.d = \infty$，再靠松弛边来改进这些估计值。

::: definition 松弛 {#def-relax}
**松弛**边 $(u, v)$，就是检验经过 $u$ 能否改进 $v$ 的估计值，若能就更新它：
$$
\textbf{if } u.d + w(u, v) < v.d \textbf{ then } v.d \gets u.d + w(u, v),\; v.\pi \gets u.
$$
:::

::: lemma 松弛的性质 {#lem-relax}
按上述方式初始化，然后以任意次序松弛各边。则：

1. *（上界）*任一时刻对每个顶点都有 $v.d \ge \delta(s, v)$，且一旦 $v.d = \delta(s, v)$，它就再也不变。
2. *（收敛性）*若 $\langle s, \dots, u, v\rangle$ 是一条最短路径，且在松弛 $(u, v)$ 之前 $u.d = \delta(s, u)$，则松弛之后 $v.d = \delta(s, v)$。
3. *（路径松弛）*若 $p = \langle v_0 = s, v_1, \dots, v_k\rangle$ 是一条最短路径，且它的边 $(v_0, v_1), (v_1, v_2), \dots, (v_{k-1}, v_k)$ 按此次序被松弛——中间可以穿插其他松弛——则之后 $v_k.d = \delta(s, v_k)$。
:::

::: proof
1. 对松弛次数归纳：初始时 $s.d = 0 \ge \delta(s, s)$（它为 $0$，若 $s$ 在负权回路上则为 $-\infty$），其余估计值都是 $\infty$。一次改变了 $v.d$ 的松弛把它置为 $u.d + w(u, v) \ge \delta(s, u) + w(u, v) \ge \delta(s, v)$，这里用到假设和 [[#eq-triangle]]。估计值从不增大，故一旦等于下界 $\delta(s, v)$ 就永远保持相等。
2. 松弛之后 $v.d \le u.d + w(u, v) = \delta(s, u) + w(u, v) = \delta(s, v)$，最后一步由 [[#lem-subpath]]。再结合第 1 条，$v.d = \delta(s, v)$。
3. 对 $i$ 归纳：$v_0.d = s.d = 0 = \delta(s, s)$（$s$ 上没有负权回路，因为从 $s$ 出发的最短路径存在），且若松弛 $(v_{i-1}, v_i)$ 时 $v_{i-1}.d = \delta(s, v_{i-1})$，则由第 2 条，之后 $v_i.d = \delta(s, v_i)$，又由第 1 条它保持不变。到 $v_i$ 的子路径是最短的，由 [[#lem-subpath]]。
:::

各算法的差别只在于*松弛哪些边、按什么次序*。

## 贝尔曼-福特算法

最简单的策略是把每条边完整地松弛 $n - 1$ 遍。

::: algorithm 贝尔曼-福特算法 {#alg-bellman-ford}
```text
BELLMAN-FORD(G, w, s)
1  initialise: s.d ← 0; v.d ← ∞ and v.π ← NIL for v ≠ s
2  for i ← 1 to n − 1
3      for each edge (u, v) in E
4          RELAX(u, v, w)
5  for each edge (u, v) in E
6      if u.d + w(u, v) < v.d
7          return FALSE              ▷ 从 s 可达一个负权回路
8  return TRUE
```
:::

::: theorem 贝尔曼-福特算法的正确性 {#thm-bellman-ford}
若 $G$ 中没有从 $s$ 可达的负权回路，贝尔曼-福特算法返回 TRUE，且对每个顶点 $v$ 有 $v.d = \delta(s, v)$；若 $G$ 有从 $s$ 可达的负权回路，它返回 FALSE。它运行 $\Theta(nm)$ 时间。
:::

::: proof
*无负权回路。*设 $v$ 从 $s$ 可达。则 $\delta(s, v)$ 由一条简单路径 $\langle s = v_0, \dots, v_k = v\rangle$ 达到，其中 $k \le n - 1$。循环的第 $i$ 轮松弛所有边，特别地包括 $(v_{i-1}, v_i)$；于是这条路径的各边在第 $1, \dots, k$ 轮中按序被松弛，由路径松弛（[[#lem-relax]]），在第 $k \le n - 1$ 轮之后 $v.d = \delta(s, v)$。不可达的顶点保持 $v.d = \infty = \delta(s, v)$（估计值只有经过一条从 $s$ 出发的路径才会变为有限）。结束时，由 [[#eq-triangle]]，对每条边都有 $v.d = \delta(s, v) \le \delta(s, u) + w(u, v) = u.d + w(u, v)$，所以第 6 行的检验永远不成立，算法返回 TRUE。

*有负权回路。*设 $c = \langle v_0, v_1, \dots, v_k = v_0\rangle$ 从 $s$ 可达且满足 $\sum_{i=1}^k w(v_{i-1}, v_i) < 0$。反设算法返回 TRUE，则对 $i = 1, \dots, k$ 有 $v_i.d \le v_{i-1}.d + w(v_{i-1}, v_i)$。这些估计值全都有限（回路可达，且经过 $n - 1$ 轮之后，凡可由至多 $n - 1$ 条边的路径到达的顶点都有有限的估计值）。沿回路求和：$\sum_i v_i.d \le \sum_i v_{i-1}.d + \sum_i w(v_{i-1}, v_i)$；两个估计值之和相等（回路中每个顶点在两边各出现一次），故 $0 \le w(c) < 0$，矛盾。

*时间。*$n - 1$ 轮各 $m$ 次松弛，外加一次检查：$\Theta(nm)$。
:::

```python
from math import inf

def bellman_ford(vertices, edges, s, trace=False):
    """Return shortest-path weights from s, or None if a negative cycle is reachable."""
    dist = {v: inf for v in vertices}
    dist[s] = 0
    for i in range(len(vertices) - 1):          # n - 1 轮
        for u, v, w in edges:
            if dist[u] + w < dist[v]:           # 松弛
                dist[v] = dist[u] + w
        if trace:
            print(i + 1, dist)
    for u, v, w in edges:                       # 多一轮：还有变化吗？
        if dist[u] + w < dist[v]:
            return None
    return dist

V = ['s', 't', 'x', 'y', 'z']
E = [('t', 'x', 5), ('t', 'y', 8), ('t', 'z', -4), ('x', 't', -2),
     ('y', 'x', -3), ('y', 'z', 9), ('z', 'x', 7), ('z', 's', 2),
     ('s', 't', 6), ('s', 'y', 7)]
print(bellman_ford(V, E, 's', trace=True))
print(bellman_ford(V, E + [('x', 'y', 1)], 's') is None)
```

::: example 演示贝尔曼-福特算法 {#ex-bellman-ford}
解释上面打印的四轮结果，并说明加入权为 $1$ 的边 $(x, y)$ 为什么会造出一个负权回路。
::: solution
各边按列表次序松弛，先松弛 $t$、$x$、$y$、$z$ 的出边，最后才松弛 $s$ 的出边。*第 1 轮：*只有 $s$ 的出边能找到有限的 $u.d$，得 $t.d = 6$、$y.d = 7$。*第 2 轮：*由 $t$：$x \gets 6 + 5 = 11$，随后 $z \gets 6 - 4 = 2$；由 $y$：$x \gets 7 - 3 = 4$。*第 3 轮：*由 $x$：$t \gets 4 - 2 = 2$。*第 4 轮：*由 $t$：$z \gets 2 - 4 = -2$。最短路径是 $s \to y \to x \to t \to z$，权为 $7, 4, 2, -2$：到 $z$ 的路径有四条边，这就是它需要全部 $n - 1 = 4$ 轮的原因（在这一边序之下）。加上权为 $1$ 的边 $x \to y$ 后，回路 $y \to x \to y$ 的权为 $-3 + 1 = -2 < 0$；它从 $s$ 可达，于是最后的检查发现仍有可松弛的边，函数返回 `None`。
:::
:::

贝尔曼-福特的 $\Theta(nm)$ 远比图搜索慢，但它通用、简单，而且易于分布执行：在**距离向量路由**（RIP，一种早期的互联网路由协议）中，每个路由器都利用邻居广播来的估计值反复松弛与自己相邻的链路，这相当于并行地运行贝尔曼-福特算法。

::: quiz
贝尔曼-福特算法在某个图上返回 FALSE。你能得出什么结论？

- [ ] 某条边的权为负，必须改用迪杰斯特拉算法。
- [x] 某个总权为负的回路从 $s$ 可达，于是从 $s$ 出发的某些最短路径权为 $-\infty$。
- [ ] 每个顶点都有 $\delta(s, v) = -\infty$。
- [ ] 图中有回路。
::: solution
由 [[#thm-bellman-ford]]，FALSE 恰表示存在从 $s$ 可达的负权回路。那时每个*由该回路*可达的顶点都有 $\delta(s, v) = -\infty$，但从它不可达的顶点保持有限的距离，所以并非每个 $\delta$ 都是 $-\infty$。仅有负边不会导致 FALSE，而迪杰斯特拉算法在这里只会算错，并不是补救办法。含有非负权回路的图仍使贝尔曼-福特算法返回 TRUE。
:::

### DAG 上的最短路径

若 $G$ 无圈，就根本没有回路，一趟松弛就够了——只要按合适的次序松弛各边。先把顶点拓扑排序（[[algorithms/graph-search#thm-topo]]），再按该次序松弛每个顶点的出边。任何路径都按拓扑序经过其顶点，于是它的各边按序被松弛，由路径松弛，一趟之后每个估计值都已正确：算法以 $\Theta(n + m)$ 时间运行，允许任意（哪怕负）的权。把权全部取反就得到 DAG 上的*最长*路径——即任务为顶点、边为优先约束的一个项目的**关键路径**，它决定最短可能的完工时间。（在一般图中，最长简单路径是 $\mathsf{NP}$-难的；见 [[complexity]]。）

```python
from math import inf

def dag_shortest_paths(order, adj, s):
    """order: a topological order; adj[u] = [(v, w), ...]; any weights."""
    dist = {u: inf for u in order}
    dist[s] = 0
    for u in order:                      # 每条路径的各边都按序松弛
        for v, w in adj[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
    return dist

adj = {'r': [('s', 5), ('t', 3)], 's': [('t', 2), ('x', 6)],
       't': [('x', 7), ('y', 4), ('z', 2)], 'x': [('y', -1), ('z', 1)],
       'y': [('z', -2)], 'z': []}
print(dag_shortest_paths(['r', 's', 't', 'x', 'y', 'z'], adj, 's'))
```

```console
$ python3 dag.py

```

::: solution
按拓扑序 $r, s, t, x, y, z$：$r$ 从 $s$ 不可达（没有指向 $r$ 的边），故其估计值保持 $\infty$，松弛它的出边不改变任何东西。由 $s$：$t \gets 2$，$x \gets 6$。由 $t$：对 $x$：$2 + 7 = 9 > 6$，不变；$y \gets 6$；$z \gets 4$。由 $x$：$y \gets 6 - 1 = 5$；对 $z$：$6 + 1 = 7 > 4$，不变。由 $y$：$z \gets 5 - 2 = 3$。于是沿 $s \to x \to y \to z$ 有 $\delta(s, z) = 3$。当一个顶点的出边被松弛时，*进入*它的每条边都已经松弛过（其尾在序中更靠前），所以它的估计值已是最终值——负权无害，因为没有回路可钻。
:::
:::

## 迪杰斯特拉算法

当所有边权非负时，我们能远比贝尔曼-福特做得更好：每个顶点的出边只需在恰当的时机松弛一次。迪杰斯特拉算法就是把队列换成优先队列的 BFS：它维护一个距离已经确定的顶点集合 $S$，反复把 $S$ 之外估计值最小的顶点并入 $S$。

::: algorithm 迪杰斯特拉算法 {#alg-dijkstra}
```text
DIJKSTRA(G, w, s)                    ▷ 要求每条边 w(u, v) ≥ 0
1  initialise: s.d ← 0; v.d ← ∞ and v.π ← NIL for v ≠ s
2  S ← ∅
3  Q ← a min-priority queue of all vertices, keyed by d
4  while Q is not empty
5      u ← EXTRACT-MIN(Q)
6      S ← S ∪ {u}
7      for each v in Adj[u]
8          RELAX(u, v, w)            ▷ 若 v.d 改变则对 Q 作 DECREASE-KEY
```
:::

::: theorem 迪杰斯特拉算法的正确性 {#thm-dijkstra}
若每条边都满足 $w(u, v) \ge 0$，则迪杰斯特拉算法终止时对每个顶点 $u$ 有 $u.d = \delta(s, u)$；进一步，$u$ 被并入 $S$ 的时刻就已经有 $u.d = \delta(s, u)$。
:::

::: proof
由于估计值一旦等于 $\delta$ 就不再改变（[[#lem-relax]]），只需证明后一结论。反设不然，设 $u$ 是第一个被并入 $S$ 时满足 $u.d \ne \delta(s, u)$ 的顶点。则 $u \ne s$（没有负权回路，故最先并入的是 $s$，且 $s.d = 0 = \delta(s, s)$），因而 $u$ 并入之前 $S \ne \emptyset$。从 $s$ 到 $u$ 存在路径，否则 $u.d = \infty = \delta(s, u)$；设 $p$ 是一条最短路径。它起点在 $S$ 中、终点在 $S$ 外，设 $y$ 为 $p$ 中第一个不属于 $S$ 的顶点，$x \in S$ 为它在 $p$ 上的前驱。由于 $x$ 是被正确并入的（$u$ 是第一个反例），$x$ 并入时 $x.d = \delta(s, x)$，且当时松弛了边 $(x, y)$；由收敛性（[[#lem-relax]]），从那时起 $y.d = \delta(s, y)$。

现在，$y$ 在最短路径 $p$ 上先于 $u$，且从 $y$ 到 $u$ 的其余各边带有**非负权**，故 $\delta(s, y) \le \delta(s, u)$。于是
$$
y.d = \delta(s, y) \le \delta(s, u) \le u.d.
$$
但 $u$ 被选中时 $y$ 和 $u$ 都在 $S$ 之外，而 $u$ 正因估计值最小才被选中，故 $u.d \le y.d$。因此上述各不等式全是等式，$u.d = \delta(s, u)$——矛盾。
:::

非负权唯一的用处在 $\delta(s, y) \le \delta(s, u)$ 这一步：$y$ 之后路径的那一段不可能使总权变小。有负权时，失败的恰恰就是这一步。

```python
import heapq
from math import inf

def dijkstra(adj, s):
    """Shortest-path weights from s; adj[u] = [(v, w), ...] with w >= 0."""
    dist = {u: inf for u in adj}
    parent = {u: None for u in adj}
    dist[s] = 0
    heap = [(0, s)]                      # （临时距离, 顶点）
    done = set()
    while heap:
        d, u = heapq.heappop(heap)
        if u in done:                    # 过时条目：u 已被确定
            continue
        done.add(u)
        for v, w in adj[u]:
            if d + w < dist[v]:          # 松弛边 (u, v)
                dist[v] = d + w
                parent[v] = u
                heapq.heappush(heap, (dist[v], v))
        print(u, d)
    return dist, parent

adj = {'s': [('t', 10), ('y', 5)], 't': [('x', 1), ('y', 2)],
       'x': [('z', 4)], 'y': [('t', 3), ('x', 9), ('z', 2)],
       'z': [('s', 7), ('x', 6)]}
dist, parent = dijkstra(adj, 's')
print(dist)
```

Python 的 `heapq` 没有 decrease-key 操作，所以这个实现每当估计值改进就压入一个新条目，并在弹出时跳过**过时**的条目——这就是所谓*懒惰删除*的标准技巧。

::: theorem 迪杰斯特拉算法的运行时间 {#thm-dijkstra-time}
用二叉堆时，迪杰斯特拉算法运行 $O((n + m)\log n)$ 时间。用斐波那契堆（摊还 $O(1)$ 的 decrease-key）时运行 $O(m + n\log n)$。
:::

::: proof
每个顶点被提取（确定）一次，每条边在其尾被确定时松弛一次。用按 $d$ 作键的二叉堆（[[data-structures/heaps]]），$n$ 次 extract-min 和至多 $m$ 次 decrease-key 各花 $O(\log n)$。改用懒惰删除时，压入的条目总数至多 $m + 1$，堆中元素从不超过 $m + 1 \le n^2$ 个，每次压入或弹出花 $O(\log m) = O(\log n)$，而弹出至多 $m + 1$ 次。两种做法总数都是 $O((n + m)\log n)$。斐波那契堆支持摊还 $O(1)$ 的 insert 和 decrease-key、摊还 $O(\log n)$ 的 extract-min，于是得到 $O(m + n\log n)$。
:::

::: warning 迪杰斯特拉算法要求非负权
只要有一条负权边，迪杰斯特拉算法就可能不声不响地返回错误的距离。在图 $s \to a$（权 $1$）、$a \to c$（$1$）、$s \to b$（$3$）、$b \to a$（$-3$）上，它在确定 $b$ 之前就确定了 $a$（距离 $1$）和 $c$（距离 $2$）；真实距离是 $\delta(s, a) = 0$ 和 $\delta(s, c) = 1$，经由 $s \to b \to a \to c$。在它上面运行列表中的 `dijkstra` 会打印 `{'s': 0, 'a': 0, 'b': 3, 'c': 2}`：对 $b \to a$ 的迟到松弛甚至纠正了 $a$，但 $c$ 因 $a$ 的旧估计值而提前确定，仍是错的。给每条边加上一个常数使权都变为非负也无济于事：那会惩罚边数多的路径，改变哪条路径最短。应当使用贝尔曼-福特算法，或 Johnson 重赋权（见下文），后者改变权的方式保持最短路径不变。
:::

::: quiz
在正权无向图上运行迪杰斯特拉算法。顶点 $u$ 从优先队列中弹出时，哪条陈述为真？

- [x] 每个满足 $\delta(s, v) < \delta(s, u)$ 的顶点 $v$ 都已经弹出。
- [ ] $u$ 的每个邻点都已经弹出。
- [ ] $u.\pi$ 恰是紧挨在 $u$ 之前弹出的顶点。
- [ ] 任何未弹出顶点的估计值都不会再改变。
::: solution
顶点按 $\delta$ 的非降次序弹出：由 [[#thm-dijkstra]]，每个顶点弹出时都有 $u.d = \delta(s, u)$；若 $\delta(s, v)$ 更小的顶点 $v$ 还留在队列中，则它在最短路径上的前驱一旦被确定，$v.d$ 就正确了——对 $\delta$ 归纳可知所有这样的 $v$ 都更早弹出。其余陈述都会落空：邻点可能更远；前驱可能早在许多步之前就被确定（例如 $y$ 是 $z$ 的前驱而 $z$ 紧跟 $y$ 弹出，但 $t$ 的前驱 $y$ 在 $t$ 前两步就被确定了）；而且弹出 $u$ 会松弛它的边，可能改变估计值。
:::
:::

## 所有顶点对之间的最短路径

要计算每对顶点之间的 $\delta(u, v)$，可以从每个顶点各运行一次单源算法：$n$ 次迪杰斯特拉算法花费 $O(n(n + m)\log n)$，$n$ 次贝尔曼-福特算法花费 $O(n^2m)$，对稠密图即 $O(n^4)$。**弗洛伊德-沃沙尔算法**对稠密图更好，允许负权，它把动态规划建立在“路径允许经过哪些中间顶点”这个集合上。

把顶点编号为 $1, \dots, n$。对 $0 \le k \le n$，设 $d^{(k)}_{ij}$ 为从 $i$ 到 $j$、所有**中间**顶点（端点之外）都在 $\{1, \dots, k\}$ 中的路径的最小权。于是 $d^{(0)}_{ij}$ 在有边时为 $w(i, j)$，$i = j$ 时为 $0$，其余情况为 $\infty$；而 $d^{(n)}_{ij} = \delta(i, j)$。

::: lemma 弗洛伊德-沃沙尔递推式 {#lem-fw}
若 $G$ 没有负权回路，则对 $k \ge 1$
$$
d^{(k)}_{ij} = \min\big(d^{(k-1)}_{ij},\; d^{(k-1)}_{ik} + d^{(k-1)}_{kj}\big).
$$ {#eq-fw}
:::

::: proof
考察一条中间顶点在 $\{1, \dots, k\}$ 中、从 $i$ 到 $j$ 的最轻路径 $p$，取它是简单的（无负权回路时可行）。若 $k$ 不是 $p$ 的中间顶点，则 $p$ 的中间顶点在 $\{1, \dots, k-1\}$ 中，$w(p) = d^{(k-1)}_{ij}$。若 $k$ 是中间顶点，它恰好出现一次，把 $p$ 分成从 $i$ 到 $k$ 和从 $k$ 到 $j$ 的两段路径，二者的中间顶点都在 $\{1, \dots, k - 1\}$ 中，且由 [[#lem-subpath]] 的子路径论证各自是此类中最轻的：$w(p) = d^{(k-1)}_{ik} + d^{(k-1)}_{kj}$。所以 $d^{(k)}_{ij}$ 是 [[#eq-fw]] 中两个值之一；同时它不大于其中任何一个，因为每个值都是某条中间顶点在 $\{1, \dots, k\}$ 中的从 $i$ 到 $j$ 的行的权（经过 $k$ 而重复顶点的行都含一条不多重的简单路径不更重，因为圈非负）。
:::

::: algorithm 弗洛伊德-沃沙尔算法 {#alg-floyd-warshall}
从矩阵 $D = (d^{(0)}_{ij})$ 出发。对 $k = 1, \dots, n$，对每对 $i$ 和 $j$，置 $D[i][j] \gets \min(D[i][j], D[i][k] + D[k][j])$。返回 $D$。
:::

就地对 $D$ 修正是安全的：第 $k$ 轮期间，元素 $D[i][k]$ 和 $D[k][j]$ 不会改变，因为 $d^{(k)}_{ik} = d^{(k-1)}_{ik}$（到 $k$ 的路径把 $k$ 用作中间顶点不会更省，因为圈非负）。于是算法以 $\Theta(n^3)$ 时间、$\Theta(n^2)$ 空间算出一切 $\delta(i, j)$。若 $G$ 有负权回路，某个对角元素最终为负，这就是标准检测方法。

```python
from math import inf

def floyd_warshall(n, edges):
    """All-pairs shortest-path weights for vertices 0..n-1."""
    D = [[0 if i == j else inf for j in range(n)] for i in range(n)]
    for u, v, w in edges:
        D[u][v] = min(D[u][v], w)
    for k in range(n):                  # 允许 k 作为中间顶点
        for i in range(n):
            for j in range(n):
                if D[i][k] + D[k][j] < D[i][j]:
                    D[i][j] = D[i][k] + D[k][j]
    return D

edges = [(0, 1, 3), (0, 2, 8), (0, 4, -4), (1, 3, 1), (1, 4, 7),
         (2, 1, 4), (3, 0, 2), (3, 2, -5), (4, 3, 6)]
for row in floyd_warshall(5, edges):
    print(row)
```


::: example 读懂矩阵 {#ex-fw}
由输出看，从 $0$ 到 $2$ 的最短路径是什么？算法还能怎样同时报告路径本身而不仅是其权？
::: solution
$D[0][2] = -3$。达到该值的一条路径：$0 \to 4$（$-4$）、$4 \to 3$（$6$）、$3 \to 2$（$-5$），总权 $-3$；与权为 $8$ 的直接边比较。要恢复路径，可维护一个矩阵 $\mathit{next}[i][j]$：在已知的从 $i$ 到 $j$ 的最好路径上紧跟 $i$ 之后的顶点。初始时对每条边置 $\mathit{next}[i][j] = j$，每当 $D[i][j]$ 经过 $k$ 得到改进就置 $\mathit{next}[i][j] \gets \mathit{next}[i][k]$。然后沿 $i, \mathit{next}[i][j], \mathit{next}[\mathit{next}[i][j]][j], \dots$ 一路走到 $j$。这里 $\mathit{next}[0][2] = 4$、$\mathit{next}[4][2] = 3$、$\mathit{next}[3][2] = 2$。
:::
:::

对带负权（但无负权回路）的稀疏图，**Johnson 算法**更快。添加一个新顶点 $q$，向每个顶点连一条零权边，从 $q$ 运行贝尔曼-福特算法得 $h(v) = \delta(q, v)$，再把每条边重赋为
$$
\hat w(u, v) = w(u, v) + h(u) - h(v) \ge 0,
$$
由三角不等式 $h(v) \le h(u) + w(u, v)$ 知其非负。从 $a$ 到 $b$ 的任何路径 $p$ 都满足 $\hat w(p) = w(p) + h(a) - h(b)$——中间的 $h$ 项裂项相消——所以这种重赋权对端点相同的所有路径改变同一个量，保持了哪些路径最短。然后 $n$ 次迪杰斯特拉算法以 $O(nm\log n)$ 时间给出所有点对。

::: history
最短路在 20 世纪 50 年代成为研究课题，动力来自电话网路由与运筹学。莱斯特·福特（Lester Ford Jr.）在 1956 年的一份 RAND 报告中描述了松弛方法；理查德·贝尔曼（Richard Bellman）在论文 “On a routing problem”（1958）中给出了动态规划形式；爱德华·穆尔（Edward F. Moore）于 1959 年发表了等价的方法；该算法以贝尔曼和福特命名。艾兹赫尔·迪杰斯特拉（Edsger Dijkstra）于 1956 年为演示 ARMAC 计算机设计了他的算法——他后来说那大约花了二十分钟，就坐在阿姆斯特丹的一家咖啡馆里——并发表在 “A note on two problems in connexion with graphs”（*Numerische Mathematik*，1959），其中还有最小生成树算法。罗伯特·弗洛伊德（Robert Floyd）的所有点对算法（“Algorithm 97: Shortest path”，1962）建立在斯蒂芬·沃沙尔（Stephen Warshall）同年的传递闭包算法（以及伯纳德·罗伊（Bernard Roy）1959 年的工作）之上。唐纳德·约翰逊（Donald Johnson）的重赋权出现于 1977 年；迈克尔·弗雷德曼（Michael Fredman）与罗伯特·塔扬（Robert Tarjan）的斐波那契堆（1984 年，期刊版 1987 年）给出了迪杰斯特拉算法的 $O(m + n\log n)$ 上界。
:::

## 实践中

路网路线规划程序并不会对每次查询都在大陆尺度的路网上跑一遍朴素的迪杰斯特拉算法。截至 2026 年，它们依赖预处理技术——带地标下界的 A* 搜索、*收缩层次*及相关方法——以数小时的预处理换取快上千倍的查询；所有这些方法的正确性都由同样的松弛论证证明，且都假定权非负。互联网路由两类协议并用：距离向量协议是分布式贝尔曼-福特，而 OSPF 这样的链路状态协议则让每个路由器在网络地图上运行迪杰斯特拉算法。

## 后续内容

迪杰斯特拉算法是**贪心**算法——它一次确定最近的顶点而从不回头——其证明正是 [[algorithms/greedy-algorithms]] 中交换论证的一次运用；普里姆最小生成树算法与它几乎同出一码。贝尔曼-福特与弗洛伊德-沃沙尔则是**动态规划**，即 [[algorithms/dynamic-programming]] 的主题；它们的子问题分别是“至多 $i$ 条边的最短路径”和“只经过前 $k$ 个顶点的最短路径”。最短增广路径将在 [[algorithms/network-flow]] 中重现，启发式搜索（A*）则见 [[artificial-intelligence]]。

::: summary
- $\delta(s, v)$ 是从 $s$ 到 $v$ 的路径的最小权；若途中可达负权回路则为 $-\infty$。最短路径的子路径仍是最短路径（[[#lem-subpath]]）。
- 所有单源算法都**松弛**边；估计值是上界，按次序松弛一条最短路径的各边能使估计值精确（[[#lem-relax]]）。
- **贝尔曼-福特**把每条边松弛 $n - 1$ 次，能处理负权并检测可达的负权回路，用时 $\Theta(nm)$（[[#thm-bellman-ford]]）。在 DAG 上按拓扑序扫描一趟即可：$\Theta(n + m)$。
- **迪杰斯特拉**按距离次序确定各顶点；它只在对**非负权**时正确（[[#thm-dijkstra]]），用二叉堆时运行 $O((n + m)\log n)$（[[#thm-dijkstra-time]]）。
- **弗洛伊德-沃沙尔**由 $d^{(k)}_{ij} = \min(d^{(k-1)}_{ij}, d^{(k-1)}_{ik} + d^{(k-1)}_{kj})$ 以 $\Theta(n^3)$ 算出所有点对（[[#lem-fw]]）；**Johnson** 用势函数重赋权，再从每个顶点运行迪杰斯特拉算法。
:::

::: exercise 手算一条最短路径 {level=1 check="7"}
在具有边 $A$–$B$（$4$）、$A$–$C$（$1$）、$C$–$B$（$2$）、$B$–$D$（$1$）、$C$–$D$（$5$）、$D$–$E$（$3$）的无向图上从 $A$ 运行迪杰斯特拉算法。各顶点按什么次序被确定，$\delta(A, E)$ 是多少？（输入 $\delta(A, E)$。）
::: solution
确定 $A$（$0$）：$B = 4$，$C = 1$。确定 $C$（$1$）：$B = \min(4, 1 + 2) = 3$，$D = 6$。确定 $B$（$3$）：$D = \min(6, 3 + 1) = 4$。确定 $D$（$4$）：$E = 7$。确定 $E$（$7$）。次序 $A, C, B, D, E$；沿 $A, C, B, D, E$ 有 $\delta(A, E) = 7$。
:::
:::

::: exercise 需要几轮？ {level=1 check="1"}
在路 $s \to v_1 \to v_2 \to \dots \to v_{9}$（正权）上运行贝尔曼-福特算法，边按 $(s, v_1), (v_1, v_2), \dots, (v_8, v_9)$ 的次序列出。几轮之后所有估计值都正确？（输入轮数。）
::: solution
第 1 轮中各边按路径方向松弛，所以每个 $v_i.d$ 都在 $v_{i-1}.d$ 之后立即变正确：由路径松弛，一轮就够。若边按*逆*序列出，则每轮只能多修正一个顶点，需要全部 $9$ 轮。贝尔曼-福特的 $n - 1$ 轮覆盖了最坏的边序；一个常用优化是某轮一无所改就立即停止。
:::
:::

::: exercise 交易者的回路 {level=2}
汇率如下：$1$ 英镑可买 $1.20$ 欧元，$1$ 欧元可买 $1.10$ 美元，$1$ 美元可买 $0.78$ 英镑。说明如何用最短路径算法发现这样的套利机会，并判断这次是否有利可图。
::: solution
一列兑换把汇率相乘得 $r_1 r_2 \cdots r_k$；绕一圈有利可图当且仅当乘积超过 $1$，即 $\sum\log r_i > 0$，即 $\sum(-\log r_i) < 0$。于是给每条边赋权 $-\log r$，用贝尔曼-福特算法寻找负权回路。这里 $1.20 \times 1.10 \times 0.78 = 1.0296 > 1$：一英镑变成约 $1.03$ 英镑，回路的权为 $-\ln 1.0296 \approx -0.029 < 0$。（真实市场会很快抹平这样的差价，而且交易成本通常超过差价。）
:::
:::

::: exercise 手算弗洛伊德-沃沙尔 {level=2 check="5"}
对顶点为 $1, 2, 3$、边为 $1 \to 2$（$8$）、$1 \to 3$（$3$）、$3 \to 2$（$2$）、$2 \to 1$（$4$）的图，计算 $D^{(1)}, D^{(2)}, D^{(3)}$ 并给出 $\delta(1, 2)$。（输入 $\delta(1, 2)$。）
::: solution
$D^{(0)}$ 的各行是 $(0, 8, 3)$、$(4, 0, \infty)$、$(\infty, 2, 0)$。$k = 1$：$D[2][3] = \min(\infty, 4 + 3) = 7$；其余不变：各行 $(0, 8, 3)$、$(4, 0, 7)$、$(\infty, 2, 0)$。$k = 2$：$D[3][1] = \min(\infty, 2 + 4) = 6$；$D[1][3]$：$8 + 7 > 3$，不变：各行 $(0, 8, 3)$、$(4, 0, 7)$、$(6, 2, 0)$。$k = 3$：$D[1][2] = \min(8, 3 + 2) = 5$；$D[2][1]$：$7 + 6 > 4$，不变：各行 $(0, 5, 3)$、$(4, 0, 7)$、$(6, 2, 0)$。故 $\delta(1, 2) = 5$，经由 $3$。
:::
:::

::: exercise 懒惰删除的计数 {level=2}
在列表的 `dijkstra` 中，对例图一共向堆中压入多少个条目？弹出的条目中有多少个已过时？并说明为什么一般情况下压入次数至多 $m + 1$。
::: solution
压入：最初的 $(0, s)$，其后每次成功松弛压一个：$s\to t$、$s \to y$；$y \to t$、$y \to x$、$y \to z$；$z \to x$；$t \to x$——共 $1 + 7 = 8$ 次压入。弹出：$8$ 次，其中 $5$ 次确定一个顶点，$3$ 次已过时：$(10, t)$、$(14, x)$、$(13, x)$。一般情况下每条边 $(u, v)$ 只松弛一次——在 $u$ 被确定时——所以它至多引起一次压入；加上初始条目，压入至多 $m + 1$ 次。
:::
:::

::: exercise 最可靠路径 {level=2}
网络的每条链路独立失效，链路 $(u, v)$ 正常工作的概率为 $r(u, v) \in (0, 1]$。说明如何用迪杰斯特拉算法找出从 $s$ 到 $t$ 最可能工作的路径，并说明其正确性条件为什么成立。
::: solution
一条路径正常工作的概率为 $\prod r(u, v)$，当 $\sum(-\log r(u, v))$ 最小时最大。由于 $0 < r \le 1$，每个权 $-\log r(u, v) \ge 0$，故迪杰斯特拉算法的条件成立，它的最短路径就是最可靠路径。（等价地，直接用概率相乘、“最大优先”运行迪杰斯特拉算法；[[#thm-dijkstra]] 的证明照样成立，因为乘以不超过 $1$ 的数决不会使概率变大——这正是非负权的类比。）
:::
:::

::: exercise 只有源点出发的边为负权 {level=3}
设唯一带负权的边都是从源 $s$ 出发的，且没有进入 $s$ 的边。证明迪杰斯特拉算法仍能算出正确的距离。
::: solution
设 $c$ 为 $s$ 的各出边权的最小值（可能为负），并考察 [[#thm-dijkstra]] 的证明。从 $s$ 到 $v \ne s$ 的任何路径都是：$s$，接一条边 $(s, x)$，再接一条从 $x$ 出发、全由非负权边组成的路径（没有边回到 $s$）。设 $u$ 是第一个以错误估计值被确定的顶点；按证明选取 $x, y$，其中 $y$ 是到 $u$ 的最短路径 $p$ 中第一个不在 $S$ 中的顶点。由于 $s \in S$ 最先被确定，$y \ne s$，且 $p$ 在 $y$ 之后的部分只用到不离开 $s$ 的边——全部非负。所以 $\delta(s, y) \le \delta(s, u)$ 依然成立，证明的其余部分不变。（等价地，给 $s$ 的每条出边加上 $-c$：从 $s$ 出发的每条路径恰用这样一条边，于是所有路径的权改变同一个量，最短路径保持不变。）
:::
:::

::: exercise 至多 k 条边的最短路径 {level=3}
设 $d_i(v)$ 为从 $s$ 到 $v$、至多 $i$ 条边的路径的最小权。证明：对贝尔曼-福特的一个变体——每轮都使用上一轮的估计值（$d_i(v) = \min(d_{i-1}(v), \min_{(u,v)\in E} d_{i-1}(u) + w(u, v))$）——$i$ 轮之后的估计值恰为 $d_i(v)$；并说明为什么 [[#alg-bellman-ford]] 的就地版本可能*领先*于 $d_i$。
::: solution
对 $i$ 归纳。$d_0(s) = 0$，其余 $d_0(v) = \infty$，与初始化一致。到 $v$ 至多 $i$ 条边的路径要么至多 $i - 1$ 条边（权 $\ge d_{i-1}(v)$，可取等号），要么恰有 $i \ge 1$ 条边，以一条到 $u$ 的 $i - 1$ 条边的路径再接边 $(u, v)$ 结束（权 $\ge d_{i-1}(u) + w(u, v)$，可取等号）。所以 $d_i(v)$ 就是这些值的最小值，这正是该递推式；而这一轮恰好由上一轮的值算出它。在就地版本中，本轮较早更新的估计值会被立即使用，所以一轮能沿多条边传播（如第二题的路径例子）：第 $i$ 轮之后估计值不超过 $d_i(v)$，且仍不低于 $\delta(s, v)$。这使就地版本只会更快，但“恰 $i$ 条边”的解释——例如中途至多 $k$ 站的最廉价航班问题所需要的——必须用两个数组的版本。
:::
