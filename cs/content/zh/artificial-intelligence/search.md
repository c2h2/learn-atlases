把 8 数码——$3 \times 3$ 框里的八个带数字的方块和一个空格——的滑块从打乱状态滑动到 $1, 2, \dots, 8$ 的排列。为送货车规划一条路线。找一个复原魔方的动作序列，或找一个组装产品的工序序列。这些都是**搜索问题**：智能体确切知道自己的动作如何改变世界，世界完全可观察且确定，它必须找到一条从所在状态走到目标状态成立的*动作序列*——而且要在行动之前全部想好。这就是 [[artificial-intelligence/intelligent-agents]] 中最简单的一类基于目标的智能体，它需要的算法是图上搜索算法，跑在大得从来无法写下的图上。

[[algorithms/graph-search]] 的广度优先搜索与 [[algorithms/shortest-paths]] 的迪杰斯特拉算法原则上能解这类问题。困难在规模：8 数码有 $181{,}440$ 个可达状态，15 数码约 $10^{13}$ 个，魔方约 $4.3 \times 10^{19}$ 个。本章讲怎样在*不*访问其大部分状态的前提下搜索这样的空间。我们先把熟悉的算法改写为**无信息**策略并加以比较，加入迭代加深——它结合了深度优先搜索的低内存与广度优先搜索的最优性。然后加入**启发式**——到目标距离的估计——并证明：由可容许启发式引导的 A* 搜索仍然找到最优解，同时只扩展启发式无法排除的状态。更好的启发式可以证明地扩展更少的状态，我们还将看到如何构造它们。

## 搜索问题

::: definition 搜索问题 {#def-search-problem}
一个**搜索问题**由以下部分构成
- 状态集 $S$ 与**初始状态** $s_0 \in S$；
- 对每个状态 $s$，一个有限的适用动作集 $\mathrm{Actions}(s)$；
- **转移模型** $\mathrm{Result}(s, a) \in S$，即在 $s$ 中执行 $a$ 到达的状态；
- **目标测试**：目标状态集 $S_G \subseteq S$（常以谓词给出）；
- 每次转移的**动作代价** $c(s, a, s') > 0$。

**解**是一个动作序列 $a_1, \dots, a_k$，其状态 $s_i = \mathrm{Result}(s_{i-1}, a_i)$ 终止于某个目标状态 $s_k \in S_G$；其**代价**是各动作代价之和。**最优**解在所有解中代价最小；我们记该代价为 $C^*$。
:::

状态与转移构成一张有向图，即**状态空间**。它是*隐式*给出的：我们能计算一个状态的后继，却无法列出所有状态。有两个量刻画它的规模以供算法分析：**分支因子** $b$，一个状态的后继数的最大值；最浅目标的**深度** $d$（最短解中的动作数）。我们还以 $m$ 表示空间中任意路径的最大长度，它可能是无穷的。全程假设每个动作至少花费某个 $\varepsilon > 0$；否则搜索可以沿着总代价越来越小的路径永远游荡下去。

::: example 8 数码的形式化 {#ex-8puzzle}
把 8 数码形式化为搜索问题，并数一数它的状态。
::: solution
*状态*是八个方块与空格在九个格子上的一种摆法，我们按行阅读顺序写成九个分量的元组，空格记 $0$：目标是 $(1, 2, 3, 4, 5, 6, 7, 8, 0)$。最自然的想法是把*动作*看作把空格*Up*、*Down*、*Left* 或 *Right* 地移动（把相邻方块滑进空格）；空格不在相应边上时动作可适用，故一个状态有 $2$、$3$ 或 $4$ 个后继，$b = 4$。*转移模型*交换空格与相邻方块。每个动作代价 $1$，于是最优解就是最短解。

共有 $9! = 362{,}880$ 种摆法，但从任一摆法出发只有一半可达。按行阅读顺序读出八个方块，忽略空格。水平移动不改变这个序列；竖直移动使一个方块越过恰好两个方块，使**逆序对**（顺序颠倒的方块对）的个数改变 $-2$、$0$ 或 $+2$。所以逆序对数的奇偶性永不改变，而奇偶性为奇的摆法——目标没有逆序对——从目标不可达。所有奇偶性正确的 $9!/2 = 181{,}440$ 种摆法都可达，是一个经典定理。用 Python 从目标出发作广度优先搜索，恰好访问 $181{,}440$ 个状态，并发现最远的离目标 $31$ 步。**平均**分支因子约 $2.67$，小于 $b = 4$；若禁止撤销上一步，还会更低。
:::
:::

### 在状态空间中搜索

本章所有算法都在长一棵**搜索树**：树根是初始状态，结点与从根出发的路径相对应。一个**结点** $n$ 记录一个状态 $n.\mathit{state}$、一个父结点、导致它的动作、以及从根来的**路径代价** $g(n)$。**扩展**一个结点就是生成它的子结点，每个适用动作一个。已生成但尚未扩展的结点之集称为**前沿**。由于许多路径通向同一个状态，图上的搜索还要记住它已经**到达**过哪些状态以及到每个状态的最佳路径代价——恰是 [[algorithms/shortest-paths]] 中的 $v.d$ 估计。

::: algorithm 最佳优先搜索 {#alg-best-first}
```text
BEST-FIRST-SEARCH(problem, f)
1  node ← NODE(state = s0, g = 0)
2  frontier ← priority queue ordered by f, containing node
3  reached ← table {s0: node}
4  while frontier is not empty
5      node ← POP(frontier)                    ▷ f 最小的结点
6      if node.state is a goal: return node    ▷ 扩展时做目标测试
7      for each child of EXPAND(node)
8          s ← child.state
9          if s not in reached or child.g < reached[s].g
10             reached[s] ← child
11             add child to frontier
12 return failure
```
:::

不同的评估函数 $f$ 给出不同的算法。$f(n) = g(n)$ 时就是**一致代价搜索**，即在隐式图上运行、遇到第一个目标就停止的迪杰斯特拉算法；它对正代价的正确性见 [[algorithms/shortest-paths#thm-dijkstra]]。取 $f(n) = \text{深度}(n)$ 并用先进先出队列代替优先队列，就是广度优先搜索（[[algorithms/graph-search#thm-bfs]]），它可以在结点被*生成*而非扩展时做目标测试，从而省下一整层。第 6 行扩展时的目标测试对一致代价搜索至关重要：第一个*到达*目标状态的路径未必最便宜，只有当目标被弹出时它的代价才最小。

::: widget graph
nodes: S@0,1; A@1,2; B@1,0; C@2,2; D@2,0; G@3,1
edges: S-A:2; S-B:1; A-C:2; B-C:4; B-D:6; C-D:1; C-G:5; D-G:3
algorithm: dijkstra
start: S
caption: 一致代价搜索就是迪杰斯特拉算法。从 $S$ 一步步演示：目标 $G$ 第一次被到达时代价为 $9$（经 $C$，即 $C$ 被确定之时），但它被确定时代价已是 $8$，经 $D$ 到达。一生成 $G$ 就停的搜索会返回较差的路径。再看 $G$ 之前确定了多少个顶点——凡是距离小于 $8$ 的一个不落。A*（下文）用启发式避开其中一些。
:::

## 无信息搜索

**无信息**（亦称**盲目**）策略只利用问题定义：它们无法分辨一个非目标状态是否比另一个"离目标更近"。我们从四条标准评判：**完备性**（有解时是否一定能找到解？）、**代价最优性**（找到的解是否最优？）、**时间**与**空间**，以生成和存储的结点数度量，写成 $b$、$d$、$m$ 与 $C^*/\varepsilon$ 的函数。

- **广度优先搜索**（BFS）在 $b$ 有限时完备，所有动作代价相同时最优。它生成 $1 + b + b^2 + \dots + b^d = O(b^d)$ 个结点且必须全部保留，故空间为 $O(b^d)$——这是致命的弱点。设 $b = 10$、每秒生成一百万个结点，深度 $10$ 需要 $10^{10}$ 个结点：时间不到三小时，但（按每结点 100 字节）内存要一太字节。
- **一致代价搜索**在代价 $\ge \varepsilon > 0$ 时完备且最优。它扩展所有满足 $g(n) < C^*$ 的结点；最坏情况下这些结点深至 $\lfloor C^*/\varepsilon\rfloor$，时间与空间均为 $O(b^{1 + \lfloor C^*/\varepsilon\rfloor})$——廉价动作很多时，这可能远大于 $b^d$。
- **深度优先搜索**（DFS）总是扩展最深的结点。它只需 $O(bm)$ 空间——当前路径加上沿途未扩展的兄弟结点——但它不最优，在无限空间上也不完备（有限空间若有圈，除非检查当前路径上的重复状态，同样不完备）。它的时间是 $O(b^m)$，$m \gg d$ 时惨不忍睹。
- **深度受限搜索**是把深度 $\ell$ 处的结点当作叶子的深度优先搜索。$\ell \ge d$ 时它完备。

**迭代加深**以限制 $0, 1, 2, \dots$ 依次运行深度受限搜索，直到找到解。

::: algorithm 迭代加深搜索 {#alg-ids}
```text
ITERATIVE-DEEPENING-SEARCH(problem)
1  for ℓ ← 0, 1, 2, …
2      result ← DEPTH-LIMITED-SEARCH(problem, ℓ)
3      if result ≠ cutoff: return result        ▷ 解，或者失败

DEPTH-LIMITED-SEARCH(problem, ℓ)              ▷ 不深入到深度 ℓ 以下的 DFS
1  return DLS(NODE(s0), ℓ)
DLS(node, ℓ)
1  if node.state is a goal: return node
2  if depth(node) = ℓ: return cutoff
3  cutoff_occurred ← false
4  for each child of EXPAND(node), 不重复当前路径上已有的状态
5      result ← DLS(child, ℓ)
6      if result = cutoff: cutoff_occurred ← true
7      else if result ≠ failure: return result
8  return cutoff if cutoff_occurred else failure
```
:::

迭代加深看上去很浪费：树的顶层每一轮都要重新生成。下一个定理表明浪费只是一个常数因子，因为在分支因子 $b \ge 2$ 的树中，大多数结点都在最底层。

::: theorem 迭代加深的代价 {#thm-ids}
在分支因子 $b \ge 2$、最浅目标在深度 $d$ 的正则树中，迭代加深在最坏情况下生成
$$
N_{\mathrm{IDS}} = \sum_{i=1}^{d} (d + 1 - i)\, b^i \;\le\; b^d \left(\frac{b}{b-1}\right)^{2}
$$
个结点（不含根），而广度优先搜索生成 $N_{\mathrm{BFS}} = \sum_{i=1}^d b^i \ge b^d$ 个。迭代加深使用 $O(bd)$ 空间；它完备，且所有动作代价相同时最优。
:::

::: proof
限制为 $\ell$ 的那一轮生成深度 $1, \dots, \ell$ 的每个结点（最坏情况，即目标恰是深度 $d$ 上最后一个被生成的结点时，最后一轮 $\ell = d$ 也如此）。因此深度 $i$ 的结点在每一轮 $\ell = i, i + 1, \dots, d$ 中各生成一次，共 $d + 1 - i$ 次，即得该和式。为估计它，令 $j = d - i$：
$$
N_{\mathrm{IDS}} = \sum_{j=0}^{d-1} (j + 1)\, b^{d - j} \le b^d \sum_{j=0}^{\infty} (j + 1)\, x^j = \frac{b^d}{(1 - x)^2}, \qquad x = \frac{1}{b},
$$
其中用到 $\lvert x\rvert < 1$ 时 $\sum_{j \ge 0} (j + 1)x^j = 1/(1-x)^2$（对几何级数逐项求导）。并且 $1/(1 - 1/b)^2 = (b/(b-1))^2$。

空间：每一轮是一次深度至多 $d$ 的深度优先搜索，存储当前路径与沿途结点的未扩展子结点，至多 $bd$ 个。完备性：若深度 $d$ 处有目标，则 $\ell = d$ 那轮一定能找到（深度受限搜索探索每条长度不超过 $\ell$ 的路径）。单位代价下的最优性：任何 $\ell < d$ 都找不到目标，因为深度小于 $d$ 处没有目标，所以返回的解长度恰为 $d$。
:::

::: example 迭代加深重复了多少？ {#ex-ids}
对 $b = 10$、$d = 5$ 比较 $N_{\mathrm{IDS}}$ 与 $N_{\mathrm{BFS}}$。
::: solution
$N_{\mathrm{IDS}} = 5 \cdot 10 + 4 \cdot 100 + 3 \cdot 1000 + 2 \cdot 10^4 + 1 \cdot 10^5 = 50 + 400 + 3000 + 20{,}000 + 100{,}000 = 123{,}450$，而 $N_{\mathrm{BFS}} = 10 + 100 + 1000 + 10^4 + 10^5 = 111{,}110$。迭代加深多做约 $11\%$ 的功，与渐近开销 $N_{\mathrm{IDS}}/N_{\mathrm{BFS}} \to b/(b-1) = 1.11$ 接近（[[#thm-ids]] 的界是相对 $b^d$ 的，故带平方）。作为交换，它至多存 $bd = 50$ 个结点而不是 $10^5$ 个。若 BFS 在生成时做目标测试而 IDS 无法避免生成最底层，二者就更接近了。深度大而未知时，迭代加深是首选的无信息方法。
:::
:::

::: widget plot
f: x/(x-1); (x/(x-1))^2
x: 2, 12
y: 0.8, 4.2
labels: N_{\mathrm{IDS}}/N_{\mathrm{BFS}} \text{（渐近）}; \text{定理关于 } b^d \text{ 的上界}
caption: 迭代加深的开销作为分支因子 $b$ 的函数。渐近地，迭代加深生成的结点数是广度优先搜索的 $b/(b-1)$ 倍；定理的上界 $(b/(b-1))^2$ 是相对最底层 $b^d$ 而言的。即使 $b = 2$ 开销也只有 $2$ 倍，$b \ge 10$ 时约为 $11\%$——用 $O(b^d)$ 的内存换到 $O(bd)$，这是很小的代价。
:::

**双向搜索**同时从起点正向、从目标反向各跑一路搜索，相遇即停；两个方向都用 BFS 时生成 $O(b^{d/2})$ 个结点而非 $O(b^d)$。它需要计算前驱的方法、单个显式的目标状态（或很少几个），代价不均衡时还需要小心设计的停止规则——第一处相遇点未必落在最优路径上。

| 策略 | 完备？ | 最优？ | 时间 | 空间 |
|---|---|---|---|---|
| 广度优先 | 是（$b$ 有限） | 单位代价 | $O(b^d)$ | $O(b^d)$ |
| 一致代价 | 是（代价 $\ge \varepsilon$） | 是 | $O(b^{1+\lfloor C^*/\varepsilon\rfloor})$ | $O(b^{1+\lfloor C^*/\varepsilon\rfloor})$ |
| 深度优先 | 否（无限空间） | 否 | $O(b^m)$ | $O(bm)$ |
| 深度受限（$\ell$） | $\ell \ge d$ 时 | 否 | $O(b^\ell)$ | $O(b\ell)$ |
| 迭代加深 | 是（$b$ 有限） | 单位代价 | $O(b^d)$ | $O(bd)$ |
| 双向（BFS） | 是 | 单位代价 | $O(b^{d/2})$ | $O(b^{d/2})$ |

::: quiz
分支因子约 $5$、单位动作代价、解的深度未知但估计在 $20$ 左右、内存有限——你会选哪种无信息策略？

- [ ] 广度优先搜索，因为它在单位代价下最优。
- [ ] 深度优先搜索，因为它内存省。
- [x] 迭代加深搜索。
- [ ] 一致代价搜索，因为它在任意代价下都最优。
::: solution
在深度 $20$，广度优先与一致代价搜索要存约 $5^{20} \approx 10^{14}$ 个结点。深度优先搜索内存便宜，却可能一头扎到深度 $20$ 以下很深的地方，且对最短解不作任何保证。迭代加深只存 $O(bd) \approx 100$ 个结点，完备，单位代价下找到最短解，并且由 [[#thm-ids]]，时间只比广度优先搜索多约 $b/(b-1) = 1.25$ 倍。
:::
:::

## 启发式搜索与 A*

**有信息**策略使用**启发式函数** $h(n)$：由 $n$ 的状态计算出、从 $n$ 的状态到目标的最低路径代价的估计。路线规划中，$h$ 可以取到目的地的直线距离；8 数码中，取放错位置的方块数。我们要求 $h(n) \ge 0$，且在目标状态处 $h(n) = 0$。

**贪心最佳优先搜索**扩展看上去离目标最近的结点，$f(n) = h(n)$。它常常很快，但无视已经付出的代价，因此不最优；在无限空间上还可能被永远引入歧途。**A\* 搜索**兼而有之：
$$
f(n) = g(n) + h(n),
$$ {#eq-astar-f}
即*经过* $n$ 的最优解的估计代价。A* 就是取这个 $f$ 的 [[#alg-best-first]]。它是否最优取决于启发式。

::: definition 可容许启发式与一致启发式 {#def-admissible}
设 $h^*(s)$ 为从 $s$ 到目标的最低代价路径的代价（不可达则为 $\infty$）。若启发式 $h$ 从不高估——对每个状态 $s$ 都有 $h(s) \le h^*(s)$——则称 $h$ **可容许**。若 $h$ 在目标状态处 $h(s) = 0$，且对每个状态 $s$、动作 $a$ 与后继 $s' = \mathrm{Result}(s, a)$ 都有
$$
h(s) \le c(s, a, s') + h(s'),
$$ {#eq-consistent}
则称 $h$ **一致**（或**单调**）。
:::

一致性就是一个三角不等式：从 $s$ 出发的估计不超过一步的代价加上从这一步所到之处的估计。它与 [[algorithms/shortest-paths#eq-triangle]] 是同一个条件，只不过 $h$ 扮演的角色是到目标的距离。

::: lemma 一致启发式可容许 {#lem-consistent-admissible}
每个一致启发式都可容许。
:::

::: proof
设 $s = s_0, s_1, \dots, s_k$ 为从 $s$ 到目标 $s_k$ 的最优路径，各步代价为 $c_1, \dots, c_k$。沿它反复使用 [[#eq-consistent]]，得 $h(s_0) \le c_1 + h(s_1) \le c_1 + c_2 + h(s_2) \le \dots \le c_1 + \dots + c_k + h(s_k) = h^*(s) + 0$。若 $s$ 不可达任何目标，则 $h^*(s) = \infty$，无话可证。
:::

逆命题不成立，但自然出现的可容许启发式几乎总是一致。A* 作*树*搜索——每个结点都是一条不同的路径——时，需要的正是可容许性。

::: theorem 可容许启发式下 A* 树搜索最优 {#thm-astar-tree}
设分支因子有限、每个动作至少花费 $\varepsilon > 0$、解存在、$h$ 可容许。则不做重复合并的 A* 搜索（每个生成的结点都加入前沿）返回最优解。
:::

::: proof
首先，A* 一定会返回某个解。前沿上每个结点都有 $f(n) \ge g(n)$，而满足 $g(n) \le C^*$ 的结点只有有限多个（长度不超过 $C^*/\varepsilon$ 的路径，每条路径的走法有限）。在算法停止之前的任何时刻，前沿上都含有一条最优路径上的结点 $n'$（起初是根；这样的结点被扩展时，它在最优路径上的子结点就被加入）。对它，$f(n') = g(n') + h(n') \le g(n') + h^*(n') = C^*$，这里用了可容许性，以及从 $n'$ 起最优路径的剩余部分恰花费 $h^*(n')$ 这一事实。于是每次弹出的结点都有 $f \le C^*$，从而 $g \le C^*$；这样的结点只有有限多个，故搜索必然结束；而在其路径末端的目标被弹出之前 $n'$ 一直在前沿上，所以搜索以返回一个目标告终。

再设 A* 返回了目标结点 $n_G$ 且 $g(n_G) > C^*$。$n_G$ 被弹出的那一刻，前沿上如前所述含有一条最优路径上的结点 $n'$，满足 $f(n') \le C^*$。但 $f(n_G) = g(n_G) + 0 > C^* \ge f(n')$，于是 A* 本会弹出 $n'$ 而不是 $n_G$——矛盾。
:::

在图上，[[#alg-best-first]] 对已到达状态的新路径除非更便宜否则丢弃（第 9 行）；一个常用的更简单的变体则干脆从不重新扩展任何状态。只有可容许性时，后一种变体可能返回次优解（[[#ex-inconsistent]]）。一致性消除了这个问题，因为它使 $f$ 沿每条路径单调增长。

::: theorem 一致启发式下的 A* 图搜索 {#thm-astar-graph}
设 $h$ 一致，且 [[#thm-astar-tree]] 的假设成立。则：
1. 沿任意路径，$f(n) = g(n) + h(n)$ 单调不减；
2. A* 按 $f$ 不减的顺序扩展结点；结点首次被扩展、状态为 $s$ 时，其路径代价已最优：$g(n) = g^*(s)$，即 $s_0$ 到 $s$ 的最低路径代价；
3. 因此任何状态都不会被扩展两次，首个被扩展的目标由最优路径到达，且 $f = C^*$。
:::

::: proof
1. 若 $n'$ 是 $n$ 经动作 $a$ 的子结点，则 $f(n') = g(n) + c(s, a, s') + h(s') \ge g(n) + h(s) = f(n)$，由 [[#eq-consistent]]。

2. *不减顺序。*设 $n$ 以值 $f(n)$ 被弹出，其子结点入堆。由第 1 部分每个子结点都有 $f \ge f(n)$，而前沿上其余结点本来就有 $f \ge f(n)$，因为 $n$ 是最小值。于是前沿的最小值从不下降，被弹出的 $f$ 值序列单调不减。

*最优路径。*设状态为 $s$ 的结点 $n$ 以 $g(n) > g^*(s)$ 被扩展。设 $P = s_0, \dots, s$ 为到 $s$ 的最优路径。此刻 $P$ 上某个结点在前沿上（根已被扩展；沿 $P$ 走到第一个"最优路径结点尚未被扩展"的状态——它的结点在其 $P$ 上前驱被扩展时入堆，或者有一个状态相同、代价相等的结点入了堆）。称它为 $n'$，$g(n') = g^*(s')$。对 $P$ 的剩余部分使用第 1 部分，$f(n') \le g^*(s) + h(s) < g(n) + h(s) = f(n)$。于是 $n'$ 有更小的 $f$，本应先于 $n$ 被弹出——矛盾。

3. 状态首次被扩展时代价已最优，之后任何路径都不会更便宜，第 9 行便不会再把它加入。最先被扩展的目标结点 $n_G$ 有 $g(n_G) = g^*(s_G)$，且 $f(n_G) = g(n_G)$。若存在更便宜的目标，它在最优路径上的结点就有 $f \le C^* < f(n_G)$，本应先被扩展。
:::

于是在一致启发式下，A* 图搜索就是在新代价 $c'(s, a, s') = c(s, a, s') - h(s) + h(s')$ 上做的一致代价搜索，而这些新代价非负当且仅当 $h$ 一致——与 [[algorithms/shortest-paths]] 中 Johnson 算法的重新赋权是同一个技巧。搜索沿 $f$ 递增的**等值线**推进，像一致代价搜索的圆环，只是朝着目标拉长了。

::: theorem A* 扩展哪些结点 {#thm-astar-contours}
设 $h$ 一致且 [[#thm-astar-tree]] 的假设成立。则 A* 扩展每个满足 $g^*(s) + h(s) < C^*$ 的状态 $s$，而不扩展任何满足 $g^*(s) + h(s) > C^*$ 的状态。（$f = C^*$ 的状态可能被扩展，也可能不会，取决于平局的处理。）
:::

::: proof
由 [[#thm-astar-graph]]，A* 按 $f$ 不减的顺序扩展状态，每个都带着最优的 $g$，并在扩展第一个目标（此时 $f = C^*$）时停止。故每个被扩展的状态都有 $g^*(s) + h(s) \le C^*$。反过来，设 $g^*(s) + h(s) < C^*$，并设 $s_0, s_1, \dots, s_j = s$ 为到 $s$ 的最优路径。由 [[#thm-astar-graph]] 的第 1 部分，其上每个状态都有 $g^*(s_i) + h(s_i) \le g^*(s) + h(s) < C^*$。只要搜索还在运行，这条路径上第一个未被扩展的状态就在前沿上有一个满足 $f < C^*$ 的结点（如上一个证明），所以搜索不可能在扩展它之前弹出一个目标（$f = C^*$）。沿路径归纳即知 $s$ 本身会被扩展。
:::

这个定理既解释了 A* 的长处，也说明了它的局限。好的启发式能**剪掉**每个满足 $g^* + h > C^*$ 的状态而不看一眼。但每个满足 $g^* + h < C^*$ 的状态*必须*被扩展，而在困难问题上，除非启发式的误差极小，这类状态的个数随解深度指数增长。事实上，在所有保证用同一个一致启发式找到最优解、并从根出发延伸路径的算法中，没有任何一个能在每个问题上都跳过满足 $g^* + h < C^*$ 的状态——在这个意义下 A* 是**最优高效**的（德赫特（Dechter）与珀尔（Pearl），1985），最多差在 $f = C^*$ 的结点之间的平局处理。

::: example A* 的执行轨迹 {#ex-astar-trace}
在一致代价搜索图中的图上，从 $S$ 到 $G$ 运行 A* 图搜索，启发式为 $h(S) = 6$、$h(A) = 5$、$h(B) = 6$、$h(C) = 4$、$h(D) = 3$、$h(G) = 0$。验证 $h$ 一致，并把扩展次数与一致代价搜索比较。
::: solution
*一致性。*对每条边的两个方向验证 [[#eq-consistent]]（$\lvert h(u) - h(v)\rvert \le c(u, v)$）：$S$–$A$：$1 \le 2$；$S$–$B$：$0 \le 1$；$A$–$C$：$1 \le 2$；$B$–$C$：$2 \le 4$；$B$–$D$：$3 \le 6$；$C$–$D$：$1 \le 1$；$C$–$G$：$4 \le 5$；$D$–$G$：$3 \le 3$。到 $G$ 的真实距离是 $h^*(D) = 3$、$h^*(C) = 4$、$h^*(A) = 6$、$h^*(B) = 8$、$h^*(S) = 8$，所以 $h$ 也是可容许的（正如 [[#lem-consistent-admissible]] 所保证），且在 $C$、$D$、$G$ 处精确。

```python
import heapq

def astar(graph, h, start, goal, reopen=True, trace=False):
    """A* 图搜索。graph: {u: {v: cost}}。返回 (cost, path)。"""
    g = {start: 0}; parent = {start: None}; closed = set()
    frontier = [(h[start], start)]
    while frontier:
        f, u = heapq.heappop(frontier)
        if u in closed or f > g[u] + h[u]: continue      # 过时表项
        if u == goal:
            path = []
            while u: path.append(u); u = parent[u]
            return g[goal], path[::-1]
        closed.add(u)
        for v, c in graph[u].items():
            if g[u] + c < g.get(v, float("inf")):
                if v in closed and not reopen: continue   # 从不重新访问已关闭的结点
                closed.discard(v)
                g[v] = g[u] + c; parent[v] = u
                heapq.heappush(frontier, (g[v] + h[v], v))
        if trace:
            live = sorted({(f, v) for f, v in frontier if v not in closed and f == g[v] + h[v]})
            print(f"expand {u} (g={g[u]}, f={f})  frontier:", " ".join(f"{v}:{f}" for f, v in live))
```

```console

expand A (g=2, f=7)  frontier: B:7 C:8
expand B (g=1, f=7)  frontier: C:8 D:10
expand C (g=4, f=8)  frontier: D:8 G:9
expand D (g=5, f=8)  frontier: G:8
(8, ['S', 'A', 'C', 'D', 'G'])
```

被弹出的 $f$ 值为 $6, 7, 7, 8, 8, 8$——单调不减，正如 [[#thm-astar-graph]] 所言。扩展 $B$（一次 $f = 7$ 的平局，按字母序打破）是无用的，但不可避免：$f(B) = 7 < C^* = 8$，所以由 [[#thm-astar-contours]]，这类算法中的*每一个*都必须看 $B$。结点 $D$ 最初经 $B$ 以 $f = 10$ 进入前沿，随后经 $C$ 被改进到 $f = 8$。解 $S, A, C, D, G$ 代价 $8$，与一致代价搜索找到的一样。这里图太小，A* 扩展的状态与一致代价搜索一样多；在 8 数码上（[[#ex-8puzzle-heuristics]]），深度 $26$ 处节省约四十倍。
:::
:::

::: example 一个可容许但不一致的启发式 {#ex-inconsistent}
在有向图 $S \to A$（$1$）、$S \to B$（$1$）、$A \to C$（$1$）、$B \to C$（$2$）、$C \to G$（$3$）上，取 $h(S) = 0$、$h(A) = 3$、$h(B) = 1$、$h(C) = 0$、$h(G) = 0$。说明 $h$ 可容许但不一致，并分别在不重新打开已关闭状态与重新打开的情形下运行 A* 图搜索。
::: solution
到目标的真实代价是 $h^*(C) = 3$、$h^*(A) = 4$、$h^*(B) = 5$、$h^*(S) = 5$，故处处 $h \le h^*$：可容许。但 $h(A) = 3 > c(A, C) + h(C) = 1$：不一致。用 `reopen=False` 运行 [[#ex-astar-trace]] 的清单：

```console
expand S (g=0, f=0)  frontier: B:2 A:4
expand B (g=1, f=2)  frontier: C:3 A:4
expand C (g=3, f=3)  frontier: A:4 G:6
expand A (g=1, f=4)  frontier: G:6
no reopening: (6, ['S', 'B', 'C', 'G'])
reopening:    (5, ['S', 'A', 'C', 'G'])
```

看似高估的值 $h(A) = 3$ 使 $A$ 迟迟不动，于是 $C$ 先经较差的路径（走 $B$，$g = 3$）被扩展。$A$ 最终被扩展时发现 $C$ 可用 $g = 2$ 到达，但 $C$ 已经关闭，不重新打开的话这个发现就被扔掉：A* 返回代价 $6$ 而不是 $5$。若允许重新打开（如 [[#alg-best-first]] 第 9 行），到 $C$ 的更便宜的路径会再次入堆，$C$ 被重新扩展，最优路径得以找到——代价是一个状态扩展两次，而在恶劣的例子上这种情况可能发生指数多次（马泰利（Martelli），1977）。
:::
:::

::: warning "A* 总能找到最短路径"
A* 只在一定条件下最优：树搜索需要可容许启发式（[[#thm-astar-tree]]），图搜索需要一致启发式——或者重新打开已关闭的状态（[[#thm-astar-graph]]、[[#ex-inconsistent]]）。一个有时高估的不可容许启发式会让 A* 返回更差的解；这有时是故意为之（**加权 A\***，$f = g + w\,h$，$w > 1$，能快得多地找到代价不超过 $w \cdot C^*$ 的解），但那样结果就不再最优。另外 A* 并不便宜：由 [[#thm-astar-contours]]，它要存储每个满足 $g^* + h < C^*$ 的状态，困难问题上它往往远早于时间耗尽就先耗尽内存。
:::

## 设计启发式

对 8 数码，有两个经典的可容许启发式
- $h_1$ = **放错位置的方块**数（空格不计），以及
- $h_2$ = **曼哈顿距离**：对每个方块，把它所在格到目标格的水平距离与竖直距离相加，再对所有方块求和。

两者都可容许：每个放错位置的方块至少要被移动一次，而每次移动使一个方块移动一格，使曼哈顿距离至多减少一。显然 $h_2 \ge h_1$——每个放错位置的方块对 $h_2$ 至少贡献 $1$。启发式越大越好吗？

::: theorem 支配性 {#thm-dominance}
设 $h_1$ 与 $h_2$ 是满足 $h_2(s) \ge h_1(s)$ 对每个状态 $s$ 的一致启发式（称 $h_2$ **支配** $h_1$）。则 A* 用 $h_2$ 扩展的、满足 $g^*(s) + h_2(s) < C^*$ 的每个状态，也会被用 $h_1$ 的 A* 扩展。
:::

::: proof
由 [[#thm-astar-contours]]，用 $h_1$ 的 A* 扩展每个满足 $g^*(s) + h_1(s) < C^*$ 的状态。若 $g^*(s) + h_2(s) < C^*$，则 $g^*(s) + h_1(s) \le g^*(s) + h_2(s) < C^*$，故 $s$ 被用 $h_1$ 的 A* 扩展。（只有 $f = C^*$ 的状态游离于比较之外，因为平局的处理。）
:::

所以对一致启发式而言，越大越好，只要启发式保持可容许且计算便宜。给定若干互不支配的可容许启发式，$h(s) = \max(h_1(s), \dots, h_k(s))$ 可容许，若它们全都一致则它也一致，且支配每一个。

启发式从何而来？一个很好的来源是**松弛问题**：把原问题对动作的某些限制去掉。在 8 数码中，若方块可以移到*任意*格子，最优代价就是放错位置的方块数 $h_1$；若方块可以移到任意*相邻*格子，哪怕格子上已有方块，最优代价就是曼哈顿距离 $h_2$。

::: theorem 松弛给出一致启发式 {#thm-relaxation}
设松弛问题与原问题有相同的状态集与目标状态集，其转移集是原问题的超集，且原转移的代价不变。则松弛问题的最优到目标代价 $h_R(s)$ 是原问题的一致（从而可容许）启发式。
:::

::: proof
*一致性。*若 $s' = \mathrm{Result}(s, a)$ 在原问题中成立，则同样的转移以同样的代价存在于松弛问题中，于是松弛问题中从 $s$ 到目标的一种方式就是先走这一步、再从 $s'$ 最优地走下去：$h_R(s) \le c(s, a, s') + h_R(s')$。并且 $h_R$ 在目标状态处为 $0$。可容许性由 [[#lem-consistent-admissible]] 得出（或直接：原问题的每个解也都是松弛问题的解，故松弛问题的最优值不会更大）。
:::

松弛问题必须*容易*解才有用——它要在每个结点上被解一遍。启发式的其他来源还有**模式数据库**：为子问题（比如 15 数码中方块 $1$–$4$，其余不管）的每个部件配置存储恰好解出它的代价，由一次反向广度优先搜索预先算出；以及从已解出的实例中*学习*启发式——后者不提供任何可容许性保证。

启发式的质量常用**有效分支因子** $b^*$ 来概括：若 A* 扩展 $N$ 个结点后找到深度 $d$ 处的解，则 $b^*$ 是深度 $d$、共 $N + 1$ 个结点的正则树的分支因子，即 $N + 1 = 1 + b^* + (b^*)^2 + \dots + (b^*)^d$。$b^*$ 接近 $1$ 的启发式能让搜索深入到很深。

::: example 8 数码上的两个启发式 {#ex-8puzzle-heuristics}
在最优解为 $6, 10, \dots, 26$ 步的随机 8 数码实例上，比较广度优先搜索、用 $h_1$ 的 A*、用 $h_2$ 的 A* 以及用 $h_2$ 的 IDA*（下文）。
::: solution
从目标出发的一次广度优先搜索算出全部 $181{,}440$ 个可达状态的精确距离；对每个深度，用固定种子随机抽取该距离上的 $20$ 个状态，平均扩展结点数。启发式为

```python
GOAL = (1, 2, 3, 4, 5, 6, 7, 8, 0)          # 0 是空格

def h1(s):   # 放错位置的方块
    return sum(1 for i, x in enumerate(s) if x and x != GOAL[i])

def h2(s):   # 曼哈顿距离
    return sum(abs(i // 3 - (x - 1) // 3) + abs(i % 3 - (x - 1) % 3)
               for i, x in enumerate(s) if x)
```

::: quiz
设 $h_1$ 与 $h_2$ 是可容许启发式。下列哪些一定可容许？

- [x] $\max(h_1, h_2)$
- [x] $\tfrac12 (h_1 + h_2)$
- [ ] $h_1 + h_2$
- [x] $\min(h_1, h_2)$

若 $h_1 \le h^*$ 且 $h_2 \le h^*$，则 $\max(h_1, h_2)$、$\min(h_1, h_2)$ 和任何平均值都 $\le h^*$。和最大可到 $2h^*$：对 8 数码，在距目标一步的状态上 $h_1 + h_2$ 就高估（$h_1 = 1$、$h_2 = 1$、$h^* = 1$，和为 $2$）。在可容许的几种中，$\max$ 支配其余的，是 A* 的最佳选择。
:::

## 节省内存：IDA*

A* 的弱点是内存。**迭代加深 A\***（IDA\*）之于 A*，恰如迭代加深之于广度优先搜索：它运行一趟趟深度优先搜索，每趟在 $f = g + h$ 超过一个**界限**时截断；界限从 $f(\text{根}) = h(s_0)$ 开始，每轮提到上一轮越界的 $f$ 值中最小的那个。

::: algorithm IDA* {#alg-ida-star}
```python
def ida_star(start, h, successors, is_goal):
    """返回最优解的代价（单位代价或正代价）。"""
    def dfs(s, g, bound, path):
        f = g + h(s)
        if f > bound: return f                  # 报告越界的 f
        if is_goal(s): return "FOUND"
        smallest = float("inf")
        for t, cost in successors(s):
            if t in path: continue              # 避免当前路径上的圈
            path.add(t)
            r = dfs(t, g + cost, bound, path)
            path.discard(t)
            if r == "FOUND": return r
            smallest = min(smallest, r)
        return smallest
    bound = h(start)
    while True:
        r = dfs(start, 0, bound, {start})
        if r == "FOUND": return bound
        if r == float("inf"): return None       # 无解
        bound = r                               # 下一条等值线
```
:::

[[#ex-8puzzle-heuristics]] 的 8 数码程序用的是同一个方案，只是把圈检查换成"不撤销上一步"。

::: theorem IDA* 最优 {#thm-ida-star}
在可容许启发式、正动作代价与有限分支因子下，IDA* 只要解存在就返回最优解的代价。它的空间是 $O(bd^*)$，其中 $d^*$ 是它探索的最长路径的长度，不超过代价为 $C^*$ 的路径中的动作数。
:::

::: proof
*不变式：*每轮开始时 $\text{bound} \le C^*$。起初 $\text{bound} = h(s_0) \le h^*(s_0) = C^*$，由可容许性。在界限 $\beta \le C^*$ 的那一轮，考虑一条最优解路径。其上每个结点 $n$ 都有 $f(n) = g(n) + h(n) \le g(n) + h^*(n) = C^*$。若 $C^* \le \beta$，即 $\beta = C^*$，则最优路径上没有结点被截断，于是深度优先搜索到达它的目标（或另一个目标）并报"找到"；找到的目标有 $g = f \le \beta = C^*$，故其代价最优。若 $\beta < C^*$，则找不到目标（任何到达的目标都将有代价 $g = f \le \beta < C^*$，不可能），新界限是超过 $\beta$ 的最小 $f$ 值。最优路径上某个结点被截断时 $f \le C^*$，所以新界限不超过 $C^*$，且严格大于 $\beta$：不变式得以维持。

*终止性：*界限严格增大，且都是满足 $f \le C^*$ 的路径的 $f$ 值，从而满足 $g \le C^*$；在代价 $\ge \varepsilon$、分支因子有限时，这样的路径只有有限多条，故不同的界限只有有限多个，于是终会到达界限为 $C^*$ 的那一轮。空间：每轮是一次存储当前路径的深度优先搜索（若它急于生成子结点，还要存储沿途的兄弟结点）。
:::

$f$ 只取很少几个不同值时 IDA* 工作得很好，比如 8 数码和 15 数码上的单位代价加整数启发式；它是第一个最优求解随机 15 数码实例的算法（科尔夫（Korf），1985）。若每个结点的 $f$ 值都不同，每轮只新增一个结点，IDA* 在 A* 扩展 $N$ 个结点的地方要扩展 $O(N^2)$ 个。其他内存受限的变体有**递归最佳优先搜索**，它在路径的每一层记住最佳的备选 $f$ 值；以及 **SMA\***，它运行 A* 直到内存放满，然后丢弃最差叶子结点，把它的 $f$ 值备份到父结点。

::: history
15 数码在 1880 年代风靡一时；它的奇偶定理已由威廉·约翰逊（William Johnson）与威廉·斯托里（William Story）发表于 1879 年的 *American Journal of Mathematics*。艾伦·纽厄尔（Allen Newell）与赫伯特·西蒙（Herbert Simon）的通用问题求解器（1959）用手段–目的分析进行搜索。彼得·哈特（Peter Hart）、尼尔斯·尼尔松（Nils Nilsson）与伯特拉姆·拉斐尔（Bertram Raphael）1968 年在 SRI 为机器人 Shakey 在 "A formal basis for the heuristic determination of minimum cost paths"（*IEEE Transactions on Systems Science and Cybernetics*）中提出了 A*，证明了它对可容许启发式的最优性；他们某个证明的一处更正发表于 1972 年。艾拉·波尔（Ira Pohl）研究了双向搜索与加权搜索（1969–70）。阿尔贝托·马泰利（Alberto Martelli，1977）指出 A* 配合不一致启发式可能重新扩展指数多次。朱迪亚·珀尔（Judea Pearl）的 *Heuristics*（1984）将这一理论体系化，里娜·德赫特（Rina Dechter）与珀尔于 1985 年证明了 A* 的最优高效性。理查德·科尔夫（Richard Korf）在 "Depth-first iterative-deepening: an optimal admissible tree search"（*Artificial Intelligence*，1985）中提出了迭代加深搜索与 IDA*。约瑟夫·卡尔伯森（Joseph Culberson）与乔纳森·谢弗（Jonathan Schaeffer）提出了模式数据库（1996，期刊版 1998），科尔夫借此于 1997 年最优地解出了魔方的随机实例。
:::

## 实际应用

启发式搜索至今仍是经典 AI 大部分工作的引擎。截至 2026 年，路线规划器把 A* 与从**地标**（对少数选定顶点使用三角不等式，得到一个可容许、一致的启发式）预计算出的下界以及分层预处理结合；电子游戏里的寻的路在网格与导航网格上跑 A*，常配加权启发式；自动规划器（[[artificial-intelligence/planning]]）使用贪心最佳优先搜索与 A*，其启发式由松弛问题自动算出——恰是 [[#thm-relaxation]]。魔方这类谜题的最优求解器使用带大型模式数据库的 IDA*。学出来的启发式与价值函数是活跃的研究领域；它们本身不带可容许性保证，所以在最优性要紧的场合会与可容许的下界结合使用。

## 后续内容

当另一个智能体替我们选走一半的着法时，搜索树就有了交替的层，A* 的最佳优先思想让位于极小化极大与 α–β 剪枝（[[artificial-intelligence/adversarial-search]]）。当状态因子化为变量时，搜索可以利用这种结构：约束传播在搜索之前先剪掉空间（[[artificial-intelligence/constraint-satisfaction]]），规划器则从动作的结构导出启发式（[[artificial-intelligence/planning]]）。当动作的结果不确定时，"解"不再是一个序列而是策略（[[artificial-intelligence/decision-making]]）。搜索的一般难度——$(n^2 - 1)$ 数码求短解是 $\mathsf{NP}$ 难的，紧凑表示下计划的存在性是 $\mathsf{PSPACE}$ 完全的——在 [[complexity]] 中学习。

::: summary
- **搜索问题**（[[#def-search-problem]]）是由动作、转移模型、目标测试与代价隐式给出的状态空间；搜索算法长出一棵路径树，维护**前沿**与**已到达**状态表（[[#alg-best-first]]）。
- 无信息策略：BFS 与一致代价搜索完备且最优，却要 $O(b^d)$ 内存；DFS 只需 $O(bm)$ 内存但两者皆非；**迭代加深**以常数因子开销兼得二者之长（[[#thm-ids]]）。
- **A\*** 按 $f = g + h$ 的顺序扩展结点。树搜索配**可容许**启发式时最优（[[#thm-astar-tree]]），图搜索配**一致**启发式时最优（[[#thm-astar-graph]]）；一致蕴涵可容许（[[#lem-consistent-admissible]]），不一致的启发式则可能误导不重新打开结点的图搜索（[[#ex-inconsistent]]）。
- A* 扩展每个满足 $g^* + h < C^*$ 的状态，一个满足 $g^* + h > C^*$ 的也不扩展（[[#thm-astar-contours]]）；因此支配的启发式更好（[[#thm-dominance]]），8 数码深度 26 处曼哈顿距离比方块错位数少十倍。
- 启发式来自**松弛问题**——其最优代价一致（[[#thm-relaxation]]）——以及模式数据库；**有效分支因子**度量启发式的质量。
- **IDA\*** 在递增的 $f$ 界限内做深度优先搜索，用线性内存找到最优解（[[#thm-ida-star]]）。
:::

::: exercise 手算迭代加深 {level=1 check="1230"}
在 $b = 10$、最浅目标在深度 $d = 3$ 的正则树中，迭代加深在最坏情况下生成多少个结点（不含根）？广度优先搜索生成多少个？（输入迭代加深的数。）
::: solution
由 [[#thm-ids]]，$N_{\mathrm{IDS}} = 3 \cdot 10 + 2 \cdot 100 + 1 \cdot 1000 = 30 + 200 + 1000 = 1230$，而广度优先搜索的 $N_{\mathrm{BFS}} = 10 + 100 + 1000 = 1110$——多约 $11\%$。（若把根也算上——它在 $\ell = 0, 1, 2, 3$ 四轮中各生成一次——再加 $4$。）
:::

::: exercise 一致吗？ {level=1}
在无向图 $S$–$A$（$1$）、$A$–$G$（$4$）、$S$–$B$（$2$）、$B$–$G$（$2$）上，判定每个启发式是否可容许、是否一致：(a) $h = (S{:}\,3, A{:}\,4, B{:}\,2, G{:}\,0)$；(b) $h = (S{:}\,4, A{:}\,1, B{:}\,2, G{:}\,0)$；(c) $h = (S{:}\,3, A{:}\,3, B{:}\,1, G{:}\,0)$。
::: solution
真实代价：$h^*(G) = 0$、$h^*(B) = 2$、$h^*(A) = \min(4, 1 + 4) = 4$（经 $S$ 为 $1 + 2 + 2 = 5$）、$h^*(S) = 4$。在无向图上，一致性指每条边上 $\lvert h(u) - h(v)\rvert \le c(u, v)$（外加 $h(G) = 0$）。
(a) 可容许（$3 \le 4$、$4 \le 4$、$2 \le 2$）。一致：$S$–$A$：$1 \le 1$；$A$–$G$：$4 \le 4$；$S$–$B$：$1 \le 2$；$B$–$G$：$2 \le 2$。是。
(b) 可容许（$4, 1, 2 \le 4, 4, 2$）。不一致：$S$–$A$ 上 $\lvert 4 - 1\rvert = 3 > 1$。
(c) 可容许。一致：$0 \le 1$、$3 \le 4$、$2 \le 2$、$1 \le 2$。是。
:::
:::

::: exercise 有效分支因子 {level=1 check="2"}
A* 扩展 $14$ 个结点后找到深度 $3$ 处的解。有效分支因子 $b^*$ 是多少？（输入 $b^*$。）
::: solution
解 $N + 1 = 1 + b^* + (b^*)^2 + (b^*)^3$，其中 $N = 14$：$b + b^2 + b^3 = 14$。试 $b = 2$：$2 + 4 + 8 = 14$。故 $b^* = 2$。
:::

::: exercise 一致代价搜索可能很慢 {level=2}
构造一族分支因子为 $2$、深度 $1$ 处有解的搜索问题，使一致代价搜索在找到最优解之前，沿参数 $k$ 指数地扩展结点，而 BFS 只扩展一个。这对界 $O(b^{1 + \lfloor C^*/\varepsilon\rfloor})$ 说明什么？
::: solution
从 $s_0$ 出发，让一个动作以代价 $1$ 直达目标，另一个动作通向一棵完整二叉树的根，树上每个动作代价 $\varepsilon = 1/k$ 且没有状态是目标。一致代价搜索扩展所有 $g < C^* = 1$ 的结点，其中包括路径代价低于 $1$ 的一切树结点——大约前 $k - 1$ 层的全部结点，约 $2^{k}$ 个。BFS 到深度 $1$ 立刻找到目标（它的解恰好是最优的）。界 $O(b^{1 + \lfloor C^*/\varepsilon\rfloor}) = O(2^{1 + k})$ 可以取到：代价差异悬殊时，对一致代价搜索而言相关的深度是 $C^*/\varepsilon$，不是 $d$。
:::
:::

::: exercise 直线距离是一致的 {level=2}
在道路地图上的路线规划中，道路代价是其长度，$h(s)$ 是 $s$ 到目的地的直线（欧几里得）距离。证明 $h$ 一致。若道路代价是行驶*时间*、而 $h$ 是直线距离除以地图上最快道路的速度上限，它还是一致的吗？
::: solution
对从 $s$ 到 $s'$、长度 $c(s, s') \ge \lVert s - s'\rVert$ 的道路（道路至少与其两端的直线段一样长），平面上的三角不等式给出 $h(s) = \lVert s - t\rVert \le \lVert s - s'\rVert + \lVert s' - t\rVert \le c(s, s') + h(s')$，其中 $t$ 是目的地；且 $h(t) = 0$。故 $h$ 一致。换成时间：从 $s$ 到 $s'$ 的道路至少耗时 $\lVert s - s'\rVert / v_{\max}$，$v_{\max}$ 是最大速度上限，于是同样的论证除以 $v_{\max}$ 得 $h(s) = \lVert s - t\rVert/v_{\max} \le c(s, s') + h(s')$：仍然一致。除以更小的速度会得到更大的启发式，它可能在快速道路上高估。
:::
:::

::: exercise A* 必须扩展这些状态 {level=2 check="3"}
在 [[#ex-astar-trace]] 的 A* 轨迹中，有多少个状态满足 $g^*(s) + h(s) < C^*$？（由 [[#thm-astar-contours]]，这些恰是 A* 不得不扩展的状态；输入它们的个数。）
::: solution
$C^* = 8$。从 $S$ 出发的最优代价是 $g^*(S) = 0$、$g^*(A) = 2$、$g^*(B) = 1$、$g^*(C) = 4$、$g^*(D) = 5$、$g^*(G) = 8$，故 $S, A, B, C, D, G$ 的 $g^* + h$ 依次为 $6, 7, 7, 8, 8, 8$。恰有三个状态 $S$、$A$、$B$ 满足 $g^* + h < 8$。轨迹还扩展了 $C$ 与 $D$，它们的 $f = C^*$：[[#thm-astar-contours]] 把这类状态交给平局处理，而这里它们不得不被扩展，因为唯一的优路径经过它们。
:::

::: exercise IDA* 对 A* {level=3}
(a) 证明若所有 $f$ 值互不相同，IDA* 可以在 A* 扩展 $N$ 个结点的问题上扩展 $\Theta(N^2)$ 个结点。(b) 解释为什么单位代价加曼哈顿启发式的 8 数码是有利情形：从 $h(s_0)$ 出发，深度 $d$ 处的解需要 IDA* 运行多少轮？(c) 为 8 数码实现 IDA*，在 100 个随机实例上把它的解长与广度优先搜索核对。
::: solution
(a) 取一条到目标的路径 $s_0, s_1, \dots, s_N$，使 $f(s_i) = i$（严格递增，例如精心选取代价与启发式即可），且别无其他状态。第 $k$ 轮的界限是 $f(s_{k}) = k$，扩展 $s_0, \dots, s_{k-1}$（在 $s_k$ 处截断），然后把界限提高一步。总和为 $\sum_{k=1}^{N} k = \Theta(N^2)$，而 A* 每个状态只扩展一次。有分支时，同样的事沿等值线逐条发生。

(b) 每步移动使 $g$ 改变 $1$、使曼哈顿距离恰好改变 $\pm 1$（一个方块移动一格），所以沿每条边 $f = g + h$ 改变 $0$ 或 $2$：从 $s_0$ 出发各条路径上的 $f$ 值与 $h(s_0)$ 同奇偶。于是界限依次为 $h(s_0), h(s_0) + 2, \dots, C^* = d$：至多 $(d - h(s_0))/2 + 1$ 轮，且每一新轮扩展的结点都比此前各轮之和还多得多，所以重复的工作只是一个常数因子。

(c) 正文的清单按 [[#ex-8puzzle-heuristics]] 的方式特化即可完成；用于该实例的程序在每个实例上都断言 IDA* 的代价等于 BFS 的距离，共 $120$ 个实例。在深度 $26$ 的实例上，它平均扩展 $5216$ 个结点，A* 是 $3803$ 个，约多 $1.4$ 倍，而路径上至多存储 $26$ 个状态。
:::
:::

::: exercise 双向搜索及其停止规则 {level=3}
双向一致代价搜索交替扩展从 $s_0$ 出发的正向搜索与从目标 $t$ 出发的反向搜索，$g_F$ 与 $g_B$ 分别是前向与后向路径代价。用一个例子说明：一旦某个状态被两路搜索都*扩展*过就停止，可能返回次优路径。然后证明下列规则是正确的：令 $\mu$ 为此前看到的、所有满足"$v$ 已被前向到达、$w$ 已被后向到达"的边 $(v, w)$ 上 $g_F(v) + c(v, w) + g_B(w)$ 的最小值，当 $\mathrm{top}_F + \mathrm{top}_B \ge \mu$ 时停止，其中 $\mathrm{top}_F$、$\mathrm{top}_B$ 是两路前沿上最小的 $g$ 值。
::: solution
*例子。*取边 $s_0 \to a$（$3$）、$a \to t$（$3$）、$s_0 \to x$（$1$）、$x \to y$（$3$）、$y \to t$（$1$）。最优路径 $s_0, x, y, t$ 代价 $5$；经 $a$ 的路径代价 $6$。交替扩展，先正向。正向：$s_0$（$g_F = 0$；以 $3$ 到达 $a$、以 $1$ 到达 $x$）。后向：$t$（$g_B = 0$；以 $3$ 到达 $a$、以 $1$ 到达 $y$）。正向：$x$（$1$；以 $4$ 到达 $y$）。后向：$y$（$1$；以 $4$ 到达 $x$）。正向：$a$（$3$）。后向：$a$（$3$）。此刻 $a$ 已被两路搜索扩展，朴素的规则返回 $s_0, a, t$，代价 $6$——尽管最优路径上没有任何状态被两路搜索都扩展过。（下面的规则在第三次扩展时就已得到 $\mu = g_F(x) + c(x, y) + g_B(y) = 1 + 3 + 1 = 5$。）

*规则的正确性。*每当某路搜索查看一条另一端已被另一路到达的边，就用它更新 $\mu$。每个候选都是一条真实路径的代价，故恒有 $\mu \ge C^*$。设规则在 $\mathrm{top}_F + \mathrm{top}_B \ge \mu$ 时触发，并反设最优路径 $P$ 的代价 $C^* < \mu$。对 $P$ 上每个状态 $u$，$\delta(s_0, u) + \delta(u, t) = C^* < \mathrm{top}_F + \mathrm{top}_B$，故 $\delta(s_0, u) < \mathrm{top}_F$ 或 $\delta(u, t) < \mathrm{top}_B$。如同迪杰斯特拉算法，凡 $\delta(s_0, u) < \mathrm{top}_F$ 的状态都已被前向扩展且 $g_F(u) = \delta(s_0, u)$，后向同理。设 $v$ 是 $P$ 上最后一个满足 $\delta(s_0, v) < \mathrm{top}_F$ 的状态（$v$ 存在，因为 $s_0$ 符合）。若 $v = t$，则 $P$ 进入 $t$ 的那条边在其尾部被前向扩展时已被查看，而 $t$ 早已被后向到达（$g_B(t) = 0$），故 $\mu \le C^*$。否则 $P$ 上的下一个状态 $w$ 有 $\delta(s_0, w) \ge \mathrm{top}_F$，于是 $\delta(w, t) < \mathrm{top}_B$，故 $w$ 已被后向扩展且 $g_B(w) = \delta(w, t)$。$v$（前向）与 $w$（后向）的两次扩展中，较晚的那次查看边 $(v, w)$ 时，另一端已被另一路以其最终值到达，故 $\mu \le g_F(v) + c(v, w) + g_B(w) = C^*$。无论如何 $\mu \le C^*$，与 $C^* < \mu$ 矛盾。于是规则触发时 $\mu = C^*$。
:::
:::
