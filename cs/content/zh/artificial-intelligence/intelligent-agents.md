恒温器读取温度并打开或关闭暖气。棋类程序读取局面并选择一步棋。路线规划器读取地图、路况报告和你的目的地，然后给出一条建议路线；扫地机器人读取自己的碰撞与脏污传感器，决定下一步往哪里开。这些系统的复杂程度悬殊，却共享同一种形状：每一个都反复**感知**周围环境的信息并对其**行动**，而评价每一个的标准，都是由此产生的一系列事件在多大程度上服务于某个目的。本课程以及大多数现代教科书所持的观点是：人工智能研究的就是如何构造这样的系统使它们行动得*好*——如何设计**理性智能体**。

本章为整个课程建立词汇表。我们精确定义智能体与环境，说明一个智能体怎样才算理性，按那些使其变容易或变难的性质对环境分类，并描述构造智能体程序的主要方式——从简单反射，到能够规划、对概率进行推理和学习的智能体。沿途我们证明三个虽小而富有教益的结论：在一个简单的世界里，一个简单反射型智能体可以是完全理性的；同一种智能体一旦失去一个传感器就可能永远失效（而随机化能把它救回来）；并且绝大多数智能体函数根本无法被任何程序实现。

## 智能体与环境

::: definition 智能体、感知与动作 {#def-agent}
**智能体**在离散的时间步 $t = 1, 2, \dots$ 中与一个**环境**交互。每一步它从可能的感知集合 $P$ 中收到一个**感知** $p_t$，然后执行可能的动作集合 $A$ 中的一个**动作** $a_t$。时刻 $t$ 的**感知序列**为 $p_{1:t} = \langle p_1, \dots, p_t\rangle$。智能体的行为由它的**智能体函数**描述
$$
f\colon P^+ \to A, \qquad a_t = f(p_{1:t}),
$$
其中 $P^+$ 是感知的全体非空有限序列之集。**智能体程序**是在某台物理机器（**架构**）上实现某个智能体函数的具体程序：它一次接收一个感知、一次返回一个动作，并保存所需的任何内部状态。
:::

智能体*函数*与智能体*程序*之间的区别很重要。函数是一个数学对象——原则上是一张无限大的表——是外部观察者看到的东西；程序才是我们写出来的东西。两个截然不同的程序可能实现同一个函数；而且，正如我们将在 [[#thm-uncountable]] 中看到的，绝大多数函数根本没有程序可言。

下面是本章贯穿始终的例子，一个刻意做得极小的世界。一台扫地机器人生存在一个由两个方格组成的世界里：$A$（在左）与 $B$（在右）。每个方格要么脏要么干净。智能体感知自己所在的方格以及该方格是否脏，因此一个感知是像 $(A, \textit{Dirty})$ 这样的二元组；共有 $\lvert P\rvert = 4$ 个感知。它的动作是 *Left*、*Right*、*Suck*，在某些变体中还有 *NoOp*（什么都不做）。*Suck* 清洁当前方格；*Left* 与 *Right* 分别移动到 $A$ 与 $B$（从 $A$ 再向左移动时智能体仍留在 $A$）。

这个世界的一个简单智能体程序是一组**条件–动作规则**：

```python
def reflex_vacuum_agent(percept):
    location, dirty = percept
    if dirty:
        return "Suck"
    return "Right" if location == "A" else "Left"
```

它实现的智能体函数对应的表以如下几行开头

| 感知序列 | 动作 |
|---|---|
| $(A, \textit{Clean})$ | *Right* |
| $(A, \textit{Dirty})$ | *Suck* |
| $(B, \textit{Clean})$ | *Left* |
| $(B, \textit{Dirty})$ | *Suck* |
| $(A, \textit{Clean}), (A, \textit{Clean})$ | *Right* |
| $(A, \textit{Clean}), (A, \textit{Dirty})$ | *Suck* |
| $\vdots$ | $\vdots$ |

——在这张表里，动作只依赖于最近一个感知。这样的智能体称为**简单反射型智能体**。它是不是一个*好*智能体，取决于我们要求它做什么，这正是下一节的主题。

::: example 这张表有多大？ {#ex-table-size}
一个只是按感知序列查一张显式表来取动作的智能体（**表驱动智能体**），需要对它可能看到的每一个序列给出一个表项。对于寿命为 $T$ 步、每次感知有 $\lvert P\rvert$ 种可能的情形，一共需要多少个表项？就扫地机器人世界取 $T = 10$ 计算一次，再对一台产生 $640 \times 480$、$256$ 级灰度图像的相机取 $T = 1$ 计算一次。
::: solution
长度为 $t$ 的感知序列是 $P^t$ 的元素，故共有 $\lvert P\rvert^t$ 个，于是表需要
$$
\sum_{t=1}^{T} \lvert P\rvert^t = \frac{\lvert P\rvert^{T+1} - \lvert P\rvert}{\lvert P\rvert - 1}
$$
个表项（当 $\lvert P\rvert \ge 2$）。对扫地机器人世界，$\lvert P\rvert = 4$、$T = 10$ 给出 $(4^{11} - 4)/3 = 1{,}398{,}100$ 个表项——在两方格的世界里，光是十步就已经超过一百万行。对于相机，一幅图像是 $256^{640 \cdot 480} = 2^{2{,}457{,}600}$ 种可能感知之一，所以即便只存一步的表也约有 $10^{739{,}811}$ 个表项，而可观测宇宙中大约只有 $10^{80}$ 个原子。表驱动智能体是一个思想实验，而不是一个设计方案：AI 的全部挑战在于写出*小程序*，从*庞大*的感知历史中产生理性行为。
:::
:::

::: widget plot
f: 4^x; 3^x; 2^x
x: 1, 10
labels: \lvert P\rvert = 4; \lvert P\rvert = 3; \lvert P\rvert = 2
caption: 长度为 $t$ 的感知序列个数 $\lvert P\rvert^t$，取两个极小的感知集合。即使一个世界只有四种可能的感知，仅长度为 10 的序列就需要一百多万行表，而且每多一步总数就乘以 $\lvert P\rvert$。改变绘图范围，看看任何表驱动设计多么快就变得不可行。
:::

## 理性

智能体的动作使环境经过一系列状态。我们用这列状态序列来评价智能体。

::: definition 性能度量与理性智能体 {#def-rational}
**性能度量**给环境状态的每一列序列赋予一个数（越高越好）。给定性能度量、智能体对环境的先验知识以及它能执行的动作，若对每一种可能的感知序列，智能体在感知序列及其内置知识所提供的证据之下选出的动作都能使性能度量的*期望*值最大，则称该智能体是**理性的**。
:::

关于这个定义，有四点值得明确说出。

1. **度量说的是环境，不是智能体的看法。** 设计者决定什么才算成功。对"吸入脏物的总量"给予奖励的扫地机器人，可以通过把脏物吐回地上再吸起来刷高分数；更好的度量应当奖励干净的地板。一般而言，设计性能度量应当按照我们在环境中真正想要的东西，而不是按照我们认为智能体应当如何行为。
2. **理性不等于全知。** 理性智能体在已经感知到的信息下最大化*期望*性能。如果你左右看过之后过马路却被陨石砸中，你并不缺乏理性。反过来，不看路就过马路的智能体即使碰巧毫发无损也是非理性的：它没有采取一个期望值为正的信息收集动作。
3. **理性相对于智能体的知识与动作而言。** 不了解自己世界地理的智能体，去探索它无可指摘；没有 *NoOp* 动作的智能体，因为移动也无可指摘。
4. **理性是按感知序列定义的。** 这正是定义可用的原因：它逐格约束智能体函数，而智能体程序必须把每一格都做对。

为了把这一切具体化，我们需要确定性能度量。考虑关于扫地机器人世界的如下假设：

- 性能度量对寿命 $T$ 步中每个时间步结束时的每个干净方格记一分；
- 地图预先已知，但初始脏污分布与智能体的初始位置未知；
- 方格一旦干净就不会再变脏；*Suck* 清洁当前方格；*Left* 与 *Right* 如上所述移动且不花费代价；
- 智能体能感知自己的位置与当前方格是否脏。

::: theorem 反射型扫地智能体是理性的 {#thm-reflex-rational}
在如上假设下，简单反射型智能体 `reflex_vacuum_agent` 从每个初始状态出发都达到*任何*智能体从该状态出发所能达到的最高分数。特别地，无论初始状态的概率分布如何，它都是理性的。
:::

::: proof
设 $c_t \in \{0, 1, 2\}$ 为第 $t$ 步之后干净方格的个数（$c_0$ 为初始个数），则得分为 $\sum_{t=1}^T c_t$。我们证明反射型智能体同时最大化每一个 $c_t$；那样它就最大化了它们的和。

先给出一个对一切智能体都成立的上界。只有 *Suck* 会改变脏污，且只清洁当前方格，所以 $c_t \le c_{t-1} + 1$，等号仅当第 $t$ 步智能体在脏方格上吸尘时才成立；并且 $c_t \le 2$。此外，若一步开始时智能体所在方格干净而另一方格脏，则该步 $c_t = c_{t-1}$（不先移过去就无法清洁另一个方格）。

下面区分初始情形。(i) $c_0 = 2$：每个智能体都有 $c_t = 2$ 对所有 $t$，即最大值。(ii) 恰有一个方格脏且智能体就在它上面：反射型智能体吸尘，于是 $t \ge 1$ 时 $c_t = 2$，为最大值。(iii) 恰有一个方格脏而智能体在另一个方格上：由上面的注记，每个智能体都有 $c_1 = 1$，且 $c_t \le 2$；反射型智能体第 1 步移动、第 2 步吸尘，于是 $c_1 = 1$、$t \ge 2$ 时 $c_t = 2$——每一步仍是最大。(iv) 两个方格都脏：每个智能体都有 $c_1 \le 1$；而且 $c_2 \le 1$ 也成立，因为第 1 步之后，要么智能体没有吸过尘（于是 $c_1 = 0$ 且 $c_2 \le 1$），要么它吸了自己脚下的方格、站在干净方格上而另一格仍脏（于是 $c_2 = c_1 = 1$）。反射型智能体达到 $c_1 = 1$（吸）、$c_2 = 1$（移），并且 $t \ge 3$ 时 $c_t = 2$；由于总有 $c_t \le 2$，它在每一步都达到最大。

于是在每种情形中，反射型智能体都达到每个 $c_t$ 的逐点最大值，从而也达到得分的最大值。在每个状态都最大化得分的智能体，在初始状态的任意概率分布下最大化期望得分，并且在每个感知序列之后都如此，这正是 [[#def-rational]]。
:::

这个定理依赖它的每一个假设。改动其中一条，同一个智能体就会变得非理性。

::: example 移动要收钱 {#ex-move-cost}
保留扫地机器人世界，但每执行一次 *Left* 或 *Right* 扣一分，并给智能体一个 *NoOp* 动作。把一个**基于模型的**智能体与反射型智能体作比较：前者记住它见过哪些方格是干净的，一旦两个方格都干净就什么都不做。对八个初始状态各模拟 $T = 1000$ 步。
::: solution
反射型智能体永远停不下来：一旦两个方格都干净，它就在两者之间来回穿梭，每步损失一分。基于模型的智能体维护一点很小的内部状态：

```python
from itertools import product

def run(agent, loc, dirt, T, move_cost):
    """模拟两方格世界 T 步；返回得分。"""
    dirt = dict(dirt); memory = {}; score = 0
    for t in range(T):
        action = agent((loc, dirt[loc]), memory)
        if action == "Suck":
            dirt[loc] = False
        elif action in ("Left", "Right"):
            loc = "A" if action == "Left" else "B"
            score -= move_cost
        score += sum(not d for d in dirt.values())   # 每个干净方格每步 +1
    return score

def reflex(percept, memory):
    loc, dirty = percept
    if dirty: return "Suck"
    return "Right" if loc == "A" else "Left"

def model_based(percept, memory):
    loc, dirty = percept
    memory[loc] = "clean"                     # 本步之后它将是干净的
    if dirty: return "Suck"
    other = "B" if loc == "A" else "A"
    if memory.get(other) == "clean": return "NoOp"
    return "Right" if loc == "A" else "Left"

for cost in (0, 1):
    for name, agent in (("reflex", reflex), ("model-based", model_based)):
        scores = [run(agent, loc, {"A": a, "B": b}, 1000, cost)
                  for loc, a, b in product("AB", (True, False), (True, False))]
        print(f"move cost {cost}: {name:12s} scores {scores} mean {sum(scores)/8}")
```

```console
$ python3 vacuum.py
move cost 0: reflex       scores [1998, 2000, 1999, 2000, 1998, 1999, 2000, 2000] mean 1999.25
move cost 0: model-based  scores [1998, 2000, 1999, 2000, 1998, 1999, 2000, 2000] mean 1999.25
move cost 1: reflex       scores [1000, 1001, 1000, 1000, 1000, 1000, 1001, 1000] mean 1000.25
move cost 1: model-based  scores [1997, 1999, 1998, 1999, 1997, 1998, 1999, 1999] mean 1998.25
```

初始状态按 (位置, $A$ 脏, $B$ 脏) 的次序列出 $= (A, \text{是}, \text{是}), (A, \text{是}, \text{否}), \dots, (B, \text{否}, \text{否})$。移动免费时两个智能体得分相同，正如 [[#thm-reflex-rational]] 所预言：二者都达到最大值。移动收费时，反射型智能体几乎损失了一半分数。例如从 $(A, \text{是}, \text{是})$ 出发，基于模型的智能体吸一下（$+1$）、移动（$-1 + 1$）、再吸（$+2$），其后 $997$ 步原地待着（每步 $+2$）：$1 + 0 + 2 + 1994 = 1997$。每个方格一位内存换来了两倍的分数。

注意，基于模型的智能体即使在两个方格初始都干净时仍然会移动一次：不亲眼去看，它无法知道另一个方格是干净的。在初始状态的均匀先验下，这一次查看是划算的——另一个方格一半的时间是脏的，及早发现值回数百点。
:::
:::

::: warning 理性不等于成功，高分也不等于理性
学生常把 rational 读成"得到最好的结果"，但它不是：理性说的是在迄今感知到的信息下*期望*性能最优。全押一注冷门赌马并赢了钱的智能体是运气好，不是理性；做了一个深思熟虑的冒险却输了的智能体是运气差，不是非理性。反过来，造一个在你恰好试过的测试用例上得高分、却没测到的情形里做出糟糕决策的智能体是很容易的。要在智能体将来会面对的环境全体分布上评估智能体——并小心选择性能度量，因为把一个错误度量优化得很好的智能体，比把一个正确度量优化得很差的智能体更糟。
:::

::: quiz
一个只感知"脏"或"干净"（感知不到位置）的扫地智能体被放入移动免费的两方格世界。哪种说法正确？

- [ ] 它只有从不移动才可能是理性的。
- [x] 它是否理性取决于它对每个感知序列做什么；一个能记住过去感知的智能体仍然可以可靠地清洁两个方格。
- [ ] 理性要求智能体知道自己的位置，所以不存在这样的理性智能体。
- [ ] 它当且仅当是简单反射型智能体时才是理性的。
::: solution
理性相对于智能体的感知与知识而言（[[#def-rational]]）：缺少一个传感器并不使智能体非理性，只有没有用好自己掌握的信息才会。一个有记忆的智能体，例如交替执行 *Right*、脏则 *Suck*、*Left*、脏则 *Suck*，无论从哪个方格出发都能清洁两个方格。简单反射型智能体在这里其实是最*糟*的选择——见 [[#thm-blind-reflex]]。
:::
:::

## 环境

智能体的设计在很大程度上取决于它的环境。**任务环境**由四样东西确定，常缩写为 **PEAS**：**P**erformance measure（性能度量）、**E**nvironment（环境）、**A**ctuator（执行器）与 **S**ensor（传感器）。

::: example 三种智能体的 PEAS 描述 {#ex-peas}
给自动出租车、一个与人带钟对弈的国际象棋程序、以及一个垃圾邮件过滤器各写一个 PEAS 描述。
::: solution
| 智能体 | 性能度量 | 环境 | 执行器 | 传感器 |
|---|---|---|---|---|
| 自动出租车 | 安全抵达、行程时间、守法、舒适、车费收入 | 道路、其他车辆、行人、乘客、天气 | 方向盘、油门、刹车、转向灯、显示屏 | 摄像头、雷达或激光雷达、GPS、车速表、里程表、麦克风 |
| 国际象棋程序 | 赢的棋局（和棋算半分），且在用时限制内 | 棋盘、对手、计时钟 | 输出着法 | 输入着法（对手的着法）、计时钟 |
| 垃圾邮件过滤器 | 拦下的垃圾邮件、送达的正常邮件（误拦一封正常邮件通常比放过一封垃圾邮件付出高得多的代价） | 用户的邮箱、发件人、用户的纠正 | 标记为垃圾、投递、隔离 | 邮件头与正文、用户的"不是垃圾"点击 |

这个练习的价值不在表格本身，而在它逼出的思考。出租车的度量包含若干相互冲突的分量，设计者必须决定如何在它们之间权衡——这正是 [[artificial-intelligence/decision-making]] 接手的效用问题。垃圾邮件过滤器的度量是不对称的，即便概率估计相同，它也会改变最优决策阈值。
:::
:::

环境在若干维度上各有不同，而每一个维度都决定了本课程中哪些技术适用。

::: definition 任务环境的性质 {#def-env-properties}
- **完全**或**部分可观察**：环境的完整相关状态是否在每个感知中都可得？（完全没有传感器的环境是**不可观察**的。）
- **单智能体**或**多智能体**：是否存在其他智能体，其性能度量依赖于我们的行动？多智能体环境可能是**竞争性**的（国际象棋）或**合作性**的（车辆避让），也可能混合。
- **确定性**或**非确定性**：下一状态是否由当前状态与动作完全决定？若一个非确定性环境的结果带有已知概率，则称其为**随机**的。
- **分集式**或**序列式**：经验能否划分为彼此独立的片段（先给这张图像分类，再给下一张），还是当前动作会影响此后的一切决策？
- **静态**或**动态**：环境能否在智能体权衡决策期间发生变化？（若只有得分在变，如带钟的国际象棋，则称**半动态**。）
- **离散**或**连续**：对状态、时间、感知与动作分别而言。
- **已知**或**未知**：*智能体*（或它的设计者）是否知道规则——每个动作的结果或结果概率？
:::

"已知"是智能体知识的性质，不是世界的性质：已知的环境可以是部分可观察的（单人纸牌游戏：规则你都知道，牌的顺序却不知道），未知的环境也可以是完全可观察的（一款新电子游戏：屏幕上什么都看得见，但按钮你还没试过来）。

::: example 环境分类 {#ex-classify}
按 [[#def-env-properties]] 的维度对下列问题分类：(a) 填字游戏；(b) 带钟的国际象棋；(c) 扑克；(d) 出租车驾驶；(e) 医学诊断；(f) 在生产线上对零件图像检测缺陷。
::: solution
| 任务 | 可观察性 | 智能体 | 确定性 | 分集性 | 静态性 | 离散性 |
|---|---|---|---|---|---|---|
| 填字游戏 | 完全 | 单 | 确定性 | 序列式 | 静态 | 离散 |
| 带钟的国际象棋 | 完全 | 多（竞争性） | 确定性 | 序列式 | 半动态 | 离散 |
| 扑克 | 部分 | 多（竞争性） | 随机 | 序列式 | 静态 | 离散 |
| 出租车驾驶 | 部分 | 多（混合） | 随机 | 序列式 | 动态 | 连续 |
| 医学诊断 | 部分 | 单（患者不建模为智能体） | 随机 | 序列式 | 动态 | 连续 |
| 零件检测 | 完全（按图像） | 单 | 确定性（按图像） | 分集式 | 半动态 | 感知连续 |

有些栏是见仁见智的判断——分类的意义在于选择技术。国际象棋是确定性的但具对抗性，因而需要博弈树搜索（[[artificial-intelligence/adversarial-search]]）；扑克增加了隐藏信息与机会。出租车驾驶同时具备一切困难性质，这就是它比国际象棋多花了几十年才被攻克的原因。检测任务为分集式：每个决策自成一体，经典工具是学出来的分类器，这是 LLM Atlas 的主题。
:::
:::

最困难的情形是部分可观察、多智能体、随机、序列式、动态、连续且未知——现实世界多半如此。本课程的顺序大致沿着这些维度推进：先处理完全可观察、确定性、单智能体问题（[[artificial-intelligence/search]]），然后是其他智能体（[[artificial-intelligence/adversarial-search]]）、结构化状态（[[artificial-intelligence/constraint-satisfaction]]、[[artificial-intelligence/logical-agents]]、[[artificial-intelligence/planning]]）、不确定性（[[artificial-intelligence/probabilistic-reasoning]]、[[artificial-intelligence/decision-making]]），最后是未知环境（[[artificial-intelligence/reinforcement-learning]]）。

### 部分可观察击溃简单反射

从扫地智能体身上取走位置传感器，使它只感知 *Dirty* 或 *Clean*。它的世界如今是部分可观察的，而对简单反射型智能体来说，后果是毁灭性的。

::: theorem 盲反射型智能体会永远失败 {#thm-blind-reflex}
在移动免费的两方格世界中，设智能体只感知当前方格是否脏。那么对每个确定性简单反射型智能体，都存在一个初始状态，使得某个方格永远不会被清洁。另一方面，一个随机化的反射型智能体——脏则吸，否则以 $\tfrac12$ 的概率各选 *Left* 或 *Right*——从每个初始状态出发都以概率 $1$ 清洁两个方格。
:::

::: proof
确定性简单反射型智能体是一个从 $\{\textit{Dirty}, \textit{Clean}\}$ 到动作的映射 $f$。一个方格只有当智能体在它脏的时候对它执行 *Suck* 才会变干净，而这只有 $f(\textit{Dirty}) = \textit{Suck}$ 才可能发生；若不成立，则从任何一个有脏方格的状态出发，那个方格就永远不会被清洁。于是设 $f(\textit{Dirty}) = \textit{Suck}$，再看 $f(\textit{Clean})$。若它是 *Suck* 或 *NoOp*，就让智能体站在一个干净方格上、另一个方格脏：它从不移动，另一格便永远脏下去。若它是 *Left*，就让智能体从 $A$ 出发，$A$ 干净而 $B$ 脏：它感知到 *Clean* 并向左移动，仍然留在 $A$，如此永远重复。*Right* 的情形对称（从 $B$ 出发，$B$ 干净而 $A$ 脏）。每种情形都有某个方格永远脏着。

对随机化智能体：只要它站在脏方格上就立刻吸，所以只需证明它最终会访问每个脏方格。当某个方格还脏而智能体站在干净方格上时，每一步都有概率 $1/2$ 移到另一个方格（朝另一格方向的移动；反方向的移动使它原地不动）。$k$ 步这样的移动之后它仍未到达另一格的概率是 $2^{-k} \to 0$，因此它以概率 $1$ 到达、吸尘，世界变干净。
:::

随机化之所以有用，恰恰因为智能体分辨不出自己的处境：对"干净"的任何确定性反应，都在某些无法区分的处境中选错；而随机反应在所有处境中都说得过去。但随机化终究是一根拐杖。一个记住自己做过什么的**基于模型的**智能体——例如每次移动后交替方向的智能体——还能做得更好，因为它用上了感知历史中的信息。

::: example 盲智能体要花多久？ {#ex-blind-time}
计算 [[#thm-blind-reflex]] 中随机化盲智能体从每个初始状态清洁两个方格所需的期望步数。
::: solution
设 $h(s)$ 为从状态 $s$ 到达干净世界所需的期望步数。干净世界 $h = 0$。若智能体站在脏方格上，它就吸尘：对那个方格已被清洁的状态 $s'$ 有 $h(s) = 1 + h(s')$。若它站在干净方格上，则 $h(s) = 1 + \tfrac12 h(s_{\text{留}}) + \tfrac12 h(s_{\text{移}})$。

在 $A$ 上、只有 $B$ 脏：$h = 1 + \tfrac12 h + \tfrac12 h(B, B \text{ 脏})$，而 $h(B, B \text{ 脏}) = 1$（吸）。故 $\tfrac12 h = 1 + \tfrac12$，解得 $h = 3$。在 $A$ 上、只有 $A$ 脏时 $h = 1$。两格都脏时，智能体先吸，然后落入前一种情形：$h = 1 + 3 = 4$。由对称性，从 $B$ 出发的值相同。一段小程序通过对方程组迭代到不动点、以及固定种子模拟（从 $A$ 出发、两格皆脏，跑 100,000 次的平均值为 $3.99$）验证了这一点。能感知位置的反射型智能体至多需要 $3$ 步；在这里，失明带来的代价是一步期望损失，但在一条 $n$ 格走廊里，盲走的随机游走需要 $n^2$ 量级的步数，而能看见的智能体扫一遍只需 $n$ 步。
:::
:::

::: widget markov
matrix: 0.5,0.5,0; 0,0,1; 0,0,1
states: on A (clean), B dirty; on B, B dirty; both clean
start: 0
steps: 10
caption: [[#thm-blind-reflex]] 中的随机化盲智能体，从 $A$ 出发、只有 $B$ 脏，表示成马尔可夫链。从状态 0 出发，它以 $1/2$ 的概率留在 $A$ 或以 $1/2$ 的概率移到 $B$；到了 $B$ 便吸尘，世界变干净。多跑几次这个随机游走，观察 $n$ 步后的分布：仍处于状态 0 的概率每步减半，所以期望步数是 $2 + 1 = 3$，与例子中的计算一致。
:::

## 构造智能体程序

智能体函数说*做什么*；智能体程序必须凭简短的描述把它计算出来。教科书区分若干种程序结构，按普适性递增。

1. **简单反射型智能体**只用当前感知、依据条件–动作规则选择动作。它快而小，且只有当正确动作能从当前感知直接读出时——本质上即环境完全可观察时——才是正确的。
2. **基于模型的反射型智能体**维护一个总结感知历史的内部**状态**。它用一个**转移模型**（世界如何演化，它的动作如何影响世界）和一个**传感器模型**（世界的状态如何在感知中体现）来更新状态。它能处理部分可观察性，[[#ex-move-cost]] 中的记忆正是如此。它的状态可以是关于世界状态的信念，也可以是状态上的概率分布——即 [[artificial-intelligence/probabilistic-reasoning]] 用前向算法计算的**信念状态**。
3. **基于目标的智能体**知道哪些状态是理想的，并通过考虑行动的未来后果来选择动作："如果我这样做会发生什么，它会让我离目标更近吗？"这是**搜索**与**规划**的领地。它比反射型智能体更灵活——换一个目标，同一个程序就会做不同的事——代价是计算。
4. **基于效用的智能体**有一个按理想程度给状态（或历史）打分的**效用函数**，从而能在冲突的目标之间权衡，并在可能的结果与不太可能的结果之间比较。理性的效用型智能体选择*期望*效用最大的动作。
5. **学习型智能体**从经验中改进上述任何一部分：*评价器*把结果与性能标准相比较，*学习元件*更新智能体的规则、模型或效用估计，*问题生成器*提出探索性动作。

这些设计与其说互相竞争，不如说层层相因；一辆自动驾驶汽车既有反射（紧急制动），又有模型（跟踪其他车辆），又有目标（目的地）、效用（舒适与速度的权衡）和学来的部件（感知）。

第二条轴是智能体如何**表示**世界状态：

- **原子式**：状态是一个不可分的标签（"我们在布加勒斯特"）；搜索算法（[[artificial-intelligence/search]]、[[artificial-intelligence/adversarial-search]]）与马尔可夫决策过程（[[artificial-intelligence/decision-making]]）在这一层工作；
- **因子式**：状态是一列变量的取值（"油量 $= 0.4$，位置 $= (3, 7)$，门开着"）；约束满足、命题逻辑、规划与贝叶斯网络都利用这种结构；
- **结构式**：状态包含对象及对象之间的关系（"我前面的卡车正在倒进奶牛场的车道"）；一阶逻辑（[[artificial-intelligence/logical-agents]]）对此加以表示。

更强的表示能用更短的篇幅描述世界——国际象棋的一条规则用一阶逻辑写只需一页，用命题逻辑写却要几千页——但与它们进行推理也更难。

::: quiz
一台送货机器人记录它访问过哪些房间，并通过搜索地图来选择去下一个取货点的路线。哪些描述适用于它？

- [x] 基于模型的，因为它维护内部状态。
- [x] 基于目标的，因为它通过考虑动作通向哪里来选择动作。
- [ ] 简单反射型，因为它对传感器作出反应。
- [ ] 表驱动的，因为地图就是一张表。
::: solution
记住访问过的房间就是内部状态（基于模型），搜索路线则是就目标考虑动作的后果（基于目标）。它不是简单反射型智能体——后者的动作只依赖当前感知；地图是用来计算动作的世界模型，而不是从感知序列到动作的表。
:::
:::

### 不是每个智能体函数都有程序

每个智能体函数都能实现吗？这个问题并非空谈：它把规格说明（函数）与工程实现（程序）分开，而且有一个干脆的答案。

::: theorem 绝大多数智能体函数不可计算 {#thm-uncountable}
设 $P$ 是满足 $\lvert P\rvert \ge 1$ 的有限感知集，$A$ 是满足 $\lvert A\rvert \ge 2$ 的动作集。则智能体函数 $f\colon P^+ \to A$ 之集不可数，而智能体程序（在任何固定程序设计语言中）之集可数。因此存在任何程序都无法实现的智能体函数。
:::

::: proof
集合 $P^+$ 是可数无穷：先按长度、长度相同时按字典序排列各序列，得 $s_1, s_2, s_3, \dots$。固定两个不同动作 $a, b \in A$。假想取值于 $\{a, b\}$ 的智能体函数能排成 $f_1, f_2, \dots$。定义：若 $f_i(s_i) = a$ 则 $g(s_i) = b$，否则 $g(s_i) = a$。那么 $g$ 在每个 $s_i$ 处都与 $f_i$ 不同，故不在表中——这就是康托尔（Cantor）的对角线论证。于是智能体函数不可数。程序是有限字母表上的有限串，这样的串只有可数个。所以函数比程序多，绝大多数函数没有程序可言。
:::

这与证明绝大多数语言不可判定的计数论证完全相同（[[theory-of-computation/decidability]]）；另见 [Maths Atlas：基数](/learn/maths/lesson.php?c=proofs&l=cardinality)。它对 AI 的教训温和而真实：给定环境的理性智能体函数可能根本不可计算；即便可计算，精确计算它也可能耗时过长。因此实际的 AI 追求**有限理性**：在计算需要时间这一前提下，给定机器上的最佳程序——现在做出不错决策的智能体，常常胜过本来会做出完美决策却为时已晚的智能体。

## AI 处理哪些问题？

有了这套词汇，我们就能描述这个领域的主要问题类别以及处理它们的章节：

- **搜索**在状态为原子、完全可观察、确定性的已知环境中寻找一条到达目标的动作序列（[[artificial-intelligence/search]]）；博弈中环境里含有一个对手（[[artificial-intelligence/adversarial-search]]）。
- **约束满足**为因子式状态寻找满足约束的赋值（[[artificial-intelligence/constraint-satisfaction]]）。
- **逻辑推理**从以形式语言表达的知识中推出新事实，保证结论在每个与知识相容的世界里都为真（[[artificial-intelligence/logical-agents]]）；**规划**利用这类表示构造行动方案（[[artificial-intelligence/planning]]）。
- **概率推理**在世界只能部分观察、规则不确定时维护信念程度（[[artificial-intelligence/probabilistic-reasoning]]），**决策论**则选择使期望效用最大的动作，也包括长时域（[[artificial-intelligence/decision-making]]）。
- **学习**从经验中改进智能体。从奖励中学习行动的强化学习是本课程的终点（[[artificial-intelligence/reinforcement-learning]]）；监督学习、神经网络与语言模型在 [LLM Atlas](/learn/llm/) 中讲授，从[学习问题](/learn/llm/lesson.php?c=ml-fundamentals&l=learning-problem)开始。

贯穿这一切的，是**知识**与**计算**之间的张力。智能体对环境了解得越多——一个更好的启发式、一个更好的模型、更强的约束——它需要搜索的就越少。本课程的多数定理都把这一定量化：更好的启发式扩展更少的结点（[[artificial-intelligence/search]]），更好的着法排序让 α–β 搜索深入一层（[[artificial-intelligence/adversarial-search]]），条件独立使概率推理变得可处理（[[artificial-intelligence/probabilistic-reasoning]]）。

::: history
图灵（Turing）的 "Computing machinery and intelligence"（*Mind*，1950）提出了"模仿游戏"，即如今所称的图灵测试，并回应了对会思考的机器这一想法的各种质疑。约翰·麦卡锡（John McCarthy）、马文·明斯基（Marvin Minsky）、纳撒尼尔·罗切斯特（Nathaniel Rochester）与克劳德·香农（Claude Shannon）起草了 1956 年达特茅斯人工智能夏季研究计划的提案，这个领域由此得名；在该会议上，艾伦·纽厄尔（Allen Newell）与赫伯特·西蒙（Herbert Simon）展示了逻辑理论家程序。纽厄尔与西蒙的通用问题求解器（1959）及其物理符号系统假说（1976）把智能刻画为符号操作。把 AI 看作理性智能体的设计，这一观点在 1990 年代成为教科书组织架构的指导思想，代表作是斯图尔特·罗素（Stuart Russell）与彼得·诺维格（Peter Norvig）的《人工智能：一种现代方法》(*Artificial Intelligence: A Modern Approach*)（初版 1995，第四版 2020）；赫伯特·西蒙的**有限理性**概念可上溯到 1950 年代，罗素与德夫卡·苏布拉马尼安（Devika Subramanian）的 "Provably bounded-optimal agents"（1995）给出了有界最优的精确含义。罗德尼·布鲁克斯（Rodney Brooks）的包容式体系结构（1986）主张不用中央模型、分层构造反射式机器人。
:::

## 后续内容

下一章 [[artificial-intelligence/search]] 构造第一批基于目标的智能体：给定问题的描述，它们找到一条解决问题的动作序列，配上好的启发式时，只考察状态空间极小的一部分就够了。信息有限下的理性这一主题将在 [[artificial-intelligence/probabilistic-reasoning]]（维护信念状态，即把基于模型的智能体的内部状态精确化）与 [[artificial-intelligence/decision-making]]（选择使期望效用最大的动作）中重现。围绕语言模型构建的智能体——它们会规划、调用工具、在软件环境中行动——是同一智能体循环的一个新兴且快速演化的应用；它们在 LLM Atlas 的[智能体](/learn/llm/course.php?c=agents)课程中讲授。

::: summary
- **智能体**把感知序列映射为动作；**智能体函数**是规格说明，**智能体程序**是其实现（[[#def-agent]]）。显式表需要 $\sum_t \lvert P\rvert^t$ 个表项，不可行（[[#ex-table-size]]）。
- **理性**智能体在其感知与知识下最大化*期望*性能（[[#def-rational]]）；理性不是全知，它依赖于性能度量，而性能度量应当描述我们在环境中真正想要的东西。
- 反射型扫地智能体在最简单的扫地机器人世界中是最优的（[[#thm-reflex-rational]]），但加上移动代价或拿掉一个传感器就会失效（[[#ex-move-cost]]、[[#thm-blind-reflex]]）；随机化能弥补部分可观察性，而更好的办法是内部状态。
- 任务环境由 **PEAS** 给出，并按可观察、多智能体、确定性、分集式、静态、离散、已知与否分类（[[#def-env-properties]]）；这些性质决定所用技术。
- 智能体程序从**简单反射**经**基于模型**、**基于目标**、**基于效用**直至**学习型**；状态有**原子式**、**因子式**、**结构式**之分。
- 绝大多数智能体函数不可计算（[[#thm-uncountable]]）；实际的 AI 追求**有限理性**。
:::

## 习题

::: exercise 数表项 {level=1 check="1398100"}
用 [[#ex-table-size]] 的公式，四个感知的表驱动扫地智能体在寿命 $T = 10$ 步时需要多少个表项？用闭式与和式互相验证。（输入表项数。）
::: solution
$\sum_{t=1}^{10} 4^t = 4 + 16 + 64 + 256 + 1024 + 4096 + 16384 + 65536 + 262144 + 1048576 = 1{,}398{,}100$，闭式给出 $(4^{11} - 4)/3 = (4{,}194{,}304 - 4)/3 = 1{,}398{,}100$。
:::
:::

::: exercise 可能的最高分 {level=1 check="1998"}
在移动免费、寿命 $T = 1000$ 步的扫地机器人世界中，从 $A$ 出发、两个方格皆脏时，任何智能体能取得的最高分是多少？（输入得分。）
::: solution
由 [[#thm-reflex-rational]] 的证明，$c_1 \le 1$、$c_2 \le 1$，且 $t \ge 3$ 时 $c_t \le 2$，而反射型智能体达到这些界。得分为 $1 + 1 + 2 \cdot 998 = 1998$，[[#ex-move-cost]] 的模拟打印过的正是这个数。
:::

::: exercise 分类并说明理由 {level=1}
按 [[#def-env-properties]] 的维度分类下列任务环境，并对你认为有争议的栏说明理由：(a) 从一个已知的打乱局面复原魔方；(b) 西洋双陆棋程序；(c) 在运动的传送带上分拣包裹的机器人；(d) 逐句处理的英法在线翻译器。

(a) 完全可观察、单智能体、确定性、序列式、静态、离散、已知——搜索的经典舞台。(b) 完全可观察（棋盘与骰子都看得见）、多智能体竞争性、随机（骰子）、序列式、静态（带钟则半动态）、离散、已知。(c) 部分可观察（标签可能被遮挡、传感器有噪声）、单智能体（若其他机器人共用传送带则多智能体）、随机、对每个包裹一阶近似下是分集式（若机器人的放置影响后续包裹则为序列式）、动态（机器人思考时传送带不停）、连续，且大体已知。(d) 输入完全可观察（那句话），但真正要紧的"状态"——要表达的语义——是隐藏的，因此在相关意义上部分可观察；单智能体；程序是确定性的，但正确的输出不确定；按句子分集（若利用前文语境则为序列式）；静态；离散；而翻译规则并无可以明确知晓的表述，这正是此类系统要靠学习的原因。

::: exercise 一个有记忆的盲智能体 {level=2}
[[#thm-blind-reflex]] 的扫地智能体只感知 *Dirty* 或 *Clean*，移动免费。设计一个只用常量存储量的确定性智能体，使它在每个初始状态下都能清洁两个方格，并给出它所需的最坏情况步数。
::: solution
让智能体数自己的步数（一个到 $6$ 为止的计数器），并执行固定计划，其中"清洁"指感知为 *Dirty* 时执行 *Suck*，否则 *NoOp*：第 1 步清洁；第 2 步 *Right*；第 3 步清洁；第 4 步 *Left*；第 5 步清洁；第 6 步起 *NoOp*。若从 $A$ 出发，第 1、3 步分别清洁 $A$、$B$。若从 $B$ 出发，第 1 步清洁 $B$，第 2 步把它留在 $B$，第 4 步移到 $A$，第 5 步清洁 $A$。于是至多 $5$ 步两个方格都干净了；从 $B$ 出发而 $A$ 脏时恰需 $5$ 步。计数器占用三个比特。这说明真正治愈部分可观察性的不是随机性，而是内部状态。
:::

::: exercise 反射型智能体何时非理性？ {level=2}
对 [[#thm-reflex-rational]] 的假设作每项改动，问反射型扫地智能体是否仍然理性；若否，描述一个更好的智能体：(a) 寿命 $T$ 为 $1$；(b) 干净方格每步以概率 $0.1$ 重新变脏；(c) 智能体不知道地图——$B$ 右边也许还有一个方格。
::: solution
(a) 理性：证明对每个 $T$ 都成立。$T = 1$ 时只有第一个动作要紧，脏则吸（否则随意）即最优。(b) 反射型智能体一发现脏污就一直移动、吸尘，这在现在反而是合理的：脏污会重现，智能体必须持续检查。移动免费时，巡逻并在发现脏污时吸尘是一条合理的策略——原地不动永远清洁不了另一个方格，而移动不花钱——尽管证明它最优需要 [[artificial-intelligence/decision-making]] 的工具。移动收费时，更好的智能体会等上一段时间，再按使代价与期望脏污相平衡的间隔返回，[[#ex-regrow]] 对此作了探索。(c) 一般并非理性：从不向右探索 $B$ 的智能体可能让一个脏方格永远脏着。理性的智能体会去探索——在 $B$ 上试一次 *Right*，看位置是否改变——而它的感知包含位置，会告诉它第三个方格是否存在。
:::
:::

::: exercise 走廊中的期望时间 {level=2 check="12"}
[[#thm-blind-reflex]] 的随机化盲智能体住在一个由方格 $1, 2, 3, 4$ 组成的走廊里（从 $1$ 向左或从 $4$ 向右移动都原地不动）。只有方格 $4$ 是脏的，智能体从方格 $1$ 出发。它首次到达方格 $4$ 之前，期望要走多少步*移动*（在干净方格上的步数）？（输入期望移动步数。）
::: solution
设 $m_i$ 为从方格 $i$ 到达 $4$ 的期望移动步数，则 $m_4 = 0$。在方格 1，一次移动以概率 $1/2$ 原地不动、以概率 $1/2$ 到 2：$m_1 = 1 + \tfrac12 m_1 + \tfrac12 m_2$，故 $m_1 = 2 + m_2$。对 $i = 2, 3$：$m_i = 1 + \tfrac12 m_{i-1} + \tfrac12 m_{i+1}$。令 $d_i = m_i - m_{i+1}$；则 $d_1 = 2$，内部方程给出 $d_i = d_{i-1} + 2$，故 $d_2 = 4$、$d_3 = 6$。于是 $m_1 = d_1 + d_2 + d_3 = 2 + 4 + 6 = 12$。一般地，$n$ 格走廊的答案是 $2 + 4 + \dots + 2(n-1) = n(n-1)$，关于 $n$ 是二次的；而知道自己在哪里的智能体只需 $n - 1$ 步。
:::
:::

::: exercise 一个处理脏污重生的基于模型的智能体 {#ex-regrow level=3}
在两方格世界中，每个干净方格每步结束时以概率 $q$ 独立地变脏。移动花费 $\mu$ 点，每个干净方格每步得一分。刚清洁过脚下这一格的智能体，既可以留下（*NoOp*），也可以移到另一个方格——它上次见到那个方格是 $k$ 步之前，当时是干净的。(a) 证明另一格此刻是脏的概率为 $1 - (1 - q)^k$。(b) 大略论证何时移动优于等待，并实现一个模拟（固定种子），对 $q = 0.05$、$\mu = 1$ 以及若干 $\theta$ 值，比较反射型智能体与一个只在 $1 - (1-q)^k$ 超过阈值 $\theta$ 时才移动的智能体。
::: solution
(a) 该方格在 $k$ 步中的每一步都保持干净的概率是 $1 - q$，且各步独立，所以它仍干净的概率是 $(1 - q)^k$，是脏的概率是 $1 - (1 - q)^k$。

(b) 移动现在立即花费 $\mu$；若另一格是脏的，赶过去吸掉它就能换回此后每步一分，直到它下次变脏，期望约 $1/q$ 步。一条粗略的规则是当 $(1 - (1-q)^k) / q \gtrsim \mu$ 时移动，对 $q = 0.05$、$\mu = 1$ 得阈值 $\theta = 0.05$ 附近——但等待的同时智能体自己的方格也会在离开期间变脏，所以精确的最优最好由 [[artificial-intelligence/decision-making]] 的方法或实验来求：

```python
import random

def simulate(theta, q=0.05, mu=1, T=100_000, seed=0):
    rng = random.Random(seed)
    dirt = {"A": False, "B": False}; loc = "A"; last_seen = {"A": 0, "B": 0}; score = 0
    for t in range(1, T + 1):
        other = "B" if loc == "A" else "A"
        if dirt[loc]:
            dirt[loc] = False                       # 吸尘
        elif theta is None or 1 - (1 - q) ** (t - last_seen[other]) > theta:
            loc = other; score -= mu                # 移动（对反射型智能体而言总是移动）
        last_seen[loc] = t
        score += sum(not d for d in dirt.values())
        for s in dirt:                              # 脏污重生
            if not dirt[s] and rng.random() < q:
                dirt[s] = True
    return score / T

print("reflex", round(simulate(None), 3))
for theta in (0.1, 0.3, 0.5, 0.7):
    print(theta, round(simulate(theta), 3))
```

```console
$ python3 regrow.py
reflex 1.043
0.1 1.437
0.3 1.673
0.5 1.628
0.7 1.526
```

反射型智能体几乎每步都为移动付费，平均每步约 $1.04$ 分；等到另一格相当可能变脏再动则好得多——在试过的阈值中 $\theta = 0.3$ 最好，约每步 $1.67$ 分。精确最优取决于 $q$ 与 $\mu$；要点在于：一点内部状态（每个方格距上次查看的时间）加一点概率推理，就能把一条非理性的反射规则变成一条合理的策略。
:::

::: exercise 可数个有限状态智能体 {level=3}
(a) 对 $\lvert P\rvert$ 个感知与 $\lvert A\rvert$ 个动作，简单反射型智能体函数有多少个？(b) **有限状态智能体**有一个有限内部状态集 $Q$、初始状态 $q_0$、更新函数 $u\colon Q \times P \to Q$ 与输出函数 $o\colon Q \times P \to A$；每收到一个感知就输出 $o(q, p)$ 并转移到状态 $u(q, p)$。证明当 $P$ 与 $A$ 有限时，有限状态智能体所实现的智能体函数之集是可数的。(c) 为什么 (b) 不与"扫地机器人世界存在理性智能体"相矛盾？
::: solution
(a) 简单反射型智能体函数由它在每个单独感知上的动作决定，故有 $\lvert A\rvert^{\lvert P\rvert}$ 个——对四个动作的扫地机器人世界是 $4^4 = 256$ 个。

(b) 不妨设 $Q = \{1, \dots, k\}$，某个 $k \ge 1$。对每个 $k$，$q_0$、$u$、$o$ 的组合只有有限多种——至多 $k \cdot k^{k\lvert P\rvert} \cdot \lvert A\rvert^{k\lvert P\rvert}$ 种——于是有限状态智能体之集是有限集的可数并，故可数；它们实现的智能体函数之集也可数（每个智能体实现一个函数）。由 [[#thm-uncountable]]，几乎所有智能体函数都不被任何有限状态智能体实现。

(c) 不可数多个智能体函数不是有限状态的，但我们需要的函数往往是：[[#thm-reflex-rational]] 的理性扫地智能体甚至是简单反射型的，[[#ex-move-cost]] 的基于模型的智能体只有四个内部状态。计数论证说的是*绝大多数*函数不可实现，而不是*有用的*那些不可实现。
:::
:::

::: exercise 设计一个性能度量 {level=2}
一家公司想要一个为写字楼电梯排程的智能体。请提出一个性能度量，说明如果度量只是"平均等待时间"会出什么问题，并给出一个 PEAS 描述。
::: solution
只看平均等待时间，就忽略了方差与尾部：智能体可能飞快地服务繁忙楼层，却让安静楼层的一位乘客等上十分钟，平均值好看得很而最坏情形无法忍受。它还忽略了电梯内耗时与能耗。更好的度量把平均等待时间、对超过（比如说）两分钟的等待的大额罚款、平均乘梯时间、消耗的电能，按与客户议定的权重组合起来；安全约束（开关门、载重）是硬约束，不进度量。PEAS：*性能*如上；*环境*：大楼、在各楼层到达并已有目的楼层的乘客、电梯机构；*执行器*：命令每部电梯前往某层、开关门；*传感器*：每层的呼叫按钮（以及若有目的层面板的话）、电梯位置与载重、门传感器、时钟。环境是部分可观察的（智能体不知道谁会到达）、随机、弱意义下多智能体（乘客会对电梯作出反应）、序列式、动态，且离散楼层与连续时间并存。
:::
