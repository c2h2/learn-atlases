到此为止的一切都是数学：单位向量、酉矩阵、投影算子。量子计算机是一个物理客体，那些抽象由真实系统去近似——冷却到比绝对零度高百分之一度的超导电路、电场中囚禁的单离子、陷在聚焦激光束里的原子、波导中的单光子——而每一种近似都在漏。本章问：造出一个量子比特需要什么；用真正要紧的数字（错误率、相干时间、门速、连接性、规模）比较各大硬件平台；描述**含噪声中等规模**时代及其算法；并把 2026 年的学科现状总结一下：什么已被演示，什么被宣称又被质疑，以及距对密码学有意义的数运行肖尔（Shor）算法还有多远。

先说两点提醒。其一，硬件变化很快，这里引用的数字是 2020 年代中期已发表的最佳器件的量级，不是任何产品的规格；凡会变的东西都标了日期。其二，量子计算招来的炒作比多数领域都多。我们按作者本人及其质疑者发表的内容来描述实验，并始终保持*演示*（器件上实测的结果）与*展望*（路线图、资源估计）的区分。各个系统的物理见[物理图谱](/learn/physics/lesson.php?c=quantum-1&l=spin)，光子部分另见[电气图谱：光纤](/learn/ee/lesson.php?c=photonics&l=optical-fibres)。

## 量子比特需要什么

2000 年，DiVincenzo 列出了任何物理实现都必须满足的要求。

::: definition DiVincenzo 准则 {#def-divincenzo}
一个物理系统可以充当量子计算机，如果它具有：(1) 由表征清楚的量子比特构成的**可扩展**物理系统；(2) 能把量子比特**初始化**到诸如 $\ket{0\cdots0}$ 的简单状态；(3) **相干时间**远长于门时；(4) 一个**通用门集**；(5) **按量子比特测量**的能力。用于量子通信还要加上 (6) 在静止量子比特与"飞行"量子比特（通常是光子）之间转换的能力，以及 (7) 把飞行量子比特可靠地传送到各地点的能力。
:::

这些准则彼此拉扯。量子比特既要与环境隔离以保持相干，又要与控制场及其他量子比特强耦合，才能被快速操纵和测量。每个平台都是这两个方向之间的折中，而品质指标就用来刻画这个折中。

- **门保真度** $F$ 或单、两量子比特门的**错误率** $\epsilon = 1 - F$，通常用**随机化基准测试**测量：随机串起一段克利福德门，其理想乘积已知，存活概率随串长 $m$ 按 $\approx(1 - \epsilon)^m$ 衰减。两量子比特门几乎总是最差的。
- **相干时间** $T_1$（弛豫）与 $T_2$（退相位），定义见 [[quantum-computing/error-correction]]；要紧的是它们与门时之比。
- **态制备与测量（SPAM）**误差，以及测量时间。
- **连接性**：哪些量子比特对能直接相互作用。受限的连接性迫使插入 SWAP 门（每个相当于三个 CNOT，[[quantum-computing/quantum-circuits#ex-identities]]），既费时间又费错误。
- **规模与均匀性**：量子比特的个数，以及它们是否彼此相像——这决定了在几对量子比特上测得的错误率是否在全片成立。

::: example 退相干之前能跑多少个门？ {#ex-gate-budget}
一个量子比特的 $T_2 = 100$ µs，两量子比特门耗时 $50$ ns。$T_2$ 内塞得下多少个串行门？若改为每个门的误差为 $\epsilon = 10^{-3}$，一个含 $5000$ 个两量子比特门的电路无任何错误地跑完的概率是多少？
::: solution
$100\,\mu\text{s}/50\text{ ns} = 2000$ 个门时。但退相干不是唯一的限制：若错误相互独立，$5000$ 个门全部成功的概率是 $(1 - 10^{-3})^{5000} = e^{5000\ln(0.999)}\approx e^{-5.0}\approx 0.0067$。没有纠错时，电路只有在期望错误数（这里是 $\epsilon G = 5$）远小于 $1$ 时才有用。所以错误率在 $10^{-3}$ 左右、未编码的器件，能以良好保真度运行至多几百到一千个两量子比特门的电路——这正是下文 **NISQ** 区域的本质。
:::
:::

这个例子的算术值得说一次，因为它被不断用来判断一台器件能做什么。

::: proposition 未纠错电路的成功概率 {#prop-budget}
若电路的 $G$ 个门各以概率 $\epsilon$ 独立失效，且只有当没有一个门失效时一次电路运行才算成功，则
$$
1 - \epsilon G\ \le\ (1 - \epsilon)^G\ \le\ e^{-\epsilon G}.
$$
特别地，当 $G\le 1/(2\epsilon)$ 时成功概率至少 $1/2$，当 $G\ge k/\epsilon$ 时至多 $e^{-k}$。
:::

::: proof
中间一式是 $G$ 个概率为 $\epsilon$ 的独立事件一个都不发生的概率。左边的不等式是伯努利不等式：$0\le\epsilon\le1$ 时 $(1 - \epsilon)^G\ge1 - G\epsilon$，归纳可证：$(1 - \epsilon)^{G+1}\ge(1 - G\epsilon)(1 - \epsilon) = 1 - (G+1)\epsilon + G\epsilon^2\ge1 - (G + 1)\epsilon$。右边的不等式由 $1 - \epsilon\le e^{-\epsilon}$（切线位于凸函数 $e^{-x}$ 之下）取 $G$ 次方得到。两个推论立即可得。
:::

真实的错误并非全都致命——有些落在随后被测掉的量子比特上，有些相互抵消——所以这个界对特定电路偏悲观，但它对 $\epsilon G$ 的标度是对的：没有纠错，电路的可用规模就是约 $1/\epsilon$ 个门。

## 主要平台

### 超导电路

超导量子比特是一个电路——电容、电感与**约瑟夫森结**（两层超导体夹一层纳米薄的绝缘体）——用光刻工艺做在芯片上。结是一个非线性电感，使电路的能级不等间距，于是最低两个能级可以当作量子比特来寻址而不激发第三能级。主流设计 **transmon**（Koch 与合作者，2007）的跃迁频率为几吉赫。为使热激发可忽略，芯片坐在约 $10$–$20$ mK 的**稀释制冷机**里（见下文习题"为什么这么冷？"）。单量子比特门是几十纳秒的微波脉冲；两量子比特门用可调耦合器或频率失谐，耗时几十到几百纳秒；测量通过与量子比特耦合的微波谐振器进行，耗时约一微秒。

**优点：**门快，用半导体工业技术制造，平面布局非常适合表面码。**缺点：**相干时间 $100$ µs 量级（截至 2026 年最好的 transmon 达几百 µs），制造造成的量子比特间差异，最近邻连接，以及每个量子比特都要有的连线与制冷——这是扩展到百万量级的几大障碍之一。最大的处理器从约一百到一千多个量子比特（IBM 2023 年发布的 Condor 芯片有 $1\,121$ 个），最好的两量子比特错误率在 $10^{-3}$ 到几 $\times10^{-3}$ 之间。Google、IBM、中国科学技术大学（USTC）等团队使用这一平台；下文讨论的 Google 2019 年的采样实验与 2024 年的纠错实验都是超导的。

### 离子阱

镱、钙或钡等元素的离子由振荡电场（泡利阱）真空囚禁，排成一条线，或分布在场效应微加工阱的各区域。量子比特是每个离子的两个超精细能级或光学能级，相干时间以秒计乃至更长——与门时相比大得惊人。门用激光（或用带磁场梯度的微波）；两量子比特门如 Mølmer–Sørensen 门，通过离子共享的振动模式把离子耦合起来，这给出链内的**全连接**。Cirac 与 Zoller 于 1995 年提出第一个离子阱量子门，Wineland 团队同年演示了 CNOT。

**优点：**量子比特完全相同（同一同位素的每个离子都一样）、已发表的两量子比特保真度最高（2024–2025 年若干实验超过 $99.9\%$）、相干时间长、连接灵活。**缺点：**门慢（微秒到几百微秒），所以算法的墙上时间（wall-clock time）长得多；以及扩展到每条链几十个离子以上很困难，需要把离子在芯片各区域间搬运（Kielpinski、Monroe 与 Wineland 于 2002 年提出的 **QCCD** 架构），或用光子把多个阱连起来。Quantinuum、IonQ 等的商用系统在 2020 年代中期为几十个量子比特（Quantinuum 的 H2 于 2024 年达到 $56$ 个）。

### 中性原子

中性原子（铷、铯、镱、锶）被逐一囚禁在**光镊**——紧聚焦的激光束——中，排成几百到几千个位点的一维或二维阵列。量子比特是相干时间很长的超精细态或核自旋态。两量子比特门用**里德堡阻塞**（Jaksch 与合作者，2000）：把一个原子激发到高激发的里德堡态，会移动其邻居的能级，使其不能被同时激发，这就得到一个受控相位。至关重要的是，光镊能在计算过程中**移动**原子，连接性因而可以重构。2023 年 12 月，哈佛–MIT–QuEra 团队（Bluvstein 与合作者）在由 $280$ 个原子编码的最多 $48$ 个逻辑量子比特上运行了算法，是当时最大的逻辑量子比特演示。**缺点：**原子损耗，循环时间比超导电路慢，两量子比特保真度 2023–2024 年前后才达到 $99.5\%$。

### 光子

光子几乎不与环境相互作用，所以退相干极小，是通信的天然载体——但正因如此它们彼此也几乎不相互作用，两量子比特门于是困难。Knill、Laflamme 与 Milburn 于 2001 年证明，借助测量与前馈就能让线性光学成为通用的，只是资源代价高昂；现代方案采用**测量型**计算：先制备一个大规模纠缠的**簇态**，计算经由单光子测量推进（Raussendorf 与 Briegel，2001），或其**融合式**变体。光子器件已运行过高斯玻色子采样实验（USTC 的"九章"始于 2020 年，Xanadu 的 Borealis 在 2022 年），用于 [[quantum-computing/quantum-complexity]] 中的优势主张。光子损耗与缺乏确定的单光子源是主要障碍。

### 其他方案

硅或锗量子点中的**自旋量子比特**（Loss 与 DiVincenzo，1998）或施主原子（Kane，1998）极小，可直接利用半导体制造；2022 年有多个团队报告两量子比特保真度超过 $99\%$，但器件仍然很小。**拓扑量子比特**把信息存放在非局域自由度中——例如超导–半导体纳米线里的马约拉纳（Majorana）零模——天然受保护、不受局域噪声影响。截至 2026 年，还没有任何拓扑量子比特被明确无误地演示；早先一个关于 Majorana 特征的宣称已于 2021 年撤稿，Microsoft 2025 年关于拓扑处理器的公告所附论文的编辑备注明确指出，该文本身并未确立拓扑模式，且该工作至今仍有争议。**量子退火机**（D-Wave）是拥有数千量子比特的模拟式优化器件；它们不是通用的门模型计算机，也从未确立过任何指数加速。

::: example 受限连接的代价 {#ex-connectivity}
量子比特 $1, \dots, n$ 排在一条线上，两量子比特门只允许在邻居之间。量子比特 $1$ 与 $n$ 之间的一个 CNOT 要花多少个 CNOT？与全连接的架构相比如何？
::: solution
用与邻居的 SWAP 把量子比特 $1$ 的状态挪到量子比特 $n$ 旁边：$n - 2$ 次 SWAP 把它带到位置 $n - 1$。施加 CNOT，然后（若必须恢复布局）再来 $n - 2$ 次 SWAP。每个 SWAP 是三个 CNOT（[[quantum-computing/quantum-circuits#ex-identities]]），总共 $3(n - 2) + 1 + 3(n - 2) = 6n - 11$ 个 CNOT；若允许量子比特保持置换后的次序，则 $3n - 5$ 个。$n = 20$ 时这是 $109$（或 $55$）个 CNOT，而不是 $1$ 个；每个 CNOT 误差 $10^{-3}$ 时，这一个操作的错误被放大约 $100$ 倍。编译器通过巧妙选择量子比特布局与布线来缓解，二维网格把距离降到 $O(\sqrt n)$；离子阱链（链内全连接）与可移动的中性原子则避开了它，代价是门更慢。表面码只需要网格上的最近邻门——这是它适合超导芯片的原因之一。
:::
:::

容错算法是一串纠错周期；时长是周期数乘以周期时间，而周期时间由门速与测量速度决定——超导量子比特约一微秒，离子阱可达几毫秒。相干时间通过错误率起作用（这里已固定），连接性通过每个逻辑门的开销起作用，量子比特数则决定算法装不装得下。这就是同一份因数分解估计在一个平台上意味着几小时、在另一个平台上意味着几个月的原因。

## NISQ 时代

2018 年，John Preskill 为我们所处的时期命了名：**含噪声中等规模量子**（NISQ，noisy intermediate-scale quantum）技术，$50$ 到几百个量子比特，噪声大到无法大规模纠错，又大到不易模拟。没有纠错，可用电路规模约以 $1/\epsilon$ 个门为限（[[#prop-budget]]）。主导这个时代的是三个想法。

- **变分算法。**一段短的带参数线路制备状态 $\ket{\psi(\vec\theta)}$，器件估计一个代价——如分子的**能量** $\bra{\psi(\vec\theta)}H\ket{\psi(\vec\theta)}$（**变分量子本征求解器**，Peruzzo 与合作者，2014），或优化问题的目标函数（**QAOA**，Farhi、Goldstone 与 Gutmann，2014）——再由经典优化器调整 $\vec\theta$。它们是启发式方法：没有证明过任何一般加速，优化景观常含梯度指数小的"贫瘠高原"（barren plateaus，McClean 与合作者，2018），而且到目前为止，在尝试过的问题上经典方法都能与之打平。
- **误差缓解。**不纠正错误，而是估计其平均效应并从测得的期望值中扣除——例如人为放大噪声运行电路、再外推到零噪声（Temme、Bravyi 与 Gambetta，2017）。缓解不需要额外量子比特，但其采样代价随电路规模乘以错误率指数增长，所以它延展了 NISQ 区域，而非逃出它。IBM 2023 年在 $127$ 个量子比特上的实验用它估计了超出暴力模拟能力的期望值；几周内经典近似方法就复现了结果——[[quantum-computing/quantum-complexity]] 的模式重演。
- **量子模拟。**多体物理的模拟式与数字式模拟——自旋模型、格点规范理论、淬火后的动力学——是最自然的近期应用，也可以说是最先交付不易通过其他途径获得的科学成果之处。

::: warning "一台有 $N$ 个量子比特的计算机就强大 $2^N$ 倍"
量子比特数是新闻稿里信息量最少的数字。器件的能力至少同样取决于错误率、连接性与相干性：$1000$ 个量子比特、两量子比特错误率 $1\%$ 的器件只能可靠运行约一百个门，而 $50$ 个错误率 $10^{-4}$ 的量子比特能运行几千个。像 IBM 的**量子体积**（quantum volume，Cross 与合作者，2019）这样的综合基准或应用级基准试图刻画这一点，但任何基准都可以被针对性优化。而且在量子比特被纠错之前，再多物理量子比特也不会让量子计算机对因数分解有用：对密码学要紧的是**逻辑**量子比特的个数与逻辑错误率。
:::

## 真实硬件上的纠错

阈值定理（[[quantum-computing/error-correction#thm-threshold]]）是一个渐近陈述；实验上的问题是：真实器件是否在阈值以下，从而使更大的码给出更小的逻辑错误率。对表面码，实验可以归结为一个数字。

::: definition 误差抑制因子 {#def-lambda}
在同一硬件上运行一族距离 $d$ 递增的码，每纠错循环逻辑错误率为 $p_L(d)$，则**误差抑制因子**为 $\Lambda = p_L(d)/p_L(d + 2)$。在阈值以下表面码的标准模型中，物理错误率为 $p$、阈值为 $p_{\mathrm{th}}$、$A$ 为常数时，
$$
p_L(d)\approx A\Bigl(\frac{p}{p_{\mathrm{th}}}\Bigr)^{(d+1)/2},\qquad \Lambda\approx\frac{p_{\mathrm{th}}}{p}.
$$ {#eq-lambda}
:::

$\Lambda > 1$ 时器件**低于阈值**：距离每步增加 $2$，逻辑错误除以 $\Lambda$，逻辑错误率随 $d$ 指数下降，而物理量子比特数 $2d^2 - 1$ 只按二次增长。$\Lambda < 1$ 时，码越大越糟。

::: application 阈值以下，2023–2024
2023 年，一个 Google 团队报告其 Sycamore 处理器上距离 $5$ 的表面码的每循环逻辑错误略低于距离 $3$（$\Lambda$ 刚过 $1$）。2024 年 12 月，同一团队在其 $105$ 量子比特的 **Willow** 处理器上报告了距离 $3$、$5$、$7$ 的表面码存储器，$\Lambda = 2.14\pm0.02$：距离每增加一档，逻辑错误约减半，距离 $7$ 时达到每循环约 $0.14\%$，且距离 $7$ 的逻辑量子比特的寿命约为片上最好物理量子比特的 $2.4$ 倍。他们还在实时条件下译码了距离 $5$ 的码。这是量子存储器中阈值定理所承诺的指数抑制的首个清晰演示。它尚未包含这些错误率下的通用逻辑门集，而每循环 $10^{-3}$ 的逻辑错误率仍比大算法所需高出约十个数量级。其他团队也在离子阱与中性原子上演示了逻辑量子比特（上面 $48$ 个逻辑量子比特的实验），其中若干情形用的是更小的码以及后选择或错误探测。
:::

caption: 在模型 [[#eq-lambda]] 下（$A = 0.1$，误差抑制因子 $\Lambda$ 为滑块 $L$），每循环逻辑错误的以 $10$ 为底的对数随码距离 $d$（横轴，奇数值）的变化。$\Lambda = 2$——大致是 2024 年的最高水平——时，达到 $10^{-12}$（水平线）需要 $d \approx 73$；$\Lambda = 10$（物理错误低于阈值十倍）时 $d \approx 21$ 就够。物理量子比特数按 $2d^2$ 增长，所以提高 $\Lambda$ 远比增加量子比特值钱。
:::

### 一台有用的机器必须多大？

资源估计把算法的逻辑开销——逻辑量子比特数、$T$ 门数、纠错循环数——与一个码、一个译码器、一个包含 $T$ 门用**魔术态工厂**（[[quantum-computing/error-correction]]）的布局、以及一个物理错误率组合起来。

::: example 一个玩具资源估计 {#ex-estimate}
用 [[#eq-lambda]]，取 $A = 0.1$、$p_{\mathrm{th}} = 1\%$，估算一个假想算法——$2000$ 个逻辑量子比特、运行 $10^9$ 个纠错循环、总失败概率 $10\%$——在物理错误率从 $5\times10^{-3}$ 到 $10^{-4}$ 时所需的码距离与物理量子比特数。
::: solution
每个量子比特每循环允许的逻辑错误是 $0.1/(2000\times10^9) = 5\times10^{-14}$。对每个 $p$，把（奇数）距离加大到 $p_L(d)$ 降到该值以下，并按每个逻辑量子比特 $2d^2 - 1$ 个物理量子比特计数。

```python
# 一个玩具表面码资源模型（仅示意，不是真实的资源估计）：
#   每量子比特每循环的逻辑错误  p_L(d) = A * (p / p_th) ** ((d + 1) / 2)
#   每个逻辑量子比特的物理量子比特数  2 d^2 - 1
A, p_th = 0.1, 1e-2

def distance_needed(p, target):
    d = 3
    while A * (p / p_th) ** ((d + 1) / 2) > target:
        d += 2                                   # 表面码距离取奇数
    return d

logical_qubits, cycles = 2000, 1e9               # 一个假想的大算法
target = 0.1 / (logical_qubits * cycles)         # 允许 10% 的总失败概率
print(f"target logical error per qubit-cycle: {target:.1e}")
for p in (5e-3, 2e-3, 1e-3, 5e-4, 1e-4):
    d = distance_needed(p, target)
    per = 2 * d * d - 1
    print(f"p = {p:.0e}: Lambda = {p_th / p:5.1f}, distance {d:3}, "
          f"{per:6} physical per logical, {logical_qubits * per / 1e6:6.2f} million data+ancilla qubits")
```

```console
$ python3 estimate.py

p = 5e-03: Lambda =   2.0, distance  81,  13121 physical per logical,  26.24 million data+ancilla qubits
p = 2e-03: Lambda =   5.0, distance  35,   2449 physical per logical,   4.90 million data+ancilla qubits
p = 1e-03: Lambda =  10.0, distance  25,   1249 physical per logical,   2.50 million data+ancilla qubits
p = 5e-04: Lambda =  20.0, distance  19,    721 physical per logical,   1.44 million data+ancilla qubits
p = 1e-04: Lambda = 100.0, distance  13,    337 physical per logical,   0.67 million data+ancilla qubits
```

$p = 10^{-3}$——2020 年代中期最好的两量子比特错误率——时，模型需要距离 $25$、约 $250$ 万物理量子比特，这还未计入魔术态工厂与布线空间（通常再加相当的量）。$p$ 减半几乎让机器减半。模型是粗糙的（真实的估计要模拟具体电路与译码器），但其结论与已发表的结果在量级上相符。
:::
:::

就因数分解而言，随着算法与布局的改进，已发表的资源估计稳步下降。Gidney 与 Ekerå（2019 年预印本，2021 年发表）估计，约 $2000$ 万错误率 $10^{-3}$ 的带噪量子比特可在约 $8$ 小时内分解 $2048$ 比特的 RSA 模数。2025 年 Gidney 估计，用近似算术、更紧凑的空闲逻辑量子比特存储与更便宜的魔术态制备，不到一百万个这样的量子比特可在一周内完成。这些都是对尚不存在的机器的展望：截至 2026 年，最大的器件至多有几千个物理量子比特、至多几十个逻辑量子比特，逻辑错误率远高于这类算法的要求。差距还要多久才能填平，确实说不准——正因如此，向后量子密码（[[cryptography/post-quantum]]）的迁移已经在进行。

::: example 格罗弗算法落到实处 {#ex-grover-practice}
一台经典计算机每秒检验 $10^9$ 个候选密钥。一台容错量子计算机每一微秒执行一个逻辑门，一次格罗弗（Grover）迭代（预言机加扩散）需要 $10^4$ 个串行逻辑门。对多大的搜索空间 $N$，格罗弗（Grover）算法（[[quantum-computing/grover]]）与经典穷举耗时相同？那是多长时间？
::: solution
经典时间：$N/10^9$ 秒。量子时间：$\frac\pi4\sqrt N$ 次迭代，每次 $10^4\cdot10^{-6} = 10^{-2}$ 秒，即 $7.85\times10^{-3}\sqrt N$ 秒。二者相等当 $\sqrt N = 7.85\times10^{-3}\times10^9 = 7.85\times10^6$，即 $N\approx6.2\times10^{13}$，此时约 $6.2\times10^4$ 秒 $\approx 17$ 小时。搜索规模更小时经典机器完胜，而在那一点之后量子计算机每赢百倍只换来十倍。配上并行的经典硬件（一千块 GPU），交叉点移到 $N$ 大 $10^6$ 倍处，对应几年的量子运行时间。平方加速要靠快的逻辑门才划算；指数加速——如肖尔（Shor）算法——则不靠。
:::
:::

## 截至 2026 年的学科现状

只总结已发表或被广泛复现的工作所确立的结论：

- **超越经典的演示。**随机线路采样（Google，2019 与 2024；USTC，2021）与高斯玻色子采样（USTC 自 2020；Xanadu，2022）产生了实验者估计为经典模拟极其昂贵的输出。早年的若干主张后来被改进的经典算法追平（[[quantum-computing/quantum-complexity]]）；最近的主张截至 2026 年仍然成立，但要提醒：其经典困难性建立在猜想之上，而这些任务没有已知的实际用途。
- **纠错。**已演示出错误率随码增大而下降的逻辑量子比特（Google 的 Willow，2024），也演示了离子阱与中性原子上的小型逻辑线路。还没有对有用算法的容错执行。
- **算法。**肖尔（Shor）算法只以编译后的玩具形式在 $15$、$21$ 一类的数上运行过（[[quantum-computing/shor]]）；没有任何量子计算机用肖尔方法分解过超出袖珍计算器能力的数。没有任何实际问题在量子计算机上比最好的经典方法解得更快，尽管对物理模型的量子模拟正在接近这一点。
- **尚未确立。**拓扑量子比特；经典数据上优化或机器学习的任何指数加速；对密码学有意义的机器的时间表。

::: history
Richard Feynman（1982）与 David Deutsch（1985）提出量子计算机；Peter Shor 1994 年的算法让造出一台成了目标。1995 年，Ignacio Cirac 与 Peter Zoller 提出离子阱量子计算机，David Wineland 在 NIST 的团队演示了囚禁离子的两量子比特门；Neil Gershenfeld 与 Isaac Chuang，以及独立地 David Cory、Amr Fahmy 与 Timothy Havel，于 1997 年提出液态核磁共振（NMR）量子计算，2001 年被用于分解 $15$。中村泰信（Yasunobu Nakamura）、Yuri Pashkin 与蔡雅升（Jaw-Shen Tsai）于 1999 年观察到超导量子比特的相干振荡，Robert Schoelkopf 团队与合作者于 2007 年引入 transmon。David DiVincenzo 于 2000 年发表他的准则；Emanuel Knill、Raymond Laflamme 与 Gerard Milburn 于 2001 年提出他们的线性光学方案。Wineland 与 Serge Haroche 因测量与操纵单个量子系统的方法获 2012 年诺贝尔物理学奖。John Preskill 于 2018 年造出 "NISQ" 一词。Google 于 2019 年报告其 Sycamore 采样实验，并于 2024 年 12 月在 Willow 上报告阈值以下的表面码存储器。
:::

## 后续内容

本章是课程的最后一章。算法（[[quantum-computing/shor]]、[[quantum-computing/grover]]）定下目标；纠错（[[quantum-computing/error-correction]]）说明达到它们需要什么；复杂性理论（[[quantum-computing/quantum-complexity]]）说明该期待什么、不该期待什么。密码学方面的后果见 [[cryptography/post-quantum]]；各平台的物理见[物理图谱](/learn/physics/lesson.php?c=quantum-1&l=formalism)的量子力学课程。Preskill 的讲义与他 2018 年的 NISQ 论文是从物理与计算结合的角度出发的最佳进阶读物，Nielsen 与 Chuang 的教材仍是本课程全部内容公认的标准参考。

::: summary
- 有用的量子计算机需要 **DiVincenzo 准则**（[[#def-divincenzo]]）：可扩量子比特、初始化、远长于门时的相干时间、通用门与按量子比特测量。
- 各平台在隔离与控制之间取舍：**超导**电路（快、平面、相干时间 $\sim$0.1 ms）、**离子阱**（最高保真度、全连接、慢）、**中性原子**（大规模可重构阵列）、**光子**（天然的通信载体、受损耗限制）及其他；截至 2026 年没有一个平台在所有指标上领先。
- 没有纠错，电路被限制在约 $1/\epsilon$ 个门（[[#ex-gate-budget]]）：这是变分算法、误差缓解与量子模拟的 **NISQ** 时代，至今没有证明过的实际优势。
- 纠错的品质指标是 $\Lambda\approx p_{\mathrm{th}}/p$（[[#eq-lambda]]）；Google 的 Willow（2024）在距离至多 $7$ 的表面码存储器上测得 $\Lambda\approx2$，是首个清晰的低于阈值的标度。
- RSA-2048 的资源估计已从约 $2000$ 万（2019）降到不足一百万（2025）个带噪量子比特；这样的机器尚不存在，到来时间也不确定。
- 对量子比特数与优势主张要留个心眼：要紧的是逻辑量子比特、逻辑错误率与经典竞争者。
:::

## 习题

::: exercise 一个相干时间内的门数 {level=1 check="2000"}
一个量子比特 $T_2 = 100$ µs，门耗时 $50$ ns。$T_2$ 内塞得下多少个门时？（填一个数。）
::: solution
$100\times10^{-6}/(50\times10^{-9}) = 2000$，同 [[#ex-gate-budget]]。对一个 $T_2 = 1$ s、门时 $100$ µs 的囚禁离子，比值是 $10^4$：门更慢，但一个相干时间内塞得更多。
:::
:::

::: exercise 一个 NISQ 电路 {level=1 check="0.999^5000"}
一个电路有 $5000$ 个两量子比特门，每个独立地以概率 $10^{-3}$ 失效，别无其他错误。它毫无错误地跑完的概率是多少？（填入精确表达式或小数。）
::: solution
$(1 - 10^{-3})^{5000} = 0.999^{5000}\approx e^{-5}\approx 0.0067$。误差缓解或许仍能提取有用的期望值，但其采样代价按大约 $e^{2\epsilon G} = e^{10}$ 增长。
:::
:::

::: exercise DiVincenzo 准则的现实 {level=1}
对 [[#def-divincenzo]] 的每一条准则，说出超导量子比特满足它的一种方式和面临的一个困难。
::: solution
(1) 可扩展：用光刻在芯片上制造大量量子比特；但连线、制冷与制造差异限制了增长。(2) 初始化：冷却到约 $10$ mK 使 $\ket0$ 成为热状态，借助测量的主动复位还能提速；残余激发是一个小误差。(3) 相干性：$T_1, T_2\sim0.1$ ms 对约 $50$ ns 的门；但材料中的二能级缺陷引起涨落。(4) 通用门：微波单量子比特门与可调耦合器的两量子比特门；但有串扰与向第三能级的泄漏。(5) 测量：经谐振器的色散读取约一微秒；但测量比门慢，还可能扰动邻居。
:::
:::

::: exercise 光纤中的光子损耗 {level=1 check="0.01"}
光纤在通信波段的衰减约为 $0.2$ dB/km。$100$ km 后光子的比例还剩多少？（填一个小数。）
::: solution
$100\times0.2 = 20$ dB，即因子 $10^{-20/10} = 10^{-2} = 0.01$。$1000$ km 后将是 $10^{-20}$——这就是长距离量子网络需要中继器（纠缠交换，[[quantum-computing/entanglement]]）或卫星的原因，因为丢失的量子比特不能被放大或复制。
:::
:::

::: exercise 测量 $\Lambda$ {level=2 check="2"}
一个表面码实验在距离 $3$、$5$、$7$ 处测得每循环逻辑错误为 $0.8\%$、$0.4\%$ 与 $0.2\%$。$\Lambda$ 是多少？[[#eq-lambda]] 对距离 $11$ 预言什么？（填 $\Lambda$。）
::: solution
$\Lambda = 0.8/0.4 = 0.4/0.2 = 2$。距离 $11$ 比 $7$ 再多两步，所以每循环 $0.2\%/4 = 0.05\%$。由 [[#eq-lambda]]，$p\approx p_{\mathrm{th}}/2$：器件比阈值低两倍。
:::
:::

::: exercise 为什么这么冷？ {level=2 check="12"}
一个 transmon 的跃迁频率 $f = 5$ GHz，处于 $T = 20$ mK。计算 $hf/(k_BT)$（取整），以及量子比特处于激发态的热概率，约 $e^{-hf/k_BT}$。（$h = 6.626\times10^{-34}$ J s，$k_B = 1.381\times10^{-23}$ J/K。）（填整数。）
::: solution
$hf = 6.626\times10^{-34}\times5\times10^9 = 3.31\times10^{-24}$ J，$k_BT = 1.381\times10^{-23}\times0.02 = 2.76\times10^{-25}$ J，所以 $hf/k_BT\approx12.0$，激发态占据数为 $e^{-12}\approx6\times10^{-6}$。若 $T = 1$ K，比值将是 $0.24$，量子比特近一半处于激发态：没法用。（实际上量子比特的有效温度常比制冷机的略高，给出 $10^{-3}$–$10^{-2}$ 量级的残余占据，由主动复位清除。）
:::
:::

::: exercise 量子–经典交叉点 {level=2 check="(pi/4*10^4*10^-6*10^9)^2"}
在 [[#ex-grover-practice]] 中，用给定的数字精确求出交叉搜索空间规模 $N$。（填入表达式或数值。）
::: solution
令 $N/10^9 = \frac\pi4\sqrt N\cdot10^4\cdot10^{-6}$，得 $\sqrt N = \frac\pi4\cdot10^4\cdot10^{-6}\cdot10^9$，所以 $N = (\frac\pi4\cdot10^{7})^2\approx6.17\times10^{13}$。对 $2^{46}\approx7\times10^{13}$ 个密钥的密钥搜索恰在交叉点附近；而对 128 比特密钥的搜索远超交叉点，两边都远：$2^{64}$ 次串行格罗弗（Grover）迭代按这些速度要约 $6\times10^9$ 年。
:::
:::

::: exercise $\Lambda\approx p_{\mathrm{th}}/p$ 从何而来 {level=3}
从下面的图像推导 [[#eq-lambda]]：距离 $d$ 的码在一个循环内失败，当且仅当沿连接对立边界的某条"短"错误链上至少出现 $(d+1)/2$ 个故障；这种链的个数至多随 $d$ 指数增长；每个位置以概率 $p$ 独立失效。
::: solution
逻辑错误要求一条重量至少 $t + 1 = (d+1)/2$ 的错误链被译码器误纠。某组 $w$ 个位置全部失效的概率是 $p^w$。设 $w = (d+1)/2$ 的相关组数为 $N_d\le C\mu^{d}$（格上的链的长度至多指数增长，$C$、$\mu$ 为常数）。则 $p_L(d)\lesssim C\mu^dp^{(d+1)/2} = C'(\mu^2p)^{(d+1)/2}$，其形状正是 $A(p/p_{\mathrm{th}})^{(d+1)/2}$，其中 $p_{\mathrm{th}} = 1/\mu^2$——阈值来自失败路径数（熵）与其概率（能量）的竞争。于是 $p_L(d)/p_L(d+2) = (p_{\mathrm{th}}/p)^{1} = \Lambda$。论证还说明了阈值为什么取决于噪声模型与译码器：它们决定了哪些链会造成失败。
:::
:::

::: exercise 资源的敏感性 {level=3}
用 [[#ex-estimate]] 的估计器，求算法长度增到 $10^{12}$ 个循环时 $p = 10^{-3}$ 所需的距离，并解释为什么距离只随计算规模对数增长。
::: solution
目标变为 $0.1/(2000\times10^{12}) = 5\times10^{-17}$。$\Lambda = 10$ 时，$p_L(d) = 0.1\cdot10^{-(d+1)/2}\le5\times10^{-17}$ 要求 $(d+1)/2\ge\log_{10}(2\times10^{15})\approx15.3$，所以 $(d + 1)/2 = 16$、$d = 31$（运行 `distance_needed(1e-3, 5e-17)` 返回 $31$），此前是 $25$：每个逻辑量子比特 $2\cdot31^2 - 1 = 1921$ 个物理量子比特，而非 $1249$。计算长了一千倍，距离只增加 $6$、量子比特数增加 $54\%$，因为 $p_L$ 随 $d$ 指数下降，$d$ 只需随计算规模的对数增长——这正是阈值定理（[[quantum-computing/error-correction#thm-threshold]]）在表面码形式下的内容。
:::
:::
