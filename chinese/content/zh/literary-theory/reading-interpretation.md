前八章一路把作者请下法庭（意图谬误）、把作品拆成楼层（未定点）、把社会送进博物馆（镜子退役）——**剩下的那个空位谁来坐？本章开庭审“读者”：他是作品的施工队（第 4 章预聘）、意义的消费者，还是新的僭主？**

## 第一庭：作者意图是不是标准 {#def-yitu}

::: definition 三派坐标 {#def-sanpai}
**反意图主义**（维姆萨特、比尔兹利，第 4 章已建档：**意图是“寻找作者大脑里的私密场景”——查无实证且法庭无关**）；**假设意图主义**（赫施《阐释的目的》1967 的反击——**“若否认作品意义有别于阐释者的意义，'有效性'一词即失去全部含义”（大意）：没有“含义”（meaning，作者所意指）与“意义”（significance，作品对后人的一切有效应）的分账，一切读法平权，学科解散**）；**文本意图**（艾柯的仲裁庭——**“文本不是任由打扮的对象”（《诠释的限度》1992 大意）：裁决者既非作者（他已退庭）也非读者（他无限诉），而是 intentio operis“文本的意图”：由文本的连贯性、内在一致性、对其他部分的容纳度出庭作证——“开放的作品不等于接受一切解释的作品”**）。**本课的坐标读数**：三派争的不是“有没有作者意图”（有，在档案馆），是**“谁的申诉有终审权”——把本体论问题（意义住在哪）悄悄换成了程序法问题（谁来举证、谁可否决）**。
:::

## 第二庭：读者的上岗证 {#def-duzhe}

::: definition 隐含读者与解释性群体 {#def-yinhang}
**伊瑟尔**：文本内置一个**隐含读者**——**不是某个人，是作品预留的“施工位清单”（第 4 章未定点的岗位说明书：谁在填空、何时被误导、何时被要求重读——“侦探小说的隐含读者是‘被作者训练过的嫌疑人’：它教你在错误处兴奋”**）；**费什**更进一步：**“解释性群体”决定文本是什么**（**“形式不是读出来的，是由解读策略决定的：把一段乱码排进‘朦胧诗’栏目，它就朦胧得有理”——误读不是事故，是不同解读制度的正常产出**）。**验收实验（本章的替换法）**：把同一首“朦胧诗”（把李商隐《锦瑟》分别编入“悼亡集”“自题诗集卷首”“爱情诗选”三种目录，收集三位读者的第一反应：**分类学（第 1 章）与阐释学在此合流：书架就是最初的解释**）。
:::

::: definition 视域融合与效果史 {#def-shiyu}
伽达默尔的哲学改装：**“前见（偏见）不是理解的障碍，是理解的条件”——“我们不存在于历史之中，历史存在于我们之中”（《真理与方法》1960 大意）**；于是**“阐释循环”从逻辑瑕疵升格为本体结构**（**部分靠预想的整体获得意义，整体靠部分被证实：这不是 vicious circle，是生意的启动资金——你带着 19 岁的库存去读《红楼梦》，49 岁来对账，账目自动翻新**）；**时间距离不是必须跨越的鸿沟，是过滤器**（“**只有当时的热不能流传：流行靠误读筛选出经典——第 4 章'经典是滚动发行的股票'的哲学总部：意义不是挖出来的矿，是逐年计提的复利——赫尔施叫它 significance，伽达默尔叫它效果史，两家账本记同一笔利息**”）。姚斯的“**期待视野**”（第 8 章文类税单的阅读侧镜像：**文学史＝期待视野的建立、满足、破裂、重建的流水账——“一部作品的价值常以'它对同时代人大逆不道'来计量”（波德莱尔，瓦莱里引述）**）——**创新在效果史里才有价格：当场没人觉得新的东西，两百年后被追封为革命，也完全可能**。
:::

## 第三庭：误读的执照 {#def-wudu}

::: definition 强误读与经典税 {#def-qiang}
布鲁姆《影响的焦虑》：**“影响即误读——强力诗人必对其先驱作‘修正性误读’（clinamen，有意偏差）：俄狄浦斯式的：杀死父亲、谎报家谱”（大意体系）**——**把“误读”从错误改判为创造的本名：传统不是被继承的，是被抢劫的**；配套的“**经典＝使我们误读得更多的作品：它比我们要得多**”（布鲁姆对《莎士比亚的正典化》的通说转述）。中国本土案卷：**“六经注我”（陆九渊）**——**最豪横的读者宣言：经典降格为自证的材料**；对面是“**我注六经**”的训诂路线——**清儒的客观性纲领（“**由字以通其词，由词以通其道**”（戴震《与是仲明论学书》）：意义的所有权之争，靠语言证据链翻案——两派不是态度之争，是证据法之争**）；以及**金圣叹的批点政变**（**“六才子书”钦定＋腰斩《水浒》：批点不是评论，是把解释权、删改权、排序权一并没收——“删去招安之后＝给一部小说立遗嘱：后人只能在他的合法继承人里选边”**）。**判例汇编的启示：中国解释学的“朱陆之争”（道问学 vs 尊德性）与欧洲的赫施—伽达默尔之争同构——争的都是“客观性归谁”：考据派押证据，性灵派押体验；两案都未宣判，两案都靠对方续命（无据之悟是民科，无悟之据是档案）**。
:::

::: example “春眠不觉晓”三方庭审 {#ex-chunmian}
孟浩然《春晓》：“春眠不觉晓，处处闻啼鸟。夜来风雨声，花落知多少。”就“这首诗写的是什么”开庭：**①意图主义检方**（请传唤作者：孟浩然生平、孟集中此诗的编年、唐人应考的“题意”惯例——**能否举证“作者意指惜春／不遇／纯感官”**）；**②反意图主义辩方**（**作者大脑查无实证：诗中一个“惜”字也没有，“不遇”说全靠传记联想**）；**③文本意图仲裁庭**（**此诗与“闺怨”“应考”类文本的连贯性检验：它在哪套惯例里最自洽**）。最后裁决：**哪个回答可以结案，哪个只能存档**。
::: solution
①**意图主义的天花板**：生平可以证明孟浩然“有过”不遇之怨（**但证不成这首诗“是”不遇之怨：相关性不是签名**）；编年若确在隐居期，也只是给“闲适”读法**加保证金，不是买断**。②**反意图主义的地板**：它赢在“**查无实证**”，输在“**也查无反证**”——纯粹封杀意图会让“作者其他诗的互文证据”全部作废（**过严：连好的间接证据都被排除的法庭办不了任何案**）。③**文本意图庭**：此诗**无人的怨（无闺、无君、无友）——只有听觉的层级（啼鸟→风雨→想象的落花生）**——闺怨类惯例需要“妆、镜、帘、月”的家具（回收第 4 章未定点：**此诗的家具清单是空的：它在“应考题意”惯例里不自洽（无颂无讽），在“山水田园”惯例里最省纸**）——**“纯感官的春晨＋一缕无法定价的惜”是文本意图的最低报价**；裁决：**“不遇”说存档（有趣、无据、不可结案）；“惜春”说可判（但“惜”字全诗未出现——判决书须写明：这是读者的补写，不是文本的原文——**艾柯的限度与费什的群体在此握手：补写合法，冒充原文非法**）**。
:::
:::

::: intuition 意图不等于成就，也不等于后果 {#def-berlin}
一条来自思想史的稳压阀（柏林的常识）：**“作者想做什么 ≠ 他做成了什么 ≠ 造成了什么后果”——三个账户三张报表，文艺批评史上九成的吵架源于用错报表**（**“《诗经》的采诗官想观测民情（意图），诗人在做情歌（成就的另一半），经学家读出后妃之德（后果）——三个都对，三个都不归对方管”**）。**阅读课的日常应用**：读完先填表——**这句话是关于作者的（传记）、关于作品的（结构）、关于我的（效果）？填错栏的论文叫“关公战秦琼”，填对栏的碎论文也胜过填错栏的天才论**。
:::

::: history 读者翻身账 {#sec-fanshen}
**先秦—汉** 解释条款齐备（“以意逆志”“诗无达诂”——**多元不是现代发明，是经学日常**）；**12—13 世纪** 陆九渊“六经注我”（**读者主权的第 8 章预演**）；**17—18 世纪** 施莱尔马赫“比作者本人更好地理解作者”（**解释学升格为普遍方法：循环论成文——注意其野心：要修好文本的原意，仍是作者中心的最后一位巨人**）；**1920s—50s** 英伽登具体化学派发轫（**1960s—70s 读者革命三连：姚斯《文学史作为对文学理论的挑战》（1967）、伊瑟尔《阅读行为》（1976）、费什《怎样做一个反意图主义分子，其实你不需要》（1971）——“读者”在十年内从配角升到主角、再升到主讲（文学史由读者主演）**）；**1967** 巴特“作者之死”（**“文本的统一性不在其来源，在其目的地”——读者作为“目的地”的加冕词**）；**1971—75** 赫尔希与伽达默尔论战（《阐释的目的》vs《真理与方法》德文版第三版——**北美 vs 欧陆：方法派 vs 本体派——两败俱伤也两全其美：此后所有人都自称中间派**）；**1990—92** 艾柯《诠释与过度诠释》（**“诠释的限度”听证会：文本会抵抗，但抵抗什么由共同体标定**）；**2000s** 认知阅读、神经美学、数字人文（**“隐含读者”开始被眼动仪采样：读者回到实验室——第 3 章的黑箱接口在读者侧复制**）；**今** **算法推荐接管“期待视野”（“用户画像＝制度化的前见”——推荐系统替你把 19 岁的偏见永久续费：效果史的利息开始按点击结算——阅读理论的下一场庭审已在门口：当读者被建模，谁为误读负责）**。
:::

::: warning 阐释四坑
**“我认为”裸奔**（**读者革命不等于人人有持枪证：“我认为”必须兑换成“文本哪一处授权我认为”——艾柯的限度即本章的枪膛保险**）；**意图谬误的民科化**（**把“作者之死”读成“不必查资料”：档案证据在“意图≠成就”意义上永远有效——死的是终审权，不是作证权**）；**效果史万能**（**“后代怎么读”不能倒灌成“它是什么”：后妃之德是《关雎》的历史，不是《关雎》的语义——除非你论证的正是这段历史本身**）；**循环当诡辩**（**“你预设了结论”的攻击只有在“预设不可修订”时才成立：带着假设去、让细节改它——这叫方法；打死不改那才叫成见（第 3 章“审查官音量”的读者版）**）。
:::

::: exercise 三种目录实验 {level=1}
把一首不含人物与题目的短诗（可用《春晓》《登鹳雀楼》）**编入三种目录**（如“悼亡”“田园”“禅理”——只需伪造目录与相邻三首诗），发给三位读者各得一句“它写的是”；统计：**相邻文本把解释拉向哪边、有没有人顶住目录**。
::: solution
判分：**目录与相邻项是“互文语境”的实验装置**（第 4 章书架即解释的实证化）；顶住者用的证据须登记（**多数人会引用不存在的细节——“记忆补写”是施工队上班的直接录像**）；结论禁止写“说明读者水平不同”，必须写**机制**（“相邻项提供了缺失的惯例钥匙”）。
:::
:::

::: exercise 报表分栏 {level=2}
就《红楼梦》“后四十回问题”写 200 字短评，**强制分三栏**：作者意图栏（程高、“后四十回为续/为残”的证据现状）、作品结构栏（“林黛玉死”作为结局的结构效果，不问原作者是谁）、效果史栏（高鹗本如何塑造了“红楼梦”这个国民文本）。**每栏末尾自评：本栏在回答什么问题。**
::: solution
判分：**三栏不得互串**（最常见违规：在结构栏论证“曹雪芹不会这么写”——**传记证据越狱**）；**效果史栏须承认“我们爱的就是这一个文本”与“校勘学另有一个文本”并行不悖（“作品与版本：一个审美对象，两个文献对象”）**；自评栏写出“意图≠成就≠后果”的应用痕迹即满分。
:::
:::

::: exercise 小论文：读者是新的僭主吗 {level=3}
写六百至一千字，评“**二十世纪的读者解放运动，最后签下的是一张空白支票：签发人与兑付人都是读者，于是'过度阐释'成了唯一的拒付理由——而'过度'的鉴定书，还是读者开的**”。须调用：**三派坐标**、**隐含读者／解释性群体**、**视域融合与时间距离**、**强误读**、**“六经注我”案卷**至少五项；并裁决：**“推荐算法把期待视野制度化了”是否使“误读的责任”从读者转移到平台**。
::: solution
判分点：五项机制（**坐标＝终审权之争；施工位与群体＝读者的双重编制；时间距离＝筛选型误读；强误读＝创造的别名；六经注我＝主权宣言的本土版**）；空白支票的回应（**参考：拒付凭证并非没有——文本抵抗（艾柯）、共同体共识（费什自制的刹车）、以及最硬的一条：误读的产出是否比原文提供更多可检验的联结（“过度”的操作定义＝为保住结论而新增的假设成本；这是经济学式的限度论——不完美，但可审计**））；算法裁决（**转移部分成立：画像把“时间距离的筛选”换成“即时反馈的强化”，读者失去了伽达默尔意义上的意外——参考判词：'平台不制造误读，它只是取消了被纠正的权利'——责任的剩余部分仍在读者：能被推荐喂养也能被一句诗饿醒**）；结论若写“**读者的王冠不是加冕来的，是接生的：文本在生产线上缺的那双手——但只要它还缺，读者就永远既是主权者又是雇工：这是阐释学最好的消息**”，即 A。
:::

::: summary
三庭闭庭归档：作者席（**含义／意义分账——死的是终审权不是作证权**）、读者席（**施工位清单＋解读制度：误读是不同规章的正常产出**）、误读席（**经典是抢劫来的遗产；六经注我与故训链条互相续命**）、三张表（**意图≠成就≠后果：填对栏比答对题更基础**）。方法一句话：**先问哪张报表，再问对错；先查谁授权，再喊我以为**。下一章压轴：现代诸流派——把本章的法庭开成一百年来的连锁法院。
:::
