前几章的作品躺在纸上，本章的作品**当着一群人的面活一次，然后销毁**——叙事与抒情在这里合流，还多请了一位证人：**观众**。理论问题随之变形：**为什么我们明知是假的，还哭？为什么“一个人假装是另一个人”是文明而非欺诈？**

## 定义：双层合同 {#def-hetong}

::: definition 假装是另一个人，在另一个人面前 {#def-zuixiao}
戏剧的最小定义：**一个人在另一个人面前假装是另一个人**——四个要素缺一不可（演员、观众、假装、当场）。由此产生的**双层合同**：**观众同时持有两张票——“这是假的”（散场就退）与“这是真的”（鼓掌就算）**；亚里士多德的“卡塔西斯”（怜悯与恐惧的**净化**）在合同层的意思：**剧场是安全的情绪压力舱：眼泪在这里按小时计薪，且自愿加班**。**与叙事、抒情的分工**：小说可以写九十年（普鲁斯特），诗可以只有一声（“啊”），戏剧**只能演现在进行**——**一切过去都必须改写成当下的冲突（“前史”在戏剧里是违禁存货，只能以“透露”的方式分期走私：信使报告、鬼魂自述、奶妈回忆——《哈姆雷特》的鬼魂是一台非法的闪回机器）**。**在场即税制**：戏剧为“此刻”缴纳一切结构税——三一律不是暴政，是税法的极端版（见下节）。
:::

## 情节动力学 {#def-qingjie}

::: definition 突转、发现与行动的语法 {#def-tuzhuan}
《诗学》的建厂图纸：**情节是灵魂，行动是模仿的对象（人“行动”才悲喜，性格只是口味）**——**西方叙事学的第一课就把“写了什么人”踩在脚下：“发生了什么事、怎样连成必然”才是引擎**。两件王牌工具：**突转**（peripeteia：**行动转向其反面**）与**发现**（anagnorisis：**从无知识到有知识**）——“**最好的情节二者同时发生**”，标本仍是《俄狄浦斯王》：**科林斯报信人登场是为了安慰（“你怕的杀父娶母命案，父母都不是你双亲”），一句话完成从最大恐惧到最大确证的转向——好消息是死刑判决书的拆封仪式；牧人被迫开口＝“发现”合龙——两千三百年后侦探小说的全部骨架在这出戏里领了出生证**。中国编剧的行话对应物：**“文似看山不喜平”**（**曲坡、倒插、横云断岭——悬念的技术名词比理论早，理论名词比技术晚：金圣叹的眉批就是没有亚里士多德参照系的《诗学》笔记**）；李渔的“**大收煞**”条款（**“必使此段之情，始终合一”：全本传奇的终点不是冲突的解决，是关系的结算——团圆=账清**）。
:::

::: definition 三一律：解释学事故的宪法化 {#def-sanyilv}
亚里士多德谈“动作整一”，意大利文艺复兴注家读出“**一个地点、二十四小时**”，经法语古典悲剧制度化——**戏剧理论史上最著名的一次“过度引申产卵”**：**1630 年代围绕高乃依《熙德》的论争中，刚成立的法兰西学院出面裁断（文学机构第一次以裁判身份公开判罚一部剧本——“批评”从此有了机关编制）**。三一律的辩护词是**可能性**：“**舞台上演两千年不似真，演两小时像真**”（高乃依《论三一律》的通说立场）——**“可信”与“真实”分家：这是第 2 章传感器与第 5 章聚焦的共同祖先：规则的对象从来不是现实，是观众**。中国戏台的反证优雅得多：**一更鼓就是三年，一个圆场就是千里——空间不签写实合同，时间按唱段计价（见下节）**。
:::

## 脚色、程式与合同的本土方案 {#def-chengshi}

::: definition 脸谱是预制的解读 {#def-juese}
**脚色制**（生旦净丑）＝**道德与性格的人肉索引**：一上场，眉法、髯口、台步已经自报善恶厚薄——**这是零聚焦的物化（上一章的“机位”穿戏服上台）；批评家称之为“类型”（type）而非“个体”（character）——但类型是效率：观众用三秒钟买好立场，把注意力省给情节的意外**。**虚拟与程式**（一台二椅、鞭代表马、桨代表船）＝**把茵加登的“未定点”做成公开制度**：**空间、时间、物体全部由观众按程式填资——戏曲从不假装是现实，因此从不担心穿帮**（**布景写实的戏剧相反：它把未定点买断，观众的施工队失业，想象力的税也就免了——两种文类，两种税负，两种快乐**）。**“科”与“科诨”**（插科打諢的丑行）＝**情绪压力舱的泄压阀：悲至十分，丑插一句——卡塔西斯的工程量控制：中国戏班比莱辛更早给眼泪装了保险丝**。
:::

::: example 《赵氏孤儿》与《俄狄浦斯王》对拆 {#ex-zhaoshi}
纪君祥《赵氏孤儿》（元杂剧）：屠岸贾灭赵氏，程婴以**亲生子换下赵氏孤儿**（**用自己的孩子冒充仇人的孩子送死**），忍辱事仇二十年，孤儿得知真相复仇。请：①指出其中的**突转与发现**各在何处（第几重？谁完成的？）；②与俄狄浦斯对表：**“知道”在两部戏里分别是什么方向的武器**；③王国维以“**列之于世界大悲剧中，亦无愧色也”**（《宋元戏曲史》）为据——**他的裁判标准是哪个版本的“悲剧”**；④王子版本问题：**元杂剧的“团圆”（复仇成功）与伏尔泰改编《中国孤儿》（1755，以感化收场）——同一故事两种结算，说明各自文类的什么条款**？
::: solution
①**发现**多重递进：孤儿的“身世发现”被铺成整场自述戏（画影图形、韩厥、程婴分段透露——**“发现”被拉成两千年的悬念长镜头：西方一幕完成的合龙，中国五折做成慢刑**）；**突转**在程婴“舍子”：**行动转向其反面＝保护孤儿的第一招是谋杀亲子——突转的道德当量超过俄狄浦斯（后者不知情，前者全知情：亚里士多德说最好的悲剧是“不知情”以避免道德恶心，此剧明知而为之——用现代话：它挑战的是“怜悯”的边界条件**）。②**“知道”的方向**：俄狄浦斯——**知道是毁灭（求真导致自我流放：知识的代价主题）**；赵氏孤儿——**知道是动员（身世一明即复仇——知识即义务：儒家伦理里“知道”不是认识论状态，是债务确认书）**。③王国维用的是**叔本华—黑格尔版的“悲剧”＋中国“怨愤”传统**的双重标准——**“无愧色”的句式本身是比价行为：比较文学的诞生现场（以欧洲范畴为中国作品争国籍——本章注记：范畴的进口税历来由弱者缴纳**）。④**复仇＝元杂剧的“收煞”结算（冤—申账目两清：团圆的会计性质）；伏尔泰把复仇改成宽恕感化——启蒙时代需要中国替他演示“理性战胜血仇”：同一素材在两种教化需求之间转厂（第 2 章兑换所的跨国分店）**。
:::

::: intuition 第三人：观众是必选项 {#int-guanzhong}
小说读者可以假装不存在，抒情诗可以无人接听，**戏剧的定义里必须有第三人**：**“我们在看”是剧本的一行隐藏台词**——所以政治审查历来先盯剧场（**演出是集合，台词是点火**），所以“第四堵墙”（19 世纪自然主义的理想：观众是偷窥者）其实是**史上最短命的合同**：从莎士比亚的独白直接向观众交底、到布莱希特的“**间离**”（**唱出来、停下来、说明——把“这是戏”重新塞回观众手里：双层合同里故意撕开上层，好让观众用另一半脑子算账**），**“墙”只是资产阶级客厅时代的一次短暂失忆**——**本章定律：剧场的注意力永远是三方合同：台上两人，台下一人，谁都不许装看不见第三个人**。
:::

::: history 剧场的账本 {#sec-zhangben}
**前 5 世纪** 雅典酒神节竞演（**悲剧是城邦的公共仪式：一城看戏，诉讼、公民誓约同场——戏剧研究的“制度第一原理”现场**）＋《诗学》解剖（**情节中心论开业**）；**汉—唐** 角抵、参军戏、踏摇娘（**滑稽戏与歌舞小戏：中国“戏剧”的多源汇流，长期不成“文学”正册——第 1 章制度说的标本：集部不收戏**）；**13—14 世纪** 元杂剧黄金期（**文人下海写勾栏：关汉卿“蒸不烂煮不熟”的〔不伏老〕——作者人格与角色人格的混装上市**）；**16—17 世纪** 明清传奇与《牡丹亭》（**“情不知所起，一往而深，生者可以死，死可以生”——汤显祖把抒情主体直接升格为宇宙原理：戏剧作为言“情”的法庭**）＋意大利即兴喜剧＋法国三一律法典化；**1670s—1760s** 伏尔泰改编《中国孤儿》、莱辛《汉堡剧表》（**市民悲剧＋批评期刊：民族戏剧规划期**）；**18—19 世纪** 佳构剧（well-made play，**“巧排结构之剧”：情境—秘密—递进—必有的解释：情节工业的 ISO 认证：易卜生从中毕业再造反**）；**1870s—1900s** 自然主义与“第四堵墙”（**易卜生、契诃夫：把客厅装上锁孔**）；**1920s** 表现主义、布莱希特史诗剧、阿尔托“残酷戏剧”（**语言让位：身体、声光、“形而上学的物理性”**）；**1950s—60s** 贝克特（**等待没有剧情可等：情节抽走之后，舞台上剩下的是等待本身——荒诞派是文类的自检程序：戏剧旁听自己的庭审**）；**1960s** 环境戏剧与“生活剧场”（**阿尔托的遗稿开奖：镜子拆除，观众被请上台**）；**今** 沉浸式与影视冲击（**在场成了稀缺品，票价回到“你也在场”四个字上——戏剧与电影的百年官司，判决写在疫情后重新亮灯的剧场里**）。
:::

::: warning 戏剧分析四坑
**拿小说标准骂戏剧**（**“对话太多没心理描写”——内心在戏剧里只能变成独白、动作或口误：媒介即可能性的清单（第 4 章施工规范）**）；**把“冲突律”当天条**（**黑格尔的冲突是近代民族国家的语法：《桃花扇》的结局不是解决是退出——“渔樵话兴亡”是冲突律的失效区，不是失败区：先问这个文类跟观众签的什么和解合同**）；**“脚色＝人物”论**（**把性格批评套在程式上：追问“窦娥的心理发展”是提着钓鱼竿去登山——类型演的是共相，程式是共相的制服**）；**“悲剧是中国没有的”**（**黑格尔式比较的旧伤：王国维“无愧色”是辩护，今天要做的是换尺子：从“命运/冲突”换到“冤/申”——中国悲剧的账本逻辑（第 2 章灯火条款的司法版）**）。
:::

::: exercise 前史走私 {level=1}
写一场 400 字独幕对话：**两个人吃顿饭，交代一件“十二年前发生的事”——不得直叙往事**，只许用“透露”手段（一句说漏、一个回避、一件旧物、一段跑调的歌）；互评：**你从哪个词推断出全案**。
::: solution
判分：**零直叙达标**（出现“当年……”即违规）；**物证/口误设计可推理**（读者还原度是得分表）；**“现在进行”的压强**（十二年前的事像桌下炸弹一样决定每个坐姿——**前史的水平看它泄漏的方式**）。
:::
:::

::: exercise 脸谱说明书 {level=2}
给一位当代公众人物或身边的“角色类型”（内卷同事、遛鸟大爷、带货主播）写一段**脚色定场诗＋三句自报**（借用脚色制逻辑：善恶厚薄先声明），然后**设计一个情节意外让类型破功**；说明：**观众的立场买卖在哪一秒被退款**。
::: solution
判分：定场诗的**索引性**（三秒买好立场——信息全在眉眼价目表）；破功点须**从类型内部长出**（不是外置事故：内卷同事的破功必须来自卷的逻辑极端化——类型与意外的焊接缝）；退款时刻定位（**“他原来是怕被抛下”——立场从道德判断改价为处境理解的那一行：这就是“发现”的日常版**）。
:::

::: exercise 小论文：剧场是文类的法庭 {level=3}
写六百至一千字，评“**小说可以撒谎，诗可以失语，戏剧必须当场：它是唯一接受观众陪审的文类**”。须调用：**双层合同**、**在场税制（前史走私）**、**突转/发现**、**程式=公开未定点**、**布莱希特撕合同**至少五项；并裁决：**影视（录播、可剪辑、无观众）是否终结了“戏剧性”——还是反过来，把双层合同卖到了全世界**。
::: solution
判分点：五项机制（**合同＝悬置是排场不是信仰；税制＝媒介即可能性的清单；王牌＝知识的武器化；程式＝想象的税负外包；间离＝把“假的”那张票亮出来算账**）；裁决（**两条参考：终结论——影视取消“当场”，演员不再知道观众在场，误镜不能重拍：不可逆性才是剧场的本体——流媒体倍速观剧是在把“现在进行”按快退键：戏剧性枯萎；迁移论——影院同样是黑暗中的集体在场，“观众”以票房、弹幕、评分延迟履行陪审义务：双层合同改签为异步合同——“这是假的”写在会员协议里，“这是真的”由眼泪按秒付费**）；结论若写“**司法也可以直播，但陪审团必须在场：戏剧性不是文类专利，是“当众”二字的利息——凡是当众，皆有戏剧**”，即 A。
:::

::: summary
剧场账本归档：合同（**两张票券：散场退假票，鼓掌算真票**）、情节（**行动是灵魂、突转与发现是王牌——“知道”可以是武器也可以是毒药**）、税制（**只能演现在进行：前史靠走私**）、程式（**公开的未定点：不装现实，故不穿帮**）、第三人（**台上两人台下一人：第四堵墙是最短命的合同**）。方法一句话：**先查观众的票上有几层，再查谁在台上装不知道第三个人**。下一章并表：文类与风格——体裁这只手，管得比你想的宽。
:::
