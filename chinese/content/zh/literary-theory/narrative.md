---
title: "叙事"
---

上一章把作品拆成楼层，本章回到运转中的那一层：**有人在对另一个人讲一件事**——这个看似透明的动作，是叙事学用一整个世纪拆开的黑话生产车间：**“谁在讲”与“谁在经历”不是一回事，“看”与“说”也不是一回事，而“讲了几次”本身就在表态**。

## 第一层：谁在讲 {#def-shuijiang}

::: definition 三个“人”只有一个在编字典 {#def-renge}
**作者**（传记实体，领工资的公民）≠**隐含作者**（布斯《小说修辞学》：**文本的守门人人格——“我自己的一个版本”：选择、排序、价值调定的总和**）≠**叙述者**（讲故事的声音，文本的雇员）。**三席分立是叙事学的第一定理**：第一人称叙述者不是作者（**否则全部自传体小说都是自供状**）；隐含作者没有名字、没有照片，只有**目录与脚注**（**它的证据全在文本的取舍里：写了什么不写什么，就是它的签名**）。**不可靠叙述者**＝布斯-麦尔逊的判例：**“说”与“事”之间裂开的缝由读者补贴**——当叙述者的判断与隐含作者的调定系统背离（**哈克说“下地狱我乐意”而文本判他得救——叙述者的道德盲区正是作品的道德刻度**），叙述就成了**双重记账**。中国古典自带公证人：**说书人的“看官听说”**（**公开承认的叙述人格：我不装透明，我认领我的立场——19 世纪欧洲小说的全知权威在宋元话本里早有同款工牌**）；以及“**春秋书法**”（**“赵盾弑其君”：史官以措辞定罪——零聚焦让位于褒贬：谁被点名、谁被省略、用“弑”还是“杀”，动词即判决书——叙事学的伦理学在公元前 5 世纪的中国已经开业**）。
:::

## 第二层：谁在看 {#def-shuikan}

::: definition 聚焦：摄影机是道德器官 {#def-jujiao}
热奈特的三分（记在镜头位上就够用）：**零聚焦**（叙述者知道得比任何人物多——**全知：上帝机位，19 世纪的标配**）；**内聚焦**（跟着某个人物的知觉走——**他不知道的我们也不知道；“房间里有什么”取决于他抬没抬眼——《红楼梦》刘姥姥进大观园：内部聚焦的经典外挂：借一个“不认识”的眼睛，让一切陈设自动标价（贾府的奢靡从此不用旁白——连板儿打鸣都成了行情）**）；**外聚焦**（只拍不透视——**海明威式硬汉摄影：行为清单，动机悬案——“他为什么不离开餐桌”成为现代小说的招牌问题**）。**“谁说”与“谁看”的分离是本区最赚钱的资产**：第一人称的“我”可以是讲述者，眼光却属于另一个“我”（**成年回忆童年即双镜头并置：“叙述我＞经验我——成长的格式塔就是两个我的视差”**）。**视角＝道德立场**的机制朴素得可怕：**用谁的动词写**——“他偷了面包／他顺手拿走／他饿到拿了”——**同一个动作三套法槌：叙事学的第一堂伦理课不在主题层，在词性层**。
:::

## 第三层：怎么摆 {#def-shijian}

::: definition 时距：时间的快门速度 {#def-shiju}
故事时间（h）与文本长度（T）的比值＝**速度**：**概述**（三十年一行字——**“林黛玉进贾府”之前先给“如去一年”级别快进**）、**场景**（对话与动作近似同速——**“一两句话一顿饭”：场景是时间的慢放**）、**停顿**（描写悬置故事——**风景与服饰的插播广告：叙事在这里呼吸**）、**省略**（对故事只字不提——**省略是作者承认自己决定不看的诚实记录**）、**总结与延展**（**“他想了很久”四个字覆盖一小时：长度不代表速度——速度是语法与词汇的把戏，不是字数统计**）。**核心用途：速度的分配＝价值的分配**——**小说把最慢的镜头给谁，就是在说谁最值得被经历**（托尔斯泰把安娜的最后一夜给了场景，把拿破仑的战役给了概述——**立场不靠形容词，靠快门**）。
:::

::: definition 频率：“一次又一次”的主题化 {#def-pinlü}
“他每周日去教堂”（**反复叙事**）与“他去了教堂”（**单次**）不等值——**频率是叙事的压缩协议，也是它的表态装置**：《左传》的“**初**”字（**追叙的开场锣：一个“初”登记一次回溯，把因果埋进伏笔的账本；篇末“遂为母子如初”再把频率折回原点——地道中赋诗的“初”与“如初”遥相呼应——一个副词完成闭环——叙事的伦理与叙事的语法在此同字**）；**反复叙事的现代用法＝把“别人如何议论”变成事件**（**“都说他疯了”三字的叙事学重量：没有事实，只有传播——谣言以频率身份入场**）。
:::

::: example 打虎的外聚焦改写 {#ex-wusong}
把“武松打虎”改写为**店家视角的外聚焦**：不许进入武松内心，不许出现虎的视角；只许用“听见、看见、官府告示、伙计的话、次日路过的血迹”。改写后回答：①英雄气如何被**转述**？②“三碗不过冈”的招牌在新版本里承担什么职能；③原作的哪些魅力**恰好依赖**内聚焦（哨棒折断那一瞬的“啊呀”是谁的）；④若再改成“官府公文”体，道德评价如何第三次翻转。
::: solution
①**转述让英雄降格为八卦、又升格为传说**：外聚焦取消信心展示——**读者与村民共享信息劣势：恐惧成为唯一的通行证（原作“明知山有虎”的主观勇气无处报销：零度的武松变成“那人不要命”的市井评书——视角即评价体系）**；②招牌＝**叙述者的预言机位**（店家之言＝内嵌的警告叙述——**“三碗不过冈”是民间对老虎的零聚焦统计：叙事里最经济的悬念发生器**）；③哨棒一节：原作魅力在**判断失误的内心现场**——**误击枯树的瞬间崩塌、那声没出口的“啊呀”是内聚焦独有资产；外聚焦只剩“棒折了”三个字的物证：所有惊险都是特权的知觉**）；④公文体的翻转：**“阳谷县景阳冈都头武松射虎有功，赏”——同一事件升为治安功绩：打虎从传奇变政绩：第四面镜头（制度）进场——叙事的每一次变焦，都是一次法庭的改组**。
:::
:::

::: intuition 叙述者是虚构缴纳的税 {#int-shui}
一个常被忽略的对称：**小说越“真实”，需要的叙述装置越复杂**（日记体、书信体、证词体、多声部口述史——**每种“我在场”都是新的修辞**）；“**第一人称＝真实**”的天真在 18 世纪被反复收割（笛福的“我”是编辑发现的稿子——**前言替小说交“真实性税”：虚构靠伪证获准存在，与上一章传奇“先假装有用才获准重要”同族**）。反向证据：**回忆录的“我”最不可靠却受合同保护（“非虚构”标签是出版法赋予的可信度补贴）**——**叙事学的清醒剂：人称只是镜头，可靠性是效果，真实是合同：三者常被一起出售，拆开单买才懂行情**。
:::

::: history 镜头的换代 {#sec-jingtou}
**前 5 世纪** 春秋书法——**措辞即审判的执照**；**汉** 《史记》**互见法**（**一个人的真相拆给多人分摊：列传各持一面镜：叙事的“全知”由拼图的不可见接缝支撑——本纪与列传的矛盾处就是史识的藏身处**）；**唐传奇** 叙述者露面（“**贞元中某公**”式公证语）；**宋元** 说话人“看官听说”——**叙述人格公开挂牌**；**明清** 章回与评点（**脂砚斋“草蛇灰线，伏脉千里”——中文原生叙事学：叙述信息的埋点管理手册：伏笔＝延迟支付，应伏＝兑付日：批评家先于理论家命名了“情节的逻辑”**）；**19 世纪** 全知权威鼎盛（平衡期：陀思妥耶夫斯基的复调已在其内部起爆——**巴赫金：“众多独立声音的小说”预告镜头民主化**）；**1900s—50s** 视角教条（**卢伯克《小说技巧》：“从哪里看”成为现代小说的宗教问题：亨利·詹姆斯的“中心意识”**）；**1960s—70s** 叙事学建制（托多罗夫命名、热奈特《叙事话语》语法表、里蒙-凯南教科书——**“语法派”把镜头换算成规则；随后“自然/人工”叙事之争、经典 vs 后经典（跨进认知、女性主义、伦理研究的领域）**）；**今** 影视与游戏接管实验（**POV 镜头、多周目叙事、旁白解构——叙事学从小说解剖室变成整个屏幕的市政条例**）。
:::

::: warning 叙事分析四坑
**把叙述者当作者传声筒**（**“鲁迅说‘我’认为”——第一人称不是自供状：三席分立是本章护照**）；**把聚焦当“观点”**（**内聚焦不是同情：跟着希特勒的眼睛看≠给他辩护——知觉位置与评价体系是两家银行**）；**“全知已死”的进步论**（**19 世纪小说不是没本事限制视角，是另一种契约：拉封丹式快进有其美学；把文学史讲成镜头升级史＝把风格讲成科技**）；**用术语代替观察**（**满纸“叙述者/聚焦化/次叙述”而不指出任何一个具体动词的效果——热奈特是梯子，不是风景；本章验收线：每个术语必须兑换一次镜头描述**）。
:::

::: exercise 动词法庭 {level=1}
以“他迟到了”为事件，写三个版本：老师聚焦／母亲聚焦／本人内聚焦；**每版恰一句，禁用心理形容词，只许动词与副词**；互评哪一版“定罪最重”、动词如何办到。
::: solution
判分：**三版聚焦不混（老师版只见门，母亲版只见饭，本人版只听见心跳）**；**动词举证**（“闯进来／还知道回来／卡在门口”——**评价全部藏在及物性里**）；定罪判定能用术语（外聚焦的重 vs 内聚焦的轻——**同情来自进得去，重判来自看得见进不去**）。
:::
:::

::: exercise 快门图 {level=2}
选一章小说，**做“时间密度心电图”**：分段登记故事时间跨度与文本字数，画折线；找出全章**最慢**与**最快**的两处，各用一句话说明“**镜头为什么在此停下/跳过**”。
::: solution
判分：**登记数据真实**（不许估算关键段）；**最慢处常是价值现场**（一顿饭、一次抬头；**停顿处插播的描写往往是阶层与性别的陈列柜**）；**最快处常是叙述者的羞处或算盘**（概述里藏立场：**“她嫁了人”五个字处理掉的一生——速度即冷漠，冷漠即判决**）。
:::
:::

::: exercise 小论文：视角即道德 {level=3}
写六百至一千字，评“**小说不教人什么是对，它只强迫人练习用谁的感官活一遍：这是它比伦理学教科书更慢、也更深的教育方式**”。须调用：**三席分立**、**不可靠叙述**、**聚焦≠同情**、**快门分配价值**、**草蛇灰线（延迟支付）**至少五项；并裁决：**第二人称叙事（“你走进酒吧”）是视角的突破还是修辞的花招**——提示：查“你”被谁指派、能否被拒绝。
::: solution
判分点：五项机制（**三席＝道德责任的分账制；不可靠＝读者被迫当法官：叙事伦理的原型现场；聚焦≠同情＝知觉银行与评价银行分账；快门＝注意力分配的宪法；伏笔＝信任契约：延迟支付考验双方信用**）；第二人称裁决（**两条参考：突破论——“你”把读者拉上证人席：人称即传票，阅读的默认旁观被撤销（卡尔维诺《如果在冬夜，一个旅人》把“你”写成阅读者本人：视角问题升格为存在合同）；花招论——“你”随时可被还原为“我”或“他”的僭主（**“你”没有自己的知觉器官：它借读者的身体：这是强制移民不是新大陆**）；判分在是否指出“你”的可拒绝性——**读者可以说“我不是你”：一次成功的第二人称小说=让人拒绝不掉的“你”**）；结论若写“**伦理学告诉你站在哪边；小说让你换一次鞋：换过鞋的人未必更善良，但再也无法假装只有一个走法**”，即 A。
:::

::: summary
三岗归档：谁讲（**三席分立＋不可靠的双重记账＋看官听说的工牌**）、谁看（**三种机位＋动词即法槌：知觉银行与评价银行分账**）、怎么摆（**快门分配价值：最慢的镜头给最值得被经历的；频率把“一次又一次”主题化**、春秋书法（**公元前 5 世纪就有人用措辞开庭**）。方法一句话：**先找镜头，再找法槌**。下一章换协议：抒情——当没人讲故事，谁在说话。
:::
