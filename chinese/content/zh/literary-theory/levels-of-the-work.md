title: "文学作品的层次"
---

作者谢幕（上一章刚送走），社会退场（镜子进了博物馆），舞台中央只剩**作品本身**——本章要把这个“只剩”拆开看：**作品是一层还是多层？它是纸上的油墨、脑中的意义，还是一个需要每次重新演出的总谱？**

## 第一战场：内容与形式 {#def-neiwai}

::: definition 橡皮泥神话与它的死法 {#def-xingshi}
朴素常识把作品想成**橡皮泥套餐**：内容（讲了什么）是先捏好的团，形式（怎么讲）是包装纸——**这套常识在 1915—1917 年遭到形式主义定点爆破**：什克洛夫斯基“**内容从来不是别的，正是形式的负担**”（《作为手法的艺术》的著名判词）——**同一团“内容”换一只盒子就是另一部作品：《少年维特》换成长篇通讯就什么都不是；“武松打虎”与“鲁提辖拳打镇关西”材料同质，文章全异**；鲍列夫式补刀更狠：**“艺术中不存在其他手段代替不了的内容”——内容＝你还没找到的形式**。中国线的验收句现成：**弗罗斯特的行业自评“诗就是在翻译中丢失的那种东西”——如果内容真是独立货柜，运输损耗应当为零；**有损耗＝包装就是货物本身**。**但爆破组也别全胜**：小说的“写什么”（题材库）确有前文本的引力（上一章的传感器），**本课判词：内容与形式是一次性浇筑的合金，只有解剖时才锯开看断面——而锯开的断面不再是作品（下一章预告：叙事学就是拿放大镜看断面的人）**。
:::

## 第二战场：作品的楼层 {#def-cengci}

::: definition 茵加登的公寓剖面图 {#def-yinjiadeng}
罗曼·茵加登（现象学）把“一部作品”拆成**地层**：**①声音层**（语音、节奏、谐音——**律课与词课的平仄韵位全在这一层开工**）；**②意义单元层**（句意及其投影的“客体”）；**③图式化外观层**（作品只提供“从某些角度看”的说明——**“枯藤老树昏鸦”给了藤与树与鸦，没给颜色浓度与镜头距离**）；**④表现客体层**（被投射的世界，其“再现客体”可再分层）。**灵魂条款：图式化必然留下“未定点”（spots of indeterminacy）**——“**作品是一张图纸，施工由阅读完成：具体化＝读者把未定点填上，而每次施工都不完全相同**”。**定理：作品≠具体化**（《哈姆雷特》不是任何一次上演；**乐谱与演奏的关系：同一部作品容许无数次不等值的具体化而仍被认出——“它是可重复识别的型，不是物”**——它也不等于某一人的心理印象：一部作品能死、能被发现、能被误读，正因为它不是印象）。**副作用登记：未定点条款是接受美学的出生纸（第 9 章的主角在此挂牌）——文本填空，读者上班**。
:::

::: definition 中国预装配：言—象—意 {#def-yanyxi}
比茵加登早一千五百年，中国批评装好了一套三层公寓加**拆卸工具**：《周易·系辞》“**书不尽言，言不尽意**”——**表达主义的悲观条款：层层有损耗（弗罗斯特的损失在战前就有东方版本）**；庄子“**得鱼忘筌**”接上王弼“**得意而忘象，得象而忘言**”——**三层结构自带单程电梯：意义到手，脚手架可拆（“忘”＝不执着于层，不等于层不存在）**；孟子“**以意逆志，是为得之**”——**读者拿自己的“意”去接作者之“志”：跨时代的对接协议**；加上汉人解《诗》的行规“**诗无达诂**”——**解释的多元不是事故，是制度设计**。对照记忆：**茵加登的“未定点”与“言不尽意”是同一枚硬币：一个说层与层之间有洞，一个说洞是常态——但中国方案不急着填洞（“不着一字，尽得风流”），现象学急着画洞的分布图：两种学术性格，一间房**。
:::

::: example 《静夜思》四层验收＋未定点清点 {#ex-jingye4}
“床前明月光，疑是地上霜。举头望明月，低头思故乡。”①按①—④层逐层报备（声音层请引用平仄课结论：无入声收尾、开口韵；意义层注意“疑是”的语法悬置）；②**列出至少五个未定点**（谁的床？什么朝代？为何举头？“故乡”里有什么？）；③裁决：**未定点是缺陷还是承重墙**——把五处分别填实试一次（写成 50 字说明文），报告损失清单；④此诗千人背得、无人背错，可它的“具体化”明明人人不同——**用“作品≠具体化”定理解释：什么没变，什么在变**。
::: solution
①声音层（27 音素的齐言＋ou/ang 的长元音韵：低音量长鸣——**没有入声刹车：整夜都是拖长的失眠**）；意义层（“疑是”悬置判断——**主体第一次在诗里显得不确定，而这正是它的普遍性来源**）；外观层（无远近、无季节温度、无家具）；客体层（一个无传记的“人”在无年代的空间里）。②未定点清点：**床（坐具？卧具？井栏？——千年考据恰是“施工纠纷”的完美标本：考据=试图以工程裁决艺术）、霜的实虚、月与人的年龄、故乡里的人与物、为何无眠**。③填实即**凶案还原**：每个确定答案谋杀其余读法——**未定点承重：这首诗的结构强度与它的模糊度成正比（“床”的考据热恰证明大众不肯让墙被官方图纸独占）**。④没变的：**图式骨架（四层结构与未定点的分布——乐谱）**；在变的：**每次施工的填充物（每个读者的床、年龄、不眠的原因——演奏）**；**“无人背错”＝乐谱稳定，“人人不同读”＝演奏不等值：作品的永存方式恰是“同一张图纸，无限工程”**。
:::
:::

::: intuition 把两头都切掉的实验 {#int-jiezhi}
新批评的处方最激进：**意图谬误**（拿作者自述当裁决＝诉诸法庭外证据）＋**影响谬误**（拿读者感动当裁决＝测心电图当文学奖）——**两头切除，只留“公共文本”：一部为细读而生的自治机器（悖论工厂：含混、反讽、张力、悖论——布鲁克斯判诗的唯一合语法句式是“拟态肯定”）**。**实验的战果**：现代大学诗歌课堂的全部操作术语（“看这首诗**自己**怎么运转”）都是它分红；**后遗症**：作品被供成**礼拜对象**——历史、政治、性别、市场全部请出门外，“这首诗关于什么”退化为单选题（“中心思想”产业的远祖登记在此）。**本课立场：本体论批评是极好的车间、极差的宪法——把文本当对象（object）研究，不妨碍同时把它当工具（tool）使用：车间与宪法分开写，学科就不打架**。
:::

::: history 楼层产权过户史 {#sec-guohu}
**前 5 世纪—3 世纪** 言意之辨备料（《易传》《庄子》《孟子》——**经学时代顺手写完的本体论**）；**220s** 王弼注《易》——**忘言忘象定型：三层公寓发产权证**；**11—12 世纪** 邵雍“以物观物”、江西派“**以意逆志**”的日常化——**读者侧条款开始积累判例**；**18—19 世纪** 德国唯心论把作品升格为“有机体”（歌德—施莱格尔—黑格尔：**“内容形式不可分”的浪漫版：艺术品是植物不是机器——本课提醒：有机体隐喻是后世新批评的本体论胎盘**）；**1926—1931** 茵加登《文学文学作品》、伽达默尔前史——**层次论上市**；**1946—1948** 维姆萨特、比尔兹利双谬误发文；**1948** 韦勒克、沃伦《文学理论》——**“外部/内部”分区图成为比较文学与系科的地图投影（“内部”＝层次、文体、意象、神话——从此课本有了目录）**；**1960s—70s** 接受美学反击（姚斯的“效果史”、伊瑟尔的“隐含读者”——**未定点条款独立建国：从“作品有什么”改问“作品做什么”）**；**1980s—** 语境反扑（“文本”重并入“实践”：书籍史、制度批评）；**今**：**课堂仍住在新批评的房子里（“回到文本”是默认地址），论文多在社会学的楼上——本章的楼层图就是学科的平面图：你住在哪层，就在哪层交租**。
:::

::: warning 层次论四坑
**“主要内容＋艺术特色”两段式**（**中心思想产业的现行税制：把合金锯开当两件商品卖——本课判决：任何“特色”清单若回答不了“去掉它内容会怎样”，即无效**）；**把未定点读成空白支票**（**“一切读法都平等”是未定点的通货膨胀：洞的分布由图纸指定——床的位置可以吵，诗的字数没人改——**施工自由≠拆迁自由**）；**用层次当宪法**（**新批评的车间规矩拿到社会上立法就会出事：它分不清“这首诗如何运转”与“这首诗应当如何被管”**）；**忘言变废言**（**“得意忘言”的流行误用＝不读文本直接提炼鸡汤：王弼的电梯是单程的，但你得先上电梯——忘是第二跳，不是免票**）。
:::

::: exercise 承重墙审计 {level=1}
选一首短诗开头两句，列出全部未定点并分类：**承重墙（填实即塌）／软装（填实无损）／违建（你的想象加戏）**；据分布判决此诗“图纸风格”（细图／草图／抽象画）。
::: solution
判分：**三类各≥1 且有理由**（“谁在说话”常承重，“季节”可软装，“作者当晚心情”多半违建）；**判决用图纸语言**（草图派＝唐诗边塞的月照何处型，细图派＝宋诗注中自带小序型）；附加：**举一处“考据想裁决的未定点”**（“春风不度玉门关”的玉门关实测坐标之争——**考据是艺术纠纷的工程化解法，注定败诉**）。
:::
:::

::: exercise 两次施工对比 {level=2}
选一部作品的两种具体化（《红楼梦》越剧改编 vs 1987 电视剧；或《静夜思》两种英译），**指出对方填了哪些你方留空的洞**，并定位“原作”在比较中的存在方式。
::: solution
判分：**以未定点为记账单位**（比“忠实”精确：越剧把宝黛填成戏曲行当、87 版填成清代服饰考据——**两次施工图纸相同、建材相异**）；**“原作”＝迫使两次施工都算数的那张图纸：它不在任何一次施工里，但它验收**；能识别“**施工队自带规范**”（剧种程式、电视剧时长——**媒介即施工规范，改编研究的本体论地基**）者满分。
:::

::: exercise 小论文：中心是一整块肉，还是一把空椅 {level=3}
写六百至一千字，评“**作品的‘中心’不是藏在楼里的宝贝，而是让所有房间连成楼的那根看不见的柱：它不占空间，却决定空间**”。须调用：**橡皮泥之死**、**未定点／具体化**、**言象意与忘言**、**双谬误与文本自治**、**乐谱与演奏**至少五项；并裁决：**“作者之死”（下一章主角）与“作品之死”（内容—形式合金论）是同一场谋杀吗**——若不，凶手分别是谁、遗产归谁。
::: solution
判分点：柱的定义（**中心＝使未定点分布可理解的原理：它自身不在楼层中，正如地基不占房间——“不着一字尽得风流”是柱的诗学显形**）；五项到位（**合金论＝拆宝贝；具体化＝空椅每次坐不同的人；忘言＝柱不可言说≠柱不存在；自治＝把柱封为唯一居民是过度立法；乐谱＝柱是可重复识别性**）；两死裁决（**参考：不是同一场——作者之死由读者继承（解释权的转移），作品之死（作为独立内容盒的死亡）由文本继承（形式总账）；真正的同一场是 1960s：当作品再被宣布为事件而非对象，两笔遗产又并回读者手中——**死亡顺序即学科史年表**）；结论若写“**空椅不是没有王，是王不在场时朝廷仍能运转：文学理论的进步，就是把‘陛下’读成制度的名字**”，即 A。
:::

::: summary
平面图归档：合金（**内容与形式一次性浇筑：锯开看断面是解剖，不是生活**）、公寓（**四层＋未定点：图纸与施工的辩证法——文本填空，读者上班**）、预装（**言象意加单程电梯：不执着于层≠层不存在**）、切除（**双谬误造出自治机器：极好的车间、极差的宪法**）。方法一句话：**问它在几层运转，再问它让谁来上班**。下一章解剖三种运转协议之一：叙事——谁在讲，讲给谁听。
