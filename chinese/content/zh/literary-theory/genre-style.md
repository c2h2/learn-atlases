---
title: "文类与风格"
---

前两章拆了叙事、抒情、戏剧三种运转协议，本章站到高处看**协议本身从哪来、为什么换**——并追问那个最玄的词：**风格，一个人怎么能“像他自己”？以及，我们凭什么认出这种“像”？**

## 定义一：文类是分发格式 {#def-wenlei}

::: definition 先有格式，后有文件 {#def-geshi}
朴素观把文类当**货架**（诗一区、小说一区，新书上架各归各位）；理论观把文类当**协议**：**期待的法典（读者进场时戴的隐形眼镜：读传奇信其奇、读讽刺信其刻薄、读田园信其“真”）＋写作的作业指南（出题即出约束：选“挽歌”就不能让死者复活）**。三条硬论据：**①创新只能被文类识别**（“**每首诗都对既有文类作出姿态：继承、篡改或伪装的遗忘——‘史无前例’的说法本身要登记在某个文类的花名册上：无前例＝最高级别的引用**”）；**②文类先于单篇存在**（先有“咏史”这个位置，才有《赤壁》在那位置上的发言——**咏史诗的义务是借古，杜牧偏要翻案：翻案证明义务在收税**）；**③文类的死比作品彻底**（九歌不再生产、骈赋断供——**作品会失传，文类会失业；而失业的文类转世为修辞：赋变成“赋体”、乐府变成词题——第 4 章“约束迁移”的宏观版**）。**巴赫金的补条：“文类是集体记忆的语法”——**史诗造英雄、小说造市侩：体裁不记录人，体裁制造可被理解的人（“‘多余人’不是俄国的现象，是长篇小说＋贵族闲谈这一文类组合的产物”）。
:::

::: definition 体裁等级制是阶级制 {#def-dengji}
古典欧洲有条清晰的**体裁食物链**：史诗—悲剧居顶（庄重人物、庄重文体），喜剧—讽刺文—牧歌在下（低人物、混合文体）——亚里士多德“模仿的对象比我们好/比我们差”已经写好了票价。这条链在 **1750s 前后被“流泪剧”（市民悲剧）拦腰斩断**：**资产者登上悲剧舞台，前提是道德词汇的换代：不再靠出身配得上悲剧，靠“敏感的心”（忧郁、善良、会哭）——哭成了新的贵族血统**。**判决：文体等级制的废除不是审美进步，是兑换所扩股（第 2 章布迪厄的分期）——“谁能哭、谁该死、谁有资格被同情”每一次改动都是一次阶级审计**。中国线的对照同样硬：**诗—文—词—曲—小说的正统排序（集部与“诗余”“词余”的称呼就是税单）**，而小说的逆袭路径与“流泪剧”同构：**明清评点家先证明小说“有用于世”（“稗官”“羽翼正史”——**先交免税申请，再领王冠**），《红楼梦》直接从“稗官”坐到“开天辟地，从未有之书”**（脂评语）。
:::

## 定义二：风格是系统性偏差 {#def-fengge}

::: definition 选择函数的指纹 {#def-zhiwen}
风格的操作定义：**在给定文类允许的自由余地里，一个作者的系统性选择偏好——风格＝选择函数的指纹**（不是“文笔好”的奖状，是**可统计的偏差**：意象库存（李白的月、杜甫的秋、李商隐的屏与灯）、句法偏好（“韩潮苏海”＝两种水文报告：一个滔滔灌注、一个浩浩平蓄——**比喻先把风格自然化，再用山水认领它——这正是本章要拆的修辞**）、虚词与称谓（杜甫好以“且、更、偏、祇”调度语气——**虚词是风格的微表情**）。**“风格即人”（布丰 1753：风格即人本身——法国学术院的就职便利贴，从此成了作文讲评的万年招牌）** 的三重麻烦：**①元好问早就开枪：“心画心声总失真，文章宁复见为人”——**他否定的不是指纹的存在，是指纹与灵魂的必然联系：伪作产业证明风格可仿、人格可演**；②科学的逆淘汰（论文要求无风格——**“越像谁越值钱，越不像谁越正确”：文学与科学在风格税上是两个税率区**）；③仿冒检验（**“黄河之水天上来”伪一句即穿帮：穿帮率才是风格的度量衡——风格不是“写得好”，是“不可替换地是这个”**）。**风格的另一半属于系统**：“时代风格”“民族风格”这些大词的正确用法不是形容词堆（“盛唐气象”），而是**共享约束的统计结果：同一套科举训练＋同一本韵书＋同一种行卷市场＝唐诗；这不是民族性，是制度性（第 2 章：镜子的镀法）。
:::

::: definition 中国风格学：从体质到品位图鉴 {#def-tili}
**曹丕《典论·论文》“文以气为主，气之清浊有体，不可力强而能”**——**风格理论的体质学开局：才性禀赋决定文风，父子兄弟不同（“徐干时有齐气”“应瑒和而不壮”——批注式风格学的开山：四字一顿，人人身故后领一份性格快递单）**；刘勰《体性》升级为**类型学**（“**若总其归途，则数穷八体**”：典雅、远奥、精约、显附、繁缛、壮丽、新奇、轻靡——**“八体”不判优劣只判门派：与欧洲体裁等级制的关键差异：中国分“体”不论阶级，只论“习”（“才有天资，学慎始习”——风格可训）**）；司空图《二十四诗品》再升级为**品味图鉴**（二十四种人格化境界：**“采采流水，蓬蓬远春”**（纤秾）一类，**以景喻风**——中国风格学拒绝定义只肯示范：**不告诉你“壮美是什么”，直接带你看二十四场风景**）。**“神韵”“性灵”“格调”三连（明清）**：**王士禛的“神韵”是“无风格之风格”的建构典范——不着一字、风致羚羊——把缺席风格化为最高风格（第 10 章“反理论的理论”预发**）；袁枚“性灵”反击（**“诗写性情，惟吾所适”——把风格从门派存款改充个人现金**）；而桐城义法把风格做成**课程大纲**（“**因文见道**”＋阳刚阴柔二品——**风格学最后一次帝国编制**）。
:::

::: example 仿作穿帮检测 {#ex-fangzuo}
甲：“**举头望明月，低头思故乡。**”乙（集句体仿作）：“**举头望月久，低头思乡频。**”——①从**对仗类型**（流水对 vs 工对）、**词的重力分布**（“明月/故乡”的整词重量 vs “月久/乡频”的拆解）、**声调展开**（“明月”的收束感与“乡频”的细碎感）三个方向出具穿帮报告；②补一条**制度证据**（“望月”“思乡”在唐前的成句状态——**伪作的破绽常不在它写了什么，在它抄了什么而不自知**）；③推广为**辨伪流程**：给“疑似席慕蓉/仓央嘉措”网络诗一条，列出你的四步检测（意象库存、句法偏好、词汇时代、标点习惯）。
::: solution
①**对仗**：甲是**假性对仗＋流水语法**（“举头/低头”动作连贯，像一次抬头又低头的完整事件：**对仗在外套，散句在内脏——“看似对实为流水”是绝句尾联的收束专利**）；乙把两个动词短语焊成**对称账目**（“久/频”＝时长与频度的统计对：**工对了，也就死了——事件对成了报表行**）；②**词重力**：“明月”“故乡”是**双音整词**，落地有回声；“月久”“乡频”为凑对**拆词**（唐诗“明月”成词，罕以“月久”对“乡频”——**拆词是仿作者最常见的车辙：他要名词，就不要复合词**）；③**声调**：“乡频”两字皆轻（平声细音），收得像耳语；“故乡”去声入韵（“乡”本平，但“故”的领起加重），**收得像关门**（**绝句要门要关，不要呵气**）；④**制度证据**：乙句是“**成句的成句**”——“举头/低头”“思乡/望月”全是现成模块的二次组装：**真唐诗用模块时必有一处不可归因（“疑是地上霜”的“疑是”）：仿作全程可归因——伪作的指纹就是太整齐（本章最锋利的一句：意外性是原创的签名，无懈可击是赝品的病名）**）。
:::
:::

::: intuition 统计能走多远 {#int-tongji}
文体统计学（stylometry）的真实战绩：**作者归属案（《联邦党人文集》麦迪逊/汉密尔顿的虚词频率裁决）、伪作侦破、莎士比亚的分稿分析——它擅长“是谁”，一窍不通“好不好”**（**把“好不好”交给统计，等于把食堂的饭菜质量交给打饭速度——测量没有错，越界才是**）。**风格的研究对象是偏好，不是水平：频率告诉你李白“用”什么，沉默告诉你他“不用”什么——“不用清单”往往更接近人格：杜甫不写闺阁的艳，李白不写耕织的细——禁区即性格**（**统计是风格学的镜子；而本章第 2 章早写了：镜子的问题从来不是照不出，是照不出它自己不照的东西**）。
:::

::: history 货架与指纹的双史 {#sec-shuangshi}
**前 4 世纪** 亚里士多德三分（媒介/对象/方式——**文类学的第一张货架图纸，票价制度同步写入**）；**3—6 世纪** 中国独立开业（曹丕“气”→挚虞“文章体”之目→刘勰八体、《文心·定势》“**文因情变，势随体成**”——**“势”＝文类的物理：水之归泽——风格学与文类学在中国同一条流水线上**）；**12 世纪** 遍注《诗品》的品第传统（**第 10 章主角预告**）；**17—18 世纪** 欧洲体裁等级制松动（**流泪剧、市民悲剧、小说起标——“感伤”作为新货币**）；**1798—1830s** 浪漫派重铸文类观（**施莱格尔的“成长的诗”：浪漫诗拒绝被任何理论穷尽——浪漫派把文类从法典改成胚胎：体裁成了进行中的实验而非既定的分区**）；**1857** 泰纳种族—环境—时代（**风格的社会决定论成文法**）；**1919** 什克洛夫斯基“**作为手法的艺术”**——**文学史＝手法与文类的更替动力学（老手法变自动，新手法上位——“创新”第一次有了机制而非神启**）；**1950s—60s** 接受美学文类修订（姚斯：期待视野；托多洛夫与热奈特：结构主义诗学——**文类语法派的顶峰**）；**1970s** 福柯话语、女性主义“身体写作”（**“谁被允许拥有风格”重新开庭：文学史对女作家的风格命名常是性别化的——“女性气质”是风格还是天花板**）；**1980s—90s** 历史诗学与认知转向（**文类从法典改为“生活形式”（维特根斯坦的入场）**）；**今** **风格大循环：AI 可仿“李白体”，风格的市场价值从“像谁”转移到“为何偏选这个”——指纹可以复刻，选择动机不能外包（下一章见：轮到读者出价）**。
:::

::: warning 文类风格四坑
**用“风格”代替分析**（**“语言清新自然”是一句零信息赞美——改写成可核查项：意象库存里有没有炊烟与鸡犬？句法是不是散句居首？——风格是证据的压缩包，不是分析的替身**）；**把文类当法律追诉**（**“这首诗不押韵还算诗吗”——文类是描述库不是法院：描述越界叫诬告；现代诗违约，违约也是合同关系的一种（沉默的谈判）**）；**“时代精神”万能贴**（**“魏晋的自觉”解释力≈0 到 100 波动——不检查制度载体（门第、选官、清谈场域）就请出时代精神，等于不查电表就怪老天**）；**辨伪迷信单一指标**（**“不用典就不是宋诗”——指纹会被多人共用：统计只给概率，孤证不定案——伪作学的第一个教训：真作家也会偶尔像假作家**）。
:::

::: exercise 小论文：AI 时代的作者指纹 {level=3}
写六百至一千字，评“**当机器能伪造一切指纹，风格才第一次现出它的原形：它不是笔迹，是签名——签名之所以有效，是因为签的人愿意为它负责**”。须调用：**选择函数**、**穿帮率**、**不用清单**、**文类=协议**、**“时代风格=制度统计”**至少五项；并裁决：**“李白体生成器”大量流通后，真李白的价值会上升还是下降**——提示：古董与真迹的价格机制。
::: solution
判分点：五项机制（**选择函数＝偏好的可统计性；穿帮率＝不可替换度的度量；不用清单＝禁区即人格；协议＝文类税单；制度统计＝“盛唐”的祛魅**）；裁决（**两条参考：上升论——仿品泛滥抬高清真与来源的价格：李白从“写得好”升格为“活过、忍过、选过”（**风格的稀缺性从审美项改为传记项：指纹越可复制，手越值钱**）；下降论——当“像李白”零成本，普通读者对李白体的感受力被通胀稀释：名作的光晕依赖稀缺分发（本雅明线）——真正的风险不是李白贬值，是读者的味觉被廉价样本定价**）；结论若写“**签名的价值来自责任链：写的人能负责，读的人才敢当真——AI 不欠任何人一个风格，这正是它写得再像也不算署名的原因**”，即 A。

::: summary
双史归档：货架（**文类＝协议：创新只能被文类识别；“无前例＝最高级别的引用”**）、阶级（**体裁食物链与它的革命：哭的新贵族血统；小说先交免税申请再领王冠**）、指纹（**风格＝选择函数：穿帮率是度量，禁区是人格；布丰的便利贴要分给元好问一半**）、体派（**从曹丕的体质学到二十四品的风景教学：中国分体不论阶级**）。方法一句话：**先查税单（文类），再查偏好的账（风格），最后查他不敢碰什么**。下一章轮到对面的人：阅读与阐释——读者上岗时间。
:::
