---
title: "文学是什么"
---

第一课先审自己用的词：**“文学”是什么**？这问题看似幼儿园水平，实际是文论两千五百年悬而未决的第一案——**因为每次开庭，连“文学”这个被告都换过人**。

## 被告的身份证 {#def-shenfenzheng}

::: definition 一个词的两次出生 {#def-liangci}
**中国户籍**：孔子门徒四科，“德行”“言语”“政事”**“文学”**（《论语·先进》）——**那时的“文学”＝文献学问，是能力证书不是文体**；此后千年，“文”的边界反复丈量：魏晋**文笔之辨**（有韵且声律镳铄者为“文”，无韵笔札者为“笔”——**中国人第一次给“纯文学”划生产区**）、《文选》不取老庄经史（萧统的**选本即定义**）、集部与“文以载道”拉锯（周敦颐“**文所以载道也**”——**车与货的比喻：文学的身份是承运人**）。**西洋户籍**：literature 早年也指**读写学问与文字记录**，直到十八九世纪才收窄成“想象的、创造性的写作”——**“文学”作为现代制度，年龄不过两百岁；我们却用它去登记两千年的户口（本词典故：用现代“文学”筛选《四库》，等于拿今天的职业名录去认领全体古人）**。两次出生共同揭示：**“文学”不是物的种类，是社会的分类作业——分类在变，作业永远在重做**。
:::

::: definition 候选定义与它们的死法 {#def-dingyi}
**①虚构说**（文学＝想象性虚构）——死于反例：《史记》算不算？《庄子》寓言呢？自传体与散文诗常年越狱；**②美感说**（文学＝美的语言）——死于丑的杰作（波德莱尔、鲁迅的冷）与顺口的美文；**③形式说**（俄国形式主义：**文学性＝语言对自身负责**——雅各布森：诗功能把语言“**投向信息本身**”；什克洛夫斯基：艺术＝**使之陌生**、“**使石头成其为石头**”——**这条最硬，硬在可操作：检验句子的“可替换性”（上一章的替换法在此转正为定义）**）；**④制度说**（伊格尔顿式的清算：**“文学”是我们给某些写作贴的价值标签——没有永恒的文学，只有“被作为文学阅读”的文本**）。**法庭现状**：①②④各管一段：**虚构说管小说、美感说管广告词、形式说管课堂、制度说管学术史**——**本课不宣判，只教四支温度计各自的工作原理**。
:::

::: example 同一行字的四种命运 {#ex-tongyi}
把“**床前明月光，疑是地上霜**”贴进四个地方：①唐诗选本；②盗窃案卷宗（嫌疑人供述“我当时看见地上有霜状物质”）；③某新诗习作《霜》（原样挪用）；④某大学“古代诗词默写”试卷（填空已给出上句）。问：**哪些情形里它是文学**？据①—④各选一说作答；最后回答：**它的“文学性”在纸面上，还是在阅读协议里**（本题允许推翻任一答案，条件是引用第 1 节证据）。
::: solution
参考判决：**选本＝制度说完美标本（它一直就是文学，因为一直被这么教）；卷宗＝文学性被**降权使用**（同一串字，被要求按指称读——**文学不是字的属性，是阅读合同条款：本合同是否要求“留意语言本身”**）；挪用＝**互文性案件：习作靠偷来的句子获得借来的文学光环——制度说顺手解释“为什么我们不叫它抄袭而叫它致敬”**；试卷＝**文学性的刑讯逼供：能默写证明不了被读懂**。收束：形式说在此露出边界——**“床前明月光”的可替换性检测其实分数不高（历代改字实验都失败，是因为它本来就浅？还是浅到透明才算好？——这是严羽讥“太白率而能古”的老案）**；**结论：四支温度计量出四个数，都真；单支读数都危险——本课程的全部诚实从此开始**。
:::
:::

::: intuition 家族相似：一个不定义的定义 {#int-jiazu}
维特根斯坦的药方：**“文学”也许根本没有共同本质，只有一张**相似性的网**——小说与戏剧共享虚构，戏剧与诗共享韵文，诗与日记共享第一人称，日记与史诗共享“真实”……**任何两项之间都连着线，但没有一根线穿过全场**。**这不是认输，是换问题：从“文学是什么”改问“它何时被当作文学”——**问句一软，全部冤案（报告文学、杂文、网络文体、AI 诗）当场改道**：它们不必证明“我是文学”，只需交代“**谁在什么场合、按什么合同读我**”。本课后续各章都在这份合同上施工：叙事合同、抒情合同、戏剧合同、阐释合同。
:::

::: history 定义史的六个路标 {#sec-lubiao}
**前 5 世纪** 文学＝学术（孔门四科）；**217** 曹丕“**经国之大业，不朽之盛事**”——**从能力升格为事业，还附赠不朽期权**；**501** 刘勰《文心雕龙》——**第一次给“文”画全家福（原道、征圣、宗经三篇把文学接到宇宙电源上）**；**1090s** 周敦颐“文以载道”——**承运人条款生效一千年**；**1800 前后** 欧洲“想象性文学”诞生（**同时发生的事：印刷市场、公共阅读、版权、民族语言课程——文学的出生证明上站着四个现代制度**）；**1917** 陌生化——**文学搬进实验室**；**1921** 周作人“**人的文学**”——**中国现代文学观念的落地：文学的定义权从选家转到“人”的定义**——**一句话把“载道”的货换成了“人”**；**2020s** **AI 写作冲击闸口：图灵测试通过者的投稿权成为新案情——定义史的惯例：每一次守门员的胜利，都以改行收场**。
:::

::: warning 定义四坑
**把现代“文学”倒灌古代**（**《文心雕龙》不是“文学理论”教科书，是“文”的治理手册——用今词裁剪古人，裁掉的全是自己看不懂的**）；**以定义代替分析**（**背下“文学＝语言的艺术”不等于会判任何一案——定义是收据，分析才是购物**）；**“文学应该有用”抢答**（**载道／审美／介入三派互殴两千年；先问“谁在要求它有用、用来干什么”——实用问题，不是本质问题**）；**用包含关系装价值判断**（**“网络文学算不算文学”吵的是资格，真正在吵的是阅读量与经费——分类学争论九成是资源学争论**）。
:::

::: exercise 身份鉴定委员会 {level=1}
委员会收到六份申请：①《滕王阁序》②某爆款网文前十章③讣告一则④产品说明书（押韵版）⑤鲁迅《野草》⑥聊天记录截图（网传“最虐对话”）。**各用一支温度计读数**（虚构／美感／形式／制度），并写一句判决书（每句≤20 字）。
::: solution
判分：**温度计不串线**（说明书用美感与形式读数会爆表、制度读数归零——**分裂读数本身即诊断**）；讣告＝**实用文的文学性寄生案例**（被截图转发即进入“被作为文学阅读”轨道——判决须点出**阅读合同的切换**）；聊天截图＝当代新案情：**“真实”退出证据链、情绪结构完成叙事——判它进还是进不了，考的就是你如何重写第四条候选定义**。
:::
:::

::: exercise 给“文学”写维基词条 {level=2}
写 150 字百科词条“文学”：**禁止使用“语言的艺术”“形象地反映现实”“表达思想感情”三句模板**；必须让虚构说、制度说各上岗一次；结尾一句“参见”指向本课程任一后续章。
::: solution
判分：**模板词清零**（三句在草稿纸出现即销毁）；**两说分工清晰**（“通常指虚构性写作的总称〔描述〕／其边界由教育、选本与奖项等制度维护〔解释〕”级）；“参见”选得刁（如“参见：叙事章——小说的定义为何最晚熟”）者加分——**词条是压缩，好词条是预告片**。
:::
:::

::: exercise 小论文：AI 能写文学吗 {level=3}
写六百至一千字，评“**AI 写诗之争的真正输赢不在机器，在人：它逼每个时代交出手里那份‘文学’合同的原件**”。须调用：**两次出生**、**四支温度计**、**家族相似（合同之问）**、**“人的文学”**至少四项；并裁决一道模拟题：**“如果 AI 作品被一千万人当作文学阅读，制度说是否被迫承认它是文学”——承认与不承认各怎么自洽**。
::: solution
判分点：历史论证（**文学制度从来不是铁板：版权、课本、奖项、选本四件套都可能扩容——承认 AI 不是逻辑障碍，是利益重组**）；温度计（**形式说最尴尬：AI 完美复刻“可替换性检测”的低分句；美感说最宽容；虚构说最省事；制度说最诚实也最无立场**）；人的文学（**1921 的“人”是人道内容＋主体资格双关——AI 案把它逼成单选题：文学的资格系于作者的“人”，还是读者的“人”**）；两难自洽（**承认派：读者合同论，一千万签字即生效——代价：定义从此彻底市场化；不承认派：作者意图论或“痛苦证书”论——代价：把《荷马史诗》等一船集体制作证的作品再次请下船**）；结论若能写“**每一轮新媒介都在问同一句话：文学的最低工资是什么——发工资的从来是阅读的人**”，即 A。
:::
:::

::: summary
第一案退庭备忘：户籍（**文学是分类作业，不是物的种类**）、四支温度计（**虚构管小说、美感管广告、形式管课堂、制度管学术——单支读数都危险**）、合同（**问“何时被作为文学读”，一切冤案改道**）、路标（**从能力到事业到承运人到“人”——货换了四次，车站还在**）。方法一句话：**遇到“××算不算文学”，先查谁在发工资**。下一章上秤：文学与社会——镜子说最风光也最委屈的一段历史。
:::
