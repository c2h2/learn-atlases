---
title: "创作过程"
---

前两章审了被告（文学）与原告（社会），本章传第三个证人：**作家本人**。麻烦在于这位证人的证词**全部出自回忆，而回忆是最会编故事的书记员**——创作理论因此是一门特殊的学科：**它的原始资料全是口供，没有一台监视器**。

## 证词一：灵感 {#def-lingan}

::: definition 磁石环与通塞之纪 {#def-ciyi}
**进口证词**：柏拉图《伊安篇》——诗人是**被诗神凭附**的狂人，磁石吸环，神—诗人—诵者—观众一串铁环，“**你并非凭技艺，而是凭神说讲这些**”——**灵感的外源说：创作者是通道不是源头**（这张收据的副作用：**作者的才能被注销，解释权上交给神——两千年后“作者之死”的祖产**）。**国产证词**：陆机《文赋》写灵感来了与走了：“**来不可遏，去不可止；藏则影去，舒则声寄**”（大意）——**中国文论第一篇创作现象学：不解释神从哪来，只描述通与塞的手感（“应感之会，通塞之纪，不可常居，理不可推”）**；刘勰《神思》补上操作手册：“**陶钧文思，贵在虚静；疏瀹五藏，澡雪精神**”＋“**思接千载”“视通万里**”——**虚静不是玄学，是干扰排除程序：灵感学的全部设备清单就两句：清空缓存（虚静）、放飞联想（神思）**。两份证词合读：**一个说“我说了不是我说的”，一个说“我知道它会走——留不住，但记得住它来的时候的样子”：前者是神学，后者是现象学——本课只收后者当教材，收前者当标本**。
:::

## 证词二：阶段表 {#def-jieduan}

::: definition 四阶段：回忆录的统计学 {#def-sijieduan}
普朗克在演讲里描述原子物理的诞生：长时间**准备**的焦虑→**沉思**的退场→旅馆窗边**顿悟**（“counter-arguments proved useless, a guiding idea came to me in a flash”大意）→**验证**的整理——科学史后来把这张表（准备—孵化—顿悟—验证）转授给一切创造心理学；**它的寿命与它的弱点同级：四阶段全部来自成功者的回忆录——失败者不提供样本，被拒绝的念头不写日记**（**幸存者偏差＋事后重构：顿悟叙事之所以性感，正因为它把三个月的模糊压缩成一帧画面：灵感的电影版**）。**文学版四阶段有它诚实的变体**：华兹华斯“**诗起源于平静中回忆起来的情感**”（《抒情歌谣集》序言——**四阶段被重写为“情绪—沉淀—回忆—组合”：顿悟换了名字，叫回忆；且明确拒绝现场即兴——浪漫派亲手给自己的酒神执照加了冷静章**）。
:::

::: definition 自动写作与它的失眠 {#def-zidong}
1924 年布勒东给酒神发制服：超现实主义宣言定义纯**心理自动主义**——“**思维的笔录，不受任何理性控制、外在于一切美学与道德**”——《磁场》们试验两人不睡觉轮写，试图**让手快过审查**。**实验结果**：产出可观的新奇，与不可持续的荒诞——**审查官比想像的忠诚：手一停，它就醒来；而新奇感在第三页集体到期（自动写作最终活成了“手法”：随机并置、梦境意象——一种可模仿的修辞，不是一条可运行的通道）**。**理论判词**：自动写作证伪了“取消审查即可直连富矿”，却坐实了另一半——**审查官（内心编辑）确实存在，且其音量可调**：**创作论的真问题从来不是‘有没有灵感’，是‘审查官音量旋钮在哪’——贾岛的推敲与布勒东的免睡，是同一颗旋钮的极限刻度**。
:::

## 证词三：手艺 {#def-shouyi}

::: definition 删、追、改 {#def-shanzhui}
**删（正确的词）**：福楼拜的书信福音——“**一个名词只有一个正确的词，一个动词只有一个正确的词，一个形容词只有一个独特的词：找不到它，你就得一直找**”（le mot juste 的通说）＋“**才华就是漫长的耐心**”——**灵感学的天敌：天才被改写为找词的体力**。曹雪芹“**批阅十载，增删五次**”（《红楼梦》第一回）——**同一条款的中国执行记录：十年与五次是删的账期**。**追（成竹的时差）**：苏轼记文同画竹——“**故画竹必先得成竹于胸中**，执笔熟视，乃见其所欲画者，**急起从之，振笔直遂，以追其所见，如兔起鹘落，少纵则逝矣**”——而**同一篇里苏轼自供失败**：“**心识其所以然，而不能至者，内外不一，心手不相应**”——**成竹论自带失败条款：胸中的完形追不上手的速度；“心手不相应”五个字是全部创作焦虑的合同原文**）。**改（选择的化石）**：“绿”字改稿案（春风又**绿**江南岸——到、过、入、满一路试错）——**炼字＝把替换法运行在创作现场：改稿痕迹是文学过程的唯一化石记录**（贾岛“**二句三年得，一吟双泪流**”与杜甫“**为人性僻耽佳句，语不惊人死不休**”——**苦吟派店招合订：灵感是会员制，不是义务教育**）。
:::

::: example 池塘生春草：一桩灵感案件的重审 {#ex-chuncao}
谢灵运“**池塘生春草**，园柳变鸣禽”——相传他自道此句“**此语有神助，非我语也**”（神助传说经《颜氏家训》等转引，脉络较复杂——**材料立场：本题只审“灵感归因”本身**）；另案：江淹“**才尽**”——传说他梦人索还五色笔——**“江郎才尽”的神话学**。请：①两案共用哪种**归因结构**（华兹华斯的“回忆”结构是否同款）；②用四阶段表给“池塘春草”补写它省略的前两阶段（它属于哪种准备期的产物）；③若你是谢灵运的经纪人，对外宣传“神助”、对内怎么训练。
::: solution
①**外部仓库归因**：灵感＝从“我之外”领取的货物（神／梦／笔）——**其功能是双保险：成功时免责（不是我说的是神说的＝同时抬高货物与压低竞争者），失败时免责（仓库没货，非战之罪）**；华兹华斯的“回忆”是同结构的**世俗版**：仓库从奥林匹斯搬进潜意识，钥匙从神授改成时间。②补写准备—孵化：谢灵运是**山水诗的流水线工人**（大量同题同格的观景—记账—成篇——“**孵化期建立在超额准备上：神助只眷顾高产者**”——统计学的浪漫主义：“非用心所至”翻译过来是“**不像是用心所至”＝自动化程度太高**”）。③经纪人与教练的双账本：**对外卖奇迹（灵感叙事＝品牌），对内练考勤（四阶段＝排班表）**——**创作工业的真实营业执照两页都是必需品：取消任何一页都会倒闭（只卖神助＝骗保；只讲考勤＝流水账）**。
:::
:::

::: intuition 黑箱与接口 {#int-heixiang}
创作心理学的诚实自我定位：**黑箱不可打开（内省报告互相矛盾，实验只能给 averages），但接口面板是标准化的**：虚静（注意力设置）、神思（联想模式）、迷狂（唤醒水平）、苦吟（编辑阈值）、顿悟（检索意外）、成竹（内塑与手追）——**六组概念是同一台机器在不同朝向上的铭牌：中国批评选了气象词汇，西方心理学选了控制论词汇，两边说的都是“审查官音量”“缓存容量”“检索时机”**（庖丁解牛提供终态描述：“**以神遇而不以目视，官知止而神欲行**”——**心手不相应的反面：技进乎道＝接口全部调平后的运行感——**注意它是事后的身体报告，不是事前可执行的操作手册：这是所有“境界描述”的通病，也是它不可替代的原因：黑箱不能打开，但运行指示灯是亮的**）。
:::

::: history 证词的排期 {#sec-paiqi}
**前 4 世纪** 磁石环——**神学执照**；**3 末** 陆机《文赋》——**通塞现象学开机**；**501** 《神思》篇——**接口术语定版（虚静／神思／情貌／辞令）**；**11 世纪** 欧阳修传“**诗穷而后工**”（梅尧臣语——**苦难作为准备期的强制融资：归因史的重要一页：把际遇写成燃料，替制度免单**）＋成竹论与心手之憾；**16 世纪** “**童心**”说（李贽《童心说》——**假人假言：创作障碍的社会命名：审查官被认出穿着礼教制服**）；**17 世纪** 蒲松龄《聊斋自志》自道“孤愤”——**才与愤的联合署名；18—19** 天才—想象—灵感升格为浪漫派国家宗教（康德“天才给艺术立法”——**“天才”概念在 18 世纪成为版权法的精神双胞胎——**天才论与版权法同时诞生是巧合吗**）；**1924** 自动写作——**审查官政变未遂**；**1945/1960s** 四阶段表进教科书、创造力心理学进实验室（吉尔福特“发散思维”——**顿悟被改写成可测的题目：智商测验化的灵感，销量大、解释少**）；**今**：**写作工坊（workshop）与 AI 副驾把“修改”制度化：创意写作学位＋人机协同时代——**“灵感”退居品牌部，“过程”接管生产部：创作理论的岗位说明书与它的研究对象实现了和解——都承认自己是流程管理**。
:::

::: warning 创作论四坑
**把灵感叙事当生产流程**（**“神助”“才尽”“一梦得句”全部是发行文案：本课读法——问文案替谁免责**）；**把“天才”当解释项**（**天才论解释不了任何一首诗，只解释为什么有人不学写诗：它是归因偷懒的尊称——康德是它最体面的辩护词，不是证据**）；**苦吟崇拜**（**“二句三年得”既是事实也是营销：慢不等于好；贾岛与李白同代且互不道歉——工时与质量的兑换率因作者而异，且不可跨行转账**）；**“方法可教，才华不可教”一句了断**（**创意写作学位的存在理由恰是：可教的虽不是源头，而是删的纪律、接口的调试、审稿人的耳朵——把不可教当围墙，是把博物馆开成健身房**）。
:::

::: exercise 灵感记账法 {level=1}
记录你一周内的三次“灵光”（任何创作场景），每次标四项：**前置任务／间隔时长／触发物／最终存活度**；月底统计：你的“神助”最可能藏在哪个工序后面。
::: solution
判分：**四项齐全**；**诚实样本**（不许事后美化触发物——**“洗澡时想到”多半是第七次重读草稿的伪装**）；合格结论形如“我的顿悟集中在间隔 2—3 天、且前置任务明确时——**我的神助有考勤记录**”。
:::
:::

::: exercise 给神助写免责条款 {level=2}
以谢灵运经纪人身份写 100 字对外宣传（必须用“神助”）＋100 字对内训练表（禁用“灵感”二字，只许出现工序动词）。互评：**两份文件互相拆台的地方在哪——它是否正是本章判决的“双账本”**。
::: solution
判分：宣传稿的**免责—抬价双功能齐全**；训练表的动词库（临摹、限时、删改、朗读、冷却、互审——**每词对应接口面板一块铭牌**）；拆台点定位准确（**宣传否认工序，工序否认神——否认工序是为了卖，否认神是为了省：两条都在控制风险——本章“双保险”的复述即及格**）。
:::

::: exercise 小论文：创造力是资源还是流程 {level=3}
写六百至一千字，评“**‘创造力’这个词是二十世纪发明的最大安慰剂：它把可练的流程重新命名为不可分的礼物，好让平庸显得天生**”。须调用：**磁石环（外源归因）**、**四阶段的幸存者偏差**、**审查官旋钮**、**“诗穷而后工”的融资叙事**、**天才与版权的同代出生**至少五项；并处理一个反方：**若创造力只是流程，为何同样训练只出一批人——流程论解释得开分布，解释不开峰值**。
::: solution
判分点：五项机制（**外源＝免责与抬价；阶段表＝回忆录统计学；旋钮＝可教部分的名字；穷而后工＝把际遇写成燃料替制度免单；天才论＝把市场稀缺性自然化**）；反方处理（**两条参考路线：①峰值＝流程×不可控变量的乘积——流程论不承诺人人同值，只承诺不可控项与可教项分账：把峰值归功“天赋”后停止研究，恰是安慰剂效应的本体；②“分布”本身是场论问题：同样的训练在不同兑换所（文坛位置、语言市场）兑换成不同产量——“只出一批人”里有一半是记账法的产物**）；结论若能写“**天才是一份排班表上没写出来的那栏名字：研究它不如去写排班表——但否认那栏存在，也纯属傲慢**”，即 A。
:::

::: summary
三证词归档：灵感（**磁石环 vs 通塞之纪：一个说“不是我”，一个说“我知道它会走”——本课收后者当教材，收前者当标本**）、阶段（**准备—孵化—顿悟—验证：幸存者回忆录＋浪漫派的改名手术**）、手艺（**删：十年五次；追：心手不相应；改：绿字化石——审查官音量是唯一实存的旋钮**）、黑箱（**六块铭牌一台机器；运行指示灯亮着，盖子打不开**）。方法一句话：**听到“神助”，就问它替谁免责**。上一章是社会的位置，下一章是作品的层次——解剖台上见。
:::
