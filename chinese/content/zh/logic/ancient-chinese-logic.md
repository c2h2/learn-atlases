title: "名与辩：中国古代逻辑"
---

结业的最后一章回到本国现场——**战国已经有过一套完整的论辩学：它的术语叫“名、辞、说、故”，它的教科书叫《墨经》，它的教授团队辩到了白马、坚白与飞矢不动。本章既不夸“我们早有”，也不笑“没成科学”：只把它当逻辑学的一份中文原件来读——顺便回答那道至今没交卷的题：这么像样的火种，为什么熄了**。

## 定义：名、辞、说、故 {#def-siceng}

::: definition 四层架构 {#def-jiagou}
**《小取》：“以名举实，以辞抒意，以说出故”**——**一门逻辑学的目录页就这一行：名＝词（举实：把对象从世界里拎出来）；辞＝命题（抒意：把判断装上真值的秤，第 3 章）；说＝论证（出故：把支持关系摆上账本，第 1 章）；故＝理由本身（《经上》：“**故，所得而后成也**”——**有了它事情才成立：墨家的“故”就是逻辑学的“前提”岗位，还分了“大故”（条件齐备必发生）与“小故”（有之不必然、无之必不然）——前者像充分条件、后者像必要条件：这两句白话定义与《前分析篇》的“必然性”分析几乎同代（第 4 章的家谱在此认亲：两家人隔着爱琴海与淮水，抄的是同一本推理的账）**）。
:::

::: definition 四式与一滑 {#def-sishi}
**《小取》给论辩发的四件兵器**：**辟**（“**举他物而以明之也**”：举例说明）、**侔**（“**比辞而俱行也**”:并列改句型——“白马，马也；乘白马，乘马也”——**同一对象在“是”字两侧滑动：白＋马是马，乘白＋马是不是“乘马”？侔式推理的漂亮与危险同源性**）、**援**（“**子然，我奚独不可以然也**”——**你行我也行：类比的法律版，第 6 章区隔术的祖师爷**）、**推**（“**以其所不取之同于其所取者，予之也**”——**把你不愿认领的同类项摆到你面前：归纳与归谬的共用发动机**）。**同页的免责声明（《小取》“此物之所然而不然”之惑——通说称“侔之蔽”）**——墨家对“也是”滑动高度警觉，自设防线的通说例证：“**爱人，待周爱人而后为爱人；乘马不待乘所有马而后为乘马**”————同一个“是”字、同一个动词，量化条件完全不同：**“爱人”要求普遍，“乘马”不要求遍乘：这是世界最早的“词汇逻辑学”笔记——对动词的语义做量化登记**（第 2 章库存、第 3 章方阵在此汇流**）。。
:::

## 公孙龙：三个思想实验 {#def-gongsun}

::: definition 白马、指物、坚白 {#def-baima}
**“白马非马”**（**不是疯话，是共相问题的开题：“马者，所以命形也；白者，所以命色也。命色者非命形也，故曰：白马非马”——通说译文：“马”指形状一类，“白”指颜色一类，颜色类不等于形状类，“白马”是两类交叠的新名——**它的真命题内核：类名（马）与种名（白马）外延不同，“是”字歧义（属于／等于）：‘白马是马’说的是‘属于’，‘白马非马’咬的是‘等于’（第 2 章“同意这个词≠同意同一件事”的战国极端版：把歧义推到刺眼，逼全场重看“是”字**）。**《指物论》**——“**物莫非指，而指非指**”（**对象无一不通过“指认”进入语言，而指认本身不是被指的对象：符号与物的关系论，两千年前的出生证；晋人谈指物如谈玄学，今天读它是符号学绪论（第 2 章三角对表的元层：词—心—物的“指”就是那条折线**））。**《坚白》**——**通说要旨：“坚、白、石不相离”，而另一派唱“离也者，天下故皆离”——**属性分析的经典开局：“坚”靠触、“白”靠视：两种知觉各得其一——那么“石本身”在哪里？感觉束之外有没有一个“一”（休谟的知觉束论、康德的物自体，在战国的竹简上都有草稿——第 3 章“为真的情形”的终极版追问**）。
:::

::: definition 三表法：最早的证据规则 {#def-sanbiao}
**《非命》“三表”**——**检验言说的三条规程：本之（“考之”古者圣王之事——历史先例）；原之（“察百姓耳目之实”——经验见证）；用之（“发以为刑政，观其中国家百姓人民之利”——实效检验）**。**逻辑课读法**（**这是把“你凭什么说”做成程序的最早中文版本：三条各管一种证据（典据、亲证、功效——第 8 章信源四问的先秦分部；它的短板同样清楚：第一条把权威置于经验之上，恰是后世“以传疑为信”的入口——三表法本身就该过三表：第一条“圣王之事”在圣王是否存在尚需考证时就已当票用了（第 2 章“规定的库存”：传统是别人存好的货，你直接上架**））。
:::

## 正名、知言与齐物：三场的三副面孔 {#def-sanchang}

::: definition 制度、症状、裁判 {#def-zhengming}
**荀子《正名》＝制度面**（“**制名以指实**”——**王者制名：命名权收归官方（第 2 章“规定定义”的政治学版）；“三惑”审计分类（通说：惑于用名以乱实、惑于用实以乱名、惑于用情欲以乱是非——用词义改写事实、用个案改写词义、用喜好冒充是非：三种“乱”到今天仍是谣言鉴定书的标准症状**）；**孔子“必也正名”＝立场面**——**名不正则言不顺：把定义问题直接当政治问题（第 2 章“库存重置”的开业致辞**）；**孟子“知言”＝症状面**——“**诐辞知其所蔽，淫辞知其所陷，邪辞知其所离，遁辞知其所穷**”（**偏颇的话知它被什么蒙住、放纵的话知它陷在多深、歪曲的话知它背离何处、躲闪的话知它理屈在哪：史上第一份“谬误症状学”——不列罪名，只读病征：第 9 章花名册的中医版（批判性思维的望闻问切——它诊断的是“话”的气色：遁辞即‘撑不住了’的生理信号——比任何谬误名录都早，也比任何名录都少可教性：直觉老练，规程缺席——这正是名辩两千年命运的前兆**））。
:::

::: definition 庄子的裁判难题 {#def-qiwu}
**《齐物论》**——“**既使我与若辩矣，若胜我，我不若胜，若果是也，我果非也邪？我胜若，若不吾胜，我果是也，而果非也邪？其或是也，其或非也邪？其俱是也，其俱非也邪？我与若不能相知也，则人固受其暗。吾谁使正之？使同乎若者正之，既与若同矣，恶能正之！使同乎我者正之，既同乎我矣，恶能正之！使异乎我与若者正之，既异乎我与若矣，恶能正之！使同乎我与若者正之，既同乎我与若矣，恶能正之！然则我与若与人俱不能相知也，而待彼也邪？**”——**逻辑学史上最早的“裁判无穷倒退”：胜者非是者（赢≠对，第 1 课“争吵淘汰证据”的元层版）；四路裁判全部驳回（同你者、同我者、异双方者、同双方者——每一路都已预设立场：第 15 课“三派终审权”的两千年前会审）**。**它不是诡辩，是怀疑论论证**——**墨家回应藏在《经》与《小取》的“当”字（墨家的回应在《经》说一系的通说大里：**“谓辩无胜，必不当”——说“辩论无所谓胜负”这句话本身，就是一场必须输掉的辩论；“或谓之是，或谓之非，当者胜也”——两可之间必有“不当”者：是非有客观裁决（“当”），只是人的辩未必达它——这条与庄子的分歧线，是中国哲学史最接近“真理的符合论对融贯论”的一场交锋**）。
:::

::: example 两小儿辩日：结案陈词 {#ex-liangxiaoer}
传为《列子·汤问》的一页：甲儿以**日初出沧沧凉凉、及其日中如探汤**为据，“**日初出远，而日中时近也**”（句意照通行本转述）；乙儿以**日初出大如车盖、及日中则如盘盂**为据，“**日初出近，而日中时远也**”。孔子不能决。**任务：①把两小儿的论证写成标准式；②各自的问题在哪一步；③“孔子不能决”在名辩语境里为什么可能是美德而非笑话**。
::: solution
①**甲**：P1 近则热、远则凉（感热规律）；P2 旦远而午近（现象：旦凉午热）；∴ 旦远午近。**乙**：P1 近则大、远则小（视觉规律）；P2 旦大午小；∴ 旦近午远——**两人各是一个合法 MP（第 4 章！结构都有效）**；②**病灶全在第一前提：两条“规律”都只在各自的感觉通道内成立（热觉、视觉），且都没有排除中介变量（大气、背景对比——视错觉与辐射强度是两套物理：感觉数据不能跨通道直接互斥（第 7 章“无混杂保单”没人签：两造各拿单一仪表测双变量系统**）；③**孔子不能决的逻辑学美德**（没有裁定权限就不下判——按名辩的行话：这是“不敢乱立‘故’”：两小儿各自有效、各自不确：“有效”与“可靠”分账（第 1 章两家事务所）在此案两千年前开庭；笑话版《两小儿辩日》嘲的是“圣人也有一不知”——本课判词：知道“不知”的边界正是全部逻辑的起点（苏格拉底的自知无知与孔子此处握手：一个用问答立法，一个用不答示范——东西方奠基动作同构（第 1 课“双方都可能错”的圣史版本**）。
:::
:::

::: intuition 名辩为什么熄了 {#int-xile}
**通说“三失”**（**①无职业市场：辩论不取士（科举以文赋取人，“问—答—驳”无编制——古希腊法庭与广场需要辩护士与智者教师，战国之后这类职业没长出来（第 9 课“分发格式决定生死”用到逻辑学科本身：一种文体没有职业分发，它就只有天才，没有传统**）；**②注疏代替论证：经典解释学太成熟，思想的时间花在“述”而不是“辨”（第 15 课“诠释的边界”的另一面：解释压倒证明**）；**③言意之辨转向：语言被当作要超越的东西（“得意而忘言”的通说化用），而不是要检查的东西——第 15 课那部单程电梯在此开工：玄学接过了庄子，名辩的电闸被拉下（怀疑论可以被敬奉，也可以被用来关门**））。**分寸声明**（**三失是解释假说不是判决：名篇传世靠文本、制度、学缘的多重偶然——“不熄”需要多少条件，“熄”只需要一些；另戒三种心态：六经注我的比附（“墨家=古希腊逻辑+实用主义”的贴图游戏）、“中绝为耻”的道德化（逻辑是方法，不是民族成绩单）、把“辩无胜”读成“和稀泥有理”（庄子说的是裁判难题，不是“别吵了”：这是本课最不该被误读的一句**。
:::

::: history 名辩的两千年：两度接电 {#sec-liangdu}
**前 4—3 世纪** 名家与墨辩的百家时段（**公孙龙“困于齐楚”的稷下现场；后期墨家写《经》《经说》接战（第 5 章因明入华的“因”早已本土发芽**）；**前 3—2 世纪** 沉默期（**《荀子·正名》《韩非子·难势》把“辩”收编进治术；司马谈“名家使人俭而善失真”（《论六家要旨》通说——史官的判词比学派的辩论活得久：图书馆赢了广场**）；**3—7 世纪** 清谈与因明并行（**谈“指物”“言意”者继续加注；佛教因明（陈那、法称的三支与因三相）经玄奘译入——外来的逻辑学第二次进场（第 5 章“喻入编制”的现场**）；**1890s—1930s** 第一次接电（**康有为、梁启超、章太炎、孙诒让一系的墨学整理＋胡适《先秦名学史》（1919 英文原版）以“古代名学”重写哲学史＋梁启超《墨经校释》一路的校勘接力——“墨辩复活术：用逻辑学这把新钥匙开两千年前的旧锁；锁开了几道（“故／理／辨”与 premise／logic／dialectic 的对译成色几何），整个 20 世纪都在返工**）；**1937—今** 第二次接电（**金岳霖《逻辑哲学》把名辩放进比较逻辑的版图（第 1 章参考书目在此见面）；沈有鼎对墨辩与名家文本的符号化重读（《墨辩的逻辑学》1940s 通说脉络——把“指”“马”读成类与分子的记法）；当代出土简帛与新整理本不断改写时间线：“名辩是活的语文学，不是博物馆”。
:::

::: exercise 侔式体检 {level=1}
给五句“比辞而俱行”做侔式体检（“是”字两侧各是什么外延？滑没滑？）：①“白马，马也；乘白马，乘马也。”②“舟，物也；乘舟，乘物也。”③“盗，人也；杀盗，杀人也。”④“书，物也；读书，读物也。”⑤“诗，文也；读诗，读文也。”
::: solution
判分：**逐句查动词的“量化条件”**（①墨家许可（乘不要求遍乘——“乘马不待乘所有马”）；②许可但滑稽（“乘物”听起来荒谬因为“物”要求上位类？其实是“乘”的宾语范围被扩大——句法合法、语感报警：**报警不等于违法**）；③侔之蔽的高发段（传世名家命题“杀盗非杀人”即此式：通说以墨家辩“盗”之所属——说“杀盗”时，“盗”是身份限定，不等于否认其为“人”：“是”在“属于”与“等于”之间换挡，伦理与逻辑在此分轨——**答题只需指出：外延同、规范力不同：法律主语与修辞主语不是一回事**）；④⑤**“读”要求意向对象（读《诗》≠读纸张）：词义随动词重排——动词是句子的法槌（第 1 课回访：动词即法槌）**。
:::

::: exercise 为“辩无胜”写答辩状 {level=2}
以墨家立场（“辩也者，有不可胜者也；两也者，有不当者也”通说大意）写**二百字答辩**：承认知识受限时怎么办、反对把“无胜”滑成“无是”；并指明答辩状里“**当**”字的判准是什么（可错？可检验？谁来当？）。
::: solution
判分：**承认裁判难题而拒绝判决虚无**（**“胜”与“是”分账之后，出路是把裁判换成程序：兼听、三表、观其效（墨家的答案：裁判不在人，在“国家百姓人民之利”的后效检验——第 6 章功效表与第 8 章可追溯性的先秦原型**）；“当”的判准（**判卷看诚实：“符合事实”需要能说清为真的情形（第 3 章）；“融贯”需要外部锚点（第 9 章免疫化警告）；“实效”有滞后与归属难题——三者各有账，任选其一须写明它的失效条件**）。

::: exercise 小论文：没交卷的题 {level=3}
写六百至一千字，评“**名辩的熄火不是智力事故，是职业事故：一个文明给什么样的人发工资，就有什么样的学问——古希腊发给了辩护士与注经人，宋代发给了八股考生；逻辑学在哪个朝代领工资，它就在那个语言里讲真话**”。须调用：**名辞说故架构**、**侔与“侔之蔽”**、**白马或指物（择一深读）**、**三表法及其第一条的病灶**、**庄子的裁判难题**、**通说“三失”**至少六项；并裁决：**“如果墨辩传统未中断，中国会独立发明现代逻辑吗”——写一份负责任的反事实史（哪三个条件必须同时成立，缺哪一个就重演熄火）**。
::: solution
判分点：六项机制（**架构＝目录页；侔＝词汇量化；白马＝“是”字歧义；三表＝证据程序＋圣王条的入口病；裁判＝胜／是分账；三失＝市场、注疏、超越论**）；反事实裁决（**三条件参考：①职业市场（法庭、议政、宗教裁判任一需要专业辩护士的制度）；②制度化的“问—答—驳”文体（学塾论敌制、学位辩论制之类）；③对语言本身而非言外之意的职业兴趣（经院式的文本技术传统）。缺①则无薪，缺②则无传，缺③则无题——名辩三失皆缺（判分看：谁把“三缺一就重演熄火”论证成了系统性质，而非三件偶然的并列；把反事实写成条件句的逻辑作业，不写成怀旧的平行宇宙**）；结论若能写“**本课结业赠言：逻辑在中国有两次出生，一次在战国没有接上电，一次在 1905 从译本里接线——两次都为同一件事：让‘讲理’有客观标准，不看谁的位子高。名辩的遗产不是‘我们早有’的存折，是‘为什么熄了’的考卷——这道题至今没交卷，交卷人是每一个把话说清楚、把账记分明的普通人**”，即 A。
:::

::: summary
原件归档：架构（**名—辞—说—故＋大故小故＝充分必要的雏形**）、四式一滑（**辟侔援推＋“爱人待周、乘马不待”的词汇量化**）、公孙龙（**白马＝“是”的歧义、指物＝符号学、坚白＝属性分析**）、三表（**典据、亲证、功效：圣王那条自带后门**）、三场（**荀子的制度、孟子的症状、庄子的裁判难题——胜者不是是者**）、熄火（**市场、注疏、超越论：通说是假说，不是判决书**）。方法一句话：**把它当原件读，不当亲戚认**。十课全毕：从论证的最小骨架到名辩的考古现场——逻辑课的结业只有一句话：**你的结论从不比前提更有资格；而把前提立得配得上结论，是一辈子的课**。
