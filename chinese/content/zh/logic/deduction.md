title: "演绎推理"
---

上一章把句子放上秤；本章修**运输**——演绎是逻辑里唯一提供**保证书**的工种：前提真则结论必真，没有“通常”**。它的代价同样明确：**它不生产新内容**。

## 定义：有效性＝保真传送带 {#def-baozhen}

::: definition 形式决定命运 {#def-xingshi}
**有效＝不可能前提真而结论假**（**传送带质检标准：不担保货真（前提真不真不归形式管），只担保运输不丢——“若前提真，结论必真”，这是全部承诺**）；**检验工具有两把**：**反例机**（**判无效只需一个“前提真结论假”的可能世界：造出来即结案——“如果下雨地就湿；地湿了；所以下雨”——洒水车路过：反例廉价，有效性昂贵**）；**真值表**（**判有效则要把所有行看完：n 个原子句 2ⁿ 行——穷举即证明：笨办法是逻辑的美德，它不靠例子取胜，靠把所有例子都看完**）。**演绎的两张出生证**：**分析性**（**“所有单身汉都未婚”靠意义就为真，不出门、不抽样、不打扰任何单身汉——弗雷格式路线：数学可归约为逻辑的宏大方案（第 1 章战线）；综合性**（**“太阳明天升起”要经验提货——休谟问题（第 7 章的引信：经验的习惯如何获得“必然”的批文？——演绎不接这个活：它把必然性全部押在形式上，因此它的安全与它的贫乏是同一件事）**）。**总判词：演绎的结论从不比前提更有资格：想要新东西去归纳，想要绝对安全只能接受废话——全部知识的冒险都发生在两极之间**。
:::

## 联结词：五把刀与两处歧义 {#def-lianjie}

::: definition ¬ ∧ ∨ → ↔ {#def-wulian}
**否定¬**（**汉语多层否定要算账：“不是不同意”＝同意？未必——“不是不同意，是还没想好”：双重否定在口语里常是缓兵而非算术（语法否定叠加，语用保留立场——审计写法：把“不是不”直接改成正式或明写“未定”**））；**合取∧**（**“且/但/却”在真值上都是∧——“他很穷但很诚实”与“他很穷且很诚实”同值：**“但”额外登记一个意外（转折词是语用的抱怨，不改账目：逻辑看不见你的失望**））；**析取∨（相容）**（**报名表上的“或”是排斥的（单选），合同与词典里的“或”是相容的（“具备驾驶执照或同等资质”——两种都有也合格）：逻辑选相容，除非明写“二者只居其一”——“去或者不去”这类“排中并列”是修辞不是联结词**））；**蕴涵→**（**下节专章处理**）；**等值↔**（**当且仅当：充要双行道——立法者的最爱与读者的雷区（“本合同自双方签字之日起生效”是必要还是充要？签字→生效，这一格是铁的；不签字是否就不生效？条款没写第二个箭头：第二个箭头是解释者的想象**））。
:::

::: definition 实质蕴涵：一张极简合同 {#def-yunhan}
**“如果 p 则 q”只在“p 真 q 假”时假**——**于是“如果 2＋2＝5，那么月亮是奶酪”为真：不是逻辑发疯，是合同写得薄：“→”不承诺 p 与 q 有任何内容关联，它只注销一种情况（前真后假）**。**这份薄合同的后果（刘易斯式“悖论”）：真前件不可能时条件句一律为真（“如果太阳明早熄灭，我就请你吃饭”永真——因为它没有违约的机会）**。**日常“如果”带着相关性与因果的厚期待——两者必须分账**：课堂立场（**评估日常与法律论证时，把“→”当“强相关”来要求：对“如果你不办卡，就说明你不在乎健康”这类句子，追问“前件真而后件假的情形你想过吗”——诡辩在薄合同上合法，在厚合同上违约：你的反驳要指着厚合同说**）。**反事实条件句**（**“早如此，竟不用今日来了”——《红楼梦》乌进孝的悔话：前件与已知事实相反，真值表当场死机（p 为假，整句永真——但人的悔意显然有内容：它比较的是一个“早如此”的世界——严格蕴涵与可能世界语义都修不全这笔账：条件句是逻辑的边疆地区，本课在界碑处留白，只要求你识别“前件已明知道假”的句子没有反驳力（它连账都没上）**）。
:::

## 四大名器与两大死法 {#def-mingqi}

::: definition MP 与 MT：仅有的两条快车道 {#def-mpmt}
**肯定前件式 MP**（**若 p 则 q；p；∴q——投币出货**）；**否定后件式 MT**（**若 p 则 q；非q；∴非p——没出货所以没投币／门禁未开所以卡无效：数学里的反证法、法庭上的“若为真必留痕，无痕”，全是 MT 穿了不同的制服（“MT 是逻辑里最能打的姿势：它让敌人的预言替自己挖坟”**））。**两大死法**：**肯定后件**（**若 p 则 q；q；∴p——地湿所以天下雨：把自动售货机当成了单向街；日常重灾区：“他这么说是因为心虚；他说了；所以他心虚”——紧张、口误、赶时间都是后件的其他爹**）；**否定前件**（**若 p 则 q；非p；∴非q——没投币所以不出货？门禁卡没刷进不去，但门可能本来就开着：努力不充分时的自我赦免书（“反正努力也没用”：否定前件式的抑郁逻辑：心理真实，形式违法**）。**钥匙模型（中文精确对应）**（**只要…就…＝充分（投币必出货）；只有…才…＝必要（没卡必不进）；两个连词是汉语逻辑的双黄线——“只有努力，才能毕业”＝毕业→努力（逆否：不努力→不毕业：MT 的轨道）；“只要努力，就能毕业”＝努力→毕业（MP 的轨道，被一次挂科即可击穿）——查一查身边人开的保证书，九成写在错的那条道上**）。
:::

::: definition 变形记：换质、换位与逆否 {#def-bianxing}
**对当方阵管“所有／有的／不”的账，联结词逻辑管“如果”的账，两者在直言命题的标准式里会师**——**三条合法变形**：**换质（**“所有 S 是 P”＝“S 都不是非 P”：双重否定的化妆术**）**、**换位（**“所有 S 是 P”→只许弱换位“有 P 是 S”（“所有人都会犯错”只能换成“有些会犯错的是人”，换不成“所有会犯错的都是人”）；“没有 S 是 P”→“没有 P 是 S”：全换；“有 S 是 P”→“有 P 是 S”：全换——**特称与否定不许越位：换位是外延的舞蹈，跳错一步就踩到“有的 P 不是 S”的空地**）**、**逆否（黄金等值式）**——**“若 p 则 q”＝“若非 q 则非 p”：条件句的黄金等值式，MT 的孪生兄弟——“若及格须满四十学时”＝“不满四十学时则不及格”：教务处的两种口音，一个意思**）。**自然演绎联合作业（方阵＋否定）**：“**并非所有都合格”＝“有些不合格”；“并非（甲且乙）”＝“非甲或非乙”（德摩根：把否定送进括号要换号——“不是又贵又难用”＝“要么不贵，要么不难用”：吐槽的两种退款理由，只需一条成立**）。
:::

::: example “只有一句是真话”宿舍案 {#ex-zhenhua}
期末成绩公布前。甲：“**全班都能及格。**”乙：“**班长不能及格。**”丙：“**有人不能及格。**”丁：“**有人能及格。**”已知**四人中只有一句真话**。问：谁说了真话？全班情况如何？
再答第二问：若已知条件改为“**只有两句真话**”，答案变不变？
::: solution
**第一步找方阵关系**：甲（A：都是）与丙（O：有不是）**矛盾**——**必一真一假：真话必在甲丙之中（矛盾律给的把手：六句里找一对矛盾，其余全假——这是此类题的“总开关”**）；于是**乙、丁皆假**：乙假→班长能及格；丁（I：有是）假→其矛盾（E：都不是）真→**全班都不及格**。回查：全班都不及格时，丙（有人不能及格）真、甲假——**与“只有一句真话”吻合**。结论：**真话是丙；全班都不及格，班长也在其中**（教学点：**“矛盾对”是题目的铰链：找到它，其余命题自动缴械**）。**第二问**：两句真话时铰链仍在甲丙之间——**甲丙仍一真一假，故乙丁之中恰有一真。设乙真（班长不及格）：丁（有人能及格）不因此而定，须分库存——若其余人及格，则乙真、丙真、丁真、甲假：三真超标；若除班长外全不及格，则乙真、丙真、丁假、甲假：恰两句真话，此解成立**；设乙假（班长及格），则丁必真，甲丙之中还要再真一句（班长及格而有人不及格：丙真、甲假）——又是三真，超标。**穷举之后唯一解：除班长外全班都不及格（“只有一句真话”则真话在丙；“两句真话”则真话是乙丙——两问同形不同果：已知条件的一句改动把解空间全部重洗：逻辑题的“题眼”就是那半行字（真值表的价值：不用聪明，用耐心：2⁴＝16 行足够，但方阵把手只用十秒）**）。
:::
:::

::: intuition 重言式：最安全与最无用之间 {#int-chongyan}
**“明天或者下雨或者不下雨”永真——并且什么也没说**：**真值表全行为真的句子不冒任何风险，因为它否决的世界集合为空**（**波普尔的反比律在此挂号：可证伪度越低的内容越安全也越穷——“不是 A 就是 B”的废话为什么气人：它把说话的风险预算花在了零赔率的赌注上，还要求你为“清醒”鼓掌**）。**推论一（永真句的正当用途）**：**重言式是逻辑的脚手架而非建筑：有效性本身不可用（“若前提真则结论真；前提真；∴结论真”是永真的——而它的用处在于把论证摆成可检查的形状：先有 MP，才有 MP 的定理）**；**推论二（警惕伪保险句）**：**“投资就有风险，不投就没有风险吗？”——问句把话题踢回未定域，两问都不承载可伪内容：政策语言里的双重永真（“可能”与“必然可能”同值：给结论上保险时，先把保险单的保额读出来：“争取完成”与“完成”之间隔着一整个问责表（第 3 章限定词账户的公文版**）。
:::

::: history 演绎术的三代家谱 {#sec-jiapu}
**前 4 世纪** 亚里士多德《前分析篇》（**三段论＝历史上第一台演绎机器：格与式的穷举是“判定程序”的祖先——把推理从口才降为算术**）；**斯多亚派**（**命题逻辑的五种“论证式”：MP 与 MT 在此登记造册——古代逻辑的第二所学校，教的是“如果”而非“所有”**）；**中世纪** 推论学说（consequentiae：演绎规则学的经院高峰期＋**“必然与偶然”的真值争论续账**）；**1879—1910** 弗雷格到《数学原理》（**现代逻辑开机：量词、推理规则、从逻辑导出算术：演绎的确定性被推到极限，也被哥德尔在 1931 年就地圈存（不完备定理：任何足够强的系统里，真不能全部收进可证明——“安全与贫乏是同一件事”的元数学盖章**）；**1930s** 形式主义纲领受挫（**确定性有了边界碑：演绎能保证的，到此为止——诚实的地图先画自己的海岸线**）；**1965 起** 自然演绎进计算机（**柯里—霍华德对应：“证明即程序”：演绎第一次有了运行结果——写得出编译器的人把亚里士多德的产品上线了**）；**中文系一侧**（**因明入华（陈那、法称的“因三相”经玄奘译传：“宗—因—喻”三段式＝印度版演绎—类比混合体；清代学者以“因明”重读《墨辩》：名辩研究的新透镜——本章末课专档：三段论、因明、墨辩三副骨架可以互相照 X 光，但别互相接骨**）。
:::

::: warning 演绎四坑
**肯定后件成瘾**（**后件可有百家（洒水、倒水、下雨）——看到“所以一定是”先查后件还有没有别的爹**）；**把有效性当结论正确**（**“有效”与“为真”是两家事务所（第 1 章）：一个完美有效的论证可以从假前提把水运到对岸——形式不生产水**）；**“只有／只要”失读**（**保证书写在错箭头上：全校都以为“只有平时分合格才能考试”＝“合格→能考”（实际是“能考→合格”）：一字读反，申诉全输**）；**用永真句装深刻**（**“凡决定都有代价，所以别做决定”：前件永真、后件违法：从安全句偷运冒险结论是鸡汤的标准生产线**）。
:::

::: exercise 病历推理 {level=1}
医生说：“**如果化验显示感染，就开抗生素。**”事后护士说“**医生开了抗生素**”。①能推出“化验显示感染”吗？写出形式；②若护士改口“**医生没开抗生素**”，能推出什么？该推出是否有效、可靠度还差什么？③把医生的话补成“当且仅当”，再重答①。
::: solution
①**不能（肯定后件）**：p→q，q ∴ p 无效——医生可能凭经验开药（后件另有其父）；②**MT 有效：¬q→¬p：“化验未显示感染”（在医生的话为真的前提下）——有效性满分、可靠性看前提：医生那句话当时是不是铁的（有没有例外条款：“重症例外”一出现，逆否就不铁：一个例外吃掉整个蕴涵的时机——充分条件的“充分”由例外清单定价（第 3 章限定词的合同版**）；③**改写成双行道后①变有效（q→p 成立——立字据的学问：合同律师的全部工作就是补第二个箭头）**。
:::
:::

::: exercise 连词改锥 {level=2}
把五句中文改写为**符号式**并判定有效／无效：①“不撞邪就不会这么倒霉；他这么倒霉；所以他撞邪了”；②“只要努力就能学会；他没学会；所以他没努力”；③“除非你有通行证，否则不能进；他进去了；所以他有通行证”；④“要么甲是主犯，要么乙是主犯；甲是主犯；所以乙不是”；⑤“不是不想去，是去不起”。（“除非…否则…”统一按“除非 p 否则不 q”＝“只有 p 才 q”＝q→p 处理。）
::: solution
①**MT 形式合法但前提含假蕴涵（“倒霉”的后件有千万爹：有效性≠可靠（第 3 坑现场）**）；②**MT：努力→学会；¬学会∴¬努力——有效；可靠性取决于“只要…就…”是否被写得太满（教学方法变量全被抹平的保证书）——有效且几乎可靠，这是日常论证的满分姿势**；③**进→通行证；进了∴有通行证（MP）：有效——“除非”句的标准驯服**；④**相容析取的非法用法（“甲或乙”允许两人都是主犯：肯定一个不能否定另一个：要判有效需先把“或”盖上排斥章（联结词一节的歧义案重审**）；⑤**不是¬去，而是¬能：语用转折＋否定移位的正例——符号式：¬想去∧¬(负担得起)→实际¬去：并列结构；“不想去”被否定的是理由不是行动：口语里的合取与辩解的分工**。
:::
