上一章管账本上的科目名；本章管**账目本身**——哪些句子能记真假、能记多真。**逻辑的第一台秤在这里：命题＝能上秤的判断内容**。

## 定义：上秤的资格 {#def-shangcheng}

::: definition 命题、语句、陈述 {#def-mingti}
**命题＝语句的判断内容**（同一命题有无数语句穿：“明天下雨”“明日有雨”“雨将明日而至”——**同义句是命题的衣服；反过来说：一句多“皮”即是歧义——“他谁都不认识”两套库存（他不认识任何人／没人认识他）：命题分裂为二——争辩双方可能各穿一件衣服**）。**不上秤的四类**：**疑问**（“关门了吗？”）、**祈使**（“把门关上！”）、**感叹**（“关得真好！”）与**预设塌方句**（见第 5 节）——**“请把窗关上”既不为真也不为假，但它是论证的 cosplay 大户：广告全是祈使句的私生子（“买它！”没有真值，因此也无法被反驳：这正是设计意图——无法为假的话，也不配为真：广告语的“不可证伪性”是它的全部营业牌照**）。**为什么非要有真值这回事**：**没有真假的句子可以参与论证的现场布置（命令、威胁、恳求），但不能参与推理的记账（第 1 课的账本）——判定“上不上秤”，是把修辞问题转成逻辑问题的第一道门**。
:::

::: definition 真值条件即语义第一原理 {#def-zhizhi}
**“理解一个句子，就是知道它为真的情形”（《逻辑哲学论》的通说要旨）**——**这句话把“意义”做成了可操作检查：你能说出“天下雨”为真需要世界长成什么样（某地、某时、有水落下），你就算懂了它；说不出，你就只是在发音**。**由此得“分歧体检术”**：**争“X 是否为真”之前，先对表“我们各自把 X 的‘为真的情形’设成了什么”——大量公共争论在第二步就已分道（“AI 有创造力”：甲的为真情形＝产出让内行意外；乙的为真情形＝产出出于自觉——两种情形各自可查，而争吵双方常常连查都没查**）。**验证的远近**：为真情形可当场查（“冰箱里有牛奶”）、要工具查（“这 U 盘是 64G”）、原则上无人能查（“银河系外存在智慧文明”）**——命题够不够格，不由能否当场查决定，但**但长期无人能查的命题，在论证中的信用额度应当自动下调（第 8 章证据课预埋）**。
:::

## 方阵：四种直言命题的对当生意 {#def-fangzhen}

::: definition A、E、I、O 的四种关系 {#def-duidang}
标准式四员：**A 全称肯定（所有 S 都是 P）、E 全称否定（所有 S 都不是 P）、I 特称肯定（有 S 是 P）、O 特称否定（有 S 不是 P）**。**四副关系**：**矛盾**（A↔O、E↔I：**必一真一假：全称与特称否定的互杀局——“都及格”为假，只差一个不及格**）；**反对**（A↔E：可同假不可同真——“都爱他”“都恨他”可以同时是谣言）；**下反对**（I↔O：可同真不可同假——“有人满意”“有人不满意”常常一起为真：**民调的两条腿：任何“有人说……所以……”都在偷用下反对关系当矛盾关系卖**）；**差等**（A→I：全称真则特称真；逆推无效——**“有的同学习惯熬夜”即便所有人都不例外也仍为真——**“特称”＝“至少一个”，不含“并非全部”：日常语言把“有的”听成“只有一些”，是方阵的第一课****）。**中文系加固**：**“不都是”≠“都不是”（“奖金不都是他拿的”＝O 命题；“都不”＝E 命题：一字之差的量刑差别（“成绩不都是老师给的”承认部分，“都不”翻脸——杠精与外交官共用方阵，各自取一格**。
:::

::: definition 限定词：论证强度的银行账户 {#def-xianding}
**“必然—通常—可能—恰好一次—除少数外”**——**限定词（模态词与量词的日常变体）是论证的强度账户：图尔敏模型把它单列一项（第 1 章战线预告），因为日常论证的对错九成发生在限定词上**：“**吸烟导致肺癌”（统计义）→“吸烟可能导致肺癌”（个体义，保守放款）→“吸烟使人必然罹患肺癌”（超额透支）**；**两种标准诈骗**：**升级诈骗**（把“研究发现 X 与 Y 相关”读成“X 导致 Y”再读成“X 必然 Y”——科普转发的三级火箭）；**降级诈骗**（“我从不迟到”被一次意外击穿——把“几乎总”伪装成“全”以便随时抵赖——**限定词的灵活度留给对方，刚性留给自己的结论**）。**审计口诀：找到结论句的限定词，再回前提里找它有没有存款——前提只开了“可能”，结论不能取“必然”（第 4 章：有效性是保真传送带——限定词透支与无效同罪）**。
:::

::: example 空主语与虚构账：国王、黛玉与前任 {#ex-kong}
三只“上秤疑难”：**①“法国现任国王是秃头”**（罗素 1905 年的那只老虎，此处原形保留）；**②“林黛玉死于心碎”**；**③“我前任从不夸我”**（分手者语）。请：判定各自能否为真、按谁的库存判、给出**可审计的改写式**。
::: solution
①**预设塌方**（句子**断定了“存在一个法国现任国王”＋“他有/没有某属性”——前半已假：罗素的方案：表面语法的主语其实不是“东西的名字”，而是存在量词的伪装：“存在唯一的 x，x 是法国国王且……”——**它为假，而不是无意义：这是驯服空词的第一次手术（“当今法国的国王”为假；而“当今法国的总统留胡子”可真可假：语法相近，逻辑异构——罗素的教学价值：把“找不到东西的主语”现形）**）；②**虚构话语**（**“林黛玉死于心碎”在现实账本无处记账（无此人了）——审计改写：“在《红楼梦》里，黛玉泪尽而逝”：给句子补上**索引**，虚构命题立刻获得客观真值（“书里”是它的时空状语：虚构不是胡说，是换了账本——“在……里”有三个合法账户：原著、同人、我的想象：前两格可审计，第三格只能自留——**粉丝大战的逻辑病理学：三方各用不同账户对账**）**）；③**私人史全称**（“从不”＝E 命题＋样本只有“我记得的”：**记忆的限定词流失症：人脑自动把“多半没有”剪辑成“从不”——改写式：“与我相处的全部年头里，我记得的夸奖次数为零（未记得的不计）”：一句话让架吵不起来（可证伪度上升，杀伤力下降：诚实的定义常常不好用——第 2 章“精确不是美德，分配诚实才是”的亲密关系版**）。
:::
:::

::: intuition 世界不在两格里，但记账只用两格 {#int-liangge}
**二值逻辑是一份预算**（真／假两格；**模糊谓词（“高”“富”“堆”）与未来偶然（“明晚会下雨吗”）在 20 世纪各自养出了多值逻辑、模糊逻辑、时态逻辑——它们不是推翻二值，是给难管的世界另设分账科目：主干账本仍是二值，因为日常推断的审计只需要它**）。**判断与信念的距离**：**同一命题可以被相信、被怀疑、被希望、被命令去相信——命题是内容的原子，命题态度（我相信 p／我担心 p／要求查明 p）是态度的外壳：论证审计只穿透外壳检查里面的内容；日常争吵九成发生在壳层（“你竟然担心这个！”——对态度发动的战争，内容全程免检——第 1 课“对人攻击”的态度版**）。**分寸**：**逻辑课给世界做的二分法很薄：它只说“每个能记账的句子必须占一格”，从不说“世界只有两格”——把二值逻辑读成二元世界观，是把会计软件当成了人生**。
:::

::: history 真值概念的几次改表 {#sec-gaibiao}
**前 4 世纪** 亚里士多德《解释篇》（**命题定义与“明天将发生海战”的真值之争：未来偶然的第一份档案——决定论与逻辑的第一次分账（《解释篇》9 章通说）**）＋中国“**刑名**”之学与墨家“**以辞抒意**”（辞＝判断层：名—辞—说—故的四层里，本章管第二层）；**中世纪** 真之符合论成典（**符合论的经院定型（“真理是符合”的句式通行）＋“指称/涵义”的雏形（suppositio 理论：词在句中指哪个——第 2 章库存问题的中世纪版**）；**1879** 弗雷格（**概念文字：判断内容（Gedanke）脱离语法外壳——本章“命题≠语句”的现代出生证**）；**1905** 罗素《论指谓》（**空词手术：描述理论；1908 类型论顺手修理了“说谎者”——自指被戴上约束带（第 10 章的名辩回响）**）；**1921** 维特根斯坦《逻辑哲学论》（**通说要旨：命题是实在的图像、复合命题是真值函式——联结词的真值表在此登记（第 4 章的账房钥匙）**）；**1930s** 塔斯基真理定义（**“雪是白的”为真，当且仅当雪是白的——T 模式：把“真”这个自家用了三千年的词送进形式化的海关：对象语言与元语言分账（“这句话是假的”在分账制下无法立案）**）；**1960s—今** 可能世界语义（克里普克：“为真”扩展为“在某些世界里为真”——模态逻辑获得沙盘；模糊逻辑进家电（空调的“较凉”档位是亚里士多德方阵的民用化：逻辑学罕见的量产落地）**。
:::

::: warning 命题四坑
**“有主语就有对象”**（**“圆的方”“现任国王”“孙悟空的金箍棒”——语法齐备、库存为空：罗素手术刀常备：主语位置可能是量词的伪装**）；**“有的”听成“只有一些”**（**逻辑“有 S 是 P”＝至少一个，不排除“所有”：汇报时说“部分项目达标”的人，可能全部达标——别替别人加限定词，也别替自己减**）；**态度战争**（**“你怎么能这么想！”——壳层交火，内容免检：把争吵拉回 p 的真值条件是唯一解毒剂**）；**限定词双向诈骗**（**升级（相关→导致）与降级（几乎总→从不，便于抵赖）：审计只查一件事——结论的限定词在前提里有没有存款**）。

::: exercise 新闻句子改写 {level=1}
把五条含混句改写为**可核查命题**（标出真值条件与限定词账户）：①“专家认为该方案总体可行”；②“多数网友表示支持”；③“新产品显著提升睡眠质量”；④“相关措施有望近期落地”；⑤“没有证据表明它无效”。
::: solution
判分示例：①**“专家”无单复数、无资质域、无引用（谁？几位？是否在相关领域内？）——改写：“内分泌学会三位作者在 2024《…》中认为该方案在其假设下可行”：限定词“总体”要落成“适用于 X 人群 Y 条件”**；②**“网友”＝抽样自“会发声的人”：真值条件实为“在 N 平台 M 条相关帖中 X% 表支持（时间窗 T）”——第 7 章抽样课的预告函**；③**“显著”缺检验（样本、对照、效应量三栏；答题只要求写“与对照组相比平均入睡时间减少的分钟数”）**；④**“有望”＝无人对“不落地”负责的免责壳（限定词的降级诈骗）——改写需指认承诺主体与时间表**；⑤**“没有证据表明无效”≠“有证据表明有效”：举证责任的方格（否定命题的证据真空不能转写成肯定——方阵 O 与 I 的下反对误用现场：它只排除“已知无效”，不排除“未知”与“有害”**。
:::

::: exercise 限定词调仓 {level=2}
给一个真实论断（自选）写**同一命题的五档强度**（必然—通常—多数情况下—可能—有一次），并标注**每档的证据门槛**；再用一句话指出：**日常语篇里人们通常在哪个档位取证、在哪个档位引用**。
::: solution
判分：**门槛单调递增可指认**（“有一次”只需一个见证，“必然”需要排除反例的机制——第 7 章的归纳与第 4 章的演绎在此握手）；**错位诊断**（取证常在“有一次”，引用常升“都这样”：**民间论证的标准汇率：用轶事的价格买入，用定律的价格卖出——本课要做的，就是把汇率表贴在大家额头上**）。

::: exercise 小论文：二值逻辑是一种礼貌 {level=3}
写六百至一千字，评“**非真即假不是世界的分辨率，而是记账员的自律：它承诺‘你的反对意见有资格被记为真或假’——这是逻辑对异议的最大礼貌**”。须调用：**上秤资格（祈使不上秤）**、**真值条件对表术**、**方阵的对当关系（至少两用）**、**限定词账户**、**虚构句索引手术**至少五项；并裁决：**“既是真的又是假的”（双面真理）能否记账——多值逻辑的引入是解放还是逃账**。
::: solution
判分点：五项机制（**资格＝异议可审计的前提；对表＝分歧体检；方阵＝反对与矛盾的火器射程差别；限定词＝强度的复式记账；索引＝换账本而非不记账**）；双面真理裁决（**两条参考：逃账论——“既真又假”若取消爆炸原理（从矛盾可推出一切），该句子便失去一切推论效力＝零存款账户：它不能参与任何论证，只装饰姿态；解放论——真值间隙理论（克莱尼一类）处理的是“证据未定”的第三态，不是“真且假”：命名要诚实——第三格是“未定”的新科目，不是允许做假账**）；结论若写“**逻辑的二值不是傲慢的判决，是可追责的承诺：你说出的每句话都敢认领一个格子——拒填表格的人，才是不礼貌的那位：而填了格子又被划掉，正是全部科学的意思**”，即 A。
:::

::: summary
上秤清单归档：资格（**能定真假才进账本；祈使与命令只布景不记账**）、对表（**说不出“为真的情形”就只是在发音**）、方阵（**矛盾互杀、反对可同假、下反对常同真、差等只走单程；“不都”≠“都不”**）、限定词（**强度的银行账户：结论的额度必须在前提存过**）、空词（**国王现形、黛玉补索引、前任剪辑记忆：手术刀常备**）。方法一句话：**先问这句话的真值条件，再问它的限定词余额**。下一章上机器：演绎——从真到必真的运输学。
:::
