上一章把论证拆成账本；本章管账本上的**科目名称**——**吵架的人有一半在争“你说的‘负责’是哪个‘负责’”**：概念不清时，逻辑再硬也是在两栋不同的楼上量楼距。

## 定义：三角对账 {#def-sanjiao}

::: definition 词、心、物的一条折线 {#def-zsx}
**概念≠语词≠对象**：同一对象有无数的名字（“土豆／马铃薯／洋芋”——**方言是名称的方言，概念是概念的方言，两者都可能假装同居**）；同一名字背后有无数的库存（十个人说“素质”，货架上摆着十种货——**“你们同意这个词”与“你们同意同一件事”是两笔独立账：争论中最大的成交假象就登记在这里**）。**定义＝把你说的词与我脑中的库存对账**（属加种差是标准账法：**“人是理性的动物”＝找大类（动物）＋找差价（理性）**——**亚里士多德的公式统治了两千年，直到柏拉图给出“无羽两足”的版本、第欧根尼拔光一只鸡扔进学园：“这就是人的定义！”——翻车现场的教学价值：种差必须选在决定性的层级上，选错层级的种差，一只秃鸡就能击穿**）。
:::

## 五条规则与五种翻车 {#def-guitse}

::: definition 审计规程 {#def-shenji}
**①相称**（外延恰好等于被定义项）——**“鸟是有羽毛的动物”恰好；“鸟是会飞的动物”既漏（企鹅）又超（蝙蝠）：过宽开门揖盗、过窄饿死亲兵——政策语言的死法与此完全一致：“不得携带危险物品上车”（什么不算危险？安检员的库存说了算：定义把裁量权转移给执法那一刻，它就失效了一半**）；**②不得循环**——“原因就是他引起的现象”“美就是令人审美愉悦的东西”——**循环定义是零利率贷款：印钞不生产价值；但注意“定义项与被定义项”在同一系统里的互释是常态（字典整体是循环的，只要每个词单独能被邻居救活，系统就活——恶性循环指“当场自套”，不是“万物互训”**）；**③慎用否定**——“幽默就是不高深”失败，但“单身汉就是未婚男子”“无罪就是不受指控所指向”成立——**规则的真身：被定义概念本身是否定性的，定义当然可以是否定的；否定只能定义有明确补集的类（“非 P”在 P 的边界清楚时才可用作差价**）；**④不得含混（禁比喻为定义）**——“建筑是凝固的音乐”“城市是有机体”——**比喻定义是启发式不是审计工具：它给你一副新眼镜，但不给你秤（能点亮联想，不能用于对账——作文里是好文笔，法庭里是好诗）**；**⑤次序中立（对核心词按重要性排序，别按情感排序）**——“**自由就是不受干涉地做应当做的事”里，删掉“应当”或“干涉”各得一种不同的自由：定义之争常是删词之争**。
:::

::: definition 内涵与外延：一升一降的跷跷板 {#def-neihan}
**内涵（属性清单）↑则外延（适用对象集）↓**——“**员工→按时到岗的员工→按时到岗且回复消息的员工”：每加一条属性，就有一批人失去资格（招聘广告的物理学：修饰语是筛子）**。**推论一（对偶定律）**：**想扩大豁免就减内涵（把“本校学生”改成“学员”——每一个泛称都是一扇为裁量开的侧门）；想收紧准入就堆内涵（申请材料的字数即门槛）**；**推论二（概念失灵）**：**当内涵的每一项都模糊（“态度”“相关”“适当”），跷跷板两头都悬空：外延由执词人的心情决定——这不是含糊，是权力的走私（第 1 章定义史的回声：“分类学争论九成是资源学争论”——定义权即分配权）**。
:::

::: definition 三种定义与一种妖术 {#def-sanzhong}
**规定定义**——**“本办法所称‘个人信息’，是指……”：立法者的魔术：无中生有地造一个科目（规定定义不分真假，只分好坏：好坏的标准＝有没有把后续纠纷引进来——好定义省官司，坏定义开法庭**）；**语词定义（词典型）**——报告既有库存（**词典释义是习惯的快照，不是合同的正本**）；**劝谕定义（persuasive definition）——用定义去劝，而不是去报账**：“**自由就是每个人做他喜欢做的事情的权力？还是做他应当做的事情的权力？”——同一对象、两种库存，各自带着情绪标签**：**劝谕定义=保留情感荷载、偷换认知内容（这是宣传在定义层的工艺：词汇不变、货架重排——上一课“诉诸情感”的定义学分支，识别口诀：去掉这个词的掌声/嘘声，还剩什么）**。
:::

::: example “与本门课程相关”一案 {#ex-xiangguan}
学生会章程规定：“**教材费仅用于与本门课程相关的书籍**。”期末，任课老师用教材费买了本班共读的科幻小说与一部纪录片。学生会审计：①支持方定义“相关＝考纲涉及”；②反对方定义“相关＝有助于达成本课程目标”；③老师主张“相关由授课人判断”；④有同学提议改成“**相关＝列入课程大纲附录且经三人小组签字**”。请用本章工具出具**审计报告**：四种立场各自在做什么（规定／语词／劝谕／操作化）？哪个定义让纠纷最少、哪个定义让学问最少？你的改法是什么？
::: solution
①**考纲说**＝把定义外包给另一份文件（**定义的借债：考纲自身的“涉及”未定义——债务转移不是清偿**）；②**目标说**＝劝谕／价值定义（**“有助于”外延宽到能装下一整个学期——过宽：审计失去牙齿**）；③**授课人说**＝放弃定义、移交裁量（**外延由心情决定＝权力走私；制度上最省事，学问上最贵：它把每一届都变成判例**）；④**清单＋签字说**＝操作定义（**“可测的才是操作”：审计从此可执行——但代价是“目标说”能救的那种课（一部改变一生的小说）被系统性排除：操作化是科学的税——交税能上高速，但高速不通向每一条小路**）；**审计报告结论**：分账不合并——**教材费拆两栏：“大纲附录清单内”（操作定义管）＋“共读拓展”（限额＋两人联签的裁量条款管：裁量保留但标价、留痕；定义的成熟不是消灭模糊，是决定把哪些模糊留在预算里并让它签字——精确不是美德，分配诚实才是）**。
:::
:::

::: intuition 边界案件与“精度的预算” {#int-bianjie}
**堆悖论**（一粒米不成堆、两粒……多少粒成“堆”？——**边界含糊是语言的常态而非故障：大多数概念有明亮的中心与模糊的黄昏（“秃头”“富有”“年轻”：每个社会都在黄昏里插自己的界桩——界桩是政策，不是发现**）。**维特根斯坦的“游戏”**（**找不到一切游戏共有的属性，只找得到“相互重叠的相似性之网”——家族相似：概念可以不靠定义而靠亲缘维系（第 15 课“文学是什么”的四支温度计在此露出底牌：“本质”输了，“亲缘”赢了——但注意：输掉的是“审计式定义”，不是“操作式定义”——法庭上不能靠家族相似判案，操场上可以**）。**教学结论**：**日常对话里，边界案件用类比解决（“你这算不算？它更像我们上次都同意的那个案子吗”——判例法思维就是类比逻辑：第 7 章见）；制定规则时，必须硬插界桩并承担界桩的政治（“满 12 周岁收全票”不公正，但可执行：模糊的定义不咬人，清楚的定义咬谁要事先公示）**。
:::

::: history 定义术的几次立法 {#sec-lishi}
**前 5—4 世纪** 名义正确之争（**中国：孔子“必也正名乎”——名不正则言不顺：把定义问题政治化的元年；希腊：克里底亚、安提丰一类智者把“nomos/physis”（约定/自然）摆上桌面——名与实的纠风运动在欧亚两端同时发生：都是礼崩乐坏时代的“库存重置”冲动**）；**前 4 世纪** 亚里士多德《工具论》（**定义＝属加种差的立法，并被安放在论辩的起点：先立名，再辨义**）＋墨家“**以名举实**”（《小取》：“**夫辩者，将以明是非之分，审治乱之纪……以名举实，以辞抒意，以说出故**”——名→辞→说的三层架构＝概念→判断→推理：与《工具论》同代的三级台阶**）；**清末民初 西学逻辑登陆（**严复译穆勒《逻辑体系》为《穆勒名学》（1905）、自著《名学浅说》（1909）：logic 最终定名“逻辑”——音译即术语的纯粹规定定义：一个词的诞生不过投票（“逻辑”二字打败“名学”“辩学”“论理学”：胜负靠人，不靠理——术语史是定义学的活教材**）；**1923** 奥格登与瑞恰慈《意义的意义》（**“语义学革命”的开山：定义成为哲学的日常业务，也写进了现代公民素养**）；**1930s—40s** 维也纳学派的可验证性标准（**“有意义的定义”被重新立法：形而上学句子被赶出科学车间——定义学的政教分离运动**）；**今** **“什么算加班”“什么算亲密关系”“什么算同一性别”——平台规则、法律与热搜共同成为定义权的竞标方：每个新词都是一次临时招标（“打工人”“小镇做题家”：被命名者的拒收权是定义学的新战场：命名从修辞升级为治理）**。
:::

::: warning 定义四坑
**“字典说”依赖症**（**词典是库存快照不是合同正本：拿“知识分子”的词典释义打赢“知识分子该不该纳税”的案子，是把描述当规范（第 1 课“是应当混淆”的定义版**））；**过度精度的迷信**（**把“幸福”定义到 0.001 分：精度超出测量与共识的预算即假数——“可操作的精确”优先于“漂亮的含混”，但“可操作”不等于“值得”（问卷第 3 项的平均分不是你的人生**））；**用定义终止讨论**（**“真正的 X 都会……”——No true Scotsman：当定义被加高到让一切反例自动出局，它是 immunized（）了：它不再陈述世界，只陈述自己（“真朋友从不背叛”：它保卫的是一段自尊，不是一个事实**））；**忘了定义有保质期**（**上一课：隐含前提会过期；本章：规定定义也会——“机动车”遇上了电动车、“工资”遇上了股权激励：世界改库存，法律补定义：每年都有词在搬家（词义演变是语言学的地震，定义学是防震规范**）。
:::

::: exercise 定义审计 {level=1}
给下列各条出**审计报告**（违反哪条规则／是否可豁免／改写方案）：①“幸福就是快乐的感觉”；②“健康就是不生病”；③“文艺就是文学和艺术”；④“宪法就是国家的根本大法”。
::: solution
判分：①**循环＋含混**（“感觉”本身要靠幸福来解释——快乐与幸福互为库存；豁免：作为劝谕可，作为审计不可）；②**否定式但可豁免**（“疾病”边界清楚时“非疾病”合法——但现代医学把健康理解为功能状态：外延过窄（“亚健康”无处安放）——**定义随医学库存搬家：保质期案例**）；③**循环（列举式定义）**——**列举是外延定义的合法形式，前提是类有限且可穷尽：“文艺”不可穷尽，故降级为“举例说明”**；④**同语反复（“宪法”里有“根本”）**——**语词定义可接受，规定定义需给出“根本”的判据（谁改、几票通过、可否司法援引：操作性判据是解药）**。

::: exercise 小论文：定义权与删词之争 {level=3}
写六百至一千字，评“**公共语言的年度账单上，最贵的一项从来不是新词，是被悄悄改定义的老词——词还是那个词，掌声与嘘声换了收货地址**”。须调用：**属加种差与秃鸡教训**、**相称规则（过宽／过窄）**、**劝谕定义工艺**、**操作化是科学的税**、**No true Scotsman 的免疫化条款**至少五项；并裁决：**谁有权定义“校园欺凌”这类规范性概念——学校、家长、平台、还是学生（论证你的分配方案，并给出该方案的失效条件）**。
::: solution
判分点：五项机制（**种差选层＝价值选层；宽窄＝开放与安全的对价；劝谕＝情感荷载改道；税＝可测性对丰富性的征收；免疫＝定义自保到脱离世界**）；裁决（**判分在“程序＋失效条件”双栏：参考方案——定义权分层：核心行为清单由学校（操作定义、可执行）、边界案件由听证含学生（类比与裁量、留痕）、申诉由第三方（复核）；失效条件：“清单被写满而听证被裁撤”＝纯操作化的黄昏——“当一词只有一份没有例外的清单，它已不解释世界，只在登记户口”**）；结论若写“**会吵架的人改前提，会立法的人改定义——而好公民的要求更高一层：他能指出，此刻谁正趁着大家争论结论时，悄悄修改词典**”，即 A。

::: summary
对账归档：三角（**词—心—物：你们同意这个词 ≠ 你们同意同一件事**）、规程（**相称、勿循环、慎用否定、勿比喻、删词警惕：秃鸡教训＝种差要选对层级**）、用途（**规定／语词／劝谕：劝谕定义＝掌声与嘘声的收货地址变更**）、界桩（**边界案件用类比，立法时硬插桩并承担政治；家族相似赢了操场，没赢法庭**）。方法一句话：**先问“你说的 X 按哪份库存”，再问“谁在管这份库存”**。下一章进入命题：把句子放上真值的秤。
:::
