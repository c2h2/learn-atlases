上一章的 MP／MT 管“如果”的运输；本章管“所有／有的”的运输——**亚里士多德的第一台机器：三个词、三次两两约会，中间人主持全场**。

## 定义：三个词的约会安排表 {#def-yuehui}

::: definition 标准式与中项 {#def-zhongxiang}
**三段论＝大前提（大项—中项）＋小前提（小项—中项）⇒结论（小项—大项）**（**“人都会错；苏格拉底是人；∴苏格拉底会错”——三个词各出场两次、结论只留两个：中项是婚介，撮合完就退场（“结论里出现婚介”即格式违法：中项必须消失在产品里，像糖溶进水**））。**驯化中文三步**：**①找结论定两端；②找两次露脸、从不进结论的那个当中项；③把两句压成 A／E／I／O 标准式（第 3 章的入场券）**。**中项的职能是码头**——**货船两次都要靠岸才能卸货转运：两次都没靠岸（都不周延），货就永远不知道对方存不存在**。
:::

::: definition 周延：一次点名算不算数 {#def-zhouyan}
**周延＝前提对该词的全部外延做了交代**（**A 命题管主词不管宾词：“所有人都会错”说完了“人”的全族，没敢说“会错的”里还有谁；E 两句都管；I 两句都不管；O 管宾词不管主词——四句话的“管辖权表”就是本章的变格表**）。**三大违规**：**①中项不周延**（**“狗是动物，猫是动物，∴猫是狗”——中项两次都只露了“动物”的脸：这是一座无岸码头，狗猫各泊一角，永远碰不上——中文病案：“爱读书的都善良，小王爱读书，∴小王善良”——也是同一台病机器——完整病例见例题**）；**②大项（或小项）扩大**（**“所有作弊都违规；这次处理都违规；∴这次处理都是作弊”——大前提只说作弊者全在“违规”圈里，没说圈里只有作弊者：结论把别人的房产也划进了自家地图——“前提只租了一间房，结论宣布整栋产权”：扩大就是伪造资产负债表**）；**③两个否定前提**（**“猫不是鸟，狗不是鸟”——两艘船都只领了“不在鸟区”的退货单，彼此位置依旧未知：拒绝信息不能当证据用；两条坏消息握不出一个好消息**。**补一条省钱规则**：**两个肯定前提推不出否定结论（乐观的传送带运不出悲观的货），结论是否定的，前提里必已藏了一个否定：悲观不生产，只走私**）。
:::

::: definition 四格与“第一格最体面” {#def-sige}
**格＝中项位置的四种排法**（**第一格：中项是大前提主词、小前提宾词（Barbara 型——“所有 M 是 P，所有 S 是 M，∴所有 S 是 P”：链条 S→M→P 笔直如代数代入；第二格：中项两次都做宾词（专管否定区分——“所有骗子都说谎，没有诚实的人说谎，∴没有诚实的人是骗子”：用属性划界；第三格：中项两次都做主词（专产特称——“所有鲸是哺乳动物，所有鲸都生活在水里，∴有些水生动物是哺乳动物”：用反例打破全称的专家；第四格是中世纪户口（补对称账目）**）。**亚里士多德的“完备化”工程**（**他宣布第一格两式“自明”，其余有效式都要化归回第一格才算获聘——逻辑史上第一次“标准化”：其他格只是第一格的变装；教学含义：机器的零件库可以只留一台主机，其余当外设**）。
:::

::: example 重建、图示与验伪 {#ex-chongjian}
①把“没有哺乳动物是卵生的，鸭子是卵生的，所以鸭子不是哺乳动物”压成标准式，判定格与式，并说明它凭什么合法；②用文氏图验证：“所有猫都怕水；有些怕水的动物很可爱；∴有些猫很可爱”为何无效——图里缺了什么；③补全省略式：“他居然不投赞成票，他可是委员。”——列出至少两种可补的大前提并各评一句。
::: solution
①**标准式**：没有 M（哺乳动物）是 P（卵生）［E］；所有 S（鸭子）是 P［A］；∴所有 S 不是 M［E］——**第二格 Camestres 型：中项（P）两次周延（A 的宾语不周延！注意：第二中命题“鸭子是卵生的”是 A，宾词“卵生”不周延——但本式合法靠的是 E 命题的对称换位：没有 M 是 P ⇔ 没有 P 是 M：先把 E 换位，中项就“靠了两次岸”（合法式的规则审查会放行：中项在 E 中周延；大项 M 在结论周延、在前提经换位后也周延——扩大嫌疑解除**）——**教学点：式的验伪是一台死机器，它甚至比你更知道你有没有违规（机器比它的驾驶员更知道自己有没有跑偏：它验三段论，人只负责把货摆对形状**）；②**文氏图**（**“猫⊂怕水”画实线包含；“有些怕水的很可爱”是 I 命题：记号点必须落在“怕水∩可爱”区，但该区与猫圈是否有交集图上没有保证：点可以在猫圈外——结论要“有的猫可爱”，图里却无处落点：反过来定义更清楚——有效＝反例无处容身；图示的价值正是让无效变得可见**）；③**省略三段论**（**候选大前提：A“委员都投赞成票”（他违了组织规矩）；B“委员都是明白人”（他不明智）；C“他不投，说明有意见”（把行为读成态度）——三种补法得出三种指控：省略式是立场的藏身处，补全就是把藏身处改成营业厅（修辞学原理：亚里士多德说省略式是“修辞的完整个体”——因为听众自己补前提，被说服显得像自己想通：省略是礼貌，也是藏赃**）。
:::
:::

::: intuition 机器与母语：中文的驯化难点 {#int-muyu}
**三段论假设每个句子都有一个确定的主词**——**汉语的主题句偏不（“这本书看了三遍了，很好”——主词？受事？施事缺席，“很好”评的是书还是“看”的体验？主词不锁定，周延就无从谈起：中文系学生的逻辑补习重点不在规则，在“说谁”的判定（把主题句改写成主谓式是现代汉语与逻辑的合资工程——“这篇课文我教了三遍”＝“我教这篇课文教了三遍”：补出主词才算上秤**）**。**量词藏在形容词里**（“**年轻人爱冲动”像 A 实为 I：通说化即违规：把概称读成全称，一次逆否就翻车：“年轻人爱冲动；他不是年轻人；∴他不会冲动”——否定前件借道概称句还魂（第 4 章死法与本章周延的联合病例）**）。**教学结论**：**规则是死的，中文是活的：本章的全部技术可以浓缩成一次翻译——把活人说的话翻译成三个词的约会表，翻译完成，对错自动显形；翻译不了的地方（歧义、主题漂移、概称），才是真正要吵的问题。
:::

::: history 一台机器的两次改装 {#sec-gaixie}
**前 4 世纪**《前分析篇》（**格与式的穷举＋“化归完备”：第一次让“推理正确性”成为可以清点的东西**）；**泰奥弗拉斯托斯**（**通说：把关系推理（“A 在 B 之左，则 B 在 A 之右”）并入逻辑的账本：三段论体系之外的第一批外挂**）；**中世纪**（**助记诗 Barbara、Celarent……六式名沿用至今：经院学者把机器拆成规则证明定理的完备性——“规则的机器”与“机器的规则”两手都硬；因明并行线：陈那、法称“因三相”（因必须在同品定有、异品遍无）——与周延理论异曲同工而路径不同：希腊管词项的管辖权，印度管属性的正反清单**）；**1772** 朗伯《逻辑学》（**三段论公理化的先声：把诸式归约到少数基本律；同一时期康德留下“从亚里士多德起未前进一步”的著名断言（后人概括的常引大意）——这句话本身成了 19 世纪革命的背景板**）；**1847—54** 布尔（**代数化：类方程吃掉三段论——“所有 S 是 P”写成 S＝SP：机器被拆成算术，19 世纪的人用符号给老机器做了换心手术**）；**1879** 弗雷格（**量词上线：三段论降级为谓词逻辑的一个小区块——但小区块成了中学课本的门面：最窄的逻辑教给了最多的人（教学法常与学术史反向行驶**）；**当代**（**三段论活在数据库查询的祖谱里（交集、子集、补集的语法是它的方言），也活在每一场“以偏概全”的指控里——指控“个例当全体”＝控告中项不周延的现代庭审**）。
:::

::: warning 三段论四坑
**把机器当世界观**（**日常论证大多不是直言三段论：概率、因果、价值各用各的逻辑——本章是入门解剖的蛙，不是蛙的全部生活（第 6—8 章各有一台别的机器）**）；**周延背成口诀而不背理由**（**口诀问“管没管全部”，理由只有一句：你谈的是它全家，还是它家几口——懂理由的人临场能自查，背口诀的人换个句式就断电**）；**用集合词偷换个体词**（**“鲁迅的作品不是一天能读完的；《故乡》是鲁迅的作品；∴《故乡》不是一天能读完的”——中项看似露脸两次，其实第一个“鲁迅的作品”是集合整体、第二个是其中一本：一台机器里藏着两个中项——四条腿的三段论是畸形（第 2 章库存问题在格子里的发作：四词三段论＝歧义的现行犯**））；**拿“都合法”当“都真”**（**式合法＋前提真实才可靠：三段论不能把假前提炼成真结论，它连一克事实都不生产（第 4 章：形式不生产水**）。
:::

::: exercise 验钞机 {level=1}
把五个推理压成标准式并用规则验伪（指认违反的具体一条）：①“鲸不是鱼，鲨鱼不是鱼，所以鲨鱼不是鲸”（注：结论碰巧为真）；②“爱读书的都善良，老李不爱读书，所以老李不善良”；③“有些公务员是党员，有些党员是学者，所以有些公务员是学者”；④自造一句“中项四腿”病句；⑤写一个**第二格**有效式并翻译成一句中文。
::: solution
判分：①**两否定前提无效——结论碰巧为真不等于推理合法：合法管运输，真管货物，一家事务所只签一张单**；②**有效：“爱读书→善良”＋“老李不善良”：MT 的三段论化（否定后件的直言版，第二格 Camestres 家族：合法且前提可查）**；③**两个特称（I＋I）推不出任何东西：中项两次不周延的必然后果——“有些”配“有些”，婚介从不上岸**；④自造四词句判“**中项歧义＝两个中项合谋：腿数不对，机器散架**”；⑤第二格（中项两次做宾词、必有一否定前提）中文示例：“所有合同都要签字；这份条子不要求签字；∴它不是合同”——**判分在“式合法”与“中文自然”双栏**。
:::

::: exercise 主题句翻译 {level=2}
把五条中文流水句改写成**可判周延的主谓标准式**：“这瓜吃了不闹肚子”“论文写了三稿还是乱”“这件事处理得不合适”“内容没问题，排版太挤了”“孩子大了就说不得”。并标注：主词到底是谁、原句藏了什么量词。
::: solution
判分示例：“**这瓜吃了不闹肚子”＝“任何人吃了这瓜都不会闹肚子”（主词从“瓜”滑向“吃的人”：受事主题句把施事藏进动词——量词“任何”凭空出现：周延表立刻要重画**）；“**孩子大了就说不得”＝“对所有孩子：一旦其成年，则不可劝”（全称藏在无标记里——概称句的读法之争就是第 3 章限定词账户的存款之争**）；每句指出**改写损失了什么**（口语的亲昵与免责：主词锁定＝责任认领——汉语的模糊不是缺陷，是把签字权留到现场的策略（语用与逻辑的分工：逻辑要签名，中文讲默契）。
:::

::: exercise 小论文：三段论是逻辑的拉丁文法 {level=3}
写六百至一千字，评“**三段论像拉丁文法：规则繁琐、终身无用，却教会后人一件事——推理的正确性写在格式里，不写在内容里；这门‘必修课’后来被弗雷格接走，改造成了程序员的母语**”。须调用：**中项码头与周延**、**三大违规至少各一案**、**格与化归（标准化）**、**省略三段论的修辞学**、**布尔—弗雷格的改装线**至少五项；并裁决：**今天还该不该教三段论——它是思维体操、文化遗产，还是错误分类的化石（给出你的课程表方案与失效条件）**。
::: solution
判分点：五项机制（**码头＝关系的隐喻；违规＝资产负债表审计；化归＝标准化即权力；省略式＝被说服的自我错觉；代数化＝机器换心**）；课程表裁决（**参考：体操论——规则训练“管辖权”直觉，迁移到概率与法律推理；遗产论——它是理性主义的世界遗产，博物馆意义≠车间意义；化石论——自然语言里直称三段论命中率极低，教学时长应让位给概率与统计谬误——三案都要写失效条件（狠一点的判法：只考“识别式”的课是文化遗产，要求“重建与验伪”的课才是体操——只养前者，本课就是化石**）；结论若能写“**三段论真正的遗产不是那十九个式，而是那个惊人的想法：正确性可以不问内容、只看排列——这个想法后来长出数学、逻辑学，最后长出计算机：文法死了，格式活着**”，即 A。

::: summary
机器归档：约会表（**三词六次出场，中项撮合完必须退场**）、周延（**管全家还是管几口：中项要靠岸、扩大即伪造、否定不握手**）、格（**第一格主机，余皆外设：标准化即权力**）、图示（**无效＝反例无处容身的反面：点上无处可画**）、母语（**主词不锁定则一切免谈：先翻译，再验伪**）。方法一句话：**把话翻译成格式，让机器替你吵架**。演绎两台机器（联结词＋三段论）竣工；下一章换燃料：或然性——归纳与类比。
:::
