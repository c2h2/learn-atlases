---
title: "因果推理"
---

上一章的五法给出嫌疑名单，本章开庭——**“A 导致 B”是逻辑里最贵的断言：别的句子要证据，它要的是机制、对照与排除；而它的待遇也最特殊：全媒体日理万机，天天在未经审判的情况下执行死刑**。

## 定义：为什么这句最贵 {#def-zuigui}

::: definition 因果断言的三张保单 {#def-baodan}
**“导致”声称的不只是“一起出现”，而是“动了它会变”——它押出三张保单**：**①时间序**（**因在果前——注意只是必要条件：先到的还有排队号与谣言**）；**②共变法**（**动因则果动：剂量、时点、去除干预三处都要应声（第 6 章共变法的正式出庭**）；**③无混杂**（**除它之外没有别的解释同样能对上账——这一张最贵：它要求你认识所有嫌疑人，包括没到案的**）。**举证责任分配**（**断因果者投保单，质疑者点嫌疑：日常讨论里谁先说“导致”谁先交保证金——媒体标题把“相关”升格“导致”是惯常的无证驾驶，而读者的转发是共犯结构里的免费司机（第 2 章劝谕定义的亲兄弟：导致是定义学骗术的因果版**））。
:::

## 相关的四个出口 {#def-siku}

::: definition A 与 B 同现的四种案情 {#def-chukou}
**①A→B**（**正解之一**）；**②B→A**（**反向因果——“常喝无糖饮料的人更胖”：是想瘦的人在换饮料：因果箭头常常被数据的方向盘骗过去（用“喝无糖”预测“体重”，等于用雨伞流量预测暴雨：雨伞不是天气的因，是天气的果——顺带一提：把反向说通，也是因果断言：审案要审方向，不只是审有没有关系**））；**③C 同时导致 A 与 B**（**混杂变量——“吃早餐的孩子成绩好”：家庭作息、父母学历、早餐桌的存在本身都是共犯（“每天有人叫你起床并准备食物的孩子”，他的“被照顾”才是主犯：第 6 章求异法的软肋在此开庭：找不到那块“同一块田”，你就只能承认自己在看戏不是在做实验**））；**④纯属巧合**（**样本量一开派对，必然有人同框：冰淇淋与溺水、耐克销量与股指、页数与书名长度——巧合不羞耻，把它写成因果才羞耻（“相关是廉价的：廉价时当免费，昂贵时才发现是收费（把巧合收进理论，理论就要替你交税：一条错误因果链能骗几十年——“早结婚所以幸福”的自传式论证就是常驻案犯**））。**审问模板**（**同现时先问四句：谁先谁后？动它会变吗？有没有第三个它？会不会只是巧？——四句问完，多数标题党当场结案**）。
:::

::: definition 怀疑清单：被告的合法辩护词 {#def-huaiyi}
**回归均值**（**极端分数之后自然回中——飞行教官的毕生错觉：表扬了学员下次就退步、批评了下次就进步，于是坚信“批评有效、表扬有害”（卡尼曼讲的空军教官通说）——真相是成绩本来就会往中间漂：把钟摆的_return_ 当成自己推的力（教育、管理、中医“见效”、球队“换帅如换刀”全在此列：任何按“极端值”筛选出来的对象，下一步都大概率变普通——“请大师驱过鬼的股票涨了”——大师与均值回归谁之功，需要对照组才能分赃**））；**选择偏差**（**去过的餐馆都好进“必吃榜”：门槛本身就是原因（第 6 章幸存者的堂兄弟：样本是自己投的，成绩当然配合演**））；**发表偏倚**（**有效实验进了论文库，无效实验进了抽屉：文献综述是在 spotlight 下数人——“荟萃分析给出了确定结论”要问：抽屉里有多少具尸体（阴性结果不发表，效应量自然虚胖——科研界的沉没成本会计**））；**安慰剂与期望效应**（**“吃了就精神”：连药盒的颜色都在给药——双盲的哲学意义：连被试的自我报告都不能信，因为自我报告会配合期待（“‘我觉得有效’是证据链上最软的环节——不是撒谎，是人本来就会配合自己的期待：这是自述数据的原罪，不是自述者的道德问题**）。
:::

::: example 三桩新闻标题：现场开庭 {#ex-kaiting}
**庭一：“研究发现：常运动的人抑郁更少。”**（媒体结论：运动抗抑郁）**庭二：“读研数量增加的城市，咖啡馆也增加——知识经济带动咖啡消费。”**庭三：“该疫苗上市后不良反应报告上升，故应停用。”**——分别指出：四出口在哪、缺哪张保单、能下的最强判决是什么。
::: solution
**庭一**（**正解可能真（运动机制可信：神经、社交、作息多条通路——但观察研究里“抑郁的人不运动”是标准反向通道：抑郁先剥夺动力，再剥夺跑鞋；最强判决：“运动与抑郁负相关，机制合理，随机对照试验（部分已做）显示中等效应”——能下“对部分人有效”，下不了“运动抗抑郁”的万能句；缺失：无混杂保单没签全（运动者往往同时不吸烟、收入更高）**）；**庭二**（**同现确实，箭头最弱：城市规模/高校/人口结构是现成的 C；咖啡馆是大学城的影子不是钱包的流向——判决：“相关成立，因果无据”；补案：同城同时段对照（大学周边 vs 产业园周边的咖啡馆增速差——差分法：政策评估的经济学家靠这一招把“同一块田”借了回来**））；**庭三**（**最难的一桩：不良反应报告上升可能全是③＋监测加强（上市后才有人盯着打疫苗的人：报告率≠发生率，这是被动监测的原罪——“疫苗犹豫”的经典配方：用“报告增加”证“疫苗有害”，再用“不接种”的对照数据证明它无害——两个数据都真，判决相反：缺的是分母**）；**最强判决：“需要主动监测与年龄匹配对照，当前证据不支持停用，支持加强追踪”——注意这种判决的语言特征：它不裁决情绪，只裁决下一步该采什么数据（因果推理的终点常常不是结论，是更好的取证方案**）。
:::

::: intuition 实验是人为的未来 {#def-shiyang2}
**随机对照为什么是黄金标准**（**随机化是唯一一台“用骰子造同一块田”的机器：两组在进入前统计上全等——于是进入后的差异只可能来自被摆弄的那一个变量——“阿司匹林与心梗、小额现金补助的实验、教育干预的随机试点：20 世纪后半叶，‘随机’成了因果知识的印钞机（兼得罪人机器：实验不能做的（种族、贫富、气候），因果知识就只能靠准实验与自然实验借来的腿走路**）。**能实验时要实验，不能实验时学会标注**（**把观察结论说成“相关＋机制猜想”，把实验结论说成“因果＋范围限定”——语言的税率表：你越接近因果，越要缴纳审慎税（免税的只有数学）**）。**古代的近亲**（**中医“效案”传统与密尔求异法的隔洋相望：没有随机化，“同病异治、异病同治”的对照智慧仍在挣扎着逼近控制变量——教训不是嘲笑古人，是看清：控制的思想到处都有，缺的从来只是制度化的实现手段（今天的 A/B 测试把它制度化到了你每次点“下一页”**）。
:::

::: history 因果审美的现代化 {#sec-xiandaihua}
**1748** 休谟《人类理智研究》（**因果不是理性发现的，是习惯性期待：必然性从对象里收回，存进了心里——第 6 章风俗主义的因果分店（这一判决逼出了康德的先验反击与 20 世纪的因果哲学百年诉讼**）；**1747** 林德坏血病试验（**海上十二名病人分六组接受不同添加——史称最早的有记录分组对照：因果知识的出生证明比它的哲学辩护晚不了多少，且一辈子没打赢过哲学官司：实验照样赢，因为它的裁判是病人活没活下来**）；**1854** 斯诺的霍乱地图（**宽街水泵：不靠病菌理论、不靠随机试验，靠地图与“没到案的水”定了案——自然实验与剩余法的教科书演出（微生物学随后赶到，给判决补上机制：流行病学先破案，实验室后取证——因果与机制两条腿的分工现场**）；**1948** 随机对照试验进入临床试验（**链霉素试验的通说里程碑：双盲从此是药物审批的成人礼——20 世纪“因果的官僚化”：想断因果，先过表格**）；**1950s—60s** 希尔（Hill）判据与因果哲学复兴（**“吸烟致肺癌”的世纪审判：没有随机试验（不能让人抽签吸烟）、机制当年不全，图尔敏与希尔各自给出了“在或然中定案”的标准（希尔判据：强度、一致性、剂量、时间、机制等九问——像侦探小说的评价表，不是定理；但表上打钩够多，烟草业就败诉了**）；**1970s—今** **结构因果模型与“因果革命”（珀尔《因果论》通说：相关、干预、反事实三层各配一门数学；工具变量把观察数据里的“借来的腿”做成了正规义肢）——“逻辑课本里的‘求异法’长出了 do 算子：农学问题变诺贝尔奖（2021 经济学奖的因果推断版图**）。
:::

::: warning 因果四坑
**滑坡的因果链收费**（**“允许 A，就会 B、C、D 直到世界末日”——链条强度＝最弱一环，而修辞按第一节链条收十节的费：审法是逐级问概率并明码标价（“每一步 0.9，第十步 0.35：滑坡不是不可能，是不免费：要算复利**））；**单一原因癖**（**事故调查、成绩下滑、王朝覆灭：人脑偏爱一句话说完——“根本原因”常常是“我们懒得列清单”的别名（充分原因族、必要原因族、差异原因：同一件事三种问法三种答案（第 15 课“一千年账本”的简化版诱惑在此开庭**））；**分母失踪**（**“死亡报告增加”“投诉暴涨”“某病高发”：没有分母的分子是修辞不是数据（第 8 章图表课的预演：先问总数、基数、监测强度**））；**机制迷信**（**反过来的坑：“说不出机制所以无效”——阿斯匹林镇痛机制几十年后才有，斯诺定案时不认识病菌：机制是加分项与解释项，不是因果的必要条件；同样，“机制听着合理”也救不了反向因果：两条都要防**）
:::

::: exercise 三句话验尸 {level=1}
对下列断言各写一份**一百字验尸报告**（箭头方向／混杂候选／缺失保单／可下的最强结论）：①“刷短视频时长越长，注意力越差”；②“用我们 App 的城市投诉处理更快”；③“坚持写日记的人更幸福”。
::: solution
判分示例：①**双向都合理（注意力差的人更爱低阻力刺激；也可能被剪辑节奏损害——方向未定；混杂：睡眠、年龄、抑郁；最强：“剂量相关的负相关，方向待纵向研究”）**；②**销售页因果（客户自选择：管理好的城市才买得起/愿意买；分母缺失：处理快慢的定义？最强：“购买决策与快城市相关”）**；③**幸福的自选择＋回忆偏倚（幸福的人更记好事：测量工具本身就是混杂；写日记是唯一“几乎免费”的干预，可以小试点，但对照难盲（知道自己写没写：心理试验的诚实税**）。
:::

::: exercise 设计一个最便宜的判决 {level=2}
把①改造成一个**你能负担的实验或准实验**：随机分组的伦理与技术障碍、可借用的自然实验（版本更新？学期节奏？）、预注册与多重比较的陷阱——写出方案与它“能支持的结论上限”。
::: solution
判分：**分组与剂量可控**（**不能禁手机，可以限时段或推送关闭——干预要能落地**）；**测量盲法**（**注意力用任务成绩而非自评：自报告会配合期待（怀疑清单第 4 条的实战**））；**预登记**（**先声明结局指标，防抽屉效应（发表偏倚的个人版：人会悄悄只报显著的那个**））；**结论上限**（**单一人群短期干预：“关闭推送两周可改善注意力任务成绩”——外推到“短视频毁掉一代人”仍是贷款：结论的上限写在样本的户口上（第 6 章广场定律的因果分店**）。

::: exercise 小论文：因果税 {level=3}
写六百至一千字，评“**现代社会把‘导致’变成了需要纳税的断言：随机试验、分母、预注册、机制审查就是税务局——逃税者用‘大家都觉得’完税，于是舆论场成了因果的地下钱庄**”。须调用：**三张保单**、**四出口至少三用**、**回归均值**、**分母失踪**、**希尔判据的定位**、**“能实验就实验／不能就标注”**至少六项；并裁决：**“因果知识只配由做过随机试验的人发言”是否公平——专家的垄断与公众的知情权之间，语言的税率该怎么定**。
::: solution
判分点：六项机制（**保单＝举证清单；出口＝审问模板；均值回归＝管理迷信的解药；分母＝数据的户口；希尔＝或然定案的清单而非定理；标注＝语言的税率**）；裁决（**参考：专业发言权论——因果断言技术性强，非专家易被“报告数”带节奏（庭三现场）；民主知情权论——政策必须被公众审，税率定得太高＝专家垄断，历史上“疫苗安全委员会”式的封闭同样翻过车；判卷在折中方案（把结论翻译成公众可审的语言＝科学传播的义务；公开数据与预注册＝把税务局变成透明车间：“认证不能替代问责，只能更换问责的货币”）**）；结论若能写“**说‘我不知道’不是失败，是把因果税单开对了位置——逻辑课教到最后，教的是一种语言的节制：知道哪句话要交税、哪句话在逃税、哪句话根本不配上账**”，即 A。
:::

::: summary
庭审归档：三张保单（**时序、共变、无混杂——第三张最贵**）、四出口（**正、反、共因、巧合：四句问完，标题党当场结案**）、辩护词（**均值回归、选择偏差、发表偏倚、安慰剂**）、实验（**骰子造同一块田：不能实验时学会标注**）、判据（**希尔九问：像侦探小说的评价表，不是定理**）。方法一句话：**断因果先投保单；投不起就明写“只是相关”**。因果法庭闭庭；下一章去案发现场的外面：如何评估你根本没参与的那份信息。
:::
