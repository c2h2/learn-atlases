---
title: "论证的结构"
---

逻辑课本通常从“什么是逻辑”讲起；本课从一句更狠的话讲起：**“我觉得我说的有道理”不是论证，复读机也能“我觉得”**——**论证是推理的成品，本课教三件事：拆开它、检验它、重建它**。

## 定义：论证的最小骨架 {#def-gujia}

::: definition 前提、结论、推断标记 {#def-qiant}
**论证＝一组陈述：一些前提（premises）声称给另一陈述（结论，conclusion）以支持**。三件解剖工具：**①结论定位器**（**因此、可见、这就是为什么、综上所述——结论的门牌号；注意“因为”永远指前提，“所以”永远指结论——中文语病的重灾区是“之所以……是因为……”的连环（“我迟到的原因，是因为闹钟坏了”——“的原因”与“因为”重复开票：语法错误里藏着逻辑懒惰**）；**②前提指示词**（**由于、根据、鉴于、既然——以及最阴险的“零标记”：两句并排，靠读者脑补支持关系（“他平时用功，这次没考好”——是解释？是反驳“努力必有好成绩”？还是纯叙事？零标记句要求你先补出“他认为……所以……”**）；**③推断关系≠心理顺序**（**人说话先说结论还是先说理由随心情；逻辑只认支持方向：前提→结论，与时间、语序、音量无关（“我反对，因为我不接受”——两个句子互为回声：这不是论证，是原地踏步的轮盘——识别“同语反复”是第一课的眼镜**））。**非论证黑名单**（**祈使句（“把证据摆出来！”）、疑问句（“这难道不是撒谎吗？”——修辞问句是论证的cosplay）、单纯断言的堆叠（“他不诚实，政策也失败，媒体还腐败”——三个主张零支持：列举不是论证，口号不是推理**）。
:::

::: definition 论证与解释、说服、争吵 {#def-biejia}
**论证 vs 解释**（**同一事实，两种问题：“为什么”问原因（解释）或问理由（论证）——“铁桥断了因为超载”是解释；“这座桥该修，因为它超载过”是论证：解释从已知出发往回找原因，论证从已知出发往前立结论（第 15 课的“说了什么 vs 做了什么”在此落地：解释不要求你相信新东西，论证要求**）；**论证 vs 说服**（**修辞学用性情与境遇说服（亚里士多德的 ethos/pathos/logos 三诉），逻辑只审 logos 一支——本课不禁止动人的结尾，只禁止用动人偷渡前提（“你能被感动，所以你被说服：眼泪是说服的收据，不是论证的发票”**）；**论证 vs 争吵**（**争吵的验收标准是赢，论证的验收标准是“双方都可能错”：争吵每回合淘汰证据，论证每回合登记证据（“立场先行的人不是在论证，是在打官司：他的前提都是聘请来的”**）。**钢铁人原则**（charity 的中文正确译法应是“原情原则”或干脆叫**“钢铁人”：先把对方的立场补到最强，再去反驳——打稻草人是快乐但零收益的活动：你推翻的每一个弱化版，都没能帮对手改进他的武器**）。
:::

::: example 群聊截图解剖 {#ex-qunliao}
把一段常见争论拆成标准式（编号前提，标“∴”出结论），并回答其后三问：
甲：“**抽烟导致肺癌，我爷爷抽到九十岁好好的，所以‘导致’是骗人的。**”
乙：“**你不能这么说，医生都不抽烟。**”
丙：“**你不就是烟厂的吗，别洗了。**”
①甲的论证：前提与结论各是什么？**哪一步出了问题**（样本？还是“导致”的含义？）；②乙的论证补出隐含前提后成立吗；③丙给了什么（论证？还是别的什么东西）；④如果甲改口：“**我认识两个人抽到九十没事——所以抽烟‘必然’致癌说不通**”，他的胜率变化多少？
::: solution
①**甲的标准式**：P1 抽烟导致肺癌（作为“人人抽必病”的强解读）；P2 我爷爷抽到九十且健康；∴ 并非“导致”。**病灶有两处且要分开判**：**样本层**（个案可以反驳全称命题——若 P1 被读成“凡抽烟必早亡”，爷爷一个样本就够（反例的逻辑效力是满格的——**本课重要律令：个案不能确证规律，但完全可以证伪全称：归纳的不对称性**）；**语义层**（甲真正的靶子其实是“导致＝必然致人于病”的通俗误解——**他赢了一个稻草人：统计学意义的“导致”（相对风险升高）根本没有被碰倒**）——**一个论证可以同时“有效”（若按强解读则形式正确）且“不相干”（打的是没人主张的版本）：有效性与相关性是两道独立的验收**；②**乙省略三段论**：隐含前提“医生（都/大多）不做有害健康的事”＋“他们不抽烟”→ 抽烟有害；**隐含前提本身要过堂**（医生不抽烟≠抽烟致病？这里靠的是“内行示范”的诉——诉诸权威，但属于合法权威域：医学对肺癌的相关权威；合法与非法只差在“域”上**）；③**丙什么都没给**（**对人攻击（ad hominem）：质疑来源利益不等于反驳主张内容——但注意分寸：丙的话作为“证据权重提示”有微弱作用（查他的利益），作为反驳则分文不值（烟厂工人也可能说对话）——本课术语：诉诸人身是“相关性归零，权重可给 0.1”**）；④**改口版更强**（把结论从“导致是骗人的”降为“‘必然致癌’说不通”——**结论缩水，前提撑得住了：这就是“论证强度与结论胆量的反比定律”：会认怂的论证往往更抗打）。
:::
:::

::: intuition 论证是可审计的叙述 {#int-shenji}
把论证想成**带凭证的账本**：前提＝入账凭证，推断规则＝记账法规，结论＝报表余额——**审计只看两件事：凭证真不真（前提的真）、记账合不合法（推断的效）**（**余额错了可以是凭证假（前提假）也可以是记错账（无效）：两种批评不可混用（“你前提不真”与“你推不出”是两家事务所的业务）**）。**由此引出本课总公式：好论证＝可靠（sound）＝有效（valid）＋前提真**——**有效只保证“若前提真则结论必真”的传送带完好；传送带不生产真理，它只运输（第 4 章的定义：有效性是保真性）——这也是逻辑课与“道理课”的区别：逻辑不管你的起点高不高，只管你的路有没有断**。
:::

::: history 论证研究的四条战线 {#sec-sixian2}
**前 4 世纪** 亚里士多德《工具论》（**论辩术的立法：《辩谬篇》是第一本“谬误案例集”——人类最早的“差评汇总”**）＋中国墨家《小取》（“**辟也者，举他物而以明之也；侔也者，比辞而俱行也；援也者，曰：子然，我奚独不可以然也？推也者，以其所不取之同于其所取者，予之也**”（《小取》）**——四式：举例（辟）、类比（侔）、以子之矛（援）、同类相推（推）——战国即有完整论式学，比《工具论》只晚一代人**）；**中世纪** 逻辑作为大学三科之首（**论辩的经院体操：现代论文“反驳—回应”结构的祖先**）；**1958** 佩雷尔曼《新修辞学》（**“论证理论从证明领域回到或然领域”——听众分为“普适听众”的设想：给说服装上理性假肢**）；**1970s** 非形式逻辑运动＋图尔敏模型（**主张—根据—保证—支撑—限定—反驳六项（Toulmin 1958）：法学家的论证解剖刀——为什么课本要讲“限定词”：因为日常论证的强度几乎全藏在“通常、大概、在……条件下”里（第 3 章命题的模态，此处预告**））；**1940s—今** 论证与人工智能（**可废止逻辑：法律与常识推理允许“例外推翻”——机器开始学“理不辩不明”，也学“话不说绝”**）；**中文系一侧的暗线**（**从《墨辩》到清儒的“文理”（刘大櫆、姚永朴讲“如何句住、如何转掉”——文章学里沉睡的逻辑：本课的任务之一是把它叫醒，但不替它招魂：逻辑学是解剖学，八股是舞蹈，两者都要，别互认**）。
:::

::: warning 论证入门四坑
**把“有道理的感觉”当论证**（**通顺≠有效：汉语的“因为……所以……”连接两个都可能是幻觉的从句——语感是统计的产物，逻辑是统计的审计员**）；**把反驳当争吵**（**“你说得不对”之后必须有内容：只否定不重建的发言是路障不是工程（第 6 章：驳论是技术活——先把对方的立场补到最强再打）**）；**给一切找“逻辑”**（**“她不喜欢我，因为今天没回消息”——形式完整、前提稀烂：逻辑救不了原料（传送带完好不代表货是真的——第 1 节的两家事务所别搞混）**）；**滥用术语砸场**（**“你这是滑坡！”“偷换概念！”——贴标签是零成本的伪反驳：谬误指控本身需要论证（它先要正确复述对方的论证——钢铁人原则对指控者同样生效**）。
:::

::: exercise 标准式重写 {level=1}
把三条日常断言改写为**标准论证式**（P1、P2……∴结论），并**补出被省略的隐含前提**：①“别信他的评测，他收了广告费”；②“这道题老师讲过，所以不会不是你笨”；③“这家店好评那么多，走吧”。
::: solution
判分：**每问两条以上前提**（含补出的隐含——①的隐含“收钱会影响评测客观性”＋“该评测属于此类”）；**结论与前提支持方向一致**（②的隐藏前提链：“讲过→应该会；不会→应该复习；你都没走通→归因只剩‘笨’？”——补全之后自然看见哪里断链（**“归因穷尽法”其实没穷尽：题难、时间、粗心——本课下次课“排除法”见**”）；③的隐含“好评数量＝质量”（**刷单制度存在，故该前提在 2020s 的电商环境里权重下调——隐含前提是有保质期的**）。
:::
:::

::: exercise 谬误预审 {level=2}
收集三条真实网络言论（截图或自写拟作），**互相交换做“预审”**：重构标准式→指认问题类型（前提假／无效／不相干）→写一句“钢铁人式反驳”（先把对方的最强版本复述一句，再打）。
::: solution
判分：**复述环节强制**（复述不出对方立场者不得进入反驳——**教练规则：说不清对手，就上不了场**）；类型判定允许多选但要给“主要问题”；钢铁人反驳里若出现“即使按你最强的说法……仍然……”句式，满分（**这是本课的规格句式**）。
:::

::: exercise 小论文：逻辑是礼貌还是暴力 {level=3}
写六百至一千字，评“**逻辑教人讲理，但‘我们来讲讲理’这句话本身常常是不讲理的开始：它假装双方在起跑线，假装裁判中立，假装结论敞开**”。须调用：**论证≠说服≠争吵**、**钢铁人原则**、**可靠＝有效＋前提真**、**隐含前提的保质期**、**术语滥用坑**至少五项；并裁决：**在亲密关系、哀悼、审美三类语境里“要逻辑”是否失礼——逻辑的适用边界由谁划定**。
::: solution
判分点：五项机制（**起跑线幻觉＝“论证≠说服”：修辞三诉从未退场；裁判幻觉＝前提里早已嵌入立场；“你讲理的样子”也是一种 ethos 表演；钢铁人＝对立面要求你诚实的反向训练；保质期＝逻辑的历史社会学入口**）；裁决（**参考路线：失礼论——哀悼与爱里有“非论证的正当表达”（拥抱不提供前提），要求逻辑＝把关系拖进错误的文类（第 8 章：文体合同用错）；边界内在论——所谓“不讲理时刻”恰是逻辑的作业面：识别对方此刻签的是哪种合同（陪伴合同？），误用逻辑本身就是逻辑不及格（“逻辑的适用边界”是逻辑问题——元层不豁免**）；结论若写“**逻辑真正的礼貌不是随时开审，而是知道什么时候该放下法槌——并且清楚自己是放下了，还是压根没有**”，即 A。

::: summary
骨架归档：三件工具（**结论定位、前提指示、支持方向≠心理顺序**）、辨析（**解释往回找、论证往前立；眼泪是说服的收据不是发票；争吵淘汰证据，论证登记证据**）、审计公式（**可靠＝有效＋前提真；两家事务所别混）、墨辩（**辟侔援推：战国就有论式学**）。方法一句话：**先重构，再指控；先钢铁人，再拔剑。下一章立靶子：什么是“论点”——一句话怎样才算“值得证明的话”。
:::
