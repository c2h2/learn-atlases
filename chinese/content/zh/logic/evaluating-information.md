前七章审的是“你手上的论证”；本章审**你根本没参与生产的那些话**——**一个成年人 99% 的知识来自证词（别人说的），因此逻辑学的最后一课不是怀疑技巧，是信任的经济学：你不可能检查一切，所以必须学会决定何时检查、相信到什么额度**。

## 定义：信赖是默认值，怀疑是预算 {#def-yuzhang}

::: definition 认识论的分包制 {#def-fenbao}
**“怀疑一切”在认识论上是不及格，不是美德**（**你关于世界的大部分“真相”——南极存在、疫苗原理、去年GDP——只能靠可信来源的转包合同（**证词（testimony）是知识的正当来源之一：哲学史上它为“还原到亲身经验”的幻想陪葬了很久，现实里它是文明的承重墙（**“一切知识要自己验证”=每个人都重新发明轮子的苦行僧式的认识论：它真正的病灶不在信任，在选错信任的对象与额度**））；**于是本章的真问题**：**怀疑是一种昂贵资产，要按“出错的代价”分配**（**“股票荐言错了亏钱”值得查到底；“某明星离婚内幕”错了只损失谈资，认真即上当（第 7 章“分母失踪”的认知版：你的注意力才是那个总预算**））。**分工社会的诚实姿势**（**不是“我都信”，也不是“都不信”，而是“我知道我信的是哪一级、在哪个环节可以升级核查”——把信任做成有档位的变速器，而不是全通或全断的开关**。
:::

::: definition 信源四问 {#def-siwen}
①**谁说的**（**具名机构、认证个人、匿名“知情人士”、还是“网友说”——匿名不是原罪，匿名的成本归属才是：“知情人士称”把断言的成本转给读者、把受益留给消息源——谁免单，谁受益**）；②**凭什么说**（**一手研究、官方公报、还是“我朋友在医院”——第 6 章的广场定律在此有了机构版本：每个来源都有自己的“广场”——卫健委的广场里全是病人，健身房的广场里全是肌肉**）；③**说给谁听**（**答辩、财报、讣告、招聘启事都是真话，只是穿了制服：体裁决定滤镜（第 8 章修辞回访）——“论文致谢里的感谢”与“招股书里的风险章节”是同源不同信的两种文本**）；④**没说什么**（**沉默是消息源递来的第二份文件：只报涨幅不报基数的股价快讯、只放冠军奖杯的宣传片——“选择性真实是所有谎言里最耐查的一种：它每个字都真**）。
:::

## 证据等级与引证通胀 {#def-dengji}

::: definition 金字塔与它的中文应用 {#def-jinzi}
**循证医学的证据金字塔**（**塔尖：系统综述/荟萃分析（把全球试验再当数据分析）；中段：随机对照试验；塔基：专家意见、个案报道、体外实验（这个等级表的哲学内容：越往下，混杂保单越没人签——第 7 章判分官换了个制服出现在医院里**）。**中文日常应用不是背金字塔，是学它的“再分析优先”原理**（**“有研究”与“关于研究的综述”不是一级证据；“动物实验显示”离你的嘴的距离＝体外→小鼠→临床→剂量四跳（科学新闻的变形记：每一跳都被标题吃掉——“巧克力助减肥”类骗局的标准死法：把小鼠的乙醇提取物翻译成人间的零食**））。**引证通胀与循环引证**（**三家平台“据外媒报道”其实是同一家通讯社伪装出三个人的复数幻觉；被转载数字在旅行中长大（“初步统计”到“官方数据显示”只差三次转发）——核查动作：沿着引文往回走，直到摸到一手（SIFT 之“追溯至原始材料”：真相常常在第一页，只是没人穿到第一页**）。
:::

::: definition 数字三查与图表口音 {#def-shuzi}
**一查分母**（**“死亡报告增加”“投诉暴涨”无分母即修辞（第 7 章旧债新还**）；**二查基数**（**“增长 200%”从 1 到 3；“下降一半”从 4 套到 2 套——百分比是相对数，脱离基数的相对数是裸奔（“专家称某种新方法使复发率下降 50%”：从万分之二降到万分之一？还是从六成降到三成？同样的 50%，两种人生**）；**三查口径**（**百分点 vs 百分比双胞胎骗局：“支持率下降 2 个百分点”被播成“下降 2%”；“失业率”的统计口径（谁被算作“正在找工作”）本身是政策变量（第 2 章规定定义的现场执法：口径即法律**））。**图表口音学**（**截断纵轴让 3% 的山坡看起来像悬崖；双轴图把两条无关曲线叠成“神同步”；气泡面积按半径画导致面积×π²（“图是数据的翻译：翻译可以有口音，也可以有冤案——审图三步：看轴从哪起、看单位、看图例有没有第二个故事**）。
:::

::: example 群聊长文完整验尸 {#ex-qunliao}
对一篇《震惊！九成专家呼吁废除英语高考》式长文做**五步验尸**：①标题与正文对表；②信源回溯；③数字三查；④图片/数据文件核对；⑤横向阅读（另开两个标签页）。请给出一份**验尸报告**，并写明每一步“最可能查出什么病”——以及**哪种病足以放弃全文，哪种只扣印象分**。
::: solution
①**标题与正文错位**（**正文说“某校教师调研显示”，标题升格“九成专家呼吁”：样本从 46 人到“专家界”：广场扩省（第 6 章）——病症：升格式标题＝全文信用预警，一病抵三病**）；②**回溯断链**（**“据外媒”三层嵌套后消失于一家地方教育论坛：引证通胀的末梢；“专家表示”无引号无单位无姓名＝裸引语（“匿名把成本转嫁”现场版**）；③**数字病**（**“英语无用论者占比 78%”：分母是“投票者”，投票者是“看到这条推送的人”——样本框塌方；“废除后平均工资提升”：相关与反向因果齐飞（第 7 章四出口全中**）；④**图表旧伤**（**配图是 2014 年另一则新闻的旧图：图片的“在场证明”功能大于信息功能——旧图新用＝情绪的移花接木**）；⑤**横向阅读**（**另开两页：搜索标题关键句发现它是 2019 年谣言的换皮；搜“英语 高考 废除”发现权威口径完全不同——**判决：事实层报废（断链＋数字＋旧图三病并发）；观点层保留为“某部分人的诉求样本”：文章作为观点的证据尚可，作为事实的证据是废品（“它骗了你一件事实，但暴露了一个真实的情绪：验尸报告的最后一栏要写：死者有几分真话，这正是它好骗人的原因**）。
:::
:::

::: intuition 平台时代：相关性的工业化 {#int-pingtai}
**推荐系统用“你会看”替换“重要”作为录用标准**（**编辑时代的把关是（商业的、政治的、专业的）三重滤镜；平台时代把滤镜换成了你的过去——于是公共议程被切片成八亿个私人议程（第 7 章相关律的社会版：平台不关心真假，关心停留时长：真假恰好有时卖得好，这是事实的运气不是事实的制度**）；**愤怒的传播系数**（**跨平台研究的一致通说：高唤起情绪（怒与惧）比平静陈述更易转发——不是人性变了，是人性的分销渠道变便宜了（“你刷到的不是世界，是世界的易怒切片**）；**辟谣的半衰期与“逆火”之争——**逆火效应的争议要诚实：早期“辟谣反而强化错误信念”的实验结论在更大样本中未能稳定复现（可复现性危机的常客）——目前可守的结论较弱但够用：辟谣有用但慢、且要讲对结构（先给替代解释，再否定原谣言：只贴“不实”标签等于把真空留给谣言自己填——“你不能用‘不对’填满一个故事，只能用一个更好的故事**）。。**搜索的动机自检**（**确认偏误的搜索版：我们搜“为什么 X 是对的”而不是“什么能推翻 X”——技术处方：故意搜反面、读完再关（“搜索引擎是你的回声壁：对着它喊‘有人反对我吗’，是这门课教的唯一咒语**）。
:::

::: history 从“无冕之王”到“全员编辑” {#sec-wumian}
**1922** 新闻学立科（**美国报界自省“黄色新闻”年代：客观性作为职业规范被发明——“客观性是一个行业的质保书，不是一个人的德性（它靠采访规程：平衡引语、消息源分级、更正栏——制度化怀疑的第一版**）；**1960—70 年代** 议程设置与把关研究（**麦库姆斯与肖的“议程设置”通说：媒体不能决定你怎么想，但能决定你想什么；“属性议程”的补充版更狠：它还能决定你用哪个角度想**）；**1843** 李普曼《公众舆论》（**“拟态环境”：我们处理的是头脑中的图景—— “刻板印象”一词进入舆论学（第 2 章“库存”的传播学分店：刻板印象就是没被审计过的联想定义**）；**1922** 政论新闻学成熟——**2000s** 维基时代（**自下而上的协作编辑把“更正栏”变成“版本历史”：过程公开第一次成为可信性资源——“信任从‘来源权威’部分迁移到‘可追溯性’：这是信息评估史上最被低估的改朝换代**）；**2010s** 事实核查职业化（**专业机构与“事实评级”尺度（真/基本属实/半真/假）——把逻辑课的判分表做成了新闻产品；同期社交机器人、深度伪造让“有图有真相”降级为“有图有存疑”：取证技术（反向图搜、元数据）成了公民新识读课的一部分**）；**中文语境**（**从《环球时报》式的“据新华社”转引链，到“据央视新闻客户端”的层级转引——消息源的行政级别体系：中国读者天然活在证据金字塔里，只是塔尖被换成了公章——本章的任务不是推翻这座塔，是给它补上第 4 问：塔顶的人没说什么**）。
:::

::: warning 信息评估四坑
**把“可查”当“已查”**（**“有出处”三个字是全篇免检？出处本身可能是循环引证的第一环：可查是资格，不是结论**）；**对称怀疑主义**（**对我方的每条都信、对敌方才做五步验尸＝你不是怀疑论者，是球迷（自我审计工具：把你最想转发的那条拿出来，按同一标准验一次：疼，就说明方法对了**）；**“那你们呢”式分流**（**被指出问题就抛另一个更大的问题：议题通货膨胀是转移注意力的老手艺——“先结本案，再审别案：一句‘那 XX 呢’不是论证，是休庭申请**）；**反智的犬儒**（**“媒体都不可信”与“因此都不看/都信”是同一枚硬币的两面：犬儒不是清醒，是放弃预算分配：它最省脑子，也最容易被“唯一敢讲真话的人”收割（第 9 章民粹修辞的预备役**）。
:::

::: exercise 建立你的白名单 {level=1}
为你关心的一个议题（教育、健康、房价任选）开一张**信源档位表**：三档（优先采信／须交叉验证／仅作情绪样本），各写两个真实例子与一句话准入标准；并规定**升级核查的触发条件**（什么情况下你会从“接受”升级成“去查原始出处”）。
::: solution
判分：**档位标准写成可操作规则**（**“优先=发布方与研究方相互独立且可下载数据”，不是“我觉得权威”**）；**“仅作情绪样本”一栏必须有内容**（**那里安放“让我特别想转发的东西”——对自己偏好的检疫区（自我审计从最疼的那格开始**）；**触发条件具体**（“涉及百分比且结论支持我的既有立场＝立刻查原始口径：偏误的警报声就是这种时候响的**）。
:::
:::

::: exercise 谣言解剖 {level=2}
选一条近期热传（健康或教育类），按例题的五步验尸写报告，并**为它写一版“合格辟谣”**（须含：替代解释、正确的口径数字、对情绪的承认——不许出现“纯属谣言”四个字单独成段）。
::: solution
判分：**先讲故事再下结论**（**“你看到的数字是从哪来的”比“这是假的”更能改变信念——半衰期规律的实操：解释必须占住谣言腾出的真空**）；**承认情绪的正当性**（**“担心孩子视力是真的，只是这份文件撑不起这个担心”——事实纠错与情绪接住同时做（第 1 课说服三诉的逻辑课分账：logos 归本课，pathos 别退回给造谣者**）；**给出更好的行动建议**（**“要做的是每天两小时户外，而不是买这个仪器”——辟谣的终点是替换行为，不是赢得争论**）。
:::

::: exercise 小论文：信任的经济学 {level=3}
写六百至一千字，评“**后真相不是‘人们不再讲真话’，而是‘真话的批发价低于谣言的零售价’——当生产的边际成本为零、核查的成本全在买方，市场就被劣质品占领：这不是道德滑坡，是定价失败**”。须调用：**证词是承重墙**、**怀疑的预算分配**、**循环引证/引证通胀**、**口径即法律**、**平台的“相关替换重要”**、**横向阅读**至少六项；并裁决：**平台该不该为信息质量负责——算法中立说与家长制说的交锋，写出你方案的失效条件**。
::: solution
判分点：六项机制（**外包制不可废；预算按出错代价分配；复数幻觉；定义即治理；停留时长做议程；离开当前页**）；平台裁决（**中立说——把关即权力，权力须问责，平台不具民主合法性；家长说——市场已失灵，不作为本身就是选择；判卷看失效条件（如“透明度换审查：标注来源、公开排序参数而非直接删帖——当‘标注’沦为新的信任装饰（人人都拿‘已核实’徽章自封），透明方案失效；届时争论会回到谁有权发证：又回到第 2 章的定义权——本课与全书在此闭环**）；结论若写“**信息时代的逻辑课，教到最深处是一句话：把怀疑留给会伤害你的断言，把信任留给可追溯的来源，把愤怒留给值得的事情——三者都不省，三者都贵**”，即 A。
:::

::: summary
信任经济学归档：默认值（**证词是承重墙：怀疑按出错代价配预算**）、四问（**谁、凭什么、说给谁、没说啥**）、等级（**再分析优先；变形记的四跳**）、通胀（**往回走到一手**）、数字（**分母、基数、口径：口径即法律**）、平台（**易怒切片＋弱但可守的辟谣学**）、动作（**横向阅读＋反证搜索**）。方法一句话：**先查谁在说，再读说了什么；最想转的那条，最先验尸**。下一章磨刀：谬误总表——把前面所有错误编成一本可翻检的字典。
:::
