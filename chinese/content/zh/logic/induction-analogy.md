title: "归纳与类比"
---

演绎管“必至”，本章管“很可能”——**人类几乎所有新知识、全部经验、以及你明天还会吃米饭这个决定，都签在这两种推理上。它们的共同点：结论永远比前提走得多一步；那一步叫风险**。

## 定义：两种归纳、一笔贷款 {#def-liangzhong}

::: definition 完全归纳与简单枚举 {#def-juhe}
**完全归纳（枚举）**（**考察全部对象：“班里 42 人逐一查过，都及格”——前提穷尽，结论其实没出门：这是披着归纳皮的合取（第 3 章的账：它的全部工作是把 42 个事实装一个口袋——安全，且零增值**）；**简单枚举**（**考察一部分、断言全体：“我见过的天鹅都白”——密尔给它的立法只有一句：未遇反例即放款——这条规则的可靠性以遭遇史为限（贷款合同：本金是经验，利息是运气，违约条款只有四个字：“下一只天鹅”——黑天鹅在澳洲等着欧洲人一千年：一个物种的颜面败给一次航海**））。**为什么必须有归纳**：**演绎从不出门，归纳替你跑腿——“太阳升起”不在任何逻辑里成立，它在 200 亿次日出里成立：本章不教你怎么避免风险（避免不了），教你怎么给风险报价**。
:::

::: definition 休谟回访：归纳能自我辩护吗 {#def-xiumen}
**标准辩护的循环**（“**归纳过去一直有效，所以归纳将来有效”——待证题当引擎用：这是第 1 章“同语反复”的宇宙级版本（零利率贷款贷给了自己**）。**休谟的判决**（**归纳在逻辑上无据，在心理上必然：支撑它的不是理性，是习惯——“风俗主义”：理性说不出理由，天性替你决定：这是一个诚实的失败，不是失败的掩饰**）。**本课立场**（**不装演绎，不跪演绎：归纳的产品是“风险报价”不是“保证书”——会算概率的人既不骂休谟（他是对的），也不装死（那样归纳就没人敢用了）：正确姿势是说出报价单——样本多大、范围多宽、什么会推翻我：一句话，把贷款改成明账**。
:::

## 采样两条纪律：数量与地理 {#def-caiyang}

::: definition 样本框与广场 {#def-gezi}
**纪律一（样本框先于样本量）**（**“调查 100 个大学生，90% 支持延长图书馆夜间开放”——在谁的楼下拦的？闭馆前十分钟的图书馆门口＝在教堂数信徒（样本不是数量的问题，是地理的问题：你在哪个广场发问卷，你的结论就属于那个广场——“总体”二字是采样学的第一页：先画出“谁有资格被算进来”，再谈比例**）；**纪律二（缺席者会说话）**（**幸存者偏差——战时统计员盯着返航飞机的弹孔建议加固弹孔最多处，幕僚一句话点死：弹孔图上没有那些没回来的飞机（沃德方案的通说版本）——“要修的不在弹孔里，在没回来的人身上：数据整理的第一步不是算已有的，是点名未到场的——问卷学、财富榜、成功学、辍学统计、差评分析（好评样本框）、创业访谈（只有活着的接受采访：失败者名单需要另一支考古队）全是同一道题**））。**中文修辞联动**（“**你身边的人都……”——“身边”即广场：“我认识的体制内的人都后悔辞职”＝写字楼三层的地质年代学（第 8 章信息评估的地基预浇**）。
:::

::: definition 密尔五法：给嫌疑名单排序 {#def-wufa}
**求同法**（**多个发病案子里唯一共同暴露项：食堂只换了一种酱油——“众案寻一：唯一公约数自动升为头号嫌疑”；软肋：什么叫“共同”取决于你切多细（都吃过酱油，也都呼吸过同一片空气：相关背景无穷，选哪个当嫌疑取决于先前的医学知识——密尔五法不是魔法，是假设搜索器**）；**求异法**（**同一块田，一半施肥一半不施——差异唯一即嫌疑：对照实验的哲学血统书，黄金标准的祖先；软肋：“同一块田”里的“同一”是玄学（土壤、坡向、鸟群路线：控制变量=对宇宙的简化申请，申请书永远写得不够长**）；**求同求异并用法**（**正反两组案一起找公约数：安慰剂对照的古典雏形**）；**剩余法**（**已知项扣除，剩余另立账户——“账对不上处有新星”：海王星的发现法（牛顿方程算完已知行星，天王星轨道仍差一点：那点差额养出了第八颗行星）；也是刑侦科日常（你不在场、钱少了、钥匙只有他有）——效力＝前提穷尽的效力：没排干净的剩余全是嫌疑（漏账与幽灵同一个长相**）；**共变法**（**跟着变的就可能是伙计： 剂量与血压共变——温度计逻辑，相关的前身；软肋：鸡鸣与日出共变亿万次（方向问题与第三者问题（共变只给嫌疑名单，不给判决书——第 7 章因果法庭接案**）。
:::

::: example 豆浆机、太阳灶与学区：三个类比审计 {#ex-leibi}
**①豆浆机案**（**“这家连锁的豆浆机好用，北京门店好用，∴我出差住的这家也好用”——拆成类比式并评估**）；**②太阳灶案**（**“月球没有大气，昼夜温差极大；某沙漠考察站希望制冷省钱，于是给考察舱罩反射层模拟月表条件”——哪一步是类比、哪一步是检验**）；**③学区案**（**“甲校去年‘县中模式’高考成绩好，丙校照搬即可”——列出三条“不同类”的理由并给出更强的替代推理**）。
::: solution
①**类比式**（**A 校有属性 abc＋好用；本店有 abc；∴本店好用——评估靠“相似点与 d（好用）的相关性”：门店品控、水质、豆子批次都与“好用”相关；“装修像”不相关——结论：中低强度类比（同一连锁提高了机器与豆子的同类性：品牌就是类比的信用背书——广告买的全部逻辑**）；②**类比只负责“生产赌注”**（**月表与沙漠同为“干燥、辐射散热、无云”，据此推断“高反射层可降温”——这是类比；真值表：装上后量温度——这是检验——好类比的标志恰恰是可检验（比喻是类比的表情包，模型是类比：合同里写明了哪些属性相关、失效边界在哪：卢瑟福的原子像太阳系同样是类比，它的功劳不是为真，是把“该量什么”指出来了**）；③**区隔三条**（**生源入口成绩不同（结果变量的主因在筛选不在模式）、教师年龄结构不同、复读生态不同——相关属性错配：照搬只搬走了“看得见的动作”，搬不走“产生动作的条件”**）；**更强的替代推理**（**先求异后类比：找一所生源与丙校同框、也用甲校模式的学校做正面案例，再小范围试点（控制变量先于全面移植——“先移植一块试验田，别移植整所学校：类比的最优使用方式是把它降级为假设**）。
:::
:::

::: intuition 火鸡的第一千零一天 {#int-huoji}
**罗素的火鸡**（**农夫喂了 1000 天，归纳曲线一路向上，“农夫爱我”几近必然——第 1001 天是感恩节：归纳的最深处不是懒惰就是感恩（材料不变，结论改朝换代，只需喂食者换一次心肠——“规律失效”不需要世界变坏，只需要你没把“农夫”放进变量表**）。**教学三点**：**①可废止性**（**归纳结论天生带撤销条款：这不是它的耻辱，是它的工作方式——“所有已知的推理里，只有肯留‘收回成命’窗口的才配叫经验**）；**②把机制纳入样本**（**火鸡的出路（如果它有逻辑课）：不只统计“喂食次数”，还要研究“喂食者靠什么吃饭”——归纳可以升级：从表面正则升到机制假设（第 7 章因果：机制是归纳的防弹衣——能讲出“为什么必然如此”的归纳，比“一直如此”抗揍**）；**③科学家的自我修养**（**波普尔的药方（第 4 章重言式反比律的续账）：科学不从确认数起，从试图推翻数起——“支持我的证据让我安心，能推翻我的证据让我进步：这句话写不进励志语录，它是方法论**）。
:::

::: history 或然性技术的编年 {#sec-biannian}
**前 5 世纪** 希波克拉底文集《流行病学》（**“观察今日之病人以预告明日之病人”：经验医学的归纳纲领＋中国“**物以类聚，方以类明**”（《周易·系辞》的归类冲动——类是象数与类比的家谱树（第 10 章名辩预支**））；**1620** 弗朗西斯·培根《新工具》（**书名直接对撞《工具论》：归纳法开业演说——“偶像洞穴与种族假象”（人的洞穴与种族的滤镜：偏见的系统命名法——从“你要小心偏见”升级到“偏见有四类、各有住址”：谬误论的第一次分区普查**）；**1739** 休谟（**把归纳问题从神学手里接过来，钉成永久刑期**）；**1843** 密尔《逻辑体系》（**五法成典（严复 1905 译入为《穆勒名学》——第 2 章术语史的姊妹案：中国现代“逻辑感”的两次输血都走归纳一路**））；**1930s—50s** 概率与归纳（**凯恩斯《概率论》（1921）把“或然”数学化；莱辛巴赫的“直推”与卡尔纳普的归纳逻辑——“20 世纪试图给贷款定价（置信度、先验、贝叶斯更新）——休谟仍在，只是改收了利息**）；**1950s—今** 确认悖论与贝叶斯复兴（**古德曼“绿蓝悖论”（新谓词“绿蓝”的发明）：连“证据支持哪个谓词”都取决于语言习惯——归纳的最后一块地板下也发现了白蚁；随后贝叶斯主义成为统计学主流方言之一：“安全”彻底放弃，“更新”接管业务**）。
:::

::: warning 或然推理四坑
**把置信度当真理**（**“重复了 99 次”不等于“必然”：频率给人安慰，机制给人预测——只有喂食记录，没有农夫画像**））；**广场谬误**（**用身边的样本断言全国、用网上的声量断言沉默的大多数：“样本框错位”是舆情报道的第一死法（第 8 章头条常客**））；**类比越权**（**用类比代替论证：“治大国若烹小鲜”是洞见也是免责——好类比生产假设，坏类比终结讨论（识别法：一个类比之后有没有跟“如何检验”；没跟，就是修辞**））；**幸存者报告**（**成功学自传：全体失败者无法出书——读任何“他们都有什么共同点”之前，先问“和我同款的失败者出过书吗”——数据会沉默，沉默不是同意**）
:::

::: exercise 报价单 {level=1}
给三条归纳结论各开一张**风险报价单**（样本框／样本量／最可能推翻它的场景／你建议的置信档）：①“食堂涨价后剩菜率上升，学生对价格敏感”；②“本校毕业生考公比例三年连升，明年还会升”；③“这款笔记 App 我用了两周，效率明显提升”。
::: solution
判分示例：①**混淆项：同期是否有换菜单／疫情限流／天气（剩菜率与价格之外变量共变——先求异再下结论）**；②**趋势外推的三条断头路（政策突变、编制口径、届别样本：“三年”的样本量=3：趋势不是定律（把“连升三次”听成“必升”＝火鸡第 3 天**）；③**自我样本 n=1、无对照、新鲜感混杂、发表偏倚（你只会记得好用时——单案例的正确用途：生成假设，不是验证（“两周”是试用期的字面义：给 App，也给自己的结论**）。
:::

::: exercise 区隔文书 {level=2}

判分：**“不同类”必须打在相关属性上**（“城市不同”不算，“生源结构不同”才算——区隔的技术含量：从千差万别里挑出“与结果有关的那几个差别”（判例法的肌肉，答辩场的肌肉，同构）**）；替代案例须说明**同类性在哪一栏**（品牌、机制、约束三项至少中二——**类比的重写权在你手里：这是本课的攻防互殴**）。

::: exercise 小论文：安全的贫乏与丰富的冒险 {level=3}

::: solution
判分点：六项机制（**穷尽即合取；循环是诚实的失败；地理决定结论的户口；五法是假设搜索器；类比的功劳在指路不在判案；感恩节条款**）；AI 裁决（**参考路线——枚举极致论：海量语料的超级共变统计，机制解释缺席即火鸡风险（它会说“一直如此”）；新物种论：模型学会了可跨任务复用的表征，类比与演绎只是被压缩进参数的或然机器；判卷看“失效条件”（“当测试题超出训练分布即现形：评测集就是那第 1001 天——所以基准分数越高，逻辑课越贵：这句话写出来就是 A 的水平：它同时得罪了两边，而且都对**）；结论若写“**家业的真相：账房先生管不了翻盘，赌徒管不了破产——成熟的人不是选边，是知道此刻该派谁上场，以及散场后一起对账**”，即 A。

::: summary
或然性归档：两种归纳（**穷尽零增值；枚举靠遭遇史放款**）、休谟（**循环＋习惯：把贷款改成明账**）、采样（**先问哪个广场；先点名未到场的**）、密尔（**五法是嫌疑名单排序器，不是判决书**）、类比（**相关属性决定强度；可检验的是模型，不可检验的是表情包；区隔是防守反击**）、火鸡（**留出撤销窗口，把机制写进样本**）。方法一句话：**下结论时附上你的死法（什么会推翻我）**。下一章专审一类结论：“A 导致 B”。
:::
