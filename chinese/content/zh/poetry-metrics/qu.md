---
title: "曲"
---

词律把自己卷死的那一年，它的弟弟接管了音乐：**曲**。上一章结尾说词“用文字给声音留座”；曲的回答是：**留什么座，加座、加菜、加人——格律史上最大规模的一次“松绑实验”**。松绑不是没有绳子：宫调、曲牌、韵位一样不少，只是绳结改打在了**板**上，不再是**字**上。

## 新宪法 {#def-xianfa}

::: definition 《中原音韵》：给语音现实发追认书 {#def-zhongyuan}
周德清《中原音韵》（1324）三条款，条条对着宋词律的尸体：**①入派三声**（北方活口语里入声已散，韵书照实登记——**曲不再查诗韵：入声字由“硬指标”降为“普通公民”，可派作平上去使用**）；**②平分阴阳**（清浊分调的既成事实建档——**曲的平声是两格，谱上写“平”还嫌不精确**）；**③十九部韵**（韵部大合并：-m 收尾并进来——**曲韵的宽是拿语音真实换的：它不保护任何已经死掉的声音**）。对照词律：词谱伺候的是**已存在的曲调**，曲谱伺候的是**正在唱的戏**——**词是古典主义（尊谱），曲是现实主义（尊耳）**；周德清的骄傲在自序的口气里——**押韵从“依书”改称“依音”：一部韵书把自己写成新闻公报，而不是法典**（它后来的命运讽刺而辉煌：**普通话读者的天然母语韵书**——见例题）。
:::

::: definition 三件新工具：衬字、复韵、俗语 {#def-gongju}
**①衬字**（谱定字数之外加进去的字：“我是蒸不烂、煮不熟、捶不匾、炒不爆、响珰珰一粒铜豌豆”——“我”“一粒”之类皆可为衬：**格律的旁路放行条：字可以是加的，板不能加——曲把‘定量’改成了‘定拍’**，说唱者的嘴第一次被允许超车而不迟到）；**②韵脚可重**（同一韵字反复押——律诗的重韵禁令在此废除：“**由他，由他**”式连押当鼓点用：**词把重韵当事故，曲当效果**）；**③语言方针大转弯**（曲“**文随语走**”：**虚字、儿化、俏皮话、歇后语全部入册——曲的雅俗比例是历代表体里最辣的**；“蒜酪味”的诨号说它下饭：**曲不摆宴席，摆夜市**——**从“词为诗余”到“曲为词余”，贬名的接力说明每次体裁扩张都会被旧体裁的卫兵记过一次**）。
:::

## 两种发行 {#def-faxing}

::: definition 小令与套数：单曲与概念专辑 {#def-xiaoling}
**小令**＝单支曲牌一次发行（《天净沙·秋思》：“**枯藤老树昏鸦，小桥流水人家，古道西风瘦马。夕阳西下，断肠人在天涯。**”——**二十九个字，前三个句子零动词：九个名词三组并置，中国韵文列锦的极限；末句“断肠人”出场收网——全曲像一部只有空镜、结尾一秒钟出现旁白的短片**）；**套数**＝同一宫调下若干曲牌连成一组、一韵到底（**概念专辑：同一调性（宫调）串烧多首，尾曲收束——戏的唱段就靠这套组曲机制叙事**）；**剧曲**＝套数＋宾白＋科介（《西厢记》【端正好】“**碧云天，黄花地，西风紧，北雁南飞。晓来谁染霜林醉？总是离人泪。**”——**首四句整购自范仲淹《苏幕遮》——**曲不害臊：“碧云天，黄叶地”——曲的“集句”挪用观：前朝名句被当布料裁进新衣，剪裁露线脚反而见手艺**；“泪染霜林”的设喻胆量：**词说愁似春水，曲直接把眼泪当染料——抒情语法从比喻升级成工艺**）。
:::

::: example 《天净沙·秋思》：本课期末试卷 {#ex-tianjingsha}
二十九天净沙，请把它当**全课浓缩卷**做五题：①标平仄（体系提示：入派三声后此曲按《中原音韵》走——“夕”还算不算入声？**先自查**）；②标韵位（韵脚见原文：鸦、家、马、下——**平上去三声通押**：诗律做不到、词勉强、曲合法）；③数动词（前三句）；④若按近体诗的“对”改写“小桥流水人家”为“中桥旱地人家”，损失什么；⑤为什么**这首“无律之曲”恰好能当格律课的结业证书**——用本课三件新工具与上一章“延迟交付”论各答一半。
::: solution
①**体系切换**：以《中原音韵》论，“夕阳”之“夕”已派入平声（派法诸家微异，曲中从活音）——**同一字在平水系是入声、在中原音韵系是平声：换法典即换国籍**（第 2 章“行为时法”条款的最高应用）。②韵脚：**鸦、家、马、下、涯（麻韵部：平上去通押）**——**三声通押让韵脚像说话自然落下；律诗的“一韵到底＋同声调”是展廊，曲的韵位是人行道**（“涯”读 yá 与今音完全兼容——**曲韵与普通话的亲和：上一章的“化石备份”在曲里是新鲜备份**）。③**零动词**：三句九名词——**列锦不是没语法，是把语法交给镜头组接（蒙太奇是曲的句法）**；④损失的是**选单的阶级成分**：“小桥流水人家”是旅游宣传片的温柔一刀——对“枯藤／古道”的衰飒正好构成**反打镜头**；“中桥旱地”对仗更“工”而全曲的**冷暖对切**报废——**曲要的不是工，是准**（对仗课的判词在曲中重审）。⑤结业理由：**它同时演示了格律的存在（宫调、牌调、韵位一样不少）与格律的松弛（衬字位、通押、零动词）——“定拍不定量”的活标本；而“延迟交付”：今天的白话选本读它毫无障碍，正说明**它押的是仍然活着的音——曲是格律家族里最后一个还记得音乐长什么样的孩子**。
:::

::: intuition 松绑的力学 {#int-songbang}
律→词→曲是一部**约束迁移史**：焊死字数（律）→松绑句数、焊死四声（词）→松绑四声与字数、焊死板拍（曲）——**每一代体裁把上一代的自由项接管为默认，把新的自由项让给表演，把纪律后撤一层：从纸面撤到拍面**。规律浮现：**文体不会“堕落”，只会换承重墙；每次“解放”都把成本转移给下一个环节**（曲把成本转给演员与乐工：衬字要有人兜得住——**格律宽松的地方，表演严格**；明清传奇反过来又收紧：字声再焊死——**松绑是不可再生资源，用完一代用下一代**）。
:::

::: history 曲的账期 {#sec-zhangqi}
**金—元初**：诸宫调（董解元《西厢记诸宫调》——**说唱长篇的组曲实验：王实甫杂剧的直接爹**）；**元**：**元杂剧黄金二十年（大都—杭州双城）：关汉卿、王实甫、马致远、白朴——**一批科举停废后的读书人把才华转行给剧场：元祐之后最优秀大脑再就业**；王国维《宋元戏曲考》给曲办加冕（“**一代之文学**”入列：楚骚、汉赋、唐诗、宋词、**元曲**——**身后的封号，领得最晚，争议最少——因为它早就不竞争了**）；**元后期—明**：**散曲雅化（张可久们把曲又写成了词）＋南曲兴起（《琵琶记》——宫调系统换血：北曲亡于雅化，南曲生于地方**）；**明**：昆曲水磨调把字声重新焊死（**魏良辅们“依水磨定腔”——曲律的复辟：松绑实验结束，回到尊谱**）；**清**：《钦定曲谱》＋花部兴起——**庙堂修谱，民间野唱：雅部胜利一次就老化一分，乱弹用“不合法”抢市场——体裁史把朝代史重演一遍**；**今**：**歌词＋说唱押韵密度回到“密韵轰炸”水准（铜豌豆的连押在 hiphop 里复活）；小品与脱口秀的“抖包袱”结构上姓“诨”——曲的尸体最少，器官全被移植**。
:::

::: warning 读曲四坑
**用词律检曲**（**衬字不是多出来的字，是谱定节奏的一部分：“我蒸不烂铜豌豆”去掉衬字反而破拍——先懂板，再数字**）；**把“俗”当降级**（**曲的俗语是技术：判断句、插话、夸张全是舞台指令的化石——文本的“闹”是演出的“准”**）；**忽略北曲南曲两套系统**（**宫调、字声、伴奏（鼓板对弦索）全不同：一部“曲律”不存在，存在的是两部宪法先后执政**）；**以为元曲=元杂剧**（**散曲独立存在：小令套数可在剧场外清唱——把全部曲当戏文读，等于把流行歌全当音乐剧**）。
:::

::: exercise 衬字车间 {level=1}
把一句五言律句（如“**床前明月光**”）**扩写成带衬字的曲味句子**：加到 12—15 字，**保留原韵脚且节奏仍能打拍**；再反向：把你扩的句子的衬字全部删除，看塌掉的是修辞还是信息。
::: solution
判分：**韵脚守住、板不乱**（拍手测：附加字须念得“滑过去”——**衬字是弱拍行李，不是强拍路障**）；**删除测试**：好衬字塌掉的是语气与人格（“我”“呀”“那”级），不是事实——**衬字是格律里的“人味儿名额”**；敢加“哎”“那答儿”之类方言衬字并说明舞台理由者加分。
:::
:::

::: exercise 三声通押的街头 {level=2}
用《中原音韵》精神写 6—8 行押韵短文（打油、数来宝、说唱段落皆可）：**必须平上去通押同一韵部**，并**至少重复使用同一韵脚字两次**（复韵当鼓点）。互测：对方能否一次拍准你的韵位。
::: solution
判分：**通押自然**（三声同部的音色差被节奏吸收——“诗律做不到、词勉强、曲合法”的亲身验证）；**复韵有功能**（重字韵当副歌／当重锤，不是词汇匮乏）；**一拍一韵的可拍性**（这是曲的真实验收标准：**嘴跟得上＝律通过**——“定拍不定量”的期末签名）。
:::
:::

::: exercise 小论文：松绑是不是进步 {level=3}
写六百至一千字，评“**从律到曲，格律没有变松，只是换了被焊死的东西：字数让位给板拍，阅读让位给表演**”。须调用：**《中原音韵》三条款**、**衬字的板位逻辑**、**三声通押与复韵**、**明清的“复辟”（昆曲重新焊死字声）**至少四项；并处理一个反方：**如果每代都在“再焊死—再松绑”之间摆动，格律史就只是循环，没有方向——你接受还是反驳**。
::: solution
判分点：换焊点论证（**约束迁移：纸面→拍面→（今天）屏幕——每一环都有真实代价与收益：表演严格化是曲的成本，不是缺点**）；复辟（**昆曲证明松绑不可持续的原因是行业需要标准件：戏班流转、师徒口传都要“谱”——自由一旦成功商用，就立刻需要新的合规**）；循环之问（**参考反驳：有方向的螺旋——每轮摆动都建立在上一轮驯化的能力增量上：元人能用衬字是因为词已训练出分片耐力，今天说唱能用密韵是因为汉语文案史压满了韵感库存——摆动的振幅在放大，基线在上移**；接受循环者须解释“为何每轮的方言与俗语都不同”，同属有效立场）；结论若能写“**格律史是‘谁负责不迟到’的历史：从数着字，到数着拍，到数着流量——问题不变，计时的钟在换**”，即 A。
:::

::: summary
松绑实验归档：宪法（**追认书：不保护任何已死的声音——讽刺的是它因此最像普通话**）、工具（**衬字=人味儿名额、复韵=鼓点、俗语=舞台指令化石**）、发行（**秋思的二十九字短片；泪染霜林：抒情从比喻升级成工艺**）、力学（**约束迁移：格律宽松处，表演严格；松绑是不可再生资源**）、账期（**加冕最晚、争议最少；“曲的尸体最少，器官全被移植”**）。方法一句话：**先找它在替谁守时，再评它松还是紧**。最后一章：意象与用典——格律的容器里，究竟装着什么。
:::
