title: "律诗"
---

前两章造好了尺（平仄）和秤（韵），本章装配主机：一首八句五十六字的机器——**律诗**。它的图纸其实只有四行字，**全部复杂性来自这四行的排列组合与少数几条“必须违章”的豁免条款**。

## 四块积木 {#def-jimu}

::: definition 四种律句与“对、粘” {#def-siji}
五言的全部地基是四个句式：**①仄仄平平仄 ②平平仄仄平 ③平平平仄仄 ④仄仄仄平平**（七言＝每句前面加一个反音步：**平仄互换的“鞋”**, 变成 ①'平平仄仄平平仄 ②'仄仄平平仄仄平 ③'仄仄平平平仄仄 ④'平平仄仄仄平平）。八句的装配遵守两条机械律：**“对”**——同一联的出句与对句平仄相反（句内起伏：**平仄仄仄平这种“踩死节奏”的句子当场报废**）；**“粘”**——下一联出句与上一联对句的第二字同声（联间衔接：**“对”制造波浪，“粘”让波浪接力——两条交替，就是一首律诗的公路剖面**，回看[[tang-literature/early-tang]]“起伏的公路”）。四句式×对粘，穷举得**五律四式（仄起/平起×首句入韵/不入韵）、七律四式**——**表是死的，推导是活的：能推出四式，就不需要背十六种格式**。
:::

::: definition 唯一的重罪：孤平 {#def-guping}
四种律句里只有②'（仄仄平平**仄**仄平）这类“**平声被夹在仄声中间孤零零**”的违约名叫**孤平**：七言“仄仄**仄**平仄仄平”（第三字该平而仄，除韵脚外只剩一个平声）——**近体诗的头号罪名，与“三平尾”（句末连用三个平声，古体的指纹）并称两大禁忌**。规则一明，口诀立塌：**“一三五不论”是民谚级的谎言——一三五有时不论，三五常常不论，但②'式的第三字、③式的第五字（救孤平位）论得比谁都狠**。合法的变通有国家目录：**①拗救**（对句相救／本句自救：把某位置的“不该平”用另一位置的“补平”找齐——**格律是个记账系统，借贷必须同时登记**）；**②特定格式**（“平平平仄仄”作“平平仄平仄”、七言“仄仄平平平仄仄”作“仄仄平平**仄平仄**”，**唐人用得多到被追认为合法——常用拗即正体：违宪案审到第三次就成了判例**）。
:::

::: example 全诗扫描：《旅夜书怀》 {#ex-luye}
杜甫：“**名岂文章著，官应老病休。星垂平野阔，月涌大江流。飘飘何所似，天地一沙鸥。**”请①逐字标平仄（入声提示：月、阔、一；“病”为去声非入——先自查再对答案）；②推出它属于四式中的哪一式，验证对与粘；③检查韵部（休、流、鸥）；④找对仗位置，并回答：**为什么这首诗读起来“没有瑕疵却巨大悲伤”——从声律角度给一个证据**。
::: solution
①**名岂文章著**＝平仄平平仄（对式①“仄仄平平仄”，首字灵活）；**官应老病休**＝平平仄仄平；**星垂平野阔**＝平平平仄仄（阔，入）；**月涌大江流**＝仄仄仄平平（月，入）；**飘飘何所似**＝平平平仄仄；**天地一沙鸥**＝平仄仄平平（一，入）。②起句仄收、第二字“岂”仄——**仄起不入韵式**；对：首联平仄相反✓；粘：“星垂”与“官应”第二字同平✓——机器图完全合规。③休、流、鸥＝**下平十一尤韵**，一韵到底✓。④**对仗在颔联（星垂／月涌：名词动词各归各位），五律的颈联（五六句）此诗用流水散句——对仗位可弹性（首联对、颈联散是杜甫常式）**。声律之悲的证据：**全诗无拗无救、干净到近乎冷——五个韵脚全是 -ou 的长元音滑闭（悠、流、鸥：开口由大收小，像一声声咽回去的长叹）；句法上“星垂／月涌”两个动词砸在第三字（平仄的鼓点），而“天地一沙鸥”的“一”是入声——宇宙级的空间被一个刹车音收束：格律的“无瑕疵”正是悲伤的容器（对比“感时花溅泪”的拗怒：杜甫两台机器都开得到满分）**。
:::
:::

::: intuition 七律为什么最晚熟 {#int-qilv}
五律初唐先熟，七律到杜甫才登顶——**因为七言的每个音步都多一层自由：上四下三的“读法断层”（“晴川／历历——汉阳／樹”的停顿与文法分组打架）需要更长的磨合**；**更因为七言的信息位宽：它能装下散文的句法与史论的语气——虚词（之、于、以、其）挤进七言的缝隙，就是“以文为律”的开工：拿笔法换宽度**。于是七律成了**最难的体：八句五十六字、四联两对、零容错率——《登高》被胡应麟推为“**古今七律第一**”：推戴先于任何颁奖词成立，凭的是它把对仗推到八句皆对的极限）**。而崔颢《黄鹤楼》——“**白雲千載空悠悠**”明晃晃三平尾、前半首几乎失粘——**却被宋人推为唐律第一**。两案并读，结论浮现：**格律是必要条件，不是充分条件；名篇的地位可以赦免出律，但出律从未毁掉名篇——先有《黄鹤楼》才有“宽限政策”，顺序不能反**。
:::

::: history 一台机器的装配史 {#sec-zhuangpei}
**500s** 永明四声八病——**图纸草创（禁忌清单时代）**；**700** 沈宋“约句准篇”——**二元平仄定标，五律先成**；**720s** 排律盛行——**考场与唱和把律诗拉长到几十韵：机器的极限测试**；**740s—760s** 李白以古体抗律、王维把律写到“无技巧”——**两种路线：绕开机器 vs 让机器隐形**；**760s—770s** 杜甫“晚节渐于诗律细”——**七律成熟：拗体与工体双轨，机器加装手动挡**；**800s—900s** 李商隐以密典入七律——**同样的齿轮，负载翻倍**；**1000s** 江西诗派“**换骨、点铁成金**”——**把杜甫的律读成可拆解的零件库（一诗一工具的教学法）**；**金元** 元好问《论诗三十首》为李商隐的奥僻开辩护票——**接受史替密典诗人补发读者**；**明** 李攀龙们复制盛唐声调——**格律派把律诗变成声调的临摹帖**；**清** 沈德潜《唐诗别裁》与“**格调**”说、**王士禛“平仄声调之学”再编课表**——律学批评达到手册化巅峰；**今** 科举废 120 年后，**平仄以“高考诗歌鉴赏＋老干体＋AI 写作评分标准”三种形态继续执政**——**机器没退休，只是换了三个新岗位**。
:::

::: warning 律诗四坑
**拿“一三五不论”免检**（**该口诀在②'式（孤平位）与救拗位全部失效：先背四句式，再学例外，例外没有目录就是野路子**）；**见到出律就判“伪作”**（**《黄鹤楼》三平尾、《静夜思》失粘——名篇赦免权真实存在；但反过来用出律证明“李白都自由所以我自由”，是把勋章当通行证**）；**只扫平仄不读句读**（**七言“上四下三”的音步与“二二三”的语法分组常打架：先按文法断句，再对平仄表——读破句等于读坏诗**）；**忽略“联”的行政结构**（**起承转合不是玄学：律诗四联=引言、两证、结论——对仗被指定在中间两联，正是“举证环节需要对称”的公文遗产**）。
:::

::: exercise 四式推演 {level=1}
不用表格，从“仄仄平平仄”出发，按对、粘推出**五律四式**的完整八句骨架（标①②③④句式号即可），再给每式配一首已知五律的**首句**作身份证。互评：谁的推导里“粘”错了位。
::: solution
判分：**推导链完整**（规则：对＝同联相对，粘＝邻联第二字同声；答案示例——仄起不入韵：①④／③②／①④／③②；仄起入韵：④②／③④／①②／③④；平起不入韵：③②／①④／③②／①④；平起入韵：②④／③②／①④／③②——**四式＝起句仄起或平起×首句入韵与否，两个开关穷举即止**）；**身份证对应**（“国破山河在”＝仄起不入韵、“青山横北郭”＝仄起入韵）；能讨论“为何没有第五式”（对粘把自由度压光）者加分。
:::
:::

::: exercise 给名联挑法 {level=2}
杜甫“感时花溅泪，恨别鸟惊心”与“星垂平野阔，月涌大江流”，前者历来被认为“拗怒”、后者“工稳”。请各自扫描平仄，**指出前者是否有拗、救在哪里**；然后回答：**同一位诗人为什么需要两台声律机器**（结合写作情境：困守长安的春 vs 舟夜漂泊的怀）。
::: solution
判分：**扫描正确**（“感时花溅泪”＝仄平平仄仄，合“平平平仄仄”首字不论之变；“恨别鸟惊心”＝仄仄仄平平（别，入）——**合式**；“星垂”一联全合正格）；关键在**结论**：所谓“拗怒”部分是**句法与语义的拧结（花溅泪？鸟惊心？主客错位）制造的听觉紧张，不一定要违反平仄——“拗”可以被读出来而不必写进格律表**；两台机器答案：**工稳是容器（漂泊需要秩序），拗怒是内容（秩序失效处的声音）——杜甫的伟大在知道哪首诗该用哪台**。
:::
:::

::: exercise 小论文：格律是协作协议 {level=3}
写六百至一千字，评“**律诗的四行图纸是世界上最省带宽的协议：它把‘好听’标准化，让一千万考生共享同一副耳朵**”。须调用：**四句式与对粘**、**孤平/三平尾的禁忌功能**、**拗救的判例化**、**《黄鹤楼》的赦免权**至少四项；并回答：**协议会不会扼杀创新——用“限制即生成器”（十四行诗、五七言、俳句各举其例）反驳，再给一个不能反驳的边界**。
::: solution
判分点：协议逻辑（**平仄=可机读的耳朵标准：省试靠它批量阅卷，诗人靠它互相听出“工拙”——没有协议，就没有“杜甫的律”这种可比较的成就**）；禁忌功能（**孤平防的是节奏塌方：一句话里平声断炊=气口消失——禁忌保护的是生理节拍，不是权威**）；判例化（**拗救证明协议有最高法院：违宪审查＋判例法=活体宪法**）；赦免（**地位的单向赦免：只赦免已被经典化的作品——“出律而名”是幸存者偏差，学习期切勿模仿**）；边界（诚实答案如：**当协议只剩余量市场（科举已废），它对多数写作者不再构成约束——律诗的“生成力”依赖制度奖励：限制必须是有人看守的限制**）；结论若能写“**创新从来发生在协议的缝隙里；问题是：先有缝隙还是先有协议——本课的答案：先有想被一千万人听见的野心**”，即 A。
:::

::: summary
机器装配完成：四块积木（**两两配对＋对粘＝公路剖面**）、刑法（**孤平死罪、三平尾指纹、拗救判例库**）、扫描实操（**《旅夜书怀》零瑕疵＋一记入声刹车**）、装配史（**永明图纸→沈宋定标→杜甫手动挡→今日三岗再就业**）。方法一句话：**先推导图纸，再谈例外；先断句，后对表**。下一章专拆律诗最讲究的零件间：对仗与对联。
:::
