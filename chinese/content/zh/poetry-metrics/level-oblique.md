---
title: "平仄"
---

格律的全部大厦砌在一种二值代码上：**平、仄**。平是“可以拖长的音”，仄是“不能拖长的音”——**唐诗的声音起伏，本质上是一场关于“气够不够用”的工程**。本章先把这把尺子造出来：包括一把普通话里已经丢失、却到处留下刻痕的尺——**入声**。

## 二元编码 {#def-erzhi}

::: definition 平仄：从四声压缩出来的比特 {#def-pingze}
中古四声（《切韵》系统）：**平、上、去、入**。近体诗不直接用四声，而是先做一次**有损压缩**：上、去、入打包为“仄”，与“平”对立——**四个状态压成一个比特，规则才能简单到可以考试**（接[[han-to-nanbeichao/landscape-yongming]]：永明诗人操作的是四声本身，沈宋之后操作系统改用平仄：**从四色画笔换成黑白打印，反而是排版术的胜利**）。为什么这样切？**平的属性是“平而长”（可拖调），仄的属性是“短促或转折”（不可拖）——律诗的“起伏”就是长音与短音的交替：把平仄读成音乐里的“延音与断音”，比读成音高曲线更接近现场**。
:::

::: definition 普通话的平仄转换器 {#def-zhuanhuan}
今人用普通话判平仄，要过三道翻译：**①阴平、阳平＝平**（ mā、má 皆可拖长）；**②上、去＝仄**；**③入声＝已失踪人口**——`-p/-t/-k` 韵尾在北方话里脱落、并入三声（“入派三声”接[[phonology/to-mandarin]]），于是“**白、石、竹、月、雪、力、笔、国**”今天读阳平、上声、去声都有——**凡读阳平者最危险：古入声字派入阳平的都冒充足好的平声**。查案工具三条：**方言证人**（粤、客、闽、吴、江淮官话保留入声：“六、七、八、十”用白读念一遍，短促即呈堂证供）；**韵尾痕迹**（-b/-d/-g 收尾者百分之百是入声——粤语使用者自带检测器）；**形声线索**（“各”入声→“洛、络、骆”皆入声：声符是家谱，家谱记罪）。
:::

::: example 用平仄读《静夜思》 {#ex-jingye}
平仄串写（依平水）：“床前明月光”＝**平平平仄平**（明平、月入）；“疑是地上霜”＝**平仄仄仄平**（地、上皆去）；“举头望明月”＝**仄平仄平仄**（月又入）；“低头思故乡”＝**平平平仄平**（低平、故去）。请完成三件事：①在串写里圈出全部入声字；②说明“月”字两次出现各完成了什么节奏动作；③从对、粘的账目上证明：**这是一首古绝，不是律绝**。
::: solution
①入声一处字形、两次出场：**“月”×2**（“地、上、故、望、是”皆去声——**去声拖得长，入声关得住门，一听便知**）。②第一句“明月光”：**平＋短促＋平——入声在乐句中间切出一个小台阶**；第三句收脚“望明月”：**全句在短音上急停，抬头的一瞬被“月”的刹车声盖住**——**入声是律句的节奏标点**。③账目：**第二句“平仄仄仄平”不属于四种标准律句之任一**（四仄一平，“地、上”连仄把节奏踩死），且**第二、三句失粘**——**有韵无律的五言古绝**。附赠辨析：李白会写律诗（他工过《登金陵凤凰台》）——**会而不尽是能力，不会而尽是缺陷；用律尺量《静夜思》量出的“出律”，正是它的体裁身份**（[[tang-literature/li-bai]]）。
:::
:::

::: intuition 身体检验法 {#int-shenti}
平长的交替骨架在语音演变中幸存（[[phonology/to-mandarin]]）——**建筑还在，只是墙上的漆换过三次**。
:::

::: history 一条声调的编年 {#sec-biannian}
**480s—510s** 周颙辨四声，沈约论文“**前句有浮声，则后句须切响**”（《宋书·谢灵运传论》——**四声入文的开工令**）；**501** 刘勰《文心雕龙·声律》“**异音相从谓之和，同声相应谓之韵**”；**601** 陆法言《切韵》——**韵书为四声立字典**；**700s** 沈宋定平仄二元的近体；**806** 空海《文镜秘府论》辑唐代声病之学；**1030s—1070s** 科举韵书《礼部韵略》颁行；**1324** 《中原音韵》入派三声，**北曲另立声系统（平分阴阳、入派上去）**；**1919** 赵元任拟《施氏食狮史》——**同音文是白话时代给文言做的一次压力测试，也顺手暴露了废入声的隐性成本**；**1958** 王力《汉语诗律学》：千年口诀变成表格学科。
:::

::: warning 判平仄四坑
**用今音硬判古入声**（“**白首”的“白”、“明月”的“月”读成平／长调即出律**——判不准就查表，查表前先找方言证人）；**把“一三五不论”当万能免检**（**它只在小范围内成立，且救不了孤平与三仄尾的边界案例——本尺子的刻度下一课细校**）；**认为平仄是音高**（**普通话的“调值”是音高曲线，平仄的第一属性是长短与开闭——把它当四声简化版，比当五线谱更接近真相**）；**忘了诗体分工**（**古体、词、曲各用各的声系统：用律诗尺子量《蜀道难》，等于用考卷改李白**）。
:::

::: exercise 入声户口普查 {level=1}
**普查记录须含“长短”判断，而非“像不像外语”**；②合格答案如《登鹳雀楼》“**白、日、欲、穷**”中的入声（“白日依山尽”的白、日，“欲穷千里目”的欲——**一首二十字里藏着四个入声**）；③“各”族：洛、络、骆；“谷”族：欲、裕、峪；“折”族：哲、浙、蛰——**形声声符即家谱：凡从“白、赤、昔、戍”得声者基本全族入声，逐个过堂即可结案**。
::: solution
判分：**普查记录须含“长短”判断，而非“像不像外语”**；②合格答案如《登鹳雀楼》“**白日依山尽**”的白、日与“**欲穷千里目**”的欲——**二十字里藏三个入声**；③“各”族：洛、络、骆；“谷”族：欲、裕、峪；“折”族：哲、浙、蛰——**形声声符即家谱：凡从“白、赤、昔、戍”得声者基本全族入声，逐个过堂即可结案**。

::: exercise 给打油诗做声带手术 {level=2}
给句子“我是真好看”做声带手术：先标注五字平仄（“看”在律诗中平去两读，自注取舍），再改成合格律句：**至少两处不同改法，分别用“替换字”与“重排语序”**。互评：哪一处改动损失了意思、哪一处只是换了漆。
::: solution
判分：**平仄标注**（我仄、是仄、真平、好仄、看平／去）；**改法一（替换）**：换字保意（如“渠自是无双”一类，平仄合规且词义无损）；**改法二（重排）**：利用位序重组（“真、看、好、我、是”在“仄仄平平仄／平平仄仄平”两类目标格式中各寻其位）——**答案开放，但必须先报目标律句格式再填字：先出图纸后施工，是本课唯一硬纪律**。
:::
:::

::: exercise 小论文：平仄是语法还是修辞 {level=3}
写六百至一千字，评“**平仄是汉语诗的形式语法：违反它不是丑，是另一种句子**”。须调用：**四声→平仄的压缩**、**“一三五不论”的限度**、**古体与近体的分工**、**词曲另立的声系统（预告）**至少四项；并回答：**当新韵运动主张“以普通话为准重新立法”，反对者在保卫什么**（提示：不只是怀旧——入声的长短属性、方言共同市场、与唐诗的兼容协议）。
::: solution
判分点：语法／修辞之分（**平仄规则像语法：不守产出的是“另一首诗体”（古体／词／自由诗），而非“坏诗”——“丑”与“另一种句子”是本课的分水岭**）；压缩逻辑（**规则的成本：越易学越普及，越普及越僵——每次松绑（拗救、词谱）都是对新场景的回应**）；“一三五不论”须被当作**民间口诀的失真**来处理；新韵之争三账并算（**听觉账：普通话读者确实听不出出律；兼容账：与全部唐诗的互译成本；市场账：方言区的退出成本——立法问题从来是利益分配**）；结论若能写“**韵书是字体文件：换字体可以，但别声称原版打错了**”，即 A。
:::
