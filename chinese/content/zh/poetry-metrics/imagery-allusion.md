title: "意象与用典"
---

前八章量的是容器：平仄、韵、句式、谱。本章开箱：**为什么“月”不用解释就凉，“柳”一出现就有挽留的意思，“栏杆”一拍人就在愁**——意象是汉语诗的公共账本，用典是往账本里加记录；**读懂这两样，格律课才从声学变成经济学**。

## 公共账本 {#def-zhangben}

::: definition 意象：预装语义的共享对象 {#def-yixiang}
意象≠修辞手法，是**协议**：一代代名篇把含义写进物，后人引用时连含义一起引用——“**月”被李白们登记为“故乡与时间”的账户（边月、秦月、明月几时有）；“柳”谐音“留”，灞桥折柳自唐人成为送别的预装程序；“雁”捎过书（苏武雁书的典故把信箱永久存进了鸟）；“栏杆／高楼”＝望不见的姿势（温庭筠“**独倚望江楼…斜晖脉脉水悠悠，肠断白蘋洲**”——**独倚、楼、水、肠断四件出厂绑定**）；“长亭”＝官方里程表变离别计量单位（十里一长亭：**驿路系统被抒情征用**）”。三级台阶：**物象（月亮）→语象（“明月”的诗歌化拼写）→典故化意象（“月”自带思乡字段）**——读到第三级，**读一句＝解压缩一柜子过往文本**：意象是汉诗的对象库，用典是它的引用计数（本课的“压缩”在例题里有正式审计）。
:::

::: definition 用典四操作 {#def-si-caozuo}
**正用**（照原案引用：“**持节云中，何日遣冯唐**”——苏轼把自己过继给冯唐的故事，求起复的表忠体）；**反用**（把典故引渡进当前的争论——同一份文件，签相反的批注：王安石《明妃曲》“**君不见咫尺长门闭阿娇，人生失意无南北**”，一句掀掉“怨画工／思汉宫”的千年剧本——失意与地理无关）；**翻案**（对原判决重开庭：“**胜败兵家事不期，包羞忍耻是男儿。江东子弟多才俊，卷土重来未可知**”——杜牧把项羽的自辩上诉到唐代的舆论庭；李清照“**至今思项羽，不肯过江东**”再翻回：**同一段乌江，宋人要的是耻，唐人要的是气——用典是跨朝代的听证会，每代重新作证**）；**化用**（无痕引用＝最高级：“**碧云天，黄花地**”整购范仲淹而无人喊抓；“**明月几时有，把酒问青天**”李唐旧题新做——**化用的法律解释：引用到无人起诉，即为公有领域**）。
:::

::: example 辛弃疾的压缩率：《永遇乐·京口北固亭怀古》 {#ex-yongyule}
“**千古江山，英雄无觅孙仲谋处……想当年，金戈铁马，气吞万里如虎。元嘉草草，封狼居胥，赢得仓皇北顾。四十三年，望中犹记，烽火扬州路。可堪回首，佛狸祠下，一片神鸦社鼓。凭谁问：廉颇老矣，尚能饭否。**”请：①在限时无注条件下读出**每个典故对当下语境的极性**（正／反／翻案）——孙权、刘裕、刘义隆、佛狸、廉颇各在替谁说哪句话；②“凭谁问”**收在廉颇上**：为什么必须是“尚能饭否”这种**问句式典故**；③把注释全部没收，此诗还“活”吗？——给“隔与不隔”做一次操作化验收（王国维“**语语都在目前，便是不隔**”）。
::: solution
①极性表：**孙权／刘裕＝正用而含讽**（英雄无觅——夸的是京口，骂的是临安：借古人**做空白对照实验**）；**刘义隆＝反用的警告**（“元嘉草草”——借宋文帝的北伐惨败，给韩侂胄的北伐预写判决书：**正话反说的教科书**）；**佛狸祠＝最狠的意象兼典故**（敌主的祠庙香火旺盛——**沦区的百姓在祭入侵者：一句画面顶十段奏疏**）；**廉颇＝自比兼自辩**（谗人环伺的老将——把“主战”与“被弃”同时挂号）。②问句式典故＝**把决定权交给问句**：陈述用典是认领，**疑问用典是叫价**——“尚能饭否”不给答案，答案由朝廷回答：**用典的最高外交格式**。③验收：没收注释后，此词**半活**——“神鸦社鼓”“金戈铁马”“廉颇老矣”靠语感与画面存活（**不隔的部分**）；“元嘉”“佛狸”失去注释即失联（**隔**）。判决：**辛词赌的是受众的公共字典仍在——它把隔的部分押给时代，用不隔的部分（画面、语气、结构）先收款**；赌赢了千年，直到字典改版（今日教学注释=**给失修字典补发词条**）。**隔与不隔不是作品的属性，是作品与读者库存的差额**（“**用典是压缩算法：字典共同＝无损，字典过期＝加密**”——例题审计结论）。
:::

::: intuition 掉书袋的辩护词 {#int-shudai}
反方证词也很长：钟嵘《诗品》以“自然英旨”论文，把借人成语的“补假”记作文病——**反用典的第一份宪章**；元好问以下，批评家屡弹“獭祭”一路——**他们把用典分成“使事”与“掉书袋”两档，判词全看典故是否还在干活；辩护词一方：黄庭坚“**点铁成金**”“**脱胎换骨**”（惠洪《冷斋夜话》所记）**——把读书定义为原料工业：问题不在用不用，在化不化**；王士禛神韵派走另一极端——**不着一字的洁癖其实也是用典（否定式用典：以不引为引，装没读过书）**。**真相折中：密度不是罪，空载才是——典故要么载画面（辛），要么载反讽（王），要么载音韵（李商隐的“庄生晓梦”—典故当乐器用）；只载学问的，才叫书袋**。
:::

::: history 一部注释产业史 {#sec-zhushi}
**唐**：类书（《艺文类聚》《初学记》——**写作供应链的原料超市，“用典＝引用即合法”时代**，[[tang-literature/early-tang]]）＋《文选》“**熟精《文选》理**”（杜甫语）——**士人的共同字典第一卷**；**宋**：西昆体把李商隐读成“獭祭”范本（**元白浅 vs 西昆密：两条发行路线**）；“**杜诗无一字无来处”的伪说流行——**神话注者比神话作者勤快：读者开始倒推每一个字的户口**；**江西派把用典方法化（点铁、夺胎——从实践升格为教学法**）；**明清**：**笺注业全盛（李善《文选注》系统重刻、冯浩玉溪生诗笺注——解释学产业化：压缩率越高，注释业越发达——这是文学经济学的铁律**）；王渔洋“神韵”做空、查慎行辈考据做多是同一市场两个板块；**清中叶—**：宋诗运动以“**以学问为诗”复辟（同光体：把注释压力转嫁给读者的一种勇气**）；**民国—今**：**“隔与不隔”之争（王国维判南宋词典故“如雾里看花”）、“典故=封建糟粕”的激进年代——注释权的革命；今日：注本销量常高于诗集——**古典诗的现代生存形式是它的脚注**（本课立场：**脚注不是尸检报告，是器官捐献同意书——让旧文本在新读者身上继续工作**）。
:::

::: warning 用典四坑
**以密为高**（**掉书袋的定义：典故空载——查到了出处却查不出为什么是它；验收句式：“这个典若换成别的，诗会损失什么？”**）；**以注代诗**（**笺注考出十件事、诗仍没读——先当诗读，再当档案读；顺序倒了就把诗读成了注**）；**以为古人到处用典**（**乐府、白居易、词之“自然”一路全在反典；用典是士大夫方言，不是古代汉语的普通话**）；**把“不隔”当白话**（**王国维测的是直观性不是口语度——“天若有情天亦老”字字认识却人人隔；不隔＝画面先行，白话只是捷径之一**）。
:::

::: exercise 意象考古 {level=1}
给“雁”或“柳”做**账目卡**：①列四个含它的诗句（学过的即可）；②各标出它在其中干什么（捎书／见证／自况／布景）；③写 30 字预测：**二十年后的 AI 诗歌里，这个字还想保留什么含义才不沦为装饰**。
::: solution
判分：**功能标注不重复、至少两句有诗可查**（“鸿雁长飞光不度”＝捎书的失败版——**连雁都飞不过去，月光比音信先到**：这类细读即得分点）；**自况要有位置感（北雁＝季节打工人）**；预测题考机制理解：**只要还有人用它承载“远方＋音信”的账，意象就活着；纯布景用法是坏账前兆**。
:::
:::

::: exercise 反用实验室 {level=2}
选一个“标准答案典故”（愚公移山、囊萤映雪、刻舟求剑、守株待兔任选），写 4—8 行：**先复述其“官方寓意”两行，再用“反用或翻案”改写两行**，最后给两句“听证会记录”（唐人会怎么判，你会怎么判）。
::: solution
判分：**翻案要有靶子**（“刻舟求剑”的官方寓意若直接复述＝未作案）；**新旧两版必须共享细节**（“剑”“舟”“标记”留在现场——**反用的取证规则：同一物证，不同供词**）；听证记录若出现“判决随时代改判”的自觉（胜败论／坚持论的利害分析），即本章知识点的满分兑现。
:::

::: exercise 小论文：用典的生死簿 {level=3}
写六百至一千字，评“**用典的兴衰是读者市场的兴衰：共同字典厚，典故是杠杆；字典薄，典故是税**”。须调用：**意象三级台阶**、**四操作各一例**、**辛弃疾压缩率案**、**注释产业史（宋神话注／清笺注／今注本销量）**至少四项；并回答：**新韵新诗的当代，诗人还“用典”吗——若“梗”就是今天的典故，两者的验收标准相同吗**（要求给出“梗”失效速度与典故千年寿命的差异机制）。
::: solution
判分点：市场逻辑（**杠杆／税之辨=有无共同库存：李白用冯唐不注释，因字典人手一册；今天用同样典故，一半读者交税**）；四操作（**正反翻化按“是否干活”验收**）；压缩率案（**隔与不隔=作品与读者库存的差额**）；梗之问（**同构：梗＝高速贬值的典故——寿命差在介质：典故靠教育制度年复一年续签，梗靠平台流量每日结算；所以梗入诗天然“隔”得快，除非把梗写成不需要梗也能懂的画面（即：完成从梗到意象的升级）**）；结论若能写“**一切用典都是在跟不存在的人合唱：字典在，声音就在**”即 A。
:::

::: summary
开箱结账：账本（**月、柳、雁、栏杆、长亭——预装语义的共享对象，读一句解压一柜子**）、操作（**正用认领、反用批注、翻案开庭、化用到无人起诉**）、审计（**辛弃疾赌公共字典：把隔的押给时代，用不隔的先收款**）、产业（**神话注、清笺注、今注本销量——压缩率越高，注释业越发达**）、直觉（**密度不是罪，空载才是**）。方法一句话：**见典先问它替谁说哪句话；见意象先查它的账龄**。最后一章把十二件事串成一根绳：怎样读一首诗。
:::
