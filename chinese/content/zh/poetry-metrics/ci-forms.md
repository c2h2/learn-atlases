---
title: "词的体式"
---

诗是“读”的文体，词起步于“唱”的文体——**这个出身差，决定了词的全部格律学都是一份乐谱的转写**。上一章说过“词无定体之霸，只有按谱打工的填词人”；本章教你读词谱，并解释一个反转：**词律后来比诗律还严——因为它要伺候的不只是耳朵，还有一件乐器**。

## 读谱 {#def-dupu}

::: definition 词牌＝乐谱＋格式合同 {#def-cipai}
词谱逐字规定四件事：**字句定数**（一句几字、全篇几句，连“叠字”“句读”都写死——《菩萨蛮》44 字、《莺啼序》240 字，**规格差出五倍半：一个牌子就是一台定制机器**）；**平仄定位**（比律诗细：**可规定某字必去、某字必上**——因为旋律的升降要咬住字调）；**韵位定所**（哪里押、押平押仄、第几句换韵——《菩萨蛮》是“**两句一换韵、平仄韵轮换**”的折返跑：照“小山重叠金明灭”数，五句一组的韵脚像换歌的副歌标记）；**分片结构**（单调一段、双调上下两片、三叠四叠——**“片”＝音乐的重复记号：下片换头不换腔，词因此是“分节歌”的文学**）。读谱法示范：**先看韵位（换几次韵＝分几幕），再看句式（长短＝呼吸），再看领字（见下节），最后才看平仄**——平仄最琐，却常是词人内卷的战场。
:::

::: definition 容量分级：令、引、近、慢 {#def-rongliang}
小令（约 58 字内）、中调、长调（慢词 91 字起）的清代分法是**事后按字数归档**，真实演化线索只有一条：**音乐在变长**。唐五代是单曲短歌（《忆江南》27 字的一支小曲）；**宋仁宗朝“市井新声”竞争，柳永把小令扩成慢词——140 字的《雨霖铃》是唐代流行歌的 12 英寸加长版：前奏铺叙、副歌回环、结尾拖腔**（“**多情自古伤离别，更那堪、冷落清秋节**”的位置正落在下片高潮轨上）；“引”“近”是介于令慢之间的加拍过渡体（**只需记住：令、引、近、慢是同一首曲子在时长轴上的四个剪辑版本**）。**容量即结构**：小令一次曝光（上一章绝句学），慢词一次**电影**——铺叙、提顿、回环全是长镜头技术；**词体史的第一推动力不是诗人，是夜生活的时长**。
:::

## 词的独立宪法 {#def-xianfa}

::: definition “别是一家”：李清照的验收标准 {#def-bieyi}
李清照《词论》对当世名家搞了一次“活体验收”：柳永“**词语是矣**”，柳永于音律“**犹有未合**”，铺叙华美一律不算过审；张先、宋祁、黄庭坚辈“**皆句读不葺之诗尔，往往不协音律**”——把名家的词当场判回“诗”；东都词坛几乎全员被打分，无人请假。她随即立宪：“**词别是一家**”——这条标准的厉害在于**评审人的资格**：被点名的全是男性顶流，而出题人是北宋末年最会写词的女性之一——**词学史上第一次“验收权”的争夺战，打赢的方式是拿出更专业的耳朵**（“**歌词要求‘五音六律五声八病’，诗文并不要求：词的门槛是双证上岗**”）。反转在后：**南宋“雅化”一脉把词往诗的方向拉（辛弃疾以文为词），格律派（周邦彦—吴文英—姜夔—张炎）则把音律推向单字四声——两条路线的尽头在 1200 年前后对撞，词律成为全中国最严的格律**。
:::

::: definition 领字与入声：指挥棒与刹车片 {#def-lingzi}
**一字领**（“**对**潇潇暮雨洒江天”“**渐**霜风凄紧”“**望**长城内外”——**一个字把后面三四个四字句全部指挥起来：领字＝乐队指挥棒，谱上注明“一字豆”，唱时起一个引导音**）；**二字领、三字领**同理（“**恰似一江**”“**最喜燕山**”级——**领字让词在整齐句式里长出一根天线，接收句外的语气**）。**入声韵的看家戏**：《忆秦娥》“**西风残照，汉家陵阙**”、《声律》课气温表——**词牌有性格：《满江红》全用入声韵（歇、烈、月、切——怒发冲冠的“齿音关门”配音的怒吼）；《兰陵王》“柳”调三叠、入声相配，送别写出了安可曲的长度**——**选词牌＝选情绪的预制板；填词人的第一道选择题不是写什么，是“用哪个歌”：词牌的“题材记忆”会替你说话（《桂殿秋》短促宜梦，《莺啼序》二百余字宜铺陈一生）**。
:::

::: example 一首《菩萨蛮》的完整读谱 {#ex-pusaman}
温庭筠《菩萨蛮》：“**水精帘里颇黎枕，暖香惹梦鸳鸯锦。江上柳如烟，雁飞残月天。　藕丝秋色浅，人胜参差剪。双鬓隔香红，玉钗头上风。**”请按本课顺序读谱：①标出韵位换韵（画出了几幕？）；②数出每句字数，解释“片”的边界；③找出可称“领”的字（若无，说明此调为何不需要领字）；④把上片“江上”两句与下片“双鬓”两句对读，**说明词的“镜头语言”与近体诗的句法分工有什么不同**（温庭筠的“无人称”在此如何靠韵位维持）。
::: solution
①韵位：**枕／锦（上声）→ 烟／天（平声先韵）→ 浅／剪（上声）→ 红／风（平声东韵）**——**两次平仄往返，四组韵＝四次换光**：上片室内（枕、锦）切到室外大远景（江、柳、雁、月），下片再切回妆饰特写——**《菩萨蛮》的“折返跑韵位”强制场景来回跳：这个牌子的“性格”就是镜头的推拉轮转**。②44 字、八句、两片各四句：**下片＝上片旋律的变奏重复（换头）**——词的结构单位是片不是联。③**无领字**：句句五字七字自成单元，此调不指挥长句——**领字是慢词的装备（长调才需要指挥棒调度长镜头；小令连呼吸都短，指挥是多余的礼貌）**。④镜头语言：**“江上柳如烟，雁飞残月天”两句纯景无人称，与近体的“主谓宾抒情句”不同；“双鬓隔香红”让首饰当主语——词的句法被歌者的停顿切碎，名词并置接的是音乐的拍点，不是语法的句子**（上一章“温的镜头”从格律上落了地：**韵位换光＋拍点并置＝花间美学的两件套硬件**）。
:::
:::

::: intuition 格律是延迟交付的音乐 {#int-yanchi}
曲谱失传后，词谱变成了什么？**一份无法运行的乐谱的注释文档：平仄是旋律的化石，韵位是节拍的化石，入声是某段咽腔的化石**——南宋以后的人填词，实际是**照着化石临摹音乐**；到明清，连临摹者也不唱歌了——**格律彻底成为“听觉记忆的纯文字备份”**（这解释了词的规则为何显得“无理的严”：去声字处当年有一个下滑音，词人不知道，只照抄——**形式是内容的存款单，利息到期后凭单仍能取钱，只是没人记得存过什么**）。对照诗：律诗的平仄在语音演变里仍自洽（长短交替还在起作用），**词的平仄有大量“纯乐理残留”**：因此“按谱填词”这件事，本质是**给一门死语言写语法**——而它居然很好用：因为备份足够完整。
:::

::: history 从歌本到字书 {#sec-geben}
**唐—五代**：曲子词＝歌本（敦煌“曲子”无题、《花间》称“**诗客曲子词**”——**作者是供应商**，[[tang-literature/five-dynasties-ci]]）；**北宋**：柳永扩刊（长调）、**苏轼“以诗为词”——第一次违约：把歌辞当诗写**（门生故吏集体抗议：**词律的独立宪法刚立，就有人拆墙**）；**1100s**：**周邦彦提举大晟府，校订旧调、创制新腔——词的皇家音乐学院定谱时代（官方乐工兼任国家标准委）**；**南宋**：李清照立宪、辛弃疾以文为词（第二次违约）、**姜夔自度曲并旁注工尺谱——词人最后一次兼任作曲人（《白石道人歌曲》旁的谱字是音乐与文学最后的订婚礼书）**；**宋元之际**：张炎《词源》、和韵内卷到“**依四声**”（唱和军备竞赛最终章：**逐字复刻对手的声调**）；**元**：曲盛词亡于乐——**词转入纯文本行业**；**清**：**《钦定词谱》八百余调、《词律》考订句读——填词成为“古典字体排印学”：清词中兴中兴的是文献，不是音乐**；**今**：歌词行业接棒填词（方文山的“素韵”与林夕的“协音”——**粤语歌保留“依声填词”的活体工序：普通话歌词则多数只押大致相同的韵——词律的最低生活保障由流行歌代发**）。
:::

::: warning 读词律四坑
**用诗律判词出律**（**词各有谱：《西江月》平仄韵互叶、《清平乐》半首换韵——“出律”多是出诗律：先找到它的歌**）；**把词牌当题目**（**《永遇乐》不是“永远遇到快乐”：词牌是曲名＋格式，题意自注或另标——误读词牌＝把 MP3 文件名当成歌词内容**）；**忽略入声字**（**词谱指定入声处用普通话挑字必错：《忆秦娥》“阙、月、绝”是硬指标——第一章的入声查案在词里是上岗取证**）；**以为“按谱填词＝安全”**（**谱管字面不管声情：把豪放词牌填成婉约内容，乐器会替听众退票——“句读不葺之诗”的判决在九百年后仍适用于 KTV**）。
:::

::: exercise 读谱员 {level=1}
取一词谱（《如梦令》《卜算子》任选），**逆向做谱**：把一首依此调填写的词（自选），逐字标出平仄与韵位，归纳出该谱的“幕表”（几幕、每幕韵性、何处顿）。互查：谁的幕表能只凭符号预测出下一句的字数？
::: solution
判分：**幕表可预测性**（能预测＝抓住了乐句周期——**韵位就是乐句的句号**）；**韵性标注含“平—仄—平”或“换几次光”**（《卜算子》偶句押、仄声韵——**两次换幕**）；标出词中入声字并给“若换平声字会怎样”的听感判断——**读谱员的耳朵＝会看谱的嘴**。
:::
:::

::: exercise 选牌 {level=2}
给自己的一段真实情绪（150 字内，忌“悲伤”“快乐”直陈）**配一个词牌**并说明理由：从“容量（令/慢）、韵位（几次换光）、声情（入声与否、韵部气温）”三项论证；不填词，只交“选曲单”。
::: solution
判分：**三项各给一句技术理由**（“选《如梦令》因它短到只能憋着；选《满江红》但我气不足，故改《鹊桥仙》——**金风玉露一相逢**的节奏适合慢慢说重话”级）；**出现“用词牌自带的题材记忆”意识**（用《鹧鸪天》写乡愁会继承“歌单里的老歌效应”——**词牌是预制板，也是前作的回声**）者满分。
:::
:::

::: exercise 小论文：先有乐还是先有律 {level=3}
写六百至一千字，评“**词律是一部失传音乐的法律遗产：它证明形式能在内容消失后继续立法**”。须调用：**词谱四件套**、**慢词的容量演化**、**《词论》别是一家**、**领字/入声的乐器残留**、**依四声唱和的内卷**至少四项；并处理一个反方：**既然音乐没了，今天填词的一切“合律”都是装——不如彻底投新韵新体（为音乐而写，例如歌词）**。
::: solution
判分点：四项机制（**乐→律的转写（化石备份）；时长驱动体裁；验收权与耳朵；依四声＝把无法验证的声符内卷成社交货币**）；反方处理（**可半接：歌词确是“词”的正统继承人——“为乐而写”从未停线，只是换了载体；但保留一派“读词”也合法：**当格律成为纯文学的声纹约束，它提供的不再是音乐而是“抵抗顺口”的摩擦力——词的价值恰在磕绊处（辛派散文句与乐句打架的位置）**）；结论若写“**我们不是在复刻声音，我们是在用文字给声音留座——只要人类还需要‘差一点唱出来’的感觉，词就不算死**”，即 A。
:::

::: summary
四份文件归档：合同（**字句、平仄、韵位、分片：一台牌子一台机器**）、时长（**柳永的 12 英寸加长版；词体史第一推动力是夜生活时长**）、宪法（**“别是一家”：乐器不签字不算过审——评审资格之战**）、化石（**领字是指挥棒，入声是刹车片；格律是延迟交付的音乐**）。方法一句话：**先找歌，再读律；先幕表，后平仄**。下一章去词的下一代产品：曲——把衬字、俗语和整个市井塞进格律的改版系统。
:::
