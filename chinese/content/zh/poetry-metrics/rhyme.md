title: "押韵与韵书"
---

上一章造了平仄这把直尺，本章上秤：**韵**。押韵看似天经地义，实际上有三桩公案：**韵按什么定义？韵部为什么是 106 个而不是 30 个？出韵为什么能毁掉一个前程？**——答案分别指向：**韵书、行政、考试**。

## 韵的解剖 {#def-jiepou}

::: definition 韵部：按韵书归档，不按耳朵 {#def-yunbu}
诗韵的“韵”＝**韵腹＋韵尾相同（介音不计，声母无关，声调必须同）**——“关、还”同韵押得，“间、简”声调不同押不得（**平上去入各押各的：律诗一韵到底且只用平声**）。关键在“**按韵书归档**”：《切韵》系韵书本是**隋音汇编**（陆法言“欲更开塞音韵”——**它记录的不是长安活口语，是南北士族读书音的联席会议纪要**，参[[phonology/rhyme-books]]），唐官定《唐韵》增为 206 韵、**同用独用**由官府贴告示（某韵“独用”＝押混即犯规；某几韵“同用”＝特许合并）；宋金之际平水系统将同用者正式并案，**106 韵的《平水韵》成为元明清近体押韵的事实标准**——**韵部史半是语音史，半是公文史：“东、冬”不同用，不是听不出来，是告示说不能混**。
:::

::: definition 韵的三件刑具 {#def-xingju}
**①出韵**：用邻韵字＝省试除名。“**东、冬不算一东、二冬的亲戚**？”——对，不算：**考官只带韵书入场，耳朵不在编制**。**②借韵特赦**：首句可用邻韵（“**孤雁出群格**”）——**格律体系给开门处留的活门：第一句是迎宾，不算正厅**。**③重韵禁令**：律诗不得复用同一韵字——**二十字的小房间不许挂两幅一样的画**；古体、词、曲另议（《中原音韵》系曲律甚至平上去通押、韵脚可重——**每一部韵书都自带一部法典**）。附一桩著名悬案：**次韵**（和诗照搬原唱韵字且次序相同）——元白把它玩成军备竞赛；苏轼《聚星堂雪》一路更叠加“禁体物语”（咏雪而不得用“玉、月、梨、梅”等字）——**险韵加禁字，和者披靡：“韵”从规则升格为难度模式，宋人在镣铐上加装负重**。
:::

::: example 一首诗的韵部验尸 {#ex-yanshi}
柳宗元《登柳州城楼寄漳汀封连四州》：“城上高楼接大荒，海天愁思正茫茫。惊风乱飐芙蓉水，密雨斜侵薜荔墙。岭树重遮千里目，江流曲似九回肠。共来百越文身地，犹自音书滞一乡。”①标出韵脚并查其平水部类；②此诗若把“荒、茫、墙、肠、乡”全换成“东、冬”韵字，情绪会掉多少；③近体“一韵到底、不用重韵、只押平声”三条，各在本诗里如何兑现？
::: solution
①韵脚：**荒、茫、墙、肠、乡**——同属下平七阳（**“墙”亦阳韵：ang 一以贯之**）：**零出韵、零重韵、平声到底**，三条全兑现。②情绪掉多少——做一组最小对照：示范改法：“接大**东**／正朦**胧**／密雨斜侵薜荔**栊**／江流曲似九弯**中**”：**阳韵（-ang）开口最大、鼻腔共鸣最长＝愁思的扩音器；东钟（-ung）口腔收拢、听感昏暗＝同一首诗意象立刻从“海天茫茫”缩成“烟雨朦胧”**——**韵不是包装纸，是配器法**（本课的“韵的音色学”：-ang 开阔、-i 细窄、闭口韵 -m 呜咽：见 warning）。③“滞一乡”的“一”是入声（**在句内当节奏标点，见上一章**）——**入声不进韵脚（律诗押平声），但随时在句中刹车：平仄管节拍，韵脚管押响，入声管停顿——三种声音职务互不兼任**。
:::
:::

::: intuition 闭口韵的尸体 {#int-bikou}
平水韵“侵、覃、盐”诸部（**下平十二侵：“吟、深、寻、心”；十四盐：“帘、尖、淹”**) 的上古—中古读音带 **-m 韵尾**（“三、南、心、金”读如 sam、nam、sam、kam——粤语仍如此，参[[phonology/to-mandarin]]）；**-m 尾在北方话约于元明之际并入 -n**，可《平水韵》把“侵寻”“廉纤”两具标本冻在卷宗里——**诗人从此押一个自己发不出的音：韵书比口语多活的这两百年，就是“格律滞后于语音”的标本**。于是：**帘卷西风，人比黄花瘦**”“**深巷明朝卖杏花**”的韵脚，原主人口中是闭着唇落锁的：**读诗的听觉考古，挖到的往往是亡音**。
:::

::: history 一部韵书的政权更迭 {#sec-zhengquan}
**601** 陆法言《切韵》——**“论韵尊陆法言”：一部家庭音韵沙龙（颜之推在座）的纪要成为三百年官韵**；**658 起**长孙讷言笺注、孙愐《唐韵》官修扩编——**韵书国有化**；**1008 起**《广韵》《集韵》——**206 韵的“字库＋索引＋判例汇编”**（韵书兼字典：**按韵查字＝按主键查询：中国第一部成功的关系型数据库**，参[[phonology/rhyme-books]]与[[chinese-characters/origins]]）；**1100s—1200s** 科场实用本《礼部韵略》与平水 106 并案——**市场把官韵减配成考试专用版**；**元**《蒙古字韵》八十一韵、周德清《中原音韵》十九韵——**北曲另立宪法：平分阴阳、入派三声，词韵与诗韵从此三套并立**；**明清**：《佩文诗韵》钦定——**科举复活的旧法典：出韵案在殿试场上一直审到 1904**；**1941**《中华新韵》十七韵（国语罗马字派）与 1965 修订、**今“中华新韵”（十四韵）**——**新韵不是要废古，是给普通话耳朵发驾照**（教育部 2012《中华新韵》行标：**两套系统并行登记：兼容协议的谈判仍在进行**）。
:::

::: warning 押韵四坑
**用今音断古人出韵**（“远上寒山石径斜（xiá），白云生处有人家”——**“斜”古属麻韵：不是古诗跑调，是你搬家换了口音**；拿不准先查平水，再下结论）；**把新韵旧韵当善恶之战**（**两套都是约定：旧韵兼容唐诗全库，新韵兼容普通话听力——选型问题，别开批斗会**）；**忽略词曲另有法典**（**词韵比诗韵宽（上去可通、可换韵），曲韵按《中原音韵》：用平水尺量李清照，量出来全是“出韵”**）；**迷信“韵位固定”的美感**（**七言二四六分明是后人口诀：真正的节拍单位是音步与停顿——先读出声，再对表格**）。
:::

::: exercise 韵的配器 {level=1}
同一句意思（如“我想你”），分别押 **-ang、-i、-u** 三组韵脚各写两行（口语或文言不限），互测：**哪组最响、哪组最私、哪组最闷**，并说明口腔开度如何“作弊”成情绪。
::: solution
判分：**三组韵脚各自统一**（-ang：窗、灯、长；-i：你、雨、期；-u：路、雾、暮级）；**口腔开度报告**（-ang 开口＝广播，-i 扁细＝耳语，-u 圆收＝被窝——**押韵的“好听”一半是元音声学**）；能自曝一次“为了韵脚改意思”（韵脚决定论的现场体验）者满分。
:::
:::

::: exercise 出韵公案重审 {level=2}
给“‘远上寒山石径斜’按普通话不押韵，诗人犯了错误”这一判词写一份**再审判决书**（150 字）：**要求引用两部“法典”**（平水韵/中华新韵）**的时间效力条款**。
::: solution
判分：**管辖权分析**（唐代作品适用唐代有效韵书：**平水（唐韵系）为行为时法，新韵为裁判时法——从旧兼从新的讨论必须先声明适用体系**）；**驳回“错误”说**（“斜”古音麻韵与“家、花”同部：**押得**）；若写“教学场合可注‘读 xiá 或依今音说明古今异’”这类务实尾巴，加分——**判决书要能执行**。
:::
:::

::: exercise 小论文：韵书是数据库还是牢笼 {level=3}
写六百至一千字，评“**韵书把语言冻成档案，诗人靠解冻与走私过日子**”。须调用：**《切韵》“联席会议纪要”性质**、**同用独用与平水并案**、**借韵特赦**、**-m 韵部消亡而韵书保留**、**新韵之争**至少五项；并回答：**如果重来一次，你会给近体诗设计几部韵**（给出你的方案并说明牺牲了谁）。
::: solution
判分点：五项机制（**韵书＝按韵归档的数据库（查字即查询）；同用独用＝行政热修；平水并案＝市场减配；亡音保留＝兼容性债务；新韵＝换运行时**）；“冻结—解冻”主线（**诗人的日常：在法定韵部内挑词＝戴着目录写作；借韵、通韵、次韵＝合法走私与炫技**）；设计方案（**开放题，判分看“牺牲了谁”的诚实：减韵部＝牺牲与唐诗的互译；保旧韵＝牺牲普通话学习者——没有无损立法**）；结论若能写“**一切格律都是语言政策：韵书不是诗写的，是诗要遵守的那座城市的规划局写的**”，即 A。
:::
:::

::: summary
三桩公案结案：定义（**按韵书归档：耳朵不在编制**）、刑具（**出韵除名、借韵特赦、重韵禁令、次韵负重**）、音色（**-ang 是扩音器、-m 是冻尸：押韵的一半是元音声学**）、政权（**沙龙纪要→官韵→考试减配版→三套宪法并立→新韵发照**）。方法一句话：**见韵先问：依哪部法典？哪年生效？**下一章装配主机器：律诗的四种平仄格式与粘对工程图。
:::
