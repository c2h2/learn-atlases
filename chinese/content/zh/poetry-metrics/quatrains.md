---
title: "绝句"
---

绝句是律诗的**半台机器**：四句、二十八字、不强制对仗——**看起来是减少了工作量，实际上是把全部难度压缩到了“怎么停”这一件事上**。本章拆两件事：**律绝的出厂设置，与古绝的另一个宇宙**。

## 半台机器 {#def-bantai}

::: definition 律绝：四句的完整论证 {#def-lvjue}
律绝＝律句×四句＋起承转合：**①④／③②或②④／③②之类由对粘推出的四行骨架，恰是律诗的前半、后半或任意截取**——**所以“绝”字旧注有“截（律诗之句）而止”一说：绝句是律诗的切片标本**。切片的难处：**没有中间两联可以“铺”，四句里起承转合各只有一步**——**第三句的“转”因此成了绝句的命门**：“**忽见陌头杨柳色**”——前两句在梳妆、绣履的深闺闭环里匀速行驶，第三句一抬头，春色撞进来了：**转不是换话题，是把前三句的框架本身掀开一角**；第四句“悔教夫婿觅封侯”顺势泄洪——**二十八字完成一次心理政变**。明人推盛唐七绝，王昌龄与李白并置最高（王世贞《艺苑卮言》的座次）——**“圣手”的头衔，发给了最会拐弯的人**。
:::

::: definition 古绝：与律并行的另一条线 {#def-gujue}
古绝不讲粘对、**可以押仄韵（含入声韵）**、句数不受八句限制——它不是“写坏了的律绝”，是**五言小诗的古老正身**：王维《送别》“**山中相送罢，日暮掩柴扉。春草年年绿，王孙归不归**”（“绿”入声在句中当刹车；“归不归”以问收束——**律绝的古雅写法**）；柳宗元《江雪》“**孤舟蓑笠翁，独钓寒江雪**”——韵脚“**曰、灭、雪**”：入声屑韵连押——**一首零下温度的诗押着一批关门音：每读一遍，喉咙都替那扇江面上了锁**（上章“音色学”的满分案例：**押韵可以押出气温**）。两线的分辨法回扣前章：**查三平尾与粘对，再查韵的声调：平声韵＋合式＝律绝；仄韵或失粘＝古绝——判卷先看用的是哪张卷子**。
:::

::: example 单曲发行：旗亭画壁 {#ex-qiting}
唐薛用弱《集异记》载：王昌龄、高适、王之涣雪日聚汴州酒肆，有乐工合奏、歌妓数辈承应——三人**私相约赌**：我辈各擅诗名，**只看歌妓们唱谁的诗，以定高下**。昌龄、高适各得数章之涣自负，指座中“**名妓之尤者**”说：她若唱我的诗，你们二位应当拜服；须臾果闻其唱《凉州词》“黄河远上白云间”——之涣揶揄二友：**“田舍翁，我句固合此辈歌。”**（细节各本略异，赌局结构诸本一致。）请用传播学重读这则故事：①赌注设定说明绝句在当时的**功能定位**；②“伶人所歌”作为排行榜的**采样偏差**（谁会点歌？）；③与本章“第三句转”连起来：**为什么适合传唱的恰是绝句而不是排律**。
::: solution
①**绝句＝单曲**：长度适配一次宴会表演、一次记忆、一次抄写（**二十八字是唐代流行歌的标准容量**——五七言近体与燕乐曲拍同构）；诗人的“名”**由歌者的歌单确认：排行榜、版权、演唱会打赏三合一的先声**。②**采样偏差**：伶人唱的是**酒席审美**（开场的壮语、收尾的巧句；“黄河远上”版的“**广场式起句＋私享式结句**”通吃两种耳朵）——**今日热歌榜同理：能上榜单的是“大众偏好的中位数”，不是诗歌史的中位数**（榜单与选本、选本与教材，同一偏差链——[[tang-literature/high-tang]]的镜子）。③**传唱需要一次转弯**：四句内“起—转”结构让听众在两分钟内经历完整情绪弧线；排律的对称长龙适合读与考，**不适合跟着筷子打拍子**——**体裁即分发格式：绝句是唐诗的短视频，律诗是论文，歌行是纪录片**。
:::
:::

::: intuition 留白的分辨率 {#int-liubai}
律诗像**论文**：八句、两联举证（对仗）、起承转合走完一条完整论证；绝句像**摄影**：**只允许一次曝光，且必须在画面外留出一个位置让读者站进去**。“**却话巴山夜雨时**”把位置留在了未来；“**低头思故乡**”把结论降级成动作；“**白云千载空悠悠**”把论据全删只剩天气——**绝句的“不尽”不是说不完，是设计上的留白：作者交出分辨率，换取读者的想象力带宽**（王士禛“神韵”说拿绝句当最高体裁：**“不着一字，尽得风流”——含蓄不是美德，是信息论：说出的部分越准，未说出的部分越可控**）。
:::

::: history 小诗体的兴废 {#sec-xiaoshi}
**六朝**：五言四句的**子夜、读曲**等吴声小曲已是绝句亲祖——**绝句生于情歌，不是生于律诗**（乐府血统优先于律诗切片说，参[[han-to-nanbeichao/folk-songs]]）；**初唐**：律绝定名于省试边缘（**五言排律是考场正装，绝句是应酬手帕**）；**盛唐**：**七绝黄金期——王昌龄“圣手”、李白并尊、高适岑参各下边塞快枪**；**中唐**：刘禹锡《竹枝》**把绝句与民歌再次对接**（“**东边日出西边雨，道是无晴却有晴**”——谐梗入诗，绝句的民歌脐带从未剪断）；杜牧以史论笔法入绝句（“**东风不与周郎便**”——**二十八字打一场反事实战役**）；李商隐“**夕阳无限好**”——**绝句史上最著名的一次半途而废**；**宋**：**王安石、苏轼、陆游把绝句当日记与随笔（“活法”：绝句成为宋诗最高频体裁——小诗体的胜利=日常书写的胜利**）；**金元**：元好问以论诗绝句三十首成组写作——**绝句还兼职当批评文体（论诗诗自杜甫《戏为六绝句》开例）**；**明清**：神韵派奉王孟绝句为天籁——**绝句被供成“含蓄”的牌位**；**今**：**题画、赠答、朋友圈——绝句是文言最后的日常口语位：每有人给风景配四行，就自动采用这个格式——体裁活在用例里，不活在教材里**。
:::

::: warning 读绝句四坑
**把古绝当“不合格律绝”打回去**（**它们是两种卷子：古绝的仄韵与散句是特色不是污点——先用上一章的判卷表，再落笔**）；**逢转必找“寓意”**（**第三句的转可以只是天气、一次抬头；转的功能是结构，不是密码——别把每道弯都读成路牌**）；**以为短＝容易**（**四句无补丁：一个衬字都藏不住；绝句是近体里淘汰率最高的体裁——唐人的量、宋人的选，才留下这几百首“名句”**）；**用名句代替全诗**（**“春蚕到死丝方尽”式的截取流传：绝句一旦被拆成单句，就只是格言——**读全首，数它是怎么走到第四句的**）。
:::

::: exercise 三句手术 {level=1}
给一句现成的打油前两句（“深夜加班人未眠”云云——自拟为准），**补写第三、四句完成一次“转＋泄洪”**：第三句必须引入一个**与前三句框架外的具体物象**，第四句不得出现情绪形容词。
::: solution
判分：**转要“撞进来”**（窗外、夜班公交、手机弹出的一条消息——**陌头杨柳色的当代等价物**）；第四句**只有动作或画面**（“把改了八版的文件命名为最终版”级——**情绪由读者代持**）；若第三句只是递进（“何况还挨领导骂”）＝未转，手术失败回炉。
:::
:::

::: exercise 气温配韵 {level=2}
写四句小诗：**先选定韵部的“气温”**（冷：-u/-ü 收拢；湿：-n 含混；开阔：-ang 长鸣；急：入声字连用——**用今音即可，注明所用体系**），再填内容；标题必须与韵脚的温度相反（如押“雪、灭”写盛夏）。
::: solution
判分：**韵脚温度自洽且可听辨**（朗读测试：同伴凭声音猜气温，猜中即合格）；**反差成立**（标题与韵脚打架处＝诗的张力——**《江雪》的冷靠入声，你的热靠什么？**）；**注明体系**（新韵/平水/方言论——上一章的“行为时法”条款在此生效）。
:::
:::

::: exercise 小论文：短的是不是接近完美的 {level=3}
写六百至一千字，评“**绝句是汉语诗的俳句化实验：它证明了最短的文体可以承担最深的经验——代价是零容错**”。须调用：**第三句转折机制**、**古绝仄韵的音色特权**、**旗亭传唱（分发格式）**、**“名句化”的截取传播**至少四项；并处理一个反方：**现代新诗几乎放弃了绝句式短制（除“三行诗”比赛）——说明留白美学已经失效**（可反驳：弹幕、签名档、金句体恰是绝句生态位）。
::: solution
判分点：四项机制（**转＝结构引擎；仄韵＝音色武器；单曲＝分发格式；截取＝传播的降维**）；零容错论证（**绝句的淘汰史：唐人数千首存世、公认数百——短体没有“中等作品”的位置，全部要么名句要么消失**——**这是体裁的饥饿营销**）；反方处理（**参考：留白从未失效，失效的是“共同背诵体制”——三行诗大赛、签名档、歌词副歌都在争夺绝句当年的生态位；真正的变化是从“可歌”迁到“可转发”：分发格式再升级，体裁会继续搬家**）；结论若写“**短不是省，是把全部力气花在怎么停——所有文体的终极考题都是结尾**”，即 A。
:::
:::

::: summary
半台机器结账：律绝（**切片说＋六朝血统说并立：四句一步棋，第三句定生死**）、古绝（**江雪的入声韵：押韵押出气温——先认卷子再打分**）、单曲（**旗亭榜＝唐诗的流媒体；体裁即分发格式**）、留白（**分辨率换带宽：含蓄是信息论不是美德**）。方法一句话：**读绝句只数两件事：它在哪里转弯，在哪里刹车**。下一章称量对仗：两句话的对称如何成为一门独立艺术——以及对联为什么是中国人最小的文学单位。
:::
