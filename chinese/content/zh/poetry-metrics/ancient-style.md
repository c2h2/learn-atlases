---
title: "古体诗"
---

前三章建起了律的法院，本章放出它的对照组：**古体诗**。先立一条判卷纪律：**古体不是“没写合格的律诗”，是与律并行、自成规格的另一种卷子**——它保留着汉魏的口音、乐府的血统，以及唐人才有的野心：**用韵文的容量，装下散文的一生**。

## 五条放行条款 {#def-fangxing}

::: definition 古体的身份证 {#def-shenfen}
与律诗分手后，古体凭五条条款自由活动：**①句数自由**（四句到百韵都行：《北征》七百字上下的五言长排就是古体）；**②押韵自由**（可仄韵、可入声韵、可**中途换韵**——一韵到底才是律的镣铐）；**③平仄自由**（不受四句式约束，于是**三平尾不再是罪，而是古体的签名**——《静夜思》的体裁户口在此落定）；**④不必对仗**（对则宽，不对则散——散句是古体的正装）；**⑤句式可杂**（三言、四言、七言、九言可混装成“杂言”，**句子的长短第一次听命于呼吸而非表格**）。合起来看：**律诗把五个维度全部焊死，古体把它们全部留成活口——两者不是新旧，是“集装箱船与散货船”的分工**。
:::

::: definition 歌行：长途分发格式 {#def-gexing}
歌行体＝古体里的**可歌长途车**：题名常带“歌、行、吟、曲”（《长恨歌》《琵琶行》《游子吟》），技术特征三件：**①换韵＝场景切换**（四句、六句一换，平仄韵交替——**韵脚一变，灯光、布景、情绪全换：歌行的分章不是分行，是分幕**；曹丕《燕歌行》作为现存第一首完整七言，本来就是乐府的歌本，[[han-to-nanbeichao/jianan]]）；**②呼语开口**（“**君不见**黄河之水天上来”“**听妇**前致词”——**歌行保留了说唱艺术的现场：有个听众被点名，诗是对他讲的**）；**③杂言＝呼吸长度**（《蜀道难》从四言到九言忽长忽短：**“噫吁嚱”三个感叹字是表格外的自由音量——情感的锯齿需要用句宽的锯齿来记录**）。**“以文为诗”的登记处**：韩愈把散文的记叙流程与虚词灌进诗里（“**横空盘硬语，妥帖力排奡**”是他给别人的诗立的榜；《石鼓歌》把一座文物的**参观报告**写成押韵长文——**连词、散文句序、金石学口吻进诗：宋人从此接上了总公司的水源**）。
:::

::: example 换韵的情绪账：《将进酒》 {#ex-jhuanun}
全诗百余字，韵脚换了数轮（大致轮廓：**平声**起韵（来、回）→**转仄**（发、雪、宴、欢）→**再转**（真、有人、尘、身）→**平声**收（雷、酣、岸、换、愁）——**平、仄、仄、平的大回环，教科书式的歌行换韵**）。请：①按韵段给全诗分幕，标出每幕的“剧情”；②说明**为什么“与尔同销万古愁”必须落在已经换过的平声韵上**（对照：若全诗押入声一韵到底，效果是什么）；③把“换韵”与上一章“转”的条款合并，总结**古体的节奏单位为什么是“韵段”而不是“句”**。
::: solution
①分幕参考：**起幕**（两个“君不见”：黄河入海、青丝成雪——平声起韵开大问题）→**劝酒幕**（“人生得意须尽欢”“会须一饮三百杯”——转入仄声，拍桌子的段落用短音）→**愤懑幕**（“钟鼓馔玉不足贵，但愿长醉不用醒”，“圣贤寂寞”“饮者留名”——仄声继续，语气下沉）→**结算幕**（“主人何为言少钱”到“**与尔同销万古愁**”——换回平声，尤韵长调拖远）。②**入声一韵到底＝一场不散的宴席堵在喉咙口**：急、促、怒；末落平声尤韵（愁）**把愤怒兑换成怅惘的长音**——“万古”的时间感正是靠“ou”的开口渐收拖出来的：**换韵是把情绪分装成可翻篇的几页；最后一韵选平，是决定“以什么姿态说完”**。③律诗的单位是句（每句合规），古体的单位是韵段：**一韵之内可以自由失粘、散句、长短——约束被移到了“这一段用什么声音”上：古体放弃了微观独裁，实行宏观联邦**。
:::
:::

::: definition 古体的双重产业 {#def-chanye}
**产业一：载史**。“诗史”的正式载体是五言古体而非律诗：《北征》《自京赴奉先县咏怀五百字》需要**行状式题目、流水账式叙述、对话实录**（三吏三别）——**律诗八句的地产装不下一场安史之乱，古体的句数自由就是档案库的扩建**（杜甫“即事名篇”的新题乐府；元白新乐府“**文章合为时而著，歌诗合为事而作**”把这条产业链制度化：古体＋乐府旧瓶＋时事新酒，[[tang-literature/mid-tang]]）。**产业二：复古**。陈子昂《感遇》、李白《古风》五十九首——**用古体“恢复风雅比兴”：古体天然带着汉魏的版权保护期，写它就是在认领一个批评传统**（“将风骨争天下”的武器库——[[tang-literature/early-tang]]）；**同一副古体，杜甫拿去装新闻，李白拿去装旗号：体裁是平台，装载政策由作者定**。
:::

::: intuition 自由的成本 {#int-chengben}
古体的五条自由，每条都标价：**句数自由→没有“二十八字定输赢”的公平擂台，长短自辩**；**换韵自由→音韵的统一感外包给结构感，写手没有结构就散架**（歌行之劣者即“韵在走，诗没走”）；**平仄自由→失去律的自动美化，句子好不好全凭句法本身——所以“唐人格律之外的功夫”恰是检验功力的裸考**；**杂言自由→音乐丢了就成散文分行**。于是文学史上有趣的现象：**古体大师全是律句也满分的人（李杜皆然）——自由是先挣得资格、再行使特权；最难的境界是“以律的耳朵写古体”：三平尾落在哪里，是精心选择的放任**（“**宽于言者，严于法**”——韩文的“唯陈言之务去”在诗里的同门功课）。
:::

::: history 古体的账龄 {#sec-zhangling}
**汉**：五言古体成熟（《古诗十九首》——**文人五言的第一批原件，无调可谐**，[[han-to-nanbeichao/nineteen-old-poems]]）；**魏—陈**：曹丕《燕歌行》首全七言、曹植骨气齐盛——**古体的两家创始店**；**晋—宋—齐**：玄言、山水、永明新变——**律的萌芽从古体的侧枝长出**（[[han-to-nanbeichao/landscape-yongming]]）；**唐**：近体定型后，**古体第一次作为“另一种制度”被意识到——文体只有在被替代时才获得自我意识**；陈子昂、李白以复古为旗、杜甫以叙事扩其用、韩愈以文为诗穷其变——**唐代同时跑完古体的三种活法**；**宋**：苏轼、陆游、杨万里古体高产——**宋诗的主力其实是古体与半古半律：一个朝代选择卷子，正如一个作者选择时态**；**金元明清**：古体转为**拟汉、拟古的“时代口音模仿秀”**（乐府题的博物馆化）——**文体寿命的末期是修辞学展览**；**今**：**“古风歌词”接住了歌行的壳（长短句＋换韵＋呼语），而律句退居题词——古体又一次靠音乐还魂：它的最后一次分发格式升级**。
:::

::: warning 读古体四坑
**用律尺判古体“出律”**（**先认卷再打分——陈子昂《登幽州台歌》失粘出韵处皆是“合法自由”：用考卷改李白，上一章的警告在本章加倍有效**）；**以为“自由＝随便”**（**歌行没有格律但有章法：换韵的位置、句长的锯齿、呼语的设置——放弃微观约束等于加重宏观责任**）；**把“以文为诗”当贬义**（**它是增量：散文句法入诗带来叙述速度与金石气；它的失败案例（滑成韵文分行）另算——评的是执行，不是纲领**）；**忽略古体的用典层次**（**古体“古”，一半在词库：它比律诗更爱用汉魏故实与虚词——体裁自带时代口音，读到“焉哉乎也”不是凑字，是仿古的包浆**）。
:::

::: exercise 为情绪换韵 {level=1}
写 12 行左右的自由古风：**必须换两次韵，且每次换韵对应一次“剧情翻页”**；标注每幕韵部的平仄属性与剧情名。互评：删去某次换韵试试——剧情是否塌了一角？
::: solution
判分：**换韵处＝可命名的剧情点**（视角切换、时间跳转、温度变化——没有剧情的换韵＝换胎不挪车）；**平仄韵的选择服务剧情**（入声当急、平声当远——用上一章“气温表”）；“删换韵塌陷测试”通过者满分——**证明你的结构长在韵上，不是贴在韵上**。
:::
:::

::: exercise 同一趟旅程两张卷 {level=2}
选一次真实行程（通勤、爬山、夜班），**写两个版本**：A 七律（全部合规：四联、中二联对仗、一韵到底）；B 歌行（≥两次换韵、可杂言、可用“君不见”级呼语）。后附 50 字说明：**哪些材料只能进 B 版，为什么**。
::: solution
判分：A 版**过律体检**（孤平、三平尾、粘对、对仗四层全查）；B 版**有章法**（换韵有剧情、句长有呼吸）；说明命中本质：**流水账式的事件序列、说给某人听的语气、来不及对称的惊呼——这些是古体的合法住户、律诗的违规搭建**（“集装箱船与散货船”的实操判决）。
:::
:::

::: exercise 小论文：体裁是一种制度 {level=3}
写六百至一千字，评“**律诗是科举制的诗，古体是士人私人档案馆的诗——两种文体两套治理**”。须调用：**五条放行条款**、**换韵分幕**、**“诗史”载体（档案库说）**、**《古风》《感遇》的复古旗号**、**“文体只有在被替代时才获得自我意识”**至少五项；并处理一个反方：**古人并不按我们的“体裁制度”写作（名篇多为“破体”）——制度论是否高估了规则**。
::: solution
判分点：制度对应（**律＝可批量评分的形式→考试与铨选；古体＝无法标准化→自辩、记事、仿古：文体分工即治理分工**）；破体反方（**答法一：规则的真实作用是存在“被违反的可能”——破体的震撼以制度存在为前提，杜甫“拗怒”之所以是成就，因为旁边站着格律；答法二：承认制度论是回溯性整理——分类是批评的事后账本，创作是当下现金流：两账都要记**）；结论若写“**体裁不是牢笼也不是建议，是定价机制：它决定哪种自由值得付多少钱**”，即 A。
:::
:::

::: summary
散货船结账：身份证（**五条活口——自由是规格，不是失误**）、歌行（**换韵分幕、呼语在场、句宽记情感**）、以文为诗（**韩愈开工、宋人接盘：叙述与虚词的增量**）、产业（**杜甫装新闻、李白装旗号——体裁是平台，装载政策由作者定**）、成本（**放弃微观约束＝加重宏观责任：宽于言者严于法**）。方法一句话：**先问这艘船挂哪国旗（体裁），再评它跑得好不好**。下一章离开诗国：词——按曲牌交作业的文体。
:::
