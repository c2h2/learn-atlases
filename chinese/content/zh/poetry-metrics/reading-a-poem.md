title: "怎样读一首诗"
---

这是格律课的结业章，也是它的自我否定章：**前九章教的是仪器，这一章教的是什么时候把仪器收起来**。先给流程，再给验尸刀（替换法），最后立一条防身守则：**任何读数都要回到诗本身复秤**。

## 五步流程 {#def-wubu}

::: definition 细读法：从体裁到余额 {#def-xidu}
**①体裁鉴定**（这首诗用哪套法典写作：古体／近体／词／曲？韵在哪个系统？——**体裁先定，罪名才有依据：用律尺判古绝是执法过错（第 3、4 章连判两案）**）；**②名义与场合**（题目、原唱、赠谁、何年——**文本的出生证明：《自京赴奉先县咏怀五百字》一半的信息在标题（诗史课的铁证）**）；**③结构地图**（律诗看起承转合与对仗位，歌行数换韵分幕，词看片与领字，曲看板——**先画电路图，再评价灯光**）；**④语言异常点**（全诗哪个字“不像该出现的”：诗眼、虚词、错位、违反语法的压缩——**清单法：找出三处“换个平实说法会损失什么”的位置**）；**⑤账本核对**（意象的库存对不对得上场合：用“雁”是捎书还是自况？典是正用还是翻案？**——第 9 章的验收单**）。五步走完再开口评价——**本流程的全部精神是一句话：先描述，后判断；先计量，后抒情**。
:::

::: definition 替换法与黑名单 {#def-tihuan}
**替换法**＝诗的可译性检测：**把一个词换成它的“等价物”，量塌方**。王安石“春风又**绿**江南岸”的传说中，“绿”曾作“到、过、入、满”——**改稿故事是古人留给我们的实验数据：颜色动词让春天发生物理变化，其余候选只是位移**；“红杏枝头**闹**春意”（宋祁）——换“浓、深、满”立刻从纪录片变统计报表——**王国维说“着一‘闹’字而境界全出”，其实是替换法自己跑出了结论**。**套话黑名单**：①“**语言优美流畅**”→ 哪个字？换成别的为什么不优美？②“**意境深远**”→ 深在哪一层：意象的账龄，还是结构的空白？③“**表达了作者强烈的思想感情**”→ 强烈与轻微在文本里的**格律证据**是什么（入声？叠字？跨句？）——**每条黑名单套话都自带一个必答反问，答不出即撤回**。黑名单的价值不在讽刺，在**把形容词逼回成可核查的句法**：本课的“沉郁”＝层折（配过施工图），同理，“语言优美”必须能翻译成平仄、韵位、领字、动词位置的某处具体选择，**否则等于没说**。
:::

::: example 期末实操：《登高》五步全扫 {#ex-denggao}
“**风急天高猿啸哀，渚清沙白鸟飞回。无边落木萧萧下，不尽长江滚滚来。万里悲秋常作客，百年多病独登台。艰难苦恨繁霜鬓，潦倒新停浊酒杯。**”按五步出报告：①体裁；②名义场合；③结构；④异常点三处；⑤账本。最后加试题：**这首诗常被引用为“格律完美”——但“完美”为什么可能是一种误读？**（提示：第 3 章“拗怒／工稳两台机器”与本步④的矛盾如何调和。）
::: solution
①**七律**：仄起入韵式（“哀、回、来、台、杯”——**平水十灰**：哀回来台皆灰韵、“杯”灰韵✓**一韵到底**；对粘全合——第 3 章扫描旧案复核）。②**场合**：大历二年夔州重阳登高——**节令是合同条款：重阳必登高、登高必悲（登临诗的体裁记忆：第 9 章的“长亭”逻辑）**。③结构：**八句皆对而四联各有职司**——首联六样景物连拍（急高哀清白回：**密度即音量**）、颔联宇宙级长镜（无边／不尽＝**空间与时间的双叠幅**）、颈联由景入己（万里＝空间、百年＝时间，“常作客”“独登台”＝**在双叠幅里放一粒人**）、尾联落到杯子（**全诗的收束定律：天下账户最终只剩一杯浊酒，且连这杯都“新停”了——杜甫把“戒酒”这种小事写成悲剧的最后一根稻草：史诗的结尾是一只空杯**）。④异常点：**“独登台”的“独”**（对仗位上对“常”——频率对孤数：**作客是常态，登台是孤例——两个副词扛住一生的重量**）；**“苦恨”的语义叠压**（苦＝极、恨＝憾：**现代读者读成“痛苦与怨恨”，损失了程度的冷感——恨而曰苦，是恨到计算成本的地步**）；**“萧萧／滚滚”的叠字分工**（落叶的**声**与江水的**势**：两个象声/象形词各管一个感官——**替换法实测：萧萧换“纷纷”只剩画面丢了声音**）。⑤账本：**猿啸（三峡典故库存：巴东三峡巫峡长，猿鸣三声泪沾裳——“哀”字有前账）**、落木（**“木”＝落叶的文学户口，自《九歌》“洞庭波兮木叶下”登记**）——**“落木”不写“落叶”：木叶自带秋天与水的旧账**。加试题答案：**“完美”是对格律统计的误读——此诗八句皆对是极限，不是模范：它的工整与它的暴力同量级（把对仗用到密不透风，本身就是一种不平之鸣：工稳到窒息＝内容的窒息）；“拗怒／工稳两台机器”在此合流——最高境界不是守规矩或破规矩，是让规矩成为压力的形状（第 3 章判词终审：“格律是悲伤的容器”的封顶判决）**。
:::

::: intuition 方法的摘除手术 {#int-zhuchu}
五步是眼镜，不是滤镜。**鲍照评谢灵运诗“如初发芙蓉，自然可爱”（《宋书》——**印象式批评的古早标本：不计量，只闻味**）**；钟嵘《诗品》“**直寻**”说：好诗来自“观今所见”，不靠“补假”——**批评史自己就养着反方法的一脉**；严羽“**羚羊挂角，无迹可求**……**不涉理路，不落言筌**”——**宋人明说：诗的最高处不在仪器读数里**。本课的和解方案：**读数用来防身（防套话、防误判、防把古诗读成白话摘要），审美用来交卷**——“**大漠孤烟直**”你可以分析它的对仗、声调、几何构图，但让孩子记住它的，永远是沙漠那一看。方法论是脚手架：**楼封顶以后，架子要拆——拆不干净的就不是楼，是工地**（本册课程页说“先描述，后判断”，这句话的反面也要记住：**判断完了，要把描述扔掉，回到那一秒的喜欢**）。
:::

::: history 这门课是怎么排出来的 {#sec-paike}
**唐**：诗是**实务**（考试、干谒、宴席——没有人写“怎样读诗指南”，规则长在肌肉里）；**中晚唐—五代**：诗格、诗式出世（王昌龄《诗格》、皎然《诗式》——**规则退化成教材：肌肉记忆失效处，笔记体登场**，[[tang-literature/high-tang]]选本同功）；**宋**：**《沧浪诗话》以“参禅”喻读诗——方法论的第一次内战（江西派的法度 vs 严羽的妙悟：本课两端都站）；注杜、笺李——学术化与反学术化同时开跑**；**金元**：元好问以论诗绝句代序跋——论诗诗＋诗文评的选本化（读法开始编成韵文口诀）；**明**：格调派给读法立法（“诗必盛唐”=以裁判代读者）；**清**：**王士禛神韵、翁方纲肌理、袁枚性灵、桐城义法——四大读法同时开业：批评史的战国时代，恰好证明没有“标准的读”**；**1920s—今**：**新文学人用西方“细读”（close reading 的中文旅行）重写课表；教科书把诗拆成“主题—意象—手法—情感”四栏——本课五步法的民间前身与简化版（它的弊病恰是黑名单：四栏填完，诗没了）**；**今**：AI 能在三秒内生成“意境深远”——**套话第一次实现了零成本量产：本课的黑名单因此升级为生存技能——当赞美可以自动补全，可核查的描述成了人最后的岗位**。
:::

::: warning 鉴赏四坑
**“背景轰炸”替代细读**（**把生平与时代复述三遍，诗只剩一句：作者的事不是诗的事——第 2 步只为第 4 步供弹药，不是论文的避难所**）；**以“标准答案”收口**（**“表达了……感情”是填空题格式，不是结论：任何情感判断必须回指文本证据（本课的格律证据链）——否则就是替赏析词典打工**）；**误把仪器当对象**（**通篇平仄韵部而无一眼看诗：这是验血报告当遗书读**）；**“我觉得”万能**（**感受自由，论证不自由：我读《登高》想到自己搬家，可以写随笔；不能写成“杜甫此联是写搬家”——**想象力要办签证，目的地由文本海关盖章**）。
:::

::: exercise 期末独立卷 {level=3}
自选一首七律或一首长调，交**完整五步报告**（≤600 字）＋**替换法两处**（每处注明“换什么词、塌什么”）＋**套话自审**：从自己上一份作业里揪出两句黑名单语言并改写为可核查句式。互评按本课标准：体裁、场合、结构、异常点、账本各 20 分。
::: solution
判分：五步齐全且**步间有引用关系**（第 4 步的异常点必须落在第 3 步的地图上、第 5 步的账本必须服务第 2 步的场合——**流程不是五道题，是一条流水线**）；替换法两处的“塌方”描述具体（损失声音／损失时间感／损失阶级色彩级）；**自审环节是全课人格测试**：能对自己的套话下死手的人，才算读懂了黑名单的精神——**这门课反的不是赞美，是免检的赞美**。
:::

::: exercise 小论文：鉴赏是科学还是鉴赏 {level=3}
写六百至一千字，评“**格律课教的不是‘怎么夸诗’，是‘怎么不让夸错’——方法的全部用处在于给直觉发放可审计的收据**”。须调用：**五步流程的相互制衡**、**替换法**、**“隔与不隔＝库存差额”（第 9 章）**、**“羚羊挂角”反方法案**、**AI 套话量产时代**至少四项；并回答：**如果审美终究私人，这门课的“评分”凭什么成立**（提示：评的是过程审计，不是趣味本身——把它写清楚）。
::: solution
判分点：制衡逻辑（**五步是防错系统：体裁防误判、场合防过度、结构防摘句、异常点防滑读、账本防硬解**）；替换法＝**可证伪性的最小单元**；库存差额（**“隔”的判决随读者市场浮动——方法连自己的失效条件都测量：这是它科学性的来源**）；反方法案（**“羚羊挂角”不是否定方法，是划定方法的辖区：仪器管得着字面，管不着“无迹”——**本课立场：无迹处正是方法设计的边界条件**）；评分之问（**参考答卷：我们从不评“你喜欢”，评“你的喜欢是否可追溯”——收据不是感受的敌人，是感受的会计；AI 能发赞美，发不出“我如何在文本里核对过”的账目——这才是人文课在自动补全时代的护城河**）；结论若能写“**读完这门课，愿你被一句诗撞倒时，除了喊‘好’，还能说出它是哪一块砖晃动了世界**”，即 A。

::: summary
结业结账：五步（**先描述后判断：一条流水线，不是五道题**）、刀（**替换法：古人自留的实验数据；黑名单把形容词逼回句法**）、终审卷（**《登高》：工稳到窒息＝内容的窒息——让规矩成为压力的形状**）、拆（**脚手架拆不干净是工地；被一句诗撞倒的时刻才是课程的结业证**）、账（**隔与不隔＝库存差额；评分评的是可追溯，不是趣味**）。十课一句话总账：**平仄是尺、韵是秤、体裁是法典、意象是货币、方法是眼镜——而诗，是秤称不动、尺量不出、法典不设防的那一点东西**。本课到此结业；下一册，宋代文学。
:::
