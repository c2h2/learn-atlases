---
title: "对仗与对联"
---

上一章说对仗被“指定在中间两联”，像公文的举证格式；本章给它单独立案：**对仗是汉语的裸型艺术——不靠形态变化、不靠外语借词，只靠语序与并置就能建成对称建筑**（[[modern-grammar/sentence-constituents]]：汉语语法重语序，对仗把这一特点推到美学立法）。它的独立发行版叫**对联**：中国人最小的文学单位，也是存活率最高的古典文体——春节没读过李商隐的人家，照样贴对联。

## 三条验收线 {#def-sanxian}

::: definition 类属、平仄、句法 {#def-yanshou}
对仗同时过三道秤：**①类属**（词义范畴）——天文对天文、地理对地理、草木对草木、颜色对颜色、数目对数目；唐人实用分类比词性更细（“门对”传统一路分到“鸟兽、花木、衣饰”……**《声律启蒙》“云对雨，雪对风，晚照对晴空”——中国蒙学的真正教材是一部对子数据库：识字、常识、平仄三合一，七岁开始背索引**）。**②平仄相反**（对句逐节奏点对立：这是律诗“对”条款在对仗侧的投影——**字义结婚、声调打架，是近体对仗的常态**）。**③句法同构**（主谓对主谓、动宾对动宾）——注意：**句法同构不等于意思相同**，意思相同就犯罪（见“合掌”）。三层强度自下而上：**合式（平仄）→工整（类属）→工而活（句法与气势）**——只查前两层的是对联打印机。
:::

::: definition 四种对法与一个罪名 {#def-sizhong}
**正对**（两句同义互补）最稳也最险——刘勰一千五百年前就放了狠话：“**反对为优，正对为劣**”（《文心雕龙·丽辞》——**同义反复在美学上按抄袭处理**）；**反对**（“**蝉噪林逾静，鸟鸣山更幽**”——以闹写静：两句相反而相成，一张照片的两次曝光）；**串对／流水对**（意思像水一样穿过一联：**“即从巴峡穿巫峡，便下襄阳向洛阳”——四个地名＋四个动词一路狂奔，对仗的站牌全在，长途车不停站**；再如“**欲穷千里目，更上一层楼**”——**条件句拆成两半，一联装进一个“如果……就……”：流水对是对仗的极限运动，戴着对称的镣铐跑散文化的直线**）；**借对**（临时借字：借音——“**清”可借“青**”；借义——“**少年”之“少”读去声时得对“长”：一个字在场内打两份工——对仗里的影子雇员制度**）。罪名：**合掌**（“**天地”对“乾坤”、家书“抵万金”之上再配“值千金”——两句话穿同一件衣服：八句的地产，一寸也不能白给**——注：“烽火连三月，家书抵万金”之“三”“万”是虚数的递进夸张，教学上常算宽对流走，不算合掌；**合掌的红线是“意思完全重合”，不是“同现数字”**）。
:::

::: example 四层对：绝句里的对仗标本 {#ex-siceng}
“**两个黄鹂鸣翠柳，一行白鹭上青天。窗含西岭千秋雪，门泊东吴万里船。**”——有人说这是“两个对联拼成的诗”（四句各自成对、无起承转合的争议之作）。请：①逐层拆解对仗（数目、颜色、动物、时空）；②回答：**没有“转”的对仗陈列为什么仍是杰作——绝句上一章的“转弯”律在此失效了吗**；③“窗含”“门泊”两个动词的位置与功能；④“西岭—东吴”“千秋—万里”在对什么。
::: solution
①数目（两个／一行；千秋／万里）＋颜色（翠／青）＋动物（黄鹂／白鹭）＋时空（**时间对空间两联互锁：三句时间是“千秋”、空间被“窗含”；四句空间是“万里”、时间藏在“东吴（三国记忆）”——**对仗的最高级：名词对名词之外，两联在时空中互为镜像**）。②转弯律未失效，**被换成了取景律**：绝句靠时间转弯，这首靠**空间调度**——两句一景、由近及远、由动归泊，第四句“门泊”把全局从飞行收回门口：**转的等价物=镜头的最后一次拉回**（**“两联对联诗”的指责由此驳回：杜甫是在用对仗做蒙太奇——对称的碎片剪出一部旅行未遂记**：诗当时作于草堂，乱平有望、船期难定，“门泊万里船”＝**想走而停在原地的对句**）。③“含”“泊”都在第三字位（节奏重拍）：**一静一系——山被装进窗，远方被拴在门口：动词是这两联唯一的司机**。④地理对地理＋年代对年代＋**方向对方位（西对东）**：**同一座草堂的四面墙，被对仗打开了四个方向——工对不是枷锁，是开窗的工兵**。
:::
:::

## 对联：独立发行 {#def-duilian}

::: definition 最小文学单位 {#def-zuixiao}
对联＝对仗脱离母体单独营业：**上联仄收、下联平收**（关门音上、拖长音下——**“仄起平收”是耳朵的问句与答句**，回看第一章的延音断音）；门联、寿联、挽联、喜联、行业联、集句联（从古诗里摘句配对——**版权时代的同人创作**）。名件解剖：**“海纳百川，有容乃大；壁立千仞，无欲则刚”**（林则徐）——**以格言联自铭：对联的“用途”从装饰升格为座右铭的实体化**；昆明大观楼长联（孙髯翁，通行本一百八十字）——**把汉楼、唐塔、宋碑…登临、凭吊、抒情打包进一副联：长联证明了小文体也能扩容成散文的容器**（“天下第一长联”的头衔与其说是美学判定，不如说是**字数军备竞赛的吉尼斯记录**）。**行业联是古代广告位**（药店“**但愿世间人无病，何妨架上药生尘**”——**对仗完成品牌价值观的两行融资**；流传的戏改版本把祝愿整个倒转成反话——**改联＝民间的二次创作与差评回复**）。
:::

::: intuition 对称是汉语的母语 {#int-duichen}
印欧语靠词形变化对齐句子，汉语靠**并置**：主语谓语谁挨着谁、几个音节对几个音节——**孩子没说对过“对子”之前，先就会说“你一拳我一脚”“再来一次没再来两次”。对仗不是修辞课的科目，是语法的显影液**（[[rhetoric/figures-of-form]]对偶章：成语几乎是对仗的化石层——“山高水长”“眼高手低”：**汉语词汇化过程里，对称是个强力模具**）。于是律诗对仗的文化成本极低、接受度极高：**它把“读得顺”变成了“看得懂公平”——对称即正义的形式感**。这也解释了对联的百毒不侵：**诗会变体裁，会消亡；对称不会，它只是换马甲——从骈四俪六到广告词“怕上火，喝×××”，对仗从没退场，只是不再署名**。
:::

::: history 对称的账本 {#sec-zhangben}
**《诗经》“昔我往矣，杨柳依依；今我来思，雨雪霏霏”——对仗的基因在四言时代已显性表达**；**汉赋**铺陈的排偶、**骈文**“俪采百字之偶”（《文心·丽辞》）——**对仗从修辞升格为文体**；**唐**：律诗定为“**中二联必对**”的制度；**宋**：对偶句独立成“**巧对**”故事集（欧阳修《归田录》多记）；**明**：朱元璋倡春联（**桃符换“春联”：官方推广让对仗下乡**——**最短文体的大规模存活，靠的是行政与商业，不是诗选**）；**清**：**对仗学上升到方法论（阮元“文言”论以偶声为文——经学家给对仗发经学执照）＋长联黄金时代（大观楼、黄鹤楼各争第一）**；**民国以来**：征对、绝对子是报刊副刊与市井智力的长期游乐项目（旧传“独角兽”对“比目鱼”之妙，在“比”字非数而鱼名自带其数——**对仗的谜题化运营**）；**今**：**春联赛、征婚联、标题党对偶（“听我说完，先别投票”）——数字时代的对仗 A/B 测试**；《声律启蒙》《笠翁对韵》从蒙学退到胎教歌单——**对仗教材的读者年龄持续下探：文体停止生产新作，就开始占领幼儿园**。
:::

::: warning 对仗四坑
**为对而对，句句合掌**（**同义对仗＝排版事故；对仗的地皮用来开窗，不用来照镜子**）；**迷信工对＝好对**（**工是底线不是上限：盛唐名家多宽对而气盛，晚唐工对渐密而气局转小——**工与盛是两个坐标轴，高分卷往往是工而不自觉**）；**把借对当出律**（**借音借义是合法科目，不是错字——查得到类书的对子先别改卷**）；**用对联平仄硬套律诗**（**对联只要求尾字仄平相承，长联句读自由：律诗是法定婚，对联是事实婚——适用不同法**）。
:::

判分：**类属标注准确**（数目、颜色、方位之类目别混）；**跨界对成立**（“屏对窗：都是发光方块——**对仗的萌点在‘原来同一类’**）；**可背性检测**（顺口度=平仄正确的副产品，念给第三人听，能复述即合格）——**蒙学教材的 KPI 至今没变**。

::: exercise 小论文：对称即正义 {level=3}
写六百至一千字，评“**对仗是中国人对‘公平’的形式训练：两句话地位平等、力量对称、各让半步**”。须调用：**类属分类学**、**反对为优的判例**、**流水对的“让步”**、**对联的仄起平收**至少四项；并处理一个反方：**对仗制造虚假平等（把不对等的事物排成对仗是修辞操纵）**——可借“广告对”案例接招。
::: solution
判分点：四项机制（**类属＝万物在法律分类学前平等；反对＝让对立面同桌；流水＝句式互相让位；仄平＝一声问一声答**）；反方处理（**承认：对仗确实能给不等者发平等制服（“与某某共命运”的排比）——因此本课三层验收同时是识破工具：查合掌（空洞）、查类属越权（攀亲戚）、查气势不对称（一实一虚的对=宣传腔）**）；结论若能写“**形式平等不是真实平等，但没有形式平等的训练，真实平等连排练场都没有**”，即 A。
:::

::: summary
对称立案结案：验收（**类属/平仄/句法三线：合式→工整→工而活**）、对法（**反对为优的千年判例、流水对的狂奔、借对的影子雇员**）、标本（**草堂四句=用对仗开窗；动词是唯一的司机**）、对联（**仄起平收的问与答、一百八十字的容器、差评回复的广告位**）、直觉（**对称是汉语的母语：它没退场，只是不再署名**）。方法一句话：**见对先查合掌，再找窗户**。下一章松绑：古体诗——律诗的反面教材如何反向养活了李白与杜甫。
:::
