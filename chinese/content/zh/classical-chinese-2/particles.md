---
title: "虚词深潜"
---

上一门课发过一张虚词入门卡（其之而以于为所者），这一门课把它们**拆开重装**：每个高频虚词其实是一家**身兼数职的壳公司**——查户口要一路查到它的**动词祖上**。文言的血肉是实词，**呼吸全在虚词**；鲁迅写孔乙己，只靠“之乎者也”四个代词就把一个酸腐人物钉在纸上——**虚词是文体的指纹，也是断代的年轮**。

## 两条流水线 {#def-liushuixian}

::: definition 名词化双机：者、所 {#def-zhesuo}
**者**＝谓词性材料进厂、名词出厂：“**学者**”（求学的人）、**“勇者”“耕者”“观者如堵”**；**定语后置的登记戳**（“**马之千里者**”“**荆州之民附操者**”“**求人可使报秦者**”——**中心词＋之＋后置定语＋者**，一道语法口令解尽倒装）；**表提顿语气**（“**陈胜者，阳城人也**——判断句式的前半拍”）。**所**＝**及物动词的宾语提取机**：“**所见闻**”=见到的听到的（动词前加“所”，动词变“受事名词”）；**“为…所”被动式**（“**若属皆且为所虏**”——**“所”字被动标记沿用至今：“为人所骗”**）；**“所以”**两吃：**表工具/凭借**（“**师者，所以传道受业解惑也**”——用来…的东西）、**表原因**（“**此所以败也**”）——**古今用法同源分叉**。两台的共同血统：**者**祖上是语气/指代、**所**祖上是名词“**处所**”（“**入之甚寒，问其所从来**”）——**处所→抽象化关联**，虚词几乎都有一次“地产出身”。
:::

::: definition 语法化之梯：以、其、焉 {#def-yiti}
**以**：动词“用、拿”（**“以其子妻之”的“以”还端着实义——“把”**）→**介词**（工具凭借：“**以子之矛**”；原因：“**不以物喜**”；时间处所：“**以是**”“**以故**”（因此——**介词的连词化走廊**）→**连词**（“**作《师说》以贻之**”——表目的，通往“来”）。**其**：指示代词“那”（“**其为人也**”的上古老家）→**人称领格“他的/他们的”**→**语气测度词**（“**其恕乎！己所不欲，勿施于人**”——从“那”到“大概吧”：**距离感磨成了把握不准**；“**其皆出于此乎**”“**尔其无忘乃父之志**”——揣度与祈使两幅面孔）。**焉**：兼词“**于之/于是**”（“**心不在焉**”——在这上面；“**三人行，必有我师焉**”——在其中）→**语气词虚化**（“**寒暑易节，始一反焉**”——只余“呢”的呼吸）。语法化的共同轨迹：**实词＞（句法杠杆：连动、悬案）＞虚词＞语气词**；**再虚化就得换新车**：于是“于”下岗、“於”接班、“乎”客串，“之”字柜台永远热闹——**虚词是语言旧造的化石，每一层都埋着一个实词的尸骨**（**王力所谓“语法职员的退休再就业”——术语不论，路线一致**）。
:::

::: example 一字三刀：“而” {#ex-er}
“而”不翻译，只**接线**——为下列句子判定接线方式，并说明为什么不是别的：①“学而时习之”；②“人不知而不愠”；③“蹴尔而与之”；④“子路率尔而对”；⑤“万钟则不辩礼义而受之”。
::: solution
**①承接（顺接）**：“学”与“习”有先后流水账——**“然后”读**；**②转折**：“不知”与“不愠”对着干——**“却”读**；**③修饰（连状语）**：“蹴尔”是“与”的**姿势**——**“着/地”读**（“蹴尔”=踢一脚的样子——**状貌进厂，动词出厂**）；④**修饰同型**：“率尔”是“对”的态度（**同型复考题**——答成“顺承”说明规则没背牢：**状貌在后、动词殿后，“而”字扛的全是“地”字读**）；⑤**转折兼讽刺**：“不辩礼义”居然“受之”——此处“而”字里装着孟子的一声冷笑（**读“竟然就”**）。判分金句：**“而”字本身零意义，它是句子的**转接头**——顺接、转接、降压（修饰），全看两头的电压差**；凡是把“而”统一译成“而且”的卷子，等于把所有开关当成灯。
:::
:::

::: intuition 虚词是文章的呼吸器官 {#int-huxi}
朗读一遍就懂：**“也”字拖长肯定，“矣”字收束已然，“乎”字上扬疑问，“哉”字放情绪，“夫”字清嗓子开话题，“盖”字先咳嗽再立论**——虚词是**语气的时间形状**（《论语》“**予欲无言**”，子贡急问“子如不言，则小子何述焉？”——**一个“焉”字收尾，把“在哪里记笔记”的焦虑留白**）。删虚词试验是最好用的鉴赏手术：**把“其恕乎”改成“恕”**——道理还在，**那一拍犹豫与劝慰全没了**；把“积土成山，风雨兴焉”的“焉”删了——**语意从“在这里”塌成“发生”**。所以：翻译可以牺牲虚词，**鉴赏必须供奉虚词**；作文想古雅，也别乱贴“之乎者也”——**虚词用错比不用更露怯**，它是方言的脚注，不是戏服的褶子。
:::

::: history 虚词：从语感家法到统计法庭 {#sec-lishi}
**汉**：经师口授“句读”时最重虚词（“**之乎者也，所以志其断绝**”一类后世概括——**标点未生，虚词先行**）；**宋元**：文话书教古文声口（陈骙《**文则**》以“**辞之道**”论文语气——**修辞学化的虚词学**）；**清**：**刘淇《助字辨略》**（“**助字**”成学，泛释经史虚词）、**王引之《经传释词》**（以**声音通假**与**举例归纳**治虚词——《经传释词》自序以“**前人所未及，余都录之**”自任，全书以经传异文与汉人旧注互证，是举例归纳法的教科书**）；**清人辨伪法庭**：**阎若璩《尚书古文疏证》**以语词年代差为罪证——**阎氏考其晚出《古文尚书》字句多袭旧籍、语汇不合三代，开“语言断代”判例**——与上一章“**市买”为东汉语**”同一法庭的证物室——**此即后世所谓“语言年代学内证”**；**民国**：《**马氏文通**》立“虚字”四卷（**介词、连词、助词、叹词，西法抽屉第一次量中式衣服**）; **杨树棠《词诠》**（1928）把经传虚词编成**语法字典**（“每一词给职名”）；**当代**：**当代计量文体学**（虚词频率向量做文体计量——**用词可仿，习惯难装**；现代判例如《红楼梦》前八十回与后四十回的虚词聚类分离**“现代计量文体学以虚词频率为最稳的文体指纹（用词可仿，习惯难装），已用于小说作者归属研究——如《红楼梦》前八十回与后四十回之辨”**）。
:::

::: warning 虚词四坑
**“一词一义”强迫症**（把“以”统一译“用”——**一词多职是常态，判职靠位置**）；**“焉=兼词”扩大化**（逢焉就拆“于之”——**语气词读法的焉，硬拆会拆出语病**：“始一反焉”没有“于”“之”可拆）；**之字五岗漏检**（“**何陋之有**”=提宾标记；“**师道之不传也久矣**”=主谓之间取消独立；“**蚓无爪牙之利**”=定语后置之字——**三个“之”，三种倒装手术，缺一把就认不出病人**）；**仿作陷阱**（明清古文家虚词用得比先秦还先秦——**频率断代防得了无意造假，防不了有意仿古**；须与字形、名物、避讳并案侦查）。
:::

::: exercise 语法切片 {level=1}
给下列各句的加粗虚词出“岗位说明书”（词性＋岗位＋一个现代汉语对应词）：①“**以**其无礼于晋，且贰于楚也”；②“若不阙秦，将焉取**之**”；③“积土成山，风雨兴**焉**”；④“身死人手，**为**天下笑”；⑤“吾所以为此**者**，以先国家之急而后私仇也”。
::: solution
参考：①以＝连词·表原因（“因为”——**注意它后面跟句子，介词跟短语：判岗看它挑多重**）；②之＝代词·宾格（“它”——代城/代物，**宾格之永远指向最近上文**）；③焉＝兼词（“于此”——山与风雨的**现场直播位**）；④为＝介词·被动（“被”——**“为所”式的前身，汉代起飞**）；⑤者＝**语气提顿＋解释接口**（“…的原因”——因果复句的**铰链**：判断句、设问句、因果句三张床它都能睡）。判分：岗位命名用语法学名，同时给现代汉语对应词——**只有术语没有译词是空转，只有译词没有术语是玄学**。
:::
:::

::: exercise 仿作鉴定 {level=2}
伪作一篇（40–80 字）“先秦风”短文（可用“盖、其、夫、焉、耳”至少三个虚词），同桌互鉴：找**时代穿帮**（先秦没有的虚词搭配、后世语法混入），并给出与本课“频率法庭”一致的三条判据。
::: solution
判分：仿作的穿帮**可被规则说明**（如先秦“也”不作句中提顿于非判断句、“们”字后缀穿帮、“**于是乎**”晚起——凡此皆由频率证据支持，**说不出判据的“感觉不对”不算鉴定**）；反向自检：**你自己的现代汉语习惯（“进行”“对于”）混进文言同样穿帮——语感的盲区是自己**。
:::
:::

::: exercise 小论文：虚词与人格 {level=3}
写六百至一千字：“一个人爱用的虚词暴露他的认知姿态”——从“其…乎”的犹豫、“盖”的开场咳嗽、“耳”的收束轻蔑、“焉”的留白中任选两条，结合作品实例（《论语》《庄子》《史记》或现代作家的语癖任一）作文体学分析，并回答：**统计说“用词可仿，习惯难装”，你同意“人格即虚词分布”到这个程度吗？**
::: solution
判分点：语气与姿态的**机制描述**（“其恕乎”=给出标准答案的同时撤掉教鞭——**测度语气的教育学**；“耳”=“不过如此”的收束——**轻蔑的语法化**）；实例带原文；对“人格即分布”给出**有保留的立场**（个人风格真实存在（作者指纹库可用），但**仿作、文体套用、时代语料都稀释人格解释**——同意 70 分即可，须写余下 30 分给了谁）；结论若落到“**读懂一个人的虚词，是读懂他的犹豫在哪里停笔**”，即 A。
:::
:::

::: summary
车间结账：双机（者=名词化＋倒装登记戳；所=宾语提取＋被动构件；“所以”两吃）、梯（以：拿→用→因为；其：那→他的→大概吧；焉：在这→呢——**每一层都埋着一个实词的尸骨**）、转接头（而：顺接转接降压，看两头电压差）、法庭（频率指纹＋仿作反例：阎若璩案在卷）。方法一句话：**虚词判岗靠位置，断代取证靠频率，鉴赏还魂靠朗读**。下一章换时代：骈文与赋——当汉字开始**对仗成性、押韵成癖**。
:::
