---
title: "传统注疏"
---

现代人读古书是**裸读**，古人读古书是**带着整栋楼读**：经文之下有传，传之下有注，注之下有疏，疏之外还有集解、正义、章句、音义、疏证——一栋住了两千年的**解释公寓**。本章教你查水电表：每种注释是什么工种、按什么规矩干活、互相怎么打架。

## 户型图鉴 {#def-huxing}

::: definition 九种注释的工种 {#def-gongzhong}
**传**（最早的两式：训诂相传——《毛诗故训传》；**史事展开**——《春秋》三传：《左传》**依经附事**以史实解经，《公羊》《穀梁》以义例解经——**同一部经，开了“史”与“例”两条生产线**）；**注**（“注”如水之灌注，使文义通——**注的定义自带水利工程**；郑玄兼采今古文的注是行业标杆）；**笺**（郑玄《毛诗笺》：以毛传为本，**未明处加以补充，小异处标记出来**——**给前辈的注做批注：同意处补光、异议处画线**）；**疏／正义**（注的注：既解经又解注——**唐代“疏不破注”的行规：子注释不得推翻母注，包着螺丝再拧一层**）；**集解**（何晏《论语集解》**集诸家善说**——**会议纪要体，注者本人不露面**；南朝皇侃《义疏》、宋邢昺《疏》层层叠加）；**章句**（**离章辨句**：分章断句加串讲——给初学者用的朗读本，赵岐《孟子章句》保存着汉代句读的现场）；**音义**（“读如”“如字”——给多音多义字标音，陆德明《经典释文》：**读音一锤，义项落定——音注是成本最小的训诂**）；**集注**（朱熹《四书章句集注》：**选家入注，义理为纲**——从“保存众说”变成“裁决众说”）；**疏证／新疏**（清代一式：**注疏＋考订**——戴震《孟子字义疏证》借解字打义理，刘宝楠《论语正义》以新疏替旧疏：“**疏不破注”改为“疏必核注”——一册新疏＝一次对整栋楼的结构性检修**）。
:::

::: definition 训诂三法与注者纪律 {#def-sanfa}
**形训**（依字形说本义——《说文》“目，人眼，近目象形”一类；**前提是这个字的字形还没骗你**：部分说解已被甲金文订正——“为”字案见[[classical-chinese-2/original-meanings]]）；**声训**（两把钥匙两扇门：上行是“**读为、读曰**”破通假——可复核的科学；下行是“**之言、之为言**”推语源——“天，颠也”式的民俗词源——同一手法，一半是手术刀，一半是算命盘）；**义训**（不借形不借音，直接给定义：注疏里满页的“**某，某也**”；含一门绝活“**反训**”——**“故”一字兼训“古”与“今”，“乱”兼训“治”：一词两反，义训里最难缠的刺头**）。**注者三纪律**：**不改字**（底本有讹？注中存校记，不私改经文——**校勘归校勘，注释归注释**）；**不代笔**（“疏不破注”——**层间契约：你可以憋着，不可以推翻你赖以上架的那层**）；**不装懂**（“**君子于其所不知，盖阙如也**”——**注里每一个“未详”“义未闻”“或曰”，都是良心记录**）。
:::

::: example 解剖一间房：“学而时习之” {#ex-xueer}
《论语·学而》首章“学而时习之，不亦说乎”——请从五层楼板各取一件材料并标注工种：①何晏《集解》所引汉说；②皇侃《义疏》／邢昺《疏》；③朱熹《集注》；④刘宝楠《正义》；⑤一部现代译注。
::: solution
**楼层记录（据要籍转述大意）**：**①何晏《集解》**：马融曰“**时者，学者以时诵习之**”——**集解体：引一家言即入册**，“时”=按时（**课程表读法：诵习以时**）；**②邢昺《疏》**：于注下加“**正义曰**”，逐句贯串补字解句——**疏的工种：让注重新流动起来**；**③朱熹《集注》**：“**学之为言效也**”（声训上岗），“时”**改训“时时”**——**从按时上课改成随时复习：教育制度变了，训诂跟着搬家**；**④刘宝楠《正义》**：钩稽汉儒“诵习”家法，**回锅反证宋人“时时”之说无据——清人用汉注打宋注，每一层都在用更古老的权威压当代的对手**；**⑤现代译注**：多从朱子“时时实习”而泛化其义——**教科书是最后一层楼，也是最薄的一层（脚注里能看到电梯井）**。楼层总结算：**同一句十二个字，先后住着“按时上课—随时复习—心性觉醒”三代租客；每一代都声称房契上写着自家的名字。**
:::
:::

::: intuition 注疏是时间折叠术 {#int-zhedie}
读注疏的隐秘快乐：**同一页纸上同时住着四个世纪**——经是先秦，注是汉魏，疏是唐宋，集注是南宋，疏证是清。一句话“三十而立”：注家或解作**学问成立**（“有所立”的汉儒口径），或解作**不为事物摇动**（道学的心性口径）——**你翻一页，等于旁听一场跨朝笔会**。这套折叠术的训练价值：**让你对“原意”这个词永久免疫**——不是没有原意，而是**原意从来只能通过层层注释抵达，每一层都是一次再创作**（“**诗无达诂，易无达占，春秋无达辞**”——《春秋繁露》，**解释学的汉代出生纸**）。所以读注的正确姿势不是“从注里挖出经”，而是**把经与注当一对上下级文件对照读**：看注给经补了什么（史料）、改了什么（立场）、忍住没改什么（时代边界）。
:::

::: history 一栋楼的扩建史 {#sec-kuojian}
**先秦**：“传”起家——师徒口耳的训诂累积（《左传》依经附事，公羊家的“解诂”是其义例版）；**汉**：注经=立派——**今古文之争让“注”成为师法家法的宪法**（“某家之学”的户口制：注一经者，弟子绛帐相传）；**郑玄**“**括囊大典，网罗众家**”，兼采今古（《毛诗笺》以毛为本、间下己意——**“注不破传”的软性突破**）；王肃注经**与之立异争名**（“王肃学”的反郑营销——**注经也可以是品牌战争**）；**唐**：孔颖达《五经正义》——**官方定本＝解释天花板，科举“疏义”取士：解释公寓收归国有**；**宋**：义理入住——朱熹《四书章句集注》以“心与理”的框架重组经义，南宋以后成为科举程式——**汉唐注疏被指“寻行数墨”，公寓迎来装修队**；**清**：乾嘉“回到汉注”——惠栋一派主张以汉儒“去古未远”的训诂重建经义；戴震立“**由字以通其词，由词以通其道**”流水线；刘宝楠《论语正义》、刘文淇《左传旧注疏证》——**新疏运动＝对整栋楼的结构性检修**；**现代**：注疏变出土文献——郭店、马王堆简帛把“校勘＋义理”提前到**经典形成之前**的阶段；《故训汇纂》与数据库把两千年故训搬上云端——**查层号的时代结束了，选楼层的时代开始了**。
:::

::: warning 用注四病
**只读译文不读注**（白话译本替你做掉了全部训练——**注疏的价值在“怎么纠结”，译文只留“结论”**）；**只读一层**（拿朱熹集注当“孔子的意思”——**把南宋租客当成房东**）；**迷信“权威注本”**（**“注不破注”意味着注本身可能憋着错**——王肃的反郑注就是“立场先行”标本——好注也须比对家底）；**以注代经**（沉迷故纸层累，**忘了先读二十遍经文**——注疏的入口永远是白文精读：**先自己撞上问题，再请楼层帮忙**）。
:::

::: exercise 分层解剖 {level=1}
任选《论语》一句（如“克己复礼”），找三层：何晏集解系（或杨伯峻译注所引汉旧说）、朱熹集注、一种现代译注，列**分歧表**：释字差异→语法差异→思想差异，各举证据。
::: solution
判分：**分歧定位到字**（如“一”读数词还是“专”——**若注家无此说，不许多头创造**）；语法差异写得出（“克”及物/不及物、“为仁”结构）；**思想差异**一句总结（约束 vs 心性是两种伦理学）；全程引用页码——**注疏实操第一课：凡判必可复核**。
:::
:::

::: exercise 注者上岗 {level=2}
给《论语》自选一句白文（如“**君子求诸己，小人求诸人**”）写一条二十至四十字的“注”，**要求仿两式**：①一句式训诂（“某，某也”）；②引经式（援他书证此句）。附校记一条（若有异文）。
::: solution
判分：注体语言合规（**文言注不是白话注的缩写**）；训诂式有辞书/经证可查；引经式出处精确到篇（“《卫灵公》：‘躬自厚而薄责于人’——互文见义”级）；校记格式（“某，一本作某／类书引作某”——如“诸，一本作之”式的通假旁记）；**自评：这条注有没有“装懂”——没有把握的字宁可标“未详”**。
:::
:::

::: exercise 小论文：解释的产权 {level=3}
写六百至一千字：“一部经典的意义，归经文还是归注疏？”必须调用本课两个史实（王肃反郑、《五经正义》官修、朱熹改“时”义、清人新疏任选其二），论**解释权的转移机制**（师法—科举—印刷—数据库），并回答：**你今天读的“原文”，是谁替你选的楼层？**
::: solution
判分点：史实调用准确（王肃案写清“**以注经争品牌**”与家学利益，不停留在“小人误国”的八卦层）；机制链完整（汉家法→唐官修→宋刻印→清考据→今数据库——**每次媒介革命换一次房东**）；“楼层自白”诚实（写出你用的版本与译者——**学术诚信的起点是承认自己一直在楼里**）；结论若为“**经典=经文＋其解释史的总和**”，即 A——但须为这句话付过论证。
:::
:::
