title: "代词、数词与称呼"
---

把一句话里最“虚”的三样东西——**谁、多少、怎么称呼**——在文言里全是重工业。代词看**位置**，数词防**掺水**，称呼查**户口**：这一章是古人人际导航系统的说明书，读错一格，不是尴尬，是**事故**。

## 代词：谁的语法 {#sec-dai}

::: definition 三支代词队伍 {#def-dai}
**自指队**（第一人称）：吾、我、予／余（《论语》**吾我分工的上古旧说：吾多主格、我多宾格——《尚书》“**予及汝皆亡**”连“汝”都同船**）、印（古书仅存的自称化石，辞书标“我”，例不数见）、**朕**（**秦始皇以前人人可自称**——屈原“**朕皇考曰伯庸**”毫无皇气；**前 221 年起国有化为帝王专名——一个代词的产权变更史**）、小子／仆／牛马走（“**太史公牛马走司马迁**再拜言”——自谦编入仆役班）、妾（女子自称的部门用语）、臣（见君即“臣”——**官职情境自动转代词**）；复数无词形，靠后加件：**曹、属、辈**（“**若属皆且为所虏**”“吾曹”）。**指人队**：女／汝、尔、而、若（“**若入前为寿**”，鸿门宴上的“你”；“**若属**”同族）、而（《左传·宣公十五年》“**余，而所嫁妇人之父也**”——“我是你所嫁妇人的父亲”，一句话说尽恩怨与语法
::: definition 称呼：名、字、谥与台阶学 {#def-chenghu}
**名**幼时所命、**字**二十冠礼所加——“**幼名，冠字，五十以伯仲，死谥，周道也**”（《礼记·檀弓》：人生四套证件）；**自称用名**（自贬是礼貌的另一半），**平辈尊长相称称字**（直呼其“名”＝君对臣、上对下的**降格打击**——《论语》里国君称孔丘，门人记老师称“夫子”）；死后有**谥**——**盖棺的评分系统**（《逸周书·谥法解》“道德博闻曰文、克定祸乱曰武”——**“文正”是文官的满分卷**）；帝王的**庙号/谥号/陵号**三套售后标签并行（太宗、文皇帝、昭陵——一人三号）。**对称敬称是台阶学**：足下、阁下、殿下、陛下——本义都是**不敢直指其人，呼其台阶下执事者传呼**（足下最平民，殿、陛是建筑标高）；自谦矩阵：**孤、寡人、不谷**（“**人之所恶，唯孤寡不谷，而王公以为称**”——《老子》看穿了这套**以凶名自居**的话术）、**不佞、不才、不肖**（无才能系）、**窃、私**（“窃以为”——意见先自降半格）、**贱息**（“**老臣贱息舒祺，最少，不肖**”——触龙说赵太后：连儿子都是“贱息”）。另有**称字、称官、称郡望、称排行**四套并行检索系统（王右军、柳河东、白二十二——**唐人的通讯录按官籍、地理、长幼三列索引**）。
:::

::: definition 数词：实数、虚数与古分数 {#def-shu}
**虚数防身三诀**：清儒通识——**古人称数，三、九、百、千、万常为“多”的借字**（王引之《经义述闻》屡发此例）：“**三仕三已**”未必点三次账、“**九死其犹未悔**”不申请保险、“**将军百战死，壮士十年归**”是互文兼虚指的双簧。**实数暗坑**：**再＝第二次**（“一鼓作气，再而衰”——“又”的兼职是后聘的）；**“倍”常通“背”**（背叛——数字里也蹲着通假）；**汉式分数**：“十死二三”“亡十二三”＝十分之二三（**《史》《汉》的伤亡口径，实数**）；“**什一**”＝十分税一（**“什一之税”**，孟子的税率考古）。**量词未量产时代**：“**乘韦先，牛十二**”（《左传·僖公三十三年》弦高犒师：熟牛皮先行、十二头牛跟上——**数词后置是上古的常规车位**）；“带甲百万、车千乘”是策士的军备报价。读先秦先装直觉：**数字＝东西，位置自由，量词还没出生**（匹、头、个是后起之秀）。
:::

::: example 一封国书的人际导航 {#ex-guoshu}
《战国策》风格模拟诏对：“**寡人不足承宗庙，夫人与诸大臣谋不谷——不谷不敏，敬诺。夫子行矣，为寡人谢齐王：‘弊邑之主，愿为兄弟，岁输皮币。’**”圈出全部称呼与自谦，译成现代外交辞令，并指出**两处故意自贬**与**一处借他人台阶**。
::: solution
**自谦矩阵**：寡人／不谷（两次自贬是**外交的缓冲垫**——老子早就看穿这套**以凶名自居求吉祥**的话术）；
:::
:::

::: intuition 代词是空的，称呼是满的 {#int-kongman}
本章的哲学：**代词的意义几乎全靠语法位置发工资**（“之”自己什么也不是，站在宾格位上才领“他/它”的薪水——**现代汉语的“他”也还兼任“它”与虚指**）；**称呼的意义则全是制度灌注的密度**（同一个“你”：尔＝平视、足下＝垫了台阶、陛下＝隔了大殿——**汉语第二人称的历史是一场漫长的客套通胀**：“你老→您”在明清才完成升级，“您”字本是“你们的”——**复数变敬数是通货膨胀的标准路径**，跨语言一致）。于是阅读策略二分：**遇到代词，查位置**（格与语序：它站在句子的哪个岗）；**遇到称呼，查制度**（谁在台上、几级台阶、避谁的名）。顺手一条写作启示：**今天的“贵司、敝处、在不”全是这套系统的活化石**——“在不”零台阶，所以只配得上朋友。
:::

::: history 从甲骨文到“您”字 {#sec-lishi}
**甲骨文**：数字系统完备，田猎刻辞记擒获用实数明细；“三、九”的虚化是传世文献层的现象（**实数在卜辞，虚数在诗书——两种记账法**）；**周**：“幼名冠字”成礼（《檀弓》），伯仲叔季进户口本（**仲尼排行第二**）；**秦前 221**：“朕”国有化、陛下制度化——**代词史的第一次产权改革**；**汉**：注经师以“**而，犹女也**”式的声训对译处理人称代词——**训诂学兼职语法学**；**清**：《马氏文通》（1898）立“代名字”一门——**印欧语法的抽屉第一次塞进文言代词，合不合身头一回有人量**；**现代**：王力等汉语史研究表明“**您**”是“你们”的合音缩变，宋元白话见形、明清北方官话完成敬称升级——**汉语史上罕见的第二人称通胀升级**；**当代**：简帛出土显示同一语句在战国抄本与传世本常用不同代词——**代词最易被传抄“通语化”，简牍因此是代词史的现场录像**。
:::

::: warning 称呼四事故
**称名事故**——对尊长直呼其“名”，古义等于当众扒工牌；**自称称字同样翻车**（抬着自己行礼）；**朕字穿越**——秦以前自称“朕”不违宪，秦以后宗室外擅自称“朕”是谋逆罪证（**断代与辨伪的双重抓手**）；**数词实读**——“三仕三已”记流水账、“亡者十二三”按全灭哭（**抒情区虚数、史书区实数——先问语域再落笔**）；**避讳盲区**——见“常山”不想“恒山”，就是**拿着改过名的身份证认人**。
:::

::: exercise 称呼审计 {level=1}
给《出师表》《出师表》节选（自“**臣本布衣，躬耕于南阳**”至“**临表涕零，不知所言**”）：列出全部自称与称人词，按“谦/敬/中性”分档，并数“先帝”出现次数的修辞账。
::: solution
判分：表内只收实际出现的词：臣（自称·谦）／先帝（称亡君·敬＋追谥）／陛下（对称·台阶学）；“先帝”凡六见——**每次提及都是把创业合伙人请上席作证人**（**刘先帝的亡灵是本表最强打手**）；“尔来二十有一年矣”的“尔”＝**那**（指示非人称——**代词一词多岗的当场抽查**）。
:::

::: exercise 数字翻译官 {level=2}
翻译并标注虚/实：①“三人行，必有我师焉”；②“亦余心之所善兮，虽九死其犹未悔”；③“再拜献大王足下”；④“行路之余，十才二三”；⑤“地方千里，带甲百万”。
要求：凡虚数注明“借字为多”的修辞动机。
::: solution
参考：①三＝约数/虚（多人之借，**“三”与“师众”对举成理**）②九＝极多（**死到九次是忠诚的夸张语法**）③再拜＝拜两次（**礼制实数：动作次数有制度，不虚**）④十二三＝十分之二三（**汉分数，实数口径**）⑤“带甲百万”未必点验——**数字的排面：策士区最虚（军备报价），礼制区最实（再拜＝拜两次，动作有制度）**）。判分：**虚/实不由数字大小定，由语域定**（礼制区实、抒情区虚、策士区最虚——**见人说数，先问场合**）。
:::
:::

::: exercise 小论文：敬称通胀史 {level=3}
写六百至一千字：从“尔汝”到“您”，从“足下”到“亲”（今日网购客服的“亲”），论**第二人称敬称的“通胀—贬值—再升级”循环**；必须调用一项本课史实（陛下台阶学、复数变敬数、“若属→你属→你们→您”合音链任一），并预测：**下一个被淘汰的敬称会是哪一个？**
::: solution
判分点：机制清晰（**敬称的寿命=它被滥用的速度**——**“哥”古义为“兄”、“爷”古义为“父”——称呼系统里每个词都有跌落与漂移史**，梁章钜《称谓录》材料具在）；史实调用准确（合音/缩变是**语音为礼貌服务**的实例）；预测成理（“宝宝/老师/师傅”的通胀路线——**“老师”从经师口径到直播口径，是当代活样本**）；结论若为“**敬称的终点是重新成为昵称**”，本课 A。
:::
:::

::: summary
导航系统结账：代词三队（位置发工资——格位语序两条前置律）、称呼四证（名冠字谥＋台阶学＋自称自贬矩阵；“朕”的产权史）、数词虚实（再＝两次、汉分数、名量词未量产时代的后置车位）、通胀一条（你们→您；**敬称是贬值最快的货币**）。方法一句话：**代词看位置，称呼查制度，数字问场合**。下一章回到虚词深水区：其、之、而、以、焉的语法学级拆解——文言语法的承重墙。
:::
