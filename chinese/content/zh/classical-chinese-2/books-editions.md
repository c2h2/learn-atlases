最后一章回到**物质**：字写在什么上、装订成什么形状、从哪座阁里散出来——这三件事决定了你今天翻开的一页里，每个字为什么在那个位置。学完本课，你将能独立做一件事：**给任意一部古书，配一部对的注本，并说清为什么是它**。这是文言Ⅱ的结业证书，也是所有后续课的门票。

## 书的物质史 {#sec-wuzhi}

::: definition 材料、装帧与阅读姿势 {#def-wuzhi}
**材料三代**：甲骨青铜（**铸**出来的字，字数受限——**殷墟十万片甲骨撑起的全部文献量，抵不过一部《左传》**）、**竹木与缣帛**（“**杀青**”：火烤竹简出汁如汗，防蠹又易书——**“汗青”“篇”“卷”“编”“删”（拿刀改字）全是我手写字的动词化石**；韦编三绝=皮绳翻断）、**纸**（东汉普及；**写本时代四百年、刻本时代一千年——“书”的默认格式决定了我们认得的每一个版式习惯**）。**装帧五变**：简册→**卷轴**（故“**卷**”为部分单位；卷轴首尾有轴，读=向左展开——**从右向左书写的物理原因**）→**经折**（佛经舒卷麻烦，改手风琴——**一拉即开，查检时代的先声**）→**蝴蝶**（唐末五代刻本，**翻页时两半页如蝶翼同向翻**）→**包背、线装**（“**叶**”“**页**”“**书口**”“**版心**”“**鱼尾**”全是版刻术语——**你手里的每本古籍影印本，都是一张宋元版片的拓影**）。关键推论：**装帧决定批注方式**——卷轴时代在卷间缝里写“**侧注**”，刻本时代在版心下写“**夹注**”、天头写“**眉批**”——**李善注的“注下疏前”体例、金圣叹的天头狠批，都是家具决定的坐姿**。
:::

::: definition 四大部家底速点 {#def-jiadi}
**经**：最小闭环=**《十三经注疏》**（阮元校刻本为通行底册；**经部十类的读书顺序从《毛诗》《左传》入最不枯燥**）；单点推荐：《论语》**杨伯峻《译注》**打前站、刘宝楠《正义》断后；《孟子》**焦循《正义》**；《诗经》**程俊英《译注》＋毛传郑笺孔疏**对照；《左传》**杨伯峻《译注》**（现代左传的天花板之一）。**史**：**点校本二十四史**（中华书局，1958—1978 集体工程——**一套书的凡例就是一部当代学术史**）；入门不读全史，读**《史记》三家注**＋《**资治通鉴**》胡三省注（**胡注：“通鉴之学，经纶措置，规模本末”——读史者的战略参谋**）。**子**：《老子》**陈鼓应《注译》**＋王弼注；《庄子》**陈鼓应《今注今译》**＋郭象注、成玄英疏；《荀子》王先谦《集解》、《韩非子》陈奇猷《集解》——**子书先清文本再谈思想，伪篇不辨则立论全歪**。**集**：《楚辞》**洪兴祖《补注》**（**“补注”体例：先列王逸注，再补自己的考订——教科书级的“接着说”姿势**）、《文选》**李善注**、杜甫**仇兆鳌《详注》**、苏轼**王文诰《辑注》**、李白**瞿蜕园、朱金城《校注》**、《红楼梦》**庚辰本影印＋人民文学校注本**并读——**集部从总集入门（《文选》《文苑英华》《全唐文》），别集精读一两家，其余翻目即可**。
:::

::: example 选案实操：一位读者的四种入口 {#ex-ruku}
场景：读完本课的理工科读者，想在一年内“真正读完一部古书”。四个备选：①《史记》全史；②《世说新语》；③《庄子》内篇七篇；④《红楼梦》。请为每人配**版本＋注本＋日程＋验收标准**各一，并说明为什么不是另外三个。
::: solution
**判例**：①《史记》**劝退全读**（一百三十卷，无师半途而废率极高）——改配**选读本＋三家注节选**，验收：“**列传精读十五篇，能画一张人物关系图**”；②《世说新语》**入门最优**（分则短、语言浅、余味长；**3 卷 36 门 1130 余则**——**日读三则，一年有余**）——版本配**余嘉锡《笺疏》**（**笺疏体示范：以史证小说——笔记升格为史料的加冕礼**），验收：“能指出哪几则被《晋书》抄走并改了口吻”；③《庄子》内七篇**思想读者的首选**（**文本量小、密度最大；成玄英疏太难，郭象注+今注对照即可**），验收：“**《逍遥游》《齐物论》各抄一遍全文并白文能读**”；④《红楼梦》**版本最复杂，不宜首战**——但一旦读完，**等于旁听了一整堂版本学**（抄本与印本的差异肉眼可见）。**共同法则：书要选“读得完”的——读不完的名著，是文言学习最大的沉没成本。**
:::

::: intuition 凡例是一本书的宪法 {#int-fanli}
中华书局点校本“**二十四史**”的凡例规定：底本择善、通校诸本、**改字必出校**——从此“点校本”三字有了法律效力；反过来，**一本整理本若不写凡例，等于治国不立宪法而自称大治**。这也是本课的方法内核：**古籍阅读的第一层理解，是理解“这个本子为什么长这样”**——同样一句“床前明月光”，宋刊本《李太白文集》与《唐诗三百首》之间的差别，不是一千个字，而是**一千年的编辑立场**（[[classical-chinese-2/commentaries]]三查在此正式上岗）。更深一层：**凡例精神可以迁移到一切二手材料**——看一篇论文，先找它的“凡例”（方法与材料说明）：底本是什么（数据库版本）、通校了什么（综述覆盖）、改字出不出校（引文是否照抄）——**版本学是批判性思维的古典形态**。
:::

::: history 藏与散 {#sec-cang}
**汉**：广收秦遗书、**建藏书之策**（石渠、天禄阁——**国家藏书的罗马**）、刘向父子校书成程序；**魏晋**：荀勖整理中经，**创四部分类之先声**——战乱之世，官藏三聚三散；**唐**：**御书四库**（集贤院写书，“**甲乙丙丁**”四部帙色——**四部有了颜色编码**）、敦煌藏经洞封存（约 1000 年前后）——**一座窑藏住了写本时代的全部底片（1900 发现、1910 劫余入京——藏与散的同一条曲线）**；**宋**：**官方刻书三系统：国子监、州郡、私刻坊刻**（**两浙路刻本号称“宋本第一”——最早的“产地认证”**）、崇文院四部书从三万到五万卷——**印刷让藏书从奇迹变成常态**；**明**：**《永乐大典》**（1408 年成书，**“用韵以统字，随字以载事”——按韵索引的巨型类书，原书十之九散于战乱，至今存四百余册**——**类书的命：编者想它做仓库，历史让它做墓碑：佚书靠它还魂（清人从《大典》辑出大量宋元文献）**）；**清**：**《四库全书》**（1782 成书，文渊等**七阁**——**抄了七遍的书照样在火灾与战争中逐阁消失；“书厄”是藏书史的常规天气**）；**民国**：**晚清四大藏书楼**（**陆氏皀库、丁氏八千卷楼、杨氏海源阁、缪氏艺风堂**）——四家宋元善本的聚散就是近代古籍流通史——**皀库归日本岩崎氏、八千卷楼归江南图书馆：私楼散，公藏收**；**《四部丛刊》影印化身千百＋各地图书馆接受捐赠——私楼的时代结束，公藏的时代开始**）；**当代**：《**中华再造善本**》（2002 起影印工程——**“再造”的哲学：把孤本变成千家有，把风险变成零**）、海外汉籍回归与高清影像（**数据库里没有国界，但有版权**）。
:::

::: warning 选书四坑
**书单崇拜**（“必读一百种”背完仍是零——**书单是地图，不是徒步；本课的“三十种”也只配当鞋柜**）；**只买畅销注本**（销量与校勘质量无关——**按“一校二据三兼”验货**）；**一套好本子打天下**（杨伯峻的《论语》与《左传》皆精品，但**注本的能力有边界**：《诗经》要找程俊英与毛传郑笺，《孟子》要上焦循——**用对工具比信对大师更可靠**）；**以“读完”为荣**（《资治通鉴》精读卷首三十卷远胜翻完二百九十四卷——**验收标准必须是“能画图/能背白文/能讲人”，不是“已读完”的打卡**）。
:::

::: exercise 我的最小藏书楼 {level=1}
经史子集各选一书名（**不许抄本课例单**，可参考《书目答问》或权威导读），各写两句推荐理由＋你**查到的**一部具体注本（书名字号作者）。
::: solution
判分：**经史子集四部各一部、不重类**（常见偏科：集部四部——史部空——**史部是文言词汇的军火库，必须有**）；每部的推荐须**有一句“为什么是它给你”**（如“《盐铁论》：会议记录体，争论语言最接近口语”）；**版本信息具体到整理者与出版年**——凡例精神，从自己的书单开始。
:::
:::

::: exercise 注本评测 {level=2}
就同一部书选**两个注本**（如《论语》杨伯峻 vs 某名家译注；《红楼梦》人民文学校注 vs 庚辰本影印），依“前言—凡例—校记”三步写出 300 字评测，给出**分场景推荐**（考试/研读/收藏）。
::: solution
判分：三步各有**页码级证据**（“凡例第 2 页称以如何本为底本，然校记中未见引据”）；分场景推荐不和稀泥（**收藏场景允许推荐“贵但善”**）；评测语言就书论书——**版本学的道德：只比较证据，不裁决品味**。
:::
:::

::: exercise 结业项目：一部书的完整档案 {level=3}
选一部你已读过的古书（诗词曲类亦可），制作**五件套**：①版本说明书（材料—抄刻—整理本谱系，一页）；②注本评测（两种以上）；③白文＋自注（选一段 10 句内，仿第 6 章体例写“注”）；④札记一则（一段话里处理一个**异文或署名问题**，仿第 8 章“三查”）；⑤四百字反思：“这一路我改变了哪些‘我以为的原作’”。
::: solution
判分点：五件套**内部互相引用**（③的注须与②所选注本对话；④须用到①的版本信息——**课程要求的不是五个作业，是一个系统**）；⑤写出至少一次**具体幻灭**（“我以为‘举头望明月’是原文，其实宋本作‘抬头望明月’——**望月姿势都被版本改变了**”——此类真实发现，胜过一百句感想）；全档案合格=**文言Ⅱ结业：你不再是文言的读者，而是它的编辑之一**。
:::
:::

::: summary
物质课结账：材料（杀青汗青、动词化石）、装帧（卷轴→线装，**家具决定坐姿**）、四部家底（经《注疏》、史点校本、子清文本、集从总集入）、藏与散（**“书厄”是藏书史的常规天气**；再造善本=把孤本变千家有）、方法（**凡例=宪法；版本学=批判性思维的古典形态**）。文言Ⅱ至此合拢：**本义—同义—代数量词—虚词—骈赋—注疏—常识—读注—书籍**，九章一条线：**古书是层累的商品，读懂它=读懂它的生产线**。下一站：两汉魏晋南北朝文学——你带着全套工具，走进文学自觉的现场。
:::
