---
title: "骈文与赋"
---

先秦的散文是徒步，汉以后的骈赋是**踩高跷行走**——还要边走边跳舞。这一章教你两件事：**看懂骈文的对称强迫症**（为什么中国人把对仗修炼成了审美本能），**看懂赋的铺张癖**（为什么描写可以理直气壮地膨胀）。它们不是文言的反面，是文言的**成年礼**：形式自觉之后，汉语才第一次知道**自己可以只是好看**。

## 骈文：对称的语法 {#def-pian}

::: definition 骈句三件：对、声、典 {#def-sanjian}

::: definition 四六：一个文体的身份证号 {#def-siliu}
“四六”之名起于晚唐——**李商隐《樊南四六甲乙集》：文体由文集名反认证件号**；宋沿为**应用文正装**：表、启、制诰、谢恩，凡对皇帝说体面话皆四六（**苏轼、王安石文集里表启满卷——唐宋作家的“公文皮肤”**）。句式以**四字六字交错为骨**（四四、六六、四六、六四四种拍子）；配套**领字**（“且夫、若夫、至若、已而”——段落发动机）与**关节语**（“是以、然则、是故”——连接件也是礼数）。六朝的文体户口：**“今之文章，盖古辞之流；有韵者文也，无韵者笔也**”（《文心雕龙·总术》大意——**押不押韵、抒情不抒情，是当时“文”科的入学考试**：经史奏记是“笔”，“吟咏风谣，流连哀思”（萧统《文选序》）才是“文”——**骈文就是“文”科的金牌项目，文笔之辨是它的出身证**）。
:::

## 赋：描写的膨胀史 {#def-fu}

::: definition 赋的三次变身 {#def-sanbian}
**名号出身**：**“赋者，铺也，铺采摘文，体物写志**”（《文心雕龙·诠赋》——**定义自带执照：铺张是本业**）；而“六诗”之赋（《毛诗序》）指**直陈其事**——**先有诗法，后有文体：手法转正为体裁**。荀子《赋篇》以隐语写礼、云、蚕、箴——**最早的“赋”是谜语文学**：铺陈特征、最后揭底，**描写文与谜语的双胞胎**。**汉大赋**：**客主问答起手**（子虚、乌有先生、亡是公——**人名即宣言：让虚构人物开座谈会**）、**空间铺排**（左山右水、东西南北逐层报价）、**卒章归讽**（结尾补一句“于是省边界、退奢乐”——结果**劝百讽一**：扬雄供认“**童子雕虫篆刻，壮夫不为**”（《法言·吾子》）——**铺张被皇帝读爽了，讽谏无人签收**）。**抒情小赋**：东汉以后，大赋的江山缩成田园一角——张衡《归田赋》“**于是仲春令月，时和气清**”——**“内转”开始**。**骈赋**：六朝给赋穿上四六礼服（《洛神》《别》《恨》）。**律赋**：唐以赋取士，**限官韵、严对仗、定格句——科举版赋，程式登峰**。**文赋**：宋人**以文为赋**——杜牧《阿房宫赋》开先声，欧阳修《秋声赋》、苏轼《赤壁赋》成典范：“**耳得之而为声，目遇之而成色**”，对偶退居二线、虚词重新呼吸；末段“洗盏更酌……**不知东方之既白**”——**韵脚退场，画面接班：赋回迁到散文的边境**。
:::

::: example 《滕王阁序》典故电梯 {#ex-tengwang}
“**酌贪泉而觉爽，处涸辙以犹欢**”“**北海虽赊，扶摇可接**”“**东隅已逝，桑榆非晚**”“**钟期既遇，奏流水以何惭**”——四组句子，各自拆出：典故原件→原义→王勃改造后的**义项搬运方向**；并解释为什么事对连用两次“水”（贪泉、涸辙）不犯“**犯复**”之忌。
::: solution
**贪泉**：广州有石泉，相传饮之者怀金——**“环境决定论”的古代实验，对照组是吴隐之**（《晋书》本传：隐之饮贪泉而励清操，粤界肃然）——王勃反手用作宣言：酌贪泉而觉爽，**环境否决不了心性**；**涸辙**：《庄子·外物》涸辙之鲋**待升斗之水**——原典是**求救**，王勃改造成**自适**（“以犹欢”——**庄子本人听了要愣一下的乐观**）；两事同属水家族，**同形异向**：一饮一居、一爽一欢——**对偶不忌题材近，只忌意思同**；**北海扶摇**：《逍遥游》“鹏之徙于南冥，**抟扶摇而上者九万里**”——“赊”（远）对“可接”：**空间之远对修养之高，“路远怕什么，翅膀够大”的压缩**；**东隅桑榆**：《后汉书·冯异传》“**失之东隅，收之桑榆**”——原典是战例结算，王勃改成**年龄的会计科目**（少年失路—来日方长：**一次用词典完成的自我安慰**）；**钟期流水**：《列子·汤问》伯牙鼓琴志在流水，钟子期识之——“**惭”字是全文枢纽：前文所有盛宴都是背景音，从此句起他要找“听的人**”——用典的电梯到这一层，**从“炫耀存款”改成“寻找收款人”**。判分金句：**骈文的典故是压缩饼干，注释是热水——泡开之后，才知道作者饿着赶路的体面与狼狈**。
:::

::: intuition 对称是审美，也是权力 {#int-duichen}
为什么汉语文明把对仗玩成**制度**（对联、律诗、四六、楹联、章回标题）？三条：**生理层**——双音节＋方块字，天然像**两扇可关闭的门**（词是积木，句是榫卯）；**认知层**——对举是**最低成本的强调**：说一遍是陈述，说两遍同构就长得像真理（格言全靠对仗加固：“满招损，谦受益”）；**政治层**——朝仪的**对称美学**：殿、门、阙、联一字排开，**语言的对仗是建筑对仗的文案版**；科举考诗赋、外交呈四六——**对称是一种服从性测试：能不能穿着镣铐跳出官方认可的舞**。读到政治层再读骈文会换一种同情：**那些看似油滑的排偶，是文体化的跪拜礼与起立鼓——作者的美，一半是镣铐反着的光**。
:::

::: history 文体等级的一次次洗牌 {#sec-xiti}
**战国**：赋=隐语与铺陈的混血（荀子）＋**纵横家的说服术**（客主问答是先秦论说常套——**赋是辩论赛的文学化**）；**汉**：大赋=**帝国宣传工程**——“劝百讽一”，扬雄划下两种“丽”的界线：“**诗人之赋丽以则，辞人之赋丽以淫**”（《法言·吾子》——**华丽要有法度红线，这是赋家自己交的忏悔书**）；**魏晋**：**文的独立**——曹丕《典论·论文》“**诗赋欲丽**”（“丽”第一次成为官方审美指标）、陆机《文赋》“**赋体物而浏亮**”（**“体物”入籍，成为赋的定义词**）；**南朝**：骈俪封顶，《文心雕龙·丽辞》《事类》**给骈文补上学科建制**；**唐**：**古文运动反骈**（“**惟陈言之务去**”——**反的是套路，不是形式**）＋**律赋入科举**（程式登峰）；**宋**：**四六独立成科**（制诰考试通用皮肤；同时欧阳修、苏轼“以文为赋”——**一人两套皮肤，各上各的班**）；**清**：**骈文中兴**——阮元抬“**文言**”（以《文选》“**事出于沉思，义归乎翰藻**”为标尺）为骈文争正统，李兆洛《**骈体文钞**》立选本定家法——**骈文被请回正厅，古文让出独木桥**；**近代**：章太炎以“文字著于竹帛”论文学界域，**骈散不再分高下——千年文体内战的现代停战协定**。
:::

::: warning 骈赋四坑
**见骈句即堆砌**（“全是废话的对仗”——**先查对偶里有没有信息差**：反对与“正对为劣”的分界，就在两句之间**有没有势能差**）；**见赋即押韵**（文赋可以不韵——**《赤壁》是“赋”名下的散文诗**，标题即体裁声明）；**用典崇拜**（今人写作贴四枚成语冒充骈四俪六——**典故要“水中着盐”，不是“汤里撒盐”：能倒出颗粒的都不是味道，是存货**）；**尊散卑骈的洁癖**（“八股之害的源头是骈文”——**文体不背制度的锅**，八股另有八股的账；教训复用自虚词课：**批评文体之前，先查它在什么岗位上班**）。
:::

::: exercise 事对拆解 {level=1}
《滕王阁序》选段里再找三组事对（“**怀帝阍而不见，奉宣室以何年**”“**冯唐易老，李广难封**”“**杨意不逢，抚凌云而自惜**”任选两组）：候选“怀帝阍—奉宣室”“冯唐—李广”“杨意—钟期”），列表：典源→原情境→搬运方向→情绪剂量。
::: solution
判分：**原情境**具体（宣室=汉文帝贾生“鬼神”对——**问的是鬼神，不问苍生，李商隐的账王勃没预支**——能串成两唐故事者加分）；**搬运方向**动词化（“难封”把李广搬进**怀才不遇的总行**）；情绪剂量诚实（冯唐李广是**安慰剂的加倍**：“我失败得有伴了”——**骈文的排偶常是心理疗愈的语法**）。
:::
:::

::: exercise 拆高跷 {level=2}
把“**老当益壮，宁移白首之心；穷且益坚，不坠青云之志**”改写成 60 字以内散文（去对偶、去典故、可保留比喻），再反向把一段白话励志文“骈化”成四六两联。
::: solution
判分：散文化后**语义保真率自评**（“宁移”“不坠”两个反问与动词的力度是否保住——**骈句的信息藏在虚词里**，删虚词即漏气）；骈化两联：**平仄收尾合规（上仄下平）＋不用现成典故**（自造“水中着盐”实验）；互评标准：**改写前后像不像同一首诗的两种穿搭**。
:::
:::

::: exercise 小论文：形式的债务 {level=3}
写六百至一千字：“骈文与律赋都是**戴着镣铐跳舞**，但镣铐有时也是舞的一部分”——结合本课一项制度（科举律赋、四六表启、外交骈文任一），论**形式约束如何反向生产内容**（被迫的含蓄、被迫的凝练、被迫的双关）；并回应：**“言之无文，行而不远”与“辞达而已”的古老拉锯，今天轮到哪一边？**
::: solution
判分点：机制例具体（谢恩表启：**必须说体面的假话时，用典=免骂护城河**——“**形式是弱势者的修辞铠甲**”一类论证达标）；“被迫的生产”写出路径（限韵逼出巧思——**律赋家法即后世“同题竞赛”的祖宗**）；拉锯给立场不骑墙（“辞达”是理想，“言之无文”是现实——**结论可为：每个时代的“达”都欠形式的债，区别只在利率**）；若引“**繁采寡情，味之必厌**”（《文心雕龙·情采》）——**骈文理论自带反形式主义警铃：能引它反骈文流弊，即满分**。
:::

::: summary
双璧展厅结账：对（四行谱＋**正反对的势能差**）、声（四六是外衣，句末平仄是骨骼——律诗的脐带在此剪断）、典（权威转账＋水中着盐）、赋三变身（隐语→帝国工程→内心独白；律赋加镣、文赋拆镣）；政治层一句：**对称是语言化的朝仪**。方法一句话：**读骈文查势能差，读赋查“铺”的去向——铺完之后给了谁**。下一章进入注疏车间：一部经如何被注、疏、集解层层包装——中国传统读书人的“深度阅读”基础设施。
:::
