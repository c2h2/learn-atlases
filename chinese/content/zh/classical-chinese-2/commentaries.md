同一部《论语》，你可以买到两小时读完的“速读”，也可以撞上八十万字的清人正义——**中间隔着两千年的出版业**。上一章学了“书里写什么”，这一章学“**书是从哪条生产线下来的**”：目录、版本、选本三张出厂单，读懂它们，你买到的注本才不会是精装的坑。

## 三张出厂单 {#def-changdan}

::: definition 目录：学术的导游词 {#def-mulu}
**《汉书·艺文志》**开创——刘歆《七略》的官方简历（**六艺、诸子、诗赋、兵书、术数、方技**六分法——**一张公元前 1 世纪的学科地图**）；**《隋书·经籍志》**定下**经史子集**四分框架，此后一千四百年中国书都住这四间房；集大成者**《四库全书总目》**：每部有一百字解题，**每类前有一篇小序论学术流别**——**类序就是导游词**：“**预知某类学术史，先读某类小序**”（鲁迅、张之洞都开过“先读《总目》几篇”的书单——**四库总目是近代以前最好用的学科入门**，张之洞《**书目答问**》即它的晚清通俗版）。用目录学的三个动作：**查一部书的户口**（著录与否、归哪类——**归类本身就是学术判决**：《水浒传》进不进集部？子部小说家？）、**查一个时代的阅读清单**（《艺文志》存汉人书桌、《经籍志》存隋人书架）、**查一种学问的家底**（经部十类的分合=经学史的断层线）。
:::

::: definition 版本：书的家族史 {#def-banben}
古籍四大流水线：**写本**（唐以前主流，**每抄一遍＝生一次孩子**）、**刻本**（唐末五代雕版普及，宋元明清递修——书第一次可以“复印”**）、**活字**（北宋毕昇——**印刷业的活字在清代才追上木刻的市占**）、**影印与排印**（20 世纪——**善本从藏家密室走进书桌**）。**善本三义：古、罕、精**——不一定宋元才叫善，**校勘精审的清刻也是善本**。**《红楼梦》教材案例**：抄本系统（“**脂本**”，现存十余种，多题《石头记》，**带脂砚斋批语——读者与作者同屋的时代痕迹**）与印本系统（程伟元、高鹗整理的程甲本、程乙本——1791 起一百二十回排印**）两系对读——**“原貌”在抄与刻的两次转世之间**；**版本学第一定律：越晚的刻本越整齐，越可能离作者越远；越早的抄本越毛糙，越可能保留口误**。
:::

::: definition 选本：选家的私人课堂 {#def-xuanben}
**总集**与**选本**两分：《文选》（**萧统编——中国第一部文学选本**：经史子不选，“文学”的边界由它绘制，**收录标准见《文选序》**）之后，选本就是**文学史的私人判决**：**《古文观止》**（康熙间**吴楚材、吴调侯**叔侄的塾本——**两百年间“古文”的国民课程表，桐城家的口味借蒙学通行**）、《唐诗三百首》（**“熟唐诗三百首，不会作诗也会吟”——俗谚的底座就是它**）——**选本让读者以为在读唐诗，其实在上选家的课**。辨选本三问：**选了谁**（经典名单的再生产）、**没选谁**（沉默比选文更响——**《文选》于陶诗仅录数首、《诗品》置之中品：“隐逸诗人之宗”的加冕在宋以后**）、**怎么评**（批语=课堂实录；《文选》学内部**李善注与五臣注的千年之争——“李善注富，五臣注通”：注本之间也在选课**）。
:::

::: example 选本公案：《登鹳雀楼》 {#ex-guanque}
“白日依山尽，一首二十字，**作者栏却有两张工牌**：《文苑英华》等总集系统列**朱斌**（或作朱佐日），《唐诗归》《唐诗三百首》以降通行本署**王之涣**。请用本课三张出厂单裁决：这算不算“伪作”？教科书该署谁？写一份二百字“版本裁决书”。
::: solution
**裁决书示范**：**一查户口**：《文苑英华》等宋人总集与《乐府诗集》诸书各自著录，**署名分歧自宋已然，非清人突发奇想****；**二查家族**：二十字绝句入乐传唱——**乐工“各选所长”是署名漂移的温床**（同一首诗像《渭城曲》一样属于“演出市场”，而不是“文集作者”）；**三查课堂**：《唐诗三百首》之后“王之涣”赢，赢在**选本权力**而非校勘结论——**署名是传播史的判决，不是创作权的终审**。结论：**不算伪作，算“共有财产的历史”**；教科书署王之涣可，**脚注里必须还朱斌一张工牌**——**版本学的礼貌：把分歧写进注里，把选择交给读者**。判分：裁决书三查齐全、有一处“存疑”用词即过；金句：**署名是选本与刻本盖的钢印——钢印会锈，底片还在**。
:::
:::

::: intuition 买注本三步：前言、凡例、校记 {#int-mai}
**第一步读前言**：看选注者**有没有目录意识**——他引不引《总目》、提不提版本、道不道学术史？**前言是一本书的学历展示**。第二步读凡例：**“本书以某本为底本，以某几本校本”——有没有底本意识**（无底本可谈，等于报告没有方法）；**注释体例**（“某，某也”的简注 vs 引旧注的繁注——**繁简无高下，有无标准才有**）。第三步抽查**校记**：校记是版本学的现场直播——“**某字，某本作某，今不从**”；**一本无校记的古籍整理本，是把舞台戏改成电影还删了片尾字幕**。**排座次口诀**：**一校（有无校勘记）、二据（引据是否具体到版本名）、三兼（注家是否“独尊一家”还是“广采众说，下己意”——清人注经的荣誉守则）**；至于**封面腰封上的“权威”“定本”**——**“定本”是版本学里的脏话：它假装校勘已经死了**（而顾广圻“**不校校之**”的精神在此：**最好的校勘是**让读者看见不校的风险**）。
:::

::: history 从校书郎到数据库 {#sec-jiaoxi}
**汉**：刘向、歆父子**校秘书**——“**一人备书本，一人持读**”的对校作业（《管子》《晏子春秋》等叙录存其程序——**校勘学的出生证明**）、《七略》“**条其篇目，撮其指意**”（《汉志》总序——**目录学的出生证明**）；**宋**：**雕版＋科举＝书籍社会**（岳珂**相台书塾**刻书以校勘精审名世——**家刻本的荣誉战**）、尤袤《**遂初堂书目》**于书名之下**注别本、校本**（**版本著录的创举**——书目第一次记录“同一本书的不同样子”）；**清**：**版本目录学成专学**——黄丕烈“**佞宋**”（每得宋本祭告、影刻——**版本崇拜与版本科学同时诞生**）、顾广圻主“**不校校之**”——不轻改字、保留旧貌：**校勘的谦逊原则**；阮元《**十三经注疏校勘记**》——**集部工程级的版本普查**；《四库全书总目》成书（1782）——**官修目录的封顶**；**民国**：《**四部丛刊**》（1922）以**影印宋元旧本**化身千百——**“赝本”的反义词是复印件**；**1958—1978**：**点校本“二十四史”**——**古籍进入国家标准工时**（通行本从此有了“当代善本”的集体身份）；**当代**：籍合网/中华经典古籍库、CADAL、各地**数字方志与全文库**——**“凡例”变成检索式，校记变成版本比对插件**；新的稀缺不再是书，是**会读校记的眼睛**。
:::

::: warning 用注本四坑
**唯厚不选**（“注释八百页一定权威”——**厚可能是转抄旧注的水墙**，看凡例是否说明自家贡献）；**唯古不选**（“民国线装必好”——**影印宋本也有宋代的讹字**，古是身价不是结论）；**跳过校记**（“反正我又不做研究”——**校记恰好告诉你的，是这首诗本来可以不是这样**——文学的不确定性是免费的）；**把底本当原作**（“我读的是《红楼梦》”——**你读的是一部具体的抄本/印本，带着它的错字、改笔与删节**——读经典=读它的**一个版本**，这个自觉比任何注都值钱）。
:::

::: exercise 户口普查 {level=1}
为《论语》《世说新语》《西厢记》各查一次“目录户口”（《汉志》/《隋志》/《四库总目》相应著录与归类），比较同一部书在不同时代目录里的归类变动，写 150 字“户口的判决”小论文。
::: solution
参考：《论语》：《汉志》入六艺略、《隋志》入经部论语类；《西厢记》：正册几无它的位置——《四库》仅于集部**词曲类**收杂剧且多存目（《四库》存目与禁毁之间——**杂剧不入正统的歧视链**——四库不录小说戏曲之故实）。判分：**归类变动必须解释到观念层**（“曲”从教坊到案头到文学史正殿的迁徙=**文体等级的政变**）；引用目录须标类名——**目录学实操：类名比书名更难造假**。
:::

::: exercise 三查裁决书 {level=2}
自选一桩唐诗署名或异文公案（如杜牧《山行》“白云生处／深处”之异），按“查户口—查家族—查课堂”写二百字裁决书，注明所用工具。
::: solution
判分：三查齐全且**各有一条出处**（工具不限：中国基本古籍库、《四库总目》、任意权威校注本）；**结论用“更可能/证据不足”而非“就是”**——裁决书的语体是法官不是粉丝；“白云生处/深处”案要点：生=动态生发、深=空间幽远——**异文不是错，是两个朝代的眼睛**（若你能各找出一个支持它的唐诗用例——加分到飞起）。
:::
:::

::: exercise 小论文：复印件时代的原本 {level=3}
写六百至一千字：“影印与数据库让《红楼梦》的每个抄本都‘化身千百’——**原本的概念还存在吗**”——须调用本课一项史实（脂本/程本、四部丛刊、点校本二十四史、CBDB 任一），论**复制技术如何改写‘权威文本’的生产**；并类比一项当代经验（扫描版论文、共享云文档版本历史、AI 校勘插件任一）。
::: solution
判分点：史实调用准确（影印“**化身千百**”同时带来**新独裁**——最方便的影印本变成新的通行原本——**复制技术的民主与垄断同时交货**）；“原本”概念给出立场（可以答“**文本的本来状态是一条河流，校勘是取水样**”——但须为此比喻付论证）；类比须对齐机制（云文档版本历史=校勘记的平民化——**谁改的、改于何时、原版是否可回滚**三问同构）；结论若落到“**我们读的从来不是原作，是原作的一个有日期的状态**”，即 A——这句话的债，下一章版本实操课还。
:::

::: summary
出厂检验结账：目录（六略→四部→《总目》类序；**归类就是判决**）、版本（抄刻印三流水线；**越整齐越远、越毛糙越近**第一定律；“定本”是脏话）、选本（《文选》划文学边界、《观止》排国民课表、**沉默比选文更响**）、验货（一校二据三兼；前言=学历展示，校记=现场直播）。方法一句话：**读任何注本之前，先读它的凡例；信任何文本之前，先问它的版本**。下一章把三样工具合起来用：选一部注本，完整读一遍——注疏课的“期末项目”。
:::
