文言Ⅱ读到这里，绊住你的往往已经不是语法，而是**世界观配置**：月份有月份的官名，星星有星星的编制，当官有当官的动词变位。本章发你四张地图：**天、地、官、时**——读完它们，古书里的世界从布景变回实景。

## 天上有编制 {#sec-tian}

::: definition 二十八宿、十二次与“七月流火” {#def-tian}
**二十八宿**＝月亮旅馆一条街（月亮约一天一宿，一月周天；四方各七宿，**苍龙、朱雀、白虎、玄武**四个“宿舍区”即四象）——“**月离于毕，俾滂沱矣**”（《诗经·渐渐之石》：月亮附着毕宿，大雨将至——**星与雨的朴素气象站**）。**十二次与分野**：黄道十二个路牌（星纪、玄枵……寿星、大火、析木），再与地上的州国一一配对（**“星分翼轸，地接衡庐”**——王勃一句占尽天文地理）——**天上的行政区划**：客星、彗孛、日食都按分野读成地方消息，**星变即警报，天象即舆情**。 **“七月流火”**：火=**心宿二（大火星）**，“流”**不是热到流动，是西斜下沉**——“**七月流火，九月授衣**”讲**暑退将凉**（授衣=备冬，**句子自己就是证物**），被误用成“天气火热”是千年冤案；《尚书·尧典》“**日中星鸟，以殷仲春**”——昼夜平分、鸟宿中天，**用星星确定春分，上古观象台写在经书里**。
:::

## 地上有别名 {#def-di}

::: definition 九州、江河与“江左” {#def-jiuzhou}
**九州两版**：《禹贡》用“**X惟Y**”句式划界（“**济河惟兖州**”“**华阳黑水惟梁州**”——地理散文的尺规作图）；《尔雅·释地》另列一版——**两版州名有出入，古书见州名先问“哪一版九州”**（用州名如引用地图版本，**版本错了全图皆错**）。**江河专名史**：“江”“河”上古专指**长江、黄河**（“**将军战河北，臣战河南**”——河=黄河；今“江河”已是通名——**通名⇄专名的引申案例**，见[[classical-chinese-2/original-meanings]]）。**水域方位词**：**江表**（自朝廷视之，长江之外——孙吴的官方视角）、**江左＝江东**（古地图**坐北朝南**，左东右西——**“江左风流”即东晋南朝的自我想象**）。**山东山西**以崤山、华山为轴，**不是省界**；**中国—中原—海内—天下**是四圈同心圆——**每圈都是一份政治宣称**。
:::

## 官有动词变位 {#def-guan}

::: definition 官有动词变位 {#def-zhiguan}
**骨架速览**：秦汉**三公九卿**（丞相—太尉—御史大夫；九卿大量管皇室私务——**家国一体的活化石**）→隋唐**三省六部**（中书拟旨、门下封驳、尚书执行；吏户礼兵刑工=用到清末的行政模块）→宋**两府三司**（中书门下掌政、枢密院掌兵、三司掌财——**把相权切成三块**）→明废丞相入**内阁**，清**军机处**（**跪着受笔录旨的班子＝皇权的最后形状**）。**任免动词变位表**：**拜**（“**拜相如为上大夫**”）、**除／授**（除=除去旧职就新任）、**辟／征**（长官自聘曰辟，皇帝特聘布衣曰征）、**迁**（默认**升**迁——“**再迁为太史令**”）、**转／徙**（平调）、**出**（京官外放）、**左迁／放／窜／逐**（降谪：**“左”就是贬**——“**一封朝奏九重天，夕贬潮阳路八千**”）、**罢／免／黜／废／夺**（去职与剥夺）、**致仕**（退休的正式名）＋**乞骸骨**（“让这把老骨头归乡”——**退休申请书的身体修辞**）。**级别黑话**：汉人径以俸禄级代官职——郡守称“**二千石**”——**工资条变成绰号**。
:::

::: example 一句日期解剖刀 {#ex-riqi}
拆三例日期：①《赤壁赋》“**壬戌之秋，七月既望**”与同篇“**徘徊于斗牛之间**”；②《后赤壁赋》“**是岁，十月之望**”；③《兰亭集序》“**永和九年，岁在癸丑，暮春之初**”。问：各句给出哪些历法层？各缺哪层？“既望”是哪天？“暮春”为什么不直写“三月”？
::: solution
**①**：干支纪**年**（壬戌——**干支年不自带公元，须借帝王纪年换算**）＋**序数月**（夏历七月）＋“**既望＝望日之后，通常十六日**”（望=十五，既=已过；同族词：**朏**=初三前后的新月，**魄**=十六后的亏光——**上古用月亮记账，日期自带月相图**）；“徘徊于斗牛之间”：月在斗宿、牛宿之间移行——**苏轼报时用的是天钟，夜景即星历**。②“是岁，十月之望”：**“是岁”回指前篇纪年——两篇赤壁共用一个坐标系**；十月十五，孟冬望日——**后赋的“月白风清”由日期签发**。③“永和九年，岁在癸丑，暮春之初”：**年号＋当年干支＋季节节**三层齐备——**东汉以后中国日期的标准格式**；“暮春”不写“三月”，用**季节切片词**（春三月的下旬），还自带《论语》“**暮春者，春服既成**”的典故滤镜——**历法词一旦进入经典，就永远多带一层情绪**。缺层提醒：三例都不记**时辰**——**史书才精确到时辰，文人随兴省略；编年体与抒情文的时钟精度不同**。
:::
:::

::: intuition 常识是跨线验证器 {#int-yanzheng}
文化常识的真正用法不是查字典，是**四线交叉验证**：一句话里的天文（星宿、月相）、历法（年号、朔望）、职官（官名的出生年代）、地理（政区沿革）必须**同时成立**——任何一线对不上，要么你解错了，要么**书有问题**。这正是阎若璩拆穿伪《古文尚书》的法庭逻辑：**语言内证**（虚词课的“市买”案，[[classical-chinese-2/particles]]）**＋职官、地名、历法的时代错位，四线合围——辨伪学的满汉全席**；王国维“二重证据”是同一原理的考古学版。副产品一条戒律：**常识不作孤证**——“七月流火”字面证据再硬，也要与全篇物候（“九月授衣”“八月载绩”）互勘；**常识的尽头仍是语境核对，不是记忆炫技**。
:::

::: history 常识的教科书史 {#sec-jiaoke}
**先秦**：常识长在制度与诗歌里（《七月》是农事历，《月令》是政府行事表——**生活即知识，本不需要“常识”这门课**）；**汉**：《**尔雅**》“释天”“释宫”“释器”“释乐”——**第一次把世界编成类目**；《释名》按义类分篇（州国、山水、饮食、服术——**分类学即世界观**）；**唐**：《**艺文类聚**》（624 年敕撰）——**事类在前、诗文在后的“唐代搜索引擎”**；**宋**：《**太平御览**》一千卷（四大类书之一）；**明**：《**三才图会**》（天文、地理、人事三才分部）——**左图右史的图像百科**；**清**：《**古今图书集成**》（1726 年成书）六汇编三十二典——**纸上数据库的极限**；**民国**：新式教科书的“本国文化”单元——**常识从类书变成公民课**；**当代**：**“中国历代人物传记资料库”（CBDB）**把数十万历史人物的官历、亲属、交游连成关系网——**常识研究从查词条进化成跑图谱**。
:::

::: warning 常识四坑
**“七月流火”式反向误用**（拿古语装今热——**引用前先查原句的物候证词**）；**以今地名度古疆域**（见“河南”就画省界——**“河南”在《项羽本纪》是河之南**；政区沿革是动态图层，须换“历史地图”底图）；**官名跨代通用**（拿“尚书令”当秦官——**每个官名都有自己的出生年月**，见[[classical-chinese-2/ancient-culture]]本表骨架）；**把常识当结论**（星宿对应分野**不是**天文学而是政治符号学——**常识告诉你“这是什么”，还要追问“谁用它、骗谁、为什么灵”**——不然你就只是把古人的世界观背成了你的世界观）。
:::

::: exercise 别名连连看 {level=1}
匹配四组并各造一个**用错语境**的反例：江左／江东、桑榆／暮年、桑梓／故乡、杜康／酒。
::: solution
判分：四组对应无误（**“桑榆”非植物志——“失之东隅，收之桑榆”与“日暮桑榆”两处互证**——上一章“与”字家谱法在此复用：**词的地图要画两遍才牢**）；反例诚实（最常见翻车：桑梓当园林、杜康当人名用错格——**别名是缩句，用错等于背错课文**）。
:::
:::

::: exercise 跨线验证官 {level=2}
自造或从文集里找一句含**两层以上**文化信息的日期/官职句（如“**元和十年，予左迁九江郡司马**”——白居易《琵琶行》序✓），拆出：年号层、职官层、地理层各自指向的公元/今地；再用任一工具（年表、《中国历史地图集》）复核，注明查核过程。
::: solution
参考案：“元和十年”=815（宪宗年号，查《中国历史纪年表》）；“左迁”=贬官；“九江郡司马”=员外散职（唐州郡官制：司马多安置罪官——**“江州司马”从此成为贬官的文学代号**——青衫泪的编制背景）。判分：**三层各有出处**；允许误差（郡名沿革之乱须标注存疑——**“查不到”也是合格的验证报告**）。
:::

::: exercise 小论文：古人的天空 {level=3}
写六百至一千字：“分野、星占、祥瑞是古人的**政治传播系统**，不是迷信残余”——以一次天象记载（日食、彗星、客星任一；示例：《春秋》经“**秋七月，有星孛入于北斗**”——鲁文公十四年（前 613）的彗星记录，被视为哈雷彗星早期观测之一）为例，分析**天象如何被读出、上奏、回应（避殿、减膳、诏求直言）**；并对照现代社会的同类机制（民调、卫星云图、经济数据），论**“权威读数”的媒介依赖**。
::: solution
判分点：经例准确（《春秋》经鲁文公十四年=前 613，“孛”=彗星——**世界上最早的哈雷彗星记录之一**，“之一”的限定语可保留）；机制完整（**天象→灾异话语→皇帝下诏/避正殿→求直言**的闭环，写清“天”是反对派的**终审法院**）；现代类比成理（权威读数依赖仪器/经典/模型——**谁掌握仪表，谁定义天意/数据**）；结论若能落在“**读古书的天，也是在读写天的人**”，即 A。
:::

::: summary
地图课结账：天（旅馆·路牌·分野＋“七月流火”翻案＋月相时态）、地（两版九州、江河专名沉浮、坐北朝南的“左东”、四圈天下）、官（家国活化石→跪着受旨的收束线；动词变位表＋“二千石”绰号法）、时（年号＋干支＋序数＋月相的标准格式，时辰看场合）。方法一句话：**四线跨线验证，孤证不立；常识负责“是什么”，你还得问“谁在用”**。下一章学读注本的“元能力”：把注疏当文体读——目录、版本、学术史的导航课。
:::
