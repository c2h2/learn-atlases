---
title: "文言同义词"
---

上一章说一词多义是网，这一章看它的孪生现象：**一义多词**。文言的可怕不在生词多，而在**熟词太像**——五个“看”、六个“到”、八层“死”，用错一个不是语病，是**僭越**。同义词林里住着三种居民：**方言的移民、语体的住户、礼制的编户**。

## 义场地图 {#sec-yichang}

::: definition 感官动词场：五个“看”的岗位 {#def-ganguan}
**视**＝通用款“看”，随上下文兼岗（“视其辙乱”是检查，“孰视之”是端详））；**瞻**＝抬头看（《诗经》“**瞻望弗及，泣涕如雨**”——瞻仰永不低头）；**望**＝向远看兼向后期许（望月、望幸——等待是望的形容词化）；**观**＝带目的带方法的看（观兵、观政、“观乎天文”——**观察、观摩、观念全是它的编制**）；**见**＝视线到达的戳章（看且有着——《说苑》“**见善如不及**”的见是战果）；再加**睹**（目验为实）、**睐**（斜眼含情，“明眸善睐”）、**睨**（侧目不屑——蔺相如“睨”柱，抱玉斜瞪柱子，随时准备碰瓷给秦王看）。一套动作被切成三根轴：**方向（瞻/望/睐睨）、意图（观/视）、结果（见/睹）**——这就叫**义场**：**同义词不抢同一个义，只分同一间办公室的工位**。
:::

::: definition 时间名词场：一天的班次表 {#def-shijian}
**朝／旦**（天亮打卡：“朝闻道”“旦日飨士卒”——旦是日出地平线的一横）；**中日／昃**（“**日中不至，则是无信**”——元方之怒精确到班次；昃是日过午而斜，**字形就是太阳下班的姿势**）；**昳／晡／哺**（午后到申时的几个班次，奏报里的“日昳”“晡时”皆是钟点代号）；**日入／夕／莫**（《诗经》“**日之夕矣，羊牛下来**”——夕半明，**莫＝日落草中，即“暮”的本字**；莫被否定词借走，暮字加班接班——**古今字上夜班**）；**昏**（日入于土，**“婚”从“昏”——婚礼本是黄昏的事**，亲迎的钟点化石）。再叠上三张历法表：**干支纪日、五更纪夜、朔朏望晦纪月相**——读日记体的奏疏先对表：**“夜分”“未旦”“既望”都是班次代号，不是形容词**。
:::

::: definition 同义之所以存在的三个户口 {#def-sange}
**①方言转写**：扬雄《方言》记“**党、晓、哲，知也。楚谓之党，或曰晓；齐宋之间谓之哲**”——三个“知道”从三个方言区移民进同一部书；又“**嫁、逝、徂、适，往也**”一条，把“往”的各地说法（逝，往也，楚语；徂，齐语——大校）像标本一样钉在卷面上：**写文章的人从雅言与方言里挑货，选词即选口音**。**②语体与节奏**：“之、如、适”同是“到……去”（“吾欲之南海”“子之武城”“适千里者，三月聚粮”——《庄子》的“适”后来还活在“适意”的旧壳里），择一而从常常是为**平仄与字数**打工：五言要一个轻的“之”，七言才给一个沉的“适”。**③礼制编户**：《礼记·曲礼》的死亡等级表——“**天子死曰崩，诸侯曰薨，大夫曰卒，士曰不禄，庶人曰死**”——五个“死”不是五个词，是**五道身份条码**；再叠加**避讳**的强制改道（改字、缺笔、空位三术），同义词库于是成了**制度史的点名册**。
:::

::: example “去”的政变与“购”的杀气 {#ex-qu}
解释加粗词，并裁决其“古今户口”：①“逝将**去**女，适彼乐土”；②“一狼径**去**”；③唐宋笔记里的“**去**岁”“**去**处”；④“吾闻汉**购**我头千金”（《史记·项羽本纪》）；⑤“燕王**买**马”（《战国策·燕策一》）。
::: solution
**“去”案**：①《诗经·硕鼠》“逝将去女”=我将**离开**你——古义的“去”是**告别站台**，不是**奔赴目的地**；②《狼》“一狼径去”=径直**走开**——蒲松龄用仿古笔法（**文言是历代人的复古 cosplay，考场里的“去”按先秦户口查**）；③唐宋口语层的“去”已转向“前往”（“去处”）——**一场持续两千年的词义政变，古义残党至今卡在成语与口语的楼里**。判分金句：**“去”的古今义恰是相反方向——最危险的熟词是熟而不知的反义平移**。“购”案：秦汉的“购”是**重金悬赏**（④句“购我头千金”即项羽那边开出的悬赏价），买才是通用款（⑤“买马且五百金”——买是市价，购是赏格）——把“购”译成“购买”，丢了**国家定价的杀气**。“直=值”附案：**古今字**（价直→价值），不是通假——通假无本义血缘，古今字同出一门（族谱法见[[classical-chinese-2/original-meanings]]）。
:::
:::

::: intuition 同义词是礼，也是音乐 {#def-liyin}
两条直觉带进文本：**礼的直觉**——见到同义套换先问“**身份、场合、避讳**”三件事：为什么这篇碑文用“殂”不用“死”（《出师表》“先帝创业未半而中道崩殂”——先帝只能崩，亮曰“殂”是变奏的敬辞）；为什么这个字缺末笔（避讳的指纹，断代的免费午餐）。**乐的直觉**——同义连文常为**双音节节奏**服务（“追亡逐北”“**殚其地之出，竭其庐之入**”——殚/竭同义对举，出/入反义对举，一句里两种对称）；**对文见义**是最省力的字典：处于对举位的两个位置对等的词，**意义要么同类要么相反**——“**贤不肖**”=贤与不肖，“**存亡之秋**”的存亡对举即生死之秋（**“亡”在“存亡”里保留“灭亡”义，“存”保留“活”义——对举让两个词互相释义**）。读不懂某个词时，**看它对面站的是谁**。
:::

::: history 同义词研究的一条长队 {#sec-duichang}
**先秦**：《尔雅·释诂》开编——“**林、烝、天、帝、皇、王、后、辟、公、侯，君也**”，把十一个方言与时代的“头面人物”通兑成一个“君”字——**人类第一部同义词典的兑付方式简单粗暴**，但它给经师发了“古今语对照表”；**汉**：扬雄《**方言**》实地采访“异地同词”，许慎《说文》的说解语言本身是一套**受控同义词网络**（“老，考也；考，老也”——互训就是同义词的结婚登记）；**唐·孔颖达**疏中常用“**浑言、析言**”的分别段玉裁把注疏经验概括成“**浑言则……析言则……**”的公式——“鸟”“隹”浑言皆禽，析言则尾长短有分；**清·段玉裁**把“浑言/析言”升级成方法论（《说文注》处处“**浑言析言**”对举——**同义词研究第一次有了显微镜刻度**）；**现代**：语义学给同义词上**义素表**：同义词表、义素分析（【±人】【±敬】打表排比——“崩薨卒死”的礼制坐标用特征开关表达）；**当代**：语料库给同义词发**频率秤**（“视/看”的换班时间、历史词典的义项消长曲线）——**《尔雅》的通兑柜台式同义词表，进化成了动态汇率表**。
:::

::: warning 同义四雷
**雷一“古今对译”**：见“去”就译“到”，见“购”就译“买”——**熟词的平移比生词更危险**（方向相反的案例就在上一章末尾与本章例题）；**雷二“同义=可换”**：把“崩”改成“死”不违法但**改史**（礼制词是条码不是修辞）；**雷三“对举必反义”**：见“A B”就拆反义古汉语“衣服、饮食”对举多是同义连文——**不是每个 AB 都是“出入”“存亡”**；**雷四“避讳过度”**：见缺笔就断代（仿本也学缺笔——**避讳是证据不是证词**，须与纸墨纸背的书志合供）。
:::

::: exercise 岗位说明书 {level=1}
为“之、如、适、诣、造”五个“到”字家族成员各写一张岗位说明书（本义、常见宾语、语体档位、一个书证），再解释为何《论语》说“子之武城”不说“子诣武城”。
::: solution
判分：**诣**带“拜见尊长/官府”的敬辞档（“及郡下，诣太守”）、**造**有“造门、造阙”的登门实感兼“造诣”引申（“《论语》“君子无终食之间违仁，造次必于是”的“造次”另有义项——**同字不同户口，不乱连线**）、**如**在“子之武城”是轻量平仄款；“诣”太重——孔夫子上任不是递名片。
:::
:::

::: exercise 避讳侦探 {level=2}
找三例避讳改字并断代：提示案——汉文帝讳**恒**（恒山作“常山”）、汉高祖讳**邦**（“邦”改“国”入汉籍）、唐太宗讳**世民**（“民”缺末笔——唐碑的免费断代码）、清圣祖讳**玄烨**（玄→元、烨缺笔）。说明“避本朝、不避前代”的断代规则与它的边界。
::: solution
判分：三例的“讳—改—代”对应无误（恒→常=汉文帝刘恒，玄→元=清圣祖玄烨——**常山、元烨类案是教科书级指纹**）；规则讲清：**只避当朝及近亲先帝（二名不偏讳、诗书不讳等细则注明版本）**；诚实声明：**改字仿刻可作伪——避讳为旁证，不作孤证**。
:::
:::

::: exercise 小论文：同义词的政治 {level=3}
写六百至一千字：“一组同义词的兴亡，就是一部微缩政治史”——任选一组（崩薨卒死／征伐侵／陛下殿下足下执事的称呼降格／“杀诛殂毙”的及物与避尊），论证**词的选择如何暴露身份、立场与时代**，并回答：**现代汉语里你正在做的“同义选词”被什么约束（礼貌？流量？审查？）**。
::: solution
判分点：组内成员的**原始使用域**写准（“征、伐、侵”的界说**古书异说**——《周礼》《司马法》各家有出入，不硬裁；能写出“告兵与不告、上击下的语感差异”这一通说核心并声明分歧即可）；“陛下/殿下/足下”的**称呼降格链**（从“不敢直指，呼其下者传意”——**敬辞的语义学就是距离学**）；现代对照落到机制（“去世/死亡/走了/没了”的场合分配＝**现代礼制**）；结论若能指出“**词典同义，语用不等**”，即 A。
:::
:::

::: summary
同义林结账：义场三轴（方向/意图/结果——工位而非竞争）、三户口（方言移民/语体节奏/礼制编户）、避讳三术与断代指纹、对文见义（看对面站的是谁）、熟词平移的雷（去、购两案在卷）。方法一句话：**词典同义，语用不等——同义词是穿着同款制服的不同部门**。下一章拆称呼系统：名、字、号、谥、庙讳与“卿、君、公、足下”的谦敬矩阵——古人的人际导航系统。
:::
