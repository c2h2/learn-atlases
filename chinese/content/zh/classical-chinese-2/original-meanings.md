title: "本义与引申"
---

上一门课教你把句子读通，这一门课教你把**一个字读厚**。字典里“一”字列到第八个义项不是编纂员无聊——是一个义位两千年攒人头的历史。本章发你三样工具：**本义的探照灯、引申的族谱学、假借的照妖镜**。

## 一词之家世 {#def-jiazu}

::: definition 本义、基本义、引申义 {#def-benyi}
**本义**=字形所能证明的最古词义——注意限定词：**字形能证明**，所以它是“构形义＋文献佐证”的双重产物（“为”的甲骨文作手牵象服役之形，许慎未见甲文而说解失实——**《说文》是最大的一部本义辞典，也是最大的一部待校勘的本义辞典**）；**基本义**=一个时代词频与义用的枢纽（“兵”构形从斤持戈，本义兵器，而战国文献的基本义已偏向士卒与军事——**本义考古的，基本义活人用的**）；**引申义**=从枢纽义放射出的新义位，三大放射途径：**接近**（兵→兵器→持兵器的人→战争）、**类似**（“綱”网的大绳→事物的总要→“纲纪”的动词化）、**对比连带**（“臭”本兼指香臭——“其臭如兰”——后来专吃秽义：**词义会偏食缩水**）。训练有素的头脑里，多义词不是一张义项表，是一棵**带根须的树**：查义先找根，派义看枝向。
:::

::: definition 引申的常规方向 {#def-fangxiang}
引申不长野路子，它有可数的几条“向光性”：**具体→抽象**（“道”道路→方法→学说；“理”治玉见纹→条理→天理）；**施受同辞**（“受”甲骨文兼授、受二事——一笔交易的两头起初共用一个词；“贷、借、假”同此纠缠）；**物→动作→施事**（“盖”本义苫也——草编覆盖物→覆盖→压倒）；**通名⇄专名**（“江河”由长江、黄河的专名熬成水的通名——**引申的方向史半部是汉语的名物史**）。方向感比义项表值钱：生词撞脸时，你能猜对它**从哪儿来、往哪儿去**。
:::

::: example “与”字家谱 {#ex-yu}
为“與（与）”字修族谱。《说文》以“一施一”说“與”——**给予是它的义枢**。从“给予”出发，把下列七例归进义位并标出引申途径：①“与之斗卮酒”；②“与嬴而不助五国”；③“失其所与，不知”；④“吾非斯人之徒与而谁与”；⑤“吾与汝毕力平险”；⑥“无乃尔是过与”；⑦“与闻国政”。

::: solution
族谱判决：**①给予=枢纽义**（活着的动词根）；**②亲附**=给予的抽象化（把好感甚至国运送出去——秦“与嬴”即此枝）；**③同盟者**=动作→角色（“所与”=给予的对象，凝成名词——“失其所与”）；**④偕同·赞同双枝共舞**（“徒与而谁与”＝与谁偕从——**同一“与”字兼挑偕同与赞同两枝，译笔只好都收**）；**⑤与=和（介词）**=偕同的再虚化（伴随→并列标记——**语法化的标准台阶：动词＞介词＞连词**，“共、同”同梯）；**⑥语气词**=假借（与“歟”通——**音同借字，与家谱无关，另立户口**）；**⑦参与**=“介入其间”义的反衍，辞书列作义项延伸，我们按辞书。族谱总图：**给予—（抽象）亲附—（角色）同盟者｜给予—（伴随）偕同—（虚化）介连词｜偕同—（介入）参与‖ 歟=借字外挂**。判分：画出五枝一借即及格；**发现④的双枝共舞为优**。
:::
:::

::: intuition 词义是网状，字典是抽屉 {#int-wang}
把多义词排成“①②③④”是印刷术的暴政：**义位实际是网，不是队列**——相邻义位互相渗透（“与”的偕同与赞同在一句里同时活着）；旧义退场常留地契（成语是词义化石库：**“走马观花”的走还骑着古义的奔**）。所以查词的正确姿势：**先定位语境义，再回链到枢纽**——像认领走失的宠物，看它像家里哪一位。进阶一层：**引申有产地，也有政变**——“经济”本“经世济民”的压缩枝，近代作了 economy 的对译名，**反被尊为新词的本义：引申可以发生政变，嫁接不是生长**。一词一政变，够你玩味。
:::

::: history 从“看图说字”到“声音穿墙” {#sec-lishi}
**先秦**：《左传》《韩非子》已开**拆字说义**先例（“止戈，武也”——**训诂的第一桶金是政治修辞**）；**汉**：《说文解字》以九千余字立“构形说义”总账（[[chinese-characters/six-categories]]），同代《释名》以**声训**穿墙（“某者某也”——词源学的第一次全国普查，虽然多数结论属**民俗词源**）；**清**：段玉裁立“**本义与引申当知所辨**”的义项纪律（《说文解字注》凡例大意），王念孙《广雅疏证》序昌言**诂训之旨存乎声音**——破字因声，**声训从玄学改装为可复核的方法**；**民国**：语义学入系，“意义”的学问有了教席；**当代**：认知语言学给引申发理论执照（**辐射范畴、链式引申、“家族相似”进中文系课表——“网络不是队列”有了学术户头**），《汉语大字典》《故训汇纂》把两千年义位归档。
:::

::: warning 词义三防
**防“望形生义”**——见字即拆：“道德”今为一个词，先秦是两条腿走路（道与德各有户口）；**双音组合成词有年代学，拆开讲可以，合起来当真要查**。防**“以今律古”**——用今义读古书：衣不读 yì（衣冠禽兽的衣是穿）、雨不读 yù（天雨墙坏的雨是落——**词义与读音同案共审，破音是入场券**）。防**“引申万能”**——逢字找本义再编派：**引申要有文献桥墩**，无书证的枝是私搭乱建；嫁接须声明（“经济”案在案，不可不察）。
:::

::: exercise 义树绘制 {level=1}
为“兵、向、解、理、举、绝”各画一棵本义—引申义树（标注枢纽义、三条向光性、至少一处“文献桥墩”例句），并在任两字之间找一根**同构枝**（不同字的相同引申路径，如“具体→抽象”）。
::: solution
判分：每树有桥墩例句（无书证的枝折掉重画）；两两同构枝命中即理解过关（“理”与“纪”都从**物的纹理**爬到**事的条理**——抽象化是所有词的成年礼）；加分：给“解”指出“解剖—瓦解—懈怠（解邂）”的**音义分手**现象（文字负担过重就分家——古今字的前奏）。
:::
:::

::: exercise 族谱悬案 {level=2}
“信”：①信言不美②愿陛下亲之信之③信义著于四海④烟涛微茫信难求⑤低眉信手续续弹⑥自可断来信。六例定位义位（诚实→相信→确实→随意→使者/媒人——五站），并裁决：⑥是引申还是假借。
::: solution
参考：①诚实（言语真实）②信任③信用（品格名词化）④确实（由“不欺”到“不妄”，副词化）⑤随意、任凭（由“任意”到“随便”——**信手**的活化石）⑥使者/媒人（**任者**——“信”本有“信使”义：符节为信→持凭证的人——**引申走“凭证→持凭证者”的连带路**，非假借）。判分：⑥的裁决须给出**证据路线**（辞书义项＋书证），不许“我觉得”。
:::
:::

::: exercise 小论文：字典的暴政 {level=3}
写六百至一千字：以本章任一多义词为例，论“**义项序列如何伪装成词义本质**”——第一义项的地位是历史（本义考占）还是使用（基本义）给的？现代语文辞书“以音配义、以频排序”的改革动了谁的奶酪？须用“经济/政变”一类**词义嫁接**案例至少一处。
::: solution
判分点：概念区分清楚（本义/基本义/首义项三者不是一回事，且**辞书编排本身是一种训诂立场**）；案例具体（“经济”对译日语译名、反被尊为“本义”的现代常识——**义项表上的篡位实录**）；能引申到方法自觉（查字典的顺序=先查家族再查户口——**义项是抽屉，词义是网**）；结论允许挑衅但须付证据——“**词典该按义频排序还是按历时排序**”这种级别的两难才算入门。
:::
:::

::: summary
义树课结账：本义两重证据（构形＋文献，《说文》兼功与罪）、枢纽义随时代漂移（兵考古的 vs 活人用的）、三条向光性（接近·类似·连带；具体→抽象是成年礼）、假借外挂（音同义异另立户口，与引申分家靠“有无文献桥墩”）、词义会政变与嫁接（经济案）。下一章逛同义词林：为什么“视、瞻、望、见、观”不是五个“看”——**同义是文言最精致的礼制**。
:::
