---
title: "山水诗与永明体"
---

上一章结案陈词说：玄言把象征任务卸掉了，风景才有机会只是风景。本课本章交货——**两件事让中国诗脱胎换骨：题材上，山水取得户主席位；声音上，诗歌装上节拍器**。前者姓谢（两个人），后者姓沈。

## 谢灵运：把山水写成考察报告 {#def-xielingyun}

::: definition 永嘉风物与“池塘春草” {#def-daxie}
**人设**：谢氏顶级门第——**灵运袭封康乐公，自以才能应参机要，却与新朝权贵竞争失利**：**前朝贵族在本朝的错位展览**，**出守既不得志，遂肆意游遨**：登山、伐木、开山通道，**从始宁南山凿山度壑直达临海，太守带随从进山像考察队——地方官的报告惊动朝廷，以为“山贼”**（《宋书》本传——**“山水”第一次以社会新闻的方式进入正史：写山水的人，本身成了山水的丑闻**）。**名句公案**：“**池塘生春草，园柳变鸣禽**”——《诗品》记其梦见族弟惠连、“**此语有神助，非吾语也**”——**后人拆穿天机：全是常用字、零典故、对偶不使劲——“奇”恰恰在“不高明”：当所有人都在炼字，不炼成了最高的炼**（**“庄老告退，山水方滋”的另一半主语，就是他**：灵运的“清”是洗掉玄言的油墨，让景物带着湿度出场）。**结构标本**：他的山水诗标准三段——**记游踪→写物貌→拉一位玄言出来收尾**：**山水诗出生时还包着玄言的襁褓**——断脐带是后代的事（谢朓、何逊、唐人们排队执行）。**“形似”上岗**：《文心·物色》给时代下考语：“**自近代以来，文贵形似，窥情风景之上，钻貌草木之中**”——**描摹本身成了价值**——比德（仁者乐山）退职，**山水从道德的比喻升格为感性的对象**。
:::

::: definition 谢朓与“小诗化” {#def-xietiao}
“**小谢**”（谢朓）相对“大谢”：**去其繁而清其骨**——大谢是长篇考察报告，小谢是**明信片：选景代替全景，气氛代替过程**：“**余霞散成绮，澄江静如练**”（《晚登三山还望京邑》）——**把长江叠成两种纺织品：宇宙级的比喻，配零度的平静；李白一辈子没走出这一联（“解道澄江净如练，令人长忆谢玄晖”）**。**“好诗圆美流转如弹丸”**（《南史》王筠引沈约语）——**诗歌美学第一次把“顺滑”本身列为标准：从“内容对不对”转向“口感好不好”**。《文心》断代总账：“**宋初文咏，体有因革，庄老告退，而山水方滋**”——**注意用词：告退／方滋——不是革命，是交接班**；而**永明体**的当期名号是“**新变**”——**中国文论史上“新变”第一次不是罪名而是型号**。
:::

## 四声八病：节拍器的发明 {#def-shenglv}

::: definition 永明声律学 {#def-yongming}
**技术背景**：周颙**善识声韵**、沈约等“**四声**”说兴——**平上去入**成为诗歌的四个音高档位（**四声≠平仄；但“平”单独成立、“上去入”后来打包为“仄”——近体诗的平仄是四声的合并报表**，[[poetry-metrics]]工厂在此上料）；**原因三条**：**佛经转读**（梵语声高的研究热，沙门与文人同堂）、**辞赋骈句**的自然节拍积累（[[classical-chinese-2/parallel-prose-fu]]的对偶是声律的前身：**字数对齐之后，下一步是音高对齐**）、**门阀沙龙的竞技化**（八斗之才也需要新的赛道）。**纲领**（沈约《宋书·谢灵运传论》）：“**欲使宫羽相变，低昂互节；若前有浮声，则后须切响。一简之内，音韵尽殊；两句之中，轻重悉异**”——**四句话=把诗从“自然押韵”升级为“全程配乐”**。**八病**：平头、上尾、蜂腰、鹤膝、大韵、小韵、旁纽、正纽——**全是“禁止”句式：只说哪种音的组合不许出现，不给你现成模板**；**禁则即采样器**：**把两句十字的全部可能音列中“难听”的那部分剪掉，剩下的可行区域会自动长成形状——那个形状，就是后来的律句**。
:::

::: example 减法如何长成加法：律句的诞生 {#ex-jianfa}
用本课机制完成一道数学题：五言一联十字，每字取平／仄两档（简化模型）：①总组合数？②若禁止“上句五字连仄、下句五字连平”（鹤膝／偏枯类），③再禁止两句对应位置同声（平头类），④再禁止偶句末字与全篇韵脚之外同声拖沓（上尾类）——剩下的“顺耳区域”长什么样？对照：这是什么文体？
::: solution
①**2 的 10 次方＝1024** 种；②—④连做减法后，**高频幸存区高度集中**：上句“**仄仄平平仄**”、下句“**平平仄仄平**”一两类模式反复出现——**因为它们在“禁相邻同调”“禁结尾撞车”“禁头把齐平”三条约束下是唯一能同时满足的最大解族**。**结论：律诗不是谁发明的，是八病的减法减出来的不动点**——沈约们以为自己在列黑名单，**黑名单穷举之日，就是格律显影之时**（所以“永明体未能成律”与“永明体发明了近体”两句都对：**失败的具体清单，成功的抽象算法**）。判分：算出数量级＋说出“不动点”即满分。
:::
:::

::: intuition 声音的政治学 {#int-shengyin}
为什么节拍器恰好在这一百年出现？**因为诗歌的“听众”换了**：汉乐府对街市与宫廷演唱，建安对酒宴，**永明对书斋与案头——当诗从“唱给人听”转为“读给眼听”，声音就从载体变成被管理的对象**（**格律是默读的语法：你脑中那个替你发音的播音员，是永明体的甲方**）。四声说的推手多为**佛门友**——**一场来自诵经声的音韵学，把汉语从“自然的声音”逼成“反思的声音”**（[[phonology/why-phonology]]：音韵学的诞生与诗同源：**先有诗的问，才有韵书的答**）；而**八病的“繁琐”**恰是它的历史功绩：**规则细到荒唐，诗人才能一起喊疼，喊疼的尺度（哪些病必忌、哪些可宽）才是后来律诗的真身**——**格律不是天才的设计，是抱怨的结晶**。
:::

::: history 从“新变”到“沈宋” {#sec-xinbian}
**483—493** 永明：竟陵王**西邸**——**沈约、谢朓、王融、萧衍、萧琛、任昉、陆倕“八友”：沙龙史上第一次把声律当 club 章程**；**490s** 钟嵘《诗品序》讥声病之说使“**文多拘忌，伤其真美**——**同时代人的差评是最硬的证物：病确实存在，药也确实苦**；**梁**：宫体诗（简文帝）——**声律与艳情的合流：新变转向题材的下探，为律诗的“艳”科提供用例**；陈、隋：**阴铿、何逊一路“** 清省 **”——五言律的雏形在南方小诗里成形；**北朝**：**庾信入北（555）——“** 南方温婉＋北方刚劲”的合体实验以流亡为燃料**；**初唐**：**沈佺期、宋之问“回忌声病，约句准篇”——律诗定型，功勋章发给了总结者**；**盛唐**：**杜甫“** 晚节渐于诗律细 **”、反方样本也在场：李白以古体抗律——**格律的统治力，从反对者的存在即可反证**）；**后世**：**“文变染乎世情”（《文心》）——从山水到声律，本单元全是“世情变了，文才不得不”的实例**。
:::

::: warning 读本课四坑
**骂八病“形式主义”**（**他们禁的是“拗口”——在没人反思过汉语声音的时代，把口感立法是科学实验不是宫体癖**）；**把“池塘生春草”读成神迹**（**神助论是诗人自己的公关**：此句的成功条件恰恰是“可学”——学的是“不炼”，而“不炼”的前提是炼到顶）；**以为山水＝自然**（**山水诗是士族的出行方式、庄园经济与“清”品味的合成品：看山是消费行为入诗——灵运的“考察队”就是物质基础；“自然”从来是被发明的观看方式**）；**用唐诗的完成度嘲笑永明的半成品**（**进化论视角的傲慢：八病的“繁琐失败”是律诗的必要工序——你不能嘲笑胚胎没有肺**）。
:::

::: exercise 春草辩护词 {level=1}
“池塘生春草”千古高唱，但一位唐人晚辈冷笑：“此吾家儿童之语也。”**为这句诗写 150 字辩护词**（限用本课两个武器：“不炼之炼”“常用字零典故零对偶”），**再用 50 字替儿童之语反驳**。
::: solution
判分：辩护词须落在**语境价值**（在“俪采百字之偶”的市场里，白描是差异化定价——**诗句的意义一半在它的时代价格表上**，此即[[classical-chinese-2/commentaries]]版本学思维的移用）；反驳也要成立：**“不炼”可被无穷仿写，一旦成为套路，“池塘春草”就降回“儿童之语”——伟大是时代与句子的合谋，单方面不背锅**。
:::
:::

::: exercise 声病体检 {level=2}
给一联自造五言（如“**竹喧归浣女，莲动下渔舟**”——这是王维现成律句，本题要求你**自造**一联合律句＋一联故意犯“平头”）：标注每字四声（依《广韵》系统粗略即可，参考[[phonology/rhyme-tables]]），指出“病”在哪、为什么读起来别扭，读给同伴盲测。
::: solution
判分：**四声标注与位置描述可复核**（平头＝**上下句第一字（或头两字）同声类**——如两句皆以“仄仄”起，头重脚轻的“脚色相同”）；盲测若**没听出来**，要老实写“此病可宽”——**八病的历史淘汰率本身就是本题的正确选项之一**（沈约自认“**达大理者，今或未能**”级诚实：规则发明人自己也未必全做到——**凡例精神：先认账，再立法**）。
:::
:::

::: exercise 小论文：形式的账本 {level=3}
写六百至一千字，论“**永明声律是一次失败的立法、成功的实验**”。须调用：**《文心》“文贵形似”**（题材独立）、**钟嵘的差评**（同时代审计）、**“律句是禁法的不动点”**机制、**庾信或初唐的下游**至少三项；并给一项当代类比（**编程语言弃用清单／短视频 BGM 卡点／校规体正字法**任选）。
::: solution
判分点：“失败”与“成功”**分账清楚**（失败＝作为强制规范，八病**繁到不可执行、齐梁即腐**；成功＝**把声音设为可讨论对象，从此中国诗有了声学**）；机制句能复述（减法的不动点——**立法失败，采样成功**）；类比对齐（**卡点=上尾的娱乐版：踩不上就“别扭”——别扭感是群众手里的校勘记**）；结论若能写“**形式是最诚实的内容：它记录一个时代对身体的要求（口齿、呼吸、默读）**”，即 A——与直觉课“播音员是甲方”互为对账单。
:::
:::

::: summary
换骨课结账：大谢（**山水以“考察报告”入场、出生包着玄言襁褓、“文贵形似”——比德退职，感性上岗**）、小谢（**明信片化＋“弹丸”口感标准**）、永明（**四声=四个档位、平仄=合并报表；八病=禁则采样器**）、庾信（**南北合体的流亡实验**——为下一章与北民歌、为唐诗备好货）。方法一句话：**问一首诗“声音归谁管、题材向谁交代”——这两个问题就是六朝的全部答案**。下一章去对岸：长城脚下的牧歌与秦淮河上的情歌——分裂的天下在歌里仍然是分裂的，但两种声腔都已准备好并入唐诗。
:::
