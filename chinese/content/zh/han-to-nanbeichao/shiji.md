---
title: "司马迁与《史记》"
---

上一课的赋替帝国说话，这一课的人**替失败者说话**——而且说的是全中国最早、也最好的一套“人”的故事。《史记》一百三十篇是一座**用五栋楼组成的迷宫**：你在任何一篇里迷路，都是设计好的——出口在别的篇里。本章发你图纸。

## 五体与断限 {#def-wuti}

::: definition 一百三十篇的建筑学 {#def-jianzhu}
**五种楼型**：**本纪**十二（天子编年——**时间的房产证**）、**表**十（**两千年前的高级电子表格**：年代、人物、国别挤进一张纸，**治《史记》者半辈子在研究表格的行列语法**）、**书**八（礼乐律历天文五行水**平准=经济专刊**——文化制度部的八份白皮书）、**世家**三十（诸侯与**孔子**——**没爵位的孔子住进贵族区，是太史公最著名的越权**）、**列传**七十（从刺客到游侠到商人的**群像长廊**，末篇《太史公自序》=建筑师的签名）。**三个越位**：①**项羽无天子而居本纪**（“政由羽出，号为霸王”——**承认事实权力，不管名分**）；②**陈涉无诸侯而入世家**（“**首事**”反秦——**起义者拿到贵族的房产证**）；③**《货殖列传》给商人立传**（“**天下熙熙，皆为利来**”——**司马迁把被史书拒收的人全部收了**）。**通史断限**：上起黄帝、下至太初——**第一部“从头讲起”的中国通史**；而“从头”本身是立场：**以五帝共祖把各族编进同一张家谱，西汉的天下在竹简上有了族谱级的统一**。
:::

::: definition 史记笔法三件套 {#def-bifa}
**一·场景与对话**（垓下的歌、鸿门的舞、易水的送别——**太史公把史官的笔换成了戏剧的场面调度**；他甚至会**在正文里署素材来源**：《刺客列传》明写“**公孙季功、董生为夏无且道如此**”——**追悼会口述史直接进正文：引源到人的史学自觉**）。**二·互见法**（一个人的真相拆开放：项羽的雄霸在《项羽本纪》，他的刻悍残怒散在各人的传里——**《高祖本纪》里刘邦英明神武，《项羽本纪》里他弃儿推车**——**主传给他体面，别传泄他的底：互见法=给复杂人物开的多窗口浏览器**）。**三·不判之判**（篇末“**太史公曰**”是唯一的正式评论席——但真正的判决在**编排**里：谁进本纪谁进列传、谁与谁同传、传的顺序、赞里引一句别人的诗——**结构即价值观，名单即檄文**；“**不载于某书**”与“**载于某书**”同样响——与上一章选本的“沉默比选文更响”同法）。
:::

::: example 三幕剧：《项羽本纪》的最后四十行 {#ex-xiangyu}
垓下：**夜闻楚歌**→“**力拔山兮气盖世，时不利兮骓不逝**”→**泣数行下，左右皆泣，莫能仰视**；东城快战：**“此天之亡我，非战之罪也”**→三处快战亲自演示“天之亡我”；乌江：**亭长具船**→“**纵江东父兄怜而王我，我何面目见之**”→**“吾知公长者，吾骑此马五岁...不忍杀，以赐公”**→**乃自刎**；太史公曰：引“**舜目重瞳**”之谣——“**羽亦起陇亩之中...分裂天下而封王侯，政由羽出，号为霸王，位虽不终，近古以来未尝有也**”——但紧接着批评“**自矜功伐，奋其私智**”，**把“天也”当场退货**：“**身死东城，尚不觉寤而不自责，过矣**……**岂不谬哉**！”问：太史公对项羽的“最终评分”在赞语里吗？
::: solution
**评分根本不在赞语里——在文体的分配里**：本纪的规格（帝王待遇）、本纪的**篇幅**（列传诸豪杰皆在项羽传里串场）、以及**全场最高光的台词配额**——**《史记》的星级由楼型决定：住进本纪，等于追认霸王为时代的主席**。赞语只是**事后口头扣分**：既给他的死写足诗（**虞兮之歌是中国文学第一首英雄绝命歌**——歌+美人+名马三件套：**太史公给失败者发了全套的抒情牌照**），又在字缝里执行史官职责（“岂不谬哉”）。**文学判无罪，史学判逻辑过失，互见法判终身观察**——同一人物三个法庭，**这正是《史记》成为文学而同时不失为史的结构原因**：它不解决矛盾，它**把矛盾排版**。
:::
:::

::: intuition 你读到的人，是几篇拼起来的 {#int-pin}
《史记》教会中国读者一件事：**没有一篇传记是真的，除非你读完他的互见全家桶**——刘邦在《高祖本纪》里是“**仁而爱人，喜施**”的开国主角，在《项羽本纪》里是**兵败时“推堕孝惠、鲁元车下”的甩娃父亲**，在《留侯世家》里被张良当面顶回“**不可**”——**同一顶冠冕在不同窗口显示不同裂纹**。这套“**多窗口读人法**”早已是现代人处理信息的本能（一个人：简历／朋友圈／前同事评价）——**司马迁只是最早拒绝单源叙事的人**。更深一层：他连“叙述者”也不给豁免——**“究天人之际”那句自述（《报任安书》）承认史家要处理的是“际”**（天人之间、事实与评价之间、爱与恨之间），**不是“天”或“人”任何一边**——《史记》的伟大不在它客观，在它**把主观的不安全感全程公开**。
:::

::: history 一部书的流与用 {#sec-liu}
**藏与显**：书成后**藏于家，“后世稍得见”**——**“成一家之言”起初是一屋之言**；**宣帝时，外孙杨恽上表奏闻，《史记》乃公布**——**一家私史等外戚关系才等到出版**；**那封自述心事的《报任安书》，今日全文赖《文选》保存**——**私函靠选本传世，文献学的黑色幽默**；**三家注**（刘宋**裴骃集解**、唐**司马贞索引**、唐**张守节正义**——**一部书的三层公寓**，[[classical-chinese-2/exegesis]]现场版）；**批点时代**：**唐宋古文运动把《史记》从“史”升格为“文”**——从“史”升格为“文”——韩愈之“气”、欧阳修之“六一风神”皆自史记门出；“文章祖《史记》”成为科举时代的作文口令**；**章学诚“六经皆史”**把史部抬进经部客厅；**鲁迅“史家之绝唱，无韵之《离骚》”**（《汉文学史纲要》）——**一句广告词统治《史记》文学地位一百年**（绝唱=**史与文此后再难同体**的悼词，也是它的颁奖辞）；**当代**：**《史记》进入全文检索与“互见法数据库”**——**把“读全家桶”从美德变成一键**。
:::

::: warning 读史四坑
**当戏剧当史料**（垓下“莫能仰视”的镜头感来自**口述与想象**——**问“可能真否”比问“是否记录”专业**）；**单篇定人**（只读《高祖本纪》崇拜刘邦，只读《项羽本纪》同情项羽——**互见法警告过你：人是多篇合成的**）；**跳过表和书**（“文学青年跳过律书平准书”——**《平准书》是汉代财政的体检报告，不懂它读不懂武帝朝的对外战争与《酷吏列传》**——**文学性长在经济与制度的地基上**）；**把太史公曰当打分器**（赞语常有**克制、反讽与不得已**——《匈奴列传》赞语于武帝伐匈奴事仅微词——“在位之臣知今上意”的曲笔**——**读赞先问：这话他能直说吗？**）。
:::

::: exercise 互见拼图 {level=1}
制作“**刘邦拼图**”：从《高祖本纪》《项羽本纪》《留侯世家》《萧相国世家》各取一至两条关键条目（如**分一杯羹、数项王十罪、踞洗见郦生、推堕子女车下**——出处须逐条核对），做四栏对照表，写一句“窗口差异”观察。
::: solution
判分：**条目—篇名零错配**（把“分一杯羹”安给项羽即出局——**互见法实操第一课：别把别人的窗口当他的脸**）；观察句写出**语用**（同一件无赖事，在本纪是“豁达权变”，在彼传是“慢而侮人”——**叙述立场=用词选择**）；允许结论“拼不齐”——**拼不齐是合格的报告**（人是过程，不是拼图）。
:::
:::

::: exercise 给名单写判决 {level=2}
《史记》列传第一是**伯夷**，末二是《游侠》《货殖》——有人据此说司马迁“**先让饿死的站在最前，最后让赚钱与犯禁的压轴**”。请写出**正方**（编排见微言）与**反方**（过度解读）各 150 字，并说明：**什么样的外部证据能让一方胜出**（同时代文体惯例／作者他处自述／版本篇序变动，举其一经）。
::: solution
判分：正方最强牌=**《报任安书》“述历黄帝以来”＋本传自序对列传顺序的自述**（“**扶义倜傥，不令己失时，立功名于天下，作七十列传**”——自序确实说明排序动机）；反方最强牌=**十表有固定世系逻辑、篇序或经后世整理**（以**《太史公自序》本身也是被抄写的文本**存疑）；胜出条件须可操作（**版本学思维：找最早目录著录核对篇序**）；判卷不看立场看**证据强度意识**。
:::
:::

::: exercise 小论文：《史记》是小说的祖先 {level=3}
写六百至一千字，论《史记》交给后世小说的四件遗产：**场景对话、类型人物（游侠／酷吏／佞幸）、“太史公曰”式的叙述人人格、以及“传奇”之名的血缘**（唐传奇的“传”即列传之传）；并以《红楼梦》某一回（如**尤三姐或晴雯**的写法）或一篇武侠小说为案例，演示其中一件遗产仍在运转。
::: solution
判分点：四件遗产至少**坐实两件**（“传”字血缘：**列传→传奇，连名字都是继承人**）；案例须**具体到句**（“那妇人睁着眼”式的人物亮相=史记列传的**开相法**——本纪列传如何给人物“**开场定妆**”）；叙述人人格对比现代网文的“**笔者按**”——**干预性叙述从未死，只是换了 ID**；结论若承认“**史与文的离婚在唐代完成，但孩子归了文**”，即 A。
:::
:::

::: summary
迷宫图纸结账：五体（**楼型即星级**）、三越位（孔子、项羽、货殖——**把被史书拒收的人全部收了**）、笔法三件套（**引源到人的场景、互见的多窗口、编排的不判之判**）、流传（家藏—外戚—三家注—古文运动—绝唱评语—数据库）。方法一句话：**读《史记》先认楼，再拼图，后问“这话他能直说吗”**。下一章离开庙堂进里巷：汉乐府——街头把话筒递给了普通人的舌头。
:::
