title: "陶渊明"
---

上一章结尾说“痛感出院，下一站风景”——但风景的第一位代言人**根本不写风景**：他写草、写豆、写穷、写死。陶渊明是中国文学史上最大的一次**降级实验**：把题材降到农活，把语言降到口语，把姿态降到“欲辨已忘言”——然后这个“降”成了后世仰望了一千六百年的高度。

## 一个人，三本账 {#def-sanzhang}

::: definition 出仕账与《归去来兮辞》 {#def-chushi}
**账目**：亲老家贫，起家州祭酒，辞；后为桓玄幕僚、刘敬宣参军，终于彭泽令——**十余年间几进几出**（**《归去来兮辞》序自报动机：“** 质性自然，非矫厉所得；饥冻虽切，违己交病**”——**“违己交病”四字是全人的总纲：饿比违己更可忍**）；**“不为五斗米”事**：《宋书·隐逸传》记他叹“**我不能为五斗米向乡里小儿折腰**”，即日解绶——**故事太好以至于人人加戏：郡遣“督邮”来县一节，《晋书》作“乡里小人”，细节出入正是传说生长的年轮**）；**《归去来兮辞》**：序＝**辞职说明书**（“**悟已往之不谏，知来者之可追。实迷途其未远，觉今是而昨非**”——**用《论语》“往者不可谏”的楚狂接舆语自我开赦**），正文＝**回家的蒙太奇**：“**三径就荒，松菊犹存”“云无心以出岫，鸟倦飞而知还”**——**“云”“鸟”两个零度意象从此被汉语承包：中国山水诗的抒情动词表，第一页是他签的名**（[[han-to-nanbeichao/zhengshi-jin]]结尾说“我将在风景里重新署名”，签名就在这两行）。
:::

::: definition 劳动账：田园诗的本相 {#def-laodong}
**田园诗不是风景画，是劳动日志**：“**种豆南山下，草盛豆苗稀。晨兴理荒秽，带月荷锄归**”——**产量写进诗（稀！），这是中国诗歌史上第一次有人承认自己种地不行**；“**道狭草木长，夕露沾我衣。衣沾不足惜，但使愿无违**”——**劳动的结论不是丰收，是“愿”的守恒**。**穷也要入账**：“**夏日长抱饥，寒夜无被眠。造夕思鸡鸣，及晨愿乌迁**”（《怨诗楚调示庞主簿邓治中》）——**饿到盼天亮好熬夜、盼天黑好躲冷：修辞的对称与生活的不对称**；《五柳先生传》——**“闲静少言，不慕荣利。好读书，不求甚解；每有会意，便欣然忘食”＋“环堵萧然，不蔽风日；短褐穿结，箪瓢屡空，晏如也”**——**自画像画到把“穷”画成版权形象：先生不知何许人也——传记主角的第一句话是取消户口（[[han-to-nanbeichao/nineteen-old-poems]]“无面”技术的传记版）**。
:::

::: definition 生死账与真意 {#def-shengsi}
**三组《挽歌辞》《自祭文》：提前给自己办葬礼**——“**死去何所道，托体同山阿**”（死亡被写成地质事件：**遗体捐给山体，山不欠人情**）；《自祭文》收以“**人生实难，死如之何**”——**对活承认难度，对死不提问：这是无宗教者的终极技术**（比较《十九首》“服食求神仙，多为药所误”——**陶渊明把汉人戳破的假药方彻底扔了，也不开新的**）；“**纵浪大化中，不喜亦不惧。应尽便须尽，无复独多虑**”（《形影神》三首**自立辩论：形、影、神三个自己开会**——**中国哲学诗的最优解：让自我内战，再让“神”劝和——结论是“委运”：随波但不认输**）。**“真意”账**：“**采菊东篱下，悠然见南山。山气日夕佳，飞鸟相与还。此中有真意，欲辨已忘言**”——**《庄子》“得意而忘言”的庄子实验现场（言意之辨绕了一百年，最后在一首田园小诗里结案：真理的保质期到语言为止）**；而同一卷里的**《述酒》**，宋人注本认定是隐语写的**刘裕禅代新闻**——**“忘言”是技术，“要说”也是技术：同一个人同时掌握沉默与密码**。
:::

::: example 矛盾体档案 {#ex-maodun}
组四对材料：A“**猛志逸四海，骛翮思远翥**”（《杂诗》）／“**少时壮且厉，抚剑独行游**”（《拟古》）；B“**采菊东篱下，悠然见南山**”；C《咏荆轲》“**惜哉剑术疏，奇功遂不成**”；D 挽歌与自祭。问题：**“静穆”的陶渊明是谁造的？四对材料如何共存？**
::: solution
**共存的技术名词：《归去来兮辞》序所谓“质性自然”——他最高的自我辩护不是道德是材质：自然＝不修剪**。逐项：**A/B 不是前后变化，是两个时态**——“猛志”是**回忆的现在进行时**（“猛志”诸咏多作于归田后：归田没杀掉青年，只给他放了假只给他放了假**）；**C 证明“题材解禁”**：他写荆轲写得刀刀见血——**“静穆”是选本的剪辑：田园诗只占陶集约三成，其余是咏史、述酒、责子、挽歌——被后人剪掉了三分之二**；**D 是矛盾的仲裁庭**：对死亡的诚实使一切姿态（猛志／静退）同时合法——**知道要死的人，热闹和清静都不装**。朱光潜说陶是“**静穆**”的极致、鲁迅反驳“**陶潜正因为并非‘浑身静穆’，所以他伟大**”（《题未定草》）——**这场 1930 年代的论战双方都引对了证据：静穆是真，金刚怒目也是真；错的只有单选题**。
:::

::: intuition 桃花源：对时间本身的隐居 {#int-taohua}
《桃花源记并诗》的设定值得逐帧看：**入口**（**晋太元中，武陵人捕鱼为业——史传笔法的开相，把小说伪装成采访**；“**忘路之远近，忽逢桃花林”——迷路是唯一的门票**）；**村里**（“**自云先世避秦时乱……不知有汉，无论魏晋**”——**他们躲的不是山，是朝代：乌托邦的定义=对时间本身的隐居**；“**黄发垂髫，并怡然自乐**”，“**其中往来种作，男女衣着，悉如外人**”——**注意：桃源人第一身份是农民——陶渊明的天堂没有文人，连诗都不作**）；**结局三连**（“**此中人语云：不足为外人道也**”——**叮嘱即诅咒**；“**处处志之……遂迷，不复得路**”——**标记失效：制度化的寻路（“志”）对偶然（“忘路”）的必败**）；**刘子骥**（“**欣然规往，未果，寻病终。后遂无问津者**”——**把真实名人写进失败名单＝用现实给虚构加盖封印：连寻访最出名的隐士的人都找不到——故事从此免疫于一切实证**）。**并诗结于“**嬴氏乱天纪，贤者避其世**”，把政治指数写进神话前台——**记藏诗说：散文负责神秘，韵文负责政论**。
:::

::: history 一场一千六百年的追封 {#sec-zhuifeng}
**丧钟初响**：颜延之《陶征士诔》——**好友写的官方悼词里陶诗几乎为零：当时他的身份是“处士”，不是诗人**；**萧统**编《陶渊明集》并作序——**“有能观其文，恬退之节亮乎；味其怀，贞慎之诚昭乎”：梁朝太子把他编成道德教材，顺带保存了作品**；**钟嵘《诗品》中品，称“** 古今隐逸诗人之宗 **”**——**标签史著名案例：中品＋“隐逸”＝盛名但封顶**；**唐**：**相对沉默的唐朝——王绩学其人，孟浩然、王维一路山水田园分走了他的题材，本尊地位不显**（**杜甫独眼识珠：“**焉得思如陶谢手**”——陶谢并提；但盛唐主流买的是“诗到王维”的账**）；**宋**：**翻案总动员——苏轼一生和陶，逐首和到底（《和陶饮酒二十首》起，贬岭南犹尽和全集）——中国文学史上最大规模的致敬行为**；**宋人公认陶在“平淡”之下藏着大力——苏轼“**质而实绮，癯而实腴**”八字，把“降”翻译回“高”**；而黄庭坚、辛弃疾以下，龚自珍“**陶诗韩笔两嶙峋**”，各领一支“怒目队”；**元**：**元**：陶渊明故事成为杂剧母题（《误入桃源》等）——“桃源”从诗变成中国舞台的空间单位**；**现**：**鲁迅《魏晋风度及文章与药及酒之关系》把陶拉回“稼穑”现场：“** 陶潜正因为并非浑身静穆，所以他伟大**”——**20 世纪的重审：既反对“封建士大夫的消极”判决，也反对“静穆”的招安**。
:::

::: warning 读陶四坑
**把田园读成民宿**（“采菊”不是生活方式博主——**他的田真穷、真饿、真种不好：浪漫化的第一层删除就是他亲自写进去的“草盛豆苗稀”**）；**把“不求甚解”当学习态度**（《五柳先生传》此句后文是“每有会意，便欣然忘食”——**“不求甚解”针对的是章句之学，主张的是“会意”：删的是训诂，留的是共鸣**）；**单选题选静穆或怒目**（鲁迅已判：**“局部的特别放大”都会得出假陶渊明**）；**把桃源当社会方案**（**记的结局是“遂迷，不复得路”——桃源的设计正是不可复得：它是批判的坐标系，不是可施工的图纸**：把它当规划图，从渔人“处处志之”那一刻就已经失败）。
:::

::: exercise 三时态朗读 {level=1}
《归园田居》其三与《杂诗》“猛志逸四海”并读，填**时态表**：哪首用身体的现在、哪首用愿望的将来、哪首是回忆的完成？再抄写“**衣沾不足惜，但使愿无违**”，标出“愿”字在这首诗里被什么押韵。
::: solution
判分：时态表不错（草盛苗稀=**当下劳作的现在时**；猛志=**从未兑现的将来时**；抚剑独行游=**追怀的完成时**）；“愿”的分析到位：**“愿无违”与“归”“衣”同韵——愿被“归”押着：归田是愿的韵脚**；能承认三首**互相反驳**且都诚实，即过。
:::
:::

::: exercise 为督邮辩护 {level=2}
“不为五斗米折腰”案，请**站督邮立场**写 150 字申述（可虚构但须合史理：考课、传令、属吏的职责），再写 50 字判词：**为什么文学史只记得县令，不记得督邮**？
::: solution
判分：申述可用材料（**督邮巡察属县是制度职能；“折腰”对上级是公务礼数**——**他把制度成本当成了人格成本**，或反过来）；判词到位：**文学史是名的经济学——一方有诗，一方只有职务；沉默的大多数不怪他们不写，怪我们只收有名字的**（此题与“无面”“托名”两案连读：**文学史的记名制本身就是最大的选本**）。
:::

::: exercise 小论文：经典的发明 {level=3}
写六百至一千字，以陶渊明接受史为案，论“**伟大诗人是作品与追封的乘积，缺一为零**”。须走材料：**颜延之诔不重其诗→钟嵘中品→唐之寂→宋之大热（苏轼和陶、朱熹定评）→鲁迅重审**；并自选一件当代“追封”案例（**凡高的市场神话、卡夫卡的出版、周杰伦进教材**任一）对齐机制；回答：**我们今天读到的“陶渊明”，几分是 405 年的他，几分是 1086 年的他**？
::: solution
判分点：链条完整且**每一环说明需求侧**（**宋人需要什么：一个能与“绮靡”传统对垒的“平淡”偶像，加上党争失意者的身份模板——苏轼和陶不是书评，是认亲**）；当代类比对齐（**作品的“原始发行量”小，“追封”决定再版与定价**）；“几分”之问**给出配比并说明依据**（范文：《归去来兮辞》的字句是 405 年，“**平淡而近自然**”这个人是 1086 年——**文本有作者，经典没有；经典是每个时代在旧文件上保存的新副本**——能写出这一句式者，A 且本课结业）。
:::

::: summary
降级实验报告：仕（**“违己交病”：饿比违己可忍；辞职信改写了《论语》**）、耕（**产量入诗＋穷入画：“无面”技术的传记版**）、死（**提前发讣告，“托体同山阿”——遗体捐给山体，山不欠人情；形影神让自我内战**）、桃源（**对时间的隐居＋刘子骥封印：不可得是其全部意义**）、追封（**中品之宗→宋之圣像→鲁迅重审：经典=作品×追封**）。方法一句话：**读陶渊明先问“这句是谁给他加的光”，读任何经典同理**。下一章：山水与声律——谢灵运把镜头对准风景本身，沈约们给汉语装上节拍器。
:::
