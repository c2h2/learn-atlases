---
title: "汉乐府"
---

赋是朝廷的扩音器，乐府是**街头递进来的话筒**。公元前二世纪，汉朝办起一座国家音乐机构，任务包括采集民歌——**中国文学史上第一次，里巷的口头创作被国家机器收录进档案**，于是有了这样一批诗：说话的不再是士大夫，是弃妇、兵卒、病妻的父亲、被虐待的孤儿。

## 机构与题目 {#sec-jigou}

::: definition 乐府：采诗的国家，因袭的题目 {#def-jigou}
**机构**：“**乐府**”本是官署名（秦代已有乐府令；**武帝确立其采诗职能**——《汉书·礼乐志》：**“至武帝定郊祀之礼……乃立乐府，采诗夜诵：赵、代、秦、楚之讴**”——**国家设立“人民声音”的档案科**）；协律都尉**李延年**（“**北方有佳人**”歌的演唱者兼作者——**宠妃之兄以歌进身：机构的第一批员工是宫廷歌手**）；**《汉志》总账**：“**感于哀乐，缘事而发**”十二字——**汉乐府的纲领：先有事的撞击，后有诗的产出**（对照《诗经》“发乎情”的温和注脚——**乐府把“事”字顶到了前台**）。**题目制度**：宋郭茂倩《乐府诗集》分乐府为**郊庙、鼓吹、相和、清商、杂曲**等十二类——**今天读到的“题”是乐工归档的编号**：《陌上桑》本名《**艳歌罗敷行**》（“艳”＝相和曲的引子段落——**曲牌残留变成诗题**）；**相和歌的“三调”**（平、清、瑟）是**调高标签**——诗是歌词，**先有旋律后有文本**。后世“**拟乐府**”：曹操《短歌行》用汉题写时事——**旧瓶装新酒，瓶上商标不许改**；到唐，“**即事名篇，无复依傍**”（杜甫《悲陈陶》诸作、元白新题乐府——**打碎瓶子直接写**——这笔债要到唐代文学课才清偿）。
:::

::: definition 口语的声口：汉乐府怎么写话 {#def-shengkou}
**①开门见山**（《东门行》：“**盎中无斗米储，还视架上无悬衣**”——**起句就是账本赤字**；《上山采蘼芜》：“**上山采蘼芜，下山逢故夫**”——**复婚修罗场，前十字就把肥皂剧开场**）。**②对话驱动**（《东门行》妻扯着丈夫衣裳哭谏，答以**“咄！行！吾去为迟！”**——**一个“咄”字保住全诗的现场录音感**；《陌上桑》使君与罗敷的问答=**全诗骨架，叙述者几乎不出场**）。**③呼告与誓言**（《上邪》“**上邪！我欲与君相知，长命无绝衰**”——**对天起诉的誓词**）。**④琐细的控诉**（《孤儿行》历数**瓜车翻覆、手为杵桩、面目多垢**——流水细节堆成童工工时表——不骂一句，只报流水账；数字即控方陈词**）。**⑤赋法人诗**（《陌上桑》罗敷夸夫：**东方千余骑，夫婿居上头**——**按方位、按颜色、按升迁速度的炫富目录＝大赋的货架搬到民歌里**；**“青丝系马尾，黄金络马头”：用财产的亮度写婚姻的硬度**）——**铺陈是乐府与赋共享的血浆：上林苑的字库与罗敷的夫婿，是同一修辞工业的两种产品**。
:::

::: example 《孔雀东南飞》：孝子社会的殉情案 {#ex-kongque}
全诗一千七百余字，**中国文学第一首长篇叙事诗**（原出《玉台新咏》题《古诗为焦仲卿妻作》；**诗前小序宣称本事：“汉末建安中，庐江府小吏焦仲卿妻刘氏，为仲卿母所遣，自誓不嫁……二人皆投水而死。时人伤之，为诗云尔。”**）。请拆四个工位：①序的“**时人伤之**”——**新闻社论腔**给全诗发的“真实”图章；②兰芝自述“**十三能织素…十六诵诗书**”——**聘礼清单式的自我举证**；③兰芝别婆婆的祝寿辞“**受母钱帛多，不堪母驱使。今日还家去，念母劳家里**”——**逐字合规的逐客令**；④合葬化鸟“**东西植松柏…中有双飞鸟，自名为鸳鸯**”——**叙事失效处的神话补丁**。
::: solution
①序＝**报告文学的防伪标**（“时人伤之”把诗挂上新闻的钩子——**与《史记》引源到人同一族谱**：中国叙事文学的“真实感”靠**转述链条**背书）。②自述＝**履历清单式自我举证**（她的一切价值按**工时与才艺**报价——**而遣她的理由恰恰与她被训练的一切无关：母要的不是“贤妇”而是“顺妇”；“** 自专由**”三字是婆婆唯一的罪状——**兰芝的悲剧不在不孝，在她完美符合所有教科书，而考试题目临时换成了服从**）。③别辞＝**礼法的钉子户**（每个字都合礼，合礼到**无法反驳**——**柔术的最高级：用对方的规则把对方钉在耻辱柱上**）。④化鸟＝**叙事学意义的“另有处理”**（现实线全部走死：休→逼→殉——**双亡之后需要团圆，民间叙事伸手借了楚辞的转化母题；注意诗并未宣布二人“成婚”，只给一对鸳鸯：制度赢了，爱情连胜利的形式都只能是逃逸**）。**全诗结构=双重束缚的教科书：焦仲卿爱妻，但“孝”要求他服从母亲；兰芝守节，但“礼”要求她服从兄长——每个美德都是另一桩美德的绞索**。
:::
:::

::: intuition 叙事的第一口奶 {#int-xushu}
中国抒情传统发达，**叙事文学却全员喝乐府的奶**：《为焦仲卿妻作》给出长篇叙事的整套模板——**线性时间＋对话推进＋关键物（蒲苇、磐石、严妆的“妾有绣腰襦”）＋类型人物（恶婆、懦夫、蛮兄、烈妇）**；《陌上桑》给“**用对话写冲突、用夸饰写拒绝**”的轻喜剧开了山——**罗敷的胜利是修辞学的胜利：她不决斗，她办一场更豪华的想象给对方看**（上林苑的手法第一次用于自卫）。连《史记》的本纪列传都与乐府同时代——**同一套“场面＋对话＋类型”的叙事工业，史书拿去写人，民歌拿去讲事**（[[han-to-nanbeichao/shiji]]的三幕剧在此认亲）。判断标准一条即可：**汉代以前，文学说“我悲伤”；汉乐府开始，文学说“那天早上，他提起剑”——从情绪到场景，是中国文学的成年礼**。
:::

::: history 机构死了，诗活着 {#sec-jiang}
**前二世纪初**：《礼乐志》“乃立乐府”——**采诗夜诵开张**；**前6年**（哀帝即位后）**裁撤乐府官员——“放郑声”的行政动作，采诗制度第一次死亡**；**东汉**复置，**采集＋文人拟作并行**：辛延年《羽林郎》——**而《焦仲卿妻》成于“时人”、传于建安之后——民间长诗以“无名”的身份进入文人传抄**；**魏晋**：**清商三调的歌词被曹操父子改写为政治抒情**（《**短歌行》《步出夏门行**》——**汉民歌的瓶，装曹公的酒：拟乐府首次成为一流文学**）；**宋齐梁陈**：南朝**“吴歌西曲”**（《子夜歌》系统——**采诗机构再立，这次的“街”在建康秦淮河**：[[han-to-nanbeichao/folk-songs]]）＋**《宋书·乐志》著录汉曲**——**乐制文献学开工：当曲子死了，唱片说明书成了正史**；梁代**智匠《古今乐录》**——**原书虽佚，辑本里藏着每首乐府的演唱信息**）；**唐**：**杜甫新题乐府“即事名篇”**、元结《舂陵行》、**元白新乐府运动**（“**文章合为时而著，歌诗合为事而作**”——**白居易把“感于哀乐缘事而发”翻译成战斗纲领：两百年前的定义成为改革口号**）；**宋**：**郭茂倩《乐府诗集》**一百卷——**全部乐府的题目总账**；**清**：**沈德潜《古诗源》以汉乐府压卷——格调派“认汉人为父”，尽管书中掺着几篇伪古诗**；**今**：汉乐府进入中学课本与国风歌曲——**“采诗夜诵”的闭环：街头→宫廷→课本→重新街头**。
:::

::: warning 读乐府四坑
**把歌词当纯诗**（“艳”“趋”“乱”是**曲式术语**不是文意——读乐府先接受它**是歌**：某些“跳跃”其实是**反复与换头**）；**把“民间”浪漫化**（采来入律=**经过宫廷乐工混音的民间**——“原生态”是后世想象；《孤儿行》的痛点真实，但**麦克风也是国家递的**）；**用道德课读《陌上桑》**（“贞烈颂”读法错过全诗的**喜剧装置**：罗敷骗人、使君上当、听众会心——**这是一则段子，不是牌坊**）；**把《孔雀东南飞》读成婆媳斗争**（恶人论太省事——**诗的真正对手是制度：每个人都按各自的礼法“正确”行事，然后全员死亡：悲剧的最高配置**）。
:::

::: exercise 童工账房 {level=1}
读《孤儿行》，列**工时表**（作业项目、往返路程、体表伤害、四季穿戴各一两条），再写 100 字：为什么“报流水账”比直接呼天抢地更有力？
::: solution
判分：账目**逐句有出处**（如“**南到江口**”“**树下收瓜**”，**条目错了本题即崩**）；机制分析到位：**数字不替读者下结论，逼读者自己得出结论——控诉的最高形式是让陪审团开口**；能指出结构反转（**篇末对亡父的呼唤=账本突然有了哭的声音：先记账后哭，哭才可信**）者优。
:::

::: exercise 镜头分析师 {level=2}
《陌上桑》写罗敷之美全靠**旁观者失态**（行者下担、少年脱帽、耕者忘犁——“**行者见罗敷，下担捋髭须**”一段）：写一张**机位图**（谁看、看什么、反应多长），并解释为何**诗人不描写她的脸**；最后仿写一段 80 字“用反应写人”（写食堂窗口阿姨/地铁上睡着的同学皆可）。
::: solution
判分：机位图写出**侧写的经济学**（美的强度=旁观者失态的**总和与阶梯**；不写脸=**把定价权交给全场，且永不穿帮——想象永远比工笔华丽**）；指出“使君的失态=叙事的发令枪”（**冲突由“看”发动——本诗是“凝视的政治学”两千年前的案例**，答题可升维到[[rhetoric/choosing-words]]的夸饰）；仿写**必须有递降或递升的阶梯**（平铺无益）。
:::
:::

::: exercise 小论文：制度如何制造烈士 {level=3}
写六百至一千字，以《孔雀东南飞》为主案，论“**诗没有坏人，只有每个人都‘正确’的制度**”：拆解焦母（寡母对独子的情感产权）、刘兄（**嫁卖妹妹的户主权限**）、仲卿（孝子服从义务与丈夫义务的互斥）、兰芝（**受教越多、议价越少**）四方各自的“礼法依据”，指出**殉情为何是此系统内唯一可执行选项**；并以一件现代家庭事件（催婚/彩礼/学区房任选）做**不贴标签的机制类比**。
::: solution
判分点：四方礼法依据**各引诗句为凭**（焦母“**吾意久怀忿，汝岂得自由**”——自由的定义权在她手里；刘兄“**先嫁得府吏，后嫁得郎君，否泰如天地，足以荣汝身**”——以利相逼；兰芝“**黄泉下相见，勿违今日言**”——誓言由女方发出：**唯一对自己人生的立法权，是决定死法**）；“唯一选项”推演完整（休→归→逼→**制度把所有合法出口焊死，非法出口成双**）；现代类比**只对齐机制不对齐烈度**（催婚=情感产权的温和版——**分清“压迫光谱”再类比，否则论文先犯道德轻罪**）；结论若落到“**读这首诗的正确情绪不是恨婆婆，是查制度**”，即 A。
:::

::: summary
话筒课结账：机构（**采诗夜诵＝人民声音的档案科**；哀帝的裁撤＝第一次死亡）、声口五件套（开门见山、对话驱动、呼告、流水账控诉、赋法人诗——**上林苑字库与罗敷夫婿同属一个修辞工业**）、《孔雀东南飞》（**双重束缚教科书＋化鸟的“另有处理”**）、来世（拟乐府—新乐府—课本—重新街头）。方法一句话：**汉乐府是“事件驱动”文学的起点——问“什么事逼出了这句话”，比问“这句话美不美”更接近它的生产方式**。下一章，文人的手接过话筒：《古诗十九首》——无名者如何成为最高的有名。
:::
