---
title: "志怪、志人与文学批评"
---

收官章讲六朝的三件新发明：**给鬼神建档（志怪）、给名士速写（志人）、给文学开庭（批评）**。三件事共用一个时代精神：**当经学不再独家供应真理，人就急着把一切——包括做梦、八卦和关于诗的意见——都记下来、分好类、排出座次。**

## 三件发明 {#def-faming}

::: definition 志怪：发明不骗人的鬼 {#def-zhiguai}
**体裁的自供状**：干宝《搜神记》序自陈材料为**“考先志于载籍，收遗逸于当时”**——残卷、口述、访闻三桶；**他本人是史官（中书令领著作）**，于是志怪的出生证上写着：**“记录”，不是“创作”**——**写鬼神而自称史笔，这是小说在史部阴影里讨到的第一张执照**。户口问题：《汉志》定义小说为**“街谈巷语，道听途说者之所造也”**，并引古语**“小道，必有可观者焉；致远恐泥，是以君子不为也”**——**小说的户口从落城起就是临时户口；而临时户口恰好意味着：没有旧规矩，新规矩随便长**（《隋书·经籍志》把鬼神怪异之作系于子部，正是这章程的魏晋执行版）。**样本解剖**（《三王墓》）：眉间尺为父复仇（干将莫邪为楚王铸剑而遇害）；王悬重赏购其头；**山中侠客开出条件：以尺之头与剑为聘，代往**；煮头三日不烂，客请王临穴——三王遂共冢。**叙事学要点：头颅是通行证，信任靠“头”当场交割；沸汤跳踯之类的超自然只做剧情胶水，动机全部人间——复仇伦理压过君臣名分。志怪最好一类的配方：鬼怪的外衣，法理的内核**。后续：《搜神后记》**旧题陶渊明撰——连鬼故事都要抢注名士的商标**；《世说》刘孝标注广引志怪——**志怪与志人在六朝互为注脚，同属一台“记录机器”**。
:::

::: definition 志人：九品中正制的文学版 {#def-zhiren}
**《世说新语》**：宋临川王刘义庆荟萃、梁刘孝标作注——**今传三十六门：德行、言语、政事、文学为首四门，任诞、简傲、豪爽、惑溺列于后**。**前四门抄自孔门科第，后门却以“越界”为风流——批评系统的头尾分裂，正是魏晋“人的重新发现”的断层线**。**体量**：一千余则，**每则三五十言——中国速写文体的封顶**。两则铁案：谢安得淮肥捷书，**“了无喜色，围棋如故”**，客问，**徐答曰“小儿辈大破贼”——语言的极限克制**；**“过户限，心喜甚，不觉屐齿之折”——细节的极限泄密**。一篇之内，礼法与身体合谋演完“雅量”的真相：**《世说》叙述学＝克制＋穿帮**。注：**刘孝标注引书数百种，亡籍赖以保存——注书反噬正文的史料权重；与裴松之《三国志注》同代同法：史与小说共享注疏技术**。**血统**：《尚书》有《语》有《志》，“语”类古书专记嘉言——**志人是语类的还魂；小说两大干（志怪＝史之余，志人＝语之余）都穿着史书的开裆裤长大**。
:::

::: definition 批评：文学开庭 {#def-piping}
百年立法链：**《典论·论文》（执照）→《文赋》（营业范围）→《文章流别论》（谱系意识）→《文心雕龙》（宪法）→《诗品》（判例汇编）→《文选》（判例全文库）**。**《文心》**五十篇：**“本乎道，师乎圣，体乎经”三篇立宪，“酌乎纬、变乎骚”两篇留改革出口**；**文体论四十字作业标准：“原始以表末，释名以章义，选文以定篇，敷理以举统”——每类文体一部通史＋定义＋选文批评＋写作要领：手册（handbook）体例的完整雏形，早于同类西方教科书千余年**。《诗品》：一百二十余人**分三品、系源流**——**九品官人法的文学版；它最大的发明是“批评可以成书”本身**：读诗读出判决书的快感，**审美的独裁与民主在“品第”里同床共枕**；它生前身后都吵翻文坛——**被骂，恰是批评取得公共地位的证据**：萧统编《文选》、刘勰作《文心》，与它同席构成齐梁文学思想的三足（曹氏父子与“四友”、齐梁诸子谁也不服谁，《魏书》《梁书》两传互见其喧）。**批评的黄金律：说诗，是当时最安全的公共发言——文论的繁荣，是言论环境的负片**。
:::

::: example 两则对读：沸汤与棋局 {#ex-duidu}
两则对读。《三王墓》（《搜神记》卷十一）＝ **“委托—验明—执行”三拍**：侠客以“得头与剑”为承包条件，煮头不烂为剧情拖延，王临穴而三头并葬。《世说·雅量》谢安闻淮肥之捷＝**“压—漏”两拍**：围棋如故、答语平淡（压），过户限折屐齿（漏——通行本作“屐齿”，版本小异而情节锁定）。请各写一段 100 字“文体法医报告”：**这两种叙事语法分别服务于什么社会功能**？
::: solution
**《三王墓》报告**：**契约叙事的原始标本**：侠客的委托要“头”作抵押——**在法庭不可信的社会里，信任必须用肉身当场结清**；煮头不烂是**剧情给拖延留的缝**，让“王亲自来看”这一步得以发生——**超自然负责物理，伦理负责动机，志怪的分工在此定型**；下游直达唐传奇《古剑记》系统、鲁迅《铸剑》（“**黑色人”宴之敖者就是那个侠客——眉间尺的头换成“头也给你”的升级版：以复仇为业的职业化）。**《雅量》报告**：**贵族人格的广告片**：功能是把“**情绪的管辖权**”立为阶级准入标准——**棋可以输，脸不能变；身体穿帮（屐齿）由作者主动上报，反而加固叙事：会穿帮的克制比不穿帮更贵**。两则合观：**志怪教中国故事“怎么编”，志人教中国文学“怎么看人”——小说与散文的两条起跑线，六朝各发一枪**。
:::
:::

::: intuition 批评是文学的议会 {#int-yihui}
把六朝文学想象成一个新国家：《典论》是**独立宣言**，创作是**经济**，《文选》是**国土普查**，《文心》是**宪法与行政法**，《诗品》是**最高法院的判词集**——**一个文学共同体什么时候开始写宪法？答案通常是：当它不再需要靠生存来解释自己的时候**。所以“文学的自觉”（鲁迅题：曹丕的时代）不是觉醒瞬间，**是制度成型：有选本（谁算自己人）、有史（从哪来）、有品（现在谁第一）、有赋（怎么写）——四有青年才谈得上自觉**。这也解释批评的爆发为什么在齐梁：**门阀政治饱和，天才内卷进评论席——写不出《两都》，就写得出批评《两都》的规则；建安给文学发牌照，六朝给文学建议会，而议会的任期，将由下一课（唐代）的盛唐来投信任票**。
:::

::: history 三家遗产的账本 {#sec-sanjia}
**唐**：**传奇把志怪的“史笔”换成“文笔”——小说史上第一次公开承认自己在编**（《古镜》《枕中》一类仍借灵异外壳，而叙述人已站到台前台后）；《世说》被宋明笔记认作祖父。**宋**：**《太平广记》四百卷按类收罗，汉魏六朝志怪赖以粗全——宋人用图书馆保存了前代的夜话**；《世说》宋本系统确立（汪藻《世说叙录》记其传播），免遭“书经三写，鲁鱼亥豕”的散亡。**《文心》在唐**：类书引之、史家称之（刘知记其详——**唐人已认其权威而读者寥寥**）。**元明**：**《文心》至元明而显——刻本、评点（杨慎等）、入“合刻”之林：批评经典也要赶在印刷窗口出生**；**冯梦龙辑《古今谭概》《笑府》——《世说》的下沉市场：隽语变笑话，品藻变段子**。**清**：**四库总目尊《文心》为“文家之楷”一路定评；纪昀批点本把它拉进科举作文的参考书队列——经典化的世俗巅峰**；校勘辑佚接力。**近代**：**鲁迅《中国小说史略》立“鬼神与怪异”“记言（志人）”诸目，小说史由此立科；《魏晋风度及文章与药及酒之关系》把《世说》当“生活的文献”来读——“世说学”成俗成之学；《文心》进入“文学理论”教科书：批评的批评，古今同一汇率**。
:::

::: warning 读本课四坑
**以现代“小说”追认志怪**（**“小说”在汉志是十家最末、“小道”——六朝人写怪不叫创作；用“我国古代短篇小说”抬轿，等于替古人改行**）；**把《世说》当史料全收**（**它是“名士行为的选美相册”——同一事或出政治宣传；刘孝标注常常自己拆台——正文与注对读是最低门槛**）；**把《文心》读成“文学概论”**（**它是文体通史＋写作指导＋文学哲学，没有“总论—文体—创作—批评”四段的现代骨架，现代目录是后人拼的**）；**忘了三件发明同根**（**鬼神、名士、作品，全在“记录—分类—品第”的同一台机器上加工：六朝的天才是归档，不是灵感——目录学与志怪同龄，这不是巧合**）。
:::

::: exercise 刘孝标上岗 {level=1}
自选一条真实存在的《世说》短则（德行/任诞各一），**仿刘孝标注写两条注**：①**出处注**（人物仕履、事件另证，可查工具书）；②**纠谬或补充注**（指出矛盾或引异文）。附 50 字说明：你的注会**加固**还是**拆台**正文？
::: solution
判分：注体语言合规（“某某书曰／按／《晋阳秋》曰”级格式）；**拆台要拆得有证据**（“按：此人是时已死，不得与某共事”是刘孝标名手法——**注的荣誉守则：不引《世说》之外不可核对的材料**）；说明到位：志人集的信用来自“每条都有来源”，注就是**随身的审计员**。
:::

::: exercise 小论文：批评的黄金时代 {level=3}
写六百至一千字，评“**《文心》与《诗品》的问世说明：一个时代的创作达到临界质量，批评才会从序跋书信升级为专著**”。须调用：**《典论》《文赋》的“单篇阶段”**、**《文选》三十卷八类的“选文规模”**、**《诗品》的品第与源流**、**齐梁声律论战（永明八病一课为已知材料）**至少四项；并对照一个当代场景（**书评区／评分网站／文学奖项争议**任一）。
::: solution
判分点：临界质量论证（**没有《文选》级别的库存，就没有资格争吵库存——批评专著发生在选本之后：萧统与刘勰、钟嵘同时在，不是巧合**）；单篇→专著的形式跃迁说清（**《典论》是专栏，《文心》是周刊——系统化本身是新的文学野心——《序志》自道其志：笼罩纲领、弥论古今，**他要的不是意见，是体系”**）；当代类比对齐机制（**评分网站的“源流表”：算法品第＋粉丝刷评——钟嵘若在世会心一笑：品第从来不只是审美**）；结论敢设条件（“批评的黄金时代需要三个前提：库存、竞争、不可直说的空间——三者齐备，议会自动召开”，即 A）。

::: summary
收官结账：志怪（**史笔执照＋“鬼怪外衣，法理内核”——下游到《聊斋》与《故事新编》**）、志人（**头尾分裂的三十六门＝魏晋思想断层线；“克制＋穿帮”的速写语法**）、批评（**从执照到议会：选本定国土、品第排座次、《文心》立宪法**）。本课也是全课结账：**从“本无一字”到“本有一本书”——汉赋的帝国、史记的人物、乐府的街、古诗的无名、建安的牌照、正始的面具、田园的降级、山水的独立、民歌的两条岸，到六朝把它们归档、分类、品第——文学自觉不是口号，是一整套制度**。带着这套制度去唐代：那边，诗将第一次不需要解释自己为什么存在。
:::
