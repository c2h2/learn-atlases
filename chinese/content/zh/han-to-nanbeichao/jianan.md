---
title: "建安文学"
---

公元 196 年，汉献帝被劫到许都——**汉朝的最后一点体面搬了家，文学却在新房东的院子里提前进入黄金时代**。三曹七子聚在邺城，做了一件此前没人做过的事：**把写诗当作身份，把品评当作社交，把“文章不朽”当作官方口号**。本章讲这场“乱世里的文学自觉”。

## 三曹 {#def-sanzao}

::: definition 曹操：旧瓶的新酒 {#def-caocao}
**乐府旧题的劫持**：曹操全部名作都是**汉乐府旧题**——《薤露》《蒿里》（**挽歌写时政**：“**白骨露于野，千里无鸡鸣。生民百遗一，念之断人肠**”，自我标注“**歌以咏志**”——**用给死人唱的歌给时代验尸**。**后世径称《薤露》《蒿里》为“汉末实录”——“诗史”之名唐人都让给了杜甫，曹操是提前交卷的人**）；《短歌行》——**“对酒当歌，人生几何”“月明星稀，乌鹊南飞”**——**《诗经》成句随手拆装（“青青子衿”“呦呦鹿鸣，食野之苹”原样搬入），经学语汇第一次被私人抒情征用**；《步出夏门行·龟虽寿》——“**老骥伏枥，志在千里；烈士暮年，壮心不已**”——**写给自己五十三岁的养老保险：寿命“不只在天”，把天命论改判成奋斗论**。刘勰定评其诗只“**古直**”二字；钟嵘列曹操于下品，却认其“**甚有悲凉之句**”——**品第与名句的错位，是《诗品》最著名的冤案现场**）；**让县自明本志令**——“**设使国家无有孤，不知当几人称帝，几人称王**”——**政治自传口语的巅峰：不加粉饰的居功，本身就是文学史著名现场**。
:::

::: definition 曹丕：批评家皇帝 {#def-caopi}
**《典论·论文》——中国文学批评的第一篇专论**，四句话改变格局：**①“盖文章，经国之大业，不朽之盛事”**——**把赋从“童子雕虫”（扬雄悔词，[[classical-chinese-2/parallel-prose-fu]]）扶正为第二套立功系统：文帝亲自给文学发牌照**；**②“文以气为主，气之清浊有体，不可力强而致”**——**天才论：风格由天赋定，如声音之异，“虽在父兄，不能以移子弟”**（连曹丕自己也认输的一句）；**③“奏议宜雅，书论宜理，铭诔尚实，诗赋欲丽”**——**四科八体，“诗赋欲丽”四字把“美”正式写进文体的 KPI——抒情文学的独立宣言**；**④“文人相轻，自古而然”**——**中国第一句文学社会学：他比谁都懂，因为他是沙龙主持人**。《燕歌行》——“**秋风萧瑟天气凉，草木摇落露为霜，群燕辞归鹄南翔**”——**现存第一首完整的七言诗，句句用韵，却用塞外思妇的口吻**：**皇帝写思妇，是文体实验也是政治人设**。
:::

::: definition 曹植：骨气奇高 {#def-cao}
**前后期人生分界=建安文学最大的一次转折样本**：前期《白马篇》——“**捐躯赴国难，视死忽如归**”，**游侠儿形象=建安士人自我想象的标准照**；后期（夺嫡失败、屡徙封国）——**“骨气奇高，词采华茂，情兼雅怨，体被文质”（钟嵘《诗品》上品，几乎是给五言定的满分模板）**：《赠白马王彪》——“**心悲动我神，弃置莫复陈**”——**“莫复陈”三字压住全诗：可陈述的都删了，删剩的就是冤**；《洛神赋》——“**凌波微步，罗袜生尘**”——**楚辞人神恋爱母题的最后一朵浪花，也是“赋”向抒情小品的完美着陆**（[[han-to-nanbeichao/han-fu]]的大商场到此拆成一座水晶展厅）。**建安五言到曹植完成“由歌到读”**：乐府声口→十九首文人声腔→**曹植的骈偶、藻饰、章法——五言正式取得书面文学的独立户籍**。
:::

::: example 邺下沙龙：同题共作的发明 {#ex-yexia}
建安年间，曹丕曹植与王粲、陈琳、刘桢、应玚、徐干同游西园，**同一晚、同一题、各写各的**（《公宴诗》等同题群作存焉）。曹丕《与吴质书》追悼这场沙龙，逐一点评亡友：“**徐干时有齐气……应玚和而不壮，刘桢壮而不密**”——**各出一处短，是“文人相轻”的反面操作：哀悼式批评**。问题：①同题共作对文体演进意味着什么？②《典论》与《与吴质书》合起来发明了哪门新职业？
::: solution
①**同题=控制变量的文学实验**：题目、场合、韵律约束全同，**高下立见——诗歌第一次有了“横向评测”**：七子的风格标签（“遒”“密”“齐气”）**正是在这种并排写作里被读出来的**——**沙龙既是生产单位，也是批评的发生器**；公宴诗的酬答结构还造出**赠答诗**这一大传统（从此诗可以“发给某人”，唐诗的一半社交由此开工）。②**批评家＋文学史家**：曹丕把品评从“月旦品人”（许劭式人物鉴定）转成**品文**——**品藻的移植：先评人后评文，是六朝批评的基因**（[[han-to-nanbeichao/tales-criticism]]的《诗品》在终点等着接这一棒）；而他“不朽之盛事”的宣言，**把自己在位的十年变成了文学的立项窗口**。
:::
:::

::: intuition 乱世为什么出“风骨” {#int-fenggu}
“建安风骨”的当期形态是刘勰的八字：“**慷慨以任气，磊落以使才**”（《文心·明诗》）——**时代把“人生短”与“功业大”同时推到极限，诗的振幅被拉满**：《十九首》里士人对着白杨叹气（“**驱车上东门**”），**到了曹操嘴里，同样的朝露主题改写成“壮心不已”——同一个绝望，十九首用它酿酒，建安用它磨刀**。所谓“风骨”，后世（陈子昂、殷璠、王士禛各有一套）反复追认，但内核三件可通约：**情感的重量（不无病呻吟）、语言的骨力（不堆砌）、时代的现场感（不躲进书斋）**。**反直觉处在于：建安的“文学自觉”不是躲开乱世修出来的——它恰恰是被乱世逼出来的：寿命不确定、功业在眼前、文字是唯一能带走的东西**。
:::

::: history 一场追认的运动 {#sec-zhuiren}
**当期（196—232）**：邺城沙龙—曹丕《典论》—曹植后期——**创作、批评、典范三件套同时到位（文学自觉的证据链在生前就闭环）**；**东晋—南朝**：谢灵运“**天下才一石，曹子建独得八斗**”（《释常谈》所引——**“八斗”从此是汉语最高级**）——**曹植被从七子里拎出来单立为“骨气”的祖宗**；刘勰《明诗》给建安立档案“**暨建安之初，五言雄赡… 慷慨以任气**”；钟嵘《诗品》列曹植于上品，而**源流表里大批诗人“其源出于陈思”**（陈思王即曹植）——**批评史上头一回，某人成了别人的“户口来源”**；**唐**：**陈子昂《与东方公书》：“** 汉魏风骨，晋宋莫传**”**——**“建安风骨”作为武器出厂：拿它打齐梁宫体的靶**；殷璠《河岳英灵集》续用此旗；**宋**：**宋人开始翻案不平：有论者指曹植“骨气”之中杂有作气——“风骨”概念第一次挨了反冲**；**明**：前后七子“**汉魏古诗**”连读——**建安被并入“汉魏”这块更大的复古招牌**；**清**：王士禛专拈“**风骨**”为论诗核心之一——**概念完成独立：建安退居货架，风骨变成商品名**；**今**：“建安风骨”入辞书——**一场持续一千八百年的追认，把三个政客和一群幕僚的唱和，封成了中国诗歌的黄金标准**。
:::

::: warning 读建安四坑
**把“诗史”喊得太早**（曹操《薤露》《蒿里》是实录精神，**“诗史”是后世追赠的称号**——给任何诗人加“史”前先问：它记录，还是它被用来证明？）；**把三曹当纯文人**（**曹操是军事统帅、曹丕是皇帝、曹植是政治失败者——建安文学的全部张力来自权力现场**；把《赠白马王彪》读成“怀才不遇”就把它读小了——**那是囚徒的申诉状**）；**把“建安风骨”当客观标准**（它是陈子昂们**造出来的武器**——文学观念史的乐趣：先有靶子，后有招牌）；**忽略七子的流离出身**（王粲依刘表、蔡琰没匈奴、陈琳易主作檄——**“慷慨任气”有它的材料学：气从苦里来**）。
:::

::: exercise 横向评测 {level=1}
同题实验：仿邺下沙龙，与朋友（或自己分饰两格）以**同一题**（如“深夜的便利店”）各写一首八行内的新诗或打油诗，然后**仿《典论》句式互评**：每人一句“甲乙各有所短”（如“X壮而不密，Y和而不壮”）。
::: solution
判分：互评句**必须对仗工整、短处各异**（**同题评测的礼法：贬要贬得不重样**）；附一百字观察：**同题之下你能看出两人的“气”吗**——“齐气”式的慢、“逸气”式的冲——**把玄学词汇翻译成可核对的语言特征（节奏、用典密度、收尾习惯），才算把曹丕读懂**。
:::
:::

::: exercise 为悲剧写判词 {level=2}
蔡琰《悲愤诗》两处：“**马边悬男头，马后载妇女**”（被驱掳的队列）；“**儿前抱我颈，问母欲何之**”（归汉别子的瞬间）。任选一处写 200 字判词——**这首诗的“真”靠什么装置成立**（对照第 2 章“引源到人”、上一章“无面”）。
::: solution
参考：靠**第一人称的身体细节**（孩子的问话最狠——**细节的私人度与虚构成本成正比：编得出“白骨露于野”，编不出“儿前抱我颈”**）＋**自传体裁的信用背书**（诗题即声明：我经历过——**《悲愤诗》是“引源到人”的极端形：源头是作者自己的身体**）；判分：能指出**女性创伤叙事在文学史的孤峰地位**（此前史诗皆男性视角——**中国最长叙事诗《孔雀东南飞》写制度吃人，《悲愤诗》写战争吃人，且都出自/贴着受害者的口吻**——**汉魏叙事诗的双壁恰好都是边缘人的证词**）。
:::

::: exercise 小论文：文学自觉的账单 {level=3}
写六百至一千字，评“**建安是文学的自觉时代（鲁迅《魏晋风度及文章与药及酒之关系》）**”。须处理三方材料：**曹丕“不朽之盛事”宣言**（自觉的官方文本）、**曹植《与杨德祖书》里对“辞赋小道”的自贬**（“**岂徒以翰墨为勋绩、辞赋为君子哉**”——**他渴望的是立功**）、**邺下沙龙的实际生产方式**（应酬、同题、品评）。论：**“自觉”究竟自觉在什么——是认识到文学有价值，还是认识到文学有代价**？并给“自觉论”挑一处**概念毛病**（如：以宣言代替生产关系／以精英样本代替时代全貌）。
::: solution
判分点：矛盾材料用足（**哥哥说文学是不朽大业，弟弟说辞赋是小道而志在立功——“自觉时代”的当事人一个在抬价，一个在压价：自觉≠自恋**）；“代价”论成理（**文学独立=它开始有自己的行情，曹植的不甘正是行情的副产品——当“文人”成为一种身份，它就能被用作贬职**：曹操以文士为幕僚、曹丕以文章自重、曹植被“文人”标签误了一生——**身份的发明即牢笼的发明**）；概念毛病命中一处即佳（**鲁迅讲演本有现场语境；“自觉”若定义为“知道自己在做文学”，那么司马迁比曹丕更“自觉”——建安的发明不是自觉，是自觉的制度化：集团、品评、传世的三位一体**）；结论敢反方（“建安不是觉醒，是**上市**——文学第一次有了交易所、评级机构与股东”）者，A。
:::

::: summary
沙龙与会场结账：曹操（**旧瓶装新酒、挽歌验尸、朝露改奋斗论**）、曹丕（**四句宣言：地位、天才、分科、相轻——皇帝给文学发牌照**；《燕歌行》七言首演）、曹植（**由歌到读：五言取得书面户籍；“莫复陈”=删剩的是冤**）、邺下（**同题共作=横向评测，批评随沙龙出生**）、风骨（**当期是“慷慨任气”，后世是武器——追认一千八百年**）。方法一句话：**先问作品出自权力的哪个位置，再谈风格**——建安的每一句“人生几何”，都是边陲王侯与流亡士人同时开口。下一章玄学与毒药之间：正始文学，阮籍的八十二首“匿名诗”如何把不能说写成中国最隐晦的伟大。
:::
