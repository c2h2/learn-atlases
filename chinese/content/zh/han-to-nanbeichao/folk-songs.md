---
title: "南北朝民歌"
---

同一百年，长江两岸各有一套声腔：**南边是竹丝里的恋爱，北边是风沙里的生死**。更奇的是两边的“恋爱词”都不直说——南朝用**谐音**（“莲”即“怜”，“丝”即“思”），北朝用**距离**（一去就是雁门、葱岭）。本章发你两部词典，外加一面镜子：**这些“民间的声音”，经过了谁的采集与改写**。

## 南朝：谐音的爱情密码 {#def-nan}

::: definition 吴歌与西曲 {#def-wuge}
**两大产区**：**吴歌**——以建康为中心的吴语区家用之声（《宋书·乐志》于相和诸类外著录“吴歌”旧目——**俗乐成建制进正史音乐志**）；**西曲**——荆郢樊邓（襄阳江陵）水商驿路上的歌（**“西”是建康人的方位：沿江西上，商人重利轻别离——所以西曲多商妇送迎，吴歌多闺阁怀春**）。**“子夜”商标**：《旧唐书·乐志》采“晋代女子名子夜”之说——**今人只确知它是吴歌第一大曲，《子夜四时歌》即其“四季套曲”**。**密码系统三件套**：**莲＝怜（爱）、丝＝思、藕＝偶**——再加一个称呼：**“欢”＝爱人**（**歌里“欢”字一出口，恋爱现场即成立——这是南朝民歌的第一人称词典**）。“**春林花多媚，春鸟意多哀**”（《子夜四时歌·春歌》——**乐景写哀的民歌版：万物都成了失恋的共犯**）。
:::

::: definition 《西洲曲》的连环术 {#def-xizhou}
南朝乐府的**天花板**，先把技术拆干净：**①接字钩锁**（“**单衫杏子红，双鬓鸦雏色**”“**栏杆十二曲，垂手明如玉**”“**莲子青如水，置莲怀袖中**”——**莲＝怜、清＝情、莲心＝怜中心：谐音在此不是点缀，是承重墙——“情”字全篇不许出现，全由“莲”族代工**。**②季节轮值**（折梅寄江北，伯劳送夏，乌臼落秋，青槐摇春——四季物候逐个上岗——**一年相思用一年物候打卡：《子夜四时歌》的时间结构被放大成单曲**）。**③梦的通行证**（“**南风知我意，吹梦到西洲**”——**现实线全程无进展（望、上楼、垂手、出门），唯一成功的旅行是梦：南朝最文明的一句抱怨**）。**写定问题**：此篇文体近江陵一带南朝小调，**口口传唱又经文人润色——“民间”与“文人”在乐府里从来是合谋，不是对立**（[[han-to-nanbeichao/han-yuefu]]“混音台”原理的极致案例）。
:::

## 北朝：风沙的声腔 {#def-bei}

::: definition 鼓角横吹里的北歌 {#def-beige}
**保存渠道极讽刺**：北朝民歌的传世户头是《**梁鼓角横吹曲**》——**南朝梁的军乐档案，替北朝保存了他们的歌**（南北政权互抄歌单：音乐是乱世里唯一免签的外交）；《乐府诗集》总账存六十几首，**汉语译写为主、间存音译词——其中“可汗”二字最要紧：《木兰诗》“昨夜见军帖，可汗大点兵”——军帖里冒出的可汗，是北朝民歌的族徽：汉家女子的忠孝故事，户口落在北亚草原的征兵制上**。**三种声腔**：**征夫**（“**陇头流水，鸣声幽咽。遥望秦川，肝肠断绝**”——《陇头歌辞》：以水声写乡愁的声学蒙太奇，陇山是北朝人的“阳关”）；**游侠**（“**男儿欲作健，结伴不须多**”——《企喻歌》）；**马上天穹**（《**敕勒歌**》：“**天似穹庐，笼盖四野。天苍苍，野茫茫，风吹草低见牛羊**”——**本为北语之歌，译成汉语反而成了中国诗歌最短的史诗：《北史》记其军宴哀唱——翻译保住的原作，有时比原文活得久**）。**《木兰诗》：北歌的集大成**——“**不闻机杼声，惟闻女叹息**”，“**万里赴戎机，关山度若飞。朔气传金柝，寒光照铁衣**”，结尾“**雄兔脚扑朔，雌兔眼迷离；双兔傍地走，安能辨我是雄雌**”——**北朝的质朴与南朝的排偶在一首里合体；它与《孔雀东南飞》并称乐府叙事双峰：一南一北，一死一活**。
:::

::: example 对音实验：同一件“悲”，两种语法 {#ex-duiyin}
南歌把哀情外包：“**春林花多媚，春鸟意多哀**”（鸟代她哀）；北歌直报内脏：“**遥望秦川，肝肠断绝**”。再对南之委婉——“**南风知我意，吹梦到西洲**”——与北之坦率：《折杨柳枝歌》“**门前一株枣，岁岁不知老。阿婆不嫁女，那得孙儿抱**”（北朝催嫁词：母亲视角，直白到粗鄙，粗鄙到坦率）。问：**两套语法各自的修辞策略与社会土壤**。
::: solution
**南：外包系统**——情不可说（礼法＋沙龙文化），于是：①**物（莲、丝）代工**；②**鸟、月、风顶岗**（“春鸟意多哀”“明月照楼”“南风知我意”——**把情绪逐项迁出主体，诗读起来像风景，其实是病历**）——土壤：**市井＋宫廷的混居住区**（吴歌西曲被都邑乐署采编，**听众既有船娘也有萧衍们**：精致是混合客户的要求）。**北：内爆系统**——情直接说（“肝肠断绝”）、事直接问（“阿婆不嫁女，那得孙儿抱”——**把婚嫁写成库存压力：北歌的幽默是账房幽默**）；土壤：**战争与徙民社会**——征戍、牧养、民族杂居，语言的墙比南朝薄，**“欢”字在北歌里出现频率远低于南歌：北歌不经营恋爱，经营的是离别本身**。合订本判分句：**南朝民歌教你“爱怎么说得不直说”，北朝民歌教你“苦怎么直说”**——唐诗把两种语法都收编：王维学前者，王昌龄学后者。
:::
:::

::: intuition “民间”是谁的民，间是谁的间 {#int-minjian}
读南北朝民歌必须先照的镜子：**每一首“民间”都经过三道公文旅行**——①**采集**（乐署/都邑的耳朵先筛：什么“够味”什么被收）；②**书写**（从歌到文本：**记音、削长就短、删俗存雅——乐府机构是混音台**，[[han-to-nanbeichao/han-yuefu]]“麦克风也是国家递的”在此加倍成立：**这次的递话筒人还是南方朝廷，唱的是北人**）；③**类编**（郭茂倩按**乐器—场合—地域**归档：**档案的格子决定了我们今天“听见”的顺序**）。结论不是“全是假的”，而是：**民歌是民间素材与官方格式的化合物——它的“真”，在情感的一手性；它的“美”，在采集的二次性**。研究它的方法随之改变：**别只问“百姓怎么想”，要同时问“谁在什么时候、为了什么、把哪几句留了下来”**。
:::

::: history 一条河的两条岸 {#sec-liangge}
**汉魏**：旧乐府的骨架仍在（相和歌辞）；**东晋—宋—齐**：**吴歌西曲大盛于都邑**，《宋书·乐志》立档——**“雅”乐之外，俗乐首次成建制进入正史音乐志**；**梁陈**：**宫廷大量仿制**（梁简文帝诸王唱和——**吴歌的“婉娈”与宫体的“艳”勾连：南朝民歌的最后一批精品，客户是皇太子**）；**北**：**北歌入梁**（鼓角横吹：**梁代军乐队的“引进歌单”成了北朝民歌唯一的家**）；**北魏—周—隋**：**南北音乐互译加速**——隋立**七部乐、九部乐**：**胡俗乐在国家礼乐里分柜上架，唐“十部乐”承之**（**从民歌到国宾宴：乐工是南北朝到隋唐真正的统一战线**）；**唐**：**拟作不断而原生停止**——**李白《子夜吴歌》“长安一片月，万户捣衣声”：唐人把吴歌的声调拿回去写长安：模仿者比原作者更“自觉”**；**宋**：**郭茂倩总账**；**明**：**冯梦龙辑《山歌》**——**三吴新吴语民歌，谐音双关系统原样复活（“石”头、“丝”——中世纪密码的明代副本）；他为山歌作序刊行，公然以俗为真——**晚明出版家复刻“乐府”职能：民间之声再次需要功名人士的保荐**）；**清—今**：信天游、南无歌与“采风”运动——**从采诗到田野录音：**采集永远先于保存，这条铁律从《汉志》到今天没有改过**（比较：[[rhetoric/registers]]的“语域”视角——民歌=被官方语域转写的市井语域）。
:::

::: warning 读民歌四坑
**把民歌当“纯民间”**（三道公文旅行：化合物不是伪品——**但也别拿它做社会调查的一手材料**：“阿婆不嫁女”是歌词，不是户籍）；**把谐音当文字游戏**（**莲＝怜不是修辞彩蛋，是礼法社会的言说必需：密码本身就是内容——它记录了哪些话不能直说**）；**以“朴素”评优劣**（《西洲曲》的连环结构精致如瑞士表——**民间的“朴素”常常是工艺的隐身衣**）；**南北对立绝对化**（《木兰诗》一诗已杂交：**边境才是常态，江南与草原都是首都的偏见**）。
:::

::: exercise 密码编译 {level=1}
破译并加注一段“莲”族歌词（自选《子夜》或《西洲曲》数句），列**三栏**：字面（物象）／谐音（情意）／句意整译；然后**自创**一首四行“新吴歌”，至少用两个现代“谐音或双关”（**Wi-Fi、蓝牙、在线、掉线都可以是“丝”**）。
::: solution
判分：三栏不串位（**译义须能反推：若去掉谐音句子即崩，密码为承重墙——标注“装饰”者扣分**）；自创作达标线：**双关要有痛感**（“蓝牙断开”能承担“绝弦”，才算真的继承了莲怜系统——**双关的生命力=不可直说的程度**）。
:::
:::

::: exercise 声腔对比表 {level=2}
以《木兰诗》与《西洲曲》填**六维对比表**（场景/出行方式/时间结构/抒情策略/性别视角/结尾动作），写结论句：两首诗都写“等待与远行”，处理方式为何南辕北辙？
::: solution
参考：**结尾动作是关键证据——《西洲曲》止于梦（“吹梦到西洲”），《木兰诗》止于辨（“安能辨我是雄雌”的俏皮）：一个把无解交给南风，一个把性别问题笑纳为战利品**；结论句到位：**南歌处理“不得”，北歌处理“去了又回”——结构差异=生活方式差异（商贸城市的离散 vs 征兵社会的远征）**；填表若全凭印象无引句，不过。
:::

::: exercise 小论文：谁在替人民唱歌 {level=3}
写六百至一千字，评“**南北朝民歌是中国第一次‘流行音乐工业’的样品**”。须调用：**吴歌西曲的都邑市场**、**梁代宫廷仿制**、**鼓角横吹的跨境存档**、**冯梦龙《山歌》的晚明重启**至少三项，论**采集—改编—发行—怀旧**四环如何每代重开；并给一个当代案例（**短视频神曲翻唱／“世界音乐”采样／乐队改编古曲**任一）。
::: solution
判分点：四环齐全且有**主语**（**每环问“谁付钱”：都邑乐署、皇太子、军乐队、书商——“民间”是这条食物链顶端的风景**）；“重开”机制说清（**每一代都需要“真声”——但“真声”总是被重新发明：冯梦龙的序、梁武帝父子的唱和、今天的“原生态”舞台是同一动作的三种皮肤**）；案例对齐（神曲翻唱=拟乐府的抖音版——**旧瓶装新酒永远有效，因为瓶是渠道，酒才是需求**）；结论若写“**‘民间’不是来源，是每一代的自建电台——频率永远开着，台标轮流换**”，即 A。
:::

::: summary
两部词典一镜：南（**莲怜丝思＋“欢”字词典＋外包语法：风景即病历**）、北（**可汗的户口、肝肠断绝的内爆语法、军宴译曲——翻译比原文长寿**）、镜子（**三道公文旅行：情感的一手性＋采集的二次性＝民歌这个化合物**）、河（**乐工与拟作的统一战线流入唐：王维收南，王昌龄收北**）。方法一句话：**听见“人民的声音”时，先找递话筒的手**。下一章收官：志怪的小说、志人的隽永、《文心》《诗品》的批评——六朝给文学装上档案柜、镜子与判决书。
:::
