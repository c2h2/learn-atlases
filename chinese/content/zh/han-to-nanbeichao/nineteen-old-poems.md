---
title: "《古诗十九首》"
---

中国诗史上最尊贵的一组诗，**作者栏全部空白**。它们本不是“一组”——直到《文选》把十九首无名的五言诗订在同一页目录上，“古诗十九首”才作为一个名字出生。本章讲两件事：**它们怎么被选出来，以及为什么匿名反而成了最高级的署名**。

## 一组诗的出生 {#def-chusheng}

::: definition 十九首的“十九”从哪来 {#def-shijiu}
**原材料**：东汉后期（**约公元二世纪**）在洛阳流传的一批文人五言——“古诗”本是**相对的时代标签**（对南朝人而言，汉诗就是“古”诗），《文选》杂收无名氏旧篇，题曰“古诗”。**装订成组**：萧统《文选》“杂诗”类下选入十九首，**自创总题“古诗十九首”——从此十九首共一条命**：顺序是选家排的（**首篇“行行重行行”以叠字起势，末数章“驱车上东门”“驱车上东门”“出郭门直视”连哭坟区——**编出一条从离别走到死亡的弧线，是策展，不是家谱**）。**枚乘说的破产**：《文选》注引旧说“或云枚乘”——枚乘是文景时人，诗里却有“**驱车上东门**”（洛阳城门）与“**游戏宛与洛**”：**地名泄露天机，刘勰直斥此说为“疏”**。**定名学教训**：**我们以为在读“汉代诗集”，其实在读《文选》的一页目录——组诗的“组”，是选本的指纹**（[[classical-chinese-2/commentaries]]三查在此第一次实习）。
:::

::: definition 双子题与三副药方 {#def-yaofang}
**主题双子：空间与时间**。**离别**——十九首的抒情主人公是**两种移动的人**：出游干求的士人（“**还顾望旧乡，长路漫浩浩**”）与等他的妻（“**荡子行不归，空床难独守**”）：**帝国的交通网与选官流动，在诗里留下等距的双影——洛阳的大道，一半走人，一半走等**。**时间**——“**生年不满百，常怀千岁忧**”“**人生非金石，岂能长寿考**”；布景恒定：“**驱车上东门，遥望郭北墓**”——**洛阳坟区的白杨，是十九首的固定美术置景**。
面对“年命如朝露”，十九首开出三副药：**①立事**——“**何不策高足，先据要路津**”：**竞争意识明写在对官路的抢占上，是东汉游动社会的年轮**；**②行乐**——“**荡涤放情志，何为自结束**”、仙人王子乔不如**金樽美酒**（“服食求神仙”的上文正是“**极宴娱心意**”的自辩——**享乐被写成对死亡的答辩词**）；**③求仙**——然后**亲手戳破**：“**服食求神仙，多为药所误**”——**连安慰剂都失效，前两副药于是也显出苦味**：立事未必得、行乐无济于事、神仙是骗局——**三副药互相拆台，剩下的药渣就是十九首的“意”：在无效中继续活着的清醒**。这一自我拆台，是它比哲学诚实的地方。
:::

::: definition 古中之冠：匿名如何加冕 {#def-jiamian}
**声调之“古”**：十九首是**五言的成年礼**（[[han-to-nanbeichao/han-yuefu]]的民歌给了骨架，**十九首把它调成文人声腔**：不用典、不呼告、不铺陈——《文心雕龙》定评：“**婉转附物，怊怅切情，实五言之冠冕也**”——**“冠冕”=从此五言有了官方尺寸**）。**“无面”的美学红利**：钟嵘《诗品》置**上品**、估价“**一字千金**”——**因为无作者可考，读者无法用“生平”稀释诗句**：“**思君令人老**”的“君”可以是夫、君、理想、皇帝——**背景真空，语义过载：这是“无面之脸”的特权**。**加冕三级跳**：《文选》收（**入教材**）→《文心》《诗品》定等（**入批评**）→**唐代以后，“古诗”成为可拟可比的文体坐标——无名的诗生了一群有名的孩子**。
:::

::: example 《迢迢牵牛星》：一条河的修辞学 {#ex-qianniu}
“迢迢牵牛星，皎皎河汉女。纤纤擢素手，札札弄机杼。终日不成章，泣涕零如雨。河汉清且浅，相去复几许？盈盈一水间，脉脉不得语。”拆四个工位：①**叠字推镜头**；②**“终日不成章”的《诗经》引线**（“**虽则七襄，不成报章**”——《大东》）；③**“清且浅”的悖论**；④**“不得语”的收场**。
::: solution
①**六组叠字的运镜**：“迢迢”“皎皎”是**星空远景**，“纤纤”“札札”切到**织机的特写与声轨**，“盈盈”回到**河的中景**，“脉脉”**停在一张不说话的脸上**——**汉语最早的完整推镜头脚本，距离以叠字计量**。②“不成章”接通《小雅·大东》——**那篇西周诗经里牵牛织女早已“七襄”而“不成报章”：十九首把经星的怨，改写成家室的怨**（**牵牛织女从“星宿被赋役”变成“夫妻被河隔”：神话的人间化，发生在东汉**；银河=制度性隔离的原型：**“盈盈一水”从此是汉语里最短的天涯**）。③**清且浅是宇宙级的强词夺理**——**河越浅，隔越无理：物理的障碍从来不是重点，被授权不许渡才是；“相去复几许”的反问=把控诉伪装成算术**。④**“不得语”**：全诗唯一动作是没有动作——**泣如雨而不得语，眼泪是语言的破产报告**（对照《上邪》呼天发誓：**汉乐府的民间嗓门是“上邪！”，十九首的文人嗓门是“脉脉不得语”——同是不平，一宣判，一吞声：声口之别即阶层之别**）。
:::
:::

::: intuition 五言为什么是“默认声腔” {#int-wuyan}
本课可做的实验：**把十九首压成四言**（“行行重行行”→“行行日远”？）——**意义保住，叹息没了：五言多出的那个字，正好是叹息的容积**。
:::

::: history 无名的胜利 {#sec-shengli}
**东汉末—魏晋**：古诗在传抄与宴集中流通，《文选注》所引“枚乘”说存其争议；**六朝**：《文选》装订成组——**组诞生**；《文心》“**五言冠冕**”、《诗品》上品——**批评界给无面者拍板：它是一切五言的祖先**；**唐**：**陈子昂“汉魏风骨”的“汉”，主力就是这批古诗与乐府——复古口号里的“古”，由无名氏供货**；**宋**：**严羽《沧浪诗话》把“古诗”列为体裁之首——选本变成诗学的户口**；**明**：复古派账本上，十九首是“**五言古诗之祖**”的头名债权人；**清**：**沈德潜《古诗源》以十九首开卷——“祖”字辈封顶**；**近世**：**朱自清《诗言志辨》、马茂元《古诗十九首探索》——学术化还乡：把“无面”还原回东汉洛阳的求职青年与空房妻子（作者第一次被推测出来：不是个人，是一类人——失意士人）**——**无名的胜利在此完成：它们不需要作者，它们需要的是历史**。
:::

::: warning 读古诗四坑
**把“组”当天团**（顺序与弧线皆选本编排——**从“离别”读到“死亡”是《文选》的策展**）；**坐实“君”是谁**（“**思君令人老**”的“君”至少四种读法而诗不表态——**言情与咏物之间的“比兴悬置”正是它的生态位**；硬做索引会把诗读薄成请假条）；**以为“无名=朴素”**（**朴素是效果，不是成本**：刘勰赞的恰是“婉转附物”的精准——**不事雕琢是最高级别的匠气反转**）；**用盛唐标准嫌它没有奇迹**（十九首的力量在**无事件**：没有战争、没有奇遇，只有季节和等待——**它证明了抒情诗可以不靠故事活着**）。
:::

::: exercise 装订师 {level=1}
重排实验：从十九首中自选**六首**，按你认为的合理顺序编成一组，写 150 字“策展序言”（仿《文选》逻辑：或按情绪曲线，或按昼夜，或按男女视角）。再对照原序，说出**原序比你高明（或不如你）的一处**。
::: solution
判分：**六首的选取与排序须同一逻辑贯穿**（如：春→秋→坟→悟：一条“看见时间”的路）；序言里**至少引用两句诗作展品标签**（用典即用法）；对照环节诚实——**原序的弧线是“从走路到躺下”（叠字起势，连哭坟收束）：你能指出这一层即通**。
:::
:::

::: exercise 荡子妇的家书 {level=2}
任选一首，**以等待者第一人称**改写为 300 字家书：**只许使用该诗文本内出现的名词作意象**，但可用现代汉语与当代场景。附 50 字自评：哪个意象最难搬，为什么？
::: solution
判分：**意象零外援**（“白露”可以搬进出租屋的窗台；“**胡马依北风，越鸟巢南枝**”可以搬成**手机里两张不同城市的地铁卡**——**移植的是机制（本能的朝向），不是器物**）；情绪保住“吞声”档（**不哭天抢地——十九首的分寸感是本题的隐藏考点**）；自评说出难点＝“**不得语**”最难：家书体裁天生要它说话，而原诗的力量恰恰是说不出口——**体裁与原文的拉锯即本题全部**。
:::
:::

::: exercise 小论文：无名为诗之极 {level=3}
写六百至一千字，论“**作者栏空白是十九首最大的文学制度**”。须调用：**枚乘说的破产**（地名内证）、**钟嵘“一字千金”**、**陈子昂式的“复古”需要无名的古**至少三项史实，并对比一件当代文本现象（**白噪音乐库无署名流行曲／网络传言的“有出处吗”／无字幕默片修复**任选其一对齐机制）；最后回答：若考古挖出十九首的确切作者，**它们会降级吗**？
::: solution
判分点：史实调用准确（**地名内证杀掉枚乘说=《尧典》式跨线验证在文学史的复现——常识课与注释课双双及格**；“一字千金”是**读者对无面的定价**；复古需要无名——**有名则有其人，其人即其局限，无名的“古”因此是无限额度的信用**）；类比对齐机制（无字幕默片修复≈无背景的诗句——**语境的消失同时是损失与解放**）；“降级”之答须给出**两种价值**（文献价值↑：作者、年代、本事全部到货；**“无面价值”↓：悬置特权作废**——**能分清两种价值即 A**；若反问“我们真的愿意知道作者吗”并说明理由，加精）。
:::
:::

::: summary
出生证明与加冕礼结账：装订（**“组”是《文选》的指纹**；枚乘说被地名击穿）、双子题（**离别×时间**：荡子与思妇=帝国交通网的正反影；**三副药方与自我拆台**）、声腔（**五言巡航速度：多出的那个字是叹息的容积**；“白露是闹钟”“衣带日已缓：身体自己报告思念”）、加冕（**无面之脸：背景真空，语义过载**；拟“古”者盈箱——**无名的诗生了有名的孩子**）。方法一句话：**读到“古诗”二字，先问谁把它称作古——“古”是追认，不是属性**。下一章进邺城：建安文人如何在战乱的间隙里，第一次大声谈论“文章不朽”。
:::
