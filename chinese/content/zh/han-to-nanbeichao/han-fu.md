---
title: "汉赋"
---

帝国需要一种配得上自己的文体：**字要多，物要全，气势要铺到纸外**。汉赋就是这份需求的交货单——它把楚辞的抒情器官切掉，换上一副**百科全书式的肺**：一口气三千字不换气。本章教你既逛这栋巨型商场，也看清它的消防通道（“讽”）为什么总是锁着。

## 赋的族谱 {#def-zupu}

::: definition 从骚体到巨赋 {#def-santi}
**一名两祖**：“赋”本义是**铺**（铺陈其事）——刘熙：“赋，敷也，敷陈其志”一体两名；它的**生理父亲是《楚辞》**（句式、兮字、香草、巫气——[[pre-qin-literature/songs-of-chu]]），**制度父亲是荀子《赋篇》**（“隐语式咏物”，**命名者即荀况**——《赋篇》“礼”“知”“云”“蚕”“针”五篇，**史上第一个用“赋”命名的文体**）。**四段进化**：①**骚体赋**（汉初：贾谊《吊屈原赋》《鵩鸟赋》——**楚声的流亡者文学**：被贬的长沙王太傅，把屈原的河照原样再渡一遍）；②**大赋定型**（枚乘《七发》：**八段问难，七件事皆不治“太子”的病，末以“要言妙道”一针见效——“七”自此成为文体代名词**，刘勰称之为“**赋首**”——**大赋的商场、问难的骨架、劝百的商业模式，全部在这一篇交货**）；③**大赋全盛**（司马相如《子虚》《上林》《大人》——**帝国样板间落成**；扬雄“四大赋”《甘泉》《河东》《羽猎》《长杨》——**皇帝游行的高清转播**；班固《两都》张衡《二京》——**首都比稿会：写赋=给城市投标**）；④**抒情转向**（东汉后期：张衡《归田赋》开田园先声，王粲《登楼赋》、祢衡《鹦鹉赋》——**大商场拆伙，赋退回书房：体物让位给写志**）。六朝小赋与骈赋接棒——**[[classical-chinese-2/parallel-prose-fu]]已见其“铺采摘文，体物写志”的定义，本章走它的前半生**。
:::

::: definition 大赋的三层构造 {#def-gouzao}
**第一层·问难格局**：《子虚赋》三张假名片——**楚使子虚、齐人乌有先生、亡是公**——**三人均为虚构，姓名即论文论点**（子虚＝子虚，乌有＝乌有，亡是公＝无此人——**用人名写批评文章，是中国文学最早的元小说装置**）：子虚夸楚、乌有夸齐、亡是公把俩人的家乡**按在地上铺**，最后替天子“讽”——**结构即政论：地方炫耀被中央炫富收编**。第二层·**铺陈目录学**：上林赋的数据库——山有山的字库、水有水的字库、果木有果木的货架（《七发》早已示范：饮食、舆马、声色、田猎、观涛——**一场一间的博览会**；联边字“**金、玉、草、虫、鱼、龙**”偏旁成行——**汉字字形的烟花：意义之外，字面本身就是排面**）。第三层·**道德回执**：曲终奏雅。收束公式：夸到极限后**主角忽然醒悟、罢猎/省囿/与士民同利**——刘勰概括为“**劝百而讽一**”——**一百分铺张买一分讽谏，汇率从一开始就不对**。
:::

::: example 上林赋的一页：字面烟花 {#ex-shanglin}
用本课已确立的材料出题：①子虚—乌有—亡是公的三峰结构如何完成“地方→中央→天子”的权力梯次？②赋中“**发仓廪以赈穷民，开田畴与百姓同之**”一句的史实效力（它是汉武帝的政策，还是赋的虚构？）？③若删去道德回执，这篇赋的**政治含义会反转吗**？
::: solution
①三峰=三级台阶：**诸侯互夸是战国遗留（子虚、乌有的口气像外交辞令），亡是公的碾压是帝国新语法——文学结构精确复刻政治整合**；细读法：**给每张假名片标“发言时长”——铺陈字数就是话语权配额**。②赈穷民、与百姓同之是**赋的应然句式，不是纪事**——《史记》《汉书》的武帝本纪里没有对应诏令能对上这段“开放上林”——**把文学当史料前，先查它是不是文体的固定配件**（教训：道德回执**属于赋，不属于朝廷**）。③会反转：**没有回执的铺陈是煽动，有了回执才叫“讽”**——赋的政治安全资格全凭这条尾巴；但读者只剪尾巴不读正文（**历代传抄里，被摘录传播的永远是铺陈段**），所以“劝百讽一”不是失败，是**这种文体的正常工况**。
:::
:::

::: intuition 炫富文学的心理学 {#int-xuanfu}
大赋是**人类最早的大型品牌宣传片**：汉武帝读《大人赋》《史记》记载：“**天子大悦，飘飘然有凌云气，游天地之间意**”。**天子读自己帝国的赋，读成了修仙广告——甲方本人是第一个观众**。据此可拆炫富文学的三拍子：**一、把体量本身审美化**（字数、物数、地名数=国力仪表盘）；**二、把读者变成游客**（赋不要求你信，只要求你**逛**）；**三、用道德回执给快感发免税证**（“讽”=让皇帝**既玩了又自省了**的一站式服务）。这三拍在今天的**城市形象片、财报、大厂年会**里原样复现——所以汉赋不是死文体，**它是“宣传片”这一古老文体的初版源码，注释都还写得一样**。
:::

::: history 赋的宫廷与退潮 {#sec-ting}
**汉初**：诸侯王养赋——**吴楚七国之乱（前 154）前后，梁孝王的梁园是第一个赋派总部，枚乘《七发》即梁园出品**；贾谊以贬官之身为王朝写下骚体备忘录；**武帝**：**乐府采诗与词赋待诏同年挂牌——朝廷同时买下“街头的声音”与“帝国的修辞”**（**上林诸赋献给一个正在开边的朝廷，文体与国运同步扩容**）；宣帝为词赋辩护，将其与“贤于倡优”并列——**宫廷承认它是高级娱乐**；**成帝**诏求遗书，**扬雄以赋见知，“天子令尚书赐笔札”**——**皇帝给文人发稿纸，汉代作家的最高待遇新闻**；王莽篡汉之际，**扬雄以耆老被召受典**，素以迟暮寂寞自处——**《方言》的编纂与天禄阁的官司，成为“学者与改朝换代”的著名悬案**——**大赋的时代随帝国财政一起结账**；**东汉**：首都比稿（《两都》《二京》）、鸿都门学以书画辞赋取士（灵帝——**赋第一次进入考试系统，虽被正统侧目**）；**建安**：邺下文人**王粲《登楼赋》、曹植《洛神赋》——大赋的架子拆了，改盖抒情的小楼**；**六朝**：赋骈合流（[[classical-chinese-2/parallel-prose-fu]]），**刘勰《诠赋》盖棺：“** 铺采摘文，体物写志**”——墓志铭写得比死者还体面**。
:::

::: warning 读赋四坑
**背字库当读懂**（大赋的难字是**设计出来的门槛**——生僻联边字的功能是“壮观”，不是“准确”；**先读结构，再查字**）；**把讽谏当史实**（“与百姓同之”是文体配件，不是政策记录——上例②已判）；**以抒情标准判大赋死刑**（“汉赋没有感情”——**它本来就不是为你这套抒情系统开发的**；六朝人嫌其“铺张扬厉”，宋人又嫌律赋“俳”，各朝都在用自家口味改判——文学批评史很大部分是**口味的翻案记录**）；**忘了赋是念给耳朵的**（“**不歌而诵谓之赋**”——班固《汉志》：赋是**朗诵艺术**的脚本，默读丢掉了它一半的能量；默读它的皇帝，才把赋变成文学）。
:::

::: exercise 结构测绘 {level=1}
读《七发》（节选即可），给八个部分画出**问难电路图**（谁发病、谁开方、为何前七帖无效），并用 100 字回答：**为什么“要言妙道”必须放在最后一帖，早一帖或晚一帖会怎样？**
::: solution
判分：**七帖的感官升级序列**（音乐—饮食—车马—游观—田猎—观涛—要言：**刺激逐级加码，正好是大赋的样板间动线**）；末帖的解释到位：**身体之病是修辞的病，只有话语能治——太子“据几而起”——**痊愈发生在“听”的瞬间：赋的世界观里，聆听即治疗即教化**；能联系自身经验（被广告“最后一句价值观”治好）加分。
:::
:::

::: exercise 博览会写作 {level=2}
仿《七发》《上林》的货架模块，为你的学校/城市写一段**三百字“炫富赋”**：一个问难框架（两位夸家乡者＋一位降维者）、一组联边或同类名单（食堂菜单、奶茶全糖榜皆可）、**一张道德回执**收尾。自评：你的回执能拦住正文吗？
::: solution
判分：**名单必须“升过维”**（按数量、稀有度或荒诞度排序——**目录学是动词不是名词**）；降维者的发言要**比双方加起来更横**（否则结构塌）；回执的无力要诚实写出（**“劝百讽一”是你自己判的汇率**）；若名单读起来像年报——恭喜，**你已与汉代赋家接通**。
:::

::: exercise 小论文：大赋的政治经济学 {level=3}
写六百至一千字：“大赋是一场**朝廷、作家与读者的三方交易**——朝廷买排面，作家买待诏，读者买奇观；讽谏是合同的免责条款。”要求调用：武帝读《大人赋》而大悦、扬雄“雕虫篆刻，壮夫不为”之悔（[[classical-chinese-2/parallel-prose-fu]]已见，此处径引）、梁园与灵帝鸿都门学（**赋的赞助制与入仕功能**）至少三项史实；并分析一个现代同类文本（城市形象片/财报年会/游戏开放世界任一）。
::: solution
判分点：史实准确（**武帝大悦说明甲方亲自上钩；扬雄之悔是作者对交易条款的追诉；鸿都门学=赋的制度胜利与品位失败同时发生**）；“三方交易”模型须被**至少一处反例**测试（如《上林》的赈穷句无人执行——**免责条款从未理赔**）；现代类比对齐机制（开放世界游戏：地图的**收集率**=目录学的当代转世；“本作纯属虚构”=道德回执）；结论若能承认“**讽刺条款的意义不是生效，是使全文得以合法**”，即 A——这句话本课已在例题②预付，论文须付尾款。
:::

::: summary
商场导览结账：族谱（楚辞父＋荀赋父；骚体—大赋—抒情四段）、构造（**三张假名片的问难格局、联边字烟花、道德回执**）、心理（宣传片三拍子：**体量审美化、读者游客化、快感免税化**）、命运（梁园总部—宫廷待诏—鸿都入试—邺下拆楼—《文心》盖棺）。方法一句话：**读赋先读它的合同结构，再读它的辞藻；问“讽给了谁”，再问“钱从哪来”**。下一章出商场进史馆：司马迁如何在竹简上建造一座让帝王也走不出去的人物迷宫。
:::
