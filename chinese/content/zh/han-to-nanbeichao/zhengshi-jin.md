---
title: "从正始到两晋"
---

建安的文人在权力旁边写诗；接下来的一百年，**写诗本身变成高危职业**。249 年高平陵之变后，名字签在哪边就是哪家的鬼——于是诗歌学会了三件事：**装哑（阮籍）、清单式自杀（嵇康）、把说理当避难所（玄言）**。本章穿过三层迷雾，去找每一层下面那张脸。

## 正始：面具的发明 {#sec-zhengshi}

::: definition 玄学、清谈与两位嵇阮 {#def-zhengshi}
**背景板**：何晏注《论语》、王弼注《老》《易》——**“以无为本”把经学宇宙论拆成本体论，士人第一次集体讨论“存在本身”**；**清谈**＝有剧本、有裁判、有观众的哲学竞技（**“谈”是表演：羽扇、麈尾、一坐皆倾——沙龙从邺下的诗会升级为目的部**）。**阮籍《咏怀》八十二首：隐晦的工程技术学**——比兴、神话、游仙、怀古轮班上岗；刘勰的三字定评“**阮旨遥深**”：**每首都像有所指，每首都不肯坐实**——这是**在告密成本为零的时代发明的抒情协议：作者不签字，文字就不能当呈堂证供**（司马昭为儿子求婚，阮籍**连醉六十日**——**用身体拒绝联姻，与用诗歌拒绝注释，是同一技术**。)**嵇康：把个性写成法律文书**——“**非汤武而薄周孔**”（《与山巨源绝交书》）——**表面开除名教，实际开除的是司马家“以孝治天下”的招牌**（**司马氏得国靠“禅让”的礼法程序，最经不起人追问忠孝的原件**）；书里列“**七不堪二不可**”——**起床困难、案牍劳形、吊丧装孝：以生活清单拒绝出仕，是“人格”作为中国文学主角的第一次完整亮相**；刑东市，**《广陵散》于今绝矣**——**死前挑一首曲子的断头台发言：传说层累到《世说》，人物就已比史料更著名**。
:::

::: definition 太康：陆机与左思的两副牌 {#def-taikang}
**晋武帝年号太康（280—289）：统一短暂、门第长存**。《文心》断代：“**缛旨星稠，繁文绮合……采缛于正始，力柔于建安**”——**修辞的大爆炸与骨力的退潮同时发生**。**陆机：形式主义的开山**——吴郡亡国世孙入洛，《文赋》**中国第一篇创作心理学**（“**遵四时以叹逝，瞻万物而思纷**”），而**“诗缘情而绮靡”六字才是核弹：把“赋欲丽”（曹丕）扩编为诗的正式定义——情＋美感，对“言志”的官方口径搞了政变**（[[han-to-nanbeichao/jianan]]的牌照到他手里改成了营业范围）；**《拟古诗》十二首：拿《十九首》做对偶与声律的靶场——“模拟”自此成为中国文学的正经训练（拟、效、仿、集句，一整套“与古人合奏”的体裁从陆机开工）**。**左思：反着打**——《咏史》八首：“**世胄蹑高位，英俊沉下僚。地势使之然，由来非一朝**”——**咏史体至此定型：历史不是教训库，是当前的社媒评论**；《三都赋》十载构思，**洛阳纸贵**——**抄写时代的爆款度量衡：纸价即印数**；钟嵘上品，赞其“**文典以怨，颇为精切，得讽谕之致**”——**“左思风力”后来成了“风力”的同义词：形式年代里，骨气以反姿态成名**。
:::

::: definition 东晋：玄言与它的裂缝 {#def-xuanyan}
**主流**：《文心·时序》“**自中朝贵玄，江左称盛；因谈馀风，遂成俗好；是以诗必柱下之旨归，赋乃漆园之义疏**”——**诗变成道德经的脚注：中国诗史上唯一一次“哲学赢过诗”**。但要按三条裂缝读：①**郭璞游仙**——“**游仙”一体在他手里“坎壈咏怀，非列仙之趣**”（《诗品》大意）：**仙乡是流亡士人的心理版图，列仙之趣的背面是陆地通胀**；②**兰亭（353）**——王羲之《兰亭序》“**一死生为虚诞，齐彭殇为妄作**”——**玄学内部对玄学的翻脸：把“齐物”的药打翻在地，痛感重新进场**；雅集群诗（孙绰、谢混诸作）仍在说理，**但理由说给山水听：理语里第一次留出了风景的台词**——**玄言不是山水的敌人，是山水的产科**；③**支遁**——以佛理解《逍遥游》，**新理层出，群贤莫之折**（《世说·文学》）——**般若学挤进清谈场子：玄学的下一棒交给佛学，诗的下一个题材（山居、登临、讲经声里的林泉）也换了赞助人**。
:::

::: example 一组假名片：李陵苏武的五言赠答 {#ex-lingwu}
《文选》“杂诗”收**李陵与苏武赠答数首**——“**携手上河梁，游子暮何之**”，**叙公元前 99 年的生离，用的却是纯熟的五言**；**其伪为现代学界通说**。问题：**伪作凭什么成立？它冒充的是哪个时代的信用？**
::: solution
**判伪的三条线（本课方法总复习）**：**①语言断代**（五言的成熟度、词汇的晚期特征——**比喻与套语的语料年龄藏不住**；阎若璩式跨线验证的文学版，[[classical-chinese-2/ancient-culture]]四线合围）；**②史实无着**（《汉书》录陵事而无诗，赠答的行事不见史传——**史无其事的唱和＝小说式情节**）；**③文体年代错位**（酬赠诗的“杂诗”格式属汉末魏后——**建安之后才有“以诗寄友人”的文学习惯**，上一章同题共作可反证）。**它冒充的是“汉代”的信用——而信用恰恰是当时文坛最缺的东西**：五言需要一个光荣的祖先（**“古诗”无名，正好给无名者发身份证**）。**文学史的二账**：**伪作的价值不减——它们是“假面抒情”的成品：后人戴上李陵的脸来哭自己的别：拟（陆机）、托（古乐府）、代（代言体）同属一族：主体不敢署名，于是发明角色**。结论句式：**它不是李陵的诗，它是汉魏之间无数离人共用的那张脸——断代断到作者是新闻，断代到一类人，才是文学史**。
:::
:::

::: intuition 一百年，四种处理“我”的办法 {#int-siZhong}
把镜头拉快：**建安（196—220）：“我”上场**——“老骥伏枥”当众自报壮志；**正始（240—254）：“我”戴面具**——阮籍的“我”在八十二场梦里换装，一个都不签字；**太康（280—289）：“我”换工装**——陆机以精密修辞盖住亡国创痛，把个性交给格律；**东晋（317—405）：“我”去住院**——玄言把情绪托管给“理”，诗成了疗养院。**四种反应是同一个人格在不同压强下的形态**：压强升高，抒情从广场退进密室、从署名退进咏怀、从语言退进沉默——**但注意最后一跳：兰亭那天，一死生被宣布为虚诞，痛感出院，下一站山水（[[han-to-nanbeichao/landscape-yongming]]）：“我”将在风景里重新署名**。
:::

::: history 从清谈到讲经 {#sec-qingtan}
**249** 高平陵之变——名士减半，清谈搬家（**从政论谈向本体论谈：安全的题目是时代的体温计**）；**262** 嵇康东市行刑，**《世说》层累成“金属人格”的神话**（**访钟会“何所闻而来，何所见而去”的机锋提前把死刑写成行为艺术**）；**289 前后** 陆机入洛—**八王之乱卷入，临刑叹“**华亭鹤唳，岂可复闻乎**”——南士北上的幻觉以死刑结账**；**300 前后** 左思《三都赋》**洛阳纸贵**——**手抄时代的传播奇迹，赋的最后一次顶流**；**311** 永嘉之乱——**刘琨并州孤守，存诗两首皆血：“**何意百炼刚，化为绕指柔**”（《重赠卢谌》）——“风骨”在北方围城里的最后一支火炬**；**353** 兰亭——**禊事＋诗＋序＋书法：一场雅集成为后世千年“文人活动”的模板**（[[classical-chinese-2/books-editions]]的装帧五变在此有了主场）；**360 年代** 支遁以佛解《庄》——**清谈的裁判席第一次坐进沙门**；**405** 陶渊明辞彭泽——**玄言的下一个对手不是山水，是“真”（下一章）**；**梁陈以降**：**《文心》成书，给整个魏晋盖棺——前引“**采缛于正始，力柔于建安**”十字——**批评史把百年写成十个字，从此后人想吵架也只能在这十个字的框架里吵**。
:::

::: warning 读魏晋四坑
**把玄言诗一律读成“倒退”**（**它是哲学赢过诗，也是诗给山水让位的必要阵痛**——评分前先问它服务的功能）；**把“归趣难求”当理解失败**（**多义是功能不是故障**——阮籍的安全靠的就是永不坐实；**坐实派每赢一首诗的本事，就输掉一个时代**）; **用伪当史**（李陵诗不能用来证明西汉有五言——**但能完美证明五世纪的人需要李陵**）；**把绮靡读成堕落**（**形式感是修辞库的扩建**：没有太康的“绮靡”，永明声律没有材料——[[han-to-nanbeichao/landscape-yongming]]见账）。
:::

::: exercise 咏怀破译 {level=1}
选《咏怀》其一（“夜中不能寐”）与任一首带神话的（自选），做**双栏注释**：左栏“可坐实”（字词、典故出处），右栏“不可坐实”（指谁？何事？）。然后写 80 字：**右栏的空白是缺陷还是结构？**
::: solution
判分：左栏**典故到源**（“**薄帷鉴明月，清风吹我襟**”白描无须典；引《庄》《骚》处给到篇名）；右栏诚实留白；结论达到这一层即优：**右栏是设计——咏怀体＝给不可说留的合法格式（“咏怀”二字即“只报心情，不报事由”——题目本身就是免责声明）**。
:::
:::

::: exercise 给玄言诗翻案书 {level=2}
立论材料只能用可核引文——《文心》：“**诗必柱下之旨归，赋乃漆园之义疏**”。写 250 字翻案书：**把玄言诗辩护为“**山水诗的产科”与“语言减压试验场**”，限用一个本课术语、一个当代类比（**概念音乐／极简主义／播客时代**任选）。
::: solution
判分：**机制论证**（理语把景物从“比德工具”的位置上**卸任**了——**山不再必须象征仁，水不再必须象征义：象征任务解除后，风景才有机会只是风景**——这一步是山水独立的前提）；术语调用准（“采缛于正始，力柔于建安”是判决，也是分期）；当代类比对齐功能（极简乐把旋律**让位**给音色——玄言把形象**让位**给概念，**让位本身是下一场革命的议程**）。
:::
:::

::: exercise 小论文：伪作、假面与匿名 {level=3}
写六百至一千字，串联本课三案：**李陵赠答的伪**、**阮籍咏怀的隐**、**陆机拟古的仿**。论：“**当署名的代价过高或信用不足，文学会发展出一套身份技术**。”须给出三案各自的身份技术名称（**托名／隐晦／模拟**）、一个共同机制、一个当代对照（**小号发言／AI 生成／匿名投稿**任选）；并回答：**文学史需要伪作吗**？
::: solution
判分点：三案技术各有一句定义（**托名＝借古人的信用；隐晦＝删自己的签字；模拟＝拜古人为监护人**）；共同机制：**身份即体裁——文学史上的“作者”有时是一种文体配置**；当代类比不猎奇（**小号=当代的“托名”：匿名使诚实成为可能——正如阮旨遥深使抒写成为可能**）；“需要吗”之答：能答“**需要其伪，不需要其欺**”（伪作是时代的证词，作伪是出版的污点——**分开记账**）即 A。
:::

::: summary
地下时期结账：正始（**面具：咏怀的匿名协议＋绝交书的清单人格——“非汤武薄周孔”打的是招牌不是经典**）、太康（**工装：“缘情绮靡”的营业范围改革＋模拟作为训练；左思以反姿态成名**）、东晋（**疗养院：哲学赢过诗，但三道裂缝——游仙、兰亭、支遁——正把钥匙递给山水**）；李陵案（**断代断到作者是新闻，断到一类人才是文学史**）。方法一句话：**先问这首诗敢不敢署名，再问它想不想出名——魏晋的全部秘密在署名方式里**。下一章：一位真的把印挂了的人——陶渊明，中国文学史上最安静的革命。
:::
