上一章领了档案，这一章进剧场：五百四十年的兴亡，被写成一部有分镜、有伏笔、让人物自己说话的长篇——韩愈说“《春秋》谨严，《左氏》浮夸”，这个“浮夸”正是叙事的胜利。

## 书与学 {#sec-shu}

::: definition 左氏档案 {#def-zuo}
《春秋左氏传》：以史事解《春秋》的“传”（另有公羊、穀梁二今文传——**《左氏》长于事，《公》《穀》长于义**，经学古今文的第一战场即此），记事迄鲁哀公二十七年（前 468），旧题鲁太史左丘明；作者两千年无定谳，学界多视为**战国早期**学者编缀各国史官纪注与“语”类文献而成。最大的文学遗产是**战争书写与行人辞令**：城濮、崤、鞌、鄢陵诸役并世称奇，子产、晏婴、叔向的政论与数百场外交流亡列于其后。经传对比最见性格：经书“陨石于宋五”六字，传中相关的世界却是诸侯聘问、占卜、梦境与朝议的洪流——**《左传》不是《春秋》的注脚，是先秦叙事的全部家底**。韩愈“《春秋》谨严，《左氏》浮夸”，“浮夸”实为**叙事的胜利**。
:::

::: definition 叙事的四大兵器 {#def-bingqi}
①**全局与分镜**：大战先排棋盘再给特写——城濮之战，先铺“退避三舍”的恩怨账与战前外交连环，镜头再落到战场分路合击；鞌之战全局是晋齐争霸，特写却是战车上一句血话：“自始合，而矢贯余手及肘，余折以御，左轮朱殷，岂敢言病”（解张）——**宏观史与微观人同框**，中国战争文学的出生证明；②**预叙**：卜筮、梦、人物判词让结局先悬着——崤之战前蹇叔哭师：“吾见师之出，而不见其入也”“勤而无所，必有悖心”——老臣的预言全程待兑现，读者看的是**过程如何兑现命运**；③**记言即性格**：宫之奇以“辅车相依，唇亡齿寒”的常识雄辩谏假道，蹇叔以哭谏挡不住霸主的野心——忠告的话术与不听的表情，都是小说笔法的前身；④**“君子曰”**：叙事结束后跳出的评论员——论赞体的祖宗（《史记》“太史公曰”、《汉书》“赞曰”、《资治通鉴》“臣光曰”一线认此祖坟）。
:::


::: example 崤之战：一部四幕剧 {#ex-xiao}
僖公三十三年：秦师袭郑，弦高犒师→蹇叔哭谏（“吾见师之出，而不见其入也”）→晋歼秦师于崤，“匹马只轮无反者”→文嬴请三帅，先轸怒而“不顾而唾”。请分析其结构艺术与“礼”的暗线。
::: solution
**余震幕**——晋襄公母文嬴（秦女）一句话放还三帅；先轸入朝问讯，怒曰“堕军实而长寇雠，亡无日矣”，随即“不顾而唾”——把唾沫唾在君臣之礼上。暗线总结：全书以“礼”为叙事裁判——秦之败先写其“轻而无礼”（师过周北门，左右免胄而下、超乘者三百乘的轻佻阅兵式）；晋之胜先算于朝堂论辩；而先轸“不顾而唾”的失礼，正与次年他“免胄入狄师”战死首尾呼应——**性格即命运，礼即结构**。
:::
:::

::: intuition 礼：左传的叙事计量单位 {#int-li}
《左传》的因果链是“礼—无礼—败—书”：多国兴衰被一套可计量的行为语法串起——飨宴的坐次、玉帛的轻重、辞令的谦倨、师过都门的举止。这不是史家的道德癖，是**叙事物理学**：无礼=系统应力，败=断裂兑现，“君子曰”=探伤报告（“宋公无盟而讨，故书曰”式笔断）。读《左传》的窍门：**盯住每一次“无礼”的镜头，等它爆炸**——城濮的子玉“玉缨琼弁”之侈、鄢陵的楚共王执弓失仪、宴子的“惟礼可以已乱”，全是同一台仪器的不同读数。这一套“以行为细节预报兴亡”的本事，后世《通鉴》的“臣光曰”、小说的“草蛇灰线”都来取了经。
:::

::: history 一部书的千年官司 {#sec-guansi}
**西汉**：《左氏》无博士，刘歆移书太常，今古文经学大战开锣；**西晋**：杜预《春秋经传集解》创“经传合一”的合编本，“传以尽经”的义例总结即其首序，今本《左传》的版式之祖；**唐**：孔颖达《正义》官定；**宋**：儒者于经传之际多所商榷；**清**：顾炎武《日知录》论《左氏》“其文则史”，刘逢禄《左氏春秋考证》复倡“左氏不传《春秋》”（今文反攻）；**民国**：古史辨派与钱穆等续攻“战国写定”说；杨伯峻《春秋左传注》（1981）集旧解、金文、历谱为今之标准本；**出土续证**：西晋汲郡《纪年》与《左氏》年代对勘，开古书校勘新局；清华简《系年》篇（2011 公布）纪事多与《左氏》同原——**战国“史官叙事传统”的又一支流**。
:::

::: warning 读《左传》三防
一**把辞令当发言记录**：数百场外交词令经史官修词（“记言半出拟构”是学界通识——仿说难在**拟其时之声口**，不在录音）；二**把卜梦当史料**：预叙类条目多为事后的**应验编排**（史家的文学手笔兼宿命装置）——信其叙事艺术，不必信其鬼神账；三**把《传》当《经》**：公羊家骂《左氏》“不传《春秋》”、古文家护“义例”，两千年官司的现代结案：**《左传》首先是战国前期的史著与文学，其次才是经**——“春秋学”的家底与“左传学”的家底，两本账分开记。
:::

::: exercise 战争分镜 {level=1}
选城濮或鞌之战，画出“棋盘层—镜头层—评论层”三层的详略表，说明左氏叙事详略的计量原则。，说明左氏“善序师律”的计量原则。
::: solution
示例（鞌）：棋盘层——齐晋争霸与战前辱使（郤克使齐，夫人帏而观之而笑——一句话开战的导火索引人注脚）；镜头层——解张“矢贯余手及肘”的三句血话，逢丑父令齐侯“下取饮”得逃、三周华泉之下的“忠仆救主”场面；评论层——“君子谓”各安刑名。计量原则：**义之所关（礼、信、贪、诬）则详，兵数地志则略**——左氏写的是“人的胜负”而非“人的死亡表”。

::: exercise 辞令修辞学 {level=2}
僖公二十六年，齐孝公伐鲁北鄙，国贫使弱，鲁使展禽（展喜）劳齐师。齐人问：“室如悬磬，野无青草，何恃而不恐?”展喜历述成王赐命、齐鲁世守之约——请分析其**用历史当武器**的三层。
::: solution
三层：①**引档案**：周公分封、世世子孙无相害的盟命记忆——把旧条约当现实武力用（“恃先王之命”）；②**戴高帽**：抬出齐桓公“犹务柔诸侯、镇尔中国”的祖风，把孝公绑在祖先的人设上——争霸者最怕被史笔除名；③**反守为攻**：“何恃而不恐”的镇定即威慑——恐惧是心理战场的第一货币，辞令是弱者的核武器。判分点：能把三层讲成博弈结构。
:::

::: exercise 小论文：先轸之唾 {level=3}
写八百至一千二百字：“不顾而唾”是失礼还是直臣的高光？结合《左传》的“礼”裁判系统与晋国政局（只作文本内推理，不强引外史）讨论：史家把一个“违礼的怒”写进经文般的叙事里，想说什么？可与蹇叔之哭对照（同为忠，一哭一唾，叙事报酬各不同）。
::: solution
判分点：能看见叙事的**双重记账**——“君子曰”系统守礼，而叙事本身敬惜真性情（先轸之怒在文本里被“表演”而非“判决”）；能把“免胄入狄师”的死读成性格的闭环（礼的债，自己还）；结论若指出“左氏的‘礼’不是教条而是**张力的测量仪**”，即达课文主旨。
:::
:::

::: summary
《左传》四课：分镜（棋盘与血话同框）、预叙（蹇叔的悼词式地形课）、记言（性格与辞令互证）、“礼”的因果引擎（无礼—应力—断裂）。它是编年体的毕业礼，也是后世叙事的总取材场——《史记》的战争、《通鉴》的评论、小说的“草蛇灰线”，都从这座剧场领的票。下一章见诸子双壁：《论语》《孟子》——从记事转向立言，散文的“说理人格”开张。
:::
