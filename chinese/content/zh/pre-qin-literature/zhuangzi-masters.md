---
title: "《庄子》与诸子"
---

孟子把说理写成辩论赛，庄子把它写成梦——蝴蝶、大鱼、盗跖、骷髅轮番上场；等荀子端坐著书、韩非磨刀上书，诸子的散文走完从“语”到“文”到“法”的全程。

## 庄子的文体革命 {#sec-zhuang}

::: definition 寓言十九，卮言日出 {#def-yuyan}
全书判词用鲁迅《汉文学史纲要》的定评：“其文则**汪洋辟阖，仪态万方**，晚周诸子之作，莫能先也”——**中国散文的想象力宪法**。
:::

::: definition 濠梁之辩：一场没有输家的辩论 {#ex-hao}
“鲦鱼出游从容，是鱼之乐也。”“子非鱼，安知鱼之乐？”“子非我，安知我不知鱼之乐？”（《秋水》）——请分析这场抬杠的**逻辑结构**与**审美结论**。
::: solution
附赠术语：惠施“历物十事”与《天下》所录辩者“二十一事”（含“一尺之捶，日取其半，万世不竭”）是名家的正装，《庄子》的戏装与之互为表里——一个负责把问题刁钻化，一个负责把问题宇宙化。
:::
:::

## 荀子与韩非：说理的两种收束 {#sec-xunhan}

::: definition 从雄辩到文章到刀笔 {#def-xunhan}
**《荀子》**：三十二篇，**个人专集的文体现身**——论文篇题（《劝学》《修身》《天论》）即目录学革命。文体两宝：《劝学》以**博喻排比筑楼**（“青，取之于蓝，而青于蓝”“不积跬步，无以至千里”——孟子的比喻军团整编成体系化工程）；《赋篇》托物设辞、分写礼、知、云、蚕、箴五物，是“赋”得名之地的先秦标本之一；《成相》以“三三七四七”的民间唱辞写政治教材——**荀子是先秦唯一主动经营文体的诸子**。
**《韩非子》**：五十五篇，法家集大成兼**怀疑主义文体家**：《说难》写进说之险——“凡说之难，在知所说之心”，**中国第一篇说服心理学**；《难一》《难二》《难势》成组**驳论文**，自设题面逐条发难——论敌缺席的法庭，逻辑的暴力美学；楚人鬻盾与矛（《难一》）、守株待兔（《五蠹》）诸寓言冷硬如判决书附件——**庄子的寓言是风筝，韩非的寓言是证物**。荀学出韩非与李斯：同一位老师，教出文学家与工程师——李斯《谏逐客书》的铺排正是荀门文章法，奏议体的先秦结业礼。
:::

::: history 庄子的两千年 {#sec-zhuangxy}
**汉**：五十二篇古本行世（司马彪、崔譔诸注），汉初黄老当国，庄子入显学之林；**魏晋**：郭象注本三十三篇定于一尊，**玄学奉“三玄”**（《老》《庄》《易》），“庄老告退，而山水方滋”（《文心雕龙·明诗》——玄言退潮，山水诗从庄子的眼睛里上岸）；**唐**：天宝年间诏封**南华真经**，道教系统收编；**宋明**：以禅解庄、以庄解禅互文成风，文人奉庄子为精神后花园；**清**：宣颖《南华经解》、刘凤苞《南华雪心编》——**文章学读法**总账（章法句法字法全从庄子处讨）；**近代**：鲁迅《汉文学史纲要》定“汪洋辟阖”之评，冯友兰《中国哲学史》视庄子为“哲学中的哲学”，学院派庄学开线；**今天**：“庖丁解牛”进理科教材题记、“相濡以沫”进流行歌词——**庄子是中国文化的心理备用电源**。
:::

::: intuition 想象力为什么是硬道理 {#int-xiangxiang}
诸子散文的竞赛里，孟子的武器是气势、荀子的武器是体系、韩非的武器是刀——庄子的武器是**把对手带出战场**：要讲“小大”，他不辩论，他让你先看见一条几千里的大鱼变鸟；要讲“死生”，他让骷髅自己开口婉拒还阳；要讲“知”，他变成蝴蝶。**论证说服脑子，想象改写提问资格**——这是文学在哲学部门赢下的最大一仗，也是中国散文“意象思维”的立约现场（[[rhetoric/figures-of-meaning]] 的远祖合同）。
:::

::: warning 诸子阅读三忌
一**以人废书**：因韩非“刻薄寡恩”跳过《说难》的心理学，因荀子“性恶”漏读《劝学》的文体——文风与主张分账；二**把寓言当庄子语录**：鲋鱼、盗跖、任公子都是**角色**，内七篇之外多后学扩写——“庄子”是文本家族，不是单一个人；三**把《难》篇读成抬杠**：其方法是“以其矛攻其盾”的内在批判（成语“自相矛盾”即出此），怀疑是方法不是立场。
:::

::: exercise 卮言仿写 {level=1}
用“寓言十九”法写一段三百字：以一个非人角色（云、秤、旧手机任选）谈“有用与无用”。要求角色有性格，论点由情节带出。
::: solution
判分：①角色逻辑自洽（秤抱怨“直”的代价）；②论点不代言（“无用之用”由故事翻面带出，不让角色喊口号）；③有一处“卮言”式散句——忽然跑题又忽然说中（如“我年轻时称金，老了称葱——金轻葱重，人间秤知道”）。得一及格，三得为 A。
:::
:::

::: exercise 濠梁裁判 {level=2}
以逻辑学立场为濠梁之辩写一份判词：惠施两问的“安知”是否同义？庄子“请循其本”的收束是有效回应还是终止辩论？只用课内名词语汇（名的辩者、合同异），不引未读书目。
::: solution
判词要点：惠施第一问问**认识依据**（你凭什么知道），第二问是反击式反诘（你非我，怎知我之知）——两问辖域不同；庄子末句“我知之濠上也”把“安知”改读为“在何处知道”，利用疑问词的语义弹性，逻辑上属偷换；“请循其本”把辩论拉回**语用层**（你当初问我时，已预设我知道——以发问者的预设反将），有效但不完备：它赢了对话，没赢论证。判决：惠施逻辑胜，庄子修辞胜——文本故意让读者两难，这是《庄子》的出题法。
:::
:::

::: exercise 小论文：诸子与士的出场 {level=3}
写八百至一千二百字：从《论语》的问答到《韩非子》的上书，散文文体如何记录“士”这一阶层的上升、分化与再收编？要求：①以两位作家的文体特征为证（语录—专书—奏议的三级跳）；②以焚书令大意为收束参照；③结论谈“思想自由与文体的共生”。
::: solution
判分点：三级跳材料准确（论孟为私学记录，荀为个人专书，韩非通向奏议——**从课堂到书房到朝廷**）；焚书令以大意引（非秦纪者皆烧之、博士官所藏除外）；结论能指出：百家文体最盛之时恰是王权最碎之时，文体统一与思想统一的交易从秦做到汉——**散文的下一幕叫“赋”**。
:::
:::

::: summary
诸子四极：孟子给说理装上音量，庄子给它装上宇宙，荀子给它装上梁柱，韩非给它装上刀口。诸子散文起于课堂问答（论），盛于雄辩（孟），化于寓言（庄），定于专书（荀），终于上书（韩）——士从教书匠走到帝王师，再走到秦廷的刀下。下一章换南方水泽：屈原出场，诗重新夺回个人声音。
:::
