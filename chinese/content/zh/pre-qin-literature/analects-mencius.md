---
title: "《论语》与《孟子》"
---

诸子争鸣从记录孔子说话开始，到孟子扛着“王道”碰瓷各国朝廷达到高潮——一部《论语》是老师的课堂速写，一部《孟子》是辩手的现场直播。散文的“说理人格”，这两本书入了编。

## 语录体的诞生 {#sec-yulu}

::: definition 论语：课堂的复调 {#def-lunyu}
《论语》：孔子弟子及再传弟子**追记**辑成（战国初编定），二十篇，论难、应答、随感杂抄——体例即“论语”（语者，论难应答之言；何晏《集解》、皇侃《义疏》、邢昺《疏》、朱熹《集注》四层注本）。文学价值藏在**文体缝隙**里：①**速写人物**：“夫子喟然叹曰”“子之武城，闻弦歌之声——夫子莞尔而笑：割鸡焉用牛刀”——笑容、口误、被弟子当场将军（“昔者偃也闻诸夫子”——老师认账：“前言戏之耳”），**《论语》是先秦唯一给圣人保留尴尬的书**；②**箴言的裸重**：“巧言令色，鲜矣仁”——无背景、无论证、结论裸奔——语录体是**记忆的文体**（刘勰《文心雕龙·论说》：“圣哲彝训曰经，述经叙理曰论”——“论”的家谱以《论语》为开山）；③**语言现场**：“先进于礼乐，野人也”的古今之争、“莫春者春服既成”的曾点言志——孔子那句“吾与点也”，是全书记载的**最高一次审美判决**。
:::

::: definition 孟子：好辩的自白 {#def-mengzi}
《孟子》七篇（弟子万章、公孙丑等“次其语”——司马迁说孟子“退而与万章之徒序《诗》《书》，述仲尼之意”），文体从《论语》的短章**长成了论辩现场**：与梁惠王、齐宣王、告子、淳于髡一轮轮交锋，**长篇气势体**开天辟地。孟子自供：“予岂好辩哉？予不得已也”——**辩，是被世道逼出来的文体**。他的三件兵器：①**知言**：“诐辞知其所蔽，淫辞知其所陷，邪辞知其所离，遁辞知其所穷”——四款话术的病理学（一张论辩失效的诊断表，后世逻辑修辞课的远祖）声）；②**养气**：“我善养吾浩然之气……其为气也，至大至刚”——**文气论的第一桶金**：韩愈“气盛言宜”、苏轼“行云流水”都来这支取；③**揠苗助长的故事军团**：揠苗、齐人骄其妻妾、弈秋诲弈、五十步笑百步、月攘一鸡——**以寓言做论证的推进器**（庄子寓言是飞机，孟子寓言是法庭证据：每个故事只干一件事——把你逼到你承认的常识上）。
:::

::: example 齐宣王问：“交邻国有道乎？” {#ex-qixuan}
孟子对曰：“有。惟仁者为能以大事小，惟智者为能以小事大”（《梁惠王下》）；另有“四境之内不治，则如之何？王顾左右而言他”（同篇）的著名连问。请分析孟子对话的**开场设计**与**收口设计**。
::: solution
开场设计：**从不设防处切入**——宣王问外交，孟子答“以大事小乐天、以小事大畏天”，把政策问题改写成**人格等级题**（仁/智/勇），君王的虚荣心自动接单。收口设计——“四境不治如之何”：此前诸问（妻子于臣、士师不治士）皆由宣王亲口断罪，到“四境之内不治”时，**判决的笔已经握在宣王自己手里**——他只能“顾左右而言他”：逃跑动作被史笔定格，成了中国散文史上最著名的**沉默特写**。技术总结：孟子不与人斗嘴，他与人的“承认”斗——先骗出你的“然”，再让你的“然”爆炸（诘问法，与苏格拉底助产术同型的平行装置——课内并档，不比较优劣）。
:::
:::

::: history 从子书到“四书” {#sec-sishu}
**战国至汉**：《孟子》列诸子，地位在荀、扬之间；**中唐**：韩愈立道统，评孟子“醇乎醇”（《读荀》）——尊孟第一推手；**宋**：王安石、二程升格，**朱熹《四书章句集注》（1190）**把《论》《孟》《学》《庸》焊成科举新经典——举业重心自此由五经迁向四书；**元**：仁宗朝定朱《注》为科场程式；**明清**：八股题目半出《论》《孟》，“代圣贤立言”的训练使二书成为全民记忆；**五四前后**：礼教靶子照打，鲁迅、周作人却以文学家读《论语》——**经学的孔子退休，文学的孔子与孟子上岗**。
:::

::: intuition 说理文的情绪工程学 {#int-qingxu}
读《孟子》当看他**怎么生气**：批杨朱墨翟“无父无君，是禽兽也”——骂到动物学；见梁惠王开口“王何必曰利”——抢定义；公孙丑问何谓浩然之气，他先答“难言也”——**先承认不可说，再一气说完**（崇高的音量控制）。情绪在孟子手里不是杂音，是**论证的音量旋钮**：该冷笑时“以邻国为壑”，该动情时“民为贵，社稷次之，君为轻”——**中国说理文的两种体温（冷讽与烫胆）从此定样**：上承《庄子》之嘲，下启韩愈《原道》以下、直至鲁迅杂文的温控线路。
:::

::: warning 读论孟三坑
一**把箴言当定理**：“唯女子与小人为难养也”一章古今聚讼，正解是**语境考古**（“小人”或谓家臣、章旨诸说并陈）而非硬洗或硬黑；二**把论辩当史实**：《孟子》与各国君的对话多经弟子**润色定型**（“望之不似人君”一类快语，是文学化的私记而非会议记录）——史实层与文学层分账；三**把民本当民主**：“民为贵”是**责任伦理的极限**（君主失格，孟子说“闻诛一夫纣矣，未闻弑君也”——革命权的理论闪电），不是主权在民的制度方案——给古人投票要按他的选票格式。
:::

::: exercise 速写精读 {level=1}
《乡党》一篇号称“孔子起居注”（“入公门，鞠躬如也”“席不正，不坐”），选三则说明：零评论的白描如何塑造人格。
::: solution
示例：“执圭，鞠躬如也，如不胜”（重器写敬）；“升车，必正立执绥”（车容写礼）；“厩焚。子退朝，曰：‘伤人乎？’不问马”（**两字省略写人**——马政时代的惊人一笔）。原理：《乡党》通篇不评一个“圣”字，只列动作——**习惯是人格的指纹**；此法即后世小说“不写之写”的远祖（与《世说新语》直接同源）。三例+原理各半即可。
:::
:::

::: exercise 五十步解剖 {level=2}
“五十步笑百步”章（《梁惠王上》）：画出孟子如何把“寡人之于国也，尽心焉耳矣”的自夸拆成**比较级陷阱**，并指出其逻辑强项与漏洞。
::: solution
拆法：梁惠王自夸“寡人之于国也，尽心焉耳矣”→孟子设战场比喻，诱其亲口判决——王曰：“不可，直不百步耳，是亦走也”：**梁惠王亲手给自己定了罪**（跑五十步与百步同类）。强项：类比+自认结构——你承认了“同类”，就得承认梁国之政与邻国同属“王道未成”，“王道之始”的入口由他自己的嘴打开；漏洞：**类比失效处**——逃兵与民政不同量纲，程度差越过阈值即是性质差（年赈三十与零之别，可以类比“走”与“不走”吗？）。判分点：既叹其论辩设计之精，又能指出“以比喻代论证”的代价。
:::
:::

::: exercise 小论文：两种说理人格 {level=3}
写八百至一千二百字：《论语》的“温而厉”与《孟子》的“直而傲”，哪种更适合做说理的公共人格？要求：①各引一章为标本；②联系一个当代媒介场景（评论区、辩论赛或知识区视频）分析两种人格的胜算与失真；③亮出你的选择并说明代价。
::: solution
判分点：标本准确（如《论语》“子温而厉，威而不猛，恭而安”；《孟子》“说大人则藐之”）；媒介分析具体（论语体适合金句与签名档传播——代价是无语境被断章；孟子体适合长辩论与知识区长视频——代价是“好辩”人设招黑）；结论不骑墙、代价说得出。
:::
:::

::: summary
论孟双峰：《论语》以速写与箴言保存了一个**会尴尬的圣人**——语录体是记忆的文体，笑容是文学的缝隙；《孟子》把说理写成竞技与人格秀——知言是诊断表，养气是发动机，故事军团是推进器，连逃跑的“顾左右而言他”都是他的分镜设计。宋人把两座峰圈进“四书”，从此中国人的口里有它们的成语，笔下有它们的语气。下一章峰回路转：庄子出场——当论辩遇到寓言的飓风。
:::
