title: "《楚辞》"

屈原是楚辞的峰顶，本课下山看整个生态系：十一篇祀歌的神殿、一百七十问撕开的天问体、“兮”字句法的呼吸，以及宋玉接棒后——南方文学如何汇入“风骚”这条大运河。

## 九歌：神殿与情场 {#sec-jiuge}

::: definition 九歌档案 {#def-jiuge}
《九歌》十一篇（题曰“九”而实十一——旧说《礼魂》为送神乱曲——教学承认：“九”是**套数之名，非数目之实**）：东皇太一（天神至尊）、云中君、湘君、湘夫人、大司命、少司命、东君（日）、河伯、山鬼、国殇（阵亡将士）、礼魂（送神）。底色是**楚地巫祭**：群巫降神，**以人神恋爱写迎神送神**——“浴兰汤兮沐芳，华采衣兮若英”（巫扮神装）；“沅有芷兮澧有兰，思公子兮未敢言”（《湘夫人》——单恋的踌躇，《诗经》送子涉淇的南方加强版）。《山鬼》：“若有人兮山之阿，被薜荔兮带女罗……风飒飒兮木萧萧，思公子兮徒离忧”——**中国文学第一个完整的女鬼形象**：既野且艳，等待到死。《国殇》换金属声：“操吴戈兮被犀甲，车错毂兮短兵接……身死兮心不惩”——祭英灵的军乐，后世“无衣”之外**另一个中国的哀荣腔**。两说并档：王逸以为屈原**见俗祀粗拙而改作**（寓“发愤”之意），朱熹《集注》沿之；今人多重其**巫文化人类学**价值（降神、人神恋、丧乱诸层）——无论作者归属，“九歌”都是**中国抒情传统的秘密产地之一**：香草、等待、迟到、失约——楚辞的四大情感装置在此首次全装出厂。
:::

## 天问与余响 {#sec-tianwen}

::: definition 天问体与对话体 {#def-tianwen}
《**天问**》：一口气一百七十多问（“遂古之初，谁传道之？上下未形，何由考之？”——问宇宙起源；“鸱龟曳衔，鲧何听焉？”问神话史事；问三代兴亡——末章回落吴、楚掌故），**四言连缀、一问到底，先秦怪力乱神一网打尽**——评价用白话：**汉语唯一以问号建成的诗**，问而不答——把《诗经》的“赋比兴”之外再造第四用：**问兴**）。文体意义：**知识总审查**——宇宙论、神话史、楚祖传说一并提交质询，先秦“怀疑精神”最极端的美学样本（与《论语》“不语怪力乱神”恰成南北一对：一个回避，一个全问）。《**卜居**》《**渔父**》：问答体短文（“吾宁悃悃款款朴以忠乎？将送往劳来斯无穷乎？”——**对偶选问句**开汉赋“七”体之先声（《七发》八段问对即其后裔）；《渔父》“沧浪之水清兮，可以濯吾缨”——以**寓言对话写人格抉择**，渔父的“与世推移”vs 三闾的“怀瑾握瑜”，是中国文学第一组**出世入世的对手戏**，其后东方朔《答客难》、韩愈《进学解》、屈原 vs 渔父的剧本演了两千年）。
:::

::: example 山鬼：一场没有观众的演出 {#ex-shangui}
“若有人兮山之阿，被薜荔兮带女罗。既含睇兮又宜笑，子慕予兮善窈窕。乘赤豹兮从文狸，辛夷车兮结桂旗。表独立兮山之上，云容容兮而在下……风飒飒兮木萧萧，思公子兮徒离忧。”——请分析：①出场的镜头调度；②“等待”的结构；③她是谁（神/巫/人/屈原自况）四说的取舍。
::: solution
①镜头：**先景后人**（山之阿——幽僻定位）→**装束**（薜荔为衣、女罗为带——野生植物的华服：她是山林本身的美）→**表情特写**（含睇宜笑——中国文学罕有的、被正面凝视的女性自信）→**仪仗**（赤豹文狸驾车队——猛兽做宠物，美的暴力配额）→**大远景**（表独立兮山之上，云容容兮而在下——孤绝开机，悲剧的景别就位）；②等待结构：**赴约—候而不至—自我怀疑—怨而不怒**（“留灵修兮憺忘归，岁既晏兮孰华予”——美人迟暮第一次与**时间的暴政**挂钩；终章风雨收场，约永不来——**楚辞的“失约”母题**在此定型，比《氓》的弃妇更纯粹：连负心人都未现身，只有缺席本身）；③四说：山鬼（幽冥之神）、巫扮神女（降神角色扮演）、恋爱诗（人神或民俗情歌）、屈原寄托（“思公子”=思君）——本课取**并档**：文本层是巫祭情诗，编辑层被屈原改写为“等待—失约”的人格寓言，接受层则成为“香草美人”的固定镜头（李贺《神弦曲》、绘画里的“山鬼图”一路到傅抱石——**她是中国艺术最常被画的女主角之一**）。
:::
:::

::: history 从“书楚语”到“集中国文学南方卷” {#sec-nanfang}
**刘向辑《楚辞》**（西汉，屈原、宋玉及汉人模拟汇编成集——“楚辞”作为**书名**始此；王逸《章句》为今存最早完注）；《**史记**》“屈原放逐，乃赋《离骚》”入通史叙事；**梁昭明《文选》**别开“骚”类——文体分类学承认其独立门户；**刘勰《文心雕龙·辨骚》**：“其衣被词人，非一代也”——**风骚并称的理论定盘**——判词大意：奇文郁起，衣被词人非一代；**宋洪兴祖补注、朱熹集注**（道学家重新入籍）；**明汪瑗、清蒋骥**地理解《楚》（行路学）；**近代以来**：楚地出土文献与传世《楚辞》互证成新学一线（地下材料与纸上文字对读）；**今**：《九歌》进舞剧、《山鬼》进游戏皮肤——**南方想象力持续返聘**。
:::

::: intuition 句法也是地理：兮字的呼吸 {#int-xi}
楚辞与诗经的肉眼区别在**句子**：《诗》四言紧凑如黄土塬，楚辞用“**兮**”字拉长呼吸（“帝子降兮北渚，目眇眇兮愁予”——兮在句中，是**巫舞的顿点**；《离骚》“名余曰正则兮，字余曰灵均”——兮在句腰，前后各成一对），加上“只”“些”等语气（《招魂》“些”字咒语群：每句尾“些”——**巫咒的化石音**）。句式的加长=抒情容量的扩容：四言适合点名与劳动，长句适合盘桓与痛哭。**南方多水多山多巫，于是汉语学会了深呼吸**——从楚辞到汉赋的篇幅、再到唐宋长短句，这条“呼吸变长”的航线，起点在那个“兮”字。
:::

::: warning 楚辞阅读四坑
一**以中原正音读南方**：“书楚语，作楚声，纪楚地，名楚物”（宋黄伯思语意）——兰芷荃蕙未必是比兴，也可能是**植物志**，象征读法之外保留字面；二**把“九”数当真**（十一篇之谜已示：套数名）；三**把宋玉全面当配角**：《九辩》“悲哉，秋之为气也”——**中国“悲秋”母题的注册人是宋玉**（“登山临水兮送将归”），《风赋》“风起于青苹之末”、《高唐》《神女》的朝云暮雨——**才子佳人+人神恋的色情想象，产权登记在宋玉名下**（“下东墙”典故出处）；四**把天问当百科全书索引**：它是**诗**，问题学价值在“问的姿态”而非答案清单——不许把它读成 FAQ。
:::

::: exercise 降神剧本 {level=1}
选《湘君》或《湘夫人》，按“迎神—候神—遇（幻遇）—送神”写出舞台提示本（含布景、情绪两栏），并标注“失约”在哪一句发生转折。
::: solution
示例《湘夫人》：迎（“帝子降兮北渚”——幻想她降临）→候（“袅袅兮秋风，洞庭波兮木叶下”——**以秋景拍电影**：中国文学最著名的布景句）→幻遇（“鸟何萃兮蘋中？罾何为兮木上？”——**反常自然=约会失败的预感**：鸟聚水草丛、渔网挂树梢，世界的秩序错位了）→送（“时不可兮骤得，聊逍遥兮容与”——自我宽解收尾）。转折判定：从“筑室水中，葺之兮荷盖”的**婚后幻想**起，想象已越界，现实已散场。布景+情绪+转折三对即可。
:::
:::

::: exercise 天问出题人 {level=2}
仿《天问》体例，就一个当代常识写十二问（宇宙、神话、历史、科技任选一切，四言为主、只问不答），并附一段说明：你的哪一问最“危险”。
::: solution
判分：①体式合（四言连缀、问而不断言，允许押韵失败）；②成序（从大问小或从古问今，有一贯的**审查逻辑**）；③“危险一问”自评：指出哪一问其实**拆的是提问者的地基**（如“成功学之所谓功，谁道之？”）。最上乘：让答案缺席成为答案本身（天问的真传）。
:::
:::

::: exercise 小论文：风骚何以并祖 {level=3}
写八百至一千二百字：《诗经》与《楚辞》被并称“风骚”，这一并案从刘勰《辨骚》到现代文学史如何运作？要求：①举体裁、题材、情感装置三组对比各一（四言/骚体、集市/神殿、怨诽/发愤）；②指出“并祖”遮蔽了什么（**楚辞的巫与鬼长期被经学化阅读洗白**）；③论“南北二元”模板的收益与风险（可引“书楚语”与“思无邪”各作一方旗帜）。
::: solution
判分点：三组对比准确；“遮蔽”一说有靶子（王逸章句的忠贞化即标本——把情诗全数编入忠君户籍）；结论能提醒：**南北二元是描述工具不是血缘成分**（屈原本身是“用南方之声写中原之志”的混血工程——《离骚》引喻多本《诗》《书》）。
:::

::: summary
楚辞生态系四桩公案：《九歌》十一篇的神殿与情场（失约母题、山鬼的完整首演）；《天问》的问号建筑学（汉语唯一以问建成的诗）；《卜居》《渔父》对话体（选问句开汉赋七体，出世入世第一对手戏）；宋玉接班（悲秋与朝云暮雨的注册表）。加上“兮”字的深呼吸——南方半场补齐，下一章清点总账：先秦文学留给两汉的遗产清单与“风骚”并案终审。
:::
