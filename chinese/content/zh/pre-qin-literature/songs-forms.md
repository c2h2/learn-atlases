上一章领了档案，这一章进车间：四言的鼓点为何三千年来只在复古时返场；重章叠句怎样用副歌换出情绪；**赋比兴**——中国文论最古老也最吵架的三个字。

## 四言：最短的行长 {#sec-siyan}

::: definition 四言体的黄金与退休 {#def-siyan}
《诗经》以**四言为主**（二二节拍：“关关/雎鸠——参差/荇菜”），一章数句、叠咏而下。四言是上古汉语的定制：单音词为主的语言+鼓点伴奏的乐舞=每拍一词、二二成句，节拍即语义单元（“桃之/夭夭”，“之”字垫音不占义）。它的黄金时代就是它的全部：《楚辞》破为杂言，汉饶歌模仿其貌，**四言在《诗经》之后只活了两次**——曹操“东临碣石，以观沧海”与毛泽东“江山如此多娇”式的四言笔法（一雄深，一政治修辞），外加历代铭文、赞、庙堂乐章（专职庄重）。为何退休？上古汉语的双音化（[[modern-vocabulary/morphemes-words]]）让单拍词渐成跛足，四言吞吐不下复合概念——**诗体换代，词法革命在前，审美在后**。读四言的口诀：按节朗读，虚字读轻，让鼓点替你断句。
:::

## 重章叠句：副歌工程学 {#def-chongzhang}

::: definition 复沓的三笔账 {#def-futa}
重章叠句=章与章框架复现、个别字更换（“采采芣苢：薄言采之→有之→掇之→捋之→袺之→襭之”——六个动词，一首劳动动作蒙太奇）。三笔账：①**音乐账**：口头乐歌的分节结构，换字即变奏，记忆成本减半、传唱寿命加倍（口传文化的存储卡格式，[[classical-chinese-1/punctuating]] 直觉课呼应）；②**情绪账**：一唱三叹，复沓是**情感的复利**——“知否知否”仍是这副骨架的宋人续作；③**意义账**：换的字就是蒙太奇的镜头——《芣苢》自“采”而“有”而“掇”而“捋”而“袺”而“襭”，动作越来越贪、收获越来越满，**全诗无一句抒情，进度条即情绪**。后世词牌的叠句、民歌的四季调、流行歌的副歌，全是这门工程学的分店。
:::

::: example 车间解剖：《无衣》 {#ex-wuyi}
“岂曰无衣？与子同袍。王于兴师，修我戈矛，与子同仇。”（《秦风·无衣》三章，袍/泽/裳、矛/戟/堂）——说明换字如何在复沓里做递进。
::: solution
骨架三章不改（同袍→同泽→同裳：内衣到战裙，共享程度递增=私己逐级让渡给同袍之谊）；武备换字（戈矛→戈戟→作堂：整编从兵器到阵列，战争机器升温）；章章以“与子同仇/偕作/偕行”收束——**同仇（情绪共识）→偕作（行动起来）→偕行（开赴前线）**，复沓的外壳里走着一条动员进度的直线。《诗经》里最硬的诗，手法却最“简单”：把程序写进副歌。**重章不等于重复：框架守恒，镜头位移。**
:::
:::

## 赋比兴：三个字的千年法庭 {#sec-fubixing}

::: definition 三义的判决书 {#def-sanyi}
名分来自《周礼·春官》“六诗”（风赋比兴雅颂），《毛诗序》改称“六义”——**本是乐官授课的六门课，被千年文论读成了六种手法**。定谳靠朱熹三条（《诗集传》《论语集注》往返校准）：**赋者，敷陈其事而直言之**（“五月斯螽动股，六月莎鸡振羽”——叙事铺排直登台面）；**比者，以彼物比此物**（“手如柔荑，肤如凝脂”——明喻暗喻的修辞格）；**兴者，先言他物以引起所咏之词**（“关关雎鸠，君子好逑”——鸟在旁边唱，诗在这边开）。麻烦在“兴”：雎鸠与爱情**理上不搭、韵上相扣**——两千年解诗人或强找义关联（郑玄：兴是“以善物喻善事”的道德版比），或干脆只认音与情的起势（“兴”近于**氛围乐器**：起调、定场、给情绪开门）。现代两派：**发端说**（兴=乐歌的开场套路，套语研究、口头程式理论——“关关雎鸠”“桃之夭夭”是一批**现成起兴模块**）vs **联想说**（物与情实有隐微相关，雎鸠“挚而有别”的伦理传说即此思路）。本课并档教学：**兴是乐制与诗意的杂交水稻——割乐律的稻，别丢诗意的稗。**
:::

::: definition 比德：后世最大的分红 {#def-bide}
比与兴合成一台象征机器：**比德传统**——自然物获得道德格位：黍稷=宗国（《王风·黍离》行迈靡靡，中心摇摇——“黍离之悲”从此有模板）；桃李=门庭，松柏=节操，兰蕙=君子， 鸱鸮=窃权者（《豳风·鸱鸮》：母鸟哭诉，禽言寓言开天荒第一）。“赋比兴”经《诗》定型后成为**中国诗法的操作系统**：汉赋铺陈（赋义扩张成文体）、楚辞香草（比德扩容成体系）、唐诗兴象（兴升格为意境）、词之寄托（比兴合体为微茫之忧——张惠言《词选》读温韦句句“《骚》自命”）——一个车间发货，三千年没断过货。
:::

::: history “兴”的定义权之战 {#sec-dingyiquan}
**汉**：郑众《周礼》注“兴者，托事于物”——道德化第一枪；郑玄“六诗”注以兴为“美见”之属；**宋**：朱熹三句定义一锤定音（“先言他物”），同时他亲口承认“兴”最难讲——“那兴字最难看”（《朱子语类》的坦白）；**清**：姚际恒、方玉润以诗学反汉学；上世纪中叶以降，语言人类学与口头程式理论入华，“套语和起兴”归位乐歌工业（“葛藟”“日月”各是高频模块）；**当代**：认知语言学的“概念隐喻”又为比德续约谈（“坚贞像松柏”是概念映射不是修辞装饰）。一个“兴”字的定义史，就是中国文论如何从经学出发、途经美学、在认知科学靠站再出发的旅程图。
:::

::: warning 技法分析三防
一**贴格强迫症**：每首诗必标“赋/比/兴”——三者是理想类型不是三格抽屉，“比而赋、兴而比”的混血才是现场常态（朱熹自己也大量注“比也”“兴也”外加“赋而比也”）；二**拆诗成零件**：讲完手法忘了《无衣》让人想出征、《芣苢》让人想跟着动手——**技法是为什么好服务的从句**；三**跨代套用**：拿宋人“寄托说”读一切（“关关雎鸠”读出微言大义连环套）——读《诗》先问周乐，再问汉儒，最后才轮到宋儒的放大镜。
:::

::: exercise 节拍实验 {level=1}
把《蒹葭》一章改写为五言/七言各一次，朗读比较，说明四言不可替代处。
::: solution
示例：七言“芦苇苍苍秋露白，所谓伊人水一方”——添字即成画面解说，原句“蒹葭苍苍，白露为霜”的**景物并列、零动词并置**（两拍四图：蒹葭-苍苍-白露-为霜）被语法胶水稀释；五言同病。结论方向：四言的苍凉=并置与留白，词法简单恰是氛围武器；改写实验即“同义不互换”的现场证明（呼应[[rhetoric/choosing-sentences]]）。
:::
:::

::: exercise 兴模块检索 {level=2}
在《诗经》里检索“南山”“河水”“桃李”三个起兴/比物模块各两例，判断各篇用法是否同一模块（发端 vs 起情 vs 比德），列出你的分类。
::: solution
参考：如“陟彼南山”（卷耳/草虫——登高起兴+忧思定场）、“河水清且涟猗”（伐檀——现实水景转议论起兴）、“桃之夭夭”（桃夭/何彼秾矣——婚嫁喜庆模块）；分类三档：纯发端（声）、起情（氛围）、比德（义），允许一篇两档并说明。判分点：例句准确+分类有标准，不强作解人。

::: exercise 小论文：一种手法的三千年 {level=3}
写八百至一千二百字：选“兴”“比德”“重章”之一，写它的部件传：①《诗经》现场；②楚辞/汉赋变形一次；③唐诗宋词再变形；④你的一次使用（作文/歌词/弹幕均可）——结论回答：古典技法在现代还活着吗，还是只剩术语？
::: solution
判分点：四站无硬伤（如把“兴”一路写到山水诗“感物动情”的源头，即算打通）；术语与作品对应准确；自用一站诚实具体（弹幕“蒹葭+1”也算标本）；结论拒两端（既非“活化石”也非“已死”，落到**场景转换**：从乐歌到文本到界面）。
:::

::: summary
车间提货单：四言=单音词时代鼓点定制的退休冠军（返场靠庄重与复古）；重章=框架守恒、镜头位移的副歌工程（芣苢的进度条、无衣的动员令）；赋比兴从乐官课程表漂移成诗法操作系统，朱子三句是判例、兴的定义权至今开庭；比德把自然物编入道德词典，供油三千年。技法是为“为什么好”服务的从句——下一章换展厅：历史散文，从上古诰命的硬话到春秋笔法的微词，再到战争直播。
