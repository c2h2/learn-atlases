---
title: "《诗经》"
---

一部歌谣总集成为“经”，是文学史最大的偶然与必然：周人的歌词集，被孔子看重、被汉廷立学、被宋人重注、被今人还原为诗——**每一代都在这 305 篇里读出自己想要的中国**。

## 数量与出身 {#sec-shushen}

::: definition 诗三百的档案 {#def-dang'ang}
总目：**305 篇**（另有 6 篇“笙诗”有目无辞，故或称 311）；年代约**西周初至春秋中叶**（前 11—前 6 世纪），地域跨十五国风——从豳土到江沱，周之文化圈几乎全图；**音乐性是第一属性**：全部入乐可歌，《墨子》“诵诗三百，弦诗三百，歌诗三百，舞诗三百”——一首诗四种演法。出身三说要并档：**采集说**——何休注《公羊传》追述“行人振木铎徇于路以采诗，献之大师”，《汉书·艺文志》也承认“古有采诗之官”；**献诗说**——《国语·周语》：“故天子听政，使公卿至于列士献诗”，上层进谏之途；**删诗说**——《史记》“古者诗三千余篇，及至孔子，去其重”，唐以降多疑（若真删，何以逸诗寥寥；欧阳修以下攻之尤力）。教学定论：**孔子与《诗》的关系是教、订、赞（“吾自卫反鲁，然后乐正，雅颂各得其所”），未必是删**——“删”更像素王神话的编制工程。
:::

::: definition 风雅颂：三分的根据 {#def-fengyasong}
分类标准是**音乐，不是内容**：**风**=诸侯国民歌乐调（十五国风 160 篇，土风电台；“风，风也”——《毛诗序》的声训）；**雅**=王畿朝廷正乐（大雅 31 多西周史诗与训诫——生民、公刘、绵、皇矣、大明“周族五部曲”；小雅 74 半民歌半宴劳，怨诽之位——“变雅”）。**颂**=宗庙舞曲乐歌（周鲁商三颂 40 篇，“颂者，容也”——舞容之诗）。四家与三层的解经地图：**今文齐鲁韩**（汉初口说，齐诗主灾异、鲁诗质朴、韩诗存《外传》）与**古文毛诗**（毛苌传、郑玄笺，汉后独存）——今天通行的“诗经”即**毛诗系统**；宋朱熹《诗集传》另起炉灶：《诗》之“风”多“里巷歌谣之作，所谓男女相与咏歌、各言其情者也”（《诗集传序》大意）——道学家反而诚实，美刺政治学让位于人情学；清人考据与今文复兴再翻案；**今人**以文学本位还原歌谣。读一经=在四层地质上钻孔。
:::

::: example “美刺”与“情诗”之间 {#ex-meici}
《关雎》——“关关雎鸠，在河之洲。窈窕淑女，君子好逑。”《毛诗序》：“《关雎》，后妃之德也……乐得淑女，以配君子”；朱熹《诗集传》肯定其“乐而不淫”但把它归入“闺房枕席之间”的正经人伦；今人余冠英《诗经选》：“一首爱情诗”。请裁决，并陈述裁决原则。
::: solution
本案无唯一判：①**文本层**：诗面写君子求女，无“后妃”字样——毛序之说是**经学读法**（诗为政教服务是汉人读经的制度前提，非其发明全属臆造，它保存了先秦“赋诗言志”的使用语境）；②**发生层**：作为周代乐歌，它最可能是贵族婚仪或情诗（“钟鼓乐之琴瑟友之”是礼乐器清单，亦可是欢想）；③**接受层**：两千年的“美刺”读法本身成为文学史事实（宫体诗避它、戏曲引它）。裁决原则与课内一致：**先问你在哪一层读**——经学课考毛郑，文学课考情诗，文化史课考两千年如何误读也是创造。把一层当全部，才是错。
:::
:::

::: history 一部歌谣的经典化流水线 {#sec-jingdianhua}
**先秦**：《诗》是贵族必修课与外交工具——孔子“不学《诗》，无以言”“诗可以兴，可以观，可以群，可以怨”（兴观群怨＝接受论的鼻祖大纲）；**汉**：立五经博士，《诗》成官方意识形态教材，齐、鲁、韩、毛四家竞岗，三家渐亡、毛诗独存（一部诗的编制之争）；**唐**：孔颖达《毛诗正义》定科举标准义；**宋**：朱熹新注动摇美刺垄断；**明**：科举主朱《传》，士子以“思无邪”揣摩三代言语；**清**：姚际恒《诗经通论》、方玉润《诗经原始》以文学读法反攻经学；**1920 年代后**：古史辨派拆“美刺”体系，文学革命诸君把《诗》请回文学史第一页；**今天**：“关关雎鸠”出现在幼儿园教材与婚礼祝词——**经典化不是封圣后不动，是每一代重新认领**。
:::

::: intuition 读《诗经》的正确姿势：先当歌唱 {#int-chang}
诗经的一切问题最终是乐的问题：四言二二节拍（“关关/雎鸠，在河/之洲”）是鼓点不是散文；重章叠句是副歌，换字是即兴变奏（下一章细解）；“兮”“只”“思”等语助是拖腔记音。汉人把它解成政教文本是**失乐后的补偿机制**——听不见旋律，只好在每个字里找微言大义。所以精读《诗经》的第一步是**按节奏朗读**（哪怕用今音），让耳朵重新上岗；第二步才是注疏（知道毛郑在哪一句安放了后妃之德）；第三步是回到歌谣现场——一个“采诗入乐”的注脚，就是它全部的本行当。
:::

一**以史证诗的瘾**：每首诗非坐实某人某事不可——采诗制度本就模糊、本事多不传，强作解人是注疏家旧疾，勿传染；二**废序过头**：朱子疑《小序》开人情读法，但美刺保存着先秦用《诗》的政治史，一删两空；三**名物失考**：“七月流火”是大火星西沉（转凉的信号），拿来形容酷暑是名物事故；“呦呦鹿鸣”的“苹”是藾蒿不是苹果——硬知识错一子，满堂彩变满堂羞；四**越阶引用**：把毛传、朱熹、余冠英三层说法混剪成“《诗经》本义”——引用必分层，混层即伪注。
:::

::: exercise 注疏对读 {level=2}
《桃夭》“之子于归，宜其室家”：《毛诗序》系于文王之世、见“男女以正，婚姻以时”之治；朱熹《诗集传》沿其美而语气归人伦日用；今人余冠英径标“贺新婚”。请比较三说，指出各自依据的类型。
::: solution
三说各自依据：**编序逻辑**（经学——《周南》为“正始之道”，桃花灼灼被读成婚嫁得时的时代诊断）、**名物情境**（文学——“桃之夭夭，有蕡其实”就是喜帖的意象库存）、**民歌功能**（民俗学——婚仪助兴的乐歌本行）。判分点在能分辨“依据类型”而非抢答“唯一正确”：三说各管一层，层内皆实。
:::

::: exercise 小论文：《诗经》是文学吗 {level=3}

::: solution
判分点：四条材料引用无硬伤；“经学也生产文学”举出具体系谱（陈子昂“风雅兴寄”、白居易“文章合为时著”皆靠经学权威背书——没有“经”，哪来“风骨”的大旗）；归类方案诚实标代价（“文学化”丢掉礼乐观材料，“经学化”压死情诗）。
:::

::: summary
《诗经》档案四条：305 篇的出身（采、献、订三说并档，删诗存疑）；音乐三分的风雅颂；毛传—郑笺—朱传—今选的**四层地质**；从聘问、科举到幼儿园的使用史。它成为“经”靠政治认领，活成“诗”靠人情还原——两件事都是真的，别互相取消。下一章进技术车间：四言节拍、重章叠句、赋比兴——“手法”如何在三千年后仍然好用。
:::
