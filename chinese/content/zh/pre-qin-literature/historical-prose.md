---
title: "历史散文"
---

中国散文的第一座山不是哲学是史官：记言、记事、寓褒贬——从诰命到笔法到国别体到纵横家，历史散文一路把“史”写成“文”，最后让“文”背着“史”走。

## 记言之难：《尚书》 {#sec-shangshu}

::: definition 尚书：上古公文包 {#def-shangshu}
《书》者，**上古之誓命诰辞的档案汇编**（“尚”者，上古——司马迁“《书》记先王之事，故长于政”）。今文 28 篇（伏生口授、汉隶写定）与古文 25 篇（东晋梅赜所奏，**宋以来判为伪书**——一千年的《古文尚书》是伪造经典案的头号标本，阎若璩《尚书古文疏证》结案）；文体谱系即公文谱系：**典**（制度）、**谟**（方略）、**训**（教诲）、**诰**（告谕）、**誓**（动员令）、**命**（任命书）。文风：佶屈聱牙（韩愈的控诉——**它是我们语言的前世方言**，“克明俊德”之类要靠训诂学开锁）。文学价值恰在“难”：《牧誓》“今日之事，不逾一日之间”的军令硬度；《无逸》周公絮叨“先知稼穑之艰难”——**诰命体里第一个活人的口气**。读《书》姿势：借曾运乾、刘起釪等今注，先认碑，再听人声。
:::

## 春秋笔法：史官的笔与刀 {#sec-bifa}

::: definition 微言大义 {#def-bifa}
《春秋》：鲁国编年史（隐至哀，前 722—前 481），文字极简——“陨石于宋五”“晋赵盾弑其君夷皋”（实际杀灵公的是赵穿——书赵盾，责在正卿亡不出境、反不讨贼——**书法**即判决）。三大笔法：**一字褒贬**（“弑”与“杀”“诛”的罪名学；“及”“次”“围”各有刑等）；**讳书**（为尊者讳——“天王狩于河阳”：晋文公召周天子，笔下来成天子打猎——孟子“孔子成《春秋》而乱臣贼子惧”与今人“历史书写即政治行为”在此握手）；**属辞比事**（排比年月与措辞，让事实自己开口——“春，王正月”的四字历法宣示）。史源学补课：先秦“《春秋》三《传》”各有家法（《左氏》**叙事本事**、《公羊》《穀梁》**解经义例**——今文经学与古文经学的第一战场）。
:::

::: example 五个字的法医学 {#ex-wuzi}
“陨石于宋五”（僖公十六年）——《穀梁传》解：“陨石，记闻。闻其磌然，视之则石，察之则五”——请说明这句话为什么是早期“语言与认知”案例。
::: solution
五字复原感知三步：**闻**（磌然——先听见坠响：以声索物）→**视**（视之则石——走近辨质：是石头）→**察**（察之则五——清点数定：共五块）。《公羊传》同调：“曷为先言陨而后言石？陨石记闻……曷为先言石而后言五？五石记见。”——三传争的不是史实，是**措辞顺序=认知顺序**的语言哲学：史笔的每一个语序都是调查笔录。结论：所谓“微言大义”的另一面是**极简文体的信息编码学**——后世“惜墨如金”的源头不是省纸，是相信每个字都在法庭上。
:::
:::

## 国别体与纵横家嘴 {#sec-guobie}

::: definition 国语与战国策 {#def-guobie}
《**国语**》：周、鲁、齐、晋、郑、楚、吴、越八国**记言**汇编（旧题丘明——与《左传》“内外传”之说宋以来存疑），长于谏说：邵公谏厉王弭谤“**防民之口，甚于防川**”——谏诤文的千古母题；《**战国策**》：战国游说辞的总集（刘向校书定名，非一人一时作），**纵横家的嘴**成为文学主角：邹忌讽齐王（妻妾客三面镜子→朝廷政治——生活寓言嫁接讽谏的妙笔）、触龙说赵太后（从“父母之爱子，则为之计深远”切入，谈判心理学全文艺化）、荆轲（易水送别的场面调度，史记取材的半成品）。文学史坐标：《左传》犹守礼官之严，《国策》全掉书袋之光——**从“辞”到“夸”的滑坡，是士人从聘问之使变成卖艺之说客**（刘向《战国策书录》“捐礼让而贵战争，弃仁义而用诈谲”已下考语）。
:::

::: intuition 史与文的中国合同 {#int-hei}
西方史诗先长大（叙事归诗），中国**史官先长大**（叙事归史）——这纸合同影响了整部文学史：小说要“羽翼信史”、章回要“据正史”抒情传统之外，中国叙事的第一合法性来自史传。读先秦历史散文要戴两副眼镜：**史的眼镜**（这条材料可信到什么层——诰命？追记？拟托？）与**文的眼镜**（这段叙事如何布排：详略、预叙、代言辞——小说技法在史书里领工资）。孟子“以意逆志”与“知人论世”两原则，从读《诗》《书》起步，是中国阐释学的出生证。
:::

::: history 从伏生口授到清华简 {#sec-zhongren}
**汉初**：伏生口授、伏生以汉隶写定“今文”二十二篇（欧阳、夏侯之学立官）；孔壁古文一出，**今古文之争**开锣（马融、郑玄贯通古今文）；**东晋**：梅赜奏上含《孔传》的古文《尚书》，此后一千三百年充当官学范本；**1680s**：阎若璩《尚书古文疏证》百有余条举证其伪，“伪古文”定谳——考据学的里程碑大案；**1923 起**：顾颉刚《古史辨》把《尧典》《禹贡》断为战国人托古的政论设计（层累说正面强攻《尚书》）；**2008 起**：清华简入藏，“《书》类”篇目与传世本对勘（多篇可与今本对读异同），真伪旧案获得战国文字的新证据链——**一部《尚书》的接受史，半部中国经学方法论**。
:::

::: warning 历史散文三雷
一**把《左传》当新闻实录**：其书成于战国前期，辞命多经**拟作与修词**（论史笔“修词”一条，钱锺书先生点破最响——记言与代言之间，史家的手在）；二**《今文》全信、《古文》全丢**：伪古文里“人心惟危，道心惟微”的十六字心传，理学家当真供奉——**文献伪而思想史真**，一刀切会切开自己的脚；三**用《国策》订史**：游说之士“面墙自是”，《策》事与《史记》《纪年》多有出入——它是**战国说服术的样本库，不是战国的台账**。
:::

::: exercise 笔法实习 {level=1}
“夏，五月，郑伯以璧假许田”（事在鲁隐公八年）——用训诂与书法知识解这句的“不正常”处（名分、礼制、措辞各一）。
::: solution
三查：①**事不正常**：祊与许田的调换，诸侯擅相易天子之田（“假”实为易——借的皮裹换的肉）；②**礼不正常**：田土之易当告于王，不告而擅易——不书其事之大而书其事之细，越礼之迹自见；③**文不正常**：“以璧假”——璧是手续费的遮羞布，《公羊》“假不言易，以是易也”点破措辞遮羞。一句九字，礼崩乐坏的体温计——判分点：能把“措辞=判断”说明白即可。
:::
:::

::: exercise 谏说修辞解剖 {level=2}
选《邵公谏厉王弭谤》全文，画出劝谏的论证链（壅川—溃—宣—“善败于是乎出”）的说服力来源与风险。
::: solution
链：弭谤=壅川（比喻立论）→川壅而溃伤人必多（灾害后果）→民之有口犹土之有山川（口的产出性：善败宣扬=财政与舆情两用）→防民之口甚于防川（结论升级）。说服源：用水利社会的共同恐惧做前提，喻体即论证；风险：**比喻承担了本应由证据承担的工作**——“川”可以导，民口之“导”由谁主导？喻体掩护了权力前提（邵公要“宣之”而宣之之权仍在王）。能指出这一层风险者 A。
:::
:::

::: exercise 小论文：史家为文 {level=3}
写八百至一千二百字：“中国叙事文学的奶妈是史官”，请论证或反驳：①举《左传》《国策》各一例小说技法预演（场面调度、细节设计、对话编排任选）；②对照章学诚“六经皆史”（《文史通义》）一线，谈“史”在中国知识谱系里的宗主地位；③谈这层“史统”对后世小说“据实虚构”尴尬的长远影响。
::: solution
判分点：技法例具体（如城濮之战的进退伏笔、易水送别的“士皆垂泪涕泣”式细节群）；“六经皆史”用于中国语境而非硬套西方诗史之争；结尾能点出“史余”观念既是小说的胎教也是它的枷锁（“稗官”自卑与“羽翼信史”自尊同根）。
:::
:::

::: summary
历史散文四步：《尚书》记言——佶屈聱牙是方言化石，伪古文案是考据学的成人礼；《春秋》笔法——一字刑名与认知笔录的合体；《国语》谏说与《战国策》游说——从礼官之严到掉书袋之光到纵横家的嘴；史与文签订的中国合同，让叙事文学两千年在史传屋檐下长大。下一章精读这场戏的主角：《左传》——战争如何被写成文学。
:::
