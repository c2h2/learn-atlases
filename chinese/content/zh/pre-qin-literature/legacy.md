title: "先秦文学的遗产"
---

最后一章不读新书，**盘库**：先秦一千年发货给两汉与后世的全部清单——文体、母题、方法、人格模板各一栏，顺带回答那个老问题：为什么中国文学的童年，长得像一座总部。

## 风骚并案：总账的第一页 {#sec-fengsao}

::: definition 并案的成立与遮蔽 {#def-bing}
“风骚”并称的建档工程：**刘安《离骚传》以“国风好色而不淫，小雅怨诽而不乱”比《离骚》**（《史记》引——风骚同案的第一份并卷动议）；**刘勰《辨骚》**判“自《九怀》以下，遽蹑其迹，而屈宋逸步，莫之能追”——屈宋入队，南卷立案；**唐宋以后**“风骚”成为“文学”的代名——“骚人”“风人之旨”遍地进入诗文与批评话头。账目两栏：**它典据了什么**——民歌与个人创作两大源头、现实关怀与浪漫想象两种能量、后世“诗言志”与“发愤著书”两条血脉（司马迁“此人皆意有所郁结”的谱系学）；**它藏起了什么**——史官叙事这一大桩被“文学”门牌移到侧厅（《左传》《国策》在文论里的户口比《诗》《骚》薄得多）、**神话与巫祭的下半截**（九歌的狂欢、天问的怪力）长期被“温柔敦厚”的口径修剪、以及无数“无名之诗”（逸诗、徒歌）——**并案是伟大的，也是精选集不是全集**。
:::

::: example 交货清单：先秦 → 汉 {#ex-jiao}
把本课九章的内容开一张“发往两汉”的运单：文体、母题、方法、人物模板四栏，每栏至少两项，注明接收方。
::: solution
**文体栏**：四言诗（汉郊庙歌辞、韦孟《讽谏》一路到曹操的返场）；骚体（贾谊《吊屈原赋》、汉初“骚”家——《史记》竟两载贾谊赋，可见热度）；赋（荀子《赋篇》的名义+楚辞的铺排，合成汉大赋）；奏议（《谏逐客书》是先秦向汉廷交出的第一份成品）；**母题栏**：香草美人（汉赋的比兴库存）、黍离与麦秀（亡国感伤的两种出厂码）、游仙与天问（汉镜铭、古诗十九首的生死追问）、士不遇（贾谊、东方朔、赵壹一路的家族病名）；**方法栏**：春秋笔法（《春秋》决事、汉儒说经）、古书辨疑的萌芽（汉人已识文献参差——校书与层累意识的前身）、比兴寄托（诗教解释学在汉初就职）；**人格模板栏**：三闾（忠而放逐的原型，贾谊到司马迁排队认领）、渔父与接舆（出世备选项）、黔首谏士的俳优一线（到汉代东方朔才长全身面）、孔墨孟荀的“师”格——**汉帝国的精神设备，半数产权是先秦的**。
:::
:::

## 四项祖产 {#sec-zuchan}

::: definition 遗产清单总表 {#def-zongbiao}
**①文体全目录**：后世每种文体回先秦认祖——诗（四言/骚）、赋（荀赋+楚声）、论（名家辩题与《难》体成组驳论）、奏议（逐客书）、书信（李斯的《上书》与《报燕惠王书》是其先秦先例——太史公《报任安书》已是汉家手笔）；寓言小品（庄子到柳宗元到《聊斋》的“赞”）；史传叙事（纪传兼采《春秋》经传与《语》《策》诸体——学界通说取其大意）；**②叙事合同**：史官握笔、褒贬内置、细节预报兴亡——中国叙事的“现实主义执照”由此颁发，小说千年要靠“羽翼信史”蹭它的信用；**③象征词典**：香草美人、黍离、松柏、沧浪——一套可继承的公共隐喻库（比任何修辞手册都长寿，因为它有**两千年使用判例**）；**④人格与文气**：三闾的殉、庄周的游、孔孟的担——**中国作家的三种脊椎姿态**；再加孟子“养气”之说与韩愈以下“气盛言宜”的文气论接轨——**人品文品一条龙审计，从先秦开始营业**。
:::

::: intuition 童年为什么像总部 {#int-zongbu}
人类童年各有神话，为何独中国先秦像一个**仍在办公的总部**？三因并陈：**文字早熟且一系不断**（甲骨到隶书，同一套字符让后人能直连原文——希腊人读荷马要靠转写与译本接力）；**教育制度把文本焊成经**（从“家学—私学—五经博士—四书科举”，每个时代重新发工资养这批书）；**解释学传统允许重写不废止**（层累不怕晚，注疏允许新——总部不断装修，从不迁址）。对比视野克制使用：不是“中国特殊论”，是**传播条件的比较**——同样的故事，装在不断电的档案系统里，就会一直当总部。
:::

::: history 盘点的方法也要盘点 {#sec-fangfa}
本课用过的工具箱清点：**层累说**（顾颉刚：先看文本生年，再谈内容）；**解释地层学**（毛郑—朱熹—清人—今选，各归其层）；**依据类型分辨**（编序逻辑/名物情境/民歌功能——《桃夭》三说课）；**文体发生学的谨慎**（一体一源是童话，多源汇流是常态）；**出土与传世互证**（清华简与传世本对勘——本课仅两度引用，留待专课）；**记忆与认领**（屈原的两千年、神话的 IP 化——接受史是文本生命的一半）。这套刀法不独为先秦设计——**从下一课（汉魏六朝）起，它们要继续上班**。
:::

::: warning 谈遗产三戒
一**祖先崇拜式归源**（凡赋必祖荀子、凡骈必祖《诗》对偶——源多流异，认祖可以，碰瓷不行）；二**用清单代替阅读**（背完“遗产十条”不等于读过《离骚》——本课前九章的原文课不能跳）；三**把“影响”写成“判决”**（说《左传》影响《史记》是研究的起点不是终点——司马迁还吃了《世本》《国策》与口传，**影响是营养学不是血型学**）。
:::

::: exercise 认祖仪式 {level=1}
任选一件后世作品（曹操诗、李商隐《无题》、《三国演义》开篇、某条高考满分作文任选），写出它的**两件先秦行李**并注明出处课文——要求每件行李有原文级证据。
::: solution
示例：《三国演义》开篇——行李一：史笔与舆图（“话说天下大势，分久必合”是《国策》“合从连衡”句式加《公羊》“治乱循环”的口语化）；行李二：预叙装置（崔州平、司马徽的“数尽”之谈，是左氏卜梦的后身）。行李一准确、二有据即可；“原文级证据”指能引得出课文原句。
:::
:::

::: exercise 反方辩论稿 {level=2}
为“风骚并称遮蔽了先秦文学的多样性”写一份五百字辩论陈词（正方），再用同样的力气写一份反驳（反方），最后判案。
::: solution
正方要点：并案=两千年聚光灯，左传、国策、神话长期在暗场；“言志”口径修剪了九歌的狂欢与天问的异端。反方要点：经典化本必有拣选，**遮蔽处自有考古学与文论续命**（《辨骚》《文心》已为“怪”翻案）；并称也**赋能**——史与骚各获“经”级待遇。判分点：双方都用课文证据；判案不骑墙（允许“遮而不灭”“灯下亦有光”的精确表述）。
:::
:::

::: exercise 课程总结卷 {level=3}
给自己出期末卷：十道填空＋一篇一千五百字总论。填空覆盖九章各一题（含答案与出处）；总论题三选一：①“先秦文学是总部”说；②“赋比兴与香草美人：中国象征主义的两次立法”；③“从史官到游士到诗人：作者身份的三次搬家”。
::: solution
自评表：填空十题每题须能定位到具体课文段落；总论①看三因（文字、制度、解释学）是否落地；②看两次立法“集体与个人”的分界是否准确（诗=礼乐公共系统，骚=个人佩戴系统——曹植以下所有“寄托”都在两套系统之间搬家）；③看“搬家”比喻是否诚实（三闾仍是史笔录入的官员，**完全意义的“个人声音”要到汉魏**——指出这一点者为 A）。
:::
:::

::: summary
盘库四柜：文体目录（每体回先秦认祖，但认祖不碰瓷）、叙事合同（史笔颁发“可信”，小说蹭信用千年）、象征词典（有两千年判例的公共隐喻）、人格脊椎（殉、游、担）。方法一箱：层累、地层、依据类型、认领与记忆——继续上班。先秦文学的童年到此闭馆；它的少年时代叫“汉赋”，它的青春期的名字，下一门课会一口气报完——**汉魏六朝文学**：帝国、大赋、竹林、陶渊明，以及“文学的自觉”那个著名的旧案，我们到时重审。
:::
