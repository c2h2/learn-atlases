---
title: "上古神话"
---

希腊神话有赫西俄德一家之言成套，北欧有《埃达》——中国神话的存世方式完全不同：**满天碎金，晚出有源，代代重铸**。本课三件事：摸清碎片的仓库、学会给神话“断代与查户口”、看懂中国人为什么把神话活成了道德与工程。

## 碎金与两大仓库 {#sec-cuijin}

::: definition 中国神话的存在方式 {#def-fangshi}
①**无系统史诗**：没有一部上古“神谱”，创世、洪水、羿与战炎黄各散在各书，且**书晚于事**——盘古开天最早的完整版本出自**三国吴人徐整《三五历纪》**（查遍先秦，没有这条书证），也就是说，我们熟悉的“开辟”是迟到者；②**两大仓库**：《**山海经**》十八篇（巫师地理书，国内/海外/大荒层层套着四方世界，保存最密的异神群：西王母其状如人、豹尾虎齿——与后来的瑶池贵妇判若两神）、《**淮南子**》（西汉淮南王宾客集合，把北方各家神话熔成宇宙论叙事：女娲补天、后羿射日、共工怒触不周山全在其中成文）；③**余料四散**：《楚辞·天问》一口气问出一百七十多个神话问题（版本的珍贵快照）、《左传》藏着被历史化的魔神（浑沌、穷奇、梼杌、饕餮四个魔神被译成四个不肖氏族——神话被录用为史官）、《列子》《帝王世纪》等晚出各书继续“补档”。
:::

::: definition 神话的四大集群 {#def-jiqun}
**开辟与造物**（盘古晚出；女娲在经典档案里的主职是补天，抟人造俗属后世层累——两笔账分开记）、**洪水与救灾**（共工振滔、鲧窃息壤、禹疏九河——三级火箭：灾、盗、治）、**文化发明**（燧人取火、神农尝草、轩辕作舟、仓颉造字而“天雨粟，鬼夜哭”（《淮南子·本经训》——文明的代价开场即鬼魅失语））、**反抗与不屈**（夸父逐日渴死、“弃其杖化为邓林”；精卫“常衔西山之木石，以堙东海”；刑天“执干戚舞”——失败者全部入册，悲剧岗位也属编制）。
:::

::: example 给“盘古”查户口 {#ex-pangu}
请排出盘古神话的文献年表，并说明“层累”方法在这里怎么用。
::: solution
户口表：先秦经籍无盘古；西汉《淮南子》论元气演化而无盘古其名；现存可征的最早完整记录是**三国吴徐整《三五历纪》**（原书已佚，赖《艺文类聚》引存“天地混沌如鸡子”），梁代任昉《述异记》续收盘古国土传说，唐宋类书层层转引反成今世通行本的祖本。**层累用法**：顾颉刚 1923 年《古史辨》方法论——“时代愈后，传说的古史期愈长”：周人最古的禹，到春秋加了尧舜，到战国有了三皇，到汉代有盘古——**盘古不是“更古的信仰被记录”，是“新的开辟需求被制造”**（为什么东汉—吴需要开天之神？族源混合与道教的宇宙论工程，都是学界给的答案）。查户口的收获：神话的**生年**比**内容**更值得先问。
:::
:::

::: intuition 中国神话的“公务员人格”
对比希腊：普罗米修斯偷火是悲剧叛逆，中国燧人氏取火是**发明登记**；宙斯们谈恋爱惹祸，中国诸神的履历表清一色是公共工程——鲧禹治水、神农尝草、后羿除害（猰貐凿齿九婴大风修蛇封豨，一份除害清单）、常羲浴月也管历法。这不是原始科学落后，是**记账文化的胜利**：神话在上古中国被“尚用”的史官精神收编，神必须**有功于民**才享受祀典（《礼记·祭法》：以死勤事、以劳定国、能御大灾、能捍大患——非此“不在祀典”）。于是中国神话的审美核心不是恐惧与崇高，而是**鞠躬尽瘁**：夸父渴死也要化林，精卫溺亡仍要填海——读神话也就是读早期中国的精神考核制度。
:::

::: history 从“子不语”到国民 IP {#sec-ip}
神话的两千年待遇史：**先秦**儒家“不语怪力乱神”但征用不客气（诸子寓言论学，山海巫书照用）；**汉**画像石把女娲伏羲画成人首蛇身对望（图像档案大增），王充《论衡》以“疾虚妄”火力稽核神话（汉代已有事实核查员）；**宋明**笔记续料而少体系；**二十世纪初**，学人以现代学科收拾遗产（旧学分野改组，歌谣与神话入新学之门）；**1923**顾颉刚《古史辨》序例唱出“层累地造成的中国古史”，神话研究从此有了断代手术刀；**1981**袁珂《中国神话传说》自上世纪中叶起数度增订，成神话集成与通俗化的枢纽；**2015 起**《西游记之大圣归来》《哪吒之魔童降世》等把神话题材做成票房 IP，游戏与网文跟进——**神话是中国叙事界唯一长生不老的公务员编制**。
:::

::: warning 用神话四坑
一**当史实读**：神话不是原始新闻，是观念的戏剧——大禹在神话学里首先是“治水的德性”而非一份水利报告（历史与传说之间隔着顾颉刚的层累层）；二**晚书证早信**：拿《三五历纪》证“盘古是夏商信仰”，等于拿 2020 年的传记证 1920 年的民俗；三**异文当正本**：西王母从《山海经》虎齿豹尾到瑶池夫人是两千年二次创作，任何“原版”都是某一层累；四**单向比附**：见洪水就说源于巴比伦、见盘古就说来自印度——比较神话学的本分是**平行研究影响**，证据链不足时，各美其美是最诚实的暂定结论。
:::

::: exercise 除害清单 {level=2}
《淮南子·本经训》记尧时“十日并出”与猰貐、凿齿、九婴、大风、封豨、长蛇之害，请整理为“灾害类型—公务员”表格（十日=旱，封豨=兽患，余类推），并解释为何中国神话的怪兽史等于一部减灾史。
::: solution
要点：十日并出（旱灾）—羿射；九婴（水火之怪）—杀；大风（风灾之兽）—逐；猰貐、凿齿（猛兽/劲敌）—击；封豨、长蛇（豕患蛇患）—殪；结论方向：怪兽名=灾害名，除害=治水除旱驱疫的**集体功绩叙事**，与希腊英雄为荣誉与爱情而战的叙事重心分道——“减灾史”读法即“有功于民”的叙事版。表格成立+结论成理即满分。
:::

::: exercise 小论文：神话为什么长生 {level=3}
写八百至一千二百字：从层累说到《哪吒》票房，论证“神话是被不断重写的公共硬盘”：①选一则神话（精卫/哪吒；若选白蛇等非先秦题材，须先说明其“入伙路径”），排其三站改写与时代需求；②回应“重写是否亵渎”一质疑；③讨论：为什么中国神话 IP 里“逆天改命”主题近年压倒“顺天敬神”？引课内《祭法》条款作对照。
::: solution
判分点：三站有书证意识（晚书晚证、异文各安其层）；亵渎之问答以“层累本是神话的存在方式”（《祭法》本身就是一次制度性的考核收编）；“逆天改命”分析联系当代观众自我叙事的需要，并指出这恰与传统中“人定胜灾”的公务员精神遥相呼应——看出这层连续性者 A。
:::

::: summary
中国神话的三把钥匙：**存世方式**（碎金、两库、晚书——先查户口再谈信仰）、**精神底色**（有功于民才入编，悲剧岗位也属编制）、**方法**（顾颉刚的层累刀：神话的生年比内容更值得先问）。神话不是文学史的序幕，是它的常驻编辑部——此后三章我们走进《诗经》：周人把歌谣编成经，中国文学第一次有了正典。
:::
