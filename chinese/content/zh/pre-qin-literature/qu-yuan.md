---
title: "屈原"
---

在他之前，《诗经》的歌者大多无名；在他之后，中国诗有了**第一张脸**：高冠、长剑、行吟泽畔的颜色憔悴。屈原把“我”写进诗里，把命写进诗外——《离骚》五百余句，是自传、是政治遗言、也是汉语浪漫主义的出生证。

## 一个人物，两层档案 {#sec-renwu}

::: definition 屈原档案 {#def-quyuan}
**史传层**：名平，字原（《离骚》“名余曰正则兮，字余曰灵均”与之互文），楚国公族，“博闻强志，明于治乱，娴于辞令”（《史记·屈原贾生列传》）——**中国第一份诗人传记**；仕途两朝：初受怀王信任任**左徒**，“入则与王图议国事以出号令，出则接遇宾客应对诸侯”，后遭疏绌（怀王—顷襄王两世、上官大夫与令尹子兰的谗妒为经、齐楚合纵连横为纬），两度放逐，终**自沉汨罗**（传统系于顷襄王二十一年、白起拔郢前后）。**文本层**：可靠著作圈定为《**离骚**》《**九章**》《**九歌**》（或谓加工民间祀歌而成）《**天问**》《**招魂**》（王逸一系归屈原，《招魂》或宋玉）——《远游》《卜居》《渔父》等则存作者争议；楚辞研究的第一间法庭，永远在审“**谁写的**”。
:::

::: example 《离骚》四部曲 {#ex-lisao}
《离骚》是中国古代最长的政治抒情诗（句数古今断法不一，本课不硬标），请给出四段式提纲并说明其**心理结构**。
::: solution
四部曲（循叙事—心理线）：**自传部**——“帝高阳之苗裔兮，朕皇考曰伯庸”（出身、生辰、美名三重天赋叙事，“名余曰正则兮，字余曰灵均”——**名字即政治纲领**：平正可法、公正可均）；**政治部**——“乘骐骥以驰骋兮，来吾道夫先路”的美政理想，与“众芳之芜秽”的变节痛账——由同僚变节写成**香草零落**；**求索部**——三次求女（宓妃、有娀之佚女、有虞之二姚）、上叩天阍、灵氛占卜、巫咸降神——**以恋爱的结构写政治的求合**（香草美人代码的全量运行）；**决意部**——一度去国远游（“国无人莫我知兮，又何怀乎故都”），却在升天之际“仆夫悲余马怀兮，蜷局顾而不行”——马都不肯走，于是陈辞请死，“愿依彭咸之遗则”。心理结构总结：**受挫—升华—回坠—殉志**——一部公元前四世纪的尊严报告，其回旋深度令“赋体”外壳形同虚设。
:::
:::

## 香草美人：一套政治符号学 {#sec-daima}

::: definition 代码破译手册 {#def-daima}
“**善鸟香草，以配忠贞；恶禽臭物，以比谗佞；灵修美人，以媲于君**”（王逸《离骚经序》——代码总表的正式公布）：香草系（兰、蕙、荃、茝、留夷、揭车——**人格的佩戴系统**：“纫秋兰以为佩”“朝饮木兰之坠露兮，夕餐秋菊之落英”——**饮食即德行**）；美人系（君、后、求女——爱情语法装载君臣遇合）；恶草系（萧、艾满庭——“户服艾以盈要兮，谓幽兰其不可佩”，**香臭颠倒即政治颠倒**）。这套代码的源头并档三说：**《诗》比德传统**（经学血缘）、**楚地巫风**（香草实为祭仪降神之具——人神恋爱结构，[[pre-qin-literature/songs-of-chu]] 专章再理账）、**士人的身体政治**（修身=治国同构，孟子“我善养吾浩然之气”是北方平行版本）。代码史影响：曹植“洛浦”、张衡“四愁”、李商隐“无题”、《红楼梦》女儿是水做的——**两千年“寄托”文学的总密码本在这里装订**。
:::

::: history 一个诗人的两千年官司与现代就职 {#sec-guansi}
**汉**：贾谊吊湘，司马迁传屈（“余读《离骚》《天问》《招魂》《哀郢》，悲其志”——**太史公亲自到汨罗打卡**）；刘安《离骚传》“与日月争光可也”（《史记》引），班固批其“露才扬己”（**汉代已开庭：忠臣还是狂士**）；王逸《楚辞章句》（东汉）宗“忠贞”说并注一切；**宋**：洪兴祖《楚辞补注》、朱熹《楚辞集注》（以“愤懑不平”重读，理学家的同情）；**清**：蒋骥《山带阁注楚辞》以地理考订行迹；**1920s—50s**：古史辨余波中曾有屈原作者权与时代定位的质疑讨论，1953 年**世界和平理事会**定屈原为世界四大文化名人之一（郭沫若历史剧《屈原》1942 年已把“雷电颂”演成民族号角——**疑案与尊神在同一世纪并行**）；**今天**：端午申遗（2009 中国端午节入联合国非遗名录）与“屈原是第一个诗人还是第一个诗歌IP”的网文辩论同屏——**他仍是活的 contested heritage（有争议的遗产）**。
:::

::: intuition 为什么是“浪漫主义” {#int-langman}
教科书给《离骚》贴“浪漫主义”，拆开其实是三项技术：**空间失控**（朝发轫于苍梧，夕余迈乎县圃——驾龙骖凤遍历天界，地理成为心理的投影幕）；**时间折叠**（前望重华、后约灵均，与古人对话如同事）；**物的参政**（佩兰、餐菊、纫蕙——人格外化成一部植物志）。北方《诗经》的想象力是**集市与农田的尺寸**（“送子涉淇，至于顿丘”），南方的想象力是**宇宙的尺寸**——不是谁高谁低，是两种心理地理学；后世李白上天入地走南派，杜甫一饭不离君国走北派——**中国诗的两大情绪回路，先秦就已布好线**。
:::

::: warning 屈原阅读四防
一**以意逆志过头**：把每句香草坐实为某朝某事（“兰”指谁、“女”指谁的索隐游戏——王逸的对照表是注本，不是考古报告）；二**把传记当实录**：《史记》屈原本传采楚汉传说，**层累痕迹明显**（郑袖、张仪诸情节与《战国策》《楚世家》出入）——读“史记中的屈原”与“楚辞中的屈原”要分两个信封；三**用忠君框架收编**：屈子的张力恰在“**忠于理想中的楚”与“忠于血缘的楚**”的撕扯（“既莫足与为美政兮，吾将从彭咸之所居”——美政在先，彭咸在后），简化成愚忠是对他的二次放逐；四**端午直接划等号**：粽子、龙舟的民俗史未必自屈原始（吴越地域旧俗说），是**纪念收编了民俗**的活标本——节日考古与诗歌考古分账。
:::

::: exercise 名字政治学 {level=1}
“名余曰正则兮，字余曰灵均”与“屈原名平字原”互文。请解释这份“名字训诂”为什么是**自述的政治纲领**，并对照现代人设（网名/宣言）写一句类比。
::: solution
要点：正则=平（“平”可训“正”“法”——公平可法），灵均=原（“原”训“均”——“均”有平、治双义）；父亲（及父师）以**可训诂的德目**命名后代，命名=立法（“皇览揆余初度兮，肇锡余以嘉名”——生辰、相貌、美名构成天赋叙事三件套）；对照：现代账号取“明镜”“天平”者，签名栏即宪章。判分：训诂准确+“命名即政治”的机制说明。
:::
:::

::: exercise 代码仿制 {level=2}
用香草美人代码写一段二百字的现代“求女”：主角求职/求项目，全程不出现“求”“职”二字，象征系统自洽（恶草=内卷话术，香草=手艺）。
::: solution
判分：①系统自洽（一种恶草对一种香草，勿混用两套喻体）；②有一次“零落”转折（兰蕙化萧艾=理想变质的现场）；③收束学“蜷局顾而不行”式动作（把决定藏在身体或物的迟疑里）。示例方向：投递=献佩，面试=叩阍，offer=得女，毁约=中道变色。
:::

::: summary
屈原四栏展签：人与书两层档案（史传采传说，文本有讼案）；《离骚》心理四部曲（受挫—升华—回坠—殉志，“名字即纲领，马不肯走即判决”）；香草美人代码（忠贞/谗佞/君遇的符号学，两千年寄托文学的总密码本）；被认领的两千年（从太史公打卡到世界文化名人）。下一章把镜头拉远：整部《楚辞》的巫堂、歌场与宋玉的“下东风”——南方文学的生态系总览。
:::
