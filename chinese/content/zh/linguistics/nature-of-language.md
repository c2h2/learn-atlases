title: "语言的性质"

上一章说清在哪一层说话；本章问说话用的是什么材料——**语言是一种能产装置：有限的材料，无穷的产品；本章的四根柱子是任意性、二层结构、价值与位移性，而每一根都要用汉语来压一遍，因为汉语在每一根上都留下了自己的划痕**。

## 定义：符号与它的三层动机 {#def-sanheng}

::: definition 任意性不是没有理由 {#def-renyi}
**通说脉络**（**索绪尔：符号的能指与所指之间无理据（“树”与 shù 之间没有物理关系）——**但这句话常被读成“语言想怎样就怎样”，正好读反（**本课把“理据”分三层记账（**①**音义之间：任意且已冻结**（**你无法说服任何人改读“的”；**这是系统的成本项，也是它保守的原因（上一章“任意性在词层，强制性在系统层”）**）；②**语素之间：可论证**（**“电脑、火车、内卷、可降解”：**复合与派生给新词提供局部理据，因此新词绝大多数不是凭空造的，而是用旧零件装的（第 4 章形态课的入口**）；③**用法之间：任意而可动**（**引申、比喻、讳饰、戏仿：**这一层是词义演变、双关与身份标记全部发生的场所（**本章的结论一句话：**任意性是一个系统级承诺，而全部文学与全部时髦都住在第二、三层**。
:::

::: definition 皮尔斯三分 {#def-pierce}
**画像、指标、符号**（**通说脉络：像似（像其对象）、指示（与对象共现）、象征（靠约定）——**本课用它做一件具体的事：**解释为什么拟声词不是任意性的反例（**①拟声是像似的，但它进入一种语言后就要受该语言的音系改造（“喵”在各语言里音节数与声调都不同；②它数量小、能产性低、且大部分新词根本不走这条路（**所以正确的表述是：**语言以象征为主，另两种被有限借用；**而诗人恰恰以放大后两种为业（第 12 课“双声叠韵与声训”：**把像似性重新塞回一个象征系统，是修辞的古老手艺**。
:::

## 二层结构与能产 {#def-erceng}

::: definition 两层的经济学 {#def-jingji}
**通说脉络**（**有意义的单位（语素、词）由无意义的单位（音位）组成——**这是一次成本革命（**记住几十个无义件，就能用组合生成无穷的有义件；**存储换成了运算（**本课给它的汉语对照：**汉字是另一套二层结构（几百个部件，几万字）：**两套二层结构在汉语里叠了一千多年（第 1 课“汉字与拼音”的前置；也是第 12 课书法课所说的“部件的字源义常常还在”——**口语的任意性与文字的理据性在同一个句子里并存，这就是中文读者对字形异常敏感的原因之一**。
:::

::: definition 递归之争 {#def-digui}
**通说脉络**（**乔姆斯基主张递归（把结构嵌进同类结构）是人类语言的核心机制；有研究以亚马逊某语言为反例提出递归非必要，其后又有争论——**本课的处理（**①**先把术语拆清**（**“从句嵌套”与“并列连缀”是两件事：**汉语的长句常用连缀（“他说不想去”、多重复句），而深嵌套在口语里罕见（**所以关于“汉语是否偏爱递归”的争论，多半是语体争论（**②**能产的层级**（**音系规则、构词、句法都能产，但能产度不同且随时代变（**“-ness、可～、～族、微～”在某几年突然高产（**能产性是可测量的时间序列，不是语法书的静态属性（第 1 课证据学：**这里语料库的证据优于直觉**）；**③**反例的代价**（**一个反例就能推翻普遍命题，也能推翻一个定义：**若“递归”被改到连并列都算，它就不再可反驳（第 3 课可反驳性：**这是关于“语言天赋”争论里最常发生的一件事——为了保住理论而换定义**。
:::

::: definition 价值：系统给的东西 {#def-jiazhi}
**通说脉络**（**索绪尔：“value”不同于“signification”；法语 mouton 与英语 sheep 不同义，因为各自系统的切分不同——**这是整个课程最有用的一条抽象（**因为它解释了所有“不可翻译”**（不是找不到词，而是两个系统在该处切法不同（**本课给它的四处回收：**韵书（一个字的“音”由它所在韵类决定）、音位（一个音的区别价值只在对立）、格律（一个字的声音价值由平仄系统在它身上切出的位置决定）、以及翻译文学（第 8 章借来的镜子：**你借来的不是词，是别人的切分**）。
:::

## 位移、虚构与装置 {#def-zhiyi}

::: definition 说不在场的事 {#def-buzai}
**通说脉络**（**位移性：语言可指称过去、未来、假设与不可能——**本课的文学推论（**①**文学是位移性的职业滥用**（**上一章的定义在此得到材料：**让人对未发生的事合作，靠的正是语言本来就能对未发生的事命题；**②**法律与货币同理**（**“合同规定三年之后”“这张纸值三百元”都是位移性命题被制度背书（**③**一个可检验的分界**（**动物通信多限于此时此地的食物与危险（通说脉络）——**因此“谈论不存在之物”的能力若为人类独有，那么虚构就不是文化的奢侈品，而是装置的标准输出（**本章不裁决独有问题，只登记这项证据的地位：它需要跨物种实验，而跨物种实验的可控性极差（第 1 课证据学：**这类命题目前只能靠①＋④，不能靠③**。
:::

::: definition 先天与后天 {#def-xiantian}
**四条论证与其强度**（**①**刺激贫乏**（**儿童听到的句子有限而说出的无限——**有力，但依赖“儿童听到的其实不多”这一测量，而自然语料统计显示输入量远大于早期估计（**这削弱了它**）；②**关键期与语言习得的普遍顺序**（**较强：**顺序普遍性难以只用教学解释；**③**克里奥尔化**（**皮钦变克里奥尔时出现新的语法——**常被当作先天装置的关键证据；争议在于接触情境本身已足够复杂（**④**特定语言障碍与孤独症的分离**（**有选择性语言障碍而一般认知正常者——**分离证据有价值，但病例稀少且诊断标准不一（**本课的方法论结论（**“天赋说”没有被证明，也没有被推翻；被证明的是：**这四条证据来自不同车间，把它们并列成“四条支持”是一种修辞，不是论证（第 1 课“证据链”与第 3 课独立来源：**这一课本身就是教材**。
:::

::: example 三个同音词的社会生命 {#ex-tongyin}
下列三种现象都建立在汉语的语音切分上，请为每一种填：**利用了哪一层动机、主要功能是什么（幽默？规避？身份？）、以及为什么英语里不容易复制**。
①“蓝瘦香菇”②“555／886”③谐音品牌名（如“骑乐无穷”一类）
::: solution
**①蓝瘦香菇**——**层：音义（**利用“音近即可暂时代换”的系统许可**）；功能：**首要不是幽默，是可否认（**一句被写成食物名的抱怨，平台与熟人都不易追责（第 8 章“加密作为保密协议”；幽默是其副产品；**难复制的原因**（**英语的音节—语素对应远不如汉语整齐：**汉语一个音节常常就是一个语素，所以整句可以被逐字替换成另一串有义音节（**这不是“汉语有趣”，是切分粗**）；**②数字谐音**——**层：正字与输入（**它同时是拼音输入法的产物——**生产条件再次决定文体（第 4 章谒客经济同款**）；功能：**速度＋圈内识别**；**③品牌谐音**——**层：语素（**替换的是同语音节里的语素（**它冒犯的是字形规范而不是语法（所以它的处罚来自文字管理而非语法（**这一栏极有诊断价值：一个社会先惩罚哪一层，就说明它把哪一层当作秩序**）；**总判**——**三种现象共同证明：**任意系统内部会出现大量局部的、可交易的像似性；它们不是语言的例外，而是语言的副产品被挪用——**而每一次挪用都需要一个动机（规避、速度或广告）：**这正好说明为什么“语言是任意的”与“汉语喜欢谐音”可以同时为真（**本章的判分点：**把两者对立起来的人，是把系统层性质当成了词汇层禁令**。
:::
:::

::: intuition 讳饰循环：三层动机的合奏 {#int-xunhuan}
**通说脉络**（**委婉语会随时间获得被讳饰物的色彩，于是需要新的委婉语（“残废—残疾—身心障碍”一类；“死”的替代语不断更新）——**这个循环是三层动机同时工作的最好标本（**①音义任意：**替换可以随便挑，因为没有理据约束；**②语素可论证：**新词总借旧零件（“障碍”本来是道路术语**）；**③用法可动：**一旦这个词与人频繁同现，褒贬就染上（**于是道德进步在词汇上表现为通胀：**同一份善意每隔二十年要重印一次钞票（**本课的警告：**别把通胀当堕落（**也别把新词当进步：**决定一个群体处境的是它的机会，不是它的词（第 9 课“语言与社会”将正面处理“政治正确语汇是否改变了态度”这一老题，此处先记一笔账**。
:::

::: history 一个概念的三代 {#sec-sandai}
**古典与中世纪**（**通说脉络：关于名称是“自然”还是“约定”的争论（《克拉底鲁》一类）——**注意：这场两千年前的辩论至今没换题（**任意 vs 理据、天赋 vs 使用，正是它的当代形式（**这就是本章值得讲史的原因——**第 11 课“观念史”：**有些问题不是没解决，是解决方式会过期**）；**1898—1950s**（**汉语被纳入这套问题：**《马氏文通》的框架之争、国语罗马字与方言调查、赵元任的声调与“施事—受事”描写（**对汉语而言，“任意性”还有一个额外的对手：字形（**汉字让汉语使用者天然倾向在字形里找理据（第 12 课汉字文化**））；**1950s—1980s**（**结构主义与生成语法各自制度化；同时“乔姆斯基语言学”成为大众词，指一切反权威文风（**一个理论被借用为姿态之后，它的可错性就被公众遗忘了（第 15 课追认**）；**1980s—今**（**认知语言学、语料库、实验与计算模型（**通说脉络：大规模语言模型让“语言能力是否需要同构的内部装置”重新成为可讨论的问题（**本章的结语提醒：**任何“模型已经证明／推翻了天赋论”的说法，都应在“证据四种”这张表上被降格——**模型没有母语者，也就没有可接受性判断，它只有分布；而分布恰好是第 1 课那张表里最弱的一种，也曾经是最新的一种**。
:::

::: warning 本课四坑
**“拟声词证明语言不是任意的”**（**以例外代替统计：**须同时给出拟声词的比例与它在音系中被改造的证据（上方皮尔斯条款**））；**“任意所以可改”**（**混淆三层：**音义层冻结，语素层可论证，用法层可动（**所有语言规划都只在第三层有效（第 9 课语言政策**））；**“不可翻译说明汉语特殊”**（**任何语言都不可完全翻译：**这是系统的普遍性质（价值**））；**用“语言天赋”打哲学仗**（**把四条不同车间的证据当四条独立支持：**并假设“后天论”意味着语言只是习惯（**而习惯无法解释：儿童受到的纠正有限，却会说出从未听过的句子——**本章只要求你分清：哪些是可核对的观察，哪些是为它们配的形而上学。

::: exercise 分层造词 {level=1}
为一个没有名字的经验造一个汉语词（例如“读到一半但不打算读完的状态”），并写明：**你动用了三层动机中的哪一层、为什么它可能被接受**。
::: solution
判分：**不得使用纯音译或纯编码**（**那不算动用理据：**复合、派生或旧词转义都算（**“为什么可能被接受”须指出它省了什么：**省字数、省解释或省风险（三者对应三层动机**）。
:::

::: exercise 给反例定价 {level=2}
找一个被语言纯粹主义者说“不合语法”的流行说法，写 100 字：**它的合法部分是什么（分布）、被反对的部分是什么（层级）、以及反对者真正反对的是什么（身份、模糊还是道德）**。
::: solution
判分：**三项不得合并**（**合并就是把身份意见写成语法判断（第 1 课管辖权表**）；**分布描述要能替换检验**（**给出两个可说的与两个说不出的对照句：**这才是“合不合”的证据**）。

::: exercise 小论文：切分即主权 {level=3}
写六百至一千字，评“**一个语言最深刻的性质不是它能表达什么，而是它在哪儿切开连续的世界：切得粗的地方，成员可以互换，于是产生谐音、双关与暗语；切得细的地方，成员各守一格，于是产生精确与不可翻译。因此比较两种语言，最有信息量的不是谁的词更多，而是它们在同一块经验上如何下刀；而一种语言被另一种改造时，最先失守的从来不是词，是刀口**”。须调用：**三层动机**、**皮尔斯三分与拟声词的地位**、**二层结构与汉字的两套二层**、**递归之争的术语问题**、**价值与不可翻译**、**讳饰循环**至少六项；并裁决：**“文字影响思维”这类说法，在本章的框架里应当被表述成什么强度的命题——你须给出一个可以被实验检验的版本，并说明它需要什么语料或实验**。
::: solution
判分点：六项机制（**三层、三分、两套二层、术语、价值、循环**）；裁决（**合格版本须降格为可检验的具体主张——**例如：“以语素—音节为单位切分语言的书写系统，会使使用者在语音切分任务中反应更快、并在同音替代游戏与暗语生产上表现出更高的可用性”（**检验：跨文字系统的语音切分反应时实验（如文盲—拼音文字—汉字三组，或同一批儿童学拼音前后测）与谐音产出的语料库统计（**判卷看是否指出混淆来源：**识字水平、语言本身、以及阅读经验的差异常与文字系统同变（**这就是“文字影响思维”难以证实又难以证伪的原因**）；结论若能写“**所以本章真正的结论是一句方法：不要把刀口当成世界的关节；两种语言在同一个经验上切法不同，恰好证明那个经验本来没有预先切好**”，即 A。

::: summary
装置归档：任意（**三层动机：冻结、可论证、可动**）、二层（**存储换运算；汉字是第二套二层**）、价值（**系统定价：不可翻译不是遗憾，是切分**）、递归（**先清术语，再争天赋**）、天赋（**四条证据来自不同车间**）、循环（**委婉语通胀：善意要每隔二十年重印**）。方法一句话：**别问它能不能表达，问它在哪儿下刀**。下一章：语音与音系——声音如何成为系统。
:::
