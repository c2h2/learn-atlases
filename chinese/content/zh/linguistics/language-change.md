title: "语言的变化"
---

上一章说变体是分层的社会事实；本章说变异是正在进行的历史——**语言变化研究里最反直觉的一条是：变化不是从集体开始的，而是从某一个人的口误、模仿或炫技开始，然后被一个群体决定收不收；因此它的规律性只能统计，不能被立法**。

## 定义：两条老命题 {#def-liangming}

::: definition 语音规律与词汇扩散 {#def-guilv}
**通说脉络**（**十九世纪后期历史语言学提出“语音规律无例外”：条件相同则变化必然一致；例外被归给类比与借用——**这是语言学第一次提出定律式命题——**它的功绩：让构拟与比较有了可推演的引擎（**它的代价：无法解释“同一个条件下有的词变了，有的没变”（**通说脉络**（**词汇扩散假说主张：语音变化是一个词一个词地在词库里传播的，处于中途的语言正好呈现分层（**通说脉络：此项假说由研究汉语方言的学者提出并以其语料为关键证据（**本课的定位：**两条不是“对错”，是尺度不同——**规律说的是音系的最终状态，扩散说的是变化的传播过程（**一个讲结局，一个讲过程；而语言学史上大多数这类争论，最后的和解都是“两个都对，各管一层”（第 1 课层级：**本章是这条方法最锋利的一次演练**。
:::

::: definition 为什么变化不可预测 {#def-buke}
**一个进化论式的两幕结构**（**①**变异在个体层面大量产生**（**口误、儿语、偷懒、炫技、外语干扰、群体认同表演——**这一层近似随机（**②**采纳在社区层有方向**（**频率、易说程度、说话人声望、网络结构、以及“听起来像谁”（**这一层高度选择性（**于是（**变化的方向可以事后解释，事前预测极难（**因为第二幕依赖社会网络的结构（**通说脉络：创新常在紧密群体内获得地下威望，而要靠弱连接跨群体扩散（**本课给它的名字：**变化是一种两阶段筛选，跟自然选择同构，因此它也必然继承同样的宿命——**没有目的、没有进度、也没有终点（第 11 章进化论条款：**这是把“语言演变”讲成“语言进步”的唯一科学反驳。
:::

## 变化的机制清单 {#def-jizhi}

::: definition 音变：省力、系统与借用 {#def-yinbian}
**常见方向**（**同化、弱化、脱落、异化、换位、混合；以及相反方向的强化（**通说脉络**）；**汉语的四张账**（**通说脉络：全浊声母清化、尖团合流、平声依清浊分调、入声在北方官话里消失并派入三声——**每一张账都同时显示规律与例外（**“茶、陈、除”声母同变是规律；“某些常用字在方言里留在旧读”是扩散的中途（**本课的追问：**省力为何总被系统拉住（**因为擦得太干净会撞车——**清化让一批旧对立消失，而语言会用送气、声调、复音化补回区别（**汉语史上最大的一次补洞是复音化：单音词大量变成双音词，一部分正是为了在音位对立于减少后重新获得区分度（**通说脉络：这是汉语史的标准解释之一（**于是本章最重要的一条机制浮出：**变化不是单向的腐蚀，而是“区别度”与“省力”之间的持续再平衡（第 3 章“省力与清楚的均衡”在历时层的复现。
:::

::: definition 重新分析与类推 {#def-licheng}
**重新分析**（**表层串不变，底层结构变了：“公园”从“公共的园子”到一个不可拆的词；“怀疑”从两个词到一个动词（**它的形式签名：**结构边界移动而语音未变（**最干净的一类变化，因为它可以当场演示（**类推**（**按现有模式造出新形式或不规则形式被规整（**它解释“例外为什么会消失”，也解释“规则为什么会有新的例外被造出来”（**本课把两者叫作变化的两只手：**重新分析改了图纸，类推照图纸加建（没有前者，语言不能改结构；没有后者，改了就传不开。
:::

::: definition 语法化：实词如何变成小词 {#def-yufahua}
**通说脉络**（**实词→语法词→附缀→屈折零件；伴随语义磨损、语音弱化、句法范围扩大与主观化——**汉语的四个样本（**“了”（完毕义动词→完成体标记）、“把”（持握义→处置式标记）、“被”（表义的动词→被动标记）、“们”（同类义→复数附缀）（**通说脉络：各条来源的细部仍有讨论，本课只取其“实→虚”的方向为通说**）；**四个伴随症状**（**语义变虚、语音变轻、能搭配的范围变宽、语义重心移向说话人的态度（**最漂亮的是主观化**（**“你看这事”的“你看”已经不要求你真的看（**这是语用层的东西沉淀进语法的现场（第 7 章的言语行为在第 4 章的形态里落了户。
:::

## 语义、接触与词库 {#def-yuyi}

::: definition 词义变化的四种朝向 {#def-sizhong}
**扩大、缩小、升格、降格**（**通说脉络**）；**汉语的三例**（**“江、河”由专名变通名（扩大）；“金、臭、谷”缩小（“金”本泛指金属，“臭”本指气味，“谷”本指百谷）；“爪牙”由武士变为帮凶（降格）；“祥”由吉凶之征专指吉（缩小兼升格）（**通说脉络**）；**本课的用法：**义变的方向常被写成“词义发展史”，而它的真实驱动力往往在社会层：**忌讳使词降格、礼貌使词替换、制度使词缩小（第 6 章讳饰循环：**没有一种语义变化是纯语义的**。
:::

::: definition 接触：借词、语义借用与底层 {#def-jiechu}
**三种影响**（**借词（整件搬来）、语义借用与仿造（照本国零件装外国图纸）、底层影响（一种语言被另一种替代后留下的痕迹）（**通说脉络**）；**汉语的三层时间**（**①两汉至唐代与西域及梵语接触（通说脉络：如“葡萄、师子、琉璃”一类上古中古借词，以及佛经翻译带来的一批双音词；②近代经由日语汉字词的大规模输入（**通说脉络：这一层争议最多而使用最广：现代汉语里“经济、社会、革命、文学、电话”一类词与日语近代术语的关系是学界长期讨论的题目（**本课的保留：**这三类关系（日语自造、日本人用旧词译新义、中国人取自日译书）都存在过，所以任何一刀切的说法都不可靠（**这就是第 1 章“史料分层”在词汇层的复现（**③当代英语借词与字母词（**通说脉络**）；**最妙的一例**（**“世界”：佛经中以“世”表时间、“界”表空间的合词，今为最普通的通用词——**一个词的语义扩大，记录了一次思想体系的移植（**本课称这类词为“来路不明的日常词”：**它们天天被用，而它们的语法与语义是别人送的（**这就是为什么词汇史总是思想史最诚实的部分。）。
:::

::: example 给一场正在进行的合并拍快照 {#ex-kuaizhao}
设计一份调查，研究你熟悉的一种语音或词汇合并（如 n/l、尖团、某两个韵母、某两个代词或称呼词），要求：**①选十个高频词与十个低频词；②说明你将按哪三个社会变量分层；③说明你如何区分“变化中”与“两派混用”；④给出一个可证伪的结论句式**。
::: solution
**①**——**词频是本章的自变量：高频词的变化速度可能与低频词相反（**高频因自动化而更容易弱化，也因被反复听到而更难被替换（**这正是词汇扩散研究的关键分歧点——**所以词表必须按可查证的频率表排序，不能凭印象**）；**②**——**年龄（第一维，最省事的近似时间）、教育与媒体接触（第二维，接近“标准账户”）、本地认同时长或居住年限（第三维）**）——必须声明三者互相混淆到什么程度；**③**——**“变化中”是社区内部有系统的分层，“混用”是同一个人在不同语体里摇摆：**用风格轴（第 8 章）区分二者：**同一个人在朗读与闲聊中差异大＝风格分层；差异小但年龄组间差异大＝进行中的世代更替（**这是本章最实用的一条技术）；**④**——**可证伪句式示例：“在本社区，该合并在 30 岁以下、受教育年限较长的组中已完成，且高频词先于低频词合并；若 30 岁以下组无差异或低频词先变，则本假说不成立”（**判分：**没有“若不成立”这一半，就不算科学结论（第 3 课：**语言学里最贵的句子是那句“我错了会看出来”**）。
:::
:::

::: intuition 变化不发生在集体里 {#int-jiti}
**一个常被忽略的推论**（**语言不是一个会变的有机体，而是一群人各自说话、彼此调适的结果；所谓“一种语言发生了变化”，严格说是“一代人学到的系统与上一人使用的系统有可测差异”（**三条后果（**①**任何“我们的语言正在被毁掉”的命题都无法成立**（**因为被毁掉的只是某一层的现行规范，而规范从来就是这一层最省事的写法（②**语言政策改变不了方向，只能改变速度**（**它能加速采纳（教材、考试、广播），却不能指定创新：没有人能立法让一个词流行（上方两幕结构**）；③**你此刻正在参与**（**每个人既是变化的受害者也是它的代理人（**本章最后的态度：**一个语言学家听见“从前的汉语更规矩”时，应当想起从前某个年轻人在某处第一个说错，并且被同伴觉得好听（**这就是全部历史）。
:::

::: history 两千年里谁在管语言 {#sec-guan}
**汉代—唐代**（**字书、韵书与经典注疏：语言规范由经学与选官制度执行（**通说脉络：**正字与读音是科举的技术要求（**这是世界上最早、最持久的“标准语基础设施”（第 1 章目录即审查的祖本**））；**宋—清**（**韵书系与口语音分道：**读书音与说话音长期并记（**于是“古今音”之争其实是“雅俗账本”之争（第 3 章“文白异读”的语言社会学前身**）；**19 世纪末—20 世纪初**（**切音字运动、拼音方案之争、国语运动：**语言规划第一次成为现代国家工程（**通说脉络：这一时期“语言”与“民族”被绑定（**本章的警告：**绑定给了拼音文字道义动力，也给了方言歧视道义外衣（第 8 章“陆军与海军”**）；**1949—1950s**（**汉字简化、拼音方案、普通话推广与全国方言调查（**规范与调查同年起步（**第 8 章那句“动机相反而互相需要”的最准确注脚**）；**1990s—今**（**全球化下的双语多语、语言活力评估与濒危语言记录（**通说脉络：国际组织提出代际传递等指标（**本章的收尾：**评估指标本身也会改变政策——**一个被写进指标的“活力”定义，会决定哪种混合算双语、哪种消亡算自愿（**测量从来不是中性的（第 1 课清单是眼镜**。
:::
