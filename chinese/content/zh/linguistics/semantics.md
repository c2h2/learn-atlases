上一章把句子切成成分；本章问切出来的东西值多少——**语义学的第一个动作是把一个看起来很自然的想法推翻：意义不在词里。它在词与世界的关系里、在词与词的关系里、在使用它的共同体那里；而这三个地方给出的答案常常不同**。

## 定义：三件分开的事 {#def-sanjian}

::: definition 指称、涵义与意义 {#def-zhicheng}
**通说脉络**（**弗雷格区分同一对象的两种“给予方式”：晨星与昏星指称相同而涵义不同——**这一步解释了三个日常难题（**①“鲁迅写的《阿 Q 正传》的作者”这种句子为什么有意义（**②替换保真原则的失效处正是涵义所在：**“小明明知 A 是 A”荒唐，“小明明知 A 是 B”合理（**③翻译中最顽固的部分：**词对不上不是找不到词，是两种系统在同一个对象上切出的涵义不同（第 2 章“价值”与“切分即主权”）。
**奥格登与理查兹的意义三角**（**通说脉络：符号—思想—所指物，三者之间是“指涉”而非等号——**本课把这张图当成本章的宪法（**它禁止三种常见错误：**把词直接贴到物上（于是争论“这个词的本义是什么”，而本义只是一个历史上的用法被特别授权；**把词直接等同于心象（于是要求每个抽象词都配图；**把解释循环当作缺陷（**词典用词解释词，循环无法取消，只能被“使用”接地（**这就是为什么本章会一路走到语用学**。
:::

::: definition 组合性及其反例 {#def-zuhe}
**通说脉络**（**整体意义由部分意义与组合方式决定——**它的力量与它的边界（**力量：**解释了为什么人能理解从未听过的句子（第 2 章能产性在意义层的对应（**边界有四类，每一类都是一个研究纲领：**①成语（**“踢桶”类习语的字面义不足以推出用法；**②语气与修辞（**“你真行”在别的语境里是反话（**语义学解释不了的部分，正是下一章的全部主题；**③格式贡献（**上一章：“送”与“让”的意义有相当比例来自格式；**④搭配限制（**“打”可以打伞、打人、打官司、打毛衣：**没有一条义素分解能算出它下一步能接什么（**本课的判分：**组合性是默认假设，不是被证明的定理：**遇到反例，先问是它失效，还是我们对“部分”的划分不对（第 4 章词界：**这里同样是划线问题**。
:::

## 词义的结构 {#def-jiegou}

::: definition 义素分析：一张漂亮的账 {#def-yesu}
**通说脉络**（**把词义分解为区别性特征：男人＝［＋人］［＋男］［＋成年］——**它最漂亮的地方与最先塌的地方（**漂亮：**亲属词几乎完全被特征决定（**这正是汉语的优势题材：**伯、叔、姑、舅、姨、堂、表七个词在英语里挤成三个，因为汉语的账本多了三条科目（父系母系、长幼、性别（**本章例题就做这笔账；**塌的地方：**“光棍是未婚男子”简洁，但“新娘”不等于“＋婚＋女”：**它有仪式、有裙子的颜色、有一整套不必言说的场景（**这就是框架与脚本研究（框架语义学一类，通说脉络）对义素分析的补充：**有些词的意义是一份流程表，不是一张属性单（**第 9 章“叙事的语法”与本章在此握手**。
:::

::: definition 范畴化：经典特征与原型 {#def-yuanxing}
**通说脉络**（**Rosch 一类实验显示范畴判断有典型性梯度与家族相似性，边界与中心并非同等清晰——**本课的三点处理（**①**它不推翻组合性**（**它推翻的是“范畴必有充要条件”：**这是一个逻辑学愿望，不是语言学事实；**②它把语义学推向社群**（**典型性依赖经验频率与文化（**于是一个人的“鸟”的中心，部分地是他的童年（**③汉语的一个具体验证**（**“蔬菜、水果、粮食”的边缘成员在各年龄段的分歧最大；而“鱼”在汉语日常分类里可以把鲸、墨鱼、娃娃鱼算进去（通说：俗分类与生物分类不一致）——**这是可以当场做的小实验：**列十个名词，让人判断“是不是鱼”，分歧最大处就是范畴的边缘（**第 1 课证据学：**这类内省数据便宜、可重复，且足以证伪“特征说”**）。
:::

::: definition 角色、配价与“吃”的多重身份 {#def-jiaose}
**通说脉络**（**施事、受事、与事、工具、处所等语义角色独立于句法位置；动词对论元数量的要求叫配价（**汉语的演示（**“鸡不吃了”上一章的歧义在此得到干净的描述：**同一表层，不同角色指派（**再看“吃”（**吃饭（受事）、吃食堂（处所）、吃工资（来源）、吃官司（受影响者）、靠山吃山（来源）——**它的配价不是固定的，而是格式各取一角（**本课的结论：**动词像一个有多个插座的电器；格式决定插哪一孔（**这句话同时是本章对“一词多义是否只是任意约定”的回答：**多义是系统的：各义项共享一个抽象骨架，差异由格式与环境补足（**这也解释了词典学的老困境：**义项切到第几条为止？（**切到“能被新格式检验”为止——**这就是本章反对无穷细分的理由（第 1 课：**分类是眼镜，不是标本**）。
:::

## 隐喻与修辞 {#def-yinyu}
::: definition 概念隐喻及其循环风险 {#def-yinyu2}
**通说脉络**（**莱考夫与约翰逊主张日常概念系统具有隐喻结构：时间是资源、争论是战争、Up 是好——**它的真贡献（**把隐喻从修辞搬进语法：**它解释了为什么“把这个论点的基础拆掉”无人觉得奇怪：**一个死的隐喻仍然在提供推理结构（**这与第 12 课“比喻派了工资就得上班”完全一致（**它的风险（**通说脉络：亦有批评指出其例证有循环之嫌——**从表达推出概念映射，再用映射解释表达；而跨语言的检验并不总是支持同一映射（**本课的态度：**把概念隐喻当作一张提问表（**问“这个表达依赖哪个方向性”，而不是当作一份已归档的心理档案；**并且要求可证伪版本**（**若“时间是资源”为真，则应能预测：一个把时间表述为循环而非资源的语言，其储蓄与守时行为会有系统差异——**这类预测的实证结果并不整齐（**这就是本章对“语言学能否谈心理”这条老路的诚实评估**。
:::

::: example 亲属词的账本 {#ex-qinshu}
把“堂兄、表兄、舅舅、姑姑、姨、公公、婆婆、小叔子”拆成义素表，并回答：**①汉语在这张表上多设了哪些科目；②英语在哪几格上合并；③一项最近的、可核对的变化正在删除哪一格**。
::: solution
**①科目表**——**［±父系］［±长于说话人］［±男性］［±血亲／姻亲］［辈分］**（**“堂”与“表”只差父系一栏；“舅／姑／姨”只差性别与父系两栏（**②英语合并处**——**brother-in-law 一词吞掉四格（**丈夫的兄弟、妻子的兄弟、姐妹的丈夫、以及广义的姻亲男性（**sibling 合并性别，cousin 合并父系与长幼（**所以英译中不是变复杂，是被迫查户口（**这就是“切分即主权”在亲属制上的表现，也是人类学把亲属词当作制度证据的理由（**③正在被删的一格**——**长幼：**“堂兄／堂弟”在年轻人口语中常被“表哥／表弟”统一为“哥／弟”两档，甚至按年龄而非宗族排序；同时独生代使“舅、姨、叔”失去指称对象而只剩称谓功能（**可核对的证据是称呼语料与家庭结构统计（**本课的方法论收尾：**一项语言变化能否被察觉，取决于它先动哪一栏：**动边缘（长幼）不易被察觉，动中心（性别）立刻引发规范争论（**这一条同时适用于语法、语用与本章最开头的指称问题（第 9 课将正面处理“谁有命名权”**）。
:::
:::

::: intuition 一词一义是个政策目标 {#int-yiyi}
**通说脉络**（**术语学与辞书编纂长期追求“一词一义”，而自然语言始终多义——**本课把这两件事分别归位——**①**多义不是懒惰**（**有限符号要应付无限经验，扩义是最便宜的手段：**新造一个词的成本是让人记住，旧词加一义的成本是让语境负责（**而语境通常是免费的（第 5 章“语法是一种强制”：**语言强迫你交的一些表格，比另一些便宜得多，所以它优先用便宜的**）；②**单义是一种制度成就**（**术语、国标、法律条文、药名：**它们要付出巨大的维护成本（审订、公布、处罚、教育）才能维持“一词一义”（**所以“一个词到底有几个意思”这个问题，在科学里问的是分布，在法律里问的是授权——**这也是上一章分词的教训：定义落地就需要有人签字**）。
:::

::: history 意义研究的四次转向 {#sec-yiyi}
**指称转向**（**弗雷格、罗素：**把意义先放在语言与世界之间处理（**遗产是今天的形式语义与真值条件（**代价是情绪、修辞与诗意被推到门外（**这正是下一章要接手的部分**）；**用法转向**（**后期维特根斯坦：**“意义是它在语言中的用法”（**通说脉络**）——**这句话把语义学的部分业务分给了社会学与语用学——**它也带来一个风险：**“用法”是无限的，除非有人规定哪些用法算数（第 1 课描写与规定的分界在此重新开庭**）；**结构转向**（**义素分析、对比语言学：**在语言内部比较切分（**它的成就就是本章的亲属词例题；**它的限度是把语言当成静态的棋盘**）；**认知与语料转向**（**原型、框架、脚本、构式、搭配频率（**通说脉络：大规模语料显示词的义项分布高度偏斜，少数搭配占去大部分出现（**于是“核心义”不再只是直觉，而是一个可以报告比例的量——**本章最后的诚实栏：**语料能算出哪个义项最常见，算不出哪个义项更“真”；**凡把频率说成本质，都是本章开头那张宪法禁止的事**）。
:::

::: exercise 小论文：意义在哪里 {level=3}
写六百至一千字，评“**每当有人说‘这个词不是这个意思’，他实际上在做一次制度行为：他在主张自己对该符号的解释权，并隐含地请求一个权威来背书。语义学的困难不是找不到意义，而是意义同时住在三个地方——系统的切分、共同体的用法、以及个别场合的意图——三者都会给出正确答案，而它们互相矛盾时，语言里没有终审法院**”。须调用：**指称与涵义**、**意义三角与解释循环**、**组合性的四类反例**、**义素与框架**、**原型与边缘分歧**、**隐喻的循环风险**至少六项；并裁决：**在“系统的切分／共同体的用法／场合的意图”三者之间，词典编纂、法庭语言与对外教学各应把哪一格排在第一位——三行回答，每行须给出一次会输的代价**。
::: solution
判分点：六项机制（**涵义、三角、组合、框架、原型、隐喻**）；三行回答（**词典：共同体用法优先，代价是永远滞后于新用法，并把边缘成员记为“俗语”；法庭：场合意图优先（立法原意），代价是词义随法官的可及心理波动，因而可被策略性制造；教学：系统切分优先（对比母语者的账本），代价是教会了规则却教不出语感，学生说得出却听不懂（**判卷看三条是否都写出了代价而非只写好处；并看是否承认：**三格排序不同会导出不同的错误类型，而识别错误类型才是这套分析的实际用处**）；结论若能写“**所以本章教的不是‘意义是什么’，而是一次纠纷该送到哪个法庭：问错了法庭，再聪明的语义学家也只能给出一个语法正确的答案**”，即 A。
:::

::: summary
意义归档：涵义（**替换失效处即涵义所在**）、三角（**禁止三种贴错标签的等号**）、组合性（**默认假设，四类反例各是一个纲领**）、义素（**亲属词是汉语的主场，框架是它的补丁**）、原型（**边缘分歧可当场测**）、隐喻（**提问表，不是档案**）。方法一句话：**先说你在哪一格找意义，再谈它是什么**。下一章：语用学——说出去的话与做出来的事。
:::
