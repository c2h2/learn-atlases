上一章把连续的声音切成单位；本章把连续的话切成单位——**而汉语在这里给语言学出了本课程里最难的一道题：“词”这个单位在印欧语里像是天然存在的，在汉语里它需要你亲手划一条线，并且要为这条线的位置负责**。

## 定义：语素与它的识别 {#def-yusu}

::: definition 最小单位 {#def-zuixiao}
**通说脉络**（**语素是最小的“形式—意义”配对单位；同一语素的不同实现叫语素变体（**如“们、每…都”一类不与所有名词组合的分布限制；英语 un- 在 lip 前变为 im- 一类**）；**识别方法**（**切分＋替换：**在保持意义可辨认的前提下不断切，直到再切就只剩语音零件（**“学习”切为“学／习”后，“习”单独几乎不再承担“学习”义（**本课的提醒：**这一步已经含有一个判断——你在决定“什么算同一意义”（**意义相同到什么程度才算同一个语素？（**这是形态学与语义学的边界纠纷，本章先记账不判决（第 6 章一词多义与同源／同音的区分将再开庭。
:::

::: definition 词根、词缀与“自由” {#def-ziyou}
**通说脉络**（**自由语素可单说，黏着语素必须挂靠——**汉语的特点：**大量语素介于两者之间（**“民、语、者、水、雨”在某些句子里可单说，在另一些里绝不（**所以汉语的“自由”是分布上倾向于单说，而不是逻辑上可以单说（**这就已经把“词”的问题从性质问题变成了频率问题（第 1 课证据学：**这里语料库的证据第一次变得不可或缺**。
:::

## 构词法 {#def-gouci}

::: definition 四种手段与汉语的两项偏好 {#def-sizhong}
**手段清单**（**复合、派生、形变（屈折）、转类——**汉语的分布：**复合占绝对优势，派生有一套“准词缀”（子、儿、头、们、化、性、者、员、手），屈折几乎缺席，转类在古代汉语极丰（“衣、王、雨”用作动词）而在今语大幅收缩（**通说脉络**）；**传统六类复合结构**（**联合（道路、买卖）、偏正（火车、周刊）、动宾（司机、注意）、主谓（地震、心疼）、附加（桌子、石头）——**本课的态度：**六类不是分类学的发现，是汉语构词法的可教性装置（**它让一门没有屈折的语言也能把“内部结构”说清楚（第 5 章句法：这六类几乎就是短语结构在词内的复写（**这正是汉语语法学最大的一个谜与最大的一个机会：**词的内骨架与句的外骨架同形（**下面“分形的语言”条款处理它。
:::

## 汉语的核心难题：词界 {#def-cijie}

::: definition 四条判据，互相打架 {#def-sitiao}
**①能否单说**（**回答时能否独立成句；**②是否最小自由形式**（**最小的能独立使用的组合；**③扩展是否自由**（**中间能否插入别的成分：**“说话”可成“说过话”，“东西（物件）”不可成“东和西”（**这就是著名的扩展法**）；**④语音线索**（**轻重音、停顿、连读变调与儿化的范围——**难点在演示（**“火车”与“烧饼”：扩展法说“火车”是词（不能说“火和车”**？其实“火和车”语法成立但意义变了**）、“烧饼”是词；而“走路”在“走了一条路”里被拆开（**于是它到底是词还是短语？（**本课的标准答案：**它在这一句里是短语，在那一句里是词：**一个形式在不同用法里属于不同单位层级，这不是失败，是事实（**我们习惯把“它是词吗”当成一个有唯一答案的问题，而这个问题的形状本身来自拉丁语法——那里词形变化会把答案写在词身上（第 1 课“范畴进来时要交分布证明”：现在你知道这句话要收什么税了。
:::

::: definition 分形的语言 {#def-fenxing}
**通说脉络**（**汉语的复合词结构与短语结构高度同型（“看见”动补／“看完”动补；“黑色”偏正／“黑的”偏正）——**三个后果（**①**汉语语法学一百年的困难在此**（**如果词与短语同构，那么“先划词再讲句”就任意为武；如果先讲结构，那么“词”根本不必存在（**第 5 章将看到构造语法如何处理这一步：**它宁可谈“位置、替代与构式”，也不给词颁发证书（**②**学习者把汉语学得快，正在这条**（**会了“火车”的结构，就能猜“电车、汽车、马车”：**透明度是汉语词汇的第一件礼物（**代价是构词的边界模糊；**印欧语的边界清晰，代价是每个词都要记形（**透明度与边界是同一笔交易的两侧（**③**计算语言学必须替你决定**（**中文分词是汉语信息处理的第一道工序；不同分词规范给出不同的词表，而错误常常不是程序 bug，是规范分歧（**通说脉络：公开评测长期以统一标注集为准，而学界也长期承认“词”的定义是这套标准的一部分（**这是“理论决定工程”的一个极干净案例：**你们在手机上看到的每一个汉字被正确归到同一个词，是因为二十年前有一群人在一份文件里签了字**）——第 1 课“清单是眼镜”的最强当代版。
:::

## 形态在时间与社会里 {#def-shijian}

::: definition 语法化与形态的周期 {#def-zhouqi}
**通说脉络**（**实词→语法词→附缀→屈折零件：一条被反复观察到的路径（“了、过、着、去、在”一类的来源；英语 be going to → gonna 一类）——**本课的核心命题（**形态不是语言的原始状态，而是语法化的沉淀物（**换句话说：**分析语会重新长出屈折，只是慢（**所以“汉语缺乏形态变化”这句话是彻底的共时误读（**它把一种语言的账本现状当成了它的物种特征（第 1 课共时与历时：**这是那一条二分在本课程里最锋利的一次应用。
:::

::: definition 形态的社会分层 {#def-shehui}
**通说脉络**（**同一语法手段在不同语体中比例悬殊：**“～性、～化、～度、可～、被～、非～”在现代书面汉语与公文、科技语体中高度密集，而在口语中低频（**本课把这一串词缀称为“现代汉语的准屈折”（**它们的密度直接测出语体的正式度（**这就是为什么“拟古”“公文化”“学术腔”一听就能分辨——**第 16 课语体：**形态不是语法问题，首先是一份身份声明**）；**新派词缀的寿命**（**“门”“吧”“客”“奴”一类词尾曾高产（通说脉络）——**高产的准词缀是词汇市场的热钱：**它们三年内遍地，十年后多半只在旧新闻里（**可核对的预测：任何被媒体批量模仿的新词缀，其能产曲线将在两年内见顶（**这是本课程第一次给出可检验的预言（第 3 课可反驳性：**如果你能拿到逐年语料，这一条可以当场证伪。
:::

::: example 你来划线 {#ex-huaxian}
在“火车、烧饼、走路、开灯、看见、研究研究、东西、国家”八个形式上画一条词／短语界线，规则必须写成**两句以内**；然后回答：**你的规则在哪一个形式上最勉强，为什么**。
::: solution
**参考规则**——**A. 若中间插入其他成分后意义不变，则判为短语；B. 若不能插入且可独立回答提问，则判为词；**勉强处逐个可见：**“走路”在 A 下有时是词有时是短语（**你的规则必须允许它随用法变，否则你就在替语言预先划账本**）；“看见”不可插入（×看和见）但能拆成“看／得／见”类补语结构（**这说明“能否插入”测的是补语关系的紧密度，不是“词性”**）；“研究研究”是同一词的重叠，重叠是形态手段（**按此它反而更像“带语法义的词形”**）；“东西”不可拆而“国家”可说“国与家”（**但那是修辞用法，不是普通句法（**于是你必须规定“扩展只在普通陈述句中测”**）；**本课判分点不在划线本身，在“最勉强”那一栏：**它暴露你的规则实际在测什么（意义？频率？语感？书面规范？（**而绝大多数人的规则实际测的是“我是否在课本里见过它连写”——这是一个正字法标准，被误当作语法标准（第 1 课层级：**这是汉语使用者最容易犯的一次串车间）。
:::
:::

::: intuition 词是一张发票 {#int-fapiao}
**为什么这门课不肯给“词”下定义**（**因为任何定义都是一张发票：它写清了你要买什么，也写清了你付什么代价（**“能单说”便宜但漏掉大量黏着成分；“最小自由形式”整齐但对汉语失效；“不可插入”实用但对补语与重叠失灵；“语音程度”客观但要测（**本课要你练成的习惯是：**遇到单位争议，先说发票，再选发票（**这与“汉语有没有词”是完全不同的问题——**汉语当然有“词感”，说话人会毫不犹豫地把“东西”当一个词；只是这份词感同时包含语义、频率、书面与习俗四份证据，而语言学要求把它拆开——**这就是本章真正的收获：**你从此不能再说“汉语没有形态”，也不能再说“汉语有词而无语法”——这两句话的毛病是同一个：用一个层级的结论去替另一个层级结账。
:::

::: history 一场持续一百二十年的划线 {#sec-huaxian}
**1898**（**《马氏文通》：**先假设词类，再从拉丁框架里取“字类”之名（**它的办法是把汉语的“字”当作词——**这一步在当时极其先进（它使汉语语法成为可能**），也正是此后一切争论的源头（**第 1 课“范畴进来时要交证明”：它当时没交（**当时也不需要交**））；**1940s—1950s**（**结构主义进入中国：**“扩展法”与“代替法”被引入，词与短语的划分成为技术争点；同时“形态学是否构成独立层级”的分歧开始影响教材（**通说脉络：这一时期确立的“语素—词—短语”三级，至今仍是汉语教学的默认结构（**它是一项制度成就，不是一个被证明的事实**））；**1980s**（**朱德熙一类以分布与功能重建汉语语法（通说脉络：以词组为句法基干的思路把重心从“词”移到“结构”，本章“分形”条款就是它的余波（**这是本课程所说的“换研究对象”而非“改对错”的又一例（第 1 课四次转向**））；**1990s—今**（**中文信息处理迫使定义落地：**分词规范、词表与标注集成为国家标准或行业约定；同时类型学把“分析语／综合语”从等级改为连续谱（**通说脉络：**这一改动让“汉语缺乏形态”这句话彻底失去了学理根据（**本章结语：**工程标准今天比理论定义更稳定，因为没有人需要它正确，只需要它一致。

::: exercise 小论文：透明度的代价 {level=3}
写六百至一千字，评“**汉语把大部分词汇做成透明的：看见、火车、地震、司机——人人看得出结构，于是人人能猜新词。这份透明度的代价是词与短语、结构与结构之间没有海关关卡：语法学家一百二十年没能划出一条所有人都承认的线。印欧语恰好相反：每个词身上盖着屈折的护照，边界清清楚楚，代价是每个形式都得死记。因此所谓‘汉语灵活、英语严密’，真相是两种语言把同一笔成本记在不同科目上——一个记在边界上，一个记在成员上**”。须调用：**语素的识别与意义同一性问题**、**四条词界判据的冲突**、**分形结构**、**语法化周期**、**准词缀的语体分层**、**分词的工程约束**至少六项；并裁决：**“成本记在不同科目”这一说法能否推广到句法（如主语、时制）——若能，请以汉语的主语问题做一次同样的记账**。
::: solution
