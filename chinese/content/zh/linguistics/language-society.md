title: "语言与社会"
---

前七章把语言当成一件装置；本章把它当成一项资产——**社会语言学的第一课不是“方言很有趣”，而是一个方法：找一组有规律的语言差异，再找一组有规律的社会差异，然后证明它们的规律相同；做到了这一步，说话人的出身就变成了可以统计的变量**。

## 定义：变体与变量 {#def-bianti}

::: definition 六个名词，一次分清 {#def-mingci}
**通说脉络**（**方言（地域变体）、社会方言（阶层、职业、年龄、性别）、语域（按场合切换的用法）、体裁与语体（按写作常规成型的用法）、个人习用（**一个人所有变体的集合**）——**本课的记法：**方言按“你是谁”分，语域按“你在做什么”分，个人习用是这两个轴交叉后你所在的那一格（**许多争吵之所以发生，是因为有人把语域问题当方言问题控诉（**“现在的年轻人不好好说话”是年龄方言的抱怨，而它常被写成语法衰落（第 1 课共时与历时、第 9 章语体的前身**））。
:::

::: definition 语言是一支有陆军的方言 {#def-junui}
**通说脉络**（**一句常被引用的话：“一个语言就是拥有陆军与海军的方言”；它不是定义，是一个社会学提示——**本课把它读成一条制度陈述（**“标准语”不是一个自然存在的高级变体，而是一套机构：一个音系表、一部字典、一套教材、一门考试、一家广播机构（**去掉任何一件，它就退化成又一种方言（**汉语的具体账本**（**通说脉络：普通话的定义是“以北京语音为标准音、以北方话为基础方言、以典范的现代白话文著作为语法规范”——**请注意三条定义各自都做过减法与让步：**北京语音被减去一批土音与轻声儿化；北方话被减去大量只在北方口语里通行的词；白话文著作里不合规范的句子被宣布不算（**所以“标准”不是采集来的，是裁剪出来的（**这也是本章全部政治性的来源：**裁剪需要有人持刀，而刀上通常写着“规范”两个字（第 1 章目录即审查、第 4 章分词标准：**定义落地总需要有人签字**）。
:::

## 方法 {#def-fangfa}

::: definition 拉波夫的两招 {#def-labov}
**通说脉络**（**二十世纪中叶以前，方言学去乡村找“最纯的老年男性发音”；城市里的土话被当作“败坏的普通话”而不值得描写。城市社会语言学的做法是：**①**风格轴**（**同一说话人被诱导出从“注意读音”到“随便聊天”的连续语体：念词表、念段落、读最小对偶、自由交谈、以及情急时的第四、第五类**）——通说脉络：朗读时最接近标准音，闲聊时最接近本地土话（**这证明变异不是随机噪声，而是沿一条可观测的风格轴分布（**每个说话人都会用整条轴，所以“不标准”不是能力缺陷，是位置选择**）；**②**难堪轴**（**用“修正研究”绕过自尊：先让人判断哪种读音“正确”，再在不知不觉中采集其实际发音（**通说脉络：结果是一条“自尊—实际用法”曲线：低层群体在意识不到的时候更常使用本地变体，而一旦察觉就向标准靠拢；中层群体的自我定位偏离最大**）——这一条是社会学可以使用的语言学证据（**它把“虚荣”变成了曲线（**本课要求你记住方法而不是结论**（**结论依赖具体社区与具体变量，换一项即可能翻转；而“先找出说话人自己不敢承认的那个变量”这招是可复制的**）——第 10 课田野方法与本章共用一条伦理：你不知道自己在观察什么，直到你问对一个问题。
:::

::: definition 两种威望 {#def-weiwang}
**通说脉络**（**“威望”分公开威望（标准音、正式场合的收益）与地下威望（本地群体的信任与“地道”）——**这一区分解释了规范语言学长期无法解释的一件事（**为什么明知“读书音”更正确，许多人仍然不肯改（**因为他们在另一套账本上挣钱（**地下威望的兑换物是：被本群体当作自己人；它的成本是：在标准化考试、朗读、面试里吃亏**）——这就是本章的第一道“代价题”（**语言政策的真实困难从来不在“哪种更好”，而在“让谁来付转换成本”（下方“审音的代价”条款会把这笔账算到元）。
:::

## 汉语的三个标本 {#def-benbiao}

::: definition 审音：一次改读的社会成本 {#def-shenyin}
**通说脉络**（**汉语的异读整理持续了几十年（1963 年《普通话异读词审音表》初稿，1985 年修订公布；此后若干字的读音在社会上仍有争议，2016 年前后的新一版征求意见稿因舆论反应而未能施行（通说脉络）——**本课把这一串事件当一份完整的成本单（**①**收益侧**（**教学、朗读、词典、语音识别、跨方言交际：**统一读音是降低全国交易成本的基础设施（②**成本侧**（**每一位教师的既有知识、每一版教材与录音、每一部字典的检索、每一位中高考考生已背下的答案（③**为什么“从俗”会激怒人**（**因为被改掉的读音往往属于已经折旧完毕的存量：改读等于宣布一批人半生的发音是错的（**舆论里“向错误妥协”这句话的真实内容是：**我不愿意无偿转让我的既有资本（**这不是语言学争论，是产权纠纷穿着语言学的鞋（第 2 课定义权即分配权的最贴切案例（**而任何一次审音若只算语音学的账，就一定会在公共舆论里输——**它必须回答：谁付钱，谁受益，是否补偿（第 5 章对策三问：社会语言学把它写成了必修题）。
:::

::: definition 称呼语：一套裸露的社会语法 {#def-chenghu}
**通说脉络**（**汉语的称谓系统承担了其他语言用形态或词汇承担的信息：亲疏、上下、内外、场合（**四个可观察的变化（**①“师傅”从行业称谓泛化为对陌生劳动者的通称，又在学校与写字楼语境里退让给“老师”；②“小姐”经历职业称谓—泛尊称—污名化的完整生命周期（**这是一个词在二十年内走完的语义耻辱环（上方讳饰循环的社会版）；③“老板、总、某工、某处”的用法随企业所有制变化而消长；④“哥、姐”在单位与网络社群中复活，用作低风险的亲密投资（**本课的判读：**称呼是语用最贵的一层，因为选错立刻可见、无法补救（第 7 章“称呼选错是语用失误而后果严重十倍”）；**而且它是双向的：**你可以用“老师”抬高对方，却不能用它抬高自己（**所以汉语的称呼表实际上是一张现场填写的权力关系图（**这就是为什么“该叫什么”常常是会议前最重要的一句话**。
:::

::: definition 性别语言：从“差异”到“立场” {#def-xingbie}
**通说脉络**（**二十世纪后三十年的研究常报告女性更靠近标准音、更多使用礼貌与缓和语；此后此类结论被大量修正：**所谓女性特征往往是“地位较低群体的语言行为”，在女性获得高地位群体成员身份后随之改变（**本课的处理（**①**先做方法检查**（**许多早期研究把“说话人性别”与“听话者性别”“场合正式度”混在一起统计（**这是一个典型的第三变量问题）；②**再做立场分析**（**“娘娘腔”“少女感”“夹子音”一类评价语的流行，说明被评价的从来不是语言本身，而是“一个人在性别上是否越界”（**语言是身份指控的替身**）——这是本章对“语言与性别”能给的、也是最有用的判断——**第 10 课网络语言将再遇到它：当一群人开始纠正另一群人的语气，通常是别的争议找到了一个安全的话题库。
:::

::: example 一次口音审判 {#ex-kouyin}
情境：一位员工在会议上用带方言色彩的普通话汇报，同事在群里模仿其语音并笑称“听不懂”。请用社会语言学写一份 150 字的分析：**①被冒犯的对象是谁、②被攻击的语言变体承担了什么社会功能、③“好好说话”这一要求在这件事里的真实内容、④两种可实施的处置及其各自受益者**。
::: solution
**①**——**被冒犯的是方言群体及其成员资格；**针对语音的嘲笑几乎从不针对“清晰度”（**同样的语音在“自己人”嘴里不构成障碍**）；**②**——**该变体承担内部信任与出身忠诚（地下威望账户）；**嘲笑它的实质是逼迫对方向公开账户转移资产；**③**——**“好好说话”在这里不是可懂度要求，是身份要求：**若真是可懂度问题，处置应是允许重复、书面确认或换座位，而不是模仿（**可核对的检验：**把同一份汇报换成书面文本，嘲笑是否消失（若消失，则议题从来不是内容）；**④**——**处置 A：以“会议语言规范”统一要求（**受益：需要跨方言协作的一方；成本：把转换成本交给最没有议价能力的人，且执行必然靠羞辱）；处置 B：只禁止模仿与嘲笑，允许可懂度协商（**受益：被攻击者与会议秩序；成本：效率略降，需主持人承担）；**本课判分：**能写出“A 便宜而 B 贵，所以机构总选 A”这一句，就是本章的成绩单（**标准是一种基础设施，而不是一种德性**。
:::
:::

::: intuition 语言能力的市场 {#int-shichang}
**一项语言能力的价值不取决于它多难，而取决于谁能兑换它**（**四种可观察的汇率变动（**①**一种变体的官方位置改变**（**普通话推广使方言的公开收益下降，地下收益上升（上方两种威望）；②**一种文体的经济位置改变**（**公文、文案、短视频口播：口语化写作忽然比书面长句值钱；**于是“错别字”标准让位于“钩子”标准（第 9 章与第 1 章分发格式）；③**一种口音的媒体可见度改变**（**当某一地区的口音在喜剧、影视与直播中反复出现，它同时获得可辨识与可嘲笑两种资本——**这是本章对“口音歧视反而增加”现象的解释：**可见度是双刃的；**④**一种语言的政策地位改变**（**下一章讨论少数民族语言与双语教育时，将把同一张表再展开一层）；**本章的收束提醒：**任何关于“语言水平下降”的主张，先问：下降的是哪种能力的兑换价——**这个问题通常能把一场道德辩论变成一次可核对的调查（第 1 课证据学：**这是社会语言学教给普通读者的唯一一件必需品**。
:::

::: history 一门学科的三次转向 {#sec-shehui}
**1940s 以前**（**方言学就是地图学：**下乡、录老年男性、绘制同言线（**它的预设是“纯”的语言在乡村与老人身上，城市是污染（**这个预设保证了它看不见自己的对象）；**1960s—1970s**（**变异研究：**城市、分层、频率、统计显著性（**通说脉络：社会语言学由此获得学科地位，因为它带来了可检验的假设）；同一时期关于“语言与思维”“受限语码”的争论（**通说脉络：一项影响极大的主张后来被批评为把工人阶级语言写成“缺陷”，而其作者本人并无此意（**这是本章反复示范的一课：**一个描述性区分被读成等级判断，往往只用一次报纸转述）；**1980s—今**（**实践、身份、立场、网络与多语（**通说脉络：研究重心从“社会决定语言”转向“语言参与建构社会”）；**汉语的并行线**（**通说脉络：1920 年代的方言调查与国语运动、1950 年代的汉语规范问题学术会议与方言调查、1955—1958 年的规范与拼音、1980 年代以后的社会语言学刊物与方言保护讨论（**一条贯穿始终的紧张：**规范与调查同时起步、互相需要，而它们的动机相反（**前者要统一，后者要记录；本章的全部伦理问题都来自这一句**。
:::

::: warning 本章四坑
**“标准语更合乎逻辑”**（**标准是行政选择；语音、语法与词汇上没有一项内部指标使某一变体更“合理”（上方定义条款：**把基础设施说成理性，是最常见的一次修辞））；**“方言正在消亡，所以要抢救”**（**动机可以理解，但要清楚：语言转用的动力是机会结构，不是审美；除非改变机会，记录只是存档（下一章田野方法课会给出“记录”与“维持”的区别））；**把群体差异读成群体能力差异**（**性别、阶层与方言的多数早期结论都栽在第三变量上（上方性别①））；**为“得体”辩护或为“土”辩护**（**两种辩护都是在道德账户上交易；**本章的立场是把成本与收益写清，把道德判断留给当事人（第 1 课描写与规定）。

写六百至一千字，评“**一切语言政策都是一张转换成本的分摊表：统一读音、推行通用语、拼写改革、正字法简化、乃至平台的内容审核，都在把同一笔费用在群体之间挪动。公开文本总是把这笔费用称作‘便利’，因为没有人愿意承认自己在向别人收费。因此评价一项语言政策的唯一诚实的问题是：谁改了口，谁没有改，以及改口的人得到了什么**”。须调用：**标准语的机构清单**、**普通话定义中的三次裁剪**、**风格轴与难堪轴**、**两种威望与账户转移**、**审音的成本单**、**称呼语的现场权力图**至少六项；并裁决：**在“通用语能力”与“本地语言维持”之间，是否存在一种把成本分配得更公平的政策工具——须给出一个具体工具（补贴、双轨教学、媒体配额、考试口径之一），并说明它会被哪一方抵制**。
::: solution
判分点：六项机制（**机构、裁剪、两轴、账户、成本单、称呼**）；工具（**合格答案须写出资金或课时从哪来、由谁执行、以及它如何避免把成本再压回同一个人身上——**例如：把方言课时加进已经排满的课表，等于向语文教师与家长收费（**判卷看是否指出抵制方的利益逻辑而非“观念落后”**）；结论若能写“**所以本章不给人放下方言的理由，也不给人嘲笑方言的理由；它只坚持一件事：凡是宣布‘为了大家方便’的政策，都必须公开那张分摊表，因为方便是一种收入，而收入要有收款人**”，即 A。
