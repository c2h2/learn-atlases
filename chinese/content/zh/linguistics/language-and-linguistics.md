title: "语言与语言学"
---

前面二十门课都在用“语言”这个词；本课开始检查它——**语言学的第一课不是学会说“主谓宾”，而是学会分辨：你在描述人们怎么说，还是在规定他们应该怎么说；这两件事在中文里共用一个名字，因此中文母语者尤其容易一辈子分不清**。

## 定义：一门学科的门与门槛 {#def-meng}

::: definition 五个层级与一个接口 {#def-cengji}
**通行的分工**（**语音—音系／形态／句法／语义／语用，加上词汇与篇章这两处接口（**本课称之为“一台机器的五个车间”（**为什么要先分车间：**因为绝大多数语言争论都是串车间的（**“‘涉及到’是病句吗”是正字法问题；“‘被自杀’合法吗”是构词问题；“他家儿子考上大学了”通不通是句法问题；“你这是什么意思”则多半是语用问题（**把它们混在一起问，就永远吵不完（第 3 课“层级”是整个课程的地基：**判对错之前，先定在哪一层判**。
:::

::: definition 描写与规定 {#def-mingming}
**规定性**（**它是一条规则：告诉你怎么写不会被扣分（**它的价值在标准化考试、编辑出版与对外教学（**它的问题不在严格，在于冒充科学（**它把“尚未收录”说成“错”，把“权威没这么用”说成“不通”（**描写性**（**它是一个观察：记录实际被使用的所有形式，包括你不喜欢的（**它的难处不在技术，在于姿态：**描写不等于赞同（**语言学家记录“被自杀”不等于支持它，正如医生记录病灶不等于表扬细菌（**本课的判分线：**一门学问若只能回答“对不对”，它就不比一本手册多什么；若它能回答“为什么有人会这样说、这样说会被谁听懂”，它才开始有用**。
:::

::: definition 三对二分 {#def-erfen}
**语言与言语**（**通说脉络：索绪尔区分社会的系统与个人的使用——**本课的读法：**这是语言学获得对象的那一次切割（**在此之前只有文法、修辞与小学；在此之后才可能有一门科学：**你必须先假设有一件叫“英语”的东西存在，才能去研究它（**这件东西其实是一个统计的近似（**这就是它最脆弱也最必要的一步（**第 1 课“清单是眼镜”的学科史版**。
**能力与表现**（**乔姆斯基区分说话人内化的规则与实际上说出的句子（**方法论后果极大：**语料里的口误、断裂、改口都不算反例（**这让理论免疫于大量脏数据，也让它容易被指责为不可证伪（**本课的态度：**能分清哪些反例是致命的、哪些是噪声，就是一门方法论（第 3 课可反驳性分级：**“口误不算”是一条便宜的辩护，只有当它能独立说明噪声从何而来时才不是便宜的**。
**共时与历时**（**同一时刻的系统与跨越时刻的变化——**索绪尔的著名比喻是下棋（**棋子此刻的关系与这盘棋的走法历史是两套描述（**本课补一条本课所有课程都会用到的推论：**绝大多数“语言正在败坏”的抱怨，都是把历时现象当成共时错误在投诉（**变化不是败坏，但变化对使用者确实是不便：**这两种说法都对，而它们分属两个层级（**这就是为什么语文教师与语言学家常常各说各话且都对（第 2 课“作者活着/作品有效”的调解书，此处重签**。
:::

## 语言这件装置 {#def-zhuangzhi}

::: definition 识别特征 {#def-tezheng}
**通行清单**（**任意性、二层结构、能产性、位移性、文化传承、置换（**本课只重点讲三条（**①**任意性**（**“兄”与“xiōng”之间没有物理理由——**注意它常被误用为“语言是任意的所以怎么改都行”（**它只说符号与对象之间无理据，不说符号与符号系统之间可以随意：**系统内部是极端保守的（**你不能把“的”改成“额”，正如你不能把象棋的马改成会飞（**任意性在词层，强制性在系统层（**这句话是本章的第一道判断题**）；**②二层结构**（**几十个无义单位（音位／笔画）组成无穷的有义单位（**这是人类语言最省资源的发明（第 1 课“记号有限，组合无穷”：**汉字其实是另一套二层结构：几百个部件写出全部文献（**两种二层结构并存，是汉语书写与口语互相塑造千年的原因（第 12 课“汉字与拼音”的前置**）；**③位移性**（**可以谈不在场、未发生、不可能的事（**文学、法律、宗教、科学全部依赖这一条（**本课的定义：**“文学”是位移性的职业滥用——让说话人不在场、事件未发生，而听者仍然合作（第 2 章“虚构作者”与第 1 章“虚构是承诺”的语言学根**。
:::

::: definition 动物通信与人类语言 {#def-dongwu}
**通说脉络**（**蜜蜂的舞蹈、长尾猴的报警叫声、鲸歌的变化、教黑猩猩手语的实验（如 Washoe、Kanzi 一类，其结论至今有争议）——**本课的处理（**①**先分清三种解释**（**先天装置、学习限制、训练效果（**猴叫有指称而无组合，人工手语有词汇而少句法：**争议的真正焦点是“缺能力”还是“缺动机与语境”（**②**为什么本章要讲这个**（**因为它给出唯一一种跨物种的检验：**如果语言只是智力的一般应用，那么聪明的动物应当表现出零星语言；如果它是专门装置，那么应当出现“其他一切都聪明，唯独不会说话”的分离（**孤独症与特定语言障碍的分离案例，以及“会说话的鹦鹉”，都提供了部分证据（**本课不裁决，只要求：任何关于“语言使人成为人”的论证，都得先过这一关**。
:::

## 语言学史速写 {#def-lishi}

::: definition 三套前史 {#def-qianshi}
**印度**（**波你尼的梵语语法（通说脉络：公元前若干世纪已有对梵语动词与词根的生成式描写——**它的惊人之处在于方法：**用有限规则与元语言生成全部合格形式（**与现代形式句法的关系是真实的谱系（19 世纪欧洲学者经由梵语接触到它（**第 4 章“语法是一个装置”的第一次出现**。
**中国**（**小学：文字、音韵、训诂（**通说脉络：它们的目标是读经与正字，不是描写口语——**这解释了汉语语言学的一个长期特征：**它以文本为对象，以注释为方法，以规范为动机（**“小学”不是科学语言学，但它提供了 1900 年以后唯一的本土概念库（**本章后面每一章都会回收一笔这笔遗产（韵部、等呼、清浊、入声、平仄**。
**欧洲**（**从《语法》逻辑语法到历史比较语言学（**通说脉络：18—19 世纪的语言谱系研究把语言当成有机体与家谱（**本课把它叫作“语言学的第一次科学化”，也叫它“第一次生物学化”：**前者使它成为学科，后者使它背上一百年的种族与优劣争议（第 11 章“进化论条款”的源头**。
:::

::: definition 现代的四次转向 {#def-sizhuan}
**结构转向**（**索绪尔、布拉格、哥本哈根、美国描写主义（**共同点：**把语言当系统，把意义推迟（**②**行为与田野转向**（**美国语言学对印第安语的调查训练出一套“没有母语者可用时如何工作”的方法（第 11 章田野方法条款：**这门课的技术底色其实来自人类学（**③**生成转向**（**1957 年以后：解释优先于描写、直觉可作证据、普遍语法可被假设（**争议：**证据的地位（**④**功能、认知与语料转向**（**1970 年代以后：频率、用法、构式、原型、语料库——**本课的立场（**四次转向都不是“推翻了”，而是改了研究对象：**系统—使用—能力—概率：**这就是为什么任何一本教科书的第一章都还是在讲这五对概念（**也提醒你：**读到任何“语言学已经证明”，先问它在哪一次转向里成立**。
:::

::: example 一条微博的五个车间 {#ex-weibo}
句子：“被就业了三年，现在连‘被增长’都懒得说了。”请按五个层级各提一个可检验的问题（不许提“对不对”），并指出：**哪一层的问题最有可能被普通读者误当成别层的**。
::: solution
**形态**——**“被＋动词”能带时量补语吗？“被就业了三年”里的“三年”修饰什么（**这是构式与论元结构问题，可用替换检验——**被表扬了三年 ✓／被吃饭了三年 ×（**音系／正字**——**引号与“被”连用的书写惯例、以及口语中的重音落点（**读者最容易把这层当成语法（**因为汉语的“规范感”很大部分是书写训练（语义**——**“被就业”把主体自己实现的事写成被迫，这是一个语义反转：**它不是“被安排就业”，是“被统计成就业”（**这是它全部讽刺力的所在（语用**——**它预设读者知道某类统计造假；它是身份标记：会用这个词的人属于某个舆论共同体——**第 10 课“暗语＝入场券”**；**篇章**——**“连……都懒得说了”把第二分句写成对第一分句的评论，形成自我消解的语气（**最容易被误认的层**——**语义与语用：**读者会说“这个词意思不通”，其实他的意思是“我不接受它的预设”（**这正是本课要治的病：**把“我不同意”翻译成“它不合语法”（第 11 课“‘不合法’是一个语法判断还是身份判断”：现在你有了回答它的工具**）。
:::
:::

::: intuition 语言学的证据学 {#int-zhengju}
**四种证据与其强度**（**①母语者可接受性判断（**快、便宜、易被规范训练污染**）；②语料库频率（**客观，但只能证明出现过，不能证明不可说**）；③实验（反应时、眼动、离线评分：**可控，但生态度低**）；④语言类型与历时材料（**能证伪普遍命题，代价是自然观察（**本课的方法论结论（**任何一条结论，先问它靠哪一种证据；只有①的结论叫“我认为”，①＋②才叫“汉语里”，加上③才敢谈机制，加上④才敢谈普遍（第 3 课“证据链”与第 8 章“独立来源”的语言学版本：**这也是为什么本课要求你以后每次引用一个语言‘事实’，都标出它的来源层级——这是本课程二十年一贯的老规矩**）。
:::

::: history 一门学问的四张面孔 {#sec-miankong}
**前现代**（**三套前史并行：**读经、正字、学梵（**语言研究是别的学问的仆人**）；**19 世纪**（**历史比较法：**语言成为有家系的对象（**它的副产品是民族叙事（**这也是它后来最难洗掉的记录**）；**1916—1950s**（**结构主义：**系统、对立、分布；**田野方法成为技术核心（**这一时期中国学者同时做了两件事：把韵书读成音系，把方言调查成地图（第 10 课与方言课**）；**1957—1970s**（**生成语法：**解释、能力、普遍（**它的遗产是把“人为什么能说出没听过的句子”变成科学问题——**它的负债是让“语料”地位下降——数据可用性争议至今未结；**1980s—今**（**语料库、实验、神经影像、计算建模与大规模模型（**通说脉络：**“语言能力”这个概念第一次有了非人类的对照物（**于是本章开头的两个老问题以新形式回来了：**描写与规定的分界、能力与表现的分界**）——这就是语言学最乐观的地方：**它每隔三十年就得重做自己的一年级生**）。
:::

::: exercise 分层 {level=1}

::: exercise 小论文：哪一层有权说话 {level=3}
写六百至一千字，评“**语言共同体里每一次关于‘正确’的争吵，实际上都是一次管辖权争议：正字法庭、语法法庭、用法法庭与声望法庭各自宣称有权终审，而它们的判据互不相通——前者的依据是文件，第二者的依据是可接受性，第三者的依据是频率，第四者的依据是谁在说。语言学不能宣布四家都是错的，它只能把这份管辖权表钉在门口，让每一次判决都写清由哪个法庭作出**”。须调用：**五个层级**、**描写与规定**、**共时与历时**、**任意性与强制性**、**四种证据的强度排序**、**四次转向**至少六项；并裁决：**四家法庭中是否应当有一家在公共教育中拥有优先权——若是，是哪一家、代价是什么；若不是，标准语考试应当考什么**。
::: solution
判分点：六项机制（**层级、姿态、时态、系统、证据、转向**）；裁决（**两条路线都可得分，但必须付代价——**主张“用法法庭优先”者须承认它无法阻止教材滞后与对外教学的低效；主张“可接受性法庭优先”者须承认它对识字率低的社群不友好，并且把母语者的偏见当成了终审权（**判分看是否出现一个具体制度设计（例如：考试只考歧义消除与信息传递，不考“是否合某版规范”**）；结论若能写“**所以语言学给公共教育的不是答案，是一份管辖权地图：它教学生区分‘我不会这样写’‘没人这样写’与‘不能这样写’——这三者的差别，就是识字与语言学的距离**”，即 A。
:::
