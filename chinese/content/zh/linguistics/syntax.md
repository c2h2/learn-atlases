上一章说汉语的词与短语同构；本章就在这个麻烦上盖房子——**句法学研究的是组合的层级，不是组合的顺序；而它最大的一个发现是：顺序看得见，层级看不见，我们却正是靠看不见的层级来解释为什么有的句子有两层意思**。

## 定义：层级而不是排队 {#def-cengji}

::: definition 为什么需要成分 {#def-chengfen}
**通说脉络**（**“我昨天读了两本厚书”不是十个词的线性串，而是层层套叠的成分（**证据一：可位移与可替换的单位不是单个词，而是整块（**“读了两本厚书”可以整体被“读了它”替换**）；**证据二：歧义常常是结构歧义而非词义歧义（**“咬死了猎人的狗”两种理解用完全相同的词与顺序——**若只有排队，这两层意思无法分开（**这就是本章的入口：**结构歧义是层级存在的直接观测证据（**第 3 课最小对立：一个可当场演示的证据**。
:::

::: definition 两种画法 {#def-lianghua}
**直接成分分析法**（**通说脉络：美国结构主义的二分切分，层次切分图；中国的“中心语—附加语—补语”分析与之高度同构（**通说脉络**）；**依存语法**（**通说脉络：每个词至多一个支配词，关系是词与词的二元连线——**两者对同一句子都合法（**本课的处理：** 成分之争不是画图偏好，而是“关系存在在哪一层”的主张：**成分法认为存在大于词的块，依存法认为块只是派生现象（**判分点：**任何一次句法分析，先声明用哪种本体论，否则后面对“错”的指责就失去对象（第 1 课“在哪一层说话”的句法版**。
:::

## 汉语的六件常用结构 {#def-liujian}

::: definition 语序与虚词 {#def-yuxu}
**通说脉络**（**汉语基本语序为主—动—宾，修饰语前置于中心语，而关系从句、领属与数量都在名词之前——**由此产生一个著名的学习难点：长定语（**“我昨天在书店碰到的那位先生的弟弟”：**英语用关系从句后置，汉语全部前置，于是名词来得很晚（**这不是“汉语落后”，是信息压缩的位置不同（第 4 章透明度：**汉语把修饰做在明处，把结构藏在大段前置里（**而虚词是汉语真正的格标记（**“的、地、得、了、着、过、把、被、给、让、对、关于”——**上一章说汉语没有屈折；本章补一句：**它把屈折的活儿外包给了这些小词，代价是小词的意义难教、且极易被学习者省略（**对外教学的绝大多数“语法错误”，其实发生在这一层（第 10 课“语言与教学”**）。
:::

::: definition 主题与主语之争 {#def-zhuti}
**通说脉络**（**“那本书我看完了”“米饭我吃过了”：一个名词在句首、后面是全主谓；汉语长期被类型学称为主题显著语言——**两派各说（**A. 句本位派：**句首是主语，汉语主语不必是施事（**代价是“主语”失去跨语言可比性；**B. 主题派：**句首是主题，主语另在深层（**代价是要为一个话题位置另立一套装置（**本课的处理（**①**先记录一个可核对的事实**（**两种分析对同一句话的预测不同：例如并列、反问与“都”的位置对哪个成分敏感——**这些是可设计的小实验（**②**再承认一个理论事实**（**“主语”这个概念来自形态丰富、主格清晰的语言；用它分析汉语，就像用有齿的钥匙开无齿的锁：**能开，但你转不动某些方向（第 4 章“范畴进来要交分布证明”**）；**③**最后记住本章的钩子（**下面构造语法条款会说：**也许根本不该找“主语”，该找“格式”**）。
:::

::: definition 格式与构式 {#def-geshi}
**通说脉络**（**论元结构构式语法把“格式”当作形式与意义的配对单位；双及物、使动、处所等格式在多语言中被反复确认——**本课用三个汉语格式讲清它的价值（**①**双及物**（**“他送我一本书”：**“送”本身不必然含“给予方向”，是格式提供了它与受益论元的组合许可（**②**“让”字**（**“我让他打了”可表使令、允让、被动三种：**三种意义不能从“让”一词推得，因为一个词没有三种内核；是三个不同格式共用了同一个词（**③**“被自杀”一类**（**上一章说“被＋动词”是构式；这里补上：**该格式自带“非自愿”的语义贡献，于是它可以接纳一个在语义上不合常规的动词而立即被读懂——**这是本章最强的论证：**格式有独立语义（**它的代价：**格式会越列越多，直到有人认为不该再叫语法，而叫清单**）——本课判分：**清单不是语法失败，是使用频率与规约化程度的语法（**这也是上一章“准词缀热钱”的句法版：格式也会红、也会死**。
:::

::: definition 结果补语与动结式 {#def-buyu}
**通说脉络**（**“V-结果／V-趋向／V-可能”（打伤、看见、走得动）是汉语最富特色的组合之一——**三件值得注意的（**①**一个动词性成分表示结果，等于把“致使＋变化”压进一个词（**这是汉语动词与论元结构的特殊接口（**它使汉语能用极短的动词串叙述极复杂的因果链：**“他推开门跑出去摔倒了”——**五个小句的因果压缩成一行（**②**它难以被二语学习者掌握**（**为什么不说“我看了累”？（**因为补语要求结果由动作直接导致，这是一个语义约束，而不是一条形式规则**）；**③**它也是汉语“词与短语同构”的极端案例**（**第 4 章：能插入吗？“打得过伤吗”？——**补语处在词、短语之间那道划不清的线上（**上一章的“分形”在此再兑现一次**。
:::

::: definition 量词 {#def-liangci}
**通说脉络**（**数词一般不直接修饰名词，需量词；个体量词、集合量词、度量衡量词、临时量词；部分名词有固有量词——**本课的三个观察（**①**量词是名词的一次分类**（**通说：形状与功能被编码进分类（条、张、面、峰一类）（**这正是上一章“分类即主权”的日常练习：**汉语儿童先学会“一头牛”而不是先学会“牛”的性（**②**量词提供了一次可测的语义投射**（**临时量词“一脸泥、一鼻子灰、一肚子主意”是把名词当容器——**修辞与语法之间没有边界，只有一条频率线（第 12 课“比喻派了工资就得上班”：**汉语的比喻很多已经付了工资**）；③**它也是方言身份标记**（**南方方言量词系统与普通话差异极大（**第 10 章方言课的入口之一（**量词是最小的、最不易被学习者察觉的、又最顽固的方言特征（**说错量词比说错语法更早暴露家乡**。
:::

## 三个框架，一道题 {#def-sange}

::: definition 同一句话的三种病历 {#def-bingli}
句子：**“他一场球打伤了观众。”**——**成分法**（**画出层级：主语“他”，谓语“一场球打伤了观众”，其中“一场球”为主题或时量—条件成分：**它的麻烦是“一场球”与“打伤”的语义关系不是常规论元（**它会被处理成附加语或特殊话题；**依存法**（**连线：打伤—他（主语）、打伤—观众（宾语）、打伤—一场球（状语性依存）：**它把争议化简为“谁支配谁”，代价是语义关系被压平（**构式法**（**这是“致使—结果”格式＋一个“事件框架”格式：**一场球”是致使源的场景而非受事；格式的语义允许“场景充当主语”（**本课的判分（**三种都能描述；但它们给出的“解释”不同：**成分法说“结构如此”，依存法说“支配如此”，构式法说“这个格式本来就带这个意思”（**要判断谁更好，须找一个只有其中一种能解释的句子——**这就是例题的任务**。
:::

::: example 一句两义 {#ex-liangyi}
“鸡不吃了。”请：**①列出两种意思；②分别指出两种意思里“鸡”的语义角色；③说明三种框架各如何解释这个歧义；④并给出一个句子，使其中一种解释变得不可能，说明你改动的是什么**。
::: solution
**①**——**A：鸡（施事）不吃了（它绝食／被喂饱了）**；**B：（我／我们）不吃鸡了**；**②**——**A 中“鸡”是施事；B 中“鸡”是受事（**同一表层形式，两种语义角色**）；**③三种解释**（**成分法：**深层结构不同（B 有一个被省略或移位的主语，A 没有），因此这是结构歧义；**依存法：**支配关系相同而语义标注不同，因此严格说这不是句法歧义而是论元标注歧义；**构式法：**同一形式被两个格式接纳（话题—受事格式与主—谓格式），格式各自带意义（**判分：**注意三者对本句的处理会推广到“饭做完了”“车修好了”一整类——**若某框架必须为每一类另立规则，它的解释力就低（**这就是奥卡姆刀在句法学里的用法**）；**④消除歧义的改动**（**“鸡不吃食了”（A**）与“这盘鸡我不吃了”（B**）**）——**改动的不是语法而是可及性：给施事配上只有动物能做的动作，或给受事配上只有食物能有的量（**这个练习的价值：**让你体感“句法歧义／语义歧义／语用歧义”这条边界其实常常只是我们决定把责任记在哪一层（第 1 课五个车间：**同一现象，三个车间都能出一张单，而它们的收费不同**。
:::
:::

::: intuition 语法不是逻辑 {#int-luoji}
**通说脉络**（**逻辑学家常设想一种无歧义的人工语言；自然语言的语法则系统性地保留歧义与冗余（**本课的三个理由（**①**冗余是鲁棒性的价格**（**汉语的“我打了他”与“他被我打了”信息相同而格式不同；如果语法只为传递命题服务，第二种就该被淘汰（**它没被淘汰，因为语法还做语篇与立场的工作（**②**歧义便宜，消除歧义也便宜**（**一句“哪个鸡？”就能解决本章例题：**所以语言不需要精密，只需要 repair 成本低于设计成本（**这是语言经济学的关键一句（第 4 章谒客经济：**说清楚的成本由说话人付，听懂的成本由听者付；两边都会在预算内行事**）；**③**因此“汉语逻辑不严”是一个彻底错误的说法（**歧义与省略是自然语言的普遍性质，不是某种语言的缺陷（**真正可比较的是：**在哪一类信息上，这个语言强迫你说清楚（**英语强迫你标时制与数，汉语强迫你标量词与结果补语（**这就是本章的结论句：语法是一种强制，而不是一种能力。**）。
:::

::: history 句法学的三次搬家 {#sec-banjia}
**传统时期**（**从逻辑三段论与文法教学来：**句子＝主项＋谓项（**这个框架至今活在“主语／谓语”两个词里（**它的优点是教得会，缺点是把它当作实在**）；**结构主义时期**（**去掉意义，只留分布与层次；直接成分分析让句法第一次可以被机器式地执行（**通说脉络：这也正是今天句法标注与自动分层的祖辈**）——第 4 章分词的工程约束：**句法被工程接手的第二次**）；**生成时期**（**1957 年以后：句法是一个内部装置，其证据包括直觉可接受性与系统性限制；短语结构规则＋转换，后演化为最简方案一类（**通说脉络：它对汉语的最大贡献是让“空代词、移位与长距离依存”成为可研究对象（**也使“汉语有没有主语”从抱怨变成一个可检验的问题**）；**功能与构式时期**（**频率、用法、规约化：语法是交互的沉淀（**通说脉络：类型学与语法化研究把“格式有独立意义”变成跨语言论题（**本章立场：这是近四十年最有产出的搬家，因为它把语篇、语用与历时重新请回句法的房子（**它付的房租是预测力变弱：功能解释常在事后（第 1 课四次转向：**这一章正好站在第四次转向里**。

::: exercise 小论文：强制的形状 {level=3}
写六百至一千字，评“**比较两种语言的语法，最有信息量的不是谁更严谨，而是它们在哪些地方不许你含糊。语法是一种由母语者集体执行的强制：它不扩大你能表达的范围，它规定你必须先交哪一份表格。因此所谓‘汉语灵活’，往往只是汉语在某些格子上不设关卡，而在另一些格子上设了外国人一辈子都过不去的关卡**”。须调用：**结构歧义作为证据**、**成分法与依存法的本体论差异**、**主题与主语之争**、**格式有独立语义**、**结果补语的致使约束**、**冗余与 repair 成本**至少六项；并裁决：**“汉语灵活”这一说法在什么条件下可被检验、又在什么条件下不可检验——请设计一项测量，并指出它的最大威胁**。
::: solution
判分点：六项机制（**证据、本体论、主题、格式、补语、repair**）；测量设计（**合格方案：**取一组同等交际任务（叙述一个致使事件、描述一张图、拒绝一个请求），测量两类母语者在“必须交代的信息项”（致使者、结果、时制、数、量词、礼貌标记）上的漏答率与自我修复次数；**最大威胁须写实**（**任务本身有语体偏好（**讲故事任务强迫叙事结构，逼迫“结果补语”出现，于是把实验设计变成了汉语的推销员**）；判卷看是否给出对照任务（**同一材料的笔语与口语、同一人两种语言的平行语料**）；结论若能写“**所以‘灵活’这个词只能这样改：一种语言的自由，是它把强制放在了别处；找到那个别处，才叫学了它的语法，也才叫懂了自己的口音**”，即 A。
