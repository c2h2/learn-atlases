上一章说意义同时住在三个地方；本章处理最麻烦的那一个——**说话人在此刻想让人做什么。语用学的入门句只有一句：说话就是做事；而它的入门难题也只有一句：我们做的常常不是嘴上说的那件事**。

## 定义：说出与做成 {#def-shuofu}

::: definition 言语行为与三个层次 {#def-cengci}
**通说脉络**（**奥斯汀区分表述句与施为句，又把一次说话拆为“说出”“在做”与“造成效果”三层；塞尔修订了分类并处理了“严肃说话与演戏”的疑难（**通说脉络**）；**汉语课堂最好用的三个例子**（**“我宣布开会”“我道歉”“我请你出去”——**请注意它们的共同点：**句子不描述一件事，它就是那件事的一部分（**由此立刻产生两个后果（**①**存在合格条件**（**在婚礼上说“我同意”才结婚；一个不是主持人的人说“我宣布开会”只是可笑**）；**②**存在诚实条件**（**说“我道歉”而无愧意，行为做成了，态度是假的：**语用学因此是唯一一门必须区分“办成了”与“骗到了”的学科（**这一条对后面所有的“语言腐败”讨论都是地基（第 21 课应用写作与第 6 课论证都会回收**。
:::

::: definition 间接言语行为 {#def-jianjie}
**通说脉络**（**塞尔：一个问题形式可以间接完成一个请求——**“你能够把盐递给我吗”没人当能力问题回答（**汉语的梯度比英语更细**（**“把盐给我”“你把盐递给我一下”“你能不能把盐递给我”“这菜是不是有点咸了”“您这儿盐放着方便吗”——**五个形式的语力相同而礼貌值相差极大（**本课的定义：**汉语的间接度是人际距离的测量仪**）——它测的不是需求的强度，是“我有没有资格直接吩咐你”（**这也是为什么汉语教材里的请求句都对，而学习者一开口就得罪人：他用的语法是满分的那个（**第 10 课“语言与教学”将把这一条写成课时**。
:::

::: definition 会话含义 {#def-hanyi}
**通说脉络**（**格赖斯：会话被一个合作前提组织，下设量、质、关系、方式四准则；说话人故意违反（flout）某一准则，听者便会推出字面之外的含义（**汉语演示**（**甲：“小周这人怎么样？”乙：“他呀，工作挺认真的。”——**乙违反了“量”的准则（回答少于期待），于是听者推出“他不想说好话”（**关键性质（**①可取消**（**“他工作挺认真的，而且别的方面也不差”：**可取消说明那不是词义（②不可分离**（**换任何同义说法，含义仍在：**说明它附着于这次说话而非某个词（③不依赖说话人自觉**（**听者推得出，即使乙并无暗示之意（**这三条正是格赖斯方案的技术优点（**它给“言外之意”一个可检验的位置：**它不是心理猜测，是推理的成本核算（**本课补一条本土化提醒：**四准则的合作假设带有很强的“信息交换”色彩；汉语的寒暄、客套与拉扯是否都是“传递信息”，值得怀疑（**礼貌性空谈可能遵守的是另一套准则（第 10 课的“语言的社会功能”**）。
:::

## 面子：汉语的主场 {#def-mianzi}

::: definition 面子理论与中国用法 {#def-lian}
**通说脉络**（**布朗与莱文森：面子分积极面子（希望被赞许）与消极面子（行动不被妨碍），许多语言策略都是为了降低面子威胁行为的威胁度——**汉语的两点特殊性（**①**面子是公共财物**（**“给面子、不给面子、留面子、伤面子、看在他面子上”：汉语里面子可以在第三者之间转让（**这使“面子”成为一个可核算、可索取、可赖账的账户（**第 4 章“义是信用记录”的近代版；也解释了为什么“当众”是汉语里最重的修饰语（**②**“脸”与“面”或许该分开记账**（**通说脉络：有学者主张“脸”近于道德声誉、“面”近于地位声望；这一区分在学术上仍有争论，但它在日常语感中是可分辨的（“不要脸”与“没面子”显然不同罪**）；**本课的处理：**不做人类学裁决，只做一件语言学的事——**统计哪些句子用来维护哪一种（**这是可以做的：**“您赏个脸”（求对方给面子）、“别让我难做人”（求第三方不损自己的道德声誉）**）。
:::

::: definition 汉语的拒绝工程 {#def-jujue}
**通说脉络**（**跨文化语用研究显示，汉语母语者在拒绝请求时更常用间接策略：延迟、岔开、给出无法控制的理由、请第三方背书——**本课把这一套称为拒绝工程——**它的标准工序：**①先接受意愿（“我真的很想帮”；**②再交付不可抗力（“实在不巧／家里那位不同意／单位刚说”；**③最后补一个替代方案或未来许诺（**注意第二道工序的技术内容：**责任必须被移给一个不能被反驳的对象（**第 5 章“无被告的损害”在此显出它的用处：**在汉语里，一个可信的拒绝需要一个不能谈判的原因（**所以“我妈不让”不是幼稚，是精确的语用设计（**这也是为什么“不行”两个字在成人汉语里近乎粗鲁：**它省掉了全部工序，等于宣布我不需要维护你的面子（**而维护面子正是维持关系的凭证**。
:::

## 指示、预设与篇章 {#def-zhishi}

::: definition 指示词与汉语的“这那” {#def-zhishi2}
**通说脉络**（**指示分人称、空间、时间与社会指示；汉语另有“这／那”的语篇指示与语气指示——**三个可教的事实（**①**“这、那”会指时间**（**“这阵子忙”“那年我还小”：**说话人站在被指的时间内部或外部，构成一种主观时距（**通说脉络：这种远近对比在汉语叙事里被大量用于“当年／如今”的对照（第 12 课“时间当对手”**）；②**“那”有贬抑的语用色彩**（**“他那叫什么文章”“你那是关心我吗”——**一个指示词做完了整个评价（**这就是为什么把“那是”改成“这是”能让一句话从讥讽变成立场声明（**③社会指示在汉语里是一整套称词语法**（**您／你、老师／师傅／大哥／老板、以及“姓＋职务”与“名＋哥／姐”：汉语用称呼承担了其他语言用形态承担的社会信息（**称呼选错是语用失误，不是语法错误，而它的后果严重十倍（**本章例题就做这件事**。
:::

::: definition 预设：句子背后的地基 {#def-yushe}
**通说脉络**（**有些内容是句子默认为真的部分（“他又迟到了”预设他以前迟到过）；疑问、否定与条件句构成“投影”难题——**本课的两个用途（**①**复杂问句**（**“你已经不再偷懒了吗”：无论答是或否，都承认了曾经偷懒（**这是汉语日常与审讯话语里最常见的装置（**第 3 课“预设与隐含”与第 6 课“清场”的应用**）；②**道歉与承认**（**“如果让你不舒服了，我道歉”预设了“你可能不舒服”，却取消了“我做了那件事”（**于是这句礼貌的话在语用上是一次不认账（**本课给这类句子一个名字：免责句式（**第 6 章“戏作＝免责声明”、第 2 课“调解书”的语用学版本（**而识别它的唯一工具，就是会把一句句话拆出字面、预设与语力三层**。
:::

::: definition 合作、礼貌与拉扯 {#def-lache}
**通说脉络**（**利奇把礼貌原则列为得体、慷慨、赞许、谦逊、一致、同情六条；汉语的“谦逊准则”长期被观察为强于“质的准则”——**这就是“哪里哪里”现象（**别人夸你，你否认（**“您做的菜真好吃”“哪有，随便弄弄”——**它在格的框架下是一次质的违规（说假话），在利的框架下是标准的礼貌（**本课的结论：**两套准则会冲突，而冲突的解决方式是语言共同体的参数（**所以跨文化误读常常不是恶意，是参数不同：客人听不懂“随便弄弄”是礼节，主人听不懂“真的很好吃”是真诚（**一个可核对的变化：**年轻一代对夸赞的回应里，“谢谢”的比例明显上升而“哪里哪里”下降（**这是语用参数在一代人身上改写的少数可直接观察案例（第 4 章“正在消失的一格”：这一格是客套（**它消失的原因多半不是西方化，是独生代缺少“当众谦让”的家庭排练场（**这是假说，须用代际语料检验**。
:::

::: example 一句“不”的十种做法 {#ex-bu}
任务：把“不”放进一段 120 字的汉语对话里，要求**全篇不出现任何直接的拒绝用语**，而读者能确定“不”已经说出口；然后写 60 字：**你用了哪三道工序、责任被移给了谁、以及这句话维护了谁的面子（积极还是消极）**。
::: solution
**参考文本**（“王：这周六您过来坐坐？李：哎哟，周六……我跟您说，我妈那天复查，我这心里一直悬着。再说我这一摊子事，您也不是不知道。等我这边缓过来，我第一时间给您打电话，真的。”）；**三道工序**——**接受意愿被省略而以“哎哟”承担（**先给情绪，不给承诺**）；不可抗力（母亲复查＝不可谈判、不可责怪的理由**）；替代方案（“我给您打电话”＝把决定权收回自己手里，因为时间由我定（**责任移交给母亲与“一摊子事”：**两者都不是李的过错，也都无法被王反驳（**面子核算**——**王得到积极面子（被邀请进“您也不是不知道”的亲密圈内，并且获得未来承诺）；李保住消极面子（未被逼到当场表态）；**代价是模糊：**王不知道自己是否被真心想邀请，李也知道自己下次还得还这笔账（**本课判分：**“代价”一栏不写不得分（**汉语的间接拒绝不是免费礼貌，它是一笔有利息的债（**这正是本章与第 4 章“义是信用记录”在方法上的接点：语用策略可以用簿记来描述，因为它本来就是簿记**。
:::
:::

::: intuition “意思”的三层 {#int-sanceng}
**同一段话可以问三个问题**（**①字面说了什么（语义）；②说这句话是在做什么（语力：请求、拒绝、威胁、调情）；③说完之后对方会怎样（语效：他会不会来、会不会记恨（**三者可以完全不重合（**“你要不去就算了”字面是给选择，语力是施压，语效常常是真让对方不去（**本课的教学用法：**任何人际纠纷的分析，把这三栏写出来，争吵立刻少一半（**这是本课程对“沟通技巧”唯一的、也是最实在的贡献（**而语言学给它一个额外的好处：这三栏不依赖真诚，依赖证据——**你能引用原句，你能指出预设，你能说明谁的面子被算错了（第 1 课证据学：**语用是最容易验证的一层，因为后果会当场发生**。
:::

::: history 语用学的三次正名 {#sec-zhengming}
**1930s—1950s**（**语法学与逻辑实证主义都致力于清除“情感与用法”：**语用一度是脏字**）；**1955 年前后奥斯汀在哈佛讲“如何以言行事”，其讲稿 1962 年出版（通说）——**一次内部爆破：**逻辑学家发现日常语言不是坏的逻辑，是另一套规则（**1960—1970s**（**格赖斯 1975 年的论文、塞尔对言语行为的修订分类、会话结构分析（轮流、相邻对、修正机制（**通说脉络：**语用学获得自己的方法论：**它靠录音，不靠内省（**这一步比理论更关键（**1970s—1980s**（**面子理论、跨文化语用学、语言转用（**通说脉络：一项反复被引用的发现是：二语使用者的语法错误常被原谅，语用失误常被当作人格缺陷（**于是“语用能力”进入语言教学大纲（**这是语用学第一次改变课堂**）；**2000s—今**（**网络交流把语用层重新地形化（**通说脉络：标点与语气词、表情符号、回复延迟、是否引用原文，全都成为礼貌值的载体（**“句号显得冷淡”这类报告并非玩笑：**一个符号的功能是语用的，因为它出现在特定渠道的特定期待里（第 1 章分发格式：**语用永远住在渠道上——**这是本章结束时的第一句话，也是下一章的全部预告。**）。
:::

::: warning 本章四坑
**把礼貌等同于真诚**（**语用学不测心意，只测功能：**“哪里哪里”可以出于真心也可以出于习惯（**批评客套虚伪是道德判断，分析客套是语用学（**两者别混（第 1 课描写与规定**））；**把间接当模糊**（**汉语的间接拒绝在共同体内部极其清楚：**“再说吧”不是“待定”，是“不”的一种礼貌形式（**把它翻译成“待定”是跨共同体误读，不是语言缺陷**））；**用本共同体的参数读别共同体**（**把“随便弄弄”听成谦虚或听成自贬，都是一种参数假设（上方拉扯条款**））；**以为语用可教**（**语用知识的传授效率远低于语法：**它需要场合、风险与重复（**这也是为什么成年学习者能说流利却仍“不像自己人”（第 10 课：教学大纲能教到什么程度的最好测量工具**。

::: exercise 小论文：语用是账本 {level=3}
