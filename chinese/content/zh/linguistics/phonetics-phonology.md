title: "语音学与音系学"
---

前两章谈系统的一般性质；本章谈系统唯一可用的材料——声音（以及它的手势与影像变体）——**本章的全部技术难度只在一处：物理上连续的声音，怎样被切成一串可以对立的单位；而切法一旦定下，说话人几乎就再也听不见别的切法了**。

## 定义：两个学科，一份材料 {#def-liangge}

::: definition 语音学与音系学的分工 {#def-fengong}
**语音学**（**研究声音的物理与生理属性：发音（舌位、气流、调音方法）、声学（频谱、时长、共振峰）、听觉（感知边界）——**它的对象是连续量（**辅音与元音之间、[t] 与 [tʰ] 之间，物理上只有程度差**）；**音系学**（**研究哪些差别在这个语言里被当作差别——**它的对象是离散的对立（**本课的一句判词：**语音学测量，音系学记账；**账本上没开的科目，说话人就看不见（**这也是为什么本课程的语音课要一直与音韵课（第 3 门）一起读：**汉语音韵学是人类历史上最早、也最彻底的一套音系账本（第 3 门课第 2 章**）。
:::

::: definition 音标是一份三行说明书 {#def-ipa}
**通说脉络**（**国际音标用“调音部位＋调音方法＋清浊”三个坐标描述一个辅音（如 [pʰ]：双唇、塞音、送气、清；[ʂ]：卷舌、擦音、清）——**本课强调它的两条纪律（**①**一音一符**（**拼写是四线格，音标是坐标：**同一个符号在任何语言里必须指同一个调音动作，否则比较就没有意义（第 2 章“价值”：**跨系统的比较必须先把切分开掉**）；②**括号即主张**（**方括号 [ ] 声称描写了实际发音，斜杠 / / 声称该差别在这个语言里区别意义（**于是“这个音该怎么标”不是格式问题，而是一个可被证伪的假设：**它等价于“我主张这个差别在此语言中不承担对立”（**这一句是本章的方法论核心（第 3 课可反驳性：**音标是语言学里最便宜的可证伪声明。
:::

## 怎么找出一个语言的单位 {#def-zhaodao}

::: definition 最小对立对 {#def-weixiao}
**操作**（**保持其他一切不变，只换一个音，看意义是否改变（**换就改变，则该差别在此语言中区别意义**）；**汉语演示**（**换声母：八 [pa] — 趴 [pʰa] — 发 [fa]；换韵母：班 [pan] — 帮 [paŋ]；换声调：妈—麻—马—骂——**三行做完，你就自己算出了汉语普通话的声母、韵母与声调的对立清单（**这是本课程极少见的、学生可以当场完成的“发现”（**它同时暴露一个陷阱：**[p] 与 [pʰ] 在汉语里对立，在英语里不对立（“spin”与“pin”的 p 送气差别是自动的、不承担意义）（**所以英语母语者初学汉语时听不出“八／趴”，不是耳朵差，是他的账本上没有这个科目（**感知的范畴化是母语的产物（第 9 课“口音与身份”）。
:::

::: definition 音位与音位变体 {#def-bianyi}
**通说脉络**（**同一个音位在不同位置上的不同实现叫音位变体；互补分布的两个音通常属于同一音位（**汉语的经典案例**（**普通话 /a/ 在不同韵尾前实现为不同元音（[a]、[ɑ]、[ɛ]、[æ] 一类，通说描写）——**初学者的震惊点是：这四个音在他们听来“本来就是同一个音”（**本课的用法：**这是整个语言学课程里最容易亲身验证的一条原理：**你的听觉已经把系统里的规则当成了物理事实（第 1 课“清单是眼镜”：**而这副眼镜是你六岁以前配的，不是天生的**。
:::

::: definition 经济性：系统不留多余的对立 {#def-jingji}
**通说脉络**（**音位系统的差别须承担功能（区别意义、或者由区别性特征承担构词与历史的一致**）；否则会被消耗掉——**本课把它写成一条经济学（**对立是有维护成本的（**每一对音位都会在某年某地因为某次合并而消失：**汉语史上浊音清化、入声消失、尖团合流，都是账本上的一次并户（第 3 门语音课与第 4 门语音史课的全部主线**）；**为什么合并总在省力处发生**（**同化、弱化、脱落都朝“发音更省事”的方向（**这是语言变化里最接近自然律的倾向（**但它会被另一个力量抵消：**交际要清楚（**所以任何只讲“省力”的音变理论都不成立：**省力与清楚之间的均衡点，才是一个语言的共时状态（第 6 章让步与均衡：**本章是它第一次出现。
:::

## 超音段与汉语的声音 {#def-chao}

::: definition 声调不是“声调” {#def-shengdiao}
**通说脉络**（**声调是音高在时间上的模式，具有区分意义的作用；调值用五度制描写（通说：赵元任的五度值）——**本课的两点处理（**①**声调是相对音高，不是绝对音高**（**所以男人和女人说同一句话，调值曲线形状相似而频率完全不同：**这解释了为什么声调语言里“跑调”不会造成误解：**调子的音乐性不在账本上（第 12 课“声与乐”：**汉语歌唱时旋律覆盖字调而听者仍能辨字，靠的是相对关系与语境（**这一条常被当作“汉语音乐性”的浪漫证据，其实它是一处精巧的信息冗余**）；②**连读变调是语法化的前夜**（**普通话上声连读变调、轻声与儿化的词界敏感性（通说）——**当一个语音规则开始依赖词与结构的边界，它就是音系与形态交界处的活样本（第 4 章形态课的第一课材料**。
:::

::: definition 音节：汉语的隐秘主角 {#def-yinjie}
**通说脉络**（**汉语音节结构整齐（声母＋韵母＋调），开音节占优，历史上的韵尾大量合并——**本课的推论（**①**音节计数等于字数**（**这使“字”成为汉语最自然的心理单位，并使韵书、对仗、骈文与诗律都以音节计——**第 13 课格律的整个设备（平仄、对仗、句数）都建立在这一条音系事实上（**所以不懂音系就无法真正读懂格律，正如不懂声带无法真正读懂唱法（第 1 门课的结语在此兑现**）；②**开音节偏爱塑造词汇**（**为什么大量外来词要加元音或减辅音（“咖啡”“巧克力”一类：**不是音译不准，是账本只收这种科目（第 6 课“外来词”条款的音系底本**。
:::

::: example 为什么四个字母要管六个音 {#ex-zimu}
拼音方案用一个字母表示若干不同的音位变体（如 i 在 [i]、[ɿ]、[ʅ] 三个位置；e 在不同韵母里的差异）。请回答三问：**①这算不算设计缺陷？②什么样的使用者会因为它而受益、谁会吃亏？③如果让你重新设计，你会牺牲什么换什么**。
::: solution
**①**——**从音系学看不是缺陷，是原则：**字母对应音位而非音值；一音位一字母可使词形的书写稳定（**“知、诗”的韵母写法相同，正说明该系统主张它们同属一个音位（**这是一个理论主张被写进了小学课本（**这也是它最有争议的地方（**②受益与吃亏**（**受益：儿童（**字母少、规则少、词形一致**）、输入法与检索（**同一音位不再因音值而分裂**）；吃亏：**学习外语与方言的人**（**他们的耳朵被训练成“拼音即音值”，而 [ʅ] 在英语、法语里根本不存在，于是产生系统性的口音（**第 9 课：口音是母语的音系账本外宾**）；**③重新设计**（**任何方案都要付出代价：**若改用严式标音，字母表会膨胀、词形会随音变、印刷与教学成本上升；若维持现状，则须在若干年以后为“音值已经变了”打补丁（**本课结论：**拼写系统是音系学、政治、教育与商业的合订本，它从不只是语音学（第 9 门课“标准音”的选择：一个地点的方言如何被选作全国账本的模板**。
:::
:::

::: intuition 你听不见的差别 {#int-ting}
**范畴化感知**（**同一类别内的连续差别被压缩，类别边界上的差别被放大（**这是语音知觉被反复确认的现象（通说脉络）——**它的社会学后果极大（**①**母语成为一副摘不掉的耳机**（**所谓“外语难学”，在语音层首先是感知范畴的重组，而不是口腔肌肉的训练（**②**“某语言里有很多个词表示雪/稻米”一类的说法，正确的版本在这里**（不是词多，而是该语言在你的听觉里切得细（第 2 章“切分即主权”的知觉版**）；**③**这也解释了为什么人对自身口音的评价总是不客观**（**他听不见自己的范畴边界（**所以本章要求的“听写音标”练习，其真正功能不是记忆符号，是暂时借来一双没被记账的耳朵（**这是语言学入门唯一一次让学员体验“理论负载”这四个字**。
:::

::: history 账本的四次改页 {#sec-zhangben}
**六世纪—十九世纪**（**韵书与韵图传统：**用一个矩阵（声母×等呼×声调）把全部读音排进表格（**那是一张一千年前的音系结构图，比欧洲同类描写更整齐（第 3 门课第 1—2 章**）；**十九世纪**（**历史比较法确立“语音规律无例外”（通说脉络）——**音变第一次被写成可推广的定律；**其代价是把例外推给类比与借用（**这条思路直到今天仍在语法与音系之间划分势力（第 5 门课**）；**二十世纪前期**（**音位学建立：布拉格的特征论、美国的音位与分布主义、以及汉语方言大调查（**通说脉络：方言调查让“同一音位在各地如何分化”成为可见数据（**这就是方言课的基础设施**）；**二十世纪中叶—今**（**区别性特征、生成音系学、自动段律理论（把“音节—韵基—音节核”写成层级结构）、实验语音学与语音合成（**通说脉络：从规则描写到约束满足，再到统计建模（**本章的收尾提醒：**每一次技术换代，都改变“什么算解释”——**当模型能从数据里学出对立而不需要“音位”这个名称时，教材里这一章的地位就要重写（第 1 课的四次转向：**这一章正处在下一次转向的门口**。
:::

::: warning 本章四坑
**“标不出来＝没有”**（**听不出差别不等于物理上没有：**先做声学或至少最小对立检验（**反过来也成立：**你以为听到的常常是你的账本允许的（上方范畴化**））；**把拼音当音标**（**它是文字方案，服务于识字、打字与推广；它允许一字母多音位，音标不允许（例题**））；**用“省力”解释一切音变**（**省力无法解释为什么清楚性压力没有把变化停在中途：**须同时给出系统内部的类比、词汇扩散与社会声望三条（第 4 门课与第 9 课**））；**把声调语言“唱歌”当反例**（**旋律覆盖字调仍能辨字，说明冗余编码；它不证明汉语“天然有音乐性”（上方①**。

::: exercise 小论文：耳朵是账本 {level=3}
写六百至一千字，评“**语音学告诉语言学一件别处少见的事：我们以为自己在感知世界，其实在读取自己的分类表。语言学家之所以能靠这一点建立起一套客观科学，恰恰是因为这套分类表是公共的、可操作的、可被最小对立当场演示的——它不像价值观那样看不见，它能让两个母语者互相听不见同一个差别**”。须调用：**两学科分工**、**括号即主张**、**最小对立的算法与陷阱**、**音位变体与互补分布**、**省力与清楚的均衡**、**声调的相对性与冗余编码**至少六项；并裁决：**“语言影响知觉”这一命题在语音层是可证实的，在词汇与语法层为何迅速变弱——你须给出一个机制解释，并指出哪种实验设计最能区分二者**。
