---
title: "词的兴起与五代"
---

词的前半生不姓“文学”，姓“音乐”：它是**歌坛的歌辞**，作者写给歌者的作业。本章讲它如何从酒席上的流行歌，一级一级爬到文学的正厅——**台阶一共四级：敦煌的野生标本、《花间集》的精装出道、南唐宫廷的私人化、以及一位亡国之君的殉葬级加冕**。

## 第一级：歌辞 {#def-geci}

::: definition 燕乐·曲子·填词 {#def-yanle}
**词的母体是燕乐**：隋唐合胡乐、俗乐、清乐而成的新音乐系统——**乐曲先行，文字后配：“依调填词”（按曲牌的格律填字），诗人第一次按“甲方”的节拍交货**（与乐府“采诗入乐”方向相反：**汉乐府是官方去配乐，唐宋曲子词是文人自来应聘**）。**野生标本**：敦煌曲子词（写本混在经卷里睡了一千年）——《菩萨蛮》“**枕前发尽千般愿：要休且待青山烂。水面上秤锤浮，直待黄河彻底枯**”——**用宇宙违章清单写爱情誓约：没有文人典故，只有山、河、秤砣——词在入城之前，先是民歌穿了件新曲子**。三件出生证：**①曲牌=格式合同**（《浣溪沙》《菩萨蛮》各是固定曲式，词题常缺、**词牌先于题目：词生来就是“命题作文”**）；**②歌者=第一读者**（写得好坏由席间的耳朵验收——**这解释了词早年的软、短、艳：宴会需要背景乐，不需要奏折**）；**③酒肆寺观=发行网**（“**花间**”二字本就是宴席的布景）。
:::

## 第二级：精装出道 {#def-huajian}

::: definition 《花间集》：第一部词的总集 {#def-hj}
**940 年**，后蜀赵崇祚编《花间集》十卷十八家——**中国文学第一部词总集，比任何批评都早地宣布：词是可以成“集”的文体**。欧阳炯作序，开篇自陈编辑方针：**诗是“述德立功”的，词是“用助妖娆之态”“命家僮歌之”的——序文亲自把词按在“艳科”的产床上**（**词的“出身声明”写得坦荡：我们这本集子就是给宴席供货的**）；序文自己给出工艺纲领——**“镂玉雕琼”“裁花剪叶”：把语言当首饰加工，词以工艺立项**。**温庭筠“香而软”的镜头**：“**小山重叠金明灭，鬓云欲度香腮雪。懒起画蛾眉，弄妆梳洗迟。照花前后镜，花面交相映。新帖绣罗襦，双双金鹧鸪。**”（《菩萨蛮》）——**全篇是物件与动作的特写剪辑：没有“我”，没有事件，只有妆台的光学——王国维称其“深美闳约”**——**温词的革命在“镜头”：抒情诗第一次不抒情，只陈列——后世称之为“密丽”，也可以叫它**：**中国文学最早的 MV 美学**。对照其“**照花前后镜，花面交相映**”——**两面镜子互为无穷：词在这种镜头深处第一次摆脱了诗的“说话”，开始“放映”**。**韦庄的补救**：“**未老莫还乡，还乡须断肠**”（《菩萨蛮》）——**同样调子，主语回来了：温是客观镜头（词如其名“花间”，无人），韦让歌手走到话筒前——词的抒情主语在五代登记户口**。
:::

## 第三级：南唐宫廷的私人化 {#def-nantang}

::: definition 干卿何事：词的免责条款 {#def-fys}
冯延巳（宰相、词人，双重编制）：“**风乍起，吹皱一池春水**”（《谒金门》）——中主李璟戏问：“**吹皱一池春水，干卿何事？**”（马令《南唐书》）——**君臣一问一答，替词签发了历史性的免责声明：词写的是池水级隐私，与政教无关**。这句戏言是文体史的化石：**诗的“美刺”义务在这里正式松绑——词的免责，是词的解放**（对照屈原、杜甫那条“每饭不忘君”的枷锁——**同一个南唐朝廷，对外交不出兵，对内交出了词的自主权**）。冯词好处在“**闲情**”：“**谁道闲情抛掷久？每到春来，惆怅还依旧**”（《蝶恋花》）——**没有事件的愁、没有对象的怅：词第一次专门处理“没有理由的情绪”——这是诗的语言办不到的低像素业务**。李璟：“**细雨梦回鸡塞远，小楼吹彻玉笙寒**”（《摊破浣溪沙》）——**思妇的等待与边塞的战事隔着一场雨对响：宫廷词人把“艳”与“世局”调成了同一种低温**。
:::

## 第四级：殉葬加冕 {#def-liyu}

::: definition 李煜：以亡国换词权 {#def-liyu2}
**前期是顶级消费品**：“**刬袜步香阶，手提金缕鞋**”（《菩萨蛮》——**小周后私会的现场直播：偷情词写得毫不心虚，因为他不知道自己是末代**）；“**花明月暗笼轻雾**”同篇起句——**南唐宫廷的镜头美学满级：然后国家没了**。降宋后四件作品构成词的“加冕礼”：①《相见欢》“**林花谢了春红，太匆匆。无奈朝来寒雨晚来风。胭脂泪，相留醉，几时重。自是人生长恨水长东**”——**从落花直接跳到人生总账：不解释、不寄事，“长恨”升格为宇宙的常数**；②《浪淘沙令》“**流水落花春去也，天上人间**”——**八个字给故国办完葬礼；③《虞美人》“问君能有几多愁？恰似一江春水向东流”——设问＋无穷大的喻体：愁第一次有了水文数据**（“**词至李后主而眼界始大，感慨遂深，遂变士大夫之词**”——王国维《人间词话》：**词的正厅钥匙，是亡国钥匙形制的**）；④《破阵子》“**四十年来家国，三千里地山河**”＋“**最是仓皇辞庙日，教坊犹奏别离歌，垂泪对宫娥**”——**以诗的句法、史的规模入词：词的载重一夜翻倍**。王国维的另一句盖棺：“**后主则俨有释迦、基督担荷人类罪恶之意**”——**夸张得恰到好处：李煜的个人损失，被词这种文体兑换成了人类的通用账单**。
:::

::: example 两件愁的质检 {#ex-zhichou}
同写愁：温庭筠《更漏子》“**梧桐树，三更雨，不道离情正苦。一叶叶，一声声，空阶滴到明**” vs 李煜《虞美人》“**问君能有几多愁？恰似一江春水向东流**”。请做三项质检：①两位各自把愁放在哪里（物件／主语）；②“滴到明”与“向东流”两种时间形态的差别；③如果花间词是“产品的愁”、后主词是“人的愁”，**词的“文学地位”为什么恰恰在后者出现后才确立**——用本课“台阶”模型作答，并指出这个模型的偏见。
::: solution
①**温：愁寄放在雨声的计时器里**（人不出现，离情由屋檐代播——**客观镜头的极致**）；**李：愁扛在自己主语上**（“问君”的君＝我——**第一人称的破产报告**）。②**“滴到明”是被动挨打的时间：一夜被切成“一叶一声”，痛苦的单位化计量**；**“向东流”是主动奔涌的时间：把一夜拉长为永远，愁获得河道与体积——从计时器到江水，是词从工艺到气象的换挡**。③台阶模型：**文学地位＝“谁在说话”的权重史**——歌辞（无人称的产品）→镜头（工匠）→士大夫之词（一个具体的人，且是亡国之君）：**词的“升等”，靠的是主语不断变重**。偏见检查（本题满分项）：**该模型以“真诚的个人表达”为终点，是王国维—今人的价值序列；花间系统完全可以反诉：去主体、重工艺正是词的另一种高峰——温庭筠的“无人”，也是解放（词从不必“有人”开始才像词）**。**结论：词的正厅里坐的是李煜，但房子是花间营造的——两案都要记录在案**。
:::
:::

::: intuition 名字即身份焦虑 {#int-mingzi}
词换过一串名字：唐人叫“曲子”“曲子词”，宋人叫“长短句”，又给它取了一个要命的别名——“**诗余**”（**字面即职称：诗的业余时间产物——不必考据语源，单这个名字的使用史就够读：一个文体靠贬低自己取得进入目录的资格**）；再往后称“乐府”（《东坡乐府》——**认亲：把词过继给汉乐府这个正经家族**）。**每次改名都是一次身份游说：曲子→长短句→乐府→诗余——四张名片恰好排出一部文体等级史**。对照本课开头：**《花间集》题“诗客曲子词”——“诗客”是要脸，“曲子词”是货名：词的一生都在脸和货之间拉扯**。
:::

::: history 词的户口迁移 {#sec-hukou}
**盛中唐**：边地燕乐与民间曲子并流（敦煌写本无作者名——**词的无名时代：歌辞属于曲调，不属于人**）；**中晚唐**：文人依调填词（白居易、刘禹锡均有《忆江南》——**“忆江南”三字本是曲牌：诗人开始给曲调打工**）；**大中年间**：温庭筠大量填词——**第一个以词名家的专业样本（“温八叉”的捷才用在小令上：天才的降级使用，恰是文体的升级燃料）**；**940**：《花间集》成——词有了“总集”户口；**南唐**：冯、李——词的宫廷化与私人化；**978**：李煜归宋，七夕命宴作《虞美人》传唱，相传赐牵机药（宋人笔记载——**词杀死作者：文体史上唯一被作品处决的皇帝**）；**宋**：柳永慢词、苏轼“以诗为词”——**词的两次“转正”：一次扩音（长调），一次夺权（言志）；宋人词序里又常见“薄技”“游戏”的自谦——**自卑与得意同句式**；**清**：常州词派张惠言以比兴说温韦（**给艳科补发“离骚”血统：花间词人醒来发现自己成了楚辞传人——经典化最荒诞的一次追授**）、王国维《人间词话》以李煜封顶——**本课文评即其徒孙**。
:::

::: warning 读词四坑
**以诗的标准骂词“格局小”**（**宴会歌辞的 KPI 本就不是美刺：先按文体合同验收，再谈突破合同**）；**把“代言体”当人格档案**（**花间词多男子作闺音：镜头后的眼睛是宰相、和尚、待诏——把“女子口吻”读成作者情史，是词学最古老的八卦**）；**神化“后主自然”而轻视花间工艺**（**“自然”也是一种修辞：后主不用典是另一种技术选择——本课质检题的反诉案**）；**用“诗余”“小道”当定论**（**那是当事人自我贬低的公关话——引用自卑语做判决书，等于采信被告的和解条款**）。
:::

::: exercise 填词体验 {level=1}
选一个词牌（《如梦令》《浣溪沙》任选，课内附格律谱），按谱填一首写**当代生活**的短词（禁“柳岸”“画桥”等古装道具）：**词牌=格式合同**，你的任务是在合同里说自己的话。互评：哪一句“违约”了（出律）？哪一句在格律里意外地像唱歌？
::: solution
判分：**合同优先**（字数、平仄、韵位按谱——出律须自注“拗”并说明动机）；**反古装检查**（意象清单里出现现代物件且与词牌化学反应良好=本题高分——**词本流行歌：让《浣溪沙》唱地铁，才是复古**）；“像唱歌”一句＝**声情合一**的直觉证据（词牌的声音设计被身体认出）。
:::

::: solution
判分：**双轨话术齐全**（免责轨：不涉政教／有古人成例；价值轨：宴席必备／传唱即销量）；**化用自然**（示范到“**风若不语，池水何皱；词若不艳，宴席何设**”的对仗级即可；生硬粘贴原话者扣分）；能预埋“他日翻案”伏笔（“聊备一格”类谦词）者加分——**谦词就是那个时代的免责声明**。
:::

::: exercise 小论文：词为什么从“艳”开始 {level=3}
写六百至一千字，评“**词的窄门不是它的耻辱，是它的产床：一切文体的出生都从‘不重要的场合’开始**”。须调用：**敦煌誓愿词**、**《花间集》序**、**“干卿何事”**、**李煜加冕**、**“诗余”命名**至少四项；并处理一个反方：**如果文体必从“小道”崛起，今天被看不起的表达（弹幕、梗、歌）是否正在候选下一文体**（要求举一例并写出“台阶模型”的预测）。
::: solution
判分点：产床机制（**音乐产业供养早期作者：免责空间＝实验空间——词的“轻”让它敢试诗不敢试的内心低像素**）；五台阶逻辑（**野生→精装→私人化→重主语→追认——地位永远最后到场**）；反方处理（**候选例：弹幕/梗——可预测其“台阶”：先匿名合唱（如敦煌曲子）、再选本化（年度热梗盘点）、再个人化（头部作者的署名作品）——预测允许被证伪，但须按模型推理**）；结论若写“**所谓雅，是当初的俗攒够了资历**”，即 A。
:::

::: summary
四级台阶结账：歌辞（**曲牌合同、歌者读者、山与秤砣的誓约**）、精装（**总集户口＋“艳科”出身声明；温的镜头与韦的主语**）、私人化（**“干卿何事”＝免责即解放；没有理由的愁是词的新业务**）、加冕（**后主以一己亡国为词预付了全部稿费；“担荷人类罪恶”是夸张，也是事实**）。名字学一句：**词的每一张名片都是游说词**。本册至此结业：从初唐的考场到汴京的江水，唐诗完成，宋词的门口已经在排队——下一册《宋代文学》，从“**以诗为词**”的那次夺权开始。
:::
