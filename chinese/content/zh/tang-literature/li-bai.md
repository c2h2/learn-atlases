---
title: "李白"
---

唐代最大的一位**自媒体**：不考进士，靠作品集、人脉与自我包装登顶；财务自由地替帝国传播了它的想象力。本章拆他的三件法宝——**嗓门、账本、人设**——再交代一件后事：他死後，“仙”如何被追封成商标。

## 嗓门 {#def-sangmen}

::: definition 天才的技术内容 {#def-technique}
**《蜀道难》的音量工程**：“**噫吁嚱，危乎高哉！蜀道之难，难于上青天**”——**三个感叹词开场（唐诗唯一）、散文句法挤进乐府旧题、反复插播“难”字副歌——这不是描写路，是用声压模拟海拔**；相传《蜀道难》见赏于贺知章，**“谪仙人”的诨号由此登记注册：李白最重要的标题，是别人给起的**。《将进酒》的时间经济学：“**君不见黄河之水天上来，奔流到海不复回。君不见高堂明镜悲白发，朝如青丝暮成雪**”——**两个“君不见”把空间巨浪折成时间悲剧；“天生我材必有用，千金散尽还复来”——自信不是性格，是修辞策略：先宣布价值，再去兑现**。“**五花马，千金裘，呼儿将出换美酒，与尔同销万古愁**”——**以消费收尾的宇宙级赊账：愁是万古的，酒是现结的**。绝句的轻功：“**飞流直下三千尺，疑是银河落九天**”“**桃花潭水深千尺，不及汪伦送我情**”——**夸张是他的正规武器而非失误：李白的“真”在强度的真实（[[rhetoric/figures-of-meaning]]夸饰一科的满分卷）**；“**清水出芙蓉，天然去雕饰**”——自述诗学：**天然是被设计出来的最高效果——注意这句话出自他的手，正是它不可全信的地方**。
:::

## 账本 {#def-zhangben}

::: definition 名人是怎么烧钱的 {#def-money}
**启动资金**：《上安州裴长史书》自曝“**曩昔东游维扬，不逾一年，散金三十余万，有落魄公子，悉皆济之**”——**一年散尽三十万金：这不是败家，是投放：慷慨即广告，接济落魄者=投资同行口碑**。**发行渠道**：干谒信是那个年代的自荐首页——《与韩荆州书》“**白陇西布衣，流落楚汉。……愿君侯不以富贵而骄之，寒贱而忽之**”＋“**必若接之以高宴，纵之以清谈，请日万言倚马可待**”——**把“请看我”写成“你在错过我”：求职信的名篇，姿态学标本**。**口碑回路**：漫游—题壁—赠答—传唱：**没有印刷榜，名声靠人肉转发；连市井段子都在替他做分发（相传汪伦以“十里桃花、万家酒店”诱其来访——桃花是潭名，万家是店主姓——李白不仅不怒，还回赠一首“不及汪伦送我情”：黑红也是红，达人懂流量）**。**制度外声誉**：玄宗征召“**仰天大笑出门去，我辈岂是蓬蒿人**”——**这一跳是三十年人脉经营的套现现场**；翰林待诏是“**宾贡**”性质的供奉（不是官，是客人——**编制外的顶流，注定待不久**）；“**安能摧眉折腰事权贵，使我不得开心颜**”（《梦游天姥吟留别》）——**赐金还山后的体面话，从此成为历代打工人退群名言**。
:::

::: definition 政治账单：永王案 {#def-zhengzhi}
**757 年入永王璘幕府，758 年定罪谋反、流放夜郎，途中遇赦**——**李白一生最大商业决策的爆雷现场**：安史乱中，玄宗分太子诸王各镇一方，**永王东巡是肃宗与玄宗权力缝隙里的险招——李白只看见“封侯”的机会，没看见棋盘上有两个皇帝**。高适、李阳冰辈多方援救，遇赦得还。《早发白帝城》：“**朝辞白帝彩云间，千里江陵一日还**”——**流放归途写成了快递速度：把缓刑写成兜风，这是他的危机公关本能**。案件史评：**后世不断有人替他喊冤、也有人断言他“识暗”（王安石、朱熹皆有贬词）——政治判断力与诗歌天才的反比，成为千年谈资：李白的失败不是道德失败，是一个修辞大脑在博弈局的必然点差**。
:::

::: example 谪仙人制造学 {#ex-zhexian}
组装“仙”的四批材料：①贺知章“**谪仙人**”之目；②杜甫《饮中八仙歌》“**天子呼来不上船，自称臣是酒中仙**”；③杜甫《春日忆李白》“**白也诗无敌，飘然思不群。清新庾开府，俊逸鲍参军**”；④宋以后笔记的“**宫中醉笔——高力士脱靴、杨贵妃捧砚**”与“**骑鲸捉月**”之死。问：**哪一条最“真实”？“仙”这个品牌各股东分别注入了什么**？
::: solution
**逐条验资**：①贺知章一锤定名——**名号由最高鉴定官签发（体制认证野生顶流）**；②杜甫写的是“酒中仙”不是“诗仙”：**八仙图里他是之一：杜甫把他放进群像，反而给足可信度——神话需要合影**；③**杜甫《春日忆李白》是全部材料里最诚实的一条：李白的“不群”原料是庾信之清与鲍照之俊——仙是勤学的合成款杜甫此评就是文学史的“溯源插件”：把天才翻译成谱系）**；④脱靴捧砚与捉月：**生前被大化**？——**都是后世加工：唐代笔记要宫闱八卦（贬权贵泄愤），宋明要人格寓言（天才不惧皇权），民间要神话闭环（仙人生天）——李白负责天才，各时代负责装修**。验资结论：**最“真实”的是③：只有杜甫愿意解释他；其余三条都在消费他。品牌学定律：伟大的商标由各取所需的股东拼装，创始人早已无法干预股价**。
:::
:::

::: intuition 反常的诚实 {#int-chengshi}
我们习惯说李白“真”——但请分清两层：**情绪的真诚**（“**与尔同销万古愁**”的慷慨是真的）**与事实的率直**（他几乎不克制：年龄夸张、金山银海、月入万言）。李白的“真”是**强度的真实**：**他不撒谎，他撒谎都撒得理直气壮——这是夸饰的人格化**。对照本课例题的谱系材料：**他的每一分“天然”背后有庾信、鲍照、《楚辞》、汉赋、游仙——“清水芙蓉”的池塘里养着整个选学传统**（[[classical-chinese-2/commentaries]]选本章：《文选》是唐人写作的“普通话”，李白是口音最重也最自信的那位北京人）。**结论：把李白读成“灵感机器”是最省事的误读；读成“带着全部传统上场、并故意即兴的人”，他才开始吓人**。
:::

::: history 一桩追封的流水 {#sec-zhuifeng}
**762** 去世（当涂依族叔李阳冰）；**764** 李阳冰《草堂集序》编其文——**家属执笔的第一版人设：天上谪仙人**；**中晚唐**：乐史《李翰林别集序》一类续写异迹——**李白集的序跋成了传奇的增量市场**；范传正为其改葬立碑；**宋**：“**诗仙**”定名流通（与“诗圣”配对——严羽时代李杜并称已成坐标）；**宋人开始“以学问看李白”：注李本出现，给天才上户口——仙话与考据同书共存**；**元**：杂剧《梧桐雨》《李谪仙醉草吓蛮书》——**“吓蛮书”：李白被外包为大唐外交部（遣使传说是民间想象的注资）**；**明清**：**胡应麟《诗薮》、王世贞《艺苑卮言》在“李杜优劣论”里反复打分——经典地位接受永续审计**；**清**：王琦《李太白诗集注》集校注大成（**“仙”由三百年考据精装成集部正编**）；**现**：郭沫若《李白与杜甫》以阶级分析扬李抑杜（**1971——连站队都重演了唐代的党争**）；**今**：课本、酒品牌、游戏角色——**李白是唯一同时入选教材与商标库的诗人：谪仙人的最终形态，是知识产权**。
:::

::: warning 读李白四坑
**当“灵感说”宣传品读**（**“斗酒诗百篇”是杜甫给他拍的广告，不是生产流程**：集中千余首、应酬体与修改稿并存——天才也交初稿）；**把豪言当收入证明**（“千金散尽”的下一句“还复来”——**也是干谒信的收款期待**）；**无视体裁分工**（**乐府歌行才是他的主场：音量与换气；律诗存作少而评价低——把“李白不工律”读成“李白不受管”是双重误会：他工过《登金陵凤凰台》**）；**用私德审判站队**（永王案是认知局限与乱世信息劣势的产物——**同情不等于洗白：把他当“人”而非“仙偶”来判，才是尊重**）。
:::

::: exercise 干谒信新写 {level=1}
用《与韩荆州书》的姿态学写一封当代“自荐信”（实习/社团/约稿皆可，150 字）：**要求把“请看我”写成“你在错过我”**，且**不得出现一句直接吹嘘**（侧面：用可核的事实与对方的利益）。互评：谁的“傲”有本金？
::: solution
判分：**结构仿件**（称对方之重＋陈己之能＋“** 必若**”式的对赌条件——“若您给我一个下午，我给您一个决定”级）；**无直接形容词自夸**（“倚马可待”是李白的形容词——你的版本应换成果实：“上次那期稿件的转发数据您看过”）；“傲的本金”检查：**没有可核成果支撑的姿态是虚张（李白有《蜀道难》），本题先比本金再比姿态**。
:::
:::

::: exercise 异文小案 {level=2}
《静夜思》通行本作“床前明月光……举头望明月”，而宋人笔记载有旧传本作“床前看明月”“低头见”字样——“跋老笔”公案闻名。**材料立场：异文细节不必背，本题只问校勘与流传的道理**：①“明月”与“看明月”一雅一拙，哪个更可能近古？为什么后世偏要“明月”？②用版本学一句口诀给本案定性（参考[[classical-chinese-2/commentaries]]）。
::: solution
参考：①**“举头／低见”是动作账（看＝抬头，身体合理），“明月”是韵脚账（光霜乡押韵、明月回环）——“看”被修成“明月”，是经典化的抛光工序：越顺口越不朽**；②口诀：**“异文不是错误，是分流——哪条水道的下游多，哪条就是主流”**（校勘不能裁决文学，但能展示选择）。判分：能不加“古人写错了”这类判决即及格。
:::
:::

::: exercise 小论文：天才是一种协作 {level=3}
写六百至一千字，评“**李白的‘不可学’，恰恰是最长协作链的产物**”。须处理：**杜甫的谱系评语**、**贺知章的名号**、**汪伦式民间转发**、**李阳冰与宋元注本的“装修”**至少三项；并解释一个悖论：**为什么文学史上只有李白被系统性模仿而几乎无人“成功”**（提示：用“模仿者只能学嗓门，学不到账本与人设”的机制来解释。
::: solution
判分点：协作链成立（**嗓门（文本）× 鉴定（贺）× 同侪背书（杜）× 分发（市井与歌姬）× 身后信托（阳冰、注家）——“天才”是这条链的总输出，而署名只有一个**）；悖论解释（**模仿李白=模仿输出端；协作链（盛唐的漫游社会、干谒市场、宾贡通道、选学教育）不可复制——**“看似最有个性者，实则最时代”**）；若引入当代对照（**顶流艺人：作品、乐评、热搜、遗属工作室——链条一模一样**）且克制不乱比，加分；结论写“**我们崇拜不可学，正说明我们想要的是那整个时代**”即 A。
:::

::: summary
顶流解剖结案：嗓门（**声压模拟海拔、夸饰=强度的真实、“天然”是设计的效果**）、账本（**散金三十万=投放、干谒信=首页、汪伦=民间分发**）、人设（**谪仙人的股东名单：贺签发、杜甫唯一在解释、各时代在装修**）、账单（**永王案的点差：修辞大脑在博弈局的必然亏损**）。方法一句话：**读李白先读他的“制作”，再读他的“天成”——顺序颠倒一次，天才加深十倍**。下一章进他的反面与知己：杜甫——把诗写成日记、史与时事评论的那个人。
:::
