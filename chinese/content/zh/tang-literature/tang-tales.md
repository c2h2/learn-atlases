---
title: "唐传奇"
---

六朝志怪只干一件事：**证明鬼神存在**（史笔的诚实）；唐传奇干了一件新事：**编故事本身成了才能**。这一字之差，鲁迅用四个字概括——**“作意虚构”**：**从前撒谎是品德问题，在唐代的一种新文体里，撒谎是作品质量**。本章拆这台新机器：它为什么偏偏在进士社会开机，以及它如何靠“女性被弃”这个母题，提前一千年写出了诉讼文书。

## 三台发动机 {#def-fadongji}

::: definition 从“街谈巷语”到“一艺之长” {#def-mingming}
**户口问题**：《汉书·艺文志》把小说家列为“**街谈巷语、道听途说者之所造**”，九流之首却明说“**君子弗为**”——**登记即贬谪：小说从此带着“有用但不入流”的户口生活**。**第一台发动机：史传笔法下移**——列传体的完整装备（姓名、籍贯、世代、际遇、篇末论赞）被拿去给狐狸、蚂蚁、游侠建档：**用写历史的语法写不存在的人，读者会连那个不存在也一起相信**（[[han-to-nanbeichao/tales-criticism]]《搜神记》的“史笔执照”在这里改签了用途：**志怪用史笔求真，传奇用史笔求像**）。**第二台发动机：进士的行卷**——宋人赵彦卫记载，唐士子投卷“**先以篇、赋、歌诗，次以杂文，谓之‘温卷’……文、史、议论三体为一体，可见其才**”，他断言这类杂文“**即传奇**”（**小说作为才华样品：一次投稿同时展示叙事、议论、抒情三项——现代作品集的雏形**）；**行卷未必是史实（宋人追述，宋人自己就爱这么干），但它是文学社会学的真事：唐代最优秀的一批散文家恰是进士，传奇恰好是他们写给自己的娱乐作业**。**第三台发动机：城市与听众**——唐代文献里已有市井“说话”（讲故事）的记载，《太平广记》所收杂俎里存着酒筵竞说的现场；寺观戏场与商旅驿路提供听众与传播网。**不必把每条证据都坐实：三台发动机里，史笔最硬、行卷最响、说话最虚——证据的虚实比例本身就是本课要交的作业**。
:::

::: example 两个梦，一篇判决书 {#ex-liangmeng}
**《枕中记》**：邯郸旅店里的卢生自叹壮志未酬，吕翁授枕——关键情节：**梦中娶高门、中进士、拜相、被诬、抄家、临刑与妻诀别；惊醒时，店主锅里的小米饭还没熟**——卢生醒悟：“**夫宠辱之道，穷达之运，得丧之理，死生之情，尽知之矣！**” **《南柯太守传》**：淳于棼醉入古槐，被迎为驸马、出守“南柯郡”二十年，**政声极好；公主死、失恩、战败，护送归**；醒后掘穴寻之：**槐安国＝大槐树下的蚁穴，南柯郡＝树枝上的一个小窝**——此后他“**遂绝欢宴，不饮酒**”（大意）。两个故事同一套机器。请回答：①两篇的“梦”分别针对什么焦虑（一个临刑，一个失恩）？②《南柯》结尾为什么必须**挖开蚂蚁窝**——只写到“梦醒”不够吗？③为什么说这两篇是“**科举社会的心理测试**”，而不是消极人生观教材？
::: solution
①**《枕中记》测“成败恐惧”**：功名路上的每一步都可能是卢生梦里的下一步——**抄家与临刑是赶考者脑内自动播放的恐怖片，让他在一锅饭的时间里看完**；**《南柯》测“恩宠依赖”**：淳于棼的一切来自主上招婿与父王信任——**失恩比战败更致命；教训不是“皆空”，是“你的地位从来不掌握在你手里”**。②**必须挖**：蚁穴是**叙事的验尸报告**——“另一世界”被降级为庭院里的一个洞：空间尺度一压，人生尺度全塌；**只写梦醒是教训，挖开才是证据——唐传奇第一次让读者看见故事的脚手架，这是“作意虚构”的自供状**。③**两篇都不劝人弃考**：故事以卢生的大彻大悟收束，唐代读者照考不误——它们的功效是把“万一失败”**预先演练一遍：梦是科举制度的压力测试环境，传奇是它的用户手册**；顺便，二篇为汤显祖“临川四梦”供了永动机——**一个母题营业一千二百年**。
:::
:::

::: definition 女性被弃：两种法律 {#def-nvxing}
**《霍小玉传》：诉讼式**。小玉自知门第不够——她那句“不当匹偶”的说辞，等于**从一开始就承认没签成合同**；于是把要求降到最低：不要求正室，只要求几年收留（**“愿岁稍久”的附纳条款，是全文最悲的段落：她把爱情的纠纷谈成了租赁的续期**）；盟誓在前的措辞满篇法律味（指山川、誓白日——**像合同条款**），被弃后她发出中国文学史上最著名的身后追诉：“**我死之后，愿为厉鬼，使君妻妾，终日不安！**”——**把家务事打成公共事件**；随后“黄衫客”强拖李益赴约——**侠客是司法缺位时的民间补丁**；传说李益此后猜忌成疾、“**狂顾乱骂，疑妻有私**”——**诅咒生效的方式正是听众想要的：薄幸人的余生由传说判处终身监禁**。 **《莺莺传》：自辩式**。莺莺“**待月西厢下，迎风户半开**”——**会写诗的女性用密码与行动夺回主动权**；被弃时她认账：“**始乱之，终弃之，固其宜矣**”——**道德自证做到无可挑剔，恰是诉讼资格被剥夺的样子**；张生的辩护词——“**夫天之所命尤物也，不妖其身，必妖于人**”——**把责任转嫁给“尤物”这个物种：文学史上最著名的渣男雄辩**；篇末一句“**时人多许张为善补过者**”——**“时人”与叙述者的语气距离，就是作者的良心距离**。元稹案：张生原型历来被宋人近指作者自况——**让主角用理论为自己脱罪的小说，是最诚实的忏悔书**；下游：《莺莺传》→《西厢记诸宫调》→王实甫《西厢记》——**一桩唐代婚约纠纷再审七百年，每次改判都站在莺莺一边**。
:::

::: intuition 异类为什么比人好 {#def-yilei}
《任氏传》：狐妖任氏**贞且义**，为陪贫士郑六冒死出行，最终死于猎犬、真身显露——**异类以人的标准活，以兽的尸体验证：中国小说最早的“双重身份悲剧”**。《柳毅传》：书生为受虐龙女千里寄书，钱塘君救亲归来**以刀逼婚**——柳毅先拒不娶、归家后再婚——**把“报恩”做成绑架式婚约，唐人的爽文桥段里藏着婚姻制度无法协商的硬伤**。合观：**传奇里最好的人格分配给了狐狸与龙。不是作者偏爱动物，是人间身份太满——士族、科第、婚媒各有法定位置，唯有异类能领走“德”的编制**。**异类是文学的人才引进计划**（[[han-to-nanbeichao/tales-criticism]]“鬼怪外衣、法理内核”在此升级为制度批评）。
:::

::: history 文体的漂移 {#sec-piaoyi}
**中唐爆发**：沈既济《枕中》《任氏》（大历—贞元间）、许尧佐《柳氏传》、白行简《李娃传》、蒋防《霍小玉传》、元稹《莺莺传》、陈玄祐《离魂记》（“**离魂**”＝身体替爱情请假——**后世《倩女离魂》《牡丹亭》的祖宗**）、李朝威《柳毅传》、牛僧孺《玄怪录》、李复言《续玄怪录》——**单篇与集并存：传奇开始有“文集”待遇**；**晚唐**：裴铏《传奇》（**书名成了文体名：“传奇”＝裴铏这本书的营销胜利**）、薛用弱《集异记》、康骈《剧谈录》——**篇数暴涨、质量转奇：宴会文学化（席间竞说）；晚唐传奇之“短”恰是它“说”的基因**；**宋**：《太平广记》五百卷大收纳（**传奇被类书“归档”：进入图书馆即进入经典**），话本把它口语化；**金元—明**：**董解元西厢、《西厢记》杂剧、“临川四梦”——“传奇”一名被戏曲整体接管：文言小说让位给舞台，故事换了货币继续流通**；**清**：蒲松龄《聊斋志异》以传奇法志怪——**唐人的“作意虚构”在清代复归为“用传奇法，而以志怪”（鲁迅语）**；**今**：**《枕中记》式的“逆袭—崩塌”模板是网文的标配结构——传奇是最长寿的文体：它早已改名换代，活在所有“讲故事”的行当里**。
:::

::: warning 读传奇四坑
**当史料读政治情节**（**牛李党争投影论过度解释《任氏》《霍小玉》：小说不是密码本——**“有本事”与“有影射”是两回事：前者是文体能力，后者是八卦经济**）；**当道德案审判人物**（**张生渣、李益薄、柳毅势：传奇的价值恰在把道德做成装置（自辩/诅咒/报恩）而非答案**）；**低估“作意虚构”的难度**（**人类“编故事还自豪”是晚近发明：希腊罗马以史诗为真，六朝以志怪为实——唐代进士第一次把虚构当才华盖章**）；**把《霍小玉》当爱情悲剧**（**它是门第婚姻的案件卷宗：小玉自己说得清楚——“妾本倡家，不当匹偶”：悲剧不在变心，在从一开始就没签成合同**）。
:::

::: exercise 给异类建档 {level=1}
用史传体为一个虚构者（地铁末班车、外卖箱、或一只城市狐狸）写 150 字“传”：**必须有籍贯、世代、一篇末“赞曰”**，且赞语要**一本正经地错误**（像“君子弗为”那样登记即贬谪）。互评：哪一句让你“连不存在也一起相信”了？
::: solution
判分：**史传装备齐全**（籍贯＋世系＋际遇＋论赞，缺一处扣一处）；**“一本正经的错误”＝把不相关的法度套给异类**（外卖箱“以准时为节操，以差评为大故”——**用错的法律越正式越好笑，越好笑越像史**）；金句检验：赞曰里藏一句真社会批评。
:::
:::

::: exercise 重写判决书 {level=2}
《霍小玉传》《莺莺传》各缺一份文件：**小玉的起诉状**（控什么罪？被告抗辩预测）与**张生的答辩状**（他会被哪句自己的台词钉死？）。任选其一写 150 字法律文书体，**必须全文引用原文各两处**。
::: solution
判分：**诉因准确**（小玉案：欺诈＋毁诺＋门第歧视——注意她主张的从来不是“爱情自由”，是“盟誓兑现”：**用她的语言，不用我们的主义**）；**张生自爆点**：用“非礼之遇，没身不忘”对撞“尤物必妖”——**同一张嘴先后引用礼与恐惧，即其伪**；文书体（事实/理由/请求三段）成立者满分。
:::
:::

::: exercise 小论文：虚构的执照 {level=3}
写六百至一千字，评“**唐传奇是中国文学第一次为‘说谎’申请执照：执照由考试制度签发，由城市听众盖章**”。须调用：**《汉志》的“君子弗为”**、**温卷说（及其证据强度）**、**《枕中》《南柯》的梦机器**、**《任氏》的异类编制**至少四项；并处理一个反驳：**若虚构靠“实用”（展示才华/娱乐市民）取得合法性，那“为虚构而虚构”要到什么时候才出现**（提示：可从《聊斋》的“孤愤”或现代文学观任选一端）。
::: solution
判分点：执照机制（**户口贬谪＋进士样品＋城市市场＝虚构的“用途合法性”：唐代小说从不以“艺术”名义获批，它以“有用”骗取通行证**）；温卷说的证据强度须诚实（**宋人追述、现代学者有疑——把存疑的史实当机制讲，本身就是学术写作示范**）；梦机器（**“验尸报告”式的自供状：小说第一次公开自己的构造**）；异类编制（**人间位置饱和，德只有异类能领取**）；反驳处理（**“为虚构而虚构”是更晚的现代执照——但唐人已备好伏笔：当“用途”耗尽（科举废除、说话升级），虚构的合法性就会转向“真诚”——《聊斋》的孤愤正是旧执照换新证的中间态**）；结论写“**所有文体都先假装有用，才获准变得重要**”即 A。
:::

::: summary
新机器结账：发动机（**史笔求像／温卷样品／城市听众**）、梦（**科举社会的压力测试＋挖开蚂蚁窝的自供状**）、女性（**厉鬼诉讼与渣男自辩：道德被做成装置**）、漂移（**书名变文体、文体变戏曲、戏曲变网文——改名换命的冠军**）。方法一句话：**读小说史，先问每个时代允许说谎的理由**。下一章收束本册：词是怎么从酒席上的流行歌曲变成文学的。
:::
