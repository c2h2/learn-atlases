---
title: "韩愈柳宗元与古文"
---

本课的名称里有个陷阱：**“古文运动”不是复古，是一次书面语的改朝换代**——把六朝三百年打磨熟的骈文请下王座，让一种自称“学秦汉”的新散文登基。更冷的事实是：**运动的胜利发生在宋代：韩柳只是发动者，欧阳修才是接收天下的人**。

## 三条纲领 {#def-gangling}

::: definition 文以明道：给文章装用途 {#def-mingdao}
韩愈一系的重建公式：**①用途**——**文以明道**（柳宗元说得最白：“**文者以明道**”，并自述写作纪律：“**未尝敢以轻心掉之**”“**惧其文而不用于世也**”（《答韦中立论师道书》“文者以明道”一系的展开——道是验收标准**））；**②语言**——“**惟陈言之务去**”（《答李翊书》：把现成的词从系统里删掉——**复古的口号，先锋的操作：不许引用，只许发明**）；**③作者**——“**气，水也；言，浮物也。水大而物之浮者大小毕浮**”（《答李翊书》：**把写作问题翻译成载重问题：先养水，再谈船**）。三条合看：**古文不是“散着写”，是给文章重新分配 KPI：从“美”改成“用”——评审标准一改，文体自然换血**。
:::

::: definition 韩愈：以文为戏与以文为诗 {#def-hanyu}
**《进学解》的自产自销**：“**沉浸醲郁，含英咀华**”“**周诰殷盘，佶屈聱牙**”（**用八个字给《尚书》写体检报告，而这八个字自己成了成语：务去陈言的现场演示**）——全文设弟子问难、先生答辩，**是《答客难》《解嘲》的翻案：自嘲体里塞满自夸，笑与怒共用一张嘴**。**《师说》**：“**师者，所以传道受业解惑也**”“**弟子不必不如师，师不必贤于弟子**”——**把“师”从身份重新定义为功能：中唐的门第社会里，这句话等于在讲台上讲平等**（“**韩氏独揽弟子之名，众人不悦，以为狂**”——**狂是真的：他不只写文章，还在拆关系的墙**）。**《祭十二郎文》**：祭文这个韵文程式，被他改成**散文的絮语与自责**——“**其信然邪？其梦邪？其传之非其真邪？**”——**三个“其……邪”连问，问句替代了悼词：文体的破例，是情绪逼出来的**。《毛颖传》为毛笔立传（**以文为戏：史传体×文具＝寓言；“戏”是文体实验的掩护色**）。苏轼盖棺：“**文起八代之衰，而道济天下之溺**”——**“八代”的清单历代算法不一，这是批评史的修辞：精确不重要，声调才重要**。
:::

::: definition 柳宗元：山水的贬官写法 {#def-liu}
**参与永贞革新失败，永州十年、柳州终身**——**古文运动的第二极，是考场之外的流放科产物**。《永州八记》不引奇句也能读：八记把**荒地当作被告来访谈**：钴鉧潭、小石城的每一块怪石，都领到一份“无人赏识”的判词——**山水在柳宗元笔下第一次以“被浪费者”的身份出场（这是屈原香草谱系的散文转世）**；《捕蛇者说》“**苛政猛于虎**”的句式扩写成全篇：**蒋氏宁愿被蛇咬，不肯被官收——对比的伦理学：毒蛇成了税吏的对照组**；《三戒》（临江之麋、黔之驴、永某氏之鼠）——**寓言成组写作：古文拿下小说的阵地**（“黔驴技穷”“庞然大物”两个成语出自同一篇**讽刺小品**）。**与韩愈的分寸**：韩文如长江——李汉为韩集作序，盛推其文如江河并注——**后人以“**韩如海，柳如江**”作对勘：海是气势，江是清深——**柳文干净，因他不需要说服任何人，只需要写清楚**）。
:::

::: example 《进学解》：把批评做成节目 {#ex-jinxue}
文章结构：国子先生晨入学馆，劝诸生“**业精于勤，荒于嬉；行成于思，毁于随**”；学生数“先生之不幸”：（“**先生之于为人，可谓成矣。然而公不见信于人，私不见助于友。跋前踬后，动辄得咎。暂为御史，遂窜南夷。三年博士，冗不见治。**”）——**学生背的“黑料清单”：被贬、无聊、命衰。先生答以“匠石之喻”（大木小柱各有所用）与“孟子好辩”“司马迁《史记》”之典，末了回到“安分”的套话——匠氏用材“各得其宜”，宰相应事“量器而授官”——你拿“进”“成”来问我，是不懂系统**。请解剖：①“业精于勤”这样的正确废话，为什么放在“被反驳”的位置上？②学生清单的功能是代言还是泄愤？③末段“工匠／医生／宰相”三联喻把“怀才不遇”重新定义成了什么？
::: solution
①**正论由导师说出、反证由学生列举——文章把“正确的道理”送进“无用的现实”里做一次压力测试：修辞结构即问题意识（“勤＝成就”这条公式的坏账，由作者亲自出庭作证）**。②**代言＋泄愤的叠加：骂的是当局（“跋前踬后，动辄得咎”——《狼跋》的典故用得又准又毒），用的却是学生的嘴——“代言体”是讽谏的安全带**（与阮籍咏怀的匿名协议同法，[[han-to-nanbeichao/zhengshi-jin]]）。③**三联喻把“不遇”从冤案重新定义为“岗位不匹配”：不指责系统不公，只质疑考核单发错——**表面服软，实际釜底抽薪：若“器”都被错配，则掌“量器”者失明——**“怀才不遇”由此获得了体制内的语法：委屈不必造反，委屈可以申请调岗，也可以申诉**。附加题：能指出全文骈散相间（**古文不是拒绝整齐，是夺回整齐的节奏自主权——骈文的对偶在韩文里改服劳役，没有被解雇**），即 A。
:::
:::

::: intuition 运动为什么会赢 {#int-ying}
骈文的真实优势：**公文、科举、外交——帝国的标准格式，省力且庄重**；它的死穴：**一切需要“推理长程化”的文体（论说、史评、书信辩难）在骈句里呼吸困难**——**双句对仗是短程记忆友好的格式，也是逻辑的减速带**。韩柳的策略不是禁止骈文，而是**新建场景**：师说、原道、碑志、祭文、寓言、山水记、书信——**把“只能骈”的文体名单撕短**。为什么宋人接了盘：**欧阳修把古文写得比骈文更好读（省力原则倒向古文）＋科举与文集出版（写本的批量誊抄）需要一种信息密度高的文体＋二程、朱熹的讲义传统自带散文需求（语录）**——**一种文体的胜利=它接住了最多的新场景**。
:::

::: history 古文：一场三次交棒的接力 {#sec-jiebang}
**中唐发动**：韩柳同时还有萧颖士、李华、独孤及、柳冕一串前驱（**“运动”有先声，才有声势**）；陆贽奏议仍以骈体达到实用高峰——**同期并行，非替代关系**；**北宋再发动**：穆修、尹洙硬学先秦（**硬拷版**），欧阳修“**条达流畅版**”定型，苏轼、曾巩各放大招——**运动成功于它被“写得好看”而非“被论证正确”**；**南宋—明**：理学家“**文以载道**”（周敦颐语——**“载”比“明”更硬：文章变成货车，文学开始给哲学打工**）；唐宋派归有光接力，**前后七子“文必秦汉”把接力棒摔了（**复古派把方法变型号——参见[[tang-literature/high-tang]]的“盛唐商标战”**）**；**清**：桐城派（方苞“义法”、刘大櫆、姚鼐“**神理气味／格律音节**”——**把古文写成可调用的接口：最后一套语法统治到 1917 年**）；**1917—1920**：**白话文运动宣布古文退场——讽刺的尾声：新文学的领袖们（胡适、鲁迅、周作人）古文功力全部顶级——**最了解内行的人负责拆行**——本课所有关于“文以明道／载道／场景”的账，在 1917 年重新清算**。
:::

::: warning 学古文运动四坑
**把“古文”当文体**（**它是运动名称：韩柳的“文”是当时的新散文，不是秦汉语法复读机——“沉浸醲郁”说明他们要的是消化，不是模仿**）；**把骈文当失败者**（**陆贽奏议、李商隐表状在职场一直赢；韩文里对偶改服劳役——**运动换的是主文体，不是灭绝副文体**）；**用“文以载道”评价韩愈**（**“载道”是宋人的收紧：韩柳谈道更近“文章该有用”——用后来的纲领追认前人，是文学史最常见的时空错账**）；**神化“务去陈言”**（**它不是口号是苦役：《答李翊书》自述“泯没与灭俱”的写作实验——先练删，再练写；今天的“拒绝套话”作业与此同源**）。
:::

::: exercise 删陈言训练 {level=1}
取一段你自己最近写的 100 字（周报、感想、评论均可），执行“**惟陈言之务去**”：**凡成语、套语、现成大词一律删除**，只允许“指得出具体东西”的表达；统计删掉的“陈言”数量。
::: solution
判分：**删除清单须诚实计数**（“综上所述”“众所周知”“不免让人感慨”——凡**无指称的架子句**入列）；**合格线：删后字数不减反增**（韩愈实验的真相——**去陈言=用细节换套话，细节比套话费纸**）；**附加：挑出一个被你删掉但其实最该保留的成语**——**韩柳也用过陈言之精英（“佶屈聱牙”自己就是新成语）：反的是惰性，不是现成性**。
:::
:::

::: exercise 新场景清单 {level=2}
“文体的胜利＝接住新场景”。为“今天的文言／正式书面语”开一张**场景审计表**：①列出仍必须用“四字格＋骈偶”的场合（贺词、悼词、碑刻、颁奖辞……）；②列出已被白话彻底接管的场合；③判断 20 年后两个场景的增减，并说明理由（**提示：看哪种格式在“短程记忆友好”与“长程推理”之间怎么站队**）。
::: solution
判分：①②各举三项以上且**按“格式的功能”而非“情感”分类**（悼词要骈，因其“庄重的限速”；论文要散，因其“推理的长程”）；③的预测须挂钩**载体**（语音输入→口语化？弹幕→新四字格？**弹幕的“XX既视感”“爷青回”就是正在发生的骈文——格式对新媒介的适应，才是本课的中唐方法论**）；空喊“复兴文言”者零分——**韩愈会先问：复兴给谁用，用在哪**。
:::

::: exercise 小论文：谁杀死了骈文 {level=3}
写六百至一千字，评“**骈文不是被古文杀死的，是被新的信息场景弃用的**”。须调用：**韩愈“惟陈言之务去”的真实战绩**、**《师说》《进学解》的场景发明**、**欧阳修的“省力流畅版”与文集、语录场景、**桐城派作为“最后一套语法”**至少四项；并处理一个反例：**李商隐的骈文在晚唐依然无敌——“无敌”与“过时”为什么可以同时成立**。
::: solution
判分点：四项机制（**去陈言=语言层面的效率竞争；场景发明=市场创造；宋版定型＋印刷讲义=基础设施；桐城接口=最后的标准化——胜利从来不是审美辩论的产物**）；反例接得住（**文体寿命与市场分层：骈文退出公共论说，退守仪式文体——“无敌”指在残存场景里做到最好，“过时”指不再拥有增量场景——**两者并立恰是文体史的常态：史诗今天也无敌且无人写**）；结论若能写“**杀死文体的从来不是对手，是场景迁移；所谓复古，是拿旧材料回应新需求**”即 A。
:::

::: summary
接力结账：纲领（**明道=改 KPI；去陈言=语言删档；养气=载重问题**）、实验（**韩如海：自嘲体、师道平等、祭文破例；柳如江：荒地被告、毒蛇对照组、寓言成组**）、胜负（**骈文死于减速带，古文赢在接住新场景**）、后账（**“载道”的收紧、七子摔棒、桐城接口、1917 清算——**最懂行的人负责拆行**）。方法一句话：**读文体之争，别听宣言，看它接住了哪些新场景**。下一章：晚唐——两座迷宫与一座黄昏。
:::
