title: "盛唐诗歌"
---

初唐的工程交付之后，盛唐的居民沿着两条路进场：**一条上终南山（以隐居招聘），一条出玉门关（以军功镀金）**——两条路都通向同一个终点：名动天下。本章先逛两条路，再拆一面镜子：**“盛唐”这顶王冠，其实是宋明人才铸好的**。

## 两条路 {#def-lianglu}

::: definition 王孟：山水的公务员与隐士 {#def-wangmeng}
**王维**：诗与仕的双优生（状元及第、官至尚书右丞，安史中受伪职而诗不晦），名“维”字“摩诘”取自《维摩诘经》——**名字即书房**。《山居秋暝》“**明月松间照，清泉石上流**”——**两个主谓宾并置，人退场：不是写景，是让景物自己值班**；《鹿柴》“**返景入深林，复照青苔上**”——**光做二次搬运，照的是最没人看的角落：王维的镜头语言=对微物的偏爱**；《鸟鸣涧》“**人闲桂花落，夜静春山空。月出惊山鸟，时鸣春涧中**”——**以知觉反常写静：花落、月出本是阈值之下的信号，只有“闲人”收得到——静不是物理量，是接收器的状态**。苏轼评语：“**味摩诘之诗，诗中有画；观摩诘之画，画中有诗”——注意这句广告词的陷阱：“诗中有画”是宋人观画方式的移植：诗的本质恰在画不出的部分（“**夜静春山空**”的空，镜头拍不到——**能被镜头拍到的都不是王维的全部**）**。**孟浩然**：布衣终老，“**不才明主弃，多病故人疏**”——**相传玄宗读到这句不悦：“卿不求朕，朕未弃卿”——干谒失败的一桩公案：皇帝亲口判他落选，隐逸从此成了他的独家品牌——**李白的广告词：“**红颜弃轩冕，白首卧松云”——**孟浩然的“不试”被盛唐名人圈包装成稀缺资产：隐逸是有市场的，代言人是李白）**。合称“王孟”：**一个在体制里买山，一个在江湖上卖山——山水诗的两张商业面孔**。
:::

::: definition 高岑王昌龄：边塞的两种镜头 {#def-biansai}
**高适《燕歌行》：社会问题片的镜头**——“**战士军前半死生，美人帐下犹歌舞**”——**同一首乐府旧题里完成阶级蒙太奇：边塞诗第一次把镜头从敌我转向官兵**；序称“**感其苦**”而作——**“其”指张守珪部将失策而朝廷不察——边塞写实与政论缝合**。 **岑参《白雪歌送武判官归京》：奇观片的镜头**——“**忽如一夜春风来，千树万树梨花开**”——**以春花撞冬雪：苦寒被改写成盛大的礼物包装，这是边塞诗的“美学滤镜”：苦难先须好看**；“**风掣红旗冻不翻**”——**一面不会飘的旗：物理的极端成为诗的奇观——岑参是感官新闻学的边地记者**。两镜头合看：**高适把边塞拉下神坛，岑参把边塞推上银幕——盛唐边塞诗的振幅，恰好是一个帝国从自信到奢侈的心电图**。**王昌龄“七绝圣手”**——“**秦时明月汉时关，万里长征人未还**”——**互文句法把一千年压缩成一夜：秦汉的月照唐人的关，边塞的全部历史在读者视网膜上叠影；绝句的“容量神话”由此定标**——**“七绝圣手”之号由明人追补（与李白争席位——**小诗体的圣号，是后世评选的产物，参见本章“镜子”一节）**。
:::

::: definition 孤篇与空白：两个著名事件 {#def-gupian}
**空白事件**：殷璠《河岳英灵集》（约 753 成书）标榜“**声律风骨始备**”，选王维、李白、高岑……**而不录杜甫**——**盛唐人在编辑盛唐时，漏掉了日后公认的半壁江山**（杜甫身后由元稹、韩愈、宋人一路追封——**经典是滚动发行的股票：盛唐当时，杜诗还是潜力股**）。**孤篇事件**：张若虚《春江花月夜》沿用陈隋宫调旧题，以“**江畔何人初见月？江月何年初照人？**”把乐府艳歌升维成宇宙追问——**但它在唐宋元明代选本里几乎无存在**，直到清末王闿运父子标举、**闻一多封它“宫体诗的自赎”“诗中的诗，顶峰上的顶峰”、再经“孤篇压全唐”的网民口号——一部被发现的经典**（与《春江花月夜》对照的是它自己：**名篇不是文本的属性，是传播史的函数**）。
:::

::: example 概念考古：“盛唐”是谁的发明 {#ex-shengtang}
请排一个年表：①殷璠《河岳英灵集》论“**开元十五年后，声律风骨始备矣**”；②南宋严羽《沧浪诗话》以“**盛唐诸公**”为最高法、“**羚羊挂角，无迹可求**”“**惟在悟**”；③明前后七子“**诗必盛唐**”；④清王士禛“神韵”再抽一层糖；⑤闻一多“盛唐是诗的盛世”。问：**这五层各在干什么？“盛唐”一词的意思变了没有？**
::: solution
**一层层揭**：①**殷璠在做当期评论**——“开元十五年”是同时代人的分期直觉，尚无神话；②**严羽在立法**——把盛唐树成“不可学”的范本（“羚羊挂角”＝**结果完美到看不出工艺：批评家用一个否定式赞美，为宋诗的“说理”翻案——捧盛唐是手段，打江西诗派是目的**）；③**七子在占产地**——“诗必盛唐”把时代变成可模仿的型号，李梦阳们的创作与其说是学盛唐，不如说是**申请盛唐的商标授权**；④**王士禛在提纯**——把盛唐蒸馏成“神韵”一剂，服务于自己的流派处方；⑤**闻一多们在画文明曲线**——“盛世=诗盛”的史观是 20 世纪的比较文明学投影。**语义检测：五层里“盛唐”从不是一个稳定对象，而是每个时代对着自己缺口立起来的标准——它的意思一直是：我们所缺的那个时代。** 结论句式：**“盛唐”不是唐诗的一个分期，是宋至清批评史的年轮；研究“盛唐”＝研究历代人想从诗里要什么。**
:::
:::

::: intuition 高峰经济学 {#int-gaofeng}
盛唐诗歌的“高峰”可以被拆解成一组**供给侧变量**：**考试全员练笔（人口）＋歌行绝句两套新体刚竣工（工具）＋帝国路网与幕府（场景）＋隐逸与军功两条成名捷径（激励）＋贵族收藏与酒肆传唱（发行）**。其中最容易被低估的是**激励**：**终南捷径与从军行，都是“不走正门”的快速通道——当一条路太挤，聪明人全去开发侧门，侧门就成了新题材的温床**：隐逸开发出山水，边塞开发出战争与雪、音乐与酒。**所谓盛世气象，一半是国库，一半是侧门**。反用这条逻辑即可解释晚唐：**侧门焊死（幕府内卷、科举垄断），山水边塞都成了“前代题材”，诗人只能回身向内——李商隐的迷宫是激励结构改变的并发症**。
:::

::: history 一条被追认的曲线 {#sec-zhuiren}
**当期**：殷璠《河岳英灵集》、高仲武《中兴间气集》——**唐人选唐诗：正在发生的经典化，现场感十足且盲点巨大**；**宋**：**严羽把盛唐供上神坛；同时苏轼们把杜甫配享为“集大成”——“盛唐”与“李杜”两套经典系统在宋完成组装**；**金元**：元好问“**曹刘坐啸虎生风，四海无人角两雄**”——**金源诗人以唐音抗宋调，“盛唐”第一次成为反攻的武器**；**明**：**前七子（李梦阳、何景明）“文必秦汉，诗必盛唐”——复古派把盛唐变成 KPI；后七子（李攀龙、王世贞）接力；竟陵派（钟惺、谭元春）嫌模拟太胖，转去挑“幽深孤峭”的盛唐**；**清**：**王士禛“神韵”选唐——《唐贤三昧集》以王孟一路为最高味——**神韵派把盛唐重新剪辑成王维频道**）；沈德潜《唐诗别裁》调和；**民国**：**闻一多、林庚把盛唐比作民族的“少年时代”（林庚的“少年精神”说）——高峰叙事最终成为一种民族心理学**；**今**：**“盛唐”进入教材与文旅（“大唐不夜城”）——概念的终点是夜游灯光：一切被追认的黄金时代，最后都负责照明**。
:::

::: warning 读盛唐四坑
**拿“盛唐”当时间段硬套**（**713—765 的边界全是约定：王维活到乱平之后，杜甫的杰作全在“盛唐”之后——按生卒年他们半辈子在“中唐”**；分期是地图网格，不是气候）；**把“诗中有画”当赞美终点**（**它同时是测量误差：用视觉尺度量听觉与时间艺术——先找画不出的那一秒**）；**以“岑参奇”“高适实”分等级**（**奇观与问题各是镜头选择；用“真”骂“美”或用“美”洗“真”都放弃解释**）；**把“孤篇压全唐”当结论**（**一句营销口号的走红史恰是本课例题：声音越大，越要问谁在什么年代需要它**）。
:::

::: exercise 反常镜头 {level=1}
模仿《鸟鸣涧》的“知觉反常”写一段 80 字短文（现代场景：自习室、地铁、宿舍皆可）：**必须用两个低于阈值的微信号写一种环境状态**，禁用“安静”“冷清”等直接形容词。互评：对方“拍不到”的那一秒是什么？
::: solution
判分：**信号要真的“小”**（笔尖的分贝、灯管的频闪、手机震动的余光——**放大微小是王维的第一语法**）；**接收器状态要可推断**（不写心情，写注意力的走向）；“拍不到的一秒”＝**文中唯一属于身体内部的那一笔**（如“忽然想起一件没回的消息”——找到了，本题满分）。
:::
:::

::: exercise 新边塞 {level=2}
“侧门经济学”实操：选一个当代“出远门讨生活”的群体（海员、货车司机、外派工地、主播驻播——**对应唐代的征人、商妇、幕僚、游侠**），写一首 8—12 行的新诗或一段 150 字“现代《燕歌行》”：**要求同时包含高适镜头（内部不公/结构性对比）与岑参镜头（异地奇观）**，并各标注一句对应关系。
::: solution
判分：**两个镜头必须各自成立**（问题镜头：一句“战士/美人”级的对仗性并置；奇观镜头：一个“梨花”级的强喻——**只写辛苦=纪录片，只写风景=宣传片，两者相撞才是边塞诗**）；对应标注合理（**用典的现代转译禁止表面化——“铁衣”不必出现，“寒光照”的机制须出现**）；附加题：指出你的题材与唐诗边塞的**一处不可通约**（诚实加分——**类比是镜头，不是镜子**）。
:::
:::

::: exercise 小论文：我们需要一个“盛唐”吗 {level=3}
写六百至一千字，评“**‘盛唐’是中国批评史发明的一面标准镜：每个时代用它量自己的身高**”。须调用：**殷璠漏杜**、**严羽“羚羊挂角”**、**“诗必盛唐”的商标战**、**闻一多“孤篇”翻案**至少三项；并处理一个反方：**如果“盛唐”只是发明，杜甫李白为什么确实伟大**（提示：区分“伟大”的两种判定——系统内的经典地位 vs 跨系统的可翻译性）。
::: solution
判分点：五项机制说清（**殷璠＝盲点证明当期标准≠后世标准；严羽＝立标准是为改诗风；七子＝标准变成品牌；闻一多＝标准的再分配**）；反方接得住：**“伟大”拆两账**（**地位账：随批评史浮动——杜甫从“潜能股”到“诗圣”即其流水；才能账：一首诗的声纹、句法、意象的不可复制性，可跨语境被反复验证——翻译会损耗而不断电，即证据**）；结论若能写“**我们不需要一个盛唐，但我们需要知道：每次有人举出‘黄金时代’，先问他量的是什么——标准的年代学就是欲望的档案**”，即 A。
:::

::: summary
两条路与一面镜结账：王孟（**买山与卖山两种隐逸经济；“闲”=接收器状态；“诗中有画”是带刻度的误读**）、高岑（**问题片与奇观片；“不会飘的旗”＝感官新闻学**）、王昌龄（**互文压缩千年于一夜**）、镜子（**殷璠漏杜＝经典滚动发行；“盛唐”＝历代欲望的年轮**）、高峰经济学（**盛世一半是国库，一半是侧门**）。方法一句话：**凡是“黄金时代”，先查是哪个年代镀的**。下一章单独立传：那个从没参加律考的人——李白，大唐最大的一位自媒体。
:::
