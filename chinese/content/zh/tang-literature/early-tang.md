---
title: "初唐诗人"
---

唐诗的开场所需的不是天才，是**两位工程师和一场叛乱**：沈佺期、宋之问把律句的螺丝拧到最后一家工厂；陈子昂从涪江边搬来“风骨”这柄大锤，砸向宫廷的琉璃瓦。本章讲律诗如何竣工、宫廷如何变成赛场、以及四杰如何一边打工一边骂街。

## 工程验收 {#def-gongcheng}

::: definition 律诗的竣工报告 {#def-lvshi}
**宫廷现场**：武后游幸赋诗竞巧——**东方虬先成赐锦袍，宋之问后作而词愈丽，夺袍更之**（“夺锦袍”：文学史最早的颁奖礼现场）——**竞技公开化：初唐宫廷是诗的赛场兼训练场**。
:::

::: definition 四杰：在宫廷里闹事 {#def-sijie}
**王勃、杨炯、卢照邻、骆宾王**——**神童、短命、下狱、逃亡四种命合一件事：有才无位**。上官体当红，他们**用乐府旧题与歌行把宫廷的镜子转向自己**：“**海内存知己，天涯若比邻**”（王勃《送杜少府之任蜀州》）——**送别诗从此有了盛唐的骨架：不哭，改拍肩**；《滕王阁序》——“**落霞与孤鹜齐飞，秋水共长天一色**”＋**“时运不齐，命途多舛”**——**骈赋的炫技场里塞进一篇牢骚：初唐最著名的一次“应景夹带”**。杜甫《戏为六绝句》为四杰撑腰：“**王杨卢骆当时体**”而“**尔曹身与名俱灭，不废江河万古流**”——**“当时体”三字是文学史自觉的标志：一代有一代的写法，嘲笑他们的人先消失**。骆宾王《为徐敬业讨武曌檄》——“**一抔之土未干，六尺之孤何托**”，**相传则天读之动容，惜“宰相安得失此人”——敌国宰相的妒才：文章效力的一次传奇测试**。
:::

::: definition 陈子昂与“风骨”政变 {#def-chenziang}
**《与东方公书》《修竹篇序》两手宣言**：“**汉魏风骨，晋宋莫传**”“**齐梁间诗，彩丽竞繁，而兴寄都绝**”——**诊断：修辞的通货膨胀（彩丽竞繁）与表达的通货紧缩（兴寄都绝）**；药方：**回到汉魏的“质”与“志”——用时间差造空间差**。**《登幽州台歌》**：“**前不见古人，后不见来者。念天地之悠悠，独怆然而涕下**”——**六言散句、不避复字、无对偶——把“复古”写成一次格律罢工：一首反技巧的诗成了技巧史的地标**。**接受史**：殷璠《河岳英灵集》推重其革新之功，明代翻刻其集、通论“**唐兴初称四杰，而伯玉《感遇》直追汉魏**”成为文学史常识——**政变成功于身后：复古旗帜的杆子，是后人替他竖起来的**。
:::

::: example 一场试帖诗的复盘 {#ex-shiti}
把本课三样工具同时用上一道真题：唐省试诗题“**赋得**××送别”类——**限题、限韵、限六韵十二句、要求“得”字起或题中字样应见于篇**。请：①列出一首合格试帖诗的“评分项清单”（格、对、切题、用典、颂圣收束）；②解释为什么**试帖诗几乎不出好诗却出了好诗人**；③用“**应试训练=全国拼音化的声调肌肉记忆**”一句，向杜甫、王维、钱起省试名作（“**曲终人不见，江上数峰青**”钱起《省试湘灵鼓瑟》）指认它的功与过。
::: solution
①**清单**：平仄粘对零失误（一票否决）、**中二联对仗工而能变**（工对及格，反对／流水对加分）、题字入句不破题、**用典切题**（湘灵必出《楚辞》）、**结句归于“温柔敦厚”**——《省试湘灵鼓瑟》的结尾“**曲终人不见，江上数峰青**”恰好满分：考核项目里长出了千古名句。**失败项示范**：只堆典故而失粘者，榜上无名且史上留不下名字。
:::
:::

::: intuition 形式先于天才 {#int-xingshi}
**行卷=作品的发行渠道**（**卷贽达官、三日观名誉——作品需要社交网络认证，“诗名”是一种共同维护的假说**）。
:::

::: history 从内廷到天下 {#sec-neiting}
**隋代**：《隋书·文学传序》提出南北文风“**各去所短，合其两长**”——统一帝国的文学政策先行，初唐只是执行；**贞观**：太宗修文学馆、亲制乐府——宫廷成为全国写作的示范单位；**高宗—武后朝**：上官仪“六对八对”之说——对仗的技术手册化（把直觉写成规程，是帝国文官系统的本能）；沈宋体于武后朝竣工，而四杰已先其锋；**开元天宝**：进士科诗赋取士权重定型——律诗从宫廷游戏升格为帝国敲门砖：形式的全民化，靠的是录取线；**张说、张九龄以“燕许大手笔”掌内制**——宫廷文章向士人气象过渡；**746 前后**：殷璠编《河岳英灵集》，选诗坐标已移到江湖与边塞——**初唐的工程，被盛唐的居民入住**；**后世**：“初唐四杰”“初唐体”诸名目皆宋明人倒排的户口——**分期本身是文学史的追授**（组是编出来的，朝也是分出来的，[[han-to-nanbeichao/nineteen-old-poems]]同法）。
:::

::: warning 读初唐四坑
**当“铺垫”来跳读**（**初唐不是等待盛世的彩排：律诗、歌行、复古论全是原创制度——彩排论是盛唐中心主义的偏见**）；**把宫廷诗当无病呻吟全删**（**夺锦、应制是文学生产制度的现场：先懂赛制，再评作品**）；**神化“风骨”口号**（**陈子昂的创作并未完全兑现纲领——《感遇》三十八首的优劣历来聚讼，纲领与产品的落差是文学史常态**）；**用今音判古诗出律**（**律诗平仄依赖中古音：入声读今平声会“误判”——“**白、日、绿、节**”皆仄；声韵课的工具在此上岗**）。
:::

::: exercise 声调体检 {level=1}
选一首五律（王勃《送杜少府》或王维《山居秋暝》），**标平仄**（依《平水韵》系统，参考[[phonology/rhyme-tables]]）、圈出中二联对仗的类型（工对/反对/流水对）、指出粘对有无“失误”及唐人如何豁免（“一三不论”与拗救可提，标不出则从简）。
::: solution
判分：**标注可复核**（入声字须按仄——“**白、日、入、绿**”级；今读平声的古入声是体检重点）；对仗分析到位（“**明月松间照，清泉石上流**”=工对之清；“**随意春芳歇，王孙自可留**”=散句收，流水势）；能指出**格律的呼吸感**（对=平衡，粘=连贯——**两原则交替即“起伏的公路”**）者优。
:::
:::

::: exercise 为四杰写颁奖词 {level=2}
以今日文学奖口吻为四杰之一写 120 字颁奖词：**必须包含一件生平硬伤（贬、死、逃、狱）、一项文体贡献、一句对其“当时体”的辩护**；再写 30 字“落选评委的批评”，让两方互怼成立。
::: solution
判分：硬伤与贡献不张冠（王勃—交趾省父、渡海卒；骆宾王—讨武檄文亡命；卢照邻—风疾去官;杨炯—“盈川”令终）；“辩护”句可用杜甫《戏为六绝句》句式（**“当时体”三字是题眼——为一代写法辩护，是文学史观的练习**）；批评方也须像评委而非喷子（**如：格律未纯、用事太密——批评要有可用的刻度**）。
:::
:::

::: exercise 小论文：考试与诗 {level=3}
写六百至一千字，评“**唐代诗的繁荣，科举（诗取士）有一份产权**”。须处理：**省试诗的格式约束**、**“行卷”的场外发行**、**试帖体与名家创作的实际渗透**（钱起省试名句入唱和圈）、**以及反例：李白不靠考试、孟浩然不第**”；结论须给“**制度与天才**”关系一个可检验的说法。
::: solution
判分点：**产权说清份额**（考试供给：声调人口、文体标准、评论市场；不供给：杰作——**但杰作必须用公共货币结算：李白的自由体仍以律句为参照系**）；反例处理干净（**李白免考是“制度外声誉”的胜利：贺知章一荐顶十卷——行卷网络与考试制度互为备份**）；可检验说法示范（“**若取消诗赋取士，律诗的普及会退化到什么程度？——对照宋代以后律诗退出考试后的格律松弛**”——**给一个反事实作为论文的承重柱**）。
:::
:::

::: summary
竣工与罢工结账：沈宋（**黑名单减法成图纸——格律=国家级质检**）、宫廷（**夺锦与应制：文学生产制度的现场**）、四杰（**应景夹带＋杜甫的“当时体”辩护**）、子昂（**复古是时间差造空间差；政变成功于身后**）、地基（**规则＋素材＋渠道＝天才的前三件套**）。方法一句话：**先问制度提供了什么可违反的常规，再谈天才**。下一章进盛唐：两条路——终南山与玉门关，王维与高岑如何分赃“山水”与“边塞”两大题材。
:::
