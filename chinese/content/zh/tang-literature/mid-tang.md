---
title: "白居易与中唐诗人"
---

安史之乱后，帝国进入漫长的善后期：藩镇、宦官、党争三套系统同时漏电。诗歌做出**两种相反的战略调整**：一路**向下兼容**（元白：写到妇孺能解），一路**高端加密**（韩孟：险到骨子里去）。本章把两路都走完，再回收一个盛唐伏笔——杜甫那些“不像诗”的材料，谁接住了。

## 善后期的声音 {#def-dali}

::: definition 大历十才子：群体名单与个体名句 {#def-shizicaizi}
“大历十才子”是**事后追封的流派**（唐人结派，多靠一部选本一张嘴**；通行名单本无定本：十个人名，宋人以来说法互有出入——**群体的边界至今模糊，潮流的边界因此清楚：战乱后的诗退回酬答应酬，气象让位精琢**）。高仲武《中兴间气集》所收即此期主力——**选本即党籍**。代表景观：**钱起《省试湘灵鼓瑟》“曲终人不见，江上数峰青”**——**中国文学最有名的考试答卷：满分作文恰好长在满分美学上，空灵到看不见考场**；“鬼传清句”的传说（夜闻阶前诵诗自称“幽意”——**考场佳句需要鬼来背书，正说明人们不信人能在省试里写出它**）。刘长卿自许“**五言长城**”——**中唐的第一句 slogan 是关于体量的，不是关于气象的：长城＝防守性建筑，隐喻很诚实**。
:::

::: definition 韩孟：不平之鸣与险怪供应链 {#def-hanmeng}
**理论**：韩愈《送孟东野序》“**大凡物不得其平则鸣**”——**把屈原到本朝全编进“鸣”的家谱，为一切难听的声音发执照**（与陈子昂的“风骨”政变同一手法：**用复古的旗，行造反的实**）。**产品**：孟郊“**冷露滴梦破，峭风梳骨寒**”——**雨刮器刮的不是玻璃是梦：韩孟派的“硬”，是把痛觉写进物性**；贾岛“**鸟宿池边树，僧敲月下门**”——**推敲的传说（冲韩节、并骑定之）是科举社会的成功学段子：一句诗的价值，要靠偶遇文坛盟主来定价**；“二句三年得，一吟双泪流”——**炼字寓言：中唐把“苦吟”从习惯升格为身份**。合观：**韩孟供应链＝理论（不平之鸣）→工艺（苦吟、炼险）→人脉（韩愈荐挽）→称号（郊岛、诗囚、奇鬼）——一条完整的反主流生产线**。
:::

::: definition 李贺：动词的政变 {#def-lihe}
“**黑云压城城欲摧，甲光向日金鳞开**”——**天体当攻城器械；“石破天惊逗秋雨”——女娲补天的裂缝里“逗”出一场雨：李贺的革命在动词：不是用形容词装饰世界，是用动词重新立法**（[[rhetoric/figures-of-meaning]]比喻科的超纲卷：**喻体与本体的距离拉到光年，靠动词强行接吻**）；“**衰兰送客咸阳道，天若有情天亦老**”——**让抽象的“天”参加一场送别：时间是被告，石头是证人**；“**玉轮轧露湿团光**”——**月亮的车轱辘碾湿了露水：神话材料被他当道具库随便改装**。生平限制：避父讳不举进士（“晋肃”撞“进士”——**礼法的谐音梗，断送一个天才的编制：唐代避讳制度的著名事故**），终身奉礼郎小官；二十七岁死；**“诗鬼”追号与“仙”成对偶——浪漫主义需要一仙一鬼的货架**。杜牧亲自为他编集作序——**顶级同行抢着做遗产执行人**。
:::

## 通俗战略 {#def-tongsu}

::: definition 白居易：把诗歌当产品做 {#def-bdy}
**纲领**：《与元九书》“**文章合为时而著，歌诗合为事而作**”——**中国文学批评史上最著名的一句产品需求文档**；《新乐府》自注“**其辞质而径，欲见之者易谕也；其言直而切，欲闻之者深诫也**”——**连“可读性指标”都写进体例（接《文心》课“事核言直”：训诂的诚实转世为谏诤的格式——公文系统的美学，白居易是总设计师）**。**读者测试**：“老妪能解”的传说（写诗欲令老妪解，不解则改——**测不测得先不论，这个传说把“可懂性”树成了方法论神话：白居易不需要真的测试，大家已经愿意相信他在测试**）。**同情诗的结构**：《观刈麦》“**今我何功德，曾不事农桑。吏禄三百石，岁晏有余粮。念此私自愧，尽日不能忘**”——**杜甫式记账升级：白居易不描写苦难的惨，登记自己与苦难的账目差——诗人站上被告席，读者自动入陪审席**。
:::

::: example 作者亲手降级了自己的代表作 {#ex-sijia}
白居易编定诗集，自分类为四：**讽谕、闲适、感伤**等科，并明言自己所重者在讽谕（美刺兴寄之作），闲适、感伤诸类多是病中愁里的自我安置。事实：传诵最广的恰是他降级的《长恨歌》《琵琶行》——元稹《白氏长庆集序》记录当时“**禁省、观寺、邮候墙壁之上无不书，王公、妾妇、牛童、马走之口无不道**”——**爆款全在作者评分最低的那一格**。请回答：①作者分类学与读者传播学各按什么变量运行？②“为时为事”的纲领为什么拦不住《长恨歌》走红？③《琵琶行》“**同是天涯沦落人，相逢何必曾相识**”——把江州司马与商妇并坐一条船，这个“并座”与《观刈麦》的“被告席”结构有什么继承与滑移？
::: solution
①**作者按政治效用的账（美刺=可上呈的资本：诗是他的第二份奏疏）；市场按故事的账（爱情＋音乐＋名士：唐代的“流行”以歌唱传抄为单位——叙事与抒情才配得上旋律）**。②**纲领约束题材，不约束才华的溢出：《长恨歌》里“为时”的框架装满了非“为时”的痴迷——好的长诗总在其纲领的边缘漏水**（“**讽乐之体，叙事之情：白居易自己也没能分清**”）。③**继承**：都让“我的余裕”与“他人的苦”同桌；**滑移**：《观刈麦》里白居易站在**有罪一侧**（余粮原语），《琵琶行》里他与琵琶女**同为天涯沦落人**——从同情结构滑向认同结构（**贬官是他拿到“沦落”入场券的方式：中唐士人把政治失意审美化的开始——这条“感伤”的路，宋代的词会接着走**）。附加判分：能指出“四等分法”本身是**文集的自我防御（作者先替审查与清议归类）**，加分。
:::
:::

::: intuition 两种信息策略 {#int-lianglu}
把元和朝当一家内容平台看：**元白＝下沉市场**（语言浅近、题材公共、以“达”为 KPI——新乐府是**写给帝国的公开信**）；**韩孟＝高端垂直**（以“奇”为护城河——苦吟是**把读者筛选成同行**）。两条路共同的处境：**宪宗朝言路时开时塞（武元衡当街被刺、白居易因母名“赏花”“新井”被停解——奏疏走不通，诗歌接管进谏与自辩）**——**当公开信道拥堵，一切文体都会转世成隐喻**。中唐诗的“变”因此不是衰退，是**同一批人在不同带宽上的重新分配**：能说的写成乐府，不能说的写成怪诗，不能说又不能忍的，写成《琵琶行》。
:::

::: history 中唐坐标 {#sec-zuobiao}
**785—805**：贞元贡举重诗赋，大历余音与新生代际同场（**韩愈四试礼部乃登**——**考场失败者联盟改写了文学史的录取标准**）；**803—805**：元白始以歌行相高；**806—820**：元和体盛——**“元和体”本含贬义（轻薄者仿元白“次韵相酬”的千言长律，洛阳纸贵到让作者尴尬）：风格被模仿者发明、被抄袭者定价**；**815**：武元衡遇刺、白居易贬江州（**《琵琶行》元年：帝国首都的挫折，外放到文学上反而盈利**）；**824**：元白唱和终身（**“元白”并称的运行机制：三千余次酬答、次韵联句——唱和从应酬变成游戏，从游戏变成文体**）；**846**：白居易卒——**他留下了中唐最完整的自我档案：自编文集＋分类法＋致元九的长信：作者兼评论家兼编辑三职合一**；**后世**：“**元轻白俗，郊寒岛瘦**”（苏轼的八字判词，流传度超过任何一部诗话——**批评家的金句是二创：被引用即获奖**）；江西诗派尊杜并学韩（**险怪一系转正为“生新”**）；**今**：“老妪能解”进入产品方法论读物（**通俗战略的终点是互联网黑话：白居易成为最早的用户思维代言人**）。
:::

::: warning 读中唐四坑
**把“大历十才子”当社团**（**没有宣言没有刊物：流派是选本与批评史的合作出品——先查名单的版本，再谈风格**）；**以“反映现实”打分**（**新乐府的价值在“制度提案”，韩孟的价值在“感官扩容”：一把尺量两路，两头都输**）；**把险怪读成晦涩的失败**（**“石破天惊逗秋雨”的动词是精确的：先还原它的物理，再抱怨它的难**）；**忽略白居易的矛盾**（**他自评与传诵的倒挂不是丑闻，是文学社会学的标本：作者意图、文本倾向、读者选择三方永远在谈判**）。
:::

::: exercise 鬼对句考证 {level=2}
钱起“曲终人不见，江上数峰青”出现在两篇作品里：《省试湘灵鼓瑟》与《暮春归故山草堂》（“谷口春残黄鸟稀”一首——**材料立场：两题均见于通行的《钱考功集》**）。①这属于版本学哪一类问题？②给两种裁决方案（“省试原创”与“旧句配题”各的证据）；③为什么“鬼诵”传说会附着在这两句上？
::: solution
参考：①**同集异题/互见的文本归属问题（与《登鹳雀楼》署名案同类——[[classical-chinese-2/commentaries]]）；②**方案 A：省试原创**（考题限韵逼出天成——**“试帖能出名句”的传奇性正是传播动力**）；**方案 B：旧句入新题**（才子有“句囊”，考试是货架——**唐人行卷献纳即靠旧作库存**）；裁决靠**两条同时出现的最早文献**与韵脚适配度；③**传说替人间的不可信出具证明：满分试卷＋满分美学＝需要非人作者**（与“思入非常”“神助”同一心理——名句总被追授超自然出处——接谢朓“池塘生春草”公案）。
:::

::: exercise 小论文：通俗是一种野心 {level=3}
写六百至一千字，评“**白居易的‘俗’是他最难的技巧：把复杂问题说简单，比说复杂难得多**”。须调用：**“老妪能解”传说**、**“元和体”被模仿的尴尬**、**《琵琶行》的并座结构**、**“元轻白俗”的需求侧**至少四项；并处理一个反方：**浅白是不是对苦难的美化（《卖炭翁》的宫市之恶被韵文包装成“好诗”，道德上安全吗）**。
::: solution
判分点：四项机制（**可懂性是设计；模仿尴尬=通俗的可复制性反噬——护城河太浅；并座=认同的美学红利；“白俗”是精英文学的份额焦虑——俗是市场成绩，不是工艺缺陷**）；反方处理：**承认张力——诗让恶“可传播”，也让恶“可欣赏”；白居易的解法是把愤怒留在事实层（宫市的账目），把音乐留给形式层——两不冲抵**（和稀泥者扣分：必须选边并承认代价）；结论写“**简单是一种勇气：它放弃行会的保护，去接受所有读者的审判**”即 A。
:::

::: summary
两路结账：善后期（**十才子＝选本出品的模糊潮流；“长城”隐喻很诚实**）、加密线（**不平之鸣发执照；李贺的动词重新立法；“诗鬼”与“诗仙”成对上架**）、兼容线（**纲领＋体例＋读者测试神话＋被告席结构**）、倒挂（**作者评分最低的一格传播最广——三方永远在谈判**）。方法一句话：**读流派先查它的名单由谁编制；读纲领先问它反对什么**。下一章回到宫廷与战场之间：晚唐——杜牧的史论笔法与李商隐的多重入口。
:::
