title: "杜甫"
---

上一章结尾预告过：李白的朋友里，藏着唐诗的另一半。杜甫是**李白的反面与知己**：一个把帝国活成广告，一个把帝国活成病历。他生前诗名平平，身后被追封为“诗圣”——**本章要同时读两个人：八世纪的杜甫，和宋以后造出来的“杜甫”**。

## 失败者简历 {#def-jianli}

::: definition 困守长安：天才的负面课程 {#def-kunshou}
**简历**：出身诗儒之家（祖父杜审言，文章四友之一——**他是“文学世家”的负资产：起点即债务**）；科举两次失意（“**奉儒守官**”的家训撞上李林甫“野无遗贤”的闹剧贡举——**天宝六年的那场集体落榜，把“朝廷不会漏人”的神话当场打脸**）；困守长安十年：“**朝扣富儿门，暮随肥马尘。残杯与冷炙，到处潜悲辛**”——**干谒诗的诚实版：李白把求职写成对赌，杜甫把求职写成记账**；直到安史乱起前后才得小官，随即陷贼、逃难、贬官、入蜀、漂泊——**他的传记就是一部唐代的故障记录**。
:::

::: definition 诗史方法：把标题写成行程单 {#def-shishi}
**“诗史”的技术定义**：不是“诗里写历史”，是**用诗的档案功能补史书拒收的部分**。三件工具：**①题目即元数据**——《自京赴奉先县咏怀五百字》《北征》：地名、里程、体裁全进标题，**史官的编年思维被压进诗题**；**②对话体实录**——“**吏呼一何怒，妇啼一何苦**”（《石壕吏》）、“**听妇前致词：三男邺城戍。一男附书至，二男新战死**”——**差吏与老妇的庭辩直接誊录，诗人全程不出面：旁观的镜头是最强的证词**；**③“诗可以怨”的官民双声道**——三吏三别**不控诉也不歌颂，只让“征”与“哭”同屏**：国家要兵，家庭给不出兵，**杜甫把这道无解方程原样抄下来——“诗史”的深度在于他不解方程**。名句归案：“**朱门酒肉臭，路有冻死骨**”——**同一秒钟的两间屋子：蒙太奇而非议论；杜甫不再加判词——对仗即史论，帝国的财政问题被压缩进一个镜头。**家用细节革命**：“**妻孥怪我在，惊定还拭泪**”（《羌村》）——**乱世重逢的第一反应不是喜是“怪”：幸存者的伦理学，史书没有栏目，杜甫开了**；《北征》写女儿：“**床前两小女，补绽才过膝**”——**裤子短这样的事写进五言长诗：贫穷第一次成为史诗细节**。
:::

::: definition 律圣：晚年把镣铐跳成芭蕾 {#def-lvsheng}
**《登高》**：“**风急天高猿啸哀，渚清沙白鸟飞回。无边落木萧萧下，不尽长江滚滚来。万里悲秋常作客，百年多病独登台。艰难苦恨繁霜鬓，潦倒新停浊酒杯**”——**八句皆对、一句数层（宋人赏“万里”一联层折至八九意）——沉郁＝一句话里叠印多重时间**；胡应麟推为“**古今七律第一**”——**这个第一是后人颁的：杜律的地位与“诗圣”同批到货（见“封条”一节）**；**《登岳阳楼》收束法示范**：“**吴楚东南坼，乾坤日夜浮**”——**十个字吞尽洞庭；“戎马关山北，凭轩涕泗流”——宇宙尺度折回北望的战乱：杜甫的收束定律＝把个人痛苦存进天下账户，利息才付得起**。
:::

::: example 《春望》：一封寄不到的信 {#ex-chunwang}
“国破山河在，城春草木深。感时花溅泪，恨别鸟惊心。烽火连三月，家书抵万金。白头搔更短，浑欲不胜簪。”（757 年，陷长安中。）请做三件解剖：①首联的“**在”与“深**”各替哪样东西报丧？②**“花溅泪”“鸟惊心”的主语是谁**——这是修辞问题还是语法问题？③给“家书抵万金”做一次**信息经济学**估值（烽火=通信中断，万金=比价系数），并说明：**为什么此诗被当作“诗史”标本却几乎不“记录”任何事件**？
::: solution
①**“山河在”=一切不在**（城郭宫室烧了，只剩地图上的自然——**“在”字是遗言的省略号**）；**“草木深”=没人**（春天照常营业，但营业给谁看：**“深”是无人之城的计量单位**）。②**语法上两可，修辞上必两可**：花使人流泪／花自溅泪、鸟惊人／恨别者闻鸟而惊——**主客界限的坍塌正是“感时”的定义：世界坏掉时，你无法确定痛苦属于你还是属于春天**（修辞课所谓“移情”的最高级：不是移情于物，是**主客系统宕机**）。③**家书无价（万金=比价失效的客气说法）——通信中断把“亲人活着”降格为待验证传闻；诗本身就是那封写不出去的信：文学在此补位通信系统**。④诗史标本却无事件——因为**诗史记录的不是事件清单，是事件过完后的心理账目：史书写了安史之乱的军报，杜甫存的是它的“情绪资产负债表”**——**两本账都要有，缺哪本我们都读不到完整的唐朝**。
:::
:::

::: intuition 两道封条的颁发记录 {#int-feng}
**④现代卸妆**：冯至《杜甫传》等把“圣”还原成“人”——**最好读的杜甫，恰是那个嫌客吵、怜小儿、自称“幽事颇相关”的草堂老翁——圣号之下住着一个爱发牢骚的邻居**。**封条阅读法：读任何“某某主义”的杜甫时，注意贴封条的那只手属于哪个世纪**。
:::

::: history 李杜：一桩千年官司 {#sec-guansi}
**生前互赏，身后并立**：杜甫赠李白诗十余首——“**千秋万岁名，寂寞身后事**”，他早为两人的行情写过预言；李白答诗冷淡且多系伪托（“饭颗山头”一诗即后人编排的假新闻）；**中唐**：元稹墓志扬杜抑李——“李杜优劣论”开审；**宋**：“李杜”并称成为默认配置——苏辙、王安石各持异同，优劣论成为固定题型；**金元**：元好问以论诗绝句重排唐代座次，李杜同受其裁判——金源批评家把唐人的官司当作自己的棋盘；**明清**：格调派与性灵派各择师资，宗杜者奉“正统”、尚李者取“天才”——一桩比较文学官司，判来判去，判的是各自的诗学立场；**今**：课本分工——李白主想象、杜甫主现实：两种“好用”各得其所（本课提醒：这是 20 世纪的排课表，不是唐人的评价）。
:::

::: warning 读杜甫四坑
**背成“忧国忧民的符号”**（**先读《羌村》《北征》里的怕、愧、喜——道德来自现场反应，不是口号**：他的“忠君”里常夹着对具体皇帝的失望账单）；**跳过题目**（**杜诗的题目是正文的三分之一：行程、对象、事由——先题后诗**）；**把“沉郁顿挫”当形容词**（**它是技术：层折（一句多意）、顿挫（律句的故意拗折）、收束（个人入天下账户）——给形容词配施工图再谈风格**）；**用封条代替阅读**（**元稹的杜甫、江西的杜甫、宋儒的杜甫、教科书杜甫，层层贴条——剥封条不是否定传统，是看清每条封条的需求侧**）。
:::

::: exercise 情绪资产负债表 {level=1}
选一场近年公共事件中的一条“官方通报＋一条民间个人记录”（微博、日记、寻人启事皆可），仿《春望》的分工**写两行诗/两句话**：一行记账目（事件清单），一行记情绪（心理账目），并写 50 字说明**两行为什么不能合并**。
::: solution
判分：**两行文体差异要肉眼可辨**（通报的语言 vs “草木深”的语言）；说明到位：**合并即互相取消——账目吞掉情绪=宣传，情绪吞掉账目=谣言；杜甫的价值在坚持两本账并存**。
:::
:::

::: exercise 圣与人的温差 {level=2}
给定材料两条：《羌村三首》“**苦辞酒味薄，黍地无人耕。兵革既未息，儿童尽东征**”；《江村》“**但有故人供禄米，微躯此外更何求**”。写 200 字：从“诗圣”里救出“人”，需要动哪两把手术刀？
::: solution
判分：**刀一：情境化**（“但有故人供禄米”＝寄人篱下的自我宽解——**圣人不讨饭，杜甫讨，而且写得体面又心酸**）；**刀二：不替换神像**（“苦辞酒味薄”四句的民瘼不是人设是家常——**拆圣号不是为了立“普通人”小像：杜甫的伟大恰在普通材料的高精度燃烧**）；引诗准确、各带出处者满分。
:::

::: exercise 小论文：为什么杜甫是“可学的” {level=3}
写六百至一千字，评“**李白不可学，杜甫可学——但‘可学’既是他封神的原因，也是他被误读的开始**”。须调用：**苏轼“能事毕矣”的集大成论**、**江西诗派的句法律谱教学法**、**元稹墓志的“体势”说**、**《戏为六绝句》的“转益多师是汝师”**至少四项；并回答：**“可学”与“伟大”矛盾吗**（提示：康德天才论／工匠传统任选其一做对照，不必生吞）。
::: solution
判分点：机制说清（**“可学”＝方法可传授：集大成（他本人转益多师）＋法度可拆解（律、法、字法）——杜甫是唐诗里第一个“带教程”的作家**）；误读链条（**可学→可考→可考据可道德化：宋人注杜、道学家封圣、教科书定型——“可学”的教程属性被偷换成“可考核”的圣人属性**）；矛盾之问接得住（**参考立场：不矛盾——“伟大”在使用者一侧：李白的伟大是一次性烟花，杜甫的伟大是一座开放工厂；也可反方：把“可学”当价值标准，正是诗学从创作转向学术的开端——立场自洽即可**）；结论若写“**我们学杜甫，学的从来不是像他，是他怎样把所有不像诗的东西变成诗**”，即 A。
:::
