title: "鲁迅的杂文与散文诗"
---

上一章拆的是讲别人故事的机器；本章进两间屋：一间朝街（**杂文**——投枪与手术刀），一间朝内（**《野草》**——对自己动手术）。两间屋共用同一套电气线路：**对立场永不免除自我审讯**。

## 第一间屋：杂文 {#def-zawen}

::: definition 一个违约文类的营业执照 {#def-yingye}
“杂文”的户口本来就疑难（第 8 章文类学的现行案卷：**非诗非文非小说的“随意文”——它的自谦（“杂”）与伪装（“报屁股”）都来自报刊专栏制度**：1918《新青年》“**随感录**”开张＝现代杂文的产房（短、快、按期、面对报馆读者——**文体由版面决定：一期一会逼出“千字千峰”的身材**）；“**且介亭**”的自译（“租界”切半——**半租界的亭子间：杂文的地理学铭牌：文体、租界、检查三者在同一张书桌上办公**）。功能定义取鲁迅自供：“**对于有害的事物，立刻给以反响或抗争，是感应的神经，攻守的手足**”（《且介亭杂文》序言）——**杂文＝文学的反射弧：不生产长篇的消化，生产毫秒级的痉挛；它的“短”不是轻视，是神经传导速度的物理要求**。
:::

::: definition 招数三式 {#def-zhaoshu}
**①引号的刑具**——《“友邦惊诧”论》：“**友邦人士，莫名之‘惊诧’，中国的人民，反在‘屠刀’之下**”式的引号流水线（篇中名句为“友邦人士，从此‘惊诧’了”一类的引号连击）——**给引用加引号＝给立场戴手铐：全文不驳“惊诧”的理由，只展览“惊诧”的排期表（今日是什么，明日是什么），让证据链自己走向判决**（讽刺经济学：不付论证的工资，让对方的自相出卖自己）；**②低语料民族志**——《论“他妈的！”》从国骂的分布密度切入（“**中国的国骂**”考据——**从最俗的语料入手做文化考古：等级制在骂人话的辈分语法里留下了完整化石：一句脏话读出一部宗法史**）；**③悖论标题**——《**为了忘却的记念**》（左联五烈士）——**“为了忘却”与“记念”互相拆台：检查制度下的修辞学——机制：标题是一起案件：当局没收“记得”的权利，文章就自称为了忘却而记（反话的语法：把禁令内化为自己的动机，好让禁令无处着力）**；《记念刘和珍君》是正面强攻版：全文在“说与说不出”之间拉锯（“我说”“我无话可说”的反复——**悼文的结构＝语言在哀悼面前的装卸记录**。
:::

## 第二间屋：《野草》 {#def-yecao}

::: definition 表达主义的黑屋 {#def-heiwu}
《野草·题辞》开场即第 4 章言意之辨的终审：“**当我沉默着的时候，我觉得充实；我将开口，同时感到空虚**”——**充实属于沉默、空虚属于开口：表达被判定为亏损生意（“言不尽意”的古条款在此长出现代神经症）**；而《野草》全书是**明知亏损仍要开业的账本**——**“辞的不动”与“不得不作”的对冲产生文体：散文诗＝违约利息的支付凭证（不押韵不给它自由，分行不给它散文的身份——两头违约，两头退税）**。
:::

::: definition 四出独幕剧：选择的修辞学 {#def-dumuju}
《野草》的体裁是**内心独幕剧**（人格被切成道具上台互质）——**《过客》**：无名客（名字是借的，“客客气气”地叫作“过客”走过野地，女孩赠布、老翁劝“回转去罢”，回答只有“**但我总须到前方去**”——**“不知道前面是坟”仍走：选择先于知识（存在主义的中国元年：不靠光明担保，只靠“不得不停下”的反面）**；**《死火》**：“我”在冰谷发现冻住的火焰，携它出谷，它**终于燃尽而灭**——**冻灭还是烧灭：两个坏选项里，“我”抢到的唯一财产是“选”的动作**（**机制：两难（aporia）的文学标本——冻灭与烧灭两种坏选项里，“我”唯一能带走的是“选过”的凭据：鲁迅不给出路，他给“出路”这个词做解剖**）；**《影的告别》**：“**我不过一个影，要别你而沉没在黑暗里了。然而黑暗又会吞并我，然而光明又会使我消失**”——**影在明暗两头都无仓位：彷徨不是犹豫，是账面清算后的唯一诚实余额**（“**我不愿彷徨于明暗之间**”——**在明与暗之间选择“被黑暗沉没”＝用自我取消完成最后的表态**）；**《风筝》**：兄长毁掉幼弟偷偷扎的风筝，多年后忏悔求恕，“**然而他是没有怨恨的——然而我的惩罚终于没有**”——**忏悔经济的坏账：受害者不记账，施害者的债就永远挂账——宽恕缺席时，愧疚成为无限期徒刑（“没有宽恕的债主”：鲁迅把自己判成无期，替读者免了票**）。
:::

::: example 无物之阵：《这样的战士》×《复仇》 {#ex-wuwu}
《这样的战士》：“**他走进无物之阵，所遇见的都对他一一点头……然而只不过是无物之阵**”——敌人身披“**好**”的外套（“好青年”“好文艺”“好国粹”），战士举矛，**对方倒地时仍像“好”**；《复仇》：两个裸持刀的人站在旷野，“**路人”层见叠出地来鉴赏——“以“无所为而看”对“看”本身罢课：他们“以自居于无所有、空虚之中，来‘让’看客无戏可看**”（大意）。请：①“无物之阵”与第 1 章“黑名单不生产作品”是同一现象吗（提示：**敌人的隐形＝规则的非正式化——讽刺的对象没有实体，因为压迫由共识与体面执行**）；②《复仇》的“拒绝被看”在装置层＝对《示众》的反向复刻（列表对照）；③裁决：**“反抗绝望”与“绝望的抗战”哪个短语更贴文本**（“绝望之为虚妄，正与希望相同”——《希望》引裴多菲）。
::: solution
①**同一种非正式权力**：八不主义禁的是文，无物之阵躲的是名——**敌人以“好”为伪装＝审查不需要法令，品味与体面就是执法者：战士的长矛因此找不到合法的落点（打击“好”＝打击共识＝自己变疯子——狂人案的成年人版本）**；②对照表（《示众》：**看＝消费他人痛苦的特权，围观产生事件**；《复仇》：**被看者的不合作罢工＝夺回“事件”的定义权——不挣扎、不流血、不满足；机制：期待违约＝对观众席开刀；同一群人在两部作品里从主角降为笑柄——鲁迅把读者也编进队列：读到“路人们”，请自查站位**）；③裁决（**“反抗绝望”偏心理史诗（存在主义励志版），常被抽空为口号；“绝望的抗战”保住战术学：战士明知无物仍举矛——斗争的形式本身成为证词，胜利从合同里删除：《这样的战士》结尾，战士老衰、死在无物之阵里——死不改变阵型，但死让阵型现形：篇末他“身中泥镞，一手还高举着没有投出的矛”——姿势即遗产**）。
:::
:::

::: intuition 两副笔锋一副肝 {#int-yifu}
杂文对外（点名、查账、上刑引号），《野草》对内（切片、自审、注销自我）——**同一条原则的两个朝向**：鲁迅的全部文体共享一个反虚伪条款：**修辞不得赦免说话人**（杂文里“我”永远在起诉名单上占一格，《野草》里连“我”的形体与影子都各自出庭——**“我的确时时解剖别人，然而更多的是更无情面地解剖我自己”（《写在〈坟〉后面》）：这句话不是谦虚，是制度设计：自我审讯是杂文公信力（引号敢给别人，先敢给自己）的抵押物**）。**本课警告性补充**：此句式常被当作“伟大”的证据引用——**本节只把它当装置登记：抵押物机制解释了鲁迅杂文为何敢用引号、他的讽刺为何免疫“你行你上”的反噬：因为他先行了、先上了、先付了**。
:::

::: history 匕首的两用史 {#sec-liangyong}
**1918** 随感录（**专栏制度开业**）；**1925—1926** 副刊笔战黄金年（《语丝》周刊——**“任意而谈，无所顾忌”的语丝文体：**刊物＝文体孵化器（第 8 章：文类是集体记忆的语法；语丝社＝一个以杂文为会标的俱乐部**），“语丝体”由此定名**）；**1928—1935** 革命文学与自由人论争（**杂文成为路线武器：鲁迅的后期杂文火力全开——同时招致“偏激”指控：偏激是反射弧的副作用，不是道德缺陷）**；**1932—1934** “论语派”幽默闲适 vs 左翼杂文的**文类斗争**（**林语堂办《论语》《人间世》：“以幽默为武器”与“以武器为武器”的同业竞争——茶与匕首的商战：两种主体性风格（第 8 章风格即选择函数：幽默选择“旁观的自由”，杂文选择“介入的负债”**）；**1940s** 延安杂文风波（**“暴露与歌颂”之争——投枪第一次要求办理持枪许可（第 9 章效果史的现行案卷）**）；**1961—62** 《燕山夜话》《三家村札记》（**杂文在计划经济年代的一次短暂复兴与它的悲剧性回收：专栏作者的命运成为杂文最后的注脚**）；**1980s—90s** 杂文复兴（**报刊复苏＝文体复苏：随笔、杂文、时评连番扩容——第 1 章制度说：文体的兴衰跟着版面的预算走**）；**今** **微博体与千字评论＝杂文的算法化续命（**转发量＝新的“反响或抗争”读数；热搜＝无物之阵的实时测绘图：引号刑具进化为表情符号——讽刺的载波频率随媒介上调；反射弧认不出主人，但认得出刺激。
:::

::: exercise 引号练习 {level=1}
从最近一轮公共争吵里取三个自称体面的口号（“为你好”“格局”“情绪稳定”任选三类），**各写 50 字“展览式”短评**：不驳其理，只排其期（何人何时对何事引用——**让排期表自己走向判决**）；互评哪条的“引号”上得最准。
::: solution
判分：**零形容词反驳**（展览体纪律）；**排期表真实可查**（日期、场合、发言人三列——**杂文的证据链底线**）；上得最准者＝让口号的自我矛盾自己显影者（“为你好”在劝捐与劝加班时的语义差——**同一引号在不同句子里的租约**）。
:::
:::

::: exercise 独幕剧改编 {level=2}
把《过客》或《风筝》改写成**三分钟当代短剧**（保留结构两难，禁用心理描写与旁白——**只许台词与舞台指示**）；附 80 字：你的版本里“冰谷/旷野”换成了什么。
::: solution
判分：**两难无损**（选项必须仍皆坏且不可退——**改成“有人点醒他”即违规：鲁迅不给的那条路，你不许私建**）；舞台指示承担装置（**布、坟、风筝＝道具的证词职能**）；换算诚实（“冰谷＝加班的写字楼”级——**换算须保留温度学：冻灭＝耗尽，烧灭＝辞职称职两种坏——保留“选”的唯一财产权**）。
:::

::: exercise 小论文：抵押物与反射弧 {level=3}
写六百至一千字，评“**鲁迅把杂文写成一种信用工具：每一枚射向别人的引号背后，都有一页先缴的自我账单——讽刺的本金是自己的不安**”。须调用：**反射弧定义**、**引号刑具**、**悖论标题**、**独幕剧的两难**、**《野草·题辞》的亏损开业**至少五项；并裁决：**社交时代的“人人有引号”是否实现了鲁迅的杂文民主化——还是只复制了它的声带**。
::: solution
判分点：五项机制（**反射弧＝毫秒级痉挛与证据链；引号＝戴手铐的引用，抵押物机制使其免疫“你行你上”；悖论标题＝禁令内化；两难＝选择的修辞学（选的动作是唯一财产）；亏损开业＝表达主义账本**）；裁决（**两条参考：民主化论——转发即专栏、热搜即无物之阵的实时测绘：人人举矛符合“反射弧”的下放；声带复制论——鲁迅的火力与自我账单分账结算，网络讽刺几乎全部只出口不上缴：缺抵押物的引号是纹身不是手铐；且“无物之阵”在算法里变成回音室——长矛挥向同一阵地的战友，阵型永不现形**）；结论若写“**杂文的寿命不取决于匕首的锋利，取决于持刀人是否把自己也算进伤口清单：复制声带者众，缴账单者寡——反射弧仍是公共体的，只是痛觉报告常常伪造**”，即 A。
:::

::: summary
两屋归档：朝街（**反射弧：引号、民族志、悖论标题三件工具；短是速度要求**）、朝内（**亏损开业的账本：四出独幕剧演出“选”的最后财产**）、电路（**修辞不得赦免说话人：自我审讯是公信力的抵押物**）、后世（**茶与匕首的商战、持枪许可、热搜续命**）。方法一句话：**先查作者的账单，再听他的判决**。文体篇还有两章：诗与散文——下一章看新文学如何解决它自己注销的那笔格律旧账。
:::
