title: "1920—30 年代的小说"
---

上一章散文领了薄执照，本章看小说如何**批量试穿外衣**：1920—1937 的十七年，白话小说把“可能写成什么样”的问题一次采样完——**问题小说、自叙传、乡土、心理、都市、市井、家族、社会分析，八种版型共用一块布料**。

## 版型总账：同代人的采样实验 {#def-banxing}

::: definition 两面店招与一场误读 {#def-dianzhao}
**1921 文学研究会**（“为人生”的文学——**血与泪的现场采访证词：文学研究会的“为人生”不是口号，是入职表：写实、暴露、反映社会现象（《小说月报》改革号要旨大意）**）vs **1921 创造社**（“为艺术”的浪漫自我——**同伴留学、同人刊物、论战起家：社团＝创业公司，店招＝融资 BP（第 2 章兑换所的民国路演）**）。**关键纠偏：这两面店招的“对立”被后世夸大了——“为艺术”的一派照样呐喊救国（《女神》的火山不闲），“为人生”的一派也讲艺术自律；真正的分歧在“自我”的入账方式：一个把“我”当作社会问题的取样点，一个把“我”直接当作品——**店招之争其实是记账法之争（第 8 章：风格的仓位）。
:::

::: definition 四种取样法 {#def-quyang}
**①问题小说（冰心）**——“**问病不给药的处方文学**”：写女子教育、家庭、战争与“爱”的疑难——**每篇附一张问诊单，药方常常只剩“爱”（“问题”被提出即完成使命：这是启蒙文体的诚实版：医生先证明自己也在病中）**；**②自叙传（郁达夫《沉沦》1921）**——**把“不体面”写成证据**：性苦闷、忧郁、弱国子民的羞耻在同一段独白里合账——“**个人的屈辱与国家的屈辱共用一个句子（《沉沦》主人公的呼号大意）：私小说的杀伤力不在暴露，在举证：原来“羞耻”可以有社会成分表**”；**③乡土（鲁镇后学：王鲁彦、台静农、彭家煌）**——**“侨居者笔下乡愁是距离的利息”**：北京的书桌俯视绍兴、台州的乡镇——**“静漠的写生”与未加装饰的悲哀（鲁迅《小说二集》导言对乡土一作家的判词大意）：看客结构换成了记账结构——故乡不再被围观，被盘点**”；**④新心理（施蛰存《梅雨之夕》《将军底头》1932—33）**——**把弗洛伊德请进杭州与唐代：偶遇的心理蒙太奇、乱伦与弑父的古典改编——“心理分析的中国签证：不写梦的解析报告，写“理性的海关被潜意识走私”的瞬间**”。
:::

## 都市、市井与家族：三种城市语法 {#def-chengshi}

::: definition 新感觉派：小说的爵士乐化 {#def-jushue}
**刘呐鸥、穆时英、施蛰存（部分）——上海分行（1930s《现代》系）**：**穆时英《夜总会里的五个人》——数字与色彩的轰炸、蒙太奇剪辑、电影分镜入文（自铸转述：五个人各持一段绝望走进夜总会：城市用噪音给失眠者做麻醉——'小说的爵士乐化'：句子带上快门速度与霓虹灯色温”）；**——**都市作为新物种首次成为主角：此前小说的城市是布景（鲁镇的镜像），此处城市是叙述者本身（马路、百货公司的视线政治——“观看的方式被明码标价：新感觉派＝本雅明式的巴黎拱廊街上海分店）**”。**老舍：把北京话从方言升级为文学语言**——**《骆驼祥子》（1936）的“个人奋斗破产抛物线”：三起三落的账目结构（买车—丢车—再攒—再失——**小说用加法与减法做一道数学证明：在制度参数不变时，努力变量的收敛值为零；“体面的，要强的，好梦想的”式的定语堆叠开场——**京味的幽默是缓冲垫，不是麻醉剂：笑着看一个人被扣除到只剩“个人”的壳）**；《月牙儿》的“穷的抒情学”（**月牙作为贯穿意象：不控诉，只照见——第 6 章呼告的撤位**）。**巴金《家》（1931）：控诉的火焰与行动号召**——据《家》后记的通行表述：“**我写《家》的时候，我仿佛在跟一些人一同受苦，一同在魔爪下面挣扎**”：青春的祭文与对“作揖主义”（觉新的“作揖主义”“不抵抗主义”是书中的定名）的鞭打；效果史的核弹级案例：多少读者因《家》而出走——一部小说作为行动号召的实证（第 9 章：意图≠成就≠后果的满汉全席）”。
:::

::: definition 社会分析的旗舰：茅盾《子夜》 {#def-ziye}
**《子夜》（1933）——“社会分析小说”的旗舰**：民族资本家吴荪甫的铁手腕在“帝国主义资本＋买办金融＋农村破产”三面夹击下崩盘（**公债市场的多空对决＝小说的高潮：让股票行情成为情节——经济学作为叙事动力学的中国首航**）；**方法论：把第 2 章“传感器”写成全景模型：吴荪甫不是坏人也不是英雄，是“1930 年代中国民族资产阶级”这一函数的图像（典型环境中的典型人物——恩格斯条款的最认真执行官）**；**它的代价同样清晰：观念先行处人物变哑（吴老太爷进城“封建僵尸”的开场寓言——象征密度压住生活质感：社会分析的强项与弱点同时上台——后来的“主题先行”病案在此已有 CT 片**。
:::

::: example 三场“进城”对照 {#ex-jincheng}
小说人物三次进城各代表一种城市语法：**①吴老太爷进城（《子夜》开篇：被霓虹灯与汽车“吓死”）**；②**祥子进城（农村青年进北平买车：身体作为生产工具）**；③**刘姥姥进大观园（第 5 章旧案：内部“乡”进内部“城”）**。列表比较：**城市在三部文本里各是舞台、角色还是语法**；再回答：**“乡下人进城”为什么是 1930s 中国小说的总情节**（提示：1930s 的史实是农村破产与都市殖民化的双向流动——**文学不是反映，是命名这股人流：给它语法**）。
::: solution
①**《子夜》：城市是语法兼凶手**（吴老太爷之死＝**旧符号系统在新感觉环境里的兼容性崩溃：他死于“看见”——城市以信息量行凶：第一章的“传感器”理论在小说开头的自我演示**）；②**《骆驼祥子》：城市是交易所兼屠宰场**（**身体是唯一资本，拉车是唯一的期权——城市把他的努力精算到零，连利息都不给：祥子的堕落是精算结果不是道德失败**）；③**《红楼梦》：城市是舞台兼标本柜**（**刘姥姥的眼睛给贾府贴价签——城乡对视的经典版；但大观园不是现代都市：它没有“行情”，只有“规矩”——行情才是现代性**）；**总情节答案**：三场进城覆盖 1930s 的全部社会动力学——**殖民资本的都市、破产的乡村、以及两者之间那条“人”的输送线：小说的任务不是同情流亡者，是把输送线本身画出来（文学命名人流的方式：给“进城”装上行情、身体、目光三种刻度——“乡下人进城”因此成为现代中国文学至今未写完的总题目（1980s 打工文学、2010s 小镇做题家：同一道大题换卷子）**。
:::
:::

::: intuition 体裁的采样竞赛 {#int-caiyang}
把八种版型摊开，会发现 1920—30s 是**一场公开的采样竞赛**：**每人认领一块新地，立一块新碑——碑文写得都不算最顶尖，但八块碑围出的范围就是“现代汉语小说”这个新物种的栖息地**（第 3 章“格式特别”的集体版：鲁迅个人试车，一代人试路）。**理论判词：实验期的产物要按“采样价值＋完成度”双栏评分——只按完成度评，会错杀样本；只按采样价值评，会把草稿当杰作（文学史教材常犯后一种错误，中学读本常犯前一种）**。**本章自选动作**：1937 年战争全面改组文坛（下一章）——**采样竞赛被中断：八种版型有六种尚未出代表作：现代文学的“未完成”不是失败，是时间被战争征用（效果史的强制截账）**。
:::

::: history 十七年采样清单 {#sec-qingdan}
**1921** 文学研究会、创造社成立＋《沉沦》出版（**店招与自叙传同年开业：新文学的两副人格都出生于 1921**）；**1923—25** 问题小说热与“为人生”讨论（**女学生读者团进场：文学革命的第一批增量用户**）；**1925—28** 乡土作群成形（**语丝社与未名社的刊物网络：文学地理从首都扩散到省城中学教员的书桌**）；**1928** 茅盾《蚀》三部曲（**大革命的一手证词：从“幻灭”到“追求”的三段式＝时代情绪的曲线记录**）；**1931—33** 《家》《子夜》《骆驼祥子》前后脚（**家族、金融、市井三大战役：三年里新文学交出了三部长篇的“重型装备”**）；**1932—34** 《现代》与新感觉派、新心理（**都市语法专利局开业**）；**1935—36** “京派／海派”论争（**焦点：文学要不要都市化、商业化——海派被斥为“恶俗”：第 8 章体裁等级制的民国重演：这次争的不是文体等级是城市等级**）；**1937.7** 抗战全面爆发（**采样竞赛鸣金：刊物停刊、内迁、朗诵与报告文学接管版面——第 4 章分发政变的同步事件**）。
:::

::: exercise 小论文：未完成如何辩护 {level=3}
写六百至一千字，评“**现代文学的‘未完成’是史学的公断还是战争的私刑：八种版型都没长满，判词不该由截账的人来写**”。须调用：**两面店招（记账法）**、**四种取样法任选二**、**三种城市语法任选二**、**《子夜》的 CT 片教训**、**采样竞赛双栏评分**至少五项；并裁决：**若 1937 年战争不曾爆发，1950 年的中国小说会更伟大吗**。
::: solution
判分点：五项机制（**店招＝仓位分工；取样＝栖息地围栏；城市语法＝行情的三种刻度；CT 片＝观念先行的可预警病灶；双栏＝实验文学的审计准则**）；裁决（**两栏都要有：更伟大论——采样期自然进入积累期，长篇小说的成熟或提前十年（《子夜》的 CT 片若不被战争打断，或被反复修改为更精密的社会模型）；不一定论——1930s 各版型的代表作其实多产自流亡与战乱（《家》《骆驼祥子》都写在动荡年）：中断论低估了文学的寄生能力；且 1950 年代的新体制本身会重划围栏：未被打断的也可能是另一种采样（对照国统区/解放区的双线）**）；加分（**指出反事实史学的方法论限度：“若没有战争”是不可检验命题——本课用法是“把战争当作一次自然实验：观察文学的哪部分是时代的孩子、哪部分是文体自己的孩子”——第 2 章传感器与第 4 章自律的长期对赌**）；结论若写“**截账只注销余额，不注销资产：八块碑没有变成八座楼，但每一块都标着经纬度——后来者是照着经纬度来盖楼的**”，即 A。
