title: "新闻写作"

上一章的文书面对一个能追问你的读者；本章的文书面对一千万个无法追问你的读者——**新闻写作是应用文里唯一把“可核验”写进体裁本身的种类：它把最重要的话放在第一段，把来源标在句子内部，把更正当作正文的一部分**。

## 定义：倒金字塔 {#def-daojinzita}

::: definition 一种为删改而写的结构 {#def-jiegou}
**通说脉络**（**把事实按重要性递减排列，第一段给出核心事实，其后逐层补充背景与细节；关于其起源有多种解释，包括按字计费的电报与线路中断，学界对其成因并不一致（**本课的解释（**①它是一次顺序革命**（**自从口头叙事以来，一切故事都把最重要的放在最后；**倒金字塔是第一次把结论放在开头，并公开承认余下部分可以不看（**它牺牲的是悬念与节奏；它换来的是可截断性（②**它的第一读者是排版编辑**（**版面在截稿前少三分之一，编辑从尾部删起；**能这样删的稿子才是合格的消息（**本章第 1 页所谓“双读者文体”的极致：**第一段给读者，尾部给编辑（③**它的代价同样具体**（**重要性由谁判定，就交给了写作者；**而写作者的重要性判断常常来自被采访者的口径（**这是新闻业最结构性的一处：它没有独立的“重要性”来源，除非它自己有第二套信息渠道（**本课的自检：**如果一篇稿子的重要性完全来自受访者的议程，那么它更接近上一章的总结，而不是新闻。**
:::

::: definition 导语、五个 W 与标题 {#def-yaoyu}
**导语**（**硬新闻第一段回答谁、什么、何时、何地，并在第二或第三段回答为什么与谁说的；**通说教科书所谓“五个 W 与一个 H”，其实是一条可核验性清单：六个格子里，空格越少，稿件的核查成本越低（②**数字的两件**（**凡数字给基数或参照，凡比例给绝对量（上一章三条失真在新闻里的对应物（**“增长 46%”在新闻里比在总结里更坏，因为读者不会再查到基数（③**标题**（**事实＋动词＋具体对象；**避免把判断写进标题：极限词“最、首、唯一、第一”须有两个独立来源，这是多数新闻机构业务规范的共同要求（通说脉络（**通说脉络：复合标题另设引题与副题，分别承担背景与补充事实（**本课的判据：**读标题应当能复述这条事实；读标题只能复述一种情绪，那是第 9 章的题目（**一句附注：**消息不写“笔者”，不写“我们感到”，不在事实段落里出现形容词；**形容词不是禁用品，它必须被放到引语里，让说它的人签名（**这是新闻写作最重要的一条匿名技术：不是没有观点，而是让观点有出处。**
:::

::: definition “某负责人表示”的三重功能 {#def-sanzhong}
**通说脉络**（**主要新闻机构的业务规范要求交代消息来源，并要求对无法核实的说法标注其来源属性（**本课把常见表述分成三档（**①具名直接引语**（**最强；**它把一句话连同说出它的人一起交给读者（②职务性匿名**（**“有关负责人表示”“相关通知明确”：它不说谁，但说了一个可反查的位置（**它的功能常常有三种：授权发布、试探口径、以及为自己留后路（**注意第三项：**当一个机构准备改变说法时，它先派一个不具名的人出来说一句；**读者把这种稿件读成信号，而不是读成事实——**这是一种正当的读法，也是新闻训练真正教的东西（③纯匿名**（**“知情人士称”“有消息称”：**它是把不可核验的部分转嫁给读者的判断，因而是负债而不是资产（**通说脉络：行业惯例通常要求匿名须满足三条件——信息重要且涉及公共利益、无法通过公开渠道获得、来源可信并经审批（**本课的写法要求：**匿名也必须可核：**至少写明其身份类别、了解情况的性质（直接经手还是听人转述）以及为何匿名（**“据一位直接经手该项审批的部门工作人员说，本报因采访需要对其身份予以隐藏”比“知情人士称”多二十字，却把它从传闻升级为证据（**这就是本章的全部秘密：**新闻不靠“客观”这个词成立，它靠可核的细节成立。**
:::

::: definition 日期测试 {#def-riqi}
**本课给的一条判据**（**把稿子的日期改成昨天，它还成立吗**）；**三种答案（**①不成立，因为里面有一个具体的时间点与一个刚发生的变化**（**这是新闻（②仍然成立**（**它是材料、总结或宣传稿；**它的新闻由头是内部日历：一次会议、一个纪念日、一项工作的节点（**通说脉络：这类稿件常被称为会议新闻或工作报道，其功能多为留痕与传达（③半成立**（**变化很小但可核，需要一个解释性的“为什么现在”段落；**这一段写不好，稿件就退化为第二种（**本课由此给出宣传与新闻的分界：**宣传稿的由头是组织的日历，新闻的由头是公众能感知的变化；**这不是价值判断，而是时间判断——**它可以在稿子上直接测出来（**这也解释了为什么会议新闻读起来都一样：**它们的读者是与会者与上级，而被报道者就是读者；**这种文体不需要新信息，它需要准确与礼仪（**上一章那条“双轨制”在这里以反面出现：**这类稿件若要成为新闻，必须重写：从会议里找出那个可感知的变化，把其余放进第二段。**
:::

::: definition 场景是特稿的数字 {#def-changjing}
**通说脉络**（**特稿或深度报道常以一个具体人物或场景开篇，再进入主题，中段以材料、多方陈述与背景展开，末段回到开头的人物或场景（**本课的四条纪律（**①不得合成**（**把三个人的话给一个人、把两次会见合成一次，属于虚构而非剪裁；**这是行业规范里最硬的一条（通说脉络（②**细节承担论证**（**“他的办公桌上有 17 份待批的材料”之所以有力，是因为它是可核对的；**一个可核的细节比一段形容词更有说服力（**本课的定义：**消息的证据是数字，特稿的证据是细节；**两者都必须可核，否则都只是修辞（③**形容词的位置**（**特稿允许形容词，但要求它挂在一个可复核的观察上：**先给可核的观察，再给一个词（**倒过来写就是文学（**这一句是本章与整门课的交界：应用文与文学的分界不在修辞多少，而在修辞是否有凭据（④**回到开头**（**末段回到开头的人物，是一种诚实的结构装置：**它强迫作者交代这一个月里那个人发生了什么变化；**写不出变化，就说明这篇特稿的主题与人物无关（**这既是结构要求，也是选材要求。**
:::

::: definition 更正、致歉与撤稿 {#def-gengzheng}
**通说脉络**（**职业道德准则与机构规范要求更正及时、位置显要，并区分事实错误与编辑处理失误（**本课的四条（**①更正不是污点，是资产**（**它是这一行唯一能公开证明自己会核对的东西（**上一章说“更正一封、留一份新版本，是文书的正道”；新闻把这句话制度化（②**更正要写出原句**（**只写“有误，应为”而不引原句，读者无法判断错误性质；**隐去原句的更正，是为自己写的更正（③**撤稿是最贵的动作**（**它使所有转载链失去凭据；**通说脉络：多数规范建议除非涉及重大失实或法律风险，不以静默删除代替更正（**“悄悄删掉”在第二章里被批评过，在这里是同一条：**单方面改写历史，一定会被要求出示版本（④**转载须溯源**（**通说脉络：有关转载的规范要求注明出处、不得歪曲原标题原意（**本课的机制解释：**转载链越长，事实与情绪的比例越向情绪倾斜，因为每一次转载都删掉一段来源说明；**这条曲线，是第 9 章“分发格式改变内容”的又一次演示。**
:::

::: example 用三把尺量一条导语 {#ex-lingdu}
“为深入推进××工作，昨日下午，我市召开专题会议，会议强调要提高站位、压实责任，确保各项任务落地见效。”请完成三项：**①做日期测试；②指出它缺哪几个 W；③假设会议确有一项可核变化（试点范围从 2 个区扩到 8 个区、新增一项免费事项），写出一条合格导语**。

::: solution
**①日期测试**——**把“昨日下午”改成前天，全文仍然成立：**没有可感知的新变化（**判定：材料，不是新闻；**它的功能是给会议留痕（②缺失**——**谁（**未写主办单位全称**）、什么（**只有动作名词，没有事项**）、何地（**“我市”而无范围**）、为什么（**无背景，无既往状态**）、谁说的（**“会议强调”是本章第三档里最弱的一种：以会议为引语，无人签名**）（**③改写**——**“本市 8 日将××试点范围由 2 个区扩大到 8 个区，新增的 3 类事项免收办理费用，覆盖约 42 万常住居民；此前该试点已运行 14 个月。市××局介绍，扩围依据是本月印发的××方案（×政办发〔2024〕12 号）。**”**（**六个格子填齐、有一处绝对量与一个可查文号、引语落到具名单位；**“提高站位”一类词全部删除，因为它不可核（**判分（**若改写后仍不含“从什么到什么”，即为本章不及格——**变化必须由两个端点定义，这是新闻与宣传在句法层的唯一区别（**这一句可以带走，用到你能写的一切文书里。**
:::
:::

::: intuition 为什么所有会议新闻读起来一样 {#int-huiyi}
**一个结构解释，不是能力解释**（**这类稿件的作者通常是单位宣传人员，其考核来自“被报道的次数”，不来自“读者是否想知道”；**于是文体是激励的产物（**三条推论（**①**它的读者已被指定**（**上级、与会者与同系统人员；**这三类人需要的是自己被写到了，而不是新信息（②**通稿制度使同质性经济化**（**一份通稿供多家媒体使用，是最便宜的新闻生产；**本课不谴责它，只标注它的后果：**通稿承担事实，本地新闻承担重要性判断；当后者消失，读者只剩通稿，于是全城的头版相同（**这一句在纸媒时代成立，在算法分发时代被放大成另一件事（**第 9 章见（③**可教的自救**（**宣传岗的人也能写出新闻，只要他每篇找得到一条：一个变化的两个端点、一个受影响的人数、一个可查的文号；**三个里找到一个，稿件就从材料变成消息（**本章给这条岗位的唯一建议：**把“领导高度重视”换成“本次会议决定了一件什么以前不能做的事”；**后者更难写，但它会在明天早上被人引用（**被引用是一种文体奖励，比发稿量好得多。**
:::

::: history 从通讯社到标注 {#sec-tongxunshe}
**1840s—1860s**（**近代通讯社在欧美的电报线路上成型；按字计费与统一供稿格式塑造了简明的文风（**通说脉络：**本课强调因果方向不是“记者变懒”，而是“渠道按字收钱”（**上一章的“按什么单位卖决定文体”第一次在新闻业兑现（②**二十世纪初**（**“客观性”逐渐成为职业规范；相关研究常把它与大众化报纸的商业利益相联系：**不站队才能卖给所有读者（**通说脉络（**本课读成一项技术发明：**把判断从句子移到来源标注里，是新闻业对“我们无法裁定谁对”这一难题的工程解（③**1930s—1940s**（**战时宣传与广播使“消息”与“动员”的关系成为核心议题；战后各国出现职业准则与自律机构（**通说脉络（④**1980s**（**中国新闻业务改革，引入“信息”“读者需求”等概念；深度报道与调查报告式写作兴起（**通说脉络：**本章把它与上一章的“调查”传统并置：**两者都假定写作者应先获得可核材料再下判断（⑤**1990s—2010s**（**网站、门户与算法分发；标题从事实句变成悬念句；更正从报眼搬到页面底部（**通说脉络：**本课的一条量化观察：**当转载与推送成为主要流量来源，“第一段”就交给机器读，而“标题”交给情绪读——**倒金字塔的第一次结构变形（⑥**2010s—今**（**事实核查机构、平台标注、图片与视频的溯源技术，以及由模型生成的文本进入供稿链（**通说脉络（**本章结语：**本章的技术全部可以还原成一句话：让每一句都可被追问到一个人或一份文件；**机器写稿并不改变这句话，它只是让可追问变得更必要，因为无人可问的时候，格式成了唯一的证词。**

写六百至一千字，评“**客观性从来不是指记者没有立场，而是指一整套让人可以绕开记者立场的工序：交代来源、注明口径、保留原话、给出反方、公开更正。它的全部力量来自一个谦逊的设计——把判断的重心从“相信我”移到“你可以查”。也正因为它如此依赖工序，它最容易伪装：一篇格式齐全、每个来源都是同一利益方的稿子，可以在每一个技术上完全合规而整体上完全失真**”。须调用：**倒金字塔的双读者**、**五个格子的核查成本**、**三档来源**、**日期测试**、**细节承担论证**、**更正与转载溯源**至少六项；并裁决：**“来源多元”这一常见要求是否足以对抗上述伪装——你须给出一条比“多元”更强的规则，并说明它在实践中被抵制的原因**。

::: solution
判分点：六项机制（**双读者、格子、三档、日期、细节、溯源**）；更强的规则（**合格答案须指向“来源的独立性”而非数量——**候选表述：①**同一事实须能追到两个互不掌握的证据链**（**一份文件与一次现场观察，而不是两家都引同一份通稿**）；②**注明每一个来源的利害关系**（**谁因这一说法获益**）；③**至少一处与主要来源相冲突的材料不得省略**（**即“反方不可省”规则**）；抵制原因（**必须是利益而非“认识不足”：**独立性核查耗时、会得罪供稿方、并使单位失去通稿带来的版面；**在按发稿量考核的岗位上，来源多元是一项负产出（**这一点与上一章的指标条款同构**）；结论若能写“**所以客观性不是一种心态而是一种成本：谁愿意为一次交叉核对多付两小时，谁就拥有它；否则我们拥有的只是格式正确的失真，而它比直白的宣传更难反驳，因为它每一格都填对了**”，即 A。
