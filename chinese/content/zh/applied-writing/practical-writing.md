---
title: "应用文的性质"
---

这门课的第一个动作是把“写得好”三个字扔掉——**应用文的成功不在文本里：通知成功是指人来了，请示成功是指被批了，报告成功是指有人据此办事；它是唯一一种会因为格式错误而被退回的文字，这一点当场就暴露了它的身份：一次用语言完成的制度行为**。

## 定义：三要素与一条判准 {#def-sanyao}

::: definition 目的、读者、格式 {#def-yaosu}
**目的**（**决定内容：应用文没有“顺便说几句”的位置；**一份文本只有一个目的，两个目的就该拆成两份文件（**这正是“请示必须一文一事”的真实理由，第 4 章会把它讲透（②**读者**（**决定语体：写给上级、写给同级、写给当事人、写给公众，是四种语言；**读者错，全文错，而辞藻救不回来（③**格式**（**决定它能否进入流程：标题、主送、正文、署名、日期、字号、附件，缺一件就少一个环节的可追溯性（**本课的判准一句话：**一份不符合格式的文件，不是“写得不规范”，而是在收文登记里没有它——**用制度语言说，它尚未存在（**这是本课与文学写作全部区别的来源：**文学的入口是读者的眼睛，应用文的入口是一道安检（**第 1 门课“目录即审查”在办公桌上的小版本（**格式由谁定，什么算一份文件就由谁定（**见下文政治学一条。
:::

::: definition 四条品质，以及它们的汇率 {#def-sitiao}
**准确**（**数字要有口径、来源与日期，时间要到日，范围要到单位；**一个不写来源的数目字，是一句提前写好的道歉（**第 3 门课“没有分母的分子”在公文里的版本（②**清晰**（**一句一事；**公文的长句不是毛病，错置的限定语才是：**限定语是保险杠（第 4 门课论辩写作），但一个可以挂到两个位置上的限定语，是一笔待发生的支出（**典型事故是数量定语歧义：**“三家银行的贷款”——三家是银行还是贷款，两种读法对应两种金额（**第 5 门课现代语法讲过的结构歧义，在这里是一种财政风险（③**简要**（**删去不承载信息的名词短语：**凡“为进一步加强……”一类开头，删掉后若信息量为零，它就是纯粹的付款方负担（**本课的定律：**篇幅与责任常成反比——**长文件往往把责任稀释在段落里，短文件必须指名一个人（④**得体**（**语气词是一张权限表：上行用“恳请”“当否，请批示”；下行用“特此通知”“请遵照执行”；平行用“请予支持”“特此函达”（**用错语气不是不礼貌，是申报了一个错误的行政关系（**这一条在第 3、5 章会各自展开（**汇率说明：**四件事在同一个句子里彼此消耗——**求快则易失准，求全则易失简，求稳则易失清晰（**本课不承诺四全，只承诺：**每次写作前先定下你愿意在哪一条上让步，并且要留下记录。
:::

::: definition 模糊是一种授权 {#def-shouquan}
**通说脉络**（**公文里存在一批合法的模糊表达：“原则上”“视情”“酌情”“适时”“有条件的”**）；**本课按行文方向分类（**①**上行文的模糊是留余地**（**下级不肯为不可控的事立军令状，于是把承诺写成“力争”（**它的真实功能：把违约的判定标准往后推（②**下行文的模糊是转嫁裁量权**（**“结合实际贯彻执行”一句话，把标准制定的成本交给执行者；**上级得到的好处是普遍适用，代价是各地做法不一，且问责时各执一词（**这是“文件层层转发”现象的语言学基础（第 4 章（③**平行文的模糊是留退路**（**商洽函里“如蒙同意”“可否见复”把对方推到决策位，同时为自己保留“未获回复”这一说辞（**判准（**本课要求对每一个模糊语提一个问题：**谁在将来为这个词下定义？**如果答案是“届时再说”，那么这份文件没有做决定，只是把决定推迟并换了人做（**推迟本身有时是正确的行政决定，**但必须被写明为推迟（**这是本课对模糊语的全部道德要求：诚实的模糊优于伪装的精确（**“原则上同意”是授权；“原则上同意，具体范围由我处解释”是完整的授权；只写“同意”而不写范围，是日后争端的合同原件。
:::

::: definition 可预期性就是它的美 {#def-mei}
**通说脉络**（**应用文的语言高度套语化：承、悉、拟、兹、特此、为荷（**本课的三重辩护（**①**节约读者**（**“特此函达”四个字是一种格式提示：**它告诉忙的人这一段可以跳（**可预期性是制度性的利他（②**承担法律效果**（**某些套语已经被判例与惯例绑定到确定后果上（**换成“漂亮一点的说法”，效果就悬空（**第 3 门课“押韵就是公证”的行政版：**固定措辞是一种低成本的公证（③**防伪**（**套语写不像，说明作者不熟悉这个流程；**它的粗劣是有用的信号（**对照：文学以陌生化为资产（第 7 门课“风格”），应用文以熟悉化为资产；**两者的美德方向相反，而它们的判准相同：**都是让文本在自己的用途里省时间（**本课的一句话总结：**文学的美德是让人舍不得读完，应用文的美德是让人不必重读。**
:::

::: definition 无读者、无动词、无日期 {#def-sanbai}
**①无读者**（**通病是写给“领导”而不是写给一个要办事的具体科室；**结果是全文无一处指名（②**无动词**（**只有“加强”“推进”“提升”这类只描述方向、不描述动作的词（**审计方法：**圈出全部动词，逐个追问“谁做、做什么、对哪个对象做”；**答不出的那个动词就是这份文件的空洞处（**这一招与论辩写作课的“段首句面试”是同一技术（③**无日期**（**没有时限的目标不可考核；**没有期限的“尽快”是汉语里最好用的免责词（**本课给的最低审计（**任何一份应用文发出前，须能回答五问：**谁、在何时之前、做什么、依据什么、由谁检查（**五问缺一个，文件仍然可以发，但那一个将由别人来回答，且答案通常对你不利（**这就是应用文的全部伦理：**你不是在表达，你是在分配义务。**
:::

::: example 拆掉责任稀释装置 {#ex-xichai}
把下面这段改写成可执行的文字，并列出你删掉的每一项、说明它原本替谁免了什么责：
“为了进一步加强管理，提高认识，各单位要结合实际，认真落实，确保取得实效，力争年底前有明显改观。”

::: solution
**一版改写**——**“各处室：9 月 30 日前完成本处室在用设备清查，填写附表并由负责人签字，报后勤处；10 月 20 日前由后勤处汇总抽查，抽查比例不低于三分之一；对未按期报送的，在 11 月办公会上说明原因。**后勤处 8 月 25 日**”**（**对照原文可见九处替换（**①“为了进一步加强管理”**（**删；它是目的，不是内容，且未指明依据哪一份文件（**免掉的责：不必交代授权来源；**②“各单位”**（**改为“各处室”并附名单；**泛指使责任无人认领（③“结合实际”**（**删；**下行文的模糊即裁量权转嫁（上方②（④“认真落实”**（**改为可检查动作“清查、填写、签字、报送”（**“落实”是无动词的典型（⑤“确保取得实效”**（**改为“抽查比例不低于三分之一”；**没有检查比例的目标不是目标，是祝愿（⑥“力争”**（**删；**上行文的模糊留给上级，下行文用它就是不给自己设标准（上方①（⑦“年底前”**（**改为两个具体日期；**⑧未写主语与受文者**（**补主送机关与署名；**⑨未写依据**（**如确有上级文件，应注明标题与发文字号（**本课的判分（**九处中找出六处并写对“免了什么责”，即本章及格；**能额外指出“我删掉的每一项都让某个人更难过，这正是它有效的原因”，即 A——**应用文的文明程度，就体现在它让谁难过的方式上。**
:::
:::

::: intuition 你在为流程写，还是为那个人写 {#int-liucheng}
**一个真实的冲突**（**应用文有两类读者：一是流程（登记、拟办、督办、归档的各个环节，它们要求要件齐全、术语标准**）；二是当事人（一个来办事的人，他要的是“我该怎么办、带什么、几天”（**通说脉络**（**长期以来前一类读者独大，于是出现了那种“干部读得懂、群众读不懂”的告知文本；**近年公开文本的写作要求明确增加了“通俗易懂”一项（**本课的分析（**①**这不是水平问题，是激励问题**（**写作者的直接责任是对流程负责（格式错会被退回，语义晦涩不会；**只要没人因为读不懂而投诉，模糊就是免费的（**所以改好这一类文字，靠的不是培训修辞，而是让“被投诉读不懂”变得可归责（**这是一个制度设计作业，不是语文作业（②**两全的技术**（**同一份文本可以分两层：**正文满足流程（要件齐全、术语标准、引据明确），附一个“办事人须知”式的清单（**步骤、时限、材料、电话（**本课称此为“双轨制”：**它不降低规范性，只是把认知成本从最没有议价能力的一方转移回来一点（③**它适用于本课全部八章**（**求职信要同时面向人力资源的筛关键词系统与那位会读你句子的人；新闻要同时满足事实核查与三分钟阅读；**任何一份应用文都有两个读者，而写作者通常只记得付钱的那一个**。
:::

::: history 比文学更早被标准化 {#sec-biaozhun}
**战国—秦汉**（**出土的官文书显示：登记、抄写、日期、署名与邮传的程式早已成型；文书行政先于文学自觉（**通说脉络：**本课把这一点放在第一课，是为了永久打断一种偏见：**“实用文是低配的作文”——事实恰好相反，最早就被严格标准化的正是它（**第 1 门课“被考试的都是经典”在此有一条更早的注脚（②**六朝—唐**（**一部文论专章讨论书札奏记；唐代使职公文与判文体成为铨选的技术要求（**通说脉络：**会写公文是一种任职资格，而不是一种修养（③**宋—清**（**则例、程式与幕友的书仪；上下行的称谓与抬格被细密规定（**抬格是格式的极端形态：**版面上的空格与挪行直接表示等级（**它证明了格式从来不是装饰，而是一张可打印的权力图（④**1912／1920**（**民国废除若干清代文种；学校改用语体文的通令最终抵达公牍（**一次语言更替改变了全部公文语体，而发文字号与归档制度几乎未变：**制度层的惯性远大于语言层（⑤**1951／1981／2012**（**三次全国性的公文处理规定；现行条例确定十五种公文，一份国家标准把版式规定到页边距与字号（**通说脉络：**这是中国历史上第一次把公文版式写成可测量的参数（**本课的判词：**可测量意味着可跨机关检索，而可检索就是把行政记忆从纸堆里搬进索引（**第 8 门课“基础设施”的语言学版（⑥**近二十年**（**公开文本被要求“通俗易懂”，同时新媒体使每一份公告都直接面对当事人（**流程读者与当事人第一次坐在同一块屏幕上（**这就是上方直觉实验所说的冲突的成因，也是本课后面八章要逐个处理的作业。

::: exercise 小论文：文风即政风 {level=3}
写六百至一千字，评“**一份机关文风的质量，可以用一个可查的指标估出：把它发给一个从未接触该事务的人，看他能否照做。凡是必须打电话问才能用的文件，都在把写作成本转成执行者的时间成本，而这种转嫁不会出现在任何一张预算表上，所以它总是被低估。因此“改进文风”从来不是一场语言运动，而是一次成本重分配：它要求写的人多花二十分钟，好让一百个人每人少花二十分钟——这就是它极少真正发生的原因**”。须调用：**三要素**、**四品质的汇率**、**模糊是授权**、**可预期性作为美德**、**三种失败**、**双轨制**至少六项；并裁决：**“文件难懂应当被追责”这一主张在实施中最容易变成什么坏事（你须给出一种具体的失败形式，并设计一条防止它的程序**。

::: solution
判分点：六项机制（**要素、汇率、模糊、可预期、失败、双轨**）；失败形式（**合格答案须给出具体的机制而非“形式主义”这种总称——**候选：①以字数上限代替质量，导致把限定语删成歧义（**准确性被清晰性吃掉**）；②以“群众满意”评价代替要件完整，导致文件不再可检索、日后无法追责；③追责落到拟稿人，而拟稿人无权改格式与流程，结果是文风指标变成对最年轻者的处罚（**判卷看是否指出这一条：任何以文字质量为名的考核，都会沿权力梯度下滑（**防它的程序的合格答法：把指标定义为“可执行性测试”**（找一位不熟悉该事务的人在无人指导下照文件办事，记录他卡住的位置**）+ 同时保留要件完整性的硬约束**（两者写在同一张评审表里，任一不达标即退回**）+ 公开该测试的样本与判定理由**（**可审计性——第 7 门课“程序理性即可审计性”在此兑现**）；结论若能写“**所以应用文写作的道德很简单：凡是你写清楚就能替别人省下的时间，你写了含糊就是花别人的时间；这门课全部八章的技术，都只是为了让这笔账能被算出来”，即 A。

:::

::: summary
身份归档：性质（**用语言完成的制度行为**）、格式（**入口安检，不是装饰**）、品质（**四条互相消耗，让步要留记录**）、模糊（**一种授权，须写明由谁定义**）、套语（**熟悉化是资产，且能防伪**）、失败（**无读者、无动词、无日期**）。方法一句话：**发出前把五问念一遍，答不出的那一问会由别人替你回答**。下一章：书信与条据——私人之间的最小公文。

:::
