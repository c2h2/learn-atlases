前八章的读者坐在你面前或必须回函；本章的读者在一块六英寸的屏幕上、只给你三行、并且随时可能删掉你——**本章的论点是：新媒体没有发明任何新的写作毛病，它只是把每一种老毛病的报酬提高了十倍，同时把纠正的成本降到了几乎为零**。

## 定义：三条硬约束 {#def-santiao}

::: definition 三行、算法与即时反馈 {#def-yueshu}
**①长度被切成三段**（**标题、封面图、首屏可见的前几十个字；**这三件之外的一切，都是需要争取的（**上一章说倒金字塔的第一读者是排版编辑；**今天的第一读者是分发系统——**它读标题与首段，替一百万人决定要不要让他们看见（②**分发者不在场**（**你不认识你的编辑，他也没有名字；**他是一套按互动率排序的规则（**于是写作对象从“读者”变成“读者的下一步动作”（**本课的定义：**这是写作史上第一次，文本的主要评价者既不读它也不为它负责（**第 1 章“目录即审查”在此有一个自动化的后代：审查不再需要有人在夜里到场（③**反馈与文本同速**（**评论区是文本的一部分；**一段话被截图后在别处获得的含义，也是它的含义（**本章后面所谓“截图友好”一条会展开这一点（**三条约束合起来给出一句判据：**屏幕上的写作是一种在他人手上完成的写作——**所以它的职业道德不再是“写得清楚”，而是“在被人断章取义之后仍然站得住”。**
:::

::: definition 四种标题与一条交付判据 {#def-sizhong}
**信息题**（**给出可核的变化与两个端点（上一章的新闻判据**）；**悬念题**（**藏起一个关键项，制造缺口；③**利益题**（**“三句话让你省下××”：许诺一个可交付的收益；④**情绪题**（**给一种感受命名并招募同感者（**本课的判据只有一条，但它是硬性的：**标题制造的问题，正文是否在三段之内回答；**回答了，它是技巧；没回答，它是欺诈而非风格（**这一条可以量化：**看跳出位置——**多数平台给出的读者流失曲线，恰好可以在正文里定位到那一句没有兑现的话（**通说脉络：完读率、平均停留与跳出位置是内容平台的常规指标（**本课不美化也不唾弃这些数字，只指出它们的用法：**它们是唯一能告诉你“你在哪一句失去了陌生人”的记录（**上一章宣传稿的作者拿不到这种东西；本章的作者拿得到，却不肯看——**这是本章对新媒体写作最刻薄也最善意的一句评价。
:::

::: definition 可截图的句子 {#def-jietu}
**一种新的修辞单位**（**过去的设计单位是篇章，后来是段落，如今是一句能被单独截图的话；**它的条件是：短、有立场、脱离上下文仍然完整（**三条后果（**①**引用单元取代了论点结构**（**一篇文章真正的资产是它那三句可能被转发的话；**于是写作开始为句子而非为论证优化（**而论证是慢的、有条件的、充满“但是”；**可截图的句子恰恰相反，它必须无条件（**这就是本章所谓的“断章的经济学”：**你写的时候就知道会被断章，于是你提前把自己断成可断的样子（**通说脉络：这类现象常被概括为“碎片化”，本课拒绝这个诊断：**它不是注意力变短，是传播单位变小；而传播单位一直由渠道决定，从竹简的字数到报纸的栏宽（**第 1 章与第 14 章的“分发格式改变内容”在此完全复现（②**脱离上下文之后仍然完整，是一句危险的设计要求**（**它意味着你写的每一句都要经得起两种读法：你给的读法与别人给的读法（**本课的技术答案：**把限定语写进被截图的那一句里；**不要写“这种做法必须反对”，要写“在××情形下、未经××程序的做法，我反对”——**后者短了五个字，却使截图无法被当作另一句话使用（**这是上一章“限定是保险杠”那条在屏幕时代的唯一有效形态（③**观点的负债表**（**一句被大量转发的话，会在你之后的每一次发言时被拿出来对账（**所以本章的职业建议只有一条：**不要写一句你不打算为一百年负责的话；**这一句听起来夸张，它的机制很平实：**屏幕不会腐烂，而纸质时代的大部分谎言是被纸张的腐烂赦免的（**第 8 章“档案运气”在此翻面：**今天的问题是档案运气太好。
:::

::: definition 更正、删除与广告标注 {#def-gengzheng}
**①更正要引原句**（**通说脉络：内容与广告相关的现行规章要求付费推广应显著标明为广告；新闻与出版方面的行业规范则要求更正及时、位置相当（**本课的解释：**标注广告不是为了读者好心地替你过滤，而是为了让你的两种话彼此不冒充：**一旦商业推荐与个人判断混用而不标注，你损失的不是某一次的信任，而是所有未被标注的那些句子的可信度（②**静默删帖是最坏的一种更正**（**它改变历史而不记录改变（上一章已说，此处补一条机制：**屏幕上的删除并不使文本消失，只使它失去作者的版本控制——**被删的截图会继续流通，而它的含义从此再没有人能修正（**所以本章唯一可接受的做法是：保留原文、显著更正、并说明改了什么；**若必须下线，也留一条“本文已于某日撤下，原因如下”（**这是上一章“更正一封、留一份新版本”在平台上的最低实现（③**转载三件**（**授权、注明出处、不改标题（**通说脉络：有关信息网络传播权的规定与行业惯例围绕这三点展开（**本课的机制解释：**改标题转载是一种把收益留给转载方、把责任留给原作者的交易；**因此判断一家平台是否可靠，只看一件事——**它有没有替你承担过你写错的东西（**这句话同时适用于平台、机构与你自己发的第一条内容。**
:::

::: definition 订阅号与服务号：开环与闭环 {#def-dingyue}
**通说脉络**（**账号式平台区分了两类：一类按周期向订阅者推送内容，一类用于办理事务并可触达既有用户（**本课立刻认出这是第四章那张表（**①推送型是开环文书**（**它只要求被接收，不要求回执；**因此它天然滑向“发过就算完成”，而它的考核指标也自然是发文次数（**这是上一章“开环文体是免费发言”的平台版本，也是为什么推送型内容总比回执型内容空洞（②**办理型是闭环文书**（**它要求一个动作：确认、缴费、预约、答复；**于是它有期限、有默认值、有回执（**本课的判读：**同一套技术上，两类文体的寿命不同——**开环的部分被算法迅速耗尽，闭环的部分成为基础设施（**这解释了一个常见现象：一个账号最有长期价值的功能，常常是它菜单里那三项办事入口（③**群发不是私信**（**把公告发进一对一的对话，是一种权限错乱（第 2 章“抄送是施事行为”的移动端复现（**本课的建议：**每一次群发之前，先问它是通知、请求还是宣传——**三种目的对应三种标题、三种结尾与三种是否要求回执的设置。**
:::

::: example 审计一条爆款 {#ex-baokuan}
标题：“我劝你千万别去××上班，除非你符合这三点”；正文前五十个字：“昨天收到一条留言，看完我沉默了……”请做三项审计：**①标题制造了什么问题，正文是否在三段内回答；②哪一句最可能被截图，截图后意思如何变形；③给出一个不损失传播力的合规改法**。

::: solution
**①交付检查**——**标题设了三个缺口：别去的理由、三点的定义、以及“除非”构成的条件；**“除非”使标题成为一个可被任何内容兑现的形式（**因为只要列出三条，任何理由都算回答**）——**这是标题党最稳的护甲：它许诺的是数量而不是内容（**若正文在前六段仍在“沉默了”的情绪里打转，则本章判据立即成立：**它是欺诈而非风格（②最可能被截图的一句**——**“我劝你千万别去××上班”；**截图后失去“除非”这个条件从句，句子从一条附条件的建议变成一条禁令，并可能被当作对具体某单位的指控（**这就是“断章的经济学”：**不是别人歪曲了你，是你在设计时就把限定语放在了不会被截图的位置（**改法：把条件写进被截图的那一句——**“三类人我不建议去××：需要稳定排班的人、抗拒重复劳动的人、以及把这份工作当过渡的人；其余人我认识不少做得很好的**）”（**它同样短，同样有立场，但它在被孤立传播时仍然诚实（③三点实务修改**——**其一，标题改为可核问题（**“××岗位的三个真实门槛：排班、重复劳动与晋升周期”**）；其二，前五十个字给出两个端点与一个来源（**“访谈了 11 名在职与离职员工，其中 4 人任职超过三年”**）；其三，若文内有商业合作，在首次出现处标注（**通说脉络：现行规章要求付费推广显著标明“广告”**）（**判分：**能指出“除非”这一形式使标题不可证伪者，即本章 A**——**这是第 3 门课的可驳倒性判据，被用在一行标题上；**而它同时也是本章对全部新媒体写作者的祝福：**可被反驳的句子才不会被误解。
:::
:::

::: intuition 一种没有档案的写作 {#def-dang}
**一个观察**（**新媒体上几乎没有人“修订”：文本要么原样留着，要么被删掉；**平台通常保留一个极短的编辑窗口与一条“已被修订”的提示（**三条后果（**①**没有版本就没有历史**（**你无法说明自己何时改变了看法；**于是作者的声音看起来永远一致，而一致不是诚实，是没有档案（**第 6 章说“单方面改写历史一定会被要求出示版本”，这里连版本都不存在（②**它使剽窃与自我剽窃都难以证明**（**发布时间的可信度取决于平台记录；**这就是为什么“截图为证”在屏幕上既是主要证据也是最弱证据（③**它把责任从作者转移到渠道**（**删掉即不存在；而“不存在”使任何讨论都失去对象（**本课的结论：**在一个不保存版本的环境里，作者要自己承担档案职能：**把发布时的原文存档、把更正写成一条新内容并链接旧内容、把自己最重要的句子连日期一起记下来（**这不是洁癖，是本课程十门课反复给的那件事：**你无法控制别人如何引用你，你只能控制你有没有一份可出示的底本——**而在新媒体上，那份底本必须你自己抄一份，因为没有任何人有义务替你留。
:::

::: history 五次改行 {#sec-gaixin}
**1990s**（**网站与论坛：写作第一次有了即时评论区；编辑与作者的关系被推迟为“版主”这种新职务（**通说脉络（②**2005 前后**（**博客使长文与个人专栏回到中心，同时带来第一个问题：谁来核查（**通说脉络（③**2009—2012**（**微博把长度限制写进文体（**这是自竹简之后第二次“物理参数决定句长”（**通说脉络：随后账号式推送平台上线，把订阅与办理分成两类接口（**上一章的“按什么单位卖”在此变成“按什么接口分发”（④**2016 前后**（**短视频与直播：文字退化为脚本与字幕；**口播稿、字幕条与画面说明成为三种互相翻译的文体（**通说脉络（⑤**2020s**（**算法推荐主导分发、广告分成使“停留时长”成为计价单位（**本课的关键转折：**你不再为读者写作，你为时长写作；**而时长是一个既不奖励真也不奖励善的指标（**第 3 章“指标一旦成为目标”在内容业的应用（⑥**现在**（**生成式工具进入供稿链：写作、配图、摘要、评论回复都可自动化（**通说脉络：**本课给全课的最后一项制度判断：**当生产与消费的边际成本都趋于零，稀缺的东西换了一类——**可核实的经历、可打开的作品、可追问的人，以及一个肯留下版本的作者（**这不是一句安慰，它是本课程的结论：从荷马的歌手到屏幕前的你，文学与技术换了很多，稀缺的东西一直是这两样：**说得清，且可出示。**
:::

::: exercise 小论文：可出示性 {level=3}
写六百至一千字，评“**屏幕把写作的两种成本改变了方向：犯错的成本下降，因为文本随时可以删；被误解的成本上升，因为文本随时会被截取。任何只奖励发布速度而不要求可出示性的平台，都会把写作者推向同一处：写出此刻好用、日后无法认领的句子。因此新媒体写作的职业道德不能建立在‘良心’上，只能建立在一种可出示的工序上：存档、版本、来源与更正——它们不让人变得更好，只让坏话更难写**”。须调用：**三条硬约束**、**交付判据**、**可截图的句子**、**删帖与更正**、**转载三件**、**开环与闭环**至少六项；并裁决：**“让坏话更难写”的工序在个人层面是否可能实现（一个人的存档能有多大效力——你须给出一个平台层面的设计，并说明它与“言论自由”之间的真实张力在哪一处**。

::: solution
判分点：六项机制（**约束、交付、截图、删帖、转载、开闭环**）；平台设计（**合格答案须是一种可审计的默认设置：**例如默认保留可查的历史版本并向读者公开“本文已被修订”的入口、转载必须携带来源标识与原标题、更正与原文同位显示、以及为作者提供一键导出自己全部历史文本的存档工具（**判卷看是否包含“作者可导出”这一条——**它是个人层面唯一有效的工序，因为它把存档成本从个人转回平台**）；张力（**必须写明它不是“自由 vs 监管”的抽象冲突，而是一处具体风险：**版本历史与导出功能会让临时性的错误永久化，从而抑制试错与坦率修改——**一个知道自己每句话都可被出示的人，可能写得更保守（**这正是可核性制度的固有代价，本章从不假装它没有**）；可用的缓解办法：**限定历史的可见范围与保留期、允许作者主动署名地更正而不被永久检索、以及在指标里区分“更正次数”与“错误次数”（**把改正计为绩效而不是污点**）；结论若能写“**所以本章最后交给读者的不是技巧而是一种习惯：把可出示当作默认设置，把不可出示的句子删在自己手里——一门课如果只能留下一句话，那就是：不要写一句你将来不敢承认的话，因为屏幕比你更记得你说过什么”，即 A。

::: summary
屏幕归档：约束（**第一读者是分发系统**）、标题（**三段之内必须交付**）、截图（**把限定语写进会被孤立传播的那一句**）、删帖（**改变历史而不记录改变**）、转载（**授权、出处、原标题**）、开闭环（**办事的入口比推送更长寿**）、存档（**没有版本就没有历史**）。全课一句话：**应用文的道德，是让被它约束的人能够读懂、能够追问、并且知道自己被谁约束——从一张借条到一条推送，这句话同样成立。**
