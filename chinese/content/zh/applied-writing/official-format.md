title: "公文的种类与格式"
---

上一章个人用一张纸为最坏的一天作保；本章国家用一张纸为一切作保——**现行规定把党政机关的公文定为十五种，另一份国家标准把它的版面规定到毫米与行数；这不是繁琐，这是人类最早、也最彻底的一次“把文体写进物理参数”的工程**。

## 定义：效力与体式 {#def-xiaoli}

::: definition 定义里的两个词 {#def-liangci}
**通说脉络**（**现行条例把公文描述为党政机关实施领导、履行职能、处理公务的、具有特定效力和规范体式的文书（**两个关键词（**①特定效力**（**一份公文一旦发出，就改变某些人的义务、权限或资源；**它不是陈述，是处分（**所以上一章那条“你在分配义务”在这里被写到极致：一个字改动预算，一句话开放或关闭一项资格（②规范体式**（**体式不是美观要求，而是可识别性要求：**收件人要能在两秒内判断这是谁、在做什么、要不要办（**本课的定义：**文种是权限的代码，格式是文件的身份证（**由此得到全章的判断标准：**凡讨论公文，先问它做的是哪一种行政行为，再问它穿的是哪一件衣服；**两者错配，就是本章全部错误的根源（**用错文种不是文笔问题，是申报了一个自己不拥有的位置。**
:::

::: definition 十五种与一张矩阵 {#def-juzhen}
**通说脉络**（**现行十五种为：决议、决定、命令（令）、公报、公告、通告、意见、通知、通报、报告、请示、批复、议案、函、纪要；此前行政机关的规定为十三种，现行规定并入党的机关文种并增列两种、改称一种（**本课不背名目，先建一张三栏矩阵（**①行文方向**（**上行（请示、报告、议案**部分情形**）、下行（命令、决定、通知、通报、批复、公告、通告、意见**多为下行**）、平行（函，以及不相隶属机关之间的意见、通知**）、内部或会议纪要类（纪要**）；②**受文者是否特定**（**公告、通告面向不特定对象；请示、报告、函面向特定机关（**这一栏直接决定你该用哪一个：向社会说事不能用“请示”，向一个机关要批复不能用“通告”（③**是否要求答复**（**请示必须批复（闭环**）；报告只要求阅知（开环**）；函商洽须复函（闭环**）；通知、通报一般不要求答复（开环**）（**本课的用法：**这三栏一旦填好，文种几乎自动确定；**选错文种的常见形态是把开环写成闭环（在报告里夹带请示**）或把闭环写成开环（用函提出一项本应请示的要求**）（**第 4 章专门处理这两种事故。**
:::

::: definition 版头、主体与版记 {#def-sanqu}
**通说脉络**（**现行格式标准把版面分为版头、主体、版记三部分：版头含份号、密级和保密期限、紧急程度、发文机关标志、发文字号、签发人等；主体含标题、主送机关、正文、附件说明、发文机关署名、成文日期、印章、附注、附件；版记含抄送机关、印发机关与印发日期，另有页码（**本课的读法：**这三段不是排版分区，是一次行政行为的三个时间层（**①**版头＝前件**（**谁在行使权力、以什么编号、对什么密级、有多急、由谁签发：**它回答“这份文件的资格从哪来”（**所以一条规则极硬：**上行文应当标注签发人姓名；**因为上级的决定需要一个可被追问的自然人（**授权在版头里露出它的脸（②**主体＝行为本身**（**标题、受文、正文、附件：这一层做那件事（③**版记＝后件**（**抄送给谁、由谁印发、何时印出：**它回答“这份文件到达了哪里”——**送达是效力的一部分（**本课的总结：**公文把授权、决定与送达打印在同一张纸上；**这就是它与文学文本最深的差别：文学作品不需要证明自己是作品（**第 1 门课“文学来盖章”在此得到一个精确的反例：公文需要一整套章，而且章是有位置的。**
:::

::: definition 发文字号、成文日期与印章 {#def-yaojian}
**发文字号**（**通说脉络：由发文机关代字、年份与顺序号组成，年份用六角括号括入，不写“第”字（**本课的定义：**它是文件的唯一标识符：**没有它，一份文件在归档后无法被检索，在争议中无法被援引（**一个没有字号的“文件”，在行政流程里近似于一张通知照片（②**成文日期**（**通说脉络：以负责人签发或会议通过的日期为准，联合行文以最后签发者为准；用阿拉伯数字将年月日标全（**为什么严重要到“标全年份”：**因为一切期限都从它起算：**一份未写全年份的文件，是把计算责任丢给收件人（**上一章那条“无日期”的病，在这里是一种失效风险（③**印章与署名**（**通说脉络：除特定情形外公文应加盖发文机关印章（**本课的分析：**印章不是签名的美术版，它是一种“不可由个人单独复制”的凭证设计：**它把行为主体从自然人换成机构，从而使文件在经手人调离后仍然有效（**这是行政记忆的技术基础：**机构能承诺，因为它比人活得久；印章就是这一事实的物质形式（**第 2 章“介绍信把信任装进纸里”在此得到它的机制版本。**
:::

::: definition 二十二行、二十八字 {#def-hangshu}
**通说脉络**（**现行格式标准规定公文用纸为 A4 型，并给出页边与版心尺寸；行数字数亦作规定，通行的排印要求是每面约二十二行、每行约二十八字（**三个后果（**①信息量被物化了**（**同一份正文在不同机关印出来占同样的页数；**于是“篇幅”成为可比较的量：**一个机关一年发了多少页，是一个可统计的行政成本（**这是把文体写进毫米之后才可能出现的统计（②**格式成为预算科目**（**印制、装订、归档、运送，都以页为单位；**规定版面实际是在规定一次行政沟通的带宽与单价（**本课的公式：**凡不可测量的东西，不会被削减；“精简文件”之所以能成为一种治理要求，前提是页数变得可比（**通说脉络：近年多次以专门文件要求控制发文数量与篇幅、为基层减负（③**它制造了一种新型错误**（**版式不合规的文件，可能在收文、归档或检查时被退回；**于是基层出现一种真实的工时支出：不是写，而是把已写好的东西重新排成合规的样子（**本章不为此辩护，也不轻蔑它：**格式是免责装置，也是一种税；本章唯一的主张是——**税应当落在纸面上，不应当落在办事的人身上。**
:::

::: example 一份要件核对表 {#ex-yaokan}
某局向市政府报送一份请示，封面写着“×局文件 ×局〔2024〕37 号”，标题为“关于申请增加编制的报告”，主送“市政府、并抄送局属各处室”，正文末写“可否，请批示”，成文日期为“×局 10 月 20 日”。请列出一份要件核对表：**指出至少六处问题及其后果**。

::: solution
**①文种错配**——**标题写“报告”而结尾要求“批示”：报告不得夹带请示事项（通说脉络），**而请示必须一文一事并要求批复（**后果：收文部门无法按办文流程交办，可能仅作阅知处理，事项原地不动（**②标题要素不全或不一致**——**通说要求标题由发文机关、事由与文种组成，且文种须与正文一致（**“关于申请增加编制的报告”把行为写反了：**申请的文书是请示，报告是汇报（**③抄送下级**——**请示不得抄送下级机关（通说脉络）；**抄送局属各处室等于把一项未获批准的要求宣布为既成事实（**后果：一是程序违规，二是一旦被驳回，本机关难以向下解释（**④成文日期不完整**——**未标全年份，且缺签发人（**上行文应标注签发人姓名；**后果：期限起算不确定，且在争议中找不到责任人（**⑤主送机关写法**——**“市政府、并抄送”把主送与抄送写在同一栏（**通说要求两者分别标注：主送在正文之前，抄送在版记（**后果：办理责任分散（**⑥发文字号体例**——**年份符号与序号写法须符合标准（六角括号、不写“第”字**）（**另需补：**联系人及电话（附注**）、附件说明（如附编制依据文件**）、印发信息与页码（**本课的判分标准：**六处之中，凡能把“后果”写成一句行政语言者**（**如“会被作阅件处理”“无法归档”“驳回后难以向下解释”**）得满分；**写成“不规范”者不得分——**“不规范”不是一个可据以行动的说法。**
:::
:::

::: intuition 为什么所有公文都长成一张脸 {#def-yizhang}
**一个类比**（**纸币、护照、邮票与公文共用同一套设计逻辑：**把信任印进物理细节，因为物理细节最难伪造（**通说脉络：伪造、变造、买卖国家机关的公文、证件、印章，是各国刑法普遍处罚的行为（**三条推论（**①版式是一种资产**（**正因为一张红头纸能让人办事，它才值得被仿造；**所以“公文能被用来诈骗”不是格式的失败，恰恰是格式成功的证明（②**统一版式降低的是核验成本**（**收件人不必读懂内容，先看版头就能判断要不要进入流程；**这是一种为注意力设计的防伪（**与上一章“可预期性是制度性利他”同源（③**它也有一个黑暗面**（**当版式承载信任，掌握版式的人就能越过内容行权；**于是现实中出现两类事故：一是内部人滥用红头，二是外部人仿造；**对应的两道防线都不是靠写字，而是靠可核验：**编号可查、渠道可回拨、以及一份文件在收文登记中必须留痕（**本课的最后一条：**不要把版式当形式，也不要迷信版式；**版式是一种为陌生人间的高效信任而做的技术，它既保护你也可能被冒充者利用——**唯一的补救是让它可核对。**
:::

::: history 版式即主权 {#sec-banshi}
**战国—秦汉**（**简牍文书已有固定的署名、日期、抄写与邮传程式；出土材料显示其严密程度超过同期任何文学写作（**通说脉络（②**唐—宋**（**皇帝文书与官文书的分类细密，避讳、抬格与用印构成一套视觉制度（**通说脉络：**抬格在版面上表示等级，本章上一章已述；此处补一句：**统一版式在帝制中国始终与“书同文”并列，因为它解决的是同一个问题：**如何让一份文件在千里之外仍然被当作同一份文件（③**明—清**（**题本、奏本区分事项与礼仪，票拟与批红把处理流程固化（**通说脉络：**这是中国历史上最接近“工作流引擎”的时代：**文书的形状决定了它需要经过哪些手（④**1912／1951／1981**（**民国废除若干清代文种；新中国成立后多次统一公文处理办法（**通说脉络：**每次政权更替的第一批技术文件里都有公文程式——**新政府先规定怎么写，再规定写什么（⑤**2000／2012**（**行政机关规定十三种；现行条例整合党政机关并定为十五种，同年格式标准更新（**通说脉络（**本课把它读成一次“接口统一”：**两个系统合并后，跨系统的检索与归档才成为可能（**这是二十世纪末企业 IT 的那件事，早了它几十年，只是打在纸上（⑥**2000s—今**（**电子公文交换、电子印章与电子档案管理规则陆续建立；同时“精简文件、控制篇幅”成为减负要求（**通说脉络（**本章结语：**当公文从纸变成一条数据，版式的物理约束消失了，但它的三件事必须保留：**唯一标识、可核验的签发、以及送达留痕——**电子文件的标准全部是为这三件事写的，不是为好看写的。**
:::

::: exercise 小论文：格式是一种技术 {level=3}
写六百至一千字，评“**公文格式是人类最早的一门“界面工程”：它假定收文的人不会读完，于是把最重要的三件事——谁在说话、说的是什么行为、这句话送到了哪里——安排在固定的位置，并用印章与编号让它们无法被事后否认。这门工程与法律同源：两者都假定人会遗忘、会抵赖、会有人冒充；两者的失败方式也相同：当遵守形式比实现内容更受奖励，形式就开始吃掉它原本要保护的东西**”。须调用：**效力与体式**、**三栏矩阵**、**三段作为时间层**、**唯一标识与成文日期**、**行数与预算**、**版式作为防伪资产**至少六项；并裁决：**“遵守形式比实现内容更受奖励”这一退化在制度上如何防止（你须给出一条不依赖个人觉悟、且可被审计的机制，并说明它的成本由谁付**。

::: solution
判分点：六项机制（**效力、矩阵、三段、标识、行数、防伪**）；机制（**合格答案须同时包含“降低形式的边际收益”与“提高内容的可核性”两端——**候选：①**要件清单化而非版式表演**：把审查集中在“有无字号、有无签发人、有无期限、有无联系人”四项可二元判定的要件上，取消对套语与篇幅的加分（**这样合规不再等于长**）；②**公开文件目录与办理结果**：让外部可核对“发了什么、办了没有”，把评价对象从文本改为后果（**这是可审计性的正面用法**）；③**退回率与办理时限统计公开**，把“文件发出去”与“事情办成了”分成两个指标（**判卷看是否给出两个指标而不是一个**）；成本（**必须写明：公开目录与统计需要档案与信息系统投入，费用在机关与纳税人；而退回到“只看内容不看形式”则会使冒充成本骤降——**因此防退化的办法不是取消形式，而是把形式收缩到不可让的那几项（**能写出“形式必须保留但必须最小化”这一句，即为 A**）；结论若能写“**所以公文格式给全部写作的教训是：形式是为不可信的世界准备的保险；保险买少了会赔，买太多会穷，而唯一靠得住的判据是——这一条形式是否真的能在有人抵赖时救你**”，即 A。
