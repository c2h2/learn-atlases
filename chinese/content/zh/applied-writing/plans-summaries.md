title: "计划、总结与调查报告"
---

前几章处理此刻发生的事；本章处理三种时间——**计划是对未来的可核验承诺，总结是对过去的审计，调查报告是对现场的取证；它们共用一条纪律：凡是不能被检查的说法，都不写进去**。

## 定义：计划 {#def-jihua}

::: definition 六要素与验收方式 {#def-liuyao}
**通说脉络**（**计划类文书一般写明目标、任务、措施、步骤、时限与责任分工（**本课补上常被省略的第六件（**①目标**（**必须可测；**通说脉络：管理学通行的五个形容词（具体、可测、可达成、相关、有时限）里，真正能救一份计划的只有一条——可测（②**任务与措施**（**任务说做到什么，措施说靠什么做到；**只有任务没有措施的，是一份愿望清单（③**步骤与时限**（**分阶段到日；**“力争”“确保”“大幅”这类词不得出现在时限栏（上一章的数字纪律（④**责任分工**（**一件事一个单位；**分给两个单位的事，等于没分（⑤**检查方式**（**谁来验收、依据什么材料、不达标怎样（**本课的公式：**没有验收方式的计划不是计划，是表态；**表态的正确文种是讲话稿，不是红头文件（⑥**层级**（**通说脉络：实务中常按时限与粗细区分“规划、计划、安排”三个词（**而真正的写法是分层：**三年写方向、年度写目标、季度写可交付、本周写动作；**把三层塞进一份文件，结果通常是三样都没有（**一份计划的精度只能延伸到它下一步能被检查的那个日期，这是本章的第一条物理定律。**
:::

::: definition 指标一旦成为目标 {#def-mubiao}
**通说脉络**（**一句常被引用的管理学格言大意为：当一个度量成为目标，它就不再是好度量（**三条机制（**①**自选指标的必然结果**（**如果考核允许被考核方选择口径，理性的做法是先降低基数再超额完成；**于是出现一种文体症状：计划里的目标总比上一年实际值高一个不痛不痒的比例（②**替换**（**难以完成的目标被替换为易完成的近似物：**“提高质量”变成“发表论文数”，“改善体验”变成“办结率”（**这不是舞弊，是指标的迁移；**每一次迁移都会在文书里留下痕迹：目标栏的措辞从结果词变成动作词（**这是读计划时最值得注意的一处变化（③**分布被平均掉**（**一个总量达标的计划可以掩盖半数单位未达标；**因此凡计划里有总量目标，就必须同时要求给出分布或最差的三个单位（**本章后面三次用到这条（**本课的对策只有一条技术性的：**要求每份计划在目标旁边写明“这个数字如何被核查、由谁核查、以及未达标时会发生什么”；**一条不写即退回——**它比任何“改进文风”的号召都便宜。**
:::

::: definition 经验栏是唯一的资产 {#def-jingyan}
**通说脉络**（**总结通常包含基本情况、主要成绩、存在问题、经验与今后打算（**逐栏判读（**①基本情况**（**只写与结论相关的量，含基数；②**成绩**（**必须带口径、时点与来源；**“大幅增长”不是成绩，是一个形容词（③**存在问题**（**上一章给了诚实度的粗糙指标：问题栏字数占比；**此处补一条更硬的：问题中至少有一条必须是本机关自己的责任（**把问题全部归因于上级支持不够、下级认识不一与客观条件，是一份总结最省力的写法，也是它最没有信息量的写法（④**经验**（**通说称“经验体会”；**本课的定义：经验是把一次做法抽象成一条可复用的规则（**它是总结里唯一对未来有用的部分，其余都只是负债的清点（**一条合格的经验必须能脱离原场景被检验：**“推行清单化是因为清单比会议便宜”可检验；“领导重视是关键”不可检验（⑤**今后打算**（**它就是下一份计划的种子；**凡此处出现闭环请求，另文请示（上一章（**本课的读法（**把某单位连续五年的计划与其上一年总结的问题栏对齐，若两者高度重复，说明这个组织在做同一件事的续集而不是在做新事（**这一句可在本章直觉实验处展开。**
:::

::: definition 三种失真 {#def-shizhen}
**①比例代替绝对量**（**“增长 50%”可能从 2 到 3；**凡百分比，必须同时给基数与口径（第 3 门课“没有分母的分子”（②**平均数掩盖分布**（**“人均”“平均办理时长”最容易被极值拉动；**凡平均数，必须同时给中位数或最差三个单位（③**以点代面**（**用最好的一个典型得出全域结论（**这是幸存者偏差的公文形态（**本课给的判据很简单：**看它如何选择样本；**“随机抽取”“按类别分层”“经基层推荐”三种说法对应三种结论强度，而第三种常常只能证明“被推荐的那几个很好”（**通说脉络：抽样与典型调查是两种不同的方法，各有适用条件（**混用它们，是本领域最常见的技术性错误，也是最难被发现的那一种——**因为它在语法上完全通顺。**
:::

::: definition 三栏、口径与强度阶梯 {#def-sanlan}
**三栏必须分开**（**事实、推断、建议各设小标题；**混写的后果是让一条建议读起来像一个事实（**这是本章对全部三种文书的共同要求，在调查报告里最致命（②**口径三件**（**统计口径（什么算一笔）、时点（截至哪一日）、样本框（从哪个名单里抽）**——**缺任一项，数字就不可比（**而不可比的数字比没有数字更坏，因为它会被当作依据重复引用（**这就是调查报告最重要的下游效应（③**结论强度阶梯**（**本课排五等：可复核凭证与直接观察＞多人独立陈述一致＞单一知情人陈述＞当事人的一致说法＞“大家普遍认为”（**最后一等在任何文书里都不应出现，因为它把责任转给一个不存在的集体（**第 3 门课证据强度在此有一个新增等级：**“座谈会上的意见”属于第四等，它只能证明材料里缺少第五等（④**建议的三件**（**执行主体、所需资源、不执行的后果；**三者缺一，它是一条抱怨而非建议（**通说脉络**（**近年统计数据质量方面的法规与问责要求多次强化，统计口径与数据来源的规范性被反复强调（**本课的中性结论：**当被调查者就是打分者时，报告的诚实度不取决于作者勇气，而取决于有没有第二条上报渠道（**这是调查报告的伦理边界：**文书学能规定口径，不能规定谁敢按口径写。**
:::

::: example 审计三个数字 {#ex-shuzi}
一份总结里有三句话：“①全年办理事项同比增长 46%；②群众满意度 98.5%；③政策覆盖率达到 100%。”请为每句补出它省略的东西，并判定哪些结论会被推翻。

::: solution
**①增长 46%**——**须补：上一年基数是多少、口径是否变更（**若本年把此前未纳入的事项并进来，增长率就是口径变化的产物**）、以及绝对量（**从 29 件到 42 件也是 46%**）。**若基数很小，则“工作显著加强”这一结论被推翻；**若口径变更，则连“增长”二字都不成立（②**满意度 98.5%**——**须补：样本框（谁被抽到**）、回收方式（**电话回访还是窗口扫码：后者由刚办完事的人自评，且未完成者不在样本内**）、以及“满意”的定义（**是“无投诉”还是“愿意再来”**）。**典型推翻：回收率不足三成且以窗口现场填写为主时，该数值只能读作“在场且愿意填的人中 98.5% 表示满意”**）（③**覆盖率 100%**——**须补：分母的名单从哪里来（**在册人口、常住、还是已申请人数**）；以及未覆盖者是否可能被漏计（**一个无固定住所的人可能同时不被任何一份名单包含，却在统计上被覆盖**）。**这一项最常被推翻：因为分母通常由被考核者自己编制（**判分：**三处都必须落到“口径、时点、样本框”三个词上**；**任何一处只写“数据不翔实”即为不及格——**“不翔实”不是可据以行动的判语，与上一章的“不规范”同属一类空转的词。**
:::
:::

::: intuition 计划为什么是总结的续集 {#def-xuji}
**一个可观察的时间巧合**（**总结在十二月写，计划在元月写；**它们的作者常常是同一个人，用同一台电脑里同一份去年文件（**三条推论（**①**于是计划天然长成“上一年问题的改写版”**（**通说现象：每年计划与上一年问题栏的相似度，高于它与今年真实需要的相似度（**这不能怪写作者：**要写出一份真正新的计划，需要重新做一遍调查，而调查没有预算（②**因此读计划的最佳方式，是把它与上一年的总结并排读**（**看哪几条问题被搬成目标、哪几条被搬成措辞略异的同一句话（**被搬成措辞的那些，就是这个组织真正的既有格局（**本课称此为“两栏并读法”，它与第 3 门课的“并表法”是同一技术（③**对写作者的实用建议**（**若你必须在续集的位置上写一份新计划，最省事的诚实做法是加一栏“本年度不再做的事”（**放弃是一种可记录的决定；**而绝大多数计划文体里没有这一栏，于是所有失败都以“继续推进”的方式永生（**本章的最后一击：**一个组织会不会真的改变方向，看它的文书模板里有没有“不再做”那一栏——**这比任何战略口号都可靠。**
:::

::: history 从“没有调查没有发言权”到口径 {#sec-diaocha}
**1930**（**一句口号把实地调查变成认识论要求，大意为“没有调查，没有发言权”（**通说脉络：**本课的两层读数：**其一，它把写报告的义务前置于下结论的权利；其二，它同时使调查报告成为入场券——**于是“谁定义口径”这个问题，第一次变成政治问题（②**1936／1961**（**一部以中国乡村为对象的经济人类学著作在国际学界获得声誉；同期另有以“解剖麻雀”为方法的典型调查被倡导（**通说脉络：**这两条传统并行至今：**一条要求方法与同行可复核，一条要求典型与可讲；**调查报告的写作困难，多半来自这两条传统在同一段文字里相遇（**这一句是本章给全部方法论争论的简化说明（③**1953 起**（**第一个长期计划开始，各单位形成“规划—计划—总结”的周期文体；统计体系同步建立（**通说脉络：**本课指出一个文体后果：**计划类文书在中国的组织生活中被赋予极高的地位，因为它同时是技术文件与承诺文件（**它比文学更早规定了一个单位如何叙述自己的未来（④**1980s**（**目标管理、责任制与“量化考核”进入机关与企业；社会学恢复后实地调查方法重回研究与政策研究（**通说脉络（**本章的关键转折：**指标一多，“指标一旦成为目标就不再是好指标”这条定律就有了大量试验场（上方指标条款（⑤**1983／1996／2009 及以后**（**统计方面的法律制定并多次修订，统计数据质量与口径规范被反复强调（**通说脉络（⑥**近十余年**（**“督帮一体”“四不两直”一类的调研方式被提倡；同时出现对过度留痕、材料考核的批评与清理（**通说脉络（**本章结语：**当“做了没有”只能由文书证明时，文书就会替事情说话；**所以本章三种文书的全部技术，都可以还原成一条：**把可核验的东西写在能核验的地方，其余的用别的办法说。**
:::

::: warning 本章四坑
**目标自选**（**通说格言：指标一旦成为目标就不再是好指标；**对策不是少用指标，而是把核查方式与未达标后果写进同一栏（上方指标条款（**））；**用“拟、力争、尽量”写时限**（**这三个词使整份文件不可验收；**它们属于讲话稿语体（上方六要素③（**））；**总结里没有自己的问题**（**问题全部外因化的总结，其信息量近似于零（上方四栏③（**））；**把座谈会意见当证据**（**它是第四等强度，只能证明材料不足（上方强度阶梯③：**“大家普遍认为”是本章唯一禁止的句子。**

::: exercise 小论文：可核验性与伦理 {level=3}
写六百至一千字，评“**现代组织之所以大量生产可核验的说法，是因为它已经无法核验动机；而一旦可核验成为唯一被承认的形态，未被度量的部分就会被系统性地低估，直到无人再记得它曾被做过。因此应用文写作里的‘具体’是一种道德要求而不是一种文体偏好：它要求作者只说那些自己愿意被别人拿去检查的话。这也解释了为什么最熟练的文书能够用完全真实的数字讲述一个完全错误的故事**”。须调用：**六要素与验收方式**、**指标成为目标之后**、**经验栏**、**三种失真**、**三栏分离**、**强度阶梯**至少六项；并裁决：**在被考核者也能核验的时代，写作伦理的底线是什么——你须给出一条可写进模板的规则，并说明它会被怎样绕过**。

::: solution
判分点：六项机制（**验收、指标异化、经验、失真、三栏、强度**）；模板规则（**合格规则须是可执行的一句，例如：“凡出现数字，其后紧跟括注（口径／时点／来源）**；凡出现结论，须标注其属于事实、推断或建议三类之一**；凡引用他人意见，须给出人数与访谈时间。”**——**判卷看规则是否只增加书写成本而不增加被核验者的风险，否则它必然被绕过**）；绕过方式（**必须是具体的：**例如按规则填齐括注，却改选口径（**把分母换成已申请人数**）或换指标（**把“办结时长”换成“首办响应时长”**）；因此底线的正确表述不是“格式合规”，而是**“同一事项连续多年保持口径不变，且口径变更须另行说明理由”**（**这条规则能被审计，因为它把变更本身变成一件需要解释的事**）；结论若能写“**所以本章的终点是一条很窄的职业伦理：不比人会说，要比人肯把自己说过的话交出去检查；文书学能做到的极限，就是让交出检查这件事有固定格式**”，即 A。

::: summary
时间归档：计划（**没有验收方式就是表态**）、精度（**只能延伸到下一个可被检查的日期**）、总结（**经验栏是唯一资产，问题栏必须有一个是自己**）、失真（**比例、平均数、以点代面**）、调查报告（**事实、推断、建议三栏分开**）、数字（**口径、时点、样本框**）。方法一句话：**只写你愿意被别人拿去检查的那些话**。下一章：新闻写作——把倒金字塔倒过来。

:::
