title: "同义词、反义词与语义场"

词典学家对“词义相近”有一句刻薄而精确的话：**没有两个词的意义完全相同，否则词典学家会毙掉其中一个**。本课学三件分析兵器——义素（成分分析）、搭配框架、标记性——把“差不多”拆成看得见的差别，再把词汇摆进它的货架（语义场）。

## 同义词与同义词群 {#sec-tongyi}

::: definition 同义群与使用词 {#def-tongyiqu}
**等义**（意义完全互换）在语言里近乎稀有动物——近似者如“月亮／月球”“春天／春季”这类通名与雅称；教科书所谓**同义词**实为**近义**。近义词聚成**同义词群**，群内有一个**核心词**（使用频率最高、能产、中性：“父亲／爸爸／爹／令尊／老爷子／家父”群以“父亲／爸爸”为核心），其余成员在若干维度上偏移。来源四条：**方言**（土豆／马铃薯／洋芋）、**文言留存**（死亡族：卒、殁、崩、殉、牺牲）、**委婉缩合**（去世、走了、不在了）、**语音与形态变异**（目／眼睛）。
:::

::: theorem 辨析三轴：意义·色彩·用法 {#rule-sanxiu}
**①义素（意义）轴**：范围大小（边疆＞边境＞边陲）、程度轻重（请求／恳求／哀求——情态递增）、集体与个体（森林／树林／树；衣服／衬衣）、具体与概括。**②色彩轴**：感情（成果—偏褒／结果—中性／后果—贬）、语体（生日·诞辰·寿辰的场合等级；去世／死／崩／驾鹤）、形象（颤抖／哆嗦／颤巍巍）。**③用法（搭配）轴**：句法框架差异（“违背”带宾、“违心”作状语）、搭配限制（交换物品·交换意见，交流思想·交流经验）、**分布**差异（“很”不能单独成句、“非常”可以）。关于时间与体貌副词的经典考题几乎全落在用法轴上。**三轴顺序即是近义词辨析词典的编纂栏目顺序。**
:::

::: example 五词手术台 {#ex-wuci}
比较“改进、改善、改变、改正、改造”：定核心、标义素差、各配一个典型搭配。
::: solution
搭配一格错即露馅：“改正生活”“改善错误”都不成话，“改变态度”则成立。五词群是汉语“单音节能产核心＋双音分工”的标本——**语素义还在起作用**，辨析有时回到词素即可（改“错”纠“误”，方向自见）。
:::

## 反义：四型与标记性 {#sec-fanyi}

::: definition 反义类型学 {#def-fanyi}
**互补反义**（complementary）：非此即彼，否定一方必然肯定另一方——生／死、真／假、正／负；测试式：“不A且不B”应构成矛盾。**等级反义**（gradable）：有中间地带、可程度化——大／小、热／冷、宽／窄；“不太大”成立，否定不蕴含对方。**反向关系**（converse）：同一情景两种视角——买／卖、教／学、老师／学生；汉语的“借”兼摄双向（“借我钱”可读作借出或借入），是系统容忍歧义的著名案例。**方向反义**：来／去、上行／下行。合式性还受**搭配**绑架：“这茶不热，得加点儿”——饮品的“冷”叫“凉”：热／凉对饮品、热／冷对天气、深／浅对颜色浓度，反义配对**随义词游移**。
:::

::: example 标记性三案 {#ex-biaoji}
①问身高用“他多高了？”而几乎不用“他多矮了？”（前者是**中性问**）；②“他不矮”比“他不高”更常用来委婉表“中等偏上”；③“桌子是长的，不是短的”与其翻转句都说得通——说明两者语用信息的差别。
::: solution
度量形容词的**正向项（无标记项）**承担全轴提问与泛指：“多高、多长、多宽、多重、多大”——问的是量度而非“高”。“矮、短、窄”是负向项，出现即宣告立场（“他矮”是信息，“他不高”是中性偏贬的委婉）。③两句皆通，但**语用不对称**：否定“更可能预期的极性”才有信息量，故“是长的不是短的”更像纠错场景。测试法沉淀：**凡可程度化的等级反义，正向项吃下提问与泛指两项特权**。这是反义研究里唯一能当工具用的抽象——也是孩子先学会问“多大”而几乎不问“多小”的谜底。
:::
:::

::: history 从互训到场论：汉语词义关系研究两千年 {#sec-hulian}
《尔雅·释诂》“台、朕、赉、畀、卜、阳，予也”——把一串互训词堆在同一义下，是同义词群的原始形态；《说文》以互训结网（“坚，刚也”“刚，强断也”），词义关系第一次织成了网。方言材料也早慧：扬雄《方言》记“猪，关东西或谓彘，或谓豕”，是地域同义场的田野先声。现代转折在结构主义入场：三十年代以后**成分分析**（man＝[＋成人＋男性]式）进入汉语词汇学，义素表让“哥哥／弟弟”只差［＋年长］成为可演示的科学；七十年代语义场论（类比音位学的区别特征）解释了颜色词、亲属词为何成体系地空缺与多价；当代语料库把辨析轴变成搭配分布的检索统计（“改进”的高频宾语是方法、工作，“改善”的是生活、关系——**共现即定义**）。
:::

::: warning 同义辨析的三个“想当然”
（1）**词素透明万能**：“请求／恳求”靠“恳”可辨，但“改善”的“善”早不单独成义——拆素须防**词素义与词义脱钩**（“马虎”无马无虎）；（2）**反义可以类推**：“大／小”相反，推不出“大米”与“小米”相反（它们只是稻米品种名）——词内语素不外包自由反义，“高兴”也没有“＊低兴”；（3）**义素差即全部**：“咱们／我们”的义素表只差［±包括听者］，但其**语用与地区分布**（北方更喜用“咱们”表亲近）才是使用知识——辨析写得出“义素差＋使用差”两栏才算完工。
:::

::: exercise 三轴填表 {level=1}
给“边疆／边境／边陲”填三轴表（意义、色彩、用法各一句）。
::: solution
意义：边疆范围大（国境内的辽阔地域），边境指边界沿线地带，边陲＝边疆一隅（书面化）；色彩：边陲文言／书面最浓，边疆政论常用，边境新闻通用；用法：边疆可接“建设～”，边境多作“～地区／～贸易”，边陲常缀“～小镇”类定中。表满三栏、无硬伤即满分。
:::
:::

::: exercise 反义分型 {level=1}
给下列配对分型：男—女、进—出、深—浅、正—负、老师—学生、胖—瘦。
::: solution
男/女＝互补；进/出＝方向反义（语境锁定“在内／在外”时趋近互补，注明即给分）；深/浅＝等级；正/负＝互补（符号域）；老师/学生＝反向（关系）；胖/瘦＝等级，且负向标记更重——问体形度量惯用“他多重？”，“多胖”几乎不成中性问。
:::
:::

::: exercise 语感语料 {level=2}
选一组本地方言与普通话的“同义对”（如“走路／行路”“星期天／礼拜日”），说明其**语体分工**或**代际分工**；再设计一个最小替换句检验“互换后变的是什么”。
::: solution
示例：“俺／我”——人称同义，但“俺”自带乡土／亲昵／诙谐三重偏移；检验句“俺觉得对”↔“我觉得对”：命题义不变，变的是**人设与场合**（语用意义、身份标记）。合格答案须点出“同义词的差别不在词典里，在说话人身上”。
:::
:::

::: exercise 小论文：谁需要辨析词典 {level=3}
《现代汉语近义词词典》类工具与“辨析三轴”孰先孰后？写一篇八百至一千二百字短论：母语者、二语学习者、AI 语言模型三类用户分别需要什么颗粒度的词义差别描写？要求：用义素表＋搭配框架各造一例，并回答“词典标不出来的差别是不是伪差别”。
::: solution
判分点：能指出三类用户需求不同（母语者要搭配/语用提示，学习者要例句库与偏误预警，模型训练靠分布而非定义）；义素表与框架例自造无误；对“标不出的差别”给出分层立场（可标而未标≠伪；原则上不可穷举的语用知识≠词典失职——工具与学科分工）；无概念混用（把“标记性”当“标注”者扣分）。
:::

::: summary
等义稀有、近义成群：同义词群以核心词为锚，差别沿三轴展开——义素（范围/轻重/集体个体）、色彩（感情/语体/形象）、用法（搭配框架与分布），三轴即辨析词典的编写栏目。反义分互补、等级、反向、方向四型；等级反义的**正向项无标记**（多高、多长）是最好用的发现。语义场让词各归其架：上下位（白菜—蔬菜）、同类并列、整体部分，场内空缺与多价解释方言与历时变异。两千年从《尔雅》互训到语料库共现，“差别在说话人身上”——辨析的尽头不是定义，是用法。
:::
