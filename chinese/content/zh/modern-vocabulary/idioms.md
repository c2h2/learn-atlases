title: "成语与熟语"
---

“胸有成竹”四个字里藏着一句画论，“莫名其妙”四个字里塌着一个已死的古语词“名（说出）”。成语是汉语词汇里的**化石层**：结构是古汉语的，意义是典故化的，使用是现代的。本课把成语放进熟语大家族里，看清各房的脾气。

## 熟语家族谱系 {#sec-putong}

::: definition 固定语与五房兄弟 {#def-shuyu}
**固定语（熟语）**是“现成的、按习惯整块使用”的语言材料，特征为**结构定型、意义整体**。分五房：**成语**（四字为主、来源有经有史、书面色彩）；**惯用语**（以三字动宾格为主：碰钉子、穿小鞋、敲边鼓，口语、**可拆用**——“碰了个软钉子”）；**谚语**（句子级、民间经验：“朝霞不出门，晚霞行千里”）；**歇后语**（两截话：引子＋说明，“外甥打灯笼——照旧（舅）”，后半常谐音）；**格言**（箴言式，多有主名：“虚心使人进步，骄傲使人落后”）。分房标准吵了几十年，可操作的三问：**字数与结构定不死？意义可拆得开？出身在书面还是口耳？**——三问各一票，多数条目能安家。
:::

::: theorem 成语三性：四字、典故、双层意义 {#rule-sanxing}
**四字格**：成语的绝对优势格（五字“莫须有”、多字“有志者事竟成”都是少数，例外自存一格）。**典故性**：来源可指（史书、子书、诗文、佛典）——口耳相传的俗谚即使成四字（“吃一堑长一智”）也常被划入“谚语／俗语”而非严格成语，词典各本处理不一。**双层意义**：字面义＋整体义，“胸有成竹”与“竹子”“胸膛”无干；**双层性正是成语误写（望文生义）与误用（望义生用）的病源**。三性全满足的是典型成员，边缘成员（“蓝天白云”式新造四字格）在“是不是成语”上合法地骑墙。
:::

## 成语的来源与“古语法保护区” {#sec-laiyuan}

::: definition 五条来路 {#def-lailu}
①**寓言与神话**：井底之蛙、螳臂当车、邯郸学步、愚公移山（先秦子书的造景之力冠绝古今）；②**史实与典故**：破釜沉舟（巨鹿之战“皆沉船破釜甑”）、四面楚歌（垓下之围）、纸上谈兵（赵括事，语出后起凝练）；③**经史本文截短**：“如履薄冰”（《诗经》“战战兢兢，如履薄冰”）、“他山”（《小雅》“他山之石，可以攻玉”）；④**后世诗文凝句**：“老当益壮”（王勃《滕王阁序》）、“青梅竹马”（李白乐府）；⑤**口耳与近代新造**：“百花齐放”一类政论凝句入成语——成语生产线从未停工，只是产量大不如前。
:::

::: example 成语里的古汉语语法陈列馆 {#ex-yufa}
指出下列成语保留的古汉语语法现象：“唯利是图、不耻下问、生死之、汗牛充栋、不名一钱、不远千里、是古非今、不以为然”。
::: solution
“唯利是图”＝**宾语前置**（“唯…是…”标记式，同构“唯命是从”）；“不耻下问”＝**意动**（以向下请教为耻）；“生死肉骨”＝**使动双连**（使死者生、使白骨长肉）；“汗牛充栋”＝**使动**（使牛马出汗、使屋宇充满）；“不名一钱”＝**名词动用**（名＝占有、拥有）；“不远千里”＝**意动**（以千里为远）；“是古非今”＝**意动**（以古为是、以今为非）；“不以为然”＝“然”作谓词“认为对”——它正是“不以为然”不等于“不以为意”的辨析钥匙。陈列馆门票：一个成语常保存一个现代汉语已死的语法词。
:::
:::

## 误写·误读·误用：病例三种 {#sec-bingli}

::: example 望文生义十连改错 {#ex-shilian}
写出下列成语的规范写法并各注一字之义：①名列前矛；②莫明其妙；③变本加利；④再接再励；⑤甘败下风；⑥走头无路；⑦黄梁美梦；⑧迫不急待；⑨金壁辉煌；⑩既往不究。
::: solution
按上一章的门急诊：①名列前茅——茅指包茅（楚国贡物之典，喻军之先头），非长矛；②莫名其妙——名＝说出（古语词仅活在此成语中）；③变本加厉——厉＝砺本字，磨刀石，谓程度更甚；④再接再厉——厉仍是磨（斗鸡磨喙），非鼓励；⑤甘拜下风——拜是拱手俯首；⑥走投无路——投＝投奔；⑦黄粱一梦——粱是粟米（蒸粱饭的饭铺故事），不是房梁；⑧迫不及待——及＝来得及；⑨金碧辉煌——碧＝青绿颜料（金玉与青绿油漆的殿宇）；⑩既往不咎——咎＝责备。十案全在**音近字越权**：成语误写是“检索捷径”病在化石层的复发（[[chinese-characters/standard-characters]]）。
:::
:::

::: intuition 成语为什么偏爱“误用”这一病 {#int-yong}
三案的共性：**使用者只接触了翻译体的成语（四字对一个近义标签），没查它的原始语义结构**。成语的“字典义”在语源里，处方两条：典故回填＋语素分析——凡把“不足为训”的“训”解作“教训”之前先查一字，即可自愈。
:::

::: history “成语”之名与熟语学的登堂入室 {#sec-chengyu-shi}
“成语”一词汉代已有，汉魏六朝文献里多指六艺之文与现成经句；唐以后渐指“古语成句”，宋人笔记考订“语有出处”成风（洪迈诸笔、王应麟《困学纪闻》皆有成语与常语的条考）；清代翟灏《通俗编》、钱大昕《恒言录》把俗语常语一并入谱，是熟语学的前夜；“成语”作为教学语法术语的现代泛定在二十世纪初的国语教科书，1930年代起“成语词典”成为独立书名品类；1980年代前后商务印书馆、上海辞书出版社诸家成语辞书竞出，成语从文人的考据雅好变成国民词表与出版工业。四字格霸权的确立与经学教育下移、骈文科举、蒙学韵书（《幼学琼林》类）三次文化工程互为因果——形式即制度。
:::

::: warning 三个滥用场景
（1）**堆砌**：公文与考场作文连发“继往开来、砥砺前行、催人奋进”——成语作装饰时语义互相抵消，密度过阈值即成噪音；（2）**色彩错配**：“始作俑者”（贬）用来致敬首创者、“登堂入室”（学问进阶）用来夸装修，“差强人意”（大致尚可）当“不能满意”用——语体与感情色彩是成语的第二张语法；（3）**对仗强迫**：“不以为然／不以为意”“应接不暇／自顾不暇”混用——近形成语共享语素，误用的源头常是**字形相似＋义首相近**。
:::

::: exercise 分房 {level=1}
把“八九不离十、耳边风、瑞雪兆丰年、打开天窗说亮话、破天荒”分入五房，各说一票理由。
::: solution
八九不离十——俗语（惯用与谚语之间的边缘户：不可拆、又非完整经验句）；耳边风——惯用语（名物化惯用，可嵌入“把劝告当成～”）；瑞雪兆丰年——谚语（完整句子、农事经验、可独立成话）；打开天窗说亮话——谚语（复句定型的直话）；破天荒——惯用语（唐时举人传说有典，但已口语泛化——成语／惯用语两栖，注明边缘身份即可）。本题考点正是“边缘户”：凡两票各半且理由成话者满分。
:::
:::

::: exercise 破案 {level=1}
给“久假不归、文不加点、不赞一词、差强人意、三人成虎”各写一句正确用法＋一句易犯的错误用法（错句不必解释）。
::: solution
久假不归：他拿书“久假不归”（正：长期借用不还）／误：他请假久了不回来；文不加点：下笔“文不加点”（正：一气呵成）／误：文章不加标点；不赞一词：对杂议“不赞一词”（正：一言不发、不置评）／误：一句也不夸奖；差强人意：表现“差强人意”（正：还算过得去）／误：令人很不满意；三人成虎：谣言“三人成虎”（正：传者众则似真）／误：三人合力成事。凡“误用句”恰是街面高频错式，本题即达标。
:::
:::

::: exercise 调查 {level=2}
收集五例本地歇后语（含谐意双关各一），标注双关类型；再选一例说明其能否直译成普通话书面语（检验“歇后语＝方言修辞”论）。
::: solution
示例：①“外甥打灯笼——照旧（舅）”＝**谐字**双关（照舅→照旧）；②“小葱拌豆腐——一青（清）二白”谐字；③“哑巴吃黄连——有苦说不出”＝会意型（无谐音）；④“竹篮打水——一场空”会意；⑤“狗咬吕洞宾——不识好人心”故事型。直译实验：谐音型一旦离开方言音系（青／清同音）双关即瘫——歇后语是**语音依赖型熟语**，这是它比成语更难进正式语体的结构原因。
:::
:::

::: exercise 小论文：成语是负债还是资产 {level=3}
“成语难学、易错、拖慢表达”与“成语四字顶千言”两说。写一篇八百至一千二百字短论：现代汉语书面语的成语密度应如何评价？要求：引“双层意义”解释误用病源、举一个“古法保护区”例（使动/意动/提宾）说明成语的教学价值、给出你对“新成语生成（内卷、躺平能否入选）”的可检验预测。
::: solution
判分点：把误用病源准确落到“字面义与整体义脱钩”；用陈列馆成语做论据（教“唯利是图”即教宾语前置）；新成语预测有可检指标（跨社群使用、寿命≥10年、结构定型、被词典追认——并指明现候选多数会死，淘汰机制即四字格竞争）；能提出“密度”操作化（每千字成语出现率）与合理区间；立场自洽即可，无须站队。
:::

::: summary
熟语五房：成语（四字、典故、双层义）、惯用语（三字动宾、可拆、口语）、谚语（句子级经验）、歇后语（两截＋谐音，语音依赖）、格言（箴言多有名姓）。成语五源：子书寓言、史事典故、经文截短、诗文凝句、近代新造；它同时是**古汉语语法保护区**（唯利是图＝提宾，汗牛＝使动，不耻下问＝意动，名／然／是＝死词活标本）。病名三件：误写（音近越权）、误义（望文生义）、误用（色彩错配、堆砌）；处方两件：典故回填、语素分析。“成语”概念的泛化是国语教科书与出版工业的近代成就——四字格霸权本身是文化工程的沉积。
:::
