title: "词义"

词典里“打”有二十来个义项，“上”十几个，“了”两个却个个高频。词义不是贴在词上的标签，而是一张**有中心、有延伸路径、有搭配习惯、有感情色彩的地图**。本课教怎么画这张图。

## 词义的两层与两面 {#sec-liangceng}

::: definition 词汇意义与语法意义 {#def-clyy}
**词汇意义**（指称义＋含义）是词认领世界切片的方式：“春”认领季节，“跑步”认领动作；**语法意义**是词在组合中充当角色的方式：量词的“个体/容器”义（一**张**纸对一**打**纸）、“了”的现实化与完成（下雨**了**）、“-们”的复数。“春”也有语法意义（时间名词的句法行为），只是薄。**理性意义**（概念内核）之外还有**色彩意义**：感情（成果／后果／结论三词内核相近，褒贬迥异）、语体（父亲／爸爸／老爷子）、形象（“土豆／马铃薯／洋芋”各自的形感与地区色彩）、敬谦（犬子／令郎）。
:::

::: theorem 义项不是清单，是地图 {#rule-yixiang}
多义词诸义项围绕**中心义**（原型）按两条路线延伸：**辐射式**——本义为中心，隐喻、转喻各拉出一条支链，支链可再分叉（“深”：水深→夜深→感情深→颜色深，支支相引而不共一线）；**连锁式**——义项A生B、B生C，A与C已无直接理据（“头”：脑袋→顶端→开头→词尾“石头”的虚化尾）。真实词典条目是两种混合：中心清晰、边缘连片，最外缘甚至脱卸为同音异素（“花”花草／花费）。词典学处理：义项按**使用频率＋心理现实**排序，不按字源——这是《现代汉语词典》与《辞源》的根本分工。
:::

::: example 给“老”画义项地图 {#ex-lao}
“老”的常见义：年岁大、资历深、陈年、去世（讳称）、前缀（老虎、老王）、副词（总是）。画辐射义项图并标注各条引申机制。
::: solution
中心【年岁大】—转喻→【资历深】（老教师）、—隐喻→【陈年】（老房子）、—讳饰→【去世】（他老了）；【前缀】与【副词（总是）】为两条**语法化**出口：前者粘着于名（老王、老虎——已无年义），后者沉入动词前（老不理会）。机制标签各就各位：转喻靠相邻（年长与资深常结伴）、隐喻靠相似（旧与老相像）、虚化靠高频占用。一张图串起语义学三大引擎，这就是“地图”胜过“清单”的原因。
:::

## 词义的演变引擎 {#sec-yanbian}

::: definition 三种变化与两种机制 {#def-sanbian}
按**范围**分：**扩大**（“菜”古指蔬菜类，今肉蛋菌藻全入；“江／河”专名变通名）、**缩小**（“金”古泛指金属——金就砺则利，今专指黄金；“臭”古凡气味皆臭（其臭如兰），今专指秽气——缩小兼贬降）、**转移**（“闻”本听见，今专嗅觉；“牺牲”本祭祀用牲，今凡殉义）。按**升降**分：**褒化**（“乖”古背离义今乖巧）、**贬降**（“爪牙”古为勇士之誉，今成帮凶）。机制只有两台：**隐喻**（相似性投射：桌面、硬盘）、**转喻**（相关性借代：白宫发表声明、他刚读完一部《红楼梦》——买书借制作）。虚化（词汇义→语法义）是转喻在高频句法位的极限延伸。
:::

::: example “潜水”的两副面孔 {#ex-qianshui}
“潜水”从军事／运动义到群聊不发言义，是哪台引擎？“水贴”之“水”（形容动词“灌水”到形容词“这帖真水”）又经历了什么？
::: solution
潜水（不发言）：**隐喻**——“沉在水面之下不露头”与“在群里不发声”的结构相似，且保留“人在场”意象（人确在列表里），属网络社区自发的系统性隐喻群（冒泡、灌水、上岸）。水贴之“水”：**转喻＋虚化**——由动作“灌水”（注水式多产）借出其物属性，再泛化为“质量低、注水多”的性状义，词性滑向形容词（太水了）——网络语把这台老引擎的转速开到了最大，但**语法化的每一步在纸面之外都有原型**（《现汉》“水”形义项收得谨慎，语言共同体跑在词典前面）。
:::
:::

::: intuition 一词多义是缺陷还是超能力
音义任意＋线条性＋省力原则，共同判了“一词一义”死刑；多义以**中心＋语境消歧**的方式把记忆成本压到最低（记一个“打”的地图胜过记二十个生词）。“歧义误读”的真实事故率极低——语境（“打酱油／打官司／打人”各不相同）与搭配（量词、动结式）是两把免费的滤网。真正该留意的是**共时分层**造成的代际多义错位（“意思”在“小意思／没意思／意思意思”里三义各异——玩笑，但幽默确实吃着这层红利）。心理语言学支持：高频多义词的义项提取快于单义词的语义整合——多义不是债，是复利。
:::

::: warning 训诂的诱惑：三个“词义事实”陷阱
（2）**组合义等于语素义相加**：“汽车”的意义拼不出“机器＋车辆”；“马车→电车→火车”类推之外，“牛车”并非自动合格（它成立另有理据）——**类推不是定义**；
:::

::: history 从《尔雅》到义素分析：中国人怎么拆词义 {#sec-cixue}
《尔雅》以“释诂”“释亲”分组串词，是**语义场**思想的三千年先声；《说文》以“转注／假借”立“义生于用”的机制观；刘熙《释名》声训虽野，处处试探“义存于音”的想头。近代转型引入外域框架后，五十年代义素分析（“丈夫”＝[＋人＋男＋已婚]式的成分分解）入汉语——**成分分析法**让“哥哥／弟弟”的长幼对立项第一次进表；八十年代起认知语义学（辐射范畴、隐喻系统、原型理论）把“深、上、老”们画成地图。三千年间词义研究从分类到分解再到成网——方法在换，问题从未变：**意义凭什么能被一个声音带走**。
:::

::: quiz
“臭”古泛指气味今专指秽气，属于词义演变的（　）。
- [ ] 扩大＋褒化
- [x] 缩小＋贬降
- [ ] 转移＋中性化
- [ ] 虚化
::: solution
范围缩小（全气味→坏气味）且评价贬降（“其臭如兰”之臭本无贬）——缩小常伴贬降，因负面经验抢词汇。

::: quiz
“桌面”“硬盘”的词义机制是（　）。
- [ ] 转喻
- [x] 隐喻
- [ ] 缩略
- [ ] 语法化
::: solution
以相似结构（平面之上有物可摆／盘的物理形状）投射新域——隐喻。转喻靠相邻（部分代整体等），本词无相邻关系。

::: exercise 义项地图 {level=1}
给“重”画辐射义项图：zhòng 族的重量大、重要、庄重，与 chóng 族的重复、层叠——先分音，再分图。
::: solution
先分头：zhòng（重量大[中心]→重要[转喻：分量→价值]→庄重[隐喻：重物之稳→举止持重]）；chóng（中心“层叠”→再次、重复）。两音两图即“同形多音多义”的标准处理，凡把 zhòng 的“庄重”连到 chóng 图上者判结构错。
:::
:::

::: exercise 演变诊断 {level=1}
判断下列词的历时变化类型（扩大／缩小／转移／褒化／贬降／虚化）：子、乖、牺牲、去、金。
::: solution
子：泛指婴儿缩小为“儿子”，又虚化为名词词尾（桌子的“子”）——缩小＋虚化连环；乖：背离义转乖巧（褒化）；牺牲：祭祀牲转殉义（转移＋褒化）；去：“离开某地”转“前往某地”（方向反转的转移，经典冤案）；金：泛指金属缩小为黄金。祥可作附加题：今“吉祥”乃古义“福”之遗存，中古曾泛出“预兆”一支（不祥之兆），范围曾扩而本义未失。
:::
:::

::: exercise 新义观察 {level=2}
收集近两年社群里发生的三个新义项（如“卷”“卷王”“卷生卷死”算一个词族的三级语法化），逐一标注机制（隐喻/转喻/虚化）与“理据透明期”是否已过。
::: solution
示例答案：“卷”（竞争内卷化）＝转喻（卷起来→挤→高强度投入的**动作借代**），已进“卷王／卷不动”能产期，理据仍透明；“破防”（游戏防线→心理崩溃）＝隐喻，透明；“蚌埠住了”＝谐音**记号化**，理据已断（新人不知“蚌埠”非地名）——凡例证含机制标签＋透明度判断＋一个自造使用例句，即满分标准。
:::
:::

::: exercise 小论文：词典该追认网络义吗 {level=3}
《现代汉语词典》收录“门、被、晒”诸新义曾多次引发全民讨论。写一篇八百至一千二百字短论：词典收新义的标准应有哪些？“描写主义”与“语言守门人”角色如何分账？要求用本课“多义地图”“色彩义”“虚化”至少三个概念。
::: solution
判分点：能提出可操作的收录门槛（语料频率＋跨社群＋预测期存活）并各配一正一反例；理解“收义不收骂名”——色彩义标注（贬／戏谑）恰是描写工具而非审查开关；能预判“收词=背书”论的错位（词典的权威性在规范用法提示，不在义项准入的褒贬）；“被”字被动式虚化的例句分析准确。
:::

::: summary
词义＝词汇义（指称内核）＋语法义＋色彩义（感情/语体/形象/敬谦）；多义词是地图不是清单：中心义＋辐射/连锁延伸，词典按频率与心理现实排序。三台引擎管演变：隐喻（相似）、转喻（相邻）、语法化（高频虚化）；范围账分扩大、缩小、转移，评价账分褒化、贬降。“词义＝字源相加”“组合义＝语素和”是两匹吃谷种的马，描写的纪律是记录社区而非替社区立法。网络语言把老引擎踩出转速，义项准入之争（词典追认权）本质是规范学与描写学的分工之争——两样都要，但要分账。
:::
