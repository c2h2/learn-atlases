---
title: "词汇的构成层次"
---

把现代汉语的词典摊开，词不是铁板一块，而是**有地层**的：最底下是几千年冲不走的基岩（基本词汇），上面压着各朝各代的来客——古语词、方言词、外来词、新词语。本课学生一副“地质锤”，敲开任意一个词，听它属于哪一层。

## 基本词汇与一般词汇 {#sec-jiben}

::: definition 两分与三性 {#def-jwc}
词汇系统分两大块：**基本词汇**——全民日常离不开、千百年长存、充当构词基础的那部分（天、地、人、山、水、父、母、走、坐、大、小、一、二、我、你）；其余统称**一般词汇**——新词、古语词、方言词、外来词、行业语、隐语等的总和。“三性”说是苏联语言学输入的学说（斯大林《马克思主义与语言学问题》1950 年出版后成为国内教材通说）：**广泛性**（全民通用不分地域阶层）、**稳固性**（千年不易，"日、月、人"跨三千年）、**能产性**（作为构词胚芽批量派生：“人”生“人民、人员、工人、人生、人造”）。
:::

::: theorem 三性是洞见也是软尺 {#rule-sanxing2}
洞见在**分层观**：词汇有了“核心—外围”，教学分级词表（《汉语水平词汇等级大纲》等级词、《通用规范汉字表》配套词表）与词典详略都有了依据；软在**操作**——广泛性靠语料词频测却混着文体分布，稳固性靠历时存活性却是“多少年算稳”，能产性靠派生产率却对“山”式类缀与“们”式虚缀一视同仁——三性互相定义、边界模糊，学界早有清算。教材立场：**当地图用，别当判决书用**——判断一个词是不是基本词，看它是否同时满足“高频、历久、能生娃”三条倾向，边缘案例承认存疑。
:::

## 古语词与历史词：两把考古铲 {#sec-guyu}

::: definition 三型分辨 {#def-sanxing3}
**历史词**：所指事物已消亡，词跟着进历史档案——皇帝、丞相、妾、贡院、鼎甲、太监。**古语词**：所指事物仍在，只是换了说法，词以“旧马甲”活在特定语体——称父亲说“家父”、请人批评说“雅正”、文言虚词“之乎者也”蹲在书面层。**旧白话词**：近代白话（元曲、明清小说）里活过、现代口语里死了的词——衙门、造化、不才、在下、小二、客官。
:::

::: example 一词一铲：判层实战 {#ex-pc}
“朕、丞相、内卷、您、衙门、导致、吧”——各属哪层？
::: solution
“朕”历史词（制度性自称已亡）；“丞相”历史词（职官亡）；“内卷”新词语（且带行业语色彩：人类学→社会流行）；“您”普通话基本层外的**常用敬称**（北方方言进入通语已完成时）；“衙门”旧白话词（今用于戏称或历史叙述）；“导致”一般词（含贬倾向的书面色彩词，“导致灾难”可、“导致成功”别扭——色彩即语体账）；“吧”语气词，基本词汇（虚词全在基岩里——基本词不分实虚）。
:::
:::

::: intuition 为什么文言语素“死而不僵” {#int-bzj}
古语词整批退场，但其中的**语素**大量转岗进词层：“民”不成词（口语说“人／老百姓”），却在“人民、民警、民主”里当家；“语、日、月”皆然。机制是汉语的**语素配方**：书面色彩不在某个词里，而在语素组合里（“吃饭”对“用餐”对“用膳”，三阶地层一目了然）。所以学文言词的捷径不是背单词，是建**语素档案**：“之、其、所、以、于”五个字，撑起一半书面语的骨架。
:::

## 方言词与外来词：两扇进客门 {#sec-fangyan}

::: definition 进入共同语的条件 {#def-jinru}
方言词进入普通话，教科书立三条件：**必要性**（通语无此义词或有缝——“搞”补上了“做／弄／干”的分工缝隙）、**普遍性**（跨方言通用度高）、**明确性**（词义稳定不漂移）。明星案例：**搞**（南方方言北上，早已入典）、**名堂、拆台、拉钩、没门儿、磨叽、埋汰**（北方官话与东北话贡献）、**尴尬、蹩脚、拎得清**（吴语）、**埋单、靓、炒鱿鱼**（粤语，1980 年代随开放“南词北伐”）。进不进口、进了留不留，市场是终审：北漂、忽悠活蹦乱跳，一批南方词已随打工潮退温。
:::

::: example 语体改写：同一件事的三个地层 {#ex-gx}
把“我爸妈挺疼我，不让我干家务”改写成书面语体与公文／家书两式，体会语素换料。
::: solution
书面语体：“父母钟爱，未尝使操持家务。”公文式（罕见场合但可训）：“该生家中对其照顾周全，家务参与较少。”对照表：爸妈→父母→家中；疼→钟爱→照顾；不让→未尝使→未参与；干家务→操持家务→家务劳动。每一格换的都是**同义语素的不同地层**：口语层、文言层、行政公文体层。改写不是“文雅化”竞赛，是语体得体性练习——给作文打“做作”分的语文老师，打的正是“地层错配”。
:::
:::

::: warning 古语词滥用的三种失态
（1）**敬谦错位**：“敬请赐复”写给朋友、“令爱”指自己女儿（应说“小女”）、“抛砖引玉”之后滔滔四十分钟；（2）**文白夹生**：“既然我们已结束会谈，兹将纪要函告”——半文半白两头不靠；（3）**历史词当活词**：新闻里称教练“教头”、校长“山长”偶有为趣味，正式任命文书仍称“县长”而非“县令”——制度性称谓的历史词复活需极其谨慎，此例说明的是“历史词＝已亡制度的标签”这一底线。得体原则（系统功能语言学之“语域”）是词汇分层的最终裁判：**没有错的词，只有错的地方**。
:::

::: history 词汇地层学的诞生：从《马氏文通》到“基本词汇论” {#sec-cengli}
同期汉语方言词汇调查与近代白话词汇研究（《水浒传》《金瓶梅》词汇考释成热潮）给了“方言层、白话层”实据；
:::

- [ ] 广泛性
- [ ] 稳固性
- [x] 能产性
- [ ] 全民性
::: solution

::: exercise 判层 {level=1}
给下列词标注地层（基本／一般—古今语词／历史／方言／外来／新词）：百姓、嬷嬷、买单、秀（show）、禾、桌、微信、朕。
::: solution
百姓：古语词泛称“民”经“老百姓”沉淀进基本层——判“古语词沉淀层”；嬷嬷：方言称谓／戏称（来源有满语借词一说，注“待考”即可得分）；买单：粤语方言词入通语；秀：英语 show 音借新词；禾：文言／南方方言层（通语口语用“稻谷／秧苗”分工）；微信：新词；朕：历史词；桌：基本词（明代已稳固）。凡“百姓、桌”类答“基本”且“嬷嬷”敢标存疑者，判为有地层感。
:::
:::

::: exercise 敬谦改错 {level=1}
“我对大家的支持抛砖引玉讲三点，还望各位不吝赐教；我的作品拙见如下，请雅正。”——挑出四处不周并修正。
::: solution
①“抛砖引玉”之后自己滔滔讲三点，与“引玉”的让贤相悖（要么改口“我先抛砖”，要么少讲）；②“我的作品拙见如下”叠床架屋——“拙作”“拙见”各谦一样，取一即可；③“雅正”是请人修改的敬辞，用“请雅正”可，逢人便“雅正”即成堆砌失礼；④一段里“赐教、雅正、拙见、抛砖引玉”密度过载，敬谦词如香水，两滴风雅，四滴熏人。标准改稿：“我先谈几点粗浅看法，算是抛砖引玉，请大家多提意见。拙见如下，请指正。”——谦敬词是古语层的活化石，用错＝地层翻车现场。
:::
:::

::: exercise 田野 {level=2}
向你家方言区长辈收集五个“通语里没有现成对应”的方言词，逐一写：音、义、能否被通语同义说法无损替换。据三条件判断其“进入普通话潜力”。
::: solution
评分看方法而非词量：晋语“夜来”（昨天）——通语“昨天”可无损替换，判无必要；吴语“戆大”（傻瓜而带迟钝相）比“傻瓜”多一层嘲而轻的意味——近义不互等，有缝；东北“磕碜”（丑／寒碜／丢人）语义宽于通语任一单词——有缝即可申请入境（最终看普遍性、明确性）。
:::
:::

::: exercise 小论文：三性说过时了吗 {level=3}
以本课材料写一篇八百至一千二百字短论：“基本词汇三性”在语料库与网络词频时代还有存在必要吗？要求：引一条你亲手验证的三性操作化尝试（给“我／的／内卷／尴尬”等做词频或词族统计）、讨论《现代汉语常用词表》类词表的地层预设，并给出“教材保留还是删除该学说”的立场。
::: solution
判分点：亲手统计真实（哪怕用现成词频表截取数字）；能指出三性说的真正遗产是“词汇分层意识”而非判据本身；对常用词表能说出其分级标准（频次＋分布域）恰是三性的工程化；立场清楚且能防守（如“保留改名‘核心词与外围词’，删三性判据”）。把三性当公理证明或当伪证一棍子打死的，均扣分析分。
:::

::: summary
词汇有两层岩性：基本词汇（广泛·稳固·能产——三性是苏联输入的理论软尺，分层意识才是真遗产）与一般词汇（古语、历史、旧白话、方言、外来、新词各层）。古语词换马甲而物在，历史词随制度陪葬，旧白话词躺在文学语体里；文言语素死而不僵，转岗成双音词的填料；方言词凭必要性、普遍性、明确性三证入境，粤语词与东北词是当代最大两拨“新移民”。改写与得体是地层的用武之地——没有错的词，只有错的地方。
:::
