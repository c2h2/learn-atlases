---
title: "新词语与网络语言"
---

词汇是语言的晴雨表，而近三十年的汉语经历了一场持续暴雨：改革开放词潮、市场经济词潮、互联网词潮、移动互联网词潮，一浪接一浪。本课讲新词语怎么生、怎么死、怎么被词典收编，以及网络语言到底是“语言污染”还是“语言生活”。

## 新词语的出生证 {#sec-chusheng}

::: definition 四种出生方式 {#def-chusheng}
**构词法老机器加班**：复合（下岗、内卷）、派生（房奴一族、×门）、缩略（双减、空巢）——绝大多数新词用的是存世工序；**旧词赋新义**：潜水、晒、卷、被××（“被就业”）——词形不动，语义嫁接；**字母与数字入文**：GDP、996、520；**专名泛化**：山寨、草根、黑马——某次事件或作品凝成的普通名词。出生渠道则高度集中：传媒、公文、技术文献、市井与网络社区；**网络时代之前新词寿命以“代”计，之后以“季”计**。
:::

::: example 给词做“年检” {#ex-nianjian}
判断下列词的生命阶段：下海、万元户、倒爷、粉丝、给力、屌丝、yyds、内卷、躺平、破防。
::: solution
**退潮层**：下海、万元户、倒爷（上世纪 1980—90 年代市场经济初期的标志性词汇，大多已成时代标签词）；**沉淀层**：粉丝（音译与本义双轨扩张，完成常规化）、内卷（学术词大众化，进入通用贬义后仍在上升期）、躺平、破防（社会心态词，热度高位、寿命待考）；**速生速死层**：给力（表情包时代网红，已部分常规化为“带劲”义）、yyds（字母首音缩略，圈层外基本不可解——跨圈失败即死亡倒计时）。**年检结论**：一个词能不能留下，看三件——跨圈层、能产（可组词）、有无不可替代的语义缝隙。yyds 三件全悬。
:::
:::

## 网络语言的语法学 {#sec-wangluo}

::: definition 网络构词的独门兵器 {#def-bingqi}
①**字母缩略**：yyds、xswl、nsdd（拼音首字母缩略，圈层暗号属性极强）；
:::

::: theorem 流行语的衰变曲线 {#rule-shuaibian}
网络词生命周期呈标准三段式：**爆发**（圈层黑话，身份标记红利）—**溢出**（大众媒体转用、语义磨损）—**常规化或死亡**（进入通用词或被弃）。检验公式三问：**去语境还懂吗**（离开梗图还能独立使用）？**能产吗**（卷王、卷不动 这类派生是否成串）？**有没有用它的正经文章**（严肃语体引用＝登记户口）。据此，2010 年代网红词里“给力、逆袭、剁手、佛系”已沉淀，“蓝瘦香菇、神马”已过气——**淘汰率九成以上，是常态不是意外**；“流行语排行榜”本质是语言死亡的现场直播。
:::

::: intuition “汉字落后论”死了，“汉语危机论”活着——同一种焦虑的换皮
每到词潮年代，就出现“汉语完了”的声音：1950 年代夹杂俄语词，1980 年代“海派英语”，2000 年代网络语法，2010 年代字母词，2020 年代 AI 翻译。语言学家的共识：**词汇是语言里最抗打击也最好变的层**——变化正是健康代谢；真正该监测的指标是：母语者**语用得体感**是否还在生成（会分场合用“yyds”与写不写规范作文，不是同一能力）与**代际交流**是否受阻。前者是教育问题，后者在汉语里从未发生；“完了”论的实质是**代际词汇差被误读为文明衰亡**。
:::

::: history 国家读词：十年一度的“汉语新词语普查” {#sec-pucha}
中国对新词的关注早已制度化：1990 年代起，《新华文摘》等转载与各出版社年编《中国语言生活状况报告》系列（教育部、国家语委 2006 年起年度发布）把新词、字母词、流行语计数成官方数据；《现代汉语词典》每版增补以词表回应现实（2012 六版收“房奴、团购、粉丝”曾上热搜）；国家语委亦发布年度“新词语”榜（如“房叔”“正能量”“点赞”等）；“网络流行语”榜（《咬文嚼字》、国家语委、各平台各出一榜）则成了新年俗。语言规划从“规范至上”（1950s 异体字整理、纯净化）转向“监测—记录—引导”——**国家成了语言生活的记账员，而非立法者**。
:::

::: warning 三组混账
（1）**把语域当语病**：网络语用于聊天不违规，用于公文、病历、判决书才违规——问题在语域错配，非“网络语”之罪；（2）**把代际当衰败**：中老年批评青少年用语，与孔子时代感叹“今人不如古人”一样，是人类代际常量；（3）**把统计当规范**：“入选流行语榜”不等于规范词，“未入选”也不等于错——排行榜是体温计，不是处方单。结论：对网络语言，**描写要贪心，规范要克制**。
:::

::: quiz
下列哪组全部属于“旧词赋新义”？
- [ ] 下海、倒爷、粉丝
- [x] 潜水、晒、被就业
- [ ] 给力、内卷、破防
- [ ] 秒、崩、卷（新派生动词组）
::: solution
潜水、晒、被就业都是既有词形挂新语义；下海倒爷是旧语素新造（下海古已有，义另构，勉强算赋义，但“倒爷”为新造）；粉丝是音译+本义双轨——本题考“出生方式”与“词汇史旧账”不是一回事。
:::
:::

::: quiz
判断网络词能否留存，最靠不住的依据是（　）。
- [ ] 跨圈层使用
- [ ] 能产性
- [x] 当期使用总量
- [ ] 是否被严肃语体引用
::: solution
总量是必要条件而非充分条件：“蓝瘦香菇”当年刷屏级，仍速死；留存看的是穿透圈层、派生能力与正式文体引用。
:::

::: quiz
“被就业”现象说明（　）。
- [ ] 汉语被动式已消亡
- [x] 高频语法结构也能被赋予新的表达功能
- [ ] 网络语没有语法
- [ ] 动词发生了名物化
::: solution
“被＋不及物动词/动词”的非法式合法化，给整个结构罩上讽刺框——**语法结构的新词化**，是“网络语没语法”论的最优反驳。
:::

::: exercise 词史分层 {level=1}
把下列词按“沉淀／退潮／速生速死”归档并各说一条判据：给力、小姐、个体户、点赞、神马、文创。
::: solution
沉淀：点赞（跨圈＋能产＋严肃语体引用）；退潮：个体户（政策语退位，成时代标签词）、小姐（贬降后公共称谓回避——“语义退化型退潮”）、神马（“什么”的谐音旧梗已谢）；速生速死／半沉淀：给力（曾刷屏，今口语局域存活、主流媒体少用——判“半沉淀”并说明即可）、文创（新常规化中）。判分看证据意识，不求唯一归档。
:::
:::

::: exercise 造词实践 {level=2}
用四种出生方式各造一个新词（要能进入真实语境），各配一句使用例句，并预判其衰变三段式落点。
::: solution
示例：构词——“自习化”（自习＋化：全民自习室时代的自我进修）；赋义——“爬”（像爬虫一样搜集数据：“我在爬价格”）；字母——“AI 味”（仿“人味／水味”的类缀用法：一眼假的机器腔）；泛化——“孔乙己”（文学人名泛指“被学历困住的年轻人”）。预判附理据（跨圈？能产？缝隙？）即可。
:::
:::

::: exercise 小论文：AI 是新词生产者还是终结者 {level=3}
大模型批量产出标题词、营销语，也实时翻译一切外语词。写一篇八百至一千二百字短论：预测 AI 时代汉语新词语的出生率、死亡率与“借词波次”是否改道？要求：引用本课“衰变三问”框架、一条你自己观察的 AI 生成词证据（如“赋能、闭环、颗粒度”在 AI 语境中的再扩散），并给出可检验的判断。
::: solution
判分点：区分“生产”（模型采样旧搭配）与“造词”（社区赋义）——AI 是**放大器**非造物主；衰变三问逐条用于 AI 热词（“赋能”跨圈已久、能产、已入严肃语体，判沉淀；纯模型口癖词判速死）；预测可检验（如“未来十年字母借词占比下降/上升，依据是自动字幕+实时翻译消灭了理解缝隙”）；概念无混用（不混淆“流行语榜”与“规范”）。
:::

::: summary
新词语四种出生（老构词法加班、旧词赋义、字母数字、专名泛化）＋网络六兵器（缩略、谐音、旧字新值、框式填槽、混排、方言借调）；衰变三段式（爆发—溢出—常规化/死亡）与三问（去语境可懂、能产、正式语体引用）是全部预测学；淘汰率九成是常态。语域错配≠语病、代际差≠衰亡、排行榜≠规范。国家对词潮的角色已从立法者变记账员——语言生活最大的制度变化。AI 时代的词潮将更快、更卷、更跨国，但“被社区赋义才算生”的门槛，机器暂时代不了工。
:::
:::
