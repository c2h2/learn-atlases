title: "语素与词"
---

“我喜欢她”五个字、五个音节、五个词——运气好时三套账目对得上；可“我喜欢她**们**”多了一个语素不加一个字，“**葡萄**牙”三个字只是一个语素加两个，“**洗了一个澡**”的一个词被时量补语劈成两半。汉语语法里最基础也最麻烦的问题就在这本对不上的账里。本课发三把尺子：**语素、词、短语**各是什么，怎么量。

## 四个“最小”，别混 {#sec-sige}

::: definition 语素、词、短语 {#def-sany}
**语素**（词素）是最小的**音义结合体**——不能再分而仍有意义的单位：“人”“民”“罗”（罗盘之罗单看无义，“萝、锣”各是另一语素）。**词**是最小的**能独立运用**的音义结合体：能单说（“谁来了？——人。”）、能单用做成分、能带语调成句。**短语**是词按规则临时组装的音义结合体（“白石桥”可以，“白苹果”别扭——短语的合成受规则与语义双重约束）。至于**字**，那是书写单位；**音节**是发音单位。汉语的麻烦与魅力，都在于“字、语素、音节”三者**大致**重合而处处例外，于是“字”常被误当“词”。
:::

::: theorem 字 ≠ 语素 ≠ 词：三类反例 {#rule-budeng}
①**一字不是语素**：连绵词“蜘蛛、蜻蜓、窈窕”与联绵式的双音单纯词“蝴蝶、鸳鸯”，以及音译词“沙发、巧克力、麦克风”——“沙发”两个字各无所指，合起来才是一个语素；②**一字多于两语素**：同形字“花₁（花草）／花₂（花钱）”在词典里分立条目——一个字位打包了互不相干的几个语素；③**语素不总是词**：“语素”“民”“谓”“第”能产而**不自由**（不说“我民”“很第”）。三张反例牌立住，就明白“3500个常用字”与“掌握3500个词”根本不是一回事——对外汉语的教学事故，一半出在拿字当词。
:::

::: example 三步切分：给“他养了一头奶牛场的牛”做成分手术 {#ex-qiefen}
先切语素，再定词界，最后标短语层次。注意“奶牛场”与“奶 牛场”之争正演示词界问题的真实样貌。
::: solution
语素层：他｜养｜了｜一｜头｜奶｜牛｜场｜的｜牛（“了、的”为虚词语素，“一”变调仍是一语素）。词层：“奶牛场”是一个名词（饲牛之场）；“奶／牛场”的切法语义立不住，判误切。短语层：他／养了／一头奶牛场的牛——量词“头”把“奶牛”锁成义团，恰好逼出“奶牛场”的整体读法。一句话里，语素—词—短语三层各行其法，这正是汉语“没有形态却层层有法”的入门标本。
:::

## 词的判定：替换、扩展、凝固 {#sec-panci}

::: definition 扩展法（插入测试） {#def-kuozhan}
在两个语素之间插入必要的虚成分，能插且意义相关的多半是**短语**（“黑板”不能插 *“黑的板”而指同一物→词；“白饭”可说“白米饭/很白的饭”→偏正短语性更强）；插不进或插上变义的判为**词**。这被称为“扩展法”，是五十年代以来汉语词界讨论的操作核心。它的三处软肋要记账：①**离合词**——“洗澡、睡觉、理发、游泳”能扩展（“洗了个热水澡”）却仍被语感判为一个词，黄伯荣、廖序东本《现代汉语》以“意义整体＋可分可合”处理，承认汉语词界有**弹性带**；②**固定短语**——“车水马龙”插不进去却也是语（成语），扩展法只判“像不像词”，不判“是不是词”；③**频率固化**——“电脑”扩展出“大的电脑”没人说不通，但没人会因此说它是短语：**词性是用了多少次决定的，不是哪一次决定的**。
:::

::: example “南京市长江大桥” {#ex-nj}
给这条著名歧义串做两种切分，并说明机器（输入法/分词器）与人各靠什么消歧。
::: solution
南京市／长江大桥（一个地名偏正短语）或 南京／市长／江大桥（荒诞读法）。人靠**语义与常识**（“长江大桥”是高频专名整体）；统计分词靠**二元/多元词表＋语言模型**：若“南京市”“长江大桥”都在词频表高区位，组合得分完胜“市长江”。这正是汉语信息处理必须先“分词”的根源：**书面汉语词间无空格，词界是推断出来的**——1992年《信息处理用现代汉语分词规范》（GB 13715）与历次国际评测（SIGHAN Bakeoff 2005起）把这门推断变成了产业工序。
:::
:::

::: intuition 母语者说不清“词”，这件事很重要
让受试给句子划词界，汉语的标注一致性高（95%上下）却不是100%：分歧集中在**类词缀**（“读者、歌手”的“者、手”）、**离合词**（“见面”算一个词还是动宾短语）与**专名**（“北京大学”切二还是切四）。有人据此说汉语根本没有“词”这个单位；更公道的读法是：汉语的“词”是一个**原型范畴**——核心成员（“山、水、电脑”）边界清楚，边缘成员（“看得见”的补语、“洗了澡”）向短语渐变。语言学任务不是宣布范畴不存在，而是描出这片渐变滩涂上的高水位线——规范词典与分词标准就是那条线。
:::

## 语素的家族 {#sec-yusu}

::: definition 定位分类 {#def-dingwei}
按**能否单用**：自由语素（“人、跑、很”）／不自由语素（“民、语、第、老-、-子”）；不自由语素再分**词根**（有实义：“民”“语”“桌”）与**词缀**（意义虚化、位置固定：“老-、第-、子、儿、头、们”等，派生专讲见下一讲）；按**音节数**：单音节语素绝对主体，双音节连绵与音译（“琵琶、逻辑、幽默”），三音节以上几乎全是译名（“巧克力、达尔文、奥林匹克”）；按**产义方式**：本族语素／文言留存（“之、乎、其、所”不口语而高产）／方言进入（“搞、俺、啥”）／外来（“咖啡、基因”）。
:::

::: example 数语素专项 {#ex-shu}
数出“玻璃葡萄架、旧博物馆、智能化、奥林匹克运动会”各含几个语素。
::: solution
“玻璃葡萄架”：玻璃(1连绵)+葡萄(1连绵)+架(1)＝3个语素、5个字；“旧博物馆”：旧＋博＋物＋馆＝4（“博”入“博识”、物入“物体”、馆入“展馆”，三面替换皆立）；“智能化”：智＋能＋化＝3（“智、能”各自成素，“-化”是词缀）；“奥林匹克运动会”：奥林匹克（一个多音节语素）＋运＋动＋会＝4（“运”单用无此义，若按联合式双音根记“运动”一素，则三素亦通——说理清楚即给分）。本题价值全在**说理**：连绵、音译、词缀、复合四件事各识破一处即达标。
:::
:::

::: history “词”如何进入汉语的自觉 {#sec-cijinchu}
传统语文学有“字”无“词”：《说文》解字，《尔雅》以“词语”为训而不论“词”之何物。1898年《马氏文通》借拉丁“ partes orationis ”立汉语“字类”，“词”作为语法单位第一次被命名；1950年代“词和词的分界”大讨论（教学语法体系与汉语汉语语法丛书诸家交锋）确立了“能独立活动的最小意义单位”的定义与扩展法的标准地位；1992年分词国标把争论成果铸成信息处理的地基；21世纪大语料时代，词由语言学概念变成**计算实体**——每部输入法、每台机器翻译的“汉语感”里都住着一套词界。一个百年前借来的单位，硬是被汉语用了回来。
:::

::: summary
语素是最小音义结合体，词是最小独立运用单位，短语是词的规则组装；字（书写）与音节（发音）常与二者对齐而处处不对齐——连绵、音译、离合词是三大错位源。判定靠三板斧：替换（替代定同一性）、独立运用（单说/成句）、扩展（插得进的偏短语），外加频率固化与语义整体作缓冲；“词”是原型范畴，边界带（词化短语、类词缀、专名）交由规范与语料划界。语素按自由/黏着、单/多音节、本族/文言/方言/外来多维归类。字不等于词，是识字教学、对外汉语与信息处理共同的第一课。
:::

“巧克力”包含的语素数是（　）。

音译多音节词是**一个**多音节语素：拆开的“巧”“克”“力”与此词意义无关（“巧克力”的“力”不表“力量”，只记音）。

::: quiz
用扩展法判断，最像短语的是（　）。
- [ ] 火车
- [x] 白饭
- [ ] 黑板
- [ ] 领袖
::: solution
“白米饭/很白的饭”扩展自然且关系透明，偏正短语性强；“火车”非“火与车”、扩不得；“黑板”不说“黑的板”；“领袖”整体借义、扩展即破（领与袖分开是衣裳部件，非“带头人”义）。
:::

- [x] 该片段对应几个汉字
- [ ] 相同语音形式的片段能否互相替代

::: exercise 离合词档案 {level=1}
“见面、跳舞、帮忙、游泳”常被说成“能分开的词”。各造一个扩展句，并依扩展法与语感各记一笔账：它们卡在哪条规则上？
::: solution
见了一面／跳了三年舞／帮了他大忙／游了泳（“游了个泳”亦通）。卡点：扩展法判短语、语感与词典判词；教材解法是承认“可分用的离合词”为词与短语之间的过渡带——记录此“两账不平”本身即本题标准答案。
:::
:::

::: exercise 同形破拆 {level=1}
“花₁花钱／花₂开花”“老₁老虎／老₂老人／老³老是”各组一个判断框架：它们分别是一字多语素还是一个语素多义？
::: solution
花草义与花费义在日常语感中联系已断，词典分立处理更稳——判**同形异素**；“老虎”的“老”是前缀（不自由），“老人”的“老”是能单用的词根，“老是”的“老”虚化为副词性语素——三个不同语素（同音同形而性质各异），《现代汉语词典》分立“老¹²³”即此立场。方法词：看**意义关联存亡＋能否独立**两条。
:::
:::

::: exercise 分词实战 {level=2}
按《信息处理用现代汉语分词规范》的精神（词典切分优先），给下句切词并标出三处你犹豫的地方及取舍理由：“他去年在北京大学东门外新开的那家奶茶店买过一杯珍珠奶茶。”
::: solution
他/去年/在/北京大学/东门外? 或 东门/外／新开/的/那/家/奶茶店? 或 奶茶/店／买/过/一/杯/珍珠/奶茶。三处犹豫示例：①“北京大学”整体专名 vs 北京/大学（GB倾向整体，校名类词典词）；②“东门外”方位合成（倾向 东门/外，方位词独立）；③“奶茶店”词汇化程度（新兴行业整体高频，可整体；“珍珠奶茶”整体为菜名条目更无争议）。本题不求唯一正确，求**每处有依据**。
:::
:::

::: exercise 小论文：字本位有没有道理 {level=3}
有学者主张汉语语法应“字本位”而非“语素/词本位”（冯志伟、陆俭明诸家对“字”的讨论各有立场，任取一家观点）。写一篇八百至一千二百字短论：以本课三处判定难题（离合、连绵、词缀）为材料，评估“字本位”的得与失。要求同时举出一个字本位解释不动、一个词本位解释不动的例子。
::: solution
判分点：把“字本位”理解为**教学与分析的切入点选择**而非文字学立场；能用“葡萄/洗澡/老-”三个难题演示词本位的边界成本；“字本位解释不动”的好例：连绵词（“玻璃”的字完全无义）、“们/第”等不见于字面的语法语素；“词本位解释不动”的好例：成语与惯用语中字的独立活动性（“唯利是图”之“是”）。立场无须统一，逻辑必须自洽；把“汉字”与“语素”混用的作文直接判重做。
:::
