---
title: "外来词"
---

一个说汉语的人每天不自觉地说几十句“外语”：“世界”是译经僧的笔译，“站”是蒙古帝国的驿站，“逻辑”是音译，“沙发”也是。外来词是词汇的**移民登记册**——本课读这本册子：移民怎么进来（机制）、几潮进来的（波次）、进来后怎么换身份证（适配）。

## 四种进法 {#sec-sizhong}

::: definition 外来词的取义机制 {#def-jizhi}
**纯音译**：全用记音字——沙发（sofa）、麦克风（microphone）、拉丁字母时代前的“德律风”（telephone）、咖啡（coffee，经荷兰语转手）、幽默（humor，林语堂 1924 年试译定名）。
**音译加意译类别词（半音半意）**：记音部件＋类属义符——啤酒（啤＝beer 首音＋酒）、卡车（卡＝car＋车）、坦克（tank＋车）、芭蕾舞（ballet＋舞）、汉堡包（Hamburg＋包）、新西兰（Zeland 尾音“兰”兼取义）。
**音义兼译（谐音配义）**：选字兼勾义——可口可乐（Coca-Cola）、哈佛（Harvard）、俱乐部（club）、基因（gene）、维他命（vitamin，与“维生素”并存竞争）。
**借形与仿译**：日语用汉字意译西语再回流的“和制汉语”（哲学、经济、社会、共和国、主义）；拉丁字母词直接入住（GDP、WTO、KTV、App）。
:::

::: theorem 音译词的汉语化四压 {#rule-siya}
外来音译进来要过四道整形：**①单音节化压缩**——多音节原词收进两三字（Moskva→莫斯科，steering→方向盘是弃音取义的例子；“的士”的“的”被抠成语素，打出“打的、的哥”整个词族）；**②类属加冕**——给记音符补个汉语义类头（啤＋酒、卡＋车、巴蕾＋舞），不戴帽子不认户口；**③声调分配**——每个记音字被强派五声（sofa→shāfā 阴平×2，hacker→hēikè 顺手变“黑”客兼义）；**④字形择美择俗**——选字自带气场：可口可乐雅俗共赏，早年“蝌蚪啃蜡”式的失败译名（Coca-Cola 曾有的直译噩梦）正是反面教材——**记音字不记音，先记脸面**。四道压力共同解释了：为什么汉语外来词长得越来越不像外语。
:::

## 五波移民潮 {#sec-wubo}

::: history 梵音东来：佛经翻译的第一波高潮 {#sec-fanyu}
东汉至唐的译经运动送来汉语史上第一波大规模外来词。**纯译**：佛陀（Buddha，省作“佛”）、菩萨（bodhisattva 省译）、罗汉（arhat）、刹那（kṣaṇa）、劫（kalpa“劫波”之省）、塔（stūpa“兜婆/塔婆”之省）、魔（māra，本字“麻”别写）、阎罗。**义译造词**：“世界”——“世”迁流（时间）与“界”方位（空间）在经论中合成双音抽象词，此词日后长进基本词汇，今人诵“世界观”时已无人知它来自恒河。翻译还养活了整套译音构词法（五不翻原则的唐宋讨论），是中国第一门系统译学。
:::

::: example 和制汉语：回流的“汉字词” {#ex-hezhi}
“哲学、经济、社会、主义”被称“和制汉语”，可它们字字是古汉语旧料——这笔账怎么算？
::: solution
三层账：**字形与词料**是中国的（“经世济民”省“经济”、“世”“代”更替——旧词都在）；**“旧词新义”的嫁接手术**多半在日本明治学者手里完成（西学概念进东亚，先经日本译界配词，如“哲学”之于 philosophy）；**再回流**由中国留日学生、译书（乙巳、丙午间大量政译书）输入国内。结论：叫它“日语借词”对机制（语义借词经日语中转），叫它“汉语材料自造”也对构形——两说不是打架，是**在不同层面记账**。真正该纠的错误印象有两个：一是“日语发明了汉字词就绑架了汉语”（材料是我们的，订单是西方的，中介是日本）；二是凡双音抽象词皆和制（因果、世界早来自佛经，时代差着一千多年）。
:::
:::

::: example 字母词入境卡 {#ex-ziimu}
“GDP、WTO、KTV、AA 制、App”——它们算外来词吗？规范怎么处理？
::: solution
算**借形词**：不转写语音、不译义，整块搬字母（汉语语法照常给它们当名词/状语用：“上 GDP”“查 App”“用 AA 制”）。规范处理有两条路：**配对名**（WTO→世贸组织，双轨并用；媒体首次出现以中文全称括注）与**收入词典**（《现代汉语词典》增字母词附录曾惹笔仗）。2010 年代广播曾下达“慎用字母词”的限令并遭舆情顶回，落点是可理解性优先：对公众透明的（KTV、GDP）通行，小众装腔的（自造缩写）自然淘汰。字母词的活跃恰好证明：**汉语消化外来的最新器官，是“零翻译”的直筒胃**。
:::
:::

::: warning 外来词判断三坑
（1）**民间词源**：“胡同＝蒙古语”之说流传广而材料弱（一说源于“水井”的比附缺史证），标“一说”才是学术姿势；反例：戈壁（蒙古语“砾漠”）、萨其马（满语）证据结实；（2）**忘恩负义**：把“电话、世界、经济”当纯本土词教学——词史无痕，但理据层有账；也**反向忘义**：把“咖啡”的阿拉伯语血统（qahwa）当它的汉语身份；（3）**把借用当取代**：字母词、日本词潮每次都被宣判“纯洁性危机”，而汉语词汇系统扩容始终靠来者不拒——**词汇纯洁是修辞，不是语言学**。
:::

::: intuition 你的第一语言里住着几门外语
数一数：一节课里说出的“世界、哲学、逻辑、沙发、的士、摩登、麦克风、刹那、站、戈壁”——十余门外来血统。语言纯度测试通不过的从来不是汉语，而是“纯度”这个概念本身。
:::

::: exercise 机制归类 {level=1}
给下列外来词开“入境卡”（原词＋机制＋汉语化痕迹）：基因、麦克风、汉堡包、俱乐部、WTO。
::: solution
基因（gene，音义兼译：“基”兼表根本义）；麦克风（microphone，纯音译，口语再省称作“麦”）；汉堡包（Hamburg＋包，半音半意＋类属）；俱乐部（club，音义兼译，“俱乐”二字自带欢乐义场）；WTO（字母借形，规范上常配“世贸组织”双轨）。入境卡两栏齐全即过。
:::

::: exercise 译名优劣评审 {level=2}
Coca-Cola 曾有“蝌蚪啃蜡”的失败旧传，后有“可口可乐”；hacker 定“黑客”，而“骇客”未选。据“四压”各写一条评析，并自拟一个你认为更好的未译词方案（原词自定）。
::: solution
评分点：用“择美/类属/声调/单音节化”逐条对照（可口可乐：四音节全保留＋四字全带正面义＝双关天花板；黑客：“黑”抢注了语义色彩，比中性的“骇客”更贴地下身份，但已导致 hacker 与“白帽”混淆——可讨论）；自拟方案须真过四压（如把某长词收进两字并戴类属帽）。
:::
:::

::: exercise 调查 {level=2}
记录自己 24 小时口语/文字里的外来词（含字母词），按五波分类统计比例；判断哪一波已“完全汉化”（母语者不再意识到外来身份）。
::: solution
示例结论：梵语波与阿尔泰波几乎全员失忆（世界、刹那、站、萨其马无一让人想到外语），欧语—和制波半自觉（逻辑、哲学仍可被指出），英语波全自觉（KTV、App 挂着字母身份证）——**外来词的“血统可见度”与借入年代成反比**，这正是汉化压力的存在证明。统计真实即给分。
:::
:::

::: exercise 小论文：和制汉语是不是“我们的”词 {level=3}
围绕“哲学、经济、社会”写八百至一千二百字短论：语言史的所有权问题对今天的词典标注、语文教育与中日文化话语各意味着什么？要求引用本课“三层账”框架、一个反例（佛经层或当代英语层），并说明你反对的一种流行误用。
::: solution
判分点：三层账用得干净（材料／手术／回流各归各位）；能识破民族主义叙事对词汇史的两种征用（“日本偷了汉语”／“汉语被日语殖民”都是把机制账记成了领土账）；词典处理有方案（如和制义源标注法：义栏注“日本译××，回流”）；立场清晰、反例准确。
:::

::: summary
外来词四种进法：纯音译、音译＋类属、音义兼译、借形仿译；进来要受汉语化四压（音节压缩、类属加冕、声调分配、字形择美）。五波移民：译经梵语（世界·刹那·塔）、征服王朝阿尔泰语（站·戈壁·萨其马）、明末清初欧语（几何·轻气养气）、清末民初和制汉语（哲学·经济·主义）、当代英语（基因·秀·字母词）。和制汉语要分三层账（字料中国／手术日本／回流留学潮），把词汇血统记成领土所有权是双重误读。词汇纯洁是修辞不是语言学——汉语的强壮从来靠消化，不靠关闸。
:::
