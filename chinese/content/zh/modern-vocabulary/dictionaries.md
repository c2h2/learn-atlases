title: "词典与工具书"

前八课的全部判断——这是语素、那是离合词、这个词义是引申——最终都要回到一个可以拍案质证的地方：**词典**。本课教你把工具书用穿：认门道、读凡例、查得准、比得出，顺带看这门千年手艺怎么从竹简走到搜索框。

## 工具书家族与门道 {#sec-jiuzu}

::: definition 三型加杂项 {#def-sanxing}
**字书**以字为条目，管形、音、义三账：《新华字典》（1953 年初版，魏建功等名家先后主编，世界印量级的国民工具）、《康熙字典》（1716，214 部）、《汉语大字典》（逾六万字，古文字与书证齐备）。**词（语言）典**以词为条目，重搭配与用法：《现代汉语词典》（1978 年初版，吕叔湘、丁声树先后主持编写，词类标注自 1993 年修订本全面引入）、《现代汉语规范词典》。**语典／百科**收典故名物：《辞源》（1915，商务，古籍阅读专用）《辞海》（1936，百科一路）。杂项：成语词典、同义词词典（辨析型是汉语特色）、方言词典（《现代汉语方言大词典》42 卷）、古文字编、韵书与字源手册。选书如选药：**读古籍配《辞源》《汉语大字典》，写文章配《现汉》与辨析词典，查字源配修订后的《说文》系工具**。
:::

::: theorem 词典的两副面孔：规范与描写 {#rule-guifan}
读词典把“尴尬”注成 gān gà 之外的一切读法都视为待校——那是纠偏提示；
:::

## 把一本词典用穿 {#sec-yongchuan}

::: example “打”字全传 {#ex-da}
查《现代汉语词典》“打”字条：记下它的读音数、义项数，找出一个书面语标记义、一个口语标记义，以及词典如何处理“打电话、打酱油、打酒”的归部。
::: solution
“打”两读（dǎ／dá，量词“一打”来自 dozen 音译——注意词典在“dá”义项后不标外来来源，那是《现代汉语外来词词典》的活）；义项近二十，从“击”本义放射：抽象义（打官司）、介词性熟语（打他那儿路过）、构成动相补语（打听到）。“打酱油／打酒”类“买”义常标〈方〉或收在复词“打酒”条下——**词典用“方、书、口、谚”四个小三角把语体地层缝进版式**（[[chinese-characters/standard-characters]]讲过的色彩轴在词典里的落款）。查完一字，等于上完一学期词汇课。
:::
:::

::: example 会读凡例的人不吃亏 {#ex-fanli}
《现汉》凡例声明：异读词从《普通话异读词审音表》；简化字、异形词以国家规范为准。据此回答：为什么同一本书里“消息”注轻声而“消息”古义不注？“笔画／笔划”为何以“笔画”为主条？
::: solution
（现行依据是 1985 年《普通话异读词审音表》；2016 年新的审定稿公开征求意见后一直未正式颁行，个别字音的调整随之悬置——词典因此“不改口”，正是程序一致的示范。）
:::
:::

::: intuition 词典的“权威”来自哪里
不是来自编者头衔，而是来自三件笨功夫：**证据的规模**（《现汉》建库早，手工卡片数十万条；《汉语大词典》千人名家会战十余年）、**程序的一致**（凡例即宪法，人人按同一定义与分立标准操作）、**修订的诚实**（一年一错的网站没人骂，十年不改的大典人人骂）。AI 时代这三件更值钱：模型能给“定义”，但给不出“可追责的编辑程序”——这就是为什么大模型答词义时仍要**引典**。
:::

::: history 从卷轴到搜索框：工具书的三次形态革命 {#sec-xingtai}
第一次，**类书与韵书的分类时代**（《尔雅》按义分类、《佩文韵府》按韵编排），检索靠背诵目录；第二次，**现代卷册时代**（《辞源》以降：部首笔画字母多套检字法并行、正文＋附录＋插图、凡例成文、版权页写清“第几版第几次”），工具书变成**工程产品**；第三次，**数据库时代**：《汉语大字典》《故训汇纂》纸质版与数字化并行（四川大学等团队的辞书数据库、汉籍全文库、字源字形库）；手机上《新华字典》APP（2016 起，内置手写与语音查字）、《现代汉语词典》APP 付费下载；国家层面建有国家语料库与“国家语言资源监测与研究中心”（2020 年挂牌）供词频与监测。形态在变，行话不变：**收得全、分得清、例得实、检得快**——四得之中，搜索框只解决了第四条。
:::

::: warning 工具书使用的四个误会
（1）**把词典当法律**：词典义项是分岔地图不是路单，文学写作里“词典没这个义项”不等于“用错了”（语言共同体先于词典）；（2）**跳读词头不读整条**：只查第一个义项，错过〈书〉〈方〉标记与“按”语，是误用的头号来源；（3）**一本词典吃遍天下**：用《新华字典》查“哲学”、用《辞源》查“内卷”，都是拿错了显微镜；（4）**把在线翻译与问答当工具书**：它们没有版本、没有责任主体、没有可回溯的编辑程序——可以问路，不可以立此存照。
:::

::: exercise 词条建档 {level=1}
任选“老、上、开”一字，为它在《现汉》中的全部义项建一张表（序号、语法类别、典型例、语体标记），并数出辐射中心。
::: solution
表齐、类不错（注意动词后挂介词“打他从这路过”类）、语体标记照录即合格；指出义项 1（如“老”年岁大）为多数支链的辐射中心者加。
:::
:::

::: exercise 双典对比 {level=2}
“下”字，《现汉》与《辞源》各查一次，写出两书处理同一词头的三点结构差异（立目单位、义项取向、书证有无）。
::: solution
①《现汉》字头下挂词组与“～”式例，“下”按动／形／方（方位）分义项；《辞源》以**复词与典故**立目（下问、下走、陛下各为条），无现代口语“下棋”位；②《现汉》义项按今频，《辞源》按古书源流；③《辞源》每条必注书证出处，《现汉》例多无出处。结论：一今一古、一词一典。
:::
:::

::: exercise 纠错实战 {level=2}
一段推文写道：“这项政策应予以嘉奖”“他的成绩不孚众望”“二人一拍即合，狼狈为奸地干了起来”。请说明三处该查词典的哪个位置（词类？色彩？搭配？）并改正。
::: solution
①“予以”词类与格式（予以＋动词性宾语）→“应予嘉奖／予以奖励”；②“不孚众望”＝不能使众人信服（贬），常被当“不负众望”（符合）——查“孚”字条＋成语条用法码；③“狼狈为奸”贬义误作合作褒义——查条目〈贬〉或语感栏。改：嘉奖改奖励、不孚改不负、狼狈为奸改齐心协力。三问各对应词类、成语整体义、色彩栏。
:::
:::

::: exercise 小论文：AI 会取代词典吗 {level=3}
以本课三件笨功夫（证据规模、程序一致、修订诚实）为框架，写一篇八百至一千二百字短论：大模型的“词义问答”与词典的功能重叠与不可替代处各在哪里？预测未来十年词典业的形态。要求引用至少两处你使用两部工具书的真实经历、一个“按”语或凡例例证，并解释“版本责任”概念。
::: solution
判分点：重叠分析（查定义、配例句）与不可替代分析（版本可追责、收词透明、修订程序）；引用真实（书名＋版次＋一次具体查得）；“按”语例证准确；预测具体且可检（如：主流词典将以“词典＋API＋监测年报”三件套出售，纯纸质退居收藏与规范公告）。把 AI 神化或妖魔化者，均按论证质量而非立场评分。
:::
:::

::: summary
工具书分字书、词典、语典三型加杂项，各管一层：现代音义用法归《现汉》，古籍典故归《辞源》，字源归大字典。词典两副面孔——描写之眼与规范之手——读法是先读凡例、再读整条、注意〈方〉〈书〉与“按”语。权威来自笨功夫：证据规模、程序一致、修订诚实。从卷轴到卷册到搜索框，三次形态革命没换掉行话“收分例检”，只把“检”做到极致。词典不是法律，但是目前人类词义知识最负责任的账本——用穿它，是词汇课终点，也是自学的起点。
:::
