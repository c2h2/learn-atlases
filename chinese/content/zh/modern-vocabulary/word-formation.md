---
title: "构词法"
---

上一课立了语素与词，这一课看它们**怎么组装**成词。汉语组装词的三大工序：**复合**（词根＋词根）、**派生**（词根＋词缀）、**重叠**（语素自配）。三者之中复合占绝对优势——汉语因此被类型为“复合法发达的分析语”。

## 五种复合式 {#sec-wuzhong}

::: definition 复合式词的内部句法 {#def-fuhe}
两个词根的组合关系与传统句法成分同构，分五类：
**联合（并列）式**——“朋友、道路、买卖、开关、窗户、国家”：语素平起平坐；注意两类现象：“窗户”“国家”义偏其一（**偏义复合词**），“买卖”则由两语素整体泛化为“生意”一义。
**偏正式**——“火车、雪白、快速、微波炉”：前根修饰后根（“火车”是以火为动力之车，“雪白”是像雪一样白）。
**动宾（支配）式**——“司机、管家、注意、投资、洗澡”：后根是受事，“司机”是“司其职”之“司＋机”（掌管机器者），不是“驾驶机器的人”这种整句压缩式误析。
**动补（补充）式**——“提高、推翻、改变、学会、改正”：后根补说前根的结果，这一式**能产极旺**（结果补语复合词是新词机器）。
**主谓（陈述）式**——“地震、心疼、海啸、日食”：前根是主题、后根陈述之。
:::

::: theorem 结构判定看“历史层次＋现时透明”双标准 {#rule-liangzhun}
真正的麻烦是**重新分析**：如“司令”本为动宾（司＋令），今人已看不见“司”的动词义，语感把它整个当成职务名词——结构义与重分析的分歧，本身就是层次感的活教材。标准操作：查成词理据（词典源流栏）→ 对照现时替换框架 → 若两可，报告两可——结构歧义是构词法的常驻人口，不是事故。
:::

::: example 逐词判定八连 {#ex-balian}
判断结构式：地震、雪花、提高、民主、火热、注定、司令、笔直。
::: solution
民主——现代译词析主谓更顺（人民作主）；循古义“民之主”则属偏正，两说皆可
:::
:::

## 派生：词缀与“类词缀” {#sec-paidu}

::: definition 词缀三件套与名词化小品 {#def-cui}
**前缀**：老-（老虎、老大、老王——“虎”不靠“老”表义）、第-（第一）、阿-（阿爸、阿Q）；**后缀**：-子（桌子、罩子——完全虚化；对比“莲子、种子”里仍作“子实”讲的词根“子”）、-儿（花儿、玩儿、门儿——北方话色彩，且兼别义别类：头（脑袋）对头儿（领导、端头））、-头（石头、甜头、苦头）；中缀汉语没有系统的，略。“桌**子**”的“子”与“莲子”的“子”之别即**词缀与词根**之别：前者意义蒸发、位置能产，后者还揣着“子实”义。
:::

::: theorem 类词缀：汉语最活跃的造词中间层 {#rule-leicui}
在“纯词根”（桌）与“纯词缀”（老-）之间有一条宽带：**类词缀**——意义半虚、位置固定、高产。当代汉语的在册名单：**～化**（现代化、绿化）、**～性**（可读性、确定性）、**～者**（读者、作者）、**～员**（演员、售货员——“员”本有实义，今作为职务类能产）、**～手**（歌手、高手）、**～热**（旅游热）、**～坛**（体坛、影坛）、**～盲**（文盲、科盲、股盲）、**～吧**（网吧、书吧）、**～门**（由“水门事件”泛化出的丑闻后缀）。判断三问：意义是否半虚？位置是否固定（一律在后）？能否批量接新（每周都有）？三问全过，就登记入册——这条“语法化进行中的生产线”正是汉语构词法最性感的地带。
:::

::: example 给新词开出生证 {#ex-chusheng}
“考研、内卷、逆袭、躺平、元宇宙、晒娃”各属哪道工序？
::: solution
考研（动宾式复合：考＋研〔究〕——“研”是缩略来的语素，见下文缩略一节）；内卷（偏正：内＋卷，挤压式竞争义为新造）；逆袭（偏正——“逆”修饰“袭”的方式）；躺平（连动式复合：躺而平之——汉语也收“打架、起床”一类连动造词）；晒娃（动宾＋语义借用：“晒”经英语 share 的“展示”义取得新功能，字形未动）；元宇宙（“元＋宇宙”的偏正装架，按 metaverse 译法仿造）。一道题串起五种工序，说明构词法标签是**分析坐标**而非互斥抽屉。
:::
:::

## 重叠与其他工序 {#sec-chongdie}

::: definition 重叠式 {#def-cd}
语素或词的自我重复：**AA** 成词——妈妈、常常、渐渐（叠音名词与副词，重叠是**构词**手段）；**重叠成形态**——“高高”“干干净净”“研究研究”（重叠不加新词，只给原词添程度、全量、短时尝试等**语法意义**，属**构形**，ABB 红彤彤、AABB、ABAB 各族同此）。一枚操作、两副面孔：**构词与构形的分界**在此露脸。
:::

::: history 缩略与“简称产业”：汉语构词的第四道工序 {#sec-suolue}
复合、派生、重叠之外，现代汉语还有一条批量产词线：**缩略**。例子：北京大学→北大、科学技术→科技、人民代表大会→人大、奥林匹克运动会→奥运会、高速铁路→高铁。机制分四类：**提取式**（并列项各取一头：科技、清华北大→清北）、**括约式**（取外框缀核心：立交桥、首都机场）、**数字式**（三好学生、双减、三农）与**统称式**（公安＝公＋安并列凝合一类）。1950年代以来缩略词井喷（扫盲→知青→两弹一星→高铁→双减），时代序列一目了然——缩略是**行政与传媒节奏**喂给构词法的饲料，汉语新词史半部是缩略史。
:::

::: warning 构词分析的三个坑
（3）**类词缀当纯词缀**：“～盲”还带着“看不见某领域”的意象活性——“科盲、股盲”成立，“色盲”另属医学术语一家——能产性高不等于意义蒸发，**语法化是梯度不是开关**。
:::

::: example 重叠的语法意义清单 {#ex-cdqd}
写出“高高、干干净净、研究研究”三组重叠各给原词添了什么意义。
::: solution
高高（程度加深，“高得过分/很”义——形容词重叠兼状态描写性）、干干净净（量级充满：全部且彻底——“重叠表全量/程度强化”）、研究研究（**短时尝试**体：动词重叠的“一下”义内置）。三种语法意义（程度、全量、时量）都**不由词义提供而由重叠形式提供**——这就是把重叠划入形态操作的理由；AA 名词“妈妈”则无此类附加义，属构词性重叠，两案分开归档。
:::
:::

::: quiz
“提高”的复合式是（　）。
- [ ] 偏正
- [ ] 动宾
- [x] 动补
- [ ] 联合
::: solution
“提”是动作、“高”是结果补语——动补式；该式能产（推翻、改正、打倒、学会），是汉语新词的重要产线。
:::
:::

::: quiz
下列“子”属于词缀（而非词根）的是（　）。
- [ ] 莲子
- [ ] 种子
- [x] 筷子
- [ ] 子弟
::: solution
“筷子”的“子”无实义、位置固定、能批量接 X——典型名词后缀；莲子、种子的“子”仍表“子实”，子弟之“子”更是本义“儿子辈”。
:::
:::

::: quiz
属于“类词缀”特征的是（　）。
- [ ] 意义完全蒸发
- [x] 意义半虚、位置固定、高产
- [ ] 只出现在连绵词中
- [ ] 必须有轻声
::: solution
类词缀的定义三问：意义半虚（“～门”离开水门专名）、位置固定（一律后置）、能产（批量造新）。“完全蒸发”是纯词缀标准（老-），连绵词与轻声与此无关。
:::

::: exercise 出生证 {level=1}
给下列新词各写一张“构词出生证”（工序＋内部式＋理据）：高铁、点赞、班味。
::: solution
高铁＝缩略＋偏正（高速铁路→高铁）；点赞＝动宾装配的新义化（“赞”由按钮名物化，再缩略自“点一个赞”）；班味＝偏正＋类后缀“～味”（铜臭味→人情味→X味，新义“某群体特有的气息”：上班族的疲惫感）——三证全过“工序＋理据”两栏即满分。
:::

::: exercise 偏义调查 {level=2}
收集五个偏义复合词（“窗户、国家”已占坑，请自寻），并设计一条替换框架测验证明其偏义。
::: solution
合格样本如“睡觉”（“觉”不贡献义）、“国家”（只指国）、“恩怨”用在“记他的怨”时之偏“怨”；测验标准：偏义项可被单项同义替换而整体不损（“窗户开着”↔“窗开着”成立而“户开着”不成立）。凡举出“东西”（物件义）者可加分：它连方位本义都丢了。
:::

::: exercise 小论文：类词缀是洪水还是活水 {level=3}
“房奴、卡奴、孩奴”“×门”“×吧”屡见报端，有人忧“词汇通胀”，有人喜“能产红利”。写一篇八百至一千二百字短论站队并防守。要求：完整应用“纯词缀—类词缀—词根”判定三问；举一个你认为已死或早夭的类词缀并说明淘汰机制；对“字母词入侵构词”（Watergate→～门、E-～）给出你的判断。
::: solution
判分点：三问用到具体词上（不是抄定义）；能举早夭者并说淘汰原因（如“～吧”自网吧热潮后退潮——须给语料或语感证据）；对字母词构词持机制论——借的是**模式**还是**材料**（“～门”抄的是 Watergate 专名泛化的路径）；结构清楚、无史实硬伤。
:::

::: summary
汉语构词三大工序：复合（联合、偏正、动宾、动补、主谓五式，动补最能产）、派生（老-/阿-/第-＋-子/-儿/-头，其上是意义半虚、位置固定、高产的“类词缀”中间车间：～化～性～者～盲～门）、重叠（构词 AA 与构形 AABB/动词重叠两幅面孔）。外加第四条流水线：缩略提取（北大、科技、“三好”）。结构判定分账共时与历时，两可处如实报告两可；词缀化是梯度不是开关，类词缀名单永远在更新——那是词汇生态健康的心电图。
:::
:::
