title: "伤痕、反思与改革文学"

上一章的文学没有读者；本章的文学突然有了读者，而且读者比作者更急切——**“伤痕”这三个字在 1978 年底成为一个时代的名字：一场文学命名运动开始了；本章要问的不是这些作品说了什么，而是它们被允许怎样说：受伤是一种权利，而权利要有申请表**。

## 定义：三个词，三次追问 {#def-sange}

::: definition 问题的阶梯 {#def-jieti}
**通说脉络**（**“伤痕文学”“反思文学”“改革文学”都是批评界事后追给的名称，且名称的提出与论争几乎同时发生——**请把这三个词读成一次追问的三级台阶（**伤痕问：谁受苦了？反思问：受苦从哪一年开始、由谁决定？改革问：那现在该怎么办？（**每一级都把问题推向一个更不方便的负责人：个人、政策、体制——**这就是为什么三级的“允许度”依次下降，而作品寿命也依次缩短**））；**一个技术事实**（**通说脉络：1977—1978 年刊物复刊、稿酬与评奖制度陆续恢复、长篇重新变得可写——**上一章的“无人可卖的市场”重新有了销量数据（**于是批评第一次可以用印数说话（第 1 章分发格式：**同一部小说，印一百万册与印三万册，会被写进两种文学史**。
:::

::: definition 为什么从短篇开始 {#def-duanpian}
**短篇的优势**（**通说脉络：这一期的标志作品几乎全是短篇与中篇——**短篇是创伤的天然文体：**它只截取一个断面，不必解释断面的成因（第 7 章“含蓄是压强”：**省略的不是细节，是责任（**一部解释成因的长篇在当时要冒的风险，恰好等于它的深度**））；**《班主任》的位置**（**通说：刘心武《班主任》（1977）以教师的焦虑发问，被视为“伤痕”的开端；卢新华《伤痕》（1978）以母女诀别与一张未及检讨的忏悔构成全篇——**请注意两篇的共用结构：**痛苦必须发生在家庭里，并且必须由一个可以被原谅的亲人承担（**家是唯一合法的受伤口（**这就是本章的核心机制：**当公共的追责不可能，私人关系就代替法庭接收全部证据**。
:::

## 家庭作为法庭 {#def-jiating}

::: definition 团圆是判决的替身 {#def-tuangyuan}
**情节公式**（**通说情节模式：离散—受难—昭雪—团聚（或团聚被延迟到篇末的一瞬）——**这是第 1 章“团圆＝司法宣告”在二十世纪的最后一次复用（**差别在于宣告者：这次不是清官，是“历史终于正确了”（**于是伤痕文学看似反叛，其深层语法仍然是平反戏（第 1 章元杂剧条款：**三愿、鬼婚、团圆，全都在，只是判官改名为“时间”**））；**眼泪的功能**（**通说脉络：这一期作品的读者反应以流泪为标志，读者来信成为批评的新文体——**哭是一种可公开的表情：**在一个刚结束“不许哭”的年代，流泪本身就是一次政治表态（**这是文学效果研究里少有的可以直接观测的案例：**报纸刊登读者来信，等于公布了一份民调（**第 1 章“收费房间＝可依赖”的远亲：**读者第一次知道自己不是一个人**。
:::

::: definition 反思文学的向下钻探 {#def-fansi}
**时间轴的延长**（**通说脉络：1979—1981 一批作品把苦难的成因从十年推到十七年，甚至推到革命胜利后的第一次政治生活——**这就是“反思”的全部技术内容：**它不增加新的主题，它把叙事的起点往前挪（第 8 章“责任认定书”：**挪起点就是重新划分责任人（**它比伤痕更危险，因为它开始涉及决定者还活着的年代**））；**《思痛录》一类回忆录的补位**（**通说脉络：迟到的个人叙述与日记、书信成为这一脉的旁支史料——**它们提供了小说拿不到的东西：**当年的语言习惯本身（**读它们最有价值的不是事件，是措辞：一个人怎样在 1957 年描述自己的邻居（第 8 章舆情档案：**词汇是比数字更诚实的证词**））；**人物类型的更新**（**通说要旨：右派、归国者、被错处的干部成为主人公——**一个民族把“受过教育的人”重新写成值得同情的对象（**这件事在 1949 年以后的文学里并非当然如此：**它是本章真正的意识形态变化，比任何控诉都深**。
:::

## 改革文学与它的困难 {#def-gaige}

::: definition 企业家作为英雄 {#def-qiyejia}
**通说脉络**（**1981 年前后出现以工厂改革为主线的小说与报告，《乔厂长上任记》一类被目为“改革文学”的代表——**新英雄的简历：**他懂技术、敢签字、能骂人、有一群拖后腿的旧干部（**这是十七年“三突出”语法的一次平移：**构图不变，主角换人（第 1 章“分镜表”：**空间语法比意识形态长寿**））；**形式的困难**（**改革没有结局：**任何一部写“正在进行”的小说都必须自行结尾，于是它只能在胜利或挫败之间硬选（**本课把这一类结尾称为“被迫签发的判决书”（第 7 章《桃花扇》“拒绝签发判决书”的反例：**改革文学不敢不签，因为它有委托方：它在替一个政策作证**）；**它的遗产**（**通说脉络：这一脉后来汇入“报告文学热”与纪实写作——**汉语非虚构的第一次职业化：**记者与作家再次合流（第 1 章“文体是官场动作”的下游：**报告文学是文学与公文的混血，它的好处是快，代价是不能慢（**它后来在 1990 年代被“深度报道”接走，见下一章与写作课的《报告与深度报道》**。
:::

::: definition 限额之争 {#def-xianeg}
**“光明与黑暗谁是主流”**（**通说脉络：1979—1980 关于“写阴暗面”的争论几度进入报刊，批评者要求分清“九个指头与一个指头”——**本课把它读成一次配额谈判（**双方争的不是真值，是发表额度：**“主流”是一个配额词（第 1 课定义权即分配权：**谁能规定“光明”的最低比例，谁就掌握了整个文学生产的计划表（**这也是上一章“成本结构”的续集：当额度被抬高，作家的最优解不是少写黑暗，而是把黑暗写成别人的故事（历史、边地、寓言——**于是下一章的“寻根”与“先锋”在配额上是被逼出来的**。
:::

::: definition 排队：谁有资格受伤 {#def-paidui}
**三类伤痕的待遇差**（**通说脉络：受难的知识分子与干部最快获得表现权；而同一时期其他受害群体（地富家庭、被管制者、少数族裔与农民）的叙述长期无人接手——**这不是阴谋，是投稿机制：**编辑部与读者的同情预算按“误解—改正”模型分配，只接受“好人被错怪”的故事（**凡不符合此模型的苦，就被判为“复杂”，而复杂性要排队（第 3 章幸存者打八折：**我们读到的伤痕，是通过了编辑同意的伤痕（**这是本章最重要的批评，也是最容易被本章自己的课本忽略的一条：**任何一次文学解放都有一个未获邀的旁听席**。
:::

::: example 三级台阶 {#ex-jieti}
下表是三则同型情节的改写，请判断各属于哪一级、**责任人被安置在哪里**，并各写一行“**要升到下一级，作者必须新增什么信息**”。
| 情节 | 责任人 | 升级所需 |
| --- | --- | --- |
| ①母亲在女儿被下放期间病逝，女儿未能诀别 | ？ | ？ |
| ②同一个人因 1957 年的一份材料被处分，批示者是当年的同学 | ？ | ？ |
| ③一位厂长推行考核制，被工会、家属与上级规章联合拖住 | ？ | ？ |
::: solution
**①伤痕**——**责任人：不可命名的“那段历史”（**升级所需：把“谁下的命令”写成一个具体机构与一份具体文件（**而这一步一旦作出，作品就从抒情转为举证，风险从个人变成组织（**注意：许多作品不是不敢升，是升上去就没有泪了：**眼泪需要无名的敌人**。
**②反思**——**责任人：一个有名字、有旧情的人（**升级所需：说明批示者为什么必须那样做，即写出制度对他的奖励结构（**这一步就是“改革”与“先锋”的分岔：**前者写坏人如何被清除，后者写没有人坏而事情仍然发生（**本课把后者称为更高难度：**它需要一套叙事装置来表现无主体的过错（**这就是下一章现代主义技巧在 1980 年代中期突然变得必要的原因，而不是因为它时髦**。
**③改革**——**责任人：一组相互冲突的规则与习惯（**升级所需：给出一套替代规则；而小说无权立法（**于是这类小说只能以“某人被任命为更大的官”收尾：**用人事解决制度问题（第 6 章政策主张的执行主体问题：**这是改革文学的结构性结尾，不是某位作者的软弱**。
:::
:::

::: intuition 命名权 {#int-mingming}
**一个批评家的权力**（**“伤痕文学”这个名字是记者与编辑共同叫响的；“反思”“改革”同样是评论文章的产物（通说脉络）——**本章把命名视为一种制度行为：**命名把一个尚在发展中的写作捆成一束，然后决定它何时“过时”（**被命名的文学寿命较短，因为名称会先于作品死亡（**第 1 章“同行评审制度”的正面与反面：命名让作品被讨论，也让作品被结账**）；**一个可迁移的检查**（**每当你看到一个“-文学”“-小说”“-诗歌”的运动标签，先问三句：**谁先说的、谁在反对、反对者的作品为什么没进同一个标签（**这就是第 6 课“清场”的日常应用：**文学史里最沉默的部分，通常是被贴错标签的那部分**）。
:::

::: history 五年日程 {#sec-richen}
**1977**《班主任》（**复刊后的第一批文本之一：**它证明刊物的开门比政策的官宣更早**）；**1978**《伤痕》与“伤痕”之名（**一个名称的诞生用了不到三个月：**这说明编辑部与读者都在等一个词（**第 1 章“文学来盖章”的镜像：这次是文学在等社会给它盖章**）；**1979** 第四次文代会、《文艺报》重启若干讨论（**制度重新招安，同时重新发配额**）；**1979—1980** “写阴暗面”与“人性、人道主义”“异化”诸讨论（**同一个冬天里，配额、哲学与文学在争同一件事：**谁能代表集体的痛苦（第 3 课“我们”的四种用法：**这一次“我们”开始分裂**））；**1980** 汪曾祺《受戒》一类“风俗—抒情”短篇出现（**本章的技术出口：**当直接陈述受限时，文学退回描写（**它与“反思”并非对立，而是同一次松绑的两条产品线（第 8 章免税区：**新的写法先住在旧的旁边**））；**1981—1983** 反思与改革并置，报告文学热起（**“快”的文体扩张：**文学第一次按新闻的日历排产**）；**1983 后** 新的整肃与“清理”开始影响刊物人事（**配额再次收紧——**于是下一章的主线已经可见：当“写什么”受限，“怎么写”就成了一切（第 4 章“诗余”与第 11 章“纲领即设备”的第三次循环**）。
:::

::: warning 本课四坑
**把“伤痕”当贬义词**（**它是描述性的时段标签：**用它骂作品，等于用“唐代”骂一首诗（第 1 课清单是眼镜**））；**以题材代替技术**（**“写文革＝重要”不成立：**须说明它用了什么叙事装置（**本章的判准：**同一题材下，谁把无名的敌人写成了有名结构，谁就留下**））；**忽略读者侧**（**这一期的读者来信、读者投票、印数与获奖构成了罕见的“读者可观测期”：**只读文本不读读者，就浪费了史料（第 1 章“可依赖的收费房间”**））；**把配额谈判决成美学争论**（**“九个指头”不是审美判断，是分配方案：**它的正确回应不是写更多光明，而是问比例由谁计算（第 2 课定义权**）。

::: exercise 配额表 {level=1}
找一份你所在机构对外展示的材料，用 80 字估算：**它给负面留了多少额度、以什么形式（时间、个案、他人）**，并写出**它最不愿意出现的那一类主语**。
::: solution
判分：**额度须有分母**（**多少分之一、占几段：**没有分母的分子不可信（第 3 课回访**）；**形式栏要具体**（**“放在三年前”“只写一个人”“由外部造成”：**这三项正是伤痕文学的配额技术（第 1 课“做别人省掉的账”。
:::

::: exercise 小论文：受伤的申请表 {level=3}
写六百至一千字，评“**每一个时代都有一张谁能诉苦的名单，而且名单通常由最需要这些故事的读者来定：他们只肯为一种苦买单——那种能被解释成误解的苦；于是一代作家学会了把自己的经历先翻译成‘好人被错怪’，再投递；本章真正值得记住的，不是这些作品有多成功，而是它们为了被听见所接受的格式**”。须调用：**三级台阶**、**家作为法庭**、**团圆作为判决替身**、**反思的前移技术**、**改革文学的结构性结尾**、**未获邀的旁听席**至少六项；并裁决：**为了被听见而接受格式，是妥协还是策略——你须给出一个判准，用来区分“借用格式”与“被格式收编”，并各举一例**。
::: solution
判分点：六项机制（**台阶、法庭、替身、前移、结构性结尾、旁听席**）；判准（**参考：**看格式被借用后是否留下残余——**若作品在合规外壳里保留了无法被解释的损失（一个不道歉的人、一笔算不清的账、一个不被团聚的结尾），它是借用；若所有损失最后都变得可以理解、可以原谅、可以归功于历史，它就被收编（判卷看是否举出两类具体文本并指出“残余”在哪一句；泛泛谈“真诚”不得分**）；结论若能写“**所以伤痕文学的功绩不是它说出了真相，而是它把真相做成了一种可以被公开朗读的格式；它的代价同样清楚：那些无法翻译进格式的苦，又等了二十年，而等的时候没人记得它们曾经缺席**”，即 A。
:::

::: summary
台阶归档：三级（**谁受苦、从哪一年、怎么办**）、法庭（**家庭接收全部证据，团圆顶替判决**）、前移（**反思的全部技术是把起点往前挪**）、改革（**用人事解决制度问题：结构性结尾**）、配额（**“主流”是分配词，不是美学词）、旁听席（**任何解放都有一份未获邀的名单**）。方法一句话：**遇到“时代之声”，先查它为了被听见签了哪些格式条款**。下一章：朦胧诗——当“写什么”受限，“怎么写”就成了一切。
:::
