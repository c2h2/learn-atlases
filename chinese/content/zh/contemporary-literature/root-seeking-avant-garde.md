title: "寻根文学与先锋小说"

上一章把战场从内容搬到形式；本章同时开出两条路——**一条往回走去借集体文化，一条往里走去拆叙事本身；两条路看起来相反，其实是同一次“题材外逃”的两种解法**。

## 定义：1985 年前后 {#def-chuangkou}

::: definition 为什么每本教材都有这一年 {#def-nianfen}
**通说脉络**（**1985 年前后出现韩少功《文学的根》一类纲领文章、阿城与贾平凹等人的中短篇、以及一批被后来批评家称为“先锋”的实验小说——**本课把这一年读成一个统计现象而非天才现象：**刊物数量、编辑部自主权、作协系统的评奖节奏、翻译出版的积压释放，四件事在同一个窗口里同时达到峰值——**第 1 章“分发格式”与上一章“配额”的合流：**当配额松动，第一波涌出的不是更好的作品，是新的分类（**因为作者首先要证明“文学不必只有一种写法”，然后才有时间写好一部）。
:::

::: definition 寻根的纲领 {#def-xungen}
**通说引韩少功《文学的根》大意**（**文学要“回到自己的民族之根”，民间文化、地域风俗被视为活的载体——**这是一份典型的招标书：**它有三项可执行内容（**①把选材范围从当代政治改成风俗与地方；②把权威从政策文本改成田野与文献；③把“民族性”设为可竞争的商品（第 11 章纲领即设备：**三项全部可教、可检查、可复制——这就是它能在两年里变成“一派”的原因**）；**它的隐藏功能**（**“根”是一个无人可指的委托人（上一章“题材外逃”条款：**当现实题材被限额，作者会搬来整个青铜时代；这次搬来的是楚辞、方言、巫傩、笔记与县城（**它的得是文学重新获得了厚度与地理；**它的失是：**“民族”这个词在此后二十年里再没被认真追问过它的成分表**）。
:::

::: definition 向外借镜子 {#def-jingzi}
**通说脉络**（**拉美“魔幻现实主义”的译介与诺贝尔奖效应，是寻根论述最重要的外来根据；而拉美的方法本身来自欧洲现代主义与本土口述传统的合成——**于是发生一次三级循环：**中国作家从外国模型里认出了自己家里的东西（第 11 章“以故为新”与上一章“影响的对象总是最近的教科书”：**教科书可以是翻译过来的（**本课给这一现象一个名字：**借来的镜子照出的不是外国，是自己家里那些一直没被承认的角落）。
:::

## 文本一：阿城的极简 {#def-acheng}

::: definition 《棋王》的技术 {#def-qi}
**通说情节**（**知青下乡、一个痴迷于象棋的人、一次车轮大战、一句“死于谋食也”的羞愧——**本课注意三件事（**①**题材的双重位移**（**把知青经验写成“吃”与“艺”，而不是写成“冤”：**于是它绕开了上一章的伤口配额（第 3 章“合法的受伤口”：**阿城没有取消创伤，他只是换了记账科目——从政治账改为生存账（**这是寻根小说最成功的策略，也是最容易被误读为“逃避”的策略**））；**②语言的复古**（**通说评其文字近笔记小说、明清小品——**他用一种已经退出日常的语言来写当代（**效果是陌生化，代价是消毒：**文言化的句子无法承载呐喊，只能承载沉默（**这就是为什么《棋王》读起来“干净”：**干净是一种被选择的可见性（第 8 章删掉形容词以后还剩下什么**））；**③英雄的降级**（**“为棋而生”的人不反对世界，他只是不参与（**这为 1980 中后期的“非英雄”提供了模板（第 10 章宝玉“拒绝估值”的现代版：**王一生拒绝的不是体制，是所有计价方式）。
:::

## 文本二：先锋的拆解 {#def-xianfeng}

::: definition 三种装置 {#def-zhuangzhi}
**①叙述者露面（元叙事）**（**通说脉络：马原一类作品让“我”出现在自己的故事里并干预情节——**这是把第 3 章“讲述者的信用”做成展览（**效果：**读者无法再把自己交给叙述者（**它的政治含义是温和的、它的语法含义是激进的：**一个会撒谎的叙述者比一个撒谎的角色更让人不安（**因为在后一种情况里，小说仍然保证有真相；前一种情况里，真相这个概念被撤了职**））；**②时间的破碎**（**通说脉络：余华、孙甘露、格非早期的短篇常把因果顺序打散，用重复与错位代替发展——**这不是炫技，是一种历史观（**当一个人无法说清“从哪一步开始出错”，线性叙事就成了谎言（**先锋小说的形式与反思文学的追问，其实是同一个问题的两种答案：反思说“我要往前再多查十年”，先锋说“查询这个动作本身可疑”（**这就是本章最重要的一句对照：两级台阶在这里分岔成两种文类**））；**③身体的过度**（**通说脉络：暴力、血、酷刑与死亡在 1980 年代末的先锋短篇中高频出现——**本课的读法须同时给出三条因果（**①审美：感官强度是叙事解体后的唯一可依赖坐标；②市场与电影：改编需要可视的场面（下方“电影中介”条款）；③伦理：当语言的公共部分被污染，肉体是剩下的最后一块可写的地（**任何一条单独讲，都会把先锋小说读歪（第 3 章三张处方：**须比较哪一条更可反驳**。
:::

::: definition 电影作为中介 {#def-dianying}
**通说脉络**（**《红高粱》《大红灯笼高高挂》一类改编在 1980 年代末—1990 年代初获得国际奖项与国内名声——**于是中国先锋文学的第一批大众读者是通过银幕获得的（**三个后果：**①**选本偏置**：被改过的作品获得二次生命，未被改的进入文学史要等学院（第 3 章“档案运气”**）；②**题材自证**：作家开始写出“可拍”的元素——**颜色、宅院、仪式、身体（**这是 1990 年代“东方奇观”批评的由来，也是它有一半道理的地方（**更准确的说法：不是为外国评委写作，是为一种新的发行渠道写作（第 1 章“发行量决定文学史”**）；③**作者署名变成品牌**：莫言获国际奖项（通说脉络：2012）把一个持续了几十年的“寻根”脉络归给一个人（第 15 课追认：**命名个人比命名系统容易，而系统被忘记——**本课的提醒：**“寻根”是一个有二十位作者的纲领，“诺奖”是一个人一个名字：**两种记账法不可通约**）。
:::

::: definition 余华的转向：作为案例的一年 {#def-yuhua}
**通说脉络**（**1980 年代末的短篇以感官暴力与叙事游戏著称；1990 年代初《活着》一类作品改用极朴素的第一人称讲历史——**常被解释为“精神转向”或“良心发现”；本课给出一个更冷、也更可核对的解释（**叙事装置的更换（**前期：**叙述者操纵一切，人物是他手里的棋子；**后期：**把叙述权交给一个不理解的当事人，让灾难由受害者平静地复述（**后一种装置的效率极高：**它把可反驳性降到最低（**受害者本人的口供不能被反驳——**于是它同时获得了最大的传播度与最大的争议（第 4 课“可传播度 ≈ 情绪强度 / 可反驳度”：**从实验到《活着》，不是从难懂到易懂，是从低传播到高传播的一次重新定价（**批评者说的“背叛”与读者说的“成熟”，其实是同一次定价行为的两个侧面**）。
:::

::: definition 为什么它在 1980 年代末结束 {#def-jieshu}
**四条因果，本课按可反驳性排序**（**①**制度与人事**（刊物编辑方针变化、若干主要作者离开或停笔——**最可核对**）；②**市场**（大众读物与影视改编分流，纯形式实验失去发行（第 9 章票房约束**）；③**代际**（下一波写作以“日常”“世俗”“新写代”自居，反对先锋的姿态本身是一次接班宣言（第 3 章“影响的焦虑”的文学场版**）；④**疲劳律**（**最不可证伪：**一种技巧一旦被普遍掌握，它就不再是发现而是格式（第 11 章格律史与上一章口号史的同一条曲线——**“先锋”最大的敌人是模仿它的第二年——**本课的态度：四条都要写出来，并且必须排序：**把④当成唯一解释的人，通常是不查①②的人）。
:::

::: example 两种外逃 {#ex-waitao}
填表比较“寻根”与“先锋”：**①委托人是谁、②第一读者是谁、③可反驳的位置在哪里、④各自放弃什么**；然后回答：**为什么同一批编辑可以在同一年同时接受这两种方案**。
::: solution
**①委托人**——**寻根：民族、地域、文化（**一个不能反驳但可以互相矛盾的委托人；**先锋：语言与叙事本身（**一个不能替你说话但也不会背叛你的委托人（**这就是为什么寻根容易成派，先锋容易成人：前者有纲领，后者只有工序（第 11 章：**复古是修辞，革新是财政**）；**②第一读者**——**寻根：关心“我们是谁”的知识读者；先锋：编辑、批评家与同行作家（**先锋的第一读者是同行人，这解释了它的技术密度与发行量之低（第 1 章“收费房间＝可依赖”的反面：**没有读者的写作，其质量由同行保证，也由其规模限制**）；**③可反驳的位置**——**寻根在“民族性”的概念上（**一个反例即可：同一批风俗可以被写成进步或落后**）；先锋在“是否只有这一种讲法”上（**一个反例即可：同一事件用线性叙事也可能同样好——**而它通常不会被这样检验，因为它被评价的是“新不新”，不是“对不对”——**这就是形式文学的评价困境：它拒绝提供可检验的命题，于是只能被年龄评价（“新”是时间词，不是价值词**）；**④放弃**——**寻根放弃了当代经验的复杂性（把当下交给别人写）；先锋放弃了读者的信任（把可理解性交给未来）；**同一年同时接受两者的编辑，其实是在做同一件事：**把文学从被限额的题材上迁走，迁到两个当时没人管制的方向去——空间与语法——**这是本章的最终解释：**1980 年代中期的形式爆发，不是文学突然变聪明了，是它被挤到了两条没人防守的门**）。
:::
:::

::: intuition 实验文学的成本 {#int-chengben}
**实验是负债经营**（**先锋写作放弃了三样东西：读者的即时代偿、影视的即时改编、评奖的即时承认（**它靠什么活下来：民刊与同人的相互确认、学院的滞后追认、外译的二次认证（**注意这三条都是慢钱（第 1 章分发格式：**一种写作若只能靠延迟渠道存活，它的主题往往就是“延迟”本身——**这就是先锋小说偏爱记忆、梦与错乱时间的社会学解释，而不只是柏格森——可核对的推论：**若把同一批作品的题材按“时间是否可逆”统计，其比例应显著高于同期写实作品（第 1 课做别人省掉的账：**这一格没人填过**）。
:::

::: history 一条纲领与三种渠道 {#sec-qudao}
1985 纲领文章与“寻根”之名（名称出现即派别成立：它同时开始失效（）；1985—1987 实验短篇的高产期（中篇与短篇的窗口：它们的印刷周期短（这就是为什么这一波不是长篇：长篇需要两年，而窗口只开了三年）；1986—1987 大型文学刊物与丛书把先锋作品“经典化”（编辑成为运动的真正组织者（第 1 章“同行评审”的中国当代版：一位主编的任期就是一场运动的寿命））；1988—1992 电影与外译提供第二市场（作者开始有两种名声：国内的读者名声与国外的学术名声，两者互不通气（**这一分裂至今仍是汉语文学国际声誉的结构**））；**1990s** “先锋批评”的学院化（**一批批评家把 1980 年代的工序整理成可教的课程（第 11 章教材化：**实验一旦进大纲，就变成基本功（**于是新一代作家的“实验”默认从这些页码出发**））；**2000—2012** 国际奖项（**最后的追认：**一个人代表了一个二十年（**本课的结语提醒：把“代表”换成“被选中来代表”，句子就诚实了**）。
:::

::: warning 本课四坑
**把寻根与先锋讲成先后两个阶段**（**它们同期、同刊、互相同情：**共同点是题材转移，区别是转移方向（**用时间顺序讲它们，会让人误以为先锋是寻根的“发展”（**更准确：**它们是同一次松绑开出的两条产品线（上一章《受戒》与反思文学的关系就是原型**））；**把“实验”当价值**（**新的不等于好的：**“新”是时间词（上方③条款**）；**把身体书写只读成勇气或只读成商品**（**须三条因果并列并排序（**只讲其一会得到两种相反的歪曲：殉道史或市场史（**而它两头都是**））；**以一位诺奖收束本章**（**它会把纲领、编辑、译者、电影共同完成的事，归给一个人的天才（第 15 课：**颁奖词是最凝练的文学史，也是最不准确的**）。
:::

::: exercise 小论文：没人防守的门 {level=3}
写六百至一千字，评“**文学的形式爆炸很少发生在自由最充分的时候，而常发生在自由刚刚足够、却仍不指向主流题材的那个窄窗口：作家于是涌向两个无人防守的方向——把题材搬到别的时间，把叙事搬到一个新的层面；这两种搬法都既能规避风险又能获得声誉，于是它们看起来像天才的自觉，实际上是通道的形状；但也仅止于看起来像：因为穿过那两道门以后写下的东西，并不是门决定的**”。须调用：**1985 的四个条件**、**寻根招标书的三项内容**、**借来的镜子**、**元叙事的语法含义**、**电影中介的三个后果**、**四条因果的可反驳性排序**至少六项；并裁决：**“通道决定论”（形式来自渠道）与“天才决定论”（形式来自个人）在解释这一时期时各在何处失灵——须各举一个只有该理论能解释、另一个不能解释的现象**。
::: solution
