上一章的作家在配额里谈判；本章的一群人换了战场——**他们不再问能写什么，他们改问怎样写；于是“看不明白”不再是一个美学抱怨，而成了一个政治指控：因为在这一场争论里，清楚等于忠诚**）。

## 定义：一个骂名的胜利 {#def-mingming}

::: definition “朦胧”一词的来历 {#def-mingci}
**通说脉络**（“朦胧”初见于 1980 年一首诗作者的来信，用以指斥某些新诗过于晦涩、难于理解；1983 年一篇评析三首诗的文章把争论推到顶点——**三步骤值得记住：**①一个贬义修辞出现；②论敌接受并使用它作为标签；③标签变成文学史章节名（第 3 课“名称即主权”的回访：**给对手起的外号，是文学史上最便宜的商标转让**）；**为什么“清楚”会被政治化**（**通说脉络：论争双方都默认诗应当“为广大读者看懂”——**于是一个可测量的指标（有多少人看懂）被当作一个道德指标（站在哪一边）（**本章的方法论核心：**一旦清晰度成为忠诚的凭据，诗人就只剩下两种选择：**把话说清楚地服从，或者把结构变复杂地不服从（**后者就是朦胧诗的形式起源：晦涩不是风格偏好，是唯一的否决权**）。
:::

::: definition 三个事件 {#def-shijian}
**《今天》（1978—1980，通说）**（**非官方油印刊物：**它的意义不在于登了什么，而在于它没有编辑部审批（**第 2 章“抽屉”的社会化：**私人写作第一次共享一台油印机（**一种文体的诞生往往只是一个印刷条件允许它连续出现**））；**《朦胧诗选》一类选本与公开论争（1980 前后，通说）**（**选本把散见的作品捆成“一代”：**于是“北岛、舒婷、顾城、江河、杨炼”成为可被引用、可被反对的单位（第 1 章“四大家并称”条款：**阵营是批评家造的，作品是诗人写的，反对者是两者共同的受益人**））；**“三个一切”的口号（通说脉络：1980 年代前期“思考一切、怀疑一切、否定一切”一类的概括被反复引用，其原始出处已多经转述）——**本课只用它做一种时代气味标本：**它证明了当时争论的真实标的不是修辞，是“个人是否有权先于集体判断”（第 3 章“我们”的第四种用法在此被取消：**“我”重新成为句子的主语**。
:::

## 文本 {#def-wenben}

::: definition 北岛：以宣言为诗 {#def-beidao}
“**卑鄙是卑鄙者的通行证，高尚是高尚者的墓志铭。**”（通说引《回答》）——**这是一句可以被单独引用的诗，而单独引用就是它的功能（**宣言诗的技术：**把一个判断写成对句，于是它能脱离全诗旅行（第 6 章口号是压缩饼干：**朦胧诗最厉害的地方不是它晦涩，是它同时生产最凝练的可引用句（**它的读者因此有两种：能背下来的与看不懂的，而前者的数量决定它的名气**））；“**我—不—答—应**”一类的否定句式与“新的转机上星星闪烁”一类收束（通说引句大意）——**本课称这种结构为“拒绝签发的判决”的第 20 世纪版（第 7 章《桃花扇》条款）：**它不提供替代方案，它只撤回承认（**这正是它在 1980 年代被读作“怀疑精神”的原因：一个不给出纲领的否定，无法被反驳，也无法被落实——**这是它的力量，也是它被批评为“空”的理由**）。
:::

::: definition 顾城：童话作为证词 {#def-gucheng}
“**黑夜给了我黑色的眼睛，我却用它寻找光明。**”（通说引《一代人》）——**两行诗的力学：**它把创伤写成感官的改造（**不是“我受苦”，而是“我的器官被重装了”（第 8 章“约束长出器官”的抒情版：**这一代人在公共档案缺位时的唯一凭据，是自己的身体**）；**为什么它只有四行**（**通说脉络：此期短诗常被选本优先收入——**短诗的不可反驳性：**它不断言因果，因此没有可被证伪的环节（第 2 课死法测试：**“黑夜—眼睛—光明”三词组合既不能证实也不能证伪：**于是它成了 1980 年代被引用最多的句子之一：**传播率最高的作品，往往正是可反驳性最低的作品（**这句话不是贬义，是发行学**。
:::

::: definition 舒婷：把“我们”重新写回爱情 {#def-shuting}
“**我如果爱你，绝不像攀援的凌霄花，借你的高枝炫耀自己。**”一类（通说引《致橡树》）——**请注意它在做什么：**它没有否定集体，它只是要求一种对等的联合（第 2 章丽娘“我情愿”的二十世纪续集：**汤显祖让情成为可诉理由，舒婷把可诉的形式写成一次合伙（**“根，紧握在地下；叶，相触在云里”一类的对偶，是把平等做成语法（**这就是它比同时代许多作品更早被大众接受的原因：**它没有攻击任何教条，它只是换了一张合同**。
:::

::: definition 杨炼与“文化史诗”的转向 {#def-yanglian}
**通说脉络**（1980 年代前期部分诗人转向长诗与文明题材（组诗《礼魂》一类）——**本课把这一转向我读为一次“题材外逃”：**配额与论争把个人抒情写成高风险区，于是“文化”成为无人可指的第三方（第 11 章“纲领”条款：**当现实题材被限额，作者会把整个青铜时代搬来作为委托人（**它的得：**诗重新获得体积与仪式感；**它的失：**抽象名词取代了具体的人，读者失去了入口——**这为下一章“寻根”铺好了红地毯：**当诗去寻文化之根，小说也会去寻**。
:::

## 论争的结构 {#def-lunzheng}

::: definition 一场无法判决的官司 {#def-guansi}
**原命题**（**通说脉络：新诗“太晦涩”“背离民族传统”“是朦胧的”——**这是审美判断；**反命题**（**通说脉络：“诗不能要求人人一看就懂”“诗的含混有传统”——**这也是审美判断；**真正的争点**（**通说脉络中反复出现的却是另外两问：**谁有权代表读者？谁有权定义“传统”？（**双方都以为自己在谈修辞，实际在谈评审权（第 2 课定义权即分配权的完美案例：**这场论争没有任何美学论证能够胜出，因为它从一开始就是资格之争（**这就是它十年不解决、且最终以“不再争论”告终的原因：**判决被代际替换执行了（**新的一代人当选编者与教授，于是“朦胧诗”进了教科书，反对者成了“当时的读者”**）。
:::

::: definition 现代派论争：第二次开庭 {#def-xiandai}
**1986 年的发言与批评**（**通说脉络：一场关于“现代派”的座谈纪要发表，论者以“失根”“移植”描述中国现代派的处境；随后官方文学刊物组织征文讨论，“是否可以这样写”成为议题——**请把两次论争按顺序看：**朦胧诗之争争的是“看得懂吗”，现代派之争争的是“该不该学外国”（**两次都不是文学内部的争论：**第一次争评审权，第二次争文化主权——**而它们共同的效果是：**把“怎么写”的问题变成了一门需要辩护的罪名——**于是形式实验从此在汉语文学里带着一种永久的答辩姿态（第 6 章让步前置：**中国先锋文学的句法里，一辈子都有一位站在对面的批评家**）。
:::

::: example 可反驳性排名 {#ex-kefbo}
把下列四句（均为通说引句或其改写）按“**可被反驳的程度**”从低到高排序，并说明：**为什么这个排序与它们的传播度大致相反**。
① 卑鄙是卑鄙者的通行证，高尚是高尚者的墓志铭
② 黑夜给了我黑色的眼睛，我却用它寻找光明
③ 我如果爱你，绝不像攀援的凌霄花
④ 在没有英雄的年代里，我只想做一个人（通说引句大意）
::: solution
**从低到高（参考）**——**②最低**（**三词组合，无因果：不可证伪**）；**①次低**（**格言式全称判断，但含可检验的道德分配：**一个反例即可削弱（“卑鄙者也有不通行的时候”）**）；**④中**（**它主张一种价值排序，可以被追问“做人与做英雄的定义”；且“没有英雄的年代”是一个可争议的历史陈述**）；**③最高**（**它提出一种爱情合同的具体条款，因此可以被反驳：“紧握在地下”也可能意味着两棵树一同被伐（**一旦提出方案，就提出可攻击的方案**）；**与传播度相反的原因**（**引用需要不可反驳性：**可反驳的句子会招来讨论，不可反驳的句子只招来回声（第 3 课“可反驳性”条款、第 6 课“死法测试”的镜像应用：**在文学里，可传播度 ≈ 1 / 可反驳度 × 情绪强度（**这条公式不是规律，是一种筛选机制的粗描述——**它同时解释了上一章的口号与本章的名句：口号与名句是同一个物种的两个亚种**）。
:::
:::

::: intuition 形式是最后的技术手段 {#int-xingshi}
**一条可迁移的解释律**（**当内容被审查、题材被配额、评价被政治化，创新就会转移到形式层：句法、意象、标点、长短、引语的有无（第 4 章“诗余”、第 11 章“纲领即设备”的同型：**这不是审美偏好，是可行性分析（**可核对的证据：**本章的形式特征（无主语、断裂、通感、文化意象）与上一章地下写作的加密技术几乎一致——**它们不是从法国来的，它们是从抽屉里来的；1980 年代中期以后，译本才作为“外来根据”被追认进来（第 8 章影响的对象总是最近的教科书：**这一代人的教科书有两套，一套是译本，一套是不许说话的那十年**）。
:::

::: history 二十年的引用史 {#sec-yinyong}
**1978—1980**《今天》（**油印：**一种文学的最低可行产品**）；**1980—1983** 命名与论争（**一个贬义词如何在三年里变成一门课的章节名**）；**1986** 现代派论争（**第二次开庭：**争点从可读性换成主权**）；**1989 以后** 诗歌的“去公共化”（**通说脉络：诗从公共论争的中心退位，转入民刊、同人写作与学院研究——**这不是失败，是分发系统的又一次搬迁：**诗歌重新成为它宋以后的样子：一个高声誉、低现金的科目（第 4 章“诗余＝免税区”的闭环：**现代文学史的“中心文类”从来不是文学性质的排名，是渠道的排名**））；**1990s—今** 选本、教材、获诺贝尔奖的中国语种写作与“北岛年年被提名”的舆论（**经典的最后一步是被引用而不再被阅读（第 3 课成语化＝流通率上升、意思归零：**名句脱离全诗，诗人脱离作品（**本章的收尾提醒：**今天大学生知道的朦胧诗，多半是那三句可背诵的诗；**这不能怪他们——**那三句本来就是照着可以背诵写的**）。
:::

::: warning 本课四坑
**把“朦胧”当作风格**（**它是对话中的一枚武器：**用它做诗学范畴，等于用对手的嘲讽建立分类学（第 1 课清单是眼镜：**更好的分类是按发表渠道与句法特征，而不是按骂名**））；**把影响只归于外国**（**译本确实重要，但形式的直接成因是可写性约束：**须同时给出两条因果链（第 8 章独立来源：**只有一条来源的影响研究，是翻译目录**））；**以“觉醒／启蒙”一笔带过**（**这是后世追认的语言（第 15 课：**它把一群人不同的选择（宣言、童话、爱情合同、文化史诗、外逃）压成一个动机（**本章的做法：**五种策略对应五种读者假设，而不是一个时代精神**））；**忽略论争的社会功能**（**这场争论让诗重新成为公共话题：**被批评是一种发行量（第 1 章“禁书名单＝推荐语清单”：**没有那几篇批判文章，许多诗不会在一年内被几十万人读到**）。
:::

判分：**“失去什么”是关键栏**（**常见答案：失去了对最初指控的回应义务——**一旦外号成了学科名词，它携带的贬义就被制度性地遗忘了（第 3 课“名称即主权”：**这就是本章标题为什么写成“一个骂名的胜利”而不是“朦胧诗”。

::: exercise 写一句可背诵的 {level=2}
写一句 20 字以内的格言式对句，要求它**可被单独引用**；然后写一行：**它靠什么不可反驳**，再写一行：**哪一个人一句话就能拆掉它**。
::: solution
判分：**拆句必须真的能拆**（**给出反例或给出隐藏前提：**写“它太绝对了”不得分（第 2 课死法测试**）；**这一题的目的是让学员体验本章的不对称：**写一句可以旅行的谎言，比写一句不能旅行的真话容易（第 6 章“假深刻”条的镜像**）。

::: exercise 小论文：形式的因果关系 {level=3}
写六百至一千字，评“**一个时代的形式特征，往往不是从它读到的外来榜样那里学来的，而是从它不能说什么里长出来的：因此研究形式的正确问题不是‘他们模仿了谁’，而是‘什么被禁止，从而使什么成为可能’；但这绝不等于说形式是审查的产物——否则一切技巧都成了政治的注脚，而技巧一旦成为政治的注脚，批评就再也不用读句子了**”。须调用：**骂名的三步**、**清晰作为忠诚凭据**、**油印本的最低可行条件**、**身体作为凭据（顾城）**、**爱情合同（舒婷）**、**题材外逃（文化史诗）**至少六项；并裁决：**“形式源于约束”与“形式源于外来影响”两种解释，哪个更容易被过度使用，为什么——须各给一个你会如何误用它的句子**。
::: solution
判分点：六项机制（**命名、忠诚、渠道、凭据、合同、外逃**）；裁决（**参考：两种都会过度使用，但误用后果不同——**“外来说”的过度使用会写成翻译目录（**它的典型误用句：“这群诗人的成就是引进现代主义”**）；“约束说”的过度使用会把一切技巧读成抵抗，取消作者的全部技艺责任（**它的典型误用句：“这种断裂是审查的直接结果”**）；判卷看学员能否指出**两者的共同错误：用单一因果解释一种可观测的技术选择（第 3 章算法条款：**更好的问法是：在给定约束与给定阅读条件下，这种写法比别种写法多争取到了什么；并追问它因此放弃了什么（**结论若能写“**形式既不是禁令的镜像，也不是外国来信；它是一份工程方案：材料是禁令，图纸是榜样，验收的是那十年唯一新出现的读者——一个愿意读不懂也要读完的人**”，即 A。
:::
