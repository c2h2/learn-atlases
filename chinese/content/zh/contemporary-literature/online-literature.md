本课前面八章里，作者至少知道自己在替谁写；本章的作者每三十秒就知道一次——**网络文学不是“文学上了网”，是一套把中国小说的说书原型重新发明的生产制度：按千字计酬、按日更新、按读者留言改剧情；本章把它当作一次罕见的自然实验来读：当筛选压力变得又大又快，汉语小说会长成什么形状**。

## 定义：一种制度 {#def-zhidu}

::: definition 三个条件 {#def-santiao}
**通说脉络**（**①1990 年代末中文网络原创站点与论坛连载出现；②2000 年前后一批长篇小说以网络为首发；③2000 年代中期付费阅读与作家分级制度成型，此后版权向影视、游戏、动漫授权——**三个条件缺一个都没有今天（**带宽决定能否连载，支付决定能否吃饭，授权决定能否做大（第 1 章“收费房间＝可依赖”的终极版：**付费墙不是文学的对立面，它是一种新的委托方（**而它的付款单位是千字，不是作品——**这是本章第一颗硬钉子：**当付费按章卖，结尾就成了销售位（**第 9 章“下回＝时间分期”的现代子孙**。
:::

::: definition 类型＝货架 {#def-leixing}
**通说脉络**（**玄幻、仙侠、都市、历史、军事、游戏、科幻、无限流、系统流等分类构成平台的基本导航——**本课的读法（**类型不是流派，是货架（**它比文学史的“派”更硬，因为它直接决定曝光位置与推荐位（第 1 章“目录即审查”：**这里的目录就是发行（**同时它也规定了读者的先验期待：所谓“套路”，就是上一次成功被写成了这次的准入条件（第 11 章纲领即设备：**平台的分类表是本时代最有效的一份创作纲领，而且没人需要读它，只需遵守它**。
:::

## 三件新装置 {#def-zhuangzhi}

::: definition 黄金三章 {#def-sanzhang}
**通说脉络（行业教程的普遍主张）**（**开头三章内必须立起主角的金手指、目标与冲突，否则读者流失、推荐落空——**这是第 3 章“第一句剧透＝预期管理”的微缩版，被压缩到八百字以内（**更准确地说：**它是话本的“入话＋头回”在付费制下的重演（第 9 章条款的完整闭环：**入话是道德预告，黄金三章是留存预告；两者都是在读者决定离开的那一秒替他做决定（**本课请读者注意一个后果：**当一部小说的前一万字由销售指标决定，它的前一万字就不再属于叙事学，属于转化率（**于是评价网络小说的正确问句不是“写得好不好”，而是“它在前五分钟承诺了什么，之后是否兑现”——**这是一个可以逐条检查的问题（第 2 课死法测试的畅销版**。
:::

::: definition 日更：把文本变成河流 {#def-rigeng}
**通说脉络**（**更新频率与全勤奖励、榜单与订阅直接挂钩；作者以“日更数千至上万字”为常态，断更即掉榜（**三个形式后果（**①**无限文本**（**一部小说的结束方式常常不是结局，而是停止连载：**作品的边界由订阅曲线决定（第 5 章“可授权的宇宙”：**宇宙不会结束，只会停更（**②**结构的碎片化**（**每章是一个自足的销售单元，于是长篇由“情节”改为由“事件颗粒”堆成——**读者可以断读三日再回来：**这既是便利也是残疾：**它使“整体的形状”成为网络小说最罕见的美——**第 4 章“折子戏反而保存了它”的第四次证明：**当进出自由，作品的单位就从全篇变成单折（**③**作者的可见性**（**感言、更新说明、单章说、作者的话：**副文本成为正文的一部分——**第 1 章“序言是说明书”的当代形态：**它现在还是客服窗口。
:::

::: definition 留言区作为进化压力 {#def-liuyan}
**通说脉络**（**“本章说”一类的章内评论让读者的反应与正文同屏；作者可看到哪一段被刷、哪一段无人回——**本课的核心判断（**这不等于读者参与创作，而是筛选压力被加速了：写作的变异照旧由作者产生，而淘汰的速度从一代人缩短到一天（**这是本章最重要的理论句，也是它最值得与达尔文而不是与“接受美学”并置的地方（**后果一：**“爽点”是一种被高频选择出来的适应器，不是作者的堕落（**它能通过筛选，因为它在十万次试验里提高了留存；**后果二：**它同时是一种近亲繁殖：**快速淘汰会消灭一切需要长时间才显出好处的写法——**慢热、留白、复杂、不可爱的角色，都在被删掉的那一批（第 6 章精选即删改：**以前删改发生在编辑的办公桌上，现在发生在第七百条评论里（**后果三：**“为已死的角色复话”：读者的抗议可以让作者改写（**这在纸刊时代不可能：**作者第一次面对一个可以即时表达偏好、并且已被付费证明偏好的委托方（**它的性质因此不是民主，是合同。
:::

## 尺度与承认 {#def-chidu}

::: definition 长度是一种收入结构 {#def-changdu}
**通说脉络**（**头部网络小说常达数百万字，其收入与订阅时长、打赏与版权授权挂钩——**本课拒绝两种流行的解释（**“作者灌水”与“故事丰富”都不成立；成立的是：**按章卖的文学生产，长度是一种收入结构，不是一种美学选择（**于是长不是缺点，是价格表（**要批评它，须批评计价方式；要赞美它，也只能赞美它的工艺（**可核对的推论：**同一体裁在不同计价制度下会呈现不同的中位长度（**第 4 章“四折是生理量”、第 7 章“长度由庆典而非叙事决定”的最终版：**这次的庆典是包月，生理量是通勤时间（**这就是为什么网络小说的第一批删节本与精选本至今没有出现：**摘要会摧毁订阅，而订阅就是作品本身**）。
:::

::: definition 承认的四道门（重新排班） {#def-sidao}
**通说脉络**（**网络作家入作协、获国家级奖项与职称评审；作品进入图书馆与大学课堂与学术论文；2011 年前后茅盾文学奖的评选引起“网络小说是否算文学”的公开讨论；主流出版社出版网络小说、作品改编影视出海——**本课把这四道门与上一章的四道门并排（**顺序完全反了：**这次是市场先给量级，然后制度来谈定价（**于是出现一种奇怪的姿势：**机构承认了作品，却仍在讨论这个门类是否值得承认（第 1 课“文学来盖章”与“通俗小说被重新归类”的最终闭环（**本课的判决：**这一次章盖不住纸——不是因为网络文学太强，是因为它已经不在同一个发行系统里；一份可以盖在纸上的章，对它相当于一枚纪念邮票（**它的真实需求是另一件事：**版权保护、分成比例与合同条款**）——这是本章给“文学与制度”这个老题的新答案：**当一个门类大到能养活一千家上下游公司，它要的不再是承认，是合同法。
:::

::: example 用“适应器”解释一个套路 {#ex-shiyingqi}
选一个网络小说套路（退婚流、赘婿流、签到流、重生复仇、系统任务任一），填四栏：**①它在前五分钟承诺了什么；②它每千字兑付什么；③它替读者处理了哪种现实约束；④要把它写成一部“好小说”，作者最少需要改动什么**。
::: solution
**示例：重生复仇**——**①承诺：**读者立刻知道这次不会重蹈覆辙（**信息优势是主角的第一件武器（**也是一种道德豁免：他不必再受骗（**②兑付**（**每千字一次小胜：一句回怼、一个身份揭晓、一份旧账被清（**第 3 章“按灾情兑付”的爽文版：**兑付频率就是它的利率（**③现实约束**（**它处理的是“来不及重来”：**一次分配错误（专业、工作、婚姻、投资）在现实里的成本是不可逆的（**重生的想象力成本极低、情绪收益极高，因此它成为一种大众适应器，而不是因为它“低级”——**这是本章反对文化等级论的论证方式：先解释需求，再评价文本**）；**④最小改动**（**不是压缩，不是加文学腔；是给胜利加上代价——**只要胜利开始记账，兑付频率就必须降低，而降低兑付等于自杀（**于是真正的改造只能换制度：**把按章付费换成一次成书的出版，或换成按季播出的影视（**本课结论：**网络文学的形式问题，绝大多数是商业条款问题；因此对它的文学批评若不懂授权合同，就只是在赞美或斥责一份它并没有签过的合同。
:::
:::

::: intuition 一次罕见的自然实验 {#int-ziyan}
**为什么这一章对方法课重要**（**文学社会学长期只能做 retrospective 的研究：一手史料、版本、印数、日记；而网络文学提供了实时数据（**留存、订阅曲线、评论热区、月票榜（**于是第一次可以观察到：**在已知的选择压力下，叙事特征如何演化（第 1 课“做别人省掉的账”：**这一格不但没人填，它甚至是第一格有数的实验——**但它有两个不可忽略的限度（**①数据只属于平台，研究者拿不到原始留存（**可复现性受限于企业意愿（第 8 章独立来源：**目前关于网络文学的多数判断，来自少数几家平台的公开数据与自述（**②被研究的对象正在修改自己的定义（**任何关于网络文学本质的论断，寿命约等于一个技术周期（**所以下面的建议比结论更有用：**读网络文学时，同时保存它的界面截图（**榜单、页面、按钮、字数统计——**因为这个文学的一部分就是它的外壳，而外壳三年一换。

::: exercise 小论文：第二次出生 {level=3}
写六百至一千字，评“**网络文学并不是现代文学史的一个分支，而是中国小说出生方式的复归：它重新成为按次收费的、有现场反馈的、以续订为存在条件的口头—书面混合文体；把这一百年的‘发表—出版—评奖’链条当作文学的自然状态，才是历史上的例外。但复归不等于循环：说书人面对的是一群听众，作者面对的是留存曲线；听众会忘记，曲线会记录，而记录会训练机器下次替谁开门**”。须调用：**三个条件**、**类型作为货架**、**黄金三章与入话**、**筛选压力加速**、**长度即收入结构**、**承认的四道门顺序反了**至少六项；并裁决：**“复归说”（回到说书）与“例外说”（百年现代文学才是常态）哪个更能指导批评实践——须给出一条你会因此改写的具体书评结论**。
::: solution
