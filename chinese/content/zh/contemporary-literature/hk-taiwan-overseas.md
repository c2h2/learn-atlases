前七章把中国文学写成一个有编辑部的整体；本章说明它其实是三个——**同一套方块字在三个不同的发薪系统里长成三种文学；本章的方法是把“中国文学”当成一个海关问题来读：谁在什么年份被算作自家人，以及那次收货换了几次秤**。

## 定义：三个系统 {#def-xitong}

::: definition 谁给作家发工资 {#def-faxin}
**通说脉络**（**战后香港以报纸连载与影视工业供养通俗写作；台湾以大学、军方文艺体制与报纸副刊供养现代主义与学院写作；海外以英文世界的大学写作项目、出版社与奖项供养一批用第二语言写作的作者——**本课的全部结论都建立在这张工资表上（第 6 章三种收入的扩展：**不是作家选择体制，是体制的形式先规定了什么能被写完（**连载按格计酬，于是有“且听下回分解”的现代子孙；教席按学期计酬，于是有可以在课堂上读的长诗；写作项目按读者计酬，于是有必须先解释文化背景的句子。
:::

::: definition 为什么不能讲成“中心与边缘” {#def-bianyuan}
**一条反例就够**（**通说脉络：1980 年代以前，港台与海外保存并延续了若干在大陆被中断的写法——现代主义技巧、通俗类型、笔记与散文、以及“五四”以后的白话抒情；这些写法在 1978 年以后被重新输入大陆（第 2 章“抽屉”与第 5 章“借来的镜子”的合流：**一次文化的绕行，比任何宣言都有效地改变了母体的语法（**所以本章的图不是同心圆，是一张改道图（**更狠的一条：**1980 年代大陆作家读到的“现代小说”，有相当一部分是从译本、再从港台评论转手而来的二次知识（**影响的对象总是最近的教科书——而教科书有时是别人的。
:::

## 香港：连载的经济学 {#def-xianggang}

::: definition 金庸的三次改写 {#def-jinyong}
**通说脉络**（**金庸（查良镛）于 1955 至 1972 年在报纸连载撰写武侠小说，其后多次修订，通行本为第三次修订；他同时是报人与社评作者——**三个技术后果（**①**版面按日计酬**（**每天必须留悬念，且不能死太多人（**读者会换报纸（第 9 章“下回＝时间分期”的二十世纪版：**连载不是文体，是订阅制（**它解释了中国通俗小说的一切“冗余”：那冗余是续订成本**））；②**修订是一种版权行为**（**第 2 章“批本即定本”与第 3 章“复用授权协议”的当代闭环：**作者本人做了三百年的评点工作，于是“哪个版本是真的”这个问题第一次由卖方回答（**它的代价是：**新修本删去的枝节，恰好是旧读者记忆最深的枝节（**于是版权有了，接受史被切了一刀**））；③**报人的双重身份**（**写社评的手与写武侠的手共用一副政治判断（**通说脉络：其小说里的忠义与华夷之辨随其报刊立场变化而调整（**这不是八卦，这是生产端证据：**同一人的两种文体在同一家报社的日历上交替（第 2 课调解书：**作者活着，两边都成立，谁也不能证明谁解释了谁**。
:::

::: definition 进入文学史的一次游行 {#def-jinru}
**通说脉络**（**1980 年代武侠小说大规模进入大陆读者；严家炎等学者公开肯定金庸，王蒙《上马末回头著稿代柬》一类文章谈论金庸并被广泛引用；1994 年前后绍兴召开金庸学术研讨会，“金学”成为报章用语；2000 年前后其作品进入中学阅读与教材选目引发争论——**本课把这条线称为“一次为期二十年的收货”（**①**谁先收货**（**大众读者与中学课本，而不是文学奖与学术专著（第 7 章经典化四道门的重排：**这次是第四道门（外译与国际声望）之前的第三道门（教材）先开了（**教材是最不浪漫但最有效的加冕礼**））；②**批评的合法化动作**（**一位主流学者说“金庸的多卷本，我一卷一卷读完了”一类（通说引大意）——**请注意这句话的功能：**它不是评价，是入场券（**它让一位教授可以承认自己读过（**这是文学场里最常见也最少被记录的一种事件：**权威替自己签发通行证，顺便替整个行业改了目录（第 1 课“同行评审”的中国当代现场**。
:::

## 台湾：现代主义的另一条时间线 {#def-taiwan}

::: definition 没有断代的一代 {#def-duandai}
**通说脉络**（**1950—1960 年代台湾有现代主义诗与小说的论战与社团（包括《现代文学》一类刊物），其作者不少任教于大学；1970 年代发生乡土文学论战，1970 年代末以后“中国文学”的归属问题在岛内被政治化（通说脉络）——**本课的三个观察（**①**技巧没有失传，是因为有教席**（**当大陆的刊物关闭时，现代主义的句法在台湾的课堂上被当作“本国文学基本功”教下去（第 2 章“十年”的对照组：**同一代人的抽屉，与同一代人的讲义（**这是本章最重要的一个不对称：**一个体制把文学变成抽屉，另一个把文学变成大纲，二十年后抽屉里的人出来时，发现大纲已经先到了（**这就是 1980 年代大陆现代主义复兴为何大量经由港台转手的社会学原因**））；②**论战是配额之争的另一种写法**（**乡土与现代之争，与上一章“光明配额”在结构上同型：**争的都是“谁代表读者”（第 3 章定义权：**同一场官司在海峡两岸分别开庭，判决相反，而两边的理由都是“人民”（**这是本课关于“文学与政治”能给的最干净的一课：**理由相同、判决相反，说明理由是装饰，判决是函数。
:::

::: definition 一篇小说的两种读法 {#def-chuqing}
**通说情节**（**白先勇《永远的尹雪艳》《游园惊梦》一类以旧家族与戏文写离散；《台北人》由多篇构成，题词取“旧时王谢堂前燕”一类（通说引句大意）——**本课的技术判词（**①**它把“寻根”写成了反方向**（**上一章的大陆作家回到县里去寻根；台北人把根装在一个人身上下船（**尹雪艳就是一座祠堂：**她永远年轻，因为记忆不允许她老（**这就是为什么这一类小说在 1980 年代的大陆被大量模仿而少被这样解释（第 5 章“时间破碎”的另一种因果：**不是怀疑历史，是历史被搬了家（**②**它在大陆被读成“爱国”**（**通说脉络：《台北人》因写旧人旧事与乡愁而获接受；而它同时是一种彻底的失败者的抒情（**两种读法都成立：**前者按主题收货，后者按形式收货（**本课把它当作本章的标本：**同一文本，两套海关税则（**而税则由“我们需不需要台湾”这一年度需求决定——**这正是第 3 章“文本出境解释权归海关”的当代版）。
:::

## 海外：奖项、翻译与“被引用的国籍” {#def-haiwai}

::: definition 用第二语言写作的人 {#def-ereryan}
**通说脉络**（**高行健 2000 年获诺贝尔文学奖；哈金以英文写作于 1990 年代末获美国国家图书奖，其关于“作家的祖国是语言”的访谈被广泛引用；还有相当一批华语诗人旅居海外以双语刊物与朗读会维系——**三个机制（**①**合法性来源外置**（**当国内奖项与刊物无法或不愿收货时，海外的奖项成为反向护照（第 7 章第四道门：**外译与国际声望可以为国内定价提供担保（**于是出现一种奇特的双向流动：**一个人在国内先被禁或被忽略，在瑞典被加冕，然后在国内被重新出版（**本课称之为“绕道加冕”（**它的成本是：评价的货币要经过两次汇率换算，而每一次换算都靠翻译与汉学系抽成（**这就是为什么“谁代表中国文学”这个问题，永远有第三个收件人**））；②**“语言即祖国”是一种处境，不是一种理论**（**这句话对当事人是描述（**他确实只有语言可以搬走**）；对读者则常被当成纲领（**于是它变成一种新的正统：仿佛离开才是诚实——**第 15 课追认：**一句自述被引用二十年之后，会长出它没有说过的意思**））；③**它改变了汉语的句子的长度**（**为译成英文而写的中文，会减少典故、缩短修饰、增加可被解释的动作（**通说脉络：部分海外写作的汉语确实更“干净”（**本课的态度：这既是损失也是获得：**损失在互文，获得在可读（而可读性在 2000 年以后成为最贵的商品（第 9 章的伏笔：下一章它就是全部）。
:::

## 范畴本身 {#def-fanchou}

::: definition “华语语系文学”：一次改口径 {#def-yuxi}
**通说脉络**（**1972 年“中国（语）文学学会”在北美成立；1970 年代末《联合报》设立小说与散文奖项并持续推动海外华文写作；2000 年代“华语语系文学／Sinophone”一类概念被提出，意在把各华语地区的写作看成平行系统而非中心与边缘——**本课的处理（**①**把概念当制度史读**（**每一个新名称的提出时间，都能对上一次具体的机构变动：学会成立、奖项设立、大学课程调整、丛书出版（第 3 章“名称即主权”：**新词不是发现，是提案（**②**它解决了一个真问题，也造出一个新问题**（**真问题：**马来西亚、新加坡、台湾、香港的写作不再被当作“地方分支”；**新问题：**“华语”成了唯一的共同项，于是政治、制度与语言的差异被一条语言线抹平（**这就是反对者所说的“以语言划疆”（**本课的裁决：**两个都是尺子，用途不同：一个用来分书架，一个用来写文学史；把它们混用的那一步，才是错误（第 1 课尺子的产地：**先问这把尺要量什么）。
:::

::: intuition 海关的自白 {#int-haiguan}
**本章的结论是一句方法**（**“中国文学”“华语文学”“中文写作”这三个词的边界各不相同，而它们在同一篇论文里被交替使用而不作说明时，论证就开始漏气（**任何一次“某某是中国人写的所以属于我们”，都应改写成：**“某某在我使用的分类标准下被归入这一类，该标准是为解决某个具体问题而选的”（**这就是第 1 课“清单是眼镜”的最终应用：**眼镜可以换，但不能不声明自己戴了眼镜；**并且应当写明代价（**把港台与海外纳入，常使一个文学史叙述失去它的制度主语：**“中国文学的现代经验”从此必须有五个不同的时间线（**这不是坏事，这是诚实：本章的全部教学就压在这一句上（**多中心的文学史更难写，但它不会在 1949 年、1966 年、1978 年与 2000 年各撒一次谎。
:::

::: history 一条改道图 {#sec-gaidao}
**1950s—1960s** 港台各自完成现代主义建制（**讲义对抽屉**）；**1972** 北美“中国（语）文学学会”成立（**通说脉络：**第一次出现一个跨地域的组织性主语（**它比任何理论早了三十年就把“华语文学”当作一个可管理的领域（**学会即海关**））；**1977—1979 台湾乡土论战余波与《联合报》文学奖设立（通说脉络：奖项开始制造经典（而它后来成了华语世界最稳定的“收货标准”之一（第 7 章四道门的南部版本）；1980s 武侠与言情小说进入大陆书市、港台现代作品经由刊物与选本转手（一次没有报关单的进口——最讽刺的连锁：大陆先锋派从中继站拿到了他们用来反对写实主义的工具（而工具的原产地标签被撕掉了）；1989 以后 新的离散写作潮（通说脉络：三种口音形成：1950 年代的、1989 年以后的、以及留学与移民的（把它们统称“海外华语文学”，就是本章批评的那种抹平））；2000／2012 两位华语相关作家获诺贝尔奖（一次在中文世界几乎不可读，一次引发国内的定价重估（两种结果都是同一种机制：声誉从外部输入，价格由内部决定。

::: exercise 小论文：五个时间线 {level=3}
写六百至一千字，评“**任何一部单线的中国现代文学史，都必须在四个年份撒谎：1949、1966、1978 与 2000。它撒的不是事实的谎，而是主语的谎——它假装‘我们’在这四道坎上始终是同一些人。而把香港、台湾与海外写进来，并不会让文学变得更丰富，它会让‘文学’这个主语变得需要解释：这是它唯一的、也是最大的用处**”。须调用：**三种发薪系统**、**连载经济学与修订版权**、**教席与抽屉的不对称**、**借镜子与只收设备**、**绕道加冕**、**新名称作为提案**至少六项；并裁决：**“多中心”写法是否只是另一种收编——你须给出一个可核对的检验（例如：某一部多中心文学史在某一具体作家身上做了什么删改）**。
::: solution
判分点：六项机制（**工资、连载、不对称、设备、加冕、提案**）；检验（**合格答案须具体到一部书或一门课，并指出它为了“多中心”而新增的省略——**常见的是：把各中心的政治各自包好，于是制度差异被翻译成了“地区特色”（**更狠的一种检验：多中心叙事是否把“市场”写成唯一共通的结构，从而用经济统一代替了政治统一（判卷看是否写出：**任何主语扩编都会带来新的漏名单：**比如马来西亚华文写作、华语科幻的翻译政治、以及被“华语”一词从分类表里抹掉的用非汉语写作的中国作者——**这才是本课的最终练习：给多中心的文学史再找一次旁听席**）；结论若能写“**所以四个撒谎的年份提醒我们：文学史不是一条河，是一叠报关单；写多中心不是为了热闹，是为了让每次盖章都留下日期和经手人”，即 A。
