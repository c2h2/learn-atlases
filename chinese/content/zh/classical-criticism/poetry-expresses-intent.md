title: "诗言志"
---

本课程从此处开始处理中国人自己怎么说文学；而第一句材料只有三个字——**“诗言志”。本章的论点是：中国文论的起点不是“怎样写”，而是“谁可以借诗说什么”；因此它的第一章不是美学，是一部许可史**。

## 定义：一个纲领的来历 {#def-gangling}

::: definition 三个字与它的场合 {#def-sange}
**通说脉络**（**“诗言志”这一公式见于传世的上古文献，战国诸子亦以类似句式论《诗》；现代研究者把它称为中国文学批评“开山的纲领”（**本课先做一件枯燥的事：找出它在什么场合被说（**它出现在两类语境里：一是论礼乐与政教的段落，二是外交与酬答中引用《诗》的记载（**注意第二类**（**春秋的贵族在宴会上让人演奏或吟诵《诗》的某篇，用以向在场的人表达自己不便直言的意思；**留下一句常被引用的话，大意是引诗各取所需（**通说脉络：**于是中国文论的第一句话，描述的是一种引用行为而不是写作行为（**本课由此得出本章的立论：**最早的诗学问题是语用学的：**一句话说在别人嘴里、被用于此时此地，它的意思由谁负责（**这一问在两千三百年后仍然是全部引用理论的问题（**第 3 门课与第 7 门课的引证伦理，在此有一个先秦的开头。**
:::

::: definition 志是什么 {#def-zhi}
**一个词的三层**（**“志”在早期文本里至少含：心中所之（怀抱与意图）、记（记下、志向的记忆）、以及识（标记与判断）（**通说脉络：**本课不取词源学的任何一说，只指出一个结构事实（**“志”这个词天然把个人意向与道德重量绑在一起：**说“志”比说“情”体面，因为它暗示一个方向的、可被审查的、可以负责的东西（**这就是言志说统治两千年的机制：**它给了私人情感一个公共身份，代价是要求它可被追问（**本课把它写成一句可迁移的判断（**凡一种理论把表达定义为“表态”，它就会同时给予许可与建立审查；**这一句在本课程后面的“文以明道”“歌诗者有声”诸章都会重演（**也适用于今天的任何一次“你要为你的话负责”的争论（**第 8 门课“面子是可转让账户”在此有一件古董版本：引诗是用公共账户花私人钱（**这一点下一章讲儒家文学观时还要用。**
:::

::: definition 一篇序的两栏 {#def-lianglan}
**通说脉络**（**汉代传下的《诗》序提出：志在心为志，发言为诗；情感在内心激动而表现为言语，言语不足则续以嗟叹咏歌；又说“变风”之作发乎情、止乎礼义（**本课把这段话读成一张两栏表（**第一栏是发生学**（**从情到言到歌到舞的递进，它解释诗为什么带音乐性：因为语言不够用（**这一条极其重要：**它是中国文论里少见的“媒介不足”论证——**诗之所以存在，是因为散文做不到（**第 4 门课声律与第 15 门课用典都是这条论证的后代（第二栏是规范**（**“发乎情，止乎礼义”：情感是材料，礼义是形状；**两者不是对立而是工序（**本课的读法（**这句常被引用为“压抑”的证据，但它更接近一份工艺说明书：**它承认情感是唯一的原料，同时给成品规定了可交付的形状（**真正的压抑不在这一句，而在谁来判定“止”的位置——**于是“温柔敦厚，诗教也”一句（**通说见于论礼的文献**）就从美学要求变成了一种语体规范：**批评不再问你是否诚实，而问你是否保持在可被容忍的强度上（**第 4 门课修辞课那条“限定是保险杠”在此有两千年的先例（**本章的作业会要求你测一测这条限定今天还值多少。**
:::

::: definition 美、刺与观 {#def-mei}
**通说脉络**（**论《诗》的旧说里有三组功能词：美（颂美）、刺（讽刺）、观（观察风俗）（**本课把“观”单独提出，因为它是一个信息制度的设计（**①谁在观察**（**名义上是统治者：**于是批评的合法性来自它对治理有用，而不是来自它正确；②用什么观察**（**歌谣与诗，因为它们在民间流通而不必通过公文系统——**这是一个关于信息渠道的洞见：**统治者知道正式报告会说谎，所以设置了一条以审美为形式的非正式信息通道（**通说脉络：古代有“采诗之官”一类传说；**本课把这一传说当作制度想象来读：**它设想的是一种不能被下级伪造的证据形式（③代价**（**以审美为代价换取合法性：**一首诗一旦被要求“可觀”，它就自动开始修饰自己（**这就是本章最难的一句话：**观察制度既给诗以地位，又给诗以任务；而任务会慢慢地把诗变成汇报材料（**第 19 课观察一节与此完全同构：**被采集的经验，在采集表上就不再是经验。**
:::

::: definition 第二组对子：发愤 {#def-fafen}
**通说脉络**（**一位汉代史家在自述性质的书简里列举若干在困厄中写成的著作，大意是说这些人心中有所郁结，故述往事、思来者；后世把这层意思概括为“发愤著书”一类（**本课把它作为言志说的对手来介绍（**①言志**（**表达是有方向的、可交付的表态；②发愤**（**表达是被积压之后的排放，它的读者不一定存在，它的功能首先是活下去（**这两条的分野在两千年里反复出现：**诗作为公共行为与诗作为存续证据（**本课给一个判准（**当你读到一份自述说“我写是为了不致发疯”，同时它又确实被刊刻流传，你不要以为这里有矛盾：**发愤说在实践上常常是一种出版策略：它用作者的痛苦为文本担保（**痛苦是最难反驳的担保物（**通说脉络：后世批评史上“穷而后工”一类说法与此相关；**本课在第 19 课已给过它的社会学读法：**把处境说成品质，是文学批评最常见的善意误解（**本章只补一句：**发愤说比言志说更长寿，因为它的担保物不必更换。**
:::

::: example 一句诗，三个场合 {#ex-sange}
取《无衣》里的“岂曰无衣，与子同袍”（**此句传世可见**）。假设你在三个场合分别引用它：**甲：一场共同行动的动员；乙：一次事后追念同侪；丙：一次对朋友的责备（嫌对方不够同盟）**。请写出每个场合里听话人要理解的意思，与说者要承担的责任，并回答：**这三个意思里，哪一个是“这句诗的意思”**）？

::: solution
**甲**（**取“同袍”之共衣共战，作动员：**听话人理解的是“我们被绑定”，说者承担的是“你据此有义务”；②乙**（**取“昔我同袍”，作追念：**此时同一句话被移入过去时，说者承担的是“我承认这段关系曾存在”；③丙**（**取“岂曰无衣”的反诘：**这是最锋利的用法：**它责备对方声称匮乏是借口；**听话人听到的是“你的困难不算困难”，这是引诗最容易伤人的地方（**哪一个是它的意思**）？**本课的答案分三层（**其一，历史语言层：这首诗在传世文本中的语境与前三者都不同（**通说认为它属于秦地一类的军中歌谣，但其本事亦无定说）；其二，语用层：三个意思都是真实的，因为它们被听懂并引起了行动（**第 3 门课意义三角：意义在指称与效果之间，不在词里；其三，制度层：三个意思的地位不同——**哪一个被记入注疏，取决于哪一种解释在那个时代对治理与教化最有用（**判分（**能写出第三层者为 A：**这告诉我们，古典文本的意义之争从来不只是解释之争，而是谁有权规定“这句话在我们的传统里代表什么”；**而本章接下来的每一章都在打这场架（**这一点在下一章儒家与道家的文学观里会立刻显形。**
:::
:::

::: intuition 为什么这个纲领难以推翻 {#int-nantui}
**一个理论的性质**（**“诗言志”是一句关于说话者的理论，而不是关于文本的理论：**它不问诗长什么样，只问说诗的人心里有什么（**三条后果（**①它的证据在别人心里**（**因此它几乎不可反驳：任何反例都可以被说成“他其实是另一种志”（**第 16 门课所谓作者意图的争议，在此有三千年前的底本（②它可以无限吸收对手**（**“缘情”来了，就说情也是志之一种；“摹仿”来了，就说摹仿者有志；“形式”来了，就说形式选择见志（**一个能吸收一切对手的理论不因此为真，它只是把可驳倒性转让给了它的应用者；③它的真正生命力在使用它的制度**（**只要教育仍以“知人论世”为主要读法、只要批评仍以“这说明了作者的什么”为常见结论，这句公式就继续在运转（**本课的教学要求（**你以后每次写下“作者在这里表达了……”，都要意识到你在用一句三千年前的公式，并且要能说出你何以知道他有那个志——**从证据链到修辞，本课已经教过你四次了（**这就是把一门理论课当逻辑课来上的理由。**
:::

::: history 一个纲领的三次改写 {#sec-gaixie}
**春秋至战国**（**聘问与宴饮中的赋诗实践；诸子引《诗》以证己说（**通说脉络：**本课的第一次改写：**“志”在此是公共的、可被审查的意向，而不是现代意义上的个人内心（②**汉代**（**《诗》被立为经，序与注构成一套解释制度；同时乐府制度采集歌谣，论者称其人“感于哀乐，缘事而发”一类（**通说见于史志（**这是重要的一处并置：**采集与解释同时被国家接手（③**宋**（**道学家的文论把“言志”重新解释为涵养的表露，于是诗的评判标准向作者的人格与工夫偏移（**通说脉络：**本课称此为道德担保的内化：**从前看它是否合礼义，现在看作者是否诚于中（④**明至清**（**复古与性灵之争反复调用“志”与“情”这一对旧材料；批评家各自把对方指为无志或溺情（**通说脉络（⑤**二十世纪四十年代**（**一部研究论著以“诗言志”为题，把这组材料梳理为一部批评史（**通说归于朱自清（**本课的评价：**它同时做了两件事：把这个公式确立为“纲领”，并使我们看见它是被确立的（⑥**一九五〇年代以后**（**“现实主义—浪漫主义”一类的二分被用来重排中国文学史；**通说脉络（**本课的结尾观察：**一个公式的寿命，取决于它能被多少次改写而不必更换名字；**这也是判断任何理论的工具：**它被改写过多少次而不死，就说明它的措辞留了多少空（**这句话你可用在任何一份制度史里。**
:::
