前两章是两篇文章；本章是一部五十篇的书——**它的野心不是提出一个论点，而是把当时人知道的一切写作安排进一个有条目的系统；本章既讲它做到了什么，也讲完备性要付什么代价**。

## 定义：这本书是什么 {#def-shishenme}

::: definition 一部行业全书 {#def-quanshu}
**通说脉络**（**南齐末一位作者完成五十篇的著作，自序说明其安排：上篇论文体，下篇论制作与批评；末篇自叙著述之志（**本课给一个现代类比，然后立刻收回它（**它最像一部行业手册：有产品目录（**三十余类文体的源流与写法**）、有生产流程（**从构思到删改**）、有质量检验清单（**评文的六条观察点）、有行业史（**时代与文变的关系**）、有职业伦理（**文才与品行**）（**它的伟大来自这个野心：完备；**它的弱点也来自这里（**下面单讲（**一句背景（**这位作者长期依附于一座寺院整理典籍，其书在成书后曾示于一位当时有影响的文人，后者称许它；**通说见于史书本传（**本课只取一条制度含义（**一部书的流传，从它被某个人称许的那一刻开始就有了运气成分；**而“被谁称许”这类事，本章后面每次都要提。**
:::

::: definition 五根柱与两步分法 {#def-zhu}
**通说脉络**（**全书开头数篇确立依据：文源于道，须征于圣人，宗于经，正其名称，并处理继承与变化的关系（**两条读法（**①这是一种授权结构**（**先把权威安放好，再谈具体写法：**在当时的写作环境里，这是一种必要的开场白，而不是一种保守（**本课反对把这类章节读成“迂腐”：**任何一部改革的行业手册都要先证明自己有资格说话；②文笔之分**（**书中按声韵把作品分为有韵与无韵两大类，分别处理（**通说脉络：**本课强调这一分的现代意义：**它说明当时人把“文学”的边界画在声音上而不是画在虚构上——**中国没有发展出以摹仿为核心的文类体系，这一条是最有力的内部证据（**第 2 门课与第 16 门课的“文学是什么”问题，在此得到一个历史答案：**这个问题在六世纪的中国问出来是另一个样子。**
:::

::: definition 研究文体的四步 {#def-sibu}
**通说脉络**（**书中自陈处理每种文体的程序：追溯其起源以表其流变，解释其名称以明其义界，选取作品以定其代表，条理其义理以立其规范（**本课把这四步按现代用途翻译一遍（**①历史**（**这个体裁最早为解决什么问题而出现的；②定义**（**它的名字当时被怎么用；③例证**（**哪些作品被视为该体裁的典范；④规范**（**由典范推出的可教条目（**你会认出这是今天一份文献综述的四个部分；**而它比任何现代教材早了约一千三百年（**本课要求你把这四步当作本课程全部写作训练的检查表：**你的每一节都要能回答这四个问题；**答不出第①步你就在写现时态，答不出第②步你在使用未经定义的关键词，答不出第③步你的规范没有例证，答不出第④步你只是堆材料（**这一条会在本课程最后三章反复出现（**它不是文学理论，是方法。**
:::

::: definition 六观：一张检验单 {#def-liuguan}
**通说脉络**（**书末论批评之难，说世人常“贵古贱今”“崇己抑人”，因而给出一组观察点：体制的安排、辞采的设置、通变、奇正、事义、声律（**本课把这张清单当作全书最可执行的一件东西，并补三条使用说明（**①它把“好”拆成了六个可分别打分的问题**（**于是分歧可以定位：“我不是不喜欢这首诗，我是认为它在第四项上过分”（**这就是本章所谓批评的可用性（②它暗含一个立场：形式项目与内容项目并列**（**通说脉络：**这是它比后世许多道德化批评更开阔的地方（③它没有权重**（**六项各占多少没有说；**而一项没有权重的清单，其结果取决于谁在填（**本课称此为“体系的空格”，它下面会反复用到。**
:::

::: definition 三对范畴 {#def-fanchou}
**通说脉络**（**下篇以成对的概念组织问题（**①情与采**（**书中说二者相依：文依附于质，质也等待文；并有那句常被引用的分别：为情而写者要约而写真，为文而写者淫丽而烦滥（**本课的换算：**这是一个关于动机的判准，但它不是道德判决，而是效率判断——**为文而写的作品会在别处付出成本（②通与变**（**继承使路径不竭，变化使生命持久（**这是一句关于任何行业的常识，被写成了一条历史规律（③隐与秀**（**隐是文外重旨，秀是篇中独拔（**注意这两件事的分裂：**一首诗可以同时缺两者；**而中国后世批评把“隐”抬得远高于“秀”——**上一章说过的道家许可证在此生效（**本课把三对范畴合起来给一个判语（**它们都是成对的，因为作者用的文体是骈文；见下节。**
:::

::: example 用六观评一联 {#ex-liuguan2}
取传世名句“海内存知己，天涯若比邻”（**此联传世可见**）。请按六观逐项写一句话评断，并给各项一个权重，最后写出你这套权重的立场。

::: solution
**逐项**（**①体制安排：此联处在赠别诗的转折位，承担从“别离”转向“不伤”的功能；②辞采设置：用字极素，无藻饰；③通变：以议论入赠别，是对伤别旧格的变；④奇正：语正而意奇，奇在把距离与情感脱钩；⑤事义：不用事，义在言外；⑥声律：对偶稳（**通说脉络：此联在律体形成期的声律地位另有讨论；本课只作练习性判断（**权重**（**你可以给③④各三成，其余四成一**（**这是重通变的批评家；**也可给②⑥各三成——**那是重语言质地的批评家（**本课要的是最后一步（**写出你的权重的立场**（**重通变者会把文学史写成一部问题解决史，因而容易低估那些不解决问题的作品；**重质地者会把文学史写成一部风格集，因而无法解释为什么有些风格会统治一个时代（**判分：**能写出“我的权重会带来这种盲区”者本章 A**（**这就是本章对“体系”的全部态度：**一张没有权重的清单不能替你判断；而一组有权重的清单，会让你看见自己的偏见——**这两者都比“凭感觉”强，而它们的区别是可审计性（**上一章那条“批评的价值由能否被执行检验”在此得到它的高级版：**由能否被追责检验。**
:::
:::

::: intuition 骈文怎样塑造一部理论 {#int-pian}
**一个被忽略的事实**（**这部书是骈体写的：四六对偶、用典、声律讲究（**三条后果（**①对句强迫命题成对**（**你要写出两半来，于是世界在理论里就以“情—采”“通—变”“隐—秀”的样子出现；**它不必然使思考二元，但它使二元最省力（②对句禁止精细的从属结构**（**“因为……所以在例外情形下……”这样的句子很难对偶；**于是这部书缺少条件句，也缺少量化表述（**这就是它的“空格”的文体来源（③用典使论点带上权威**（**一个判断被写成两件事的类比，它就不需要论证；**这是骈体最强大的修辞功能，也是它最危险的（**本课的一般化（**要理解任何一部理论著作为什么不说某句话，先看它的文体能不能说那句话；**这一问在读今天的学术论文时同样有效：**为什么社会学的段落总是先讲方法再讲结论？为什么心理学的段落总是先讲显著性？这些都不是学科逻辑而是文体的语法（**第 10 门课与应用文课都会再讲一次。**
:::

::: exercise 小论文：完备性的代价 {level=3}
写六百至一千字，评“**体系型著作的力量来自它拒绝遗漏，它的失败也来自这里：当一切标准并列而不排序，读者总能找到支持自己趣味的那一篇。这类书因此格外长寿，也格外容易被架空——后世引用它的句子，同时用它反对它的对手。要真正继承一部体系，必须替它补上一件它拒绝做的事：给出权重的理由**。须调用：**行业全书的类比及其收回**、**授权式开场**、**四步程序**、**六观与其权重空缺**、**三对范畴**、**骈体与范畴形状**至少六项；并裁决：**你更愿意写一部体系还是一件论点（以你此刻能写出的东西为限，说明你放弃的那一种的长处**。

::: solution
