前两章的文学观都是关于用途与限度的；本章两篇文字第一次开口描写手艺本身——**批评在第三个世纪换了一个问题：不再只问诗该干什么，而问一首诗是怎么做成的，以及为什么我做不成**。

## 定义：《典论·论文》 {#def-dianlun}

::: definition 四句名言的三种工作 {#def-siju}
**通说脉络**（**这是一篇评骘同时代作家的短文，全书已佚，其论文一篇因一部诗文总集而存（**四句常被引用的话各在做不同的工作（**①“文人相轻，自古而然”**（**这是一句社会学的开场：**它把批评的对象从作品移到批评者，并先给读者的偏见打预防针；②“奏议宜雅，书论宜理，铭诔尚实，诗赋欲丽”**（**四科各有其宜：这是文体分类的早期成式；**注意它的句式——**不是描述而是规定，也不是美学而是职务说明书（③“文以气为主，气之清浊有体，不可力强而致”**（**才能被说成先天的、不可转让的，并以音乐作比：同一曲谱，人之引气不齐，父兄不能移子弟（**通说脉络：**这是中国文论里最接近天才论的一句（④“盖文章，经国之大业，不朽之盛事”**（**写作被赋予两项尊严：政务与不朽（**本课把第③④两句放在一起读，因为它们构成一个结构（**才能是不可转让的，作品却是可转让的不朽；**于是写作成为一件把不可让渡的东西转化为可让渡的东西的事业（**本章的第一句话：**这是中国文论里第一份把文学说成资产的说明书（**而它出自一位将来要做皇帝的人的手笔，这一点不是巧合，下面单讲。**
:::

::: definition 谁在评谁 {#def-shui}
**通说脉络**（**建安年间一个贵族圈子里的作家们同题写作、互相赠答并彼此评点；此文即在其中产生（**本课的三点制度读法（**①当文本在圈子里流通，描写手艺就比判断道德更有用**（**你要说“你这句比我好在哪”，而“他的心术正”对同题竞技毫无意义；**这就是本章所谓技术转向的社会条件（**这一句是本课对方程式的重写：**批评的粒度由交换的频率决定；**第 14 门课的“发行格式改变内容”在此提前四百年出现（②评议是一种位置（**评定同时代人是把批评当作权力的操练；**一位未来的皇帝给当代作家排定高下，这件事的性质不是文学（**通说脉络：**本课提醒：**不要把这一层读成“阴谋”，它更接近一种常规：**在同一个小圈子里，判断力是最有价值的社交资本；③我们读到的文本是选本的产物**（**全书已佚，一篇因总集而存；**于是中国批评史的第一部名文，其实是另一场选择的结果（**上一章那句“读法有出身”在此立刻可用：**我们现在以为“文体论始于曹丕”，这一判断的分量取决于《文选》编者觉得哪一篇值得收（**这一点在第 4 章会更尖锐，因为编《文选》的人与写《文心雕龙》的人年代相接。**

## 定义：《文赋》 {#def-wenf}

::: definition 意、物、文的三角 {#def-sanjiao}
**通说脉络**（**一篇以赋体论文学制作的作品，其序里有那句常被引用的自述：常担心意不能称合物，文不能逮及意；并说并非知之为难，能为之难（**本课把它读成一个三层模型（**①物**（**外物与遭遇：四时迁物、万物感意；②意**（**在心中成形的东西；③文**（**写出来的东西（**每一段都有损耗，而两种损耗的性质不同：**意不称物是认识问题，文不逮意是技术问题（**通说脉络：**这个三角的价值在于它给了批评一个诊断程序（**在本章的例题里我们把它当作故障定位表使用（**一句比较（**它与现代语义学里那个思想—指称—符号的三角形式相近而旨趣不同：**陆机的三角是为写作者设的，语义学的三角是为解释者设的（**通说脉络：两者常被并提；**本课要求你写比较时说明这个方向差，否则就是一种无内容的相似（**第 6 门课与本课在此握手，也在此分手。**
:::

::: definition 诗缘情而绮靡 {#def-yuanqing}
**通说脉络**（**同一篇作品在论文体的一段里说，诗因情而发且文饰华美（**这一句在两千年里被当作与“诗言志”对立的宣言；本课对此做三重处理（**①文本层**（**在原文里它是十来个并列短句中的一个，用来描述某种文体的风貌，语气不是立法（**通说脉络：**②范畴层**（**“缘情”与“绮靡”并举才是要点：它把情感与形式之美绑在同一体裁上，**于是“写得漂亮”第一次被写成抒情诗的正当义务（③接受层**（**把它读成宣言，是后来人在别的争论里需要的读法（**这是本章最重要的一课（**一个句子的思想史作用，往往大于它的思想内容；而研究前者比研究后者更能解释为什么某些话被记住（**第 1 章那句“公式的寿命取决于措辞里的空格”，在此有一则实例：**“言志”与“缘情”之所以能对立两千年，是因为两边都没有定义清楚（**本课把它们并排而不判胜负（**它们回答的是不同问题：一个问表达许可给谁，一个问文体的义务是什么（**把它们对立起来，是用政治争论的框架去套一份文体清单——**而这一操作在二十世纪的中国学界非常流行（**通说脉络（**注意，这一句本身就是上一章的教训：你以为在读古人，其实你在沿用某份教材的两栏。**
:::

::: definition 制作的词汇 {#def-cizuo}
**通说脉络**（**这篇作品贡献了一批后来成为常识的说法：要挑一句要害的话立在一篇之要（后世所谓警策）；美石藏于山中而使山辉，水怀珠而川媚；以及凭虚无以求有、敲寂寞以求音一类（**本课把这批句子读成一次词汇发明（**①它们都是空间与听觉的隐喻**（**“立”“居要”“韫”“辉”“叩”：制作被想象成安置与敲击（**这不是修辞，是概念装置：**此后中国批评说一首诗“有句无篇”“一篇生辉”，用的都是这套空间词汇的下游（②它们承认了制作里有偶然**（**“叩寂寞而求音”意味着可能敲不出声音：**这是技术文本最诚实的样子；③它们是可教的**（**与“气”的不可力强而致相反，这里的每一步都是工序（**于是本章的两篇文字恰好构成一对（**曹丕讲禀赋的不可转让，陆机讲工序的可传授；**通说脉络：**后世“天成”与“人工”之争、以及“文章本天成，妙手偶得之”一类的宋人句子，都在这一对之间摆（**本课的判断（**任何写作教学都必须在两件事上同时说话：**哪些是可教的工序，哪些不是；只讲前者教出匠气，只讲后者教出借口（**这一句是本课程对全部写作课的要求，你在后面三门写作课里会看到它被反复执行。**
:::

::: example 用三角定位一次故障 {#ex-guzhang}
三种失败的现象：**甲：你有一堆材料，写出来却像清单；乙：你心里明白要写什么，坐下来三分钟就写不出第二句；丙：你写完了，读一遍觉得“意思被写小了”**。请各判断故障落在物、意、文的哪一层，并给一种可执行的修法。

::: solution
**甲——故障在“意”**（**材料不缺，缺的是把材料组织起来的那个判断；**症状是清单式：**每一段都在同一层，没有一句承担观点；修法：**先用一句话写下你想主张什么，然后删去所有不能为这句话作证的材料（**第 19 课与论说文课那条“主题是筛子”在此是同一道工序（②乙——故障在“物”**（**不是不会写，是没有可写的经验：**脑子里只有类别词（“秋天”“故乡”）而没有一次具体的观察；修法：**停止写作，去做一次带记录的观察，并规定自己必须写出三个别人写不出的细节（**这一条与上一章的“观察即采集”相冲：**本课的答案是：采集用于认识，用于写作时要把表重新撕开（③丙——故障在“文”**（**经验与意思都在，语言容量不够；**而它常常是句法问题不是词汇问题：**中文里“意被写小”多半发生在把复杂关系写成并列短句之处；修法：**先找出那句被写小的主张，再给它一个句子结构（让步、条件、递进），然后重读（**通说脉络：**这一层正是陆机“文不逮意”的原意所在（**判分（**三条修法都必须是今天能做的动作**（**写“多读多写”“积累素材”者本章不及格——**这不是安慰，是本章唯一的评分标准：**批评的价值由它能否被执行为检验。**
:::

::: exercise 小论文：禀赋与工序 {level=3}
写六百至一千字，评“**把才能说成先天的气，是一种极其实用的理论：它解释了为什么教学有边界，也替失败者准备好了体面的说法；它同时替成功者解释了为什么他的成功并非努力的结果——两种安慰都由同一句话提供。而把制作说成工序，是另一种实用：它使写作可以被教、被定价、被卖给外来者，也使写作者成为一个行业。中国文论在第三个世纪就同时买下了这两套话，此后再未丢掉**。须调用：**四句各做何种工作**、**评议作为一种位置**、**意物文三角**、**缘情与绮靡的绑定**、**制作词汇的空间隐喻**、**名文的选本出身**至少六项；并裁决：**一种写作教学应当把重心放在哪一套话上，并说明另一套话被你如何处理**。

::: solution
判分点：六项机制；裁决（**必须处理“另一套话”而非宣布胜利：**合格答案的骨架：**教工序，讲禀赋**（**工序是可评分的对象，故教学必须以它为主；**而禀赋要说清楚它的功能：它解释差异，不解释优劣；**具体做法：**①在评语里只写可执行项（**“此处缺让步”而非“缺乏才气”**）；②在讨论成就差异时允许使用天赋语汇，但要求它只做描述不做判决；③公开教学的能力上限（**告诉学生这门课能保证什么、不能保证什么；**这一条是本题的最高分点，与本课程反复的“不撒谎”一致（**被处理掉的那一套**（**若不谈禀赋，写作教学会滑向“写得不好是功夫不到”的道德指责；**若只谈禀赋，则学费无处收取（**本课把这一句视为对全部写作培训的社会学定义（**这一处必须写出来才给 A**）；结论若能写“**所以两千年前那两句话仍是我们此刻的处境：一个人要靠工序谋生，要靠差异自处；批评的全部诚实，就在于分别对这两件事说话，而不在其间撒谎**”，即 A。
