上一章的书拒绝作判断，因为它要给整个行业建目录；本章的书只做一件事——**把诗人排进三个等级，并且为每个人写一句理由。本章的论点是：批评成为一门学科，不是从提出定义开始，而是从这种可被反驳的姿态开始**。

## 定义：一部排名的书 {#def-pauming}

::: definition 三品与一句理由 {#def-sanpin}
**通说脉络**（**这是一部论五言诗的著作，把汉代至齐梁的诗人一百余家分为上、中、下三品，每人系一段短评（**本课先指出这个格式的革命性（**①它必须表态**（**不能两可，不能说“各有千秋”；**排名是一种承诺（②它必须给理由**（**理由可以错，但没有理由的赞美无法讨论；③它把分歧从人格移到判断**（**你可以反对某人在中品，而不必反对作者的品格（**通说脉络：**这就是本章标题下的第一句话：**把评价写成可反驳的形式，是批评史上的真正发明（**它比任何一条美学命题都更耐用（**对照上一章：那部书给了六项标准却不给权重；**这本书给了权重（**三品就是权重**）！**于是两书互补，而后世把它们当作对手——**这是接受史上一个常见的错位。**
:::

::: definition 直寻 {#def-zhixun}
**通说脉络**（**书中有一句常被引用的话，大意是考察古今的佳句，多半不是借补前人语料得来，而是直接取得；并批评当时拘守声病之作使文多拘忌、伤其真美（**本课分三层（**①文本层**（**“直寻”针对的是两类风尚：堆砌书事的“补假”，与讲究声病的拘束（**通说脉络：齐梁声律之论盛行，这是它的靶（②理论层**（**它主张佳句的来源是诗人对景物的直接遭遇，而不是对前人语句的加工（**这是一条关于发生学的命题（③检验层**（**这条命题可以被反驳：该书所举的许多“直寻”名句，其实都有前人文句的背景；**而“直接”本身是一个程度概念（**本课的评价（**“直寻”是一个真命题的假形式：**它正确地反对了一种以材料量为美德的写作，错误地假设了存在一种不经语言的直观；**第 15 门课“用典是申诉书的附件”在此得到它的对手；**而这两者的争辩在两千年里从未结束，因为它其实是关于写作教学的一个问题：**你能教给学生的东西有多少是间接的（**凡主张“只能直接”的人，通常已经有了一种不可教的资本；**这一句本章不放过，请在小论文里驳它。**
:::

::: definition 每人一个祖先 {#def-zushan}
**通说脉络**（**该书为多数诗人标注其诗风所自出，例如某人“其源出于某家”，并把若干支上溯到《国风》《小雅》与少数几位早期作家（**本课称此为谱系法，并给出它的三种功能与两种失败（**三种功能**（**①它把零散的相似变成可叙述的关系**（**“像”被说成“继承”，于是风格有了历史；②它是一种压缩的记忆术**（**记住一个人的源头，就记住了半句评语；**在印刷之前这是一种知识基础设施；③它建立了一个标准（**“出于”某家意味着某家是尺度（**通说脉络：**这一点使它同时成为一份经典目录（两种失败**（**其一，误认：风格相似可能来自共同处境、共同文体或巧合，而非阅读关系；**一个系统若不能区分“像”与“读过”，它写出来的就不是影响史而是相似史；其二，无源可归：当一个诗人不属于任何一支，系统要么强行安置，要么把他压低（**本课举一个最著名的例子：**通说脉络：后世最不平时，说某位被置于中品的诗人其源出于一位名声不高的作家；**这一案例在两千年里被反复提起，其意义不在委屈了谁，而在于它暴露了系统的形状——**下面单列一节。**
:::

::: definition 一位中品的诗人 {#def-zhongpin}
**通说脉络**（**该书把后世公认地位极高的某位诗人放在中品，并给出一条不高的源头；宋以后其地位不断上升，到若干批评家笔下已进入最上（**本课把这件事当作一次“评级系统故障”的完整记录，做四步分析（**①系统内的解释**（**该系统的权重压在辞采的华美与风力；**这位诗人的语言在该系统里被读作“质直”，因而分数有限（**这不是偏见，这是权重的结果；②系统的寿命**（**品第是一个评价体系在一个时刻的输出，而评价体系的寿命短于它评的作品；**于是我们得到了批评史最重要的一条定律（**作品的地位可以移动，因为它的评价体系的权重被后人改了（③后世的改法**（**宋人抬高这位诗人，靠的不是替他重新排名，而是换掉权重：**把“不事雕琢”从缺陷改述为一种成就；**上一章那条“缺陷被重述为理想”在此有了一则教科书案例（**第 19 课“含蓄是压强”、第 14 课“借来的镜子”都属同一机制（④本课给学生的要求（**你读任何一份榜单（文学奖、排名、评分**），都要问这三句：**这套权重是什么；**它比被评的东西更长寿吗；**有没有人是靠改权重而不是靠得奖翻身的（**这三句是可以带进任何一份工作的批评技能。**
:::

::: definition 滋味 {#def-ziwei}
**通说脉络**（**该书称五言为众作之有滋味者，并把“指事造形，穷情写物”的切至作为好处（**本课把“味”这个范畴单独讲，因为它是中国文论此后一千年的主要感官隐喻（**①它把评价放在身体上**（**不是“真”而是“耐咀嚼”；**这带来一种新的论证格式：**好作品是你会重读的作品——**一种可操作的事实主张（②它无法转译**（**你无法把“有味”翻译成一个定义；**这正是它的力量与它的问题（**上一章那条“短语要翻译”的训练在此最有用；③它埋下了后来的整套词汇**（**味、韵、兴趣、神韵——**通说脉络：**本章第 7、9 两章都是这条线索的后代（**本课的中立判断（**一种范畴若能被持续使用而不被定义，它一定在做某件定义做不到的事：**它把判断的责任留在体验者身上，而不交给规则；**而规则一旦建立，趣味就失去发言权——**这是审美范畴的政治学，也是下一章要处理的分裂。**
:::

::: example 一句评语的三种读法 {#ex-pingyu}
取该书一条评语的抽象形式：“其源出于某家，文体省静，长于某类题材”（**本课不用原句，只用其结构**）：**甲：某人之诗源出于乙；乙：其体省静；丙：长于某类题材**。请指出这三项各属什么性质的判断，并说明若其中一项被推翻，其余两项还成立吗。

::: solution
**性质**（**甲是关系命题**（**发生学，可被书目、自述、同时代记载证伪，是本条中唯一有真值的一种；乙是风格描述**（**它是一个概括，可用语料分布来支持或削弱，但不可证伪到零；丙是题材归类的统计陈述**（**可查（**可推翻性**（**若甲被推翻（**例如证明此人未读过乙**），乙丙并不因此变假，但甲所承担的论证作用消失了：**风格描述失去了它的解释；**于是读者往往仍保留乙丙，只删去甲（**这就是谱系系统的日常运转：**分类被拆掉之后，描述活得很好（**本课由此给出读批评史的一条技术规则（**遇到一条“影响”论断，先把它换成“相似”看看你还剩什么：**若剩下的是“他们处理同一类处境的方式相同”，那么原本是一个解释，现在也是一个解释，只是它的证据要求低得多（**第 3 门课与论说文课的“另找因变量”在此完全可用（**判分：**能写出“换成相似后证据要求降低”者为 A**——**这是本课程影响研究的标准操作，也是把一副两千年前的谱系系统变成现代工具的唯一一步（**通说脉络：现代研究者在讨论影响与时同时，做的正是这件事。**
:::
:::

::: intuition 为什么榜单从不消失 {#int-bang}
**一个顽固的现象**（**每一代人都知道榜单愚蠢，每一代人都继续做榜（**四条理由（**①排名强迫表态**（**而表态产生可以争论的空间；**无排名的批评，其排名藏在篇幅与形容词里（**本课的公式：**凡不排名的评价体系，都在暗中排名，只是不公开权重；②它制造争议，争议是它的发行渠道**（**一部把某人放在中品的书，比一部夸所有书的书更容易被抄（③它是记忆的基础设施**（**一百余人的三栏表是一种可携带的知识；④它把批评者的位置固定下来**（**给出排名的人必须为此辩护；**辩护产生理论（**本课对第④条的解释是本节的要点：**理论不是从赞美里长出来的，是从被人追问“为什么他在中品”里长出来的（**这一句适用于论文答辩、适用于产品评审、也适用于你在群里转发一张排名（**而本章全部教训可以合成一句：**如果你想让一个判断产生知识，就把它排进一个可被反对的序列里；**这就是《诗品》为什么比它同时代许多精妙的散文更重要。**
:::

::: history 一部品第之书的升降 {#sec-shengjiang}
**齐梁之际**（**一书成，其目标只是给五言诗作者定等差；**通说脉络（②**隋唐**（**它被当作诗学与类书的材料引用，其品第并不总被接受；**唐代有人批评其品第未当一类说法见于载籍（**通说脉络：**本课指出：**被批评恰恰证明它设定的等差已被当作严肃对象（③**宋**（**印本流传，同时新的经典正在形成：**被它列入中品的那位诗人地位上升（**通说脉络（④**明**（**复古派与主性灵一派各引其语句为援：前者取其论源流，后者取其反补假（**通说脉络：**本课称此为“一部书被两个门户分尸”，是体系著作最常见的命运（⑤**十八至十九世纪**（**论者以“滋味”上接后世神韵之说，其谱系法被读成诗史方法（**通说脉络（⑥**二十世纪**（**它被写进“文学批评史”与“诗话研究”的教科书，并获“现存最早的论诗专著”一类的惯称；**通说脉络：**本课的最后一次提醒：**“最早”这一类称号是学科建设的产物：它们取决于哪类文献被认定为“论诗”，而被这样认定的标准本身是二十世纪的（**本章不否认其价值，只要求你在用这个词时，把它的颁发者一起写出来。**

::: exercise 小论文：排名生产理论 {level=3}
写六百至一千字，评“**凡不排名的评价体系都在暗中排名。学院拒绝给作品排座次，却用发表渠道、引用与推荐信的长短完成了排名；差别在于它不公开权重，因而不可反驳。钟嵘的贡献不是他的趣味，而是他肯把趣味写成名单：他愿意把自己的趣味写成一份可能被一百个后人反对的名单。今天任何声称不做价值判断的批评，其实只是把价值判断外包给了算法**。须调用：**三品加理由的格式**、**直寻的三层**、**谱系的两种失败**、**中品诗人案例**、**滋味范畴**、**被门户分尸的命运**至少六项；并裁决：**公开排名与拒绝排名，哪一种在道德上更可辩护（必须考虑被排在下位者的处境**。

::: solution
