title: "严羽与以禅喻诗"
---

上一章末尾说到，宋代诗话的海洋里出现了一部形式上不满于它的书——**它说诗的好处不可说、不涉理路，却写出了中国最像体系的一部诗论；本章要解释这个悖论，并解释它为什么去另一个宗教里借词**。

## 定义：这本书的形状 {#def-xingzhuang}

::: definition 五门与一句纲领 {#def-wumen}
**通说脉络**（**一部论诗著作分若干门，通常记为诗辨、诗体、诗法、诗评、考证，另附答友人书以自明宗旨；其成书在十三世纪上半（**纲领句是常被引用的那几句：禅重在妙悟，诗道也在妙悟；诗有别材，不关书本；诗有别趣，不关义理（**本课先讲形式（**五门的安排是：先立标准，再分类体式，再给学法门径，再作评骘，最后处理考证问题——**这是一份教科书目录，不是一串札记（**通说脉络：**于是第一个悖论出现：**一部主张“不涉理路”的书，选择了最能讲理路的形式（**本课的解答（**严羽的主张不是“不可说”，而是“不可证明”：**不可证明的东西不能靠论证交付，只能靠次序与对照去指；**五门就是那套指的手势（**这一读法把本书从“反智的神秘主义”救出来，也从“自洽的体系”里把它放走——**它是一份关于如何指认的诗学指南，而不是一套关于诗是什么的理论（**这一句是本章的定盘星。**
:::

::: definition 妙悟与熟参 {#def-miaowu}
**通说脉络**（**同一本书里并存两组说法：一则曰悟，一则曰须先熟参、须从最上乘着手、须具正法眼（**这两组话的关系是中国文论史上被误读最多的一处（**①妙悟是结论**（**它描述判别力出现的方式：突然能分；②熟参是方法**（**大量阅读并比较，直到你能不假思索地分辨高下（**通说脉络：**于是严羽真正可执行的那句话是后一句：**它的操作含义是——判别力来自比较样本的量与序，而不是来自规则表（**本课把它译成今天的语言：**你无法通过背诵评分标准学会评分；你要看足够多成对的作品，直到标准长在你身上（**这是全部学徒制与同行评审的认识论，也是第 3 门课那条“精选即删改”的高级版；③两个层次的混淆造成误读**（**把结论当方法，就会产生“不必读书”的诗人形象；而把方法当结论，就会产生“读得多就是好”的学者形象（**通说脉络：**这两种误读在历史上都真实发生过，而且都自称本于严羽（**这一条是你写任何思想史时都该带的一件工具：**一种说法被谁引用，往往不取决于它说了什么，而取决于它省略了什么。**
:::

::: definition 为什么是禅 {#def-weishenme}
**一个方法论问题**（**当时的作者也可以借经学、子学或玄学的词汇，为什么借的是禅宗的话语（**本课的答案是一句一般规律（**一个领域在借用术语时，借的永远是另一个领域当下最热闹的那个问题（**①禅宗内部正在争论权威从何而来**（**祖师、经典、顿悟、法脉、正统与旁出；②诗论此刻正在争论同一件事**（**汉魏、盛唐、本朝诸家；谁是正统，学谁算入门，学谁算走偏（**通说脉络：**两处的争论结构相同，故词汇可搬；③搬过来的不只是一个词，而是一整套判教语法**（**于是严羽的批评获得了三件此前没有的东西：**法统**（**有传承谱系；②入门阶次**（**有从浅入深的课程；③旁门判定**（**可以指人为“未悟”，而不必指出他哪一字错（**本课的重点在第③件：**它使判断变得不可反驳，而不可反驳性正是它吸引后世的原因，也是它该受批评的地方（**上一章我们要求外来范畴必须附“它原来用于反驳什么”；**本节的示范就是回答：严羽借禅，是为了反驳把作诗当成读书量的竞赛（**通说脉络：其批评对象包括以才学、以议论为诗的风气；**这一步是诚实的借用，因为它连同反驳对象一起搬了过来。**
:::

::: definition 第一义的代价 {#def-diyiyi}
**通说脉络**（**该书主张学诗须从最上乘、须悟第一义，并以盛唐为不可逾的标准（**本课给四条后果，两条是收益，两条是代价（**收益①它建立了一种历史意识**（**把历代诗排成一个可判断序列，这是中国批评里最接近文学史写法的一步；②它给出了可教的课程**（**先学什么、后学什么、什么不可碰（**代价③它把标准固定在过去的某一段**（**此后任何新作都只能在“近于盛唐”的刻度上被读；**一个以历史某段为绝对标准的系统，必然把同时代人判为退化或僭越——**这就是后世对它“诗必盛唐”一类的继承所产生的实际效果（**通说脉络：明代复古一派常被上溯到此书（④它把对手放逐出讨论**（**“未悟”不是一个可反驳的指控；**你可以说它没道理，但不能举出一个反例（**本课把第④条作为本章的批判顶点：**一种术语一旦能解释一切失败而不给出任何可核查的标准，它就从批评工具变成了身份徽章（**第 5 章那句“可反驳性是批评的发明”在此得到它的反例（**而代价③也提醒我们：一个标准被固定在某段历史，往往是因为它的支持者需要一部经典来支撑当下的派别斗争（**这是全部复古运动的公共秘密（**下一章讲小说戏曲批评时，会看到它的反面：被排斥者如何自己造一个法统。**
:::

::: definition 那四句比喻 {#def-biyu}
**通说脉络**（**书中有那组常被引用的话，大意是诗如空中之音、相中之色、水中之月、镜中之象，言语有尽而意蕴无穷（**本课做逐词的技术分析（**①四个比喻共有的是“可见而不可执”的结构**（**声音不可握、影像不可触、水中月捞不起、镜中象无实体；**它们不是四个不同的美感，而是同一命题的四次证明；②它们都在处理同一个语义学难题**（**一首诗的意义既不在字句之内**（**否则可穷尽**），也不在字句之外**（**否则无法确定；**这就是第 6 门课意义三角所处理的那类“中介”问题，而严羽用四个意象回避了它的表述（③它们是论证还是修辞**）？**本课的判断：**它们是论证的一种弱形式：把四个独立领域的相似并列，等于给一个不可证明的命题提供四次类比担保（**通说脉络：这类“四喻并列”是骈文传统里最常见的说服术之一；**而它的效力取决于读者对这四个领域的熟悉度（**今天读它的人多半只觉其美，不觉其论证——**这不是我们的损失，而是它作为论证本来就有保质期（**这一句请在小论文里替我反驳。**
:::

::: example 找出今天的判教语法 {#ex-panjiao}

::: solution
**一个可能的答案形状**（**法统**（**“真正的小说应上承某两位现代作家”一类的谱系叙述；②入门阶次**（**“先读这二十本，再谈当代”一类的课程式清单，常由书评或播客给出；③旁门判定**（**“那不是文学，那是类型小说/自媒体/网文”一类的排除句（**它们的“第一义”**（**多半不是任何具体品质，而是一种趣味立场的追认：**凡是让判断无法被核查的表述，都属于旁门判定技术（**被排除者的三种回应**（**①接受标准并申请入内**（**改写自己的作品；②另建一个法统**（**为被排斥的一类造一条自己的谱系，并追认两位经典——**这是最常见的成功策略，下一章会看到它在小说戏曲上的完整演出；③攻击标准本身**（**指出“不可核查的判断”是身份徽章（**本课指出：**这一种在理论上最强，在传播上最弱，因为它要求听众具备第 5 章的可反驳性判准；**而那是最稀有的一种听众（**判分（**能把第②种回应识别为“法统复制”而非“进步”者为 A**——**它说明一个被排斥的类别要获得地位，通常不靠推翻标准，而靠自建标准；**于是全部经典化史都是关于谁有权写目录的历史（**这一句从上一章的“选本出身”一路贯通到本章，也是本课程第 16 门课的旧题新解。**

::: intuition 妙悟在答辩场上 {#int-dayan}
**一个日常验证**（**你有没有听过一句评语：“这首有感觉”“这段不对”“气息不正”（**本课指出：**这些句子今天的用法与严羽的“妙悟”完全相同，它们不是评价而是终止讨论（**三条后果（**①它们对说者有利**（**不可核查的判断总是把成本转给被判断者；②它们有时是真的**（**说者可能确实见过足够多的成例而说不出标准——**这正是熟参的产物；③它们因此是一种诚实的困境**（**一个有判别力的人常常无法交付他的判据（**本课给的处理办法（**不要要求对方给出规则，而要要求他给对比：**你说这段不对，那么请你从同一位作者的另一段里举出一段对的，并说你听到差别在哪一句；**这一问几乎总能迫使对方交付可核查的东西，若他做不到，他就有理由收回这句判断（**这就是本章最重要的实操：**用成对样本逼出判据；**它同时也是严羽本人真正推荐的方法（**熟参**）——**也就是说，他真正的遗产不是“妙悟”这个词，而是一个可执行的练习；**本章的全部篇幅就是为了说这一句。**
:::

::: history 一部书的四派用途 {#sec-sipai}
**十三世纪**（**一部论诗著作写成；其时江西诗派的影响与修正仍在进行，各种“如何学”的说法并存（**通说脉络（②**十三至十四世纪**（**其说已见征引与批评；**元代诗论中“师古”与“性理”两派各取所需（**通说脉络（③**十六世纪**（**复古一派主张“诗必盛唐”，其判教语法与此书同型；**论者常把此书列为先声（**通说脉络：**本课的态度：**先声的叙事总是后写的；**它把一部书抬为门户的创立者，同时抹去它与其他宋代资源的关系（④**十七世纪**（**主神韵一说者与之接绪；同时考据一路的学者著文纠其谬，指其禅语用典不切（**通说脉络：**这一场批评是本领域罕见的一次“术语审计”：**审的不是诗学主张，而是借词用得对不对；**本课认为它的方法比结论更值得学（⑤**十八世纪**（**一部大型丛书的提要给它一个类目与考语（**通说脉络：**目录的位置决定了后来二百年的读法（⑥**二十世纪**（**它被读成“审美自律”“形象思维”“纯诗”的先驱；**通说脉络（**本课的收尾判断（**这一连串用途说明一件事：**一部书的“影响”，多数时候是后来者从它身上取用与自己议题相应的那几句；**而严羽的书恰好同时提供了神秘主义、教科书、门户经典与反考据四种原料（**上一章那句“重新归类九百年”在本章升级为“被四派各自引用而不以为怪”；**这不是严羽的成功，这是措辞空格的数量（**第 1 章的公式，至此已用了七次，你应该已经会自己套了。**

::: exercise 小论文：不可核查的判断 {level=3}
