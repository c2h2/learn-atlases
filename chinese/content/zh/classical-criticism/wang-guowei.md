前九章讲了批评如何取得职务、如何取得方法、如何为被排斥者立法；最后一章回到 1908 年——**一个人用宋人笔记的条目体，写下了一部语法属于另一个传统的书；本章要说明这为什么既是中国古典文论的终结，也是它的最后一次成功**。

## 定义：一部什么书 {#def-shenmeshu}

::: definition 版本与体例 {#def-banben}
**通说脉络**（**一部论词的著作在二十世纪初先后发表于一种刊物，条目数十则，作者身后另有删订之本；其未删之本包含较多带有哲学色彩的条目（**本课先做三件版本工作（**①它不是一本成书**（**作者是陆续写出、陆续删改的；**我们今天引的句子，可能出自已被作者本人删去的那一部分；②它是条目体**（**上一章说过这种文体的四种成因，此处又添一种：作者要写的东西彼此不成系统，而他又想立刻发表；③它发表在新的传播装置上**（**刊物、按期、面向不相识的读者（**通说脉络：**本课指出一个常被忽略的事实：**批评第一次以“连载”的形式出现——**而连载的批评不必自洽，因为它不必被装订（**这就是本章的开场悖论：**这部作品在它自己的形式上是传统的，在它的出版方式上是现代的，而在它的问题意识上是外来的（**三件事必须同时看见；**只看见任何一件，都会得出一种错误的文学史（**这一句也是本课程对全部“近代转折”叙事的总评。**
:::

::: definition 境界 {#def-jingjie}

## 定义：隔与不隔 {#def-ge}

::: definition 一个可执行的判准 {#def-buge}
**通说脉络**（**书中以“隔”与“不隔”论作品的高下，大意是语语如在目前则不隔，替代与粉饰使读者需经中介则隔（**本课把这当成全书最有用的一个工具，先给它一次优点审查，再给它一次失效审查（**优点①它是可操作的**（**它把问题定位到具体的一处：这一句要不要读者先去猜；②它是可反驳的**（**你指出某处“隔”，我可以在同一处证明它不隔——**只要我们能说清读者读到第几字需要什么前置；③它是反权威的**（**它不问出处，所以它不奖励阅读量（**这是本章所谓民主化的含义（**失效①它没有分级**（**隔几分？隔多少算失？**——**上一章那个“缺权重”的老毛病又出现了；②它依赖一个未被追问的假设**（**“读者应当立刻感到”——而这一假设本身是一种趣味；**用典一派的辩护恰恰是：适当的中介延长回味（**通说脉络：此即明清两代用典与反用典之争的延续；③它无制度**（**“隔”的判定没有第二人复核，也没有申诉处；**于是它从判准退化为口令（**本课的处方（**判准脱离制度之后就再也无法被追责任——**这就是本章的理论高点，也是全课程十九次“可审计性”论述的最后一次。
:::

::: definition 三则引词 {#def-sanze}
**通说脉络**（**书末有几则常被引用的话，以三句宋词依次比附古今成大事业大学问者必经的三种境界：独上高楼、衣带渐宽、灯火阑珊（**本课把这三则当作整门课程的结尾来教，因为它们是一次引用行为（**①三句原为情词**（**作者的挪取与原作语义无关；②挪取的方式是断章**（**这正是本课程第 1 章所说“诗言志”最初描述的那种用法：在宴会上取一句诗完成自己的一句话；③它成功了两千年来最难的一件事**（**使被引用的三句在大众语感里获得了一个新用途，而原用途并未消失（**本课的课程总结句（**中国文论从“引用”开始，到“引用”结束：中间两千年都在替这一行为寻找根据（**通说脉络：**这三则写于作者由文学转向古史之前；他此后数十年以另一种方法工作（**通说脉络（**这一句不是八卦：**它说明这部书是一次未完成的规划；**而所有未完成的规划都比完成的作品更容易被后人写成自己需要的样子（**第 1 章“纲领被改写四次而不死”，最后一例是它自己。
:::

::: example 用隔与不隔评自己 {#ex-ziwo}

::: solution

::: intuition 为什么这个词活下来了 {#int-huoxia}
**一个统计事实**（**今天的美学、教材与评论里，“境界”“隔”仍在被使用；“神韵”“肌理”“格调”多半只在教科书里出现（**三条解释（**①它被译名化了**（**它被当作一个外来概念的对应词来教，因而可以在没有师承的课堂里传授；**旧范畴要靠共同阅读经典才能激活，译名只靠定义（②它的对立项清楚**（**境界／无境界、隔／不隔，是可以用一句话教完的二值判断；**而“神韵”没有反命题（**这一条来自上一章：不可检验的词不能进入考试（③它有制度载体**（**它进入了教材与试题；**一个范畴的寿命等于最后一个能熟练使用它的教师的退休时间再加上一轮教材修订（**本课用最后一句开玩笑，也当真理：**凡你正在被要求掌握的美学名词，都应当先问一句：哪个考试考它。**
:::
