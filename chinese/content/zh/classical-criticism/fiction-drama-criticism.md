前面七章处理的都是被承认的类别；本章的批评对象在传统目录里没有位置——**于是这些批评家做了一件理论史上很少被这样描述的事：他们不只是为小说辩护，他们动手把小说改成配得上辩护的样子**。

## 定义：三件事 {#def-sanjian}

::: definition 造法统 {#def-fatong}
**通说脉络**（**明末一位以异端著称的思想家提出以“童心”论文学价值，并有评点《水浒》《西厢》的本子传世——**而这些本子的真伪至今有争论；同时另有一位批评家把若干部作品并列为“才子书”（**本课把这两件事都读成法统建设（**①“童心”是一种资格论证**（**它不问体裁高低，只问表达是否未被道理闻见遮蔽；**于是一部小说可以凭这一点与诗文平坐（**通说脉络：**这是本章第一次出现“用一个普遍性质替换一个等级标准”的策略（②“才子书”是一份目录**（**被并列即被抬高；**而它把经、史、诗、文与小说戏剧排进同一清单，这个动作本身就是文类史的革命（**本课对第②条的精确判断（**名单的力量来自它不完成；**通说脉络：所谓六才子书之说并未全部评骘（**一份完成的清单是可核查的，一份未完成的清单则是许诺；许诺能动员跟随者，而核查只会招来反对（**上一章末尾那条“被排斥者自建法统”在此有了完整的案例（**而下一章会看到它怎样被学界接收。
:::

::: definition 造方法 {#def-fangfa}
**通说脉络**（**十七世纪的一位批评家为他评订的小说与戏曲各写了一系列“读法”与序文，逐回有批语、句下有夹批，并讨论结构、伏笔、视角与人物笔法（**本课把这套装置称作中国最接近细读的方法，并指出它的三个部件（**①读法**（**一份阅读指令清单，先规定你应当注意什么；②回前批与夹批**（**把评论分散在正文之间，使阅读成为对话；③结构术语**（**“草蛇灰线”一类说法被用来指称伏笔与照应（**通说脉络：**这三件恰好对应今天的教科书、脚注与叙事学术语，而其出现早了三百年（**本课最看重的是它的发生位置：**方法的创新发生在等级底层，因为上层的方法已经固化为考试的格式；**诗文的读法在科举里有定本，而小说没有既定读法，于是可以发明读法（**这一句是一个一般规律：**任何一个新领域的方法论繁荣，都先于它的经典化；等到经典定了，方法论就开始写注释（**你在本课程第 14 章与第 21 章会一再看到这条。**
:::

::: definition 造文本 {#def-wenben}
**通说脉络**（**这一批批评家常常不止评论，还动手改：一位批评家以七十回本行世，删去招安以后的部分并修改文字；一对父子修订评点的《三国演义》成为此后最通行的本子；一位评点者称《金瓶梅》为“第一奇书”并作长篇批语（**本课称此为**以编辑进行批评**，并给它四条理由与一条后果（**①改动即主张**（**删掉一段就是主张这一段不该存在；**它的强度高于任何一句评语，因为它不可撤回；②改本成为通行本**（**于是后世读到的“原作”其实是批评家的本子；**而绝大多数读者不知道（**这就是本章最尖锐的一句：**在中国，谁控制本文，谁就控制解释；**与上一章“谁有权写目录”相接（③它使作者变成可争议的对象**（**批语常声称知道作者的用意与手法，而作者不在场且文本已被改（**通说脉络：署名为某评点者的本子真伪问题至今是专门课题；④它带来一个新问题**（**校勘与批评从此无法分开；**这是本章交给第 10 章学术写作的第一个具体难题（**本课的态度（**我们不必谴责他们改；**我们要做的是把每一次改动写进附录——**这一句是本课程所谓版本意识的全部内容（**第 20 章与此对接。**
:::

## 定义：戏曲的例外 {#def-xiqu}

::: definition 一位编剧写的理论 {#def-bianju}
**通说脉络**（**十七世纪一位身兼编剧、排演与卖文为生的作者，写下一部论戏曲的著作，把结构列为第一，主张一本戏须有主脑、头绪宜减、并讨论宾白、科诨与收束（**本课认为这是中国批评里最被低估的一部书，理由三条（**①它的读者是干活的人**（**不是考生；**因此它的每条建议都可执行——**这是本课程一以贯之的评分标准，本章把它提前三百年（②它承认自己在卖**（**写作与排演是为生计；**这部书因此第一次把文学当产业来写（**上一章的“出版那一种成因”在此成了作者自己的话题（③它的判断标准是观众的注意力**（**它问的是“此刻台上无人看”，而不是“此句是否近于盛唐”（**本课把第③条称为本章的理论要点：**一部以“是否有人继续看”为标准的批评，天然地比以“是否合乎典范”为标准的批评更接近经验科学——**它的判准可以在下次演出中被验证（**第 19 课与第 9 章的“可执行性判准”，在一部戏本理论里得到它在中国文论中的最好例子。**
:::

::: definition 一部小说与一群批者 {#def-pizhe}
**通说脉络**（**十八世纪一部未完成的小说以抄本流传，若干抄本上有署名批语，其中一位批者与作者家族的关系、批语的层累与年代，至今是专门争论的题目；这些批语透露了作者修改的痕迹与后半部的一些线索；九十年代以后的一部刊本则以活字排印行世（**本课把这一案例作为全章的收束，因为它同时具备四种不确定性（**①作者不确定**（**且文本未完成的“结尾”另有他人续成；②批者不确定**（**署名可能是别号，可能不止一人，批语可能是多次誊抄的层累；③本文不确定**（**抄本互异，无作者手定本；④解释共同体不确定**（**同一批语被读成创作谈、被读成家族史、也被读成政治寓言（**本课的方法句（**面对这种材料，任何一句“作者其实想……”都必须同时说明：**你在用哪个本子、哪一层批语、以及该批语的断代依据；**做不到就说明你的句子不属于考证而属于诠释，而诠释也要说明它的规则（**这一条将在本课程最后三章变成一次次的评分标准（**而本章最愿意让你带走的是那个反直觉的安慰：**这些不确定性不是我们知道的障碍，而是我们知道的内容——**一部十九世纪前几乎无人整理、由抄手与书坊保存下来的小说，其文本状态本身就是它的社会史。**
:::

::: example 评点与细读 {#ex-xidu}
下面两段都评同一类材料（**本课自造的抽象形式**）：**甲：“读至此，不觉失声。作者此笔，伏在三回之前，读者忘之，而作者不敢忘也。”乙：“此处与前文某句呼应，构成叙事上的期待，其效果依赖读者对这一类套式的熟悉。”**请写出三条方法上的相同与一条根本不同。

::: solution
**三条相同**（**①都把效果归因于结构而非辞藻；②都预设一个理想读者**（**甲的“读者忘之，作者不敢忘”，乙的“读者对套式的熟悉”；**两者都是关于阅读时间的主张；③都以局部证明整体**（**举一处伏笔来主张这部作品是有设计的（**一条不同**（**甲同时是诠释与赞美，它不要求可复核，因为它默认作者在场并可被揣测；**它的句式是“作者不敢忘”，这是一个关于作者心理的断言；乙则把因果安在读者一侧的可查机制上**（**套式的存在可以在别的作品里统计；**于是它不依赖作者意图（**本课的判决（**这不是古今之别，而是证据责任的分配之别：**甲把责任交给天才，乙把责任交给惯例；**而惯例可查，天才不可查（**通说脉络：**有意思的是，甲的写法更接近现代读者的阅读经验，乙的写法更接近现代论文的要求；**这也是本章给全体学生的提醒：**你若要在论文里写“作者伏笔深远”，你必须有作者论伏笔的材料，否则请改写成读者一侧的机制（**判分：**能写出这条改写规则者为 A**——**它是论说文课那条“可执行性判准”与第 3 门课“换科目引用”在本章的合成应用，也是接下来三章反复的评分依据。**
:::
:::

::: intuition 名单为什么不完成 {#int-mingdan}
**一个现象**（**从“才子书”到今天的各种“必读”“十大”，名单很少被完成，也很少被修订（**四条解释（**①未完成的名单是开放的**（**每个后来者都觉得自己可以补上一名；**这使名单成为公共事业而不是私人判断；②完成会引入责任**（**一旦你的清单完整，每一个缺席者都成了你的疏忽（**这是本章的社交洞察；③修订需要新的判别力**（**而判别力会随趣味贬值；**名单的维持成本远高于其创立成本（④名单的真正功能是招生**（**它使持名单者成为可被寻找的人（**本课由此给一条读史纪律（**任何时候看到一份经典书单，先问它是为了教学、为了收藏、为了排他，还是为了招生；**这四种成因会造出四种极不相同的名单，而它们看起来一样（**通说脉络：**本章末尾的这条尤其适用于你此刻所在的学科：你的专业的“必读十本”多半是若干代人招生与自我正当化的沉积，而不是一次会议的结果——**它是一次又一次会议，只是没有人记录（**这就是下一章为什么从档案讲起。**
:::

::: history 从被禁到被研究 {#sec-jin}
**十五至十六世纪**（**刊本小说与戏曲演出扩大；论者偶有评语，多附于序跋（**通说脉络（②**十六世纪后期至十七世纪**（**评点本大量出现，与书坊的经营相互依赖；**一部小说同时有数种评本竞争（**通说脉络：**本课强调这一条：**批评成为出版业的组成部分，评点者的名声是销量的一部分（③**十七世纪中叶**（**改订本成为通行本；戏曲批评出现体系化的编剧论（**通说脉络（④**十七世纪末至十八世纪**（**小说评点继续；同时朝廷屡有查禁与销毁的举措（**通说脉络：**本课把禁书与评点并置读：**禁令是一份反向的书目，它替批评家完成了营销（**这一条在本课程第 2 章“禁与传”里说过一次，本章是它的实证（⑤**十八世纪后期至十九世纪**（**抄本与批语流传，排印本行世；批评的重心从“文章作法”移向情节与人物（**通说脉络（⑥**二十世纪初**（**一部戏曲史著作以现代学术方法整理材料；另有一篇以外来哲学读该小说的论文出现，随后考证一路兴起，作者与版本的问题成为中心（**通说脉络：**本课的最后一笔（**被排斥的类别在获得地位的同时，也换掉了评价它的学科：**从“读法之争”变成“考证之争”，而考证一旦成为正统，趣味又失去了发言权（**这与上一章结尾的“四派用途”首尾相接，也构成了下一章的问题——**批评史到此结束，方法论从此开始。**
