上一章的批评家在争类别的生存权；本章的批评家已经默认诗的位置，转而争论另一件事——**该向哪个时代取法，以及一首诗的好处究竟住在格律、才情、学问还是韵味里。本章的论点是：这不是一场门户混战，而是一个自我修正系统运行了四百年的记录**。

## 定义：一轮循环 {#def-xunhuan}

::: definition 四派与各自的诊断 {#def-sipai}
**通说脉络**（**明代前后七子一系以“诗必盛唐”一类口号取法盛唐；公安三袁起而以“独抒性灵，不拘格套”一类主张反模拟；竟陵一派追求幽深孤峭之趣；清代则有格调、神韵、性灵、肌理数说相寻（**本课把它们排成一个诊断链（**①七子诊断当下之弊为气象衰歇**（**故取法高格；②公安诊断七子之弊为无人只在拟古**（**故取诸心；③竟陵诊断公安之弊为俚俗易尽**（**故求深峭；④清人诊断明人之弊为空疏无根**（**故有以学问济诗的肌理一派，亦有以韵味救滑易的神韵说（**这是一个标准的正题—反题结构，只是它不是黑格尔式的上升：**四百年后问题一个也没解决（**本课的第一条分析（**每一派的主张都正确，因为它正是对上一派实际弊病的准确描述；**而它的方案一旦施行，就会生产新的弊病（**这就是为什么本章读起来令人不安：**你无法通过选择正确的阵营来避免错误——**只能选择你愿意犯哪一种错误（**这一句是本课对任何一次“方法论之争”的通用评论。
:::

::: definition 四个方向词 {#def-fangxiang}
**通说脉络**（**格调、神韵、性灵、肌理这四个词此后成为清代诗学的基本词汇（**本课给它们做一次语义学检验（**①它们都可被实例化**（**每一派都能举出十首“有神韵”“有肌理”的诗；②它们都不可被检验**（**没有一种做法被任何一派明确禁止；**关键在于：四派共享同一批语料，而共享语料时，范例不能证明规则；③它们的语义是负方向的**（**“神韵”真正的用法是说“不是这一种”，即排除掉露、尽、实、博；**于是它是一台方向的指示器而不是一台判定的机器（**本课的判语（**这四个词是这门学科在无法验证时的正常产物：它们把判定标准转化为品位信号，使同门之间可以互相识别；**这一读法并不取消它们的价值——**上一章末尾那条“名单的功能是招生”在此升级为“范畴的功能是识别同门”；而识别同门的代价是把论证外包给趣味（**第 16 门课文学理论会再处理这件事，本章只要求你做一件事：**每次遇到一个不可检验的褒义词，先把它翻译成一个禁令；**译不出，则该词在你手里只是出身证明。
:::

## 定义：一次体系化的努力 {#def-tixi}

::: definition 叶燮的表 {#def-yexie}
**通说脉络**（**十七世纪一部论诗的著作提出两组要素：就对象说，理、事、情；就作者说，才、胆、识、力；并以“识”为四者之本（**本课把这张表当作明清唯一一次真正的体系化尝试来读（**①它把不可分解的“才能”拆成四项**（**而“识”是判断力，可以来自读书与阅历；**这一步使“才”第一次成为可教育的东西；②它同时给出对象一侧的三项**（**于是作品是两组变量的函数，而不是灵感的赠物；③它的弱点是这张表没有权重也没有交互项**（**“识高而胆弱”会写出什么？“才高而识浅”呢？**——**表给出的是词汇，不是预测（**本课的判断（**这正是本章与上一章的分工：**《文心雕龙》是行业全书，叶燮是一张评分表的草图；**两人都缺同一样东西：**权重与交互；**而权重恰恰是任何一门经验学科最难交出的东西，因为它要求你把趣味写成成本函数（**这一句将在本课程最后三章的“可审计性”里收到回报。**
:::

::: definition 范畴与权力 {#def-quanli}
**通说脉络**（**十八世纪一位倡导格调说的批评家历位清要，其选本与论诗之说盛行政坛与科场；身后因文字案件牵连而被追夺赠谥一类处分（**本课只取三条制度含义（**①范畴与政治荣誉绑定之后，反对它就有政治风险**（**于是它的流行不再需要论证；②它的拥护者随之变成投机者**（**因为掌握该范畴即掌握了一条仕途上的口音；③它身后的失势同样不是学术事件**（**同一批诗在两朝被读成“高格”与“气象已尽”，差别往往在评审人的出身（**通说脉络：**本课由此提出本章最难的一句话（**一种批评范畴一旦被权力收编，它就会在下一次权力改组中被当作旧势力清算；而它的替罪羊是诗（**这一条在第 19 课、第 21 章与本课程第 8 章都出现过；**本章只是给它加上一个十八世纪的日期（**你若将来主持任何评审，请记住这三条：**标准公开、权重写死、并且允许申诉——**这是使范畴不沦为出身证明的全部可行技术。**
:::

::: definition 两百年后的两句反证 {#def-fanzheng}
**通说脉络**（**十八世纪末一位诗人论史有“江山代有才人出，各领风骚数百年”一类名句；同时另有一派主张诗须根柢于学问，宋诗一路在道咸以后大盛（**本课把这两件事放在一起，因为它们构成了本章的结尾问题（**①“各领风骚数百年”是一种历史乐观**（**它承认每个时代都有自己的诗，于是不必有盛唐这个标准；②宋诗派的实践是它的兑现**（**用学问、用笔力、用散文化的句法写诗，写出的东西不能再用“神韵”来判；**也就是说，一个范畴的失效常常不是因为被驳倒，而是因为出现了它无法描述的新作品（**这是本章最重要的理论结论（**范畴的寿命取决于它能否覆盖新写作；**这与上一章“标准固定于过去某段则同时代必被判为退化”首尾一贯（**而它的实用含义是（**评估任何一种评价框架，别问它对不对，问它最近五年里有多少新作品它能描述（**你把这个指标用到文学、建筑、软件与学术评价上，都会得到有趣的结果。
:::

::: example 同一首二十字 {#ex-ershi}
取传世五言绝句“空山不见人，但闻人语响。返景入深林，复照青苔上”。请分别以格调、神韵、性灵、肌理四说各写一句评语，然后回答：**这四句评语能互相反驳吗**）？

::: solution
**四句评语**（**格调：**格清而响远，然气格近于短峭，非其最上；②神韵：**不着一字而意在言外，声色俱化；③性灵：**眼前语，真趣自在，不必以学问相高；④肌理：**“返景”“复照”二语有物理可据，惜全篇少书卷支撑（**通说脉络：此四句为本课依各家理论立场拟作的评语，不是引文；四家论诗之要旨则各有本集可据（**能互相反驳吗**）？**不能，理由有三（**其一，四句都只调用该诗已有的特征，没有一项特征是某一派独占的；其二，四句都没有禁止任何改写**（**没有说“若删去某句则不成立”，因此它们的判据都可容忍该诗原样存在；其三，它们的评价对象实为不同的问题——**气象、韵味、真诚、知识含量（**本课的结论（**这是一次共享语料、不共享判准的完美示范；**而它告诉我们：**在判准不可通约的争论里，胜负从来不由文本决定；**于是研究这些争论的正确方法不是判它们谁对，而是记录各方在什么制度位置上、向谁说话（**这一句把本章变成一门社会学，也是本章留给下一章的接口——**因为王国维用的正是另一套来自他处的判准（**判分（**能写出“它们评价的是不同问题而非同一问题的不同答案”者为 A**（**这是本课程给全部“学派比较”的模板；**它比“各有道理”要硬得多：它把一场争论改写成一份问题清单（**论说文课“另找因变量”的那一招，在此第三次出现。
:::
:::

::: intuition 旧币仍在流通 {#int-jiubi}
**一个语言事实**（**今天写旧体诗的人、编年选的人与评诗的老师，仍在使用格调、神韵、性灵这些词（**三条观察（**①它们已不承担论证**（**没有人因为“无神韵”而拒绝一首诗进入选本；**它们被用来给已经做出的选择配一句体面的话；②它们是出身证明**（**会用这些词的人彼此识别；**而用错的人会被立刻听出——**这一功能在两百年里没有变化；③它们偶尔还有效**（**当你需要在三首同样可辩护的诗里选一首时，“有神韵”会替你压缩一次判断；**旧币在零钱上仍好用，只是不能用于大宗交易（**本课的教学建议（**你应当学会这些词，理由与学任何一门外语的同源：你的研究对象用它们说话；**但你在自己的论文里应当把它们翻译成可核查的说法，除非你的读者与你共享同一套判准——**而在跨学科学术写作里，你几乎从不与人共享判准（**这一句是下一章“学术语言”的预告。
:::

::: history 四百年的口径变更 {#sec-koujing}
**十五世纪末至十六世纪**（**以盛唐为法的口号提出并风行，复古成为文坛的公共语言（**通说脉络（②**十六世纪末至十七世纪初**（**性灵之说起于三袁；竟陵别为幽深（**通说脉络：**本课只补一条物质原因：**刻本与选本的繁荣使“当代主张”可以在几年内传遍各省（**第 4 章“印刷是隐形赞助人”在此重演（③**十七世纪后半**（**遗民诗人以“情景”“现量”一类说法重议诗的本性；另一部论著给出理事情与才胆识力的表（**通说脉络（④**十七世纪末至十八世纪前期**（**神韵说成为士大夫社交中的雅正之词（**通说脉络（⑤**十八世纪**（**格调、性灵、肌理数说并峙，诗话一体复兴；同时选本成为门户的实体（**通说脉络：**本课强调：**一派之争往往先体现为选本之争：**谁被选入即被承认（**这是上一章“控制本文即控制解释”的诗版（⑥**十九世纪至二十世纪**（**宋诗一路与“同光体”余响；新文学兴起后，上述范畴被写进文学批评史教科书（**通说脉络（**本章结语：**四百年里被更换的是口径，被继承的是“必须有一个正统”这一前提；**而这个前提才是本章真正要交给你审问的东西——**下一章会用一部用外来范畴写成的小书，把这个前提第一次动摇。**

::: exercise 小论文：正统的前提 {level=3}
