上一章那部书把诗人排进三栏；本章的材料是一千年来不断有人往抽屉里添的笔记——**几百本随手写的诗话，构成了中国批评真正的日常文体；本章要论证：它的随意不是缺陷，而是一种认识论，它的散漫也带来一种它自己不曾预期的证据制度**。

## 定义：一种文体 {#def-wenti}

::: definition 条目体与它的四个部件 {#def-sibujian}
**通说脉络**（**“诗话”之名起于宋代一部以“闲谈”自居的著作，此后仿作者众，宋人所作存世已有数十种（**一条典型的诗话常含四个部件（**①本事**（**谁在什么场合写了这一句；②句**（**被摘出的那一联或一句；③评**（**一句判断，常以比喻或类比交付；④附**（**考订字义、爵里、版本异同一类（**本课对第④条特别看重：**它是中文批评里最早的引证习惯：**判断之外，还要给出可查的东西（**而它的可靠度需要独立评估：**本事多半是传闻（**通说脉络：论者常提醒诗话之记事不可尽信，须与史传文集对校；**本章的处理（**部件②③是批评，部件①④是证据；**把它们混作一谈，是读诗话的第一种失败（**这一句就是本章全部的史料学；**你以后读任何一份“据说”式材料都用得上。**
:::

::: definition 为什么不写成体系 {#def-tixi}
**一个明显的问题**（**宋代已有体系性写作的能力，为什么论诗却多用条目（**本课给四种答案，并说明它们并不互相排斥（**①认识论的**（**若诗的好处主要在“可意喻而不可言传”的部分，则体系化是一种背叛（**这一条与上一章的“滋味”与下一章的“以禅喻诗”连成一线；②社交的**（**诗话的预设读者是能接话的人；**条目体是一次对话的记录而不是对读者的讲授（**通说脉络：**本课把它称作“未装订状态”：**一部书在被装订之前，是可以随时被人插话的；③实用的**（**士人需要的是可在宴会上引用的条目，不是论证；④出版的**（**笔记可分卷独立成书，各自流通；**一种文体能存活千年，通常是因为它符合生产的组织方式（**本课的结论（**四个答案各解释一部分；**而第④条常被忽视，恰因它最不舒服：**它说明一种文体的盛行可以用发行来解释，不必用精神来解释（**第 14 章“计费器作为甲方”在此早了八百年发生一次。**
:::

::: definition 点铁成金与夺胎换骨 {#def-diantie}
**通说脉络**（**一位诗人及其后学留下两组语汇：一说作诗如以灵丹点铁成金，一说“夺胎”“换意”各有其法；这些说法经由一部笔记流传，其确切含义至今讨论不一（**本课把这一组材料当作中国文论最重要的一次“改写理论”来讲（**①它解决的问题**（**在一个人人熟读前人的社会里，任何新鲜句子都必然与前人相似；**于是问题不是“如何创新”，而是“如何合法地继承”；②它给的答案**（**继承的合法性不来自你读过，而来自你改得好：换其意而增其善，或易其辞而存其意（**本课称此为一份复用授权协议：**它规定了什么条件下前人的句子可以出现在你的作品里，并且不算抄袭；③它的对手**（**上一章的“直寻”：好句不由补假而来（**于是中国诗论出现了两千年最有用的一场争论：写作是遭遇还是改写**）？（**本课的裁决（**这是一道伪问题，因为两边各自描述的是写作的不同阶段：**素材来自遭遇，成品来自改写；**而真正的分歧是评价的重心放在哪一端（**这一句请在小论文里反驳我，本课不接受双方都对的和稀泥答案。**
:::

::: definition 活法 {#def-huofa}
**通说脉络**（**宋人论诗有“活法”一说，大意是学者须先受规矩，而后能出于规矩之外；又有“死句”“活句”之辨，从禅语借来（**本课把这一条读成一种教学法（**①它把规则分成两级**（**可教的与不可教的；②它承认教学有反作用**（**规矩教得太牢会变成约束，故须有“活”这一步；③它是事后追认的**（**“活”总是由已经成功的人被追认为“活法”，由失败者则被称作“无法”（**本课指出这一条是本章最锋利的一句：**任何一门手艺在解释自己为什么教不出人时，都会发明一个“活”字；**这句话适用于写作教学、投资、医学与棋（**你以后在任何一份培训材料里看到“灵活运用”，就把它翻译为“此处我们不负责”，然后再决定是否付钱。**
:::

::: definition 唐人的三个命题 {#def-tangren}
**回到唐代，作为对照（**①一位诗人写给朋友的长信里主张文章合为时而作、歌诗合为事而作（**通说脉络：**这是本章所谓职务论的极端形式，也是它最诚实的表述：**它承认自己的目的是讽喻，并愿意为此接受文辞的降格；②另一位作序的人说，欢愉之辞难工，而穷苦之言易好（**通说脉络：**本课在第 19 课已给过它的社会学读法，此处补一句：**它把一个关于处境的说法写成了关于品质的说法，因而可被后世误用作对困苦的赞美（③还有人提出“韵外之致”一类的追求，把好处安置在文字之外（**通说脉络；另有一部以品类分论诗境的著作旧题其撰，作者问题至今未了（**上一章的教训在此完全适用：**我们引用这些命题时，要一起引用它们的场合——①②是书信与序跋，是私人的解释；③是答人之问，是一种示范；**它们都不是论文，所以它们都不曾试图自洽（**这就是唐诗论与宋诗话的根本区别：**唐人的洞见多为偶发，宋人的洞见多为方法；偶发者深，方法者可传。**
:::

::: example 拆一条诗话 {#ex-chaotiao}

::: solution

::: intuition 诗话是抄本时代的朋友圈 {#int-pengyouquan}
**一个类比，两条限制**（**相似处**（**短、快、以摘句为核心、靠转发流通、作者与读者互换、常有内行笑话；**它的知识密度低而社交密度高（**不相似处（**其一，诗话有年功与累积：**一个人一辈子记一条，一百人各记一条，就成了一部资料；**而一条社交贴的寿命以小时计（**本课认为这是关键差异：**诗话有沉淀，因为它有抄与刻的成本，而成本会筛掉一部分内容——**筛选留下了什么，今天看并不总是好的那一半；其二，诗话不要求即时回应，**于是它可以慢慢错，也可以慢慢被改对：一条记误的作品，会被后出的诗话纠正（**这一条与上一章“没有版本就没有历史”相对：**诗话有一种缓慢的自我更正，因为它是一千年间的连续写作（**本课由此得出本章最后一条方法（**判断一种文体的知识价值，不要看它的单条质量，要看它的累积与更正机制；**这句话适用于今天的任何一场争论、任何一份维基百科式的资料，也适用于你正在写的那份文献综述。**
