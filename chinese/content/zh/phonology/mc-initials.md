韵书给了几千条反切，等韵图给了三十几个“字母”——把它们对齐，就是中古声母这门学问的全部现场。本课先背一张表格化的“声母名单”，再学会它的真正身份：**三十六字母不是《切韵》的声母表，而是一份晚了几百年、被诚实的拼写系统出卖了的旧音档案**。

## 三十六字母 {#sec-zishiliu}

::: definition 五音六音与清浊 {#def-wuyin}
三十六字母按发音部位（唐人称“唇舌牙齿喉”五音，宋代加“半舌半齿”成七音）与发音方法（塞音塞擦音分全清、次清、全浊，鼻音边音为次浊，擦音多归清）排成矩阵：**帮滂並明｜非敷奉微**（唇音重轻两套）、**端透定泥｜知彻澄娘**（舌音舌头舌上两套）、**精清从心邪｜照穿床审禅**（齿音齿头正齿两套）、**见溪群疑**（牙音）、**影晓匣喻**（喉音）、**来日**（半舌半齿）。每字是一个声类的代表符号：**帮读“北”不读“帮”的字音，它是记号**。全清全浊之别是汉语声调史的最大变量（平分阴阳、入派三声都拿它当自变量，见[[phonology/to-mandarin]]）。矩阵口诀：“**五音清浊各三位，鼻边归次浊；帮滂並明对非敷奉微，端透定泥对知彻澄娘。**”
:::

::: history 守温三十字母 → 三十六字母 {#sec-shouwen}
敦煌遗书中有《唐写守温入关五篇》残卷，列三十字母：唇牙喉齿各按部位成组，尚无“非敷奉微”独立成行（“不芳並明”四字母担着后来分两排的业务），也无“床禅日”等之齐备。宋人《韵镜》行世的三十六字母在其上增补成阵——增补的时代正是轻唇音、舌上音独立成音位的时代完成时。**从三十到三十六之间躺着的，就是晚唐五代的音变现场**。字母之学与韵书之学自此分进合流：韵书记“字归何切”，字母图“音有几位”。
:::

## 字母不是切韵的声母表 {#sec-bushi}

::: theorem 三十六与四十一二之间 {#rule-siying}
以反切系联检验（见下节），《切韵》声类多于三十六字母：清代陈兰《切韵考》系联得**四十类**，近代学者继续补正，主流结论为**四十一类**（分歧集中在日母与“俟、禅”诸类的分合——要点在差异模式而非尾数）：帮与非、滂与敷、並与奉、明与微**各各互补**——帮组只切一四等字，非组只切三等合口字，两堆切语上字**永不同韵等见面**，故《切韵》实为一类，后人分立两字母以配两时代两音值；端与知、彻与澄同理（三等系联后拆出“娘”与“日”的纠缠更著）。结论：**三十六字母是《切韵》音类在唐末宋初的“投影近亲”，不是它的原件**——用字母读切韵，等于用京剧韵白读《诗经》：差不至于差，但必须心里有代沟。
:::

::: example 系联小案：帮类家族 {#ex-xilian}
材料三道切语：①杯，布回切；②悲，府文切；③北，博德切。问：上字“布、博”与“府”是否同类？凭什么判定？若判同类，三组今音（b/f）的差异又作何解释？
::: solution
布、博同为帮母切上字（杯、北皆帮母字，直下音和）；“府”今读 f-（三十六字母归非母），切出的“悲”却是帮母 p-——今音 b/f 之差正是轻重唇分化的伤疤（上章类隔案）。按“上字用同一字或同组字即同类”的第一层系联，布、府通过“同被用于帮组字且彼此又音互见”系联一链；但若仅凭**分布**（布只在一四等、府只在三等合口）则得“互补分布、古本一类”的判定——这正是曾运干归纳的“分布补充”法。本题即陈兰四十一类工作的最小单元：**类由证据链定义，不由字形或今音定义**。
:::
:::

::: definition 反切系联法四路 {#def-xilian}
陈兰《切韵考》奠基、经后人整理的四路操作：**基本系联**（凡上字相同、或用字互为一字之切上字者，所切字同声类）；**同字异切作桥**（同一被切字的几条切语，其不同上字互证同类——又音材料提供链条的搭桥）；**分析法**（同一上字切出的两批下字分处不相交的韵等，则该上字实兼两类，须拆——解决“一字两读当两职”）；**分布补充**（两堆上字互补分布且语音对应，判为历史同类）。四条的产物即“声类”表：**切韵声类 ≠ 三十六字母 ≠ 拟音**，三层各司其职：类是分布事实，字母是历史命名，音值是构拟推断。
:::

::: warning 声母学习的三个陷阱
（1）**把字母当音标背**：“並”不读 bíng 那个音，它是“定类全浊塞音”的符号；音值各家拟音（*b/ *d/ *g- 带声气流与否）是论文不是教条。（2）**用普通话声母硬对三十六字母**：普通话 f- 可来自非奉微三途、h- 与匣晓纠缠、零声母背后站着影云以疑微——**一对多、多对一**是规律而非例外，须查“普通话声母来源表”（下一课附表）。（3）**拿《切韵》无“照穿床审”轻重的分别去考《诗经》**：上古声母研究（见[[phonology/old-chinese]]）用的证据是谐声与通假，不是韵书字母；两套系统隔着一千年，证据链不可串门。
:::

::: exercise 类隔判读 {level=2}
判断下列切语在“今读层面”是否类隔，还原其《切韵》声类并说明音变条件：①眉，武夷切；②都，当孤切；③悲，府文切。
::: solution
①武（微母）切眉（明母）：轻重唇类隔，切语时代“武”仍在明母——条件：三等合口促重唇读轻唇，微母出自明母；②都，当孤切：端切端，一四等不触发舌上化，音和——“先判类属、再论隔否”的顺序示范；③悲，府文切：府今 f-（非母）而悲为帮母 p-，今读层面呈隔、切语时代同为重唇本属音和——与①同型而方向相反（一为彼时本同、一为今已分化），两案并置，方见“类隔是关系判断”的真义。
:::

::: exercise 来源追溯 {level=2}
普通话声母 f 的字来自三十六字母哪些母？各举两例并给条件；h 与零声母呢？
::: solution
f：非（飞）、敷（拂）、奉（房）、微（无——微母字“无”系轻唇浊音清化后与奉母合流读 f）——条件皆三等合口（“未、微”系三等开口例外走零声母）；h：晓（火）一等二等、匣（侯）浊音清化依仄归 h；零声母：影（哀）、喻（云以）、疑（疑母洪音ŋ>∅，我）、微（微-未类开口）——一对多的每一条都是“规律无例外”的零件。
:::

::: exercise 小论文：一张表的三次生命 {level=3}
以三十六字母为对象写八百至一千二百字：它作为**唐末宋初拼音实践的操作表**（反切上字排序、韵图布格）、作为**《切韵》声类的近似投影**（四十/四十一类问题）、作为**现代方言与对音的比较坐标**（闽客白读、汉越音、译名材料）分别如何被使用？要求：每种用法举一例；说明把三十六字母当《切韵》实录为什么是方法论事故；结尾用一句话说明本课“类、母、音值”三分层的实用价值。
::: solution
判分点：三种用法不误置（操作表在韵图检音、投影在系联统计、坐标在对音比较各举一课内/课外例）；“字母崇拜”批评指向混淆共时记号与历时的音（与[[modern-vocabulary/dictionaries]]“词典两副面孔”同构）；三分层结论表述为“证据等级不同的三张地图，不得叠印”。
:::

::: summary
三十六字母＝部位（唇舌牙齿喉＋半舌半齿）×方法（清浊）的声类符号阵，源出守温三十字母的唐本，增补于轻唇、舌上分立完成的时代。反切系联（基本系联、同字异切、分析法、分布补充）证明《切韵》声类为四十一上下，帮非、端知两组是同一声类的两副时代面孔——**字母是投影，声类是分布，拟音是推断**，三分层是使用音韵材料的第一纪律。下一课把镜头从“声”移到“韵”：韵摄、等与开合，以及四声的真正含义。
:::
