title: "反切"
---

在没有字母的文明里给一个死字注音，古人交出的答卷漂亮得惊人：**拿两个活字，一个借头、一个借尾，拼出第三个字**——这就是反切。它是韵书的原子、音韵学的第一道门，也是中国古代语言学最像“技术”的发明。

## 原理与读法 {#sec-yuanli}

::: definition 反切 {#def-fanqie}
反切（古称“反”，又称反语、反音）用两个字注一个字：**上字取声（声母），下字取韵与调（韵母＋声调）**，急读相合即得其音。《切韵》：“东，德红切”——德提供 d-，红提供 -ōng（平声），合为 dōng。字例的常规写法是“×，××切”或“××反”。直音（“邕音雍”）遇同音字荒年即断顿，读若（《说文》“瞽读若嗀”）只是模糊比喻；反切第一次让**任何字皆可两字拼出**，注音从此成为可系统的工程。
:::

::: theorem 用今音拼反切的三道修正 {#rule-sandao}
用普通话拼古反切，三处必须校正：**①类隔切**——早期声母不分轻重唇、不分舌头舌上，上字按今类“隔”了一层：如“眉，武夷切”，武今读 w-（微母），拼出来却是 méi——因为**切语产生的时代“武”与“眉”同为 m-**，此类须依韵书声类改拼；“非敷奉微”系上字切帮组字皆然，它们是“古无轻唇音”的活化石。**②平声两轨与清浊**：下字定平上去入，而**平声分阴阳看上字的清浊**——“东，德红切”德清音→阴平 dōng，“同，徒红切”徒浊音→阳平 tóng：同一个“红”字，声调被上字遥控。**③切语的音势变迁**：切语用字自身也在变，今读者须还原其历史身份——“现，胡甸切”胡 h-＋甸 -iàn→xiàn ✓；若拿“许”今音 x- 去拼“许健切”，就错过了它晓母 [h] 的本相。口诀：**拼不出别慌，先查是不是音变，不是古人写错**。
:::

::: example 逐字施工 {#ex-shigong}
⑤匪，非偉切。
::: solution
①h＋áo→háo（匣母 h 与今 h 同源，直拼）；②l＋àn→làn（下字“战”供去声）✓；③贯：古 g- ＋患（huàn 的韵母 -uan、去声）→ guàn ✓；④m＋ào→mào ✓；⑤匪：非（今 f，切语时代与帮同读重唇）＋偉（-ěi·上声）→ fěi ✓。五例全直拼成功者说明你已掌握“取声取韵”的手感，留意 ⑤ 的批注才算掌握历史层。
:::

## 反切从哪来 {#sec-lai}

::: history 佛经转写与“声韵之分”的发现 {#sec-fojing}
汉代注经只用直音读若，声与韵从不分说——“东，德红切”式的分析在汉人眼里并无必要。局面随佛教东传而变：梵文悉昙字母有“体文＋声点”的音素分析传统，转写真言需逐音配字，沙门与士人在“胡语十四音、四流音”的表格式拼读前，第一次看清汉语自己的骨架。旧题魏孙炎《尔雅音义》大量用反切，被视为制度化之始（《颜氏家训·音辞》已追论“近为人”的反语风气）；魏晋玄谈与清浊之辨随后把“声类”“韻部”变成可议之物，终于汇成《切韵》。**没有哪一门本土学问独自走到门口，跨语言接触提供了踹门的力**——这是音韵学给文明交流史写下的判词。
:::

::: intuition 反切是汉字文明里的“隐形字母”
反切上字按今音分类，可整理成声类表（《切韵》系联得四十一类，见[[phonology/mc-initials]]），下字按韵归列为一二三四等、开合口——**韵书用两万个汉字做成了“声母表＋韵母表”的二维坐标**，每个字是其格子里的标签，每道反切是格子间的指针。宋代等韵图索性把坐标画成方阵（[[phonology/rhyme-tables]]），反切从注音法升格为**音系学操作**：给一个未收字，也能靠反切链定位它的声、韵、等、开合。说反切是汉字系统的“拼音方案”，不是修辞，是结构事实。
:::

## 反切与古今音的断层扫描 {#sec-duan}

::: example “同”与“东”的声调遥控 {#ex-dong}
“东，德红切”“同，徒红切”“孔，康董切”“空，苦红切”——四例全用洪音东韵作料，今音却 dōng/tóng/kǒng/kōng 各异。列出每条的“变量”，总结反切系统对音类的编码。
::: solution
自变量三个：上字定声母兼**平声阴阳**（德清→阴平东，徒浊→阳平同，苦溪清→阴平空）；下字定韵母＋声调（红-ōng 平，董-uŋ 上——注意“空”下字换“红”而音不变，因“康董切”与“苦红切”是同一韵类不同调的内部分工，孔=上、空=平，调随下字）；等与开合藏在下字里（东合口一等）。编码结论：**反切是“声调清浊分流、韵等打包”的二维编码**——它记录的不是拼音，是《切韵》时代音系学的原始数据库。
:::
:::

::: warning 反切学习三忌
一忌**用今音硬拼后放弃**：拼出“废音”先查类隔、查清浊、查音变，八成是历史的正常回声；二忌**拿单个反切当“古音证据”用满**：一道切只能说明**该字与切语字的音类关系**，证明“古无轻唇音”需要几百道切语的**统计倾向**（钱大昕的方法，见[[chinese-characters/six-categories]]的谐声与清儒传统）；三忌**把反切读法与审音表读音对立**：规范审音定今读，反切供历史账——“骑 qí 旧读 jì”之争正源于混淆两本账（现行规范只有 qí，jì 是反切分化留下的旧读层）。
:::

::: quiz
反切上字提供、下字不提供的一项是（　）。
- [x] 声母
- [ ] 韵母
- [ ] 声调
- [ ] 等呼
::: solution
上字取声，下字取韵与调（等呼随韵母在下字）；“平声阴阳看上字清浊”是第二层规则。
:::

::: quiz
“眉，武夷切”今拼应得 méi 而非 wéi，原因是（　）。
- [ ] 下字失读
- [x] 切语时代“武”仍读重唇 m-，属类隔切
- [ ] 眉为又音
- [ ] 抄本讹字
::: solution
轻唇（微母 w-）出自重唇明母，切语早于分化，故上字“武”当时声母即 m-——类隔切是音变的年轮，不是错误。
:::
:::

::: quiz
“同，徒红切”读阳平的决定因素是（　）。
- [ ] 下字“红”的阳平
- [x] 上字“徒”为浊声母，平声依清浊归阳
- [ ] 徒为去声
- [ ] 韵母洪音化
::: solution
下字只给“平声”这一档；阴/阳由上字清浊分配——浊音平声今归阳平，是入派三声之外最铁的规律之一。
:::

::: exercise 施工五连 {level=1}
拼读下列反切并标注需要修正的位置：①当，都郎切；②遍，方见切；③昏，许昆切；④偶，五久切；⑤空，苦红切。
::: solution
①d＋áng→dāng，上字清音、下字平声→阴平 ✓；②方今 f-，切“遍”得 biàn——轻重唇类隔改 b-，下字“见”记去声，拼 biàn ✓；③许今 xǔ，晓母本 h-：h＋ūn→hūn（若以今 x- 硬拼得 xūn 即误，音势变迁修正）；④五＝疑母 ŋ-，今零声母化；下字“久”上声，次浊上声今仍上声 → ǒu；⑤k＋ōng→kōng，与“东德红切”对照：同为清音阴平，徒（浊）红切才出阳平——清浊遥控练习过关即满分。
:::

::: exercise 类隔分拣 {level=2}
判断下列切语属“音和”还是“类隔”，并给出今读拼法（判定坐标系以切语时代为准，若采三十六字母系请另行声明）：①悲，府文切；②眉，武夷切；③杯，布回切；④展，知堰切。
::: solution
①悲帮母 p-、府非母 f-（三十六字母层面）——若以《切韵》时代论本属音和（同为重唇），以今字母系论则呈类隔之相：**判定坐标系先声明**，两种说法各得半分、说清给全分；②武（微母 w-）切眉（明母 m-）：标准轻重唇类隔，上字回读重唇拼 méi；③布帮母切杯帮母：音和，bēi；④知母自切：音和，zhǎn。本题真意：**音和／类隔是关系判断不是字籍判断**——同一道切在不同声母系统里归类不同，这正是“切语早于音变”的又一证。
:::
:::

::: exercise 小侦探 {level=2}
材料三道切语：①无，武夫切；②肤，甫无切；③矛，莫浮切。反切上字的系联原则是“切上字与被切字声母同类”。任务：据此重建“武/甫/莫”与“无/肤/矛”的声母关系，解释为何今读出现 f/w 与 p/m 的分歧，并说明这组材料如何支持钱大昕“古无轻唇音”说。
::: solution
①武（今微母 w）切无（今零/w）——武无同类，且与③莫—矛（明母 m）同型；②甫（帮母 p）切肤（今敷母 f）——轻重唇对转。三条合并：**今读 f/w 的字，其切语上字全落在帮组重唇（帮武明甫）**——上字系联原则保证同类，故切语时代其声母即 p/m 类；钱大昕“古无轻唇音”由数百例统计而成，本题是其微缩演示：**先立“同类”公理，再看今读分歧，唯一解释是分化音变**。
:::

::: exercise 小论文：反切的思想史席位 {level=3}
写一篇八百至一千二百字短论：反切是否构成汉字文明中的“字母发现”？要求：引用“丢掉/只取”流水线意象论证声韵调三参数的**可分离性**已被操作化；对比韩国训民正音（1443，音素字母创制）说明为何“分析”可以停在坐标层而不落到字母层（考虑汉字威望、音节观、佛经接触的深浅）；回应一个反论（“反切只是查字术，不含理论”）。
::: solution
判分点：核心论证成立（反切=把音节拆为声/韵/调三个可独立替换的参数——替换框架已是操作化的音位分析）；训民正音对照史实正确（朝鲜世宗君臣 1443 年创制的二十八个字母，用以记录朝鲜语并转写汉音）；“为何分析可停在坐标层而不落字母层”给出制度与观念理由（汉字为经籍正统、反切已够用、韵图满足结构表达、佛经接触未深及士大夫主流）；反论处理认真（“查字术”与“理论”之别恰在《韵镜》的方阵与清人声类系联——理论活在操作与传承里）。
:::

::: summary
反切＝上字取声、下字取韵调的两字拼音系统，汉末佛经转写催化而生，韵书因它成为可能。今音拼读须带三道修正：类隔切（轻唇重唇、舌上舌头的年轮）、平声阴阳随上字清浊、切语用字自身音变的核对。它的思想史分量：把汉语音节拆成三个可独立替换的参数，是汉字文明内的“隐形字母表”——不必造字母，也抵达了音系学的坐标层。练好反切，后面六章的声类、韵摄、等第全是它的延伸应用。
:::
