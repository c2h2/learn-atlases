title: "中古韵母与声调"
---

声母是音节的首富，韵母才是全族的户籍。《广韵》二百零六韵如何归并为十六摄、“等”到底是什么、四声从何定义又向何分化——本课把“韵”与“调”两本账一次算清。

## 韵母的层级：小韵—韵—摄 {#sec-jiceng}

::: definition 三级户籍与四类型 {#def-sanji}
韵母系统三级管理：**小韵**（同音组，反切锁定）→ **韵**（206 个，韵书分类单位）→ **韵摄**（十六摄，宋人为检诗韵“同用独用”归纳的更大类，如宕摄含唐阳、江摄入声归业鐸）。十六摄名目：“通、江、止、遇、蟹、臻、山、果、假、宕、江、曾、流、咸、深、効”，诵诀分三组：“通江止遇蟹，臻山果假宕，曾流咸深効”（効摄管“盐添咸衔厳”之家；江摄独立，与见系“江”字无涉）。按韵尾分四类：**开声**（元音尾，歌戈之微）、**阳声**（鼻音尾 -m/-n/-ŋ：侵覃、真寒东、阳江）、**入声**（塞音尾 -p/-t/-k：缉合、质曷物、药鐸）——**阳入成套**：宕—効（-ŋ/-k）、臻—质（-n/-t）、深—侵（-m/-p），整齐到类型学可疑，正是《切韵》“综合”性格的铁证（上章之狱）。独缺位一处：**痕韵无独立入声韵目**（“兀、哌”之类少数入声字附见魂没诸韵，未立韵目），千年来被引为“系统有裂缝”的标本。
:::

::: theorem 等：韵与声母共谋的四档分类 {#rule-deng}
“等”是等韵图每韵分排的纵横格：**一等**主元音洪大低后（*-ɑ 类）、**二等**带 -r- 介音或元音偏前而喉化（李方桂拟 *-r-，今闽客读 k-/g- 组“江、项”之别即其回声）、**三等**带 -i- 介音（整个系统最“挤”的人口大镇，轻唇化、腭化全发生于此）、**四等**古无 -i- 介音而与一等邻近（“先、萧”今读细音为后期腭化）。三关键：①**等是“整个小韵的属性”而非声母的属性**——同一声母可切出三四等字（见溪群疑俱全），故“见溪群疑分洪细”之说错；②**二等重喉音**“江无见溪”之类的韵母声母配合限制，由韵图格子直接显示；③**四等合口极稀**（“玄”类数字），故《韵镜》或借格处理——格子空着，恰见音系有边界。
:::

::: example 摄的用法：查“江”的全家 {#ex-she}
写出江韵字在中古系统里的“三兄弟”（开阳入对应）与所属摄；再用普通话反推：为何“江 jiāng、窗 chuāng、双 shuāng”同韵而“江”今读见母细音？
::: solution
江韵属**江摄**（独立成摄，因元音 *-ɔŋ 与宕摄*-ɑŋ 有别）；入声为**覚韵**（-k 尾：捉、卓——江覚对应）；无对应开声（阳声独来）。普通话：江摄并入宕摄（-aŋ），“江”读 jiāng 是见母二等颚化（k-→tɕ-，细音条件，见[[phonology/to-mandarin]]）；窗、双保留洪音读法说明二等字分途——**摄是历史地理的“省”，韵是“县市”，小韵是“门牌”**，做方言比较一律先上升到摄。
:::

## 四声：从“声”到“调” {#sec-sisheng}

::: definition 四声的三重身份 {#def-sisheng}
**类别身份**：平上去入是音节的第三层特征（与声、韵并列），《切韵》靠它分卷；**形态身份**：上去两途常是构词手段——“王 wáng 平声（名）→wàng 去声（动词：称王）”“衣 yī→yì（穿）”“治 chí（理）→zhì（治理好的）”，此谓**读破（四声别义）**；去声常对应上古 **-s 后缀**（周法高、梅祖麟一脉：使动、名物化）、上声常对应 **-ʔ 尾**（“父、母、女、宝”等亲属与指小词的 -ʔ 之谜）——声调是构词化石的沉积层。**描写身份**：调值不可考，只能从“平言舒、上厉、上去远、入质直”的旧目——结合旧传《调经》一系文献对四声的形容、齐梁人论声病的“平言/上去”对举、以及今方言调类对应，推拟：平为中平长调、上为升或带喉塞短升、去为高降或带 -s 余韵的长去、入为短促带塞尾——**给中古调值写精确五度制是越权，给调类写演化方程是本行**（平分阴阳、浊上变去见[[phonology/to-mandarin]]）。
:::

::: history “四声”之被发现：永明声律与佛教转读 {#sec-yongming}
汉语从来有人说“声”，但把**四声立为文字艺术纲领**的，是南齐永明八年（约 480—490）周颙、沈约一伙：“欲使五色相宣、八音相让……四声韵遍，八病微避。”沈约《宋书·谢灵运传论》自夸“自骚人以来，此秘未睹”；钟嵘《品》讥其“襞积细密”。四声说兴起的同期，正是转读佛经（以声论经）、梵文声明论输入之时——四声之“发现”，一半是文学的自觉，一半是跨语言比较的副产品。自此“声病—近体—词律”一路到《中原音韵》“入派三声”皆为此谱系的后话。
:::

::: warning 韵母声调学习四坑
（1）**拿今韵反推中古韵**：“街 jiē”中古在佳韵二等（佳韵拟音诸家作 *kˠɛ 一类，与今读相距甚远）——佳皆皆蟹诸摄读今 -ei/-ai 各有来历，先查后说；（2）**混淆“等”与“呼”**：开口合口是唇形维度（有无 -u-），等是元音/介音维度，两轴垂直才定坐标；（3）**“上去常是后缀”读成“上去常是错读”**：读破是构词不是正误，文言教学可保留“王天下 wàng”而不宜贬为“旧读怪异”；（4）**把入声当“短音”**：入声本质在塞音尾，长短是派生特征，日语汉音（setsu 的尾元音即 -t 的“影子”）、粤语（-t 完整保留）皆可作证。
:::

::: exercise 户籍归档 {level=1}
为“东、真、盐、歌、业”五字各定：摄、开阳入类别、有无入声伙伴；再指出哪两个属于同一对“阳入相配”。
::: solution
东＝通摄阳声（-ŋ），伙伴“屋”；真＝臻摄阳声（-n），伙伴“质”；盐＝咸摄阳声（-m），伙伴“帖”；歌＝果摄开声，无伙伴；业＝咸摄入声（魚怯切，-p），恰与“盐”成一对阳入相配。答“业属深摄入声”不得分——深摄的阳入对是“侵—缉”。五档全对且指出“盐—业”配对者满分。
:::
:::

::: exercise 读破整理 {level=2}
为“衣、朝、数、处、食”各列平/上/去读与对应词义，并推测哪些去声读可能带 -s 使动/名物化来源。
::: solution
衣 yī 名→yì 动（穿，名→动之去）；朝 zhāo 晨→cháo 朝见/朝廷（名动相因）；数 shǔ 动→shù 名（动→名之去）；处 chǔ 动→chù 名（动→名）；食 shí 动→sì 动词“给…吃”（使动，去声 -s 典型候选）。凡“使/被”与“名物化”两型皆 -s 候选；本题练“调类=形态学地层”的眼光，立场取周法高—梅祖麟说或持谨慎皆有理，理由给分。
:::
:::

::: exercise 摄级比较 {level=2}
方言材料：厦门“行 kiâ（走）/hiâŋ（行为）”、北京“巷 xiàng”对粤语“巷 hong6”。用“摄”的上升抽象解释：(a) 厦门两读是什么关系；(b) 北京“巷”的 -iang 韵来自哪摄的什么过程。
::: solution
(a) 文白异读：hiâŋ 为梗摄文读层（“行”属庚韵二等，-ŋ 尾保留），kiâ 为白读层（主元音高前化，与“喉、鉤”类白读同层）——两读不是母子派生，而是两时代两渠道的继承层次；(b) “巷”为江摄匣母二等（*hrɔŋ），粤语 hong6 保留江摄主元音 -ɔŋ，北京 -iang 来自江摄归入宕摄（-aŋ）后主元音再高化前化的连锁——两级比较一画线，表面的“无规矩”就成了两时代的音值剖面。
:::

::: exercise 小论文：韵母是系统，声调是历史 {level=3}
写八百至一千二百字，用本课材料完成一个论证：(a) 阳入相配的“过分齐整”与“痕韵缺入”这一对现象，如何同时支持“《切韵》是综合系统”与“音系可以局部不对称”；(b) 读破四声别义证明声调承担形态功能，那么“调类比调值稳定”该如何从入派三声反证（预设读者：学完本章的中文系二年级）；(c) 给这门课的一位同学写一句“什么时候你会用到韵摄”的实用理由。
::: solution
判分点：(a) 齐整=多源折衷的人工秩序，缺位=活音系的自然伤口，两者并存恰排除了“单一活音录”；(b) 调值可改（入派三声=调值与配列重排）而调类记忆在字书/方言分派中守恒，稳定性论证落到“类是类标签、值是值实现”（音位—音值之分，与[[sounds-of-mandarin/tones]]五度制遥应）；(c) 一句真话即可（读词律、查通假、比方言）。
:::

::: summary
韵母三级户籍（小韵→206 韵→十六摄），四类结构（开阳入＋独缺的痕入一角）；阳入相配是《切韵》最齐整也最可疑的美。等的四档是元音/介音的坐标而非声母的属性，二等带 -r-、三等挤 -i- 是后面全部大音变的火药。四声是类别、是形态化石（-s、-ʔ）、是调值悬案——调类演算可推，调值复原当忌。带着“摄”的望远镜，方言分歧立刻从噪音变成对应；下一课看宋人如何把这一切排成一张图。
:::
