---
title: "上古音"
---

把《切韵》坐标再往回推一千年，就是《诗经》的时代——韵部对不上、谐声字互相“招供”、声调还没有诞生。上古音是音韵学的珠峰：证据最硬、争议最多、风景最壮。

## 三门更老的证据 {#sec-zhengju}

::: definition 上古音材料层 {#def-cailiao}
①**诗经韵**：《诗经》用韵与先秦韵文（楚辞、周易彖爻辞）——押韵是古人亲手登记的同韵表；②**谐声系统**：《说文》形声字声旁网络（“工”族：空、江、红、巧、考；“各”族：路、格、客、洛、搁）——造字时代同声旁者声韵相同或极近，这是一部**埋在手机都打不出字的甲骨文里的韵书**；③**通假与声训**：传世文献假借（蚤=早、信=伸）加出土简帛（郭店、上博以“各”代“洛”类），是古人投票的同音认证；辅以读若、声训、早期译音（梵佛、葡萄类西域词）与汉藏比较。谐声看**造字层**（商周），诗经看**诵读层**（西周春秋），通假看**书写层**（随时）——三层互证，才谈得上“上古”一个时代。
:::

::: history 清儒：三百年分部首发 {#sec-qingru}
明代陈第《毛诗古音考》（1606）立“时有古今，地有南北，字有更革，音有转移”，废“叶音”之弊，开古音学之门；顾炎武《音学五书》以《诗经》韵字归为古韵**十部**，第一次用统计眼光整理全部韵脚；段玉裁《六书音均表》分**十七部**，并指出“**同谐声者必同部**”——把谐声系列纳入分部的第二证据链，古韵学由是“大备”（王力语）；江有诰、王念孙各有所增（脂祭分部入声系统理顺），孔广森倡**古无去声**说，戴学分合细入声。清儒手里没有音标、没有出土简帛，全凭《诗经》三百篇与一万五千字《说文》排比——**分布分析法在中国的第一次大规模成功，比西方结构主义早了三百年**。今用王力**十一部**系统（之、幽、宵、侯、鱼、支、脂微、职德、药铎、屋、东部诸分合），教材多依之。
:::

::: example 谐声的招供：各族 {#ex-ge}
“各”是声旁：格、阁、搁读 g-，路、露、洛读 l-，客、喀读 k-（kʰ）。若上古声母与今日一样，一个“各”（见母 k-）为什么招出 **l-** 家亲戚？
::: solution
任何单一 k- 都教不出 l- 的学生。唯一经济的解释：“各”的上古音带**复辅音**——李方桂式 *kl-（复声母），Baxter–Sagart 式 *k.r-（带音节性前缀）——后世各支分流：丢流音成分的成“格、阁”（k-），丢塞音成分的成“路、洛”（*k.rak > lak），异读与又音里还留着两套痕迹。**谐声系列是复辅音的集体宿舍**：一声旁教出“不同声母”的几家弟子，就是它当年不止一个声母的供状。钱大昕“古无轻唇音”（“匍匐”之或作“蒲服”、非敷奉微字与帮组字互谐互假类）、“古无舌上音”（知彻澄与端透定互谐互读类）用的正是同一把钥匙：**今音差异＋谐声一致＝上古合并**。
:::
:::

::: theorem 声调之前：-ʔ、-s 与入声的王国 {#rule-shengdiao}
上古声调问题是上古音最性感的悬案。证据链：①诗经调类通押格局与中古四声不齐（上去杂揉、入声独峻）；②谐声系统里**去声字常与入声字同族**（“至”族、“对”族之类）、**上声字常带“止、母、女”等亲属指小词**；③汉藏比较与形态残留。据此，平山久雄—周法高—梅祖麟一脉提出：**去声来自 *-s 后缀**（使动、名物化：“王 wàng、治 zhì、食 sì”正是化石，见[[phonology/mc-finals-tones]]），**上声来自 *-ʔ 尾**（喉塞音，与闽语“飞歌”类白读、藏文对应词互证）；入声本带塞音尾，最保守。于是上古的“调”还不是音高曲线，而是**韵尾的余晖**——四声是塞音与擦音退化出来的产物，这是汉语史最漂亮的一章。
:::

::: intuition 孔子与你的语言屏障
李方桂一派的著名推论：若穿越回春秋，与孔子对话基本无法互通——不是词汇难，是**整个音节结构不同**：他嘴里 *k.rak（“各”）、*maːʔ（“马”，上声 *-ʔ 来源示意）式的复辅音与开音节长元音系统，经先秦两汉的“简化雪崩”（前缀脱落、复声母单化、韵尾合并）才凝成《切韵》的四十一类、《现汉》的二十一个声母。**构拟不是给古人录音，是给规律建模**：每套拟音（高本汉、李方桂、Baxter–Sagart、郑张尚芳各家）都是一台解释机器，考卷同而答案各异——把某家拟音当“标准答案背诵”，是上古音学习的第一病。
:::

::: history 构拟时代的百年赛道 {#sec-gouji}
高本汉（1910s—1920s）以《切韵》框架向上推拟，第一个给上古音画全图（类型学怪异的复声母遭诘病）；王力《诗经韵读》《汉语史稿》立十一部与谨慎体系，“不自证怪异”；李方桂 1971—73 年《说文解字读若考》与《上古音研究》把谐声读若尽入彀中，*kl- 式复声母成国际通例；1980 年代后，出土简帛（郭店、上博、清华）源源供给战国抄本通假，成为“书写层”新证据；郑张尚芳、白一平—沙加尔（2014）引入**前缀与准双音节**模型，上古汉语向藏缅语的形态学图景靠拢；STEDT 与可检索的拟音数据库让分部与谐声统计进入可复算时代。**一部上古音史=证据不断升级、模型不断被推翻的裁判所**。
:::

::: warning 上古音学习四戒
戒**背拟音为圣典**（各家体系不可通约，引注标明体系）；戒**谐音当词源**（“天=颠”式声训是形态联想不是音变规律，滥用即民科之门，参[[modern-vocabulary/lexicon-layers]]“民间词源”条）；戒**跨层借证**（拿中古韵书材料证上古、或反之，证据链各有时代管辖权）；戒**神秘主义**（“上古音=英语/藏语/努尔哈赤语”诸说，凡无规律对应、可证伪预测者一律出局——汉藏同源是严肃课题，不是自由恋爱）。
:::

::: exercise 分部实操 {level=1}
《诗经·周南·关雎》“流、求”“芼、思”两组韵脚，用十一部系统判断各位何部，并说明今音为何失联。
::: solution
流、求同幽部（*-u 类韵，今音 liú/qiú 仍留同痕）；芼属宵部、思属之部——本不同部，此章为交韵（两韵交叉）现象；今音 máo/sī 失联是宵之两部元音各自演变之果。判对四位归部即给分，韵部口径允许注明所据体系（王力十一部/其他）。
:::
:::

::: exercise 复声母办案 {level=2}
“蒙”从“冡”得声，而“冡”族有“梦（m-）、龐（p-）、龍（l-）”。请拟一条复辅音方案解释这三家，并说明你方案的可检验预测（至少一条）。
::: solution
开放题。示例路线：设“冡”带鼻冠塞音或冠音-流音复声母（如 *m.q- 类），其后裔分流：存鼻音成“梦”m-，存流音成“龍”l-（*r->l-），失冠音又浊化成“龐”p-。评分要求：给出任一 *C1C2- 型方案＋至少一条可检验预测（如：该族又音/通假应现 m-↔l- 交替；同族“朦、籠”诸字声母应各自合规分流）。方案自洽、预测可证伪即满分；只报拟音不给检验者半分。
:::
:::

::: exercise 小论文：穿越者的听力 {level=3}
假设你真带手机穿越回公元前 500 年的洛阳周边，用八百至一千二百字写你的“听力报告”：哪些音你完全听不出区别（合并）、哪些音你觉得多余（今已消失的对立：复辅音、-m/-p 尾、-ʔ/-s 尾）、你多久能被当地人听懂（音节结构简化速率的想象）。要求全部论点锚定本课三层证据之一，禁止无对应规律的“像外语”式感慨。
::: solution
判分点：‘听不出’须落在真合并上（如复辅音听成单辅音、之脂支细别无从分辨）；‘多余感’须锚定 -p/-t/-k、-m/-n/-ŋ、-ʔ/-s 与谐声通假各一例；速率论证须引“谐声→切韵→普通话”压缩实例（“各”族即现成一案）。每一断言标‘据/测’；无对应规律的‘像外语’式感慨酌情扣分。
:::

::: summary
上古音以三门证据立基：诗经韵（诵读层）、谐声（造字层）、通假声训（书写层），出土简帛仍在加码。清儒三百年分部（陈第破叶音—顾炎武十部—段玉裁十七部与“同谐声必同部”）完成分布分析的中国首演；现代构拟把声母推向复辅音（*kl-/*k.r-）、把声调推向韵尾（*-s 去、*-ʔ 上、塞尾入），孔子已不能说今话。拟音是模型不是录音，跨层借证与神秘主义是两大雷区——带着可证伪的要求读任何一家，你就摸到了这门珠峰学问的门径。
:::
