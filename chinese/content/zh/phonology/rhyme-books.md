title: "《切韵》与《广韵》"
---

如果说反切是砖，韵书就是那座被供了两千年的殿。隋开皇年间的这场“审音沙龙”定下的蓝图，唐宋两朝扩建为《广韵》，此后一千三百年无人能绕开——本课带你进殿：看清它的间架，也看清它的性格争论。

## 一部“开会”开出来的韵书 {#sec-kaihui}

::: history 《切韵》的诞生与传世 {#sec-qieyun}
隋开皇年间（约 580 年代），颜之推、萧该、卢思道、薛道衡一辈名士在陆法言家中夜谈论韵，“论及南北声读，考校韵文同异，斟酌其折中”——陆法言记其议论，于仁寿元年（601）写定《切韵》十卷，收一万两千余字、分立一百九十三韵（或作一百九十四），每字以反切注音、义训从简。唐代科举诗赋日重，孙愐《唐韵》为之增字丰注，屡经修订；至宋大中祥符元年（1008），陈彭年、丘雍等奉敕重修成《大宋重修广韵》五卷，收字二万六千余、仍分二百零六韵，卷内附“同用独用”之注以供程试。陆书原本至近代已几乎不存，而敦煌、吐鲁番出土唐写本片断与日本藏旧抄陆续重见（二十世纪有《唐写本切韵残卷》等多种辑印），其骨架原样活在《广韵》里——**一部失传的书，靠一部修订本活着，这恰是韵书史的正常工作方式**。
:::

::: definition 《广韵》的间架 {#def-jianjia}
《广韵》五卷按声调分帙：**平声分上下两卷（字多），上、去、入各一卷**；卷内分韵，平声东冬钟江以下五十七韵、上声五十五韵、去声六十韵、入声三十四韵，凡二百零六；每韵内再分**小韵**（同音字组，首字注反切，其下直列同音诸字），共三千八百九十个——**小韵即一个音节的“户口本”**，反切、声类、韵等的信息全钉在小韵头上。韵目次序（东冬钟江支脂之微…）不是检字索引，是音感分类：相邻韵目音近，分合之间全是历代审音的官司。先背一组“四声套”：东—董—送—屋，平上去入一系贯通、入声以 -k 尾自成一格——**四声不只是调子，更是同一韵基的四种形态**（平声独占两卷只因字多，东韵字全在上平，无“半韵”跨卷）。
:::

::: example 四声一套：东董送屋 {#ex-sisheng}
《广韵》东韵“东，德红切”、董韵“董，多动切”、送韵“送，苏控切”、屋韵“屋，乌谷切”。排比四字的声、韵、尾，说明《广韵》“以类相从”的编排逻辑。
::: solution
东德红切 təŋ、董多动切 təŋX、送苏控切 sowŋH、屋乌谷切 ʔuk（拟音取通行框架示意）：东董送三字韵基相同、只差声调；屋字带 -k 塞音尾，与 -ŋ 阳声成套对应（阳入相配）。《广韵》的目录学就是音系的目录学：按韵编字、以调分行、入声独立成卷——一部没有索引的数据库，键是音节，值是反切与同音组。进而，查到“送，苏控切”即可推问：同韵同声母的平声、上声字头存在与否一目了然——小韵的“有音无字”缺位（空槽），后来由《韵镜》用圆圈一一填出。
:::

## 性质之争：《切韵》记的是哪张嘴 {#doc-xingzhi}

::: theorem 定韵之争：一时之音还是综合系统 {#rule-dingyun}
《切韵》音系是什么？三派：**单一音系派**认定它记录某地实际口语或读书音（长安、洛阳、邺下各有其说）；**综合音系派**（王力《论〈切韵〉的性质》持此说）认为它“折衷南北、兼存古音”，是审音委员会的**最大公约数系统**，非一时一地之语；还有一派视之为服务科举与跨方言沟通的“规范参照系”——人造而实用。课堂立场：**把《切韵》当“带音标的文言正音总目”用**——它精确到可以推理声韵结构，又综合到不必回答“老奶奶这样说话吗”。注意两个事实支持综合说：其一，分韵比任何已知方言都细（之脂支三韵并立，阳声入声成套得类型学上过分齐整）；其二，颜之推在《家训·音辞》里已经痛骂“南染吴越、北杂夷虏”，他们的志向正是**超越一地之音**。
:::

::: example 平水韵：206 韵的“科举简化版” {#ex-pingshui}
唐诗用韵比《切韵》宽还是严？金代书坊《新刊韵略》平本一系（习称“平水韵”）把 206 韵并成 106 韵：把若干“同用”邻韵径行合并。以“东、冬”与“江、阳”为例，说明平水韵合并的依据与后果。
::: solution
“东”拟音 -uwng、“冬”-uwng 主元音有异（*-uŋ 与 *-oŋ 之别，取“音近可通”义即可）、“钟”-jwoŋ、“江”-æwŋ。唐代诗作中“东冬”已常用不分，官方“同用”注顺势并入（东冬同用、江与阳唐通转之类），平水韵更把“同用独用”升格为韵部——结果是诗韵定格比《切韵》时音落后三四百年，直到 1917 年还写在诗人嘴上。结论：206 韵是语言学的骨架，106 韵是创作学的现行，两套坐标系要同时装进脑子（[[poetry-metrics]]将全程使用后者）。
:::
:::

::: warning 读韵书四防
（1）**防把韵目当单词读**：小韵头是音的代表字不是词义单位；（2）**防忽略又音**：一字两读常分两义（“王”平声为名词、去声为动词“王天下”），只查头一个音会读失词性与词义（“王”平声为名词、去声为动词“王天下”；“数、雨”上去别义同理）；（3）**防把《广韵》义训当本义**：它是韵书不是《说文》，释义随俗从简；（4）**防用《广韵》音拼现代姓氏地名的“古音”**：音类≠音值，族谱上“读若×”的传说经不起反切核对。
:::

::: exercise 结构复述 {level=1}
不看本课，画出“卷→韵→小韵→反切/同音组”结构图，并回答：为什么平声占两卷而上去入各一卷？
::: solution
图完整即对；平声两卷的答案：平声字（在诗歌与常用词中）量最大，编纂时按多寡切分上下——卷帙分配是字数的妥协，不是音类的分裂（东韵字全在上平，无“半韵”跨卷）。
:::

::: exercise 四声套系 {level=1}
默写“东、董、送、屋”四字的《广韵》反切（可参考课内例题），再写出四字在通行拟音框架里的韵尾与声调标记，解释“阳入相配”。
::: solution
东德红切、董多动切、送苏控切、屋乌谷切（皆《广韵》原本）；韵尾：-ŋ／-ŋX／-ŋH／-k，阳声鼻音尾与入声塞音尾成套——屋即东韵系统的入声伙伴（东董送为一系、屋为东之入）。四切无误且“阳入相配”解释到位即满分。
:::
:::

::: exercise 性质立场文 {level=2}
三选一站队（单一音系／综合系统／科举规范参照），写四百字辩护：引至少两条课内证据（分韵之细、《颜氏家训》态度、阳入齐整、唐写本“同用”注），并回应对方最强的一条反驳。
::: solution
判分点：证据与立场自洽（选“综合”者可举之脂支三分无方言支持；选“单一”者须解释齐整的阳入配对——类型学上并非不可能）；对方反驳不是稻草人；允许结论为“不可判定”，论证质量论分。
:::
:::

::: exercise 小论文：从《切韵》到《现汉》：审音的两种国家 {level=3}
写八百至一千二百字：开皇审音会议与 1956 年之后普通话审音委员会相隔一千三百五十年，任务却相似——为一个超方言共同体定“标准读法”。比较两组的材料（韵书对语料）、方法（考校同异对词频统计）、困境（南北折衷对从俗从简）与产品（193 韵对 6 版《审音表》草案之争），并回答：为什么两者都被同时代人骂过“改音乱俗”？要求引用课内一处《切韵》分韵实例与一处审音表争议实例。
::: solution
判分点：类比落在“规范化 vs 描写”的结构性张力（[[modern-vocabulary/dictionaries]]两副面孔的回声）；材料—方法—困境三轴至少各展开一处；引用无硬伤（隋之“南北声读”、2016 草案之“说、骑”热搜）；结论可以开放，但须给出“代价与收益如何分配”的政治语言学视角（谁被要求改口）。
:::

::: summary
《切韵》601 年成书于一次士人审音夜谈，193 韵以反切为血、以韵目为骨；唐《唐韵》增、宋《广韵》扩建为 206 韵、26000 字、3890 小韵的五卷数据库，阳入成套、平声分帙。它的“失传—寄生—出土”三部曲与“单一还是综合”的性质之争，提醒我们韵书既非录音也非乱账，而是**音类关系的最大显式记录**。平水韵 106 是其诗学分册，等韵图是其矩阵化转世——下一章我们就去读宋人画的矩阵。
:::
