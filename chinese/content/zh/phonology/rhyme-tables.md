---
title: "等韵图"
---

韵书是按韵编排的电话簿，等韵图则把它改写成一张**元素周期表**：声母排成列，韵与等分成栏，四声叠成层，每格一个音节——有字填字，无字画圈。宋人没有字母，却画出了汉语语音系统的完整矩阵。

## 韵图是什么 {#sec-yuntu}

::: definition 等韵图与两部代表作 {#def-yuntu}
等韵图（韵图）把反切系统坐标化：**纵列声母**（三十六字母按唇舌牙齿喉与清浊排定），**横栏韵与等**（同图内按四等分档），**四声分层**（平上去入各占一段）；格中列代表字，字头统领一格同音。现存两大系统：《韵镜》（宋人翻刻旧籍，五卷四十三图，逐图标目如“东董送屋 通开第一”之制，保存早期正规韵图体制，是研究《切韵》结构的主证）与《切韵指掌图》（旧题司马光，二十图，分等别开合、按图检切，属通俗速查系，偶有疏舛）。后世《韵略易通》等为简化一脉。**格子的坐标意义**：一列是同声母四声全变的纵队，一行是同韵异母的横排，一图是一韵摄开合一等的全部户口。
:::

::: example 查图三步：从反切到坐标 {#ex-chatu}
在《韵镜》里定位“东”（德红切）。
::: solution
第一步**归韵立图**：东属通摄、开口、一等，对应第一图（图名“东董送屋 通开一”——四声套直接写进图名）；第二步**上字查列**：德归端母列（舌头音全清）；第三步**下字定栏层**：红定韵母与平声层。落格读作“端母·通开一·平”，顺带看见全家族：本格上下层是东—董—送—屋（同韵四声），同行邻列是冬、宗、聪（同声母邻韵）。**反切是密码，韵图是坐标纸**——图读会了，切语自动变成地址。
:::
:::

::: definition 行话速成：转、开合、图名 {#def-zhuan}
**转**：四声成套的一群韵（通摄诸韵为一转），四十三图即按转排布；**开合**：有无 -u- 介音的另一轴，东为开口、冬为合口，别为两图；**等**：栏内分档（一等洪、二等在韵图中自为一段、三等最繁、四等附末）。图名行话如“通合一 东董送屋”——背得摄名与开合等，图名即检索式：**韵图是数据库，图名是查询键**。门法（韵图的“例外条例”，处理声母与韵等不配的归字规则）条目繁多聚讼，初学可缓，须知其存在即可。
:::

::: intuition 一张图等于一组论文
韵图的深层信息常被低估。娘母格稀如晨星、非组字母只出现在三等合口——这些“格子分布”是音系限制的一手记录，比任何文字描述都诚实。**空圈（○）**标记“有其音而无其字”的座位：语音合法、词汇缺席，后世新词常在此落户。清浊矩阵则把四声行为预装进系统：平分阴阳要等浊音清化才兑现，但韵图的格子早替北方官话搭好了收银台。所以现代学者以韵图为独立证据源——**反切给类、字母给名、韵图给坐标，三角定位方为可靠**。
:::

::: history 韵图的印度血统与东亚旅行 {#sec-xilv}
“以表列音”的形式不是华夏土产：随悉昙学（梵文拼音图表）入唐，以辅音为经、元音为纬的音表原则启发了中国学者——但韵图把无声调语言的形式改造成**四声分层**的矩阵，又发明“等”的栏轴，全是汉语化的再创造。这张表之后继续旅行：朝鲜创制训民正音（1443）时以中国音韵之学为参照、日本悉昙四声图籍亦余裔可见。工具的来路与归处都在文明交流线上——与反切因佛经而生的故事首尾相衔。
:::

::: warning 读图四防
一防**把字母当音值**：格上“並”不读 bìng，字母是符号，音值靠构拟；二防**拿今音串格**：韵图按《切韵》系统布阵，“机、诗”今音相近、图上分居齿头与正齿两列——腭化是图后千年才发生的事；三防**版本混引**：《韵镜》诸本与《指掌图》字母数目、分图有出入，引用须说版本；四防**空圈过度诠释**：多数空圈是有音无字，少数是编图者系统限制或疏漏——“空即预留”是好原则，不是万能钥匙。
:::

::: exercise 格位推演 {level=1}
写出下列字在韵图中的坐标（摄、开合、等、声调、声母列）：①公；②冬；③送；④屋。
::: solution
公＝通合一·平·见母（古红切，东韵合口）；冬＝通合一·平·端母（都宗切，冬韵）；送＝通合一·去·心母（苏控切，冬韵去声）；屋＝通合一·入·影母（乌谷切，屋韵）。要点：东冬同摄同合口而两韵（东冬分图相邻）；送为冬之去、屋为东之入——写出“送属冬韵去声、屋属东韵入声”即满分。
:::
:::

::: exercise 空圈招聘 {level=2}
韵图为“有其音无其字”的格位画圈。请举一个后世给空圈“补字”的例子（近代新造或借用的字均可），说明它的音系位置与进入时代，并解释早期韵图宁画圈不造字的道理。
::: solution
示范案：**“她”**——口语早有第三人称阴性音（上古之部“彼”行、中古后“伊”“渠”分工，白话兴起需要一个专字），1920 年代刘半农等倡用“她”字，正是给汉语人称系统里一个长期画圈的格位发了字形。道理：字形是词汇层、格位是系统层；编图者忠于系统、不越权造字——**圆圈是语言学家的诚实：宁可留白，不可造假**（对照[[modern-vocabulary/new-words]]的新词落户机制）。
:::
:::

::: exercise 坐标三角 {level=2}
某字《广韵》切语“渠容切”。请推其坐标（声母列、摄、开合、等、声调），并说出与它同格、同列、同层的各一字。
::: solution
渠供声（群母，牙音全浊），容供韵调（钟韵、通摄、三等、平声）→ 坐标：群母·通摄钟韵开口三等·平声，今读 qióng。同格（同音组）：蛩（与“渠容切”同小韵）；同栏不同层：融（以母·钟韵·平声——同一图内换列不换栏）；同列不同图：通摄东韵图中群母平声那一格（坐标指认即可，格中有字无字听凭原图）。判分只看坐标三要素（列、栏、层）是否无误。
:::
:::

::: exercise 小论文：没有字母的音位学 {level=3}
写八百至一千二百字，论证或反驳：“韵图与反切系联证明，汉语传统语言学在无字母条件下达到了结构主义音位学的水平。”要求：(a) 举韵图三项“结构主义特征”（对立表、空位、分布限制各一）；(b) 引乔姆斯基之前音位学“矩阵表”传统（语料—矩阵是 Firth 以前描写语言学的常规武器）作跨文明对照一句即可；(c) 给“达到了/未达到”一个立场并处理一个最强反例（如：无音值、无共时描写对象、门法之繁琐）。
::: solution
判分点：三项特征落到实处（对立：四清浊位；空位：○；分布：非组限三等）；对照不牵强（矩阵表格=描写语言学共同方法，不必攀附“中国早在一千年前就…”式廉价优先权）；反例处理诚实（韵图无音值、服务诵经科第而非理论科学）；结论允许两可，论证质量决定分数。
:::
:::

::: summary
等韵图=把《切韵》反切系统画成声母×韵等×四声的坐标矩阵：《韵镜》四十三图存正规体制，《指掌图》作通俗检切；转、摄、开合、等是它的检索键，空圈是它对“系统先于词汇”的千年证词。韵图的格子分布（娘母星稀、非组限三等）是音系限制的实录，与反切、字母构成三角证据。带着查图三步（归图、查列、定层）再读韵书，反切便从密码变成地址——下一章我们掉转镜头，用这套坐标去看更古老的上古音。
:::
