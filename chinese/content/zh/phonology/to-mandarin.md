《切韵》的音系怎么变成今天手机里的拼音输入法？这中间一千年发生了五六件大事，件件有规律、条条可倒推。本课是音变规律的演武场：学会五条定律，普通话的每个字你都能报出它的中古户口。

## 《中原音韵》：北音的现场录音 {#sec-zhongyuan}

::: history 1324 年的调音台 {#sec-zhlu}
元代周德清以北方唱曲实践为据撰《中原音韵》（1324），为北曲“正语”立范：音系归为**十九韵类**，每韵类下按平阴、平阳、上、去四声调类排 586 组同音字表（小韵），原入声字分派附于四声之内——周德清自道其法曰“入派三声”。它与《切韵》系统判然两副面孔：**入声不再独立成卷**（入声字派入平上去三声——“入派三声”至此书面登记）；**全浊塞音塞擦音清化**完成（字母系统对不上旧图）；**平分阴阳**白纸黑字。韵书史从“照古经”变成“录时音”——**一部曲律书意外成为近代官话音的出生证明**，也从此引出韵书学的两门学问：今音学（《切韵》系）与近音学（《中原音韵》系）。
:::

::: theorem 五条定律（中古→北京音） {#rule-wutiao}
①**平分阴阳**：平声依声母清浊分家——清音平声归阴平（东、诗），浊音平声归阳平（同、时）。②**浊上变去**：全浊上声并入去声（伴、淡、近——凡“並定群从崇船”系上声字今读去声）。③**入派三声**（普通话格局）：全浊入归阳平（合、学、直），次浊入归去声（木、六、月），清音入散派无规律（一、八、出、北——死记硬背层）。④**全浊清化，平送仄不送**：并定群从崇船禅清化，平声变送气（同 tʰ-、步 pʰ-）、仄声变不送气（徒 t-、部 p-）——故普通话“抱/报”“洞/动”声母之差常是调类之差。⑤**见系细音腭化**（较晚，清代完成）：k/kʰ/x 在 -i/-ü 前变 j/q/x（京、溪、兴），与精组尖音合流为团音（“酒=九”），中原官话、胶辽官话部分保留尖团之别——**分辨尖团是方言地图上的等高线**。
:::

::: example 一字户政 {#ex-huizheng}
倒推“同”的演变履历（《广韵》徒红切），逐条列出触发的定律。
::: solution
户口：定母（全浊）、东韵一等、平声、通摄。①全浊清化＋平送：d-→tʰ-（触发②④之“平送”）；②平分阴阳：浊平→阳平。今音 tóng 一步不差。反向验算“洞”：徒弄切，定母去声——去声不受“平送”，仄声不送气→d-，今 dòng ✓。练到此，五律已通。
:::
:::

::: warning 定律使用三忌
一忌**拿定律教方言**：五条是北方官话（北京音系）的演化，粤语、闽语各有自己的合同（粤语保留九声六调、入声三尾，闽语文白两层并存——层次未剥离时“例外”成群，那是两层的叠印不是规律的破产）；二忌**忘掉文白异读**：“薄”báo（白）/bó（文）、“滴”dī/dì 之类是同一规律在不同层次的两次落款；三忌**单字硬推**：规律按**类**运作（全浊入**一类**字归阳平），查某字先定其《广韵》声母清浊与调类——先查户口再搬家，顺序不可反。
:::

::: quiz
“近”今读去声，触发的定律是（　）。
- [ ] 入派三声
- [x] 浊上变去
- [ ] 平分阴阳
- [ ] 全浊送气
::: solution
“近”全浊（群母）上声→去声，浊上变去的标准案例。
:::

::: quiz
入派三声后，声调最没有规律的一批是（　）。
- [ ] 全浊入
- [ ] 次浊入
- [x] 清音入
- [ ] 鼻音声母入
::: solution
全浊入归阳平、次浊入归去声皆有定规，唯清入散派四声，成为现代“记背层”。
:::

::: quiz
“酒”“九”今音无别，反映的历史音变是（　）。
- [ ] 浊音清化
- [x] 尖团合流（见系腭化与精组细音合流）
- [ ] 微母消失
- [ ] 阴声韵合并
::: solution
k-系细音颚化为 j 系（团音）、ts 系细音（尖音）跟进合流；保留分别的方言即“尖团不分”的反证。
:::

::: exercise 履历倒填 {level=1}
为“同、步、近、木、京”各填演变触发条（用五律编号）与今读。
::: solution
同：浊平→阳平＋平送 tʰ→tóng；步：並母去声（仄）不送→bù；近：浊上变去→jìn；木：次浊入归去→mù；京：见母细音腭化 k->j-＋清平→阴平→jīng（此字不涉入声，两律结算）。五条各对其号即满分。
:::
:::

::: exercise 例外审计 {level=2}
“白”bái 为全浊入（並母陌韵入声），按律归阳平——它确实读阳平！但“白”在“白事”里读 bó、在“明白”里读轻声 bai。请查证并写二百字审计：这是规律的例外，还是层次的叠印？
::: solution
审计结论示例：bái 合律（全浊入→阳平）；“明白”mangbai·bo 之类属词汇化轻声与又音保留（“白事”bó 为文读层残迹），是**层次**问题不是规律反例；能区分“规律层/词汇层/语体层”三层即达标——与[[phonology/why-phonology]]“例外即未解条件”呼应。
:::
:::

::: exercise 小论文：拼音输入法的音韵学 {level=3}
写八百至一千二百字：说明为什么一个会用拼音输入法的北京人，能在不知《切韵》的情况下“背诵”入派三声的多数结果——又从哪些字上必然翻车（举清入三字以上）。延伸一问：尖团合流在年轻 speaker 与方言区的回潮（“小壮”类“团音化”调查报道）说明规律的什么性质？要求含一张自制的“我的清入散派清单”。
::: solution
判分点：讲清“个体语言习得重演集体音变结果”（共时系统即千年史的最终快照，输入法键位是化石的操作层）；翻车清单真实可查（笔、必、北、黑、粥…清入四声皆有例）；尖团讨论落在“规律的共时权威 vs 方言变异”性质（允许引读调查，不许编数据）。
:::

::: summary
中古音到普通话是一场有合同的拆迁：平分阴阳、浊上变去两条铁律先行，入派三声安置入声侨民（清入无定向），全浊清化按“平送仄不送”改门牌，见系细音腭化最后收尾并合流尖团。《中原音韵》1324 年为这场拆迁录了口供；文白异读是两次施工的叠层，不是违约证据。会用输入法不等于懂音韵，但你每次打字都在投票——投给一千年里那几条从没输过的规律。
:::
:::
