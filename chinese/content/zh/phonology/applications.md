title: "音韵学的应用"
---

考试不考《切韵》，但背《切韵》的人处处得分。本课把前八章的器械开出五张处方：读诗、校书、解词、正音、教汉语——音韵学的“应用金融”现场。

## 处方一：读诗与格律 {#sec-shici}

::: example 失韵诊断出诊单 {#ex-shiyun}
诊断并给讲解口径：①杜牧“远上寒山石径斜，白云深处有人家”；②柳宗元“千山鸟飞绝，万径人踪灭”；③《诗经·芣苢》“采采芣苢，薄言采之。采采芣苢，薄言有之”。
::: solution
①麻韵二等（斜、家、花）——唐本押，今读 -ie/-ia 分途，讲解用“音变无瑕疵”口径（[[phonology/why-phonology]]）；②绝、灭、雪＝入声薛月类，普通话失塞尾但留 -üe 同痕，粤语 zit/mit/syut 全句铿锵——推荐课堂放一条粤读音频，胜过千言；③之、有之：之部与幽部**交韵**（每隔句换韵），《诗经》常格非出韵。三单各开一味药：音变、方音、诗体。
:::
:::

::: definition 平仄与今音的换算器
会用平仄三步：①**平声＝阴平＋阳平**（普通话读一二声者大半可当“平”候选）；②**上去入皆仄**——但去声里藏着**浊上变去**的仄字（“市、近、慢”本仄），阳平里藏着**入派阳平**的仄字（“竹、白、学”本仄）；③逢“一三五不论”处需检**入声字**清单（清入散派重灾区：笔、竹、屋、北、一、十、出……）。结论：**普通话读诗填词者，需要一张约三百字的入声速查表**——这正是音韵学给写作的最小可用交付。
:::

## 处方二、三：校书与解词 {#sec-jiaoshi}

::: example 因声求义医案 {#ex-qiumi}
古人注解里多有假借：“信”读为“伸”（《易·系辞》“屈信相感”），“早”多作“蚤”；旧时声训又有“德者，得也”“羊，祥也”。请用音韵学给声训分级，辨其可信与可疑。
::: solution
分级标准：双声（声同/近）、叠韵（韵同/近）、对转旁转（阴阳入相转）三级之内可信，出圈即伪。**信=伸**：同为书母真部，声韵全同，通假是合法支票；**蚤=早**：同为精母幽部，同音假借。反例警示：民俗吉祥话“酒=久、鹿=禄、蝠=福”类谐音，只取今音单轴之近、语义先行——声训的黄金律：**先过音，再谈义；音不够，说是“祈愿式联想”**（[[modern-vocabulary/lexicon-layers]]民间词源条同治）。
:::
:::

::: intuition 方言是免费的音韵学实验室
做一张自家方言—普通话对照表（50 字起手：古全浊平声字＋入声字＋见系细音字），你会发现：全浊平声在吴语保持浊音或送气分调、闽语把“猪、鱼”读如古无唇齿音的洪音、你的方言把“街、解”读 k- 系——**每一条个人语感都能在中古音账本上找到科目**。这就是为什么课堂练习总从“读你的母语”开始（[[phonology/why-phonology]]方言侦探题的正式版）：音韵学的归纳法从自己身上挖证据。
:::

::: history 从校勘记到汉语史：音韵学的学术就业史 {#sec-jiuye}
清儒以音韵治经（钱大昕“古无轻唇音”出于读史札记，非为音韵而音韵）；章太炎《文始》以声转系联词族（开汉语词源学之山，亦开“穿凿”之骂）；高本汉以后，音韵学与考古材料合流（甲骨金文考字常须问音：某字从某声、当读为某）；二十世纪子学新出土（马王堆、郭店、上博、清华简）几乎每批都有“以音韵通假读简”的名场面；今天，它受雇于：辞书审音（每处“又音”取舍都是历史语言学论文）、古诗词格律软件（校验器的背后是一张中古音数据库）、方言保护与语言政策（非遗曲本收音、拼音方案修订讨论）、国际汉语教学（偏误分析：“为什么”类问题的权威答案库）。
:::

::: warning 应用时的三种越权
①**拿通假当随便写错字**：通假有时代与抄写传统的约束，汉以后文人写“蚤”作“早”是仿古不是通假；②**拿构拟当普通话纠错执照**：以“存古”为名纠正他人读音（坚持“斜”必读 xiá 之类）而无规范依据，是社交自杀，审音表与教材才是现行法（[[modern-vocabulary/dictionaries]]两本账）；③**拿格律软件当诗学权威**：软件依平水韵或依新韵须先声明，用今音引擎判杜诗“出韵”者，是工具的反面教材。
:::

::: exercise 平仄体检 {level=1}
用三步换算法检查王之涣“白日依山尽，黄河入海流”的平仄（标注每字古今调类），指出哪里今平古仄。
::: solution
白（並母入声→阳平，古仄）、日（rì，入声仄）、依（平）、山（平）、尽（本上声、浊上变去今 jìn，古皆仄）、黄（平）、河（平）、入（rù，入声仄）、海（上声仄）、流（平）。今平而古仄者唯**白**字——五言“仄仄平平仄”句式中它占仄位，按今读判平即误；点出“白、入、尽”三字身份即达标。
:::
:::

::: exercise 简帛小医 {level=2}
简本与今本的关系，可能是同代通假，也可能是文本流传中的系统分化。开放题：请评断“通假说”与“文本异流说”各自需要什么证据。
::: solution
通假说需：同时代同地域“辩/便”互用例＋音理条件（二字声韵同源，具备入场资格）；异流传说需：抄本系统谱系（今本属哪一传本）＋思想史动机（黄老与儒家攻防下的改字）。评分看证据分级意识（音近只是入场券，抄本与文例才是主证），不要求定论。
:::
:::

::: exercise 小论文：音韵学的社会分工 {level=3}
写八百至一千二百字：从本课五张处方中选两张，分析其“专业门槛与公众参与”的张力——诗词圈的新老韵之争（中华新韵 vs 平水韵）、审音表的舆论战场各举一例。要求：给出你的方案（如：双轨制、分级标注），并用“规范与描写”框架（[[modern-vocabulary/dictionaries]]）收束。
::: solution
判分点：冲突描述准确（《中华新韵》推广与诗词界拉锯、2016 审音草案风波——各写一桩即可）；方案有边界意识（谁在什么场合依哪套——语域分治是常见解）；收束落到“词典/规范/学术”三本账不串票。和稀泥者（“都行”）不得分。
:::

::: summary
音韵学的五张处方：读诗（失韵诊断＋入声速查表）、填词（今音平仄三步换算）、校书（通假的时代执照）、解词（声训先过音轴）、正音与教学（偏误权威答案库＋方言自证）。学术就业史证明它从没离开现场：清儒札记、简帛释读、辞书审音、格律引擎。应用的第一美德是**分账**：古音与今读、规范与描写、学术与审美——各回各家，各找各妈；串票的时刻，就是音韵学重新变成“绝学”的时刻。课程至此结业，愿你的语感从此有了档案馆。
:::
