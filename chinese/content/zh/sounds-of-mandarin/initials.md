“的、哥、可”三个字，外国人要先学会三件事才能读对：它们是清音，它们不送气或很送气，它们的舌根碰的是软腭。这三条信息恰好是任何一本普通话教材都默认你“天生会”的东西——因为你是母语者，你的耳朵早在会说话之前就把这套系统装好了。本章的任务是把装好的东西拆开来看：普通话的 21 个声母（外加“零声母”），每个发音动作的两条坐标——部位与方法，以及这两条坐标为什么偏偏是这几样。学完这一章，你应该能对任一声母报出它的“档案”（如 ch：舌尖后、送气、清、塞擦音），能在听不出差别时说出自己在丢哪条特征，也能把你方言里的声母与这张表一一对齐。

## 声母是什么

::: definition 声母 {#def-shengmu}
汉语音节传统的三分法是声母、韵母、声调：音节开头的那个音（或音群的位置）是**声母**，其后到音节末了的部分是韵母，全音节带上音高轮廓是声调。普通话有 21 个声母：b、p、m、f、d、t、n、l、g、k、h、j、q、x、zh、ch、sh、r、z、c、s，全部由辅音充当；另外承认一种“没有辅音”的开头，称为**零声母**。
:::

::: definition 零声母 {#def-lingshengmu}
韵母直接位于音节开头的状况。如“安 an”“欧 ou”“一 yi”“五 wu”四个音节，开头没有辅音，声母位置是空的，这个空位记作零声母。拼音以 y、w 起头书写它（i、u、ü 起头的零声母音节改写作 yi、wu、yu 等，详见[[sounds-of-mandarin/syllables-pinyin]]），但 y、w **不是**两个声母：它们是字母层面的拼写装置，不是发音上的新单位。
:::

::: note 辨析：声母与辅音 {#note-shengmu-fuyin}
声母是汉语传统的**结构**概念（音节开头的成分），辅音是语音学的**发音**概念（气流明显受阻的音，见[[sounds-of-mandarin/speech-sounds#def-fuyin-yuanyin]]），两者不是一回事：普通话的辅音约 22 个，声母只收 21 个——ŋ（“英”的韵尾）是辅音却不作声母；反过来，声母之外的辅音 -n、-ng 站在韵尾的位置上。一个概念问“它在音节的哪一格”，另一个问“口腔里发生了什么”。方言调查里两类问题常常同时出现，分开问才不乱。
:::

::: quiz
下列音节的开头，**带有辅音声母**的是哪一项？
- [ ] 安 ān
- [x] 堆 duī
- [ ] 鹅 é
- [ ] 羊 yáng
::: solution
“堆”的声母是 d，舌尖中、不送气、清塞音 [t]。其余三项开头都没有辅音：“安、鹅”是零声母的开口呼例子，“羊”以 y 起头，属拼写装置，声母位置是空的。留意“歪、娃、野”一类也会招疑问：它们同样写 y、w，同样零声母——凡 y、w 起头的音节都不带辅音声母，y、w 是拼音正字法，不是发音事实。
:::
:::

## 第一条坐标：发音部位

发音部位是成阻的地点：气流从肺出来，在喉以上的哪一段被捏住、挤窄或封死。部位的名目各家稍有出入，本课程随黄廖本分七处，从前到后是：

::: definition 普通话声母的发音部位（黄廖本七分） {#def-buwei}
**双唇音** b、p、m——上下唇成阻；**唇齿音** f——下唇抵上齿；**舌尖前音** z、c、s——舌尖抵或近上齿背（俗称平舌音）；**舌尖中音** d、t、n、l——舌尖抵上齿龈；**舌尖后音** zh、ch、sh、r——舌尖上抬抵或近硬腭前部（俗称翘舌音）；**舌面音** j、q、x——舌面前部抵或近硬腭；**舌根音** g、k、h——舌根抵或近软腭。有的教材把舌尖前、舌尖中合为一类而称六分；胡裕树本等又用“舌面前、舌面后”之名代替“舌面、舌根”。名目不同，口腔里的位置一样——报档案时先报口径，再报结论。
:::

每处都请你自己试一遍：发“巴”，双唇先合后开；发“佛”，下唇碰上门齿，注意不是上下唇互碰，也不是上齿咬住下唇用力（那是咬唇的 [v] 方向，老派“沪味”普通话常被笑的地方）；发“资”，舌尖平伸抵住上齿背，顶不到齿龈；发“知”，舌头上卷，舌尖够到硬腭前部——这个“翘”不是可选项，zh ch sh r 的听感八成来自够到哪儿；发“得”，舌尖平平地抵上齿龈，恰在“资”“知”两站之间；发“基”，舌面前贴硬腭，舌尖反而垂在下齿后；发“哥”，舌根抬起碰软腭，咽喉后壁都跟着紧。

两个部位最容易混。其一是**舌尖前与舌尖后**（z c s 与 zh ch sh r）：除窄缝的位置前后差一两厘米，频谱上的噪声中心就移了一大截，所以方言里“四、十”之辨全凭这一抬。其二是**舌面与舌尖后**（j q x 与 zh ch sh）：硬腭上两个相邻的坝段，听感接近，却各自有严格的搭配限制——j、q、x 只跟 i、ü 开头的韵母（“基、居”），zh、ch、sh 不跟 i、ü 齐齿、撮口呼拼（“猪”的韵母是 u 不是 ü，把“去、居”发成翘舌便是著名的“尖音”，见[[sounds-of-mandarin/finals]]与[[history-of-chinese/modern-standard]]）。

## 第二条坐标：发音方法

发音部位说“在哪儿堵”，发音方法说“怎么堵”。四个问题依次问：

1. **怎么成阻**：完全封死再放开是**塞音**（b p d t g k）；封死后留缝挤出是**塞擦音**（z c zh ch j q）；一直不封死只留窄缝是**擦音**（f s sh r x h）；口腔封死、软腭下垂放鼻腔是**鼻音**（m n ŋ）；口腔中路留两边、舌尖轻抵是**边音**（l）。
2. **声带颤不颤**：颤是**浊音**，不颤是**清音**。普通话声母里浊音只有 m、n、l、r 四个，其余十七个全是清音。
3. **气流强弱**（对塞音、塞擦音而言）：除阻后有明显的一段送气（h 噪声）是**送气音**，没有是不送气音。普通话有五对：b/p、d/t、g/k、z/c、zh/ch（外加 j/q，共六对，说“五对”时把 j/q 并进塞擦组数）。
4. **气流出路**：走嘴是口音，走鼻是鼻音——上面第 1 条已含。

::: theorem 普通话塞音塞擦音的辨义特征是送气，不是清浊 {#rule-songqi}
普通话的 b p、d t、g k、z c、zh ch、j q 各组之内，区别意义的特征是**送气与否**：p t k c ch q 送气，b d g z zh j 不送气。两组声带都不颤，全是清音；浊音这一维度在声母上不参与辨义。
:::

::: proof 为什么断定 b d g 不是浊音
三条证据。其一，仪器可查：浊塞音的特征是除阻前声带已在振动（嗓音起始时间 VOT 为负或近零），测普通话“八”的声母，除阻与声带振动之间隔着一小段静默或噪声，是清音的格局；英语词首的 b 才带前置浊音。其二，母语者“听不见”这个维度：把“八”发成带嗓的 [b]，普通话母语者只觉得“有点洋腔/河南腔”，不会以为换了字——若浊音成位，他必然能分辨。其三，历史的回声：古代汉语的全浊声母（并、定、群、从、澄、邪等）在北方话里清化了，今北方方言“平声送气、仄声不送”的分派（同→tóng、洞→dòng）正是那次清化的化石——浊音丢了，送气没丢，可见系统在“送气”与“浊否”之间选了前者。顺带记一句跨语言的教训：韩国语、吴语的学生常把普通话 b、p 都当清音听（他们分别用“松音/送气”维度），英语、法语、吴语的学生把 b、p 听成清浊（他们有浊音维度）——档案没错，各自的耳朵偏科不同。
:::

::: example 给 chàng 建档 {#ex-jianlang-chang}
给出“唱”chàng 声母的完整发音描述，并解释方法一条为什么“塞擦”而不是“塞”或“擦”。
::: solution
舌尖后、送气、清、塞擦音。说它“塞擦”：成阻阶段舌尖与硬腭前完全封死（如塞），然后不猛地放开，而是退出一条窄缝挤气摩擦（如擦）——同一成阻“先塞后擦”，故称塞擦。“唱”的声母 ch 与“唱”的韵母 -ang 无干，本建档只记声母；连调值全写是 [tʂʰaŋ⁵¹]。自查题：把“唱”拖长唱出来——拖住的是擦的段落（[tʂʰ] 的摩擦段可以拖，塞的段落拖不了），这也是听辨塞擦与纯擦音 r [ʐ] 的窍门。
:::
:::

::: example 给 ràng 建档 {#ex-jianlang-rang}
“让”ràng 的声母 r，各家记音不同：[ʐ]、[ʐ̞]、[ɻ]。你在课堂上该用哪个？
::: solution
本课程随黄廖本记 [ʐ]：浊、舌尖后、擦音（有的教材写作近音 [ɻ]，因为实际摩擦常常很轻）。档案的其余部分没有分歧：部位在舌尖后（同 zh ch sh），浊音——r 是普通话声母里唯一的擦音浊音。方言里 r 的“变读”（南京话“人”读 [l-]、济南话读零声母带 [ɻ] 起头、不少南方方言读 [z] 或 [j]）正因为它在普通话音系里既浊又是擦音、独来独往，历史来源却来自几处，见[[dialects/mandarin-dialects]]。
:::
:::

## 零声母音节实际开口时是什么

说零声母“没有辅音”，说的是系统里空着；实际开口的一瞬，口腔不会真空。“安”起头常带一点喉塞 [ʔ]；“一”的开头是舌面前高元音向音位 [i] 滑动的过程，有的教材给滑音符号记 [j] 起头；“五”“乌”类带圆唇滑动 [w]。这些都是语音学的细描（见[[sounds-of-mandarin/speech-sounds#def-yinwei]]的分层），音系层面它们都不是音位。拼音的 y、w 写法恰是给这类音节“找齐开头”的：i 行韵母自成音节写作 yi、ya、ye，u 行写作 wu、wa、wo，ü 行写作 yu、yue（ü 上两点省略，因为 y 后不会有 ü 以外的冲突）。规则的细节在[[sounds-of-mandarin/syllables-pinyin]]展开。

::: example “乌鸦”与“鸭” {#ex-wuya}
“乌鸦 wūyā”两个音节都是零声母吗？为什么“鸭 yā”的 y 不是声母，而“牙 yá”的 y 也不是？
::: solution
都是零声母：“乌”[u⁵⁵] 以合口滑动起头，“鸦”[ia⁵⁵] 以齐齿滑动起头。拼音规则：无声母、韵母是 i 开头者写作 y 加韵母（ia→ya），u 自成音节写作 wu——y、w 是“写出来”的，不是“多出来一个辅音”。检验法在系统层：任何普通话母语者都不能把 y 与别的声母对立出词来（没有“ia”与“ya”两个不同音），它就只是拼写。有趣的是口语里“呀 ya”常带很实的腭部摩擦，语流快了又像真辅音——系统空着，嘴上不空，这一句把上一章“社会/物理两层”再验证了一遍。
:::
:::

## 练耳朵：对与不对的声母

把混淆对摆在韵母调值相同的条件下听，是本章的“实验课”。“四 sì”与“是 shì”差部位（舌尖前对舌尖后）；“错 cuò”与“绰 chuò”同为送气塞擦，也差平翘；“粗 cū”与“出 chū”一边塞擦一边擦音、部位又不同，要拆成两步听；“老 lǎo”与“脑 nǎo”差通路（气流走口腔两侧还是走鼻腔）；“鱼 yú”与“驴 lú”差零声母与声母，顺带检验撮口元音。绕口令“四是四，十是十”练的不是嘴皮，是舌位控制与听觉反馈的连接。方言者纠偏的第一步永远是**听辨**：n/l 不分的人要先能分，才谈得上会说——怎么听、怎么录、怎么记，[[sounds-of-mandarin/dialect-differences]]和[[dialects/fieldwork]]各给一半办法。

::: history
汉语给声母分类的传统比现代语音学早了一千年。唐末守温三十字母（敦煌文献所出）已经按“唇、舌、牙、齿、喉”五音配“清浊”为声母排序，宋代扩为三十六字母（见溪群疑、端透定泥、知彻澄娘、帮滂並明、精清从心邪、照穿床审禅、来日、影喻晓匣），等韵图的横行就是这张表。今天教科书的双唇/唇齿/舌尖/舌面/舌根五分，是对“五音”的精密化；“平翘”“尖团”这些旧名仍活在方言研究和戏曲行当里。1918 年注音字母公布，b p m f 念作“玻、坡、摸、佛”，是为声母教学而造的呼读音——字母名不是音值（ㄅ 并不读“玻”的音，只是好教）；1958 年汉语拼音方案沿用这套呼读音，只是换了一串拉丁字母。
:::

## 后续内容

声母只是音节的一半。韵母的四呼与结构在[[sounds-of-mandarin/finals]]，两者拼合成的音节表与拼音正词在[[sounds-of-mandarin/syllables-pinyin]]；声母的历史层次（帮滂並明如何变成今天的 b p m f 与各地方音）是[[phonology/mc-initials]]的课程内容；本章反复用到的“送气/浊音”维度在方言里的不同选择，看[[dialects/wu]]与[[dialects/mandarin-dialects]]。下一节复习题里将出现你家乡话的名字——把它写进表里，这一章才算学完。

::: summary
- 声母是音节开头的成分，普通话 21 个，全由辅音充当；零声母是结构空位，不是“省略了某个辅音”。
- 两条坐标定位一切声母：发音部位（双唇、唇齿、舌尖前、舌尖中、舌尖后、舌面、舌根——黄廖本七分；六分说请核对教材）与发音方法（塞、鼻、擦、塞擦、边；清浊；送气与否）。
- 普通话塞音、塞擦音以**送气**辨义，b d g z zh j 是清不送气音，不是浊音；浊声母只有 m n l r。
- 尖团、平翘的限制是韵母配合问题，但听感差异生在部位上；纠偏先纠耳。
- 声母与辅音、呼读音与音值、零声母的“系统空位”与“实际起音”是三组必须分清的分层。
:::

## 习题

::: exercise 数浊音 {level=1 check="4"}
普通话 21 个声母中，浊声母一共有几个？
::: solution
4 个：m、n、l、r。其余 17 个都是清音。ŋ 虽是浊鼻辅音，但不作声母，不在此列。
:::
:::

::: exercise 数部位 {level=1 check="6"}
在“六分部位”的说法下（不另立舌尖中，d t n l 归入舌尖），普通话声母的发音部位共有几处？
::: solution
6 处：双唇、唇齿、舌尖（含 d t n l 与 z c s）、舌尖后、舌面、舌根。黄廖本七分（舌尖单列），本课程正文用七分表，本题按六分问——这类数目分歧都是归类口径，不是事实分歧，答卷时先声明口径。
:::
:::

::: exercise 五个音的档案 {level=1}
给下列声母逐条建档（部位＋方法，含清浊、送气与否）：f、q、s、zh、n。
::: solution
f：唇齿、清、擦音。q：舌面、送气、清、塞擦音 [tɕʰ]。s：舌尖前、清、擦音。zh：舌尖后、不送气、清、塞擦音 [tʂ]。n：舌尖中、浊、鼻音。建档要求说全：部位、成阻方式、清浊、送气与否，缺项即算未建完。
:::
:::

::: exercise 听辨配对 {level=2}
为下列每组字找出“声母之差”落在哪条特征上：（1）粗 cū／苏 sū；（2）招 zhāo／交 jiāo；（3）班 bān／攀 pān；（4）兰 lán／南 nán。
::: solution
（1）c [tsʰ]／s [s]：同为舌尖前清音，塞擦与擦的方法之别（成阻有无完全封死阶段）。（2）zh [tʂ]／j [tɕ]：同为不送气清塞擦，部位之别（舌尖后对舌面）。（3）b [p]／p [pʰ]：同部位同方法，送气与否。（4）l／n：同为舌尖中浊音，边音对鼻音，通路之别（气走口腔两侧还是鼻腔）。
:::
:::

::: exercise 三条证据 {level=2}
“妈 m、飞 f、喝 h 是浊音”这句话对哪个字才成立？对其余两个字，分别用什么身体证据和仪器证据驳回？
::: solution
这句话只对“妈”成立：m 是浊鼻音，成阻段里声带始终振动。f、h 都是清擦音，声带不颤：身体证据是手按喉部拖长发“佛——”“喝——”，喉头没有振动；仪器证据是语图上擦音段不见低频的嗓音横杠（m 的鼻音段则有）。21 个声母里以“颤不颤”立得住的浊音，只有 m、n、l、r 四个。
:::
:::

::: exercise 纠一个洋腔 {level=2}
你的英语朋友说汉语，“弟弟”像“提提”、“哥哥”像“科科”。用音位理论解释：他到底哪一条特征没学？为什么他自己的语言里“没有”这条特征？
::: solution
他把普通话“不送气清塞音 vs 送气清塞音”的对立，听成了英语“浊 vs 清”的对立：在他耳朵里 d 对 *did* 的 [d]、t 对 *top* 的 [tʰ]，于是“弟、提”都读得像英语的送气/浊音。他没学的是**送气**这条辨义特征在汉语的成位地位——英语里送气不成位（*spin*、*pin* 同位变体），母语系统从未要求他区分“送气不送气”而要求他区分“浊不浊”，两个系统在同一维物理量上切了不同的刀。纠偏顺序：先练听（把 b p 与 d t g k 六对摆成听辨表），再练发（纸条放嘴前看气流），最后成词成句。
:::
:::

::: exercise 转写六个声母 {level=2}
把“非、知、才、西、日、五”的声母改写成方括号里的音值（零声母请标明），每个音补一句发音描述。
::: solution
非 [f] 唇齿清擦；知 [tʂ] 舌尖后不送气清塞擦；才 [tsʰ] 舌尖前送气清塞擦；西 [s] 舌尖前清擦；日 [ʐ] 舌尖后浊擦（记 [ɻ] 亦可，说明你的系统）；五 [u] 零声母（起头圆唇滑动，系统层无辅音）。转写用音位还是音值取决于你要谈什么，见[[sounds-of-mandarin/speech-sounds#def-yinwei]]。
:::
:::

::: exercise 给“玻坡摸佛”挑错 {level=3}
有人说：“b 的读音就是‘玻’，所以玻 [po] 才是声母的音值。”用呼读音、音值、音位三层，分条指出这句话混了什么、不错的是什么。
::: solution
不错的是：课堂上 b 确实念“玻”——这是呼读音，为了称呼字母、便于拼读而给声母配的“带元音的读法”，教材明言它不是音值。混掉的是两层：（1）音值上 b 是清不送气双唇塞音 [p]，[po] 多了一个央元音尾巴；（2）音位上 b 是 /p/ 这个单位，与 /pʰ/（“坡”）对立——呼读音若读成 [pʰo] 就成了另一个音位。结论：把“玻坡摸佛”当注音用没事，当音标用全错。扩展题：为什么呼读音普遍要配一个元音？（纯辅音除阻后无持续段，拖不长、叫不应。）
:::
:::

::: exercise 家乡话对照表 {level=3}
列一张你家乡话（或你熟悉的方言点）与普通话的声母对照表：只列“对不上”的行（合并、多出、读法不同），每行给两个例字，并标注哪些行会造成普通话的“方音”。不知道怎么写，可先读[[dialects/mandarin-dialects]]的常见对应，或按[[dialects/fieldwork]]的办法自己记两张单字表。
::: hint
先处理三组最常见的：平翘（z c s／zh ch sh r）、n l、f h；再查吴语区的浊音、闽语区的“轻唇归重唇”、客家区的 f h；最后看零声母音节前多出的 [ŋ]、[n] 或鼻化起头。
:::
::: solution
合格的答案形如：“平水话：普通话 n／l 合流为 [l]（“南北”同音，都读 [l-] 起头）；普通话 hu- 多读 f-（“湖”读 [fu]）；多出浊塞音 b d g（“大”声母带嗓）。三行中前两行直接造成方音，第三行是方言特征、学说普通话时转成清不送气。”评分看：对应是否可复核（例字音值要能标出来）、是否只谈系统不谈优劣（见[[sounds-of-mandarin/dialect-differences]]的规范）、有没有把自己方言的音位与音值混标（[l] 还是 /l/？）。
:::
