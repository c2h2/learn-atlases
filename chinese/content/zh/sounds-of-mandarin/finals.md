“姐、略、全、冬”四个常用字，拼音分别是 jie、lue、quan、dong——四个韵母的“写法”与实际元音之间，处处都有故事：jie 里的 e 其实念 ê［ɛ］，lue 的 üe 藏着一个不点两点的 ü，quan 的 u 是撮口而非合口，dong 的 o 干脆就是 u 的变脸。韵母是音节里信息最多的一块：它带着介音说明声母能不能配，带着主元音说明声音亮不亮，带着韵尾说明诗能不能押。这一章给韵母建立三层档案——结构、类别、四呼——并且分清两件常被混为一谈的东西：**韵母**（音节的成分）与**韵**（诗律的单位）。

## 韵母的结构：头、腹、尾

::: definition 韵母与韵头、韵腹、韵尾 {#def-yunmu}
声母之后、连同声调之前的部分都是**韵母**。韵母最多三层：**韵头**（介音，只能是 i、u、ü 之一，站在最前）、**韵腹**（主要元音，音最强、最长的一个，缺一不可）、**韵尾**（收束的部分，可以是元音 i、u，也可以是鼻辅音 n、ng）。如“严 yán”［iɛn］：韵头 i、韵腹 ê、韵尾 n；“哥 gē”［kɤ］只有韵腹；“太 tài”［tʰai］韵腹 a、韵尾 i。
:::

韵腹是必有的，韵头、韵尾看具体韵母。术语上把“元音韵尾”与“辅音韵尾”分开谈：普通话的元音韵尾只有 i、u 两个（ao 写的 o，舌位其实朝 u 走），辅音韵尾只有 n、ng 两个——尾音的库存比声母小得多，这正是汉语音节“开得多、收得窄”的面目。历史层里入声的 -p、-t、-k 韵尾在北方话消亡的故事，见[[history-of-chinese/middle-chinese-language]]。

::: example 给“关 guān”拆结构 {#ex-guan}
分析“关”的韵母，并说明它在四呼里属哪一类。
::: solution
韵母 uan：韵头 u（合口介音），韵腹 a，韵尾 n（舌尖前鼻音，收尾时舌尖抵齿龈——与 ng 的舌根成阻对照着发就能分开）。带 u 介音，故属合口呼。拆结构的检验动作：把音节拖长，“前快后亮尾短”——先略过 u（介音轻而快），音落在 a 上（韵腹），最后舌尖一抬结束（韵尾 n）。会“拖”就会拆。
:::
:::

## 三十九个韵母的账目

随黄廖本，普通话韵母共 39 个，按结构分三组：

1. **单韵母** 10 个：a、o、e、ê、i、u、ü、er、-i［ɿ］、-i［ʅ］。后两个是上一章的舌尖元音（各随 z、c、s 与 zh、ch、sh、r 出现）；ê 单用只在感叹“欸”，主要出现在 ie、üe 里充当韵腹；er 是一个音位性的“卷舌动作＋中央元音”，只作个别字的整个韵母（儿、耳、二），又是儿化的来源（见[[sounds-of-mandarin/sandhi]]）。
2. **复韵母** 13 个：ai、ei、ao、ou、ia、ie、ua、uo、üe、iao、iou、uai、uei。复韵母按“亮音在哪个位置”再分三种：ai、ei、ao、ou 以主要元音起头、向韵尾滑动，响亮段在前，称**前响**；ia、ie、ua、uo、üe 以介音起头、亮音在后，称**后响**；iao、iou、uai、uei 是“介音＋前响”的叠加，两头轻中间亮再收向韵尾，称**中响**。三种的分野用一根手指就能检验：拖长发音，下颌张开最大的那一瞬出现在开头、中间还是后段。前响的韵尾轻而短，[i]、[u] 只剩方向；后响的韵头同样轻，主元音扛住全音节的音量。
3. **鼻韵母** 16 个：以 -n 收尾的 8 个——an、ian、uan、üan、en、in、uen、ün；以 -ng 收尾的 8 个——ang、iang、uang、ueng、eng、ing、ong、iong。

三组之和 10＋13＋16＝39。数目随教材会有出入：有人把 -i［ɿ］、-i［ʅ］ 从单韵母账上划掉（说它们是“协和元音”不算独立韵母），有人把 er 单列“特殊韵母”，于是见 37、38 诸说；黄廖本 39 是最通行的账。记数目不在背，在账清：每个韵母要么在单里、要么在复里、要么在鼻里，一个不漏；方言里多出的元音（晋语一些点的〔ʅ〕自成音节、吴语的紧喉短元音）、少掉的（多数西南官话只剩 i、u 两呼，撮口并入齐齿或合口：“去”读近“气”、“出”读粗化），一对照就现形。

用这张账背表，比从任何一角横背都牢的办法是“坐标定位”：给一个韵母，先问结构（单？带什么尾？），再问四呼（哪门介音），两句户口对上，它就在图上只剩一格。同学互考最见效的题型是“我说口型你报音”——一人撮口发 ü，另一人要在 i、ü、u、ê 里报出唯一解，再互对“户口”。韵母表的熟练度，直接决定后面学格律（平仄押韵）、学方言（单元音对应）、学音韵（摄韵归并）三件事的速度，值得在这一章多花两个晚自习。

::: example iou 的“吞音”不是吞音 {#ex-iou}
“牛 niú、六 liù、秋 qiū”的韵母是 iou，写作 iu；“归 guī”的韵母是 uei，写作 ui。是口语吞了 o、e，还是拼音省了？
::: solution
拼写省（iou→iu、uei→ui、uen→un，限声母之后），口语不省：慢读“牛”分明先 i 后 o 再 u；只在语流快、声调轻时才弱化得近乎［niəu］→［niə］。因此分析层面“iu”是两个音位 i、u 加一个不写出来的韵腹——音系论里 iou 的归并正有分歧（有的分析把 ou 视作韵腹＋韵尾，韵腹 o 是音位 /o/ 的音位变体），我们的结构分析按拼写本相“韵头 i＋韵腹 o＋韵尾 u”处理。记住两条：省写有语音条件（声母之后才省，零声母写 you、wei、wen），标调有补救（“流 liú”调号落在 u，正是按省后写法就近落）。
:::
:::

## 为什么“ong、ing”的拼写各藏一件事

::: definition 拼写与音值的三处错位 {#def-yunmu-pinyin}
鼻韵母的拼写里有三处“字母搬家”：（1）iong 的韵腹是撮口的 ü 类音，拼写记作 iong（实际音近［yŋ］，起头带唇圆）；（2）ong、iong 的“o”不读“喔”，它的舌位近 u：冬 dōng 的韵母音值近［ʊŋ］，即“u 的 ng 韵”；（3）ing、eng 的 e、i 在快读中弱化，［iŋ］［əŋ］里的中央元音短而含糊。凡此种种，都是《汉语拼音方案》为系统整齐与拼式简短做的安排——**方案是音位原则与实用折衷的产物，不是语音的实录**（详[[sounds-of-mandarin/syllables-pinyin]]）。
:::

::: example “东、英、雍”建档 {#ex-dong-ying-yong}
写出“东 dōng、英 yīng、雍 yōng”三字的韵母结构，并标出各自拼写里的“机关”。
::: solution
东：韵母 ong，结构上是“［u］的韵腹＋ng 韵尾”，拼写作 o 是方案的字母安排；零声母字写 dong。英：韵母 ing＝韵头 i＋ng 尾（韵腹弱化），零声母写 ying，y 是书写装置。雍：韵母 iong，实际音近［yŋ］，零声母写 yong，撮口的 ü 在 y 后不加点；把它分析为“韵头 ü＋ng 尾”最合发音。三字连读，正是普通话后响鼻韵“单元音化”的三条平行线——字母各异，口腔各司其职。
:::
:::

::: note 辨析：o 与 uo {#note-o-uo}
o 与 uo 主元音同一来源，站位互补：o 只出现在双唇音、唇齿音之后（波 bo、坡 po、摸 mo、佛 fo），uo 出现在其余声母之后（多 duo、郭 guo、窝 wo〔零声母〕）。有的教材据此把二者判为同一音位的条件变体，教学语法则常算两个韵母——本课程按 39 账算两个，同时记住“b o 里的 o 并不饱满，慢听近乎〔uɔ〕”的记音分歧，两种口径都见于名家之手。考试按课本，调查按嘴巴。
:::

::: warning 韵母“有 i 有 u”不等于“头腹尾齐全”
✗“bi”拆成 b＋i 就非说有韵头；✗“ben”里 e 看不见就是“无韵腹”。✓ 只有 i、u、ü 出现在**介音位置**时才是韵头：“边 biān”是韵头 i＋韵腹 a＋韵尾 n；“逼 bī”［pi］只有韵腹。韵腹永远在——找不到“a、o、e”字样不等于没有主元音：ben 的 e 是韵腹，bing 的 i 兼作韵腹（ing 的元音性有归并分歧，随教材声明）。判断永远回到两点：谁是拖长时最响的那个（韵腹），它前面有没有轻快的 i、u、ü（韵头）。
:::

::: quiz

::: quiz

- [x] 韵头

::: remark 字母名与音值
课堂呼读元音字母：a“啊”、o“喔”、e“鹅”、i“衣”、u“乌”、ü“迂”——都是拿一个零声母音节给字母起的名，方便称说，不等于音值记录（o 呼“喔”[ɔ]，而“波”里的 o 又近 [uɔ]）。这与声母的呼读音“玻坡摸佛”是同一种教学设计：方案自己声明过，字母的名字和字母在拼式里的值，是两回事。凡遇“字母怎么读”的争论，先分清问的是名字还是值。
:::

## 四呼：按介音给韵母分户

::: definition 四呼 {#def-sihu}
按韵头的有无与属性分四档：**开口呼**——无韵头且韵腹不是 i、u、ü（a、ai、an、ang、e、ei、en、eng、o、ong、er、-i［ɿ］、-i［ʅ］）；**齐齿呼**——韵头或韵腹是 i（i、ia、ie、iao、iou、ian、iang、ing 等）；**合口呼**——韵头或韵腹是 u（u、ua、uo、uai、uei、uan、uen、uang、ueng、ong）；**撮口呼**——韵头或韵腹是 ü（ü、üe、üan、ün、iong）。四呼之名来自等韵学，清代由“开合”两呼细分为四呼，沿用至今。
:::

::: definition 元音的三条发音特征 {#def-yuanyin-tezheng}
元音由三样口腔状态决定：舌位**前后**（i 前、u 后、a 央偏后）、舌位**高低**（i、u 闭，a 开，e、ê 居中）、唇形**圆展**（u、ü 圆，i 展）。由此可给单元音“定位”：i 是舌面前高展唇元音，ü 只比 i 多一分圆唇，u 比 ü 退后且舌位更高——“姐、举、居”三音的辨析全在这三格之间。元音 chart 的“梯形”就是这三条特征的两向投影（前—后、高—低），自己画一张，十个单韵母各就各位。
:::

::: example “鱼”与“五”{#ex-yu-wu}
方言学员总把“鱼 yú”念成“无 wú”。用[[#def-yuanyin-tezheng]]开一张处方。
::: solution
两音的韵腹只差一条特征：ü 是舌面前高圆唇元音，u 是舌面后高圆唇元音——前后之别，圆唇相同。处方分三步：①先发 i（舌位前、高、展唇），保持舌位不动，只把双唇拢圆——出来的必是 ü；②对照发 u，体会舌位后退、会撮的差别；③最小对立练习“鱼—无、学—活、月—袜”，先听辨后跟读，慢速成对，再入语流。西南官话区此合并最常见（“去”读近“裤”），纠“ü 读 u”先纠“撮口”这个动作本身——许多话里唇不圆、舌不前的“ü”其实滑向了 i。
:::
:::

::: application 韵母的“功夫”：播音与演唱里的头、腹、尾
传统曲艺讲“字正腔圆”，诀窍恰在本章的三分法：字头（声母）要“叼住即弹”，字腹要拉开立稳，字尾要“归音到位”——唱“光 guāng”，腔圆在 a 的延长，韵尾 ng 必须收得住，否则“光”滑成“瓜”；朗诵“安 ān”同理，舌尖不抵齿龈，字音就“散”。播音训练的“叼、开、收”三字诀，就是韵头、韵腹、韵尾的表演说明书。学结构不是为做题：你从此知道“腔圆”圆在哪个音段、“归韵”归到哪个动作。
:::

四呼不只是分类癖。它与声母的配合规矩咬合得最紧：**舌尖前 z、c、s、舌尖后 zh、ch、sh、r、舌根 g、k、h 只拼开口、合口，不拼齐齿、撮口**（“资”的 i 是舌尖元音 -i［ɿ］，算开口）；**舌面 j、q、x 只拼齐齿、撮口**（“基、居”），与上一组恰好互补；**双唇 b、p、m 与唇齿 f 不拼 u 介音的合口呼**（f 拼 ua 的“花”方言里才有——“无锡人把‘花’念‘fā’”之类的方音即源于合口限制）。规则细节到[[sounds-of-mandarin/syllables-pinyin]]用音节表全验，此处先立四呼的户口：见一个音节，先查它是哪一呼，声母可以配谁立刻缩小范围。配合规律也有“例外”的假象：有人举“翁 wēng、嗡 wēng”说 f、w 拼合口——其实“翁”是零声母的 ueng，“嗡”是 ong 的又读，都与唇音无干；又有人拿“否 fǒu、某 mǒu”说唇音拼ou——ou 是开口呼，不违例。查例外的正确动作是把字的四呼户口查实，再对表：八成“例外”死在自己报错的户口上。

::: example “雪 xuě”到底几层 {#ex-xue}
分析“雪”的韵母，回答四问：韵头是什么？韵腹是什么？拼写里谁被省略了？四呼属哪类？
::: solution
韵母 üe：韵头 ü；韵腹是 ê［ɛ］——拼写用字母 e 充当（ie、üe 同此，正如 def-yunmu 的“严”字）；被“省略”的是 ü 上两点（ü 列 j、q、x、y 之后去点的拼写规则）；有 ü 介音，属撮口呼。检验动程：从撮口滑向半开，双唇由圆到展，下颌下落——“雪”的“好听”正在这一步由闭到开的动程里。
:::

## 韵与韵母：两套系统的分工 {#sec-yun-yunmu}

“韵”是诗律单位：传统押韵只问韵腹、韵尾是否同部，不论四呼；平仄另是一层规矩（近体诗押平声韵，词可以换韵）。“关 uan”与“山 an”韵母不同（一有 u 介音，一无），按今音押韵却同收 -n、主元音相近，算得一路；在平水韵，“家 ia”与“麻 a”同属麻韵，“回 uei”与“雷 ei”韵母不同却同属灰韵。与“韵”相对的老术语还有“双声”：声母相同谓之双声（“参差”“踌躇”），“叠韵”则韵同（“窈窕”“彷徨”）——连绵词的声音之美，古人用双声叠韵四个字就点破了，其现代翻译正是声母系统与韵母系统。押韵的宽严随文体而变：古体宽、近体严、曲韵另是一部书——引用“某字与某字同韵”，先说清用的是哪部韵书。本图谱说到“平水韵”时以《佩文诗韵》一系为准，见[[poetry-metrics/rhyme]]。

::: history
“韵”的分析在中国有二千年积累：《切韵》一系分韵从一百九十余类到《平水韵》一百六部，是诗赋用韵的官尺；等韵图把声母列行、韵字列格，开齐合撮“四呼”之名到清代潘耒《类音》已讲得眉目分明。1920 年代“韵母”进入现代教学语言，马叙伦、黎锦熙诸家各有界说，今黄廖本的“韵头—韵腹—韵尾”三分已成通说。传统今说之间，“韵”与“韵母”的分工最要拎清：一个为押韵划界，一个给音节动手术。
:::

## 后续内容

韵母与声母能拼出哪些音节、拼音正词法把哪些动程写了出来（iou→iu 之外还有 ü 的两点、y、w 诸规则），见[[sounds-of-mandarin/syllables-pinyin]]；韵尾弱化与轻声的关系在[[sounds-of-mandarin/sandhi]]；元音的历史（中古四等如何变成今天的介音系统）是[[phonology/mc-finals-tones]]的主题。背一背本章的 39 账表，下一章做声调时还要用它给“韵”定坐标。另留一个自练：把你名字的普通话读音拆到头、腹、尾，再查它在你的方言里少了哪一格——一张纸就能完成的“韵母田野调查”。

::: summary
- 韵母分韵头、韵腹、韵尾三层；韵腹必有，元音韵尾只有 i、u，辅音韵尾只有 n、ng。
- 黄廖本 39 韵母的总账：单 10（含 ê、er、两个舌尖元音）、复 13（按前响、后响、中响）、鼻 16（-n 八、-ng 八）。
- 拼写与音值有系统错位：iong 撮口、ong 音近［uŋ］、ie üe 的 e 是 ê、iou uei uen 声母后省写；拼音是方案，不是实录。
- 四呼按介音划户，与声母配合规则互为表里：g、k、h、z、c、s、zh、ch、sh、r 不拼齐撮，j、q、x 只拼齐撮；o 与 uo 互补分布，方言与教材的账法有别。
- 元音的三条发音特征（舌位前后、高低、唇形圆展）是纠方音的坐标：ü 与 u 之差，就在“前”的一格。
- “韵”不论四呼，“韵母”细到音节；说押韵先说“哪部韵”。
:::

## 习题

::: exercise 数齐齿 {level=1 check="4"}
在 ia、ie、ian、ing、üan、uai 六个韵母中，属于齐齿呼的有几个？
::: solution
4 个：ia、ie、ian、ing（均以 i 起头/韵腹为 i）。üan 是撮口呼，uai 是合口呼。数之前先按[[#def-sihu]]报口径：四呼看介音，不看主元音。
:::
:::

::: exercise 四呼对号 {level=1}
给“看 kān、见 jiàn、关 guān、元 yuán”四个字按韵母定四呼，并各指出韵头、韵腹、韵尾。
::: solution
看 an：开口呼，无头，腹 a，尾 n。见 ian：齐齿呼，头 i，腹 a，尾 n。关 uan：合口呼，头 u，腹 a，尾 n。元 üan：撮口呼，头 ü（写作 y），腹 a，尾 n。四字韵腹韵尾全同，四呼各一——四呼之别纯粹是介音之别。
:::
:::

::: exercise 找韵腹 {level=1}
指出下列音节的韵腹（主要元音）：duo、lun、xia、gei、jin。
::: solution
duo［uɔ］韵腹 o［ɔ］；lun［luən］韵腹 e［ə］（uen 省写作 un，省而不吞）；xia［ɕia］韵腹 a；gei［kei］韵腹 e；jin［tɕin］韵腹 i（in 分析上可视为 i＋尾 n；若依“韵腹 ê 弱化”一说请注明所从）。拖长发音找“最响的那个”，是最可靠的土办法。
:::
:::

::: exercise 押韵分析 {level=2}
李白《早发白帝城》韵脚为“间、还、山”（朝辞白帝彩云间，千里江陵一日还……轻舟已过万重山）。按今音与平水韵分别说明三者的韵母与所属韵部，判断它们“同韵母”与“同韵”是否同时成立。
::: solution
今音：间 jian［iɛn］、还 huan［uan］、山 shan［an］，韵母不同（齐齿／合口／开口）。平水韵：三字同属上平十五删，故同韵、可相押。于是“同韵”成立而“同韵母”不成立——正是[[#sec-yun-yunmu]]的分界实例：韵部合并四呼，韵母分析四呼。顺带留意“还 huán”带 u 介音仍与“间、山”同韵：押韵不论介音，此处最直观。
:::
:::

::: exercise 配合诊断 {level=2}
某学习者在纸上写出五个音节：fiao、guai、güan、xü（他把 ü 的两点也写了）、ziao。按声韵配合规律与拼写规则逐一判断：哪些是普通话的合法音节？不合法的各违反了什么？
::: solution
guai 合法：合口呼，g 组可拼 u 类韵（“拐 guǎi”）。xü 的音合法、写法不合法：j、q、x 后的 ü 按规定去两点，正写 xu（“叙 xù”）。fiao 不合法：f 不与齐齿呼相拼，普通话无此音。ziao 不合法：舌尖前组（z、c、s）不拼 iao，“小”有 xiao（舌面）而无 ziao。güan 不合法：舌根组不拼撮口 üan（“关”是合口 guan）；况且 ü 也不写在 g 后。做这类题靠两张表对查：四呼户口表 × 声母部位表。“物理上发得出”与“系统里拼得出”是两回事——又一次“可能”与“现实”的分家（见[[sounds-of-mandarin/speech-sounds#sec-yinwei]]）。
:::
:::

::: exercise 拼写还原 {level=2}
把 niu、dui、lun、jiang 四个拼式还原为带音值的结构式（韵头／韵腹／韵尾三项，标出省写），并为每字找一个例字。
::: solution
niu＝iou：头 i、腹 o、尾 u（声母后省 o），例“牛”。dui＝uei：头 u、腹 e、尾 i，例“对”。lun＝uen：头 u、腹 e、尾 n，例“论”。jiang＝iang：头 i、腹 a、尾 ng，例“江”。注意 dui 的 e 与 lun 的 e 同是省而不吞：慢读分明，快读弱化（iou 条同理，参[[#ex-iou]]）。
:::
:::

::: exercise 归并的分歧 {level=3}
ing 该分析为“i＋ŋ”还是“（韵腹弱化）＋ŋ”？ong 该算“u 的鼻音韵”还是独立韵母？写二百字，摆出两种立场各自的证据，并给出你在本课程采用的处理。
::: hint
证据可考虑：拼音字母、实际音值（弱化央音）、方言与历史的对应（闽南语“东”读 tang 类）、四呼归类方便。立场没有唯一，口径必须一致。
:::
::: solution
参考立场：本课程把 ing 处理为“韵头 i＋韵尾 ng、韵腹弱化”，把 ong 处理为“音近［uŋ］的鼻韵母、拼写作 o”——理由是（1）音值上主元音确实又短又央；（2）ong 归合口与 u 行整齐。反方立场同样可举：把 ing、ong 视为独立单元音性韵母，可避免“无韵腹”的尴尬，也便于与方言对读（闽南 tang、tok 显示 ong 曾有 a 类主元音，见[[phonology/to-mandarin]]）。评分看：是否摆证据而非比嗓门、是否自觉声明所从；“课本说有韵腹所以有”零分。
:::
:::

::: exercise 自家方言的元音账 {level=3}
用你家乡话与普通话各读“诗、知、鸡、资”四字，检查韵母是否相同；写一段分析：你的方言里 -i［ɿ］、-i［ʅ］、i 三个元音是几个音位？给替换证据。
::: solution
普通话里三字韵母三分（知 -i［ɿ］／诗 -i［ʅ］／鸡 i），各随其声母出现，严格讲是互补的音位变体问题（舌尖两个各有环境，主流分析归为三个音位或“/-i/ 的条件变体”两可，教材多按后者记 -i）。方言常见格局：西南官话“诗、师、知、资”同韵，吴语保留舌尖元音且多单元音化。合格答案须给“同环境替换换不换词”的判断，并如实标音（拿不准就标两个方案，写清分歧）。此题无标准音值答案，有标准的论证格式。
:::
