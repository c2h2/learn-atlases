“宇宙洪荒”四个字，调值恰好是 214、51、35、55——上、去、阳、阴，四种调型一字一个，像是给声调课预先备好的教具。声调是汉语与其他语言最不相同、也最容易被母语者“日用而不知”的一层：你会用四声，却可能说不清“三声到底是不是先降后升”“为什么有人把你的声调听岔而把你的重音听对”。这一章给声调建档：它是什么（音高的曲拱）、怎么记（五度制）、普通话有哪几个（四声加轻声）、它管什么（辨义），以及它和句子的语调怎样共处。

## 声调是音高的曲拱

::: definition 声调 {#def-shengdiao}
音节发音时**音高的升降曲折型式**，能区别词汇或语法意义，称**声调**。它是音高的一种辨义用法（参见[[sounds-of-mandarin/speech-sounds]]结尾对四要素身份的交代）：载着声调的音节，主元音的音高不是平的或有任人自由起伏的，而是按系统规定的曲拱行进——高低之外还讲究**形状**：平、升、降、升降、降升。
:::

::: theorem 声调听的是“形状”，不是绝对音高 {#rule-xiangdui}
同一调值对所有人是同一个调：男低音读“妈”、女高音读“妈”、小孩尖着嗓子读“妈”，只要音高的**相对起伏形状**相同（高平），听者就归为同一声调。声调是一个在个人音域内伸缩的曲拱。
:::

::: proof 形状恒常性的日常证据
电话里男人女人把“买、卖”念成各自都舒服的音区，“卖”的降落形状不变，没人听岔——这是形状恒常性的直接体验。实验室里的强证据是**移调合成**：把一段录音的基频曲线整体提高或压低（保持形状），调类识别基本不受影响；保留基频的绝对数值而**抹平形状**（把 51 削成 33），受试立刻把“爸”听成“巴”一类。人的听觉对语音声调的解析，用的正是语言里对语调“音域压缩”的同一套机制——你激动时音域拉宽、所有调更“陡”，听者照样还原出你的用词。声调的这种相对性，也解释了为什么学方言或唱歌时要换一套“音高换算表”：形状要整体搬迁，绝对数值一概靠不住。顺带拆一条常见误会：有人以为自己“嗓子亮所以声调准”——音域宽窄只是画布好坏，不保证形状画得对；调值准不准，量的永远是曲线的走向。
:::

## 调值、调类与五度制 {#sec-diaozhi-diaolei}

::: definition 调值与调类 {#def-diaozhi-diaolei}
**调值**是声调的实际读法，用音高形式（五度数字）记写，如普通话阴平 55、去声 51。**调类**是声调的类别名称，是把调值归纳出的类——普通话四个调类：阴平、阳平、上声、去声，通称“四声”。调值说“怎么念”，调类说“归哪一类”；调类名（阴、阳、上、去）带着中古音史的出身（见[[phonology/mc-finals-tones]]），不同方言里同名调类的调值往往不同，同值调类的名称也可能不同。
:::

::: definition 五度制 {#def-wudu}
赵元任创制的记调法：取一人音域，分为五度（1 最低，5 最高），以时间为横轴、度数为纵轴画出调值曲线，或直接用两位、三位数字记起、止（与中间低点）的度数：55 高平、35 中升、51 全降、214 降升。配套另有“声调字母”标在字旁（˥ ˧˥ ˨˩˦ ˥˩）。五度记的是**相对**音高，正与[[#rule-xiangdui]]呼应。
:::

普通话四声的档案如下（调值为通行记法，各家在细部略有出入，上声尤甚）：

| 调类 | 调值 | 调型 | 例字 |
|---|---|---|---|
| 阴平 | 55 | 高平 | 春、花、天、开 |
| 阳平 | 35 | 中升 | 潮、河、回、明 |
| 上声 | 214 | 降升（低曲） | 雨、水、马、草 |
| 去声 | 51 | 全降 | 落、雪、夜、地 |

全表最标准的例字是 i 的“衣、移、倚、毅”四连：[i⁵⁵]、[i³⁵]、[i²¹⁴]、[i⁵¹]——同一音节戴上四顶帽子，一字一帽。课堂点名四声也常用成组的“四声联”：诗—时—使—试（ʅ 行）、飞—肥—匪—费（ei 行）、之—直—止—至（ʅ 行，另一系列）。练调值请从这些“声韵母全同、只换帽子”的联子起步，别的声音变量都不许动——控制变量是语音实验的第一课。

::: remark 上声的“低”
上声的完整调 214 的听感要点不在“最后升上去”，而在**前半的低而久**：单念、强调时升尾明显；语流里在别调之前多半只读低平的“半上”［21］（“慢说三声，平时念‘北京’的上声就常到不了 4 度”——请对照[[sounds-of-mandarin/sandhi]]变调一章）。慢说三声，平时念“北”的单字，升尾也常常到不了 4 度——有的教材据此主张上声的“本调”应记作低平 21，升尾是停顿处的填充——这是有依据的少数派分析；本课程随通行教材记 214，逢单字、强调时按 214 练，逢连读按变调规则走。
:::

::: application 声调的“病人名单”
说普通话最常出的声调毛病，可以开成一张诊所名单：①去声降落不到位，51 念成 53，听感“没劲儿”——练“夜、大、去”要落到音域底；②阳平起音过高，35 念成 45 甚至 55，“人”近“仁”而不辨；③上声升尾过度，单字拐成三折，词里又处处打满升调，听者反被带偏；④方言调类迁移，把母语调值直接套上普通话调类（各地方言与普通话的调类对应整齐而调值错位，正因此“说对了调类、念错了调值”是方言腔的主成分）。自我诊断的处方只有一个字：录。录“衣移倚毅”与各调联子，画五度曲线与标准对照，比读十遍绕口令都见效。
:::

::: quiz
五度制里“5”表示什么？
- [ ] 每秒振动 500 次
- [x] 个人音域里的最高一度
- [ ] 全音阶里的第 5 级
- [ ] 比 4 度响五分之一
::: solution
五度制把每个人的音域高头到地底均分五档，5 是最高档——人人自己的“天花板”不同，档位的相对位置相同，这正是它适合记“形状恒常”声调的原因（[[#def-wudu]]）。其余选项把音高与频率、音强混为一谈。
:::
:::

## 声调干什么活：辨义

::: example 一个音节的四顶帽子 {#ex-si-ma}
写出“妈、麻、马、骂”的调值，说明它们构成怎样的最小对立，并再找一组声韵母相同的四声对子。
::: solution
妈 [ma⁵⁵]、麻 [ma³⁵]、马 [ma²¹⁴]、骂 [ma⁵¹]：声母、韵母全同，调值各不相同，四个词彼此最小对立——声调单枪匹马就换了词。另一组：西 [ɕi⁵⁵]、习 [ɕi³⁵]、洗 [ɕi²¹⁴]、细 [ɕi⁵¹]。像声母韵母一样，把声调列入音位清单（超音段音位）才算普通话音系的全班名。
:::
:::

::: example “宇宙洪荒”逐字建档 {#ex-yuzhou}
给“宇宙洪荒”逐字标调值，并指出四字合起来为什么是理想的“四声表”。
::: solution
宇 [y²¹⁴] 上声，宙 [tʂou⁵¹] 去声，洪 [xʊŋ³⁵] 阳平，荒 [xwaŋ⁵⁵] 阴平——四个调类一字一个，四种曲拱一次看全，且都是常用字。读一遍四字，再打乱重排成“荒洪宙宇”（55 35 51 214）也不换字：声调不粘在“字”上改来改去，是词库给每个词条挂的固定属性，朗读时才临场变调（见[[sounds-of-mandarin/sandhi]]）。
:::
:::

::: example 声调与轻声的对举 {#ex-didao}
“地道 dìdào”与“地·道 di·dao”意义不同，请说明差别落在哪一层。
::: solution
前者两个音节各戴各调（51+51），是“标准、纯粹”的形容词；后者第二音节失掉本调、轻而短（51+轻），是“地下通道”的名词——差别不在声母韵母，在**调的有无与轻重**：轻声不是第五个调，是音节的声调特征被“剥掉”的状态（[[sounds-of-mandarin/sandhi]]）。同样手段成对存在的还有“东西”：dōng xī 是方位（东与西），dōng·xi 是物品；“大爷”dà yé（称呼祖父辈排行长者）与 dà·ye（伯叔的别称，随方言小异）同理。
:::
:::

::: theorem 调类数目是系统的账 {#rule-diaolei-shumu}
一种语言或方言有几个调类，由它自己的历史归纳得出，不由“四声”之名规定：普通话 4 类（再加轻声一说）；吴语多数 7 类上下；粤语传统分析 9 类（平上去入各分阴阳再加阴上之类，各家计法有异）；也有官话点平上去三声而分合与北京不同。入声作为调类在普通话消失（收塞音尾的短调入派他调），却在晋语、粤语、闽语、客家话等活着。
:::

::: proof 数调类的正确办法（以及为什么“入声”难数）
数法仍是替换法：同音段条件下，换音高轮廓是否换词，换词的轮廓各成一类。普通话拿“i”的四顶帽子一测即得 4。吴语、粤语里同样的测验会分出更多类；带 -p、-t、-k 尾的入声自成一组，其“短”与“尾音”与“调值”三件事绑在一起，不同学者按“调类”或“韵尾”划账，于是有 9 类、8 类诸说——数目分歧多半是账法分歧，不是耳朵分歧。这正是音位学“归并有分歧”在声调上的重演（[[sounds-of-mandarin/speech-sounds#rule-phoneme-test]]）。
:::

## 声调与语调：两层音高怎么共处

声调在**字**上活动，语调在**句**上活动。陈述、疑问、呼唤、强调给全句音高加“倾斜与压缩”：去声在陈述句末仍是“降”的形状，只是整个音域往下溜；升调问句把全句末端的音域抬高，“卖”字再念得高一些陡一些，仍是“卖”而不听成“买”——因为形状没变。两层同时加载而互不摧毁，是汉语语音处理最著名的工程设计。句末疑问语气也常被人误当“加了个升调的声调”：“你去吗”的“吗”本读轻声，升的是全句语调的尾，不是“吗”多戴了一顶调帽——声调与语调的账，落笔要分开。唱歌是它的反例与极限：旋律强制了绝对音高走向，声调形状被碾平，全靠语境辨义——旧时“依字行腔”的谱曲规矩（阴平配平直腔、去声配下滑腔之类）正是给声调在旋律里“保留形状”打的补丁，昆曲与老派京戏讲究于此。

::: intuition 把五度制想成“简谱”
五度制与首调唱名的道理相同：12345 不是绝对音高，是音阶上的档位；合唱队里男女声部相差八度，同一份简谱唱出来频率完全不同，曲子却是同一支。声调亦然——把每个人的音域当成他自己的“do re mi sol la”，55 就是“la—la—”拖平，35 是“mi→la”的上行，51 是“la→do”的直落，214 则是“re→do→fa”的先沉后挑。用唱谱的办法记调值，手风琴般的绝对音高习惯就再也骗不了你。练耳也顺手练了：听到“衣移倚毅”若能心里哼出“la-la、mi-la、re-do-fa、la-do”，声调这门课就算入了门。
:::

::: warning 别把调值当调名用，也别把轻声数成第五声
✗ “普通话有五声：阴阳上去加轻声”——轻声不辨调类，是失掉本调的轻短读法，不算“第五声”。✗ 把 55 叫“平声”、把 214 叫“上声调值就是先降后升，任何位置都完整读出来”——调值随位置变（半上、变调），调类名不变；“平上去入”这四个调类名是中古史的账（平声今分阴阳，入声派完），拿去称呼今调值会张冠李戴。✓ 说数值带“调值”二字（“55 是这个上声字在这个位置的实际调值”），说类别用“调类”，说轻短读法用“轻声”。
:::

::: history
“四声”之名起于南朝：周颙著《四声切韵》（书佚），沈约倡“四声八病”之说用于诗文声律（《宋书·谢灵运传论》“欲使宫羽相变，低昂互节”），平上去入自此成为汉语声调分析的骨骱。北朝以来平声分阴阳的条件是声母清浊，浊音清化后调值一分为二，今之“阴阳上去”由此而来；元周德清《中原音韵》（1324）为北曲“入派三声”，记下北方入声消亡的现场。现代一端，1920 年代赵元任创五度记调法与声调字母，此后汉语方言的调值调查才有了通用的刻度——今天《现代汉语词典》每一字头右上角的那串数字，都是这把尺子的产物。
:::

## 借词戴帽子的规矩

外来的声音进入汉语，声调是现取的：咖啡的“珈琲”本有古音，今读 kā fēi 两顶阴平帽，与英语 *coffee* 的重轻格式毫无对应；“沙发”shā fā、“雷达”léi dá、“幽默”yōu mò——一律从借字之本调。“德先生”“赛先生”时代给 *democracy*、*science* 派的是“德、赛”两字的调，可见声调系统对外来货的处理是“音尽量仿、调听命的”。比较：日语借汉语词也要按本族音系改造声调（汉音吴音），声调是各系统不容谈判的主权——这与[[linguistics/phonetics-phonology]]里“借音先过音系过滤”的总规律一致。

::: quiz
“咖啡”两字皆阴平，与英语 *coffee*（重音在前、次音轻弱）的处理完全不同。这说明（　）。
- [ ] 汉语借词其实不模仿外语读音
- [x] 声调与轻重各有系统，借词进入汉语要改戴本系统的声调帽子
- [ ] 英语没有高低音高的变化
- [ ] “咖啡”的读法是审音表专门规定的外来语例外
::: solution
借词的音系适应是常态：音段尽量仿原音，超音段（声调、轻重）按本系统重新配置。“咖啡”用的是既有字的本调，谈不上专门规定（D 错）；英语有音高变化，只是不用于辨词义（C 错）；A 与“尽量仿”的事实相反。
:::
:::

## 后续内容

声调在语流里的变形（半上、两上相连、一不变调）与轻声、儿化整章在[[sounds-of-mandarin/sandhi]]；平仄是调值的诗律分账，见[[poetry-metrics/level-oblique]]；方言调类的对应（“某方言的阴平多数字在普通话读什么”）是方音辨正与历史音韵的共同课题，见[[dialects/mandarin-dialects]]与[[phonology/to-mandarin]]；音高曲线的声学测量属[[linguistics/phonetics-phonology]]与声学语音学的交界。

::: summary
- 声调是音高的辨义曲拱；听辨靠相对形状，不靠绝对音高（[[#rule-xiangdui]]）。
- 调值是实际读法（五度数字），调类是归纳的类别（普通话：阴平 55、阳平 35、上声 214、去声 51）；五度制为赵元任所创。
- 声调单凭一己就能换词（妈麻马骂、西习洗细），是超音段音位；轻声是失掉本调的轻短读法，不是第五声。
- 上声的低曲是听感之本，连读时常只读“半上”；调类数目随系统记账，入声在普通话派入他调、在南方方言尚存。
- 声调与语调分属字、句两层，靠“形状”与“音域”分工共存；唱歌是声调被旋律碾平的极端情形。
- 调类的历史账（平声分阴阳、入派三声）就在日常调值里，声调课由此直通音韵学；借词入汉语，音段尽量仿、声调按本系统重新指派。
:::

仿照 i 的“衣移倚毅”，给韵母 u 与 ü 各凑一组四声例字并标调值；再检查韵母 a：四个调类都能配上常用字吗？
::: solution
u 行：乌 [u⁵⁵]、无 [u³⁵]、五 [u²¹⁴]、悟 [u⁵¹]；ü 行：淤 [y⁵⁵]、鱼 [y³⁵]、雨 [y²¹⁴]、遇 [y⁵¹]（零声母正写 yū、yú、yǔ、yù）。a 行要靠“啊”的阴阳上去四读（ā á ǎ à）才凑得齐，叹词之外成词稀少——本题真正考的是账目意识：普通话并非每个韵母都在四个调类上摊满字，某些“四声齐全”的表格是借多音字撑起来的。摊不摊得满，本身就是音系的史迹。
:::

::: exercise 形状迁移 {level=2}
用五度制记你方言四声的调值（不确定就找一位年长的母语者念“衣移倚毅”类标准对子取平均），再写一条你的方言调类与普通话调类的对应规律，并举两个字验证例外。
::: solution
示范：河南开封话调值约为 41、55、35、24（阴平低降、阳平高平、上声高升、去声低升——各家记法略异）；对应规律举例：开封去声 24 对应普通话去声 51（“大、路”），开封阴平 41 对应普通话阴平 55（“天、风”）。例外须显式举出：入声派入各调的字在老派话里的读法与新派向普通话靠拢，就是“规律正在移动”的活例。评分看调值是否来自真实取音、规律是否给例外留了位置。
:::

::: exercise 谁的“妈” {level=2}
男声基频约 110 Hz、女声约 220 Hz。有人说“女人的‘妈’比男人的高一个八度，所以她念的不是阴平 55”。用本章原理批驳这句话。
::: solution
五度制记的是个人音域里的相对档位，与绝对频率无涉（[[#def-wudu]]、[[#rule-xiangdui]]）：女声的“5”度确实在约 250 Hz 上下，但她唱“妈”若保持高平不升不降，调值仍是 55、调类仍是阴平。把跨人的频率差当调值差，犯了拿“海拔”比“坡度”的错——正如把“绝对音高”当“声调”，与[[sounds-of-mandarin/speech-sounds]]“绝对音高不辨义”直接矛盾。
:::
:::

::: exercise 辨“先降后升” {level=2}
一位老师教“三声就是先降后升”，学生把每一处三声都读成完整的降升。指出这教学对在哪里、错在哪里，并给课堂上的分段处方。
::: solution
对：单字调、强调位置上的上声确有 214 的降升全貌，且“低”是它的听感标识；错：把它当“任何位置”的读法——三声在非三声前只读半上 21（“北京”之“北”），在两上相连的前字变 35（“你好”），轻声前亦有变化（[[sounds-of-mandarin/sandhi]]）。处方：单字朗读练全调 214；词语朗读练 21 与 35；句子里再谈“低而长、别翘尾巴”。考试口径（给“本调”）随通行教材记 214。
:::

::: exercise 调类对应与历史 {level=3}
“诗、时、死、四”四字今读 55、35、214、51。请推测它们在中古的调类（平上去入、清浊不要求精确定位，方向对即可），并说明“时的声母与诗的声母一浊一清”如何解释“同为平声，今调不同”。
::: solution
诗（阴平）、时（阳平）、死（上声）、四（去声）：中古平上去去大致有绪——平声字今读阴平或阳平，条件是中古声母清浊：清（全清）平声入今阴平（诗书心母全清），浊（全浊）平声入今阳平（时禅母全浊）。“平声分阴阳”正是浊音清化的声调补偿（“平送仄不送”的塞音故事是同一场音变的另一半，见[[sounds-of-mandarin/initials]]、[[phonology/to-mandarin]]）。死（上声止韵心母）、四（去声至韵心母）则是上去之别留在今调值上。评分：说清“同一今调类里混着历史来源、同一古调类因清浊分今调”即达标。
:::

::: exercise 声调的“音域实验” {level=3}
用手机录音把你朗读“春天的周末”一句正常读一遍、耳语（气声，不带嗓音）读一遍，对比两句声调是否“还在”，写二百字解释差别。
::: solution
观察：正常朗读，“春天的周末”五字轮廓（55、55、轻、55、51）分明；耳语版去掉了声带周期振动，只剩气噪声谱，听者辨调主要靠残余的强弱与口型线索，辨义明显变差却不至于全塌（辅音元音身份仍在）。解释须点破：五度制记录的是**带嗓音的**基频轮廓；无声带振动，调值的物理载体就没了——“声调依赖浊音”由此得证；而声调的“轮廓”在听觉上有部分冗余编码可凭，与母语预期结合尚存几分。
:::
