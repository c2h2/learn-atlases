同一个“人”字，北京人说 rén［ʐən³⁵］，成都人说近似［zən²¹］，温州人说近似［nan³¹］——三字三耳，却都是汉语。方言与普通话的差距不是杂乱无章的“错”，而是**一套对一套的整齐对应**：声母有声母的合并法，韵母有韵母的归并法，调类有调类的错位表。辨正的全部学问就建立在这份整齐上：先查明你的方言把普通话的哪些音“并”到了哪里，再按对应规律成批地改——比一个字一个字死记快十倍，也稳十倍。这一章教你给自己做一次“方音体检”，并开出第一张正音处方。

## 为什么方音是“系统”而不是“错误集”

::: definition 方音与对应规律 {#def-fangyin}
某地方言母语者说普通话时带出的口音叫**方音**。方音的特征几乎从不是零星失误，而是**母语语音系统的整体迁移**：方言里合并了的音位，说普通话时也合并；方言里缺的音，说普通话时用近似音顶替；方言的调值，会像帽子一样扣到普通话的字上。因为迁移的是系统，所以方可统计、方可预测、方可成批矫正——这就是“辨正”（把方音与普通话的差异逐条辨认、逐条纠正）科学的根基。
:::

::: remark 辨正不是排座次
语言学上，各汉语方言互为“兄弟”而非“标准与歪版”：吴语保留全浊声母、粤语保留入声韵尾，恰恰是普通话丢掉的古音层（参[[phonology/mc-initials]]、[[history-of-chinese/periods]]）；而普通话的平分阴阳、入派三声，也是自己一路演变的成果。辨正的全部前提是一句社会语言学常识：**口音无高下，场合有规范**——课堂、考场、话筒前采用共同语的标准音，回家说家乡话，两件事不打架。把方音当“丑”去羞耻，是正音教育最大的历史弯路；把它当“迁移”去工程化解决，才是这一章的立场。
:::

## 声母三案：平翘、n/l、f/h

::: example 案一：平舌顶替翘舌 {#ex-pingqiao}
武汉、成都、南京等地的方言里，精组（z c s）与知系（zh ch sh）历史上合成了一路（“四=事”“才=柴”同音）。这些地区的普通话学习者查的不是“哪些字读错”，而是“**哪些字本该翘**”。
::: solution
三条成批的办法。其一，**声旁类推**：翘舌声旁家族如“召”（招昭沼超绍皆读 zh/ch/sh）、“中”（忠盅衷）、“少”（抄钞砂纱，黑名单：妙 miào）；平舌家族如“宗”（棕综踪）、“则”（侧测厕）、“曾”（曾增缯皆 z 组）。一族记一个代表字，胜记零散十字，例外（黑名单）单独登记。其二，**配列规律**：普通话的 ua、uai、uang 三个合口呼韵母**只跟 zh ch sh 拼、绝不跟 z c s 拼**（抓 zhuā、揣 chuāi、双 shuāng）——平舌化方音里读如“杂”类的字，只要韵母是 ua/uai/uang，闭眼翘舌必对。其三，**常用字表过筛**：三千五百通用字里翘舌声母字约占三成，按表自读自录、逐词勾对——笨办法召回率最高，任何方言区通用。
:::
:::

::: example 案二：n、l 一家 {#ex-nl}
西南官话、湘语、赣语大片区域“牛=刘”“女=旅”。难点不在发音（两音各地方言都发得出），在**字的归属**记忆。
::: solution
声旁类推在这族最灵：定 n 的声旁族：“乃”（奶耐衲）、“尼”（泥怩昵）、“农”（浓侬）；定 l 的声旁族：“卢”（炉芦颅庐轳）、“吕”（旅铝闾）、“洛”（烙骆）、“良”（浪狼廊，黑名单：酿 niàng）。方言里 n/l 两读的字多半恰好落进这两串声旁的家族，类推效率极高；拿不准的回到词典。终极判据仍是词典：**“内、年、暖、牛、你、女”六常用字每天过一遍**，方音区考生的卷面失分大半在这六个字上。
:::
:::

::: example 案三：f 与 h 的辖区之争 {#ex-fh}
湘语、客家话、粤语及江淮部分片的方言，“湖=服”“花=发”不同音而彼此纠缠：有的只留 h，有的只留 f，有的按韵母瓜分（u 韵前混）。
::: solution
先查自己是哪一派（用“湖服、花发、灰飞、方荒”四组词自测录音）。再记普通话的分配账：**“无、文、万、武、微、未、网”一组方音常读 f/v，普通话读零声母（拼写 w/u）**——“武”不读 fǔ；而“夫、服、福、防、分、飞”等古非敷奉母字普通话一律 f，绝不变 h。剩下的“f 还是 h”逐字之争（“荒/方”“混/份”）靠字源账：非组字读 f、晓匣母字读 h——音韵学入门后一表在手（见[[phonology/to-mandarin]]的对应规律族）；入门之前，按常用字表逐字标记即可。
:::
:::

## 韵母两案：前后鼻音与 ü

::: example “根更”之争 {#ex-nng}
西南官话大部、晋语部分片区，前鼻音 -n 与后鼻音 -ng 合并为一套（常收在鼻化或 -ŋ）。“陈=程”“斤=经”“宾=冰”同音者即属此案。
::: solution
发音端：-n 舌尖抵上齿龈，-ng 舌根抵软腭，让母语者对着镜子把手指分别放下巴与喉结感受位置差（元音相同、除阻部位不同，见[[sounds-of-mandarin/finals]]的鼻韵母节）。归字端：en 与 eng、in 与 ing 的字数悬殊、声旁界限清楚，可整族迁移：记“生、成、名、平、明”一族后鼻（声旁“生”：牲笙甥；“成”：城盛诚），记“人、民、真、身”一族前鼻（“真”族：镇慎? 填滇均前鼻 ✓）。方言里“根”与“更”同音的人，背单词表时务必给后鼻族打红勾——你不是学不会发音，你是**耳朵从来没被分配过这两家的户口**。
:::
:::

::: example ü 的失踪案 {#ex-u-umlaut}
不少中原、西南方音无撮口呼：ü 读 i（“鱼=疑”）或 u（“去=趣”? 读 cu?），或干脆并入“五”类。
::: solution
补 ü 的通道最短：先发 i，再保持舌位把唇拢圆——一个动作得到 ü（[[sounds-of-mandarin/finals]]的“单音素说”在此变成体操）。归字上，ü 系韵母的字族小而易数（“鱼、女、居、去、学、全、宣、军”八族统辖绝大多数字），半天背完；难在**拼写纪律**：j q x 后写 u 实读 ü（去 qù），与“路 lù、粗 cū”界限分明——正词法一条规则就把两案纠纷一次了断（[[sounds-of-mandarin/syllables-pinyin]]）。
:::
:::

## 声调的账最复杂：调类对得上，调值对不上

::: theorem 调类对应与“换帽子” {#rule-dulei-duizhi}
多数方言与普通话之间有大致整齐的**调类对应**（阴平阳平上声去声各归各的“历史户口”，见[[sounds-of-mandarin/tones]]的调类账）。方音最顽固的一层往往不是声母韵母，而是**调值错位**：你的“阴平”可能是低平 22，套在普通话的阴平（55 高平）上就成了“洋腔”的元凶。辨正办法叫“换帽子”：字不用重学（调类不变），只把每类的实际音高曲线整体换成普通话的五度值——四顶帽子换完，口音去七成。
:::

::: example 入声字的去向 {#ex-rusheng}
成都、重庆一带入声整类归阳平（“食”读如“时”），南京、合肥、扬州等地则自留入声一个调类。一个保留入声或入声归派与北京不同的方言者，学普通话时该从哪里补账？
::: solution
先立总账：**普通话没有入声**，古入声字已“入派三声”、散归四个今调，北京的散归无简法、全凭记；但有一只可靠的粗筛：**阳平字里凡带鼻音韵尾（-n、-ng）的一律不是入声**（人、忙、年皆舒声），阳平中剩下无鼻尾的一批再逐字过表——粗筛加过表，常用字的入声嫌疑名单能缩到很短，再整族背下“一六七八九十、白食节月雪足曲国”一批高频入声字，账就平了。常用入声字几百个自成一族（一六七八九十、白食节月雪足曲国），整族背是正路；背熟一族，等于替方言与北京音的千年账本做平（入声的史账见[[history-of-chinese/middle-chinese-language]]，今方言地图见[[dialects/mandarin-dialects]]）。
:::
:::

::: intuition 耳朵先于舌头：最小对立对的道理 {#intuition-ting}
辨正训练的第一课往往不在嘴上，而在耳朵上。n/l、平翘、前后鼻的合并者，其感知系统已把两个音位归成一族——听不出区别，自然发不出区别（音位感知同化，见[[linguistics/phonetics-phonology]]的感知范畴化）。对策是“最小对立对”听辨：根/更、男/蓝、四/事随机播放、书面打勾，错到一定比例再上发音练习；实验心理学证明成人重建对立感靠**高强度反馈**（立刻对答案），泡在音频里“磨耳朵”而不判对错，收效近零。每天十分钟、两周见分贝——先让耳朵登记两家的户口，舌头才拿得到派遣。
:::

::: warning 三件忌讳
一忌**羞家**：把方言当污点，说普通话前先“戒”家乡话——系统迁移不靠戒除靠对照，且双语（方普）能力本身是资产。二忌**过正**：为显标准而满口夸张翘舌、句句拖降调，听感比带点方音更糟（“矫枉过正”在音变里是真实的社会评价）。三忌**望文生音与古音梗**：按声旁硬念（“函”读近“含”尚可类推，“昧”读“未”就是造字）、或把已废止的旧读当“有文化”搬回来（1985 年《审音表》统读之后，“确”不再读 qiǎo、“质”不再读 zhǐ，诸如此类）——规范读音的裁判是《审音表》与《现代汉语词典》，不是“我们老师当年教的”。
:::

::: history
方音辨正不是从零开始的现代发明：元代周德清《中原音韵》为“正语”而作，明代《洪武正韵》之争、清代官学里的《正音释略》《正音切韵指掌》一路办到清代官话正音书局，“正音”始终是通语教育的显学。科学化的转机在二十世纪：赵元任 1920 年代的方言调查开启音素级记音的时代；1956—1960 年全国方言普查摸清家底，各省编成《方言概况》；1962 年初版的《汉语方音字汇》把十六个方言点的字音排成对照大表——**对应规律从经验口诀变成可查的表**。此后各地方音教材、测试大纲的“本地区方音难点”一节，都是那张表的区县级延伸。你做的辨正功课，是这门“普查国家”学问的私人版。
:::

方音辨正的成果要靠朗读与说话来验收，测试扣分点与自查表见[[sounds-of-mandarin/putonghua-test]]；各地方音的分区与谱系见[[dialects/mandarin-dialects]]与[[dialects/wu]]、[[dialects/cantonese]]等课程；历史音层（为何“入派三声”、为何“浊音清化”）的因果账在[[phonology/to-mandarin]]与[[history-of-chinese/lexical-history]]。本章的期末作业只有一条：找一段自己的普通话录音，按“声母案—韵母案—调值帽”三层各列一张问题清单，再按清单做两周的成批矫正，两周后录同题对照——用数据说话，是语音学的待客之道。

::: summary
- 方音是语音系统的整体迁移：合并跟着合并、缺音用近音顶、调值扣帽子——因此可统计、可成批矫正。
- 声母三案：平翘（声旁类推＋配列法＋字表过筛）、n/l（声旁族＋黑名单）、f/h（先定自己哪一派，再按古音组记账）。
- 韵母两案：前后鼻音（部位体操＋声旁族分配）、ü（圆唇体操＋八族字表＋拼写纪律）。
- 声调是“换帽子”工程：调类对应不变，调值按五度表整体替换；调值迁移最隐蔽，录音曲线是唯一诚实的镜子。
- 辨正的立场：口音无高下，场合有规范；忌羞家、忌过正、忌古音梗。
:::

连续朗读“高、开、山、青”四个阴平字：先用你方言的阴平调值读，再用 55 高平读；录两段，比较基频曲线与听感。报告写二百字：你的出发调值约是几度？换帽难点在哪（上不去高度？维持不平？）。
::: solution
合格报告三要素：①报出方言阴平的估读调值（如低平 22、中平 33，或川渝的高降? 以实测为准）；②两段曲线的对照截图或描述（起点高度、斜率）；③难点归因——低平区者常见“抬到 5 度维持不住”，入声区者常见“短而陡像去声”。教师口径：凡报告数据自洽（录音—曲线—结论三对口）即为优，不要求“标准答案调值”。
:::

::: exercise 最小对立对编排 {level=2}
为一位母语为成都话的学习者设计“an/ang 分家”十天练习：列出每天的最小对立对词表（每天四组）、每天一个绕口令或对话任务、以及自测标准。
::: solution
参考骨架：Day1 班—帮、关—光；Day2 三—桑、丹—当；Day3 山—商、翻—方，每日四组、循环复习前日；每天跟录音朗读，再脱稿“听写”（手机朗读软件报词自写），写对八成为过关；Day7 进绕口令（“扁担长，板凳宽”经典款，专攻 an/ang 交叠）；Day9 双人对话（一问“饭馆在哪儿”一答“广场东巷”）；Day10 朗读一段三百字短文，统计 an/ang 错读率，错三以下进入下一案。要点：**集中一案、成批对立、每日自测**——这是辨正训练的通用模具，换个案名就是 n/l 十天、平翘十天。
:::

::: exercise 辨正的边界 {level=3}
有人说：“我普通话二甲都过了，回家还得被我妈说‘不好好说话’。”从“场合语域”与“认同”两个概念写三百字评论：语音上完全同化的“无口音普通话”在现实中意味着什么？辨正教育的合理终点在哪里？
::: hint
可用材料：你自己的方普语码切换体验；社会语言学“口音认同”话题任意一篇科普；[[dialects/fieldwork]]里发音人的双言生活。
:::
::: solution
参考论点：①“无口音”本质是放弃方普两套系统里的一套，代价是语域减半——家人、同乡、乡音梗全要弃用；②规范的目标是**可懂度与场合得体**，不是“查无此人”：二甲已足以在任何公共场合履职，剩余方音是身份标记而非缺陷；③辨正教育的合理终点=“该标准时标准、该带口音时带口音”的双言能力＋元语言自觉（知道自己在哪层做选择）。判分看论证是否用了“语域/认同”两概念并给出可操作判据，煽情与方言优越论各扣一半。
:::
