字典说“你好”是两个上声（nǐ hǎo），你的嘴却从来没这么读过——你脱口而出的是“ní hǎo”。变调、轻声、儿化是语流给声调系统开的三扇侧门：单字音是系统的档案，连续语流才是它运转的现场。这一章把三扇门的规则说尽：上声相连谁升、一不变到什么调、句尾的“啊”如何随前音变脸、哪些音节会轻到失去声调、“儿”又怎样从一个词缀缩成韵母上的一个卷舌动作。它们全都是**系统的、强制的、教而不会——不教也会**的语法：你会，但说不出；这一章就说给你听。

## 变调：语流里的声调互让

::: definition 变调 {#def-biantiao}
音节在连续语流中受邻音影响而发生的声调变化，称**变调**。与语速、强调造成的自由变化不同，变调是系统的：条件固定（谁在谁前）、方向固定（变哪个调）、全体母语者一致。普通话的调值表（[[sounds-of-mandarin/tones]]）记的是**单字调**（citation tone，字典里的“本调”）；连读时按本章规则改写。
:::

::: theorem 上声变调：连上相替，低不见底 {#rule-shangsheng-biantiao}
（一）**两上相连，前字变阳平**（35）：你好 [ni³⁵ xau²¹⁴]、水果、洗脸、管理。（二）**上声在非上声前只读“半上”**（21，低而不升）：北京、语言、火车。（三）三个以上上声相连，**按音组两层套用**：每个两字组的前字变 35，末字保留全调 214；分组随语法结构走（下节例题）。
:::

::: proof 为什么总是低升让路
上声的听感本钱是“低”（[[sounds-of-mandarin/tones]]的 remark）。两个低曲相连，前字的升尾还没起来就被后字的降头吃掉，低段糊成一片——于是系统改用对比度更高的阳平轮廓给前字让路（旧说“异化”dissimilation：相邻同调彼此推远）。“半上”同理：后面不跟低曲时，升尾本就无必要，低平段足以表明身份。这套互让在汉语各方言里各有变体（吴语的连读变调成“系统性大改”，一字调值全组重构，远超普通话的修补幅度），可见“单字调归字典、连读调归语法”是汉语声调的通例。
:::

::: example 三上相连的分组 {#ex-san-shang}
“小老虎”与“管理好”都是三个上声，实际调值各是什么？语法分组怎样在读音上留下脚印？
::: solution
“管理好”＝［管理］＋［好］（动补）：管（在理的低曲前）→35，理（在好的低曲前）→35，好→214：读如 [uan³⁵ li³⁵ xau²¹⁴]。“小老虎”＝［小］＋［老虎］：组内“老”在“虎”前变 35；“小”挨着的已是升起的 35（不再是低曲），按规则只读半上 21：[ɕiau²¹ lau³⁵ xu²¹⁴]。慢读分组分明时两式对立；快读流变里多数人把“小老虎”也拉平为 35 35 214——变调循音步循环应用，结构与频率都在账上。听出“管理好”头两字全升、“小老虎”头字低平，正是听懂语法结构的耳朵功夫。
:::
:::

::: theorem 一、不变调 {#rule-yibu-biantiao}
“一”（本调 yī 55）：**去声前读阳平 35**（一定 [i³⁵ tiŋ⁵¹]）；**阴平、阳平、上声前读去声 51**（一天、一年、一起）；**单用、报数、序数、词末恢复 55**（第一、唯一、“一、二、三”）。“不”（本调 bù 51）：**去声前读阳平 35**（不必、不去）；其余不变。附注两则：插入语“看一看、试一试”里的“一”已弱读轻声，不另言变调；北京土话“七、八”于去声前亦有变读（“七块”念近 qí kuài 的老派），普通话规范不收，测试从 55。
:::

::: example “坐一天船，看一看，一定不迟到” {#ex-yi-bu-real}
标出句中每个“一”“不”的实际调值，并说明各自条件。
::: solution
“一天”的“一”在阴平“天”前，读 51：[i⁵¹ tʰiɛn⁵⁵]。“看一看”的“一”夹在重叠动词中间，整个音节弱读轻声，变调表里没有它的账。“一定”的“一”在去声“定”前，读 35：[i³⁵ tiŋ⁵¹]。“不迟到”的“不”在去声“到”前，读 35：[pu³⁵]；“迟”阳平 35 照旧。全句连读（词内轻声未细标）：[tsuɔ⁵¹ i⁵¹ tʰiɛn⁵⁵ ʈʂʰuan³⁵，kʰan⁵¹ i· kʰan⁵⁵，i³⁵ tiŋ⁵¹ pu³⁵ ʈʂʰɿ³⁵ tau⁵¹]。本题的坑恰在“看一看”：那是**轻声弱化**通道，不是变调通道——两条管线分开记账（下节[[#def-qingsheng]]）。
:::
:::

::: quiz
“水果、水桶”两词里，上声字“水”的实际调值分别是（　）。
- [ ] 都是 214
- [x] 都是 35
- [ ] 前者 35，后者 21
- [ ] 前者 21，后者 35
::: solution
“果、桶”皆上声，两词同属“两上相连”，前字一律变 35。本题的诱惑是以为“桶”与“果”的调不同——先查本调再套规则，是变调题的唯一解法；要想让“水”读 21，后字得换非上声（“水缸”）。
:::
:::

## 啊的音变：句尾的语气词随前音换装

语气词“啊”（轻声，本音 [a]）粘在任何音节之后，会在交界处补一个与**前音收束动作**同色的滑音——语流里没有真空，句尾元音总被前一个音段的习惯动作染色。

::: theorem 啊的音变 {#rule-a-bianyin}
看前音节的收束动作：收 a、e、i、o、ü → **呀** [ia]（来啊 lái ya、对啊 duì ya、去啊 qù ya）；收 u、ao、ou → **哇** [ua]（走啊 zǒu wa、好啊 hǎo wa、漏啊 lòu wa）；收 n → **呐** [na]（看啊 kàn na、天啊 tiān na）；收 ng → 鼻化的 [ŋa]（唱啊 chàng nga、冷啊 lěng nga）；收舌尖元音 -i[ɿ]、-i[ʅ] → 该舌尖位置的延续加 [a]（字啊 [tsɿa]、是啊 [ʂʅa]）；前有儿化 → [ra]（花儿啊 huār ra）。
:::

::: proof 同化的一贯逻辑
[ia] 的 i 是前音高元音舌位的余响，[ua] 的 u 是圆唇的余响，[na] 的 n 是舌尖鼻音尚未除阻的尾巴，[ŋa] 的鼻化是软腭没来得及抬起——同化（assimilation）让相邻动作省力，书写里的“呀、哇、呐”只是把耳朵听见的染色登记在册（正字法宽严各版本不同：《现汉》多统收于“啊”而注出音变，吕叔湘《现代汉语八百词》对各“啊”有分说）。记住这是**必然**音变：自然语流里“看啊”读成 kàn a（中间干干净净）反而出戏。
:::

## 轻声：被剥掉帽子的音节

::: definition 轻声 {#def-qingsheng}
语流中某些音节失去本调、读得**又轻又短**的现象。轻声不是第五个调类（[[sounds-of-mandarin/tones]]），而是声调的**中和与弱化**：音长缩短、音强减弱、元音央化（“妈妈”的第二字元音近乎 [ə]）。其音高不自治，**随前字调值而定**：阴平后≈3 度、阳平后≈2 度、上声后≈4 度、去声后≈2 度（通行记法，各家小数位有出入）。
:::

::: theorem 轻声住在哪里 {#rule-qingsheng-jia}
（一）**语法成分**：助词（的、了、着、过、吗、呢）、趋向补语（拿起来）、重叠动词的后字（看看）、量词“个”与部分代词后缀（们）。（二）**词尾**：子、头、巴（桌子、石头、尾巴）。（三）**词的义项标记**：东西（dōng·xi 物件／dōng xī 方位）、兄弟（xiōng·di 弟弟／xiōng dì 兄与弟）、大爷（dà·ye／dà yé）。（四）**习惯的双音常用词**：妈妈、星星、客气、商量——这批“词典标音为主”的轻声词构成测试词表（《普通话水平测试实施纲要》轻声音节词表），也是“会不会说过普通话”的听感分水岭。
:::

::: widget plot

x: 0, 1
y: 0, 6
labels: 阴平后的轻声; 阳平后的轻声; 上声后的轻声; 去声后的轻声

:::

::: example “妈妈”的声学档案 {#ex-mama}
比较“妈妈 màma”两字：声母、韵母、调值、时长、元音清晰度，逐项列差。
::: solution
同源同音却处处不同（两字本调都来自“妈”mā）：首字 55 满档，时长足、元音 [a] 饱满；次字轻声，时长约为前者一半，音高约 3 度，元音央化成 [ə] 方向，声母 m 也短。若把第二字恢复为 55（mā mā），听感立刻变成“点名式强调”。结论：轻声是“调＋长＋强＋清晰度”四件套的整体削弱，只在音高上留下一条随前字摆布的尾巴——也正因此机器朗读把轻声念成原调时，人耳一听便知“洋腔”。
:::
:::

::: warning 轻声不是想轻就轻
普通话轻声词的**范围小于北京土话**：北京话里“告诉”读近 gàosong、“事情”读近 shìqing、“地方”读近 dìfang，普通话词典或注又读、或以本调为主——学习者以《现汉》与测试词表为凭即可；千万别按影视里“京腔全开”的耳朵自行扩产，把“曾经、必须、友谊”也读轻，那是把方言习惯冒充规范——词典不轻，你就不轻。考试口径与街头口径不一致时，答考试用前者，懂差别是这一章的全部诚意。
:::

## 儿化：一个词缀缩进韵母

::: definition 儿化与儿化韵 {#def-erhua}
后缀“儿”（ér）在语流中失去独立音节，把卷舌动作并入前字韵母，叫**儿化**；儿化的韵母叫**儿化韵**。拼音写作原韵母后加 r（花儿 huār、小孩儿 xiǎor），“儿”不再单拼。普通话的 39 韵经儿化归并成二十多个儿化韵（通行账目 26），合并是它的本性：“根儿”与“歌儿”儿化后同音 [kɚ⁵⁵]——en 与 e 的分别在卷舌前塌缩成同一格。
:::

儿化的主要音变（教学简化，细部各家记音不同）：收 -i、-n 尾的**丢尾**（小孩儿 xiǎor [ɕiauɚ²¹⁴]、门儿 mér、圈儿 qiūr）；收 -ng 尾的**丢 ng 并鼻化**（瓶儿 píngr [pʰiɚ̃³⁵]、棒儿 bàngr）；主要元音为 i、ü 的开口儿化式**垫入中元音**再卷舌（鸡儿 jīr [tɕjiɚ⁵⁵]、小鱼儿 yúr [yɚ³⁵]）；舌尖元音 -i[ɿ]、-i[ʅ] 整个换成 [ɚ]（字儿 zìr、事儿 shìr）；其余韵母直接卷舌（花儿 huār、味儿 wèir [uɚ⁵¹]）。

::: example 三个儿化的还原 {#ex-erhua-3}
给“门儿、瓶儿、事儿”各标实际音值，说明各自动了韵母的哪一层，并指出一处“合并”的证据。
::: solution
门儿 [mɚ̃⁵⁵]：收 -n 丢尾、元音鼻化并卷舌；瓶儿 [pʰiɚ̃³⁵]：收 -ng 丢尾、同样鼻化卷舌；事儿 [ʂɚ⁵¹]：舌尖后元音整个让位给 [ɚ]。三式本调韵母分别是 en、ing、[ʅ]，儿化后挤进相邻两格（前两个都带鼻化 [ɚ̃]，“门儿”又与“歌儿”隔格相对——en、e 之别在卷舌前已经塌缩）——合并的账一目了然：儿化韵是普通话韵母系统的“简化副本”，开齐合撮与 -n、-ng 的区分度在卷舌动作前一律退让。
:::
:::

::: theorem 儿化的三个职能 {#rule-erhua-gongneng}
（一）**别义**：头（脑袋）／头儿（一端、领头的）、面（面粉）／面儿（粉末状物：药面儿）、眼（器官）／眼儿（小孔）、亮（形容词）／亮儿（名词：光亮的地方）。（二）**别类**：形容、动词语素加“儿”转为名词是常见构词法（尖→尖儿、盖→盖儿；能否单立以《现汉》词目为准）。（三）**色彩**：细小、亲切、随意（小孩儿、门缝儿、玩儿、在哪儿）。注意：普通话的儿化**有词目限制**（《现汉》标注为准，测试大纲另列常用儿化词表），不是“想卷就卷”的自由构形：“水儿”“狗儿”词典不收，写进作文就是方音或旧白登台。
:::

::: proof “儿”怎么从名词缩成一个小动作
“儿”中古日母支韵，义为“婴儿、细小”，唐代起虚化为表小名词尾，宋元北方话里词尾“儿”与前字愈贴愈紧，最终由独立音节（ér）降为轻读缀、再降为韵母上的卷舌特征——语法化与语音弱化的教科书级路径（同类：普通话“们”、英语 -ing 的鼻音化）。证据就在账面上：独立“儿”还活在“儿子、儿童、儿戏”里，卷舌 r 只在词尾值班；一个字的两种寿命共存于同一部词典（参[[history-of-chinese/lexical-history]]）。
:::

::: quiz
“花”huā 与“花儿”huār，音系上少了什么、多了什么？
- [ ] 少一个音位，多一个声调
- [x] 两字并成一句，韵母带上卷舌特征
- [ ] 少一个儿化韵，多一个音素 r
- [ ] 什么也没变，只是写法不同
::: solution
“花儿”是一个音节（[[#def-erhua]]）：书写多一个 r，音系上是“词缀并入宿主”——两音节缩一音节，韵母添上 [ɚ] 的卷舌特征；“少一个音素”的表述错在 r 不是独立音位。听“花儿”拖不出“儿”的本调，即证。
:::
:::

::: quiz
下列词语的轻声**不区别意义**的是哪一项？
- [ ] 东西 dōng·xi
- [ ] 兄弟 xiōng·di
- [x] 妈妈 mā·ma
- [ ] 大爷 dà·ye
::: solution
“妈妈”只有轻声一读（没有“mā mà”全调对立项），轻声纯粹是构词习惯（[[#rule-qingsheng-jia]]第四类）；其余三项都存在“全调义项／轻声义项”的对立。
:::
:::

::: history
儿化的文字证据晚于口语证据：元曲衬字与明清白话小说里“儿”缀已俯拾即是（《金瓶梅》《醒世姻缘传》用“儿”字之密，正是朗读时的卷舌密度），而等韵学家直到清代才肯为它立说——潘耒以还，“儿化”逐渐进入韵书脚注。普通话确立后，轻声与儿化因“北京语音”的出身经历了一场身份拉锯：1950—60 年代的语言学家为“哪些词该轻、哪些该儿”反复制表（1963 年《普通话异读词审音表（初稿）》与后来的普通话试点教材均设专表），1985 年审音表与 2003、2021 两版测试大纲把口径落进考卷（2016 年审音表修订稿曾公开征求意见，截至 2026 年未见正式颁行取代 1985 年版——引用读音规范时留意文件身份）——你手里的轻声词表，是七十年规范工程的成品。
:::

::: remark 变调、轻声、儿化的“管辖域”
三样现象各自以不同的语言单位为活动范围：上声变调以**音步/词**为域（“小老虎”的分组分歧正是“域多大”的活证据）；一、不变调介于词与短语之间，虚字义实就弱、义虚就变；轻声与儿化则是**词法**现象——哪些词轻、哪些词儿，词库逐词登记（所以才有“词表”可依）。把这条“管辖域”线索带到[[modern-grammar]]的构形与构词之争、[[linguistics/morphology]]的“词是什么”难题里看，会发现本章的三扇侧门其实通向形态学的大门。
:::

## 后续内容

变调、轻声、儿化的“现场执行”在朗读语流里接受综合检验，[[sounds-of-mandarin/putonghua-test]]给出测试题型；连读变调的类型学（吴语连调的“系统重构”路线）见[[dialects/wu]]；“儿、们、了”这批轻读缀的来源与年代，归[[history-of-chinese/lexical-history]]与语法化研究。本章知识点的体检表就藏在你昨天的语音里：录一分钟自由聊天，数出你实际用了几个轻声、几次上声变调——你会发现规则一条没漏，只是从来没问过你。

::: summary
- 变调是语流的强制改写：两上相连前字变 35；上声在非上声前读半上 21；三上连读按语法分组套用（[[#rule-shangsheng-biantiao]]）。
- 一：去声前 35，其余 51，单用／序数／末位 55；不：去声前 35（[[#rule-yibu-biantiao]]）。
- 句尾“啊”随前音收束动作变“呀哇呐 nga”——同化，不是儿戏（[[#rule-a-bianyin]]）。
- 轻声是四件套的整体削弱，音高随前字（3/2/4/2），住处在语法成分、词尾、别义义项与习惯词表。
- 儿化把“儿”缩进韵母：丢尾、鼻化、并韵，功能是别义、别类、色彩；范围以词表为凭，不靠灵感。
- 三样现象的管辖域不同：变调属音步、轻声儿化属词法——这条线索直通形态学。
:::

::: exercise 轻声音高 {level=1 check="4"}
按通行记数，“桌子上”类“上声＋轻声”组合里，轻声音节的音高约在第几度？
::: solution
4 度（“姐·姐、奶·奶”型）：前字低谷反弹，轻声音节落在中高。四值口诀“阴三阳二上四去二”（[[#def-qingsheng]]）。
:::
:::

::: exercise 儿化韵的账 {level=1 check="26"}
通行教材（黄廖本）把普通话韵母儿化后归并成多少个儿化韵？
::: solution
26 个（各家统计略有出入；考试从教材）。合并是儿化的本性：分得清的韵母一“儿”就挤进同格——“根儿”与“歌儿”同音即是（参[[#ex-erhua-3]]）。
:::
:::

::: exercise 标出实际调值 {level=1}
给“保险箱、老读者、李小姐”三组各标出每个音节的**实际调值**（非本调），并写出分组。
::: solution
“保险箱”＝［保险］＋［箱］：保在两上之前变 35；险后面是阴平，读半上 21；箱 55。全式 [pau³⁵ ɕian²¹ ɕiaŋ⁵⁵]。“老读者”＝［老］＋［读者］：老在阳平“读”前读 21；读 35；者在词末读全调 214。全式 [lau²¹ tu³⁵ ʈʂɤ²¹⁴]。“李小姐”＝［李］＋［小姐］，而“小姐”组内“小”在“姐”前变 35；“李”又在底层上声“小”前，变 35；姐 214。全式 [li³⁵ ɕiau³⁵ tɕiɛ²¹⁴]。三组示范三种分组深度；本题重在“先分组、再套用”——凡不问结构、直接背“三上＝35 35 214”者，按未完成计。
:::
:::

::: exercise 啊的五张脸 {level=2}
给“快来看啊、真好啊、加油啊、唱啊、是啊”各写出“啊”的实际读音（用呀哇呐等汉字与音值），并注明所随前音。
::: solution
来看啊：看收 [n] → [na]（呐）；好啊：好收 [u] → [ua]（哇）；加油啊：油收 [u]（iou 尾）→ [ua]（哇）；唱啊：唱收 [ŋ] → [ŋa]/鼻化；是啊：是收 -i[ʅ] → [ʅa]（听感近“扎”不送气浊化之间）。写汉字时“呀哇呐”从俗亦可、统一写“啊”亦可，标音必须如实。
:::
:::

::: exercise 轻声与词义 {level=2}
“他说她是我的**兄弟**。”“这**东西**不错。”每句的轻声在不在？两种读法各是什么意思？再自造一对靠轻声别义的句子。
::: solution
兄弟：读 xiōng·di（弟轻）指弟弟一个；读 xiōng dì（皆本调）指兄与弟两人（或客套互称）。东西：dōng·xi 指物件，dōng xī 指方向。自造句示例：“他［盖ɡài］被子”与“他盖了个［盖儿ɡàr］”——动词与名物两读，一轻一儿各司其职；凡落在词表内的对立（头／头儿、眼／眼儿一类）都算。判分看：是否承认**全调读法的意义也是合法义项**（不是“读错”），与[[#rule-qingsheng-jia]]第三类呼应。
:::
:::

::: exercise 儿化合法性鉴定 {level=2}
“小孩儿、花儿、猫儿、水儿”——逐词判定是否为普通话的规范词目，并陈述你的三步鉴定法。
::: solution
三步：一查《现汉》——词目带“儿”者规范成立（小孩儿、花儿俱收；“水儿”“猫儿”不收）；二验语感——脱离上下文能否脱口而出；三对功能——合[[#rule-erhua-gongneng]]三条中的哪一条。结论：前两个合法（分别属色彩义与常用词目），后两个词典无账，属方言自由式或旧白；作文、朗读测试一律不带 r。文艺腔里的“猫儿腻”是习语整体，救不了“猫儿”单立。本题练的不是猜词，是**规范查询的素养**：字字有出处，条条可对表。
:::
:::

::: exercise 一段话的变调体检 {level=3}
朗读并录音：“晚上好，老李！我找小李，他家里人说他在午睡。等一会儿再打搅他，好不好？”标出其中的上声变调、半上、“一”的变调、轻声与儿化，统计各类处数，并与录音互核。
::: solution
参考清单（慢读口径；停顿与个人习惯会造成变体，以你能辩护为准）：晚上——“上”轻声，“晚”随之读半上；老李、小李——“老、小”在“李”（上声）前变 35；我找——“我”在“找”（上声）前变 35；午睡——“午”在去声前读 21；一会儿——“一”在去声“会儿”前读 35，“会”儿化为 huìr；打搅——“打”在“搅”（上声）前变 35，“搅”后接轻声“他”，读半上 21；好不好——前“好”在轻读“不”前多读半上，句末“好”保留全调 214。统计大致：连上变 35 约四处，半上四五处，“一”变一处，轻声两三处，儿化一处。评分看流程：清单、录音、互核三件齐全，凡与《现汉》词目音冲突处已注明。
:::
:::

::: exercise 规范的弹性 {level=3}
“我们”“他们”的“们”，“事情”“告诉”“地方”的轻声，词典与测试大纲的标注并不一致（又读、轻重两可）；有教师主张“能轻则轻”，有播音教材主张“从典”。写三百字谈你的处理：规范、语感、考场三个坐标如何权衡。
::: hint
可用材料：《现汉》凡例对轻声标注的说明；《普通话水平测试大纲》（以你手头版次为准）的轻声词表；你听过的新闻朗读与相声各三分钟。
:::
::: solution
参考立场：词典的“可轻可重”如实记录了共时变异，不是敷衍；测试以词表为准，因为评分需要边界；个人口语按语感（接近北京自然口语）走，不必“背表轻读”，否则“书卷气轻”反成新的不自然。三者冲突时的次序随场合切换：考场上词表优先，写作标音时词典优先，自由对话时自然优先——把坐标说清楚的答案就是好答案。
:::
:::
