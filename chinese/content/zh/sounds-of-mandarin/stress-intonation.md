“我没说他拿了你的书。”这句话把重音搬到哪个词上，就换哪个意思——搬到“我”是澄清当事人，搬到“书”是限定对象，六个词养着六句话。词有轻重，句有停连，全句有高低起伏的语调：声调管字，本章三件套管字以上的全部音乐。这一章把这些“看不见的设计”写成可操作的规则与练习，因为它们有两个直接用处：把话说清楚（重音错位就是表达事故），以及把文章读出声来好听（朗读与测试的第三题全靠它）。

## 词的重轻：普通话的“节拍器”

::: definition 重音与轻重格式 {#def-zhongyin}
几个音节并成音组时，有的音节发音长、强、清晰，有的短、弱、模糊，强的那个叫**重音**。在**词**的层面，习惯音高的强弱搭配叫**轻重格式**。普通话双音词的常见格式是**中重**（后重）：学习、语言、伟大；此外有**重轻**格式（轻声词：妈妈、桌子，见[[sounds-of-mandarin/sandhi]]）与少量两字均重或两可的情形。三、四音节的词与固定短语出现“**次重＋主重**”的层级（“北京大学”读来北轻、京更轻、大最重、学收得住——各家标法小异，两两相对的中重骨架不变）。
:::

::: remark 汉语的“重音”是弱势重音
与英语的强重音（重读音节元音饱满、弱读元音央化，对比悬殊）相比，普通话的轻重之别**温和得多**：汉语靠音高（声调）辨义，音节时长与响度的伸缩空间被声调锁住，所以教学上常说汉语是“音节计时”的语言——每个音节像节拍器上等长的点（实验测得汉语介于“音节计时”与“重音计时”之间，比英语整齐、比法语松散，各家结论随材料而异）。这解释了两件事：外国人说中文“一个字一个字地蹦”之所以不难懂，以及汉语歌词能整齐对拍——节拍器语言天生合拍。市井回声里同理：叫卖调“磨剪子来——戗菜刀”把音节拉成等长的腔板，节奏一乱，走调又走字；老铺伙计的口音课，第一课从来是“把拍子踩匀”。
:::

## 音步：汉语节奏的最小轮

::: definition 音步 {#def-yinbu}
韵律上组织音节的最小单位，普通话的典型音步是**双音节**（标准音步）；单字成“超音步/残音步”、三音节成扩展音步。词和词串都要排进音步：双音节是标准拍；三音节按构词切分为“1＋2”或“2＋1”（“图书馆”是 2＋1——“图书”修饰“馆”，读来“图书”紧、“馆”松），绝不许从中间腰斩。韵律语法学（冯胜利一系）用音步解释过一批句法现象，如“进行、加以、实行”后只配双音动词（“进行调查”可，“*进行查”不可）——详见《汉语韵律句法学》。
:::

四字格偏爱（成语、四字标语）与骈文的四六句式，都是音步在文体上的投影：2＋2 拍最稳，读来“像中国话”。写文章时“他快速地跑”不如“他飞快地跑”顺口，除了语体还有节律账——“快速地”三音节把 2＋2 拍撞歪了。韵律不是装饰，是汉语组织信息的基本骨架。

::: example 给一句话排拍子 {#ex-paizi}
用“／”标出下句的自然停顿，并说明虚词的拍子归属：“我们的学校坐落在风景优美的西郊”。
::: solution
自然读法：我们的学校／坐落在／风景优美的／西郊。节拍点全落在双音节组上（学校、坐落、风景、优美、西郊）；“的、在、了”这类虚词从不独立成拍，寄生在前字之后——把它们读成独立一拍，立刻拗口（拗口即违规，判断标准就是你每天说话的习惯）。虚词轻而短、实词撑节拍，这与轻声词表（[[sounds-of-mandarin/sandhi]]）是同一枚硬币的两面。
:::
:::

## 句子的三件乐器：停顿、重音、语调

::: definition 停顿与停连 {#def-tingdun}
**停顿**分两类：** grammatical 停顿**（语法停顿，对应标点与结构层次）与**修辞停顿**（逻辑停顿、情感留白，所谓“此时无声胜有声”）。标点不是停的刻度而是提示：逗号处结构未必停（“虽然……但是”一气读），句长时不逗号也须按层次偷气。误停即误读——“下雨天留客天天留我不留”的著名断句游戏（“下雨天，留客天。天留我不？留！”）证明：停在哪里，意思就在哪里。
:::

::: definition 逻辑重音 {#def-luoji}
语法重音是默认奏法（一般谓宾强于主、状补强于中，中心语强于虚词附加成分）；说话人为强调某信息而**违反默认**把重音搬过去，叫**逻辑重音**。重音的乐器不止音量：拉长音长、放宽音域、字头加重都可胜任——但**不得改变调型**（把“书 shū”抬成“ú”就不是强调，是错字——见本章后文警告）。
:::

::: definition 语调 {#def-yudiao}
全句的音高走向，句末最显。汉语教学传统分四式：**降调**（陈述、请求、命令：我走了。／请坐。）、**升调**（问话、惊讶、号召：你叫什么名字?／真的吗?）、**平调**（迟疑、冷淡、严肃：真的? 不好说。）、**曲调**（讽刺、双关、余味：哼，你“聪明”得很！）。语调叠加在各字声调之上：它不磨掉调型，而是**整体搬移音域并压缩幅度**——疑问把全句的天花板抬高，降调让尾部一路滑坡，字与字的相对形状保持（[[sounds-of-mandarin/tones]]的两层分工，这里兑现）。
:::

::: example 一句话六个重心 {#ex-liuge-zhongxin}
“我没说他拿了你的书。”给逻辑重音的六种摆法各写出被强调的语义。
::: solution
重音在“我”：别人说的，不是我。在“没”：全力否认（“我可没说！”）。在“说”：他可能只是示意、写了条子，未必“说”了。在“他”：说的有别人。在“你的”：拿的是你的书，不是别人的。在“书”：拿的是书，不是笔。全句像一架六键琴，弹哪键亮哪键——而每次弹奏，六个词的声调调型一个都没变：重音动的是音域、时长与清晰度，声调的“形状”在下一层值班（[[#rule-liangceng]]）。
:::
:::

::: example 当去声遇上升调 {#ex-qusheng-sheng}
“你去不去？”句末“去”是去声（51，全降），全句却是上升语调——矛盾吗？写下来分析。
::: solution
不矛盾，两层各让一步：语调层的“尾向上升”体现在**音域整体抬高与尾字不塌到底**——“去”的相对轮廓仍是“从高往低收”的小形状，只是这个形状被安置在爬升的大坡上，实际曲线呈复合样态；听者仍判“去”为去声，因为字层形状在，同时听出疑问，因为句层在升。把两层拆开的最好办法是变奏实验：同字分别放进陈述（“我不去。”）与疑问（“我不去？”）里录音——“去”的降头一次彻底、一次含蓄，而绝不会翻成升调的阳平“qú”。字调是承重墙，语调是软装，此例两样都露了馅。
:::
:::

::: theorem 两层音高互不侵占 {#rule-liangceng}
字层的声调与句层的语调分轨传输：声调保形状（调型），语调改音域（整体高低与尾向）。疑问不使阴平变阳平，强调不使去声变上声；反之，写诗填词若把字调的“字调走向”与吟诵旋律拧着来（旧称“倒字”：把“明月”唱成“名月”方向），听感立刻串行。广告歌、rap 填词至今守这条老规矩——**旋律可借声调的形状，不可毁它**。
:::

::: proof 从倒字到辨义：形状优先的证据
听者把降尾的“来啊～”听成邀请而非命令，靠的是调型＋尾向的组合解码；把同一句“他来了”分别用升、降读，语义由叙述变求证，而每个字的调类分毫不动。实验上，把语流的绝对音高曲线做“平移＋缩放”，调类与语气判断均稳定（[[sounds-of-mandarin/tones]]的移调实验在此复用）；反过来，只抹平字调（保持语调大波浪），母语者顿失辨义——**字调是承重墙，语调是软装**。戏曲“依字行腔”之所以成律，正因为腔（旋律线）必须让字调的升降形状听得出来，阴平配平直腔、去声配下滑腔皆是此理。
:::

::: quiz
“他大概不来了吧。”读出迟疑、将信将疑的语气，宜用（　）。
- [ ] 降调，果断收
- [ ] 升调，高挑收
- [x] 平调为主，尾字略平直、拖长
- [ ] 曲调，重音砸在“大概”
::: solution
迟疑冷淡属平调地盘：音域收窄、尾势平（[[#def-yudiao]]）。降调显得下结论，升调显得求证，曲调转讽刺；要“将信将疑”而非“讥笑”，平调才贴。（“吧”本身是语气词，疑问升调或迟疑平调两可，题目要的迟疑版在平。）
:::
:::

::: quiz
把“学习语法很重要”按自然音步排读，切分正确的是哪一项？
- [ ] 学习语／法很重／要
- [x] 学习／语法／很重要
- [ ] 学／习语／法／很重／要
- [ ] 学习／语法很／重要
::: solution
正确拍法是“学习／语法／很重要”：两个双音词各成一拍，“很”作程度副词寄生在“重要”前（逻辑重音落“重”）。其余切法或把“语法”腰斩、或把“学习”拆零、或把“语法很”捆成一拍切破结构——音步永远不越词界、虚词不占主拍：先语法，后节奏。
:::
:::

::: warning 重音不是“把声调喊歪”
强调的字可以拉长、可以更亮、音域可以更宽，**不可以改调型**：把“真 zhēn”加重成“zhén”（借阳平的升势充“力度”）、把“不 bù”喊出拐弯，都是拿字调当重音使——听者先听到“错字”，才可能想到“强调”。规范练法：同一句分别强调六词录音回听，检查被强调字的调值曲线是否依旧标准（[[#def-luoji]]）。顺带一条朗读腔黑名单：句末习惯性升调（“播音上扬腔”）、每句同速同高、逢双字必一顿的“机器人节奏”——它们的问题都同一：拿语调层当习惯，压过信息本身。
:::

::: application 电话、语音键与“看不见的脸”
失去了表情与手势，口语的信息量有一大块要由语调层补回来：电话里“嗯？”的一声短升＝“请再说一遍”，尾势平直的“好的”＝公事公办，上扬拖长的“好——的”＝亲热或敷衍（视音域宽窄）。语音消息的“已读不回感”正来自对方句调的平直化。反过来，朗读时“对空说话”比“对人说话”难，补偿手段是把重音与停连做得更夸张一点——播音训练的“对象感”，说白了是**在脑中给语调层找一个听众**。
:::

::: history
汉语文人对句内音乐的感受极早：虚词“也者”之辨、骈四俪六之制、词牌词谱之学，无不在打磨音步与句调；旧时私塾“读书”讲究抑扬吞吐，是把语调教学做进了日常。科学一端，赵元任三十年代用仪器与谱图研究汉语字调与语句语调（英文专文多种），奠定了“字调＋句调两层”的分析框架；陈望道《修辞学发凡》（1932）把“声律”列为辞格之一；1950 年代以后，朗读与朗诵艺术总结出“停连、重音、语气、节奏”四要素口令，经播音教学与普通话测试放大成今人的常识；中央台几代播音艺术家（齐越、夏青诸家）的示范录音，至今仍是“汉语句调该是什么样子”的活标本。一套“句子的音乐”，半部汉语美学，加半部实验语音学。
:::

::: quiz
“这也行？”与“这也行。”两句词序完全相同，区别只在（　）。
- [ ] 逻辑重音的位置
- [x] 语调层的尾向（升与降）及由此带来的语气义
- [ ] 声调调类不同
- [ ] 音步切分不同

同词同字调，全在句层：升调尾把陈述改写成“难以置信”的惊叹反问，降调尾则是冷淡的认可。字调、音步、重音三样都没动——语调单独就能改换句子的语用力，这是它作为“乐器”的独立席位（[[#def-yudiao]]）。
:::

::: summary
- 词有轻重格式：普通话双音词以“中重”为主干，轻声是重轻式的固化；汉语音节整齐，重音弱势。
- 双音节是标准音步；成语、骈文、标语的四字偏爱都是音步投影；音步不越词界。
- 停处分语法与修辞两类，标点只是提示；“停在哪里，意思在哪里”。
- 逻辑重音搬信息焦点，乐器是时长、音域、清晰度，**不得改动调型**。
- 语调分升降平曲四式，与字调两层共存：语调搬音域、声调保形状——倒字与洋腔都是串层事故。
:::

## 习题

::: exercise 音步切分 {level=1}
给“现代汉语很难”按自然音步与虚词寄生规则标出读法（用“／”分拍），并解释为什么不是“现代／汉语／很／难”。
::: solution
自然读法：现代汉语／很难（“现代汉语”两两成双，“很难”里“很”寄生于“难”，一拍）。四拍切法把虚词立成了独立拍、又把语义“很难”拆散——停顿多而碎即“碎读”，是朗读初学通病。判断口诀：一拍两实词，虚词不占拍。
:::

::: exercise 找重音 {level=1}
“他昨天借给我一本书。”针对六种追问（谁借的？/ 什么时候借的？/ 借给谁？/ 借的是什么？/ 是借不是买？），指出逻辑重音应落在哪个词。
::: solution
谁借的——“他”；什么时候——“昨天”；借给谁——“我”;借的是什么——“书”；是不是借——“借”；“给”与“我”之间强调接受方向时重音在“给”。六问六答各动一词，调型无一改变——本题即[[#ex-liuge-zhongxin]]方法的复做，熟练即得。
:::
:::

::: exercise 语调的语用清单 {level=2}
听一段二十分钟的访谈或播客，记下八处句尾：各是升降平曲哪一式？说话人想达到的效果（求证、封顶、留话、调侃）是什么？整理成一张两列表。
::: solution
样本参考走向：嘉宾陈述事实多降尾（封顶，不留讨论口）；举例未完用平或微升（留话，“还有下文”）；主持人追问高升（求证）；玩笑话配曲调或怪重音（调侃信号）。合格线：每处都能报出“尾向＋功能”配对；若一段谈话八句全用同一尾势，恭喜你采集到“机器朗读”标本——回去重听，多半是照稿念。
:::
:::

::: exercise 语调配型 {level=1}
给下列句子各配一种语调（降／升／平／曲）并说明理由：（1）“这事我不同意。”（立场坚定）（2）“你们这是搞什么名堂呀。”（质问）（3）“说也说不完。”（无奈）（4）“您可真是个大人物！”（讽刺）
::: solution
(1) 降调：结论、命令之骨干；(2) 升调：疑问句家族；(3) 平调：无力、拖延的情绪色彩；(4) 曲调：字面捧、意里贬，双关归曲（“大人物”上再加逻辑重音）。四句各可辩论边缘读法，主型如上——能“辩论边缘”正说明规则是倾向而非枷锁。
:::

::: exercise 停连诊断 {level=2}
某主播读“本市将新建五座 跨江 人行景观桥”，把定语全断开了。请按层次给这个多层定语正确断法（哪里可停、哪里绝不许停、哪里可偷气），并解释“跨江”与“人行景观”之间的结构关系为什么决定切分。
::: solution
定语链：五座‖（跨江）‖（人行景观）桥。层级：“跨江”修饰“桥”（跨江的桥），“人行、景观”也修饰“桥”——两者是并列的定语而非互相限定（跨江的桥，供人行、具景观功能），故切分在定语之间，绝不可切进“人行／景观／桥”? 内部“人行景观桥”结合紧，宜连读；“五座”后是数量词边界，可停可不停；“新建”与宾语之间、动词与“五座”之间也可偷气（逗号前换气）。错断（“跨江 人行”连读）会让听者以为“人行跨江”，把修饰语捆错了对象——**定语内部不乱捆，动词宾语不留白**，是停连的两条铁律。
:::

::: exercise 重音与调型的仪器作业 {level=2}
用任意能画基频曲线的手机软件（语音分析类均可），录“我请他吃饭”分别强调“我”“他”“吃饭”三遍，观察：被强调字的基频曲线形状变不变？句尾走向变不变？写二百字结论。
::: solution
预期观察：强调处基频**幅度放大**（曲线拉陡）、时长加长，但“请 qǐng”“他 tā”的升降形状仍保持；全句尾部走向随语气（陈述微降）。凡有人把“请”读成一路向上充强调，上声形状就串成了阳平，正是[[#def-luoji]]警告过的违规现场。结论应落在“两层分工”上——语调改音域（软装），声调保形状（承重墙）（[[#rule-liangceng]]）。
:::

::: exercise 一段的乐谱 {level=3}
自选一段三百字内的散文（版权安全：用公版文如朱自清《春》开头或自写），为它标一份“朗读谱”：停连（∨∧）、重音（·）、语调走向（↘↗→）与语速变化（快慢记号），并给三个关键标记写一句理由。
::: hint
先默读定“意思地图”（信息重心在哪几句），再上标记；标完自己读一遍并录音，检验“听录音能否不看点就听懂层次”。
:::
::: solution
合格线：①停顿层次与句法层次一致（不切破词、不误捆定语）；②每段只有一两个主重音，逻辑重音用在对比处；③句尾语调多样（不句句同调）；④快慢随内容（叙述快、抒情缓，排比渐强收得住）。三个理由须各引一条规则（[[#def-tingdun]]、[[#def-luoji]]、[[#def-yudiao]]）为凭——“凭感觉好听”只能得一半分。
:::

::: exercise 倒字侦探 {level=3}
听一首你熟悉的流行歌，找出一个“倒字”处（唱出来易听成别字的词，或粉丝圈常玩梗的空耳），用本章两层理论解释：旋律给了怎样的“语调”，毁掉了哪个字的“声调形状”？再想：为什么有些歌（如某些南音体系或戏曲化唱腔）几乎不倒字？
::: solution
示例分析框架：某句旋律在高音区下行唱“想你”，若“想”被配成一路上挑的旋律线，听者按阳平解码成“翔你”——旋律的“语调层”压过了字调层，调型形状被改写，辨义跟着翻车。不倒字一方的办法正是“依字行腔”：旋律线给字调形状让路（阴平平直、上去声配下行尾等），或用衬音垫腔过渡。评分看：调型—旋律的对应分析是否专业、举例是否可复核（注明曲目段落），不许编造唱词。
:::
