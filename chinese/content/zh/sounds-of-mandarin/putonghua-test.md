普通话水平测试（PSC）是世界上规模最大的语言标准化考试之一：自 1994 年建立以来，教师、播音员、公务员、千万在校生走进考场，把这一章前八节的全部知识折算成一张百分制成绩单。它也因此是最好的“期末模拟器”：四个大题各查一层的功夫——单字词查声韵调的底子，词组查轻声儿化变调的自动化，朗读篇章查语流里的停连语调，命题说话查脱稿状态下方音会不会“回潮”。这一章把测试讲成一张可以照着执行的备考地图，顺便把朗读这门手艺本身教给你。

## 测试是什么：制度与分数

::: definition 普通话水平测试 {#def-putonghua-test}
**普通话水平测试**（Putonghua Proficiency Test）由语言文字工作部门与测试机构组织实施，测查应试人掌握普通话**规范通语**的程度——注意测的是“规范程度”，不是方言出身，也不是口才。1994 年由原国家语委等部门联合建立，2000 年《国家通用语言文字法》施行后获得法律依据；制度与大纲多次修订（2003 年《普通话水平测试大纲》、2021 年《普通话水平测试实施纲要》推行机辅机考），分值框架二十余年未变。教师、播音主持、服务行业等岗位依规定持有相应等级证书（教师资格一般要求二级乙等以上，语文教师多要求二级甲等以上，播音相关岗位要求一级——以当地文件为准）。
:::

::: theorem 卷面结构（现行框架） {#rule-juanmian}
四题连考，全程约十七分钟：
一、**读单音节字词** 100 个，10 分，限时约 3 分钟——每字只考本调单字音，**不作任何变调**；
二、**读多音节词语** 50 组，20 分，限时约 2 分钟——轻声、儿化、上声变调、“一不”变调的埋雷区；
三、**朗读短文** 1 篇（从公布的六十篇中选），30 分，限时 4 分钟——查语流：停连、重音、语调、速度、添字漏字回读各扣各的分；
四、**命题说话** 3 分钟，40 分，从当批话题中抽其一——独白，查“没人盯着还说标准不标准”。
:::

::: theorem 等级分数线 {#rule-dengji}
一级甲等 **97 分及以上**（需经国家测试机构复审认定）；一级乙等 92；二级甲等 87；二级乙等 80；三级甲等 70；三级乙等 60。三级六等，60 分及格线以下不予等级。分数由系统初评加人工复审合成；一级甲等的“复审线”设计，是因为 97 分以上语音瑕疵已近耳力极限，需要更严的一双耳朵把关。
:::

labels: 四题累计满分
caption: 分数结构的台阶线：单字词 10 → 词组 30 → 朗读 60 → 说话 100。一眼看穿备考权重的秘密：**命题说话占四成，朗读占三成**——多数考生把八成力气花在只值三成的“读准字”上，本末倒置。声韵调的底子当然重要（它决定说话题的上限），但分数本身长在语流里。

::: example 分数判等 {#ex-pandeng}
某考生：单字词 9.2、词组 17.6、朗读 25.4、说话 34.0。她是什么等级？失分结构说明她最该补什么？
::: solution
总分 86.2，二级乙等（80 ≤ 86.2 < 87，差 0.8 分即二甲——常见“卡线”惨案）。失分率对比：单字 8%、词组 12%、朗读 15.3%、说话 15%——失分随“自由度”上升而放大，典型的**单字音过关、语流自动化不足**画像：单字能读对，连读时调值打折、停连生硬、方音回潮。处方不是再背字表，而是每天朗读计时录音＋两三分钟说话自述（[[#ex-shuohua]]），把“对”练成“自然”。
:::
:::

## 单字词与词组：埋雷与排雷

::: warning 单字题的第一雷是“想多” {#warning-danzi}
读单音节字词**一律读本调**：不连读变调（“管理”拆成两张卡片，各读各的 214）、不轻声、不见儿化拼写就卷舌。“北”字卡片读 běi 满调，别滑成 bě·；“儿”字卡片读 ér，别读成 r。手滑的根源是词感太好——把相邻卡片在心里连成了词。遮行法（手指压住下一行）可解。
:::

::: theorem 词组题的雷区分布 {#rule-ciLei}
50 组词组通常埋三类雷：**变调类**（上声连读、一不变调——读原调即错）、**轻声类**（测试词表内的轻声词读满调扣分）、**儿化类**（词表儿化词不卷舌扣分；反过来，词表外的“*水儿”硬卷也算错）。另有习惯性误读字（“档案 dàng”读成 dǎng、“畸形 jī”读成 qí、“气氛 fēn”读成 fèn——多为 1985 年审音表统读前的旧读残存）与生僻声韵（“有、与”类 r-、零声母 u 起头的字）。排雷法无他：**过表**——大纲词表逐词自测录音，把“认识但读错”的揪出来，这批词通常只占词表百分之几，却贡献了考场大半失分。
:::

::: example 五个词的自测 {#ex-wuge}
“奶奶、月亮、使劲儿、不仅、处理”——先自读录音，再对照：各组考什么？
::: solution
奶奶 nǎi·nai：考轻声（后字轻短、音高 4 度，见[[sounds-of-mandarin/sandhi]]的轻声图）；月亮 yuè·liang：考词典轻声词（读满调 liáng 即错）；使劲儿 shǐjìnr：考儿化（合音为一个音节，读成“劲·儿”两音节扣分）；不仅 bùjǐn：考“不”在本调 51（“仅”是上声，**不变调**——“不只在去声前变”的反向陷阱）；处理 chǔlǐ：考“处”chǔ 上声的动词读音（读 chù 即错，处分/处理/处置各归各位）。五个词覆盖五个雷种，是“自测样本”的密度极限；真正的排雷要过完整词表。
:::
:::

## 朗读短文：四十年的六十篇

::: definition 作品朗读题 {#def-langdu}
从**六十篇朗读作品**（《普通话水平测试实施纲要》附目录，现代名家散文与说明文节选，累计约六千字量级的篇目群）中当场抽一篇，四分钟内读完全文（约四百音节）。评分四管齐下：**语音准确**（声韵调错误逐音节扣）、**语调与停连**（该停不停、不该停乱停、句句同调都扣）、**流畅度**（语速失控、断裂停顿过多扣分；读错**不回读**——回读按瑕疵计，改对了也算错）、**添漏字**（口误吞字添字逐处计）。六十篇受版权保护，练习须购正式出版物或官方材料；本图谱只教方法、不印课文。
:::

::: theorem 朗读的四层功课 {#rule-langdu-si}
（一）**字**：逐篇过生僻词（“伧俗”“罅隙”一类的书面词，以所选篇目实际词表为准），标音自读；（二）**连**：按音步与句法标停连（[[sounds-of-mandarin/stress-intonation]]的朗读谱法），虚词不占拍；（三）**调**：句尾走向多样（陈述降、疑问升，不句句上挑）；（四）**速**：每分钟二百二到二百六十音节为宜（各家播音教材区间略异），**宁慢勿碎**——慢而连贯高于快而切碎。录音自查三遍：第一遍对字，第二遍对停连，第三遍只听“像不像说话”。
:::

::: example 一次带伤的朗读 {#ex-shang}
某生读自拟长句“她轻轻地合上了那本厚厚的书”，读成“她轻／轻地／合上了那／本厚厚的书”，并把重音砸在“那”字。按本节的四层功课指出失误并给出改正读法。
::: solution
两处切分都切破了词：“轻轻”是重叠式状态词、内部不许下刀，“那本”是指示词加量词的紧密结合体、同样不能拦腰——正确停连：她轻轻地／合上了／那本厚厚的书（“地、了”寄生，节拍点全在双音节组上，见[[sounds-of-mandarin/stress-intonation]]的音步规则）。重音方面：本句的信息焦点是“合上”这个动作与“厚厚的”这个状态，“那”只是虚指限定，重音砸过去等于告诉听者“我不知该强调什么”。改正后录音回听：断点落在结构边界、重音落在实词焦点，即为合格。顺带一条考场纪律：这类失误**不当场回读**——改也来不及，读下去，流畅比一个字的面子值钱。
:::
:::

## 命题说话：三分钟的照妖镜

::: definition 命题说话题 {#def-shuohua}
从当批话题（历版大纲各备三十个，多为“我喜欢的季节、我的愿望、童年往事、学习方法”一类的短题作文式话题）抽其一，作**三分钟单向独白**。评分三大件：**语音标准程度**（方音的浓度与系统性）、**词汇语法规范**（方言词、方言句式、口头禅“然后、那个”过频都扣）、**自然流畅**（背稿痕迹、长时间卡顿、离题都扣）。它占四十分，是全卷最重的一题——也是最能区分“会读”与“会说”的一题。
:::

::: warning 背稿与“去脚本化”训练
机考时代的说话题配有**重复率与韵律监测**：背范文、背“万能稿”会被降档扣分（各测试站执行口径从严）。正路是按话题群各备**提纲**而非文稿，练“开口即提纲”的功夫：观点句＋两例＋收束句，边想边说、语速降档、容许修补（“或者说”是合法的自然修补，背稿的零修补反而可疑——评分员的经验：**完美即嫌疑**）。每周三次三分钟自述录音，方音、语法、口头禅各听一遍，是三到四周内提升说话题最陡的学习曲线。
:::

::: example 三十话题的备考账 {#ex-shuohua}
“我喜欢的动物、我的心愿、一件难忘的事、谈诚信、学会宽容……”面对三十个话题，如何以最少份的准备覆盖全库？
::: solution
**积木法**：把话题按骨架归并——“写人”组（尊敬的人、朋友、老师……共用一个“人物积木”：身份一句＋特质两句＋事例一段＋感受收尾）；“叙事”组（难忘的事、童年、一次经历……共用“事件积木”：起因一句＋经过四句＋当时心情＋今天回想）；“说理”组（诚信、宽容、环保……共用“观点积木”：立场一句＋正反各一例＋自身做法＋升华一句）。三十题归约成五六个积木，考场上按题装配：**装提纲，不背句子**——既避重复率红线，又保“想与说同时”的自然度。语音端另备一册：把方音体检单（[[sounds-of-mandarin/dialect-differences]]）上合并过的音对着“说”练，专名、数字、儿化词做口头替换操，让正确的音在自由语流里也赢。
:::
:::

::: quiz
朗读短文时读错了一个字，正确的考场策略是（　）。
- [ ] 立即回读纠正
- [x] 继续往下读，不回读
- [ ] 跳过该词
- [ ] 放慢速度示意“我知道我错了”
::: solution
回读按不流畅计、且原误仍记（[[#def-langdu]]）；跳读则添“缺读”新账。唯一不加重损失的是继续读——错一个字扣语音分，慌神回读要赔上流畅分与节奏。心态同理适用于说话题：修补一下口误继续说，恰是“自然”的表现。
:::
:::

::: history
“测一口普通话”的制度之路：1955 年确定普通话标准后，师资与播音队伍先行考核；1986 年全国语言文字工作会议提出“加强普及普通话工作”，九十年代初部分省市试点等级测试；**1994 年**国家语委、国家教委、广播电影电视部联合推行普通话水平测试，等级标准与规程渐次成型；1998 年起每年九月“推广普通话宣传周”把测试带入公众视野；2000 年《国家通用语言文字法》以法律条文确认“普通话和规范汉字”的国家通用语言文字地位，并对教师、播音、公务、公共服务诸行业提出达标要求；2003、2021 两版大纲把考试推上机考与人工智能评测的轨道——一套纸笔口试四十年的最终形态，是把“耳朵的共识”写成“分数的共识”。
:::

## 后续内容

备考的技术支撑都在本章上游：单字音诊断见[[sounds-of-mandarin/speech-sounds]]至[[sounds-of-mandarin/tones]]，词组雷区的规则账在[[sounds-of-mandarin/sandhi]]，朗读的停连语调在[[sounds-of-mandarin/stress-intonation]]，方音底账与矫正工程在[[sounds-of-mandarin/dialect-differences]]。测试之外，把普通话说得“好听”属于演讲与朗读艺术，本图谱暂未开课；而“该说得多标准”的社会学答案，见[[dialects/fieldwork]]里发音人在话筒前与灶台旁的两副口音——标准不是羞耻的别名，是能力的量程。

::: summary
- 测试四题十七分钟：单字词 10、词组 20、朗读 30、说话 40；三级六等，二甲 87、一乙 92、一甲 97（另加复审）。
- 单字词读**本调**、不作变调；词组题埋变调、轻声、儿化、统读四类雷，过表是唯一排雷法。
- 朗读查“字—连—调—速”四层，宁慢勿碎、错不回读。
- 说话题最重也最难：去脚本化，备提纲积木不备范文；自然度上“完美即嫌疑”。
- 备考权重跟着分数走：把练读的时间分一半给“脱稿说”，等级立刻不同。
:::

::: exercise 判等级 {level=1 check="87"}
某考生总分 88.5，获普通话水平测试的等级是二级几等？（填“二甲”所对应的分数线数字，即该等级的最低分。）
::: solution
二级甲等（87 ≤ 88.5 < 92，故为二甲）。注意 87 分正是二乙升二甲的门槛线，88.5 已稳在档内。

::: exercise 单字还是语流 {level=1}
判断下列读法在“读单音节字词”题中是否扣分：（1）“好”读满调 214；（2）“们”读轻声；（3）看到相邻两字“管理”便把“管”读成 35。
::: solution
（1）不扣——单字读本调正是要求（[[#rule-juanmian]]）；（2）要扣——“们”卡片单读也应读其本调 mén（满调），读轻声是“自作变调”；（3）要扣——连读变调只发生在语流，卡片之间不发生（[[#warning-danzi]]）。本题专治词感太好的人。
:::
:::

::: exercise 排雷清单 {level=2}
给词组题自拟一张“雷区五类”清单（变调、轻声、儿化、统读旧读、易混声韵各举两词），并按[[sounds-of-mandarin/dialect-differences]]的方法给自己各标“已过/未过”。
::: solution
参考样例：变调（水果、一定）；轻声（月亮、事情—以词表为准）；儿化（小孩儿、没准儿）；统读旧读（档案 dàng、卓越 zhuó）；易混声韵（“牛”n 与“留”l、“更”eng 与“根”en）。自查三步：自读录音、对《现汉》注音、错词入本——三周内错词重测两轮，通过率即备考进度条。
:::
:::

::: exercise 六十篇的用法 {level=2}
你没有官方朗读教材，只找到同学借抄的半篇课文。请按本章给出合规而有效的两周朗读备考方案（材料、每天任务、自评指标）。
::: solution
材料合法获取是第一步：大纲朗读作品目录公开，各篇收于正式出版物（教材或测试配套读本），借抄残篇不足以备考。方案骨架：第 1—7 天每天一篇——生词标音（字层）、标停连朗读谱（连层）、掐表读两遍录音（速层：二百二至二百六音节/分钟）；第 8—12 天第二轮，每篇改“读＋说”打包：读毕脱稿复述大意一分钟（给说话题搭桥）；第 13—14 天模拟：随机三篇连考全流程。自评三指标：错字数、停顿次数、句尾语调重复率——逐日记表，曲线比感觉诚实。
:::

::: exercise 给说话题搭骨架 {level=3}
从“说理”组任选一题（如“谈诚信”），写一份**只有提纲**（不超过十行）的三分钟说话骨架，并说明每段的时长配额与防背稿机制。
::: solution
样例骨架：立场（诚信是默认契约，20 秒）→ 正面例：还伞的经历（50 秒）→ 反面：考场作弊的代价（50 秒）→ 自身做法：借书按时还（20 秒）→ 收束：信任是慢存款（20 秒）。防背稿三招：只写关键词不写句；录音时允许“换个说”；同一骨架换不同事例练三遍——考场装配件，不装录像带。评分看：骨架是否五件齐全、时长是否凑得满三分钟（宁可留十秒余量，不要超时被打断）、有没有写出你的具体事例（空转大词按“内容空泛”扣分）。

::: exercise 一张成绩单的处方 {level=3}
某方言区考生两次成绩：第一次 79.5（单字 8.6／词组 16.0／朗读 23.0／说话 31.9），第二次 83.0（9.2／18.4／25.8／29.6）。请构造一份自洽的“第二次成绩＋诊断＋下一步处方”短评（二百字内），解释为何“说话分不升反降”值得警惕。
::: solution
参考结论：字、词、朗读全线上升而说话题下降，几乎总指向同一病因——**应试化**：备考期集中刷字词与朗读篇目，脱稿口语荒废，考场上自由语流方音回潮、口头禅与卡顿增多（“完美即嫌疑”的另一面是“生硬即掉线”）。处方：字词训练减量到每天十分钟保温，每周新增三次三分钟自述录音＋一次三分钟朗读+复述打包；下次考前两周做全真模拟三次，模拟分与实考分的差值应进入一分之内的可预测区间——“分数稳定”本身就是合格的信号。
