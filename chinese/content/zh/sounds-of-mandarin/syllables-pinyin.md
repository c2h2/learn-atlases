“西安”与“先天”，连起来都写作 xian 开头，却要写成 Xi'an 和 xian——一个撇号隔开的是两座城市与一个成语的先机。音节是汉语发音的“呼吸单位”，拼音是把这套单位转写成拉丁字母的工程方案：它既有语言学原理（音位概括、互补归并），又有历史习惯（知不送气读 zh、撮口去两点），还有正词法的社会学（词连写、专名大写）。这一章把三件事分开讲清楚：普通话的音节能长成什么样（结构）、《汉语拼音方案》怎样书写它们（拼写规则）、以及按词连写时的正词法。学完你应该能做到：见到任何拼音立刻还原出它的音值结构，见到任何念法立刻判断它“拼不拼得出”，并解释方案里每一条看似“多此一举”的规则其实都不多余。

先声明本章的三件工具：方括号 [ ] 记实际音值、斜线 / / 记音位、不带括号的小字母串记**拼音拼式**（如 zhī）。三层各查各账，是本课从头到尾的规矩（[[sounds-of-mandarin/speech-sounds]]）。

## 音节：呼吸之间的一次成调

::: definition 音节 {#def-yinjie}
音节是发音上最自然的活动单位：一次用力、一落一起的响度起伏形成一个音节。汉语里汉字与音节大体一对一（“人”一个音节），例外主要是儿化（“花儿”两个字读一个音节）与少量合音形式（“俩”是“两个”的合音、“咱”是“咱们”的合音；它们的归类各家有争议，教学上仍以一字一音为常轨）。
:::

::: definition 普通话的音节模板 {#def-muban}
普通话音节的最完整格局是：**(声母)＋(韵头)＋韵腹＋(韵尾)＋声调**，括号表示可有可无，韵腹与声调两格永远占着。韵尾只收元音 i、u 或鼻音 n、ng；声母位置单一，不收辅音串。任何合法音节都是这五格的一种填法：他 [tʰa⁵⁵] 占三格，窗 [tʂʰuaŋ⁵⁵] 五格全满，安 [an⁵⁵] 空着声母格。
:::

::: theorem 普通话不开辅音串 {#rule-jujin}
普通话的合法音节没有声母串或韵尾串：音节开头至多一位辅音（或不填），结尾至多一个元音尾加一个鼻音尾。i、u 作韵头、韵尾时是滑音性的，不参与“辅音连缀”的账。
:::

::: proof 一个只放单人过关的海关
英语 *strengths* 一个音节里塞得进八个音素；普通话连 sp-、-nts 这类组合都不存在，声母、韵尾都只许“单人进出”。至于上古可能的复辅音，今天只以化石面目留在少数双音联绵形式里——《尔雅·释器》“不律谓之笔”，“不律／笔”的对应被一些学者视为复声母的孑遗（此说尚有争论，见[[history-of-chinese/old-chinese-language]]）。海关的宽严是历时的账：中古的 -p、-t、-k 韵尾与全浊声母都退关了，北方话如今只放行这张五格表。类型学上，汉藏语系多数语言的音节结构都比印欧语“干净”，普通话是其中最严的一档。
:::

模板五格，为什么日常却说普通话“没有多少音节”？算一笔乘法账：21 个声母（加零声母共 22 个开头）乘 39 个韵母，理论上限八百多；扣掉四呼配合的种种限制（唇音不拼撮口、舌面只拼齐齿与撮口……），再扣掉历史上从未派过字的组合（模板放行、词库无账，见后面诊断题），实数只剩**四百多个不带调音节**；乘上四声（再扣轻声与“调不成字”的空格），《现代汉语词典》一类的常用字表里约摸**一千二百多个带调音节**。英语的可用音节数以千计且允许多音节词几乎自由造“响”，汉语则像一副固定张数的牌——信息密度因此更多押在声调与语境上，这是“汉语为什么单音节语素占优、四声为什么如此重要”这一大问题的算术背景，语言学课[[linguistics/language-and-linguistics]]接着谈。

::: example 给 shuāng 拆到底 {#ex-shuang}
按[[#def-muban]]拆“双 shuāng”，写出五格的每一项与音值，并算这个音节含几个音段音位。
::: solution
声母 sh [ʂ]；韵头 u [u]；韵腹 a [a]；韵尾 ng [ŋ]；声调阴平 55。音段音位四个（/ʂ u a ŋ/）；字母却有六个，因为 sh、ng 各以两个字母记一个音位。本题顺带复习字母账：拼音的字母数从不是音位数的可靠指标（[[sounds-of-mandarin/finals]]）。
:::
:::

::: example 四字模板测验 {#ex-sige-muban}
判断下列念法能否成为普通话音节，能者给出拼音与例字，不能者说明卡在哪一层：（1）[kuaŋ²¹⁴]；（2）[pʰi²¹⁴]；（3）[kaŋ⁵⁵]；（4）[m̩³⁵]。
::: solution
（1）[kuaŋ²¹⁴]＝广，合法，五格全满。（2）[pʰi²¹⁴]＝痞，合法，拼 pǐ。（3）[kaŋ⁵⁵]＝冈，合法。（4）[m̩³⁵] 是成音节鼻音（感叹词“呣”一类）：不经韵腹格而自成音节，方案在韵母表后特别以附注安顿它，教学语法一般不记入 39 韵母账（[[sounds-of-mandarin/finals]]）。本题的用意：模板判“合法”，字典判“有字”，使用频率判“常用”——三本账都得会查。
:::
:::

## 《汉语拼音方案》是一本说明书

方案 1958 年由第一届全国人民代表大会批准，正文六件：字母表、声母表、韵母表、声调符号、隔音符号，以及字母用法的附注条款。它给 26 个拉丁字母规定了名字与职司，给声母表的 21 个呼读音与韵母表的 35 个韵母规定了写法（ê、两个 -i、er 等表外户口另有安置，与黄廖本 39 账的口径出入见[[sounds-of-mandarin/finals]]），给四声规定了符号（阴平ˉ、阳平ˊ、上ˇ、去ˋ，轻声不标），并立下几条“变形规则”。方案的第一原理是**音位化的省俭**：一个音位原则上一次写法，条件变体归并书写。字母与音值的对应里，最“反直觉”的一批如下：

| 字母 | 音值 | 字母 | 音值 |
|---|---|---|---|
| b、d、g | [p]、[t]、[k] 清不送气 | zh、ch、sh | [tʂ]、[tʂʰ]、[ʂ] |
| p、t、k | [pʰ]、[tʰ]、[kʰ] 送气 | r | [ʐ]（或记 [ɻ]） |
| j、q、x | [tɕ]、[tɕʰ]、[ɕ] | z、c、s | [ts]、[tsʰ]、[s] |
| zi、ci、si 的 i | [ɿ] | qi、xi 的 i | [i] |
| yi、wu、yu 的 y、w | 零声母的书写装置 | ü（或写作 u） | [y] |

::: theorem 拼写变形四条 {#rule-pinxiu}
（一）**ü 的去点**：ü 行韵母跟 j、q、x、y 相拼时省两点（居 jū、全 quán、月 yuè）；跟 n、l 相拼保留两点（女 nǚ、绿 lǜ、略 lüè）。
（二）**三尾缩写**：iou、uei、uen 前面加声母时省作 iu、ui、un（牛 niu、对 dui、论 lun）。
（三）**零声母改写**：i 行韵母零声母时改 y 头（衣 yi、牙 ya、云 yun），u 行改 w 头（乌 wu、窝 wo），ü 行加 y 且去两点（鱼 yu、元 yuan）。
（四）**隔音符号**：a、o、e 起头的零声母音节连在其他音节之后、可能被误会成一个音节时，中间加隔音撇号（方案原例：皮鹅 pí'o；实用例：西安 Xī'an）。
:::

::: proof 每条规则省在一处、补在一处
ü 去点，是因为 j、q、x 根本不拼 u 类合口（[[sounds-of-mandarin/finals]]的分配规律），两点省而不混；n、l 两组既拼 u 又拼 ü（路 lù／绿 lǜ），两点必须留。三尾缩写是高频的产物——iou、uei、uen 是普通话最忙的几条韵，拼式短一笔，课本与电报就省一笔；代价是书面不再显示“流 liú”的韵腹，教学语法年年为此补课。零声母改写 y、w，为的是“音节看得见边界”：y、w 本身就是边界标记，大多时候撇号可省，易混处才出手。一套拼写法的好坏，全在“经济”与“防混”这架天平两端摆得准不准；1958 年的设计，经受住了六十年键盘输入与字典排序的检验。顺带交代 v 的身世：方案字母表收 26 字母，但 v 不拼普通话固有音——它留给方言、少数民族语言与外来语的记音，于是 ü 在键盘上借 v 安身（lü 打 lv），成了民间事实标准；字典排序则把 ü 附在 u 部之后。字母、音位、键帽，三层之间处处是这种“权宜成了制度”的年轮。
:::

::: example 调号落谁头上 {#ex-diaohao}
指出 jiǔ（九）、guī（归）、wén（文）、tiān（天）四式调号的“户主”，并归纳规则。
::: solution
韵腹是 a、o、e 的，调号标在它们头上（tiān、wén）；iou、uei 缩写成 iu、ui 后，调号标在**后一个**字母上——jiǔ、guī；i、ü 标调去点（jiā、nǚ）。教学顺口溜“有 a 不放过，无 a 找 o、e，i、u 并列标在后”是同一规则的儿歌版。
:::
:::

::: quiz
“全 quán”的韵母是什么？
- [ ] uan［uan］
- [x] üan［yɛn］，跟在 q 后省了两点
- [ ] uen
- [ ] ien
::: solution
撮口 üan；声母 q 之后两点按规则省去，写作 u——读“全”若真按合口 u 起头，就成了把“全”念近“船”的方音。方案“去点”条款的代价永远由舌头支付，不由笔头。
:::
:::

::: quiz
普通话不带调音节“四百多个”、带调“一千二百多个”，两个数相除约三倍，最接近四声之数的原因是什么？
- [ ] 每个声母恰好配四个声调的字
- [x] 绝大多数音节能分属四个调类，只有少数位置（如上声的冷僻韵）空着
- [ ] 轻声也算一声，所以不止三倍
- [ ] 数字来自不同字典，纯属巧合
::: solution
四声是套在几乎所有音节上的“公共帽子架”，于是带调数≈不带调数×4 再扣空缺；空缺并不规则，正是查账的乐趣（[[#ex-sige-muban]]的三本账）。C 项的“轻声也算”会破坏调类账（见[[sounds-of-mandarin/tones]]）。
:::
:::

::: quiz
下列拼写**不合**方案的是哪一项？
- [ ] 皮鹅 pí'o
- [ ] 旅游 lǚyóu
- [x] “远”写作 yüǎn
- [ ] 儿 ér
::: solution
ü 行零声母加 y 且去两点（鱼 yu、月 yue、远 yuan），从不写 yü。“旅游”的 lǚ 必须带两点，因为 l 组存在 u／ü 对立（“鲁／旅”）——同一个字母，在 y 后裸奔、在 l 后戴帽，全看有没有对头。
:::
:::

## 按词书写：正词法

拼音的第二个战场在词。《汉语拼音正词法基本规则》（GB/T 16159—2012）的原则一句话：**以词为连写单位**——“人”rén、“人民”rénmín、“人民医院”作 Rénmín Yīyuàn（专名按词分写、各词起头大写）。专有名词各有细则：人名姓前名后、名的各字连写（Lǐ Xiǎobái），地名专名与通名分写；大写与移行另有规定。“词”的边界争议（“火车”是一个词还是两个词？）会一路跟到拼音里，但日常应用只需记住三件事：连写按词不按字，专名首字母大写，隔音撇号别丢——Xian 是“先”，Xi'an 才是西安。

::: example 一张拼音名片 {#ex-mingpian}
把“李小白，北京大学的汉语教师”按人名规则与正词法拼写。
::: solution
Lǐ Xiǎobái，Běijīng Dàxué de Hànyǔ jiàoshī。要点四条：人名姓前名后、名连写、首字母大写；“北京大学”按词分写、各取大写字头；虚词“的”轻读、小写、分写；普通词“汉语、教师”各按词连写。西文语序的场合可作 Xiǎobái Lǐ，姓仍建议全拼且不大写成 LI（正词法的宽容度按场合递增）。
:::
:::

::: warning 三个高频拼写事故
其一，“西安”写成小写连排的 xian，与“先”撞车——专名必须大写起头且加撇：Xi'an。其二，“绿”写成 lǔ——ü 在 l、n 之后必须保留两点，写成 lu 就成了“鲁”。其三，“九”标成 jiù 或 jiǔ 而调号落在 i——iu 的调号规定落在后一个字母 u 上，且“九”是上声。规则冷冰冰，事故全在热气腾腾的笔头上；下笔拿不准，回[[#rule-pinxiu]]对条款。
:::

::: history
给汉字配字母的设想起于晚清。1892 年卢戆章《切韵林音鉴》开先声；其后“切音字运动”（十九世纪九十年代至民国初年）造出二十多种方案，影响最大的是王照《官话合声字母》（1900 年成书）——取假名式笔画、照官话声韵两拼。1918 年注音字母公布（见[[phonology/fanqie]]所在一线的近现代史），1928 年政府又公布拉丁字母式的《国语罗马字拼音法式》作为“第二式”；三十年代拉丁化新文字运动主张拼音连词、方言分区，声势甚大。1949 年后成立专门机构、征集方案，周有光任中国文字改革委员会拼音方案委员会起草组组长，主持拟稿：1955 年 10 月全国文字改革会议听取草案说明，1956 年 2 月《汉语拼音方案（草案）》公布、征求全国意见，1957 年修订，1958 年 2 月 11 日第一届全国人民代表大会第五次会议批准。此后它的身份一路“晋级”：中国人名地名罗马字母拼写的国家标准、联合国地名标准化会议的采用方案（1977）、国际标准 ISO 7098（1982）、《国家通用语言文字法》（2000 年通过）规定的法定工具。设计者自比“拐棍”——方案不替汉字走路，只是扶着它把音说清楚；这一定位六十年未变。
:::

::: note 辨析：音标、拼音、注音的“名”与“实” {#note-sanzhongxiutong}
四种书写语音的东西，身份不同：国际音标是**转写工具**，一音一符、跨语言通用，严式带方括号；注音字母是**历史音标**，1918 年公布、今天仍在中国台湾地区通行，笔画式字形；汉语拼音是**法定拼写方案**，管字典、管地名、管键盘，不管严式记音；至于词典里的“音序检字”，是拼音的第三种用途。四套符号对同一个“知”字分别写作 [tʂʅ⁵⁵]、ㄓ、zhī、归“z”部——有人问“知怎么拼”，先问他要哪一种。
:::

::: application 你的键盘是一个音位学实验室
拼音输入法把本章规则做成了日常动作：输入 xi'an 时在 i 与 a 间断开——隔音条款由你亲手执行；打 lü 时键盘让你按 v——方案的“对头”规则转世为候选词；打 jiou 出不了“九”，因为词库只认 iu——省写条款内化成肌肉记忆。输入法的模糊音开关（in/ing、z/zh 互通）更有意思：它等于把官方不便明说的方音现实，做成技术妥协。语音输入与识别时代，音节模板又成为语言模型切词的底层假设——一套 1958 年的说明书，运行在 2020 年代的芯片上，字面意义上的“方案常青”。
:::

## 后续内容

音节的“能拼不能拼”依赖声韵配合的分配规律，其韵母账在[[sounds-of-mandarin/finals]]；语流中音节的声调与时长变形（变调、轻声、儿化）在[[sounds-of-mandarin/sandhi]]；拼音键盘输入把本章规则日常化——每个输入法都在替你执行隔音与省写条款；至于“方案今后会不会改”，截至 2026 年没有修订公布的计划，关注国家语词规范文件即可。

::: summary
- 音节模板＝(声母)(韵头)韵腹(韵尾)＋声调；普通话不开辅音串，韵尾限于 i、u、n、ng（[[#def-muban]]、[[#rule-jujin]]）。
- 汉字与音节大体一对一；儿化是“两字一音节”的常见例外。
- 方案是音位化＋经济＋防混的折衷：b、p 记 /p、pʰ/，ü 依对头戴帽脱帽，iou、uei、uen 声母后省写，y、w 标记零声母边界，撇号防误会，调号有户主。
- 方案韵母表 35 与教学 39 账口径不同——报数先报账法。
- 正词法以词连写；专名大写、人名连写、撇号防混，是日常三件事。
- 字母、音位、键帽是三层：v 顶替 ü、模糊音开关、字典音序，都是拼写在技术里的年轮——学拼写规则，顺便学了一部六十年的语言规划活史。
:::

## 习题

::: exercise 模板容量 {level=1 check="4"}
按[[#def-muban]]，普通话一个“五格全满”的音节最多含几个音段音位（不计声调）？
::: solution
4 个：声母、韵头、韵腹、韵尾各一（如“窗”/ʂ u a ŋ/）。声调另占一格，是超音段的——音段容量的天花板就是四。
:::
:::

::: exercise 找错别拼 {level=1}
下列拼式各有一处违规，改正并注明所犯条款：（1）xian（市名“西安”）；（2）lǔ（颜色“绿”）；（3）jiù（数目“九”）；（4）qü（动词“去”）；（5）nu（人女之“女”）。
::: solution
（1）Xī'an：专名起头大写，a 起头音节连后加撇。（2）lǜ：ü 在 l、n 后不可去点（“路／绿”对立）。（3）jiǔ：“九”是上声；iu 的调号本就标在后一个字母上。（4）qù：j、q、x 后的 ü 必须去点。（5）nǚ：“女”带两点且上声——省了点就成“努”。每题的处置都可由“有没有对头”推出：对头在，记号必须在；对头无，记号必省——方案的经济与防混，一句话讲完。
:::
:::

::: exercise 呼读音查账 {level=1}
声母教学念“玻、坡、摸、佛”，方案却说明这些只是字母与音节的“呼读音”。请解释：为什么单念 b 要带一个 o 的尾巴？这个 o 会不会误导学生对 b 音值的理解？
::: solution
纯塞音除阻后没有可持续的段，课堂上叫不应、拖不长，于是配一个短元音成音节来称呼它——呼读音是教学装置，不是音值记录（详见[[sounds-of-mandarin/initials]]的“玻坡摸佛”挑错题）。会误导：把“玻”[puo] 当 [p] 的实录，就会给 b 添出浊音或元音尾巴两种错觉；对治办法是本章反复练的三层分别——字母的名字、拼写里的值、实际音值，各查各的账。
:::
:::

::: exercise 模板卡壳诊断 {level=2}
一位学英语归来的朋友想练三个“普通话里没有”的音：[ŋi⁵¹]、[fai⁵¹]、[to⁵⁵]。逐项判定：模板放不放行？字典有没有字？“常用”又怎么算？
::: solution
[ŋi⁵¹]：不放行——ŋ 不在普通话声母清单里（它只在韵尾值班，见[[sounds-of-mandarin/initials]]），音节不合法；广州话、闽南语白读里有这个声母。[fai⁵¹]：放行而字典无账——f 拼 ai 结构合规，普通话却不收此音（“费”读 fèi，不是 fai；方言里“飞／灰”一类读近 fai 的另有其人）。[to⁵⁵]：同样“模板过、字典空”——“多”音 [tuɔ⁵⁵]，普通话无 [to] 一系（粤语“多”tɔ¹ 是它的分身）。结论：合法（模板）、有字（词库）、常用（频率）是三本账；方言对照与词典编纂，都在这三本账的落差里做文章。
:::
:::

::: exercise 给撇号找位置 {level=2}
判断下列合写词要不要隔音撇号，要则标出，不要则说明理由：西安、皮鹅、白衣（“衣”拼 yi）、名誉（míngyù）、感恩（二字皆零声母，合写一词）。
::: solution
西安 Xī'an：要——不隔会被切作“先 xian”一个音节，方案的标准例子正是这一类。皮鹅 pí'o：要——方案示例原词。白衣 bái yī：不必——按词分写，且“衣”写作 yi 自带边界符号。名誉 míngyù：不要——后字 yù 以书写符号 y 起头，音节界自明。感恩：写作 gǎn'ēn 更稳，写作 gannen 也读不坏——方案只规定“可能误会时”加撇，边缘处两可；答卷引用方案原文“可能误会”四字并写明自己的切分理由即可。
:::
:::

::: exercise 方案的取舍 {level=3}
“知”zhī 用双字母 zh，而不像某些方案为它造一个特殊字母；“女”nǚ 保留两点。用“经济—防混”天平分别为这两个决定各写一段辩护，再各给一条反对意见。
::: solution
zh 双字母：打字机与键盘零改装（经济），且与 ch、sh 同族成系统，好教好记（防混）；反方：拼式膨胀——“知道 zhīdào”五字母，若单字母记 [tʂ] 可省两笔，排版与电报时代实有其损。ü 的两点：在 n、l 后必须保留（“路／绿”对头在），在 j、q、x、y 后全脱（互补保证不混）；反方：“戴帽—脱帽”给初学者添了条件规则，不如像某些键盘方案一律写 v——现实里电子书写正是这样“二轨并存”的。两案在当年方案讨论中都有记载；本题练的是“为规范讲理”，立场不限。
:::
:::

::: exercise 音节表实地查账 {level=3}
用《现代汉语词典》（或任一按拼音排序的字表）完成：（1）找出声母 ch、韵母 uan 的各调例字（至少四个调各一字）；（2）说明字典音序为什么按 a、o、e、i、u、ü 排韵母而不是按口腔图排；（3）统计 chuān、chuán、chuǎn、chuàn 四调的字量，判断哪一调最忙、哪一调靠僻字撑账。
::: solution
示例：chuān（穿）、chuán（传、船）、chuǎn（踳，罕用）、chuàn（串、钏）。阴平、阳平、去声字都不少，上声最冷、常靠僻字撑账。字典音序是“音节模板＋拼写字母”的投影：韵母按拼写字母序（先主要元音字母后韵尾字母，ü 附于 u），不是口腔图——方案反身塑造了教学与检索，这是最好的一例。第三问只许用你手上的字典说话，注明页码；查证路径写清楚，比结论更值钱——这是语音课的实证底线。
:::
