说一声“妈（mā）”，你已经做成了三件通常要读到大学中文系才说得清的事。物理上，声带周期振动，产生了仪器可以记录的声波；生理上，肺部有控制地送气，声带靠拢振动，舌面平放，双唇张开，鼻腔通道关闭；社会上，我们从汉语的声音库存里挑出了 [ma⁵⁵] 这一个音，而不是 [ma⁵¹]（骂），也不是 [ma³⁵]（麻）。前两件事一切语言的声音都有，第三件——挑选、约定、辨义——才是语音独有的。这门课程从这里出发：普通话的声音系统究竟是什么，它们怎样发出、怎样听辨、怎样区别意义。这些母语者本来全都会做，却几乎没有人会说；把它们**说**出来，就是本课全部的工作。

## 语音与它的三种性质

::: definition 语音 {#def-yuyin}
语音是语言的意义借以表达的声音，是语言的物质外壳。它像一切声音那样是在空气中传播的波，具有**物理属性**；像一切随意动作那样由发音器官发出，具有**生理属性**；而一种声音成为语音，是因为一个社团把它用作意义的载体——于是有了最要紧的**社会属性**。
:::

三种属性不是三种声音，而是看待同一个声音的三个入口。物理学从声波进入：频率、振幅、时长、振动的构成；生理学从动作进入：谁在供气，谁在振动，气流在口腔的哪一处遇到阻碍；社会约定则规定——口所能发的那么多声音里，哪些被用来搭配意义，哪些音的差别算数、哪些不算数。分别以这三个入口为中心的科学是**声学语音学**（acoustic phonetics）、**发音语音学**（articulatory phonetics）和**音系学**（phonology），加上研究接收端的听觉语音学，就是语音学的版图。本课程以发音的分析为骨架，借声学的数据作证，把辨义的功能问题留给音位一节和[[linguistics/phonetics-phonology]]。

把不是语音的声音摆出来，可以做试金石。雷声、机器声只有物理属性，不消说。咳嗽、清嗓、打喷嚏出自身体的发声器官，却没有被任何语言的声音系统挑选过，不携带约定义，不算语音。婴儿半岁前的咿呀发声几乎能发出世界各种语言的音，到一两岁间逐渐“缩水”，只剩下母语的那几套——缩水发生在社会这一层，是母语音系接管发音器官的过程。感叹词“唉”“哼”拖着音有几分意义，却不进入各语言的音系、不参与造词，属于边缘现象；至于“语言”与“言语”的区分（语言是社会约定系统，言语是个人在具体场合对它的使用），提示我们：本课描述的普通话，是系统的普通话，不是任何个人嘴里的那一种。

::: quiz
下列各项中，属于语言学所说的“语音”的是哪一项？
- [ ] 风吹窗缝发出的哨音
- [ ] 婴儿玩兴正浓时的“ba-ba-ga”声
- [x] 说话人说“你”时发出的音节 [ni²¹⁴]
- [ ] 台下表示赞许的鼓掌声
::: solution
语音必须是担负语言约定意义的声音。风哨不是人发出的；婴儿的咿呀虽然用的是人的发音器官，音却还没有进入母语的系统，不携带约定义（他发的 ba 不等于任何一个词）；掌声是姿势不是音。只有“你”这个音节选自汉语的声音系统、承载一个确定的语法词——它是语音。
:::

## 语音的物理性质：音高、音强、音长、音色

声波是空气疏密振动的传播，物理性质有四样：**频率**（每秒钟完整振动的次数，单位赫兹 Hz）、**振幅**（气压变化的幅度）、**时长**和**振动的构成**（哪些简单振动以什么比例叠加，形成波形）。人耳对这四样的感知依次是**音高**、**音强**、**音长**和**音色**：频率高则音高，振幅大则音强，持续久则音长，波形不同则音色不同。同一音高上古琴与钢琴可以分辨，人群里能听出自家孩子的脚步声，靠的都是音色。

::: definition 音色 {#def-yinse}
声音的特色。它由基频之上叠加的泛音结构决定（声学上表现为若干被加强的频带，称为**共振峰** formant），追根究底有三项来源：发音体的性质、共鸣器的形状、发音的方式（碰、擦、吹、弹）。在语音里，第三项相对固定，音色的差异主要落在共鸣腔的形状上——这正是下一节的主题。
:::

音高取决于基频，但两者不是一个东西的两面：频率是声波的性质，音高是听到它的感觉。人能听到大约 16 到 20000 Hz 的声音，却只在其中一段敏感的区间里分辨音高——对基频差别（约 500 Hz 以下）人耳特别挑剔，这恰好覆盖了嗓音说话的全部范围。音强主要由振幅决定，可同一振幅的不同频率听起来并不一样响：两头（很低沉与很尖细）都显得弱——所以“悄悄话”并不比正常音量的同内容耳语“轻”。

“振动的构成”还划出一条对课程至关重要的线：**浊音**与**清音**。声带周期振动时，声波带着明显的周期，乐音成分占先，是浊音（voiced）；声带不带振动、气流挤过窄缝成噪，是非周期波，是清音（voiceless）。把手按在喉结上拖长“思——”与“么——”，前者喉头振动、后者没有，这就是清浊的生理标准。普通话的声母几乎全为清音，只有 m、n、l、r 四个浊音——这条看似琐碎的事实，将在下一章、也在英语母语者学中文的字典里反复出现。

最后交代四种要素在普通话里的“身份”。音长在普通话不辨义：“八”字拖长说或急说，都还是八，只关语速。**绝对**音高也不辨义：同一声调轮廓，男低音与女高音说的是同一个词。音强一般不单独辨义（它的用武之地是重音，见[[sounds-of-mandarin/stress-intonation]]）。唯独音高的**升降曲折**被系统征用了——轮廓不同就换词，这就是声调，本课程第[[sounds-of-mandarin/tones]]章的主角。声调是“音高的辨义用法”，不是音高本身，记住这个限定，后面就不会乱。

::: example 三个元音的差别在哪里 {#ex-sangeyuanyin}
[i]、[u]、[a] 三个音，尽量说得一样长、一样响、一样高，为什么依然一听两样？从物理与生理两方面分析。
::: solution
物理上：振幅、时长、基频都“一样”了，剩下的差别只能是波形，也就是音色。生理上：音色来自共鸣腔的形状，而三个音的腔形天差地别——发 [a] 时口大开、舌位低后，咽腔口腔合成一个大而敞的腔；发 [i] 时口腔前部被抬起的舌面压出一条窄槽，咽腔相对宽敞；发 [u] 时双唇拢圆前突，舌身后缩，口腔又狭又长。腔形不同，被加强的共振峰就不同，基频相同也判然两样。附带一条练耳的提醒：辨元音靠音色，辨音高靠声调——初学转写的人常把“录音里这个人换了个声调”误听成“换了个元音”。
:::
:::

## 语音的生理性质：发音器官与气流

发音器官天然分三段，把接收端算上则四段。第一段是**动力器官**：肺、横膈膜与肋间肌肉，管气流，是发音的发动机。第二段是**发声器官**：喉头与其中的声带。两条声带的松紧、长短、振动方式决定“有没有声、什么样嗓音”：拉紧而薄则音高高，放松则低。喉头里声带上方还有一对**假声带**（室带），平常不参与振动，某些语言（以及人刻意压着嗓子念经）会让它们参与，发出沙哑紧缩的音色。第三段是**共振腔与调音器官**：咽腔、口腔、鼻腔作共鸣器；口腔里唇、齿、牙、舌、硬腭、软腭诸部可动可挡，给腔塑形。舌是最活跃的调音器，习惯上分为舌尖、舌叶、舌面（前、中）、舌根；上门齿和齿龈是舌头抵靠的“砧板”；软腭和小舌是口腔通往鼻腔的闸门——抬起则关鼻，下垂则开鼻。此外还有通到鼻腔的一条岔路：气流从鼻出，是**鼻化**的音。同一条气流、同一只声源，经过不同的塑形，就是那么多种音色。

::: definition 气流机制 {#def-qiliu}
使空气流动起来以发声的机制，有三种：**肺气流**（肺部挤压，气流呼出或吸入）、**喉气流**（声门上下移动带动气流，内爆音与挤喉音属之，见于许多非洲与美洲语言）、**舌气流**（舌体在口腔内压缩再释放，如搭嘴音）。世界语言的绝大多数音、普通话的全部语音都是**肺部呼气音**；汉语里的咂嘴声、“嘁”等唤马声有吸音，但都不在语言系统之内。
:::

::: definition 辅音与元音 {#def-fuyin-yuanyin}
按气流出呼吸道时是否**明显受阻**划分：明显受阻的是**辅音**——阻碍可以在喉、可以在口腔，可以完全封死（塞音），也可以只留窄缝让气流摩擦（擦音）；不明显受阻的是**元音**。注意清浊**不**参与这条界线：[m]、[n] 是浊音却是辅音，因为双唇或舌尖完全封住了口腔；[s] 是清音也是辅音，因为窄缝的阻碍明显。也别忘了反面：元音也可以是清化的（汉语普通话句尾轻声的“吗”常常只剩一个清音的 [A]），元音不等于响音。
:::

::: example 给一个音“建档”：[m] {#ex-jianlang-m}
从气流、声带、口鼻通路三方面分析 [m]（“妈”的声母）。
::: solution
气流：肺部呼气。声带：振动——把手按在喉上拖长“妈——”可感。通路：双唇闭拢，口腔封死；软腭下垂开鼻，气流带着鼻腔共鸣而出——[m] 是鼻音。再按[[#def-fuyin-yuanyin]]检查：口腔有明显阻碍，故为辅音，虽然它浊而响。合起来的三个特征：浊、双唇、鼻音。给一个音“建档”就是把每个可观察的动作各写成一条特征，本课程对每个音都这样处理：特征不是标签，每一条都对应一件你可以亲自验证的身体事。
:::
:::

生理学描述语音的**可能**，不描述它的**现实**。发音器官能够发出的音，比任何一门语言所使用的多出许多倍；一个人只会发自己母语的那几十个音，是婴儿期就被系统“定制”了肌肉习惯的缘故——成年人学外语“听不出、发不出”，一半原因是耳朵和嘴都先要重新定制。社会属性又一次伸手动了生理的领地。

## 语音的社会性质：音位与替换 {#sec-yinwei}

现在来到与语言本身关系最紧的一层。汉语里“你 [ni²¹⁴]”与“李 [li²¹⁴]”：调值相同、韵母相同，声母 [n] 与 [l] 之差换掉了整个词，连带意义。这种“一音之差、一词之别”的差别，音系学称为**对立**（opposition）；处于对立之中的音，在这个语言里就是**不同的音位**。

::: definition 音位 {#def-yinwei}
一个语言中能够**区别意义**的最小语音单位。判定办法是**替换法**（commutation）：把甲音与乙音安在同一个位置互相替换，若换出了不同的词，甲乙对立，是两个音位；若换不出词、或者词不变只是“腔调变了”，这个差别在该语言就不辨义。不辨义的音可以归为同一音位的**条件变体**（音位变体 allophone）：它们要么各有出现的场合、彼此**互补分布**，要么自由互换而意义无别。
:::

::: theorem 音位的判定：对立与互补 {#rule-phoneme-test}
在一个语言里，若两个音可以出现在同一位置而替换后区别意义，它们属于**不同**的音位；若替换从不区别意义，它们**可能**属于同一音位，此时须再查分布——两个音从不在同一场合露面（互补分布），是同一音位不同条件变体的通常情形；同场自由换用而意义无碍，则属自由变体。
:::

::: proof 为什么替换法只能直接证明“不同”
对立能证明“不同”：把“八 [pa⁵⁵]”的声母换成“趴”的声母，得到另一个词，故 [p] 与 [pʰ] 在普通话对立，是两个音位。但“换不出差别”不能一步跳到“同一个音位”，因为两个音也许只是碰巧没有同场机会——还得查分布，再定归并。英语里 *pin* 的 [pʰ] 与 *spin* 的 [p] 送气差别分明，可把 *spin* 的 p 换成送气音，词义不动，只是“说怪了”：原来英语的 [pʰ] 只出现在重读音节开头、[p] 只出现在 s 之后，从不照面，互补而归于同一音位 /p/。可见音位是**功能**范畴，不是物理范畴；归并与否，取决于该系统的辨义需要。每种语言都这样把几百种可发的音压缩成几十个单位，再加上声调、轻声这些超音段的单位，就够支配千言万语——语言的省俭不下于任何工程。
:::

::: example 同一差别，两个系统两种处理 {#ex-qingzhu}
老派上海话与今吴语多数地点的声母系统里，[p]（清不送气）、[pʰ]（清送气）、[b]（浊）三套并存；普通话只有前两套，[b] 在声母位置根本不出现。用音位的概念描述两种系统的差别。
::: solution
吴语里浊音能辨义：同韵同调的位置上，清不送气与浊互换会换词，故清浊对立，是两个音位。普通话里浊音这一列空着：把“八”的声母发得带嗓音，听者不会想到别的字——差别不被利用，就不成其为一个音位；反倒是送气不送气在“八/趴”的对换上辨了义，于是 /p/ 与 /pʰ/ 对立。结论：同一个生理差别（浊与否），在一个系统里是音位特征，在另一个系统里连区别特征都不是。学外语时的“听而不闻”，根源即在音系早已替耳朵做了过滤。
:::
:::

::: quiz

- [ ] 说得短的 [ma] 与拖得长的 [ma\cdot]
- [x] “自 [tsɿ⁵¹]”与“次 [tsʰɿ⁵¹]”的声母
- [ ] 男声的 [ma⁵⁵] 与女声的 [ma⁵⁵]
- [ ] 同一人在不同语速下说得清楚或含混的“安”字的 [a]

普通话语义不由音长、绝对音高、清晰度的差别负担，这三组替换都不换词；只有 [ts] 与 [tsʰ] 能在同样的韵母和调值上换出词（自/次、紫/此——对子里韵母与调值全都相同，才作数），“送气”在普通话是辨义特征，两个音位。附一条英汉对照：英语靠清浊辨义（pin/bin），普通话靠送气辨义（拼/宾），英语送气与否不辨义（*spin*、*pin* 的 p 是同一音位的变体）——各系统“抓”的特征不同。
:::
:::

::: quiz
关于音位，下列哪种说法**不正确**？

- [ ] 两种音物理上相近，也不一定属于同一音位
- [x] 两种音只要生理上有差别，任何语言都会把它们视为不同音位

:::

## 语音学与音标

转写（transcription）是把音落到纸面的技术。国际音标（International Phonetic Alphabet, IPA）是通行的工具：国际语音学学会自 1888 年起制定、历次修订，原则是“一个音位符对应一个音”，字母不够时添新字形、加变音符号（送气加 ʰ，鼻化加波浪号，长音加冒号）。转写有宽严：**宽式**记到音位层，两边画斜线；**严式**记实际音值，两边画方括号。本课程凡讲发音细节即严式，凡谈系统即宽式，各章尽量注明所用系统。

::: example 一个字母盖住了几个音 {#ex-san-ge-i}
拼音字母 i 在 zī、shī、bǐ 三个音节里代表几个不同的音？给出严式转写。
::: solution
三个：[tsɿ⁵⁵]、[ʂʅ⁵⁵]、[pi²¹⁴]。z、c、s 后面的 [ɿ] 与 zh、ch、sh、r 后面的 [ʅ]，是摩擦不除窄、延续出来的元音，习惯称**舌尖元音**（分别属舌尖前、舌尖后）；b 后面的 [i] 才是真正的舌面前高元音。拼音把它们同写作 i，正字法盖住了发音——这就是“拼音不是音标”的一个实例。黄廖本用 -i[ɿ]、-i[ʅ] 两个记号标记它们（表示“只跟在 z c s / zh ch sh r 后面的 i”），本课程沿用；各家在细部记法上略有出入，属技术分歧，不是谁错。
:::
:::

::: warning 方括号与斜线不得混用，字母不等于音
[] 记的是实际音值，/ / 记的是系统单位，拼音字母记的是**拼写**——三层各有各的规矩。✗ “b 是浊音，因为拼音 b 像英语的 b”——错在拿字母当前：拼音的 b 记的是清不送气塞音 /p/，实际音值 [p]；✗“i 是一个音”——见[[#ex-san-ge-i]]。✓ 谈发音查方括号，谈系统查斜线，谈拼写查《汉语拼音方案》。本课程后文提到声母 b p m f 时指的是音位 /p pʰ m f/ 那一套对立，不再重说。
:::

::: history
中国音韵学自《切韵》一系有精细的声韵调分析，韵图把音节排成表格，是前现代世界最严整的音系描写之一，本课程的“声母、韵母、四呼”框架便承此而来。但把耳朵换成仪器是二十世纪的事：1920 年代起，赵元任在中央研究院历史语言研究所主持方言的留声机录音实验，创制了声调字母与五度记调法——本课程记声调的那把尺子即其遗制；五十年代，中国科学院语言研究所与声学研究所用语谱仪研究汉语语音，元音共振峰、送气段时长这些本章引用的“数据”，正是在那一批仪器上量出来的。从反切到语谱图，方法换了，问的却是同一个问题：汉字的音，究竟是什么。
:::

## 后续内容

音位与三种性质是本课程的地图，此后各章是它的分省图。下一章把声母逐一建档：发音部位与发音方法，[[sounds-of-mandarin/initials]]；韵母与四呼在[[sounds-of-mandarin/finals]]；声调与五度制在[[sounds-of-mandarin/tones]]。音位的理论后台——区别特征、音位概括——在[[linguistics/phonetics-phonology]]；本课本地方言与普通话的对照，见[[dialects/mandarin-dialects]]。学完本章，请随手做一件小事：给身边三位方言各不相同的朋友各录一句同音词表，用替换法判断哪些音在他们的话里对立——本章的全部道理，都在那张小小的录音单上。

::: summary
- 语音有物理、生理、社会三种属性；社会属性是本质属性，音位是它的单位（[[#def-yuyin]]、[[#def-yinwei]]）。
- 物理四要素——频率、振幅、时长、波形——对应感知四要素音高、音强、音长、音色；普通话只用音高的轮廓（声调）辨义，不用音长与绝对音高。
- 发音器官三段：动力（肺）、发声（声带）、共振与调音（咽口鼻腔与唇齿舌腭）；气流机制以肺部呼气为主（[[#def-qiliu]]）。
- 辅音与元音的分界是“有无明显阻碍”，不是清浊（[[#def-fuyin-yuanyin]]）。
- 音位以替换法判定：同位替换辨义即对立；不辨义再看互补分布，归为条件变体（[[#rule-phoneme-test]]）。
- 同一生理差别在不同系统可以一个是音位特征、一个什么都不是（吴语浊音、英语送气）。
- 转写分层：[] 严式、// 宽式；拼音是拼写不是音标，字母 i 背后有三个音。
:::

## 习题

::: exercise 数音素 {level=1 check="4"}
音节 zhuāng（庄）可以从几个方向分析：声母 zh、介音 u、主要元音 a、韵尾 ng。把每个单位算一个音位，这个音节一共包含几个音位？
::: solution
4 个：/tʂ/（zh）、/u/、/a/、/ŋ/（ng）。分析时注意两点：zh 是一个声母（一个音位），不要拆成 z 和 h 两个字母；ng 的写法是两个字母、一个鼻辅音音位。字母数（6）与音位数（4）不相等，拼音不是音标的又一例。
:::
:::

::: exercise 辨一组对立的音位 {level=1 check="3"}
“爸 bà、怕 pà、骂 mà”三个音节的韵母与调值完全相同，三个声母互相对立。这三个对立一共涉及几个声母音位？
::: solution
3 个：/p/、/pʰ/、/m/。爸/怕的对立是送气与否，怕/骂的对立是塞音与鼻音的方法之别。三者在同一位置互相替换都换词，两两对立，故为三个音位。若再算上“那/辣”（/n/、/l/），同一条韵母上可以站更多音位。
:::
:::

::: exercise 判断清浊 {level=1}
下列声母哪些是浊音：f、s、r、m、n、l、h。说出你的检验方法。
::: solution
浊音是 r、m、n、l 四个。检验方法即本章的标准：手按喉部拖长发音，声带振动者为浊。普通话声母里浊音只有 m、n、l、r（再加不作声母用的 ŋ），其余十七个皆为清音——这一事实在[[sounds-of-mandarin/initials]]还会从部位与方法两个方向重新数一遍。
:::
:::

::: exercise 替换法实战：ü 与 i {level=2}
用替换法判断普通话的 [y]（ü）与 [i] 是否属于不同音位。要求给出具体的对立词对，并说明韵母与调值的一致性。
::: solution
对立成立。最小对立对如“你 [ni²¹⁴] / 女 [ny²¹⁴]”、“里 [li²¹⁴] / 旅 [ly²¹⁴]”：同一声母、同一调值，只把 [i] 换成 [y] 就换掉了词。故 [i] 与 [y] 在普通话分属两个音位 /i/、/y/。做这题的要领是先把其余条件全部固定再换音：韵尾不同、调值不同，“对子”就不最小，结论也不可靠。
:::
:::

::: exercise 严厉与温和 {level=2}
老师把“坐下！”说得严厉，把“坐下吧”说得温和。除音色外，音高、音强、音长各起了什么作用？为什么说这里“什么音位都没有变”，语音却在“说话”？
::: solution
严厉版通常音域抬高、调型陡峭、重音突出、音节时长对比加大；温和版音域放平、结尾拖长、常有轻声化。全过程中声母、韵母、四声的**音位**一个未变——变的是超音段的用法：音高在声调之上的再分配（重音与语调，见[[sounds-of-mandarin/stress-intonation]]）、音强与音长的节律安排。这正说明物理参数分两层：系统层负责词汇与语法意义，用法层负责语气与情感；“说出态度”靠后者，“说出词”靠前者。
:::
:::

::: exercise 英语者的“浊音病” {level=2}
英语母语者学普通话，常把 b、d、g 发成 [b]、[d]、[ɡ]。用本章的音位理论解释这个偏误的来源，并说明为什么中国人往往听不出他错在哪里。
::: solution
英语里清浊对立（pin/bin），送气不成位（*spin*、*pin* 只差变体）；普通话恰好相反：送气对立、清浊不辨义（声母无浊塞音）。英语者把母语的辨义特征迁移到汉语的塞音上，以为拼音的 b 该读成英语词尾的 b；而拼音字母 b 记的是清不送气塞音 /p/——字母不是音。中国人听不出错，是因为自己的系统不利用浊音这个维度——耳朵同样被系统定制过。两个方向的“听而不闻”，是音系对输入的过滤，也是语音教学的第一个难点。
:::
:::

::: exercise 转写一组音节 {level=2}
用严式音标（含调值）转写下列音节：四、十、屋、鸭。标出声调调值，并在转写后说明每个声母/元音的生理依据。
::: solution
“四” [sɿ⁵¹]（舌尖前清擦音加延续的舌尖元音）；“十” [ʂʅ³⁵]（普通话阳平；舌尖后清擦音后接 [ʅ]）；“屋” [u⁵⁵]（零声母，舌面后高圆唇元音起头，若把开头的圆唇动程也算上，可记作 [wu⁵⁵]）；“鸭” [ia⁵⁵] 或带腭滑音 [ja⁵⁵]（零声母齐齿）。转写的每个方括号里，都应当能指出一个可验证的动作——说不出动作的音，转写就还没懂。
:::
:::

::: exercise 给“错别音”定罪 {level=3}
有人把“主要”的“主”读成 [tsu]（类似“组”的声母），把“报纸”的“纸”读成 [tsɿ]。判断这两处各动了什么发音部位，并说明在普通话里为什么它们算“错”，而在某些方言里不算。
::: solution
“主”本是舌尖后（翘舌）音 [tʂu²¹⁴]，读成 [tsu] 是把舌叶从硬腭前放到了上齿龈，方法未变、部位变了；“纸”本是 [tʂʅ²¹⁴]（舌尖后清塞擦声母，接舌尖后元音），读成 [tsɿ] 则声母换成了舌尖前一类（塞擦甚至擦音），整个换了类。在普通话系统里，[tʂ] 组与 [ts] 组对立（知/资、主/组两两换词），读错就换义，故为“错”；在两类声母合流的方言（如不少西南官话平翘不分）里，它们同一音位，说同样的音不算错——对错随系统而变，这是“语音的社会性质”最日常的应用题。
:::
:::

::: exercise 小论文：我的音系 {level=3}
用三百到五百字写一段自我分析：选定自己方言（或祖辈方言）里普通话不利用的一个区别特征（浊音、鼻边音合并、入声、元音长短、声调数目差异皆可），给出至少两对“替换换词”的例子，并判断它与普通话系统的关系：是音位增删、还是合并分立。
::: hint
先列一张你的方言与普通话的“声母韵母调”三栏对照，再找同韵同调的最小对子。对子找不到，就说明该特征在你的话里也不辨义，不能算音位。
:::
::: solution
评分要点：①特征描述可观察（部位、方法、清浊、调值，而非“土音”一类评价词）；②对立例满足“其他条件全部相同”的最小对立要求；③与普通话的比较落在音位层面（哪个合并、哪个多出），不说“谁比谁标准”；④能注明材料来源（自己的话，或某地某年龄组，见[[dialects/fieldwork]]的方法提示）。常见失分：用普通话拼音当音标（把“土”字拼成 tu 便以为与普通话同音位——拼写掩盖了 [tʰu] 与 [tu] 之外也许还有第三种读法）；把音位差别说成“咬字不清”。
:::
