前十章讲作品如何被生产；本章讲它如何被转移——**全课的总账是一句话：世界文学不是一批作品，而是一套转移技术；一部作品在翻译里“失去”的东西，恰好是它被允许保留下来的那部分所付的收据**。

## 定义：三次换对象 {#def-sandui}

::: definition 从原文、译本到系统 {#def-duixiang}
**通说脉络**（**翻译研究在二十世纪换了三次研究对象：先研究如何译（语言学区，1950—60 年代），再研究译作的效果与规范（描述学派，1970 年代），最后研究译本在文学系统里的位置与文化权力（文化转向，1970 年代以后）（**三次换对象的三句结论（**①**“忠实”不是判准，是修辞**（**它把一次技术选择写成一种道德态度；**于是所有关于忠实的争论都以争吵结束，而以谁有权定义“忠实”告终（**本章要给出可操作的替代判准（例题会用到（②**换对象比换结论重要**（**语言学问题（这个词能否换成那个词）永远无法回答社会学问题（为什么这本书被译而另一本不被译）（**第 1 章层级论在翻译里的复现（③**多元系统的一条规律**（**通说脉络：有学者提出，当一种文学处于危机、年轻或被他语文学大量涌入的位置时，翻译文学会占据该系统的中心；当它稳定自信时，翻译退居边缘（**本课视之为全门课最有用的单条可检验假说，**因为它预言了两件事：**一是翻译最繁荣的年份恰是本土文类失灵的年份；二是繁荣期之后，人们会忘掉这些译本曾是原创的模型（**第二件将在本章末尾成为对当代的判词。
:::

::: definition 三种不可译与它们真实的价格 {#def-buke}
**通说脉络**（**译界长期用“不可译”描述三类困难：形式（音韵、格律、字形）、语用（双关、敬称、语域）、以及制度性专名（官职、度量、法条）（**本课的读法（**①**先把“不可译”拆成不可译与不划算**（**形式上的确有些东西在任何译法里都必失其一；而更多时候，译者是在说：**这一处要译好需要额外的工时、脚注与编辑的耐心，而这份合同不付这笔钱（**这是本章最尖的一句话：**“不可译”常常是价格谈不拢的外交说法（②**一份古老的清单**（**通说脉络：佛经翻译传统中留有一份关于“何类词不宜翻”的条目式说法，被后世归纳为若干“不翻”**）**——**本课的判读：**它不是承认失败，而是一份成本收益表：**某些词保留原文音读，比强行用本地词更便宜也更安全（**第 2 章“文本的三层装配”在此有一个音译版本（③**它的对偶是过度可译**（**同一处困难常被译过头：把双关改成解释、把方言改成书面语、把敬称一律改成通称（**本课称此为“可译性通胀”：**当一切都被译得通顺，文本的社会分层就被抹平，而分层常常正是原作的内容（**第 7 门课“语域不是礼貌是准入”在译本里的损失，是这项通胀的利息（**这就是为什么许多译本“更好读”，却不再是一部阶级小说。
:::

::: definition 汇率、转译与自我转译 {#def-huivil}
**汇率**（**通说脉络：翻译流量高度不对称，少数语言的译出量长期远高于译入量（**本课拒绝把“某国只读自己”讲成民族性格：**它是一个汇率事实：在中心语里，一本书不必翻译也能卖；在小语种里，作者若要被读到，常须直接用中心语写作（**这就是上一章“退出一种语言”的全部代价所在（②**转译（一本书的第三种语言**（**通说脉络：近代东亚有大量文本经由日语或英语中转；若干现代术语的构成材料本身也是从日语回流的汉字词（**本课的三点（**其一，转译不是偷懒而是渠道经济学：**两种语言之间若没有直接的出版关系，就必须付第三方中介费（**其二，转译会留下结构痕迹：**从句法到篇章顺序，中继语的习惯会留在终点语文本里（**通说脉络：现代汉语书面语的若干“欧化”句式即由译经与翻译文体引入，学界长期讨论（**其三，最容易被忽略：**转译使原作的“国籍”变得无关紧要（**一部被两次转译的书，其作者本人已不是必要的证据（**第 1 章的作者功能在此完成它的环球航行（③**自我转译**（**通说脉络：有作家把自己早年的本国语言作品重写为英语，或亲手校订自己的译本（**本课读成一次资产过户：**作者通过重新出版自己，改变了自己在文学系统中的位置——**从“被译出的异类”变成“中心语里的作家”（**它的收益是可核实的一栏：稿酬币种、读者规模与奖项资格；它的损失是一栏没人核对的：那种语言里独有的节奏（**第 6 章“写作工坊改变生产环节”在此有一个更极端的版本：**语言本身换了生产线**。
:::

::: definition 删改的三本账 {#def-shanchu}
**通说脉络**（**译本中的删改大致出于三类压力：进口国的审查、出版方的篇幅与可读性、以及译者对“本国读者不能理解”的判断（**三本账分别记法不同（**①**审查账**（**可查、有文件、有判决（**它的后果最容易被误记为“原作本无此段”（**第 1 章“档案运气”在此变成一项取证要求：**比较初刊本、删节本与未删节评注本，是本章给读者的家庭作业（②**篇幅账**（**通说脉络：若干十九世纪世界名著的最早外语译本曾略去议论、次要人物线与风景描写（**本课称此为“会场的拆除”：**删掉的那部分往往是原作参与本国公共辩论的部分，而它在译入语里没有对应会场（**上一章俄国的长篇议论即属此类（**于是“原著没那么爱讲道理”这个印象，是一份装订决定的产物（③**判断账**（**译者的“读者不懂”预估，最难核查，因为它没有文件（**本课的处理：**不指责，但要区分：**审查删的是被禁止的东西，判断删的是被估价为零的东西；**前者留下判例，后者只留下序言里一句委婉话（**第 9 门课论辩写作所谓“让步前置”，在译序里最常见到它的商业化身。
:::

::: definition 误译可以是本国文学的资产 {#def-wuyi}
**通说脉络**（**两个常被引用的案例：一位现代派诗人据他人笔记改写中国古诗，其成果进入本国诗歌选本；一位英国诗人改写波斯四行诗，使其原作者在本国以外闻名（**四个判断（**①**文学系统只问可用性**（**这些改写在原文语言学界常被指为错误，而它们在英语诗歌里是有效作品；**这不是道德问题，是两个系统的判准不同：**学术系统核对真值，文学系统核对可用性（**第 1 章“描写与规定”的又一次分裂（②**它使“影响”变成一件可疑的事**（**被改写者成为本国文学的资产后，本国读者从中读到的是自己的现代性；**于是“中国诗影响了美国现代诗”这句常被引用的判断，指的其实是一次误读的生产力（**第 10 章“趋同而非影响”在此得到一个更极端的版本：**有时连文本都不是同一部（③**回流**（**通说脉络：被改写而闻名的作者，其在本国的名声反而部分由外国的名声构成（**这是全章最重要的一次镜像：**世界文学的读者结构可以把一部作品的“故乡”搬走（**上一章“货架名先于作品”与本章“译本先于原作”合起来，就是本课对“民族文学”的全部批判（④**它同时抬高与压低价格**（**改写者获得声誉与稿费；**被改写者获得一个名字，而这个名字不再属于他的语言（**第 11 章的“谁付账”问题在此抵达它的终点：**翻译的利润表从来不平，而会计科目由译入语一侧设置。**
:::

::: definition 译者的报酬等级与隐身 {#def-baochou}
**通说脉络**（**多数出版体系按字数向译者一次性付酬，而向作者付预付加版税；译者的名字在封面的位置、书评是否提及、以及奖项是否单设译名，各国差异极大（**本课的四条（**①**“译者隐身”不是观念落后，是报酬结构**（**一次性付酬意味着译者不承担销量风险，也不分享销量收益；**不分享收益的人自然不被要求签名（**这是第 4 章“报价单”最干净的一个变体（②**署名是一种可买的奢侈**（**通说脉络：某些语种与某些丛书把译名放在与作者同等的位置，并在书评中并列讨论（**本课要求读者：**每次推荐一本译作，把译者念出来；**这是一项几乎无成本的价值转移（③**由谁决定译法**（**编辑、作者、译者与读者四方对术语的分歧，最终常由“谁承担读者投诉”决定（**通说脉络：学术经典的修订译本常因术语争论而拖延多年（**本课的判读：**术语是文学的宪法条款，而宪法的修订程序从来比立法更政治（**第 3 章“定义落地总需要有人签字”在此有一份译本证据（④**机器的新位置**（**通说脉络：机器翻译的公开实验始于二十世纪五十年代中期，其经费与声誉在数十年间经历一次大幅收缩与一次爆发式恢复（**本课只记一条制度事实：**当翻译从手艺变成水电，“谁付钱”的问题不会消失，它只会变成“谁维护模型、谁的语料被用作训练、以及谁的名字不出现在致谢里”（**第 14 章的网络文学与本章在此汇合：**翻译的下一步不是译得更好，而是译到不需要被意识到——**而所有不被意识到的劳动，其报酬都由不签名的人承担。
:::

::: example 给一部译本做审计 {#ex-shenji}
选一部你读过的译本，用 200 字完成四项：**①列出它删、合并或改写的三处（可与原文或另一种译本比对）；②为每一处判定它属于三本账中的哪一本；③指出这三笔的收益人与付款人；④给出一条可证伪的“好译本”判准**。

::: solution
**①取证顺序**——**先比初版与再版，再比删节本与全译本，最后比另一种语言的转译本；**若无法取得原文，用两个译本互证：凡两译本一致而某处突兀，常是底本或体例问题；凡两译本分歧，常是原书真正的难点（**判分：**必须区分“我核对过”与“我推测”（**第 1 章证据强度：**这一区分本章给满分，混淆则不及格（②**归账**——**被删的段落涉及本国政治禁忌→审查账；被合并的长描写与次要人物→篇幅账；被改写成通顺套语的双关、方言与敬称→判断账（**若三处都归入“译者水平”，即为零分：**这是把制度问题私人化，是本章从头到尾在反对的那一件事（③**收益人与付款人**——**收益人通常是渠道方：更短的稿幅、更低的印制成本、更少的投诉与更“干净”的读者体验；**付款人是原文的作者与其语言的读者，因为他们失去的是不可追索的东西（**本课称此为“翻译的负外部性”：**成本落在不签合同的一方（**第 8 章“谁付转换成本”在译本里的最终形式（④**可证伪判准**——**合格示例：“同一原作的两个译本，若某处在甲本中保留了原文的语域分层而乙本抹平，则乙本在该处为劣译；此判断可由原文语体标注复核”（**不合格示例：“好译本应当像原作一样自然”——**它无法被任何程序检验（第 3 课可驳倒性排序：**“自然”是本课在第十一章里最后一次听到、也是最后一次拒绝的词。**
:::

::: intuition 原文是档案，译本是作品 {#int-dang}
**一个刻意过分的命题**（**世界文学的读者绝大多数读的是译本；因此就实际流通而言，一部作品的存在形式是它的译本群，而不是它的原稿（**三条论证（**①**功能论证**（**被引用、被改编、被攻击、被禁、被放进课本的，都是某个译本；**原文承担的是另一种功能：它是核对与追索的凭据，也就是档案（②**它不否认原文的价值**（**恰恰相反：**没有档案，译本无法被纠错；**所以本章要的是更强的档案意识（版本、注疏、校勘、语文学），而不是更强的原文崇拜（**第 1 章与第 6 章的全部技术在此变成译本时代的必需品（③**它的当代形式**（**在机器字幕与自动摘要的年代，多数人第一次“读到”的外国文本，是一层没有名字的转写；**它甚至不再声称自己在翻译（**本课的最后一段留给这一句：**我们花了十章学会说“凡是文学都有生产条件”；本章的结论只是把这句话用到翻译上：**译本不是原作的影子，它是另一件作品，有自己的赞助人、自己的审查、自己的报酬表与自己的沉默——**而世界文学就是这些沉默加起来的总量；把它叫作“流失”，是我们唯一诚实的度量单位。
:::

::: history 六次转手 {#sec-liuci}
**前三—后二世纪**（**七十子译本使一部希腊文译本成为西方的“原文”；同一时期，南亚与东亚的佛经译场把翻译变成一种有编制、有译语、有争议的官业（**通说脉络：**本课把这两件事并置：**翻译第一次成为国家工程，也第一次产生了“何词不可译”的规则清单（②**四—十六世纪**（**手抄、注疏与方言化；若干宗教译本参与塑造了后来的标准语（**通说脉络：一位改革者的方言译本与其语法影响长期被讨论（**第 8 章“标准语是裁剪出来的”：刀在这里是译经（③**十六—十七世纪**（**方言圣经、天主教译经之争（通说脉络：关于术语的长期争论，涉及能否用既有词翻译至高概念（**术语之争就是主权之争；**这一条本课已在上一章用汉字、用阿拉伯语、用斯瓦希里语各演示一次（④**十九世纪**（**国际版权的谈判使翻译从占有变成授权；同时，殖民行政需要语法书、词汇表与法典译本（**通说脉络：**本课的判词：现代翻译职业的两副面孔同时诞生——**一为作家付版税，一为帝国做索引（⑤**二十世纪上半—六十年代**（**战争与流亡使“用第二语言写作”成为常规；机器翻译的公开实验出现，随后其资助大幅收缩（**通说脉络（**一次技术热潮被一份评估报告打断，此后二十年该领域靠少数实验室延续（**这是本课给“AI 与文学”的最重要先例：**技术的失败往往不是失败，是撤资（⑥**七十年代—今**（**文化转向、后殖民翻译研究、“理论的旅行”成为一句通用语、区域奖项要求入围作品有译本、以及模型翻译的普及（**通说脉络（**本章结语：**一句二十世纪八十年代初成形的说法——理论也会旅行，并在旅途中改变用途——现已成为世界文学的日常工作语言；**而一个学科的最高成就，是让它的术语通俗到没人再想起它曾是论点（**第 4 章“成语化＝流通率上升、意思归零”在此完成它对整门课的最后一课。**
:::

::: exercise 小论文：世界文学的账 {level=3}
写八百至一千二百字，评“**一部作品成为世界文学的方式，是它在一连串别人手里变得有用：有用于一场语言改革、有用于一套丛书的市场定位、有用于一门课程的教纲、有用于一项政策的对外形象。所谓普遍性，就是这些具体用处的合计；而合计之后剩下的东西，被称作它的文学性——那不过是所有用途都耗尽之后仍然无法用完的那一点余量**”。须调用：**三次换对象**、**多元系统规律**、**不可译与不划算**、**转译与自我转译**、**删改三本账**、**误译作为本国资产**、**译者报酬结构**至少六项；并裁决：**这一账目式描述是否会取消“价值”这一概念（若一切伟大都是被使用出来的，我们还能不能说某部作品更好——你须给出一个既能算账又不把账当全部的说法，并说明它在哪一类反例前会失败**。

::: solution
判分点：七项机制（**对象、系统、不可译、转译、三本账、误译、报酬**）；裁决（**合格答案的核心是把两件事分开：**“被使用”解释流通，“余量”解释为什么它在用途耗尽后仍被重新使用；**因此一个既不天真也不犬儒的说法应满足两条：①它承认任何一部被读到的作品都有账目；②它保留一个可被历史检验的判据——**例如：一部作品在脱离其原始用途（语言改革、丛书定位、政治形象）之后仍被重新启用，且每次启用都产生新的解释冲突；**这个判据是可核对的，因此不是神秘主义（**判卷看是否写出“脱离用途后仍被启用”这一可操作形式，而不是写“真正的艺术超越时代”这类同样无法检验的话**）；失败反例（**必须给一个：**例如某个只在原语境被使用、此后完全无人重印的畅销文本——**账目法能解释它的流行而无法解释它的消失，除非引入文本的内部特征；反之，一部从未被任何机构使用而被个人读者保存的手稿，则暴露账目法的盲点（**能举出任一类即为满分**）；结论若能写“**所以这门课的终点不是给任何作品定价，而是要求每一次定价都附上明细：谁译的、谁删的、谁教的、谁引用的——明细公开之后，我们仍然可以说一部作品更好，但我们说的不再是‘大家都这么说’，而是‘它在用途耗尽之后仍然供不出答案’，而这是一件可以一起核对的事**”，即 A。

:::
:::

::: summary
总账归档：对象（**换研究对象比换结论重要**）、系统（**它只问可用性，不问真值**）、不可译（**先问是不划算还是不可能**）、转译（**一本书的第三种语言**）、三本账（**审查留判例，判断只留一句委婉话**）、误译（**可以是本国资产，并搬走一部作品的故乡**）、报酬（**不分享收益的人不被要求签名**）。全课一句话：**从荷马到今天，文学从未独自旅行；它一路上带着译者、编辑、书单、审查官与资助方的名字，而我们的任务不是歌颂这段旅程，是把这些名字一个个填回署名栏。**

:::
