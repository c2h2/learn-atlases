上一章文学学会了开会；本章它宣布开会扼杀灵魂——**而本章最要紧的一句是：浪漫派反对机构的斗争，最终以建立新机构告终；今天我们把那套机构叫作“创作”与“版权”**。

## 定义：一个词的三级跳 {#def-santiao}

::: definition 从文体到气质到产业 {#def-ciyi}
**通说脉络**（**这个词的本义是“像传奇那样”，指一种文体属性；十八世纪末被用来命名一种性格与时代气质；十九世纪中叶以后又成了文化工业的产品类别（**三级跳的三个后果（**①**批评术语的语义会漂移到反义**（**“romanesque”本是贬义的“荒诞不经”，跳到褒义后再跳回商品标签（**第 6 章语义降格与升格的双向循环在此以五十年为单位完成（②**命名一场运动等于给它发纲领**（**通说脉络：一场刊物上的断片论争完成了“浪漫派”的自我命名（**在此之前没有人是浪漫派；**这一句适用于本课所有带“-ism”的章节（③**气质的产业化有固定路线**（**反市场的生活方式被包装成可复制的形象出售：**长发、黑衣、忧郁、失眠、早逝（**本课称此为“姿态的批发”：**浪漫派发明了艺术家的形象，而形象比作品更赚钱——**这是本章对“为什么浪漫派赢了”的唯一回答**。
:::

::: definition 反污名：把病卖成资产 {#def-wei}

:::

::: definition 断片、交响、以及“未完成” {#def-duanpian}
**断片**（**通说脉络：十九世纪初的刊物以编号断片、对话与随想为体，主张“正在形成”本身高于完成的作品（**三个理由（**①**未完成强制读者参与**（**作品的意义不再在其中，而在它与读者之间；**这是二十世纪接受理论的祖先（第 16 章会算这笔账（②**它是审查的解法**（**断片没有可指认的论点；**被删除的断片比被删除的论文更难申辩（**第 4 章“脚注的两套账”的姊妹技术（③**它是新的出版节奏**（**刊物按月出、断片编号排：这套格式让哲学第一次有了连载（**本课的当代一击：**一条一百四十字的、故意不写完的句子，与两百年前的编号断片是同一形式；差别在结算方式——**断片的传播靠沙龙与刊物，转发靠计数平台（**同一形式，不同结算：**这句话可以在第 1 章、第 9 章与本章各用一次，每次都是新的**）；②**“无限”与崇高**（**通说脉络：一个此前属于修辞学的词成为诗学核心范畴，风景由此从背景变成主角（**本课的技术分析：**当“无限”成为标准，描写就必须不断加码——**这是浪漫主义后期自我耗尽的财务原因（**想象力通货膨胀：每一部作品都必须比上一部更崇高，直到整个类别破产（第 1 章“修辞物种爆发”在此得到一次完整的破产清算演示**。
:::

::: definition 脚注：抒情诗里的学术附件 {#def-jiaozhu}
**通说脉络**（**十九世纪有的长诗以大量自注闻名，诗人用学者口吻解释自己的想象（**本课读成一次“账户混用”**（**抒情诗属于“不可考证”的账户，脚注属于“可考证”的账户；把它们装订在一起，等于宣称诗人同时拥有两种权威（**三个后果（**①**幽默提前被制度化**（**自注常把诗意的严肃踩碎：**这是浪漫派自己发明的反浪漫技术（②**它为版权提供了证据链**（**注里记了灵感来源、实地见闻与阅读书目（**一个人如何证明一首长诗不是抄的？**靠附件（**第 1 章“署名是一份需要保管的合同”的最妙案例（③**它暴露了浪漫派的裂缝**（**天才应当无师自通，而脚注说明他有书（**本课的结论：**浪漫派真正的矛盾不是“情感与形式”，而是“灵感”与“产权”：一个要求作品无来源，一个要求作品有来源——**而我们的法律至今站在产权一边**）。
:::

::: definition 一本引发模仿的小书 {#ex-vierte}
**通说脉络**（**十八世纪末一部书信体小说在欧洲引发青年模仿其服饰与结局的传闻，并在若干地区被禁（**本课的处理（**①**传闻的证据强度要打折**（**“教会人自杀”是道德恐慌的标准句式，其可核对部分很小（**第 3 课：幸存者打八折，指控也要打八折（②**但它确实造成了一个先例**（**从此“小说有害”成了一种可立法的主张：**文学被承认为一种有因果力的社会变量——**这是本章的悖论**）：**审查者的这一票，比任何书评都更实在地抬高了文学的地位（**第 1 章“文学来盖章”的又一次兑现（③**它发明了“读者作为危险群体”**（**此前担心的对象是听众多、观众多；此处担心的是单独一人、深夜、与一本书（**本课的判断：**现代意义上的“私密阅读”第一次被当作公共问题——**因为它确实是一种新的自由，而所有新的自由都会收到第一张传票**）。
:::

::: definition 一场剧院里的投票 {#ex-ounani}
**通说脉络**（**十九世纪三十年代的巴黎，一部浪漫派剧作首演前夜与场内发生支持者与批评者的长期对峙（**本课的三个读数（**①**这是评审席的公开改选**（**上一章说规则是会议纪律；此处有人冲进会议室抢席位（**浪漫派与古典派之争，最终是一场关于“谁算裁判”的武装辩论**）；②**它把观众分成有名字的阵营**（**媒体第一次报道“谁在包厢里”：**文学派系变成体育式的对抗，而对抗本身可被售票（**本课称此招为“对抗性发行”：**当一部作品卖不动时，把它的反对者做成节目（**第 16 课的“骂战是流量”的祖本**）；③**它证明了胜利的代价**（**改席之后，新的裁判立刻开始立新的规矩；**浪漫派在剧场获胜的同一年，它的反机构姿态就成了机构（**这就是本章开头那句“以建立新机构告终”的具体年份**）。
:::

::: intuition 灵感的工厂 {#def-gongchang}
**通说脉络**（**浪漫派的天才论与十八世纪末至十九世纪的版权法在同期确立（**本课把两件事并表（**①**“灵感”与“财产”是一对搭档**（**要证明一件作品属于你，最有力的说法不是“我写了它”，而是“只有我能写它”——**不可让渡的独特性，恰好是产权最好的抵押物（**于是浪漫派的神秘主义与资产阶级的合同法互相成全**）；②**今天的报酬结构揭穿了这个故事**（**内容产业付钱给“产能”，不付钱给“灵感”：日更、周更、季度考核、指标（**写作者的自我叙述仍是浪漫派的，薪酬表仍是抄写员的（**本课的判词：**这是本章留给读者的日常工具：**每当有人用“天赋”解释一份报酬的分配，就问另外九个人做了什么（③**而我们不能因此嘲笑浪漫派**（**“想象”这一词被他们抬到器官的地位之后，人才有了以虚构抵抗现实的法律语言（**第 2 章丽娘、第 7 章《聊斋》与本章在此共享一份章程：**想象不是逃避，是一种管辖权的主张**。
:::

::: history 一场多中心的运动与一次合并记账 {#sec-hebing}
**1770s—1790s**（**德意志：一部悲剧的第二版、一份刊物、一伙大学生式的文人集团（**“耶拿小组”的存在期极短，却是欧洲第一例“以刊物为组织形式的文学运动”**）；**1798—1830**（**英格兰：一部合集的序言把诗重新定义为“强烈情感的自然流露”，又补上一句“在平静中回忆起来的情感”（**通说脉络：这半句限制常被教科书略去（**本课的读法：**浪漫主义的第一份纲领自己就带了刹车；**凡是把“自发”写成理论的文本，都会在后半句把纪律找回来**）；③**1800—1830**（**法兰西：一位批评家把德语词译入法语并遭到围攻；一场剧院对峙（**通说脉络：一个文学概念跨国旅行时，总会带来一位外国敌人（**这是世界文学的通用汇率：**进口概念的价值一半在于它能让本地人吵架**）；④**1800—1860**（**俄国的浪漫主义与民族叙事、波兰的流亡诗人、以及各国的民歌收集（**通说脉络：赫尔德一系的“民族之声”设想为民歌、童话与史诗的搜集提供了动机（**本课的判断：**这是全课最重的一条：**“每个民族有自己的文学”这一常识，是这次收集运动的产物；**它使文学成为民族资格的证据（**第 11 章的翻译与第 18 章的“谁有资格说一种语言”都从这里领工资**）；⑤**1830 之后**（**“浪漫主义”成为一个历史分期；现实主义以它的失败为生（**通说脉络：**每一场后继运动都需要一个浪漫派来反对，而它反对的是自己需要的那个版本**）——本课的收束：**所以我们不能“讲完浪漫主义”，只能讲它的历代使用者（**这正是第 16 章“追认”的核心技术**）。

::: exercise 小论文：想象力与产权 {level=3}
