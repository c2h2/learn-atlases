title: "希腊与罗马"
---

这门课不讲“西方文学的源头”，因为“源头”是一个后果而不是一个原因——**我们手中的希腊，是两千年的抄本、课本、译本与注疏挑剩的东西；本章的真正对象不是荷马，而是那台一直替他做选择的机器**。

## 定义：口头诗的技术 {#def-kouTou}

::: definition 程式与“度量” {#def-chengshi}
**通说脉络**（**二十世纪初，帕里与洛德以田野录音（南斯拉夫口头史诗歌手）与文本内部统计立论：无文字社会的长篇韵文靠“程式语＋步格”现场生成（**通说脉络**）；**“捷足的阿基里斯”“玫瑰色手指的黎明”“灰色的海”**（**通说引其例证大意）——**本课的三点结论（**①**修饰语不是选择而是义务**（**在步格的某个位置需要某个形状的词，程式就替你把词送到：**美学效果是约束的副产品（第 3 门课格律、第 8 章样板戏“三突出”：同一条力学（**约束产生形式，不产生质量；但它确实产生形式**）；②**记忆不是存储而是再生成**（**歌手“每一次表演都是一次作诗”（**这与抄本文化的“定本”概念正相反：**于是“荷马是谁”这个问题在它的语境里几乎无意义**）；③**书面化的瞬间就是损失开始的瞬间**（**记音必然丢掉手势、曲调、场合与听众反馈；**而换来的是一部可被注释、可被考试、可被翻译的书（**本章后面所有的“经典化”，都发生在这次交换之上**。
:::

::: definition 史诗的经济学 {#def-jingji}
**一个长文本需要什么**（**六千行以上的韵文，需要：一套程式库、一个愿意整夜听的听众、一个能付钱的赞助场合（通说脉络：宴饮、赛会、宗教节庆）；**对照本课前面各门**（**元杂剧的四折是生理量，话本是回本的长度，网络小说是千字计酬（**希腊史诗的“长度单位”是一夜：**所以它的结构是并置与重复，而不是悬念与回收（**第 9 章“循环是最大团圆承诺”的反题：**口头叙事不靠结局抓住你，它靠你已经在这里。
:::

## 一部被挑选的遗产 {#def-yichan}

::: definition 为什么只剩三位悲剧家 {#def-sanwei}
**事实层**（**通说脉络：悲剧三大家留有全本，其余数百部多存残篇与标题；而古代记载的剧作家名单远比我们读到的长**）——两条因果（**①**语文课本**（**通说脉络：拜占庭时代的学校选本决定了今传的核心篇目（**“选本即审查”的第 N 次兑现，而这次的审查官是一位九世纪的教师（第 1 章目录即审查**）；②**材料的运气**（**莎草纸在埃及干燥处幸存，在欧洲潮湿处腐烂；羊皮纸贵，故只抄有用之物（**第 8 章档案运气：所谓“希腊的辉煌”里，包含一张我们永远看不见的损失清单（**本课要求你在心里为它留一格空白（**这是世界文学这门课最必要的一项纪律：我们不能只研究幸存者的语法。
:::

::: definition 亚里士多德被读错的那一次 {#def-sanheyi}
**通说脉络**（**《诗学》论行动的整一、论摹仿与“卡塔西斯”；十六世纪意大利注疏把“整一”推演为时间、地点、动作“三一律”，遂成古典主义铁律，又为浪漫派所破——**本课的读法（**①**这是一次影响研究能做的最干净的事**（**误读有具体的注疏、具体的年份、具体的舞台后果；**它不是“误解”，是生产（**②**被误读的概念恰恰最有权力**（**“三一律”从未在《诗学》里被这样写出，却统治了欧洲剧场一百五十年——**理论的权威常常来自它的错误版本**）；③**它与本课的另一条线相接**（**同一部《诗学》经由阿拉伯文译本进入伊斯兰世界，在那里被读成诗学与修辞学（通说脉络：法拉比与阿维森纳一类注疏）——**一部书可以在两个文明里变成两门不同的学科（**这就是“翻译与接受”一章的先声。
:::

## 罗马：影响的债主 {#def-luoma}

::: definition 翻译作为一种征服 {#def-fanyi}
**通说脉络**（**罗马文学以翻译与改写希腊为开端；贺拉斯有句常被引用的话，大意是“被俘的希腊俘获了她的野蛮征服者”（**通说引其大意**）；维吉尔《埃涅阿斯纪》同时依循与超越荷马；卡图卢斯与新诗人一派主张短制、精工与博学者趣味——**三个理论要点（**①**“影响的焦虑”在此成形**（**拉丁文学的起点是一笔欠债，因此它的荣誉制度是“胜过原作”：转译、并置、竞争——**这为整个欧洲后世对经典的“改写权”提供了先例（②**学者之诗（**通说脉络：亚历山大学者的校勘与注疏传统养育了“以学问为诗”的流派（**这与宋代“以才学为诗、以议论为诗”是可比的文学社会学现象（**两者的共同条件是：典籍已多，新作必须靠互文来显示位置（第 3 章“以故为新”的跨文化同型**）；③**罗马发明了“经典课程”这件装置**（**通说脉络：修辞学校的课本、演练题与范本文本（**它比任何一部杰作都更能说明“经典如何生效”：**经典不是被读的，是被考试的（第 1 章“文学来盖章”的制度原型**。
:::

::: definition 两条传出路线 {#def-lianglu}
**拉丁路线**（**通说脉络：中世纪西欧通过拉丁译本、摘要与教父引用接受希腊，柏拉图长期缺席，直到十二—十五世纪才逐步回归（**一条断与续的曲线：**西欧失去的其实是希腊语本身（②**阿拉伯—叙利亚路线**（**通说脉络：八—十世纪巴格达的翻译运动把希腊哲学与科学译为阿拉伯文，再回译为拉丁文；《诗学》在此被读作关于“夸饰与劝喻”的书（**本课的方法论收获：**“希腊遗产”不是一条河流，而是两个水利系统；**任何把“西方”当单一接收者的叙述，都在此处露出破绽（**这也是本章反对“源头”这个词的理由：**所谓源头，是几条互不相干的接受史在二十世纪被合并记账的结果**。
:::

::: example 一个程式语的三种命运 {#ex-chengs}
“玫瑰色手指的黎明”一类的程式语，请分别说明它在①口头表演、②亚历山大学者的抄本、③现代汉语译本中各自是什么（技术件／文物／修辞），并回答：**为什么现代读者常常觉得荷马的比喻“太美”，而研究者却认为它们在原语境里几乎不美**。
::: solution
**①表演中**——**它是备件：**歌手在步格的这个位置需要“黎明＋一个双音节形容”，程式即取用；**它的“美”是可靠性的美感，像一把好扳手（**②抄本中**——**它变成文本的指纹：**注疏者开始问“为何称黎明为玫瑰色手指”，于是程式被追认为意象（**这是文学批评的第一次错置：**把库存读成选择（③译本中**——**它变成风格标签：**译者保留它，汉语读者读到“异域的诗味”；译者删掉它，文本立刻变得“通顺而像我们自己写的”（**本课的判分在最后一问**（**现代读者的“太美”是距离的产物：程式语的重复率极高，而在口头语境里，重复不是修辞是效率；**我们觉得美，正因为我们听不到那个不觉得美的现场（**这与本课对一切“古典的庄严”的处理一致：**庄严常常是失聪的结果（第 8 章“成语化＝流通率上升、意思归零”的古希腊版。
:::
:::

::: intuition “古典”是一种版权 {#def-gudian}
**为什么这个标签总在移动**（**通说脉络：所谓古典时代（公元前五世纪雅典）本身是后世建构：罗马人奉其为典范，文艺复兴奉其为对手，十九世纪德国大学奉其为民族教育的模型（**本课把“古典”拆成三个部件（**①一套课程（**决定谁必须读；**②一套版本（**决定读哪个本子；**③一套不可追问的权威（**决定不允许用什么问题去问它（**于是“回到原典”永远是一次再立法：**每一次都换掉前一次的三件东西（**对照本章的汉语同学科：《诗经》在今文古文、汉宋之争、以及现代选本里的三次换位，是同一台机器的本地型号（第 3 门课“版本即意识形态”：希腊与汉朝同时证明了：**一部书的确切文字，取决于谁有权定本。
:::

::: history 两千年的收货记录 {#sec-shouhuo}
**公元前五—四世纪**（**雅典剧场与节日：一次性事件，抄本少量流通（**“文学”此时是一种公共技艺，不是私人财产**）；**前三—前一世纪**（**亚历山大里亚的校勘与罗马的仿作：**第一次“定本”，第一次“经典清单”（**通说脉络：**这同时是现代编辑学与比较文学的童年**）；**九—十二世纪**（**拜占庭的课本与阿拉伯的译场：**两条收货线各自入库（**同一批货物，两份税单**）；**十五—十七世纪**（**印刷术把校勘本变成教科书；三一律由注疏变成法律（**学术的错误获得行政寿命（**这是本章给“学术—权力”关系的最强案例**）；**十八—十九世纪**（**温克尔曼与希腊美学的“高贵的单纯”、德国办学的古典课程、尼采的反击（**通说脉络：《悲剧的诞生》以希腊为名义发动对希腊教育的战争（**一次漂亮的操作：**用一个更早的希腊，取消当下的希腊（**这一招后来被反复使用，本课会在下一批章节再遇到它**）；**二十世纪—今**（**线形文字 B 的释读、帕里的田野录音、纸草残片、以及翻译与电影改编（**通说脉络：**“希腊”最后一次换主人：从语文学与人文教育，交给考古、认知科学与文化产业（**本章结语：**我们仍然在读希腊，只是那台挑选的机器已经换成了我们认不全的模样——**奖项、数据库、以及一个决定哪部译本进书店的采购员。
:::
