title: "写实主义与自然主义"
---

上一章的人要求无限；这一章的人要求账目——**但本章的第一句话是一个否定：写实主义不是一种“照原样描写”的技法，因为任何时代都不缺照原样描写的人；它是一种新出现的声明，一种关于小说与真实之间合同的公开承诺，以及一份直到二十世纪还在被引用的政治纲领**。

## 定义：一份声明的三段措辞 {#def-shengming}

::: definition 镜子、账簿与法庭 {#def-jingzi}
**通说脉络**（**十九世纪中叶的法国出现了一批互相关联的主张：小说应写当代风俗、应写无名者、应以科学方法研究社会、并应像历史一样提供证据（**三段措辞（**①**镜子**（**一部小说被说成沿路行走的镜子（**通说脉络：司汤达一类的比喻**）——**它的重点不在“照出”，而在“谁有权说镜子照错了”（**镜子不接受意见，只接受事实**）——这是一个修辞上的政变：**它把文学争论从品味转到证据（②**账簿**（**一部多卷本巨著自命为“社会史学家”，声称要写出风尚、职业、财产与法条（**通说脉络：巴尔扎克《人间喜剧》的序言纲领**）——**本课的判读：**这是文学史上第一次有人把产量当作论点：**九十余部成书、人物反复出场、姓名构成索引——**一部小说集变成一个可查询的数据库（**第 3 门课“清单是不肯散架的国”在此变成资产清单（③**法庭**（**小说家受审**（**通说脉络：十九世纪五十年代巴黎以“伤风败俗”起诉一部小说及其主编（**通说脉络：福楼拜与《两界评论》**）——**起诉要求文本有一个可指认的意思；**辩护则主张：意义在风格之中，而风格无法被摘录**）——本课的核心判词：**这场审判发明了现代小说的技术条件：**当一部书能被定位到某一句，它就可以被定罪；于是伟大的一代开始写不能被定位的句子（**第 9 课“作者的沉默是讽刺的法律条件”在此得到它的欧洲判决书**。
:::

::: definition 自由间接引语：无人认领的句子 {#def-zhiyou}
**通说脉络**（**一种不加引导词、不改变时态而混入人物口吻的叙述；十九世纪法国小说将其常规化（**本课拆成三件设备（**①**成本的转移**（**直接引语便宜而清楚，一段一人在说话；自由间接引语昂贵而模糊，代价是读者必须自己判断是谁在这么想（**于是小说第一次把“判断的劳动”外包给读者（**这是叙事技术的里程碑：**它把读者从听众升级为共同作者（②**免责结构**（**没有任何人物为这句话签字，因此没有人可以被起诉**）；③**它使“众声”成为小说的定义性经验**（**通说脉络：巴赫金一系把小说的本质读作多种社会声音的并存与交锋（**本课的用法：**写实主义之所以显得“深”，不是因为它写心理，而是因为它把一句社会意见与一个人的信念印在同一个句子里，且不注明出处——**这一句可以当本章的毕业论文题目用**）。
:::

::: definition 连载：读者是有投票权的合著者 {#def-lianzai}
**结构**（**通说脉络：十九世纪英美的月刊与日报连载使小说按段出售，作者据发行量与读者反应改稿（**三个后果（**①**悬念是商业装置**（**每期末留钩子：这与话本的“下回分解”、与网络文学的黄金三章是同一力学（第 9 章与第 14 章：**分期改变时间感**）**；②**人物会复活**（**通说脉络：某畅销小说因读者对船难结局的抗议而在成书时改写结局——**这一事件常被引用，其因果强度则常被夸大（**本课的处理：**不否认作者意志，只指出制度事实：连载制把“改主意”变成一种可辩护的商业决定**）；③**长度是价格的函数**（**三卷本的页数由订阅合同的格式规定（**本课的公式：**别问十九世纪小说为什么长，问它按什么单位卖**（**第 2 门课“长度是生理量”、第 14 章“千字计酬”在此连成一条线：文学形式的第一位解释变量从来是计费方式**）。
:::

::: definition 一种新角色：作为证人的人文学者 {#def-zhuren}
**通说脉络**（**十九世纪后期出现一批以文学声望介入公共案件的写作者：一部关于童工与济贫法的小说推动立法讨论；一位小说家在冤案时期发表公开信（**通说脉络：左拉在一桩军事冤案高峰期致国家元首的长文**）；**三个层次（**①**文学第一次拥有可转让的道德资本**（**一位小说家的名字可以为一份请愿书增加签名以外的东西（**这是本章最重要的社会学事实：**“知识分子”是一种职务，而这个职务由小说家首先出任**）；②**资本的兑现率随媒介变化**（**同一篇文章在报纸与在小册子里的效力不同：**而作者立刻发现，最有效的用法是把它印成单行本出售（**道德姿态与市场行为在同一次操作中完成：**本课不把这叫作伪善，叫作汇率**）；③**传说的加成**（**通说脉络：一部反奴隶制的小说与一场战争的因果关系，常被一句据称出自总统之口的玩笑话固定下来（**这是全课反复使用的史料分层练习：**事实层是销量与议会发言记录；传说层是那半句轶闻；**而教科书往往只保留了轶闻**）。
:::

::: definition 一扇门与一具尸体 {#ex-men}

::: solution
**其一（关门**——**剧本的结尾把裁决权交给一个音响事件：**她不辩解，她离开（**第 9 课“作者的沉默”的舞台版：**判决不由作者宣布，由一记关门宣布；**通说脉络：这记关门据传曾在剧场外引起欢呼或口哨的轶闻（**本课只把它当传说层，但指出其功能：**它证明观众已经把一出戏当作一项社会决议来投票（**其二（公寓**——**开场描写做了一件社会学工作：**它把人物放进价格里（**房租、楼层、家具的磨损、楼梯的气味：**在人物说话之前，读者已经知道他付得起什么（**本课的核心判据：**写实主义的“深”常常是会计的深：**人物的悲剧很少是被证明的，通常是被定价的（**为什么比自白有效**——**自白是一个人在陈述，房间是一个系统在陈述；**而系统不会被起诉（**这一句同时解释了本章的镜子、账簿与法庭三个比喻为什么是一件事：**写实主义发明了“非人格的证人”这种叙事权威——**它比任何一个人物都可信，因为它无人认领**）。

::: definition 婚姻市场：写实主义的真实感来自哪里 {#def-hunyin}
**通说脉络**（**十九世纪欧洲出现以感情与个人选择为理想的婚姻观，同时妇女的财产权与离婚可能长期受限；大量写实小说的主线是遗产、年金、陪嫁与体面的收入（**三个读法（**①**情节的真正发动机是现金流的转移**（**谁有陪嫁、谁继承、谁必须工作：**本课建议读者为一部写实小说做一张现金流量表——**你会发现情节转折与收入变化高度重合（②**“爱情”作为制度性词汇**（**通说脉络：它在此期成为婚姻的主要正当性语言（**本课的判断：**正当性语言的兴起往往与被替代的旧标准同时发生：**当财产不再公开是条件，它就变成必须在场而不可言说的条件（**这一条可直接用于分析当代婚恋话语（③**它决定了女性人物的选择集**（**小说里的女性比社会史里的更清醒，因为她们的处境是收入风险：**包法利夫人、安娜、以及若干“不检点”的女主角，其罪名多半是财务性的：**她们花了本不属于自己的那笔——**本课对“通奸小说”的定义：**一种关于共同财产与无权处分的叙事**）。
:::

::: definition 自然主义：把方法借来，把结论写坏 {#def-ziran}
**通说脉络**（**十九世纪后期一种主张以观察与实验方法写小说的流派，以一部关于酒精、劳工与矿区的小说群为代表（**本课的三段（**①**它借的是权威不是方法**（**当时的生理学为它提供了“实验”这个词；**而小说无法做对照实验：它只能做“充分的细节”（**于是方法变成了一种修辞担保（**第 5 章“以学问为诗”的近代版**）；②**它真正的发明是题材配额**（**洗衣妇、矿工、醉汉、店铺学徒进入长篇小说的中心（**本课判词：**文学史上被称作品味革命的，多数时候是配额革命：**描写对象没变，可列举的对象清单扩了（**第 6 章“文体”与第 8 章“变体”在此接上**）；③**它的失败也是可教的**（**决定论叙事要求环境解释一切，而情节要求人物做出选择：**于是自然主义小说常常在最关键处偷偷放弃前提，让人物“突然觉醒”——**本课称此为“理论的漏账”：**任何以科学自我担保的批评理论，都会在它自己的作品里暴露它不能支付的那一项**）。
:::

::: example 为“真实”做一次审计 {#ex-shenji}
选一段以“真实”著称的描写（写实或自然主义均可），完成三项审计：**①列出其中有叙事功能的细节与无叙事功能的细节；②假设删除后者，文本剩余多少信息与多少“真实感”；③指出这段描写靠哪一种权威取得信任**。

::: solution
**①两栏**——**功能细节：推动行动、限定条件、暴露人物处分的权力**；无功能细节：颜色、气味、器物、身体的无关部位（**关键不是删除它们，而是发现它们的存在形式：**它们通常是可替换的（**这就是“真实感”的来源：**一个可替换的细节被写成不可替换，读者便读到“现实”**）；②剩余量**——**信息几乎不损失，真实感大幅塌陷；**由此得出本章的技术结论：**“真实”不是内容属性，是细节的呈现方式（**第 4 章“无功能细节是文类的指纹”的完整证明**）；③权威类型**——**候选有三种：**亲见（**记者式的目击**）、方法（**科学式的观察**）、以及无人称（**自由间接引语式的系统陈述**）；**本课要求判出它是哪一种，并说明其代价：**诉诸亲见者须对事实负责，因此可被事实推翻；诉诸方法者须对程序负责，因此可被同行审查；诉诸无人称者不对任何具体事物负责，因此几乎不可反驳（**判分：**能写出“不可反驳性正是它的市场优势”一句，即本章 A——**这句话同时是写实主义的功绩与它的危险**）。
:::
:::

::: intuition 一句关于幻灭的算术 {#def-huanmie}
**为什么每一场后继运动都以写实主义为靶**（**通说脉络：二十世纪的现代主义、新小说与后现代批评先后以“反映论”“逼真性”“现实主义霸权”为名攻击它（**本课给出三条算术（**①**它的成功使它成为默认值**（**任何被称作“客观”“敢写”“直面现实”的赞美，都在使用它发明的词汇；**默认值的特征是看不见自己**）；②**它的合同是可撤销的**（**读者可以在同一书架上换一份合同：**这是二十世纪实验文学得以存在的技术前提**）；③**它从未停止生产新的不真实**（**写实主义最成功的作品里常有一种不可信的强度：**巴尔扎克的夸张、狄更斯的漫画、福楼拜的抒情（**本课的结论：**写实主义不是取消了修辞，是成功地隐瞒了修辞——**于是每一代后来者的工作不是“回到真实”，而是“揭穿一份旧的隐瞒”——**这也是本课给整门世界文学课程的第 6 条通用规律：**文学史的前进方式，是把上一次默认的写法变成这一次主动的选择**。
:::

::: history 一场命名在身后的运动 {#sec-mingming}
**1820s—1840s**（**历史哲学、社会统计的兴起与“风俗研究”的雄心：**小说第一次宣称自己是一种知识（**通说脉络：同年出现的第一批社会调查报告与小说共享读者**）；②**1850s**（**一个标签在巴黎被一家刊物用出来；一部小说受审（**通说脉络：**术语与审判同年：**这不是巧合，是同一件事的两面——**当一种写法被法庭传唤，它就必须有一个名字**）；③**1860s—1880s**（**连载、租型与通俗书的扩张；自然主义宣言与论战；北欧问题剧（**通说脉络：**欧洲出现真正意义上的大众阅读市场（**本课的提醒：**写实主义的经典化靠的不是它的高级，而是它同时占领了高端与低端**）；④**1890s—1930s**（**关于“现实主义”的理论争论在一场政治流亡的知识圈里达到顶点（**通说脉络：卢卡奇与布莱希特一派关于表现主义的论战（**本课的最重要史实：**“现实主义”作为战斗概念的黄金时代，在它所谓的大师去世之后几十年；**每一个文学时期的名字，都是后世争论的产物（**第 1 章与第 5 章在此合成一条**）；⑤**1950s—今**（**各国以“现实主义”为纲的官方文艺政策、以及第三世界对它的重新征用（**通说脉络：**一个十九世纪巴黎的标签成为二十世纪全球文学政策的通用货币**）——本课结语：**这既是它权力的证明，也是它作为分析概念的破产——**所以本章教你用它的技法（配额、无人称、现金流），而不是用它的名字**）。
:::

::: exercise 小论文：真实是一种呈现方式 {level=3}
写六百至一千字，评“**写实主义最伟大的发明不是它写了什么，而是它使一种信任成为可能：读者愿意相信眼前这段文字不受任何人操纵。这种信任在法学上叫作‘无人认领的陈述’，在叙事学上叫作客观性，在市场上的名字叫作真。因此凡是追问‘文学如何反映现实’的问题都问错了方向；正确的问题是：在什么条件下，一群人同意把某种人工制品当作证据来读**”。须调用：**镜子与账簿**、**审判与风格辩护**、**自由间接引语**、**连载制**、**婚姻市场与定价**、**命名的身后性**至少六项；并裁决：**“把文本当证据读”的习惯是否也支配了今天的非虚构写作与短视频“实拍”——你须举出一个正在发生的例子，并说明它与十九世纪合同的差别**。

::: solution
判分点：六项机制（**声明、审判、无人称、连载、定价、身后命名**）；当代例（**合格例：手持镜头与晃动作为“不可操纵”的证明、未经剪辑的长镜头、截图与原始文件、直播的不可撤回性；**须写出它与十九世纪合同的差别：**十九世纪的无人称靠句法取得，今天的靠“制作痕迹的缺席”取得；前者让作者消失于修辞，后者让机器代替作者作证**）——判卷看是否指出这一层——**这是本课的终点：见证人从叙述者换成了记录设备，而信任的结构一模一样**）；结论若能写“**所以写实主义留给我们的不是一种风格，而是一项可以随时撤回的信任：一旦有人问‘这是真的吗’，他就已经在执行一份十九世纪签的合同**”，即 A。

合同归档：声明（**镜子把品味之争改成证据之争**）、审判（**可定位即可定罪**）、无人称（**判断的劳动外包给读者**）、连载（**先问按什么单位卖**）、定价（**悲剧常常是被算出来的**）、命名（**封圣发生在葬礼之后**）。方法一句话：**别问它真不真，问它在什么条件下被当作证据读**。下一章：十九世纪的俄国——文学作为一个国家的议会。
