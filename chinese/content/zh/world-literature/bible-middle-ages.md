title: "《圣经》与中世纪文学"

上一章说“源头”是被造出来的；本章看一个更硬的例子——**一部书如何造出一整个文学秩序：它不仅提供题材，还提供了“文本一定另有深意”这一读法本身；而现代世界文学的几乎每一套解释技术，都是它的世俗变体**。

## 定义：文本、正典、译本 {#def-zhengdian}

::: definition 一部书的三层装配 {#def-sancao}
**文本层**（**通说脉络：希伯来圣经正典与基督教正典目录不同，次经与伪典在各传统中进出；七十子希腊文译本、武加大译本先后成为“权威文本”（**也就是说：被当作原文的，本身已是译本**）；**正典层**（**通说脉络：目录由会议、教会与抄写传统长期确定——**“哪些书是书”先于“书里说什么”（**本章的第一课：**任何研究“圣经文学”的课程，都默认了一份别人签过字的书单（第 1 章目录即审查的最极端版本（**这里的“审查”不是删除，是入围**））；**注解层**（**通说脉络：从教父注经到《四书章句》式的中世纪注疏，文本之外层层加壳（**结果：一部书的“意义”成为一个可继承、可诉讼、可分裂的产业（**中世纪异端的许多案件，争的不是信什么，而是谁有权解释（**这就是第 2 课定义权即分配权的最高标的**。
:::

::: definition 启示与作者权 {#def-qishi}
**通说脉络**（**“默示”观念下，作者被视为器具；摩西五经的传统归属，而文本内部有大量后世编订痕迹（通说脉络：底本学说的形成即以此为基础）——**本课的三个推论（**①**“作者”在这一传统里是权威标签，不是职业身份**（**这与上一章“荷马是编辑假说”恰好对称：**希腊把作品交给一个不存在的个人，希伯来把作品交给一位先知（**两种处理都服务于同一件事：定本的不可追问性（②**因此“抄袭”在此不适用**（**一部引用并改写前圣之书的作品，其荣誉在忠实（**第 3 章“以故为新”在神圣文本里的合法版（③**而它给现代版权留下一个难题**（**至今各译本的版权、公版边界与“译本即作品”的法律地位，仍在解释“启示”与“劳动”谁拥有文本（**本章的冷判：**世界文学市场今天卖的不是原典，是一版一版的译本版权：一部拒绝作者的书，反而养出了最繁复的作者法**）。
:::

## 解释的技术 {#def-jieshi}

::: definition 四重解经与三重义 {#def-sizhong}
**通说脉络**（**中世纪通行的“字面、寓言、道德、灵性（末世）”四重义；有诗概括其分工（**通说脉络**）；与之并行的是预表论：旧约之事为新约之事的“预像”（**通说脉络：亚当在睡眠中所取之肋骨，预表基督之死与教会**）；**汉语的对照**（**诗经的赋比兴与“美刺”、楚辞的王逸章句以“香草美人”为固定的政治比兴、春秋三传与“微言大义”、以及“诗无达诂”这一句口号——**本课把它写成一条比较命题（**两个传统都发展出“文本必另有深意”的解释学，而它们的动机不同：一个要调和神圣文本与教义（**若字面说不通，必有灵意**）；一个要调和经典与政教（**若讽刺不可言，必有美意**）——**结论：**“深意”是权威文本的安全阀——**它同时保护文本与保护读者（**这是本章最有用的一个概念（**它解释了为什么一切“寓言化读法”在被推翻前都显得无懈可击：它不需要证据，只需要一个不能反驳的动机**。
:::

::: definition 一个方法的两份后果 {#def-liangguo}
**后果一：文学获得等级**（**通说脉络：中世纪诗学常把诗归于修辞与虚构，地位低于神学与史；而“神话”被解释为“寓言之衣”（**于是后世为异教故事辩护的万能句式出现：**“它其实是讲……”（**这句话在汉语批评里同样常用（“此诗实刺……”）**——它救了许多作品，也定了一种罪：**故事本身没有权利（后果二：现代世俗解释的谱系**（**通说脉络：从寓意解经到弗洛伊德的梦的解析——**“表面另有真相、真相需被破解、破解有规则”这三条完全是注经术的世俗化（**本课的判词：**现代批评最骄傲的“穿透表象”，是它不肯承认的继承（**第 15 课与第 19 课都会再遇到这笔遗产（**而承认它，是对中世纪最实际的尊重**。
:::

## 文类 {#def-wenlei}

::: definition 圣徒传、武功歌、传奇 {#def-sanlei}
**圣徒传（**通说脉络：圣徒行传有固定的“模板化叙事”：出生预兆、拒婚、苦修、受试、殉道、遗迹显灵**）（**它的读法与小说完全不同：**读者要核对的是“合不合模板”，不是“真不真”（**这是一次对“再现契约”的重新签约（第 6 章“虚构是承诺”：圣徒传是一份不同种类的承诺（②**武功歌**（**通说脉络：英雄史诗在吟诵与记录之间反复成形，抄本常彼此出入（**第 1 章“世代累积”的欧洲版：**《罗兰》没有作者，只有一个反复誊写的战场（③**传奇（**通说脉络：亚瑟王系统由凯尔特素材、法国韵文与后世的散文汇编层层加高（**本课称它为“欧洲的头回与正话”：**框架不断被后来的抄写者改宽（第 9 章话本框架结构的可比项（**而它的终极版本不是某位大师，是一部大汇编（通说脉络：马洛礼一类的汇编本）。
:::

::: definition 宫廷之爱：一次发明的恋爱语法 {#def-gongting}
**通说脉络**（**十一—十二世纪普罗旺斯抒情诗与法国宫廷传奇确立一套爱情话语：仰望的贵妇、被悬置的欲望、公开的效劳与隐秘的关系（**通说脉络：后世学者对“宫廷之爱”是否为制度还是文学约定长期争论（**本课的三个要点（**①**约定与制度的争辩本身就是文学史**（**若它是制度，它是被文学反塑的生活；若它是文学，它证明了话语可以生成行为——**两种答案都指向同一件事：剧本先于演员**）；②**它发明了三样后世用得太多的东西**（**“仰望”作为欲望的结构、**“不得”作为欲望的燃料、**“秘密”作为关系的证据（**这三项至今仍是中国言情叙事的基本设备（第 2 门课丽娘、《西厢》在此得到一份外来对照）**——区别在于：**丽娘的死是对现实的抗议，宫廷之爱的不得是游戏的前提（③**它提供了“元小说”的中世纪原型**（**通说脉络：《玫瑰传奇》后半部由另一位作者续写并讨论“该不该写”；《十日谈》的讲故事框架让叙述本身成为主题（**于是本章最重要的一句：**后现代常用的自我指涉，中世纪已经发明过一遍——**世界文学不是一条进步线，是一台反复取件的仓库（**这是本章对第 15 课“追认”的第一次实战）。
:::

::: example 预表与比兴 {#ex-yubiao}
请把《诗经·关雎》的传统经学解释与一首中世纪释诗（通说脉络：同一首字面为情诗而灵意解为基督与教会）并列，填四栏：**字面、被指定的深意、深意的担保者、若担保者失效则文本会怎样**；并裁决：**两种解释哪一种更“过度”**。
::: solution
**①字面**——**两边都是情诗（**这是全部麻烦的开始：字面太好，舍不得删，也舍不得只留它（**②深意**——**经学：后妃之德、风化之始；灵意：基督与教会（**结构完全相同：**把一首诗升级为一份教义附件（**③担保者**——**关键差别在此：**经学的担保者是师法与家法（**毛传、郑笺、孔疏一条链**）；灵意的担保者是教会权威与预表体系（**于是“过度”之争在两处都无法用文本自身判胜负：它是一场关于谁有权定本的争端——**这就是“裁决”一栏的正确答法：“过度诠释”是一个永远无法在文本内部成立的罪名**）（④担保失效**——**经学链断裂后，《关雎》被读回情诗（**二十世纪的文学史教材做了这件事**）；教会权威式微后，同一首释诗被读回修辞练习（**两边都发生了一次“重新字面化”：**而这恰恰证明“字面”不是自然层，是最新的一次解释（**本课判分：**能写出这一句即为 A——**我们所谓的“本义”，是解释链断裂之后的那一次解释**。
:::
:::

::: intuition 中世纪是一场发明 {#def-faming}
**“中世纪”这个概念本身是后世的产物**（**通说脉络：分期术语由人文主义者与其后的教育制度发明；“哥特”最初是骂人的话，浪漫主义把它改成了资产（**三条推论（**①**每一个“黑暗时代”叙事都是一次自我抬举**（**说别人黑暗，是为了让自己成为黎明（**本课把这一条同时用于中国：“近代以前是停滞的”这一句的功能完全相同（第 11 章进化论条款；②**学科的兴起依赖民族叙事**（**浪漫主义收集民谣、编语法、建大学：**中世纪研究是民族国家的孩子（**所以它现在最难做的部分，是如何在不靠民族叙事的情况下获得预算（③**而研究对象确实存在过**（**这不是虚无主义：**抄本、教堂、诗律与律制都在；被发明的是把它们讲成一个时代的那口气**）——本章的方法论结论：**研究观念史时，把“分期”“传统”“黄金时代”当成三类待查证据，而不是三类现成坐标）。
:::

::: history 一部书的四次转手 {#sec-zhuanshou}
**公元前—二世纪**（**正典成形与译本权威（**七十子译本：一部希腊文译本成为拉丁西方不懂的“原文”——**这是世界文学史上最著名的一次“译本倒位”**）；**四—五世纪**（**拉丁教父与武加大译本；希腊语在西欧退场（**一次语言更替决定了下一千年的阅读方式**）**；**十三—十四世纪**（**方言文学的胜利与但丁（**通说脉络：以方言写最高题材，同时以拉丁论文为方言辩护（**一种语言要成为文学语言，往往需要先用另一种语言写出它的资格申请书——**这一句对理解白话文运动极有用（**同样的申请书是用文言写的**）；**十五—十六世纪**（**印刷术、方言圣经与宗教改革（**通说脉络：**“人人可读”的口号与“译本应忠于原文”的争论同时出现（**翻译伦理第一次成为公共政治问题（第 11 章翻译课的起点）**）；**十九世纪**（**底本学说、历史考据与民间文学运动（**对神圣文本的“去神圣化”研究，与对俗文学的“再经典化”同时发生（**这是本章最漂亮的一个对称（**而两者用的是同一套语文学工具**）；**二十世纪—今**（**文学读法（圣经作为文学）、大众改编、以及各语种的“易读本”市场（**通说脉络：**一部以启示为起源的书，最终以版权、译本分级与影视授权参与世界文学市场（**本章结语：**它没有失败，它只是换成了另一种机构形式——**而这正是下一章要处理的：一个文学秩序如何换掉它的上帝。
:::

::: exercise 小论文：解释学是继承 {level=3}
写六百至一千字，评“**现代批评自称发现了文本的潜台词，其实它只是继承了注经术：相信表面另有真相、真相需要破解、破解有规则且解释权属于有资格者。区别只在担保者换成了方法、理论或学科权威。因此所谓‘从寓言读法解放文本’，从来不是取消深意，而是把定本权从教会移到大学；一旦看清这一点，我们就再也不会把某一种读法称作自然读法**”。须调用：**三层装配（文本、正典、注解）**、**启示与作者权**、**四重义与预表**、**“诗无达诂”的对照**、**世俗解释的谱系**、**“中世纪”作为发明**至少六项；并裁决：**如果一切读法都是继承的解释学，那么一种读法比另一种更好，还能意味着什么——你须给出不依赖“还原文本原意”的判准**。
::: solution
判分点：六项机制（**装配、作者、四重义、对照、谱系、发明**）；判准（**合格答案须给出后果性或可错性一类的判据——**例如：①它能解释多少此前无法解释的形式特征（**例如为什么某文本反复强调“秘密”而非“相遇”**）；②它的担保者可被追问且能回答（**大学式担保者也须接受同行与语料的质询，这与教会式担保的关键差异在于“可替换”**）；③它降低误读的成本而非提高（**判卷看是否拒绝用“更客观”这种词蒙混**）；结论若能写“**所以本章教的是解释学的账目法：每当一种读法自称自然而必然，就问它把定本权从谁手里夺来、交给了谁，以及谁因此不能再说话**”，即 A。

::: summary
秩序归档：装配（**文本、入围书单、注解产业**）、作者（**权威标签，不是职业**）、深意（**安全阀：保护文本也保护读者**）、谱系（**现代“穿透表象”是注经术的世俗化**）、文类（**模板核对而非真伪核对**）、发明（**“黑暗时代”是一种自我抬举**）。方法一句话：**遇到“自然的读法”，先问它上一次由谁定本**。下一章：文艺复兴——当赞助人换了，文学的形式跟着换。
:::
