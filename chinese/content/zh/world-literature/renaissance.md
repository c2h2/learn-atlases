## 定义：一个分期术语的出身 {#def-fenqi}

::: definition 谁发明了“再生” {#def-bukehardt}
**通说脉络**（**“再生”的说法早已有之，而把它做成一整套历史解释的是十九世纪中叶的一部著作（**通说脉络：布克哈特**）；其主张可压缩成一句：**意大利城邦的世界、艺术与冒险精神，是现代“个人”的出生地（**本课的三个动作（**①**把它读成一个论点而不是一个事实**（**它的证据是肖像、日记、自传与艺术家传记（**问题不在证据假，而在推法：这些文类在修道院与宫廷里早已存在（**②**发现“个人”是一种可反证的历史主张**（**通说脉络：后世研究大量指出，所谓近代个人主义的特征在更早的文本里并不稀见（**于是一门学科的成果是：把一句口号研究成了一份需要发票的账单（**③**同时拒绝另一种便宜话**（**“文艺复兴不存在”也是错的：**赞助结构、抄本流通、方言出版与修辞教育确实变了（**本章的立场：**分期不是发现也不是虚构，是一套为行政与课程服务的分类装置，它既真又假（**这句话适用于中国文学史上的任何一次“某某的觉醒”**）。

::: definition 同时代的两本账 {#def-zhang}
**通说脉络**（**就在“人的发现”被写进教科书的同一个世纪，欧洲发生了大规模的驱逐与强制改宗（**通说脉络：十五世纪末伊比利亚的驱逐令与随后的宗教裁判所实践**）；**本课的处理**（**这不是“翻案”，是一次并表（**进步叙事的常规技术是把同时发生的另一些事挪到另一栏（**第 16 课将把这一招命名为“同时代的两本账”，并用于一切“某某时代”的说法）**——它也是本章对“人文主义”的唯一一句道德判断：**人文主义既是一门解放的学问，也是一门关于“人”的资格的课程——**而“谁算人”这一问，恰好在同一百年里被给出了最坏的答案**。

::: definition 印刷：把异端与经典一起放大 {#def-yinshua}

::: definition 乌托邦：一个不肯交稿的承诺 {#def-wutuopang}
**通说脉络**（**十六世纪初一部以“虚构旅行”写理想政制的著作确立了一种文类（**通说脉络：莫尔《乌托邦》一系**）；它的三条语法（**①**“在某处”**（**地理上的不可能性是文本的法律豁免：**我不说这里应当如此，我只说那里如此（**这是第 2 章丽娘一课“梦是管辖区”的空间版本（②**描述代替论证**（**乌托邦的力量在于细写作息、餐食、公职与旅行许可；**它不给理由，只给你一份可住的图纸——**于是它天然要求读者补写“这样代价是什么”——**而作者拒绝补写（③**标题即免责声明**（**通说脉络：书名与序言长期在“玩笑”与“认真”之间摇摆（**本课的判词：**乌托邦是文类的“预付款”制度：**它把读者对现实的全部不满预先存入一个不改动的账户，靠利息过日子（**第 10 课将在科幻与一九八〇年代“寻根”里再遇到它（**并会发现：乌托邦与反乌托邦共用一套排版，只换署名人的态度**）。
:::

::: definition 随笔：把“我在想”写成形式 {#def-suibi}
**通说脉络**（**十六世纪后期一位作家以“尝试”为题自创文类（**通说脉络：蒙田**）；**四个形式特征**（**题目小、结构随思绪、大量引诗而不注版本、结论常自我推翻（**本课的方法论读法（**①**这是第一次把“认错的现场”作为文类卖点**（**上一章的注经术把深意藏在文本之后，随笔把犹豫放在句子当中**）；②**它的诚实是一种特权**（**能写“我错了”的前提是有一位不会追究的读者；**随笔是和平年代的文体（**这一条使我们可以用它测量一切高压写作：能保留多少自我推翻，就有多少自由（第 10 课的抽屉文学在此得到一个可操作的指标**）；③**它给后世留下一件武器**（**“论……的一个片段”这种句式至今是散文的最高自由度格式（**代价是它允许作者在任何地方停下（第 1 门课“随笔与说服的分工”）。
:::

::: definition 十四行、幕表与打破混合 {#def-xingshi}
**十四行**（**通说脉络：从彼特拉克体的 octave 与 sestet 到莎士比亚体的三四句加对句；分节差异对应不同的论证节奏（**本课用第 3 门课的术语称此为“论证的物理形式”：**前八句提出问题、后六句翻转，或三组并列加一句冷收尾——**格律不是包装，是推理的时间安排**）；②**幕表戏**（**通说脉络：意大利即兴喜剧以角色程式与剧情提纲演出，台词现场生成（**这与元杂剧“一人主唱”的声学约束、与话本的“得胜头回”同属一类事实：**在书面定本出现以前，角色比剧本稳定**）——第 1 章“世代累积”的剧场版**；③**打破混合**（**通说脉络：古典主义要求悲剧与喜剧不混，而近代剧论主张混合（**这是世界文学里最干净的一次“规则变更实验”：**改的只是允许哪些并置，改完之后人物的内心才变得可以写（**因为“高贵者说粗话”从违规变成了资源）**——第 7 章“语域”一节在此得到它的历史分量：**语域不是礼貌，是准入。
:::

::: example “一个版本”还是“一个作者” {#ex-banben}
关于近代早期戏剧的一段文本，学界长期存在“较早的异文本”与“后来整理本”之分，并有“某位同代人的补写”一说。请用 180 字写出：**①若采用“作者”框架，你会把哪些差异解释为手误；②若采用“剧团文本”框架，你会把哪些解释为演出与改稿；③两种框架各自会漏掉什么**。

::: solution
**①作者框架**——**把删节、简化、韵脚改动与舞台便利读作抄手之误；**其优点是维持解释的一致性（**一个人格作为错误模型**）；其漏失：**它无法解释那些“显然是为了让某演员更方便”的改动，只能称作“败坏”（②剧团框架**——**把同一些差异读作角色调整、 官方删改、场次增删与演员更替；**其优点是承认文本是协作物；**其漏失：它难以说明为什么某些改动在艺术上明显更好，而“剧团”并不以艺术为目标函数**）——本课的裁决**两个框架的差别不在“是否尊重作品”，而在你把什么当作文本的生产单位（**第 1 章“作者假说”与本章赞助市场在这里对上：作者概念是版权法与传记教育的产物，剧团概念是账簿与演出表的产物（**判分：**能写出“框架决定哪些差异算错误”即本章及格——**这是版本学的第一句话，也是本章对“校勘即道德”的一次脱敏**）——第 1 门课与第 2 门课的“版本即意识形态”在此变成一条可操作的技术规则）。
:::
:::

::: exercise 小论文：分期是行政 {level=3}
写六百至一千字，评“**把历史切成时代是一种行政行为：它先划定疆界与税种，再去找证据；它把某些同时发生的事编入一期预算，把另一些推入赤字。因此每一次分期改革都是一次财政改革——中世纪变短、文艺复兴变宽、启蒙运动从巴黎迁到爱丁堡与苏州，都不是新史料的结果，而是新的纳税人名单。真正可靠的史学方法，是随时准备指出：这一期预算把谁的账记错了栏**”。须调用：**分期术语的十九世纪出身**、**“个人”作为可反证的历史主张**、**赞助结构决定作品边界**、**印刷的四项后果**、**乌托邦的三条语法**、**随笔作为特权文体**至少六项；并裁决：**如果分期只是行政，文学史还能不能有任何时间概念——你须给出一个既不依赖“时代精神”也不退化为编年的替代单位，并说明它如何被证伪**。

::: solution
判分点：六项机制（**出身、可反证、赞助、印刷、乌托邦、随笔**）；替代单位（**合格候选：流通网络（某一译本—书单—期刊的节点图**）、制度装置（版权、审查、教席）、文体寿命（某程式的兴衰**）；须写明证伪条件——**例如：若某文体的兴衰曲线与其载体机构的收支曲线无关，则本解释失效（**判卷看是否出现“若……则本说不成立”这一半（第 3 课：**没有可驳倒性的时间概念只是换了名字的宿命论**）；结论若能写“**所以本章教的是时间上的账目法：不是‘没有时代’，而是任何时代都必须出示它的合并报表——以及那张报表上被合并掉的损失”，即 A。
