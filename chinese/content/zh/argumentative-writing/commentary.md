---
title: "时评与评论"
---

前七章是道场，本章进城——**时评是议论文的成年礼：它要求你在信息不全时开口、在立场喧嚣时举证、并且在自己的文章明天就会过期的前提下，署上真名**。

## 定义：两份合同 {#def-lianghetong}

::: definition 时评的合同：时效与公共 {#def-shiping}
**时效条款**（**“必须现在说”是时评的入场券，也是它的到期日：隔天即罐头（“昨天的义愤今天发，味道不变，营养全失——过期的不是文字，是相关性**）；**由此生出一条职业伦理：快是时评的天职，防反转是它的遗嘱执行人（下节详表**））；**公共条款**（**私事要过一道翻译才配上报纸：“我的早餐涨价”是日记，“早餐价格沿供应链的传导在哪个环节被截留”才是时评——时评的第一道工序是把“我”翻译成“我们”（但第 7 课的审计先走：这个“我们”必须可点名：时评的“我们”=受影响者的清单，不是修辞的拼车**））；**未到期条款**（**“利益相关者还没说完”——公共讨论的程序感：时评裁决的常常不是事实（事实归调查），而是“此事如何处置才算交代”：评论员的权力是追问的权力，不是结案的权力（“越权结案”是时评最体面的滥权：把“应查明”写成“已查明”，稿子发得出去，公信力收不回来**）。
:::

::: definition 由头、议题、论点三步 {#def-youtou}
**由头是钩子不是论点**（**隔夜瓜与好由头的区别：由头正在发生、且利益相关者还没说完——“由头的作用是请读者进门，进门之后你就得开始上账”**）；**议题化**（**把事件从“谁坏”改写成“哪条规则失灵”：同一事件可议题化为食品安全、外包治理、信息公开、家长监督四种——议题选择先于论点，选题的偏见在选题时就已完成（第 6 章广场的机构版：报社的“广场”叫编前会**））；**论点定型**（**走第 2 课全套：可辩、单一、带限定与死法——时评论点的特殊处只在场合：“它必须在 1200 字内可完成验收：大到需要一本书的论点，对报纸是不诚实的（‘废除某制度’类宏大处方，多数时候应改写为‘某条款应按某程序复议’：时评的美德是可执行的谦逊**）。
:::

## 文体谱系：五副面孔 {#def-wufu}

::: definition 声部、牌照与音量 {#def-shengbu}
**消息评论**（**贴战场，一事一议，论证量最小但时效最硬：“它的KPI是快与准，不是深——让快评干深评的活，等于让救护车跑长途**）；**本报评论员／法人声部**（**署名“本报”的“我们”是法人：它有权代表编辑部，也有义务不装成真理——机构署名的文章，论点强度必须低于作者私名的同一篇文章（机构为错别字道歉，也为过头的论点道歉：法人声部的限定词是它的责任保险**））；**专栏**（**个人风格牌照：读者原谅偏激，不原谅糊涂——专栏的特权是“我言之凿凿”，义务是“我随时指名认账”（“签名即担保：无名专栏是时评界的游资**））；**随笔式评论／杂文血统**（**第 16 课匕首与投枪的版面续费：用形象与反讽说理——但皮肤学红线照章执行（反讽在截图中流失：杂文式时评的现代税，交给截图浏览器缴**））；**社论**（**共识倡议体：最高音量配最低信息——所以社论失分最快：它的技术难点是“在必须团结的前提下容纳分歧”（写得好的社论给争论装管道，写不好的给结论刷绿漆**）。
:::

::: definition 配平法与烂尾楼 {#def-peiping}
**千字时评的配平参考**（**一桩（事实核约 200 字）＋一理（机制约 300）＋一驳（让步约 200）＋一案（对策约 200）——配平不是八股，不配平才是八股（全桩无理＝愤青文；全理无桩＝空政文；全案无驳＝广告文——三病的共同病灶：把文体当成安全区**））；**对策段的三问**（**谁执行（具名机构还是“有关部门”——“有关部门”是中文里最大的无人认领账户）、代价谁付（预算与人力从哪儿划拨）、副作用怎么监测（“‘加强监管’四个字的成本记在谁账上：时评烂尾楼集中在对策段：把‘应当加强’当竣工交付**））；**标题＝招股书**（**标题承诺的强度＝全文的信用额度：标题募集“惊人”，正文兑付“一般”，属于虚假陈述（“标题是时评的预支支票：兑现日见人品——而兑现日永远比发表日早于你的想象：反转往往在当天傍晚**）。
:::

::: definition 评论的另一栏：文艺评论 {#def-yiping}
**分工**（**时评处理“怎么办”，文艺评论处理“值不值、为什么”——但两栏共享同一副骨架：论点、证据、让步、限度（“文艺不是免检区：‘这片子让我哭了’是入场券，‘它靠什么让我哭、这算不算好’才是作业”（第 15 课抒情课的写作版：感受要过论证的海关**））；**论据的特殊料性**（**文艺评论的证据是文本细节：一个镜头、一处押韵、一次沉默——引用即举证（“空谈‘演技炸裂’不如指认三秒：第 3 课‘挖机制’在影评里叫‘指出它怎么做到’**”）；**剧透伦理**（**剧透首先是文体合同问题：论证“叙事结构的失效”可能需要剧透到底，那就先声明（“把选择权交还读者：这是评论者与读者的契约精神最小测试**））；**评分可还原**（**星级＝论点，必须能还原成判断句清单（“给七分的理由列表若与给九分的完全相同，分数只是心跳的曲线图**。
:::

::: example 食堂通报：三段式提纲与互相拆由头 {#ex-shitang}
某市教育局通报：多所学校食堂承包企业“食材以次充好”，名单公布、负责人被查、涉事学校取消评优。**任务：①各自把它议题化为四种议题之一并亮桩；②同桌互评：对方的选题在替谁省话；③写“让步段”——为承包企业协会写一句最强反驳，并把它安置进你的正文。**
::: solution
①四议题示例——**监管议题**（“评优挂钩是运动式问责，常态化的飞行检查与家委会抽检权才是要害”；死法：抽检权试点校未改善）；**合同议题**（“校园餐的病根在低价中标：评标规则应设成本红线而非最低价”；死法：成本红线上调后饭菜价格转嫁家长）；**信息议题**（“通报式公开是终点式公开：应建立家长可实时查询的供应链台账”）；**责任议题**（“学校把经营权外包，不能把监护外包：校长陪餐制应从‘吃’升级为‘查’”**）；**互评考点**（**每个议题都在替某个责任人省话：监管议题替企业省了道德叙述，合同议题替监管省了追责，信息议题两头都不得罪但最难落地——把这层“省话地图”画出来，才算看懂选题的政治学（第 6 章广场定律的编辑部版**））；②**让步段范文**（“**承包协会或辩：以次充好是个别企业逐利，不应上升为对集中供餐模式的否定——同一供应链标准下，社会餐饮的合格率并不低。此点在案：模式本身不是病灶。**”——安置方式：放在事实核之后、机制段之前，用“即便如此，校园场景的不可退出性仍然使……”接回（第 6 章让步前置：让对手的王牌在你阵地上打过一遍，再由你收编**）。
:::
:::

::: intuition 速度、反转与延时判断 {#int-fanzhuan}
**时评的头号职业风险是反转**（**而多数反转不是被新证据推翻，是被自己省掉的程序推翻：没等通报全文、没问另一方、没查原始文件——“防反转的三条硬纪律：①关键事实必须有第二独立来源（第 8 章循环引证的执业版）；②涉及具体指控时给被指控方留一行（‘截至发稿未获回应’：这行字是免责条款，也是新闻业的体面**）；③把‘情绪时差’写进排期：最热的一天往往证据最薄——延后六小时的判断，平均质量高于抢跑的判断（“延时不是迟钝，是把判断留在证据到账之后：时评人可以认错，但别养成认错的职业**））。**“抢着判刑”的结构原因**（**平台的奖励函数按转发计费，不按平反计费（第 8 章平台论的时评分账：写作者对抗体制的方式，不是假装自己没有 KPI，而是把 KPI 的差额写进文中（“把‘本文基于截至某时的通报’放在开头，等于给读者安装了撤回按钮：这是数字时代评论者最便宜的诚实**））。
:::

::: history 报章言论的四代声音 {#sec-sida}
**1900s** 报章言论体诞生（**梁启超《清议报》《新民丛报》时期的政论（通说：其“评论时局”一体风靡士林中，“笔锋常带情感”的自述即出于这一文体的自觉——时评在中国的第一身份是“启蒙的讲台”（第 2 课、第 1 课两次会签的文体政变现场**））；**1918—1920s** 新闻学教科书与“社评”文体建制（**通说：新文化运动前后，首批中文新闻学教科书把社论、时评、通信等报章文体分岗定编，写作课自此有了“社评”的岗位说明书——时评从才气变职业，靠的是教材与版面编制，不是名篇**））；**1940s** 大后方的时评与杂文合流（**第 16 课“广场就位”的余响：发表＝在场＝风险——那个年代的“反转险”由检查机关代管，今天的由流量代收**）；**1978** 真理标准讨论（**通说：一篇特约评论员文章引发全国性讨论——中文时评史的能量峰值：它证明一件旧事——言论的权重不取决于音量，取决于它是否说中了制度急需的那句话（时评的理想型样本，也是所有怀才不遇者的温柔陷阱：时代需要的话不是天天有，多数稿子只是把地锄好**））；**1980s—2000s** 时评黄金时代与职业化（**通说：都市报扩版、专栏制与“时评人”职业出现（“写作有了工资条，也就有了编辑部的止损线：署名制把风险写进了身份证**））；**2010s—今** 平台化（**公众号“评论”与官方新媒体评论端并行：发布周期从日缩到小时，“隔夜罐头”变成“隔小时罐头”——职业边界再次重写：今天的时评人一半是作者，一半是自己的事实核查员（第 8 章全员编辑的执业版**。
:::

::: warning 时评四坑
**把愤怒当洞察**（**情绪浓度与机制深度常常成反比：最热的事最难写——因为所有角度都被前六小时占用了：好策略是“做别人省掉的那部分账”（别人骂品行，你查合同；别人查合同，你问监督者谁来监督**”）；**循环时评**（**“要完善制度”“要加强监管”“要落实责任”——三要是万能补药也是零热量：时评的制度批评必须具体到“哪一条、谁执行、如何复议”，否则只是在给制度挠痒（第 2 课“重视体”的社论版**）；**署名越权**（**用“本报评论员”的声部写私人快意（机构信用被你刷了信用卡）或用“网友说”的匿名写法人级指控（该担的责任你逃了）：声部与担责必须同权重**）；**道德人数**（**用“哪个中国人都看不下去”代替证据：绑架式“我们”上报纸就是它的成文法形态（第 7 课人质条款的头条版：解绑只需一步——写出那份受影响者的可点名清单**）。
:::

::: exercise 议题化练习 {level=1}
给同一则新闻（自选本周热点）写四个不同议题的论点句（监管／合同／信息／责任各一），各配一行“此选题在替谁省话”；再选一个写成 200 字提纲（桩—让—理—案）。
::: solution
判分：**四句不得互相转述**（**换标签不换维度＝一个议题穿了四件马甲**）；**“省话地图”必须点名**（**省了谁的话：被骂者、监管者、还是读者自己的行动**）；提纲四件俱全且“案”过三问（谁执行／代价／副作用）。
:::
:::

::: exercise 影评的论证化 {level=2}
选一部近期影片，写 250 字短评，要求：①一个可辩论点；②三处文本细节作证据（镜头／台词／剪辑各一）；③一句“它靠什么打动我”的机制解释；④剧透声明。
::: solution
判分：**细节必须可回查**（**时间点或场景定位——“有一幕”不是举证，是回忆的剪彩**）；**机制句不许用“演技炸裂”类纯感受词**（**指认手法如何操纵你的注意力与期待：第 3 课“挖机制”的银幕版**）；**星级若给出，须能还原为三条判断句**（金句可还原条款的评分版）。
:::

::: exercise 小论文：署名的重量 {level=3}
写六百至一千字，评“**时评的全部尊严写在署名那两个字里：匿名让人敢说，署名让人负责——而评论这门职业的全部技术，就是让一个人既敢说又负责：这是比‘勇气’更精确的美德，叫程序化的勇气**”。须调用：**两份合同**、**议题化与省话地图**、**法人声部**、**配平法**、**对策三问**、**防反转三纪律**至少六项；并裁决：**算法平台上人人都有评论版——“时评人”这个职业还会存在吗（你须给出该职业的不可替代内核，或诚实地宣布它的转型形态）**。
::: solution
判分点：六项机制（**合同＝执业资格；议题化＝政治学地图；声部＝责任会计；配平＝工程规范；三问＝落地监理；三纪律＝安全冗余**）；职业裁决（**参考：内核论——职业不可替代处不在“快”（机器更快）也不在“敢”（匿名更敢），而在“愿意用自己的历史为这一篇担保”：署名是可追索性的载体；转型论——职业并入“核查＋论证策展”：从写手变审计师（判卷看是否有人承认“敢说的激励在下降、负责的技术在升值”——把行业说得疼一点的答案更可信**）；结论若能写“**署名的重量，本质是一种时间承诺：愿不愿意让明天、下个月、以及对手的截图，来看今天这一版——敢在将来被复查的句子，才是现在配被读的句子**”，即 A。
:::

::: summary
进城归档：合同（**时效与公共：把“我”译成可点名的“我们”；评论的权力是追问不是结案**）、三步（**由头—议题化—论点：选题的偏见在选题时完成**）、谱系（**五副面孔，声部与担问同权重**）、配平（**桩理驳案：三要是零热量补药**）、文艺栏（**感受过海关、细节可回查、评分可还原**）、风险（**防反转三纪律：程序化的勇气**）。方法一句话：**先问这份合同允许我说什么，再说别人不敢说的话**。下一章换个馆子：书评影评与推荐语的光谱。
:::
