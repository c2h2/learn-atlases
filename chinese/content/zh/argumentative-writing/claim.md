---
title: "论点"
---

上一章钉了桩；本章给桩做深加工——**论点不是“我想说什么”，是“我敢让人查什么”：它的类型、句法、强度、保险杠，全部可以在动笔前验收**。

## 定义：主张四型 {#def-sixing}

::: definition 是什么／算什么／好不好／怎么办 {#def-sitype}
**①事实主张**（“**课后服务使双职工家庭的接送成本下降”——可查；死法：数据口径**）；**②定义主张**（“**刷单应该算诈骗，不算营销”——争的是分类与名分；死法：立法目的、同类先例（第 2 章“定义权即分配权”的写作现场：定义型论点的全部工作＝说明为什么旧的格子装不下新的事实**））；**③价值主张**（“**烂片该被市场淘汰，不该被审查拯救”——争的是评价标准；死法：价值排序被换掉（“你谈效率，他谈公平：不是谁赢了，是计分表换了**））；**④政策主张**（“**短视频平台应对未成年人默认关闭自动续播”——含执行主体与手段；死法：可行性与副作用（“‘应当’之后必须有人、有钱、有后果：三样缺一，论点只是愿望**）。**错型检验（跑题的病理学）**：**政策题写成价值散文＝把“怎么办”答成“很重要”（上一章第四坑的病历名）；定义题写成事实报道＝以为查清了就赢，其实对面从没否认过事实，一直在抢命名权（“‘电竞是不是体育’的辩论里，赛方从不否认选手训练苦——他们要的是‘体育’这个户口”）；价值题写成事实清单＝“摆数据赢麻了”，可对方一句“数据我都认，标准我不认”就全场归零——**四类主张各自配各自的证据，配错类型，全对也白干**。
:::

## 句法与强度 {#def-jufa}

::: definition 一句话原则与动词法槌 {#def-yijuhua}
**句法验收**：**一个句子、一个法槌动词（应当／必须／可以／值得／不宜）、一个“因为”能装下全文**（“**写得下‘本文认为 X，因为 A、B、C’，论点就存在；写不出 A B C，存在的只是情绪（提纲是对自己开的支票：空头支票骗不了别人，专骗自己**））。**强度三档（逻辑课反比定律的写作版）**（**强命题（“必须立法禁止”）证据链要能扛住全国执法；中命题（“应在 X 场景试点”）只需一个可信的试点设计；弱命题（“值得讨论”）安全但接近零贡献——选档的纪律：把强命题的胆量留给政策句，把弱命题的退路写进限定词，别反过来（新手常见病：主张“禁止一切”，证据只够“试点一个学期”：强度透支＝全文的资产泡沫**）。**限定词＝论点的保险杠**（“**在X条件下／对Y人群／三年内”——限定不是心虚，是给论点装防撞区：杠精专攻无限定的英雄（“‘作业应该减少’是英雄；‘对初二以上、作业时长中位数超 90 分钟的学生，书面作业应设总量上限’是装了保险杠的装甲车：反驳它要先找到那块没限定的地方，而你没有留下那种地方**））。
:::

::: definition 可辩护性三问 {#def-sanwen}
**①有反方吗**（**能立刻说出“谁反对、为什么反对”：说不出就回炉（反对者名单是论点的出生证明：第 1 课“留座”的资格审**））；**②能分解吗**（**能拆成两三个可独立验收的分论点——拆不开通常意味着里面只有一个词在发热（“‘科技改变教育’拆成三句都成立的话之后，你会发现没有一句需要论证：热的是词，不是理**））；**③有死法吗**（**写得出一句“如果……发现……，本论点即告失效”——写不出死法的论点不是坚强，是根本没上场（波普尔的写作课版：可伪条款是论点的投保凭证**）。**三问全过，论点定型；此后全文的唯一职责，是把这三问的答案排成读者愿意走的顺序（第 4 课：结构就是走路的顺序**。
:::

::: example 题面加工车间 {#ex-jiagong}
五个真题或仿真题面，各加工成**带限定与死法的论点**，并标注主张类型：①“垃圾是放错位置的资源”（2019 上海）；②“俗话说：‘车有车道，马有马道’，数字时代，人有人的道”（2023 天津）；③“假如云看不见自己变化的形状／当你如飞鸟一样俯瞰这片土地／你会明白带宽有限，人生无限”（2020 天津）；④“好故事会发生在身边／好故事就在我们身边”（2023 上海）；⑤“他好读书，不好文学”（仿：改造某生“只刷难题不做归纳”的评语体题面）。
::: solution
①**定义型转政策型**（**“‘资源’是一个处理能力的命名：当回收边际成本低于开采，垃圾才配称资源——因此市政分类的补贴应优先投向‘可盈利品类’”；限定：在“成本低于开采”条件下；死法：试点城市分类组的综合能耗高于混合焚烧（“把抒情句翻译成分账句：题面给你情怀，你给题面资产负债表**）；②**价值＋政策**（**“数字时代的‘道’应由路权规则而非平台惯例分配：平台默认设置应当作‘占道’受监管”；死法：监管成本高于事故损失（“车道之喻的相关属性是‘排他与责任’，不是‘快慢’——比喻在论点里的职位是承重测试员，不是董事长**））；③**价值主张＋限定**（**“对已接入网络的学生，‘无限’的风险不是知识过载而是注意力破产：校本课程应增设‘带宽使用’的显性训练”；死法：干预后注意力指标无改善（“题面说人生无限，你的论点敢说‘哪种无限、对谁、多贵’：诗往宽处写，论点往窄处钉**））；④**事实＋定义混合的陷阱题**（**“‘发生在身边’是叙事经济的产地偏见：好故事的标准应是改写了读者的因果表，而非距离——因此语文选文应提高‘远方文本’配额”；死法：对照班读远方文本的共情测量无差异（“警惕：这题的引力是把‘身边’默认成美德——论点敢审题面，才算对等谈判**））；⑤**评语体改写（政策）**（**“‘只刷难题’是反馈周期的错配：难题的单题信息量大但单位时间信息率低——应设‘归纳时段’强制占比 30%”；死法：加归纳时段后测与刷题组无差（“把批评改写为机制，再把机制改写为可试的处方：评语体的议论，最容易从定性滑向处方，本章教你主动走这条路**）。
:::

::: intuition 论点是个甲方 {#int-jiafang}
**论点是全文的甲方**：**材料、结构、语言全是它的乙方——甲方定错了，工程越努力越尴尬（“素材库救不了错论点：它只会把危房装修得更像样板间**）。**养甲方三步（动笔前的验收单）**（**收窄（大题小作：“谈骨气”不如“骨气在和平年代的兑换率”——**刀口越窄，切口越深（第 2 题的“道”只取“路权”一义：**一词一义是论点的开工证**））；**换位（把自家论点站到对面阵营里念一遍：会心一笑还是如坐针毡？如坐针毡才是好消息）**；**预算（为每个分论点预估证据成本：A 要查年报、B 只要一个实验、C 要访谈——排不出成本表的论点，会在半夜两点被你本人推翻**）。**论点的道德感**（**别用修辞抬强度：把“值得试点”写成“必须立法”以壮声势，是把全班的诚信押在自己胆量上——议论文最早的品德教育：不夸大自己的命题，如同不篡改别人的立场**。
:::

::: history 论点观的几次换代 {#sec-huandai}
**先秦** 立言与立义（**《易传》“修辞立其诚”——论点伦理的祖句：诚在先，辞在后；墨家“以说出故”——论点必须有故可依（逻辑课第 10 章的正式访客**）；**汉** “论”成体（**王充《论衡》自序其例：“疾虚妄”——为“论点必须可辩可查”立了行业门规；《过秦论》式的“一家之言”开始有版权意识**）；**南朝** 《文心雕龙·论说》（“**圣哲彝训曰经，述经叙理曰论”——把“论”从经的附庸里登出独立户口的籍贯页；“义贵圆通，辞忌枝碎”——论点验收标准的骈文版**）；**宋** 议论文与新文体的先声（**王安石“务为有适用而作”——论点带着工程需求出场；苏轼翻案文把“取径逼仄”做成方法：论点=角度的自觉时代**）；**清—近代** 经世文与报章（**魏源《海国图志》与经世文统（通说：论点开始对“效果”负责——“师夷”之论先问“管用不管用”，再问“体面不体面”；梁启超新文体——论点学习在杂志上连载：论点开始对“发行量”负责：两种压力至今在考场作文的血管里开会**）；**1917 后** 文体学进入课程（**国文教科书设“议论文”科目（与记叙、说明、应用并列的四分法沿用至今：这是中国写作教学史上最大的一次体裁立法——四分法既是地图也是铁轨：一代代人把“可辩之点”开往“议论”这条轨道**）；**当代**（**图尔敏式“主张＋限定＋反驳”进写作教材；高考评分标准里的“深刻”条款（透过现象深入本质、观点具有启发作用）——国家考试用评分细则给“论点观”发年度版号（第 10 课细读这份合同**）。
:::

::: warning 论点四坑
**“重视体”论点**（“**我们应当重视阅读”——重视无主语、无预算、无死法：三无一死的句子不配当甲方（改写：谁、花什么、换什么**））；**定义走私**（**“真正的读书是精读”——用定义偷渡结论（第 2 章免疫化的写作发作：一旦你的论点里住进“真正的 X”，请出示该定义的租金合同**））；**一题多夫**（**前半篇论证“要慢”，后半篇论证“要快”：两个甲方共租一栋楼，施工队只能把楼盖成 S 形（发现办法：检查“因为”能装几句——装不下的都是前夫**））；**强度虚荣**（**为显得深刻而加码：“应该”升“必须”、“必须”升“唯有”——深刻不在调门，在机剖（评分标准里的“深刻”指的是机制层，不是音量层：把“必须”降回“值得试点”而证据密度不变的文章，分数常升不降**。
:::

::: exercise 三问验收 {level=1}
给五条自造主张做**可辩护性三问**（反方名单／分解表／死法条款），不合格者就地改写：①“读书使人进步”；②“学校食堂应该更好吃”；③“网络游戏导致青少年近视”；④“真正的强者都孤独”；⑤“班级日志值得试行三个月”。
::: solution
判分：**三问各给一句可核查的答案**（**“进步”要落到指标；“更好吃”要定义谁嘴、预算谁出；“导致近视”与“相关”分账＋混杂（户外时长）；“真正的强者”＝定义走私现行犯；⑤政策型最健康，仍要写死法（“三个月后班级事务透明度无变化即撤**）；改写合格线＝**反对者会出现在名单上且认得出自己**。
:::
:::

::: exercise 强度调档 {level=2}
把同一内核调三档写出（强／中／弱各一句），并为每档配**匹配的最低证据**：**“手机与成绩”**议题。再判定：校报、家长会、向教育局建议，分别该用哪档。
::: solution
判分：**三档分明**（强“应全面禁带”＝需全校对照实验＋执法成本；中“建议课堂统一收纳”＝需一个试点班数据＋纠纷率；弱“值得讨论”＝只需说明争议现状**）；**场合配档**（**校报可用中档并留讨论；家长会中档＋情绪管理条款；建议信宜中偏高但必须附可行性与预算——场合的听证级别决定命题的强度上限：错档发言，是论证界的越级上访**）。
:::
:::

::: exercise 小论文：论点的死法 {level=3}
写六百至一千字，评“**一个没有写死法的论点，是对读者的绑架：它把‘我可能错’外包给了别人去发现——好作者提前认领这笔债**”。须调用：**主张四型与错型检验**、**一句话原则**、**强度三档与场合配档**、**限定保险杠**、**三问验收**、**“重视体”与“定义走私”两坑**至少六项；并裁决：**考场作文只有 90 分钟，要不要放弃“死法条款”这类奢侈品——给出你的“考场最小可运行论点”规格**。
::: solution
判分点：六项机制（**配型、句法、调档、保险、验收、坑位**）；裁决（**参考：90 分钟里死法条款不是奢侈品是省件——它替你砍掉两个写不完的分论点（“有死法的论点自带篇幅预算”）；考场最小规格：一句话＋一限定＋一反方＋一行死法（约 60 字），其余全是施工（判卷看是否有人把“放弃死法”论证成理性（如“篇幅换置信度不划算，改用让步句替代”：也算成立，但须承认这是降级而非免票**）；结论若能写“**写死法不是诅咒自己的房子会塌，是声明：这房子经得起查、也赔得起——论点的全部信用，来自作者敢于留下的那处软肋**”，即 A。
:::

::: summary
加工单归档：四型（**是什么／算什么／好不好／怎么办：配错类型，全对也白干**）、句法（**一动词一因为；写不出 ABC 就别动笔**）、强度（**场合决定上限：别用胆量代替证据**）、保险杠（**限定是防撞区不是遮羞布**）、三问（**反方、分解、死法**）、甲方论（**论点定错，装修越勤越尴尬**）。方法一句话：**先让论点输一次，再让它上岗**。下一章查账：证据的种类与诚实。
:::
