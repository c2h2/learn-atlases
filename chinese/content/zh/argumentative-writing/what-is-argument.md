---
title: "什么是议论文"
---

逻辑课发了秤，本章开工盖房——**议论文＝把论证写成别人愿意读完的散文。它的第一个定义是否定性的：议论文不是“我有观点”文，不是抒情文换了标点，更不是三段口号的合唱**。

## 定义：可辩之点 {#def-kebian}

::: definition 题目、论点、主张、口号 {#def-sige}
**题目≠论点**（“**《谈骨气》是题目；‘骨气是穷人的不动产’是论点：题目是地盘，论点是你在地盘上钉的桩——检查法：题目后面能不能接‘我认为……，请你不必同意’：接不上的就只是话题（‘论’‘说’‘谈’‘浅议’：体裁招牌不是论点；《我的理想》更不是——它默认你只要交代，不需要论证**）；**论点＝可辩之主张**（**一句话、可同意可反对、有对立立场存在（“‘吸烟有害健康’今天不算论点——它是没人反对的常识：论点要有输的可能：一个不会输的命题不配开文（第 3 课限定词回访：把常识加回争议浓度，它才重新成为论点——‘吸烟有害健康’写成‘公共场所禁烟的收益大于执法成本’就有得辩了**））；**主张≠口号**（**口号是论点的压缩饼干：它供传播不供检验（“‘我命由我不由天’：金句、表情、转发齐活——它作为论点需要三页纸，作为口号只需要一口气：议论文的训练就是把金句还原成负债表**）。**一篇只许有一个总论点**（**多点并立叫合集：高中作文的“中心明确”不是美德，是审计要求——总论点只有一个，分论点给它打工；发现有两个总论点，说明你写了两篇半**）。
:::

::: definition 文体合同：议论文与它的三个邻居 {#def-hetong}
**与说明文**（**说明文回答“是什么”，不要求你树敌；议论文必须有一个假想的反对者站在对面（第 5 课“聚焦≠同情”的写作版：反对者不是敌人，是你的第二个读者兼质检员**）；**与抒情文**（**抒情文的真理性靠诚（“我真的难过”），议论文的真理性靠据（“我说的成立”）——两者可以合租（鲁迅的杂文就是带体温的论证，第 16 课），但账目要分：感动不能入账为论据（第 1 课眼泪收据**）；**与驳论文**（**驳是立的特殊工序：先破后立、边破边立——不是文体是工种（第 6 课专章**））。**总合同**（**议论文与读者的契约：我承诺①一个说得清的立场②拿得出的理由③对反方诚实——读者承诺①读完②按理由而不是按交情裁决：违约可以从作者开始，因为读者随时可以离场——新媒体时代，他的离场以毫秒计：这就是为什么今天的开头段都在改写“契约谈判”：第一句就得报出“我要跟你辩什么**”）。
:::

::: example 同一题的四种开头 {#ex-siktou}
题：《手机该不该管》。四种开头，判断各签的是哪种合同（说明／抒情／口号／议论），并给第四种打分：①“**手机，一种二十一世纪的通讯工具。**”②“**夜深了，屏幕还亮着，像一扇不肯关的门。**”③“**管住手机，赢回人生！**”④“**学校普遍禁手机，但我不认为禁令提高了成绩——它只是把课堂失败改名为纪律问题。**”
::: solution
①**说明文发票**（**定义正确、零风险、零论点：读者会等你亮桩，而耐心只有三行——“从词典释义开头”是议论文最普遍的违约：把说明当论证的起点，往往说明作者还没决定反对谁**）；②**抒情合同**（**比喻漂亮且真诚——但它承诺的是感受不是理由：作开头段是借了议论文的钱买抒情的货，第二段必须还本付息：接“我的成绩因此……”就又违约（个人轶事是证据的香料，不是主菜**））；③**口号**（**压缩饼干：语气在替论证走路——“赢回人生”这种短语是修辞的预付卡：刷起来痛快，兑付全靠作者补写：而补写恰恰是全文的工作量**）；④**签合同**（**可辩（有人主张禁令有效）、单一（禁令与成绩的关系）、有对立面的位置留好了（“普遍禁”三字承认现状——让步的痕迹从第一句就在），且暗含全文结构（先立“没提高成绩”的事实层，再辩“改名为纪律问题”的机制层：第 4 课的谋篇从第 4 句就开始**）；**打分：④满分——注意它的语气并不强硬，甚至带让步：好论点的标志不是音量大，是反对者能在同一页找到他自己**。
:::
:::

::: intuition 你不是在演讲，是在寄挂号信 {#int-guahao}
**演说的模型是人群，议论文的模型是一封会被转寄的挂号信**（**读者会：挑着读、转发给对手、截图你的破绽、并在三年后翻出来——“因此每个句子都要经得起‘被最有能力误解你的人转述’：这是钢铁人原则的写作版：先按最恶意也最聪明的读法自审**）。**写作的逻辑学红利**（**说一遍就忘，写下来可审计：文字把瞬时的情绪定住成可检验的账目——这正是从韩非“难”体到图尔敏版式一脉相承的执念：把说理从口头的天气变成书面的地质（第 8 课“难”体与六项的会师：为什么论辩术最终都需要文体学：因为说服有听众，论证有读者**）。
:::

::: history 议论文的四种职业 {#sec-zhiye}
**前 3—前 2 世纪** 游说士与“难”体（**韩非《难》篇：逐段引述对方立场再逐段拆——史上最早的“反驳体”作文模板：它的存在说明当时已有“标准论点”可供难（第 8 课：每个时代都有自己的“可辩之点”库存**）；**汉** 政论与奏疏（**贾谊《过秦论》以气势立论、晁错《论贵粟疏》以算账立论——中文议论文的两条原始赛道：调门派与账房派，至今分金煮酒各据一方**）；**唐—清** 科场“论”与“策”（**《文心雕龙·论说》早立了法：“**义贵圆通，辞忌枝碎**”（论要圆通＝无死角；辞忌枝碎＝别炫技）——**八股文的“小题”训练（“学而时习之”写三百段破题）把一纲多目练成了民族肌肉，也把可辩之点驯化成了代圣立言：议论文在科举里的双面遗产（第 9 课考场的远祖：考试塑造文体，文体反塑思维**））；**1902—1920s** 报章政论（**梁启超的“新文体”（自述“笔锋常带情感”，体务奔放——**情感与逻辑在报纸上合股：发行量是第一位读者；胡适改以“作文章如说话”为纲：刍议体把姿态放低到“刍”（割草的），论证的权威从圣贤挪到方法（第 16 课“白话不是被杀死是被停止报销”的孪生事件：文体政变**）；**1977—今** 考场（**高考恢复：议论文成为一亿人的写作母语——每年六月全国同题共答：这是世界上规模最大的定期论证资格考试，也是“可辩之点”的年度招标：“本手妙手俗手”“故事的力量”——题目年年出，等于给你发一张辩题委托书**）。
:::

::: warning 开工四坑
**词典开头依赖症**（**“XX，字典里解释为……”——把说明文当安全区：三行之后读者知道你要论证一个没人反对的东西：从共识开头，往争议走；别从释义开头，往空白走**）；**例子替论点值班**（**开头爱迪生、中间司马迁、结尾感动中国：三个故事之间没有论证的钢筋——“举例子是论证的工序之一，不是全部（第 3 课）：例子之间必须有一句“因此说明”：没有这句，文章是货架不是仓库**）；**假装没有反对者**（**通篇单向输出：最危险的读者被开除——真正的写作是给他留座位（“‘有人会说……但我还认为……’不是示弱，是结构零件：让步句是承重墙上的梁（第 6 课）**）；**把“意义”当“证明”**（**“这件事很重要”讲三遍——重要性不是真理性：价值与事实两本账（第 1 课“是/应当”之分）：你论证的是“对不对”，不是“重不重要”：很多作文跑题没跑远，只是把证明换成了强调**）。
:::

::: exercise 造桩 {level=1}
给五个题目各钉一根**可辩之桩**（一句话论点＋一句“谁会反对、为什么”）：①《谈韧》；②《 AI 与作业》；③《远方的风景》；④《规则与人情》；⑤《熬夜晚点名》。
::: solution
判分：**桩子要能输**（**“韧是美德”不合格——没人反对；“逆境中‘放弃训练’比坚持更能提高成功率，因为我们从未为放弃设计过课程”合格：它敢让人立刻找茬**）；**对立面要具体**（**不是“有人可能不同意”，是“班主任与家长委员会都会反对，理由是课堂秩序优先于个体节律”——对立面越具体，下文越好写：写作的作弊常从模糊的观众开始**）。
:::

::: exercise 开头段手术 {level=2}
取自己旧作一段开头（或仿写），做三种手术：改写成说明文开头、口号开头、以及**合格的合同式开头**（含一个让步句）；用五十道批注说明三版各自的得与失。
::: solution
判分：**得与失必须不对称**（**说明版得安全失无桩；口号版得流量失兑付；合同版得多花两行给反对者让座——把“代价”写成两行的考生，说明他真懂合同不是装饰**）；批注里禁用“更好”“更生动”（**换掉形容词，写机制：哪个句子在替谁工作**）。
:::
:::

::: exercise 小论文：论“可辩之点”的通货膨胀 {level=3}
写六百至一千字，评“**当一个社会把所有问题都变成‘观点之争’，可辩之点就通货膨胀了：连重力该不该存在都可以‘我觉得’——救币的办法不是禁止表态，是恢复兑付：每个‘我认为’后面要能跟出‘因为’，以及‘怎样算我说错’**”。须调用：**题目≠论点**、**口号的兑付义务**、**反对者留座**、**“重要性≠真理性”**、**第四种开头的结构预告**、**1977 后“年度招标”**至少六项；并裁决：**人人都能发观点的时代，是论证的黄金期还是坏账期（你的方案须包含一条“作者自己先遵守”的纪律）**。
::: solution
判分点：六项机制（**钉桩、兑付、留座、分账、结构、招标**）；裁决（**参考：黄金期论——检查成本下降、多方在场即进步；坏账期论——表态零成本导致劣币；判卷看方案（“兑付纪律”示例：每个主张附可伪条件——‘我认为作业应限总量，若本校试点后睡眠时间未升而焦虑未降，我即收回’：写不出这句的，自动降级为心情日记——‘我觉得’的自由，是以‘我怎样算错’的义务为准备金的：央妈不发货币，发的是可验证性**）；结论若能写“**议论文的全部尊严在于它随时可以被反驳，并且作者把这个‘随时’写在了明处：这就是开头段的工作——先告诉世界：我在这儿，我错在哪儿**”，即 A。
:::
:::

::: summary
开工归档：四件（**题目是地盘、论点是桩、口号是压缩饼干、一篇一纲**）、合同（**对读者承诺立场—理由—诚实，给反对者留座**）、开头（**从共识往争议走；第四种开头的让步句是梁不是疤**）、职业史（**难体—政论—科场—报章—考场：考试塑造文体，文体反塑思维**）。方法一句话：**钉一根输得起的桩，再开工**。下一章立论点的深加工：主张的类型与强度。
:::
