title: "证据"

论点是要钱的，证据是付款方式——**上一章立了甲方，本章开始查账：议论文的信用，一半写在论点里，一半写在“作者引用与转述事实的方式”里**。

## 定义：五座料仓 {#def-liaocang}

::: definition 证据的料性与用法 {#def-wulei}
**①事实与数据**（**硬度最高、也最易被使用不当：数据四查在第 8 章已授（分母、基数、口径、图例）——写作课补第五查：用途错位（“把 A 调查的百分比引去撑 B 结论：数据没撒谎，是搬运工换了收货单**））；**②权威言论**（**合法域＋分歧幅度两个开关（逻辑课第 1 章回访）：写作要求是“引用共识、标注分歧”（“‘专家认为’要写成‘多数心血管学会的意见是……，少数研究者保留意见’：权威的正确用法不是终场哨，是可查的中间站**）；**③法规与文本**（**议论文里的“文件原文”是稀有硬通货：引用要带条款号与生效期（法规会废止、指南会更新：引一条 1998 年的文件处理 2024 年的纠纷，等于拿旧地图打新仗**））；**④个案与轶事**（**岗位问题见下节：个案是好的证人，坏的证人会长**））；**⑤经验与直觉**（**“我做了十年班主任，一看就知道”——它有资格作为“启动假设”入场，没有资格作为“结论的终点”：老班主任的直觉是压缩的数据库，解压后大多能查到出处，查不到出处的那部分叫成见（第 1 课“语感是统计的产物”的行业版**）。**共同纪律**（**证据的价值＝来源×相关性×时效——三项任一为零，乘积为零（“‘真实、重要、但过时’与‘生动、相关、但来源不明’是同一种废票**）。
:::

::: definition 个案的三个岗位 {#def-gehgang}
**岗位一：证伪全称**（**一个反例杀一条定律（逻辑课第 1 章的满格效力）——“‘只要努力就能上重点’被一个具体的人击穿：个案在这里是狙击枪**）；**岗位二：例证／具象化**（**规律已在别处确立，个案负责让读者看见它长什么样——“统计说辍学者里 60% 是女生，小 D 的故事让这个数字有了脸：合法且必要：抽象的正义感不动人，动人的正义感才募集得到行动（论文不该求人感动，但政策论证的读者确实需要一张脸**））；**岗位三：开场诱饵**（**用一个故事把读者带进争议——但要紧的是它只领门票不领工资：开场轶事必须在第二段“退役”，全文的承重交给结构与数据（爽文的标准死法：开场故事＋数据化妆＋结尾回到同一个故事——首尾呼应的修辞闭环里，一个孤例被供成了神**）。**越权就业**（**“我邻居／我同学／我爷爷”出任主证＝用轶事的存款办全款的业务：识别法——把个案删掉，论证是否照常成立？照常，说明它是装饰；崩塌，说明全文就靠它一个人扛楼（一人扛楼的论证，验收标准只有一条：那个人必须站得住到终审**）。
:::

## 引文三德 {#def-yinwen}

::: definition 不断章、不转义、不装裱 {#def-sande}
**①不断章**（**把“游戏是……的麻醉”前后两段拼起来常常是另一句话：引文的邻居不是废话，是它的法庭（操作：引 15 字以上必查上下文各一屏；引用译文必核原文与译者——转译的引语是二手烟**））；**②不转义**（**名言旅行中义变：“民可使由之不可使睹”的句读公案（传统句读本有分歧，标点一挪立场翻转）——古文的引文自带“断句风险”，这是中文议论文特有的雷区（对策：有争议的引文降级为“大意”，不供在引号里当证据**））；**③不装裱**（**用名言当画框代替论证：“‘鲁迅说’三个字不是论据，是论据的包装盒（查包装里的货：鲁迅在哪篇文章、对谁说的、那一年在吵什么——“名人的每句话都归他当时的战场所有：把 1925 年的弹药插到 2025 年的墙上，先查膛线**）。**查源规程**（**名言先查最早出处，再查是原著还是转引，最后查语境——教科书级的示范对象恰恰是“事实自己会说话”这句流行话：它的考据常停在 19 世纪报人的转述层，原典难觅（本课只立规程不背引文：查源流程比任何一条引文都值钱——它是这门课唯一让你带走的嫁妆**）。
:::

::: example 爽文全面查账 {#ex-chazhag}
读这段“数据详实”的爆款节选，开**查账报告**（病灶至少五处，每处开一张整改单）：
“**权威报告显示，90% 的家长支持推迟上学；某重点中学试行后，一本率上升 30%。校长说：‘我们只是把孩子的睡眠还给了孩子。’数据显示，睡眠不足青少年的比例高达 78%，‘这不是个例，这是时代病！’专家称，推迟上学一小时可提升 GDP。**”
::: solution
病灶示例（**五处起步**）：**①“权威报告”无主体无年份无样本框**（整改：补“谁、何时、何机构、N 多大、在哪个广场（家长群体内部也分层——重点校家长与普通校家长的“支持”是两个物种**））；**②“一本率上升 30%”三缺**（基数（从 1% 到 1.3% 也是 30%）、选择偏差（“某重点中学”＝名校效应与生源自选择）、时间窗（整改：补对照校与差分口径（第 7 章的“借田”技术在这里上班**））；**③引语越权**（**校长的话是抒情不是数据，作为“措施实施者证言”合法、作为“措施有效”的证据非法：谁受益谁发言，发言算立场不算证明**）；**④“78%”与“时代病”之间的逻辑跳板**（**患病率数字＋修辞升华＝把事实主张直接升格为政策主张的中间环节全部省略（补链：睡眠不足→学业损失→推迟上学为最优解——每一环都要单独交货**））；**⑤“专家称……提升 GDP”**（**跨尺度空头（睡眠—学业—劳动力—GDP：因果链长到不可验证，滑坡的乐观镜像；整改：要么给模型与假设，要么删——“‘专家称 GDP’类引语在本文里出现的瞬间，可当作作者的信用熔断器**）；**加分项**（**通篇未出现一个反方数据或反对意见：第 1 课“假装没有反对者”的总爆发——查账报告最后一行：建议整篇降格为“愿望综述”**）。
:::
:::

::: intuition 事实不会自己说话 {#int-shishi}
**“摆事实”是个诚实的动作，只要你不假装事实会列队点名**（**你选的每个事实都经过四道门：搜得到、看得上、查得到源、敢署名——四道门都是你的指纹（所以写作课的诚实不是“不撒谎”的低标准，是“把选择偏见申报出来”的高标准：主动写出“本文数据多来自城市学校研究，农村结论需谨慎”一行，胜过通篇“客观地说”**）。**硬料与软料配比**（**议论文不是数据报表：全硬则读如验尸，全软则读如算命（配比参考：事实层硬、机制层明、价值层真——硬料负责真，软料负责通：引语与个案的正确职能是让硬料被人读懂，而不是替硬料作保**）。**多源冲突的处理**（**同一事件三份自述互相矛盾时（招生纠纷、师生冲突）：作者的职业操守体现在“并陈＋评估可信度维度（利益相关度、时间近度、细节可核度）”，而不是替读者提前和好（罗生门不是没真相，是真相需要仲裁程序：议论文作者经常身兼证人、律师与法官——最少要声明今天戴哪顶帽子**。
:::

::: history 证据观的两条传统 {#sec-liangtiaotong}
**中国一路**（**孔子“文献不足故也，足则吾能征之矣”——“征”＝举证责任的先秦铭文；《中庸》“博学之，审问之，慎思之，明辨之，笃行之”——证据处理的五道工序（教材把“论”的素材标准一路接到“审问”上；王充“疾虚妄”＋清儒“无征不信”的考据门规——**中文写作里“引证”的传统比“论证”的传统厚：这是遗产也是陷阱：长于征引、短于推演，章学诚“六经皆史”把经降为史料，反而给“凡引皆可查”立了宪（第 2 章定义权：考据学是中文世界的可验证性运动，只是它的对象是文本不是世界**））；**西一路**（**亚里士多德“例证 paradeigma 与演绎 syllogismos 是论证的两种基因”；1605 培根《学术的进展》奠基经验取证；19 世纪“史料批判”方法化（**通说：以兰克学派为标志的史料考证制度化，让历史学从文学里分户出去——“每个学科都在 19 世纪给自己的证据立了海关”；20 世纪循证医学把“证据等级”做成金字塔（第 8 章）——**写作课的证据观其实是各学科海关的合并报关单**）。**中文系的交汇**（**1917 后“引证法”进国文教科书；1980 年代议论文“论据三要素（事实、道理、数据）”定型；2010s 后“事实核查”作为新文体职业进场——**证据的诚实从士大夫的自律，变成编辑的规范，再变成可外包的岗位：每一次外包都让“自查”生疏一分：所以本章要在你最不需要查账的年代，把查账的手感练下来**）。
:::

::: warning 证据四坑
**装饰性引用**（**引文越堆越多、功能越来越小：引用不是配菜是结构件——每引一句要能回答“删了它论证塌不塌”（不塌就删：名言不是护墙板**）；**平均数骗局**（**平均数三兄弟（均值、中位数、众数）混用：“平均月薪 2 万”与“中位数 8 千”同时为真且都在说真话——报告者选谁，就是立场（写作对策：涉收入房价一律标注用了哪一个**）；**二手引用链**（**从公众号引鲁迅、从论文摘要引实验、从书评读书——每一跳都是转义风险（规程：重要证据追到一手，次要证据标明“转引自”：转引不是罪，隐瞒转引才是**）；**时效失修**（**“据统计”后面是 2009 年的普查：数据会腐烂，法律会更新（交付前全文搜“年”字重读一遍：这是最便宜的质检，也是最能救命的**）。
:::

::: exercise 查源实操 {level=1}
选三条广为流传的“名人名言”（自定），做完整查源：最早出处→是否原典→译文/转引链→语境（他那年在吵什么）→结论（可用为论据／只能作“大意”／建议弃用）。附五十个字复盘：**哪一跳最容易失守**。
::: solution
判分：**流程完整重于结论对错**（**查不到也要写出“查了哪里、停在哪一跳”——负责任的“存疑”合格，漂亮的“据说”不合格**）；复盘考点（**最危险的一跳通常是“从二手到一手”：人人都以为别人查过（第 8 章循环引证的个人版：引文界的三家外媒**）。
:::
:::

::: exercise 一份数据的旅行 {level=2}
跟踪一个公开数字（如“网民规模”“离婚率”）从原始发布到三个转述版本的变化：列表标出每一跳损失或添加的口径（分母、年龄段、城乡、年份），并写一句**该数字在你文章里能撑住的最强主张**。
::: solution
判分：**三跳对比表**（**常见病灶：抹去年份、抹去年龄组、把“离结比”讲成“离婚率”——口径蒸发三部曲**）；**最强主张与数据同宽**（“‘2023 年我国离结比为 X%（民政部口径）’撑得住；‘一半婚姻正在破裂’撑不住：数据的腰围决定句子的裙子”。
:::
:::

::: exercise 小论文：证据的诚实是一种文体 {level=3}
写六百至一千字，评“**证据的诚实不是道德标语，是文体特征：它写在括注里、写在‘转引自’三个字里、写在主动申报的局限段落里——读者不一定查，但永远感觉得到：文章的气场，就是可查性的气场**”。须调用：**三项乘积**、**个案三岗位**、**引文三德**、**选择偏见申报**、**二手引用链规程**、**平均数三兄弟**至少六项；并裁决：**AI 生成引用（包括编造文献）批量出现的年代，写作者的“可查性纪律”是负担还是护城河——给出你的行业规范草案（至少三条，含一条针对自己）**。
::: solution
判分点：六项机制（**乘积、岗位、三德、申报、链条、口径**）；裁决（**参考：负担论在短期内成立（自查慢于机编），长期看可查性是稀缺品——当引用泛滥，“带完整出处的句子”溢价（通胀时代的硬通货逻辑）；规范草案示例：①关键数据双源；②转引必标；③对自己——每个主张默写“死法”（与第 2 课闭环：判卷看三条是否真有一条“对自己更狠”的（只约束别人＝第 8 章对称怀疑主义：你仍是球迷**）；结论若能写“**证据的诚实最后是一种时间美学：撒谎的句子即刻生效、逐年贬值；诚实的句子慢半拍、却按复利升值——写作的人终究是在利率里生活**”，即 A。
:::

::: summary
查账日归档：五仓（**数据、权威、法规、个案、经验——来源×相关性×时效，一零全零**）、三岗位（**证伪、具象、诱饵：别让它越权就业**）、三德（**不断章、不转义、不装裱**）、配比（**事实硬、机制明、价值真**）、规程（**追一手、标转引、查年检**）。方法一句话：**每一条证据都按“对方会请独立审计”的标准交货**。下一章给证据接上推理的电路：论证方法。
:::
