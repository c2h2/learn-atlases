title: "考场作文"
---

结业章回到那间九十分钟的屋子——**考场作文是把整门课压缩成交付的能力：题面是合同，时间是预算，阅卷人是只给你两分钟的甲方：本章不教投机，教的是把认真做成流水线**。

## 定义：题面即合同 {#def-hetong}

::: definition 三条约款 {#def-santiao}
**①任务条款**（**“写一篇演讲稿”“给校长的一封信”“与青年读者交流”——文体与声部义务（第 5 课小标题糖衣的反面：文体不是包装，是第二论点：演讲稿的论据要适合被听见，书信的论证要适合被一个人收到（“‘演讲稿’三个字意味着：有在场的人、有你的嗓音、有可以被鼓掌打断的节奏——把它写成论文，等于穿着泳装出席听证会**））；**②材料条款**（**材料是地基，不是天花板：引材料开头是交钥匙，通篇复述材料是替房东看房（“摘材料 200 字＋例柜 300 字＋喊话 100 字”的“三段式”之所以是零分标本：它履行了引用义务，拒绝履行论证义务**））；**③评分条款**（**“深刻”＝机制层（第 2 课回访：不是调门高，是你说出了别人没看见的因果；“丰富”＝一材多用的层次；“有文采”＝准确的强调位与节奏（第 7 课）；“有创意”＝角度的窄与深——把四条从玄学翻译回词条表，发展等级就不是运气，是选配清单**。
:::

::: definition 审题四步与跑题三级 {#def-shenti}
**四步**（**①圈任务动词（写什么体、对谁说话、完成什么动作）；②辨主张类型（这题要的是事实、定义、价值还是政策？——四型错配是跑题的最深河道（“‘该不该’出现＝政策或价值；‘是什么’出现＝定义谈判**）；③**找谈判词**（**题目给的不是论点，是几个要去谈判的词：“本手、妙手、俗手”“故事的力量”——先在草稿纸上给每个关键词划出它的解释光谱（本手＝基本功？规则内？守成？），选一个并声明（第 2 课：定义权即分配权——考场里，分配权在你手里，这是题面让给你的**）；④列让步位（**这题最强的反方是谁——列不出，你的文章在考场上也会很脆**）。**跑题三级**（**误读任务（写成了体裁判定：把“给青年读者”写成给领导汇报）＜ 偏题（谈了关键词但换了维度：谈“故事的力量”写成“要多读书”）＜ 套作（穿着别人礼服的尸体：背来的范文与题面只有两个词的同学关系——三级同罪：没有履行本合同：判分不看你想说什么，看你交了什么**。
:::

## 九十分钟工序 {#def-gongxu}

::: definition 八十二三五五 {#def-yunzhuan}
**审题 8 分钟**（**四步走完＋谈判词光谱图：这 8 分钟买断全文的方向险——“考场最大的浪费，是用 70 分钟写一篇审错题：快就是慢，慢就是快在此处的字面义**））；**造桩与提纲 12 分钟**（**最小可运行包：一句话桩＋一限定＋一反方＋一行死法（60 字，第 2 课规格）＋六行句子图纸（第 5 课规格）——“提纲的 12 分钟是唯一稳赚的投资：它花掉的是你最不缺的（时间），保住的是你最缺的（逻辑**））；**骨架写作 55 分钟**（**按段落功能计时：桩段 8、机制段 15、让步驳段 12、处方段 12、收口 8——写崩一段的处置预案：跳过补路标，绝不回头大改（“考场的完美主义是廉价的奢侈：初稿的诚实比段落的华丽值钱：你要交付的是一座能住人的房子，不是装修广告**））；**检查 15 分钟**（**三查：桩还在吗（结尾段与首段是否同一论点——写着写着换夫是高频事故）；连接词兑现吗（抽读全篇“因此／可见”，过连词海关）；字数与硬伤（错字、引文、人名：扣的是明码标价的分——“检查不是礼貌，是二次审计：审计自己比被审计体面**）。
:::

::: definition 段首句面试与宿构应变 {#def-mianshi}
**段首句替你面试**（**阅卷动线两分钟一道题：六个段首句连起来读，应该就是一篇能独立存活的摘要（写完后做这个“摘要抽读”：断一处，补一处——这是考场性价比最高的单项训练**））；**宿构的边界**（**背范文＝预装假家具（题面来敲门，家具全对不上：只能现编——现编的破洞就是套作的罪证）；合法装备是“工序与句型”——让步句型、限定词库、反例三问、图纸法：可迁移的是脚手架，不可迁移的是楼（“把‘苏轼被贬’预制成万能论据的人，会在‘科技伦理’题里被迫把苏轼送上火箭：素材按机制归档（激励类、监督类、认知类），考场上领的不是故事，是功能件**））；**临场造桩三步**（**从题面的谈判词找一个“人人默认的解释”，问它一句“总是吗？对谁？代价呢？”——绝大多数真题的桩，就埋在这三连问里（“本手”题：人人默认“练好本手才有妙手”——追问“有没有把本手练成肌肉记忆反而不敢变通的人”，一个限定段就活了：考场创新不需要新事典，只需要对旧共识多问半句**。
:::

::: example 三题的 60 字交付包 {#ex-jiaofubao}
用“桩＋限定＋反方＋死法”给三题各出一个最小可运行包，并各写一行“我会被误判成跑题的风险点”：①“老舍《想北平》：‘我的雨是跟着风走的’——城市与人”（改编）；②“有人称我们是‘强国一代’”（2023 北京卷大意）；③“好的故事可以引发我们联想和思考，给我们以启迪和感动”（2023 上海卷大意）。
::: solution
①**包**（**“城市塑造人，但以‘可退出’为前提：对能离开的北平，老舍的眷恋才是选择而非囚笼”；限定：仅论“有退出权者”的眷恋；反方：乡土文学会反驳——离开恰恰更难；死法：举不出“退出权与眷恋强度”的两难样本**”）；**风险点**（**被读成“写故乡”＝价值散文违约：本文的桩在“退出权”，不在“乡愁”——全文第一段就得把这个词钉上**）；②**包**（**“‘强国一代’是被授予的称号，值得核对账单：一代人的功劳簿里要留出个人的负债栏”；限定：讨论命名行为本身，不否认成就；反方：宏观叙事会给个体尊严；死法：举不出一个‘称号掩盖个体账单’的具体案例**”）；**风险点**（**极易滑成表态文或愤青文两头翻车：让步段（成就真实）必须出现在拆之前（第 6 章让步前置的考场用法**）；③**包**（**“好故事的启迪来自它敢于不代替你下结论：留白处读者自己完成道德判断——被讲透的故事只训练顺从”；限定：论“引发思考型”故事，抒情故事除外；反方：民间故事正是靠讲透才代代相传；死法：对照实验（留白版与讲透版的接受差异）在想象与文献里都无支撑**”）；**风险点**（**“故事”一词若不先收窄（第 5 课“一词一义”），全文会被三个含义拉扯：桩段第一句先声明取“叙事作品”义**。
:::
:::

::: intuition 考场是一种文类 {#int-wenlei}
**把考场当作一个真实的文类来研究，而不是当作学术的牢房来抱怨**（**它有公开的合同（考试说明）、稳定的评分共同体（阅卷组）、两分钟的注意力经济（段首句工程）——第 8 章的全部方法论在这里同样适用：读合同、配声部、控预算（“抱怨‘考场不容思辨’的世代与靠考场写出思辨的世代，用的是同一张题面：差别在把题面当判决书，还是当谈判桌**）。**它的诚实**（**标准化评分确实迟钝于异类、灵敏于清晰——那就先交付清晰，再在清晰的内部藏一点真的东西（“限额不是羞辱：十四万个阅卷小时里，清晰是对陌生人最大的礼貌：而真正的思辨从不惧格式，它只是在格式里学会了更小声道地说话——这也是文章千古一切高压文体的共同经历（第 16 课的曲笔谱系在此领一份考场分红**。
:::

::: history 考场文体的换代 {#sec-huandai2}
**1977—80 年代** 命题作文时代（**恢复高考（**通说：早年大作文多为统一命题，写人记事与读后感并存；1980 年代“一事一议”“短论”成为训练主流——议论文凭借考场与时评教学法（第 8 课）的双向供血重新登基，时评与考场自此互喂**））；**1999 话题作文（“答案是丰富多彩的”——自拟题、自选体的放权实验：代价是宿构与套话的黄金时代（放权没有配给验收标准，考场就自己发明了“文体不限”=“文体不必”的读法））；2000s 材料作文时代（收权：给材料、限定范围——审题训练从此成为一门显学（四步法是被逼出来的合同读法））；2014 后 任务驱动型（“与年轻人交流”“给××的一封信”：任务条款入场（第 8 课“声部义务”的国家版本：考场的文体学复兴——形式又重要起来了，因为它成了可验收的动作））；2020s（“本手、妙手、俗手”（2022）与“好的故事”（2023 等：关键词谈判＋思辨规格双升级——评分细则里“辩证”“多层”字样增密：这是“可辩之点年度招标”（第 1 课）的最新一标：命题组显然修过本课第 2 课）。
:::

::: warning 考场四坑
**抄材料起步，喊口号收尾**（**中间再摆三个例子：一份合同也没履行的“伪交付”（第 1 课“列举不是论证”的官方卷面版——判分表对它有专门称呼：基础分**））；**文体漂移**（**开头演讲稿、中间议论文、结尾抒情散文：三个声部互相拆台——定体后在每张段首卡上默写一句“我现在对谁说什么”（第 8 课声部意识的考场开关**）；**假深刻**（**“既要……又要……还要……”的全面，实为不敢主张：辩证不是各打五十大板的平均主义（第 6 课：让步要能收回，骑墙只是怕摔——“权衡”必须给出权重与理由，否则“全面”=弃权**）；**字迹与字数的明码损失**（**把最贵的思辨押在最便宜的扣分项上：卷面与字数是“论证之外唯一 100% 可控的分”——工程问题工程解决（平时按 820 字练收口，考场自然不断水**。
:::

::: exercise 摘要抽读 {level=1}
写一遍 800 字限时文（任一真题），完成后只交出六个段首句；自评：**抽读断点在哪？段首句连读是否已构成一篇合格摘要？**（其余段落当场作废不计）
::: solution
判分：**六句须含：桩、限定、反方处理、机制、处方、收口各一**（**缺件＝图纸缺陷，与文采无关**）；**断点定位**（**两句间需要“因此／然而”而你没写出＝两段互不相识（第 5 课衔接词测谎的考场复检**。
:::
:::

::: exercise 套作改造 {level=2}
取一段典型宿构文（“当苏轼被贬……当司马迁受刑……当海伦·凯勒……”排比开头），做两项手术：①按机制重新归档素材（激励／监督／认知三类）；②用本题谈判词把归档件接上桩——写出术后 150 字，并标出“删掉了什么”。
::: solution
判分：**删掉的必须多于新增的**（**宿构病在超载：三个名字挤掉的是你的主张——“删名字、加机制”是本课外科主刀**）；**归档标签准确**（**苏轼若被用于“心理调适”，属认知类；硬接“制度监督”＝零件错装：**把苏轼送上火箭现场版）。
:::
:::

::: exercise 小论文：交卷之后 {level=3}
写六百至一千字，评“**考场作文教给一个人的，与其说是写作，不如说是一种公民写作的最小规格：在限时的公共合同中，向不完全同意你的人，用可核查的方式，把一句你敢负责的话说清楚——铃响交卷之后，人生只是换了一张更大的答题卡**”。须调用：**三条约款**、**审题四步**、**八二三五五**、**段首句工程**、**假深刻条款**、**“考场是文类不是牢房”**至少六项；并裁决：**标准化考试与思辨写作到底互为解药还是互为枷锁——用一个“如果我是命题人”的具体方案回答（含一条你会故意设置的“反套作条款”**）。
::: solution
判分点：六项机制（**合同、谈判、预算、面试、弃权识别、文类意识**）；裁决（**参考：解药论——标准化把思辨变成可验收动作，逼它离开沙龙；枷锁论——两分钟注意力奖励清晰、惩罚幽微，长期塑造“清楚即深刻”的口味；方案判分在细节（合格示例：给出可反驳的立场＋要求考生在文中引用并回应一个指定反方文本＋按‘让步质量’单独给分——反套作条款示例：“凡文中出现未被本题关键词激活的名人，该例作废”：把宿构从风险变成明亏——判卷看方案是否也遵守本课合同（你的方案本身可辩、有反方、有死法：这是全课的期末元考试**）；结论若能写“**交卷之后才明白：这门课教过的从来不是作文，是一种愿意被复查的人格——题面会过期，分数会贬值，只有‘我说的每句话都留着撤回按钮’这件事，终身有效**”，即 A。
:::
:::

::: summary
交付归档：合同（**任务、材料、评分三条款：判分看你交了什么**）、审题（**圈动词、辨四型、找谈判词、列让步位**）、工序（**八二三五五：检查是二次审计**）、装备（**脚手架可带，楼得现造：素材按机制归档**）、人格（**清晰是对陌生人的礼貌；思辨在格式里学会小声道**）。十课十讲一句收束：**把话说清楚，把账记分明，为对手留座，给自己留撤回按钮——交卷铃响，公民的答卷才开始。**
:::
