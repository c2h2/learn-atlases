前五章管对不对，本章管好不好读——但先立一条宪法：**语言不是论证的衣服，是它的皮肤：换皮肤会改变体温（第 15 课合金论的写作版：锯开断面，内容和形式各自都不是原作品**。

## 定义：准确层 {#def-zhunque}

::: definition 连接词的公开账目 {#def-lianjie}
**“因此／然而／况且／换言之／也就是说”＝逻辑连接词的海关申报单**（**误用审计三案**：①“**他每天打卡，可见他敬业**”——“可见”为归纳背书，但打卡与敬业是相关不是定义（连接词比结论更常撒谎：审文章先审连词——“全文‘因此’共八处、其中五处前件推不出后件：这份审计报告比读后感值钱**）；②“**成绩下降，由此可见管理松弛；管理没有松弛，可见成绩不会下降**”——假二难借“可见”连发两枪（第 4 章否定前件借道还魂：连接词给无效式发通行证**）；③“**换言之**”后面换了论题（**换言与换题只差一字：检查法——去掉“换言之”，前后两句还能互相还原吗（还原失败＝作者在悄悄改合同**）。**“之所以……是因为……”回访**（**第 1 课“的原因与因为重复开票”的升级版：这个句型本身合法，滥用在于把因果倒装当深刻：“他成功，是因为他坚持”——倒装不增加信息，只增加停顿（伪因果的常见化妆：把时间顺序用倒装句伪装成机制**）。
:::

::: definition 限定词的焦距与强调位 {#def-jiangjiao}
**同一命题，限定词住哪间房，焦点就照哪张床**（**“在双职工家庭中，多数家长支持延时托管”（限定在主句＝全文范围）vs“多数家长在双职工家庭中支持延时托管”（歧义：支持发生在家庭里？）vs“家长总体上支持延时托管，尤其在双职工家庭”（让步式补充＝把限定当保险而非合同）——写完读一遍：我的限定是范围还是补丁？**）；**强调位法则**（**汉语句首与句末是全文仅有的两次敲槌：“然而”挪到句首，反驳的力度升半级；“并不必然”挪到句末，给读者留出了回旋的后廊——但敲槌滥用即哑：一段两个“正是”、三段四个“恰恰”，读如有人在你耳边一直跺脚**）；**“是”字与倒装的配额**（**“真正的问题是”“值得注意的是”——这两个短语每占用一次，就透支一次读者的信任：千字文里各以两次为顶（到第三次，它自己就成了被注意到的问题**）。
:::

## 得体层：人称与数字 {#def-deti}

::: definition “我们”的四种所有制 {#def-women}
**全民式**（“**我们都爱孩子**”——查汇率：换成“部分人”，句子塌吗？不塌即假存款（往读者账户里存钱，存折却不是他的：被代付的读者会用退出来提现**）；**同行式**（“**我们知道**”——学术写作里的老毛病：把“本领域共识”塞进两个人的论文（第 8 章证据分级：共识要能出示文件**））；**圈子式**（“**咱们打工人的苦**”——修辞的拥抱，合法的拉拢：识别它不犯罪，被它绕过论证才犯罪（“说‘咱们’的时候，他递来的不是证据，是工牌：先问工牌能不能刷开数据室的门**））；**绑架式**（“**任何一个有良知的人都会同意**”——道德人质（第 9 章诉诸群众与恐惧的联名保单：不同意＝自认无良知：解绑句式唯一且好用——“良知与本题结论没有推导关系，请出示论证”**）。**数字与模糊语的双账本**（**精确的地方别修辞（“超标 3.2 倍”就写 3.2 倍，别写“触目惊心”）**；修辞的地方别精确（“这种做法令人疲惫”后面接“据统计 76% 的同事皱眉”——用数据给感受化妆，两头不兑现（第 3 课用途错位的语言版：数字管事实，形容词管态度，各记各的账；混账一次，审计降级全文）。
:::

## 节奏层 {#def-jizou}

::: definition 整散、四字格与三红线 {#def-jouzou}
**整散句＝呼吸设计**（**整句（排比、对偶）提速加压，散句减速留白：论证的紧张段用散句（因果链需要每一环看清楚），动员段与收口段可整（情绪结清）**）；**排比三合法一滥用**（**列举、蓄势、对仗皆合法；滥用＝代替论证——“它节约时间，它提高效率，它改变命运”三行整句之后，读者记得的只有节奏：排比每多一行，怀疑自动少一分：节奏在替逻辑收税（识别口诀：排比的各项若可以互换位置且不损失信息，它们就没有信息，只有音量**））；**四字格的引力**（**成语是三秒钟的引经据典：“众所周知、不言而喻、毋庸置疑”——三个四字格能盖住三个缺失的论证（还债规程：用了“毋庸讳言”，就要在下一句把“讳”的部分摊开：成语省下的引用，要记得还**））；**三条红线**（**①反讽在转述中流失（你的反讽会被截图成正面主张——网络时代的引号刺客：重要主张别穿反讽的隐身衣（第 16 课“曲笔”的代价在今天的版面重演**）；**②双关不可转述进结论**（**“棋如人生，落子无悔”——双关的两条轨道不能在判决日合并行驶（把修辞的巧合当论证的必然：第 6 章类比付息条款同样适用于成语**））；**③幽默不能替让步**（**笑倒的对手没有认错：段子赢了，问题还在原地——幽默是修辞的烈酒：可以敬读者，不能当主食**）。
:::

::: example 三档处理：同一段的三张面孔 {#ex-sandang}
内核段：“**学校统一收集手机，课间还是有人玩，说明这办法效果有限。**”分别改写为①学术档（供课题报告）、②报刊评论档（供晚报版）、③考场档（供 60 分起步的高考卷），各 70—110 字；然后互评：**每档为了自己的读者，牺牲了什么**。
::: solution
①**学术档**（“**某校实施手机统一保管制度后，课间时段学生自报使用时长仅下降 18%（n=312，两学期），提示以物理隔离为主的干预对同伴在场情境下的使用行为效力有限**”——牺牲：可读性与现场感（术语把“玩”拆成“同伴在场情境下的使用行为”：精确的代价是体温**）；②**报刊档**（“**铁盒锁得住手机，锁不住走神：课间十分钟被交出来的不只是屏幕，还有本该用来吵架、望天、发呆的时间——制度管物，教育管心，这笔账不能只让校长一个人算**”——牺牲：可证伪性（“锁不住走神”多好听，也多不可查：金句的赔付率极高（第 3 课装裱条款换到语言层**））；③**考场档**（“**统一收纳手机，收的是道具，收不走动机。若课堂本身缺少让人抬头的理由，任何保管制度都只是把问题寄存（亮桩式判断句＋一个比喻封顶＋限度：本文不反对收纳，反对把收纳当作教育）**”——牺牲：证据（考场档默认“后文会补”，若忘补则与报刊档同罪；但它保住了两样：可辩的桩与限定的保险杠**）；**互评要点**（**三档不是三副良心，是三份不同的合同：学术卖可复核，报刊卖共鸣里的方向感，考场卖两分钟内的清楚——换档不换诚实：哪一档都不许把“有限”写成“无效”、把“动机”写成“品行”）。
:::
:::

::: intuition “我说不清”是情报不是道歉 {#int-shuo}
“**我说不清，但我感觉是这样**!”——**这句话常被当谦虚，其实是情报：它宣布论点尚未成形（第 1 课“写不出 ABC 的只是情绪”的语言版**）；**说不清的三种病情**（**①概念未定义（你心里“好学校”有三张面孔）；②机制未打通（知道两端，中间是隧道）；③反例未处理（有一条你在躲）——开药顺序即课程顺序：第 2 课造桩、第 4 课电路、第 6 课清场：写作课的全部语法，最后都回到逻辑课的字母表**）。**相反方向的病：说得太清**（**“过度确定”文风（每个句子都斩钉截铁、每个判断都没有误差线）在第 3 课查账里活不过十分钟：成熟的文风是“强度与证据同轨”——证据走到哪儿，语气跟到哪儿：语言的诚实，最终是一种跟随的艺术**）。
:::

::: history 辞达观的四次立法 {#sec-cida}
**春秋** 孔子“**辞达而已矣**”（《论语》——达意为上限：反对超过达意的装饰；又“**言之不文，行而不远**”（《左传》——没有文采传不远：**两句话合起来是中国文章学的第一对张力：省税派与远行派，从此共写一本账**）；**南朝** 《文心雕龙·情采》“**文附质也”“质待文也**”（采与质的互相等待：**合金论的骈文版：不是先有裸思想再穿衣，是衣成才有形**）；**唐** 古文家“惟陈言之务去”（韩愈《答李翊书》——**去陈言＝语言层的反例攻防：成语与套话是思想的默认选项，去掉它们，被迫开始真正思考（第 9 章“清单不生产作品”的正面配方：清除模板句是论证的开机自检**”）；**清** 顾炎武《日知录》“**辞有滥而意不违，则宁写而不删；不若辞足以达意，而无乎冗字也**”（通说化用——**删字先删虚夸：考据学的语言纪律：每个形容词都要能出示证据（这是中文世界里最早的“形容词的海关”**）；**现代**（**现代白话纲领（**通说：“话怎么说，文章就怎么写”（胡适）——**口语的幻觉：以为去掉骈偶就去了陈言，其实只是换了一批陈言（“随着社会的不断发展”：新八股的出生证明；批评语学的兴起（第 16 课“名目”的语义学分店：对公文套话的系统审计**）；**当代**（**视觉排版的介入：加粗、小标题、要点符号改变了汉语论证的节奏单元（第 8 章“信息呈现即论证环境”：语言课的下半场在版面与屏幕上**）。
:::

::: warning 语言四坑
**连接词通胀**（**“综上所述”前面只有一句话、“由此可见”前面只有心情：连接词的信用与它的库存成反比（每用一次“显然”，请自查是否刚刚证明过**）；**伪复数**（**全文的“我们”没有一处能替换成具体人群（“本校高二年级 412 名学生”）＝空头联名（第 3 章选择偏见申报的语言版：你代表谁，先点名谁**）；**金句依赖**（**每段结尾都想要一句能被摘抄的话：摘抄率与论证率成反比（第 1 课口号条款的段落版：金句是浓缩饼干，全文不能只有饼干**）；**修辞的免责声明**（**“我开玩笑的”“开个玩笑别当真”贴在冒犯之后——语言的后悔药不存在：反讽与双关的代价在发出时就已支付（第 6 章：对读者负责＝在第一句话就负责**）。

::: exercise 连词审计 {level=1}
取自己旧作一段（或仿写），圈出全部连接词，列表：连接词／前后件／是否兑现（兑现／夸大／错位）——并写出**替换或删改方案**（至少三处）。
::: solution
判分：**“因此”类逐项过堂**（**前件能否写出“若……则……”的合法式——写不出即夸大**）；**删改方案要给出替代连接词或删除后句意的变化**（**“可见”删掉，句子反而更诚实：连接词有时不是桥，是滑梯**）。
:::

::: exercise 人称体检 {level=2}
把一段社论里的“我们／大家／任何人”全部替换为**可点名的人群与规模**，逐处判断：替换后句子还成立吗？列出**替换后崩塌的原句清单**并诊断病灶。
::: solution
判分：**崩塌清单是本文真正的作业**（**崩塌＝原文靠假存款支撑（第 2 课“真正的 X”的同款审计**）；若全篇无一崩塌，需解释（**作者是真的逐处界定过，还是你的替换不够狠——诚实的两种可能都要写**）。
:::

::: exercise 小论文：皮肤的伦理 {level=3}
写六百至一千字，评“**‘语言是透明的工具’是天真的：它更像是皮肤——你透过它看世界，世界也透过它摸你：所以修辞的伦理不是‘少用’，是‘别用它借刀’——借读者的手，砍自己没查证的结论**”。须调用：**连词海关**、**我们四制**、**双账本**、**排比税率**、**三红线**、**三档合同**至少六项；并裁决：**为说服而优化表达，与为操纵而优化表达，界线在何处——写出三条可交给编辑部执行的判据**。
::: solution
判分点：六项机制（**海关、所有制、双账本、税率、红线、合同**）；界线裁决（**参考：操纵＝把可错的写成必然的、把代付的写成共识的、把未证的写成显然的——三条判据示例：①强度对齐检测（随机抽五个判断句，比较其限定词与证据表：错配率>20% 退改）；②人质清零（所有“任何……的人”句式必须改写为可点名的群体）；③金句可还原（每个金句须能改写成不带修辞的同义判断，否则降级为标题——判卷看：判据是否也可被作者自己执行（对称怀疑主义：第 8 章球迷条款的语言版**）；结论若能写“**修辞的荣誉在于它愿意被还原：好比喻经得起‘换句话说’，好排比经得起删，好‘我们’经得起点名——皮肤之下，你仍是那个要交税的人**”，即 A。
:::

::: summary
皮肤学归档：准确（**连词海关、限定焦距、强调配额**）、得体（**我们的四种所有制、数字与形容词分账**）、节奏（**整散呼吸、排比税率、成语借债要还**）、三红线（**反讽流失、双关不进判决、幽默不作让步**）、三档（**换档不换诚实**）。方法一句话：**每个修辞都问一句：你替谁干了活，替逻辑还是替逃避**。下一章进城：时评与评论写作。
:::
