title: "评论与推荐语"
---

上一章说文艺评论要过论证的海关；本章把整座市场摊开——**从学术书评到八个字的带货文案，是同一条句子的五种汇率：“值得一读”在最高档需要三页论证，在最低档只需要一句顺口溜：跨界写作的第一步，是换汇**。

## 定义：一条光谱 {#def-guangpu}

::: definition 五档文类与举证汇率 {#def-wudang}
**学术书评**（**同行合同：篇幅以千字计、对照以同领域三五种著作计、判断以贡献与缺憾计——它的“好”必须可复议**）；**报刊书介**（**公众导读合同：翻译行话、给出入口章、回答“我为什么要在这本书上花两小时”——举证减半，但诚实不减**）；**平台短评**（**口碑市场：三十字内交付一个可转述的判断——“它考验的是压缩，不是省略：压缩保留论证的骨架，省略砍掉它**））；**带货推荐语**（**商业合同：受众是买家不是读者，卖的是“你会获得什么体验”——允许热情，不许虚构（“‘三天读完’是承诺，‘一生受用’是欺诈：体验类主张要按广告法与良心双规审计**））；**腰封与名人语**（**广告的广告：当所有书都是“年度最震撼”，震撼的购买力归零——推荐语的通胀与本币改革（第 3 章引证通胀的营销分号：货币史在这里重演，币名从“经典”换成“封神”**）。**共同底盘**（**五档共用法庭：你读过吗（证据来自文本内部）、你拿什么比（对照系）、你敢说对谁不值吗（限定）——档位在变，三问不变（“光谱不是滑坡：滑下去的不是文类，是诚实**）。
:::

## 书评的三副眼镜 {#def-sange}

::: definition 描述、评估、推荐 {#def-mulu}
**①描述**（**“它讲什么”——作者封底的话不算数：先用 80 字证明你真读过（描述是对作者的轻度不敬的正当形式：转述即质检；技术：用“本书主张……为此它提出……但它在＿＿处让步”的句式，一句话含三件：论点、方法、软肋**））；**②评估**（**“它想做的事做成了几成”——对照作者意图与成就（第 15 课三张报表“意图≠成就≠后果”的读书版：评估不是问“你喜欢吗”，是问“它的目标读者会得到什么、失去什么”；对照系三选：同类书、作者的旧书、书内的野心（“用托尔斯泰的标准评一本入门读物是偷懒，用爽文的标准评《万历》也是——选错对照系，整篇评论自动作废**））；**③推荐**（**“对谁”——推荐的伦理：“人人适合”＝没人适合；把书卖给对的人，不是卖给所有人（“把一本经济学科普推给‘所有想改变命运的人’，是把手术刀卖成护身符**）。**三序不可乱**（**先推荐后描述＝带货；只描述不评估＝目录搬运工；评估了不敢推荐＝学术滑头（书评的职业荣誉在第三步：你的判断要让读者敢把两小时押上去**。
:::

::: definition 推荐语的诚实工程 {#def-gongcheng}
**三件套**（**适合谁（具体到处境：“给正在犹豫要不要转行的三十岁读者”，不是“给所有人”）；不适合谁（“不适合：想要成功学配方的人，本书第 2 章会让你失望”——**“不适合我”是推荐语里最贵也最少见的五个字：它同时完成限定、人设与反向筛选：写它的人按读者退款率领工资**）；一句证据定位（**页码或场景：“第 47 页那张对照表，值回书价”——可回查的推荐是样本装，不可回查的是气氛组**））。**腰封病志**（**名人语批发（“读到流泪”的人如果每位读者都是，眼泪就按斤计价）、数字夸大（“畅销 1000 万册”的口径：套装算几册）、权威拼车（“获某奖入围”写成“获某奖”——第 3 章口径三查在出版业的分支营业。
:::

::: definition 现场性：影剧评的地租 {#def-changjing}
**演没了，证据只剩你的记忆**（**第 15 剧“在场税”的评论版：剧评的证据纪律更严——版本、场次、卡司、剧场必须标注（同一剧目两班卡司可以是两部作品：不给卡司的剧评是在评论剧本，那叫读后感**））；**剧透分级**（**本章把上章合同细化：结构类评论须透到命门才成立（“评《东方快车谋杀案》不谈结局，等于评理发不谈头发”——此时剧透是职责）；而透错层级是违约（“一句‘凶手是他’对没看过的人是谋杀，对论证却是必需：分级标注（核心诡计／关键转折／细节）是评论者的安全带**））；**“无剧透评论”的悖论**（**它的可行解：把论点上移到不必剧透也成立的高度（“这部片子的道德重心在共谋，不在悬念”——论点的抽象层级越高，剧透依赖越低：剧透考验的不是胆量，是论点的海拔**。
:::

::: example 同一本书的三档文本 {#ex-sandang}
为一本讲明清漕运的经济史著作，写三档文本并自评：**①学术书评摘要**（150 字，须含对照系与一条缺憾）；**②报刊书介**（200 字，含入口章与“对谁”）；**③带货推荐语**（80 字，含“不适合谁”）。
::: solution
①**学术档**（“**本书以漕运重构明代财政的实物—货币双轨，较之此前制度史处理，优势在把运输损耗与浮勒摊回中央—州县两级账本；其‘行政性亏空内生’论可与清代陋规研究对读。缺憾在南方民漕一节样本偏倚官书，船户视角仅凭三件碑刻支撑。第 4 章费率测算可复核，附录数据最宜引用。**”——自评：对照系（制度史旧著、清代陋规研究）、缺憾（样本偏倚）、可回查（第 4 章与附录）三件齐；风险：同行会去查那三件碑**）；②**报刊档**（“**如果你以为漕运只是‘把粮食运到北京’，第 2 章会改掉你这个句子：一条河如何喂养十万人的职业、催生一种介于报销与分赃之间的官僚语言——本书最好的入门是第 2 章与结语，前者给场景，后者给问题。适合：读历史想顺带懂点财政经济的读者；不适合：要爽、要名人宫闱的睡前两小时。**”——自评：入口章＋两句式“对谁”，把导读合同签满；“官僚语言”一处是修辞，但可回查，勉强过关**）；③**带货档**（“**给做供应链、做财务、或正怀疑‘体制内语言’的人：第 4 页那张费率表，你会想起自己的报销单。不适合要鸡汤和要爽文的——本书只保证让你更会算账。**”——自评：适合谁具体到处境、不适合谁点名、证据定位到页；未犯腰封病（不称“必看”“封神”：一旦使用，本币再次通胀）。
:::
:::

::: intuition 推荐是预言，差评是手术 {#int-yanyu}
**推荐语受一条检验：兑现率**（**“你会喜欢”是关于读者未来的陈述，写它在为明天的自己开仓：一个长期写推荐的人，其信誉＝历史句子的兑付曲线——这就是为什么“年度最佳”滥发是行业自残：它透支的是所有诚实推荐者的共同准备金（公地悲剧的文类版**）。**差评三重义务**（**对事（“它把人物当议程的容器”而不是“它烂”——形容词是判决书的占位符，机制才是判决本身）；给对照（“同题的 XX 用三页做到的事，它用三百页错过”——差评没有对照系，只是脾气**）；**留公道（区分作品与其事故（“第一部的导演缺席不等于主创无能——把工业问题骂成道德问题，差评也会通胀**”）。**《知言》的旧账**（**孟子“知人论世”——以意逆志，是“得之”；不知其人而论其世，是多数差评的病灶（第 15 课意图谬误的民间版：注意分寸——以意逆志不是请作者出庭（意图是极好的脚手架、极差的终审（第 15 课条款照贴）：剧透之外，评论的第二重禁忌是“作者已死”被误读成“研究作者的人有罪”**）。
:::

::: history 好评的账本 {#sec-haoping}
**战国** 孟子“**颂其诗，读其书，不知其人，可乎？是以论其世也**”（《万章下》——**评论的第一份方法条款：知人论世**）；**南朝** 《文心雕龙·知音》（**通说要旨：篇中历数贵古贱今、崇己抑人之蔽，给出程序“缀文者情动而辞发，观文者披文以入情”——**中国批评学的元问题：我们凭什么判断一部我们并不完全理解的作品；“无私于轻重，不偏于憎爱”（该篇成语）给评论的诚实提前立了法（第 1 课钢铁人的南朝版本**））；**宋—清 诗话、文论与评点（**金圣叹式夹批：推荐语的现场化巅峰——眉批一句“妙”，举证三行（传统评点其实比今天的大多数“绝了”更守举证纪律**））；**1920s—30s** 现代书评栏诞生（**报纸副刊设书评、出版与批评互喂——“新书需要名声，批评需要阵地：这场交换产生了中国最早的一批职业评论人，也产生了最早的软文纠纷（人性不需要等到算法**））；**1980s—90s** 读书热与“书话”（**唐弢、黄裳一路书话文体：推荐语的文学化封顶——随笔的私人声部为公共判断作保（“我替你读”的古典契约**））；**2000s—今** 平台评分（**豆瓣式星级成为事实上的国民口碑基础设施——随之而来的军备赛：粉丝打榜、水军五星、对家一星（“评分系统的地震学：中位数比均值诚实，评论区比分数诚实——今天的推荐语写作，是在噪声里做信号：这本身就是论证方法问题（第 8 章基础率与样本框的娱乐业分店**）。
:::

::: warning 推荐四坑
**气氛组**（**通篇“震撼、封神、必看”，没有一个可回查的定位：推荐语的第一审计是“删去所有形容词后还剩什么”（剩页码与场景的合格，剩叹号的归零**）；**错对照**（**用诺奖标准评入门读物、用票房标准评实验剧——对照系错位＝整篇作废（选对照系是评论者的宪法法院，比判决更权力大**）；**剧透越权**（**把“我不喜欢”写成“它结局是坏的”：剧透只能服务论证，不能服务泄愤（核心诡计类作品的剧透，等同对读者的财产伤害**）；**人书合一**（**作者塌房，书就被烧；作品伟大，人品就被赦——两头都是取消制的懒政：“知人论世”是方法，不是连坐法（第 15 课意图条款：作品与作者的账要分两本记，两本都要记**）。
:::

::: exercise 压缩测试 {level=1}
把你写过或见过的一段 300 字长评，压成 30 字短评，要求**保留论证骨架**（对象＋判断＋一条证据线索）；再反向：把一句“绝了”扩成 80 字合格短评。
::: solution
判分：**压缩不得只留情绪**（**骨架三件缺一即“省略而非压缩”**）；**扩写必须引入可回查证据**（**场景、页码、场次、卡司任选一——“绝了”的病灶是零指涉：扩写手术就是把感叹号改写成句号加证据**）。
:::
:::

::: exercise 三件套写作 {level=2}
为你最近读完的作品（书、剧、展览任一）写一条“诚实推荐”：适合谁（到处境）、不适合谁（点名一种读者）、一句可回查证据；并为它拟**一句不会通胀的夸法**（禁用：震撼、封神、必看、天花板）。
::: solution
判分：**禁词表是硬杠**（**通胀词出现即重写——练习的目标是恢复币值，不是练习谦虚**）；**“不适合谁”必须是真实人群而非假想敌**（“不适合没耐心的人”是侮辱，“不适合想要操作手册的读者”是服务**）；“不通胀的夸法”考点（**具体到可复查：‘它敢在第 3 集把主角消失 40 分钟’胜过十次‘炸裂’）。
:::
:::

::: exercise 小论文：评论家的清贫 {level=3}
写六百至一千字，评“**评论家是文化经济的清贫部门：他替读者省时间、替作者照盲点、替市场维持币值——三件事都不直接产生销售额，所以他的全部收入来自信誉的利息：这就是为什么好评可以廉价，差评必须贵，而推荐语的通货膨胀，最后由最诚实的作者付账**”。须调用：**五档汇率**、**三副眼镜**、**推荐三件套**、**兑现率与公地**、**差评三重义务**、**知人论世的分寸**至少六项；并裁决：**“坏作品是否值得存在”——从评论者职业伦理出发（不许引用“市场会决定”作为答案：市场的答案也是论证，把它拆开再答**）。
::: solution
判分点：六项机制（**汇率＝合同层级；三镜＝工序；三件套＝限定工程；兑付曲线＝信誉会计；三重义务＝手术规范；知人论世＝两本账**）；裁决（**参考：存在权与好评权分离——坏作品当然可以存在（检查不是评论家的职务，第 6 课追问权条款），但评论家没有义务替它维持币值：拒绝推荐与给出差评都是执业，“不评价”则是最被滥用的消极自由（真正该审的是“沉默的算法原因”——若沉默是策略，沉默就是虚假陈述的温柔版：把“市场会决定”拆成“谁在定义可见性”（第 8 章平台论回访）才算答到题眼**）；结论若能写“**清贫部门的资产负债表上，唯一不能折旧的是公信力：好评让你今天被喜欢，公信让你明天被引用——评论这行，做的是时间的期货**”，即 A。
:::
:::

::: summary
市场归档：光谱（**五档汇率，同一诚实底盘：读过、比过、敢说对谁不值**）、三镜（**描述、评估、推荐：序不可乱**）、三件套（**适合谁、不适合谁、可回查一句**）、现场（**卡司标注、剧透分级、论点海拔**）、账本（**兑现率、差评手术、知人论世两本账**）。方法一句话：**按读者退款率领工资的人，才配写推荐语**。最后一章：回到考场——把这门课在 90 分钟里交付。
:::
