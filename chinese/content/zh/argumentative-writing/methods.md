---
title: "论证方法"
---

上一章备了料，本章接通电路——**同样的证据，接不同的方法就是不同的灯：议论文的“论证方法”不是作文术语菜单，是五种风险分配方案**。

## 定义：五条电路 {#def-diaolu}

::: definition 每种方法是一种输法 {#def-fangfa}
**①演绎（含省略式）**（**安全，但结论不超过前提——写作的故障常不在小前提，在不敢见光的大前提（“‘他成绩好是因为补课’：大前提‘补课决定成绩’一见到光就死（逻辑课省略三段论的写作现场：把你的大前提默写出来读一遍，是论证方法的第一道工序**））；**②归纳（枚举）**（**从样本到规律：风险报价单制度（第 6 章）——写作要求：在文中就报出广场（“调查来自本校三个重点班”一行，买你全文的诚实险**））；**③例证**（**归纳的现场表演：选、摆、挖三字诀见下节**）；**④类比**（**相似性贷款：三件套（相关属性清单＋失效边界＋可检验推论）——本章补一条记账法：类比每一跳都要付息（相似≠同类，同类≠同理），长链类比（A 像 B，B 像 C）是复利债务，两段之内必违约**））；**⑤因果**（**最贵的保单：三张单缺一就在文中降级措辞（第 7 章的税率体现在修辞上：能写“相关”就别写“导致”，除非你交了税**））。**配型表**（**政策主张吃因果＋成本收益；定义主张吃归类后果与命名目的；价值主张吃标准、权衡与反例；事实主张吃数据链与口径——方法不是装饰，是配型：错配的文叫“论证方法齐全”**）。
:::

::: definition 例证三字诀：选、摆、挖 {#def-liuge}
**选典型**（**典型≠极端：极端案例抓眼球但反方一句“个例”就能退货——除非你的任务就是证伪全称（狙击枪岗位）；典型＝把机制演示得最干净的那个样本（“论证‘补贴改变行为’，选一个政策前后只动了补贴一项的县城，胜过三个热闹的一线城市**）；**摆一组不摆一族**（**同类三例胜过异类十例的错觉——数例子是小学数学：三例若各带一个不同机制，反而互相拆台（例证阵列的排列逻辑是机制分解，不是数量堆叠：A 例证激励、B 例证信息、C 例证默认选项——三例三齿轮**））；**挖到机制层**（**“例子是矿不是金饰”——挖法三问：这个例子里什么变量动了？换个场景还成立吗？它支持我的哪一层（事实／机制／价值）？挖到底的例子能长出一段分析，挖不动的例子只能配一句“可见……”（全文“可见”计数是例证质量的免费检测：“‘可见’出现四次，说明有四个例子在裸奔**）。
:::

::: definition 归谬与反例：两条防守反击线路 {#def-guimiu}
**归谬（以子之矛）**（**先替对方立场打工，再让它破产：“若按此逻辑，则……”——墨家“推”的写作版（以其所不取之同于其所取者予之）；孟子“守株”式夹具（《公孙丑上》“非徒无益，而又害之”:先顺着做，让荒谬自己长大）；韩非鬻矛陷盾的成对命题陈列——归谬的宪法条文：“**以子之矛，陷子之盾，何如？**”——**逻辑课第 1 章“援”与“推”在这个句子里合体营业**）；**技术要点**（**荒谬必须是立场的推论而不是修辞的漫画：推出的是“对方的必然”，不是“对方的画风”：漫画式归谬＝稻草人穿礼服**））；**反例攻防**（**自建反例＝提前打疫苗（在正文里替反对者发一枚炮弹并当场处理——处理不了就把它写进“限度”段并调整论点强度：反例是论点的健身教练，专练你没限定的那块肌肉**）。**两段式配方（让步—转折）**（“**诚然……但是……”是中文议论文性价比最高的句型——前提：诚然部分要真诚（第 6 章：让步是梁不是疤），但是部分要接住诚然抛回的球（让步过的强度，转折时不得偷偷收回：收回就是违约）。
:::

::: example 一论三法：并排比较 {#ex-sanfa}
论点：**“高中晚自习应增设自主时段。”**用三种方法各写一个 120 字的核心段，并互相指认对方的“电损”（该方法在此处必然损失什么）。
::: solution
**甲·演绎段**（**大前提“学习技能的形成需要自主分配练习时间（自我调节学习研究的共识域）”＋小前提“晚自习全由教师主导，无自主分配空间”∴应增设——**电损：小前提的“全无”是全称命题，被任何一个试行班击穿；且结论只到“应有”，走不到“应马上全面有”：强度卡在演绎的额度里，政策细节要另立段落付款**）；**乙·归纳段**（**三校试点数据并置：睡眠、作业完成率、成绩三指标同向改善——电损：三校皆自愿报名的试点校（自选择广场）；且“改善”窗口只有两学期（趋势不是一切）：归纳段必须自报广场，否则被反方一句“试点校都是好学校”清零**）；**丙·类比段**（**“教练不能替运动员举铁”：学习如训练，主导权错位即负荷错位——电损：类比只供“直觉的便利”，不提供“此场景相关属性成立”的证明——必须补一段“学校晚自习与训练的三项相关同类＋一项关键异类（学生无选择权）”——异类恰是反对者的主炮位：类比段不主动交代异类，等于把后门留给别人踹**）；**并排判词**（**三段各管一层：演绎管方向合法，归纳管事实有效，类比管读者可理解——好的政策文三段接力，且电损互补；单法到底的文章，输在把一种灯当整条电路）。
:::
:::

::: intuition 方法是风险分配方案 {#int-fenpei}
**五种电路的“安全—增值”排序**（**演绎最安最穷；归纳、类比渐富渐险；因果最富最贵；例证居中但极易滥——选方法＝选你愿意向读者承诺的检验强度（第 3 章死法条款的方法版：演绎段的死法藏在前提里，归纳段的死法在样本框里，类比段的死法在异类里：知道自己死在哪一段，才配写那一段**）。**方法混搭的次序**（**给陌生读者写信的顺序：类比开门（让外行懂）→归纳交货（让内行服）→演绎收口（把个案升为规则）→因果兜底（说明干预与边界）——这个次序也是“说服成本”的次序：先借熟悉感，再上证据，最后谈机制；反过来先上回归表的议论文，往往不是不行，是不想被读完**。
:::

::: history 方法观的中西双轨 {#sec-shuanggui}
**中国一路**（**《墨辩》辟侔援推——四种基本电路的战国命名（逻辑课第 10 章回访）；《韩非子·难》体“或曰”双层声部——史载其体：先列可被引用、再被驳倒的立场，是中国论证史上最早的“虚拟反方”装置（第 1 课“留座”的制度化：让对手以“或曰”的名义住在你的文章里**）；孟子善喻与善推（“以杀人喻为政”的类比军团与“是不为也，非不能也”的能／可区分——类比与演绎双修；清儒考据的归纳方法化——“孤证不立”的行规（证据数量与来源独立性的一票否决：中文世界自己的“多重比对”标准**））；**西方一路**（**亚里士多德《修辞学》例证与演绎二分；《前分析篇》演绎电路正式命名；培根新工具的归纳电路；密尔五法（电路的工程化）；图尔敏版式把“保证”从幕后提到台面——隐藏大前提的显性化运动（第 1 章战线在写作课的驻军**）；**交汇**（**1905 年《穆勒名学》译出，归纳法进入中文写作的术语工具箱；20 世纪初“论据—论证—论点”三要素定型为国文教学语法（把方法论压缩成背诵条目是制度化的代价：一代人背熟了“例证法、引用法、比喻法、对比法”四个名词，然后把它们用成了四种文体模板**）；**当代**（**议论文“结构模式化”批评与“思辨写作”改革（任务驱动型作文：把方法重新捆回问题——2014 后“争议情境＋多任务”题面流行：方法考试回归论证考试的官方信号）。
:::

::: warning 方法四坑
**文体模板化**（**“总分总＋三例子＋一名言”是方法尸体标本：模板的正确用法是脚手架不是建筑（拆的时机与顺序才是技术：第 4 课详讲**））；**类比当证明**（**类比能救人于不懂，不能救人于不信：写完类比段自问“我有没有为它的同类性付过钱”（本章甲乙丙的丙段教训：异类不申报，后门必被踹**））；**三段同法**（**全文只敢用归纳：读如材料汇总；或只用演绎：读如证明题且大前提越来越心虚——“方法的单调不是风格，是资产类别单一：一个反例击穿一个方法，多样性能让反方多开三条战线**）；**“引用论证”当独立方法**（**引用是证据的搬运工序，不是推理类型：权威言论最终仍通过演绎（若权威在域内则可信）或归纳（多数共识）上班（把搬运写成立项，是“方法齐全”症的病根**）。
:::

::: exercise 五法轮训 {level=1}
用“校服应不应统一”同一论题，各写 80 字段：演绎、归纳、类比、因果、归谬——并各配一行“本段的死法”。
::: solution
判分：**五段五死法各不相同**（**演绎死前提、归纳死样本、类比死异类、因果死混杂、归谬死“对方不是这个意思”——写不出本段死法的，说明没吃透该法**）；归谬段判词：**推出的荒谬必须是立场的必然，不是它的画风**。
:::
:::

::: exercise 给文章换电路 {level=2}
取自己一篇旧作的核心段（原本多半是例证堆），改写为归纳段与因果段各一版，各 150 字；说明两版各自的证据新增成本。
::: solution
判分：**改归纳必须真的补样本框**（**不补就只是把三个例子改称“多数”：换汤不换药**）；**改因果必须真的列混杂**（**没有混杂清单的因果段＝把相关写成命令**）；成本意识（**能写出“此版需要两张表、一次访谈，我不付——故保留原版并降级措辞”的回答是满分：方法的诚实首先是预算的诚实**）。
:::
:::

::: exercise 小论文：方法即道德 {level=3}
写六百至一千字，评“**选论证方法就是选你愿意被如何反驳：用演绎的人接受查前提，用归纳的人接受查样本，用类比的人接受查异类——拒绝这一切检验而自称‘你不懂我’的，不是方法问题，是不想付论证的税**”。须调用：**五种输法**、**例证三字诀**、**类比三件套**、**归谬的反漫画条款**、**“或曰”装置**、**次序（类比开门—归纳交货—演绎收口—因果兜底）**至少六项；并裁决：**“把文章写给愿意被说服的人”还是“写给掌握资源的人”——受众决定方法还是方法决定受众**。
::: solution
判分点：六项机制（**输法＝税种；挖例＝质检；三件套＝贷款合同；反漫画＝对敌诚实；或曰＝制度性留座；次序＝说服成本学**）；裁决（**两条参考：受众决定论——决定资源归属的读者需要因果与成本段，公共说服需要类比与归纳：方法向受众交底；方法决定论——文体训练反过来塑造读者（长期只写模板文，读者失去对长论证的消化能力：受众不是自然物，是教育的产物——判卷看第三条：无论站哪边，须声明“本文（你这篇小论文）选择了哪种输法、准备死在哪一段”——元层当场兑现（自报死法，全文最高荣誉条款**）；结论若能写“**方法即道德：你愿意接受哪种检查，就配拥有哪种读者；你逃避哪种反驳，就正在成为哪种人**”，即 A。
:::

::: summary
电路归档：五法（**各是一种输法，死法位置各不相同**）、例证（**选典型、摆一组、挖机制：“可见”计数免费检测**）、类比（**三件套＋长链违约定律**）、归谬（**立场的必然，不是画风**）、或曰（**让对手住在文章里**）、次序（**先懂后服再规则**）。方法一句话：**动笔前先选一种你输得起的输法**。下一章排线：结构。
:::
