---
title: "结构"
---

论点定了、证据备了、电路选了，本章排线——**结构不是把话说漂亮的位置学，是作者替读者铺的路：路平，人才肯走到你的结论门口**。

## 定义：四种版式 {#def-banshi}

::: definition 并列、层进、对照、驳论 {#def-sizhong}
**并列式**（**三个分论点同层同维站成一排——并列的纪律：分论点必须回答同一个问题（“‘个人、社会、国家’是万能抽屉，不是分析：任何题目都能塞，说明它什么也没说；再查‘互斥’与‘穷尽’：两个分论点互相渗透＝没切干净；三个说完还有第四层＝没切完整**））；**层进式**（**是什么—为什么—怎么办，或现象—机制—对策——递进的体检法：删掉第三段，第二段是否已经把话说完？说完即伪递进（真递进＝后段以前段为前提且不重复其账目：像楼梯，不像同一幅画的三个拷贝**））；**对照式**（**正反双城：同一坐标两张图（“‘勤则治，怠则废’——对照的暗坑：两城若不在同一维度取景（东城谈成绩、西城谈健康），读者发现不了对比，只发现了跑题**））；**驳论式**（**先破后立：树立靶—拆承重—清场—起新楼（第 6 课全套工序；本章先记一条：驳论式最大的风险是“只破不立”，拆完一栋危楼交付一片废墟**））。**版式选择法**（**看论点的形状：政策论点偏层进（现状—原因—方案—风险）；价值争论偏对照；对手强大的议题偏驳论；并列式最省力也最平庸——“用并列不是错，把并列写成三个同义改写才是错**）。
:::

::: definition 开头三件事与结尾三忌 {#def-touwei}
**开头三件事**（**①亮桩（第 1 课第四种开头）；②让座（反对者入席——“第一段没有反对者的文章，第二段就开始骗人”）；③报路线（“全文分两步：先说明禁令为何无效，再说明何种规则有效”——路线图不是预告目录，是承诺预算：报了路线没走，属于违约**）；**开头时长比例**（**千字文开头一百二十字封顶：考场的耐心与读者的膀胱一样有限（“从词典出发的文章，多数死在去厕所的路上**）。**结尾三忌**（**①口号复现（把开头句子喊大声不叫收束叫耳鸣**）；**②升华绑架（“让我们携手走进新时代”——升华与论点的汇率为零：从具体主张飞不到人类，除非你路上换了三次发动机**）；**③故事会师（首尾同故事=孤例供神的仪式版（第 3 课）——故事结尾的正确用法：换一个变奏故事，让新故事与论点勾稽，读者在熟悉的口感里吃到新账**）；**结尾应办的事**（**收口（把分论点折回总论点一句内——“能一句装下的复杂度，才是你真掌握的复杂度”）＋限度（第 3 章死法在此兑现：本文适用于……，不适用于……：诚实的结尾是全文最贵的一段广告”）＋下一步（给读者一个买得起的行动：论证的落款不是感叹号，是工单**）。
:::

## 段落：基本工程单元 {#def-duanluo}

::: definition 四件套与路标件 {#def-sijian}
**一个主张段＝观点＋证据＋分析＋小结**（**观点句段首亮出（考卷阅卷的动线是竖着扫的：段首句就是你的招聘广告**）；**证据按料性入场（第 3 课）；分析件是全段利润所在：说明证据为何支持观点、排除了什么替代解释、到什么程度（“‘数据显示 X 上升’之后那三行‘这说明……但也可能……因此在本论点内……’才是文章的心脏**）；**小结句回写论点（回写不是复读，是结清：‘可见，禁令管住了行为，管不住动机’——一句结清，下段才能开新账**）——**缺分析件的段落是承重墙里填砖头：外表一样，验收时见光**）。**过渡句=路标兼修订条款**（“**以上谈的是效率，以下谈公平：此二者在此题中不是一回事**”——两个职能：给上一章关门、给这一章开门；结构病“思路跳跃”的投诉，八成由缺路标引起（路标句成本十二字，赔偿是一整段的误解：全文性价比之王**）。**段长纪律**（**论证段一百到两百字为常态；超过二百五十字，先怀疑你把两段缝在了一起；低于五十字，通常是一个例子加一句感叹）。
:::

::: definition 提纲的两级工艺 {#def-tigang}
**词提纲 vs 句子提纲**（**词提纲是给记忆力的提示（“开头：手机；段二：英国研究……”），句子提纲才是给逻辑的图纸（段二句：“自愿试用的学校样本，使‘成绩改善’与‘学校意愿’无法分离”——图纸上能看出承重，提示条上只看得到字**））；**句子提纲的验收三行**（**每段一句完整判断句；每句标注职能（立/证/驳/收）；相邻两句之间能写出衔接词（写出“因此”还是“相反”？写不出＝两段不认识**））；**写作顺序≠验收顺序**（**可以先写最有货的一段（通常是他方最强论或机制段），但交付前必须按读者顺序重读一遍——“先写哪段是作者的权利，怎么排是读者的合同：违约的代价是没人知道你第二段在替第一段还债**）。
:::

::: example 结构 CT：五病会诊 {#ex-ct}
一篇《劳动教育必修》学生习作梗概如下，请做**结构 CT**：指认五种病的病灶句，并各开一张重排手术单——“**第一段：劳动是人类文明的源泉（160 字抒情排比）。第二段：高尔基热爱劳动。第三段：鲁班热爱劳动。第四段：李大钊赞劳动。第五段：可是现在很多同学不爱劳动（‘有的’列举四个‘有的’，170 字）。第六段：因此我们要重视劳动教育。第七段：让青春在劳动中闪光！**”全文 720 字，出现“重视”五次，“因为”零次。
::: solution
五病会诊——**①头重脚轻**（**第一段 160 字抒情排比：开头干的是散文的活，且未亮桩未让座：手术单——压到 90 字内，保留“为什么此时谈劳动”一句由头，补出可辩之桩（劳动教育应计入必修学分还是只做倡导？**））；**②例柜（平面重复）**（**二三四段同一功能（举例赞劳动）重复三遍：三个拷贝不是三个分论点：手术单——合并为一段例证，省出字数补分析件（劳动教育的机制是什么：技能？品格？对体力劳动者的态度？——三案不同政策：一句话说清本文取哪一个**））；**③有“列举”无“归因”**（**第五段四个“有的”＝现象清单：为什么不爱劳动（评价权重？家长替代？课表挤压？）一个没答——“为什么”层整体缺席（层进式断在第二级**）；**④伪结论**（**第六段“因此要重视”：从“存在现象”跳到“应当重视”，中间的因果链与政策细节全部省略（第 3 课查账案第④病灶同款：重视体论点回魂：手术单——换成具体处方＋责任主体＋代价（计入综合素质评价的哪一项、由谁记录、如何防造假**））；**⑤口号复现结尾**（**第七段升华汇率为零：手术单——换“限度＋下一步”（本文只论证‘记录方式’的防作弊设计，不处理‘是否应设劳动课’的价值之争；建议先在本校试点两学期的‘劳动过程档案’——一段把全文从演讲拽回工程**）；**总检**（**全文“重视”五次、“因为”零次：这是一台没有发动机的宣传车——重排后的建议骨架：由头（40 字）—桩（60 字，含让步）—机制段（劳动教育改变态度的路径与证据）—他方最强论（增加负担、造假）与处理—处方段（记录方式设计）—限度与下一步：字数不变，功能翻倍**。
:::
:::

::: intuition 结构是注意力经济学 {#int-zhuyili}
**读者只有三次原谅**（**第一处路障：读两遍才懂；第二处：开始怀疑你有几层；第三处：决定只看结论——结构的本质是把误解率外包给自己的劳动（自己多铺十句路标，读者少打三次退堂鼓**）。**中文段落的传统资源**（**起承转合其实是一台“注意力调度器”：起=承诺、承=履约、转=重新取景（转不是换题，是同一笔账换个科目：第 2 章定义权的温和版）、合=结清——八股的“过接”“束股”是史上最苛刻的过渡句训练（把路标做成文体强制件：今天看是镣铐，当时看是新手村的新手保护**）。**“文无定法”的读法**（**这句正确的话常被用来逃避学版式：版式是引力不是镣铐——先按引力走，走熟了才知道哪里可以跳、跳了会不会摔（第 15 课“程式=公开未定点”的结构版：规矩在先，出格才是风格；没有规矩的出格，叫迷路**。
:::

::: history 章法学的账本 {#sec-zhangfa}
**南朝** 《文心雕龙·章句》（“**章句在于情理，而述作不失其统**”通说化用＋《附会》“**总一统理，首尾一体**”（大意）——文章学第一次为“统一性”立法（**刘勰给结构下的定义：总秩序术——不是排座位，是修铁路**）；**宋元—明清** 章句之学（**朱熹教人读书先求“文势”；吕祖谦《古文关键》开“看文章起处、转处、结处”的评点课——结构第一次成为可教的知识（把天才的路数写成导航说明**）；**明清** 八股（**破题—承题—起讲—入手—起股—中股—后股—束股——把“起承转合”制度化到段落编号级：效率惊人（任何人经半年训练皆可写成篇），代价同样惊人（可辩之点让位于代圣立言：第 2 课“论点的驯化”——结构工艺与思想自由的著名冤家案**））；**1920s—30s** 现代文章学入课（**“言之有物、言之有序”成为写作教学口号；“语法与逻辑进课堂”运动（第 16 课文体政变的续集：结构开始被当作逻辑问题而不是气韵问题来教**））；**1980s—今** 考场文体（**“三段论式应试结构”与“反模板”运动拉锯；2014 后任务驱动题把评分点从“完整”加挂到“完成具体任务”——评分标准的指挥棒，才是真正的结构学教材（第 10 课细读这份合同**）。
:::

::: warning 结构四坑
**目录幻觉**（**把“本文分三部分”当路线图：路线图必须写论点（“先说明 X 无效，再论证 Y 有效”），不是写目录编号**）；**小标题依赖**（**用四个小标题掩盖四个小段落不会衔接——小标题是目录的糖衣：拿掉小标题，段落还认识路吗（拿掉不认识，说明你写的是 PPT 不是文章**）；**字数分配当结构**（**“开头 100、结尾 100、中间凑够就行”：结构是功能配重，不是字数民主（机制段该占 300 字就写 300 字——平均主义的段落是摊大饼**）；**修改只改句子**（**通病：改稿三轮全在润色词句，结构一次没动（改稿顺序学：先查骨架（版式对不对）、再查段落（四件全不全）、最后才轮到句子：倒着改的人会改到天亮**。
:::

::: exercise 句子图纸 {level=1}
为你第 2 课钉的桩画一份**句子提纲**：六段（含让步段与限度段），每段一句完整判断句＋职能标注（立/证/驳/收）＋相邻句间写出衔接词（因此/然而/进一步/与之相比）。
::: solution
判分：**每句可独立验收**（**判断句，不是名词短语**）；**衔接词栏最能抓 bug**（**两处该写“因此”却写出“相反”的断裂，或写了“进一步”其实只是换例子——图纸上的断裂，就是成文后读者摔跤的坑位**）。
:::
:::

::: exercise 同一副骨架三种版式 {level=2}
任选一个议题（如“校园手机分级管理”），分别用层进式与对照式列出提纲（各六行），并写明：**若改用驳论式，你要树的最强靶子是谁、它的承重墙是哪一句**。
::: solution
判分：**两版提纲的机制段不得互换**（**能互换说明两版只是换了标题的同一篇**）；驳论式靶子判分：**必须是该议题的真实最强立场（第 1 课钢铁人：靶子要能让对方本人点头认领**）；承重墙要指出**拆掉它立场即塌的那一句**（“不是‘这个观点不好’，是‘其有效性依赖家长全程监督，而该假设在双职工场景断裂’：拆墙拆砂浆，不拆门牌。
:::
:::

::: exercise 小论文：结构即礼貌 {level=3}
写六百至一千字，评“**把文章写得难读，不是深刻，是对他人时间的挪用：结构是作者把方便留给自己、还是留给读者的总选择——也是议论文最初的公共道德**”。须调用：**四种版式选择法**、**开头三件事**、**结尾“限度＋下一步”**、**段落四件套**、**句子提纲**、**三次原谅**至少六项；并裁决：**学术写作、公文与考场作文各自“奖励”什么结构——为什么同一种逻辑在不同文体会穿不同的衣服（举一种“换衣服出事”的实例）**。
::: solution
判分点：六项机制（**选择法＝论点形状；让座＝公共性；限度＝诚实定价；四件套＝段落利润；图纸＝可施工性；三次原谅＝预算制**）；裁决（**参考：学术奖励路标密集＋限定词满格（防御性文体：处处“本文并不主张”）；公文奖励结论前置＋依据紧跟（“收文即决策”的动线）；考场奖励首段亮桩＋段首功能句（阅卷动线两分钟一道题）——换衣服出事实例：**把论文腔搬进考场（限定词满格而判卷人以为不敢亮明主张）、把考场腔搬进论文（排比升华句在文献面前裸奔：第 8 章“文类合同用错”的结构版**）；结论若能写“**结构是文字的公共基础设施：你修的每一段路标，都在替你向陌生人说一句——你的时间值得尊重；而尊重读者最好的方式，是让他有朝一日也能走你走过的夜路”，即 A。
:::

::: summary
排线归档：四版式（**并列查互斥穷尽、层进查楼梯、对照查同框、驳论查立**）、首尾（**亮桩让座报路线；收口限度工单**）、段落（**四件套＋路标句＋段长纪律**）、提纲（**句子图纸＋衔接词测谎**）、读法（**三次原谅；文无定法是出格权，不是免学券**）。方法一句话：**先画图纸，再搬砖**。下一章专拆反方：驳论。
:::
