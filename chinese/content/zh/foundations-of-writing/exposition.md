---
title: "说明"
---

说明文是写作的**公共服务**：不求动人，但求说清——把一样东西、一道程序、一个概念，讲给**零基础的读者**听懂。这门手艺的职业道德只有一条：**别假设读者跟你一样懂**。

## 三个邻居，一张边界图 {#sec-bianjie}

::: definition 说明的户籍 {#def-huji}
表达方式的三兄弟常被混住：**描写**要读者**感受**（“月色如积水空明”），**说明**要读者**知道**（“灯箱由面板、光源、底座三部分构成”），**议论**要读者**相信**（“节能灯优于白炽灯，因为……”）。判据一句话：**删掉它，损失的是氛围（描写）、信息（说明）还是立场（议论）？**——考场上最常见的文体车祸：说明文里夹抒情（“啊，笔袋，你默默无闻奉献一生”——**拟人化说明是偷懒，不是生动**），以及把“介绍《海底两万里》”写成情节复述加读后感（**说明书目要有说明书的自觉：作者、设定、结构、版本、读法，故事梗概只是其中一格**）。说明文的两个亚种：**事物说明**（构造、功能、流程——说明书、食谱、地图注记）与**事理说明**（概念、原理、关系——为什么高铁上手机信号差）。共同指标只有一个：**读者的复述准确率**——他能否照着你的文，组装出那个东西/复述那个原理？
:::

::: definition 四种顺序与六件工具 {def-shunxu}
**顺序按对象的骨架选**：时间（制作流程、演变史）、空间（建筑、地图——“由南向北”“自下而上”，**方位词是说明文的红绿灯**）、逻辑（由表及里、由因到果、由主到次——概念类默认档）、程序（操作步骤——可编号，可图示，**禁止跳步**）。**方法六件套**：**下定义**（被定义概念＝种差＋属概念——“正方形是四边相等且四角为直角的四边形”，**定义不能循环、不能否定、不能比喻**：“好奇心是一种饥饿”是描写，不是定义）；**分类**（“图书按用途分为…”——**子项相加要等于母项，一次只用一个分类标准**——按开本和按内容混分=分类学的车祸现场）；**举例子**（抽象原理的落地签）；**列数字**（**数字要带约数的礼貌**——“约”“上下”“左右”：把测量值写成精确值，假精确比模糊更不诚实）；**作比较**（新事物挂靠旧经验——“这个水库相当于两万个标准泳池”）；**打比方**（**说明文里打比方是脚手架**：帮读者翻第一道墙，翻过去就拆——打比方不算论据）。
:::

::: example 说明文改写：《如何系鞋带》 {#ex-xiedai}
给三年级新生写一则“如何系鞋带”的说明。下面是初稿，请按“顺序、可操作、零先验”三查改写，并列出初稿的跳步清单：
“先把鞋带交叉拉紧，然后绕一圈，打个结，再抽出一个耳朵就好了，很简单的。”
::: solution
三查定罪：**顺序**（“绕一圈”发生在什么状态之后？步骤间的**前置条件**全缺）；**可操作**（“拉紧”——往哪个方向、用几只手？“打个结”是单结还是双结？）；**零先验**（“耳朵”是行话——**对不懂的人，每个名词都要当场发货**；“很简单”是作者的特权陈述，**对读者的困难零成本**——禁用“很简单”“不言而喻”类禁用词）。跳步清单：交叉的方向（左压右还是右压左，**成品有区别**）、穿孔的朝向（上下方向决定下一步能否成立）、绕圈后线头从哪进哪出、活结的两个环如何互相穿、拉紧的方向（两环对角拉，一提鞋带就散——**初稿的“抽出一个耳朵”正是散结病因**）。改写示范（节选）：“①两手持绳头，左右交叉，**左绳从下往上**穿过右绳形成的圈，两手同时向**斜上方**拉直——此时鞋面上是一个单结。②捏住左绳对折，形成一个环，食指顶住环根部……”——**每步以动词开头，一步只做一个动作，方位词不省略**。判分金标准：让从没系过鞋带的人照做（或想象照做）**不提问**——**读者每提出一个“然后呢”，就是作者欠下一步的债**。
:::
:::

::: intuition 说明的礼貌 {#int-lingmao}
说明文是**最谦卑的文体**，它的道德感藏在细节里：①**术语当场解释**（第一次出现必须给通俗等价物——“地幔（地球中间那层石头，像煮得半熟的鸡蛋的蛋清）”）；②**数字带体温**（“高 8848.86 米”之后补一句“相当于从头楼顶到大楼底再爬两千八百多层”——**数字要让身体有感觉**）；③**不确定要自首**（“约”“目前所知”“尚无定论”——**诚实的模糊优于假装的精确**，这条与科普伦理直通，参见[[modern-vocabulary/dictionaries]]式的存疑传统）；④**为笨蛋设计，为专家核对**（读者画像先行：写给同学和写给评委，是两份说明书——**说明文没有“大众”读者，只有一类人**）。冷幽默总结：抒情文害怕读者无动于衷，说明文害怕读者**问“然后呢”**——都怕对了。
:::

::: history 从《考工记》到说明文课文 {#sec-kecheng}
中国本有强大的说明传统：**《考工记》**（先秦手工业技术文献——“凡攻木之工七，攻金之工六”：分类、程序、标准齐全，**两千年前的国家标准说明书**）；**《齐民要术》**（农事程序说明的模范：耕田、收种各有时令，条目如代码）；**《天工开物》**（明——“巧人巧器”全流程说明，配图与数据并重，被译介海外）；**笔记传统**（《梦溪笔谈》说明活字印刷术——**毕昇的发明全靠沈括的说明文传世**：一段文字保住一项技术，说明文的存档功）；**现代**：“说明文”作为教学文体随白话教科书确立（与实用文写作同步：**说明文是现代化、工业化催生的文体需求**——说明书、公约、百科都需要**会写清楚的人**）；**1950s 起** 说明文进教材序列（《中国石拱桥》《核舟记》类课文成为几代人的“说明”启蒙——**叶圣陶为教材写的示范说明文**长期入选，作者与文体互相成就）；**当代**：高考一度热考实用类文本（图表、说明书、邀请函——**“应用文”与“说明文”的合流**），随后在“任务驱动型作文”里以**发言稿、书信、广播稿**名义继续出场：**说明从未离开考场，只是换了工装**。
:::

::: warning 说明四大忌
一**循环定义**（用“爱好”解释“兴趣”，再用“兴趣”解释“爱好”）——**定义必须踩在已知的地上**）；二**标准漂移**（“书分为中国的、外国的、古代的、平装的”——**一次一个分类标准**，混用=把三个抽屉倒进一个筐）；三**拟人卖萌**（“小水滴周游世界”通篇到底——**打比方是脚手架不是主结构**，比喻替代不了机制，读者笑完什么都没记住）；四**数据裸露**（贴一串数字不解释量级、单位、来源——**数字不翻译就等于没说**；来源存疑的数字宁可不用：**说明文的信用是唯一的资产**）。
:::

::: exercise 零先验写作 {level=1}
写 150 字说明：①“什么是月食”（对象：小学二年级）；②“如何折叠并封装一封信”（对象：没见过信封的人）。要求：动词开头分步、无未解释术语、结尾自问“读者会问哪个‘然后呢’”并补上。
::: solution
判分：①须处理“影子从哪来”（先说明影子=光被挡——**原理在前，现象才有地方挂**）；②须有“开口朝哪”“胶水还是水”（自粘条要解释“撕开的那条纸皮下面有胶”——**这就是零先验**）；每个“然后呢”补丁 +1 分，出现“很简单”直接扣回。
:::
:::

::: exercise 分类手术 {level=2}
给学校社团做一次分类说明：现有 12 个社团名单自拟，按**单一标准**分两类三档，写成 120 字说明，并附一句“我放弃了另一种分法，因为……”。
::: solution
判分：子项相加=母项（无遗漏无重叠）；标准唯一且**服务说明目的**（按“是否要上台表演”分比按名字首字母分更有信息量——**分类是为了解决读者的问题，不是为了整齐**）；“放弃说明”展示元认知（另一种标准也成立但服务另一个问题——分类是观点，不是真理）。
:::
:::

::: exercise 小论文：清楚是一种道德 {level=3}
写六百至一千字：有人说“把东西写清楚只是技术问题，把东西写美才是文学问题”，请评论。要求：①以一段经典说明文（《中国石拱桥》《核舟记》或说明书案例）分析“清楚的技艺”；②联系**信息时代**（谣言、带货文案、AI 生成说明）论“清楚”与“诚实”的绑定；③给出你的结论：清楚与美是对立的吗？
::: solution
判分点：能拆“清楚”的技艺含量（选序=判断力，分类=世界观，数字翻译=同理心）；信息时代案例可用（“科学配方”无数据=不诚实，谣言的流畅反证**流畅不是清楚的近义词**）；结论反题：清楚与美同源——**都为读者着想的两种形态**；引叶圣陶式“写东西是给人看的”收束者可满分。
:::

::: summary
说明车间出厂检验四项：**户籍**（要读者知道，不是感动）、**骨架**（时间/空间/逻辑/程序，方位词是红绿灯）、**六件工具**（定义不循环、分类单标准、数字带体温、比方当脚手架用完就拆）、**礼貌**（术语当场解释、不确定自首、读者画像先行）。出厂指标只有一行字：**读者的复述准确率**。下一章收拾标点和语病——语言的卫生条例。
:::
