title: "语言与标点"
---

语言的毛病要靠耳朵抓，标点的毛病要靠规则治。本章是写作课的**卫生条例**：文从字顺四字是底线，标点是语气的乐谱——两者都练成习惯，卷面自己会说话。

## 文从字顺：耳朵当质检员 {#sec-wcn}

::: definition 四种不顺与朗读法 {#def-bushun}
“**思想不集中，文章就不通。**”——**写作与思考是一个东西**；病句的根源在思路，不在语感。语病医院与语法课分诊（句法病理详诊见[[modern-grammar/faulty-sentences]]），本章带四件常发病号回家：**搭配不当**（“记起了过去的往事和同学们的音容笑貌”——“想起音容”可，“想起笑貌”不行——**并列结构要分别试婚**）、**成分多余**（“大约……左右”“基本上完全”——**两头话挤死中间**）、**指代不明**（“小明告诉小刚，他获奖了”——三个他抢一个位置）、**关联词错位**（前后主语不同，“不但”要放在主语前：“不但他去了，我也去了”；主语相同，关联词跟在主语后：“他不但去了，还唱了两首”——口诀一条：**同主后，异主前**——前后主语不同，“不但”应在“我”前——口诀只此一条够用）。**质检流程**：写完**朗读**（默读骗耳朵，出声不骗——气不够的地方就是句子过长的地方）；**缩句复查**（挑主干：谁—做—什么？枝叶配不配？）。
:::

## 标点：语气的乐谱 {#sec-biaodian}

::: definition 国标与常用账 {#def-guobiao}
国家标准 **GB/T 15834—2011《标点符号用法》**（前身为 1995 年版）：16 种点号＋标号各司其职，课堂高频账目：**顿号 vs 逗号**（“我们跑步、跳远、投掷”——句内**并列词语**用顿号，**并列分句**用逗号：“我们跑步，我们跳远”——**两次“我们”之间没有顿号的容身之处**；并列词语带语气词后改用逗号：“又香呢，又甜呢”）；**书名号**（管“作品”：书籍、文章、报刊、影视、歌曲——“《读者》”对；活动、主题、栏目不是作品，用引号不用书名号：“读书节”开幕，别写成《读书节》）；**引号跟点**（引文独立，句末点在引号内；引文作句子成分，点留在引号外——**引号是房客，标点是房东：房子（整句）里才算房客的账**）；**“某某说”的位置学**（放在引文前用冒号：他说：“去吧。”放在引文中间用逗号：“去吧，”他说，“天黑前回来。”——**说在引中用逗号，是考卷常客**）；**分号**（并列分句之间，**已有逗号的复句求层次清楚才请分号出面**——它不是“高级逗号”）；**序号层级**（公文传统：一、（一）1.（1）——**作文里保持一层一种就功德无量**）。
:::

::: intuition 抄读检查法 {#int-chaodu}
考卷上没有老师，只有你自己——终检三遍法：**第一遍听**（出声或心里慢读，卡壳即病句——**舌头是最便宜的语法医生**）；**第二遍数**（数段落是否失衡、数每段是否只做一件事、数感叹号是否超支——**数字不会陪感觉撒谎**）；**第三遍抄**（把易错字在草稿纸上抄一遍再回填——“的地得”“在再”“做作”三对冤家**逐处点名**，不靠眼缘）。标点急救箱：**一逗到底**（长句拆短，句号是呼吸不是认输）；**有顿无逗**（并列分句误用顿号——读三遍就听出来）；**引文标点各回各家**（整句内、成分外）；**标题、书名、问句末尾不画蛇添足**（古书靠句读，“读书略解义理，不以章句为事”的师承口授时代，句读是私功而非公器）；**1919** 国语统一筹备会通过《请颁行新式标点符号议案》（马裕藻、钱玄同、周秉常、胡适等联名——**标点从私功变公器，与新文化运动同轨**）；**1920** 教育部通令行用；**1951** 中央人民政府出版总署公布《标点符号用法》（第一次政府颁行统一用法）；**1990** 国家语委、新闻出版署修订发布；**1995** 首个国家标准 GB/T 15834—1995；**2011** 现行国标 GB/T 15834—2011（增连接号三分、规定“！”“？”在无停顿处可省等细则——**标点也有版本管理**）；**网络时代**：标点进入语用野生期——**“好的”与“好的。”“好的！”是三种天气**（句号的冷、感叹的热、无标点的松弛）；“！！！”的通胀让单个感叹号贬值（抒情课的数字封顶学在此复现，见[[foundations-of-writing/expressing-feeling]]）；“~~”波浪号卖萌、“一”破折号拉成横线——**语用创新好玩，考卷按国标办事**：两套账本都要会记。
:::

::: warning 语言标点四漏
一**“的地得”裸奔**（定性名、状动地、动补得——口诀谁都会，逐处点名才是功夫；写作课的止损线：**拿不准就读三遍**）；二**问号滥用**（“我不知道他为什么不来。”——**从句疑问不是提问**）**）；三**标点抄写走形**（**半角全角不分是电子时代的错别字**）；四**卷面当草稿**（涂改团、插入号满天飞——**卷面是读者的第一印象，标点的第一职责是视觉秩序**）。
:::

::: exercise 朗读门诊 {level=1}
把下面病句段朗读并修改（四处毛病）：“他的家乡是山东人，出产苹果、山东的苹果特别甜、每年秋天，果农们忙着摘苹果、装苹果和苹果的运输。”
::: solution
门诊单：①**搭配不当**“家乡是山东人”→“他是山东人”或“家乡是山东”；②**并列层级混乱**“苹果、山东的苹果”重复且顿号连分句；③**一逗到底/顿号当逗号**“特别甜、每年秋天”跨了句子；④**并列成分结构不齐**“摘苹果、装苹果和苹果的运输”——动词性与名词性混装，改“摘苹果、装苹果、运苹果”。改写示例：“他是山东人。家乡出产苹果，秋天的时候特别甜，果农们忙着摘、装、运。”——**并列要同级，同级要同形**。
:::
:::

::: exercise 标点作文 {level=2}
用不超过 60 字写一段对话，要求同时出现：冒号提示“说”、插在引文中的“他说”（逗号）、问号、引号内句末点号与引号外点号各一处。逐条标注每个标点的“房东/房客”身份。
::: solution
示例：“你走哪条路？”她问，“导航说都在修。”——“远吗？”“不远，”她说，“一脚油门的事。”判分：插入式“她说”后用逗号；独立问句问号在引号内（房客结账）；“不远，”逗号属**引文自带**（原文是“不远。”改逗号随插入式——说明文逻辑：**引文标点随句法角色走**）。标错一处讲清理由不扣满。
:::
:::

::: exercise 小论文：标点的性格 {level=3}
写六百至一千字：以聊天中“好的。”“好的!”“好的～”“好”为例，论**同一信息的四种语气价格**；再谈严肃文本与日常语用是否需要两套标点规范，你如何在两者间切换。
::: solution
判分点：四种写法的价格分析到位（句号的降温/感叹的营业/波浪的撒娇/裸字的随意——**标点是最小的表情包**）；能区分**规范层（国标）与语用层（社群约定）**且不厚此薄彼；切换标准说清（对象与场合决定账本——给编辑发稿件与给死党回消息是两种汇率），并能点出：**乱用套账本比守旧更累**（在正式文本发“好的～”≈在作文里喊救命）。
:::
:::

::: summary
卫生所结账：**句病四号**到语法医院复诊，本章配耳检（朗读+缩句）；**标点按国标记账**（顿逗分词与分句、“说”在引中用逗号、引文点号看房客还是房东）；**终检三遍**：听、数、抄；**网络标点两套账本**：“好的。”的冷与“好的！”的热都合法，看场合。语言与标点是写作的个人卫生——不扣分的时候没人夸，扣分的时候全怪它。最后一章：修改——把“写完”变成“写好”的那道工序。
:::
