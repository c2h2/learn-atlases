---
title: "抒情"
---

抒情是写作的存款业务：前面攒下多少可感的细节，这里才敢取出多少感动。本章的反面教材名单很长——“啊！”开头的作文、结尾的口号、全员感动的班会——**情感的正确写法，是让读者自己感动**。

## 两条渠道，三种当铺 {#sec-qudao}

::: definition 直抒与间接 {#def-qudao}
抒情两条渠道：**直接抒情**（“我很想它”——那棵被砍的梧桐——喊话式，短、烈、贵：**一处最多值三十字，多了就虚**）与**间接抒情**（把感情寄存到别处，三间当铺）：**借景抒情**（“念天地之悠悠，独怆然而涕下”——天地是景的批发商；现代版：外婆去世后再没生过火的灶台——**景一说话，泪就省了**）；**托物抒情**（整篇寄存在一物上：白杨、梅花、风筝——物是感情的**不动产**，一篇一套房就够）；**叙事抒情**（**最高利息的渠道**：《项脊轩志》“庭有枇杷树，吾妻死之年所手植也，今已亭亭如盖矣”——零形容词、零感叹号，时间自己走完悲伤的全程；《背影》的买橘子同属此类：**事一具体，情就自动**）。教学顺序与考试直觉常把直抒当“感情真挚”的同义词——**真挚不等于高分贝**；响的是扩音器，深的是留声机。
:::

::: example 病例会诊：《再见了，母校》结尾 {#ex-muxiao}
原文：“六年过去了，我即将离开母校。啊，母校！您是我的摇篮，我的灯塔，我的第二个家！我一定会永远永远怀念您的！母校，我爱你！”请会诊（三种病），并做一台“降分贝升当量”的手术。
::: solution
会诊：**病一·排比通货膨胀**（摇篮、灯塔、家——三个过期比喻连发，每个都在稀释下一个；**比喻连用如连喊价，喊到第三个没人信**）；**病二·呼告成瘾**（“啊，母校！”“母校，我爱你！”——直抒超支；喊出来的爱是欠条，做出来的才是存款）；**病三·承诺空头**（“永远永远怀念”——六年的感情用六个字结算，**副词叠加倍的不是感情是心虚**）。手术方案：**把当铺全部重开——删掉三个比喻、两个呼告、一个永远**；寄存到**一个场景＋一个物件**：“最后一次锁教室门，我把钥匙在窗台放了很久才推给老师。楼道里那幅中国地图，右上角被我贴过一面小红旗——那节语文课我讲南海。旗还在，我下周就交钥匙了。”——“我爱你”三个字一个没有，全文都是它。手术命名：**降分贝，升当量**。
:::
:::

::: intuition 克制为什么更贵 {#int-le}
经济学解释：感情的**稀缺性定价**。读者心里有一杆秤——你写“我伤心极了”，是在**报价**；你写“爸爸把我的碗筷也洗了”（妈妈去世后的第一顿饭，家人谁都没说话），是在**交货**。报价多了，信用破产；交货，货自己会说话。中外美学在此合流：中国讲“**哀而不伤，乐而不淫**”（《论语》的中和美学——不是不许感情，是感情要有容器）；西洋现代主义讲冰山与“**展示，不要告诉**”（show, don't tell——同一条课程标准的两种方言）。容器技术三件：**停在动作上**（情绪最高点恰好收束，让动作当句号：“我把试卷翻到背面，背面是空的”）；**让物替你说**（“旗还在，我下周就交钥匙了”）；**数字封顶**（一篇作文的感叹号限额三个、呼告限额一次——**超支的标点会替你说谎**）。
:::

::: history 抒情的课程史与文体史 {#sec-kecheng}
**古典库存**：诗言志（《尚书·尧典》“诗言志，歌永言”——抒情权的出生证明）、赋“体物写志”、词为“艳科”到苏轼辛弃疾**开口向“诗”抢地盘**（豪放派的诞生=抒情音量改革）；**文教线**：1950 年代后“表达方式四分法”（记叙/描写/说明/议论）与“抒情”作为**表达方式老五**的暧昧地位（有的教材四分含抒情、有的单列——**教学法内部也没谈拢**）；**创作线**：1940s 冯至《十四行集》、1980s “朦胧诗”（北岛“我不相信”——**直抒的现代重铸：喊话可以高级，前提是每一行都有货单**）、海子“面朝大海”（1989 后成为国民抒情模板，也被仿写玩坏——**模板化的反抗一旦流行就成了新模板**）；**课堂现状**：抒情训练集中于**结尾升华**环节（“由真情到哲理”的最后一公里），于是诞生新文体病：**“升华强迫症”**——一只蜗牛爬墙也要悟出人生大道理（本章主张：**允许文章不升华，只完成**——写清楚一次想念，功德已圆满）。
:::

::: warning 抒情三假
一**借来的感动**（写“每读到这首诗我都泪流满面”）——**别人的作品不是你感情的发票**；要写它凭什么，别写你哭了）；二**节日抒情**（母亲节作文的“妈妈的爱”流水线：送伞、背我上医院、深夜牛奶——**公共事件冒充私人记忆**，妈妈的真实癖好一个没有）；三**悲情集资**（家人重病、家境贫寒按需编造以换取感动——**用惨换分是情感乞讨**，与“加戏癖”同案，见[[foundations-of-writing/narration]]记叙的诚信）。三假共犯：**把抒情当目的**——抒情是叙事的利息，不是提款机的目标金额。
:::

::: exercise 交货练习 {level=1}
从下列“报价句”任选三句，各改写成 40 字内的“交货”（只许用动作、物件、数字，不许出现情绪名词）：①我很难过 ②我很想爷爷 ③我特别感动 ④我们班都舍不得他。
::: solution
方向示例：②“爷爷的收音机还放在他常坐的椅边，电池早没了，我每周还是把它摆正一次。”④“值日表贴出来，他的名字后面那格没人舍得排新活，一直空到学期末。”判分：**情绪名词零出现**且可被读者反推；反推失败=交货不足。
:::
:::

::: exercise 降分贝手术 {level=2}
找一段自己旧作的抒情段（或范文里的呼告段），做“母校结尾”同款手术：删呼告、删过期比喻、改寄存到**一个场景＋一个物件**；文末附 30 字自诊：“原稿在喊，新稿在……”
::: solution
判分：新稿**不出现被删掉的三类词**（啊/永远/摇篮灯塔类库存喻）；场景必须**具体到能拍下来**（时间、位置、手上拿着什么）；自诊句诚实（“在摆证据”“在闭嘴”都算对）。原段与手术段并列粘贴，方便验收疤痕。
:::
:::

::: exercise 小论文：抒情与公共模板 {level=3}
写六百至一千字：“为什么一到母亲节，全网都在转发同一句话？”以节日文案、应援口号、毕业朋友圈为材料，论**公共抒情模板的便利与暴政**，并给出你的“私人表达保留地”方案（可操作，不许喊口号）。
::: solution
判分点：机制说清（模板降低表达成本，同时**预定了什么值得感动**——暴政在预定，不在方便）；能引本课当铺模型（公共模板=无人验收的期货）；方案具体（如：每逢转发先写三行自家的；给妈妈发**只有你俩懂的梗**而非祝福体）。允许悲观派：模板吞掉一切，但**私人语料库是最后的自留地**——能自证有地契者为 A。
:::
:::

::: summary
抒情事务所规章：**渠道**（直抒限额三十字，间接三当铺——景、物、事，叙事利息最高）；**定价**（报价破产，交货升值——爸爸洗了你的碗筷，胜过一千个感叹号）；**容器**（停在动作上、让物替你说、数字封顶）；**伦理**（允许只完成不升华——一只蜗牛可以只是爬完墙）。下一章学最冷静的文体：说明——把话说明白，是比把话说美更难的礼貌。
:::
