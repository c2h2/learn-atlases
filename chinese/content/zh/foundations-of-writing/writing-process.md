---
title: "写作的过程"
---

写作课的第一件工具不是辞藻，是**工序**：从想写到交稿，中间那段被大多数人跳过或乱走的路。这门课九个星期，先把流水线立起来——之后每一章都是这条线上的一道工位。

## 流程五工位 {#sec-liucheng}

::: definition 写作过程模型 {#def-gongwei}
**积累—构思—起草—修改—校对**（过程写作法的工位表，教学名称略有出入，工序一致）：①**积累**（材料仓：观察笔记、摘录、口述——**写不出首先是没货**，见[[foundations-of-writing/observation-material]]）；②**构思**（定对象、定读者、定用途“三题纸”，再列纲——叶圣陶的比喻：写作的源头是生活，“**这源头要很盈很清，流出来的水才得着不竭与清**”（《泉与溪》大意，1934））；③**起草**（允许烂：**“写糟糕的初稿的权利”**——彼得·埃尔博《没有教师的写作》1973 的核心合同：**第一稿的任务是存在，不是优秀**））；④**修改**（改的不是错字，是**顺序、详略、立场**——见[[foundations-of-writing/revision]]）；⑤**校对**（别字、漏字、标点——工序上它必须**最后**，先校后改等于擦地板等装修）。五工位是**学习支架不是铁轨**：成熟写作者会跳站、回跑——**但“从没写过初稿直接交神来之笔”这一站，谁也跳不过**。
:::

::: definition 线性的表，循环的厂 {#def-xunhuan}
课堂教的“审题→立意→行文→修改”是一条直线（因为考场是直线交付）；心理学模型（弗劳尔与海斯 1981）说真写作是**循环**：计划—转写—评阅三个工序**嵌套往复**——写到第三段发现立意不对，退回去重想，是**正常工时**不是失败。两者的裂缝处发生的是**“教学错位”**：学生把起草当成成品生产（每句当末稿写），于是一句话磨十分钟、后面没时间、修改彻底缺席——**把校对当修改、把修改当重写、把重写当推倒重来**，全线拥堵。治法：**计时分程**（45 分钟考场版：5 审+8 纲+27 写+5 读），以及**起草期禁橡皮**（埃尔博：起草时怀疑心要请出房间——**内部编辑是起草期的非法侵入者**）。
:::

::: example 45 分钟极限赛 {#ex-45}
考场压缩版：题目随机（如《排队》），45 分钟完成 700 字。请给一张**工序计时卡**，并说明每站“做不完”时的降级方案。
::: solution
计时卡：**审题 5′**（圈出对象词与限制词，在草稿纸写下“我要对谁说件什么事”一句）→ **构思 8′**（中心句 1 句＋素材 3 个＋顺序 2 案，选 1 划 1；**列 3 段纲**：起／中／收各一行）→ **起草 27′**（按纲铺，卡壳素材就跳段——**跳段不算违章**；剩 3′ 写结尾，不写“立志”写“动作”）→ **读改 5′**（出声默读末段＋首段，修病句、补标点；**此时才允许当校对员**）。降级方案：审题超时的用“对象词造句法”强行开口；构思超时的砍到“一事一感”；起草写不完的**保结尾**（残局里一个完整收尾值 5 分——阅卷看首尾）；全崩预案：最后 8′ 把中心句扩写成三段式短文——**烂结构好过烂空白**。本练习的真面目：把“写作能力”拆成**时间管理＋工序纪律**。
:::
:::

::: intuition 修改不是补丁，是第二次投胎 {#int-xiugai}
新手以为修改=改错字；老手知道修改=**重想一遍**。给课堂一个安全版本的金句：“**初稿的意义，只在于让你知道自己在想什么**”——写是思考的显影液。这与[[foundations-of-writing/theme-structure]]的“意在笔先”不矛盾：动笔前有一整块，起草中它会碎、会重组——显影之后才看清那块究竟是什么。中外在此会师：卢延让“吟安一个字，捻断数茎须”是修改的浪漫化，曹雪芹“披阅十载，增删五次”是修改的资本化——**修改是精品的必经工序：有修改过程传世的，部部成了佳作**。
:::

::: history 一堂作文课的两百年 {#sec-kecheng}
**1904** 壬寅—癸卯学制：课堂写作以课业编制诞生（月课、季考）；**1920s** 白话入课堂，“我手写我口”成为合法选项；**1924—1930s** 夏丏尊、叶圣陶一系编订国文课本与《文心》（1934），**“读写结合”教学法成形**——精读即写作的范本库；**1950—1960s** 教学大纲化，“记叙文／说明文／议论文”三分体制确立（**文体三分是教学法的发明，不是文学的分类**——本课反复强调）；**1963** 第一部全国大纲立“双基”；**1978** 高考恢复，作文重归计分；**1980s—1990s** “放胆文—得手文”教学实验与“观察—思维—表达”训练线并进；**1999—2001** 新课标把“有创意地表达”“减少题目限制”写入条文；**2016 起** 统编教材把写作编入“生活写作”序列；**考场外**：过程写作法经翻译进入教研文献，**写作工坊在民间写作教育与大学写作中心复活**——课堂与工坊两条轨道，仍在并轨施工中。
:::

::: warning 工序四违章
一**边写边改**（起草期养编辑=每小时 200 字的慢性自杀——起草与评阅的工位要**物理分时**）；二**只改字句不动结构**（末稿与初稿的区别不在形容词，在**骨架**——改了标点没改顺序，等于装修没改户型）；三**把修改交出去**（“老师你帮我看看哪儿不对”——修改的主人是作者，教师的红笔是体检报告不是代吃——**自己的稿子自己先动刀**）；四**迷信灵感开工**（“等有感觉再写”=把开工证交给天气——职业写手的对策是**工序代替心情**：坐、定时、动笔，感觉是流程的副产品，不是入场券）。
:::

::: exercise 三题纸 {level=1}
写一篇 500 字小记（题目自拟）之前，先交“三题纸”：对象、读者、用途各一句＋中心句一句＋3 段纲。然后按纸施工，末尾附 50 字“偏航报告”。
::: solution
判分：三题纸齐且**互相约束**（用途能检验中心句是否空转）；偏航报告诚实记录“哪一段写跑题、为什么跑”——**跑题处的素材往往是真兴趣**，会利用偏航者 A。范文向：对象“早市”、读者“没逛过早市的中学生”、用途“让他明天想去一次”——中心句因此必须含**一个可复现的动作**。
:::
:::

::: exercise 计时拆解 {level=2}
把你上次写 800 字的真实时间账（估到 5 分钟）记下来：审题／构思／起草／修改各占几分钟？与 45′ 配比对照，开一张**个人违章单**（一项最严重的工序错误＋改正动作）。
::: solution
典型诊断：构思≈0′（直接违章“无图施工”）；修改≈0′（“写完即交”）；起草占八成且超时（边写边改）。改正动作要**可执行**（“下次先在草稿纸写中心句再动笔”，比“我要认真”可执行一百倍）。判分点：有账、有单、有动作，不要求忏悔文学。
:::
:::

::: exercise 小论文：过程与灵感 {level=3}
写六百至一千字：给“灵感说”写一份**尸检报告**（它如何解释天才、如何吓退新手、如何为拖延作证），再开一张“工序说”的处方（含一个你自己的反例——某次“灵感突然来”其实发生在哪个工序之后）。
::: solution
判分点：尸检三刀到位（天才叙事的神秘化、新手被吓退的门槛效应、“等灵感”=不进场）；处方承认灵感的工序学身份（**阿基米德的浴缸出现在洗澡之后**——顿悟是长期积累加专注之后的奖赏，数学家庞加莱自述的“马车上的顿悟”前面是多年的苦思）；反例真实具体。
:::
:::

::: summary
本章提货：**五工位**（积累—构思—起草—修改—校对）与两张许可证——**烂草稿许可证**（起草期编辑回避）与**回跑许可证**（循环是常态）；一条铁律：**校对必须最后**；一个真相：把写作拆成工序之后，“我不会写”就缩小为“我在某一站缺勤”——**可诊断，就可训练**。下一章进第一站：观察与积累——把“没得写”这三个字从字典里删掉。
:::
