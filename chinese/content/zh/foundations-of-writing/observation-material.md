---
title: "观察与积累"
---

“没得写”是写作课第一疑难杂症——本章拆穿它：**你不是不会写，你是没看见**。看是被训练的肌肉，记是被系统化的习惯；仓里有货，笔才有米。

## 看见，而不是认出 {#sec-kanjian}

::: definition 观看的懒政与改革 {#def-kanjian}
大脑的默认设置是**认出**（“树”“交警”“地铁”——贴标签即完工），写作者要的是**看见**（什克洛夫斯基所谓“**使石头成为石头**”——把事物从标签里赎回来；**陌生化**手法在[[rhetoric/what-is-rhetoric]]已见面，本章讲它的**输入端**功夫）。训练三刀：①**五感分账**（看见的不算新闻，**闻见、听见、摸见**才新鲜——“早市”的库存词是“热闹”，观察者的账上是“鱼腥混着炸油条的烟、秤砣磕案板的闷响、塑料袋在指环上勒出的白”）；②**特写强迫症**（拒收全景：逼自己拍“一枚硬币在摊主油亮掌心里的旅行”）；③**数字入眼**（“人多”是懒账，“排队的人从三号窗口拐了两个弯、第九个在刷手机第七分钟”是可写的账）。**契诃夫的教训**：他教兄弟看窗台——“**你不必告诉我月亮在发光，让我看到碎玻璃上的一抹闪光**”（致兄弟亚历山大·契诃夫书，1888 的名言大意——**细节是描写界的硬通货**）。
:::

::: definition 观察笔记三栏法 {#def-sanlan}
随身本（或手机备忘录）分三栏：**看见／推断／感受**——训练“**事实与脑补分账**”。示例：看见“她每隔半分钟看一次墙上的钟”／推断“在等人，且等得心虚”／感受“我替她着急”。三栏的价值全在**分账**：写作事故一半是把推断当事实写（“他悲伤地走进来”——你只看见低头和快），一半是把感受当共识卖（“感动的场面”——你自己没记录可感的细节）。**每天 15 分钟 × 三则**，两周起效——这是本课程的**处方级作业**（与[[foundations-of-writing/language-punctuation]]的语料库并列为两条日常线）。
:::

## 材料仓库管 {#sec-cangku}

::: definition 材料四库与来源三档 {#def-siku}
按**存什么**分四库：**人**（肖像库：长相、口头禅、习惯动作——“父亲的口头禅”比“父爱如山”可写一百倍）、**事**（情节库：完整事件+意外转折）、**理**（观点库：金句、争论、反常识判断）、**情**（情绪库：当时的身体反应——紧张是“手滑在袖口上蹭了三次”）。按**从哪来**分三档并标**置信度**：**亲历**（最高，但有“只在此山中”的盲区）、**听闻**（口述与二手材料——注明转手次数，“听三姨说”要写得出从谁到谁）、**想象**（合法材料，但作者心里要**给它挂假一赔三的牌子**：虚构是小说的权利，不是记叙文的免罪券——把“合理想象”写进记叙文，等于承认编造）。**口述史小手艺**（听闻库的正规进货渠道）：问题从“还记得什么”开闸、用细节追细节（“那天早上你穿的什么？”）、**不纠正对方的记忆**（口述的价值一半在“记成了什么样”）；一小时口述能出三篇好作文——**你家就有一座没开采的材料矿**。
:::

::: example 同一个早市，三家进货 {#ex-zaoshi}
场景：早市，卖鱼摊。请分别开一张**亲历**、一张**听闻**、一张**想象**的材料卡，并说明三张卡各自的用法与红线。
::: solution
**亲历卡**（看见／推断／感受三栏）：看见“他把翻肚的鲫鱼挑回盆里，手指插进鱼鳃试了几条，最后拎起两条最小的”／推断“他在替人挑鱼——付钱的今晚不吃这条”／感受“我忽然不敢看他笑”。用法：直接进记叙文，红线是**推断栏不得混进正文当事实**。**听闻卡**：三姨讲她第一次去鱼市“以为鱼和菜市场一样讲价，结果人家按条报价，多问一句‘能挑吗’被白了一眼”——记录转手链（三姨→我），注明讲述日期。用法：非虚构复述，红线是**不得写成亲历**（“我看见”三个字是宣誓）。**想象卡**：鱼贩凌晨三点的进货路（我从未去过）。用法：小说/散文的合法翅膀；红线是**在记叙文里把它包装成采访**——想象进对文体，叫创作；进错文体，叫作假。三张卡三种法律身份——**材料的诚信从分档开始**。
:::
:::

::: intuition 账户思维：为什么有人“越写越多” {#int-zhanghu}
“没得写”的人把写作当**取款**（灵感来了取一笔，取干拉倒）；会写的人把它当**对账单**（观察是存款，写作是记账——存款和取款之间有**复利**：记过“鱼鳃试指”的人，下次会自动注意到肉摊的刀法——**观察训练改变你感知的收货标准**，仓越盘越活）。**叶圣陶的处方最老实：“养源”——把生活本身过成泉源，而不是过成素材的猎场**）。所以本章作业反直觉：**先好好活，顺手记**。有人问记多少算够——问存款的人才会问这个。
:::

::: history 从“读万卷书”到语料库 {#sec-chuantong}
中国写作教育历来重“蓄材”：**“读万卷书，行万里路”**（语出明人画论，后来移用于文章学——名言也有自己的出处层次）是官方配方；**司马迁网罗放失旧闻**（《报任安书》——采访与档案并用的祖师爷）；**李贺锦囊**（李商隐所记：他骑驴外出，得句即投锦囊，归而再写——把“积累”活成了浪漫偶像）；**顾炎武车上马腹抄书**（《日知录》是摘抄卡系统的胜利）；**钱锺书与《管锥编》式笔记**（以卡片与札记为学，讲义堆成小山）；**现代**：叶圣陶反复要学生立日记、设笔记（他的讲义里，日记与笔记是常设科目）；**当下**：收藏夹、稍后读、语料 App——**史上材料最足、笔记最缺的一代**（收藏是占有的幻觉——**不复述的记忆不是记忆**）。
:::

::: warning 积累四病
一**收藏癖**（剪藏三千条、成文零——**摘抄不是积累，复述+应用才是**；每条收藏须能一句转述，否则删）；二**猎场病**（出门不生活，只“找素材”——**素材是生活的利息，本金必须先付**）；三**编造病**（“助人为乐”的库存模板、编出来的“外婆”——**记叙文的诚信是第一美德**：写不出感动可以写“没感动”，真实比正确高级）；四**过期罐头病**（全员共用司马迁受宫刑、爱迪生发明电灯、霍金坐轮椅的“万能例”——**不是这些人物不能用，是未经你观察加工的直接批发即复读**；用公众人物也须给出**你自己的读法**）。
:::

::: exercise 十五分钟三栏 {level=1}
去一个人多的地方（食堂、车站、小区门口），15 分钟写三则三栏笔记。提交后互评：把对方“推断栏”里“证据不足”的条目用△标出。
::: solution
判分：看见栏**无形容词特权**（有形容词须带出处细节）；推断栏**动词可数**（“他在等”证据不足，“第三次看表”是证据）；感受栏允许“没有感觉”。互评△密度最高的那位，正是下一位进步最快的——**被标△是这门课的好运气**。
:::
:::

::: exercise 家庭口述史 {level=2}
采访一位家人 40 分钟（题目：“你最后一次挨打/你第一份工作的工资”任选），整理成 600 字口述实录。要求：转手链清楚、保留一处“他纠正自己记忆”的原话、文末附你的一条△（哪里你不信）。
::: solution
判分点：①**从细节追细节**的提问痕迹（“那天你穿的什么”级问题至少一个）；②“记成什么样”**不修正地保留**（口述的价值所在）；③△的诚实（“他说‘你爸当时也在场’，但我爸说他那年不在家”——**矛盾正是史料**）。这份作业同时是家史——二十年后再读，价值翻倍。
:::
:::

::: exercise 材料矿脉图 {level=3}
用一周三栏笔记，做一张你的“矿脉图”：标出三条最富的矿脉（人/事/理/情），每条开列 3 个可写题目＋1 个预设中心句＋1 个疑问（还需要什么材料）。
::: solution
判分：矿脉来自**重复出现**（某类素材三天见三次=矿脉，一次=偶然）；题目具体（《奶奶的第二个手机》不是《亲情》）；中心句有立场（可被证明或推翻的句子）；疑问栏诚实（“需要：她第一次用它给谁打电话”——**下一步的观察就有着落了**）。图上三条矿脉即你本学期作文库存。
:::
:::

::: summary
本章拆了“没得写”的诊室：**看**（认出→看见：五感分账、特写强迫、数字入眼——让石头成为石头）、**记**（三栏法：看见／推断／感受，事实与脑补分账）、**存**（四库三档：人事情理分库，亲历／听闻／想象分法律身份）、**取**（按题提货，公众人物也要自己的读法）。处方就一张：**每天十五分钟，先好好活，顺手记**。下一章立规矩：一篇只养一个主人——立意与结构。
:::
