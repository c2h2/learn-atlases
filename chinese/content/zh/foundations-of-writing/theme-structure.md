---
title: "立意与结构"
---

材料是砖，立意是图纸，结构是承重墙——没有图纸的工地叫砖堆，没有承重墙的房子叫布景。本章两件事：**一篇只养一个主人**；**把主人请到最显眼的位置**。

## 立意：一意立法 {#sec-liyi}

::: definition 中心句是宪法 {#def-zhongxin}
**立意**=这篇作文“到底说什么”的一句话答案（教学语言叫中心，修辞学叫**主旨**，新闻学叫 lead 的判断句）。三条立法程序：①**一句话检验**（中心句必须**主谓宾齐全、可被反驳**——“母爱”不是句子，“母亲的唠叨里藏着她的时间焦虑”才是；**可被反驳，才成其为观点**）；②**剪枝法**（草稿里每句问一遍：这句侍奉谁？——**侍奉第二个主人的句子，文学上叫岔笔，考场上叫跑题前科**）；③**延迟裁决**（别在提笔前把立意焊死：叶圣陶“意在笔先”是**有一整块**，不是有一句口号——**整块是模糊的充实，动笔后它会碎、会重组，显影后才看清**，见[[foundations-of-writing/writing-process]]）。立意的档次感：**写他人未察 > 写人尽皆知而你能写细 > 写人云亦云的“深刻”**——宁可具体一寸，不挂抽象一尺。
:::

::: example 立意门诊：同一张照片 {#ex-zhaopian}
作文课发一张照片：校门口的修车摊，摊主边补胎边看书。三个同学的中心句如下，请门诊并各自开方：
甲：《我们要热爱学习》　乙：《修车摊也精彩》　丙：《他在等一个不会来的人——不，他就是来看书的》
::: solution
**甲：立意感冒**——口号病（“热爱学习”是墙上的标语，不是你的判断；照片里的人在看书，不是在看“学习”这个概念）。处方：回到细节提问——他看的什么书？为什么是这本？（追问出：他的摊上摊开一本菜谱，菜谱中间夹着本诗集——**反差即立意**：谋生的手也配得上诗——收敛成可辩的一句话）。
**乙：立意贫血**——“也精彩”是把别人的评价当自己的（精彩在哪？说不清=没立）。处方：把“精彩”换成**一个具体发现**（他看书时摊上没人，有人来时他合书的速度——原来他**防备着被看见读书**？→“体面的偏见：连旁观者都觉得修车的不该读诗”——比“精彩”深三层）。
**丙：立意过敏**——自我感动症（“等一个不会来的人”是小说腔硬套纪实；照片没给的东西被想象全额报销——**虚构进错文体**案值同上章）。但它**有救**：把破折号后的自我纠正保留为立意——“我原本想替他写一段苦情，后来发现他就是来看书的”——**把‘我想多了’写成文章**，恰好是对滥情的疫苗（此法专业名：**元记叙**，示范于[[pre-qin-literature/legacy]]的“反方辩论”精神）。门诊总结：立意三查——**是你的话吗？站得住细节吗？配得上这篇篇幅吗？**
:::
:::

## 结构：注意力的经济学 {#sec-jiegou}

::: definition 详略是投票，顺序是剧本 {#def-xianglue}
**详略**=把字数当选票投给谁（中心句的每个关键词必须有一处“重场戏”；**给配角的篇幅超过主角，读者就换戏看**）。**顺序**四案：**顺叙**（安全但易平铺——救法：在关键节点放慢成场景）、**倒叙**（结果先行：第一句先给尸体——悬念是借来的注意力）、**插叙**（中途借一段过去，**进出要有门**：进靠触发物“那把伞让我想起……”，出靠回扣“伞还在我手里”——**无门进出即跑题**）、**平叙**（双线“花开两朵各表一枝”——考场慎用，双线=两份预算）。**过渡与照应**是关节液：段与段之间靠**路标词**（然而、更重要的是、那年之后）与**复沓的关键词**（每段都回来敲一次门的中心意象）缝合；首尾照应是给读者的握手礼。
:::

::: definition 起承转合与开头结尾类型学 {#def-qc}
元人乔孟谈论乐府四法，后世移用于文章：**起要美丽，中要饱满，转要有筋斗，结尾要响亮**（“凤头、猪肚、豹尾”的通俗版）——起承转合不是八股，是**读者注意力的四段融资**：开题借钱（凭什么继续读）、承接扩建、转折还债（意外与代价）、收束结息。**开头货架**：场景直入（“他合书的速度比谁都快”）、悬念（“我这辈子没见过我爸哭，除了那台收音机”）、定义重定义（“所谓老家，就是你要回去一次才能确认回不去的地方”）、禁引名句滥用（“古人云”开场=把房产证写成别人的名字）；**结尾货架**：动作收尾（不立志志，立一个动作）、意象收尾（物还在，人已非——慎用“雨还在下”这类公版）、回环收尾（首尾同一场景，视角已换）、**禁“通过这件事我明自我”**（结尾的总结陈述是全文最便宜的零件）。**病案速查**：跑题=宪法失效；平铺=没有重场戏；头重脚轻=开头是富的猪肚结尾是穷的豹尾；断裂=没有关节液——**每种病都有一句手术单**。
:::

::: intuition 结构是替读者安排座位 {#int-zuowei}
新手按**时间的顺序**写（我先是去了，然后看了，最后吃了），老手按**理解的顺序**写（最该先知道的先说，最重的压轴或当头）。判断一篇的结构只需换位：**假设读者只有三次耐心的机会**——第一段（凭什么读）、中段最疲劳处（凭什么不弃）、最后一段（值不值得回味）——三处各押一件最好的货，其余都是运输。这就是“凤头猪肚豹尾”的现代解码：**不是体型的比喻，是预算的分配**。结构与立意的合同也在此签订：**结构=用篇幅论证中心句**，详写处即论据，略写处即背景板——一句话作文因此有救：**把中心句放大到每个场景**。
:::

::: history 从八股到提纲 {#sec-bagu}
**明清**：八股文把“结构学”推到极致也推到反面——起讲、入股、大结各有程式，**格式能保下限，不能出上限**；**1902—1905** 废科举，课堂写作失去模板母体；**1919—1930s** 国语运动后“作文法”出版热，起承转合让位“开端—中段—结尾”——**三段式接棒程式化**；**1950s 起** 苏联教学法影响下的**“编写提纲”训练**进大纲（列提纲=结构工序显性化，至今是作文课标准动作）；**1980—1990s** “文体训练序列”（记叙—说明—议论分段过关）与“单项训练作文”（扩写、缩写、改写——**把结构拆成零件练**）；**2000s 起** 话题作文与“文体自选”把结构权还给作者，随之而来的是**“文化散文腔”的结构赝品**——排比＋典故＋感叹号的仿制品泛滥；**今天**：思维导图与“故事软件”（beat sheet）在写作工坊并行——**提纲工具换了皮肤，结构学没有过时**。
:::

::: warning 结构四案底
一**头重脚轻**（前 800 字还在“那是一个风和日丽的早晨”，高潮剩 3 行——**重场戏预算倒挂**，改法：从草稿第 2 段开始写）；二**小标题依赖症**（“春/夏/秋/冬”“一/二/三”的拼盘体——**小标题是结构的外挂支架，掩盖没有承重墙的事实**；用则每个标题须有自己的重心）；三**反转成瘾**（“其实是梦/其实是我记错了”——**反转是信用卡，透支结尾的信任**；反转必须回收前文伏笔才算数）；四**华丽开头囚笼**（开头铺了四组排比，正文供不起同样的天气——**开头的修辞是欠条，全文要还**）。
:::

::: exercise 中心句手术 {level=1}
给下列“中心句”做手术，使其可被反驳且配得上细节：①《诚信》②《我的老师》③《坚持》。
::: solution
方向参考：①“被看见的诚信不算诚信——考场橡皮递过去之前，才是真正的考验”；②“他改我作文的红笔比批改更狠的是那句‘你自己再读一遍’”；③“坚持的故事只讲成功，是幸存者写给失败者的嘲讽”。判分：改写句须(a)有具体场景入口(b)能被一个反例挑战(c)你自己写得下去——三者缺一回炉。

::: exercise 预算重排 {level=2}
取你上次作文（或范文）做“篇幅审计”：五段各占百分比，对照中心句关键词的出场与比重，开一张**倒挂清单**并写 100 字重排方案（哪段砍半、哪段扩成场景、从哪句开场）。
::: solution
判分：审计用数字（38%/25%/20%/10%/7%）；倒挂诊断精确到句（“开头 6 行天气对中心句贡献为零”）；重排方案含**新第一句**（“从第 2 段开始写”是万能起手式）。范文常见案底：开头排比 15%＋结尾口号 12%＝**修辞两头肥，正文中间瘦**。
:::
:::

::: exercise 小论文：结构与真诚 {level=3}
写六百至一千字：“把文章写得‘像篇文章’，是否背叛真诚？”要求：①举一个“结构即真诚”的正例（如朱自清《背影》中“背影”的多次出现）；②举一个“结构赝品”的反例（仿文化散文腔/小标题拼盘）；③给出你的分界线：**什么时候结构是服务，什么时候是表演**。
::: solution
判分点：正例能指出复现如何**加深真实**（不是凑格式，是情感的反复惦记）；反例点出赝品机制（结构先于内容=为排比而排比）；分界线见功力——推荐立场：**结构是对读者的礼宾，真诚是对材料的诚实；礼宾不得伪造客人**（没有的感动不得用排比装出）。
:::
:::

::: summary
本章两件工具：立意三查（是你的话吗／站得住细节吗／配得上篇幅吗——**口号、贫血、过敏三味感冒药先停**）；结构四件（详略是投票、顺序是剧本、关节液是路标与复沓、首尾是两次握手）。八股保下限不保上限，提纲换了皮肤结构学不过时——因为**读者的耐心三千年来没有变多**。下一章专攻“场景”：记叙的时序、六要素台账，以及概叙与场景的比例学。
:::
