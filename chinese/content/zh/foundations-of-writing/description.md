---
title: "描写"
---

描写是叙事的暂停键：故事停下来，让读者**站进场景里**。暂停要有理由——本章教的就是理由与手法：感官怎么分工、镜头怎么摆、笔墨怎么省。

## 感官分工与镜头摆位 {#sec-ganguan}

::: definition 五感配平 {#def-wugan}
描写的第一性原理：**读者只能通过你的感官进入现场**。五感配平三规矩：①**视觉降权**（新手稿子 90% 是视力报告——老手先问“这里有什么声音/什么气味/什么温度/脚底下什么触感”；气味是记忆的捷径，“一碗馄饨的猪油味”比十行夜景更能让人回到巷子）；②**一景一主感**（一个场景选一种感官当主角，其余做和声——主感由**场景情绪**指定：紧张给听觉（钟摆、喉结），荒凉给触觉（风里的沙、椅面的灰））；③**形容词先过磅**（“美丽的、漂亮的、迷人的”是通货贬值的三兄弟——**换名词与动词**：“她的头发像被雷劈过”胜过“她很凌乱”；“夕阳把楼房的西墙烫成铜色”里没有一个抒情形容词）。
:::

::: definition 镜头四摆 {#def-jingtou}
**定点描写**（站定一位置扫全景到特写——说明性场景友好）、**移步换景**（人走景移，游记的脊椎；病在写成导游词——**每站只留一个跟“主题”握手的景**）、**高低双机**（俯察“车像甲虫爬”与仰观“烟囱插进云”切换，空间立刻立体）、**由远及近/由表及里**（经典焦距程序：远轮廓→近细节→细到“他领带上有个饭粒”——**特写即伏笔**，饭粒会说话）。四摆的共同纪律：**镜头是叙述者站的位子，不是作者的炫耀**——谁在看这景色，就写谁看得见的部分（心情不好的人看不见晚霞，只看见“天像一块没洗的抹布”——**景语的户口登记在人物名下**，专业名：见[[rhetoric/figures-of-meaning]]的“触景生情”反转用法：**先有情，才有那副眼镜**）。
:::

## 白描、工笔与通感 {#sec-baimiao}

::: definition 两种笔墨，一种偏心 {#def-bimo}
**白描**（借国画术语：不设色、只勾线——用最少的名词动词出形：《背影》——零形容词的动词解剖，百年后仍是最贵的背影）与**工笔**（重彩细描：《荷塘月色》的月光、荷香、树影层层上色——**铺张是有预算的抒情，滥用就是通胀**）。选择标准不在文采高低，在**人物与心境**：见过世面的人或克制的叙述者用白描（话少=分量），情绪满到要溢出来的时刻允许工笔一次（**工笔是烟花，天天放就是噪音**）。**通感**（修辞格的明星：“微风过处，送来缕缕清香，仿佛远处高楼上渺茫的歌声似的”——嗅觉串门到听觉；“她的笑很甜”——味觉兼职）：通感不是修辞炫技，是**感官在情绪里的真实串线**，用得准比用得多值钱。
:::

::: example 病历：一段公版风景 {#ex-gongban}
作文《春》开头：“春天来了，万物复苏，小草从土里探出头来，花儿露出了笑脸，小鸟在枝头唱着歌，小河欢快地奔向远方。”请开病历本（病名、病灶、处方各至少三条），并改写成一段"你家楼下的春天"。
::: solution
病历：**病名一·公用素材复印机**（“万物复苏”“探出头”“露笑脸”“奔向远方”全是**公共库存**——从词典抄来的拟人，没人在自家楼下见过小草探头）；**病名二·全员视觉＋全员快乐**（春天的声音、气味、温度、腿上的柳絮过敏全部缺席；且情绪先行盖章“欢快”，感官还没来得及投票）；**病名三·动词集体下岗**（“来了、复苏、探出、露出、唱着、奔向”——一半是“是”字句的亲戚，一半是**拟人化的万能动作**，没有一个是只有此处才会发生的动作）。处方：**退货重进货**——到楼下（或窗边、上学路上）用 15 分钟三栏笔记重新采集；**一景一主感**试一次“春天先从什么声音/气味开始”；**动词专项**——把每个万能动词换成“此处独有”的动作。改写示例：“春天是从塑料袋开始的。风把去年冬留的白袋子绑在栅栏上，抽得啪啪响，像没人接的电话；槐花的甜香翻墙进来，混在尾气味里，呛出一代人共同的鼻涕虫记忆——妈喊我回家收衣服，那被单上已经铺好一层细黄的花。”——万物复苏一个没提，春天在场。
:::
:::

::: intuition 描写是叙事的利息 {#int-xifen}
判一段描写好坏的**唯一实用标准**：删掉它，叙事会不会塌？**描写是叙事的利息**——本金（故事与情感）在场，描写让读者富起来；本金缺席，再华美的描写都是**裸的通胀**（“作文选体”风景段两千字，人物至今没走出家门）。所以描写的开工许可证只有一张：**此处需要暂停**——要么给情绪一个落脚点（情景交融），要么给后文一个伏笔位（特写即预告），要么给读者一张地图（环境定场）。**为写景而写景的，叫插图，不叫描写**。
:::

::: history 从“赋”到“描写训练” {#sec-fuli}
中国文学本有**描写大宗**：**汉赋**“铺采摛文，体物写志”（《文心雕龙·诠赋》——写物即言志的官方时代，铺张是正体）；**山水诗**（谢灵运“池塘生春草”——自然入诗取得户口）；**六朝小札**“风烟俱净，天山共色”（吴均）把山水缩成明信片；**唐宋古文与诗词**的“境界”线（“红杏枝头春意闹”——王国维最赏这一个“闹”字——**炼字即炼感官**——宋祁词与王国维《人间词话》课堂并读）；**清代画论**把“描”字传家：《芥子园画传》的谱式教学；**近代**：《文心》与作文教材把“描写”从画论搬进语文课，与“记叙、说明、议论”并列为**表达方式四分法**（教学法发明，同上章提醒）；**现当代**：老舍“北平的秋”、汪曾祺的高邮咸鸭蛋（**白描＋口语音**的现代示范：写吃食即写故乡）；**今天**：影视分镜与“种草文案”成为新一代描写教材——**说明词与描写文的边界将在[[foundations-of-writing/exposition]]开庭**。
:::

::: warning 描写三病
一**堆砌**（形容词连环炸：“绚丽多彩的金色灿烂的朝霞”——**三个形容词等于一个都没有**；处方：每句形容词限额一个，超出的拿去换名词动词）；二**公版意象**（月亮必“如玉盘”，眼睛必“黑葡萄”——**比喻是消费品，用别人用过的比喻=贴条形码**；库存比喻先自查，再决定是致敬还是退货）；三**描写与人物脱钩**（叙述者是个赶时间的初中生，景色却像散文家附体——**眼镜要配人物**：年龄、职业、心情决定他“看见什么”；一个细节登记错了户口，整段描写就要搬去“风景明信片”货架）。
:::

::: exercise 主感改写 {level=1}
取一段你写过的写景（或直接用“暴雨前的教室”），改写两遍：A 遍主感=听觉，B 遍主感=嗅觉；每遍不超过 80 字、形容词每句限一个。
::: solution
判分：两遍**信息不重复**（同一场景交出两份不同的证据链）；主感外恰有一处和声（听觉遍里一抹气味）；动词专项过关（“砸、拍、挠”各归其声位）。两遍对比后写 30 字结论：哪种感官先找到你，为什么——**这就是你的敏感区报告**。
:::
:::

::: exercise 眼镜装配 {level=2}
同一场景“商场中庭”，分别装配三副眼镜写三段各 60 字：①等人要迟到的上班族 ②第一次进大商场的乡下老人 ③巡夜的保安。要求：三段不出现身份介绍，只靠**看见的东西**露身份。
::: solution
判分：上班族只看见钟与出口（景语=焦虑的路标）；老人的动词表暴露参照系（“厕所比家里客厅还大”“没人买东西他们为什么排队”）；保安的注意力的编制结构（消防栓、监控死角、插座）——**职业是最好的一副眼镜**。三段身份可猜中且不靠名牌者满分。
:::
:::

::: exercise 小论文：描写的通货膨胀 {level=3}
写六百至一千字：以“作文选体风景段”为标本，论“辞藻通胀”如何发生（公共比喻的超发、形容词的滥铸、情绪先行的定价管制），并对照一位名家的白描（老舍/汪曾祺/《背影》任选）说明**通货是怎么稳住的**。
::: solution
判分点：病理机制说清（库存比喻=公共铸币超发，人人用就人人不值钱）；名家例能落到动词与名词账上（“他肥胖的身子向左微倾”——零形容词何以保值）；结论允许保守派（通胀无解，只有**个人紧缩政策**：少形容词、勤观察、删三遍）——**能给出自己可执行紧缩条款者为 A**。
:::
:::

::: summary
描写车间提货：五感配平（视觉降权、一景一主感、形容词过磅）、镜头四摆（景语登记在人物名下）、笔墨三档（白描是动词解剖，工笔是限量烟花，通感是感官在情绪里串线）、以及压箱底那张许可证——**此处需要暂停**。下一章学一种最冷静的文体：说明——把话说明白，是比把话说美更难的礼貌。
:::
