---
title: "记叙"
---

记叙文是写作课的呼吸：把事情按秩序交给读者。本章不教“发生过的每件事”，教**事件的搬运术**——六要素的台账、概叙与场景的比例、把一秒钟写慢的镜头，以及一条铁律：**一事一感**。

## 六要素：台账与取舍 {#sec-liuyao}

::: definition 5W1H 的会计精神 {#def-liuyao}
时间、地点、人物、起因、经过、结果（新闻学 5W1H 的教学版）——它的身份不是填空模板，是**台账**：交稿前逐栏核账，**缺“起因”的文章读者替你乱补，缺“结果”的文章读者替你生气**。三条会计规则：①**要素可藏不可缺**（叙述可不写地点，但作者必须知道——知道而不写叫留白，不知道硬写叫穿帮）；②**经过是复式记账**（事件的经过必须记满“动作＋反应”双向账：他递伞／她没接——**单向账写出来是流水，双向账才是故事**）；③**起因值一次修改**（多数“跑题”病根在起因：起因写歪，后文全在替错误铺路——所以 45 分钟赛的构思 8 分钟里，**起因占四分钟**）。
:::

## 概叙与场景：速写与直播 {#sec-changjing}

::: definition 比例学 {#def-bili}
记叙有两种时速：**概叙**（“暑假过得很快”——一句话跑三个月，是**运输**）与**场景**（“井绳的凉气顺着指尖往上爬，西瓜在桶里撞着桶壁响”）——是**直播**）。好记叙文是运输为主、**直播关键三刻**：①矛盾摊牌的一刻 ②人物做选择的一刻 ③你感情破防的一刻——这三处**放慢成场景**（动作拆开、对话进场、感官全开），其余一律概叙赶路。新手比例恰好相反：吃住的流水各直播五百字，重场戏一句“我很感动”运输过境——**把镜头当成了纪念相机，什么都拍=什么都没有**。慢镜头技术三件：**动作分帧**（“他把钱递给我”→“他数出三张，指头在裤腿上蘸了两下，才捏着边角递过来”——**分帧即特写**）；**对话进场**（引号里的话带口癖与停顿，比“他劝了我半天”多活十倍）；**感官插队**（场景里至少一种非视觉账：声音、气味、触觉——见[[foundations-of-writing/observation-material]]五感分账）。
:::

::: example 把“他很生气”写成三十秒 {#ex-shengqi}
考场题《那一刻，我（他）明白了》常见死句：“爸爸很生气。”请用场景三件套改写为百字内片段，要求全程不出现“生气”二字；再说明改写中的分帧、对话、感官各在哪。
::: solution
示例：“爸爸没说话。他把卷子摊开，又对齐桌沿，对齐了再挪开半指。我妈从厨房探头，又把头缩回去。安静了三秒——他开口，声音平得不像他：‘这道题，教过你吗？’我以为要挨吼，结果只是很长的安静。”三件套对账：**分帧**（摊、对齐、挪半指——怒气的会计学，动作越轻压强越大）；**对话**（“声音平得不像他”+问句不给答案——**真正的怒在台词的空白处**）；**感官**（厨房探头的动静、那段安静本身的“听感”——**安静有了重量**）。加分项：妈妈缩回的头（旁观者的直觉替读者抬高了水位）。判分核心：**不写情绪名，写出情绪的行为清单**。
:::
:::

::: intuition 一事一感：短篇的消化极限 {#int-yishi}
本章的铁律：**一篇只记叙一件事、只供养一种感情**（教学传统里的“**以小见大**”，工程语言里的“**聚焦即放大**”）。为什么不是“写小事”而是“**写一件事**”：中学生的生活半径不是短板，是**分辨率的优势**——写得出“一次家长会上的四十分钟”，就具备了写“一场战役”的全部工序（《左传》的城濮之战也是从“退避三舍”一个动作起针的，见[[pre-qin-literature/zuo-zhuan]]）。反面病理：**“拼盘体”**（三段素材各三百字=三篇半截文章）与**“编年史体”**（从早到晚流水=对日记的抄袭）。改治法各一：拼盘体选最疼的那块**扩成场景**，其余砍掉做背景；编年史体**掐头去尾、从事件中段开写**（专业名 in medias res，事中起笔——**荷马也从中途讲起**）。
:::

::: history 记叙训练的教学谱系 {#sec-putong}
**1920s—1930s** 国语课“记叙文”名目确立（与说明文、议论文三分；**“记叙文”是教学文体，不是文学体裁**——它收编回忆录、游记、特写、短篇小说的公共零件）；**叶圣陶一系的教材把文章分作记述、叙述、抒情、说理诸项讲习，记叙的工序有了课本化的第一条；**1950s** 苏联体系“观察—想象—表达”三线并进，记叙训练强调**记叙顺序与人称**两知识点；**1963/1978/1986/1992/2000** 大纲迭代：从“把话说清楚”到“**有中心、有条理、有一定详略**”（这几字的提纲是记叙训练的宪法条文）；**1999 起** 中考高考“文体不限/文体自选”——记叙文第一次被允许**不穿校服**，随即出现新八股“**半命题 + 细节描写 + 结尾升华**”三段式；**2016 起** 统编教材写作分册（“学会记事”“文从字顺”独立成单元——**记叙工序重新拆开教学**）；**今天**：老师要“真情实感”，市场要“反转爽点”，两边都在争夺同一批青少年读者——本章选边：**先把事讲清，再谈讲得出彩**。
:::

::: warning 记叙四害
一**流水账**（概叙过量——治法：给全文限“场景预算”千字只许两处直播）；二**加戏癖**（“我扶着老奶奶”式拔高、结尾突然献爱心——**情感通胀比细节通缩更快毁掉信用**）；三**人称漂移**（“我妈说我傻，你猜我是不是傻”——叙述人称“我/他/你”的换岗须有岗哨：**一人称到底最安全**）；四**详略赖形容词**（“我非常非常难过”是情绪的借条——**程度副词是场景的赝品**，写“把冰棍吃完了，签子舔了三遍”即可，难过不用你说）。
:::

::: exercise 台账体检 {level=1}
给你最近一篇记叙文做六要素核账：逐栏标“明写／暗知／缺失”，并找出“单向账”（只有动作没有反应）最严重的一处，改写成双向账。
::: solution
判分：核账表完整；“暗知”栏须真能答出（问：那天几点？作者秒答=合格）；改写示例：“我摔门进屋”→“我摔门，门在框里跳了两跳才挂住；屋外的脚步声顿了一下，走了”——**反应是回声，回声标定空间大小**。
:::
:::

::: exercise 三刻直播 {level=2}
题目《那一次，我没有退缩》：先列出你的“关键三刻”（摊牌/选择/破防各一行），只为三刻写场景草稿（各≤120 字），其余一律一句概叙带过——提交这份“只有重场戏的骨架”。
::: solution
判分：三刻互不重复（摊牌=冲突现形，选择=付出代价，破防=感情改口）；每刻至少用一件慢镜工具；**“选择”一刻必须可见代价**（退缩的好处被你明写出来，不退才算选择——**没有代价的选择是摆拍**）。骨架合格，全文只是往上填运输里程。
:::
:::

::: exercise 小论文：记叙的诚信 {level=3}
写六百至一千字：老师要求“真情实感”，可真实的生活常常不够“感人”。当“真实”与“好故事”冲突时，记叙文应该站在哪边？要求：①分析“编一个更感人的真事”为何是自相矛盾；②举一个你读过的、**用工序而非情节取胜**的记叙范例；③说明“素材不够”时你允许的三种补救及其文体边界。
::: solution
判分点：①“更感人的真事”=编的——矛盾的钥匙在“真”是文体契约不是道德装饰；②范例标准不限名篇（同学作文里“奶奶的老年机每次都接”式的具体即可，能说出其工序：分帧/对话/克制）；③三种补救推荐清单：**换角度写自己**（把镜头给旁观者）、**压缩时间**（只写九十秒）、**换文体**（去写小说——**把编的放进承认编的筐里**）——并声明每种的红线。
:::
:::

::: summary
记叙四工序：**核账**（六要素：可藏不可缺，经过记双向账，起因值一次修改）；**配速**（概叙运输、场景直播，重场三刻放慢）；**慢镜三件套**（动作分帧、对话进场、感官插队——不写情绪名，写情绪的行为清单）；**守铁律**（一事一感，以小见大不是写小，是写深）。下一章进描写的调色房：定点与移步、白描与工笔、五感的分工与不通（通感）。
:::
