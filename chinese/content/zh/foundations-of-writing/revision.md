---
title: "修改"
---

本章教写作课最值钱的一课：**跟自己的宝贝稿子分手**。海明威被问到任何严肃写作的第一稿是什么，他的粗话答案被引了半个世纪——**所有严肃写作者都欠初稿的债，也都靠还债成为写作者**。

## 三层刀法 {#sec-sandao}

::: definition 结构刀、段落刀、句子刀 {#def-sandao}
**修改三层，顺序不可颠倒**（在下层动手前必须停上层——**装修不能先刷漆后砸墙**）：**①结构刀**（把稿子倒出提纲：每段一句话概括，贴一旁——**提纲会显形**：跑题段、重复段、缺席的重场戏一目了然；再问宪法三题：中心句还是那句吗？哪个段落侍奉二主？关键三刻直播了吗？）、**②段落刀**（段内**一核一事**，首句当**段旨哨兵**；长段劈短；两段黏连则加路标词；过渡检查进出门的插叙门框）、**③句子刀**（朗读定病；删三类赘词——**“进行了”“十分非常”“基本上其实”**；动词升级优先于形容词加戏；**每句一个主角，长句斩成呼吸**）。**字数配比也在此层**：初稿普遍主角欠戏、龙套加冕——**结构刀砍掉的往往是开头，救活的往往是结尾**。
:::

::: example 一个段落的三层手术 {#ex-shoushu}
病案（《拔河比赛》）：“大家都非常努力地拉着绳子，场面十分热烈，同学们都在呐喊，我也很激动，感觉团结的力量真大。绳子一会儿过去一会儿过来，最后我们赢了，明白了一个道理：团结就是力量。”请开三层手术单并写出术后段落。
::: solution
**结构刀**：全段把“重场三刻”全部漏拍（无摊牌、无选择、无破防），却抢拍了一句升华（“团结就是力量”提前结账）——手术单：**砍掉首尾两句议论，中间扩写成一次直播**。段落刀：一段侍奉五主（拉、喊、我感、绳子、道理）——拆成**一拉一喊一收尾**三小段。句子刀：“非常努力、十分热烈、很激动”三组程度副词全部**换交货清单**；“一会儿过去一会儿过来”是好观察，**留着，但要给准主语**。判分金句：**升华不是不能写，是不能替读者写**——把道理从作文里赶出去，让它从读者心里长出来。
:::
:::

::: intuition 割爱律：与宝贝分手的技术 {#int-geai}
修改的最大阻力不是眼力，是**感情**——“那段排比我很喜欢”“这个开头花了我二十分钟”。三条心理工程：**冷却法**（初稿过夜再改——**陌生的自己才是严格的编辑**；考场压缩版：先写结尾，五分钟后再回来读）；**转移账户法**（舍不得删的句子，**移入“备用素材本”**——不是删除，是调岗；素材本会证明：好句子在这里比在正文里更值钱）；**读者替身法**（请同桌只读你的**段首句**，复述文章——他复述不出的部分，就是你以为写了、实际没写的话）。名句做精神股东：曹雪芹“披阅十载，增删五次”是修改的资本化；王安石“春风又绿江南岸”（洪迈《容斋续笔》所记“绿”字数易）是动词的修改史头牌；宋代笔记传欧阳修门下作“逸马践犬”之题，佳者只寥寥数字——**简的工夫在信息不在字数**；贾岛“推敲”相遇韩愈，连声调都归修改管（唐宋诗话佳话）——**修改的手，最后会伸向声音**。
:::

::: history 修改观的教学史 {#sec-jiaoxue}
中国文论早有“修改”专章：《文心雕龙·熔裁》“**句有可削，足见其疏；字不得减，乃知其密**”（“密”的定义——**密不是短，是抽不掉字**）；史家以“简”为尚，**“事溢于句外”是上等货**；贾岛“推敲”韩愈定“敲”（唐宋诗话佳话——**连声调都归修改管**）；王安石“春风又绿江南岸”（洪迈《容斋续笔》所记，**“绿”字数易**——动词的修改史头牌）；现代教学中，**叶圣陶“写完之后至少读两遍”**成几代课堂口令；1980 年代起“**作文批改重于精批细改**”讨论、教师改红不如学生自改（**主体性转向：修改权归作者**）；过程写作法（[[foundations-of-writing/writing-process]]）把 revising/editing 分家——**改内容不是改错字**；统编教材设“**文从字顺”“语言简明**”与互评、自改活动课；**今天**：AI 校对随叫随到，人的修改第一次有了“对手戏演员”——但**判断哪句是我的声音，仍是作者亲自动手的事**。
:::

::: warning 修改四误
一**只改错别字**（把修改当校对——**动刀顺序倒着来，刷漆的墙第二天就拆**）；二**越改越长**（每轮只加不删=往行李箱里塞纪念品；**立删账：本轮删字数不得少于新增的一半**）；三**推倒重来成瘾**（第三遍又重起炉灶=前三遍的合法逃避；**修改是对着同一块石头雕**）；四**互评说客套话**（“写得很好，语句优美”=零信息；量表制互评：**必指一处病＋一个可执行的改法**，写不出改法者视同未评）。
:::

::: exercise 一张提纲显形 {level=1}
把自己最近一篇作文**倒成提纲**（每段一句概括），用三种符号标出：侍奉二主段、缺席重场戏、黏连段；然后只动**结构刀**，列出手术清单（不含任何字句修改）。
::: solution
判分：提纲句须**主谓式概括**（不是抄段首句）；三种诊断至少各给一处证据或注明“未见”；手术清单动词开头（“砍”“并”“提前”“扩”）。**清单里出现一个形容词，判该条无效**——结构刀不许碰修辞。
:::
:::

::: exercise 量表互评 {level=2}
同桌互评，按量表交表：①中心句抄录（评者概括的）＋作者原句，比对；②最有卖相的一句（引原文）；③最想让重拍的一处（指明缺哪一“刻”）；④给出一个**作者可当场执行**的改法；⑤一处存疑请作者答辩。
::: solution
判分点：①比对即诊断（两个中心句对不上=立意传送失败）；④是硬指标——**“这里要更生动”判无效**，“把‘他很着急’改成他看表的三个动作”判合格；⑤存疑须具体到句。双向签收回执：作者对每条写“改／不改＋一句理由”——**不改是合法选项，不回应才是违规**。
:::
:::

::: exercise 终稿战：修改即重写 {level=3}
选一稿，三轮修改后附三张手术单（各轮：刀层、动刀处数、删字数/增字数）＋200 字结语：三轮里哪一轮最疼，为什么**“修改即重写”这句话在哪里是修辞、在哪里是事实**。
::: solution
判分点：三轮**必须不同层**（结构/段落/句子各一轮，混层者退回）；删增统计要真实（越改越短的通常更接近真相）；结语标准：结构轮疼在砍掉喜欢但没用的部分（**情感的账**），句子轮疼在承认原来的漂亮是镀层（**自恋的账**）——能分清“**重写=推倒”与“重写=重构**”并拿自己稿子作证者，本章 A，也是本课结业证书。
:::
:::

::: summary
修改工场结账：**刀自上而下**（结构→段落→句子，装修不先刷漆）、**心要冷却**（过夜、调岗、请替身——与宝贝分手是技术不是性格）、**评要有量表**（客套话=零信息，改法才是货币）、**账要记删增**（“字不得减乃知其密”——密是抽不掉，不是短）。九章至此全线贯通：观察进仓、立法定宪、记叙铺轨、描写上色、抒情计息、说明守礼、标点除尘、修改出厂——**写作这件苦差事，从此在你手里有了流水线**。去写，去改；剩下的交给下一个题目。
:::
