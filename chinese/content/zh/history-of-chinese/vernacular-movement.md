title: "白话文运动"
---

上一章说规划改得动区分、改不动发音；本章是那句话说反的一次例外——**十几年里，中国人书写所用的语法换了一套，而说话没有变；本章要解释为什么偏偏这一格改得动**。

## 定义：它改的是哪一层 {#def-na-yi-ceng}

::: definition 书面语的语法层 {#def-yufacing}
**先把对象分清（**①语音层**（**本章几乎没动：白话文的字音沿用读书音与官话音的混合；②词汇层**（**大量旧词退出书面，一批新词与翻译词进入；但这一层随时都在变，不足以解释本章的事件；③书写系统与文体格式**（**标点、分段、直行改横行、报头与副刊——**这些看起来是化妆，实际是效率；④句法层**（**白话文采用的句子组织方式，既不是文言，也不是任何一座城的自然口语：长定语、关联词成对使用、被动式的范围扩大、以及“对于××来说”一类框架（**通说脉络：**本课的定义（**白话文运动是一次书面语句法的更换，它把“写”从一种跨时代的低带宽协议（上一章末条**），换成一种接近当时口语且可向外语开放的接口（**这个定义有一个立刻可验证的推论（**它的成功应当首先出现在依赖阅读而非依赖肌肉训练的场合：报刊、讲义、公文、合同；**而确实如此（**规划只在它不要求改变口音的地方成功——**这就是本章对上一章末尾那个问题的答案。**
:::

::: definition 三样东西 {#def-sanyang}

::: definition 反对者的论证并不弱 {#def-fandui}
**通说脉络**（**反对的一方包括以传统古文写作闻名的作家与一批留有海外经历的学者，其论点大意为：文言承载精微与节制，白话不足以表达高深的思辨；文学的标准应由典范决定而非由多数人决定；此外还有对文化断裂的忧虑（**本课先做一件不讨好的事（**这些论点中有相当一部分是经验命题，而不是怀旧：**例如“抽象论述需要句法的节制与短句”，这在若干文体里可以被检验（**然后做第二件（**它们失败的地方不在论证，在位置：**其一，他们的主张需要以行政或学校为杠杆，而他们手中没有；其二，他们的刊物仍在文言圈子里流通，其读者正是已经不需要被说服的人；其三，通说脉络指出若干批评白话的报刊自己也办白话副刊——**这最后一句最锋利：**一个阵营开始用对方的格式赚钱时，格式之争已经有了结果（**本课的方法教训（**读任何一场论战，不要只比较两边的论据，要把两边的发行量、课程表与招聘条件列在旁边；**这是本课程第 3 门课与第 6 门课反复要求的“先问谁在签字”的历史学版本（**论据的胜负是事后叙述，位置的胜负是当时的新闻。**
:::

::: definition 欧化：谁给汉语换了句法 {#def-ouhua}
**通说脉络**（**新书面语的形成有两条外来渠道：翻译，以及改革派对“直译式句法”的主动提倡——**当时有人主张以贴近外语词序的写法来增加汉语的精密性（**本课把这件事讲成一次有意的语言工程，并给它三条后果（**①它确实增加了可用的句法工具**（**多层定语、显式的逻辑连接、被动与处置范围扩大；**学术汉语至今靠这套工具（②代价是口语距离拉大**（**一句二十个定语的长句在白话口语里不自然，于是在新书面语内部又形成新的“写与说的裂缝”；**本章的循环感在此出现：**白话文以“我手写我口”为号召，二十年后它自己的书面语也被批评为不说人话——**这个循环在每一代改革后都会重演，值得你记一辈子（③若干项目是纯粹的形式模仿**（**通说脉络：若干当时推广的用法（包括某一人称代词的新字形、某些复数与类别标记）出于“语言应当有对称的形式”这一类理据，而这一理据是逻辑美学而不是语言需要（**本课的评价（**“她”字的推广是一个极有趣的案例：**它在口语里毫无区别，纯粹是书写层的区分；**这说明文字可以强加一种口头不存在的对立，而一旦进入印刷它就变得自然（**第 2 门课“汉字改写分类学”在此得到二十世纪最漂亮的一例：**书写不是记录语言，它是给语言增加区别。**
:::

::: definition 未完成的部分 {#def-weiwancheng}
**这场运动没有做的三件事，以及它们后来去了哪里（**①它没有规定标准音**（**那是国语运动的另一条线，下一章讲；**两条线在十九一〇至二十年代常被同一批人提倡，却是两件不同的技术工作（②它没有解决方言区的书写**（**白话文以官话为基础方言，对非官话区的人而言仍是一门需要在学校学的书面语（**本课把今天的“作文腔”读作这一未完成任务的残留：**一种既不接近当地口语也不接近自然口语的中间书面语（③它没有建立一套新的正字法**（**字形的系统改革要到四十年代以后；异体字与简化问题被顺延（**本课对第③条的读法（**一次变革通常只能改一层；**试图同时改语音、语法、文字的改革会在每一层都失败（**这就是上一章的“想回滚语音”的失败与本章的“只改句法”的成功的比较：**成功者窄。**这一句我建议你抄下来，将来评价任何一次改革方案都用得上。**
:::

::: example 两段话，五处差异 {#ex-liangduan}
下面是本课自造的两段同义文字。**甲：此事本末，具如前议，奈何中变。**乙：关于这件事的经过情形，我们先前已经讨论过了，现在为什么要改变主意呢**）。请指出：**①乙段中哪些虚词与格式在甲段没有对应；②哪些是口语固有、哪些更接近翻译体；③你用什么标准区分这两者**。

::: solution
**①新增的框架**（**“关于……的”介引框架、“先前已经……过”的时貌组合、“为什么……呢”的疑问框架（**甲段用一个副词与一个疑问词就把意思带过，乙段要求把每一项关系显式化（②口语固有 vs 翻译体**（**“经过情形”“讨论过了”“改变主意”这类动宾与时貌组合可在近代白话里找到先例，属于口语固有层；**而“关于这件事的经过情形，我们先前已经讨论过了”这样长的前置框架、以及一个话题上挂多层定语，在自然口语里通常会被拆成两句（**通说脉络：**换句话说，乙段比任何人的自然口语更“完整”，这正是新书面语的特征（③区分标准**（**三条：**其一，历时——**该格式在近代白话里是否已有**）；其二，分布——**它是否只在书面出现（口语语料里绝迹）；**这是最硬的一条，因为它可统计；其三，可拆分性——**自然口语是否倾向于把它拆成两个小句（**通说脉络：这三条也正是今天判断“网络新用法是否已进入语法”的做法（**判分：**写出第二条“分布”且能说出用什么样的口语语料去查者，为 A**——**这一处本课要看的不是你知道多少事实，而是你能否把一场一百年的争论改写成一项可执行的检验（**这就是把文学史变成社会科学的那一步（**也是上一章那条“有方向才算证据”的白话版。**

**一个阅读反应**（**今天的人读一九二〇年代的文章，会觉得它半文半白、用词生硬、感叹号太多（**本课的三层解释（**①这是过渡语体的真实特征**（**旧格式正在退出而新格式尚未定型，于是同一篇文章里并存三层（②后人的“成熟”标准是由胜利者的下一阶段回望的**（**他们读到的是留下来的最好的那几篇；**而当时的平均水平远比选本低（**第 2 门课“精选即删改”在此变成文体史的一条（③每一个时代的成熟样式都曾是一次失败的试验**（**我们觉得文言“庄重”是因为它已不再被用来写急稿与笑话；**我们觉得白话“自然”只是因为它赢了（**本课把这写成一条判断标准（**当你觉得一种新文体幼稚时，先问：我在拿它的选本与它的对手的全集比吗**）？**这一问在本课程里已经出现过三次：**在文学史、在语言现状与在应用文里；**今天它是本章的收尾，也是下一章的问题：**一场成功的变革之后，谁来规定它算标准。**

::: exercise 小论文：窄的成功 {level=3}
写六百至一千字，评“**历史上成功的语言改革都很窄：只动一层，且这一层必须能通过阅读而非肌肉训练获得。想同时改语音、文字与语法的方案，通常在三层上同时失败。可这里有一个道德问题：窄的改革之所以容易，正因为它不触碰说话人的身份——它只改文件。于是语言改革的可行域与它的重要性成反比：越是不重要的层次越好改，越是关系到一个人能否被听懂的部分越贵**。须调用：**改的是哪一层**、**三样东西**、**论战的两造与位置**、**欧化及其代价**、**未完成的三件事**、**过渡文体的判断法**至少六项；并裁决：**如果你是改革者，你会选择“窄而成功”还是“宽而失败”（必须给出一个可被后人核对的成败判准**。

::: summary
白话文运动：层（**句法，不是口音**）、条件（**教材、印刷与新人**）、论战（**位置胜过论据**）、欧化（**增加了工具，也拉开了新的写说裂缝**）、遗留（**标准音、方言区书写与新正字法被顺延**）、读史法（**别拿选本比全集**）。下一章也是末章：现代汉语共同语的确立——把标准做成一张音表、一门课与一场考试。

:::
