上一章讲格式怎样长出来；本章讲一种口语怎样铺到半个中国——**没有一道命令颁布过官话，没有一部法典定义过它，而它成了清末每个人都需要的那种话；本章把它当作一次无主体规划的长篇实验来读**。

## 定义：什么叫“官话的形成” {#def-xingcheng}

::: definition 三个不同的问题 {#def-sanwen}
**本章先把一团争论拆成三个问句（**①北方话的那些结构变化何时完成**（**这是语音史问题；②一种跨地域的口语通用语何时出现、被谁使用**（**这是社会语言史问题；③它何时被记录、被规定、被制成标准**（**这是制度化问题（**通说脉络**（**三者在史料里各有不同的证据，而著作常把它们混答（**本课的分工（**第一个问题给出结构，第二个给出分布，第三个给出名分；**而本章的论点是：**在汉语史上，第三个问题被回答得最晚，这正是它能被广泛接受的原因——**一种还没有名分的通用语不冒犯任何地方话，因为它不是任何地方的方言（**这一句是本课上半场的全部要害，后面三节都在为它举证。**
:::

::: definition 一条时间线，四个锚点 {#def-sigeman}
**通说脉络**（**北方话的关键变化按材料可排出如下序列（**①唐至宋**（**全浊声母清化的最早迹象被从若干类间接材料中推定；**入声尚存（②十三世纪**（**一部为北曲编的韵书显示平声依清浊分两类、入声字被派入其余三声；同时一种为新帝国发明的文字留下的碑刻与词表，记录了当时的北方读书与官话层（③十四至十七世纪**（**闭口鼻音韵尾并入前鼻音韵尾；一组塞音韵尾在北方消失；**官话一词在文献里逐渐常见（④十七至十九世纪**（**若干北方特征继续扩散；同时来华者以拉丁字母为汉语记音，留下官话与读书音的两套拼法（**通说脉络（**本课对这条线的两点批评（**其一，每一个锚点都是“某类材料第一次显示”，不是变化完成的时间（上一章可见度律；其二，四个锚点的密度极不均匀：**十三世纪因为有曲韵书与八思巴字而密，十至十二世纪因缺乏近口语材料而稀；**于是我们对官话形成的“了解”，其形状其实是文献保存的形状（**这一句写下来很容易，用它读文献很难——**本章要求你在后面每一节都试一次。**
:::

::: definition 一部想回滚语言的韵书 {#def-hongwu}
**通说脉络**（**十四世纪官修的一部韵书试图以更接近旧读书系统的分韵为准，纠正“从俗”的读音；它在此后数百年里被用于科举与文风，却始终未能成为实际口语的描述（**本课把这件事称作**中国语言史上第一次有据可查的回滚尝试**（**它失败在哪（**①它没有改变任何人的利害结构**（**应举者要的是合格的格式与押韵依据，不是把口音换掉；韵书满足了前者，于是它作为一种格式工具活着，而它的语音主张没人执行（②它没有可用的教师与考试**（**没有发音考试、没有师资培训、没有方言地区的额外课时（**第 9 章推普之所以成功，恰是因为二十世纪的这三样都在（③它的目标是文字与押韵的分类，而分类可以维持；**分类维持的是区分，不是音值（**本课由此得到一条政策力学（**规划能改变“必须区分什么”，几乎不能改变“怎么发音”；**前者是一张表，后者是几万小时的肌肉训练（**这句话适用于本章，也适用于上一章的量词、下一章的异读，以及你今天看到的任何一次“规范用词”运动（**它能改变你在正式文件里写哪个词，改变不了你在家里说哪个词。**
:::

::: definition 一次更聪明的尝试 {#def-zhengyin}
**通说脉络**（**十八世纪前期，因官员口音影响公务，朝廷曾下令在若干南方省份推行官话训练，地方上出现过以正音为目的的书院与读本一类设施（**本课认为这次尝试比前一次更值得研究，因为它做对了三件事（**①它对准了一个具体的、可核的场合**（**不是“让说话更雅”，而是“上堂问案要让两边听懂”（②它用了当地识字的人做教师**（**读本是为方言使用者编的，逐字对照（**这比抽象命令便宜得多（③它不试图废除方言**（**它教的是再加一门话，而不是换掉一门话（**第 8 章“相加而非相减”在此有一则十八世纪的先例（**那么它为什么仍然没有留下长期效果**）？**本课给出三条结构原因（**其一，它不改变考试的内容：只要考试不考口语，学时就会被别的科目借走；其二，它的受益者不是学习者而是办公者；**没有受益者自付成本的规划，只能维持到预算结束；其三，它所在的时代没有可复制的标准音载体——**没有录音、没有广播，因而每一间正音书院的读音都取决于当地那位教师（**这是本章最重要的一句：**在留声机之前，任何标准音政策的实际覆盖率都等于师资的覆盖率；**而师资从来是财政项目，不是语言项目。**
:::

::: definition 一种话没有名字的时候 {#def-wuming}
**通说脉络**（**明清文献里的“官话”是一个通名，指跨地域办事用的口语，并不特指某一处口音；各地说的官话彼此有别，也没有一个人说“标准官话”（**本课的三个观察（**①无名的标准是有效率的**（**正因为它不声明自己是某城的口音，一个说南昌官话的人与一个说南京官话的人都不觉得自己在让步；**名分是一种排他性，而排他性会招来抵抗（**第 1 章“分类即主权”在此给出它的反面：**在主权未定时，流通更快（②它的载体不是学校而是行业**（**衙门、镖行、漕运、盐商、戏班、寺庙的挂单网络与科举的座师关系；**这些是十九世纪中国真正的通讯系统，而它们都说官话（**本课称此为“行业的语言政策”：**没有一份文件，却有工资与生意（③它被记录时已开始被规定**（**十九世纪中叶以后，外国人为学汉语编的词典与教材多以北京官话为纲；**而中国自己的第一部官方国音方案要到二十世纪初才出现（**于是本章的核心悖论（**官话先被全世界记录，后被本国命名；**这一时间差解释了下一章为什么白话文运动与国语运动几乎同时发生而彼此不完全合拍——**它们处理的其实是同一件事的两个面：**书面语用什么话写，与口头共同语以什么音为标准（**这两个问题在十九世纪的中国还没有被分开提出。**
:::

::: definition 官话内部的层次 {#def-cengci}
**通说脉络**（**官话并不是一个均质系统，它有读书音层与口语音层、有官方场合与市集场合的差异（**三条可操作的读法（**①对音材料要分层看**（**十六至十七世纪来华者的拼写常同时记录“文言读音”和“官话口语”，而拼法的差异恰好暴露两套系统的存在（**通说脉络：**这类材料是本领域最被低估的一类，因为编写者往往不知道自己在做社会语言学（②文白差异在官话里也存在，只是层次比闽语浅**（**若干字有两读，一读随旧韵书系统、一读随今音；**方言课那一章的方法在此完全适用，只需把“时代层次”换成“语域层次”（③“某地官话”是一种混合体，而不是某地方言的别称**（**在南方城市里，官话常表现为本地音系加上官话词汇与句式的临时组合；**这类变体在旧文献中常被称为“蓝青官话”一类（**通说脉络：**本课看重它：**它是语言接触的现场证据，也是本章与第 8 章的接缝：**一种通用语在传播时不是被复制，而是被本地重新拼装；**于是十九世纪的中国有许多种官话，正如今天有许多种普通话——**这句话是本章要留给你的最后一件工具，它在下一章会变成一场运动。**
:::

::: example 四种材料，一个问题 {#ex-sizhong}
问题：古全浊声母的清化在某一地某一时是否已经完成。四种材料：**甲：一部保守的分韵韵书仍把清浊分列；乙：一部韵图把某些位置标注为“浊”；丙：一份同时代人的书信与契约中，浊声母字与清声母字互相假借；丁：现代该地话已完全清化。**请排证据强度，说明每种材料会怎样骗人，并设计一条能区分“已清化”与“正在清化”的检验。

::: solution
**强度排序**（**丁最可靠但只能证明下限；丙最有意思，因为它是行为证据；甲与乙都是分类系统的陈述，不能直接证明音值（上方可见度律（**各会怎么骗人**（**甲：韵书照抄旧分类可以抄三百年（**它证明的是有人还在按旧类写诗**）；乙：韵图的“浊”可能是术语的惯性；丙：假借可能沿袭书写习惯、可能来自仿古、也可能只是错字；丁：现代状态无法告诉你变化何时完成（③可区分的检验**（**其一，看丙类材料里的假借是否单向：**若只有浊→清的借用而无逆向，说明说话人已不觉得两组有区别；若双向都有，可能是异体字风尚而不是合并（**这一条最实用，也最常被跳过；**其二，找“条件性”证据：**若干点会留下部分字仍读浊音的残例，若清化是音变应有条件残留，若只是书写风尚则残留是随机的；其三，用外部记录交叉验证：**同时代域外对音若已无浊声母记法，则丙的解释被加强（**通说脉络：这正是本领域处理此类问题的实际做法（**判分（**能把“单向性”这一条写出来者为 A**——**它是历史语言学里少数真正可靠的推理之一：**行为证据要成为证据，必须显示方向；**这一句完全适用于你在文学史、社会史与任何一次“某风气何时兴起”的论证（**本章由此给全课一条统一的证据观：**孤立的相似是巧合，有方向的相似才是历史。**
:::
:::

::: intuition 没有词典的语言扩张最快 {#int-wucidian}
**一个可迁移的观察**（**官话扩张的四百年里，没有一部规定它怎么读的官方字典；第一部这样的字典是二十世纪的产物（**三条推论（**①不确定性是润滑剂**（**没有权威判定，每个地区都能把自己接近官话的那部分算作官话；**扩张因此不需要任何人说“我要改”（**这是所有标准扩散的隐藏机制，从度量衡到文件命名规范都如此（②词典是争论的产物而不是前提**（**一部读音字典通常在两种读法都已流行、且必须要有人裁定时才编；**所以词典的第一页应写“因诉讼而作”（**本课给这一句的用武之地：任何一次公司命名规范，都是先有冲突后有手册（③于是本章的结论是反直觉的一句（**语言规划的大部分工作在语言已经变完之后；**它的真正功能不是改变语言，而是分配名分——**而名分会改变下一次变化的成本（**下一章会给出一个罕见的例外：**一次书面语的变革在十几年内完成，因为它改变了考试、教材与报刊，也就是改变了受益者。**
:::

**八至十四世纪**（**北方话若干关键变化在间接材料中渐显；**都城迁移与运河使汴、京诸地口音先后居于中心（**通说脉络（②**十三世纪**（**新帝国的文字与碑刻记录了一种带北方口语特征的官话层；**同时行政网络把北方词汇带入全国文书（**通说脉络：**本课强调这一条：**异族统治没有消灭通用语，反而加速它，因为它需要一个与各方言区都能办事的低配语言（③**十四世纪**（**一部官方韵书的回滚尝试；同时南方城市形成各自的官话变体（**通说脉络（④**十七至十八世纪**（**来华者的字母记音留下文言音与官话音两套；清中期出现正音读本与书院一类设施（**通说脉络（⑤**十九世纪**（**词典、教科书与通商口岸的商务口语使官话被域外系统记录；太平天国与人口变动再改一次内陆方言版图（**通说脉络（⑥**十九世纪末至二十世纪**（**留声机与广播出现；切音字运动、读音统一会与国语教科书相继而来（**通说脉络：**本章的最后一条因果（**标准音的可能性取决于复制声音的技术；**在此之前，所谓标准只是拼写、韵书与教师的口音（**技术不是传播的渠道，它是标准的物质条件（**这句话是本章与下一章的接缝。**

::: exercise 小论文：规划的边界 {level=3}
写六百至一千字，评“**语言规划的成功率与它想改变的对象成反比：改文字最快，改词汇其次，改读音较难，改口语的语法几乎无望，而改“谁在什么场合必须说什么话”最有效也最昂贵。这个梯度不是语言学问题，是成本问题：文字只需重新印刷，读音要重新训练几万小时。所有失败的语言政策都错估了自己所在的那一格**。须调用：**三个问题的拆分**、**四个锚点与可见度**、**回滚失败三因**、**正音尝试做对的三件事**、**无名则无抵抗**、**行业的语言政策**至少六项；并裁决：**把这一梯度搬到其他制度变迁（货币、度量、编程规范、术语），说出它在哪里失效以及为什么**。

判分点：六项机制；裁决（**须指出一处梯度失效的机制：**合格候选：①**度量衡**（**它比读音改得更成功，不是因为单位更易学，而是因为它有市场准入的强制与仪器制造者的利益一致；**这说明梯度真正的变量不是心理成本而是“是否有第三方替你执行”，本课接受这个修正——**它比原始梯度理论更好（**这是全章最高分的答案方向（②**货币**（**改币制可以在一夜之间完成而改读音不能，因为它靠记账系统与合同强制执行；**同一机制解释了为什么“共同语”在商业场合比在家庭场合容易推广；③失效处（**编程规范恰恰相反：技术上极易改，实际改起来极慢，因为它的强制手段只有社会压力；**这说明梯度里还漏了一维：**改动的收益是否集中于早期采纳者（**判卷看到这一类结构分析即给高分，看它是否在念教条即扣分**）；结论若能写“**所以我们评价任何一项语言规划的正确问法不是它好不好，而是它把成本放在哪：印一本书、训练一批教师、还是改变一批岗位的录用条件；成本越靠后越有效，也越容易在选举、预算与人手上失败——这就是官话的故事，也是任何共同语的故事**”，即 A。
