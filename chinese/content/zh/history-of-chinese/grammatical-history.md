上一章的词至少能一条条列出来；本章要追的是格式——**虚词、语序与句式，它们不留韵脚，不肯进字典，而且每次变化都会在书面语里留下旧层，于是汉语的语法史读起来像一座不断加盖而从不拆旧屋的城**。

## 定义：这门学问的两条纪律 {#def-jilv}

::: definition 可断代的语料与抄本的断代 {#def-duandai}
**第一条纪律**（**通说脉络：汉语历史语法研究的一条基本规则是，每一条例句必须能够断代，不能用“古书里见过”当作证据（**本课补上常被忽略的第二层（**断代分两件事：**作品写作的年代与抄本、刊本的年代；**一部汉代成书的书若只有宋刻本，其句法可能被抄手规范化（**第 4 章“版本即意识形态”在此变成一项技术限制（**三条推论（**①最早的书证只给出上限**（**格式出现于文字之前早已在说；②最晚的书证给出下限；**而一个格式从出现到常规之间常有二三百年，这段时间里它可能是文体时尚而不是口语；③频率比出现更重要**（**一个孤例是作家个人趣味，一个在百篇文献里逐年增加的格式才是变化（**通说脉络：语法化研究普遍认为频率上升与结构固化相关（**本课的中性表述：**没有频率的语法史只是例字汇编；**这正是上一章末尾那条“词典的引证原则天然偏向最早”的语法版（**同一枚硬币的两面：词汇史可以靠孤例证明存在，语法史不行——**因为语法是可产的，而可产性只能由分布显示。**
:::

::: definition 重新分析需要一处歧义 {#def-chongfen}
**机制**（**第 9 门课那条“重新分析改图纸”在此是唯一可用的因果解释；**而它有一个苛刻的前提：**重新分析只能发生在一种结构两种读法都成立的句子上（**本课把这句话称为本章的操作定义：**要证明一次语法化，就要找到（或推断出）那个两可读的句子（**通说脉络：术语上这叫过渡阶段，即同一形式同时具新旧两种用法的时期（**于是产生一个方法论的悖论：**两可的句子在形式上无法确证，因为我们没有母语者可问；**处理办法有三种（**①找分布：新旧两种环境各占多少；②找后续限制：**若一种读法后来发展出新的搭配限制（如只能接某类动词**），则两可已解除；③找并行：**同一时期是否有同类格式也在改（类比的力量在这里可测（**本课的判决（**三种办法都不如一次录音可靠，而三者相加常常足以让人信服；**这是人文学里“多重弱证据构成一个强结论”的标准情形（**上一章“多路证据指同一方向”的语法版——**请记住这个组合：**单条弱证据加多条弱证据，不等于中等强度；它们只有在指向同一分布时才共同增强。**
:::

::: definition 体貌：一套新机器 {#def-timao}
**通说脉络**（**上古没有后世那样的体貌标记系统；**若干实义动词在中古语法化为专职标记（**①“完毕”义的动词变为完成标记；②“附着”义的动词变为持续标记；③“经过”义的动词变为经历标记（**本课把第①条讲成一个完整案例，因为它是本章最好的标本（**它的每一步都可在文献里数：**先是连动式里的实义动词，再是紧附动词之后的补语，再是词尾（**通说脉络：**关键的中间态是那个“动词—补语—宾语”三种切法都通的句子（**一旦它被重新分析为“动词＋词尾＋宾语”，新的体貌系统就出现了（**注意这里发生的规模：**一次重新分析创造了汉语的一种新时制资源，此后所有动词都能带它；**这就是语法化为什么被称作“语言的发明机制”：**它不造新词，它造新格式（**而它与上一章的双音化恰好互补：**双音化增加词的长度，语法化增加句子的层次（**汉语的两千年形态变化，就这两句话。
:::

::: definition 处置、被动与判断词 {#def-chuzhi}
**三条线的共同形状**（**①处置式来自“拿、持”一类动词的连动结构；②被动式来自“遭受”义动词；③判断词来自一个复指性的指示代词（**通说脉络：三条都被二十世纪学者系统讨论过，其中判断词的来源与时代是二十世纪语法史最著名的论题之一（**本课要讲的不是结论而是那个形状（**三条线的起点都是实词，都在连动或复指结构里处于次要位置，都在重新分析后成为句子的骨架成分（**这一形状给了一个可迁移的识别法：**要预测一种语言下一步会长出什么虚词，去看它现在哪些实词处在次要动词的位置上（**这句话在方言调查中可直接用：**若干方言的处所词、给予动词与“在”类介词正处在中间态（**通说脉络：方言语法研究的大量案例属于此类（**本课称此为“活着的语法化”，并把它列为本章最值钱的一项应用：**历史不在书里，它在你的邻居嘴边正在发生（**而这也解释了为什么方言语法与语法史是同一门课的两半（**第 8 章与本门课在此合并（**判断词那条还额外给一课：**“是”作为判断词在上古文言里罕用，而它在后世口语层是唯一的判断式——**一次彻底的语法化在书面语里几乎看不见，因为它取代的正是文言自己。
:::

::: definition 量词：一次迟到的语法化 {#def-liangci}
**通说脉络**（**早期文献里数词可直接修饰名词，后世则要求一个中间成分；**这一变化被广泛视为汉语类型上的一件大事（**本课讲三件事（**①时间很长**（**从零星到强制经历数百年，而强制完成的证据恰恰是“不写就成病句”的语感出现，这最难断代（②它是类型的改变**（**量词系统使汉语成为一种“分类语言”：**每一类名词被要求归入一个类；**第 6 门课语义里的“分类即系统”在此有了语法实现（③它与认知有关而不只是装饰**（**通说脉络：有研究讨论量词与“可别度／形状凸显”的关系；**本课只取其可检验的一半：**若量词只是装饰，它不会在几百年里把名词按形状与功能重新分拣一遍（**这一课的全章总结在此：**语法史最动人的不是格式的更替，而是每一次更替都悄悄换掉了说话人不得不做出的区分——**文言里你可以不问“几匹马”的“匹”，一旦量词强制，你就必须替每个名词归类（**第 8 章那句“语法是一种强制”，在本章有了它的汉语史证明。
:::

::: example 排一个序列 {#ex-xulie}
下面是四种抽象句式（**本课自造，非引文**）：**甲：他做完这件事，然后走了；乙：他做了这件事；丙：他走了；丁：天黑了。**请排列它们出现的先后顺序，说明每一步重新分析发生在哪里，以及你会用哪些分布证据支持这个顺序。

::: solution
**顺序**（**甲→乙→丙→丁**（**通说脉络**（**甲里“完毕”义是实义的，且整个结构是两个动作的时序排列；乙里它紧附于前一个动词，句子被重新分析为“动＋标记＋宾”；丙里它出现在句末而没有宾语可容身，于是被再次重新分析为整个命题的完整或新情况标记；丁里它已能附着于形容词，说明限制条件消失——**能产性达到最大（**每一步的重新分析处**（**甲与乙之间：**“动＋了＋宾”可切为“动＋了”后接宾，也可切为“动了”后接宾，这就是两可句；乙与丙之间：**了后无宾时的归属；**两可在此（③分布证据**（**其一，统计“了”后接宾语的比例随年代的变化；②统计其后能否再加别的成分（**能否再带结果补语、否定词的位置**）；③统计能否用于形容词与非动作动词——**最后这一项是判“完全语法化”的最硬一条，因为它要求该形式已脱离原动词的选择限制（**本课的评分点（**你若在丁处补一句“形容词用例出现之前，该形式仍可能只是补语”，即为满分：**这是本章唯一的进阶要求：**语法化的证明不是找到用例，而是证明它已不受原词的搭配限制（**这一句可以搬到任何“某观念起源于某年”的争论里：**要证明一个观念存在，要证明的不是它被说出，而是它已可被自由使用。**
:::

::: intuition 文言是一台延时装置 {#int-yanshi}
**一个本章反复遇到的现象**（**口语层在变，书面层不变，于是同一时代的文献里共存着相隔数百年的两套格式（**三条后果（**①停滞是错觉**（**汉语语法“两千年不变”这一说法之所以顽固，是因为它只读了文言（**这一条同时是本章给全部比较文明论的答复：**先看它读过什么，再看它相信什么（②两层互相借用**（**口语层吸收文言的庄重格式，文言偶尔吸收口语的虚词；**这类借用的方向与场合可统计，构成语体史（③因此任何“某代语法”的说法都必须指明层**（**唐代文言、唐代接近口语的记录、以及宋代的刊本，是三个对象（**上一章那句“换主语”在此最后一次出现：**“在唐代接近口语的文献里，此格式如何分布”——**这一句法可以救你一半的论文（**本课把这台“延时装置”作为全章最后的一个比喻：**文言不是汉语的过去，它是汉语为了跨时代交流而维持的一个低带宽协议；**协议会拖慢变化，但不会阻止——**它只是把变化的时间常数拉长到没人注意。**
:::

::: history 从文通到语料库 {#sec-wentong}
