前两章的语言分别住在韵脚与韵书里；本章的语言第一次住在舞台上——**当戏班需要让人听懂宾白、当译官需要让人能买货，口语就不得不被写下来；于是汉语史从“押韵的字”换成了“说话的句子”，而噪音也一起进来了**。

## 定义：材料的一次换代 {#def-cailiao}

::: definition 五类不得不写口语的文本 {#def-wulei}
**通说脉络**（**十三世纪以后，汉语史的主要证据换了一批（**①曲的宾白与戏文（**为演出而写，不能全用文言；②话本与说唱文本；③禅录与语录一类的近口语记录；④给外国人用的会话课本与词表；⑤元代特殊公文，即按蒙古语句法直译的汉文文书（**本课把第五类讲细一点，因为它最出人意料（**通说脉络：元代部分诏令文书采用贴近口语、且语序受蒙古语影响的直译体式，后世称“硬译公文体”一类（**它的史料价值是双重的（**其一，它是当时口语语法的意外快照：**没有人会故意用文言写“每”字作复数、把状语放在动词之后；**只有不得不照口语硬译的人才会；其二，它是接触导致句法变化的少数有明确起点的案例之一（**第 8 章接触三本账在此有一个可断代的标本（**一句警告随之而来：**这类文本是翻译体，不能直接当自然口语；**用它论证句法时必须区分“元代汉语本来如此”与“文书吏照原文硬搬”——**这是本章最常被写坏的一段，也是你能靠细心胜出的一段。**
:::

::: definition 清化、派调与 -m 尾 {#def-sanbian}
**通说脉络**（**北方话在近代完成三条大变化（**①全浊声母清化，并按声调条件分为送气与不送气两路（**方言课那条“完成度”在此变成时间轴（②入声消失，其字被派入其他声调（**《中原音韵》一类的曲韵书是这一状态的账本；而它按曲律需要标注“入派三声”，说明实际已无独立读法（**通说脉络（③闭口鼻音韵尾并入前鼻音韵尾（**通说脉络：北方话在元明之际完成；而《中原音韵》里是否还保留一分，学界有不同看法（**本课把第③条当作一条教学样板：**一个音变的“完成时间”取决于你信哪份材料：**韵书可能保守、韵图可能理想化、对音可能受对方文字限制、而现代方言只提供结果（**于是“某某变化完成于某世纪”这类句子，正确的读法是：**这是某一份材料的分类状态第一次出现在记载里的时间（**上一章那句“可见度”在本章获得了第三种用法：**前两章管有没有材料，本章管材料对齐不准。**
:::

::: definition 尖团与一条悬案 {#def-xuana}
**通说脉络**（**另一条常被引用的变化是尖团合流：一组舌尖前声母在细音前并入舌面组；一般认为这在北方话里完成较晚（**为什么本章要花一节讲一条晚近的变化（**①它演示“条件音变”的形状**（**同一声母在不同韵母前走上不同路，因此分合不是音与音的事，是音与环境的事；②它是社会变异的活例**（**合流与不合流在若干方言与老派读法里同时存在，因而可以按年龄、地区与文体分层观察；③它有一桩史料悬案**（**若干韵书与等韵著作对这两组的处理不一致，而分歧恰好落在“谁在读书、谁在说话”的界面上（**通说脉络（**本课的方法结论（**一条音变之所以能被精确断代，从来不是因为它发生得突然，而是因为有人在那一年恰好把它写进了一本为某种用途编的书；**这句话听起来像取消了一切断代，其实它是唯一的诚实表述；**它同时给出了改进方向：**要找多种互相独立的记录，然后承认中间那段没有记载的时间里事情已经做完了——**第 9 章“规律管结局、扩散管过程”在此第一次兑现。**
:::

::: definition 六件新格式 {#def-liujian}
**通说脉络**（**近代汉语的语法面貌与文言差别巨大，而差别集中在虚词与格式（**①体貌系统成形**（**完成、持续、经历与可能各有专职标记；**它们都是更早的实词虚化来的（②动补结构大发展**（**结果补语与可能补语成为汉语的一种核心构造；**通说脉络：这是汉语史语法研究里争论最持久的一项，因为它关系到汉语如何组织“动作与结果”（③处置式与被动式分工**（**通说脉络：处置标记在唐宋之际成熟、被动标记在近代口语层扩大（④复数标记、结构助词与语气词成套更替**（**旧的一套在文言里保留，新的一套在宾白里出现，于是同一时代有两套并存（⑤差比句式换用新的比较标记（**通说脉络（⑥疑问与否定形式的口语化**（**新的疑问语气词与否定词进入文本；**它们的来源历来有若干家说法（**本课对第⑥条特别处理（**语气词的来源研究（**通说脉络：二十世纪有学者系统讨论过若干语气词来自更早的否定词或语末成分**）？**是本课程所谓“语法化”的最好教材：**因为它显示的是抽象化＋语音弱化＋主观化三件事同时发生（**而它同时是本章最不该背的一节：**结论会改，方法不会改——**你要记住的是那三件同时发生的事，以及“来源推测的强度取决于文献里语气词出现的时间还是它实际被使用的时间”这一问句（**答案是后者，而后者永远早于前者。**
:::

::: definition 一部课本的面板数据 {#def-mianban}
**一个罕见的情形**（**通说脉络：近代有一种给朝鲜译官用的汉语会话课本，历代多次修订、重抄并附谚文注音；现存若干彼此有差异的版本（**本课称其为“语言史上的面板数据”**（**同一份材料在数百年间被同一批人反复更新，版本差异因此近似于按时间序列抽样（**它使三类以前无法问的问题变得可问（**①哪些格式在这一时期由新兴变常规**（**看同一处对话在各版本里的措辞变化；②哪些是文体保守**（**若某格式在早期本已出现而后又被改回文言说法，那是编者的规范化，不是口语的倒退（③版本差异中有多少是抄手方言**（**修订者的母语会影响替换哪些词（**通说脉络：**这一类研究在本课看来是本领域最扎实的一种：**它不构拟、不假设、不借用外部证据，只做版本对勘；**而它的结论支撑着所有大胆的构拟（**这就是本章的价值观：**在材料能钉死的地方钉死，其余地方明确标注。**
:::

::: example 六个句子，四个问题 {#ex-liuju}
下面是本课自造的仿古白话句子（**不是引文**）：**甲：他把门掩上；乙：我正吃着饭；丙：比旧年贵些；丁：每人都有一份；戊：你见我不；己：他打碎了碗。**请回答：**①哪些格式在上古文言里不成立或须换式；②每条的新格式是什么；③哪些来自更早的实词虚化；④若这六句出现在一份元代公文的硬译体里，你还多问一句什么。

::: solution
**①与文言不合者**（**甲（**文言处置式另有格式，且不用后来的处置标记**）、乙（**持续体标记不用此式**）、丙（**差比句在文言里用另一套介引格式**）、丁（**复数标记不用此形**）、戊（**反复问在此式里与文言的“未/无”问式不同源**）；**己在文言里可用动宾式表达，但结果补语的组合能力远不及后世（②新格式即本章六件（**处置、持续、差比、复数、反复问、动补（③来自实词虚化者至少三条**（**处置标记来自“拿、持”一类动词，被动标记来自“遭受”义动词，完成与持续标记来自动词“终了”“附着”义（**通说脉络：**这就是语法化：语义虚化、语音弱化、句法位置固定三件事同向发生（④元代硬译体要多问的那一句（**这个格式是汉语口语的变化，还是译文书面对上层语言的复制**）？**判别办法有三：**看它是否同时出现在非翻译类文本（话本、语录**）；看它是否有汉语内部的演变线索；看后来的白话是否延续它（**若三问皆否，则它是一次文体的短期借入，没有进入口语（**这一条是本章对“接触导致变化”这一流行命题的唯一防波堤（**判分：**写出④中任一判别办法者本章 A**（**因为接触研究的失败案例，绝大多数就是把翻译文体当口语证据（**上一章的“副本限制”与本节是同一门课的两讲。**

::: intuition 听见那个人的不是文体 {#int-ting}

::: history 十三世纪为什么是边界 {#sec-bianjie}
