上一章的语言只剩韵脚与字形；本章的语言有一部书——**这是全世界材料最充分的早期音系之一，而它的奇怪之处在于：这部书从来不是任何人的口音记录，它是一件为跨地域交流而设计的工具**。

## 定义：一部书与它的账目 {#def-qieyun}

::: definition 韵、类、图 {#def-lei}
**通说脉络**（**公元 601 年一部韵书把万余字按声调与韵分若干部，内部再按同音字分组，每组用一个反切注音；该书经唐代与宋代增修，通行的宋本分二百零六个韵（**三个技术名词（**①韵**（**为作诗服务的单位：韵母与声调相同而声母可以不同；②韵类与声类**（**由反切用字的关系推出来的更细的分类，它们是构拟的起点而不是抄来的清单（③韵图**（**把全部音节排成一张表：横行分声纽与等，纵列分声调与开合（**本课要你看第三件东西，因为它最容易被忽略（**一张音节表上会有空格：某些位置有音而无字；**通说脉络：**这一件是语言学史上很早的一次“可能的词”记录：**系统允许、语言没有实现的位置被抄了下来（**这一条与第 5 门课句法里的“合乎语法而无人说过”完全同构，也是本章最想让理论界注意的一件事（**一格空格的主张强度，并不低于一个字的反切：两者都是在说“这个位置属于这个系统”。
:::

::: definition 反切系联 {#def-xilian}
**通说脉络**（**反切上字取声母、下字取韵母与声调；清代学者把全部反切用字互相系联，不借助任何录音就求出了声类与韵类的归并数（**本课用教材常举的一例演示其逻辑（**“东，德红切”与“冬，都宗切”：上字“德”“都”经系联归同一声类，说明两字声母相同；而下字“红”“宗”无法与其他字系联成一组，故两字所属韵类不同（**注意这里的推理方向（**我们不是先知道它们不同韵再去找反切，而是先看反切用字是否可归并（**这就是纯粹内证的漂亮之处：**它是一个自足的代数（**三条限制，与上一章同（**①系联的结果依赖你接受哪条规则；**若反切下字本身含介音信息，同一类可能被拆成两类（**通说脉络：所谓“重纽”即由此而来，其音值至今无定说（②书上的分类可能多于实际音系（**为作诗而分的类，口语里可能早已合并；③也可能少于实际（**若两类字永远同音，则反切无法区分它们（**本课由此得出一条一般结论（**任何用符号系统重建对象系统的学科都会遇到这一对麻烦：**分类过细的风险来自材料的目标，分类过粗的风险来自材料的分辨率；**而《切韵》两样都占——**它既太为诗服务，又太依赖少数编者的判断。
:::

::: definition 四份外国副本 {#def-fuguang}
**通说脉络**（**中古汉语的研究材料除了韵书韵图，还有三类间接证据：译音与对音、域外汉字音、以及方言比较（**本课把它讲成一件意外（**八至十世纪，几个邻国把当时中国的读书音抄回了自己家：佛经转写留下了汉字与梵藏文字的对照；日本、朝鲜与越南各自的汉字音系统各自继承了某个时期、某个层次的读法（**通说脉络：**于是重建中古音有一份外国副本——**这是汉语史上独一无二的情形（**而它的限制同样具体（**①外来的抄本不是录音：它经过对方音系的过滤，日语没有的辅音尾会被元音代替（②每一层抄本的年代与地点都有争议（**通说脉络：日本“汉音”相传与唐代长安读书音有关，但其形成过程复杂（③借入以后本地还在变（**于是这些材料只能用来支持或反驳类别的分合，不能用来定音值（**本课的方法论评点（**这份副本的价值不在于它更真实，而在于它独立：**同一件事由互不相通的两组人各自记录一次，是历史语言学能得到的最接近实验的证据（**上一章那句“独立证据增强可信度”在此有了具体的地理形状：洛阳、长安、奈良、开城、河内。
:::

::: definition 接口不是口音 {#def-jiekou}
**通说脉络**（**关于这部韵书所录是否为一时一地的音系，学界长期讨论；**本课接受讨论现状，然后把它换成一个制度问题（**①它的读者是谁**（**需要在不同地域做官与应举、需要按同一标准押韵的人；②它的设计目标是可互操作**（**它不承诺与任何一座城的口音一致，只承诺南北读书人都能在同一张表里查到自己的读法；③因此它的“综合”不是失误，而是产品规格（**本课的比喻接上一章与方言课：**这是一套精英文化的通用接口：**它不属于任何一座城，所以任何一座城的读书人都能用它（**接口的设计目标是可互操作，不是自然；**而接口一旦成功，就会被误认为自然——**唐代以后任何人问“某字怎么读”，查的总是同一部书（**于是本章最难的一句来了（**我们今天所谓“中古音”，其骨架是一部工具书的目录；**这不是指控它不科学，而是提醒：**构拟的对象是一个书面共同语的类别系统，而不是七世纪洛阳街头的话（**你若将来写音韵学与文学史的关系，请把这句话放在第一段（**它会替你挡住一半的审稿意见。**
:::

::: definition 声调与清浊 {#def-qingzhuo}
**一条贯穿一千年的因果链**（**通说脉络：四声各依声母的清浊在后世分化为两类，于是多数方言有六个到八个调类（**本课把这条链写成三条可核对的命题（**①分调的条件在声母而不在韵母**（**证据：同一韵同一调的字，若声母清浊不同，今调类常不同；②分调发生之后，原条件本身消失了**（**北方话浊声母清化，于是声调成了唯一携带旧信息的成分（**这是汉语史上最重要的“信息搬家”：**声母丢的东西由声调接手（③因此方言之间调类数的差别，主要是这条链完成程度的差别**（**方言课那句“同一条变化的不同完成度”在此闭环（**本课的教学习惯要求（**每当你看见一条“甲引起乙”的历史规律，都要问一句：**引起乙的那个条件今天还在吗**）？**若不在，那么乙就成了甲的化石——**而化石的分布比骨头更能画出地图（**第 9 章“词汇扩散”与本节是同一件事的两半：**规律说的是结果，扩散说的是过程。**
:::

::: example 从四组反切推两件事 {#ex-fanzqie}
设某韵书片断只有以下八个小韵，其反切下字如下（**甲：古 x 切；乙：古 x 切；丙：公 x 切；丁：工 x 切；戊：居 x 切；己：举 x 切；庚：九 x 切；辛：几 x 切**）。已知“古、公、工”三字经系联归同一声类，“居、举、九、几”归另一声类。请回答：①这部片断里有几个声类；②要判定“甲与丙是否同韵类”，你还缺什么；③这个练习与上一章的谐声练习的根本差别在哪里。

::: solution
**①两个声类**（**上字系联成两组即两类；**注意这一结论不依赖任何音值假设（②缺的是下字的系联**（**韵类由下字之间的关系决定，而题目只给了下字相同与否；**要判甲丙是否同类，须看它们各自的下字能否与其他字互相系联；**若“某字既是甲的下字又出现在丙的切下”则同类，否则不能定（**这里有一条常被忽视的推理限制：**系联给出的是“可分”，不是“可并”；**两个字未被系联到一组，可能真不同类，也可能是材料不足——**这就是所谓“系联的封闭性不足”（**通说脉络：**所以任何“《切韵》有若干类”的数目都应写明是用哪种补充规则补出来的（③与谐声练习的差别**（**反切是同时代人明确主张的关系（**他们写下这个字读如某字**），谐声是造字时代的字形关系且叠层数百年（**前者的证据强度高一级，因为它有主张人（**本课把这一条写成一句可迁移的判断（**历史证据的强度，取决于能否找到一个人曾经为它负责；**注疏、韵书序言、判案文书、日记里的注音，都比字形强：**因为它们是行为而不是结构（**这一句适用于你以后引的一切材料（**第 1 课的四种强度在此获得了它的第四条：**行为记录 > 结构痕迹。
:::
:::

::: intuition 为什么今天仍要读一部不能用的书 {#int-buneng}
**一个常见的抱怨**（**这部韵书对今天的作诗毫无用处，为什么还要学**）？**本课的答复有三层（**①它是一份穷举的清单**（**它把当时认为存在的音类关系全部写出，包括编者不用的那些；**清单的价值恰在于它完整，而不在于每条都被用到（**第 20 章“名册即评分标准”在此翻面：**名册的价值也在于它记下了未被选中的那些人（②它是唯一有内部核对机制的材料**（**反切之间互相定义，因此一处错误会在系联中暴露；**能被内部核对的文献在人文学里极少，这是它值得依赖的原因（③它教会我们尊重工具书**（**工具书不是知识，是知识的格式；**而格式往往比结论长寿——**今天我们不知道唐代怎么说话，但知道七世纪的几个人决定把音分成两百多个格，这个决定塑造了此后至少一千年的音韵学问题（**本课把这句话说到底（**一部书能规定后来人问什么，这是它最大的历史作用；**这一句既是音韵史的，也是文书学的（**第 3 章“格式即意识形态”在此换了一个朝代重演一遍。
:::

::: history 一部书的千年注脚 {#sec-zhujie}
**六〇一**（**一次私人居会上几位学者争论南北读音异同，次年一人据记录编成此书，其序留下那句常被引用的话（**通说脉络：**本课只取一点：**它是一份会议记录的产品；**而序里承认自己折衷，这一坦白使后来一千年的争论有了起点（②**七至十世纪**（**唐代增修与刊定，使它的分韵细节在写本中流传（**通说脉络（③**十一世纪初**（**宋代官修本定型，通行至今的分韵数目由此而来（**通说脉络：**本课强调这一条：**今天被当作“中古音”的东西，其外形是十一世纪官修本的产物；**我们研究的对象本身已被后世编辑（④**十二世纪前后**（**韵图出现，把音节排成表格；**现存最早的韵图通常归于宋代（**通说脉络：**这是结构主义音系学在中国的前身，且它没有术语（上方空格一条（⑤**十九世纪**（**一位学者以系联法从反切中求出声类韵类，使无录音的重建成为可核对的运算（**通说归于陈澍（⑥**二十世纪初**（**敦煌与吐鲁番所出写本使学界看到该书原貌，并证明传世本的分韵经过后人改动（**通说脉络：**本课的结论与此前多次相同：**材料的运气决定理论的边界；**二十世纪初之前无人能提出今天这些疑问，不是因为前人不够聪明（**档案运气在此第二次兑现（**下一次大概在出土文献的统计方法里。**
