上一章说我们最好的材料是韵文与字形；本章把这两样用到极限——**上古汉语是一门没有录音、没有母语者、甚至没有一本词典的语言，而学者们从押韵的字里、从一个字的写法里，重建出了一套有内部矛盾、可被反驳的系统**。

## 定义：韵部 {#def-yunbu}

::: definition 用统计重建一个已死的音系 {#def-tongji}
**通说脉络**（**清代学者把《诗经》等韵文的韵脚字归并成若干部，从十几部到二十几部；分部之精，使汉语史在录音出现之前就有了一门可比学科（**本课把这件事讲成方法而非掌故（**①这是一次纯粹的内证**（**没有同时代拼音，没有外语对音，只有“哪些字一起押韵”这一条关系（**由它可推出韵类的分合，推不出音值（②分部依赖一个假设**（**押韵是近音而非任意；**这个假设之所以可接受，是因为分部结果自洽、且与谐声系统吻合（**这就是所谓最佳解释推论（**逻辑课那条：不是不能反驳，而是反驳的代价比接受更大（③出土文献让这件事重新开始**（**通说脉络：近几十年公布的战国抄本与传世文献的异文，为若干分部提供了新证据（**本课只取一条教训：**同一段文本的早期抄本比宋刻本更接近当时用字习惯；**于是校勘学变成音韵学的一个分支（**这是本章给文献学学生的礼物（**也是给所有人的一个提醒：**证据的年代层次本身就是论证的一部分（**第 1 课史料分层的回访。
:::

::: definition 谐声与声母 {#def-xiesheng}
**一条常被忽视的事实**（**形声字的声符不止是“提示”，它是一个谱系：**同一个声符之下的字，上古声母应当相同或相邻（**而麻烦正从这里来：**若干声符之下既有见母一类读法，又来母一类读法（**以“各”为声符的一批字里，既有读 k- 类的，也有读 l- 类的（**通说脉络：**三种解释，必须逐个称重量（**①上古有复辅音声母，后世分别简化为两个单辅音；②造字跨数百年、若干地域，本来混入不同读法；③所谓“声符”判定有误，某些字并非该声符派生（**本课的判读：**第①种解释力最强而最难直接检验，第②种最保守，第③种在任何具体字上都无法排除；**所以成熟的写法是：**“谐声交替支持某种复声母的假设”，而不是“上古汉语有复辅音”**——**前者是证据的重量，后者是信仰（**这一处是本章最想教你的一件事：**同一份材料可以说出一句弱而真的话，也可以导出一句强而可疑的话，而差别只在动词与时态（**这一条与上一章“可见度陈述”完全同构，也适用于你写的一切论文。**
:::

::: definition 一个假说的形状 {#def-jiazh}
**通说脉络**（**一个有影响的假说认为，上古汉语没有后来的词汇声调，而声调来自韵尾的丢失：其中去声与一个后缀性擦音有关，上声与一个喉塞成分有关；这一思路与东南亚语言的声调发生研究并行（**本课不判断真伪，只把它的形状给你看清楚（**①它有独立证据**（**书面藏语里有类似的后缀与喉塞符号而无词汇声调；**若干汉语-亲属语对应词按此假说能对齐；同时越南语的声调发生被独立研究清楚，说明“韵尾丢失产生声调”是一种真实存在的机制（**通说脉络：**这是本假说最强的地方：它不靠汉语材料单独支撑（②它有代价**（**若上古无声调，则《诗经》的押韵规则需要重新解释：韵脚的一致要靠韵基而非调类（**这一步是可以反驳的，也确实有人在反驳（③它解释了许多不相关的东西**（**为什么去声字与入声字在谐声里关系密切、为什么若干异读表现为声调交替而声母韵母不变（**本课在这里给一个全课程通用的判据（**一个假说的接受度，取决于它把多少件互不相干的麻烦变成一次说明，以及它新增了多少未解释的例外；**这两项都公开可查，所以构拟之争不是一群人在猜测，而是同一场权衡在不同权重下得出的不同答案（**逻辑课“换科目引用”在此反过来用：**当两个学派各自引用不同科目时，你应当检查他们是否各自回避了对方的科目（**这一句是本课给你读任何争论的万能钥匙。**
:::

::: definition 形态的争论 {#def-xingtai}
**问题**（**上古汉语有没有词形变化**）？**通说脉络**（**讨论长期分裂（**本课认为值得记的是三条证据与其各自的洞（**①清浊交替**（**若干意义相关的字表现为声母清浊不同；**洞：**清浊也可能是方言或词汇层次，而非同一词的两种形式（②四声别义**（**旧注用“如字”与“读破”记录同一个字的不同读音与不同意义（**通说脉络：**这一条最硬，因为它是同时代人自觉的描写而非后人推测（**洞：**注读是规范系统，未必等于口语现实（③代词分工**（**若干传世文献里不同形式的代词分布互补，曾被解释为格的对立；**而同一系统在不同方言区的文本里表现不一（**通说脉络（**本课的结论不在答案，在方法（**这场争论持续一百年而不停，是因为它其实不是同一场争论：**内部构拟派要的是系统整齐，比较派要的是跨语言对应，文献派要的是可断代的实例；**三种标准各自合理、互不还原（**所以你若将来选一个立场，请写明你用的是哪一种“算作证据”的标准——**这一句应当抄在你笔记的第一页（**第 1 门课四种强度在此升级为四种制度（

::: definition 五种句法与一个警告 {#def-wuzhong}
**通说脉络**（**传世文言的句法与后世不同（**①判断句一般不用系词；②疑问代词与否定句中的代词宾语前置；③“之”一类成分可取消一个主谓结构的独立性；④被动意义由若干不同格式分担；⑤代词有多套形式而分布不齐（**本课给一个警告，它比这五条加起来还重要（**我们称之为“文言”的这个东西，是数百年间多种口语、多种文体与多种抄写规范的混合物；**把它的句法当作“上古汉语的语法”，等于把拉丁语当作二十世纪欧洲的语法（**通说脉络：**具体后果有三（**①先秦诸子的文本经汉代抄写与后世刊刻，句法可能被规范化；②韵文与散文的句法不同，押韵位置会强制变格；③不同学派的抄本传统不同，因而“同一时代”内部差异巨大（**于是这一章的正确写法永远是：**在传世的某类文献里，某格式如何分布**，而不是“上古汉语如何”（**这一句与上一章“可见度”是一对孪生命题：**前者管时间层次，后者管文献层次（**合起来就是本课程反复要求的那句：**主语要写清楚，哪怕主语很难看。**
:::

::: example 五步推一个谐声结论 {#ex-xie}
已知：**①“各”为若干字的声符；②这些字的后世读音分属两类声母；③其中一类在若干方言里读如流音；④某批押韵材料里两类字不与同类字通押**。请推出三种可相容的解释，并说明你需要哪两种新证据才能在它们之间做选择。

::: solution
**第一步（**确认已知里的“同”是什么意思：**①说谐声关系，③说是方言读法，②说是历时分类；**三者不在同一层（**这是谐声论证最常见的偷换：把字形关系读成音值关系（**第二步（**三种解释（**甲：更早时期有一类共同来源（复声母**），后代分为二；乙：声符关系成立而造字时代跨度大，两类本为不同时期的读音记录；丙：某字的声符归类本身有误（**通说脉络：**三种都可由现有材料说出（**第三步（**你要的两类新证据：其一，跨语言对应**（**若亲属语中有同源词，其声母在两类之间保持交替，则甲增强；②早期抄本的异文与假借**（**若两类字在早期文献里互相假借，说明抄手感知为同音或近音；**这直接检验“交替是否真实存在”而不是“字形是否相似”（**第四步（**注意这两类证据的强度不同：**跨语言对应依赖同源判定，本身可争；异文假借是同时代人的行为，属直接证据（**第 1 门课的四种强度（**判分（**能把“偷换”那一句写出来者为 A**——**因为汉语史上多数夸大的结论，都是把字形关系、方言差异与历史分类三者中的一项当作另一项的证据（**这一句是本章的考点，也是本章想留在你身上的习惯。**

::: intuition 说“上古没有声调”时的三种说法 {#int-sanzhong}
