---
title: "简体字与繁体字"
---

“简”与“繁”不是今天才有的对立：汉字三千年**总体趋简**，简化字只是这条长流上最新、也最制度化的一个浪头。本章回答四个问题：简体字是什么（它古已有之）；1950年代的方案“简”了哪些、怎么简的；合并造成的**信息丢失**如何补偿；以及简繁关系的正确打开方式。

## 定义：简体、繁体、异体是三个概念 {#sec-dingyi}

**简体字**是比旧行正体笔画省省的写法——“国”之于“國”、“从”之于“從”，宋元平话、碑刻别字、商号账本里早有它们的身影（旧学称“俗字”）。“繁体字”则指现行规范简体所对应、历史上长期充当正体的写法。二者是**同一字位的两种规体**：说“繁”不等于“正统”，说“简”不等于“新造”。

::: definition 异体字整理是另一条轨道 {#def-yiti}
**异体字**是同一字的不同写法共时并存（“峰峯、畧略、詠咏”都是），整理原则“存一汰余”。1955年《第一批异体字整理表》淘汰异体一千余个（如“峯”歸“峰”、“畧”歸“略”、“麄”歸“粗”），管的是**一个字的写法竞争**；《汉字简化方案》管的是**繁简字位合并**。两件事常被混谈：简化字里相当一部分（如“灶、尘、体”）同时是异体整理的结果——它们本来就在候选之列。
:::

::: theorem 简化不是1956年的发明，是一场七十年的接力 {#rule-jiejli}
1922年陆费逵发表《汉字简化的意见》，开知识界正式讨论之端；1931年徐泽敏《常用简体字稿》等辑录问世；1935年8月国民政府教育部公布《第一批简体字表》（324字），**旋因争议于次年收回**；1936年国语统一筹备会制成收字千余的《简体字谱》，存档未行。1950年代中国文字改革委员会接手工程化：1956年1月国务院公布《汉字简化方案》（分批推行的227个简化字与14个简化偏旁，1958年推齐），1959至1964年陆续补正，1964年5月公布《简化字总表》共收**2236字**。1977年《第二次汉字简化方案（草案）》试行，**1986年6月国务院明令废止**，同年重发重新整理的《简化字总表》为现行依据；2013年《通用规范汉字表》（8105字）总集成。简言：简体字的自然史近千年，法定史近百年，其间还有收回、废止两次急刹车。
:::

## 简化的七种手法 {#sec-shoufa}

::: definition 构形手法目录 {#def-shoufa}
①**沿用古字**：启用早期本字或古文——“云（雲）、网（網）、从（從）、礼（禮，《说文》以“礼”为古文）”；②**采用俗字**：宋元以来的民间省笔——“体、坛、惊、灶、护、处、电、开、丧”；③**草书楷化**：行草轮廓转成楷笔——“书、长、东、乐、与、龟、鸟、门”；④**同音替代（假借）**：拿现成简体字兼记繁字——“谷（穀）、余（餘）、面（麪）、只（隻）”；⑤**改换声旁**：旧声符换成笔画少的——“护（護→户声）、认（認→人声）、惊（驚→京声）、灯（燈→丁声）、邻（鄰→令声）、远（遠→元声）”；⑥**省略部件**：“习（習）、声（聲）、术（朮）、岛（島）、们（們）”；⑦**符号替换（记号化）**：用不表音义的简单记号批量换件——“又”族（对、戏、欢、仅、劝）、“乂”族（赵、凤、这、还）。
:::

::: example 逐字开鉴定书 {#ex-jianding}
判定“国、习、护、灯”各用何种手法，并说明为什么一个字可以兼挂两三门。
::: solution
“国”：俗字（唐五代已见“国”写作囗内“玉”的省体，兼有会意新解的色彩）——②为主；“习”：《说文》正体“習，数飞也”，“习”为省笔俗体——②＋⑥；“护”：“護”改蒦声为户声的新形声——⑤为主，兼俗字来源；“灯”：“燈”改登声为丁声——⑤。一字多手法不足怪：**来源层（历史上从哪来）与操作层（方案怎么处理）是两个坐标系**；简化方案的绝大多数条目，都站在“久已流通的俗写”与“整理者的一次法定认可”的交点上。
:::

## 合并案与“回繁”的陷阱 {#sec-hebing}

::: example 高频合并案九对转繁 {#ex-jiudui}
给下列词语转繁：头发、发展、干净、干戈、乾隆、皇后、谷子、余数、叶子。
::: solution
頭髮／發展／乾淨／干戈／乾隆／皇后／穀子／餘數／葉子。要点四条：**按义定字**——“乾”读gān义（乾燥、乾淨）简作“干”，读qián（乾隆）者保留；“幹”才、枝幹之“幹”简作“干”，与“乾”各归各路；“后”为本字（皇后、后土），被借去记“前後”之“後”，转繁时只在“前後、後來”处复原；“穀物”之“穀”归“穀”，“山谷”之“谷”自若是也。九对无它法，记的是**合并边界**而非整张表。
:::
:::

::: theorem 合并丢了什么：一道算术题 {#rule-suan}
十个高频合并简体接管的源字：“发”接髮、發；“干”接（本字干、）乾、幹；“后”接後；“谷”接穀；“面”接麪；“台”接臺、檯、颱；“叶”接葉；“余”接餘；“郁”接鬱；“涂”接塗——共**十四字上下**。丢失的全是**书写层的同音区分**：语音未变，词义未变，双音语境几乎全能复位（“頭髮”不碰“發展”，“山谷”不碰“五穀”）。真正需要专门补偿的只剩两域：书法题款、古籍与人名地名的转写——以及一个统计事实：日常阅读里合并字的实际歧义率**远小于**舆论想象。
:::

::: warning “恢复繁体字”口号下的三种混淆
（1）**拿异体当繁简**：“峰／峯”是异体竞争，简繁两不相干；（2）**拿通假当混同**：“云／雲”的合并只是恢复经籍里早有的假借关系，不是“毁灭了‘云气’的本义”——“雲”义之“云”千年白字成了合流常态；（3）**拿姓氏当错误**：“范”古姓与“範”姓本两家，简化后同形，族谱、碑传检索须回原字。反向误区也要防：以为简体都是“断裂新造”——“礼、从、网、处”皆出自《说文》古文与千年俗写，简化字与古代字库之间是**继承关系**，不是决裂关系。政策评价前，先分这三笔账。
:::

::: intuition “汉字落后论”的历史位置
1920—1940年代，钱玄同、赵元任、黎锦熙们主张削繁就简乃至拉丁化，背景是亡国危机下的识字效率焦虑——那时成人口径文盲率以八成计，激进议论有其历史合理处（切音字到“汉字革命”的谱系见[[sounds-of-mandarin/syllables-pinyin]]）。1950年代的简化是这条脉络的制度化。今日盘点：简化确实压低了初学门槛（常用字均笔下降、识字周期缩短为可测事实），代价则是合并型字义的书写层区分与历史文本的“断层感”。把它说成“毁弃传统”或“完美工程”都不准确——**一次有得有失、可修补而无需推倒的标准化**。
:::

::: example “游／遊”与“余／餘”：两种合并的命运 {#ex-liangzhong}
“游览”规范写作“游览”还是“遊览”？“余暇”的“余”与第一人称“余”是什么关系？
::: solution
“遊”在1955年异体整理中作为“游”的异体被淘汰，水流、游泳、游历、游览一律作“游”——这是**异体并案**不是简繁合并。第二问是陷阱：第一人称“余”是本字自若，“餘”则省去“人”旁并入“余”——于是“余”兼两职：人称代词本字＋“餘”的简体。转繁时人称“余”仍作“余”，“其餘、年餘、業餘”一律复原作“餘”。**合并案查“回繁边界”的捷径是查“古自有之”**：古字兼差的合并（后、余、云）总有本字问题，回繁规则必须逐字背。
:::
:::

## 简繁并存的世界 {#sec-bingcun}

::: history 二简字兴废：激进实验的解剖 {#sec-erjian}
1977年12月公布的《第二次汉字简化方案（草案）》把第一方案的逻辑推到极限：继续省笔、继续记号化、继续同音兼并，部分教材、工具书与报刊排字试行了一段短时期。问题立刻显形：字形系统未定型——报头、课本、铅字铸模各改各样，一代学生的字帖与出版界铅字互不相认；同时它触到合并型简字的老病灶：**再合并一次，语义复位的机会也没了**。1986年6月，国务院批转国家委《关于重新发表〈简化字总表〉的请示》，明令废止第二方案、重发重新整理的总表为唯一依据。“二简”遗产今天主要剩两样：民间手写里挥之不去的省笔惯性（如把“副”省作临时俗体一类——它不合法度），以及政策史上的教训：**文字标准的改动成本以十年计，任何“再简一次”的冲动都必须先回答系统稳定性账**。
:::

::: quiz
《简化字总表》现行收字规模是（　）。
- [ ] 324字
- [ ] 227字
- [x] 2236字
- [ ] 8105字
::: solution
1964年总表收简化字（含简化偏旁推定的系列字）2236字，1986年重发沿用。324是1935年民国第一批表，227是1956年方案的严格计数，8105是2013年《通用规范汉字表》的总字数。

::: quiz
下列属于“改换声旁”手法的是（　）。
- [ ] 书（書）
- [x] 灯（燈）
- [ ] 谷（穀）
- [ ] 习（習）
::: solution
“灯”以“丁”代“登”声，典型换旁。“书”是草书楷化，“谷”是同音替代，“习”是省笔俗字。

::: quiz
“乾净、乾隆、枝干”三词对应的繁体书写，正确的是（　）。
- [ ] 乾净、乾隆、枝幹
- [x] 乾淨、乾隆、枝幹
- [ ] 幹净、乾陆、枝干
- [ ] 乾净、乾陆、枝干
::: solution
乾燥之“乾”（gān）简作“干”，乾隆之“乾”（qián）保留，幹才、枝幹之“幹”简作“干”——三“干”分家读回三字。第一、三、四项各错至少一处。

::: exercise 手法归类 {level=1}
把下列简字按七类手法归档：“网、乐、认、欢、术、处、远”。
::: solution
网—沿用古字；乐—草书楷化；认—改换声旁；欢—符号替换（“又”族）；术—省略部件（“朮”借“術”，再省笔）；处—采用俗字（“處”俗“处”）；远—改换声旁（袁→元）。判分允许个别字两说并存，须能自圆。
:::
:::

::: exercise 找错 {level=1}
一份简繁转换练习里有三个错例：①“頭髮”写成“头發”；②“乾隆”写成“干隆”；③表“剩下的”一词写成“餘下”。指出各自错在哪、属于哪种错误类型。
::: solution
①合并未分家——“髮”当简作“发”；②干／乾／幹三合一后误并——年号“乾隆”不可作“干”；③反向错误：“餘下”简化应作“余下”，此处该繁而简。错型名称：合并字**该分未分**、**不当而合**。
:::
:::

::: exercise 转繁实战 {level=2}
将下段碑刻式短句转繁（自定取舍并说明）：“敕建后土庙，乾隆九年重修，谷旦敬书。”
::: solution
“敕建后土庙，乾隆九年重修，穀旦敬书（書）”。难点：①“后土”是本字神名，**不作“後”**——合并案的经典试金石；②“谷旦”一语出自《诗经·陈风》“穀旦”之典（善旦），题款从旧体时应复原作“穀旦”；③“书”若全句从旧则作“書”，“敕、修、敬”皆本字无改动。转繁评分看的是**边界意识**：本字不妄改，合并字逐词查。
:::
:::

::: exercise 数据调查 {level=2}
在自己近一周的书写/输入文本里数出合并字（发、干、后、谷、面、台、叶、余、郁、涂）的出现频率，抽查五例：若转繁，有无歧义风险？写二百字小结。
::: solution
合格答案须给出真实计数（哪怕样本只有百余字）、五例逐条“可复原／有险”判断（如“晾干”之“干”复位为“乾”，“干才、躯干”复位为“幹”——日常搭配里人自动化解，机器却要词表）与结论：合并字的歧义主要藏在**低频双音框架**（“干系”之“干”本字？“關係”简作“关系”又是异体并案一例）。
:::
:::

::: exercise 小论文：简繁之争能两全吗 {level=3}
“识繁写简”“书繁听简”等折中主张流传数十年。写一篇八百至一千二百字短论：简繁双轨的可行边界在哪里？要求用本章的“手法／合并／异体”三概念各一处，并回应一个反对意见。
::: solution
判分点：三个概念用得准确（识繁写简涉及**字位与规体**之辨；“两全”论者多从古籍阅读与书法立论，须核对“断层感”是否真由简化造成——繁本今人亦难读，可用本章统计事实质疑）；能区分教育课时问题（读繁能力）与制度统一问题（写哪套字）；对回应反方认真（不稻草人）；无事实硬伤（年份、表名、字数错一处扣分）。
:::

::: summary
简体不是新造：近千年俗字长流＋1922—1956七十年接力，1964《简化字总表》2236字、1986重发沿用、2013归入8105字《通用规范汉字表》；“二简”1977试行、1986废止。七种手法：沿古、用俗、草化、音借、换旁、省略、记号化。合并型简字（发干后谷面台叶余郁涂，接源字十四上下）只丢书写层同音区分，双音语境基本复位，重灾在题款与转写。异体整理、简繁合并、通假古今三账分开算；简繁并存的现实里，“按义定字、查合并边界”是全部的技术。
:::
:::
