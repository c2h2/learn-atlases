上一站我们说“成熟汉字只能讲到甲骨为止”——这一章就下铲到这两处最大的矿：殷墟的龟甲兽骨，和西周列鼎列盘上的铸铭。它们不是同一种东西：甲骨是**钻出来问神**的档案库，青铜是**铸出来传给子孙**的纪念碑；两者的书手、工具、载体、目的全都不同，字形性格也就不同。学完这一章你应该能：认出两类材料的字形脾气，看懂一版甲骨释文和一篇金文释文的每个符号是什么意思，并知道释读这门手艺的规矩——哪些字是铁案，哪些是猜想，哪些人把猜想讲成了爆款。

## 甲骨：占卜流水线上的字

::: definition 甲骨与甲骨学 {#def-jiagu}
**甲骨**指商代后期（约前 1300—前 1046）王室占卜用的龟甲与兽骨（以牛肩胛骨为主），事前加工（削、磨、钻、凿），临事**灼**之使背裂出兆纹，王与贞人据兆断吉凶，事后把这次占卜的经过刻（少数先写后刻）在其上——叙、命、占、验与序数刻辞，即**卜辞**。甲骨学的基本功包括：辨识单字、断代（董作宾据贞人名与书风立**五期说**，其后学者以地层、坑位、卜组不断修正）、以及释读未识字。已出材料以《甲骨文合集》《甲骨文合集补编》等为大宗，著录书连绵百年。
:::

::: definition 治骨与成辞的流水线 {#def-gongyi}
甲骨占卜有一套固定工艺：取料（龟腹甲为主、牛肩胛骨次之）—削磨平整—在背面**钻凿**（圆形凿与条形钻相间排成行）—用火灼之，正面随之裂出“卜”形兆纹—王与贞人**占**兆纹之吉凶—把此次占卜刻于兆侧，并标**序数**（第几卜，由兆干走向可复原整个灼卜顺序），事后有应验再补**验辞**。这套“前加工”本身就是释读证据：钻凿的排列规定兆的次序，兆序错乱往往意味着**拼版**（同牛肩多片、同龟腹正反面）关系——今天整理新出土甲骨，第一步仍是“找邻居配框架”，认字反在其次。
:::

::: theorem 释读四把钥匙 {#rule-shidu}
认一个未识甲骨字，依次过四关：（一）**字形比对**——与小篆、古文字形体线一系相承者最稳（王、牛、日、月类，铁案）；（二）**辞例互证**——同一字反复出现在“干支卜，某贞：旬亡祸”一类固定句式中，位置即语法，语法框住词性；（三）**传世文献对读**——《说文》所收古文、《史记》世系之类可与之对榫（王国维验商王世系即此法的巅峰应用）；（四）**构形系联**——拿偏旁系统推：从“水”之字多与水涉，从“玉”（二玉相从）之字多与玉器涉。四把钥匙齐备方可称“释曰”；只用一把（形似）的，叫“臆说”。已识字两千余，仍有一千多字（多为人名、族名、地名）在暗处。
:::

::: example 一片卜辞的读法示范 {#ex-buci-read}
读一片依通式改写的卜辞：“癸卯卜，殻贞：旬亡祸？在四月。王占曰：有祟。五日丁未，□雨。”——逐件标注成分，并说明这片卜辞能告诉研究者什么。
::: solution
件件有着落：“癸卯”叙（干支日，贞问之日，卜问未来十日即“旬”之吉凶，故常逢癸）；“殻贞”命辞的贞人名（殻为武丁时书手，一片卜辞的断代就靠他与同坑共出的贞人组）；“旬亡祸”命（占问句式）；“在四月”月系；“王占曰有祟”占辞；“五日丁未雨”验辞（事后应验追刻）。它能给的：断代（贞人＋月份）、语言（“亡祸”否定式、干支纪日法）、宗教观念（旬神与王占）、气象记录（是日验雨——殷墟天气档案的一条）。“一片卜辞是多重证据的压缩包”，此之谓。
:::
:::

::: remark 甲骨的字形性格
刀刻急就：线条细直、转折多方（圆转费刀）、字形大小参差、正反繁简随便（“羊”正写倒写、实心空心并存，“涉”作二止一水或多水）——这是**手写的自由度**，也是初学释读的第一道坎：一字多形是常态，定型要等金石与字书。记住一条纪律：凡“甲、乙两形其实是同一个字”的判断，须有**同辞例互换**或后世字形一线相承的证据——不能只看“长得很像”。
:::

## 金文：传留给子孙的字体

::: definition 金文与吉金著录传统 {#def-jinwen}
**金文**指商周青铜器上的铭文（“吉金”为铜的美称），商器铭短（族徽、作器者名），周器铭长，记册命、征伐、赏赐、诉讼。字数之冠为西周晚期**毛公鼎**，四百九十七字，一篇诰誓正文。著录之学宋人开山（《考古图》《宣和博古图》、薛尚功《历代钟鼎彝器款识法帖》），清道咸以后集大成（阮元《积古斋钟鼎彝器款识》与吴大澂、孙诒让诸家形声之学），近代《三代吉金文存》《殷周金文集成》与字书《金文编》为今之渊薮。铸铭工艺：范上反书刻模、合范浇铸，故字形**圆厚**，与刀刻甲骨的瘦硬成两副面孔；春秋以后亦有刻款。
:::

::: theorem 金文读法三注意 {#rule-jinwen-du}
（一）**词例套语**：金文高度程式化——“隹（唯）九月”“王若曰”“用作朕皇考某公宝尊鼎”“子子孙孙万年永宝用”；读通套语，全篇骨架自现，这是与读甲骨不同的“句式地图”。（二）**通假密集**：上古音近通假为常（“福”作“畐”，“万”作“万”象蝎形之借；“对扬王休”诸字各有本字之争）——金文的半壁江山在**音**上，不通古音（[[phonology/mc-initials]]以上）只能望铭兴叹。（三）**器铭关系**：同一王世诸器需拼“历谱”，断错一器，连读全乱；“金文谱系”是集体工程，个人独释终千年巨制者，学史上只当笑话讲。
:::

::: example 释字一例：从“辰”到“农”的事 {#ex-chen}
“辰”的甲骨形或说象蝎形、或说象蜃（耕具）形；它是“农”“秾”一类字的声旁。请判断这条线索能走多远。
::: solution
稳妥走法：辰的本形两说并存（虫形/工具形），未可必；它作为**声旁**系联的字（农、秾等）上古音读同部，属“声旁考古”可用之材（[[chinese-characters/phonetic-compounds]]展开）；若进一步说“辰就是犁，故汉字见证原始农业”，则越过三件套进入想象——古文字证史的铁律：**字形证据必须与考古、文献三角互证才准签字**（王国维“二重证据法”是底线，不是天花板）。本题示范“能走到哪儿算哪儿”的分寸。
:::

::: warning 地下材料的三种滥用
一曰**以形说文化**：见“武”从止戈便论“中国人尚和”，见“安”中一“女”便论上古婚俗——构形理据（造字时的理据）不是造字时的社会调查报告，许多部件只是区别符号（[[chinese-characters/six-categories]]）。二曰**时代错置**：拿《说文》所据晚出小篆形体反过来“纠正”甲骨金文的释读，或用今字形断“古人本义”，都是拿下游的水灌上游的田。三曰**伪史料**：拓片市场上“甲骨”“骨刻文”十有九赝（所谓“骨刻文”的真伪之争绵延多年），未见科学发掘与正规著录的“新材料”，一律按故事会待遇。
:::

::: remark 金文的“笔迹”问题
青铜铭文是先写好、再上范：商周书手或以笔书于泥范（反书待铸），或经过摹刻转写，故金文圆折肥厚处常存**笔意**——“子”“牛”头部的实心团块（所谓“肥笔”）即毛笔痕迹的化石；而器纹残泐、铸缩又给每篇加了随机失真。由此生出一门“字体发展史”的功夫：以有年代坐标的诸器排比字形与书风的演变序列（一字之形可作断代的辅证，正如笔迹鉴定），与历谱互证互校。读金文拓片时，你看到的既是“字”，也是“字的手迹”，还是“手的工艺”——三层叠加，恰是书法史与文字学共用同一堆材料的原因（[[chinese-characters/seal-to-regular]]展开，字的文化面见[[chinese-characters/characters-and-culture]]）。
:::

::: history
甲骨学的童年自带传奇：1899 年王懿荣识“龙骨”为古物，学问随即从药铺转入书斋与田野。其后二十年间，罗振玉追出出土地在安阳殷墟并释商先公，王国维以卜辞证《殷本纪》世系几若符节——“纸上材料”与“地下材料”第一次互相打手印，史学界由此立下“二重证据法”的家规（《古史新证》）。1928 年起中央研究院十五次发掘殷墟，1936 年 YH127 坑、1976 年妇好墓把甲骨从“古董”变成“考古地层里的档案”；1950 年代以后，小屯南地、花园庄东与周原甲骨续写著录。金文方面，从宋人《考古图》到《殷周金文集成》，从吴大澂《说文古籀补》到《金文编》，一代代摹录、校释、分代——这门学问的“硬”，全写在著录书那些诚实的“未详”“阙疑”里。
:::

## 后续内容

甲骨、金文之后是“隶变”——字形从线条走向笔画，古文字时代落幕（[[chinese-characters/seal-to-regular]]）；释读四钥匙里最吃功夫的“构形系联”，其理论总结在[[chinese-characters/six-categories]]；金文与古音的纠缠在[[phonology/mc-initials]]与上古音部分。练习建议：找一部《甲骨文常用字字典》与《金文编》，每天对照十例做“形变日记”——一个月后，你对“字为什么会写成现在这样”的感觉会完全不同。

::: summary
- 甲骨＝王室占卜档案：加工—灼裂—占断—刻辞（叙命占验）；断代靠贞人组与书风（五期说）。
- 释读四把钥匙：形体比对、辞例互证、文献对读、构形系联——缺一把都是臆说的风险。
- 甲骨字形“自由”恰因系统稳定；一字多形是常态，归形须凭辞例或字系证据。
- 金文＝纪念碑文体：套语地图＋通假（音）＋历谱断代三件套；毛公鼎以最长铭文与历谱地位著称。
- 地下材料三忌：以形说文化、时代错置、伪材料——“二重证据”是底线。
:::

::: exercise 正反之辨 {level=1}
判断并改正：（1）“甲骨文同一个字有正写反写，说明当时用字极不规范，释读只能靠猜。”（2）“金文比甲骨文字形丰满，所以金文比甲骨文晚出。”（3）“拓片里的缺字应据残笔与辞例补出，补不了就标注阙疑。”
::: solution
（1）错——正反不拘恰是系统稳定的标志（见“甲骨的字形性格”remark），释读靠四把钥匙不靠猜；（2）错——字体风格差异源于载体与工艺，商周金文与甲骨**同时并存**（商代既有甲骨也有铜铭），先后须以材料断代而非字形胖瘦；（3）对——“阙疑”是著录的职业道德，强补是学术事故。判分：三案各须引一条正文依据。
:::

::: exercise 释读流程 {level=1}
某新出甲骨有一字从“辵”从“彳”从“止”（示意），辞例为“王往至于□”。请依次写出四把钥匙各怎么派上用场，并给出你允许的结论等级（铁案/通说/待考）。
::: solution
形体比对：与后世“徏”“徂”“往”诸字形作谱系比对（给出候选本字）；辞例：“王往至于□”的□居“至于”之后，词性被框定为名词，地名的概率最高；文献：《诗》《书》“徂”“适”“格”诸“往”义词对音对形（给本字假设）；系联：从“彳”从“止”之字多与行涉有关（旁证）。四级证据齐而不同指向时，结论只能记“待考（倾向某）”——本题判分在**流程完整＋结论等级恰当**，不在猜中某个具体字。
:::

::: exercise 断代小案 {level=2}
同坑共出卜辞分属贞人“殻”与“宾”组，且称谓有“父乙”“母庚”。用五期说与称谓法给这片卜辞一个粗断，并说明这套方法各自的可靠边界。
::: solution
贞人同坑＝同时期共事（组断代）；“父乙、母庚”式称谓限定了所祭先王辈分（王世坐标）。两者叠加可粗断“武丁世前后”一类区间。边界：贞人组内有续用、称谓跨组出现、且坑位扰乱即失效——断代学结论多是“区间＋概率”，引用时须保留误差（这也是为什么教材写“约前 1300—前 1046”而不是某一年）。
:::

::: exercise 一件铜器的证词 {level=2}
假设新见铜器一首：铭文有“隹十又二月既生霸丁亥，王格于大室，荣赐贝十朋”? 以册命套语自拟，命你断代。列出可用的断代要素清单（不少于五项）与结论的表述规范。
::: solution
要素清单：①历日（王年＋月名＋月相“既生霸”＋干支）能否纳入有王世历谱、与已知器拼合否；②官称与册命格式（“王格于大室”一类即时代语法的指纹）；③称谓与谥法问题（某王之号是否生前即称）；④字形书风（与标准器群比对，作辅助线）；⑤器形纹饰与铭位（考古学坐标，器型学自有其谱）。表述规范：给“区间＋置信度＋所据要素”，并列出“若某器断代有变则本器随动”的连带关系——金文断代从来是牵一器动全局的网，孤器独断是外行行为。
:::

::: exercise 拓片辨伪 {level=2}
网售“甲骨文拓片”某件，卜辞通顺、字形匀整、含“数字预测未来地震”内容。列出不少于四条疑点，并给出鉴定程序。

以“一片卜辞 vs 一篇尚书”为题写四百字：王国维用甲骨证《殷本纪》世系“几若合符节”，这句话的兴奋与限度各在哪里？要求用到“二重证据法”与至少一处具体环节（如先公先王名号的对应、个别世次不合的著名异同）。
::: hint
可参：《古史新证》的总纲文字；甲骨文与《殷本纪》世系对照表（各通史教材皆有，挑一张看它哪里“严丝合缝”哪里“略有出入”）。
:::
::: solution
参考走向：兴奋在于——传说里的商王名单第一次在**独立来源**的地下档案里成串复现，古史从此有了可检验性；限度在于——合符的是“名号与大致次序”，细节世次已有出入（先公先王的世次与个别名号，传世文献与卜辞互有出入，学者已加是正），且卜辞是占卜档案，非为修史而作，用它“证史”须防把宗教记录当编年史读。结论应落在方法自觉：二重证据不是“印证癖”，是**交叉校勘**——两处不同来源相互制衡处，才叫信史。
:::
