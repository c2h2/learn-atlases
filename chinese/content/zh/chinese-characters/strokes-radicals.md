从“这个字怎么一笔一笔写出来”到“这堆字怎么查、怎么排序、怎么标准化”，本章把汉字的最小单位层级——**笔画、部件、整字**，加上检索用的**部首**——一次讲清。它们是识字教学的语法、字典学的螺丝钉、输入法与字库工程的底层规格。

## 笔画：最小的书写单位 {#sec-bihua}

::: definition 笔画与笔画系统 {#def-bihua}
笔画是**书写时笔从落周到提起连续完成的一段线条**，是现代汉字分析的最小单位。《现代汉语通用字笔顺规范》（国家语委1997年发布）把通用字的笔画归为**横、竖、撇、点、折**五大类（所谓“札字法”：横如“一”、竖如“丨”、撇如“丿”、点如“丶”、折如“乙”），折类包含横折、竖折、撇折、各种弯钩复合笔画等数十种小类。数笔画、排检、统计字频时都按这个五分法操作：“为”四画、“凸”五画、“爽”十画。
:::

::: definition 笔顺：书写的线性规范 {#def-bishun}
笔顺是笔画出现的先后次序。通行规则八条：**先横后竖**（十）、**先撇后捺**（人）、**从上到下**（三）、**从左到右**（明）、**先外后内**（月）、**先里头后封口**（田）、**先中间后两边**（小、水）、走之底的**捺最后写**（过、建）。此外有若干专字专规：右上三包围先上后左下（司、冈），带戈钩的字先写斜钩再写其后短撇点（我、成），相交的撇与折笔先撇后折（九、力）。
:::

::: theorem 笔顺不是审美问题，是规范问题 {#rule-bishun-gui}
同一字符不同笔顺并存，会直接制造三场事故：（一）**笔画数不一致**——“必”先写心还是先写撇，各本不一，检字表就无所适从；（二）**规范考核失分**——语文教学、教师资格测试按《笔顺规范》判卷，俗顺（如“火”先写两竖撇再补点）一律算错；（三）**信息化标准冲突**——笔画类排序（如《辞海》老本、部分字符集排序）以笔顺首笔归类，首笔不一则序位漂移。所以记住：笔顺是有**国标**的东西，权威以《现代汉语通用字笔顺规范》为准，争议字查它，不查网络动图。
:::

::: example 逐字验算笔顺 {#ex-bishun-yan}
按规范写出“为、九、火、凸”的笔画序列与画数。
::: solution
“为”：点、撇、横折钩、点，四画；“九”：撇、横折弯钩，二画（先撇后折）；“火”：点、短撇、竖撇、捺，四画（先两侧点后两笔支撑）；“凸”：短竖、横、竖、横折折折、长横，五画。判断标准不靠手感，靠查表——这正是“规范”存在的理由。
:::

## 永字八法到字形规范化 {#sec-baxing}

::: history 从八法到国标：笔画的千年标准化路
唐代书论托名张旭等确立“永字八法”，宋《玉海》所引、元陈绎曾《翰林要诀》大加敷衍——八法本质是**笔法教学口诀**，不是笔画分类学。印刷术兴起后出现第一个真问题：同一字，抄手、刻工写法各异，**字形**需要标准。1965年文化部、文委公布《印刷通用汉字字形表》（6196字），确定“从俗、从简、注意系统性”的新字形原则，一批老印字形退场（如“者”腹取“日”不取“曰”，“今”末笔取点不取横，“琴”下从“今”不从“金”）。1988年《现代汉语通用字表》（7000字）、1997年《现代汉语通用字笔顺规范》、2009年《汉字部首表》（主部首201个、附形部首99个）相继出台，至此“字形—笔画数—笔顺—部首归属”四件套全部标准化——一个传统“写大字先生”的江湖，让位于国家标准的精确工程。
:::

::: warning 印刷体不是唯一正确的字
“竖钩带不带钩”“点写作侧点还是挑点”“木字旁的捺改点”——这些是**印刷字形与手写变体**的正常出入：规范管的是笔画数、笔顺、部件构成（构件同一性），不管毛笔趣味与细部风格。批改作业时因“口的横折写成两笔”判错、或相反地放任“横的起笔顿角算一画”，都是把字形规范与笔画规范混为一谈。规范汉字判定的三层：**构件对、笔画数对、笔顺对**；形状胖瘦不在其列。
:::

## 部件：笔画与整字之间的结构层 {#sec-bujian}

::: definition 部件与结构类型 {#def-bujian}
部件（码元、字素、组件）是**由笔画构成、又具有独立组字能力**的单位：“意”可拆“音、心”，“音”再拆“立、日”。按能否独立成字分**成字部件**（“日、木、口”）与**非字件**（“刂、宀、艹、辶”的规范称“立刀儿、宝盖头、草字头、走之底”——名称本身也是1997规范规定过的）；按构字功能分**形旁、声旁、记号**三类（亦声字之辨见[[chinese-characters/phonetic-compounds]]）；按整字布局分**左右、上下、包围、品字、独体**五类结构。
:::

::: theorem 部件分析是“两层切分”，不是一把乱拆 {#rule-liangceng}
科学的拆分只切**单层结构**：先按直接构件一刀两断（“意→音＋心”），再各自往下拆（“音→立＋日”）。跳层拆（“意→立＋日＋心”一口气）会破坏结构信息、笔画统计与编码；拆错位置则把继承关系全乱——“颖”若跳层拆成“匕、禾、页”三件，就丢掉了“顷”这一中间结构层，考释与编码都会错位。分析到“最小又成字或约定成部件”为止，剩下的就是非字件或独体记号。
:::

::: example 给五个字做部件体检 {#ex-tijian}
“问、壁、颖、疑、国”：指出直接构件与结构类型，并标出其中的形旁、声旁与记号。
::: solution
“问”：门＋口，内外（门形表义？“问”从口门声——门在此是声旁的特例）；“壁”：辟＋土，形声，辟声土形，上下；“颖”：从禾顷声（《说文》“颖，禾末也”），禾形、顷声；“疑”：甲骨文像人持杵行疑之形，隶变后部件关系失重——部件分析判为**记号字**（构件不再表音表义的孤子）；“国”：囗＋玉，国是玉的会意还是形声有争论——“囗”是范围符号（记号性构件），“玉”表义，简化字“国”常被引作“简化后形声含混”的讨论案例（详见下一章）。体检结论：连“疑、国”这样看似部件清楚的字，功能判定也常常失血。
:::
:::

## 部首：从540到201的检索史 {#sec-bushou}

::: definition 部首 {#def-bushou}
部首是**按义类或形体归类的字首**，同一部首的字在字典里聚拢一处。它的功能有两副面孔：**义类标识**（“艸、水、玉”成串地表类目，说文系统的遗产）与**纯检索符号**（近世字典“检字法”面孔，连“难检字查什么部”都规定成口诀：查不出的字按起笔、按难检附表）。部首不是部件：部件是结构单位，部首是排序单位——同一字取哪个部件作部首，字典说了算。
:::

::: history 部首系统的四次瘦身 {#sec-bushou-line}
- 东汉·许慎《说文解字》：540部，一字一部，部首皆取有义类统摄力的字，构形逻辑与检索功能合一；
- 辽·行均《龙龛手鉴》（997）应俗写检索之需，已将部首省并为242部——部首瘦身的先声；
- 明·梅膺祚《字汇》（1615）：并省为**214部**，按笔画排部首、部内再按笔画排字——部首由义类系统转为**检索骨架**；清《康熙字典》沿用，成近代最大公约数；
- 民国至当代：《辞源》《辞海》各有增删（200部上下）；《新华字典》（初版1953）行“部首＋笔画”检字，189部；2009年《汉字部首表》定**主部首201、附形部首99**，为工具书与信息化定分止争。
:::

::: example 部首归类的三桩悬案 {#ex-sanhua}
“为、闻、颖”在三套系统里各查什么部？
::: solution
“为”：无成字部首可归，归**丶部**（取首笔，检字规则“查不到部首查起笔”的典型）；“闻”：门部（外形优先，虽然义符在“耳”）；“颖”：《说文》系归**禾部**（形旁），《新华字典》按现代字形查**匕部或页部**均可通过难检表旁及——形义分离的部首系统里，“该字实际收在哪”永远比“该字该在哪”更有发言权。
:::
:::

::: intuition 孩子眼里的字是图画，字典眼里的字是套娃
一年级学生写“树”会自己总结“木、又、寸三个部件”，写得对但拆层不对（规范的多层分析是“树→木＋尌，尌→壴＋寸”，而“木、又、寸”的俗拆也不为无因——部件层级本就允许多套分析，只要自洽）。语言是：**分析有公理，字没有唯一答案**——部件学、部首学是“够用就行”的工程学科，标准统一才有交流。这恰是本章与下一章（简化与规范）的接口：标准一旦发布，写字、查字、排序、输入法编码全跟着它走。
:::

::: example 四角号码：绕开部首的另一条路 {#ex-sijiao}
为什么1920年代要发明四角号码检字？请说出部首检字的两大痛点与四角号码的对策。
::: solution
痛点一：不知部首（“彙、为、凸”之困）；痛点二：部首在字的位置不定（上下左右内外皆有），翻找成本高。四角号码（王云五1925年提出）干脆取消部首，取字之四角各一**笔形**编成四位数字（附一位补码），能看字就能写码——“端、放”一类生僻字检索立等可取。代价是笔形判别的主观歧义与口诀训练成本，最终它败给了拼音检字（1978年《现代汉语词典》以降），却在“知形不知音”的档案、古籍整理中保有一线香火。检字法的竞争史说明：**检索系统的优劣不在原理优雅，在用户门槛**。
:::
:::

::: history 一个字的笔画之争：以“乃”与“与”为镜 {#sec-naiyu}
“乃”行书连写一笔而就，楷化规范定为两画，俗写一笔者大有人在；“与”的笔顺（横、竖折折钩、横）在课堂内外长期打架。这类小案的公开处理程序是：教师与出版单位按规范执行、规范修订时依调查改——笔画的确定性，是现代国家给文字世界的第一张“身份证号码表”。1955年《第一批异体字整理表》与1965年《字形表》《笔顺规范》一脉相承：**先定形，再定序，最后才能定“典”**。
:::

::: summary
层级三件套：笔画（五类：横竖撇点折）→ 部件（成字/非字、形旁/声旁/记号、五种布局）→ 整字；部首是检索单位而非结构单位，540部（说文）→214部（字汇、康熙字典）→201主部首（2009国标）。笔顺八规则加专字专规，权威是1997《笔顺规范》；印刷字形的新旧之变在1965《字形表》一锤定音。永字八法是笔法口诀、非笔画统计；部件分析切单层、到最小功能件为止；部首归类、四角号码与拼音检字的更替，写尽了“门槛优先”的工具演化律。
:::

::: exercise 笔画统计 {level=1}
数出下列字的规范笔画数：“凸、爽、四、乃、乃”? 重复——改：“凸、爽、四、为、火”。
::: solution
凸5、爽11、四5、为4、火4。“四”五画（竖、横折、撇、竖弯、横——末笔是长横封口，别把“撇”漏成竖弯）；“爽”十一画（大＋四个“ㄨ”）。

::: exercise 找错 {level=1}
指出下列说法的错误：①“永字八法包括了全部八种基本笔画”；②“部首就是最有意义的部件”；③“笔顺对了笔画数才能对”。
::: solution
①八法是笔法口诀，按现代五类笔画算“永”并不齐（缺折类）；②部首是排序单位，未必表义（检字系统里“为”归丶部）；③两半句互不成条件——笔顺与画数是不同维度，错顺可能数对、对顺可能数错（拆并笔画时）。
:::

::: exercise 部件切分 {level=2}
对“赢、裹、街、国”做单层直接构件切分，并标注每个构件的类型（成字/非字、可表音义/记号）。
::: solution
赢：《说文》“从贝，嬴省声”，学术切分先分“嬴省／贝”两层；通行的“亡口月贝凡”是便于记写的多层俗拆——两说皆可用，但须注明自己是哪一层；裹：从衣、果声，“衣”从中剖开裹住“果”（所谓穿心结构）；街：从行、圭声，“行”分作左右两半成字；国：囗＋玉（囗范围符号、玉义符；“玉”是否兼声有争论）。本题重在“先切直接构件、再谈功能”，凡把“赢”一口气拆五件而不分层者扣分。
:::

::: exercise 检字实战 {level=2}
不用拼音，分别用部首法、四角号码法、笔画排序法查出“彧、杌、耄”的归属：各写部首/号码首角/所在起笔类，并报告每种方法“会不会卡壳”。
::: solution
彧：主流字典收“彡”部，若不知部则依起笔横类难检表旁搜；杌：木部，首笔横（提手旁、木字旁首笔同归横类）；耄：老部（变形“耂”头）、起笔横。卡壳点是诚实报告的重点：彧易卡（不知部）、杌不卡（形旁明显）、耄半卡（老部变形“耂”认不认得出）。体验结论：部首法的门槛在“部首变形与归属记忆”。
:::

::: exercise 小论文：笔顺该不该“从俗” {level=3}
“火、必、为、与”等字的笔顺长期存在“教学规范”与“大众俗写”双轨。写一篇八百至一千二百字的短论：笔顺规范应不应该向俗写让步？要求引用本章“规范问题三场事故”的框架，并各找一个反例。
::: solution
判分点：立场明确且成理（让与不让都能写好）；正确使用“事故框架”（检字、考核、排序）——让步论多从手写连贯性、认知负担立论，守成论强调标准稳定与信息处理一致；反例真实（如“乃”一笔俗写造成两画统计失灵的实例，或“九”先折后撇俗顺导致排序错位的设想案）；结论给出可操作方案（如“教学单一规范＋社会双轨共存、检字系统以规范为准”）者加分。
:::
