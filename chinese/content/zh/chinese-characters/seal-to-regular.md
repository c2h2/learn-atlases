把一片甲骨上的“為”和楷书“为”并排放：上面那只牵象的手，下面只剩四笔横折钩点。中间这三千年发生的事，术语叫**隶变**——古文字时代的一场“拆屋重盖”，也是本课最该装进脑子的一段工程史。这一章讲清楚四种常用字体（篆、隶、草、楷）各是什么、谁先谁后、为什么变，以及变完之后那个要命的问题：**为什么今天的字“讲不通道理”的地方，多半都在隶变的刀口上。**

## 字体名目：先认牌再打牌

::: definition 大篆、小篆与“篆” {#def-zhuan}
**大篆**是后世对秦统一前西周—春秋战国文字的习惯统称（金文、石鼓文、六国古文都在这个大筐里，筐本身不精确）；**小篆**专指秦规范后的官方正体——《说文》所录 9353 字即以其为字头系统，相传李斯作《仓颉篇》、赵高作《爰历篇》、胡毋敬作《博学篇》为字范（三篇皆佚，名目见于著录）。小篆的性格：线条匀圆、结构修长定形、一字一形——**汉字史上第一次全国性字形标准化**，虽然标准是靠文书行政与吏学传承推行的。
:::

::: definition 隶书：名字就说明出身 {#def-lishu}
**隶**字本义及“附属、差役”，隶书得名于“佐隶之事”——日常文书求快，把篆书婉曲的长线条**解散**为平直的短笔画：圆转变方折、长线拆横捺、构件混同省并。考古所见，**战国秦系俗体已开其端**（睡虎地秦简、青川木牍是“古隶”），西汉通行成“汉隶”（东汉碑刻的“蚕头雁尾、一波三折”是它的艺术巅峰而非日常常态）。隶变完成了古今文字的分水岭：自此**字形不再依赖构形理据**，汉字从“据义辨形”的体系转入“记号为主”的体系（[[chinese-characters/writing-and-language]]的“理据四尺子”自此少了一尺硬杠杠）。
:::

::: definition 草、行、楷 {#def-cao-xing-kai}
**草书**起于隶书的连笔急就（章草—今草—狂草一条艺术线），**楷书**（真书、正书）出于汉末新隶之省变——钟繇被推为早期大家，至魏晋与行书（介于楷草之间，“真行”相杂）同经二王父子手笔定型，隋唐成为官定正体并沿用至今。注意次序的陷阱：**草书并不“在”楷书之后**，草、楷、行长期并行互摄——字体谱系是一棵分叉交错的树，不是单列纵队（见下图）。
:::

## 隶变：汉字的一次“重构”

::: theorem 隶变的四把手术刀 {#rule-libian}
（一）**笔画化**：线条改笔画——篆书一“垂”下来的一笔，拆成横、竖、撇、捺，字形由“图”变成“笔画串”。（二）**混同**：原来不同的构件合并成同一形状（“服”的左半、“燕”尾与“鱼”尾——多个来源同形，理据就此掩埋）。（三）**省并**：重复部件合写、繁难部件删节（“灋”省作“法”，廌、去、水三件存二；诸如此类，以省并字表为准）。（四）**音化与重分析**：给难解的记号换个“会意”的新解释（“射”本像弓上搭箭，隶定后成了“身＋寸”，汉人遂有“寸身之射”一类附会——俗理据顶替了古理据）。
:::

::: proof 为什么非变不可
驱动力从来只有一个字：**快**。战国的外交文书、秦帝国“以衡石量书”的日课、狱讼簿籍——刀笔吏在竹木简上以毛笔疾书，圆转的篆“写不快”，于是省、连、方、直。朝廷的标准体（碑刻、虎符、诏版）与小吏的日常体像一条河的水面与河底：水面平静，河底暗流冲出了新河道；等隶书已经写定，朝廷碑刻（熹平石经用隶书）才追认——**字体史是“俗体造反、雅体招安”的循环**，楷书接隶班、宋体字腔接楷班，莫不如此（[[chinese-characters/strokes-radicals]]的印刷字形另有一账）。
:::

::: example “為”字三千年档案 {#ex-wei}
逐层描述“為”的字形史并判定理据存亡：甲骨作手牵象；篆文省变；隶楷作“爲”，简化字作“为”。
::: solution
甲骨从“手”引“象”，说“作为、劳作”之义（象助耕役之说，学界习用而语源仍有讨论）；战国楚系、秦系各自省变，篆文承秦系，手形已讹；隶变把象形部分压成一串不可解读的折笔记号——**古理据全断**，今人拆“爲”为“爪＋母”式说解皆属再诠释；楷书“爲”草化俗写，最终简化字取草书之形定为“为”——**新理据干脆没有，靠认读强记**。一个字走完“图画—构意—记号—草定”全程，教科书级的标本。
:::
:::

::: example “曰”与“日”的陷阱 {#ex-yue-ri}
隶楷里“日、曰、目”三形只差一点一横，篆以上呢？为什么小学生的“区别字”难题，恰是隶变的纪念品？
::: solution
篆书以上三字形界分明（日中一实画、曰（开口呼气之形/或曰口上一画）与目（竖睁双眶）各不相干）；隶变把椭圆框一律压成方框，区别只剩**框内一笔的形态**——混同手术的后遗症。这解释了两件事：一是古籍翻刻中“曰/日”互讹是校勘学常客；二是识字教学中“形近字”难题几乎全出自古隶变后的记号化——不是孩子粗心，是三千年前那一刀切得太齐。
:::
:::

::: theorem 标准化的国家传统 {#rule-biaozhun}
字体史的另一半是**正字法政治**：秦“书同文”以小篆范天下、以隶书行于官事（正俗两轨并用）；东汉熹平石经，蔡邕书丹刻石、正定五经文字于太学门外（时“乘车看视者日数千百辆”），魏**正始三年**（242）立**三体石经**，以古文、篆、隶三种字体并刻——同一部经典，替三个时代的字形建档；唐颜元孙《干禄字书》分“俗、通、正”三体司科举书写，开后世正俗字书之先。规律一句话：**每次字体换代期，必有一波国家正字工程**——因为“怎么写算对”直接决定考试、法令与经典的可信度。
:::

::: remark 书法侧的账
字体演变与书法艺术互为因果但不同账：篆的“玉箸”、隶的“蚕头雁尾”、楷的“永字八法”，都是**字体特征的风格化**；反过来，名家的笔迹（钟繇、二王、欧褚颜柳）会被后人翻刻成**新的字形标准**——今天宋体字的骨架即经雕版与写刻双重过滤的唐楷。因此看一件碑帖，要分三层读：它是什么字体（史）、什么书风（艺）、被谁刻成何样（版刻层）。本章只需记住一个事实：**我们写“楷书”，其实是把一千六百年前最流行的“草”（新体）供成了正楷**——钟繇的“章程书”在当时也快得很。
:::

::: intuition 笔画是笔顺的化石
今天的笔画形状，其实是**运笔动作的遗存**：撇是向左下快送的收笔渐提，捺是右下按顿后的一拓，点是笔尖最短的一次触纸，横是右手左向自然弧线的拉直。儿童与初学者的“倒笔”习惯（把撇写成竖、点写成捺），恰与隶变时大众“把线写成画”的混乱隔代同构——两千年前的吏员在竹简上干的，和你在田字格里干的，是同一场笔画化。明白了这一点，笔顺规则就不再是戒律：它是让笔尖按最省力的路径复现字形史。
:::

::: application 拿到一张旧拓，先做三步体检
一看**笔画指纹**：蚕头雁尾？玉箸匀线？提按顿挫齐备？——字体年代粗判。二看**结构体势**：修长取纵势多近篆隶，方正平直近楷，欹侧连绵属行草。三看**载体与工艺**：碑刻看刀意（方笔未必是书写原貌，刻工能造出“折刀头”），法帖看刻痕与墨迹的代际（宋拓、明拓字口肥瘦不同），简牍帛书看朱墨笔顺。最后一步是查：著录、藏地、拓工、翻刻谱。一套动作做下来，你已从“看字”进入“读材料”——这正是一切书法史、字体史功课的地基（[[calligraphy]]的入门方法即此）。
:::

::: history
这一千五百年的标准件是几批石头与竹木：云梦睡虎地、天水放马滩诸批秦简（合计数千枚）让“隶起于秦吏”从传说（程邨隶书之说）变实物；临沂银雀山、马王堆、定州诸汉简铺开隶变的每一年轮；洛阳曹魏正始三体石经残石、山东熹平石经残字（及后世翻刻）立起“官方字表”的坐标；到唐开成石经，以隶定楷书再刻十二经——每一次王朝觉得自己有义务把“正经的字”刻给天下看。书手一边，钟繇的《宣示表》以摹本存形，二王法帖以刻帖化身，欧褚颜柳的碑成为印刷字腔的祖本——字体史从不在博物馆里，它正在你屏幕上这套“思源黑体/宋体”的字腔里值班。
:::

## 后续内容

隶变之后，“字怎么拆”换了规则系统——部首与笔画的现代账在[[chinese-characters/strokes-radicals]]；“六书”分析古文字一把好手、对付隶楷常失手的原因（[[#rule-libian]]的混同与重分析即其一）在[[chinese-characters/six-categories]]；书法三门：笔法、结构、碑帖，归[[calligraphy]]。作业：挑五个最常用的偏旁（氵、阝左、阝右、月（肉）、艹），各写两例“古理据已断、俗字源可讲”的字，下章带来对账。

::: summary
- 四大名目认清：篆（大篆泛称/小篆秦正体）、隶（俗快写升格，古今分水岭）、草（先行且自成一艺术线）、楷（新隶省变，魏晋定、隋唐官定）。
- 隶变四刀：笔画化、混同、省并、重分析——理据大面积下架，汉字转入记号为主时代。
- 演变动力是书写速度（俗体造反），官方以正字工程招安（石经、字书）——字体换代期必有正字运动。
- 书法与字体两本账：今天的楷书与印刷字腔，都是当年的流行快写加历代翻刻的合力。
:::

## 习题

::: exercise 三体石经 {level=1 check="242"}
曹魏三体石经立于公元哪一年？“三体”指哪三种字体？它为何是字体史的“坐标器”？
::: solution
242 年（魏正始三年）；古文、篆、隶三体并刻。同一部经三种时代字形并列，等于官方公布一份**跨时代字形对照表**——断代、校勘、字史研究各取所需（[[#rule-biaozhun]]）。
:::

::: exercise 字体排排坐 {level=1}
把下列语料按字体与大致年代归类并说明判据：①蚕头雁尾的整碑；②匀圆长方的诏版；③连笔急就、字字区分的早期草；④《说文》字头。
::: solution
①汉隶（东汉碑刻艺术化阶段）；②小篆（秦诏版，正体官器）；③章草（存隶意、字字不连）；④小篆系统（兼存古文、籀文）。判据各一：笔形（波磔）、线条（玉箸）、字间（独立）与体例（字书）。全对不难，难的是**每条判据说得出**——认字体即认“笔画指纹”。
:::
:::

::: exercise 排队断代 {level=1}
把下列“字体语料”按出现先后排序：①曹全碑式整碑；②睡虎地秦简；③小篆诏版；④三体石经；⑤二王法帖摹本。再各配一条断代判据。
::: solution
顺序：③秦（前221后）→②战国末—秦（古隶）→①东汉碑（艺术隶）→④242 年（古今篆隶并列之石）→⑤东晋（今草、行楷之熟）。判据各一：诏版正体/秦简古隶波磔未备/汉碑蚕头雁尾/石经三体例/法帖楷行成熟。本题练的是“字体坐标系”——先有年代轴，再谈演变因果。
:::
:::

::: exercise 混同侦缉 {level=2}
隶变把不同来源的构件混成同形。举出至少三组“今同形、古异源”的例子（如“月”旁与“肉”旁;“服”的左旁、“有”的下部? 以可靠字例为准），并说明这类混同给“据形说义”设下的坑。
::: solution
安全例：①左“月”旁实多“肉”（腿、肌、背）；②“春”篆从艸从日表示、屯声，隶定后声符亡形，与“秦、泰”共头而同源异实；③“有”下从“肉”（手持肉之形）今亦作“月”。坑的机制见“射”案（[[#rule-libian]]第四条）：混同后的拆字讲“理据”多是层后加建，凡“从某从某所以某义”的说法先问一句**隶变前长这样吗**——这一问能挡掉九成民间字源学。
:::
:::

::: exercise 给一场造反写招安诏 {level=2}
以东汉某朝官口吻写二百字奏疏，主张“以隶行文书、以篆存经典”（提示：正俗两轨之利、经典字体之神圣、公文效率之切）。
::: solution
要点：①承认现实——狱事簿书非隶不办，强民作篆是刻舟；②守住象征——郊祀碑铭、经典写定宜存篆隶以见“字统相承”；③给出配套——立字学、课童史、石经校字，把两轨都纳入官学。判分看立场平衡度（一味崇古或一味趋易皆失分）——真实的政策讨论从来发生在两轨之间，熹平、正始、开成三次石经都是这份奏疏的施行细则。
:::

::: exercise 小论文 {level=3}
“字体演变的动力在效率，字体的稳定靠制度。”结合本章材料（秦隶并轨、石经三次、印刷字腔）写一篇四百字短评，并回应一个反例式质疑：“如果效率至上，为什么汉字最终没走拼音化？”（可引[[chinese-characters/writing-and-language]]的三条件作答。）
::: hint
材料可用：本章正文与图；“书同文”诏版实物数；三体石经残石存世情况可查《中国大百科全书·语言文字》卷。
:::
::: solution
参考骨架：论点一，俗体推力实证（隶、草、行全出身快写）；论点二，制度拉力实证（每次换代期的正字工程与考试指挥棒）；论点三，拼音化未成的三条件（语素成块、方言鸿沟、字书锚）恰在“稳定”项加码——效率改变**字形**从来成功，效率想要**换系统**则撞上整部社会结构。结论落点：汉字史=速度与制度的拔河，绳子中间的红布条叫“通用字表”。判分看是否正面处理反例而非绕开。
:::
