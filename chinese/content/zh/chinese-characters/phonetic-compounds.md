“读半边”这件事，语文老师骂了几十年，语言学家却要替它说句公道话：**读半边在造字时代基本是准的**，不准是三千年的音变在退账。声旁是汉字系统里埋着的一套音韵档案——会读它的人，识字快一倍，猜古音十拿九稳，连背英语拟声词都多一副耳朵。这一章办三件事：给声旁“确权”（它当初凭什么记这个音）、给“不准”立案（语音规律的对应表）、给使用画线（什么时候能读半边，什么时候读半边就是错字）。

## 声旁的确权：谐声系列是什么

::: definition 谐声系列 {#def-xiesheng}
同一个声符（音符）孳生的一组形声字构成一个**谐声系列**：如“青”族（清、请、静、精、睛），“也”族（地、池、驰、施、蛇）。系列内的字在**造字时代**声韵相同或极近，韵部则几乎总是同部——这是高本汉以来两千余系列统计的大结论。谐声系列是汉语史的核心数据源：上古声母系统的构拟（复辅音之争全靠它）、《诗经》用韵的旁证、方言与对外译音的连结点，全在这张表上（[[phonology/old-chinese]]）。
:::

::: theorem 声旁的三种出生 {#rule-chusheng}
被拿去当声符的字，出生方式有三种：**借音字**（本无其字，写同音字：也、它）、**同族分化**（新旧词本出一源，造字相承：“干”为岸义本字，“旱”为干燥分化字而音同相承；本义被借走、原字留下记音）、**纯粹记音**（形声造字时直接选一个音近字挂牌：青、工）。三种出生解释了声旁的两个脾气：一是**音近即可**（不必全同，方言与时音有宽容度），二是**义常有鬼**（同族分化的声旁顺手兼带一点义，所谓“声中有义”的合理内核，语源学的入口；但拿它推一切字的“右文”，就滑向看图说话）。
:::

::: example 一族四声母 {#ex-gui}
“圭”读 guī，它的族人却四散：珪 guī、闺 guī、桂 guì、眭 suī、畦 qí、娃 wá、鞋 xié、街 jiē。请用谐声律与对应律解释这场四散。
::: solution
先确权：谐声时代（上古）这一族声母同居见系（k 类）——“畦、娃、鞋、街”今读的零声母、x、j 是各自韵母环境下历时音变的分叉：见母细音腭化出 j、x 路（街、鞋、眭之变各有师承，学界拟音不一），合口洪音前保住 g/k 路（珪、闺、桂）。“圭”读 guī 反倒是族内保守派。结论：**同族 ≠ 同今音；同族 ＝ 同一段被切片的历史录音。**声旁不认拼音方案，它认三千年前的音节。
:::
:::

## 不准的规律：音变是守法的

::: theorem 对应律而非个案律 {#rule-duiying}
今音与声符的偏差大头走**规则对应**：（一）**腭化**——g、k、h 在细音（i、ü 及 i、ü 开头韵）前变为 j、q、x：经典例：**“工 gōng—江 jiāng”一对**——同为见母，洪音前留守、细音前改姓；“家（古牙切）jiā—古 gǔ”再证一例。同一位祖先按韵母环境分家，声旁把两岔的子孙都登记在族谱上。（二）**浊音清化**：中古全浊声母按“平送仄不送”清化，同族因平仄分派生出送气差（“皮”平声送气 p-，其族“被”“坡”一路清化各走各路）。（三）**韵部分合**：主元音与韵尾历次合并，使同族韵母今天只剩“亲戚关系”而非“同韵关系”。三律一过，“读不准”剩下的小数才是真例外（俗读、训读、方音改字）。
:::

::: proof 为什么音变能这么“守规矩”
因为音变作用于**一类音**而非一个字：当北方话决定“g、k、h 遇 i 要腭化”，它不查字典、不分熟字生字，一律执行——除非被隔音、轻声、借字等条件挡住（词汇扩散理论讨论的正是“执行得多整齐”）。这就是历史语言学的承重墙：**语音规律无例外**（新语法学派口号），例外要么揭示更深的条件（音位环境、类推），要么根本不是语音变化（训读、借用）。谐声系列是这面墙最漂亮的验尸报告：两千组系列的“错乱”几乎全部能排进几十条对应，剩下几条成了学界的名案（如某些“晓母—明母”互谐争议）。
:::

::: example 什么时候读半边 {#ex-bianbian}
按现代规范音给下列“读半边”判分：①“诣”读作“旨”；②“栈”读作“戋”；③“酗”读作“凶”；④“眈”读作“尤”——“眈”从“冘”声，冘今音 yín，而“眈”规范读 dān。
::: solution
①错：“诣”规范音 yì，与“旨”zhǐ 声韵俱远，属三律之外的硬例外（查《广韵》五礼切可追账）；②错而近理：“栈”zhàn 与“戋”jiān 韵近声异（上古端元类相遇，中古各投一路），类推只能到“近音”为止；③典型俗读：“酗”规范音 xù，读 xiōng 是被“凶”形拉偏的传媒高频事故；④“眈”dān 从“冘”声而声韵皆迁，读半边必错。支持率衰减的三台泵：**生僻、断层、俗读**。口诀一句话：**认字认全字，猜音猜一族；单字不可信，系列可参证。**
:::

::: history
声旁的学问几乎与《说文》同岁：许慎“从某、某声”的术语就是谐声学的第一次总登记；清代段玉裁“同谐声者必同部”一声断喝（《六书音均表》），把古韵分部从十部推到十七部，谐声正式成为构拟古音的正牌证据；高本汉 1923 年起以两千余系列表检验上古声母，曾运乾、陆志韦、董同龢、李方桂一路增补，复辅音假设（*kl-、*ml- 类）从惊雷变常谈；当代郑张尚芳—白一平—沙加尔体系里，谐声与藏缅对照、方言存古层、汉字文化圈域外音三方会审，一个“各”字能写出半部上古音学术史。一句话：**声旁是汉字给语言学留的钥匙。**
:::

::: definition 谐声律 {#def-xielü}
统计事实两条：**（一）**谐声时代，同声符字声母相同或极近（同发音部位、同方法为常，邻纽通融为例外）；**（二）**其韵部几乎必然相同（或严格对转）。“几乎必然”是量化结论：对《说文》九千余字做系统检验者，韵部出组的比例不足百分之几，且集中于晚起字与传写讹字。这两条就是“谐声系联”能当古音证据用的执照，也是“读半边”在某些场合“莫名准”的数学地基。
:::

::: intuition 声旁是儿童与外国人的识字加速器，也是他们的陷阱
七岁儿童学“请清晴睛”时自发总结“右边念 qing”，效率暴涨——这是民间谐声律的自然习得；随后他念出“青色的‘青’读 jīn”式错误，再被纠偏。母语者对声旁的信任在小学三四年级达峰、五年级被“误读扣分”打落，此后终身半信半疑。本课程的目标是重建**成年人的信任**：知道声旁的有效期（上古—中古）、知道三律的汇率表、知道查证的门路。识字教育研究的共识大体如此：声旁意识强且被正确引导的学习者，生僻字猜读命中率与词族记忆都显著占优——工具无罪，误导在于“只教准、不教不准”。
:::

::: example 量一量你的直觉 {#ex-直觉}
不查字典，凭声旁给下列字定调（声调也算音）：“兑、炬、殉、诣、粒、帖”。然后查《现汉》，对答案。
::: solution
常见内心答案：兑 duì（对）、炬 jù（对）、殉 xùn（对，声符“旬”xún 只差调）、诣 yì（多数人错读 zhǐ）、粒 lì（对，“立”同音）、帖 tiē/tiě/tiè（三读，声符“占”只给近似）。五比一，正是成年人声旁信任度的真实水位。把这题留作“体检”：以后每遇生字先猜后查，一个月，你会重新校准对这位三千年老员工的期望值。
:::

## 应用：认字的统计学与词源的好奇心

::: application 一字之差四个音：音序里的声旁课
“祗 zhī（敬）、祇 qí（地神，又读 zhǐ）、柢 dǐ（根本）、低 dī、纸 zhǐ”——右半在“氏、氐”两点之间纠缠千年（“氐氏之辨”），一字之差牵出四个声母，恰是声旁系联失效区的全息样本。查字典音序时，认对部件＝选对读音＝排对页码；写错部件＝查无此字。同样地，“部署”误“布署”、“脉络”误“脉洛”，一半是默写里“读半边”失控。**把声旁从认字拐杖升级成系联工具**（记一族、带一串、错一查三），是这门课替语文课补的那张账单。
:::

## 后续内容

谐声与上古声母构拟的正面课程在[[phonology/old-chinese]]；六书框架内的形声定义在[[chinese-characters/six-categories]]；“声中有义”与词源学的边界在[[history-of-chinese/lexical-history]]；词汇层面“字族教学”的展开见[[modern-vocabulary]]。练习建议：给“也、工、青、各、圭”五族各列二十字，标注今声母，统计“准/不准”比例并尝试按对应律归类——做完这一课，你对“读半边”的态度会变成对一位老人的态度：尊重，但别全信。

::: summary
- 谐声系列＝同声符孳生字的家族；造字时代声韵相同或极近、韵部几乎恒同。
- 声旁三种出生（借音、同族分化、纯记音）解释其“音近即可、义常有鬼”两脾气。
- 今音“读不准”大头走规则对应：腭化、浊音清化、韵部分合；例外才是真学问的入口。
- 语音规律无例外＋词汇扩散：声旁是音变守法性的验尸报告。
- 实用立场：认字认全字、猜音猜一族；读半边是统计工具不是特权。
:::

## 习题

::: exercise 系列清点 {level=1}
写出“工”声与“主”声的谐声系列各六字，标今音，算出与声符今音完全一致的比例。
::: solution
工族：功 gōng、攻 gōng、贡 gòng、恐 kǒng（下从心）、项? 非族——换“紅 hóng”、空 kōng、控 kòng；主族：注 zhù、住 zhù、柱 zhù、蛀 zhù、炷 zhù、砫? 换“徏?”换“珠 zhū”“蛛 zhū”。完全一致比例（与 gōng/zhǔ 全同）：工族 2/8≈25%，主族视“主 zhǔ/注 zhù”调别而 0—30% 区间。本题的真目的：**亲手量一次“准”与“不准”的比例**，比任何说教都更牢。
:::
:::

::: exercise 腭化配对 {level=1 check="3"}
现代汉语 j、q、x 三个声母，历史来源中的老三家是哪三母（写声母字母或“牙音”名目亦可）？据此判断“家、去、虚、告”四字里今读与古声母已经“换脸”的有几个（不计两读）。
::: solution
老三家：**见溪群（g、k、[g]）腭化为 j、q、x**（影晓组细音另线）。换脸字：家（见母→j）、去（溪母→q）、虚（晓母→x，属影晓线）——告未换（gào，洪音前原样）。若从宽只算见溪群线：家、去两字，“虚”注晓母腭化亦可计分。
:::
:::

::: exercise 调类侦探 {level=2}
“共、供、恭”同源相因（见母东韵去/平诸读），“被、皮”同族异级——用“平送仄不送”与浊音清化表，解释“群母字今读不送气 k 与送气 kʰ 并存”的一种合法来源，并各举一字。
::: solution
主通道两条：①全浊平声送气化——“奇”（群母平声→qí）；②全浊上、去声（仄声）清化为不送气——“巨”（群母语韵上声→jù）、“共”（群母用韵去声→gòng）。故同一古声母今分 k/q 两路属清化条件分工，不算例外。判分看能否把“条件”说成环境（声调/等第）而非背例。
:::
:::

::: exercise 例外捕手 {level=2}
“皆 jiē”从“比 bǐ”声。请按三律检查：这是腭化、清化、韵部哪一路的问题？能否排进对应？排不进时你的备用解释是什么？
::: solution
“皆”上古见母质/脂类韵，“比”帮母脂部——声母 k/p 相差在**复辅音或邻纽**假设里安顿（“比”有频眉切、房脂切诸又音可作桥），韵则脂皆旁转。学生答案允许三种姿态：存疑、引复辅音说、引又音说——但必须写明“这是三律管不到的硬案”，不许硬掰。
:::
:::

::: exercise 小论文 {level=3}
“右文说”（宋人王圣美创导：声符兼主义，如“戋”有小义——浅、钱、残、盏诸字皆含“小、少”意味）是词源学的先声还是文字游戏的歧途？写四百字：举它做对的一例、做砸的一例，并给出“声中有义”的**可操作检验标准**（提示：音义同步＋文献书证＋非孤证）。
::: hint
材料：沈兼士《右文说在训诂学上之沿革及其推阐》；任一《源字》类词典翻“因声求义”凡例。
:::
::: solution
做对例：“仑”族——伦、理、论、抡皆含“条理、次序”义素，族内多数共义且有书证，词源学至今认领（“伦者，理也”一类旧注即其先声）。做砸例：凡强行“每声必含义”者，撞在同族借字上即崩。可操作标准：①该声符族的**多数**成员共有某义素；②古书有用例；③非孤证（族外无平行反例）。判分看能否区分“统计倾向”与“逐字判决”。
:::
:::
