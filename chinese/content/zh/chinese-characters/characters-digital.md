---
title: "数字时代的汉字"
---

汉字曾被断言“活不过计算机”。1980年代，“不能进入信息时代”几乎是汉字落后论的铁证；四十年后，中文是互联网上产量最大的语言之一，键盘与屏幕对汉字毫无排异。本章讲这场绝地翻盘的工程史——**编码、输入、字形、识别**四大发明——以及数字时代给汉字带来的新病与新玩法。

## 编码：给汉字上户口 {#sec-bianma}

::: definition 从区位到统一码位 {#def-quwei}
电子计算机只认二进制，汉字上机的第一步是给每个字分配**号码**。中国第一条高速公路是 **GB 2312—1980《信息交换用汉字编码字符集·基本集》**：收繁体以外的规范汉字6763个加符号682种，按“**94个区×每区94位**”排成方阵（一级字按拼音排、二级字按部首笔画排）。由区位到机内码的口诀是每级各加160（十六进制的A0）：如“地”在第21区21位，区位码2121，国标码即3535（十六进制），机内码B5B5。**BIG5**（台湾，1984）以42021—87797等双字节段收字一万四千上下，与GB各自为政的十年正是中文乱码的黄金年代。
:::

::: theorem 两千年同文，两千年异码 {#rule-yima}
GB、BIG5、EUC、Shift-JIS、KSX——汉字文化圈各造码表，同一段文字换个环境就是“锟斤拷烫烫烫”。出路只有一条：**一个世界一张表**。1991年Unicode联盟成立，与ISO 10646“共同准则、一次编码”联动的工程把全世界文字编进一张十万级码位的总表（现行标准收录字符逾十五万）；其中**CJK统一表意文字基本区**（U+4E00–U+9FFF）收20,992位，扩展A（6592字）、扩展B（42,711字）直到2024年Unicode 16.0的扩展H，**总计数万字**。当年的“万码奔腾”，终结于“一字一码、全球统一”。
:::

::: example 一个码位，几张面孔 {#ex-yima-duoxing}
“强／強”“户／戶”在两台设备上是同一码位吗？为什么显示不一样？人名里的扩展区字（如“𬀩”）在老系统里成了方框，问题出在哪一层？
::: solution
统一码位只登记**字位**不登记**字形**（汉字统一的最大妥协与最大智慧）：“强”与“強”“戸”与“戶”多为同一码位的**地域变体字形**，由字体（或 `lang` 渲染环境）决定长相；“𬀩”显示成方框说明**字体层**缺字形（码位有户口、字库没盖房）——解决顺序是：升级字库→装厂商扩展字体→最次用PUA（私用区）造字或贴图。三层（码位/字形/输入）各自的病，要先定位再吃药。
:::
:::

## 输入与印刷：从“万码奔腾”到“预测即输入” {#sec-shuru}

::: definition 输入法的三代 {#def-sr}
**音码**：拼音、双拼、注音——零门槛，靠同音消歧；**形码**：仓颉（朱邦复，1970年代末）、五笔（王永民，86版）——按字根拆字，重码少、熟手快，学习成本高；**第三代（智能整句）**：2000年代随手机与云计算成熟，整句语言模型预测把“输入”变成“挑选”，速度天花板让位于输入法背后的语料规模。市场更迭（智能ABC→搜狗拼音2006→手机内置智能输入法）的实质是：**消歧的主权从人手里移交给了模型**。
:::

::: history 748工程：把汉字塞进激光的那十年 {#sec-748}
1974年8月1日，“汉字信息处理系统工程”（748工程）立项，王选团队的任务是汉字激光照排。核心难点不是激光而是**汉字轮廓信息的海量存储与复原**——王选以参数化轮廓描述（“用数学函数描述笔画”）加专用超大规模电路把放大百倍的字形实时还原，1979年压排首张样报、1981年通过鉴定、1980年代中期起让报社铅字退役，北大方正由此成产业。没有这一仗，中文印刷不知还要在“铅与火”的熔炉边困多少年——“结束了铅与火的时代”，是这一代工程留给报业的公论。同期另一战场是“进入PC”：中文卡、汉卡、中文之星（1992）、倚天RichWin（1994），直至Windows原生支持——硬件、软件、字库三位一体补齐，1990年代末中文互联网开始爆发。所谓“汉字告别信息时代”，最终被证明是**工程问题，不是文字问题**。
:::

## 数字时代的字病与新玩法 {#sec-bing}

::: example “蓝瘦香菇”是别字吗 {#ex-lsxg}
用[[chinese-characters/standard-characters]]的“三轨计过”诊断下列网络书写：①蓝瘦香菇（难受想哭）；②“awsl”式拼音首字母；③同一条消息，一台设备显“强”、另一台显“強”；④“砼”（tóng，建筑界造的会意字）进公文。
::: solution
①**有意的谐音修辞**（方言梗玩梗，主体明知正字）——不是病，是文体；但若迁移进正式文本则按错处理；②**字母代码语篇**（拼音首字母造词），是行话与圈层暗号，跨圈即失效；③**字位—字形层面的正常现象**：同一码位不同字体地域字形，不构成任何错误，却常被当成“你打错了”；④**行业自造字**（就像上文的“砼”）：规范字表边缘的“行业专字”，公文须改“混凝土”。诊断结论：网络不是“字崩”，而是**语域分裂加剧**——每个圈层自定合法书写，规范问题从“对错”转为“得体”。
:::
:::

::: intuition 提笔忘字：衰退的是哪块肌肉
实验心理学的定位很准：受损的是**运动性产出**（手的笔画程序），不是**识别性知识**（眼与脑的字形库）——所以你能一眼认出“尴尬”两个字，却写不出左半。数字输入没有削弱“识字”，只是把产出通道从“逐笔书写”改成了“整字选择”；正如计算器没有削弱数感的人，只淘汰了只会算的人。“该不该焦虑”的判据在用途：若写字只剩签名与书法，那是审美事务；若职业仍需手写（医疗文书、批注、教育），产出通道就得刻意保养。
:::

::: warning 三个流行误解
（1）“Unicode 统一是把中韩日汉字合并成一种字”——统一的是**码位**，字形变体照常保留（由地区字体与字形规范分别渲染）；（2）“字库缺字怪 Unicode 慢”——缺字常是**主权问题**：人名用字需提交 IRGN/ICC 国际提案评审，从提交到进码表以“年”计，地方公安的“生僻字人名”积压正是这条流水线的瓶颈；（3）“键盘时代汉字会被拼音文字取代”——四十年技术史给出的方向恰好相反：拼音输入法**提高**了汉字的输入速度上限，屏幕反而让汉字文化圈的年轻一代写更多的汉字（发送量意义上）。
:::

::: history OCR 与古籍：让机器读一千年的字 {#sec-ocr}
汉字识别是模式识别教科书里的常驻难题（几千类、形近、粘连）。印刷体 OCR 1990年代随扫描仪普及商品化；手写识别 HTR 在手机与银行单据场景磨了二十年；真正的分水岭是**古籍与出土文献**：扫描、切字、单字识别、字形检索一体化的“数字人文”基础设施（如汉字字形数据库、甲骨文字符库与 AI 缀合研究）把“说字形”变成“查字形”。方向有趣地倒转了——当年为“汉字上机”发明的技术，如今成了**保存汉字三千年**的主力工具。
:::

“区位码”即94×94矩阵之谓（一级字按拼音、二级字按部首笔画）。它是 1980 年的中国方案，Unicode 统一是其二十年后。

::: exercise 编码换算 {level=1}
“地”区位码2121：写出其国标码与机内码（十六进制），并倒推验证。
::: solution
两步通式：**国标码＝区位码（化十六进制后）＋2020H；机内码＝国标码＋8080H**。本题：区位(21,21)→十六进制(15,15)→国标码3535H→机内码B5B5H。倒推：B5B5−8080＝3535，35−20＝15（十六进制）＝21（十进制），“地”回到21区21位，闭环成立。学员常见错处是把“＋32（20H）”与“＋160（80H）”两步混作一步。
:::
:::

::: exercise 分层诊断 {level=2}
三条事故，各定位到“编码/字库/输入/识别”哪一层：①邮件从企业系统到苹果手机上变乱码；②某APP能搜到自己名字，客服回复里名字却是方框；③扫描版 PDF 全文检索搜不出某词。
::: solution
①编码层（收发两端字符集不一致/转换丢失）；②字库层（服务端渲染字体缺字，或对方设备字体缺字——数据未坏，脸没带）；③识别层（PDF 是图片，OCR 未做或没认出）。分层定位是数字时代“字病”的全套门诊流程。
:::
:::

::: exercise 语域改写 {level=2}
把一段网络语域留言改写成两种语域：①校园公告；②给长辈的短信（保留原意，得体优先）：“绝绝子这家店，yyds，冲！！！”
::: solution
①公告体：“本餐厅口味广受好评，欢迎同学们前往品尝。”②家常体：“妈，那家店特别好吃，周末带您去试试？”评分看**语域匹配**而非正字唯一：原句本身是合规汉字的修辞新用（不是错字），改写任务考察的是对“同一信息、多重书写系统”的自觉——数字时代的“书法”。
:::

::: exercise 小论文：汉字会被 AI 改写吗 {level=3}
结合本章“四层栈”与上一章“检索捷径”，写一篇八百至一千二百字短论：语音输入、大模型续写、图像生成文字正在怎样重新分配“写”的工作？预测：十年后汉字的日常使用形态。要求引用一个本章史实（748工程/输入法更迭/Unicode 统一任一）作类比支点，并给出可检验的判断而非口号。
::: solution
判分点：类比有支点（如以“激光照排消灭了铅字工人，但消灭不了排版需求”类比“AI 消灭打字，消灭不了写字的需求”）；能区分产出通道（书写/选择/口述）与知识本身；“可检验判断”示例——“手写体教学课时不会被取消，但考核标准将转向易读性与书法”；无汉字优越论/灭亡论的立场硬伤。
:::

::: summary
汉字上机四件套：编码（GB 2312 区位方阵→万码奔腾→Unicode 统一码位，CJK 基本区20,992位、扩展累计近十万）、字库（码位≠字形，地域字形与豆腐块）、输入（音码/形码/整句预测，消歧主权移交模型）、识别（OCR/HTR/古籍数字人文）。748工程与激光照排证明“汉字落后”实为工程缺口；网络书写不是字崩而是语域分裂；提笔忘字丢的是产出肌肉不是识字知识。字从甲骨走到屏幕，靠的从来不是天命，是每一代人现造的舟楫。
:::
:::
