你会写五千个汉字，却未必见过它们工作时的样子。这一章不谈某个字的历史，谈“字”这个装置本身：文字是什么，它记录语言的哪一层，为什么唯独汉字在三千年语音剧变里始终没有散架，以及“汉字表意、拉丁字母表音”这句人人会说的话，错在哪个字。理论课？不——这正是你以后学六书、辨繁简、跟输入法较劲时踩的地基。

## 文字是什么

::: definition 文字 {#def-wenzi}
文字是**记录语言的可视符号系统**，由三样东西构成：一套有名的单位（字或字母）、一条“怎样把话写下来”的构形原理（写法系统），以及共同体执行的字形规范。文字不是语言的透明外套：它有**自己的实体**（形状）、自己的单位（字）、自己的演化动力——这些都可以脱离“话音”单独考察，正如考察一套棋具不必先复盘棋局。
:::

::: definition 语素音节文字 {#def-yisuxiyin}
汉字是**语素音节文字**（morphosyllabic）：一个字的基本职能是记录汉语的一个音节－语素单位——“山”[ʂan⁵⁵] 是一个音节，通常也是一个语素；而“葡萄”两个字才是一个语素，“们”是一个语素却没有独立音节地位。这种“按语素切、按音节写”的定位，决定了汉字表里的一切特征：数量庞大（要一个一个记）、跨方言稳定（形状不绑死音值）、也决定了“一字一义”的民间想象为什么总是半真半假。
:::

::: theorem 文字与语言的三处不同步 {#rule-butongbu}
（一）**实体不同**：语言是声音（和时间），文字是形状（和空间）；“读”是把形状解码回语言，“写”是编码，两步都不是翻译。（二）**变化速度不同**：字形天然保守——抄写要像原样，字形就滞后；语音则日夜磨损。于是“本字”“本义”追不上“俗字”“俗写”，字形的地貌里存着各时代的化石。（三）**系统松紧不同**：拼音文字跟音走，音变三百年，原文变天书（今日英国人读不出乔叟）；汉字把意义焊在形状上，“见”字的粤语、闽南语、日语汉音读法各异，纸面却共享同一篇《论语》——**记音系统随音漂，记形系统靠字书锚定**。
:::

::: proof 汉字为什么没变成拼音 {#proof-hanzi-pinyin}
不是中国人“重道轻器”或汉字“先进落后”，是三个条件的组合：语素在汉语里天然成块（一个字基本等于一个语素，切分干净）；方言的读音鸿沟让“按音拼写”必然一地一拼、写不到一块；而字书与科举提供了全世界最强势的**字形锚**——一千三百年的标准答案都在“怎么写”上。三个条件今天已变其二（共同语普及、音系锚可换拼音），于是“汉字会不会拉丁化”成了二十世纪认真试过、又认真停下的问题（[[chinese-characters/simplification]]细账）。
:::

## “表意文字”之误

::: definition 记意与记音的谱系 {#def-jiyi-jiyin}
文字类型学按**基本单位记什么**分谱：记语素的叫语素文字（汉字是代表）；记音位的叫音位文字（拉丁、西里尔）；记音节的叫音节文字（假名是代表，希腊文历史上也这么来过）。注意三谱之间是**倾向**不是纯种：英语数字里住着记意因子（“4”在三种语言里都读 four/quatros/四），汉语形声字里住着记音因子（“湖”的“胡”只给音）。因此**“汉字＝表意、字母＝表音”这句话错在等号**：成熟文字都是记意与记音的混合物，汉字特殊在混合配方——七成五到九成的字自带声旁，却由意符定域。
:::

::: example 拆穿“六书＝造字方法”的流行讲法 {#ex-liushu-method}
课本常说六书是“六种造字方法”，于是指事象形在先、形声在后，汉字“进化”得越来越聪明。这个讲法哪里松了？
::: solution
六书首先是**分析框架**（秦汉人拿去拆字分类的术语），不是发生学清单：象形指事字在字系里占比极小（现代通用字表里不足百分之二），且甲骨里已有的形声字说明“会意优先、形声殿后”的进化叙事不成立——早期汉字就已在两条路（记意与记音）上并进。更麻烦的是转注假借两书，历来解释分歧大到“四体二用”说干脆把它们逐出造字法（见[[chinese-characters/six-categories]]）。结论：六书好用，但它是“眼镜”不是“族谱”。
:::
:::

::: example “打”字账 {#ex-da}
“打水的打、打伞的打、打电话的打、‘一打铅笔’的打”——查《现代汉语词典》，“打”的义项排了十几条。一个字等于一个词吗？
::: solution
不等于。“打”记的是同音同形的**若干语素**：动词“打击”系列是自家引申的账，量词“一打”（dozen 的音译）纯属同音借字，与提手旁毫无血缘；词典按意义关联分列义项，分不开的就算两个同形语素。语素音节文字的“一字一音一义”理想，在“打”这里被同音借用与引申分化同时打破——这是所有成熟文字的通病：符号有限，语言无穷，挤一挤总有同形。
:::
:::

::: intuition 你读的不是字，是词：顺手实验一个 {#intuition-ci}
“研表究明，汉字的序顺并不定一能影阅响读。”初读不觉有异，再看一遍才发觉每个词都被拆乱了——这不是段子，是证据：熟练读者以**词**为识别单位，字形只要词形轮廓在，内部顺序就蒙混过关。汉字系统给了这种读法加倍的理由：语素一字、词多双音，视觉词形高度规则。反过来，这个实验也解释了为什么“每下八年”式的错别字（“每”实为“每”、“八”实为“久”，你多半又没看出来）能在校对三遍后仍然存活——你不是在读字，你在读预期。
:::

::: remark 文字也会“遮住”语言
识字的人读自己的语言，永远隔着字形这副眼镜：我们觉得“句子”是单位的天然名字（语＋字？），说“他这个人不行”时脑内浮现的是形状不是声纹；甚至音位账也被字形改写——方言区学习者常以为“对”韵母“多”一个 u，因为拼音写着 duì。语言学家要戴两副眼镜：先有语言、后有文字；文字一旦上岗，又反过来发配语言的感知。这一章的全部要点浓缩成一句：**文字是语言的仆人，也是语言的编辑。**
:::

## 字有三层户口：形、音、义

::: definition 字的三层属性 {#def-xingyinyi}
每个通行汉字挂着三层档案：**字形层**（笔画、部件、书写顺序与印刷字形）、**字音层**（它在语言里对应的音节与声调，随语音史漂移）、**字义层**（它承担的语素义与词义，随词汇史漂移）。查字典、审字形、正字音，都是按层调档；把三层搅在一起，就是常见语病的产地：“‘果’字没有那一点”（把楷书写成宋体是印刷层的事）、“‘空’念去声才古雅”（字音层的事，另有审音账，见[[sounds-of-mandarin/putonghua-test]]）、“‘笨’的本义是竹子的白膜所以…”（字义层的考据，未必管今天的用法）。
:::

::: example 一层一层问 {#ex-sanceng}
判断下列说法各在哪层出错或成立：（1）“日”字是个圆的，中间一点是太阳。（2）“奇”在“奇数”里读 jī 不读 qí。（3）“冏”是象形字，本义是“光明”，所以它“本来就有这个意思”。
::: solution
（1）字形层半对半错：甲骨文“日”确是圆形加点（象形），今字形是隶变磨平的结果——把楷书的“方框加点”直接等同三千年前的“图画”，跨越了字体层。（2）字音层正确：多音字按义定读，“奇数”读 jī 有字典账（审音表亦收 jī 读）。（3）字义层正确、语用层错：“冏”的本义确有出处（《说文》系“光”类），但它二十年后当“窘”字用纯属**同音借用**的新生命——本义管不了借义，正如“楷”（楷树）管不了“楷模”的日常账（[[chinese-characters/phonetic-compounds]]声旁问题同理）。三层各查各账，是这门课反复练的基本功。
:::
:::

::: theorem 文字规范的四把尺子 {#rule-sizibiao}
一个字形能不能算“对”，由四把尺子先后量：**系统的理据**（构形合不合字例，如“冒”的上部不该是“曰”）、**字书的传统**（《说文》—《康熙字典》—《现汉》一线）、**国家的字表**（《通用规范汉字表》与印刷、手写分开立标准，[[chinese-characters/standard-characters]]）、**共同体的习惯**（约定俗成最终一票否决——“呆板”改读 dāibǎn? 的旧案、“确”的 qiǎo 读退场，都是习惯与规范的长期谈判）。学这门课的人要练出“四尺俱在”的自觉：既不拿字书砸流行，也不拿流行赖字书。
:::

::: quiz
“汉字是表意文字，所以不反映读音。”这句话的漏洞主要在（　）。
- [ ] 汉字其实完全按音拼写
- [x] 绝大多数汉字含声旁，且表意/表音是倾向而非纯种
- [ ] 表意的只有简化字
- [ ] 漏洞在于“反映”一词
::: solution
形声字占绝对多数、声旁就是记音构件（[[#def-jiyi-jiyin]]）；成熟文字都是混合配方，等号才是错处。
:::
:::

::: quiz
“他看不见。”把“见”改写成同音的“建”，句子读不通——这说明（　）。
- [ ] 汉字书写容易出错
- [x] 汉字把同音语素按义分形，书面辨析是它的核心功能之一
- [ ] 普通话声调没有区别作用
- [ ] 错别字也是合法的异体字
::: solution
一音多孔、分字记账正是语素音节文字的看家本领（[[#def-yisuxiyin]]）；“同音代替”在简化字工程里被审慎限制（“后/後”式归并是特例且有争议），日常书写里它只配叫错别字。
:::
:::

::: history
“文字是什么”在古人是神话题：仓颉造字说至迟战国已流行（《荀子》《淮南子》各有一笔），汉代又给它补上“见鸟兽蹄迒之迹”的观察剧本——神话本身很懂事：它把“起源”交给一个历史人物，说明古人知道文字是**被造成的**。现代学者的答案更冷：贾湖刻符、良渚陶符都零散不成系统，文字是行政、祭祀、记忆术长期催生的**集体工程**；甲骨文已经是成熟体系，前面还该有一千年量级的“童年”（[[chinese-characters/origins]]细看这桩公案）。二十世纪，这个问题升级为类型学：安特生、葛劳耐、唐兰、裘锡圭……从“图画—文字”“音意之辨”到“六书新解”，每一代人重新回答“汉字到底是什么”——这一章给的是当代教科书版共识，共识本身也在岗。
:::

::: application 错别字的成因表，就是文字原理的负面清单
“在/再”“须/需”“的/地/得”的混用，全部发生在**同音语素**的接口上——因为汉字按音配形，选字这一步就是按音索形，索错即错（这就是为什么错别字是“别字”不是“错字”：字都对，配错了）。而“步”多加一点、“肺”写成“氾”旁的错，发生在**字形层**的部件失守。两类错误的比例与年龄、输入法强相关：拼音输入法把“按音索形”自动化后，形近错别字减少、同音错别字上升，语文教师的课堂反馈早已证实——工具不改文字，只改错的分布。懂了这一层，纠偏就有处方：同音错要**回到义**（组词辨析），形近错要**回到形**（部件溯源，[[chinese-characters/strokes-radicals]]的功夫）。
:::

::: summary
- 文字是记录语言的可视符号系统，有自己的实体、单位与演化动力——它是语言的仆人，也是语言的编辑。
- 汉字定性为语素音节文字：按语素切、按音节写，由此解释其跨方言稳定与“一字一义”错觉。
- 文字与语言三处不同步（实体／速度／松紧）；汉字未拉丁化是语素成块＋方言鸿沟＋字书强势的组合解。
- “表意/表音”是倾向谱不是纯种分类：汉字混合配方（形声为主、意符定域）。
- 字有形音义三层户口，规范由理据、字书、字表、习惯四把尺子先后量。
:::

::: exercise 定性判断 {level=1}
把下列文字单位按“记语素／记音节／记音位”归类并各举一例：汉字“河”、日文假名 ka、英文词缀 -ing、阿拉伯字母 ب。这个四分法（加上记音节的第三型）缺了哪一类常见单位？
::: solution
“河”记语素（音节级）；ka 记音节；-ing 与 ب 记音位（前者是词缀兼表语法义，属“准记意”边缘）。缺的一类是**记意符号**（数字、&、@、性别符号等跨语言记意件）——正文已见其在“4”身上复活（[[#def-jiyi-jiyin]]）。判分看你能否给“-ing”说出两可的理由。
:::

::: exercise 三层户口 {level=1}
给“特、注、您”各建一张三层档案（字形层：结构＋笔顺要点；字音层：音节声调＋文白/又读；字义层：本义→常用义的账），并各标一处最容易出错的地方。
::: solution
样例“您”：字形层“你＋心”上下结构、九笔；字音层 nín 阳平，无又读；字义层由“你”加敬义构成（“心”表敬，会意），口语表敬称、复数“您几位”。易错：把“您”当“你们”用（“您们”的合法性争议，正是“敬称无复数”的语义账）。三层各安一处，判分即按三处齐全。
:::

::: exercise 拆“进化论” {level=2}
“象形→指事→会意→形声”常被讲成汉字从低级到高级的进化阶梯。用本章观点列出该叙事的三个漏洞，并在每空处填一个具体的字或事实。
::: solution
①甲骨里形声字已大量存在——“河”“洹”一类水名从水得声，商代人已经会“意符＋声符”装配，阶梯的“早期纯象形”一级不成立；②记意字少而难增，记音路才是扩容主力——“进化”是配比漂移不是能力升级；③“低级/高级”暗含“拼音为终点”的目的论——汉字未走拼音路有结构性原因（[[#rule-butongbu]]与[[#proof-hanzi-pinyin]]），非关智力。举字即可得分，不必站队“汉字优越/落后”任一方。
:::

::: exercise 统计读图 {level=2}
就本章“形声占比爬坡图”写二百字读图报告：说清数据的来源性质（各家统计）、为什么甲骨比例最不可靠、以及“双音节化”怎样推动形声加速。
::: solution
要点：①各家依释读字量与归类标准不同，同一批料可算出十个百分点以上的差——引用须注版本；②甲骨识字率低且多为专有名词（人名族名），抽样偏了；③词汇双音化后新词按“语素拼装”造字，形声模板（选意符＋选声符）是唯一的流水线。凡结论写成“大约”“通说”并在脚注留出处者满分——这本身就是本章教的读图规范。
:::

“骑”1985 年审音后统读 qí、旧读 jì 废止，近年诗词朗诵里“一骑（jì）红尘”又成热搜；“帧”统读 zhēn，影视行业仍普遍读 zhèng“一帧”。就这两案各用理据、字书、字表、习惯四把尺子写一百五十字裁断意见，并说明你若当值会怎么判。

参考走向：“骑”：理据层旧读 jì 有韵书来源（“乘人”义自有切语），字表层《审音表》统读 qí 已是终审，习惯层大众读音本就是 qí——复活的 jì 是“古音梗”不是活用法：考试广播依 qí，古典吟诵场合作趣谈可存而不论，不得称“唯一正确”。“帧”：理据层 zhēn 有据，字表层统读 zhēn，习惯层专业圈 zhèng 已成形——术语允许双轨（行业音与规范音各管一段），如同“血”的文白两读被默许。判分看四尺是否逐一过堂、结论是否可执行，不看口味。
