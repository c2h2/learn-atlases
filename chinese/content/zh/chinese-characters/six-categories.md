“武”是从止从戈的“止戈”吗？“忠”是“中心”吗？——这是人人都会的拆字法，也是东汉许慎用一生整理的分析框架在民间的余晖。六书（指事、象形、形声、会意、转注、假借）是中国语言学家给汉字发明的一套“语法”，用了近两千年，至今仍是字典编纂、识字教学、古文字考释的公共语言。这一章要做的不是背诵六条定义，而是学会**用它并知道它的边界**：哪些字六书一招制敌，哪些字两千年争不出结论，以及为什么“六书是造字法”这句话既对又错。

## 六书的账本与它的身世

::: definition 六书其名 {#def-liushu-ming}
“六书”之名见《周礼·地官》“保氏教国子，先以六书”（原文未列目）。汉人给出的三份书目互有出入：许慎《说文解字·叙》——指事、象形、形声、会意、转注、假借（有界说与例字）；班固《汉书·艺文志》——象形、象事、象意、象声、转注、假借；郑众注《周礼》——象形、会意、转注、处事、假借、谐声。名目小异、实指略同，后世从许慎之名。**六书首先是“分析分类法”**：它回答“现有之字可以归为哪几类”，并不严格回答“字是按什么顺序造出来的”。
:::

::: theorem 许慎的四条操作定义 {#rule-shuwu}
照录《说文·叙》的界定与例字，逐字体会其操作含义：
**指事**——“视而可识，察而见意，上下是也”：符号不能独立成图画，须“察”其位置、抽象关系会意。
**象形**——“画成其物，随体诘诎，日月是也”：描摹外形，一笔不苟地“跟着物体弯”。
**形声**——“以事为名，取譬相成，江河是也”：意符定类（水）、声符比音（可、工）。
**会意**——“比类合谊，以见指撝，武信是也”：两个以上意符拼出**新义**，非简单相加。
**转注**——“建类一首，同意相受，考老是也”：定义千古谜案（下节）。
**假借**——“本无其字，依声托事，令长是也”：不造字形、借现成字表词。
:::

::: remark 四张牌先打好的原因
六条不是并列的六扇门：真正“造新字”的主力是**形声**（汉字九成走此门），其次会意，象形指事是地基砖少，转注假借更像**用字法**——故清代戴震一系有“四体二用”说（象形指事会意形声为体，转注假借为用），影响深远但非定论。学习顺序也照此排：先认地基（象形指事）、再看拼装（会意形声）、最后碰悬案（转注假借）。
:::

## 象形与指事：地基与天花板

::: example 象形字的“像”有多像 {#ex-xiangxing}
“日”圆中有实画、“月”缺如弦中有影、“鱼”有头尾鳍鳞、“网”作方目——这些是《说文》时代的解释。请以甲金文字形检验：**象形是“素描”还是“轮廓线加区别记号”？**
::: solution
是后者。甲骨“日”作圈中一点（或竟作空圈），并非画太阳发光；“月”作半环加一画，只为与“日”“夕”相别；“鱼”其实简化到只剩头、身刺、尾三组区别特征。结论：**象形＝最小区别特征线描**，与漫画同理——它不追求像，追求“在这个系统里唯一”。这解决了象形字两大谜题：为何笔画省到几乎不可再省（特征足够即停）；为何“同实异字、异实同字”时有（系统需要区别，不需要分类学正确）。
:::
:::

::: theorem 指事：抽象义的窄门 {#rule-zhishi}
指事分两路。**纯符号**：一、二、三（积画），上、下（本作“丄、丅”，以短横相对长横的位置表“上、下”），最抽象。**加标号的象形字**（亦称“附指事”）：刃（刀口上加一点）、本末（木下/上加横画标根梢）、甘（口中所含一画）。注意：这条路**造不出新字的量**——符号空间有限，一、二、三已经到“三”还得出“四”，抽象概念画不出轮廓。所以指事与象形在字系中占比极小（通用字表内合计百分之一二），却贡献了“本、末、刃、甘”这类高频字与**一切分析术语**。
:::

::: quiz
“亦”字（本为“大”人形腋下加两点）属于（　）。
- [ ] 象形
- [x] 指事（附标号于象形字）
- [ ] 会意
- [ ] 形声
::: solution
人形＋两点标“腋窝”位置：主体是图画、指示靠符号，正是“附指事”（[[#rule-zhishi]]）。“亦”后被借为副词，又造“腋”字——一字数案的标本（见[[#def-jiajie]]）。
:::

## 会意与形声：拼装与量产

::: definition 会意 {#def-huiyi}
两个以上**意符**并置合成新义。经典结构如“休”（人依木）、“明”（日月相合，或从囧从月）、“涉”（两止历水）、“采”（手在木上）。会意与象形的分界：部件本身是否还各自成字（“果”像木上实垂，为一物之形→象形；“休”是两件事的关系→会意）。会意造字的难点在于**画面依赖**：拼出的义要够具体才好领会，于是高频抽象词多走形声。
:::

::: definition 形声 {#def-xingsheng}
意符（形旁）提示义类，声符提示读音：“河”从水可声、“湖”从水胡声。“以事为名，取譬相成”的工业意义：一套**无限产能的流水线**——新词出现，选个意符＋选个近似音的字做声符即可挂牌（“炉、颅、栌”各随其类）。汉字自商代以来九成上下按此模子造出，是字系不死的根本原因（[[chinese-characters/writing-and-language]]爬坡图）。
:::

::: theorem 形声判读三步与两大陷阱 {#rule-xingsheng-san}
三步：一拆（找出哪半是义类候选、哪半能独立成字）、二验（声符今音与整字是否同/近——不同则查其古音与语音史）、三查（拿字典或字源书核对《说文》说解，注意讹变后的“假部件”，“月（肉）”旁陷阱见[[chinese-characters/seal-to-regular]]）。
陷阱一：**位置不是语法**——形符可在上（空）、在下（盆）、在外（圃）、在内（病）、左（湖）、右（歃），习惯偏左下，规则不绝对。陷阱二：**声符有年代**——“江、河”上古见鱼谟通押、“省、睎”一类谐声包含复辅音遗迹的争论，声符的“不准”常是语音史的年轮（详见[[chinese-characters/phonetic-compounds]]与[[phonology/to-mandarin]]）。
:::

::: example 一次失败的归类 {#ex-weapon}
“武”：《左传》“止戈为武”，楚庄王已用此说。按《说文》它入会意；现代古文字学者却说“止”象足形、本义是“持戈而行（征伐）”。请分析：这个字还能不能测出六书之外的答案？
::: solution
能，且这正是六书的常态而非例外。古文字形从戈从止，“止”为足形表行进——则“会意”仍成立，只是**拼的义变了**（征伐示武，而非止息兵戈）。“止戈”说不是文字学结论，是春秋人的**政治诠释**（用字形讲理念，所谓“字源外号”）。由此得出本章最重要的方法论：**六书分析的对象是构形，构形解释依赖字形所处时代**——拿隶楷说字理，先问隶变（[[chinese-characters/seal-to-regular]]）把零件换过没有。
:::
:::

::: definition 意符的“类”与声符的“族” {#def-yifu-shengfu}
意符提示的是**义类**不是定义：“水”旁字未必都“有水”，但在“液体、与水涉”的语义场里（江、洗、沼、漏各取其一角）；《说文》540 部即 540 个义类的总账，字书部首是它的子孙（[[chinese-characters/strokes-radicals]]）。声符则牵出**谐声族**：同一声符的一串形声字（“也”族：地、弛、池、施、蛇）在造字时代与整字音同或音近，族内互证即得上古音的粗线条（[[chinese-characters/phonetic-compounds]]正面展开）。因此六书分析从来不是拆完就完：**拆意符接上词典语义学，拆声符接上历史音韵学**——两千年前的框架，一头连着今天的两门课。
:::

::: example “也”族小调查 {#ex-ye-family}
以“也”为声符想十个字，标注每字意符与义类，再判断今音与“也”的关系。
::: solution
地（土旁，今读 dì）、池（水旁，chí）、驰（马旁，chí）、施（㫃旁，shī）、蛇（虫旁，shé）、他（人旁，tā），再分化出她、它；族内意符各标义类（土地、水池、马跑、虫豸、人称），声符一律“也”。今音对照：dì 存舌齿邻旧读、chí 送气塞擦、shī 擦音化、tā 塞音清化——一族四五种声母，恰是“声符记录的是**上古**音近关系”的活证据；若据此骂“声符不可靠”，等于怪家谱上的老宅地图不标新公路。
:::
:::

## 悬案与借字：转注、假借

::: definition 假借 {#def-jiajie}
“本无其字，依声托事”：词有音有义而无字，拿同音现成字来记。“令、长”许慎例字（县令、长吏之令长皆借“号令／久长”字为之）；更古的例子是第一人称“我”（本兵器名）、“汝”（本水名）、“而”（本颊毛）。**假借不造新字形，故称“用字法”**；它给汉字装上了“按音记词”的阀门——表意字系里大量抽象词、虚词全靠它（“其”本象箕形，借为语助、代词之后，本义另造后起形声字“箕”负担——“借字夺主、本义迁居”是假借的常见下半场）。
:::

::: theorem 转注十三家 {#rule-zhuanzhu}
“建类一首，同意相受，考老是也。”两个例字“考／老”同部同义、声亦相近（幽宵旁转之说），于是定义有两种主解：**形转说**——建一首类（部首）、同意互相授受（互训加声旁增殖，如“老”生“考”）；**音转说／义转说**——方言转音或义近相注，造字之转注。各家至今未定，教科书多列三说存疑。给初学者的实用立场：把转注当作**字族增殖的记载**（互训＋同部＋声近）来处理字典里的“某与某同意”条，其余留给专门史。
:::

::: remark 为什么“六书是造字方法”既对又错
对：象形、指事、会意、形声确是四种**构形手段**；错：六书成说时秦汉人已不造字，它是给既成文字库做的**事后分类**；且分类边界会漏：“为、射”一类混同重分析字（隶变产物）、省形省声的变格（构件被部分替换，说解须从字书）、假借字（用字非造字）都证明：**框架为解释主流而生，边角永远在框架外跳舞**。这正是所有“类型学”的命运——好处是可教可查可讨论，坏处的上限是逼你把不进的硬塞。
:::

::: history
六书的理论史半部是经学：《周礼》“六书”是贵族小学课程名目，汉儒为它配目（《艺文志》本刘歆《七略》、郑众、许慎三家）、晋唐以后义界渐密——戴震“四体二用”出，段玉裁注《说文》推波助澜（“叙”注里逐条补说），再到近代唐兰“三书说”（象形、象意、象声）与陈梦家同源异目的改组，当代裘锡圭《文字学概要》再删繁就简（把“抽象字/组合字”重划界限，形声改称“意音字”立场）。一门“分类学”修了两千年，每一代人都嫌前人不够“科学”，每一代又都继续用许慎的名词写论文——**框架的寿命来自好用，不来自无懈可击**。
:::

## 后续内容

六书在古文字考释中的实战见[[chinese-characters/oracle-bronze]]（四把钥匙与构形系联）；声符如何用于上古音研究在[[chinese-characters/phonetic-compounds]]；“部件、笔画、部首”的现代分析框架（为教学与检索设计，与六书互补）在[[chinese-characters/strokes-radicals]]。课后操：从字典任翻二十字，逐一归类（象形/指事/会意/形声/非六书/存疑），再查《说文》说解与一种古文字编对答案——错题的分布就是你“字感”的体检报告。

::: summary
- 六书是汉人为字库做的分类框架：四体（象形、指事、会意、形声）造形，转注、假借历来被划出“造字”之外（四体二用）。
- 象形＝最小区别特征线描；指事靠位置与标号，门路最窄。
- 会意拼画面义、形声走流水线——形声占九成，是汉字扩张的唯一引擎。
- 形声判读三步（拆、验、查）两坑（位置不绝对、声符有年代）；假借与通假一名两实。
- 转注千年悬案；六书的边界漏风处（重分析字、省变格）恰是字形史（隶变）与用字法（借字）的接缝。
:::

## 习题

::: exercise 六书速配 {level=1}
给下列字配六书类（以《说文》立场为答案，隶楷异变者加注）：上、刃、齿、徒、颈、鼻。
::: solution
上＝指事（丄）；刃＝指事（刀上加标）；齿＝象形（齿列与口，篆加“止”声后近形声——注出即加分）；徒＝形声（从辵、土声）；颈＝形声（从页、巠声）；鼻＝形声（从自、畀声，“自”本象鼻形）。本题关键在**答案要能报出形声的“从某某声”格式**，报不出即判未掌握。
:::
:::

::: exercise 部件真假 {level=1}
下列楷书的“月”旁或其他疑似意符，哪些是真意符（义类仍在上班）、哪些是隶变形变的假部件？判断并说明：肝、胡、有、修、盆、京。
::: solution
肝（月＝肉，表身体部位，真意符）；胡（从肉、古声，月旁存本义“牛喉”一类肉义，真而需字书）；有（甲骨文从又从肉，手持肉为“有”，楷身之“月”即肉——真）；修（从彡、攸声，彡表文饰，真）；盆（皿，真）；京（象形字，下面的“口小”是形迹不是部件，谈不上真假）。练习要点：**先问这个位置在篆书是什么**，再谈真假。
:::
:::

::: exercise 通假还是假借 {level=2}
判断并说明理由：①古书“蚤”借为“早”；②“乌”（本鸟名）用为疑问代词与否定语气词；③“而”本颊毛借为连词；④某生把“已经”写成“以经”。
::: solution
①“早”本有其字而借“蚤”——**通假**（书写层），非六书之假借（造字层“本无其字”的借用才是）；②疑问与否定语气词无形可象、又无现成字，借鸟名“乌”为之——假借；③“而”同例；④学生别字：既非“本无其字”也无规范背书，纯错。一、四之别正是[[#def-jiajie]]的“门槛”考点。
:::
:::

::: exercise 给“亦”字写档案 {level=2}
以“亦”为对象写二百字字档：字形分析、本义、假借去向、后起字、六书归类争议（若有）。材料可查《说文》、任一古文字编与《辞源》。
::: solution
档案要点：大形加两点指两腋→指事（附标号）；本义“腋”；借为副词“亦”（语气/承接）；本义后起形声字“腋”；争议点——借字行而本义晦，是“假借夺本字”的常见生态。判分看四件齐全＋注明“亦/腋”古今字关系，引书到版本页码者优。

::: exercise 小论文 {level=3}
“把转注改成两个同义互训字的关系，这个定义就清晰可用了。”请写四百字：先按你倾向的某一系（形转/音转/义转）给出可操作判据，再说明该方案会误伤哪些材料，最后评价“存疑”是不是更诚实的教科书处理。
::: hint
可参材料：《说文叙》段注；裘锡圭《文字学概要》转注节；任何一篇综述“转注论史”的期刊文章（先搜关键词“转注 综观”）。

::: solution
参考走向（形转版）：判据＝同部首＋义通＋声近＋出现有先后（如老→考、颠→顶一类常被引用的例，引用前先验上古声类），误伤：同部同声的**纯分化字**（如“益/溢”本古今字却不同部）与无部首相受者（异体改形）。结论段应承认：悬案之“悬”在定义只有一句十二字、例词只有一对；教材“三说并列＋操作立场”正是把学术诚实转译成教学法——这不是和稀泥，是把判断的**证据等级**标在图上。
