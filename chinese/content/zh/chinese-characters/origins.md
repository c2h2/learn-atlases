“仓颉四目，见鸟兽之迹而造字”——故事动人，但考古铲下的答案更古老也更琐碎：字不是一个人造的，是记账的、占卜的、铸鼎的几代人慢慢磨出来的。这一章解决三个问题：凭什么说“这是文字”而“那只是符号”；贾湖刻符、良渚刻符、城子崖陶文各够不够格；以及为什么全中国教科书都同意：**成熟的汉字体系，目前只能讲到三千年前的甲骨为止**——之前那一千年上下的“童年期”，证据在哪里、又缺在哪里。

## 判定标准：什么时候“图画”变成“文字”

::: definition 文字的发生与前文字 {#def-qianwenzi}
**前文字**（proto-writing，也称原始记事）指辅助记忆、尚未与语言的音义单位固定的符号手段：结绳、刻契、筹码式的积算符号、族群徽记、图画叙事。它们“能表意”却**不对应语言的线性序列**——读的人只能猜出大意，读不出音节与语法。**文字**则必须满足与语言的三线挂钩：每个固定形体对应语言中**可重复使用的单位**（词或语素），排列顺序对应话序，能**成句**并无限生成新记录。
:::

::: theorem 判定三件套 {#rule-santaojian}
考古符号要升格为“文字”，须同时过三关：（一）**单位性**——同一形体反复出现且可分析出与语素对应的音值（可与后代文字或同期语言材料对验）；（二）**序列性**——形体成串排列，顺序承载语法或至少固定的读法；（三）**能产性**——体系能记录未见过的句子（判据：字形间有构件复用与组合规则，而非各自孤立的记号）。三缺一，就只能称“刻符”“图形序列”，写进《文字学》第一章，写不进《上古汉语》的语料库。
:::

::: proof 为什么门槛必须这么高
因为“像字”是最廉价的相似：陶工印记、族徽、巫师符号个个笔画宛然。若放宽标准，贾湖刻符能把汉字史拉到八千六百年，埃及、两河也都“更早”——学术史反复演示：每当新石遗址出土带符号器物，媒体即宣布“文字起源改写”；而学界要的是**能读出话的材料**。门槛高不是保守，是方法论：三件套每一项都有可操作的对验程序（单位性靠重出频率统计，序列性靠排列规则，能产性靠构件分析），拿不出对验，一切归“存疑”。这是本章给读者的真正的行囊：**会怀疑，更要会验证。**
:::

::: example 用三件套量一量贾湖 {#ex-jiahu}
河南舞阳贾湖遗址的龟甲、骨器上发现一批刻符号（数十例、数种，数目各家统计略异），碳十四约公元前 6600—前 6200，个别形似后世“目”“日”。请逐条过三件套。
::: solution
单位性：符号多**单次出现**、跨器重复率低，难以证明对应固定语素；个别字形与三千年后的甲骨“目”“日”神似，但形似不等于同源——线条简单者趋同率极高（地球各地画“眼睛”都是圈加瞳）。序列性：无一例成串，无读序可言；能产性：构件复用系统无法建立。三关皆未过，结论：新石器时代**刻符**，与汉字起源**有关怀**（契刻传统是汉字来源之一，下节），但不是文字。判断不依赖“我相信/不相信”，只依赖三件套的可验程序。
:::
:::

## 候选链：刻符、图形、与那一千年缺环

::: theorem 汉字的来源：两条河道 {#def-lianghetiao}
学界通说，汉字由**图画记事**与**契刻记数**两条河道汇成：图画提供“据形系联”的造字理据（字、日、月、象、斗一类），契刻提供抽象指事与数字符号（一二三、上下的古体，及“契”本义本身）。两河道在龙山—二里头阶段的**图形与契刻合流**（族徽加字、记数加形）中交汇，到商代贞人手里结晶为可释读的体系。这说法的长处：解释了为何甲骨文中象形字少而形声字已多（[[chinese-characters/writing-and-language]]的形声爬坡），因为合流不是单线进化，是两套技术并轨提速。
:::

::: remark 证据链上的几处硬货
**良渚文化**（约前 3300—前 2300）：江浙一带玉器陶器上刻符颇富，尤以成场的神人兽面图纹与个别**多符连刻**之例最受关注；山东**章丘城子崖**龙山文化陶片上的**五符连刻**是东部沿海“图形连缀”的最强单例——诸家释读较多（以“旦于出日”一说影响较大），均未获公认。**二里头**（约前 1750 以降）陶器刻符二十余种，并见**符号组合**之例，时代地点正落在缺口上。三处各说各话，互相之间没有释读通道——这既是“缺环论”的硬证据，也是“多说并存”的原因。
:::

::: intuition “起点”是材质的谎言
注意一个容易被忽略的方法论：我们今天能看见的“最早”，几乎全是**最耐埋**的——龟甲兽骨、青铜石头。商周时代更常规的日常书写写在竹简、木牍、丝帛上，甚至直接书于地面墙粉，早已腐朽无存（出土简牍都是侥幸：埋藏环境恰好）。所以“汉字三千年前突然出现”必然是错觉：**不是字不存在，是载体不给我们看**。推论有二：其一，任何“某刻符=最早文字”的说法，都要先问“比它晚又比甲骨早的常规载体在不在”；其二，汉字童年期缺的那一千年，多半不是空白而是**腐烂**。把材质偏差刻进脑子，能挡住一半的“改写历史”头条。
:::

::: example 城子崖五连刻符怎么读 {#ex-chengziya}
城子崖龙山陶片上的五符连刻，出土以来释读纷纷（以“旦于出日”一说影响较大），无一获得公认。请评估：即便某家释读正确，能改写“文字起点”吗？
::: solution
不能，且原因值得背下来：改写历史需要**系统的同时代可释读语料**，单件孤例只能提出问题不能解决问题。假设五连刻确实读“旦于出日”（一句话！），它与甲骨文的字形谱系是否相承仍无中间证据（同时、同地、成批的字在哪里？）；而一旦成批，它便自动满足三件套、不再需要“假设”——这就是孤例的宿命：**要么是缺失的环（等下一铲土），要么只是巧合**。学术史上对城子崖的克制引用（“值得注意的线索”）不是胆小，是对证据等级的诚实。
:::
:::

::: theorem 传说如何与考古同桌 {#rule-chuanshuo}
仓颉造字说的三重证据：战国《世本》“仓颉作书”、《荀子·解蔽》“**好书写也者众矣，而仓氏独传，以一者也**”、《淮南子·本经》“昔者仓颉作书而天雨粟，鬼夜哭”。《荀子》一句最值钱：写字的人多得很，仓家之所以留名，靠“**专一**”——这是把“发明权”改写成“专业化”的社会学解释，与考古完全同桌：文字起于众工，成于巫史，名字留给集合的代理人。汉代给仓颉配上“四目”“龙颜”与观察鸟迹的剧情，属于神话的标准加装（每一项都在放大“观物取象”的发明故事，服务“文字神圣”的时代需要）。
:::

::: application 把三件套带去读新闻
检索任意“××遗址改写文字史”报道，用三步核查：一、符号是否**重复出现且数量可观**（单位性）；二、是否**成串**（序列性）；三、研究者是否给得出**构件复用**分析（能产性）。三项皆“无”而标题用“最早文字”者，正常处理是“发现刻符”。本章训练的最大红利不是记住贾湖多少年，而是拿到一条免疫带：以后遇到“××比两河早”的爆款，你三秒钟就能问出对的问题。
:::

::: history
甲骨文的重新发现是学术史的富矿：1899 年金石家王懿荣在“龙骨”上认出契文，刘鹗《铁云藏龟》1903 年影印传世；孙诒让《契文举例》草创未精，罗振玉考订甲骨出土地为殷墟、释出商王世名，王国维再据卜辞印证《史记·殷本纪》所记商王世系——二十年间，一味药材变成一门“甲骨学”，把中国信史推上商代，也把“文字起源”的讨论从神话改写成考古问题。1928 年起中央研究院对殷墟科学发掘，1936 年 YH127 一坑出卜辞一万七千余片——这门学科的谦卑与雄辩，都埋在那样的坑位里。
:::

::: example 一片甲骨的档案 {#ex-keci}
读一段典型卜辞的框架（据释文通例改写）：“癸巳卜，殻贞：旬亡祸？王占曰：来庚? 简化为——王占曰：有祟。五日戊戌，雷雨有……”指出各成分名称，并说明它为何同时满足“三件套”。
::: solution
卜辞通式五件：**叙**（干支日期）、**命**（贞人所问：“旬亡祸”——未来十日无灾祸吗）、**占**（王看兆纹下的判断）、**验**（事后验证的追记，常有“七日己亥允……”句式）、署辞刻手之类附加。就三件套看：命辞与占辞是**成句的汉语**（主语惯常省略，“旬亡祸”这样的疑问句式齐备），同一贞人名（殻）跨坑重出（单位性与个人书手风格），上千片卜辞用同一套构件生成无穷新句子（能产性）——这就是为什么“能读出话”是文字判定里唯一不会说谎的证据。顺带注意：卜辞已是高度程式化的**成熟文体**，程式化恰恰是“此文字已用久了”的老年斑。
:::

## 后续内容

甲骨文长什么样、怎么读，专课细讲：[[chinese-characters/oracle-bronze]]；“字书台阶图”里《说文》的分量，在[[chinese-characters/six-categories]]正面展开；二里头与更早符号的最新发掘逐年刷新，读法用本章的三件套自测即可。想练真功夫：找一部甲骨文字编，抄十个“水”旁字与十个“木”旁字，数构件复用的证据——三件套的第一手体验，比一百篇科普都管用。

::: summary
- 文字 vs 前文字的分界是三件套：单位性（固定形体对应可重用语素）、序列性（成串可诵读）、能产性（构件复用成系统）。
- 贾湖刻符、良渚刻符、城子崖五连刻各是重要线索，皆因三件套未满而不得入“文字”籍；孤例不改史。
- 汉字两条来源河道（图画记事＋契刻记数）在龙山—二里头合流，至甲骨结晶。
- 仓颉传说≠信史，但《荀子》“众造独传”一句是古人给集体发明权让路的洞见。
- 已知字数随字书累积涨到五六万，常用字三千五却始终老面孔——“字的海涨，字的底不涨”。
:::

::: exercise 三件套速判 {level=1}
判断下列各项是否已构成文字，各用一句话说缺哪件：（1）结绳“大事大结，小事小结”；（2）某遗址同址出土同形刻符 37 例，均单出无串；（3）某筒帛上与传世古书可对读的整句文字。
::: solution
（1）非文字：无单位性之验证（结无音值，绳无读法），属前文字记事；（2）够到单位性，缺序列与能产——仍是刻符；（3）三项全满（可与语言对验、成句、能产），是文字且成系统。判分看是否**逐项引用判据**，不许只报“是/不是”。

::: exercise 材质偏差清单 {level=2}

::: solution

加强例：出土地点—时段落在两河道交汇区（豫西晋南，龙山—二里头）的**成批组合刻符**，且构件既见象形源又见指事源；削弱例：若确证成熟甲骨文字之前中原无契刻传统、或其“图画”源全系外来。最弱一环：从“符号”到“可读之文”的**临界期**（前 2000—前 1300）材料仍薄，谁也没握到那把“成串可对读”的关键陶片——所以“通说”二字后面，其实站着一条未合的账。本题不要求站队，只要求你能指出账挂在哪儿。

参考论点：传说是古人**问题意识**的化石——“谁造字”背后是“文字凭什么可信”（占卜、政令都靠它）；职业集团（巫史）借神话自赋神圣；而《荀子》的“众造独传”证明战国理性足以给神话让位。研究史角度：神话提供最初假说（观物取象→象形优先），随后被反噬（“仓颉一体造字”的想当然阻碍了渐进论），恰是“问题推动学科、成见拖后腿”的标本。判分看论证层次，不看是否背诵《说文》叙。
