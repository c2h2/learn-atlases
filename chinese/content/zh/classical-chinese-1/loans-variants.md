---
title: "通假字与古今字"
---

“学而时习之，不亦**说**乎？”——心里明白是“悦”，手上怀疑是不是印错：**没印错**。文言的书写系统人手不够、正字未定，于是发展出三套“借用户口”的制度：通假、古今字、异体。分不清，就读不了两千年前的“别字”。

## 通假：急来抱佛脚的借字 {#sec-tongjia}

::: definition 本字与借字 {#def-benjie}
**通假**：写文章时临时借用一个**音同音近**的字来顶替本字——“不可不**蚤**自来谢项王”（蚤=早）、“愿伯具言臣之不敢**倍**德也”（倍=背）、“阳货**归**孔子豚”（归=馈，赠送）、“知者乐水，仁者乐山”（知=智，读去声）。三要点：①**通假是共时借用**——蚤与早同时并存，写的人不是造字，是“别字合法化”的用字习惯（上古字少、书写权威未定、师传口授重音不重形）；②**判据=音+例**：音必须上古同部（蚤/早同精母幽部，倍/背同並母之部——拿上古音表对质，见[[phonology/old-chinese]]），例必须有故训背书（郑玄注《周礼》已经开仓：“故书假借字多矣”——汉人就承认老文件满纸借字）；③**读法=认贼作父**：借字按本字义读，音也随本字破读（说 yuè、知 zhì、女 rǔ、亡 wú）。
:::

## 古今字与异体：两种“一户两地” {#sec-gujin}

::: definition 古今字：一词换过几次身份证 {#def-gujin}
**古今字**：同一个词，不同时代用不同字形——古字兼职太多，加偏旁“分家”：**说→悦**（“学而时习之”之“说”兼“喜悦”，后加心旁专职）、**知→智**、**然→燃**（“然”本义燃烧——下面是火；假借成“然而”后，本业反由新字接管，古今字里最黑色幽默的换位）、**益→溢**（益的甲骨文字形=水从皿中满出，本义“溢”；借去当“利益”后，水旁回来救火）、**县→悬**（县的古文=首倒悬于木，本义悬挂；州县义抢注后造悬字）、**取→娶、田→畋、要→腰、食→饲**。与通假的分手标准：**古今字有造字产业的继承关系**（今字为古字的一个义项量身定制，字形上有血缘——多半加旁），通假只是**音同的临时租赁**（蚤与早字形无血缘，纯声音交易）。
:::

::: definition 异体字：同名同姓的连体双胞胎 {#def-yiti}
**异体字**：音同、义同、**任何场合都可互换**而字形不同——峰/峯、群/羣（上下一挪）、村/邨、咏/詠、遍/徧、线/綫。异体不改变语言，只改变抄写员的工时：历史上异体大户靠**字书与正字令**收编（《干禄字书》辨古今通俗、乾隆《康熙字典》定体、1955 年《第一批异体字整理表》一次淘汰 1053 个异体格）。阅读价值在两处：查字典时**认得谁是谁的双胞胎**（免得为“巖/岩”跑两趟），以及书法字典里欣赏同一字的七十二变（[[chinese-characters/simplification]] 简化字的许多刀法——“虫”吞“蟲”、“网”收“網”——本就是对异体逻辑的官方续办）。
:::

::: example 三关会审 {#ex-hui}
三句各判户籍（通假/古今字/异体/本字多义）：①“属予作文以记之”（《岳阳楼记》） ②“属引凄异”（《三峡》） ③“愿伯具言臣之不敢倍德也”（《鸿门宴》）。
::: solution
①属=嘱：嘱是后起分化字，严格判**古今字**；课堂速判常归“通假”——本案的判例意义正在于此：**通假与古今字是同一现象的不同历史截面**（借而未造新字者为通假，借久转正、新字分家者成古今字）。判“通假”给及格，判“古今字”给满分，判出“正在从通假走向古今字”给小论文加分；②属=连续：本字**多义**（属 zhǔ 自带连接义，无需假借——别把每个难字都当通假，那是文字疑罪推定）；③倍=背：**通假**（音同租赁，千年老租户，未见新字分家）。三案各判有据即出堂。
:::
:::

::: history 因声求义：两千年解码学 {#sec-jiedu}
汉儒解经已懂“就其声以求其义”——郑玄注三礼动辄“某读为某”“故书某为某”，把假借当常规案卷办；清代**段玉裁**把话挑明（《说文解字注》论假借：用字之借，道理全在声音），**王念孙、王引之父子**《经义述闻》以声音通训诂，推倒汉人无数“望文生义”旧账——《诗》“终风且暴”，王念孙读“终”为“既”，“既风且暴”一锤定音，是《经义述闻》的招牌案。二十世纪学者给假借立起现代总账：**“本无本字的假借”（六书本义，如“而”“汝”这类无字可画者的借音记词）与“本有本字的通假”（用字之借，如蚤之于早）正式分账**，教科书从此不把一切同音换字一锅炖。解码学问声问韵、查书查注疏——汉字史最像刑侦学的一章。
:::

::: warning 借字四防
一**凡难必通**：见字不顺就喊通假，是万能钥匙开所有锁——先穷尽本字引申（“属引凄异”的属自带“连续”义，无需借）；判通假三证：音近（上古标准）、例同（同时代平行用例）、训古（注疏先师已曰“某读为某”）；二**以今音断古案**：蚤/早今音同不难，难的是“女/汝”今音已分而上古同、归/馈今声已异而古为牙音近邻——音准必须拿上古音表当尺（借字冤案，一半坏在拿今音断古案）；四**无视繁简源流**：简体字形可能罩着多个来源（“干”罩乾/幹、“后”罩後），读借字先回繁体户口再开庭。三**通假古今混判**：判据只看一点——有没有“为借义造新字”的分家事实（嘱/燃/悦有，蚤/倍无）；四**无视繁简**：读古籍繁体，“说”字身兼数职（shuō/yuè 两读两义）——繁简对读先复原字头再查借（[[chinese-characters/simplification]] 一字多源条款）。
:::

::: exercise 户籍登记 {level=1}
八句判类（通假/古今字/异体/本字多义）：①“学而时习之，不亦说乎” ②“寡助之至，亲戚畔之” ③“日知其所亡” ④“师者，所以传道受业解惑也” ⑤“玉不琢，不成器” ⑥“将军身被坚执锐” ⑦“属予作文以记之” ⑧“蟹六跪而二螯”。
::: solution
①说/悦：古今字（悦为分化字；答通假给部分分，理由同⑦）；②畔/叛：通假（未造新字）；③亡/无：通假（亡之本义“逃跑”另案——“日知其所亡”借表“无”）；④受/授：古今字（受本兼“授予/接受”二义，授为后起分化字）；⑤“玉不琢”无借（干扰案：别患凡难必通）；⑥被/披：古今字（披为后起，被本义寝衣——第 2 课判例回收）；⑦属/嘱：古今字（嘱后起）；⑧跪：本字——蟹“跪”是腿足的词义引申（同字兼职），不是借字；判“多义/本字”即可。八案判六即满分，两成之地留给学术争议（通假与古今的截面之争）。
:::

::: exercise 音理对质 {level=2}
用上古音常识说明：为什么“女”可通“汝”而“妈”不通“马”？再查一个“归/馈”的声母韵部关系。
::: solution
女/汝：上古同属**鱼部、日/泥母邻近**（且“女”本有 rǔ 一读——破读即化石），音近可借，且有 rǔ 的破读化石作证；妈/马：音虽相近，但“妈”字晚出、历代文献从无借“妈”为“马”（借字必须有例），光音近开案就是冤狱制造机。“归/馈”：同为牙音声母（见/群邻纽），韵部微/物对转——音近有谱，馈又是后起分化字，一案两制交界。判分点：说清“音近只是入场券，用例+故训才是判决书”；音理方向不翻车即可。
:::
:::

::: exercise 小论文：错别字何以合法 {level=3}
写八百至一千二百字：通假的本质是“当时的错别字、后世的正字法”。以“蚤/早”与今天“登陆/登录”“账户/帐号”的拉锯对照，讨论：一个字用错的人够多，就转正——文字规范与语言民主的边界在哪里？要求：通假三证用于现代案例各一；可引课内普通话审音旧账（[[sounds-of-mandarin/putonghua-test]]）；给出你的“转正程序”三条。
::: solution
判分点：三证迁移合理（现代借字案同样要音近、用例、权威背书——词典收录=新版“故训”）；“帐号”案解剖分清**字量经济**（借字省笔画）与**系统熵**（一字多义增歧义）；转正程序可操作（如：使用率阈值+分布广度+歧义成本审计三关）；引“郑玄承认老文件满纸借字”作历史注脚。
:::

::: summary
三套户政背熟再上路：通假=音同租赁（蚤住进的早家，无血缘，判案靠上古音+故训）、古今字=义项分家（说分给悦、然让位给燃、益请回溢——有血缘，今字多半加旁）、异体=双黄蛋（峰峯同户同命，正字令一纸并户）。读借字认本字、音随义破；判通假先过“本字多义”排查，别搞文字疑罪推定。下一课练绝活：白文句读——没有标点的两千年，古人靠什么把书断对。
:::
