title: "古今词义"
---

实词是会搬家的住户：有的门牌没动、屋里换了人；有的连人带门搬去了对街。**读文言最大的危险不是生词，是“熟词”**——你以为认识“去”，它认识的是两千年前的你。

## 四大迁移路线 {#sec-sidaolu}

::: definition 扩大、缩小、转移、升降 {#def-kuoda}
**扩大**：江、河本专名（长江、黄河），唐以后通名化，“江南”的江有了万条；脸本指两颊，今收全脸；菜本指蔬菜之属，今荤素一锅收。**缩小**：臭（xiù→chòu）本凡气味（其臭如兰），今专恶味；禽本猎获物总名（飞禽走兽皆禽），今专鸟类；宫本泛指屋室，秦汉后皇家专用——皇权的语义圈地。**转移**：搬家换焦点——兵本兵器（“弃甲曳兵而走”），后指士兵、战事；獄本诉讼案件（“小大之狱，虽不能察，必以情”），后指关押之所；書本指书写与字迹（《说文》“书，著也”），后转指典籍册页；去本**离开**（“去国怀乡”=离开国都），后来的方向整个掉头成“前往”——古今等值反向的头号刺客。**升降**：爪牙本褒义，指环卫国家的猛将（汉人奏疏“将军者，国之爪牙”式称许，“股肱之臣”至今受惠）；乖本乖悖违背，唐宋后转“乖巧”，贬义洗白——下坠词上升。词义无褒贬，账上有涨跌。
:::

::: definition 假朋友名单：双音词的陷阱 {#def-jieipengyou}
文言双音组合常是**两个单音词临时并肩**，与现代双音词同形不同心——最危险名单：**卑鄙**（诸葛亮“先帝不以臣卑鄙”=身份低微、见识短浅，自谦；今=人格下作）；**感激**（同篇“由是感激”=心被感动奋发；今=道谢）；**牺牲**（《左传》“牺牲玉帛，弗敢加也”=纯色全牲的祭品，名词；今自带“献出生命”的崇高）；**地方**（“地方千里”=土地方圆，两个词：地＋方；今=administered area）；**婚姻**（《左传》“婚姻之好”=姻亲关系之家；今=结婚制度）。识别口诀：**双音节先拆两半，各查各户口**——拆完仍通的是真双音词，拆完散架的是假朋友（方法接[[modern-vocabulary/morphemes-words]]）。
:::

::: example 一词档案卡：“汤” {#ex-tang}
为“汤”建四栏档案（古义→今义路线、书证、残留化石、现代误读风险）。
::: solution
档案：①古义=**沸水/热水**（“及其日中如探汤”“赴汤蹈火”——汤与“热汤”的汤同族）；②转移路线：热水→煮取的汁液（茶汤、羹汤）→今“菜汤”——同一物类，焦点从“烫”移到“内容物”；③残留化石：成语“赴汤蹈火”“固若金汤”（金城汤池=沸水护城河，防御工事狠版本）、温泉地名“汤”（汤山、汤池）——古义在成语与地名里装死，随时诈尸；④误读风险：见“汤”译菜汤，则“及其日中如探汤”变成正午把手伸进蔬菜汤——刑罚现场变食堂。四栏齐即示范。
:::
:::

::: definition 死法的等级：讳饰系统 {#def-weishi}
“死”是汉语讳饰的富矿，礼书给了一套**分级词汇表**：天子崩、诸侯薨、大夫卒、士不禄、庶人死（《礼记·曲礼》）——死的委婉是身份的最后一次广播。另有战场讳饰（“填沟壑”自谦、“山陵崩坏”避讳）、病榻讳饰（“不在”“大行”“宾天”）、现当代接续上岗（“走了”“去世”“长眠”“圆寂”“见马克思”）。一条规律贯穿：**委婉词被其遮盖物污染，必须不断上新**（[[rhetoric/registers]] 讳饰军备竞赛的词汇史总账）——“去世”本极庄重，用滥即中性；医院改口“走了”，是新一轮上账。
:::

::: history 旧词穿新衣：最后一波大迁移 {#sec-yiceng}
晚清民国，为翻异域概念，一批古词被召回穿新衣：**经济**（古=经世济民，大才大用；新=economy）、**社会**（古=社日里正的乡俗集会，“社会”本祭社的分身；新=society）、**革命**（古=革其天命，《易经》“汤武革命”，刀口对着天；新=revolution，对准制度）、**文化**（古=文德教化，动词气质；新=culture 名词柜）。这批“回归形译词”多数由日文借词渠道返销（[[modern-vocabulary/loanwords]] 有账），特点是**字形无缝、语义换心**——比生词更会骗人：读《后汉书》见“社会”、读《宋史》见“经济”，脑内自动弹窗的正是错解。王力先生主持的现代汉语学科建制里，词义研究始终被按着“历史”的肩讲——本课把一句大意当作训：**词汇史是最不理睬“万古如斯”的历史。**
:::

::: warning 三个高频陷阱
一**以今律古**：“父母妻子”古=父、母、妻、子四人（“妻子”双音同形假朋友），以今义读之，户口少一半；“牺牲”以今义读《左传》，祭祀变烈士追悼；二**以古括今**：认为“江”古今只是“大小不同”——专名与通名是**词义性质**之差，不是量级；三**无视时代切片**：“去”的“前往”义唐五代已见苗头、宋后大行——词义断代是区间不是开关，判“古今”先问**文本的写作年代**（[[classical-chinese-1/what-is-wenyan]] 地层说在此兑现）。
:::

::: exercise 户口普查 {level=1}
给六词各判一条路线并给一枚书证或化石：江、臭、獄、乖、币、汤。
::: solution
江=扩大（专名→通名，“江南”可指多水之南）；臭=缩小（气味总名→恶味，幸存于“乳臭未干”的 xiù 读）；獄=转移（案件→场所，“小大之狱”是案子）；乖=升华（违背→乖巧，方向翻面）；币=转移（缯帛礼品的专名→货币泛称——交际物换人）；汤=转移（沸水→汁液，“赴汤蹈火”化石）。路线+证据各半即满分。
:::
:::

::: exercise 假朋友逮捕 {level=2}
指出下列各句里最危险的双音组合并说明陷阱：妻子、地方、感激、学者。
::: solution
妻子=妻与子（两人组，杜甫“却看妻子愁何在”至今可读，但先秦两汉文书里“妻子”常真带儿女——陷阱在“子”的计数）；地方=土地+方圆（“地方千里”=面积千里，非 region）；感激=感动奋发（“由是感激”不含谢字）；学者=求学的人（“学者有为”）或道术之士分裂后的“有学问的人”后起——判“哪个时代”再落子。四案各指陷阱并给断代即满分。
:::
:::

::: exercise 讳饰编年 {level=2}
为“死”制一张十词讳饰表：崩、薨、卒、不禄、死、填沟壑、山陵崩、仙逝、去世、走了——按身份等级/语体/时代三列归档，并预测下一个接班词。
::: solution
等级列（礼记五等）：崩—帝王、薨—诸侯（今沿用元首级）、卒—大夫（今书面“病卒”）、不禄—士、死—庶人；语体列：山陵崩（当朝避讳）、填沟壑（自谦）、仙逝/宾天（宗教色彩）、去世（书面中性）、走了（口语现役）；接班预测合理即可（“去了”“不在了”现役，“睡去”候选）——判分在归档正确+机制解释用“污染-上新”规律。
:::
:::

::: exercise 小论文：一个词的 Biography {level=3}
写八百至一千二百字：为“经济”或“社会”或“网络”写一篇词传（biography），从本义到回归新衣到数字时代的再迁移（如“经济下行”“被××”新组合），须含：本义与演化的书证≥3、一次同形假朋友的误读实例、对“词义有没有正确解”的一句立场。
::: solution
判分点：三书证可查且年代无错；假朋友实例真实（论文献引“经济”为经世济民而作者）；立场句清晰（如：正确解=时代约定解，词典是判决书的存档不是宪法）——引本课“租约”比喻并改写者加分。
:::
:::

::: summary
词义四路搬家：扩大（江河并房）、缩小（臭禽宫退租）、转移（兵獄换址，“去”甚至改了朝向）、升降（爪牙跌落、乖洗白）；双音假朋友要拆户口（妻子真带子、感激不谢人）；讳饰是委婉词的污染-上新长跑；晚清民国“旧词穿新衣”完成最大一次换心迁移（经济、社会、革命）。词汇史是最不服从“万古如斯”的历史——本课交付一副镜片：**见熟词起疑，遇双音先拆，落义必标年代。**下一课请出十大虚词：之其而于为乃则者所——文言语法的心脏起搏器。
:::
