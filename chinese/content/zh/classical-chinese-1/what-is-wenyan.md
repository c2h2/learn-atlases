---
title: "什么是文言文"
---

一个韩国人、一个日本人和一个唐朝人坐在同一张案前，读同一卷《论语》，读成三种声音、竟也能差不多懂——这就是文言：**一种靠汉字焊接、不靠活人嗓音保存的书面语**。本课先把它的三件身份证看清楚。

## 身份证一：它是一门语言，不是一堆名言 {#sec-yuyan}

::: definition 文言的定义与三特征 {#def-wenyan}
**文言**：以先秦两汉书面语为典范、经汉代以后两千年摹仿而稳定的汉语书面系统（名称本身也古：《周易·乾·文言》的“文言”本义是“文饰之言”；拿它做一门语言的总名，迟至清末学堂与“东文”“西洋文”对举而起——名与实都值得一张身份证）。系统三特征：①**单音成词**——“国破山河在”五字五个词，现代汉语同句要长出“国家、破碎、河流”的双音尾巴（文言=古汉语的**词法**，不是古汉语的“语气”）；②**意合为纲**——关联词稀、主语能省，“入则无法家拂士，出则无敌国外患”的假设关系全靠对仗位置自己站着（[[modern-grammar/complex-sentences]] 意合的极致版）；③**尚简忌复**——“一鼓作气，再而衰，三而竭”，连“鼓”字都省两次，压缩率是文言的体面也是它的暗礁（漏译即漏考点）。
:::

## 身份证二：白话的同胞兄弟，不是它的老年照 {#sec-baihua}

::: definition 文白关系：双言分工的两千年 {#def-shuangyan}
最大误解要先枪毙：“文言=古人说的话”。孔子讲课的口语比《论语》啰嗦十倍，汉代人已看不懂《尚书》——**文言从诞生起就是书面语**，口语则继续生长成历代白话（汉译佛经、唐变文、宋语录、元杂剧、明清小说一路留声）。于是形成人类语言学标本级的**双言格局（diglossia）**：文言管科举、公文、史书、书信（庄重场合），白话管家务、市集、说书、情书（日常场合）——识字的人天然双语，切换之自然如同今天切换微信与邮件。汉字在此格局里居功：它不追语音——同写“风雨”，唐音、粤语、官话各自上口而意义不搬家（[[chinese-characters/writing-and-language]] 超方言性；语音账本见[[phonology/why-phonology]]）。
:::

::: example 压缩率现场 {#ex-yashuo}
《岳阳楼记》“政通人和，百废具兴”八字——请算压缩比并指认今译多出来的是什么。
::: solution
压缩比约 1:3。多出来的三层：①**语法胶水**（助词“了、的”、并列连词、主语补全——文言意合省掉的框架今译必须显式化）；②**双音化填充**（“政→政事”“废→荒废的事业”——古今词法换代费，[[modern-vocabulary/morphemes-words]] 单音词萎缩账）；③**冗余保险**（口语化转写要留听话容错）。结论：**文言不是“说话少”，是默认信息全在共享知识里**——今译=替它把省掉的公共内存重新买回。
:::
:::

::: definition 身份证三：有地层，可断代 {#def-diceng}
文言两千年不是一块板：①**先秦原生层**——真正的口语录音，例外多、面貌野（《尚书》佶屈聱牙正说明它当时也难）；②**汉至唐摹古层**——司马迁开先，韩柳古文运动定型，“文言”成为按典范写作的手艺；③**宋元白话渗入层**——语录、平话开窗：话本里“恁地”“次第”（处处）已是活白话词钻进文言纸面；④**明清仿古与调剂层**——八股文的“替古人说话”体最纯，同时《水浒》《红楼》让白话反灌，桐城派讲“雅洁”就是在防口语的腥味。**断代试纸**很简单：“再而衰”的先秦语法、“契丹”的唐以后名物、“臣窃以为”的奏议套话、“的、了”密度——一张文本三张试纸。读文言先问：**这是哪个时代的人，在摹仿哪个时代？**
:::

::: intuition 文言的正确打开方式：眼睛读，耳朵帮 {#int-dufa}
学现代外语靠“听说领先”，文言恰恰反着来：它没有母语者，**耳朵是借来的**。最优路径是“**视觉优先+耳音辅助**”：认字（本字通假各归各位）→ 取义（词义史就位）→ 断句（句读即语法分析，[[classical-chinese-1/punctuating]]）→ 诵读（声气节奏帮你锁定“之/乎/者也”的语法位置——虚词是听觉的标点）。背诵在此不可耻且高效：背二十篇典范，语法指纹自动入库——**语言感是样本的统计量**（现代二语习得研究给私塾背书平反了一半，条件是：背时须通大义）。
:::

::: history “文言”这个名字 {#sec-ziming}
自问自答一段命名史：**先秦**无“文言”之名（都是活文字，无须点名）；**汉代**经师口中的“文”“古字”已开始给时代划界；**唐**人论文“文言”连用渐多，指文辞；**宋**儒常以“文言”与“道”对举，文论关键词由此定盘；**清末**学堂章程语文分途，**1904 年前后“文言”终于指一种语言**，与“白话”对坐，从此成学科术语；**1920 年代后**再退休成遗产科目。一个词的寿命史，就是这门语言的兴衰史。
:::

::: warning 学文言的三种姿势错误
一**背语法不背文**：把“之”的十九种用法背成经，见到活句仍然断不了——规则是标本，样本才是活体（本课全部语法点都长在选段上，不许离体记忆）；二**以白话硬套**：“吾谁欺”非译成“我骗谁”的语序才算懂——**词的古今错位是浅坑，语序的古今错位是深坑**（[[classical-chinese-1/special-patterns]]）；三**只译不读**：文言是声写系统，默译一百遍不如成诵十遍——句读的呼吸、虚词的轻重，全在嘴上见真章。
:::

::: exercise 断代试纸 {level=1}
给四句各断一个最可能时代层（先秦/汉唐摹古/宋元白话渗入/明清）并给一枚试纸证据：①“恁地不解，却来问人。”②“一鼓作气，再而衰。”③“伏惟陛下圣德广被，臣无任犬马屏营之至。”④《诗经》“窈窕淑女”。
::: solution
①宋元白话层（“恁地”活白话词）；②先秦原生（“再”作“第二次”、动词承前省）；③明清奏议仿古文（套话密度+“伏惟”框架——摹古层晚期公文腔）；④先秦原生（双声叠韵连绵、无后世虚词）。试纸证据各配对即满分。
:::
:::

::: exercise 压缩率实验室 {level=2}
选《岳阳楼记》或《爱莲说》一段 30 字内，逐字列表（字/义/今对应词），统计今译字数，指出“语法胶水、双音化、冗余”三项各自吃掉的字数。
::: solution
判分点：字表无错义；三项分账可核对（胶水≈今译增补虚词数，双音≈单→双扩展数，冗余≈口语化加拍）；末尾一题反思：哪一字最难搬家——最硬的字就是文化词条（如“谪”“岫”），为词条建卡即本课作业。
:::
:::

::: exercise 小论文：文言死了还是退休了 {level=3}
写八百至一千二百字：“文言”1920 年退出实用、却在成语、公文四字词、标题、品牌命名里日日返场——请统计一份当日报纸标题的文言成分（四字格、之字结构、单音动词），论证你的判词：死亡/退休/变身？要求引用本课“双言分工”与“地层”两概念，数据可复现。
::: solution
判分点：标题抽样≥20 条、文言成分分类计数（格式词“诸如/旨在”、四字格、之字定语）；论证用“双言”框架解释返场场合（庄重域=文言的地盘未失）；判词允许“变身存活”一类立场，但须给出**场合清单**作为领地证据。
:::
:::

::: summary
文言三张身份证：一门有词法语法的**语言**（单音成词、意合为纲、尚简忌复）；白话的**同胞兄弟**而非老年照（双言两千年，汉字超方言续命）；一部有地层的**断代标本**（原生—摹古—渗入—调剂四层，读文言先问“谁在摹仿谁”）。名字本身也是一部兴衰史：辞饰之义起于经，语言之名定于清末，退休于民国，返场于今天每一则庄重标题。下一课进工具架：《说文》《康熙字典》到《辞源》《汉语大字典》——把“查书”查成“读书”的前置技能。
:::
