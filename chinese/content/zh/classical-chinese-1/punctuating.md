---
title: "古书句读"
---

古书原不分段、不标点：孩子先读“大学之道在明明德”，先生才许他读“大学之道，在明明德”——**断句的位置，就是理解到达的位置**。句读（dòu）是文言课的期末实操题，也是传统学术的第一门手艺。

## 句读的账与史 {#sec-zhang}

::: definition 句读是什么、为什么值钱 {#def-judou}
**句**=语意完足处（圈/句号）, **读**=语意未到、气不可断处（点/读号）——“彼童子之师，授之书而习其句读者，非吾所谓传其道解其惑者也”——韩愈把“教断句”列为小学，自认要做的是大学。这套**符号系统是读者的作业**：刻本白文、抄本旁点，点书即解题（旧学馆“点书”即先生以圈点标蒙生进度——圈点本身就是批阅痕迹）。句读为何值钱：**古代注本极少保留歧读，断错即全句翻案**——最经典的歧读案：《论语》“民可使由之不可使知之”——一逗之差，孔子改行。吕叔湘《古书句读释例》（1934）辑两千年断句翻车案盈册，是本行的事故调查报告。
:::

::: history 从“离经辨志”到圈点本 {#sec-lijing}
句读是有科举身份的正课：《礼记·学记》“**一年，视离经辨志**”——入学第一年考“析经断句、辨明志意”，是官方课程表里的句读课；汉代都讲本已有“章句”之学（《汉书·艺文志》已警告章句浮风——“说五字之文，至于二三万言”，断到支离也是病）；宋印本书坊渐用**圈点**，章句、评点、句读三套系统并行到清末（《师说》“句读之不知，惑之不解”是中唐常态证词）；**1920 年**民国教育部通令普通教育用新式标点（1920 年北洋政府教育部通令颁行《采用新式标点符号案》），圈点退位、逗号进宫——**句读从“读者自证功夫”变成“作者代客泊车”，断句的责任从此移交给排版工**。本课手艺双向：白文能断，标点能疑。
:::

## 六把断句刀 {#sec-liudao}

::: definition 句读方法论 {#def-liu}
①**虚词路标**：句末词（也、矣、耳、焉、乎、哉、欤、与）=红绿灯，句首词（夫、盖、惟、然、是故、于是）=起跑器——末字停、领头起，命中率最高的一把刀；②**结构对文**：骈偶、排比、反复的模板会自己画线（“忠而被谤，故放逐之；信而见疑，故怨生焉”式的对仗两行，断一处知两处）；③**顶针接口**：上句尾即下句头（“军书十二卷，卷卷有爷名”），重复处必有缝；④**题写与呼语**：“学而时习之”的“子曰”“诗云”“曾子曰”=章节标题牌，凡“曰/云/言”后必跟引文，引文起讫靠“曰”配对；⑤**句法归位**：主语（谁）、谓语（动）、宾语（何）三角验证——两个动词抢一个主语处、代词“之”无所指处，即当断；⑥**版本与注疏外援**：同一句三家注本异读，抄本/类书所引的旁证（“民可使由之”新读虽巧，先秦句式库不支持“可，使由之”的停顿格式——**断句要过同时代语法这一关**，非“读着顺”即可改经）。
:::

::: example 白文实测 {#ex-baiwen}
给白文断句并说刀法：“夫学须静也才须学也非学无以广才非志无以成学”（诸葛亮《诫子书》）
::: solution
断：“夫学须静也，才须学也。非学无以广才，非志无以成学。”刀法清点：①“夫”领头起跑、“也”二字停（路标）；②“非学无以…非志无以…”对文双联（结构）；③“学须静/才须学”顶针式对举接榫；四“才/学”两见成环（A→B→A 链条）。译文核对：学习须静，才靠学得；不学不能扩才，无志不能成学——语义闭环即断句闭环。刀法点满三种即合格。
:::
:::

::: intuition 句读是一种立场 {#int-lichang}
断句=解释，案卷为证：除了“民可使由之”的千年改判案，1973 年马王堆帛书出土，《老子》开篇写作“道可道也，非恒道也”——一个“也”字、一个“恒”字（避文帝刘恒讳改“常”），让通行本的断法与字面都露出改动痕迹：**我们点的“古书”，常常是汉代人点给汉代人听的版本**。句读因此有两副面孔：对读者，它是理解的温度计；对学者，它是版本的X光。凡遇“历来都这么断”，多问一句：头一个这么断的是谁、他见过什么本子？——这一问，就从学生进了研究院的门。
:::

::: warning 断句四常错
一**错断引文**：引文起讫要“曰/云/言”配对、人称与事理一贯——“某某子曰”后到哪句为止，是注家常年开庭的案由；二**误认虚词**：句末“也”判断，“也”字亦可用于句中表顿挫（“其闻道也亦先乎吾”——“也”在句中一停，“亦先乎吾”才收口）——**也/焉/乎皆有“句中一停”兼职工**，别见“也”就画圈；三**以今律古**：“吾谁欺？欺天乎”硬按今语序连读（“吾谁”不断开），清人笑话书里收录的就是这类书呆子断法——代词宾语前置的缝，要按上古语法画；四**轻改旧读**：新读再妙，先过同时代语法与版本双重门——“断句自由度”不等于“断句随意度”。
:::

::: exercise 手术五例 {level=1}
断句并标刀法：①“学而时习之不亦说乎有朋自远方来不亦乐乎” ②“臣诚知不如徐公美臣之妻私臣臣之妾畏臣臣之客欲有求于臣皆以美于徐公” ③“积土成山风雨兴焉积水成渊蛟龙生焉” ④“宋人有耕者田中有株兔走触株折颈而死” ⑤“予独爱莲之出淤泥而不染濯清涟而不妖”。
::: solution
①子曰/乎乎路标两收（“说”通“悦”，断处即通假处——句读与上一课握手）；②“臣之妻/妾/客”三排比对文，末“皆以美于徐公”总收（顶针“臣臣”接缝+对文）；③“焉焉”双句号+对文严整（骈句模板）；④“者”提顿起叙事，“株株”顶针、四小句流水（者也路标+顶针）；⑤“之”字结构长读不断，“染/妖”对文收。五例刀法各点名即满分。
:::
:::

::: exercise 错案平反 {level=2}
断句两式对照：某教材点作“一鼓，作气；再而衰；三而竭”，与通行本“一鼓作气，再而衰，三而竭”不同——判断异同与优劣，并给译法。
::: solution
两式所断相同（逗号位置改的是**停顿节奏不是句法关系**）：通行式以“一鼓作气”为成语化整读，“一鼓，作气”式强调条件—结果两步（齐军伐长勺，鲁庄公将鼓之，曹刿“未可”；“可矣”之后“一鼓作气”）——优劣：课堂朗读用通行式（气势顺），语法分析可用切分式（主谓清晰）；译：“第一次击鼓，士气振作”。判分点：说清“同句法、异节奏”、不被逗号改动吓出重新解释——**句读争议先分“解释之争”与“停顿之争”**，本案属后者。
:::

::: exercise 白文考试 {level=2}
无标点实测（课内材料自选 60—80 字，或从《论语》《孟子》《庄》《左传》取一段从未标点过的白文影印），断句后**先**与三种注本对答案，统计你的正确率，并记录一处注本间不一致处，写 100 字判断。
::: solution
判分点：白文影印存档；正确率自计诚实；注本分歧处记录页码，判断段须引虚词/对文/版本至少一类依据——允许判“存疑待校”，禁止硬解。本练习的目的不是全对，是让你**见注本如见证人席**。
:::
:::

::: exercise 小论文：标点把谁变成了作者 {level=3}
写八百至一千二百字：从 1920 年标点通令说到“古籍整理本是我们真正读的书”——标点者隐身却参与写作（课内举例：《论语》歧读案、帛书“也”字案，再加一例你亲自断错被纠正的实录）。论证：新式标点是句读的“翻译”还是“篡改”？并提案：整理古籍是否在书末附“断句异读记”应成行规。
::: solution
判分点：三案引用无硬伤（帛书年代 1973 正确）；“翻译/篡改”之辨落到机制（标点=单值化选择，原文多值并存；每标点即一次微注释）；行规提案具体（附异读记的体例设想）；结尾允许幽默：标点者最大的美德是让人看不见，其次是让人查得到。
:::
:::

::: summary
句读课结业三句话：**断句的位置=理解到达的位置**（虚词路标、对文顶针、曰云引文、句法归位、版本外援六刀连用）；**句读=解释**（“民可使由之”一逗改判孔子，帛书一个“也”字照出今本的汉代胎记）；**句读=制度史**（从《学记》“离经”课到 1920 年标点进宫，断句责任从读者转给作者，我们的自由随逗号增多而减少）。下一课也是本课最后一门正经工序：今译八技——留、换、补、删、调、对、拆合，把两千年压缩包完整解压。
:::
