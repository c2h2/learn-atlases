---
title: "文言今译"
---

翻译是文言课的期末考试，也是两千年来的日常作业——古人注经，“传”就是当时的今译。本课给一套**可检查的解压工艺**：五个动作、三档标准、一张评分表，把压缩包还原成不丢数据的现代汉语。

## 五个动作 {#sec-wu}

::: definition 留、换、补、删、调 {#def-wu}
**留**：专有与制度直接搬——人名地名官名年号（“贞观”“丞相”照录或加脚注，不折腾成“唐太宗年间宰相”的二道贩子格式）、古今一通的词（“山”“水”“笑”）。**换**：单音换双音、古词换今词——“戈”换“兵器”前先问语境要不要保留“戈”的锋利（换词有语义税：见[[classical-chinese-1/old-and-new-meanings]]）。**补**：补省略（主语、宾语、介词——上一课欠的括号在此结算）、补逻辑胶水（“之乎者也”的隐含关系译成“因为/虽然/那么”）、补文化脚注（“有司”=主管官员，正文补不下就注）。**删**：删无义虚词（句首“夫”、提顿“者”、凑足音节的“之”——“夫战，勇气也”的“夫”删，不删就成了“那战争啊…”的翻译腔）、删公文套语（“谨按”“伏惟”“即冒昧”进格式词垃圾桶）。**调**：调语序——宾语前置、介宾后置、定语后置全部复位成现代队形（“何陋之有→有何陋”“青于蓝→比蓝更青”）。**口诀：留专名、换普词、补省略、删虚耗、调倒装——五字各管一类，动刀前先回句式课调四张 X 光片。**
:::

## 三档标准 {#sec-san}

::: definition 信、达、雅的文言专用版 {#def-xin}
**信**：信息对账——实词一个不错义、虚词语气不走样（“其…乎”测度译成肯定=失血；“不亦…乎”反问译成陈述=截肢）；自查法：**倒译**——把你的今译再翻回文言，与原文比句法与词数，差额处即案发现场。**达**：译文自己要是通顺的现代汉语，不许“文言腔混进白话户”（“进行学习”“做出观看”是翻译腔双料货，[[rhetoric/choosing-sentences]] 欧化账）。**雅**：分寸感——原文朴，译文不绣花（《论语》译成散文诗=过度加工）；原文奥，译文不装浅（《庄子》的诡谐要有诡谐的对应）。**严复 1897《天演论》序**提出“译事三难：信、达、雅”，本是为西学东渐设计，今天倒过来管“古文东渐”一样灵——三档有优先级：**信达优先，雅看能力，任何以雅害信者不及格。**
:::

::: example 三译评卷 {#ex-ping}
原文：“吾妻之美我者，私我也。”（《邹忌讽齐王纳谏》）
甲：“我的妻子认为我美，是偏爱我。”乙：“妻以我为美，缘私我也。”丙：“我太太觉得我好看，因为她偏心我呀。”——按五动作与信达雅评卷。
::: solution
甲：合格基准卷——“美我”意动调为“认为我美”（调✓）、“者…也”判断架换成“是”字（换✓）、无漏无增；扣在平淡，原文的层层推理语气没电。乙：没翻译，只换体（白话读成文言=零解压，**“以雅害信”的反向病例：以雅拒达**）。丙：“太太”“好看”“呀”三连把策士家庭剧译成情景喜剧——语体跑电（“私”译“偏心”勉强、加“她”补主语✓），末叹词无中生有；**信字扣分**：达与雅都过了头。判分示范：**先对信息账（信），再验现代话（达），最后称语体（雅）**——评卷顺序不可乱。
:::
:::

::: definition 硬骨头清单：直译失灵处 {#def-yinggu}
五类词，五把不同的钥匙：①**名物制度**（“仗下”“趋”“再拜”“牺牲”）——没有对等物，只能**文内文外双轨**：“趋而进”译“小步快走上前（表恭敬）”，括号即脚注的平民版；②**文化语义场**（“社稷”=国家但带土谷神香气、“桑梓”=故乡但带树影）——保留形象加注来源，或干脆换死喻（“国家”），二选一，别造“种桑树的地方”式生煎；③**谦敬系统**（“寡人”“不谷”“足下”“执事”“窃”“敢”）——今无对等谦敬级，通译“我/您”+语体补偿（对王言“我”改“在下/臣”酌情）；④**音韵修辞**（联绵、叠音、用典、双关）——音损无法两全，**保义丢音是常赔，连义丢典是事故**（“桃之夭夭”的“夭夭”注“少壮貌”，韵丢得光明正大）；⑤**古今假朋友的最后一跳**（“牺牲”译“纯色祭品”，“感激”译“心被感动奋发”）——[[classical-chinese-1/old-and-new-meanings]] 的假朋友名单在翻译端原额兑付。
:::

::: history 从“诂”到评分表 {#sec-jinyi}
中国的“今译学”有两千年工龄：《礼记·王制》设计“移用语”之官掌“达言语、通志意”，是跨方言翻译的官制起点；**《尔雅》**十九篇，“释诂、释言、释训”把古语方语翻成通语——以今言释古言谓之“诂”，训诂学即上古的今译系；汉代今文经师口耳听录写定经典，本身就是听译工程；**唐孔颖达领衔修《五经正义》**，恐汉魏旧注“辞意幽深”令学者迷路，一并作疏——国家级古文今译审定委员会；**1958 年起点校本“二十四史”校点出版**，注译本时代开幕，译文从“注的赠品”升格为独立商品；**高考文言翻译题按 2—4 个采分点给分**——“信”第一次有了可操作的阅卷形式。这门“译”的学问，从王官之学考进了期末卷。
:::

::: warning 今译四病
一**以译代解**：整句直译却词义全错（“再拜”译“拜两次”算对了一半；典型案：“肉食者谋之”译“吃肉的人谋划它”字面对而文化层丢光——“肉食者”指当权者，**直译可以是脚手架，不能是交付物**）；二**加戏**：译“醉翁之意”添“他多么渴望啊”，原文的含蓄被你演成独幕剧——**增词只能补语法，不许补情绪**；三**减字**：“贤哉回也”译“颜回很贤”——感叹架“哉…也”折成陈述句，语气即信息，删了就是失血；四**套版**：一切“之乎者也”都译“的了吗呢”——“唯利是图”的“是”译成“的”者，当值庭前收监（提宾旗手案，虚词不是语气词的固定工）。
:::

::: exercise 采分点自评 {level=1}
译三句并自标采分点（每句 2—3 处，注明考点类型）：①“夫晋，何厌之有？” ②“我孰与城北徐公美？” ③“所以遣将守关者，备他盗之出入与非常也。”
::: solution
参考：①“晋国有什么满足的时候？”——采分：何…之有提宾（句式）、厌=满足（实词）、夫删（虚词）；②“我跟城北徐公谁更美？”——孰与=固定句式“与…相比谁更”（句式）；③“派将领守函谷关的原因，是防备其他盗贼进出和意外变故”——所以=…的原因（句式）、出入=偏义复词、义偏“入”（防备进来；译“进出”亦通，点出偏义算加分采分点）、非常=意外变故（古今异义）。三句采分点各标 2 处即满分——**标得准比译得美更接近本课的硬指标**。
:::
:::

::: exercise 语体配平 {level=2}
同译“公等遇雨，皆已失期，失期当斩”（《陈涉世家》）为三种现代语体：新闻转述、历史课件、短视频文案，各一句并说明配平动作。
::: solution
参考：新闻体“据报道，戍卒九百人途中遇雨误期，依秦法误期当斩”（客观框+“据”字免责，原文紧迫感让位于准确）；课件体“遇雨→失期→当斩：一条法律如何逼出陈胜吴广”（因果链箭头化，标题党是教具的雅）；短视频体“迟到就处死？这班我是不上了!”（第二人称代入+悬念反问——戏可以加在**框架层**，不可伪造原文层：判决词、人物动作须有出处）。三式配平动作点名即满分。
:::
:::

::: exercise 完整交付 {level=2}
选 100—150 字课内文言段落，产出三件套：①逐句对译表（原文/今译/采分点三列）；②一段流畅整译（供朗读）；③150 字工艺报告（用了哪几个“留换补删调”、最难的一处及备选方案）。
::: solution
判分点：对译表无错义、采分点命名用课内术语（提宾/意动/假朋友…）；整译达且语体配平；工艺报告诚实（承认一处“丢”并算清为何弃车保帅——韵、形象、语气三选二是行业常态）——**会算损失账，才算入了翻译的门**。
:::
:::

::: exercise 小论文：一切翻译都是解释吗 {level=3}
写八百至一千二百字：以“民可使由之”或你亲手译过的一个难句为例，论证“译文是原文的一种解释，而非原文的影子”；须使用：五动作术语、信达雅优先级、一个“两译并存互证”的例子；结论回答：既然一切译皆解释，为何考试仍判译文对错？
::: solution
判分点：论点落在**约束下的解释**（歧义空间存在，但语法、时代、版本为边界——“可，使由之”被判非法正因同时代句法库不支持）；用“两译并存互证”（如“学而不思则罔”的罔=迷惘/欺罔旧争，一案两说并陈）；结论不滑向相对主义（考试判的是边界内对错，不是唯一最佳）——引课内“句读=解释”并比较两课的“自由与边界”。
:::
:::

::: summary
今译五动作：留专名、换普词、补省略、删虚耗、调倒装；三标准优先级：信（倒译对账）＞达（现代话自检）＞雅（语体配平），以雅害信者不及格；硬骨头五类各有钥匙（制度双轨、文化注源、谦敬补偿、音损明赔、假朋友原额兑付）。从《尔雅》的“诂”到点校本二十四史再到采分点，中国“今译”这门学问答了两千年——下一课把五动作全数上机：整篇精读，从《左传》到《爱莲说》，验货的时刻到了。
:::
