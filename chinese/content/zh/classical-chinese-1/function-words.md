---
title: "虚词十天王"
---

文言的语法不穿形态的衣服，全凭虚词点灯。**之其而于为乃则者所以**——十个字管起句法、逻辑与语气的大半江山。本课一王一卡：王座（词性）、版图（用法）、判据（怎么认）、口诀（怎么译）。

## 代词系与助词系 {#sec-dai}

::: definition 之：三代同堂的忙字 {#def-zhi}
①**代词**：主之、客之，“使之闻之”连用两“之”（兼语与宾语各为其主）；②**动词**：往也——“吾欲之南海”，后面接地名即动词，判据最硬；③**助词**三职：**结构助词“的”**（“古人之道”）；**宾语前置旗手**（“何陋之有”“句读之不知”——“之”把宾语提上动词前，是提宾的专用信号旗）；**取消句子独立性**（“师道之不传也久矣”——主谓之间一插“之”，句子降格成短语，只能做主语、宾语或时间状语从句）——翻译口诀：**独立“之”字不译“的”，提宾“之”字提前译**。
:::

::: definition 其：本名是代词，兼职是语气 {#def-qi}
①**第三人称代词领格**：其子、其妻——“他的/她的/它的”；活用为**活用己称**：“余亦悔其随之而不得极夫游之乐也”（王安石《游褒禅山记》，其=自己）——反身用法古人偶一为之，考卷常设；②**指示代词**：“其巫，老妪也”（课内《西门豹》——其=那，指着一位老太太）；③**语气副词**：测度“其皆出于此乎”（大概）、祈使“尔其无忘乃父之志”（可要啊）——语气“其”坐在句首或谓语前，**译成“大概/难道/可要”，全看上下文脸色**。判据：能补“他的”者代词，能加“大概”者语气，两不沾者再查指示。
:::

::: definition 者所：两台名词化机器 {#def-zhesuo}
**者**：①动词/形容词+者=动作执行者或特征持有者（“学者”古义：求学的人；“来者”“往者”“大者”“远者”）；②**语气提顿**：表停顿与判断（“陈胜者，阳城人也”——判断句的主语后垫子）；③“者”+数词=列举归类（“此五者，邦之蠹也”）。**所**：所+动词=受事或相关项（“所爱”“所见”=所爱的人/所见的事）；**为…所…**=被动式（“为人所欺”）；**所以**=…的原因/用来…的凭借（“此先汉所以兴隆也”），与今表结果的连词是假朋友（[[classical-chinese-1/old-and-new-meanings]] 在册）。合击判据：**“者”字主动，“所”字被动**——读者与读物、学者与所学。
:::

## 介词与连词系 {#sec-jie}

::: definition 而：一根连接神经 {#def-er}
“而”只连接**谓词性**成分（动、形、小句），四张脸：**并列**（“敏于事而慎于言”——可换“和/又”）；**承接**（“学而时习之”“退而甘食其土之有”——先“退”后“甘食”，时间链条）；**转折**（“青，取之于蓝，而青于蓝”——可换“却”）；**修饰**（“吾尝跂而望矣”——连接状语与谓语，译“地”或不译）。判据三板斧：**能换“又/和”者并列，能换“却”者转折，前后有先后者承接，剩下贴动词前即修饰**。“而”不连接名词——见“而”连名词，此“而”通“尔”（你）。
:::

::: definition 以、于、为：三位介词plus {#def-yiwuwei}
**以**：①介词“用、拿、凭、因为”（“以子之矛”“以其境过清”——工具、依据、原因一伞三雨）；②连词，用法近“而”（“作《师说》以贻之”——目的，“来”字译法）；判据：**“以”后必留名词性宾语位**（“以”的宾语常前置或省略：“一言以蔽之”=以一言；“何以知”）。**于**：万能引介——处所（“战于长勺”）、对象（“告之于帝”）、比较（“青于蓝”）、被动施事（“受制于人”）；译名随谓语变戏法，**位置铁律：介宾永远在动后**（状语后置的现代脚印，[[modern-grammar/special-constructions]]）。**为**：①介词“替、给、被、因为”（“为人所欺”之被动；“不足为外人道”）；②动词 wéi“做、是、成为”（“如今人方为刀俎，我为鱼肉”——判断句两“为”）；③句尾语气词 wèi（“何以伐为”——“要…干什么”，与“何…为”框架成对）。三王同案时，先分音（wéi/wèi），再定位，后配译。
:::

::: definition 乃、则：两句之间的路标 {#def-naize}
**乃**：①副词“这才、竟然”（“乃入见”——时间紧接；“今其智乃反不能及”——竟然，语气拐弯）；②判断词“是”（“此乃臣效命之秋也”——乃字判断，与“者也”同族）；③代词“你的”（代词“你的”一职偶见注疏，备考勿恋战）。**则**：①承接“就、便”（“学而不思则罔”——条件反射的路标）；②转折“却、倒是”（“于其身也，则耻师焉”）；③并列分条“就…（同时）…”（“居庙堂之高则忧其民，处江湖之远则忧其君”——对举两景）；④判断“是、就是”（“此则岳阳楼之大观也”）。**乃看时间或语气落差，则看逻辑顺拐还是拐弯。**
:::

::: example 十字全上庭 {#ex-ting}
“臣闻吏议逐客，窃以为过矣……此四君者，皆以客之功。”（《谏逐客书》）——指出“以”“为”“者”“之”各司何职。
::: solution
“窃以为”=“私意谓”的凝固格式（“以为”连用，认为——**两个词焊成一词的化石**）；“此四君者”之“者”=语气提顿（判断句主语垫子）；“皆以客之功”之“以”=“凭借、依靠”（动词义路，或解“因”）；“客之功”之“之”=结构助词“的”。庭训：**同字异职靠位置，一词多译靠事理**；《谏逐客书》此句正是“逐客之非”的证词，虚词判对，政见才读得出口。
:::
:::

::: history 虚词：从语感到科学 {#sec-xuci}
古人读文言先不教虚词：唐宋蒙学习“语例”靠背诵，直到**南宋陈骙《文则》**系统比况辞气，章句之学初具文论体格；**元代卢以纬《助语辞》**——汉语第一部虚词专书，刊行于 14 世纪前期专为蒙生解释“之乎者也”的口气；**清代刘淇《助字辨略》**（1711）、**王引之《经传释词》**（1798）以经师之力收尽先秦虚词案卷——“之”字几十义、“其”字当读为“几”之类的考据，乾嘉学派的看家功夫；**《马氏文通》**（1898）终于给虚词发“介词/连词/助词”的西洋户口（“虚字”三品的拉丁改锥有争议，但术语从此通行）。今日学虚词的讽刺处：**当年是母语气感，如今是外语技能**——十张卡片，是给失落语感装的假肢，装上后要多走（多读），才会像真的。
:::

::: warning 虚词四大误诊
一**一词当一义**：背了“之=的”便“何陋之有”译“什么的”——每见虚词先问句型（判断？被动？提宾？），句型定，虚词定；二**位置视而不见**：“青于蓝”译“青在蓝”丢掉比较——介宾在动后是文言铁律，译成现代汉语须搬回动前（搬不动就是特殊句式，见下课）；三**古今假朋友**：“所以”表原因凭借，“无论”是“更别说”，“虽然”=“虽+是这样”——双音词组合先拆；四**过度精确**：连词“而”的并列/承接在诗文中常两可（“敏而好学”究竟是并列还是承接，旧注早已开吵），古人用虚词靠乐感，训诂强分五官，反失其浑——**判“可两从”比硬选一边更像学问**。
:::

::: exercise 判词十卡 {level=1}
给各句加点虚词定职：①何陋**之**有 ②其皆出于此乎 ③退**而**甘食 ④作《师说》**以**贻之 ⑤青，取之于蓝，**而**青于蓝 ⑥先臣**乃**忘之? 换：⑥度我至军中，公**乃**入 ⑦此则岳阳楼**之**大观也 ⑧学**而**时习之。
::: solution
①提宾旗手（“有何陋”还原）；②语气副词测度（大概）；③承接（先退后食）；④连词目的（来）；⑤转折（却）；⑥时间副词“这才”（等到）；⑦结构助词“的”（定语标记，非取消——“此”字判断句骨架在）；⑧承接或并列皆可两从——判两可并说理据即满分。八卡全对即出师。
:::
:::

::: exercise 病历会诊 {level=2}
译文门诊：“其巫，老妪，不去，为河伯娶妇，巫之患也”（自拟病译：“那巫婆不离开，替河伯娶老婆，成了巫婆的病患”），指出三处虚词/句式病灶并重译。
::: solution
病灶：①“不去”在此=不离开（走）——“去”古今反向，译文却按“不离开”绕口（“去”本句若作“不离开”，是古今义打架，当改“不肯离开”或核对原句是“不去”还是“不敢去”——**译文自相矛盾即报警**）；②“为”wèi 介词“替”✓，但漏译被动可能（若原意为“被河伯娶妇之议所累”，当用“为……所”）；③“巫之患”的“之”非“的”的顺接，应译“巫婆对此事的忧虑/是巫婆的祸患”之判断。重译示范：那巫婆是本地老妪，年年不去，全赖河伯娶妇一事敛财——这正是巫婆生财也生畏的关窍。判分点：能自证病在虚词与词义合力处，重译成句。
:::
:::

::: exercise 白文实测 {level=2}
背诵核对实测：用本课卡片在《谏逐客书》开篇 60 字内指出“之/以/于/者/乃”各一处并标注职名（允许查原文——开卷考的是判职，不是背功）。
::: solution
标准核对：原文开头“臣闻吏议逐客，窃以为过矣”：以为=凝固格式；“昔穆公求士，西取由余于戎，东得百里奚于宛”：“于”处所+对象两见；“并国二十，遂霸西戎。孝公用商鞅之法”：“之”的；“此四君者，皆以客之功”：“以”凭借、“者”提顿。判分：五处各有原文坐标，虚词职名准确——查原文不扣分，这是“带卷考试”的真意。
:::

::: exercise 小论文：虚词与语言性格 {level=3}
写八百至一千二百字：文言虚词是“意合语法”的总开关（无形态、虚词+语序顶起全部句法），据此讨论：一种“少形态、多虚词”的语言，培养出的思维有什么特征？（可调用“而”的模糊连接 vs 英语 which/that 的显式；结论须可反驳——给出一个支持形态语言的论据。）
::: solution
判分点：对“意合/形合”有课内定义与例句（[[modern-grammar/complex-sentences]] 的“意合与形合”在此回收）；比较论证具体（虚词“而”一连接四义=留白，关系从句代词必须点名先行词=锁定）；结论承认两刃剑（留白生浑融与诗性，也生考卷陷阱与训诂官司）；给得出反方论据才满分——单边抒情退回。
:::

::: summary
十张卡片各归各位：之（代/动/助三职，提宾与独字是考点）、其（领格为主、句首测度语气）、者所（一主动一受动的名词化车床）、而（四张脸三板斧）、以于为（介词plus：工具—原因、万能引介、wéi/wèi 分音）、乃则（时间落差与逻辑拐弯）。虚词史=从母语气感退化为外语技能的补偿史，卡片是假肢，多读才是复健。下一课语序：判断句、被动、宾语前置、定语后置——文言句法的四张X光片。
:::
