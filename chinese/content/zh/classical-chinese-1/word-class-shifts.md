---
title: "词类活用"
---

文言词库人手少，一个词常常跨岗兼职：名词今天站岗当动词，形容词明天兼职做“使之”。**活用不是修辞，是语法**——判断它、翻译它，是读文言的分水岭。

## 名词的跨界 {#sec-mingci}

::: definition 名词用如动词 {#def-mingdong}
名词坐到谓语位上，后面带宾语或“之”，就干起了动词的活：**衣冠**（“皆衣冠”——穿衣戴帽，两个名词双双上岗）、**军**（“晋军函陵”——驻军）、**王**（“沛公欲王关中”——称王）、**目**（“范增数目项王”——使眼色）、**坑**（“项王军新安坑之”——活埋）。**判据三查**：①位置（副词“皆/数/欲”后头或能愿动词后头的名词，几乎必是动词）；②搭配（名词+宾语/补语，“衣冠”“军函陵”）；③对文（“衣冠”与“履”对举、“耳”与“目”对举，互文见义）。**译法**：补一个动词（称王、驻军）或直接用其动作义（目→用眼色示意）。
:::

::: definition 名词作状语 {#def-zhuangyu}
名词直接坐在动词前，不当事、只打比方或报方位：**箕畚运于渤海之尾**（用箕畚）、**蚕食诸侯**（像蚕吃叶一样）、**云集响应**（像云一样聚，像回声一样应——“云/响”是比喻状语）、**夜缒而出**（在夜里）、**豕人立而啼**（像人一样站立）、**日**削**月**割（一天天、一月月——时间名词表渐化）。判断：动词前已有真动词，名词再挤进去=状语；**译文模板：用/像/在+名词**。现代汉语只剩“电话联系”零星化石，文言满街跑。
:::

## 动词形容词的“使心术” {#sec-shdong}

::: definition 使动、意动、为动 {#def-shiyi}
**使动**：主语“使”宾语做谓语的事或进入状态——“生死而肉骨”（使死者复生，使白骨长肉，《左传》）、“项伯杀人，臣活之”（使活）、“先破秦入咸阳者王之”（使他为王）、“苦其心志，劳其筋骨”（使其心志受苦）。**意动**：主语“认为”宾语如何、或“把它当作”——“孔子登东山而小鲁”（认为鲁国小）、“吾从而师之”（把他当作老师）、“侣鱼虾而友麋鹿”（以鱼虾为侣、以麋鹿为友）、“邑人奇之”（认为他奇特）。**为动**：为宾语而动词——“死国可乎”（为国事而死）、“等死，死国可乎”《陈涉世家》、“夫人将启之”（为她开门——《左传》段，为动之属）。**一副判据试两动**：中间能否塞进“使”（使…=使动）或“认为/以…为”（意动）；“死/战/急”类为着宾语而发=为动。**使动是改变世界，意动是改变眼光，为动是改变立场。**
:::

::: example 活用检测五连 {#ex-shan}
判各句活用类型并给译法：①“生死而肉骨” ②“渔人甚异之” ③“常以身翼蔽沛公” ④“假舟楫者，非能水也” ⑤“今亡亦死，举大计亦死，等死，死国可乎”。
::: solution
①使动（使死者生、使白骨肉）——补“使”字检验✓；②意动（认为它奇怪——“异”是形容词意动的招牌）；③名词状语（像鸟翼一样遮护——模板“像+名”）；④名词用如动词（水=游水，能愿动词“能”后必动词）；⑤为动（为国事而死——“死”为宾语发动词）。判据各点一句即满分：使、认为、像、能、为——五个测试词就是五把钥匙。
:::
:::


::: definition 活用不是自由恋爱 {#def-bianjie}
活用有**名单与职规**：名词跨界当动词的常客是职名、器物、身体、方位（王、军、衣、目、面、东），山水类几乎不挪窝（“山”无“像山一样阻挡”的合法用例，诗家语另论）；形容词的使动意动各有一批高频户口（苦、劳、丰、富／奇、异、小、大、耻、师）；**“动词”本身较少再活用**（使动由不及物动词与形容词担任）。“是不是活用”的终审在**句法位置**：同一个“衣”，在“解衣衣我”里前一个是本业名词、后一个是活用动词——一字两职，位置分赃。另注意**音随义转**传统读法：“王”wáng→wàng（称王）、“雨”yǔ→yù（down 降）、“衣”yī→yì（穿）——旧读破字是活用的听觉标签，今音不必强求，读书法须知道。
:::

::: history “虚实”之外的第三本账 {#sec-zhang}
古代语文学不立“词类”之名，却有活用的实操注脚：汉人注经遇“王”读去声、遇“衣”读去声，以**音读**标记兼职（“读破”传统，[[classical-chinese-1/reference-tools]] 韵书层）；《马氏文通》（1898）以拉丁“转品”（transumptio）收编汉语活用，开“名字用如动字”“形容字用如动字”的格义谱；二十世纪语法学争论活用的**存量**：王力一系主张“词类活用”是临时兼职，吕叔湘提示许多“活用”实为**一词多义**（“目”使眼色义早已词典化），“词类活用”与“兼类”至今是教材边界的拉锯战（现代汉语语法课里的“拿手”之争即其地表余震，[[modern-grammar/parts-of-speech]]）。教学口径本课这样定：**凡能在同时代语料里找到“本业”高频活着的，判活用；本业已死、兼职转正的，判义项**——判据即频率证据，不是感觉。
:::

::: warning 活用四坑
一**见名就动**：“君君，臣臣，父父，子子”是名动双岗金例，“父不父，子不子”同理——但“山”“江”类别硬派工；二**使动意动不分**：“苦其心志”（使苦）与“耻学于师”（以…为耻）差一个“使/认为”——塞词测试不许偷懒；三**把兼类当活用**：“衣”的“穿”义古书高频，“穿”已是义项不是兼职——判据看频率（上节终审）；四**今译锁死原文**：“侣鱼虾而友麋鹿”译成“与鱼虾作伴”丢了“以…为”的眼光游戏——**使意动的译法里保留“当作”框架**。
:::

::: exercise 塞词测试 {level=1}
用“使/认为/为着/像·用”给五句验明正身：①劳其筋骨 ②邑人奇之 ③嫂蛇行 ④既泣之三日，乃誓疗之（《病梅馆记》）⑤死事，义也。
::: solution
①使动（使筋骨劳累）；②意动（认为他奇特）；③名词状语（像蛇一样爬）；④为动（为梅花哭泣——“泣之”=为之泣；判一般动词带宾语亦通，说明两读即加分）；⑤为动（为事情而死，译“殉”）。五判+每判注明塞入词即满分。
:::
:::

::: exercise 一词两职 {level=2}
为下列各句圈出“本业/兼职”两职并各注译：①解衣衣我 ②左右欲刃相如 ③风乎舞雩 ④三顾臣于草庐。
::: solution
①前“衣”名词（外衣）、后“衣”动词（给…穿，兼为动/使动之泽，译“让…穿”通）；②“刃”名词→动词（杀）；③“风”名词→动词（乘凉吹风——“风乎舞雩”=在舞雩吹风）；④“顾”动词本业（拜访）——**④是干扰项：无活用**，判“本业”即对。圈职+译各到位即满分。
:::
:::

::: exercise 活用与不活用 {level=2}
判断并说明为什么不行：某生作文拟古句“狮吼其林，山立其前”——“山立”可乎？“吼其林”的“其”顶“于林”吗？
::: solution
“山立”=像山一样立——名词作状语是文言合法模板（“云集响应”同格），可；“狮吼其林”=在其林吼，“其”作“于+其”解不合法（其=领格/语气，无“在”义），当改“吼于林”——**活用名单内许跨界，名单外许今人幽默**：判“合语法/不合语法”各给依据即满分，欢迎附“文言也有诗家语的让步条款”。
:::
:::

::: exercise 小论文：活用是语法还是修辞 {level=3}
写八百至一千二百字：“山立其前”合法而“山其”不通、“水”可“能水”而“川”罕见——请以本课“名单与频率”理论，论证你立场：活用属于**语法的临时许可**还是**修辞的个人创造**？要求：自造合格与不合格例句各二（附判据）、引用课内“兼类/活用拉锯”史实、回应“诗家语可宽”论。
::: solution
判分点：自造例句语法自洽（合“像+名/使+形”等模板）且有一处“不合格”真不合格（如及物动词强作使动）；立场援引频率判据而非纯粹语感；“诗家语让步条款”有边界（何时宽：韵文对举；何时不许：散文句法）。单边之见扣结构分。
:::
:::

::: summary
活用五张合同：名→动（位置判据：能愿、副词、宾语后头）、名→状（像/用/在模板）、使动（改变世界：使…）、意动（改变眼光：认为…）、为动（改变立场：为着…）；但活用不是自由恋爱——有名单、有频率、有音读标签，王力吕叔湘的兼类拉锯提醒：**判“兼职”还是“转行”，证据在同时代语料的出勤表里**。下一课句法影像科：判断句、被动句、前置与后置——文言语序的四张X光片。
:::
