---
title: "文言特殊句式"
---

现代汉语的句序是排队进站的乘客，文言的句序是有仪仗的朝会：**判断不用“是”，被动有四套制服，宾语会插队到动词前，定语能站到中心语背后**——还有整句整句的主干玩失踪（省略）。本课是句法影像科：四张 X 光片，一张对照表。

## 片一：判断句——“是”不在场 {#sec-pan1}

::: definition 判断句的正面与侧面 {#def-panduan}
文言的判断句**靠语气与名词直接谓语，不靠判断动词**：正格“**……者，……也**”（陈胜者，阳城人也）；省“者”（和氏璧，天下所共传宝也）、省“也”（陈胜者，阳城人）、双省（荀卿，赵人——《史记》两字户口最省）加强判断用副词：**乃、为、即、则**（此乃臣效命之秋也；人为刀俎，我为鱼肉；此则岳阳楼之大观也）。否定判断专用“**非**”：人非生而知之者；子非鱼，安知鱼之乐；是非君子之言也（《礼记》）——“非”否定的是整个谓语，不是“不是”的省略。**最大陷阱**：文言的“是”多是**指示代词“这”**——“是吾忧也”=这是我的忧虑；“是社稷之臣也，何以伐为”——判断词“是”战国末开始萌芽、汉以后站稳（《桃花源记》“问今是何世”已是今式），它正是从“这”语法化而来（[[modern-vocabulary/lexicon-layers]] 语法化链条在此有一站）。
:::

## 片二：被动——四套制服加一套便衣 {#sec-pan2}

::: definition 被动标记全谱 {#def-beidong}
①“**于/乎**”引施事：“治于人”（劳心者治人，劳力者治于人）、“内惑于郑袖，外欺于张仪”；②“**为**”字句：“身为宋国笑”（《韩非子》守株农夫的结案陈词，宋国第一表情包）、“为天下笑者，何也”（《过秦论》）；③“**为……所……**”：“为巡船所物色”“先即制人，后则为人所制”（《史记》）；④“**见**”字站岗在动词前：“信而见疑，忠而被谤”（《屈原列传》）。注意“见”的第二职业——**指代性副词“对我”**：“慈父见背”（父亲离我而去）、“君既若见录”“府吏见督责”——同一个“见”，一表被动一表指向，考卷最爱同框比武；⑤**便衣被动（无标记）**：“屈原放逐，《离骚》赋作”“兵败地削”——主语是受事，全凭事理与对文（“兵败”与“地削”对举互证）。被动史一句话：**“见/于/为”先秦在役，“为…所…”两汉成规，“被”字句（“被”+动）汉后渐兴**——“被”本义“遭受、蒙”（“亮身被七十五创”还是实义动词），语法化完成于中古（[[modern-grammar/special-constructions]] 被字句的前传在此）。
:::

## 片三：宾语的三条插队通道 {#sec-pan3}

::: definition 前置宾语三型 {#def-qianzhi}
**甲·疑问代词宾语前置**：“大王来何操？”“沛公安在？”“臣实不才，又谁敢怨？”——疑问代词（谁、何、安、孰、恶）做宾语，站动词前，上古铁律。**乙·否定句代词宾语前置**：“时人莫之许也”“古之人不余欺也”“不患人之不己知”——否定词（不、莫、未、毋）+代词宾语，宾语挪到动词前（“不余欺”=不欺余）。**丙·“是/之”是提宾旗手**：“唯命是从”“唯利是图”成语组：“唯利是图”“唯命是从”“何陋之有”“句读之不知，惑之不解，或师焉，或不焉”——“是/之”是专用提宾标点，**成语里全尸犹存**（现代“唯…是…”框架即此语法化石，“唯利是视”原出《左传》——礼制语体至今沿用）。三型共同精神：**焦点前置**——疑问焦点、否定对立项、排他“唯”字，都受“先看我”的礼遇（信息结构与语序的勾当，[[modern-grammar/sentence-constituents]] 句尾追光在此反向打灯）。
:::

## 片四：定语后置与省略 {#sec-pan4}

::: definition 定语的后座与成分失踪 {#def-houzhi}
**定语后置**两式：①中心语+**之**+定语（+**者**）：“马之千里者，一食或尽粟一石”“蚓无爪牙之利、筋骨之强”（《劝学》：锋利的爪牙、强健的筋骨——后置押韵兼突出）；②中心语+定语（数量短语最常后坐）：“铸以为金人十二”（《过秦论》）、“盖简桃核修狭者为之”（《核舟记》——长而窄的桃核，形容词组也肯坐后座）；“带长铗之陆离兮，冠切云之崔嵬”（《涉江》）兼①式与楚声夸饰。**省略**是文言的日常省电：省主语（“度我至军中，公乃入”——前句主语“将军”省）、省谓语（“一鼓作气，再〔鼓〕而衰，三〔鼓〕而竭”）、省宾语（“竖子不足与〔之〕谋”“敢以〔之〕荐”）、省介词（“将军战河北，臣战河南”省“于”；“加刃”之上省“以”）。**翻译即补全：今译时补出的每个括号，都是文言省下的公共内存**（[[classical-chinese-1/what-is-wenyan]] 压缩率之债在此结算）。
:::

::: example 影像科综合读片 {#ex-duopian}
“若属皆且为所虏！”（《鸿门宴》）——一句三考点，读片并还原。
::: solution
①被动式“为所”连写：**“为〔之〕所虏”省了施事宾语——“为…所…”早期允许“为”后空转**（“若属皆且为所虏”=你们都将被他俘虏）；②“且”副词“将要”坐状语位；③“属”=辈、类（“若属”=你们这班人——敬损尺度见语体）。还原现代语序：你们都将被（沛公）俘虏。举一反三：“为人所笑”施事出现即常规式；“为所”裸奔是省到极处的早期形态——**省略与被动两课在此握手**。判全三标即出科。
:::
:::

::: history “倒装”的发现与千年争论 {#sec-daozhuang}
先秦人不觉自己的句序怪——那是母语。第一个把“怪”写进账本的是**《马氏文通》**（1898）：马建忠以西洋文法为镜，立“**倒装**”名目，历数“疑问代词、否定代词、起词（提宾）”诸倒——文言句法第一次被从inside照出X光（[[modern-grammar/what-is-grammar]] 有它的名分）。此后千年笔战围绕“倒”的方向：是古人**真这么说**（口语实录说），还是书写**变体**（骈偶押韵说）？二十世纪的语法家（杨伯峻《文言文法》一系）给出冷静裁决：**疑问/否定代词宾语前置是上古活的语法强制**（《论语》《孟子》齐整得没有例外余地），后世仿古才沦为修辞——一句话：先秦是纪律，汉以后是仿古腔。**读文言的断代眼，一半就长在这些句序指纹上**（[[classical-chinese-1/what-is-wenyan]] 地层说回收）。
:::

::: warning 读片四误
一**见“是”便判断**：“是吾忧也”译成“是我的忧虑”碰巧通、译“这是”才合古——“是”判成判断动词前，先问时代（汉前多半是“这”）；二**乱还原**：把“不己知”顺手还原成“不知己”不算完——**须知为何前置**（否定+代词的强制），否则“知我者”“不知命也”这类**未前置**的合法式反被你改错（否定句前置有代词条件，人称代词“我/尔”前置松动：“不我屑”有、“不知我”亦有——条件不查即误伤）；三**无标被动当主动**：“兵败地削”译“军队打败了仗”尚可，“地削”译“土地削减”就丢了被削——事理判受事，动词前补“被”；四**后置定语漏“之”**：“马之千里者”读成“马的千里者”囫囵——“之”是后置的**路牌**，认牌才能归位（千里之马）。
:::

::: exercise 归位手术 {level=1}
还原语序并标类型：①何陋之有 ②莫之能御也 ③客有吹洞箫者 ④舜发于畎亩之中 ⑤客何为者（《鸿门宴》）。
::: solution
①提宾旗手（有何陋——“之”路牌）；②否定句代词宾语（莫之能御=莫能御之，“之”前置且中间插能愿动词——两条件同框）;③定语后置无“之”式（有吹洞箫之客——中心语+者字短语）;④“于”引进处所，非被动（舜从田间被起用——此处**语义被动、句法介宾补语**，判“起于/发于”类要事理与句法分账）;⑤疑问代词宾语（客为何=客人干什么）。五刀到位即满分。
:::
:::

::: exercise 对比透视 {level=2}
《论语》“不患人之不己知，患不知人也”——同一句里“不己知”前置而“不知人”不前置，为什么？
::: solution
裁决要点：前置的**充要条件是代词宾语**——“己”是反身代词（上古代词，随否定式前置）；“人”是普通名词（做“知”的宾语不许插队）。同句对照，正证“前置有条件”而非古人随机——**语言里的规则感就藏在这种同框差异里**。能点出“代词 vs 名词”对立即满分。
:::
:::

::: exercise 整篇读片 {level=2}
给《鸿门宴》一段 60 字（自择含“大王来何操”“若属皆且为所虏”一段）做句式清单：每句标正常/判断/被动/前置/省略，并出一句“最复杂”给综合判词。
::: solution
参考清单（以“大王来何操？曰：不敢复言，私见张良，具告以事…”段为准，句读从教材）：“大王来何操”（疑问代词前置）；“具告以事”（介宾后置〔状语后坐〕+省略“之”）；“毋内诸侯”（省略主语+使令否定）；“若属皆且为所虏”（为所裸奔）；“吾属今为之虏矣”（“为+之+所/表被动”施事补全版——与前句恰成**同段对照实验**）。最复杂判词给“具告以事”（双病并立）合理。清单全对+对照点破即满分。
:::
:::

::: exercise 小论文：句序的等级制度 {level=3}
写八百至一千二百字：文言“谁重要谁插队”（焦点前置）而现代汉语“谁重要谁站句尾”（尾重追光）——以本课句式为证据，讨论语序与权力/礼仪的隐喻关系是否成立（成语“唯命是从”用在现代公文里算复古还是僭越？“被就业”的被动又是什么姿态？）；要求调用本课总原理与[[modern-grammar/special-constructions]]“镜头与立场”。
::: solution
判分点：两种语序原则表述准确（插队=先秦焦点礼遇、尾重=现代信息追光）；“唯命是从”分析区分**格式沿袭与语法复活**（公文里是成语化石非规则运作）；结论不玄幻——语序隐喻是解释的修辞，句法证据才是本体的纪律（敢自我拆台者加分）。
:::
:::

::: summary
五张片子：判断句（“者…也”语气+乃为非，警惕“是”的代词本职）、被动句（于/为/为…所…/见/便衣五套制服，“被”字迟到）、宾语前置（疑问代词、否定代词、“唯…是…”——焦点插队三通道，条件查清再还原）、定语后置（“之…者”路牌+数量后座）、省略（主语谓语宾语介词全可失踪，今译补账）。总原理一句：**文言把队排成朝会，现代汉语把队排成地铁**——先秦是纪律，汉以后是仿古腔。下一课认借字：通假、古今字、异体——文言的“错别字”户籍科。
:::
