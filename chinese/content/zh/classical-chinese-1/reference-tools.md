title: "字典与工具书"
---

读文言的底气一半来自“会查”。本课教四层工具：**字书**（问字的出身）、**韵书**（问字的旧读）、**注释**（问古人怎么懂）、**类书与数据库**（问词的全部案卷）。查书查对了，就是带着两千年学者随行。

## 字书层：从《说文》到《汉语大字典》 {#sec-zishu}

::: definition 说文：为读经而生的字形法庭 {#def-shuowen}
许慎《说文解字》成书于 100—121 年间，收字 9,353，立 **540 部首**，以“**先解形、因形说义、因义说音**”办案：小字下“小也，象物微之形”，考字必先认体。**三本读账本**：①许慎没有见过甲骨文金文，构形十中有误判——典型如“為”字解作“母猴也”，金文里分明是手牵象作工之形；②它记录的是**古义系统**，读先秦书第一会诊，清段玉裁《说文解字注》（1815）与桂馥、朱骏声、王筠并列“说文四家”，是本案的二审法庭；③它的部首是**义类目录**不是检字法（按造字之理归部：木部收树木、艸部收草名），查字先要懂造字思维。用法口诀：**求本义问说文，求用义问后世书**。
:::

::: definition 康熙字典与今人大字典 {#def-kangxi}
《康熙字典》（1716，张玉书、陈廷敬等）收字四万七千，体例一句话：**每字先列音切（唐韵、广韵、集韵、史记音义诸书照抄），后列义项，每义一条最早书证**——它不裁决，只归档，义项的年代学就藏在引证顺序里，会读引证就等于会查词义断代。它的坑也出名：错引、杜撰条目偶有（王引之《字典考证》纠三百余条），**清人引书凭记忆，键盘时代以前**。现代标准配置：《**汉语大字典**》（收字六万，字形音义史全录，学术案卷）与《**汉语大词典**》（复词与书证网，查“典故”与双音词的总账）；案头速查交给《辞源》（修订本，专管旧书旧音旧事）与王力《古汉语常用字字典》（常字常义列频率，附有“古汉语通论”小百科）。
:::

::: example 一字会诊：“再” {#ex-zai}
“一鼓作气，再而衰，三而竭”——按《康熙字典》的路线会诊“再”字，说明工具书如何终结“再次”的误译。
::: solution
①定位字头“再”（冂部六画）；②核音切：《唐韵》《广韵》诸切归“在代切”一等，无破读分流——音不变；③读义项与引证：首义“一举而二度也”，书证早到《易》《礼》（“再拜”“再三”皆“二度”义组）；“重复、又”的副词义书证明显晚出——**引证顺序就是词义年表**；④判决：先秦“再”=第二次/两次，故“再而衰”是“第二次（击鼓）士气就衰”，译“再次”是把晋唐以后的词义回填先秦。四步走完，误译出局。
:::
:::



::: definition 注释层：古人怎么懂，我们怎么再懂 {#def-zhushi}
字典解字，注释解句。**传注体例有台阶**：《毛诗传》之“传”是逼近原意的讲解；**郑玄**遍注群经，“注”成专名（“注者，著也”——把意思钉在句上）；唐人为汉注再作解曰**“疏”**（正义），于是标准书影是**经—注—疏三层同页**（《十三经注疏》）；集解则会萃众说（何晏《论语集解》聚诸家，朱熹《四书章句集注》宋学另起炉灶）。读注的三个姿势：①**先白读原文再抬头看注**——注是钥匙不是拐杖；②认得注的术语：“曰为”“谓之”下定义，“读曰”“读为”点通假，“某当为某”是校勘改字，“之属”“貌”是描形状貌；③注家也会错，**唐疏驳汉注、清儒驳唐疏的官司满页皆是**——服从最后一种意见之前，你在场。
:::

::: history 从韵书到鼠标：工具书的换代之路 {#sec-huandai}
音切账本在**韵书**：《切韵》601 年建档，宋《广韵》206 韵为文言读音的总法庭（“读破”异读、通假求音都拿它对表，[[phonology/rhyme-books]]）；反切不够用时还有**直音、叶音**的旧习——明人陈第 1606 年一声“时有古今，地有南北，字有更革，音有转移”（《毛诗古音考》），把叶音案推翻，古音学由此立案（[[phonology/fanqie]] 续账）。类书是印刷时代的搜索引擎：《艺文类聚》《太平御览》按类囤书证，词典编纂者千年靠它取料。**数字化完成最后一次换代**：汉籍全文库（维基文库、中研院“汉籍全文资料库”）让“逐字查”升级为“逐词全网查”——**“再”字的全部书证一屏可列，词义断代从学者绝活变成中学生作业**。但检索解决不了判决：数据库给你一百个例子，哪个义项配得上此句，仍旧人来拍板——工具换代，判断不换代。
:::

::: intuition 工具书是法庭，不是圣旨 {#int-ting}
把查书想成开庭：原文是当事人，字典是户籍科，韵书是声纹档案，注疏是证人席，类书是监控录像，你是法官。误读的常见形态是**让户籍科当法官**：“再”字字典明明两义并列（二度/重复），选哪个只有句子的时代说了算。于是“会查”的定义显形：**知道哪一层工具回答哪一层问题，并在证据冲突时履行裁决责任。**查三本工具书打一份判词，胜过抄十页参考译文——这也是本课一切“引用即证据”训练的母题。
:::

::: warning 工具依赖症三诊
一**惟字典论**：拿《辞源》义项序号直接填空，不顾句法位置与时代——义项是菜单，点菜要看胃（“再”的“重复”义写进先秦译文，字典没罪，你有）；二**惟注疏论**：朱熹说“格者，至也”，便当物理事实——注是宋学家的作业答案，不是经本身；三**惟数据库论**：grep 到二十条书证就当结论，不看版本、不管讹字、不分体裁——**检索出频率，检索不出适切**。三诊同一处方：工具是证据链，判决页永远署名：你。
:::

::: exercise 查书实操 {level=1}
用任意两种工具（纸本或汉库）查“去”字：列其本义、两个常用古义、一个今义，各配一条书证，并给“去皮”的“去”定时代。
::: solution
要点：本义“人离开”（《孟子》“君子于是去之”之属，“离开”义组）；常用古义“除去/丢弃”（课内常例“巫妪行去”——“扔进河里”的去除义）与“距离”（“相去四十里”《鸿门宴》——**距离义易被当今义漏判**）；今义“前往”后起（明清白话常）。“去皮”=“除去”义，中古已行，判唐宋可用。两工具+四义带证即满分。
:::
:::

::: exercise 术语破译 {level=2}
给注疏术语下定义并各举一例：曰/谓之、读曰/读为、当为、貌。
::: solution
“曰、谓之”=下定义（《尔雅》“母为妣”“父曰考”一路格式）；“读曰/读为”=破通假，以本字易借字（经注中“某读曰某”皆此类——判分重在机制说明）；“当为”=校勘改讹字（字形致误的“甲当为乙”）；“貌”=描摹性状（“莞尔，微笑貌”式描状注解）。四术语机制正确即满分，举例允许合理变体。
:::
:::

::: exercise 判词练习 {level=2}
“将军身被坚执锐”的“被”：用四层工具（说文/韵书或音切/注或语法书/数据库）出一份完整判词：音、形、义、通假判断。
::: solution
判词要点：说文“被，寝衣也”本义=寝衣；此处义“覆盖→披戴”引申（“被+衣/甲”跨层）；音义配合：此义当读“披”音（音随义走，韵书与今注注音 pī）；“披”是后起分化字，“被/披”属**古今字**关系而非临时借音；数据库：《史记》《汉书》“被坚执锐”书证成串，皆“披”义。判决：“被”在此为“披”之**古今字**用法——不是临时借音，是“覆盖/披戴”义分化前的分工。四层各有记录+判对关系即满分。
:::
:::

::: exercise 小论文：工具会换代，判断不会 {level=3}
写八百至一千二百字：选一个你查过的真实疑难字/词（附两本工具书对照记录截图或摘录），描述从“查到”到“判定”的全过程，标注每一步用到的工具层与你的裁决依据；回答：数据库与 AI 让“查书”变廉价之后，文言学习者的核心竞争力还剩下什么？
::: solution
判分点：记录真实、两工具对照点明确；“判定”步骤写出**冲突或不足**（义项不合/书证晚出/版本存疑至少其一）；对“廉价检索时代”的回应落在判断力与问题意识（能提出好问题、能识别假答案），允许引用本课“法庭与圣旨”案并要求改写发展。
:::

::: summary
四层工具四种问句：字书问出身（说文系形说义、康熙归档引证——**引证顺序即词义年表**）、韵书问旧读（切韵建档、陈第破叶音）、注释问古人之所懂（经注疏三层、术语即程序语言）、类书与数据库问天下用法（检索换代、判断不换）。查书的正确想象是开庭：工具出庭作证，你负责判决——署名权不可外包。下一课进实词车间：古今词义的扩大、缩小、转移与避讳贬降——“走”“去”“汤”的老底，一网打尽。
:::
