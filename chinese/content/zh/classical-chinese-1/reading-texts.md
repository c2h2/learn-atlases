---
title: "整篇精读"
---

九课的工具全部上桌，这一课是总演练：五段经典文本，一遍走完**正音—通假—句读—句法—今译—鉴赏**六道手续。读文言的终点不是“懂了一个词”，是“一篇是活的”。

## 案一：《左传》战场速写 {#sec-zuozhuan}

::: example 曹刿论战（节录） {#ex-caogui}
“十年春，齐师伐我。公将战。曹刿请见。其乡人曰：‘肉食者谋之，又何间焉？’刿曰：‘肉食者鄙，未能远谋。’……公与之乘。战于长勺。公将鼓之。刿曰：‘未可。’齐人三鼓。刿曰：‘可矣。’齐师败绩。”——白文可自测，工具全上。
::: solution
手续清点：**正音**“间”jiàn（参与）、“鄙”bǐ（固陋）；**通假**无硬案（“鄙”本字引申）；**句读**“肉食者谋之，又何间焉？”反问架（焉=句末语气+疑问，译文“又何必参与呢”）；**句式**“战于长勺”介宾后坐（调→“在长勺作战”）；**文化**“齐师伐我”之“我”=鲁国自称——《春秋》笔法自家史料自家口吻（《左传》礼制：“钟鼓鸣之曰伐，潜师曰侵”——“伐”自带宣战布告的排场）；**鉴赏刀口**：“公将鼓之/未可/齐人三鼓/可矣”——省略到极限的战场电报（“鼓之”=击鼓进军，“之”足音节），一“未可”一“可矣”六个字打完长勺之战——**《左传》的叙事经济=句法省略+战争留白**。
:::
:::

## 案二：《论语》五十字 {#sec-lunyu}

::: example 学而篇三章连读 {#ex-xueer}
“子曰：‘学而时习之，不亦说乎？有朋自远方来，不亦乐乎？人不知而不愠，不亦君子乎？’”——三十余字，读出整部《论语》的句式库存。
::: solution
**说=悦**（通假+破读 yuè）；**时**=按时（一说“时常”——朱熹注的影响，两说并存的老实呈现，正是注疏层课的实操）；**不亦…乎**=反问框架（译“不也…吗”，语气账：反问=肯定到不需争论）；**知**=被了解（**无标记被动**——“人不知”=别人不了解我，便衣被动第 N 次出庭）；**愠**yùn（怒而藏于内）；三章三排比，每章以“不亦…乎”收束——**格言体的音乐性**：框架复现+递进（个人之乐→朋友之乐→人格之乐，层递格）；**题旨层**：三句从学习到交往到修养，是《论语》开卷的“学习学”大纲——注家说“入学之门第一义”。一章练完五课，这就是选它开篇的理由。
:::
:::

## 案三：《孟子》的论辩拳法 {#sec-mengzi}

::: example 鱼我所欲也（节录） {#ex-yuwo}
“鱼，我所欲也；熊掌，亦我所欲也。二者不可得兼，舍鱼而取熊掌者也。生，亦我所欲也；义，亦我所欲也。二者不可得兼，舍生而取义者也。”
::: solution
**句法**：两套“……者也”判断句收束，对文完全对称——**先立语法模板，再灌思想内容**（模板一旦搭好，第二组自动完成论证的心理绑架：不接受“舍生取义”，就得先拆掉你自己点头的“舍鱼取熊掌”）；**修辞回收**：类比论证+层递（欲→兼→取）+对偶，文言议论文的三板斧在 2300 年前已成套；**硬译陷阱**：“兼”=同时拥有，非“兼职”；“取义”勿加戏成“争取正义”（取=择定，冷词不许热血）；**批判性一问**：类比是修辞不是逻辑——熊掌之喻偷渡了“义高于生如熊掌高于鱼”的**价值序**，这个序正是论证要证的（循环之嫌——孟子未答，课文不讳）——精读的高阶动作：连工具带漏洞一起看清。
:::
:::

## 案四：《庄子》的深渊 {#sec-zhuangzi}

::: example 秋水（节录） {#ex-qiushui}
“井蛙不可以（之）语于海者，拘于虚也；夏虫不可以（之）语于冰者，笃于时也；曲士不可以（之）语于道者，束于教也。”（通行本文字略异，节录以“井蛙…拘于虚也”为骨）
::: solution
**句读**三“者”提顿三“也”收束=骈句模板；**句法**双重被动齐飞：“拘于虚、笃于时、束于教”三个“于”字被动（于引进施事=被空间/时限/教化所缚——“于”的被动职务连任三届）；省略“语之”的指代宾语（补：之=井蛙辈）；**词义**“虚”通“墟”（所居之处——借字又一站）；“曲士”=乡曲之士（僻壤之士——解“一曲之见”是今人顺水推舟，注家未必然，可注不可定）；**今译的代价清单**：三连排的地理纵深（海/冰/道）译成白话会平——保义丢韵，本课第 N 次执行；**哲学读法**：三段是认识论的三重牢笼（空间、时间、教化），庄子用句式的整齐演出“局限的整齐”——**形式即论点**的文言现场（与修辞课“整句的秩序预付”互证）。
:::
:::

## 案五：宋散文眼 {#sec-songwen}

::: example 爱莲说 {#ex-ailian}
“水陆草木之花，可爱者甚蕃。晋陶渊明独爱菊；自李唐来，世人甚爱牡丹；予独爱莲之出淤泥而不染，濯清涟而不妖，中通外直，不蔓不枝，香远益清，亭亭净植，可远观而不可亵玩焉。”
::: solution
**文体**：“说”=议论小赋（爱莲之说，题裁一体——《马说》《师说》同族）；**句法**：“予独爱莲之出淤泥而不染”——**主谓之间“之”字取消独立性**（“莲出淤泥而不染”降格为“爱”的宾语，第 4 课头号考点在名篇上岗）；“可远观而不可亵玩焉”=转折+句末焉；**词类活用三连**：“不蔓不枝”——蔓、枝名词用如动词（生蔓、长枝，第 5 课名单内职）；“香远益清”——香而远、清而益清，性状当叙述用，诗化句法，不强拆；**修辞总账**：菊=隐逸（陶潜牌）、牡丹=富贵（世人牌）、莲=君子（自画像牌）——**对比+衬托+象征**三位，一篇 119 字承载整座人格色谱；**用字**：“蕃”=多（fán）、“亵”xiè（轻慢）、“植”=立（净植=洁净地立着，植之本字，无需破通）。精读终曲：从《左传》的电报到《爱莲说》的香水——工具没变，文体在变；**文言不是一个文体，是一千个体裁的联合体**。
:::
:::

::: intuition 精读的四种呼吸 {#int-huxi}
同一段文字可以换四种读法：**显微镜读**（逐字考据，一篇读一星期——清人的日课）、**逻辑读**（只抓论证骨架，画论证图——孟子篇的循环质疑即此读的产物）、**美读**（“以语言得作者的神气”——叶圣陶倡“美读”说，读出曹刿的淡定与庄子的浩叹）、**互文读**（把《爱莲说》放进“托物言志”谱系，上接《荀子·法行》的玉德论，下启周敦颐的理学人格——单篇读成群像）。中学老师常抱怨“文言教成解剖课”——病根在四种呼吸只做其一；本课五案故意各按一种主打：案一叙事语法、案二句式库存、案三论证批判、案四形式即论点、案五文体谱系。**精读不是读细，是有选择地细。**
:::

::: history 精读课文的千年换代 {#sec-keben}
“读哪些文言”本身就是一部教育史：汉代重经（《诗》立博士；邹鲁谚“遗子黄金满籯，不如一经”——《汉书·韦贤传》存账）；唐宋以诗赋与古文取士，宋人语“《文选》烂，秀才半”——总集即教科书；元明退到《四书》章句，蒙学读《千家诗》；**1904 年《奏定学堂章程》**“读经讲经”科与“中国文”科并存，经典让位学科；**1920 年后**课文白话化，文言精读缩编进“文言文”单元；**1980 年代人教社**文言课文占比约四成，与“彻底摆脱文言”的激进案拉锯；**2017 统编本**古诗文百余篇，占全部课文近半，配“多读多背、不求甚解”的统编方针——**从“一经”到“一百二十篇”，精读篇目的换代，就是“培养什么人”的答案换代。**
:::

::: warning 精读四止
一**止于译**：全文对译即宣布学会——《鱼我所欲》的循环论证、曹刿的留白艺术，全在译文之外；二**死于碎**：一个字讲四十分钟，一篇上三课时——碎片化感动不了人，也考不倒人（整篇的呼吸感要整篇读，晨读十分钟整读>晚自习四十分钟零件盘点）；三**迷信一家注**：朱熹“时=时常”与汉注“按时”并陈才见注疏生态（参考书只买一家的通病）；四**以今度古**：用今人价值观径断古人（“曹刿的乡人真冷漠”“孟子强词夺理”）——历史语境是精读的空气，脱离即窒息。
:::

::: exercise 独立手术 {level=2}
从《孟子》《庄子》《左传》《战国策》任一未学过选段（80—120 字）做六道手续完整报告（版式仿本案五格式）。
::: solution
判分点：六栏齐备且顺序执行；正音通假各≥2 处有据（注本或字典页码）；句法诊断点名句式类型；今译采分点自标；鉴赏不复述译文、须含一处“形式服务论点”的观察——六栏皆满即结业手术合格。
:::

::: exercise 同题对读 {level=2}
“勇”主题对读：《曹刿论战》（夫战，勇气也）、《论语》（勇者不惧）、（《孟子》“自反而缩，虽千万人吾往矣”一章）——列表比较三家“勇”的定义与论证策略。
::: solution
参考表：曹刿=勇在士气（物理—时机变量，叙事给例）；论语=勇在人格（道德常量，格言定义）；孟子=勇在自我审查（“自反而缩，虽千万人吾往矣”——理义内求，推论+引语）——三家定义不同、证明方式不同（例证/定义/内省推论）；判分：定义准确+论证策略各点名+表外结论一句（“勇”是坐标不同而非对错之争）。
:::

::: exercise 小论文：精读一篇还是读通一片 {level=3}
写八百至一千二百字：叶圣陶说“教材无非是个例子”——精读五案若只为应考，值不值？要求：①以本课某案为例展示“单篇→群文”的两条延伸路径；②讨论“举反三”需要哪些条件（模板显式化、变式对比例）；③给出你自己的“一学期精读六篇 vs 泛读三十篇”课单并辩护。
::: solution
判分点：延伸路径真实可走（案三→《告子上》全文→中西舍生取义对论；案五→托物言志谱系+理学背景）；“举一反三”机制说清楚（反三需先识别“一”的类型特征——即课内句式与文体模板）；课单含篇目、顺序、检查方式——空谈“兴趣”不给结构者退回。
