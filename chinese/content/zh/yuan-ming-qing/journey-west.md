上一章的账本记到招安为止；本章换一本空账本——**《西游记》的伟大不在于它说了什么，而在于它允许三种读法同时成立，并且每一种都能在里面找到自己的证明：这就是寓言的形式特征——它的意义不在作者存了多少，而在读者能存进多少**。

## 定义：三种读法与一场作者讼案 {#def-sandu}

::: definition 三张处方 {#def-chufang}
**①证道读法**（**以全真内丹术语解八十一难：铅汞、婴儿姹女、心肾（通说脉络：明代刊本多带道教色彩，清儒有“丹经”之说）——**它的证据很硬：书里确实用了一套修炼语汇；它的弱点同样硬：解释力太强，什么都能解释（第 1 课“不可反驳的解释不是解释，是立场”**）；**②玩世读法**（**神魔外壳下的晚明官场讽刺：圣旨、奏本、斡旋、背景（通说读法脉络）——**证据在细节的行政程序里：天界有一整套衙门作风（**它最流行，因为它最实用：读成讽刺，读者就从迷信里赎回了笑声**）；**③修心读法**（“心猿”“意马”是全书自用的语汇（通说）——**把取经读成一个心的训练史：**它的长处是把全书变成一个连续动作（而非一串遭遇）**）。**作者讼案**（**今见早出繁本为万历二十年（1592）世德堂本，今见早出繁本为万历二十年（1592）金陵世德堂刊本，序文作者与成书经过另有讨论（通说）；清代曾有“邱处机作”之说盛行（因《大唐西域记》与《长春西游记》同名而混），鲁迅、胡适据《天启淮安府志》著录归于吴承恩（通说脉络）——**一部书的书名可以被另一部书偷走作者三百年（第 9 章真伪案的最夸张版本：**署名不是真相，是一份需要保管的合同**。
:::

## 寓言的经济学 {#def-jingji}

::: definition 把心理过程写成冒险 {#def-xinyuan}
**心猿意马**（**“心猿”本是佛典与宋明言论里的现成比喻（通说）；《西游记》的发明是把比喻当成角色表：**一个比喻一旦被派了工资，它就得每天上班（**寓言的经济学：一次内心事件必须卖一个场面：**贪吃要长成猪，嗔怒要长出棒（第 3 章降本工程在心理层的移植：**把“多因”压成“有人”，这里的“人”是自己的器官**））；**妖怪的分类学**（**八十一难的对手大致是几种失调：口腹（八戒式的贪）、虚名（斗法与赌赛）、情欲（女儿国、蝎子精）、恐死（求长生的整条线）——**于是“打怪”获得了可复述的含义：**但小说从不点破，点破就成了语录（**寓言的分寸在于保留场面的独立性：这也是它能在三种读法之间反复出租的原因（第 9 章“超级 IP”的心理版。
:::

## 天宫与灵山的衙门化 {#def-yamenu}

::: definition 造反的逻辑边界 {#def-zaofan}
“**皇帝轮流做，明年到我家。**”（通说引文）——**注意这句话的语法：它不否认皇权，它否认现任（第 3 章“省话地图”：**连叛逆也不追问制度：**孙悟空要打倒的只是坐在龙椅上的那位，天宫的公文、官制、排队与升迁全都保留（**这也是他能被招安的前提：他要的是编制，不是改革（**造反的想象力在这里触到了它的天花板：这部小说后来让这只猴子成了佛，但没有让任何一座天宫改选**。
:::

::: definition 箍：一项治理技术 {#def-gu}
**紧箍的功能**（**外部强制的最小装置：**它不问动机，只罚动作（**它的成功标志是它最终消失：取经尽头“箍儿自不在了”一类收束（通说情节）——**规训完成的定义是约束变得看不见（第 7 课限定=保险杠的英雄版：**箍是打在一个人身上的“政策限定词”：它让“齐天”的强度透支变成可执行的路线（第 2 课强度三档：不套箍，他活不过第三回**））；**它同时是一个伦理难题**（**观音授箍、唐僧念咒、悟空受力：**三方之中没有一个可以申诉（第 6 课：被驳者的四美德在这里没有位置，因为这是一次没有对手的管教：**爱的暴力常被这样免审（**小说的诚实在于它不假装悟空不恨：他一次次想走，又因为箍、因为义、因为打不赢而留下）。
:::

## 妖怪的社会学 {#def-shehui}

::: definition 关系决定结局 {#def-guanxi}
**后台规则**（**通说读法：有主子的妖怪被领回，无主子的被打死（金毛犼、青牛、黄眉 vs 白骨精、蜘蛛精、六耳猕猴）——**这不是作者的讽刺，是小说的因果模型：**行为只决定过程，关系决定结局（第 3 章算法的水浒镜像：那里是“哪一栏”，这里是“谁家的”（**更狠的是它连例外都不给：六耳猕猴既无后台又被打死——它甚至不是妖，是“二心”的化身（**因果模型在这里自我缝合：连反例都被收编进教义（第 1 课：不可反驳**））；**孙悟空的求援学**（**他的战斗方案从“单打”变成“查户口”：**先调查来路的族谱与雇佣关系，再决定是打还是请（**这是全书最现代也最官僚的一层：武力的效率取决于它能否被上级的程序吸收（第 8 章“信源四问”的降妖版：**先问“你是谁的人”）。
:::

## 难数与无字经 {#def-nanshu}

::: definition KPI 的自我完备 {#def-kpi}
**八十一难**（**通说情节：末后清点难簿，不足八十一，于是再补一难（通天河老鼋掀冰）——**目标从“取经”变成“凑数”：**制度在自身完成度上发现了新的可测量项（第 10 课“检查是二次审计”的荒诞版：**当验收标准本身可以被加戏，工作就永远做不完（而小说把这件事写成了一个笑话：这是它最冷的一页）。
:::

::: definition 无字真经 {#def-wuzi}
**通说情节**（**阿难、迦叶索“人事”不得，传无字之经；东土怪之，返而复请，始得有字真经——**三层反讽叠在一起：①**佛也要钱（**渎神到寺院会计层面**）；②**无字才是真的（**内容被宣布为零**）；③**但人间需要纸（“**只可向那边求之”：读者被要求自己填（第 1 课“分发格式决定生死”的反题：**如果格式决定一切，那么内容可以是零；而这部小说偏要把零写成一部百回的畅销书：**它在演示“空”的成本：为了让人接受无字，必须先造出十万八千里的字。
:::

::: example 三读白骨精 {#ex-baigujing}
“三打白骨精”（通说情节）分别用①证道、②玩世、③修心三种读法各写 60 字解读；然后写第 4 种“非寓言”读法：**把它当成一个信息不对称的委托—代理故事**，并说明：**四种读法里，哪一种最难被驳倒，为什么**。
::: solution
**①证道**——**妖魔起于自身水火：打的是自己体内的妄动；三打是三次火候的调匀（**优点：与文本术语相容；风险：**它把外部世界全部取消**。
**②玩世**——**妖怪会变，官印与文书也会变；难的不是打，是让上级相信你已经打过（**它把全书读成公文事故：孙悟空的委屈是基层干部的经典叙事（**证据：唐僧每次都要“证词”**））。
**③修心**——**悟空看见的是事实，唐僧看见的是动机；三打写的是“信任需要成本，而成本由被信任者付”（**最容易被现代读者引用，因为它是管理课材料。
**④委托—代理**——**委托人（唐僧）不可观察行动结果，只能观察代理人的表象行为（“打死一个女子”）；代理人（悟空）掌握全部信息却不被相信；重复博弈中的最优解是**先示好再打**，但悟空的性格不支持（**信息经济学把“义”翻译成合约问题。
**判词**——**最难驳倒的是④：**因为它不索取文本授权（不需要书里出现“信息”二字），只需要结构同形（这正是所有“科学读法”的共同策略，也是寓言长寿的机制：**它的骨架足够抽象，能被任何一套当代术语收养（第 15 课“经典＝可被反复误读的精度”**）；**最易驳倒的是①**（**它声称这是作者与宗教传统的原意——**原意可被文本与史料反驳；结构同形不可（第 15 课意图谬误：读者能存进去的，永远比作者存进去的多——但把存款当本金，就是讼案的开始）。
:::
:::

::: intuition 寓言是开源的 {#def-kaiyuan}
**《西游》的续书与改写从未停过**（**明季续书、清代戏曲、民国连环画、动画与电影（通说脉络）——**一部寓言的寿命取决于它能被多少次错误地读懂：**每次误读都提供一个新的市场（第 3 章“可授权的宇宙”的最强案例：**孙悟空是中文世界最成功的开源角色：他的许可证上只写了一句“不许停下来**”）；**“儿童化”是一次伟大的降维**（**把修炼与讽刺删掉、保留打怪：二十世纪把《西游》读成童话（通说脉络）——**这不是退化，是文类的换电池：**寓言必须让最小的读者也能进场，否则它只配活在注疏里（第 7 章“精选即删改”的正面案例：**有时候删改是救生**。
:::

::: exercise 小论文：开源的猴子 {level=3}

::: summary
空账本归档：三读（**并列展示，并排可驳倒性**）、心猿（**比喻一旦派了工资就得每天上班**）、天宫（**造反要的是编制**）、箍（**约束成功的标志是它看不见：而小说不替他道歉**）、关系（**六耳猕猴缝合因果：连反例都被收编**）、无字（**把零写成十万八千里的字**）。方法一句话：**先问这部书允许几种读法，再问它替你留了哪块咽不下去的东西**。下一章：家庭的小说——《金瓶梅》与拟话本。
