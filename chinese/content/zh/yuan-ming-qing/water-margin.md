title: "《水浒传》"
---

上一章的算法把一切归给大人物；本章把它搬到江湖——**《水浒传》做的是一场道德实验：把“义”放到没有公共规则的环境里运行；结果它既生出武松式的深情，也生出劫法场时“不问青红皂白”的滥杀：小说诚实地记了两组账，这是它比任何侠义故事都现代的地方**。

## 定义：并传——最贵的接力赛 {#def-bingzhuan}

::: definition 二十回一双眼睛 {#def-jieli}
**结构**（**鲁十回、林十回、杨志、武松、宋江……一个人物的主场演完就把镜头交给下一个来者（通说“套结构／连环结构”）——**文学史上一场昂贵的接力：**每棒换一双眼睛，代价是没有一个人看完全部（第 3 章末的问题在此被解：不讲全知，讲转手：**权威从一个叙述者变成一串证人（第 8 章“独立来源”的叙事化：真相由彼此不认识的人分段作证**））；**技术红利**（**新人物永远由“被谈论”先出场：史进说鲁达、茶坊说林冲、酒店说宋江——**名声先到，人后到：**读者带着账本见客（第 9 章推荐语：水浒世界的社交货币是绰号＋一件传闻（“杀人须见血，救人须救彻”一类江湖格言（通说）——**绰号是评语的固化：一个人被社区如此引用，就被如此定价**））；**结构风险**（**主角游移、前重后轻：招安之后节奏失控（通说批评）——**这不是笔力衰退，是文类换挡：并传体写“入伙”天然好看（每条上山的理由都不同），写“结伙”天然难看（一个集体没有视角**。
:::

## 林冲：选项的逐条注销 {#def-linchong}

::: definition 忍的算术 {#def-ren}
**七次退让**（**误闯白虎堂前忍、刺配沧州忍、途中董超薛霸要下手仍忍、沧州牢城营忍、看守草料场忍、陆谦来骗也忍——**通说情节链：**直到山神庙亲耳听见自己将被烧死，他才杀人（“忍”不是性格，是一套退路清单；把清单逐条划掉，剩下的那道就是暴力的算术（第 2 课“限定条件”的负向实验：**一个人的所有限定都被制度注销之后，你不能再用“性格变了”解释他**））；**风雪山神庙**（**那一场火是文件销毁：**他最后的良民身份被烧掉了——**鲁迅《华盖集》“论‘费厄泼赖’应该缓行”一节里以“山神庙”“野猪林”为喻（通说引用脉络）——**现代读者也在替林冲记账：**“不犯我不犯他”的道德在专门违法的人面前失效，这是《水浒》被二十世纪反复引用的原因**）；**上梁山还要纳投名状**（**落草也要业绩：**连造反都有入职流程（第 6 章“制度先于意愿”：梁山不是自由人的联合，是一个有 KPI 的武装公司**。
:::

## 宋江：信用的发行者 {#def-songjiang}

::: definition 及时雨的天使投资 {#def-shiyu}
**“及时雨”的机制**（**他在还没有故事的时候就预付了所有故事：初见便送棺材本、认义、埋人——**道德信用的天使投资：**他的本金不是钱，是“此人必不卖我”的预期（第 9 章“推荐是预言，兑现率是工资”的信用版：**宋江的兑付率极高，于是他的名字成了流通货币（江湖上“山东呼保义”五个字可以抵一支军队（**语言经济学：绰号是代币，宋江是造币厂**）））；**账本的两栏**（**对兄弟一栏记满：义气、患难、同死；对平民一栏常常空着（**通说批评：李逵式“杀将去”的代价由旁人支付——**这不是作者的道德败坏，是文类的记账法：小说只对有名有姓者算账（第 8 章“没有分母的分子”：梁山的高光时刻，从来没有统计过街面上死了几个卖炊饼的**））；**“替天行道”的旗帜学**（**一面旗把劫掠改写成候补公职权：**品牌再定位，长期目标写进合同（第 4 政策主张的完整案例——**执行主体是谁？“天”不签约，能签约的只有皇帝：所以招安不是宋江的失算，是这块旗子的唯一兑付方式（悲剧是商业模式的必然**。
:::

## 义的两面 {#def-yi}

::: definition 私刑的合法化 {#def-wusong}
**武十回的连环**（**西门庆—潘金莲一案：告状失败（通说情节：官府被买通，告状不准）→ 武自营取证（邻舍立中证、口供画字）→ 私刑处决 → 自动去官府投案（**通说情节——**技术判词：这是水浒世界最精彩的一次程序替代：**取证、见证、自首三样俱全：私刑被办成了一个自制法庭（第 8 章“程序是弱者唯一付得起的武器”的反面：**程序买不通时，弱者只能自建程序，而自建程序的成本是命**）；**司马迁的旧账**（《史记·游侠列传》“**以匹夫之细，窃杀生之权，君子是讥**”（通说引文）——**汉代史官已经给这件事定过价：民间的义与国家的权相冲，史家讥，侠客行；《水浒》把这笔分歧写成了一整部小说的收支表**。
:::

::: definition 滥杀的账 {#def-lansha}
**江州劫法场**（**通说文本里李逵“**不问军民，一斧劈将去**”一类描写（引文大意从通说）——**小说不回避、甚至不评论：**它只是把这两组数字并排放着（义士的斧与看客的头（**这是《水浒》的道德勇气：**它把读者的欢呼与读者的不安留在同一页（通说批评脉络：自明人笔记至现代小说史研究，皆有“羡杀”之讥（第 1 课“不给出事故”的反面：**不给出解释，也是叙事的一种诚实**））；**“义”的分类学**（**对兄弟的互惠（可回收）、对弱者的同情（偶发）、对敌人的销毁（不留名）——**三种“义”共用一个字，因此常常彼此掩护（第 2 课“一个词必须一义”：读《水浒》的全部技术，就在每次出现“义”字时问一句：哪一栏？**）。
:::

## 语言、评点与下游 {#def-xiayou}

::: definition 与粗致精 {#def-yuyan}
**宋人说唱材料的语言底座**（**通说脉络：成书“以白话为语言底本、累代层积”（明人已有“**与粗致精**”之评，通说引文）——**方言、行业语、衙门套语入文：**人物不说理，人物办事（第 9 章话本“我们、你、我”进正文的胜利在此结账：**《水浒》的第一位作者不是罗氏，是汴京与山东的说话声**）；**技术细节**（**“那婆娘”“那厮”“官人”“大郎”的称谓系统＝社会坐标；一句话内定位说话人与受话人的尊卑亲疏（第 7 课“称谓是权力的收据”的教科书页**。
:::

::: definition 金圣叹斩《水浒》 {#def-zhan}
**七十回本**（****通说：金评本以“惊马”一回首（石碣天文）为全书之止，另增“卢俊义做梦、英雄尽戮”为收（通说），并伪托“贯华堂古本”为据——**批评家的不满被写成第七十一回：**他不能容忍招安，于是给全书加了一场集体处决的梦（第 1 章“团圆＝司法宣告”的反向：**用噩梦代替判决**））；**改写结局的权力**（**这是中国批评史上唯一一次“改写结局”成功进入通行本（通说脉络）——**读法可以造经典，也可以造版本：**我们今天说的“《水浒》到梁山泊英雄排座次为止”，一半是金圣叹的教学成果（第 2 章批本即定本、第 3 章毛氏《读法》的三部曲在此合奏：**十七世纪的三位编辑（李卓吾、金圣叹、毛宗岗）比十四世纪的任何作者都更决定我们读什么**））。
:::

::: definition 从三十六人到一百八 {#def-xiawu}
**史料的瘦**（**通说：北宋末宋江起于河朔、史载三十六人、海州一带受招安（通说脉络）——**宋人笔记（如宣和遗事一类）与地方志里，这支队伍已被写成“三十六猛将”的名单（第 1 课史料分层的标本：**从“宋江三十六人”到“一百八人”，中间隔的是三百年的说书与两次水灾**））；**招安的下游**（**元代杂剧里的梁山人物多有“正果”，明人续书、清人《荡寇志》则让它们被剿灭（通说脉络）——**同一伙强盗，在不同朝代交替被招安与被讨伐：**文学史的招安政策随政治气候调整（第 3 章“立场三向叠加”的水浒版**。
:::

::: example 给“义”开分栏账 {#ex-zhang}
任选一个梁山情节（“三打祝家庄”，通说），为其中的“义”开三栏账：**对兄弟（谁受益）／对共同体（谁立了规矩）／对第三方（谁付账）**，并写出：**如果这场仗被一个祝家庄的庄客见证，小说的哪一句话会消失**。
::: solution
**三栏**——**兄弟栏**（**入伙者分战利品、受伤者被抬回、败退时有人断后：**可回收的义，记账清楚（第 9 章互惠原理**）；**共同体栏**（**“三日内破庄”一类军令与“先破祝家以立威”的战略目标：**义被折算成组织纪律与信誉（立威是给潜在盟友与敌人看的广告（第 3 章招牌经济学**）；**第三方栏**（**庄客、钟离一家、登云之妻与一家老小：**账面上只有人数与“尽数诛戮”一类的动词（第 8 章“分子与分母”——**这就是为什么这一回读来既痛快又不安**）；**“若由庄客见证会消失的句子”**——**凡称对方为“淫妇”“丑虏”的定性语，以及“替天行道”的旗号本身：**见证人换一位，同一行为的科目就全换：这不是版本问题，是视角的物理性质（第 4 章：所谓“客观叙述”只是没人有机会说话**）。
:::
:::

::: intuition 侠的两种用法 {#int-xia}
**“侠”在中国叙事里始终是一项备用制度**（**它不被赞美为自由，被默认为补救：官府失能时，私人暴力才取得执照（第 6 章“让步要能收回”：水浒的执照是故事随时在收——**武松自首、宋江尽忠、李逵被毒死（**全书对“侠”的三次收权：小说比它的读者更懂暴力需要善后**）；**现代用法**（**从民国武侠到影视，梁山故事被反复改写为“反抗压迫”（通说脉络）——**每一版都删掉一些第三方账目：**改编史就是分栏史（第 7 章“精选即删改”的政治版：**谁被从账本上划掉，是意识形态最诚实的自传**）。
:::

::: history 一本强盗书的升职 {#sec-shengzhi}
**1120s** 宋江起事与受降（**通说：**历史只给了三十六个名字与一次归附（第 1 课“骨架与血肉”的分账从这两个数字开始**））；**1200s—1300s** 《宣和遗事》与说话、杂剧中的水浒人物（**名单、绰号、情节雏形渐积：**集体写作在通俗文学里是生产方式（第 2 章条款**））；**1400s—1500s** 百回繁本与嘉靖间的刊刻（**通说脉络：**一条强盗线被写成长篇小说，需要书坊先相信长度可以卖钱（第 1 章条款的第二次兑现**））；**1600s** 李卓吾评本与“发愤之所作”说（通说脉络——**批评家替它申请了文学资格：**一部讲杀人的书被读成一部讲不平的书**）；**1640s—1660s** 金圣叹七十回本（**删结局、加噩梦、伪古本：**编辑的胜利**）；**1700s** 《荡寇志》（**反向收权：**让梁山被王师剿尽——**清人用一部续书把一部小说的判决改了回来（第 3 章“版本即意识形态”的极端案例**））；**1900s—今** 从“革命小说”到黑帮叙事与课本节选（**《智取生辰纲》的独立命运：**选本把造反讲成智慧，把断头讲成代价的缺省（第 7 章长案**）。
:::

::: warning 水浒四坑
**把“农民起义”当天职解释**（**一部书被一种生产方式解释到底，就再无内部道德问题：**它首先是一部关于暴力组织如何自我合法化的小说（这个题目在任何时代都有效**））；**把“义”读成无条件美德**（**三栏不分，则滥杀可被掩护为豪迈（**每次出现“义”字问一句：哪一栏（分类学条款**）））；**以金本为古本**（**七十回本是十七世纪的编辑成果：**引用要注明版本；“原貌”在这里是一种幻觉（第 1 课版本方法论第四响**））；**替人物做心理诊断**（**李逵是叙事装置，不是病例：**他的功能是把“义”推到不计算的程度，好让读者看见不计算的代价（第 3 章：性格是分配的结果**。

::: exercise 小论文：暴力需要善后 {level=3}
写六百至一千字，评“**《水浒》最诚实的地方，是它写完英雄的行动以后还要拍一场清算：它知道一把斧头劈下去以后要有谁来扫地，所以它让宋江尽忠、让李逵被毒、让卢俊义梦见刀斧手——它并不比读者更热爱暴力，它只是比别人更早地问了一句：然后呢**”。须调用：**并传的接力与盲区**、**退路的逐条注销**、**宋江的造币机制**、**旗帜与招安的兑付逻辑**、**私刑作为自制法庭**、**金圣叹的噩梦**至少六项；并裁决：**“侠”作为备用制度在叙事上是否只能以失败告终——必须以“如果梁山大成功”为思想实验，写出那部可能存在的小说长什么样（以及它为什么不好看）**。
::: solution
判分点：六项机制（**接力、注销、造币、兑付、自制法庭、噩梦**）；思想实验（**参考：若招安后功臣封王、共享太平，故事就变成一部授职名录：**梁山的叙事价值恰恰来自它的解散方式（暴力团体的合法化在制度上不可能，所以只能在叙事上悲剧——“然后呢”是这类小说唯一的续集（判卷看是否指出：**《水浒》之后的《荡寇志》与《金庸》式归隐，是同一个“然后呢”的两种答案：一个替它判罪，一个替它退场**）；结论若能写“**所有歌颂出手的小说都会在一句‘后来呢’里露馅：《水浒》把这句问话写进了正文，所以它是经典，而不是爽文**”，即 A。
