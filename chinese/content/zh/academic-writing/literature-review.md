title: "文献综述"
---

前三章备齐了问题、材料与卡片；本章把它们写成一段能让评审放行的文字——**综述不是把别人说过的话摘要一遍，而是把一领域分成三栏：哪些已定、哪些在争、哪些无人问；然后说明你站在哪一格**。

## 定义：单位是问题 {#def-danwei}

::: definition 书架目录与战场地图 {#def-dituzu}
**本课的第一判据（**综述的组织单位是问题，不是作者（**按作者排列的综述是一份书架目录；**按问题排列的综述是一张战场地图（**一个可以在宿舍里做的检验（**把你综述的小标题里所有人名删掉；**若小标题仍然成立，你写的是综述；**若剩下空白，你写的是一份读书报告（**通说脉络：**这就是多数“综述被退回”的实际原因，而评语往往写成“综述缺乏评述”，这说法太弱，它应当写成：你没有提出任何问题来组织这些文献（**为什么这很难**（**因为它要求你先有问题；**而学生常在写完综述之后才有问题（**本课的顺序建议：**先写第三章的三句测试与第四章的五栏卡片，再回来排小标题；**若你按别的顺序写，你会重做一遍——**这不是吓你，这是本章唯一一处对时间的忠告。
:::

::: definition 三栏与那张矩阵表 {#def-juzhen}
**综述的内容只有三栏（**①已定**（**不再有人认真反对的东西：术语的定义、材料的整理成果、若干被反复验证的结论；**写明它已定，是为了让读者知道你不打算重做（②在争**（**两派或三派，且分歧可被定位到某一份材料或某一个前提（**定位不到分歧点的“争论”多半是你没有读懂（③无人问**（**包括三类：无人注意的问题、无人使用的方法、以及无人核对的旧说法（**技法（**用一张矩阵表把这四栏排出来：行是一篇篇文献，列是你在问的三四个子问题、他们用的材料、他们的方法、以及他们是否触及你的问题（**排完之后小标题会自己长出来**（**因为同一列上出现的空白或对立，就是你的小节（**通说脉络：**这就是循证研究中证据表的通俗版；**而它有一个副作用本课认为比方法学价值更大：**它逼你承认有几篇文献你根本没读懂，因为那一格填不出来（**这一格空白，就是你答辩上最可能被击穿的地方（**趁还来得及，去读。**
:::

## 定义：三种失败 {#def-shibai}

::: definition 编年体与权威名单 {#def-biannian}
**①编年体**（**“二十世纪三十年代有人提出，五十年代有人补充，八十年代有人修正”（**它的病灶：无人对任何判断负责，因为时间被当成了原因（**改写办法：**把年代放进括号，把主张放进主干（②权威名单**（**列出所有该引的名人以求安全（**本课的诊断：**这是一种保险行为而非学术行为；**它的成本是引证通胀——**引用不再指向任何具体的依赖关系，于是它也不能再保护你（**评审的读法很直接：**一段里出现七个名字而没有一个判断，等于告诉读者此人没有判断（**这一条是第 17 门课“引证通胀”在综述里的具体形态；**顺带说一句，把一位你并未真正读过的权威列进来，也已经是第 8 章要讨论的那一类问题（③贪全**（**想写一部覆盖全部语言的文学史式综述（**处理：**若你真做一份可复现的全面综述，它本身就是一篇论文，应按论文标准写并另设题目；**否则请收缩到你的材料能到的地方（**通说脉络：**系统综述之所以在医学里被单独成为一类，就是因为它是一份研究而不是背景；**人文学科也常如此，只是少有人这样声明（**这一句是本章对学生最实用的一句：**你写的综述可以变成一篇可发表的短文，前提是你按研究而不是按背景来写它。
:::

::: definition 缺口与两张皮 {#def-quekou}
**综述的最后一句必须是缺口；**而缺口有严格的形状要求（**①它必须是前两栏的推论**（**不是新话题（②它必须与你的三句测试逐字对齐**（**若你的缺口是“尚未有人核对某类材料的引用情况”，而你的主张是“某观念在宋代已经形成”，那么你的论文有两张皮（**通说脉络：**导师圈的这个词很粗，但很准：综述讲一套，正文做另一套（③它必须是可以被你完成的**（**若缺口是“此问题需一部完整的总集”，那是愿望（**一个可自检的句式（**“已有的讨论在＿＿与＿＿之间分歧，其分歧取决于＿＿是否成立；本文用＿＿检验＿＿。”**若这个句式你填不满，说明你的综述还没有把分歧定位到前提上（**这就是上一章“反读”的集体版：**反读用于一篇文章，综述用于一领域，动作相同（**本课由此给一句总纲：**综述不是关于过去的报告，而是关于你那一格辩护的开头；**这就是为什么它必须写在你的设计之后。**
:::

::: definition 贡献的三型 {#def-gongxian}
**“本文的贡献”只能是三种之一，且必须只挑一种为主（**①新材料**（**一份没人用过的档案、语料、访谈或版本；②新方法**（**把一个别处成熟的方法搬到你这类材料上，并说明它在此处的失真（**第 3 门课与上一章“方法错置”在此兑现（③新解释**（**材料与前说都在，你给出另一种说明，并证明旧说明在一个可指出的地方失效（**本课对“创新”一词的处理（**学位论文要求写创新点，这是制度而不是知识要求；**正确的写法是把它当作一个位置声明：**与谁不同、在何处不同、凭何判定不同（**通说脉络：**把“创新”写成“不同”，可以免除全部夸大的风险，而它同样满足表格（**这一条也解释了为什么综述要老实写“已定”栏：**你若不承认已有共识，读者会以为你不知道；**你若不知道共识，你就无法把你的不同说清楚（**全课程至此的一条暗线：**承认得越多，可主张的越少，而可主张的那一点越硬（**这是学术文体与宣传文体的根本算术差别。**
:::

::: example 重组一段综述 {#ex-chongzu}
一段典型的综述原文（**本课自造的仿体**）：“**张三指出该现象与商业化有关。李四认为应归因于制度变迁。王五又补充了技术因素。赵六不同意张三。近年来学者们对此进行了多角度探讨，取得了丰富成果。**”请指出三处病，并按问题重组。

::: solution
**三处病**（**①主语全是人名**（**删掉人名后小标题与信息全废（上方判据）；②分歧未定位**（**“不同意”没有说出在哪个前提上不同意，于是无法推进；③末句是一种无人负责的赞美**（**“丰富成果”不可核查，且是全文唯一一句判断，反而暴露作者没有判断（**重组形状**（**把问题拆成三个可判定的子问：**其一，成因的第一位是需求侧还是制度侧（**张三与李四的分歧实际在这一问；**他们的分歧取决于一个双方都未检验的假设：商业化程度能否被度量**）；其二，技术因素是原因还是条件（**王五的主张与①并不冲突，他与张三的分歧被综述错记为同类**）；其三，证据能否区分这几种解释（**若不能，则所谓“多角度探讨”其实是三种不可通约的描述（**三栏落位**（**已定：该现象的时间范围与基本材料；在争：成因第一位；无人问：**没有一篇用同一份材料检验过三种解释**（**这就是缺口，而它逐字对齐你的研究问题（**判分（**能识别出“王五与张三的分歧并不同类”者为 A**（**这是综述最难的一种错误：**把不同问题的答案排成同一排，然后宣布存在争论；**它制造的是伪争论，而伪争论一旦被写进综述，你的论文就在反驳一个不存在的人——**第 17 门课“钢铁人”的反面在此出现（**判卷时我给这一条最高分，因为它比任何文献量都更能说明一个人是否读懂了他读的东西。**
:::
:::

::: intuition 综述是给三个读者写的 {#int-sange}
**三个读者与他们的不同要求**（**①导师与开题委员会**（**他们要的是“此人知道自己不必做什么”；**所以“已定”栏要写得比“在争”栏更明确；②未来的评审**（**他要找的攻击点是你那句最宽的概括；**所以本章最重要的一条纪律在此（**凡你写下的领域概括，都可能被引用来反对你（**“学界历来认为”“多数研究同意”这两类句子，须能被你举出三篇；**举不出就把它们改成“张三与李四均主张”（③一年后的你**（**你要靠这段综述决定论文第二章写什么；**所以缺口那一句要写成一条待办而不是结论（**通说脉络：**本课把这称为外交文书的写法：它必须同时经得起三方翻译（**这也是第 24 门课那条“只写你愿意被别人拿去检查的话”的学术版——**而综述是这门课里最容易被截图的一段：你的“研究现状”三个字，常被导师原样抄进意见表。**
:::

::: history 一种文体的来历 {#sec-laili}
**十九世纪**（**研究型大学把“在既有工作之上推进”设为学位论文的条件，专题报告式综述随之成为训练环节（**通说脉络：**这就是为什么第二章必须写综述：它不是一种知识礼貌，而是一项制度残留的考核（②**二十世纪中叶以前**（**人文学术以长编、考订与札记的形式交代前说，其体例近似注疏（**通说脉络（③**1970 年代**（**为汇总大量试验结果而提出的“荟萃分析”一类方法出现，使“对已有研究做研究”成为独立方法（**通说脉络（④**1990 年代以来**（**循证医学与系统综述的报告规范逐步定型：检索式、纳入排除、流程图、偏倚评估（**通说脉络：**本课强调：**这套规范比人文学科的综述早地解决了本章开头那个问题——**它要求综述本身可复现（⑤**本世纪**（**部分学科要求投稿附文献地图或综述；同时出现以批量生产综述为业的论文工厂（**通说脉络：**这一现象给综述一个新问题：**一份格式完美、内容编造的综述如何在评审中不被识破（**本课的答案与下一章同一：**靠它内部的可核性——**每一句概括是否指向具体文献、每一处“在争”是否给得出两篇对手（**评审只能抽查，因此你写下的每一句都会按可被抽查的标准来衡量；**这就是为什么本章要求你写矩阵表：**它让你在写作当天就知道哪一格会被抽查出来是空的（⑥**最近**（**生成式工具可以片刻产出一篇像样的综述（**通说脉络：**本章的收束判断（**综述这种文体的全部价值，本来就在于有人替一领域的分歧承担判断；**工具能替你排列，不能替你承担（**你交出的那份矩阵表，就是承担的证据。

::: exercise 小论文：替对手说好 {level=3}
