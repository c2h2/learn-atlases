上一章让你能重现自己读了哪些；本章要让你能重现自己为什么这样想——**而它首先要拆掉一个几乎人人使用的装置：摘抄。摘抄把“我读过”与“我理解了”记成了同一份文件，于是在写作那天，两者一起失效**。

## 定义：一张卡片五栏 {#def-wulane}

::: definition 五栏格式 {#def-wu}
**本课的强制格式**（**一张笔记只写一件事，分五栏：①可打开的位置**（**作者、年、页码；若是网络材料，加访问日期与稳定地址（**通说脉络：**一部讲论文手艺的老书把卡片当作工作核心，其理由至今成立：卡片不会被装订成你以为的样子（②最小片段**（**只有当你需要它的原词时才抄，且标明这是抄（③作者的主张**（**用作者自己的术语写，不加你的评论；④最强证据**（**作者用来支持它的那件东西：数据、引文、版本、例证；⑤我的反应**（**同意、反对、待核、以及它让你想到什么（**本课对第五栏的严格规定（**它必须出现在前四栏都写完之后，并且必须能与前四栏区分（**这一条就是第 8 章诚信问题的预习：**许多抄袭不是偷别人的话，而是把别人的主张写成自己的反应而不自知（**通说脉络：**这也是本课程反复的“把事实与推断分栏”在个人层面的形态（**应用文那条“事实／推断／建议三栏必须分开”，在此缩成一张卡片。**
:::

::: definition 最小可引用单位 {#def-danwei}
**一张卡片该多大**（**要小到能在写作时被单独取用（**三条判准（**①它只包含一个可判断真假的成分**（**若你无法用一句话说出这张卡片在主张什么，它应当被拆成两张；②它能被单独引用**（**将来你在论文里可能只用到它，而无需连带另外三点；③它带有自己的位置**（**页码跟着卡片走，不跟着文件走（**本课的量化建议（**一份硕士论文通常需要三百到六百张这种卡片；**若你写了六个月只有三十张，你多半在读而不在做笔记，或者在抄（**反面（**“一章一张卡片”的写法几乎必然产生印象型笔记：**因为它太大，装不下区分，于是只剩下你的感受（**通说脉络：**感受不是没有价值，它是灵感的来源；**但它是不可审计的，所以它只能待在第五栏。**
:::

## 定义：三遍读法 {#def-sanbian}

::: definition 每一遍交付一栏 {#def-jiaofu}
**本课的顺序（**①第一遍**（**只读标题、结论、小节题与注释首末；交付：这张文献与我的问题是什么关系**（**材料、方法、对手、还是背景**）；**写不出这一句就删掉它，别存进硬盘（②第二遍**（**读方法与证据；交付第三、四栏（③第三遍**（**只在必要时读；**目的是试图在合上文件后重建作者的论证；**重建不出来的地方就是你没懂的地方，也就是你不能引它的地方（**通说脉络：**这一遍是本课程对“读懂”的操作定义：**能重建，才算懂（**它与上一章“注释先读”合起来构成一门课的阅读法（**本课对第一遍的态度（**多数学生不肯做第一遍，因为它看起来像没认真读；**而它是节省时间的全部来源：**在第一遍上，你应当淘汰九成材料（**淘汰要有记录（**你要写下为什么淘汰**），否则你在写综述时会怀疑自己漏了什么，然后回头重读一遍——**这是研究生第一年最常见的一次时间损失。**
:::

::: definition 反读 {#def-fandu}
**高阶的一步（**在读完作者的论证之后，做三件事（**①找出他回避的例子**（**若一篇论文的论证最依赖某一时段或某一类材料，而他恰好没有处理边界上的例子，那里就是他的弱点，也是你的机会；②找出他未讨论的三种可能反对**（**并判断这三种反对是否在他的框架内可被回答；若其中一种他能回答而他没有回答，那是疏忽；若他不能回答，那是缺口（**这就是第 2 章“第三项”选题法的日常做法（③注意脚注最密的地方**（**本课给一条经验性读法（**不是统计规律，只是习惯：**作者在一个地方引十条，通常说明他自己也不安心（**通说脉络：**这句话只能用来决定你下一步去核什么，不能用来做指控（**这是它与本章全部其他建议的区别：**反读是一种取证路线，不是一种结论（**你在答辩里若说“我认为作者的论证在某处依赖一个未说明的假设”，这是贡献；**若你说“作者脚注多所以心虚”，这是失礼（**两者的材料完全相同。**
:::

::: definition 三种失败的笔记 {#def-shibai}
**①摘抄型**（**只有第二栏；其症状是笔记本很漂亮，写作时想不起自己为什么抄（**本课的诊断（**抄写的动作太舒服，它冒充了理解的动作；②印象型**（**只有第五栏；其症状是“这篇文章很有意思，但我说不清哪儿有意思”；③收藏型**（**材料在八个文件夹与两个软件里，一栏未写（**本课的戒律（**凡未写下至少一条反应的材料，一律视为未读（**这一条在开题与答辩时都要执行：**若你无法为某篇你说读过的文献交出第三栏，就不要把它列进参考文献（**通说脉络：**参考文献里有一篇你并未真正读过的东西，是学术界最常见也最不被追究的一种不端（**这一句会在第 8 章变成一次分类讨论。**
:::

::: example 改写一张卡片 {#ex-kapian}
一张学生的笔记全文如下：“**读某先生《某某集》。先生论宋人之词，以为一洗绮罗香泽之态，读之使人气象凛然，深得风骚之旨，可谓知言。**”请诊断并改写为五栏。

::: solution
**诊断**（**五栏全无：**第二栏是抄，抄的还是一句赞语；第三栏**（**作者的主张**）被省略了；第四栏**（**证据**）不存在；第五栏**（**我的反应**）被混入引语，写成“可谓知言”，而这既非作者主张亦非可核查反应——**最致命的是第一栏：没有页码，也没有版本（**通说脉络：**没有页码的引文在写作那天是不可用的：它既不能核对，也不能引用（**改写形状**（**位置：作者、书名、版本、页；②原文：仅当“一洗绮罗香泽之态”确为其原话时抄，并加引号；③作者主张：宋代某派词的评价性判断——其价值在于风格与“风骚”传统的接续；④最强证据：作者所举例篇；若原文未举例，此栏写“未举例”，这一栏的空白本身就是信息；⑤我的反应：其判断标准与前一门课第 9 章“格调”一类的方向词同型，**不可检验**；可用于我的第二章作为清代批评语言的证据，不可用于证明宋词的品格（**判分**（**能自动在第⑤栏写下“可用于什么、不可用于什么”者为 A**（**这是卡片与读书笔记的真正分界：**一张卡片必须预先说明它能承担什么论证；**否则写作那天你会高用它——**而高用引文正是评审最常圈出的毛病（**这一处也解释了为什么笔记要写五栏而不是三栏：第三栏与第五栏之间那道缝，就是你与那本书之间的距离（**通说脉络：**而这距离就是论文里所谓“研究现状与本文的关系”。**
:::
:::

::: intuition 一年后那个更懒的你 {#int-yinian}
**本课对读者的设定**（**笔记的唯一读者是十二个月后的你；**而他有三项变化：不记得任何上下文、比现在更急、且倾向于用最小的努力完成当前动作（**四条设计要求（**①不依赖记忆**（**每一张卡片自足；不写“见前”“如前所述”，除非附上编号；②不依赖好意**（**写清楚“此处作者未举例”，而不是留白**（**留白在一年后会被读成“当时我认为很重要”（③可被机器帮忙**（**一致的字段、可检索的关键词、以及不含“最终版”“真的最终版”的文件名；**命名规范不是洁癖，是给未来的你留的检索式；④三处备份**（**一份在本地、一份在别处、一份可导出为纯文本；**数据库与软件会停服，纯文本不会（**通说脉络：**本课把这称为研究档案的四十年标准：**你写的代码、记的笔记与存的语料，应当按“四十年后还有人想知道你怎么做的”来保存（**第 3 章的检索日志与本章的卡片合起来，就是那份档案的全部；**而绝大多数研究者的档案在毕业那天丢失——**这不是个人悲剧，这是知识的损失。**
:::

::: exercise 小论文：用自己的话 {level=3}
