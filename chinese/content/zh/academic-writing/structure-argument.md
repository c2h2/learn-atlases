title: "结构与论证"

前五章管你读什么、记什么；本章管你写出来的东西怎样立住——**论文的每一节只承担一种功能，每一个段落搭成主张、保证、证据、限定四件；结构不是美观问题，而是让读者能在你最弱的地方打中你的方式**。

## 定义：节的功能 {#def-gongneng}

::: definition 一节一事 {#def-yijie}
**本课的强制规则**（**一节只承担一种功能：交代背景、界定术语、交付材料、执行论证、处理反例、说明局限（**三条检验（**①小标题检验**（**把小标题写成一句主张而不是一段说明；**若一个小标题必须用“和”“及”才能说完，那是两节（②删除检验**（**假想删去本节，全文是否仍然成立；**若成立且无损，本节应当删（**通说脉络：**“若无必要，勿增实体”这条中世纪的原则，在写作课上的形式就是这一问；③换位检验**（**把本节移到别处是否同样合适；**若同样合适，说明它未与论证咬合（**为什么这条规则常被违反**（**因为写作者希望每一节都显得充实；**而论文的充实感来自一处只说一事的重复劳动，不来自一节说五事（**本章的口号（**结构的功能是让反对可以定位；**一节说五事的文章不能被反驳，也不能被支持——**它只能被评价为“还行”，而这在学术里等于被忽略（**与上一章“综述是给三个读者写的”相衔：能被抽查的段落才有信誉（**这一句也是第 17 门课那条“可被杀死的论点才是论点”的建筑版本。**
:::

::: definition 骨架的三种排法 {#def-gujia}
**三种常见结构及各自的适用（**①由证据到结论（**归纳式；**适用于材料新而读者未必同意你的推论；好处是每一步都可核查，坏处是读者要读到最后才知道你要说什么（②由结论到证据**（**倒金字塔式；**第 24 门课为编辑发明的格式，本章把它给评审（**适用于期刊论文与一切读者可能只读前两页的场合；**它的风险是首段一旦说满，后文就成了重复（**本课的处方：**首段给主张与三条理由，后文给理由之间的差别（③问题式**（**以一个难题引入，逐步排除不成立的解法，最后给出你的解；**适用于长篇与人文学科（**通说脉络：**本章的偏好（**学位论文用第三种，其摘要与第一章末用第二种；**这是两种结构的合法拼接，其接缝处必须有一句“本文的论证路线是……”（**这一句叫路线图；**没有路线图的长文，其读者会迷路，而迷路的读者会把责任算在作者头上（**这一条与第 19 门课“结构不是美学而是承重”同构（**本章把它给论文。**
:::

## 定义：段落的四件 {#def-sijian}

::: definition 主张、保证、证据、限定 {#def-si}
**本课教的段落模型（**①主张**（**本段要立住的那一句，通常在段首；②保证**（**从证据到主张之间那一步凭什么成立：一条规则、一个推论原则、或一处公认的类比；③证据**（**你的材料、数据、引文、版本；④限定**（**这一步在什么条件下不成立、你的结论到哪为止（**通说脉络：**这一框架来自一部讲研究技艺的著作对论证的分析，是二十世纪后半叶最可教的一版（**本课最看重第②件（**它是最常被省略的一件，而它是评审真正在看的一件（**学生写“此诗作于某年，故作者时在某地”，其中的保证是一条未说出的规则“集中编年的可靠性”——**一旦写出保证，读者就能攻击保证而不是攻击你的材料，而这正是好的争论该发生的地方（**第④件的位置（**限定必须在本段之内，不能留到“展望”；**把限定推到最后一章是一种修辞技巧而非诚实（**这与第 9 章局限一节完全同一议题（**本课给一个评分动作：**凡段落只有主张与证据两件者，本段不得分**（**理由：它不给你任何可改进的接口——**你无法“部分同意”一个只有两句的段落。**
:::

::: definition 让步而不失位置 {#def-rangbu}
**让步的技术规格**（**①让步要具体到可核查**（**“此说有一缺点”不是让步；“此说无法解释某类材料中的三例”才是（**第 17 门课“钢铁人”的操作含义：**你让步的必须是对手最强的那一版，不是最弱的（②让步后要有一个转折的成本表**（**句式：即使如此，本文仍主张＿＿，因为其代价落在＿＿，而本文认为＿＿更贵（**让步不是礼貌，是一次成本比较的公开（③不得让步于不可两立之处**（**若对手的结论与你的结论不能同真，你只能说“他更强地解释甲类材料，我更强地解释乙类”，并给出划界的依据；**含糊的“各有道理”会被评审读成你没有理解分歧的性质（**通说脉络：**这一条在人文学科尤其重要，因为这里的分歧常常是判准之争而非事实之争；**判准之争不能靠让步解决，只能靠说明你为何采用这一判准（**而说明判准的位置是第一章，不是第四章——**这是本章对结构的一处具体建议：**把判准声明放在第一章末，不要埋在方法节里，因为它将决定读者如何读你全部的材料（**这是第 16 门课那条“标准即分配”的段落级执行。**
:::

::: example 拆一段 {#ex-chai}
一段学生的论文原文（**本课自造的仿体**）：“**宋代类书繁多，文人多以博物相高。某书引《某某记》一条，其文与今本小异。可见宋人所见书与今不同，此风一时如此，学者不宜以今本限之。**”请用四件拆解，并补出所缺。

::: solution
**拆解**（**主张**（**末句“学者不宜以今本限之”；②保证**（**未写；**其隐含保证是“类书所引即宋人所见之本”与“小异足以推翻以今本校勘的惯例”两件，且这两件并不互相支持（③证据**（**一条引文之“小异”；**而“小异”未列明，故证据其实未被交付（④限定**（**无（**三处补法**（**①把主张缩到证据能承担的范围：**此条可证宋人所引与今本有一处文字之异**（**一个可核的最小主张；②补保证并说明其弱：**若类书引书不改字，则此异可据以推其所见本；然类书多删节改易，故其推论力有限（**这一步不是自贬，它是把你的论证从“不可信”搬到“可信但未定”的位置上，而后者是可以继续工作的（③补限定：**本文仅据此一条讨论其一例，不作一般结论；**这一句会替你挡掉答辩上至少两个问题（**判分（**能识别出该段的两个未声明保证并且指出它们互不相容者为 A**（**这就是“保证”这一件的训练目标：**论证的失败极少在材料，而在材料到自己结论之间那一步偷偷走了捷径（**第 3 门课“连词海关”在段落级有了它的高级版：**每一个“故”“可见”“由此”都是一次关税未付的过境（**本章要求学生通读自己的稿子，只圈这几个词，然后在每个词后面插一句保证（**这是本章唯一的作业，也是本章最有效的作业。**
:::

::: intuition 结构的道德意义 {#int-dao}
**一个不常见的说法**（**把论文写清楚是一种道德行为（**三条论证（**①含混的结构使读者无法定位错误，因此它把出错的成本转嫁给读者；**清晰则把成本留在作者身上（**这就是本章所谓可审计性在段落层的形态（②含混常常是策略性的**（**它使一篇无内容的论文显得有内容，使一个未证明的主张显得已证明（**本课不假设作者有意；**但读者的读法不能按作者意图来定（③清晰使他人可以接着做**（**你的第五节被推翻时，别人能在你的第四节上继续；**含混的文章被推翻时一切归零（**通说脉络：**这是学术界对“写得难懂”长期宽容的代价：**它使一部分人用晦涩来掩盖未做的工作，而所有人和他一起付利息（**本课的立场与第 1 章“可核实的最小单位”相同：**你若希望别人核你的说法，你就要先按能被核的方式装订；而装订不是包装，装订是主张的一部分（**这一句在应用文里叫格式，在论文里叫结构，在网页上叫信息架构；**三者是同一门手艺的三个名字。**
:::

::: exercise 小论文：可被击中的结构 {level=3}
写六百至一千字，评“**清晰不是文风偏好，而是一种风险分配：它把可能被证明错误的部分摆在最前面，好让别人不必读完你的四十页就能指出你错在哪。学术写作因此是一种自愿暴露的写作，而它之所以有效，是因为整个行业都按同一种暴露来计价：可被击中的论点才值得被引用**。须调用：**一节一事与三条检验**、**三种骨架及其拼接**、**段落四件**、**让步的成本表**、**判准前置**、**合规而无论证的论文可以被写出来**至少六项；并裁决：**倒金字塔式（结论前置）是否应当被规定为人文论文的默认结构（须给出你反对或支持的代价**。

::: solution
判分点：六项机制；裁决（**必须写出你所选立场的代价：**支持结论前置**（**代价：人文学科的主张常依赖材料的积累顺序，先给结论会使读者以你的结论去读材料，从而看不到材料中的其他可能——**这是把发现的过程换成结论的展示，而发现正是这类论文的全部价值（**若答卷能指出这一层，即为高分；②反对**（**代价：读者可能在到达你的结论前放弃，而现实中文稿的评审是按小时计价的；**这一代价是真实的、经济的，不是美学的（**本课接受的综合**（**分层前置**（**摘要与第一章末前置结论，正文各章保留发现的顺序，并在每章首用一句承上；**这既满足“可被击中在前”，也不把发现压成展示（**判卷最高分给这条结构方案，因为它可执行且不牺牲价值（**加分（**能承认“可被击中的论点才值得被引用”这句里有市场逻辑**（**引用是学术的销量；**于是清晰部分地是被引用压力教出来的，而不是被美德教出来的——**这一句与上一章“工具能替你排列，不能替你承担”合成一个完整的现实主义：**行业的压力与行业的伦理常常做的是同一件事，只是动机不同（**结论若能写“**所以我支持分层前置：让反对者在前五页就找到他要打的那句话，让你自己在第四章保留那一点绕远路的好处。一篇论文最诚实的形式，是它把可能被证明错误的部分摆在最贵的位置上——最贵的位置是别人会读的那几页**”，即 A。
