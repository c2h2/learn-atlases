前九章给了你一份可以交出去的稿子；最后一章处理那两个小时——**答辩不是考试，而是一次有限度的审计：几个读过你论文的人，用最省力的方式找出你最不能防守的那一句。因此准备答辩的正确方法不是背讲稿，而是攻击自己的稿子**。

## 定义：论文这台机器 {#def-jiqi}

::: definition 部件与各自的扣分 {#def-bujian}
**一份学位论文的十个部件与其唯一职责（**①摘要**（**交付一个结果；**病：只交付主题——“本文讨论了某某”不是摘要，是目录的一行（**本课的规则与上一章给空白期那条相同：给它一个动词与一个宾语（②绪论与问题**（**三句测试的正式版本；**病：把主题当问题（③综述**（**三栏与缺口；**病：书架目录（④方法或材料**（**让他人能重做；**病：写成读书心得（⑤分析与章节主体**（**一节一事；**病：一节五事（⑥反例与对手**（**钢铁人的制度化；**病：全文没有一个对手（⑦结论**（**只说材料支持的，且交代它到哪儿为止；**病：结论比引言还大（⑧局限**（**见下节（⑨参考文献**（**你读过且支持你那一句；⑩附录与致谢**（**给后来者留路（**通说脉络：**这十个部件不是格式要求，而是十个可分别打分的位置；**评审表上的栏目基本就是这十个（**本课的备考建议：**按这十项给自己先打一次分，并写下每一项你预计别人会给几分——**两者之差就是你的不安，而不安的位置就是答辩要问的位置（**这一条是本章最省时间的一项准备。**
:::

::: definition 局限一节的三条规则 {#def-juxian}
**这一节最容易被写成道歉或写成空页（**①写真的局限**（**即那些会削弱你的结论的东西：材料的边界、方法的替代解释、样本的构成；**判据：**读完这一节，读者应当对你的结论的信心略低于读之前（**做不到就是广告（②不写谦虚辞令**（**“本人水平有限”“错误难免”一类句子不传递任何信息，而它们会让评审怀疑你在敷衍；**承认要具体到可改正（③每条局限配一个“若要解决需要什么”（**这不是展望体的礼节，而是让读者判断你的局限是技术限制还是设计缺陷（**本课说（**局限一节是全篇最容易拿分也最容易丢分的一节，因为它是一次自我认识的能力测试（**它与上一章末“可交接的承诺”同源：**能说出自己在哪里必须收手的人，别处才可信（**通说脉络：**这也解释了为什么有些评审会因一句恰当的局限说明而放过一个更大的漏洞：他们读的是作者的判断力，不是清单。**
:::

::: definition 五类提问 {#def-lei}
**答辩上的问题大致分五种，而它们的意图不同（**①澄清型**（**“你这里说的某某指什么”；**意图：他不理解或不确信你理解（②挑战型**（**“你的材料能否支持这个结论”；**意图：这是他真正反对的地方（③扩展型**（**“能否推到别的时间、别的地区、别的人群”；**意图：他在替你找可发表的部分（④比较型**（**“为什么不用某理论或某方法”；**意图：他想知道你是否知道有别的路（⑤无关型**（**一个明显跑题的问题（**意图：他在测你被拖走时会不会失态，或者他只是走神（**本课的判别法（**分不清意图时，就用一句中立的重问把责任拿回来：**“您是在问我的定义，还是在问这个结论是否能成立？”**（**这一句在真实答辩里既救人也暴露人；**它救那些只是问不清的人，它让挑战型问题提前显形，于是你有整个剩下的时间去回答它（**通说脉络：**这一招与第 17 门课的“清场”是同一动作的口头版。**
:::

::: definition 回答的四步 {#def-sibu}
**每一问按四步答（**①复述**（**用你自己的话把问题说一遍；**两个作用：买到十秒钟，并且防止你回答一个他没问的问题（②承认可承认的**（**这一问里对方对的部分，明确说对；**注意让步要具体（**③给出你的理由或材料**（**并且只给直接相关的那一两条；**答辩上最长的失败是重新讲一遍论文（④说明你打算怎么处理**（**改一句措辞、补一节、加一个脚注、或承认无法处理而写进局限（**本课的四步禁忌（**不得说“您在文中没读懂”式反指**（**它把责任推给在场者，而你在他们的规则里；**不得说“这个以后再说”**（**除非你当场写明“改为第几节”（**通说脉络：**答辩记录会被写进修改说明，而“以后再说”在文件里的名字叫“未修改”（**这一条与上一章“痕迹”直接相接：**答辩之后的修改说明，是这场审计唯一留下的可查文件；**它是你的签名。**
:::

::: definition 防守清单 {#def-qingdan}
**本课要求的准备物**（**一份不超过十页的表，每一章三问：**这一章最强的反对是什么；**我据何回答；**若我答不了，论文的哪一句需要改（**三条用法（**①它在答辩前是无价的**（**因为它把攻击面数出来了；**评审的攻击面永远是你最不愿意说的那一句（②它在答辩中不可带入**（**你必须把它的要点背下来，尤其是第三栏（③它在答辩之后可以直接改写成修改说明**（**你在压力下说过的每句承诺都应落进文件（**通说脉络：**许多学校要求提交“修改对照表”；**把它当成防守清单的续页，而不是抄写工作（**本课给一句总结：**答辩上唯一真正有用的资产，是你能不能准确说出自己论文的三条弱点以及它们的边界；**评审对弱点本身大多不介意，他们介意的是你不知道（**这一句本章写两遍，因为它是最容易被忽视的一条：**知道弱点是你的工作，有弱点不是。**
:::

::: example 五问 {#ex-wuwen}
五个常见提问与两种回答（**本课自造的仿体**）。请判断哪种回答落在四步的哪一步，以及坏回答犯了哪一条。**问：为什么只用了这两份报纸？**（**好：**您问的是材料的代表性。这两份是按发行量与立场分布选的，它们不能代表晚报系统，这是本文的限制；若要补足需要加入某市的两份晚报，我在局限一节已写明**。坏：**当时能找到的就是这些**。另判：**问：你的结论是不是太大了？**（**好：**是，我接受这一批评。我把结论第三句的范围由“某时期”改为“在这两份报纸所反映的讨论中”，并把这一改动写进修改说明**。坏：**我不同意，我认为我的结论是有依据的**。（**再判：问：为什么不用某理论？**（**好：**我知道该理论处理这一问题的一支讨论，未采用是因为它在解释＿＿上需要本文没有的材料；我在第二章交代了这一取舍**。坏：**这个理论不太适合本题**。

::: solution
**逐步核对**（**四个“好”回答都含①复述或②承认，并至少含④一个可写入文件的动作：补材料、改句子、写局限、注明取舍（**两个“坏”回答的病灶（**①“当时能找到的就是这些”——**这是一句只解释历史而不处理问题的话；**它的正确版本必须包含一个动作（**比如把它写成局限（**这一条最见答辩的技术：**评审真正要的不是理由，理由在论文里已经给过了；他要的是你会不会把它变成一句可核查的修改（②“我不同意”——**不是因为它不同意，而是因为它跳过了①②，并且没有④；**在答辩桌上把一场审计变成了第二次辩论，而第二次辩论你赢不了，因为你没有否决权（③“不太适合本题”——**这是一句没有内容的判断；**它比承认不知道更糟，因为它宣称了一个你不打算辩护的判断（**本课的判分（**能看出“好”回答的共同点是它们都可以直接抄进修改说明者为 A**（**这就是本章标题下的全部内容：**答辩不是把论文再说一遍，而是当场产出论文的下一版（**你能当场产出多少，你的成绩就是多少；**这不是策略建议，这是评审表的实际写法（**通说脉络：**这一句常被学生误认为犬儒；**本课的回答：评审的裁量权是制度事实，而你的诚实与准备是制度唯一无法否认的东西——**二者都在场，才是这场仪式存在的理由。**
:::

::: intuition 为什么要有一个人站在你的论文前面 {#int-zhanzai}
**一件古老而古怪的制度**（**你写了一份纸，然后几个人当着一间屋子的面对它提问，而你必须亲自回答（**三条解释（**①质量审计**（**但一份匿名送审的文件也能做到，且更便宜（②社会化的仪式**（**人类学式的解释，部分正确（③责任的在场**（**本课最看重这一条：**它假定一个主张的后面必须站着一个能负责的人；**他不能把主张交给机构、交给工具、交给死者，也不能在困难问题时说“这一段不是我写的”（**通说脉络：**这就是为什么学位至今不肯取消答辩而只靠文本；**当文本的生产可以被外包时，制度会把重心挪回那个能说话的人身上（**本课对当代的推论（**这也是本章放在整门课最后的理由：**检索、笔记、综述、结构、引证、规范、语言，全都可以被工具部分代做，唯独“我在这些人面前为这些句子辩护”不能（**你在答辩桌前的那两个小时，就是这门职业为“一个人愿意为自己写下的话负责”所设的法庭；**而本课程二十八门课从头到尾教的那件事——写能被别人核对的东西——只在这里有一次强制的现场执行（**这一句也是整个项目最后一章愿意留下的话。**
:::

::: history 一场两小时的仪式是怎么来的 {#sec-yishi}
