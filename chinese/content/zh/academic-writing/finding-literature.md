上一章说选题要签得到材料；本章讲怎么签——**它的目标不是读全，也不是显得读得多，而是让一个没有参与你的人能够重现你读过的那一批文献。可复现性是检索唯一的成绩**。

## 定义：一次检索的五个参数 {#def-wucan}

::: definition 检索日志 {#def-rizhi}
**本课的强制格式**（**每一次检索记五项：**库**（**你查的是哪个数据库、哪套书目、哪个馆藏目录；②检索式**（**包括全部同义词与截词；③限定**（**年限、语种、文献类型；④命中数**（**当次返回多少条；⑤日期与操作者（**为什么第五项不是官僚主义**（**数据库每月增删，同一检索式在六月与十一月会给出不同结果；**没有日期的检索式是不可复现的，因而它不能算方法（**这是第 24 门课那条“口径、时点、样本框”在学术写作里的原形：**任何统计与任何检索都有一个生产日期，写下来是你唯一的免责方式（**本课还有一条：**记录被排除的东西比记录被收录的更难，也更有价值；**排除清单是检索成果的一半，而它几乎总被删掉（**通说脉络：**近年学位论文评审里之所以越来越常要求附检索式，就是因为“我没找到”与“我没找”在结果上完全一样（**这一句本章要你用一辈子。
:::

::: definition 检索式怎么搭 {#def-jiansuoshi}
**四步**（**①把一个概念拆成三组词**（**本名、异名与旧译、上义词与下义词；**人名与地名要包括字号、笔名、异写与旧拼法（②用逻辑组连接**（**组内用“或”，组间用“与”；**先宽后窄（③加两类噪声过滤**（**高频同形词与跨领域同名词；④看检出的前二十条，倒回去改词（**本课的量化直觉（**检索有两个互斥的指标：找得全与筛得净（**通说脉络：**这就是情报学里常说的查全与查准不可兼得；**人文研究通常应当先保查全（**漏掉一篇对手论文是不可补救的**），在第二轮再收紧（**一个可操作的停止规则（**连续读完三十篇而不再出现你必须新引的文献，即可停止扩张——**这与第 4 章的“饱和”同义（**本课警告：**没有停止规则的检索不是勤奋，是拖延的高级形式：它感觉像工作，且可以在任何时候被解释为“我还在读”。**
:::

## 定义：五类材料与五种偏差 {#def-wulei}

::: definition 期刊、专著、论文、一手与二次 {#def-piancha}
**①期刊论文**（**快、经过评审、但存在发表偏倚：不显著与不成功的研究更少出现（**通说脉络：**这是循证医学反复量化过的一种偏差，近年已有人文例子（②专著**（**系统、慢、章节体例不一；**它的缺点是不可切分引用：你可能要为一页话引三百页（③学位论文与会议文**（**早、常常未定稿、可及性差；**引用前须查其是否已刊为论文（④一手材料**（**档案、碑刻、文书、口述、语料；**它们不受检索保障，只受保存与数字化运气支配（**第 25 门课那条“档案运气”在此就是你的可行性（⑤二次与三次文献**（**综述、手册、教科书、条目；**优点是它们替你做了整合，危险是你会把它们的错误当成共识（**通说脉络：**一项错误一旦进入三次文献，就不再需要有人为它辩护（**本课给的一条铁律：**凡是你只从二手文献读来的关键论断，或者去查原件，或者在文中写明转引（**这是第 7 章引证规则的本体，本章先立为戒律（**五个参数与五种偏差合起来给出本章的诊断句：**你检到的文献集的形状，是由收录政策与数字化运气决定的，而不是由知识的重要性决定的；**而收录政策是商业决定（**通说脉络：**这是本课希望你在读任何综述时都保留的一点怀疑。
:::

::: definition 语言与库的边界 {#def-yuyan}
**一个常被忽略的事实**（**不同数据库覆盖的刊物不同，中文库与外文库的重叠远比想象小；而以英语为主的引文索引会系统性地让非英语研究变得不可见（**通说脉络：**系统综述方法学把这一现象称为语言偏倚，并要求检索者至少做一种非英语来源的补充检索（**本课给人文研究的等价操作（**①用同一概念在两种书写系统里各检一次；②找出该领域最重要的三家出版社或丛书的目录，逐条翻一遍（**书目就是数据库的祖先；③找一位不在这个圈子里的同行，问他“你会去哪找”——**外行问你查哪儿，比内行告诉你查哪儿有用（**通说脉络：**这三步在多数情况下能补出两到三成你本会漏掉的文献；**而这正是评审能看出来的那部分工作。
:::

::: definition 滚雪球与枢纽文献 {#def-xueqiu}
**两种方向的追溯**（**向后查它的参考文献；向前查引用它的工作（**通说脉络：**引文索引正是为此而发明：一件工作被引用的次数可以被数出来（**本课的两个用途与一个陷阱（**用途①找枢纽**（**一个领域通常有十几篇被反复引用的工作，漏掉它们意味着你要重复别人早已解决的一步（**这就是导师问“你读过某某吗”时的真实含义：他在测你的引文网络有没有中心（②找对手**（**一篇反对你立场的论文常常躺在你最好的文章的引文里（**陷阱**（**被引次数不区分引用的态度；**引文分析早已把引用分为工具性引用、赞许引用与批评引用三类，而计数把三者加在一起（**所以数出来的名次是一种可见度，不是评价（**这一句是第 8 门课那条“引证通胀”的姊妹：你未来写基金申请时会被要求报引用数，届时请记住它把帮你的与被反驳的算作了同一件事。
:::

::: example 写出检索式 {#ex-shi}

::: intuition 为什么先读注释 {#int-zhushi}
**一个阅读顺序的建议**（**拿到一篇可能相关的长文，本课建议的顺序是：标题与摘要→结论→注释与书目→图表或引文分布→正文（**理由（**①注释暴露它的对手**（**一篇论文反驳谁、感谢谁、转引谁，全在脚注里；**这比摘要诚实，因为摘要是自我形象，注释是工作记录（②书目暴露它的材料边界**（**你立刻知道自己是否同意它的来源；③你能看出它是否只引二次文献**（**关键处全转引，说明作者也未见原件（**这一条的价值极高：**它是判断一篇权威论文是否名过其实最快的方法（**通说脉络：**许多著名的错误持续存在，正因为每一代人都从注释里读到它而不是从原件里（**本课把这称为“注释是论文的体检表”；**下一章讲笔记时，第一个要抄的就是注释。
:::

::: history 从书目到幻觉引文 {#sec-xishou}
