上一章的段落里，保证是从证据到主张的那一步；本章讲怎么把这一步的来路写下来——**引用是一种债务记录：你从哪里拿走了什么，必须写明，因为读者要顺着你这条线去核你那个结论。它的格式不重要到值得焦虑，它的功能重要到压倒一切**。

## 定义：两套体系 {#def-liangtao}

::: definition 文中注与页下注 {#def-tixi}
**两套主流做法**（**①著者—出版年制**（**文中“作者，年”，文末按字母或拼音排序；**优点是读者能立刻判断新旧与来源，适合实证学科；②注释—书目制**（**页下或文末编号注，书后列全部条目；**优点是便于交代版本、卷叶、异文与讨论，适合人文与古籍（**通说脉络：**中国的国家标准同时提供顺序编码与著者—出版年两种著录方式，各刊与各校再自订细则（**本课的三条实用结论（**①不要混用**（**混用不是风格问题，它意味着有两套追溯路径而两者都不完整；②细则从你的发表方或学校（**这一条不需要论证；**但请在动笔前拿到那份文件，因为它会影响你全文的注（③同一书前后用同一版本**（**见下一节（**本课对格式焦虑的处方（**格式错误是可修复的技术问题；而引用功能是不可修复的伦理问题：**一条格式完美而内容伪造的引文，比一条格式杂乱而可核对的引文坏一百倍（**这一句会在第 8 章成为分类的基础。**
:::

::: definition 六条戒律 {#def-liutiao}
**本课的硬性要求**（**①直接引语逐字并加标示，省略须显式标记；②你只从二手读来的关键论断，须写“转引自”或去查原件；**二者择一，不许沉默（③一个观点有多个来源时，引最原始与最可核的那一个，其余可注“另见”；④参考文献只列你实际引用过的；**列而未引是一种虚张，它在评审眼里等于谎报（⑤未刊材料、访谈、私通信件须按其可及性标注，并在访谈前取得对方对可引范围的同意（**第 8 章专讲；⑥网络材料须记访问日期与尽可能稳定的标识（**网页会消失；**一个没有日期的网址等于一条无法核对的引文（**通说脉络：**这与上一章检索日志的第五参数是同一件事：凡依赖时间的来源，都要带时间（**本课把第②条称为全章最重要的一条戒律：**它管的是学术中最普遍的一种失误——把道听途说写成了亲眼所见；**而这种失误一旦发生在你最关键的那一句上，你整篇论文的可靠性会被重新估定。**
:::

## 定义：古籍与版本 {#def-guji}

::: definition 标到能被找到 {#def-banye}
**中文古籍引用的常规**（**除书名与篇名外，须标版本、卷次与叶次或页码；同书多次引用须统一版本（**本课给三条理由，第三条最常被忽略（**①页码随版本变**（**同一句话在丛书本与单刻本里可能相隔十页；只写书名等于不写；②文本随版本变**（**删节、改字、避讳缺笔与后人增补都可能在某一版里出现（**前一门课第 8 章那条“谁控制本文谁就控制解释”，在此变成你的责任（③版本本身可能是一种立场**（**一个评点本、一个官方修订本与一个抄本，可能给出三种“原貌”（**通说脉络：**本课的判据（**一句“某书云”若要能承担论证，你至少要说清：你用的是哪一个本子，以及为什么用它（**做不到就把句子写成“今传某本作……”，把不确定性交给读者而不是藏起来（**这一条与第 9 章“限定与证据强度成比例”直接衔接：**版本说明就是一种限定，而限定必须写在会被引用到的那一句里（**这是应用文那条老规矩在古籍引用里的应用。**
:::

::: definition 引文链与幽灵条目 {#def-lian}
**一种沿袭千年的故障**（**甲引乙、乙引丙、而丙的说法本不如此，或丙并不存在；三代之后，没有人再查原件（**通说脉络：**上一章已给机理解释：**一项错误一旦进入三次文献，就不再需要有人为它辩护（**本课给的三道防护（**①关键句必查原件**（**“关键”的定义是：若此句为假，你的结论受损（**这一判定要在你抄卡片的那一天做，不是在校对那天（②优先引一手与初刊**（**若只能引重编本，须注明所据（③对任何“历来认为”保持过敏**（**一句被十个作者重复的话，可能只有一条源头，而那条源头可能是误读（**本课称此为“单源头幻觉”：**表面的共识往往是抄袭的谱系（**通说脉络：**近年一种新情形使这一防护变得紧迫：生成式工具可以造出格式完美、作者真实而标题不存在的条目，且能附上看似合理的页码（**通说脉络：**本章的结论因此很硬：**凡未经你打开过的条目，不得进入参考文献表；**这条要求在过去是可以通融的礼节，如今是可核性的最后防线（**这一句也是第 8 章里那条分类“疏忽与伪造的界线”的技术前提。**
:::

::: example 找五处 {#ex-wuchu}
下面一段引注（**本课自造的仿体**）：“**关于此事，历来学者多有异议。甲先生在《某某集》中说得很明白：‘此论大谬。’乙先生亦持同见。丙《某研究》（某出版社 2010 年版）转引甲说，可为据。参看丁主编《某某史》，第 300 页。此外可参戊《某书》，虽未阅，其说或可参考。**”请找出五处引用问题并改写。

::: solution
**五处**（**①“历来学者多有异议”是无人负责的概括**（**须改为可数的：某、乙两位主张（**上一章“历来认为须能举三篇”在此完全适用（②引甲先生的赞语式断句“此论大谬”而未标版本与页（**且这句是否为原话不可知（**引语必须逐字且可定位（③依赖丙的转引而未标“转引自”**（**这是戒律②的直接违反；**若甲的原书你未见，须写“转引自丙”并说明未见（④“参看丁书第 300 页”未标版本与出版项**（**页码无版本等于无页码；**另外“参看”未说明该页支持什么：是让读者看同一说法，还是看一个反例（**本课要求：**每一处“参见”都要带一句它支持你哪一句（⑤“戊书虽未阅”却列入**（**自相矛盾：未阅之书不能作证，也不能被列进书目（**本课对第⑤条的处理是本章的道德核心：**这句“虽未阅”看似诚实，实际是把核查责任与撒谎的嫌疑一起转给读者；**正确的做法是不列（**判分（**能解释第⑤条为何比第③条更值得警惕者为 A**（**理由是：③是疏忽，⑤是明知；**而学术不端的分类正以这两者为界（**第 8 章会把它写成一张表；**本章先把技术说清楚：**参考文献表的每一项都必须满足两个条件——你读过它，且它支持你所说的那一句（**两个条件缺一个，那张表就失去了它唯一的功能（**这是本章给全课程的一条底线。**
:::
:::

::: intuition 那张表是自画像 {#int-zihua}
**一件无法隐藏的事**（**参考文献表会泄露你实际读了什么，而与你声称读了什么无关（**四条读法（**①年代分布**（**若全部条目都在最近五年，说明你只读了当下的讨论，没有读前说；若都在八十年前，说明你没读近二十年的争论；②语种分布**（**只有一种语言，即只有一视野（**上一章语言偏倚在此变成你的病历（③类型分布**（**若二手文献远多于一手材料，你的论证悬在别人的概括上；④引用构成**（**你引谁、不引谁，是这份表里唯一真正会被当作立场来读的部分（**通说脉络：**已有研究分析引用的性别与地区构成，其方法与本章的技术相同：把引用视为可见度而非评价（**本课的忠告（**不要为构成而伪造引用——**那是引证通胀的另一种形式；**要做的是在写完初稿之后把这张表读一遍，问它是不是你想说的那个人（**若它不是你想要的样子，通常说明你漏读了什么，而不是漏引了什么（**这就是这张表作为诊断工具的真正用法；**它是评审先看的那几页，也正是你最后校对的那几页。**
:::

::: history 一条注释的两百年 {#sec-zhushi}
**十七至十八世纪**（**考据之学以引书必注卷叶为常规，一条异说可以校出十余处出处（**通说脉络：**本课把这条常规看作可追索性最早的职业形式：**它比欧洲的现代脚注早，其功能完全相同（②**十九世纪末**（**若干学术团体开始统一论文体例，注释与书目的位置被写进刊物规定（**通说脉络（③**二十世纪初**（**新式大学与学报把页下注与参考文献表输入中文写作；同时关于古籍整理的引书规范在研究机构中定型（**通说脉络（④**1920 年代末**（**一个心理学刊物团体制定统一的稿例，成为后来美国心理学会格式的前身；**“著者—出版年—页码”由此成为实证学科的标准（**通说脉络（⑤**二十世纪后半叶**（**国际文献著录标准与各领域格式相继成形，中国的著录规则于八十年代立为国家标准并多次修订（**通说脉络（⑥**九十年代末以后**（**数字对象唯一标识普及，条目获得一个不依赖网址的编号；同时相似性检测系统被用于学位论文，一篇论文与既有文本的重合比例成为可测指标（**通说脉络：**本课对⑥的态度（**这是引用制度第一次由机器执行；**它的效果是双面的：它把抄写变得危险，也把改写变得奖励——**于是出现了一种新现象：为了降低相似度而改写原文，同时不标注来源；**而按本章的判据，这正是上一章小论文所处理的那种剽窃（**相似度检测量的是文字重合，不量的是依赖关系；**这两者不相等，评审也知道（**通说脉络：**你要避免的从来不是被检出，而是欠款。**
:::

::: exercise 小论文：欠款与勋章 {level=3}
写六百至一千字，评“**注释曾经是学者的勋章：它显示博学与师承。今天它应当是审计底稿：它显示每一句主张可以从哪里被核对。这次从荣誉到会计的转变，正是学术职业自我理解的变化——它不再以见识为荣，而以可交接为荣。而抵触这次转变的人，多半不是不懂格式，是不愿意把自己写成可被检查的人**。须调用：**两套体系及不可混用**、**六条戒律**、**古籍须标版本**、**单源头幻觉**、**参考文献表作为自画像**、**机器执行引证制度**至少六项；并裁决：**你愿意把你的研究材料开放到什么程度（数据、语料、笔记、访谈记录）；给出你能承诺的边界与理由**。

::: solution
判分点：六项机制；裁决（**必须给边界而非姿态：**本课接受的答案形状**（**分四层承诺并各写理由：①**引文与出处**（**无保留；**这本来就是债务记录；②**你构建的语料与检索记录**（**宜开放，因为它决定别人能否重做你的第③章；**代价是清洗与说明的工时——这一代价须写出来，不得假装不存在（**这是判卷最高分之一：**诚实的开放承诺必须包括你愿意付多少工时；③**访谈与口述**（**通常不可开放，因为受访者未曾同意被陌生人阅读；**这里的边界不是方便而是承诺（**与第 8 章的知情同意直接相接；④**你的笔记草稿**（**无义务开放；**而一旦开放，就要接受它被当作主张来读（**这一层最微妙：草稿里满是你自己都不再同意的句子（**加分（**能指出“可交接”也有代价**（**当材料成为可交接的标准，稀缺材料的占有者获得不成比例的权力，而“不开放”有时是保护被访者、有时只是护城河；**能区分这两种不开放的人，才算读懂本章（**结论若能写“**所以本章不主张彻底公开，只主张一件事：你留下的每一条注都要能替你回答‘你怎么知道’。这一问在勋章时代可以被博学回避，在会计时代不能。至于你的笔记、语料与访谈，请按你能负责的范围承诺，并把不开放的理由与被保护的人一起写出来——这才是可交接的意思**”，即 A。
