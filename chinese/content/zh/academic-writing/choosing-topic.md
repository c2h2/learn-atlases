上一章给了一个测试；本章处理测试之前那件更常见的事——**手里只有一个模糊的兴趣，而十四个月后要交出一本论文。本章的论点是：选题不是发现一个问题，而是谈一份合同，其中最没有耐心的签约方是工期**。

## 定义：三个圆与两道附加条款 {#def-sangeyuan}

::: definition 可及材料、可完成时间、有人关心 {#def-yuan}
**本课的模型**（**一个可做的题目必须落在三个圆的交集里：你能拿到的材料；你能在期限内做完的工作；以及有人在等的结果（**①可及材料**（**问的不是“有什么材料”，而是“我能签到哪张借阅证、能不能买数据库、受访者愿不愿意见我”（**通说脉络：**这三件事的失败率远高于研究能力本身（②可完成时间**（**先估工作量再定范围，而不是相反（**本课的算法在本章第五节（③有人关心**（**“关心”有一个可核的定义：**至少有一个人会因为你做出来或做不出来而改变他写的下一段（**找不到这个人，你的工作就没有对手也没有读者，而它将同时失去质量压力与发表可能（**两道附加条款（**④你来得及学会所需技能吗**（**一门语言、一个统计包、一种古籍整理体例；学习曲线是设计的一部分，不是个人英雄主义的对象；⑤你承受得起失败吗**（**有些题目会牵动他人的名誉、家族的隐私或一个机构的利益；**这一条在第 8 章展开（**本课的判语（**大多数被否掉的开题，死因不是不新颖，而是第①②④条：材料签不到、时间不够、技能不会（**而评语通常写成“题目过大”，于是学生以为问题在于野心（**这是选题教育中最常见的一次误导。**
:::

::: definition 可失败性 {#def-shibai}
**本课给“好选题”的真正判准（**不是重要，而是：**如果你的假设被否定，有人会更想知道为什么（**三条推论（**①一个只能成功的设计不是研究**（**若任何材料都能被用来证明结论，那么你已经写完了，剩下的只是抄（②可失败性是可辩护性的另一面**（**能被否定的题目在答辩里也能被守住：因为你提前说明了什么会推翻你，而你没有被那样推翻（③它替你选好了读者**（**愿意读一个失败结果的人，正是会读你成功结果的人（**通说脉络：**近年“负结果也应发表”的运动之所以必要，是因为发表制度系统性地奖励了不可失败的设计（**本课的实操（**在开题报告的末尾加一段：**本研究的假设将在何种结果下被推翻；**这一句写得出，说明你有一个研究；写不出，说明你有一份计划中的宣传（**它同时是上一章“预登记”的通俗形式：**把你的软处先说出来，是它最便宜的保险（**第 18 门课那条“让步前置”，本章把它变成一段制度化的文字。**
:::

## 定义：三种来源 {#def-sanyuan}

::: definition 材料的缝隙 {#def-fengxi}
**做法**（**找到一处尚未被利用的材料：一个新整理的数据库、一批未刊稿、一套地方档案、一组口述、一个只有你读得懂的语言或行业内部文本（**它的优点**（**结论很难被抢，因为你手上的东西别人没有；**它的对手通常只能争“这材料能说明什么”，而不是“这材料不存在”（**它的风险（**材料可能不回答问题；**新料的诱惑常常使研究者忘记自己本来要问什么——**本课称此为“档案恋爱”（**处理办法（**在签约之前做一次“材料—问题对照表”：左栏是你问的三个子问题，右栏是这份材料对每一问能交付什么；**若右栏有一格空白，就必须在设计里另找来源；**这张表要在开题时交出来，它是全课程唯一强制的表格（**通说脉络：**旧说的“上穷碧落下黄泉，动手动脚找材料”，说的就是这张表的两个动作（**第 3 章检索与第 4 章笔记会各自接住它的一半。**
:::

::: definition 方法的错置与第三项 {#def-cuozhi}
**第二种（**把甲领域成熟的方法搬到乙类材料上（**如用计量方法处理一个从未被计量的语料库；用文学批评的叙事分析处理一份判决书（**优点**（**它的贡献天然可说清楚；**风险**（**方法带着它自己的问题清单，搬过来时容易只搬工具（**本课的处方（**须回答两问：**这个方法原本为反驳什么而发明；**它在乙类材料上会怎样失真（**这一条与前一门课程第 7 章“借词连同一整套争论结构一起搬来”同构；**也是第 17 门课“换科目引用”的对偶（**第三种（**在一个有两派的争论里找第三项**（**不是调和两派，而是找出双方共享而无人检验的一个前提（**本课称此为最好的一种选题，理由三条（**①它的对手是现成的且有名有姓；②它的贡献不需要自夸**（**你可以写：“此前的两支讨论都假设了＿＿，本文检验这一假设”；③它即使失败也有信息**（**若该前提成立，则两支的争论被证明是真实的；**无论结果如何，你的第二段都有话说——**这就是可失败性的完美形状（**它的代价（**难；**它要求你真的读完两派，而不是读完两派的摘要（**通说脉络：**本课对学生的一贯建议是：先做第二种，再争取第三种；第一种靠运气，而运气不可排进工期。**
:::

::: definition 四次收窄 {#def-shoushai}
**从兴趣到设计的四步，每步须交付一件东西（**①兴趣→主题**（**交付：一段不超过一百字的说法，里面必须有一个具体名词与一个时间段（**通说脉络：**“我喜欢宋词”不能交付；“南宋后期词集里的题序”可以（②主题→问题**（**交付：上一章的三句测试（③问题→设计**（**交付：材料清单、抽样框、以及你打算做的每一次统计或校勘（**第 3、4 章负责它；④设计→工期**（**交付：一张倒推表与一组放弃条件（**下一节（**本课的检查方法（**每一步的交付物只有一件；**若你在第②步交付不出一件而只有口头描述，那么第③步的一切都是想象（**这就是导师说“再想想”的实际含义——**他不是在否定你的题目，他是在拒绝进入下一层，因为下一层需要上一层的实物（**理解这一点可以省下三个月。**
:::

::: definition 倒推与放弃条件 {#def-daotui}
**工期算法（**①从交稿日往回数出你可用于研究的天数（**不是月份，是天；②按你的设计估三项工作量：读与抄、做与算、写；**各乘以二**（**本课的经验系数，通说亦如是（③把算不下的部分删掉，而不是把每天加班排进去（**加班不是计划，是一种借贷（④先定“最小可完成单元”：**哪一个题目、哪一章、哪一节，是你即使一切出错也能交出去的东西（**这一件东西必须先写，因为它决定你的安全边际；⑤写两条放弃条件：**若第 X 周仍未拿到 Y，则改做 Z；**放弃条件须写在开题报告里而不是留在心里，因为它是一份合同而不是情绪（**本课的比喻（**这与第 24 门课那份“计划”的唯一区别是：学术计划里的验收方式是给自己用的（**而自用的验收方式仍然要是验收方式（**通说脉络：**“预答辩分流”一类的制度在若干学校已经存在；它的合理内核就是这张倒推表，而不是羞辱（**你若在开题时主动交出这张表，你此后遇到的每一次延期都会少一场解释。**
:::

::: example 四个选题 {#ex-sige}
给四个学生的题目做体检并改造：**甲：研究某位现代作家的乡土书写。乙：某市近十年民间借贷纠纷判决书中的利率认定。丙：《论语》的仁爱思想研究。丁：某短视频平台上“古风电音”的评论区如何用古典词句。**

::: solution
**甲**（**四圆全缺：**材料无边界（**全部作品？**）、对手不明、范围无界（**改造：**选定两个时段相近但立场相反的批评者对该作家的两次评价，或选定一个具体形式特征（**如某类意象在 1930 与 1940 年代的迁移**），并把材料缩到一个可数完的集子（②乙——最健康的一个**（**材料可及**（**公开裁判文书**）、有人关心**（**司法实务与法学界都有人在等**）、可失败**（**若利率认定并无趋同，则相关学说被削弱**）；**它需要的三处补强：抽样框（**哪些法院、哪些年份、检索式写下来**）、隐私与匿名（**第 8 章**）、以及一个替代解释（**可能是法官构成的变化而非规则的变化**）（③丙——汇编式的极端例**（**它甚至不是题目而是一个专业的名字（**改造的第一刀是把“思想研究”换成一个可争的判断**（**例如某译法与某注家的关系（**“仁”在哪些句子里不可能读作某义**），第二刀是限定材料版本；**改造后它会显得小得可笑，而这正是它第一次成为研究（④丁——好问题，但设计最难**（**材料在流动，平台的取样规则你不可控；**可及材料这一圆最脆（**补强办法：**每天定时抓一次评论并存档（**把不可控的材料变成一份你自己的时间序列——**这正是前一门课里那套“面板数据”思路的平民版本**）；**同时须处理伦理：评论区不是公共广场，用户不知道你会引他们的话（**第 8 章专讲（**判分（**能给丁设计存档方案者本章 A**（**它考查的不是想法而是工程：**一个选题的真正难度常常藏在采集阶段，而采集阶段最不容易在开题时被看见（**本课把这一条列为本章最想教的一件事。**
:::

::: intuition 热点的剩余寿命 {#int-redian}
**一个可测量的东西**（**一个新话题大约有多久可做（**本课给的三条指标（**①有没有人开始写综述**（**综述出现说明领域已经认为它结束了；②有没有期刊做专号**（**专号说明编辑已经认为它结束了；③批评的火力是否已从观点转向方法**（**当有人开始说“这个领域的量化做得不严谨”，说明这个领域已经不缺题目（**三条同时出现时，你此刻上车，将在四年后下车，而届时无人等门（**本课给的替代策略（**在热点的邻题找那个尚未被处理的问题：**它继承热点的读者，而不继承热点的拥挤；**这是学术市场里唯一稳定的套利（**通说脉络：**这一条并不犬儒：热点之所以热，是因为确实有一批人在等答案；你要做的只是判断“等到现在还缺什么”，而不是“现在什么最响”。**
:::

::: history 一篇论文的制度史 {#sec-zhidu}
