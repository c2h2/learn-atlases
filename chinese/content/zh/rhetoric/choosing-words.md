---
title: "词语的选用"
---

词典是静止的库存，写作是每秒几十次的领料。选词有四根轴：**准确、色彩、声音、新鲜**——前两根管“对不对”，第三根管“顺不顺耳”，第四根管“肯不肯再看一眼”。

## 轴一：准确 {#sec-zhunque}

::: definition 准确的三个刻度 {#def-zhunque}
①**义域宽窄**：“结果/成果/后果”同一根轴上的三段（中性—褒—贬），“处罚/惩处”一轻一重——选词先定**量级与极性**；②**搭配户口**：“发扬”只跟“传统/精神/民主”住宿，“改进”收“工作/方法/服务”——[[modern-vocabulary/sense-relations]] 的搭配档案在写作端就是选词档案，病句章“肩负传统”案即户口黑户；③**上下位适当**：“他买了水果”对母亲是废话，对海关申报是精确——**准确性永远相对于题旨**，不存在“越具体越好”的教条（诗要“橘”，报关单要“柑橘属水果”）。
:::

## 轴二：色彩 {#sec-secai}

::: definition 色彩的三件外衣 {#def-secai}
**感情色彩**：聪明/机灵/狡猾/精明是同一素质的四份证词，选一个就是投一票；**语体色彩**：老公/丈夫/爱人/先生/我家那口子——五个词指同一个人，各自的场合不同（[[rhetoric/registers]] 全课）；文言词“之/其/所”混进菜谱就是穿礼服炒菜。**形象色彩**：“明晃晃、湿漉漉、米白、藕荷”自带感官胶片，——抽象词退席处，形象词上岗。但三件外衣都会旧：“可爱”曾经纯褒，“奇葩”已然变脸，色彩是活的账（[[modern-vocabulary/word-meaning]] 语义迁移）。
:::

::: example 一份通报的三层着装 {#ex-tongbao}
同厂事故，为三种受众各改一则主送句：①内部通报 ②监管报送 ③公众号推文。原料句：“车间老张违规操作，机器轧伤了手，大家注意。”
::: solution
①内部：“成型车间张某未按规程作业，致手部受伤——各部门本周复训。”（准确+追责口径，“大家注意”升格为指令）；②报送：“2024年3月X日，我司成型工序发生机械伤害一般事故，伤者张某，无生命危险。”（术语“机械伤害”、定级“一般事故”——监管语体的户口齐全）；③推文：“3月7日下午，一台机器咬伤了一位老师傅的手。我们想讲讲规程背后的人。”（拟人转移锋芒、软叙事——题旨从追责转向安全文化）。同实三衣，一件都不能穿错门。
:::
:::

## 轴三：声音 {#sec-shengyin}

::: definition 音节、平仄与忌讳音 {#def-shengyin}
**音节配平**：汉语偏爱对称的“音步”——“开展调查”顺、“开展查”不通；公文动词双音化（“收钱”变“收受”、“买房”变“购置”）一半是语体，一半是音节的天平（[[modern-vocabulary/word-formation]] 双音化）。**平仄自然律**：不学近体诗也会凭耳朵排句——“因地制宜”两平两仄踩得稳，长句收尾凭耳判断：**关键信息落在响亮的音节上（开口呼、仄声收尾）更立得住**。**忌讳与谐音**：“4”楼改“F”层、“伞”忌送、“破财”改“碎碎平安”——语音的修辞学连着民俗心理学（谐音辞格见[[rhetoric/figures-of-form]]）。
:::

## 轴四：新鲜 {#sec-xinxian}

::: definition 陌生化与它的预算 {#def-mosheng}
俄国形式主义者什克洛夫斯基 1917 年提出**陌生化**（остранение）：自动化让“石头不成其为石头”，艺术的职责是“使石头成其为石头”——延长感知的工时。选词层面即：避开自动售货机词汇（“岁月静好”“感恩遇见”），给旧事换生脸（不说“天亮了”而说“东天泛起蟹壳青”——举一正例：“东风夜放花千树”，把满城灯火说成一夜花开）。但新鲜有**预算制**：一篇文章的生面孔配额有限，超载则读者罢工；**新鲜是准确的副产品**——王安石“春风又**绿**江南岸”的“绿”字公案：改“到、过、入、满”皆不谐，最后请出形容词做动词——那不是求新，是“到/过”装不下“看得见的春风”。
:::

::: history 从“炼字”到“搭配词典” {#sec-lianzi}
古典修辞学早有选词专章：南宋陈骙《文则》比物连类开辞格研究先河，刘勰《文心雕龙·练字》专篇，加上唐人“吟安一个字，捻断数茎须”（卢延让）——**一字之择，可以重于全篇**：“吟安一个字，捻断数茎须”（卢延让）是唐人以命换字的证词。二十世纪，选词从诗话转入学堂：作文教科书给近义词配“辨析表”，《现代汉语词典》标文体，计算时代更出现**搭配词典与语料库频率**——“的/地”之争、“作出/做出”之择，今日的答案一半在语感，一半在数据库。
:::

::: warning 选词三病
一**近义词盲**：“发挥作用”“提高水平”张口就来，从不想“发挥”为何不能配“水平”——搭配户口不查，病句门诊排队；二**套话癌**：“在……的大背景下，以……为抓手，赋能……闭环”——套话是选择的弃权票，一整段无一处个人观察；三**新鲜过载**：通篇生造（“雨很伤心地下”）、文言乱入（“吾辈打工人”玩梗可以，公文即用即病）——**陌生化是给重点上保险，不是给全文刷漆**。
:::

::: exercise 辨微 {level=1}
任选三组辨析并各造一句证明你分得开：①断定/肯定 ②违反/违犯 ③启动/起动 ④搜集/收集。
::: solution
①断定下结论（证据足）、肯定表确认/不否认（语气）；②违反+纪律法规（对象一般）、违犯+法律/纲纪（性质重，带犯罪色）；③启动=使程序/项目开动，起动=机器发动机开始运转（技术语）；④收集侧重归拢已散之物，搜集强调四处寻找（搜=主动扫描）。造句语义自证即满分。
:::
:::

::: exercise 给旧词发新证 {level=2}
选一个被用钝的词（“正能量”“打卡”“绝了”任一），写 150 字：先列出它的自动化用法三例，再给它设计一个“重新陌生化”的用法，并说明新用法靠什么机制生效。
::: solution
参考机制：降格/升格（把“打卡”用于心跳：“给心动打卡”——大词小用）；字面化复活（“正能量”回到物理学的做功语境——拆词源）；错搭生义（“绝了”恢复“绝=断”本义写武侠）。机制点名+语感不硬即满分。
:::
:::

::: exercise 编辑实战 {level=2}
修改以下文案（最少改动，说明每处理由）：“在这个春暖花开的季节里，我们怀着无比激动的心情，隆重迎来了本届读书节盛大开幕。”
::: solution
参考：删“在这个春暖花开的季节里”（套话+与读书节无必然）;删“无比激动”（套话程度虚高）；“隆重迎来了……盛大开幕”句式杂糅且状语堆叠——改“本届读书节开幕”。示范判分：每一刀都能指认病灶类型（[[modern-grammar/faulty-sentences]] 术语）。
:::
:::

::: exercise 小论文：我的词语账本 {level=3}
写八百至一千二百字：收集你最近一周真实说/写的 20 个“自动词”（聊天高频词），逐个做四轴审计（准确/色彩/声音/新鲜），淘汰 5 个并给替代词与理由；最后回答：一个人为自己的语言记账，与思想有什么利害关系？（提示：奥威尔在《政治与英语》里说，语言的堕落与思想的堕落互为因果——你同意几成？）
::: solution
判分点：20 词真实可查（自录一周聊天语料即可）；审计用四轴术语且替代词配得上“为什么更好”；结尾对奥威尔命题给出**有保留的立场**（同意/反对都要举得出反例：新思想常常先有新词）。
:::
:::

::: summary
四轴口诀：准确查户口（义域、搭配、上下位），色彩看场合（感情、语体、形象），声音掂轻重（音节、平仄、忌讳），新鲜省着用（陌生化有预算，且永远是准确的副产品）。古典“炼字”与语料库“搭配频率”是同一条河的上游下游——选词的尽头不是词，是你对世界的分辨力。下一课把镜头从词拉远：句子形式的选择——长短、整散、主动被动、常格与变异。
:::
