---
title: "句式的选择"
---

词是砖，句式是房子的开间与采光。同一批词，换一套句式就是换一种命运：**长句精确，短句锋利；整句成阵，散句行气；主动执刀，被动承刀；常格是路，变异是闪电。**

## 长与短 {#sec-changduan}

::: definition 长短句的战场分工 {#def-changduan}
**长句**靠多层定语状语把话说“严丝合缝”——法律、学术、科技文体赖它界定概念（“因不可抗力不能履行合同的，根据不可抗力的影响，部分或者全部免除责任”——一个分号都不能挪）；**短句**靠断裂制造速度与强调——应急指令、诗、口语、悼词的地盘（“失火。速来。”）。写作成病有两个方向：**长句癌**（一句话三层套叠，读者在从句里失联——欧化之弊，见下）与**短句癖**（通篇电报体，关系词全删，思想被迫自行组装）。名家手法恰是**长短相间**：“曲曲折折的荷塘上面，弥望的是田田的叶子。”（《荷塘月色》长句铺陈，忽然“叶子出水很高，像亭亭的舞女的裙”一顿一顿地往前送）——节奏学的老话：**长句气短则断之，短句气促则贯之。**
:::

## 整与散、主动与被动 {#sec-zhengsan}

::: definition 三对句式变量 {#def-sandui}
**整句**（结构相同或相近、音节匀齐：对偶、排比成阵）长于气势与条贯——“横眉冷对千夫指，俯首甘为孺子牛”；**散句**（长短参差、结构随意）长于自然与流动。好文章**以散运整**：整句是阅兵式，散句是行军——全阅兵则呆，全散步则散。**主动与被动**是视角选择（[[modern-grammar/special-constructions]] 被字句的“镜头与立场”在此复用）：“失误造成了三百万元损失”追责明确；“三百万元被损失了”则合法度全无——被动另有准入条件，**选句式先过语法的门，再谈修辞**。**肯定与否定、常式与易位**（“怎么了，你？”——倒装是情感的越级）各成一组，原则只有一个：**焦点位置**——汉语句尾是天然的追光，谁该被看见，谁就坐末排。
:::

::: example 同一新闻的四种机位 {#ex-sijiwei}
原料：“昨日某化工厂排放超标，附近河水出现死鱼。”改写：①工厂自查报告 ②环保组织举报信 ③电视口播 ④诗歌（任选视角）。
::: solution
①“昨日系统检修期间，出水口数值出现短时波动，公司已启动核查。”（施事隐去为“数值波动”——名物化+被动化去罪化，公文被字句的经典用法）；②“超标排放！昨天，这条河被投了毒——死鱼是证词。”（受事前置+“被投毒”道德框架，呼告起句）；③“昨天，一家化工厂排放超标，河水里出现死鱼，居民反映强烈。”（时间词开头、主动叙述、口语短停）；④“鱼翻白的时候/厂区的灯还亮着”（并置零连词——意象蒙太奇，关系交给读者）。**四版无一句“假话”，四版已是四个世界**——句式即立场的语法学证明。
:::
:::

::: history 百年欧化：长句的入侵与和解 {#sec-ouhua}
1919 年前后，傅斯年疾呼造“欧化的国语”——论说文体需要欧洲语法的绵密机器；余光中半个世纪后清点账本，《中文的翻译体》数落“代名词病、名词病、形容词病”:“对……进行了调查”“作出重要的贡献”把汉语的动词优势埋进万能动词+名词的垫子底下。今天账已结清一半：**限制性长定语合法落地**（学术语言没有它没法写），**“进行/加以/给予”滥用被识别为赘语**。余光中《听听那冷雨》示范了和解方案：西式的层层叠置与中式的短句节奏同炉共冶——欧化不是罪，不懂母语声口的欧化才是。
:::

::: warning 句式四坑
一**套框上瘾**：“通过……使……”“随着……的……”空转长句（病句章主语淹溺案在这里是惯犯）——介词框架是脚手架，不是房子；二**整句强迫症**：逢事必“一方面……另一方面……”，两段没有“一方面”就没法开写——提纲思维冒充结构；三**被字句滥用**：“他被看见了这只鸟”句法非法——“看见”的施事本是人，硬塞给“他”只落得两不着床；施受关系先自查，再谈修辞；四**结尾失焦**：该被看见的信息埋在长定语里（“由市级部门在三年前启动的、以社区为单位的、覆盖十万家庭的试点已经评估完毕”——要点“评估完毕”前移：**尾重是修辞，尾轻是事故**）。
:::

::: exercise 长短调音 {level=1}
把长句改写为短句组，再说明何场景用长、何场景用短：该校对因家庭困难而未能参加上周校外研学活动的学生进行了名单复核并安排补活动。
::: solution
短句版：“名单复核完了。没参加研学的孩子，学校另安排一次。”（家长群通知：短句+儿化+零术语）。长句用于存档公文（责任、范围、条件一句锁死），短版用于触达——判分点：改写保住三个事实要素（困难/缺席/补做），并各给语体理由。
:::
:::

::: exercise 机位练习 {level=2}
“电梯里有人抽烟”分别以：物业公告、讽刺随笔、被动控诉体三式各写两句。
::: solution
公告：“电梯为封闭公共空间。吸烟者将被纳入监控取证。”（短句+施事明确+后果）；随笔：“总有人把两平米的铁箱子当成自家的烟囱。”（比喻+“自家的”反讽所有权限额）；控诉体：“早高峰的电梯被一支烟占领了。我们被允许屏住呼吸。”（被字句的“遭受”底色+“被允许”反语——网络被字式的合法化使用）。三式立场与句式互证即满分。
:::
:::

::: exercise 拆弹专家 {level=2}
拆解并治愈长句（保留全部信息）：针对目前存在的部分员工在未经审批的情况下擅自使用个人账户为公司收付款项的现象财务部门决定从本月起开展专项清理。
::: solution
参考：拆三句——“近期，部分员工未经审批，使用个人账户收付公司款项。该行为违反财务制度。财务部决定自本月起开展专项清理。”（原句三病：主语被“针对……现象”介词框架长距隔离、缺句读致“现象财务部”粘连、动词链超载——断句+复位即痊愈）。病灶命名准确+语义零丢失即满分。
:::
:::

::: exercise 小论文：句式与真相 {level=3}
写八百至一千二百字：收集同一事件（明星八卦或公共事件均可）的三种文本（通稿/评论/段子）各一节，分析其句式配置（长短、主被动、整散）如何各自“制造”了事实的侧面；回答：既然句式即立场，客观报道是否存在？要求用本课“四版新闻”案例作对照。
::: solution
判分点：三文本句式统计可复现（平均句长、被字比例、整句密度任二）；立场机制点破而不犬儒（客观≠无句式，客观=句式与题旨的诚实比例）；对“四版机位”案例有引用有推进。
:::
:::

::: summary
长短是节奏（精确与锋利各有战场，名家靠相间吃饭），整散是队形（以散运整，阅兵不能占全程），主被动是机位（追光永远打在句尾——尾重是修辞，尾轻是事故），常格变异是表情（倒装即情感的越级报告）。欧化百年告诉我们：句式库存会扩容，但每一分绵密都可能有声口上的利息。下一课进辞格馆正厅：比喻——修辞学里最古老、也被研究得最疯的那门学问。
:::
