---
title: "风格"
---

语体是场合的制服，风格是**不肯脱下来的个人体香**。本课把镜头从“社会”摇回“人”：风格何物、能否分类、能否学习、以及“文如其人”这句老话经得起多少审讯。

## 风格的定义与两对刻度 {#sec-dingyi}

::: definition 风格：选择系统的指纹 {#def-fengge}
**风格=一个人在语体许可范围内稳定成习的选择系统**——同样写离别，王维“西出阳关无故人”平视一句顶一万句，王勃“无为在歧路，儿女共沾巾”把劝慰写成昂头，李商隐却“相见时难别亦难”绕柱三匝。可测量的落点全在课文旧工具里：**词频偏好**（张爱玲爱“铜锈绿”“月白”的颜色词库）、**句法指纹**（鲁迅的文言残留短句与曲折复句并用；汪曾祺的“短。极短。”标点性格）、**辞格库存**（钱钟书的比喻军火库 vs 赵树理几乎不越白描雷池）、**节奏口癖**。时代风格是放大版指纹：唐文的雄浑与晚明小品的狎昵不是两位作者之差，是**语体库存与题旨期待的换代**。
:::

::: definition 两对经典刻度 {#def-kedu}
风格学的手摇刻度盘，最耐用的两对：**朴素—绚丽**（“清水出芙蓉，天然去雕饰”vs 汉赋的铺采摘文、《子虚》《上林》的地名字典；注意朴素≠简陋——**绚烂之极归于平淡**是第二座峰，苏轼晚年语）；**简洁—繁丰**（《春秋》字字褒贬 vs 马尔克斯一个段落走三代人；中国批评传统偏简——“句有可削，足见其疏；字不得减，乃知其密”刘勰《熔裁》十字针砭）。刻度本身无褒贬，**位置才有权重**：繁丰失度叫冗蔓，简洁失度叫枯窘——风格判分永远带题旨配重（悼词贵简，赋贵铺）。
:::

::: example 盲测：三个句子的东家 {#ex-mangce}
三句各判东家并给体证（仿作亦须按“某家风”指认）：①“南京的鸭巷我已不大记得，只记得盐水鸭确实比别处淡些。”②“于浩歌狂热之际中寒；于天上看见深渊。”③“月亮升起来，院子里凉爽得很，干净得很。”
::: solution
①**汪曾祺风**——淡到失去形容词的抒情、口语的味觉记忆、“我已不大记得”的迂回；②鲁迅《野草》——介宾起势的文言骨架+悖论对偶，“于天上看见深渊”的冷硬形而上；③**孙犁风**（《荷花淀》一路）——白描+叠用“得很”的方言口吻+短句洁净如洗过的院子。**判词只许引用可数证据**（词库/句法/标点），禁用“我感觉像”——感觉是结论的化装舞会。
:::
:::

::: theorem 文如其人：一半成立，一半是债 {#rule-zhuren}
扬雄说“言，心声也；书，心画也”，传统批评据此把风格当人品收据。现代审问给出折中判决：**风格如人，如其“向语言索取的方式”，不如其道德账目**——海子的悖论短句与他真信的殉道同构（成立）；某大作家的谦卑长句与其私下的刻薄并不矛盾（长句是文体人格，不是护照人格）。可操作的区分：**语言人格**（文本内可证的偏好系统）与**经验人格**（传记真相）——风格学只承诺前者；用风格给人定罪或洗白，都是把相关当因果。但“一半是债”也要还：长期写作的人确实被文体塑形——**你怎样说话，就怎样想事的概率不低**，这就是为什么修辞学从不敢把“诚”字归档。
:::

::: history 从《文心雕龙·体性》到风格统计学 {#sec-lishi}
中国风格学的第一座体系是刘勰《体性》：**八体**（典雅、远奥、精约、显附、繁缛、壮丽、新奇、轻靡）两两成轴，并抛出千年命题“**才性异区，文辞繁诡**”——风格根于才性，然“学慎始习”，亦可陶铸（“摹体以定习，因性以练才”）。钟嵘《诗品》分品第、严羽《沧浪诗话》以“入神”为最高格，都是这把标尺的后裔。西学那头，布丰 1753 年接任法兰西学术院院士的就职演说丢出那句名言：“**风格就是人本人**”（le style n'est que l'homme même）——与扬雄隔一千八百年击掌。二十世纪末新武器入场：**计算文体学**用词频、功能词分布、n-gram 给作者归属打分（《红楼梦》前八十回与后四十回的统计学分歧成为公开课程案例；疑似合著的章回被判出“第三支笔”）——**指纹隐喻完成它的数字化转世：从“体性”到向量空间，风格学始终是辨认“谁在说话”的学问。**
:::

::: warning 风格三迷
一**风格拜物**：把口癖当天才（“他句子短，所以他也该短句”——学风格不学其题旨，只学到毛孔）；二**风格平等主义的滑坡**：“各有各的好，无法比较”——刻度不可比位置可比：枯窘与简练是两回事，判分权在证据不在心情；三**统计万能**：词频指纹判作者，前提是**文体与时代受控**（用现代白话训练模型去断宋文，等于用鞋底化石的模具量活人脚）——方法是显微镜，不是审判锤。
:::

::: exercise 仿写与穿帮 {level=1}
各用一句话仿“鲁迅风”“汪曾祺风”，并自曝两处最易穿帮的模仿点。
::: solution
参考：鲁迅风——“我家门外可以作证：有两棵树，此外便没有别的什么了。”（文言骨架+冷反讽+“此外”的板起脸）；汪风——“豆腐很嫩。酱油是后加的，倒也不妨。”（短句+味觉小确幸+“倒也”的宽厚）。穿帮点示范：鲁迅风最忌油滑（把反讽写成段子），汪风最忌用力（抒情一冒头即出戏）。仿件+穿帮自曝各二即满分。
:::
:::

::: exercise 一句话测词库 {level=2}
取同一作者两篇短文（各 300 字），统计其高频实词与虚词前十五，验证“词库指纹”是否存在；再与另一作者对照表比较，陈述你的置信度。
::: solution
判分点：统计过程可复现（列表附后）；指纹论据须落在**功能词与搭配偏好**（“其实/大抵/自然”类），不拿题材词充数；置信度声明包含样本量局限——统计诚实是本课给文科生的第一个现代训练。
:::
:::

::: exercise 风格会诊 {level=2}
某品牌请两位文案写“老味道”主题：甲“时光煨旧了烟火，舌尖上的乡愁从未走远。”乙“还是那口锅。汤比二十年前，浓。”判两篇风格坐标（两对刻度定位+题旨适配），并说明投放渠道。
::: solution
甲=绚丽×繁丰端（比喻授权全开，“舌尖上的”已是公共库存——陈旧感与怀旧题旨撞车）：适合节日情感片旁白；乙=朴素×简洁端（“还是那口锅”零修辞起步、“浓”单字收句脚，味觉证据自给）：适合门店海报与包装。判分点：坐标+各一“为何适合”落到媒体物理属性（视听时长/瞥读距离）。
:::
:::

::: exercise 小论文：风格可以被教吗 {level=3}
写八百至一千二百字：刘勰说“摹体以定习，因性以练才”（先临摹体式定习惯，再顺性情练才干），布丰说风格即人本人——写作课到底能教什么？用你自己一学期语料（两份早稿+现稿）做证据，指认一项**可教**的微观习惯（标点对、句子长度、套话戒断等）与一项你判断**不可教**的东西，并给出你的教学论边界。
::: solution
判分点：三稿对比证据真实（改动处标注）；“可教”项须是可操作可检查的动作（非“多读多写”空转）；“不可教”项给出反例意识（教过没学会/学会反受伤各一）；结尾回应刘勰与布丰之争且**有保留**——允许结论是“可教的是戒律，不可教的是胃口”，但必须自证。
:::
:::

::: summary
风格=语体许可范围内稳定成习的选择系统，词库、句法、辞格、标点是它的四组指纹；朴素/绚丽、简洁/繁丰两对刻度无褒贬、位置有权重；“文如其人”判给语言人格一半产权，统计方法让指纹可计数，但显微镜不是审判锤。刘勰的“摹体定习、因性练才”是千年前的教学大纲，今天仍不过时——可教的是戒律与眼力，不可教的是胃口与命。下一课全课收官实战：给真实文本做修辞分析手术。
:::
