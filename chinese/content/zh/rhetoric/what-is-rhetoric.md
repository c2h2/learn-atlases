---
title: "什么是修辞"
---

“修辞”两个字挂在中文系课表上，却常年被误会成“教你写漂亮话的手艺班”。这一课先正名：**修辞学是关于“选择”的科学——语言有得选，选得对不对，凭什么说对。**

## 正名：从“修辞立其诚”说起 {#sec-zhengming}

::: definition 修辞与修辞学 {#def-xiuci}
汉语“修辞”古已有之：《周易·乾·文言》“修辞立其诚”，本指言语的修养与诚意的持守；西语 rhetoric 出自亚里士多德，本义是“在任何给定情境中发现可用的说服手段”。两脉合流成现代学科定义——**修辞学研究与调整语用以适应题旨情景的规律**：陈望道《修辞学发凡》的宪章条款“修辞以适应题旨情景为第一义”。三个关键词：**选择**（语言系统提供库存，修辞是在库存里挑）、**适合**（没有绝对的好句，只有对了场合的句子）、**效果**（不达效果的修辞是装饰品堆砌）。
:::

::: theorem 三道防线：修辞不是什么 {#rule-fangxian}
①**修辞≠藻饰**：“他走了”在讣告里是修辞的上乘（适合“敬与哀”的题旨），堆砌“溘然长逝化作夜空中最亮的星”反而是失礼——**调整**（消极修辞：准确、简约、通顺）与**修饰**（积极修辞：辞格、形象）是修辞的两翼，教学传统重修饰轻调整，是偏科。②**修辞≠辞格大全**：辞格是选择的历史结晶，不是选择本身；不用任何辞格的《背影》语言是顶级修辞。③**修辞≠语法对立面**：“语法问通不通，修辞问妥不妥”——“她死了。死得很轻。”语法合格、修辞精彩；“美丽的悲伤”语法合格、修辞看场合。**三层判分：合语法 → 合逻辑 → 合情景，修辞学坐在第三层。**
:::

::: example 一坐三问 {#ex-sanzuo}
为同一事件（老师宣布取消月考）各写一句：对学生班会、对家长群、对校长工作报告——并标出每句的题旨情景判断。
::: solution
班会：“月考取消——大家先别急着欢呼，我们把复习计划升级一下。”（题旨：安抚+引导；情景：同侪在场、口语、幽默额度高）；家长群：“月考已取消，后续安排将另行通知，请各位家长放心。”（题旨：信息+镇定；情景：书面正式、对方有焦虑预期，“放心”二字即对症的修辞）；报告：“本学期起优化过程性评价，原月考安排相应调整。”（题旨：政策表述；情景：对上负责，“取消”婉转为“调整”是讳饰也是体制语体要求）。**三句无一句“漂亮”，三句都是好修辞。**
:::
:::

::: definition 两派与一个传统 {#def-liangpai}
中国现代修辞学内部有头有名分的分野：**格义派**（以辞格为纲，编“九十七式”的清单之学，上承南宋《文则》以来研究辞格的“谱录”传统）与**义法派/适应派**（以题旨情景为纲，《修辞学发凡》集其大成：消极修辞与积极修辞二分，辞格降级为“积极修辞的特例”）。教科书今天用的“语词汇编+句式+辞格”三板斧，是两派折中后的公约数。判派系的小测验：一本书若目录是“比喻/比拟/借代……”，它是格义派；若开宗明义“适合题旨情景”，它是发凡派——**两派不是对错，是望远镜与风景画**。
:::

::: history 修辞的四段生命 {#sec-siming}
**古典萌蘖**：孔子“辞达而已”、《周易》“修辞立其诚”、《文心雕龙·镕裁》裁芟浮词——没有学科，全是诗话评点里的零金碎玉；**现代转型**：学堂课本把“作文法”编成练习（1921《作文轶规》），1932《修辞学发凡》立起“题旨情景”宪章，“修辞学”定名；**规范化时代**：1951 年《语法修辞讲话》把修辞并入“写通中文”的国家工程，从此修辞与病句同桌、与标点同卷；**跨界时代**：1980 年后语用学、文体学、认知语言学、传播学纷纷来分一杯羹——广告、舆论场、外交记者会成了新修辞学实验室。四段生命的总题不变：**言语如何配得上场合与心意。**
:::

::: intuition “修”不是“饰” {#int-xiu}
“修辞”的“修”，今人一读就想到“美化”；但在古汉语里“修”首先是**整治、调整**——修屋顶不是给屋顶刷漆，是把它修理到不漏。《修辞学发凡》的消极修辞（明确、通顺、平齐）正是这份“不漏”的手艺：删一个冗词、调一个语序、换一语域，文本从“能看”到“耐看”。**大修辞无痕**：一切辞藻是创可贴，真正的修辞常常是让句子回到它本该的形状——《背影》里那句“我买几个橘子去”，无一字修辞术，全是修辞。
:::

::: warning 三种天真病
一**藻饰病**：把“修辞”写成“好词好句摘抄大赛”，作文里塞满“岁月静好”“星河滚烫”——库存词不答题旨，是语言的自动售货机；二**辞格病**：读到“他放下行李，也放下了心”不辨双拟不分析效果，只喊“比喻！”——认格不是修辞学，效果论证才是；三**灵感病**：“写作靠感觉，规则误英雄”——感觉本身是长期选择训练的沉积，本课的全部野心就是把这点“感觉”摊在桌上检查。
:::

::: exercise 三版广告 {level=1}
给同一款保温杯写三句文案：老年市场、户外圈、写字楼礼品，各一句并说明题旨与语域判断。
::: solution
参考：老年“一口热的，从早暖到戏散”（情景：晨练与戏曲、口语、利益=持续）；户外“零下二十度，第一口水是烫的”（题旨：极限可靠性、数字作证、体感细节）；礼品“他加班到十点，杯子替他记得喝水”（受赠人不在场的人情账——“替”字是修辞眼）。三句判词到位即满分。
:::
:::

::: exercise 找出“看不见的修辞” {level=2}
读《背影》选段（父亲买橘一段），列举其中至少三处**不借助任何辞格**而生效的修辞手段。
::: solution
参考点：叙事的延迟与慢放（“他用两手攀着……”分步动词链——白描的节奏即情感）；口语的直接引语插入（“我买几个橘子去”——人物语言原色入文）；数字与颜色的克制（“黑布马褂”“深青布棉袍”——暗色铺底让“橘”发光，色彩修辞不用一个比喻）。三处+效果论证即满分。
:::
:::

::: exercise 小论文：谁是修辞人 {level=3}
写八百至一千二百字：选一段你身边的真实话语（家庭群劝架/弹幕/导购直播任选），论证“人人都是修辞人”：指出至少五个可指认的选择点（为何用此词此句此表情符、此语气词），并评估各自对题旨情景的贴合度。要求语料注明时间场合。
::: solution
判分点：语料真实可核；选择点≥5 且各配“备选为何未选”的对比论证（修辞学的方法即**证明选择曾经存在**）；贴合度评价有题旨重述作基准；不下“他口才真好”这类无分析的判词。
:::
:::

::: summary
修辞=在语言库存中为特定题旨与情景做选择，并为效果负责；“修辞立其诚”给伦理，“适应题旨情景”给方法，“修是整治不是化妆”给气质。格义派与发凡派是望远镜与风景画，三道防线（藻饰、辞格、灵感三种天真）清完场，后面的课就能安心干活：选词、选句、辞格、声律、语体、风格，直至给真实文本做分析手术。
:::
