---
title: "语体"
---

词有户口，句有场合，整篇文本有“体”。语体（register）是语言对社会生活的分类账：**谈事情用嘴，红头文件用纸，代码注释用第三种腔调**——用错场合的语法正确句，依然是错句。

## 口语与书面语 {#sec-koushu}

::: definition 一对连续统 {#def-erfen}
语体分裂的第一刀切在**媒体**上：口语（音响信号、现场共参、短句缀行、冗余度高——“那个，就是说，大概，可能吧”全是 face-saving 的缓冲垫）与书面语（视觉符号、脱离语境、长句架构、密度高——可以一句三百字不违约）。但两者不是两个国家，是**同一光谱的两极**：台词、口播、直播是带稿的口语；微信聊天是敲字的口语（“书面化的口语”新变体——用打字的速度过嘴的生活）。汉语史在这条带上反复摆渡：文言与白话分家千年（“言文分离”），1917 年白话运动“言文一致”收编——**普通话书面语就是口语的正字化**，这在全球书面语谱系里都算年轻。
:::

::: definition 体与体之间的公文 {#def-gongwen}
民族语体（function style）传统切五块——**科学语体、政论语体、新闻语体、公文语体、文艺语体**（口头语体则是媒体端的另一坐标，勿与五体混轴），1960 年代教学体系从苏联功能文体学引进并定型：科学体（术语单义、逻辑连接词全副、被动与名词化高发——“实验表明”禁止“我感觉”）；政论体（立场先行、判断句与反问成阵、“必须/坚决/深入贯彻”三连）；新闻体（倒金字塔、直接引语、**引述动词的免责设计**——“据称”“当地时间”是修辞学的避险气囊）；公文体（用语词典化：“贵局”“收悉”“妥否，请批复”——整串是语用公式，逐字不可替换；被动与无主句天然当值）；文艺体（唯一**鼓励个人方言与超常规搭配**的体——科学体的失误在文艺体是得分点，语体纪律的边界案例）。
:::

::: example 一语的五个宇宙 {#ex-wuyu}
把“本公司决定不再生产某型号产品”改写为五种语体各一句，并标出各自的“体标”。
::: solution
科学/技术：“型号 X 于 2024Q2 停产，替代方案见表 3。”（体标：编号、时间表）；政论：“坚决淘汰落后产能，把资源交给未来。”（体标：“坚决”+动宾口号化）；新闻：“记者从公司获悉，该型号产品将于下季度停产。”（体标：消息来源框）；公文：“经研究，现就X型号产品停产有关事项通知如下。”（体标：“经研究”“现就……通知如下”公式框架）；文艺：“流水线尽头，最后一台X没有装上一颗螺丝——像一句决定不说出口的话。”（体标：比喻授权、破折号留白）。**同一命题的五件体衣，体标各可验尸。**
:::
:::

::: definition 网络语言：一种语体还是一窝 {#def-wangluo}
“网络语言”是个筐：弹幕（即时共在+**字幕寄生**——原文还在，评论在滚）、微博/动态（字数镣铐下的浓缩修辞，标题党句法）、群聊（@、[表情]、“收到”复读——**表情符是副语言的官方化**：语调有了写法，是文字史新鲜事）、直播口播（成交动词+倒计时：“三二一上链接”）。共同基因：**平台可供性（affordance）直接铸造句法**——字数限制造出凝练体，回复树造出嵌套省略，转发语造出“套壳引语”（“看到最后泪目了”=转发语与原文的缝合怪，结构混乱的病句章亲戚在这里是常规构式）。网络语体对传统的冲击不在“坏语法”，在**混合速度**：公文腔、客服腔、二次元黑话同屏调情（“宝子，家人们，奉告各位”）。
:::

::: history “语体”概念的登记史 {#sec-dengji}
汉语本有“体”的批评传统（《文心雕龙·体性》分八体，讲的是风格；现代“语体学”是另一脉）。二十世纪三十年代“语文体”“公文式”已入日常；1940 年代起学界给“语体=功能变体”下定义；真正的建制时刻是**1960 年前后教学体系引入苏联的功能文体分类**，五种体写进教科书，成为几代人的语感地图；1980 年代功能文体学、1990 年代“语体交际观”再给地图加了用户维度（语体不是衣柜，是对话的门票）。2010 年代后，网络语言学爆发——分类地图第一次被用户量反推：**每天新增的语料比过去一千年总和还多，“体”的户口必须夜审。**
:::

::: warning 语体病三例
一**升堂入室错穿**：讣告写“老爷子下线了，R.I.P.”（网络哀悼语入侵殡葬公文体，圈内可、公开即事故——参[[modern-grammar/faulty-sentences]]“语域得体”判例）；二**客服腔感染**：政府通报“宝子们注意啦！病毒来袭，亲，戴口罩哟”——亲近的代价是权威透支，疫情语言史有账；三**文体漂移**：论文摘要写成散文（“在这个快节奏的时代……”）、判决书写成檄文——判分标准永远是**本文体的读者预期**，不是作者舒适区。语体错误的统一名称：**得体性违约**——语法错是病，语体错是尴尬，尴尬比病更难被原谅。
:::

::: exercise 语体翻译官 {level=1}
“您的快递晚了，别急”改写为：①官方客服体 ②道歉函公文体 ③脱口秀体 各一句。
::: solution
①“非常抱歉给您带来不便，您的快件当前延迟，我们将持续为您跟进物流信息。”（客服体=道歉+状态+行动+称呼“您”）；②“关于快件延误事宜，我处深表歉意，已启动赔付流程，特此致函。”（“我处”“特此”公式）；③“您的快递正在完成它的西西弗斯之旅——推上去，又滚回来。”（文艺/段子体：神话借尸+轻佻题旨错配制造笑点——幽默=受控的语体违约）。三体体标齐即满分。
:::
:::

::: exercise 混血鉴定 {level=2}
收集三句“语体混血”真实语料（如“本平台郑重告知：双击666”），判定其生成机制（反讽/营销/玩梗）与得体性收支。
::: solution
参考机制：庄严词+轻场面=**降格喜剧**（“郑重告知”公文框套“666”黑话，庄重感被征用后炸膛）；营销体专吃权威蹭（“家人们，奉告”）；判定收支看**受众是否共享解码暗号**——圈内会心=收入，圈外被冒犯=支出。三例+机制各配即满分。
:::
:::

::: exercise 一份通知的五套衣服 {level=2}
就“周五停电检修”写五条通知：物业公告栏、部门群、给重要客户的私信、广播口播、小学生广播稿——各注明语体选择三理由。
::: solution
参考要点：公告栏=公文骨架+要点化；部门群=短句+收到请求+时间地点前置（移动端扫读）；私信=敬语系统全开+“您”+落款人名；口播=数字口语化“五号下午两点到四点”+重复关键信息（听觉不可回滚）；小学版=“小灯泡要休息一个下午”。每条三理由含媒体/受众/目的维度即满分。
:::
:::

::: exercise 小论文：语体平权时代 {level=3}
写八百至一千二百字：“公文体返场表情包、客服腔入侵通报、学术黑话出圈成梗”——语体边界是松了还是重组了？用本课“体标”方法分析两则真实争议语料，并给出你的“语体礼仪修正案”三条。
::: solution
判分点：两则语料的体标拆解可复核；核心论证承认“混合加速≠边界消失”（场合期待仍在审判，只是陪审团年轻化）；修正案具体到场景（如：公共服务文本禁玩梗、私人账号标“个人语体”免责声明）；引“尴尬比病更难被原谅”并给出你的剂量条款。
:::

::: summary
语体是语言对场合的分类账：媒体一刀（口语/书面及其间大片滩涂），功能五体（科学、政论、新闻、公文、文艺——文艺是唯一发超常规通行证的体），网络语团把平台可供性写成新句法。得体性违约比语法错误更扎心，因为它冒犯的是**在座所有人**——这就是为什么下一课要从“场合”走向“人”：风格，语体流水线上那些不肯穿制服的名字。
:::
