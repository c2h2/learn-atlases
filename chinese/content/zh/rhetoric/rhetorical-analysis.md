---
title: "修辞分析实战"
---

前八课的工具全部上桌，这一课只教一件事：**怎样对一段真实话语做一场可复核的手术**。分析不是“我觉得好”，是“它在此处做了此选择，机制如此，效果如此，证据如下”。

## 方法学：三步一案表 {#sec-fangfa}

::: definition 描述—解释—评价 {#def-sanbu}
**第一步描述**：把文本里的选择点逐一指认（词、句、辞格、声律、语体、风格信号）——只登记事实，禁下判词；**第二步解释**：每个选择点回答三问——*为什么选它*（题旨情景压过来的那道题）、*备选为何落选*（**证明选择曾经存在**，本课最高频失分点）、*机制怎么走*（用哪条课的哪条线：焦点在句尾？平仄在句脚？借代靠库存？）；**第三步评价**：给效果打分并写明**打分标准**（达意？得体？记忆留存？受众反应可否观测）。一案表五栏：语料摘录｜选择点｜机制｜备选项｜效果与标准——五栏齐，手术算完成；只有形容词的“赏析”等于只开了刀不写病历。
:::

::: definition 修辞格的判定树 {#def-panding}
面对一个疑似辞格，按序问：①意义是否**搬家**？搬家靠**相似**→比喻系（有喻词=明喻，判断架=暗喻，只留体=借喻）；靠“**当作**”直入动作→比拟；靠**相关**→借代；②是否**超额言说**且意图公开→夸张；③是否**反向行驶**且有解→反语；④一根绳**挂两钩**→双关；⑤只动**格式**（对称、复现、台阶）→形式厅诸格。判例示范：“他是我们村的气象台”——①搬家✓ 相似✓ →比喻系→“是”判断架→**暗喻**（预报天气=话语权威借代✓ 二层套叠，不作二层判———**能判一格不判两格，是判例的节制美德**）。
:::

::: example 手术示范：一句政策口号 {#ex-shufa}
“绿水青山就是金山银山。”——上表动刀。
::: solution
选择点：①判断句架“A就是B”（暗喻+确言语气，“就”字焊死等同，不留“像”的让步缝）；②平行对举“绿水青山/金山银山”（偏正结构镜像、颜色对颜色、自然财宝对人间财宝——**以空间换时间**的对偶账）；③“山水”对“山”的重出（顶真意味的链条感，同字复现=口号刻痕）；④零连接词（因果、条件全押在并置上——意合的最高规格，判断即论证）；⑤音节 4+2+4，平声尾“山”放远（可持续的余韵由韵脚开口音 an 承包）。备选证明：若改“保护生态能促进经济繁荣”，术语正确但**无画面、无对称、无刻痕**——传播账本一算即输。效果：对仗+暗喻+确言三合一，把复杂政策压缩成可背诵、可书写、可涂墙的**空间化真理**。争议也随机制来：等同式判断句把“可以转化”的关系说成“就是”的同一关系——**修辞强度与逻辑精确是一对显式的汇率**，这正是评价栏该写的话：不判它对错，判它**买到了什么、付了什么**。
:::
:::

::: definition 四案场：演讲、广告、新闻、歌词 {#def-sianchang}
**演讲**：查三诉配置（ethos 身份构建——自称与履历投放密度；pathos——故事、呼告、音步催浪；logos——数据与框架），并查**现场可供性**（重复与呼应在听觉里的复听率决定修辞配比，书面稿朗读必翻车处即证据）；**广告**：查诉求轴（信息型/转化型）、承诺的语法包装（“有助于”免责斜坡、比较级陷阱“更”无基准）、互文偷电（对成语、歌词、名言的**寄生式改写**——熟句韵脚是现成的注意力贷款）；**新闻**：查及物性系统（“警方使用武力”vs“冲突中有人受伤”——施事显隐=责任分配）、引语分级（直接/间接/自由间接的距离政治）、名物化（“降价”变“优化价格策略”）——系统功能语言学的清单在汉语同样锋利（[[modern-grammar/sentence-patterns]] 被字句机位）；**歌词**：韵密与旋律音节的咬合、虚词为元音让路——词曲抢拍时语义让位，副歌首字开口度=高音的合伙人。
:::

::: history 从《诗大序》到批评话语分析 {#sec-piping}
中国有系统的文本解释从《诗》学开始：《诗大序》“诗言志”定题旨，《毛传》的“赋比兴”读数法是最早的**辞格判定树**（朱熹《诗集传》千年后仍按此逐句批注）；金圣叹、脂砚斋的**夹批与眉批**是汉语修辞分析的文体发明——分析以寄生文本的形式存在，与手术对象同屏。西方那头，亚里士多德三诉是万用起点，二十世纪新修辞学（韦恩·布思以“认同”重定义修辞）把战场从说服扩到**认同**（identification：修辞是说“我们是一伙”的语法）；1970 年代后批评话语分析（费尔克拉夫）把权力审计制度化为常规流程——新闻用词、机构话术、议程句法皆可庭询。本课立场：**四案场全谱系混血**——判定树是毛传的，三诉是亚里士多德的，权力审计是费尔克拉夫的，口号解剖是汉语自己的。
:::

::: warning 分析四忌
一忌**贴标签式分析**：“运用了比喻的修辞手法，生动形象”——零机制零证据，等于没开刀只报了刀数；二忌**过度阐释**：给每个虚词安罪名（把“了”读成“作者对时代的告别”——时态助词不背这锅）——**每一判必须可证伪**：说得出“若此处换X则此判不成立”才算立案；三忌**脱离体裁**：用悼词标准要求产品发布会——场合不对，一切精妙的分析都是漂亮的错卷；四忌**无伦理栏**：分析 persuasive 技术而不标注其操纵剂量（广告庭的“焦虑-解药”配方、通稿的“被字免责”），是把手术报告写成种草文——**修辞学派的职业道德：解剖刀要写清朝向**。
:::

::: exercise 完整手术 {level=2}
给一句你常用的口号/歌词/广告语做五栏一案表全案（不少于 5 个选择点），其中“备选证明”栏每点必须给出可替换写法并说明败因。
::: solution
判分点：选择点≥5 且跨 ≥3 个工具层（词/句/格/声/体）；备选项真实存在（替换句可成立但传播账本落败）；机制点名到课；评价栏含自定的可检查标准——缺一栏退回。
:::
:::

::: exercise 辩庭：操纵还是修辞 {level=3}
选一则有争议的说服文本（带货话术/公益恐吓广告/竞选金句），先做机制分析，再开“伦理庭”：控方指其操纵点，辩方以“受众可拒绝”辩护，你写判词——标准必须显式（信息透明、可逆性、脆弱群体三条至少用两条）。
::: solution
判分点：机制与伦理两栏分立不混（先把刀法写清再谈刀伤）；判词使用显式标准且可复用于新案；对“受众可拒绝”给出经验性反驳或支持（媒介情境里的拒绝成本）；结论允许灰色地带但必须划出你判定的红线位置。
:::
:::

::: exercise 全课总复习卷 {level=2}
不翻阅笔记，凭记忆列出九课各一个“随身带走”的命题（一句话），并用其中三个命题分析同一则 30 字内微文本。
::: solution
参考命题流：修辞=选择且适合题旨情景（一）／选词四轴准确优先（二）／句式即立场、尾重是追光（三）／隐喻是承重墙不是烟花（四）／形式=秩序预付与解码率生意（五）／四台节拍器、好听不等于真确（六）／得体性违约（七）／风格是指纹、语言人格（八）／分析三问+备选项证明（九）。三命题一文本=合格缝合手术；能指出命题间张力（如新鲜 vs 得体）加分。
:::
:::

::: summary
分析三步：描述只登记、解释必证明“选择曾经存在”、评价先亮标准；判定树把意义辞格与形式辞格一网可判，体裁是判决书的第一行，伦理栏是修辞人的执业执照——**解剖刀要写清朝向**。至此修辞学九课全部结业：从“什么是修辞”的宪章，到选词、选句、辞格、声律、语体、风格六道工序，最后站上手术台。语言的库存（词汇课）、骨架（语法课）、声学（语音音韵两课）、文字（汉字课）你都见过——修辞是把它们一起端上桌的那只手。下一站按图谱前行：议论写作——当修辞从“把话说好”走进“把理讲赢”。
:::
