---
title: "声律与节奏"
---

汉语随身带着一件音乐行李：音节整齐、有声调、韵母可查典。本课清点三样声律资源——**韵、调、节**，再看它们在诗与口号两座城里如何异地执业。

## 韵：回文的锚 {#sec-yun}

::: definition 押韵的机制与账本 {#def-yatie}
**押韵**=若干句尾（或句中定位）用同韵母的字，周期回响制造“提前预知—命中兑现”的快感：**韵是听觉得来的记忆假体**（口传文化靠它搬运《诗经》与史诗，[[sounds-of-mandarin/speech-sounds]] 的音节清晰度在此复利）。诗韵的账本历代不同：《切韵》系 206 韵为近体诗法定押韵库（平水并为 106，见[[phonology/rhyme-books]]），曲韵《中原音韵》平分阴阳入派三声（[[phonology/to-mandarin]]），今天唱作人直接用普通话十三辙与拼音韵母——**韵书是一部压缩的语音史，选韵=选时代**。歌词押韵密疏另有算盘：副歌密韵成钩，主歌疏韵叙事；换韵即换气的段落感。**双声叠韵**是词内的微韵：双声=声母相同（“参差”cēn cī），叠韵=韵母相同（“窈窕”yǎo tiǎo；《诗经》“我马玄夫”的“玄黄”即病困叠韵成词）——联绵词多半是双声叠韵的化石，把音节美学焊死在词形里（[[modern-vocabulary/morphemes-words]] 联绵字条）。
:::

::: example 声音的取证现场 {#ex-zhengjv}
《琵琶行》：“大弦嘈嘈如急雨，小弦切切如私语。嘈嘈切切错杂弹，大珠小珠落玉盘。”请列出它的声音施工队。
::: solution
①叠音：嘈嘈（粗弦重锤）、切切（细语碎拨）——AA 式摹状自带音量参数；②换韵工程：前四句“雨、语”撮口细声相衔，到“盘”忽换开口呼——**韵母的口腔开度就是音量的调音台**，珠落玉盘必须由“an”来接；③“嘈嘈切切”重出+“错杂弹”三字仄尾打顿——拟声、复沓、节奏顿挫三队同开，才换来“珠子落盘”的通感。这是白居易的施工日志，句句可验。
:::
:::

## 调与节：平仄和音步 {#sec-tiao}

::: definition 平仄：给文章装上抑扬 {#def-pingze}
四声二元化是汉语节奏学的天才简化：**平（平声，长而稳）对仄（上、去、入，短促高下）**——南朝齐永明间沈约（441—513）发现四声、倡“声病说”（八病之禁），到初盛唐律化成“对”（一联内平仄相反）与“黏”（联与联间平仄相承）两条铁律，近体诗自此有了音阶（详[[phonology/mc-finals-tones]]；格律实操在[[poetry-metrics]]）。**散文不讲对黏，但照吃平仄的账**：成语偏爱“平平仄仄”对“仄仄平平”的四音节模板（“高山流水”“地久天长”），句脚平声有余韵（适合收束）、仄声斩截（适合立威）；播音腔的“句尾下沉”其实是去声当家。**音步**（音节群）是第二架节拍器：现代诗的“顿”（“轻轻的我走了，正如我轻轻的来”三三五的呼吸）、标语口号的“二二三”七字岗与“发展是硬道理”式五字三顿——**节奏的本质是规律性重复+可预期的违约**，平仄、音步、韵脚是三台并排的节拍器。
:::

::: definition 音乐性的双城：诗与口号 {#def-shuangcheng}
同一套声律资源，在**诗**里供审美（韵可以疏、可以换、可以故意出韵制造踉跄——出韵的不谐本身就是修辞），在**口号**里供记忆（政策标语把押韵当存储卡用：“车到山前必有路，有路必有丰田车”顶真+押韵双保险。汉语广告爱用“四四”“七七”模板与尾韵，因为**韵脚相邻的词会被大脑误记为关系密切**（心理学“韵律即真理”效应：押韵的格言被判定更可信——声音美学直接干预信念，实验文献已有复现）。“押韵的谎言说得快，不押韵的真话说得累”——这是声律的伦理暗面，下一课语体课见分晓。
:::

::: history 从“声依永”到“新诗韵表” {#sec-lishi}
《尚书·尧典》（成书战国，追记托古）早有一句总纲：“**诗言志，歌永言，声依永，律和声**”——延长语言成歌，配合声音成律，三千年不变的施工图。沈约四声说（约 480 年代）是音韵学第一次反哺诗歌工程；《切韵》601 年立档后，诗人按韵书交作业一千三百年（1941 年《中华新韵》按今音归部，是“改按普通话押韵”的官方并轨）。新诗百年走了两条线：**戴望舒《雨巷》**式的音乐余韵（“她彷徨在这寂寥的雨巷”叠韵、复沓的晚近交响）与**朗诵诗、歌词**的工业声律（每行几“顿”成为现代诗格律学的核心计量——何其芳“顿数说”1950s）。今天的说唱词人以密韵与内韵复兴了这门旧手艺：**韵脚从未过时，只是换台演出。**
:::

::: warning 声律三忌
一忌**因韵害意**（“韵脚事故”）：为押“ang”硬造“伟大的辉煌照亮了前方的方向”——韵是仆人，串味即主客倒置；打油诗的病因从来不是不押韵，是**押韵押成了自动联想机**；二忌**通稿体韵律幻觉**：全文“四四对+尾韵”，庄重没攒下、滑稽倒满仓（骈散之辩的现代版，[[rhetoric/figures-of-form]]）；三忌**拟声词滥放**：“噼里啪啦轰隆隆”无差别铺满儿童文学以外文体——声音资源用错语域，等于在葬礼上自带音响。
:::

::: exercise 平仄体检 {level=1}
给“无边落木萧萧下，不尽长江滚滚来”标平仄（依今音亦可），说明它符合哪条律、句脚效果如何。
::: solution
今音版：平平仄仄平平仄／仄仄平平仄仄平（“不”入声今去、“滚”上——上声归仄）✓完全成“对”；句脚“下”（仄）催顿、“来”（平）放远——上句收不住，下句放得开，落木之促与长江之遥先由声读出。标对+两项说明即满分（注：古音“陌”“质”等入声字归仄，依平水更严，皆合格）。
:::
:::

::: exercise 口号调音师 {level=2}
把“请给老年人让座，注意扶梯安全”写成两条各不超 14 字、押韵且语域得体的地铁口播，并解释你的韵位选择。
::: solution
参考：①“您让一个座，暖一程车”（uo/e 邻韵通押，口语暖域）；②低龄域方案“握紧扶手，稳稳走走”（ou 韵叠用，亲子专列可用，正线偏软）；庄重域定稿参考“先下后上，文明礼让”（ang 韵庄重，去声收多、干脆指令型）。韵位解释涉及开度/声调/语域三选一即合格——允许失败案：比油滑更糟的是无方案。
:::
:::

::: exercise 歌词韵脚审计 {level=2}
选一首你歌单里的中文歌词（8 行以上），统计韵脚密度与换韵位置，判断韵式与段落功能的配合，并挑一处“为韵害意”或赞一处“险韵成功”。
::: solution
判分点：韵脚表可复核（标注每行韵母）；密度结论与段落对应（副歌密/主歌疏等）；个案论证给出**语义代价或收益**的具体所指——不许以“很押韵很好听”结案。
:::
:::

::: exercise 小论文：格律的遗产 {level=3}
写八百至一千二百字：以一首现代歌词或新诗为细读对象，回答“废除了格律以后，现代诗靠什么维持音乐性”（可用资源：顿数、复沓、内韵、跨行、声音象征）；必须与一首近体诗同题对照（各选写“月”或“雨”者）。
::: solution
判分点：两作品声音资源清单齐备且术语准确；论证承认“音乐性标准随文体改变”而拒绝“新诗无音乐”的稻草人；对照段落指出同一资源（如叠音）在两体中功能位移。
:::
:::

::: summary
声律四台节拍器——韵（周期回响+口腔开度调音台）、调（平仄对黏，句脚定收放）、节（音步顿数，规律重复+可预期违约）、纹（双声叠韵的词内微韵）。诗把它们调成审美，口号把它们调成存储卡，“韵律即真理”效应提醒我们：好听与真确是两条独立跑道。上一课形式、这一课声音，下一课离开句子，进入社会：语体——谁在什么场合、以什么身份说话。
:::
