title: "意义辞格"
---

本课是辞格馆的正厅：比喻及其亲戚（比拟、借代）、夸口的艺术（夸张）、声音的诡计（双关）、说反话的权利（反语）。六件展品共享一个秘密——**意义可以顺着相似、相关、相违三条轨道滑轨搬家**。

## 比喻：辞格之王 {#sec-biyu}

::: definition 本体、喻体与三级台阶 {#def-biyu}
比喻=不同类事物因相似点搭桥：本体、喻体、相似项三件。台阶三级：**明喻**（甲像乙：如、似、若、仿佛——“问君能有几多愁，恰似一江春水向东流”）、**暗喻**（甲是乙：这人是一堵墙）、**借喻**（本体与喻词全退场，只留喻体上阵：《故乡》里杨二嫂被起诨名“圆规”，此后文中处处直接以“圆规”称之））。判别的金标准只有一条：**本体喻体必须异类而有似**——“他像他哥哥”同类比较，不是辞格；“月亮像一只船”才及格。刘勰《文心雕龙·比兴》早说透：胡越之物可合为肝胆——比喻的魔法是**距离产生闪电**：本体喻体越远，相似点被点亮时越亮（“人生如旅馆”比“脸如苹果”亮十倍，也险十倍——险喻易滑成歪比喻）。
:::

::: definition 死比喻与活思维 {#def-si}
**死喻**：用过千年、没人再“看见”画面的比喻——“手腕”“桌面”“文件夹”“挂钩”“瀑布流量”，比喻的化石，词典直接收为义项；**潜喻**只挑一个侧面：说“他钻进死胡同”，只取胡同的“死”，不取青砖与蝉声。现代认知语言学（Lakoff & Johnson，1980）掀了桌布：隐喻首先是**思维方式**而非修辞装饰——“时间是金钱”（花费、节省、浪费）、“辩论是战争”（击破、占上风、防线失守）、“上是高兴、下是低落”（情绪高涨／心情跌到谷底）——我们用身体空间给抽象概念定位，**辞格清单的底下是一整层认知地质**（本课旧称“比喻的连锁”“系统隐喻”皆其地表露头）。
:::

## 比拟、借代：滑轨另两条 {#sec-bini}

::: definition 比拟：把A当B过日子 {#def-bini}
**拟人**：物载人言行——“感时花溅泪，恨别鸟惊心”；**拟物**：人作他物——正例：“他夹着尾巴逃跑了”（人作兽）。比拟与借喻的分辨是老考题：**比拟是“当作”（甲的动作直接是乙的动作，句法上无“乙=”判断），借喻是“像是且只留乙”**；“海风在吼”比拟（海风照旧在场，只是借了喉管）；“恶霸登门”，满村不说恶霸只说“阎王到了”——本体全程退席，读者自动解码：这是借喻。**扩而充之**：拟物可以把抽象物当实物搬运——“把快乐打包”“忧愁超重”，现代文案靠这条滑轨吃饭。
:::

::: definition 借代：相关性顶替相似性 {#def-jiedai}
比喻靠**相似**，借代靠**相关**——本体与借体在同一个世界的隔壁：以部分代整体（“不拿群众一针一线”）、以特征代本体（“圆规”同时是借代的标本：尖细身形的特征牌）、以具体代抽象（“烽火连三月”＝战争）、以工具/场所代当事（“白宫表态”“他把青春交给了讲台”）。借代的账本：**代什么必须读者算得出**——“红领巾进场”可解（时代常识库存），生代即晦涩。与借喻的分界一句话：**借喻可改明喻（像），借代不可改（“针线”不像“财物”，它本来就是财物的一部分）**。
:::

## 夸张、双关、反语 {#sec-kuzhang}

::: definition 三件带刺的展品 {#def-kuzhang}
**夸张**：言过其实而人知其过——“飞流直下三千尺”，放大；缩小夸张如“一个汗珠摔八瓣”（土地劳作的重量），又有“室仅方丈，可以容膝”的蟪蛄式小（《项脊轩志》）。夸张的合法牌照是**依据真实+意图公开**：白发“三千丈”，愁是真的，尺子不必真。 **双关**：一句话挂两个钩子——谐音双关（“东边日出西边雨，道是无晴却有晴”，刘禹锡民歌体：晴＝情）与语义双关（一词多义并挂：“他这人挺有‘意思’”，出场语境决定哪层显影；相声、歇后语、广告是双关的三个家）。**反语**：字面与心意反着走——《纪念刘和珍君》里“几个所谓学者文人的阴险的论调”，“所谓”二字即反语的信号灯；日常“你可真行啊”，音调一斜义翻转。反语的命门是**解得开的暗号**：同一句话，自家人听得懂讽刺，对家听得成挑衅——修辞学在这里直通舆论学。
:::

::: example 家族分拣台 {#ex-fenjian}
分拣并说明依据：①问君能有几多愁，恰似一江春水向东流 ②石狮子“醒”在桥头 ③不拿群众一针一线 ④“圆规”一副尖酸相 ⑤眼泪是心底的漏雨 ⑥“乖乖，这楼高得能碰着飞机！” ⑦“你居然是这种同学！” ⑧“春蚕到死丝方尽”。
::: solution
①明喻（愁似春水：抽象→具象，量与绵延双取）；②拟人（石狮借了“醒”的喉管——无判断词，非喻）；③借代（部分代整体：一针一线=财物）；④借代（特征代本人；若上文未铺身形，此处即“借喻读感”——依赖库存度决定它是谁的标本，见借代账本条）；⑤暗喻（判断句架）；⑥夸张（放大；惊叹语气发牌照）；⑦反语（惊+假“居然”——责备的表演化）；⑧双关（丝=思，蚕丝的“丝”与相思的“思”同音同卷；只点双关）。八件全对即出厅。
:::
:::

::: history 从“比兴”到“概念隐喻” {#sec-lishi}
中国修辞论比喻始于经学：**“赋比兴”**是《诗》学六义的三件工具，钟嵘《诗品》序把“比”定义为“因物喻志”，刘勰《比兴》以“胡越合体、肝胆可照”说尽异类搭桥的原理——比兴还兼着政教解说器（“善鸟香草以配忠贞”，王逸《楚辞章句序》注“善鸟香草以配忠贞”——香草美人的解码手册）。西方那头，亚里士多德《诗学》称比喻为“天才的标志”，从朗吉努斯（《论崇高》，托名，公元一世纪前后）到蒲柏，都拿它度量崇高的剂量。二十世纪的掉头最精彩：瑞恰兹（I. A. Richards, 1936）把比喻还原为“思想的普遍车辆”（vehicles of thought）；1980 年 Lakoff & Johnson《我们赖以生存的隐喻》一锤定音——隐喻住在概念系统里，不住在诗选里。辞格学由此与认知科学接榫：**你以为你在说话，其实是你的隐喻在替你说。**
:::

::: warning 出厅前的四条禁令
一禁**同类作比**：“她像她妈妈一样爱花”——比喻登记处不收户内人口；二禁**混喻**（mixed metaphor）：“这艘改革之船插上互联网的翅膀，在蓝海上乘风破浪疾驰如马”——一船三兽，图像自相踩踏；改段如改船舱：**一页只烧一炉香**；三禁**死喻硬盘活**：对“桌面”“挂钩”再作文章，读者的电击只会花在“为什么突然把我当外宾”上——新喻要**生而自带电量**；四禁**反语不分场合**：对丧家讲“这下清静了”不叫修辞，叫事故——题旨情景宪章高悬，辞格再炫，先过合宪审查。
:::

::: exercise 分拣与造册 {level=1}
各造一句自证掌握：拟人、缩小夸张、语义双关、反语——每句附一句“生效机制”说明。
::: solution
参考：拟人“巷口的路灯咳了一声，天就亮了”（咳=喉管借用+破晓事件连坐）；缩小“他的嗓门小得怕自己的呼吸”（以怕衬小）；双关：“他这个人，就是太‘真’了——录音笔都嫌他真。”（真诚/逼真两义并挂——语境决定显影层）；反语“完美，钥匙又在门里隔着呢”（倒霉时刻的“完美”=糟透，语气词是牌照）。四格自造+机制点名即满分。
:::
:::

::: exercise 混喻手术 {level=2}
治愈并解释：我们的团队要插上腾飞的翅膀，在市场的蓝海里锚定赛道，跑出护城河的加速度。
::: solution
病灶：翅膀（鸟）、蓝海（船）、锚（船）、赛道（陆跑）、护城河（战争）、加速度（物理）——六个源域抢一台戏。治法一（守恒）：全船化——“在市场的蓝海里，我们的船调整帆位、避开暗礁，驶向新航线”；治法二（分层）：允许换喻但**一段一域**、换域处给句读与过渡。手术理由+两法任一即满分。
:::

::: exercise 死喻考古 {level=2}
找五个现代汉语里的死喻（如“窗口期”“抓手”“瀑布流”），每个写 40 字：其被磨损的原始画面+什么文体又把它盘活的办法。
::: solution
参考：“抓手”本为攀岩指力点，公文里磨成纯功能件；盘活：“他的事业需要一根能抠住指甲的抓手”——回到岩壁。判分点：五喻的原始画面解释正确（不许百度式错源）、复活句确让画面“重新可见”（陌生化检验合格）。
:::

::: exercise 小论文：灾难隐喻与舆论 {level=3}
写八百至一千二百字：收集公共报道中的五例隐喻（如风暴/防线/洪水/摘桃，词自选），用概念隐喻框架分析其源域（灾难类/战争类/自然类）各自“框定”了怎样的应对剧本；回答：媒体用“战疫”“风暴”时，是描述现实还是征召情绪？要求例证注明出处时间。
::: solution
判分点：五例可核+源域归类；“框定”分析到位（灾难框架→服从疏散剧本；战争框架→动员敌我剧本；两框架可互斥地推出不同政策蕴含）；结论有立场并自承边界（隐喻是认知必需品，也是操纵现成弹药——问题不在用不用，在不自知）。
:::

::: summary
意义辞格的物理课：比喻靠异类相似（越远越亮，也越险），比拟是“当作”、借代是“隔壁”、夸张要“公开的超额”、双关一绳两钩、反语反向行驶且全凭暗号。认知语言学把整个展厅搬进了大脑——隐喻不是词藻的烟花，是概念系统的承重墙。出厅四禁令（同类禁比、混喻禁舱、死喻禁盘、反语禁闯祸场）。下一课轮到形式厅：对偶、排比、反复、层递、用典——汉语最讲“体格”的那一半江山。
:::
