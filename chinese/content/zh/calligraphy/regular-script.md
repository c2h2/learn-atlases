---
title: "楷书与永字八法"
---

楷书是五体里的**法定货币**：认字靠它，字帖先写它，考试与门匾供它——而它也是最容易被写成**印刷体描红**的一体。这一章把“真书”还原成它本来的样子：**一套有发力学的动作系统**，教具仍是一个“永”字。

## 楷书的身份证 {#sec-kai}

::: definition 真书、正书与楷书 {#def-zheng}
三个名字一段历史：**真书／正书**（汉末隶解散落、章草便速之际，**去雁尾、省波磔、立规整**的新体，魏晋成气候——钟繇与二王并称祖师级人物）；**楷书**之名来自“可为楷法”——**楷者，法也、式也**，它从诞生起就是“标准字”的代名词。关键认知：**楷书不是“写字认真”，是一种有自己字法的书体**——部件写法、笔顺习惯、钩趯方圆皆有谱（唐颜元孙《**干禄字书**》以**俗、通、正**三栏给字形分层——**哪个字“对”，历史上是有账本的**）。唐以后一切写法争论都以唐碑字法为法庭——而唐碑内部，欧颜柳三家恰好是三种宪法。
:::

::: definition 永字八法：八个动作 {#def-bafa}
**侧**（点）：不是按下去，是**掷过去**——空势取侧，入纸即按即收（“**点如坠石**”：石头落地前已在半空有了重量）；**勒**（横）：逆入平出——笔尖先微微向左顶（逆势）再右行；“横平竖直”的平是“**平举**”不是“水平”——纸面取三五度上扬，如衔勒**绷着**，松弛下垂=字塌；**努**（竖）：直而不板——弓虽张而带弹力，过直则僵，微有粗细起伏；**趯**（钩）：蹲锋蓄力，踢出见锋——钩的病十之九成在“行笔未到先踢”；**策**（提）：如扬鞭，**根粗梢锐靠的是加速度**；**掠**（长撇）：放长笔肚、笔尖送尽——忌甩虚尖（掠如梳发，秃拽则枯）；**啄**（短撇）：从空中下喙，快而刁；**磔**（捺）：渐行渐按，三拍而出——“磔”本为割牲之刀，铺毫缓行，至出脚处**驻而趱出**；“**每作一波，常三过折笔**”是古诀论隶势的话（《题卫夫人〈笔阵图〉后》传为王羲之撰——此文本本身即“传说书法学”标本，见下章），借来形容捺脚的起、行、驻三拍。
:::

::: definition 唐碑三宪法：欧险、颜筋、柳骨 {#def-sanjia}
**欧阳询《九成宫》**：法度森严而**险中求稳**——横画仰势明显、竖画微弓、中宫上提，重心常差一线不倒（俗称“排衙立仗”的**甲胄体**：每个笔画都像上了弦”）；**颜真卿《多宝塔》《麻姑仙坛记》**：**横细竖粗、两肩平满、中宫宽疏**——篆籀笔意入楷（“颜筋”：筋是弹力不是肥肉，**圆劲**是关键词）；**柳公权《玄秘塔碑》**：**瘦硬挺劲、笔笔断而笔笔意连**——柳公权谏唐宪宗“心正则笔正”（旧唐书本传）一句，又把书品与人品焊死千年；世人并称“颜筋柳骨”——**筋是含忍之力，骨是外露之力**。选择学帖学欧防油滑、学颜防墨猪、学柳防柴——**三家的病恰好互相做解药**。
:::

::: example “永”字门诊：八法一屏检查 {#ex-yong}
学员写“永”字：点如米粒（无坠势）、横如桌面（纯水平）、竖如电线（僵直）、钩似鼠尾（提前踢）、长撇末端发白（虚尖）、捺像滑梯（一划而光）。逐笔给动作处方，不许用“多练”二字。
::: solution
**点**：病在**从纸面起笔**——处方：笔离纸一寸“扔”下去，让笔肚自己砸出侧锋三角（“坠石”是自由落体不是按压泵）；**横**：病在起手即平——处方：**先左顶半分再右行**，且整横取五度仰（检验：把纸转五度，这条横应变成“真水平”）；**竖**：病在匀速直拽——处方：入纸轻、中段行中带按、将尽**驻**（弓弩之“努”=绷，不是铁轨）；**钩**：病在行未至意先泄——处方：到地处**蹲**（笔锋上翘再弹踢，口诀“**作蹲必三**”：一蹲二转三踢）；**长撇**：病在速度递减——处方：**送尽**（笔尖离纸时还有三成力，掠发不断头）；**捺**：病在匀速滑行——处方：**三拍**（起—渐按—驻—趱出，嘴里数“一二三”，磔刀要顿一下才割断）。八笔连写的总节奏：**慢（取逆势）—快（中行）—驻（收势）**，整个“永”字是一组**呼吸循环**而不是八根线头。
:::
:::

::: intuition “横平竖直”是脚手架，不是建筑 {#int-hengping}
初学口诀“横平竖直”害了多少人：**它是给儿童的稳定器，不是给书家的终点**。看唐碑就会发现：**横不平（仰势取势）、竖不直（弓弩蓄力）、点不圆（侧面落地）**——所谓平直，是**视觉的平直**（力的平衡），不是**几何的平直**（尺子的平直）。这个区分适用于整个基础训练层：**所有“规范”都是视觉规范**——间架的“匀称”是重力的匀称，笔顺的“正确”是流畅的正确；把脚手架当建筑的人，写出来的字**齐而僵、正而卧**，正是老教师口中“美术字腔”的病根。教学上的正解：**先给尺子（描红规范），再藏尺子（读唐碑的险），最后扔尺子（书者的平衡自校准）**——**三步即从写字到书法的距离**。
:::

::: history 楷法千年：从新体到台阁 {#sec-qiannian}
**汉末**：楷名萌芽，**钟繇**（151—230）以行押入楷，被后世追尊“楷书之祖”；**魏晋**：二王今体——《**黄庭经》《乐毅论**》小楷范本确立“正书”美学标尺；**北朝**：碑刻坊手把楷书写出刀味——**《张猛龙碑》**等魏碑“斜画紧结”，为千年后碑学留下军火库；**隋**：南北混血，传说智永（王羲之七世孙）**书《真草千字文》八百部分施诸寺**（“退笔冢”“铁门限”同出这一传说系统——唐以后书史的话本层）；**初唐**：欧褚并立，**字样学**制度化（《干禄字书》）；**中晚唐**：颜柳尚法封顶（752《多宝塔》→841《玄秘塔》——**一个世纪的法定剂量**）；**宋**：尚意兴起，**楷书失去榜首**（苏轼“我书意造本无法”乃行草之论——楷法转入**刻书字体**：宋体字的远祖在刻工手里继续立法）；**元**：赵孟頫复古回到钟王，**小楷复兴**；**明**：**文征明**小楷与刻帖工业；**清**：**馆阁体**把楷法推成科举刑具（“**乌、方、光**”三字诀——黑大圆光的干禄标准；**傅山“宁拙毋巧”是反馆阁宣言**）；**1905** 科举废，馆阁解体；**1980 年代**：**硬笔热**与钢笔字帖接管识字书写，毛笔楷退入展厅与兴趣班——**楷书的“法定货币”地位改锚为“审美身份证**”。
:::

::: warning 楷学四坑
**“描红终身制”**（垫着描一年，离帖即瘫痪——**对临、背临才是进货，描红只是验钞**）；**“印刷体崇拜”**（把楷体字库当最高标准——**字库是字的尸体标本**：整齐来自间距机器，笔画全无来去；学楷学碑帖，**字库仅供查字法**）；**“一家定终身”**（入门三个月定欧，十年不换——**初学可专一家，进阶必须换防**：欧久了油？换颜；颜肥了猪？换柳——三家的病互为解药）；**“楷书=慢书”**（一路磨蹭叫**描**，不叫楷——**楷有楷的速度**：笔笔送尽、动作完整即可快，古谚“真书如站立”——站是蓄走之势）。
:::

写“永、之、以、九”四字（含侧勒努趯策掠啄磔主要成员），按八法逐笔自评（每条动作名＋完成度○△×），附一张“最差一笔”的改进前后对照。
::: solution
判分：动作名**全用八法术语**（写“那一捺”不给分，写“磔的三拍”给分）；自评敢打×（全卷皆○者退回重写——**自评过松与描红依赖同源**）；改进对照能看出**动作差异**而非“更用力”（用力不是动作学，蛮力不入处方）。
:::

::: exercise 三帖横评 {level=2}
收集欧《九成宫》、颜《多宝塔》、柳《玄秘塔》中同一字（如“之”“不”“大”——三帖皆有高频字）各三例，列表比对：横之仰角、竖之弓度、中宫松紧、钩之蹲势；写 150 字“三宪法比较摘要”。
::: solution
判分：表格四项齐全且有**测量语言**（“欧的横约五度、颜约平满”——**目测也算测量，只要带单位**）；摘要能下一句判词如“欧如立仗、颜如庙堂、柳如谏官**”）；加分：发现同一碑内不同页的风格漂移（**刻工与翻刻的指纹**——读帖读到文物层）。
:::

::: exercise 小论文：法与活 {level=3}
写六百至一千字：“一切标准都会馆阁化”——以唐代楷法、清代馆阁体、今天的作文模式或字库字体为例，论证**立法—僵化—反动—再立法**的节奏；并回答：一个正在学法的人，如何预支“破法”的疫苗而不堕入“无法”？
::: solution
判分点：节奏论证有**具体名件**（馆阁“乌方光”、傅山“宁拙毋巧”——反动宣言必附文本）；预支疫苗的方案可执行如**临习两家以上互相救偏、比对原碑与印刷本的差异、以“背临”测验法度是否长在自己身上**）；结论不骑墙（允许保守但要付出论证——**写出“不似之似”所付出的代价**）；空喊“创新”零分。
:::

::: summary
楷书法庭闭庭：名分（俗通正账本）、动作（八法=八次呼吸，平直是视觉不是尺子）、判例（欧颜柳互救，三家的病是对方的药）、刑期（一切标准皆会馆阁化——**反馆阁不是不立法，是让法保持体温**）。站着会呼吸了，下一章学走：行书与草书——“楷如立、行如走、草如奔”，以及被误解最深的“龙飞凤舞”。
:::
