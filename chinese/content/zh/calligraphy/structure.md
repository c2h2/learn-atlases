title: "间架结构"
---

同样八个笔画，摆法是字，乱摆是散沙——间架结构研究**零件在方格里的建筑学**。这一章先立三条物理，再逛古人的三十六条房规，最后治好四个常见病。

## 三条结构物理 {#sec-wuli}

::: definition 重心、主笔、布白 {#def-wuli}
**①重心**（方块字有一个看不见的**坠点**——结构的全部秘密是让笔画**围绕它而不压死它**：**重心稳而不居中才活**——颜体的“中”正而不呆、欧体的“中”险而不倒，同一个坠点，两种站姿）；**②主笔**（一字只许一次英雄：“大”的捺、“天”的下横、“十”的竖——**主笔舒展，余笔收敛**；主笔放两笔=两个人抢话筒）；**③布白**（结构的高级视角：**看的不是黑线，是白块**——“口”围出一口匀气，“川”把空当排成三间房；清人邓石如“**疏处可以走马，密处不使透肤，常计白以当黑，奇趣乃出**”（经包世臣《艺舟双楫》传录）——**布白是结构的音乐性**）。
:::

::: definition 三十六法与中宫 {#def-sanishi}
唐传欧阳询《**三十六法**》（实经宋人整理编次，托名祖师是古人行规）是第一部“结体法”汇编：**排叠**（“鑫”的三层楼阁）、**避就**（部件互相让位——你伸我一收，如“林”左捺变点）、**顶戴**（上重下轻要戴得稳）、**支撑**（“中”“十”一柱擎天）、**朝揖**（多体字互相见礼：“翼”的三部分拱手而立）、**包裹**（“国”“园”的外框不方不圆——**框是手势，不是火柴盒**）、**穿插**（“中”“申”竖笔贯通）……不必背全，**记它的分类学精神：结构问题先命名，后解决**——这套话术练的就是“看见为什么好看”。配套口诀：**字如人立**（独体要有站姿）、**四面停匀而中宫紧凑**（“**中宫**”=方格核心的收紧区——向心离心都要有圆心；黄庭坚长枪大戟而中宫极紧，是**收紧核心再甩四肢**的舞蹈演员）。
:::

::: example 四字门诊 {#ex-zhen}
硬笔病案：“想”写成分离的三层楼、“区”写成火柴盒、“森”写成三棵等大的树、“成”的斜钩软塌如面条。逐字开**结构处方**（只动间架，不动笔画质量）。
::: solution
**“想”**：相与心是**朝揖关系**——病在“相”过宽、心字底过远，三字变成搬家现场；处方：**相部横向压缩三成，心字底以卧钩托住“相”的右半重心**（上下结构的哲学：下部是底座不是备注）。“**区**”：外框是**手势**——上横略仰、左竖微弓、底横取斜势留出“气口”，框内“×”靠上靠右（包裹法的“内空不匀才活”）。“**森**”：排叠不是复印——**三棵松树要一将两卒**：上部“木”为主笔舒展的中军，左下缩肩、右下让脚（同形三叠，中主、左让、右收的“品字”原则，“晶”“鑫”皆然）。“**成**”：斜钩是**主笔兼承重墙**——起笔立定、行笔渐按带弧（弓而不塌）、出钩前顿足再踢；其余四笔全部**向斜钩聚拢**（中宫收紧，四肢才能放开——软的从来不是钩，是周围太散衬它孤）。判分标准：**每句处方必须落在“关系”上**（谁让谁、谁托谁、谁主谁次），说“多练”者以庸医论。
:::
:::

::: intuition 中宫：一个几何概念的政治学 {#int-zhonggong}
“中宫”本是天文星占术语（天王之座），借进书论后成了**结构政治学**：核心收紧=集权，四肢舒展=放权——**欧体中宫紧而险（险中求稳的能臣体）、颜体中宫宽而满（雍容自足的宰相体）、李邕行书斜中立（将军体）**——读帖读到此层，等于看穿了**字体的宪政**。反证在病案里：**四角撑满=无政府**（每个笔画各自为政，字成气球）；**中心堆死=过度集权**（四面无白，字成墨饼）。好的结构史就是**放权与收权的摆动史**：晋人尚韵（松弛的中宫）、唐人尚法（严格的中宫）、宋人尚意（中宫随缘）——下一课读风格史，先把这个圆心装进眼睛。
:::

::: history 结体学的千年账本 {#sec-zhangben}
**东汉**：蔡邕《笔论》“**为书之体，须入其形……纵横有可象者，方得谓之书**”（结构意识的第一次宣言：字要**有形象力**）；**晋**：传卫夫人《笔阵图》以战阵喻点画（“横如千里阵云”——**每个笔画一次战役部署**）；**唐**：欧阳询《三十六法》托名汇编、颜柳尚法把结体推到**法定剂量**（“颜柳”是结构法的两部药典）；**宋**：黄庭坚《论书》重“字中有笔”而中宫紧敛，**尚意不改几何**；**元**：李溥光（释溥光）《雪庵字要》等把结体口诀化、**市井化**（民间写字班的教材层）；**明**：《字汇》《六书精蕴》出版热，结构服务于**字体设计**（宋体字的骨架在此世纪定型）；**清**：邓石如“计白当黑”（布白理论封顶）+ 包世臣《艺舟双楫》传录——**白第一次入册为产权人**；**近代**二十世纪三十年代**“汉字改革”论战中结构之辩（拉丁派嫌它繁，守成派以**艺术**自卫——结构问题第一次政治化）；**当代**：字体工程时代——**你在屏幕上读的每个字都是被间架学设计过的**（方正、汉仪等字库以“中宫放松”“重心高低”做商品差异；故宫体、瘦金体字体之争＝结构审美的舆论战场）。
:::

::: warning 间架四迷思
一**“字无百日功”的误解**（肌肉记忆百日可成，**眼力无百日**——不练读帖的手只会复制错误，**临帖百遍不如读帖一遍再临一遍**）；二**格依赖症**（米字格离了就散——**格是外骨骼，中宫要长进本体**：撤格三步：临格—临界—悬空）；三**字体明星模仿秀**（直接学瘦金体、学启体——**风格是二阶产物，先立一阶结构**：瘦金的一切妙处建立在欧阳询的地基上，地基没打就装修，学成“火柴棒体”）；四**行楷结构混用**（把行的连写逻辑搬进楷书的部件与笔顺——楷有楷构、行有行法——**跨体借结构要先查该体的字法**，否则两边都不是）。
:::

::: exercise 读帖拆房 {level=1}
选欧《九成宫》颜《多宝塔》各四字（欧：“九、成、宫、泉”；颜：“大、千、宝、氏”），每字标注：重心高低、主笔是谁、中宫松紧、最大白块位置。
::: solution
判分：四字栏齐全且**欧颜对比成对**（同一“九”字：欧中宫上提险收、颜中宫宽博平实——标注须能让没帖的人**按图默写**出大致风格）；出现“都挺好看”零分——**本课只收结构学语言**：高低、松紧、收放、揖让。
:::
:::

::: exercise 一品字手术 {level=2}
“晶、鑫、森”任选两字：先按“三棵等大的树”写一遍（病案），再按“一将两卒”的品字原则重设计与调整（画出各部分的让位示意），附 100 字说明书。
::: solution
判分：让位关系明确（上者舒展、左者缩肩、右者让脚——或依字形变体，**能自圆其说即可**）；说明书用足三词：**排叠、避让、重心**；加分项：发现“鑫”与“森”的差别（金笔画少靠**形小让**，木笔画多靠**笔缩让**——同原则两种预算）。
:::
:::

::: exercise 小论文：结构的时代精神 {level=3}
写六百至一千字：“颜体是中唐的，瘦金体是北宋末的，馆阁体是明代的”——选择一体，论证其结构与**时代气质/制度**的关联（科举、金石学、宫廷趣味、印刷），并给这个论证方法设一条**防过度诠释**的护栏。
::: solution
判分点：关联论证具体（颜体之“宽厚”与盛中唐文化自信、人格崇拜的合流，且须提**宋人追认**（欧阳修尚颜）这一层——风格常被后世“再任命”）；制度面有证据（科举小楷→馆阁的“乌方光”）；护栏达标：**结构反映时代是修辞假说，不是因果定律**——举一个反例守住诚实（同一时代的多种书风并存）。
:::
