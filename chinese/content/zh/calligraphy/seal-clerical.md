---
title: "篆书与隶书"
---

写熟了今体（楷行草），该回头认祖了——今天字形的**全部零件**都埋在两层地质里：**篆**（线条的时代）与**隶**（笔画的时代）。中间那道断层叫**隶变**，汉字史上唯一一次结构性断裂——**认得它，你才算知道自己在写什么**。

## 地质层一：篆 {#sec-zhuan}

::: definition 大篆小篆与“婉而通” {#def-zhuan}
**篆**的家族：甲骨（契）、金文（铸）、**大篆**（籀文、石鼓文——秦系文字的敦厚样本），到**李斯小篆**完成第一次国家美学（后世形容其线“**画如铁石，字若飞动**”——语出唐人评李斯，玉箸、铁线皆其流裔：**等粗、等速、纯中锋**）。笔法总纲六个字：**“篆尚婉而通**”（孙过庭《书谱》）——**婉**（无棱角，转折暗过——圆是篆的呼吸）、**通**（气不断，一笔如引丝）；书写动作：垂直下笔、中锋匀速，藏头护尾——**几乎没有“动作”，只有“运动”**。为什么练篆？**篆是中锋的声乐基本功**：楷的行、草的使转里一切“线条质量”问题（扁、飘、薄）病根都在侧锋代步——**篆一年，等于给线条做一年核心训练**。
:::

## 地质层二：隶 {#sec-li}

::: definition 隶变：断开两周，接通今文 {#def-libian}
**隶变**：战国晚期至东汉四百年间，秦隶一步步把篆书**拉直、压扁、省并、分笔**——圆转改方折、连绵断成笔画、部件混同改形（“春、泰、秦”的上部自此各不相认）——**古文字（依形表意，看图可猜）从此变成今文字（记号拼写，不学不识）**。定性一句：**隶变是汉字史上唯一一次不可逆的断裂——之前是“看图说话”，之后是“按码认读”**。汉人自道其速：“**秦时官狱职务繁，初有隶书，以趣约易**”（许慎《说文解字叙》）；传秦**程邈**整理佐隶——与蒙恬造笔同案，**传说归功，整理属实**。《书谱》对句记笔法气质：**“篆尚婉而通，隶欲精而密”**——婉是呼吸，密是骨。
:::

::: definition 蚕头雁尾与一波三折 {#def-canrou}
隶书身份证三件：**①蚕头雁尾**（横画逆入圆钝如蚕头，收笔渐按后趱出挑脚如雁尾）；**②雁不双飞**（**一字之内雁尾只许一次**——主横之外一律敛脚，双尾则互相争空，字如打架）；**③横张势**（篆的方块压成扁方，挑脚左右分背——“**八分**”之名教学取“**体势如八字分散**”一说，其余诸说并存备注）。技术枢纽：**篆转隶折**——转折处提笔顿、换面再行；**方折如剪是隶的剪刀法**，婉转而过的“折钗股”留给篆。
:::

::: example 四字风格罗盘 {#ex-panpan}
汉隶四大名刻——《张迁碑》《曹全碑》《礼器碑》《史晨碑》——各以一个身体动作、一种乐器、一个季节作比，写成可执行的四张“临帖处方”（说明各适合治什么书写毛病）。
::: solution
**《张迁》**：站桩＋低音鼓＋深秋——方笔斩截、结体扁厚、拙中藏巧；**治油滑**（写过行书手痒者临百字即老实）；**《曹全》**：舞蹈＋长笛＋春水——秀逸流畅、雁尾舒展、匀净如写春联；**治呆板**（馆阁腔患者的解药，但贪其漂亮会得甜俗）；**《礼器》**：刀工＋古琴＋清霜——线细而劲、瘦硬通神、布白如计白当黑的范本；**治墨猪**（虚胖无骨者）；**《史晨》**：拱手＋埙＋平旦——中和醇正、法度井井，隶书里的“馆阁”正面样本（规矩不是罪，僵化才是）；**治狂放失形者**。罗盘用法：**先测病，再选碑**——四碑不是四道菜，是四味药；同一“于”字四写法各临十遍，指头会替眼睛记住区别。
:::
:::

::: intuition 篆是哑谜，隶是公文包 {#int-yama}
两种古体的**受众结构**决定它们的气质：篆的观众是**神与祖先**（卜问、铭功、勒石——所以慢、圆、对称、装饰性，线条本身是仪式）；隶的观众是**衙门与账本**（催办、抄录、碑告——所以快、方、省并、可读性优先，**形式是被公文量压出来的**）。这解释了两者的“手感分工”：**写篆要降心率**（匀速长线条，一喘气就露锋），**写隶要带节奏**（蚕头雁尾=一吸一呼的拍子，匀速反而死板）。练古篆隶的实用回报在现代写字台上很具体：**识读**（印章、牌匾大量用篆隶，读不出会尴尬）、**字源**（认得隶变就能解释“春”为什么是“三＋人＋日”，不再写错“泰”的中间）、**字体设计鉴赏**（宋体的横细竖粗是**隶变的印刷遗产**——你天天在用两千年前的设计）。
:::

::: history 两层地质的一兴一绝一复兴 {#sec-fuxing}
**秦**：李斯作小篆，泰山、琅琊**刻石**——国家美学第一次上石（原石不存，存宋拓与后世摹刻——**连“法典”都是抄本，字体史靠转写存活**）；**东汉**：隶碑大熟（熹平石经以隶书丹，蔡邕手稿与太学观摹）；**魏晋以还**：隶转为碑刻“登记用礼服”（墓碣首题多用隶，正文行楷——**礼服与常服的分工**）；**唐**：李阳冰铁线篆续秦汉绝响——**篆的孤本三百年**；**元明**：篆隶两衰，赵孟頫以篆额入碑而家法渐薄；**清**：碑学起，篆隶**招魂复生**——**邓石如（1743—1793）**以长锋羊毫写篆隶，——包世臣《艺舟双楫》传述品第，推为**千数百年未有**的完成人；**伊秉绶（1754—1815）**把隶书写成**建筑**（横平竖直如搭梁，汉隶的极简派）；**何绍基（1799—1873）**回腕高悬、**以篆籀行书入分隶**（一生作“寿”字千百，回腕一号）；**赵之谦**魏碑化篆隶，**吴昌硕**以《石鼓》为家底，**篆隶金石熔为一炉**——海派市场与展览机制第一次让篆隶成为展厅主角**；**二十世纪**：甲骨（1899 起）、敦煌汉简、居延简、马王堆帛书、郭店与上博简、清华简（2008 入藏）……**出土材料把“隶变”从结论变回过程**——**战国秦简上的“隶”一路写到东汉碑上的“隶”，中间环节不再是空白**；篆隶研究进入“拓本让位于文物”的世纪。
:::

::: warning 古体四坑
**任笔为篆**（不会《说文》就“凭感觉画篆”——**篆有师承字法**（《说文》9353 与部首系统，[[chinese-characters/six-categories]]），合文须有来历；**错字写进印章，盖出去就是赝品**）；**把“雁不双飞”当豁免**（“那我只写一个雁尾其他全躺平”——**主笔之外的横也要有俯仰**，只飞一雁不等于八只鸡）；**迷信名碑字帖翻印本**（碑本经**凿工、拓工、翻刻**三道手，宋拓与清拓判若两碑——**初学须选影印原大佳拓**，字口锯齿状多系翻刻之咎，非古人笔法）；**用今文字猜古文字**（古文字形近者极多（“戊己巳”“口凵”相乱是入门常识），**识字须查须记，猜必翻车**）。
:::

::: exercise 中锋长线条 {level=1}
小篆练习：画“之”字形长线条（玉箸篆基本功）四十字：要求线宽一致、转折暗过、行笔无抖动；自测“**呼吸法**”——写三笔一换气，还是憋气写完。
::: solution
判分：线宽波动超两成者**回炉慢速**（抖不是错，**变速才是抖的元凶**）；转折处出棱角者练“**暗过**”（转时笔杆微捻、笔尖不离原线）；呼吸记录诚实（憋气=心率升=手抖的因果链被自己抓到，抓到即教学目的达成）；加分：用硬笔同样画一遍——体会**中锋原理与工具无关**。
:::
:::

::: exercise 隶变观察员 {level=2}
选“春、秦、泰、年、奉”五字，从古文字编/字典中抄录各自篆形，再标出隶变后部件**混同或改形**的具体位置；写一则 120 字“事故报告”（哪一笔被拉直了、哪两块合并了）。
::: solution
判分：五字来源标注齐全（字形书/编号）；事故报告**定位到笔**（“艸部三笔并为一横加一撇”级别）；能解释为何隶变后“不学不识”（部件不再像画——**记号化**）；金句示例：**“春”不是三人日，是草芽、太阳与舂捣之杵在隶变后的遗容**。
:::
:::

::: exercise 小论文：谁杀死了一只野雁 {level=3}
写六百至一千字：以“隶变”为对象，论**书写效率如何改写文字系统**——要求含一条“反证护栏”（效率解释不了的例外，如八分对篆意的保留、隶书中的复古装饰笔），并类比一项当代字变（网络简化字、emoji、拼音缩略语任选）预测其“隶变度”。
::: solution
判分点：机制清楚（**隶变非一人一时**：日常快写→约定→官方确认三阶段，程邈式人物是“确认者”而非发明者）；护栏达标（能举**复古/礼制/装饰**对效率的抵抗——如《熹平石经》以隶之精整对抗俗写的放任）；类比有度（“yyds”是不是记号化？预测允许出错但须写**判据**——可读人群、构形是否理据化、有无字典收编）；结论若能落到“**今天的字法就是上一次隶变的账单**”，即 A。
:::
:::

::: summary
认祖课结账：篆（婉而通，中锋的声乐课，降心率的艺术）、隶变（公文压力下的断裂，看图→按码）、隶（蚕头雁尾、**雁不双飞**、八分横张，带节奏的艺术）、四碑（**是四味药不是四道菜**）、今用（印章牌匾与宋体里的两千年存款）。两层地质踩实了，下一章登高：把三千年的书体与书风装进一张年表——书法史的全景与断代口诀。
:::
