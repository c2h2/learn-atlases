---
title: "行书与草书"
---

楷书站定了，下一章教身体往前走。“**楷如立，行如走，草如奔**”——这三个动词出自书论旧说（《书谱》“**真以点画为形质，使转为情性；草以点画为情性，使转为形质**”，又云“**行近乎小真，所谓草不兼真，殆于专谨；草不通行，故非鸿伟**”——原文有出入，大意即“行真草”谱系）；本节把走路与奔跑拆成可学的动作，顺便洗一项千年冤案：“龙飞凤舞”。

## 走：行书 {#sec-xing}

::: definition 行书：楷草之间 {#def-xing}
行书生于**楷书的提速需求**：真书写的公文太慢，草书又太不顾及旁人——于是“真之小讹”的快写体成形为第二种日常字体（传后汉**刘德升**为行书之祖——**祖师是个传说级人物**，与蒙恬造笔同属追认史学）。两个分支：**行楷**（靠近真书：笔断意连，公文信件的安全速度——上一课连笔三法的地界）与**行草**（靠近草书：连笔成串，情绪与速度都高半格）。两件法帖定了行书的千古宪法：《**兰亭序**》——太宗遗事：酒醒后“**更书数百百本，终不能及**”（事见何延之《兰亭记》，唐人小说笔法，宋人已疑）——**不可超越的原因不是技巧退步，是那个晚上的微风、酒与好友无法回购**；《**怀仁集王圣教序**》——僧怀仁**积二十余年集王羲之行书字**摹刻上石（“集字”=把已故大师存世字迹逐字检出、拼成新文——**字库检索的唐代祖版**），此后千年，学行书者家传一本。
:::

## 奔：草书 {#sec-cao}

::: definition 章草、今草、狂草 {#def-cao}
**章草**（隶书的快写层：存雁尾、字字独立——传史游作《**急就章**》，识字课本出身；汉晋简牍上是它的日常相）→ **今草**（二王去雁尾、增使转，字头尾连成气——**草自此有“字”**：草符有师承系统，历代《草诀》与《草韵》把符号编成韵语传抄）→ **狂草**（张旭、怀素：一笔数字、行距互侵、满纸云烟——**从“读”转向“看”的临界实验**）。两条铁律：**草有草法，一字不可自造**——同一草符常对应多个今字形，识读须查《草书字典》，**私造草字等于私改密码本**；孙过庭狠话：“**真以点画为形质，使转为情性；草以点画为情性，使转为形质**”“**草不兼真，殆于专谨；真不通草，殊非翰札**”——**草书的放纵，是按汇率结算的**。
:::

::: example 请假条双联 {#ex-qingjia}
同一句话——“昨夜风雨大作，瓦落庭中，晨起扫叶，遂迟半日”——分别写成行楷（致教务）与狂草（寄书赠同好），逐件自评：对方读得出吗？读不出是谁的错？
::: solution
**行楷件**评分标准：连笔不超过字三成、牵丝细于笔画本体、每字重心独立站住——**收件人无需书法修养即可阅读**是硬指标（读不出=信使失职）；**狂草件**评分标准：**草法出处逐字可查**（《草书字典》抽检五字，私造一处即退回）、线条有**枯润节奏**（一墨到底如平路骑车，无减速也无冲刺）、行气贯而**字组有呼吸**（三字一组与独立字交替）。核心判分在**第二问**：狂草读不出**不是读者的错，也不是作者的错，是文体的契约**——狂草交付的是**笔迹的交响乐**，文本可读性只算伴奏（**但信件不是交响乐**：把狂草寄给教务处=用交响乐团按门铃）。加分反思：写草件前先自问——**这幅字写给谁看？字数几个？墙有多大？**
:::
:::

::: intuition 狂草：最讲法度的放纵 {#int-kuangcao}
“龙飞凤舞”在大众语里是**骂人话**（=乱写），在书论里却是**最高级的恭维**——前提是飞得有法、舞得有拍。狂草的纪律清单：**草法**（符号系统一字不可私造——**先当文字学家，再当酒神**）；**使转**（张旭“**听江声然后笔法始**”，又学**公孙大娘舞剑器**而“神气抖擻，草书入神”（杜甫《观公孙大娘弟子舞剑器行》序）——**线条是时间的舞蹈，不是空间的涂改**）；**章法**（满纸的**黑**要排队，**白**更要排队——字组、行气、疏密如交响乐的声部进入表）；**收放**（狂而不嚎：**一处爆点，通篇压阵**——怀素《自叙》狂到极处仍有小楷落款，酒神背后站着会计）。教学寓意：**放纵是能力的最高税阶，不是放弃缴税**——“我写字随意但好看”者，请先交草法税单。
:::

::: history 快写小史：从案牍到展厅 {#sec-kaixie}
**秦汉**：汉人旧说“秦时官狱职务繁，初有隶书以趣约易”（《说文解字叙》所记）——**快写是行政的排泄物**：正体应付朝会，草率才吃得完积压；**汉**：史游《急就章》授童子，章草成**第一部识字课本级的草书**；**东汉**：草书社会热，**赵壹《非草书》**痛批时人“师尚杜、崔”，练到“夕惕不息”式入魔，赵壹斥其“临事无意”（原文大意）——**史上第一场“实用派 vs 表现派”的庭审记录**；**魏晋**：二王今草定型；**唐**：张旭以醉登记进书法史（杜甫《饮中八仙歌》“**张旭三杯草圣传，脱帽露顶王公前，挥毫落纸如云烟**”），怀素《**自叙**》集颜真卿、戴叔伦辈同时评语——**狂草获得第一本当代五星合集**；**宋**：米芾“**臣书刷字**”（《书史》）——**速度第一次自报家门**；**晚明**：徐渭、张瑞图——狂草成**乱世的心理小说**，涨墨与绞锋是时代的脑电波；**清**：傅山“**宁拙毋巧，宁丑毋媚，宁支离毋轻滑，宁直率毋安排**”（《作字示儿侄》）——**为一切丑态前卫预发执照**；**现代**：钢笔与键盘先后接管快写，**狂草彻底退居展厅**——“快”的实用岗消失了，只剩下**快的美学**。
:::

::: warning 行草四雷
**“龙飞凤舞”当褒义用**（外行夸人语，内行听作“无政府”——**夸人字好看，请指到具体处**：“这行枯笔痛快”胜过“有气势”一万倍）；**楷不成而谋草**（“我楷书太板，不如练草”**逃跑式换体**——板是手的肌肉没学会调锋，草只会把它放大成抖；说白版判词：**楷不成人，草必滑****）；**一笔拉长充“一笔书”**（真正的连绵靠**使转**不靠**拖**——线条中段疲软者，长只暴露长）；**签名当草书毕业**（签名是**个人商标**不是**公共文本**——商标合法，草书看账）。
:::

::: exercise 草法五十问 {level=1}
查《草书字典》，为“天地玄黄、宇宙洪荒”前十字各找**一个**今草形，抄录并标注符号来源；然后默写十字，自检：与字典符合度几成？
::: solution
判分：十字全有出处（页码/帖名即“税单”）；凡自创形打回（“差不多”即差很多——草符认差）；默写符合度八成以下者，**下周量减半、遍数加倍**——快写的地基是死记。
:::
:::

::: exercise 一语三写 {level=2}
“学然后知不足”分别写：楷书（送展览）、行楷（写黑板）、行草（赠好友），附 120 字“速度—正式度”换算说明书（每处连笔与简省，注明为何在该档位被允许）。
::: solution
判分：三件**档位差可被外人排序**（不说明也能分出正式度高矮）；说明书每处连笔有理由（“行草件此二字牵丝，因笔顺同路”=合格；“感觉顺”=半合格，追问笔顺）；出现“草书=乱写”**观念**零容忍——观念错比笔画错扣得狠。
:::
:::

::: exercise 小论文：快的伦理 {level=3}
写六百至一千字：从“赵壹《非草书》的愤怒”到当代“电子签名与手写签名之争”任选一端，论“书写速度提升带来的**可读性税**由谁缴纳”；须用本课“契约”框架（不同文体=不同税率的合同）。
::: solution
判分点：史实与论证分工清楚（赵壹是**证据**不是**论点**；须处理“实用派对表现派”的结构而非站队）；契约框架用得准确（公文、私信、展品、商标四种文体的“可读性税率”排序及理由）；若写当代，须区分**效率争议**与**审美争议**（狂草退展与医生字丑**不同一议题**——混谈者扣逻辑分）。
:::

::: summary
速度课结账：行（两分支、宪法两帖、兰亭不可回购）、草（三段位、草法税单、孙过庭汇率）、狂（三条纪律、一处爆点通篇压阵）、雷（不逃楷、不拖线、不拿签名当毕业）。腿会走了，下一章回头认祖：篆与隶——**今天字形的地质层**，以及“隶变”这场静悄悄的革命。
:::
