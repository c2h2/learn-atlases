---
title: "特殊句式"
---

“把、被、存现、连动、兼语”——教学语法的五大名捕：个个日常，个个对外国人高危。本课一间间开博物馆展柜：每件句式挂三块牌——**形式条件、语义底色、历史出身**。

## 把字句：处置式的现代招牌 {#sec-ba}

::: definition 把字句三件套 {#def-ba}
格式：**主语＋把＋宾语＋动词＋后续成分**。三道门卡：①谓语不能是光杆动词（*我把书看 → 我把书看了／看完了／看了一遍——带上后续成分才站稳）；②“把”的宾语**有定**（我把那本书看完了 / *我把一本书看完了）；③动词须带处置力（*他把孩子很听话×；不情愿、认得类心理动词出局）。否定与能愿动词站“把”前：我没把作业做完／他应该把真相说出来。语义底色=**处置**（动作施加于对象并使其受影响），所以“把”字句天然是结果补语的黄金搭档（把窗子打开／把敌人打得落花流水）。出身：“把”本义“持、拿”（杜甫“醉把茱萸仔细看”仍是手里拿），唐代虚化为工具/对象介词，处置式至宋元白话大盛——**把字句是一部握在手里的语法化史**。
:::

::: example 把字句门诊 {#ex-ba2}
判合法性并说明各卡在哪道门：①我把他认出来了。②我把眼泪流了下来。③他把球踢进了球门。④他把戏演得很精彩。
::: solution
①边缘合法：“认出”处置义弱，靠“出来”补足结果才立住——把字句对动词的“作为感”要求在此最严；②不合法：流泪是自动事件，眼泪未受处置——**“把”的宾语必须是受影响者**；③合范：踢进=动作＋结果，宾语有定；④合法（“演得很精彩”补足谓语）——但“把戏”连读撞车名词“把戏”，听感歧义。四案各中即满分。
:::
:::

## 被字句、存现句、连动与兼语 {#sec-bei}

::: definition 被字句与它的同门 {#def-bei}
格式：**受事＋被（＋施事）＋动词＋后续成分**（他被我批评了一顿；*他被我打）。三门：谓语同样拒光杆；施事可省（信被撕了）；“被”的古典底色是**不如意**（《史记》“韩信被诛”式的被动祸事），现代已通吃中性与褒义，但口语的“让/叫/给”仍偏消极（钱包让小偷摸走了）。同门异形：**“见”“于”为文言被动**（见笑于人、吾常见笑于大方之家）；“被＋动词”凝固成词（被迫、被动、被告——词汇化的化石层）；网络时代反弹出**“被××”强制式**（被就业、被增长：X 常为不及物，“被”重新领有“非自愿”古义，一个句式养活半部舆情史）。
:::

::: definition 存现句·连动句·兼语句 {#def-cunxian}
**存现句**：处所＋动词＋存现物——“门口有棵树｜台上坐着主席团｜昨天村里死了一头牛”。三格式（有/V 着/V 了）共享“布景→出现主体”的信息流（信息结构“旧景新物”的教科书样本）。**连动句**：一主多动、无连接、有时序或目的（他拿钥匙开门走了；我去商店买瓶水；他骑自行车上班）——动词间可加“就/再/着”测试层次。**兼语句**：V1 的宾语兼任 V2 的主语（我请他来｜老师批评他迟到｜妈妈让我穿秋裤——V1 限于**使令/称呼/推选**家族：请叫让派逼命选称）。**区分兼语与主谓短语做宾**：“我知道他来”——“他”不是“知道”的受事，无兼语（简易测试：**V1 无使令义即非兼语**——“知道、觉得、看见”类后接的是主谓短语做宾语）；兼语可被字化（他被我请来了✓），知识类不行（*他是被我知道的来——不通）。
:::

::: example 四式串演 {#ex-chuanyan}
用同一批演员（经理/客户/合同）各造一句：把、被、连动、兼语；再用一句话说明四式的信息焦点各落在哪。
::: solution
经理把合同签了（焦点：合同的处理结果）；合同被客户退回来了（焦点：合同的遭遇）；经理拿着合同去找客户（焦点：连串动作的行程）；经理请客户确认合同（焦点：使令与其目的）。四式=同一世界的四种打光方式：**把照明受事、被照明遭遇、连动排成时间轴、兼语搭桥两个动作**——句式不是同义改写，是镜头语言。
:::
:::

::: history 句式的年轮 {#sec-nianlun}
被字句的“被”本义“覆盖、施加”（“被之衣服”之“被”），引申出“遭受”，秦汉已见“诛—被诛”式；存现句的上古祖先在《诗经》“山有榛，隰有苓”；连动与兼语是汉语**无连词传统**的两翼（英语须 then/to 挂靠，汉语直接并排小句——意合性格的句法证据，复句章续论）；把字句晚出而强势，宋元白话里已是叙事主力（《朱子语类》把字句成群）。**每个特殊句式都是一条语法化铁路的终点站**——特殊，只因我们忘了它曾是一次搬家。
:::

::: warning 句式使用四防
一防**把/被乱换**：“我把他没办法”合法、“我把办法没办法”? ——把字句动词须可处置，“没办法”惯用语整体不可拆；“被他看见了”合法，但“*这被大家知道”（知晓类无处置）别扭；二防**存现句主语执念**：非要给“台上坐着主席团”找出施事主语，是把话题语言硬拗成主语语言；三防**兼语连动混诊**：“让他进去”（兼语）与“拿了票进去”（连动）差一个**使令桥**；四防**被字句褒义洁癖**：“他被选为代表”合法通行，网络“被××”则是能产新构式——语言的规矩比校规多，也比校规新。
:::

::: exercise 句式改写实验室 {level=1}
“风把屋顶掀了”改写为主动句、被字句、存现句三式；说明每式焦点与语体移位。
::: solution
主动：风掀了屋顶（中性叙事）；被字：屋顶被风掀了（受事主题+遭遇视角，报道体）；存现：昨夜村东头掀了一片屋顶／屋顶上如今又盖了新瓦（存现式偏重事件呈现，可省施事——灾难叙事常用）。三式+焦点+语体各到位即满分。
:::
:::

::: exercise 兼语连动双探 {level=2}
分辨：“他推着车卖菜｜他推着车进了院｜老师让他重复一遍｜我有个朋友在外地”。各给一句测试依据。
::: solution
推+卖：同时进行的连动（方式+目的，可插“着/就”）；推车+进院：时序连动（先后可验）；让：兼语（使令桥✓，可被字化“他被老师叫去重复一遍”）；“有个朋友”：连动套兼语式存现（“有”带兼语“朋友”+小句——兼语式的存在变体，能拆“有一个朋友，他在外地”即现形）。四判有据即满分。
:::
:::

::: exercise 小论文：句式的社会生活 {level=3}
写八百至一千二百字：收集近三年媒体/朋友圈里五个“被××”实例，分析其论元特征（及物性？褒贬？机构责任者隐去？），并比较“把权力关进制度的笼子”里“把”字的政治修辞能量；结论回答：为什么汉语的“特殊句式”其实是公共话语的常规武器？要求实例可检、标注日期来源。
::: solution
判分点：五例真实+论元分析（不及物/施事隐去/非自愿义三特征各有分布）；“把”字政治修辞（处置感的能动性：制度为主体、权力为受事——把字句的“处置”底色在公共文本的活用）；结论落到句式=立场资源的层面；语料日期可核。
:::
:::

::: summary
五大名捕各带底色：把字句讲处置（宾语要定、谓语要“有事”）、被字句讲遭遇（古恨今用、网络回潮）、存现句先布景再上演员、连动句并排时间、兼语句一宾两职。全是语法化铁路的终点站，“特殊”只因忘了曾经搬家。句式不是同义改写器，是镜头与立场——把照明受事、被照明遭遇、存现给景、连动给序、兼语给关系。下一课收官：复句——当句子开始自己组织交通。
:::
