词怎么搭成积木墙？这一课给两样工具：**五种结构关系**（短语的五行元素表）与**层次分析法**（把线性句子的立体骨架一层层剥出来）。工具在手，歧义从玄学变成几何。

## 五种结构关系 {#sec-wuzhong}

::: definition 短语五官系 {#def-wuxing}
按成分间关系分五型：**主谓**（他来了｜心思｜细腻）、**动宾**（看书｜打篮球）、**偏正**（状中：仔细看｜定中：新书）、**动补/述补**（看完、跑得快、洗干净）、**联合**（调查研究、京津、伟大而平凡）。前三型“有头”——功能等于核心那一项（向心结构：定中=名词性、状中=动词性、述宾=动词性）；联合最民主（整体功能=成员功能）；补语是汉语特色——**结果/程度/趋向/可能/数量**五补系统（打完·好得很·站起来·打得完·看一眼），英语只能用小句表达的意思，汉语用一个补语收编。
:::

::: example 层次分析示范：咬死了猎人的狗 {#ex-gou}
切分并解释两读。
::: solution
读 A（狗干的）：[咬死了猎人的]狗——定中结构，定语内部是述宾[咬死了[猎人]]；读 B（命案现场）：[咬死了[猎人的狗]]——述宾结构，宾语=猎人的狗。**同一串词、两种层级**——层次分析法把“谁的锅”画在树上：修饰关系挂哪一层，语义就归谁。考试口诀：**先找中心语，中心语一换，树就分家**。
:::
:::

::: definition 层次分析法三条铁律 {#def-tier}
①**二分**为主（一次切两半，联合可多分）；②**每个片段有意义且结构成立**（切出的两块自身须是合法的语法单位）；③**切分不改类**（切后各块仍按原类组合，虚词附着头字走）。流程：**大到小、先骨干后枝叶**——主谓/动宾先分家，再剥状语定语，最后到词。它是美国结构主义“直接成分分析”（IC）的汉用版，教学语法三十年国骂之源，也是人类第一次让小学生**看见**句子的骨骼。
:::

::: intuition 向心与离心：火车头原理
偏正、动宾、主谓都是“向心”的——整列火车有一个头（中心语），功能跟着头走（红苹果还是名词性）。但汉语有两列“离心火车”让结构主义头疼一辈子：**“我的书”整体是名词，“的”字短语“卖的”也是名词，可“书”与“的”谁都不是头**；**“看书”是动词性，“书”却是名词**。Bloomfield 当年被“the ten o'clock train”难住，汉语版本遍地都是。解法两派：要么承认“的”是变格词缀（形式派），要么放弃“功能=中心语之和”的等式（功能派）。课堂立场：**五官系是教学地图，不是本体论判决书**——地图好用，别把它当成国土本身。
:::

::: history 从剥洋葱到树：分析工具的引进与国产化 {#sec-gongju}
直接成分分析（IC）出自美国结构主义（哈里斯、布龙菲尔德 1930—50 年代），核心理念只有一句：**语言单位成层构造，意义在层级里分配**。1950 年代随“方法热”进入汉语语法界，与苏联语法学一道塑造了中国教学句法；1979 年吕叔湘《关于汉语词法的一些问题》诸文把“词法句法接口”的汉语疑难摊开在桌面上；黄廖本把层次分析定成中文系基本功，从此“二分到词”成为几代人的语法初夜。八十年代后生成语法的**树形图**（标志图）登陆，二分升级为“阶状投射”，层次法的孙子们已能画移动与空语类——但本课仍从洋葱剥起：**所有树都长在会剥洋葱的手上**。
:::

::: warning 切分三防
一防**多切/少切**：“看了三天”切“看了/三天”还是“看/了三天”，以虚词附着律裁决（“了”紧贴动词走，切在“看了”后）；一刀未经测试即落刀是通病。二防**把联合当偏正**：“新材料”能不能插“和”？“新和材料”不成话，即偏正——**插入测试**（和/的/地）是鉴别液。三防**切到语义为止**：层次分析只裁结构不裁真假，“无色的绿色思想”树完全合法，荒谬在词典不在句法（乔姆斯基名句的汉语分身）。
:::

::: quiz
“洗干净”的结构类型是（　）。
- [ ] 动宾
- [x] 述补
- [ ] 偏正
- [ ] 联合
::: solution
“干净”补充说明“洗”的结果——结果补语；可扩为可能式“洗得干净/洗不干净”是补语家族的身份证。

::: quiz
“卖菜的”整体功能是名词性，但找不到名词中心语——这暴露的是（　）。
- [ ] 层次分析无效
- [x] 向心/离心之争：功能未必等于中心语之和
- [ ] “的”是动词
- [ ] 该结构不合语法
::: solution
“的”字短语是经典离心结构——教学地图与本体论的落差正在于此。

::: quiz
层次分析法切分“看了三天”时，正确首选是（　）。
- [ ] 看了／三天（动宾）
- [x] 看了／三天（述补）——“三天”补充时量
- [ ] 看／了三天（定中）
- [ ] 不可切
::: solution
时量“三天”补充动作时长，属时量补语——述补框架；动宾分析无法解释“看三天”与“看三天书”的嵌套差。
:::

::: exercise 洋葱实操 {level=1}
对“他认真地看完了那本旧书”做二分到底的层次分析，标出五型关系。
::: solution
他‖认真地看完了那本旧书（主谓）→ 认真地/看完了那本旧书（状中）→ 看完了/那本旧书（述宾）→ 看/完（述补）＋ 那本/旧书（定中）→ 那本…量名、旧/书形名。五型齐、二分无违例即满分。
:::
:::

::: exercise 歧义双树 {level=2}
为“开刀的医生”与“学习文件很重要”各画两棵树，说明每树的语义解读。
::: solution
“学习文件很重要”：A 树 [[学习文件]很重要]——主谓结构，主语“学习文件”内部述宾（“研习文件这件事很重要”）；B 树 [学习[文件很重要]]——述宾，动词“学习”带小句宾语（“课文告诉我们：文件很重要”）。“开刀的医生”：A=[开刀的]医生（定中：给病人开刀的医生）；B=开[刀的医生]？不成立——该串唯一合法树为定中；换成“缝裤子的”类离心结构可见“的”字短语独立成格。能自造一个真正双树例并画对者加分。
:::
:::

::: exercise 小论文：句法有没有颜色 {level=3}
写八百至一千二百字：“无色的绿色思想在愤怒地睡觉”句法完美、语义荒诞——这说明句法是一个**自主的模块**吗？结合本课（树不查字典）与词汇语义（“绿色”与“思想”的义征冲突）写一场模拟法庭：控方（句法自治）与辩方（句法-语义连续体）各陈词三百字，你做陪审并给出裁决理由。要求引用“向心/离心之争”作为“规则也有例外开口”的先例。
::: solution
判分点：控方论点（层级结构可脱离真值检验；病句≠不合语法）；辩方论点（选限、框架语义、构式对词类的挑选——句法并非全自治）；裁决不要求和稀泥，要给出**分层标准**（结构合格性测试是什么、语义合格性测试是什么）；引用离心结构作为“规则开口”先例使用得当。
:::
:::

::: summary
短语五官系（主谓、动宾、偏正、述补、联合）给组合定性，层次分析法给线性串定形：二分、验证、不改类三律之下，“咬死了猎人的狗”从一句话变成两棵树。向心/离心之争提醒我们地图与国土之别；乔姆斯基的荒谬诗则划界：树不查字典。下一课把这副骨架按到句子上——七种句子成分登场，长句从此可以拆着读。
:::
