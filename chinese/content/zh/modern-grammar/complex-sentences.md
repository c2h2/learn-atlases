---
title: "复句"
---

单句是独栋，复句是小区：物业合同（关联词）有的写死、有的全靠邻里默契。本课三件事：划清单复句的界（一条著名的渐变带）、认十一类关系、学会给二重复句“断楼层”。

## 单复句之界 {#sec-jie}

::: definition 界限与三测试 {#def-jie}
原则：**包含两个或两个以上主谓结构、互不作句法成分**的是一句话里的复句；反之仍为单句。三测试：①**成分测试**——“我知道他会来”里“他会来”整体做“知道”的宾语=单句；②**共享测试**——“他拿了票进场坐下”共享主语、动作连发=连动单句（一“套”动作，非多句）；③**关联词归属**——关联词能插入且分句可独立成感的，多半复句（“他不但来了，还迟到了”）。诚实声明：**汉语单复句边界是渐变带**——连动、兼语、主谓做宾、流水小句把中间地带排成光谱；教学语法按“结构+意义”双条件划线，是可用不等于完美的妥协。
:::

::: definition 十一类关系两大家 {#def-shiyi}
**联合复句**（分句平等）：并列（既…又…/一边…一边…）、连贯（先…然后…/……接着…）、递进（不但…而且…）、解证（也就是说）；**偏正复句**（一主一偏）：因果（因为…所以/既然…就）、转折（虽然…但是/然而）、假设（如果…就/要是…的话）、条件（只要…就/只有…才/无论…都）、让步（即使…也）、目的（以便/免得）。连词可以**全缺席**：“下雨了，不去了。”——意合复句，汉语的默认模式；关联词是显化零件，装与不装、装哪对，都是语义与语体的决定。
:::

::: example 二重复句断楼层 {#ex-erchong}
“虽然天气很冷，但是大家干得热火朝天，因为任务明天必须完成。”——断出两层关系。
::: solution
第一刀切在**转折**：“天气冷”与后面全句为转折关系（虽然｜但是+因为）；第二刀在“但是”内部切**因果**（干得热火朝天‖因为任务明天必须完成）。画法：先找**管得最宽的关联词对**（“虽然…但是…”横跨全句=第一层），残余内部再找第二层。**楼层判据**：拆除试验——拆去“因为…”句，全句转折仍完整；拆去“虽然…”，因果段独立但语气悬空——层级高下立判。
:::
:::

::: intuition 流水句：汉语的小句高速公路
“武松把门只一推，天天地下望时，静嘻嘻的没有一个人坐。”（《水浒传》旧白话）——小句一个接一个，不靠连词靠时间顺序与话题一贯，这就是**流水句**：无主从标记、关系靠语序与语境自组装。它是口语与古典白话的常态，也是复句理论的难题（分析家们从朱德熙到当代生成派都在给流水句装“隐形结构”）。教学立场：**流水句是复句的零标记形态**，读它靠汉语语感，写它靠标点的分寸——逗号是流水的水位线，句号才是堤坝。
:::

::: history 意合与形合：一场类型学命名 {#sec-yihe}
“东方语言意合（parataxis），西方语言形合（hypotaxis）”的说法是二十世纪类型语言学的通行对子——现代汉语学界自吕叔湘《汉语语法分析问题》起反复申说：汉语小句连接靠语义与语序，关联词是“可选显化”；英语反之，从属于句法强制。这一对概念把“为什么中国人写作文爱用逗号一逗到底、英国老师判 run-on sentence”讲成了**类型学宿命而非个人马虎**——写作的语篇训练（衔接与连贯）由此接棒语法（详见[[rhetoric]]与写作课群）。
:::

::: warning 关联词四病
一**配对错乱**：“由于…因此…”混套（由于…所以／因为…因此各归各号，语体还不同）；二**位置违规**：关联词跟着主语走有规矩——**两分句同主语，关联词在主语后**（他不但学习好，体育也好）；**主语不同，关联词在主语前**（正例：不但他不肯来，他父亲也不肯来——“不但”领起第一个主语）；三**多余**：“之所以…的原因是因为…”三头因果怪；四**逻辑违约**：“因为…所以…”硬接无因果的两事（因为今天星期三，所以天气好——形式关联、语义破产，病句章同案并办）。
:::

- [ ] 连动句
::: solution
“他会来”整体做“知道”的宾语，成分共享即单句——成分测试是单复句第一关。

- [ ] 并列
- [ ] 转折

::: solution

::: exercise 单复分拣 {level=1}
判单/复并给依据：①他低着头走过去。②他低着头，走了过去。③组织讨论并通过名单。④群众讨论了，也通过了这个方案。
::: solution
①连动单句（共享主语、动作成套）；②逗号一分为二，多数口径判**连贯复句**（小句间不作成分；也允许“同主语句中之逗”判单句——注明分歧给分）；③联合短语做谓语的单句（无停顿、共宾语）；④复句（并列，共享宾语“方案”后置=蒙下省略的并列小句）。四判有据即满分。
:::
:::

::: exercise 楼层测绘 {level=2}
给三层复句断层并标注关系：“如果下雨，运动会就改期或者取消，因为会期已定，不能轻易改动。”
::: solution
第一层**因果**（前面两个小句‖因为…不能轻易改动——“因为”管到句末）；第二层在“如果”段内部：**假设**（如果下雨‖就改期或取消）；第三层“改期或者取消”：**选择**（联合短语内部，已降至短语层——是否计为第三层依口径，短语层/小句层分清即可）。断层+关系全对即满分。
:::
:::

::: exercise 病文医生 {level=2}
修改并归类病因：①他不但成绩好，而且也很努力。②尽管天气不好，可是仍然出发。③我所以喜欢《水浒》，是因为人物写得鲜明的原因。
::: solution
①“而且”后“也”与递进框冗余（删“也”），且两轴宜同级别：“成绩好”与“很努力”一果一因，递进牵强——改为“他不但成绩好，而且很用功”（同主语，“不但”在主语后）；②后分句缺主语（尽管天气不好，可是我们仍然出发）——主语不同而蒙上省略不合法；③“之所以…是因为…的原因”三头因果怪，删“的原因”。三病各位：关联冗余、主语脱漏、格式杂糅。全对即满分。
:::
:::

::: exercise 小论文：一逗到底的国民病 {level=3}
写八百至一千二百字：以一段真实网文/学生作文（不少于 60 字、注明出处/自撰）为样本，统计其逗号数与句读问题，用本课理论解释“一逗到底”的成因（流水句传统×标点教学缺位×欧化长句的三重奏），并给出一份“断句规范建议”（面向公众号或公文各三条）。
::: solution
判分点：样本真实+逗号密度统计；成因三声部各有交代（意合传统给土壤、无分号/句号训练、翻译体连锁句）；建议可操作（如：主语更换即考虑断句；“的/了”后长链超 40 字强制检查；分号用于并列大句）；不犯“汉语不讲句法所以可以乱断”的相对主义错。
:::
:::

::: summary
单复句之间是一条光谱（成分测试、共享测试、关联词归属三把游标卡尺）；十一类关系归两大家族（联合与偏正），关联词是可装可卸的显化零件——汉语的默认是意合，流水句则是零标记的高速公路。断楼层口诀：最大跨度先行，剩余递归。关联词四病（错配、错位、多余、逻辑违约）与“一逗到底”都是本课的门诊常客。复句之下是成分，复句之上是篇章——下一课也是本课收官：病句诊室，把你学过的每一件工具都开一遍诊。
:::
