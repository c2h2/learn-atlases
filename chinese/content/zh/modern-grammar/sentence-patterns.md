title: "句型与句类"
---

同一堆词，换个“语气包装”就是另一句话；同一套骨架，缺主少谓照样交际。本课两张分类网：**按结构分句型**（主谓句与非主谓句），**按语气分句类**（陈述、疑问、祈使、感叹）——两网交叉，任何句子都有坐标。

## 句型：按结构编队 {#sec-juxing}

::: definition 主谓句与非主谓句 {#def-feizhuer}
**主谓句**：主语谓语齐备（她笑了／今天冷得很）。按谓语核心再分四队：**动词谓语句**（他看书）、**形容词谓语句**（花很美｜他大我三岁）、**名词谓语句**（今天星期三；你好热情！——判断词“是”缺席也能谓语，靠语境与语气）、**主谓谓语句**（他|身体很好｜这事|我心里有数——大主语+小主谓做谓语，汉语的招牌句型，话题结构的最纯样本）。**非主谓句**：天生无需主谓齐（下雨了！／禁止吸烟／哎呀！／火车！）——注意与**省略句**的区别：省略靠上下文可还原（“你去吗？”“去。”），非主谓句**根本无须还原**（* 天下雨了的“天”补不出来）；两者试卷上年年混，学界也年年吵，教学口径按“能否明确还原”划线。
:::

::: example 主谓谓语句的识别 {#ex-zhuwei}
分辨：①他身体很好。②他的身体很好。③身体很好。——哪个是主谓谓语句？切分给谁？
::: solution
①主谓谓语句：大主语“他”＋谓语“身体很好”（小主谓做谓语）；②普通形容词谓语句（主语=“他的身体”偏正短语）；③非主谓句（形容词性非主谓）。测试：**能否插入“是”或话题停顿**（他呀，身体很好✓——大主语是话题，可提可顿，这是主谓谓语句与偏正主语句的分水岭）；再测领属还原：“他的身体很好”≡①只在多数场合等价，对比语境中①的“他”是**关涉对象而非领有者**（“他书读得多”≠他拥有全部书）。
:::
:::

## 句类：按语气包装 {#sec-julei}

::: definition 四大句类与疑问系统 {#def-si}
**陈述句**（默认包装）、**疑问句**、**祈使句**（禁止吸烟／你走吧／千万别说）、**感叹句**（多么美啊／好大的雾）。疑问句四式各有专用装备：**是非问**（+吗/语调↑：你去吗？）、**特指问**（疑问代词留守原位：谁去？你买了什么？——汉语不搬疑问词，与英语 wh-fronting 分手处）、**正反问**（去不去／好不好／是不是——汉语特产，V-not-V 的复制术）、**选择问**（还是你走，还是我走？）。语气是**句子的时态之外另一层强制包装**：同一命题“你走”，四包装皆合法（你走了。你走吗？你走！你走啊！？——四句情绪任务全不同）——语义学说命题，语法学说包装线。
:::

::: history 汉语语法学界的两只拦路虎 {#sec-hulu}
“主谓谓语句”自丁声树等《现代汉语语法讲话》（1961）系统论证后成为教学标准件：它救活了“他身体很好”类无数句子，也宣告“主语=施事”教义的破产；“非主谓句”之名经三五年代大讨论（谁承认“静夜”式独词成句）定型，背后是“句子=交际单位”对“句子=主谓逻辑”的胜利。黎锦熙早年“句句有主谓”的强拆方案（找不到主语就“省略”）已被扫进语法学博物馆——**承认汉语可以不用主语说话，是汉语语法学断奶成人的一刻**。
:::

::: warning 句型句类四误
一误**“名词谓语句=省略‘是’”**：“今天星期三”是合法句型不是残句——判定看语言共同体的语感（“今天*是星期三”在多数场合反而生硬）；二误**反问当疑问**：“谁知道啊！”（=谁都不知道）形式带疑、功能表态——句类按**行事功能**判不按问号判；三误**独词句=句子词**：“火灾！”是感叹包装的非主谓句，与词“火灾”同形异职；四误**把“主谓齐全”当汉语常格**：对话、标题、标语、口语里非主谓句占半壁江山——“主谓齐”是书面欧化腔的错觉（与[[rhetoric]]的句风章接上）。
:::

::: quiz
“他一个人走了。”“一个人走了。”后者（　）。
- [ ] 省略句（承前省主语）
- [x] 非主谓句或省略句须看语境：可明确还原者为省略句
- [ ] 主谓谓语句
- [ ] 病句
::: solution
教学划线：**能否明确还原**。独白新信息场景=非主谓句；对话承接上句=省略句——同一表层，两种户口。
:::
:::

::: quiz
“是不是他来？”是（　）。
- [x] 正反问（“是不是”整体做谓语框架）
- [ ] 是非问
- [ ] 选择问
- [ ] 特指问
::: solution
V-not-V 复制式正反问；“是…还是…”才是选择问——装备不同，勿混。
:::
:::

::: quiz
“王冕死了父亲”在教学语法里判为（　）。
- [ ] 病句（王冕没死）
- [x] 主语施领错位但合法的特殊主谓句
- [ ] 非主谓句
- [ ] 存现句不存在
::: solution
领属失去事件（“死”类动词允许领有者做话题主语）——句型合法、语义特殊，正是主谓句“话题优先”家风的展示窗。
:::

::: exercise 双网定位 {level=1}
为下列句子各给句型+句类双坐标：①明天刮台风。②严禁烟火！③你怎么才来呀？④好香的咖啡！
::: solution
①主谓句·动词谓语句（“明天”时间名词主语＋“刮台风”）＋陈述句（也可析为存现式无主句，注明两说给分）；②动词性非主谓句＋祈使句；③主谓句·动词谓语句（“怎么”做状语）＋特指问；④名词性非主谓句＋感叹句。八标全对即满分。
:::
:::

::: exercise 反问翻译机 {level=2}
把三句反问译成陈述义并倒推装备：“谁稀罕？”“这我可不答应吧？”“他不就去了一次吗？”
::: solution
＝“没人稀罕”（疑问代词“谁”任指化＋降调感叹包装）；＝“我不答应”（“吧”弱化＋“可”强调的反诘，命题取反）；＝“他就去过一次”（“不是…吗”正反同义：反问的极性翻转律）。倒推装备：任指代词、语气词、正反框架皆可载反诘——**问句形式≠疑问功能**，句类判定的功能学补丁。
:::
:::

::: exercise 小论文：汉语是话题型语言吗 {level=3}
写八百至一千二百字：以本课三证据（主谓谓语句、受事主题句“这事我早忘了”、流水句雏形）评估“汉语=话题优先语言”（Li & Thompson 1976 类型学）这一标签：它对二语教学有什么用、对句法研究又有什么过度概括之嫌？要求含一个你方言/口语里的话题句样本，并给出“标签有用但需加刻度”式的收束。
::: solution
判分点：三证据各给一句分析；标签的双刃（教学上解释“为什么汉语可以说‘水果我爱吃’；研究上掩盖了话题的主句/从句层级差与重轻读差别）；样本真实；收束给“话题优先是一个连续统参数，汉语在高端但非唯一”的分寸。
:::
:::

::: summary
句型按结构编队（主谓四队＋非主谓四型），句类按语气包装（陈疑祈叹，疑问四式各有装备）。主谓谓语句与非主谓句两大“拦路虎”收编入册的过程，就是汉语语法学摆脱“句句主谓”教义、承认**话题优先家风**的过程。双坐标定位任何句子：结构一维、语气一维，再加功能一剂补丁（反问不疑）。下一课进特殊句式博物馆：把字句、被字句、存现句、连动兼语——汉语语法的四大名捕。
:::
