title: "实词"

词类是语法学的第一张元素周期表——氢氦锂硼好排，碳氮氧就打架。本课按教学语法“十二类”发货单清点汉语实词，再重点勘察三条边界线：名动、动形、以及那个谁都不肯收留的“区别词”。

## 十二类总表与实词六家门 {#sec-shier}

::: definition 十二类与三张标准 {#def-shier}
教学语法（黄廖框架）分词为十二类：**实词六**——名词、动词、形容词、数词、量词、代词；**虚词四**——副词、介词、连词、助词（下章专课）；**独立词二**——叹词、拟声词。分类用三条标准加权：**分布**（能进什么框架）为主，**意义**（词汇语义类）为辅，**功能**（能否单用、充当什么成分）为校验。实词六家的门规速记：名词进“数量×、×的”；动词进“×不×、×着/了/过、(+宾语)”；形容词进“很×、×不×”而拒绝宾语；数词量词“数+量+名”一条龙；代词吃的是“指代框架”。
:::

::: theorem 三大件的鉴别三板斧 {#rule-sanbanfu}
**名动之争**：能带宾语的是动（“学习”），能受数量修饰的是名（“一种学习”）；两可者判“动名兼类”还是“动词名用”，看**义隔**——“进行调查研究”里“研究”意义未变，主流判名物化使用而非兼类。**形动之争**：“很×”通（很干净）且**不能带宾语**（*很他头发）为形容词；能带宾语、可加“了”表变化（变了颜色）为动词——中间地带叫**状态动词/心理动词**（ “怪、愧、急人” ）。终极一招**“×不×”提问测试**：汉语谓词通吃（好不好/去不去/是不是），问不倒的才不是谓词。
:::

::: example “给”字四连问 {#ex-gei}
判四句里“给”的词性：①他给我一本书。②你给我老实点。③衣服给洗了。④给大家讲讲。
::: solution
①给予动词（双宾结构本家）；②祈使句里的“给”已经虚到情态/催促标记的边缘（学界或归介词、或归助动词，答案注明分歧即算对）；③被动标记（“被”义，“给”表被动多用于不如意事件、口语色彩浓）；④介词（引进对象，“向大家讲讲”义）。一条虚化链贯穿：给予动词>受益/对象介词>被动、催促标记——**同一个字形挂着词类光谱的四站**，语法化阶梯（[[modern-vocabulary/lexicon-layers]]语法化条）的现役样品。
:::
:::

## 边界上的三户人家 {#sec-bianjie}

::: definition 区别词、状态词、时间词 {#def-sanhu}
**区别词**（非谓形容词）：金、男、野生、主要、初级、大型——只能直接修饰名词，**不进“很×”、不做谓语、前加“的”成“的”字短语**（*很男、×这很金；“正的”“副的”✓）。它是《马氏文通》“介词”之外百年悬案的定居点：名词 subclasses 收不进、形容词收不进（不能谓词化），遂单立一户。**状态词**：绿油油、干干净净、血红、傻乎乎——“很”不吃它（*很绿油油），却自带程度语义，做谓语必带“的”（脸色煞白的）；形容词与它的关系≈性质与快照。**时间词**：明天、刚才、从来——做主语有争议（“明天是周六”各派判据不同）但**直接做状语不需介词**（明天见）、又能受“的”修饰（下周二**的**会）——名词的户口本、副词的作息表，教学语法寄押在名词，语言学各派各有判决。
:::

::: history 词类观的百年变迁 {#sec-cilei}
《马氏文通》1898 立名字、代字、动字、静字、状字、介字、连字、助字、叹字九类，汉语词类学开张；黎锦熙《新著国语文法》（1924）“依句辨品”走到极端——词无定类，位段定职；战后教学主流折中为“多功能说”（词有本类、可借用）；五十年代词类大讨论（关于汉语词类的标准之争）确立分布标准为主；吕叔湘《汉语语法分析问题》（1979）把“词类两难”讲成人人可见的常识，一句定乾坤：分布是硬道理，边界是活历史。黄廖本十二类即这场百年谈判的现行约章。
:::

::: warning 词类练习三防
一防**意义一刀切**：“勇敢”是形容词——“很勇敢”✓、“勇敢”做主语✓（“勇敢是一种品质”）——形容词做主宾语不必变形式，意义判“抽象名词”者皆翻车；二防**每词查户口**：词类是**类**的统计倾向，个案永远有游移（“代表”们），要背的是框架不是标签；三防**忽视量词的系统性**：名量词与名词的语义选择（条-长物、张-平面物、粒-小圆物）是汉语语法最诗意的部分，也是对外汉语的偏误火山（*一匹牛）——下一课虚词、这一课量词，是汉语语法的两道命门。
:::

::: quiz
下列**最**能证明“金”是区别词而非形容词的是（　）。
- [ ] 金可以修饰名词
- [x] “金”不能说“很金”，也不能做谓语
- [ ] 金是名词性语素
- [ ] 金可构成“金的”
::: solution
区别词三不：不进“很”、不做强谓语、不加“了”；只直接定语（或成“的”字短语）——分布否定证据最硬。
:::
:::

::: quiz
“很干净 / *很雪白”的对立说明（　）。
- [ ] 雪白是名词
- [x] 状态词自带程度义、拒绝程度副词
- [ ] 干净是状态词
- [ ] 汉语没有程度系统
::: solution
性质形容词可以吃“很”，状态词（雪白、绿油油）程度已饱和——形式与意义的分工标本。
:::
:::

::: quiz
量词系统的主要语法功能是（　）。
- [ ] 表复数
- [x] 与数词配合给名词计量，并携带形状/语用信息
- [ ] 强调动词时量
- [ ] 代替介词
::: solution
“数+量+名”框架里量词既强制（*三书）又表意（条/张/粒的选择暴露名词的形状类别）——汉语独有的语法诗意。
:::

::: exercise 框架分拣 {level=1}
用“很×、×不×、+宾语、数量+×”四框架给“容易、讨论、丰富、骄傲”各测一遍，判类并指出多功能处。
::: solution
容易：很✓、×不✓、宾语✗→形容词；讨论：很✗、宾✓（讨论问题）、可重叠（讨论讨论）→动词；丰富：很✓＋宾✓（丰富文化生活）→形动兼类（使动用法已固化）；骄傲：很✓、宾✗、做主语✓（“骄傲使人落后”）→形容词（居主宾语≠强制名词化）。判类＋点出“丰富”两栖即满分。
:::
:::

::: exercise 偏误门诊 {level=2}
为外国学习者的三句偏误写出规则解释：①“*我明天见了你”；②“*他很高了个子”；③“*三条马”。
::: solution
①“明天”将事件定位未来，与完成“了”冲突——时间词是定位框架而非普通名词；②汉语形容词不能带受事宾语，需改“他个子很高”（主谓谓语句，见[[modern-grammar/special-constructions]]）或“他高”限于比较句框架；③量词按语义类别选择：马用“匹”——条/张/粒的偏误暴露母语无量词系统的迁移。三解各中要害即满分。
:::
:::

::: exercise 小论文：词类是发现还是发明 {level=3}
写八百至一千二百字：词类像化学元素（客观等待清点）还是像行政区划（有用但可选择）？用本课三户“边界人家”（区别词、状态词、时间词）立论：每一户的单立/寄押方案比较；引英语“名物化无须变形”与日语形容词活用对照一句；最后给你的框架选型表态（教学简明优先 vs 理论一致优先）。
::: solution
判分点：三户各给出两种安置方案及其代价（如区别词并入形容词→“很”测试失效；并入名词→定语功能过剩）；对照不越界（形态丰富语的词类是形态类，汉语是分布类——可通约但不可硬套）；表态有标准意识（同一材料在不同目的下的最优切分不同——发明服务于发现）。
:::

::: summary
实词六家靠分布框架发身份证，三大件用三板斧（带宾语、很×、×不×）分拣；区别词、状态词、时间词三户边界人家提醒我们：汉语词类是**统计倾向的原型范畴**，不是非黑即白的户籍。量词是汉语的语法名片兼对外教学火药库，“给”字四连则预演了虚词一章的主角身世——实词虚化、虚词实化，词类的河床永远在改道。背表不如练框架：下一课虚词，专看这些改道冲积出来的“语法泥金”。
:::
:::
