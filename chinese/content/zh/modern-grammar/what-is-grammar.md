---
title: "什么是语法"
---

“一个人说话凭什么能被听懂？”，除了词汇表，还必须有一套拼装规则——这套规则就是语法。本课先给语法学“定纲”：单位、关系、以及汉语语法为何跟印欧语长得完全不一样。

## 语法的零件与装配 {#sec-danwei}

::: definition 语法单位四级 {#def-siji}
语素（最小的音义结合体，见[[modern-vocabulary/morphemes-words]]）→ 词 → 短语 → 句子。语法学管两件事：**单位**（哪级是哪级、边界在哪）与**关系**（单位之间的组合规则）。关系又分两类：**组合关系**（横向：主语+谓语、动词+宾语能不能配）与**聚合关系**（纵向：同一槽位可以换哪些成员——“吃/做/炒+饭”是一个聚合）。会造句=掌握组合，会选词=掌握聚合——索绪尔这两个轴，是全部语法描写的坐标系。
:::

::: definition 汉语语法的三大性格 {#def-xingge}
①**缺乏形态**：名词无格无数、动词无变位，“我打他/他打我”全靠位置和虚词——**语序因此成为第一语法手段**；②**词无定形、一句多职**：“研究”在“进行研究”里是名词、在“研究问题”里是动词，汉语词类是**分布类**不是形态类；③**短语、复合词、句子同一套结构**：“下雨”可以是词、是短语、也是句子（“下雨了。”）——**三级同构**是汉语的特色，也是它所有“词还是短语”“主语是什么”争论的病根（[[modern-vocabulary/morphemes-words]]的汉语特点在语法层的回响）。
:::

::: example 分布法办案：“研究”是什么词？ {#ex-yanjiu}
甲：进行研究。乙：研究问题。丙：很研究。丁：研究的。——四个环境的语法反应不同，据此给“研究”定身份。
::: solution
甲：受“进行”支配=动名词性用法（汉语里即动词的名词化使用，不作“兼类”处理是主流）；乙：带宾语=动词典型分布 ✓；丙：“很+形容词”是形容词的典型框架，“很研究”接受度低——说明“研究”未按形容词分布办事；丁：“的”字=名词化结构（“研究的”=研究的〔东西/人〕）。结论：**汉语词类是“多功能”的**——动词本类就能做主宾语而不必变词形（“调查正在进行”），这正与印欧语“名词化=形态改变”分道扬镳。
:::
:::

::: theorem 三级语法单位说（黄廖框架） {#rule-sanji}
教学语法采用三级：词—短语—句子（语素归词汇学，句群归篇章）；词性用分布标准定：**能出现在什么框架里**（“很×”“×不×”“×着/了/过”“数量+×”……），结合意义作参考。三级间的过渡地带正是汉语的深水区：主谓短语可做主语（“你不去也好”）、单词可成句（“禁止吸烟。”/“喂！”）——**级别按功能判，不按长度判**。
:::

::: intuition 语法是“社会约定”，不是“逻辑定律”
“一个人一个人地排队”合法，“一个一个人地排队”别扭——没有逻辑解释，只有分布事实。语法学家首先像语言学家而非立法委员：记录共同体认可的模式（描写），再谨慎提出建议（规范）。两副面孔要分清（与[[modern-vocabulary/dictionaries]]词典的两副面孔同构）：把“别”从连词判成副词是学术争论，把“凯旋归来”从病句判成犯罪则是语域洁癖——**语法课训练的是分辨这两件事的耳朵**。
:::

::: history 从“句读”到“语法学”：中国法统的两次换血 {#sec-fatong}
传统中国有极发达的文章学与句读论，但没有以“词类、成分”为骨干的语法学。第一次换血：1898 年《马氏文通》借拉丁框架为文言立法——“因西文四读之线画中国字句”的自觉错位；第二次换血：1920 年代起以**活口语**为对象、以**分布**为标准（黎锦熙《新著国语文法》的“凡词、依句辨品、离句无品”是激进版，见[[modern-vocabulary/morphemes-words]]），1950 年代规范化运动又把这套描写固化为全民“对错感”（《语法修辞讲话》—语文课本—高考试卷一线串起）。今天课堂里的“主谓宾定状补”是这三百年三次换血的沉淀岩——**每层都是合理时代的不合理妥协**。
:::

::: warning 语法入门三防
一防**用英语语法考汉语**：“汉语有没有被动句/进行体/词性转换？”是语法学问题（可问答案）；“汉语应该有时态变化才算完善”是语法学笑话——形态手段与语序虚词手段只是路线不同，无高低；二防**成分分析法万能化**：成分分析（中心词—附加语）擅长句法外壳，不擅长语义（“鸡不吃了”两读同树），学完成分法要接着学变换与语义指向；三防**把规范当语法**：病句题是公共写作的最低标准，不是自然语言的最高标准——文学作品里的“不规范”常常是最经济的表达（修辞学见下一门课）。
:::

::: exercise 分布测试 {level=1}
给“代表”设计三个分布框架，分别判定它的名词、动词用法；再举一个“很×”可说与不可说的词对并解释其类别。
::: solution
“三位代表/代表团”＝名词框架（数量+×）；“代表大家发言”＝动词框架（+施事主语+小句）；“×们”测试（代表们 ✓ 兼类坐实）。“很高/很聪明”✓（形容词），“很桌子/很跑步”✗（名动不同进“很”框）——“区别词/状态词”等疑难户即从框架差异里浮出（下章展开）。
:::
:::

::: exercise 两副面孔 {level=2}
对“无语不成句，无句不成篇”的两则网络语料——“绝绝子”“Given 名字”——按描写与规范两条线各写一句判词，并声明各自依据。
::: solution
描写线：记录构式（“绝绝子”＝ AABB 式网络强化构式、“Given+X”＝双语语码混用的语用标记）与其使用社群、语域；规范线：判定其公共域适用度（正式文书不宜、亚文化圈层内合法）。判词两条、依据各一即达标；把两线混成一锅（“错！”/“都对！”）均不得分——本课第一训练目标即分账能力。
:::
:::

::: exercise 小论文：语法本能 {level=3}
写八百至一千二百字：一个没上过语法课的奶奶能凭“感觉”判断“饭吃了被我”不通，却说不出主谓宾——她的知识是什么性质的知识？本课程与她的关系是“授予规则”“整理直觉”还是“改写语感”？要求以三个自己社群的真实例句立论（一个合法但教科书不教、一个不合教科书但人人说、一个人人不说但理论上合法），并回应一个“语法无用论”。
::: solution
判分点：三个例句真实且分析到位（分布/频率/语域各议其一）；“知识性质”落点（程序性知识 vs 陈述性知识；教学语法是其二阶整理）；对“无用论”的反驳不靠情怀靠例（写作修改、二语教学、语言技术皆一阶直觉的失灵处）。
:::

::: summary
语法=拼装规则：四级单位（语素—词—短语—句）乘组合聚合双轴。汉语三大性格——无形态、词多功能、三级同构——决定了它的语法学必须用分布法而非形态法办案，也决定了它一切争论（词界、词类、主语）的独特配方。教学语法的“主谓宾定状补”是《马氏文通》以来三次换血的沉淀岩，用时要记得岩层年代，更要记得：你早就拥有一整套语法知识，本课程只是把它从直觉请进账本。
:::
:::
