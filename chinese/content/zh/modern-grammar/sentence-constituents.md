---
title: "句子成分"
---

短语披上语调成为句子，骨架上就挂出七个职务名称：主谓宾、定状补，再加独立语与提示成分。本课发两套工具——**符号提取法**（语文课的加线体系）与**语义指向分析**（distribution 之外的那半只眼睛）。

## 成分总表与符号法 {#sec-chengfen}

::: definition 七成分与一句话总纲 {#def-qi}
句子=前后有停顿语调、能独立运用的交际单位；成分体系：**主语**（陈述对象）—**谓语**（陈述核心）—**宾语**（动作涉及者）三条骨架；**定语**（的名词修饰语）、**状语**（地动词修饰语）、**补语**（得/结果/时量/动量补充语）三组附加；外加**独立语**（“看来、据说、哎呀、北京—上海”式句外成分：呼语、插入、提示）。总纲一句：**名动形各安其位——名词性做主宾、动词形词做谓、形容词名词做定状补**。加线符号系统（语文版）：主语双横线、谓语竖线、宾语波浪线、定语（ ）、状语［ ］、补语〈 〉——六套标点一套句。
:::

::: example 加线实操 {#ex-jiaxian}
用加线符号分析：“他十分仔细地观察着那里的地形。”并回答：全句有没有补语？“那里的”是什么成分？
::: solution
主语“他”；谓语中心“观察”＋动态助词“着”（助词附庸，不单独分析）；宾语中心“地形”；定语“（那里的）”；状语“［十分仔细地］”（状中短语整体做状语，“十分”修饰“仔细”）。补语：无——本题陷阱正在此。易错两处：“那里的”是定语不是状语（“的/地”一筛即分）；“着”不另立成分。
:::
:::

::: theorem 组成分三测试 {#rule-sanshi}
①**提问法**：（谁）谓语？→主语；谓语（谁/什么）？→宾语；谓语（怎么样/在哪/多久）？→状补；（什么样）的→定语。②**“的地得”筛**：定中“的”、状中“地”、述补“得”——三个路标词各领一类附加语（零形定语（“木头桌”）与无标记状语（“快跑”之“快”）另靠位置与词性补判）。③**提取对照**：“昨天在礼堂我们开了会”vs 任意挪序——**状语多层排序定律**：时间＞处所＞范围情状＞关介对象＞动词（“昨天下午在礼堂跟代表们热烈地讨论了问题”一层不乱）。
:::

::: example 语义指向：一碗汤的两种锅气 {#ex-zhi}
“我们跟他谈了很久。”——“很久”指向动还是人？“他老婆病了半个月了”可说，“*他老婆病了半个月”不可说——为什么？“只有你知道”与“你知道的只有我”——“只有”的指向差在哪？
::: solution
“很久”做时量补语指向**动作的时长**（可问“谈了多久”），不指向“汤/他”；若换成“汤热了很久”，“很久”指向**状态持续**——补语语义指向不同，句法位置同一。时量补语要求**可延续**的谓语（“病”可延续故能带“半个月”；“死”不可，故“死了三天”指的是死后状态而非死这个动作的持续——语义指向分析替时体系统擦屁股）。副词“只有”在前句指向**知识对象集合**（限定“谁”）、在后句指向**数量**（限定“我知道的”范围）——一个状语，语义镜头对准谁，意义就跟谁走；成分分析给位置，指向分析给准星。
:::
:::

::: history 成分分析的三次下沉 {#sec-xiachen}
教学语法句法经历三代同堂：第一代“中心词分析”（成分加线，1950s 定型进中学课本，至今是全民语法母语）；第二代结构主义层次分析（上一课的二分树，钻进大学讲台）；第三代生成语法（成分统治关系 c-command、空代词、移位——1980s 起接管专业研究）。三代各干各的活：改作文用第一代，析歧义第二代，做理论第三代。语法学的“内卷”史证明：**没有更好的分析，只有更合适场合的分析**（本课程的立场：工具实用主义）。
:::

::: warning 成分四坑
一坑**主语=施事**：“台上坐着主席团”主语是处所非施事、“他给了我一本书”与“这本书我看过”（受事主题句）——**汉语主语是话题位，不包管语义角色**（话题优先是汉语的类型学身份证）；二坑**独立语漏网**：“据说、看来、哎呀、北京—上海”这些句外成分不做主谓宾也成句，分析时单列“独立语”，硬塞进骨架即扭曲；三坑**“是”字万能论**：“是”可判断（他是我哥）、存在（门口是一棵树）、焦点（我是知道）——三个“是”三种句法，别签一份合同；四坑**忘了句子≠短语**：短语加语调才成句，所以“很好”是短语，“很好。”是句子——主谓齐不齐是句子的事，“下雨了”无主也成句（非主谓句专章再论）。
:::

::: quiz
“昨天下午在礼堂”在“昨天下午在礼堂我们开了会”中做（　）。
- [ ] 主语
- [x] 状语（时间与处所两层）
- [ ] 独立语
- [ ] 补语
::: solution
时间、处所名词短语直接做状语（时间词特权，[[modern-grammar/parts-of-speech]]）；句首状语不停留在主语位。

- [ ] 名词／动词

“门口站着一个哨兵”的主语是（　）。

- [x] 门口（处所主语，存现句）
- [ ] 无主语

::: exercise 加线全景 {level=1}
给“代表们热烈地讨论并通过了大会的报告。”做全套加线；并说明联合谓语共用宾语时的配搭检查法，自造一个配搭失败的病句。
::: solution
‖代表们‖‖［热烈地］讨论并通过‖<了>（大会的）报告‖：主语“代表们”；联合谓语“讨论并通过”（“了”附动词后）；宾语“报告”＋定语“（大会的）”；状语“［热烈地］”。**配搭检查**：共用宾语须与两动词分别配搭——“讨论报告”✓“通过报告”✓，联合成立；自造反例如“看见和听到了一阵歌声”（*看见歌声）即“动宾搭配不当”病族，专章见[[modern-grammar/faulty-sentences]]。加线全对＋检查法说清＋反例成立即满分。
:::
:::

::: exercise 指向破案 {level=2}
“他爸爸批评得很厉害。”有歧义吗？用语义指向解释；再造一个含“差点没”的句子并说明其指向的极性翻转机制（选做）。
::: solution
有：补语“很厉害”可指向**批评的力度**（批评得厉害）或**爸爸被批后的惨状**（亏得“把”字句可拆：“把他爸爸批评得很厉害”指向爸爸）——无标记时默认指向动词量级，语境可翻转；“差点没摔倒”=没摔倒（愿望）/“差点没考上”=考上了（负面愿望的否定冗余）——极性由**愿望方向**决定，指向分析＋语用合谋。分析到位即满分。
:::
:::

::: exercise 小论文：主语是什么 {level=3}
写八百至一千二百字：结构主义主语=谓语所陈述的名词性成分；逻辑主语=施事；教学主语=“双横线那一坨”。三者对“台上坐着主席团/连他都不认识你/这件事我早忘了”各给何判？你要向校长解释为什么孩子的试卷上“汉语主语是动作发出者”被打了叉——写一封三百字的信，再用语言学论证展开。
::: solution
判分点：三定义逐一过招并自认其代价（结构定义放过主谓谓语句、逻辑定义死于存现句与受事主语句、教学定义=约定但稳定）；信符合语域（不炫学术黑话）；核心论证落在“汉语主语=话题位”的类型学事实，并引出课程下一站：句型章（主谓谓语句与存现句的正名之地）。
:::
:::

::: summary
七成分一句话总纲：骨架主谓宾、附加定状补、句外独立语。加线符号是全民语法母语，但三测试（提问、的地得、提取排序）才给它牙齿；语义指向补上位置学缺的半只眼睛——状语补语对准谁，意义就跟谁走。三代分析各守各岗：改作文、析歧义、做理论。最大的一课：**汉语主语是话题席位，不是施事岗位**——存现句与受事主两句的户口问题，请移步下一课句型志。
:::
