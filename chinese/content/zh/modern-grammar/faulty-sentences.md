---
title: "病句的诊断与修改"
---

前八课发的全部工具，在这一间诊室排队挂号。病句教学的高考口径是**六大类**（语序不当、搭配不当、成分残缺或赘余、结构混乱、表意不明、不合逻辑）；本课给三样东西：**族谱、诊断流程、修改伦理**。

## 六大类的族谱 {#sec-zupu}

::: definition 六族十五小类速览 {#def-liu}
**一 语序不当**：多项定语乱序（梯队：领属→数量→动因→属性→中心语——“村里刚出土的两件宋代瓷器”）、关联词位置（主语同异定前后，[[modern-grammar/complex-sentences]]）、状语乱梯（范围与程度状语各有座次：“都”先于“也许”？——凭语感立案，用对比句定谳）。**二 搭配不当**：动宾（“扩大规模”“提高效率”各归各位，*“提高范围”×）、主谓（*他的去世使我悲哀很久）、正反对冲（“能否…是关键”两面搭一面）。**三 残缺与赘余**：介词淹没主语（通过…使…）、缺中心语（“据…显示”与“…的结果”两头合拢）、堆叠赘余（“大约…左右”“忍俊不禁地笑了”“个人私见”）。**四 结构混乱**：句式杂糅（“原因是因为”“本着…为原则”）、中途易辙（前句主语活到一半换了车）。**五 表意不明**：指代悬空（“这”无所指）、切分歧义（三个中学老师的爸爸）、施受两读（“他的笑话”——他讲的笑话，还是别人拿他开涮，领属/主宾两解）。**六 不合逻辑**：自相矛盾（约…左右）、否定失当（“避免不”“未尝不会不”套娃）、分类不当（报纸电视等文学作品）、强加因果。
:::

::: example 十二连环诊室 {#ex-shier}
判类：①学习成效的高低，取决于努力。②他马上立刻集合了队伍。③通过这次活动，使大家受到了教育。④我们肩负着并继承了老一辈的优良传统。⑤三个县里的干部来开会。⑥古典芭蕾舞剧《天鹅湖》曾来过中国。⑦他连小学没毕业。⑧为了避免不再生事，他搬了家。⑨报纸、广播、电视和各类文艺形式。⑩他的家乡是青岛人。⑪这个问题我解决不了他。⑫我基本上完全同意。
::: solution
①两面对一面（搭配不当之正反对冲——“努力”改“是否努力”或删“高低”）；②状语堆叠赘余；③介词淹主语（残缺）；④隐性搭配不当：“肩负”只能带“使命/任务”，在联合谓语里与共用宾语“传统”暗中失搭——拆开配平：“继承了老一辈的优良传统，肩负着新的使命”；⑤切分歧义（三个/县里）；⑥主谓失搭（剧不能“来”，改“曾来华演出”）；⑦“连”字框残缺（应“连…都/也”）；⑧否定失当（避免+不=双重否定做坏事——删“不”）；⑨并列含属种（报纸本身即文艺/传播形式，集合自含——不合逻辑之分类不当）；⑩主宾不类（家乡是人——句式杂糅：他家乡是青岛/他是青岛人）。⑪两句粘连（句式杂糅：“这个问题我解决不了”与“他解决不了这个问题”并轨失配）——择一；⑫自相矛盾（“基本上”与“完全”互斥）。十二案全中即出师。
:::
:::

::: theorem 诊断流程三步与修改三德 {#rule-liucheng}
**三步诊断**：①**紧缩法**——提取主干（谁/什么＋做＋什么），主谓宾一照妖（搭配、残缺、杂糅全现形）；②**缩叶法**——逐层查附加（定状补的语序、赘余、两面对一面）；③**逻辑复核**——事理自洽吗（矛盾、否定、分类、因果）。**修改三德**：**存真**（原意是甲方，改动是乙方，乙方不得反客为主）；**最小**（能删不改、能换一词不换全句——“多改”本身是新的病）；**留痕**（教学与编辑场景标注改动依据，可复核可申诉）。
:::

::: history 病句意识的一千年与七十年 {#sec-bingju}
古人校书讲“鲁鱼亥豕”，那是文字之病；**句法之病**作为全民科目，始于 1951 年《语法修辞讲话》的报纸专栏——它把“写通了没有”从士大夫的修养变成公民的技能，高考试卷的病句题即其曾孙。七十年间两桩公案值得铭记：“凯旋而归”删不删（重复义成词，词典已转正）；“十分浪费”管不管（程度副词+动词的搭配面持续漂移）——**病句是移动的边界线**，但“移动”不等于“随意”：通行情报来自语料与共同体，不等于“大家都错那就对了”。
:::

::: warning 诊室三个医疗事故
一**把风格当病**：“她死了。死得很轻。”（跨句碎片是修辞）——病句判定须有**同格对比**（常规表达确实存在且更达标）；二**把演变当病**：“十分+名词”（十分现代）、“被就业”都是构式扩占，编辑可守成，语法学要记账；三**把修改当写作**：改后句子正确但无生气——病句教学的最高级是**写出无需修改的句子**，诊断学毕业等于免疫学入学。
:::

::: exercise 主治医生 {level=1}
六选二精诊（判类+最小修改+依据）：①中国是世界上人口最多的国家之一。②他的革新老实方法值得学习。③我们既要学会做事，也要学会做人。④这部电影，我在去年就看过它了。⑤谁也不能否认家庭教育不是影响一生的。⑥两个工厂的工会领导开会。
::: solution
①**无病**（“最…之一”量度自洽，陷阱题，修即事故）；②“革新”宜改“改进”（改进方法、革新技术各归本义）；③无病（递进合法）——再陷；④“它”复指冗余（连词成句：电影我看过了——删“它”）；⑤三重否定翻车（“不能否认不是”=否认其为，删“不是”改“是”或删“不”）；⑥切分歧义（两个/工厂的——“工厂的两个工会领导”）。任二精诊（类+改+据）即满分。
:::
:::

::: exercise 广告法庭 {level=2}
广告名案三则开庭：“默默无蚊（闻）”“骑乐无穷（其）“酒负盛名（久）”。控方（规范派）与辩方（活用派）各陈词，你陪审：分场景（药品说明/朋友圈/招牌）给出“对/错/看场合”的判决表。
::: solution
控方案头：错别字污染文字规范、误导学字期儿童；辩方案头：谐音双关是修辞格（[[rhetoric]]“仿拟”），成语生命力本在流转；判决表范式：公共服务文本从严、商业创意文本从宽并加标注、教材考场绝对从严——**“对错”的真语法是“语域得体”**，一句话说清，判分。
:::
:::

::: exercise 小论文：病句是错误还是变化 {level=3}
写八百至一千二百字：从“凯旋而归”的转正与“非常+名词”（非常时代）的未决拉锯出发，论证你的“病句相对论边界”：哪些病是能力不足（performance 可恕、competence 未立），哪些是系统演变的前兆，哪些纯属文体误配。要求：三个案例+一条你自拟的“判决优先序”（规范/语感/频率谁先谁后），并回应“语文教师是不是该第一个反对语言变化”。
::: solution
判分点：三案例分诊准确（成分套娃错误= competence 病例、程度副词+名词=演变前沿、谐音广告=语域案）；优先序自洽可操作；“教师反变革”回应不极端（教师的职责是**分清场合的语法**，不是充当语言的防腐工）；引用本课“移动边界线”史实无误。
:::
:::

::: summary
病句六大类十五小类是族谱，三步诊断（紧缩、缩叶、逻辑复核）是流程，三德（存真、最小、留痕）是医风；七十年病句教育把“写通”变成公民技能，而“凯旋而归”的转正提醒我们：边界在移动，但移动有账本。全课九章至此闭卷——从“什么是语法”到“把句子写通”，你手里已经有了：分布的尺、层次的刀、句式的镜头与诊室的灯。语法不是背诵的律法，是把话说稳的手艺；下一门课（修辞）教你把手艺再往前挪一寸：把话说活。
:::
