title: "苏轼"
---

上一章结尾说，初宋词里的“我”是可转借的职位；本章写那个把生日写进词里的人——**苏轼不是把词写大了，他是把自己住了进去：以诗为词、以文为词、以经历为词牌，从此词的信用报表上多了一栏“作者本人”**。

## 定义：生平即注疏 {#def-shengping}

::: definition 一条贬官路线＝一部作品年表 {#def-luxian}
**眉山—汴京—杭州—密州—徐州—湖州—黄州—惠州—儋州—常州**（**把路线图与作品集叠印，重合率高得吓人：《江城子·密州出猎》写于 1075 的密州、两篇《赤壁》写于 1082 的黄州、《食荔枝》成于惠州、《六月二十日夜渡海》成于儋州北归——**这不是巧合，是机制：宋代的贬所制度把作者从中央的公文机器里拔出来，塞进江湖、灾害、稻田与海上：履历表成了选题库（第 16 课“位置生产文本”的宋代标准案例：贬官是宋代文学的隐形主编**）。**乌台诗案（1079）**（**因诗下狱：文字被逐句审讯（通说：御史台举其诗以为讪谤）——**一次事件教会他两件事：其一，诗会作为呈堂证供（此后他的“有意于文字者”转入诗余与尺牍）；其二，词的免责传统可以接住诗的负债（**免税区在事故后变成避债区：文类的法律地位决定它能装什么）。
:::

## 黄州：作者装置 {#def-huangzhou}

::: definition 从“臣”改写成“客” {#def-ke}
**《赤壁赋》的主客双声**（**客吹洞箫如怨如慕，苏子答以水月之辨——**把让步制度化：全文最强的虚无之辩先由“客”说完、说满，才轮到主人拆解（第 6 课让步前置的赋体远祖：客是他的反方座位，永远留在他自己家里**）；**“**逝者如斯，而未尝往也；盈虚者如彼，而卒莫消长也**”**——**同一条水，两个账簿（变轨与不变轨）：宋诗“说理”不是喊口号，是把同一事物放进两套报表对账（回访宋诗课**）；**《后赤壁赋》的孤鹤**（**“道士顾笑，予亦惊寤”——**结尾不结账：赋第一次以悬念收尾（第 15 课未定点的高级用法：他把赋的结尾留成敞开的门**）；**《卜算子·雁》**——“**拣尽寒枝不肯栖，寂寞沙洲冷**”（黄州作，通说）——**人格自像不画脸，画一只鸟的住宿问题：贬所处境的最高压缩（不肯=立场，沙洲=处境，冷=体感：三行完成自传**）；**《临江仙》的传说**（“**小舟从此逝，江海寄馀生**”——**宋人笔记载“郡守大惊叩门”的故事，未必实有而人人愿信（接受史的自动补写：读者替作者拍续集：传奇是作品的分红**。
:::

::: definition 定风波：把事故改写成天气 {#def-dingfengbo}
“**莫听穿林打叶声，何妨吟啸且徐行。竹杖芒鞋轻胜马，谁怕？一蓑烟雨任平生。**”（1082，黄州；序“沙湖道中遇雨，雨具先去”——**词的序第一次记录一件小事的坐标：遇雨、同行、先觉——这些都不是词的传统题目（小题＋日期＋地点＝把词接入“日记体”的公文血统**）；**技术拆解**（**①“莫听／何妨”＝注意力的两次主动调仓（不是风景变了，是记账科目换了）；②“穿林打叶”＝把政治风声译成气象（第 16 课曲笔的正面用法：不是不敢说，是把危险层级整体翻译**）；③**料峭山风与斜照——身体先于心灵和解（**“归去，也无风雨也无晴”不是顿悟的凯歌，是湿衣服吹干之后的报表平账：苏轼的伟大在于他先冷，后想通（体验在前、哲学在后：这是与庄子“安时而处顺”最表面的相似与最深的不同。
:::

## 以诗为词的管辖权案 {#def-guanxia}

::: definition 四项扩容工程 {#def-kuorong}
**①题序制度**（“**乙卯正月二十日夜记梦**”“**丙辰中秋，欢饮达旦，大醉，作此篇兼怀子由**”——**日期、人名、事由进入词的封面：应歌文本第一次变成纪事文本（第 1 课文类协议的改写：词的收件人从“歌者”换成“史”（《江城子》悼亡“**不思量，自难忘**”，词开始承接诗才有的“私人名分”事务**））；**②诗题入侵**（**悼亡、怀古、说理、田园试问——**词的科目表向诗全面开放；《念奴娇·赤壁》把“三国”变成沉思材料：“**故国神游，多情应笑我，早生华发**”——**周瑜在词里被苏轼当作镜子用，而且是反着照：英雄的年轻对照自己的早生华发：怀古不是致敬，是找茬式对账（“人生如梦，一尊还酹江月”是转账给江月：把无法核销的损失挂入公共账户**））；**③议论入词**（“**人有悲欢离合，月有阴晴圆缺，此事古难全**”——**把结论直接写进歌词：宋人嫌它太尽，今人赞它太准：**词的“要眇宜修”与诗的“说尽”之间，他选择两边都违约（《水调歌头》序“不知天上宫阙，今夕是何年”的问，正是把“月”当成政论对象：问天不答，词替天答**））；**④清雄与谐音律的争议**（**晁补之、李清照一路讥其“多不谐音律”“句读不葺之诗”（通说归名）——**这不是审美保守，是管辖权抗议：扩容＝改变文类的资产结构：**当“作者”进驻，歌者退租：房租与署名权之争，才是这场公案的房契。
:::

::: definition 晚年：把苦难观光化 {#def-wannian}
**“日啖荔枝三百颗，不辞长作岭南人”**（《食荔枝》）／**“九死南荒吾不恨，兹游奇绝冠平生”**（《六月二十日夜渡海》）——**注意句式：不写“恨”，写“不恨”；不写“奇”，写“冠平生”：**苦难被改写成一笔有收益的旅行（观光化不是麻木：麻木是没有叙述，他把叙述权夺回来了（对比初宋词“不给出事故”：苏轼晚年是“给事故改标题”——同一留白技术，用途从掩饰变成自救**）；**朝云**（**惠州侍妾王朝云亡，词以悼之（《西江月·梅花》“高情已逐晓云空”通说归名）——**他一生把私人关系写进公共文体的次数，前无古人：词的“私人权限”是他申请的专利（回访第 1 课：抒情“我”由职位变真人，从他开工**）；**《寒食帖》**（**1082 黄州诗稿：涂改与字形欹侧成为文本的一部分（回访书法课：手稿的“修改痕迹”是文学的复本：**词的定本神话在此破产：文学最好的状态，恰恰是它没被誊清的时候。
:::

::: example 同题对读：两座雨中的城 {#ex-duizuo}
把《定风波》（沙湖道中遇雨）与柳永《雨霖铃》（寒蝉凄切）并读：二者都写“雨／凄景＋行程”，请从**①谁在说话、②同伴是谁、③雨最后落在哪里**三栏做对照表；再回答：**为什么柳永的雨下在离别里，苏轼的雨下在身体里**。
::: solution
**①说话人**——柳：**代言的男性歌者口吻（对“兰舟”上的人说“执手相看泪眼”，人称是可转借的职位（第 15 课）**；苏：**一个带姓名与日期的人（序先报到：“雨具先去，同行皆狼狈”——先给出证人身份再作证词**）；**②同伴**——柳的在场者是**爱人（私密关系＝情感银行）**；苏的在场者是**“同行皆狼狈”的众人＋一个自我（社会关系＋内心会议：词里第一次有了“群众演员”）**；**③雨的去向**——柳的雨**在别后的想象里（“杨柳岸晓风残月”＝雨下在给未来的预支账上）**；苏的雨**从头到尾下在皮肉上（“料峭春风吹酒醒，微冷”：身体先付款，心再找零）**；**总判词**——**柳永写的是关系中的雨（离别是一种身份），苏轼写的是处境中的雨（贬谪是一种气候）：**前者词借人情，后者词经我身：从“职位”到“真人”的全部运费，苏轼一生付清。
:::
:::

::: intuition 苏轼是宋代的公共人格 {#int-gongwu}
**“苏轼”在两宋已是文化偶像**（**唱和、集句、题咏苏轼画像（宋人已有“坡诗注”产业与“和苏”风会（通说脉络）——**榜样的生产机制：宋代人已经在消费苏轼；偶像化不是身后事，是进行时**）；**他的可模仿性极高，可复制性为零**（**学苏者得其旷、失其术：因为“旷”不是气质，是一整套处理技术（注意力调仓、叙述权回收、对账式怀古）——**学苏轼的正确姿势是抄他的工序，不是抄他的心情（金圣叹所谓“行乐法”（第 15 课接受史回访**）；**“一肚皮不合时宜”（宋人笔记通说：朝云识其“一肚皮不入时宜”）**——**时宜是制度，不合是位置：**苏轼的伟大不在他超越了党争（他没有：他两边都被贬），而在他把两边都贬成了素材（这是文类特权：只有当文学的账本足够大，政治的亏损才能在另一本账上结清。
:::

::: history 苏氏年表（选点） {#sec-nianbiao}
**1037** 生于眉州；**1057** 进士及第（欧阳修知贡举本年——师生相遇于评分标准里：**古文运动的传位仪式（第 1 课嘉祐二年的另一条时间线**）；**1071—74** 杭州通判（**西湖产业化：“水光潋滟晴方好”（《饮湖上初晴后雨》通说）——**风景被一句诗收编为公共财产：城市从此按诗招租**）；**1075 密州（《江城子》两首：出猎与记梦——同年同地写了词的两种未来）；1076 超然台记＋《水调歌头》（“超然”二字是他早期的品牌名：用庄子给仕途做外包）；1079 乌台诗案；1082 黄州二赋、《念奴娇》《定风波》《寒食帖》（一个作者的奇迹年——更准确说：一次制度性闲置的年息）；1084 《题西林壁》（“不识庐山真面目，只缘身在此山中”——宋人说理的巅峰之一：认识论被写成旅游投诉）；1089—91 知杭州（苏堤：行政作品比文章更长寿：文学与基建共享同一个作者名）；1094 惠州；1097 儋州（办学、载书过海：流放地把宋代文化的边界推到海岛）；1101 北归卒于常州（身后：从“元祐党人”到“文忠公”再到文化偶像：平反的速度追不上人设繁殖的速度）。
:::

::: warning 苏轼四坑
**旷达贴纸**（**把全部作品压成“乐观”二字：**旷是工序的结果，不是作品的前提——先用《卜算子》的冷、《寒食帖》的苦做成本，才有《定风波》的利（只读利不读成本，是理财诈骗**））；**“豪放词派”的教科书惯性**（**“苏辛豪放派”是后人划的仓（明清词论与近代教材的遗产）：苏轼自己没申报流派，宋人也未见“豪放派”运作——**用流派讲苏轼是拿地图旅行：苏词的多数作品在“清雄”与应歌之间，不在“豪放”里**））；**传奇当史**（**“小舟从此逝”的叩门故事、“十年生死”的悼亡年份、“一肚皮”的朝云对话：宋人笔记层——**笔记不是造假，是把解释当新闻：引用要标层（第 1 课史料分层**））；**把技术读成天才**（**“他生性豁达”取消了全部工艺史：**题序、对账、翻译事故、留悬念——每一项都是可教的技术（本课教苏轼，是为了让你也能做他做过的事：不是成为他，是学他的工序**。
:::

::: exercise 工序还原 {level=1}
从《念奴娇·赤壁》《江城子·密州出猎》《浣溪沙》（山下兰芽短浸溪）各挑两句，填表：用了哪道工序（注意调仓／对账式怀古／小题坐标／自我调侃／翻译事故）？如果去掉这道工序，原句会剩什么？
::: solution
判分：**工序名称可自定但须可定义**；**“去掉后”栏要真做减法**（**如删“多情应笑我”的自我调侃，全词只剩壮语，壮语会因无裂缝而失真：**裂缝是可信度的来源（第 3 课：限定词的保险杆在词里叫自嘲）。
:::

::: exercise 为“客”写辩护词 {level=2}

::: exercise 小论文：作者的回归 {level=3}
写六百至一千字，评“**唐代把作者藏在体裁后面（即使杜甫的“我”也是律诗的官服），宋代让作者站到封面上——苏轼是这个转变的产权人：此后中国文学的一切信用，都以“此人确曾这样活过”为抵押**”。须调用：**贬所制度＝隐形主编**、**乌台诗案的文类后果**、**题序制度**、**对账式怀古**、**给事故改标题**、**旷达贴纸四坑**至少六项；并裁决：**“作者已死”（第 15 课）与“苏轼学的抵押机制”矛盾吗——用本课材料写一份双方都能签字的调解书**。
::: solution
判分点：六项机制（**制度、事故、封面、对账、标题、贴纸**）；调解书（**参考：作品的法庭上作者不出庭（意图谬误条款照旧）；但文类史的市场只对“可传记的写作者”放款——“作者已死”是阅读端的宪法，“作者活着”是生产端的商法（调解书两条：①解释有效性的终审权在文本；②文体扩容的信用由作者的处境提供抵押：二者分管两案，互不越审：**苏轼既死了又活着——死在解释学，活在经济学**）；结论若能写“**抵押物不是名声，是工序：一个人如何在亏损里保持记账能力——这门技术的名字，宋代以后就叫苏轼”，即 A。
