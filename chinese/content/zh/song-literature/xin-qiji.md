---
title: "辛弃疾与豪放"
---

上一章末尾说，仓库烧了以后文学只剩下背诵；本章写一个连军队都没有、只剩下词的人——**辛弃疾的全部词学，可以读成他那两篇没被采用的策论所生的利息：武力的账户被帝国冻结，他就在长短句里替代性提现**。

## 定义：被拒收的策论 {#def-celun}

::: definition 一一个人的两份文书 {#def-liangfenshu}
**《美芹十论》（1170）与《九议》（通说进呈年份略异）**（**一份完整的战略文件：取齐、守鲁、抚金、屯田、造谣、动员工——**逻辑链严整到可以直接排进本课第 4 门课的“政策主张”模板（四型配型：这是教科书级的 policy claim，带执行主体与预算）**）；**朝廷的批复**（**嘉许其“壮声”而无限期搁置其方案——**注意这个处理法：不否定你的主张，只安排你的任期（第 6 课“驳不掉的就不采用”：最省事的否决是表扬**）；**于是发生了中国文学史上最合算的一笔换汇**（**策论的全部技术（材料核、利害算、敌情表、动员语）转入长短句：**辛弃疾的词不是诗人的副产品，是政策分析师的复用软件（第 2 课“论点要有输的可能”——他一生最想要的赢，在纸面上实现不了，就在纸面上写得最像真的。
:::

::: definition 归正人：他的身份条款 {#def-guizheng}
**“归正人”**（**辛系“归正人”（由北方南归者的官方称呼，通说：宋廷对这一群体既用且防）——**这一条身份决定了他一生的绩效考核：别人考的是政绩，他考的是忠诚的可持续性**）；**少年事件的自注**（**《鹧鸪天》“**壮岁旌旗拥万夫，锦襜突骑渡江初**”——1162 年耿京军中的抗金事变与缚张安国南归（通说史实）：**他的词常常自带简历脚注：别人用典用古人，他用自己的档案（第 3 章李清照用目录作证，辛弃疾用战报作证：两个人都在给抒情找可核对的凭证**）；**《水龙吟·登建康赏心亭》**——“**把吴钩看了，栏杆拍遍，无人会、登临意**”——**一件兵器被反复检查而不出鞘：**武器的用途退化成了修辞道具（这是全课的核心句：豪放的技术起点，是武力的通货膨胀——刀不砍东西，就只好看、要拍、要拍栏杆）。
:::

## 以文为词的完成时 {#def-yiwen}

::: definition 四项技术 {#def-sixiang}
**①以议论为词**（“**凭谁问：廉颇老矣，尚能饭否**”（1205《永遇乐·京口北固亭怀古》）——**结尾是一个问句式的申请表格：用典密度＝申诉书的附件数量（全词五六个典故连发，每个都在证明“我有先例、请对号入座”）**）；**②以古文笔法入词**（**虚词转折、“之”“矣”句脚、散句领字——**词的呼吸被改成了奏疏的呼吸：宋人已疑其“非本色”（通说脉络）：**“不本色”正是他的申报类目：他把词的税种从歌词改成了文章（第 3 章的两部立法，他第三个窗口办事：既不听律，也不听家法，听事功**）；**③以经史为料**（**掉书袋的军事用途——**典故不是装饰，是弹药：每个典故是一个可用的先例（第 7 课“引经据典是借债要还”的军人版：他还得起，因为他的债主是历史**）；**④以结构制造反转**（**《破阵子》：八句战争片＋一句醒后——“**了却君王天下事，赢得生前身后名。可怜白发生**”——**上片的叙事越圆满，下句的取消越残酷：这是“计划失败”的词体语法（第 2 课死法测试的英雄版：他的论点自己写下了自己的反驳**。
:::

::: definition 寄托的读取规则 {#def-jituo}
**《青玉案·元夕》**——“**众里寻他千百度，蓦然回首，那人却在，灯火阑珊处**”——**梁启超评“自怜幽独，伤心人别有怀抱”（通说引评大意）；**“寄托”的读取规则：不是每首都有影射（那是猜谜），而是他的作品系统里存在一个稳定的“不与同席”姿势（阑珊处＝拒绝入场的位置：**不合作的姿态在词里被写成美学，因为它在朝堂上被写成罪名**）；**《摸鱼儿》**（1179）——“**君莫舞，君不见、玉环飞燕皆尘土**”“**闲愁最苦……受人妒**”——**用《离骚》的香草美人系统做外壳，内里是一份弹劾状的草稿（第 9 课屈子谱系的宋代续费：**当直谏的成本高于用典的成本，文学就收到一笔转移支付（第 16 课曲笔生存技术的宋词主账**））；**《菩萨蛮·书江西造口壁》**——“**青山遮不住，毕竟东流去**”——**地理写成历史判断：**水是他的同事：它不需要批准就能推进（对比策论：文件需要批准，所以停在他抽屉里**。
:::

## 闲居的四十年 {#def-xianju}

::: definition 豪放派的田园分册 {#def-tianyuan}
**《清平乐·村居》《西江月·夜行黄沙道中》**——“**稻花香里说丰年，听取蛙声一片**”“**茅檐低小，溪上青青草**”——**写于带湖、瓢泉闲居期（通说）：**中国文学最好的农村词之一，出自一个本想带兵的人的手（第 15 课“风格＝选择函数”的极端案例：函数自变量不是志趣，是任命状**）；**技术说明**（**《清平乐》以“醉”统一视角（翁媪对语与小儿打捞——**酒是叙述许可证：醉汉能说的、能夸的，醒人办不到：辛弃疾闲居词的真正主角是“被允许无事可做”**））；**《贺新郎》“我见青山多妩媚，料青山见我应如是”**——**把同事关系扩展到地质：**当人的听众全部离场，他给作品申请了一位自然见证人（第 15 课“抒情我”的对话性：辛词的对谈对象从君、友，降级又升级为山。
:::

::: example 复盘与演习 {#ex-fupan}
对照《破阵子》（醉里挑灯看剑）与苏轼《江城子·密州出猎》（老夫聊发少年狂），两首都是“武事词”，做三栏表：**①叙述位置（谁在行动）、②时间方向（向哪儿去）、③结尾账目**；然后回答：**为什么同为“想打仗”，一个是演习，一个是复盘**。
::: solution
**①叙述位置**——**苏轼：知州在演习中扮演将军（“亲射虎，看孙郎”“持节云中，何日遣冯唐”——**角色扮演＋等待任命：行动在想象与请命中，现实里他安稳地站在场外**）；辛弃疾：**曾真的在夜里带人抓过人，所以他的叙述位置在回忆的指挥位（“八百里分麾下炙，五十弦翻塞外声，沙场秋点兵”——**军中程序细节精确到像值日表：细节的把握度暴露了经验等级**）；②**时间方向**——**苏词向前（盼遣、望西北“会挽雕弓如满月”）**：期待式**；辛词向后退到梦中再一步跌回（“了却君王天下事”在梦里已完成，**醒来只剩“可怜白发生”这一笔现金流**）；③**结尾账目**——**苏词的结尾是未兑的支票（豪气是信用额度）**；辛词的结尾是坏账确认函**（**梦里的胜利不产生折旧，现实的衰老产生全部成本**）；**总判**——**演习与复盘的分界：**苏轼写“我想去”，辛弃疾写“我去过”：前者的豪迈来自可能性，后者的豪迈来自不可追——“可怜白发生”五个字之所以是宋词最重的结账语，因为它是唯一不能用修辞付现的那一种。
:::
:::

::: intuition 豪放是冻结资产的替代性提现 {#int-tixian}
**“苏辛”合订本的利润与成本**（**把苏轼与辛弃疾捆成“豪放派”（明清词论到近代教材的层累，第 2 课已破一处）——**合订利润归教材，成本归理解：苏轼是士大夫的扩容实验，辛弃疾是被拒者的事功文体：一个有执照，一个在申诉（两人的“豪”差着一个身份距离**）；**他的产量与处境**（**传世词六百余首，宋人之冠（通说量级）——**高产与被闲置是同一件事的两面：宋代给失意文官的补偿是时间（俸禄＋祠禄＋不许签书：政治的禁用期就是文学的生产期——“贬官是隐形主编”在本章升级为“闲居是隐形生产线”（第 2 课黄州条目续费**）；**“掉书袋”的两面审计**（**宋人已有“好用事”之议（通说脉络）——辩护：**密不是病，密是焦虑：一个只有先例能打动当权者的时代，抒情必须携带文件（第 7 课语言三档：他把词的档拉到了公文包那一档，代价是失去一部分读者，收益是留下全部证据。
:::

::: history 一位申诉者的一生 {#sec-shengping}
**1140** 生于金占济南历城（**在金治下受学（通说：蔡松年、党怀英一系北士文风的影响脉络）——**他的文化口音里有北方：后来南宋文人嫌他“硬”，那是他的口音不是他的毛病**）；**1161—62 耿京起军、缚张安国南归（二十一岁：履历顶点在起点——此后六十年都在试图追上自己的十七岁前史）；1170 《美芹十论》；1179 《摸鱼儿》（“君莫舞”：言路以隐喻方式营业”）；1181 起 落职闲居带湖（约十年以上：“稼”字自此成为笔名：把退休改成职业（“稼轩”的自嘲是修辞学上的抢注：先把自嘲说尽，嘲笑就失效了（第 16 课“把渠道写进语法”的反向操作：把失业写进号））））；1192—1203 瓢泉居（词产量高峰：宋代最好的乡村词与被冻结的战略家同在一个屋檐下）；1203—1205 出仕又去（为韩侂胄起复：主战派需要用他背书，他需要借路出兵——双方都只出半场（这段公案后来成了他身后的名声污点之一，通说脉络））；1205 京口词（《永遇乐》《南乡子》）；1207 卒（通说：临终呼“杀贼”——传说层再次出现（第 1 课分层条款）：这一层不证明事件，证明所有人都不相信他会安静地死。
:::

::: warning 辛词四坑
**“爱国词人”的邮票读法**（**先贴主题再读句子，于是《西江月·夜行黄沙道中》也要找抗金隐喻：**寄托读取的边界是作品系统里是否存在稳定姿势，不是评论者需要主题（第 15 课“过度诠释”的红色版**））；**豪放＝大声**（**把风格读成分贝：其《祝英台近·晚春》一篇历来被认为“昵狎温柔，魂销意尽”一路（元人评语，传说—评点层通说存之）——**一集之内两种音量：用“豪放”统一他的音量，等于把他的抑郁当伴奏**））；**用典当学问炫示**（**辛词用事多被读成书袋或读成学问：**先问功能：这份材料是弹药、先例、还是免罪符（同一典在不同段落里功能不同）**）；**忽略北人身份**（**只把他当南宋词人，等于删掉他半本档案：**他是金朝长大的南宋官员，他的“恢复”不是口号，是口音、亲族与不可译的乡愁（他的北地经验在江南词坛是稀缺资产，也是终身的政治风险（归正人条款）**）。
:::

::: exercise 反转结构 {level=1}
仿《破阵子》写一段 60 字的“圆满—取消”：前若干句全力完成一个计划（考试、项目、比赛任选），末句一笔作废；自评：**作废句有没有动用具体成本**。
::: solution
判分：**前段必须真的写成功**（**打七折的圆满作废时无痛感：**兑现越彻底，取消越响**）；**作废句须含不可修辞的成本**（**年龄、病历、账单——“可惜没成功”是叹词，“可怜白发生”是账目（第 3 课证据学的练习版。
:::

::: exercise 为策论找听众 {level=2}

::: solution

::: exercise 小论文：武力的通货膨胀 {level=3}
写六百至一千字，评“**一个人把武力值全数投入文学，通常是因为武力的账户被冻结：豪放不是风格，是替代性提现；用典不是学问，是找不到现时听众的人向历史招标——所谓豪放派的全部壮丽，建立在帝国拒绝给一份策论盖章的那个下午**”。须调用：**策论利息**、**归正人身份条款**、**以文为词四技术**、**反转结构**、**闲居＝隐形生产线**、**寄托读取边界**至少六项；并裁决：**文学是否永远是政治失利的再就业——你须举一个“反例”（在顺境中写作且写得好的宋人）并说明该反例的效力边界**。
::: solution
判分点：六项机制（**换汇、身份、公文技术、作废句、时间补偿、隐喻言路**）；裁决（**参考：反例候选——晏殊（宰相词，第 1 课）效力边界：他的“不给出事故”恰是顺境的文体学，可证“顺境也能写”，但也证成另一条：**顺境写得从容，逆境写得可核对；文学史的信用偏好在长期上偏向后者（这就是辛弃疾的六百年股价**）；结论若能写“**帝国拒绝盖章的那下午，不是文学的幸事，只是文学的机会：机会不等于幸事——把所有苦难都写成才华的人，应该被要求补一张成本清单”，即 A。
