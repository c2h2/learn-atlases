---
title: "北宋前期词"
---

唐代文学课在安史之乱后落幕，本课从一场太平盛世的宴席重新开席——**词（曲子词）本来是歌场里的东西：燕乐配上长短句，酒令催出第一个作者群；宋初要讲的，是这种“宴席文体”如何被书房接管，而接管者又如何被码头夺回去**。

## 定义：一种文类的生产线 {#def-shengchan}

::: definition 宴席、歌者、文本 {#def-yanxi}
**初宋词的三件设备**（**①表演现场**（**酒筵、歌席、节序宴集：词的篇幅由宴席时长定，上片待歌、下片劝酒的结构残留着程序单（**《醉翁亭记》的“宴酣之乐”是散文版，词的“怅望立苍苔”是它的散场版**））；**②传播机制**（**口传＋抄本：柳永词“凡有井水饮处，即能歌柳词”（叶梦得《避暑录话》所记通说）——**一句时评，写尽了传播学的全部要素：覆盖网（井水=生活动线）、用户（饮者）、载体（歌者之口）**））；**③作者处境**（**宰相晏殊与小吏柳永同写一种文体，处境差着天壤——于是文体内部长出了两个审美政府（**第 15 课“场”的现场：同一种货币，两种信用**））。**制度的定盘星**（**宋初沿五代设教坊、置大晟府（徽宗崇宁年间）掌乐：国家既管雅乐也管俗乐的声音库存——**词牌的“格”从此有了官方副本：填词从“依声”慢慢变成“依谱”（第 14 课声律学的宋分号**）。
:::

::: definition 小令的语法 {#def-xiaoling}
**唐五代的遗产**（**《花间》的闺阁语汇＋南唐的士人深情：晏殊《珠玉词》接的是冯延巳的线（**“无可奈何”一类软语里的理性，是他的口音**）；**小令的体裁合同**（**短、藏、留白：四十字里不许出现一段议论——**它的文类亲戚是绝句，不是赋；于是初宋词的“深美”是配额制的：感情必须经过调度（schedule）才能上台：一曲《浣溪沙》上片排景、下片放情，像宰相批公文：先例一定，准了**）。
:::

## 书房宰相与奉旨词人 {#def-liangfu}

::: definition 晏殊：以不动写动 {#def-yanshu}
**《珠玉词》的从容**（**“**无可奈何花落去，似曾相识燕归来**”——**对仗与虚词的化合：一层惜春、一层再来，两层的落差被平衡术抹平（宋祁称赏其“对”，本联本事即载于时话——只取通说）**；**宰相的写法是“不给出事故”**（**他的词里没有贬所、没有离别的原因、没有姓名：**痛苦被处理成天气——这就是“富贵气”的真身：不是有钱，是有底气不把话说完（第 15 课“未定点”的阶级性：留白是奢侈品，柳永就白不起来**））；**书房经济学**（**门生故吏满天下，词是余事（“**不为无益之事，何以遣有涯之生**”——宋人相传之语（笔记系统）——**此句可作全朝词学的免责声明：词的“无益”恰是其自由的前提：官方身份与私人文体分账，两本账都干净）。
:::

::: definition 柳永：奉旨填词的算法 {#def-liuyong}
**身份事故**（**应进士举，仁宗批“且去填词”，遂自称“奉旨填词柳三变”（通说：见宋人笔记）——**一次拒信改成一个笔名：体制的否决被他自己转成品牌（第 16 课“执照”故事的宋初版：不给执照，就自印**）；**慢词的技术革命**（**长调＋铺叙＋市井语：《望海潮》写杭州“**有三秋桂子，十里荷花**”——金主完颜亮闻歌起投鞭之志的传说（罗大经《鹤林玉露》通说），正好说明这种词的传播力：**它不是给唱和用的，是给城市听的**；《雨霖铃》“**杨柳岸，晓风残月**”与晏殊的“小园香径”之别：**一个是码头的时间表（今宵酒醒何处），一个是书房的日程表（夕阳西下）；前者给离别排了小时，后者给闲愁排了年**））；**“俗”的审计**（**“词坛以为病”的批评史事实（通说：晁补之、李清照一路讥其“词语尘下”）——但“尘下”正是他的定位策略：**士大夫写“情”要保身份，柳永写“情”只保市场（第 15 课“文类=协议”：柳永单方面改约，读者全体到场**）；**双账本人物**（**传唱极广而士评极低，是文学场的常态案例（**布迪厄兑换所两枚奖章：市场畅销=圈内贬值的担保：柳永两样都拿了，所以文学史必须替他翻案两次：一次由苏门，一次由王国维**。
:::

::: definition 欧阳修：分账的专家 {#def-ouyang}
**一人两面**（**古文运动领袖与《六一诗话》（中国首部以“诗话”为名的批评体——**把诗论从序跋里解放成随笔：批评的文体发明**）+ 词集《醉翁琴趣外篇》的艳与《六一诗话》的雅并存（**宋人于其艳词早有真伪之疑：混入他人词目的公案——**文集是滤网，词集是下水：同一作者的两套账本，古人比我们更懂分账**）；**“诗余”的执照**（**词为“诗余”的通说观念在宋人语中成形——**这不是贬值，是免税区：诗管言志（官方账），词管言情（私人账）：文体分工=人格合规方案（第 15 课文类合同的道德版**）；**交游与词坛生态**（**幕府、同年、后进的唱和网：张先以“云破月来花弄影”获“张三影”之目（通说：本句及“娇柔懒起，帘压卷花影”“柳径无人，堕絮飞无影”本句自举——**读者给你起外号，是传播的最低成本营销：宋人已懂标签化**））。
:::

::: example 一场宴席的文体分配 {#ex-yanxi2}
假设你在至和年间的汴京为欧阳修的寿筵做“节目总监”，可用三位作者各一首：晏殊《浣溪沙》（一曲新词酒一杯）、柳永《望海潮》、欧阳修自己的一首《朝中措》（送行）。请排定演出顺序并写串场词（各 40 字），说明：**每首在宴席的哪个“程序”上、对哪拨听众、触发哪种身份**。
::: solution
**参考排法**——**①开场《望海潮》**（**程序：待客；听众：全场；身份：本市自豪感——用柳永的码头爆款作公共背景音乐，因其“赋体”铺排能压场：但避开其恋情慢词，防止席间“尘下”风险（**选柳永的哪一首，就是选他的哪一面：作家的形象管理在选本里，不在自述里**））；**②中场晏殊《浣溪沙》**（**程序：行酒；听众：上宾；身份：士大夫的共有修养——“无可奈何”一联把季节感变成身份接头暗号：**听懂对仗的人自动入会（第 15 课“隐含读者”的阶级门**））；**③收场欧阳修《朝中羡》**（**程序：送别；听众：主角本人；身份：庆历余人的政治乡愁——“平山栏槛倚晴空”的堂署语，把寿筵轻轻推到“功名”话题上，**给主人一个既不受贿赂也不失礼的台阶**）；**串场原则**（**先公共后私人、先城市后书房、先热闹后余味——宴席的结构学就是文体的结构学（词的“应歌”本性在此显形：**不是我们选词来配程序，是程序生来就长着词的形状**）。
:::
:::

::: intuition 承平是一种审美 {#int-chengping}
**初宋词的“富贵气”不是题材，是时制**（**真仁之治的长期太平＋城市商业的兴起：**没有事故的语言，就长得从容（晏殊）；有事故也不慌，因为制度会兜底（欧阳修）——两种从容都是承平的利息（对照第 16 课：战乱一来，词的利息立刻清零：李清照的下半生就是这条曲线**）；**“诗余”的双重身份**（**正因为不被当成正经文学，词才敢说正经文学不许说的话：**低压线路能过交流电（第 15 课“文类的年龄等级”：新文类靠不被信任获得实验自由**））。
:::

::: history 从歌场到选本 {#sec-xuanben}
**960s—1000s** 宋初沿五代教坊与歌曲库存（**《花间集》后蜀广政已编：中国第一部词总集（通说）——**选本先于批评：先有“什么算词”的库存，后有“什么该算词”的辩论（第 15 课制度论：经典化从目录学开始**）；**1000s—1050s 柳永专力慢词与市井传唱（井水即传播；同时开始出现“词坛以为病”的士大夫审计）；1040s—1060s 诗文革新与词为“诗余”的分工定型（改革派在散文里胜利，同时在词里放权——一场运动两条战线，谁也不抢谁的粮（第 2 课“文体政变”的另一半）；1057 欧阳修知贡举（评分标准改变文风：古文靠科举定于一尊（第 9 课“考试塑造文体”的宋代第一轮）；1102 大晟府（提举官修旧制、搜补遗缺——国家给流行歌曲做版本库：词牌的“格”有了官方副本）；1140s—1170s 唱和与选本（《乐府雅词》类选本编次（通说：曾慥《乐府雅词》）——雅正的标准写进选目：不评论，只删除：审查的最高形式是目录（第 2 课定义权的选本版）。
:::

::: warning 初宋词四坑
**用“进步”讲风格**（**柳永“发展了”词、晏殊“保守”——价值排序冒充机制描述：两人是两条产品线的定位，不是快慢车（慢词不等于“更高级的阶段”：周邦彦之后小令仍在写**））；**以自述当履历**（**“奉旨填词”是传说层（笔记系统），正史无载：本课按通说标出——**宋人笔记是词学的史料，也是词学的地摊：引用前先查它在哪层记账**）；**忽略“分账”制度**（**把一个人的诗与词读成一个人心史：宋人自己会反对：**文集与词集是两套账本，混账读等于读假账（欧阳修艳词的真伪案正是后人混账的产物**））；**把“富贵气”读成内容**（**晏殊的从容是时制与身份的合成品：读成“性格”就把历史读成了心理（第 15 课“风格=选择函数”：他不写事故，是他的配额，不是他的天性**）。
:::

::: exercise 两账本对读 {level=1}
选欧阳修（或晏殊）同一时段的诗一首、词一首，做**对读表**：题材／自称／收件人／可说不可说；据此回答：**为什么某事只能出现在词里**。
::: solution
判分：**“可说不可说”一栏要写制度不写气质**（**诗有赠答对象与言志义务，词的演唱者替你分担了作者责任（第 16 课杂文“代言”的宋代版**）；结论禁“词更真诚”（**要说出真诚的技术条件：是谁在替你受审**）。
:::
:::

::: exercise 为柳永定位 {level=2}
假如你是汴京瓦舍的“节目策划”，用《望海潮》《雨霖铃》各写一段 60 字的推荐词，面向两种听众（行会商人／落第士子）；并自评：**哪一句是在消费作者名声，哪一句是在制造需求**。
::: solution
判分：**两种文案的“卖点词库”应几乎不相交**（**商人买“都市自豪感”（三秋桂子），士子买“身份焦虑”（杨柳岸的失意感）**）；**自我审计**（**“奉旨填词”的名号在两种文案里的用法：对士子是认同的暗号，对商人只是招牌——同一个标签，两种现金流**。
:::
:::

::: exercise 小论文：太平的利息 {level=3}
写六百至一千字，评“**初宋词的从容是按天收取的利息：承平付本金，身份付保险，‘诗余’付免检——三样一停，这声音立刻改变：所以读晏殊的从容，要读成读一张利率表，而不是读一颗心**”。须调用：**宴席—传播—处境三件设备**、**小令的配额制**、**“不给出事故”的写法**、**柳永的双账本与市场定位**、**诗余免税区**、**笔记史料分层**至少六项；并裁决：**“国家繁荣提升文学品质”在初宋词这个案子上成立还是反证（你须给出“若南渡后，同一批设备会发生什么”的推演作为对照实验）**。
::: solution
判分点：六项机制（**设备、配额、留白、市场、免税、史料层**）；裁决（**参考：成立面——覆盖网（井水）、演出经济、闲愁配额皆承平之赐；反证面——承平也供养了“不给出事故”的自我审查，且真正的语言扩容由被排斥者完成（柳永）：**繁荣不提升品质，繁荣提升流通；品质常常发生在流通不良的账户里（对照实验：南渡后同一设备——宴席改成流亡、传播改为题壁与唱和残本、身份改成遗民，于是“留白”瞬间失效，李清照的《词论》与《金石录后序》把配额制打回事故清单：利息停了，本金还在，利息就只是修辞**）；结论若能写“**读承平之词，是在读它的账单：每一句不动声色，都有一项没被付钱的损失；初宋词的美学，就是不肯付的那部分”，即 A。
:::
:::

::: summary
生产线归档：设备（**宴席、歌者、处境——两种审美政府同写一种货币**）、小令（**配额制与留白的阶级性**）、书房（**晏殊不给出事故**）、码头（**柳永：一次拒信改成一个笔名；给离别排了小时**）、分账（**诗余免税区与两套账本**）。方法一句话：**先问这首词在宴席上的座位，再问它在作者账本上的科目**。下一章：把免税区改成自贸区的人——苏轼。
:::
