---
title: "方言的分区"
---

上一章说明三条尺子会互相打架；本章给出这门手艺真正用过的那一把——**分区不看两种话“像不像”，看它们的音类分合是否平行；也就是说，方言学比的不是词表，是账目的科目表**。

## 定义：三种分区法 {#def-fenzoning}

::: definition 谱系、类型与区域 {#def-sanfa}
**①谱系式**（**问“哪一种先分开”；**它给出一棵树（②**类型式**（**问“特征是否相同”；**它给出一张特征表（③**区域式**（**问“哪些特征在同一片地方一起出现”；**它给出一束同言线（**通说脉络**（**汉语方言的主流做法介于二与三之间，而它的具体工具是音类分合的比较：**不比较“这个字你怎么读”，而比较“这一类字与那一类字在你那儿是分是合”（**为什么用这个工具，本章给三条理由（**其一，读音相似可能是巧合或借用，而**成套的分合难以偶然相同**（其二，分合关系可跨方言逐字核算，**它是可复核的**（其三，一条分合的完成度本身就记录了变化的时间（**这一条与“同源的两种完成度”接上（**一句话记住：**词是天气，音类是分合的气候。**
:::

::: definition 为什么是音系而不是词汇 {#def-yinlei}
**词汇的问题是它可以被借**（**一个词在整个东亚旅行而不必有任何亲缘关系（第 9 章借词账（**语法与音类相对稳定而词表流动，所以词汇相似不能证明同源，最多证明接触（②**音类分合是一种“负证据”**（**两种方言在同一批字上做出同样的合并、又在同一批字上保持区分，这种一致性很难用借用解释，因为借词不会整齐地只填进合并后的那一格（③**通说脉络：以音类的分合而非语音的相似作为分区依据，是二十世纪后期方言学的方法共识（**本课补一条限制，这条限制在考试中常被忽略（**音类分合证明的是“它们经历了同一场变化”，不能证明“它们在此之后没有分开”；**所以分区图上的每一块，都是一组变化的完成范围，而不是一个共同祖先的遗产（**这就是本章的论点：**方言地图是一幅变化地理图，不是一份家谱。**
:::

::: definition 七区、十区与改线 {#def-shiqu}
**通说脉络**（**1950 年代的全国方言调查配套提出一个七区草案：官话、吴、湘、赣、客家、闽、粤；1980 年代的一部语言地图集把它改为十区：**增晋语、徽语与平话（**第二版又移动了若干条线（**本课逐条读这次改动（**①晋语从官话分出**（**通说归于一位音韵学家的提议，其标准简洁到近乎任性：**这一带的方言保留入声**（**而官话的定义性特征之一恰是入声消失（**一次改动说明：一个特征足以改一块地图，只要这个特征被选为定义项（②**徽语独立**（**争议最大的一区；**它的位置在吴语与赣语之间，特征是一部分像吴、一部分像赣，另有一些自己的创新（**反对者说它是过渡带而非独立单位（**本课的判读：过渡带是不是一个“区”，取决于分区为了什么用——**为了修词典，过渡带值得单独一页；**为了画政策地图，它会被人抹掉（③**平话的归属**（**广西几种变体，与粤语、官话与彼此之间的关系长期未定（**这是一个尚未结案的案例，而它正是本章希望你去看的：**一个分类还在动的时候，你能看见它的骨头（**通说脉络：客家与赣语的关系亦有“客赣合一”与“分别成区”两说（**这两说的分歧点不在事实，而在“哪一次迁徙应被当作分隔事件”——**历史假设直接进入分类标准，这就是本章所谓的加权之争。**
:::

::: definition 官话的内部分区 {#def-guanhua}
**通说脉络**（**官话常被再分为若干大区，常见的说法是八块：东北、北京、冀鲁、中原、兰银、西南、江淮、胶辽（**分区线索主要是**入声字派到哪个声调**（**同一个中古来源在甲区并入去声、在乙区并入阳平，这就是分合不平行的硬证据（**通说脉络：西南官话覆盖长江中上游与云贵，是近代移民的结果（**江淮官话则同时有两个特征：入声残留与若干韵类与北方不同；**它是“官话内部最南方的一块”，也是官话与吴、赣、徽接触的前沿（**本课给一个读图训练（**看一张官话分区图，问三个问题：**①省界是否被反复尊重（**若线总与省界重合，要怀疑分区受了行政资料的影响；②线的密度是否等于铁路与河流的密度；③大片内部无差异的区域，是调查不足还是真的均质（**第三问的答案常常是调查不足——**本课的这条怀疑规则，请你在看任何地图时使用（**地图的分辨率等于经费的分辨率，这是本章唯一一句经济学。**
:::

::: example 用分合划区 {#ex-fenhe}
下表给出六个调查点对三组字类的处理方式（“分”表示两类字读音不同，“合”表示相同**）：

| 点 | 古全浊平声 vs 去声 | 入声是否独立 | 山摄开口一二等 |
|---|---|---|---|
| 甲 | 分 | 独立 | 分 |
| 乙 | 分 | 独立 | 分 |
| 丙 | 分 | 派入其他三声 | 合 |
| 丁 | 合 | 派入其他三声 | 合 |
| 戊 | 合 | 派入其他三声 | 合 |
| 己 | 分 | 派入其他三声 | 分 |

请按“分合平行”划区，并说明你的划分与按“听感相似度”可能有什么不同。

::: solution
**第一步：挑定义项**（**三项中，入声独立一条最有区分力，因为它是**一条变化的完成度**，而另外两条可能是渐进的类型差异（**于是：甲乙自成一区（**入声独立**）；丙丁戊己为一区（②**第二层**（**在大区内再用其余两项：**丁戊（两项皆合）**、**丙与己（各项不一致，属过渡（**己尤其尴尬：入声已派入而他声仍与甲乙同——**这就是本章要教的读法：己不是一个“混合的方言”，它是三条变化以不同速度经过同一个地方（**第 9 章词汇扩散在此直接可见：**变化不是一次完成的，所以地图上的边界数量取决于你选了哪几条变化（③**与相似度的差别**（**若按“听感像”来分，己可能被判给甲乙，因为它的声调格局听起来近；**而分合平行把它划到大区一侧：它已完成入声的消失这一条最重要的账（**本课的结论写法（**任何分区方案都应写明三件事：**用了哪几条音类分合、各条权重如何、以及哪些点因为落在过渡带上而无论怎样划线都会反对（**第三项就是本章的诚实条款：**一份不写反对意见的分区报告，是不可信的。**
:::
:::

::: intuition 同一个县城，三种分区 {#int-san}
**现象**（**同一地的方言在不同著作里被归入不同区；**说话人自己则说“我们这里的话谁都听得懂”（**三条解释（**①特征表不同**（**每位学者带的清单不同：**有人看入声，有人看浊音，有人看韵摄分合（②权重不同**（**同一个特征表，权重也可以是政治性的：**若把“移民史可解释”当作权重，则一个区会因为一次迁徙传说而被合并或拆开（③**点的密度**（**方言图由有限的调查点插值而成；**在两个稀薄区之间画出的那条线，其实是“这里没人调查”的记号（**本课给一条读论文的规则：**先看它的点在哪里，再看线在哪里；线穿过空白区时，它表达的只是作者的犹豫（**这三条在语言学里成立，在社会科学的任何分类里也成立（**逻辑课那句“分类即主权”在此得到一个技术版本：**主权的行使方式，是选特征表。**
:::

::: history 六十年三次改线 {#sec-gai}
**1930s—1940s**（**现代方言调查起步，点集中于东部与沿江（**通说脉络：**本课的第一处提醒：**中国方言图的西部轮廓，长期是外推出来的（②**1955—1956**（**配合共同语推广与文字改革，全国方言调查启动并提出七区草案（**通说脉络：**分区与政策同年的这一事实，不是缺陷而是语境：**调查队同时承担“摸清语言状况”与“评估推普难度”两项任务（③**1960**（**一部方言概要以七区框架写成教科书，影响数代人的分区直觉（**通说脉络（④**1980s**（**以音类分合为标准的讨论推动了晋语与徽语的提出；客家与赣语关系另有合区一说（**通说脉络（⑤**1987／2012**（**语言地图集初版定十区，第二版改线（**通说脉络：**改线本身是最好的教材：**对照两版，你会看到哪些点在中间被补测（⑥**2015 起**（**语言资源保护工程大幅增加调查点；**本课的预测（**也是它可以被检验的一句：**点密到一定程度，现在这些“区”会全部失效，取而代之的是若干条特征的独立分布图（**这正是本章论点的可反驳形式：**如果分区是变化地理图，那么它终将变成一张动画（**一位老派学者会反对这句话，而反对得有道理——**因为可沟通的分类也是知识。**
:::

::: exercise 小论文：发现还是发明 {level=3}
写六百至一千字，评“**分区是发明不是发现，但它不是任意的发明：数据只能否决方案，不能生成方案。一部好的方言地图集之所以值得相信，不是因为它画对了，而是因为它把选特征、定权重、设定点这三步全部公开，让反对者能够精确地指出自己反对哪一步。坏的分类则把自己的前三步藏起来，只把最后的线示人，于是它看起来像自然**。须调用：**三种分区法**、**分合平行**、**晋语一例**、**官话八块**、**线的分辨率与经费**、**过渡带**至少六项；并裁决：**“分类即主权”与“分类要可反驳”是否冲突（若一项分类被政策采用，它的可反驳性会发生什么变化**。

::: solution
判分点：六项机制（**三法、平行、晋语例、八块、分辨率、过渡带**）；裁决（**须写出一个机制而非格言：**候选：分类一旦被采用，反对的成本就从学术转到利益——**学者反对一个方案只需另举特征，而一旦被划入某区的群体反对，它会牵动教材、经费与身份，于是反对者减少而“沉默的一致”增加；**这就是可反驳性的社会学条件（**一个分类的可反驳性依赖于有没有人付得起反驳的成本**）；也应给出制度补救（**候选：分区层级上保留“未定”这一类，并让改线必须附说明；公开原始记音；以及把分区与资源分配脱钩，使反对分区不再等于反对拨款——**判卷看这三条是否被想到，而不是看你站哪一边**）；结论若能写“**所以本章的结论不是‘分区无用’而是‘分区要留缝’；一门学科成熟的标志之一，是它的地图上写着未定**”，即 A。
