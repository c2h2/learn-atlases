title: "官话方言"
---

上一章的分合表在本章有了内容——**官话是汉语里覆盖面积最大、内部差异相对最小的一块，而这两件事是同一件事：它的均质不是天生的，是被道路、军队与移民摊平的**。

## 定义：一个语区的两条特征 {#def-gd}

::: definition 入声消失与全浊清化 {#def-tezheng}
**通说脉络**（**官话的两条最通行的判断特征（**①**古入声字大多不再有塞音韵尾**（**它们被派入其他声调；派入哪一声，正是官话内部划分的主要依据（②**全浊声母清化，并按声调条件分成两路**（**通说：平声送气、仄声不送气；**这条规则在官话里执行得最彻底，而它正是上一章“完成度”的样板：**同一条清化，吴语没走完，若干边境方言只走完一半（**本课补两条常被忽略的特征（**③**山咸深臻曾梗摄的韵类合并程度高**（**北方许多点元音系统比南方简化，但补偿性地发展出更多的复合元音与鼻音韵尾的对转（④**儿化与轻声丰富**（**这是官话最靠韵律的特征；**它与词法相互作用：**“头、子、儿”一类后缀在北方产出率高，而它们的读音又影响声调（**通说脉络（**一条读法上的提醒（**官话并不“缺少入声所以简单”；**它只是把负担从韵尾搬到了声调与韵律上（**这是第 3 门课“省力与清楚的均衡”在方言层的应用：**没有哪种方言是简化了的，只有把复杂度放在别处的方言。
:::

::: definition 八块怎么分 {#def-bakuai}
**通说脉络**（**官话常被分为若干大区，常见为八：北京、东北、冀鲁、中原、兰银、西南、江淮、胶辽（**三条划分线索（**①入声派入何调**（**西南官话多数把入声整批并入一个调类（**这是它内部出奇一致的原因**）；江淮官话则保留入声，因而成为“官话里的例外”（②**几组韵类的分合**（**如曾梗二摄与深流的读法差异，常被用来切开中原与冀鲁（**通说脉络：**这些分合都是上一章那张表里的行；**同一张表换一批点就能重画（③**移民史**（**西南官话的广域分布是明清两次大迁移的结果（**通说：明初以南京一带人口迁入云南、贵州诸卫所，清初“湖广填四川”；**这两件事解释了为什么相隔千里的城市口音相似而它们的乡村口音彼此不同（**本课称此为**方言的飞地效应**（**城市说移民话，乡村说老话；**于是官话区内出现一种奇特的双层格局：**行政网络是一种口音，农业腹地是另一种（**第 4 章吴语里的城乡差别在此以最大尺度重演。**
:::

::: definition 均质是怎么摊出来的 {#def-junzhi}
**三条机制（**①驿路与运河**（**一种口语沿运输线扩散，其结果是一条带状分布而不是块状分布：**地图上“西南官话”那一大片，其实是几条水路与驿路的加粗投影（②**驻军与屯田**（**通说脉络：明代卫所制度把成批北方人口安置到南方各地，形成方言岛与“军话”一类的变体（**这一类点在本课第 7、10 章还会遇到，它们是分区图上最难看的斑点——**而难看的斑点恰恰是历史证据：**一个孤立地说着近似北方话的村子，是一次有档案可查的迁移的存根（③**科举与官场**（**“官话”这个词本身指的是官员之间用的口语（**通说脉络：明清以“官话”称跨地域的通用口语，官员须能在公务中互通（**本课强调它的社会学含义（**官话先是行政与商务的口语通用语，两个世纪后才被制成音系表与考试（**第 7 章会给出这条时间线；**此处先记下本章的判决：**共同语从来不是被规定出来的，它是先被使用、后被追认为标准的；**追认文件的作用是让人相信它一直存在（**这一句与第 8 章“标准语是基础设施”连读。
:::

::: definition 为什么它内部差异小 {#def-chai}
**一个事实与两种解释**（**官话区跨越极大的地理范围而互通程度高，这在世界范围内都少见（**①**分层较新**（**通说脉络：北方方言的多数内部分歧发生在中古晚期之后，分化时间短（**注意这一条与“移民摊平”难以分开——**它们是同一件事的两种说法：**每一次大迁移都重置了分歧的钟（②**接触与再统一**（**反复的战乱、移民与行政整合不断把差异抹去；**方言学上称这种区域为“水平化”区域：特征在广大范围内被拉平（**通说脉络（③**也有例外，而例外最有价值**（**晋西南、江淮一线、以及若干屯戍方言岛，都是官话内的“非均质斑块”（**本课给一条研究建议：**学官话方言，不要先去学它的中心，要去学它的边缘：**边缘保留了被拉平之前的层次，而边缘恰好是分类学上有争议的地方（**这就是本章对“争议即资料”这句话的具体用法。
:::

::: example 一个词走遍官话区 {#ex-ci}
“完蛋了、没有了”这件事，在不同官话点上的说法差异很大。请调查或推测下列几处的形式：**北京、济南、西安、成都、南京、银川**；然后回答：**为什么这类词的差异比“山、水、人”这类词的差异大得多**。

::: solution
**调查提示**（**这类词是口语底层词，方言词典与地方语料里常见；**形式差异可能包括不同的动词、不同的否定与不同的体（**要点不在标准答案，而在解释（**为什么差异大（**其一，**基本动作与状态词的日常使用频率高，变化也快**（**高频词是形式的磨损区（②其二，**这类词不在书面语里，因而没有正字法的锚**（**一个字一旦被写进教材与考试，它的读音就有守护者；**口语词没有（**第 2 门课“文字是标准的守夜人”在此得到一个反面推论（③其三，**这类词最容易互相借用又被替换，因为它们携带地区身份**（**人们会故意说本地说法来表示自己是谁（**第 8 章“立场”那条（**判分：**能写出“没有书面锚”这一点即为 A**（**它同时解释了一个更大的现象：**汉语方言之间语法与常用词的分歧，比文献语言的词汇分歧深得多；**所以你在读方言材料时，凡遇到一个字被随意借用记音，那正是没有标准的证据——**而那种随意，恰好是本章要找的年代层。
:::
:::

::: intuition 你的口音是哪一条线上的 {#int-ni}
**一个可自测的练习**（**把自己或家人的口音按本章四条特征过一遍：**入声字读成什么、全浊字送不送气、儿化用不用、“给、看、拿”这三个词怎么说（**四问之后你会知道两件不太愉快的事（**其一，你的口音不是“普通话加杂质”，而是一条有来源的线；其二，你以为是自己的错误的东西，可能是整个片区的一致特征（**本课对第二件事的解释（**学校教的是一种抽象标准，家里传的是一个片区特征；**两者冲突时，被记为“错误”的一方永远是后者（**这就是为什么学方言的人常常经历一次小小的羞耻然后释然：**羞耻是因为原来那不是缺陷，释然是因为它有名字、有地图、有别的几千万人说它（**这一条我写在这里，是因为本课程的读者多半正站在两者之间（**第 1 门课那条“描写不是赞同”在此变成对个人适用的一句：**先描写，再判断——对别人，也对你自己。
:::

::: history 一种通用语的三次改名 {#sec-gai}
**中古以后**（**北方口语在韵书系统之外生长；**通说脉络：宋元之际的北方音已具备若干官话特征，诸宫调与元曲用之（**《中原音韵》一类书为它留了账（**第 3 章汉语史会展开（②**明清**（**“官话”成为跨地域口语的通称；**它是行政与商务的通用语，各地说的官话彼此有别，没有一个人说“标准官话”（**通说脉络：**本课把这段称为“无名标准时期”：**有一个方向，没有一个中心（③**1913／1932**（**一个委员会逐字议定国音，失败后改以北京音为标准（**通说脉络（④**1955／1956**（**共同语以北京语音为标准音、以北方话为基础方言、以典范现代白话文著作为语法规范被定义；**官话作为一个方言区，从此与一种国家语言同名异实（**本课的提醒：**这是中国语言史上最大一次名实重组：**从前说“官话”是一种工具，现在说“普通话”是一种身份（**第 8 章的账户比喻在此有了主语（⑤**1980s 至今**（**方言地图细化，西南官话内部差异被重新描写；同时普及率上升使片区特征向标准靠拢（**通说脉络：**一个正在发生的过程，本课称之为“再水平化”：**这次拉平的力量不是移民而是学校与屏幕（**你此刻说的每一个词都在其中——**这不是哀悼，是一条观察：一种均质正在形成，而它的代价是本地特征变成个人趣味。**
:::

::: exercise 小论文：均质的政治 {level=3}
写六百至一千字，评“**一个大语区的内部一致通常不是自然状态，而是交通、驻军、市场与行政反复摊平的结果；也正因如此，一个语区的边界往往是旧帝国行政边界的化石。当摊平的力量换成学校与屏幕，语区边界就停止移动，转而变成态度边界：人们开始在口音上而不是在理解上划分彼此**。须调用：**两条判断特征**、**八块划分**、**飞地效应**、**无名标准时期**、**再水平化**、**边缘保留层次**至少六项；并裁决：**摊平是否可逆（若不可逆，方言学在做什么——你须给出一个不以怀旧为理由的回答**。

::: solution
