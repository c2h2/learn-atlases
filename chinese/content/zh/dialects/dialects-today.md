前八章教你辨认与记录；本章要问一个更难的问题——**如果一门话不再有人用它挣饭钱，那么关于它的一切善意加起来能顶多少。本章的立场是先算账再谈感情**。

## 定义：转用怎么发生 {#def-zhuanyong}

::: definition 三个阶段与一个指标 {#def-sanjie}
**通说脉络**（**语言转用通常被描述为三阶段：①全区双语，两种话各管一批场合；②共同语进入家庭之外的所有公共场合，方言只剩亲昵语域；③家长不再把方言传给子女（**第三阶段是一个可测量的事件**（**一个常被引用的国际评估框架把“代际传递”列为语言活力的首要因素（**通说脉络（**本课给它一个更锋利的形式（**一门话的命运不取决于有多少人说它，而取决于有多少七岁的人听它被当作默认的称呼语使用（**为什么这条比使用人数更硬：**人数会因人口基数而虚高，七岁孩子的家庭语域不会（**一条常被误读的乐观数据**（**“还有几千万人说”与“十几年后不再传”完全可以同时为真；**这就是本章所谓**“迟发性消亡”**（**一门话在成为遗产之后，通常还能活二十年，足够拍完纪录片与开三次会（**本课要求你以后看到“多少万人仍在说”这类数字时，第一反应是问：**他们说给谁听。**
:::

::: definition 为什么放弃是理性的 {#def-lixing}
**本章拒绝一切把转用归因于“观念落后”的说法，改给三条机制（**①兑换价**（**一种话能换到多少教育、工作与医疗，决定了它在家庭预算里的位置；**共同语在这张表上的价格由考试与招聘确定，而这两处不讨论方言（②转换成本由家庭独自承担**（**入学即需完成的一次转换，没有人报销；**理性的家长因此提前买断（**这是本章最重要的一条：**不是学校禁止方言，而是学校只提供一条轨道，于是家庭被迫做减法（③声望不可分割**（**家长不是嫌方言不好，而是不愿孩子在评估中被记为“有口音的人”（**第 1 章与第 4 章在此合流（**三条机制合起来给出本章的政策判断：**凡是不能改动这三条的措施，都不会改变传递，只会改变关于传递的谈话（**下一节把这句话变成一张表。**
:::

::: definition 记录、象征、领域与机会 {#def-leixing}
**①记录**（**记音、语法描写、词典、有声档案；**几乎必然成功，因为它不需要任何人改变行为；**它改变的是未来人的知识，不是当代人的选择（②**象征地位**（**方言节目、招牌、非遗名录、地铁报站用两种话；**它能提高态度分，通常不改变使用（**本章定律（**与第 5 章那条同源：**象征性支持与实际转用可以同时上升；**当一门话只在纪念它的时候被说，它就完成了向文物的转化（③**占领领域**（**母语或方言课程、司法与医疗场合的翻译、地方行政允许使用；**它确实改变使用，但需要预算、编制与考核让步——**这是它的真实成本，也是它常被换成②的原因（④**改变机会结构**（**让一门话成为某种工作的入职条件：跨境贸易、地方医疗、幼儿教育、区域传媒的本地制作要求；**这是唯一被历史记录证明能扭转传递的一类，而它通常不归语言主管部门管（**本课的核心判断（**前三类改变“关于语言的说法”，第四类改变语言；**而绝大多数方言政策属于前三类，不是出于冷漠，是因为第四类不在发文机关的权限内（**这句话是本门课最难听也最该记住的一句：**一个部门若不能决定招聘条件与课程表，它就只能发表态。**
:::

::: definition 保护不是禁止 {#def-jinzh}
**一个逻辑澄清**（**“保护方言”与“推广普通话”并非零和；**要减少的从来不是共同语的能力，而是必须只会一种话的处境（**三条推论（**①双语不是相加的障碍**（**通说脉络：主流研究不支持“学方言妨碍学共同语”这一常见担心（**本课的中性表述：**如果它是真的，我们应该能在方言区与共同语教学强度之间看到系统的学业差异，而实际观察到的方向并不支持它（②真正的稀缺是时间**（**一周十六小时里塞进两种书写系统，必然有一方被挤到口语层；**这是排课问题，不是能力问题（**把它说成能力问题，就是本章反对的那种偷换（③制度不对称**（**通说脉络：我国有关法规对少数民族使用本民族语言文字有专门条款，而汉语方言不在这些条款的对象之内；**于是“给方言争一门课”在行政语言里没有对应的申请项（**本课对这一事实的价值判断是零：**它只是一个约束条件；**而任何不提它的保护方案，都会在第一年失败于“无处申报”。**
:::

::: example 审计一份保护方案 {#ex-fangan}
下面是某地一份虚构的“方言保护实施方案”的六条：**①成立方言保护工作领导小组；②在电视台保留一档方言节目并增加播出时段；③编撰方言词典与读本；④在部分小学开设每周地方文化兴趣课，学生自愿参加；⑤建立方言有声数据库；⑥要求出租车司机“会用方言问候乘客以提升城市形象”。**请按四类干预归类，并逐条写出它改变什么、成本由谁付、以及它的典型失败方式。

::: solution
**归类**（**①属组织而非干预（**它改变的是文件流转**）；②象征；③记录；④领域（**弱形式的领域**）；⑤记录；⑥象征伪装成机会结构（**③⑤是最诚实的两条**（**它们不需要别人改变行为，且成果可核对；**其失败方式是无人使用（**通说：档案的使用率远低于其建设成本，这是记录工作的固有性质，不是缺点（②的失败方式最典型**（**节目保留而观众老化：它服务的是已经会说的人，而不是正在失去的孩子；**于是预算买到的是“我们做了”这句话（④是本章唯一值得加钱的一条，但它的失败方式写在题面上**（**“每周”“兴趣”“自愿”三个词合起来等于零强制、零考核、零升学关联；**而第 2 节说过，家庭按考核与招聘分配语言；**要让它有效，须改动三件事之一：**计入课程表并考核、与某项实际收益挂钩、或使教师岗位本身要求方言能力（**这三条分别对应领域、机会与编制（⑥是本章的讽刺靶**（**它把语言义务加给一个没有议价能力的职业群体，而不给它任何对应的资源；**要求别人为你的怀旧付费，是象征类干预最常见的堕落形式（①的判断**（**领导小组是文书装置：它使“没人负责”变成“有人发文”；**本课不否定其作用——**它决定预算能否被拨出，也就是决定③⑤能否存在（**判分：**能把六条按“改变语言还是改变说法”分成两栏者，本章 A**（**而这一栏分法可以直接搬到任何一份关于读书、写作、教育或文化政策的文件上——**这是本课给全部十门课的通用工具。**

::: intuition 星期二的下午 {#int-xingqi}
**本课给一条判别式，用来检验任何一项语言保护措施**（**它是否要求某个人在某个星期二的下午，因为不会说这门话而失去某样东西**）；**三条说明（**①为什么是星期二下午**（**因为真正的语言政策不住在仪式上，而住在考勤表里：岗位说明书、课程表、晋升条件、接诊流程（②“失去某样东西”必须是具体的**（**一份工作、一次不被打断的问诊、一个不必找亲戚翻译的窗口；**这三样东西的共同点是有代价（**没有代价的措施是姿态，姿态本身不是坏事，但它不改变传递（③这条判别式也是自我检查**（**本课程让你记音、描写、写论文；**它们都不会让任何人在星期二下午失去什么；**所以记录工作在道德上诚实而在效果上谦卑——**本课认为承认这一点，比把记录称作“拯救”要更接近事实（**第 10 章会给出在这种谦卑之下仍然值得做的三件事（**此处先立一句：档案不是救援，是证词。**
:::

::: history 一边调查，一边统一 {#sec-jinjin}
**1950s**（**全国方言调查与共同语推广同时起步；**通说脉络：**本课的第一处判断：**这不是自相矛盾，而是一项工程的两面：**要知道往哪里推，必须先知道有什么（**这解释了为什么方言学的机构化与推普同岁（②**1982**（**推广全国通用的普通话被写入宪法（**通说脉络（③**1990s**（**有学者以一本书的标题提出“我们不知道为什么语言在消失”这一疑问；**国际组织自九十年代起把语言多样性列为议题，二〇〇〇年代出现濒危语言评估框架（**通说脉络：**本课取其方法不取其分类：**这套框架把代际传递列为第一，恰好把政策从“有多少人说”引向“说给谁听”（④**2000**（**国家通用语言文字法通过，确立通用语言的法律地位并保留方言的特定使用领域（**通说脉络（⑤**2008—2010**（**关于电视与教学语言的公共讨论在广州等地出现，规模为大范围城市运动式表达（**通说脉络：**本课的两点读法：**其一，参与者以城市中产为主，说明方言作为文化资本的时代已经开始；其二，诉求落在频道上而非岗位与课程表上，说明它无法进入第四类干预（⑥**2015 起**（**语言资源保护工程在千余点录音；**同时城镇化与跨地区婚姻比例继续上升（**通说脉络：**本章的收尾判断：**这两件事的方向相反，而它们的强度都在增加；**所以未来二十年我们大概会看到：档案空前完整，使用空前稀薄（**这不是预言，是本章认为最可能的均值（**第 10 章讨论在这样的均值下个人能做什么。**

::: exercise 小论文：能承诺什么 {level=3}
写六百至一千字，评“**语言保护是唯一一种公开承认自己可能失败的政策领域：没有任何政府成功逆转过一次完成中的转用，而失败的例子都以一世纪为单位。正因如此，它的伦理不该建立在‘一定能保住’上，而应建立在两件事上：一是不得用纪念代替选择，二是不得让别人为你的审美付账。剩下能做的，是让愿意说的人有地方说，让想学的人有得学，并把说不好听的那部分也记下来**。须调用：**三阶段与代际传递**、**放弃的三条机制**、**四类干预**、**保护不是禁止**、**制度不对称**、**档案运气与证词**至少六项；并裁决：**如果你只能说服一个部门，你选哪一个，放弃什么**。
