title: "吴语"
---

官话是摊平之后的大陆；吴语是这一章的第一块“未被摊平”的地方——**它保留了一种别处已经丢掉的发声方式，也保留了另一样更麻烦的东西：一套只在成串说话时才存在的声调**。

## 定义：浊声母 {#def-ze}

::: definition 清音浊流 {#def-qingyin}
**通说脉络**（**吴语最常被引用的特征，是它保留了古全浊声母：当北方把一批声母读成送气或不送气的清音时，吴语多地仍读带浊音色彩的音（**而本课程的第一个修正就是这个说法本身（**许多点的“浊音”并非英语那样的纯浊塞音，而是被称为“清音浊流”的一类弛声：**成阻阶段声带不振动、除阻后带气声（**通说脉络：**本课要你把这件事读成一个方法论教训（**一个用了百年的分类说法，可以既在“与对立面不同”的意义上正确、又在“它是什么”的意义上不精确；**方言学里充满这种说法，处理它们的规则是：**先问这个特征是用什么标准测出来的，再问它在哪些点上成立（**第二个修正更重要（**上海市区话的浊音正在弱化甚至并入清音对立（**通说脉络：年轻说话人中区分度下降被反复记录（**于是本章的第一条时间线开始：**吴语最有名的特征，正在它最有名的城市里消失——**而消失的方向与官话一致（**这不是巧合，这是下一节的主题。**
:::

::: definition 声调是单位的属性 {#def-biantiao}
**吴语的第二件难事是连读变调**（**通说脉络：多数吴语点的单字调有七到八个，而实际说话时几乎听不到单字调：**音节组成词或短语时，整串重新分配一套调型（**本课给它一个精确的表述（**在吴语里，声调不是字的属性，而是韵律单位的属性（**这一句应当与第 3 门课那句“括号即主张”一起记：**任何把声调标在单字上的教材，都在教一种不存在的说法；**它教的是一套抽象的对立，而不是一门话（**通说脉络**（**变调的两类模式常被称为前字主导与后字主导：**前者整串调型由前字决定，后者由末字决定（**其理论意义被语言学界反复讨论，因为它说明**音系规则可以跨词界运作，而它对语法的边界并不敏感（**这是吴语在现代语言学理论里地位特殊的原因（**它给句法课那条“结构歧义是层级证据”提供了一个音系的对应物：**变调的行为只能由一个更大的单位解释，而这个单位往往不等于任何一个语法成分。**
:::

::: definition 六片与它们的差异 {#def-liupian}
**通说脉络**（**吴语通常分为若干片，常见说法为六：环太湖的太湖片、台州、瓯江、上丽、处衢与宣州（**三条读法（**①太湖片是中心，其余是边缘**（**而边缘保留了中心没有的特征：**瓯江片与处衢片的韵类分合、词汇与变调类型都离太湖片很远（**上一章那条“学边缘不学中心”在此立刻可用（②**内部的互通度低于外人想象**（**太湖片内部尚可勉强相闻，瓯江片与太湖片之间接近不通（**这提醒我们：**“吴语”是一个学术单位，不是一种日常互通的口语；**说“吴语使用者”时，你说的是一个分类，不是一群能开会的人（③**行政边界在图上很显眼**（**通说现象：若干界线与旧府界、山地与水系重合（**本课的态度是既承认也不迷信：**重合说明移民与市场的地理，不说明血统（**这一句在本章末的小论文里会被要求展开。**
:::

::: definition 上海话是最新的吴语 {#def-shanghai}
**通说脉络**（**现代上海市区话形成于开埠以后的大规模移民，混合了太湖片若干点的特点并经历了明显的拉平（**四项后果（**①浊音弱化、②声调归并、③变调简化、④词汇向书面语与普通话靠拢（**本课的判决（**上海话不是“最典型的吴语”，而是**吴语里最晚形成、最被拉平的一支**（**于是出现一种常见的错位：**以外地人的印象，上海话代表吴语；以特征的数量，最能代表吴语的是它西面与南面的乡镇与山区（**这个错位本身是本章的教学内容：**一种变体的代表性来自它的经济与媒体地位，不来自它的典型性；**第 8 章“语言的声望账户”在此得到一个方言内部的案例（**更值得记的是它的机制：**城市把周围的差异吸进来再压平；**所以一个语区最大的城市，往往是这个语区特征最少的地方（**这句话对官话、吴语、粤语与任何正在城市化的语言都成立——**你可以把它当作本章的可移植结论。**
:::

::: definition 温州话与“难懂”这个指标 {#def-wenzhou}
**一个流行说法**（**舆论常把温州话列为“最难懂的方言”（**本课的两步处理（**①先承认它无法量化**（**“难懂”不是一个属性，而是一个关系量：它等于听者母语与目标话的距离，减去听者的接触量（**同一个温州话，对青田人是邻居，对哈尔滨人是外语（**因此“最难懂”这类排行，在任何语言学上都是零信息（②再问它为什么流行**（**因为瓯江片与太湖片的差异确实大（**声调类别多、韵类分合不同、常用词另有一套、变调规则自成系统**）；而且温州地区宗族与商业网络密集，内部一致性高而对外封闭（**通说脉络：**于是这一条变成第 8 章的一个应用：**“难懂”排行榜其实是一张接触量排行榜的反面投影；**而它流行得如此顺利，说明人们愿意把“我不熟悉”说成“它神秘”（**本课给的可替代写法（**永远不要说某种话难懂，要说“对某类说话人而言互通度低，因为哪几项特征不同”——**这是一次很小的语言卫生行为，它是整门方言课的入门礼。**
:::

::: example 五十四种读法与一个表 {#ex-biaoge}
设某吴语点有五个单字调，编号 1 至 5；两字组的连读变调可用下表概括（左为前字调类，上为后字调类，格中为整串实际调型**）：

| 前＼后 | 1 | 2 | 3 | 5 |
|---|---|---|---|---|
| 1 | 55-31 | 55-31 | 55-31 | 55-31 |
| 2 | 12-44 | 12-44 | 12-34 | 12-34 |
| 3 | 33-53 | 33-53 | 33-44 | 33-44 |
| 5 | 13-33 | 13-33 | 13-33 | 13-33 |

请回答三问：**①这是前字主导还是后字主导（②从表里能推出几条规律（③为什么查这张表不能替代听。

::: solution
**①判断**（**每一行的输出调型只依赖前字所在行：同前字的三列几乎完全一致；**因此是前字主导型（**若换一种方言，同列的输出一致，则为后字主导（②规律**（**其一，后字调类信息几乎被抹去：**只在第 2、3 行第 3 列出现一次细微差异；**这说明**变调系统会牺牲对立来换取韵律的整齐（**第 3 门课“省力与清楚的均衡”在此是一张大字报；**其二，第 1 行的整串调型像是一个整体重音模式：**两字组在此更像一个词（③为什么表不能替代听**（**因为表中省去了三件只在时间里的东西：**音节长度、边界处的停顿习惯，以及说话人在什么单位上决定重新起调；**而第三件恰恰是变调的核心机制（**通说脉络：变调域通常与韵律词或音步对应（**这就是本章要求你做练习而非背诵的理由：**变调不是记忆题，是节奏题；**一个只会查表的记音者，会把两个不同的词记成同一串声调——**这种错误在本课程里有一个名字：**把主张当成了事实（**第 3 门课括号那条。**
:::
:::

::: intuition 一部小说的发音问题 {#def-xiaoshuo}
**通说脉络**（**晚清有一部以苏州话对白写成的长篇小说，成为方言文学常被引用的一例；此前亦有采录吴地山歌与说唱的本子（**本课用它提三个问题（**①作者如何拼写没有正字法的词**（**借字、俗字、记音字与自造字并用；**于是文本里保存了一场持续的拼写实验（**第 1 门课“汉字改写分类学”的微观版本（②读者是谁**（**用苏白写对白，假定读者能读又不能说：方言在此是一种人物标记与地方色彩（**这就是方言在文学里的合法位置：**它是被引用的一种声音，不是一种书写语言（**这一句请与第 21、22 章对照：**北方官话区的作家写方言时不必加注，吴语区的作家要加注——**同一个技术在不同语区的成本不同，这解释了为什么方言文学的比例沿语区倾斜（③今天它算什么材料**（**语言学家能用它做词汇与语法的证据，但须分层处理：**小说的拼写惯例可能沿袭前代刻本，也可能被作者标准化（**这就回到本课程反复的那条分层：**文本层、习惯层、口语层——三者不重合；**而任何一条方言语法结论若只有一份文学作品为证，就只能记作“传说层”。**
:::

::: history 从一本调查到一门舆论 {#sec-wu}
**六朝至唐宋**（**江南口语在文献中留下若干层次（**通说脉络：**本课只取一条可靠的读法：**今日吴语里的若干词汇与音读，只能用历史层次来解释，不能用“古音活化石”解释（**“活化石”这个词在本课程被禁止，理由与上一章“谁保留古音”那条相同（②**明清**（**南戏与昆山腔的音韵、山歌与弹词抄本，使吴语长期有一种书面存在（**通说脉络（③**1890 年代**（**一部以苏白对白写成的小说刊行（**通说脉络（④**1928**（**一部吴语研究以记音与问卷描写多点，成为本书所谓“中国方言学的实验室”的开张（**通说归于赵元任（⑤**1980 年代以后**（**方言词典、分县调查与语法研究积累；同时城市化使城乡差别的方向改变：**从前是乡村保存旧特征，现在是城市的老年层保存（**通说脉络：**本课称此为“年龄取代地理”，并认为这是本世纪汉语方言最重要的一个结构变化（⑥**2008 至今**（**方言保护的公共讨论、地方媒体与学校兴趣班的试验，以及语言资源保护工程的记音（**通说脉络（**本课的判断：**当一门话的传承从地理问题变成课时表问题，它的命运就交给了行政与预算；**第 9 章详述。**

::: exercise 小论文：书面化的经济学 {level=3}
写六百至一千字，评“**一种方言能否书面化，主要不取决于它的文学才能，而取决于有没有一个以它计费的产业：发行、唱片、电台、字幕与教材。二十世纪粤语拥有这一整套，吴语只拥有其中几样；结果前者发展出可用的记音惯例，后者停留在对白里的地方色彩。所谓方言的衰落，往往先是它的书写用途被撤销，然后才是无人会说**。须调用：**清音浊流与测法**、**连读变调**、**上海的拉平**、**“难懂”排行**、**方言小说的三个问题**、**年龄取代地理**至少六项；并裁决：**给一门话一个书写系统，会加快还是减慢它的消亡（必须给出机制与一个反例**。

::: solution
判分点：六项机制；裁决（**合格答案须两面：**加快的一面（**正字法需要标准，标准需要选一个点作基础；**这一选择会剥夺其他点的书面资格，并把内部差异变成“错别字问题”——**于是书写系统成为又一种拉平力量（**这是本课最希望看到的答案，因为它与第 3 章“正字法即税收”同构**）；减慢的一面（**有写法的话可以被教、被引、被当作身份徽章，儿童会因它能出现在屏幕上而愿意学；**反例候选：**若干被规范化、出版语法书与字典的方言仍然在两三代人内转用共同语（**因为书写不改变机会结构**）；以及一个支持性反例（**希伯来语被举为“书写与教育使一种口语复活”的常例；**它之所以罕见，恰是因为它需要国家级的预算与移民——**判卷看是否用这个例子来说明“条件而非意愿”**）；结论若能写“**所以书面对一门话不是氧气而是橱窗：它能改变别人怎么看这门话，很少改变谁会用它养家；真正的杠杆在机会结构，而记录与书写是我们在杠杆之外还能做的两件事**”，即 A。
