## 定义：为什么“之间”最难 {#def-zhijian}

::: definition 三种处置与它们的支持者 {#def-sanzhong}
**一块介于两区之间的地方，地图集只有三种画法**（**①并入较近的一区**（**读者满意、单位少、政策好执行；**代价是把过渡的特征写成“例外”（②**另立为一区**（**尊重特征束；**代价是承认单位的数量取决于研究者的偏好，并且从此要为一个区的教材与经费辩护（③**标为未定**（**最诚实；**几乎从不被采用（**本课对第③条的解释值得记住：**地图的读者——教科书、财政、地方身份——都需要一个格子；**一个空格子比一个错格子更让人不安（**这就是为什么方言图上找不到“未定”这两个字，而研究报告里到处是它（**本章四块地方，每一块都曾被三种处置轮流使用过；**你读到某本书把徽州话归入吴语、另一本列为独立一区时，看到的不是资料冲突，而是三种处置在竞争。**
:::

::: definition 老湘语与新湘语 {#def-xiang}
**通说脉络**（**湘语常被分为“老派”与“新派”两类：**老湘语若干点保留古全浊声母的浊音或带浊音色彩的读法，新湘语多已清化，其中长沙话最接近官话（**三条读法（**①这是一次可以当场观察的官话化**（**省会在一百多年里把自己的方言推向官话类型，而西面与南面的乡镇保留了旧读（**上一章那条“年龄取代地理”在此变成“省会取代乡镇”（②“老、新”两个词是价值判断还是年代判断**（**在方言学里它们指特征，不指优劣；**但在日常语言里，“老湘语”听起来像落后——**本课要求你在写作时补一句“此处老派指保留某特征”，这是很低成本的清晰（③**湘语边界的成因**（**洞庭湖平原与湘江水道是交通线而不是屏障；**清代以来反复的移民与商业使沿江一带的方言不断与官话对齐，而山区保留旧特征（**通说脉络：**这是本章的一般规律：**水的两边相似，山的两边不同；**所以方言图与地形图并排看，比与行政区划并排看更有解释力（**第 2 章“线与山、河、省界重合”在此得到一个偏向地形的答案。**
:::

::: definition 赣语与客家的分合 {#def-gan}
**通说脉络**（**赣语分布在江西中北部与邻近湘鄂皖若干县；它与客家话的关系长期有“合为一区”与“各为一区”两说（**常被引用的一条特征是：**部分古全浊声母字今读送气，且不完全受平仄条件限制**（**这与官话的“平声送气、仄声不送气”形成对照（**通说脉络（**本课强调三点（**①一条特征可以立一个区，也可以拆一个区**（**上一章晋语依入声被立出；客赣若依送气条件合并，就得把两区的内部差异写成“片”（②**省名与语区的重合是巧合还是方法**（**“赣”是江西的简称；**当一个语区被用省命名时，学者与行政都在同一张图上工作，此后每一次“本省方言”的表述都会把行政边界当作语言边界（**这一处请与前章的客家对读：**客家拒绝被省界切割，赣语则被一个省界命名（③**赣与客的分歧点在迁徙史**（**认为该合的人看音类，认为该分的人看一次可考的迁出与定居；**这是本章开头三种处置的又一次演出——**而观众是申请经费的地方机构，它们通常希望自己是独立的一区。**
:::

::: definition 徽语：最没有根据地的争议 {#def-hui}
**通说脉络**（**徽语指皖南一带若干方言，常被描述为“一部分像吴语、一部分像赣语、另有一些自己的创新”；它是否独立成区，是汉语方言学里悬而未决的问题之一（**三条本课认为值得记的东西（**①它的特征确实杂**（**声调类别多、韵母有若干特殊的鼻化与儿化类型、体标记与附近方言不同（**通说脉络：**杂不是资料不足：**一个长期作为通道与分家的地区，本来就应当是杂的（②**徽州有过一种极强的一致性，而那种一致性不是语言的**（**明清以来徽商网络、宗族与契约文书构成了一个高度自洽的区域社会；**这一地区留传下来的民间文书数量之大，在同类区域里突出（**通说脉络：**本课把它写成本章最反直觉的一句：**一个有发达文书文化的地区，没有为它的方言赢得一个确定的分区地位；**文书是契约语言写的，方言只是被说出来（**第 5、6 章“单据决定命运”在此以反例补全：**单据要用通用语写才有法律效力——**徽州商人恰恰是最早精通这一点的人（③**争议为什么悬而不决**（**因为要判它“独立”，须指出它独有的创新；**而创新在过渡带上是各自独立发生的，无法证明共同起源（**这就是分合平行的方法在这里的极限（**本章要求你写下这句话：**方法不能回答的问题，不是方法的失败，是问题的边界。**
:::

::: definition 平话：一个待定的名字 {#def-ping}
**通说脉络**（**广西若干地区的变体被称作“平话”，其与粤语、官话以及彼此之间的关系长期未定；在地图集的一部方案里它被单列为一个单位，此后争议不断（**三点（**①名称的来历本身含混**（**通说认为它取自当地对自己话的称呼一类来源；**当一个分区单位的名称来自他称或自称而语源不清时，学界通常会争论半个世纪（②**它的位置决定了它的命运**（**广西是官话、粤语、平话、客家话与多种非汉语语言（壮语等）交错的省区；**在如此密集的接触地带，任何一条单一标准都能找到支持它的点，也能找到反对它的点（**通说脉络（**这是第 9 章“接触三本账”最集中的现场（③**一个尚未结案的案例最有教学价值**（**你可以在图书馆里自己数：同一批点在四五种方案里被归入四个单位（**本课布置给每一个觉得“分类很无聊”的人：**把某一片地区的各种归入方案抄成一页，然后问哪一派的证据最弱——**这个练习比本章全部正文更能教会你什么叫论证强度（**第 3 门课与论说文课在此合流。**
