前两章的方言各有一件招牌特征；本章的两种话各有一件更麻烦的东西——**闽语在同一个人的嘴里装着好几个时代的读音，客家话则把一个人群讲给自己的迁徙故事写进了方言地图**。

## 定义：文白异读 {#def-wenbai}

::: definition 一个字的两个户口 {#def-liangdu}
**通说脉络**（**闽语以文白异读发达著称：**同一个字常有一个读书音与一个口语音，两套读法的对应是成系统的而非临时（**关键在“成系统”三字（**若只是几个字有两读，那是例外；**而闽语里两读的分野可以按韵类与声母类整批描述，这说明**这里曾经有两条输入路径**（**其一，本地口语的自然传承；其二，跟读书系统与更近的通用语学来的读音（**本课给一个更好用的说法：**文读是外来的官方标准，被逐代吸收；白读是它到来之前本地已经有的说法——**于是闽语的音系像一座老城的地下：**每一层都对应一个时代的通用语与一种制度（**第 1 章的“层次叠加”在本章有了具体地层（**而它的可核性极强：**同一个字在“学生”与“教书”里读不同音，这两处不是随意分配的（**下一节的分布律要处理的正是这件事。
:::

::: definition 白读是更早的层次 {#def-baidus}
**通说脉络**（**若干闽语白读层带有被认为更古老的特征，常被引用的例子包括一批古非母字读成双唇塞音一类现象（**这一现象在清代学者提出的“古无轻唇音”一类论断下被反复引用（**本课分三层处理，这是本课程从头到尾的史料分层法（**①可核层**（**在若干闽语点确实能记录到这类读音，且成批出现；②推论层**（**它表明白读层早于某次声母分化；**这一步需要排除接触与借用，而排除并不总能做到；③传说层**（**“闽语保存了唐宋古音”“衣冠入闽带来某朝洛阳音”一类的成套说法：它们把语言层次与族群迁徙一一对应，而这类对应几乎从不可核（**本课的判语（**第三层在民间写作里最有生命力，也最常被用来做身份广告；**你的工作不是嘲笑它，而是写明哪一句属于哪一层——**这门课在文学课上练的那件事，在这里是同一种手艺。**
:::

::: definition 双言：一种话，两种语域 {#def-shuangyan}
**通说脉络**（**社会学里有一个概念叫双言，指一种语言内部的高变体与低变体各管一批场合，说话人不会在同一场合里混用（**本课认为闽语是汉语内部最接近这一模型的案例（**①分布律**（**文读管书面、正式、抽象与新词；白读管身体、食物、亲属与日常动作（**通说脉络：**其二**（**违反分布会被听见：**用一个字的白读去读一个文言复合词，会立刻显得受教育程度可疑；**这种即时可判性说明两层的边界不是词库问题而是语域问题（**其三（**两层都在萎缩，而萎缩速度不同：**文读层因普通话与书面语靠拢而被替换，白读层因日常口语转用普通话而消失——**结果是最有闽语特色的两套系统同时被抽掉，取而代之的是一种带闽语口音的普通话（**这是本章给“语言转用”下的定义：**不是换了一种话，而是把两套系统换成一套加一层口音（**第 9 章会把这句话当作全章的骨架。
:::

::: definition 五个片与一个海 {#def-wupian}
**通说脉络**（**闽语常被分为闽南、闽东、闽北、闽中、莆仙等若干片，片间互通度低（**三条后果（**①“闽语”作为一个单位靠的是共同创新与共同层次，而不是内部互通**（**这正是上一章“分合平行”而非“像不像”的意思（②**渡海即分家**（**闽南语随移民入台、入南洋；**若干在福建本地已相异的口音，在境外成为不同的社群语言（**通说脉络：**本课给一个比较：**闽语是汉语方言里最早“跨国”的一支，而它的跨国比普通话早了一百年——**这不是荣耀，是它作为贫穷沿海人口谋生方式的记录（③**海南与雷州的闽语**（**随驻军与移民南下的闽语在海南形成一大片方言区；**而岛上另有若干被称为“军话”的变体，其形成传说与明代卫所有关（**通说脉络：**注意这里出现了上一章的镜像：**官话区被移民带进南方，闽语区被移民带进热带；**方言岛与“飞地”是同一枚硬币的两面，区别只在于谁记账。**
:::

::: definition 客家：一个自称的语区 {#def-kejie}
**通说脉络**（**客家话分布粤、闽、赣、桂等地的山区与丘陵，内部差异不小而认同很强（**三条线（**①名称**（**“客”是与“土”相对的一个登记范畴；**在清代东南的土著与移民矛盾中，这一称呼被固化，并在十九世纪中叶的冲突后进入公共语言（**通说脉络：**本课的第一层判断：**一个由赋役与户籍产生的他称，后来变成一个自称，再后来成为一个学术分区名——**这条路径在世界方言地理里并不罕见，而它在客家身上最清楚（②**叙事**（**二十世纪三十年代一部研究著作把散落的族谱、迁徙传说与方言分布整合成一个系统的迁徙叙事（**通说脉络：**本课不判断这个叙事在细节上的真伪，只指出它的功能：**它使一个语言群体能够回答“我们是谁”，并使后来的方言学分区承受一种它无法拒绝的压力（**这一句请重读一遍：**当一个人群坚持自己是“一种人”，语言学很难仅凭音类分合说它不是（③**客赣之争**（**客家话与赣语的关系长期有“合为一区”与“各自成区”两说（**通说脉络：**本课的读法：**两说各有音类证据，分歧的真正焦点是“是否把一次迁徙史作为分类依据”——**上一章说分区的权重常由移民史决定，本章是这个论断最好的标本。**
:::

::: intuition 侨批：一门话的资产负债表 {#def-qiaopi}
