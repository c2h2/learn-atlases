最后一章把前九章的手艺压进一本笔记——**本章的论点略带挑衅：方言调查的全部难点不是听出声音，而是决定把什么写下来；每一个你写下的音，都是一次关于“这是同一个音”的主张**。

## 定义：音与记音 {#def-jiyin}

::: definition 归纳先于考证 {#def-guidna}
**通说脉络**（**调查的第一步是记音，第二步是归纳音系，第三步才是找本字与论层次（**本课解释这个顺序为什么不能颠倒（**①不先归纳就会记“对”的音**（**初学者习惯把陌生的音写成熟悉的字或熟悉的字母，于是记音表读起来像任何方言都行——**这是被自己的音位库存审查过的材料（②音系归纳是一种主张**（**把两个音写成一个符号，是主张它们在同一系统里不区别意义（**第 3 门课那条“括号即主张”在此有了最硬的形式：**你的方括号与斜杠是论文里的第一个论点，而且它藏在笔记里没人审（③本字考证要等到最后**（**因为一旦你给一个音写上一个汉字，你就会开始按那个字的读音去听它（**这是记音工作里最常见的一种污染，而它一旦发生就不可逆（**本课的操作规程（**在头两周里禁止写汉字；**先用任意符号把区别记下来，等你能在听到时反应出对立，再去想它对应哪个中古类别、哪个字（**这条规程可以在任何人身上试验，成本是一两周的不适（**它同时也是本课程给“先描写、后判断”这条伦理的具体做法。
:::

::: definition 三件工具 {#def-gongju}
**①调值**（**用五度制给声调记相对音高；**通说脉络：这套记法出自二十世纪的一位语言学家，它的设计优点是廉价而可比较（**三条戒律：**同一个调值必须由同一位听者、同一只耳、同一间屋测得；**换人换环境等于换标尺；②必须测多个发音人与多个字，因为调值是类的中心而不是某次的实现（③录音比现场听更可靠而更不全面，因为录音丢掉了节奏与手势，而手势常与语调同构（**通说脉络：**②最小对立**（**找一对只差一个成分的词，是证明一个音位存在的最便宜的论证（第 3 门课（**它的困难在于：母语者常常不觉得两个音有区别，而它们的区别在系统里已经消失；**于是你需要第二件东西——③**长篇自然语料**（**一段讲述、一次争吵、一段笑话；**只有它会提供你没想到要问的格式与词（**上一章六题诱发设计解决的是格子的完整性，长篇语料解决的是格子的诚实性（**本课给一条比例：**如果你的笔记里只有词表与单句，那你记下的是一门你不认识的语言（**这句话听起来夸张，它的意思是：**语法与语用只出现在成段的话里，而那是发音人唯一不看你脸色的时刻。
:::

::: definition 谁的语言，谁的记录 {#def-chanquan}
**四个问题，本课要求你在出发前答出来（**①发音人的时间怎么付酬**（**通说惯例是等价补偿；**本课补充一句：付酬会改变语速与耐心，也改变对方纠正你的意愿，所以要在笔记里写明（②录音可以被谁听**（**一次村庄访谈可能被变成论文、教材、数据库与一段短视频；**这四种用途的同意范围并不相同，而它们通常被一份概括的同意书吞掉（**这是本章认为方言工作最需要改进的一处：**通用同意书在语言学里等于没有同意（③名字与地点怎么标**（**写“某村张氏老人”就再也找不到他；**写“浙江省××县××村，男，1947 年生”则可能让他在村里被指认（**通说脉络：涉及个人信息的材料通常要求脱敏；**本课的立场是：**脱敏保护的是人，不保护学者的可复核性——**所以要保留可回到现场的路径（通过中间人），而不是删掉路径（④记录能不能帮上忙**（**这是最难的一问，因为答案多半是“不能”；**本课反对把记录说成救援，但支持做三件确实有效的事（**见下一节**。
:::

::: definition 三件确实有效的事 {#def-sanjian}
**①把材料还给社区**（**一本能读的册子、一段能放的录音、一套给孩子听的音频；**它的成本极低而其效果在学术评价指标里是零，这正是它重要的原因（**通说脉络：不少方言研究成果从未回到被研究的村子（②**培养本地的记录者**（**一位县里的教师记下的二十年，胜过一位学者记下的两周；**这不是修辞，是数据量的算术（③**把不确定写清楚**（**在报告里标明哪些音你听不真、哪些话只有一位发音人说过、哪些结论需要更多点；**本课认为这是本章唯一的“硬道德”：**含糊的报告会被后人当作证据使用，而你已经无法为他们辩解（**第 8 章那条在这里闭环（**通说脉络**（**国际与国内都有伦理审查与知情同意的规范，语言学田野工作被逐步纳入；**本课不评论其执行，只指出它的后果：**规范化让年轻的记录者第一次要认真考虑自己与研究对象之间的权力差（**这一步在别的学科走了几十年（**它在方言学里走得慢，因为发音人常常是亲戚。
:::

::: example 一个音的十二分钟 {#ex-yige}
你在某县记音，把一个字记成送气清塞音。三天后听录音，你注意到它在两个词里像是不送气，而在第三个词里有明显的喉部紧化。请写出接下来十二分钟内你能做的六件事，并按证据强度排序。

::: solution
**先立一条原则**（**你现在面对的不是“记错了”，而是一个还没归纳完的音位问题（**六件事（**①重听全部含该词的录音，列出所有出现环境**（**成本最低的复核；**若分布有条件，则可能是音位变体（②问发音人一对可能构成最小对的词**（**若他否认有区别而录音里持续有区别，就转入③；**注意：否认区别是正常反应，不是不可靠（③检查是否伴随其他线索**（**元音长度、声门紧张、声调起点；**一个“送气与否”的对立常已改为别的承载方式（**通说脉络：**这是语法化与音变研究反复看到的“替代”现象（④换一位发音人重复同一批词**（**单人一次观察在任何学科里都是最弱的证据（**第 1 门课四种强度（⑤把该词放入句子，让他造句而不是单说**（**送气特征常常只在强调位置出现（⑥在笔记上写下你的不确定并注明日期（**这一条最容易被省略而最有用：**三个月后你会忘记自己当时犹豫过（**按证据强度排序**（**多人多环境的分布＞同一环境内的稳定伴随特征＞单人否认或承认＞一次现场印象（**判分：**把⑥写出来者本章给满分**——**因为记音工作的唯一可继承的成果，是带着犹豫标记的材料；**而犹豫标记是后来者敢于推翻你的许可证（**这一句适用于本课程全部写作。
:::
:::

::: intuition 记音改变你听到的东西 {#int-gai}
**一个每个记录者都会遇到的现象**（**学记音之前，你听到的是一片；**学完之后，你听到一串类别（**三条后果（**①这是一种获得，也是一种损失**（**你再也无法用“听不懂”来保护自己；**而同一种能力会让你高估自己的可靠度（②符号是你的感官的模具**（**用过某套记音字母的人，会在那套字母区分的地方听出区别，在它合并的地方听不出（**第 3 门课那条“音位库存”在个人层面的复现（③所以要定期与同伴做双人背对背记音**（**同一段录音两人各记，然后对表；**分歧处就是你的耳朵而非对方口音的问题所在（**通说脉络：这是语言学训练里最朴素也最有效的质量控制；**本课要求你至少做三次，因为它会在半小时内治好一种病：**把“我听清了”当成证据。
:::

::: history 一本笔记的历史 {#sec-biji}
**公元前一世纪前后**（**一部地方词语手册以问与抄的方式搜集各地说法；**通说脉络：**本课把它读作第一次田野：**它的困难与我们相同：**对方说的是词，你要的是系统（②**十九世纪末—二十世纪初**（**方言调查与方言地图在欧洲兴起；**通说脉络：**本课只取一条方法上的后果：**地图要求统一的调查项目，于是“问同样的问题”成为一门手艺的核心；**1950 年代中国的统一词表是这条线索的延续（③**1928**（**一部吴语研究把记音、问卷与地图结合，并使用了新的调值记法（**通说脉络（④**1950s**（**大规模调查队与统一表格：本课程的“可比性来自问同一批问题”由此而来（**通说脉络（⑤**1980s—2000s**（**磁带与数字录音使复核成为可能，长篇语料开始入库（**通说脉络：**本课指出一次安静的方法革命：**当录音可被反复听，记音从“印象加判断”变成“可审计的材料”（⑥**现在**（**手机、云端转写与自动标注；**模型能给出音标，却不为它听错了什么负责（**通说脉络：**本章最后一问留给读者：**当记音可以由机器完成，调查者的不可替代之处在哪里（**本课的答案：**在决定问什么、在听出自己听不出什么、以及愿意在笔记上写下不确定——**三件事都不在模型的责任范围里，因为它们都是责任本身（**这就是本课程二十五章反复的那句话的另一半：**技术改变工序，不改变可核对性这件事的价值。
:::

::: exercise 小论文：责任与技术 {level=3}
写六百至一千字，评“**田野工作的伦理之所以难以处理，是因为它的伤害通常不是恶意造成的：一位好心的记录者带回一批珍贵的材料，把它们放进一个村里人永远打不开的数据库，用村里的名字换取期刊的认可，然后在告别时说感谢配合。这里的每一步单独看都无害。因此方言调查真正需要的不是更多守则，而是把一件本来隐形的东西变成可核对的义务：材料的去向、同意的层级，以及研究者本人对错误的可追索性**。须调用：**归纳先于考证**、**三件工具**、**四个产权问题**、**三件有效的事**、**十二分钟的六步**、**机器记音**至少六项；并裁决：**“可追索性”如何在不吓退研究者的前提下实现（给出一种具体制度并说明它会漏掉什么**。
