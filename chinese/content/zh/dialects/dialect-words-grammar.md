前六章反复说“词汇是天气、音类是气候”；本章把这两样东西摊开成可核对的清单——**并给出一条本课认为最重要的田野教训：你用普通话问出来的方言，永远是方言化的普通话**。

## 定义：词汇层 {#def-cihui}

::: definition 三种差异 {#def-sanzhong}
**①词形替换**（**同一事物用一个完全不同的词说**（**走的动作，一些地方说“行”；**这与古代汉语的分工相合，因而常被当作层次证据（**通说脉络（②语义转移**（**同一个词，意义范围不同：**指孩子的词在有些点上只指儿子，指父亲的词在有些点上指祖父（**通说脉络：**这一类最容易造成跨方言的误会，因为它在词表上显示为“相同”（**本课的分类法：**词形替换是可数的，语义转移是不可数的——**所以任何以“共同词占比”为据的论证，都须先说明它如何处理一词多义（③词汇空缺**（**本地没有现成词，于是用一个短语或借一个共同语词（**本课看重空缺：**它暴露一套概念系统里没有做过区分的东西**（**亲属称谓与容器、米粒与饭食的分类差异是最容易观察的例子（**通说脉络：**这就是词汇人类学留给方言学的一条遗产：**词表不是一张标签清单，而是一份地方分类学的账目（**第 2 门课“汉字改写分类学”在这里有了口语版。**
:::

::: definition 基本词与文化词 {#def-jiben}
**通说脉络**（**比较研究把词分成两层：身体部位、亲属、数目、动作与自然物等“基本词”，以及器物、制度、食物与抽象名词等“文化词”（**三条用法（**①基本词用于判断关系远近**（**它们的替换慢，因而在词表上更有分量（②文化词用于判断接触**（**一批同源的物名沿贸易线散开，比任何史书的记载都更诚实（**通说脉络：**本章的建议：**做两种清单，分别报告；**把它们加总成一个“相似度百分比”，是把两本账合成一本（**上一章审计总结时说过同样的话（③词表要记音也要记用法**（**一个词的正确记录包含：谁会说、在什么场合说、以及它的语体色彩（**只记词不记语体，就会把老派词记成通用词，于是三十年后有人拿你的记录去证明一个从未存在过的说法（**这是本课对“档案运气”那条的方言学应用：**你的笔记会被后人当作证据，而你无法为他们辩解（**第 10 章会把这句话变成操作规程。
:::

::: definition 四类语法差异 {#def-silei}
**①虚词**（**否定、体貌、处所、复数、语末语气，各方言各有一套；**这是方言之间最不“对等”的地方（②句式**（**比较、处置、被动、与格、疑问的格式各不相同（**通说脉络：**双宾语的次序与比较句的介词，是方言语法里被引用最多的两条（③语序与位置**（**副词后置、状语位置、以及若干方言里“先做这件事”的说法（**上一章粤语一条（④重音与节奏**（**被研究得最少的一层；**而它恰恰是外语者一听就能分辨的东西（**通说脉络：**本课给一条排序：**越靠近句子骨架的差异越硬——**句式比虚词硬，虚词比词硬，词比名称硬（**这条排序就是第一章那句“语法差异最有诊断力”的展开；**而它的推论令人不安：**我们最容易记录的（词表），恰好是最不能证明关系的。**
:::

::: definition 语法能不能被借 {#def-jie}
**通说脉络**（**传统说法认为语法结构很少被借用，而接触语言学的讨论里，长期双语的地区确实会出现格式复制（**本课把两说合成一个可检验的命题（**借用的顺序是：实词 → 虚词 → 格式；而格式被复制通常需要三个条件**（**大量双语人口、共同语威望悬殊、以及两种话的类型本来接近（**这三条在二十世纪后期的中国沿海方言区几乎全部满足（**于是出现一种新对象：**一种带方言语法而词汇来自共同语的口语，通常被称为“某地普通话”（**本课的定义：**它不是“说得不标准”，而是一种正在形成中的变体：它的音系是当地的，词汇是共通的，语法是混合的（**这一句请与前六章连读：**从前方言学家描写方言，现在他们需要描写这种中间话，而中间话最难写，因为没有人承认它是一种语言（**第 9 章会把这句话作为它的主要问题。**
:::

::: example 设计一套六题 {#ex-liuti}
你要考察一种陌生方言的体貌与比较格式。请设计六道诱发题，并说明每题为什么这样设计、以及如何避免“翻译式回答”。

::: solution
**先说失败的方法**（**把普通话句子念给他听，请他“用家乡话说一遍”：这等于请他做翻译，而翻译的目标是对方以为你想要的那句话（**本课称此为“诱导出规范答案”，它是方言语法调查的头号误差来源（**六道诱发题**（**①连续动作**（**给他看一段正在做的动作，问“他现在在做什么”；**考察持续标记（②刚刚完成**（**问“他刚才做完了什么”；**考察完整体标记与它的否定（③曾经有过的经历**（**问“他这辈子做过这件事吗”；**考察经历体（④能力与可能**（**问“他做得动吗”“他能不能做”；**考察可能补语与其否定式（⑤两物相比**（**摆出两样东西请他比较大小或贵贱；**考察比较格式与比较标记（⑥给某人一样东西**（**真的把东西递过去并说一句话；**考察与格、双宾语序与给予动词（**共同设计原则**（**每题都给出一个可观察的场景与一个必答的问题，让回答者处于“不得不说什么”的位置，而不是“要不要翻译”的位置；**并且每题都要能引出肯定与否定两种形式，因为否定式常常不规则，而最不规则的地方最有比较价值（**通说脉络：**这是历史比较语言学早已知道的一条：**例外是系统的窗口（**判分（**六道里若有三题以上是“念一句让他跟读”，本题不及格（**剩下的分数给“记录时同时写下语体与说话人年龄”**（上方词表③：同一条规则在语法调查里同样适用。
:::

::: intuition 口音在耳朵，语法在舌头 {#int-tou}
**一个日常观察**（**听一个人说带地方色彩的普通话，我们常能判断他的家乡，即使他的声调已经很像普通话（**本课的解释（**①他保留下来的是虚词、语序与节奏**（**这些东西没有对应物可替换，也无法用“换个词”掩盖（**音系可以借，词汇可以换，句子骨架不能搬家（②因此语法是底层的可见面**（**语言接触研究里“底层”指的是被替换的语言留下的结构；**而在个人身上，底层就是他的语法（**这一条与第 1 章那条呼应：**“底层”是一个推论，个人语法才是观察；**先记录后者的差异，再谈前者的成因（③一个对自己有用的推论**（**一个人学外语时最难改的，也恰恰是这三样；**这就是为什么成年人的外语听起来有“母语”，而词汇量早已超过教材（**本课把这条写在这里，是为了让本章的技术与你自己的身体连上：**你不是在描写一种“土话”，你是在描写一种人人都在做、只是没人被教过的事情——**用两套系统说话（**这一句在下一章会变成政策问题。**
:::

::: history 从词表到句式 {#sec-cihui}
**公元前一世纪前后**（**一部地方词语手册以“同一件事各地叫什么”为纲；**通说脉络：**本章的全部词汇学方法都从那一句问题里长出来（②**1950s**（**全国方言调查使用统一的词汇表格，第一次使跨地区比较成为可能（**通说脉络：**本课的评价：**词表调查的真正贡献不是词，是可比性——**它把十个省的人问同一批问题（**这在社会调查里叫问卷设计，在语言学里叫运气（③**1970s—1980s**（**方言语法研究逐渐成为一个方向；**通说脉络：**本课给一条制度解释：**语法研究晚，是因为它要求调查者本人能判断格式的合语法性，而这需要语感加训练；**记音只需要耳朵（④**1980s—1990s**（**方言语法专书与论文增多，出现按语法专题（体貌、处置、被动、疑问）汇编的比较研究（**通说脉络（⑤**2000s**（**语料库与方言数据库；**同时网络上的方言词表由使用者投稿形成，其质量与覆盖都极不均匀（**通说脉络：**本课的一条警告：**用户投稿的词表会把“有人愿意写的词”当作“本地在用的词”，而愿意写的往往是奇怪的那一批（**幸存者打八折在此完全适用（⑥**现在与将来**（**语言资源保护工程采集长篇口语，第一次为句法研究提供自然语料（**通说脉络：**本章的可检验预测：**当长篇口语语料可被检索，本章那张“句式最硬”的表会被推翻若干行；**而这是好事——**这说明我们的表是暂时的，而暂时的表才是可核对的表（**这就是本课程在第 2 章、第 6 章与本门课第 2 章反复写的那句话。**
:::

::: exercise 小论文：可借与不可借 {level=3}
写六百至一千字，评“**语言接触里有一种朴素的等级：东西先过来，名字跟过来，最后才轮到格式。这个等级是真实的，也是可被推翻的——它更像是对时间与双语人口数量的记录，而不是一条语法结构的天然禁区。二十世纪后期的中国沿海方言提供了一个大型实验：共同语通过屏幕进入每一个家庭，其强度超过历史上任何一次接触；结果不是方言被替换，而是方言被抽走句式、留下腔调。假如这个判断成立，那么将来我们能记录的‘方言’，将主要是口音的目录**。须调用：**三种差异**、**基本词与文化词**、**四类语法差异及其硬度排序**、**借用的顺序与条件**、**中间话**、**语料库与投稿词表的偏差**至少六项；并裁决：**这个预言在多大程度上是可反驳的（举出一项你尚未做、但能在两年内做完、且若为假就足以推翻它的研究**。

::: solution
判分点：六项机制；裁决（**合格答案须给出一项可执行研究，例如：①**同一社区两个年龄层的长篇小说式自然口语对比**（**若能证明 1990 与 2015 两代人的句式差异不超过词汇差异，预言被削弱（**关键在必须是自然口语而非诱发句，因为诱发出来的句子会把方言语法请出来**）；②**方言电视剧字幕的语法标注对比**（**若近年作品保留句式而只换词，则“屏幕抽走句式”不成立；③**同一方言在移民社区与本土社区的对比**（**若移民社区保留句式而本土社区丢失，机制就从“接触强度”变成“学校介入”，这是可以区分的（**判卷看是否提出可区分的机制，而非只看态度**）；结论若能写“**口音的目录是一部分真理；更准确的说法是：我们将拥有两种东西——一种用于亲密场合的、语法被削薄的变体，和一种用于公共场合的、带当地腔调的共同语。方言学要做的，是在削薄发生之前把完整的一层记下来，因为削薄不可逆，而记录可以等**”，即 A。
