title: "方言与语言"
---

前面三门课把汉语当作一个对象：一套声母、一部语法、一段文学史。本章开始把它拆开——**你会发现“汉语”是一个装着十种互相听不懂的口语的仓库，而仓库的门牌是由写字的手挂上去的，不是由耳朵听出来的**。

## 定义：三条界线 {#def-jie}

::: definition 互通度为什么不够用 {#def-hutong}
**语言学入门会给一条判据：**两种说法的说话人不学习就能听懂，就是同一种语言（**这条判据在汉语里立刻断成三截（**①连续体**（**甲村听懂乙村，乙村听懂丙村，甲村听不懂丙村；**“互通”在这种情形下是一个没有答案的问题，因为它要求你把一条渐变带切成两段（**欧洲与中国的山区都有这种布；它证明“语言”这个单位不能由互通度定义，因为互通度本身没有边界（②**单向懂**（**北方方言区的人常能听懂西南官话，反之未必；**双方都听懂第三方的普通话，于是各自认为对方“有口音”（**本课的提醒：**互通度是一个不对称的量，把它当作对称的量来用，是分类错误的第一步（③**书写覆盖**（**说苏州话与说温州话的人共用一套汉字、一套书面语与一部文学史；**于是“同一种语言”这个判断的真实根据不是耳朵，是字（**这就是本章的核心机制：**汉字是一台把差异极大的口语归入同一记录的机器**（第 2 门课与第 10 门课在此会师：**当文字统一而口语分裂，“语言”与“方言”的界线就由制度画，而制度画线的位置恰好是它需要负责的位置。**
:::

::: definition 一句格言的用处 {#def-geyan}
**通说脉络**（**有一句常被转述的意第绪语格言，大意是“一种语言就是拥有陆军与海军的方言”（**本课不把它当作愤世嫉俗的漂亮话，而当作一条可检验的说明：**它预测三件事（**①**有标准语的变体被称为语言**（**它有学校、词典、考试与播音员；②**没有这些的变体被称为方言**（**于是说话人自己也会说“我们那边的方言土”（**这是制度把分类塞进母语者的嘴（③**改变分类的最快办法不是证明什么，而是建一所学校**（**这三条预测在二十世纪都被兑现，兑现得最彻底的一件，就是普通话本身：**它在 1955 年被定义之前，是若干种北方口语的统称；被定义之后，它成了一种有音系表、有测试、有口音等级的语言（第 8 章“标准语是基础设施”的另一个名字（**本课由此给出全课程的操作定义：**“语言”是一个行政单位，“方言”是一个行政单位下的行政单位，“口音”是一个人的误差；**而真正自然存在的，只有说话的人与他们彼此听懂的份额。**
:::

::: definition 音系、词汇与语法三层 {#def-sancang}
**①音系层**（**声调类别数从北方官话的四类到若干东南方言的七至九类；韵尾方面，北方大多无入声韵尾，粤、客、闽部分方言保留 -p、-t、-k 之类的塞音尾，吴语保留喉塞式的入声但韵尾已弱化（**通说脉络：**同一批中古来源的字，在各区走向不同结果，这是方言分类主要看音系的理由（②**词汇层**（**基本词分岔：**“站、瞧、瞅、看”“儿子、囡、查某子”一类；**本课强调基本词（身体、亲属、数目、动作）分岔才是硬差异，文化词与物名分岔只是清单不同（③**语法层**（**最被低估、也最有诊断力的一层：**否定词、体标记、比较句、语序与复数标记各不相同；**语法差异之所以重要，是因为**借词天天在发生而语法结构极少被借（**这一条把本章与第 9 章的“接触三本账”连起来（**一个可当场试的技术（**要判断两种话差多少，不要问词，要问三句：**“我没有”“被他打了”“比我还高”**——**看否定、被动与比较怎么用（**这三句是方言调查里成本最低的一件工具。**
:::

::: definition 差异从哪里来 {#def-sange}
**①分别继承**（**同一中古来源在不同地区按不同速度演变；**最典型的是全浊声母的清化：北方基本清化，吴语多地保留浊音或带浊音色彩，若干官话点则部分字读浊擦音（**通说脉络：**由此可得本章最重要的方法论：**方言差异常常不是谁“古”谁“今”，而是同一条变化的不同完成度（**“讲普通话的人保留古音少”这个常识是错的，正确说法是**它保留的那一层与南方方言保留的那一层不同（②**层次叠加**（**一种方言里叠着若干时代的读书音：**文读与白读**（**白读是日常传承，文读是跟读书系统与更近的通用语学来的（**闽语是这一现象的极端案例，本课第 6 章展开（**层次概念的解释力在于：它使“一处方言里有两套读音系统”从怪事变成常事；**而它就是一部活的《切韵》分层证据（③**接触**（**与邻近非汉语语言的长期借用与底层影响（**通说脉络：**由此产生一类难处理的对象：**桂南、广西一带几种互相之间以及与粤语、官话之间关系都有争议的变体；**争议本身是好消息——**它说明分类从来不是发现，而是提出一个可被反对的方案（**这一句同时是本课对逻辑课与论说文课的回访（**一个分类若能被反驳，它才有内容。**
:::

::: example 三对说法，三把尺子 {#ex-sandui}
用三条尺子分别判断下列各对是“同一种语言”还是“两种语言”：**甲：苏州话与上海话；乙：普通话与东北官话；丙：闽南语与闽东话**。尺子一：互通度；尺子二：历史来源（同源程度**）；尺子三：本地人怎么说、制度怎么算。

::: solution
**甲**——**互通度中上（**城区年轻人彼此能懂，乡镇之间费力**）；同源程度高（**同属吴语，音类分合高度平行**）；制度与舆论算“同一种方言的两个点”（**但上海话因城市地位而被当作“一种话”，苏州话则被称作“乡下话”——**同一音系事实上的两种社会命运（②**乙**——**互通度很高、同源程度极高、制度上算同一种语言的两种口音；**这是三把尺子唯一对齐的一对，也是为什么人们愿意承认它（③**丙**——**互通度低（**词汇有对应但声调、韵类与常用词都不同**）；同源程度仍高（**同属闽语，文白分层机制相同**）；本地人与制度都算“两种方言”，而国际分类里常把它们各列为一种语言（**判分（**必须写出结论的形式：**“三把尺子在甲、丙两处不一致，所以任何答案都要先声明采用哪一把；**本课认为诚实的写法是：**音系上同源、口语上不通、行政上一种语言”——**三件分开说，就是本章的全部方法（**最差的答卷是断言“它们本来就是两种语言”或“本来就是方言”，因为那正是把行政尺子伪装成听觉尺子（**第 8 章那条“凡说‘好好说话’就问谁免费”在此的复述：**凡说“那才是正经话”，就问谁在为此办考试。**
:::
:::

::: intuition 口音可以原谅，方言要求改正 {#int-kouyin}
**先立一对区分**（**口音**（**音系不同而词法句法共用：**“他的普通话有口音”（②**方言**（**三层都不同：**“我听不懂他说的话”（**这个区分不是语言学概念，是礼貌与惩罚的分界：**有口音是被容忍的个人特征，说方言是可以被纠正的公共行为（**三条观察（**①**容忍度沿着声望走**（**同一种差异，来自首都叫“标准”，来自县城叫“土”；**第 8 章的“难堪轴”在此有一根平行轴：**声望轴（②**“口音”这个词把责任放在个人身上**（**说某人“有口音”，隐含一条基线；**而基线不是自然存在的，它是被考试与播音制度维持的（③**因此本章给一个可以带走的态度**（**遇到一段听不懂的话，正确的第一反应不是“这是什么方言”，而是“我和他之间还差多少共同的制度”；**听懂一半从来不是能力问题，是共同曝光量的问题（**这一句在方言调查一章还会用到：**调查者最需要训练的美德，是把自己听不懂这件事如实记录下来，而不解释成对方说不清楚。**
:::

::: history 一部词表、一张图与一次改名 {#sec-lishi}
**公元前一世纪前后**（**一部辑录各地日常词语的书按释义排布各国之语（**通说归于扬雄（**本课的两点读法：**其一，它证明地域差异在汉代已被当作可搜集的知识对象；其二，它以“同一件事物在不同地方叫什么”为纲，因而天然是一份词汇清单而不是一张地图——**中国的方言学最初是词表传统，直到二十世纪才变成音系传统（②**601**（**一部韵书在序里说明它折衷“南北是非、古今异同”（**通说脉络：**这一句常被引用，本课强调它的另一种含义：**早在七世纪，学者已经知道地域差异与时代差异会搅在一起，而一部为考试服务的书必须假装这两层可以理顺（③**十七世纪**（**来华的欧洲人为传习汉语编写字书与音表，其中包含官话与各口音的材料（**通说脉络：**本课只取一点：**最早把汉语方言当作可记录对象的人里，有一批是为了学它的外国人（④**1928**（**一部吴语研究用记音与问卷描写若干点，确立了方法（**通说归于赵元任（⑤**1956／1987**（**一次全国方言调查配一个七区草案；三十年后一部语言地图集定为十区，第二版又移动了线（**通说脉络（**本课的结论：**中国的方言分区每三十年改一次，这不是一门科学的失败，而是它的正常状态——**新点补上、界线重新画（⑥**2015 起**（**一项语言资源保护工程在千余处设点录音（**通说脉络：**本章最后指出一个伦理：**当记录的理由是“快没了”，记录本身就成了一种安慰；**本课要求你在读完第十课后仍然记得这句话（**第 9 章展开。**

::: exercise 三句话调查 {level=1}
向你身边说非官话方言的人（或用方言材料）问三句：**“我没有”“被他打了”“比我还高”**，记录其方言形式，并指出三层里哪一层差异最大。

::: solution

:::

::: exercise 小论文：命名即分配 {level=3}
写六百至一千字，评“**把一种话称作语言还是方言，决定的不是它听上去如何，而是它能要求什么：学校里的教学用语、法庭上的翻译、电台的时段、以及儿童是否必须为它放弃自己的发音。正因如此，分类学总是政治学的第一章；而语言学能贡献的，只是一个否定的证明——没有任何结构标准能把这些变体排成高下**。须调用：**三条尺子**、**连续体**、**同源的两种完成度**、**层次叠加**、**口音与方言的分界**、**记录的伦理**至少六项；并裁决：**当语言学证明不了高下，为什么仍有千万家长主动放弃把方言传给下一代（你必须给出机制，而不是道德评判**。

::: solution
判分点：六项机制（**尺子、连续体、完成度、层次、口音、记录**）；家长一侧的机制（**合格答案须写成本地与家庭的经济算术而非“观念落后”：**候选：①**语言能力的兑换价**（**第 8 章：一种话能换到多少教育与工资，决定了它在家庭预算里的位置**）；②**孩子的在校成本**（**说方言入学要在数年内自行完成转换，而这笔转换费没有任何人支付；**家长为避免这一成本而提前买断（**这是全章最应该写清的一条**）；③**声望的不可分性**（**家长不是嫌方言不好，而是不愿孩子在评估中被标记为“有口音的人”（上方口音条）；④**信息不对称**（**多数家庭不知道双语抚养不会损害学业；**而制度从不告诉他们——**故机制之一是宣传义务被省略**）；结论方向（**若能写出“**所以语言转用的真正推动者不是政策而是家长的预算表；任何以保护为名的政策，若不同时降低共同语的兑换价或不补偿转换成本，就只是在道德上指责做出理性选择的人**”，即 A；**本课要求这种结论：既不作怀旧姿态，也不假装中立。**
