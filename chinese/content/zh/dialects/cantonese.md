上一章说一种话能否书面化取决于有没有以它计费的产业；本章是这一命题的唯一完整案例——**粤语是汉语方言里唯一在二十世纪拥有唱片、电影、字幕与歌词的变体，所以它的地位不是政策给的，也因此随时可能随产业一起搬走**。

## 定义：声调的账 {#def-shengdiao}

::: definition 九声六调 {#def-jiusheng}
**通说脉络**（**广州话常说“九个声调、六个调值”（**这不是文字游戏，而是一次记账（**①古四声各依清浊分为阴阳，得六类舒声调；②古入声字按主要元音的长短或韵尾条件再分三类，形成上、中、下入（**通说脉络：**而三入的音高分别与三个舒声调相同，只是多带一个塞音韵尾；**所以“九个类、六个音高”同时为真（**本课的教学点（**这就是第 3 门课那条“范畴与音值是两本账”的方言实例；**学方言的人常在这里出错，因为他数的是自己听到的音高，而方言学数的是分合（**记住这条你就能对付任何“某方言有几个声调”的争论：**先问对方按什么分类，再问数的是调类还是调值（**这一问句是本章要你带走的第一件工具。**
:::

::: definition 韵尾与元音 {#def-yunwei}
**粤语保留了完整的配对**（**鼻音韵尾 -m、-n 与塞音韵尾 -p、-t 成套相对，加上鼻音与塞音的喉部收尾（**通说脉络：**它的历史意义一目了然：**别的方言拆掉了一半的格子，粤语把两半都留下了（**本课立刻加上两句限制，否则就成了“化石论”（**①留下不等于原样**（**粤语的元音系统、复合元音与声母都经历了各自的演变；**若干描写把它的元音处理为长短对立，这在分析上是重要的一步，而不是对“古音”的复述（通说脉络（②保留也有代价**（**保留塞音韵尾使音节收尾紧张，进而影响连读与借词的适应方式（**第 3 门课那条均衡律在此适用：**粤语不是更保守，它是把复杂度留在了韵尾上，而官话把复杂度搬去了声调与韵律（**于是本章的第一条比较：**吴语丢了韵尾而保留浊音，官话两样都丢而发展轻声与儿化，粤语两样都留而把声调数加到九——**三条路径没有一条是“进步”。**
:::

::: definition 五个语法点 {#def-wudian}
**本课用五个短例说明“语法差异比词汇差异硬”（第 1 章那条（（**①体标记**（**完成、持续、经历各有专职标记；**这与普通话的“了、着、过”看起来整齐对应，实际用法并不重合（**通说脉络：**一个教训：翻译对等不等于语法对等（②“先”后置**（**表示“先做这件事”的副词放在动词之后（**这是汉语各方言里罕见的语序，也是粤语身份最明显的标记之一（通说脉络（③比较用“过”**（**“甲高过乙”一类格式；**它的来源是“超过”，属于本章的语法化案例（第 9 章汉语史的方言版（④与格与双宾**（**给予类的两个宾语次序与普通话不同（**通说脉络：**这类差异不会出现在词表里，只能从整句里看出来——**所以调查必须整句诱发（上方③（⑤复数标记**（**人称代词后接一个复数成分（**它与若干方言的“辈、等、们”形成对照，是历史比较里常被引用的一处（**通说脉络（**本课把五件事合成一句话：**粤语与普通话的差别，句法层比词表层深；**而词表层的差异最容易被看见、也最没有分类价值——**这就是方言学与“方言笑话”之间的距离。**
:::

::: definition 方言用字 {#def-yongzi}
**粤语有一批只在粤语里用的字**（**表事物、表否定、表处所、表复数、表体的常用词各有其字（**通说脉络：**这一层是本章最有意思的社会事实：**一种没有官方标准的语言，长出了一套民间正字法，而且它在使用者之间能被读懂（**三条机制（**①借音字**（**拿一个音同的现成字记它，代价是把词义拖到别处；②义音合成**（**用一个义符加一个声符造新字，这是汉字系统的常规生产方式（③借用与训读**（**写一个意思相近的常用字而按粤语读它（**通说脉络：**这三条与第 1 门课讲的记音字、假借与俗字完全同构；**换句话说，**方言用字不是汉字的例外，而是汉字常规生产能力在缺乏标准时的展开（**本课的判语（**一个外地人看粤语书写觉得“字都写错了”，这个反应是准确的语法判断加错误的前提：它不是写错的普通话，而是另一种语言的书写；**而它“看起来错”，是因为没有一本字典有权宣布它对——**下一节讲这本字典为什么始终没有出现。**
:::

::: definition 产业给的地位 {#def-chanye}
**通说脉络**（**二十世纪后半叶，粤语经由唱片、电影与电视获得了一种其他汉语方言没有的公共存在（**本课的四层分析（**①**记音惯例随工业出现**（**字幕组、歌词与报章用语在几十年里形成一套可复用的写法：**这是自发的正字法，它的规范力量是销量（②**声望可以逆向来**（**普通话里吸收了一批粤语词与说法（**通说脉络：若干源自粤语的口语词在九十年代前后进入北方口语的常用层（**这是中国语言史上少见的方向：**在“共同语—方言”的轴线之外，还存在“富裕的方言—贫穷的方言”这条轴线（**第 8 章的兑换价在此最清晰（③**歌词是一种语言工程**（**粤语有九类声调与严格的韵尾，因此歌词必须与旋律配合声调，形成“依字上腔”的行规（**通说脉络：**其文化后果是：一门话的音系约束成为一门手艺的标准；**不会分辨声调的人写不了词（**这就是产业如何把音韵学变成职业要求（④**产业搬走，地位跟着搬**（**通说脉络：世纪之交以后，影视与音乐工业的重心北移，珠三角人口结构剧变，普通话成为集市与工厂的通用语（**本课的结论：**粤语的公共地位是工业的副产品，而不是政策的礼物；**凡是副产品，都会在产业离开时变成负担——**这就是下一章讲闽语时会重演的一句话，只是那里的载体不是工业而是侨乡。**
:::

::: definition 2010 年前后的一场争论 {#def-2010}
**通说脉络**（**约在 2010 年前后，广州因电视与学校教学语言安排的调整，出现过较大规模的公共讨论与市民表达（**本课不评论各方主张的正当性，只记录四条结构（**①**争论的对象是频道，不是发音**（**它争的是公共时段与教学语言，也就是上一章所谓“陆军与海军”（②**参与者主要是城市中产**（**他们把粤语当作文化资本而不是交际工具；**这一点极为重要：**一场以“保存”为名的运动，其主力是已经不需要用这门话找工作的人（③**诉求的语法暴露了机制**（**当时的口号多是“保护我们的语言”一类；**而“我们的”是它的力量所在，也是它的限制：**它把一门话定义为地方身份的标志，而不是把说它的人定义为需要服务的使用者（**后果：这类诉求难以争取到双语教育式的预算，只能争取到节目时段（④**结果两头都不满意**（**频道未变，态度变了：**若干研究注意到此后年轻人的方言认同反而上升而使用率下降——**象征性支持与实际转用可以同时增长（**本课把这一条作为全课程的一条定律：**当一种语言变成文化遗产，它的日常功能通常已经结束；**遗产是被纪念的东西，不是被使用的东西。**
:::
