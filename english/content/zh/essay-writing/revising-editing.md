张雨写完了一篇文章的初稿，题目是 *Should cities replace some car parking in the centre with parks and seating?*（城市是否应该把市中心的部分停车位改成公园和座椅？）老师把初稿还给她，页边写了三条评语：*Your second and fourth paragraphs make the same point.*（你的第二段和第四段说的是同一点。）——*Where is the counter-argument you mention in the introduction?*（你在引言里提到的反方论点在哪里？）——*Your conclusion argues for more parking, not less.*（你的结论主张的是增加停车位，而不是减少。）张雨花了一个晚上改稿。她把 *good* 改成 *beneficial*，改了九处，订正了每一个冠词，把 *a lot of* 改成 *numerous*，又在三个段落的开头加上 *Moreover*。第二稿比第一稿更正确。但它仍然有那三个问题。

她做的是编辑。初稿需要的是修改：合并两个段落，补写一个缺失的段落，要么改结论，要么改论点。老师的评语针对的是论证和结构，在词语上下多少功夫也回答不了它们。这是任何语言的作者浪费修改时间最常见的方式，从最早研究人们怎样修改的时候起，就有记录了（[[essay-writing/writing-process]]）。

本课为两种工作提供方法：针对论证和结构**修改**文章，以及针对语言**编辑**文章。本课还讲反馈——怎样给别人反馈，怎样利用你收到的反馈。基本的编辑清单、错误代码和错误记录在 [[sentences-and-paragraphs/editing]] 中讲授；本课把它们运用于整篇文章，并补充在它们之前要做的更大范围的检查。

## 两种改动

::: definition 修改和编辑 {#def-revising-editing}
- **修改**（revising）改变的是文章说什么以及怎样组织：它的论点，各段的要点及其顺序，哪些写进去、哪些删掉，怎样处理反对意见，结论是否顺理成章。修改可以增加、删除、挪动或重写整个段落。
- **编辑**（editing）改变的是文章怎样说：句子结构、语法、用词、语域、简洁、标点和拼写。**校对**（proofreading）是编辑中最后、范围最窄的部分：在交稿之前查找表面的笔误。

两者的区别在于：一种改动影响文章的意义，另一种不影响。
:::

::: theorem 先修改，后编辑 {#rule-revise-first}
1. **先通读全文**，不拿笔，像读者那样读。记下论证和结构上的问题；先什么也不改。
2. **从最大的单位往下修改**：先是论点和对问题的回答；然后是各段的顺序和要点；然后是每段内部的支撑。
3. **只有在结构确定之后才编辑**：先是句子，然后是语法和用词，最后是校对。
4. 只要可能，**在各遍检查之间留出时间**，在起草和修改之间也留出时间。
:::

::: proof
费格利和威特（Faigley and Witte，1981）把作者所做的修改分为**表面改动**（surface changes）和**意义改动**（meaning changes）：前者使文章的意义保持原样（拼写、时态、同义词、标点），后者改变文章所说的内容。在他们的研究中，缺乏经验的学生作者所做的大多是表面改动，而成年专家作者所做的意义改动要多得多——这与萨默斯（Sommers，1980）报告的对比相同。专家作者从上往下修改，是因为较高层面上的改动可以使较低层面的工作变得没有必要：编辑一个将被删掉的段落中的句子毫无意义。先读一遍而不改动，是这条规则中最难做到的部分，因为错误很扎眼；但一个在每个错误处都停下来的作者，永远看不到整体。修改之前停一停之所以有帮助，是因为刚写完初稿的作者读到的仍是自己想写的东西；过一天之后，他们读到的更多是纸上实际写的东西。
:::

::: quiz
哪一项改动是**修改**而不是编辑？
- [ ] 把全文的 *a lot of* 都换成 *many*
- [ ] 把 *The number of cars have fallen* 改成 *has fallen*
- [x] 把反方论点从第一个主体段挪到结论之前
- [ ] 把一个长句拆成两句
::: solution
挪动一个段落改变了论证的组织，所以是修改。其他几项改动的是用词、语法或句子的边界，而没有改变文章说的内容——属于编辑。
:::
:::

## 修改论证和结构

### 题目检验和论点检验

最先要问的修改问题，就是 [[essay-writing/writing-process#rule-revise]] 列出的那些：文章是否回答了问题？它的立场是否始终如一？两个快速的检验可以回答这两个问题。

::: theorem 检验整篇文章的两个方法 {#rule-two-tests}
1. **题目检验。** 把题目抄在初稿的最上方。紧接着读论点句和结论的第一句。它们回答的是不是**这个**问题——它的任务词、话题和限定（[[essay-writing/understanding-the-question#def-question-parts]]）？
2. **论点检验。** 把论点句和结论中的重申并排放在一起。它们给出的回答是否相同？如果不同，就判断主体部分支持的是哪一个，然后修改另一个。
:::

::: proof
这两个检验只要两分钟，却能发现代价最大的问题。一篇偏离题目的文章，通常是因为作者在起草时跟着自己的想法走，而这种偏离往往只有把开头和结尾放在一起读时才看得出来。结论与论点不一致，在学习者的文章中尤其常见：写主体部分的过程改变了作者的想法，这是好事，但在此之前写好的引言仍然表述着原来的观点。解决的办法是修改论点，使之与文章实际论证的内容相符，而不是把主体部分硬拉回原来的立场（[[essay-writing/conclusions#rule-restate]]）。
:::

### 反向提纲

::: definition 反向提纲 {#def-reverse-outline}
**反向提纲**（reverse outline）是**根据**初稿而不是在初稿之前制作的提纲。作者为每一段在页边用几个词写下：(1) 这一段**说**什么——它的要点；(2) 它**做**什么——它在论证中的任务（给出理由、举例、回应反对意见、作结论）。然后单独阅读这张要点清单，把它当作文章的骨架。
:::

::: theorem 使用反向提纲 {#rule-reverse-outline}
阅读各段要点的清单，并问：

1. **每一段是否只有一个要点？** 如果你需要两行字才能说清它说了什么，它可能需要拆分。
2. **有没有重复的要点？** 要点相同的两段应该合并，或者删掉其中一段。
3. **每个要点是否都支持或检验论点？** 两者都不做的要点就是离题的，不管多有趣。
4. **有没有缺什么**——论点许诺过的，或者读者会期待的东西——一个理由、一个反对意见、一个定义？
5. **顺序是不是最好的？** 如果两段交换位置，论证会不会更清楚？
:::

::: proof
初稿把结构藏在句子下面；反向提纲把它揭示出来。写下每一段**说**什么，迫使作者表述它的要点，而如果这一段根本没有要点，就很难写出来。写下它**做**什么，则揭示了论证的形状：三段都在*给出理由*，却没有一段在*回应反对意见*，这就是一个看得见的空缺。许多大学写作指南都推荐这种方法，它与 [[essay-writing/writing-process#def-outline]] 中的计划提纲正好相反：计划提纲说明文章应该做什么；反向提纲说明它实际上做了什么。
:::

::: example 一份反向提纲 {#ex-reverse-outline}
张雨的初稿有六段。她的反向提纲如下：

1. *Says*：城市很拥挤；停车占用空间；论点——把部分停车位改成公园和座椅。*Does*：引言，论点。
2. *Says*：公园使人更健康——散步，新鲜空气。*Does*：理由。
3. *Says*：座椅让老年人可以休息，在市中心停留更久。*Does*：理由。
4. *Says*：绿地有益健康，树木净化空气。*Does*：理由。
5. *Says*：我们镇上新建的广场很受家庭欢迎。*Does*：例子。
6. *Says*：商店需要开车来的顾客，所以城市应该保留停车位。*Does*：结论。

用 [[#rule-reverse-outline]] 中的问题为她的修改制定计划。
::: solution
1. **每段一个要点？** 基本上是。第1段把背景和论点结合在一起，引言本来就应该这样。
2. **重复**：第2段和第4段都论证绿地能改善健康。把它们合并成一个更有力的段落，把空气质量这一点作为其中的一部分保留下来。
3. **对论点的支撑**：第5段是一个例子，不是一个要点。它属于某个理由段的内部——很可能是关于人们在市中心停留更久的那一段（第3段）。
4. **缺失的部分**：引言中许诺的反方论点。关于商店和司机的反对意见出现了，但出现在**结论**里，在那里它推翻了论点。它需要单独成段，并得到回应（[[essay-writing/counter-arguments#rule-rebuttal]]）：例如，保留短时停车位和装卸区，并指出在宜人的市中心停留更久的人可能花钱更多。
5. **顺序和结论**：引言 → 健康（合并第2段和第4段）→ 停留更久（第3段 + 第5段的例子）→ 关于商店的反对意见及其回应 → 一个重申论点的新结论。

修改后的文章有五段而不是六段，回答了老师的全部三条评语。这些改动没有一项是对语言的编辑。
:::
:::

### 修改段落

结构一旦正确，就可以对照 [[essay-writing/arguing-a-point#rule-paragraph-shape]] 中的形状检查每一段：一个主张、一个解释、支撑，以及回扣论点。

::: theorem 修改一个主体段 {#rule-revise-paragraph}
对每个主体段，检查：

1. **主题句**表明了段落的要点，并显示了它与论点或上一段的关系（[[essay-writing/signposting#rule-paragraph-links]]）。
2. **解释**说明了要点为什么成立或怎样起作用，而不只是说它成立。
3. **支撑**——一个例子、证据、一个理由——具体、相关、准确。标出任何你无法注明出处的数字或事实；删掉它，或者找到出处。
4. **每一个句子**都围绕要点。挪走或删掉不围绕要点的句子。
5. 如果联系还不清楚，**最后一句**把要点与问题联系起来。
:::

::: example 修改一个段落 {#ex-revise-paragraph}
修改下面这个主体段，它出自一篇主张图书馆应该出借工具的文章。先不要编辑语言：只处理它的内容和顺序。

*Libraries are very important in our society. Many people use libraries every week. Lending tools would reduce waste. Lots of things are thrown away. My neighbour bought a ladder and used it once. Libraries are also quiet places to study. If tools are shared, fewer are made.*
::: solution
1. **找出要点。** 这一段真正的主张在第3句：*lending tools would reduce waste*（出借工具能减少浪费）。第1–2句是关于图书馆的泛泛之谈；第6句（安静的学习场所）离题了。
2. **找出解释。** 第7句解释了出借**怎样**减少浪费：共享工具意味着生产得更少。它应该紧跟在主张之后。
3. **找出支撑。** 第5句（邻居的梯子）是一则轶事。如果它能显示机制——为一次使用而买的工具——就可以作为例证保留下来，并以例证的身份出现。
4. **删掉**第1、2、6句。第4句（*Lots of things are thrown away*）太模糊，支撑不了任何东西。
5. **加上**与论点的**联系**。

修改稿（只改内容和顺序；语言以后再编辑）：

*Lending tools would reduce waste. If a tool is shared, fewer need to be made, and fewer end up thrown away after a few uses. Many tools are bought for a single job — a ladder for one repair, a drill for one set of shelves — and then kept for years or discarded. A library that lends them turns one object into many uses. That is a strong reason for libraries, which already exist to share things, to share tools too.*
:::
:::

::: warning 只修改表面
✗ 老师的评语是 *This paragraph does not answer the question.*，却去把 *good* 改成 *beneficial*、加上 *Moreover*、订正冠词。

读每一条评语，问一问它针对的是文章说**什么**，还是**怎样**说。针对内容的评语只能通过修改来回答。在一个没有要点的段落里加上同义词和连接词，会使它更长、更正式，但它仍然没有要点（[[essay-writing/signposting#rule-connectives]]）。
:::

## 针对语言进行编辑

编辑从结构确定之后开始。[[sentences-and-paragraphs/editing#rule-checklist]] 中的清单——句子边界、动词形式、一致、冠词、复数、介词、用词——适用于文章，也适用于任何文本。文章还有自己的四个关注点。

::: theorem 文章编辑的四遍检查 {#rule-edit-passes}
1. **语域。** 检查在文章中显得非正式的特征：缩约形式（*don't*），口语化的词语，以及有中性对应词时使用的短语动词（*a lot of*、*get*、*stuff*、*find out*），泛指人们的 *you*，以及感叹句。保持语域一致（[[collocation-and-register/register#rule-consistent]]）。
2. **简洁。** 删掉不起作用的词语：*It is a fact that*、*in today's modern world*、*the reason why … is because*、*in my personal opinion*、叠用的词（*each and every*）。在动词更清楚的地方，用动词代替围绕弱动词构成的名词短语（*make a decision* → *decide*）（[[style-and-rhetoric/concision]]）。
3. **主张的强度。** 对照支撑检查每一个主张：对文章没有证明的主张加上模糊限制（*may*、*often*、*tends to*），对已经证明的主张去掉模糊限制（[[modality/hedging-boosting#rule-what-to-hedge]]）。
4. **你自己的错误。** 查找你的错误记录显示你最常犯的错误（[[sentences-and-paragraphs/editing#rule-feedback]]）——对许多作者来说是一致、冠词、复数和逗号粘连——每次只查一类。

然后**校对**拼写、标点、数字和格式，最好在纸上校对，或者在改变字体或字号之后校对，使文本看起来陌生。
:::

::: proof
这几遍检查之所以分开，是因为每一遍都需要不同的注意力。检查语域意味着倾听文章的语气；检查简洁意味着追问每个短语是否值得保留；检查主张的强度意味着把所说的与所证明的相比较；检查错误则意味着放慢速度，降到单词的层面。一个同时寻找所有这些问题的读者，哪一种都看不到多少。对第二语言作者来说，查找个人错误是效率最高的一遍检查，因为错误的分布并不均匀：大多数作者反复犯的只是少数几类错误，有针对性的查找比泛泛地阅读能更快地发现它们。
:::

::: example 编辑一个段落 {#ex-edit}
针对语域、简洁和主张的强度编辑这一段。内容和顺序已经没有问题了。

*In today's modern world, it is a fact that lots of tools are bought for just one job and then they get thrown away. You don't need to own a drill that you'll use for ten minutes! Sharing tools definitely solves the problem of waste and will make our cities completely sustainable.*
::: solution
1. **语域**：*lots of* → *many*；*get thrown away* → *are thrown away*；*You don't need …*（第二人称、缩约形式、感叹句）→ 一个关于一般人的陈述。
2. **简洁**：*In today's modern world, it is a fact that* 什么也没有增加 → 删掉；*and then they* → *and then*。
3. **主张的强度**：*definitely solves* 和 *completely sustainable* 的主张远远超出一个关于工具的段落所能证明的 → 加上模糊限制并收窄。

> *Many tools are bought for a single job and then thrown away. Few households need to own a drill that will be used for ten minutes a year. Sharing tools would not solve the problem of waste, but it would reduce one part of it, at little cost.*

编辑后的段落更短，语域一致，只主张它能支撑的东西。
:::
:::

::: quiz
哪一个句子最适合正式文章？
- [ ] *You can't expect people to pay for something they'll hardly ever use.*
- [ ] *It is a well-known fact that in today's society nobody wants to pay for tools.*
- [x] *Few people are willing to pay for something they will rarely use.*
- [ ] *Absolutely nobody would ever pay for a tool they don't need!*
::: solution
第三句语域中性、简洁，主张也很有分寸。第一句用了 *you*、缩约形式和非正式的语气；第二句啰嗦，而且主张过度（*nobody*）；第四句主张过度，还以感叹号结尾。
:::

## 反馈：提供和利用

::: definition 反馈和同伴互评 {#def-feedback}
**反馈**（feedback）是读者对初稿的回应，目的是让作者改进它：来自老师、辅导员、同学或任何读过这篇文章的人的评语。**同伴互评**（peer review，也叫 *peer response*、*peer feedback*）是来自处于同一阶段的其他作者——通常是同学——的反馈，他们互相阅读初稿，常常有一套指导问题。
:::

::: theorem 对初稿提供反馈 {#rule-giving-feedback}
1. **先通读全文**，以读者的身份作出回应：按你的理解，论点是什么？最有说服力的要点是什么？你在哪里看糊涂了？
2. **先评论大的方面**：对问题的回答、结构、支撑。语法留到以后，除非错误使某一段难以理解。
3. **要具体**：指出某一段或某一句。*Paragraph 3 seems to make the same point as paragraph 2* 有帮助；*Good structure* 没有帮助。
4. **描述对你的影响**，而不是下结论：*I wasn't sure here whether this was your view or the opposing view* 比 *This is wrong* 更便于利用。
5. **建议，而不是改写**：提出问题，给出选择；文章属于作者。
6. **具体地说出哪些地方写得好**，让作者保留下来。
:::

::: proof
作者需要知道自己的文章在别人读来是什么样子，而这恰恰是他们自己读不出来的东西。同伴读者对语法的了解可能不如老师，但能准确地说出自己在哪里失去了线索，或者误解了论点，而这些信息正是修改所需要的。描述影响而不是下结论，把决定权留给作者，也避免了关于趣味的争论。关于同伴互评的研究表明，评阅者也能从中学到东西：伦德斯特罗姆和贝克（Lundstrom and Baker，2009）发现，接受过提供同伴反馈训练的英语学习者大学生，一个学期下来自己写作的进步，比只接受反馈的学生更大。
:::

::: theorem 利用反馈 {#rule-using-feedback}
1. **给评语分类**：修改类（内容、结构、支撑）和编辑类（语言）。先处理第一类。
2. **寻找规律**：两位读者都提出的评语，或者老师在几篇文章上都写了的评语，是最重要的。
3. **作出决定**：你是作者。不是每一条建议都能改进你的文章；如果你不同意，要说得出为什么。但一条说读者感到困惑的评语，是关于读者阅读体验的事实，即使他们建议的解决办法不对。
4. 对任何看不懂的评语，**提出疑问**。
5. **自己订正标出的错误**，并在错误记录中记下它们的类型（[[sentences-and-paragraphs/editing#rule-feedback]]）。
:::

::: proof
关于书面反馈的研究一直是一场长期争论的主题。特拉斯科特（Truscott，1996）认为，纠正第二语言作者的语法错误是无效的，甚至可能有害；费里斯（Ferris，1999）回应说，证据并不支持放弃纠错，清楚的、有选择的反馈可能有帮助。比切纳和费里斯（Bitchener and Ferris，2012）综述的后续研究发现了证据，表明有针对性的书面纠错能提高准确性，尤其是在只针对少数几类错误时；同时也表明，作者怎样利用反馈与反馈本身同样重要。对于内容和结构的修改，主要的启示是实际的：具体的、分清主次的、并且被付诸行动的评语会改变初稿；读一遍就归档的评语不会。
:::

::: example 回应同伴的初稿 {#ex-peer}
一位同学的文章回答 *Should secondary schools start later in the morning?* 她的引言以 *There are advantages and disadvantages to starting school later.* 结尾。她的三个主体段都主张推迟上课时间；她的结论说 *schools should start at half past nine.* 文中有十几处冠词错误。按照 [[#rule-giving-feedback]] 写四条评语。
::: solution
答案不唯一。评语范例：

1. **以读者的身份**：*I understood from your conclusion that you think schools should start later — at 9.30 — and your three paragraphs all argue for that. Your paragraph on sleep, with the explanation of teenagers' body clocks, convinced me most.*
2. **最大的问题**：*Your introduction doesn't tell me your view yet — it says there are advantages and disadvantages. Could the last sentence say what your conclusion says, so that I know from the start where you stand?*
3. **一个空缺**：*I kept thinking about parents who start work early. Would a paragraph on that objection, and your answer to it, make the essay stronger?*
4. **编辑，留到最后**：*There are some article errors (I've underlined a few in paragraph 2) — maybe one to check when you edit.*

这些评语从写得好的地方开始，先指出最大的问题，提出建议而不是改写，并把语法留到最后。
:::
:::

::: warning 照单全收——或者一概不收
两种相反的习惯都会浪费反馈。有些作者读者建议什么就改什么，包括相互矛盾的建议，或者出于误读的建议；结果可能东拼西凑。另一些作者为每一个句子辩护，什么也不改。把每一条评语当作关于文章是怎样被阅读的信息，判断问题是什么，然后自己选择解决办法。
:::

### 软件和自动化工具

截至2026年，许多作者使用拼写和语法检查工具、翻译工具以及人工智能写作助手。拼写和语法检查工具能发现许多表面错误，也会漏掉一些：它们能标出错误的动词形式，却标不出拼写正确而在语境中用错的词（把 *there* 写成 *their*，把 *from* 写成 *form*），而且它们的有些建议本身就是错的（[[sentences-and-paragraphs/editing]]）。对于文章是否回答了问题，它们说不出任何有用的东西。改写或生成整句的工具则引出一个不同的问题，它根本与语言无关：这份作业是否仍然是你自己的。中学、大学和考试对允许哪些帮助都有自己的规定，而且这些规定会变化；使用任何工具之前，先弄清楚规定是什么，绝不要把不是你写的文字当作自己的交上去（[[academic-writing/academic-integrity]]）。即使在允许使用工具的地方，本课的修改问题——论点是否清楚，每段是否有要点，结论是否顺理成章——也必须由作者自己来回答。

::: note 英汉对比
- **修改和润色。** 汉语的“修改”同时涵盖修改（revising）和编辑（editing），“润色”则侧重语言；英语的这一区分值得保留，因为一份需要修改的初稿，靠润色是改不好的。
- **教师反馈和同伴反馈。** 主要通过教师批改来学习的学生，起初可能觉得同学的评语不如老师的可靠，或者不愿意批评同学的作品。这并不是哪一种文化所特有的，而且会随着练习而改变。卡森和纳尔逊（Carson and Nelson，1996）对美国一个同伴互评班上的中国学生做了一项小型研究，发现对群体和谐的顾虑影响了学生愿意说什么；在台湾，闵（Min，2006）发现，学生在接受了怎样提供反馈的训练之后，他们的评语变得更有用，同伴在修改时也采纳了更多的评语。[[#rule-giving-feedback]] 中的指导原则——描述影响、要具体、提出建议——使批评性的评语更容易给出，也更容易接受。
- **范文。** 向范文学习是中国写作教育的一个悠久传统，也很有用：范文显示了一篇完成的文章是什么样子。但在修改时，问题不是 *How close is my essay to the model?*（我的文章离范文有多近？），而是 *Does my essay answer this question?*（我的文章回答了这个问题吗？）一份朝着背诵过的范文修改的初稿，常常会失去自己的论证。
- **编辑中的翻译。** 部分用汉语起草、或者通过翻译来检查句子的作者，应该把结果当作英语来编辑：翻译出来的句子常常保留汉语的语序、双重连接词（虽然……但是）和全角标点（，。）。专门查找这些问题。
:::

::: history
修改和写作一样古老，著名作家的手稿显示了修改可以走多远。威廉·华兹华斯（William Wordsworth）几乎用了一生的时间来写他的自传体长诗《序曲》（*The Prelude*）：1799年的两卷本，1805年的十三卷本，以及他去世后于1850年出版的十四卷本，它们在许多段落和整体结构上都有差异。对普通作者怎样修改的系统研究则开始得晚得多。南希·萨默斯（Nancy Sommers，1980）比较了学生作者和有经验的作者，莱斯特·费格利和斯蒂芬·威特（Lester Faigley and Stephen Witte，1981）提出了表面改动与意义改动的区分。把同伴当作读者的做法也在同一时期发展起来：彼得·埃尔博（Peter Elbow）的《没有老师的写作》（*Writing Without Teachers*，1973）描述了作者小组在没有老师的情况下互相回应初稿，肯尼斯·布鲁菲（Kenneth Bruffee）在20世纪70和80年代关于协作学习的研究，帮助使同伴互评成为美国写作课的常规部分，并从那里传播到第二语言教学中。
:::

## 后续内容

一次写完一篇文章，只有几分钟时间修改和检查，是 [[essay-writing/timed-essays]] 的主题。为清晰、简洁和文体而编辑，在 [[style-and-rhetoric/editing-for-style]]、[[style-and-rhetoric/concision]] 和 [[style-and-rhetoric/clarity]] 中展开；研究写作的同行评审是发表过程的正式环节，见 [[academic-writing/peer-review]]。基本的编辑清单、错误代码和错误记录见 [[sentences-and-paragraphs/editing]]，学术写作的语域见 [[collocation-and-register/register]] 和 [[academic-writing/academic-style]]。

::: summary
- 修改改变文章说什么以及怎样组织；编辑改变它怎样说；校对是最后对笔误的查找（[[#def-revising-editing]]）。
- 先修改后编辑，在通读全文而不改动之后，从最大的单位往下修改（[[#rule-revise-first]]）。
- 用题目检验和论点检验检查整篇文章（[[#rule-two-tests]]）。
- 反向提纲——每段说什么、做什么——揭示重复、空缺、离题的段落和更好的顺序（[[#def-reverse-outline]]、[[#rule-reverse-outline]]）。
- 针对主题句、解释、支撑、统一性以及与论点的联系修改每一段（[[#rule-revise-paragraph]]）。
- 分几遍编辑文章：语域、简洁、主张的强度以及你自己常犯的错误，然后校对（[[#rule-edit-passes]]）。
- 以读者的身份提供反馈：先大后小，具体，描述影响，提出建议而不是改写（[[#rule-giving-feedback]]）；利用反馈时，分类、寻找规律，并以作者的身份作出决定（[[#rule-using-feedback]]）。
- 语法检查工具和其他工具能发现一些表面错误，但不能修改论证；遵守关于允许使用哪些工具的规定。
:::

## 练习

::: exercise 修改还是编辑？ {level=1}
每一项改动是修改还是编辑？(a) 删掉一个没有回答问题的段落。(b) 把 *don't* 改成 *do not*。(c) 加一个回应反对意见的段落。(d) 把 *make an improvement* 换成 *improve*。(e) 重写论点，使它与结论相符。(f) 把 *informations* 改成 *information*。
::: solution
修改：(a)、(c)、(e)。编辑：(b)、(d)、(f)。
:::
:::

::: exercise 说什么和做什么 {level=1}
对于每个段落概要，说出这一段*做*什么：给出理由、举例、提出反对意见、回应反对意见、引入或作结论。(a) *Critics argue that free museums lose income.* (b) *Free entry brings in families who could not afford tickets.* (c) *A museum in the writer's own town became much busier after it stopped charging.* (d) *Other income — shops, donations, paid exhibitions — can replace ticket sales.* (e) *Free entry is a condition of a museum doing its public job.*
::: solution
(a) 提出反对意见。(b) 给出理由。(c) 举例。(d) 回应反对意见。(e) 作结论（如果放在开头，则是连同论点一起引入）。
:::
:::

::: exercise 语域和简洁 {level=1}
为正式文章编辑每个句子。(a) *Lots of people reckon that cycling is way better than driving.* (b) *The reason why this is important is because it saves money.* (c) *In my personal opinion, I think that schools should do something about it.* (d) *You can't really blame them for not wanting to pay.*
::: solution
可能的答案：(a) *Many people believe that cycling is much better than driving.* (b) *This is important because it saves money.* (c) *Schools should act on this.*（或 *In my view, schools should …*）(d) *Their unwillingness to pay is understandable.*
:::
:::

::: exercise 写一份反向提纲 {level=2}
为这份短文计划写一份反向提纲（说什么 / 做什么），并说出两个需要修改的问题。*(1) Introduction: online shopping is growing; thesis — it is better for most people than shopping in person. (2) Online shopping saves time. (3) Online prices are often lower. (4) Shopping in person lets you see and touch goods before buying. (5) Online shopping saves money because prices are lower. (6) Conclusion: both kinds of shopping have advantages.*
::: solution
反向提纲：(1) 说网购更好 / 引入并表明论点；(2) 说节省时间 / 理由；(3) 说价格更低 / 理由；(4) 说实体店购物可以看到商品 / 反对意见，但没有回应；(5) 说省钱 / 理由——与 (3) 相同；(6) 说两种购物各有优点 / 作结论，但从论点后退了。

问题：第3段和第5段说的是同一点——合并；第4段是一个没有反驳的反对意见——回应它（例如，退货政策、评价）；结论与论点不符——重写，使它重申论点。任选两个。
:::
:::

::: exercise 加模糊限制还是加强？ {level=2}
每个主张都出自一篇只举了一两个例子、没有系统证据的文章。改写每个主张，使它的强度与支撑相称。(a) *Remote working always makes employees happier.* (b) *Free buses will certainly end traffic congestion.* (c) *Street trees reduce summer temperatures.*（主体部分引用了一项有测量数据的研究。）
::: solution
可能的答案：(a) *Remote working often makes employees happier*，或 *can make many employees happier*。(b) *Free buses may reduce congestion slightly, but are unlikely to end it.* (c) 主体部分引用了证据，所以这个主张可以成立，也许可以加上它的范围：*Street trees reduce summer temperatures in the streets they shade.*
:::
:::

::: exercise 给反馈分类 {level=2}
一名学生收到了这些评语。把它们分为修改类和编辑类，并把修改类评语按重要性排序。(a) *Your conclusion doesn't answer the question.* (b) *Check your use of "the" in paragraph 2.* (c) *Paragraph 3 needs an example.* (d) *Contractions are too informal for an essay.* (e) *I can't tell whether paragraph 4 is your view or the opposing view.* (f) *Spelling: "enviroment".*
::: solution
修改类：(a)、(e)、(c)。编辑类：(b)、(d)、(f)。

顺序：(a) 最先——一篇没有回答问题的文章在最高层面上就失败了；(e) 其次——对立场的困惑影响整个论证的阅读，可以通过标示反方论点来解决（[[essay-writing/counter-arguments#rule-placing]]）；(c) 最后——在一个段落内部补充支撑。
:::
:::

::: exercise 修改并编辑一个段落 {level=3}
这一段出自一篇主张中学应该教烹饪的文章。先修改它（内容和顺序），再编辑它（语言），并展示两个阶段。

*Nowadays, with the development of society, cooking is a very important skill. Lots of young people can't cook. Fast food is popular. My cousin only eats instant noodles. If people can cook, they can eat more healthily, because they control what goes into their food. Cooking is also fun. Therefore, schools should definitely teach cooking to every single student.*
::: hint
这一段真正的要点是什么？哪些句子解释它，哪些说明它，哪些离题或空洞？
:::
::: solution
**修改。** 要点是健康：会做饭的人能控制食物里放什么。空洞的开头（*Nowadays, with the development of society*）删掉；*Cooking is also fun* 是另一个要点，删掉（或者移到另一段）；*Fast food is popular* 和表弟的方便面可以变成一个简短的例证，说明年轻人不会做饭时会发生什么；最后一句与论点相联系。

**编辑后的版本：**

> *Teaching cooking at school would help young people to eat more healthily. A person who can cook controls what goes into a meal — how much salt, sugar and fat, and how many vegetables — while a person who cannot depends on ready-made food, whose contents someone else has chosen. Many young people leave home without knowing how to prepare a simple meal, and fall back on instant noodles and takeaways. A short practical course at secondary school would give every student the skill to choose otherwise, which is why cooking deserves a place in the curriculum.*

检查：一个要点；对机制的解释；用一般性的说法作例证（表弟换成了一个普遍的现象，如果作为事实陈述，需要注明出处）；没有非正式的语言（*lots of*、*can't*）；过度的主张（*definitely … every single student*）换成了一项建议。
:::
:::

::: exercise 提供反馈 {level=3}
下面是一篇为这个练习而写的短文（约180词）。按照 [[#rule-giving-feedback]] 对它写四条评语，然后说出作者应该首先根据哪一条评语采取行动。

*Should cities ban fireworks?*

*Fireworks are very popular all over the world. They are used at many festivals. There are good and bad points about fireworks.*

*Firstly, fireworks are dangerous. Every year, people are injured, especially children. Moreover, they frighten pets and wild animals.*

*Secondly, fireworks cause noise and air pollution. Furthermore, the smoke can make the air unhealthy for hours.*

*On the other hand, fireworks are an important part of many traditions and celebrations. People enjoy watching them, and public displays bring communities together.*

*In conclusion, fireworks have advantages and disadvantages. Cities should think carefully about this issue.*
::: solution
答案不唯一。评语范例：

1. *Your second and third paragraphs gave me clear reasons — safety, and noise and pollution — and the point about pets was one I hadn't thought of.*
2. *I couldn't tell what your answer to the question was: the introduction and conclusion both say there are good and bad points. What do you think — ban all fireworks, ban private ones, or allow them? If your thesis said that, I'd read the body knowing where it was going.*
3. *Your fourth paragraph gives a strong argument against a ban, but nothing answers it. If you think cities should ban fireworks, how would you respond to people who value the traditions? (Could public displays be allowed while private fireworks are banned?)*
4. *The claim about injuries every year would be stronger with a source, or with "can be injured" if you don't have one.*

作者应该首先根据第2条评语采取行动：没有立场，文章就没有回答问题，而立场决定了应该怎样回应第4段，以及结论应该说什么。
:::
:::
