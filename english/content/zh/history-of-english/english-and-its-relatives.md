把四个表示“父亲”的词并排放在一起：英语 *father*，荷兰语 *vader*，拉丁语 *pater*，梵语 *pitár-*。它们的相似一目了然，但这还不足以证明任何东西——英语 *bad* 和波斯语 *bad* 看起来也很像，意思也一样（“坏”），而它们彼此毫无关系。现在再加上四个表示“脚”的词：*foot*，*voet*，*pes*（词干 *ped-*），*pad-*；以及四个表示“鱼”的词：*fish*，*vis*，*piscis*，还有古爱尔兰语的 *íasc*。更有意思的东西出现了：凡是拉丁语和梵语在词首有 *p* 的地方，英语都是 *f*，荷兰语是 *f* 或 *v*。这不是相似，而是**对应**（correspondence），它在几百个词里反复出现，而如此规则的对应不可能出于偶然。它证明英语、荷兰语、拉丁语和梵语都是从同一种无人记录下来的祖先语言演变而来的。

本章说明语言学家怎样把语言归入语系，以及英语在世界上最大的语系——印欧语系——中处于什么位置。它介绍英语所属的日耳曼语族，最先把日耳曼语和它的亲属语言分开的那条音变定律，以及用来部分构拟一种五千多年前所说的语言的方法——历史比较法。它还解释为什么英语词汇在纸面上看起来那么不像日耳曼语，而英语却仍然被归为日耳曼语。许多例子来自[[word-formation/greek-latin-roots]]中的拉丁语和希腊语词根：在这里你会看到，其中一些借来的词根是英语本族词的远房表亲。

## 语系

语言一直在变化，而且在不同的地方变化不同。一个群体分裂之后——因为迁徙、征服、高山或大海——每一部分的语言都会继续变化，过了足够多的世纪，各部分之间就再也听不懂了。拉丁语在有文字记载的历史中就经历了这一过程：西罗马帝国各地所说的拉丁语，在大约一千年里变成了葡萄牙语、西班牙语、加泰罗尼亚语、法语、意大利语、罗马尼亚语和许多其他语言。在这个例子里，我们有祖先语言的文字记录。在大多数情况下我们没有，祖先语言只能从它的后代推断出来。

::: definition 语系，同源词 {#def-family}
**语系**（language family）是从同一种更早的语言——它们的**原始语**（proto-language）——演变而来的一组语言。一个语系的各种语言彼此有**亲缘关系**（genetically related）——这是借自生物学的比喻，意思是谱系上的传承，与基因无关。**语族**（branch）是语系中的一个子群，它有一个属于自己的、较晚的共同祖先（日耳曼语族、罗曼语族、斯拉夫语族）。

亲属语言中由原始语的同一个词演变而来的词叫作**同源词**（cognates）：英语 *father*，德语 *Vater*，拉丁语 *pater*。同源词不一定长得像——英语 *hundred* 和拉丁语 *centum* 是同源词——而长得像的词也不一定是同源词。
:::

词与词之间的另外两种关系必须和同源关系区分开来。**外来词**（loanword）是从另一种语言借来的词：英语 *paternal* 不是拉丁语 *pater* 的同源词，而是从它借来的（经由中世纪拉丁语 *paternalis*）。还有一些词是**偶然**（chance）相似：每种语言只有几十个音而有成千上万个词，巧合是免不了的。

::: theorem 历史比较法 {#rule-comparative}
证明语言之间有亲属关系、并构拟它们的原始语，用的是**历史比较法**（comparative method）：

1. 收集**基本词汇**（basic vocabulary）——数词、亲属称谓、身体部位、代词、常用动词——这些词很少被借用。
2. 寻找**规则的语音对应**（regular sound correspondences）：一种语言里的一个音，在许多词里、在相同的位置上，都对应另一种语言里的同一个音（拉丁语 *p-* : 英语 *f-*，见于 *pater*/*father*，*pes*/*foot*，*piscis*/*fish*，*plenus*/*full*）。
3. 用**条件**（音的位置、重音、相邻的音）或借用来解释例外，而不是为个别情况找特殊理由。
4. 为每一组对应构拟原始语中的一个音，使每个有文献记录的音都能通过合理的变化从它推导出来。语言学书籍用星号标记构拟形式；本图谱用 *Proto-Indo-European*（原始印欧语，PIE）或 *Proto-Germanic*（原始日耳曼语）这些词来标明，并用斜体书写：PIE *ph₂tḗr*“父亲”（*h₂* 代表一个已经消失的辅音；见历史注）。
5. 还要用**共有的语法**（shared grammar）来证实亲属关系——尤其是不规则形式和词尾，因为这些几乎从不被借用。
:::

::: proof
这种方法之所以有效，是因为音变在很大程度上是**有规律的**（regular）：一个音在一个群体中发生变化时，它在相同条件下出现的每一个词里都会变化。这一原则由莱比锡的“新语法学派”在1878年作为定律提出。虽然它有已知的局限（有些变化是一个词一个词地在词汇中扩散的，[[linguistics/variation-change]]会说明这一点），但在几个世纪的尺度上它足够可靠，所以一个在几十个基本词中反复出现的对应，几乎不可能是偶然。单凭相似什么也证明不了，因为偶然和借用都会造成相似。基本词汇中的规则对应，加上语法中共有的不规则现象，才是偶然和借用造不出来的。注意这种方法做不到什么：它构拟的是一套对应系统，而不是一段录音。我们不知道 PIE 听起来具体是什么样子，只知道它必定有哪些区别。
:::

::: warning 看着像不等于证据
✗ 英语 *bad* 和波斯语 *bad* 意思相同，所以这两个词有亲属关系。它们没有：这种相似是巧合，而且英语 *bad* 根本没有已知的同源词。
✗ 拉丁语 *deus* 和希腊语 *theos*（“神”）一定是同源词。它们不是：希腊语的 *th-* 和拉丁语的 *d-* 没有规则的对应。
✗ 英语 *day* 来自拉丁语 *dies*。不是：*day* 是日耳曼语词（德语 *Tag*），而拉丁语 *dies* 和 *deus* 以及 *Zeus*（宙斯）这个名字属于一类。
✓ 英语 *ten* 和拉丁语 *decem* 是同源词，尽管它们看起来没那么像，因为 *t* : *d* 是一个规则的对应（*two* : *duo*，*tooth* : *dent-*，*eat* : *edere*）。

一定要问：这种相似是否有规律，是否出现在基本词汇中，以及一种语言是否可能从另一种语言借来了这个词。
:::

::: example 检验一个所谓的同源词 {#ex-test}
有人说英语 *much* 和西班牙语 *mucho*（“多”）是同源词。用[[#rule-comparative]]检验这个说法。
::: solution
1. **是基本词汇吗？** 是，两个都是常用词——所以借用的可能性不大，这个说法值得检验。
2. **有规则的对应吗？** 西班牙语来自拉丁语，所以要看拉丁语的 *multum*“多”。如果这两个词是同源词，拉丁语的 *-lt-* 就必须对应英语的 *-ch*；但没有别的词对显示这样的对应。
3. **每个词自己的历史。** 英语 *much* 来自古英语 *micel*“大的”（苏格兰语至今还有 *mickle*），它与希腊语 *megas*“大的”同源——这是格林定律中的 *g* → *k*。西班牙语 *mucho* 来自拉丁语 *multum*，经过了西班牙语中 *-ult-* 变为 *-uch-* 的规则变化（如 *cuchillo*“刀”来自拉丁语 *cultellum*）。
4. **结论。** 这两个词有不同的祖先；它们今天的相似是各自独立的变化造成的巧合。*much* 在拉丁语里真正的同源词是 *magnus*“大的”——英语也有它，是借来的，见于 *magnify* 和 *magnitude*。
:::
:::

## 印欧语系

欧洲的大多数语言，以及南亚和西亚的许多语言，都属于一个语系——**印欧语系**（Indo-European），它得名于欧洲扩张时代之前这个语系最东和最西的语族。以其中现存语言为第一语言的人，几乎占世界人口的一半。

| 印度-伊朗语族 | 梵语、阿维斯陀语 → 印地语-乌尔都语、孟加拉语、旁遮普语、马拉地语；波斯语、普什图语、库尔德语 |
| 希腊语族 | 古希腊语 → 现代希腊语 |
| 意大利语族 | 拉丁语 → 罗曼诸语言：葡萄牙语、西班牙语、加泰罗尼亚语、法语、意大利语、罗马尼亚语 |
| 凯尔特语族 | 高卢语、古爱尔兰语 → 爱尔兰语、苏格兰盖尔语、威尔士语、布列塔尼语 |
| 日耳曼语族 | 哥特语、古诺尔斯语、古英语 → 英语、德语、荷兰语、弗里西语、斯堪的纳维亚诸语言 |

| 安纳托利亚语族（已消亡） | 赫梯语、卢维语 |

有两个语族只见于古代文献。**赫梯语**（Hittite）是今天土耳其境内一个古代帝国的语言，保存在公元前2千纪用楔形文字书写的泥板上；1915年捷克学者赫罗兹尼（Bedřich Hrozný）确认它属于印欧语系。**吐火罗语**（Tocharian）见于在塔里木盆地——今天的新疆，库车和吐鲁番附近——发现的大约公元6至8世纪的佛教写本：它是古代世界最东边的印欧语言，使用于中亚腹地。

原始印欧语在何时何地使用，是这个领域里持续最久的争论之一。**草原假说**（steppe hypothesis）与金布塔斯（Marija Gimbutas）的名字相联系，其现代形式则与安东尼（David Anthony，《马、车轮和语言》（*The Horse, the Wheel, and Language*），2007）相联系，它把原始印欧语定位于黑海和里海以北的草原，时间大约在公元前4500–3000年；PIE 中共有的表示车轮、车轴和马车的词汇，说明它的年代晚于轮式运输的发明。伦弗鲁（Colin Renfrew）1987年提出的**安纳托利亚假说**（Anatolian hypothesis）则把这个语系的扩散与几千年前农业从安纳托利亚向外传播联系起来。2015年以来，古 DNA 研究显示，公元前3千纪有大规模的人群从草原迁入欧洲，大多数学者认为这支持草原假说，至少对欧洲的各语族而言如此；不过这个问题并没有定论。对学习者来说，要点很朴素：构拟出来的语言是真实的——就像它的后代是真实的一样——但关于说这种语言的人的每一种说法都是推断。

哪一组可以作为两种语言有亲属关系的证据？

- [ ] 英语 *paternal* 和拉丁语 *paternus*，都是“父亲的”
- [x] 英语 *three*、*thin*、*thou* 与拉丁语 *tres*、*tenuis*、*tu*
- [ ] 英语 *mama* 和普通话“妈妈” *māma*
::: solution
第三个选项显示了一个**规则的**对应——英语 *th-* 对应拉丁语 *t-*——而且出现在好几个基本词中。*bad* 是偶然相似；*paternal* 是拉丁语外来词，所以它显示的是接触，而不是传承；而 *mama* 和 *papa* 这类词在许多语言中独立产生，因为它们是婴儿最早发出的音节之一。
:::

## 格林定律：日耳曼语是怎样分出来的

日耳曼语之所以构成一个语族，是因为它的各种语言共有一组其他语族都没有的变化。其中最著名的是辅音的一次转移，由丹麦学者拉斯克（Rasmus Rask，1818）发现，并由雅各布·格林（Jacob Grimm）在其《德语语法》（*Deutsche Grammatik*）第二版（1822）中系统地表述出来。它在英语中称为**格林定律**（Grimm's law），也叫第一次日耳曼语辅音转移。

::: theorem 格林定律 {#rule-grimm}
从原始印欧语发展到原始日耳曼语的过程中，三组塞音像链条一样依次转移：

1. 清塞音 ***p, t, k*** 变成擦音 ***f, θ, h***：拉丁语 *pater* – *father*；拉丁语 *tres* – *three*；拉丁语 *centum*（*c* = /k/）– *hundred*；拉丁语 *cornu* – *horn*。
2. 浊塞音 ***b, d, g*** 变成清音 ***p, t, k***：拉丁语 *decem* – *ten*；拉丁语 *dent-* – *tooth*；拉丁语 *genu* – *knee*；拉丁语 *granum* – *corn*。（PIE 的 *b* 很少见，所以 *b* → *p* 的例子不多。）
3. “浊送气”塞音 ***bh, dh, gh*** 变成 ***b, d, g***：梵语 *bhrātar-* – *brother*；梵语 *dhā-*“放” – *do*；拉丁语 *hostis* 的词根（PIE *ghosti-*）– *guest*。

拉丁语、希腊语和梵语没有经历这次转移（尽管它们各有自己的变化：PIE 的 *bh* 在拉丁语 *frater* 里是 *f*，在希腊语 *phrātēr* 里是 *ph*），所以它们的辅音通常更接近原始语。
:::

::: proof
证据是这些对应在基本词汇中的规律性：一旦认出这三组音，几十对同源词就排列整齐了——*foot* : *ped-*，*fish* : *piscis*，*fire* : 希腊语 *pyr*，*thin* : *tenuis*，*heart* : *cord-*，*hound* : *canis*，*two* : *duo*，*eat* : *edere*，*cold* : *gelidus*，*bear*（“携带”）: 梵语 *bhar-*。这些变化构成一条链：如果浊塞音在旧的清塞音变成擦音之前就变成了清音，那么 *ten* 今天就会以 *th* 开头。所以变化的顺序也是这个假说的一部分。这次转移还解释了英语**内部**的词对，其中一个词是继承来的，另一个是从拉丁语借来的：*father* / *paternal*，*foot* / *pedal*，*fish* / *piscine*，*three* / *triple*，*heart* / *cordial*，*hound* / *canine*，*tooth* / *dental*，*ten* / *decimal*，*corn* / *grain*。每一对都是同一个 PIE 词根两次进入英语：一次通过继承，经历了格林定律；一次通过借用，没有经历格林定律。
:::

格林定律有例外，而解释这些例外是历史比较法的一次胜利。为什么哥特语的 *fadar*“父亲”是 *d*，而 *brōþar*“兄弟”是 *þ*（= /θ/），尽管这两个词在 PIE 中都是 *t*？1875年，丹麦语言学家维尔纳（Karl Verner）在一篇两年后发表的论文中指出，答案在于原始语中重音的位置，而梵语保存了这个位置：*pitár-* 的重音在 *t* 之后，而 *bhrā́tar-* 的重音在 *t* 之前。凡是 PIE 重音不紧挨在前面的地方，新产生的擦音就变成了浊音。**维尔纳定律**（Verner's law）把一个表面上的例外变成了规律性的证明。它还解释了现代英语中至今可见的一组交替：*was* 和 *were*。*s* 和 *r* 原本是同一个音；在复数形式中，古时的重音位置不同，于是它先变成 *z*，再变成 *r*。（现代 *father* 中的 *th* 是英语晚得多的一次变化：古英语是 *fæder*，读 /ð/ 的 *father* 要到1500年前后才通行。）

::: example 运用格林定律 {#ex-grimm}
用格林定律找出每个拉丁语词在英语本族词中的同源词，再举出一个从该拉丁语词借来的英语词。

1. 拉丁语 *pes*，*ped-*“脚”
2. 拉丁语 *cor*，*cord-*“心”
3. 拉丁语 *genu*“膝”
4. 拉丁语 *tres*“三”
5. 拉丁语 *frater*“兄弟”
::: solution
1. *p* → *f*，*d* → *t*：**foot**。借词：*pedal*，*pedestrian*。
2. *k* → *h*，*d* → *t*：**heart**（元音不同，元音常常如此）。借词：*cordial*“发自内心的，热情的”，以及经由法语借入的 *courage*。
3. *g* → *k*：**knee**。这个 *k* 在古英语里是发音的，至今仍然写出来（[[sounds-of-english/spelling-and-sound#rule-silent]]）；德语 *Knie* 至今还读出它。借词：*genuflect*“屈膝”。
4. *t* → *θ*：**three**。借词：*triple*，*trio*，*trinity*。
5. 这一题是个陷阱：拉丁语的 *f-* 本身是 PIE *bh* 在拉丁语中的演变结果，而格林定律在日耳曼语中把 *bh* 变成了 *b*：**brother**。借词：*fraternal*，*fraternity*。直接比较拉丁语和英语，得到的是 *f* : *b*，这个对应是规则的，但只是因为两者都来自 *bh*。

这些词对说明了为什么人们说英语词汇有两个层次：表示日常事物的日耳曼本族词，以及表示学术或抽象意义的、以拉丁语为基础的形容词。
:::
:::

::: quiz
拉丁语 *duo* 和英语 *two* 是同源词。你认为哪个拉丁语词对应英语 *tooth*？
- [x] *dent-*，如 *dental*
- [ ] *tot*
- [ ] *thent-*
- [ ] *pent-*
::: solution
根据格林定律，PIE 的 *d* 变成了日耳曼语的 *t*，所以拉丁语的 *d* 对应英语的 *t*：*duo* / *two*，*decem* / *ten*，以及 *dent-* / *tooth*。（英语 *tooth* 还在 *th* 前丢失了一个 *n*；古英语 *tōþ* 和德语 *Zahn* 对照可以看出这一点。）
:::
:::

## 日耳曼语族

原始日耳曼语大概在公元前最后几个世纪通行于斯堪的纳维亚南部和德国北部沿海。说这种语言的人与罗马人有接触，从他们那里借入了一些词，比如英语 *street*（拉丁语 *strata*）、*wine* 和 *cheese* 的祖先形式；最早的日耳曼语文字是如尼文（runes），大约从公元2世纪开始刻写。最著名的早期铭文之一刻在丹麦加勒胡斯（Gallehus）出土的一只金角杯上，年代约为公元400年：*ek hlewagastiz holtijaz horna tawido*“我，霍尔特之子（或：霍尔特的）赫勒瓦加斯提兹，制作了这只角杯”。在 *horna* 里你能看到 *horn*，而 *ek* 是 *I* 的祖先（比较德语 *ich*）。

::: definition 日耳曼语的分支 {#def-germanic}
日耳曼诸语言通常分为三支：

- **东日耳曼语支**（East Germanic），已经消亡，主要通过**哥特语**（Gothic）为人所知；哥特语的材料来自4世纪主教乌尔菲拉（Wulfila）翻译的《圣经》——这是所有日耳曼语言中最早的成篇文献。
- **北日耳曼语支**（North Germanic）：**古诺尔斯语**（Old Norse）及其后代冰岛语、法罗语、挪威语、丹麦语和瑞典语。
- **西日耳曼语支**（West Germanic）：**古英语**（Old English）、古弗里西语、古撒克逊语、古荷兰语和古高地德语，以及它们的后代英语、苏格兰语、弗里西语、荷兰语（及南非荷兰语）、低地德语、德语和意第绪语。

英语和弗里西语、古撒克逊语以及荷兰语的部分特征同属一个子群，有时称为**北海日耳曼语**（North Sea Germanic，又称 *Ingvaeonic*）；在这个子群里，英语和弗里西语尤其接近。
:::

除了格林定律，还有什么使这些语言都成为“日耳曼语”呢？有几个其他语族所没有的特征：

- **重音落在词根的第一个音节上。** PIE 的重音可以落在一个词的不同音节上；日耳曼语把它固定在词根的第一个音节上。这就是为什么英语本族词的重音在词首（*father*，*mother*，*happy*，*water*），为什么 *be-*、*for-* 这样的前缀不重读（*become*，*forget*），以及为什么许多词尾后来弱化并消失了——这是后面几章要讲的故事。
- **用齿音后缀构成过去时。** 除了旧有的元音变化模式（*sing* – *sang*），日耳曼语还创造了一种新的过去时，带 *-d-* 或 *-t-* 后缀：哥特语 *nasida*“救了”，古英语 *lufode*“爱了”，现代英语 *walked*，德语 *sagte*。这种**弱变化**（weak）过去时就是今天规则的 *-ed* 的来源；较古老的元音变化类型保留在**强变化**（strong）动词中。
- **两个时。** 日耳曼语动词只有现在时和过去时两种形式；将来和完成要用其他词来表达。现代英语的 *will go* 和 *have gone* 是后来的发展，并不是继承下来的单一形式。
- **强变化和弱变化形容词**，即根据前面是否有限定词而使用的两套形容词词尾（德语至今还有 *guter Wein* 与 *der gute Wein* 之分）。英语在中世纪失去了这种区别。
- **在日耳曼语以外没有已知同源词的词**，如 *sea*、*ship* 和 *wife*。有些学者提出，它们是从日耳曼语兴起之地所说的一种非印欧语言借来的；这种“底层”（substrate）说法尚未得到证明。

::: theorem 强变化动词保留了一种印欧语模式 {#rule-ablaut}
英语强变化动词的元音交替——*sing*、*sang*、*sung*；*drive*、*drove*、*driven*；*ride*、*rode*、*ridden*——不是英语的发明，而是一个叫作**元音递变**（ablaut，又称元音交替）的规则系统，继承自原始印欧语；在原始印欧语中，元音 *e*、*o* 和零形式在同一个词根内交替。希腊语显示了同样的系统：*leípō*“我离开”，*léloipa*“我已离开”，*élipon*“我离开了”。今天的学习者是把元音递变当作一张不规则动词表来接触的；在历史上，它是构成时的规则方式，而 *-ed* 类型才是后来者。
:::

::: proof
证据是整套模式的吻合：在哥特语、古英语、古诺尔斯语和古高地德语中，相同的词根里有相同的三分元音交替，而希腊语、拉丁语和梵语中也有同类的交替。这正是[[#rule-comparative]]第5点所说的那种证据：各语言共有的、看似不规则的语法，不可能是借来的。古英语有七类强变化动词，每一类都有自己的元音系列，强变化动词也比今天多得多。在此后的一千年里，许多强变化动词转入了弱变化类型——*helpan*、*healp* 变成了 *help*、*helped*；*climb* 曾经有过去式 *clomb*——也有少数朝相反的方向变化（美国英语的 *dive*、*dove*；*wear*、*wore*）。学习者那张不规则动词表，就是一个曾经有规则的系统所剩下的部分（[[history-of-english/old-english]]）。
:::

### 英语最近的亲属

荷兰语和德语与英语共有大部分日耳曼词汇，但德语经历了第二次辅音转移，即**高地德语辅音转移**（High German consonant shift，大约在公元6至8世纪），而英语、荷兰语和低地德语没有经历。它解释了英语和德语同源词之间的许多差别：

| 英语 | 荷兰语 | 德语 | 德语中的转移 |
|---|---|---|---|
| *ten* | *tien* | *zehn* | *t* → *z* /ts/ |
| *water* | *water* | *Wasser* | *t* → *ss* |
| *pepper* | *peper* | *Pfeffer* | *p* → *pf*，*ff* |
| *make* | *maken* | *machen* | *k* → *ch* |
| *that* | *dat* | *das* | *θ* → *d*（另一项变化） |

英语还有一些只与弗里西语共有的变化。在这两种语言里，前元音之前的 *k* 都变成了 *ch*：*cheese* 和 *church* 对应西弗里西语的 *tsiis* 和 *tsjerke*，而荷兰语是 *kaas* 和 *kerk*。两者还都丢失了擦音前的 *n*，同时把元音变长：*five*、*us*、*other*、*tooth*、*goose* 对应德语 *fünf*、*uns*、*ander*、*Zahn*、*Gans*。

::: example 匹配日耳曼语中的同源词 {#ex-germanic}
给出下列每个德语词的英语同源词，并说明是哪一种语音差别造成了变化：*Zunge*，*Apfel*，*Pfund*，*Herz*，*machen*，*Fuß*。
::: solution
1. *Zunge* —— **tongue**：词首的 *t* → 德语 *z* /ts/。
2. *Apfel* —— **apple**：*p* 在辅音后或词首 → 德语 *pf*，在其他位置 → *pf*/*ff*。
3. *Pfund* —— **pound**：*p* → *pf*。（两者都很早就从拉丁语 *pondo*（一种重量单位）借入，借入时间早于高地德语转移——我们正是由此知道这次转移晚于这次借用。）
4. *Herz* —— **heart**：*t* → *z*。（两者中的 *h* 都来自格林定律的 *k* → *h*：比较拉丁语 *cord-*。）
5. *machen* —— **make**：元音后的 *k* → *ch* /x/。
6. *Fuß* —— **foot**：元音后的 *t* → *ß* /s/。（两者中的 *f* 都来自格林定律的 *p* → *f*：拉丁语 *ped-*。）

德语在一个词里同时显示了两次转移：*Fuß* 既有格林定律的 *f*，又有高地德语的 *ß*；英语 *foot* 只有格林定律的 *f*。这就是历史比较法所恢复的相对年代：先是日耳曼语转移，很久以后才是高地德语转移。
:::
:::

## 为什么英语看起来不像日耳曼语

随便翻开一本英语词典的任何一页，大多数词目都源自法语或拉丁语。翻开一本英语小说，大多数连续出现的词却是日耳曼语词。两种说法都对，而二者之间的区别对语言分类很重要。

::: theorem 分类依据的是继承，而不是词汇统计 {#rule-inheritance}
一种语言的归类依据的是它**继承**（inherited）了什么——它的基本词汇、语音对应和核心语法——而不是它词典中借词所占的比例。英语是西日耳曼语，因为：

1. 它的基本词汇绝大多数是日耳曼语词：代词（*I*，*you*，*we*），数词（*one* 到 *ten*），亲属称谓（*father*，*mother*，*son*，*daughter*），身体部位（*hand*，*foot*，*head*，*heart*），常用动词（*be*，*have*，*do*，*go*，*come*，*eat*，*see*）和功能词（*the*，*and*，*of*，*in*）；
2. 它的语法源自古英语：强变化和弱变化动词，所有格 *-s*，比较级和最高级的 *-er*、*-est*，情态动词；
3. 它的语音系统显示出日耳曼语的各种变化，包括格林定律和本族词的词首重音。

大量罗曼语和拉丁语词汇是英语成为一种独立语言之后通过**接触**（contact）——也就是借用——而来的。
:::

::: proof
用两种不同方法所做的统计最清楚地说明了这一点。统计词典的**词目**时，*the* 和 *ubiquitous* 被同等对待；占主导的是构成任何一部词典大部分内容的罕用词和学术词，而这些词大多来自法语和拉丁语。这类统计中最著名的是芬肯施泰特（Finkenstaedt）和沃尔夫（Wolff）所做的（《有序的丰富》（*Ordered Profusion*），1973），他们用了《简明牛津英语词典》（*Shorter Oxford English Dictionary*）中大约八万个词，发现法语和拉丁语各自是其中略多于四分之一的词的来源，而日耳曼语词（古英语、古诺尔斯语、荷兰语）约占四分之一。与此相反，统计**连续文本**时，每个词每出现一次都计数一次，而任何英语文本中最常用的词——*the*、*of*、*and*、*to*、*a*、*in*、*is*、*it*——几乎都是本族词。德金（Durkin）的《借词》（*Borrowed Words*，2014）说明，统计方法不同，得到的图景差别有多大：越往词频表上方走，借词越少，尽管有些极常用的词，如 *people*、*very* 和 *use*，来自法语。两种统计都不能决定分类。词汇可以被大量借用，英语就是证明；而基本词汇和核心语法才是语言一代一代传下去的东西。
:::

::: example 按来源给一个句子的词分类 {#ex-sorting}
把下面这个句子中的每个词分为日耳曼语词（继承自古英语或借自古诺尔斯语）或罗曼语/拉丁语词：*The young doctor gave her patient some simple advice about his diet.*
::: solution
日耳曼语词：*the*，*young*，*gave*（古英语 *giefan*；现代形式的 *g-* 是受诺尔斯语影响——见[[history-of-english/vikings-norse]]），*her*，*some*，*about*，*his*。罗曼语/拉丁语词：*doctor*（拉丁语，经由法语），*patient*（法语，源自拉丁语），*simple*（法语），*advice*（法语 *avis*），*diet*（法语，源自拉丁语，最终源自希腊语）。

七个日耳曼语词，五个罗曼语词；但要注意哪些是哪些。日耳曼语词是语法框架——冠词、代词、动词、介词——而罗曼语词是表示内容的名词和形容词。去掉罗曼语词，仍然能看出英语句子的结构：*The young ___ gave her ___ some ___ ___ about his ___.* 去掉日耳曼语词，剩下的就只是一串词了。这就是说英语是一种拥有大量借入词汇的日耳曼语的含义。
:::
:::

::: note 英汉对比
汉语属于另一个语系——**汉藏语系**（Sino-Tibetan），同属这个语系的还有藏语、缅甸语以及中国南方和喜马拉雅地区的许多语言。历史比较法从未证明汉藏语系和印欧语系之间有亲属关系，所以英语词和汉语词之间的相似，要么是偶然，要么是借用：*tea* 来自“茶”的闽南语形式 *te*，而汉语“沙发” *shāfā* 来自英语 *sofa*。学习者不应该在这两种语言之间寻找同源词。

不过，这种方法本身在汉语中的运作和在英语中完全一样。汉语的各种变体——官话、吴语、粤语、闽语、客家话等——之间的差别不亚于许多欧洲语言之间的差别，而且它们显示出规则的对应。在粤语中以 *-p*、*-t*、*-k* 结尾的字——十 *sap*、一 *jat*、六 *luk*——在普通话中以元音结尾——*shí*、*yī*、*liù*——这个对应贯穿几百个字。正像拉丁语和英语的情形一样，最简单的解释是它们有一个带塞音韵尾的共同祖先，而《切韵》（公元601年）等古代韵书证实了这一点。瑞典汉学家高本汉（Bernhard Karlgren）在20世纪初构拟中古汉语，用的正是本章所讲的历史比较法，只不过应用于现代方言和那些韵书。如果你懂两种汉语变体，你就已经知道规则的对应是什么感觉了。
:::

::: history
语言构成语系的想法比历史比较法更早，但转折点通常定在1786年。1786年2月2日，法官兼东方学家威廉·琼斯爵士（Sir William Jones）在加尔各答亚洲学会发表演说（1788年出版），说梵语与希腊语和拉丁语“无论在动词词根上还是在语法形式上，都有一种强烈的亲缘关系，绝不可能是偶然造成的；这种关系如此之强，以至于任何一位语文学家在考察这三种语言之后，都不能不相信它们出自某个共同的源头，而这个源头或许已不复存在”。琼斯并不是第一个注意到这种相似的人，他的另一些归类也是错的，但他对语法的强调以及他那句“某个共同的源头，而这个源头或许已不复存在”确定了此后的研究方向。在接下来的半个世纪里，拉斯克（Rasmus Rask）、葆朴（Franz Bopp）和雅各布·格林建立了历史比较法；施莱歇尔（August Schleicher）在19世纪50、60年代画出了最早的印欧语系树形图，甚至尝试用构拟的 PIE 写了一则寓言。1879年，年轻的索绪尔（Ferdinand de Saussure）仅凭语言内部的模式就论证说，PIE 一定有一些没有任何子语言保存下来的音；20世纪赫梯语被破译以后，人们发现它在一些预言的位置上恰好有一个写作 *ḫ* 的辅音。对一种没有记录的语言所作的预言，被后来发现的一种语言所证实——这是这种方法不只是聪明的猜测的最有力证据。
:::

## 由此往下

5世纪日耳曼移民把他们的方言带到不列颠时，英语成为一种独立的语言：这是[[history-of-english/old-english]]的开端。它的北日耳曼表亲随着维京人回到了英格兰（[[history-of-english/vikings-norse]]），它的罗曼语表亲则随着诺曼人（[[history-of-english/norman-french]]）和文艺复兴时期的学者（[[history-of-english/early-modern-english]]）而来。音变怎样在一个群体中和在词汇中扩散，是[[linguistics/variation-change]]的主题；借词中的拉丁语和希腊语词根今天怎样使用，见[[word-formation/greek-latin-roots]]。

::: summary
- **语系**是从同一种原始语演变而来的一组语言；**同源词**是由同一个祖先词演变而来的词，它们不一定长得像（[[#def-family]]）。
- 亲属关系要靠基本词汇中**规则的语音对应**和共有的不规则语法来证明，而不是靠相似，因为偶然和借用也会造成相似（[[#rule-comparative]]）。
- 英语是**印欧语系** **西日耳曼语支**的语言，与弗里西语最接近，其次是荷兰语、低地德语和德语（[[#def-germanic]]）。
- **格林定律**把 PIE 的 *p t k* 变成 *f θ h*，*b d g* 变成 *p t k*，*bh dh gh* 变成 *b d g*：*father* / *pater*，*ten* / *decem*，*brother* / *bhrātar-*（[[#rule-grimm]]）。维尔纳定律解释了它的例外，并保留在 *was* / *were* 中。
- 日耳曼语还把重音固定在词根音节上，并创造了齿音（*-ed*）过去时；强变化动词的元音变化（*sing*、*sang*、*sung*）继承自 PIE（[[#rule-ablaut]]）。
- 英语有许多法语和拉丁语词，但它的归类依据的是它继承来的基本词汇和语法（[[#rule-inheritance]]）。
- *foot* / *pedal* 和 *heart* / *cordial* 这样的词对，是同一个 PIE 词根两次进入英语：一次继承，一次借用。
:::

## 习题

::: exercise 同源、借用还是巧合？ {level=1}
对每一组词，说明这个英语词是另一个词的同源词、从它借来的词，还是偶然相似。

1. 英语 *mother* – 拉丁语 *mater*
2. 英语 *maternal* – 拉丁语 *maternus*
3. 英语 *bad* – 波斯语 *bad*
4. 英语 *night* – 德语 *Nacht*
5. 英语 *table* – 拉丁语 *tabula*
::: solution
1. 同源词（继承自同一个 PIE 词；格林定律：*t* → *θ*，后来变为 *th* /ð/）。
2. 借词：*maternal* 是中世纪晚期从拉丁语（经由法语或中世纪拉丁语）进入英语的。
3. 偶然相似。
4. 同源词：两者都继承自原始日耳曼语（英语的 *gh* 曾经和德语的 *ch* 一样表示 /x/ 这个音）。
5. 借词：*table* 来自拉丁语，经由法语。
:::
:::

::: exercise 语族 {level=1}
说出下列每种语言所属的印欧语族：威尔士语、印地语、瑞典语、葡萄牙语、波兰语、赫梯语、荷兰语。
::: solution
威尔士语——凯尔特语族；印地语——印度-伊朗语族；瑞典语——日耳曼语族（北支）；葡萄牙语——意大利语族（罗曼语）；波兰语——波罗的-斯拉夫语族（斯拉夫语）；赫梯语——安纳托利亚语族（已消亡）；荷兰语——日耳曼语族（西支）。
:::

::: exercise 数一数格林定律的对应 {level=1 check="3"}
在下列词对中，有几对的英语词显示了格林定律的 *p* → *f*？*father* / *pater*；*pen* / *penna*；*fish* / *piscis*；*fire* / 希腊语 *pyr*；*pepper* / *piper*。
::: solution
**3**：*father*、*fish* 和 *fire*。*pen* 和 *pepper* 以 *p* 开头，因为它们不是继承来的：两者都是在格林定律已经停止起作用之后从拉丁语借来的（*penna*“羽毛”，经由法语；*piper*），所以保留了 *p*。
:::
:::

::: exercise 继承词与借词的词对 {level=2}
每个拉丁语词根都两次进入了英语。给出表示每个意义的英语本族词和借入的拉丁语源词。

1. “牙齿”（拉丁语 *dent-*）
2. “三”（拉丁语 *tri-*）
3. “狗”（拉丁语 *canis*）
4. “十”（拉丁语 *decem*）
5. “谷物，谷粒”（拉丁语 *granum*）
::: hint
找本族词时，对第一个辅音应用格林定律：*d* → *t*，*t* → *th*，*k* → *h*，*g* → *k*。
:::
::: solution
1. *tooth* / *dental*（还有 *dentist*）。
2. *three* / *triple*，*trio*，*triangle*。
3. *hound* / *canine*。（*hound* 在古英语里是表示“狗”的通用词，作 *hund*；*dog* 是一个来源不明的后起词。）
4. *ten* / *decimal*（还有 *December*，它曾是罗马历的第十个月）。
5. *corn* / *grain*（经由法语），*granary*，*granule*。
:::
:::

::: exercise 解释一个例外 {level=2}
拉丁语 *piper*“胡椒”和拉丁语 *planta*“植物”以 *p* 开头，英语 *pepper* 和 *plant* 也以 *p* 开头。这与格林定律矛盾吗？请解释。
::: solution
不矛盾。格林定律适用于从原始印欧语**继承**到日耳曼语中的词。*pepper* 和 *plant* 是从拉丁语**借来**的——*pepper* 借得早，是日耳曼诸民族与罗马接触时借入的；*plant* 是在古英语时期借入的——都在转移发生之后，所以它们的 *p* 从未转移过。（如果它们是这些拉丁语词的继承同源词，就会以 *f* 开头。）借用是历史比较法解释表面例外的标准方法之一（[[#rule-comparative]]第3点）。德语 *Pfeffer* 说明这次借用发生在高地德语转移之前，因为这个词受到了转移的影响。
:::
:::

::: exercise 德语和英语 {level=2}
用高地德语辅音转移给出下列词的英语同源词：*Zeit*，*Pfanne*，*Wasser*，*Buch*，*zwei*，*Schiff*。
::: solution
*Zeit* —— *tide*（取其古义“时间”，如 *Christmastide*“圣诞节期”；英语中表示“时间”的 *time* 是另一个日耳曼语词）；*Pfanne* —— *pan*；*Wasser* —— *water*；*Buch* —— *book*；*zwei* —— *two*；*Schiff* —— *ship*（德语的 *sch* 对应英语来自古英语 *sc* 的 *sh*）。
:::
:::

::: exercise 英语“其实”是罗曼语吗？ {level=3}
一位同学说：“英语词典里一半以上的词来自法语和拉丁语，所以英语其实是罗曼语。”写一段120–180词的回应，说明这些数字实际上衡量的是什么，以及语言学家为什么把英语归为日耳曼语。
::: solution
参考答案：*The figure is roughly right for dictionary headwords — counts such as Finkenstaedt and Wolff's (1973) put French and Latin together above half — but it measures the wrong thing. A dictionary lists every word once, so rare and learned words like* ubiquitous *count as much as* the. *In running text, where each word is counted every time it is used, the most frequent words — articles, pronouns, prepositions, auxiliaries, numbers and common verbs — are almost all Germanic, and they make up most of what we say and write. More importantly, languages are classified by what they inherit, not by what they borrow. English inherited its basic vocabulary and its grammar — strong verbs, the dental past, the genitive* -s *— from Proto-Germanic, and its native words show Grimm's law. The French and Latin words came later, through contact. English is a Germanic language with an unusually large borrowed vocabulary.*
:::
:::

::: exercise 构拟一组对应 {level=3}
下面是三种语言中表示四个意义的词：

| | 语言 A | 语言 B | 语言 C |
|---|---|---|---|
| “二” | *duo* | *two* | *dva* |
| “三” | *tres* | *three* | *tri* |
| “十” | *decem* | *ten* | *desyat'* |
| “牙齿” | *dent-* | *tooth* | — |

（A 是拉丁语，B 是英语，C 是俄语。）写出第一个辅音的对应关系，说明哪种语言很可能发生了变化，以及为什么。
::: hint
看各列：每个辅音出现在几种语言里？然后回想[[#rule-grimm]]中的那条链。
:::
::: solution
有两组对应。（1）拉丁语 *d* : 英语 *t* : 俄语 *d*（*duo* / *two* / *dva*；*decem* / *ten* / *desyat'*；*dent-* / *tooth*）。（2）拉丁语 *t* : 英语 *th* : 俄语 *t*（*tres* / *three* / *tri*）。在每一组里，拉丁语和俄语一致，英语是例外。最简单的假设是：原始语像拉丁语和俄语一样有 *d* 和 *t*，而英语（连同其他日耳曼语）改变了它们：*d* → *t*，*t* → *θ*。如果情况相反，就得有两种属于不同语族的语言各自独立地发生了同样的变化，这种可能性较小。这就是从零开始构拟出来的格林定律——变化的顺序也随之得出：如果 *d* 先变成了 *t*，那么 *two* 中新产生的 *t* 就会继续变成 *th*。
:::
:::
