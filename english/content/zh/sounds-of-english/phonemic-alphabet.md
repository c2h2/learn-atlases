看四个常用词：*though*（虽然）、*through*（穿过）、*tough*（坚韧的）、*cough*（咳嗽）。它们都以字母 *-ough* 结尾，却分别与 *go*、*too*、*stuff*、*off* 押韵。再看 *see*（看见）、*sea*（海）、*me*（我）、*key*（钥匙）、*ski*（滑雪）、*people*（人们）和 *receive*（收到）：同一个元音，七种不同的拼法。英语的拼写不能可靠地告诉你一个词怎么读，所以每本学习型词典都在两条斜线之间再给出一种“拼写”：*though* /ðəʊ/，*through* /θruː/，*tough* /tʌf/，*cough* /kɒf/。

这第二种拼写就是**音位标音**（phonemic transcription）。在其中，一个符号永远表示一个音，一个音也永远用同一个符号。一旦你会读它，就能在词典里查到任何词的读音，哪怕是从来没听过的词。

本章列出整个图谱使用的符号。它们是威尔斯（John Wells）的《朗文发音词典》（*Longman Pronunciation Dictionary*，简称 LPD）所用的符号，除了细微差别外，也是牛津、剑桥和柯林斯学习型词典所用的符号。本章还介绍我们用作模式的两种口音、给元音命名的关键词，以及一张把我们的符号与许多中国学习者在学校学过的“DJ 音标”“KK 音标”相对照的表。后面的各章和各课程都直接使用这套系统而不再解释，所以遇到不清楚的符号，随时回到这里查看。

## 音位

英语母语者在 *top*（顶部）、*stop*（停止）、*water*（水）和 *football*（足球）里说 *t* 的方式各不相同（下面会看到怎么不同）。但他们把这些都听成“同一个 *t*”。同样，说普通话的人发 *tiān*（天）和 *tā*（他）里的 *a* 并不一样，听起来却是同一个 *a*。每种语言都把许多略有差别的音归并成少数几个起作用的单位。这些单位叫作音位。

::: definition 音位 {#def-phoneme}
**音位**（phoneme，课本里常叫“音素”）是一种语言中能够区别意义的最小语音单位之一。把一个词里的一个音位换掉，可能得到另一个词：*pin*（别针）→ *bin*（垃圾箱）→ *bun*（小圆面包）→ *bud*（芽）。音位标音把一个词的每个音位用一个符号写在两条斜线之间：/pɪn/，/bɪn/，/bʌn/，/bʌd/。
:::

::: definition 最小对立体 {#def-minimal-pair}
**最小对立体**（minimal pair）是在同一位置上只有一个音位不同的两个词：*ship*（船）/ʃɪp/ 和 *sheep*（羊）/ʃiːp/，*light*（光）/laɪt/ 和 *right*（右；对的）/raɪt/，*bag*（包）/bæɡ/ 和 *back*（背；后面）/bæk/。最小对立体证明两个音是不同的音位，也是最好的练习材料。
:::

注意，最小对立体讲的是**音**，不是拼写。*Bear*（熊）和 *pear*（梨）是一对最小对立体（GB 读 /beə/、/peə/）。*Knight*（骑士）和 *night*（夜晚）则不是：它们看起来不同，读音却一样，都是 /naɪt/。拼写不同而读音相同的词叫作**同音异义词**（homophones）。

同一个音位的不同发音方式叫作它的**音位变体**（allophones）。音位变体写在方括号里，因为它们比音位标音显示更多细节：[tʰ] 表示一个带气流的 /t/。用方括号写的标音是**语音标音**（phonetic transcription，严式标音）。

::: widget graph
nodes: /t/@0,2; [tʰ] top@-3,0; [t] stop@-1,0; [ɾ] water GA@1,0; [ʔ] football@3,0
edges: /t/>[tʰ] top; /t/>[t] stop; /t/>[ɾ] water GA; /t/>[ʔ] football
caption: 一个音位，几个音位变体。音位 /t/（top）在 *top* 的开头带一股气流；在 *stop* 里位于 /s/ 之后，不带气流；在通用美式发音的 *water* 里位于两个元音之间，读成一个像短促 *d* 的快速闪音；在 *football* 里位于另一个辅音之前，常常读成“喉塞音”（声带短暂闭合一下）。英语母语者把这四种都听成“*t*”。圆圈可以拖动；箭头表示“读作”。
:::

::: theorem 一个符号，一个音位 {#rule-one-symbol}
在音位标音中：

1. 每个符号只代表一个音位，每个音位也只有一个符号；
2. 不发音的字母不写出来：*knee*（膝盖）/niː/，*lamb*（羔羊）/læm/；
3. 拼写里没有显示出来的音要写出来：*use*（使用，动词）/juːz/ 以 /j/ 开头；
4. 标音放在两条斜线之间，重音符号标在重读音节之前：*about*（关于）/əˈbaʊt/。
:::

::: proof
这条规则来自标音的目的：不论拼写如何，准确地显示一个词包含哪些音位。它只管到音位为止。音位标音不显示音位变体，因为说英语的人会自动加上它们：你不必在 *top* 里写出那股气流，因为每个位于重读音节开头的 /t/ 都带这股气流。当某一课需要这种细节时，就用方括号。
:::

::: quiz
哪一组是**最小对立体**？
- [ ] *write* – *right*
- [x] *thin* – *tin*
- [ ] *cat* – *dogs*
- [ ] *know* – *no*
::: solution
*Thin*（薄的）/θɪn/ 和 *tin*（锡）/tɪn/ 在同一位置上恰好有一个音位不同（/θ/ 和 /t/）。*Write*（写）和 *right* 都读 /raɪt/，*know*（知道）和 *no*（不）都读 /nəʊ/（GB）、/noʊ/（GA）：它们是同音异义词，读音没有区别。*Cat*（猫）和 *dogs*（狗，复数）几乎每个音都不同。
:::
:::

## 两种模式：通用英式发音和通用美式发音

说英语的口音有很多种，它们都是真正的英语。但学习者仍然需要一个模式：一种清晰、广泛听得懂、能在词典里查到的口音。本图谱使用两种。

::: definition GB 和 GA {#def-gb-ga}
**通用英式发音**（General British，GB）是最常被当作英式模式来教、在英国词典中列在首位的英语口音。它是长期被称为“标准发音”（Received Pronunciation，RP）的那种口音的现代形式；克鲁滕登（Alan Cruttenden）的《吉姆森英语发音》（*Gimson's Pronunciation of English*，2014）就用“通用英式发音”来称呼它。**通用美式发音**（General American，GA）是在美国大部分地区都能听到、没有明显地方特征的英语口音；它是美国词典的模式。两者都有数以百万计的人在说，谁也不比谁更“正确”，也不比任何其他口音更“正确”。
:::

最大的一项差别在于字母 *r*：

::: theorem GB 和 GA 最主要的差别 {#rule-rhotic}
1. **元音后的 r。** 凡拼写中有 *r* 的地方，GA 都读出 /r/：*car*（汽车）/kɑːr/，*hard*（硬的）/hɑːrd/。GB 只在元音前读出 /r/：*car* /kɑː/，*hard* /hɑːd/，但 *carry*（携带）/ˈkæri/、*car alarm*（汽车警报器）/kɑːr əˈlɑːm/ 里要读。像 GA 这样的口音叫作**卷舌口音**（rhotic），像 GB 这样的叫作**非卷舌口音**（non-rhotic）。
2. **某些元音。** GA 没有元音 /ɒ/：*hot*（热的）在 GB 里是 /hɒt/，在 GA 里是 /hɑːt/。*go*（去）的元音在 GB 里是 /əʊ/，在 GA 里是 /oʊ/。有些词在 GB 里读 /ɑː/，在 GA 里读 /æ/：*bath*（洗澡）、*grass*（草）、*can't*（不能）。
3. **元音之间的 t。** 在 GA 里，位于重读音节之后、两个元音之间的 /t/ 通常读成一个快速的闪音：*water*（水）、*city*（城市）、*better*（更好）。
:::

::: proof
这些是学习者最先听到的差别；还有更多差别，见[[sounds-of-english/long-vowels-diphthongs]]和[[world-englishes/british-american]]。两种口音都来自17世纪的英语，那时各地元音后的 *r* 都还要读出来。在英格兰东南部，元音后的 *r* 在18世纪消失了，而美式英语和苏格兰、爱尔兰英语一样保留了它。*t* 的闪音化是后来美式（以及澳大利亚）英语中的发展。两种口音都不是在每一方面都“更古老”或“更纯正”：各自保留了一些旧特征，也改变了另一些。
:::

本图谱中，当 GB 和 GA 不同时，两者都给出，GB 在前：*car* /kɑː/（GB），/kɑːr/（GA）。没有差别时，只给一种标音。

## 元音符号和词汇集

各种英语口音之间差别最大的是元音。像 *bath* 这个词，在 GB 里是 /ɑː/，在 GA 里是 /æ/；*hot* 在一种口音里是 /ɒ/，在另一种里是 /ɑː/。为了能在任何口音中谈论“*bath* 的元音”，威尔斯（1982）给每一组词起了一个用大写字母书写的**关键词**。

::: definition 词汇集 {#def-lexical-set}
**词汇集**（lexical set）是在参考口音中元音相同的一组词，用一个大写的关键词命名：KIT 词汇集（*kit*（成套工具）、*ship*（船）、*bridge*（桥）、*milk*（牛奶）……），FLEECE 词汇集（*fleece*（羊毛）、*sheep*（羊）、*see*（看见）、*key*（钥匙）……），等等。不管你说哪种口音，关键词都能指称这个元音：“BATH 元音”指 *bath*、*grass*、*ask*（问）的元音，不论它是 /ɑː/（GB）还是 /æ/（GA）。
:::

这些关键词经过挑选，不容易和别的词混淆。下面是威尔斯的24个词汇集以及我们为 GB 和 GA 所用的符号，另加三个表示非重读元音的关键词。

关于这张表的几点说明：

- **长与短。** 符号 ː 表示“长”。在 GB 里，不带 ː 的元音（ɪ e æ ʌ ɒ ʊ ə）是**短元音**；带 ː 的是**长元音**；用两个符号书写的是**双元音**，即从一个位置滑向另一个位置的元音。GA 沿用同样的符号，但它在 LOT 里用 /ɑː/，说明 GA 的元音分组和 GB 并不完全相同。
- **GA 的卷舌元音。** 我们把 GA 的 NURSE 写作 /ɜːr/，把 lettER 写作 /ər/。有些词典以及下面的 KK 系统把它们写作 [ɝ] 和 [ɚ]：符号不同，音是一样的。
- **GA 的 THOUGHT 元音。** 许多美国人，特别是西部的美国人和加拿大人，把 LOT 和 THOUGHT 读成一样：对他们来说，*cot*（小床）和 *caught*（抓住过）是同音词。词典仍把这两个元音分开。
- **GB 的 CURE。** 许多说 GB 的人现在用 /ɔː/（*saw* 的元音）来读 *sure*、*poor* 和 *your*（你的）。LPD 两种都给出。
- **弱读的 /i/ 和 /u/。** happY 元音 /i/ 只用在非重读音节里；它介于 /ɪ/ 和 /iː/ 之间。同样，/u/ 出现在非重读音节里，例如 *thank you*（谢谢你）/ˈθæŋk ju/ 的最后一个元音和 *situation*（情况）/ˌsɪtʃuˈeɪʃn/ 的中间。

::: warning 音标符号不是拼音字母
许多符号看起来像拼音字母，代表的却是不同的音。

- /j/ 是 *yes* 里的 *y*。它不是拼音的 *j*（如 *jiā* 家）：用拼音的 *j* 去读 /jes/，会得到一个不存在的词。
- /e/ 是 *bed* 的元音。它不是拼音的 *e*（如 *hē* 喝），后者是另一个靠后的元音。
- /ʌ/（*cup*）和 /ɑː/（*car*）是英语的两个不同元音，而拼音对这两类音都只用一个 *a*。
- /r/ 是英语的 *r*，发音时没有摩擦，双唇收圆。它不是拼音的 *r*（如 *rè* 热）。
- /i/、/iː/、/ɪ/ 是三个不同的符号。拼音的 *i* 在 *zi*、*shi* 里又是另一个值，代表一个英语里没有的元音。

一定要按关键词读符号，永远不要按拼音的读法去读。
:::

::: example 读音标 {#ex-read}
这些是什么词？/ˈmʌni/，/θɔːt/，/ˈwɪndəʊ/（GB），/ʃʊd/，/jʌŋ/。
::: solution
按关键词读出每个符号：

1. /ˈmʌni/：/m/ + STRUT 元音 + /n/ + happY 元音，重音在第一个音节：*money*（钱）。
2. /θɔːt/：/θ/（*thin*）+ THOUGHT 元音 + /t/：*thought*（想过；思想）。
3. /ˈwɪndəʊ/：/w/ + KIT + /n/ + /d/ + GOAT：*window*（窗户）。
4. /ʃʊd/：/ʃ/（*shoe*）+ FOOT + /d/：*should*（应该）（*l* 不发音）。
5. /jʌŋ/：/j/（*yes*）+ STRUT + /ŋ/（*sing*）：*young*（年轻的）。
:::
:::

::: example 写音标 {#ex-write}
用音位符号写出下列单词的 GB 和 GA 读音：*cheese*（奶酪），*bird*（鸟），*thank*（感谢），*door*（门）。
::: solution
要一个音一个音地写，而不是一个字母一个字母地写。

1. *cheese*：*ch* 是一个音 /tʃ/；*ee* 是 FLEECE 元音 /iː/；*s* 读 /z/，词尾的 *e* 不发音：/tʃiːz/（GB 和 GA 相同）。
2. *bird*：/b/ + NURSE 元音 + /d/。GB /bɜːd/，GA /bɜːrd/。
3. *thank*：/θ/ + TRAP + /ŋ/ + /k/。*n* 在 /k/ 前读 /ŋ/：/θæŋk/。
4. *door*：/d/ + FORCE 元音。GB /dɔː/，GA /dɔːr/。
:::
:::

::: quiz
哪个词读作 /ʃuː/？
- [ ] *sue*
- [x] *shoe*
- [ ] *show*
- [ ] *shy*
::: solution
/ʃ/ 是 *sh* 音，/uː/ 是 GOOSE 元音：*shoe*（鞋）。*Sue*（起诉）读 /suː/，*show*（展示）读 /ʃəʊ/（GB）或 /ʃoʊ/（GA），*shy*（害羞的）读 /ʃaɪ/。
:::
:::

## 重音符号和长音符号

两个或更多音节的词有一个音节是**重读**的：它比其他音节更响、更长，音高更高（或更低）。一个小竖线 ˈ 标在重读音节的**前面**：*about*（关于）/əˈbaʊt/，*teacher*（老师）/ˈtiːtʃə/（GB），/ˈtiːtʃər/（GA）。长词还可以有**次重音**，用一个低位的小竖线 ˌ 表示：*understand*（理解）/ˌʌndəˈstænd/（GB）。[[sounds-of-english/word-stress-basics]]讲解重音的规律。

::: warning 重音符号标在音节之前
✗ /ˈəbaʊt/——这样标表示第一个音节重读。
✓ /əˈbaʊt/——符号标在重读音节 *bout* 的**前面**，而不是标在元音上。

不要把重音符号 ˈ 和撇号混淆，也不要把长音符号 ː 和冒号混淆。许多词典把 ː 印成两个小三角；有些旧书印成冒号。
:::

## DJ、KK 和我们的符号

许多中国学习者最早接触的是两种较早的标音系统之一。

- **DJ 音标**是琼斯（Daniel Jones）《英语发音词典》（*English Pronouncing Dictionary*）1977年以前各版所用的标音法。许多旧版中国教材和词典都用它。1977年由吉姆森（A. C. Gimson）主编的第14版改动了几个元音符号；今天的中国教材使用的符号与新符号相近，而新符号也就是我们的符号。
- **KK 音标**是肯尼恩（John Kenyon）和诺特（Thomas Knott）《美式英语发音词典》（*A Pronouncing Dictionary of American English*，1944）的标音法。它描写的是美式英语，在台湾地区以及中国大陆的一些美式英语教材中仍然常见。

::: theorem DJ、KK 与本图谱的对应 {#rule-dj-kk}
三种系统的辅音符号相同。元音对应如下：

| 关键词 | 本图谱：GB | DJ（1977年以前） | 本图谱：GA | KK |
|---|---|---|---|---|
| FLEECE | iː | iː | iː | i |
| KIT | ɪ | i | ɪ | ɪ |
| DRESS | e | e | e | ɛ |
| TRAP | æ | æ | æ | æ |
| STRUT | ʌ | ʌ | ʌ | ʌ |
| LOT | ɒ | ɔ | ɑː | ɑ |
| PALM, START | ɑː | ɑː | ɑː, ɑːr | ɑ, ɑr |
| THOUGHT, NORTH | ɔː | ɔː | ɔː, ɔːr | ɔ, ɔr |
| FOOT | ʊ | u | ʊ | ʊ |
| GOOSE | uː | uː | uː | u |
| NURSE | ɜː | əː | ɜːr | ɝ |
| commA, lettER | ə | ə | ə, ər | ə, ɚ |
| FACE | eɪ | ei | eɪ | e |
| PRICE | aɪ | ai | aɪ | aɪ |
| CHOICE | ɔɪ | ɔi | ɔɪ | ɔɪ |
| GOAT | əʊ | əu | oʊ | o |
| MOUTH | aʊ | au | aʊ | aʊ |
| NEAR | ɪə | iə | ɪr | ɪr |
| SQUARE | eə | ɛə | er | ɛr |
| CURE | ʊə | uə | ʊr | ʊr |

三点差别可以解释这张表的大部分内容：DJ 只用长短来表示 KIT–FLEECE 和 FOOT–GOOSE 的区别（[i]–[iː]，[u]–[uː]）；KK 只用音质来表示（[ɪ]–[i]，[ʊ]–[u]），并且从不使用长音符号；我们的系统两者都用，因为每一对元音在音质**和**长短上都有区别。
:::

::: proof
*ship* 的元音不仅仅是 *sheep* 元音的短化版本：舌位更低、更靠后，肌肉更放松。把 DJ 的 [i] 当作“短的 [iː]”来读的学习者，常常把 *ship* 读得像一个快速的 *sheep*。吉姆森1977年的新符号（ɪ、ʊ、ɒ、ɜː）就是为了显示这种音质差别而选定的。KK 显示音质而不显示长短，这适合美式英语，因为在美式英语里，长短对区分元音不如在 GB 里重要。我们的系统两者都显示，这样同一套符号就能同时用于 GB 和 GA。表中给出的是每个系统**通常**使用的符号；不同的词典和教材之间有细微差别（有些较早的 DJ 印本把 GOAT 写作 [ou]；有些 KK 表把 FACE 和 GOAT 写作 [eɪ] 和 [oʊ]）。
:::

::: example 从 DJ 到我们的符号 {#ex-dj}
一本旧教材给出 *ship*（船）[ʃip]、*good*（好的）[gud] 和 *hot*（热的）[hɔt]。用我们的系统写出它们。
::: solution
按关键词逐一查表：

1. [ʃip]：DJ 的 [i] 是 KIT，即我们的 /ɪ/：/ʃɪp/。
2. [gud]：DJ 的 [u] 是 FOOT，即我们的 /ʊ/；DJ 的 [g] 就是我们的 /ɡ/（同一个字母，字体不同）：/ɡʊd/。
3. [hɔt]：DJ 的 [ɔ] 是 LOT，即我们的 /ɒ/（GB）。在 GA 里 LOT 元音是 /ɑː/：/hɒt/（GB），/hɑːt/（GA）。
:::
:::

::: example 从 KK 到我们的符号 {#ex-kk}
一本 KK 词典给出 *name*（名字）[nem]、*bird*（鸟）[bɝd] 和 *better*（更好）[ˈbɛtɚ]。用我们的系统写出它们的 GA 读音。
::: solution
1. [nem]：KK 的 [e] 是 FACE 元音，即我们的 /eɪ/：/neɪm/。
2. [bɝd]：KK 的 [ɝ] 是 NURSE 元音，即我们 GA 的 /ɜːr/：/bɜːrd/。
3. [ˈbɛtɚ]：KK 的 [ɛ] 是 DRESS，即我们的 /e/；KK 的 [ɚ] 是 lettER，即我们 GA 的 /ər/：/ˈbetər/。

GB 的形式是 /neɪm/、/bɜːd/、/ˈbetə/。
:::
:::

::: quiz
某个词用 KK 写作 [hom]。用我们的 GB 标音是什么？
- [ ] /hɒm/
- [ ] /huːm/
- [x] /həʊm/
- [ ] /hɔːm/
::: solution
KK 的 [o] 是 GOAT 元音，在 GB 里是 /əʊ/，在 GA 里是 /oʊ/。这个词是 *home*（家）：/həʊm/（GB），/hoʊm/（GA）。
:::
:::

::: note 英汉对比
- **有多少个音？** 中国的中小学教材常说英语有“48个音素”：20个元音和28个辅音。我们的表里有24个辅音。教材多出来的四个是 /ts/、/dz/、/tr/、/dr/，如 *cats*（猫，复数）、*beds*（床，复数）、*tree*（树）、*dream*（梦）。在对英语的标准描写中，这些是由两个音位组成的**连缀**，而不是单个音位，因为两部分可以分开、单独出现（*cat* + *s*）。它们仍然值得练习，因为听起来像单个的音。
- **拼音不是国际音标。** 拼音是为了用拉丁字母书写普通话而设计的，不是为了跨语言地表示语音。它的 *b、d、g* 是清音；它的 *j、q、x* 是英语没有的音；它的 *r*、*e*、*i* 与英语的 /r/、/e/、/ɪ/ 都不相同。英语的每个符号都要按关键词来读。
- **书写中文名字。** 一个用拼音写的中文名字，比如 *Zhou Xin*，说英语的人会按英语字母的读法来读。了解他们可能怎么读，并告诉别人你希望怎么读，会很有帮助。
:::

::: history
国际音标由1886年成立的那个协会（见[[sounds-of-english/how-speech-is-made]]）于1888年首次发表。琼斯在他的《英语发音词典》（1917）中使用了它；在20世纪的大部分时间里，他的符号都是书写英式英语的标准方式——也就是中国课堂上的“DJ”。肯尼恩和诺特于1944年把国际音标符号用于美式英语（“KK”）。1977年，琼斯词典的新任主编吉姆森引入了能显示元音音质差别的符号，大多数学习型词典随后采用了它们。威尔斯的《英语口音》（*Accents of English*，1982）提出了词汇集，他的《朗文发音词典》（1990；第3版2008）用本图谱所用的符号并列给出 GB 和 GA 读音。
:::

## 后续内容

接下来的四章讲解符号背后的音：[[sounds-of-english/short-vowels]]、[[sounds-of-english/long-vowels-diphthongs]]、[[sounds-of-english/stops-fricatives]]和[[sounds-of-english/nasals-approximants]]。[[core-vocabulary/using-a-dictionary]]说明怎样利用词典词条里的标音。音位是怎样被发现的、为什么会有音位变体，这是[[linguistics/phonetics-phonology]]的内容。

::: summary
- **音位**是能区别意义的语音单位；**最小对立体**（*ship*–*sheep*）只有一个音位不同（[[#def-phoneme]]，[[#def-minimal-pair]]）。
- 音位标音写在斜线之间，每个音位一个符号；语音细节（如 [tʰ] 这样的音位变体）写在方括号里（[[#rule-one-symbol]]）。
- 本图谱使用两种模式——**通用英式发音**和**通用美式发音**，两者不同时都给出（[[#def-gb-ga]]）；没有哪种口音比另一种更正确。
- GB 和 GA 最大的差别是元音后的 *r*：GA 读出来，GB 不读（[[#rule-rhotic]]）。
- 我们的符号是《朗文发音词典》的符号：24个辅音；元音用威尔斯的**词汇集**（KIT、FLEECE、GOAT……）命名，词汇集可以在任何口音中指称一个元音（[[#def-lexical-set]]）。
- 重音符号 ˈ 标在重读音节的**前面**；ː 表示长。
- DJ 只用长短表示元音对，KK 只用音质表示；我们的系统两者都表示（[[#rule-dj-kk]]）。
- 拼音字母不是国际音标符号：每个符号都要按关键词来读。
:::

::: exercise 解释这张表 {level=3}
一位同学在学校学的是 DJ 音标，她说：“*ship* 和 *sheep* 的元音是一样的，只是一个短一点。”利用[[#rule-dj-kk]]中的表和你对元音的了解，写三四句话解释为什么这个说法不完全对，以及她应该练习什么。
::: hint
想一想舌头的位置，而不仅仅是时间长短。

::: solution
参考答案：“用 DJ 音标，*ship* 是 [ʃip]，*sheep* 是 [ʃiːp]，所以看得见的唯一区别是长音符号。但这两个元音在音质上也不同：发 *ship* 时舌位稍低、稍靠后，口腔更放松，所以我们的系统写作 /ɪ/，KK 写作 [ɪ]。如果你只是把 *sheep* 说得快一点，说英语的人可能仍然听成 *sheep*。要练习舌位：先说 *sheep*，然后让舌头稍稍下降、放松，说 *ship*；并用 *ship*–*sheep*、*sit*–*seat*、*live*–*leave* 这样的最小对立体来练习。”
:::

::: exercise 你自己的名字 {level=3}
写出你的名字（或者一个中文名字，如 *Zhou Xin* 或 *Xu Qing*）的拼音形式被大多数说英语的人读出来时可能的样子，用音位符号表示。然后写一段简短的说明（两三句英语），告诉一位新同事怎么读它。
::: solution
答案因人而异。以 *Zhou Xin* 为例：不懂拼音的说英语的人常把 *Zh* 读成 /z/ 或 /ʒ/，把 *ou* 读成 /aʊ/（像 *out* 里那样），把 *X* 读成 /z/ 或 /ks/，把 *in* 读成 /ɪn/，结果大致是 /zaʊ zɪn/。一段有帮助的说明：*"My family name is Zhou — it sounds a bit like Joe. My given name, Xin, sounds close to shin. In English I put my given name first: Xin Zhou."*（我姓 Zhou，听起来有点像 Joe。我的名字 Xin 听起来接近 shin。用英语时我把名字放在前面：Xin Zhou。）只要为每个音节给出清楚的英语参照、并说明哪个是姓，就是好答案。
