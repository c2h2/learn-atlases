*strengths*（力量，复数）有几个音节？大多数说英语的人只说一个：/streŋθs/（有些人说 /streŋkθs/）。这个词的元音前有三个辅音，元音后有三四个辅音，但只有一个元音，所以只有一拍。把它说成 *si-te-reng-ke-si* 的学习者，把一个音节变成了五个。其中每个音也许都发对了，听话人却仍然可能听不出这个词，因为它的**形状**错了。

普通话的音节短而简单：元音前最多一个辅音，元音后只有 *-n*、*-ng*（或 *-r*）。英语允许元音前最多有三个辅音，元音后最多有四个。本章讲解什么是音节，英语允许哪些辅音组合，怎样数音节，以及怎样说出 *str-*、*-sts*、*-ksθs* 这样的连缀，既不添加元音，也不丢掉音——这对语法也很重要，因为英语的词尾 *-s* 和 *-ed* 不断地造出新的连缀。

## 什么是音节？

说 *banana*（香蕉），同时拍手。你会拍三下：*ba-na-na*。每拍一下标出一个**音节**，即以一个元音为核心的一个语音节拍。

::: definition 音节、音节首、音节核、音节尾 {#def-syllable}
**音节**（syllable）是以一个元音（有时是一个成音节辅音）为中心的语音单位。中心叫作**音节核**（nucleus）。它前面的辅音构成**音节首**（onset）；它后面的辅音构成**音节尾**（coda）。音节核和音节尾合称**韵基**（rhyme），因为两个词最后的韵基相同时就押韵（*cat – hat*（猫—帽子），*light – night*（光—夜晚））。只有音节核是必需的：*I*（我）/aɪ/ 是一个既没有音节首也没有音节尾的音节。
:::

::: widget graph

caption: 用树形图表示的音节 *strengths* /streŋθs/：音节首（onset）由三个辅音组成（/s t r/），音节核（nucleus）是短元音 /e/，音节尾（coda）由三个辅音组成（/ŋ θ s/；有些人在 /ŋ/ 后面加 /k/）。韵基（rhyme）是从元音到结尾的全部内容。普通话的音节，音节首最多只能容纳一个辅音，音节尾最多一个鼻音（或 *r*）。这些点可以拖动。
:::

### 数音节

::: theorem 数音节 {#rule-count}
一个词的音节数等于其中**元音音**的个数（加上成音节辅音），而不是元音字母的个数：

- *cake*（蛋糕）/keɪk/——1个（词尾的 *e* 不发音）；*changed*（改变，过去式）/tʃeɪndʒd/——1个；*strengths*——1个。
- *wanted*（想要，过去式）/ˈwɒntɪd/（GB）——2个：在 /t/ 或 /d/ 之后，词尾 *-ed* 增加一个音节；*watched*（看，过去式）/wɒtʃt/——1个：在其他辅音之后不增加。
- *every*（每个）/ˈevri/——2个；*Wednesday*（星期三）/ˈwenzdeɪ/——2个；*business*（生意）/ˈbɪznəs/——2个；*chocolate*（巧克力）/ˈtʃɒklət/（GB）——2个。在这些词里，有一个书写的元音不发音。
- *button*（纽扣）/ˈbʌtn/——2个；*little*（小的）/ˈlɪtl/——2个：第二个音节是成音节的 /n/ 或 /l/。

有些词有两种常见的读法：*family*（家庭）/ˈfæməli/ 或 /ˈfæmli/，*different*（不同的）/ˈdɪfrənt/ 或 /ˈdɪfərənt/，*comfortable*（舒适的）/ˈkʌmftəbl/ 或 /ˈkʌmfətəbl/。LPD 等词典两种都列出。
:::

::: proof
音节是围绕最开、最响的音——元音——构成的，因为耳朵正是把它们听成节拍。辅音聚集在元音周围。当一个元音又弱又短时（schwa 常常如此），它在正常说话中可能完全消失，两边的辅音就连在一起：*chocolate*、*every*、*family*。如果剩下的辅音是鼻音或 /l/，它本身就能承担这一拍（*button*、*little*）。所以音节数取决于读音而不是拼写，并且在仔细说话和随意说话中可能不同。
:::

::: quiz
*asked*（问，过去式）/ɑːskt/（GB），/æskt/（GA）有几个音节？
- [x] 1
- [ ] 2
- [ ] 3
::: solution
一个元音音，所以一个音节，音节尾由三个辅音 /skt/ 组成。词尾 *-ed* 只有在 /t/ 或 /d/ 之后才增加音节（*wanted*，*needed*（需要，过去式））。说成 /ˈɑːskɪd/ 或 /ˈɑːskə tə/ 就加上了这个词所没有的音节。
:::
:::

::: example 数一个句子的节拍 {#ex-count}
*Every Wednesday my family has chocolate cake.*（每个星期三我们家都吃巧克力蛋糕。）这个句子有几个音节？按正常说话来数，然后和书写的元音字母个数比较。
::: solution
逐词数出元音**音**（[[#rule-count]]）：

| 词 | 音标（GB） | 音节数 |
|---|---|---|
| *Every* | /ˈevri/ | 2 |
| *Wednesday* | /ˈwenzdeɪ/ | 2 |
| *my* | /maɪ/ | 1 |
| *family* | /ˈfæmli/ 或 /ˈfæməli/ | 2 或 3 |
| *has* | /hæz/（弱读 /həz/） | 1 |
| *chocolate* | /ˈtʃɒklət/ | 2 |
| *cake* | /keɪk/ | 1 |

总数：随意说话时11个；如果 *family* 读三个音节，就是12个。这些书写的词里有18个元音字母（*y* 作元音时也算），所以数字母会得出完全错误的节奏。多出来的字母要么不发音（*cake*、*Wednesday*），要么代表通常不读出来的元音（*every*、*chocolate*）。
:::
:::

## 英语允许哪些连缀？

在同一个音节首或音节尾里的两个或更多辅音构成一个**辅音连缀**。英语允许许多连缀，但不是任何组合都可以：*blick* 可以是一个英语单词（只是碰巧不存在），*bnick* 却不可能。

::: definition 辅音连缀 {#def-cluster}
**辅音连缀**（consonant cluster）是在一个音节的音节首或音节尾里、中间没有元音的两个或更多辅音的序列：*play*（玩）里的 *pl*，*street*（街道）里的 *str*，*wants*（想要，第三人称单数）里的 *nts*。在音位标音中，连缀是一串辅音符号：/pleɪ/，/striːt/，/wɒnts/（GB）。*sh* 或 *ng* 这样的拼写不是连缀，因为它代表一个音。
:::

::: theorem 音节首连缀 {#rule-onsets}
1. **两个辅音。** 常见的模式有：
   - 爆破音或 /f/、/θ/、/ʃ/ 后面跟 /l/、/r/、/w/ 或 /j/：*play*（玩），*bring*（带来），*twin*（双胞胎之一），*cute*（可爱的）/kjuːt/，*fly*（飞），*three*（三），*shrink*（缩小）；
   - /s/ 后面跟清爆破音、鼻音、/l/ 或 /w/：*spot*（斑点），*stop*（停止），*sky*（天空），*small*（小的），*snow*（雪），*slow*（慢的），*swim*（游泳）。
   英语音节首不允许：/tl/、/dl/（*tl-*、*dl-*），/sr/，/pw/（某些名字除外），以及任何含 /ŋ/、/ʒ/（外来词除外）或“/h/ + /j/ 以外的辅音”的音节首（*huge*（巨大的）/hjuːdʒ/）。
2. **三个辅音。** 三辅音的音节首总是“/s/ + 清爆破音 /p t k/ + 近音”：*spring*（春天）/spr/，*split*（分开）/spl/，*street*（街道）/str/，*scream*（尖叫）/skr/，*square*（广场）/skw/，*spew*（喷出）/spj/，*skewer*（烤肉叉）/skj/，以及 GB 的 *stew*（炖菜）/stj/。
3. 音节首的辅音永远不超过三个。
:::

::: theorem 音节尾连缀 {#rule-codas}
英语的音节尾最多可以有四个辅音。常见的两辅音音节尾包括“鼻音或 /l/ + 辅音”（*hand*（手），*think*（想），*help*（帮助），*milk*（牛奶）），“/s/ + 爆破音”（*fast*（快的），*ask*（问），*lisp*（口齿不清））以及“爆破音 + /s/ 或 /t/”（*box*（盒子）/ks/，*act*（行动）/kt/）。更长的音节尾通常是由语法词尾造成的：*-s*（复数、第三人称单数、所有格）、*-ed*（过去式）和 *-th*（序数词和名词）：

| 音节尾 | 例词 | 构成 |
|---|---|---|
| /sts/ | *texts*（短信，复数）/teksts/ | *text* + *-s* |
| /mpt/ | *jumped*（跳，过去式）/dʒʌmpt/ | *jump* + *-ed* |
| /lpt/ | *helped*（帮助，过去式）/helpt/ | *help* + *-ed* |
| /nθs/ | *months*（月，复数）/mʌnθs/ | *month* + *-s* |
| /ksθ/ | *sixth*（第六）/sɪksθ/ | *six* + *-th* |
| /ksθs/ | *sixths*（六分之一，复数）/sɪksθs/ | *sixth* + *-s* |
| /mpst/ | *glimpsed*（瞥见，过去式）/ɡlɪmpst/ | *glimpse* + *-ed* |
:::

::: proof
[[#rule-onsets]]和[[#rule-codas]]中的模式符合在许多语言中都观察到的一个普遍倾向：在一个音节里，从音节首到元音，音的响度（“响音度”）趋于上升，到音节尾结束又趋于下降——爆破音和摩擦音的响度最低，然后是鼻音，然后是 /l/ 和 /r/，然后是滑音，然后是元音。*Play* 是上升的（/p/ → /l/ → 元音）；*lpay* 会先降后升，英语不允许。/s/ 是音节边缘一个有名的例外：*stop* 和 *texts* 里的 /s/ 不在预期的顺序之内，所以 /s/ 可以开始三辅音音节首，也可以结束很长的音节尾。这些是对英语的概括描写；LPD 和标准的音系学教材（Roach 2009；Cruttenden 2014）给出了完整的列表。
:::

::: example 可能还是不可能？ {#ex-possible}
下面这些编造的词，哪些可能是英语单词？*blick*，*bnick*，*strop*，*sprill*，*ngat*，*tlop*，*frisk*（一个真实的词），*stwem*。
::: solution
对照[[#rule-onsets]]检查每个音节首：

1. *blick* /blɪk/：/bl/——爆破音 + /l/——可能。（这是“可能存在但实际不存在的词”的经典例子。）
2. *bnick* /bnɪk/：/bn/——爆破音 + 鼻音——不允许。
3. *strop* /strɒp/：/str/——/s/ + 清爆破音 + 近音——可能；实际上它是一个少见的词（磨刀皮带）。
4. *sprill* /sprɪl/：/spr/——可能。
5. *ngat*：音节首是 /ŋ/——不允许。
6. *tlop*：/tl/——英语词首不允许。
7. *frisk* /frɪsk/：音节首 /fr/ 和音节尾 /sk/——都允许（这是一个真实的词，意为“搜身”）。
8. *stwem* /stwem/：/stw/——“/s/ + 清爆破音 + /w/”不在三辅音音节首的列表上——不允许（尽管 *sw-* 和 *tw-* 各自都存在）。

知道什么是可能的，对听力有帮助：如果你听到一个意想不到的连缀，很可能是听错了一个元音或辅音。
:::
:::

## 说出连缀

### 会出什么错

母语音节较简单的学习者，通常用两种办法之一让连缀适应自己的模式。

::: warning 不要在连缀里添加元音
✗ 把 *street* 读成 /səˈtriːt/ 或 /sɪˈtriːt/——一个音节变成了两个。
✗ 把 *desk* 读成 /ˈdeskə/，把 *milk* 读成 /ˈmɪlkə/。
✓ *street*（街道）/striːt/，*desk*（书桌）/desk/，*milk*（牛奶）/mɪlk/——各一个音节。

添加的元音可能改变词（*sport*（运动）→ *support*（支持）/səˈpɔːt/；*blow*（吹）→ *below*（在下面））或者让词难以辨认。要把辅音**连在一起**：在前一个辅音结束之前就开始发后一个辅音。
:::

::: warning 不要丢掉词尾
✗ *Yesterday I ask him.* ✗ *She want two book.* ✗ *Three month ago.*
✓ *Yesterday I asked him.*（我昨天问了他。）/ɑːskt/ ✓ *She wants two books.*（她想要两本书。）/wɒnts/，/bʊks/ ✓ *Three months ago.*（三个月以前。）/mʌnθs/

英语词尾的许多连缀就是**语法**：*asked* 的 /t/ 标志过去时，*wants* 的 /s/ 标志第三人称，*books* 和 *months* 的 /s/ 标志复数。丢掉连缀的最后一个辅音，就丢掉了语法。母语者在快速说话中确实会简化某些连缀（*next week*（下周）/neks wiːk/；见[[connected-speech/elision-assimilation]]），但他们很少把语法词尾完全丢掉，而听话人正是靠这些词尾来理解谁在什么时候做了什么。
:::

### 怎样练习

::: theorem 练习连缀的方法 {#rule-practice}
1. **从元音开始。** 先练韵基，再一个一个地加辅音：练 *texts* 时，说 *ex* → *ext* → *exts* → *texts*。练音节首时，朝着元音的方向加辅音：*reet* → *treet* → *street*。
2. **让辅音重叠。** 在 *act* 或 *jumped* 这样的连缀里，第一个爆破音通常不除阻：前一个闭合还没打开，舌头就移到了下一个闭合的位置。不要让一股气流或一个元音从它们之间漏出来。
3. **保持音节数。** 拍出节拍：*texts* 拍一下，*wanted* 拍两下，*jumped* 拍一下。
4. **先慢，再自然。** 先慢慢地把每个辅音都读出来，再用正常的速度说。正常的速度常常让连缀更容易，因为动作会互相重叠。
:::

::: example 构建一个连缀 {#ex-build}
用[[#rule-practice]]练习 *months*（月，复数）/mʌnθs/ 和 *asked*（问，过去式）/ɑːskt/（GB）。
::: solution
*months*：
1. 从元音和鼻音开始：*un* /ʌn/ → *mun* /mʌn/。
2. 加 /θ/：/n/ 之后舌尖留在齿龈上，然后向前滑到牙齿：*munth* /mʌnθ/。
3. 加 /s/：把舌尖从牙齿处稍稍收回到牙齿后面：*months* /mʌnθs/。（许多母语者在快速说话中把它简化为 /mʌns/ 或 /mʌnts/；清楚的 /θ/ 仍然是模式。）

*asked*：
1. *ass* /ɑːs/ → *ask* /ɑːsk/：保持 /s/ 的嘶嘶声，直到舌后部为 /k/ 闭合。
2. 加 /t/，**但不要让 /k/ 除阻**：在舌后部仍然闭合时，把舌尖抬到齿龈，然后只让 /t/ 除阻：/ɑːskt/。
3. 拍一下手。如果你拍了两下，说明你加了一个元音。
:::
:::

::: example 修复学习者的音节 {#ex-repair}
一位学习者把 *She wants to buy six desks.*（她想买六张书桌。）读成了 *she want-e-su tu bai si-ku-su de-su-ku-su*。数一数学习者的版本和标准版本的音节，并说明哪里出了错。
::: solution
标准读法（GB）：/ʃi ˈwɒnts tə ˈbaɪ ˈsɪks ˈdesks/——*She*（1）*wants*（1）*to*（1）*buy*（1）*six*（1）*desks*（1）= **6个音节**。

学习者的版本：*she*（1）*want-e-su*（3）*tu*（1）*bai*（1）*si-ku-su*（3）*de-su-ku-su*（4）= **13个音节**。

哪里出了错：
1. 在连缀 /nts/、/ks/ 和 /sks/ 的里面和后面加了元音，使节拍数增加了一倍多。
2. 句子失去了节奏：重读音节 *wants*、*buy*、*six*、*desks* 应该是节拍；多出来的元音把它们淹没了。

修复：从元音向外练习音节尾——*ants* → *wants*；*iks* → *six*；*esk* → *desk* → *desks*——整个句子拍六下。
:::
:::

::: quiz
哪个词的音节首有**三个辅音**？
- [ ] *stay*
- [x] *splash*
- [ ] *flash*
- [ ] *shrimp*
::: solution
*Splash*（溅）/splæʃ/ 以 /spl/ 开头：/s/ + 清爆破音 + 近音。*Stay*（停留）和 *flash*（闪光）的音节首有两个辅音（/st/，/fl/）。*Shrimp*（虾）/ʃrɪmp/ 也只有两个：/ʃ/ 是一个音，所以 *shr* 是 /ʃr/。
:::
:::

## 一段简短的对话

**Mohammed:** *What are your plans for the next six months?*（接下来的六个月你有什么计划？）

**Li Na:** *First, I've got my driving test in March. Then I start a new job in the spring.*（首先，三月份我要考驾照。然后春天我开始一份新工作。）

**Mohammed:** *Congratulations! Where's the job?*（恭喜！工作在哪里？）

**Li Na:** *At a sports club in the west of the city. I helped there last summer, and they asked me to come back.*（在城西的一家体育俱乐部。去年夏天我在那里帮过忙，他们请我回去。）

**Mohammed:** *That's great. It sounds like the next six months will be busy.*（太好了。听起来接下来的六个月会很忙。）

要注意听的连缀——**音节首**：*plans* /pl/，*driving* /dr/，*spring* /spr/，*sports* /sp/，*club* /kl/；**音节尾**：*plans* /nz/，*next* /kst/，*six* /ks/，*months* /nθs/，*first* /st/，*test* /st/，*helped* /lpt/，*last* /st/，*asked* /skt/，*sports* /ts/，*west* /st/，*sounds* /ndz/。

::: note 英汉对比
- **普通话的音节。** 标准普通话的音节结构是 (C)(G)V(N)：开头最多一个辅音（*zh*、*q* 这样的破擦音算一个），一个可有可无的介音（主要元音前的 *i*、*u*、*ü*，如 *jiā*、*guó*），一个元音，以及一个可有可无的韵尾 *-n* 或 *-ng*（或儿化的 *-r*）。没有辅音连缀，结尾也没有爆破音或摩擦音。因此 *strengths* 这样的英语音节远远超出了普通话的模式。
- **一字一音节。** 汉字给每个音节一个字，所以中国读者习惯于看到音节。英语拼写则不然：*strengths* 有九个字母、一个音节，*idea*（主意）有四个字母、三个音节。要数元音音，不要数字母。
- **添加的元音。** 添加的元音通常短而居中，像普通话 *de*（的）里的 *e*：*desk* 变成类似 *desk-e* 的音。说粤语和闽南话的人，母语里有词尾 /p t k/，在词尾爆破音后面加的元音往往较少，但仍然可能觉得“/s/ + 爆破音”连缀和语法词尾很难。
- **语法和语音一起。** 由于汉语没有表示时和数的屈折变化（[[core-grammar/past-simple]]，[[core-grammar/nouns-pronouns]]），丢掉 *asked* 词尾 /t/ 或 *books* 词尾 /s/ 的学习者，可能同时也忘了语法。练习连缀就是练习语法。
:::

::: history
英语词首的连缀曾经更多。在古英语和中古英语里，*knee*（膝盖）、*know*（知道）和 *knight*（骑士）里的 *k*，*gnaw*（啃）里的 *g*，*write*（写）和 *wrong*（错的）里的 *w* 都是要读出来的：*knight* 以 /kn/ 开头，就像它的德语同源词 *Knecht* 至今仍然那样。这些连缀大约在15到18世纪之间被简化了（/kn/ 是最后消失的之一，在17世纪）。那时拼写已经固定下来，所以英语词首满是“不发音字母”——这是[[sounds-of-english/spelling-and-sound]]的话题。
:::

## 后续内容

拼写规律、不发音字母以及词尾 *-s* 和 *-ed* 的读音在[[sounds-of-english/spelling-and-sound]]中讲解。一个词的哪个音节重读，是[[sounds-of-english/word-stress-basics]]的内容。在快速说话中，连缀会跨越词界被简化（*next week*，*last time*）：见[[connected-speech/elision-assimilation]]和[[connected-speech/rhythm]]。

::: summary
- **音节**有一个音节核（通常是元音），前面可以有音节首，后面可以有音节尾（[[#def-syllable]]）。
- 按**元音音**而不是字母数音节：*changed* 有1个，*wanted* 2个，*every* 2个，*button* 2个（[[#rule-count]]）。
- **辅音连缀**是音节首或音节尾里连在一起的两个或更多辅音（[[#def-cluster]]）。
- 英语音节首最多三个辅音；三辅音音节首是“/s/ + /p t k/ + 近音”（*spring*，*street*，*square*）（[[#rule-onsets]]）。
- 音节尾最多可以有四个辅音，主要是因为词尾 *-s*、*-ed* 和 *-th*（*texts*，*helped*，*sixths*）（[[#rule-codas]]）。
- 不要在连缀里加元音（*street* 是一个音节），也不要丢掉承载语法的词尾辅音（*asked*，*wants*，*months*）。
- 从元音向外练习，让辅音重叠，拍出节拍（[[#rule-practice]]）。
:::

## 习题

::: exercise 数音节 {level=1}
每个词有几个音节？

*cake*（蛋糕），*changed*（改变，过去式），*wanted*（想要，过去式），*banana*（香蕉），*every*（每个），*little*（小的），*strengths*（力量，复数），*photographer*（摄影师）
::: solution
*cake* 1；*changed* 1；*wanted* 2；*banana* 3；*every* 2（/ˈevri/）；*little* 2（成音节的 /l/）；*strengths* 1；*photographer* 4（/fəˈtɒɡrəfə/）。
:::
:::

::: exercise 音节首、音节核、音节尾 {level=1}
把每个单音节词分成音节首、音节核和音节尾（用音位符号）。

*play*（玩），*ask*（问），*spring*（春天），*texts*（短信，复数），*eye*（眼睛）
::: solution
- *play* /pleɪ/：音节首 /pl/，音节核 /eɪ/，没有音节尾。
- *ask* /ɑːsk/（GB）：没有音节首，音节核 /ɑː/，音节尾 /sk/。
- *spring* /sprɪŋ/：音节首 /spr/，音节核 /ɪ/，音节尾 /ŋ/。
- *texts* /teksts/：音节首 /t/，音节核 /e/，音节尾 /ksts/。
- *eye* /aɪ/：没有音节首，音节核 /aɪ/，没有音节尾。
:::
:::

::: exercise 可能的英语单词？ {level=1}
这些编造的词中，哪些在英语里是可能的？*plim*，*dlock*，*skrat*，*sring*，*glemps*
::: solution
可能：*plim*（/pl/），*skrat*（/skr/），*glemps*（音节首 /ɡl/，音节尾 /mps/，和 *glimpse*（瞥见）一样）。不可能：*dlock*（/dl/ 不是英语的音节首）和 *sring*（/sr/ 不是英语的音节首）。
:::
:::

::: exercise 一个音节还是两个？ {level=2}
词尾 *-ed* 是否增加一个音节？用音位符号写出每个词。

*started*（开始，过去式），*stopped*（停止，过去式），*needed*（需要，过去式），*played*（玩，过去式），*missed*（错过，过去式），*decided*（决定，过去式）
::: solution
增加一个音节（在 /t/ 或 /d/ 之后）：*started* /ˈstɑːtɪd/（GB），*needed* /ˈniːdɪd/，*decided* /dɪˈsaɪdɪd/。
不增加音节：*stopped* /stɒpt/（GB），*played* /pleɪd/，*missed* /mɪst/。
（在 GA 里，增加的元音常常是 /ə/：/ˈstɑːrtəd/。）
:::
:::

::: exercise 最长的音节尾 {level=2 check="4"}
*texts* /teksts/ 的音节尾有几个辅音？
::: solution
元音 /e/ 之后是 /k/、/s/、/t/、/s/：四个辅音。（字母 *x* 代表两个音，/ks/。）答案是4。
:::
:::

::: exercise 找出语法 {level=2}
在每个句子中找出承载语法（过去式、复数、第三人称单数或所有格）的连缀，并说明每个连缀表示什么。

1. *He jumped and laughed.*（他又跳又笑。）
2. *The kids' bikes are outside.*（孩子们的自行车在外面。）
3. *She asks questions in all her lessons.*（她在每节课上都提问。）
::: solution
1. *jumped* /dʒʌmpt/：/pt/——过去式；*laughed* /lɑːft/（GB），/læft/（GA）：/ft/——过去式。
2. *kids'* /kɪdz/：/dz/——复数兼所有格；*bikes* /baɪks/：/ks/——复数。
3. *asks* /ɑːsks/（GB）：/sks/——第三人称单数；*questions* /ˈkwestʃənz/：/nz/——复数；*lessons* /ˈlesnz/：/nz/——复数。
:::
:::

::: exercise 修复音节 {level=3}
一位学习者朗读下面这个句子时加了元音：*Last spring the students planned six tests.*（去年春天，学生们计划了六次测验。）用音位符号写出标准读法（GB 或 GA），数出它的音节数，并为最难的两个词设计一个练习步骤。
::: hint
找出最长的连缀：一个是过去式，一个是复数。
:::
::: solution
标准读法（GB）：/lɑːst sprɪŋ ðə ˈstjuːdnts plænd sɪks tests/。GA：/læst sprɪŋ ðə ˈstuːdnts plænd sɪks tests/。

音节：*Last* 1，*spring* 1，*the* 1，*students* 2（*stu-dents*，带成音节的 /n/ 或 /ən/），*planned* 1，*six* 1，*tests* 1 = **8**。

最难的词和练习步骤（也可以选别的词）：
- *tests* /tests/：*es* → *est* → *ests* → *tests*。不要丢掉词尾的 /s/（复数），也不要在 /t/ 和 /s/ 之间加元音。
- *planned* /plænd/：*an* → *and* → *land* → *planned*。舌头抵着齿龈，让 /n/ 和 /d/ 连在一起，并把元音发长（后面跟着浊音 /d/）。
- （*students*：*dents* → 带成音节 /n/ 的 *-dnts* → *students*。）
:::
:::

::: exercise 口头小结 {level=3}
说（并录下）四五个句子，讲讲你上周做了什么，至少用五个以连缀结尾的过去式动词（如 *worked*、*helped*、*asked*、*watched*、*finished*）和至少三个以连缀结尾的复数名词（如 *friends*、*texts*、*months*）。听录音并检查：每个连缀是否保持在一个音节之内？每个词尾都听得见吗？
::: solution
答案因人而异。一个范例：

> *Last week I worked late on Monday and Tuesday. On Wednesday I helped two friends move flat, and we watched a film afterwards. I finished my report on Thursday and asked my manager for comments. At the weekend I answered all my texts.*

**译文：**上周一和周二我都加班到很晚。周三我帮两个朋友搬家，之后我们看了一场电影。周四我写完了报告，并请经理提意见。周末我回复了所有的短信。

过去式连缀：*worked* /kt/，*helped* /lpt/，*watched* /tʃt/，*finished* /ʃt/，*asked* /skt/，*answered* 在 GB 的 /ə/ 之后是 /d/（GA 是 /rd/）。复数连缀：*friends* /ndz/，*comments* /nts/，*texts* /ksts/。检查录音里有没有加元音（✗ *work-ed*，✗ *help-e-d*）和丢词尾（✗ *I finish my report*）。
:::
:::
