大声说出 *photograph*（照片）、*photographer*（摄影师）和 *photographic*（摄影的）。这三个词开头的字母相同，但每个词里强的音节不同：**PHO**tograph，pho**TO**grapher，photo**GRA**phic。而且元音随着重音而变化：第一个 *o* 在 *photograph* 里读 /əʊ/，在 *photographer* 里却是弱的 /ə/。听话人听到 pho**TO**graph，大概还是能听懂——但要费更多力气，也可能听成另一个词。

英语里每个多于一个音节的词，都有一个音节是**重读**的：它比其他音节突出。读对重音和发对音一样重要，因为说英语的人靠重音来辨认词。本章讲解什么是重音，词典怎样标重音，以及预测重音最有用的规律：双音节名词和动词，会移动重音的后缀和不移动重音的后缀，以及复合词。本章以[[sounds-of-english/syllables-clusters]]的音节和[[sounds-of-english/short-vowels]]的弱元音为基础。

## 什么是词重音？

::: definition 词重音 {#def-stress}
**词重音**（word stress）是一个词中某个音节比其他音节更突出。突出的音节是**重读**音节；其他音节是**非重读**音节。有些较长的词还有一个**次重音**（secondary stress），它比主要的（**主**）重音弱，但比非重读音节强：在 *photographic* 里，主重音在 *-graph-* 上，次重音在 *pho-* 上。
:::

在本课程中，重音有三种写法：

- 用词典使用的国际音标符号：主重音音节前加 **ˈ**，次重音音节前加 **ˌ**：/ˈfəʊtəɡrɑːf/，/fəˈtɒɡrəfə/，/ˌfəʊtəˈɡræfɪk/（GB）；
- 在普通拼写中用大写字母，如 **PHO**tograph——一种快捷的非正式方法；
- 用大小圆圈组成的图式：*photograph* **O**oo，*photographer* o**O**oo，*photographic* oo**O**o（这里次重音算作小圆圈）。

注意，音标符号要放在重读音节的**前面**，而不是它的元音上面：*about*（关于）写作 /əˈbaʊt/，而不是 /əbˈaʊt/。

::: theorem 是什么让一个音节重读 {#rule-cues}
英语的重读音节和非重读音节有四个方面的区别，通常同时出现：

1. **音高。** 声音在它上面上升或下降。单独说一个词时，音高通常在重读音节上跳升或下降。
2. **长度。** 它更长：元音保持的时间更久。
3. **响度。** 它稍微响一些。
4. **元音音质。** 它有一个完整的元音。非重读音节非常常见的是弱元音——/ə/、/i/、/u/ 或 /ɪ/——或者成音节辅音（[[sounds-of-english/short-vowels#rule-reduction]]）。

其中第四点是大多数学习者忘记的。英语的非重读音节不只是轻一些：它们的元音会**变**。*Photograph* /ˈfəʊtəɡrɑːf/ 的第二个音节是 schwa；*photographer* /fəˈtɒɡrəfə/ 的第一、第三、第四个音节都是 schwa。
:::

::: proof
对英语的研究（始于20世纪50年代弗赖伊（Dennis Fry）的实验）发现，对听话人来说，音高和长度是比单纯的响度更强的重音线索。元音音质在实际中同样重要：因为非重读元音很弱，重读音节就在它们的衬托下突显出来。这也解释了为什么重音对辨认词如此重要。重音放错，不只是挪动了一个响亮的节拍；它把完整的元音放在了应该是弱元音的地方，又把弱元音放在了应该是完整元音的地方，于是词的声音形状就变了。
:::

下图是三个 *photo-* 词的示意图：每个峰标出重读音节。

::: widget plot
f: 7.5 + 1.6*exp(-10*(x-1)^2); 5 + 1.6*exp(-10*(x-2)^2); 2.5 + 0.7*exp(-10*(x-1)^2) + 1.6*exp(-10*(x-3)^2); 1.6*exp(-10*(x-s)^2)

caption: 词重音的示意图——不是测量结果。横轴是音节序号（1、2、3、4）；每条线在重读音节上升到一个峰，就像实际说话时音高、长度和响度的变化那样。*Photograph* /ˈfəʊtəɡrɑːf/ 的峰在第1个音节，*photographer* /fəˈtɒɡrəfə/ 在第2个，*photographic* /ˌfəʊtəˈɡræfɪk/ 在第3个，并在第1个音节上有一个较小的峰（次重音）。移动滑块 s，给你自己的一个词安放重音，并按线所示的峰的位置说出这个词。

::: warning 重音不是每个音节都一样
✗ 每个音节说得一样长、一样有力：*pho-to-gra-pher*，每个音节同样强。
✗ 移动重音：✗ pho**TO**graph，✗ **PHO**tographer，✗ **HO**tel，✗ com**FOR**table，✗ in**TER**esting。
✓ **PHO**tograph /ˈfəʊtəɡrɑːf/，pho**TO**grapher /fəˈtɒɡrəfə/，ho**TEL**（酒店）/həʊˈtel/，**COM**fortable（舒适的）/ˈkʌmftəbl/，**IN**teresting（有趣的）/ˈɪntrəstɪŋ/。

这两种错误都使词更难辨认。学一个两个或更多音节的新词时，一定要同时学它的重音在哪里——词典用 ˈ 标出。
:::

## 双音节词的规律

没有哪一条规则能预测英语每个词的重音，但几种倾向覆盖了很大一部分词汇。

::: theorem 双音节的名词、形容词和动词 {#rule-two}
1. 大多数双音节**名词**和**形容词**重音在**第一个**音节：**TA**ble（桌子），**WIN**dow（窗户），**MO**ney（钱），**CHI**na（中国），**HAP**py（快乐的），**CLE**ver（聪明的），**YEL**low（黄色的）。
2. 许多双音节**动词**重音在**第二个**音节，尤其是以 *be-*、*de-*、*re-*、*for-*、*ex-*、*con-* 等前缀开头的：be**GIN**（开始），de**CIDE**（决定），re**PEAT**（重复），for**GET**（忘记），ex**PLAIN**（解释），con**TROL**（控制）。但许多常用动词重音在第一个音节：**O**pen（打开），**LIS**ten（听），**HAP**pen（发生），**AN**swer（回答），**VI**sit（拜访），**STU**dy（学习），**FI**nish（完成）。
3. 第（1）条的**例外**很常见，必须记住：ho**TEL**（酒店），ma**CHINE**（机器），a**DVICE**（建议），mis**TAKE**（错误），Ju**LY**（七月），a**LONE**（独自），cor**RECT**（正确的）。
:::

::: proof
词首重音的倾向可以追溯到古英语的日耳曼式重音，它落在词根的第一个音节上（详见下文的历史部分）。古英语动词的前缀通常不重读（*be-*、*for-*、*a-*），所以重音落在词根上：*begin*，*forget*，*arise*（出现）。许多从拉丁语和法语借来的动词，同样是“前缀 + 词根”（*de-cide*，*re-peat*，*ex-plain*），也重读词根。从法语借来的名词有时保留了词尾重音（*hotel*，*machine*），所以名词规则有例外。
:::

### 名词—动词对

有一组常见的双音节词，大多是经法语从拉丁语来的，拼写相同，既可作名词又可作动词。其中许多靠重音区分：**名词重音在第一个**音节，**动词重音在第二个**。非重读音节的元音通常弱化。

| 词 | 名词 | 动词 |
|---|---|---|
| *record* | /ˈrekɔːd/（GB），/ˈrekərd/（GA）*a world record*（世界纪录） | /rɪˈkɔːd/（GB），/rɪˈkɔːrd/（GA）*record a song*（录一首歌） |
| *present* | /ˈpreznt/ *a birthday present*（生日礼物） | /prɪˈzent/ *present an idea*（提出一个想法） |
| *object* | /ˈɒbdʒekt/（GB），/ˈɑːbdʒekt/（GA）*a heavy object*（一个重物） | /əbˈdʒekt/ *object to a plan*（反对一项计划） |
| *permit* | /ˈpɜːmɪt/（GB），/ˈpɜːrmɪt/（GA）*a work permit*（工作许可证） | /pəˈmɪt/（GB），/pərˈmɪt/（GA）*permit smoking*（允许吸烟） |
| *increase* | /ˈɪnkriːs/ *a price increase*（涨价） | /ɪnˈkriːs/ *prices increase*（价格上涨） |
| *export* | /ˈekspɔːt/（GB）*China's exports*（中国的出口商品） | /ɪkˈspɔːt/（GB）*export cars*（出口汽车） |
| *produce* | /ˈprɒdjuːs/（GB），/ˈproʊduːs/（GA）*fresh produce*（新鲜农产品） | /prəˈdjuːs/（GB），/prəˈduːs/（GA）*produce a film*（制作一部电影） |
| *contrast* | /ˈkɒntrɑːst/（GB），/ˈkɑːntræst/（GA）*a strong contrast*（鲜明的对比） | /kənˈtrɑːst/（GB），/kənˈtræst/（GA）*contrast two ideas*（对比两个观点） |

并不是所有既作名词又作动词的词都这样。*Visit*（拜访）、*answer*（回答）、*promise*（承诺）和 *travel*（旅行）无论作名词还是动词，重音都在第一个音节；*control*（控制）、*report*（报告）、*respect*（尊重）、*surprise*（惊奇）和 *advice*/*advise*（建议）都在第二个音节。有些词的名词还有两种读法：*research*（研究）在 GB 里读 /rɪˈsɜːtʃ/ 或 /ˈriːsɜːtʃ/，LPD 两种都列出；*address*（地址，名词）在 GB 里读 /əˈdres/，在 GA 里常读 /ˈædres/。

::: example 名词还是动词？ {#ex-noun-verb}
标出黑体词的重音，并说明它是名词还是动词。

1. *Farmers **produce** most of the country's food.*（农民生产这个国家的大部分食物。）
2. *They sell local **produce** at the market.*（他们在市场上卖本地农产品。）
3. *Did anyone **object** to the new rules?*（有人反对新规定吗？）
4. *There was a strange **object** in the sky.*（天上有一个奇怪的物体。）
5. *We need a **permit** to park here.*（我们需要许可证才能在这里停车。）
::: solution
1. pro**DUCE** /prəˈdjuːs/（GB）——动词（在主语 *Farmers* 之后）。
2. **PRO**duce /ˈprɒdjuːs/（GB）——名词（“农产品”），在 *local* 之后。
3. ob**JECT** /əbˈdʒekt/——动词，在 *Did anyone* 之后。
4. **OB**ject /ˈɒbdʒekt/（GB）——名词，在 *a strange* 之后。
5. **PER**mit /ˈpɜːmɪt/（GB）——名词，在 *a* 之后。

注意非重读音节的元音怎样变弱：名词 *object* 的第二个音节是完整的 /e/（/ˈɒbdʒekt/），而动词的第一个音节是弱的 /ə/（/əbˈdʒekt/）。
:::
:::

::: quiz
在哪个句子里 *present* 的重音在**第二个**音节？
- [ ] *She gave me a present.*
- [ ] *Everyone was present at the meeting.*
- [x] *He will present the results tomorrow.*
- [ ] *Live in the present.*
::: solution
只有动词（*present the results*，“展示、正式提出”）读 pre**SENT** /prɪˈzent/：*He will present the results tomorrow.*（他明天将公布结果。）名词（“礼物”；“现在”）和形容词（“在场的”）都读 **PRE**sent /ˈpreznt/：*She gave me a present.*（她送了我一份礼物。）*Everyone was present at the meeting.*（每个人都出席了会议。）*Live in the present.*（活在当下。）
:::
:::

## 后缀与重音

许多较长的英语词是由一个较短的词加上一个**后缀**（词尾）构成的：*photograph* + *-ic*，*able* + *-ity*，*happy* + *-ness*。有些后缀会移动词的重音；有些则让重音留在原处。对学习者来说，这是最有用的一组重音规则，因为它能让你预测成千上万个词的重音。

::: theorem 固定重音的后缀 {#rule-suffix}
1. 带 *-ion*（*-tion*、*-sion*）、*-ic*、*-ical*、*-ity*、*-ial*、*-ian*、*-ious*、*-ient* 的词，**重音在后缀前面紧挨着的那个音节**：
   - **e**ducate（教育）→ edu**CA**tion（教育，名词）；de**CIDE**（决定）→ de**CI**sion（决定，名词）；**E**conomy（经济）→ eco**NO**mic（经济的）；**PO**litics（政治）→ po**LI**tical（政治的）；**A**ble（能够的）→ a**BI**lity（能力）；e**LEC**tric（电的）→ elec**TRI**city（电）；**MU**sic（音乐）→ mu**SI**cian（音乐家）；**MYS**tery（谜）→ mys**TE**rious（神秘的）。
2. 带 *-ee*、*-eer*、*-ese*、*-ique*、*-ette* 的词，**重音在后缀本身**：employ**EE**（雇员），engi**NEER**（工程师），Chi**NESE**（中国的），u**NIQUE**（独特的），ciga**RETTE**（香烟）（GB）。
3. 带 *-ic* 的常见例外：**A**rabic（阿拉伯语），**CA**tholic（天主教的），**LU**natic（疯子），**PO**litics（政治），**RHE**toric（修辞），**A**rithmetic（算术，名词）。
:::

::: theorem 不移动重音的后缀 {#rule-neutral}
许多后缀是**重音中性**的：它们增加一个音节，但重音仍留在原词的位置。包括 *-ness*、*-ment*、*-ful*、*-less*、*-ly*、*-er*、*-ing*、*-ed*、*-able*（通常）、*-ship*、*-hood*、*-ish*：

- **HAP**py（快乐的）→ **HAP**piness（幸福）；em**PLOY**（雇用）→ em**PLOY**ment（就业）；**BEAU**ty（美）→ **BEAU**tiful（美丽的）；**CARE**（小心）→ **CARE**less（粗心的）；**SUD**den（突然的）→ **SUD**denly（突然地）；de**VE**lop（发展）→ de**VE**loper（开发者），de**VE**loping，de**VE**loped；**COM**fort（舒适）→ **COM**fortable（舒适的）；**FRIEND**（朋友）→ **FRIEND**ship（友谊）；**CHILD**（儿童）→ **CHILD**hood（童年）。
:::

::: proof
这种区别来自后缀的历史。固定重音的后缀（*-ion*、*-ic*、*-ity*）随着拉丁语和法语词进入英语，也带来了它们自己的重音规则：拉丁语中，倒数第二个音节如果是重音节就重读它，否则重读倒数第三个音节；这些词尾中的 *-ic-*、*-it-*、*-i-* 构成一个短而轻的音节，于是重音就落在它们的前面。中性后缀大多是英语本族的（*-ness*、*-ful*、*-less*、*-ly*、*-ship*、*-hood*），它们只是加在一个重音已经确定的词上。（*-ment* 和 *-able* 来自法语，但表现得像本族后缀。）在实际中，这意味着一旦知道了原词的重音，中性后缀就不费任何力气；固定重音的后缀则需要用规则。
:::

::: example 一个词族 {#ex-family}
标出下列各词族中每个词的主重音，并说明适用哪条后缀规则。

1. *photograph*（照片），*photography*（摄影），*photographic*（摄影的）
2. *economy*（经济），*economic*（经济的），*economist*（经济学家）
3. *public*（公众的），*publicity*（宣传），*publicly*（公开地）
::: solution
1. **PHO**tograph /ˈfəʊtəɡrɑːf/——随原词记住。pho**TO**graphy /fəˈtɒɡrəfi/——这里的 *-y* 属于希腊语来源的 *-graphy*，重音在 *-graph-* 前面的音节：把它和 *geography*（地理）、*biography*（传记）当作一个模式来记（*-ography* 的重音总是在 *-OG-* 上）。photo**GRA**phic /ˌfəʊtəˈɡræfɪk/——*-ic*：重音在前一个音节（[[#rule-suffix]]）。
2. e**CO**nomy /ɪˈkɒnəmi/（GB）——随原词记住；eco**NO**mic /ˌiːkəˈnɒmɪk/ 或 /ˌekəˈnɒmɪk/——*-ic*；e**CO**nomist /ɪˈkɒnəmɪst/——*-ist* 在这里不移动重音（随 *economy*）。
3. **PUB**lic /ˈpʌblɪk/；pub**LI**city /pʌbˈlɪsəti/——*-ity*：重音在前一个音节；**PUB**licly /ˈpʌblɪkli/——*-ly* 是中性的（[[#rule-neutral]]）。

在第1和第2个词族中，注意元音怎样变化：*photo-* 各词的第一个音节是 /əʊ/ → /ə/ → /əʊ/，*econom-* 各词的第二个音节是 /ɒ/ → /ə/ → /ɒ/。
:::
:::

## 复合词

**复合词**是由两个词构成的词：*blackboard*（黑板），*bus stop*（公共汽车站），*mobile phone*（手机）。复合名词的重音通常在**第一**部分，而“形容词 + 名词”短语的重音通常在**第二**部分：

| 复合名词（重读第一部分） | 短语（重读第二部分） |
|---|---|
| a **BLACK**bird（乌鸫，一种鸟） | a black **BIRD**（任何一只黑色的鸟） |
| a **GREEN**house（温室，种植物的玻璃房） | a green **HOUSE**（一座漆成绿色的房子） |
| a **HOT** dog（热狗，面包夹香肠） | a hot **DOG**（一只觉得热的狗） |
| a **BUS** stop（公共汽车站），a **BOOK**shop（书店），a **CAR** park（停车场） | a big **SHOP**（一家大商店），a new **CAR**（一辆新车） |

例外很多——第一部分表示材料或地点的复合词常常重读第二部分（*apple **PIE***（苹果派），*town **HALL***（市政厅））——这些在[[connected-speech/word-stress-patterns]]中学习。

::: example 复合词还是短语？ {#ex-compound}
标出黑体词的重音，并解释意思上的区别。

1. *We grow tomatoes in a **greenhouse**.*（我们在温室里种西红柿。）/ *They live in a **green house** near the station.*（他们住在车站附近的一座绿房子里。）
2. *I'd like a **hot dog** with onions.*（我要一个加洋葱的热狗。）/ *Give the **hot dog** some water.*（给那只热坏了的狗一些水。）
3. *She teaches at the **English school** in town.*（她在城里的英语学校教书。）/ *She's an **English teacher**.*（她是英语老师。）
::: solution
1. **GREEN**house /ˈɡriːnhaʊs/——复合名词：种植物的玻璃房。green **HOUSE**——短语：一座绿色的房子。
2. **HOT** dog——复合词：面包卷夹香肠。hot **DOG**——短语：一只太热的狗。
3. *English school* 和 *English teacher* 都可以是两者中的任何一种。**ENG**lish teacher（复合词）是“教英语的人”；English **TEA**cher（短语）是“英国籍的老师”。同样，**ENG**lish school 是“教英语的学校”，English **SCHOOL** 是“英国的一所学校”。

在口语中，只有重音承载这个区别——拼写可能完全相同（*hot dog*），或只差一个空格（*greenhouse*，*green house*）。
:::
:::

::: example 找出一段短文中的重音 {#ex-text}
在每个多于一个音节的词的主重音下画线（或用大写字母写出）：*My sister is a photographer. Last year she visited Japan and took beautiful pictures of the mountains.*（我姐姐是一名摄影师。去年她去了日本，拍了很多美丽的山景照片。）
::: solution
*My **SIS**ter is a pho**TO**grapher. Last year she **VI**sited Ja**PAN** and took **BEAU**tiful **PIC**tures of the **MOUN**tains.*

- *sister*（姐妹），*pictures*（照片），*mountains*（山）：双音节名词，重音在第一个音节（[[#rule-two]]）。
- *photographer*：要记住（*-ography*/*-ographer* 词族）。
- *visited*：*visit* 的重音在第一个音节；*-ed* 是中性的（[[#rule-neutral]]）。
- *Japan*（日本）/dʒəˈpæn/：名词规则的一个例外（但 *Japanese*（日本的）是 Japa**NESE**，带 *-ese*）。
- *beautiful*：*beauty* + 中性的 *-ful*。

注意 *Japan* 的重音在 *Japanese* 里移动了：/ˌdʒæpəˈniːz/。第一个元音在 *Japan* 里是弱的 /ə/，在 *Japanese* 里是完整的 /æ/。
:::
:::

## 英美差异

少数常用词在 GB 和 GA 里重音不同。两种读音都正确；选一种并保持一致。

| 词 | GB | GA |
|---|---|---|
| *garage*（车库） | /ˈɡærɑːʒ/ 或 /ˈɡærɪdʒ/ | /ɡəˈrɑːʒ/ |
| *ballet*（芭蕾） | /ˈbæleɪ/ | /bæˈleɪ/ |
| *café*（咖啡馆） | /ˈkæfeɪ/ | /kæˈfeɪ/ |
| *adult*（成年人） | /ˈædʌlt/（也读 /əˈdʌlt/） | /əˈdʌlt/ 或 /ˈædʌlt/ |
| *laboratory*（实验室） | /ləˈbɒrətri/ | /ˈlæbrətɔːri/ |
| *cigarette*（香烟） | /ˌsɪɡəˈret/ | /ˈsɪɡəret/ 或 /ˌsɪɡəˈret/ |
| *address*（地址，名词） | /əˈdres/ | /ˈædres/ 或 /əˈdres/ |

这些词大多是从法语借来的：GA 常常保留了法语的词尾重音（*ballet*，*café*，*garage*），而 GB 按照本族模式把它移到了第一个音节（[[#rule-two]]）。

## 一段简短的对话

**Receptionist:** *Good afternoon. Welcome to the Riverside Hotel.*（下午好。欢迎光临河畔酒店。）

**Wang Lei:** *Hello. I have a reservation for two nights. My name is Wang.*（你好。我预订了两个晚上。我姓王。）

**Receptionist:** *Let me check. Yes — a double room, with breakfast. Can I see your passport, please?*（我查一下。是的——一间双人房，含早餐。请出示一下您的护照好吗？）

**Wang Lei:** *Here you are. Is there a restaurant in the hotel?*（给你。酒店里有餐厅吗？）

**Receptionist:** *Yes, on the ground floor. And there's a computer in the lobby if you need one.*（有，在一楼。如果您需要，大堂里还有一台电脑。）

要注意的重音：after**NOON**（一个重读第二部分的复合词），**WEL**come，**RI**verside，ho**TEL**，reser**VA**tion（*-tion*），**DOU**ble，**BREAK**fast（复合词），**PASS**port（复合词），**RES**taurant，com**PU**ter，**LOB**by。比较 *Hotel* 和 *Riverside*：一个是重音在第二个音节的双音节名词（例外），一个是重音在第一个音节的三音节复合词。

::: note 英汉对比
- **声调与重音。** 普通话的每个音节都带声调，完整的音节长度大致相同。因此学习者往往给每个英语音节都发完整的元音、同样的长度，抹平了重读音节和非重读音节的区别。普通话里最接近英语非重读音节的是**轻声**：*bàba*（爸爸）、*xièxie*（谢谢）或 *dōngxi*（东西）的第二个音节短、轻、弱，就像 *father*（父亲）或 *thank you*（谢谢你）的非重读音节。
- **音高不是声调。** 英语重读音节上的音高变化不是区别词义的声调：*photograph* 的 *PHO-* 可以用升调也可以用降调说，仍然是同一个词。不能变的是**哪个**音节承载这个变化。
- **汉语借词。** 汉语词的英语说法常常会移动重音：*Beijing* 通常读 /ˌbeɪˈdʒɪŋ/，重音在第二个音节，*kung fu*（功夫）/ˌkʌŋ ˈfuː/ 也是如此。说英语的人套用自己的规律，就像说汉语的人对英语词套用普通话的规律一样。
- **典型错误。** 中国学习者常读错重音的词包括 *interesting*（**IN**teresting），*comfortable*（**COM**fortable），*vegetable*（**VEG**etable，蔬菜），*hotel*（ho**TEL**），*develop*（de**VE**lop，发展），*event*（e**VENT**，事件）和 *Chinese*（单说时读 Chi**NESE**）。
:::

::: history
古英语和其他早期日耳曼语言一样，重音落在词根的第一个音节上：*Ēngland*（英格兰），*wīfmann*（后来的 *woman*，女人），前缀通常不重读（*be-*、*for-*）。1066年以后，成千上万的法语词进入英语，它们的重音靠近词尾（法语 *nature*（自然）、*honour*（荣誉）、*village*（村庄））。在乔叟（14世纪后期）的诗里，这类词仍然可以根据格律需要重读任何一个音节；在之后的几个世纪里，它们大多在本族模式的影响下把重音移到了第一个音节（**NA**ture，**HON**our，**VIL**lage）。16、17世纪直接从拉丁语借入的词遵循另一套体系——也就是解释 *-ic* 和 *-ity* 前面重音的那条拉丁语规则（[[#rule-suffix]]）——所以英语现在有两层重音规律：一层本族的，一层拉丁的。*record*、*present* 和 *object* 这种名词—动词模式至少可以追溯到16世纪，此后扩展到了更多的词。词典从18世纪开始标注重音：沃克（John Walker）的《批判性发音词典》（*Critical Pronouncing Dictionary*，1791）几乎在每个词条上都标了重音。
:::

## 后续内容

较长词的重音、更多后缀规律和复合词重音在[[connected-speech/word-stress-patterns]]中展开。在句子里，有些词重读，有些词弱读：见[[connected-speech/sentence-stress]]、[[connected-speech/weak-forms]]和[[connected-speech/rhythm]]。后缀作为构词手段，是[[word-formation/suffixes]]的内容。中国学习者在英语语音和节奏上的特殊困难，汇集在[[sounds-of-english/sounds-for-chinese-speakers]]中。

::: summary
- **词重音**是一个词中某个音节的突出；长词还可能有次重音（[[#def-stress]]）。
- 词典用 ˈ 标主重音，用 ˌ 标次重音，标在音节的**前面**：/fəˈtɒɡrəfə/。
- 重读音节有音高变化、更长、更响，并且有完整的元音；非重读音节常常是弱元音（[[#rule-cues]]）。
- 大多数双音节名词和形容词重音在第一个音节；许多动词，尤其是带前缀的，重音在第二个音节（[[#rule-two]]）。
- 在 *record*、*present*、*object* 这样的名词—动词对中，名词重读第一个音节，动词重读第二个音节。
- *-ion*、*-ic*、*-ity*、*-ial*、*-ious* 使重音落在它们前面；*-ee*、*-eer*、*-ese*、*-ique* 本身重读（[[#rule-suffix]]）。
- *-ness*、*-ment*、*-ful*、*-less*、*-ly*、*-er*、*-ing* 不移动重音（[[#rule-neutral]]）。
- 复合名词通常重读第一部分（*BLACKbird*），短语重读第二部分（*black BIRD*）。
:::

加上后缀，并标出新词的重音。重音移动了吗？

5. **CARE** → **CARE**fully（小心地）——没有移动（*-ful*、*-ly* 是中性的）。

::: exercise 诊断错误 {level=3}
一位学习者说：*I think this is a very inTERESTing deVElopment. The comPAny will proDUCE more vegeTAbles.*（意思是：我认为这是一个非常有趣的发展。公司将生产更多蔬菜。）找出每个错误的重音，给出正确的重音，并说明本章的哪条规律能帮上忙。
::: solution
1. *in**TER**esting* ✗ → **IN**teresting /ˈɪntrəstɪŋ/ ✓。原词 *interest*（兴趣）的重音在第一个音节，*-ing* 是中性的（[[#rule-neutral]]）；正常说话时这个词有三个音节。
2. *de**VE**lopment* ✓——正确：*de**VE**lop* + 中性的 *-ment*。
3. *com**PA**ny* ✗ → **COM**pany /ˈkʌmpəni/ ✓。名词，重音在第一个音节（[[#rule-two]]）；第二个元音是弱的 /ə/。
4. *pro**DUCE*** ✓——作动词是正确的（名词读 **PRO**duce）。
5. *vege**TA**bles* ✗ → **VEG**etables /ˈvedʒtəblz/ ✓。名词，重音在第一个音节；正常说话时它有三个音节，而不是四个，因为第二个元音消失了。

五个重音中有两个是对的。错误都是把重音放到了靠后的音节上；每一处，名词规律或中性后缀规则都能给出正确答案。
:::
:::

::: exercise 说这段对话 {level=3}
和一位同伴大声朗读“一段简短的对话”一节中的对话，并录音。朗读之前，标出每个两个或更多音节的词的重音。之后听录音：非重读音节是否短而弱？选出三个你认为重音不清楚的词，用下面的方法逐个练习。

方法：（1）在词典中找出重读音节；（2）慢慢地说这个词，只在重读音节上拍手；（3）把非重读元音读弱；（4）用正常速度在句子里说这个词。
::: solution
答案因人而异。对话中学习者常觉得难的词：*reservation*（预订）/ˌrezəˈveɪʃn/（重音在 *-va-*，次重音在 *res-*，*-er-* 和 *-tion* 是弱元音）；*restaurant*（餐厅）/ˈrestrɒnt/ 或 /ˈrestərɒnt/（GB），/ˈrestərɑːnt/（GA）——重音在第一个音节，在 GB 里常常只有两个音节；*computer* /kəmˈpjuːtə/（第一个音节是弱的 /ə/）；*afternoon*（下午）/ˌɑːftəˈnuːn/（GB），重音在末尾。好的录音在每个重读音节上都有清楚的音高和长度的峰，峰与峰之间是短而弱的非重读音节。
:::
