把两根手指轻轻放在喉咙前面。现在发一个长长的 *ssssss*，像蛇吐信子的声音。然后不要停，把它变成长长的 *zzzzzz*，像蜜蜂嗡嗡的声音。从 *s* 变成 *z* 的那一刻，你的手指下面会感到一阵振动开始；回到 *s*，振动又停了。你的舌头没有动，嘴唇也没有动。只有喉咙深处的一样东西变了，而正是这一个变化，把 *Sue*（休，人名）变成 *zoo*（动物园），把 *bus*（公共汽车）变成 *buzz*（嗡嗡声），把 *place*（地方）变成 *plays*（玩；戏剧）。

本章讲的是发出语音的“机器”：肺、喉咙、舌头、嘴唇和鼻子。使用它并不需要懂生物学。你只需要知道几个名称，这样后面各章就能简短而准确地说出“把舌尖放在上齿后面的那道隆起上”这样的话。你还需要三个简单的问题，用来描写英语里几乎所有的辅音；另有三个问题，用来描写所有的元音。有了这些，一个新的音就不再神秘：你能弄清它是怎么发出来的，并有针对性地练习。

像 /s/ 和 /z/ 这样写在两条斜线之间的，表示的是**音**，不是字母。下一章[[sounds-of-english/phonemic-alphabet]]会讲解所有的符号。本章只用到其中几个，每个都配有一个常用词。

## 发音器官

英语（以及汉语）中几乎所有的语音，都是用从肺里**呼出**的气流发出的。气流在出去的路上经过喉咙、口腔，有时还经过鼻腔。这条通道的不同部位可以打开、关闭或变窄。每一种变化都产生一个不同的音。

| 部位 | 在哪里 | 在说话中的作用 |
|---|---|---|
| 肺 | 胸腔里 | 把气推出去 |
| 喉（larynx，俗称“喉头”） | 喉咙里，“喉结”后面 | 容纳声带 |
| 声带（vocal folds） | 喉内两条小小的肌肉带 | 发浊音时振动，发清音时分开 |
| 咽腔（pharynx） | 喉咙后部的空间 | “管道”的一部分，参与塑造元音 |
| 软腭（soft palate，又称 velum） | 口腔顶部靠后的柔软部分 | 向上抬起时关闭鼻腔通道，向下垂时打开它 |
| 硬腭（hard palate） | 口腔顶部中间坚硬的部分 | 发 *yes*（是）里的 /j/ 时舌头靠近它 |
| 齿龈（alveolar ridge） | 上门齿正后方那道坚硬的隆起 | 发 /t/、/d/、/n/、/l/ 时舌头接触它 |
| 牙齿 | 上齿和下齿 | 发 /f/、/v/ 和两个 *th* 音时，嘴唇或舌头接触它 |
| 舌 | 舌尖、舌叶（紧挨舌尖之后）、舌前部、舌后部 | 最重要的活动器官：大多数元音和辅音都靠它 |
| 嘴唇 | | 发 /p/、/b/、/m/ 时闭合；发 *food*（食物）里的 /uː/ 和 /w/ 时收圆 |
| 鼻腔 | 鼻子后面的空间 | 发 /m/、/n/、/ŋ/ 时气流从这里通过 |

试着自己找到每一个部位。用舌尖从上门齿往后舔：先碰到牙齿，然后是一道小隆起（齿龈），再往后硬腭向上拱起，到很靠后的地方又变软了（软腭）。张大嘴、对着镜子说 *ah*，就能看见软腭。

::: definition 发音器官 {#def-articulator}
**发音器官**（articulators）是口腔和喉咙里为发出某个音而活动或被接触的部位。**主动发音器官**会动：嘴唇、舌头和软腭。**被动发音器官**保持不动，由别的器官向它靠近：上齿、齿龈和硬腭。
:::

我们说 /t/ 是“在齿龈处”发出的，意思是舌头（主动发音器官）接触齿龈（被动发音器官）。两者相接触或相靠近的地方叫作**发音部位**（place of articulation）。

## 嗓音：喉咙里的振动

声带是喉内两条小而柔软的肌肉带。它们可以分开，让气流自由通过；也可以合拢。当它们合拢、气流从中间挤过去时，声带就会飞快地一开一合——成年人说话时大约每秒100到250次。这种快速的开合产生一种嗡嗡的振动，我们称之为**嗓音**（voice）。

::: definition 浊音与清音 {#def-voicing}
发音时声带振动的音是**浊音**（voiced），声带不振动的音是**清音**（voiceless）。在正常说话时，英语的元音都是浊音。辅音则两种都有：/z/、/v/、/m/、/l/ 是浊音；/s/、/f/、/h/ 是清音。
:::

检验任何一个音，有三种方法：

1. 像本章开头那样把手指放在喉咙上，感觉有没有振动。
2. 用双手捂住耳朵发这个音。浊音在脑袋里听起来响亮、嗡嗡作响；清音只是轻轻的嘶嘶声。
3. 试着用这个音唱一段曲调。你可以用 *mmmm* 或 *zzzz* 唱歌，却没法用 *ssss* 或 *ffff* 唱。

下面的图说明了嗓音为什么能承载曲调。声带产生的是一种不断重复的波。一个重复的波由许多简单的波叠加而成——一个最低的波，再加上它的“谐波”——然后口腔把其中一些加强、另一些减弱。正因如此，同一种嗡嗡声才能变成 *ee*、*ah* 或 *oo*。

英语的许多辅音是**成对**出现的：两个音在同一部位、用同一方法发出，一个是清音，一个是浊音。

::: theorem 清浊对立的辅音对 {#rule-pairs}
下列英语辅音构成主要靠清浊区分的音对：

| 清音 | 浊音 | 例词 |
|---|---|---|
| /p/ | /b/ | *pie*（馅饼）– *buy*（买） |
| /t/ | /d/ | *ten*（十）– *den*（兽穴） |
| /k/ | /ɡ/ | *coat*（外套）– *goat*（山羊） |
| /f/ | /v/ | *fan*（风扇）– *van*（厢式货车） |
| /θ/ | /ð/ | *thigh*（大腿）– *thy*（〔古〕你的） |
| /s/ | /z/ | *sip*（小口喝）– *zip*（拉链） |
| /ʃ/ | /ʒ/ | *Confucian*（孔子的）– *confusion*（混乱） |
| /tʃ/ | /dʒ/ | *cheap*（便宜的）– *jeep*（吉普车） |

只改变辅音的清浊，就可能变成另一个词：*fan* 和 *van* 意思完全不同。
:::

::: proof
每一对音都用同样的发音器官、以同样的方法发出，只有声带的动作不同。在实际说话中，英语母语者并不只靠清浊来区分这些音对。在词首，/p/、/t/、/k/ 还带有一股气流（送气）；在词尾，/b/、/d/、/ɡ/ 前面的元音比 /p/、/t/、/k/ 前面的元音长。这些附加的区别在[[sounds-of-english/stops-fricatives]]中讲解。这就是上表说“主要”的原因。/ʃ/–/ʒ/ 这一对比较特殊：/ʒ/ 是英语里最少见的辅音，几乎从不出现在词首，所以例子只好用两个长词（*Confucian* /kənˈfjuːʃən/，*confusion* /kənˈfjuːʒən/）。
:::

::: quiz
哪个词以浊音**开头**？
- [ ] *sea*
- [ ] *fine*
- [x] *very*
- [ ] *hat*
::: solution
*Very*（非常）以 /v/ 开头：下唇接触上齿，声带振动，所以能感到振动。*sea*（海）里的 /s/、*fine*（好的）里的 /f/、*hat*（帽子）里的 /h/ 都是清音——只有气流，没有振动。
:::
:::

::: example 感受区别 {#ex-feel-voicing}
把手指放在喉咙上，慢慢地说这几个词：*fast*（快的）、*vast*（巨大的）、*sink*（水槽；下沉）、*zinc*（锌）。每个词的振动从哪里开始？
::: solution
1. *fast* /fɑːst/（GB），/fæst/（GA）：/f/ 是清音。振动从元音才开始。
2. *vast*：/v/ 是浊音。振动从第一个音就立刻开始。
3. *sink*：/s/ 是清音。振动从元音 /ɪ/ 开始。
4. *zinc*：/z/ 是浊音。振动立刻开始。

每一对词里，口腔的动作都一样；变的只是振动开始的位置。还要注意，每个词在结束之前振动都会**停止**：结尾的 /st/ 和 /ŋk/ 里都有清辅音（/ŋ/ 本身是浊音，/k/ 不是）。
:::
:::

## 元音和辅音

在学校里你学过 *a、e、i、o、u* 是“元音”。那些是元音**字母**。本课程里的元音指的是**音**，而这两个概念并不总是一致。

::: definition 元音与辅音 {#def-vowel-consonant}
**元音**（vowel）是气流从口腔中部自由通过、没有任何会产生噪音的闭塞或收窄时发出的音。**辅音**（consonant）是在口腔或喉咙的某处把气流通道堵住或收窄而发出的音。在英语里，元音通常是一个音节的中心，辅音位于它的前后。
:::

英语有两个音介于这两类之间：/j/（*yes* 的第一个音）和 /w/（*wet*（湿的）的第一个音）。发这两个音时口腔几乎和发元音时一样开，但它们不构成音节的中心，所以算作辅音。它们常被称为**半元音**（semivowels）。

::: warning 字母不等于音
✗ *an university*，✗ *an European country*——学习者看的是第一个**字母** *u* 或 *e*。
✓ *a university*（一所大学）、*a European country*（一个欧洲国家）、*a one-way street*（一条单行道）——这些词以**辅音**音 /j/ 和 /w/ 开头，所以用 *a*。
✓ *an hour*（一小时）、*an honest man*（一个诚实的人）——这些词以**元音**音开头，因为 *h* 不发音。

用 *a* 还是 *an*，取决于后面那个词的第一个**音**，而不是第一个字母。*the* 也一样：许多人在辅音音前读 /ðə/，在元音音前读 /ði/ 或 /ðiː/（*the apple*（那个苹果），*the hour*（那个小时））。
:::

### 描写辅音

每个辅音都可以用三个问题来描写。语音学家把答案称为**清浊**、**发音部位**和**发音方法**。

::: theorem 描写辅音的三个问题 {#rule-voice-place-manner}
描写一个辅音，要回答：

1. **清浊**：声带振动吗？（浊音还是清音）
2. **部位**：气流在哪里被阻塞或收窄？（哪两个发音器官相接触或靠近）
3. **方法**：气流是怎样被阻塞或收窄的？（完全闭塞、收窄、从鼻腔通过，等等）

如果英语的两个辅音对这三个问题的回答完全相同，它们就是同一个音。
:::

英语辅音用到的**发音部位**，从口腔前部到后部依次是：

| 部位 | 什么接触什么 | 英语例子 |
|---|---|---|
| 双唇音（bilabial） | 上下两唇 | /p/ *pen*（钢笔），/b/ *bed*（床），/m/ *man*（男人） |
| 唇齿音（labiodental） | 下唇和上齿 | /f/ *fish*（鱼），/v/ *voice*（嗓音） |
| 齿间音（dental） | 舌尖和上齿 | /θ/ *think*（想），/ð/ *this*（这个） |
| 齿龈音（alveolar） | 舌尖和齿龈 | /t/ *top*（顶部），/d/ *dog*（狗），/s/ *sun*（太阳），/z/ *zoo*（动物园），/n/ *no*（不），/l/ *leg*（腿） |
| 齿龈后音（postalveolar） | 舌叶和齿龈稍后的部位 | /ʃ/ *shoe*（鞋），/ʒ/ *measure*（测量），/tʃ/ *chair*（椅子），/dʒ/ *jam*（果酱），/r/ *red*（红色） |
| 硬腭音（palatal） | 舌前部和硬腭 | /j/ *yes*（是） |
| 软腭音（velar） | 舌后部和软腭 | /k/ *cat*（猫），/ɡ/ *go*（去），/ŋ/ *sing*（唱） |
| 声门音（glottal） | 两片声带之间 | /h/ *hat*（帽子） |

/w/（*wet*）同时用到两个部位：双唇收圆，舌后部向软腭抬起。它叫作**唇–软腭音**（labial-velar）。

英语用到的**发音方法**：

| 方法 | 气流怎么了 | 英语例子 |
|---|---|---|
| 爆破音（塞音，plosive / stop） | 先被完全阻住，然后突然放开 | /p b t d k ɡ/ |
| 摩擦音（擦音，fricative） | 从一道窄缝里挤出，产生嘶嘶的噪音 | /f v θ ð s z ʃ ʒ h/ |
| 破擦音（塞擦音，affricate） | 先被阻住，然后从窄缝里慢慢放开 | /tʃ dʒ/ |
| 鼻音（nasal） | 在口腔里被阻住，但软腭下垂，气流从鼻腔出去 | /m n ŋ/ |
| 近音（approximant） | 发音器官彼此靠近，但还没近到产生噪音 | /l r w j/ |

/l/ 是一种特殊的近音：舌尖接触齿龈，但气流从舌头的**两侧**出去。它叫作**边近音**（lateral approximant，“边”就是“两侧”的意思）。

::: example 描写一个辅音 {#ex-describe-consonant}
描写 *sun*（太阳）、*man*（男人）和 *go*（去）的第一个音。
::: solution
- *sun* /s/：声带不振动（清音）；舌尖靠近齿龈（齿龈音）；气流从窄缝里挤出，发出嘶嘶声（摩擦音）。所以 /s/ 是**清齿龈摩擦音**。
- *man* /m/：可以用它哼歌（浊音）；双唇闭合（双唇音）；气流从鼻腔出去（鼻音）。所以 /m/ 是**浊双唇鼻音**。
- *go* /ɡ/：浊音；舌后部接触软腭（软腭音）；气流先被完全阻住再放开（爆破音）。所以 /ɡ/ 是**浊软腭爆破音**。

语音学家按“清浊—部位—方法”的顺序给出这三个答案。
:::
:::

::: quiz
哪个音是**清唇齿摩擦音**？
- [ ] /v/ as in *van*
- [x] /f/ as in *fan*
- [ ] /p/ as in *pan*
- [ ] /θ/ as in *thank*
::: solution
唇齿音指下唇和上齿：只能是 /f/ 或 /v/。摩擦音指气流从窄缝里嘶嘶地挤出。清音指没有振动：所以是 /f/。/v/ 是它的浊音搭档；/p/ 是双唇音、爆破音；/θ/ 是齿间音（舌头和牙齿）。
:::
:::

### 描写元音

发元音时，什么也不接触什么。舌头改变口腔里空间的形状，嘴唇改变出口的形状。三个问题可以描写一个元音。

::: theorem 描写元音的三个问题 {#rule-vowel-questions}
描写一个元音，要回答：

1. **舌位高低**：舌头抬得多高？**闭元音**（close vowel）舌位高、口几乎闭合，如 *see*（看见）；**开元音**（open vowel）舌位低、口张开，如 *father*（父亲）。介于两者之间的是**中元音**（mid vowel），如 *bed*（床）。
2. **舌位前后**：舌头哪一部分最高？**前元音**是舌前部最高（*see*，*bed*，*cat*（猫））；**后元音**是舌后部最高（*food*（食物），*saw*（看见，see 的过去式），*hot*（热的））；**央元音**是舌中部最高（*about*（关于）的第一个音）。
3. **嘴唇**：双唇是**圆唇**（向前突出成圆形，如 *food* 和 *saw*）还是**不圆唇**（展开或放松，如 *see* 和 *cat*）？

有些元音在发音过程中会变化（*my*（我的），*now*（现在），*boy*（男孩）），有些元音比别的长。这些是[[sounds-of-english/short-vowels]]和[[sounds-of-english/long-vowels-diphthongs]]的内容。
:::

::: proof
舌位高低和前后描写的是舌头的最高点，因为这一点决定了口腔里两个主要空间的形状：它前面的空间和它后面的空间。每一种形状都会加强嗓音中的某些谐波（见上图），我们的耳朵就把结果听成某个特定的元音。圆唇使前面的空间变长，声音又随之改变。真实的舌头并不是移动到固定的点上：这些标签描写的是一个区域，每个人的元音都略有不同。所以元音图只是一个指南，而不是精确的地图。
:::

::: example 描写一个元音 {#ex-describe-vowel}
依次说 *see*（看见）、*saw*（看见，过去式）、*sat*（坐，过去式），对着镜子观察自己的嘴。描写每个词里的元音。
::: solution
- *see* /siː/：口几乎闭合，舌前部抬高，双唇展开（像微笑）。这个元音是**闭、前、不圆唇**元音。
- *saw* /sɔː/：舌后部稍稍抬起，双唇收圆。这个元音是**中、后、圆唇**元音（在 GB 里比中元音略高，在 GA 里略低）。
- *sat* /sæt/：下颌下降，舌位低而靠前，双唇不圆。这个元音是**开（或次开）、前、不圆唇**元音。

从 *see* 到 *sat*，你能感到下颌往下移。从 *see* 到 *saw*，你能感到舌头往后缩、嘴唇变圆。
:::
:::

::: intuition 把舌头想成一座小山
把舌头想象成口腔里的一座小山。发 *see* 时，山顶又高又靠近门牙。发 *food* 时，山顶也高，但在后面。发 *father* 时，整座山又低又平。每个元音都是山顶的一个不同位置，再加上圆唇或扁唇。
:::

## 鼻腔和软腭

软腭是一扇门。它向**上**抬时，关上通往鼻腔的路，所有气流都从口腔出去。英语几乎所有的音都是这个位置。它向**下**垂时，气流就可以从鼻腔出去。

发 /m/、/n/、/ŋ/ 时，口腔在某一处是闭合的（/m/ 在双唇，/n/ 在齿龈，/ŋ/ 在软腭），所以气流只能从鼻腔出去。试一试：发一个长长的 *mmmm*，然后捏住鼻子。声音停了，因为气流无路可走。再发一个长长的 *ssss* 并捏住鼻子。什么也没变，因为气流本来就是从口腔出去的。

::: example 找出区别 {#ex-find-difference}
下面每对词的第一个音之间唯一的区别是什么？（用三个问题来判断。）

1. *bat*（球拍；蝙蝠）– *mat*（垫子）
2. *tie*（领带）– *sigh*（叹气）
3. *sea*（海）– *she*（她）
::: solution
1. /b/ 和 /m/ 都是浊音、双唇音。发 /b/ 时气流被阻住再放开（爆破音）；发 /m/ 时气流从鼻腔出去（鼻音）。区别在**方法**：发 /b/ 时软腭抬起，发 /m/ 时软腭下垂。
2. /t/ 和 /s/ 都是清音、齿龈音。发 /t/ 时舌头把通道完全堵住；发 /s/ 时留一道窄缝。区别在**方法**：爆破音对摩擦音。
3. /s/ 和 /ʃ/ 都是清摩擦音。/s/ 的窄缝在齿龈；/ʃ/ 的窄缝稍稍靠后，舌面更宽，嘴唇通常收圆。区别在**部位**：齿龈音对齿龈后音。
:::
:::

## 课堂对话

一位老师和两名学生在练习 *v* 音。大声读出来，说每个音时感受一下它。

**Ms Okafor:** *Put your top teeth on your lower lip. Now blow.*（把上齿放在下唇上。现在吹气。）

**Zhang Hao:** *Ffffff. Like this?*（Ffffff。是这样吗？）

**Ms Okafor:** *Good. That's /f/. Now do the same, but add your voice.*（很好。这就是 /f/。现在照样做，但加上嗓音。）

**Zhang Hao:** *Vvvvvv. Oh, my lip is buzzing!*（Vvvvvv。哦，我的嘴唇在发麻振动！）

**Ms Okafor:** *Exactly. Your vocal folds are vibrating. That's /v/. Now say "very".*（没错。你的声带在振动。这就是 /v/。现在说 “very”。）

**Maria:** *Very. Very good!*（Very。非常好！）

**Ms Okafor:** *Now try "wet" and "vet". For "wet", don't touch your teeth. Just round your lips.*（现在试试 “wet” 和 “vet”。说 “wet” 时不要碰牙齿，只要把嘴唇收圆。）

**Zhang Hao:** *Wet … vet. They feel completely different.*（Wet……vet。感觉完全不一样。）

**Ms Okafor:** *They are. One uses the lips and the teeth; the other uses round lips and no teeth at all.*（本来就不一样。一个用嘴唇和牙齿；另一个用圆唇，完全不用牙齿。）

::: note 英汉对比
普通话用的是同样的发音器官，许多音的发音部位也相同。但普通话和英语利用**清浊**的方式不同。

- 在普通话里，音节开头的辅音几乎都是清音。浊音只有 *m*、*n*、*l*、*r*（还有音节末尾的 *ng*）。拼音的 *b*、*d*、*g* **不是**浊音：它们是不送气的清音，而拼音的 *p*、*t*、*k* 是送气的清音。普通话靠送气与否（那一股气流）来区分这些音对，而不是靠清浊。
- 英语有浊摩擦音——/v/、/ð/、/z/、/ʒ/——标准普通话里没有这些独立的音。对说普通话的人来说，*zoo* 里 /z/ 的振动是声带要做的新动作。
- 中国学习者的母语背景各不相同。说吴语（如上海话）的人，母语里本来就有 /v/、/z/ 这样的浊音，往往觉得 *very* 和 *zoo* 很容易。

所以，本章“手指放在喉咙上”的检验值得经常做。它让你用自己的身体检查，是否发出了英语需要的那种振动。
:::

::: history
人们描写语音是怎样发出来的，已有两千多年的历史：古印度研究梵语的语法学家按发音部位和发音方法给语音分类，比欧洲学者早得多。就英语而言，现代语音学兴起于19世纪。1867年，贝尔（Alexander Melville Bell）出版了《可视语言》（*Visible Speech*），这套符号画出了发音器官的位置。1877年，斯威特（Henry Sweet）出版了《语音学手册》（*A Handbook of Phonetics*），提出了一套细致的语音描写体系。1886年，以帕西（Paul Passy）为首的一批语言教师成立了一个协会，它后来成为**国际语音学会**（International Phonetic Association）；该会的字母表——国际音标（IPA）——于1888年首次发表，你在下一章要学的符号就来源于此。
:::

## 后续内容

描写辅音的三个问题（清浊、部位、方法）和描写元音的三个问题（高低、前后、圆唇）在本课程每一章都会用到。[[sounds-of-english/phonemic-alphabet]]为英语的每一个音配上一个符号。[[sounds-of-english/short-vowels]]和[[sounds-of-english/long-vowels-diphthongs]]逐一讲解元音；[[sounds-of-english/stops-fricatives]]和[[sounds-of-english/nasals-approximants]]逐一讲解辅音。想了解完整的语音科学（包括其他语言的语音）的读者，可以阅读[[linguistics/phonetics-phonology]]。

::: summary
- 语音是由肺里呼出的气流经**发音器官**塑造而成的：嘴唇、舌头和软腭会动；牙齿、齿龈和硬腭不动（[[#def-articulator]]）。
- 声带振动的音是**浊音**，不振动的是**清音**；把手指放在喉咙上就能感到区别（[[#def-voicing]]）。
- 英语的许多辅音成清浊对：/p b/、/t d/、/k ɡ/、/f v/、/θ ð/、/s z/、/ʃ ʒ/、/tʃ dʒ/（[[#rule-pairs]]）。
- 元音和辅音指的是**音**，不是字母：*university* 以辅音 /j/ 开头，所以说 *a university*。
- 辅音用**清浊、部位、方法**描写（[[#rule-voice-place-manner]]）；元音用**舌位高低、前后和圆唇与否**描写（[[#rule-vowel-questions]]）。
- 软腭下垂时，气流从鼻腔通过：/m/、/n/、/ŋ/ 是英语的鼻音。
- 普通话用送气而不是清浊来区分 *b*/*p*、*d*/*t*、*g*/*k*，也没有独立的 /v/、/ð/、/z/、/ʒ/；对许多中国学习者来说，英语浊辅音的振动需要专门练习。
:::

## 习题

::: exercise 浊音还是清音？ {level=1}
把手指放在喉咙上，说出每个词的**第一个**音。它是浊音还是清音？

*fish*（鱼），*dog*（狗），*map*（地图），*hand*（手），*zero*（零），*ship*（船），*look*（看），*tea*（茶）
::: solution
浊音：*dog* /d/，*map* /m/，*zero* /z/，*look* /l/。
清音：*fish* /f/，*hand* /h/，*ship* /ʃ/，*tea* /t/。
:::
:::

::: exercise 找搭档 {level=1}
每个词都以某个清浊音对中的一个音开头。写出一个真实的英语单词，它以这一对中的**另一个**音开头，其余部分不变。

1. *pig*（猪）  2. *fine*（好的）  3. *Sue*（休，人名）  4. *coat*（外套）  5. *chin*（下巴）
::: solution
1. *big*（大的）（/p/ → /b/）
2. *vine*（葡萄藤）（/f/ → /v/）
3. *zoo*（动物园）（/s/ → /z/）
4. *goat*（山羊）（/k/ → /ɡ/）
5. *gin*（杜松子酒）（/tʃ/ → /dʒ/）

只要是真实的单词，别的答案也可以；但比如 *bit* 就不是 *pig* 的搭档，因为最后一个音也变了。
:::
:::

::: exercise 说出部位 {level=1}
发每个词的**第一个**音时，哪两个发音器官相接触或靠近？从这些中选择：双唇音、唇齿音、齿间音、齿龈音、软腭音、声门音。

*boy*（男孩），*think*（想），*king*（国王），*van*（厢式货车），*nose*（鼻子），*house*（房子）
::: solution
*boy* /b/——双唇音；*think* /θ/——齿间音；*king* /k/——软腭音；*van* /v/——唇齿音；*nose* /n/——齿龈音；*house* /h/——声门音。
:::
:::

::: exercise A 还是 an？ {level=2}
在每个词或短语前填 *a* 或 *an*，并说明是哪个**音**决定的。

1. ___ umbrella  2. ___ uniform  3. ___ hour  4. ___ horse  5. ___ one-hour meeting  6. ___ X-ray  7. ___ MP3 file
::: solution
1. *an umbrella*（一把伞）——元音 /ʌ/。
2. *a uniform*（一套制服）——辅音 /j/（/ˈjuːnɪfɔːm/，GA /ˈjuːnɪfɔːrm/）。
3. *an hour*（一小时）——元音 /aʊ/；*h* 不发音。
4. *a horse*（一匹马）——辅音 /h/。
5. *a one-hour meeting*（一个一小时的会议）——辅音 /w/（*one* 读 /wʌn/）。
6. *an X-ray*（一张X光片）——元音 /e/（字母 *X* 读 /eks/）。
7. *an MP3 file*（一个MP3文件）——元音 /e/（字母 *M* 读 /em/）。
:::
:::

::: exercise 描写这个音 {level=2}
给出每个词第一个音的清浊、部位和方法：*dog*（狗），*fan*（风扇），*shop*（商店），*net*（网）。
::: solution
- *dog* /d/：浊齿龈爆破音。
- *fan* /f/：清唇齿摩擦音。
- *shop* /ʃ/：清齿龈后摩擦音。
- *net* /n/：浊齿龈鼻音。
:::
:::

::: exercise 哪个不一样？ {level=2}
每组中有一个音的**部位**和其他几个不同。是哪一个？

1. /p/, /b/, /m/, /f/
2. /t/, /s/, /k/, /n/
3. /k/, /ɡ/, /ŋ/, /h/
::: solution
1. /f/——唇齿音；其他都是双唇音。
2. /k/——软腭音；其他都是齿龈音。
3. /h/——声门音；其他都是软腭音。
:::
:::

::: exercise 数一数浊音 {level=2 check="5"}
单词 *bands*（乐队，复数）读作 /bændz/。它有几个音？其中几个是浊音？请输入浊音的个数。
::: hint
数一数两条斜线之间的符号：每个符号是一个音。记住，正常说话时元音都是浊音，然后逐个检查辅音。
:::
::: solution
*bands* 有五个音：/b/、/æ/、/n/、/d/、/z/。这里五个字母各代表一个音，但要注意字母 *s* 代表的是 /z/ 音。五个音全是浊音：/b/ 和 /d/ 是浊爆破音，/n/ 是浊鼻音，/z/ 是浊摩擦音，/æ/ 是元音。答案是5。
:::
:::

::: exercise 解释一个错误 {level=3}
一位学习者想说 *vine*（葡萄藤）时说成了 *wine*（葡萄酒），想说 *vest*（背心）时说成了 *west*（西方）。用描写辅音的三个问题解释 /w/ 和 /v/ 的区别，并写出三条她可以照着做的简短指令，帮助她发出 /v/。
::: hint
比较这两个音的部位和方法。两者都是浊音。
:::
::: solution
/w/ 和 /v/ 都是浊音，所以问题不在清浊。它们的区别在**部位**和**方法**：
- /w/ 是唇–软腭音：双唇收圆，不碰牙齿；舌后部抬起。它是近音，所以没有摩擦噪音。
- /v/ 是唇齿音：上齿接触下唇。它是摩擦音，所以气流从窄缝里挤出，发出振动的噪音。

指令（类似的任何一组都对）：
1. 把上齿轻轻放在下唇内侧。不要圆唇。
2. 吹气，发出 /f/（*ffff*）。
3. 继续吹气并加上嗓音，让嘴唇有发麻的感觉：*vvvv*。然后接上元音：*vvv-ine*。

她可以对着镜子检查自己：发 /v/ 时应该能看到上齿放在下唇上；发 /w/ 时双唇成一个小圆圈。
:::
:::

::: exercise 口语任务：发音日记 {level=3}
选五个你觉得难读的英语单词。对每个词，写出这个词，找出其中最难的音，并用三个问题描写这个音（如果是元音，就用舌位高低、前后和圆唇与否）。然后把每个词慢慢地说五遍，每一遍检查一件事（比如“我的嘴唇碰到牙齿了吗？”）。
::: solution
答案因人而异。一条示范记录：

- *clothes*（衣服）——最难的音：词尾 /z/ 前面的 /ð/。/ð/ 是浊齿间摩擦音：舌尖轻放在上齿之间或上齿背后，气流从窄缝中通过，声带振动。检查1：我的舌头碰到牙齿了吗？检查2：我能感到振动吗？检查3：发结尾的 /z/ 时振动还在吗？

一条好的记录要正确说出是哪个音，给出全部三个标签，并把每个标签变成一件可以对着镜子或用手指检查的事。
:::
:::
