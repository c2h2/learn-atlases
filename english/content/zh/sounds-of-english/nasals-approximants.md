“I'm sinking about it,” 黄梅说。她的朋友纳闷：什么东西在下沉（*sinking*）？黄梅想说的是 *thinking*（在想），她做了两处小小的改动：开头的 /θ/ 变成了 /s/，结尾的 *ng* 变成了 /n/。第一种改动是[[sounds-of-english/stops-fricatives]]的内容。本章讲第二种，以及学英语的人常常觉得“滑溜溜”抓不住的其他几个音：鼻音 /m/、/n/、/ŋ/，两种 /l/，英语的 /r/，以及滑音 /w/ 和 /j/。

这七个音有一个共同点：气流自由地通过鼻腔或从舌头上流过，既没有摩擦音的噪音，也没有爆破音的爆发。它们都是浊音。而且它们是**在词中的位置**最为重要的辅音：/ŋ/ 永远不能位于词首，GB 只在元音前读 /r/，/l/ 在词尾会改变音色。

## 鼻音

::: definition 鼻音 {#def-nasal}
**鼻音**（nasal）是口腔完全闭合、软腭下垂、所有气流都从鼻腔出去而发出的辅音。英语有三个鼻音，都是浊音：双唇的 /m/（*map*（地图））、齿龈的 /n/（*nap*（小睡））和软腭的 /ŋ/（*sing*（唱））。
:::

三个鼻音的发音部位，恰好和三对爆破音的部位相同。唯一的区别在软腭：发爆破音时抬起，发鼻音时下垂。

nodes: lips@-3,2.6; alveolar ridge@0,2.6; soft palate@3,2.6; p b@-3,1.2; t d@0,1.2; k ɡ@3,1.2; m@-3,-0.2; n@0,-0.2; ŋ@3,-0.2
edges: lips-p b; alveolar ridge-t d; soft palate-k ɡ; p b-m; t d-n; k ɡ-ŋ
caption: 爆破音和鼻音共用发音部位。每一列是一个闭合部位：双唇（lips）、齿龈（alveolar ridge）、软腭（soft palate）。上面是爆破音（软腭抬起，气流被阻住）；下面是在同一部位发出的鼻音（软腭下垂，气流从鼻腔出去）。要找到 /ŋ/，先说 *k*，保持口腔后部的闭合，然后哼出声来。这些点可以拖动。
:::

### /m/ 和 /n/

/m/（双唇闭合）和 /n/（舌尖抵住齿龈）在音节开头时，对大多数学习者来说都不难。在词尾则需要注意：

- 词尾的 /m/ 和 /n/ 必须分开：*some*（一些）– *sun*（太阳），*team*（队）– *teen*（十几岁的少年），*home*（家）– *hone*（磨练），*Tim*（蒂姆，人名）– *tin*（锡）。发 /m/ 时双唇闭合；发 /n/ 时双唇张开，舌头抵在齿龈上。
- 词尾的鼻音要保持足够长的时间才能被听见，特别是在停顿之前。如果词尾鼻音只是元音上的一点鼻化色彩（像法语 *bon* 那样），可能就不会被听成一个辅音。

### /ŋ/

发 /ŋ/ 时，把舌后部抬起抵住软腭，就像发 /k/ 或 /ɡ/ 那样，让气流从鼻腔出去。舌尖留在下面，在下齿后面。

::: theorem /ŋ/ 能出现在哪里 {#rule-ng}
1. /ŋ/ **永远不在**英语单词或音节的开头。它只出现在元音之后：*sing*（唱），*long*（长的），*thank*（感谢），*finger*（手指）。
2. 它拼作 *ng*（*sing*，*young*（年轻的））或拼作 /k/、/ɡ/ 前的 *n*（*think*（想）/θɪŋk/，*uncle*（叔叔）/ˈʌŋkl/，*anger*（愤怒）/ˈæŋɡə/（GB））。
3. 在 GB 和 GA 里，**词尾**的 *ng* 读 /ŋ/，没有 /ɡ/：*sing* /sɪŋ/，*long* /lɒŋ/（GB）。给这个词加上词尾之后仍然如此：*singer*（歌手）/ˈsɪŋə/，*singing*（唱歌）/ˈsɪŋɪŋ/，*longing*（渴望）。
4. 一个不是由更短的词构成的词，**词中间**的 *ng* 通常读 /ŋɡ/：*finger* /ˈfɪŋɡə/，*English*（英语）/ˈɪŋɡlɪʃ/，*hungry*（饿的）/ˈhʌŋɡri/，*language*（语言）。比较级 *longer*（更长）、*stronger*（更强）、*younger*（更年轻）也读 /ŋɡ/。
:::

::: proof
在中古英语里，*ng* 总是读 /ŋɡ/。16到17世纪之间，词尾的 /ɡ/ 脱落了，由这些词构成的词也保留了新的读音（*sing* → *singer*）。不是这样构成的词，如 *finger*，保留了 /ɡ/。比较级是一个古老的例外。在英格兰西北部和中部地区，许多人至今仍在 *sing* 和 *singer* 里读出 /ŋɡ/——这再次提醒我们，GB 只是众多口音中的一种模式。所以第3、4两点是有历史来由的倾向，LPD 逐词列出了例外。
:::

::: example *Singer* 和 *finger* {#ex-ng}
写出下列词的音标（GB）：*thing*（东西），*thinking*（想），*finger*（手指），*singer*（歌手），*younger*（更年轻），*bank*（银行）。
::: solution
逐词运用[[#rule-ng]]：

1. *thing* /θɪŋ/：*ng* 在词尾——只读 /ŋ/。
2. *thinking* /ˈθɪŋkɪŋ/：/k/ 前的 *n* 读 /ŋ/；词尾的 *-ing* 读 /ɪŋ/。
3. *finger* /ˈfɪŋɡə/：*ng* 在一个不是由更短的词构成的词中间——读 /ŋɡ/。
4. *singer* /ˈsɪŋə/：*sing* + *-er*；保留 *sing* 的 /ŋ/，没有 /ɡ/。
5. *younger* /ˈjʌŋɡə/：比较级——读 /ŋɡ/（比较 *young* /jʌŋ/）。
6. *bank* /bæŋk/：/k/ 前的 *n* 读 /ŋ/。

在 GA 里，除了 *finger*、*singer*、*younger* 词尾读 /ər/ 以外，音标都相同。
:::
:::

::: warning 把词尾的 /n/ 和 /ŋ/ 分开
✗ 在仔细说话时把 *I'm thinking about it.*（我在考虑。）里的 *-ing* 读成 /n/，或者把 *thing* 读成 *thin*。
✓ *thin*（薄的）/θɪn/ – *thing*（东西）/θɪŋ/；*ran*（跑，过去式）/ræn/ – *rang*（响，过去式）/ræŋ/；*win*（赢）/wɪn/ – *wing*（翅膀）/wɪŋ/；*ton*（吨）/tʌn/ – *tongue*（舌头）/tʌŋ/；*kin*（亲属）/kɪn/ – *king*（国王）/kɪŋ/。

发 /n/ 时，舌**尖**抬到齿龈；发 /ŋ/ 时，舌尖留在下面，舌**后部**抬起。不要在 /ŋ/ 后面加 /ɡ/ 或 /k/（把 *thing* 读成 ✗ /θɪŋk/，听起来就像 *think*）。注意，许多母语者在非正式说话中确实把 *-ing* 读成 /ɪn/（*goin'*，*nothin'*）；这是语体特征，不是另一个词，但 *thin* 和 *thing* 仍然必须分开。
:::

### 成音节鼻音

在 /t/ 或 /d/ 之后，拼作 *-en*、*-on* 或 *-an* 的非重读音节常常不带任何元音：舌头为 /t/ 或 /d/ 停在齿龈上，气流从鼻腔释放出去。这时 /n/ 自己构成一个音节，写作 /n̩/，或者在 LPD 里只写 /n/、前面不写元音：*button*（纽扣）/ˈbʌtn/，*garden*（花园）/ˈɡɑːdn/（GB），*sudden*（突然的）/ˈsʌdn/，*written*（写，过去分词）/ˈrɪtn/。/l/ 也可以这样成音节：*little*（小的）/ˈlɪtl/，*middle*（中间）/ˈmɪdl/。

## /l/：边音

::: definition 边近音 {#def-lateral}
发英语的 /l/ 时，舌尖接触齿龈，和发 /t/、/n/ 一样，但舌的两侧放低，气流从一侧或两侧流出。它是浊音，没有摩擦：一个**边近音**（lateral approximant）。
:::

英语有两种主要的 /l/，它们是同一个音位的音位变体（[[sounds-of-english/phonemic-alphabet#def-phoneme]]）。

::: theorem 清晰 /l/ 和含糊 /l/ {#rule-dark-l}
在 GB 里，/l/ 在元音或 /j/ 前是**清晰的** [l]（clear l）：*light*（光），*leaf*（叶子），*alive*（活着的），*value*（价值）。在词尾和辅音前是**含糊的** [ɫ]（dark l）：*feel*（感觉），*bell*（铃），*milk*（牛奶），*help*（帮助），*table*（桌子）。发含糊 /l/ 时，舌后部还要向软腭抬起，使 /l/ 带上一种像 *oo* 的色彩。在 GA 里，/l/ 在所有位置上都相当含糊。
:::

::: proof
在 *leaf* [liːf] 和 *feel* [fiːɫ]、*lip*（嘴唇）和 *pill*（药片）这样的词对中可以听出这种对比。两种音从不改变词义——*feel* 末尾用清晰的 /l/，意思仍然是 *feel*——所以它们是音位变体。但如果学习者丢掉含糊的 /l/，或者用一个元音来代替它，词就变了：*feel* 变成 *fee*（费用），*bell* 变成 *bay*（海湾）或 *bear*（熊），*milk* 变成类似 *miuk* 的音。在伦敦和英格兰东南部的许多口音里，含糊的 /l/ 本身变成了一个像 [ʊ] 的元音（“*l* 元音化”：*milk* [mɪʊk]）；这在口语中很常见，但 GB 和 GA 模式都保留辅音。
:::

要发好含糊的 /l/：慢慢地说 *feel*，在结尾让舌尖保持在齿龈上。你应该能够把 /l/ 延长——*feeeelllll*——并且始终感觉到舌尖抵着齿龈。

::: example 清晰还是含糊？ {#ex-l}
在 GB 里，下列每个词中的 /l/ 哪个是清晰的、哪个是含糊的？*little*（小的），*lily*（百合），*please*（请），*world*（世界），*usually*（通常）。
::: solution
运用[[#rule-dark-l]]：元音前清晰；词尾或辅音前含糊。

1. *little* /ˈlɪtl/：第一个 /l/ 在元音前——清晰；第二个是词尾的成音节 /l/——含糊。
2. *lily* /ˈlɪli/：两个都在元音前——清晰。
3. *please* /pliːz/：在元音前——清晰（并且在送气的 /p/ 之后部分清化）。
4. *world* GB /wɜːld/，GA /wɜːrld/：在 /d/ 前——含糊。
5. *usually* /ˈjuːʒuəli/ 或 /ˈjuːʒəli/：在元音前——清晰。
:::
:::

## /r/

::: definition 英语的 /r/ {#def-r}
GB 和 GA 中英语的 /r/ 是一个**齿龈后近音**，语音学家写作 [ɹ]。舌尖向齿龈后部抬起，但**不接触**它（许多人则是把舌体向上、向后隆起）；双唇略圆；舌的两侧贴着上面靠后的牙齿；没有摩擦，没有闪弹，也没有颤动。它是浊音。
:::

::: theorem /r/ 在哪里读出来 {#rule-r}
1. 在 GB 和 GA 里，/r/ 在元音前都要读出来：*red*（红色），*very*（非常），*story*（故事），*tree*（树）。
2. 在 GA（卷舌口音）里，元音之后——词尾或辅音前——的 /r/ 也要读出来：*car* /kɑːr/，*hard* /hɑːrd/，*teacher* /ˈtiːtʃər/。
3. 在 GB（非卷舌口音）里，元音后的书写 *r* **不**读出来，除非后面跟着元音：*car* /kɑː/，*hard* /hɑːd/。如果下一个词以元音开头，就读出 /r/ 把两个词连起来：*far away*（遥远）/ˌfɑːr əˈweɪ/，*for ever*（永远）。这叫**连接 r**（linking r）。
4. 许多说 GB 的人还会在两个元音之间插入一个拼写里没有的 /r/，出现在 /ə/、/ɑː/ 或 /ɔː/ 之后：*the idea of it*（那个想法）/ði aɪˈdɪər əv ɪt/，*law and order*（法律与秩序）。这种**插入 r**（intrusive r）在自然的 GB 口语中非常常见，尽管有些人不喜欢它。
:::

::: proof
第2、3条就是[[sounds-of-english/phonemic-alphabet#rule-rhotic]]所说的卷舌差别。连接 /r/ 和插入 /r/ 表明，GB 的 /r/ 并没有简单地消失：说话人现在把它当作一个出现在元音之间的音。插入 /r/ 恰好出现在拼写里如果有 *r* 就会出现连接 /r/ 的地方（对这些说话人来说，*idea of* 和 *ear of* 押韵），所以它是这个系统的自然延伸，而不是马虎。更多例子见[[connected-speech/linking]]。
:::

### /l/ 还是 /r/？

/l/ 和 /r/ 都是在齿龈附近发出的浊近音，所以母语不区分这两个音的学习者（说日语和韩语的人，以及说某些汉语方言的人）可能觉得它们很难。区别在于：发 /l/ 时舌尖**接触**齿龈，气流从两侧流出；发 /r/ 时舌尖**不接触**任何地方，双唇收圆。

**音对：** *light*（光）– *right*（右；对的），*long*（长的）– *wrong*（错的），*lead*（带领）– *read*（读），*glass*（玻璃）– *grass*（草），*fly*（飞）– *fry*（油炸），*collect*（收集）– *correct*（改正），*clown*（小丑）– *crown*（王冠），*alive*（活着的）– *arrive*（到达）。

- *Turn right at the lights.*（在红绿灯处右转。）
- *Is this the right answer, or the wrong one?*（这是正确答案，还是错误答案？）
- *Please collect the tests and correct them.*（请把试卷收上来批改一下。）

::: example 跟着舌尖走 {#ex-lr}
读 *Laura left her red gloves on the rail.*（劳拉把她的红手套落在栏杆上了。）找出每个 /l/ 和 /r/，说出舌尖是否接触齿龈，并说出在 GB 里哪些 /r/ 要读出来。
::: solution
先写出音标：GB /ˈlɔːrə left hə red ɡlʌvz ɒn ðə reɪl/。

- *Laura*：开头的 /l/——舌尖接触，清晰 /l/。*r* 在元音前——读出 /r/，舌尖不接触。
- *left*：/l/ 在元音前——舌尖接触，清晰。
- *her*：在 GB 里 *r* 不读，因为后面跟的是辅音（*red* 的 *r*）；在 GA 里是 /hər/（弱读式）。
- *red*：/r/ 在元音前——读出来，双唇略圆。
- *gloves*：/ɡl/——/l/ 在元音前，所以清晰；/ɡ/ 闭合之后舌尖紧接着接触齿龈。
- *rail*：开头是 /r/（不接触），结尾是含糊的 /l/（舌尖接触，舌后部抬起）。

这个句子在“接触”和“不接触”之间交替。对着镜子慢慢说，你应该看到每个 /l/ 时舌尖抬起，每个 /r/ 时双唇收圆。
:::
:::

::: quiz
发哪个音时舌尖**不**接触口腔顶部？
- [ ] /l/ in *light*
- [ ] /n/ in *night*
- [x] /r/ in *right*
- [ ] /t/ in *tight*
::: solution
发 /r/ 时，舌尖向齿龈后部抬起但不接触（或者舌体隆起），所以气流自由流过。发 /l/、/n/ 和 /t/ 时舌尖都接触齿龈：/t/ 阻住气流，/n/ 把气流送进鼻腔，/l/ 让气流从两侧流出。
:::
:::

## /w/ 和 /j/：滑音

::: definition 滑音 {#def-glides}
/w/ 和 /j/ 是**滑音**（glides，又称半元音）：从一个类似元音的位置出发、迅速滑入后面元音的近音。发 /w/ 时，双唇收圆，舌后部抬起，就像发 /uː/ 一样（*wet*（湿的），*away*（离开））。发 /j/ 时，舌前部向硬腭抬起，就像发 /iː/ 一样（*yes*（是），*beyond*（超出））。它们总是出现在元音前。
:::

对学习者来说，最难的情形是滑音位于和它相似的元音之前：

- /w/ 在 /uː/ 或 /ʊ/ 前：*woo*（求爱），*wood*（木头），*would*（将会），*woman*（女人），*wool*（羊毛），*wolf*（狼）。开始时双唇必须比发元音时收得**更圆**，然后稍稍张开：*wood* /wʊd/ 不是 *ood*。
- /j/ 在 /iː/ 或 /ɪ/ 前：*year*（年），*yeast*（酵母），*yield*（产出），*yes*。开始时舌头必须比发元音时抬得**更高**：*year* /jɪə/（GB），/jɪr/（GA）不是 *ear*（耳朵）；*yeast* 不是 *east*（东方）。

**音对：** *year*（年）– *ear*（耳朵），*yeast*（酵母）– *east*（东方），*Yale*（耶鲁）– *ale*（麦芽酒），*wood*（木头）– *could*（能够）（元音相同，第一个音不同），*woo*（求爱）– *ooh*（哦）。

GB 和大多数 GA 的说话人把 *which*（哪个）和 *witch*（女巫）、*where*（哪里）和 *wear*（穿）、*whale*（鲸）和 *Wales*（威尔士）读得一样，都用 /w/。苏格兰、爱尔兰和美国部分地区的一些人给 *wh* 保留一个清音 [ʍ]；LPD 等词典把它列为一种可选读法。

::: example *Ear* 还是 *year*？ {#ex-glides}
黄梅说 *I studied English for one ear*（意思是：我学了一年英语），还说 *I'd like a wooden toy*（我想要一个木头玩具），但把 *wooden* 说成了 *ooden*。她应该改什么？
::: solution
1. *year*：她漏掉了 /j/。开始时让舌前部非常靠近硬腭——比发元音时更近——然后滑入元音：/jɪə/（GB），/jɪr/（GA）。没有 /j/，这个词就成了 *ear*，头上的一个部位。
2. *wooden*（木制的）/ˈwʊdn/：她漏掉了 /w/。开始时双唇紧紧收圆并向前突出，然后稍稍放松，进入 /ʊ/。一个有用的练习：连着说 *we*、*woo*、*wood*，每个词开头都保持同样有力的圆唇。

这两个错误都来自拼音习惯：拼音里写作 *yi* 和 *wu* 的音节读 [i] 和 [u]，元音前没有单独的滑音。
:::
:::

::: quiz
哪个词以**辅音**开头？
- [ ] *hour*
- [ ] *ear*
- [x] *year*
- [ ] *honest*
::: solution
*Year*（年）以滑音 /j/ 开头，这是一个辅音。*Hour*（小时）和 *honest*（诚实的）以元音开头，因为 *h* 不发音；*ear*（耳朵）以元音 /ɪə/（GB）开头。所以我们说 *a year*，但说 *an hour*、*an ear* 和 *an honest answer*（一个诚实的回答）。
:::
:::

## 商店里的对话

**Huang Mei:** *Hello. I'm looking for a long wool scarf. Something warm.*（你好。我想找一条长的羊毛围巾。暖和一点的。）

**Assistant:** *We've got a lovely one in yellow. Would you like to see it?*（我们有一条很漂亮的黄色的。您想看看吗？）

**Huang Mei:** *Yes, please. Oh, it's really soft. Is there a larger one?*（好的，谢谢。哦，真软。有大一点的吗？）

**Assistant:** *That's the longest we have, I'm afraid. We'll have more in the winter.*（恐怕这已经是最长的了。冬天会有更多货。）

**Huang Mei:** *All right, I'll take it. Can I pay with my phone?*（好吧，我买了。可以用手机付款吗？）

**Assistant:** *Of course. Would you like a bag?*（当然可以。需要袋子吗？）

**Huang Mei:** *No, thanks. I'll wear it now. It's cold outside!*（不用了，谢谢。我现在就戴上。外面很冷！）

注意听：*looking*、*long*、*something*、*longest* 里的 /ŋ/；*looking*、*lovely*、*larger*、*yellow* 里清晰的 /l/，*wool*、*all*、*I'll*、*we'll*、*cold* 里含糊的 /l/；*really*、*right* 里的 /r/（在 GA 里还有 *larger*、*more*、*winter*、*wear* 里的 /r/）；*wool*、*we've*、*would*、*we'll*、*winter*、*wear* 里的 /w/；*yellow*、*yes* 里的 /j/。

::: note 英汉对比
- **词尾鼻音。** 标准普通话的音节可以以 *-n* 和 *-ng* 结尾，所以英语词尾的 /n/ 和 /ŋ/ 并不陌生。但许多南方方言以及上海话等吴语的使用者，在自己的方言里不区分 *-in* 和 *-ing*、*-en* 和 *-eng*，可能会觉得 *thin – thing* 或 *ran – rang* 很难。标准普通话没有词尾的 *-m*：说普通话的人有时把 *some* 说得像 *sun*，把 *time* 说得像 *tine*。说粤语和客家话的人有词尾 *-m*，通常觉得很容易。
- **词首的 /ŋ/。** 有些汉语方言允许 *ng* 出现在音节开头（粤语“我” *ngo*），但英语从不允许；这主要和名字有关。
- **/l/ 和 /n/。** 在中国西南和南方的许多方言里——例如四川、重庆、湖南和湖北的大部分地区——*n* 和 *l* 不是两个独立的音位，说这些方言的人可能把 *night*（夜晚）和 *light*（光）、*no*（不）和 *low*（低的）读得一样。许多较年轻的香港粤语使用者也把 *n* 读成 *l*。最后一章提供了练习（[[sounds-of-english/sounds-for-chinese-speakers]]）。
- **词尾的 /l/。** 普通话没有词尾的 /l/（“儿”的词尾 *-r* 是另一回事）。学习者往往丢掉含糊的 /l/，或者在它后面加一个元音（*feel* → *fee*、*feel-o*）。在词尾要让舌尖保持在齿龈上。
- **拼音的 *r* 不是英语的 /r/。** 拼音的 *r*（如“人、热”）是舌尖后卷、带一点摩擦、双唇展开发出的。英语的 /r/ 没有摩擦，双唇收圆。从英语的 /w/ 出发、把舌尖稍稍抬起，是找到它的好办法。
- **滑音。** 拼音的 *yi*、*ying*、*wu* 没有单独的滑音，这就是为什么 *year* 可能听起来像 *ear*，*wood* 像 *ood*。
:::

::: history
字母 *ng* 曾经在所有位置上都表示两个音 /ŋɡ/，就像今天 *finger* 里那样；词尾的 /ɡ/ 在16、17世纪脱落了（见[[#rule-ng]]）。把 *-ing* 读成 /ɪn/ 的读法也很古老：18世纪，*-in'* 在英格兰的上流时髦人士中很常见，后来按拼写读出的 /ɪŋ/ 才成为有声望的形式。英格兰东南部元音后 /r/ 的脱落——它造就了非卷舌的 GB——主要发生在18世纪；美式英语以及苏格兰、爱尔兰和英格兰西南部的口音保留了它。
:::

## 后续内容

现在你已经学完了全部24个辅音和所有元音。[[sounds-of-english/syllables-clusters]]说明它们怎样组合成音节，包括含 /l/、/r/、/w/、/j/ 的连缀（*play*（玩），*three*（三），*twelve*（十二），*music*（音乐））以及 *-nths*、*-lts* 这样的词尾。连接 /r/、插入 /r/ 以及快速说话中的省音在[[connected-speech/linking]]中讲解。中国学习者在 /n/、/l/、/r/、/v/、/w/ 上的具体困难集中在[[sounds-of-english/sounds-for-chinese-speakers]]中讨论。

::: summary
- 鼻音 /m n ŋ/ 和 /p b/、/t d/、/k ɡ/ 在相同的部位发出，只是软腭下垂（[[#def-nasal]]）。
- /ŋ/ 永远不在词首；词尾的 *ng*（以及 *singer* 里的）读 /ŋ/，不带 /ɡ/，但 *finger*、*English*、*longer* 里读 /ŋɡ/（[[#rule-ng]]）。
- 把词尾的 /m/、/n/、/ŋ/ 分开：*some – sun*，*thin – thing*。
- /l/ 是边近音（[[#def-lateral]]）；在 GB 里，它在元音前清晰，在词尾和辅音前含糊（[[#rule-dark-l]]）。不要丢掉词尾的 /l/。
- 英语的 /r/ 是一个没有摩擦的近音，舌尖抬起但不接触，双唇收圆（[[#def-r]]）。GA 读出每一个书写的 *r*；GB 只在元音前读，并有连接 /r/ 和插入 /r/（[[#rule-r]]）。
- /l/ 和 /r/：发 /l/ 时舌尖接触，发 /r/ 时不接触：*light – right*，*collect – correct*。
- 滑音 /w/ 和 /j/ 的起点比后面的元音更“闭”：*wood* 不是 *ood*，*year* 不是 *ear*（[[#def-glides]]）。
:::

## 习题

::: exercise /n/ 还是 /ŋ/？ {level=1}
每个词以 /n/ 还是 /ŋ/ 结尾？

*thin*（薄的），*thing*（东西），*sun*（太阳），*song*（歌），*ran*（跑，过去式），*rang*（响，过去式），*wing*（翅膀），*win*（赢）
::: solution
/n/：*thin*，*sun*，*ran*，*win*。/ŋ/：*thing*，*song*，*rang*，*wing*。
:::
:::

::: exercise 清晰还是含糊的 /l/（GB）？ {level=1}
在 GB 里，每个词中的 /l/ 是清晰的还是含糊的？

*lemon*（柠檬），*ball*（球），*film*（电影），*glass*（玻璃），*table*（桌子），*yellow*（黄色）
::: solution
清晰（在元音前）：*lemon*，*glass*，*yellow*。含糊（在词尾或辅音前）：*ball*，*film*，*table*。
:::
:::

::: exercise *r* 读不读？ {level=1}
在 GB 里，每个短语中的书写 *r* 读不读出来？（只回答第一个词里的 *r*。）

1. *car park*（停车场）  2. *car alarm*（汽车警报器）  3. *for me*（为我）  4. *for us*（为我们）  5. *very*（非常）  6. *teacher*（老师）
::: solution
1. 不读——后面跟着辅音。2. 读——在 *alarm* 的元音前读连接 /r/。3. 不读。4. 读——连接 /r/（*for* 弱读或强读都是）。5. 读——在词中元音前读 /r/。6. 不读——在词尾、停顿之前。（在 GA 里，这六个都读出来。）
:::
:::

::: exercise 写音标 {level=2}
用 GB 和 GA 写出音标：*strong*（强的），*stronger*（更强的），*wrong*（错的），*long*（长的），*yellow*（黄色）。
::: solution
- *strong*：GB /strɒŋ/，GA /strɔːŋ/。
- *stronger*：GB /ˈstrɒŋɡə/，GA /ˈstrɔːŋɡər/——比较级，所以读 /ŋɡ/。
- *wrong*：GB /rɒŋ/，GA /rɔːŋ/——*w* 不发音。
- *long*：GB /lɒŋ/，GA /lɔːŋ/。
- *yellow*：GB /ˈjeləʊ/，GA /ˈjeloʊ/。
:::
:::

::: exercise 改正这个词 {level=2}
每个句子里都有一个用错的词，原因是 /l/–/r/、/n/–/ŋ/ 或滑音方面的错误。写出原本想说的词。

1. *Turn light at the corner.*（意思是：在拐角处右转。）
2. *I've lived here for three ears.*（意思是：我在这里住了三年。）
3. *She can't stop sinking about the exam.*（意思是：她忍不住一直想着考试。）
4. *Please collect my spelling mistakes.*（意思是：请改正我的拼写错误。）
5. *He plays the violin in a band — he's a good sinner.*（意思是：他在乐队里拉小提琴——他还是个好歌手。）
::: solution
1. *light* → *right*（右）（用 /l/ 代替了 /r/）。
2. *ears* → *years*（年）（漏掉了 /j/）。
3. *sinking* → *thinking*（想）（用 /s/ 代替了 /θ/——这是[[sounds-of-english/stops-fricatives]]的问题；这里词尾的 /ŋ/ 是对的）。
4. *collect* → *correct*（改正）（用 /l/ 代替了 /r/）。
5. *sinner*（罪人）→ *singer*（歌手）（用 /n/ 代替了 /ŋ/）。
:::
:::

::: exercise 数鼻音 {level=2 check="4"}
*morning*（早晨）里有几个鼻音？（用 GB 音标 /ˈmɔːnɪŋ/。）再加上 *sing*（唱）里的鼻音。输入总数。
::: solution
*morning* /ˈmɔːnɪŋ/ 有三个：/m/、/n/、/ŋ/。*sing* /sɪŋ/ 有一个：/ŋ/（没有 /ɡ/）。总数是4。
:::
:::

::: exercise 解释一条规则 {level=3}
一位学习者问：“为什么 *singer* 不读 /ɡ/，而 *finger* 读 /ɡ/，两个词不都拼作 *-nger* 吗？”为她写一段简短的解释（三四句话），每一类再举两个例子。
::: hint
这个词是由一个以 *ng* 结尾的更短的词构成的吗？
:::
::: solution
参考答案：“*Singer* 是 *sing* + *-er*。在词尾，*ng* 只读 /ŋ/，加上词尾时我们保留那个较短词的读音：*sing* /sɪŋ/，*singer* /ˈsɪŋə/。*Finger* 不是由一个叫 *fing* 的词构成的，所以 *ng* 在词的内部，在那里通常读 /ŋɡ/。和 *singer* 一类的词：*hanger*（衣架），*ringing*（响）。和 *finger* 一类的词：*anger*（愤怒），*hungry*（饿的）。要注意 *longer*、*stronger* 和 *younger*：它们由 *long*、*strong* 和 *young* 构成，但作为比较级，它们读 /ŋɡ/。”
:::
:::

::: exercise 在语境中练习 {level=3}
给朋友写一条短消息（40–60词），讲一次长途旅行，至少用四个含 /ŋ/ 的词、四个含 /l/ 的词（有清晰的，也有含糊的）和四个含 /r/ 的词。大声朗读并录音，逐一检查这些音。
::: solution
答案因人而异。一个范例：

> *Hi Lily! The train was really long — nearly eleven hours. I spent the morning reading and the evening looking at the hills. I'm feeling tired, but well. I'll ring you tomorrow after I've slept. Hope everything's all right with you!*

**译文：**嗨，莉莉！火车坐得真久——将近十一个小时。我上午看书，傍晚看山。我觉得有点累，但挺好的。等我睡一觉，明天给你打电话。希望你一切都好！

- /ŋ/：*long*，*morning*，*reading*，*evening*，*looking*，*feeling*，*ring*，*everything*。
- 清晰 /l/（在元音前）：*Lily*（两个），*really*，*eleven*，*looking*，*feeling*，*slept*。
- 含糊 /l/（在词尾或辅音前）：*hills*，*well*，*I'll*，*all*。
- GB 里的 /r/（在元音前）：*train*，*really*，*reading*，*ring*，*tomorrow*，*everything*，*right*。在 GA 里还有 *nearly*、*hours*、*after*、*tired*；GB 的 *tired* 读 /ˈtaɪəd/，没有 /r/。
:::
:::
