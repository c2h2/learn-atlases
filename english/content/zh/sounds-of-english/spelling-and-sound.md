大声读这两个句子：*I read a book every evening.*（我每天晚上读一本书。）*Yesterday I read a book about Mars.*（昨天我读了一本关于火星的书。）*read* 这个词在两句里拼写相同，在第一句里读 /riːd/，在第二句里读 /red/。再看 *hoping*（希望）和 *hopping*（单脚跳），*diner*（用餐者）和 *dinner*（晚餐）：多一个字母，元音就不同了。英语拼写不是一套简单的语音密码——但也不是一团乱麻。大多数词都遵循一定的规律，这些规律是可以学会的。难的词大多是非常常用的词，你会频繁地遇到它们，可以一个一个地记住。

本章介绍主要的规律：辅音字母怎样读，双写辅音和“不发音的 *e*”告诉你元音的什么信息，最常见的元音拼写，不发音字母，以及词尾 *-s* 和 *-ed*。最后讲述那段历史，解释为什么那么多日常词不守这些规律。本章使用[[sounds-of-english/phonemic-alphabet]]的符号和[[sounds-of-english/syllables-clusters]]的音节知识。

## 字母与读音

英语有26个字母，而 GB 有44个音位。所以有些音位必须用字母组合来书写，有些字母必须代表不止一个音。

::: definition 字位 {#def-grapheme}
**字位**（grapheme）是在一个词中代表一个音位的一个字母或一组字母。*ship*（船）/ʃɪp/ 里有三个字位：*sh*、*i*、*p*。*night*（夜晚）/naɪt/ 里有三个：*n*、*igh*、*t*。代表一个音的两个字母（*sh*、*ee*、*ck*）叫作**二合字母**（digraph）；三个字母（*igh*、*tch*、*dge*）叫作**三合字母**（trigraph）。
:::

这种关系是双向的。一个音位可以有多种拼法：下图显示 /iː/ 的主要拼法。一个字位也可以有几种读音：*ea* 在 *meat*（肉）里读 /iː/，在 *bread*（面包）里读 /e/，在 *great*（伟大的）里读 /eɪ/（[[sounds-of-english/long-vowels-diphthongs#ex-ea]]）。

::: widget graph
nodes: /iː/@0,2; ee@-3.5,0; ea@-2.5,-1; e@-1.5,0; ie@-0.5,-1; ei@0.5,0; i@1.5,-1; ey@2.5,0; eo@3.5,-1
edges: /iː/>ee; /iː/>ea; /iː/>e; /iː/>ie; /iː/>ei; /iː/>i; /iː/>ey; /iː/>eo
caption: 一个音，多种拼法：FLEECE 元音 /iː/ 可以写作 *ee*（*see* 看见）、*ea*（*eat* 吃）、*e*（*he* 他，*these* 这些）、*ie*（*field* 田野）、*ei*（*receive* 收到）、*i*（*police* 警察）、*ey*（*key* 钥匙）和 *eo*（*people* 人们）。前三种最常见；其余的只出现在少数词里，最后一种只出现在一个常用词里。英语的大多数元音都有类似的一把“扇子”似的拼法。
:::

## 辅音字母

大多数辅音字母只有一个主要读音，就是音标表里的读音：*b* /b/，*d* /d/，*f* /f/，*m* /m/，等等。主要的例外都有规律可循。

::: theorem 软音和硬音 *c*、*g* {#rule-c-g}
1. *c* 在 *e*、*i*、*y* 前读“软音” /s/（*cent*（分），*city*（城市），*cycle*（循环），*place*（地方）），在其他位置读“硬音” /k/（*cat*（猫），*cold*（冷的），*cut*（切），*class*（班级），*music*（音乐））。
2. *g* 在 *a*、*o*、*u*、辅音前或词尾通常读“硬音” /ɡ/（*game*（游戏），*go*（去），*gun*（枪），*glass*（玻璃），*bag*（包））。在 *e*、*i*、*y* 前常常读“软音” /dʒ/（*gem*（宝石），*giant*（巨人），*gym*（体育馆），*age*（年龄），*page*（页）），但也有许多读 /ɡ/ 的常用例外：*get*（得到），*give*（给），*girl*（女孩），*gift*（礼物），*begin*（开始），*together*（一起），*tiger*（老虎）。
3. 为了让 *e* 或 *i* 前的 *g* 保持硬音，英语有时加一个 *u*：*guess*（猜），*guide*（向导），*guitar*（吉他）。为了在 *a* 或 *o* 前表示软音的 *g* 或 *c*，就保留一个不发音的 *e*：*changeable*（易变的），*noticeable*（显而易见的）。
:::

::: proof
*c* 的规则非常可靠；*g* 的规则只是一种倾向。原因在于历史。软音主要是随着法语词和拉丁语词进入英语的（*city*，*gem*），而许多英语本族词在 *e* 和 *i* 前保留了硬音 *g*（*get*，*give*，*begin*），有时还受到古诺尔斯语的影响。所以遇到 *e*、*i*、*y* 前的 *g*，如果是新词，就查一下词典。
:::

### 双写辅音告诉你什么

::: theorem 双写辅音与短元音 {#rule-double}
在重读音节里，单个元音字母后面的**双写**辅音字母（或 *ck*、*tch*、*dge*）通常表示这个元音是**短**的；单个辅音字母后面再跟一个元音字母，通常表示它是**长**的（长元音或双元音）：

| 短元音 | 长元音 |
|---|---|
| *hopping*（单脚跳）/ˈhɒpɪŋ/（GB） | *hoping*（希望）/ˈhəʊpɪŋ/（GB） |
| *dinner*（晚餐）/ˈdɪnə/ | *diner*（用餐者）/ˈdaɪnə/ |
| *latter*（后者）/ˈlætə/ | *later*（后来）/ˈleɪtə/ |
| *filling*（填充物）/ˈfɪlɪŋ/ | *filing*（归档）/ˈfaɪlɪŋ/ |
| *back*（背），*catch*（抓住），*badge*（徽章） | *bake*（烘焙），*coach*（教练），*page*（页） |

双写的辅音读作**一个**辅音：*dinner* 里只有一个 /n/。
:::

::: proof
双写字母是一种拼写手段，而不是一个音：它使重读音节闭合，从而表示一个短（“受阻”）元音（[[sounds-of-english/short-vowels#rule-checked]]）。这正是加词尾时那条熟悉的拼写规则的来由：*hop* + *-ing* → *hopping*（双写辅音，保持元音短），而 *hope* + *-ing* → *hoping*（去掉 *e*；单个辅音保持元音长）。两个方向上都有例外——*very*（非常）、*many*（许多）、*body*（身体）、*city*（城市）和 *river*（河）在单个辅音前是短元音——所以这条规则用来读带词尾的词（*-ing*、*-er*、*-ed*）很可靠，用于其他词则不那么可靠。加词尾时的拼写变化在[[word-formation/spelling-changes]]中讲解。
:::

## 元音字母

五个元音字母各有一个“短”读音和一个“长”读音。长读音通常就是这个字母的**名称**。

| 字母 | 名称 / 长读音 | 短读音 |
|---|---|---|
| *a* | /eɪ/ *name*（名字），*late*（迟的） | /æ/ *cat*（猫），*hat*（帽子） |
| *e* | /iː/ *these*（这些），*Pete*（皮特） | /e/ *bed*（床），*pet*（宠物） |
| *i*（以及 *y*） | /aɪ/ *time*（时间），*bite*（咬），*my*（我的） | /ɪ/ *sit*（坐），*bit*（一点儿），*gym*（体育馆） |
| *o* | /əʊ/（GA /oʊ/）*home*（家），*hope*（希望） | /ɒ/（GA /ɑː/）*hot*（热的），*hop*（单脚跳） |
| *u* | /juː/ *cute*（可爱的），*tube*（管子）；/uː/ *rule*（规则） | /ʌ/ *cut*（切），*tub*（浴缸）；/ʊ/ *put*（放） |

::: theorem 不发音的 *e* {#rule-silent-e}
单个辅音字母后的词尾 *e* 通常不发音，它表示这个辅音前的元音字母读长音（“名称”音）：*hat*（帽子）/hæt/ – *hate*（恨）/heɪt/；*pet*（宠物）– *Pete*（皮特）；*bit*（一点儿）– *bite*（咬）；*hop*（单脚跳）– *hope*（希望）；*cut*（切）– *cute*（可爱的）。在较长的词里，它在重读音节中起同样的作用：*mistake*（错误），*complete*（完成），*arrive*（到达），*alone*（独自）。
:::

::: proof
词尾的 *e* 曾经是要读出来的；在中古英语里，*name* 有两个音节。在14、15世纪词尾元音脱落时，它前面的长元音仍然保持长音，而 *e* 作为这一标志留在了拼写里。后来书写者又类推着给其他词加上了 *e*。有几个非常常用的词不守这个规律，因为它们的元音后来变短了或发生了其他变化：*have*（有），*give*（给），*live*（居住，动词），*come*（来），*some*（一些），*done*（做，过去分词），*love*（爱），*gone*（去，过去分词），*one*（一），*were*（是，过去式），*there*（那里）。不发音的 *e* 还有别的用途：它让 *c* 和 *g* 保持软音（*dance*（跳舞），*large*（大的）），还让词不以 *v* 或 *u* 结尾（*have*，*blue*（蓝色）），这是英语拼写所避免的。
:::

::: quiz
哪个词**不**遵循“不发音的 *e*”这一规律？
- [ ] *same*
- [ ] *note*
- [x] *come*
- [ ] *wide*
::: solution
在 *same*（相同的）/seɪm/、*note*（笔记）/nəʊt/（GB）和 *wide*（宽的）/waɪd/ 里，词尾的 *e* 使元音变长。*Come*（来）/kʌm/ 是短的 STRUT 元音，尽管它的拼写和 *home* 相像。它是常见的例外之一（还有 *some*、*done*、*love*、*have*、*give*）。
:::
:::

### 元音 + *r*

元音字母后面跟 *r* 时，通常有一个不同于上述长短读音的读音：

| 拼写 | GB | GA | 例词 |
|---|---|---|---|
| *ar* | /ɑː/ | /ɑːr/ | *car*（汽车），*hard*（硬的），*start*（开始） |
| *er*，*ir*，*ur* | /ɜː/ | /ɜːr/ | *her*（她），*bird*（鸟），*turn*（转） |
| *or* | /ɔː/ | /ɔːr/ | *for*（为了），*short*（短的），*born*（出生的） |
| *are*，*air* | /eə/ | /er/ | *care*（关心），*hair*（头发） |
| *ere*，*eer*，*ear* | /ɪə/ | /ɪr/ | *here*（这里），*beer*（啤酒），*near*（近的） |
| *ire* | /aɪə/ | /aɪr/ | *fire*（火），*hire*（雇用） |
| *ore*，*oar*，*oor* | /ɔː/ | /ɔːr/ | *more*（更多），*board*（板），*door*（门） |
| *ure* | /jʊə/，/jɔː/ | /jʊr/ | *pure*（纯的），*cure*（治愈） |

当 *r* 后面在同一个词里又跟着一个元音时，短读音常常又回来了：*carry*（携带），*very*（非常），*sorry*（抱歉的），*hurry*（匆忙）（GB /ˈhʌri/）。

::: example 预测新词的读音 {#ex-predict}
你第一次遇到这些词：*mope*（闷闷不乐），*glitch*（小故障），*strand*（一缕），*flaw*（缺陷），*sleet*（雨夹雪），*pounce*（猛扑）。用这些规律预测它们的读音，并说明你有多大把握。
::: solution
1. *mope*：*o* + 辅音 + 不发音的 *e* → 长音 /əʊ/（[[#rule-silent-e]]）：/məʊp/（GB），/moʊp/（GA）。很可能对。
2. *glitch*：*i* 后面的 *tch* → 短音 /ɪ/ 和 /tʃ/：/ɡlɪtʃ/。很可能对。
3. *strand*：*a* 在连缀前，没有词尾 *e* → 短音 /æ/：/strænd/。很可能对（GB 在这里不用 /ɑː/）。
4. *flaw*：*aw* → /ɔː/：/flɔː/。很可能对。
5. *sleet*：*ee* → /iː/：/sliːt/。几乎肯定对：*ee* 非常有规律。
6. *pounce*：*ou* → 通常读 /aʊ/；*ce* → 软音 /s/，*e* 不发音：/paʊns/。可能对，但 *ou* 还有别的读音（*touch*，*soup*），所以查一下词典比较稳妥。

这六个预测实际上都是对的。规律对这类词——不太常用的单音节词——最管用。最常用的词（*one*、*two*、*have*、*does*）反而最不规则。
:::
:::

## 不发音字母

::: theorem 常见的不发音字母 {#rule-silent}
下列字母在所示的模式中不发音：

| 模式 | 例词 |
|---|---|
| 词首的 *kn-*、*gn-* | *know*（知道），*knee*（膝盖），*knife*（刀）；*gnaw*（啃），*sign*（标志），*foreign*（外国的） |
| 词首的 *wr-* | *write*（写），*wrong*（错的），*wrist*（手腕） |
| 词尾的 *-mb* | *lamb*（羔羊），*climb*（攀登），*thumb*（拇指），*bomb*（炸弹） |
| *t* 前的 *b* | *doubt*（怀疑），*debt*（债务），*subtle*（微妙的） |
| *-stle*，*-sten* | *castle*（城堡），*whistle*（口哨），*listen*（听），*fasten*（系紧） |
| *-alk*、*-alm*、*-alf*、*-ould* 里的 *l* | *walk*（走），*talk*（谈），*calm*（平静的），*half*（一半），*could*（能够），*should*（应该） |
| *gh* | *night*（夜晚），*though*（虽然），*daughter*（女儿）（但在 *laugh*（笑）、*enough*（足够）、*cough*（咳嗽）里读 /f/） |
| *h* | *hour*（小时），*honest*（诚实的），*honour*（荣誉）；*what*（什么），*why*（为什么）（在 GB 和大多数 GA 里） |
| 其他 | *psychology*（心理学）（*p*），*autumn*（秋天）（*n*），*island*（岛）（*s*），*answer*（回答），*two*（二）（*w*），*Wednesday*（星期三）（第一个 *d*），*receipt*（收据）（*p*） |
:::

::: example 找出不发音字母 {#ex-silent}
找出这个句子中的不发音字母，并写出每个含不发音字母的词的音标：*The knight could not climb the castle wall, so he went home to listen to the rain.*（骑士爬不上城堡的墙，于是回家听雨去了。）
::: solution
- *knight*（骑士）/naɪt/：*k* 和 *gh* 不发音。
- *could* /kʊd/：*l* 不发音。
- *climb* /klaɪm/：*b* 不发音。
- *castle* /ˈkɑːsl/（GB），/ˈkæsl/（GA）：*t* 不发音（*e* 也不发音——这个音节是成音节的 /l/）。
- *home* /həʊm/：词尾 *e* 不发音（它标志长元音）。
- *listen* /ˈlɪsn/：*t* 不发音。
- *rain* /reɪn/：*ai* 是一个元音；没有不发音的字母，只是两个字母代表一个音。

在 *the* 里，*e* 并非不发音：它代表 schwa（/ðə/）。在 *wall*（墙）/wɔːl/ 里，两个字母 *l* 代表一个 /l/——这是双写字母，不是不发音字母。
:::
:::

::: warning 不要看见什么就读什么
✗ 把 *Wednesday* 读成 /ˈwednzdeɪ/，✗ 把 *salmon* 读成 /ˈsælmən/，✗ 在 GB 里把 *iron* 读成 /ˈaɪrən/，✗ 把 *listen* 里的 /t/ 读出来，读成 /ˈlɪstən/。
✓ *Wednesday*（星期三）/ˈwenzdeɪ/，*salmon*（三文鱼）/ˈsæmən/，*iron*（铁；熨斗）/ˈaɪən/（GB），/ˈaɪərn/（GA），*listen*（听）/ˈlɪsn/。

把不发音的字母读出来，叫作**按拼写发音**（spelling pronunciation）。少数按拼写的读法随着时间推移已被接受（现在许多人把 *often*（经常）里的 *t* 读出来：LPD 同时给出 /ˈɒfn/ 和 /ˈɒftən/），但大多数听起来就是错的。一个常用词看起来很奇怪时，查一次它的音标，然后记住。
:::

## 词尾 *-s* 和 *-ed*

英语里出现频率最高的拼写，是语法词尾 *-s*（复数、第三人称单数、所有格）和 *-ed*（过去式、过去分词）。它们各有三种读音，由所加的那个词的**最后一个音**决定。

::: theorem *-s* 和 *-ed* 的读音 {#rule-s-ed}
**词尾 *-s* / *-es***：
1. 在嘶音和嘘音 /s z ʃ ʒ tʃ dʒ/ 之后读 /ɪz/（GA 也读 /əz/）：*buses*（公共汽车），*roses*（玫瑰），*wishes*（愿望），*garages*（车库），*watches*（手表），*judges*（法官）。这会增加一个音节。
2. 在其他清音 /p t k f θ/ 之后读 /s/：*cups*（杯子），*cats*（猫），*books*（书），*laughs*（笑），*months*（月）。
3. 在其他浊音（包括所有元音）之后读 /z/：*dogs*（狗），*bags*（包），*days*（天），*runs*（跑），*calls*（打电话），*goes*（去）。

**词尾 *-ed***：
1. 在 /t/ 或 /d/ 之后读 /ɪd/（GA 常读 /əd/）：*wanted*（想要），*needed*（需要），*started*（开始）。这会增加一个音节。
2. 在其他清音 /p k f θ s ʃ tʃ/ 之后读 /t/：*stopped*（停止），*looked*（看），*laughed*（笑），*missed*（错过），*washed*（洗），*watched*（观看）。
3. 在其他浊音（包括所有元音）之后读 /d/：*played*（玩），*cleaned*（打扫），*lived*（居住），*called*（打电话），*changed*（改变）。
:::

::: proof
这个规律来自英语在音节末尾所允许的组合。在 /s/、/z/ 和其他嘶音之后，再加一个 /s/ 或 /z/ 几乎听不出来（*bus* + /z/），所以要加一个元音；在 /t/ 和 /d/ 之后，*-ed* 也是如此。在其他情况下，词尾只是随着它前面那个音的清浊而变化：清音后读清音（*cats*，*looked*），浊音后读浊音（*dogs*，*played*），因为音节尾里的连缀必须全是清音，或者（对 /z/ 和 /d/ 而言）在末尾带声（[[sounds-of-english/syllables-clusters#rule-codas]]）。注意，起决定作用的是**音**，不是字母：*laughs* 以音 /f/ 结尾，所以读 /s/；*raced*（赛跑，过去式）以音 /s/ 结尾，所以读 /t/。
:::

::: example 选择词尾读音 {#ex-endings}
读出下列词中 *-s* 或 *-ed* 的读音：*boxes*（盒子），*thinks*（想），*pens*（钢笔），*hoped*（希望，过去式），*ended*（结束，过去式），*fixed*（修理，过去式），*judged*（判断，过去式）。
::: solution
先找出原词的最后一个音：

1. *box* 以 /ks/ 结尾——最后一个音 /s/ 是嘶音 → /ɪz/：*boxes* /ˈbɒksɪz/（GB），2个音节。
2. *think* 以清音 /k/ 结尾 → /s/：*thinks* /θɪŋks/。
3. *pen* 以浊音 /n/ 结尾 → /z/：*pens* /penz/。
4. *hope* 以清音 /p/ 结尾（*e* 不发音）→ /t/：*hoped* /həʊpt/（GB），1个音节。
5. *end* 以 /d/ 结尾 → /ɪd/：*ended* /ˈendɪd/，2个音节。
6. *fix* 以清音 /ks/ 结尾 → /t/：*fixed* /fɪkst/，1个音节。
7. *judge* 以 /dʒ/ 结尾，是浊音但不是 /t/ 或 /d/ → /d/：*judged* /dʒʌdʒd/，1个音节。
:::
:::

::: warning *-ed* 不总是一个音节
✗ 把 *washed* 读成 /ˈwɒʃɪd/，✗ 把 *planned* 读成 /ˈplɑːnɪd/，✗ 把 *looked* 读成 /ˈlʊkɪd/。
✓ *washed*（洗，过去式）/wɒʃt/，*planned*（计划，过去式）/plænd/，*looked*（看，过去式）/lʊkt/——各一个音节。

只有在 /t/ 和 /d/ 之后，*-ed* 才增加一个音节。（少数形容词保留了古老的 /ɪd/：*a learned professor*（一位博学的教授）/ˈlɜːnɪd/，*a naked eye*（肉眼），*wicked*（邪恶的），*a crooked line*（一条弯曲的线），*my beloved*（我心爱的人）——但动词 *learned*、*crooked* 只有一个音节。）
:::

## 拼写相同，词不同

**同形异音词**（homographs）是拼写相同而读音不同的词。有些是不同的词；许多是一个名词和一个动词，重音不同或末尾辅音不同。

- *read* /riːd/（读，现在式）– *read* /red/（读，过去式）
- *live* /lɪv/（居住，动词）– *live* /laɪv/（现场的，形容词：*live music*（现场音乐））
- *lead* /liːd/（带领）– *lead* /led/（铅）
- *tear* /tɪə/（眼泪）– *tear* /teə/（撕）
- *wind* /wɪnd/（风）– *wind* /waɪnd/（缠绕；上发条）
- *close* /kləʊz/（关上）– *close* /kləʊs/（近的）
- *use* /juːz/（使用，动词）– *use* /juːs/（用处，名词）
- *record* /rɪˈkɔːd/（记录，动词）– *record* /ˈrekɔːd/（记录，名词），GB；见[[sounds-of-english/word-stress-basics]]

::: example 在同形异音词之间选择 {#ex-homograph}
选出每个句子中黑体词的读音，并说明句子里的什么告诉了你。

1. *The **wind** was so strong that the trees bent.*（风大得把树都吹弯了。）
2. *Don't forget to **wind** the clock.*（别忘了给钟上发条。）
3. *Please **close** the window.*（请关上窗户。）
4. *The station is very **close** to our house.*（车站离我们家很近。）
5. *What's the **use** of a map without a compass?*（没有指南针，地图有什么用？）
::: solution
1. /wɪnd/——*the* 表明它是名词（“风”）。
2. /waɪnd/——在 *to* 之后，是动词（“转动、上发条”）。
3. /kləʊz/（GB），/kloʊz/（GA）——在 *please* 之后，是一个指令：动词“关上”，读 /z/。
4. /kləʊs/（GB），/kloʊs/（GA）——在 *very* 之后，是形容词（“近的”），读 /s/。
5. /juːs/——在 *the* 之后，是名词，读 /s/；动词（*Can I use it?*（我能用它吗？））读 /juːz/。

句子的语法——*the* 后面的名词，*to* 后面或作为指令的动词，*very* 后面的形容词——选定了读音。像 *use* 和 *close* 这样的名词—动词对，常常在末尾辅音的清浊上有区别：名词或形容词用清音，动词用浊音（还有 *advice*（建议，名词）– *advise*（建议，动词），*belief*（信念）– *believe*（相信））。
:::
:::

::: quiz
在哪个句子里 *live* 读作 /laɪv/？
- [ ] *Where do you live?*
- [ ] *I live in a small flat.*
- [x] *The concert was broadcast live.*
- [ ] *They want to live abroad.*
::: solution
当 *live* 的意思是“正在发生的、不是录播的”（形容词或副词）时，读 /laɪv/，是 PRICE 元音：*The concert was broadcast live.*（音乐会是现场直播的。）在其他句子里，它是动词“居住”，读 /lɪv/，是 KIT 元音：*Where do you live?*（你住在哪里？）*I live in a small flat.*（我住在一套小公寓里。）*They want to live abroad.*（他们想去国外生活。）
:::
:::

## 朗读：一则简短的告示

> *Welcome to Riverside Library. Please switch off your phone, keep your bags on the floor, and speak quietly. Children under eight must be with an adult. We close at half past nine on weekdays and at noon on Saturdays.*

**译文：**欢迎来到河畔图书馆。请关闭手机，把包放在地上，轻声说话。八岁以下儿童须由成人陪同。工作日九点半闭馆，星期六中午闭馆。

告示中的规律：*side*、*phone*、*close* 和 *nine* 里不发音的 *e* 标志长元音（但 *welcome* /ˈwelkəm/ 里不是，因为它含有例外词 *come*）；*phone* 里的 *ph*；*switch* 里的 *tch*；*eight* 里的 *igh*（/eɪt/，*ei* 加上不发音的 *gh*）；*floor* 里的 *oo*（/ɔː/——一个例外）和 *noon* 里的 *oo*（/uː/）；*half* 里不发音的 *l*；*bags*、*weekdays*、*Saturdays* 里读 /z/ 的 *-s*；*quietly* 里的 *-ly*。

::: note 英汉对比
- **汉字与读音。** 汉字也不能可靠地显示读音：像“清”这样的字，声旁提供了线索，但许多声旁相同的字读音并不相同。所以中国读者早就知道，文字可以只是读音的一个粗略指南。英语拼写比许多学习者以为的更有规律：运用本章的规律，并把那些非常常用的例外一个一个记住。
- **拼音习惯。** 拼音几乎完全规则，学习者有时以为英语字母也一样。特别是，他们以为每个书写的元音都要读出来（*Wednesday*，*chocolate*），每个字母只有一个读音（*cat*、*car*、*care*、*was*、*about* 里的 *a*），词尾的 *e* 是一个元音（它通常不发音）。
- **自然拼读。** 现在中国的许多小学教**自然拼读**（phonics）：本章这样的字母—读音规律。自然拼读对于朗读新词、拼写听到的词非常有用；但对那些不规则的常用词，以及拼写所不显示的重音，它代替不了词典。
- **学习新词。** 学一个新词时，要同时学三样东西：拼写，音标（带重音符号），以及意思。只从拼写学来的词，常常读音是错的。
:::

::: history
英语拼写为什么是这个样子？好几层历史叠在一起。古英语的拼写相当规则。1066年诺曼征服之后，受过法语训练的抄写员引入了新的拼法：用 *qu* 代替较早的 *cw*（*queen*），用 *ou* 表示元音 /uː/（*hous*，后来是 *house*），用 *gh* 表示一个类似苏格兰 *loch*（湖）里 *ch* 的音（*night*），在 *e* 和 *i* 前用 *c* 表示 /s/。1476年，卡克斯顿（William Caxton）在英格兰建立了第一家印刷所，印刷商逐渐固定了许多词的拼写——但在同几个世纪里，元音大推移（约1400–1700）改变了长元音，*knight* 的 *k* 和 *night* 的 *gh* 这类音也消失了。拼写留了下来，读音却变了。在16、17世纪，学者们添加字母来显示词的拉丁语来源：*debt* 和 *doubt* 里的 *b*（拉丁语 *debitum*、*dubitare*），以及——出于误会——*island* 里的 *s*（误以为它和 *isle* 有关，而 *isle* 来自拉丁语 *insula*；*island* 其实是一个英语本族词）。约翰逊（Samuel Johnson）的《英语词典》（*Dictionary*，1755）帮助统一了英式拼写，韦伯斯特（Noah Webster）的《美国英语词典》（*American Dictionary*，1828）确立了一些美式拼法（*color*（颜色），*center*（中心））。
:::

## 后续内容

本章的规律只管**音**；它们不显示哪个音节重读。那是[[sounds-of-english/word-stress-basics]]的内容。加词尾时的拼写变化（*hopping*，*happier*）见[[word-formation/spelling-changes]]，书面写作中的大写和拼写见[[sentences-and-paragraphs/capitals-spelling]]，英语拼写的历史见[[history-of-english/early-modern-english]]和[[history-of-english/dictionaries-grammars]]。

::: summary
- **字位**是代表一个音位的一个字母或一组字母（*sh*，*igh*，*tch*）；英语用26个字母表示44个音位（GB）（[[#def-grapheme]]）。
- *c* 在 *e*、*i*、*y* 前读 /s/，在其他位置读 /k/；*e*、*i*、*y* 前的 *g* 常读 /dʒ/，但有许多例外（[[#rule-c-g]]）。
- 双写辅音（或 *ck*、*tch*、*dge*）通常跟在短元音后面：*hopping*，*dinner*，*back*（[[#rule-double]]）。
- 词尾不发音的 *e* 通常使它前面的元音变长：*hat – hate*，*bit – bite*——但 *have*、*give*、*come*、*love* 等常用词例外（[[#rule-silent-e]]）。
- *r* 前的元音字母有自己的读音（*car*，*her*，*for*，*care*）；常见的元音二合字母（*ee*、*ai*、*oa*、*ou*、*ow*、*oo*）有一个主要读音和一些例外。
- 不发音字母有规律：*kn-*，*wr-*，*-mb*，*-stle*，*walk* 里的 *l*，*night* 里的 *gh*（[[#rule-silent]]）。
- *-s* 读 /ɪz/、/s/ 或 /z/，*-ed* 读 /ɪd/、/t/ 或 /d/，由词的最后一个**音**决定（[[#rule-s-ed]]）。
:::

::: exercise 解释例外 {level=3}
一位朋友说：“英语拼写根本没有规则：看看 *have* 和 *gave*，*come* 和 *home*，*put* 和 *but*。”写一段简短的回答（四到六句），解释这些规律是什么，为什么这几个词不守规律，以及学习者应该怎样对待这样的词。
::: solution
参考答案：“规则是有的，但有些非常常用的词不守规则。词尾不发音的 *e* 通常使元音变长，比如 *gave*（给，过去式）和 *home*（家）；*have*（有）和 *come*（来）是例外，因为它们的元音在几百年前、拼写固定下来以后变短了。字母 *u* 通常读 STRUT 元音，比如 *but*（但是）；*put*（放）保留了一个较老的元音，因为从 FOOT 元音到 STRUT 的变化在 /p/ 这样的唇音之后没有发生。这样的例外大多是使用频率很高的词，你会经常听到，足以一个一个地记住。对不太常用的词，这些规律很管用；拿不准时，词典里的音标会给出答案。”
:::

::: exercise 朗读 {level=3}
大声朗读下面这段文字并录音。朗读之前，标出（1）每个不发音字母，（2）每个 *-s* 和 *-ed* 词尾及其读音，（3）任何你没有把握的词。在词典里查一查这些词。

> *Last autumn my neighbour planted twelve lemon trees in his garden. He watered them daily and talked to them while he worked. Now he answers every question about lemons, whether you ask or not.*

**译文：**去年秋天，我的邻居在他的花园里种了十二棵柠檬树。他每天给它们浇水，一边干活一边和它们说话。现在，不管你问不问，他都会回答所有关于柠檬的问题。
::: solution
不发音字母：*autumn*（词尾的 *n*），*neighbour*（*gh*；GA 拼作 *neighbor*），*talked*（*l*），*answers*（*w*），*whether* 和 *while*（*h*，在 GB 和大多数 GA 里），*twelve*（词尾的 *e*）。词尾：*planted* /ɪd/；*trees* /z/；*watered* /d/；*talked* /t/；*worked* /t/；*answers* /z/；*lemons* /z/。学习者常需要查的词：*autumn* /ˈɔːtəm/，*neighbour* /ˈneɪbə/，*daily* /ˈdeɪli/，*question* /ˈkwestʃən/，*whether* /ˈweðə/（GB）。好的朗读会让 *planted* 保持两个音节，*talked* 和 *worked* 保持一个音节，并且不读出不发音的字母。
