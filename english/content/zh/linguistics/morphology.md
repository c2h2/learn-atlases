1958年，琼·伯科（Jean Berko）给幼儿看一幅画，画上是一只像小鸟一样的小动物，并且说：*This is a wug.* 然后她给他们看两只：*Now there is another one. There are two of them. There are two …* 大多数孩子（年龄大约在四到七岁之间）都说 *wugs*——用的是复数的 /z/ 形式，这正是 /ɡ/ 之后应该用的形式。他们谁也没有听过这个词，因为它是伯科生造的。他们不可能是在重复一个记住了的形式；他们是在运用规则。同样是这些孩子，还告诉她：一个每天都 *ricks* 的人昨天 *ricked*，一只身上长满 *quirks* 的狗是 *quirky* 的。

这个实验以《儿童对英语形态的学习》（“The child's learning of English morphology”）为题发表在《词》（*Word*）杂志上，它最清楚地表明：说话人是把词的结构作为一个系统、而不只是作为一张清单来掌握的。本章追问这个系统包含什么。实用方面——什么是语素，怎样把 *unhappiness* 切分为 *un-* + *happy* + *-ness*，*-s* 和 *-ed* 的读音，以及英语主要的前缀、后缀和复合词——在 [[word-formation/morphemes]] 和《构词法》（*Word Formation*）课程的其余部分讲授，这里假定读者已经掌握。我们要更进一步：什么是词，屈折变化和派生在理论上有什么区别，为什么有些词缀可以自由地构成新词而另一些不能，词的内部是怎样构造的，以及英语和汉语普通话在世界语言中处于什么位置。

## 词形、词位和语素

“词”（*word*）这个词至少有三种意思，形态学需要把它们区分开来。

::: definition 词形、词位和语素 {#def-lexeme}
**词形**（word-form）是在语篇中出现的一个具体形式：*sings*、*sang*、*singing* 和 *sing* 是四个词形。**词位**（lexeme）是这些形式所共属的那个抽象的词典词，在语言学书籍中用小型大写字母书写，这里直接称名：词位 SING。**语素**（morpheme）是具有意义或语法功能的最小单位（[[word-formation/morphemes#def-morpheme]]）；**形素**（morph）是表达语素的实际的一段语音或拼写，同一个语素的不同形素是它的**语素变体**（allomorphs，[[word-formation/morphemes#def-allomorph]]）。
:::

有了这些术语，人们熟悉的那个区分就可以表述得很精确了。**屈折变化**（inflection）构成同一个词位的不同词形（*sing*、*sings*、*sang*、*sung*、*singing*）；**派生**（derivation）从一个已有的词位构成一个新的词位（*sing* → *singer*）。学习型词典是一张词位的清单；它在 *sing* 词条下列出不规则词形 *sang* 和 *sung*，而 *singer* 有自己的词条。

并不是每个语素都有自己的形素。三种情况表明，意义和形式之间的关系可以是间接的：

- **零形式**（zero）。*Sheep* 在 *one sheep* 中是单数，在 *two sheep* 中是复数，形式没有变化。有些分析设立一个“零”复数形素；另一些分析则简单地说这个词位的两种形式相同。
- **异干互补**（suppletion）。*Went* 是 *go* 的过去式，*better* 是 *good* 的比较级，*worse* 是 *bad* 的比较级：屈折形式完全是另一个词根。*Went* 原来是 *wend*“去，转向”的过去式，在中古英语晚期取代了 *go* 原来的过去式。
- **内部变化**（internal change）。*Sang*、*feet*、*mice* 通过改变词根的元音来表示过去或复数（从历史上说，是通过称为元音交替［ablaut］和元音变音［umlaut］的过程）。

还有相反的情况：一个看起来像语素、自身却没有意义的成分。*cranberry*（蔓越莓）中的 *cran-* 不出现在任何其他英语词中，但 *cranberry* 显然是一种浆果；这样的成分叫作**蔓越莓语素**（cranberry morphemes）。*huckleberry* 中的 *Huckle-* 和 *unkempt* 中的 *-kempt* 也是。它们说明，语素既是意义的单位，也是结构的单位。

::: quiz
词形 *run*、*ran*、*runs*、*runner*、*runners*、*running*（如 *She is running*）代表多少个**词位**？
- [ ] 一个
- [x] 两个
- [ ] 三个
- [ ] 六个
::: solution
两个：RUN（*run*、*ran*、*runs*、*running*）和 RUNNER（*runner*、*runners*），后者是用 *-er* 从 RUN 派生出来的。作为动词形式的 *Running* 是屈折变化；如果它用作名词（*Running is good for you*），许多分析会把它看作另一个派生词位，在这一点上各家语法有分歧。
:::
:::

## 理论上的屈折变化和派生

[[word-formation/morphemes#rule-four-tests]] 给出了四条实用的测试：派生可以改变词类，屈折变化从不改变词类；屈折变化适用于一个词类的几乎所有成员；屈折变化位于派生之外；屈折变化是句法所要求的。形态学家试图说明这些测试背后是什么。

::: theorem 什么使一个词缀成为屈折词缀 {#rule-inflection}
1. **屈折变化是句法所需要的。** 屈折范畴是词外部的语法规则所涉及的范畴：一致（*she work**s***）、限定分句中的时、代词的格（*I*/*me*）。派生对句法来说是不可见的，除了它所产生的词类。（这是安德森［Stephen Anderson］在1982年提出的定义。）
2. **屈折变化是成聚合的。** 屈折形式成套出现——构成一个**聚合**（paradigm，词形变化表）——每种范畴组合占一格，该词类的每个词位都有整套形式，即使某些格是不规则的或空缺的。
3. **屈折变化在语义上是规则的。** 复数给任何名词加上“多于一个”的意思；而 *teacher*、*printer*、*diner* 和 *sleeper*（卧铺车厢）中的 *-er* 意思相当不同。
4. **界线是一个连续统，而不是一堵墙。** 有些词缀兼有两者的特性：把形容词变成副词的 *-ly* 几乎完全能产、完全规则，但它改变词类，也不是任何一致规则所要求的。
:::

::: proof
每一条特性都解释了一条实用测试。如果屈折变化是句法所需要的，那么凡是能出现在那个句法位置上的词都必须能够有这种屈折形式（因此有范围测试），它不能改变句法已经选定的词类（因此有词类测试），它还必须位于词的边缘，在那里句法能“看到”它（因此有顺序测试）。聚合解释了为什么屈折变化中的空缺会被感到是空缺：说话人拿不准 *stride* 的过去分词是什么（*strode*？*stridden*？）时，会觉得这一格一定有一个形式；而没有人觉得词位 KIND 一定有一个带 *-ish* 的派生形容词。特性4得到广泛认可：鲍尔、利伯和普拉格（Bauer, Lieber and Plag，2013）以及赫德尔斯顿和普勒姆（2002）都指出了边缘情况，有几种语言的某些范畴（如俄语的体）被语言学家作了不同的归类。英语只有八个屈折词缀，是一种界线特别容易划分的语言。
:::

::: example 三种边缘情况 {#ex-borderline}
用 [[#rule-inflection]] 中的特性判断下面每个词尾应当怎样归类，并说明难点在哪里。

1. *quickly*、*carefully*、*happily* 中的 *-ly*。
2. *an interesting book* 中的 *-ing* 和 *a worried look* 中的 *-ed*。
3. *the woman's car* 和 *the woman next door's car* 中的 *-'s*。
::: solution
1. *-ly* 是规则的，与形容词搭配几乎完全能产，这一点像屈折变化（特性3）。但它把词类从形容词变成副词，而且没有哪条一致规则要求它——*She ran quick* 是不标准的，但并不违反一致。所以大多数语法书和学习型词典把它看作派生；赫德尔斯顿和普勒姆（2002）指出，它是派生后缀中最像屈折变化的一个。
2. *Interesting* 和 *worried* 起初是动词形式（屈折变化），但在这里表现得像形容词：它们可以受 *very* 修饰（*a very interesting book*），有比较级（*more interesting*），可以跟在 *seem* 后面（*She seemed worried*），而动词不能。一个由屈折变化构成的形式被转变成了一个新的词位——一个形容词。词类测试能显示哪种用法是哪种：✓ *very interesting*（形容词）与 ✗ *She is very interesting her students*（动词）。
3. *-'s* 看起来像名词的屈折变化，但在 *the woman next door's car* 中它附着在 *door* 上，而 *door* 并不是车主。它附着在整个名词短语 *the woman next door* 的末尾。一个在读音上是词的一部分、却附着于短语的成分叫作**附着语素**（clitic）。所以英语的所有格最好分析为附着语素，而不是格的屈折变化——这就是为什么有些英语屈折词缀的清单（如 [[word-formation/morphemes]] 中的那一份）加注把它列入，而另一些则不列入。
:::
:::

## 能产性和阻断

有些词缀几乎可以加在任何合适的词基上，包括全新的词；另一些只见于一张固定的旧词清单中。

::: definition 能产性 {#def-productivity}
一个形态过程的**能产性**（productivity）取决于说话人在多大程度上用它构成新词。*-ness* 能产性很高：它几乎可以加在任何形容词上，包括新的形容词（*Instagrammable-ness* 一听就懂）。*-th*（*warmth*、*width*、*depth*、*truth*）是非能产的：没有新的名词用它构成，像 *coolth* 这样的新造词听起来像是开玩笑。能产性是程度问题，而且会随时间而变化。
:::

能产性怎样测量？简单地数一数有多少词含有某个词缀会产生误导：*-ment* 出现在许多旧词中（*government*、*movement*），但现在用于构成新词的情况远不如 *-ness* 或 *-ization* 多。更好的线索是：在一个大型语料库中，带有该词缀、只出现一次的词有多少——这些词叫作**单现词**（hapax legomena，源自希腊语，意为“只说过一次的”）。罕见的词大多是新造的或临时构成的词，所以一个词缀构成的词中如果有许多单现词，说话人就仍在用它造词。拜恩（Harald Baayen）在20世纪90年代初提出了这类测量方法，此后对英语后缀的语料库研究证实了直觉所提示的结论：*-ness* 远比 *-ity* 能产，*-ity* 又远比 *-th* 能产。

::: definition 阻断 {#def-blocking}
**阻断**（blocking）是指，由于已经存在一个意义相同的词，一个规则的构词形式就不被使用。*Stealer* 不用来表示“偷东西的人”，因为已经有 *thief*；✗ *gloriosity* 被 *glory* 阻断，尽管 *curious* → *curiosity* 是规则的（阿罗诺夫［Mark Aronoff］在《生成语法中的构词法》［*Word Formation in Generative Grammar*］，1976年中讨论过这一对词）；在成人英语中，*goed* 被 *went* 阻断。
:::

阻断不是绝对的。*Stealer* 在复合词和固定短语中是可能的（*a scene-stealer*），而当两个词发展出不同的意义时，它们可以共存：在英式英语中 *cooker* 是一种厨房用具，*cook* 才是人。儿童是阻断的最佳证据：在学会 *went* 之前，他们说 *goed*；一旦 *went* 掌握牢固，规则形式就消失了（[[linguistics/language-acquisition]]）。

::: example 能产性和阻断 {#ex-productivity}
对每个形式，说明它是现有的词、可能但未被使用的词，还是被阻断的词，并加以解释。

1. *bakery*、*brewery*、✗ *teachery*
2. *unhappy*、? *unsad*
3. *driver*、*swimmer*、*cooker*（“做饭的人”）
4. *broadness*、*breadth*
5. *happiness*、*happity*
::: solution
1. *Bakery* 和 *brewery* 是现有的词：*-ery* 构成表示做某事的场所的名词。*Teachery* 本来是一个可能的构词，但被 *school* 阻断了，因为 *school* 已经填补了这个意义——何况 *-ery* 现在的能产性本来就有限。
2. *Unhappy* 存在。? *Unsad* 原则上可能，但很罕见，因为 *un-* 倾向于加在意义积极的形容词上（*unkind*、*unwell*、*unhealthy*），而 *sad* 的反面通常用 *happy* 表达。这是叶斯柏森（Otto Jespersen）最早描述的一种倾向，不是绝对的规则：*unselfish* 的词基就是消极的。
3. *Driver* 和 *swimmer* 存在。表示人的 *cooker* 被 *cook* 阻断（这是转类的一个例子：动词 *cook* 用作名词）；*cooker* 在英式英语中以另一个意义保存下来。
4. 两个都存在。*Breadth* 是一个旧的 *-th* 名词，是表示度量的常规说法（*length*、*breadth* 和 *height*）；*broadness* 是一个较新的 *-ness* 构词，用于其他意义（*the broadness of his accent*）。在意义可以分化时，阻断较弱。
5. *Happiness* 存在。✗ *Happity* 不可能：*-ity* 主要加在拉丁语来源的词基上（*curious*、*able*、*real*），而不加在 *happy* 这样的本族词上。这是对词基的限制，不是阻断。
:::
:::

## 复杂词的结构

词中的语素并不只是排成一行。它们是一层一层构建起来的，正如 [[word-formation/morphemes#ex-unlockable]] 对 *unlockable* 所展示的那样，而每一层都有一个词类。

::: theorem 英语词的中心词和层次 {#rule-heads}
1. **词有层级结构。** 每个词缀都附加在某一特定词类的词基上，产生某一特定词类的词：*-ness* 附加在形容词上，产生名词；表示“不”的 *un-* 附加在形容词上。
2. **最右边的成分通常是中心词。** 在英语复合词和带后缀的词中，最后一个成分决定词类和基本意义：*blackbird* 是一种鸟（名词），*sweeten* 是动词，因为 *-en* 构成动词，*kindness* 是名词，因为有 *-ness*。前缀通常不改变词类（*kind*/*unkind*，*write*/*rewrite*），但也有少数会改变（*enlarge* 中的 *en-*，*befriend* 中的 *be-*）。威廉斯（Edwin Williams，1981）称之为**右手中心词规则**（righthand head rule）。
3. **复合词有自己的重音模式。** 名词复合词的重音通常在第一个成分上（*a ˈblackbird*、*a ˈgreenhouse*），而短语的主重音在名词上（*a black ˈbird*、*a green ˈhouse*）。例外很多（*apple ˈpie*、*Oxford ˈStreet*，但 *ˈOxford Road*），见 [[connected-speech/word-stress-patterns]]。
:::

:::

### 两类后缀

英语有两组派生后缀，它们在语音和组合上表现不同。第一组大多来自拉丁语或法语，包括 *-ity*、*-ic*、*-ion*、*-ous* 和 *-al*。它们常常移动词基的重音并改变其元音：*proˈductive* → *producˈtivity*，*ˈatom* → *aˈtomic*，*sane* /seɪn/ → *sanity* /ˈsænəti/。第二组大多是本族的，包括 *-ness*、*-less*、*-ful*、*-ly* 和 *-er*：它们不改变词基的重音和元音（*proˈductiveness*、*ˈatomless*、*ˈsaneness*）。

::: definition 第一类词缀和第二类词缀 {#def-affix-classes}
**第一类**（Class I，或**第一层级**［level 1］）词缀，如 *-ity*、*-ic*、*-ion* 和否定前缀 *in-*，会移动重音或改变元音，既附加在词上，也附加在粘着词根上（*elect-ric*、*nat-ion*），并且出现在更靠近词根的位置。**第二类**（Class II，或**第二层级**［level 2］）词缀，如 *-ness*、*-less*、*-ful* 和 *un-*，不影响重音，附加在完整的词上，出现在更靠外的位置。这一区分由西格尔（Dorothy Siegel，1974）提出，并在基帕斯基（Paul Kiparsky）的**词汇音系学**（lexical phonology，1982）中得到发展。
:::

这一理论作出一个预测：第一类词缀不应附加在第二类词缀之外。*Hopelessness*（第二类在第二类之内）没有问题；✗ *hopelessity*（第一类的 *-ity* 在第二类的 *-less* 之外）不可能。这一预测大体正确，但有一些著名的反例。*Ungrammaticality* 似乎需要把 *un-*（第二类）放在 *-ity*（第一类）之内，因为 *-ity* 改变了 *grammatical* 的重音，而 *un-* 附加在形容词上：[ [un- grammatical] -ity ] 这种括法符合意义，[ un- [grammatical -ity] ] 这种括法符合语音。这样的情况叫作**括号悖论**（bracketing paradoxes），它是形态学家至今仍在争论词的结构有多少由音系决定、有多少由意义决定的原因之一。

::: quiz
哪一对词显示了**第一类**后缀，即移动词基重音的后缀？
- [ ] *ˈcareful* → *ˈcarefulness*
- [x] *ˈpersonal* → *ˌpersoˈnality*
- [ ] *ˈhope* → *ˈhopeless*
- [ ] *ˈkind* → *ˈkindly*
::: solution
*-ity* 是第一类后缀：它把主重音放在它前面的音节上，所以 *ˈpersonal* 变成 *ˌpersoˈnality*，*-al* 的元音也从 /ə/ 变为完整元音 /æ/。*-ness*、*-less* 和 *-ly* 是第二类后缀，让词基的重音留在原处。
:::
:::

::: example 一个括号悖论 {#ex-unhappier}
*Unhappier* 的意思是“更不快乐”。利用两个事实说明它的结构为什么是一个难题：（a）*un-* 附加在形容词上；（b）比较级 *-er* 只附加在短形容词上（单音节的，或以 *-y*、*-ow*、*-le* 结尾的双音节的），所以我们说 *happier*，却说 *more comfortable*，而不说 ✗ *comfortabler*。
::: solution
1. **意义**是“更 [不快乐]”：一个比以前 *unhappier* 的人是更不快乐了，而不是 *not happier*（那意思是“并不比……更快乐”）。所以按意义，结构应当是 [ [un- happy] -er ]，*-er* 最后加上。
2. **形式**：*-er* 只附加在短形容词上。*Unhappy* 有三个音节，所以按照事实（b），✗ *unhappy* + *-er* 应当是不可能的，就像 ✗ *uncomfortabler* 一样。按语音，结构应当是 [ un- [happy -er] ]，*-er* 先加在双音节的 *happy* 上。
3. **悖论**：意义要求一种括法，形式要求另一种括法。没有哪一种结构能同时满足两者。
4. **提出的解决办法**各不相同。有些语言学家允许结构在不同层面上不同——意义用一种括法，语音用另一种括法。另一些人指出，*-er* 可以附加在以 *un-* 开头的较长形容词上（*untidier*、*unluckier*），因为这一限制实际上涉及的是词基 *happy*、*tidy*、*lucky*，于是重新表述了事实（b）。这个例子说明，词的结构和句子结构一样，可以通过用数据检验假设来研究。
:::
:::

## 词是怎样构成的：总结

英语的各种构词过程在《构词法》中各有一课专门讲授。在理论上，它们可以分为增加材料的、除词类外什么都不改变的、以及缩短的。

| 过程 | 例子 | 是否增加材料？ | 课 |
|---|---|---|---|
| **词缀法**（affixation，派生） | *kind* → *kindness*，*rewrite* | 是 | [[word-formation/prefixes]]，[[word-formation/suffixes]] |
| **复合**（compounding） | *black* + *bird* → *blackbird* | 是（增加第二个词根） | [[word-formation/compounds]] |
| **转类**（conversion） | *email*（名词）→ *to email*（动词） | 否 | [[word-formation/conversion]] |
| **截短**（clipping） | *laboratory* → *lab* | 否（缩短） | [[word-formation/shortening]] |
| **拼缀**（blending） | *breakfast* + *lunch* → *brunch* | 否（合并） | [[word-formation/shortening]] |
| **首字母拼音词和首字母缩略词**（acronyms and initialisms） | *NATO*（作为一个词读），*BBC*（逐个字母读） | 否（缩短） | [[word-formation/shortening]] |
| **逆构词**（back-formation） | *editor* → *edit*，*television* → *televise* | 去掉一个表面上的词缀 | [[word-formation/suffixes]] |
| **借用**（borrowing） | *tofu*，*kowtow*（来自“叩头”），*lychee* | 是（来自另一种语言） | 《英语史》（*History of English*）课程 |

逆构词是形态推动变化的一个好例子：*editor*（来自拉丁语）看起来像 *edit* + *-or*，于是说话人造出了动词 *edit*，而这个动词以前是不存在的。*burgle* 来自 *burglar*，*babysit* 来自 *babysitter*，也是同样的情况。

*Donation* 在英语中是较早的词；*donate* 是18世纪末在美国通过去掉看起来像后缀的 *-ion* 而从它构成的。*Unhappy* 是加前缀，*brunch* 是拼缀词，*lab* 是截短词。

## 语言比较：形态类型

各种语言在词内部所做的工作多少大不相同。施莱歇尔（August Schleicher）等19世纪的语言学家把语言分为几种类型，这种分类至今仍在使用，不过现在是作为一组倾向，而不是作为几个格子。

::: definition 形态类型 {#def-typology}
- **孤立语**（isolating language，或**分析语**［analytic language］）每个词的语素很少，主要用独立的词和语序来表达语法意义。越南语和汉语普通话是标准的例子。
- **黏着语**（agglutinating language）用许多语素构成词，每个语素有一个清楚的意义和容易切分的形式。土耳其语 *ev-ler-im-de*“房子-复数-我的-在……里”=“在我的（几所）房子里”。
- **屈折语**（fusional language，或 inflecting language）的词缀在一个形式中同时表达几种意义。拉丁语 *amō*“我爱”：*-ō* 同时表示第一人称、单数、现在时、陈述语气和主动语态。
- **多式综合语**（polysynthetic language）能把许多词根和词缀组合成一个长词，相当于英语的一整个句子；北美的许多语言，如因纽特诸语言和莫霍克语（Mohawk），被描述为这种类型。

格林伯格（Joseph Greenberg，1960）提出用指数来测量这些倾向，例如一个语篇样本中每个词的平均语素数（**综合指数**，index of synthesis）。
:::

英语是一种混合类型。自古英语以来，它已经变得分析性强得多；古英语的名词、形容词和冠词都有格词尾（见《英语史》课程）：今天的英语在古英语用格的地方用语序（*The dog bit the man* 与 *The man bit the dog*），在其他语言用屈折变化的地方用助动词（*will go*、*has gone*），在拉丁语用格的地方用介词（*of the king*）。但它残存的屈折变化是融合性的：*works* 的 *-s* 同时表示第三人称、单数和现在时。而它的派生形态大部分借自拉丁语和法语，产生了 *denationalisation* 这样的长词，孤立语会用一个短语来表达这样的意思。

::: example 按类型分类 {#ex-typology}
说明每个例子显示了其所属语言的什么形态类型。

1. 汉语普通话 我明天去北京 *‘I go to Beijing tomorrow’*；我昨天去北京了 *‘I went to Beijing yesterday’*。
2. 土耳其语 *ev*“房子”，*evler*“（几所）房子”，*evlerim*“我的（几所）房子”，*evlerimde*“在我的（几所）房子里”。
3. 英语 *took*、*mice*、*went*。
4. 英语 *will have been working*。
::: solution
1. **孤立语。** 动词“去”不变化。时间由独立的词（“明天”“昨天”）表达，完成由独立的助词“了”表达，“了”放在动词后还是句末由句法决定。这里每个词都是一个语素，只有“北京”除外（“北”+“京”，一个复合词中的两个语素）。
2. **黏着语。** 每个后缀增加一个意义（*-ler* 复数，*-im*“我的”，*-de*“在……里”），每个后缀都可以干净地切分出来。
3. 处于极端的**屈折语**：一个形式同时表达词根和过去或复数，没有可切分的词缀（*took*、*mice* 中的内部变化；*went* 中的异干互补）。
4. **分析语**：四个独立的词分别表达将来、完成体、进行体和动词。拉丁语或土耳其语会把其中的大部分放进一个词里。
:::
:::

::: note 英汉对比
有时有人说汉语“没有形态”。这只就屈折变化而言才是对的。汉语普通话的构词很丰富，其中大部分是复合。朱德熙在《语法讲义》（1982）中按照组成部分之间的语法关系给复合词分类，这些关系与短语中的关系相同：**联合**（coordinate，道路：“道”+“路”）、**偏正**（modifier–head，白菜：“白”+“菜”，火车：“火”+“车”）、**述宾**（verb–object，司机：“司”掌管 +“机”机器，即 *driver*；动员：“动”+“员”人员）、**述补**（verb–complement，提高：“提”+“高”，即 *raise*；说明：“说”+“明”清楚，即 *explain*）和**主谓**（subject–predicate，地震：“地”+“震”，心疼：“心”+“疼”）。相比之下，大多数英语复合词是修饰语–中心词型的（*blackbird*、*bookshop*），中心词在右边——与偏正式复合词的顺序相同。

普通话还有**重叠**（reduplication，看看“看一下”，高高兴兴“非常高兴地”），少量词缀（“老师”中的“老-”，“第三”中的“第-”，“桌子”中的“-子”，表示人的复数的“-们”），以及一组不断扩大的**类词缀**（affix-like morphemes），如“-化”（*-isation*，现代化）、“-性”（*-ity, -ness*，可能性）、“-者”（*-er*，读者）和“非-”（*non-*，非正式），其中有几个部分是由于从欧洲语言翻译而变得能产的。帕卡德（Jerome Packard）的《汉语形态学》（*The Morphology of Chinese*，2000）是对这些模式的语言学研究。

在普通话中，“词”本身比在英语中更难界定。书写中没有空格，而有些述宾式复合词可以被其他成分隔开：“睡觉”可以变成“睡了一个好觉”。这些**离合词**（separable words）在某些方面像词，在另一些方面像短语——这提醒我们，“词”是一个理论概念，要用标准来界定，即使在英语中也是如此（*ice cream* 是一个词还是两个词？）。
:::

## 心智中的形态

伯科的实验表明，儿童会把规则应用于新词。那么不规则形式又是怎样的呢？自20世纪80年代以来，有两类理论一直在竞争，争论主要围绕英语的过去式展开。

::: theorem 关于规则形式和不规则形式的两种解释 {#rule-dual-route}
1. **双路径**（dual-route）解释（平克［Steven Pinker］，《词与规则》［*Words and Rules*］，1999）认为，*walked* 这样的规则形式是由规则（“加 *-ed*”）构成的，而 *went* 和 *sang* 这样的不规则形式储存在记忆中，并且储存的形式会阻断规则。
2. **单一机制**（single-mechanism，联结主义［connectionist］）解释始于鲁姆哈特和麦克莱兰（Rumelhart and McClelland）1986年的模型，认为规则形式和不规则形式都是由同一个联想网络产生的，这个网络用说话人听到过的形式训练而成；规则性是许多相似形式的效应，而不是规则的效应。
3. 两种解释对需要解释的数据看法一致：*-ed* 对新动词的能产性（*She googled it*）；存在一些小的不规则词族（*sing–sang*、*ring–rang*），它们偶尔会吸引新成员（一些说话人和儿童说 *bring–brang*）；以及高频的不规则形式得以保存，而低频的不规则形式随着时间推移变成规则形式（*help–holp* 变成了 *helped*）。
:::

::: proof
两方都提出了证据。双路径的支持者指出，规则的屈折变化甚至适用于读音与任何现有动词都不相似的词（*He out-Gorbachev'd Gorbachev*），还指出一些病人研究中，脑损伤对规则形式和不规则形式的影响不同。单一机制模型的支持者指出，网络也能推广到不寻常的词，而且在某些语言中规则性是程度问题。语言变化研究在一点上与两方都一致：利伯曼及其同事（Lieberman and colleagues，2007）统计了古英语中后来变成规则动词的不规则动词，发现规则化的速度与频率密切相关——低频的不规则动词规则化的速度远远快于高频的。这场争论尚无定论，目前的许多理论把储存的形式与对储存形式的概括结合在一起。
:::

::: warning 形态学不是词源学
今天分析一个词的形态，要问的是说话人现在能从中辨认出什么，而不是它从哪里来。*Disaster* 来自拉丁语 *dis-* + *astrum*“星”（“星象不吉的”），但对现代说话人来说它是一个语素。✗ *Disaster has two morphemes because it means ‘bad star’.* ✓ *Disaster is one morpheme today; historically it was formed from* dis- *and* astrum. 历史可以帮助学习者记住一个词（[[word-formation/greek-latin-roots]]），但它是历时的知识，不是共时分析的一部分（[[linguistics/what-linguistics-studies#def-synchronic]]）。
:::

::: history
形态分析比语言学的其他任何部分都古老。波你尼（Pāṇini）的梵语语法（通常认为成书于公元前4世纪前后）用将近四千条简洁的规则从词根和词缀推导出这种语言的词。而直到19世纪，欧洲语法一直使用要背下来的整词聚合——*amo, amas, amat*。20世纪的结构主义者把语素作为基本单位：布龙菲尔德的《语言论》（1933）为它下了定义，20世纪四五十年代的美国语言学家发展出一套从田野数据中找出陌生语言的语素的程序。生成语法起初把形态交给句法和音系处理；乔姆斯基的《论名词化》（“Remarks on nominalization”，1970）和阿罗诺夫的《生成语法中的构词法》（1976）则主张词有自己的结构和自己的规则。琼·伯科的 wug 测试（1958）成为语言研究中最著名的实验之一，至今仍在许多语言中用来测试儿童的形态知识。
:::

## 后续内容

关于英语构词的实用课在《构词法》中：[[word-formation/prefixes]]、[[word-formation/suffixes]]、[[word-formation/compounds]]、[[word-formation/conversion]]、[[word-formation/shortening]] 和 [[word-formation/greek-latin-roots]]。形态与重音的相互作用见 [[connected-speech/word-stress-patterns]]。儿童对屈折变化的学习——wug 测试、过度规则化以及英语语素出现的顺序——将在 [[linguistics/language-acquisition]] 中再次讨论。下一章 [[linguistics/phrases-constituents]] 把层级结构的观念应用于句子。

::: summary
- **词形**是语篇中的形式，**词位**是抽象的词典词，**语素**是意义或功能的最小单位，由**形素**和**语素变体**实现；形式可以涉及零形式、异干互补、内部变化和蔓越莓语素。
- **屈折变化**为句法构成同一个词位的各种形式，组成**聚合**；**派生**构成新的词位。两者的界线是一个连续统。
- **能产性**是一个过程构成新词的程度（*-ness* 很高，*-th* 为零）；当已有一个意义相同的词时，**阻断**会阻止规则的构词形式（*thief*、*went*）。
- 词有**层级结构**；在英语中，最右边的成分通常是**中心词**。**第一类**词缀移动重音，位于**第二类**词缀之内，**括号悖论**是例外。
- 语言的类型从**孤立语**（汉语普通话）到**黏着语**（土耳其语）、**屈折语**（拉丁语）和**多式综合语**；英语混合了分析性的句法、融合性的屈折变化和拉丁语来源的派生。
- 普通话屈折变化很少，但有丰富的**复合**（联合、偏正、述宾、述补、主谓）、重叠和类词缀；在两种语言中，“词”都很难界定。
- **双路径**理论和**单一机制**理论竞相解释规则形式和不规则形式；频率保护不规则形式。
:::

## 习题

::: exercise 词形和词位 {level=1 check="3"}
*happy*、*happier*、*happiest*、*happiness*、*unhappy*、*unhappier* 代表多少个词位？
::: solution
**3** 个：HAPPY（*happy*、*happier*、*happiest*）、HAPPINESS 和 UNHAPPY（*unhappy*、*unhappier*）。比较级和最高级是屈折变化；*-ness* 和 *un-* 派生出新的词位。
:::
:::

::: exercise 零形式、异干互补还是内部变化？ {level=1}
说明每个形式怎样表达其语法意义：*geese*、*worse*、*deer*（复数）、*was*、*drove*、*fish*（复数）。
::: solution
- *geese*：内部变化（元音）。
- *worse*：异干互补（*bad* 的比较级）。
- *deer*（复数）：零形式。
- *was*：异干互补（*be* 的过去式，与 *be* 和 *is* 是不同的词根）。
- *drove*：内部变化。
- *fish*（复数）：零形式（*fishes* 也用，尤其是指不同种类的鱼）。
:::
:::

::: exercise 说出构词过程 {level=1}
说出构词过程的名称：*smog*、*to text*（来自名词）、*flu*、*to self-isolate*、*UN*、*to housekeep*。
::: solution
*smog*：拼缀（*smoke* + *fog*）。*to text*：转类。*flu*：截短（*influenza*）。*self-isolate*：复合（或者用组合形式 *self-* 加前缀）。*UN*：首字母缩略词。*to housekeep*：由 *housekeeper* 逆构词而来。
:::
:::

::: exercise 画出层次 {level=2}
仿照 *denationalisation* 的图示，按词缀加上的顺序展示 *unreadability* 和 *rethinkable* 的层次，并标出每一阶段的词类。其中有括号悖论吗？
::: solution
- *unreadability*：*read*（V）→ *readable*（A，*-able*）→ *unreadable*（A，*un-*）→ *unreadability*（N，*-ity*）。每一步的词类都很清楚，但 *-ity*（第一类）加在 *un-*（第二类）之外，正如 *ungrammaticality* 一样，所以按照第一类/第二类理论，它是一个括号悖论：意义需要 [ [un- [read -able] ] -ity ]，而层级顺序要求 *-ity* 在 *un-* 之内。
- *rethinkable*：*think*（V）→ *rethink*（V，*re-*）→ *rethinkable*（A，*-able*）。*Re-* 附加在动词上，*-able* 也附加在动词上，所以没有悖论；另一种顺序 ✗ *re-* + *thinkable* 行不通，因为 *re-* 不附加在形容词上。
:::
:::

::: exercise 能产不能产？ {level=2}
把下面的后缀按在现代英语中的能产性从高到低排列，并为每一个给出一条证据：*-th*（*warmth*）、*-ness*、*-ity*、*-ise/-ize*。
::: solution
大致是：*-ness*（几乎可以加在任何形容词上，包括新的形容词）、*-ise/-ize*（构成许多新动词，*prioritise*、*weaponise*、*monetise*）、*-ity*（仍在构成新词，但主要加在以 *-able*、*-al*、*-ic* 结尾的拉丁语来源词基上：*walkability*）、*-th*（没有新构词；*coolth* 是开玩笑的说法）。*-ness* 和 *-ize* 的排名可能因语域和语料库而不同；最清楚的证据是在一个大型的新近语料库中，带有各个后缀的词里单现词所占的比例。
:::
:::

::: exercise 汉语复合词 {level=2}
用朱德熙的类型（联合、偏正、述宾、述补、主谓）给下面每个普通话复合词分类，并给出最接近的英语对应词：毕业、黑板、改善、买卖、头疼、打破。
::: solution
- 毕业（“毕”完成 +“业”学业）：述宾——*graduate*。
- 黑板（“黑”+“板”）：偏正——*blackboard*（在英语中也是修饰语–中心词型）。
- 改善（“改”改变 +“善”好）：述补——*improve*。
- 买卖（“买”+“卖”）：联合——*business, trade*。
- 头疼（“头”+“疼”）：主谓——*headache*（在英语中是修饰语–中心词型复合词：一种疼痛）。
- 打破（“打”+“破”）：述补——*break, smash*。

注意“毕业”也是离合词：毕了业。

::: exercise 设计你自己的 wug 测试 {level=3}
仿照伯科（1958）的方式设计四个测试项目，以了解一个儿童（或成年学习者）是否掌握了（a）复数的 /ɪz/ 语素变体，（b）过去式 *-ed*，（c）表示施事者的派生后缀 *-er*，（d）所有格 *-'s*。按照测试者会说的话写出每个项目，并给出预期的答案及其读音。
::: hint
生造一些符合英语音位配列的词，并选择它们的末尾音，使正确的语素变体可以预测。
:::
::: solution
范例项目（任何对等的一组项目都可以）：

（a）*This is a tass. Now there are two of them. There are two …*——*tasses* /ˈtæsɪz/。词基以 /s/ 结尾，所以必须用 /ɪz/。（伯科发现儿童在这个形式上远不如在其他形式上可靠，许多孩子只是重复 *tass*。）

（b）*This man knows how to spow. He is spowing. He did the same thing yesterday. What did he do yesterday? Yesterday he …*——*spowed* /spəʊd/（通用英式发音），/spoʊd/（通用美式发音），元音之后用 /d/。

（c）*This woman zibs every day. She's a very good …*——*zibber* /ˈzɪbə/（通用英式发音），/ˈzɪbər/（通用美式发音）。

（d）*This is a niz who owns a hat. Whose hat is it? It is the …*——*niz's hat* /ˈnɪzɪz/。

每个项目都使用一个无意义的词基，使答案不可能是记住的，并用一个句子框架使所要求的形式显得自然。
:::
:::

::: exercise 它是一个词吗？ {level=3}
写150–200词，讨论英语的 *ice cream* 和普通话的“睡觉”是不是单个的词。至少使用三条标准（例如拼写、重音、可分离性、意义、各部分能否分别受修饰）。
::: solution
一篇范文：

*Neither case is decided by one criterion. English* ice cream *is written as two words, but spelling is a convention: we write* bookshop *as one word and* book club *as two, though their structure is the same. In stress,* ice cream *is variable — many speakers stress* ice*, as in a compound, and some stress* cream*. Its parts cannot be modified separately: ✗* icy cream *and ✗* ice delicious cream *do not mean ‘ice cream’, and its meaning is more specific than ‘cream with ice’. By these criteria it behaves as one word, a compound noun. Mandarin* 睡觉 *passes some tests for a word: its meaning ‘sleep’ is not simply ‘sleep + feel’, and it is listed in dictionaries. But it can be separated:* 睡了一个好觉 *puts an aspect marker and a modified object between its parts, as a verb–object phrase would. Linguists therefore call such forms separable words (*离合词*): they are words in the lexicon and phrases in the syntax. The comparison shows that "word" must be defined by explicit criteria, which may disagree.*
