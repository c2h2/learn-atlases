索菲娅走进公寓。她脸通红，头发湿漉漉的，大口喘着气。

**Her flatmate:** *What have you been doing?*（你干什么去了？）

**Sofia:** *I've been running. I've run ten kilometres!*（我去跑步了。我跑了十公里！）

索菲娅在两句话里用了现在完成时的两种形式。*I've been running* 描述的是一个在一段时间里一直持续到现在的**活动**；它的迹象——通红的脸、湿漉漉的头发——现在看得见。*I've run ten kilometres* 描述的是一个**结果**：一段已经跑完、可以计数的距离。两句都和所有的现在完成形式一样，从现在看过去。区别又一次在于体：进行形式还是一般形式。

这一课讲**现在完成进行时**的形式和用法，以及 *I've read* 和 *I've been reading* 之间的选择。它以 [[tense-and-aspect/present-perfect]]（完成体：从现在看）和 [[tense-and-aspect/simple-and-progressive]]（进行体：从内部看，正在进行）为基础。

## 形式

::: definition 现在完成进行时 {#def-ppp}
**现在完成进行时**（present perfect progressive，也叫 present perfect continuous）由 *have/has* + ***been*** + ***-ing*** 形式构成：*I have been waiting*、*she has been working*。它把现在时、完成体和进行体结合在一起。它把一个**活动表现为在一段一直延续到现在的时间里正在进行**：这个活动可能仍在继续，也可能刚刚停止。
:::

| | 陈述句 | 否定句 | 疑问句 |
|---|---|---|---|
| *I*、*you*、*we*、*they* | *I've been waiting.*（我一直在等。） | *I haven't been waiting long.*（我没等多久。） | *Have you been waiting long?*（你等了很久吗？） |
| *he*、*she*、*it* | *It's been raining.*（一直在下雨。） | *It hasn't been raining.*（没有下过雨。） | *Has it been raining?*（下过雨了吗？） |

这个形式按 [[tense-and-aspect/time-tense-aspect#rule-verb-phrase]] 中的顺序构成：表示完成的 *have* 在前，后面跟过去分词（*been*）；表示进行的 *be* 随后，后面跟 *-ing* 形式。说话时助动词要弱读：*I've been waiting* 听起来像 /aɪv bɪn ˈweɪtɪŋ/（GB），*been* 常读 /bɪn/ 而不是 /biːn/。在美式英语中，*been* 在所有位置上通常都读 /bɪn/。

## 意义和用法

::: theorem 现在完成进行时的用法 {#rule-ppp-uses}
现在完成进行时用于：

1. **在过去开始、现在仍在进行的活动**，通常与 *for*、*since*、*How long…?*、*all day*、*all morning* 连用：*I'**ve been waiting** for forty minutes.*（我已经等了四十分钟了。）*How long **have** you **been learning** Chinese?*（你学中文多久了？）*It'**s been raining** all day.*（下了一整天雨。）
2. **刚刚停止、现在有看得见的结果的活动**，常常不带时间词语：*Your eyes are red. **Have** you **been crying**?*（你眼睛红红的。你哭过了吗？）*Sorry about the mess — I'**ve been painting**.*（对不起，弄得这么乱——我一直在刷油漆。）*The ground is wet. It'**s been raining**.*（地是湿的。刚才下过雨。）
3. **到现在为止重复的或暂时的活动**，常与 *lately*、*recently*、*these days* 连用：*I'**ve been sleeping** badly lately.*（我最近睡得不好。）*She'**s been going** to yoga classes since January.*（她从一月起一直在上瑜伽课。）*We'**ve been eating** out a lot recently.*（我们最近经常在外面吃饭。）
:::

::: proof
完成体把参照时间放在现在，把事件放在它之前或一直延续到它；进行体从内部表现事件，把它看作一个有持续时间、不一定完成的活动（[[tense-and-aspect/simple-and-progressive#def-progressive]]）。两者合起来，就得到“在一段一直延续到现在的时间里进行的活动”。在用法1中，活动延续到现在并且还在继续。在用法2中，活动几乎延续到现在，它的痕迹还在；听话人感兴趣的是活动，而不是结果。在用法3中，活动是在一段延续到现在的时间里重复发生的一连串事件，进行体加上了“这是暂时的”这层意思。夸克等（1985）和斯旺（Swan，2016）描述了同样的三种用法。
:::

- *The phone **has been ringing** for ages — aren't you going to answer it?*（电话响了半天了——你不接吗？）
- *I'**ve been thinking** about what you said.*（我一直在想你说的话。）
- *We'**ve been trying** to call you all afternoon!*（我们一下午都在给你打电话！）
- *Ahmed **has been working** at the airport since he left school.*（艾哈迈德毕业以后一直在机场工作。）

::: example 根据迹象判断 {#ex-evidence}
对每种情况，用现在完成进行时说出这些人一直在做什么。(a) 文的手上沾满了面粉。(b) 两个孩子拿着足球进来，鞋上全是泥。(c) 科菲的眼睛很疲倦，桌上到处都是文件。(d) 路是湿的，到处都是水坑。
::: solution
(a) *She's been baking*（她一直在烤东西）（或 *She's been making dumplings*“她一直在包饺子”）。

(b) *They've been playing football.*（他们一直在踢足球。）

(c) *He's been working / studying / reading all day.*（他工作／学习／看书看了一整天。）

(d) *It's been raining.*（刚才一直在下雨。）

每种情况中，活动都刚刚停止（或者仍在进行），我们现在能看到它的影响。这是用法2。这里用现在完成时的一般形式听起来就不对：✗ *She's baked* 对手上的面粉什么也没说；它宣布的是一个结果（*She's baked a cake*“她烤好了一个蛋糕”——就在这里）。
:::
:::

::: quiz
*Sorry I'm late. Have you been waiting long?*（对不起我来晚了。你等了很久吗？）说话人为什么用现在完成进行时？
- [ ] 因为等待已经结束，属于过去。
- [x] 因为等待是一个在一段一直延续到现在的时间里进行的活动。
- [ ] 因为 *wait* 是状态动词。
- [ ] 因为有一个表示已经结束的时间的词语。
::: solution
听话人从过去某个时候起一直等到现在：这是在一段延续到现在的时间里进行的活动（用法1）。*Wait* 是活动，不是状态，所以用进行形式很自然。如果有一个已经结束的时间（*Did you wait long yesterday?*“你昨天等了很久吗？”），就用一般过去时。
:::
:::

## *I've read* 还是 *I've been reading*？

两种形式都把过去和现在联系起来。问题在于说话人想谈什么。

::: theorem 现在完成时的一般形式还是进行形式 {#rule-simple-or-progressive}
1. 用**一般**形式表示**已经完成的结果**，尤其是说出**多少**的时候：*I've read three chapters.*（我读了三章。）*She's written two reports this week.*（她这个星期写了两份报告。）*They've painted the kitchen*（他们把厨房刷好了）（已经完成）。
2. 用**进行**形式表示**活动**本身，尤其是说出**多久**的时候：*I've been reading all morning.*（我读了一上午书。）*She's been writing reports all week.*（她这一个星期都在写报告。）*They've been painting the kitchen*（他们一直在刷厨房）（也许还没刷完）。
3. **状态动词**用**一般**形式，即使与 *for*、*since* 和 *How long…?* 连用：*I've known her for years*（我认识她好多年了），不说 ✗ *I've been knowing her*。*How long have you had this bike?*（这辆自行车你买了多久了？），不说 ✗ *have you been having*。
4. ***live***、***work***、***study***、***teach***、***stay*** 和 ***wait*** 与 *for*、*since* 连用时，两种形式都可以，区别很小：*I've lived / I've been living here for five years.*（我在这里住了五年了。）进行形式可以暗示情况更具暂时性。
:::

::: proof
这条规则来自两种体的意义。一个数字（*three chapters*、*two reports*）计算的是完整的单位，所以需要把事件表现为完整的形式：一般形式。一段时间（*all morning*）从内部衡量活动，所以适合用进行形式。状态没有“正在进行”的阶段（[[tense-and-aspect/simple-and-progressive#rule-states]]），所以即使它持续到现在，也仍用一般形式。对 *live*、*work* 这样的动词来说，情况既可以看作状态（我住在哪里），也可以看作活动（我在做什么），所以两种形式都正确；斯旺（2016）和墨菲（Murphy，2019）给出的规则相同。
:::

| 一般形式：结果，多少 | 进行形式：活动，多久 |
|---|---|
| *I've read your book. It's great!*（我读完你的书了。写得真好！）（我读完了） | *I've been reading your book.*（我一直在读你的书。）（还没读完） |
| *She's phoned ten customers.*（她已经给十个客户打了电话。） | *She's been phoning customers all morning.*（她一上午都在给客户打电话。） |
| *I've cleaned the car.*（我把车洗干净了。）（车现在是干净的） | *I've been cleaning the car.*（我一直在洗车。）（所以我身上这么脏） |
| *How many cups of coffee have you drunk?*（你喝了几杯咖啡了？） | *How long have you been drinking coffee?*（你喝咖啡多久了？） |
| *I've known Liu Yang since 2010.*（我从2010年起就认识刘洋。）（状态） | ——（*know* 不用进行形式） |

::: example 一般形式还是进行形式？ {#ex-simple-progressive}
选择更好的形式并说明理由。(a) *I (have written / have been writing) emails since nine o'clock. I've (written / been writing) twenty-five.*（我从九点起一直在写电子邮件。已经写了二十五封了。）(b) *Someone (has eaten / has been eating) my chocolate — there's none left!*（有人把我的巧克力吃了——一点儿都不剩了！）(c) *Someone (has eaten / has been eating) my chocolate — there's only half of it left.*（有人一直在偷吃我的巧克力——只剩一半了。）(d) *How long (have you had / have you been having) that cough?*（你咳嗽多久了？）(e) *My sister (has been learning / has learned) to drive for six months, but she still can't park.*（我姐姐学开车学了六个月了，可还是不会停车。）
::: solution
(a) *have been writing*——活动，与 *since* 连用；*written*——一个数字，所以是结果：*I've written twenty-five.*

(b) *has eaten*——完成了：全吃光了（结果）。

(c) *has been eating*——活动在进行，没有完成；剩下的一半就是证据。（也可以说 *has eaten some of*。）

(d) *have you had*——这里 *have a cough* 是一种状态；用一般形式是正常的。

(e) *has been learning*——在六个月里进行的活动，还没有完成（她还不会停车）。*Has learned to drive* 的意思是她现在会开车了。
:::
:::

::: warning 与 *for* 和 *since* 连用时用现在进行时或一般现在时
✗ *I'm waiting for you for an hour!* ✓ *I've been waiting for you for an hour!*（我等了你一个小时了！）

✗ *She studies English since 2019.* ✓ *She's been studying English since 2019.*（她从2019年起一直在学英语。）（或 *She's studied …*）

✗ *How long are you living in Beijing?* ✓ *How long have you been living in Beijing?*（你在北京住了多久了？）

在过去开始、现在仍在继续的情况需要完成形式。现在时的形式对现在之前的时间什么也没说。
:::

::: warning 与数字或状态连用时用进行形式
✗ *I've been drinking four cups of tea.* ✓ *I've drunk four cups of tea.*（我已经喝了四杯茶。）

✗ *I've been knowing him since primary school.* ✓ *I've known him since primary school.*（我从小学起就认识他。）

✗ *We've been having this flat for two years.* ✓ *We've had this flat for two years.*（这套公寓我们已经有两年了。）

若干个已经完成的单位需要一般形式。状态动词（*know*、表示拥有的 *have*、*believe*、*like*）保持一般形式。
:::

### 否定和持续时间

在谈论一段延续到现在的时间的否定句中，一般形式更常见：*I **haven't seen** her for ages.*（我好久没见到她了。）*We **haven't had** a holiday since 2022.*（我们从2022年起就没有休过假。）否定的进行形式用于一个不再是习惯的活动：*I **haven't been sleeping** well*（我最近一直睡得不好）（= 最近睡眠一直很差）。

::: example 从一般过去时到现在完成时 {#ex-transform}
现在是下午4点。用现在完成时的一般形式或进行形式，以及 *for* 或 *since*，把每组句子改写成一个句子。(a) *Lina started cooking at 1 p.m. She is still cooking.*（莉娜下午1点开始做饭。她现在还在做。）(b) *Lina has cooked four dishes. She started at 1 p.m.*（莉娜已经做了四个菜。她是下午1点开始的。）（问：多少？）(c) *Jamal met Ana in 2018. They are still friends.*（贾迈勒2018年认识了安娜。他们现在仍然是朋友。）(d) *It started snowing on Monday. It hasn't stopped.*（星期一开始下雪。到现在还没停。）
::: solution
(a) *Lina has been cooking since 1 p.m.*（莉娜从下午1点起一直在做饭。）（或 *for three hours*“做了三个小时”）——活动，多久。

(b) *Lina has cooked four dishes since 1 p.m.*（莉娜从下午1点起已经做了四个菜。）——若干个完成了的单位：一般形式。

(c) *Jamal and Ana have been friends since 2018.*（贾迈勒和安娜从2018年起就是朋友。）（或 *Jamal has known Ana since 2018.*“贾迈勒从2018年起就认识安娜。”）——*be friends* 和 *know* 是状态：一般形式。

(d) *It has been snowing since Monday.*（从星期一起一直在下雪。）——延续到现在的活动，与 *since* 连用。
:::
:::

::: example 在医生那里的一段对话 {#ex-doctor}
读这段对话，说明每一个现在完成形式的理由。

**Doctor:** *What seems to be the problem?*（您哪里不舒服？）

**Mr Okafor:** *I've been getting headaches. I've had three this week.*（我最近老是头疼。这个星期已经疼了三次了。）

**Doctor:** *How long have you been feeling like this?*（这种感觉有多久了？）

**Mr Okafor:** *About a month. I've been working very long hours since I started my new job.*（大约一个月了。自从开始新工作以来，我一直工作到很晚。）

**Doctor:** *Have you taken anything for the pain?*（您吃过什么止痛的药吗？）

**Mr Okafor:** *I've tried some painkillers, but they haven't helped much.*（我试过一些止痛药，但没什么用。）
::: solution
1. *I've been getting headaches*——到现在为止重复的活动（用法3）。
2. *I've had three*——若干个完整的事件，所以用一般形式。
3. *have you been feeling*——*feel* 表示身体感觉，所以可以用进行形式，而且医生问的是活动持续的时间（*How long*）。*How long have you felt like this?* 也正确。
4. *I've been working … since I started*——延续到现在的活动，与 *since* + 一般过去时分句连用。
5. *Have you taken anything*——一个已经完成的动作（到现在为止的任何时候），它的结果很要紧。
6. *I've tried*、*haven't helped*——到现在为止的结果：止痛药没有让他好起来。
:::

哪个句子是正确的？

- [ ] *I've been buying three new shirts today.*
- [x] *I've been trying to call you all day.*
- [ ] *I'm living here since last year.*

*Try to call*（试着打电话）是一个在延续到现在的时间里（*all day*）重复的活动：用进行形式。*Know* 是状态（*I've known Mei for ten years*“我认识小梅十年了”）；*three new shirts* 是若干次已经完成的购买（*I've bought three new shirts*“我买了三件新衬衫”）；延续到现在的情况需要完成形式（*I've been living / I've lived here since last year*“我从去年起就住在这里”）。

::: note 英汉对比
- **“一直”和“了……了”。** 汉语表示一直持续到现在的活动，通常用“一直”，或者用一段时间加两个“了”：“我一直在等你”或“我等了你半个小时了”。英语需要用现在完成进行时：*I've been waiting for you (for half an hour).* 用现在进行时直接翻译（✗ *I'm waiting for you half an hour*）就丢掉了“延续到现在的这段时间”。
- **“一直在”是最接近的对应。** 汉语可以把“一直”和“在”结合起来（他一直在找工作），这与 *He's been looking for a job* 非常接近。但汉语没有一个与 *have been* + *-ing* 相对应的单一形式；这个意思是由几个词合在一起表达的。
- **“刚才”和迹象。** “你刚才在跑步吗？”问的是片刻之前的一个活动。英语可以用过去进行时（*Were you running just now?*），如果现在看得见迹象，也可以用现在完成进行时：*Have you been running?* 当你看着一张通红的脸时，第二种说法更自然。
- **结果和数量。** “我看了三章”是 *I've read three chapters*（如果有已经结束的时间，就是 *I read three chapters*），而不是 ✗ *I've been reading three chapters*。汉语用数字和“了”表示数量；英语用一般形式表示完成。
- **又是状态动词。** “我认识他十年了”是 *I've known him for ten years*。因为“认识”不加“在”，学习者很少说 ✗ *I'm knowing him*；但他们常常类推其他动词，在 *have been* 之后加上进行形式。先检查动词。
:::

::: history
完成体与进行体的结合，是在两者各自都已存在之后才发展起来的。奥托·叶斯柏森（Otto Jespersen）在他的《现代英语语法》（*Modern English Grammar*）第四部分（1931）中，把进行形式称为**扩展时态**（expanded tenses），并把它们描述为把一个较短的事件放进一个较长的“时间框架”中的形式。在他的描述中，完成进行形式是完成形式的扩展形式：一个被看作一直延续到现在的框架的活动。语料库研究表明这种形式有多么专门化。拜伯等（Biber et al.，1999）发现，与一般形式相比，结合了完成体和进行体的动词短语在每一种语域中都很少见；它们最常出现在会话和小说中，用于人们解释自己一直在做什么。对学习者来说，这意味着这种形式并不常用，但一旦需要它——*I've been waiting for an hour!*（我已经等了一个小时了！）——别的形式都代替不了。
:::

## 后续学习

过去完成进行时（*I had been waiting for an hour when the bus came*“公共汽车来的时候，我已经等了一个小时了”）是从过去某一点看的同样结构，属于 [[tense-and-aspect/narrative-tenses]] 的内容。将来完成进行时（*By June I'll have been working here for ten years*“到六月我在这里工作就满十年了”）出现在 [[tense-and-aspect/future-forms]] 中。[[tense-and-aspect/tense-and-chinese]] 把汉语的手段——“一直”“在”、两个“了”——与英语的形式放在一起比较。

::: summary
- 现在完成进行时是 *have/has been* + *-ing*：*I've been waiting*（[[#def-ppp]]）。
- 它表示在一段延续到现在的时间里进行的活动：仍在继续（*for*、*since*、*How long…?*），刚刚停止并有看得见的结果（*Have you been crying?*），或者最近一再发生（*I've been sleeping badly*）（[[#rule-ppp-uses]]）。
- 已经完成的结果以及**多少**用一般形式（*I've read three chapters*），活动以及**多久**用进行形式（*I've been reading all morning*）（[[#rule-simple-or-progressive]]）。
- 状态动词保持一般形式：*I've known her for years*，而不是 ✗ *I've been knowing*。
- *Live*、*work*、*study*、*teach*、*stay* 和 *wait* 与 *for*、*since* 连用时两种形式都可以。
- 延续到现在的情况需要完成形式：不说 ✗ *I'm waiting for an hour*；汉语用“一直”“在”和两个“了”等几个词合起来表达这个意思。
:::

## 习题

::: exercise 构成现在完成进行时 {level=1}
(a) *I / wait / for you* (b) *she / study / all evening* (c) *it / rain / since Monday* (d) *they / not work / very hard* (e) *you / run?*（疑问句）
::: solution
(a) *I've been waiting for you.*（我一直在等你。）(b) *She's been studying all evening.*（她学习了一晚上。）(c) *It's been raining since Monday.*（从星期一起一直在下雨。）(d) *They haven't been working very hard.*（他们一直不太努力。）(e) *Have you been running?*（你刚才一直在跑步吗？）
:::
:::

::: exercise *How long* 还是 *how many*？ {level=1}
用 *How long* 或 *How many* 完成疑问句。(a) *___ have you been waiting?*（你等了多久了？）(b) *___ books have you read this year?*（你今年读了几本书？）(c) *___ have you lived in this city?*（你在这座城市住了多久了？）(d) *___ times have you called her?*（你给她打了几次电话了？）
::: solution
(a) *How long*；(b) *How many*；(c) *How long*；(d) *How many*。
:::
:::

::: exercise 活动还是结果？ {level=1}
说出每个句子谈的是活动（A）还是结果（R）。(a) *I've been cleaning the kitchen.*（我一直在打扫厨房。）(b) *I've cleaned the kitchen.*（我把厨房打扫干净了。）(c) *She's been writing her essay.*（她一直在写论文。）(d) *She's written her essay.*（她写完论文了。）
::: solution
(a) A；(b) R（厨房现在是干净的）；(c) A（也许还没写完）；(d) R（写完了）。
:::
:::

::: exercise 一般形式还是进行形式？ {level=2}
用现在完成时的一般形式或进行形式填空。(a) *I'm tired. I ___ (drive) for six hours.*（我累了。我已经开了六个小时车了。）(b) *We ___ (drive) 500 kilometres today.*（我们今天已经开了500公里了。）(c) *How long ___ you ___ (know) Mr Tanaka?*（你认识田中先生多久了？）(d) *Look at your hands! What ___ you ___ (do)?*（看看你的手！你干什么了？）(e) *I ___ (lose) my phone. Have you seen it?*（我的手机丢了。你看见了吗？）(f) *She ___ (teach) at this school since 2012.*（她从2012年起就在这所学校教书。）
::: solution
(a) *'ve been driving*；(b) *'ve driven*；(c) *have you known*（状态）；(d) *have you been doing*；(e) *'ve lost*（结果；不是活动）；(f) *has taught* 或 *has been teaching*（*teach* 与 *since* 连用时两者都正确）。
:::
:::

::: exercise 一直在发生什么？ {level=2}
用现在完成进行时写一个句子，解释每种情况。(a) *Amira is out of breath.*（阿米拉上气不接下气。）(b) *The kitchen smells of cake.*（厨房里有蛋糕的香味。）(c) *Ben's English has improved a lot.*（本的英语进步了很多。）（用 *recently*）(d) *Your phone battery is almost empty.*（你的手机快没电了。）
::: solution
可能的答案：(a) *She's been running / climbing the stairs.*（她刚才一直在跑步／爬楼梯。）(b) *Someone's been baking.*（有人一直在烤东西。）(c) *He's been practising a lot recently.*（他最近一直在大量练习。）（或 *He's been watching English films.*“他一直在看英语电影。”）(d) *You've been using it all day.*（你用了一整天了。）（或 *You've been playing games on it.*“你一直在用它玩游戏。”）
:::
:::

::: exercise 改正错误 {level=2}
改正有错误的句子。(a) *I'm learning English for six years.* (b) *I've been finishing my homework.*（意思是：作业已经做完了）(c) *She's been having a headache since this morning.* (d) *They've been waiting since two hours.* (e) *It's been snowing all night.*
::: solution
(a) *I've been learning English for six years.*（我学英语已经六年了。）(b) *I've finished my homework.*（我做完作业了。）(c) *She's had a headache since this morning.*（她从早上起就一直头疼。）（*have a headache* 是状态）(d) *They've been waiting for two hours.*（他们已经等了两个小时了。）(e) 正确。（下了一整夜雪。）
:::
:::

::: exercise 翻译 {level=3}
把下列句子译成英语。(a) 我等了你一个小时了！(b) 他最近一直在找工作。(c) 我今天已经写了五封邮件。(d) 你哭了吗？你的眼睛红红的。(e) 我们认识二十年了。(f) 我学中文学了三年了，可是还说得不好。
::: hint
对每个句子问：是活动还是结果？是状态动词吗？这段时间是否延续到现在？
:::
::: solution
(a) *I've been waiting for you for an hour!*（延续到现在的活动）

(b) *He's been looking for a job recently.*（或 *lately*）（到现在为止反复进行的活动）

(c) *I've already written five emails today.*（一个数字：一般形式；*today* 还没过完）

(d) *Have you been crying? Your eyes are red.*（现在看得见的迹象）

(e) *We've known each other for twenty years.*（状态）

(f) *I've been learning Chinese for three years, but I still can't speak it well.*（延续到现在的活动；*I've learned Chinese for three years* 不太自然，因为学习还没有完成）
:::
:::

::: exercise 写一条消息 {level=3}
你已经两个月没给一个朋友写信了。写一条消息（80–120词），告诉他你一直在做什么，以及做完了什么。至少用三个现在完成进行时的动词和三个现在完成时一般形式的动词，*for* 和 *since* 至少各用一次。
::: solution
答案因人而异。示例：

*Hi Sam, sorry I haven't written for so long! I've been working really hard since I started my new job in September. I've also been taking driving lessons, and I passed my test last week — finally! What else? I've been reading a lot on the train, and I've finished four novels this month. My brother has been staying with me for three weeks, so the flat is a bit crowded. I've visited my parents twice, and they say hello. What have you been doing? Write soon!*

**译文：**嗨，萨姆，对不起，好久没给你写信了！自从九月开始新工作，我一直干得非常辛苦。我还一直在学开车，上星期终于通过了考试！还有什么呢？我在火车上一直读了不少书，这个月已经读完了四本小说。我弟弟在我这儿住了三个星期了，所以公寓有点挤。我去看了父母两次，他们向你问好。你最近在忙什么？快回信！

检查：延续到现在的活动用现在完成进行时（*'ve been working*、*'ve been taking*、*'ve been reading*、*has been staying*、*have you been doing*）；结果、数字和否定用现在完成时的一般形式（*haven't written*、*'ve finished four novels*、*'ve visited … twice*）；已经结束的时间用一般过去时（*passed … last week*、*started in September*）；*for* + 一段时间，*since* + 一般过去时分句。
:::
