硕士课程的第一周，陈雨（Chen Yu）收到了一门课的阅读书目：三章教科书、两篇综述和十一篇研究论文，共约350页，要在三周内讨论完。如果按她读英语课本的速度来读——仔细地读每一个句子，每个生词都查——要花的时间会远远超过三周。没有人指望她这样读。这门课上没有人把所有东西都精读；能应付过来的学生，是那些针对每篇语篇决定自己需要从中得到什么、为此必须读多少的人。

本章讲的就是这些决定。它说明如何在阅读之前**概览**（survey）一篇语篇，如何把它的结构变成**问题**，如何为每一部分选择精读、略读还是跳过，以及如何应对一份长长的阅读书目——先读哪些、怎样找到更多、怎样记录。本章建立在 [[reading-skills/reading-with-a-purpose]] 中的三种阅读方式和 [[academic-reading/academic-texts]] 中的学术语篇地图之上。这些都不能代替精读：它们的目的是确保把精读用在重要的页面上。

## 有计划地阅读

::: definition 策略性阅读 {#def-strategic-reading}
**策略性阅读**（strategic reading）就是有计划地阅读：读者决定**为什么**读一篇语篇、需要从中得到**什么**，并据此决定读**哪些部分**、读得**多仔细**，并在阅读过程中和读完之后检查需要是否得到了满足。它的主要阶段是**概览**语篇、**设问**、**有选择地阅读**和**复习**。
:::

学术阅读的目的比日常阅读更多样。学生读一篇语篇，可能是为了：

- 在听讲座之前或选择论文题目之前获得一个话题的**概览**；
- **回答一个问题**：关于 X 已知些什么，Y 通常怎样测量，Z 在中国有没有人研究过；
- 深入**理解一个概念或方法**，因为后面的学习要依靠它；
- 为研讨课或批判性评论**评价**一项研究或一个论证；
- 寻找可以在自己的写作中引用的**证据和来源**。

每种目的需要不同的阅读方式。获得概览需要把一篇综述从头到尾略读一遍；评价一项研究需要慢慢地读它的方法和结果；寻找来源需要浏览参考文献列表。先决定目的，正是大多数缺乏经验的读者跳过的一步。

::: theorem 让任务决定深度 {#rule-depth}
对每一篇语篇，以及一篇长文的每一部分，从三种深度中选一种：

1. **精读**能回答你的问题、或你必须评价或引用的部分：每一句都读，并做笔记。
2. **略读**提供背景的部分：各段的第一句、标题、图表及其说明文字。
3. **跳过**这项任务不需要的部分，并记下你跳过了它们，以便任务改变时可以回来读。

开始之前就作决定，阅读过程中再加以调整。大多数学术语篇都是在不同的部分同时以这三种深度来读的。
:::

::: proof
阅读时间有限，而理解要花时间：关于阅读速度的研究表明，速度和准确性之间存在此消彼长的关系，那些号称能大大提高阅读速度而又完全理解的技巧并没有得到证据支持（Rayner et al. 2016）。因此读者不可能什么都精读，必须有所选择。这样选择是安全的，因为学术语篇的组织方式使它的各部分可以分开阅读（[[academic-reading/academic-texts#rule-imrad-questions]]）：不读文献回顾也能判断一项研究的方法，不看统计数字也能找到主要发现。莫提默·艾德勒（Mortimer Adler）在《如何阅读一本书》（*How to Read a Book*，与查尔斯·范多伦〔Charles Van Doren〕合著的修订版，1972）中也说过同样的道理：**检视阅读**（inspectional reading）——对全书快速而系统的浏览——在对值得细读的内容进行缓慢的**分析阅读**（analytical reading）之前。只有当读者在知道某一部分的内容之前就把它跳过时，这条规则才会失效；这就是为什么概览要放在最前面。
:::

## 概览一篇语篇

::: definition 概览 {#def-survey}
**概览**（survey，也叫 preview）一篇语篇，就是在阅读之前快速浏览它的整体结构，以便了解它讲什么、怎样组织，以及你需要的信息可能在哪里。概览一篇论文通常需要五到十五分钟；一本书要稍长一些。
:::

::: theorem 概览时看什么 {#rule-survey}
1. **标题和作者信息**：话题、领域、日期——以及这篇语篇对你的目的来说是否足够新。
2. **摘要**，或一本书的前言和目录页。
3. **标题和小标题**：论证的框架。
4. **引言**（特别是最后一段）和**结论**。
5. **图和表**及其说明文字：它们常常承载着主要结果。
6. 看起来相关的部分中**每段的第一句**。
7. **参考文献列表**：有多长，有多新，哪些名字反复出现。

最后，用一两句话说出这篇语篇主张什么，以及你要精读哪些部分。
:::

下面是对一章虚构教科书概览的开头。它的目录是：

> *Chapter 6: Language and Memory. 6.1 What is working memory? 6.2 Measuring working memory span. 6.3 Working memory and reading in a first language. 6.4 Working memory and second-language learning. 6.5 Can working memory be trained? Summary. Review questions. Further reading.*

本章小结的开头是：*Working memory is a limited system for holding and manipulating information over short periods. Its capacity differs between individuals and is related to reading comprehension in both first and second languages. Training programmes improve performance on the tasks that are trained, but there is little evidence that the improvement transfers to reading or other skills.*

::: example 把概览变成问题 {#ex-survey-questions}
你在写一篇题为 *What helps adults learn a second language?*（什么有助于成年人学习第二语言？）的论文。只利用上面的目录和小结，(a) 决定本章哪些小节精读、略读或跳过，(b) 写出你阅读时要回答的问题。
::: solution
**先定目的。** 这篇论文讨论的是成年人的第二语言学习，所以这一章只有在工作记忆与之相关的地方才重要。

**(a) 深度。**
- 6.1 *What is working memory?* ——**略读**：你需要定义（很可能是一个黑体术语或在一个方框里），但不需要每个细节。
- 6.2 *Measuring working memory span* ——**略读**或**跳过**：只有当你要讨论测量它的研究时才有用。
- 6.3 *Working memory and reading in a first language* ——**略读**：背景。
- 6.4 *Working memory and second-language learning* ——**精读**：这一节回答你的问题。
- 6.5 *Can working memory be trained?* ——**精读**：如果训练不能迁移（如小结所说），这对一篇讨论什么有助于学习者的论文来说是有用的论点。
- 复习题和延伸阅读——**寻读**延伸阅读，找关于第二语言学习的来源。

**(b) 问题。** 把标题变成问题，再让它们针对论文的题目：
- *What is working memory, in one sentence I can cite?*
- *How strongly is working memory related to second-language learning, and in which skills?*
- *If working memory differs between people, what can learners with a smaller span do?*
- *What is the evidence that training working memory does or does not help language learning?*

这些问题把阅读变成寻找答案，并且立刻表明6.4节的哪些部分是重要的。
:::
:::

::: quiz
你在概览一篇研究论文，以决定它是否与你的论文相关。在概览阶段，下面哪一项用处**最小**？
- [ ] 摘要
- [ ] 标题和图的说明文字
- [x] 对统计分析的详细描述
- [ ] 引言的最后一段
::: solution
概览看的是能表明语篇讲什么、怎样组织的部分。统计细节属于对方法部分的精读，那是后来的事，而且只有在论文确实相关时才需要。
:::
:::

## 设问

读者为回答自己提出的问题而阅读时，理解得更多，也记得更牢。这一思想是最古老的著名学习方法的核心。

::: definition SQ3R {#def-sq3r}
**SQ3R** 是弗朗西斯·P·罗宾逊（Francis P. Robinson）在《有效学习》（*Effective Study*，1946）中描述的一种学习教科书的方法。它的五个步骤是：

1. **概览**（Survey）这一章：标题、小结、图表；
2. **提问**（Question）：把每个标题变成一个问题；
3. **阅读**（Read）每一节以回答它的问题；
4. **复述**（Recite）：不看书，说出或写出答案；
5. **复习**（Review）：最后再把问题和答案过一遍，过些时候再回头看。
:::

这一方法的价值不在于这五个字母，而在于其中的两个思想。第一是**为寻找答案而读**：像 *Causes of the 1929 crash* 这样的标题变成 *What caused the 1929 crash?*，读者去找原因，而不是以同样的注意力读每一个句子。第二是**不看书回忆**。邓洛斯基等人（Dunlosky et al.，2013）在一篇关于学习技巧的大型综述中，把**练习测试**（practice testing，即像*复述*这一步那样努力回忆信息）和**分散练习**（distributed practice，即间隔一段时间复习）评为效用最高的技巧，而把**重读**（rereading）和**画重点**（highlighting）评为效用低的技巧。把一章重读两遍的学生可能觉得内容很熟悉，但熟悉并不等于能够回忆和运用。

::: warning 用画重点代替阅读
✗ 把每一页的大部分都画上重点，然后在研讨课之前重读画过的内容。

✓ 为回答一个问题读一节，合上书，用自己的几句话写出答案；只标出陈述主张的那个句子和关键证据。

画重点让人觉得自己在用功，但它把“什么重要”的决定推迟了：如果半页纸都是黄色的，就等于什么也没有选。邓洛斯基等人（2013）发现，几乎没有证据表明按学生通常的用法画重点能促进学习。如果你要在语篇上做标记，就要少标、有目的地标——在页边用符号表示*主张*、*证据*、*定义*、*不同意*——并在旁边用自己的话写一条简短的笔记。这一方法在 [[academic-reading/notes-and-summaries]] 中展开讲解。
:::

## 有选择地阅读

有选择地阅读并不是粗心地阅读。它讲究的是在**哪里**仔细。对同一篇研究论文，一个要评价这项研究的学生和一个要找背景的学生，会以不同的深度读不同的部分：

| 部分 | 为了获得话题概览 | 为了评价这项研究 | 为了引用主要发现 |
|---|---|---|---|
| 摘要 | 精读 | 精读 | 精读 |
| 引言 | 略读；读对早期研究的回顾以找来源 | 略读；精读空白和目的 | 略读；读目的 |
| 方法 | 跳过或略读 | 精读 | 略读：设计和样本 |
| 结果 | 略读图和表 | 精读 | 精读主要结果 |
| 讨论 | 读第一段和最后一段 | 精读，特别是局限 | 读第一段和局限 |
| 参考文献 | 浏览寻找有用的来源 | 核查关键引用 | — |

::: example 为三项任务选择深度 {#ex-three-tasks}
一篇（虚构的）论文报告了一项对五所大学900名学生的调查，内容是他们在学习中如何使用生成式人工智能工具。说出在下列每项任务中你会精读哪些部分：(a) 你需要一个最近的统计数字，用在你那篇关于教育中的人工智能的论文的引言里；(b) 你要在研讨课上介绍这篇论文，必须评论它的优点和不足；(c) 你在计划就同一话题做自己的调查。
::: solution
**(a) 一个统计数字。** 精读摘要，在结果中**寻读**你需要的数字；读方法部分，读到足以在引用时正确描述样本（*a survey of 900 students at five universities*）并核查问题是怎样提的就够了。其余大部分跳过。

**(b) 研讨课上的评价。** 精读**方法**（大学和学生是怎样选的？究竟问了他们什么？回答是匿名的吗？），精读**结果**（数字支持那些主张吗？），以及**讨论**，特别是局限。略读引言以了解目的。

**(c) 计划自己的调查。** 最仔细地读**方法**——问卷、抽样、数据怎样分析——并在附录或补充材料中找问卷本身。讨论局限的那一段告诉你作者会在哪些方面换一种做法，这对你自己的设计很有价值。

同一篇论文，三种不同的读法：目的决定了深度（[[#rule-depth]]）。
:::
:::

## 应对阅读书目

::: theorem 读完一份阅读书目 {#rule-reading-list}
1. **分拣**（triage）：对每一项做简短的概览，按当前任务把它们分为*必读*、*有用*和*选读*。
2. **按概括程度的顺序读**：先读教科书的章节或综述，再读研究论文，这样总体图景会让具体研究更容易读懂。
3. 在每一组内**先读新的再读旧的**，除非一篇较早的语篇是人人都引用的经典；新的语篇会概括此前的研究。
4. **顺着参考文献找**：从一篇有用的语篇出发，**向后**看它引用的来源，**向前**看引用了它的后来的语篇（引文数据库和学术文献搜索引擎会显示这些）。
5. **做阅读记录**：每篇语篇记下完整的参考文献信息、阅读日期、阅读深度，以及两三行关于它主张什么、你能用什么的笔记。
:::

::: proof
分拣把一份不可能读完的书目变成可以应付的书目：必读的各项分配到时间，选读的各项做一次概览，在记录里写一行。从概括到具体的阅读顺序把综述对这一领域的概括当作背景知识，正是这一点使专业的研究论文变得可读。新的语篇有后见之明的优势；而一篇所有新语篇都引用的旧语篇，通常正因为如此而值得一读。向后和向前追踪参考文献——有时叫做**滚雪球**（snowballing）——比关键词检索更可靠地找到与手头这篇联系最紧密的语篇。阅读记录之所以重要，是因为大多数学生几周之内就会忘记哪篇论文说了什么；当时做的记录可以省去重读，而且保存了引用所需的细节（[[academic-reading/paraphrase-and-quotation]]）。
:::

::: example 给阅读书目分拣 {#ex-triage}
为了写一篇题为 *Should primary schools teach handwriting or typing first?*（小学应该先教手写还是先教打字？）的论文，一位学生找到了以下（虚构的）材料。把它们分为必读、有用和选读，并给出阅读顺序。(1) 一篇2022年关于手写与早期读写能力研究的综述。(2) 一项1995年的研究，考察儿童在练习手写或打字之后的字母辨认，后来的大多数研究都引用它。(3) 一项2020年的实验，比较大学生用手和用笔记本电脑做笔记。(4) 一份说明小学必须教什么的国家课程文件。(5) 一项2019年的研究，考察7岁儿童在上了一年打字课之后的拼写。(6) 一位教师的博客文章，认为手写已经过时。
::: solution
**必读：** (1)，综述——它提供概览，并引出其他研究；(5)，一项直接针对这个年龄段和这个问题的研究；(4)，因为论文讨论的是学校应该教什么，而课程文件表明学校现在教什么。

**有用：** (2)，那篇被大量引用的较早研究：在综述之后读，综述会说明它为什么重要，以及后来的研究是否证实了它。

**选读：** (3)——大学生做笔记与幼儿学写字是不同的问题；可以审慎地提到它，但它不是关于小学的证据。(6)——博客文章是观点，不是研究；它也许能提供一个可供讨论的观点实例，但不是证据的来源。

**顺序：** (1) 综述 → (5) → (2) → (4) → 时间允许再读 (3) 和 (6)。在记录中，这位学生为 (3) 注明它的研究对象与论文话题不同，以免忘记这一点。
:::
:::

::: quiz
一位学生找到了一篇2023年的论文，正好是她的话题。找到其他密切相关语篇的最快而可靠的方法是什么？
- [ ] 再用同样的关键词检索一次
- [x] 看它引用的语篇和后来引用它的语篇

:::

## 词汇和速度

第二语言读者还要多作一个决定：遇到生词怎么办。除了英语中最常用的词，学术语篇还包含三类词汇：

- **学术词汇**（academic vocabulary）：在许多学科中常见、但在日常英语中不常用的词——*analyse*、*concept*、*significant*、*derive*、*framework*、*hypothesis*。最著名的描述是**学术词汇表**（Academic Word List，Coxhead 2000），包括570个词族，选自一个约350万词的学术语篇语料库，语篇来自四大领域（文科、商科、法律和理科）。考克斯黑德报告说，这些词族约占她的学术语料库中形符的10%，而在小说中所占比例要小得多，这就是为什么为了学术阅读值得及早学习它们。学术词汇及其词表在 [[collocation-and-register/academic-vocabulary]] 中讲授。
- **专业词汇**（technical vocabulary）：某一领域的术语——*working memory*、*ozone*、*heteroskedasticity*——通常在教科书和术语表中有定义，随学科本身一起学习。
- 恰好出现在某篇语篇中的**低频词**。

对每一类的策略不同。把学术词汇作为一个整体来学，因为它会在每门学科中反复出现。为你的领域建立一份专业术语表，附上教科书中的定义，因为它们会在这一领域的每篇语篇中反复出现。对低频词则按 [[reading-skills/words-from-context]] 的方法处理：如果这个词不是关键，就根据上下文猜；只有当它的意思对你的问题很重要时才去查。

阅读速度是另一个限制。学术语篇读得比小说慢，密集的方法部分读得更慢；这很正常，并不说明英语差。有两样东西能让学术阅读更快而不降低理解：背景知识（这就是为什么要先读综述和教科书），以及对这一体裁的词汇和结构的熟悉，而这种熟悉随着每读一篇论文而增长。

::: example 一周的阅读计划 {#ex-week-plan}
本章开头提到的陈雨这周有六个小时用于这门课的第一个专题：两章教科书（每章约30页）、一篇综述（18页）和四篇研究论文（每篇12–20页）。研讨课的问题是：*What explains the gap in reading achievement between children from richer and poorer families?*（如何解释富裕家庭和贫困家庭儿童在阅读成绩上的差距？）写一份计划。
::: solution
**第1步——分拣和概览（1小时）。** 把七篇语篇各概览约八分钟：摘要或小结、标题、图表、结论。把它们分类；判断出有一篇研究论文讨论的是另一个年龄段（选读），两章教科书内容重叠（精读一章，略读另一章）。

**第2步——概览话题（1½小时）。** 以混合的深度读较相关的那一章教科书，把标题变成问题；精读综述的引言、结论和讨论差距成因的部分，略读其余部分。

**第3步——研究论文（2½小时）。** 对三篇相关的研究论文，精读摘要、引言中的研究目的、结果中的图表和讨论；对综述称为最有力的那项研究，还要精读方法部分，以便能对它作出评论。

**第4步——复习（1小时）。** 不看材料，用五行字写出研讨课问题的答案，每一点注明来源；对照阅读记录检查；记下两个要在研讨课上提出的问题。

这份计划把大部分时间花在能回答研讨课问题的地方，并为以后的论文留下了记录。它是一份计划，而不是无论发生什么都要照办的时间表：如果综述表明某篇论文是核心，计划就要改变。
:::
:::

::: note 英汉对比
- **精读和泛读。** 许多中国学习者在学校里就知道两种阅读方式：精读（intensive reading，逐句阅读，每个词和每个结构都要讲解）和泛读（extensive reading）。策略性阅读在同一篇语篇中两者兼用——重要的部分精读，其余的略读。需要改掉的习惯是把整篇研究论文当作精读课文来读。
- **用中文读背景。** 读一本中文教科书或综述来快速了解一个新领域，是一种合理的策略，也能让英文语篇更容易读。但你写作时需要的是英文术语，而它们并不总是一一对应：阅读时要做一份两栏的术语表（英文术语、中文术语、英文定义）。
- **翻译放在最后一步。** 把一段话译成中文可以帮你弄懂一个难句，但作为读一份阅读书目的方式，它太慢了，而且会掩盖英语中标示重点的结构。先用英语为寻找答案而读；只翻译你仍然读不懂的部分。
- **书目中的中文来源。** 在许多话题上都有英文阅读书目所忽略的中文研究。它们可能很有价值，但要弄清你的课程是否希望你引用它们，以及怎样引用（通常是给出翻译后的标题，并在括号里附上原标题）。
:::

::: history
高效阅读教科书的方法始于20世纪上半叶，当时美国的大学迅速发展，开始教授学习技能。俄亥俄州立大学的心理学家弗朗西斯·P·罗宾逊在《有效学习》（1946）中描述了 SQ3R，其依据是战时为必须在短时间内学会大量内容的军事学员开设的课程。莫提默·艾德勒的《如何阅读一本书》（1940）面向普通读者；他与查尔斯·范多伦合写的修订版（1972）提出了阅读的四个层次，从基础阅读、检视阅读、分析阅读到主题阅读（syntopical reading）——把同一主题的几本书放在一起读，这与文献综述所做的事很接近。2013年，约翰·邓洛斯基（John Dunlosky）及其同事综述了关于学生常用的十种学习技巧的研究，他们得出的结论——自我测试和间隔练习的效果远远好于重读和画重点——自那以后一直影响着有关学习的建议。
:::

## 下一步

本章的概览和设问通向对句子的精读（[[academic-reading/dense-sentences]]）和对论证的精读（[[academic-reading/claims-and-evidence]]）。阅读时记下什么，是 [[academic-reading/notes-and-summaries]] 的主题。从作者的角度检索和选择来源，在 [[academic-writing/finding-sources]] 中讲授；用阅读书目来规划论文，在 [[essay-writing/writing-process]] 中讲授。

::: summary
- **策略性阅读**意味着决定为什么读一篇语篇、需要从中得到什么，以及哪些部分读得多仔细（[[#def-strategic-reading]]）。
- 为每一部分选择**精读、略读或跳过**——任务决定深度（[[#rule-depth]]）。
- 先**概览**：标题、摘要、标题和小标题、引言和结论、图表、各段首句、参考文献（[[#rule-survey]]）。
- 把标题变成**问题**，为回答问题而读；不看书回忆比重读或画重点更有效（Dunlosky et al. 2013）。
- 应对阅读书目的方法是：**分拣**，**先概括后具体**、**先新后旧**地读，向后和向前**追踪参考文献**，并做**阅读记录**（[[#rule-reading-list]]）。
- 把**学术词汇**作为一个整体来学（学术词汇表：570个词族，Coxhead 2000），专业术语随学科一起学，低频词按普通阅读的方法处理。
:::

## 习题

::: exercise 精读、略读还是跳过 {level=1}
你的任务是弄清一项（虚构的）研究是怎样测量学生的压力的。对论文的每一部分，说出精读、略读还是跳过：(a) 摘要；(b) 引言；(c) 方法部分的 *Measures* 小节；(d) 结果；(e) 致谢。
::: solution
(a) 精读（它可能说出了测量工具的名称）；(b) 略读（只看目的）；(c) 精读——测量工具就是在这里描述的；(d) 略读，或者跳过，除非你需要知道这一测量工具的表现如何；(e) 跳过。
:::
:::

::: exercise 把标题变成问题 {level=1}
把每个教科书标题变成一个你可以为回答它而阅读的问题。(a) *The causes of urban flooding* (b) *Advantages and limitations of online surveys* (c) *Photosynthesis in low light* (d) *The 1978 economic reforms*
::: solution
可能的问题：(a) *What causes flooding in cities?* (b) *What are the advantages of online surveys, and what are their limitations?* (c) *How does photosynthesis change when there is little light?* (d) *What were the 1978 economic reforms, and what did they change?* 任何这一节很可能会回答的问题都可以接受；问 *why* 和 *how* 的问题比只问 *what* 的问题能引出更有用的阅读。
:::
:::

::: exercise 哪一类词汇？ {level=1}
在一篇地理学论文中，把每个词归类为学术词汇（A）、本领域的专业词汇（T）或高频通用词（G）。(a) *analyse* (b) *permafrost* (c) *significant* (d) *river* (e) *precipitation* (f) *framework*
::: solution
(a) A；(b) T；(c) A；(d) G；(e) T（在地理学和气象学中，它是指雨、雪等的专业术语“降水”；在通用英语中它还有别的意思）；(f) A。有些词处于学术词汇和专业词汇的交界处——这很正常，分类的意义在于学习策略，而不在于标签。
:::
:::

::: exercise 概览并概括 {level=2}
下面是对一篇虚构论文进行概览所得的信息。写两句话：这篇论文主张什么，以及如果你的论文题目是 *how cities can reduce heat in summer*（城市如何在夏季降温），你会精读哪些部分。

> *Title: Cool roofs and street temperatures: evidence from a summer field study. Abstract (last sentence): Roofs painted with reflective coatings lowered nearby street-level air temperatures by a small but measurable amount on the hottest afternoons. Headings: 1 Introduction 2 Study area and methods 3 Results 3.1 Roof surface temperature 3.2 Street air temperature 3.3 Indoor temperature 4 Discussion 5 Conclusions.*
::: solution
一个好的答案：*The article claims that reflective roof coatings slightly lowered air temperatures in nearby streets on the hottest afternoons. For an essay on reducing heat in cities, I would read sections 3.2 and 3.3 and the Discussion closely, and the methods enough to know where and for how long the study was done.*（3.1可以略读：屋顶表面温度是通向街道炎热问题的一步，而不是对它的回答。）
:::
:::

::: exercise 排列阅读书目 {level=2}
为了写一篇题为 *Does bilingualism affect children's attention?*（双语会影响儿童的注意力吗？）的论文，把下列虚构材料排成合理的阅读顺序，并说出哪一项是选读：(1) 一篇2017年的研究论文，报告了一项有80名双语儿童和80名单语儿童参加的实验；(2) 一篇2022年关于双语与注意力研究的综述，报告说结果不一；(3) 一项2004年的研究，常被说成是这一研究方向的起点；(4) 一篇2021年的报纸文章，报道说“speaking two languages makes children smarter”（说两种语言让孩子更聪明）。
::: solution
先读 (2) 综述——它提供概览，并解释为什么结果不一；接着读 (3)，作为综述会讨论的经典研究；然后读 (1)，一项具体的近期研究，读时要记着综述提出的批评。(4) 是选读：它不是研究来源，它的标题很可能超出了证据（*smarter* 并不等于 *better attention*）。它也许可以用作研究在媒体中被如何报道的一个例子。
:::
:::

::: exercise 复述，不要重读 {level=2}
把本章“设问”一节读一遍。合上书，用三句话写出：SQ3R 是什么，本章说它的哪两个思想最有价值，以及邓洛斯基等人（2013）关于重读和画重点有什么发现。然后对照课文检查你的答案。
::: solution
参考答案：*SQ3R is a method for studying textbooks described by Robinson in 1946: survey, question, read, recite, review. Its most valuable ideas are reading to answer questions and recalling the answers without looking. Dunlosky et al. (2013) rated practice testing and spaced practice as highly useful, but rereading and highlighting as of low utility.* 这道题的要点在于方法：凭记忆写下来再检查，本身就是*复述*这一步。
:::
:::

::: exercise 一份阅读计划 {level=3}
选一个你正在学习的话题，或者用 *the effects of remote work on productivity*（远程工作对生产率的影响）。（在图书馆数据库或学术文献搜索引擎中）找一篇关于它的综述和三篇研究论文。为每一篇记下完整的参考文献信息，概览它，并写两行说明它主张什么以及你会精读哪些部分。然后像 [[#ex-week-plan]] 那样，写一份在五小时内读完它们的计划。
::: hint
每条参考文献都要在数据库本身中核实；不要从你没有核实过的摘要或列表中抄参考文献。
:::
::: solution
答案取决于找到的语篇。好的答案有完整且经过核实的参考文献，为每篇语篇写出一两句话的主张，而且这是语篇自己的主张（不是其引言中的背景），有理有据地选择阅读深度，计划把综述放在最前面，并在最后留出复习的时间。差的答案把每篇语篇都从头读到尾，或者列出了自己没有核实过其主张的语篇。
:::
:::

::: exercise 滚雪球 {level=3}
从你觉得有用的一篇论文出发，(a) 列出它引用的三篇看起来相关的语篇，并根据它们被引用的方式说明理由（在引言中？在讨论中？作为一种方法？）；(b) 用引文数据库或学术搜索引擎找到两篇引用了它的后来的语篇，说出每一篇补充了什么。像本章的图那样，把这五篇语篇和原文画成一张小地图。
::: solution
答案取决于所选的论文。好的答案说明*为什么*每篇被引用的语篇看起来相关——例如*在讨论中被引用三次，是作者不同意的主要研究*，或*在方法中被引用，是问卷的来源*——并判断后来的语篇是证实、扩展还是挑战了原文。地图应该用箭头从引用的语篇指向被引用的语篇。注意到你的两篇语篇引用了同一篇较早的研究，就说明它是这一领域的核心。
:::
:::
