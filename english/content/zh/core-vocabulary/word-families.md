看看下面四个句子：

- *We need to **decide** today.*（我们今天需要做决定。）
- *It was a difficult **decision**.*（那是一个艰难的决定。）
- *She is a **decisive** leader.*（她是一位果断的领导人。）
- *I'm still **undecided**.*（我还没拿定主意。）

如果你认识 *decide*，即使从没见过另外三个词，你多半也能看懂它们。它们有一个共同的部分 *decide*（或 *decis-*），而它们的结尾和开头也能告诉你一些信息：*-ion* 构成名词，*-ive* 构成形容词，*un-* 表示“不”。像这样以同一个基础词构成的一组词，叫作一个**词族**。

词族之所以重要，有两个原因。第一，它让学习更省力：把一个成员学好了，其他成员就容易得多。这就是词汇量研究按词族计数的原因（[[core-vocabulary/frequency-and-coverage]]）。第二，它帮助你正确使用英语：在句子中担任不同的成分时，英语常常需要不同的形式，而汉语可以用同一个形式。“决定”在“我们决定了”里是动词，在“这个决定”里是名词，但英语需要 *decide* 和 *decision* 两个词。本章说明词族是怎样构成的，哪些词尾表示哪种词类，以及怎样利用词族学得更快。

## 什么是词族？

::: definition 词族 {#def-word-family}
**词族**（word family）是一个基础词加上它的**屈折形式**和常见的**派生形式**。例如，*care*（关心）的词族包括 *cares*、*cared*、*caring*（屈折形式）和 *careful*、*carefully*、*careless*、*carelessly*（派生形式）。
:::

这两类词族成员的构成方式不同。

::: definition 屈折变化和派生 {#def-inflection-derivation}
**屈折变化**（inflection）是加上一个表示语法意义（例如复数、过去时或比较）的词尾，并不构成新词：*book* → *books*，*walk* → *walked*，*tall* → *taller*。**派生**（derivation）是加上一个**前缀**（prefix）或**后缀**（suffix）构成新词，新词常常有新的意义或新的词类：*happy* → *unhappy*，*happy* → *happiness*。
:::

英语只有八个规则的屈折词尾，在 [[core-grammar/word-classes]] 中都会遇到：

| 词尾 | 作用 | 例子 |
|---|---|---|
| *-s* | 名词复数 | *book* → *books* |
| *-'s* | 所有格 | *Tom* → *Tom's* |
| *-s* | 动词一般现在时第三人称单数 | *work* → *works* |
| *-ed* | 过去式 | *work* → *worked* |
| *-ed* / *-en* | 过去分词 | *work* → *worked*；*take* → *taken* |
| *-ing* | -ing 形式 | *work* → *working* |
| *-er* | 比较级 | *fast* → *faster* |
| *-est* | 最高级 | *fast* → *fastest* |

派生词缀则多得多。语言学家劳里·鲍尔（Laurie Bauer）和保罗·内申（Paul Nation）在1993年把它们分为七个等级，从最常用、最规则的（例如 *un-*、*-er*、*-ness*、*-less* 和 *-ly*）到少见、不规则的。本章不需要完整的清单；最有用的词缀列在下面的表里。《构词法》课程会详细讲解它们：[[word-formation/prefixes]] 和 [[word-formation/suffixes]]。

::: widget graph
nodes: decide@0,0; decides@-3,2; decided@-1,2; deciding@1,2; decision@-3,-2; decisive@0,-2; undecided@3,-2; decisively@-1.5,-4; indecisive@1.5,-4
edges: decide>decides; decide>decided; decide>deciding; decide>decision; decide>decisive; decided>undecided; decisive>decisively; decisive>indecisive
caption: *decide* 的词族。上面一行是屈折形式（同一个词的不同语法形式）；下面几行是派生形式（新词）。每个箭头表示“由……构成”。可以拖动这些词，重新排列词族。
:::

::: quiz
哪一组表示的是**派生**，而不是屈折变化？
- [ ] *play* → *played*
- [ ] *box* → *boxes*
- [x] *kind* → *kindness*
- [ ] *big* → *bigger*
::: solution
*-ness* 由形容词 *kind*（友好的）构成一个新词——名词 *kindness*（友好）：这是派生。其他几组只是加上屈折词尾（过去式、复数、比较级），仍是同一个词。
:::
:::

## 表示词类的词尾

关于后缀，最有用的知识是它们通常构成哪种词类。遇到一个新词时，它的词尾常常能告诉你它是名词、形容词、动词还是副词——由此你就知道它在句子中怎样用。

::: theorem 常见后缀及其构成的词类 {#rule-suffix-class}
下列后缀通常构成表中所示的词类。

| 词类 | 后缀 | 例子 |
|---|---|---|
| 名词 | *-tion*、*-sion*、*-ment*、*-ness*、*-ity*、*-ance*、*-ence*、*-er*、*-or*、*-ist* | *information*（信息）、*decision*（决定）、*payment*（付款）、*kindness*（友好）、*ability*（能力）、*distance*（距离）、*difference*（差别）、*teacher*（教师）、*actor*（演员）、*artist*（艺术家） |
| 形容词 | *-ful*、*-less*、*-ous*、*-al*、*-ive*、*-able*、*-ible*、*-y*、*-ic* | *useful*（有用的）、*careless*（粗心的）、*dangerous*（危险的）、*national*（国家的）、*active*（积极的）、*comfortable*（舒服的）、*possible*（可能的）、*sunny*（晴朗的）、*economic*（经济的） |
| 动词 | *-ize*（英式英语常作 *-ise*）、*-en*、*-ify* | *organize*/*organise*（组织）、*widen*（加宽）、*simplify*（简化） |
| 副词 | *-ly*（加在形容词后） | *quickly*（快速地）、*carefully*（仔细地）、*happily*（快乐地） |

这是一个很强的倾向，而不是绝对的规则：*-ly* 也构成一些形容词（*friendly* 友好的、*lovely* 可爱的、*lonely* 孤独的），*-al* 也构成一些名词（*arrival* 到达、*refusal* 拒绝）。
:::

::: proof
这些词尾是随着带有它们的词进入英语的——其中许多来自法语和拉丁语（*-tion*、*-ity*、*-ous*、*-able*），另一些来自古英语（*-ness*、*-ful*、*-less*、*-ly*）。由于每个词尾都出现在许多同一词类的词里，它就成了这一词类的标志。例外之所以存在，是因为每个词都有自己的历史。*Friendly* 来自一个古老的形容词词尾，意思是“像……的”，它与副词词尾 *-ly* 同源，所以 *-ly* 在一些词里表示形容词，在另一些词里表示副词。学习型词典总会标出词类（[[core-vocabulary/using-a-dictionary]]）。
:::

::: quiz
下面哪个以 *-ly* 结尾的词是**形容词**，而不是副词？
- [ ] *quickly*
- [x] *friendly*
- [ ] *happily*
- [ ] *carefully*
::: solution
*Friendly* 是形容词：*a friendly dog*（一条友好的狗），*She is very friendly.*（她很友好。）它没有自己的副词形式；我们说 *in a friendly way*（以友好的方式）。另外三个是由形容词 *quick*、*happy* 和 *careful* 构成的副词。其他以 *-ly* 结尾的形容词还有 *lovely*、*lonely*、*ugly*（丑的）和 *elderly*（年长的）。
:::
:::

::: example 哪个形式适合填空？ {#ex-which-form}
用 *success* / *succeed* / *successful* / *successfully* 这一词族中的正确成员完成句子，并说明你是怎样选择的。

1. *She is a very ___ businesswoman.*（她是一位非常成功的女商人。）
2. *Hard work is the key to ___.*（努力是成功的关键。）
3. *If you practise, you will ___.*（只要你练习，你就会成功。）
4. *The team ___ finished the project.*（这个团队成功地完成了项目。）
::: solution
看空格在句子中担任什么成分。

1. 在 *very* 和名词 *businesswoman* 之间：需要一个形容词。→ *successful*（*-ful* 构成形容词）。
2. 在介词 *to* 之后，*the key to …*：需要一个名词。→ *success*。
3. 在 *will* 之后：需要动词原形。→ *succeed*。
4. 在主语 *The team* 和动词 *finished* 之间：需要一个副词来说明“怎样”。→ *successfully*（形容词加 *-ly*）。

完整答案：*She is a very successful businesswoman. Hard work is the key to success. If you practise, you will succeed. The team successfully finished the project.*
:::
:::

::: warning 用错了词族成员
中国学习者常常知道正确的词族，却选错了成员，因为对应的汉语词形式不变。

- ✗ *I am very success.* ✓ *I am very successful.*（我非常成功。）
- ✗ *We must protection the environment.* ✓ *We must protect the environment.*（我们必须保护环境。）
- ✗ *He speaks English very fluent.* ✓ *He speaks English very fluently.*（他英语说得很流利。）
- ✗ *It is important to make a decide.* ✓ *It is important to make a decision.*（做出决定很重要。）

听的人通常能听懂，但句子听起来不对。说出或写下这个词之前，先问自己：句子的这个位置需要名词、动词、形容词还是副词？
:::

## 改变意义的前缀

前缀通常不改变词类，而是改变意义。有少数几个前缀非常常用，值得早学。

| 前缀 | 意义 | 例子 |
|---|---|---|
| *un-* | 不；做相反的动作 | *unhappy*（不高兴的）、*unusual*（不寻常的）；*unlock*（开锁）、*undo*（解开，撤销） |
| *in-*、*im-*、*il-*、*ir-* | 不 | *incorrect*（不正确的）、*impossible*（不可能的）、*illegal*（违法的）、*irregular*（不规则的） |
| *dis-* | 不；相反 | *dislike*（不喜欢）、*disagree*（不同意）、*dishonest*（不诚实的） |
| *re-* | 再，重新 | *rewrite*（重写）、*rebuild*（重建）、*reopen*（重新开放） |
| *mis-* | 错误地 | *misunderstand*（误解）、*misspell*（拼错） |
| *pre-* | 预先 | *preview*（预览）、*prepay*（预付） |
| *over-* | 过度 | *oversleep*（睡过头）、*overcooked*（煮过头的） |

*im-*、*il-* 和 *ir-* 是 *in-* 在某些字母前的变体：*im-* 用在 *p*、*b*、*m* 前（*impossible*、*imbalance* 不平衡、*immature* 不成熟的），*il-* 用在 *l* 前（*illegal*），*ir-* 用在 *r* 前（*irregular*）。这条规则不能用来随意造新词——构成新形容词时 *un-* 要常用得多——但它有助于你认出这些词。

::: example 根据构成部分猜新词 {#ex-guess-parts}
李伟读到：*The story was so unbelievable that nobody trusted him.*（这个说法太难以置信了，没有人相信他。）他不认识 *unbelievable*。他怎样才能弄清它的意思？
::: solution
他把这个词拆成几部分：

- *un-* =“不”
- *believe* = 相信（他认识的词）
- *-able* =“能被……的”（构成形容词：*washable*“可洗的”）

所以 *unbelievable* =“不能被相信的”，即“难以置信的”。上下文也吻合：*nobody trusted him*（没有人相信他）。注意拼写的变化：*believe* 末尾的 *e* 在 *-able* 前去掉了。[[word-formation/spelling-changes]] 讲解这些变化。
:::
:::

::: quiz
*rewrite* 是什么意思？
- [ ] 写得不好
- [x] 重写
- [ ] 不写
- [ ] 预先写
::: solution
*Re-* 表示“再，重新”，所以 *rewrite* 的意思是“重写”（常常是为了写得更好）。“写得不好”要用 *mis-*；“预先写”要用 *pre-*。
:::
:::

## 词族内部的读音和拼写

词族成员的读音不一定相同。加上后缀时，重音可能移动，元音也可能改变。对听者来说，这是词族中最难的部分之一。

| 词 | GB | GA | 重音 |
|---|---|---|---|
| *photograph*（照片） | /ˈfəʊtəɡrɑːf/ | /ˈfoʊtəɡræf/ | 第一个音节 |
| *photography*（摄影） | /fəˈtɒɡrəfi/ | /fəˈtɑːɡrəfi/ | 第二个音节 |
| *photographic*（摄影的） | /ˌfəʊtəˈɡræfɪk/ | /ˌfoʊtəˈɡræfɪk/ | 第三个音节 |
| *economy*（经济） | /ɪˈkɒnəmi/ | /ɪˈkɑːnəmi/ | 第二个音节 |
| *economic*（经济的） | /ˌiːkəˈnɒmɪk/ | /ˌiːkəˈnɑːmɪk/ | 第三个音节 |

两个有用的倾向：以 *-ic* 和 *-tion*/*-sion* 结尾的词，重音通常在词尾前面的那个音节上（*eCOnomic*、*phoTOgraphic*、*deCIsion*、*inforMAtion*）；以 *-graphy* 和 *-logy* 结尾的词，重音在 *-graphy* 或 *-logy* 前面的那个音节上（*phoTOgraphy*、*geOgraphy* 地理、*biOlogy* 生物学）。[[sounds-of-english/word-stress-basics]] 说明怎样听出和读出重音，《连贯语流》课程在 [[connected-speech/word-stress-patterns]] 中会再讲到它。

拼写也可能变化：*happy* → *happiness*（*y* 变成 *i*），*decide* → *decision*（*d* 变成 *s*），*begin* → *beginning*（辅音字母双写）。见 [[word-formation/spelling-changes]]。

::: example 制作词族表 {#ex-family-table}
为 *employ*（雇用）的词族制作一张表，包括名词、形容词和动词，并为每个词写一个例句。
::: solution
| 词 | 词类 | 意义 | 例句 |
|---|---|---|---|
| *employ* | 动词 | 给某人一份有报酬的工作 | *The factory employs 300 people.*（这家工厂雇用了300人。） |
| *employer* | 名词 | 提供工作的人或公司，雇主 | *My employer pays me every month.*（我的雇主每月给我发工资。） |
| *employee* | 名词 | 有这份工作的人，雇员 | *She is an employee of the bank.*（她是这家银行的职员。） |
| *employment* | 名词 | 有一份有报酬的工作，就业 | *Employment in the city has grown.*（这座城市的就业增加了。） |
| *unemployed* | 形容词 | 没有工作的，失业的 | *He has been unemployed since March.*（他从三月起就失业了。） |
| *unemployment* | 名词 | 没有工作的状态；失业人数 | *Unemployment fell last year.*（去年失业率下降了。） |

注意 *employer* / *employee* 这一对：*-er* 指做这个动作的人，*-ee* 指承受这个动作的人（还有 *trainer* 培训者 / *trainee* 受训者，*interviewer* 面试官 / *interviewee* 面试者）。
:::
:::

::: note 英汉对比
汉语里一个形式常常可以作名词、动词或形容词：决定、发展、幸福、成功。词类由词在句中的位置以及“的”“地”这样的小词来表示。英语也允许一些词不改变形式就改变词类——*work*、*love*、*answer* 和 *change* 都既可以是名词，也可以是动词。这叫**转类**（conversion），[[word-formation/conversion]] 会讲到它。但对大量英语词来说，词类是由词尾表示的：*develop* / *development*（发展），*happy* / *happiness* / *happily*（幸福），*succeed* / *success* / *successful*（成功）。所以学一个英语词时，也要学它的词族，并注意哪个词尾表示哪种词类。汉语里“地”能把形容词变成状语（快乐地）；英语里 *-ly* 起类似的作用（*happily*）。
:::

::: warning 形似而非的词族成员
有些词看起来像某个词族的成员，意思却不同。要分开来学。

- *hard*“困难的；努力地”—— *hardly*“几乎不”：*He hardly worked*（他几乎没干活）的意思是他干得很少，而不是他工作努力。✓ *He worked hard.*（他工作很努力。）
- *late*（迟的）—— *lately*“最近”：*I've been tired lately.*（我最近很累。）✗ *I arrived lately.* ✓ *I arrived late.*（我到晚了。）
- *near*（近的）—— *nearly*“几乎”：*I nearly missed the bus.*（我差点没赶上公共汽车。）
- *high*（高的）—— *highly*“非常；高度地”：*highly recommended*（极力推荐的）、*highly skilled*（技术高超的）。✓ *The bird flew high.*（鸟飞得很高。）
:::

## 借助词族学习

::: theorem 学整个词族，而不只是一个词 {#rule-learn-family}
学一个高频词时，也要学它词族中最常见的成员——通常是其他词类的一两个形式——并注意重音和拼写如何变化。遇到生词时，先看看里面有没有你已经认识的基础词和词缀，再去查词典。
:::

::: proof
阅读研究表明，如果学习者认识基础词和词缀，常常能认出一个新的词族成员，所以词族能让词汇量增长得更快（[[core-vocabulary/frequency-and-coverage]] 正是因此按词族计数）。但认得和会用是两回事（[[core-vocabulary/knowing-a-word]]）：学习者常常能看懂 *employment*，却还是说 ✗ *I am looking for an employ*。所以要在产出中使用，词族成员必须专门学习和练习，而不能只靠猜。而且猜词有局限：形似而非的成员（*hardly*、*lately*）以及意义不等于各部分相加的词（*understand*）必须根据上下文或查词典来确认。
:::

::: example 改正一段短文中的词类错误 {#ex-correct-text}
找出并改正这段话中的五个词类错误。

> *My city has changed a lot. Ten years ago, the streets were not very safety. Now there are many beauty parks, and people walk there happy in the evening. The government has done a lot of develop, and the air is clean. I think the change is very success.*

译文（按原意）：我的城市变化很大。十年前，街道不太安全。现在有许多美丽的公园，人们晚上在那里愉快地散步。政府做了很多发展工作，空气很干净。我认为这个变化非常成功。
::: solution
1. *not very safety* → *not very safe*——*very* 后面需要形容词；*safety*（安全）是名词。
2. *many beauty parks* → *many beautiful parks*——名词前需要形容词；*beauty*（美）是名词。
3. *walk there happy* → *walk there happily*——说明人们怎样散步需要副词。
4. *a lot of develop* → *a lot of development*（或 *a lot of work on development*）——*a lot of* 后面需要名词。
5. *very success* → *very successful*——*very* 后面需要形容词。

*The air is clean* 是正确的：*is* 后面用形容词 *clean* 没错。
:::
:::

::: history
把词族作为统计和教授词汇的单位，可以追溯到早期的词表。迈克尔·韦斯特（Michael West）的《通用英语词表》（*General Service List*，1953年）在每个词目下列出它常见的派生形式。劳里·鲍尔和保罗·内申的论文《词族》（"Word families"，1993年）使这个概念有了清晰的形式：按词缀的常用程度、规则程度和能产程度分为七个等级，使研究者能够准确说明哪些形式算作一个词族。内申后来的词频表（例如 Nation（2006）等研究中使用的词表）就是按这一方案建立的词族表。
:::

::: summary
- **词族**是一个基础词加上它的屈折形式（*decides*、*decided*）和常见的派生形式（*decision*、*decisive*、*undecided*）。
- **屈折变化**加上语法词尾，仍是同一个词；**派生**加上前缀或后缀，构成新词。
- 后缀通常表示词类：*-tion*、*-ment*、*-ness*、*-ity*（名词）；*-ful*、*-less*、*-ous*、*-al*、*-ive*、*-able*（形容词）；*-ize*/*-ise*、*-en*、*-ify*（动词）；*-ly*（副词）。这是一个很强的倾向，但有 *friendly* 这样的例外。
- 前缀通常改变意义而不改变词类：*un-*、*in-*/*im-*/*il-*/*ir-*、*dis-*“不”；*re-*“再”；*mis-*“错误地”。
- 词族内部重音和拼写可能变化：*PHOtograph*、*phoTOgraphy*、*photoGRAphic*。
- 汉语常常用一个形式表示几种词类；英语则常常需要不同的词族成员。选择词形之前，先看句子需要什么。
- 小心 *hardly* 和 *lately* 这样形似而非的词族成员。
:::

## 练习

::: exercise 屈折变化还是派生？ {level=1}
说出每一种变化是屈折变化还是派生。

1. *cat* → *cats*
2. *teach* → *teacher*
3. *clean* → *cleaned*
4. *possible* → *impossible*
5. *dark* → *darkness*
6. *small* → *smallest*
::: solution
1. 屈折变化（复数）。
2. 派生（新名词，“教书的人”）。
3. 屈折变化（过去式）。
4. 派生（意义相反的新形容词）。
5. 派生（新名词）。
6. 屈折变化（最高级）。
:::
:::

::: exercise 名词、动词、形容词还是副词？ {level=1}
根据词尾判断每个词的词类。

*kindness*、*careful*、*simplify*、*slowly*、*movement*、*dangerous*、*widen*、*ability*
::: solution
- 名词：*kindness*（*-ness*），*movement*（*-ment*），*ability*（*-ity*）。
- 形容词：*careful*（*-ful*），*dangerous*（*-ous*）。
- 动词：*simplify*（*-ify*），*widen*（*-en*）。
- 副词：*slowly*（*-ly*）。
:::
:::

*happy*、*possible*、*legal*、*agree*、*correct*、*regular*、*kind*、*honest*
::: solution

::: exercise 选择词族成员 {level=2}
用括号中词的正确形式完成句子。

1. *Thank you for your ___ (kind).*（谢谢你的好意。）
2. *Please drive ___ (careful) — the road is wet.*（请小心驾驶——路面是湿的。）
3. *The ___ (different) between the two cities is the weather.*（这两座城市的差别在于天气。）
4. *Can you ___ (explanation) this word to me?*（你能给我解释一下这个词吗？）
5. *It was a very ___ (use) meeting.*（那是一次很有用的会议。）
::: solution
1. *kindness*——*your* 后面需要名词。
2. *carefully*——副词说明怎样驾驶。
3. *difference*——*The* 后面需要名词。
4. *explain*——*Can you* 后面需要动词原形。
5. *useful*——在 *very* 和名词 *meeting* 之间需要形容词。（*Useless* 也合乎语法，但意思相反。）
:::
:::

::: exercise 有几个词族成员？ {level=2 check="5"}
下面这些词中，有几个属于 *nation*（国家，民族）的词族？*national*、*nature*、*international*、*nationality*、*nationally*、*native*、*nations*
::: hint
词族成员包含基础词 *nation*，再加上词缀。只是看起来相似的词，可能来自不同的基础词。
:::
::: solution
**5**个：*national*、*international*、*nationality*、*nationally*、*nations*。*Nature*（自然）和 *native*（本地的）在很久以前的拉丁语历史上和 *nation* 有关系，但在现代英语里它们是意义不同的词，认识 *nation* 的学习者无法由此推出它们的意思。词族表不收这两个词。
:::
:::

::: exercise Hard 还是 hardly？ {level=2}
选择正确的词。

1. *She studied (hard / hardly) for the exam and passed.*（她为考试努力学习，通过了。）
2. *It was so noisy that I could (hard / hardly) hear you.*（太吵了，我几乎听不见你说话。）
3. *Have you seen any good films (late / lately)?*（你最近看过什么好电影吗？）
4. *The train arrived (late / lately) again.*（火车又晚点了。）
::: solution
1. *hard*——“努力地”。
2. *hardly*——“几乎不”。
3. *lately*——“最近”。
4. *late*——“不准时，迟”。
:::
:::

::: exercise 自己制作词族表 {level=3}
从下面的词中选一个：*create*（创造）、*comfort*（安慰，舒适）、*act*（行动）、*friend*（朋友）。仿照 [[#ex-family-table]] 中 *employ* 的表，制作一张至少有四个成员的词族表，写出词类、简短的意义和一个例句。标出每个成员的重读音节。
::: hint
学习型词典常常在词条末尾列出派生形式，或者把它们作为相邻的独立词条。
:::
::: solution
以 *create* 为例：

| 词 | 词类 | 重音 | 例句 |
|---|---|---|---|
| *create* | 动词 | cre-ATE（/kriˈeɪt/） | *The company created 50 new jobs.*（这家公司创造了50个新工作岗位。） |
| *creation* | 名词 | cre-A-tion | *The creation of the park took two years.*（建造这个公园花了两年时间。） |
| *creative* | 形容词 | cre-A-tive | *She is a very creative designer.*（她是一位很有创造力的设计师。） |
| *creativity* | 名词 | cre-a-TIV-i-ty | *This job needs creativity.*（这份工作需要创造力。） |
| *creator* | 名词 | cre-A-tor | *He is the creator of a popular TV show.*（他是一档热门电视节目的创作者。） |

检查你的表：每个句子是否把成员用在了正确的位置上（*the* 后面用名词，名词前面或 *very* 后面用形容词，等等）。

::: exercise 改正段落 {level=3}
改正这段话中的词类错误。共有五处。

> *Learning English is not easy, but it is very importance. My teacher always says that daily practice is the key to succeed. I was very nervousness in my first lesson, but now I can speak more confident. I hope to be a fluently speaker one day.*

译文（按原意）：学英语不容易，但非常重要。我的老师总是说，每天练习是成功的关键。第一节课时我非常紧张，但现在我能更自信地说英语了。我希望有一天能成为一个说话流利的人。
::: solution
1. *very importance* → *very important*——*is very* 后面用形容词。
2. *the key to succeed* → *the key to success*——*the key to* 后面用名词。
3. *very nervousness* → *very nervous*——*was very* 后面用形容词。
4. *speak more confident* → *speak more confidently*——副词说明我怎样说。
5. *a fluently speaker* → *a fluent speaker*——名词前用形容词。

*Daily practice* 是正确的：这里的 *practice* 是名词，英式英语和美式英语都这样用。改正后的版本：

> *Learning English is not easy, but it is very important. My teacher always says that daily practice is the key to success. I was very nervous in my first lesson, but now I can speak more confidently. I hope to be a fluent speaker one day.*

译文：学英语不容易，但非常重要。我的老师总是说，每天练习是成功的关键。第一节课时我非常紧张，但现在我能更自信地说英语了。我希望有一天能成为一个说英语流利的人。
:::
