星期一晚上，刘洋从一张单词表上学了三十个新词。他一遍又一遍地读这张表，直到能说出每个词的意思。他确信自己已经会了。到了星期五，老师进行了一次小测验，他只记得九个。

每个学习者都有过这样的经历。这并不说明刘洋的记性不好，而是说明他的学习方法——在一个晚上把单词表读很多遍——是记住单词效果最差的方法之一。从19世纪80年代到今天，关于记忆的研究清楚地表明了什么是有效的：**自我测试**而不是重读，以及把练习**分散**到几天、几个星期中，而不是一次做完。本章说明我们为什么会遗忘，什么能帮助记住单词，怎样制作和使用单词卡，以及怎样安排每天的学习。没有哪种方法能不费力气就让单词留住，也没有哪一种安排适合所有人；但有些努力的回报要比另一些高得多。

## 我们为什么会遗忘

::: definition 遗忘曲线 {#def-forgetting-curve}
**遗忘曲线**（forgetting curve）是一张显示所学内容随着时间推移还记得多少的图。学习之后不久遗忘得最快，然后逐渐变慢。
:::

最早对遗忘进行仔细测量的是德国心理学家艾宾浩斯（Hermann Ebbinghaus），他把结果发表在《论记忆》（*Über das Gedächtnis*，1885年）一书中。他学习一些无意义音节组成的表（例如 *DAX* 和 *BOK*），等待不同的时间，然后测量重新学习同一张表时**节省**了多少时间。他的结果是：

| 学习后经过的时间 | 节省率（重新学习时节省的时间） |
|---|---|
| 20分钟 | 约58% |
| 1小时 | 约44% |
| 1天 | 约34% |
| 6天 | 约25% |
| 31天 | 约21% |

大部分遗忘发生在最初的几个小时和第一天里；此后，遗忘就慢得多了。艾宾浩斯只测试了他自己，但他的主要结果被一次又一次地重复发现。2015年，雅普·穆雷（Jaap Murre）和约里·德罗斯（Joeri Dros）仔细地重复了他的实验，得到了一条非常相似的曲线。

::: example 读懂艾宾浩斯的表 {#ex-ebbinghaus}
“一天后节省率为34%”是什么意思？如果学一张表用了20分钟，一天后重新学大约要多久？31天后呢？
::: solution
节省率衡量的是重新学习比第一次学习**少**用多少时间。一天后节省率为34%，意思是重新学习少用了约34%的时间——大约是原来时间的66%。

- 1天后：20分钟的66% ≈ **13分钟**。
- 31天后：节省率约为21%，所以重新学习约需原来时间的79%：20分钟的79% ≈ **16分钟**。

两点启示：第一，即使过了一个月，记忆仍有残留（重新学习比从零开始学要快）；第二，丢失的部分大多是在第一天丢失的。这就是学习后尽快进行第一次复习如此有用的原因。
:::
:::

## 自我测试：提取练习

::: definition 提取练习 {#def-retrieval}
**提取练习**（retrieval practice）是指努力从记忆中把东西找回来——例如看着中文意思，努力想起对应的英语词——而不是再看一遍答案。它也叫**测试效应**（testing effect），因为测试就是一种提取。
:::

::: theorem 提取比重读更有效 {#rule-retrieval}
努力从记忆中回想一个词，然后核对答案，比用同样的时间把这个词和它的意思再读一遍，记得更久。回想时付出的努力本身就是让记忆更牢固的原因之一，即使第一次回想失败了也是如此。
:::

::: proof
许多实验都表明了这一点。罗迪格（Henry Roediger）和卡皮克（Jeffrey Karpicke）（2006）发现，就一篇文章接受测试的学生，一周后记住的内容比用同样时间重读文章的学生更多——尽管重读的学生自我感觉更有把握。卡皮克和罗迪格（2008）教学生外语词对；学生通过回想来反复练习的词，一周后记得比只是反复学习的词好得多。每一次成功的提取，都让下一次找到这个词的路径更容易走。相反，重读会让一个词看起来眼熟，而这种眼熟的感觉很容易被误当作已经掌握。卡皮克、巴特勒和罗迪格（Karpicke, Butler & Roediger，2009）发现，大多数学生自己学习时选择的是重读。
:::

::: warning “我把单词表读了十遍，所以我会了”
一遍又一遍地读单词表让人觉得在学习，因为这些词变得眼熟了。但眼熟只是接受性的，而且很短暂（[[core-vocabulary/knowing-a-word]]）。检验是否认识一个词，要看你能不能在**不看**的情况下把它想起来。把英语遮住，看着意思，说出或写出这个词；然后核对。想不起来的那些词，正是需要练习的词。
:::

::: quiz
下面哪一项是提取练习？
- [ ] 把单词表大声读三遍
- [ ] 把新词抄在笔记本上
- [x] 遮住英语词，根据中文意思努力把它们写出来
- [ ] 在文章中用荧光笔标出新词
::: solution
只有第三项要求你从记忆中把词找回来。其他几项都可以一边看着词一边做。（抄写和标记能帮助你注意到词，但它们不是提取。）
:::
:::

## 间隔

::: definition 间隔练习和集中练习 {#def-spacing}
**集中练习**（massed practice）是指在一次学习中把某样东西学很多遍（就像刘洋的星期一晚上）。**间隔练习**（spaced practice，也叫**分散练习**，distributed practice）是指把同样多的学习分散到几次进行，中间有间隔。按逐渐延长的间隔进行复习的方法，常被称为**间隔重复**（spaced repetition）。
:::

::: theorem 把复习分散到不同的时间 {#rule-spacing}
在总学习时间相同的情况下，分散到几天里的复习，比在一次学习中完成同样的复习，记得要久得多。需要记住的时间越长，复习之间的间隔就应该越长。
:::

::: proof
这种**间隔效应**（spacing effect）是记忆研究中证据最充分的发现之一。塞佩达（Nicholas Cepeda）及其同事（2006）综述了数百项关于间隔练习和集中练习的实验，发现间隔练习有明显的优势。在后来的一项大型研究中（Cepeda et al. 2008），两次学习之间的最佳间隔随着距离最终测试的时间而增长：对几天后的测试来说，短间隔最好；对几个月后的测试来说，长间隔更好。一种解释是，间隔一段时间后的复习需要更费力地提取，而费力的提取会增强记忆（[[#rule-retrieval]]）；另一种解释是，在不同日子里的复习把这个词和更多不同的情境联系起来。对学词来说，实际的结论是：学完后尽快复习，然后间隔越来越长地再复习。
:::

:::

::: example 安排复习计划 {#ex-plan-reviews}
星期一，刘洋用单词卡学了20个新词。他每天有15分钟学词汇。按照 [[#rule-spacing]]，为他安排接下来两周的复习计划。
::: solution
一个间隔逐渐延长的计划：

| 日期 | 他做什么 |
|---|---|
| 星期一（第0天） | 用卡片学这20个词：看、回想、核对 |
| 星期二（第1天） | 第一次复习：凭记忆过一遍全部20张卡片 |
| 星期四（第3天） | 第二次复习；把很容易想起来的卡片放进“以后再复习”的一叠 |
| 星期一（第7天） | 第三次复习全部20张；难的放到最后再过一遍 |
| 星期一（第14天） | 第四次复习；容易的卡片放进每月复习的一叠 |

其他日子他学新词，并复习那些词。每次复习只需几分钟，因为他是在回想，而不是重新学。间隔（1、2、4、7天）逐渐延长，正如规则所说。具体是哪几天关系不大；重要的是第一次复习要早，此后间隔越来越长。
:::
:::

## 单词卡

单词卡（闪卡）是一种古老而简单的工具，只要结合提取和间隔来使用，就有研究的支持。保罗·内申（2013）对怎样使用单词卡提出了详细的建议；下面的规则就依据这些建议。

::: theorem 怎样使用单词卡 {#rule-word-cards}
1. 一面写英语词（和读音），另一面写意思——写中文译文就可以——再加一个简短的例句或搭配。
2. **先回想再翻面**：看着一面，说出或写出另一面，然后核对。
3. 双向练习：从英语到意思（为了理解），从意思到英语（为了使用）。
4. 一叠卡片的数量要少到几分钟就能过一遍，而且每次都要**打乱顺序**，以免记住的是顺序。
5. 已经熟悉的卡片移到以后复习的一叠，难的卡片留在每天复习的一叠。
6. 对于非常难记的词，建立一个记忆联系——一个画面、一个句子、一个读音上的联系（[[#ex-keyword]]）——然后在一个真实的句子里用这个词。
:::

::: proof
第2步和第5步把提取练习和间隔融入了卡片：每看一张卡片就是一次小测验，容易的卡片比难的卡片出现得少。第3步很重要，因为接受性知识和产出性知识是不同的（[[core-vocabulary/knowing-a-word]]）：想起 *afraid* 的意思，并不能训练你在需要时说出 *afraid*。第4步避免了记住的是词在卡片中的位置而不是词本身。德国作家塞巴斯蒂安·莱特纳（Sebastian Leitner）在1972年描述了一种卡片系统，分“新的”“认识的”“很熟的”几个盒子——认识的卡片向前移，不认识的就退回第一个盒子；许多纸质和电脑上的系统都采用了同样的思路。第6步利用了这样一个事实：联系越多的记忆越容易找到。
:::

::: example 制作一张好的单词卡 {#ex-word-card}
王芳在一个故事里遇到 *afraid*：*The little boy was afraid of the dark.*（小男孩怕黑。）为它制作一张单词卡。
::: solution
**正面：**

*afraid* /əˈfreɪd/ — adjective（形容词）

**反面：**

害怕的 — *afraid of something*：*She's afraid of dogs.*（她怕狗。）另外，*I'm afraid …* = 礼貌地告诉别人坏消息的说法：*I'm afraid I can't come.*（恐怕我来不了。）

卡片上要注意的几点：句型 *afraid of*（不说 ✗ *afraid with*）；*afraid* 不用在名词前（✗ *an afraid boy*；要说 *a frightened boy* 或 *a scared boy*，一个受惊的男孩）；在礼貌的口语中还有另一个非常常见的用法。练习时，她先看正面，努力说出意思和句型；再看反面，努力说出 *afraid of* + 一个名词。
:::
:::

::: example 为难记的词建立记忆联系 {#ex-keyword}
陈宇总是记不住 *candle* /ˈkændl/“蜡烛”。读音联系怎样能帮上忙？
::: solution
**关键词法**（keyword method，Atkinson and Raugh 1975）把新词的读音和一个你认识的词联系起来，再把两者和一个画面联系起来。

1. 找一个读音相近的熟悉的词：*candle* /ˈkændl/ 听起来有点像“看到”（kàndào）。
2. 想象一个把读音和意义联系起来的画面：在黑暗的房间里，只有点亮 *candle*，你才能**看到**东西。
3. 使用这个词：*We lit a candle when the lights went out.*（停电时我们点了一支蜡烛。）

这个联系只是一座桥。它在头几次有帮助；此后，靠的是遇到和使用这个词让它留下来，而这座桥就会被忘掉。这种方法对某些词、某些学习者效果很好，特别是对具体名词；对 *however*（然而）或 *although*（虽然）这样的词，例句的效果更好。
:::
:::

## 再次遇到单词

卡片适合于第一步：把形式和意义联系起来。但要真正认识一个词——它的搭配、语法、语域——需要在真实的语言中多次遇到它。保罗·内申把一门均衡的语言课程描述为大致等量的四个“组成部分”（strands）：从**以意义为中心的输入**（阅读和听力）中学习，通过**以意义为中心的输出**（口语和写作）来学习，**以语言为中心的学习**（专门的学习，例如单词卡和查词典），以及**流利性发展**（快速、轻松地运用已经掌握的东西）（Nation 2007）。单词卡属于第三部分。没有另外三部分，从卡片上学来的词就会单薄而用不上。

::: note 英汉对比
许多中国学习者是“背单词”长大的：背单词表，常常是按字母顺序排的，还练习“默写”（听写单词，或根据中文意思写出单词）。其中一部分是非常好的练习：默写就是提取，反复复习单词表也是一种间隔。有两部分效果较差。按字母顺序排列的单词表把形式相近的词放在一起（*adapt* 适应、*adopt* 采用、*adept* 熟练的），这使它们更容易混淆（关于干扰，见 [[core-vocabulary/everyday-topics]]）。而单词表上只配一个中文意思的词，有形式和意义，却没有用法。保留长处——凭记忆回想、多次复习——再加上例句、搭配，以及在阅读和听力中与这个词的相遇。
:::

::: application 每天的学习安排
一个大约20–30分钟的示范安排——请根据你的时间和水平调整：

1. **5分钟——复习**：今天到期要复习的那叠卡片，凭记忆回想，打乱顺序。
2. **5分钟——新词**：5–10个新的高频词（[[core-vocabulary/frequency-and-coverage]]），或者本周遇到、想要使用的词。为每个词做一张带例句的卡片（[[core-vocabulary/using-a-dictionary]]）。
3. **10–15分钟——以意义为中心的阅读或听力**，难度要让你感觉轻松（一本分级读物、一个面向学习者的播客），昨天学的词可能会在其中再次出现（[[reading-skills/extensive-reading]]）。
4. **2分钟——使用**：用今天学的词说或写两个句子。

这些数字是举例，不是指标。研究支持的是原则——提取、间隔、多次相遇——而不是每天学多少个词这样的具体数字。
:::

::: history
1885年，赫尔曼·艾宾浩斯发表了第一部关于记忆的实验研究《论记忆》；书中既描述了遗忘曲线，也描述了把练习分散到几天里的好处。1967年，美国语言教师保罗·皮姆斯勒（Paul Pimsleur）提出了一个按逐级延长的间隔回想新词的“记忆时间表”，每个间隔都比前一个长好几倍。1972年，德国科普作家塞巴斯蒂安·莱特纳描述了他用于间隔复习的卡片盒系统。1975年，理查德·阿特金森（Richard Atkinson）和迈克尔·劳（Michael Raugh）用学习俄语词汇的学习者检验了关键词法。21世纪头十年，大型研究和综述——塞佩达等人（2006，2008）关于间隔的研究，以及罗迪格和卡皮克（2006）关于提取的研究——使这些发现成为学习研究中最可靠的结论之一。
:::

## 后续内容

值得做成卡片的是哪些词，见 [[core-vocabulary/frequency-and-coverage]]；怎样查到它们的用法，见 [[core-vocabulary/using-a-dictionary]]；为什么词块值得整体学习，见 [[core-vocabulary/phrases-and-chunks]]。在阅读中再次遇到单词是 [[reading-skills/extensive-reading]] 的主题，在听力中再次遇到单词是 [[listening-and-conversation/learning-from-media]] 的主题。《构词法》课程的最后一章介绍怎样在学习中利用构词成分：[[word-formation/learning-with-word-formation]]。

::: summary
- 学习之后不久遗忘得最快，然后逐渐变慢（艾宾浩斯1885；Murre & Dros 2015 重复验证）。
- **提取练习**——凭记忆回想一个词，然后核对——比重读记得更久（Roediger & Karpicke 2006；Karpicke & Roediger 2008）。眼熟不等于掌握。
- 总时间相同时，**间隔练习**胜过集中练习；需要记住的时间越长，间隔就应该越长（Cepeda et al. 2006，2008）。
- 使用**单词卡**时，要双向提取、每叠卡片少一些、打乱顺序、逐渐延长复习间隔；每张卡片都加上一个例句或搭配。
- **关键词法**这样的记忆联系有助于记住难记的具体名词；之后要在句子中使用这个词。
- 卡片只是四个组成部分之一：单词还需要在阅读和听力中多次遇到，并在口语和写作中使用。
:::

根据本章内容，判断每个说法是正确还是错误。

1. 大部分遗忘发生在学习后的第一天。
2. 把单词表读很多遍是记住它的最好办法。
3. 在总时间相同的情况下，分在不同日子里的三次短时间学习，比一次长时间学习好。
4. 回想一个词失败了就是浪费时间。
5. 练习单词卡时应该总是按同样的顺序。
::: solution
1. 正确（艾宾浩斯的表）。
2. 错误——提取练习效果更好。
3. 正确——间隔效应。
4. 错误——即使回想失败，努力回想也会增强记忆，特别是之后核对了答案的话。
5. 错误——要打乱顺序，以免记住的是顺序。
:::

::: exercise 是不是提取？ {level=1}
下面哪些活动是提取练习？

1. 看着一张厨房的图片，用英语说出里面东西的名称。
2. 读课本一章中的新词。
3. 朋友读中文意思，你写出英语词。
4. 听一张单词表的单词和意思。
5. 用这周学的新词给朋友讲你的一天。
::: solution
是提取：1、3和5——每一项你都要从记忆中把词拿出来。不是提取：2和4——你是在看到或听到这些词的同时接收它们。
:::

::: exercise 正面和反面 {level=1}
按照 [[#rule-word-cards]] 为 *borrow* 制作一张单词卡：每一面写什么？
::: solution
- **正面：** *borrow* /ˈbɒrəʊ/（GB），/ˈbɑːroʊ/（GA）——动词。
- **反面：** 借（进来）——*borrow something from someone*：*Can I borrow your pen?*（我能借你的笔吗？）比较 *lend*（借出）。

双向练习：从 *borrow* 到意思，以及从“借（进来）”到 *borrow* 和它的句型。
:::

::: exercise 第四次复习 {level=2 check="15"}
刘洋在第0天学了一个词，第1天第一次复习。此后，每次复习之间的间隔都是前一次的两倍。他的第四次复习在第几天？
::: solution
间隔是1、2、4和8天。复习分别在第1天、第1 + 2 = 3天、第3 + 4 = 7天和第7 + 8 = **15**天。
:::
:::

::: exercise 读懂曲线 {level=2}
用艾宾浩斯的表回答。(a) 1小时后节省了多少？(b) 表中哪两个时间点之间，每小时节省率下降得最多？(c) 为什么这说明第一次复习要早？
::: solution
(a) 约44%。

(b) 在20分钟和1小时之间：节省率从约58%降到约44%——40分钟里下降了14个百分点。而在1天和6天之间，五天里只下降了约9个百分点。

(c) 因为一开始遗忘得最快，当天或第二天的复习能在大部分内容丢失之前把这个词抓住；此后遗忘变慢，所以后面的复习可以等得更久一些。
:::
:::

::: exercise 改进一个学习计划 {level=2}
周敏的计划：*Every Sunday I will learn 100 new words from an alphabetical list by reading it for two hours. I will not look at the list again until the next test.*（每个星期天，我要花两个小时读一张按字母顺序排列的单词表，学100个新词。下次考试之前我不会再看这张表。）提出三种改进这个计划的办法，每种都用本章中的一个理由加以说明。
::: solution
可能的改进：

1. 把时间分散到一周里（例如每天15–20分钟），而不是一天两小时——间隔（[[#rule-spacing]]）。
2. 自我测试而不是读：遮住英语，把它想起来——提取练习（[[#rule-retrieval]]）。
3. 在学习后的第1、3、7天复习，而不是只在考试时复习——第一次复习要早（[[#ex-ebbinghaus]]）。
4. 按频率和需要选词，按主题学，而不是按字母顺序——形式相近的词放在一起容易混淆（[[core-vocabulary/everyday-topics]]）。
5. 为每个词加上一个例句或搭配，并在阅读中遇到这些词（[[core-vocabulary/knowing-a-word]]）。

任意三条加上正确的理由，就是好的答案。
:::
:::

::: exercise 你自己的两周计划 {level=3}
为自己设计一个两周的词汇学习计划。说明你每天有多少时间，你要学哪些词（为什么是这些词），你要怎样复习它们（具体在哪几天），以及在卡片之外你将怎样遇到和使用它们。
::: hint
以示范安排和 [[#ex-plan-reviews]] 为样板，但要适合你自己的时间和目标。
:::
::: solution
答案因人而异。一个好的计划：

- 对可用的时间来说是现实的（例如工作日20分钟，周末40分钟）；
- 按频率和需要选词（例如在一本分级读物中遇到的词，或者 [[core-vocabulary/everyday-topics]] 中一个话题的词汇）；
- 包括回想，而不只是阅读，并按逐渐延长的间隔复习（例如第1、3、7和14天）；
- 包括以意义为中心的阅读或听力，以及用新词进行的少量口语或写作。
:::
:::

::: exercise 向同学解释 {level=3}
一个同学说：*Testing myself is stressful. I prefer to read my notes again — it's easier and I feel I learn more.*（自我测试让人紧张。我更喜欢把笔记再读一遍——这样更容易，而且我觉得学到的更多。）用英语写一段简短的回复（80–100词），友善地解释为什么自我测试效果更好，并建议一个容易上手的办法。
::: solution
示范回复：

*I understand — rereading feels easier. But that easy feeling can be misleading: the words look familiar, so you think you know them. Studies show that trying to remember a word, even when you fail, makes it stay longer than reading it again (Roediger and Karpicke 2006). You don't need a real test. Try this: cover the English side of your notes, look at the Chinese, and say the English words. Then check. Do it for five minutes a day, on different days. It's a bit harder, but you'll remember much more.*（我理解——重读感觉更容易。但这种轻松的感觉可能会误导你：这些词看起来眼熟，所以你以为自己会了。研究表明，努力回想一个词，即使没想起来，也比再读一遍记得更久（Roediger and Karpicke 2006）。你不需要正式的测试。试试这样：遮住笔记的英语部分，看着中文，说出英语词，然后核对。每天做五分钟，分在不同的日子里。这样稍微难一点，但你会记住多得多的东西。）

好的答案要提到眼熟的感觉、提取的好处（引不引用文献都可以），并给出一个简单实用的第一步。
:::
:::

::: exercise 记忆联系 {level=3}
选两个你觉得难记的英语词。为每个词建立一个记忆联系（读音联系、画面或小故事），然后用这个词写一个自然的英语句子。说说你认为这个联系会不会有帮助，为什么。
::: solution
答案因人而异。一个示范：

- *ankle* /ˈæŋkl/“脚踝”——读音联系：*ankle* 听起来像 *uncle*（叔叔）。画面：我叔叔踢足球时扭伤了脚踝。句子：*I hurt my ankle when I fell down the stairs.*（我从楼梯上摔下来，伤了脚踝。）这个联系应该有帮助，因为这个画面很容易想象。
- *despite*“尽管”——像这样的词很难找到读音联系，所以我改为学一个词块：*despite the rain*（尽管下雨）——*We went out despite the rain.*（尽管下雨，我们还是出去了。）对于语法词，例句比画面效果更好。

好的答案包括一个清楚的联系、一个自然的句子，以及一个简短的判断，说明这种方法对某些词比对另一些词更合适。
:::
