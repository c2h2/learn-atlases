五个英语句子，都是被动语态，以及它们最自然的汉语译文：

- *The bridge was built in 1957.* —— 这座桥建于1957年。
- *The meeting has been postponed.* —— 会议推迟了。
- *He was hit by a car.* —— 他被车撞了。
- *English is spoken all over the world.* —— 世界各地都有人说英语。
- *It is said that the house is haunted.* —— 据说这房子闹鬼。

五句中只有一句用了“被”。其余几句用的是表示日期的正式句式（建于）、根本不带被动标记的句子（会议推迟了——会议是话题，汉语不需要说出是谁推迟的）、带不定主语的主动句（有人说），以及一个固定说法（据说）。如果每句都用“被”来翻译，这五句都看得懂，却都很别扭：? 这座桥在1957年被建造，? 会议已经被推迟了，? 英语被全世界的人说。

被动语态是一个更大现象中最为人熟知的例子。在英语和汉语之间翻译，经常需要改变**结构**——语态、词类、肯定与否定、承载某个意义的单位。翻译学者把这些改变称为**转换**（shifts），本课描述其中主要的几种以及何时进行这些转换。

## 什么是转换

::: definition 转换、词性转换和调整 {#def-shift}
**翻译转换**（translation shift）是对原文与译文之间形式对应的偏离：译文用不同的语法结构、词类或单位来表达原文的意义。这个术语出自卡特福德（J. C. Catford）的《翻译的语言学理论》（*A Linguistic Theory of Translation*，1965），书中区分了**层次转换**（level shifts，一种意义在一种语言中用语法表达，在另一种语言中用词汇表达：英语的时 ~ 汉语的时间词）和**范畴转换**（category shifts）：**结构**转换（语序、主动和被动）、**类别**转换（名词变动词）、**单位**转换（词变短语、分句变句子）以及**系统内**转换（在一种语言中是单数，在另一种语言中是复数）。

维奈和达贝尔内（Vinay and Darbelnet，1958）把间接翻译中最重要的两种称为**词性转换**（transposition）——改变词类而不改变意义（*after he arrives* → *after his arrival*）——和**调整**（modulation）——改变视角（*It is not difficult* → *It is easy*；*Wet paint* → 油漆未干）。
:::

::: widget graph
title: 维奈和达贝尔内的翻译程序

:::

::: theorem 何时转换 {#rule-when-shift}
当目的语中形式上对应的结构**不合语法**、**不自然**、**不够清楚**或**在意义或效果上不同**时，就进行转换。不要仅仅为了显示自己会转换而转换：形式上对应、读起来又自然的结构就是最好的选择（[[translation/what-translation-is#rule-literal-first]]）。
:::

::: proof
转换是“能直译就直译，该意译才意译”这一原则的实现机制。在英语和汉语之间，转换比在亲属关系相近的欧洲语言之间必要得多，因为两种语法恰恰在发生转换的那些方面存在差异：语态、词类、强制性范畴和句子单位（[[translation/english-chinese-compared]]）。卡特福德的分类之所以有用，是因为它表明转换是有系统的——同样的类型在一个又一个文本中反复出现——因而是可以教的。不必要的转换是相反的毛病：它们带来细微的侧重变化，并使译文更难与原文核对。
:::

## 英语被动句的汉译

英语使用被动语态的频率比汉语高得多，尤其是在学术、技术、法律和新闻写作中。语料库比较（例如肖忠华、麦克内里和钱毓芳［Xiao, McEnery and Qian］，《英汉被动结构》，"Passive constructions in English and Chinese"，2006）发现，被动结构在汉语文本中远不如在可比的英语文本中常见，而且汉语的“被”字句在用法上受到限制。

::: theorem 英语被动句的译法 {#rule-passive-zh}
对于英语被动句，考虑下列汉语结构，大致按优先顺序排列：

1. **意义被动**（notional passive）——受事作话题，不带标记：*The problem has been solved* → 问题解决了；*The tickets are sold out* → 票卖完了。
2. **以施事为主语的主动句**，如果施事已知或由 *by* 短语给出：*The decision was made by the board* → 董事会作出了这个决定。
3. **以不定或泛指主语构成的主动句**（有人、人们、大家、我们）：*English is spoken in many countries* → 很多国家的人说英语。
4. **无人称被动句的固定说法**：*It is said that* → 据说；*It is reported that* → 据报道；*It is believed that* → 人们认为 / 一般认为；*It must be admitted that* → 必须承认。
5. **正式句式**：由 + 施事（这项工作由王教授负责——公文用语，中性）；为……所（书面语）；受到、遭到、得到、予以 + 动名词（受到批评、得到批准、予以支持）；用“是……的”表示过去的事实（这座寺庙是唐代修建的）；用“于”表示日期和地点（建于1957年）。
6. **被**（或口语中的叫、让、给）——尤其是当事件对主语**不利**时（*He was cheated* → 他被骗了），或者必须说出施事而又要保留受事作话题时。
:::

::: proof
这个顺序反映了汉语的用法。意义被动是汉语表达被动意义最常用的方式，因为话题可以不带任何标记就是动词的受事（这本书我看完了；饭做好了）——这是话题突出的直接结果（[[translation/english-chinese-compared#def-topic]]）。“被”字句传统上主要用于不愉快的事件——李讷和汤普森（1981）把它的典型意义描述为对主语不利——尽管受翻译影响的现代书面汉语对它的使用更广泛了（被评为先进、被选为代表），但每个英语被动句都用“被”，听起来仍然像翻译。英语选用被动语态常常是出于信息结构的原因——保持话题作主语，避免说出模糊的施事——而汉语可以通过话题化来满足这些需要，不必改变语态。策略5属于正式语域：“予以”“由”“于”在公文和法律汉语中很常见，在会话中就不合适了。
:::

::: example 五个被动句，五种策略 {#ex-passive-zh}
译成汉语，并说出你所用的是 [[#rule-passive-zh]] 中的哪种策略。(a) *All the seats have been taken.* (b) *The new airport was opened by the mayor last week.* (c) *Smoking is not allowed in the building.* (d) *It is estimated that the project will cost two billion yuan.* (e) *My bike was stolen last night.*
::: solution
(a) 意义被动：座位都满了。/ 座位都有人了。（1）

(b) 以施事为主语的主动句：新机场上周由市长主持启用。（5，“由”，正式）或 市长上周为新机场揭幕。（2）在新闻报道中，“新机场上周正式启用，市长出席了启用仪式”也很自然：被动的 *was opened by* 变成了两个主动分句。

(c) 告示的固定格式：楼内禁止吸烟。/ 楼内不准吸烟。——不带主语的主动动词。

(d) 无人称的固定说法：据估计，这个项目将耗资二十亿元。（4）

(e) 用“被”，因为事件是不利的：我的自行车昨晚被偷了。（6）意义被动的 ? 我的自行车昨晚偷了 是不能接受的，因为自行车不带标记就不能作“偷”的话题——它会被理解为主动。口语中也可以说“我自行车昨晚让人偷了”。
:::
:::

::: warning 每个被动句都用“被”
✗ 这个问题已经被讨论过很多次了。 ✓ 这个问题已经讨论过很多次了。

✗ 晚饭被做好了。 ✓ 晚饭做好了。

✗ 他被选为班长，被大家祝贺了。 ✓ 他当选为班长，大家都向他表示祝贺。

当事件对主语不利，或者必须说出施事时，才用“被”；其他情况下先试试意义被动或主动句。
:::

## 汉译英：何时用被动语态

反方向的转换同样重要。汉语的意义被动句和无主语句常常需要译成英语被动句；而有些英语文本——科学报告、公文——在汉语用带“我们”或不带主语的主动动词的地方，要求使用被动语态。

::: theorem 英语何时需要被动语态 {#rule-passive-en}
汉译英时，在下列情况下用英语被动语态：

1. 施事不明或不重要的**意义被动**句：这座桥去年修好了 → *The bridge was repaired last year*；信已经寄出去了 → *The letter has been sent.*
2. 正式文本中说明必须做什么的**无主语**陈述：要加强安全管理 → *Safety management must be strengthened*（或者不那么正式地说：*We need to tighten safety procedures*）。
3. 在**科学和技术**写作中描述方法：将样品加热至80度 → *The samples were heated to 80°C.*
4. 为了在一系列句子中**保持话题作主语**：这家公司成立于1998年，2010年被一家外国企业收购 → *The company was founded in 1998 and was bought by a foreign group in 2010.*

当施事已知且重要时，或者被动语态会使句子在责任问题上含糊其辞时，不要用被动语态：我们犯了错误 → *We made mistakes*，而不是 ✗ *Mistakes were made.*
:::

::: proof
英语每个分句都需要主语，当施事不明、不重要或显而易见时，被动语态可以让受事作主语（[[verb-patterns/the-passive]]）。第3点和第4点源于语域和信息结构：英语的方法部分按惯例用被动语态描述操作程序，而被动语态能让一个段落保持同一个主语，这是英语的衔接所偏爱的。最后的警告既关乎文体，也关乎诚实：“无施事被动句”可以掩盖是谁做了某事，译文不应掩盖原文明确说出的责任。
:::

::: example 汉译英中的语态选择 {#ex-passive-en}
译成英语。(a) 这个问题必须尽快解决。 (b) 会上，大家对这个方案提出了很多意见。 (c) 文物出土后，立即送往省博物馆修复。
::: solution
(a) *This problem must be solved as soon as possible.*——带有义务意义的意义被动句；没有说出施事。（如果说话人指的是“我们”，*We must solve this problem quickly* 也正确。）

(b) *At the meeting, many objections were raised to the plan*——或者用主动语态：*People at the meeting raised many objections to the plan.* 如果读者应当知道是谁提出反对，主动语态更好；如果要点是反对意见本身，就用被动语态。

(c) *After the artefacts were excavated, they were sent straight to the provincial museum for restoration.* / *Once excavated, the artefacts were taken straight to the provincial museum to be restored.*——汉语有两个以文物为话题的无主语分句；英语保留文物作主语，用了两个被动结构，第一个简化为分词（*Once excavated*）。
:::
:::

::: quiz
在研究论文中，*The results are shown in Table 2* 最自然的汉语译文是哪一个？
- [ ] 结果被显示在表2中。
- [x] 结果见表2。
- [ ] 表2被用来显示结果。
- [ ] 我们把结果显示在表2。
::: solution
“结果见表2”（或“结果如表2所示”）是汉语学术写作的标准格式。“被显示”照搬了英语的被动语态；第三个颠倒了意义的焦点；第四个合乎语法，但不符合惯例。
:::
:::

## 词类转换

::: definition 词类转换 {#def-conversion}
**词类转换**（conversion of word class）——即维奈和达贝尔内的**词性转换**（transposition）、卡特福德的**类别转换**（class shift）——是用另一词类的词来翻译某一词类的词，而意义不变：用汉语动词译英语名词，用汉语动词译英语介词，用汉语副词或动词译英语形容词，以及反方向的转换。张培基的《英汉翻译教程》（1980）把它作为英汉翻译的基本技巧之一（词类转译法）。
:::

::: theorem 常见的词类转换 {#rule-conversion}
**英译汉**

1. **名词 → 动词**：*He is a good swimmer* → 他游泳游得很好；*I'm a stranger here* → 我对这儿不熟；*The sight of the sea made her happy* → 她一看到大海就很高兴；*Thank you for your help* → 谢谢你帮我。
2. **介词 → 动词**：*She left without a word* → 她一句话没说就走了；*a house with a garden* → 带花园的房子；*Are you for or against the plan?* → 你赞成还是反对这个计划？
3. **形容词 → 动词**：*I'm sure he'll come* → 我相信他会来；*She is fond of music* → 她喜欢音乐；*They are aware of the risks* → 他们知道有风险。
4. 当英语形容词修饰表示动作的名词时，**形容词 → 副词**：*We had a brief talk* → 我们简单地谈了谈；*a careful reading of the report* → 仔细阅读报告。
5. **副词 → 形容词或名词**：*He is physically weak but mentally strong* → 他身体虽弱，意志却很坚强。

**汉译英**：反方向的转换——汉语动词变为英语名词、介词和形容词——就是 [[translation/chinese-into-english#rule-subordinate]] 中描述的形合手段：他很会做饭 → *He is a good cook*；我们必须了解情况 → *We need an understanding of the situation*（正式）或 *We need to understand the situation.*
:::

::: proof
词类转换是静态与动态对比在词层面的表现（[[translation/english-chinese-compared#rule-static]]）。英语中表示施事的名词（*swimmer*、*cook*、*learner*）和表示动作的名词带有动词意义，而 *sure*、*afraid*、*aware*、*fond*、*capable* 这类英语形容词对应汉语表示心理状态的动词。英语介词数量多，承载着汉语常用动词（带、过、穿、拿、用）表达的关系，其中许多动词在其他用法中也是汉语介词。第4点中形容词到副词的转换源于第一种转换：表示动作的名词一旦变成动词，修饰它的形容词就必须变成副词。在构词上两种语言也不同：英语内部的转类（*to email*、*a walk*）是另一种现象，见 [[word-formation/conversion]]。
:::

::: example 一个句子中的词类转换 {#ex-conversion}
译成汉语，并指出每一处词类转换：*Her rapid recovery after the operation was a great relief to her family, who had been anxious about the outcome.*
::: solution
1. **主干**：*Her rapid recovery … was a great relief to her family*。
2. **表示动作的名词 → 动词**：*recovery* → 恢复；*relief* → 松了一口气（动词短语）；*the outcome* → 结果（这里用名词也可以，或者用分句“手术能不能成功”）。
3. **形容词 → 副词或动词**：*rapid* → 很快地（副词）；*anxious about* → 担心（动词）。
4. **语序和分译**：非限制性从句 *who had been anxious …* 是背景，所以放在前面。

家人原本一直担心手术的结果，见她术后恢复得这么快，都松了一口气。/ 她手术后恢复得很快，一直提心吊胆的家人终于放下心来。

英语只有一个限定动词（*was*），关系从句里还有两个；汉语有五个动词（担心、见、恢复、松了一口气，或放下心来）。
:::
:::

## 正说与反说

::: theorem 正反表达 {#rule-negation}
在一种语言中用肯定形式表达的意义，在另一种语言中常常最好用否定形式表达，反之亦然——这就是维奈和达贝尔内所说的**调整**（modulation）：

- **英语肯定 → 汉语否定**：*Wet paint* → 油漆未干；*Members only* → 非会员免进；*Keep off the grass* → 请勿践踏草坪；*He is the last person to tell a lie* → 他绝不会说谎；*The explanation is far from satisfactory* → 这个解释很不令人满意（*far from* 在形式上是肯定的）。
- **英语否定 → 汉语肯定**：*I couldn't agree more* → 我完全同意；*It won't be long before …* → 很快就会……；*Don't lose heart* → 要有信心；*not until* → 直到……才：*He didn't arrive until midnight* → 他半夜才到。
- **双重否定和低调陈述**：*not uncommon* → 很常见 / 并不少见；*not without reason* → 不无道理。

根据语境选择在目的语中自然的形式——尤其是在标识上，每种语言都有固定的格式。
:::

::: proof
不同语言对于哪种说法是惯用说法各不相同，调整保留了意义而改变了视角。标识和固定说法是差异最明显的地方，因为两种语言都有标准格式，读者一眼就能认出来；✗ “湿油漆”或 ✗ *Paint not dry* 能看懂，但标识不是这么写的。英语还有许多意义上否定、形式上肯定的说法（*fail to*、*far from*、*the last person to*、*too … to*），或者反过来的说法（*cannot … too*：*You cannot be too careful*，意为“要尽可能小心”），学习者常常读错。译者的第一项任务是正确理解它们；第二项是在目的语中选择自然的形式。
:::

::: example 理解和翻译否定 {#ex-negation}
译成汉语，注意肯定与否定。(a) *You can't be too careful when you cross this road.* (b) *She failed to notice the sign.* (c) *Nothing could be further from the truth.* (d) *It was not until she got home that she realised she had lost her phone.*
::: solution
(a) *Can't … too* 的意思是“无论多小心都不为过”：过这条马路，再小心也不为过。/ 过这条马路一定要特别小心。✗ “过马路你不能太小心”把意思弄反了。

(b) *Fail to* 在意义上是否定的：她没注意到那个标志。

(c) 否定形式表达强烈的肯定意义（“那完全不是真的”）：这完全不是事实。/ 事实恰恰相反。

(d) *Not until* → 直到……才：她直到回到家，才发现手机丢了。
:::
:::

- [ ] 最后我向他请教了——最后我向他请教了。
::: solution
*The last person to …* 的意思是“最不可能或最不适合做……的人”。汉语译文必须说出否定的意义；直译成“最后一个”会误导读者，不过在确实指一个名单的语境中，这样译就对了。
:::
:::

## 其他转换

另外几种结构差异也需要经常进行转换。

- **存在句 *there* 和 *have***：*There is a cat on the roof* → 屋顶上有只猫（地点在前，用“有”）；*This room has two windows* → 这个房间有两扇窗（结构相同）。
- **“把”字句**：如果英语句子中的动作改变了一个定指宾语的状态或位置，常常对应汉语的“把”字句：*Put the book on the shelf* → 把书放到书架上；*She tore the letter to pieces* → 她把信撕得粉碎。译成英语时，“把”消失了，句子变成主谓宾加一个表示结果的短语。
- **结果动词**：汉语的动结式复合词（看完、听懂、打破）对应带小品词或副词的英语动词，或者单独的动词：*finish reading*、*understand*、*break*；而英语的短语动词常常对应汉语的动补式复合词：*eat up* → 吃光，*find out* → 查明。
- **数的系统内转换**：*He has blue eyes* → 他的眼睛是蓝色的（没有复数）；*the scissors*（在英语中是复数）→ 剪刀（没有数）。
- **单位转换**：一个词变成一个短语（*bilingual* → 会说两种语言的），或者一个分句变成一个短语（*as soon as he arrived* → 他一到）。分译和合译是更大范围的单位转换（[[translation/english-into-chinese]]、[[translation/chinese-into-english]]）。

::: note 英汉对比
- **现代汉语的“被”正在变化。** 除了传统的不利意义外，“被”现在在正式书面汉语中也用于中性和积极的意义（被评为、被授予），而且大约从2009年起，它还有了一种带讽刺意味的网络用法（被就业、被自愿），描述强加于某人、并非出于其本人选择的事情。译成英语的译者必须捕捉到其中的讽刺；译成汉语的译者不应以读者会听出讽刺意味的方式使用“被”。
- **转换可以补偿。** 在一处丢失的意义常常可以在另一处恢复：如果 *rapid* 不能译成形容词，可以译成副词；如果被动语态不能让施事隐而不说，不定主语可以做到。维奈和达贝尔内把这称为**补偿**（compensation）。
- **有时需要形式对应。** 双语法律文件、逐行对照注释和语言学例句，可能要求译者避免转换、保留原文结构，而以牺牲自然度为代价。由翻译要求决定（[[translation/what-translation-is#rule-brief]]）。
:::

::: history
翻译通过有规律的结构变化来进行，这一观念是在20世纪五六十年代形成理论的。让-保罗·维奈和让·达贝尔内的《法英比较文体学》（*Stylistique comparée du français et de l'anglais*，1958）对法英之间的翻译程序进行了分类，以词性转换和调整为核心的间接程序。卡特福德的《翻译的语言学理论》（*A Linguistic Theory of Translation*，1965）以韩礼德（M. A. K. Halliday）的系统语法为基础，提出了“转换”（shift）这一术语。在中国，同样的现象早已在教材中作为技巧来描述——词类转译、正反表达、被动语态的译法——张培基的《英汉翻译教程》（1980）为大学生系统地阐述了这些技巧。汉语被动句本身的历史也很长：“被”本义是“覆盖”或“蒙受”，它作为被动标记的用法是在古代汉语和中古汉语中发展起来的，它与不愉快事件的联系一直保留到现代汉语中。
:::

## 后续内容

结构转换是后面每一课的工具：带有被动语态和名词化结构的专业文本，见 [[translation/specialised-translation]]；必须快速完成转换的口译，见 [[translation/interpreting]]；机器翻译——其输出常常未能完成自然的汉语或英语所需要的转换——见 [[translation/machine-translation]]。关于英语被动语态本身，见 [[verb-patterns/the-passive]]；关于英语内部的转类，见 [[word-formation/conversion]]。

::: summary
- **转换**是原文和译文之间结构、词类、单位或范畴的改变；**词性转换**改变词类，**调整**改变视角（[[#def-shift]]）。
- 当形式上对应的结构不合语法、不自然、不清楚或效果不同时才转换——否则不转换（[[#rule-when-shift]]）。
- 英语被动句译成汉语：先试试**意义被动**、以施事或不定主语构成的**主动句**、**固定说法**（据说、据报道）或正式句式（由、受到、于），然后才用典型地表示不利事件的**“被”**（[[#rule-passive-zh]]）。
- 译成英语时，意义被动句、无人称的义务陈述、科学方法以及保持话题作主语时用被动语态——但不要用它来掩盖已知的施事（[[#rule-passive-en]]）。
- **转换词类**：英语名词、介词和形容词常常变成汉语动词，汉语动词常常变成英语名词和介词（[[#rule-conversion]]）。
- **肯定和否定**形式常常互换，尤其是在标识和固定说法中；要仔细理解 *can't … too*、*the last person to*、*not until* 和 *fail to*（[[#rule-negation]]）。
:::

## 习题

::: exercise 意义被动 {level=1}
不用“被”译成汉语。(a) *The work has been finished.* (b) *The shop is closed on Mondays.* (c) *Breakfast is served from seven to nine.*
::: solution
(a) 工作完成了。/ 活儿干完了。 (b) 商店周一不营业。/ 本店周一休息。 (c) 早餐供应时间为七点至九点。/ 早饭七点到九点。
:::
:::

::: exercise 无人称的固定说法 {level=1}
翻译。(a) *It is said that he speaks six languages.* (b) *It is reported that the floods have displaced thousands of people.* (c) *It is generally believed that exercise improves mood.*
::: solution
(a) 据说他会说六种语言。 (b) 据报道，洪水已导致数千人流离失所。 (c) 人们普遍认为，锻炼能改善情绪。/ 一般认为……
:::
:::

::: exercise 标识 {level=1}
给出每个英语标识通常的汉语说法，并说明肯定与否定是否改变。(a) *Wet paint* (b) *Staff only* (c) *Mind the gap* (d) *No entry*
::: solution
(a) 油漆未干——肯定 → 否定。(b) 非工作人员禁止入内 / 员工专用——前者变为否定，后者保留肯定。(c) 小心站台间隙——肯定与否定不变（警告）。(d) 禁止入内 / 禁止通行——肯定与否定不变。
:::
:::

::: exercise 被动还是主动？ {level=2}
译成英语，选择主动或被动语态，并说明理由。(a) 这座寺庙始建于宋代，明代重修过。 (b) 我们对数据进行了统计分析。（在研究论文中） (c) 他被公司开除了。
::: solution
(a) *The temple was first built in the Song dynasty and rebuilt in the Ming.*——被动语态：建造者不明，寺庙保持作主语。(b) *The data were analysed statistically.*（被动语态，方法部分的惯例）或 *We analysed the data statistically*（主动语态，在许多期刊中越来越常见；以期刊要求为准）。(c) *He was dismissed by the company* / *The company dismissed him* / *He was fired*——被动语态让“他”保持作主语和话题；*by the company* 常常可以省去。
:::
:::

::: exercise 词类转换 {level=2}
用词类转换把下列句子译成汉语，并说出是哪种转换。(a) *She is a heavy sleeper.* (b) *Thanks to his help, we finished on time.* (c) *I am afraid I can't come.* (d) *The plane is now over the Pacific.*
::: solution
(a) 她睡得很沉。（名词 *sleeper* → 动词“睡”；形容词 *heavy* → 补语“很沉”）(b) 多亏他帮忙，我们按时完成了。（名词 *help* → 动词“帮忙”）(c) 恐怕我来不了。（形容词 *afraid* → 带动词性的副词“恐怕”）(d) 飞机正飞越太平洋上空。（介词 *over* → 动词“飞越”）
:::
:::

::: exercise 理解错的否定 {level=2}
下列每个译文都误解了英语原文。解释错误并加以改正。(a) *I couldn't care less.* → 我不能更少地关心了。 (b) *He is too clever not to see the problem.* → 他太聪明了，看不到问题。 (c) *All that glitters is not gold.* → 所有发光的都不是金子。
::: solution
(a) *Couldn't care less* 的意思是“我根本不在乎”：我才不在乎呢。(b) *Too … not to* 的意思是“聪明到一定能看出来”：他那么聪明，不会看不出问题。(c) 这里的 *All … is not* 意思是“并非全部”：闪光的不一定都是金子。——英语谚语的语序把 *not* 放在 *all* 之后，但意义是部分否定。
:::
:::

::: exercise 分析转换 {level=3}
列出英语和汉语之间的每一处转换（语态、词类、肯定否定、单位、语序）：*Visitors are reminded that photography is not permitted without the written consent of the management.* —— 参观者请注意：未经管理方书面同意，不得拍照。
::: hint
看看 *are reminded*、*photography*、*without* 和 *consent* 发生了什么变化。
:::
::: solution
1. **语态**：*Visitors are reminded*（被动语态，施事 = 管理方）→ 参观者请注意（对参观者提出的主动请求；视角的调整）。
2. **词类**：*photography*（名词）→ 拍照（动词）；*consent*（名词）→ 同意（动词）；*written*（形容词）→ 书面（用作状语）。
3. **肯定否定与结构**：*is not permitted without*（一个否定加一个否定介词）→ 未经……不得（两个否定，汉语规章的固定正式句式）；被动的 *is not permitted* 变成情态词“不得”。
4. **语序**：条件 *without … consent* 在汉语中放在禁止之前（背景在前）。
5. **单位**：*that* 从句变成冒号后面一个独立的陈述。
:::
:::

::: exercise 运用转换翻译 {level=3}
把下面的句子译成汉语，然后不看原文，把你的汉语再译回英语，并加以比较。哪些转换被还原了，哪些没有？*The proposal was rejected by a large majority, which came as no surprise to those who had followed the debate.*
::: solution
汉语参考译文：这项提案以压倒性多数被否决了，一直关注这场辩论的人对此并不感到意外。（或者：提案遭到绝大多数人反对，未获通过……）回译：*The proposal was voted down by an overwhelming majority, and people who had been following the debate were not surprised.* 转换：被动语态被保留了（“被否决”，因为否决对提案来说是不利的），或者变成了“遭到 + 名词”；*which came as no surprise to*（带物称主语的指代整个分句的关系从句）变成了带人称主语的分句（……的人对此并不感到意外），回译时又变成了以 *people* 为主语的并列分句——这一转换没有被还原。*No surprise*（否定的名词短语）→ 并不感到意外（否定的动词）→ *were not surprised*（否定的形容词）。
:::
:::
