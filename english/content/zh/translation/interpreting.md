一个来自加纳的工程师代表团正在参观苏州的一家工厂。生产经理站在一台机器旁边说：

> 这条生产线是去年引进的，自动化程度比较高，原来要二十个工人，现在三个人就够了，效率提高了差不多五倍，当然，前期投入也不小。

她停下来，看着口译员。口译员只听了这句话一遍；没有文本可以回头看，没有词典，还有十二个人在等着。几秒钟之内，她说：

> *This production line was installed last year. It's highly automated: it used to need twenty workers, and now three are enough, so efficiency is up almost fivefold. Of course, the initial investment was considerable.*

本课程前面几课所描述的一切都在这几秒钟里发生了：流水句被拆成了四个英语句子；话题“这条生产线”变成了被动句（*was installed*）的主语；分句之间的关系——结果（*so*）、让步（*Of course*）——被明确表达出来；补出了时；“不小”变成了 *considerable*（用肯定的词表达否定的形式）。而口译员是实时完成这一切的，同时还在留意经理是否要接着往下说。

**口译**（interpreting）——口头的翻译——与笔译遵循相同的原则，但工作条件不同：原文只听一遍，译文要立即产出，口译员无法修改。本课描述口译的主要方式、它们所要求的脑力投入、使交替传译成为可能的笔记、英汉同声传译的策略，以及口译员的角色。

## 口译的方式

::: definition 口译的方式 {#def-modes}
- **交替传译**（consecutive interpreting，常简称“交传”）：讲话人讲一段——一句话或者几分钟——然后停下来；口译员随即译出这一段，通常借助笔记。
- **同声传译**（simultaneous interpreting，“同传”）：口译员边听边说，通常坐在戴着耳机和麦克风的译员厢里，比讲话人晚几秒钟。
- **耳语传译**（whispered interpreting，*chuchotage*）：不用设备，对一两个听众低声进行的同声传译。
- **联络口译**（liaison interpreting）或**对话口译**（dialogue interpreting）：对会话中简短话轮的交替传译——商务会谈、参观访问、医疗和警务问询、社区服务。
- **视译**（sight translation）：当场阅读书面文本并口头译出。
- **远程口译**（remote interpreting）：通过视频或音频连线进行的上述任何一种口译，口译员与讲话人不在同一个地方。
:::

口译方式由场合决定。使用多种语言的会议用同声传译，因为交替传译会使每篇讲话的时长加倍。谈判、记者招待会、宴会和参观访问常用交替传译，它不需要设备，也能让双方都听到对方的话。法庭和医院为个人提供交替传译或耳语传译。

## 口译的要求

::: theorem 译意义，不译词语 {#rule-sense}
口译员应当**听取每一段的意义**——讲话人想说什么，以及为什么这样说——并用自然的目的语口语**表达这一意义**，而不是逐词转换。必须准确保留的词语——**数字、名称、头衔、专业术语、引语**——是例外，要作为例外记下来或记住。
:::

::: proof
法国口译员兼学者塞莱斯科维奇（Danica Seleskovitch）与勒代雷（Marianne Lederer）从20世纪60年代末起把这一观念发展为**释意理论**（interpretive theory，*théorie du sens*）（塞莱斯科维奇，《国际会议口译员》［*L'interprète dans les conférences internationales*］，1968）：有经验的口译员理解一段话之后，就放下它的词语——他们称这一阶段为**脱离语言外壳**（deverbalisation）——再重新表达其意义。这样做有充分的理由。短时记忆只能保持几秒钟的确切措辞，却能保持一个意义；而且英汉之间结构差异太大，逐词转换会产生不可接受的话语（[[translation/english-chinese-compared]]）。数字和名称无法脱离语言外壳——它们没有可以依靠的“意义”——这就是为什么它们是口译中最常见的错误之一，也是为什么口译员听到它们就立即写下来。
:::

口译员兼研究者吉尔（Daniel Gile）用他的**精力分配模式**（Effort Models，《口笔译训练的基本概念与模式》［*Basic Concepts and Models for Interpreter and Translator Training*］，1995；修订版2009）来描述口译的脑力工作。他提出，在同声传译中，口译员把有限的处理能力分配给**听辨与分析**、**短时记忆**、**言语产出**和管理前三者的**协调**这几项精力。在交替传译中，第一阶段（听）包括听辨与分析、**笔记**、记忆和协调；第二阶段（说）包括**回忆**、**读笔记**和产出。

::: widget graph
title: 吉尔的同声传译精力分配模式
nodes: total capacity@4,8; listening and analysis@0,5; short term memory@3,5; speech production@6,5; coordination@9,5; heard segment@0,2; target speech@6,2
edges: total capacity>listening and analysis; total capacity>short term memory; total capacity>speech production; total capacity>coordination; heard segment>listening and analysis; listening and analysis>short term memory; short term memory>speech production; speech production>target speech; coordination>short term memory
caption: 据吉尔（1995；2009）。四项精力（listening and analysis 听辨与分析，short term memory 短时记忆，speech production 言语产出，coordination 协调）都取自同一个有限的总处理能力（total capacity）。当某一项精力需要更多时——一段密集的数字、一种不熟悉的口音、汉语名词前的一个长修饰语——留给其他几项的就少了，错误就会出现在别处，常常是几秒钟之后。吉尔的**走钢丝假说**（tightrope hypothesis）认为，口译员在大部分时间里都在接近饱和的状态下工作，这就是为什么看似容易的片段也会出错。这个模式是解释困难的框架，而不是一个测量出来的量。拖动节点，换一种方式排列这几项精力。
:::

::: quiz
根据吉尔的精力分配模式，为什么口译员可能在一串数字之后紧接着把一个简单的句子译错？
- [ ] 因为简单句比数字更难译。
- [x] 因为数字占用了太多的处理能力，留给听辨和处理下一句的能力太少了。
- [ ] 因为口译员说话时就停止了听。
- [ ] 因为数字总是最后才译。
::: solution
处理能力是共享的：记录和说出数字需要额外的精力，而从听辨那里借来的精力，就表现为下一段的错误。这就是为什么口译员尽可能提前准备数字，也是为什么要请讲话人慢慢读出数字。
:::
:::

## 交替传译与笔记

交替传译的口译员并不把讲话记录下来；他们记下的是**凭记忆重建意义**所需要的东西。罗赞（Jean-François Rozan）的《交替传译笔记》（*La prise de notes en interprétation consécutive*，1956）提出的七条原则，至今仍是大多数教学的基础。

::: theorem 罗赞的笔记原则 {#rule-rozan}
1. **记意思，不记词语**：一个意思用一个符号，不管讲话人用的是什么词。
2. 按固定的规则**缩写**长词（常常取首尾字母：*pdt* 代表 *president*，“经”代表“经济”）。
3. 用清楚的符号**记下意思之间的联系**——原因、转折、结果、条件（*bc* 或 ∵ 表示 *because*，*but* 或一条线，→ 或 ∴ 表示 *therefore*）：这些正是记忆最容易丢失的东西。
4. 清楚地**标出否定**（在符号上划一道）。
5. **标出强调**（下划线表示 *very*、*important*；双下划线表示 *extremely*）。
6. **竖着写**：一行一个意思，从上到下，让结构一目了然。
7. **错位排列**（*décalage*）：每个新成分（主语、动词、宾语）比前一个更向右缩进，并列的成分上下对齐。

此外，还要有一小套自己的**符号**——表示*国家*、*会议*、*增长*、*问题*、*同意*——熟练到写的时候不用思考。
:::

::: proof
罗赞的原则源于释意理论：如果口译员把意义保持在记忆中，笔记只需要起触发作用，并保存记忆无法保存的东西——论证的结构、联系、数字和名称。逐词笔记太慢（人们每分钟说一百多个词，没有人写得那么快），还会导致逐词翻译。竖式排列反映了讲话的层级结构，口译员往下一瞥，就能看到主句及其从属成分——这恰恰是英语所需要、汉语留作隐含的层级结构（[[translation/chinese-into-english#rule-four-steps]]）。口译员对用哪种语言记笔记意见不一：有的用目的语记，这样转换开始得早；许多人混用符号、缩写和对每个词来说写起来更快的那种语言——一个汉字常常比一个英语单词写得快，而一个英语缩写又比一个笔画复杂的汉字快。
:::

::: example 一段话的笔记 {#ex-notes}
展示口译员可能为本课开头那位工厂经理的话所作的笔记，以及如何把它们转成英语。
::: solution
1. **笔记**（一种可能的版本，竖着写，缩进用空格表示）：

```
line    in ↑ last y
  auto  ++
was 20 ppl
  now 3 ok
→ eff ↑ ~×5
but $ in  big
```

2. **解读**：*line*（这条生产线）；*in ↑ last y*（引进，去年）；*auto ++*（自动化程度高）；*was 20 ppl / now 3 ok*（对比，上下对齐）；*→*（结果）；*eff ↑ ~×5*（效率提高了约五倍）；*but*（让步）；*$ in big*（投入大）。
3. **译出**：联系符号（→ 和 *but*）告诉口译员在哪里用 *so* 和 *Of course*；竖向的对比 *20 / 3* 产生了 *used to … now* 的结构。口译员根据意义来说：*This production line was installed last year. It's highly automated …*

注意没有记下来的东西：比较、差不多（近似——用 ~ 保留了）、当然（由 *but* 暗示）、前期（不言自明）。记忆会补上它们。
:::
:::

::: warning 记得太多
✗ 试图记下每一个词：口译员跟不上，漏掉了下一句，并且把笔记照着念成逐词翻译。

✓ 先听，只记结构、联系、数字、名称和关键术语——而且要看着讲话人，而不只是盯着笔记本。
:::

## 数字

数字是英汉口译中最容易出错的成分，因为两种语言的数位分组不同：英语以千为单位（*thousand*、*million*、*billion*），汉语以万为单位（万、亿）（[[core-vocabulary/numbers-dates-money]]）。

::: theorem 大数字的口译 {#rule-numbers}
1. 一听到数字，就**用阿拉伯数字写下来**，连同单位。
2. **按数位分组换算**：万 = 10 thousand；十万 = 100 thousand；百万 = 1 million；千万 = 10 million；亿 = 100 million；十亿 = 1 billion。一个快捷的办法是按源语的数位体系加分隔符记下数字（3|5000万 → 3.5 亿），在纸上而不是在脑子里换算。
3. **近似的数要保持近似**：近三千万 → *nearly thirty million*；*roughly 1.5 billion* → 约十五亿。
4. **检查结果是否合理**：这座城市真的有250亿人吗？
:::

::: proof
在两种数位体系之间换算，要求口译员在把数字保持在记忆中、并继续听的同时移动小数点——用吉尔的术语来说，这对处理能力是很大的负担。写下数字可以解放记忆，在纸上换算也比心算不容易出错。合理性检查能发现最常见的错误，即差了十倍（把“十亿”译成 *one hundred million*）。口译员常常根据讲话人的文件提前准备讲话中的关键数字。
:::

::: example 换算数字 {#ex-numbers}
译成英语：去年全市接待游客一亿两千万人次，旅游收入达一千八百亿元，比前年增长百分之十二点五。
::: solution
1. **笔记**：1.2 亿 人次；1800 亿 元；+12.5%。
2. **换算**：1.2亿 = 120 million；1800亿 = 180 billion。
3. **译出**：*Last year the city received 120 million tourist visits, and tourism revenue reached 180 billion yuan, up 12.5 per cent on the year before.*

“人次”是按每人每次计算的访问量（一个人去了两次就算两次），所以 *tourist visits* 比 *tourists* 更准确。*Up 12.5 per cent on the year before* 是“比前年增长”在英语中的自然搭配。
:::
:::

## 英汉同声传译

在同声传译中，口译员不能等到句子结束；她一有足够的内容就开始说，通常比讲话人晚几秒钟（这叫**听说时差**，ear–voice span，或 *décalage*）。在英语和汉语之间，这造成了一个特殊的困难：两种语言安排修饰语、分句和要点的顺序不同（[[translation/english-chinese-compared#rule-order]]）。

::: theorem 按顺序工作：断句与预测 {#rule-linearity}
1. 把原文**切分**成短小的意义单位（有时称为“切香肠法”），每来一个单位就译出一个，用连接词或简短的重复把它们连起来：这常被称为**句法线性原则**（principle of syntactic linearity，在中国的口译课程中叫“顺句驱动”）。
2. **只在一个片段内部重组**，而不是在整个句子范围内重组。
3. **使用能让你早点开口的重新表述**：英语的长后置修饰语可以变成一个新的汉语分句，而不是名词前的“的”字短语；汉语名词前的长修饰语可以译成一个稍后才说出中心名词的英语句子。
4. 当一个片段没有下一个词就无法开始时（长修饰语末尾的汉语动词，分句末尾的英语 *not*），**稍等片刻**，但不要等到记忆溢出。
5. 根据语境、讲话惯例和讲话人的幻灯片**进行预测**——但要随时准备纠正。
:::

::: proof
如果汉语口译员要等到 *The proposal that the committee discussed at its meeting last Tuesday in Geneva after a long debate about funding …* 结束才说出“提案”，记忆就会溢出。按顺序译出——这项提案，委员会上周二在日内瓦开会时讨论过，之前就资金问题进行了长时间辩论，……——使负担保持在低水平，代价是汉语不如笔译那样优雅。口译研究和教学把这种权衡视为正常：同声传译的输出是作为口语来评判的，短分句和重复在口语中是可以接受的，而不是作为书面文本来评判。预测之所以行得通，是因为讲话在结构上（致谢、欢迎、议程各项的顺序）、常常在内容上都是可以预见的；但预测错了的口译员必须迅速、平实地补救。
:::

::: example 切分一个英语长句 {#ex-segment}
展示同声传译员可能怎样逐段把这个句子译成汉语：*The report, which was published yesterday by an independent panel of experts after two years of research, warns that water shortages could affect a quarter of the world's population by 2050.*
::: solution
1. **听到的片段**：*The report* / *which was published yesterday* / *by an independent panel of experts* / *after two years of research* / *warns that* / *water shortages could affect* / *a quarter of the world's population* / *by 2050*。
2. **按顺序译出**：

这份报告， / 昨天发布， / 由一个独立专家小组撰写， / 他们研究了两年。 / 报告警告说， / 水资源短缺可能会影响到 / 全世界四分之一的人口， / 时间是到2050年。

3. **说明**：关系从句变成了“这份报告”后面的一串简短说明；被动的 *published by* 拆成了“发布”和“由……撰写”；*after two years of research* 变成了一个分句；“报告警告说”重复主语，以重新开始主句；*by 2050* 用“时间是”加在末尾——在笔译中它会放在前面（到2050年，……）。结果是可以接受的汉语口语；笔译则会调整语序。
:::
:::

::: quiz
在汉译英同声传译中，讲话人说：我们这次在上海召开的、有来自三十多个国家和地区的代表参加的……哪一种开头最好？
- [ ] 一言不发，等中心名词出现。
- [x] *We are holding this meeting in Shanghai, and it brings together delegates from more than thirty countries and regions …*
- [ ] *Our this time in Shanghai held …*
- [ ] *The thirty countries meeting in Shanghai …*
::: solution
中心名词（会议或大会）还没有出现，但可以从语境中预测出来。用一个完整的分句开头，口译员就能按顺序译出长修饰语，等中心名词出现时再把它接上（*… and this conference is …*）。等待有超负荷的风险；另外两个选项不合语法或者是错的。
:::
:::

## 口译员的角色

::: theorem 职业操守 {#rule-conduct}
1. **准确与完整**：译出所说的一切，包括你自己不会说的话——粗鲁的话、错误、模糊限制语——不增加、不遗漏、不软化，除非场合明显需要文化调整，而且双方都已接受。
2. **公正**：不偏袒任何一方，不为任何一方出主意或辩护。
3. **保密**：不泄露工作中听到的内容。
4. **第一人称**：用讲话人的人称来译（*I propose …*，我提议……），而不是用间接引语（*He says he proposes …*）。
5. **透明**：如果你需要对方重复或澄清，或者出了错，要公开说明，用第三人称（*The interpreter would like to correct …*）。
6. **准备**：事先研究主题、讲话人和术语（[[translation/specialised-translation#rule-termbase]]）。
:::

::: proof
这些原则以各种形式出现在职业协会的守则中——对会议口译员来说，是1953年成立的国际会议口译员协会（AIIC）的守则——也出现在法庭口译和医疗口译的标准中。它们源于口译员所处的位置：双方完全依赖口译员来了解对方的话，而且无法核实。把一句粗鲁的话说得委婉些似乎是好意，但这剥夺了听者了解讲话人的信息，也使口译员成了参与者。第一人称让双方相互交谈，而不是与口译员交谈。文化调整是最难处理的情况：一个不会起作用的笑话，一个毫无意义的成语，一个在英语中听起来很奇怪的客套话。口译员通常平实地译出其意图（*a Chinese saying that means …*），而不是不声不响地把它替换掉。
:::

::: example 一个棘手的时刻 {#ex-role}
在一次商务宴请上，中方主人笑着说：我们这个小地方，招待不周，请多包涵。联络口译员应当怎样译出，为什么？
::: solution
1. **意义**：一句约定俗成的谦辞——字面意思是“我们地方小，招待得不好，请原谅”——主人并不是照字面的意思说的；它表达的是礼貌。
2. **风险**：照字面翻译（*Our place is small and our hospitality is poor, please forgive us*）可能让客人困惑或尴尬，他们可能觉得自己必须加以反驳。
3. **译出**：用一种行得通的英语形式保留礼貌和谦逊：*We're a small place, so please forgive us if we haven't looked after you as well as we'd like — we're very glad to have you here.* 最后一个分句把意图（欢迎）明确表达出来，这是主人会接受的一个小小的文化调整。
4. **不要**：换成 *Enjoy your meal!*（丢掉了谦逊），或者加上评论（*He doesn't really mean it*），那就违反了公正原则和第一人称原则。
:::
:::

::: note 英汉对比
- **方向性。** 中国的口译员常常双向工作（在汉英译员厢中，译入 B 语言的 *retour* 是正常的），而在某些国际组织，口译员主要译入自己的第一语言。译入英语时，最大的风险是时、冠词和连接词；译入汉语时，是英语的长后置修饰语和靠后出现的否定。
- **公共讲话的格式。** 汉语讲话以固定的格式开头和结尾（尊敬的各位来宾，女士们、先生们，祝大会圆满成功）；英语讲话用的是另一些格式（*Distinguished guests, ladies and gentlemen*；*I wish the conference every success*）。要事先准备好；听众最先正是在这些地方评判口译员。
- **引语和诗句。** 中国讲话人常常引用古诗句（海内存知己，天涯若比邻）。口译员不可能在两秒钟内写出文学译文：要清楚地译出意思，如果可能，事先根据讲话稿准备一个译文（[[translation/literary-translation]]）。
- **口音。** 英语和汉语都有许多口音；口译员要用世界各地的英语变体和各地方言口音的普通话训练听力（[[listening-and-conversation/accents]]）。
:::

::: history
口译与语言之间的接触一样古老，但会议口译作为一种职业始于20世纪。在1919年的巴黎和会上，英语与法语一起成为外交语言，口译员以交替传译的方式工作，常常凭笔记译出长篇讲话。戴耳机的同声传译在20世纪20年代就有过尝试，第一次大规模使用是在纽伦堡国际军事法庭（1945—1946），使用英语、法语、德语和俄语。联合国在成立初期就采用了同声传译，国际会议口译员协会（AIIC）于1953年在巴黎成立。罗赞于1956年出版了交替传译笔记指南，塞莱斯科维奇对会议口译员的研究于1968年问世。汉语在联合国成立时就是其正式语言，1973年成为联合国大会的工作语言；中华人民共和国于1971年恢复在联合国的席位后，中国会议口译员的培养发展起来，包括1979年起在北京开办的联合国支持的译员培训项目。在2020—2022年的新冠疫情期间，远程口译和在线口译得到了广泛普及。
:::

## 后续内容

机器翻译——现在也能进行自动语音翻译——是 [[translation/machine-translation]] 的主题。口译所依赖的听力技能在 [[listening-and-conversation/how-listening-works]] 和 [[connected-speech/hearing-fast-speech]] 中训练；口译员也要做的公众演讲，见 [[presentations-and-discussion/delivery]]。这里快速运用的重组技巧，就是 [[translation/english-into-chinese]] 和 [[translation/chinese-into-english]] 中的技巧。

::: summary
- 主要的**口译方式**有交替传译、同声传译、耳语传译、联络口译和视译，根据场合选择（[[#def-modes]]）。
- **译意义，不译词语**——但数字、名称、头衔和术语除外，它们必须准确保留（[[#rule-sense]]）。
- 吉尔的**精力分配模式**解释了口译为什么会在负荷过重时出错：听辨、记忆、产出（以及笔记）共享有限的处理能力。
- **笔记**按罗赞的原则，竖着写、错位排列，记下意思、联系、否定、强调、数字和名称（[[#rule-rozan]]）。
- **数字**：立即写下阿拉伯数字，在纸上把万、亿换算成 thousand、million 和 billion；检查是否合理（[[#rule-numbers]]）。
- 在英汉**同声传译**中，切分并按顺序工作（顺句驱动），在片段内部重组，稍作等待，谨慎预测（[[#rule-linearity]]）。
- **职业操守**：准确与完整、公正、保密、第一人称、对错误保持透明、事先准备（[[#rule-conduct]]）。
:::

## 习题

::: exercise 口译方式 {level=1}
下列每种场合适合哪种口译方式？(a) 一个使用六种语言的两天会议。(b) 一位来访部长在北京举行的记者招待会。(c) 一位医生和一位不会说汉语的病人。(d) 一位需要立刻知道一份中文文件内容的律师。
::: solution
(a) 同声传译，在译员厢中进行。(b) 交替传译（在记者招待会上很常见，这样两种语言都能听到），如果有设备，也可以用同声传译。(c) 联络（对话）口译，交替进行，话轮简短。(d) 视译。
:::
:::

::: exercise 数字 {level=1}
换算。(a) 三千五百万 (b) 四亿 (c) 2.8 billion (d) 650,000
::: solution
(a) *35 million* (b) *400 million* (c) 二十八亿 (d) 六十五万
:::
:::

::: exercise 笔记符号 {level=1}
为每个意思创造或选择一个快捷的笔记符号或缩写，并解释它为什么好记。(a) *increase* (b) *government* (c) *because* (d) *cooperation* (e) *not*
::: solution
可能的答案：(a) ↑（方向）；(b) *gov* 或一个插着旗子的方框（一座建筑）；(c) ∵ 或 *bc*；(d) 两个相连的圆圈，或“合”；(e) 在下一个符号上划一道。任何统一、快捷、不会混淆的体系都可以；检验的标准是十分钟后你能否不假思索地读懂它。
:::
:::

::: exercise 凭笔记交替传译 {level=2}
请同伴以正常语速朗读下面这段话一遍，你按罗赞的原则做笔记；然后把它译成汉语。*Thank you, Chair. Our company has worked in this region for fifteen years. We now employ about two thousand local staff, and last year we opened a training centre for young engineers. But we face two problems: high transport costs and a shortage of skilled technicians. We hope that today's meeting will help us find solutions to both.*
::: solution
参考译文：谢谢主席。我们公司在这个地区已经经营了十五年，现在雇用了大约两千名当地员工，去年还开办了一个青年工程师培训中心。但是我们面临两个问题：一是运输成本高，二是缺乏熟练技术人员。我们希望今天的会议能帮助我们找到解决这两个问题的办法。——检查你的笔记中是否有：15 y，~2000 local，last y training centre，*but*（一个清楚的联系符号），竖向列出的2个问题，hope → solutions。两个问题的列举很自然地译成“一是……二是……”，这是汉语表示列举的结构。
:::
:::

::: exercise 切分 {level=2}
像同声传译员那样，不等句子结束，逐段把这个句子译成英语：由我国自主研发、历时十年建成、全长五十五公里的这座跨海大桥，今天正式通车。
::: solution
一种可能的顺序译法：*Developed independently in this country, / built over ten years, / fifty-five kilometres long, / this sea-crossing bridge / opened to traffic today.*——每个汉语修饰语都变成放在主语前面的英语分词短语或形容词短语，这是英语允许的；中心名词在汉语给出时才出现。笔译则更可能说 *The 55-kilometre sea bridge, developed independently in China and built over ten years, opened to traffic today.*
:::
:::

::: exercise 一句谦辞 {level=2}
为中国听众译成汉语，让礼貌显得自然：*I'm no expert on this, so I'm sure you'll correct me if I get anything wrong — but here's how I see it.*
::: solution
参考译文：我在这方面不是专家，说得不对的地方，还请大家指正。下面谈谈我的一点看法。——英语的模糊限制变成了汉语的格式“还请大家指正”和“一点看法”，这些是约定俗成的说法，听起来很自然；照字面翻译（我肯定你们会纠正我）会显得很奇怪。
:::
:::

::: exercise 职业伦理 {level=3}
你在一家中国供应商和一位英国买家的会谈中担任口译。买家恼火地说：*Frankly, your last shipment was a disaster, and if this happens again, we're finished with you.* 你很熟悉的供应商经理显得很焦虑。你会怎么说，为什么？如果供应商后来私下问你买家“到底怎么想”，你会怎么做？
::: hint
想一想准确、公正、保密和第一人称。
:::
::: solution
用第一人称准确地译出，保留其力度：坦白说，你们上一批货简直是一场灾难。如果再出现这种情况，我们就不跟你们合作了。把它说得委婉些（例如“上一批货有些问题”）会剥夺供应商的重要信息，也使你成了参与者。语气可以与原话相当，但不要夸大。私下里，你不能发表对买家意图的看法，也不能透露其他谈话中的任何内容：你可以说你的职责是译出所说的话，并建议供应商在会谈中通过你直接问买家。
:::
:::

::: exercise 视译 {level=3}
把这段话视译成英语，大声说出并录音，然后听录音，列出你在表达上的两个问题和英语上的两个问题。本次活动旨在增进两国青年之间的相互了解与友谊。活动期间，双方代表将参观学校、企业和社区，并就教育、就业等共同关心的问题深入交流。
::: solution
参考译文：*The aim of this event is to build understanding and friendship between young people from our two countries. During the visit, the delegates will tour schools, businesses and local communities, and will have in-depth discussions on issues of shared concern, such as education and employment.* 要找的典型问题：表达方面，说出第一个动词之前长时间犹豫，重新开头，语调平板；英语方面，逐词对译，如 *mutual understanding and friendship among the youths*，“社区”译成 *communities* 而不加 *local*，或者 *deeply exchange*。注意“旨在”变成了 *The aim … is to*，“就……深入交流”变成了 *have in-depth discussions on*。
:::
:::
