陈静在开普敦的一所大学访学一个学期。第一天早上，她问一位实验室技术员设备什么时候能准备好。*I'll do it just now*，他说，于是她在实验台旁等着。二十分钟后她又问了一次。*Now-now*，他笑着说，这一次两分钟就准备好了。一个星期后，一位从都柏林来的客座讲师对她说 *I'm after reading your report*，她一时拿不准他到底读了没有。在一次会议晚宴上，一位加拿大学生跟她讲起湖边的一座 [hʌʊs]，一位澳大利亚同事问她星期天 arvo 去不去参加 barbie。

这些句子里没有一个是错误。*Just now* 在南非英语中的意思是“过一会儿，稍后”，*now-now* 的意思是“马上”；*I'm after reading it* 在爱尔兰英语中的意思是“我刚读完”；加拿大人 *house* 中的元音，以及澳大利亚人的 *barbie*“烧烤”和 *arvo*“下午”，都是数以百万计的人所说的标准变体中的普通特征。这些国家都属于卡奇鲁的内圈（[[world-englishes/models#def-circles]]）：英语是大多数人口或者很大一部分人口的第一语言。然而每个国家都有自己的英语，它由谁在什么时候到那里定居、他们遇到了哪些其他语言所塑造。

本章描述其中的七种：在凯尔特语言旁边成长起来的爱尔兰、苏格兰和威尔士的英语，以及在移民殖民地成长起来的加拿大、澳大利亚、新西兰和南非的英语。本章用威尔斯的词汇集（[[sounds-of-english/phonemic-alphabet#def-lexical-set]]）来描述元音，并以 [[world-englishes/british-american]] 中英式英语和美式英语的比较为基础。

## 新变体是怎样形成的

::: definition 方言、口音和变体 {#def-variety}
**方言**（dialect）是一种语言的某种形式，有自己的语法和词汇，通常也有自己的发音，为一个地区群体或社会群体所共有；**口音**（accent）是一种发音方式（[[listening-and-conversation/accents#def-accent]]）。**变体**（variety）是语言学家用来指一种语言任何可以区分出来的形式——国家标准、地区方言、社会方言——的中性术语，不暗示它的地位如何。
:::

当来自英国和爱尔兰许多地区、说英语的移民来到一个新的国家时，他们带来了许多方言。他们的子女并不说其中任何一种；他们说的是一种新的混合体。英国语言学家特鲁吉尔（Peter Trudgill）在《新方言的形成：殖民地英语的必然性》（*New-Dialect Formation: The Inevitability of Colonial Englishes*，2004）中描述了这一过程，他使用的是新西兰第一代移民后代的录音，这些录音录制于20世纪40年代，由“新西兰英语的起源”（Origins of New Zealand English）项目加以研究（戈登等，Gordon et al. 2004）。

::: theorem 新方言形成的阶段 {#rule-new-dialect}
按照特鲁吉尔（2004）的观点，当说不同方言的人在一起定居时，大约经过三代就会形成一种新的方言：

1. **初步拉平**（rudimentary levelling）——成年移民放弃自己言语中一些地方色彩最浓的特征。
2. **变异**（variability）——在殖民地出生的第一代人说话时个人差异很大，混用父母和邻居方言的特征。
3. **聚焦**（focusing）——下一代人确定了一种共同的变体。通常是**多数**形式胜出：大多数最初移民所用的特征保留下来，少数特征消失。

有些少数特征以新的功能保留下来（**再分配**，reallocation），新变体还可能产生原有方言中都没有的形式。
:::

::: proof
这一理论解释了为什么澳大利亚英语、新西兰英语和南非英语在许多方面听起来很相似。三者主要都是在19世纪由同样的混合人群定居的——英格兰南部人、英格兰其他地区的人、苏格兰人和爱尔兰人，其中英格兰南部人是最大的群体。这一混合体中的多数特征——无 R 音、BATH 类词中的长 /ɑː/——成了新变体的特征。相比之下，美国在更早的17和18世纪就有人定居，那时无 R 音还没有在英格兰南部传开，而且移民的构成也不同，这有助于解释为什么美式英语有 R 音。特鲁吉尔认为结果基本上由混合的比例决定，这一观点有争议：其他研究者更看重声望和身份认同等社会因素，施奈德的动态模型就是如此（[[world-englishes/models#def-dynamic]]）。但这些阶段本身是有充分记录的。
:::

## 爱尔兰

英语随12世纪盎格鲁-诺曼人的入侵传入爱尔兰，但成为大多数人口的语言要晚得多：先是通过16和17世纪的殖民垦殖，尤其是在19世纪——大饥荒（1845–1852）、移民和英语授课的学校教育，使大多数说爱尔兰语的人在几代之内转用了英语。根据1937年宪法，爱尔兰语（盖尔语）是爱尔兰共和国的第一官方语言，英语是第二官方语言；英语是大多数人的第一语言。**爱尔兰英语**（Irish English，也称 Hiberno-English）显示出爱尔兰语的影响，尤其是在语法上，因为整个民族是把英语作为第二语言学会、然后传给子女的。

::: theorem 爱尔兰英语的一些特征 {#rule-irish}
1. ***after* 完成体**：用 *be after* + *-ing* 表示最近完成的动作：*I'm after finishing the report*“我刚写完报告”。它对应于爱尔兰语中一个用 *tar éis*“在……之后”的结构。
2. **习惯性 *do be***：*He does be tired in the evenings*“他晚上通常很累”。
3. **复数 *you***：复数用 *ye* 或 *youse*（*Are ye coming?*）。
4. **内嵌倒装**：*I wonder is he coming*（标准英语为 *I wonder whether he is coming*）。
5. **用分裂句表示强调**：*It's tired you are*“你累了”，把焦点成分提到 *it's* 后面。
6. **发音**：有 R 音；FACE 和 GOAT 常为单元音 [eː]、[oː]；/θ/ 和 /ð/ 常为齿塞音 [t̪]、[d̪]（*think*、*this*）；/l/ 在所有位置都是清晰 l。
:::

::: example 理解爱尔兰英语 {#ex-irish}
用标准英语解释每个句子的意思，并说出是哪个特征。（a）*She's after telling me the news.*（b）*Ye'll be hungry after the journey.*（c）*They do be working late on Fridays.*（d）*I asked him was he ready.*
::: solution
1. （a）“她刚把消息告诉我”——*after* 完成体（[[#rule-irish]] 第1点）。意思是**最近**完成的事件，而不是将来的事件；把 *after* 理解为“以后”的学习者会误解。
2. （b）“你们旅途之后会饿的”——复数 *ye*（第3点）。
3. （c）“他们星期五通常工作到很晚”——习惯性 *do be*（第2点）。
4. （d）“我问他是否准备好了”——内嵌倒装（第4点）：间接疑问句里保留了 *Was he ready?* 的疑问语序。

这四种用法在爱尔兰英语口语中都是标准的，（a）、（c）和（d）也出现在爱尔兰作家描写对话的作品中。
:::
:::

## 苏格兰

苏格兰有两种关系密切、都源自古英语的言语形式：**苏格兰语**（Scots），由古英语的诺森布里亚方言发展而来，直到17世纪都是苏格兰宫廷和文学的语言；以及**苏格兰标准英语**（Scottish Standard English），即用苏格兰口音说的标准英语。许多说话人根据场合在两者之间的连续体上移动。根据《欧洲区域或少数民族语言宪章》，英国承认苏格兰语为一种区域或少数民族语言；在苏格兰2011年的人口普查中，约150万人报告说会说苏格兰语。盖尔语是一种凯尔特语言，主要在高地和岛屿地区使用。

::: theorem 苏格兰英语的一些特征 {#rule-scottish}
1. **有 R 音**：元音后有 /r/，常为闪音 [ɾ]（*car* [kaɾ]）。
2. **元音对立较少**：FOOT 和 GOOSE 没有区别（*pull* 和 *pool* 同音，[pʉl]），TRAP 和 PALM、LOT 和 THOUGHT 之间也常常没有区别（*cot* 和 *caught* 听起来一样）。
3. **FACE 和 GOAT 为单元音**：[e]、[o]。
4. **苏格兰元音长度规则**（Scottish Vowel Length Rule）：元音的长短取决于后面的音——在 /r/ 前、浊擦音前和语素末尾为长元音，其他地方为短元音——所以 *brewed* 的元音长，*brood* 的元音短。
5. ***loch*** 以及苏格兰语词语和名字中有 **/x/**。
6. **词语**，如 *wee*“小的”、*outwith*“在……之外”、*kirk*“教堂”、*bairn*“孩子”、*ken*“知道”（苏格兰语）。
7. **语法**：*I'll not* 与 *I won't* 并用；*need* + 过去分词（*The car needs washed*）。
:::

苏格兰元音长度规则很好地说明了一种口音可以以参考口音所没有的方式而有系统性。在 GB 中，*brewed* 和 *brood* 的区别不是元音长短的问题；在苏格兰英语中却是，而且可以根据词的语法结构预测（*brewed* 是 *brew* + *-ed*）。

## 威尔士

英语从16世纪起在威尔士传播，19世纪随着工业化传播得尤其快；威尔士语是一种凯尔特语言，至今仍是相当一部分少数人的第一语言，特别是在北部和西部。《1993年威尔士语言法》赋予威尔士语在威尔士公共事务中与英语平等的地位，《2011年威尔士语言（威尔士）措施》则赋予它官方地位。**威尔士英语**（Welsh English）在说威尔士语的北部和西部与工业化的东南部之间差别很大。许多说话人身上描述到的特征（威尔斯 Wells 1982，第2卷）包括：/l/ 在所有位置都是清晰 l；FACE 和 GOAT 常为单元音；元音之间的辅音延长（*money* [ˈmʌnːi]）；不变的附加疑问 *isn't it?*（*You're coming tomorrow, isn't it?*）；以及为了聚焦而把一个短语前置（*Coal they were carrying*），这对应于威尔士语的一种句式。大多数变体没有 R 音。

::: quiz
一个人说 *I'm after phoning the office.* 这最可能是哪种变体，是什么意思？
- [ ] 苏格兰英语；“我待会儿给办公室打电话。”
- [x] 爱尔兰英语；“我刚给办公室打过电话。”
- [ ] 南非英语；“我正要给办公室打电话。”
- [ ] 加拿大英语；“我在找办公室的电话号码。”
::: solution
*be after* + *-ing* 完成体是爱尔兰英语的一个著名特征（[[#rule-irish]]），表示最近完成的动作。它从不表示“以后”。
:::
:::

## 加拿大

**加拿大英语**（Canadian English）由效忠派的英语发展而来。效忠派是在美国独立战争（1775–1783）期间和之后离开美国的英国王室支持者，后来又有大批来自英国和爱尔兰的移民加入。因此，加拿大英语在发音和许多词汇上接近美式英语，但保留了一些英式惯例。根据1969年的《官方语言法》，法语是另一种官方语言，加拿大英语从法语中借用了一些词（*poutine*“肉汁奶酪薯条”，*tuque* 或 *toque*“毛线帽”）。

::: theorem 加拿大英语的一些特征 {#rule-canadian}
1. **有 R 音**，与 GA 一样，元音也大体与 GA 相似，/t/ 发闪音。
2. **加拿大式抬高**（Canadian raising）：PRICE 和 MOUTH 的双元音在清辅音前以一个较高、较央的元音开始。*Write* 是 [rʌɪt]，而 *ride* 是 [raɪd]；*about* 和 *house* 用 [ʌʊ]，而 *loud* 和 *houses* 不用。
3. **LOT–THOUGHT 合并**：对大多数说话人来说，*cot* 和 *caught* 听起来一样。
4. **拼写**：一种混合——*colour*、*centre* 和 *cheque* 与英国相同，但 *-ize*、*tire* 和 *curb* 与美国相同；《加拿大牛津词典》（*Canadian Oxford Dictionary*，1998）等参考书记录了通常的选择。
5. **词汇**：*washroom*“公共厕所”，*loonie*“一元硬币”，*toque*；*eh* 作为征求同意的附加语（*Nice day, eh?*）。
:::

::: example 加拿大式抬高 {#ex-raising}
预测一位加拿大人读下列词时，元音是抬高的（[ʌɪ]、[ʌʊ]）还是不抬高的（[aɪ]、[aʊ]）：（a）*knife*，（b）*knives*，（c）*mouth*（名词），（d）*mouths*，（e）*rice*，（f）*rise*。
::: solution
应用 [[#rule-canadian]] 第2点：在**清**辅音前抬高，在浊辅音前或词尾不抬高。

1. （a）*knife* /f/——清音：**抬高** [nʌɪf]。
2. （b）*knives* /vz/——浊音：**不抬高** [naɪvz]。
3. （c）*mouth* /θ/——清音：**抬高** [mʌʊθ]。
4. （d）*mouths*——通常为 /ðz/，浊音：**不抬高** [maʊðz]。
5. （e）*rice* /s/——清音：**抬高** [rʌɪs]。
6. （f）*rise* /z/——浊音：**不抬高** [raɪz]。

这条规则非常有规律，以至于同一个词的单数和复数形式会出现元音差别。美国北部部分地区的许多说话人也有类似的模式，至少在 PRICE 上如此。
:::
:::

## 澳大利亚

英语于1788年随运送囚犯和官员的“第一舰队”（First Fleet）来到澳大利亚。在那里出生的头几代人，从伦敦、英格兰东南部、爱尔兰和其他方言的混合中，到19世纪中叶形成了一种可以辨认的澳大利亚口音（[[#rule-new-dialect]]）。1965年，米切尔（Alexander Mitchell）和德尔布里奇（Arthur Delbridge）在《澳大利亚青少年的言语》（*The Speech of Australian Adolescents*）中描述了一个从**粗犷型**（broad）经**一般型**（general）到**文雅型**（cultivated）的澳大利亚英语连续体，最后一种最接近 RP；此后，文雅型一端变得越来越少，一般澳大利亚英语成了全国标准。《麦考瑞词典》（*Macquarie Dictionary*，1981）把澳大利亚的词汇和拼写规范化了，拼写大多遵循英国惯例。

::: theorem 澳大利亚英语的一些特征 {#rule-australian}
1. **无 R 音**，BATH 类词大多用 /ɑː/（不过许多词，如 *dance* 和 *castle*，因地区和说话人不同而在 /ɑː/ 和 /æ/ 之间变化）。
2. **起点移位的双元音**：FACE 的起点较低，接近 [æɪ]（*day*）；PRICE 的起点较后，接近 [ɑe]；GOAT 的起点较开、较央。
3. 元音之间的 **/t/ 发闪音**，与 GA 一样（*water* [ˈwoːɾə]）。
4. **陈述句末升调**（high rising terminal）：陈述句末尾用升调，尤其在叙述和解释中，用来确认听话人在跟着听。它不会把陈述句变成疑问句。
5. 以 *-o* 和 *-ie*/*-y* 结尾的**指小词**：*arvo*“下午”，*servo*“加油站”，*brekkie*“早餐”，*barbie*“烧烤”；许多是非正式的，但所有社会群体都使用。
6. **来自原住民语言的借词**，尤其是表示动植物和地名的：*kangaroo*、*koala*、*boomerang*、*Canberra*。
:::

澳大利亚还有**原住民英语**（Aboriginal English），这是许多原住民和托雷斯海峡岛民所说的一组变体，具有语法、词汇和话语方面的特征——例如直接提问和对话中沉默的不同用法——语言学家伊兹（Diana Eades）在《原住民使用英语的方式》（*Aboriginal Ways of Using English*，2013）中对此作了描述。原住民英语使用者和标准澳大利亚英语使用者在法庭和学校里的误解，一直是她研究的重点。Kriol 是澳大利亚北部一种以英语为词汇来源的克里奥尔语，在 [[world-englishes/pidgins-creoles]] 中介绍。

## 新西兰

英国对新西兰有系统的移民定居始于英国王室与毛利酋长签订《怀唐伊条约》（1840）之后。**新西兰英语**（New Zealand English）与澳大利亚英语相似，但又有所不同；“新西兰英语的起源”项目所分析的录音显示，它形成于19世纪后期。根据1987年的《毛利语言法》，毛利语成为官方语言，此后毛利语对新西兰英语词汇的影响大大增加。

::: theorem 新西兰英语的一些特征 {#rule-nz}
1. **前元音链移**：TRAP 和 DRESS 抬高（所以用其他口音的标准来看，*bad* 接近 [bed]，*pen* 接近 [pin]），KIT 央化为一个接近 [ə] 的元音（*fish*、*six*）。
2. **NEAR–SQUARE 合并**：对许多年轻人来说，*beer* 和 *bear*、*here* 和 *hair* 听起来一样，通常都用 NEAR 的元音。
3. **无 R 音**（南岛南部部分地区除外，那里保留着一种与苏格兰移民有关的 R 音口音）。
4. 陈述句中的**句末升调**，与澳大利亚一样。
5. 所有新西兰人日常使用的**毛利语词**：*kia ora*“你好，谢谢”，*whānau*“大家庭”，*kai*“食物”，*haka*，*Aotearoa*“新西兰”。
:::

::: example 听新西兰元音 {#ex-nz}
一位新西兰人对陈静说：*Put the pen next to the bed.* 她听到的是 *pin* 和 *bid*。过了一会儿他说 *There's a fish in the tank*，她听到的接近 *fush*。解释每一种听感，并说明她可以怎样适应。
::: solution
1. *pen*、*bed*——新西兰的 DRESS 元音抬高了（[[#rule-nz]] 第1点），所以在习惯 GB 或 GA 的听者听来，它像他们的 KIT 元音：*pin*、*bid*。
2. *fish*——新西兰的 KIT 元音央化了，接近 [ə]，所以在她听来像她的 STRUT 元音：*fush*。

这两项变化是相互关联的：DRESS 向上移进 KIT 的位置，KIT 就移向中央，所以对新西兰人来说这两个词仍然有区别（*pen* ≠ *pin*）。为了适应，陈静可以始终如一地运用这些对应关系：这位说话人在 *pen*、*bed*、*ten* 中类似 [i] 的元音是 DRESS；在 *fish*、*six*、*big* 中类似 [ə] 的元音是 KIT。正如 [[listening-and-conversation/accents#rule-adapt]] 所说，听者通常几分钟之内就能学会这样的对应关系。这些元音和 GB 的一样有规律；只是排列方式不同而已。
:::
:::

## 南非

英国人于1795年、又于1806年从荷兰人手中夺取了开普，说英语的移民从1820年起大批到来。南非的英语一直与阿非利卡语（由荷兰语发展而来）以及祖鲁语（isiZulu）、科萨语（isiXhosa）和索托语（Sesotho）等非洲语言接触。1996年宪法承认了11种官方语言，英语是其中之一；2023年南非手语被增列为第12种。英语是少数人的家庭语言（2011年人口普查中不到总人口的十分之一），但它是政府、高等教育、商业和全国性媒体的主要语言，也是数百万人的第二语言。

语言学家区分几种**南非英语**（South African Englishes）：南非白人英语（大多数英国裔南非英语使用者的第一语言）、南非黑人英语（一种第二语言变体，在城市中产阶级中越来越多地成为第一语言）、南非印度裔英语（现在是大多数印度裔南非人的第一语言），以及开普平原（Cape Flats）的英语等。《按历史原则编纂的南非英语词典》（*Dictionary of South African English on Historical Principles*，1996）把它们共有的词汇规范化了。

::: theorem 南非英语的一些特征 {#rule-sae}
1. **来自阿非利卡语和非洲语言的词**：*braai*“烧烤”，*bakkie*“皮卡”，*veld*“开阔的草原”，*indaba*“会议，大会”（来自祖鲁语），*lekker*“好的，棒的”。
2. **独特的时间表达**：*just now*“过一会儿，稍后”；*now-now*“马上”；*now*“很快”。
3. **英语词的本地意义**：*robot*“交通信号灯”；*location*（历史上）“黑人城镇”。
4. **回应语 *Is it?***，不变地用来表示感兴趣，相当于 *Really?*（*I've just come back from Durban. — Is it?*）。
5. **发音**（南非白人英语）：无 R 音；“KIT 分裂”（KIT split），即 KIT 在软腭辅音和 /h/ 旁边为 [ɪ]（*kit*、*big*、*his*），在其他地方为一个较央的元音（*bit*、*limit*）；GOOSE 元音前移。
:::

::: example 理解时间词 {#ex-sae}
回到本章开头。开普敦的技术员说 *I'll do it just now*，后来又说 *Now-now*。解释这个误会，并建议陈静本可以怎样避免它。
::: solution
在南非英语中，*just now* 的意思是“过一会儿，稍后”（[[#rule-sae]] 第2点），而在英式和美式英语中它的意思是“刚才”或“此刻”。陈静按 GB 或 GA 的意思理解，等着对方马上行动。*Now-now* 的意思是“马上”，所以第二次回答之后很快就有了行动。

她本可以**具体地问一问**：*Sorry — will that be in a few minutes, or later today?* 这一策略对每种变体都有效（[[listening-and-conversation/clarification]]）。没有人说错话；同样的词在不同的标准变体中有不同的约定意义，就像 *table* 和 *quite* 在英国和美国之间那样（[[world-englishes/british-american]]）。
:::
:::

::: warning 把某个特征当笑话来学
✗ 模仿澳大利亚人的 *barbie* 或爱尔兰人的 *I'm after…* 来逗全班笑，或者用一种变体最刻板化的特征来描述它。
✓ 把这些特征当作关于数百万人如何说话的事实来学，了解它们的意义和使用场合。

这些变体的许多特征在国外主要是通过笑话和广告为人所知的，而笑话和广告会夸大这些特征，并把它们与对说话人的刻板印象联系起来。一个对该变体的说话人使用夸张特征的学习者，很可能是在冒犯对方，而不是在显示知识。学习这些特征的目的是**理解**说话人，而不是模仿他们。
:::

::: note 英汉对比
- **熟悉的模式。** 移民殖民地中新变体的发展在汉语中也有类似情况：新加坡、马来西亚和台湾所说的华语在各社群分开之后形成了自己的词汇和发音，新加坡和马来西亚的“巴刹”（市场，来自马来语 *pasar*）这样的词显示了与当地语言的接触。这些是变体，不是错误。
- **时间词。** 陈静对 *just now* 的困惑很常见：汉语的“刚才”与 GB/GA 的意义相同，所以学习者以为它到处都是这个意思。凡是时间表达很重要的时候，都要核实一下。
- **听力练习。** 主要听惯 GB 或 GA 的学习者，起初常常觉得苏格兰、新西兰和南非口音很难听懂。本章中的特征都是有规律的，事先了解它们可以缩短适应所需的时间。
:::

::: history
对这些变体的描述是随着它们的规范化而出现的。在19世纪，“殖民地”词语汇编——常常由觉得这些词很好笑的访客编写——是主要的资料来源。严肃的描述始于20世纪：米切尔和德尔布里奇对澳大利亚言语的研究（1965）；威尔斯（John Wells）的《英语口音》（1982），其第二、三卷涵盖了不列颠群岛和不列颠群岛“以外”的英语；澳大利亚的《麦考瑞词典》（1981）；《按历史原则编纂的南非英语词典》（1996）；《新西兰英语词典》（*Dictionary of New Zealand English*，1997）；以及《加拿大牛津词典》（1998）。“新西兰英语的起源”项目利用20世纪40年代录制的早期新西兰人的录音，为新变体的形成提供了难得的证据，由戈登等（2004）和特鲁吉尔（2004）加以分析。
:::

## 后续内容

英语主要作为第二语言的后殖民英语——南亚、东南亚、非洲和加勒比的英语——是接下来三章的主题，从 [[world-englishes/south-asian-englishes]] 开始。理解陌生口音的策略见 [[listening-and-conversation/accents]]，围绕地区口音的态度见 [[world-englishes/accent-identity]]。语言学家怎样研究地区变异和社会变异，是 [[linguistics/variation-change]] 的主题。

::: summary
- 英语是爱尔兰、苏格兰、威尔士、加拿大、澳大利亚和新西兰大多数人的第一语言，也是南非少数人的第一语言；每个国家都有自己的标准变体（[[#def-variety]]）。
- 新变体由移民方言的混合经过大约三代形成，通常保留多数形式（特鲁吉尔2004；[[#rule-new-dialect]]）。
- 爱尔兰英语有 *after* 完成体、习惯性 *do be* 和复数 *ye*（[[#rule-irish]]）；苏格兰英语有 R 音，元音对立较少，有苏格兰元音长度规则，并与苏格兰语并存（[[#rule-scottish]]）。
- 加拿大英语接近美式英语，有加拿大式抬高和混合拼写（[[#rule-canadian]]）。
- 澳大利亚英语和新西兰英语无 R 音，双元音和前元音发生了移位；新西兰英语有 NEAR–SQUARE 合并和许多毛利语词（[[#rule-australian]]、[[#rule-nz]]）。
- 南非英语有来自阿非利卡语和非洲语言的词，并有自己的时间表达（*just now*“稍后”，*now-now*“马上”）（[[#rule-sae]]）。
- 学习这些特征是为了理解说话人，而不是为了模仿或嘲笑他们。
:::

## 习题

::: exercise 哪种变体？ {level=1}
说出下列每个词或短语典型地属于哪种变体：（a）*arvo*，（b）*whānau*，（c）*robot*“交通信号灯”，（d）*loonie*，（e）*wee*“小的”，（f）*ye*（复数 *you*）。
::: solution
（a）澳大利亚英语（b）新西兰英语（c）南非英语（d）加拿大英语（e）苏格兰英语（f）爱尔兰英语
:::
:::

::: exercise 有没有 R 音 {level=1}
下列变体中哪些通常有 R 音？苏格兰英语、爱尔兰英语、加拿大英语、澳大利亚英语、新西兰英语（全国大部分地区）、南非白人英语、威尔士英语（大多数变体）。
::: solution
有 R 音：苏格兰英语、爱尔兰英语、加拿大英语。无 R 音：澳大利亚英语、新西兰英语（南岛南部部分地区除外）、南非白人英语、大多数威尔士英语变体。
:::
:::

::: exercise 意义 {level=1}
用标准英式或美式英语说出意思：（a）爱尔兰英语 *I'm after eating*；（b）南非英语 *now-now*；（c）澳大利亚英语 *brekkie*；（d）苏格兰英语 *The car needs washed*；（e）加拿大英语 *washroom*。
::: solution
(a) ‘I have just eaten.’ (b) ‘very soon’ (c) ‘breakfast’ (d) ‘The car needs washing / needs to be washed.’ (e) ‘public toilet, restroom’
:::
:::

::: exercise 加拿大式抬高 {level=2}
加拿大人读下列哪些词时通常用抬高的元音？*bike*、*tribe*、*shout*、*loud*、*wife*、*wives*、*ice*、*eyes*。解释其中的规律。
::: solution
抬高：*bike*、*shout*、*wife*、*ice*——每个词的 PRICE 或 MOUTH 都在清辅音（/k/、/t/、/f/、/s/）之前。不抬高：*tribe*、*loud*、*wives*、*eyes*——在浊辅音（/b/、/d/、/vz/、/z/）之前（[[#rule-canadian]]）。
:::
:::

::: exercise 解释元音 {level=2}
一位苏格兰人读 *tied* 时用长元音，读 *tide* 时用短元音，尽管两个词都是 PRICE 元音、都以 /d/ 结尾。用 [[#rule-scottish]] 解释原因。
::: solution
根据苏格兰元音长度规则，元音在语素末尾为长元音。*Tied* 是 *tie* + *-d*：元音位于语素 *tie* 的末尾，所以是长的。在 *tide* 中，元音后面在同一个语素内跟着 /d/，所以是短的。这种差别要根据词的结构来预测，而不能只根据语音。
:::
:::

::: exercise 新方言 {level=2}
用 [[#rule-new-dialect]]，以三四个句子解释为什么澳大利亚英语和新西兰英语没有 R 音，而美式英语和加拿大英语有 R 音。
::: solution
新变体往往保留大多数最初移民的特征。澳大利亚和新西兰主要在19世纪有人定居，那时无 R 音在英格兰南部已很普遍，而英格兰南部人是最大的移民群体；无 R 音就在新变体中保留下来。北美洲的定居更早，从17世纪就开始了，那时无 R 音还没有传开，而且移民来自有 R 音的地区；加拿大英语主要是从美国效忠派的英语发展而来的。所以这一差别反映了定居的时间和移民的来源。
:::
:::

::: exercise 听力计划 {level=3}
你将在格拉斯哥、都柏林、奥克兰或约翰内斯堡度过一个学期（任选其一）。写一个简短的计划（150–200词），为听懂当地英语做准备：你预计会遇到本章中的哪些特征，你将怎样练习听辨它们，以及当一个词或时间表达不清楚时你会使用的两个澄清问题。
::: solution
答案因人而异。例如，一个针对奥克兰的好计划会列出抬高的 DRESS 和 TRAP 以及央化的 KIT 元音（所以 *pen* 听起来可能像 *pin*，*fish* 接近 *fush*）、NEAR–SQUARE 合并（*here* 和 *hair*）、句末升调（并不表示说话人在提问），以及 *kia ora*、*whānau* 和 *kai* 等毛利语词。它会计划在访谈或播客中听几位不同的新西兰人说话，记下元音的对应关系（[[listening-and-conversation/accents#rule-adapt]]），并包括 *Sorry, did you say "ten" or "tin"?* 和 *What does "whānau" mean exactly here?* 这样的问题。
:::

::: exercise 描述一种变体 {level=3}
从本章中选一种变体，写一段180–220词的文字向同学介绍它：在哪里使用，怎样发展而来，三个特征（至少一个语法或词汇特征和一个发音特征，各附一个例子），以及关于它今天地位的一点。通篇使用中性的描述性语言。
::: solution
答案因人而异。一段好的文字内容准确，至少引用一个来源（威尔斯1982，特鲁吉尔2004，关于爱尔兰英语的希基 Hickey 2007，关于新西兰英语的戈登等2004），每个特征都附有例子和释义（*I'm after finishing it*“我刚做完”），并避免使用 *strange*、*funny*、*lazy* 或 *wrong* 等评价性词语。它应当提到地位：例如，爱尔兰语是爱尔兰的第一官方语言，而英语是大多数人的第一语言；或者毛利语自1987年起是新西兰的官方语言。
:::
