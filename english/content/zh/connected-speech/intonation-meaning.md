两位酒店前台对一位客人说了完全相同的话：*Good morning. How can I help you?*（早上好。有什么可以帮您？）第一位的声音在 *mor-* 上升得很高，然后降得很低；在 *help* 上又清楚地动了一下。第二位的声音几乎不动——每个音节都差不多在同一个音高上。两人的话都合乎语法，发音都正确，用的也都是“对的”调。可是大多数说英语的听话人会说，第一位前台很友好，第二位则显得厌倦、疲惫，甚至无礼。

上一章[[connected-speech/intonation-basics]]讲了调的选择——降调、升调、降升调——怎样帮助标示陈述句和疑问句、列举和附加疑问句，以及话轮的结束。本章讲英语语调的另一项主要工作：表示说话人的**态度**和感情——感兴趣、惊讶、礼貌、怀疑、不耐烦。这在很大程度上并不取决于用哪个调，而取决于**音域**：声音移动的幅度有多大。这是学习者最容易被误解的领域之一，因为听话人对语调作出反应时，自己往往并没有察觉。

## 音域

::: definition 音域 {#def-range}
说话人在某一时刻的**音域**（pitch range），是他所用的最高音高和最低音高之间的距离。说话人可以用**宽**的音域（变化大，峰值高，结尾低），也可以用**窄**的音域（变化小，接近中间的音高）。音域是相对于每个人自己的嗓音而言的：重要的是用了自己音域的多少。

音域可以从一个调群到下一个调群发生变化，也可以在单个调核上改变：**高降调**从音域的顶部附近开始，**低降调**从中间开始。
:::

::: theorem 音域暗示什么 {#rule-range}
在英语中（GB 和 GA 都是如此）：

1. 比平常**宽**的音域暗示**投入**：感兴趣、热情、惊讶、温暖，或任何强烈的感情——包括愤怒。用高降调说 *That's a ˈgreat i↘**dea**!*（这主意太棒了！）听起来很热情。
2. 比平常**窄**的音域暗示**不投入**：例行公事、厌倦、疲惫、伤心——如果出乎意料，还会显得不友好。同样一句 *That's a great i↘**dea**.*（这主意不错。）用低而小的降调说出来，听起来可能礼貌但不以为然，或者带有讽刺。
3. 一个调群的起点比前一个**高**，表示它是**新的、对比的或令人惊讶的**；起点**低**，则表示补充或插话：*I ˈmet ↘**Sam** — | (lower) you ˈknow, my ˈold ↘**neigh**bour.*（我遇见了萨姆——（较低）你知道的，我以前的邻居。）

这些都是倾向，而不是固定的意义。窄的音域在正式的通知或念一串数字时是正常的，在那些场合并不算无礼。
:::

::: proof
为什么宽的音域听起来是感兴趣？古森霍文（Carlos Gussenhoven）在《声调与语调的音系学》（*The Phonology of Tone and Intonation*，2004）中提出的一种解释是“用力代码”（effort code）：说话时更用力的人，音高变化更大、更精确，听话人就把这种用力理解为重要或感情投入。音高与意义之间的这类联系在许多语言中都能找到。但每种语言对多大的音域算正常也有自己的惯例。听话人用自己语言的标准来评判说话人，所以在一种语言中正常的音域，在另一种语言中可能听起来平淡——或者夸张。克鲁滕登（Cruttenden 2014）和韦尔斯（Wells 2006）都强调，英语在友好的谈话中使用相当宽的音域，在需要热情的场合用窄的音域，会被听成一种态度，而不是口音。
:::

::: example 同样的词，不同的音域 {#ex-range}
大多数说英语的人会怎样理解下面每种回答？每次都是降调。

**A:** *I've got the job!*（我得到那份工作了！）
1. **B:** *That's ↘**won**derful.*（太好了。——音域窄、低）
2. **B:** *That's ↘**won**derful!*（太好了！——音域宽、高降调）
3. **B:** *Oh, ↘**real**ly. | That's ↘**won**derful.*（哦，是吗。太好了。——都窄，而且慢）
::: solution
1. 礼貌，但不太感兴趣——或者，取决于两人的关系，略带讽刺或嫉妒。词说的是“太好了”，音高说的却不是。
2. 真心高兴、热情。这正是 A 希望听到的。
3. 厌倦，甚至不友好：用窄降调说 *Oh, really* 暗示“我不感兴趣”，窄的 *That's wonderful* 又证实了这一点。

每种情况下，听话人都更相信音高而不是词。这就是为什么用窄音域说话的学习者，即使说的每样东西都对，也可能被误解。
:::
:::

## 各种调暗示什么

[[connected-speech/intonation-basics]]中的调没有固定的意义，但每种调都有大多数描写都认同的典型效果。

::: theorem 各种调的典型效果 {#rule-attitude}
1. **降调** ↘——肯定、完整、就事论事。**高降调**增加强调或感情：*It's ↘**beau**tiful!*（真美！）；**低降调**则平静或超然。
2. **低升调** ↗——开放、鼓励、不置可否；在问候和例行的交流中常常显得友好：*Good ↗**mor**ning*（早上好——愉快地）；*↗**Thanks***（谢啦——为一件小事随口道谢）。
3. **高升调** ↗（起点高，终点很高）——请对方重复，或不相信：*She's ↗**what**?*（她怎么了？）*↗**Sor**ry?*（GB，意思是“请再说一遍？”）。
4. **降升调** ↘↗——保留、对比或言外之意：*It's ↘↗**good** …*（还不错……——但不是很好）；礼貌的纠正或部分同意：*↘↗**Wed**nesday, | I think*（我想是星期三——不是星期二）；警告：*↘↗**Care**ful!*（小心！）
5. **升降调** ↗↘——赞叹，或语气很肯定；也可能听起来带挑衅或讽刺：*↗↘**Love**ly!*（真好！——非常赞叹，或者是反话）；*Of ↗↘**course**.*（那当然。——显而易见）。
:::

::: proof
这些效果可以从“说完了”（降调）和“开放”（升调）的基本对立来理解。降调把事情结束掉，所以听起来很肯定。升调把事情留给听话人，所以听起来不那么武断——带着鼓励、试探或疑问。降升调一开始像是要结束，随后又把事情重新打开：说话人说了一件事，同时表示事情不止于此，所以它常常暗示“但是……”。升降调是一个先蓄势再下降的降调，所以听起来比普通降调更投入——赞叹，或者在内容不值得这样投入时，成了反话。降升调在 GB 中特别常用，承担了大量表示礼貌和言外之意的工作；说 GA 的人也用它，但用得较少（Wells 2006）。
:::

::: example *Thank you* 和 *Sorry* {#ex-thanks}
描述每种调的效果（GB）。

1. *↘**Thank** you.*（谢谢你。——高降调）2. *↗**Thank** you.*（谢谢。——低升调）3. *↘**Sor**ry.*（对不起。）4. *↗**Sor**ry?*（什么？——高升调）5. *↘↗**Sor**ry, | but …*（不好意思，但是……）
::: solution
1. 真诚的感谢，为一件重要的事：一份礼物，真正的帮助。
2. 例行的致意——对递给你零钱的店员，或公交车司机。不算无礼，但很轻。（为了一个大忙这样说，就显得太随便了。）
3. 道歉：*I'm sorry.*（对不起。）
4. 请对方重复：*Pardon? What did you say?*（请再说一遍？你说什么？）（在 GA 中，用升调说 *Excuse me?* 或 *Sorry?* 也是这个用法。）
5. 礼貌地引出不同意见或拒绝：*↘↗Sorry, | but I don't ↘think that's right.*（不好意思，我觉得那样不对。）

在 *thank you* 中，调核在 *thank* 上，*you* 在调尾里；把调核放在 *you* 上的学习者（*thank ↘**you***），听起来像是在感谢这个人而不是另一个人。
:::
:::

::: quiz
一位同事问 *Did you like the presentation?*（你喜欢那个演讲吗？），你回答 *The ↘↗**slides** were good.*（幻灯片做得不错。）你的同事很可能理解成什么？
- [ ] 你喜欢演讲的一切。
- [x] 你喜欢幻灯片，但不喜欢别的东西——也许是演讲本身。
- [ ] 你没听见问题。
- [ ] 你在问幻灯片好不好。
::: solution
*slides* 上的降升调让它带上了对比：幻灯片做得不错——暗示别的东西不好。用降调（*The ˈslides were ↘**good***），回答就是一个单纯的正面评价。降升调让说英语的人可以礼貌地批评，而不必把批评说出口。
:::
:::

## 礼貌

::: theorem 请求、提议和命令中的语调 {#rule-polite}
1. 疑问句形式的**请求**和**提议**用**升调**通常听起来更礼貌：*Could you ˈopen the ↗**win**dow?*（你能把窗户打开吗？）*Would you ˈlike some ↗**more**?*（你还要再来点吗？）用降调，同样的请求可能听起来像命令：*Could you ˈopen the ↘**win**dow.*
2. 用**降调**的**祈使句**是命令：*ˈSit ↘**down**.*（坐下。）用**降升调**或**升调**，它们就变成了邀请或温和的鼓励：*ˈSit ↘↗**down***（请坐——别拘束）；*ˈDon't ↗**wor**ry.*（别担心。）
3. **简短的回答和应答**，音域宽听起来友好，音域窄听起来生硬：*↘**Yes**!*（是的！——高降调，高兴）对比 *↘**Yes**.*（是。——低而短，冷淡）。
4. **特殊疑问句**用升调会更温和：*ˈWhat's your ↗**name**?*（你叫什么名字呀？——对孩子或紧张的人）对比 *ˈWhat's your ↘**name**?*（你叫什么名字？——中性；如果说得慢、音域窄，就像在填官方表格）。
:::

::: proof
在英语中，礼貌在很大程度上是给听话人留余地：让请求听起来像一个可以拒绝的真正的问题，让指示听起来像一个建议。升调让事情保持开放，所以留了余地；降调把事情结束掉，所以没有留。语法承担了一部分这样的工作（用 *Could you …?* 而不用 *Open …*），但语调可以抵消礼貌语法的效果。用低而窄的降调说 *Could you open the window*，语法上是礼貌的，却常常被听成不耐烦。
:::

::: example 商店和办公室 {#ex-polite}
标出能让每句话听起来友好而礼貌的调，再标出会让它听起来不耐烦的调（GB）。

1. *Can I help you?*（有什么可以帮您？——店员）
2. *Take a seat.*（请坐。——前台）
3. *Next, please.*（下一位。——在柜台）
::: solution
1. 友好：*Can I ↗**help** you?*（音域宽，升调）。不耐烦：*Can I ↘**help** you.*（窄，低降调——它甚至可能意味着“你在这儿干什么？”）。
2. 友好：*ˈTake a ↘↗**seat**.*（降升调）或 *ˈTake a ↗**seat**.* 不耐烦或冷淡：*ˈTake a ↘**seat**.*（窄，低）。
3. 友好：*↘**Next**, | ↗**please**.*（或者在 *Next* 上用宽的降调，*please* 上升）。不耐烦：*↘**Next**. | ↘**Please**.*（两个短而低的降调）。
:::
:::

::: warning 词是对的，态度却错了
✗ *Could you ˈhelp me with ˈthis ↘**form**.*——用窄音域和低降调说：语法上是礼貌的，听起来却像一个指示。
✓ *Could you ˈhelp me with ˈthis ↗**form**?*（你能帮我填一下这张表吗？）——更宽的音域和升调。

✗ *↘**Thanks**.*——在别人花了一个小时帮你之后，说得又短又低又平：可能显得不领情。
✓ *↘**Thank** you ˈso ↘**much**!*（太感谢你了！）——更宽的音域和高降调。

说英语的听话人很少意识到自己是在对音高作出反应。他们不会想“那是个窄降调”；他们会想“她不友好”。怀疑自己遇到这种情况的学习者，首先应该试着在重要的词上**拓宽音域**。
:::

## 意义不是一一对应的

人们很容易想列一张清单——“降升调 = 怀疑”，“升降调 = 惊讶”——然后背下来。大多数研究英语语调的学者都告诫不要这样做。奥康纳和阿诺德（O'Connor and Arnold 1961）给他们的每一种调型都列了一组态度，但后来的学者（其中有 Crystal 1969、Brazil 1985/1997、Cruttenden 2014 和 Wells 2006）指出，同一个调在不同的语境中可以表达不同的态度，而且态度往往更多地由音域、响度、语速、音质和面部表情来传达，而不是单靠调。*Oh, ↗↘**love**ly*（哦，真好）可以是真心的高兴，也可以是辛辣的反话；只有语境才能决定。最可靠的概括，就是本章中那些大的概括：降调结束，升调开放，降升调暗示言外之意，宽音域表示投入。

::: example 一个听起来不友好的学习者 {#ex-learner}
一位在伦敦咖啡馆工作的中国学生，被经理告知顾客觉得她不友好。她很惊讶：她总是说 *Hello*（你好）、*What would you like?*（您要点什么？）和 *Thank you*（谢谢）。一段录音显示，她说每个短语都用一个短促的降调，音域很窄，位于她嗓音的中部。你会给她什么建议？
::: solution
词是对的，降调本身也没有错。问题在于**音域**：问候和道谢用窄降调，在说英语的人听来是例行公事或不感兴趣（[[#rule-range]]）。建议：

- 问候起点高一些，用更宽的降调，或用升调：*↘**Hel**lo!*（高降调）或 *Hel↗**lo**.*
- 用升调问 *What would you ↗**like**?*，或用起点高的宽降调。
- 对顾客说 *↘**Thank** you* 时用高降调，调核保持在 *thank* 上。
- 用夸张的方式练习：一开始会觉得太过了，但说话人觉得夸张的，在听话人听来通常是正常的。

原因很可能不是她的“中文语调”——普通话的每个音节都有很大的音高变化——而是紧张、注意力集中在说对词上，以及缺乏英语音高习惯的练习（[[#rule-range]]和下面的说明）。
:::
:::

::: note 英汉对比
- **普通话的音域很宽——在声调上。** 普通话的四个声调用到了嗓音的整个音域，普通话中的焦点和感情也会拓宽音域（Xu 1999）。所以，中国人说英语时音域窄，并不是直接照搬普通话。更可能的原因是注意力集中在词和语法上、朗读、紧张，以及在普通话中音高已经被字调“用掉了”，说话人不习惯在整个短语上自由地移动音高。[[connected-speech/tones-and-intonation]]会更详细地讨论这一点。
- **在普通话里，语气词承担了这项工作。** 英语用调和音域表示的许多态度，在普通话中由句末语气词来表示：*a* 啊（缓和、活泼），*ba* 吧（建议、征求同意），*ne* 呢（持续的兴趣），*ma* 嘛（显而易见）。英语里没有语气词，学习者必须用音高来做同样的工作。
- **礼貌形式。** 普通话的请求用“请”“麻烦你”这样的词来表示礼貌。英语也有 *please* 和 *could you*，但正如本章所示，如果语调平板或降得很低，它们并不能保证礼貌。
- **说粤语的人**用语气词用得更多（*aa3*、*laa1*、*wo3* ……），同样的建议也适用：语气词所带的态度必须转移到英语句子的音高上。
:::

::: history
语调表达态度的观念由来已久，但为学习者所作的系统描写，始于奥康纳（J. D. O'Connor）和阿诺德（G. F. Arnold）的《口语英语语调》（*Intonation of Colloquial English*，1961），书中给每一种调型配了一组态度意义，并用对话加以说明。克里斯特尔（David Crystal）的《英语的韵律系统与语调》（*Prosodic Systems and Intonation in English*，1969）说明了音域、响度、语速和节奏怎样与调结合，并对固定的态度标签持怀疑态度。布雷齐尔（David Brazil）在《英语语调的交际价值》（*The Communicative Value of Intonation in English*，1985；剑桥大学出版社版1997）中发展了**话语语调**理论，用说话人把什么当作共知的（“指称”调，如降升调）、把什么当作新的（“宣告”调，如降调）来解释调，并把音高“调阶”（key）——高、中、低——看作一个单独的系统。古森霍文（Carlos Gussenhoven，2004）把音高的意义与跨语言存在的生物学“代码”联系起来。韦尔斯（Wells 2006）把这些观点综合成一套供学习者使用的实用描写。
:::

- **音域**是声音移动的幅度；英语在友好的谈话中使用相当宽的音域（[[#def-range]]）。
- **宽**的音域暗示投入（感兴趣、热情、惊讶）；**窄**的音域暗示例行公事、厌倦或不友好（[[#rule-range]]）。
- 典型效果：**降调**肯定，**低升调**开放或友好，**高升调**表示“请再说一遍？”或不相信，**降升调**表示保留或言外之意，**升降调**表示赞叹或反语（[[#rule-attitude]]）。
- 请求和提议用升调更礼貌；祈使句用降调是命令，用降升调是邀请（[[#rule-polite]]）。
- 调和意义不是一一对应的；语境、音域、响度和语速都起作用。
- 学习者英语中的窄音域通常来自注意力分散和紧张，而不是普通话本身；在重要的词上拓宽音域。
:::

## 习题

::: exercise 感不感兴趣？ {level=1}
哪个回答听起来更感兴趣？

1. （a）用高升调说 *ˈReally?*（真的？）（b）用低而窄的降调说 *ˈReally.*（是吗。）
2. （a）*That's ↘**nice**.*（挺好。）低而短。（b）*That's ↘**nice**!*（太好了！）用高降调。
::: solution
1. （a）——高升调表示惊讶和兴趣；（b）听起来很厌倦。2. （b）——高降调和宽音域表示热情；（a）听起来是例行公事或没被打动。
:::
:::

::: exercise 哪种调？ {level=1}
选择最合适的调（降调、低升调、高升调、降升调或升降调）。

1. 你没听清别人说的话：*Sorry?*（什么？）2. 提醒别人地板是湿的：*Careful!*（小心！）3. 感谢开车送你去机场的朋友：*Thank you!*（谢谢你！）4. 你对朋友的新公寓非常赞叹：*Lovely!*（真漂亮！）
::: solution
1. 高升调：*↗**Sor**ry?* 2. 降升调：*↘↗**Care**ful!*（如果情况紧急，也可以用高降调）。3. 降调，高而宽：*↘**Thank** you!* 4. 升降调：*↗↘**Love**ly!*（或高降调）。
:::
:::

::: exercise 言外之意 {level=1}
每句中的降升调暗示了什么？

1. *The ↘↗**food** was good.*（菜还不错。）2. *I can ↘↗**try**.*（我可以试试。）3. *↘↗**Some** of them are right.*（有些是对的。）
::: solution
1. 菜不错——但别的东西（服务、价格）不好。2. 我可以试试——但不保证成功。3. 有些是对的——但不是全部。
:::
:::

::: exercise 礼不礼貌？ {level=2 check="2"}
下面四个请求中，有几个在说英语的人听来可能是礼貌的？

（a）*Could you ˈpass the ↗**salt**?*（能把盐递给我吗？）（b）*Could you ˈpass the ↘**salt**.*（窄，低降调）（c）*ˈPass the ↘**salt**.*（把盐递过来。——窄，低降调）（d）*Would you ˈmind ˈpassing the ↗**salt**?*（麻烦你把盐递给我好吗？）
::: solution
（a）和（d）：疑问句形式的请求，用升调。（b）语法上是礼貌的，但窄而低的降调让它听起来像命令；（c）是单纯的命令。答案是2。
:::
:::

::: exercise 标出态度 {level=2}
用 *It's ten o'clock.*（十点了。）这几个词，标出调核，并选择调和音域来表达每种态度。

1. 中性地报时。2. 惊讶——你以为还早得多。3. 责备——你十几岁的儿子回家晚了。4. 保留——是十点了，但商店可能还开着。
::: solution
1. *It's ˈten o'↘**clock**.*——正常的降调，中等音域。（*O'clock* 是最后一个实义词。）
2. *It's ˈten o'↗**clock**?*——高升调，宽音域。或者在 *ten* 上用高降调：*It's ↘**ten** o'clock!*
3. *It's ↘**ten** o'clock.*——在 *ten* 上用高降调（重要的是时间），说得慢而刻意。或者用升降调：*It's ↗↘**ten** o'clock.*
4. *It's ˈten o'↘↗**clock** …*——降升调：但也许还来得及。
:::
:::

::: exercise GB 和 GA {level=2}
一个英国人说 *I ↘↗**like** it*（我喜欢它——*like* 上用降升调）。你会怎样理解？说 GA 的人可能怎样表达同样的意思？
::: solution
降升调暗示有保留：*I like it — but …*（我喜欢——但是……）（也许是“但太贵了”，或“但也不是特别喜欢”）。说 GA 的人也这样用降升调，但常常用得较少；他们可能用升调或平的结尾，加上词（*I like it, but …*），或者把对比明确说出来。两种口音中这个意思都能听懂。
:::
:::

::: exercise 挽救一段冷冰冰的对话 {level=3}
这段对话在语法上无可挑剔，但 B 听起来不友好。给 B 的话重新标上能让人感到温暖的调和音域，并解释你的选择。

**A:** *Hi! I'm Kate, I'm new in the department.*（你好！我是凯特，刚来这个部门。）
**B:** *↘Hello. | I'm ↘Wang Lei. | ↘Welcome.*（你好。我是王磊。欢迎。——都低而窄）
**A:** *Do you know where the printer is?*（你知道打印机在哪儿吗？）
**B:** *It's on the ↘second floor.*（在二楼。——低而窄）
::: hint
先考虑音域，再考虑调。B 的哪些调群可以用升调或降升调？
:::
::: solution
**B:** *↘**Hel**lo! | I'm ˈWang ↘**Lei**. | ↘↗**Wel**come!*——或者用高降调说 *↘**Wel**come!* *Hello* 起点高、降得宽，表示感兴趣；*Welcome* 用降升调或高降调，听起来很温暖。
**B:** *It's on the ↘**sec**ond floor*——起点高，降得宽；或者更友好些：*It's on the ↘**sec**ond floor | — I can ↗**show** you, if you like?*（在二楼——要不要我带你去？）主要的变化在音域：同样的调放在更宽的音域里，就已经显得更友好了。提议上的升调给 A 留了接受或拒绝的余地。
:::
:::

::: exercise 录音比较 {level=3}
选五个日常短语（例如 *Good morning* 早上好，*Thank you* 谢谢，*Could you help me?* 你能帮我一下吗？，*That's great* 太好了，*See you tomorrow* 明天见）。先用你平常的方式把每个短语录下来，再有意用更宽的音域录一遍。两遍都听一听。哪一遍你自己觉得更自然？你认为说英语的人会觉得哪一遍更友好？用两三句话写下你注意到的东西。
::: solution
答案因人而异。大多数学习者发现，音域宽的那一遍说的时候觉得夸张，回放时却听起来很自然；而平常的那一遍听起来比预想的要平。好的回答会注意到每个短语的调核在哪里（*Good ↘**mor**ning*，*↘**Thank** you*，*Could you ↗**help** me?*，*That's ↘**great***，*See you to↘**mor**row*），以及拓宽是否发生在调核上。如果可能，把录音和母语者说同样短语的录音作比较。
:::
:::
