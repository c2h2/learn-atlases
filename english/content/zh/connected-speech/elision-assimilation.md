一位学习者听同事说话，听到的是 /ʃiːz ɪn ðə ˈneks ˈruːm/（她在隔壁房间）。她认识 *next*（隔壁的；下一个）和 *room*（房间）这两个词，但她学的 *next* 是 /nekst/，而她听到的里面没有 /t/。后来这位同事又说了一些听起来像 *tem pounds* 和 *wudja like a coffee?* 的话。可是并没有 *tem* 或 *wudja* 这样的词。发生了什么？

在连贯语流中，词界上的音不只是连在一起（[[connected-speech/linking]]）；它们还可能**脱落**或**改变**。*next* 的 /t/ 在两个辅音之间脱落了；*ten*（十）的 /n/ 在 *pounds*（英镑）的 /p/ 前变成了 /m/；*would* 的 /d/ 和 *you* 的 /j/ 融合成了 /dʒ/。这些过程——**省音**和**同化**——在所有说英语的人的话语中都很正常，GB 和 GA 都是如此，正式和非正式的话语也都是如此。你不必全部使用它们，但必须认得出它们，因为如果不认识它们，快速口语就很难听懂。本章还讲解非正式的口语形式 *gonna*、*wanna* 和 *gotta*，它们有自己的规则。

## 省音：脱落的音

::: definition 省音 {#def-elision}
**省音**（elision）是一个词单说时有的某个音在连贯语流中脱落。在 *next day*（第二天）/ˈneks ˈdeɪ/ 中，*next* 的 /t/ 被省略了；在 *camera*（照相机）/ˈkæmrə/ 中，中间的元音被省略了。
:::

最常见的省音涉及 /t/ 和 /d/。

::: theorem /t/ 和 /d/ 的省略 {#rule-td}
处在**另外两个辅音之间**的 /t/ 或 /d/ 常常被省略：

- *next day*（第二天）/ˈneks ˈdeɪ/，*last week*（上周）/ˈlɑːs ˈwiːk/（GB），*first thing*（首先要做的事）/ˈfɜːs ˈθɪŋ/（GB），*don't know*（不知道）/ˈdəʊn ˈnəʊ/（GB）
- *old man*（老人）/ˈəʊl ˈmæn/（GB），*hand bag* → *handbag*（手提包）/ˈhænbæɡ/，*stand still*（站着别动）
- 词内部：*exactly*（确切地）/ɪɡˈzækli/，*mostly*（大部分）/ˈməʊsli/（GB），*facts*（事实）/fæks/，*friendship*（友谊）/ˈfrenʃɪp/
- 过去时词尾：*looked back*（回头看）/ˈlʊk ˈbæk/，*mixed bag*（大杂烩）/ˈmɪks ˈbæɡ/

后面跟着元音时，通常**不**省略：*next of kin*（近亲）/ˈnekst əv ˈkɪn/，*last orders*（最后一轮点单），*old age*（老年）。当 /t/ 或 /d/ 后面是 /h/ 或 /j/，或者说话人在仔细地说或强调时，省略的可能性最小。
:::

::: proof
挤在两个辅音之间的 /t/ 或 /d/ 很短，即使发出来也很难听见，因为爆破音需要后面跟一个元音，它的除阻才听得出来。所以说话人就省掉了这个动作。罗奇（Roach 2009）和克鲁滕登（Cruttenden 2014）都把它描述为英语中最常见的省音之一。当被省略的 /t/ 或 /d/ 是语法词尾时（*looked*，*mixed*），意思通常能从上下文中看出来：*Yesterday I looked back*（昨天我回头看了）不可能是现在时。在元音前，爆破音可以除阻到元音上，很容易听见，所以保留下来。这就是连读（[[connected-speech/linking#rule-cv]]）和省音配合工作的原因之一：*next of kin* 连读，*next day* 省音。
:::

::: quiz
在流利的口语中，哪个短语里的 /t/ 最可能被省略？
- [ ] *last of all*
- [x] *last night*
- [ ] *at last*
- [ ] *the last answer*
::: solution
在 *last night*（昨晚）中，/t/ 处在 /s/ 和 /n/ 两个辅音之间，所以常常脱落：[ˈlɑːs ˈnaɪt]（GB），[ˈlæs ˈnaɪt]（GA）。在 *last of all*（最后）和 *the last answer*（最后一个答案）中，后面跟着元音，/t/ 与它连读；在 *at last*（终于）中，它在末尾、停顿之前，会保留下来（或变成喉塞音）。
:::
:::

在流利的口语中，其他省音也很常见：

::: theorem 其他常见的省音 {#rule-elision}
1. **非重读音节中的弱元音**会脱落，尤其是在辅音和 /r/、/l/ 或 /n/ 之间，或者在词首 /p t k/ 之后：*camera*（照相机）/ˈkæmrə/，*family*（家庭）/ˈfæmli/，*chocolate*（巧克力）/ˈtʃɒklət/（GB），*different*（不同的）/ˈdɪfrənt/，*interesting*（有趣的）/ˈɪntrəstɪŋ/，*vegetable*（蔬菜）/ˈvedʒtəbl/；*police*（警察）[pliːs]，*correct*（正确的）[krekt]，*support*（支持）[spɔːt]（GB），*potato*（土豆）[pʰˈteɪtəʊ]（GB），*today*（今天）[tʰˈdeɪ]。其中许多形式现在已经是词典里通常的读音。
2. ***of* 的 /v/** 在辅音前常常脱落：*lots of them*（它们中的很多）/ˈlɒts ə ðəm/（GB），*a cup of coffee*（一杯咖啡）/ə ˈkʌp ə ˈkɒfi/（GB）。
3. *he*、*him*、*her*、*have* 的**弱读式中的 /h/** 在句中脱落（[[connected-speech/weak-forms]]）。
4. **辅音连缀中的 /θ/ 和 /ð/**：*months*（月，复数）/mʌnθs/ 常常读成 [mʌns] 或 [mʌnts]；*clothes*（衣服）/kləʊðz/（GB）常常读成 /kləʊz/，和动词 *close*（关）一样。
:::

::: example 哪些音可以省略？ {#ex-elide}
说明在流利的口语中，每个短语里黑体的 /t/ 或 /d/ 是否可能被省略，以及原因。

1. *nex**t** week*（下周）
2. *nex**t** August*（明年八月）
3. *I wan**t** to go*（我想去）
4. *a col**d** day*（寒冷的一天）
5. *a col**d** evening*（寒冷的傍晚）
6. *She pass**ed** the test.*（她通过了考试。）
::: solution
1. **可能**：/kst/ + /w/——/t/ 处在 /s/ 和 /w/ 之间：/ˈneks ˈwiːk/。
2. **不太可能**：后面跟着元音，所以 /t/ 与它连读：/ˈnekst ˈɔːɡəst/（GB）[ˈneks ˈtɔːɡəst]。
3. **常常是合并而不是脱落**：/nt/ + /t/——两个 /t/ 合成一个：/ˈwɒn tə/（GB）。在 GA 中常常是 [ˈwɑːnə]——见下文的 *wanna*。
4. **可能**：/ld/ + /d/——*cold* 的 /d/ 与 *day* 的 /d/ 合并，或者脱落：[ˈkəʊl ˈdeɪ]（GB）。
5. **不太可能**：后面跟着元音：[ˈkəʊl ˈdiːvnɪŋ]（GB）——/d/ 与 *evening* 连读。
6. **在快速口语中可能**：/pɑːst ðə/ → /ˈpɑːs ðə/（GB）。在说考试的语境中，过去的意思仍然很清楚。
:::
:::

## 同化：改变的音

::: definition 同化 {#def-assimilation}
**同化**（assimilation）是一个音发生变化，变得更像相邻的音。在 *ten pounds*（十英镑）中，*ten* 的 /n/ 变成了 [m]，像后面的 /p/ 一样用双唇发出：[ˈtem ˈpaʊndz]。在英语中，发生变化的通常是一个词的**最后**一个音，引起变化的是下一个词的**第一个**音。
:::

::: theorem /t/、/d/ 和 /n/ 的发音部位同化 {#rule-place}
词尾的齿龈音 /t/、/d/ 和 /n/ 常常采用后面辅音的发音部位：

| 在……之前 | /t/ 变成 | /d/ 变成 | /n/ 变成 | 例子 |
|---|---|---|---|---|
| /p/、/b/、/m/（双唇） | [p] | [b] | [m] | *that man*（那个人）[ˈðæp ˈmæn]，*good boy*（好孩子）[ˈɡʊb ˈbɔɪ]，*ten pounds*（十英镑）[ˈtem ˈpaʊndz]，*in bed*（在床上）[ɪm ˈbed] |
| /k/、/ɡ/（软腭） | [k] | [ɡ] | [ŋ] | *that case*（那个案子）[ˈðæk ˈkeɪs]，*bad cold*（重感冒）[ˈbæɡ ˈkəʊld]，*ten cups*（十个杯子）[ˈteŋ ˈkʌps]，*in case*（以防万一）[ɪŋ ˈkeɪs] |

/s/ 和 /z/ 在 /ʃ/ 和 /j/ 前变成 [ʃ] 和 [ʒ]：*this shop*（这家店）[ðɪʃ ˈʃɒp]（GB），*those shoes*（那双鞋）[ðəʊʒ ˈʃuːz]（GB），*this year*（今年）[ðɪʃ ˈjɪə]（GB）。

用双唇或舌后部发出的辅音（/p b m k ɡ ŋ/）不会这样变化：*bad cold* 中的 *bad* 会变，但 *big day*（重要的日子）中的 *big* 不变。
:::

::: proof
同化来自发音动作的重叠。说 *ten pounds* 时，舌头要先碰到齿龈发 /n/，然后双唇要闭合发 /p/。在流利的口语中，/n/ 还没说完双唇就开始闭合，舌头的动作也常常减弱或省掉，于是这个鼻音听起来就是 [m]。齿龈音之所以会变，是因为舌尖动作快，它的动作很容易被下一个音掩盖；双唇或舌后部的闭塞则不会以同样的方式被掩盖。在 GB 中，辅音前的词尾 /t/ 也常常被喉塞音代替（[ˈðæʔ ˈmæn]），它与同化相互竞争。同化是可选的，取决于语速和语体，但它并不是“马虎”：克鲁滕登（Cruttenden 2014）把它看作 GB 的正常特征。
:::

听话人很善于还原同化。在加斯克尔（Gaskell）和马斯伦-威尔逊（Marslen-Wilson）（1996）的实验中，说英语的人在 /b/ 前听到 [liːm]（*leam bacon*）时能认出 *lean*（瘦的），但当同样的 [m] 出现在一个不可能引起它的音之前时，就很少能认出来。换句话说，听话人利用后面的音来推断说话人想说什么。学习者也可以学会这样做：/p/ 前的 [tem] 就是 *ten*。

::: example 预测同化 {#ex-assim}
说明在流利的口语中词界上的音可能怎样变化，并说明适用哪条规则。

1. *green park*（绿园） 2. *red car*（红色的车） 3. *that boy*（那个男孩） 4. *one more*（再来一个） 5. *in Glasgow*（在格拉斯哥） 6. *nice shoes*（好看的鞋）
::: solution
1. /n/ + /p/ → [m]：[ˈɡriːm ˈpɑːk]（GB）——发音部位同化（[[#rule-place]]）。
2. /d/ + /k/ → [ɡ]：[ˈreɡ ˈkɑː]（GB）。
3. /t/ + /b/ → [p]：[ˈðæp ˈbɔɪ]，或者在 GB 中常常用喉塞音 [ˈðæʔ ˈbɔɪ]。
4. /n/ + /m/ → [m]：[ˈwʌm ˈmɔː]（GB）——一个长的 [mː]。
5. /n/ + /ɡ/ → [ŋ]：[ɪŋ ˈɡlɑːzɡəʊ]（GB）。
6. /s/ + /ʃ/ → [ʃ]：[ˈnaɪʃ ˈʃuːz]——一个长的 [ʃː]。

每种情况下，听话人仍然听到的是 *green*、*red*、*that*、*one*、*in*、*nice*：这种变化可以从后面的音预测出来。
:::
:::

::: theorem 与 /j/ 的融合 {#rule-coalescence}
以 /t/、/d/、/s/ 或 /z/ 结尾的词后面跟着以 /j/ 开头的词——尤其是 *you*、*your* 和 *year*——时，这两个音常常**融合**成一个：

- /t/ + /j/ → [tʃ]：*don't you*（你不……吗）[ˈdəʊntʃu]（GB），*last year*（去年）[lɑːs ˈtʃɪə]（GB），*what you need*（你需要的东西）[ˈwɒtʃə ˈniːd]（GB）
- /d/ + /j/ → [dʒ]：*would you*（你愿意……吗）[ˈwʊdʒu]，*did you*（你……了吗）[ˈdɪdʒu]，*could you*（你能……吗）[ˈkʊdʒu]
- /s/ + /j/ → [ʃ]：*I miss you*（我想你）[aɪ ˈmɪʃ ju]，*bless you*（保重；长命百岁——别人打喷嚏时说）[ˈbleʃ ju]
- /z/ + /j/ → [ʒ]：*as you know*（如你所知）[əʒ ju ˈnəʊ]（GB），*is your*（你的……是）[ɪʒ jə]

这种融合叫作**融合同化**（coalescence，也叫 *yod coalescence*，*yod* 是 /j/ 的一个名称）。
:::

::: proof
融合同化也是同一种重叠：/j/ 是舌头靠近硬腭、就在齿龈后面发出的，它与 /t/ 或 /s/ 重叠时，结果就是一个处于两者之间的音——/tʃ/ 或 /ʃ/。在英语的历史上，许多词内部也发生过同样的过程：*nature*（自然）/ˈneɪtʃə/（GB）和 *question*（问题）/ˈkwestʃən/ 以前有 /tj/，*sure*（确定的）和 *sugar*（糖）以前有 /sj/。这个过程在 GB 中仍在进行，例如 *tune*（曲调）/tjuːn/ 常常读成 [tʃuːn]，*duty*（责任）/ˈdjuːti/ 常常读成 [ˈdʒuːti]。GA 在这些词里已经完全丢掉了 /j/（*tune* /tuːn/，*duty* /ˈduːti/），所以没有什么可以融合的。在词界上，与 *you* 的融合在 GB 和 GA 中都很常见。
:::

::: example *Would you* 和 *don't you* {#ex-coalesce}
写出这些问句在流利的口语中通常的说法（GB 和 GA），并标出重音。

1. *Would you like a coffee?*（你想喝杯咖啡吗？）2. *Did you see that?*（你看见了吗？）3. *Don't you think so?*（你不这么认为吗？）4. *What did you do?*（你做了什么？）
::: solution
1. GB [ˈwʊdʒə ˈlaɪk ə ˈkɒfi]，GA [ˈwʊdʒə ˈlaɪk ə ˈkɑːfi]——*would* + *you* 融合，*you* 弱读为 /jə/。
2. [ˈdɪdʒə ˈsiː ðæt]——/d/ + /j/ → [dʒ]。（*That* 在这里是指示代词；它也可以是调核：*Did you see ↘**that**?*）
3. GB [ˈdəʊntʃə ˈθɪŋk səʊ]，GA [ˈdoʊntʃə ˈθɪŋk soʊ]——/t/ + /j/ → [tʃ]。
4. GB [ˈwɒdʒə ˈduː]，GA [ˈwʌdʒə ˈduː]——*did* 弱化并与 *you* 融合；*what* 的 /t/ 脱落。在 GA 非常快的口语中，这常常听起来像 *whaddya do?* [ˈwʌɾəjə ˈduː] 或 *whadja do?*

注意，这四句中实义动词都保留了完整的形式和重音；只有功能词发生了变化。
:::
:::

### 清浊

第三种较小的同化影响清浊。在几个非常常用的短语中，浊辅音在清辅音前变成清辅音：*have to*（不得不）/ˈhæf tə/，*has to* /ˈhæs tə/，*used to*（过去常常）/ˈjuːs tə/，*supposed to*（应该）/səˈpəʊs tə/（GB）。这些现在已经是这些短语的正常读音，而 *have to* /ˈhæf tə/ 也因此与 *have two*（有两个）/ˈhæv ˈtuː/ 区分开来。

### GB 和 GA

- **喉塞音（GB 和 GA）。** 在辅音前，词尾的 /t/ 在两种口音中都常常是喉塞音：*that man* [ˈðæʔ ˈmæn]，*not now*（现在不行），*football*（足球）（[[sounds-of-english/stops-fricatives]]）。在元音之间，喉塞音化的 /t/（*water* [ˈwɔːʔə]）在许多英国口音中都能听到，在年轻人中也越来越多，但还不被认为是 GB 的典型特征。
- **GA 的 /nt/。** 在 GA 中，/n/ 之后、非重读元音之前的 /t/ 常常脱落：*twenty*（二十）[ˈtweni]，*winter*（冬天）[ˈwɪnər]，*internet*（互联网）[ˈɪnərnet]，*wanted*（想要，过去式）[ˈwɑːnɪd]。*Winter* 和 *winner*（获胜者）可能听起来一样。
- **GA 的闪音。** 元音之间的 /t/ 或 /d/ 在 GA 中是闪音，词内部和跨词都是如此：*a lot of*（很多）[ə ˈlɑːɾəv]，*get it*（明白了）[ˈɡeɾɪt]（[[connected-speech/linking#rule-cv]]）。

## *Gonna*、*wanna* 和其他非正式形式

有些组合弱化得非常频繁，以至于有了自己的非正式拼写。它们不是俚语词：它们是普通的快速读音的拼写形式。

| 完整形式 | 非正式形式 | 读音 |
|---|---|---|
| *going to*（表示将来） | *gonna* | GB [ˈɡɒnə]，GA [ˈɡɑːnə] 或 [ˈɡʌnə]；在 *I'm* 之后常常读 [ˈaɪmənə] |
| *want to* | *wanna* | GB [ˈwɒnə]，GA [ˈwɑːnə] |
| *(have) got to* | *gotta* | GB [ˈɡɒtə]，GA [ˈɡɑːɾə] |
| *have to*，*has to* | *hafta*，*hasta* | [ˈhæftə]，[ˈhæstə] |
| *kind of*，*sort of* | *kinda*，*sorta* | [ˈkaɪndə]，GB [ˈsɔːtə]，GA [ˈsɔːrɾə] |
| *let me*，*give me* | *lemme*，*gimme* | [ˈlemi]，[ˈɡɪmi] |
| *don't know* | *dunno* | GB [dəˈnəʊ]，GA [dəˈnoʊ] |

::: theorem 什么时候可以用 *gonna* 和 *wanna* {#rule-gonna}
1. ***Gonna*** 只有在表示将来、后面跟动词时才能代替 *going to*：*I'm gonna call her.*（我要给她打电话。）它不能代替“*going to* + 地点”：✗ *I'm gonna the station.* ✓ *I'm going to the station.*（我要去车站。）
2. ***Wanna*** 代替“*want to* + 动词”：*I wanna go home.*（我想回家。）它不能代替 *wants to*（✗ *She wanna go*），也不能代替“*want* + 名词”（不能用 ✗ *I wanna coffee* 来表示 *I want a coffee*，我想要一杯咖啡）。
3. 当做第二个动作的人不是 *want* 的主语时，也不能用 *wanna*。*Who do you want to visit?* 可以表示“你想去拜访哪个人？”——这时 *Who do you wanna visit?* 是可以的。但 *Who do you want to win?* 的意思是“你希望哪个人成为获胜者？”——这里获胜的是另外一个人，在这个意思下不能说 ✗ *Who do you wanna win?*
4. **语域**：这些形式属于非正式口语。在书面上，它们出现在非正式的消息、小说的对话和歌名中，永远不出现在论文、报告或考试中。大多数说 [ˈɡɒnə] 的人写的是 *going to*。
:::

::: proof
第1条和第2条来自意义：*gonna* 是将来时结构“*be going to* + 动词”的弱化，这个结构非常常用，已经成了一个单位；“*going to* + 地点”则是普通的动词 *go* 加介词，不以同样的方式弱化。第3条从20世纪70年代起就引起了语言学家的兴趣（Chomsky and Lasnik 1977）：看起来，只有当 *want* 和 *to* 之间什么都没有——连一个隐含的人都没有——的时候，它们才能合并。在 *Who do you want to win?*（“你希望 X 赢”）中，隐含的 X 处在 *want* 和 *to* 之间，这就阻止了合并。第4条是一种惯例：非正式拼写在正式文字中显得马虎，尽管它们所代表的读音是各种背景的人都在用的。
:::

::: quiz
哪个句子可以用 *wanna* 来说？
- [ ] *She wants to stay.*
- [ ] *I want a sandwich.*
- [x] *We want to stay.*
- [ ] *Who do you want to win the match?*（意思是“你希望哪个队赢？”）
::: solution
*We want to stay*（我们想留下）是“*want to* + 动词”，*want* 的主语也是留下的人：*We wanna stay.* *Wants to* 不能变成 *wanna*（*She wants to stay*，她想留下）；“*want a* + 名词”不是 *want to*（*I want a sandwich*，我想要一个三明治）；在最后一句中，获胜的是 *you* 以外的人，这阻止了 *wanna*（[[#rule-gonna]]，第3条）。
:::
:::

::: warning *Gonna* 不是用来写的词
✗ *In this essay I'm gonna discuss the causes of climate change.*
✓ *In this essay I will discuss the causes of climate change.*（在这篇文章中，我将讨论气候变化的原因。）/ *This essay discusses …*（本文讨论……）

✗ *I'm gonna the library.* ✓ *I'm going to the library.*（我要去图书馆。）

如果你愿意，可以在随意的谈话和发给朋友的消息中使用这些非正式形式。你完全不必说它们也能让人听懂；但你必须**认得出**它们，因为在电影、对话和播客中到处都是。
:::

::: example 能用 *gonna* 或 *wanna* 吗？ {#ex-gonna}
说明每个句子中的黑体部分能否非正式地说成和写成 *gonna* 或 *wanna*。

1. *It's **going to** rain.*（要下雨了。）
2. *Are you **going to** the party?*（你去参加聚会吗？）
3. *I don't **want to** talk about it.*（我不想谈这件事。）
4. *He **wants to** leave early.*（他想早点走。）
5. *Do you **want to** see it?*（你想看看吗？）
6. *Who do you **want to** help you?*（你想让谁帮你？）
::: solution
1. **可以**：将来 + 动词——*It's gonna rain.*
2. **不可以**：“*going to* + 地点”（*the party*）。
3. **可以**：*I don't wanna talk about it.*
4. **不可以**：*wants to*——*-s* 阻止了它。（在非常快的口语中，这几个词仍然可能弱化为 [ˈwɒnts tə]，但不会变成 *wanna*。）
5. **可以**：*Do you wanna see it?*——常常说成 [dʒə ˈwɒnə ˈsiː ɪt]（GB）。
6. **不可以**：帮忙的是另一个人，在意义上处在 *want* 和 *to* 之间（“你想让 X 帮你”），就像[[#rule-gonna]]第3条那样。
:::
:::

::: widget graph
nodes: /n/@-4,3; [m] before p b m as in ten pounds@-5,1; [ŋ] before k ɡ as in ten cups@-3,1; /t/@0,3; [p] before p b m as in that man@-1,1; [k] before k ɡ as in that case@1,1; /d/ + /j/@4,3; [dʒ] as in would you@4,1; /s/ + /j/ or /ʃ/@0,-0.5; [ʃ] as in this shop@0,-2; /t/ between consonants@-4,-0.5; lost as in next day@-4,-2

caption: 词界上的主要变化。发音部位同化：/n/ 在双唇辅音前变成 [m]，在 /k/ 或 /ɡ/ 前变成 [ŋ]；/t/（和 /d/）以同样的方式变化。融合同化：/d/ + /j/ 融合成 [dʒ]（*would you*），/t/ + /j/ 融合成 [tʃ]。/s/ 在 /ʃ/ 或 /j/ 前变成 [ʃ]。省音：两个辅音之间的 /t/（和 /d/）常常脱落（*next day*，图中 lost 意为“脱落”）。所有这些都是可选的；在快速、放松的口语中更常见。方框可以拖动。
:::

::: note 英汉对比
- **说普通话的人熟悉的变化。** 普通话在快速口语中也会改变音节交界处的音：在 *miànbāo* 面包 中，*-n* 在 *b* 前常常读得更接近 [m]；在随意的北京话里，*zěnme* 怎么 或 *bù zhīdào* 不知道 都会大大弱化。变调（如 *nǐ hǎo* 你好 中第三声在另一个第三声前的变化）是另一种由相邻成分引起的变化，不过它涉及的是声调，而不是辅音。所以，一个音因为后面的音而改变，这个概念并不新。
- **新的地方。** 英语的同化和省音影响**辅音连缀**，而普通话没有辅音连缀。一个下了很大功夫才把 *next* 的 /t/ 发出来的学习者，可能会觉得把它省掉是错的。在你自己说话时，保留它没有问题；在听的时候，你必须预料到它可能不在。
- **过去时。** 因为汉语不在动词上标示时态，学习者常常听不出（也说不出）*-ed*。省音使这更难了：在 *looked back* 中，/t/ 通常已经没有了。注意过去的其他标志（*yesterday*、*last week*），听不出词尾也不要担心。
- **网络英语中的拼写形式。** 学习者在歌曲、电影和社交媒体中会遇到 *gonna*、*wanna* 和 *gotta*。认识它们很有用；但在考试作文和正式英语中，应该写完整形式。
:::

::: history
早期的语音学家就知道音会随语境而变化——斯威特（Henry Sweet）在19世纪就讨论过同化——但为学习者所作的系统描写出现在20世纪。吉姆森（A. C. Gimson）的《英语发音导论》（*An Introduction to the Pronunciation of English*，1962）详细描写了 RP 中的同化、省音和连读，这本书经克鲁滕登（Alan Cruttenden）修订，至今仍是标准的参考书（《吉姆森英语发音》，*Gimson's Pronunciation of English*，第8版，2014）。非正式拼写 *gonna* 和 *wanna* 在20世纪的印刷品中变得常见；对 *wanna* 的限制在20世纪70年代成为句法学中一个著名的问题，乔姆斯基（Noam Chomsky）和拉斯尼克（Howard Lasnik）（1977）等人都讨论过。20世纪90年代，加斯克尔（Gareth Gaskell）和马斯伦-威尔逊（William Marslen-Wilson）等心理语言学家用实验表明了听话人怎样利用后面的音来还原同化。
:::

## 后续内容

在真实话语中辨认省音和同化了的词的练习，见[[connected-speech/hearing-fast-speech]]。连贯语流的音高是接下来三章的内容，从[[connected-speech/intonation-basics]]开始。喉塞音化、闪音化和弱化方式不同的口音，在[[listening-and-conversation/accents]]和[[world-englishes/british-american]]中讨论。

::: summary
- **省音**是连贯语流中某个音的脱落；**同化**是一个音变得更像它相邻的音（[[#def-elision]]，[[#def-assimilation]]）。
- 两个辅音之间的 /t/ 和 /d/ 常常被省略：*next day*、*last week*、*looked back*；在元音前则不省略（[[#rule-td]]）。
- 弱元音常常脱落（*camera*、*family*、*police*），辅音前 *of* 的 /v/ 和弱读式中的 /h/ 也常常脱落（[[#rule-elision]]）。
- 词尾的 /t d n/ 采用后面辅音的发音部位：*ten pounds* [tem]，*ten cups* [teŋ]，*good boy* [ɡʊb]；/s z/ 在 /ʃ j/ 前变成 [ʃ ʒ]（[[#rule-place]]）。
- /t d s z/ + /j/ 融合成 [tʃ dʒ ʃ ʒ]：*would you* [ˈwʊdʒu]，*last year*（[[#rule-coalescence]]）。
- GA 把 /n/ 后的 /t/ 省掉（*twenty* [ˈtweni]），把元音之间的 /t/ 读成闪音；两种口音都在辅音前把 /t/ 喉塞音化。
- *Gonna* = 表示将来的 *going to* + 动词；*wanna* = *want to* + 动词，不能代替 *wants to*，做动作的是别人时也不能用；两者都属于非正式口语（[[#rule-gonna]]）。
:::

## 习题

::: exercise 找出省音 {level=1}
在流利的口语中，哪个 /t/ 或 /d/ 可能被省略？

1. *Just a minute.*（稍等一下。）2. *Just now.*（刚才。）3. *I don't like it.*（我不喜欢。）4. *a blind man*（一个盲人）5. *the old office*（旧办公室）
::: solution
1. 不太可能：*just‿a*——后面跟着元音，所以 /t/ 连读。2. 可能：[ˈdʒʌs ˈnaʊ]。3. 可能：[aɪ ˈdəʊn ˈlaɪk ɪt]（GB）——*don't* 的 /t/ 处在 /n/ 和 /l/ 之间。4. 可能：[ə ˈblaɪn ˈmæn]，而且 /n/ 可能同化为 [m]：[ə ˈblaɪm ˈmæn]。5. 不太可能：后面跟着元音：*old‿office*。
:::
:::

::: exercise 哪种同化？ {level=1}
第一个词的最后一个辅音可能怎样变化？

1. *ten men*（十个人）2. *bad girl*（坏女孩）3. *sit back*（往后坐）4. *London bus*（伦敦公交车）5. *ten girls*（十个女孩）
::: solution
1. [m]：[ˈtem ˈmen] 2. [ɡ]：[ˈbæɡ ˈɡɜːl]（GB） 3. [p]（或喉塞音）：[ˈsɪp ˈbæk] 4. [m]：[ˈlʌndəm ˈbʌs] 5. [ŋ]：[ˈteŋ ˈɡɜːlz]（GB）
:::

::: exercise 能不能用 *gonna*？ {level=1}
哪些句子可以用 *gonna*？

1. *We're going to be late.*（我们要迟到了。）2. *We're going to Paris.*（我们要去巴黎。）3. *What are you going to do?*（你打算做什么？）4. *I was going to call you.*（我本来要给你打电话的。）
::: solution
第1、3、4句：将来（第4句是过去将来）+ 动词：*We're gonna be late*，*What are you gonna do?*，*I was gonna call you*。第2句不行：“*going to* + 地点”。
:::

::: exercise 数一数变化 {level=2 check="3"}
用 GB 流利地说 *Did you find the green bag last week?*（你上周找到那个绿色的包了吗？）。下面这些变化中有几种可能发生：（a）*did you* 中的融合同化；（b）*green bag* 中 /n/ 的同化；（c）*last week* 中 /t/ 的省略？
::: solution
三种都可能：（a）[ˈdɪdʒə]——/d/ + /j/ 融合（[[#rule-coalescence]]）；（b）[ˈɡriːm ˈbæɡ]——/b/ 前的 /n/（[[#rule-place]]）；（c）[ˈlɑːs ˈwiːk]——/s/ 和 /w/ 之间的 /t/（[[#rule-td]]）。答案是3。
:::
:::

::: solution

::: exercise GB 和 GA {level=2}
写出 *tune*（曲调）、*duty*（责任）和 *twenty*（二十）在流利口语中的 GB 和 GA 读音，并解释其中的区别。
::: solution
*tune*：GB /tjuːn/，常常读 [tʃuːn]（词内部的融合同化）；GA /tuːn/（没有 /j/）。*duty*：GB /ˈdjuːti/，常常读 [ˈdʒuːti]；GA /ˈduːti/，带闪音 [ˈduːɾi]。*twenty*：GB /ˈtwenti/；GA /ˈtwenti/，非常常见的读法是 [ˈtweni]，/n/ 后的 /t/ 脱落。GA 在这些词里 /t d n/ 之后的 /j/ 已经脱落（yod-dropping），所以没有什么可以融合；GB 保留 /j/，并常常让它与前面的辅音融合。
:::

::: exercise 快速口语听写 {level=3}
一个朋友给你留了这条语音消息，这里按照实际的说法记了下来（GB）。用普通拼写写出它，然后列出你能找到的每一处省音、同化和融合同化。

[hiː | ɪts ˈsæm | ˈwʊdʒə ˈlaɪk tə ˈkʌm tə ðə ˈsɪnəmə ˈneks ˈwiːk | ðeə ˈʃəʊɪŋ ðə ˈnjuː ˈfɪlm | ɪŋ ˈkeɪs jər ˈɪntrəstɪd | ˈlemi ˈnəʊ | ˈtʃɪəz]
::: hint
这条消息有七个短的部分，用 | 隔开。找一找 [dʒ]、/k/ 前的 [ŋ] 和一个丢失的 /t/。
:::
::: solution
*Hi. It's Sam. Would you like to come to the cinema next week? They're showing the new film, in case you're interested. Let me know. Cheers.*（你好，我是萨姆。下周想不想一起去看电影？他们在放那部新片，如果你有兴趣的话。告诉我一声。再见。）

变化：
- *would you* [ˈwʊdʒə]：/d/ + /j/ 的融合同化，*you* 弱读（[[#rule-coalescence]]）。
- *next week* [ˈneks ˈwiːk]：辅音之间 /t/ 的省略（[[#rule-td]]）。
- *in case* [ɪŋ ˈkeɪs]：/n/ 在 /k/ 前同化为 [ŋ]（[[#rule-place]]）。
- *interested* [ˈɪntrəstɪd]：一个弱元音被省略，三个音节而不是四个（[[#rule-elision]]）。
- *let me* [ˈlemi]：非正式的 *lemme*，/t/ 脱落了。
- 弱读式：*to* 两次读 [tə]，*they're* [ðeə]，*you're* [jər]（在 *interested* 前带连接 /r/）。

一个词一个词地读，这段音标看起来全是不认识的词；一旦你预料到这些变化，这条消息就很容易听懂了。
:::
:::

::: exercise 你自己的快速口语 {level=3}
写五个你可能对朋友说的短句（例如关于周末的计划）。标出可能发生省音、同化或融合同化的地方，然后把每个句子说两遍：一遍仔细地说，一遍流利地说。哪些变化你觉得自然，哪些在你自己说话时宁愿避免？用两三句话解释。
::: solution
答案因人而异。一个范例：*Did you get my message?*（你收到我的消息了吗？）（融合同化 [ˈdɪdʒə]）；*I'm going to the beach next Saturday*（我下周六要去海边）（*next* 中 /t/ 的省略）；*Do you want to come?*（你想来吗？）（[dʒə ˈwɒnə ˈkʌm]）；*We can meet in Brighton*（我们可以在布莱顿见面）（/b/ 前的 /n/ → [m]）；*Let me know by Friday*（星期五之前告诉我）（[ˈlemi]）。一段好的反思可能会说：“融合同化和脱落的 /t/ 感觉很自然；和不太熟的人说话时，我会避免用 *wanna* 和 *lemme*，但我会注意听这些形式。”任何选择都可以，只要学习者能认出所有这些形式。
:::
