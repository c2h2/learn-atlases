一位学了多年英语的学习者看电影时，听到一个角色说了一句大概是 [aɪ ˈdʌnəʊ wɒts ˈɡɒnə ˈhæpm] 的话。她一个词也没听出来。接着字幕出现了：*I don't know what's going to happen.*（我不知道会发生什么。）每个词她都认识——学英语的第一年她就能写出这个句子。问题不在词汇或语法，而在于：她所认识的那些词、以她所认识的那种形式，并没有出现在她听到的声音里。

这是听自然英语的核心问题。本课程前面几章描写了词在连贯语流中会发生什么：非重读音节弱化（[[connected-speech/weak-forms]]），词与词连在一起（[[connected-speech/linking]]），音脱落和改变（[[connected-speech/elision-assimilation]]），音高把语流组织成带有调核的调群（[[connected-speech/intonation-basics]]）。本章把这些知识反过来用：说明听话人怎样**利用**这些模式来解码快速口语，以及怎样练习。

## 切分问题

::: definition 切分 {#def-segmentation}
在书面上，词与词之间用空格隔开。口语里没有空格：一个词的音连到下一个词上，中间没有停顿，正如[[connected-speech/linking]]所示。**切分**（segmentation）是听话人找出一个词在哪里结束、下一个词从哪里开始的任务。母语听话人自动地、毫不费力地完成这项任务；对学习者来说，这正是他们“认识”的话听起来却是一片模糊的主要原因之一。
:::

口语中的停顿出现在调群之间，而不是词与词之间，而且即使在调群之间也常常没有停顿。像 *Did you see where I put my keys?*（你看见我把钥匙放哪儿了吗？）这样的句子，通常是一股不间断的语流：[ˈdɪdʒə ˈsiː weər aɪ ˈpʊt maɪ ˈkiːz]。听话人必须在一串完全没有清楚界限的音中找出六个或更多的词。

::: theorem 强音节标示词的开头 {#rule-strong}
在英语中，大多数**实义词**以一个**强音节**开头——即带有完整元音的音节（不是 /ə/，也不是弱的 /ɪ/ 或 /ʊ/）。卡特勒（Cutler）和卡特（Carter）（1987）统计了一个大型英语口语语料库中的词，发现大约十个实义词中有九个是这样开头的。

由此得出一个有用的听力策略：**把每个强音节当作一个实义词可能的开头**，把弱音节当作可能的功能词，或较长单词中的非重读部分。在 [ðə ˈtiːtʃər ɪkˈspleɪnd ɪt ə ˈɡen]（*The teacher explained it again*，老师又解释了一遍）中，强音节 *tea-*、*-plained* 和 *-gain* 提示有三个实义词。*Tea-* 是 *teacher* 的开头。*-plained* 不是一个词的开头——它是 *explained* 的结尾——但听话人很快就能从这种猜测中纠正过来，而强音节周围的弱音节大多是功能词：*the*、*it*、*a-*。
:::

::: proof
卡特勒和诺里斯（Cutler and Norris 1988）把这称为**节律切分策略**（metrical segmentation strategy），并通过实验表明英语听话人确实在使用它：他们发现，从强音节开始的词比跨越强音节的词更容易被找出来。这个策略之所以有效，是因为英语单词的构成方式（大多数常用实义词重音在第一个音节上，或者是单音节词），也因为功能词通常是弱读的（[[connected-speech/weak-forms]]）。它是一种概率，而不是规则：*exPLAIN*、*aBOUT* 和 *toDAY* 是例外，听话人会用其他知识来纠正猜测。但它给了听话人一个起点：强音节就是要找的地方。
:::

::: quiz
在流利的口语中，短语 *a cup of tea in the garden*（在花园里喝一杯茶）有这些音节：*a · cup · of · tea · in · the · gar · den*。哪些音节是强音节，因而可以很好地猜作实义词的开头？
- [ ] *a*、*of*、*in*、*the*
- [x] *cup*、*tea*、*gar-*
- [ ] *cup*、*tea*、*-den*
- [ ] 全部八个
::: solution
*Cup*、*tea* 和 *gar-* 带有完整元音（/ʌ/、/iː/、/ɑː/），分别是三个实义词 *cup*、*tea* 和 *garden* 的开头。*A*、*of*、*in* 和 *the* 是弱读形式的功能词（/ə/，/əv/ 或 /ə/，/ɪn/，/ðə/）；*-den* /dən/ 带弱元音，是 *garden* 的结尾。
:::
:::

## 利用重音和语调来解码

::: theorem 怎样听一句快速的话 {#rule-listen}
1. **先听重读的词。** 实义词带有重音，是语音信号中最清楚的部分；信息通常可以从它们重建出来。在 *I ˈthought you were ˈgoing to ˈcall me last ˈnight*（我以为你昨晚会给我打电话）中，重读的词 *thought*、*going*、*call* 和 *night* 提供了大部分意思。
2. **补上语法。** 重音之间的弱音节大多是代词、助动词、介词和冠词。你知道哪些是可能的：在 *I thought* 之后、*going* 之前，[jə wə] 只能是 *you were*（或 *you're*）。
3. **利用调核。** 每个调群的调核落在最重要的新信息上（[[connected-speech/sentence-stress#rule-last]]）。如果别的都没听到，也要抓住调核。
4. **利用调。** 降调通常标示一个说完了的陈述或话轮的结束；升调或降升调标示没说完的话或疑问（[[connected-speech/intonation-basics]]）。调告诉你该等还是该回答。
5. **利用语境和预期。** 听话人不断地预测可能会说什么。当一串音可以有不止一种切分方法时，选择说得通的那一种。
:::

::: proof
这个策略也反映了母语者的听力过程。心理语言学研究表明，听话人并不是先一个音一个音、再一个词一个词地处理话语；他们根据部分信息迅速作出猜测，并在更多信息到来时加以修正（Field 2008 为语言教师提供了一个通俗易懂的介绍）。功能词单独拿出来，连母语听话人也常常认不出来：从录音中剪出来的 [ə]，可能是 *a*、*of*、*are*、*or* 或 *her*。它们是靠语境——周围的重读词和语法——辨认出来的。在听懂句子之前就想把每个词都听清楚的学习者，是在尝试做一件母语听话人自己都不做的事。
:::

::: example 解码一个句子 {#ex-decode}
一个说话人以正常语速说（GB）：[ˈwɒdʒə ˈθɪŋk əv ðə ˈfɪlm]。一步一步地推出这个句子。
::: solution
1. **重读音节**：[ˈwɒ]、[ˈθɪŋk]、[ˈfɪlm]。*Think*（想）和 *film*（电影）是清楚的实义词。[ˈwɒdʒə] 是一个重读音节，后面跟着 [dʒə]。
2. **弱化的语块**：[dʒə] 很常见的是融合后的 *did you* 或 *do you*（[[connected-speech/elision-assimilation#rule-coalescence]]）。所以 [ˈwɒdʒə] 是 *what did you* 或 *what do you*，*what* 的 /t/ 脱落了。
3. **语法**：*What d'you think of the film?*——[əv] 是 *of*，[ðə] 是 *the*。
4. **时态**：*What did you think*（问一部已经看过的电影）或 *What do you think*（在讨论一部电影）。由语境——例如刚从电影院出来——来决定。

完整的句子：*What did you think of the film?*（你觉得这部电影怎么样？）只有重读的词听得清楚；其余的都是重建出来的。
:::
:::

::: example 抓住调核 {#ex-nuclei}
车站广播说得很快，喇叭的音质也很差。这里标出了调群和调核（GB）。你需要听清哪些词？为什么？

*The ˈtrain now ˈarriving at ˈplatform ↘↗**four** | is the ˈten fif↘**teen** service | to ↘**Man**chester, | ˈcalling at ↗**Stoke**, | ↗**Mac**clesfield | and ↘**Stock**port.*（现在到达四号站台的列车是十点十五分开往曼彻斯特的班次，沿途停靠斯托克、麦克尔斯菲尔德和斯托克波特。）
::: solution
调核是 *four*、*fifteen*、*Manchester*、*Stoke*、*Macclesfield* 和 *Stockport*——正是旅客需要的信息：站台、时间、终点站和停靠站。其余部分（*the train now arriving at*，*is the*，*service to*，*calling at*）是可以预测的，作为每个调核前的助跑说得很快。调也有帮助：*four* 上的降升调和列举中的升调表示后面还有话；*Stockport* 上的降调标志着列举和广播的结束（[[connected-speech/intonation-basics#rule-tags]]）。抓住了这六个调核的听话人，就听懂了这条广播。
:::
:::

## 弱化的语块

有些组合弱化得非常频繁，把它们当作**语块**——有自己读音形状的单一单位——来学，比每次都去推导要容易。它们大多已在[[connected-speech/weak-forms]]和[[connected-speech/elision-assimilation]]中描写过；这里把它们集中起来，供辨认之用。

| 你听到的 | 意思 | 例子 |
|---|---|---|
| [dʒə] | *do you*，*did you* | *[dʒə] want one?*（你要一个吗？） |
| [ˈwɒdʒə]，[ˈwʌdʒə]（GA [ˈwʌɾəjə]） | *what do you*，*what did you* | *[ˈwɒdʒə] mean?*（你什么意思？） |
| [ˈwʊdʒə]，[ˈkʊdʒə] | *would you*，*could you* | *[ˈkʊdʒə] help me?*（你能帮我一下吗？） |
| [ˈdəʊntʃə] | *don't you* | *[ˈdəʊntʃə] like it?*（你不喜欢吗？） |
| [ˈɡɒnə]，[ˈwɒnə]，[ˈɡɒtə]（GA [ˈɡʌnə]，[ˈwɑːnə]，[ˈɡɑːɾə]） | *going to*，*want to*，*got to* | *I'm [ˈɡɒnə] be late.*（我要迟到了。） |
| [dəˈnəʊ]，[ˈdʌnəʊ] | *don't know* | *I [dəˈnəʊ].*（我不知道。） |
| [ˈkaɪndə]，[ˈsɔːtə] | *kind of*，*sort of* | *It's [ˈkaɪndə] strange.*（这有点奇怪。） |
| [ˈlemi]，[ˈɡɪmi] | *let me*，*give me* | *[ˈlemi] see.*（让我看看。） |
| [əm]，[ðəm] | *them* | *Tell [əm] I'm coming.*（告诉他们我就来。） |
| [kəz]，[kɒz] | *because* | *I left [kəz] I was tired.*（我走了，因为我累了。） |
| [ˈɪnɪt]（英国非正式口语） | *isn't it* | *Cold today, [ˈɪnɪt]?*（今天挺冷，是吧？） |
| [ˈwɒtʃə] | *what are you*，*what you*（GB） | *[ˈwɒtʃə] doing?*（你在干什么？） |

::: example 对话中的语块 {#ex-chunks}
用标准拼写写出这段无意中听到的对话（GB，非正式）。

**A:** [ˈwɒtʃə ˈdʊɪŋ təˈnaɪt]
**B:** [aɪ dəˈnəʊ | ˈprɒbli ˈnʌθɪŋ | ˈwaɪ]
**A:** [ˈwɒnə ˈkʌm tə ðə ˈpʌb]
**B:** [ˈʃʊə | ˈlemi ˈtel ˈsæm | hiː ˈmaɪt ˈwɒnə ˈkʌm ˈtuː]
::: solution
**A:** *What are you doing tonight?*（你今晚干什么？）
**B:** *I don't know. Probably nothing. Why?*（不知道。大概没什么事。怎么了？）
**A:** *(Do you) want to come to the pub?*（想去酒吧吗？）
**B:** *Sure. Let me tell Sam — he might want to come too.*（好啊。我跟萨姆说一声——他可能也想去。）

说明：[ˈwɒtʃə] = *what are you*；[dəˈnəʊ] = *don't know*；[ˈprɒbli]——*probably* 中一个弱音节被省略了（[[connected-speech/elision-assimilation#rule-elision]]）；[ˈwɒnə] = *want to*，A 的问句把 *do you* 完全丢掉了，这在非正式口语中很常见；[ˈlemi] = *let me*。
:::
:::

## 词界有歧义的时候

因为词与词之间没有停顿，有些音串可以有不止一种切分方法。[[connected-speech/linking#ex-boundary]]举过 *grey tape*（灰色胶带）和 *great ape*（大猩猩等类人猿）这样的例子。下图展示听话人怎样同时考虑这两种可能。

::: widget graph
nodes: heard /ɡreɪteɪp/@0,3; grey + tape@-3,1.5; great + ape@3,1.5; context - a parcel to wrap@-3,0; context - a zoo@3,0; the speaker meant grey tape@-3,-1.5; the speaker meant great ape@3,-1.5
edges: heard /ɡreɪteɪp/>grey + tape; heard /ɡreɪteɪp/>great + ape; grey + tape>context - a parcel to wrap; great + ape>context - a zoo; context - a parcel to wrap>the speaker meant grey tape; context - a zoo>the speaker meant great ape
caption: 同一串音的两种切分方法。听话人听到 /ɡreɪteɪp/（heard），会自动地考虑不止一种切分：*grey + tape* 或 *great + ape*。语境（context）决定说话人的意思（the speaker meant）：要包一个包裹（a parcel to wrap），还是在动物园（a zoo）。细小的语音细节可能有帮助——*tape* 的 /t/ 送气，*great* 的 /eɪ/ 较短，在 GA 中 *great ape* 可能带闪音——但在快速口语中，决定通常是由语境作出的。方框可以拖动。
:::

母语者也会切分错，尤其是在听歌词的时候，因为那时语境很弱，音乐又掩盖了话语的节奏。这类误听叫作 **mondegreen**（“误听词”），来自一首苏格兰民谣中的一句 *and laid him on the green*（把他放在草地上），美国作家西尔维娅·赖特（Sylvia Wright）小时候把它听成了 *and Lady Mondegreen*（和蒙德格林夫人）。

::: warning 不要等着听清每一个词
✗ 每遇到一个没听清的词就停下录音，或者在继续往下听之前，想把每个功能词都听清楚。
✓ 听重读的词和调核，先抓大意，再把其余部分补上。

✗ 只用语速慢、发音仔细的学习材料。
✓ 把它们和自然话语——对话、播客、电影——搭配起来用，哪怕一开始听懂得少一些。

快速口语中的功能词，谁都听不清楚。在每个功能词上停下来的听话人，会丢掉整个句子。而为学习者慢速录制、每个词都用强读式的材料，并不能训练耳朵去适应真实话语中的弱化形式。
:::

## 练习

::: theorem 四种练习方法 {#rule-practice}
1. **听写。** 把一段简短的自然录音（一两个句子）听几遍，准确地写下所说的话。然后和文字稿对照。错误会显示你还认不出哪些弱化形式。
2. **合作听写重构（dictogloss）。** 以正常语速把一段短文（一个段落）听两遍，只记下关键词；然后独自或和同伴一起，尽可能准确地重构原文，再与原文对照（Wajnryb 1990）。这能训练你听出重读词并重建语法。
3. **跟读（shadowing）。** 跟着录音说，落后零点几秒，模仿节奏、弱化和语调。自己说出弱化形式，会让它们更容易被听出来。
4. **先听，后看文字稿。** 先不看文字听；然后读文字稿再听一遍，准确地注意你听到的和写出来的有什么不同；最后不看文字再听一遍。
:::

::: proof
每种方法针对一种不同的技能。听写迫使你注意每一个词，包括弱读式，因而准确地显示出切分在哪里失败了。合作听写重构训练的是相反的技能——从重读词来理解——并把它与语法结合起来。跟读把感知和产出联系起来：能流利地说出 [ˈwɒdʒə] 的学习者，也更善于认出它。先不看文字稿地听，可以防止用阅读代替听；之后再看文字稿，能让书面形式和口语形式之间的差距显现出来。教师使用听写已有几百年的历史；它对连贯语流的价值在于，错误本身能提供信息。
:::

::: example 一次听写和其中的错误 {#ex-dictation}
一位学习者在播客中听到：*I've been meaning to ask you about that for ages.*（我一直想问你那件事，想了好久了。）她写成了：*I've been mean to ask you a bout that for age.* 用本课程讲过的过程解释每一个错误。
::: solution
- 把 *meaning to* 写成 *mean to*：在快速、非正式的口语中，*-ing* 常常读成 [ɪn] 而不是 [ɪŋ]，*to* 也是弱读的：[ˈmiːnɪn tə]。弱音节 [ɪn] 在语流中丢失了，学习者选择了一个她认识的动词形式。
- 把 *about* 写成 *a bout*：*about* 的第一个音节是弱的 /ə/，听起来和冠词 *a* 一样（[[#rule-strong]]：*-bout* 是强音节，而这个词从它前面就开始了——这是学习者必须记住的一个例外）。
- 把 *for ages* 写成 *for age*：*ages* 的 /z/ 在调群末尾很弱，也许还清化了；但语法（*for* + 表示时间的复数说法）本可以把它补回来。
- *ask you* 写对了：学习者听到的可能是 [ˈɑːsk jə] 或 [ˈɑːskjuː]——/k/ 和 /j/ 的连读。

每个错误都出在学习者只依靠声音的地方；语法和常用语块 *for ages*（很久）本可以纠正其中两个。
:::
:::

::: note 英汉对比
- **汉语的每个音节都算数。** 在普通话中，几乎每个音节都是一个带有完整元音和声调的语素，听话人期待每个音节都清楚。英语的弱音节并不清楚，学习者可能以为自己“漏听”了什么，而实际上那里本来就没有多少可听的。
- **听强音节，而不是听“字”。** 中文读者习惯把文字分成一个一个的字，每个字一个音节。对英语听力来说，更有用的单位是**音步**（[[connected-speech/rhythm#def-foot]]）：一个强音节加上它后面的弱音节。像[[#rule-strong]]那样，去听强音节。
- **考试听力和真实听力。** 许多听力考试使用朗读得很清楚的稿子，在这类考试中成绩很好的学习者，可能仍然觉得电影和对话很难。两者都有用，但只有自然话语才能训练你辨认弱化形式。
- **字幕。** 中文字幕帮助你跟上情节，却让你跳过了英语。英文字幕对把声音和词联系起来更有用；最好的办法是先不看字幕听，然后再看英文字幕听，就像[[#rule-practice]]第4条那样。
:::

::: history
在语言教学中系统地关注对自然、弱化话语的听力，始于20世纪70年代。吉莉恩·布朗（Gillian Brown）的《听英语口语》（*Listening to Spoken English*，1977；第2版1990）为教师描写了会话英语中的弱化现象，并说明了它和教学材料中仔细的发音有多么不同。20世纪80年代，安妮·卡特勒（Anne Cutler）和她的同事研究了听话人怎样切分话语：卡特勒和卡特（1987）发现英语实义词以强音节开头占绝对优势，卡特勒和诺里斯（1988）提出了节律切分策略。鲁思·瓦伊恩里布（Ruth Wajnryb）的《语法听写》（*Grammar Dictation*，1990）使合作听写重构广为人知。约翰·菲尔德（John Field）的《语言课堂中的听力》（*Listening in the Language Classroom*，2008）主张教师应该直接训练听力中的解码过程，而不只是测试理解。*mondegreen* 这个词是西尔维娅·赖特在1954年发表于《哈泼斯杂志》（*Harper's Magazine*）的一篇随笔中创造的。
:::

## 后续内容

这是本课程的最后一章。较长语篇的听力策略——抓大意、听细节——在[[listening-and-conversation/how-listening-works]]和[[listening-and-conversation/gist-and-detail]]中展开；弱化和连读方式不同的口音，见[[listening-and-conversation/accents]]；用电影、播客和其他媒体进行练习，见[[listening-and-conversation/learning-from-media]]。

::: summary
- 口语中没有空格；**切分**——找出词界——是学习者的主要困难之一（[[#def-segmentation]]）。
- 大多数英语实义词以**强音节**开头；把强音节当作词的可能开头（Cutler and Carter 1987；[[#rule-strong]]）。
- 先听重读的词和调核，再根据语法和语境补上功能词；利用调来判断说话人是否说完了（[[#rule-listen]]）。
- 把常见的**弱化语块**——[dʒə]、[ˈwɒdʒə]、*gonna*、*dunno*、*lemme*——当作整体来学。
- 有歧义的切分（*grey tape* / *great ape*）主要靠语境来解决。
- 用**听写**、**合作听写重构**、**跟读**和**先听后看文字稿**的方法来练习（[[#rule-practice]]）。
:::

## 习题

::: exercise 强音节 {level=1}
在心里给强音节画线，并说明它们是哪些实义词的开头。

1. *a glass of water*（一杯水）2. *in the morning*（在早上）3. *She's at the station.*（她在车站。）
::: solution
1. *glass*，*wa-*（*water*）。2. *mor-*（*morning*）。3. *sta-*（*station*）。（*She's*、*at* 和 *the* 在正常口语中是弱读的。）
:::
:::

::: exercise 语块 {level=1}
用标准拼写写出来。

1. [dʒə ˈwɒnə ˈkʌm] 2. [aɪ dəˈnəʊ] 3. [ˈlemi ˈsiː] 4. [ˈkʊdʒə ˈhelp mi]
::: solution
1. *Do you want to come?*（你想来吗？）2. *I don't know.*（我不知道。）3. *Let me see.*（让我看看。）4. *Could you help me?*（你能帮我一下吗？）
:::
:::

::: exercise 两种切分方法 {level=1}
每串音都可以有两种切分方法。写出两种。

1. [ə ˈnaɪs ˈmæn] 2. [sʌ ˈmʌðəz] 3. [ˈaɪs ˈkriːm]
::: solution
1. *a nice man*（一个好人）或 *an ice man*（一个卖冰的人）。2. *some others*（另外一些）（/m/ 与元音连读，[[connected-speech/linking#rule-cv]]）或 *some mothers*（一些母亲）（两个 /m/ 说成一个，[[connected-speech/linking#rule-cc]]）；较长的 [mː] 提示是 *mothers*。3. *ice cream*（冰淇淋）或 *I scream*（我尖叫）（*cream* 的 /k/ 送气；*scream* 中的不送气）。
:::
:::

::: exercise 数强音节 {level=2 check="3"}
以正常语速说 *The teacher explained it again*（老师又解释了一遍），有几个强音节？
::: solution
*tea-*（/iː/）、*-plained*（/eɪ/）和 *-gain*（/e/）。*The*、*-cher*、*ex-*、*it* 和 *a-* 是弱的。答案是3。
:::
:::

::: exercise 从重音重建句子 {level=2}
你只听清了重读的词：*... ˈthought ... ˈmeeting ... ˈTuesday ... ˈmoved ... ˈFriday.* 重建一个可能的句子，并标出它的调群和调核。
::: solution
*I ˈthought the ˈmeeting was on ↘↗**Tues**day, | but it's been ˈmoved to ↘**Fri**day.*（我以为会议在星期二，可是它改到星期五了。）

也可以有别的重建（*We thought the meeting on Tuesday had been moved to Friday*，我们以为星期二的会议改到星期五了）；好的答案按顺序使用重读的词，并补上合理的功能词。调核 *Friday* 是新信息。
:::
:::

::: exercise 她听到了什么？ {level=2}
一位学习者把 *I've got to go.*（我得走了。）写成了 *I got a go*。解释这个错误。
::: solution
*Got to* 常常弱化为 [ˈɡɒtə]（GB）或 [ˈɡɑːɾə]（GA），*I've* 在 /ɡ/ 前弱化为 [aɪv]，甚至 [aɪ]。学习者听到 [aɪ ˈɡɒtə ˈɡəʊ]，把 [ˈɡɒtə] 切分成了 *got a*——这本身也是一个真实的英语组合。语法（*I've got to* + 动词）和语境（有人要离开）表明说的是 *I've got to go*。*Gotta* 是一个需要学的语块（[[connected-speech/elision-assimilation#rule-gonna]]）。
:::
:::

::: exercise 听写项目 {level=3}
选一段30秒的自然英语片段（播客或电影中的对话，而不是新闻朗读）。把你听到的全部写下来，需要听几遍就听几遍。然后和文字稿或字幕对照，把你的错误分类：弱读式、连读、省音/同化、语块、词汇、其他。
::: hint
选一段有文字稿的片段。先把每一处不同标出来，再判断本课程的哪一章能解释它。
:::
::: solution
答案因人而异。典型的结果是：大多数错误涉及弱读式（漏掉了 *of*、*to*、*have*）、语块（*gonna*、*d'you*）和跨词界的连读，涉及生词的较少。好的答案会举出两三个具体例子，并把每个例子和一个过程联系起来，例如：“我把 *I wanted to* 写成了 *I want to*：*wanted* 的 *-ed* 在 *to* 前脱落了——这是省音。”
:::
:::

::: exercise 跟读日记 {level=3}
连续一周，每天用五分钟跟读同一段一分钟的片段。在第1天和第7天给自己录音，并记下：你能说出哪些弱化形式？你在哪里跟丢了说话人？有什么变化？
::: solution
答案因人而异。学习者通常报告说，第1天他们在弱化语块和长调尾处跟不上，到第7天就能跟上节奏，并说出大多数弱读式。一份好的日记会写出具体的短语（例如 *what are you gonna do* [ˈwɒtʃə ˈɡɒnə ˈduː]，你打算怎么办），并注意到调核和整体旋律比单个的词更容易模仿。
:::
:::
