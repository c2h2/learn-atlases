每一个说普通话的人都已经是控制音高的行家。要把 *mā* 妈、*má* 麻、*mǎ* 马 和 *mà* 骂 说对，你必须在每个音节上控制声音的高低和走向，一秒钟要控制好多次。那么，为什么那么多老师说中国学习者的英语语调“平板”或“一顿一顿的”，或者说每个词“听起来都像带着声调”？

答案并不是说普通话的人不会控制音高，而是普通话和英语用音高做**不同的工作**。在普通话中，音高首先是词的一部分；在英语中，它属于短语（[[connected-speech/intonation-basics#def-tone]]）。对一种工作完全正确的习惯，可能会妨碍另一种工作。本章比较这两个系统，说明普通话的习惯在哪里有帮助、在哪里有干扰，并提供训练英语音高模式的实用方法。本章不重讲英语语调本身——那部分内容见[[connected-speech/intonation-basics]]和[[connected-speech/intonation-meaning]]。

## 普通话的声调

为了比较这两个系统，我们需要一种记录普通话声调的方法。通常用的方法是中国语言学家赵元任（Yuen Ren Chao）发明的。

::: definition 赵氏五度标调法 {#def-chao}
在**五度标调法**（Chao tone numbers，也叫“调符”，tone letters）中，说话人的音域被分成五度，从1（最低）到5（最高），一个声调用它起点、（转折点、）终点的度数来记录。标准普通话的四个声调单念时是：

| 声调 | 拼音调号 | 五度值 | 形状 | 例子 |
|---|---|---|---|---|
| 1（阴平） | ā | 55 | 高平 | *mā* 妈 |
| 2（阳平） | á | 35 | 升 | *má* 麻 |
| 3（上声） | ǎ | 214 | 低，先降后升 | *mǎ* 马 |
| 4（去声） | à | 51 | 降，从高到低 | *mà* 骂 |

此外还有**轻声**：一个短而轻的音节，它的音高取决于前面的声调，如 *māma* 妈妈、*xièxie* 谢谢 或 *dōngxi* 东西 的第二个音节。
:::

这些调值描写的是单念的音节。在连贯语流中，它们会发生变化：

::: theorem 连贯语流中的普通话声调 {#rule-sandhi}
1. **上声在上声前**变成升调，像阳平：*nǐ hǎo* 你好 说成 *ní hǎo*；*hěn hǎo* 很好 说成 *hén hǎo*。
2. **上声在其他声调前**通常只保留它的低的部分（“半上”，约为21或211）：*hǎo chī* 好吃，*Běijīng* 北京。完整的降升调214主要出现在话语末尾，或者这个音节被强调的时候。
3. ***yī* 一 和 *bù* 不** 的声调随后一个音节而变：*bù* 在去声前变成 *bú*（*bú shì* 不是），*yī* 在去声前变成 *yí*（*yí gè* 一个），在其他声调前变成 *yì*（*yì tiān* 一天）。
4. **轻声音节**短而弱，它的音高由前面的音节决定：在阴平、阳平或去声后面相当低，在上声后面较高。
:::

::: proof
这些变化是普通话语法的一部分，不是可有可无的变体：一个人如果把 *nǐ hǎo* 说成两个完整的214，听起来会很奇怪。它们说明普通话的音高并不只是一串固定的形状、每个音节一个；它会根据相邻的成分加以调整，就像英语的音在同化中被调整一样（[[connected-speech/elision-assimilation]]）。但这些调整是局部的、有规则可循的，每个音节仍然带有一个能辨认出词的声调。其他汉语方言有不同的系统：**粤语**通常被描写为有六个声调（例如 *si1* 诗 55，*si2* 史 25，*si3* 试 33，*si4* 时 21，*si5* 市 23，*si6* 事 22），在几个不同的高度上使用平调，也没有普通话那样的轻声。说粤语、吴语、闽语和其他方言的人，各自把自己的音高习惯带进英语，本章的内容并不完全同样适用于他们。
:::

## 普通话的语调

人们常说“汉语有声调，所以没有语调”。这不对。说普通话的人也在整段话语上运用音高，来表示疑问、焦点、感情和话轮的结束。

::: theorem 普通话语调怎样起作用 {#rule-mandarin-int}
1. **声调保持形状。** 普通话中的语调改变的是声调的**高度和音域**——把它们升高或降低、拓宽或压窄——但去声仍然降，阳平仍然升。
2. **不带语气词的问句**（*Nǐ míngtiān zǒu?* 你明天走？）通常用较高的音高说出，尤其是在接近末尾的地方，而最后一个音节保持自己的声调。
3. **焦点**通过拓宽焦点词的音域、延长它来表示；在北京话中，后面的词的音高会降低并压缩（Xu 1999）。
4. **音高下倾**：在一个陈述句中，音高往往逐渐下降，和英语一样。
:::

::: proof
赵元任用一个著名的比喻描述过这种关系：字调就像骑在语调大波浪上的小波纹（Chao 1968）。两个层次叠加在一起。在英语中只有一个层次：非重读音节没有自己的音高，短语的主要变化从调核开始，贯穿调尾（[[connected-speech/sentence-stress#def-nucleus]]）。所以英语的调尾在降调之后可以又长又低又平——*I ˈsaw it in the ↘**pa**per this morning*（我今天早上在报纸上看到的）——而普通话调尾中的每个音节，即使被压缩了，也必须仍然能凭声调辨认出来。
:::

::: example 两种语言中的疑问句 {#ex-questions}
比较音高是怎样把下面两句变成疑问句的。

1. 普通话：*Nǐ míngtiān qù?* 你明天去？
2. 英语：*You're going to↗**mor**row?*（你明天去？）
::: solution
1. 在普通话中，整句话用较高的音高说，尤其是末尾，但 *qù* 去 仍然是去声：它还是降的，只是起点更高，也许降得没那么陡。听话人既听出了“去”这个词，也听出了疑问。
2. 在英语中，调核是 *-mor-*，声音从那里一直上升到调群结束：*-row* 继续往上。没有字调要保持，所以问句的末尾是高的。

把普通话模式迁移过来的学习者，可能会用整体偏高的音高说 *You're going tomorrow?*，却在 *-row* 上用一个降调结尾（好像它是个去声音节）。说英语的听话人听到末尾的降调，可能会把这个问句当成陈述句。
:::
:::

::: quiz
在普通话问句 *Tā shì lǎoshī?* 他是老师？ 中，不带语气词说的时候，最后一个音节 *shī* 通常怎样？
- [ ] 它变成升的阳平，以表示疑问。
- [x] 它保持高平的阴平，但句子的音高，尤其是接近末尾的地方，被抬高了。
- [ ] 它变成轻声。
- [ ] 什么也不变：普通话不能说不带语气词的问句。
::: solution
在普通话中，语调改变声调的高度和音域，但不改变它们的形状（[[#rule-mandarin-int]]）：*shī* 仍然是阴平，只是音高抬高了。如果它变成升调，听话人可能会听成另一个音节。相比之下，英语的 *He's a ↗**teach**er?*（他是老师？）从调核开始上升，因为 *teacher* 这个词没有需要保持的声调。
:::
:::

## 普通话的习惯在哪里造成干扰

::: theorem 常见的迁移模式 {#rule-transfer}
老师和研究者常常在以普通话为母语的学习者的英语中描述到以下特征。并不是每个学习者都有全部这些特征。

1. **每个音节都有音高变化**，或者每个重读音节都有，好像每个音节都带着声调。结果听起来一顿一顿的，听话人找不到调核。短词常常被说成一个降的、像去声一样的音高：*I ↘ want ↘ to ↘ go ↘ home.*（我想回家。）
2. 调群末尾的**降调太短太陡**，像去声。在英语中，它们可能听起来生硬或不耐烦（[[connected-speech/intonation-meaning#rule-range]]）。
3. **整体音域窄**，尤其是在朗读或专注于用词的时候——于是说话人听起来平板或不感兴趣。
4. **升调和降升调很少**，于是非末尾的调群听起来像已经说完，陈述句形式的问句听起来像陈述句。
5. **调核位置不对**，因为主要的音高变化没有集中在一个音节上（[[connected-speech/sentence-stress]]）。
:::

::: proof
这些特征每一个都来自普通话的系统。如果每个音节都需要一个音高目标，那么自然也会给每个英语音节一个——而去声是一个清楚的降调，在普通话口语中非常常见，很容易成为默认选择。普通话的降调在一个音节内完成，所以英语的降调被说得太短。普通话的音域被“花”在了声调上，英语用音域表达的态度，在普通话中大多由语气词来表达（[[connected-speech/intonation-meaning]]）。普通话的问句用语气词或抬高音高来标示，而不是用末尾的升调。这些都不是音高控制能力差的表现；它们是很好地掌握了另一个系统的表现。

也有**优势**。说普通话的人能精确地听出和发出音高的差别；轻声为他们提供了弱音节和调尾的模型；北京话和英语一样，在焦点之后压缩音高（但粤语不是这样；见[[connected-speech/sentence-stress]]）；而降而后升的上声在形状上接近英语的降升调。
:::

::: example 一顿一顿的朗读 {#ex-choppy}
一位学习者朗读：*I went to the shop to buy some bread.*（我去商店买了些面包。）每个词都有自己的一个小降调，像去声一样，*bread* 以一个短而陡的降调结尾。你会怎样修改？
::: solution
1. **一个调核。** 在一个调群里只有一个主要变化，在最后一个实义词上：*I ˈwent to the ˈshop to ˈbuy some ↘**bread**.*
2. **功能词上不要降。** *I*、*to*、*the*、*some* 是弱读式（[[connected-speech/weak-forms]]），没有自己的音高变化；它们依附在重读音节的音高上。
3. **重读音节是“台阶”，不是“降”。** 在调核之前，*went*、*shop* 和 *buy* 是重读的，但通常只带一点音高上的台阶，往往一个比一个稍低。
4. **一个更长、更平滑的降调。** *bread* 上的降调起点更高，占满整个音节，结尾很低：它是舒展开的，而不是被截断的。

一个有用的比喻：在英语中，句子的大部分是助跑，调核是起跳。
:::
:::

::: warning 不要把英语重音对应到普通话声调上
✗ 把英语的重读音节当作去声、非重读音节当作阴平，于是 *PHOtograph*（照片）的每个音节都有自己的音高形状：*PHO-* 上一个降调，接着两个高平的音节。
✗ 把英语降调当作“第四声”、升调当作“第二声”，用在每个词上：*↘ Where ↘ do ↘ you ↗ live?*

英语重音是由长度、响度、元音音质和音高共同表现的（[[sounds-of-english/word-stress-basics]]），一个重读音节的音高取决于它在语调模式中的位置，而不取决于词。同一个音节 *PHO-* 可以高、可以低、可以升、可以降，它仍然是 *photograph*。普通话声调可以帮助你**感受**一种音高形状（见下文），但它们不是英语单词的密码。
:::

## 训练英语音高

::: theorem 练习方法 {#rule-practice}
1. **哼出旋律。** 说一个短语，然后闭着嘴把它哼出来，只保留音高和节奏。哼唱去掉了词，也就去掉了每个音节一个声调的习惯。然后保持哼出来的旋律，再说一遍。
2. **先标再说。** 在朗读一段文字之前，标出调群（|）、调核（黑体）和调（↘ ↗ ↘↗）。大多数学习者事先决定好变化在哪里，读得就会更好。
3. **夸张。** 把调核上的降或升做得比自己觉得自然的大得多。录音通常显示，“夸张”的版本听起来是正常的（[[connected-speech/intonation-meaning#ex-learner]]）。
4. **跟读。** 听一段自然话语的短录音，跟着它说，落后零点几秒，模仿的是旋律而不是词。
5. **把普通话声调当作桥梁——只用在一个音节上。** 一个单音节的英语回答可以借用一个声调的形状：*↘No*（不）像去声的降，*↗Yes?*（嗯？）像阳平的升，降升调 *↘↗Well …*（嗯……）像完整的上声。然后把同样的形状铺展到更长的短语上，变化从调核开始。
:::

::: proof
这些方法针对问题的不同方面。哼唱和跟读训练耳朵和嗓音去掌握整段旋律，而不是一个音节一个音节的目标。标记把“变化放在哪里”的决定和说话的费力分开。夸张抵消了因为专注而造成的窄音域。声调桥梁利用学习者已经会做的事——在一个音节上发出降、升或曲折——作为起点，然后教普通话没有的英语特征：把这个变化铺展到调尾上。没有哪种方法能代替大量地听自然的英语；但它们让你更容易注意到自己听到了什么。
:::

::: example 从一个音节到一个短语 {#ex-bridge}
用声调桥梁练习降升调，从一个音节开始。

1. *↘↗**Sure**.*（当然。）2. *I'm ↘↗**sure**.*（我确定。）3. *I'm ↘↗**sure** it's fine.*（我相信没问题。）4. *I'm ↘↗**sure** it'll be fine on the day.*（我相信到时候会没问题的。）
::: solution
1. 在单个音节上，英语降升调接近完整的普通话上声214——先降后升——但起点更高：*sure* 从中高处开始，下降，再升起。
2. *I'm* 不重读，是低的；整个降升调仍然在 *sure* 上完成。
3. 现在降发生在 *sure* 上，升则铺展在调尾 *it's fine* 上：*sure* 下降，*it's* 是低的，*fine* 上升。*Fine* 在这里没有自己的“调”；它只是承载升调的末尾。
4. 调尾更长了：*sure* 下降，*it'll be fine on the* 保持低，*day* 上升。同一个旋律，被拉长了。

意思：说话人在安慰对方，也许带一点保留（*I'm sure it'll be fine — but …* 我相信会没问题——不过……），如[[connected-speech/intonation-meaning#rule-attitude]]所述。在这个练习中，学习者从一个音节上的类似声调的变化，过渡到了一个短语上的英语变化。
:::
:::

::: example 给一段短文标调 {#ex-mark}
为朗读标出这条消息（GB），然后按标记把它说出来。

*Hi everyone. The meeting has moved to Thursday afternoon. If you can't come, please let me know by Wednesday. Thanks.*（大家好。会议改到星期四下午了。如果你来不了，请在星期三之前告诉我。谢谢。）
::: solution
*↘**Hi** everyone. | The ˈmeeting has ˈmoved to ˈThursday ↘**af**ternoon. | If you ↘↗**can't** come, | ˈplease let me ˈknow by ↘**Wednes**day. | ↘**Thanks**.*

- *everyone* 在 *Hi* 的调尾里（调核之后的称呼语）。
- *Thursday afternoon*：调核在最后一个实义词上；*Thursday* 重读，但没有单独的变化。
- *If you can't come*：非末尾的从句，用降升调；调核是 *can't*，因为否定是关键。
- *Thanks* 用高而宽的降调——友好，而不生硬。

五个调群，五个调核：其余每个音节都依附在它们上面。
:::
:::

::: note 英汉对比
- **用轻声作调尾的模型。** *xièxie* 谢谢 或 *zhuōzi* 桌子 中又轻又短的音节，是普通话中最接近英语非重读音节和调尾的东西。把英语调尾“像轻声一样”说出来——短、轻、跟着调核的音高走——是一个有用的比喻。
- **去声和英语降调。** 去声短而陡。末尾调核上的英语降调通常更舒展，幅度随态度而变化。在 *↘**no**w*（现在）、*↘**rea**lly*（真的）、*↘**won**derful*（太好了）这样的词上练习长的降调。
- **说其他方言的人。** 说粤语的人有六个声调、许多平调，可能会给英语音节在不同高度上加平的音高；而且由于粤语在焦点之后不压缩音高（Wu and Xu 2010），他们可能比北京人更难掌握又低又平的英语调尾。说上海话等吴语的人，声调常常铺展在整个词上，又可能有不同的习惯。
- **不只是中国学习者。** 说其他声调语言（越南语、泰语、约鲁巴语）的人，以及说语调很不一样的语言（法语、日语）的人，也需要学习英语的系统。这里描述的困难关乎音高习惯，而不是能力。
:::

::: history
赵元任（Yuen Ren Chao，1892–1982）在1930年发表于《语音学教师》（*Le Maître Phonétique*）的《一套标调的字母》（“A system of tone-letters”）中提出了他的调符系统；至今它仍是描写汉语以及许多其他语言声调的标准方法。带有调号 ā á ǎ à 的汉语拼音方案于1958年在中华人民共和国正式通过。赵元任的《中国话的文法》（*A Grammar of Spoken Chinese*，1968）描写了声调和语调的相互作用，包括波浪上的波纹这个比喻。20世纪90年代，许毅（Yi Xu）等语音学家用声学测量表明了说普通话的人怎样在保持声调形状的同时标示焦点和疑问（Xu 1999）。从那时起，汉语和英语音高的比较以及学习者的问题，已经成为第二语言语音学的一个重要研究领域。
:::

## 后续内容

本课程的最后一章[[connected-speech/hearing-fast-speech]]，把重音、弱读式、连读和语调结合起来，用于解码自然的话语。用录音、跟读和媒体材料进行练习，在[[listening-and-conversation/learning-from-media]]中展开。

::: summary
- 普通话用音高区分**词**（声调：用五度值表示为55、35、214、51，另有轻声）；英语用音高表示**短语**——调核、调和音域（[[#def-chao]]）。
- 普通话声调在语境中会变化（上声变调、半上、“一”和“不”的变调），但每个音节都保留一个声调（[[#rule-sandhi]]）。
- 普通话也有语调：它把声调升高、降低、拓宽、压窄，但保持它们的形状——“波浪上的波纹”（[[#rule-mandarin-int]]）。
- 典型的迁移：每个音节都有变化，降调短而陡，音域窄，升调和降升调少，调核不清楚（[[#rule-transfer]]）。也有优势：精确的音高控制、轻声，以及北京话焦点后的压缩。
- 通过哼唱、标记、夸张和跟读来练习；把声调形状用在一个音节上作为桥梁，然后把它铺展到调尾上（[[#rule-practice]]）。
:::

## 习题

::: exercise 五度值 {level=1}
写出每个字单念时声调的五度值：1. *tāng* 汤 2. *táng* 糖 3. *tǎng* 躺 4. *tàng* 烫
::: solution
1. 55 2. 35 3. 214 4. 51
:::
:::

::: exercise 变调 {level=1}
在正常说话时，第一个音节怎么读？

1. *hěn hǎo* 很好 2. *bù duì* 不对 3. *yī tiān* 一天 4. *hǎo chī* 好吃
::: solution
1. *hén*——上声在上声前变成升调。2. *bú*——在去声前。3. *yì*——在阴平前。4. 半上（低，约21）：*hǎo* 在阴平前。
:::
:::

::: exercise 词还是短语？ {level=1}
在哪种语言中改变音高会改变**词**，在哪种语言中会改变短语传达的**信息**？各举一个例子。
::: solution
普通话：改变音高可以改变词——*mǎi* 买 和 *mài* 卖。英语：改变音高改变的是信息，而不是词——*↘**Mon**day*（星期一。——回答）和 *↗**Mon**day?*（星期一？——提问）（[[connected-speech/intonation-basics#def-tone]]）。
:::
:::

::: exercise 降多少？ {level=2 check="4"}
在赵元任的五度标度上，去声单念时降了几度？
::: solution
去声是51：从5度降到1度，降了4度。（英语降调没有固定的幅度：可大可小，它的幅度表达态度。）
:::
:::

::: exercise 找出调核 {level=2}
一位学习者给每个词一个单独的降调：*She ↘ is ↘ a ↘ teach ↘ er.*（她是老师。）把它改写成一个调群，标出调核，并描述其他音节应该怎样。
::: solution
*She's a ↘**teach**er.* 调核是 *teach-*；降调从那里开始，*-er* 是低的，在调尾里。*She's a* 不重读，没有自己的变化——作为助跑，说得又快又轻。用缩约形式 *She's*（或弱读的 *is* /z/）也去掉了一个被错误重读的音节。
:::
:::

::: exercise 问句还是陈述句？ {level=2}
一位学习者用较高的音高问 *You're from Shanghai?*（你是上海人？），但最后一个音节 *-hai* 是个短降调。解释为什么说英语的人可能听不出这是问句，以及怎样改正。
::: solution
在英语中，陈述句形式的问句只靠升调来标示（[[connected-speech/intonation-basics#rule-questions]]）。学习者像普通话中不带语气词的问句那样抬高了整体音高，却在最后一个音节上保留了降调——也许因为 *hǎi* 海 在普通话中有声调，或者出于习惯。说英语的人听到末尾的降调，就理解成了陈述句。改正：把调核放在 *-hai* 上，从那里**上升**：*You're from Shang↗**hai**?*——话语的末尾应该明显高于调核的起点。
:::
:::

::: exercise 先哼再说 {level=3}
从本课程的例子中选三个句子（例如 *Would you like ↗tea | or ↘coffee?* 你要茶还是咖啡？，*If you're ↘↗free | we could go to the ↘cinema* 如果你有空，我们可以去看电影，*It's a ↘lovely day, | ↘isn't it?* 天气真好，是吧？）。对每一句：（1）标调；（2）哼出来；（3）按哼出来的旋律说出来；（4）录音并比较。记下你第一次尝试和最后一次尝试之间有什么变化。
::: solution
答案因人而异。一份好的报告会注意到，例如：“第一次我给 *would*、*like* 和 *tea* 各加了一个降调；哼过以后，唯一的变化只剩下 *tea* 上的升和 *coffee* 上的降。”或者：“我在 *cinema* 上的降调太短了；哼唱让它变长了。”关键的检验是：在录音中，听话人能否在每个调群中听到一个主要的变化，并且是在标出的调核上。
:::
:::

::: exercise 教给朋友 {level=3}
给一位说中文的朋友写一段简短的说明（80–120个英文词，或相应长度的中文），讲清普通话声调和英语语调的主要区别，各举一个例子，并给一条实用的建议。
::: solution
范例（中文）：“在普通话里，每个音节都有自己的声调，而且声调是词的一部分：*mǎi* 买 和 *mài* 卖 是不同的词。英语的词没有声调。英语是每个短语有一个主要的音高变化，落在最重要的词上，它改变的是意思，而不是词：*Monday* 用降调是回答，用升调是提问。所以说英语时，不要给每个词都加音高变化。选出重要的词，在那里做一个清楚的降或升，其他的词说得轻而快。建议：先把句子哼出来，再用同样的旋律说出来。”答案因人而异；好的答案对两边各举一个准确的例子，并给出一条可用的建议。
:::
:::
