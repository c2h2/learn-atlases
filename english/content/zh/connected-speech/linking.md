听一个说英语的人说 *Pick it up.*（把它捡起来。）你听到的不会是三个分开的词 *pick* · *it* · *up*，而更接近 *pi-ki-tup*：*pick* 的 /k/ 成了下一个音节的开头，*it* 的 /t/ 也一样。同样，*an apple*（一个苹果）听起来像 *a-napple*，*turn off*（关掉）像 *tur-noff*，而 *go out*（出去）的两个元音之间有一个小小的 *w*：*go-wout*。

这种词与词的连接叫作**连读**。它是英语听起来流畅的原因之一，也是学习者难以听出一个词在哪里结束、下一个词从哪里开始的原因之一。一个把每个词都分开说的学习者——常常在每个元音前喉咙里轻轻卡一下——即使每个音都发得对，听起来也一顿一顿的、很慢。本章讲解 GB 和 GA 中连读的主要类型：辅音连元音，元音连元音时加滑音 /j/ 或 /w/，连接 /r/ 和插入 /r/，以及两个辅音的连接。本章以[[connected-speech/rhythm]]的节奏和[[connected-speech/weak-forms]]的弱读式为基础，弱读式几乎总是和周围的词连在一起。

## 辅音连元音

::: definition 连读 {#def-linking}
**连读**（linking）是把一个词的最后一个音和下一个词的第一个音平滑地连接起来，中间没有停顿，也没有喉塞音。它发生在一个调群（[[connected-speech/sentence-stress#def-nucleus]]）之内，而不跨越真正的停顿。
:::

::: theorem 辅音 + 元音 {#rule-cv}
一个词以辅音结尾、下一个词以元音开头时，这个辅音与元音连在一起，就像它是下一个音节的开头一样：

- *pick it up*（把它捡起来）/ˈpɪk ɪt ˈʌp/ → [ˈpɪ kɪ ˈtʌp]
- *an apple*（一个苹果）/ən ˈæpl/ → [ə ˈnæpl]
- *turn off*（关掉）→ [tɜː ˈnɒf]（GB）
- *look at it*（看看它）→ [ˈlʊ kə tɪt]
- *first of all*（首先）→ [ˈfɜː stə ˈvɔːl]（GB）
- *Is it ready?*（准备好了吗？）→ [ɪ zɪt ˈredi]

在 GA 中，位于词尾、处在两个元音之间的 /t/ 通常是一个快速的闪音 [ɾ]，像一个短促的 *d*：*get up*（起床）[ɡe ˈɾʌp]，*a lot of*（很多）[ə ˈlɑː ɾəv]，*what about*（……怎么样）[ˈwʌ ɾə ˈbaʊt]，*put it on*（把它穿上）[ˈpʊ ɾɪ ˈɾɑːn]。
:::

::: proof
英语音节倾向于以辅音开头，所以元音前的词尾辅音自然地被拉进下一个音节。不过这种连接并不彻底：说英语的人仍然保留了词界的一些痕迹。比较 *a name*（一个名字）和 *an aim*（一个目标），或 *I scream*（我尖叫）和 *ice cream*（冰淇淋）。在 *ice cream* 里，/k/ 位于重读音节开头，带一股气流（送气，[kʰ]），而在 *I scream* 里，/k/ 在 /s/ 之后，不送气；而且 /aɪ/ 在 *ice* 里较短，因为它后面是同一个词中的清辅音 /s/（[[sounds-of-english/long-vowels-diphthongs#rule-clipping]]）。这些细小的差别从20世纪50年代起就有人研究，它们能帮助听话人——但在快速口语中它们常常小到听不出来，这时就靠上下文来判断。GA 的闪音遵循的规律，和 *water*、*city* 中产生闪音的规律相同（[[sounds-of-english/phonemic-alphabet#rule-rhotic]]）：/t/ 处在两个元音之间，而不在重读音节的开头。
:::

::: example 标出辅音与元音的连读 {#ex-cv}
用 ‿ 标出每一处辅音与元音的连读，并说明这个短语听起来是什么样的。

1. *Come in and sit down.*（进来坐吧。）
2. *I've got an idea.*（我有个主意。）
3. *Not at all.*（一点也不。）
::: solution
1. *Come‿in‿and sit down.*——[kʌ mɪ nən ˈsɪt ˈdaʊn]。*And* 弱读为 /ən/，*in* 的 /n/ 连到它上面。*Sit down* 没有这种连读：/t/ + /d/ 都是辅音（见下文“两个辅音”）。
2. *I've got‿an‿idea.*——GB [aɪv ˈɡɒ tə naɪ ˈdɪə]；GA [aɪv ˈɡɑː ɾə naɪ ˈdiːə]。*I've* 和 *got* 之间没有连读：/v/ + /ɡ/ 都是辅音。
3. *Not‿at‿all.*——GB [ˈnɒ tə ˈtɔːl]；GA [ˈnɑː ɾə ˈɾɑːl] 或 [ˈnɑː ɾə ˈɾɔːl]，有两个闪音。在 GB 中，许多人在随意的口语里把第一个 /t/ 说成喉塞音，但第二个 /t/ 在重读的 *all* 开头，是连读的：[ˈnɒʔ ə ˈtɔːl]。

检查每一个词界：辅音与元音的连读需要**前面**是辅音，**后面**是元音。
:::
:::

## 元音连元音

一个词以元音结尾、下一个词以元音开头时，英语不让两个元音之间出现空隙或喉塞音。它用一个短的滑音把空隙填上。

::: theorem 元音 + 元音 {#rule-vv}
1. 在以高、前位置结束的元音——/iː/、/i/、/ɪ/（包括 /eɪ/、/aɪ/、/ɔɪ/ 中的 /ɪ/）——之后，出现一个短的 **/j/** 滑音：*see it*（看见它）[ˈsiː ʲɪt]，*the end*（结尾）[ði ʲˈend]，*I agree*（我同意）[aɪ ʲəˈɡriː]，*say again*（再说一遍）[ˈseɪ ʲəˈɡen]，*enjoy it*（喜欢它）[ɪnˈdʒɔɪ ʲɪt]。
2. 在以高、后、圆唇位置结束的元音——/uː/、/u/、/ʊ/（包括 /əʊ/（GB）、/oʊ/（GA）、/aʊ/ 中的 /ʊ/）——之后，出现一个短的 **/w/** 滑音：*do it*（做吧）[ˈduː ʷɪt]，*go out*（出去）[ˈɡəʊ ʷˈaʊt]（GB），*how old*（多大）[ˈhaʊ ʷˈəʊld]（GB），*two eggs*（两个鸡蛋）[ˈtuː ʷˈeɡz]，*you are*（你是）[ju ʷə]。
3. 在其他元音——/ə/、/ɑː/、/ɔː/、/ɜː/、/ɪə/、/eə/——之后，GB 用 **/r/**（[[#rule-r]]）。GA 本来就把每个书面上的 *r* 都读出来，所以在拼写中没有 *r* 的地方，它只是把两个元音直接连起来：*the idea of it*（那个主意）[ði aɪˈdiːə əv ɪt]。
:::

::: proof
滑音并不是说话人额外加上的音位；它们是从一个元音位置移到另一个元音位置、中间不停止发声的自然结果。在 /iː/ 或 /aɪ/ 的末尾，舌头高而靠前，这正是 /j/ 的位置；在 /uː/ 或 /aʊ/ 的末尾，舌头高而靠后，嘴唇是圆的，这正是 /w/ 的位置。嗓音移向下一个元音时，就会经过这些位置。所以语音学家常常把滑音写得小一些，[ʲ] 和 [ʷ]，或者放在括号里。/j/ 滑音和 /w/ 滑音在 GB 和 GA 中是一样的。罗奇（Roach 2009）和克鲁滕登（Cruttenden 2014）都描写了它们；克鲁滕登指出，它们比完整的辅音 /j/ 和 /w/ 弱，所以 *I earn*（我挣）和 *I yearn*（我渴望）仍然不同。
:::

::: quiz
在 *Do you know Anna?*（你认识安娜吗？）中，*know* 和 *Anna* 之间用哪个滑音连接？
- [ ] /j/
- [x] /w/
- [ ] 只在 GB 中用 /r/
- [ ] 没有滑音：用喉塞音
::: solution
*Know* 以 /əʊ/（GB）或 /oʊ/（GA）结尾，它的最后部分是高、后、圆唇的，所以形成 /w/ 滑音：[ˈnəʊ ʷˈænə]。用喉塞音会让两个词听起来是分开的，而且带强调意味。
:::
:::

## 连接 /r/ 和插入 /r/

GB 是非 r 音化口音：元音后书面上的 *r* 在辅音或停顿前不发音（[[sounds-of-english/nasals-approximants#rule-r]]）。但当下一个词以元音开头时，/r/ 又回来了。

::: theorem GB 中的连接 /r/ 和插入 /r/ {#rule-r}
1. **连接 /r/**（linking r）。拼写以 *r* 或 *re* 结尾的词，在下一个词以元音开头时带 /r/ 读出：*far*（远）读 /fɑː/，但 *far away*（很远）读 /ˌfɑːr əˈweɪ/；*more often*（更经常）/ˈmɔːr ˈɒfn/；*here it is*（就在这儿）/ˈhɪər ɪt ɪz/；*after all*（毕竟）/ˌɑːftər ˈɔːl/；*for example*（例如）/fər ɪɡˈzɑːmpl/。
2. **插入 /r/**（intrusive r）。许多说 GB 的人还会在拼写中没有 *r* 的两个元音之间加一个 /r/，出现在 /ə/、/ɑː/、/ɔː/ 和 /ɪə/ 之后：*the idea of it* /ði aɪˈdɪər əv ɪt/；*law and order*（法律和秩序）/ˌlɔːr ən ˈɔːdə/；*China and Japan*（中国和日本）/ˈtʃaɪnər ən dʒəˈpæn/；*Africa and Asia*（非洲和亚洲）。它也出现在词内部：*drawing*（图画）[ˈdrɔːrɪŋ]。
3. **GA** 在拼写中有 *r* 的地方都读 /r/，所以连接 /r/ 就是它普通的 /r/。插入 /r/ 不是 GA 的特征。
:::

::: proof
连接 /r/ 和插入 /r/ 来自 GB 的历史。18世纪，英格兰东南部元音后的 /r/ 脱落了，但在后面跟着元音的地方保留了下来，于是出现了 *far* /fɑː/ 和 *far away* /fɑːr əˈweɪ/ 这样的对子。说话人逐渐把 /r/ 当作在某些元音之间出现的音，并把它扩展到本来没有 *r* 的词上：*idea of* 现在的表现和 *ear of* 完全一样。插入 /r/ 长期以来被批评为“不正确”，尤其是在书面上把它拼出来的时候，但大多数说 GB 的人在流利的口语中都使用它，包括许多自以为不用它的人（Wells 2008，见 LPD；Cruttenden 2014）。以 GB 为模式的学习者应该使用连接 /r/；插入 /r/ 是可选的——你需要认得出它，但你也可以用滑音或不加滑音来连接。
:::

::: example 连接还是插入？ {#ex-r}
在 GB 中，下面哪些短语有连接 /r/，哪些有插入 /r/，哪些都没有？在 GA 中又怎样？

1. *Where is it?*（它在哪儿？）2. *Where did it go?*（它跑哪儿去了？）3. *Asia and Europe*（亚洲和欧洲）4. *saw it*（看见了它）5. *a pair of shoes*（一双鞋）6. *a sofa bed*（一张沙发床）
::: solution
1. **连接 /r/**：*where* 拼写中有 *r*，而 *is* 以元音开头：/ˈweər ɪz ɪt/。GA：/ˈwer ɪz ɪt/，是它普通的 /r/。
2. **没有**：*did* 以辅音开头：/ˈweə dɪd ɪt ˈɡəʊ/。GA：/ˈwer/。
3. **插入 /r/**（对许多人来说）：*Asia* 里没有 *r*，但是 /ə/ + 元音：/ˈeɪʒər ən ˈjʊərəp/。GA：/ˈeɪʒə ən ˈjʊrəp/，没有 /r/。
4. **插入 /r/**（对许多人来说）：/ˈsɔːr ɪt/。GA：/ˈsɑː ɪt/ 或 /ˈsɔː ɪt/，没有 /r/。
5. **连接 /r/**：/ə ˈpeər əv ˈʃuːz/。GA：/ə ˈper əv ˈʃuːz/。
6. **没有**：*bed* 以辅音开头：/ə ˈsəʊfə bed/。
:::
:::

::: warning 不要用喉塞音把词隔开
✗ *pick* [ʔ] *it* [ʔ] *up*——✗ *I* [ʔ] *am* [ʔ] *an* [ʔ] *engineer*——在每个元音前喉咙里轻轻卡一下。
✓ *pick‿it‿up* [ˈpɪ kɪ ˈtʌp]——✓ *I‿am‿an‿engineer*（我是工程师）[aɪ ʲəm ə ˌnendʒɪˈnɪə]（GB）。

喉塞音 [ʔ] 是声带的短暂闭合。说英语的人确实会在元音前用它——但主要是为了强调（*It's [ʔ]↘**aw**ful!*，太糟了！）或在停顿之后。在每个以元音开头的词前面都用它，会让话语听起来生硬、过分小心，还会掩盖弱读式，而弱读式需要依靠周围的词。
:::

## 两个辅音

连读也影响在词界相遇的两个辅音。

::: theorem 辅音 + 辅音 {#rule-cc}
1. **两个相同的辅音**只说一次，稍微延长——而不是中间断开说两次：*bus stop*（公共汽车站）[ˈbʌsːtɒp]，*this side*（这一边），*big game*（大型比赛），*black cat*（黑猫），*good day*（美好的一天），*some more*（再来一些）。对 /p t k b d ɡ/ 来说，是一次闭塞，保持得长一些，一次除阻。
2. **两个不同的爆破音**（*hot dog*，*good boy*，*that place*，*big cat*）：第一个爆破音通常**不除阻**——舌头或嘴唇形成闭塞，但要到第二个爆破音时才把气放出来：*hot dog*（热狗）[ˈhɒt̚ dɒɡ]（GB）。
3. 辅音之间**不加元音**：*bus stop*，不是 ✗ [ˈbʌsə ˈstɒpə]；*good boy*（好孩子），不是 ✗ [ˈɡʊdə ˈbɔɪ]。
:::

::: proof
这些规则来自让嗓音和口腔保持连续运动：如果每个爆破音都除阻，然后重新开始下一个，那么每个词界都会出现一个小小的间断。第2条和词内部的情况一样：在 *doctor*（医生）和 *actor*（演员）里，/k/ 在 /t/ 之前也不除阻。一个除了阻的爆破音，后面带一点气流或一个元音，是学习者英语中多余音节最常见的来源之一（[[sounds-of-english/syllables-clusters#rule-practice]]）。下一章的省音和同化，描写的是词界上的辅音发生改变或脱落的情况。
:::

::: example 词在哪里分开？ {#ex-boundary}
下面每一对在连贯语流中听起来都非常相似。说明有什么（如果有的话）能帮助听话人听出区别，以及在什么也帮不上的时候，上下文怎样起决定作用。

1. *ice cream*（冰淇淋）——*I scream*（我尖叫）
2. *a name*（一个名字）——*an aim*（一个目标）
3. *grey tape*（灰色胶带）——*great ape*（大猩猩等类人猿）
::: solution
1. 在 *ice cream* 中，/k/ 位于重读音节 *cream* 的开头，所以送气 [kʰ]；在 *I scream* 中，它在 *scream* 内部跟在 /s/ 后面，不送气。/aɪ/ 在 *ice* 里（在同一音节的 /s/ 之前）也比在 *I* 里短。这些线索是真实的，但很细小。
2. 几乎没有区别：两者都是 [ə ˈneɪm]。有些人想说清楚时，会在 *an aim* 里把 /n/ 稍微拉长，或加一个喉塞音。实际上靠上下文决定（*What's your name?* ——*a name*；*Our aim is …* ——*an aim*）。
3. 在 *great ape* 中，/t/ 是 *great* 的结尾；在 GB 中它可能变成喉塞音或除阻很弱，*great* 的 /eɪ/ 也较短（在清辅音 /t/ 之前）。在 *grey tape* 中，/t/ 位于重读的 *tape* 开头，送气 [tʰ]。在 GA 中，*great ape* 可能带闪音 [ˈɡreɪ ɾeɪp]，而 *grey tape* 从不这样——这是一个更清楚的线索。

说英语的人通常不知不觉地就解决了这类歧义，因为在上下文中只有一种理解说得通。对学习者来说，要记住的是：听到一串音时，试试不止一种划分方法（[[connected-speech/hearing-fast-speech]]）。
:::
:::

::: example 一段连读的对话 {#ex-dialogue}
标出这段对话中的连读（‿），并注明每一处的类型（辅音—元音、/j/、/w/、/r/）。用 GB。

**Liu Yang:** *Are you OK? You look a bit upset.*（你没事吧？你看起来有点不高兴。）
**Sam:** *I'm all right. I just lost my umbrella on the way in.*（我没事。我只是进来的路上把伞弄丢了。）
::: solution
**Liu Yang:** *Are you‿OK? You look‿a bit‿upset.*
- *Are you*：没有连读——在 GB 中，弱读的 *are* /ə/ 中的 *r* 在辅音 /j/ 前不发音。*you‿OK*：/u/ + /əʊ/ → /w/ 滑音 [ju ʷəʊˈkeɪ]。
- *look‿a*：辅音—元音 [ˈlʊ kə]；*bit‿upset*：辅音—元音 [bɪ tʌpˈset]（在 GB 随意的口语中，/t/ 常常说成喉塞音，[bɪʔ ʌpˈset]）。

**Sam:** *I'm‿all right. I just lost my‿umbrella‿on the way‿in.*
- *I'm‿all*：辅音—元音 [aɪ ˈmɔːl]。
- *my‿umbrella*：/aɪ/ + /ʌ/ → /j/ 滑音 [maɪ ʲʌmˈbrelə]。
- *umbrella‿on*：/ə/ + /ɒ/ → 对许多说 GB 的人来说是插入 /r/ [ʌmˈbrelər ɒn]；不加滑音直接连接也可以。
- *way‿in*：/eɪ/ + /ɪ/ → /j/ 滑音 [ˈweɪ ʲɪn]。
- *just lost*：在随意的口语中，*just* 的 /t/ 在 /l/ 前通常脱落——这是省音（[[connected-speech/elision-assimilation]]）。
:::
:::

::: note 英汉对比
- **普通话把音节分开。** 在普通话里，即使辅音遇到元音，音节界限也保持不变：*Xī'ān* 西安是两个音节，*xi* + *an*，拼音中的隔音符号正是为了表明它不是 *xiān* 先。*Tiān'ānmén* 天安门也不说成 *tiā-nān-mén*。英语恰好相反：*an apple* 说成 *a-napple*。所以说普通话的人把词分开的本能，与英语的连读是相冲突的。
- **喉塞音。** 普通话中没有声母的音节（*ān* 安、*ài* 爱、*ō* 噢）常常以喉塞音或类似的喉部阻塞开始。学习者把这个习惯带进英语，在每个以元音开头的词前都加 [ʔ]（*pick [ʔ]it [ʔ]up*）。练习时把辅音移过去：先说 *pi-ki-tup*、*a-napple*、*tur-noff*，然后加快速度。
- **词尾辅音。** 普通话音节只以元音、*-n*、*-ng*（或 *-r*）结尾，所以英语的词尾爆破音是个难点（[[sounds-of-english/sounds-for-chinese-speakers#rule-finals]]）。连读在这里反而有帮助：元音前的词尾辅音移到下一个音节里，在那里更容易发出来。*Get‿up*（起床）比单说 *get* 更容易。
- **连接 /r/ 和普通话的儿化。** 普通话的儿化韵尾（*nǎr* 哪儿 中的 *-r*）和英语的连接 /r/ 不一样，但习惯儿化的学习者熟悉音节末尾的卷舌色彩，这对 GA 的词尾 /r/ 可能有帮助。
- **南方方言中 /n/ 和 /l/ 不分的人**，要注意连读中的 /n/：*in it* [ɪ nɪt] 不能变成 [ɪ lɪt]。
:::

::: history
对话语中词界如何标示的研究始于美国结构主义语言学家。特雷杰（George Trager）和史密斯（Henry Lee Smith）在《英语结构纲要》（*An Outline of English Structure*，1951）中提出了一个“加号音渡”音位，用来标示 *a name* 和 *an aim* 这类对子中的词界。莱希斯特（Ilse Lehiste，1960）对这类对子作了声学测量，表明词界并不是由一个特殊的音来标示的，而是由它周围的音位变体的细小差别来标示的——送气、长度、喉化。在英国语音学中，琼斯（Daniel Jones）和吉姆森（A. C. Gimson）描写了连接 /r/ 和插入 /r/；吉姆森的《英语发音导论》（*Introduction to the Pronunciation of English*，1962）及其后来的各版，即现在的《吉姆森英语发音》（*Gimson's Pronunciation of English*，Cruttenden 2014），把插入 /r/ 看作这种口音的正常特征，而不是错误。
:::

## 后续内容

连读把音连起来；[[connected-speech/elision-assimilation]]描写词界上的音怎样脱落和改变。把连读的词听成分开的词的练习，见[[connected-speech/hearing-fast-speech]]。连读也是[[listening-and-conversation/how-listening-works]]中日常流利度的一部分，以及[[listening-and-conversation/accents]]中口音差异的一部分。

::: summary
- **连读**把一个词的最后一个音和下一个词的第一个音连起来，中间没有停顿或喉塞音（[[#def-linking]]）。
- 元音前的词尾辅音移到元音上：*pick‿it‿up* [ˈpɪ kɪ ˈtʌp]；在 GA 中，两个元音之间的 /t/ 变成闪音：*get‿up* [ɡe ˈɾʌp]（[[#rule-cv]]）。
- 元音之间，/iː/ 和以 /ɪ/ 结尾的双元音后面加 /j/ 滑音；/uː/ 和以 /ʊ/ 结尾的双元音后面加 /w/ 滑音（[[#rule-vv]]）。
- GB 在拼写有 *r* 的地方用**连接 /r/**（*far away*），许多人在没有 *r* 的地方用**插入 /r/**（*law and order*）；GA 没有这种单独的过程（[[#rule-r]]）。
- 两个相同的辅音只说一次，延长一些；两个爆破音中的第一个通常不除阻；不加元音（[[#rule-cc]]）。
- 在以元音开头的词前加喉塞音会让话语一顿一顿的；只在强调时使用。
- 普通话把音节分开（*Xī'ān*）；英语把它们连起来（*a‿napple*）。
:::

## 习题

::: exercise 标出连读 {level=1}
用 ‿ 标出辅音与元音的连读。

1. *Turn it off.*（把它关掉。）2. *Can I have a look at it?*（我能看一下吗？）3. *She lives in an old house.*（她住在一座老房子里。）
::: solution
1. *Turn‿it‿off.* 2. *Can‿I have‿a look‿at‿it?*（*I have*：/aɪ/ + /h/——没有连读，除非在快速口语中 *have* 丢掉了 /h/：*Can‿I‿(h)ave*。）3. *She lives‿in‿an‿old house.*
:::
:::

::: exercise /j/ 还是 /w/？ {level=1}
两个词之间用哪个滑音连接：/j/ 还是 /w/？

1. *see us*（看见我们）2. *go away*（走开）3. *my office*（我的办公室）4. *new idea*（新主意）5. *how is it*（怎么样）6. *play outside*（在外面玩）
::: solution
1. /j/ 2. /w/ 3. /j/ 4. /w/（*new* 以 /uː/ 结尾） 5. /w/ 6. /j/
:::
:::

::: exercise /r/ 在哪里？ {level=1}
在 GB 中，哪些短语有连接 /r/？

*car park*（停车场），*car alarm*（汽车警报器），*here and there*（到处），*here we are*（我们到了），*four eggs*（四个鸡蛋），*four boys*（四个男孩）
::: solution
*car alarm* /kɑːr əˈlɑːm/，*here and there* /ˈhɪər ən ˈðeə/，*four eggs* /ˈfɔːr ˈeɡz/。没有 /r/ 的：*car park*，*here we are*（在 *we* 之前和句末），*four boys*。在 GA 中，它们都有 /r/，因为 GA 把每个书面上的 *r* 都读出来。
:::
:::

::: exercise 有几处连读？ {level=2 check="3"}
在 *Put it on a plate*（把它放在盘子里）中（GB，正常语速），有几处辅音与元音的连读（C‿V）？
::: solution
*Put‿it‿on‿a plate*：*put‿it*（/t/ + /ɪ/），*it‿on*（/t/ + /ɒ/），*on‿a*（/n/ + /ə/）。*a* 和 *plate* 之间是元音遇到辅音，所以没有这种连读。答案是3。
:::
:::

::: exercise GB 还是 GA？ {level=2}
用 GB 和 GA 写出音标，标出连读：*Better ask her about it.*（最好问问她这件事。）
::: solution
GB：/ˈbetər ˈɑːsk ər əˈbaʊt ɪt/——*better‿ask* 和 *her‿about* 中有连接 /r/；*about‿it* 是辅音—元音连读。GA：[ˈbeɾər ˈæsk ər əˈbaʊ ɾɪt]——/r/ 是 GA 普通的 /r/；*better* 的 /t/ 和 *about* 在 *it* 前的词尾 /t/ 都是闪音。
:::
:::

::: exercise 连接辅音 {level=2}
说明词界上的辅音是怎样连接的。

1. *bus stop*（公共汽车站）2. *good dog*（好狗）3. *black coffee*（黑咖啡）4. *hot day*（炎热的一天）5. *some money*（一些钱）
::: solution
1. 两个相同的 /s/：一个长的 [sː]。2. 两个相同的 /d/：一次闭塞，保持得长一些，一次除阻。3. 两个相同的 /k/：一个长的闭塞。4. /t/ + /d/：/t/ 不除阻（或在 GB 中是喉塞音）；中间没有元音。5. 两个相同的 /m/：一个长的 [mː]。
:::
:::

::: exercise 改正朗读 {level=3}
一位学习者把 *I asked if I could eat it after all*（我问过我到底能不能吃）读成 *I* [ʔ] *ask-uh* · *if* [ʔ] *I* · *could-uh* [ʔ] *eat* [ʔ] *it* · *after* [ʔ] *all*。列出问题，并写出说 GB 的人会用的连读。
::: hint
看每一个词界：每个词的最后一个音是什么，下一个词的第一个音是什么？
:::
::: solution
问题：在以元音开头的词 *asked*、*if*、*eat*、*it*、*all* 前加了喉塞音；*ask* 和 *could* 后面加了元音，造出了多余的音节；*asked* 表示过去时的 /t/ 丢了。

范例（GB）：*I‿asked‿if‿I could‿eat‿it‿after‿all.*——[aɪ ʲˈɑːsk tɪ faɪ kʊ ˈdiː tɪ ˈtɑːftə ˈrɔːl]：*I* 后面是 /j/ 滑音；*asked‿if*（/t/ 移过去）、*if‿I*、*could‿eat*、*eat‿it*、*it‿after* 是辅音—元音连读；*after‿all* 中是连接 /r/。*Could* 常常弱读为 /kəd/：[kə ˈdiːt]。
:::
:::

::: exercise 给一段短文连读 {level=3}
写三四句话讲讲你的早晨（例如你吃了什么，怎样去上学或上班）。标出所有的连读（辅音—元音、/j/、/w/、GB 的 /r/），然后把这段话大声读两遍——一遍慢读，一遍用正常语速——每一处连读都要保持。
::: solution
答案因人而异。一个范例：*I got‿up‿at seven‿and had‿an‿egg‿and some toast. Then I walked to the station‿in the rain‿and caught‿a train‿at‿eight.*（我七点起床，吃了一个鸡蛋和一些吐司。然后我冒着雨走到车站，赶上了八点的火车。）连读：辅音—元音连读有 *got‿up*、*up‿at*、*seven‿and*、*had‿an*、*an‿egg*、*egg‿and*、*station‿in*、*rain‿and*、*caught‿a*、*train‿at*、*at‿eight*。好的答案会找出每一个辅音遇到元音的词界，朗读时在这些地方不加喉塞音。
:::
:::
