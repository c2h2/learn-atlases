在词典里查 *Japanese*（日本的；日语），你会看到 /ˌdʒæpəˈniːz/：主重音在最后一个音节 *-nese* 上。现在听别人说 *a Japanese car*（一辆日本车）或 *Japanese food*（日本菜）。强拍常常移到了前面：**JA**panese **FOOD**。*thirteen*（十三）也是这样：*She's thir**TEEN***（她十三岁），但 ***THIR**teen **PEO**ple*（十三个人）。说话人说错了吗？没有。英语的重音不是像标签一样固定贴在词上的：它属于一个词，但也会随着周围的词而调整。

[[sounds-of-english/word-stress-basics]]讲了什么是重音，并给出了双音节词的主要规律、固定重音的后缀（*-ion*、*-ic*、*-ity*）以及不移动重音的后缀（*-ness*、*-ment*、*-ful*）。本章更进一步。它讨论较长的词，从词尾往前数的词尾，前缀，打破“重读第一部分”规律的复合词，短语动词以及由它们构成的名词，还有**重音转移**——也就是 *Japanese food* 中的那种移动。这些规律是从词通往句子的桥梁：从下一章起，重音将属于整个短语。

## 重音级别与重音模式

一个长词并不只是“一个重读音节，其余都不重读”。区分三个级别是有用的。

::: definition 重音级别 {#def-levels}
在一个多音节词中，我们区分：

1. **主重音**（primary stress）——最强的音节，在标音中用 ˈ 标出：*education*（教育）/ˌedʒuˈkeɪʃn/ 中的 *-ca-*；
2. **次重音**（secondary stress）——一个带完整元音、有一定突出度的音节，在词中位于主重音之前，用 ˌ 标出：*education* 中的 *ed-*；
3. **非重读**音节——不加标记。大多数是弱元音（/ə/、/i/、/u/、/ɪ/）或成音节辅音，如 *education* 中的 *-tion*；少数保留完整元音，如 *photograph*（照片）/ˈfəʊtəɡrɑːf/（GB）的最后一个音节。

在正文中，我们用圆圈表示重音模式：O 表示主重音，o 表示其他每个音节。*Education* 是 ooOo；*photograph* 是 Ooo；*thirteen* 是 oO。
:::

次重音几乎总是出现在主重音**之前**。在主重音之后，英语的音节通常不重读，即使它们的元音是完整的。这一点对下文的重音转移很重要：像 *Japanese* 这样的词有一个次重音*随时*可以接替主重音（*ˌJapaˈnese*），而像 *Chinese*（中国的；汉语）这样的词在主重音之前有一个完整元音，/ˌtʃaɪˈniːz/，也可以这样做。

::: theorem 从词尾数起的词尾 {#rule-ending}
有几种常见的词尾把主重音放在离词尾固定距离的位置上。

1. **-ate**，用于三个或更多音节的词：重音在倒数第三个音节——**CON**centrate（集中）/ˈkɒnsəntreɪt/（GB），**ED**ucate（教育），com**MU**nicate（交流）/kəˈmjuːnɪkeɪt/，in**VES**tigate（调查），ap**PRE**ciate（欣赏；感激）/əˈpriːʃieɪt/。
2. **-ise / -ize**（GB 两种拼写都用，GA 用 *-ize*）：通常也一样——**OR**ganise（组织），**RE**cognise（认出），**CRI**ticise（批评），a**PO**logise（道歉）/əˈpɒlədʒaɪz/（GB），/əˈpɑːlədʒaɪz/（GA）。
3. **-ify**：重音在紧挨着 *-ify* 的前一个音节——i**DEN**tify（识别）/aɪˈdentɪfaɪ/，**CLAS**sify（分类），**JUS**tify（证明……有理）。
4. **-ography、-ology、-onomy、-osophy、-ometer**：重音在词尾前面那个 *o* 上——ge**OG**raphy（地理）/dʒiˈɒɡrəfi/（GB），bi**OL**ogy（生物学），as**TRON**omy（天文学），phi**LOS**ophy（哲学），ther**MOM**eter（温度计）。再加上 *-ical*，重音又会移动：bio**LO**gical（生物的）/ˌbaɪəˈlɒdʒɪkl/（GB）。
:::

::: proof
这些词尾来自拉丁语和希腊语，它们的表现与[[sounds-of-english/word-stress-basics#rule-suffix]]中固定重音的后缀相同：重音是从词尾往前数音节来决定的，而不是从词首往后数。这就是为什么再加一个后缀时重音会移动（*biology* → *biological*）。这些规则是倾向，有例外。例如，双音节的 *-ate* 动词不在第1条的范围内，而且在这里 GB 和 GA 常常不同：*donate*（捐赠）在 GB 里读 /dəʊˈneɪt/，在 GA 里通常读 /ˈdoʊneɪt/；*rotate*（旋转）和 *frustrate*（使沮丧）也一样（GB 重读 *-ate*，GA 重读第一个音节），而 *create*（创造）/kriˈeɪt/ 在两种口音里都重读 *-ate*。当词典和规则不一致时，以词典为准。
:::

::: warning 不要重读词尾
✗ communi**CATE**，✗ organ**ISE**，✗ identi**FY**，✗ geo**GRA**phy。
✓ com**MU**nicate，**OR**ganise，i**DEN**tify，ge**OG**raphy。

词尾 *-ate*、*-ise* 和 *-ify* 比较长，含有双元音（/eɪt/、/aɪz/、/aɪ/），所以听起来很“强”，学习者常常把主重音放在它们上面。它们确实保留完整的元音，但不是重读音节：节拍出现在词中更靠前的地方。
:::

### GB 和 GA：*-ary*、*-ory*、*-ery*

有一组词尾在两种参考口音里听起来很不一样。在重读音节之后，GB 把 *-ary*、*-ory* 和 *-ery* 弱化为弱元音，而且常常完全丢掉其中一个；GA 在那里保留一个完整元音，并带次重音。

| 词 | GB | GA |
|---|---|---|
| *dictionary*（词典） | /ˈdɪkʃənri/（也读 /ˈdɪkʃənəri/） | /ˈdɪkʃəˌneri/ |
| *secretary*（秘书） | /ˈsekrətri/ | /ˈsekrəˌteri/ |
| *territory*（领土） | /ˈterətri/ | /ˈterəˌtɔːri/ |
| *necessary*（必要的） | /ˈnesəsəri/ | /ˈnesəˌseri/ |

主重音在两种口音里的位置相同；不同的是它之后的节奏。GB 的 *dictionary* 有三个音节，在重音之后很快地说完（Ooo）；GA 的 *dictionary* 有四个音节，在 *-nar-* 上还有第二个拍子（Ooo 加一个小峰，写作 ˈ…ˌ）。两者都不是错误。选定一种模式并保持一致，同时要准备好听到两种读法。

::: quiz
*investigate*（调查）的主重音在哪里？
- [ ] *IN*-ves-ti-gate
- [x] in-*VES*-ti-gate
- [ ] in-ves-*TI*-gate
- [ ] in-ves-ti-*GATE*
::: solution
*-ate* 用于三个或更多音节的词时，重音在倒数第三个音节（[[#rule-ending]]）：往回数 *gate*（1）、*ti*（2）、*ves*（3）。这个词读 in**VES**tigate /ɪnˈvestɪɡeɪt/。词尾 *-gate* 保留完整元音 /eɪ/，但不重读。
:::
:::

## 前缀

*un-*、*in-*、*dis-*、*mis-*、*re-* 这样的前缀通常**不是**词的主重音：词根保留它自己的重音。

- **HAP**py（快乐的）→ un**HAP**py（不快乐的）/ʌnˈhæpi/；**POS**sible（可能的）→ im**POS**sible（不可能的）；a**GREE**（同意）→ disa**GREE**（不同意）/ˌdɪsəˈɡriː/；under**STAND**（理解）→ misunder**STAND**（误解）。

有两个细节值得了解。

1. 前缀常常保留**完整元音**和一个次重音：*unhappy* 里是 /ʌ/，不是 /ə/；*disagree* 里是带次重音的 /ɪ/。
2. *re-* 有两种读法。在“再一次”的意思已经淡化的旧词里，它是弱读的：*recover*（康复）/rɪˈkʌvə/（GB），*remark*（评论），*repeat*（重复）。当它明确表示“再一次”时，它读完整的 /riː/，带次重音：*re-cover*（重新覆盖）/ˌriːˈkʌvə/（GB），*rewrite*（重写），*reopen*（重新开放）。两个 *recover* 就靠这个元音来区分。

当两个带前缀的词形成**对比**时，前缀承担重音：*Did you say **EN**courage or **DIS**courage?*（你说的是“鼓励”还是“劝阻”？）——*I said **UN**happy, not **HAP**py.*（我说的是“不快乐”，不是“快乐”。）这是对比重音，它属于句子，而不属于词：见[[connected-speech/sentence-stress]]。

## 复合词：什么时候重读第二部分

复合名词通常的规律是重读第一部分：*a **BUS** stop*（公共汽车站），*a **BOOK**shop*（书店），*a **GREEN**house*（温室）（[[sounds-of-english/word-stress-basics]]）。但有一大类复合词，以及某些复合形容词和复合动词，重读第二部分。LPD 等词典和主要的学习型词典都标出复合词的重音，值得查一查；下面的规则涵盖主要的几类。

::: theorem 重读第二部分的复合词 {#rule-compound}
下列几类中，主重音通常落在第二部分（第一部分保留次重音）：

1. **道路和地点的名称**，以 *Street* 结尾的除外：*Oxford **ROAD***（牛津路），*Fifth **AV**enue*（第五大道），*Trafalgar **SQUARE***（特拉法尔加广场），*Kew **GAR**dens*（邱园）——但 ***OX**ford Street*（牛津街），***BAKER** Street*（贝克街）。
2. **由什么做成**，即第一部分是材料或配料：*apple **PIE***（苹果派），*paper **BAG***（纸袋），*stone **WALL***（石墙）。
3. **何时或何地**，即第一部分表示时间或地点：*Christmas **DAY***（圣诞节当天），*Christmas **EVE***（圣诞前夜），*town **HALL***（市政厅），*summer **HOL**iday*（暑假）。
4. **复合形容词**，尤其是以 *-ed* 或 *-ing* 结尾的，或以数字开头的：*bad-**TEM**pered*（脾气坏的），*open-**MIN**ded*（思想开放的），*good-**LOOK**ing*（好看的），*second-**CLASS***（二等的），*three-**WHEEL**er*（三轮车）。
5. **用作副词或动词的复合词**：*north-**EAST***（东北），*head-**FIRST***（头朝前地），*down**STAIRS***（在楼下）；*ill-**TREAT***（虐待），*down**GRADE***（降级）。

在第3类中比较 ***CHRIST**mas card*（圣诞贺卡），它遵循通常的重读第一部分的规律：贺卡并不是在同样意义上“在圣诞节”的东西，而语言也并不能解释每一个例子。
:::

::: proof
通常的第一部分重音表明复合词是一类事物的一个名称：*greenhouse*（温室）并不只是一座碰巧是绿色的房子。当第一部分只是描述第二部分——它是用什么做的，在何时或何地——复合词的表现就更像“形容词 + 名词”的短语，而短语是在末尾重读的（*a green **HOUSE***，一座绿色的房子）。这就是第2类和第3类背后的道理，它能解释许多例子。但这个体系是一个词一个词地形成的，所以不能完全预测：*apple **PIE***（苹果派）重读末尾，而同样以水果命名的 ***OR**ange juice*（橙汁）通常重读开头；*Street* 名重读第一部分，*Road* 名重读第二部分，说英语的人也说不出原因（罗奇（Roach 2009）和克鲁滕登（Cruttenden 2014）都列出了这类例子，并称之为不可预测）。遇到常见的就记下来。
:::

::: example 街、路还是广场？ {#ex-compound}
标出每个名称的主重音，并说明它属于[[#rule-compound]]的哪一类。

1. *Nanjing Road*（南京路） 2. *Wall Street*（华尔街） 3. *Tiananmen Square*（天安门广场） 4. *a paper cup*（一个纸杯） 5. *a Christmas tree*（一棵圣诞树） 6. *New Year's Day*（元旦）
::: solution
1. *Nanjing **ROAD***——第1类：*Road* 名，重读第二部分。
2. ***WALL** Street*——第1类中的例外：*Street* 名重读第一部分。
3. *Tiananmen **SQUARE***——又是第1类（*Square* 和 *Road*、*Avenue* 一样）。
4. *a paper **CUP***——第2类：第一部分表示材料。
5. *a **CHRIST**mas tree*——这个**不**属于第3类：它和 *Christmas card* 一样，遵循通常的第一部分重音。好的词典会标作 ˈ…。
6. *New Year's **DAY***——第3类：时间词 + *Day*，和 *Christmas Day* 一样。

第5项和第6项说明为什么这条规则只是指南，而不是定律：两者都以一个节日开头，但只有一个重读末尾。
:::
:::

::: quiz
哪个短语通常重读**第一**部分？
- [ ] *town hall*
- [ ] *apple pie*
- [x] *bus stop*
- [ ] *Oxford Road*
::: solution
*Bus stop*（公共汽车站）是普通的复合名词：***BUS** stop*。其他几个都属于[[#rule-compound]]中重读第二部分的类别：*town **HALL***（市政厅，地点），*apple **PIE***（苹果派，配料），*Oxford **ROAD***（牛津路，不以 *Street* 结尾的道路名）。
:::
:::

## 短语动词及由它们构成的名词

许多日常动词由一个动词加一个小品词构成：*set up*（建立；布置），*take off*（起飞），*break down*（出故障），*log in*（登录），*check in*（办理登记手续），*work out*（算出；锻炼）。其中许多都有一个由相同部分构成的名词。重音把它们区分开来。

::: theorem 短语动词及其名词 {#rule-phrasal}
1. 在**短语动词**中，**小品词**重读：*The plane took **OFF***（飞机起飞了）；*We set **UP** the room*（我们把房间布置好了）；*The car broke **DOWN***（汽车坏了）；*You need to log **IN***（你需要登录）。如果后面跟一个宾语名词，这个名词通常承担短语的主要重音，但小品词仍然是带完整元音的强音节：*set **UP** a **COM**pany*（成立一家公司）。
2. 在由它构成的**名词**（或形容词）中，**动词**部分重读：*a smooth **TAKE**off*（一次平稳的起飞），*a new **SET**up*（一套新的布置），*a **BREAK**down*（一次故障），*your **LOG**in*（你的登录名），*the **CHECK**-in desk*（登记柜台），*a **WORK**out*（一次锻炼）。
3. 动词后面的介词（*look at*，*wait for*，*depend on*）则不同：它通常不重读，读弱读式。*I'm **LOOK**ing at it.*（我正在看它。）只有副词小品词才承担重音。
:::

::: proof
第2条又是复合词规则：名词 *setup* 是一个事物的一个名称，和 *bus stop* 一样重读第一部分。第1条来自句子重音：短语动词是“动词 + 副词”，而副词是实义词，要重读（[[connected-speech/sentence-stress]]）；在短语末尾，最后一个实义词最突出。介词是功能词，所以在第3条中是弱读的（[[connected-speech/weak-forms]]）。这种区别是听得出来的：*What are you **LOOK**ing at?*（你在看什么？——介词）对比 *Could you look **UP** this word?*（你能查一下这个词吗？——小品词）。
:::

::: example 动词还是名词？ {#ex-phrasal}
标出黑体词的重音，并说明每个是短语动词还是名词。

1. *There's been a **break-in** at the school.*（学校发生了一起入室盗窃。）
2. *Someone tried to **break in** last night.*（昨晚有人试图闯进来。）
3. *What time is **check-in**?*（几点办理登记？）
4. *We can **check in** online.*（我们可以在网上办理登记。）
5. *Let's **work out** the cost.*（我们来算一算费用。）
6. *I do a short **workout** every morning.*（我每天早上做一次简短的锻炼。）
::: solution
1. ***BREAK**-in*——名词（在 *a* 之后）：重读动词部分。
2. *break **IN***——短语动词：重读小品词。
3. ***CHECK**-in*——名词。
4. *check **IN***——短语动词。
5. *work **OUT** the **COST***——短语动词；短语的主要重音落在宾语 *cost* 上，但 *out* 仍然是强的，带完整元音 /aʊ/。
6. ***WORK**out*——名词。

拼写能提供一点帮助（名词常常加连字符或写成一个词），但在口语中，重音是唯一的线索。
:::
:::

## 重音转移

现在回到 *Japanese food*。*Japanese*、*thirteen*、*afternoon*（下午）、*Chinese*、*unknown*（不知名的）和 *bad-tempered* 这样的词有两个强音节：一个次重音后面跟着主重音（ooO，oO）。当这样的词出现在另一个强音节之前时，主重音常常移到前面那个音节上。

::: theorem 重音转移 {#rule-shift}
一个在主重音之前有次重音的词（模式为 ˌ…ˈ…），如果在同一短语中紧跟着一个重读音节，常常把它的主要重音移到前面的音节上：

- ˌthirˈteen → ***THIR**teen **PEO**ple*（十三个人）；ˌJapaˈnese → ***JA**panese **FOOD***（日本菜）；ˌafterˈnoon → ***AF**ternoon **TEA***（下午茶）；ˌbad-ˈtempered → *a **BAD**-tempered **TEA**cher*（一位脾气坏的老师）；ˌunˈknown → *an **UN**known **AR**tist*（一位不知名的艺术家）。

当这个词在短语末尾时（*She's thir**TEEN***，她十三岁；*It's Japa**NESE***，这是日本的），或者下一个音节不重读时（*thir**TEEN** a**GAIN***，又是十三），**不**发生转移。它是流利口语中常见的倾向，不是必须的。
:::

::: proof
英语倾向于避免两个强拍紧挨在一起（**重音冲突**，stress clash）。重音转移把它们分开：*thirteen people* 的强音节 *thir-* 和 *peo-* 被一个非重读音节隔开，形成强弱交替（O o O o）。利伯曼（Liberman）和普林斯（Prince）（1977）把这称为*节奏规则*（rhythm rule）。它只适用于本来就有一个靠前的强音节可以移过去的词：*Chinese* /ˌtʃaɪˈniːz/ 可以转移（***CHI**nese **FOOD***，中国菜），但 *Japan*（日本）/dʒəˈpæn/ 不行，因为它的第一个元音是弱的：我们说 *Ja**PAN**'s **EX**ports*（日本的出口），没有转移。英语的节奏在[[connected-speech/rhythm]]中讨论。
:::

::: example *Thirteen* 还是 *thirty*？ {#ex-shift}
一位店员说：*That's thirteen pounds.*（一共十三英镑。）顾客听成了 *thirty*（三十）。用[[#rule-shift]]解释为什么这个错误很容易发生，以及顾客可以改为注意听什么。
::: solution
1. 单说时，*thirteen* 是 oO（/ˌθɜːˈtiːn/，GB），*thirty* 是 Oo（/ˈθɜːti/，GB；/ˈθɜːrti/，GA），所以重音能把它们区分开。
2. 在重读音节 *pounds* 之前，*thirteen* 发生转移：***THIR**teen **POUNDS***——现在它和 ***THIR**ty **POUNDS*** 的模式相同了。重音不再起作用。
3. 仍然不同的是第二个音节：*-teen* 是长元音 /iː/，以 /n/ 结尾；*-ty* 是短的弱 /i/，没有 /n/。在 GA 里，*thirty* 的 *t* 常常是闪音，[ˈθɜːrɾi]，而 *thirteen* 里从不这样。

所以顾客应该注意听长的 /iːn/，而不是重音——或者干脆确认一下：*Sorry, one-three or three-oh?*（不好意思，是一三还是三零？）[[everyday-english/numbers-in-conversation]]里有更多关于说数字和确认数字的内容。
:::
:::

## 拼写相同，元音不同

[[sounds-of-english/word-stress-basics]]介绍了靠重音区分的名词—动词对（*a **RE**cord*，一项纪录；*to re**CORD***，录制）。另有一组词，两种用法的重音**相同**，但最后的元音不同。这些是以 *-ate* 结尾的词：动词读完整的 /eɪt/，名词或形容词读弱的 /ət/。

| 词 | 名词或形容词 | 动词 |
|---|---|---|
| *estimate* | /ˈestɪmət/ *a rough estimate*（粗略的估计） | /ˈestɪmeɪt/ *estimate the cost*（估算费用） |
| *separate* | /ˈseprət/ *separate rooms*（分开的房间） | /ˈsepəreɪt/ *separate the eggs*（把蛋分开） |
| *graduate* | /ˈɡrædʒuət/ *a university graduate*（一名大学毕业生） | /ˈɡrædʒueɪt/ *graduate next year*（明年毕业） |
| *approximate* | /əˈprɒksɪmət/（GB）*an approximate figure*（一个近似的数字） | /əˈprɒksɪmeɪt/（GB）*approximate the curve*（逼近这条曲线） |

重读音节是相同的，所以重音读对的学习者无论哪种用法都能被听懂；但在名词或形容词里用完整的 /eɪt/，听起来就像动词了。

::: example 一个移动着的词族 {#ex-family}
标出 *democrat*（民主主义者）、*democracy*（民主）、*democratic*（民主的）的主重音（以及次重音，如果有的话），并用本章和[[sounds-of-english/word-stress-basics]]的规则解释每一个。第一个音节的元音怎样变化？
::: solution
1. ***DEM**ocrat* /ˈdeməkræt/——随词记住；Ooo，最后一个音节是完整元音 /æ/。
2. *de**MOC**racy* /dɪˈmɒkrəsi/（GB），/dɪˈmɑːkrəsi/（GA）——*-acy* 和 *-ography* 一样，把重音放在它前面的音节上；oOoo。
3. *ˌdemo**CRAT**ic* /ˌdeməˈkrætɪk/——*-ic* 使紧挨着它的前一个音节重读（[[sounds-of-english/word-stress-basics#rule-suffix]]）；第一个音节有次重音；ooOo。

第一个元音在音节重读时是完整的 /e/（*democrat*，*democratic*），在重音移走了的 *democracy* 里是弱的 /ɪ/。因为 *democratic* 在 *dem-* 上有次重音，它在短语中可以转移：***DEM**ocratic **COUN**tries*（民主国家）（[[#rule-shift]]）。
:::
:::

下图展示另一个词族。每个箭头表示加上一个后缀或前缀；大写字母表示主重音的位置。

::: widget graph
nodes: NAtion@0,3; NAtional@0,2; natioNALity@-2,1; interNAtional@2,1; interNAtionalise@2,0; NAtionalise@-2,0

caption: *nation*（国家）词族。*-al*（*national*，国家的，/ˈnæʃnəl/）、前缀 *inter-* 和 *-ise* 都让主重音留在原处，不过 *-al* 把元音从 /eɪ/ 变成了 /æ/；*-ity*（*nationality*，国籍，/ˌnæʃəˈnæləti/）把重音拉到紧挨着它的前一个音节上。*International*（国际的）/ˌɪntəˈnæʃnəl/（GB）在 *in-* 上有次重音，所以在短语中可以转移：***IN**ternational **FLIGHTS***（国际航班）。词可以拖动；箭头表示“加上一个词缀”。
:::

::: quiz
在哪个短语中通常会发生重音转移？
- [ ] *She's from Japan.*
- [x] *an afternoon nap*
- [ ] *It's at three in the afternoon.*
- [ ] *Is he thirteen?*
::: solution
重音转移需要一个前面有次重音的词（*ˌafterˈnoon*），**而且**在同一短语中后面跟着一个重读音节（*nap*）：***AF**ternoon **NAP***（午睡）。在其他句子里，这个词在短语末尾（*afternoon*，*thirteen*），或者前面没有强音节（*Japan* /dʒəˈpæn/）：*She's from Japan.*（她来自日本。）*It's at three in the afternoon.*（是在下午三点。）*Is he thirteen?*（他十三岁吗？）
:::

::: note 英汉对比
- **普通话也用“轻”来区分词。** 在普通话里，*dōngxī*（东西，“东边和西边”）和 *dōngxi*（东西，“物品”），或 *dìdào*（地道，“地下通道”）和 *dìdao*（地道，“正宗的”）之间的区别，靠的是第二个音节：一个是完整的声调，另一个是又轻又短的轻声。英语的 *a **GREEN**house*（温室）和 *a green **HOUSE***（绿色的房子）的道理与此可以相比——区别在于哪一部分强。所以“轻重改变意义”这个概念对说普通话的人来说并不陌生；新的地方在于，在英语里它几乎适用于每一个复合词和短语。
- **短语动词的小品词。** 汉语有“动词 + 补语”的组合（*zhàn qǐlái* 站起来），其中的补语常常读得很轻；学习者可能把这个习惯带过来，把 *stand up*、*give up*、*log in* 的小品词读得很弱。在英语里，短语动词的小品词是强的：*give **UP***（放弃），*log **IN***（登录）。
- **长词尾。** 给每个音节都加上完整声调的学习者，往往把 *-ate*、*-ise*、*-ify* 这样的长词尾读成词中最强的部分。练习这些词时，要把清楚的节拍放在更前面：com**MU**nicate，**OR**ganise。
- **数字。** [[#ex-shift]]中 *-teen*/*-ty* 的问题，学习者和母语者都会遇到：这是英语本身的特点，不是学习者的错误。
:::

::: history
第一部为学习者系统研究英语重音的著作是金登（Roger Kingdon）的《英语重音基础》（*The Groundwork of English Stress*，1958），书中列出了数千个单词、后缀和复合词的重音。十年后，乔姆斯基（Chomsky）和哈勒（Morris Halle）的《英语音系》（*The Sound Pattern of English*，1968）试图用一小套规则推导出英语的词重音，像拉丁语重音规则那样从词尾往前数音节——这就是[[#rule-ending]]的基础。1977年，利伯曼（Mark Liberman）和普林斯（Alan Prince）提出，重音是相邻成分之间相对强弱的问题，可以画成树形图或格栅；他们对“节奏规则”的解释，把重音转移（[[#rule-shift]]）说明为避免强拍冲突。现代的发音词典，尤其是 LPD（1990；第3版2008），都标出复合词和短语的重音，并注明哪里可能发生重音转移。
:::

## 后续内容

重音现在从词走向句子：[[connected-speech/sentence-stress]]讲解句子中哪些词重读，以及主要重音（调核）落在哪里。非重读词的弱化在[[connected-speech/weak-forms]]中，重音转移背后的强弱拍交替在[[connected-speech/rhythm]]中。前缀和后缀作为构词手段，是[[word-formation/suffixes]]的内容；作为词汇的词族，见[[core-vocabulary/word-families]]。

::: summary
- 长词有**主重音**、**次重音**（在主重音之前）和非重读音节，其中有些带完整元音（[[#def-levels]]）。
- 较长词中的 *-ate* 和 *-ise* 通常重读倒数第三个音节；*-ify* 以及 *-ology*、*-ography* 重读它们前面的音节（[[#rule-ending]]）。
- *-ary*、*-ory*、*-ery* 在 GB 中是弱读的（*dictionary* /ˈdɪkʃənri/），在 GA 中保留完整元音（/ˈdɪkʃəˌneri/）。
- 前缀很少承担主重音；表示“再一次”的 *re-* 读完整的 /riː/（*re-cover*）。
- 道路和广场名称、材料、时间和地点、许多复合形容词、副词和动词重读**第二**部分；*Street* 名则不然（[[#rule-compound]]）。
- 短语动词重读小品词（*set **UP***）；由它们构成的名词重读动词部分（*a **SET**up*）（[[#rule-phrasal]]）。
- *thirteen* 和 *Japanese* 这样的词在重读音节前会把重音前移（*THIRteen PEOple*）（[[#rule-shift]]）。
:::

::: exercise GB 和 GA {level=2}

::: exercise 改正重音 {level=3}
一个学生朗读：*My SISter is a seCRETary at the uniVERsity. She has to orGANise meetings and comMUnicate with stuDENTS from interNAtional programmes, and she works on OXford ROAD.*（意思是：我姐姐是大学的秘书。她要组织会议，和国际项目的学生沟通，她在牛津路上班。）找出错误的重音，改正它们，并给出每一处所依据的规则。
::: hint
检查 *secretary*、*organise*、*students* 和 *Oxford Road*。所标的重音中有四个是对的。
:::
::: solution
- ✗ *se**CRE**tary* → ✓ ***SEC**retary*——随词记住；词尾 *-ary* 是弱读的（GB）或只有次重音（GA）。
- ✗ *or**GAN**ise* → ✓ ***OR**ganise*——较长词中的 *-ise*：倒数第三个音节（[[#rule-ending]]）。
- ✗ *stu**DENTS*** → ✓ ***STU**dents*——双音节名词，重读第一个音节。
- *OXford ROAD*——两个大写并不同样正确：主重音在 ***ROAD*** 上（*Oxford **ROAD***，[[#rule-compound]]），*Ox-* 上只有次重音。
- 正确的：***SIS**ter*，*uni**VER**sity*（*-ity* 前面的重音），*com**MU**nicate*（*-ate*，倒数第三个），*inter**NA**tional*——不过在 *international programmes* 里很可能发生重音转移：***IN**ternational **PRO**grammes*。
:::
:::
