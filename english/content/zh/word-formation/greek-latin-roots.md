李晓雨在国际学校上学的第一天，拿到的课程表上有 *biology*（生物）、*geography*（地理）和 *physics*（物理），阅读书目里有一本 *autobiography*（自传），科学实验室里有 *microscope*（显微镜）、*thermometer*（温度计），楼顶上还有一架 *telescope*（望远镜）。这些英语单词对她来说几乎都是新的，但要学的东西并没有看上去那么多。*Biology* 和 *biography*（传记）都有 *bio-*“生命”；*biography*、*geography* 和 *autobiography* 都有 *-graph-*“写”；*microscope* 和 *telescope* 都有 *-scope*“观察”；*thermometer* 是“热”+“测量”。十几个来自希腊语的构词部件就能解释所有这些词。

英语的学术和科技词汇在很大程度上是由希腊语和拉丁语的部件构成的。这些部件通常不能单独作为英语单词使用——英语里没有 *bio* 或 *spect* 这样的词——但它们出现在成百上千个词里，意义稳定。认识最常见部件的学习者，常常能推断出一个新学术词的大致意思，而且新词和已知的词联系在一起，也就记得更牢。本章介绍最有用的希腊语和拉丁语词根，说明它们怎样相互结合、怎样和前缀后缀结合，以及在哪些地方会误导人。

这些词是怎样进入英语的——大多是在文艺复兴时期以及其后的科学世纪——在 [[history-of-english/early-modern-english]] 中讲述；这里我们只看它们是怎样构成的。

## 构词成分和粘着词根

::: definition 构词成分 {#def-combining-form}
**构词成分**（combining form）是一种粘着成分，通常来自希腊语或拉丁语，它和另一个这样的成分（或和一个词）结合，构成新词：*bio-* + *-logy* → *biology*（生物学），*tele-* + *-phone* → *telephone*（电话），*micro-* + *-scope* → *microscope*（显微镜）。用这种方法构成的词叫作**新古典复合词**（neoclassical compound）：说它是复合词，是因为它把两个或更多具有完整意义的成分连在一起；说它是“新古典”的，是因为它的部件来自古典语言，而大多数词却是在现代造出来的。
:::

构词成分像词根一样有完整的意义（“生命”“远”“小”），又像词缀一样是粘着的。许多构词成分既可以在词首，也可以在词尾：*graph* 在 *graphic*（图形的）中在前，在 *photograph*（照片）中在后；*phone* 在 *telephone* 中在后，在 *phonetics*（语音学）中在前。两个希腊语成分之间英语通常加元音 *o*（*therm-o-meter*、*bi-o-logy*、*dem-o-cracy*）；两个拉丁语成分之间常加 *i*（*agr-i-culture* 农业）。

拉丁语给了英语许多**粘着词根**，它们不是构词成分，而是动词的词根，前面通常带一个拉丁语前缀：*in-spect*（检查）、*trans-port*（运输）、*pre-dict*（预测）、*intro-duce*（介绍）。你在 [[word-formation/morphemes#def-free-bound]] 中见过一个：*receive*（收到）、*perceive*（察觉）、*deceive*（欺骗）中的 *-ceive*。

## 希腊语成分

| 成分 | 意义 | 例子 |
|---|---|---|
| *bio-* | 生命 | *biology*（生物学）、*biography*（传记）、*antibiotic*（抗生素）、*biodegradable*（可生物降解的） |
| *geo-* | 地，土地 | *geography*（地理）、*geology*（地质学）、*geometry*（几何） |
| *photo-* | 光 | *photograph*（照片）、*photosynthesis*（光合作用） |
| *tele-* | 远 | *telephone*（电话）、*television*（电视）、*telescope*（望远镜） |
| *micro-* | 小，微 | *microscope*（显微镜）、*microphone*（麦克风）、*microwave*（微波炉） |
| *auto-* | 自己 | *autobiography*（自传）、*automatic*（自动的）、*autograph*（亲笔签名） |
| *chron-* | 时间 | *chronological*（按时间顺序的）、*chronic*（慢性的）、*synchronise*（使同步） |
| *therm-* | 热 | *thermometer*（温度计）、*thermal*（热的） |
| *hydr-* | 水 | *hydrogen*（氢）、*dehydrated*（脱水的）、*hydroelectric*（水力发电的） |
| *psych-* | 心理，精神 | *psychology*（心理学）、*psychiatrist*（精神科医生） |
| *dem-* | 人民 | *democracy*（民主）、*epidemic*（流行病） |
| *-graph*、*-graphy* | 写，画；书写的东西，记录 | *photograph*（照片）、*paragraph*（段落）、*geography*（地理）、*biography*（传记） |
| *-logy* | ……学；*-logist* 研究……的人 | *biology*（生物学）、*psychology*（心理学）、*sociology*（社会学）、*ecologist*（生态学家） |
| *-phone* | 声音 | *telephone*（电话）、*microphone*（麦克风）、*headphones*（耳机） |
| *-scope* | 观察用的仪器 | *microscope*（显微镜）、*telescope*（望远镜）、*horoscope*（星象，占星） |
| *-meter*（英式英语的计量单位也写作 *-metre*） | 测量 | *thermometer*（温度计）、*speedometer*（速度表）；*kilometre*（英式，千米）、*kilometer*（美式） |
| *-cracy*、*-crat* | 统治；统治者，拥护者 | *democracy*（民主）、*bureaucracy*（官僚主义）、*democrat*（民主主义者） |

其中有些成分除了相互结合以外，也和英语单词或拉丁语词根结合：*microwave*（微波炉）、*headphones*（耳机）、*television*（电视；希腊语 *tele-* + 源自拉丁语的 *vision*）。纯正主义者曾经不喜欢这种混合词；如今已经没有人在意了。

::: theorem 希腊语型词的重音 {#rule-greek-stress}
1. 以 ***-logy***、***-graphy***、***-logist*** 和 ***-grapher*** 结尾的词，重音在这个词尾前面的那个音节上：*bi**OL**ogy*（生物学）、*ge**OG**raphy*（地理）、*psych**OL**ogist*（心理学家）、*pho**TOG**rapher*（摄影师）。
2. 以 ***-meter*** 结尾、表示仪器的词，重音通常在 *-meter* 前面的那个音节上：*ther**MOM**eter*（温度计）、*ba**ROM**eter*（气压计）、*spee**DOM**eter*（速度表）。（计量单位不同：英式英语说 ***KIL**ometre*，美式英语常说 *ki**LOM**eter*。）
3. 以 ***-ic*** 结尾的词遵循 *-ic* 规则：*bio**LOG**ical*（生物的）、*photo**GRAPH**ic*（摄影的）、*demo**CRAT**ic*（民主的）（[[sounds-of-english/word-stress-basics#rule-suffix]]）。
:::

所以在一个词族中，重音以及随之而来的元音会发生变化：**PHO**tograph、pho**TOG**raphy、photo**GRAPH**ic。懂得这条规则的学习者第一次就能把词读对（[[word-formation/suffixes#ex-stress]]）。

::: quiz
*chronological* order 是什么意思？
- [ ] 按大小排列的顺序
- [x] 按时间排列的顺序，从最早到最晚
- [ ] 按重要性排列的顺序
- [ ] 按字母排列的顺序
::: solution
*Chron-* 的意思是“时间”，*-logical* 的意思是“与……的研究或逻辑有关的”：*chronological order* 就是事情发生的先后顺序。比较 *chronic*（长期的：*a chronic illness* 慢性病）和 *synchronise*（使同时发生，使同步）。
:::
:::

::: example 推断一个科学词汇 {#ex-greek}
根据构成部分推断每个词的意义，然后用句子检验。

1. *Most plastic bags are not **biodegradable**.*（大多数塑料袋不能被生物降解。）
2. *She was **dehydrated** after the long run.*（长跑之后她脱水了。）
3. *His **autobiography** was published last year.*（他的自传去年出版了。）
4. *The doctor used a **stethoscope**.*（医生用了听诊器。）
::: solution
1. *bio-*“生命”+ *de-*“向下，分开”+ *grade*“台阶”+ *-able*“能被……的”：“能被生物分解的”（被细菌分解）。句子吻合：塑料袋不会腐烂掉。
2. *de-*“去除”+ *hydr-*“水”+ *-ate*（构成动词）+ *-ed*：“身体失去了太多水分的”。吻合：长跑之后没有喝水。
3. *auto-*“自己”+ *bio-*“生命”+ *-graphy*“书写”：“由本人写的自己的生平故事”。比较 *biography*（传记），是由别人写的。
4. *stetho-* + *-scope*“观察用的仪器”。*Stetho-* 不在表中；它来自希腊语的“胸部”。各部分合起来是“检查胸部的仪器”，这是对的——但医生是通过它*听*，而不是看。词根给出大致的意思；上下文和词典给出确切的意思。
:::
:::

## 拉丁语词根

| 词根 | 意义 | 例子 |
|---|---|---|
| *port* | 携带 | *transport*（运输）、*import*（进口）、*export*（出口）、*portable*（便携的）、*report*（报告） |
| *spect*、*spic* | 看 | *inspect*（检查）、*respect*（尊重）、*spectator*（观众）、*prospect*（前景）、*suspicious*（怀疑的） |
| *dict* | 说 | *predict*（预测）、*dictionary*（词典）、*contradict*（与……矛盾）、*dictate*（口授） |
| *duc*、*duct* | 引导 | *introduce*（介绍）、*produce*（生产）、*education*（教育）、*conduct*（进行；指挥） |
| *scrib*、*script* | 写 | *describe*（描述）、*subscribe*（订阅）、*script*（剧本）、*manuscript*（手稿） |
| *mit*、*miss* | 送，派 | *transmit*（传送）、*admit*（承认；准许进入）、*mission*（使命）、*dismiss*（解雇；不予考虑） |
| *vid*、*vis* | 看见 | *video*（视频）、*evidence*（证据）、*visible*（看得见的）、*revise*（修改） |
| *aud* | 听 | *audio*（音频）、*audience*（观众，听众）、*audible*（听得见的） |
| *struct* | 建造 | *construct*（建造）、*structure*（结构）、*instruction*（指示）、*destroy*（毁坏；*struct* 变了形） |
| *ject* | 投，掷 | *inject*（注射）、*project*（项目；投射）、*reject*（拒绝）、*object*（物体；反对） |
| *rupt* | 破，断 | *interrupt*（打断）、*erupt*（爆发）、*bankrupt*（破产的）、*disrupt*（扰乱） |
| *tract* | 拉，拖 | *attract*（吸引）、*extract*（提取）、*tractor*（拖拉机）、*distract*（使分心） |
| *ven*、*vent* | 来 | *invent*（发明）、*event*（事件）、*convenient*（方便的）、*prevent*（阻止） |

一个词根常常和几个前缀一起出现，前缀表示方向或动作的类型。看看 *port*“携带”：

- *ex-*“向外”→ *export*“把货物运出国”（出口）
- *im-*（= *in-*）“向内”→ *import*“把货物运进国”（进口）
- *trans-*“横过”→ *transport*“从一地运到另一地”（运输）
- *re-*“回”→ *report*“把消息带回来”（报告）
- *sup-*（= *sub-*）“在下”→ *support*“从下面托着”（支持）

拉丁语前缀在某些词根前会改变最后一个辅音字母，就像 *in-* 在 *impossible* 中那样（[[word-formation/prefixes#rule-negative]]）：表示“一起”的 *con-* 会变成 *com-*（*compose* 组成）、*col-*（*collect* 收集）和 *cor-*（*correct* 改正）；表示“向，到”的 *ad-* 会变成 *ac-*（*accept* 接受）、*af-*（*affect* 影响）、*ap-*（*approve* 批准）、*at-*（*attract* 吸引）；表示“在下”的 *sub-* 会变成 *sup-*（*support* 支持）、*suf-*（*suffer* 遭受）。认出这些拼写有助于你找到词根。

::: example 还原前缀的变化 {#ex-assimilation}
每个词都以一个最后字母发生了变化的拉丁语前缀开头。给出原来的前缀，找出词根从哪里开始，并说明拼写中为什么有双辅音字母。

1. *collect*（收集）
2. *accept*（接受）
3. *support*（支持）
4. *correct*（改正）
5. *affect*（影响）
::: solution
1. *col-* = *con-*“一起”+ *lect*（拉丁语 *legere*“收集”）：“收集到一起”。*n* 在 *l* 前变成 *l*，于是有了 *ll*。
2. *ac-* = *ad-*“向”+ *cept*（拉丁语 *capere*“拿，取”，也是 *receive* 和 *reception* 的词根）：“拿到自己这里来”。*d* 在 *c* 前变成 *c*。
3. *sup-* = *sub-*“在下”+ *port*“携带”：“从下面托着”。*b* 在 *p* 前变成 *p*。
4. *cor-* = *con-* + *rect*（拉丁语 *regere*“引导，统治”，如 *direct* 指引）：“弄直”。*n* 在 *r* 前变成 *r*。
5. *af-* = *ad-* + *fect*（拉丁语 *facere*“做，制作”，如 *effect* 效果、*factory* 工厂）：“作用于，对……做某事”。*d* 在 *f* 前变成 *f*。

双辅音字母是一个有用的信号：一个学术词如果以 *acc-*、*aff-*、*app-*、*att-*、*coll-*、*comm-*、*corr-*、*supp-* 或 *suff-* 开头，背后往往就是“拉丁语前缀 + 词根”。同样的变化也解释了 *illegal*（违法的）和 *irregular*（不规则的）中的双字母（[[word-formation/prefixes#rule-negative]]）——以及忘记它们而造成的拼写错误（✗ *acomodation*，✓ *accommodation* 住宿）。
:::
:::

::: example 一个词根，许多词 {#ex-latin}
利用词根 *dict*“说”以及你认识的前缀和后缀，解释每个加粗的词。

1. *Can you **predict** the result?*（你能预测结果吗？）
2. *The two reports **contradict** each other.*（这两份报告相互矛盾。）
3. *Look it up in a **dictionary**.*（查一下词典。）
4. *The teacher **dictated** a short text to the class.*（老师给全班听写了一篇短文。）
::: solution
1. *pre-*“在……之前”+ *dict*“说”：“在事情发生之前说出”——预测。
2. *contra-*“相反”+ *dict*：“说相反的话”——相互矛盾。
3. *dict* + *-ion*（名词）+ *-ary*（场所或汇集）：“词语（说法）的汇集”——词典。
4. *dict* + *-ate*（动词）：“大声说出词句让别人写下来”——口授，听写。同一个词根还构成 *dictator*（独裁者），即说的话就是法律的统治者。

这四个意义各不相同，但都保留了“说”的概念，这使它们更容易一起记住。
:::
:::

## 利用词根猜测词义

::: theorem 根据词根猜词 {#rule-guess}
要推断一个含有希腊语或拉丁语部件的生词的意义：

1. **拆分它**：找出前缀、词根或构词成分，以及后缀（*in-spect-ion*）。
2. **给每一部分它的基本意义**，再按“后缀（词类），前缀 + 词根（意义）”的方式合起来：*inspection* = 一个名词，“往里看”（检查）。
3. **在上下文中检验猜测。** 如果不吻合，这个词可能已经偏离了它的构成部分的意义，或者你拆错了。
4. **重要的词要查词典核实。** 词根给出意义的大致范围；词典给出确切的、现代的意义。
:::

::: proof
词根之所以有用，是因为许多学术词就是用这些部件构成的，而且常常是在现代、有意地由懂拉丁语和希腊语的科学家和学者造出来的，他们想要意义一目了然的名称（*thermometer* 温度计、*photosynthesis* 光合作用、*biodegradable* 可生物降解的）。对这类词来说，各部分加起来很吻合。但大多数带拉丁语词根的词是现成借来的，在学习者遇到它们之前，它们的意义已经在拉丁语、法语和英语中变化了好几个世纪。*Prevent* 是 *pre-*“在……之前”+ *vent*“来”——原来是“先来，先行动”，现在是“阻止某事发生”。*Suspect* 是 *sub-*“在下”+ *spect*“看”——“从下面看，偷偷地看”（怀疑）。历史意义是有用的记忆辅助，但它不是定义。关于学习者猜词的研究支持这种平衡：Nation（2013）建议把学习最常用的词缀和词根作为一种策略，同时提醒说，根据构成部分作出的猜测必须始终用上下文来核实。
:::

::: warning 会误导人的词根
- 词根不一定在它看起来的地方：*pedestrian*（行人）含有拉丁语的 *ped-*“脚”，而 *pediatrician*（英式 *paediatrician*，儿科医生）含有希腊语的 *paed-*“儿童”。两者都有 *ped*。
- 历史意义可能和现代意义相去甚远：*prevent*（“先来”）现在的意思是“阻止”；*candidate*（候选人）来自拉丁语 *candidus*“白色的”（古罗马的候选人穿白色托加袍），这对理解今天的选举毫无帮助。
- 有些词只是看起来含有某个词根。*Audit*（审计）确实含有 *aud*“听”（账目从前是通过大声宣读来核查的），但 *portion*（一部分）和 *port*“携带”毫无关系：它来自拉丁语的“份额”。
- *Phil-*“爱”和 *-phobia*“恐惧”乍一看形似，容易混淆：*philosophy* 是“爱智慧”（哲学），*claustrophobia* 是“对封闭空间的恐惧”（幽闭恐惧症）。

当构成部分的意义和上下文不一致时，相信上下文，并查证。
:::

::: quiz
一位朋友说 *transparent* 的意思一定是“穿过父母”。最好的回答是哪一个？
- [ ] 对：*trans-* 的意思是“穿过”。
- [x] *Trans-* 是对的，但 *parent* 不是英语单词 *parent*（父母）：这个词根的意思是“出现，被看见”，所以 *transparent* 是“能被看穿的”。
- [ ] *Transparent* 没有构成部分；必须作为整体来学。
- [ ] 前缀是 *tran-*，不是 *trans-*。
::: solution
*Transparent*（透明的）是 *trans-*“穿过”+ 拉丁语词根 *par-*“出现”（如 *appear* 出现、*apparent* 明显的）+ *-ent*（形容词）：“能被看穿的”。字母 *parent* 只是巧合。这提醒我们要用真正含有这个部件的词——*apparent*、*appear*——以及上下文来核查每一部分：*transparent glass*（透明玻璃），*a transparent process*（透明的程序）。
:::
:::

::: example 读一段科学文字 {#ex-paragraph}
利用词根、前缀和后缀解释加粗的词。然后说出哪个词最难用词根解释。

> *In **photosynthesis**, plants use the energy of sunlight to make sugar. Scientists **measure** the process with special **instruments**, and a **microscope** shows the structures inside the leaf. The results are **visible** within hours, and they **contradict** an older **hypothesis**.*

**译文：**在光合作用中，植物利用阳光的能量制造糖分。科学家用专门的仪器测量这一过程，显微镜显示出叶片内部的结构。几小时内就能看到结果，这些结果与一个较早的假说相矛盾。
::: solution
- *photosynthesis*：*photo-*“光”+ *synthesis*“合成”（希腊语 *syn-*“一起”+ *thesis*“放置”）：“利用光把东西合在一起”——用光的能量制造糖分（光合作用）。
- *measure*：对英语学习者来说不是希腊语或拉丁语的复合词；它是一个要整体学习的基本词（测量）（它和 *-meter* 有关，但关系很远）。
- *instruments*：*in-* + *struct*“建造”+ *-ment* + *-s*——历史上是“建在里面的东西，设备”；现代意义“测量用的工具或乐器”离各部分的意义很远。这是词根最难解释的词。
- *microscope*：*micro-*“小”+ *-scope*“观察用的仪器”（显微镜）。
- *visible*：*vis*“看见”+ *-ible*“能被……的”：“能被看见的”。
- *contradict*：*contra-*“相反”+ *dict*“说”：“说相反的话”（与……矛盾）。
- *hypothesis*：希腊语 *hypo-*“在下”+ *thesis*“放置”：“放在下面的东西”——作为检验基础而提出的想法（假说）。构成部分有帮助，但科学上的意义必须专门学。
:::
:::

::: note 英汉对比
汉语的科学和学术术语，构成方式和英语的新古典复合词非常相似：由有意义的部件构成，每个部件写成一个汉字。其中许多可以和希腊语或拉丁语成分逐一对应。*Telescope* 是“望远镜”——“望”是看，“远”是远，“镜”是镜片——几乎正好是 *tele-*“远”+ *-scope*“观察用的仪器”。*Microscope* 是“显微镜”，即“显示微小东西的仪器”；*thermometer* 是“温度计”，即“测量温度的仪器”；*biology* 是“生物学”，即“研究生物的学问”，其中“学”起 *-logy* 的作用；*geography* 是“地理”。许多这样的汉语术语是在十九世纪末二十世纪初为翻译欧洲科学而创造的，其中有些最初是在日本造出来的。

这给了中国学习者真正的优势：汉语培养的逐个部件阅读专业术语的习惯，正是英语学术词汇所需要的。中国的词汇书常常因此讲授英语的**词根**和**词缀**。有两点需要注意。第一，英语的部件不像汉字那样一眼就能看出来，而且拼写会变化（*con-*、*com-*、*col-*）；你需要对它们足够熟悉才能认出来。第二，有些流行的记忆方法会编造并不存在的“词根”（把 *pear* 拆成 *p* + *ear*）；它们也许能暂时帮助记忆，但教的是错误的拆分。要用真正的词根，这些词根可以在词典的词源说明中查到。
:::

::: history
文艺复兴时期，英语大量借入拉丁语和希腊语词，而这种借用颇有争议。批评者把这些新的学术词称为**墨水瓶词**（inkhorn terms）——带着学者墨水瓶气味的词——托马斯·威尔逊（Thomas Wilson）在《修辞的艺术》（*Arte of Rhetorique*，1553年）中嘲笑那些在英语中塞满这类词的作者。其中许多词还是流传了下来（*education* 教育、*conspicuous* 显眼的、*exaggerate* 夸张），另一些则消失了。从十八、十九世纪起，科学家有意地用希腊语和拉丁语的部件来给新事物和新领域命名，这类新词至今每年都在产生。有些词是精心造出来的：1834年，学者威廉·休厄尔（William Whewell）仿照 *artist*（艺术家）提出了 *scientist*（科学家）一词，用来指研究自然界的人。
:::

## 后续内容

和拉丁语词根结合的前缀（*ex-*、*in-*、*re-*、*trans-*、*sub-*）列在 [[word-formation/prefixes]] 中，构成词类的后缀（*-ion*、*-ive*、*-ible*）列在 [[word-formation/suffixes]] 中；*-able* 和 *-ible* 之间的选择在 [[word-formation/spelling-changes]] 中讲解。怎样把词根变成一种学习方法——以及什么时候不能相信它们——是 [[word-formation/learning-with-word-formation]] 的内容。关于这些词的历史，见 [[history-of-english/early-modern-english]]；关于最常用到它们的学术词汇，见 [[collocation-and-register/academic-vocabulary]]。

::: summary
- 学术和科技英语大量由希腊语和拉丁语部件构成，这些部件是**粘着的**：它们本身不是英语单词。
- **希腊语构词成分**相互结合构成**新古典复合词**：*bio-*“生命”、*geo-*“地”、*tele-*“远”、*micro-*“小”、*auto-*“自己”、*-graph*“写”、*-logy*“……学”、*-scope*“观察”、*-meter*“测量”。
- **拉丁语词根**通常带前缀：*port*“携带”、*spect*“看”、*dict*“说”、*duct*“引导”、*script*“写”、*miss*“送”、*vis*“看见”、*struct*“建造”、*ject*“投”、*tract*“拉”。前缀在某些词根前改变最后一个字母：*com-*、*col-*、*cor-*；*ac-*、*af-*、*ap-*。
- *-logy*、*-graphy* 和 *-meter* 把重音放在它们前面的音节上：*bi**OL**ogy*、*ther**MOM**eter*。
- 猜词：拆分这个词，给每个部分它的基本意义，在上下文中检验猜测，重要的词查词典核实。
- 词根的意义是历史意义；现代意义可能已经变了（*prevent*、*candidate*），有些字母组合只是看起来像词根（*transparent* 里没有 *parent*）。
- 汉语的专业术语（望远镜、生物学）也是这样逐个部件构成的——这是真正的帮助，前提是你用的是真正的词根。
:::

::: exercise 拆分对不对？ {level=2}
下面的分析对不对？不对的话，请说明。

1. *spectacles*（眼镜）含有 *spect*“看”。
2. *dictionary*（词典）含有 *dict*“说”。
3. *important*（重要的）含有 *port*“携带”。

5. *phonetics*（语音学）含有 *phon*“声音”。
::: solution
1. 对：*spectacles*（眼镜）是用来透过它看东西的；*a spectacle* 是值得看的场面（奇观）。

4. 不对：这里的 *ped-* 是拉丁语的“脚”——行人是步行的人。表示“儿童”的希腊语 *paed-*/*ped-* 出现在 *paediatrician*/*pediatrician*（儿科医生）中。

::: exercise 解释一段学术文字 {level=3}
读下面这段话。选出六个由希腊语或拉丁语部件构成的词，把每个词拆分成部件，给出各部件的意义，并说明这些部件能否导向现代意义。

> *The researchers interviewed two hundred students and transcribed the recordings. Their analysis suggests that students who receive regular feedback produce more coherent arguments. However, the authors admit that the sample was small, and they recommend a larger, international study.*

**译文：**研究人员采访了两百名学生，并把录音转写成文字。他们的分析表明，定期得到反馈的学生能写出更连贯的论证。不过，作者承认样本较小，并建议开展一项规模更大的国际研究。
::: solution
参考答案（也可以选别的词）：

- *interviewed*：*inter-*“在……之间”+ *view*（来自拉丁语 *videre*“看见”，经由法语）+ *-ed*——“相互看见”；现代意义“向某人提问”（采访，面试）与之有关，但已有变化。
- *transcribed*：*trans-*“横过”+ *scrib*“写”+ *-ed*——从一种形式“写过去”到另一种形式：把话语写成文字（转写）。部件能很好地导向意义。
- *receive*：*re-*“回”+ *-ceive*“拿”——“拿回来”；现在只是“得到”。部分有帮助。
- *produce*：*pro-*“向前”+ *duc*“引导”——“向前引出，拿出来”；现代意义“制造，产生”与之接近。
- *admit*：*ad-*“向”+ *mit*“送”——“让进来”；*admit* that something is true（承认某事属实）就是把它“放进”论证里来。作为记忆辅助有帮助。
- *international*：*inter-*“在……之间”+ *nation* + *-al*——“国家之间的”（国际的）。一目了然。

你也可以选 *analysis*（希腊语 *ana-*“向上，彻底”+ *lysis*“松开”——“拆分成部分”，分析）或 *coherent*（*co-*“一起”+ *her*“粘”——“粘在一起的”，逻辑上连贯的）。
:::

::: exercise 制作一张词根卡片 {level=3}
从表中选一个拉丁语词根（例如 *duct*、*mit*/*miss* 或 *tract*）。制作一张“词根卡片”，内容包括：词根和它的意义；含有这个词根的六个词，每个词标出前缀和后缀；每个词的词类和中文译文；其中两个词的例句各一个；还有一个**看起来**含有这个词根、其实不含的词。用一本给出词源的词典核查每个词。
::: solution
以 *duc*/*duct*“引导”为例：

| 词 | 部件 | 词类 | 中文 |
|---|---|---|---|
| *introduce* | *intro-*“向内”+ *duc* | 动词 | 介绍，引进 |
| *produce* | *pro-*“向前”+ *duc* | 动词 | 生产 |
| *reduce* | *re-*“回”+ *duc* | 动词 | 减少 |
| *education* | *e-*（= *ex-*）“向外”+ *duc* + *-ation* | 名词 | 教育 |
| *conductor* | *con-*“一起”+ *duct* + *-or* | 名词 | 指挥，售票员，导体 |
| *product* | *pro-* + *duct* | 名词 | 产品 |

例句：*Let me introduce my colleague, Dr Patel.*（让我介绍一下我的同事帕特尔博士。）—— *The company wants to reduce its costs.*（公司想降低成本。）

一个形似的词：*duck*（鸭子）听起来像 *duc*，但它是表示这种鸟的古英语词，和拉丁语 *ducere* 毫无关系。

你自己的卡片只能用真正的词（每个都查词典核实），部件的意义应当是历史意义，如果现代意义已经变了，要注明。
