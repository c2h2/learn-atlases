周敏的室友在冰箱上留了一张便条：

> *Got flu, sorry! Can't come to the lab today. Could you tell Prof. Ellis I'll email the stats ASAP? Also, brunch on Sat is still on — the café by the gym. BTW, the new sitcom on the BBC is great!*

**译文：**我得了流感，抱歉！今天不能去实验室了。你能告诉埃利斯教授我会尽快把统计数据用邮件发给他吗？另外，星期六的早午餐照常——在健身房旁边那家咖啡馆。顺便说一句，BBC 的那部新情景喜剧很好看！

这些词的完整形式周敏全都认识，但这里将近一半的词都是缩短了的。*Flu* 是 *influenza*（流感）；*lab* 是 *laboratory*（实验室）；*fridge* 是 *refrigerator*（冰箱）；*stats* 是 *statistics*（统计数据）；*gym* 是 *gymnasium*（健身房）；*Prof.* 是 *Professor*（教授）；*Sat* 是 *Saturday*（星期六）。*Brunch*（早午餐）由 *breakfast*（早餐）和 *lunch*（午餐）构成，*sitcom*（情景喜剧）由 *situation comedy* 构成。*ASAP*、*BTW* 和 *BBC* 分别由 *as soon as possible*（尽快）、*by the way*（顺便说一句）和 *British Broadcasting Corporation*（英国广播公司）的首字母构成。

英语缩短词语主要有三种方式：截去一个词的一部分（**截短**），把两个词的部分连在一起（**拼缀**），以及取几个词的首字母（**首字母拼音词**和**首字母缩略词**）。缩短的词在会话、消息、新闻和科学中随处可见，其中许多已经成了普通的词，说话人根本不再觉得它们是缩略形式：*bus*（公共汽车）、*photo*（照片）、*exam*（考试）、*laser*（激光）。本章讲解这三种方式，缩略形式怎样读、怎样写，哪些是非正式的，以及它们前面用什么冠词。

## 截短

::: definition 截短 {#def-clipping}
**截短**（clipping）是截去一个较长的词的一部分，构成一个较短的词，意义和词类都不改变：*laboratory* → *lab*（实验室），*examination* → *exam*（考试），*telephone* → *phone*（电话），*influenza* → *flu*（流感）。新词叫作**截短词**（clipping）或截短形式。
:::

英语在三个位置截短词语。截去词尾是最常见的。

| 截去的部分 | 例子 |
|---|---|
| **词尾**（截尾） | *lab*(*oratory*) 实验室、*exam*(*ination*) 考试、*gym*(*nasium*) 健身房、*photo*(*graph*) 照片、*ad*(*vertisement*) 广告、*info*(*rmation*) 信息、*memo*(*randum*) 备忘录、*uni*(*versity*) 大学（英式英语）、*maths*/*math*（*mathematics* 数学） |
| **词首**（截头） | (*tele*)*phone* 电话、(*omni*)*bus* 公共汽车、(*aero*)*plane* / (*air*)*plane* 飞机 |
| **两头** | (*in*)*flu*(*enza*) 流感、(*re*)*frig*(*erator*) → *fridge* 冰箱 |

有些截短词来自短语或复合词：*mobile*（*mobile phone* 手机）、*pub*（*public house* 酒馆）、*sitcom*（*situation comedy* 情景喜剧）、*sci-fi*（*science fiction* 科幻）。还有些为了和读音一致而改变了拼写：*bike*（来自 *bicycle* 自行车）、*fridge*（用 *dg* 表示 /dʒ/ 音）、*mic* 或 *mike*（来自 *microphone* 麦克风）。英式英语和澳大利亚英语还会在截短词后加 *-y* 或 *-ie*，使它听起来亲切随意：*telly*（*television* 电视）、*brekkie*（*breakfast* 早餐）、*barbie*（*barbecue* 烧烤，尤其是澳大利亚英语）。

::: theorem 截短词与语域 {#rule-clip-register}
1. 大多数截短词起源于非正式的口语。许多一直是**非正式的**：*uni*、*telly*、*info*、*ad*、*fridge*、*stats*、*mic*。在正式写作中，要用完整的词：*university*、*television*、*information*、*advertisement*、*refrigerator*、*statistics*。
2. 有些截短词已经变成**中性的**，在各种语域中都用，而完整形式反倒显得过时或专业：*bus*（而不是 *omnibus*）、*phone*、*photo*、*exam*、*flu*、*plane*、*pub*、*gym*。有些完整形式只用于特殊的意义：*influenza* 用于医学，*examination* 用于正式或医学场合（*a medical examination* 体检）。
3. 英式英语和美式英语在一些词上有差别：英式 *maths*，美式 *math*；英式 *uni*（美式英语没有对应的说法，说 *college* 或 *school*）。

学习型词典会给非正式的截短词标上 *informal*（非正式）。
:::

::: proof
较短的词说起来更省力，所以常用的词有变短的倾向，而截短通常从最常用这个词的群体开始——学生（*exam*、*lab*、*uni*）、医生和护士、某个行业的从业者。一旦一个截短词被所有人在所有场合使用，长的形式就开始显得特别，截短词就成了普通的词。这在很久以前就发生在 *bus*（来自 *omnibus*，十九世纪初）、*cab*（出租车，来自 *cabriolet*）和 *pram*（婴儿车，来自 *perambulator*）身上，近来又发生在 *phone* 和 *photo* 身上。所以一个截短词是否仍是非正式的，是每个词在某一时期的具体情况，这就是词典要给它加标签的原因。
:::

::: quiz
在一篇正式的大学论文中，哪个截短词**最**不合适？
- [ ] *bus*
- [ ] *exam*
- [x] *info*
- [ ] *phone*
::: solution
*Info* 仍是非正式的：在论文中要写 *information*。*Bus*、*exam* 和 *phone* 现在都是在各种语域中使用的中性词。（*Exam* 在大多数学术写作中都可以用；*examination* 更正式一些。）
:::
:::

::: example 截去了哪一部分？ {#ex-clipping}
给出每个截短词的完整形式，说明截去的是哪一部分（词尾、词首还是两头），并说明这个截短词是非正式的还是中性的。

1. *I left my umbrella on the **plane**.*（我把伞落在飞机上了。）
2. *There's some milk in the **fridge**.*（冰箱里有些牛奶。）
3. *My sister is in her second year at **uni**.*（我妹妹在读大学二年级。）
4. *Let's take the **bus**.*（我们坐公共汽车吧。）
5. *I'll send you the **memo**.*（我会把备忘录发给你。）
::: solution
1. *plane* ← *aeroplane*（英式）或 *airplane*（美式）：截去了词首。中性。
2. *fridge* ← *refrigerator*：截去了两头，拼写也改变了（用 *dg* 表示 /dʒ/）。介于非正式和中性之间；在技术性写作中用 *refrigerator*。
3. *uni* ← *university*：截去了词尾。非正式，主要用于英式和澳大利亚英语。
4. *bus* ← *omnibus*：截去了词首。中性——*omnibus* 已经不再用来指这种车。
5. *memo* ← *memorandum*：截去了词尾。在办公室里是中性的；*memorandum* 是正式或法律用语。
:::
:::

## 拼缀词

::: definition 拼缀词 {#def-blend}
**拼缀词**（blend）是把两个词的部分连在一起构成的词，通常取第一个词的开头和第二个词的结尾：*br*(*eakfast*) + (*l*)*unch* → *brunch*（早午餐）；*sm*(*oke*) + (*f*)*og* → *smog*（烟雾）；*mo*(*tor*) + (*ho*)*tel* → *motel*（汽车旅馆）。它的意义结合了两个词的意义。
:::

拼缀词和复合词不同，因为它截去了词的一部分（复合词保留整个词：*bus stop*）；它和截短词也不同，因为它合并了两个词（截短词只缩短一个词）。常见的拼缀词：

| 拼缀词 | 来源 | 意义 |
|---|---|---|
| *brunch* | *breakfast* + *lunch* | 上午较晚时吃的一餐，早午餐 |
| *smog* | *smoke* + *fog* | 城市中的污染空气，烟雾 |
| *motel* | *motor* + *hotel* | 供驾车旅行者住的旅馆，汽车旅馆 |
| *emoticon* | *emotion* + *icon* | 用键盘符号组成的表情，如 :-) |
| *podcast* | *iPod* + *broadcast* | 供下载的录制节目，播客 |
| *vlog* | *video* + *blog* | 用视频做的博客，视频博客 |
| *Chinglish* | *Chinese* + *English* | 受汉语迁移影响的英语，中式英语 |
| *Brexit* | *Britain* + *exit* | 英国脱离欧盟 |

拼缀词在广告、新闻和科技领域很流行，因为它们简短上口。有些（*brunch*、*smog*、*motel*）已经成了普通的词；许多其他的则是为某一场合造的，很快就被遗忘了。少数拼缀词还产生了新的构词部件：从 *alcoholic*（酗酒者）中产生了词尾 *-aholic*（“对某事物上瘾、停不下来的人”），出现在 *workaholic*（工作狂）和 *chocaholic*（巧克力迷）中；从 *Watergate*（水门事件）中产生了词尾 *-gate*，新闻界用它指称任何丑闻。

::: example 拼缀词是怎样构成的？ {#ex-blend}
说明每个拼缀词是怎样构成的，并给出它的意义。

1. *motel*
2. *Spanglish*
3. *infotainment*
4. *emoticon*
::: solution
1. *mo*(*tor*) + (*h*)*otel*——供驾车旅行者住的旅馆，客房附近有停车位。两个词在 *-otel* 处重叠。
2. *Span*(*ish*) + (*E*)*nglish*——西班牙语和英语的混合，美国的一些双语者使用。比较 *Chinglish*。
3. *info*(*rmation*) + (*enter*)*tainment*——以娱乐的方式呈现新闻或事实的电视节目，信息娱乐节目。
4. *emoti*(*on*) + *icon*——用键盘字符组成的面部图形，如 :-)。今天那些表示面孔和物品的小图片叫作 *emoji*（表情符号），这个词借自日语，并不是 *emotion* 的拼缀词，尽管许多说英语的人把两者联系在一起。

对于每个拼缀词，读者只有认识两个来源词，才能把它们还原出来：拼缀词依赖作者和读者共有的知识，这就是许多拼缀词流传不下来的原因。
:::
:::

## 首字母拼音词和首字母缩略词

::: definition 首字母缩略词和首字母拼音词 {#def-acronym}
两者都由一个短语的首字母构成。

- **首字母缩略词**（initialism）**逐个字母**地读：*BBC* /ˌbiː biː ˈsiː/（*British Broadcasting Corporation* 英国广播公司）、*USA*（美国）、*EU*（欧盟）、*CEO*（首席执行官）、*DIY*（*do it yourself* 自己动手）、*ATM*（自动取款机）。
- **首字母拼音词**（acronym）**作为一个词**来读：*NASA* /ˈnæsə/（*National Aeronautics and Space Administration* 美国国家航空航天局）、*NATO* /ˈneɪtəʊ/（GB），/ˈneɪtoʊ/（GA）（北约）、*AIDS*（艾滋病）、*PIN*（*personal identification number* 个人识别码，密码）。

许多人把两种都叫作 *acronym*；词典也是这样。但这种区分关系到读音，也关系到用 *a* 还是 *an*。
:::

有些首字母拼音词已经非常普通，用小写字母书写，大多数说话人都不知道它们原来是缩略语：*laser*（激光；*light amplification by stimulated emission of radiation*）、*radar*（雷达；*radio detection and ranging*）、*scuba*（水肺；*self-contained underwater breathing apparatus*）。有些缩略语两种读法都有：*FAQ*（*frequently asked questions* 常见问题）读 /ˌef eɪ ˈkjuː/ 或 /fæk/，*ASAP* 读 /ˌeɪ es eɪ ˈpiː/ 或 /ˈeɪsæp/。

::: theorem 首字母缩略词的读法和写法 {#rule-initialism}
1. **重音**：首字母缩略词重音在**最后一个**字母上，其他字母重音较弱：*B B **C***、*U **K***、*C E **O***、*D I **Y***。
2. **字母名称**：用英语的字母名称来读。字母 *Z* 在英式英语中读 *zed* /zed/，在美式英语中读 *zee* /ziː/；*H* 读 /eɪtʃ/（也有人读 /heɪtʃ/）。
3. **复数**：加一个小写的 *-s*，通常不加撇号：*CDs*、*MPs*（议员）、*PhDs*（博士）、*the 1990s*（20世纪90年代）。
4. **句点**：现代英式用法写 *BBC*、*UK*、*PhD*、*eg*/*e.g.*、*Dr*、*Mr*，很少或不用句点；美式用法更常写 *U.S.*、*Ph.D.*、*Dr.*、*Mr.*。选定一种风格，前后一致。
5. **首次出现**：为一般读者写作时，第一次出现要写出全称，把缩略形式放在括号里：*the World Health Organization (WHO)*（世界卫生组织）。此后只用缩略形式就够了。
:::

::: theorem 用 *a* 还是 *an*；用 *the* 还是不用冠词 {#rule-article}
1. 用 *a* 还是 *an* 取决于第一个**音**，而不是第一个字母。许多字母名称以元音开头：*F* /ef/、*H* /eɪtʃ/、*L* /el/、*M* /em/、*N* /en/、*S* /es/、*X* /eks/，当然还有 *A*、*E*、*I*、*O*。所以说：*an FBI agent*（一名联邦调查局特工）、*an MP*（一位议员）、*an NHS hospital*（一家国民保健署的医院）、*an SUV*（一辆运动型多用途车）、*an X-ray*（一张X光片）。但 *U* 以 /j/ 开头：*a UN report*（一份联合国报告）、*a UFO*（一个不明飞行物）。作为一个词来读的首字母拼音词则按它自己的第一个音：*a NATO country*（一个北约国家）、*a NASA scientist*（一位美国航天局的科学家）。
2. 表示组织、国家和机构的**首字母缩略词**通常带 ***the***：*the BBC*、*the EU*、*the UN*、*the UK*、*the USA*。作为词来读的**首字母拼音词**通常不带：*NASA*、*NATO*、*UNESCO*（联合国教科文组织）。有些首字母缩略词不带 *the*，因为它们是事物的名称，而不是机构的名称：*DIY*、*CPR*（心肺复苏）、*TV*（*on TV* 在电视上）。
:::

::: quiz
哪一句是正确的？
- [ ] *She works for a NHS hospital.*
- [x] *She works for an NHS hospital.*
- [ ] *She works for a hospital of NHS.*
- [ ] *She works for an the NHS hospital.*
::: solution
*NHS*（*National Health Service*，英国的公共医疗体系，国民保健署）是首字母缩略词，读 /ˌen eɪtʃ ˈes/。它以元音 /e/ 开头，所以用 *an*：*an NHS hospital*（她在一家国民保健署的医院工作。）后面不跟名词时，用 *the*：*She works for the NHS.*（她在国民保健署工作。）
:::
:::

::: example 读出来并选择冠词 {#ex-article}
把每个缩略语读出来，判断它是首字母缩略词还是首字母拼音词，并在前面填上 *a* 或 *an*。

1. ___ *FAQ* page（常见问题页面）
2. ___ *UFO*（不明飞行物）
3. ___ *NASA* mission（美国航天局的任务）
4. ___ *MBA* student（工商管理硕士学生）
5. ___ *USB* cable（USB 数据线）
6. ___ *HR* manager（人力资源经理）
::: solution
1. 如果逐个字母读 /ˌef eɪ ˈkjuː/（首字母缩略词），写作 *an FAQ page*；如果作为词读 /fæk/（首字母拼音词），写作 *a FAQ page*。两种都有。
2. *a UFO*——通常逐个字母读，/ˌjuː ef ˈəʊ/（GB），/ˌjuː ef ˈoʊ/（GA）；*U* 以 /j/ 开头，所以用 *a*。（也有人读 /ˈjuːfəʊ/，同样用 *a*。）
3. *a NASA mission*——作为词来读，/ˈnæsə/，以 /n/ 开头。
4. *an MBA student*（*Master of Business Administration* 工商管理硕士）——*M* 读 /em/。
5. *a USB cable*——*U* 读 /juː/。
6. *an HR manager*（*human resources* 人力资源）——*H* 读 /eɪtʃ/。（把 *H* 读成 /heɪtʃ/ 的人写 *a HR manager*；*an* 是通常的书面形式。）
:::

## 消息中的缩略形式

短信、聊天和社交媒体使用许多缩略语：*BTW*（*by the way* 顺便说一句）、*FYI*（*for your information* 供你参考）、*IMO*（*in my opinion* 依我看）、*LOL*（*laughing out loud* 大笑）、*TBH*（*to be honest* 说实话）、*ASAP*（尽快），还有 *u*（*you* 你）、*thx*（*thanks* 谢谢）、*pls*（*please* 请）这样的简写。它们在朋友之间很有用，*ASAP* 和 *FYI* 在工作邮件中也很常见。但它们是非正式的，不认识它们的读者会感到困惑，所以不适合用在论文、正式邮件或求职申请中。

::: warning 在不合适的语域中使用缩略形式
- ✗ *Dear Professor Smith, I'd like some info about the uni's MA programmes ASAP. Thx!*
- ✓ *Dear Professor Smith, I would be grateful for some information about the university's MA programmes. Thank you in advance.*（尊敬的史密斯教授：如能告知贵校文学硕士项目的相关信息，我将不胜感激。先行致谢。）

*MA*（*Master of Arts* 文学硕士）没有问题：它是标准的首字母缩略词。*Info*、*uni*、*ASAP* 和 *Thx* 是非正式的。面对来自其他国家的读者，缩略形式也要注意：*uni* 在美式英语中不常用，本地机构的首字母缩略词（*NHS*、*DMV* 美国机动车辆管理局、*HSK* 汉语水平考试）应当为可能不认识它们的读者写出全称。
:::

::: example 从消息到正式邮件 {#ex-register}
把这条发给同事的消息改写成一封发给经理的简短正式邮件。替换所有非正式的缩略形式。

> *Hi! FYI the stats from the lab are ready. Can u check the info b4 the exam board mtg on Fri? Thx, Ana*

**译文：**嗨！告诉你一下，实验室的统计数据好了。你能在星期五考试委员会开会之前核对一下这些信息吗？谢谢，安娜
::: solution
参考答案：

> *Dear Ms Wang,*
>
> *I am writing to let you know that the statistics from the laboratory are now ready. Could you please check the information before the examination board meeting on Friday?*
>
> *Thank you.*
>
> *Best regards,*
> *Ana Costa*

**译文：**尊敬的王女士：特此告知，实验室的统计数据现已备妥。能否请您在星期五考试委员会会议之前核对这些信息？谢谢。此致敬礼，安娜·科斯塔

改动：*FYI* → *I am writing to let you know*；*stats* → *statistics*；*lab* → *laboratory*（在许多工作场所 *lab* 也可以接受）；*u* → *you*；*info* → *information*；*b4* → *before*；*exam* → *examination*（或保留中性的 *exam*）；*mtg* → *meeting*；*Fri* → *Friday*；*Thx* → *Thank you*。称呼和结尾也改成了正式的格式（[[sentences-and-paragraphs/emails-messages]]）。
:::

::: note 英汉对比
汉语经常缩短名称和短语，但方式通常和英语不同。汉语的缩略语或简称一般是**从每个词中取一个字**：北京大学 → 北大，高速铁路 → 高铁，春节运输 → 春运，环境保护 → 环保。由于每个字都是一个有意义的音节，缩略形式仍然是有意义的词。英语中最接近的是 *sitcom*、*sci-fi* 这样的截短复合词和拼缀词；像 *BBC* 这样的英语首字母缩略词，在汉语中没有由汉字构成的对应形式。

汉语确实直接使用许多英语首字母缩略词——*GDP*、*CEO*、*VIP*、*ATM*、*Wi-Fi*、*CT*——还有一些由拼音构成，例如 *RMB*（人民币）和 *HSK*（汉语水平考试）。在英语中使用首字母缩略词时，有两点需要注意。第一，用英语的字母名称来读，重音放在最后一个字母上：*G D **P***、*C E **O***；字母 *Z* 在英式英语中读 *zed*，在美式英语中读 *zee*。第二，按字面翻译的汉语简称在英语中行不通：英语读者无法从一个自造的首字母缩略词还原出“高铁”。要写出完整的英语名称（*high-speed rail*），只有在缩略形式已经通用时才加上它。
:::

::: history
截短词在英语中已经用了好几个世纪，也常常受到批评。*Mob*（暴民）是在17世纪80年代从拉丁语短语 *mobile vulgus*“善变的平民”截短而来的；1710年，乔纳森·斯威夫特（Jonathan Swift）在《闲谈者》（*The Tatler*）上抱怨 *mob* 和 *rep*（*reputation* 名声）这类时髦的截短词，认为它们正在败坏英语。*Mob* 流传下来了；*rep* 至今仍在非正式场合使用。拼缀词的通俗名称来自刘易斯·卡罗尔（Lewis Carroll）：在《爱丽丝镜中奇遇》（*Through the Looking-Glass*，1871年）中，矮胖子（Humpty Dumpty）解释说 *slithy* 的意思是“lithe and slimy”（柔软而黏滑）——“这就像一个旅行皮箱（portmanteau），两个意思装进了一个词里”。（portmanteau 是一种可以打开成两半的大旅行箱。）首字母拼音词随着大型组织、军队和科技的发展，在二十世纪变得常见起来；*radar*（雷达）是第二次世界大战期间在美国海军中造出来的，*laser*（激光）则是在20世纪50年代后期造出的，不久之后，第一台激光器于1960年制成。
:::

## 后续内容

缩短的词是非正式词汇的一个重要部分，在完整形式和缩略形式之间做选择是一个语域问题：见 [[collocation-and-register/register]]，关于消息和邮件，见 [[sentences-and-paragraphs/emails-messages]]。*babysit*（临时照看孩子，来自 *babysitter*）这样的逆构词通过去掉看起来像后缀的部分来缩短一个词，在 [[word-formation/learning-with-word-formation]] 中讨论。许多截短词来自希腊语和拉丁语词（*photo*、*bus*、*lab*）；它们的词根是 [[word-formation/greek-latin-roots]] 的内容。

::: summary
- **截短**截去一个词的一部分：通常是词尾（*lab*、*exam*、*photo*），有时是词首（*phone*、*bus*）或两头（*flu*、*fridge*）。意义和词类不变。
- 许多截短词是**非正式的**（*uni*、*info*、*telly*、*stats*）；另一些现在已是中性词（*bus*、*phone*、*exam*、*flu*）。查看词典的标注。
- **拼缀词**把两个词的部分连在一起：*brunch*、*smog*、*motel*、*Chinglish*。有些流传下来，许多则没有。
- **首字母缩略词**逐个字母地读（*BBC*、*CEO*）；**首字母拼音词**作为一个词来读（*NASA*、*laser*）。首字母缩略词重音在最后一个字母上。
- 用 *a* 还是 *an* 取决于第一个**音**：*an MP*、*an FBI agent*、*a UN report*、*a NASA scientist*。表示机构的首字母缩略词通常带 *the*（*the BBC*、*the EU*）；作为词来读的首字母拼音词通常不带（*NASA*）。
- 为一般读者写作时，第一次要写出全称；消息中的缩略语（*BTW*、*thx*）不要用在正式写作中。
:::

::: exercise 截短词、拼缀词还是首字母缩略语？ {level=1}
说出每个词是用哪种方式构成的。

*brunch*、*lab*、*NATO*、*smog*、*bus*、*BBC*、*motel*、*info*

- 首字母缩略词（逐个字母读）：*BBC*

在首字母缩略词 *CEO* 中，有几个字母带**主**重音？

在每个词前填上 *a* 或 *an*。

1. ___ *MP*（议员）
2. ___ *UFO*（不明飞行物）
3. ___ *SUV*（运动型多用途车）

::: exercise 正式还是非正式？ {level=2}
替换这些大学论文句子中非正式的缩略形式。

1. *The uni has three labs for chemistry.*（这所大学有三个化学实验室。）
2. *Many students feel stressed before exams.*（许多学生考试前感到压力很大。）
3. *The govt published the stats in 2023.*（政府在2023年公布了统计数据。）
4. *Ads on TV target young people.*（电视广告以年轻人为目标。）
::: solution
1. *The university has three laboratories for chemistry.*（*Labs* 在许多科学文本中可以接受，但在论文中 *laboratories* 更稳妥。）
2. 不需要改动：*exams* 是中性的，可以用在论文中（*examinations* 更正式）。
3. *The government published the statistics in 2023.*（*Govt* 只是笔记中用的书面缩写。）
4. *Advertisements on television target young people.*（*TV* 在许多论文中可以接受；*television* 更正式。）
:::
:::

::: exercise 构成拼缀词 {level=2}
下面每对词构成什么拼缀词？给出每个词的意义。

1. *breakfast* + *lunch*
2. *smoke* + *fog*
3. *web* + *log*（然后再截短）
4. *Chinese* + *English*
::: solution
1. *brunch*——上午较晚时吃的一餐，代替早餐和午餐（早午餐）。
2. *smog*——空气污染，烟（或其他污染物）和雾的混合（烟雾）。
3. *weblog* → *blog*——有人定期发帖的网站（博客）。*Weblog* 是 *web* + *log* 构成的复合词；*blog* 是它的截短词，截去了 *we-*。
4. *Chinglish*——在词语或结构上显示出汉语迁移的英语（中式英语）。这个词在非正式场合使用；语言学家把它和 *China English*（中国英语，在中国用来表达中国事物的英语）区分开来（[[world-englishes/english-in-china]]）。
:::
:::

::: exercise 解释一则告示 {level=3}
一位刚到的外国职员在中国一家使用英语的办公室里看到这则告示。为不认识任何缩略语的读者改写它，并说明每个缩略语代表什么。

> *All new staff: please bring your ID, CV and a passport photo to HR by Fri. Your PIN for the ATM card will be sent by SMS. Questions? See the FAQ on the intranet.*

**译文：**全体新员工：请于星期五前把身份证件、简历和一张护照照片交到人力资源部。银行卡的密码将通过短信发送。有问题吗？请查看内网上的常见问题。
::: solution
缩略语：*ID*——identity document（身份证件，身份证）；*CV*——curriculum vitae（简历；美式英语通常说 *résumé*）；*HR*——human resources（人力资源，人事部门）；*Fri*——Friday（星期五）；*PIN*——personal identification number（个人识别码，密码）；*ATM*——automated teller machine（自动取款机）；*SMS*——short message service（短信服务，短信）；*FAQ*——frequently asked questions（常见问题）。*Photo* 是 *photograph* 的截短词，*intranet*（内网）是用表示“在……内”的前缀 *intra-* 构成的词（一个私有的内部网络）。

改写后的版本：

> *All new staff: please bring your identity card, your curriculum vitae and a passport photograph to the human resources office by Friday. The personal identification number for your bank card will be sent to you by text message. If you have any questions, please read the frequently asked questions page on the company's internal website.*

**译文：**全体新员工：请于星期五前把身份证、简历和一张护照照片交到人力资源部办公室。你的银行卡个人识别码将通过短信发给你。如有任何问题，请阅读公司内部网站上的常见问题页面。

（注意，人们常说 *PIN number*，尽管 *N* 已经表示 *number*；在严谨的写作中，只用 *PIN* 就够了。）
:::
:::

::: exercise 收集缩略形式 {level=3}
用一天时间收集你在英语中遇到的十个缩略形式——在课本里、网站上、标牌上或消息中。为每一个写出完整形式，说明它是截短词、拼缀词、首字母拼音词还是首字母缩略词，说明它怎样读，并说明你是否会在正式邮件中使用它。然后写两句话，谈谈你注意到了什么：哪一类最常见，出现在什么地方？
::: solution

| 形式 | 完整形式 | 类别 | 读作 | 用于正式邮件？ |
|---|---|---|---|---|
| *app* | *application*（应用程序） | 截短词 | /æp/ | 可以（现已是中性词） |
| *Wi-Fi* | ——（商标名称，不是某个短语的缩写） | —— | /ˈwaɪ faɪ/ | 可以 |
| *UK* | *United Kingdom*（英国） | 首字母缩略词 | /ˌjuː ˈkeɪ/ | 可以 |
| *UNESCO* | *United Nations Educational, Scientific and Cultural Organization*（联合国教科文组织） | 首字母拼音词 | /juːˈneskəʊ/ | 可以 |
| *vlog* | *video* + *blog*（视频博客） | 拼缀词 | /vlɒɡ/ | 不可以 |
| *gym* | *gymnasium*（健身房） | 截短词 | /dʒɪm/ | 可以 |
| *ASAP* | *as soon as possible*（尽快） | 首字母缩略词或首字母拼音词 | /ˌeɪ es eɪ ˈpiː/ | 只在某些工作场所可以 |
