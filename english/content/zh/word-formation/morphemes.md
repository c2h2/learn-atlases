王芳在读一篇新闻报道，遇到一个从没见过的词：*unaffordable*。她没有去拿手机查。她看出了三个已经认识的部分——*un-*“不”，*afford*“有足够的钱买”，*-able*“能被……的”——把它们合在一起：“人们没有足够的钱买的”。原句是 *Housing in the city centre has become unaffordable for young families.*（市中心的住房已经让年轻家庭负担不起了。）她的猜测完全吻合。

中国读者时时刻刻都在不假思索地这样做。第一次见到“电动车”，你认识“电”“动”“车”，马上就明白了。英语单词也是由部分构成的，但这些部分比较难看出来：它们不是一个个独立的字，不一定和音节对应，连在一起时拼写还可能改变。本章说明英语单词的构成部分是什么，给它们命名，并讲解怎样稳妥地把一个词拆分成几部分。本课程的其余各章都以此为基础。

词族的核心概念——屈折变化和派生，以及每种词类的常见词尾——已经在 [[core-vocabulary/word-families]] 中介绍过。这里我们更仔细地看看这些部分本身。

## 有意义的最小部分

::: definition 语素 {#def-morpheme}
**语素**（morpheme）是词中具有意义或语法作用的最小部分。它不能再分成仍然有意义的更小部分。

- *cat*（猫）是一个语素。
- *cats*（猫，复数）是两个：*cat* + *-s*（“不止一个”）。
- *unkind*（不友好的）是两个：*un-*（“不”）+ *kind*。
- *unkindness*（不友好）是三个：*un-* + *kind* + *-ness*（构成名词）。
- *teachers*（教师们）是三个：*teach* + *-er*（“做……的人”）+ *-s*（复数）。
:::

检验的标准是意义。*Kind* 不能再分：*k* 和 *ind* 都没有意义。而 *-ness* 之所以是语素，是因为它在几百个词中起同样的作用：*kindness*（友好）、*darkness*（黑暗）、*sadness*（悲伤）、*happiness*（幸福）、*illness*（疾病）。

语素和音节不是一回事。**音节**（syllable）是声音的单位；语素是意义的单位。两者常常不对应：

| 词 | 音节 | 语素 |
|---|---|---|
| *elephant*（大象） | 3（*el-e-phant*） | 1 |
| *cats*（猫，复数） | 1 | 2（*cat* + *-s*） |
| *walked* /wɔːkt/（走了） | 1 | 2（*walk* + *-ed*） |
| *helpful*（有帮助的） | 2（*help-ful*） | 2（*help* + *-ful*） |
| *banana*（香蕉） | 3 | 1 |
| *unhappiness*（不幸福） | 4 | 3（*un-* + *happy* + *-ness*） |

*Elephant* 和 *banana* 是没有构成部分的长词：它们的任何一部分单独都没有意义。*Walked* 是有两个部分的短词：词尾 *-ed* 在这里没有增加音节，却增加了一个意义——“在过去”。

::: quiz
*rewritten*（重写过的）有几个语素？
- [ ] 1
- [ ] 2
- [x] 3
- [ ] 4
::: solution
三个：*re-*（“再，重新”）+ *write* + *-en*（过去分词词尾，如 *taken*、*eaten*）。加 *-en* 时 *write* 末尾的 *e* 去掉了，*t* 双写了，但拼写变化并不增加或减少语素。这个词恰好也有三个音节（*re-writ-ten*），但那只是巧合：要数的是意义，而不是音节。
:::
:::

## 自由语素和粘着语素

有些语素能单独作为词使用。另一些只能和别的成分连在一起出现。

::: definition 自由语素和粘着语素 {#def-free-bound}
**自由语素**（free morpheme）能单独作为一个词使用：*kind*（友好的）、*book*（书）、*help*（帮助）、*happy*（快乐的）、*the*。**粘着语素**（bound morpheme）不能单独出现，必须附着在另一个语素上：*un-*、*re-*、*-ness*、*-ful*、*-s*、*-ed*。
:::

大多数前缀和后缀是粘着的。但有些**词根**也是粘着的。看看下面这些词：

- *receive*（收到）、*perceive*（察觉）、*deceive*（欺骗）、*conceive*（构想）
- *reception*（接待）、*perception*（感知）、*deception*（欺骗）、*conception*（概念）

它们显然有一个共同的部分 *-ceive*（在 *-ion* 前是 *-cept-*），前缀 *re-*、*per-*、*de-* 和 *con-* 也都很眼熟。但 *ceive* 不是英语单词。它来自拉丁语动词 *capere*“拿，取”，只出现在较长的词里面。它是一个**粘着词根**。[[word-formation/greek-latin-roots]] 一章讲的就是这样的词根。

::: definition 词根、词缀、前缀、后缀和基础 {#def-root-affix}
- **词根**（root）是词的核心，承载词的主要意义的语素：*unkindness* 中的 *kind*，*unhelpful* 中的 *help*，*receive* 中的 *-ceive*。
- **词缀**（affix）是加在词根或更大的词上的粘着语素。词根前面的词缀是**前缀**（prefix）：*un-*、*re-*、*dis-*。词根后面的词缀是**后缀**（suffix）：*-ness*、*-ful*、*-ly*。
- **基础**（base）是词缀所加上去的那个部分。它可以是词根（*kindness* 中的 *kind*），也可以是已经带有词缀的词（*unkindness* 中的 *unkind*；*helpfulness* 中的 *helpful*）。有些书把基础叫作**词干**（stem）。
:::

我们把前缀写成后面带连字符的形式（*un-*），把后缀写成前面带连字符的形式（*-ness*），以表示它们附着在哪一边。连字符不是拼写的一部分：写作 *unkind*，而不是 *un-kind*。

大多数英语单词只有一个词根。**复合词**有两个或更多词根：*bookshop*（书店）是 *book* + *shop*，*bookshops* 是 *book* + *shop* + *-s*。复合词是 [[word-formation/compounds]] 的内容。

::: quiz
哪个词含有**粘着词根**——本身不是英语单词的词根？
- [ ] *careless*
- [ ] *unhappy*
- [x] *inspect*
- [ ] *rebuild*
::: solution
*Inspect*（检查）是 *in-*“向内”+ *spect*“看”（来自拉丁语 *specere*，如 *spectator* 观众、*respect* 尊重、*prospect* 前景）。*Spect* 本身不是词，所以它是粘着词根。其他几个词的词根——*care*（关心）、*happy*（快乐的）、*build*（建造）——都是自由的。
:::
:::

## 屈折变化和派生

词末的粘着语素起两种截然不同的作用。你在 [[core-vocabulary/word-families#def-inflection-derivation]] 中已经见过这种区别：**屈折变化**（inflection）表示语法，仍是同一个词；**派生**（derivation）构成新词。英语只有八个屈折后缀：

| 屈折后缀 | 作用 | 例子 |
|---|---|---|
| *-s* | 名词复数 | *books*（书，复数） |
| *-'s* | 所有格 | *Anna's*（安娜的） |
| *-s* | 动词一般现在时第三人称单数 | *works*（工作） |
| *-ed* | 过去式 | *worked* |
| *-ed* / *-en* | 过去分词 | *worked*、*taken* |
| *-ing* | 动词的 -ing 形式 | *working* |
| *-er* | 比较级 | *faster*（更快的） |
| *-est* | 最高级 | *fastest*（最快的） |

其他所有词缀都是派生词缀，包括英语的全部前缀。遇到一个新词时，怎样区分这两类？下面四个检验方法有帮助。

::: theorem 区分屈折变化和派生的四个检验 {#rule-four-tests}
1. **词类。** 派生可以改变词类（形容词 *kind* → 名词 *kindness*；动词 *teach* → 名词 *teacher*）。屈折变化从不改变词类：*books* 仍是名词，*worked* 仍是动词。
2. **范围。** 屈折词尾几乎能加在该词类的每一个词上：几乎每个可数名词都有复数，几乎每个动词都有过去式。派生词缀则有选择性：我们说 *kindness* 和 *sadness*，却不说 ✗ *goodity* 或 ✗ *happity*。
3. **顺序。** 屈折词尾在最后。在 *teachers* 中，复数 *-s* 在派生后缀 *-er* 之后；✗ *teachser* 是不可能的。派生词缀在里面，更靠近词根。
4. **语法。** 屈折词尾常常是句子所要求的：*She work___ here* 必须是 *works*。派生词缀是对词的选择，而不是语法的要求。
:::

::: proof
这些检验来自两类词缀各自的用途。屈折词尾给出一个已有的词的语法形式，所以凡是可能需要这个形式的词都必须能用它，而且它不能改变这个词的类别。派生词缀构成一个新词，这个新词作为独立的词进入词典；某个新词是否存在，部分取决于历史和使用习惯，所以使用范围参差不齐。这些检验对英语是可靠的，因为英语的屈折词尾很少。在别的情况下它们只是倾向：少数派生词缀，例如加在形容词后面的 *-ly*，几乎和屈折词尾一样规则，因此有些语法学家把 *-ly* 和屈折变化放在一起讨论。不过学习型词典仍然把 *quickly* 列为和 *quick* 不同的另一个词。
:::

有两个词尾两类都属于。要看它的作用，而不是看它的形式。

- *-er*：在 *taller*（更高的）、*faster*（更快的）中是比较级（屈折变化）；在 *teacher*（教师）、*driver*（司机）、*printer*（打印机）中构成名词（派生）。
- *-ing*：在 *She is building a house*（她正在建一座房子）中是动词的 -ing 形式（屈折变化）；在 *a tall building*（一座高楼）中是名词的一部分，*building*“房子、办公楼等建筑物”甚至有自己的复数 *buildings*（派生）。

::: example 屈折变化还是派生？ {#ex-which-ending}
判断每个加粗的词尾是屈折词尾还是派生后缀，并说明理由。

1. *The new print**er** is faster than the old one.*（新打印机比旧的快。）
2. *This road is wid**er** than ours.*（这条路比我们那条宽。）
3. *She has three sister**s**.*（她有三个姐妹。）
4. *We had a long meet**ing** this morning.*（今天上午我们开了一个很长的会。）
5. *They are meet**ing** us at the station.*（他们会到车站接我们。）
::: solution
1. *printer*：派生。*-er* 把动词 *print*（打印）变成名词“打印的机器”（检验1：词类改变了）。
2. *wider*：屈折变化。*-er* 是形容词 *wide*（宽的）的比较级；*wider* 仍是形容词（检验1），而且几乎每个短形容词都有这个形式（检验2）。第1句中的 *faster* 也是屈折变化。
3. *sisters*：屈折变化，名词的复数。
4. *meeting*：派生。*A long meeting* 中的 *meeting* 是名词（它跟在 *a long* 后面，并有复数 *meetings*）。
5. *meeting*：屈折变化。*Are meeting* 是动词 *meet* 的现在进行时。
:::
:::

## 一个语素，几种形式

复数词尾写作 *-s* 或 *-es*，但有三种不同的读音。

::: definition 语素变体 {#def-allomorph}
**语素变体**（allomorph）是同一个语素的不同形式之一。复数语素在口语中有三个变体：*cats* /kæts/（猫）中的 /s/，*bags* /bæɡz/（包）中的 /z/，*buses* /ˈbʌsɪz/（公共汽车）中的 /ɪz/。表示“不”的前缀 *in-* 在书面上有 *in-*、*im-*、*il-* 和 *ir-* 几个变体：*incorrect*（不正确的）、*impossible*（不可能的）、*illegal*（违法的）、*irregular*（不规则的）。
:::

选用哪个变体并不是随意的，它取决于词尾前面的那个音。

::: theorem *-s* 和 *-ed* 的读音 {#rule-s-ed}
词尾 *-s*（复数、所有格和第三人称单数）和 *-ed*（过去式和过去分词）的读音取决于基础的最后一个音：

| 基础的最后一个音 | *-s* | *-ed* |
|---|---|---|
| /s/、/z/、/ʃ/、/ʒ/、/tʃ/、/dʒ/ | /ɪz/：*buses*、*wishes*（愿望）、*watches*（手表）、*judges*（法官） | 同下面几行：*wished* 读 /t/，*judged* 读 /d/ |
| /t/、/d/ | 同下面几行：*cats* 读 /s/，*beds* 读 /z/ | /ɪd/：*wanted*（想要）、*needed*（需要） |
| 其他清音（/p/、/k/、/f/、/θ/ ……） | /s/：*cups*（杯子）、*books*、*laughs*（笑） | /t/：*helped*（帮助）、*looked*（看）、*laughed* |
| 其他浊音（/b/、/ɡ/、/m/、/l/、元音……） | /z/：*jobs*（工作）、*bags*、*days*（天）、*pens*（笔） | /d/：*robbed*（抢劫）、*played*（玩）、*called*（叫） |
:::

::: proof
当词尾很难听出来时，就需要加上元音 /ɪ/：在咝音后面，再加一个 /s/ 或 /z/ 会和它融在一起（*bus* + /z/）；在 /t/ 或 /d/ 后面，表示过去的 /t/ 或 /d/ 会消失。在其他情况下，词尾只需在清浊上和前面的音保持一致——清音后用清音，浊音后用浊音——这比清浊混在一起好发。拼写完全不显示这些：三种变体的 *-s* 和 *-ed* 写法都一样。GB 和 GA 遵循同样的规则；有些人，特别是在美国，说 /əz/ 和 /əd/，而不是 /ɪz/ 和 /ɪd/。[[sounds-of-english/syllables-clusters]] 练习这些词尾构成的辅音连缀。
:::

::: warning 给 *-ed* 多加一个音节
许多学习者把每个 *-ed* 都读成单独的一个音节：把 *walked* 读成 ✗ /ˈwɔːkɪd/，把 *plugged* 读成 ✗ /ˈplʌɡɪd/。✓ *walked* /wɔːkt/ 和 *plugged* /plʌɡd/（插上插头了）都只有一个音节。只有以 /t/ 或 /d/ 结尾的动词才多出一个音节：*wanted* /ˈwɒntɪd/（GB），/ˈwɑːntɪd/（GA），*needed* /ˈniːdɪd/。*-s* 也一样：*likes* 读 /laɪks/，一个音节，不是 ✗ /ˈlaɪkɪz/。
:::

## 把词拆分成语素

要把一个长词拆分成语素，应从外向里拆，并检查每一部分。

::: theorem 怎样拆分一个词 {#rule-split}
1. **去掉词末的屈折词尾**（*-s*、*-ed*、*-ing*、*-er*、*-est*）。它总是最后一个语素。
2. **从词尾开始，一次去掉一个后缀**，每次都问：剩下的部分是不是你认识的词或词根？*carelessly* → *careless* + *-ly* → *care* + *-less* + *-ly*。
3. **从词首去掉前缀**：*unhelpful* → *un-* + *helpful*。
4. **核查基础之前，先还原拼写变化**：*happiness* → *happi* + *-ness*，而 *happi* 就是把 *y* 变成 *i* 的 *happy*；*hoping* → *hop(e)* + *-ing*。
5. **核查意义。** 每一部分都必须有意义，而且这个意义要对整个词的意义有所贡献。如果某一部分没有意义，或者各部分的意义加起来不等于整个词的意义，那么它在这个词里就不是语素。
:::

第5步最重要，也是学习者最常忘记的一步。*Carpet*（地毯）里有 *car* 和 *pet* 的字母，但它们都和 *carpet* 的意义毫无关系：它是一个语素。*butterfly*（蝴蝶）的情况又不一样：*butter*（黄油）和 *fly*（苍蝇；飞）是真正的语素，也是真正的词，但谁也不能由它们推出“一种有大翅膀的美丽昆虫”。语言学家仍把 *butterfly* 算作由两个语素构成的复合词，因为它是由两个词构成的；但对学习者来说，它必须作为一个整体来学。[[word-formation/learning-with-word-formation]] 会再讨论这类陷阱。

下图显示一个有三个语素的词的结构。每个箭头表示“由……构成”。

::: widget graph
nodes: unhappiness@0,4; unhappy@-2,2; -ness@2,2; un-@-3,0; happy@-1,0
edges: unhappiness>unhappy; unhappiness>-ness; unhappy>un-; unhappy>happy
caption: *unhappiness*（不幸福）的结构。先把 *un-* 加在形容词 *happy* 上，得到形容词 *unhappy*；然后 *-ness* 把这个形容词变成名词。这个词是一层一层构成的，而不是一步构成的。可以拖动这些词，重新排列这棵树。
:::

为什么是这个顺序，而不是 *un-* + *happiness*？因为 *un-* 主要加在形容词（*unkind* 不友好的、*unusual* 不寻常的、*unfair* 不公平的）和动词（*untie* 解开、*unlock* 开锁）上，只加在少数名词上。*Unhappy* 是一个词；然后 *-ness* 由它构成名词。层次的顺序可以改变一个词的意义，下面的例子就说明了这一点。

::: example 一个词，两种结构 {#ex-unlockable}
*unlockable* 是什么意思？用两种不同的方式拆分它，并解释两种意义。
::: solution
语素是 *un-* + *lock* + *-able*。它们可以按两种顺序组合。

1. 先 *lock* + *-able* = *lockable*“能被锁上的”；然后 *un-* + *lockable* =“**不**能被锁上的”。这里 *un-* 的意思是“不”，和用在形容词前一样：*This old door is unlockable — the lock is broken.*（这扇旧门锁不上——锁坏了。）
2. 先 *un-* + *lock* = 动词 *unlock*“用钥匙打开”；然后 *unlock* + *-able* =“能被**打开**的”。这里 *un-* 的意思是“做相反的动作”，和用在动词前一样：*The phone is unlockable with your fingerprint.*（这部手机可以用指纹解锁。）

所以同样三个语素，根据哪一层在先，会得出相反的意义。在实际的文本中由上下文决定；上下文不能使意义清楚时，细心的作者会避免用这个词。
:::
:::

::: example 数语素 {#ex-count}
把每个词拆分成语素，说出每个语素的名称（词根、前缀、派生后缀或屈折词尾），并给出总数。

1. *disagreements*（分歧，复数）
2. *carelessly*（粗心地）
3. *rebuilt*（重建了）
4. *nationalities*（国籍，复数）
::: solution
1. *dis-*（前缀，“不”）+ *agree*（词根）+ *-ment*（派生后缀，构成名词）+ *-s*（屈折词尾，复数）= **4**。
2. *care*（词根）+ *-less*（派生后缀，“没有”）+ *-ly*（派生后缀，构成副词）= **3**。
3. 从词的构成部分来看是 *re-*（前缀，“再”）+ *built* = **2**。*Built* 是 *build* 的过去式，但过去是靠把 *d* 变成 *t* 来表示的，而不是加上一个单独的部分；我们把它算作 *build* + 过去时，所以语言学家会说 *re-* + *build* + 过去时 = 3个语素。只要说明理由，两种答案都可以接受。
4. *nation*（词根）+ *-al*（派生后缀，构成形容词）+ *-ity*（派生后缀，构成名词）+ *-s*（屈折词尾，复数；*y* 在 *-s* 前变成 *ie*）= **4**。

第3题说明，语素不一定有自己的一段拼写。不规则的过去式 *took*、*ran*、*went* 也各含两个语素——一个动词和“过去”——却没有可以切下来的词尾。
:::
:::

::: example 词内部的拼写变化 {#ex-spelling-inside}
拆分下面的词，并还原拼写变化：*happiness*（幸福）、*making*（制作）、*stopped*（停止了）、*possibility*（可能性）。
::: solution
- *happiness* = *happy* + *-ness*：在后缀前 *y* 变成 *i*。
- *making* = *make* + *-ing*：在元音前去掉末尾的 *e*。
- *stopped* = *stop* + *-ed*：在重读短元音后双写末尾的辅音字母 *p*。
- *possibility* = *possible* + *-ity*：在 *-ity* 前 *-ble* 变成 *-bil-*（还有 *able* → *ability* 能力，*visible* → *visibility* 能见度）。

这些变化都有规则，[[word-formation/spelling-changes]] 会讲解。拆分词时要预料到它们，不要把 *happi* 或 *mak* 当成新的词根。
:::
:::

::: note 英汉对比
中国读者在语素方面有先天的优势，因为汉字把大多数语素都显示出来了。在大多数汉语词中，每个字都是一个音节、一个语素：电脑是“电”+“脑”，火车是“火”+“车”，学生是“学”+“生”。也有例外——葡萄、蝴蝶、咖啡和沙发是两个字却只有一个语素，因为在这些词里两个字单独都没有意义——但总的对应关系很强。中国语言学家把 morpheme 叫作“语素”（有些较早的书叫“词素”）。

英语里没有这种对应。一个语素可能是一个音节的一部分（*cats* 的 *-s*），可能是一个音节（*un-*），也可能是好几个音节（*elephant*），而书面上没有任何东西显示一个语素在哪里结束、下一个从哪里开始。所以寻找构成部分的习惯是有用的，但必须根据意义来找，而不是根据字母或音节。另一个大的区别是屈折变化：汉语几乎没有屈折变化（“们”只用于人，而且常常省略；“了”“着”“过”是单独的助词，不是动词的一部分），所以英语的小词尾 *-s* 和 *-ed* 很容易被忘掉。它们和其他语素一样是语素，也承载意义：对听者来说，*book* 和 *books* 的意思不同。
:::

::: warning 按字母而不是按意义拆分
不要只因为某些片段看起来像词或词缀，就把一个词拆成这些片段。

- *carpet*（地毯）不是 *car* + *pet*；*season*（季节）不是 *sea* + *son*；*discuss*（讨论）里没有表示“不”的 *dis-*。
- *deliver*（递送）跟 *liver*（肝）毫无关系，*pineapple*（菠萝）也不是一种 *apple*（苹果）。
- *island*（岛）是一个语素：它的 *s* 是在十六世纪加进拼写里的，因为人们把这个词和 *isle*（小岛）联系在一起，而 *isle* 是另一个词，两者来源并不相同。

如果各个片段的意义加起来不等于这个词的意义，这些片段在这个词里就不是语素。
:::

::: history
词由有意义的部分构成，这个观念非常古老：两千多年前，梵语语法学家波你尼（Pāṇini）就把词分析成词根和词缀。**语素**这个术语是波兰语言学家博杜恩·德·库尔特内（Jan Baudouin de Courtenay）在十九世纪后期提出的。美国语言学家布龙菲尔德（Leonard Bloomfield）在《语言论》（*Language*，1933年）中把语素定义为在语音和意义上与任何其他形式都没有部分相似之处的形式——也就是不能再分成有意义的部分的形式，从此语素成为英语研究的核心概念。鲍尔、利伯和普拉格的《牛津英语形态学参考指南》（*The Oxford Reference Guide to English Morphology*，2013年）等现代英语词结构的描述仍然从这个单位出发，同时讨论 *went* 和 *cranberry*（蔓越莓）这样的难题——*cranberry* 中的 *cran-* 不出现在任何其他英语单词中。
:::

## 后续内容

接下来的几章更详细地考察语素本身：[[word-formation/prefixes]] 和 [[word-formation/suffixes]] 描述承担大部分构词工作的词缀，[[word-formation/compounds]] 讨论有两个词根的词，[[word-formation/greek-latin-roots]] 讨论 *spect* 和 *-ceive* 这样的粘着词根。[[word-formation/spelling-changes]] 讲解 *happiness* 和 *stopped* 背后的规则。关于 *-s* 和 *-ed* 在快速语流中的读音，见 [[sounds-of-english/syllables-clusters]]；关于作为语言学一个分支的形态学，见 [[linguistics/morphology]]。

::: summary
- **语素**是词中具有意义或语法作用的最小部分：*un-* + *kind* + *-ness*。
- 语素是意义的单位，而不是声音的单位：*elephant* 有三个音节、一个语素；*cats* 有一个音节、两个语素。
- **自由**语素本身可以成词（*kind*）；**粘着**语素不能（*un-*、*-ness*，以及 *-ceive* 这样的粘着词根）。
- 一个词有一个**词根**，前面可以有**前缀**，后面可以有**后缀**；词缀加在**基础**上，而基础本身可能已经带有词缀。
- **屈折词尾**（英语只有八个）表示语法，从不改变词类，总在最后；**派生**词缀构成新词。
- 一个语素可以有几种形式（**语素变体**）：复数的 /s/、/z/、/ɪz/；*in-*、*im-*、*il-*、*ir-*。
- 从外向里拆分一个词，还原拼写变化，并核查每一部分都增添了意义；*carpet* 不是 *car* + *pet*。
:::

::: exercise 自由的还是粘着的？ {level=1}

1. ***kind**ness*（友好）
2. *re**write***（重写）

4. *book**s***（书，复数）
5. *in**spect***（检查）
6. ***friend**ship*（友谊）

1. *kind*：自由的（它是一个词）。
2. *write*：自由的。
3. *dis-*：粘着的（前缀）。
4. *-s*：粘着的（屈折词尾）。
5. *spect*：粘着的（本身不是英语单词的词根）。

::: exercise 屈折变化还是派生？ {level=2}
加粗的词尾是屈折词尾还是派生后缀？

1. *My bag is heavi**er** than yours.*（我的包比你的重。）
2. *He works as a cleaner in a hotel; the clean**er** comes at six.*（他在一家旅馆当清洁工；清洁工六点来。）
3. *I love the paint**ing** above your sofa.*（我很喜欢你沙发上方的那幅画。）
4. *She's paint**ing** the kitchen.*（她正在粉刷厨房。）
5. *The play**er**s are tired after the match.*（比赛结束后队员们都累了。）
::: solution
1. 屈折变化（*heavy* 的比较级）。
2. 派生：*cleaner* 是名词，“做清洁的人”。
3. 派生：*painting* 在这里是名词（“画”），有复数 *paintings*。
4. 屈折变化：现在进行时中的 -ing 形式。
5. 派生：*-er* 把动词 *play* 变成名词 *player*（队员）。它后面的 *-s* 是屈折词尾（复数）——而且在最后，屈折词尾总是这样。
:::
:::

::: exercise 读出词尾 {level=2}
词尾读 /s/、/z/ 还是 /ɪz/（*-s*），读 /t/、/d/ 还是 /ɪd/（*-ed*）？

*maps*（地图）、*boxes*（盒子）、*trees*（树）、*washed*（洗了）、*started*（开始了）、*opened*（打开了）、*clothes*（衣服）、*pages*（页）
::: hint
看基础的最后一个**音**，而不是最后一个字母。*Box* 以音 /ks/ 结尾。
:::
::: solution
- *maps* /mæps/：/s/（在清音 /p/ 后）。
- *boxes* /ˈbɒksɪz/（GB），/ˈbɑːksɪz/（GA）：/ɪz/（在 /s/ 后）。
- *trees* /triːz/：/z/（在元音后）。
- *washed* /wɒʃt/（GB），/wɑːʃt/（GA）：/t/（在清音 /ʃ/ 后）。
- *started* /ˈstɑːtɪd/（GB），/ˈstɑːrtɪd/（GA）：/ɪd/（在 /t/ 后）。
- *opened* /ˈəʊpənd/（GB），/ˈoʊpənd/（GA）：/d/（在浊音 /n/ 后）。
- *clothes* 不是 *cloth*（布）的复数：它是一个单独的词，“穿的东西”，读 /kləʊðz/（GB），/kloʊðz/（GA），口语中常读 /kləʊz/。*cloth* 的复数是 *cloths* /klɒθs/（GB），/klɔːθs/（GA）。这提醒我们要核查各部分是否真的能相加。

::: exercise 拆分并标注 {level=2}
把每个词拆分成语素，并把每个语素标为词根（R）、前缀（P）、派生后缀（D）或屈折词尾（I）。

*misunderstood*（误解了）、*employers*（雇主，复数）、*unfriendliness*（不友好）、*rethinking*（重新考虑）
::: solution
- *mis-*（P）+ *understood*（R + I：*understand* + 过去分词；*understood* 没有可以分开的词尾）。许多学习者还在 *understand* 里看到 *under* + *stand*，但它的意义不能由这两部分构成，所以对学习者来说它是一个词根。
- *employ*（R）+ *-er*（D）+ *-s*（I）。
- *un-*（P）+ *friend*（R）+ *-ly*（D，构成形容词 *friendly*）+ *-ness*（D；*y* → *i*）。四个语素。
- *re-*（P）+ *think*（R）+ *-ing*（I）。
:::

::: exercise 真正的构成部分还是假的？ {level=3}
说出每个词括号中的片段是不是它真正的语素。解释你的答案，有真正的分析时请给出。

1. *rebuild*（*re-* + *build*）
2. *report*（*re-* + *port*）
3. *carpet*（*car* + *pet*）
4. *teacher*（*teach* + *-er*）
5. *corner*（*corn* + *-er*）
6. *uncover*（*un-* + *cover*）
::: hint
问两个问题：每个片段在别处有没有意义？对今天说英语的人来说，这些意义加起来是不是整个词的意义？
:::
::: solution
1. 是：*re-*“再”+ *build*“建造”；*rebuild* 的意思是“重建”。
2. 从历史上看是——拉丁语 *re-*“回”+ *portare*“携带”；*report*（报告）就是把消息“带回来”——而且 *port* 也出现在 *transport*（运输）、*export*（出口）、*import*（进口）中。但这里的 *re-* 不是“再”的意思，词义也不能由各部分推出。这类词算不算两个语素，语言学家有不同看法；对学习者来说，*report* 最好作为一个词来学，同时注意词根 *port*，作为记忆的帮助（[[word-formation/greek-latin-roots]]）。
3. 不是：*carpet*（地毯）是一个语素。*car* 和 *pet* 都对它的意义没有贡献。
4. 是：*teach* + *-er*“教书的人”。
5. 不是：*corner*（角落）并不是“做 corn 的人或物”。*Corner* 是一个语素。字母 *-er* 并不总是后缀 *-er*：比较 *water*（水）、*paper*（纸）、*never*（从不）。
6. 是：*un-*“做相反的动作”+ *cover*“盖上”；*uncover* 的意思是“揭开盖子”，因而也指“发现隐藏的东西”。
:::
:::

::: exercise 给同学讲解一个词 {level=3}
从下面的词中选两个：*unbreakable*、*disagreement*、*rewritable*、*carelessness*。为每个词写三四句话，向同学说明这个词是怎样构成的、是什么意思。用上 *root*、*prefix*、*suffix* 和 *base* 这几个术语（词根、前缀、后缀、基础），按正确的顺序显示各个层次，最后用你自己的一个例句结尾。
::: solution
参考答案（你的措辞可以不同）：

- *unbreakable*（打不破的）：词根是动词 *break*（打破）。先加后缀 *-able*，得到形容词 *breakable*“能被打破的”。然后在这个基础上加前缀 *un-*“不”，得到 *unbreakable*“不能被打破的”。（*un-* + *break* 行不通，因为 *unbreak* 不是一个词。）例句：*These plates are unbreakable, so they are good for children.*（这些盘子摔不碎，所以适合孩子用。）
- *disagreement*（分歧）：词根是动词 *agree*（同意）。前缀 *dis-*“不”构成动词 *disagree*（不同意），后缀 *-ment* 把这个动词变成名词。例句：*There was a small disagreement about the price.*（在价格上有一点分歧。）
- *rewritable*（可重写的）：词根是 *write*（写）。*re-*“再”构成 *rewrite*（重写），*-able* 构成 *rewritable*“能被重写的”；在 *-able* 前 *write* 的 *e* 去掉了。例句：*This disc is rewritable.*（这张光盘可以重复刻录。）
- *carelessness*（粗心）：词根是 *care*（小心）。*-less*“没有”构成形容词 *careless*（粗心的），*-ness* 构成名词。例句：*The accident was caused by carelessness.*（这次事故是粗心造成的。）

检查你自己的答案：每一层都必须是真正的词（*breakable*、*disagree*、*rewrite*、*careless*），每个后缀构成的词类都必须是下一层所需要的。
:::
:::
