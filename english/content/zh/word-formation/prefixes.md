张磊在帮朋友搬家，他拿起一罐稀释剂，上面贴着一个大大的红色标签：*HIGHLY INFLAMMABLE*。他知道 *in-* 的意思是“不”——*incorrect*（不正确的）、*incomplete*（不完整的）、*invisible*（看不见的）——于是认定这罐东西放在灶台旁边是安全的。他错了，而且错得很危险。*Inflammable* 的意思是“易燃的”，和 *flammable* 完全一样。它的 *in-* 是另一个前缀，意思是“在内，进入”：易燃的东西会“进入火焰”。

前缀是学习者所能掌握的最有用的构词部件之一。少数几个前缀出现在成千上万个词里，意义通常清楚而稳定。但正如张磊所发现的，同样的拼写可能隐藏着两个不同的前缀，而一个看起来眼熟的前缀，也不一定在起它通常的作用。本章按意义列出常见的前缀——否定、逆转、错误、程度、时间、数量和地点——说明怎样在几个否定前缀之间做出选择，并指出其中的陷阱。

基本术语（语素、前缀、基础、粘着）在 [[word-formation/morphemes]] 中讲解过。[[core-vocabulary/word-families]] 中有一张简短的前缀表。

## 前缀的作用

::: definition 前缀 {#def-prefix}
**前缀**（prefix）是放在基础前面的词缀。它给基础增添一个意义——“不”“再”“在……之前”“过度”——构成一个新词：*happy* → *unhappy*（快乐的 → 不快乐的），*write* → *rewrite*（写 → 重写），*war* → *pre-war*（战争 → 战前的），*eat* → *overeat*（吃 → 吃得过多）。
:::

::: theorem 前缀通常不改变词类 {#rule-prefix-class}
在英语中，前缀通常改变词的**意义**，而不改变它的**词类**：*happy* 和 *unhappy* 都是形容词，*write* 和 *rewrite* 都是动词，*market*（市场）和 *supermarket*（超市）都是名词。决定词类的通常是词末的后缀（[[word-formation/suffixes]]）。

少数前缀是例外。*En-*（在 *b* 和 *p* 前写作 *em-*）和 *be-* 构成动词：*large* → *enlarge*（大的 → 扩大），*danger* → *endanger*（危险 → 危及），*power* → *empower*（权力 → 授权），*friend* → *befriend*（朋友 → 与……交朋友）。*Out-* 通常不改变词类，但会改变动词的用法（见 [[#ex-out]]）。
:::

所以遇到一个带前缀的词时，要问的问题是：“这个前缀增添了什么意义？”大多数前缀读得很轻或不重读——*un**HAP**py*、*re**WRITE***、*mis**LEAD***（误导）——或者带次重音（*ˌoverˈeat*）。重音留在基础上，这也是带前缀的词听起来容易懂的原因之一：熟悉的部分正是读得重的部分。（关于重音，见 [[sounds-of-english/word-stress-basics]]。）

## 否定前缀：*un-*、*in-*、*dis-*、*non-*

有四个前缀表示“不”或“相反”。它们一起构成了成千上万个词。

| 前缀 | 主要加在 | 例子 |
|---|---|---|
| *un-* | 形容词（包括以 *-able*、*-ed*、*-ing* 结尾的形容词）、少数名词 | *unhappy*（不快乐的）、*unfair*（不公平的）、*unusual*（不寻常的）、*unable*（不能的）、*unexpected*（意外的）、*unwilling*（不情愿的）、*unrest*（动荡） |
| *in-*（*im-*、*il-*、*ir-*） | 来自拉丁语或法语的形容词 | *incorrect*（不正确的）、*invisible*（看不见的）、*impossible*（不可能的）、*illegal*（违法的）、*irregular*（不规则的） |
| *dis-* | 动词、名词和形容词 | *disagree*（不同意）、*dislike*（不喜欢）、*disorder*（混乱）、*dishonest*（不诚实的）、*disloyal*（不忠的） |
| *non-* | 名词和形容词 | *non-smoker*（不吸烟者）、*non-fiction*（非虚构作品）、*non-stop*（不停的）、*non-urgent*（不紧急的） |

::: theorem 选择否定前缀 {#rule-negative}
1. **每个否定词都要照原样学。** 选用哪个前缀是由用法固定下来的，而不是由一条总能套用的规则决定的：我们说 *unhappy*，却说 *impossible*；说 *dishonest*，却说 *unkind*（不友好的）。学习型词典会给出每个形容词的反义词。
2. **需要一个新词时，形容词用 *un-* 最稳妥**，名词以及表示“不属于这一类”时用 *non-*：*unaffordable*（负担不起的）、*unshareable*（不能分享的）、*non-member*（非会员）、*non-native*（非母语的）。
3. ***In-* 在某些辅音前改变形式**：在 *p*、*b*、*m* 前写作 *im-*（*impatient* 不耐烦的、*imbalance* 不平衡、*immature* 不成熟的），在 *l* 前写作 *il-*（*illegal* 违法的、*illogical* 不合逻辑的），在 *r* 前写作 *ir-*（*irregular* 不规则的、*irresponsible* 不负责任的），其他情况下写作 *in-*（*inactive* 不活跃的、*incorrect* 不正确的、*informal* 非正式的）。现在几乎不再用 *in-* 构成新词。
4. ***Un-* 和 *non-* 的意义可能不同。** *Non-* 是中性的：“不属于这一类”。*Un-* 常常带有评判：“不像应有的那样”。一本 *non-scientific* 的书讲的是科学以外的东西；一个 *unscientific* 的论证是不科学的、站不住的论证。*non-professional* 是指不以此为职业的人；*unprofessional* 的行为是达不到职业标准的行为。
:::

::: proof
这种格局来自历史。*Un-* 是英语本族的前缀：古英语里就已经有了，而且一直被用来构成新词。*In-* 是随着从拉丁语和法语借来的词进入英语的，主要在中古英语和早期现代英语时期，它一直附着在这类词上：*im-*、*il-*、*ir-* 是拉丁语的拼写，其中的 *n* 已经变得和后面的辅音相同。对词典和语料库中构词现象的研究（Bauer 1983；Plag 2018；Bauer, Lieber & Plag 2013）一致认为，*un-* 和 *non-* 具有能产性——仍被用来构成新词——而 *in-* 的能产性至多是很有限的：现代英语中新的否定形容词几乎总是用 *un-* 或 *non-*。*Dis-* 来自拉丁语，经由法语进入英语，现在仍在使用，主要和动词搭配。由于这四个前缀是在不同时期随着不同的词进入英语的，对于已有的词，没有一条单一的规则能决定用哪一个。
:::

::: quiz
哪一个**不是**真正的英语单词？
- [ ] *unhappy*
- [ ] *impolite*
- [x] *inhappy*
- [ ] *dishonest*
::: solution
不存在 *inhappy* 这个词。*happy* 的反义词是 *unhappy*：*happy* 是一个来源于日耳曼语的词（来自 *hap*“运气”，这个词借自古诺尔斯语），它用本族前缀 *un-*。*Impolite*（不礼貌的；*in-* 在 *p* 前变成 *im-*）和 *dishonest*（不诚实的）都是标准的词。
:::
:::

::: example 选择否定前缀 {#ex-negative}
用 *un-*、*in-*（*im-*、*il-*、*ir-*）、*dis-* 或 *non-* 构成括号中词的反义词，完成句子，并说明你为什么这样选择。

1. *Parking here is ___ (legal); you may get a fine.*（在这里停车是违法的，你可能会被罚款。）
2. *I'm afraid I ___ (agree) with you.*（恐怕我不同意你的看法。）
3. *The fruit is still green — it's ___ (ripe).*（这水果还是青的——没熟。）
4. *This is a ___ (smoking) hotel.*（这是一家禁烟酒店。）
5. *His handwriting is completely ___ (readable).*（他的字迹完全看不清。）
6. *She was very ___ (patient) with the slow waiter.*（她对那个慢吞吞的服务员很不耐烦。）
::: solution
1. *illegal*——*legal* 是来自拉丁语的形容词，用 *in-*，在 *l* 前变成 *il-*。
2. *disagree*——*dis-* 是和动词搭配的常用否定前缀。
3. *unripe*——*ripe* 是本族形容词；通常用 *un-*。
4. *non-smoking*——*non-* 表示“不属于这一类”：不允许吸烟的酒店。（没有 *unsmoking* 这个词。）
5. *unreadable*——由英语动词构成的 *-able* 形容词几乎总是用 *un-*（*unbreakable* 打不破的、*unbelievable* 难以置信的）。注意：说字迹时 *illegible*（难以辨认的）也是正确的，但它是另一个词，来自拉丁语 *legibilis*。
6. *impatient*——*patient* 用 *in-*，在 *p* 前变成 *im-*。
:::
:::

## 逆转和去除：*un-*、*de-*、*dis-*

和动词连用时，*un-* 的意义不同。它不表示“不”，而表示“做相反的动作”或“撤销”。

- *tie* → *untie*（系 → 解开），*lock* → *unlock*（锁 → 开锁），*pack* → *unpack*（打包 → 打开行李），*do* → *undo*（做 → 撤销），*zip* → *unzip*（拉上拉链 → 拉开拉链），*fold* → *unfold*（折叠 → 展开）
- *To unpack a suitcase*（打开箱子取出东西）不是“不装箱子”，而是装好以后把东西拿出来。

*De-* 和 *dis-* 也可以表示逆转或去除：

- *de-*：*defrost*（除霜，解冻）、*decode*（解码，把密码变回普通文字）、*deforest*（砍伐森林）、*devalue*（贬值）
- *dis-*：*disconnect*（断开）、*disappear*（消失）、*dislike*（不喜欢）、*disembark*（下船，下飞机）

你在 [[word-formation/morphemes#ex-unlockable]] 中看到，*un-* 的两种意义可以使一个词产生歧义。下图总结了这两种意义。

::: widget graph
nodes: un-@0,4; not (with adjectives)@-3,2; reverse (with verbs)@3,2; unhappy@-4.5,0; unfair@-3,0; unexpected@-1.5,0; untie@1.5,0; unlock@3,0; unpack@4.5,0
edges: un->not (with adjectives); un->reverse (with verbs); not (with adjectives)>unhappy; not (with adjectives)>unfair; not (with adjectives)>unexpected; reverse (with verbs)>untie; reverse (with verbs)>unlock; reverse (with verbs)>unpack
caption: *un-* 的两种意义。用在形容词前（以及用作形容词的分词前，如 *unexpected*）表示“不”（not）；用在动词前表示“做相反的动作”（reverse）。可以拖动这些词，换一种方式分组。
:::

::: quiz
在 *She unfolded the letter and read it*（她展开信读了起来）中，*unfold* 是什么意思？
- [ ] 她没有折这封信。
- [x] 她把折着的信打开了。
- [ ] 她把信又折了一次。
- [ ] 她把信折得不好。
::: solution
*Fold* 是动词，所以 *un-* 表示“做相反的动作”：信原来是折着的，她把它打开了。“没有折”要说 *didn't fold*；“再折一次”是 *refold*；“折得不好”要用 *mis-*，不过 *misfold* 除了在科学领域以外很少用。
:::
:::

## 错误地和不好地：*mis-*、*mal-*

- *mis-*“错误地”：*misunderstand*（误解）、*mispronounce*（读错）、*misspell*（拼错）、*mislead*（误导）、*misprint*（印错）、*misuse*（误用，滥用）。
- *mal-*“不好地”：*malfunction*（故障）、*malnutrition*（营养不良）、*malpractice*（玩忽职守，医疗事故）。*Mal-* 少见得多，大多用于正式或专业的场合。

注意 *misspell* 和 *misspelling* 的拼写：*mis-* + *spell* 得到两个 *s*。同样，*un-* + *natural* 得到 *unnatural*（不自然的），*dis-* + *satisfied* 得到 *dissatisfied*（不满意的）。加前缀时什么也不去掉（[[word-formation/spelling-changes]]）。

## 程度和大小：*over-*、*under-*、*out-*、*super-*、*sub-*

这些前缀说明多少，或者说明某物和另一物在位置上的关系。其中几个既有表示程度的意义，又有表示位置的意义。

| 前缀 | 意义 | 例子 |
|---|---|---|
| *over-* | 过度 | *overeat*（吃得过多）、*oversleep*（睡过头）、*overcrowded*（过于拥挤的）、*overpriced*（要价过高的） |
| | 在上方，越过 | *overhead*（头顶上的）、*overcoat*（大衣）、*overseas*（海外的） |
| *under-* | 不足 | *underpaid*（报酬过低的）、*undercooked*（没煮熟的）、*underestimate*（低估） |
| | 在下方 | *underground*（地下的；地铁）、*underline*（在下面画线）、*underwater*（水下的） |
| *out-* | 比……更多、更好 | *outrun*（跑得比……快）、*outnumber*（在数量上超过）、*outgrow*（长得比……大）、*outlive*（比……活得长） |
| *super-* | 在上；超过一般 | *superhuman*（超人的）、*superstar*（超级明星）、*supermarket*（超市） |
| *sub-* | 在下；低于；部分 | *subway*（地下通道；美式英语的地铁）、*subtitle*（字幕）、*substandard*（低于标准的）、*subgroup*（小组，子群） |

*Over-* 和 *under-* 在表示程度时意义相反：*overpaid* / *underpaid*（报酬过高的 / 过低的），*overestimate* / *underestimate*（高估 / 低估），*overcooked* / *undercooked*（煮过头的 / 没煮熟的）。它们在这个意义上能产性很强：第一次见到 *overthink*（想得过多）、*overshare*（过度分享）或 *underuse*（使用不足），你就能看懂。

::: example 程度还是位置？ {#ex-over-under}
在下面每个句子里，*over-* 或 *under-* 表示程度（“过度”“不足”）还是位置（“在上方”“在下方”）？说出这个词的意思。

1. *The bus was so overcrowded that we waited for the next one.*（公共汽车太挤了，我们等了下一辆。）
2. *Put on your overcoat — it's cold.*（穿上大衣——天冷。）
3. *Nurses here are underpaid.*（这里的护士报酬太低。）
4. *We took the underground to the museum.*（我们坐地铁去了博物馆。）
5. *I think you underestimate how long the journey takes.*（我觉得你低估了路上要花的时间。）
::: solution
1. 程度：*overcrowded*“人太多的”。
2. 位置：*overcoat*“穿在其他衣服外面的外套”，即大衣。
3. 程度：*underpaid*“报酬太低的”。
4. 位置：*underground*“城市地下的铁路”（英式英语；美式英语通常说 *subway*）。
5. 程度：*underestimate*“认为某事物比实际更小、更短或更少”。

一个快速的检验：如果能加上“太”（*too crowded* 太挤，*paid too little* 报酬太低），这个前缀就表示程度。程度意义通常用于形容词、分词和动词；位置意义常出现在名词中（*overcoat*、*underground*、*underwear* 内衣）。
:::
:::

::: example *Out-* 和宾语 {#ex-out}
比较下面的句子。*out-* 增添了什么意义？动词的语法发生了什么变化？

1. *Mia runs fast.*（米娅跑得快。）→ *Mia outran all the other girls.*（米娅跑得比其他所有女孩都快。）
2. *Tom lived to 90.*（汤姆活到了90岁。）→ *Tom outlived his brothers.*（汤姆比他的兄弟们活得都长。）
3. *The students number about 300.*（学生约有300人。）→ *The students outnumber the teachers ten to one.*（学生人数是教师的十倍。）
::: solution
*Out-* 的意思是“比别人更多、更远或更好”。比较需要第二个人或物——被超过的那一方——这一方就成了新动词的**宾语**：

1. *Mia runs fast* 中的 *run* 没有宾语；*outrun* 有宾语：*all the other girls*。*Mia outran them* = 她跑得比她们快。
2. *Outlive his brothers* = 比他的兄弟们活得长。
3. *Outnumber the teachers* = 在数量上超过教师。

所以 *out-* 是一个不寻常的前缀：它不改变词类（动词仍是动词），却把一个没有宾语的动词变成了需要宾语的动词。不能说 ✗ *Mia outran.*
:::
:::

## 时间和顺序：*pre-*、*post-*、*re-*、*ex-*、*fore-*

| 前缀 | 意义 | 例子 |
|---|---|---|
| *pre-* | 在……之前 | *pre-war*（战前的）、*preview*（预览）、*prepay*（预付）、*pre-school*（学龄前的） |
| *post-* | 在……之后 | *post-war*（战后的）、*postgraduate*（研究生）、*postpone*（推迟） |
| *re-* | 再；回 | *rewrite*（重写）、*rebuild*（重建）、*reopen*（重新开放）、*recycle*（回收利用）、*repay*（偿还） |
| *ex-* | 前任的，以前的 | *ex-wife*（前妻）、*ex-president*（前总统）、*ex-colleague*（以前的同事） |
| *fore-* | 预先；在前面 | *forecast*（预报）、*foresee*（预见）、*forehead*（前额） |

*Re-* 是英语中能产性最强的前缀之一：几乎任何结果可以重复的动作动词都可以加上它（*rename* 重新命名、*reheat* 重新加热、*restart* 重新启动、*reload* 重新加载）。它很难和状态动词连用：✗ *reknow*，✗ *relike*。

::: warning 带连字符和不带连字符的 *re-*
有几个带 *re-* 的动词有一个不能由各部分推出的旧意义，还有一个可以推出的新意义。连字符把它们区分开：

- *recover*“（病后）康复”—— *re-cover*“换上新的套子”：*We had the old sofa re-covered.*（我们请人给旧沙发换了新面料。）
- *reform*“改革（制度）”—— *re-form*“重新组成”：*The band re-formed after ten years.*（这支乐队十年后重组了。）
- *resign*“辞职”—— *re-sign*“再次签约”：*The player re-signed with his old club.*（这名球员和老东家续约了。）
- *recount*“讲述（故事）”—— *re-count*“重新计数”：*The votes were re-counted.*（选票重新点了一遍。）

✗ *The singer recovered the old song*（想说“重新录制了这首老歌”）会让人误解；✓ *The singer covered the old song*（这位歌手翻唱了这首老歌）或 *made a new recording of it*（重新录制了它）。如果 *re-* 只是“再”的意思而且不会引起误解，就不需要连字符：*rewrite*、*reopen*。在以 *e* 开头的基础前，两种写法都有：*re-enter*（重新进入；英式英语常用），*reenter*（美式英语常用）。
:::

表示“前任的”的 *ex-* 总是带连字符，主要加在表示人和身份的名词前：*my ex-boss*（我的前老板）、*an ex-soldier*（一位退伍军人）。它和 *export*（出口）、*exit*（出口）中表示“向外”的 *ex-* 来自同一个拉丁语 *ex*“出自”——不再担任某个职务的人就是“出”了这个职务——但在英语中两者的作用不同：表示“前任的”的 *ex-* 可以自由地加在英语名词前，而 *export* 中表示“向外”的 *ex-* 是从拉丁语借来的词的一部分，你会在 [[word-formation/greek-latin-roots]] 中遇到它。在非正式英语中，*ex* 本身还可以作名词：*She's still friends with her ex.*（她和前男友仍然是朋友。）

## 数量：*uni-*、*mono-*、*bi-*、*tri-*、*multi-*、*semi-*

| 前缀 | 意义 | 例子 |
|---|---|---|
| *uni-*、*mono-* | 一，单 | *uniform*（制服）、*unicycle*（独轮车）、*monolingual*（单语的）、*monotone*（单调的语调） |
| *bi-* | 二，双 | *bicycle*（自行车）、*bilingual*（双语的）、*bilateral*（双边的） |
| *tri-* | 三 | *triangle*（三角形）、*tricycle*（三轮车）、*trilingual*（三语的） |
| *multi-* | 多 | *multinational*（跨国的）、*multicultural*（多元文化的）、*multi-storey*（多层的；英式英语指多层停车场） |
| *semi-* | 半；部分地 | *semicircle*（半圆）、*semi-final*（半决赛）、*semi-skilled*（半熟练的） |

*Uni-*、*bi-* 和 *multi-* 来自拉丁语，*mono-* 来自希腊语，*tri-* 在拉丁语和希腊语中都有。在科学词汇中，希腊语和拉丁语的数字前缀成系列地使用（*monoxide* 一氧化物、*dioxide* 二氧化物、*trioxide* 三氧化物），[[word-formation/greek-latin-roots]] 会再讲到。

::: warning *Biweekly* 和 *bimonthly*
*Bi-* 的意思是“二”，但在表示时间的词里有歧义。*A biweekly meeting* 可以指“每两周一次的会”，也可以指“每周两次的会”；*bimonthly* 可以指“每两个月一次”，也可以指“每月两次”。韦氏词典（Merriam-Webster）等词典两种意义都收录。细心的作者会避开这个问题：✓ *every two weeks*（每两周）、*twice a week*（每周两次）、*every other month*（隔月）。*Biannual*（一年两次的）和 *biennial*（两年一次的）也容易混淆。英式英语还有 *fortnightly*“每两周一次的”。
:::

## 地点和关系：*inter-*、*trans-*、*co-*、*anti-*

- *inter-*“在……之间，相互”：*international*（国际的）、*interview*（面试，采访）、*interact*（互动）、*intercity*（城际的）
- *trans-*“横过，贯穿”：*transatlantic*（横跨大西洋的）、*transport*（运输）、*translate*（翻译）、*transform*（改变）
- *co-*“共同，一起”：*co-worker*（同事）、*co-author*（合著者）、*cooperate*（合作）、*co-founder*（联合创始人）
- *anti-*“反对，抗”：*anti-war*（反战的）、*antisocial*（反社会的；不爱交际的）、*anti-virus*（防病毒的）、*antibiotic*（抗生素）

*Co-* 在元音前常带连字符（部分英式写法作 *co-operate*，美式和许多英式写法作 *cooperate*），在表示人的新词中也常带（*co-host* 联合主持人、*co-pilot* 副驾驶）。两种写法都对；按你的词典或所在机构的格式规范来写。

::: quiz
*co-founder* 是什么？
- [ ] 第二次创立公司的人
- [x] 和别人一起创立某个机构的两个或多个人之一
- [ ] 反对创始人的人
- [ ] 前任创始人
::: solution
*Co-* 的意思是“和别人一起”：*She is the co-founder of a small design company*（她是一家小设计公司的联合创始人）——她和另外一个或几个人一起创办了这家公司。“反对”要用 *anti-*；“前任”要用 *ex-*；“再”要用 *re-*。
:::
:::

::: example 短文中的前缀 {#ex-text}
读下面的短文，根据前缀和基础说明每个加粗的词的意思。

> *The old cinema in our town was **rebuilt** last year. It now shows **subtitled** films from many countries, and the **pre-show** talks are popular. Tickets are not **overpriced**, and the staff are never **impolite**. Some people say the café is **undersized**, but I **disagree**.*

**译文：**我们镇上的老电影院去年重建了。现在它放映许多国家的带字幕的电影，放映前的讲座很受欢迎。票价不贵，工作人员也从不失礼。有人说咖啡馆太小了，但我不同意。
::: solution
- *rebuilt*：*re-*“再”+ *built*——重新建造的。
- *subtitled*：*sub-*“在下”+ *title* + *-ed*——画面下方有翻译文字的，即带字幕的。
- *pre-show*：*pre-*“在……之前”+ *show*——在电影放映之前进行的。
- *overpriced*：*over-*“过度”+ *priced*——价格比应有的高。
- *impolite*：*im-*（= *p* 前的 *in-*）“不”+ *polite*——不礼貌的，粗鲁的。
- *undersized*：*under-*“不足”+ *sized*——太小的。
- *disagree*：*dis-*“不，相反”+ *agree*——持不同意见。

这里的每个前缀都保持了基础的词类：*rebuilt* 和 *disagree* 是动词，和 *built*、*agree* 一样；*impolite* 是形容词，和 *polite* 一样。
:::
:::

::: note 英汉对比
许多英语前缀在汉语中有相近的对应成分，有些现代汉语词就是作为英语词的译名而造出来的：*supermarket* 是“超级市场”或“超市”，*ex-wife* 是“前妻”，*semi-final* 是“半决赛”，*bilingual* 是“双语”，*anti-war* 是“反战”，*misunderstand* 是“误解”。中国语法学家把“超、前、半、反、非、不、多、可”这类字叫作**类前缀**（quasi-prefix），这个术语出自吕叔湘的《汉语语法分析问题》（1979）：它们在许多词里表现得像前缀，但仍保留作为普通语素的意义，所以汉语真正的词缀很少。这种相似性使中国学习者比较容易掌握英语前缀。

有两点需要注意。第一，英语用前缀的地方汉语常常用一个完整的词，而且词序可能不同：*pre-war* 是“战前”，*post-war* 是“战后”，“前”“后”在名词之后，而英语的 *pre-* 和 *post-* 在名词之前。第二，“不”涵盖了 *un-*、*in-*、*dis-* 和 *non-* 的意义，所以汉语在选择这几个前缀时帮不上忙：“不可能”是 *impossible*，“不诚实”是 *dishonest*，“不高兴”是 *unhappy*，“不吸烟的”是 *non-smoking*。英语的选择要一个词一个词地学（[[#rule-negative]]）。
:::

::: warning 名不副实的前缀
- *inflammable* = *flammable*“易燃的”。其中的 *in-* 表示“进入”（拉丁语 *inflammare*“点燃”）。它的反义词是 *non-flammable*（不易燃的）。
- *invaluable* =“极其宝贵的”，而不是“没有价值的”。*Priceless*（无价的）与此类似。表示“没有价值的”的词是 *worthless*。
- *unloosen* = *loosen*（松开），*ravel* 和 *unravel* 都可以表示（线）“散开”：这里的 *un-* 几乎没有增添什么意义。
- *disgruntled*“不满的”在普通用法中没有肯定形式 *gruntled*；小说家伍德豪斯（P. G. Wodehouse）曾把 *gruntled* 当作玩笑来用。

如果一个带前缀的词似乎和上下文相矛盾，就查查词典。
:::

::: history
英语的两个主要否定前缀显示了英语的双重历史。*Un-* 来自古英语，在其他日耳曼语言中也有（德语的 *un-*，如 *unmöglich*“不可能的”）。*In-* 是随着成千上万个拉丁语和法语词进入英语的，特别是在十四至十七世纪之间。结果就出现了兼用两套系统的词对，例如 *unable*（不能的）和 *inability*（无能力），*unjust*（不公正的）和 *injustice*（不公正）。*inflammable* 引起的混淆也来自同样的历史：拉丁语既有表示否定的 *in-*，也有表示“在内，进入”的 *in-*。二十世纪，英语国家的消防安全机构开始在警示标签上优先使用 *flammable*，因为 *inflammable* 可能被误读为“不易燃的”；这两个词至今都是正确的。
:::

## 后续内容

前缀很少改变词类；后缀通常会改变词类，它们是 [[word-formation/suffixes]] 的内容。许多来自拉丁语和希腊语的前缀——*ex-*“向外”、*pro-*“向前”、*tele-*“远”——在学术词汇中和粘着词根结合；见 [[word-formation/greek-latin-roots]]。*misspell* 和 *unnatural* 这类词的拼写属于 [[word-formation/spelling-changes]] 的内容，[[word-formation/learning-with-word-formation]] 说明怎样稳妥地利用前缀猜测生词。关于英语借入的带 *in-* 和 *dis-* 的词，见 [[history-of-english/norman-french]] 和 [[history-of-english/early-modern-english]]。

::: summary
- **前缀**放在基础前面，通常改变**意义**而不改变词类；构成动词的 *en-*/*em-* 和 *be-* 是例外。
- **否定前缀**：*un-*（最常用，仍用来构成新词），*in-*/*im-*/*il-*/*ir-*（用于来自拉丁语的形容词；几乎不再用来构成新词），*dis-*（常与动词搭配），*non-*（中性的“不属于这一类”）。每个词的否定形式都要照原样学。
- 和动词连用时，*un-*、*de-* 和 *dis-* 表示“逆转”或“去除”：*untie*（解开）、*defrost*（除霜）、*disconnect*（断开）。
- *mis-*“错误地”；*over-*“过度”，*under-*“不足”；*out-*“胜过”（而且它增加了一个宾语：*outrun someone* 跑得比某人快）。
- 时间：*pre-*、*post-*、*re-*（再）、*ex-*（前任的，带连字符）。数量：*uni-*、*mono-*、*bi-*、*tri-*、*multi-*、*semi-*。地点：*inter-*、*trans-*、*co-*、*anti-*、*sub-*、*super-*。
- 连字符区分 *re-cover* 和 *recover*、*re-sign* 和 *resign*。
- 小心 *inflammable*（= *flammable*）、*invaluable*（= 非常宝贵的）以及有歧义的 *biweekly*。
:::

::: exercise 有几个前缀？ {level=1 check="3"}

::: exercise “不”还是“逆转”？ {level=2}
在每个词中，*un-* 表示“不”还是“做相反的动作”？

*unlock*、*unkind*、*undress*、*unknown*、*unplug*、*unsafe*、*unwrap*、*unwashed*
::: solution
- “不”：*unkind*（不友好的）、*unknown*（不知名的）、*unsafe*（不安全的）、*unwashed*（没洗过的）（形容词，或用作形容词的分词：*unwashed clothes* 是没有洗过的衣服）。
- “逆转”：*unlock*（开锁）、*undress*（脱衣服）、*unplug*（拔掉插头）、*unwrap*（打开包装）（动词：去掉锁、衣服、插头、包装）。

::: exercise *Un-* 还是 *non-*？ {level=2}
选择更合适的词，并说明区别。

1. *It was very (unprofessional / non-professional) of him to shout at a customer.*（他对顾客大喊大叫，非常不专业。）
2. *The club is open to (unmembers / non-members) on Sundays.*（俱乐部星期天对非会员开放。）
3. *Astrology is (unscientific / non-scientific): its claims fail when they are tested.*（占星术是不科学的：它的说法一经检验就站不住。）
4. *The library has a large (unfiction / non-fiction) section.*（图书馆有一个很大的非虚构类图书区。）
::: solution
1. *unprofessional*——它评判他的行为达不到应有的标准。
2. *non-members*——“不是会员的人”，是中性的描述；没有 *unmembers* 这个词。
3. *unscientific*——它把占星术评判为不好的科学，而不只是说它属于另一门学科。（*Non-scientific* 只是描述而不评判某种本来就不是科学的东西，比如诗歌。）
4. *non-fiction*——不是小说或故事的书；没有 *unfiction* 这个词。
:::
:::

::: exercise 改正句子 {level=2}
每个句子在前缀上有一个错误。请改正。

1. *I'm sorry, I unagree with you.*
2. *Keep the gas away from fire — it's very inflammable, so it's quite safe.*
3. *The meeting is biweekly, so we'll see you next Tuesday and the Tuesday after.*
4. *Smoking is inlegal in this building.*
::: solution
1. ✗ *unagree* → ✓ *I'm sorry, I disagree with you.*（对不起，我不同意你的看法。）（这个动词用 *dis-*。）
2. 前缀被误读了：*inflammable* 的意思是“易燃的”。✓ *Keep the gas away from fire — it's highly inflammable*（或 *flammable*），*so it's dangerous.*（让燃气远离明火——它极易燃烧，所以很危险。）
3. *Biweekly* 有歧义，而“下星期二和再下一个星期二”的意思是 *weekly*（每周的）。✓ *The meeting is weekly.*（会议每周一次。）（如果要表示每两周一次：*The meeting is every two weeks.*）
4. ✗ *inlegal* → ✓ *illegal*：*in-* 在 *l* 前变成 *il-*。（这栋楼内吸烟是违法的。）
:::

::: exercise 解释一则告示 {level=3}
学生宿舍里有这样一则告示。解释每个带前缀的词的意义，并用不含这些前缀的更简单的英语改写这则告示。

> *Non-residents must sign in at reception. Do not overload the washing machines. Misuse of the fire alarm is illegal. Rooms must be vacated and unlocked by 10 a.m. on departure day; rooms left untidy will be recleaned at the resident's expense.*

**译文：**非住宿人员须在前台登记。洗衣机不要装得过满。滥用火警警报属违法行为。离开当天上午10点前须腾空房间，不要锁门；房间如不整洁，将重新打扫，费用由住宿者承担。
::: hint
有些词在词根前有两个语素（*recleaned* = *re-* + *clean* + *-ed*）。对于 *unlocked*，问一问 *un-* 是“不”还是“逆转”。
:::
::: solution
- *non-residents*：不住在宿舍里的人。
- *overload*：装得太多。
- *misuse*：错误地使用某物（这里指没有火灾时触发警报）。
- *illegal*：*il-*（= *in-*）“不”+ *legal*——违法的。
- *unlocked*：“没有上锁的”——用作形容词的过去分词，描述房间必须保持的状态。（这种状态是“开锁”这个动作的结果，所以在这里 *un-* 的两种意义导向同一个要求：门不要锁。）
- *untidy*：不整洁的。
- *recleaned*：再打扫一次。

一个更简单的版本：*People who do not live here must sign in at reception. Do not put too many clothes in the washing machines. Using the fire alarm when there is no fire is against the law. On the day you leave, you must be out of your room by 10 a.m. and leave the door open. If your room is not tidy, it will be cleaned again and you will pay for it.*

**译文：**不住在这里的人必须在前台登记。不要往洗衣机里放太多衣服。没有火灾时使用火警警报是违法的。离开那天，你必须在上午10点前离开房间，并且不要锁门。如果你的房间不整洁，会被再打扫一遍，费用由你支付。
:::
:::

::: exercise 你自己造的新词 {level=3}
说英语的人随时都在造新的带前缀的词，听的人一听就懂。用 *re-*、*over-*、*un-* 和 *non-* 各造一个你自己的新词，每个词用在一个关于你日常生活的句子里，并说明为什么即使词典里没有这些词，听的人也能听懂。然后说明为什么你**不能**用同样的方法以 *in-* 造新词。
::: solution
参考答案：

- *re-*：*My phone needed a restart, and then I had to re-download all my apps.*（我的手机需要重启，然后我得把所有应用重新下载一遍。）（*Re-* 加上任何可以重复的动作动词，人们马上就能听懂。）
- *over-*：*I overplanned the trip — there was no time to relax.*（我把旅行计划得太满了——根本没时间放松。）（*Over-*“过度”加动作动词。）
- *un-*：*Before you leave, please unmute your microphone and say goodbye.*（离开之前，请打开麦克风，说声再见。）（*Un-*“逆转”加动词。）或者加形容词：*This hotel is unaffordable in summer.*（夏天这家酒店贵得住不起。）
- *non-*：*The office has a non-coffee drinker corner.*（办公室有一个给不喝咖啡的人的角落。）（*Non-*“不属于这一类”加名词短语。）

听的人能听懂这些词，是因为 *re-*、*over-*、*un-* 和 *non-* 具有**能产性**：它们经常被用来构成新词，而且意义稳定。*In-* 在现代英语中几乎没有能产性：它主要保留在很久以前借入的词里，所以 ✗ *inaffordable* 这样的新词听起来不对，已有的词必须一个一个地学。
:::
:::
