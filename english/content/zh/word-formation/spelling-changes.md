马琳给她的英语老师写了一封短邮件。拼写检查功能关着，她犯了六个拼写错误：

> *I am writting to say that I am hopeing to join the begining class. I have been studing English for a year, and I think it is a responsable choice. I am sure it will bring me a lot of happyness.*

**译文：**我写信是想说，我希望参加初级班。我学英语已经一年了，我认为这是一个负责任的选择。我相信它会给我带来很多快乐。

这些错误全都出在同一个地方：给一个词加后缀的那个点上。*Write* + *-ing* 是 *writing*（写；一个 *t*），*hope* + *-ing* 是 *hoping*（希望；没有 *e*），*begin* + *-ing* 是 *beginning*（开始；两个 *n*），*study* + *-ing* 是 *studying*（学习；保留 *y*），*happy* + *-ness* 是 *happiness*（快乐；*y* → *i*），而 *responsible*（负责任的）以 *-ible* 结尾。英语拼写看起来不规则，但语素连接处的变化遵循为数不多的几条规则，而且大多数规则都有道理：它们让基础词的读音在拼写中仍然看得出来。

本章讲解这些规则：去掉不发音的 *e*，双写末尾辅音字母，把 *y* 变成 *i*，几条较小的规则，以及光靠规则无法决定的两种选择：*-able*/*-ible* 和 *-ance*/*-ence*。英语拼写与读音的一般关系是 [[sounds-of-english/spelling-and-sound]] 的内容。

## 元音后缀和辅音后缀

这些规则取决于后缀的第一个字母。

::: definition 元音后缀和辅音后缀 {#def-vowel-suffix}
**元音后缀**以元音字母开头：*-ing*、*-ed*、*-er*、*-est*、*-able*、*-ous*、*-ive*、*-ity*、*-al*、*-ence*。在这些规则里，*-y*（如 *icy* 冰冷的、*sunny* 晴朗的）也算元音后缀。**辅音后缀**以辅音字母开头：*-ment*、*-ness*、*-ful*、*-less*、*-ly*、*-s*。
:::

## 不发音的 *e*

::: theorem 去掉不发音的 *e* {#rule-drop-e}
当一个词以不发音的 *e* 结尾时：

1. **在元音后缀前去掉 *e***：*hope* → *hoping*（希望），*make* → *making*（做），*write* → *writer*（作者），*use* → *usable*（可用的），*create* → *creative*（有创造力的），*ice* → *icy*（冰冷的），*fame* → *famous*（著名的）。
2. **在辅音后缀前保留 *e***：*hope* → *hopeful*（有希望的），*care* → *careful*（小心的），*move* → *movement*（运动），*love* → *lovely*（可爱的），*safe* → *safely*（安全地），*late* → *lateness*（迟到）。
:::

::: proof
不发音的 *e* 有它的作用：它表示前面的元音是“长”的（读字母本身的名称）：*hop*（跳）/hɒp/（GB），/hɑːp/（GA），而 *hope*（希望）/həʊp/（GB），/hoʊp/（GA）；*cut*（切）对 *cute*（可爱的）。元音后缀也能起同样的作用，因为单个辅音字母后面跟一个元音字母，同样表示长元音：*hoping*、*cuter*。所以在元音后缀前不再需要 *e*，就去掉。在辅音后缀前仍然需要它，所以保留：如果没有它，*hopful* 会让人以为元音和 *hop* 一样。从历史上看，这个 *e* 在中古英语里是发音的；它不再发音之后，书写者把它保留下来，作为长元音的标记，拼写规则就是围绕这个用法形成的。
:::

例外也符合这条规则的逻辑——*e* 还有作用的时候就保留：

- **软音 *c* 和 *g* 在 *a* 或 *o* 前**：*notice* → *noticeable*（显而易见的），*change* → *changeable*（易变的），*manage* → *manageable*（可控制的），*courage* → *courageous*（勇敢的）。如果没有 *e*，*a* 或 *o* 前的 *c* 和 *g* 就会读成“硬音”（/k/、/ɡ/），如 *cable*（电缆）和 *go*（去）。
- **为了区分两个词**：*dye* → *dyeing*（染色），而 *die* → *dying*（死）；*singe* → *singeing*（烧焦），而 *sing* → *singing*（唱歌）。
- **在 *ee*、*oe* 和 *ye* 之后**：*see* → *seeing*（看见），*agree* → *agreeing*（同意），*canoe* → *canoeing*（划独木舟），*eye* → *eyeing*（注视；也写作 *eying*）。

有几个常用词在辅音后缀前也去掉 *e*：*true* → *truly*（真正地），*argue* → *argument*（争论），*whole* → *wholly*（完全地），*nine* → *ninth*（第九），*awe* → *awful*（糟糕的）。还有些词有两种公认的拼法，其中一种更偏英式：*judgement*（判断；英式，一般用法）/ *judgment*（美式，以及英式法律用语）；*ageing*（变老；英式）/ *aging*（美式）。

::: quiz
哪个拼法是正确的？
- [ ] *noticable*
- [x] *noticeable*
- [ ] *noticible*
- [ ] *notisable*
::: solution
*Notice* + *-able* 保留 *e*：如果没有它，*a* 前面的 *c* 会读成 /k/。所以是 *noticeable*（显而易见的）/ˈnəʊtɪsəbl/（GB），/ˈnoʊtɪsəbl/（GA）。*serviceable*（耐用的）、*peaceable*（和平的）和 *changeable*（易变的）也是这样。
:::
:::

## 双写末尾辅音字母

::: theorem 双写末尾辅音字母 {#rule-double}
在元音后缀前，当以下**三个条件都满足**时，双写词末的辅音字母：

1. 词以**一个元音字母 + 一个辅音字母**结尾（*stop*、*big*、*begin*、*prefer*）；
2. **最后一个音节重读**（单音节词都算重读）；
3. 这个辅音字母不是 *w*、*x* 或 *y*。

所以：*stop* → *stopped*、*stopping*（停止）；*big* → *bigger*、*biggest*（大）；*run* → *running*、*runner*（跑；跑步者）；*begin* → *beginning*、*beginner*（开始；初学者）；*prefer* → *preferred*（更喜欢）；*admit* → *admitted*（承认）；*occur* → *occurred*、*occurrence*（发生）。

但下列情况不双写：

- 辅音字母前有**两个元音字母**：*rain* → *raining*（下雨），*cook* → *cooked*（烹饪），*beat* → *beaten*（打）；
- 词以**两个辅音字母**结尾：*help* → *helped*（帮助），*start* → *starting*（开始），*fast* → *faster*（快）；
- 最后一个音节**不重读**：*open* → *opening*（打开），*visit* → *visited*（拜访），*happen* → *happened*（发生），*offer* → *offering*（提供），*budget* → *budgeted*（编预算）；
- 辅音字母是 *w*、*x* 或 *y*：*snow* → *snowing*（下雪），*fix* → *fixed*（修理），*play* → *playing*（玩）；
- 后缀是**辅音后缀**：*ship* → *shipment*（装运），*sad* → *sadness*（悲伤），*glad* → *gladly*（乐意地）。
:::

::: proof
双写的作用和不发音的 *e* 正好相反：它表示元音保持**短**音。单个辅音字母后面跟元音字母，通常表示长元音（*hoping* 希望、*diner* 用餐者、*later* 后来）；两个辅音字母表示短元音（*hopping* 跳、*dinner* 晚餐、*latter* 后者）。所以 *hop* + *-ing* 需要两个 *p*，才能保住 *hop* 的短元音。重读这个条件也出于同样的逻辑：这条规则保护的是重读元音的读音，而非重读元音通常本来就弱化成 /ə/ 或 /ɪ/，所以 *opening* 或 *visited* 里没有什么需要保护的。当后缀把重音从最后一个音节移走时，双写也随之停止：*preFER* → *preferred*（重音不变），但 *PREFerence*（偏爱；重音移动，单个 *r*）；*reFER* → *referring*（提到），但 *REFerence*（参考）。
:::

::: example 双写还是不双写？ {#ex-double}
加上后缀，并说明你的判断。

1. *plan* + *-ed*
2. *visit* + *-ing*
3. *forget* + *-ing*
4. *wait* + *-ed*
5. *wet* + *-er*
6. *listen* + *-er*
7. *fix* + *-ing*
8. *commit* + *-ment*
::: solution
1. *planned*（计划）——一个元音 + 一个辅音，单音节（重读）：双写。
2. *visiting*（拜访）——最后一个音节（*-it*）不重读：**VI**sit。
3. *forgetting*（忘记）——for**GET**：最后一个音节重读，一个元音 + 一个辅音：双写。
4. *waited*（等待）——两个元音字母（*ai*）：不双写。
5. *wetter*（更湿的）——单音节，一个元音 + 一个辅音：双写。
6. *listener*（听者）——**LIS**ten：最后一个音节不重读。
7. *fixing*（修理）——*x* 从不双写。
8. *commitment*（承诺）——*-ment* 是辅音后缀：不双写（比较带元音后缀的 *committed* 坚定的、*committee* 委员会）。
:::
:::

### 英式和美式的 *l*

英式英语在单个元音字母后面的词末 *l*，即使所在音节不重读，也要双写；美式英语通常遵循一般规则，不双写：

| 英式英语 | 美式英语 |
|---|---|
| *travel* → *travelled*、*travelling*、*traveller*（旅行；旅行者） | *traveled*、*traveling*、*traveler* |
| *cancel* → *cancelled*、*cancelling*（取消） | *canceled*、*canceling*（但两者都写 *cancellation*） |
| *model* → *modelling*（建模；当模特） | *modeling* |
| *label* → *labelled*（贴标签） | *labeled* |

两种拼法在各自的变体中都是正确的；一篇文章里要保持一致。

### 以 *-c* 结尾的词

以 *-ic* 结尾的词在 *-ed*、*-ing* 和 *-er* 前加 *k*，使 *c* 仍读 /k/：*panic* → *panicked*、*panicking*（惊慌）；*picnic* → *picnicked*、*picnicker*（野餐；野餐者）；*traffic* → *trafficking*（非法买卖）。

## 把 *y* 变成 *i*

::: theorem 辅音字母后的 *y* {#rule-y-i}
1. 当一个词以**辅音字母 + *y*** 结尾时，在任何后缀前把 *y* 变成 *i*，**但**以 *i* 开头的后缀**除外**：*happy* → *happiness*、*happily*、*happier*（快乐）；*carry* → *carried*、*carries*、*carrier*（携带；承运人）；*study* → *studies*、*studied*（学习）；*beauty* → *beautiful*（美丽的）；*rely* → *reliable*（可靠的）。
2. 在 ***-ing***（和 *-ish*）前保留 *y*，以免写出两个 *i*：*study* → *studying*，*carry* → *carrying*，*baby* → *babyish*（孩子气的）。
3. 当一个词以**元音字母 + *y*** 结尾时，保留 *y*：*play* → *played*、*player*（玩；运动员）；*enjoy* → *enjoyment*、*enjoyable*（享受；令人愉快的）；*grey* → *greyer*（更灰的；美式 *gray* → *grayer*）。有四个常见的例外：*day* → *daily*（每天的），*pay* → *paid*（付钱），*say* → *said*（说），*lay* → *laid*（放）。
4. 以 ***-ie*** 结尾的词在 *-ing* 前把它变成 *y*：*die* → *dying*（死），*lie* → *lying*（躺；说谎），*tie* → *tying*（系）。
:::

有几个单音节形容词在 *-ly* 和 *-ness* 前保留 *y*：*shy* → *shyly*、*shyness*（害羞）；*dry* → *dryness*（干燥；还有 *dryly*，也写作 *drily*）；*sly* → *slyly*（狡猾地）。而 *busy* + *-ness* 变成了 *business*（生意），有了自己的读音 /ˈbɪznəs/ 和自己的意义；“忙碌的状态”是 *busyness*。

::: quiz
哪一句是正确的？
- [ ] *She studys every evening.*
- [ ] *She is studing for an exam.*
- [x] *She studied hard and is still studying.*（她学习很用功，现在还在学。）
- [ ] *She studyed hard and is still studiing.*
::: solution
*Study* 以辅音字母 + *y* 结尾：在 *-es* 和 *-ed* 前 *y* → *i*（*studies*、*studied*），但在 *-ing* 前保留 *y*（*studying*），否则就会有两个 *i*。
:::
:::

::: example 给以 *-y* 结尾的词加词尾 {#ex-y}
加上词尾并说明理由。

1. *easy* + *-ly*
2. *enjoy* + *-able*
3. *try* + *-ing*，*try* + *-ed*
4. *company* + *-s*
5. *say* + *-ed*
6. *lie* + *-ing*
::: solution
1. *easily*（容易地）——辅音字母 + *y*：*y* → *i*。
2. *enjoyable*（令人愉快的）——元音字母 + *y*：保留 *y*。
3. *trying*（在 *-ing* 前保留 *y*），*tried*（*y* → *i*）（尝试）。
4. *companies*（公司）——辅音字母 + *y*：*y* → *i*，*-s* 变成 *-es*。
5. *said*（说）——四个例外之一（*day*、*pay*、*say*、*lay*）。
6. *lying*（躺；说谎）——*-ie* 在 *-ing* 前变成 *y*。
:::
:::

## 几条较小的规则：前缀、*-ful*、*all-*、*-ly*

- **前缀从不改变基础词的拼写**，基础词也从不改变前缀（拉丁语同化形式如 *il-*、*im-* 除外：[[word-formation/prefixes#rule-negative]]）。所以连接处可能出现两个相同的字母：*mis-* + *spell* → *misspell*（拼错）；*un-* + *necessary* → *unnecessary*（不必要的）；*dis-* + *satisfied* → *dissatisfied*（不满意的）；*over-* + *rate* → *overrated*（被高估的）；*im-* + *mature* → *immature*（不成熟的）。
- **后缀 *-ful* 只有一个 *l***：*careful*（小心的）、*beautiful*（美丽的）、*spoonful*（一匙），尽管单词 *full*（满的）有两个。副词照常加 *-ly*：*carefully*、*beautifully*。
- ***All* 在少数几个词的开头变成 *al-***：*always*（总是）、*already*（已经）、*almost*（几乎）、*although*（虽然）、*altogether*（完全）。但在严谨的书面语中 *all right*（好的）是两个词（*alright* 在非正式书面语中很常见），而且 *already*（“在此之前”）和 *all ready*（“全都准备好了”）不同。
- **以 *-ly* 结尾的副词**：以辅音字母 + *-le* 结尾的形容词把 *-le* 变成 *-ly*：*simple* → *simply*（简单地），*gentle* → *gently*（温柔地），*possible* → *possibly*（可能）。以 *-ll* 结尾的形容词只加 *-y*：*full* → *fully*（完全地），*dull* → *dully*（单调地）。以 *-ic* 结尾的形容词加 *-ally*：*basic* → *basically*（基本上），*tragic* → *tragically*（悲惨地）（*publicly* 公开地 除外）。

## *-able* 还是 *-ible*？

两个词尾都表示“能被……的”，读音也相同（/əbl/），所以拼写需要选择。

::: theorem *-able* 还是 *-ible* {#rule-able-ible}
1. 基础部分是一个**完整的英语单词**时，用 ***-able***：*accept* → *acceptable*（可接受的），*read* → *readable*（易读的），*wash* → *washable*（可洗的），*suit* → *suitable*（合适的），*comfort* → *comfortable*（舒适的），*rely* → *reliable*（可靠的），*notice* → *noticeable*（显而易见的）。所有新词都用 *-able*：*downloadable*（可下载的），*recyclable*（可回收的）。
2. ***-ible*** 通常跟在本身**不是**英语单词的拉丁语词根后面：*visible*（看得见的）、*possible*（可能的）、*edible*（可食用的）、*terrible*（可怕的）、*horrible*（恐怖的）、*incredible*（难以置信的）、*plausible*（似乎合理的）。
3. 这是一个很强的倾向，但有例外，必须专门记：*responsible*（负责任的）、*sensible*（明智的）、*flexible*（灵活的）、*accessible*（可进入的）、*digestible*（易消化的）、*convertible*（可转换的）用 *-ible*，尽管 *response*、*sense*、*flex*、*access*、*digest* 和 *convert* 都是单词。其中有几个有相关的 *-ion* 名词（*convert* → *conversion*、*convertible*；*digest* → *digestion*、*digestible*；*flex* → *flexion*、*flexible*），这是一个有用的提示：如果基础部分还能构成 *-sion* 或 *-tion* 名词，很可能用 *-ible*。
:::

::: proof
这两个词尾来自拉丁语的 *-abilis* 和 *-ibilis*，它们属于拉丁语动词的不同类别；英语借入了许多带这两种词尾的现成词。当英语开始自己构造新的形容词时，用的是 *-able*，部分原因是 *-able* 在法语中也是常用形式，而这类词汇大多来自法语。这就是为什么 *-able* 是能产的——它可以加在任何英语动词后面——而 *-ible* 只保留在借来的词里。关于 *-ion* 名词的提示之所以有效，是因为 *-ible* 词和 *-sion*/*-tion* 名词常常来自同一个拉丁语词干（*vis-ible*、*vis-ion*；*digest-ible*、*digest-ion*）。这只是提示，不是规则：*collectable* 和 *collectible*（值得收藏的）两种拼法都有。
:::

::: example 选择词尾 {#ex-able}
加上 *-able* 或 *-ible*，并说明选择的理由。注意连接处的其他拼写规则。

1. *rely*
2. *vis-*（看）
3. *love*
4. *manage*
5. *forget*
6. *digest*
::: solution
1. *reliable*（可靠的）——*rely* 是完整的单词：*-able*；辅音字母 + *y* → *i*（[[#rule-y-i]]）。
2. *visible*（看得见的）——*vis-* 是拉丁语词根，不是英语单词：*-ible*。
3. *lovable*（可爱的）——完整的单词：*-able*；在元音后缀前去掉不发音的 *e*（[[#rule-drop-e]]）。（也能见到 *loveable*，但 *lovable* 是通常的拼法。）
4. *manageable*（可控制的）——*-able*，软音 *g* 在 *a* 前保留 *e*。
5. *forgettable*（容易被忘记的；最常见于 *unforgettable* 难忘的）——*forget* + *-able*，*t* 双写，因为 for**GET** 的最后一个音节重读（[[#rule-double]]）。
6. *digestible*（易消化的）——一个要记住的例外：*digest* 是单词，但形容词用 *-ible*，与名词 *digestion*（消化）对应。
:::
:::

## *-ance*、*-ence*、*-ant*、*-ent*

这几个词尾没有简单的规则，因为它们同样来自拉丁语的不同动词类别。不过有三点很有帮助。

1. **成对对应。** 知道了形容词，就知道了名词：*important* → *importance*（重要），*relevant* → *relevance*（相关），*different* → *difference*（不同），*independent* → *independence*（独立），*patient* → *patience*（耐心）。
2. **软音和硬音 *c*、*g*。** 在“软音” *c*（/s/）或 *g*（/dʒ/）之后，词尾是 *-ence*/*-ent*，因为 *c* 和 *g* 在 *e* 前读软音：*innocence*（无辜）、*intelligent*（聪明的）、*emergency*（紧急情况）、*diligent*（勤奋的）。在“硬音” *c*（/k/）或 *g*（/ɡ/）之后，词尾是 *-ance*/*-ant*：*significant*（重要的）、*elegance*（优雅）、*extravagant*（奢侈的）。
3. **常见错误不多。** 一个短短的清单就能涵盖大部分：*independent*（独立的；不是 ✗ *independant*），*existence*（存在；不是 ✗ *existance*），*appearance*（外表；不是 ✗ *appearence*），*occurrence*（发生；双写 *r*，用 *-ence*），*maintenance*（维护；来自 *maintain*，但写作 *-ten-*），*relevant*（相关的），*permanent*（永久的）。

在英式英语中，*dependant* 是名词（“经济上依靠某人的人”，受抚养者），*dependent* 是形容词（依赖的）；美式英语两者都用 *dependent*。

::: warning 别太相信拼写检查
拼写检查能发现 ✗ *happyness* 和 ✗ *begining*，但发现不了用错地方的真实单词：把 *dyeing*（染色）写成 *dying*（死），把 *latter*（后者）写成 *later*（后来），把 *hopping*（跳）写成 *hoping*（希望），把 *dinner*（晚餐）写成 *diner*（用餐者），把 *all ready*（全都准备好了）写成 *already*（已经）。要检查你的拼写检查工具是否设置成了你所写的变体——英式英语（*travelled*、*organise*、*colour*）或美式英语（*traveled*、*organize*、*color*）——否则它会把正确的词标成错误，却发现不了一篇文章中混用两种变体的问题。
:::

::: example 改正马琳的邮件 {#ex-email}
改正本章开头马琳邮件中的六个拼写错误，并说出每个错误违反的规则。

> *I am writting to say that I am hopeing to join the begining class. I have been studing English for a year, and I think it is a responsable choice. I am sure it will bring me a lot of happyness.*

**译文：**我写信是想说，我希望参加初级班。我学英语已经一年了，我认为这是一个负责任的选择。我相信它会给我带来很多快乐。
::: solution
1. *writting* → *writing*（写）。*Write* 以不发音的 *e* 结尾：在 *-ing* 前去掉（[[#rule-drop-e]]）。*write* 的元音是长元音（/aɪ/），所以不双写；*written* 有两个 *t*，是因为它的元音是短元音（/ɪ/）。
2. *hopeing* → *hoping*（希望）：在 *-ing* 前去掉不发音的 *e*。
3. *begining* → *beginning*（开始）：be**GIN** 的最后一个音节重读，以一个元音 + 一个辅音结尾：双写 *n*（[[#rule-double]]）。
4. *studing* → *studying*（学习）：在 *-ing* 前保留 *y*（[[#rule-y-i]]）。
5. *responsable* → *responsible*（负责任的）：要专门记住的 *-ible* 词之一（[[#rule-able-ible]]）。
6. *happyness* → *happiness*（快乐）：辅音字母 + *y* 在 *-ness* 前变成 *i*。

改正后：*I am writing to say that I am hoping to join the beginning class. I have been studying English for a year, and I think it is a responsible choice. I am sure it will bring me a lot of happiness.*（老师可能还会建议用 *the beginners' class*，这是这种班级通常的叫法。）
:::
:::

::: note 英汉对比
汉语书写中没有与这些规则对应的东西。一个汉字和另一个汉字组合时，字形从不改变（“学”在“学生”“大学”和“学习”中都一样），而可能反映读音变化的拼音，在日常书写中并不用来拼写词语。所以，一个词加上后缀时拼写会变化——*happy*、*happi-ness*——这个概念对中国学习者来说是新的，由此产生的错误（✗ *happyness*、✗ *studing*、✗ *begining*）在各个水平上都很常见。

有两点能帮上忙。第一，一旦你看清这些规则保护的是什么——基础词的长元音和短元音（在 GB 中，*hoping* /həʊp-/ 对 *hopping* /hɒp-/）——它们就说得通了。用正确的元音把词大声读出来，常常就能知道某个字母该双写还是该去掉。第二，变化发生在语素之间的**连接处**，所以检查自己写的东西时，要看带后缀的词的结尾。[[word-formation/morphemes#rule-split]] 中拆分词的技能反过来也适用：如果你能看出 *happi* + *ness*，你也就能写出来。
:::

::: history
英语拼写主要是在十七、十八世纪由印刷商、后来由词典固定下来的，其中最重要的是塞缪尔·约翰逊（Samuel Johnson）的《英语词典》（*Dictionary of the English Language*，1755年），它的拼法成了英国的标准。本章的大多数规则在那时已经是通行做法。诺亚·韦伯斯特（Noah Webster）在他的《美国英语词典》（*American Dictionary of the English Language*，1828年）中为美式英语作了一些改动，其中包括非重读音节中只写一个 *l*（*traveler*、*canceled*）——这就是为什么英式和美式英语在 *l* 的双写上不同，而在其他规则上一致。此后简化拼写的提议屡次出现，但这里描述的规则两百多年来一直保持稳定。
:::

## 后续内容

关于英语字母与读音的一般关系，见 [[sounds-of-english/spelling-and-sound]]；关于英式和美式拼写的整体差异，见 [[world-englishes/british-american]]。检查自己文章中的拼写和其他错误，属于 [[sentences-and-paragraphs/capitals-spelling]] 和 [[sentences-and-paragraphs/editing]] 的内容。本课程的最后一章 [[word-formation/learning-with-word-formation]] 讲怎样利用本课程中所有的构词部件——连同它们的拼写变化——来学习新词。

::: summary
- 规则取决于后缀：**元音后缀**（*-ing*、*-ed*、*-er*、*-able*、*-ous*、*-y* ……）和**辅音后缀**（*-ment*、*-ness*、*-ful*、*-ly*、*-s*）。
- **不发音的 *e*** 在元音后缀前去掉（*hoping*、*creative*），在辅音后缀前保留（*hopeful*、*movement*）；软音 *c*/*g* 在 *a*/*o* 前保留 *e*（*noticeable*、*courageous*）。
- 最后一个音节重读时，单个元音字母后的单个末尾辅音字母要**双写**（*stopped*、*beginning*、*preferred*），非重读音节后（*opening*、*visited*）以及 *w*、*x*、*y* 不双写。英式英语还双写 *l*（*travelled*）；美式英语不双写（*traveled*）。
- **辅音字母 + *y*** 在后缀前变成 *i*（*happiness*、*carried*），但 *-ing* 前不变（*carrying*）；元音字母 + *y* 保留 *y*（*played*），*daily*、*paid*、*said*、*laid* 除外。
- 前缀不改变基础词（*misspell*、*unnecessary*）；*-ful* 只有一个 *l*；*all* 在 *always*、*already* 中变成 *al-*。
- 完整单词后和所有新词用 ***-able***；***-ible*** 大多跟在拉丁语词根后（*visible*），有些例外要专门记（*responsible*）。
- ***-ance*/*-ence***：和 *-ant*/*-ent* 成对记；软音 *c*/*g* 后用 *-ence*/*-ent*。
:::

## 练习

::: exercise 去掉 *e* 还是保留？ {level=1}
加上后缀。

*make* + *-ing*，*care* + *-ful*，*use* + *-less*，*nerve* + *-ous*，*move* + *-ment*，*create* + *-ive*，*change* + *-able*，*write* + *-er*
::: solution
*making*（做），*careful*（小心的），*useless*（无用的），*nervous*（紧张的），*movement*（运动），*creative*（有创造力的），*changeable*（易变的；软音 *g* 在 *a* 前保留 *e*），*writer*（作者）。
:::

::: exercise 双写还是不双写？ {level=1}
给每个动词加 *-ing*。

*swim*，*sleep*，*shop*，*open*，*begin*，*jump*，*put*，*happen*
::: solution
*swimming*（游泳），*sleeping*（睡觉；两个元音字母），*shopping*（购物），*opening*（打开；最后一个音节不重读），*beginning*（开始），*jumping*（跳；两个辅音字母），*putting*（放），*happening*（发生；最后一个音节不重读）。
:::

::: exercise *y* 还是 *i*？ {level=1}
加上词尾。

*cry* + *-ed*，*cry* + *-ing*，*play* + *-er*，*lucky* + *-ly*，*city* + *-s*，*buy* + *-er*
::: solution
*cried*（哭），*crying*（哭），*player*（运动员），*luckily*（幸运地），*cities*（城市），*buyer*（买家）。
:::

::: exercise 有几个错误？ {level=2 check="4"}
这个句子里有几个拼写错误？*We travelled to the city by train, stoped at a small vilage, and had a realy enjoyable day, although it was rainning.*
::: hint
*Travelled* 在英式英语中是正确的。
:::
::: solution
**4**个：*stoped* → *stopped*（停下；双写 *p*），*vilage* → *village*（村庄），*realy* → *really*（真正地；*real* + *-ly*：*real* 的 *l* 加上 *-ly* 的 *l*），*rainning* → *raining*（下雨；*n* 前有两个元音字母：不双写）。*Travelled*（英式）、*enjoyable* 和 *although* 是正确的。

（*Village* 不是语素连接处的错误；它有两个 *l* 只是因为这个词本来就这样拼。）

改正后：*We travelled to the city by train, stopped at a small village, and had a really enjoyable day, although it was raining.*（我们坐火车去了城里，在一个小村庄停了一下，度过了非常愉快的一天，虽然在下雨。）
:::
:::

::: exercise *-able* 还是 *-ible*？ {level=2}
补全每个词。

*comfort___*，*vis___*，*wash___*，*poss___*，*depend___*，*respons___*，*ed___*（可以吃的），*understand___*
::: solution
*comfortable*（舒适的），*visible*（看得见的），*washable*（可洗的），*possible*（可能的），*dependable*（可靠的），*responsible*（负责任的），*edible*（可食用的），*understandable*（可以理解的）。

*Comfort*、*wash*、*depend* 和 *understand* 是完整的英语单词：用 *-able*。*Vis-*、*poss-* 和 *ed-* 是拉丁语词根：用 *-ible*。*Responsible* 是要记住的例外。
:::
:::

::: exercise 重音和双写 {level=2}
解释每对词在拼写上的差别。

1. *preferred* — *preference*
2. *admitted* — *visited*
3. *hoping* — *hopping*
4. *travelled*（英式）— *traveled*（美式）
::: solution
1. pre**FER**red（更喜欢）：*prefer* 最后一个音节上的重音保持不变，所以 *r* 双写。**PREF**erence（偏爱）：*-ence* 把重音移到第一个音节，所以不双写。
2. ad**MIT**（承认）：最后一个音节重读，*t* 双写。**VIS**it（拜访）：最后一个音节不重读，单个 *t*。
3. *hoping*（希望）来自 *hope*（长元音；去掉 *e*）；*hopping*（跳）来自 *hop*（短元音；双写 *p* 使它保持短音）。拼写表明了是哪个词。
4. 英式英语在单个元音字母后的词末 *l*，即使在非重读音节中也双写；美式英语遵循一般规则，不双写。
:::
:::

::: exercise 校对一段文字 {level=3}
改正这段文字中的拼写错误。一共有八个。说出每个错误违反了哪条规则。

> *Last summer I started a new hobby: cycleing. At the begining I was very nervus, and I fell off twice. My freinds were very helpfull, and they gave me usefull advice. Now I ride every day, and I am planing a longer trip. It is the most enjoiable thing I have done this year.*
::: solution
1. *cycleing* → *cycling*（骑自行车）：在 *-ing* 前去掉不发音的 *e*。
2. *begining* → *beginning*（开始）：最后一个音节重读（be**GIN**），一个元音 + 一个辅音：双写。
3. *nervus* → *nervous*（紧张的）：后缀是 *-ous*（*nerve* + *-ous*，去掉 *e*）。
4. *freinds* → *friends*（朋友）：不是语素规则，只是这个词本身的拼法（*i* 在 *e* 前）。
5. *helpfull* → *helpful*（有帮助的）：后缀 *-ful* 只有一个 *l*。
6. *usefull* → *useful*（有用的）：同上。
7. *planing* → *planning*（计划）：*plan* 是一个元音 + 一个辅音：双写（*planing* 来自 *plane*“刨平”）。
8. *enjoiable* → *enjoyable*（令人愉快的）：元音字母 + *y* 保留 *y*。

改正后：*Last summer I started a new hobby: cycling. At the beginning I was very nervous, and I fell off twice. My friends were very helpful, and they gave me useful advice. Now I ride every day, and I am planning a longer trip. It is the most enjoyable thing I have done this year.*

**译文：**去年夏天我开始了一项新爱好：骑自行车。一开始我很紧张，摔下来过两次。朋友们帮了很大的忙，给了我很多有用的建议。现在我每天都骑，还在计划一次更长的骑行。这是我今年做过的最愉快的事。
:::
:::

::: exercise 写作和检查 {level=3}
写80–100个词，讲你最近学会的一件事。至少用十个带后缀的词，其中至少两个去掉 *e*，两个双写辅音字母，两个把 *y* 变成 *i*。然后在这些词下面画线，并为每个词写出基础词、后缀和规则。
::: solution
范文：

> *Last month I tried **baking** bread for the first time. My first loaf was a **disappointing** failure: I had been **hurrying**, and I **stopped** the kneading too early. My sister, who is a **surprisingly** good cook, gave me some **useful** tips. The **beginning** is the hardest part, she said, and **patience** is everything. My second loaf was **tastier** and **easier** to slice, and the third was **completely** different — light and **lovely**. Now I am **planning** to try rye bread, which is **apparently** more difficult.*

**译文：**上个月我第一次试着烤面包。第一个面包是个令人失望的失败：我太着急了，揉面停得太早。我姐姐做饭出奇地好，她给了我一些有用的建议。她说，开头是最难的，耐心就是一切。我的第二个面包更好吃，也更容易切，第三个则完全不同——又松又可爱。现在我打算试试黑麦面包，据说更难。

- 去掉 *e*：*baking*（*bake* + *-ing*），*surprisingly*（*surprise* + *-ing* + *-ly*），*tastier*（*taste* + *-y*，再加 *-er*：在 *-y* 前去掉 *e*）
- 双写：*stopped*（*stop* + *-ed*），*beginning*（*begin* + *-ing*），*planning*（*plan* + *-ing*）
- *y* → *i*：*tastier*（*tasty* + *-er*），*easier*（*easy* + *-er*）
- 在 *-ing* 前保留 *y*：*hurrying*（*hurry* + *-ing*）
- 在辅音后缀前保留 *e*：*completely*（*complete* + *-ly*），*lovely*（*love* + *-ly*），*useful*（*use* + *-ful*）
- 没有变化：*disappointing*（*dis-* + *appoint* + *-ing*：两个 *p* 属于基础词，不是双写），*apparently*（*apparent* + *-ly*），*patience*

用同样的方法检查你自己的文章：在每个画线的词旁边写出基础词和后缀，变化（如果有的话）就一目了然了。
:::
