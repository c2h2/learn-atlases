刘洋写了一篇关于家乡城市的作文，开头几句是这样的：

> *In the last twenty years, the develop of my city has been very rapidly. The government has made many improves, and people's lives are more convenience than before.*

**译文（按原意）：**在过去二十年里，我的城市发展得非常快。政府做了许多改进，人们的生活比以前更方便了。

老师每个词都看得懂，但还是标出了四个错误。*Develop*、*rapidly*、*improves* 和 *convenience* 所属的词族都对，但每个都选错了成员：句子需要的是 *development*（发展）、*rapid*（迅速的）、*improvements*（改进）和 *convenient*（方便的）。在英语中，词的结尾通常告诉你它的词类，而句子决定需要哪种词类。在汉语中，“发展”可以是名词也可以是动词，“方便”可以是形容词也可以是名词，形式都不变，所以写作的中国学习者从词本身得不到任何提醒。

本章讲的就是造成这些差别的词尾：**后缀**。[[core-vocabulary/word-families#rule-suffix-class]] 中有一张常见后缀的初步表格。这里我们更进一步：几个后缀都可能时选哪一个，后缀除了词类以外还增添什么意义，哪些后缀会移动重音，以及哪些后缀仍在用来构成新词。

## 后缀的作用

::: definition 后缀 {#def-suffix}
**后缀**（suffix）是放在基础后面的词缀。派生后缀通常同时做两件事：给新词一个**词类**，并增添一个**意义**。*-ness* 构成名词，意思是“……的状态或性质”（*kind* → *kindness*，友好的 → 友好）；*-less* 构成形容词，意思是“没有……的”（*care* → *careless*，小心 → 粗心的）；*-ify* 构成动词，意思是“使……”（*simple* → *simplify*，简单的 → 简化）。
:::

::: theorem 最后一个后缀决定词类 {#rule-last-suffix}
一个词有几个派生后缀时，它的词类由**最后**一个后缀决定：*nation*（名词，国家）→ *national*（形容词，国家的）→ *nationalise*（动词，使国有化）→ *nationalisation*（名词，国有化）。前缀通常不影响词类（[[word-formation/prefixes#rule-prefix-class]]）。屈折词尾在所有派生后缀之后，也不改变词类：*nationalisations* 仍是名词。
:::

## 构成名词

### 由动词构成名词

| 后缀 | 意义 | 例子 |
|---|---|---|
| *-tion*、*-ation*、*-sion* | ……的行为或结果 | *inform* → *information*（通知 → 信息），*decide* → *decision*（决定），*organise* → *organisation*（组织） |
| *-ment* | ……的行为或结果 | *pay* → *payment*（付款），*develop* → *development*（发展），*agree* → *agreement*（同意 → 协议） |
| *-al* | ……的行为 | *arrive* → *arrival*（到达），*refuse* → *refusal*（拒绝），*approve* → *approval*（批准） |
| *-ance*、*-ence* | ……的行为或状态 | *perform* → *performance*（表演），*exist* → *existence*（存在），*prefer* → *preference*（偏好） |
| *-ing* | ……的行为；做成的东西 | *build* → *building*（建筑物），*meet* → *meeting*（会议），*paint* → *painting*（画） |

::: theorem 为动词选择名词后缀 {#rule-verb-noun}
大多数动词只有一个常用的名词形式，必须和动词一起学：*decide* → *decision*（不是 ✗ *decidement*），*arrive* → *arrival*（不是 ✗ *arrivation*），*improve* → *improvement*（改进；不是 ✗ *improvation*）。有两个倾向可以帮忙：

1. 以 *-ise*/*-ize* 和 *-ify* 结尾的动词用 *-ation*：*organise* → *organisation*（组织），*realise* → *realisation*（认识到），*classify* → *classification*（分类），*simplify* → *simplification*（简化）。
2. 以 *-ate* 结尾的动词用 *-ion*：*educate* → *education*（教育），*create* → *creation*（创造），*translate* → *translation*（翻译）。

如果有两个名词形式，它们的意义通常不同：*a building*（建筑物）/ *the construction*（建造过程）；*an arrival*（一个到达的人或一次到达）/ *the arrivals hall*（到达大厅）。
:::

::: proof
这些后缀是随着整个词进入英语的，大多来自法语和拉丁语（*-tion*、*-ment*、*-ance*、*-al*），每个英语动词通常保留了随它一起进来的、或者最早由它构成的那个名词。一个名词一旦确立，就很少需要另一个意义相同的名词，所以后者不会通用——语言学家把这叫作**阻断**（blocking）：*decision* 的存在阻断了 ✗ *decidement*。上面两个倾向之所以有规律，是因为 *-ise*、*-ify* 和 *-ate* 本身就是拉丁语型的后缀，而 *-ation*/*-ion* 是与之配套的拉丁语型名词词尾。*-ing* 则不同：它几乎能由任何动词构成名词（*the swimming* 游泳，*the cooking* 烹饪），但这类名词通常表示活动，而不是结果。
:::

::: example 用哪个名词？ {#ex-noun}
用括号中动词的名词形式完成句子。

1. *We are waiting for the ___ (arrive) of the train.*（我们在等火车到站。）
2. *The ___ (govern) has announced new rules.*（政府宣布了新规定。）
3. *She made an important ___ (discover).*（她有了一个重要的发现。）
4. *I'd like some ___ (inform) about the course.*（我想了解一些关于这门课的信息。）
5. *His ___ (perform) in the final was excellent.*（他在决赛中的表现非常出色。）
6. *The ___ (organise) of the event took months.*（组织这次活动花了好几个月。）
::: solution
1. *arrival*（*-al*）。2. *government*（*-ment*）。3. *discovery*（*-y*；不太常见，但这是已确立的形式）。4. *information*（*-ation*）。5. *performance*（*-ance*）。6. *organisation*（美式英语 *organization*；*-ise*/*-ize* → *-ation*，[[#rule-verb-noun]]）。

第3句说明后缀的清单不是封闭的：*-y* 也由少数动词构成名词（*discover* → *discovery* 发现，*deliver* → *delivery* 递送，*recover* → *recovery* 康复）。所以名词形式必须和动词一起学。
:::
:::

### 由形容词构成名词：*-ness*、*-ity* 等

| 后缀 | 例子 |
|---|---|
| *-ness* | *kind* → *kindness*（友好），*dark* → *darkness*（黑暗），*happy* → *happiness*（幸福），*aware* → *awareness*（意识） |
| *-ity* | *able* → *ability*（能力），*possible* → *possibility*（可能性），*real* → *reality*（现实），*popular* → *popularity*（受欢迎程度） |
| *-ance*、*-ence*、*-cy* | *important* → *importance*（重要性），*different* → *difference*（差别），*accurate* → *accuracy*（准确性） |
| *-th* | *wide* → *width*（宽度），*long* → *length*（长度），*deep* → *depth*（深度），*strong* → *strength*（力量），*warm* → *warmth*（温暖），*true* → *truth*（真相） |

::: theorem *-ness* 和 *-ity* {#rule-ness-ity}
1. ***-ness*** 几乎可以加在任何形容词上，构成新名词时通常选用它：*politeness*（礼貌）、*readiness*（准备就绪）、*user-friendliness*（易用性）。它从不改变基础的重音或元音。
2. ***-ity*** 主要加在来自拉丁语或法语的形容词上，特别是以 *-able*/*-ible*、*-al*、*-ar* 和 *-ic* 结尾的形容词：*ability*、*visibility*（能见度）、*reality*、*popularity*、*electricity*（电）。它把重音移到它前面的那个音节上，而且常常改变元音。
3. 以 *-ant* 和 *-ent* 结尾的形容词用 *-ance* 和 *-ence*：*important* → *importance*，*independent* → *independence*（独立）。
:::

::: proof
关于英语构词法的研究一致认为，*-ness* 是英语中能产性最强的构成名词的后缀（Plag 2018；Bauer, Lieber & Plag 2013）：它是本族后缀，几乎能加在任何形容词上，而且所得的词意义总是一目了然。*-ity* 是随着拉丁语和法语词进来的，一直偏好同一来源的基础；它仍被用来由这类基础构成新名词（*walkability* 步行友好度、*scalability* 可扩展性都是新词），但很少用于本族基础。有些形容词两种名词都有，用法通常不同：*sensitivity*（敏感性）是科学和医学中的常用词（*light sensitivity* 光敏感性），而 *sensitiveness* 很少用。以 *-th* 结尾的名词是古老的本族构词；现在不再造新的，所以只能逐个记住。
:::

### 表示人的名词

| 后缀 | 意义 | 例子 |
|---|---|---|
| *-er* | 做……的人或物 | *teacher*（教师）、*driver*（司机）、*player*（运动员）、*printer*（打印机）、*dishwasher*（洗碗机） |
| *-or* | 同上，多用于拉丁语型的词 | *actor*（演员）、*visitor*（访客）、*editor*（编辑）、*director*（导演，主任）、*translator*（译者） |
| *-ist* | 从事或演奏……的人 | *pianist*（钢琴家）、*scientist*（科学家）、*journalist*（记者）、*dentist*（牙医） |
| *-ian* | 精通……的人；属于……的人 | *musician*（音乐家）、*librarian*（图书管理员）、*historian*（历史学家）、*Canadian*（加拿大人） |
| *-ant*、*-ent* | 做……的人 | *assistant*（助手）、*applicant*（申请人）、*student*（学生）、*resident*（居民） |
| *-ee* | 承受某个动作的人 | *employee*（雇员）、*trainee*（受训者）、*interviewee*（面试者）、*payee*（收款人） |

*-er* 的能产性远远超过其他后缀：它几乎可以加在任何动词上，所以 *blogger*（博主）、*podcaster*（播客主播）、*streamer*（直播主播）这样的新词人们一看就懂。它也表示机器和工具（*printer* 打印机、*charger* 充电器、*opener* 开瓶器）。*-or* 和 *-er* 读音相同（GB 读 /ə/，GA 读 /ər/），所以拼写必须记住：*visitor* 却是 *writer*（作者），*actor* 却是 *speaker*（演讲者）。

*-ee* 通常指承受动作的人——*employer*（雇主）雇用 *employee*（雇员）——但在少数词里，它指的只是做某件事的人：*escapee* 是逃走了的人，*attendee* 是出席会议的人。它读重音：*emplo**YEE***、*trai**NEE***。

::: quiz
哪个词的意思是“正在接受培训的人”？
- [ ] *trainer*
- [x] *trainee*
- [ ] *training*
- [ ] *trainor*
::: solution
*-ee* 指承受动作的人：*trainee*（受训者）由 *trainer*（培训者）培训。*Training* 是培训这项活动，*trainor* 这个词不存在。
:::

## 构成形容词

| 后缀 | 意义 | 例子 |
|---|---|---|
| *-able*、*-ible* | 能被……的；具有……的 | *washable*（可洗的）、*readable*（易读的）、*comfortable*（舒服的）、*visible*（看得见的）、*possible*（可能的） |
| *-ful* | 充满……的，有……的 | *careful*（小心的）、*useful*（有用的）、*helpful*（有帮助的）、*beautiful*（美丽的） |
| *-less* | 没有……的 | *careless*（粗心的）、*useless*（无用的）、*homeless*（无家可归的）、*endless*（无尽的） |
| *-ous* | 具有……性质的 | *dangerous*（危险的）、*famous*（著名的）、*nervous*（紧张的）、*various*（各种各样的） |
| *-al* | 与……有关的 | *national*（国家的）、*cultural*（文化的）、*musical*（音乐的）、*personal*（个人的） |
| *-ive* | 倾向于……的，具有……性质的 | *active*（积极的）、*creative*（有创造力的）、*expensive*（昂贵的）、*attractive*（有吸引力的） |
| *-ic*、*-ical* | 与……有关的 | *economic*（经济的）、*scientific*（科学的）、*historical*（历史的）、*political*（政治的） |
| *-y* | 有……的，像……的 | *sunny*（晴朗的）、*rainy*（下雨的）、*salty*（咸的）、*sleepy*（困倦的） |
| *-ish* | 有点……的；大约；某国的 | *reddish*（略带红色的）、*tallish*（个子偏高的）、*sixish*（六点左右）、*British*（英国的）、*Turkish*（土耳其的） |
| *-ly* | 具有……特点的 | *friendly*（友好的）、*lovely*（可爱的）、*costly*（昂贵的）、*weekly*（每周的） |

*-able* 是能产性最强的形容词后缀：它几乎能加在任何及物动词上，表示“能被……的”（*downloadable* 可下载的、*recyclable* 可回收的、*shareable* 可分享的）。*-ible* 不再用来构成新词；两者之间的选择属于 [[word-formation/spelling-changes]] 的内容。

*-ful* 和 *-less* 常常成对（*careful* / *careless* 小心的 / 粗心的，*useful* / *useless* 有用的 / 无用的，*helpful* / *helpless*），但并非总是如此：有 *beautiful*，却没有 ✗ *beautiless*；有 *homeless*，却没有 ✗ *homeful*。而且一对词也不一定像你预想的那样意义相反：*helpless* 的意思是“无法自助的，无助的”，而不是“没有帮助的”（那是 *unhelpful*）。

::: example 选择形容词后缀 {#ex-adjective}
用括号中的词构成形容词完成句子，并说明后缀增添了什么意义。

1. *Thanks — that was really ___ (help).*（谢谢——这真的很有帮助。）
2. *Don't worry, these glasses are ___ (wash) — put them in the dishwasher.*（别担心，这些杯子可以洗——放进洗碗机吧。）
3. *The film was so long and ___ (end) that I fell asleep.*（这部电影又长又没完没了，我都睡着了。）
4. *Be careful on the roads; it's ___ (ice) this morning.*（路上小心，今天早上路面结冰了。）
5. *She's very ___ (create) — she paints, writes and designs clothes.*（她很有创造力——画画、写作，还设计服装。）
6. *Without the key I was ___ (help): I couldn't get in.*（没有钥匙我毫无办法：进不去。）
::: solution
1. *helpful*——*-ful*“有，给予”：它提供了帮助。
2. *washable*——*-able*“能被……的”：它们可以洗。
3. *endless*——*-less*“没有”：似乎没有尽头。
4. *icy*——*-y*“有，覆盖着”（*ice* 的 *e* 在 *-y* 前去掉）。
5. *creative*——*-ive*“倾向于，擅长”（*create* 的 *e* 在 *-ive* 前去掉）。
6. *helpless*——*-less*“没有”：什么也做不了。比较第1句和第6句：*helpful* 和 *helpless* 并不是简单的反义词。*helpful* 的反义词是 *unhelpful*。
:::
:::

*-ish* 在非正式口语中非常常用，可以表示“大约”：*Let's meet at sixish.*（我们六点左右见吧。）*She's thirtyish.*（她三十岁上下。）说话人甚至单用 *ish* 作非正式的回答：*Are you ready? — Ish.*（你准备好了吗？——差不多吧。）

::: warning *-ic* 还是 *-ical*？
有些形容词有两种意义不同的形式。学习型词典会标明区别；最常见的几对是：

- *economic*“经济的，与经济有关的”—— *economical*“节省的，不浪费钱或燃料的”：*economic growth*（经济增长）；*an economical car*（一辆省油的车）。
- *historic*“有历史意义的”—— *historical*“关于过去的，历史上的”：*a historic victory*（一次历史性的胜利）；*historical documents*（历史文献）。
- *electric*“用电的”—— *electrical*“与电有关的”：*an electric car*（一辆电动汽车）；*electrical engineering*（电气工程）。
- *classic*“一流的，典型的，经久不衰的”—— *classical*“古希腊罗马的；严肃音乐的”：*a classic film*（一部经典电影）；*classical music*（古典音乐）。

✗ *This car is very economic.* ✓ *This car is very economical.*（这辆车很省油。）✗ *I like reading historic novels.* ✓ *I like reading historical novels.*（我喜欢读历史小说。）许多其他的词只有一种形式（*scientific* 科学的、*political* 政治的、*basic* 基本的），有些有两种形式但意义相同（*geographic*、*geographical* 地理的）。
:::

## 构成动词

| 后缀 | 意义 | 例子 |
|---|---|---|
| *-ise*、*-ize* | 使……化，成为；使处于某种状态 | *modernise*（使现代化）、*organise*（组织）、*realise*（认识到；实现）、*summarise*（总结）、*globalise*（使全球化） |
| *-ify* | 使…… | *simplify*（简化）、*classify*（分类）、*identify*（识别）、*purify*（净化） |
| *-en* | 使……，变得…… | *widen*（加宽）、*shorten*（缩短）、*darken*（变暗）、*soften*（软化）、*strengthen*（加强）、*lengthen*（加长） |
| *-ate* | （拉丁语型词中）使，做 | *activate*（激活）、*motivate*（激励）、*hyphenate*（用连字符连接） |

*-ise*/*-ize* 和 *-ify* 有能产性，特别是在技术和商务英语中（*digitise* 数字化、*prioritise* 优先处理、*gamify* 游戏化）。*-en* 加在短形容词（*wide*、*short*、*dark*、*soft*）和少数名词（*strength*、*length*）后面；现在不再用它构成新动词。

::: theorem *-ise* 还是 *-ize*？ {#rule-ise-ize}
1. **美式英语**用 *-ize*：*organize*、*realize*、*modernize*。
2. **英式英语**两种都接受。*-ise* 在英国报刊和日常写作中更常见；牛津大学出版社（所谓“牛津拼写”）以及其他一些出版社和国际组织用 *-ize*。无论选哪一种，都要前后一致。
3. 有些动词在两种变体中都**始终**拼作 *-ise*，因为它们的 *-ise* 不是这个后缀，而是词根的一部分：*advertise*（做广告）、*advise*（建议）、*comprise*（包括）、*compromise*（妥协）、*despise*（鄙视）、*exercise*（锻炼）、*improvise*（即兴创作）、*revise*（修改）、*supervise*（监督）、*surprise*（使惊奇）、*televise*（电视播出）。*analyse*（分析）、*paralyse*（使瘫痪）在英式英语中拼作 *-yse*，在美式英语中拼作 *-yze*。
4. 名词随动词而定：*organisation*/*organization*。
:::

## 构成副词

主要的副词后缀是 *-ly*，加在形容词后面：*quick* → *quickly*（快地），*careful* → *carefully*（仔细地），*happy* → *happily*（快乐地），*basic* → *basically*（基本上）（以 *-ic* 结尾的形容词加 *-ally*；*publicly* 公开地 是唯一常见的例外）。还有两个较小的类别：

- *-ward(s)*“朝……方向”：*backward(s)*（向后）、*forward(s)*（向前）、*upward(s)*（向上）、*homeward(s)*（向家）。英式英语作副词时偏好 *-wards*（*walk backwards* 倒着走）；美式英语常用 *-ward*。
- *-wise*“以……方式；就……而言”：*clockwise*（顺时针地）、*likewise*（同样地），非正式地还有 *money-wise*（在钱的方面）、*weather-wise*（就天气而言）（*Weather-wise, it was a good week.* 就天气而言，这一周不错。）这种非正式用法在口语中常见，但正式写作中避免使用。

## 后缀与重音

有些后缀改变基础的读音；另一些不改变。规则见 [[sounds-of-english/word-stress-basics#rule-suffix]] 和 [[sounds-of-english/word-stress-basics#rule-neutral]]：简单地说，*-ion*、*-ic*、*-ical*、*-ity*、*-ial* 和 *-ious* 把重音放在紧挨在它们前面的音节上；*-ee* 和 *-eer* 自己带重音；*-ness*、*-ment*、*-ful*、*-less*、*-ly*、*-er* 和 *-ish* 不移动重音。

那一章只简单提到的一点是：移动重音的后缀常常也会改变基础的**元音**：

| 基础 | 派生词 | 元音变化 |
|---|---|---|
| *nation* /ˈneɪʃn/（国家） | *national* /ˈnæʃnəl/（国家的） | /eɪ/ → /æ/ |
| *sane* /seɪn/（神智正常的） | *sanity* /ˈsænəti/（神智正常） | /eɪ/ → /æ/ |
| *divine* /dɪˈvaɪn/（神的） | *divinity* /dɪˈvɪnəti/（神性） | /aɪ/ → /ɪ/ |
| *serene* /səˈriːn/（宁静的） | *serenity* /səˈrenəti/（宁静） | /iː/ → /e/ |
| *photograph* /ˈfəʊtəɡrɑːf/（GB，照片） | *photography* /fəˈtɒɡrəfi/（GB，摄影） | /əʊ/ → /ə/，/ə/ → /ɒ/ |

拼写保持不变，所以读者一眼就能认出词族，但听者未必：*sanity* 听起来不像 *sane*。这也是要学会每个词族成员的读音、而不只是基础的读音的又一个理由（[[connected-speech/word-stress-patterns]]）。

::: example 词族中的重音和元音 {#ex-stress}
标出每个词的重读音节，并说明哪条后缀规则可以解释它。

1. *produce*（动词，生产）、*production*（生产）、*productive*（多产的）、*productivity*（生产率）
2. *person*（人）、*personal*（个人的）、*personality*（个性）
3. *employ*（雇用）、*employment*（就业）、*employee*（雇员）
::: solution
1. pro**DUCE**——基础。pro**DUC**tion——*-ion*：重音在它前面。pro**DUC**tive——这里 *-ive* 保持基础的重音。produc**TIV**ity /ˌprɒdʌkˈtɪvəti/（GB），/ˌproʊdʌkˈtɪvəti/（GA）——*-ity*：重音在它前面，所以向右移了一个音节。
2. **PER**son——基础。**PER**sonal——这里 *-al* 不移动重音。perso**NAL**ity /ˌpɜːsəˈnæləti/（GB），/ˌpɜːrsəˈnæləti/（GA）——*-ity*：重音在它前面的音节上，*personal* 中弱读的 /ə/ 变成了完整的 /æ/。
3. em**PLOY**——基础。em**PLOY**ment——*-ment* 不影响重音。emplo**YEE**——*-ee* 自己带重音（也有人读 em**PLOY**ee）。
:::
:::

::: quiz
哪个词的重音在**第三个**音节上？
- [ ] *possible*
- [x] *possibility*
- [ ] *impossible*
- [ ] *possibly*
::: solution
*-ity* 把重音放在紧挨在它前面的音节上：pos-si-**BIL**-i-ty /ˌpɒsəˈbɪləti/（GB），/ˌpɑːsəˈbɪləti/（GA）。*Possible*（可能的）和 *possibly*（可能地）重音在第一个音节，*impossible*（不可能的）重音在第二个音节（前缀 *im-* 不带重音）。
:::
:::

::: note 英汉对比
汉语真正的后缀很少。最常见的是“子”（桌子、椅子）、“儿”（花儿，主要在北方话中）、“头”（石头、木头）和表示复数的“们”，“们”主要用于人。此外，还有一组字在许多词中起类似后缀的作用：“者”（作者、读者——接近 *-er*）、“家”（科学家、钢琴家——接近 *-ist*）、“员”（服务员、运动员）、“性”（可能性、重要性——接近 *-ity* 和 *-ness*）和“化”（现代化、全球化——接近 *-ise* 和 *-isation*）。中国语法学家把它们叫作**类后缀**（quasi-suffix）。其中有几个，特别是“性”和“化”，在二十世纪大量翻译欧洲语言的时期变得常用得多。

真正的区别不在于后缀的多少，而在于后缀的用途。在汉语中，“发展”“方便”“成功”这样的词可以作名词、动词或形容词，形式不变；它的作用由它在句中的位置以及“的”“地”这样的词来显示。在英语中，词类通常**在词本身**中由后缀显示，而句子的语法要求用正确的词类。所以中国学习者在写作时要学会每次都问：*Does this place in the sentence need a noun, a verb, an adjective or an adverb?*（句子的这个位置需要名词、动词、形容词还是副词？）——然后选择构成这个词类的后缀。
:::

::: example 修改作文 {#ex-essay}
改正本章开头刘洋句子中的四个词类错误，并解释每一处修改。

> *In the last twenty years, the develop of my city has been very rapidly. The government has made many improves, and people's lives are more convenience than before.*
::: solution
1. *the develop* → *the development*。在 *the* 之后、*of* 之前需要名词；*-ment* 由动词 *develop* 构成名词。
2. *has been very rapidly* → *has been very rapid*。在 *be* 之后需要形容词，而不是副词。（也可以说 *my city has developed very rapidly*，这里副词修饰动词。）
3. *many improves* → *many improvements*。在 *many* 之后需要复数名词；*-ment* 构成名词，*-s* 构成复数。
4. *more convenience* → *more convenient*。在 *are more* 之后需要形容词；*convenience* 是名词。

改正后：*In the last twenty years, the development of my city has been very rapid. The government has made many improvements, and people's lives are more convenient than before.*

**译文：**在过去二十年里，我的城市发展得非常快。政府做了许多改进，人们的生活比以前更方便了。
:::
:::

::: history
后缀 *-ize* 可以追溯到希腊语的动词词尾 *-izein*，它进入拉丁语成为 *-izare*，进入法语成为 *-iser*。英语中以 *-ize* 结尾的动词起初按照希腊语和拉丁语拼作 *z*；*-ise* 这种拼法是后来在法语（词尾拼作 *s*）的影响下在英国流行开来的。诺亚·韦伯斯特（Noah Webster）的《美国英语词典》（*An American Dictionary of the English Language*，1828年）帮助确立了美式拼写中的 *-ize*，而英国的用法一直不统一。牛津大学出版社把 *-ize* 保留为本社的规范，所以带 *z* 的英式拼法被称为“牛津拼写”。今天这两种拼法在英式英语中都是正确的。
:::

## 后续内容

有些后缀会带来拼写变化——*happy* + *-ness* = *happiness*，*hope* + *-ful* = *hopeful*，而 *hope* + *-ing* = *hoping*——[[word-formation/spelling-changes]] 列出这些规则，包括 *-able* 和 *-ible* 之间的选择。一个词也可以**不加任何**后缀而改变词类（*a text* 一条短信，*to text* 发短信）；那是 [[word-formation/conversion]] 的内容。在学术写作中，以 *-tion*、*-ment* 和 *-ity* 构成的名词特别多；[[collocation-and-register/academic-vocabulary]] 讨论这些词，重音模式则在 [[connected-speech/word-stress-patterns]] 中练习。

::: summary
- **后缀**在基础之后；派生后缀给词一个**词类**并增添意义。**最后一个**派生后缀决定词类。
- 由动词构成名词：*-tion*、*-ment*、*-al*、*-ance*/*-ence*、*-ing*。名词形式必须和每个动词一起学（*decision*、*arrival*、*improvement*）；*-ise*/*-ify* 动词用 *-ation*。
- 由形容词构成名词：*-ness*（任何形容词都可以，构成新词时通常用它）和 *-ity*（拉丁语型基础；移动重音）；旧词中有 *-th*（*width* 宽度、*strength* 力量）。
- 表示人：*-er*（能产性最强）、*-or*、*-ist*、*-ian*、*-ant*/*-ent*；*-ee* 表示承受动作的人。
- 形容词：*-able*（有能产性）、*-ful*、*-less*、*-ous*、*-al*、*-ive*、*-ic*/*-ical*（*economic* ≠ *economical*）、*-y*、*-ish*。
- 动词：*-ise*/*-ize*（美式英语用 *-ize*；英式英语两种都用）、*-ify*、*-en*。副词：*-ly*。
- *-ion*、*-ic*、*-ity* 移动重音，并可能改变元音（*sane* → *sanity*）；*-ness*、*-ment*、*-ful*、*-less*、*-ly* 不移动重音。
:::

::: exercise 修改段落 {level=3}
找出并改正这段话中的六个词类错误。

> *Online shopping is very convenience, and it saves a lot of time. But it also has some disadvantage. Deliveries create a lot of pollute, and some products are not safety. I think we should be more care when we buy things online, and the government should strong the rules.*

**译文（按原意）：**网上购物非常方便，而且节省很多时间。但它也有一些缺点。送货造成大量污染，有些产品也不安全。我认为我们网上买东西时应该更加小心，政府也应该加强规定。
::: solution
1. *very convenience* → *very convenient*——*very* 后面用形容词。
2. *some disadvantage* → *some disadvantages*——*some* 和可数名词连用时需要复数名词。
3. *a lot of pollute* → *a lot of pollution*——*a lot of* 后面用名词。
4. *not safety* → *not safe*——*are not* 后面用形容词。
5. *more care* → *more careful*——*be more* 后面用形容词。
6. *should strong the rules* → *should strengthen the rules*——*should* 后面用动词；*-en* 由 *strength* 构成动词。

第2处错误是屈折词尾（复数 *-s*），而不是派生后缀，但它仍是中国学习者很容易忽略的词形错误。

改正后：*Online shopping is very convenient, and it saves a lot of time. But it also has some disadvantages. Deliveries create a lot of pollution, and some products are not safe. I think we should be more careful when we buy things online, and the government should strengthen the rules.*
:::
