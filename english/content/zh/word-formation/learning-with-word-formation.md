周浩在读一篇新闻报道，遇到了三个从没见过的词：*unaffordable*、*carpet* 和 *deregulation*。他用本课程的方法来处理这三个词。*Un-afford-able* 马上就成功了：“负担不起的”，太贵了，句子（*Rents in the city centre have become unaffordable.* 市中心的房租已经让人负担不起了。）也证实了这一点。*De-regul-ation* 花的时间长一些，但 *regular*（有规律的）和 *regulate*（管理，规范）帮了忙：“取消规定”（放松管制），这和一篇关于银行的文章正好吻合。*Carpet* 则是一场灾难。*Car* + *pet* 得出“汽车的宠物”，放在 *We bought a new carpet for the living room.*（我们给客厅买了一块新地毯。）里完全说不通。他查了词典：*carpet*（地毯）在英语里根本没有构成部分。

这就是本章的全部内容。构词部件是学习者手中最有用的工具之一：它们把成千上万个词变成几百个部件和规律。但使用时必须进行两项核查——上下文核查，以及对重要的词进行词典核查——因为有些词只是看起来有构成部分。本章把整个课程汇总成一套方法：怎样根据部件猜词，怎样核查猜测，怎样识别陷阱，以及怎样利用词族成组地学词，而不是一个一个地学。

## 构词部件为什么有用

有三个原因，而且各不相同。

1. **猜测。** 遇到一个新词时，它的构成部分常常能告诉你它的大致意思：*re-* + *write* =“重写”；*-less* =“没有”；*bio-* =“生命”。你可以不停下来，继续往下读。
2. **记忆。** 和已知词联系在一起的新词，比孤立的词更容易记住。如果你认识 *predict*（预测）和 *dictionary*（词典），*contradict*（与……矛盾）就更容易记；如果你认识 *apparent*（明显的），*transparent*（透明的）就更容易记。
3. **产出。** 如果你知道 *-ness* 把形容词变成名词，*-ise*（*-ize*）构成动词，写作时你就能造出需要的形式，并加以核查（*kindness* 善良，*modernise* 使现代化），而不会因为只认识某个词的形容词形式就干脆不用它。

Nation（2013）把学习构词部件列为词汇增长的主要策略之一，与根据上下文猜词、使用词典和用词卡学习并列，因为少数常用词缀出现在数量极多的词中。[[word-formation/prefixes]] 和 [[word-formation/suffixes]] 中的前缀和后缀正是这些常用词缀。

## 构词部件法

::: theorem 构词部件法 {#rule-method}
在文章中遇到一个生词时：

1. 把这个词**拆分**成你认得的部件（[[word-formation/morphemes#rule-split]]），并还原连接处的拼写变化（*happi-ness* → *happy* + *-ness*；[[word-formation/spelling-changes]]）。
2. 根据最后一个后缀（[[word-formation/suffixes#rule-last-suffix]]）和它在句中的位置（[[word-formation/conversion#rule-clues]]）**确定词类**。
3. 把各部分的意义**合起来**，作出初步猜测。
4. **用上下文检验猜测。** 它和句子、段落吻合吗？如果不吻合，换一种拆分方式，或者把这个词当作没有可用部件的整体。
5. **重要的词要查词典核实**，尤其是你自己想用的词；记下确切的意义、读音和一个典型的例句。
:::

::: proof
第4步是学习者最常跳过的一步，而正是这一步使这个方法变得可靠。Nation（2013）综述的关于学习者猜词的研究表明，把词拆成部件、却不用上下文检验结果的学习者，会自信满满地犯错。第1–3步给出一个假设；第4步检验它；第5步确认它，并补充部件永远给不了的东西——确切的现代意义、搭配和语体。因此，这个方法不是“根据部件算出意义”，而是“根据部件作出猜测，再加以检验”。
:::

::: example 使用这个方法 {#ex-method}
对加粗的词使用构词部件法。

> *Many students find the new rules* ***counterproductive***: *they were meant to save time,* *but in fact they make everything slower.*（许多学生认为新规定适得其反：它们本来是为了节省时间，实际上却让一切都变慢了。）
::: solution
1. 拆分：*counter-* + *product* + *-ive*。*Product*（产品）与 *produce*（生产）有关（*pro-*“向前”+ *duc*“引导”；[[word-formation/greek-latin-roots]]）。
2. 词类：*-ive* 构成形容词；它出现在 *find the new rules* 之后（*find something + 形容词*），所以是形容词。
3. 合起来：*counter-*“反对，相反”+ *productive*“产生好结果的”→“与好结果背道而驰的”。
4. 上下文：这些规定本来是为了节省时间，却让事情变慢了——效果与预期相反。猜测吻合。
5. 词典：*counterproductive*“产生与预期相反的效果的”（适得其反的）。猜测是对的，词典使它更加精确。
:::
:::

## 陷阱：错误拆分

::: definition 错误拆分 {#def-false-analysis}
**错误拆分**（false analysis）是把一个词拆成看起来像语素、其实并不是语素的部分。这些字母恰好和某个前缀、后缀或单词相同，但这个词从来不是由它们构成的，“各部分的意义”和这个词的意义毫无关系。
:::

一些容易引起错误拆分的常用词：

| 词 | 错误拆分 | 实际情况 |
|---|---|---|
| *carpet*（地毯） | *car* + *pet* | 一个语素；借自古法语或意大利语，最终来自拉丁语 |
| *butterfly*（蝴蝶） | *butter* + *fly* | 古英语中确实是复合词，但没有人确切知道为什么这种昆虫以黄油命名；各部分解释不了意义 |
| *discuss*（讨论） | *dis-* + *cuss* | 来自拉丁语 *discutere*“摇散，审查”；里面没有英语基础词 *cuss* |
| *deliver*（递送） | *de-* + *liver* | 来自法语，最终来自拉丁语 *de-* + *liberare*“释放”（如 *liberate* 解放）；和肝脏这个器官毫无关系 |
| *island*（岛） | *is* + *land* | 古英语 *īegland*；*s* 是十六世纪在毫不相干的词 *isle*（小岛）的影响下加上去的 |
| *female*（女性） | *fe-* + *male* | 经由法语来自拉丁语 *femella*“年轻女子”；它被改造得像 *male*（男性），但这两个词没有亲缘关系 |
| *pineapple*（菠萝） | *pine* + *apple* | 确实是复合词，但意义已经转移：它最初指松果，后来才用来指这种热带水果 |
| *understand*（理解） | *under* + *stand* | 来自古英语的真正复合词，但它的意义无法从“站在下面”推出 |

这张表展示了两种不同的陷阱。在 *carpet*、*discuss*、*deliver*、*island* 和 *female* 中，这些部分根本不存在。在 *butterfly*、*pineapple* 和 *understand* 中，部分是真的，但意义不是组合性的——不能通过组合各部分推出。上下文核查能同时发现这两种陷阱。

::: warning “词根”太多了
有些流行的记忆书把几乎每个英语单词都拆成“词根”，包括那些根本没有词根的词：把 *pear*（梨）拆成 *p* + *ear*，把 *ambition*（雄心）拆成 *am* + *bit* + *ion*。作为记忆窍门，它们也许能管用一阵子，但教的是错误的习惯：在没有部件的地方看出部件，并且相信部件胜过相信上下文。真正的构词部件是可以核查的：查词典里的词源，或者找一组真正含有这个部件的词（*inspect* 检查、*spectator* 观众、*respect* 尊重都含有 *spect*；*pear* 和 *ear* 没有任何共同之处）。如果你找不到至少两个含有同一部件、意义相关的其他词，就要对这个“部件”存疑。
:::

::: quiz
哪个词**能够**拆分成可以解释其意义的部分？
- [ ] *carpet*
- [ ] *discuss*
- [x] *disagree*
- [ ] *deliver*
::: solution
*Disagree*（不同意）是 *dis-*“不，相反”+ *agree*（同意）：“不同意”——完全是组合性的。*Carpet*、*discuss* 和 *deliver* 只是看起来含有部件（*car*、*dis-*、*de-*）；在英语中，它们都不是由这些部件构成的。
:::
:::

::: example 真部件还是假部件？ {#ex-false}
判断每个词能否有效地拆分，并说明理由。

1. *rewrite*
2. *report*
3. *restaurant*
4. *reread*
5. *recommend*
::: solution
1. 能：*re-*“再”+ *write*（写）。完全是组合性的（重写）。
2. 部分能：*re-*“回”+ *port*“携带”——把消息“带回来”（报告）（[[word-formation/greek-latin-roots]]）。作为记忆辅助有用，但这里的 *re-* 不是“再”的意思，英语里也没有这个意义上的动词 *port*。
3. 不能：*restaurant*（餐馆）来自法语（“使你恢复体力的地方”）；拆出 *re-* 和 *-ant* 得不到任何有用的东西。要作为整词来学。
4. 能：*re-*“再”+ *read*（读）：“重读”。注意读音：/ˌriːˈriːd/。
5. 从历史上看是 *re-* + *commend*“称赞，托付”，但对学习者来说，这些部分推不出“推荐”这个意义。要作为整词来学；注意拼写（一个 *c*，两个 *m*）。

词首的字母 *re* 只有在后面跟着一个真正的基础词（*write*、*read*、*build*、*open*），而且意义是“再”或“回”的时候，才是前缀。
:::
:::

## 当说话者重新分析词语时

错误拆分不只是学习者的错误。母语者也这样做，而当很多人都这样做时，它就可能改变语言。

::: definition 逆构词 {#def-back-formation}
**逆构词**（back-formation）是从一个已有的较长的词中去掉看起来像词缀的部分，构成一个新的、较短的词。较长的词**先**出现：*editor*（编辑）→ *edit*（编辑），*burglar*（入室窃贼）→ *burgle*（入室盗窃），*babysitter*（临时保姆）→ *babysit*（临时照看孩子），*donation*（捐赠）→ *donate*（捐赠），*television*（电视）→ *televise*（电视播送）。说话者把 *-or*、*-ar*、*-er* 和 *-ion* 当作后缀，“还原”出一个从未存在过的动词。
:::

在逆构词中，最初作出的分析是错误的——*burglar* 从来不是 *burgle* + *-ar*——但一旦新词被接受，这个词族就是规则的了：*burgle*/*burglar* 看起来和 *teach*/*teacher*（教/教师）一模一样。对学习者来说，这是个好消息：不管历史如何，这些词对的表现都和普通词族一样。只有很新的或带玩笑性质的逆构词可能仍然显得不够正式（来自 *enthusiasm* 热情 的 *enthuse* 表现出热情，受到一些作者的批评）。

::: definition 民间词源 {#def-folk-etymology}
**民间词源**（folk etymology）是把一个陌生的词或词的一部分改造得像熟悉的词。说话者不理解某个部分，就用一个看起来说得通的东西代替它：

- *cockroach*（蟑螂）来自西班牙语 *cucaracha*，被改造得好像含有 *cock*（公鸡）和 *roach*（拟鲤）；
- *bridegroom*（新郎）来自古英语 *brȳdguma*（*guma*“男人”），在 *guma* 不再使用之后，被改造成含有 *groom*；
- *female*（女性），被改造得像 *male*（见上表）；
- *hamburger*（汉堡包），原意是“来自汉堡的”（*Hamburg* + *-er*），被重新分析为 *ham*（火腿）+ *burger*，由此产生了 *burger*（汉堡）、*cheeseburger*（芝士汉堡）和 *veggie burger*（素汉堡）——尽管汉堡包里并没有火腿。
:::

民间词源也会产生关于词语来历的错误故事。一个有名的故事说，*sincere*（真诚的）来自拉丁语 *sine cera*“没有蜡”，因为诚实的雕刻家不用蜡掩盖裂缝。这个故事很吸引人，但不是真的：这个词来自拉丁语 *sincerus*“干净的，纯的”。和上面那些假词根一样，这类故事可以在好的词源词典中核查，而且应当核查。

::: widget graph
nodes: Hamburg + -er@-4,2; hamburger@-1,2; ham + burger (re-analysis)@2,2; burger@5,4; cheeseburger@5,2; veggie burger@5,0; editor@-4,-2; edit (back-formation)@-1,-2
edges: Hamburg + -er>hamburger; hamburger>ham + burger (re-analysis); ham + burger (re-analysis)>burger; ham + burger (re-analysis)>cheeseburger; ham + burger (re-analysis)>veggie burger; editor>edit (back-formation)

:::

::: example 哪个先出现？ {#ex-back-formation}
每对词中，哪个词更古老？如果没有把握，就查一本给出词源的词典，并说明较新的那个词是不是逆构词。

1. *teach* — *teacher*
2. *edit* — *editor*
3. *donate* — *donation*
4. *write* — *writer*
5. *sightseeing* — *sightsee*
::: solution
1. *teach*（教）更古老；*teacher*（教师）是用 *-er* 构成的普通派生词。
2. *editor*（编辑）更古老；*edit* 是逆构词。
3. *donation*（捐赠）更古老；*donate* 是逆构词。
4. *write*（写）更古老；*writer*（作者）是普通派生词。
5. *sightseeing*（观光）更古老；*sightsee* 是逆构词。

注意，这些词对今天看起来都一样：单凭现代语言，你看不出哪个词先出现。所以日期必须来自词典，而不是来自部件——而且就使用这些词而言，这并不重要。
:::
:::

## 用词族学习

懂得词是怎样构成的，会改变你学词的方式：不是一个一个地学，而是成族地学。词族的概念和词族成员表在 [[core-vocabulary/word-families]] 中介绍；这里我们看怎样利用构词法来扩展这些词族。

::: theorem 扩展词族 {#rule-grow}
每学一个新词，花一分钟扩展它的词族：

1. **屈折形式**：对你来说总是可以规则地构成的形式（*decide*、*decides*、*decided*、*deciding* 决定）。
2. **常用的、规则的派生词**：用本课程中的常用词缀构成的词（*decision* 决定、*decisive* 果断的、*indecisive* 优柔寡断的、*decisively* 果断地、*undecided* 未决定的）。
3. 词族中的**读音变化**，特别是重音和元音的变化（*de**CIDE*** /dɪˈsaɪd/，*de**CI**sion* /dɪˈsɪʒn/；[[sounds-of-english/word-stress-basics#rule-suffix]]）。
4. **空缺和陷阱**：不存在的形式，或者意义和部件所暗示的不同的形式（✗ *decidement*；作形容词用的 *decided* 意为“明确的，确定无疑的”：*a decided advantage* 明显的优势）。

然后在学习词典中核查这个词族，学习词典会把派生形式列在词条末尾或紧挨着的地方。
:::

Bauer 和 Nation（1993）正是为此把英语词缀分成了若干**级别**——用来判断学习者能认出哪些词族成员。在最低的级别，一个词族只包括屈折形式（*decide*、*decides*、*decided*）；接下来的级别加入最常用、最规则的词缀，如 *-er*、*-ness*、*-less*、*-ly*、*un-*、*-ment* 和 *-ful*；最高的级别加入不太常用或以较不规则的方式改变基础词的词缀，最后是 [[word-formation/greek-latin-roots]] 中的古典词根。这些级别是学习顺序的指南：先学规则的、常用的规律，因为它们最快见效。

::: example 一条词族笔记 {#ex-family}
周浩刚学了 *afford*（负担得起）。扩展它的词族，并加上注释。
::: solution
| 形式 | 词类 | 部件 | 注释 |
|---|---|---|---|
| *afford*、*affords*、*afforded*、*affording* | 动词 | — | 通常和 *can*/*could*/*be able to* 连用：*We can't afford a car.*（我们买不起车。） |
| *affordable* | 形容词 | *afford* + *-able* | “不太贵的”：*affordable housing*（经济适用房；一个常用搭配） |
| *unaffordable* | 形容词 | *un-* + *affordable* | 他那篇文章里的词（负担不起的） |
| *affordability* | 名词 | *affordable* + *-ity* | 正式，用于报告和新闻（可负担性）；*-able* → *-abil-ity*（[[word-formation/suffixes#rule-ness-ity]]） |

陷阱：没有 ✗ *affordment*；表示“支付能力”的名词是 *affordability*，不是 ✗ *affordance*（*affordance* 这个词存在，但它是设计学和心理学中的术语，意义不同）。

读音：在各种形式中重音都在 *-ford-* 上：*af**FORD***、*af**FORD**able*、*unaf**FORD**able*；而在 *afforda**BIL**ity* 中，*-ity* 移动了主重音。

一分钟的功夫，一个新词就变成了周浩能认出的五种形式和能使用的四种形式。
:::
:::

::: note 英汉对比
中国学习者本来就是成族地学词汇的——但汉语的词族建立在共同的汉字上。认识“学”，学习者就能认出“学生”“学校”“大学”“学习”“数学”，汉语教学也充分利用了这一点。英语词族的运作方式与此相似，但有两点重要的不同。

第一，英语的部件在视觉上不是分开的。一个汉字始终是一个单位；而一个英语语素必须从一串字母中找出来，它的边界还可能被拼写变化（*happi-ness*）或同化（*im-possible*、*col-lect*）掩盖。所以，要让词族学习法很好地发挥作用，先得掌握本课程中的拆分技能和拼写规则。

第二，一个英语词族通常停留在同一个意义范围内，却改变**词类**（*decide* 决定、*decision* 决定、*decisive* 果断的），学习者必须在每个句子中选对词类。用“学”构成的汉语复合词属于不同的意义范围（学生、学校、大学、数学），而且词类并不标在词上。所以中国学习者在英语中的典型错误，不是理解不了词族，而是选错了成员：✗ *It is important to success*，✗ *I am very interesting in music*。像 [[#rule-grow]] 那样连同词类一起扩展词族，正是针对这类错误的。
:::

::: history
通过构词部件教英语词汇并不是新做法：美国心理学家爱德华·桑代克（Edward Thorndike）在1941年出版了《英语后缀教学》（*The Teaching of English Suffixes*），其中统计了各个后缀出现的频率。从二十世纪八九十年代起，人们对把它作为第二语言学习策略的兴趣日益增长，研究者开始探讨学习者需要多少词，以及应当怎样计算词族。Bauer 和 Nation 的词缀级别（1993年）对计算问题给出了有原则的回答，成为后来研究和教学中使用的许多词族表的基础。此后的研究继续表明，词缀知识随着总词汇量的增长而增长，而且是可以教的。
:::

## 后续内容

本章的方法是推断生词的几种方式之一；一般意义上的根据上下文猜词是 [[reading-skills/words-from-context]] 的内容，用词典核查猜测在 [[core-vocabulary/using-a-dictionary]] 中讲授。怎样复习新词使它们留在记忆中，见 [[core-vocabulary/learning-and-remembering]]。关于构词部件最能发挥作用的学术词汇，见 [[collocation-and-register/academic-vocabulary]]。

::: summary
- 构词部件在三方面有帮助：**猜测**词义、**记住**新词，以及**产出**你需要的形式。
- **构词部件法**：拆分这个词，确定词类，把意义合起来，**用上下文检验猜测**，重要的词查词典核实。
- **错误拆分**把一个词拆成它并不具有的部分（*carpet*、*discuss*、*deliver*、*island*、*female*）；有些真正的复合词不是组合性的（*butterfly*、*understand*）。
- 检验一个“部件”的方法是找出真正含有它的其他词；不要相信编造词根的记忆窍门。
- **逆构词**去掉一个表面上的词缀来构成新词（*editor* → *edit*，*burglar* → *burgle*）；**民间词源**把陌生的词改造得像熟悉的词（*cockroach*，*hamburger* → *burger*）。*sincere* = *sine cera* 这类故事是假的。
- **扩展词族**：屈折形式、常用派生词、读音变化、空缺和陷阱——按 Bauer 和 Nation 的级别所建议的顺序进行。
- 对中国学习者来说，难点不在于理解词族，而在于为句子**选对成员**。
:::

## 练习

::: exercise 拆分并猜测 {level=1}
把每个词拆分成部件，并猜测它的意义。

1. *rethink*
2. *homeless*
3. *unbreakable*
4. *misunderstanding*
5. *powerful*
6. *preview*
::: solution
1. *re-* + *think*：“重新考虑”。
2. *home* + *-less*：“没有家的”（无家可归的）。
3. *un-* + *break* + *-able*：“不能被打破的”（牢不可破的）。
4. *mis-* + *understand* + *-ing*：“没有正确理解”（误解；这里是名词）。
5. *power* + *-ful*：“有很大力量的”（强大的）。
6. *pre-* + *view*：“事先看”——电影或展览在公众看到之前的放映或展出（预览，预展）。
:::
:::

::: exercise 是真部件吗？ {level=1}
哪些词能有效地拆分成可以解释其意义的部分？哪些不能？

*unkind*，*carpet*，*teacher*，*hammer*，*careless*，*island*，*rebuild*，*discuss*
::: solution
能有效拆分的：*unkind*（不友善的；*un-* + *kind*），*teacher*（教师；*teach* + *-er*），*careless*（粗心的；*care* + *-less*），*rebuild*（重建；*re-* + *build*）。

不能有效拆分的：*carpet*（地毯），*hammer*（锤子；这里的 *-er* 不是后缀：锤子不是“做 ham 的人”），*island*（岛），*discuss*（讨论）。
:::
:::

::: exercise 数一数有效拆分 {level=1 check="3"}
下面这些词中，有几个能有效地拆分成一个真正的前缀和一个真正的英语基础词？*rewrite*，*recipe*，*unhappy*，*uncle*，*dislike*，*display*
::: solution
**3**个：*rewrite*（重写）、*unhappy*（不快乐的）、*dislike*（不喜欢）。*Recipe*（食谱）、*uncle*（叔叔）和 *display*（展示）开头的字母相同，但英语里没有意义合适的基础词 *cipe*、*cle* 或 *play*（*display* 来自法语，不是 *dis-* + *play*）。
:::
:::

::: exercise 逆构词 {level=2}
每个动词都是通过逆构词构成的。给出构成它的那个较早的词。

1. *edit*
2. *burgle*
3. *babysit*
4. *donate*
5. *televise*
::: solution
1. *editor*（编辑）。2. *burglar*（入室窃贼）。3. *babysitter*（临时保姆）。4. *donation*（捐赠）。5. *television*（电视）。
:::

::: exercise 使用这个方法 {level=2}
对加粗的词使用构词部件法的五个步骤。写出每一步。

> *The museum is* ***inaccessible*** *to wheelchair users,* *because there are steps at every entrance and no lift.*（这座博物馆坐轮椅的人进不去，因为每个入口都有台阶，也没有电梯。）
::: solution
1. 拆分：*in-* + *access* + *-ible*。
2. 词类：*-ible* 构成形容词；在 *is* 之后，它是形容词。
3. 合起来：*in-*“不”+ *access*“通道，进入”+ *-ible*“能被……的”：“不能进入或到达的”。
4. 上下文：因为有台阶又没有电梯，坐轮椅的人进不去。猜测吻合。
5. 词典：*inaccessible*“难以或无法到达或进入的”（无法进入的）；也指“难以理解的”（*an inaccessible book* 一本难懂的书）。注意是 *-ible*，不是 *-able*（[[word-formation/spelling-changes#rule-able-ible]]）。
:::
:::

::: exercise 选择词族成员 {level=2}
为每个空选出正确的形式。

1. *It is important to ___ in your exams.*（考试取得成功很重要。）（success / succeed / successful）
2. *I am very ___ in music.*（我对音乐很感兴趣。）（interest / interesting / interested）
3. *She made a quick ___.*（她很快作出了决定。）（decide / decision / decisive）
4. *The film was ___ long.*（这部电影长得出人意料。）（surprise / surprising / surprisingly）
5. *We need to ___ the system.*（我们需要简化这个系统。）（simple / simplify / simplicity）
::: solution
1. *succeed*（*to* 后面用动词）。2. *interested*（表示人的感受）。3. *decision*（形容词后面用名词）。4. *surprisingly*（副词，修饰形容词 *long*）。5. *simplify*（*to* 后面用动词）。
:::
:::

::: exercise 核查一个故事 {level=3}
一位同学给你讲了两个关于英语单词的故事。说明哪个是真的，哪个是假的，以及你可以怎样核查。

1. “*Sincere* 来自拉丁语 *sine cera*‘没有蜡’，因为不用蜡掩盖裂缝的罗马雕刻家是诚实的。”
2. “*Hamburger* 和火腿没有关系；它来自汉堡这座城市，*burger* 是后来从它构成的。”
::: solution
1. 假的。*Sincere*（真诚的）来自拉丁语 *sincerus*“干净的，纯的，完整的”；*sine cera* 的故事是一个众所周知的编造。核查：一本给出词源的词典（如《牛津英语词典》或在线词源词典）会给出真正的来源，还常常提到这个错误的故事。
2. 真的。*Hamburger* 是 *Hamburg* + *-er*“来自汉堡的”。说话者把它重新分析为 *ham* + *burger*，于是 *burger* 成了一个词，并成为 *cheeseburger* 和 *veggie burger* 中的构词成分。核查：同样的词典会给出 *burger* 的来源和年代。

总的教训：好听的故事不是证据。要核查词源，就像核查根据部件作出的猜测一样。
:::
:::

::: exercise 扩展一个词族 {level=3}
选一个你最近学的动词（或者用 *produce*、*create* 或 *employ*）。按照 [[#rule-grow]] 扩展它的词族：屈折形式，至少四个派生形式及其词类，每个形式的重音，其中两个形式各一个例句，以及至少一个空缺或陷阱。然后在学习词典中核查每一个形式。
::: solution
以 *employ*（雇用）为例：

- 屈折形式：*employ*、*employs*、*employed*、*employing*
- 派生形式：
  - *employer*（名词，雇用别人的人或公司，雇主）：em**PLOY**er
  - *employee*（名词，被雇用的人，雇员）：em**PLOY**ee 或 employ**EE**（两种读法都能听到）
  - *employment*（名词，就业）：em**PLOY**ment
  - *unemployed*（形容词，失业的）：unem**PLOYED**
  - *unemployment*（名词，失业）：unem**PLOY**ment
  - *employable*（形容词，适合被雇用的）：em**PLOY**able
- 例句：*The factory employs 300 people.*（这家工厂雇用了300人。）—— *Unemployment has fallen this year.*（今年失业率下降了。）
- 陷阱：*-er* 是提供工作的一方，*-ee* 是接受工作的一方（*employer*/*employee*，就像 *interviewer* 面试官/*interviewee* 被面试者）；没有 ✗ *employation*。

你的词族应当只包含你核查过的形式，重音要根据词典标出，而不是靠猜。
:::
:::
