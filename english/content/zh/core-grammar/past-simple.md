比较两个汉语句子：“我昨天去北京”和“我明天去北京”。动词“去”是一样的，只有时间词变了。再比较英语：

- *I **went** to Beijing yesterday.*（我昨天去了北京。）
- *I'**m going** to Beijing tomorrow.*（我明天去北京。）

在英语中，动词本身要变，尽管 *yesterday* 已经告诉了我们时间。这看起来像是浪费：为什么要把“过去”说两遍？但在英语中，动词形式不是可有可无的。*I go to Beijing yesterday* 在每个说英语的人听来都是错的，因为现在时形式表示“习惯或现在”，而 *yesterday* 表示“过去”，两者互相矛盾。

这一课讲**一般过去时**（past simple）：规则的 *-ed* 词尾及其拼写和三种读音，最常见的不规则动词，用 *did* 构成的疑问句和否定句，以及什么时候用一般过去时。它还要解释为什么汉语的“了”和英语的过去时不是一回事。

## 形式

::: definition 一般过去时 {#def-past-simple}
**一般过去时**是不带助动词使用的动词过去式。**规则动词**（regular verb）用词尾 ***-ed*** 构成过去式：*work* → *worked*，*live* → *lived*。**不规则动词**（irregular verb）有自己的过去式，必须记住：*go* → *went*，*see* → *saw*。一般过去时**对所有主语都用同一个形式**（*I worked*、*she worked*、*they worked*），只有 *be* 例外，它有 *was* 和 *were*。
:::

- *I **watched** a film last night.*（我昨晚看了一部电影。）
- *She **lived** in Japan for two years.*（她在日本住过两年。）
- *We **went** to the beach on Sunday.*（我们星期天去了海边。）
- *They **were** very tired after the trip.*（旅行之后他们很累。）

过去时没有 *-s*：✗ *He workeds.* *be* 的过去式（*was*、*were*）见 [[core-grammar/be-and-have]]。

### *-ed* 的拼写

::: theorem 规则过去式的拼写 {#rule-ed-spelling}
1. 大多数动词加 ***-ed***：*work* → *worked*，*play* → *played*，*open* → *opened*。
2. 以 ***-e*** 结尾的动词只加 ***-d***：*live* → *lived*，*like* → *liked*，*agree* → *agreed*。
3. 以**辅音字母 + *-y*** 结尾的动词，把 *y* 变为 ***-ied***：*study* → *studied*，*try* → *tried*，*carry* → *carried*。元音字母后的 *-y* 不变：*play* → *played*，*stay* → *stayed*。（但 *pay* → *paid*、*say* → *said*、*lay* → *laid* 是不规则的。）
4. 以**一个元音字母 + 一个辅音字母**结尾、且**重音在最后一个音节**的动词，双写这个辅音字母：*stop* → *stopped*，*plan* → *planned*，*prefer* → *preferred*。最后一个音节不重读时不双写：*visit* → *visited*，*open* → *opened*，*happen* → *happened*。*w*、*x*、*y* 从不双写：*fix* → *fixed*，*show* → *showed*。
5. 英式英语中，一个元音字母后的词尾 *-l* 即使不重读也要双写（*travel* → *travelled*，*cancel* → *cancelled*）；美式英语通常不双写（*traveled*、*canceled*）。
:::

::: proof
这些规则和 *-ing*（[[core-grammar/present-continuous#rule-ing-spelling]]）以及 *-s* 词尾（*study* → *studies*，[[core-grammar/present-simple#rule-s-spelling]]）的拼写规则相同。双写使短元音保持短元音：*planned* 读 /plænd/，而 *planed* 读 /pleɪnd/（来自 *plane*）。与 *-ing* 有一个不同：加 *-ing* 时我们保留 *y*（*studying*，以避免出现 *ii*），加 *-ed* 时则要变（*studied*）。
:::

### *-ed* 的读音

::: theorem 规则过去式的读音 {#rule-ed-sound}
词尾 *-ed* 有三种读音，由动词的最后一个**音**决定：

1. 在 **/t/** 或 **/d/** 之后：读 **/ɪd/**（GA 常读 /əd/），多出一个音节：*wanted*、*needed*、*visited*、*decided*。
2. 在其他**清音**——/p/、/k/、/f/、/s/、/ʃ/、/tʃ/、/θ/——之后：读 **/t/**：*stopped*、*worked*、*laughed*、*missed*、*washed*、*watched*。
3. 在**浊音**——其他所有辅音和所有元音——之后：读 **/d/**：*lived*、*played*、*opened*、*called*、*changed*、*cried*。
:::

::: proof
道理和 *-s* 词尾一样（[[core-grammar/present-simple#rule-s-sound]]）。/t/ 是清音，/d/ 是浊音，所以词尾与它前面那个音的清浊保持一致。在 /t/ 或 /d/ 之后，再加一个 /t/ 或 /d/ 就听不出来了（*want* + /t/ 听起来就像 *want*），所以要插入一个元音。注意拼写并不显示读音：*stopped* 只有一个音节，/stɒpt/（GB）、/stɑːpt/（GA），尽管它有六个字母、两个元音字母。有两个形容词保留了古老的 /ɪd/：*naked* /ˈneɪkɪd/（赤裸的）和 *wicked* /ˈwɪkɪd/（邪恶的）；还有一些以 *-ed* 结尾的形容词读 /ɪd/，而相应的动词读 /d/ 或 /t/：*a learned* /ˈlɜːnɪd/ *professor*（一位博学的教授），*an aged* /ˈeɪdʒɪd/ *relative*（一位年迈的亲戚）——但 *She learned* /lɜːnd/ *fast*（她学得很快）。
:::

中国人常犯两种发音错误之一：给每个 *-ed* 都加上元音（把 *worked* 读成 ✗ “work-ed”，两个音节），或者干脆把词尾丢掉，使 *I worked* 听起来像 *I work*。练习这些辅音连缀：*worked* /wɜːkt/（GB）、/wɜːrkt/（GA）以 /kt/ 结尾，*lived* /lɪvd/ 以 /vd/ 结尾。

::: example *-ed* 的拼写和读音 {#ex-ed}
写出一般过去时，并说明 *-ed* 怎么读：*hope*、*hop*、*need*、*cry*、*kiss*、*enjoy*、*permit*、*rain*。
::: solution
| 动词 | 过去式 | 拼写规则 | *-ed* 的读音 |
|---|---|---|---|
| *hope*（希望） | *hoped* | 以 *e* 结尾：加 *-d* | /t/（在 /p/ 之后） |
| *hop*（跳） | *hopped* | 一个元音字母 + 一个辅音字母，重读：双写 | /t/（在 /p/ 之后） |
| *need* | *needed* | 加 *-ed* | /ɪd/（在 /d/ 之后） |
| *cry* | *cried* | 辅音字母 + *y* → *-ied* | /d/（在元音 /aɪ/ 之后） |
| *kiss* | *kissed* | 加 *-ed* | /t/（在 /s/ 之后） |
| *enjoy* | *enjoyed* | 元音字母 + *y*：加 *-ed* | /d/ |
| *permit* | *permitted* | 重音在 *-mit*：双写 | /ɪd/（在 /t/ 之后） |
| *rain* | *rained* | 加 *-ed* | /d/（在 /n/ 之后） |

*Hoped* 和 *hopped* 的元音读音不同（GB 分别是 /həʊpt/ 和 /hɒpt/），拼写用双写的 *p* 表明了这一点。
:::
:::

::: quiz
下面哪个动词的 *-ed* 读作多出来的一个音节 /ɪd/？
- [ ] *walked*
- [ ] *played*
- [x] *started*
- [ ] *watched*
::: solution
*Start* 以 /t/ 结尾，所以 *started* 读作 /ˈstɑːtɪd/（GB）、/ˈstɑːrtəd/（GA）——两个音节。*Walked* 和 *watched* 以 /t/ 结尾（在清音 /k/ 和 /tʃ/ 之后），*played* 以 /d/ 结尾（在元音之后）。这三个词都只有一个音节。
:::
:::

### 不规则动词

英语大约有两百个不规则动词，但大多数很少用。然而，最常用的动词往往是不规则的：*be*、*have*、*do*、*say*、*go*、*get*、*make*、*know*、*think*、*take*、*see* 和 *come* 都是不规则动词，而且是英语中使用频率最高的动词之一。按相同的变化模式分组学习会有帮助。

| 模式 | 动词 |
|---|---|
| 不变 | *cut* → *cut*，*put* → *put*，*hit* → *hit*，*let* → *let*，*cost* → *cost*，*set* → *set*，*shut* → *shut* |
| 拼写相同，读音改变 | *read* /riːd/ → *read* /red/ |
| *-ought* / *-aught* | *buy* → *bought*，*bring* → *brought*，*think* → *thought*，*fight* → *fought*，*catch* → *caught*，*teach* → *taught* |
| *-d* → *-t* | *send* → *sent*，*spend* → *spent*，*build* → *built*，*lend* → *lent* |
| 长元音 → 短元音 + *t* | *keep* → *kept*，*sleep* → *slept*，*feel* → *felt*，*leave* → *left*，*meet* → *met*，*mean* → *meant* |
| 元音 *i* → *a* | *begin* → *began*，*drink* → *drank*，*sing* → *sang*，*swim* → *swam*，*sit* → *sat*，*give* → *gave* |
| 元音 → *o* | *write* → *wrote*，*drive* → *drove*，*ride* → *rode*，*speak* → *spoke*，*break* → *broke*，*choose* → *chose*，*sell* → *sold*，*tell* → *told* |
| 元音 → *oo* / *ew* | *take* → *took*，*stand* → *stood*，*understand* → *understood*，*know* → *knew*，*grow* → *grew*，*fly* → *flew*，*throw* → *threw* |
| *-ay* → *-aid* | *say* → *said* /sed/，*pay* → *paid*，*lay* → *laid* |
| 其他 | *go* → *went*，*do* → *did*，*see* → *saw*，*eat* → *ate*，*come* → *came*，*run* → *ran*，*get* → *got*，*find* → *found*，*have* → *had*，*make* → *made*，*hear* → *heard*，*lose* → *lost*，*wear* → *wore*，*forget* → *forgot* |

有几个动词既有规则的过去式，也有不规则的过去式。在英式英语中，*learnt*、*dreamt*、*spelt*、*burnt* 和 *smelt* 与 *learned*、*dreamed* 等并存，都很常见；美式英语通常更喜欢 *-ed* 形式。两种都正确。美式英语还有一些英式英语没有的不规则形式，比如 *dove*（与 *dived* 并存）和非正式的 *snuck*（与 *sneaked* 并存）。学习型词典列出了每个不规则动词的过去式。

## 疑问句和否定句

::: theorem 一般过去时的疑问句和否定句 {#rule-did}
疑问句和否定句对所有主语都用 ***did***，后面跟主要动词的**原形**：

- 否定句：*主语 + did not (didn't) + 原形*：*I **didn't go**.*（我没去。）*She **didn't like** it.*（她不喜欢。）
- 疑问句：*（疑问词 +）did + 主语 + 原形*：***Did** you **go**?*（你去了吗？）*Where **did** she **work**?*（她以前在哪里工作？）
- 简略回答：*Yes, I did.* *No, they didn't.*

*be* 用 *was* 和 *were* 作自己的操作词：*I wasn't there.*（我当时不在那儿。）*Were you at home?*（你当时在家吗？）*could* 这样的情态动词也不需要 *did*：*I couldn't come.*（我来不了。）
:::

::: proof
这就是 [[core-grammar/questions-and-negatives#rule-operator]] 中的操作词体系用于过去时。*Did* 是 *do* 的过去式：它承载过去时，所以主要动词回到原形。在两个动词上都标过去时（✗ *Did you went?*）就把过去标了两次，英语不允许这样做，正如它不允许两个 *-s* 词尾（✗ *Does she likes?*）一样。主语疑问句照例不需要 *did*：*Who **told** you?*（谁告诉你的？）*What **happened**?*（发生了什么事？）
:::

- *Did you see the match last night? — Yes, I did. It was great!*（你看昨晚的比赛了吗？——看了。太精彩了！）
- *I didn't hear the alarm, so I was late.*（我没听见闹钟，所以迟到了。）
- *Where did you buy that coat?*（你那件外套是在哪儿买的？）
- *Why didn't you call me?*（你为什么没给我打电话？）
- *What time did the train arrive?*（火车几点到的？）
- *Who ate the last dumpling?*（谁吃了最后一个饺子？）（主语疑问句：不用 *did*）

::: warning 一个动词短语里有两个过去式
✗ *Did you went to the party?* ✓ *Did you go to the party?*（你去参加聚会了吗？）

✗ *I didn't saw him.* ✓ *I didn't see him.*（我没看见他。）

✗ *Where did she bought it?* ✓ *Where did she buy it?*（她是在哪儿买的？）

✗ *Who did tell you?*（作为主语疑问句）✓ *Who told you?*（谁告诉你的？）

在 *did* 或 *didn't* 之后，主要动词总是用原形。过去时只标一次，标在 *did* 上。
:::

::: example 疑问句和否定句 {#ex-did}
把句子变成否定句，然后构成一个一般疑问句，再就括号中的部分构成一个 *wh-* 疑问句。*Kenji bought [a new camera] last week.*（健二上星期买了一台新相机。）
::: solution
1. 否定句：没有操作词，所以加 *didn't*，并用原形 *buy*：*Kenji **didn't buy** a new camera last week.*
2. 一般疑问句：*did* 放在主语前，用原形：***Did** Kenji **buy** a new camera last week? — Yes, he did.*
3. *Wh-* 疑问句：括号中的部分是宾语（一样东西）→ *what*：***What did** Kenji **buy** last week?*（健二上星期买了什么？）——*A new camera.*

主语疑问句不需要 *did*：*Who bought a new camera last week?*（谁上星期买了一台新相机？）——*Kenji (did).*
:::
:::

## 意义和用法

::: theorem 一般过去时的用法 {#rule-past-uses}
一般过去时用于：

1. **在过去某个确定时间完成的动作和事件**：*I met her in 2019.*（我是2019年认识她的。）*The shop closed at six yesterday.*（商店昨天六点关的门。）
2. **已经结束的过去状态和情况**：*We lived in a small flat when I was a child.*（我小时候我们住在一套小公寓里。）*He was very shy at school.*（他上学时很害羞。）
3. **过去的习惯**：*I walked to school every day.*（我以前每天步行上学。）（也可以说 *I used to walk*，见 [[tense-and-aspect/past-habits]]。）
4. 故事中按发生顺序叙述的**一连串事件**：*She opened the door, looked around and switched on the light.*（她打开门，四处看了看，然后打开了灯。）
:::

::: proof
一般过去时把情况置于一个**已经结束、与现在分开**的时间里。这个时间可以说出来（*yesterday*、*in 2019*、*two weeks ago*），也可以由上下文表明（一个故事，一次关于某人童年的谈话）。因为那段时间已经结束，一般过去时对现在什么也没说：*She lived in Paris*（她在巴黎住过）暗示她现在不住在那里了。当一个事件与现在相联系、而不是与一个已经结束的时间相联系时——*I've lost my keys*（我把钥匙丢了）（我现在仍然没有钥匙）——英语常常改用现在完成时；这种对比在 [[tense-and-aspect/present-perfect]] 中讲解。
:::

与一般过去时连用的常见时间词语有：*yesterday*（昨天）、*last night*（昨晚）、*last week*（上星期）、*last year*（去年）、*in 2015*（在2015年）、*on Monday*（在星期一）、*at three o'clock*（在三点钟）、*when I was young*（我年轻的时候），以及放在一段时间之后的 ***ago***：*two days ago*（两天前）、*a long time ago*（很久以前）。

::: warning *ago* 和 *before*
✗ *I came to Shanghai before three years.* ✓ *I came to Shanghai three years ago.*（我三年前来到上海。）

要从现在往回算，就把 ***ago*** 放在那段时间的**后面**。*before* + 一段时间（*before three years*）不这样用；*before* 放在一个时间点或事件之前（*before 2020*“2020年以前”，*before lunch*“午饭前”）。汉语的“三年前”把“前”放在数字后面，和英语的 *ago* 一样。
:::

::: example 讲故事 {#ex-story}
用动词的一般过去时完成这个故事，并指出哪些是不规则动词。

*Last Saturday Li Na (1 wake) up early. She (2 make) some tea, (3 pack) a small bag and (4 take) the bus to the mountains. The weather (5 be) perfect. She (6 walk) for three hours and (7 stop) for lunch by a lake. On the way back she (8 see) a group of monkeys, but they (9 not come) close. She (10 get) home at seven, tired but happy.*

**译文：**上星期六，李娜起得很早。她泡了点茶，收拾了一个小包，坐公共汽车去了山里。天气好极了。她走了三个小时，在一个湖边停下来吃午饭。回来的路上她看到一群猴子，但它们没有靠近。她七点到家，虽然很累，但很开心。
::: solution
(1) *woke*（不规则）；(2) *made*（不规则）；(3) *packed*（规则，读 /t/）；(4) *took*（不规则）；(5) *was*（不规则，*be*，单数主语）；(6) *walked*（规则，读 /t/）；(7) *stopped*（规则，双写 *p*，读 /t/）；(8) *saw*（不规则）；(9) *didn't come*（用 *didn't* + 原形构成否定）；(10) *got*（不规则）。

在故事中，每一个描述事件的限定动词都用过去时，尽管 *Last Saturday* 已经确定了时间。汉语则不需要给每个动词都加标记。
:::
:::

::: quiz
哪个句子是正确的？
- [ ] *I see her two days ago.*
- [ ] *Did she called you yesterday?*
- [x] *We didn't have time to finish.*
- [ ] *He goed home early.*
::: solution
*We didn't have time*（我们没有时间完成）用的是 *didn't* + 原形 *have*。其他几句需要过去式 *saw*（*I saw her two days ago*“我两天前见过她”），*did* 之后要用原形（*Did she call you?*“她给你打电话了吗？”），以及不规则过去式 *went*（*He went home early*“他早早回家了”）。✗ *goed* 这样的形式是很自然的错误——以英语为第一语言的幼儿也会犯，因为他们把规则变化用到了所有动词上。
:::
:::

::: example “了”和英语的过去时 {#ex-le}
译成英语，并说明每个句子中“了”和英语一般过去时是否同时出现。(a) 我昨天买了一本书。(b) 我昨天很累。(c) 你吃了饭再走吧。(d) 我以前不喜欢吃辣的。
::: solution
(a) *I bought a book yesterday.* 这里“了”（完成）和过去时（*bought*）同时出现，因为完成的动作在过去。

(b) *I was very tired yesterday.* 汉语没有“了”，但英语需要过去式 *was*：这种状态属于一个已经结束的时间。

(c) *Have something to eat before you go.*（或 *Eat first, then go.*）“了”表示吃饭将在离开之前完成，但时间是将来，所以英语不用过去时。

(d) *I didn't like spicy food before.*（或 *I never used to like spicy food*；*used to* 在 [[tense-and-aspect/past-habits]] 中讲解。）没有“了”，但这是过去的状态：*didn't like*。

所以，英语的过去时跟着情况发生的**时间**走，而“了”跟着**完成**走。两者经常同时出现，如 (a)，但谁也不能预示另一个。
:::
:::

::: note 英汉对比
- **“了”不是过去时。** 动词后的“了”表示动作完成（完成体），而不表示动作发生在过去。它可以出现在关于将来的句子里（明天吃了饭再走），而许多关于过去的句子没有“了”（我以前住在上海 → *I lived in Shanghai before*；他昨天很忙 → *He was very busy yesterday*）。所以“把‘了’译成 *-ed*”不是一条可靠的规则。在英语中，每一个关于过去的限定动词都要用过去式，不管汉语用不用“了”。
- **光有时间词不够。** 汉语用“昨天”“去年”“以前”这样的词表示过去时间，动词保持不变。英语既需要时间词，也需要过去式：*I went there last year.*（我去年去过那儿。）
- **“过”和经历。** “我去过北京”（我曾经在某个时候到过北京）通常译成现在完成时 *I've been to Beijing*，除非说出了一个过去的时间：*I went to Beijing in 2018*（我2018年去过北京）。见 [[tense-and-aspect/present-perfect]]。
- **过去的状态。** 汉语的形容词和“是”不随过去时间变化（他小时候很胖）；英语的 *be* 要变：*He was quite chubby as a child.*（他小时候胖乎乎的。）记得给动词加 *-ed* 的学习者，常常忘了用 *was* 和 *were*。
- **词尾辅音连缀。** /kt/、/pt/、/vd/ 这样的词尾在普通话里不存在，所以说话时 *-ed* 很容易被丢掉；发出一个短而清楚的 /t/ 或 /d/ 就够了。

汉语体助词与英语时态的关系在 [[tense-and-aspect/tense-and-chinese]] 中详细讨论。
:::

::: history
英语动词分属两个古老的家族。**强变化动词**（strong verb）通过改变元音构成过去式，*sing* → *sang*、*drive* → *drove* 至今仍是这样；**弱变化动词**（weak verb）加上一个带 *-d* 或 *-t* 的词尾，那就是 *-ed* 的前身。所有新动词都加入弱变化（规则）类型——*googled*（用谷歌搜索了）、*texted*（发了短信）、*emailed*（发了电子邮件）——而且几百年来，许多强变化动词也转了过去：*help* 的过去式曾经是 *holp*，*climb* 的过去式曾经是 *clomb*。埃雷兹·利伯曼（Erez Lieberman）等人发表在《自然》（*Nature*，2007年）上的一项研究追溯了古英语中的177个不规则动词，发现其中98个至今仍不规则；动词越少用，变得规则就越快，而 *be*、*have*、*go*、*see* 这样非常常用的动词则保留了不规则形式。变化偶尔也朝相反的方向进行：美式英语有 *dove* 和 *snuck*，与较老的规则形式 *dived* 和 *sneaked* 并存。
:::

## 后续学习

一般过去时是讲故事的基本时态。《时与体》课程在此基础上讲解过去进行时和过去完成时（[[tense-and-aspect/narrative-tenses]]），表示过去习惯的 *used to* 和 *would*（[[tense-and-aspect/past-habits]]），以及一般过去时与现在完成时的区别（[[tense-and-aspect/present-perfect]]）。情态动词的过去形式（*could*、*had to*）见 [[core-grammar/first-modals]]。

::: summary
- 一般过去时对所有主语用同一个形式（*be* 除外：*was*/*were*）：规则动词加 *-ed*；不规则动词有自己的形式（*went*、*saw*、*took*）（[[#def-past-simple]]）。
- 拼写：以 *e* 结尾加 *-d*，辅音字母 + *y* → *-ied*，单个重读元音字母后的末尾辅音字母双写（*stopped*），英式 *travelled* / 美式 *traveled*（[[#rule-ed-spelling]]）。
- 读音：在 /t/ 和 /d/ 后读 /ɪd/，在其他清音后读 /t/，其余情况读 /d/（[[#rule-ed-sound]]）。
- 疑问句和否定句对所有主语都用 *did* + 原形：*Did you go?*（你去了吗？）*I didn't go.*（我没去。）绝不能说 ✗ *Did you went*（[[#rule-did]]）。
- 一般过去时用于在确定的过去时间完成的动作和状态、过去的习惯以及一连串事件（[[#rule-past-uses]]）；往回算时间用 *ago*（*three years ago*“三年前”）。
- 汉语的“了”表示完成，而不表示过去时间；在英语中，每一个关于过去的动词都要用过去式，即使句中已经有 *yesterday*。
:::

::: exercise 否定句和疑问句 {level=2}
写出否定句和一般疑问句。(a) *She found her keys.*（她找到了钥匙。）(b) *They were at home.*（他们当时在家。）(c) *He understood the question.*（他理解了这个问题。）(d) *We had a good time.*（我们玩得很开心。）
::: solution
(a) *She didn't find her keys.* / *Did she find her keys?* (b) *They weren't at home.* / *Were they at home?* (c) *He didn't understand the question.* / *Did he understand the question?* (d) *We didn't have a good time.* / *Did we have a good time?*（或者问另一个人：*Did you have a good time?*）

::: exercise 关于过去的疑问句 {level=2}
写出以下面的话为答案的疑问句。(a) *I went to Hainan.*（我去了海南。）（*Where …?*）(b) *We left at six.*（我们六点离开的。）（*What time …?*）(c) *She paid 200 yuan.*（她付了200元。）（*How much …?*）(d) *My brother broke it.*（是我弟弟弄坏的。）（*Who …?*）(e) *Because I was ill.*（因为我病了。）（*Why …?*——问为什么没来上课）

::: exercise 改正错误 {level=2}
改正句子。(a) *I buyed a new phone yesterday.* (b) *When you arrived?* (c) *She didn't knew the answer.* (d) *We go to the cinema last night.* (e) *I met him before two weeks.* (f) *Did you enjoyed the film?*
::: solution
(a) *I **bought** a new phone yesterday.*（我昨天买了一部新手机。）(b) *When **did you arrive**?*（你什么时候到的？）(c) *She didn't **know** the answer.*（她不知道答案。）(d) *We **went** to the cinema last night.*（我们昨晚去看电影了。）(e) *I met him **two weeks ago**.*（我两个星期前见过他。）(f) *Did you **enjoy** the film?*（你喜欢这部电影吗？）
:::

::: exercise 翻译 {level=3}
译成英语，在英语需要的地方用一般过去时。

(a) 我昨天没去上班，因为我病了。(b) 你上周末做了什么？(c) 他小时候住在农村。(d) 我们五年前认识的。(e) 她打开窗户，看了看外面，然后笑了。
::: hint
即使没有“了”，也要找出过去的时间；检查每一个动词，包括 *be*。
:::
::: solution
(a) *I didn't go to work yesterday because I was ill.*（美式英语常用 *sick*）——用 *was*，不能用 ✗ *am*。

(b) *What did you do last weekend?*（美式英语也说 *on the weekend*）

(c) *He lived in the countryside when he was a child.*（或 *as a child*）——汉语没有“了”，但英语要用过去时。

(d) *We met five years ago.*（*meet* = 初次认识；*ago* 放在那段时间之后）

(e) *She opened the window, looked outside and then smiled.*（一连串事件；*looked* 译“看了看”，即看一下）
:::
:::

::: exercise 写写某一天 {level=3}
写一段八到十句的短文，讲讲你生活中难忘的一天。至少用六个不规则动词、一个否定句和一个疑问句（例如那天你问别人的一个问题）。
::: solution
答案因人而异。示例：

*The day I got my university results was one of the happiest of my life. I woke up very early, but I didn't want to check the website alone. I went to my grandmother's flat, and she made me a bowl of noodles. My hands shook when I typed my number. Then I saw my score and shouted so loudly that the neighbour knocked on the door. "Did something happen?" he asked. My grandmother laughed and told him the news. In the evening my whole family came for dinner, and we ate and talked until midnight.*

**译文：**我拿到高考成绩的那一天，是我一生中最快乐的日子之一。我醒得很早，但不想一个人查网站。我去了奶奶家，她给我煮了一碗面。我输入考号时手在发抖。然后我看到了分数，大喊了一声，声音大得连邻居都来敲门了。“出什么事了吗？”他问。奶奶笑着把消息告诉了他。晚上全家人都来吃饭，我们边吃边聊，一直到半夜。

检查：不规则过去式（*got*、*was*、*woke*、*went*、*made*、*shook*、*saw*、*told*、*came*、*ate*）；否定句 *didn't want* + 原形；疑问句 *Did something happen?* 用 *did* + 原形；规则过去式的读音正确（*typed* /t/、*shouted* /ɪd/、*knocked* /t/、*asked* /t/、*laughed* /t/、*talked* /t/）。
