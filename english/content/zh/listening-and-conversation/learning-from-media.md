吴杰看了几百个小时带中文字幕的英语电视剧。他熟悉里面的人物、笑话和结局。可是当他试着不看字幕看一集时，听懂的比他预想的少得多；和讲英语的同事谈话时，他的听力也没有多大长进。他的同学 Nadia 看得少得多，但方法不同：看她熟悉的话题的短视频，先带英文字幕看，再不带字幕看，常常看好几遍，有时还把说话人的句子大声跟着说出来。一年以后，她的听力明显比他好。

差别不在于英语的量，而在于**怎样**使用它。录音、播客、电影、电视和网上的演讲，是大多数学习者所能接触到的最丰富的英语口语来源——声音、口音和情境比任何课堂都多得多。但是听媒体并不自动等于学习。本章说明怎样选择难度合适的材料，怎样分阶段使用字幕，怎样把重量的**泛听**和重细节的**精听**结合起来，怎样练习**跟读**（shadowing），以及怎样让学过的词变成听得出来的词。它把[[listening-and-conversation/how-listening-works]]和[[connected-speech/hearing-fast-speech#rule-practice]]中的观点付诸实践，并且是[[reading-skills/extensive-reading]]在听力方面的搭档。

## 选择材料

::: theorem 选择你大部分能听懂的材料 {#rule-choose}
做日常听力练习时，选择这样的录音：

1. **你大部分能听懂**——不费力就能听懂大意，花些力气能听懂大部分细节；
2. **话题是你了解或关心的**，这样你的背景知识能帮上忙（[[listening-and-conversation/how-listening-works#def-schema]]）；
3. **音质好**，而且一开始只有一两个说话清楚的人，而不是很多人同时说话；
4. **短到可以反复听**——做精听时，两到五分钟；
5. 随着时间推移，**来自许多说话人和许多口音**（[[listening-and-conversation/accents#rule-adapt]]）。
:::

::: proof
关于词汇覆盖率的研究解释了第一点。韦布和罗杰斯（Webb and Rodgers 2009）分析了大量电影和电视节目的语言，估计观众需要认识最常用的大约3,000个词族，再加上专有名词和 *um* 这类边缘词，才能认识95%的词；要达到98%，大约需要两倍的词汇量。低于这个水平，不认识的词太多，听话人无法从语境中猜出其余的部分（[[core-vocabulary/frequency-and-coverage]]）。熟悉的话题有帮助，因为自上而下的知识能填补单靠声音留下的空缺。音质清楚、说话人少，能让还很慢的解码过程得以进行。短的录音可以一遍又一遍地听——这是在细节上下功夫的唯一途径。而许多不同的声音，能让听话人知道哪些东西属于这门语言，而不是属于某一个说话人。
:::

不同类型的材料适合不同的阶段：

| 材料 | 为什么有帮助 | 难度 |
|---|---|---|
| 为学习者编写的**分级音频**（分级读物的有声版、学习者播客） | 词汇受控，说话清楚，常常附有文稿 | 最容易 |
| 熟悉话题的**演讲和讲座** | 一个说话人，有准备的话语，常常有文稿或英文字幕 | 中等 |
| **新闻**报道 | 标准口音，结构清楚，但信息密集，语速快 | 中等到难 |
| **访谈和对话类播客** | 真实的会话，有反馈语、犹豫，有几个说话人 | 中等到难 |
| **纪录片** | 旁白清楚，画面辅助理解意思 | 中等 |
| **电影和电视剧** | 说话人多，有俚语、情绪、噪音，话语快速重叠 | 最难 |

表中的顺序只是一个粗略的参考，而不是规则。一部以你熟悉的工作环境为背景的喜剧，可能比一篇关于经济的新闻报道更容易。检验标准始终是[[#rule-choose]]：你能听懂大部分吗？

::: example 为学习者选择材料 {#ex-choose}
三个学习者来征求意见。为每个人推荐材料，并解释原因。

1. 李娜能听懂慢而清楚的话，但在正常的会话中就跟不上了。她喜欢做饭。
2. Rafael 能听懂新闻，但觉得电影很难。他是一名护士。
3. 金智宇（Kim Ji-woo）能听懂大多数美国人说话，但英国犯罪剧几乎一句也听不懂。
::: solution
1. **李娜**：做饭的视频和播客，从一位边做边讲解的主持人开始。话题熟悉，画面辅助理解意思（[[#rule-choose]]，第1点和第2点）。之后再看有几个说话人、会话自然的烹饪比赛节目。
2. **Rafael**：关于健康和护理的访谈和对话类播客——熟悉话题的真实会话——然后再看医院题材的电视剧，在那里，话题仍然有助于他听懂电影中更快、更带情绪的话语。
3. **金智宇**：先听来自英国不同地区的说话人的简短访谈和演讲，然后看那部电视剧本身，一开始带英文字幕（[[#rule-subtitles]]）。问题在于对口音的经验，而不是总体的英语水平（[[listening-and-conversation/accents#rule-strategies]]）。
:::
:::

## 字幕

字幕是关于从媒体中学习最常见的问题，而研究给出了一个相当清楚的答案。

::: definition 字幕和同语字幕 {#def-subtitles}
观众母语（这里是中文）的**字幕**（subtitles）翻译所说的内容。**同语字幕**（captions，节目是英语时也叫*英文字幕*）用同一种语言显示实际说出的词。**文稿**（transcript）是录音的完整文本，在听之前或之后阅读。
:::

::: theorem 分阶段使用字幕 {#rule-subtitles}
1. **中文字幕**能帮助你欣赏和理解故事，但你主要是在**读**中文，所以它们对你的英语听力帮助不大。把它们用于娱乐，或者用于第一遍看较难的材料。
2. **英文字幕**把声音和书面的词联系起来。这是对学习最有用的阶段：你能看到一个词在哪里结束、下一个词在哪里开始，也能注意到书面的词在快速话语中是怎么读的。
3. **不看字幕**是目标。先用已经带英文字幕看过的材料过渡到不看字幕，再用难度较低的新材料。

处理一个短片段的好方法：**不看字幕**看一遍，抓大意 → 带**英文字幕**看一遍，核对并留意 → **不看字幕**再看一遍。
:::

::: proof
米特勒和麦奎因（Mitterer and McQueen 2009）让荷兰听话人看一集带有陌生的苏格兰口音或澳大利亚口音的电视节目，分别带英文字幕、荷兰语字幕或不带字幕，然后测试他们对同一种口音的新句子的辨认能力。带**英文**字幕看的听话人表现最好；带**荷兰语**字幕看的人比完全不看字幕的人还差，因为字幕告诉了他们意思，所以他们不需要去学习说话人的音是怎样对应到词上的。关于带同语字幕的视频的研究综述（例如 Montero Perez, Van Den Noortgate and Desmet 2013）也发现，同语字幕有助于理解和词汇学习。先不看字幕看一遍，能让你主动地听；然后英文字幕让你核对自己的理解，留意自己漏掉了什么——这就是[[listening-and-conversation/gist-and-detail#rule-cycle]]中的“留意”这一步。
:::

::: warning 母语字幕
✗ 看每个节目都带中文字幕，并把它算作听力练习。
✓ 娱乐时用中文字幕，练习时用英文字幕——或者不用字幕。

你的眼睛读得比耳朵听懂得快，所以带着母语字幕，你会读故事，而几乎不去听。这就是为什么几百个小时的观看可能让听力几乎原地不动，就像吴杰那样。带着中文字幕放松地看一部电影没有任何问题——但不要指望它能训练你的英语耳朵。
:::

## 泛听和精听

::: definition 泛听和精听 {#def-intensive}
**泛听**（extensive listening）是指为了理解意思和享受，大量地听足够容易听懂的材料，而不停下来研究它：上班路上听一个播客，晚上看一部剧。**精听**（intensive listening）是指仔细地处理一段短录音——听好几遍，用英文字幕或文稿核对，写下你听到的内容，研究快速话语中的各种形式。
:::

::: theorem 两者结合 {#rule-combine}
泛听培养**速度、自动解码能力**以及对许多声音的**熟悉程度**；精听培养**准确性**，并让你知道自己没有听出来的是什么。两者都需要。对许多学习者来说，一个实际的平衡是每周大量泛听，再加上一两次简短的精听。
:::

::: proof
两种练习训练的是不同的东西。快速、自动的词语辨认——即[[listening-and-conversation/how-listening-works#rule-decoding]]中的解码——只有经过大量练习才能培养起来，就像阅读速度一样（[[reading-skills/extensive-reading]]）；泛听提供了这种练习。但如果只做泛听，听话人可以忽略自己听不出的东西，靠语境蒙混过去；精听则把这些空缺暴露出来。菲尔德（Field 2008）认为，课堂上的听力教学过于侧重测试理解，而太少训练解码，他建议针对学习者听错的那些语段，做简短、集中的练习。用英文字幕和听写做精听，正是在做这件事。
:::

::: example 计划一周 {#ex-week}
赵明每天大约有30分钟用于英语听力，他的目标是更好地听懂工作会议。为他计划一周。
::: solution
一个可能的计划：

- **周一到周五，泛听（20分钟）**：上班路上听一个关于他所在行业的访谈播客，不停顿。他听大意，不为细节操心。
- **周一、周三、周五，精听（10分钟）**：从同一个播客中选一个2到3分钟的片段。不看字幕 → 看英文字幕或文稿 → 再不看字幕听一遍；他写下三个一开始没听出来的短语（[[#rule-subtitles]]）。
- **周二和周四（10分钟）**：跟读前一天精听过的片段中的一分钟（[[#rule-shadowing]]）。
- **周末**：为了娱乐看一部电影或一部剧，带英文字幕。

这个计划让材料符合他的目标（谈论工作，有几个说话人），把泛听和精听结合起来（[[#rule-combine]]），并在几天里反复使用同一个片段。
:::
:::

::: example 用一个片段做听写 {#ex-dictation}
Ana 把一段访谈中十秒钟的内容听了四遍，写下：

*I think the ___ thing is ___ you're ___ to ask for help.*

文稿上写的是：*I think the main thing is that you're not afraid to ask for help.*（我觉得最重要的是你不要害怕求助。）她漏掉了什么？为什么？
::: solution
她漏掉了 *main*、*that* 和 *not afraid*。

- *that* [ðət] 是一个**弱读式**，非常短，不重读（[[connected-speech/weak-forms]]）。
- *not afraid* 很可能读成了 [nɒʔəˈfreɪd]——连在一起，/t/ 读作喉塞音，*afraid* 的第一个音节是弱读的（[[connected-speech/linking]]）。
- *main* 可能是因为 *the main* [ðə ˈmeɪn] 在 *thing* 前面说得很快而漏掉了；但它是重读的，所以第五遍集中听这个空缺，很可能就能听出来。

这次听写的价值在于诊断：Ana 现在知道她的问题在于弱读式和连读，而不是词汇——每个词她都认识。这正是单靠泛听显示不出来的那种空缺（[[listening-and-conversation/how-listening-works#ex-diagnose]]）。
:::
:::

::: quiz
哪一项活动是**精听**？
- [ ] 在长途火车上听一本有声书。
- [ ] 周末带英文字幕看完一整部剧。
- [x] 把一个两分钟的片段听五遍，写下每一个词。
- [ ] 做饭时把播客当作背景声音开着。
::: solution
精听是对一段短录音的仔细、反复的处理。其他几项活动要么是泛听（有声书、电视剧），要么几乎算不上在听（背景里开着的播客，如果你并没有跟着听的话）。
:::
:::

## 跟读

::: definition 跟读 {#def-shadowing}
**跟读**（shadowing）是指一边听，一边几乎同时把说话人说的话大声说出来——落后几分之一秒，像影子一样。它不同于在录音停下之后再**复述**。
:::

::: theorem 怎样跟读 {#rule-shadowing}
1. **选一段短录音**（30到60秒），是你已经听懂了的，最好有文稿。
2. 先**一边听一边读**文稿几遍。
3. **小声跟着说**：跟着录音轻声说，即使漏掉一些词，也要跟上节奏和旋律。
4. **看着文稿跟读**：清楚地说，与说话人的重音、连读和语调保持一致。
5. **不看文稿跟读。**
6. **把自己录下来**，与原录音比较：你在哪里落后了？哪些弱读式或连读你没有做到？
:::

::: proof
跟读迫使你以话语到来的速度处理它，没有时间翻译，并且要准确地再现连贯语流的各种特征——弱读式、连读、重读音节的节奏——正是这些特征使快速话语难以听懂（[[connected-speech/rhythm]]）。人们普遍认为，在自己的发音中练习这些特征，会使它们更容易被辨认出来。跟读有一些研究支持：例如，滨田（Hamada 2016）发现，练习跟读的日本英语学习者听力有所提高，而且水平较低的学习者提高得更多。但是这方面的研究仍然有限，各项研究中效果的大小也不尽相同。最好把跟读当作一种有用的技巧，而不是一套完整的方法。
:::

::: example 一次跟读练习 {#ex-shadowing}
Mehmet 跟读演讲中的这个句子：*What I want to talk about today is how we can make our cities a bit greener.*（我今天想谈的是，我们怎样能让我们的城市更绿一点。）在他的录音里，他把每个词都读得很完整：[wɒt aɪ wɒnt tuː tɔːk əˈbaʊt təˈdeɪ ɪz haʊ wiː kæn meɪk ˈaʊə ˈsɪtiz eɪ bɪt ˈɡriːnə]，结果落后了一秒。他应该在哪些方面下功夫？
::: solution
说话人说的很可能是 [wɒʔaɪ ˈwɒnə ˈtɔːk əˌbaʊʔ təˈdeɪ | z ˈhaʊ wi kən ˈmeɪk ɑː ˈsɪtiz ə bɪʔ ˈɡriːnə] 这样，调核在 *greener* 上。

1. **弱读式**：*to* [tə]、*can* [kən]、*a* [ə]、*our* [ɑː]——Mehmet 用的是强读式，花的时间更长（[[connected-speech/weak-forms]]）。
2. ***want to*** 在快速、非正式的话语中 → [ˈwɒnə]。
3. **连读和喉塞音**：*What I* [wɒʔaɪ]、*about today*、*bit greener*。
4. **节奏**：只有 *want*、*talk*、*today*、*how*、*make*、*cities*、*greener* 是重读的；其余的词都被挤在它们之间（[[connected-speech/rhythm]]）。

做了这些改变之后，他就能跟上说话人了——而且他也会发现，在别人的话里听出同样的形式变得更容易了。
:::
:::

## 再次遇到学过的词

从词表或阅读文章中学到的词，在话语中常常很难认出来。书面形式 *comfortable* 并不能让你准备好听到 [ˈkʌmftəbl̩]；*probably* 可能是 [ˈprɒbli]；*going to* 可能是 [ˈɡənə]。

::: theorem 把认识的词变成听得出的词 {#rule-hear-words}
1. **学拼写时也学发音**：学一个词时，查一下它的发音和重音（[[core-vocabulary/using-a-dictionary]]）。
2. **听你学过的词**：学完一组词之后，选择同一话题的听力材料，这样你就能在话语中再次遇到它们。
3. **留意弱化形式**：当英文字幕显示了一个你没听出来的词时，把那一段再听一遍，记下它是怎么读的。
4. **收集短语，而不只是单词**：*at the end of the day*（归根到底）、*to be honest*（说实话）、*I was like*（我当时就……）是作为整体被听到的（[[core-vocabulary/phrases-and-chunks]]）。
5. **把相遇的时间拉开**：在几天、几周之内多次再遇到一个词，才能让它留下来（[[core-vocabulary/learning-and-remembering#rule-spacing]]）。
:::

::: proof
在话语中认出一个词，需要记得它在连贯语流中**听起来**是什么样，而不只是它怎么写；一个只在印刷品中见过的词，在快速话语中可能认得很慢，或者根本认不出来。在听力中反复遇到它，就能建立起这种记忆。关于从观看中附带学习词汇的研究支持这一点：例如，彼得斯和韦布（Peters and Webb 2018）发现，学习者仅仅看一部纪录片就学到了一些新词，而出现次数越多的词越可能被学会。不过，单靠观看学词是很慢的，所以它和有意识的学习结合起来效果最好：先学一个词，再在听力中再次遇到它（[[core-vocabulary/learning-and-remembering]]）。
:::

::: quiz
你刚刚学了二十个关于气候的词。对你的听力来说，下一步最好做什么？
- [ ] 再从另一个话题学二十个词。
- [x] 听一个关于气候的简短演讲，先不看字幕，再带英文字幕。
- [ ] 带中文字幕看一部喜剧电影。
- [ ] 尽可能快地大声读词表。
::: solution
听同一话题的材料，能让你有机会借助语境在话语中再次遇到这些新词。然后英文字幕会显示出哪些词你听到了，哪些漏掉了（[[#rule-hear-words]]、[[#rule-subtitles]]）。
:::
:::

::: note 英汉对比
- **到处都是字幕。** 中国的视频平台常常默认显示字幕，许多学习者习惯了屏幕上总有文字。这个习惯使得转向不看字幕听变得更难；要有意识地练习（[[#rule-subtitles]]）。
- **课堂录音和真实话语。** 听力考试和教材录音通常比真实的话语更慢、更清楚，很少有犹豫或重叠。媒体展示了英语在真实使用中听起来是什么样的——包括各种口音，以及真实会话中的 *um*、*like* 和说了一半又重来的话（[[listening-and-conversation/how-listening-works]]）。
- **大声跟读并不陌生。** 许多中国学习者练习过朗读和背诵课文。跟读以这个习惯为基础，但用的是自然话语的录音，是实时进行的，注意的是连读和弱读式，而不是一个个清楚分开的词。
- **利用你喜欢的东西。** 你本来就会用中文看、听你喜欢的东西；找一些相同话题的英语材料——某项运动、某个爱好、某个学科领域。正是兴趣让泛听能够坚持几个月。
:::

::: history
录音技术一出现，就改变了语言学习。从20世纪初开始，就有用留声机唱片录制的语言课程出售；50年代和60年代，受听说法强调听和重复的影响，语言实验室——学生在里面用录音机听和跟读的房间——在中小学和大学里普及开来。20世纪80年代，克拉申（Stephen Krashen）的输入假说认为，语言主要是通过理解信息而习得的，这鼓励了大量地听和读难度合适的材料。图文电视和 DVD 的字幕功能使同语字幕得到广泛普及，从21世纪初开始，网络视频和播客为学习者提供了来自许多国家的、几乎无限的真实话语录音。此后，关于字幕的研究——例如范德普兰克（Vanderplank）从20世纪80年代开始的研究——以及关于从观看中附带学习词汇的研究，为学习者如何用好这些材料提供了证据。
:::

## 后续内容

本章在阅读方面的对应内容是[[reading-skills/extensive-reading]]。精听所揭示的连贯语流的特征，在[[connected-speech/weak-forms]]、[[connected-speech/linking]]和[[connected-speech/hearing-fast-speech]]中讲授。怎样记住你遇到的词，是[[core-vocabulary/learning-and-remembering]]的内容。听许多口音在[[listening-and-conversation/accents]]中讨论，而在现场谈话中运用你的听力，则在[[listening-and-conversation/turn-taking]]和[[presentations-and-discussion/seminars-discussion]]中讨论。

::: summary
- 选择你**大部分能听懂**的材料：话题熟悉，音质清楚，短到可以反复听，并且随着时间推移来自许多说话人（[[#rule-choose]]）。
- 母语字幕训练的是阅读，而不是听力；**英文字幕**最有帮助；逐步过渡到不用字幕（[[#def-subtitles]]、[[#rule-subtitles]]；Mitterer and McQueen 2009）。
- **泛听**培养速度和熟悉程度；**精听**培养准确性，并显示你漏掉了什么；两者要结合（[[#def-intensive]]、[[#rule-combine]]）。
- **跟读**——跟着录音说，落后几分之一秒——训练节奏、弱读式和连读（[[#def-shadowing]]、[[#rule-shadowing]]）。
- 把认识的词变成听得出的词：学它们的发音，听同一话题的材料，留意弱化形式，收集短语，并把与它们相遇的时间拉开（[[#rule-hear-words]]）。
:::

## 练习

::: exercise 泛听还是精听？ {level=1}
给每项活动标上 E（泛听）或 I（精听）。

(a) 一边走路一边听播客。(b) 逐词写下一段20秒的内容。(c) 周末为了好玩看一部剧。(d) 把一分钟的内容听三遍，然后核对文稿。
::: solution
(a) E (b) I (c) E (d) I
:::
:::

::: exercise 字幕 {level=1}
把处理一个片段的这几个阶段排成有用的顺序：(a) 不看字幕再看一遍 (b) 带英文字幕看 (c) 不看字幕看，写下大意。
::: solution
(c)、(b)、(a)（[[#rule-subtitles]]）。
:::
:::

::: exercise 问题出在哪里？ {level=1}
每个学习者在使用媒体时都有一个问题。用几个词说出这个问题。

(a) *I always watch with Chinese subtitles, but my listening isn't improving.*（我总是带中文字幕看，可是听力没有提高。）(b) *I chose a fast comedy with ten characters, and I understood almost nothing.*（我选了一部有十个角色、节奏很快的喜剧，几乎什么都没听懂。）(c) *I only ever listen to one presenter.*（我只听一个主持人。）
::: solution
(a) 在读中文而不是在听；用英文字幕或不用字幕。(b) 材料太难；选择你大部分能听懂的材料（[[#rule-choose]]）。(c) 声音太少；听许多说话人和许多口音。
:::
:::

::: exercise 计划一个片段 {level=2}
选一个你感兴趣的话题，描述一段你可以用来做精听的两到五分钟的录音。然后参照本章的图，写出你将遵循的步骤。
::: solution
答案因人而异。好的回答会说出一种具体的录音（*一段三分钟的足球比赛新闻报道*、*一个关于睡眠的演讲的前四分钟*），解释它为什么符合[[#rule-choose]]，并列出步骤：不看字幕 → 写下大意 → 英文字幕 → 记下漏掉的内容 → 再不看字幕 → 跟读一小段。
:::
:::

::: exercise 弱化形式 {level=2}
一个学习者在录音中没听出这些词。写出每个词的完整形式。

(a) [ˈɡənə] (b) [ˈwɒnə] (c) [ˈkʌmftəbl̩] (d) [ˈprɒbli] (e) [ˈdʒuː ˈwɒnə]
::: solution
(a) *going to* (b) *want to* (c) *comfortable* (d) *probably* (e) *do you want to*（[[connected-speech/elision-assimilation]]）
:::
:::

::: exercise 跟读并比较 {level=2}
按照[[#rule-shadowing]]，跟读一段你已经听懂的30秒录音。把自己录下来，列出你的版本与说话人不同的三个地方——例如用了强读式而不是弱读式，少了一处连读，或者调核放在了不同的位置。
::: hint
注意那些小的语法词（*to*、*and*、*of*、*can*、*was*），以及以辅音结尾、后面紧跟以元音开头的词的那些词。
:::
::: solution
答案因人而异。常见的发现：*to* 读成了 [tuː] 而不是 [tə]；*and* 读成了 [ænd] 而不是 [ən]；*get_up* 没有连读；说话人把调核放在了前面，而自己把调核放在了最后一个词上（[[connected-speech/sentence-stress]]）。
:::
:::

::: exercise 四周计划 {level=3}
为自己（或为你描述的一个学习者）写一个大约120到180词的四周听力计划。其中要包括：材料，泛听和精听各多少，字幕怎样使用，跟读，以及你怎样再次遇到新学的词。说明你怎样知道这个计划是否有效。
::: solution
答案因人而异。好的计划是具体的（什么材料，多少分钟，哪几天），把泛听和精听结合起来（[[#rule-combine]]），从英文字幕逐步过渡到不用字幕，包括简短的跟读练习，并把词汇学习与同一话题的听力联系起来（[[#rule-hear-words]]）。衡量进步的好方法是具体的：例如，在四周的开始和结束时，各对同类材料做一次听写，或者看第一次听一个新片段时能听懂多大比例。
:::
:::

::: exercise 给朋友提建议 {level=3}
本章开头的吴杰来征求你的意见。写一条简短的消息（80到120词），解释为什么他看了那么多小时，听力却没有多大提高，以及他应该做出什么改变。
::: solution
参考答案：

*Hi Wu Jie — I think the problem is the Chinese subtitles. Your eyes read the story faster than your ears can listen, so you've been practising reading Chinese, not listening to English! You don't need to stop watching your series, but try this: choose a short scene, watch it without subtitles, then with English subtitles, then without again. Do that a few times a week. Also, find a podcast about something you like and listen on the way to work, without stopping. After a couple of months you'll notice a big difference. Good luck!*

**译文：**嗨，吴杰——我觉得问题出在中文字幕上。你的眼睛读故事比耳朵听得快，所以你一直在练习读中文，而不是听英语！你不用停止看你的剧，但可以试试这样：选一个短的场景，先不看字幕看，然后带英文字幕看，再不看字幕看一遍。每周这样做几次。另外，找一个关于你喜欢的东西的播客，上班路上听，不要停。过几个月你就会发现很大的不同。祝你好运！

这条消息给出了原因（母语字幕，[[#rule-subtitles]]），保留了他喜欢的东西，并建议他既做精听也做泛听（[[#rule-combine]]）。
:::
:::
