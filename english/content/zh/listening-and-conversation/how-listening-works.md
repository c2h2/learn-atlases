陈静咳嗽得很厉害，药剂师正在向她说明怎样服药。陈静认真地听，清楚地听到了这几个词：*two*（两）、*day*（天）、*empty stomach*（空腹）。她谢过药剂师就回家了，第二天早上在早饭前吃了药。那天晚上她看了标签：*Take two tablets a day with food. Do not take on an empty stomach.*（每天两片，与食物同服。请勿空腹服用。）

重要的词陈静都听到了。出问题的不是她的耳朵，而是她的猜测：她把听到的词放进了自己预想的那个句子里，而那个又短又快、不重读的小词 *not* 跟这个句子对不上，所以她没听到它。

一周以后，同事 Ravi 在办公室的茶水间对她说了一句话：[ˈwɒnə ˈɡræb ə ˈbaɪt ˈleɪtə]。这一次她完全不知道对方在说什么。*Want to grab a bite later?*（待会儿一起去吃点东西吗？）里的每个词她都认识——但她没能在那一串声音里找出这些词，所以连猜都无从猜起。

这两次失败正好相反，合在一起说明了本章要讲的内容。听不是在脑子里录音。听话人同时在两个层面上工作：**自下而上**，把声音变成音节、词和句子；**自上而下**，利用对情境、话题和说话人的了解来预期接下来会说什么。好的听力两者都需要。陈静的第一次失败是一个没有被声音纠正的自上而下的猜测；第二次是自下而上的失败，使她连猜测的依据都没有。

## 两个方向的加工

::: definition 自下而上的加工 {#def-bottom-up}
**自下而上的加工**（bottom-up processing，也叫**解码**，decoding）是从语音信号本身构建意义：听话人听到声音，把它们组成音节，辨认出词，把词放进短语和分句，从而得出所说的话的字面意思。它从小单位走向大单位。
:::

::: definition 自上而下的加工 {#def-top-down}
**自上而下的加工**（top-down processing）是利用信号中没有的知识来理解信号：关于世界的知识，关于情境（商店、讲座、电话）的知识，关于说话人、话题、前面已经说过的话的知识，以及这类谈话通常怎样进行的知识。听话人用这些知识来**预测**可能会说什么，并**解释**听到的内容。它从大单位走向小单位。
:::

两者并不是先后分开的两个阶段。听话人不是先把整个句子解码完，然后再去思考它：在句子还没说完的时候，来自上层的知识就已经在引导下层的辨认，而每听到一个新词，预期又会随之改变。下图显示了各个层次和两个方向。

::: widget graph

:::

::: theorem 听话人同时利用两个方向 {#rule-interactive}
成功的听力**同时**使用自下而上和自上而下的加工。自下而上的加工提供证据；自上而下的加工提供预期，使证据能被迅速地解释。信号清楚而话题陌生时，听话人更多地依靠解码；信号不好（噪音、说话太快、口音陌生）或话题熟悉时，他们更多地依靠知识。两者都可能出错，也都可以纠正对方。
:::

::: proof
实验表明，两个方向都在起作用，即使对母语听话人也是如此。

- **单独听到的词很难辨认。** 波拉克和皮克特（Pollack and Pickett 1963）从流利对话的录音中剪出一个个单词，放给听话人听。脱离了语境，只有大约一半的词能被辨认出来，而同样的词在原来的对话中毫不费力就能听懂。语境——周围的词——承担了很大一部分工作。
- **听话人会听到自己预期的东西。** 沃伦（Warren 1970）把录音句子中 *legislatures*（立法机构）一词里的一个音换成了一声咳嗽。听话人说他们听到了完整的词，包括那个缺失的音，而且说不出咳嗽出现在哪里。这叫作**音位恢复**（phonemic restoration）：大脑根据这个词应该是什么样子来填补空缺。
- **知识必须在听的时候就能用上。** 布兰斯福德和约翰逊（Bransford and Johnson 1972）让人们听一小段文字，它用笼统的词描述一项日常活动，却不说出活动的名称。在听**之前**就被告知话题（洗衣服）的人，比没有标题或者听完才被告知话题的人理解和记住的内容多得多。

没有解码，就没有可以解释的东西；没有知识，解码就很慢，每个听不清的词都会成为死胡同。图中的两列始终在一起工作。
:::

::: quiz
下面哪一项是**自上而下**加工的例子？
- [ ] 听出一个词有三个音节，重音在第一个音节上。
- [ ] 注意到 [dʒə] 是 *do you* 的弱化形式。
- [x] 因为你正站在售票柜台前，所以预期会听到一个价格。
- [ ] 听出一个句子以降调结尾。
::: solution
预期听到价格来自关于情境的知识，而不是来自声音本身：这是自上而下的加工。数音节、辨认弱化形式和听出降调，都是在处理信号本身：属于自下而上的加工。
:::
:::

## 自下而上：从声音到词

自下而上的第一项任务是把语流切分成词。口语没有空格，而且在连贯语流中，词会弱化、连读和变化。这些过程以及应对它们的策略——听强音节，学习 [dʒə]、[ˈwɒnə] 这类弱化语块——在[[connected-speech/hearing-fast-speech]]中讲授；本章以它们为基础。

一旦听话人听到了几个音，词的辨认就很快。心理语言学家把它描述为一种**竞争**：一个词开头的几个音一出现，所有以这样的音开头的词都成为可能的候选，随着更多的声音到来，候选词逐渐减少（马斯伦-威尔逊和韦尔什 Marslen-Wilson and Welsh 1978 把这组候选词称为**词群**，cohort）。听到 [ˈkæ…] 时，英语听话人脑中有 *cat*、*can*、*cab*、*candle*、*camera*、*captain* 等许多词在竞争；听到 [ˈkæp…] 就只剩下 *captain*、*capital*、*cap*；语境又排除了剩下的大部分。母语听话人通常在一个常用词还没说完时就已经认出了它。

::: theorem 什么让解码变难 {#rule-decoding}
在下列情况下，自下而上的加工对学习者来说很难：

1. **这个词不认识**——一个从没见过的词，说得再清楚也认不出来；
2. **只认识这个词的书面形式或仔细的读法**——*comfortable* 读成 [ˈkʌmftəbl]，*probably* 读成 [ˈprɒbli]，*going to* 读成 [ˈɡənə]；
3. **词的边界不清楚**——*an apple* [əˈnæpl]、*get it* [ˈɡetɪt] 这样的连读形式（[[connected-speech/linking]]）；
4. **说话快**——每个词占的时间少了，思考的时间也少了；
5. **口音陌生**——元音和辅音不在听话人预期的位置上（[[listening-and-conversation/accents]]）；
6. **信号不好**——背景噪音、电话线路差、几个人同时说话。
:::

::: proof
第1点和第2点关于词汇。要轻松地听懂话语，听话人需要认识其中的大多数词。内申（Nation 2006）统计了英语口语语料库中的词，估计要认识会话中98%的词次，需要掌握6,000至7,000个词族；范泽兰和施密特（van Zeeland and Schmitt 2013）发现，覆盖率低一些、在95%左右时，听话人往往也能基本听懂。无论按哪种说法，词汇量都给听力设定了上限。但只在纸面上认识一个词是不够的：学习者经常说，他们听到自己“认识的词”时却“认不出来”（Goh 2000 把这列为新加坡的中国学生报告最多的问题之一），因为他们记住的是书面形式或仔细的读音，而不是快速口语中的形式。

第4点关于时间。陶罗萨和艾利森（Tauroza and Allison 1990）测量了英式英语的录音，发现平均语速是：会话约每分钟210词，访谈约190词，电台独白约160词，给非母语听众的讲座约140词。会话是最快的一种话语，而学习者在课堂上听得最少的恰恰是它。
:::

::: example 哪些词会难听清？ {#ex-hard-words}
一位导游说（GB，自然语速）：*We'll probably have about twenty minutes, so you've got time for a coffee and a quick look round the market.*（我们大概有二十分钟左右，所以你们有时间喝杯咖啡，再到市场里很快地转一圈。）对学习者来说，哪些部分可能难以解码？为什么？
::: solution
1. *We'll*——弱读式 [wɪl] 或 [wl]，在 *probably* 前面很容易丢失。
2. *probably*——在快速口语中通常读成 [ˈprɒbli]，甚至 [ˈprɒli]：学习者可能只知道 [ˈprɒbəbli]。
3. *have about*——弱读的 *have* [əv] 与 *about* [əˈbaʊt] 连读：[əvəˈbaʊt]，重音前有三个弱音节。
4. *twenty*——清楚，因为它重读而且重要；在 GA 中可能读成 [ˈtwʌni] 或 [ˈtweni]，/n/ 后面没有 /t/。
5. *so you've got*——[səʊ juv ˈɡɒt]：*you've* 是弱读的，听起来可能像 *you*。
6. *a quick look round the market*——实义词 *quick*、*look*、*round*、*market* 很清楚；*a* 和 *the* 是弱读的。

重读的词——*probably*、*twenty*、*minutes*、*time*、*coffee*、*quick*、*look*、*market*——承载了信息；难的部分大多是弱读的功能词。抓住重读词、又了解情境（旅游途中的一站）的听话人，就能重建其余部分：*about twenty minutes, time for coffee and the market*（大约二十分钟，有时间喝咖啡、逛市场）。
:::
:::

## 自上而下：知识与预期

::: definition 图式 {#def-schema}
**图式**（schema，复数 **schemata** 或 **schemas**）是关于某类熟悉的情境或话题的一套有组织的知识：通常会发生什么、按什么顺序、谁说什么、可能出现哪些词。例如，“餐馆”图式包括被领到桌前、服务员递上菜单并问喝什么、点菜、吃饭、要账单和付钱。听话人用图式来预测和填补空缺。
:::

听话人在听的时候会带上几种知识：

- **情境。** 在值机柜台前，你预期会听到 *passport*（护照）、*bags*（行李）、*window or aisle*（靠窗还是靠过道）。在诊所里，你预期会听到 *How long have you had it?*（这样有多久了？）
- **说话人。** 一位总是抱怨交通的同事，很可能一开口就谈交通。
- **话题。** 如果你懂一点足球，听一场足球比赛的报道就比听一项你不了解的运动容易得多。
- **前面说过的话。** 只有记得 *it* 或 *they* 这样的代词指的是什么，才能理解它；一个问题限定了回答可能是什么。
- **谈话的类型。** 新闻报道先给出要点；笑话把要点留到最后；故事从何人、何地、何时开始（[[listening-and-conversation/storytelling]]）。

::: example 听之前先预测 {#ex-predict}
赵琳要给一家酒店打电话订房间。打电话之前，列出她可以预期前台会问些什么，以及她应该准备好听到哪些词。
::: solution
根据她关于订酒店的图式：

1. **日期**——*When would you like to arrive? How many nights?*（您想哪天到？住几晚？）词语：*arriving*（到达）、*checking out*（退房）、*nights*（晚）、*the twelfth*（十二号）这样的日期。
2. **人数和房型**——*How many guests? A double or a twin? Single occupancy?*（几位客人？大床房还是双床房？一个人住吗？）
3. **价格和条件**——*That's £120 a night, including breakfast. Is that OK?*（每晚120英镑，含早餐。可以吗？）词语：*including*（包括）、*excluding*（不包括）、*VAT*（增值税）、*deposit*（押金）、*cancellation*（取消）。
4. **姓名和信息**——*Can I take a name? Could you spell that? And a contact number?*（请问您贵姓？能拼一下吗？还有联系电话？）（[[everyday-english/personal-information]]）
5. **付款**——*Can I take a card to secure the booking?*（可以提供一张卡来担保预订吗？）

有了这份清单，赵琳就不必从零开始解码每一个词。当她听到 [ˈtwɪn ɔː ˈdʌbl] 时，她预期会有关于房型的问题，所以很容易认出 *twin or double*（双床还是大床）。这份清单也显示出她必须仔细听的地方——数字、日期和价格很难预测，必须靠解码（[[listening-and-conversation/gist-and-detail]]）。
:::
:::

::: theorem 核对你的猜测 {#rule-check-guesses}
自上而下的预期是猜测，而猜测可能是错的。好的听话人**对自己的理解不抓得太死**，一旦信号对不上就加以修改。尤其要仔细听那些能把意思反过来的词，即使它们又短又不重读：*not* 和 *n't*、*no*、*never*、*only*、*except*、*unless*、*without*、*before* 和 *after*。当重要的事取决于它们时，要核实（[[listening-and-conversation/clarification]]）。
:::

::: proof
预期使听得快，但当说话人说出意料之外的话时，它也容易导致听错。本章开头陈静的错误很典型：她预期听到的是关于**什么时候**吃药的指示，就把 *empty stomach* 放了进去，而说话人说的却是这些药**不能**那样吃。否定词又短又不重读——*Do ˈnot take*（请勿服用）会很清楚，但 *Don't ˈtake them on an ˈempty ˈstomach*（别空腹吃）把重音放在了实义词上。听话人不可能把每样东西都听得清清楚楚，但她可以注意到一个重要的指示取决于一个小词，并加以核实：*Sorry — so I should take them with food, not before?*（不好意思——那我应该跟饭一起吃，而不是饭前吃，对吗？）
:::

::: warning 只猜不核实
✗ 听到几个词，断定说话人大概是什么意思，然后就不再听了。
✓ 作出猜测，继续听下去，看它是否对得上，在意思重要时加以核实。

✗ *The meeting's been moved — so it's tomorrow.*（听话人猜测了新的日期。）
✓ *The meeting's been moved? To when?*（会议改期了？改到什么时候？）

自上而下的加工不是“用猜代替听”，而是“一边听一边猜”。一个有了猜测就停止解码的听话人，会犯一些自以为正确的错误。
:::

::: quiz
一个朋友说：*I'd love to come to the party, but I'm working on Saturday.*（我很想去参加聚会，可是我星期六要上班。）你清楚地听到了 *love to come* 和 *party*，但没听清其余部分。最好怎么做？
- [ ] 断定朋友会来，因为你听到了 *love to come*。
- [ ] 什么也不说，因为问是不礼貌的。
- [x] 注意到 *but* 在你听到的部分之后引出了别的内容，并问：*Sorry — so can you come or not?*
- [ ] 请朋友一个词一个词地把整句话重复一遍。
::: solution
*I'd love to…, but…* 是礼貌地说**不**的常见方式；重要的信息在 *but* 后面。在 *love to come* 处就停下来的听话人会理解错。问一个简短、具体的问题（*Sorry — so can you come or not?*，不好意思——那你到底能不能来？）既快又自然；请对方一个词一个词地重复既慢又没有必要。
:::
:::

## 听力为什么会失败

学习者描述自己的听力问题时常常用同样的话：*It's too fast*（太快了），*I understand the words but not the meaning*（词都懂，意思不懂），*I miss the beginning of the next sentence while I'm still thinking about the last one*（我还在想上一句，下一句的开头就错过了）。Goh（2000）请新加坡的中国学生写听力日记，发现问题出现在加工的每一个阶段：认不出认识的词，还在想上一部分时错过了下一部分的开头，听懂了词却没听懂意思，以及很快就忘了听到的内容。

::: theorem 听力失败的常见原因 {#rule-breakdown}
听力失败时，原因通常是下面之一：

1. **解码**——词不认识，或者认识但在口语形式中没认出来（[[#rule-decoding]]）。
2. **速度和记忆**——听话人还在处理一个句子，下一个句子就开始了，结果两个都丢了。把不熟悉的声音保持在记忆中是很累的；解码越费力，留给意义的注意力就越少。
3. **卡住**——一个不认识的词让听话人停了下来，他试图弄明白它，结果错过了后面的话。
4. **缺少知识**——听话人不了解话题、情境或某个文化典故。
5. **预期错误**——听话人一开始就构建了错误的图景，并把所有内容都套进去（[[#rule-check-guesses]]）。
6. **翻译**——听话人先把每个句子翻译成母语再去理解，这需要时间，而说话人不会给这个时间。
7. **焦虑**——担心听不懂会占用注意力，使其他问题变得更糟。
:::

::: proof
这些原因是相互联系的。解码慢（1）会耗掉注意力，于是留给在记忆中保持句子（2）和发现预期错误（5）的注意力就少了。翻译（6）给每个句子都增加了一个步骤，而焦虑（7）既是其他问题的结果，又会使它们更糟。实际的启示是：改进其中任何一个部分都会对其余部分有帮助。更快地认出常用词和语块，可以腾出注意力来理解意义；好的预测使解码更容易；冷静地决定放过一个不认识的词，能让听话人继续跟住说话人。
:::

::: example 诊断一次听力失败 {#ex-diagnose}
下面是四位学习者在一次听力练习后写的笔记。分别说出主要问题是[[#rule-breakdown]]中的哪一个原因，并提出一个解决办法。

1. *"The speaker said a word like 'tenure' and I spent the next ten seconds trying to think what it meant. After that I was lost."*（说话人说了一个像 tenure 的词，我接下来花了十秒钟去想它是什么意思。之后我就跟不上了。）
2. *"I understood every sentence, but I didn't know why they were laughing about the 'M25'."*（每个句子我都听懂了，但我不知道他们为什么拿 M25 开玩笑。）
3. *"I caught 'flight', 'cancelled' and 'tomorrow', so I thought my flight was cancelled. Actually they said the cancelled flights were yesterday's and tomorrow's were fine."*（我听到了“航班”“取消”和“明天”，就以为我的航班被取消了。其实他们说的是取消的是昨天的航班，明天的都正常。）
4. *"When I read the transcript afterwards, I knew all the words. I just couldn't hear 'I should've asked her'."*（事后看文字稿，所有的词我都认识。我就是没听出 I should've asked her。）
::: solution
1. **卡住**（3）。放过这个不认识的词；继续去听后面的重读词，过后再回到这个词——语境可能会解释它，如果没有，你可以问或者去查。
2. **缺少知识**（4）。M25 是环绕伦敦的高速公路，以堵车闻名：这个笑话需要这一文化事实。声音里没有任何东西能帮上忙。解决办法是在听之前读一些有关话题的背景材料，以及开口问。
3. **预期错误**（5）。听话人根据三个词构建了一幅图景，却没有注意到 *yesterday*（昨天）和 *fine*（正常）和它对不上（[[#rule-check-guesses]]）。要注意听那些改变时间或把意思反过来的词，采取行动之前先核实。
4. **认识的形式没解码出来**（1）。*Should've asked her* 在快速口语中读作 [ˈʃʊdəv ˈɑːskt ə] 或 [ˈʃʊdə ˈɑːstə]：弱读的 *have*，/k/ 和 /t/ 被省略，弱读的 *her*。学习者认识书面形式，却不认识口语形式；对这类语块进行听写和跟读会有帮助（[[connected-speech/hearing-fast-speech#rule-practice]]）。
:::
:::

## 会话中的听

很多听力练习用的是录音，你不能让它停下来，也不能向它提问。在会话中，听就不一样了：你可以问，说话人通常也会调整。这种双向的听在一个方面更容易——你可以请求帮助——在另一个方面更难：你必须一边听一边准备自己的回答。

::: example 在会话中重建一个话轮 {#ex-rebuild}
Kwame 第一次去朋友 Li Na 的公寓。进门时她说了一句话，他只听到了重读的词：

**Li Na:** *… ˈshoes … ˈdoor … ˈslippers … ˈbasket …*（……鞋……门……拖鞋……篮子……）

Kwame 该怎样利用这些词？
::: solution
1. **自下而上**：四个清楚的实义词——*shoes*（鞋）、*door*（门）、*slippers*（拖鞋）、*basket*（篮子）。
2. **自上而下**：情境（进入别人家）、说话人（Li Na，她可能有进门换鞋的习惯）以及这些词的顺序，提示这是一个指示或一个提议：*You can leave your shoes by the door — there are some slippers in the basket.*（鞋可以放在门边——篮子里有拖鞋。）
3. **核实**：这个猜测很可能是对的，但这关系到行动（他也许应该把鞋放**进**篮子里）。一边做一边简单地核实是很自然的：*Here? Great — thanks!*（放这儿？好的——谢谢！）同时把鞋放在门边。

在会话中，听话人不必先全部听懂再行动：他可以表现出自己理解了什么，让说话人来纠正。这是[[listening-and-conversation/clarification]]的内容。
:::
:::

::: note 英汉对比
- **音节与词。** 普通话的音节类型很少——不计声调约400个——而且几乎每个音节都保留完整的元音和声调，所以音节之间的界限很清楚。英语可能的音节有好几千个，非重读音节会弱化，词的边界又被连读掩盖了。中国听话人对每个音节一样用心的习惯在英语中行不通：要注意重读音节（[[connected-speech/hearing-fast-speech#rule-strong]]）。
- **考试听力。** 中国的许多学习者主要用考试录音练习听力：清楚、朗读得很仔细，语速往往适中，而且问题事先印好了。这对解码仔细的话语、根据问题进行预测是很好的训练，但几乎没有练到每分钟200词、有话语重叠和弱化形式的会话。要在练习中加入自然的话语（[[listening-and-conversation/learning-from-media]]）。
- **边听边翻译。** 读的人可以停下来翻译；听的人不行。如果你发现自己在把每个句子转换成中文，就试着去听出一幅画面或一个大意，必要时只翻译关键词。
- **阅读强，听力弱。** 许多中国学习者能读懂的文章，比他们能听懂的话难得多。差距通常不在词汇，而在口语形式：这些词他们认识的是书面形式。这是个好消息——知识已经在那里了，听力练习要做的是把它和声音联系起来。
:::

::: history
在语言教学中，听在很长时间里被当作一种被动的技能：学习者听一篇材料，然后回答关于它的问题，这测试了理解，却没有教怎样理解。20世纪70和80年代，关于人怎样理解话语的研究改变了这种看法。心理学家表明，听话人会主动地利用自己的知识：沃伦（Richard Warren）的音位恢复实验（1970）以及布兰斯福德（John Bransford）和约翰逊（Marcia Johnson）关于语境与理解的研究（1972）是两个著名的例子。布朗（Gillian Brown）和尤尔（George Yule）的《口语教学》（*Teaching the Spoken Language*，1983）以及安德森（Anne Anderson）和林奇（Tony Lynch）的《听力》（*Listening*，1988）把这些观点引入了教学，把听描述为构建理解的主动过程。21世纪初，Goh（Christine Goh）、范德格里夫特（Larry Vandergrift）和菲尔德（John Field）主张，应该直接教给学习者听的过程和策略——怎样预测、监控和修补自己的理解——而不只是测试结果。
:::

## 后续内容

下一章[[listening-and-conversation/gist-and-detail]]把这些观点变成听较长录音的方法：预测，先听主要意思，再听细节。解码快速口语是[[connected-speech/hearing-fast-speech]]的内容；使自下而上的加工更困难的陌生口音，在[[listening-and-conversation/accents]]中讨论；没听懂时怎样问，在[[listening-and-conversation/clarification]]中讲授。用真实录音进行的练习，在[[listening-and-conversation/learning-from-media]]中安排。

::: summary
- 听力把**自下而上**的加工（从声音到词再到意义）和**自上而下**的加工（来自知识和预期）同时结合起来（[[#def-bottom-up]]、[[#def-top-down]]、[[#rule-interactive]]）。
- 即使是母语听话人，从会话中剪出来的词也只能认出大约一半（Pollack and Pickett 1963），而且他们会“听到”自己预期的声音（Warren 1970）：语境承担了很大一部分工作。
- 当词不认识、只认识书面形式、被连读、语速快、口音陌生或有噪音时，解码就很难（[[#rule-decoding]]）；会话约每分钟210词，是最快的一种话语（Tauroza and Allison 1990）。
- **图式**——关于情境和话题的知识——使你能够预测；在听之前和听的过程中都要用上它（[[#def-schema]]）。
- 预期只是猜测：要注意听那些把意思反过来的短词，在重要时加以核实（[[#rule-check-guesses]]）。
- 听力失败通常来自解码、速度和记忆、卡住、缺少知识、预期错误、翻译或焦虑；改进其中一项会对其他各项都有帮助（[[#rule-breakdown]]）。
:::

## 练习

::: exercise 自下而上还是自上而下？ {level=1}
说出下面各项主要是自下而上（B）还是自上而下（T）。

(a) 把 [ˈprɒbli] 认作 *probably*。(b) 在机场值机柜台预期会听到 *window or aisle*。(c) 听出 *fifteen* 的重音在 *-teen* 上。(d) 知道 *it* 指的是前面提到的笔记本电脑。(e) 预期一个故事会从事情发生的时间和地点讲起。(f) 听出一个词在哪里结束、下一个词从哪里开始。
::: solution
(a) B (b) T (c) B (d) T（前面说过的话）(e) T（谈话的类型）(f) B
:::
:::

::: exercise 把意思反过来的词 {level=1}
每个句子里都有一个听话人可能漏掉的短词。把它找出来，并说出没有它时听话人会错误地理解成什么。

(a) *You don't need to bring anything.*（你什么都不用带。）(b) *The museum's open every day except Monday.*（博物馆除星期一外每天开放。）(c) *You can't park here unless you've got a permit.*（除非有许可证，否则不能在这里停车。）(d) *Only the first floor has been painted.*（只有一楼刷过漆了。）
::: solution
(a) *don't*——没有它：*You need to bring anything*（要带点东西）。(b) *except*——没有它：包括星期一在内每天都开放。(c) *can't* 和 *unless*——没有 *can't*，似乎可以停车；没有 *unless…*，似乎永远不能停车。(d) *Only*——没有它：一楼刷过漆了，也许其他楼层也刷过了。
:::
:::

::: exercise 图式清单 {level=1}
在下面每个情境中，写出五个你预期会听到的词或短语。

(a) 在理发店。(b) 给诊所打电话预约。(c) 大学课程的第一天。
::: solution
参考答案（还有许多其他可能）：

(a) *How would you like it?*（您想怎么剪？）、*just a trim*（稍微修一修）、*shorter at the sides*（两边短一点）、*a fringe*（刘海）、*Is that OK?*（这样可以吗？）

(b) *What's the problem?*（哪里不舒服？）、*the earliest appointment*（最早的预约）、*Is it urgent?*（急吗？）、*date of birth*（出生日期）、*Can you come in at…?*（您能在……来吗？）

(c) *timetable*（课程表）、*reading list*（阅读书目）、*assessment*（考核）、*office hours*（答疑时间）、*seminar groups*（研讨小组）。
:::
:::

::: exercise 多少个词？ {level=2 check="70"}
Tauroza 和 Allison（1990）发现，会话的平均语速约为每分钟210词。按这个速度，说话人20秒钟说多少个词？
::: solution
每分钟210词就是 210 ÷ 60 = 每秒3.5词；3.5 × 20 = **70** 词。二十秒大约是会话中一两个话轮的长度，所以一个因为想一个词而走神五秒钟的听话人，会错过大约17个词。
:::
:::

::: exercise 诊断 {level=2}
说出下面每个问题的主要原因（见[[#rule-breakdown]]）。

(a) *I knew the words "per cent" and "rise", but the numbers went past too fast to write down.*（我认识 per cent 和 rise 这两个词，可是数字一闪而过，来不及记下来。）
(b) *I was translating the first sentence when she started the second one.*（我还在翻译第一句，她就开始说第二句了。）
(c) *Everyone laughed when he said he was "from Yorkshire", and I didn't know why.*（他说自己“来自约克郡”时大家都笑了，我不知道为什么。）
(d) *I thought the lecture was about birds, but the word was "words".*（我以为讲座讲的是鸟，其实那个词是 words。）
::: solution
(a) 速度和记忆（2），而且数字必须靠解码（[[listening-and-conversation/gist-and-detail]]）。(b) 翻译（6），它导致了速度和记忆的问题。(c) 缺少知识（4）——一个文化典故。(d) 解码（1）——/bɜːdz/ 和 /wɜːdz/ 只有第一个辅音不同——随后是预期错误（5），讲座的其余部分也没能把它纠正过来。
:::
:::

::: exercise 先预测，再核对 {level=2}
你要听一段周末的天气预报。(a) 写出六个你预期会听到的词。(b) 下面是这段天气预报。你写的哪些词出现了？其中哪些词比较难预测？

*Saturday starts dry and bright, but cloud will build from the west during the afternoon, with showers reaching coastal areas by evening. Sunday looks wetter and windier, with highs of only eleven degrees.*（星期六开始时干燥晴朗，但下午云层将从西部逐渐增多，傍晚时阵雨将到达沿海地区。星期日雨更多、风更大，最高气温只有十一度。）
::: solution
(a) 可能的预测：*sunny*（晴）、*rain*（雨）、*showers*（阵雨）、*cloud*（云）、*wind*（风）、*degrees*（度）、*temperature*（气温）、*dry*（干燥）、*cold*（冷）。
(b) 预报中可以预测的词：*dry*、*bright*、*cloud*、*showers*、*wetter*、*windier*、*degrees*。较难预测的：*build from the west*（从西部增多）、*coastal areas*（沿海地区）、*highs of only eleven*（最高只有十一度）——正是这些细节使这段预报与别的预报不同：在哪里、什么时候、程度多大。它们必须靠解码，而且往往正是你需要的信息（[[listening-and-conversation/gist-and-detail]]）。
:::
:::

::: exercise 重建信息 {level=3}
在一列嘈杂的火车上，你只听到了一段广播中的这些重读词：*… ˈapologise … ˈdelay … ˈsignal ˈproblem … ˈBirmingham … ˈtwenty ˈminutes … ˈconnecting ˈservices …*（……道歉……延误……信号问题……伯明翰……二十分钟……换乘车次……）写出最可能的完整广播，然后说明你会向其他乘客核实哪些部分，为什么。
::: hint
利用你关于火车广播的图式：谁在说话，他们通常先说什么，乘客需要知道什么。
:::
::: solution
一种可能的广播：*We apologise for the delay to this service. This is due to a signal problem near Birmingham. We expect to be running about twenty minutes late. Passengers with connecting services should speak to a member of staff.*（本次列车晚点，我们深表歉意。这是由于伯明翰附近的信号故障造成的。预计列车将晚点约二十分钟。需要换乘的乘客请与工作人员联系。）（其他说法也可以。）

要核实的部分：**twenty minutes**——是二十还是二十五分钟，是晚点还是更久？**Birmingham**——是伯明翰附近出了问题，还是列车现在要在伯明翰停靠？**connecting services**——需要换乘的乘客应该怎么做？这些细节影响你的行动，而且无法根据图式预测。向另一位乘客简短地问一句是很自然的：*Sorry, did they say twenty minutes?*（不好意思，他们说的是二十分钟吗？）
:::
:::

::: exercise 听力日记 {level=3}
用一周时间，每次用英语听过东西之后（一次谈话、一段视频、一节课），写两三句话：你听懂了什么，在哪里跟丢了，你认为是[[#rule-breakdown]]中的哪个原因造成的。周末时找出规律，选一件事来练习。
::: solution
答案因人而异。有用的日记是具体的：不是 *"It was too fast"*（太快了），而是 *"I lost the speaker after 'which is why we decided…' because I was still thinking about 'redundancy', which I didn't know"*（在 which is why we decided… 之后我就跟丢了，因为我还在想 redundancy 这个不认识的词）（卡住）。常见的规律有：(1) 在快速口语中认不出认识的词——用听写和语块来练习（[[connected-speech/hearing-fast-speech]]）；(2) 被不认识的词卡住——练习放过它，去听下一个重音；(3) 缺少背景知识——听之前先读一读有关话题的材料。为下一周选定一个目标，比试图把所有问题一下子都解决更有用。
:::
