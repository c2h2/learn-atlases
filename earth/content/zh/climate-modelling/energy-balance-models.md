能量平衡模型是把气候模型化归为其不可再简的论证：行星的温度由它吸收的阳光与其发射的红外之间的平衡设定，而其他一切——风、风暴、云、森林——都是服务于这个平衡或其纬度再分配的管道。写成一个常微分方程，模型可以在一个下午标定、一分钟求解、并被追问气候科学最深的结构性事实：反馈的放大因子、冰-反照率反馈创造的**多重平衡**、让无冰地球与雪球地球在同一轮太阳下都稳定的**滞后**、以及由海洋的不情愿设定的瞬态增暖时标。本课完整建造这个家族：零维"带恒温器的黑体"模型及其两参数线性化；一维扩散的Budyko–Sellers模型及其分岔图；连接观测瞬态增暖、以及用于从历史记录估计气候敏感度的双层仿真器的时变版本——混合层与双层；以及诚实的清单：EBM不能做什么（天气、动力学、云除了作为一个参数之外的任何东西）。先修是[[climate-system/energy-budget]]一课；练习要你亲手复现曾经填满期刊的结果——因为一个你自己做出分岔的EBM，是防止误读下游昂贵模型的最佳防线。

## 零维模型

::: definition 零维能量平衡模型 {#def-zerod}
把地球剥成一个全球平均的温度计：一个温度T、一个能量收支。模型写作**C dT/dt = (1 − α)S/4 − I(T)**，其中S/4是被稀释到球面上的太阳常数（1361/4 ≈ 340 W/m²）、α是行星反照率（~0.30）、I(T)是向外长波辐射。I的三种闭合给出模型的三重人格。**黑体**闭合I = σT⁴给出有效辐射温度T = (S(1−α)/4σ)^¼ = 255 K——从太空看到的温度，比表面冷33 K，整个温室效应作为一个未被建模的缺口（开创这门学科的那道练习，从Fourier 1824年"纯净空气"论证起）。**线性化**闭合I = A + BT——对真实辐射方案的两参数拟合、整个领域的主力（当前气候A ≈ 210 W/m²、B ≈ 2 W m⁻² K⁻¹；等价的净出口形式I = F₀ + λT，当变量是表面、不是大气顶时普朗克反馈λ ≈ 3.3 W m⁻² K⁻¹）——把平衡变成算术：T_eq = ((1−α)S/4 − A)/B，把扰动变成放大定律ΔT = ΔF/(B − dASR/dT)，其中任何让吸收阳光随温度增长的反馈（冰-反照率、水汽）都在蚕食分母、倍增响应。**反馈形式**的闭合I = F₀ + λ₀T − ΣλᵢT把同一方程写成ΔT = ΔF/(λ₀ − Σλᵢ) = f·ΔT₀，[[climate-system/feedbacks-sensitivity]]一课的"无反馈响应乘放大因子"以其最纯粹的可读形式出现，放大因子f = 1/(1 − Rλ₀)，R是反馈强度之和；用话说：系统的敏感度是普朗克响应除以反馈蚕食了它多少，而**失控**始于它们把它吃光之时（λ_net → 0）。零维模型的美德是彻底的透明（每个分岔都是一个坐标轴上的草图）与彻底的去地理化：它看不见一个半球、一个季节、一朵云，而它是所有能看见这些东西的模型的解释脊梁。
:::

## 冰-反照率与一维模型

::: definition 冰-反照率反馈与一维扩散模型 {#def-icealbedo}
零维模型的一大添加是纬度，一大非线性是冰。**冰-反照率反馈**：雪与冰把α从~0.15（海洋）抬到~0.6–0.8，所以更冷的行星是更反照的行星，也就是更冷的行星——一个带阈值几何的正反馈，因为开关只在冰缘所在的温度带里猛烈动作（像α(T) = α₀ + (α₁ − α₀)·(T_m − T)/ΔT这样在融化温度T_m上下几度内爬升的参数化）。**扩散热输送**：大气与海洋沿温度梯度搬运热量，而最简单的守恒能量闭合让经向热通量正比于温度的曲率，F_y = −C·∂T/∂y，其散度成为一个扩散项C·∂²T/∂y²（North 1979分类法的"大尺度扩散"类，单个扩散率被调参到模型的赤道-极地对比匹配观测的约60 K）。**Budyko–Sellers模型**（Budyko 1969、Sellers 1973）把两者结合：**C(1−α(T))S(μ)/4 − (A + BT) + D·(d²T/dμ²) = 0**，μ = sin(纬度)，作为一个边界值问题求解、极地零通量。它的发现是这个模型五十五年后仍在被教授的原因：对今天的太阳，暖解唯一且稳定；当太阳输入下降（或冰-反照率耦合增强），暖状态与一个**寒冷的、被冰覆盖的状态**在一段参数范围内**共存**，中间隔着一条不稳定分支——而转变是**滞后的**，因为融冰与退反照率在一个方向上互相加强，而反向只在低得多的冰-反照率强迫下才开始。模型的分岔雪球地球（太阳减少约6%或等效时崩溃到全球冰封、恢复需要模型里数百倍于当前的CO₂，与新生元古代冰期盖碳酸盐记录的约10⁵ ppm上限相符，1992年Kirschvink–1998年Hoffman–2017年地层长卷）是气候科学里最简单的演示：**系统对缓变强迫的响应可以不连续**——[[climate-change/tipping-points]]一课每个翻转点论证的模板。
:::

## 含时模型

::: definition 含时EBM：混合层、双层、与瞬态响应 {#def-transient}
给零维模型一个热容量与一段强迫历史，它就变成观测记录的解读者。**单层（混合层）模型**C dT/dt = F(t) − λT有指数解T(t) = (F/λ)(1 − e^(−t/τ))，e倍时标τ = C/λ：取混合层的C ≈ 10⁸ J m⁻² K⁻¹（25–50米海洋）与λ ≈ 3.3，τ ≈ 1年——表层海洋接受一个强迫台阶的节奏。**双层能量平衡模型**（一层表面C₁压在深层海洋C₂之上、以效率κ交换热量——一个自1980年代使用、2000年代为观测估计形式化了的类）添加了使瞬态气候与平衡气候不同的那一个过程：**海洋热吸收**，N = κ(T₁ − T₂)，它吸掉今天三分之一的强迫、让观测增暖远低于其平衡值；其解有两个时标——十年尺度的"穿透"模与百年尺度的"调整"模——而其拟合参数（λ与κ）是从历史温度与热含量记录通往ECS与TCR的标准EBM路径（Lewis与Curry 2014年ECS ≈ 1.6 °C的双层估计及其后续批评、至今仍分裂领域的2020年代"历史记录中的ECS"文献，就是一个EBM能与不能主张什么的案例研究）。**全球平均但能量分辨**的推广——表面与大气、长波与短波通道、陆地与海洋各设收支——保持ODE的性格同时修好具体的零维病症（"基于表面对大气顶的强迫"之惑在双层记账中消解）。这个家族现代角色的诚实总结：EBM不再是预测，它们是**传递函数**——在综合评估模型内部把强迫情景变成温度轨迹的廉价、可微、可解释的替代物（MAGICC线，从1990年代Wigley与Raper版本到校准到整个CMIP系综的2011年Meinshausen MAGICC6）、以及在需要一万个未来而不是一个的不确定性研究内部。
:::

::: example 完整的零维模型：一页算完 {#ex-zerod-worked}
标定、扰动、弄坏——学生应当掌握的四个数字跑完整个零维模型。**标定：**取S = 1361 W/m²、α = 0.30，吸收平均为238 W/m²；设I = A + BT，A = 210、B = 2.0，平衡就是T = (238 − 210)/2 = 14 °C——离实际表面均值一度以内，两个参数、不点名任何温室物理（线性化是*穿过*当下拟合的，这就是模型的全部戏法与其全部诚实）。**用CO₂扰动：**倍增给出ΔF = 5.35 ln 2 ≈ 3.7 W/m²；只用类普朗克的B = 2，增暖是3.7/2 ≈ 1.9 °C——但基于表面的普朗克参数是3.3，给出练习里的无反馈1.2 °C；这个差（B拟合在大气顶对λ定义在表面）是教训一：粗心地读EBM参数。**添加反馈：**水汽（≈ +1.8）、表面反照率（≈ +0.8）、云（多数模型净≈ +0.6）对抗直减率（−1.1），总和的净反馈吃掉3.3中的约2.1，留下λ_net ≈ 1.2与ΔT_eq = 3.7/1.2 ≈ 3 °C——Charney数字，由一行方程复现，其参数是在GCM与卫星里测出来的。**弄坏它：**把冷状态里的冰-反照率项抬到3 W m⁻² K⁻¹，λ_net变小、放大因子超过10、暖平衡在一个阈值太阳之下消失——下一个示例的雪球，以算术的姿态到来。这四步就是这个模型全部的职业生涯：它穿过当下被标定，被信任于响应的符号与粗略大小，只要反馈依赖状态就不被信任其量级，而*恰在它断裂处最有信息量*，因为一行模型里的分岔是一个关于真实系统能做什么的定理。
:::

::: example Budyko的图：从黑板上算出雪球地球 {#ex-budyko}
Budyko 1969年的计算装得下一块黑板，却改变了气候理论能装下的东西。以全球平均温度为横轴，画出吸收的太阳辐射（温暖的无冰状态高、冰让行星变成镜子的地方低）与向外长波（随T陡升、近乎线性）。曲线相交处行星平衡；吸收超过发射处增暖；相反处变冷。对今天的太阳只有一个交点——暖状态——而且它是稳定的。把太阳调低几个百分点（或加强反照率耦合），吸收太阳曲线上的冰-反照率折角就产生**三个交点**：一个稳定的暖状态、一个稳定的冷状态、以及两者之间一个不稳定状态。系统的历史于是取决于它的过去：冷却得足够缓，暖状态滑向冰缘直到交点不复存在，行星**坠落**到冷分支——一次从平滑强迫变化来的不连续转变；从冷分支加热，它保持冻结直到CO₂（在模型里是工业化前的几百倍；在新生元古代记录里，是从Sturtian与Marinoan冰川沉积的同位素与盖碳酸盐地质读出的约10⁵ ppm、2010–2020年代U-Pb定年地层学）抹去暖分支的竞争者、行星跳回。这条滞后回路画出的是该领域至今仍在争论的三个概念的奠基示例：**翻转**（平衡消失的折叠分岔）、**滞后**（让冰期退出CO₂远超最终稳定值的路径依赖）、以及**早期预警**（折叠附近的临界慢化——2009–2020年代统计检测纲领，其对真实的、噪声驱动的、部分观测的气候的适用性仍有争议，2023–2025年AMOC预警信号之争再次演示）。模型的定量雪球阈值（太阳减少6%）后来被更好的反照率与CO₂风化处修正（2000–2010年代"硬雪球对浆雪"之辩，部分由化石证据暗示的赤道开阔水避难所解决），但定性结构——S形的平衡曲线——在十年评估之后的每本教科书与每个翻转点简报里存活下来。
:::

::: example 双层EBM与历史记录的争夺 {#ex-twolayer}
双层能量平衡模型——表层、海洋层、强迫进、辐射与热吸收出——是四个数字与两个微分方程，而它在2014年产出了十年争议最大的气候敏感度估计。设定：C₁ dT₁/dt = F(t) − λT₁ − κ(T₁ − T₂)；C₂ dT₂/dt = κ(T₁ − T₂) −（深海泄漏），由最佳估计的强迫历史驱动（温室气体、带着其顽固负号的气溶胶、2013–2021年把气溶胶强迫的量级向上修订、两次重塑了这一文献），拟合到1850–2013年温度记录、并越来越多地拟合到海洋热含量记录（AR6时代的领悟：热含量、不是表面温度，才是能量收支约束更好的积分量）。Lewis与Curry 2014年的双层拟合返回ECS约1.5–1.7 °C——低于CMIP5范围——而随之而来的争论是EBM认识论的大师课。**批评**：估计倚赖世纪中叶的气溶胶冷却及其不确定的强迫（2010–2020年代清洁空气与船舶航迹文献）、倚赖假定的内部变率型（2000年代"停滞期"的太平洋增暖型、在其自然模被计入之前让2010年代初的记录看起来低敏感度，2015–2019年关于型效应与"响应面"方法的文献）、以及倚赖λ跨气候的线性——最后一条只有在EBM为绕开而建的GCM里才可检验。**辩护**：方法的假设是显式而可审计的，不像一个百万核时模式的，而热含量约束的版本（用Argo时代海洋增暖的2020年代拟合）把ECS拉回2.5–3.5 °C。2020年代的综合（美国国家科学院2019年报告与AR6 2021年的三角验证）把EBM估计当作一条证据线——对其间包含的物理可信、对其无法表达的反馈结构失明——这正是层级的判词：双层模式是问"仅凭历史记录、给定这四个假设意味着什么"的正确仪器、是问"事情就只有这些吗"的错误仪器。
:::

::: example 地球之外的EBM：作为分岔图的宜居带 {#ex-exoplanet}
能量平衡模型最意外的第二职业是系外行星气候学，在那里它们不是玩具模型而是最前沿——毕竟只有一颗行星有气象站。**宜居带**（表面液态水稳定的轨道距离范围）恰恰按Budyko几何计算：吸收的恒星通量对抗向外辐射，内缘由**湿温室/失控**极限设定（水汽到达平流层、光解逃逸——1993年Kasting时代的1维辐射-对流计算、把内缘向内移动并发现潮汐锁定状态之间异步自转"眼球"行星的2010年代3维GCM重估），外缘由**CO₂凝结与最大温室**极限设定（CO₂在自身凝结或辐射饱和之前能加厚多少——2013–2020年外缘的最大CO₂研究）。零维模型的教科书结果——T ∝ S^¼，所以在金星轨道的行星（1.9倍地球通量）按黑体逻辑只热约45 K，这就是为什么金星的460 K之差是一个温室故事、不是距离故事——为每场"金星是失控温室吗"的讨论定框，而冰-反照率分岔为"冰冻的地球大小行星"之问定框：对M型矮星，2010–2020年代潮汐锁定与自转状态文献（2013–2016年Yang等的环流共振结果、JWST 2023–2025年观测开始检验预测的2020年代TRAPPIST-1系统论文）把EBM的三个平衡变成一个普查问题——已观测的行星哪些坐在哪条分支上。故事的告诫一半同样有教益：固定云与规定反照率的EBM在1990–2010年代把**宜居带内缘弄错了两倍**，因为湿温室里的云反馈才是答案，而2019–2024年3维GCM与实验室天体生物学的重估（2020年代的失控极限、"类织星假阳性"文献）证明零维模型的诚实——其假设写在一行里——也是它的天花板：当缺失的物理*就是*反馈本身，分岔图就是一个关于行星的假说、不是关于一颗行星的陈述。
:::

::: history 两个世纪平衡行星的账目 {#hist-ebm}
**1824–1896**：Fourier注意到地球表面远比其辐射温度所暗示的暖、并提出大气作为绝缘体（"像带玻璃盖的箱子"，1824）；Tyndall 1859–1861年的实验认定水汽与CO₂是吸收气体；Arrhenius在其学生Ekholm的CO₂估算指引下、用Langley的太阳光谱测量，在1896年算出CO₂倍增把一个层模型增暖几度——能量平衡论证与温室计算在同一个十年诞生。**1950–1969**：现代时代开幕——Möller 1963与Kuhn 1961的辐射-对流反馈计算；Budyko 1962年的《地球表面的热平衡》确立行星作为账本的方法；1965年Manabe–Wetherald的CO₂模型与1967年水汽反馈版本随后；而Budyko 1969年的冰-反照率模型发表了第一个气候分岔，立刻遭到气象学建制的质疑（它喂大的1970年代"新冰期"恐慌是被气溶胶与海洋物理化解的、不是因为模型把几何弄错了）。**1973–1979**：Sellers 1973年的辐射作用能量平衡模型推广了反照率方案；North 1979年对能量平衡模型的分类（按输送律、辐射律、反照率律）固定了至今教授的通分类法；最早的雪球线索进入地质文献。**1992–2003**：Kirschvink命名雪球地球（1992）、Hoffman等发表盖碳酸盐论据（1998，2017年新生元古代定年计划补全了地层），而EBM作为综合评估引擎找到第二春（MAGICC谱系、1990–2011年Wigley–Raper–Meinshausen对GCM的校准）。**2014–2025**：Lewis与Curry的历史记录ECS估计开启双层战争；AR6（2021）让海洋热含量充当仲裁；JWST时代把EBM分岔图变成可观测系外行星的预测，而2023–2025年"失控极限"重估完成了从Arrhenius层模型到其他恒星周围行星的圆——一行模型活得比每一个为取代它而建的模型都久。
:::

- [x] 因为冰-反照率反馈是滞后的：冻结状态的高反照率必须先被克服，反馈才会反转，所以冰期退出的阈值超过解冻后的稳定水平
- [ ] 因为海洋的热容量永久延迟增暖
- [ ] 因为CO₂被海冰吸收

::: solution :::
在S形平衡曲线上，系统坐在冷分支上直到暖分支重现——而这需要大到足以消灭冷平衡的强迫、不只是越过不稳定阈值。错配的地质学解法（模型数百倍CO₂的退出冰期要求对盖碳酸盐同位素记录的估计）涉及解冻后风化的缓慢抽除（2000–2010年代让高CO₂自我设限的"风化恒温器"、百万年时标）——EBM的滞后是对的，而地质学补上了缺失的慢项。
:::
:::

::: quiz {#quiz-diffusive}
扩散EBM的赤道-极地温度对比：

- [ ] 相对观测太大，因为模式中涡旋效率低下
- [x] 一旦计入冰-反照率反馈，对给定扩散率而言太小，而所需的扩散率不是常数而是一个调参数字——真实输送是非线性、涡旋受限的迹象
- [ ] 恰好正确，这就是扩散是标准闭合的原因
- [ ] 与所选扩散率无关

::: solution :::
用常数扩散率，模式过冷的极地加强冰-反照率反馈并过度冻结（"极地过冷"病症），而观测大气的涡旋输送在斜压不稳定性用完可用能量时饱和——扩散率其实是一个依赖状态、受限的量（1990–2020年代"涡旋饱和"与依赖湿度的输送文献、以及作为替代的2010年代基于湿度/能量的输送模型）。教训可推广：EBM恰在其输送闭合假装地理不存在之处失败，而其修补史测绘了真实气候的非线性。
:::
:::

## 练习题

::: exercise {level=1 check="255"}
**辐射温度。**取S = 1361 W/m²、α = 0.30、σ = 5.67 × 10⁻⁸ W m⁻² K⁻⁴，计算地球的有效辐射温度T = [S(1−α)/4σ]^¼，以开尔文计（最接近的K）。
::: solution :::
吸收 = 1361 × 0.70/4 = 238.2 W/m²；T⁴ = 238.2/5.67 × 10⁻⁸ = 4.20 × 10⁹ K⁴；T = **255 K**——卫星感受到的温度，比表面低33 K，整个温室效应作为一个未被建模的数字，以及本课程每个辐射模型的起点。
:::
:::

::: exercise {level=1 check="15"}
**线性化平衡。**在模型I = A + BT中，A = 210 W/m²、B = 2.0 W m⁻² K⁻¹，什么平衡温度（°C）平衡240 W/m²的吸收太阳通量？
::: solution :::
T = (240 − 210)/2.0 = **15 °C**——标定的戏法：两个参数穿过当下拟合复现平均态，这就是为什么EBM被信任于*变化*、不被信任于绝对值，也是为什么必须始终说明参数的出身（在哪里拟合的？）。
:::
:::

::: exercise {level=1 check="1.5"}
**混合层时标。**取混合层热容量C = 1.5 × 10⁸ J m⁻² K⁻¹（约35米海洋）与λ = 3.3 W m⁻² K⁻¹，e倍时标τ = C/λ是多少年（3.15 × 10⁷ s/年）？
::: solution :::
τ = 1.5 × 10⁸/3.3 = 4.55 × 10⁷ s = **1.5年**——表面气候对任何强迫脉冲响应的速度上限（火山喷发按这只时钟恢复，1991年皮纳图博的下探与1993–1995年的回弹是自然实验），也是*观测*增暖滞后长得多的原因：脉冲扩散进深海，而那是双层模型的全部主题。
:::
:::

::: exercise {level=2 check="11"}
**接近失控的放大。**如果冷状态中冰-反照率反馈强度是3.0 W m⁻² K⁻¹、对抗普朗克响应λ₀ = 3.3 W m⁻² K⁻¹，增暖被放大多少倍（f = λ₀/(λ₀ − Σλ)）？
::: solution :::
f = 3.3/(3.3 − 3.0) = **11**——1.2 °C的无反馈响应变成13 °C，而把反馈推到3.3就让答案无穷：放大公式就是失控温室、雪球坠落、以及"云反馈吃掉普朗克响应"的ECS辩论，写成一个分数。
:::
:::

::: exercise {level=2 check="0.9"}
**海洋热吸收。**今天的净强迫是F = 3.7 W/m²（一个倍增的量级，姑且这么说），地球能量不平衡（热吸收）是N = 0.8 W/m²。取λ = 3.3 W m⁻² K⁻¹，表面*表达*出的增暖T = (F − N)/λ是多少？
::: solution :::
T = (3.7 − 0.8)/3.3 = 0.88 ≈ **0.9 °C**——双层模型的核心记账：五分之二的强迫藏在海洋里，这就是为什么观测增暖低估平衡增暖、为什么"承诺增暖"在零排放时也存在、以及为什么海洋热含量记录（AR6时代的仲裁者）是储存了多少、而非丢失了多少的诚实度量。
:::
:::

::: exercise {level=2 check="24"}
**趋近平衡。**一个双层EBM的长（调整）时标对持续强迫是τ₂ = 8年。表面达到其平衡增暖的95%要多久（t ≈ 3τ）？
::: solution :::
1 − e^(−3) = 0.95，所以t = 3 × 8 = **24年**——这就是"平衡"敏感度在任何情景的头几十年不可见的原因、是TCR（瞬态的、大约ECS的一半）是2020年代实际经历之量的原因、也是停止排放会很快停止*强迫*、却让表面继续调整几十年的原因。
:::
:::

::: exercise {level=3 check="7.5"}
**冰期退出的算术。**一个雪球行星需要工业化前100倍的CO₂才能逃脱。用F = 5.35 ln(C/C₀)与λ₀ = 3.3（还没有冰-反照率的帮助），仅凭CO₂的无反馈增暖是多少K？
::: solution :::
F = 5.35 × ln 100 = 24.6 W/m²；ΔT = 24.6/3.3 = **7.5 K**——加上塌缩中的冰-反照率反馈骑在上面，足以跨回暖分支：练习复现了为什么新生元古代的逃脱需要*地质上极端*的CO₂（约10⁵ ppm的盖碳酸盐估计）、以及为什么今天同样的100倍、没有冰盖可失去，将是一场约7–8 K的无反馈灾难——EBM对同一个数字的两个答案，一个让人安心、一个不。
:::
:::

::: exercise {level=3 check="2.1"}
**从记录求ECS。**历史记录给出：2020年强迫F = 2.7 W/m²、不平衡N = 0.7 W/m²、观测增暖ΔT = 1.1 K。拟合λ = (F − N)/ΔT并用F₂× = 3.8 W/m²计算ECS = F₂×/λ。
::: solution :::
λ = (2.7 − 0.7)/1.1 = 1.82 W m⁻² K⁻¹；ECS = 3.8/1.82 = **2.1 °C**——一次除法里的Lewis–Curry低敏感度估计家族，以及下一口气里的批评：答案悬在N上（Argo时代的热含量，被2020年代测量向上修订，从而抬高λ、拉高ECS）与悬在假设λ一直恒定、而云机制在重组上——EBM给出记录意味着什么的尽可能干净的陈述、*以及*它为了这么说必须假设的一切。
:::
:::

::: exercise {level=3 check="22.4"}
**恒星通量缩放。**一颗行星接收到地球吸收通量的1.4倍，反照率与发射律相同。其黑体温度超出地球255 K多少K（T ∝ S^¼；1.4^¼ = 1.088）？
::: solution :::
T = 255 × 1.088 = 277.4 K，ΔT = **22.4 K**——让距离成为温度弱控制的四分之一次幂律（金星接收1.9倍却热460 K：差别是大气、不是轨道），它把宜居带的宽度设为通量的几十个百分点，也正是为什么失控与凝结*阈值*——非线性的、云与化学受限的——而不是四分之一次幂本身，决定带的边缘实际落在哪里。
:::
:::

::: warning EBM误导的四种方式
1. **"模型说15 °C，所以模型把温度钉死了。"**零维模型的平均态是*拟合*穿过当下的——A与B被选成答案就是今天。模型对绝对温度没有任何内容；它的内容全在*微分*里（当某物变化时平衡如何移动），每个主张都该带着这个星号来读。33 K的温室缺口是同一警告的响亮版本：黑体温度是一个关于向太空发射的陈述、绝不是关于我们居住的表面的陈述。
2. **"λ = 3.3，所以敏感度是1.2 °C、辩论结束了。"**普朗克响应是λ_net里的一项；填满剩余约2 W m⁻² K⁻¹的那些反馈依赖状态、由云主导、依赖型——而把λ当作历史记录上常数的EBM拟合（2014–2020年从历史记录求ECS文献的核心假设、也是其核心批评）测量的是一个*有效*λ、对某个特定强迫型与气候状态平均过的，不是大气的一个属性。
3. **"模型里的分岔就是一个预报。"**雪球解证明真实系统*能*有一个冷的替代状态；它没有说地球接近折叠、没有说人为扰动指向它（它指向反面——增暖）、也没有说模型的6%太阳阈值是真实阈值（风化反馈、云、古地理把它移动数倍）。玩具模型里的分岔是存在定理与风险框架——2010–2020年代翻转点的传播失败（"本世纪AMOC崩溃"的头条对抗AR6低概率评估）就是定理解读成预测时会发生的事。
4. **"EBM是拿来教的；真正的工作用GCM。"**2020年代的现实：EBM及其推广运行在每个给碳定价的综合评估模型里（MAGICC-DICE链）、每个大系综仿真研究里、政策建模者碰到的每次快速情景筛选里、以及每篇系外行星宜居性论文里。正确的框架是层级：EBM不是一个糟糕的GCM，它是一件*不同的仪器*——其假设可审计、其分岔是定理、而其与复杂模型的分歧是满屋子数字里最有信息量的那一个。
:::

## 总结

::: summary
能量平衡模型把气候化归为一个账本——吸收的阳光对抗发射的红外——而这个化归是多产的：零维模型的放大定律ΔT = ΔF/(λ₀ − Σλ)包含整个反馈形式论、并把失控显示为分母的消失；Budyko–Sellers冰-反照率模型添加纬度与一个非线性，从而用黑板上的两条曲线证明该领域最深的结构性事实——多重平衡、折叠分岔、滞后——雪球地球、其约10⁵ ppm的冰期退出CO₂、以及此后每个翻转点论证的模板；含时的双层模型添加海洋热吸收、成为历史记录的诚实解读者，其四个参数（λ、κ、C₁、C₂）是敏感度科学中争议最大的数字（Lewis–Curry事件、热含量时代的修订）。EBM以有教益的方式失败——调参的均值、恒定的λ、去地理的输送、作为参数的云——而每次失败都点出一个上层阶梯必须承担的过程。它们的现代角色不是预测而是*传递*：评估与综合评估机器内部的强迫到温度函数、系外行星气候学的假说生成器、以及本课程自己的标定仪器——因为每个亲手找到雪球的学生都确切知道是哪个假设干下的，而这种素养正是百万核时的模式无法就其自身提供的。
:::
