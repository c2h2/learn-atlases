模式评估是气候建模事业整个的认识论主张：既然没人能运行模型所预测的实验，预测的全部价值取决于模型在多大程度上复现了它们**没有**被调参去复现的一切——这个逻辑被看着领域为此挣扎五十年的预测哲学家们说得最干净，而被建模者自己实践着，不均衡地、带着著名的失败。这门学问有三条腿，本课三条都建。**确认**——我们方程解对了吗？——[[climate-modelling/numerical-methods]]一课的人造解、守恒审计与基准算例，算术的同行评审。**验证**——解描述观测的世界吗？——平均态偏差、变率谱、卫星时代的收支、过程评估与古气候留出检验，围绕领域来之不易的规则组织：对照独立于调参目标的观测评估、在决策在乎的变量上报告技巧、不信任任何唯一成功就是其被拟合之处的模型。**确证**——成功向预测转移多少？——任何RMSE都无法完全闭合的认识论一跃，领域通过跨证据线的三角验证（AR6 2021置信语言机器）、通过涌现约束（2012–2020年代把模式间散布加一项观测变成收窄敏感度的纲领，及其2019–2021年警示性事件，旗舰的砧状云约束在复现中失败）、并通过诚实的词汇——"稳健""很可能""低置信"——来管理这些词汇是评估们发明的，因为"已证明"永远不可得。本课的案例研究是该领域的评估博物馆，为成功与尴尬双方的教益而选：把一个模式失败变成诊断胜利的北极海冰记录预测分析；触手伸到敏感度本身的南大洋冷偏差；死于复现的那个约束；以及落在每个模式系综之上、迫使共同体做出十年最公开一次评估清算的2023–2024年记录增暖年——其回答"模式没有错，它们只是没被启动"就是评估逻辑的一句话。先修是[[climate-modelling/model-hierarchy]]与[[climate-modelling/parameterisation]]两课；回报是免疫——对"模式把X弄错了所以Y别听"的谬误、对"模式一致所以已成定论"的谬误、以及远更常见的职业错误：在你被给定的变量上、而不是你需要的变量上评估一个模式。

::: definition 确认、验证、与证据的逻辑 {#def-evidence}
这三个动词不是同义词，而该领域的历史部分上是学会分离它们的故事。**确认**问离散化的方程是否被正确求解——网格收敛研究、人造解、守恒审计、基准套件——产出"这份代码以这个精度求解这些方程"式的陈述，一个关于算术的主张，多少观测一致性都无法替代（一个错误的方程可以被完美求解，2024–2025年层积云瓦解的运行同时是确认的成功与验证的谜题）。**验证**问被确认的方程是否描述观测的系统——这里的逻辑是经Oreskes中转的波普尔：模式被信任不是因为它通过检验，而是因为它的失败可定位、其出人意料的成功在积累（1994–2001年"模式像侦探一样赢得信任"的论证，靠未被调参去拟合的预测与观测的汇合）。**校准与确证**——统计的两条腿——问给定成员的技巧与独立性，系综的散布应如何加权，2010–2020年代文献正在进行的争吵（2009–2010系综加权辩论、2018–2020年代"气候模式排名"之争关于基于技巧的加权是收窄还是偏差预测范围、2023–2025统计学共同体的介入）。评估们编纂的操作哲学（AR6 2021置信框架：陈述按**证据线**之间的一致——直接观测、古气候、理论、模式——及每条的质量与数量分级）是该领域与强意义确认之不可能性的休战：没有单次模式评估能确证一个预测，但当每条独立的认知方式都与一个预测一致时它就存活，而2021年物理科学报告要点的头条归因（人类对气候与天气的影响、海洋的增暖、冰的流失）正是这样的多线存活。定义的工作规则值得在度量到来之前背下：**评估的问题从来不是"模式匹配吗"，而是"为何匹配、对照哪些独立数据、以及这个量级的不匹配对我正要做出的推断意味着什么？"**——最后那一句就是评估与记分之间的分界。
:::

::: definition 度量：偏差、评分、图、以及它们藏什么 {#def-metrics}
评估文献的仪表盘不大而凶险。**平均态偏差**（模式减观测、2010–2020年代CMIP图集地图）是使用最多也最被误用的数字：当南大洋1 K的冷偏差被读作"模式在那里错了"而不是"模式在那里错在一个其动力学后果——位移的风应力、位移的水团属性、有偏的一个变率模——可能远比1 K更要紧的模式"时就是误用；当偏差被分解为造出它的过程（模式诊断文献的辐射收支与热输送分解、自2000年CERES时代让东南太平洋低云偏差成为该领域被评估最多的数字的云反馈地图）时就是正确使用。**Taylor图**（2001年Taylor统计量把相关、标准差比与中心化RMSE画在极坐标上）一眼组织多模式技巧比较而把偏差完全藏起来——一个模式可以带着10 K的均值偏移坐在参考点上，图臭名昭著的盲点，这就是为什么严肃的版本添加偏差环、或转向**三分量分解**（MSE = 偏差² + 方差失配² + 2σₘσ₀(1−r)：本课练习下面的widget，领域对"这个模式是哪种错？"的回答）。从验证科学进口的**技巧评分**——异常相关、RMSE、概率的Brier评分、1990–2020年代预报验证文献的可靠性与分辨率分解——气候评估不断借用也不断误用（这些评分假设系综采样真相的分布，而被调参的多模式系综出了名地不如此——CMIP系综散布的过度自信，2010–2020年代散布对误差文献的中心发现：对许多变量模式间方差把真实不确定性低估一到两倍）。以及**评估数据集自身**，二十世纪最被低估的评估基础设施：再分析（ERA5及其前身，其自身的模式内容让"模式对再分析"成为一个部分循环的比较，2010–2020年代文献公开陈述）、卫星合成（2000年以来的CERES辐射、MODIS云与气溶胶产品、2006年以来的CloudSat–CALIPSO云廓线、2024–2025年EarthCARE时代）、以及原位阵列（2000年代以来Argo的4,000个浮标做出的海洋热含量验证——2020年代决定性的度量、锚定AR6头条数字通过的能源收支一致性检验的那一个）——这些就是评估一个气候模式与评估一张天气图之间的区别。
:::

::: definition 过程评估与涌现约束 {#def-process-emergent}
记分告诉你一个模式是错的；过程评估告诉你**为什么**，而2010–2020年代纲领（2010年代Pincus等"气候模式对照过程级观测的评估"的呼吁、E3SM与能源部试验台传统、其数据——DYCOMS、VOCALS、COMBINE、2020年代外场计划档案——部分就是为了成为模式评估仪器而存在的外场考察）就是实践：比较模式的*机制*——其夹卷率对抗拉曼散射与雷达观测、其边界层统计对抗探空机队合成、其ENSO热输送对抗锚系阵列——不只是其输出，因为两个当今偏差相同而机制相反的模式在强迫下会灾难性地分岔，而对一个预测要紧的评估是检验那个正在做预测的机制。**涌现约束**把同一个想法跨系综操作化：当目标（ECS、气溶胶强迫、热带环流变化）的模式间散布跨模式与一个可测量的当今量（砧状云温度、辐射的季节循环、南大洋变率）相关时，该量的观测加上穿过系综的回归线就产出目标的一个收窄估计——2012年Brient–Boucher热带砧状云约束与2014年Sherwood–Bohon–Del Genio对流聚集约束是ECS纲领的旗舰、2020年Sherwood等的*Nature*综述是把它们折进2.3–4.5 °C可信范围的综合。该方法2019–2021年的清算既是气候学也是研究伦理的必读书：砧状云约束**在复现中失败**（2019–2021年再分析——2020年Wall等与2021年Cho等的卫星重处理研究发现，一旦CloudSat记录变长、早期时代的反演伪影被校正，观测到的砧状云增暖趋势缺席或反向），事件产出该领域显式的方法学论文（2019–2021年准则：要求物理机制、检验对数据集与方法的敏感性、量化伪相关风险——2020年代统计卫生的综合），以及一个永久的告诫：十五个共享物理与共享调参的模式之间的相关不是十五次独立抽样——2020年代约束有效性文献的有效样本量问题。定义的资产负债表：涌现约束仍是该领域最有力的*推论*工具——它们杀死了CMIP6的热尾部、锚定了AR6的敏感度范围——条件是它们被当作带数据集依赖寿命的假说、随记录变长而重跑、并且永远不在缺少其复现状态时被引用。
:::

::: definition 留出检验：古气候、极端、与循环性问题 {#def-heldout}
信息量最大的评估使用建模者从未见过的数据，而该领域与那个理想的关系统是一部诱惑的目录。**古气候作为留出检验**是[[palaeoclimate/last-two-millennia]]与[[palaeoclimate/deep-time]]两课的数据使之可能的金标准：末次盛冰期的120米海平面、中中新世的3–4米与3–4 °C、始新世的温室梯度，是自然用未知模型跑的CO₂实验，而PMIP计划的协议运行（2017–2022年CMIP6古气候强迫实验）让预测2100年的同一份代码去后报它们；2020年代综合的判词是双刃的——模式通过大尺度型检验（冰期型、上新世高纬放大）而在幅度与区域细节上失败（冰期海洋的温度季节性与始新世"北极有棕榈"的水文），而失败富有信息，恰恰因为古世界压测预测所依赖的那些反馈。**极端评估**是公众实际消费的留出检验，也是模式被正确提问时处理得最好的一环：ETCCDI指数套件与热极端归因统计量（[[natural-hazards/risk-reduction]]与[[climate-change/attribution]]两课的机器）显示模式复现观测的热极端与降水强度趋势（极端降雨的Clausius–Clapeyron缩放、2010–2020年代卫星与雨量计综合），而在复合事件的统计、阻塞持续性与区域尾部上挣扎——诚实的陈述是：模式在由平均态物理推出的极端上评估良好、在由网格看不见的动力学推出的极端上评估糟糕。**循环性问题**是时代的方法论自觉：再分析是模式、调参目标迁移进评估集（2020年代审计文献发现许多发表的"评估"用的正是参数化被调参去拟合的同一批卫星产品）、检测归因指纹与模式评估共享同一批观测，而2010–2020年代的回应——留出数据协议、从神经科学进口的双重使用词汇、AR6按哪些证据线独立于哪些来给每个主张分级的实践——是该领域承认其确证问题既是物理的也是统计的：在一个有限的观测系统里，同样40年的卫星记录同时是调参目标、评估与归因数据，而诚实在于说出当三个角色被分离时哪些主张存活。
:::

::: example 北极海冰：那次奏效的失败 {#ex-arctic-eval}
2007年九月海冰极小值——1996–2005平均的四分之一在一个夏天消失、模式们的2100年到来日期被提前了一个世纪——是该领域最有教益的评估序列，因为模式错了，而领域把错误变得有产出。第一步，**承认并定位**：CMIP3一代的系综海冰下降太慢（2008–2013年Stroeve等与Holland–Stroeve–van Thoolen的诊断：初始态冰太厚、融池与冰脊物理缺失或偏弱、海洋热吸收有偏），一张可定位的清单、不是对整个事业的判决书。第二步，**建造记录预测**：Stroeve与Notz 2018年的方法——把观测的九月范围对模式自己的CO₂强迫回归、在多数模式按构造一致的1953年锚定、读出轨迹隐含的越过无冰阈值：观测记录跟踪系综中更陡的成员、中心模式隐含的日期比其自己的预测早几十年、该方法现在是2020年代评估"第一个无冰九月在2030年代、可能早于2035年"语言的标准（AR6 2021与IPCC特别报告时代的陈述，有2020年与2020年代的极小值作伴）。第三步，**把失败转化为结构**：海冰反馈（冰-反照率项的状态依赖、薄冰厚度分布对融化的控制）作为一个命名的不确定性进入敏感度文献，因为评估精确说出了缺失的是哪个物理。示例的评估定理：一个以可定位、单调方式出错的模式家族可以比偶然正确的更富信息——而发表自己记录预测、而不是埋葬意外的共同体，是其后来的预测值得信任的共同体。
:::

::: example 南大洋冷偏差：一个数字，五个后果 {#ex-southern-ocean}
CMIP档案里每个耦合模式都带着同一道疤：南大洋上的变淡与变冷偏差、其1–2 K的幅度存活了四代模式的"冷块"（CMIP3–CMIP6图集地图最稳健的共同偏差、2010–2020年代文献最爱的"一个其实是机制的偏差"示例）。评估链条运行如下：偏差意味着模式的水团（副南极模式水与南极中层水，其属性由2010–2020年代Argo时代调查文献测量）太淡也太深，因为耦合模式的降水、海冰与涡旋混合参数化——2000–2020年代分辨率研究的粗网格涡旋不敏感——把层结放错了位置；水团误差在模式自己的翻转环流中向北传播，所以偏差不是局地的、而是全球温跃层的一个边界条件；层结误差使人为热与碳的吸收有偏（南大洋占海洋热吸收的三分之二、2010–2020年代属性追踪综合），从而使模式在其他所有地方预测的瞬态增暖有偏；海冰边缘位置误差喂养风应力反馈、而在显示AMOC的模式里那设定其盐平衡；而——评估的点睛之笔——历史增暖型的"受迫"成分部分就是这个偏差在发展，所以使用历史记录的敏感度双层能量平衡估计（[[climate-modelling/energy-balance-models]]一课的Lewis–Curry事件）把它作为一个型效应继承下来。这个例子就是本课论点的单个偏差：地图上的单个数字是可评估的，其后果是系统性的，而诚实的陈述——"我们的模式共享一个机制误差，其预测符号我们可以划界但无法消除"——比任何技巧评分都更有价值，因为它告诉用户这个偏差能腐蚀哪些推断、不能腐蚀哪些。
:::

::: example 死于记录长度的砧状云约束 {#ex-anvil}
热带砧状云涌现约束的兴衰是评估时代最干净的方法论示范课。**兴：**Brient等2012年的分析在2000年代的卫星与再分析中发现，向太空辐射的砧状云温度增暖少于表面——对流云升入住更暖更稳定环境的签名，在模式的物理里意味着更暖世界里更多的高云与正云反馈；把模式ECS对模拟的砧状云温度趋势回归、插入观测值，得到接近4 °C的ECS、舒适地高于CMIP5均值，而约束挺过2014–2018年的复现尝试（2016–2018年中层温度与外流高度变体），成为2019–2020年排除低端论证的支柱之一。**衰：**随着CloudSat记录变长、再分析时代的反演伪影被审计（2019–2021年重处理文献——2020年Wall等对2000–2017卫星记录的分析与2021年Cho等的*Nature Geoscience*再分析发现，一旦早期时代的采样与反演偏差被校正，显著的砧状云增暖趋势并不存在），约束所需的观测趋势蒸发了，随之而去的是其ECS含义；2021–2023年方法学尸检（约束有效性文献的有效样本量与数据集敏感性准则）把发生的事形式化了：一个从10年合并卫星记录估计的年代际趋势、对着十几个物理上纠缠的模式回归，从来不是其置信区间所声称的那个样本。**残余：**物理机制（夹卷控制的砧状云高度）仍然活着且可检验（2020年代云分辨与EarthCARE时代计划），约束方法以更严格的卫生存活下来，而事件是该领域自我纠错管用的证明——缓慢地、公开地、朝正确的方向，这是验证科学真正能保证的评估科学的唯一属性。
:::

::: example 2023年：记录离开包络的那一年 {#ex-2023}
当2023年打碎全球平均温度记录——年平均达到约高于1850–1900的1.45 °C（WMO、Copernicus与Berkeley Earth 2024年的声明）、2023–2024年海表记录与北大西洋2023年春季非凡的距平运行在每个CMIP6系综成员之上——公众之问"模式错了吗"值得精确的回答，而评估共同体的回应是整课逻辑浓缩在一个事件里。**第一，记账：**CMIP6历史运行的系综包络不是单次实现的预测区间——它们是受迫响应加内部变率、从扰动初始条件出发的样本，而当内部模态（2023年太平洋2020年代拉尼娜到厄尔尼诺的转换、2010–2020年代文献的年代际太平洋与大西洋变率）叠在趋势上时，一个记录年可以合法地落在所有成员之上；2024–2025年归因分解（2024–2025年对2023年距成分的研究）把超额分给厄尔尼诺的启动、2020年IMO规则减少船舶气溶胶硫酸盐的台阶（[[atmospheric-chemistry/aerosols]]一课的活实验）、年代际内部变率、以及——带着诚实的误差棒——可能略大于系综均值的受迫响应，最后一项从单一年份不可判定。**第二，诚实的异议：**2024年Hansen等的分析主张模式低估增暖（"管道中的增暖"论文的气溶胶强迫与平衡论证）与共同体的答复（2024–2025模式共同体在辩护系综的同时承认[[climate-modelling/parameterisation]]一课编目的气溶胶强迫与云反馈不确定性）把领域的分歧摆在实际所在处——不在2023年是否被"预测"（没人预测单个年份到1.5 °C），而在受迫趋势是什么、历史拟合中有多少是补偿误差。**第三，评估判词：**模式的多十年受迫响应仍被最重要的能量收支一致性检验所验证——观测的表面增暖、海洋热含量与陆地项之和匹配卫星观测的辐射不平衡（2020年代能量收支闭合综合）——而包络之外的单一年份什么也不证伪，除了包络作为预报的流行读法。给评估科学的2023年教训：公众永远会把系综读成预报，而共同体的义务是每年用一句话说清包络是什么——评估们在2023年之前从未在公开场合做到过。
:::

::: history 评估作为该领域的第二门科学 {#hist-evaluation}
**1950–1988**：确认从评估结束处开始——1950年RFC预报对持续法的异常相关定下了此后每个评分继承的"相对无技巧的技巧"标准；1960–1970年代数值天气验证科学（1960–1970年代EPV与MOS统计、1970年代Brier与可靠性分解）建起气候将在半个世纪后借用的工具箱；而1979–1988气候模式互比的婴儿期（1982–1984年GCM比较计划、1989年ECMWF研讨会上提出的1988–1990年AMIP）发明了模式应按共同协议运行、公开审计的观念。**1989–2003**：比较时代——AMIP I–II与1990年代IASPECS和PMIP1让多模式评估成为常规，1990年代"评估GCM"教科书一代（1994–2003年McGuffie–Henderson-Sellers与Legates–Willmott统计量之辩）争论哪些评分要紧，2001年Taylor图与2000年代CERES与Argo卫星及原位革命给评估其现代仪器，而IPCC第三次评估2001年的模式评估章节把置信词汇法典化。**2004–2016**：诊断时代——2009–2010气候模式评估计划与2011–2016"十年模式"回顾、2012–2015涌现约束发明浪潮（2012年砧状云、2014年对流、2015年Stevens对理论引导评估的呼吁）、2013–2016北极海冰与南大洋偏差文献把单个偏差变成系统性诊断、以及2014–2016系综加权战争（2010–2013与2016–2018年关于技巧知情平均的辩论）。**2017–2025**：复现时代——CMIP6的协议宪法与模式描述透明度、2019–2021砧状云约束复现失败与2020–2023约束方法学清理、2021年AR6证据线置信机器全速运转、2023年记录年公开评估危机与2024–2025年Hansen交锋、以及2020年代机器学习仿真器的新评估问题——如何验证一个训练数据就是验证其他一切的观测的模式——循环性问题，终于，以机器规模。
:::

::: quiz {#quiz-heldout}
一次评估只有在所用数据是下列哪种时才在科学上有信息量：

- [ ] 卫星来源而不是模式来源
- [x] 独立于调参目标——模式未被拟合去用的数据——成功才是证据而不是重述
- [ ] 长于三十年
- [ ] 全球而不是区域

::: solution :::
逻辑是留出检验：一个调参到CERES辐射的模式会按构造"复现"CERES辐射，而对照它评估报告的是调参、不是物理。要求是角色的独立、不是仪器的独立——当被评估的过程未被调参碰过时，再分析甚至被调参的卫星产品也能为评估所用，这就是为什么CMIP6模式描述里的调参目标文档是评估基础设施、也是"模式对再分析"比较携带2010–2020年代文献明确标注的循环性星号的原因。
:::

::: quiz {#quiz-emergent}
砧状云约束2019–2021年的失败主要教会该领域：涌现约束需要：

- [ ] 系综里更多的模式
- [x] 一个被证明的物理机制加上数据集稳健性检验，因为跨物理上纠缠的模式、在短记录上的相关可以是共享假设的伪影
- [ ] 来自太空而不是地面的观测

## 练习题

::: exercise {level=1 check="0.2"}
**中心化MSE。**模式与观测方差相等、型相关r = 0.9。以方差的单位计，中心化MSE是多少？
::: solution :::
MSE_c = σ²(1 + 1 − 2r) = 2 − 1.8 = **0.2**——0.9的相关，论文里庆祝的那个数字，仍留下百分之二十的方差作为型误差，而widget的曲线对偏差不增一字：练习是该领域常设的论证——相关是形状的描述、绝不是正确性的度量。
:::
:::

::: exercise {level=1 check="9"}
**偏差分量。**一个温度场模式偏差+3 K、没有型误差也没有方差失配。以K²为单位其MSE是多少？
::: solution :::
MSE = 偏差² = **9 K²**——与一个无偏差但有3 K不相关型噪声的模式总误差相同，而这正是分解的全部要点：相同的评分、对均值驱动的影响相反的寓意（热浪阈值响应偏差、方差驱动的响应噪声），这就是为什么与影响相关的评估必须按决策的函数形式给分量加权。
:::
:::

::: exercise {level=1 check="0.6"}
**技巧评分。**一个NAO指数预报的异常相关为0.6、气候态的为0。如果两者都具有预报的方差，其相对气候态的均方误差技巧是多少？（技巧 = 1 − MSE_f/MSE_c，MSE_c = 2σ²，MSE_f = 2σ²(1−r)）
::: solution :::
技巧 = 1 − (1 − 0.6) = **0.6**——以及练习设下的陷阱：只有当方差匹配时MSE技巧才等于相关；一个相关0.6、方差只有观测一半的预报，尽管"看见了信号"、得分却比气候态更差，验证科学的可靠性对分辨率之课，气候评估在不断重学。
:::
:::

::: exercise {level=2 check="3.6"}
**涌现约束算术。**跨20个模式，ECS对一个可测量云统计量x的回归为ECS = 2.0 + 4.0x（r² = 0.64）；观测给出x = 0.40 ± 0.05。受约束的ECS中心值是多少？
::: solution :::
ECS = 2.0 + 4.0 × 0.40 = **3.6 °C**——约束的头条；接下来两道练习补上误差预算与怀疑，因为数字的可信度完全活在r²、系综的有效规模、以及观测独立于模式调参与否——砧状云事件使这三个问题成为必答。
:::
:::

::: exercise {level=2 check="0.5"}
**约束不确定性。**对上述约束，把观测的±0.05通过斜率传播、并把回归散布（±0.5 °C）按平方和开根加入。受约束的ECS不确定性是多少°C？
::: solution :::
斜率项：4.0 × 0.05 = 0.2；总计 = √(0.2² + 0.5²) = √0.29 ≈ **0.54 ≈ 0.5 °C**——观测只贡献宽度的五分之一：涌现约束的误差棒由系综的散布主导，这就是为什么回归弱时方法什么都不收窄（r² = 0.64留下三分之一的方差未解释）、也是为什么2020年代方法学论文要求可辩护的是散布、不只是斜率。
:::
:::

::: exercise {level=2 check="5"}
**有效样本量。**一个20模式系综的ECS与约束变量共变，但模式共享5个不同的物理家族。把家族当作独立抽样，有效样本量是多少？
::: solution :::
**5**——2020年代约束有效性文献形式化的有效样本量校正：当独立信息是n = 5时用n = 20计算的回归置信区间窄了√4 = 2倍，而2019–2021年的复现失败，穿上统计的外衣，就是假设了系综从未有过的独立性的置信区间——多模式系综均值文献（2010年代加权辩论）从另一个方向教的同一课。
:::
:::

::: exercise {level=3 check="4"}
**记录预测。**一个模式家族的海冰下降对累积排放回归为冰面积 = 6 − 1.0·S（S以1000 Gt CO₂计、面积以10⁶ km²计）；2020年的观测位于4.0。如果家族的斜率成立，观测轨迹隐含的2020年之后到无冰的排放是多少？
::: solution :::
无冰在S = 6；观测的2020年位置S₂₀₂₀ = (6 − 4.0)/1.0 = 2.0；剩余 = 6 − 2 = **4**千Gt CO₂——以及方法两个诚实的星号：斜率是系综的，而如果真实系统的薄冰反馈更陡（2010–2020年代变薄文献的警告），真正的截距会更早到来；记录预测是一个关于模式物理、锚定在观测位置上的陈述，其好坏恰等于模式机制的好坏——北极之课，再用代数讲一遍。
:::
:::

::: exercise {level=3 check="0.63"}
**系综作为预报。**如果CMIP6历史系综2020年代的多均值比观测的2015–2024均值低0.15 °C、而系综对十年均值的内部变率散布是0.12 °C，该模式家族在2σ水平上有偏吗？
::: solution :::
差距0.15对2σ = 0.24：比值为0.15/0.24 = **0.63** < 1，所以**没有**——观测落在系综自身噪声的两倍之内，所以单个十年不能证伪受迫响应（2023年事件一次除法给出的回答）；差距只有在跨独立十年或跨变量（模式也必须通过的能量收支一致性检验）积累时才成为证据，"包络之外"与"物理之外"的分别是2023–2025年公开辩论需要而大多没得到的那句话。
:::
:::

::: exercise {level=3 check="12"}
**评估失败的检测。**一个模式的降水频率偏差是−20%、最湿日强度偏差+10%。如果极端按频率 × 平均强度缩放，模式对一个5日总降水事件低估多少百分比？（0.8 × 1.1 = 0.88）
::: solution :::
0.88 → 低估**12%**——让评估变得依赖变量的复合事件算术：一个模式可以通过平均降水（偏差在均值里抵消）、在频率上失败（毛毛雨问题）、在强度上失败、并在第三个数字上把总量弄错，这就是为什么水文与影响评估（2010–2020年代的ETCCDI与强度分布诊断）必须在决策使用的统计量上做、绝不在图集地图上的年均值上做。
:::
:::

::: warning 评估的四种谬误
1. **"模式把1998年弄错了/把2023年弄错了，所以它是错的。"**单个年份、单个季节、单个事件住在内部变率之内；系综包络是受迫加内部实现的样本、不是日历的预测区间，而2023年事件的算术（一个记录年在十年均值噪声的2σ之内）是一般情形。对模式有效的批评是系统性的——共享的机制误差、有偏的趋势、缺失的物理——而无效的是抓包年份，评估科学一次除法就能回答。
2. **"模式一致，所以预测已成定论。"**系综的一致部分是调参的一致——成员共享代码、参数化、调参目标、有时还有同样的通量调整（2010–2020年代系谱文献、有效样本量校正），而2019–2021热模式事件证明一个自信的共识能携带一个共享的补偿误差。一致提升置信；只有独立的证据线——古气候、过程、观测、理论——才大幅提升它，这就是AR6按证据线、不按投票数分级的原因。
3. **"更好的评分意味着更好的预测。"**评分给当今态的复现排名；预测依赖反馈——导数——而2010–2020年代加权文献一贯的发现是：系综的技巧知情加权几乎不改变中心预测、不可预测地改变尾部，因为当今的技巧与明天的反馈技巧关系微弱（最好地复现季节循环的模式不是云反馈最好的模式，砧状云事件的结构教训）。用评分排除不可辩护的、不用来给可信的排名。
4. **"评估是一章、不是一种方法。"**该领域真正的失败是社会学的：评估数据集迁移进调参目标、省略调参历史的模式描述（CMIP6 2018–2021的透明度改进存在，正因为2000–2010年代是不透明的）、奖励新模拟胜过审计旧模拟的会议、以及2023–2025年发现十年的公众困惑源于从未解释系综是什么。评估是整个事业运行其上的方法，而其实践——留出数据、机制检验、复现、包含模式家族自身误差的公开误差预算——是气候预测与神谕权威之间唯一站立的东西。
:::

## 总结

::: summary
模式评估是气候科学整个的认识论交易，以三种语域进行：确认（离散化的方程被正确求解——基准、守恒、收敛）、验证（被求解的方程描述世界——偏差分解为机制、技巧在决策的变量上评分、从古世界到卫星时代的留出检验）、以及确证（成功向预测转移多少——靠跨独立证据线的三角验证管理，AR6置信机器、以及诚实的词汇因为"已证明"在结构上不可得）。仪表盘——平均态偏差、Taylor几何、三分量MSE分解、从天气验证借来的技巧评分——不可或缺而每一样都对某物失明，这就是为什么该领域成熟的实践是过程评估（检验那个正在做预测的机制）与涌现约束（把散布与观测相关以收窄目标），并以2012–2021年砧状云事件作为永久的方法论税：数据集稳健性、机制、有效样本量，否则它就不是约束。案例研究以四种语域教同一课——北极海冰（一个可定位的失败被转化为记录预测）、南大洋冷偏差（一道疤、系统性的后果）、砧状云约束（复现作为自我纠错）、以及2023年（包络不是预报，而说出这一点是评估科学的公共职责）。要拒绝的谬误：抓包年份、共识即真相、评分即预测、评估即一章。模式不是证据；评估是证据如何通过模式说话——而诚实地区行，带着公开的调参与留出的检验，它是前面二十课里任何东西值得相信的原因。
:::
