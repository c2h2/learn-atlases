箱模型是气候-地球系统模型的水管图：一小撮充分混合的隔室——大气、生物圈、表层海洋、深海、沉积物——由通量连接，每个盒子只遵守守恒：累积的必须是从外面流进来的。能量平衡模型理想化辐射，箱模型则理想化**环流与混合**，而描述一个CO₂分子在表层海洋十年的同样两行代数，也描述一个热距平在深海的千年、一种污染物从湖泊的清除、以及翻转温盐环流的淡水引擎。其数学内容是线性系统理论：盒子是耦合的一阶方程，其特征值是气候的**记忆时标**，其脉冲响应是1990年代以来每个碳循环仿真器都在拟合的格林函数，而其定态是平流与扩散通量之间的平衡，可以是多重的、带滞后的、并且在Stommel 1961年的盐引擎里——在同一片海洋的两个状态之间翻转。本课从分析单元向上建造这门手艺：储量与周转时间；四箱碳循环及其放射性碳校准；Revelle因子与海洋为何是块差海绵；Stommel的箱环流及其滞后；以及把1960年代箱模型与它们至今仍在检验的地球系统模型连接起来的脉冲响应机器。先修是[[earth-system/carbon-cycle]]一课的储量与[[climate-modelling/energy-balance-models]]一课的双层热模型——后者是一个戴着辐射帽子的箱模型。

::: definition 储量、通量、周转时间 {#def-reservoirs}
箱模型的原子有三种：**储量**（装着某种守恒示踪物若干量X的盒子，以克、摩尔或焦耳计）、**通量**（盒子之间的流，单位量/时间）、以及记账方程**dX/dt = Σin − Σout**。由此产出整个主题最有用的一个数字：**周转时间τ = X/Φ**，储量除以它的过流——定态下充分混合盒子里一个分子的平均年龄。碳循环是那张经典表（工业化前单位，Gt C）：大气590，光合作用与呼吸通量各约每年60（对生物圈τ约8年）、表层海洋1020，海气交换每年约74–90（τ约12年）、深海38,100，生物泵输出与混合每年约10（τ约几个千年）、沉积物与岩石圈以百万年计。把这张表背下来，你就拥有了气候的日历：每个盒子给出自己的时钟，而每个气候问题的可预测性由负责它的那个盒子设定——森林对政策的响应以十年计、海洋表层以十年计、深海与冰盖以世纪计。守恒记账的第二件工具是**空中分数**：排放中留在大气的部分，今天约45%，它是所有盒子通量的净结果，也是模型间比较的标准诊断量。箱模型的诚实条件写在明处：每个盒子内部充分混合（一个数字代表一切）、通量是线性的一阶转移（除非显式写出非线性，如碳酸盐化学）、边界是固定的（除非加上冰盖与沉积物这类慢盒子）。这些简化是换取可解性的代价，而本课的每个例子都在审计这个代价。
:::

::: definition 四箱碳循环及其放射性碳校准 {#def-fourbox}
主力箱模型耦合四个储量——大气、陆地生物圈、表层海洋、深海（外加一个沉积物箱管百万年的尾巴）——用一阶转移系数，而其现代形式**不是由碳本身、而是由其放射性孪生兄弟校准的**：放射性碳。化石燃料CO₂不带¹⁴C（50,000年里已衰变完），所以**Suess效应**——1850年代以来树轮、1980年代以来博物馆空气里测量的¹⁴C/¹²C稀释——独立揭示海洋与生物圈吸收了多少化石碳；而1955–1963大气试验的**核爆脉冲**，以示踪物计一夜之间让大气¹⁴C翻倍、此后一直在衰减，是史上最大的一次蓄意示踪实验，其大气e倍衰减时间（对表层海洋约16年，1990–2020年代把Suess与核爆数据综合成一个约每年74–84 Gt C的海气交换估计）是模型最大转移系数的直接测量。深海的更新——深层水的¹⁴C年龄约1,000–1,600年，从1970年代以来的GEOSHIP与GO-SHIP调查断面、以及1990–2020年代的放射性碳制图海洋学读出——设定了慢转移，而模型对一个化石脉冲的响应恰好分解成那些时标：十年（表层均衡）、十年到世纪（温跃层吸收）、千年（深海混合）、万年往上（碳酸盐化学与风化，深时一课的硅酸盐风化恒温器）。四箱模型的现代后裔是拟合到完整模型与观测的**脉冲响应函数**——1990年代至2001年Bern与Joos谱系碳循环模型的四指数形式（标准Archer时代参数化中的0.21 + 0.36e^(−t/400) + 0.28e^(−t/55) + 0.15e^(−t/6.4)，"公元12,000年仍有22%的排放悬在空气中"的结果让"CO₂是永恒的"成为定量陈述而不是口号）——以及校准到全球碳预算2020年代版本观测约束海洋吸收估计的2020年代后继者，其最慢的指数是诚实的承认：箱模型看不见最终将完成这项工作的碳酸盐化学。
:::

::: definition Revelle因子：海洋为何是块差海绵 {#def-revelle}
海洋碳循环中最有后果的数字不是通量而是比值。海水的溶解无机碳（约2,000 µmol/kg）被碳酸盐化学缓冲：添加的CO₂大部分转化为碳酸氢根，释放的氢离子抑制进一步溶解——现代表层海洋的**Revelle因子R = (ΔpCO₂/pCO₂)/(ΔDIC/DIC) ≈ 10–17**，意味着表层DIC上升1%需要大气CO₂上升10–17%才能把它压进去。这个数字1957年由Revelle与Suess在他们用一句话奠定了本领域谨慎传统的论文里发表——回应当年"海洋会收走我们的化石CO₂"的希望：海洋是"这种酸性气体的差溶剂"——而关于海洋实际取走了多少人为碳（2020年代全球碳预算海洋汇的约150–175 Gt C，约排放的四分之一）的每个计算都是R及其搭档气体交换速率的下游。Revelle因子是箱模型的非线性心脏：海气通量F = k·ΔpCO₂对分压差看似线性，但计入碳酸盐缓冲后ΔpCO₂对添加的碳是极硬的功能，所以**溶解度泵的效率随我们的使用而下降**——R随变暖上升（暖水溶碳更少、化学更硬），而海洋汇占排放的份额（在观测记录中稳定在约25–30%，表层海洋CO₂图集与GO-SHIP重复断面清单的2020年代综合）如果排放继续上升就必须作为分数下降。同样的缓冲算术解释了2020年代增强风化提案的**碱度杠杆**（加碱降低R、让同样的DIC在更低pCO₂下容纳更多碳）、冰期CO₂问题（为什么冰期海洋需要寒冷、高溶解度、营养盐重排的组合才能抽走100 ppm——[[palaeoclimate/deep-time]]课的最后一次冰期-间冰期摆动）、以及[[oceanography/ocean-chemistry]]一课的酸化，一石三鸟：海洋取走的CO₂正是让表层pH降低0.1单位的CO₂，缓冲只是消耗碱度的客气说法。
:::

::: definition Stommel箱模型：盐引擎与它的两片海洋 {#def-stommel}
Stommel 1961年的论文"具有不同流体两个储量的温盐对流"是两个盒子、四个参数、以及气候动力学最有后果的方程之一。两个盒子（高纬与低纬）以密度差驱动的输送ψ交换水——**ψ = α·Δρ**，Δρ由温度与盐度对比构建（密度随热下降、随盐上升）——而一个给定的淡水通量（蒸发减降水，一个数字的水循环）让一个盒子更咸，而流本身平流盐、闭合回路：**更多的流 → 更多盐被输入北方 → 更密的北方 → 更多的流**，一个正反馈，其盐度方程的定态**F·ΔS = 交换项**对一段淡水强迫承认**三个解**：一个强北沉状态（现代大西洋，北大西洋深水形成处）、一个弱或反向的南沉状态、以及中间一个不稳定状态。模型的演示——后来全部在远更复杂的机器中找到——：**同一强迫下的多重平衡**；**滞后**——把系统淡化过一个鞍结，环流崩溃，但恢复原来的淡水通量并不恢复它，没有第二次更大的推动崩溃不可逆；以及渐变强迫下的**瞬态过冲与"传送带减慢"**，GCM中1980–1990年代的灌水实验（1985年Manabe–Stouffer CO₂实验的大西洋变淡、2004年以来RAPID阵列与声称二十世纪减慢的指纹重建在2020年代被作为自然变率争论的1990–2020年代"观测记录中的AMOC减弱"之辩）全都继承自这两个盒子。2020年代的相关性是活的：AMOC早期预警文献（2010–2020年代的临界慢化统计、2023年Ditlevsen–Ditlevsen *Nature Communications*从大西洋海温指纹得出的世纪尺度崩溃风险主张及其2024–2025年统计反驳）在其机器的每个层面上都是一个穿着观测不确定性外衣的箱模型分岔——这恰恰是为什么箱模型，把假设摆在桌面上，仍是该领域关于*可能*发生什么的论证，而层级结构对*将*发生什么的判断谨慎得多。
:::

::: example 四箱碳循环：数字、时标、脉冲 {#ex-fourbox-numbers}
用标准的1990年代校准写出四箱碳模型（工业化前大气590 Gt C、到2020年代升到875；表层海洋1020；深海38,100；陆地生物610；海气交换每年约74–90 Gt C、以核爆¹⁴C校准；温跃层转移对1,000年箱每年约5；输出泵每年约10），运行它的三个标志性实验。**定态：**每个通量相抵，这张表是一张平衡的快照，而模型的第一美德是可读性——一个政策相关的预算（排放约10、空中约4.7、海洋约2.8、陆地约3.1 Gt C/年，全球碳预算2020年代数字在误差棒内闭合账簿）字面上就是模型的残差项。**Suess检验：**按历史排放曲线注入100%无¹⁴C的碳，大气Δ¹⁴C的稀释在交换系数取对之后于测量散布内匹配树轮与博物馆空气记录——模型在一个它未被拟合的同位素上得到验证，1990–2020年代用整个表层海洋CO₂图集做的同一练习。**脉冲：**在t = 0注入100 Gt C，看着定义里的四个指数衰减——十年少了三分之一（表层均衡）、一个世纪少了三分之二（温跃层）、一千年少了90%（深海混合）、然后是约20%那条长、平、诚实的尾巴，只有碳酸盐中和（[[biogeochemistry/carbon-deep-time]]一课溶解的方解石与风化、从古新世-始新世极热事件与2010–2020年代PETM碳酸盐清洗文献读出的100,000年恢复时钟）才会清除。每个学生都该做一次的练习，用电子表格或手算：把排放翻倍，看着空中分数随汇按Revelle因子的比例饱和而爬升——模型对"海洋能一直舀水吗"的回答是一个恰好在你需要它不变时变糟的数字，而它变糟是有原因的（化学、不是生物），任何通量调整都撤销不了。
:::

::: example Stommel的引擎求解：四个参数产出三片海洋 {#ex-stommel-solved}
一旦承认定态，两箱模型就是一个代数方程，而把它算出来是地球科学中最干净的多重平衡计算。令无量纲盐度对比s = (S_north − S_south)/(参照)、淡水强迫为f（北方蒸发超过降水，现代值为正）；盐守恒的定态写作**f·s = ψ(s)·(1 − s)**，而密度驱动的输送**ψ = a·s + b·T项**对s线性——一个关于s的三次方程。对现代的f，三次方程有三个实根：s ≈ 0.9（强北沉，盐被输入并被蒸发烧掉——今天的大西洋）、s ≈ 0.1（弱或反向）、以及一个中间的不稳定根；相图是教科书级的鞍结几何，而把f向上扫（按2020年代格陵兰与变暖预测的速率加融水或降水）让稳定根走向不稳定根直到两者湮灭、环流在一个有限阈值处**跳变**到弱状态——而把f往下扫回来，弱状态一直保持到低得多的f：滞后环，用铅笔画出来。这个玩具教给严肃模型的定量教训：崩溃是**快的**（几十年，跳变自己的时标）而其逼近是慢的（临界慢化——早期预警信号的物理基础）；恢复需要的强迫比崩溃需要的温和得多（2020年代"如果我们停止变暖AMOC会反弹吗"文献的中心不对称，也是"我们以后能修好它"不是代数所说的原因）；而真实海洋的额外盒子——南大洋竞争的盐引擎、太平洋多雨的几何（太平洋为什么没有现代深水形成：它的淡水强迫坐在同一个分岔的错误一边，2010–2020年代古太平洋通道与海道关闭文献关于大西洋翻转为何是地质上新近且地理上偶然安排论证）——让三次方程复杂化但没把它移除。当2023年Ditlevsen警告主张与其2024–2025年反驳争论大西洋海温指纹是否包含鞍结的逼近时，双方在底层引用的都是Stommel的两个盒子——这就是1961年一个四参数模型至今仍是关于海洋接下来能做什么被引用最多的陈述的方式。
:::

::: example 气候的记忆：特征值、格林函数、以及箱模型记得什么 {#ex-memory}
任何线性箱模型都是一个矩阵，而矩阵的特征值就是气候的记忆。双层热模型（表面箱、海洋箱）有两个特征值——约十年的模式与约世纪的模式——而其阶跃响应是两个指数之和；四箱碳模型有四个；1990年代海洋-碳文献的八箱模型有八个；而完整的地球系统模型，其"盒子"数以十万计，特征值谱稠密到功能上连续——这正是脉冲响应技巧可行的原因：**对模型的脉冲响应拟合几个指数，你就在拟合分辨率内重现了它的线性行为**（1990年代至2009年Hall–Archer与Joos谱系的碳脉冲响应函数、2000–2020年代把任何强迫历史在毫秒内变成温度轨迹的海洋热含量格林函数方法、支撑大多数快速模式不确定性分析的"阶跃响应仿真"学派）。三个值得内化的推论。**记忆不是一个数字：**大气对火山强迫"记得"约2年（皮纳图博的恢复）、表层海洋十年、温跃层一个世纪、深海一千年——所以同一个系统对不同问题表现出不同的可预测性时距，特征值谱就是十年预报瞄准海洋模式、百年预测瞄准辐射模式的原因。**叠加是许可证也是极限：**线性箱模型让你把任何排放路径分解成脉冲并求和其响应（[[climate-change/emissions-budgets]]一课每个碳预算剩余碳数字背后的计算），但许可证死在物理非线性之处——高DIC下的碳酸盐饱和度、环流翻转、冰盖阈值——而2020年代"碳循环会加速它造成的变暖吗"的问题（[[biogeochemistry/carbon-today]]一课的永久冻土与火反馈）恰恰是关于叠加在哪里失效的问题。**最慢的特征值是一台承诺机器：**1.5 °C目标意味着多世纪海平面上升的原因、2050年代净零承诺买到以世纪计的气候收益的原因，是系统最慢的盒子——深海、冰盖、沉积物——按自己的时钟积分今天的通量，而没有排放路径能跑赢一个特征值。
:::

::: example 示踪箱：从Broecker的砖块到冰期碳地图 {#ex-tracer-boxes}
箱模型第二个较少被宣扬的成功是它们**是从数据反向建造的**：不是预测示踪物、而是把它们反演成环流。Broecker 1974–1982年的"砖块"模型——海洋作为一小撮带平流与扩散输送的盒子，拟合到¹⁴C、δ¹³C与营养盐三件套的分布——确立了整个调查计划至今使用的定量词汇：水团的**放射性碳年龄**作为其更新时钟（深太平洋对大西洋约2,000年的¹⁴C亏损，指出传送带在下沉与停滞在哪里的不对称，从1990–2020年代组装的GLODAP与GO-SHIP碳酸盐系统清单读出）、**预成营养盐与δ¹³C**签名作为生物泵强度、以及关键洞见：冰期海洋把它的额外碳储存在**深海与南大洋**、不是表层——从Broecker的营养盐捕获假说经过TAPE与MAP项目的海盆尺度同位素调查（2020年代冰期亚北极与南大洋岩芯综合）到箱模型互比显示更新年龄变化与铁限制输出各解释100 ppm一部分的1980–2010年代链条。同样的反演逻辑以更细的粒度贯穿现代示踪海洋学——1990年代以来氟氯烃与SF₆的输运时间分布（TTD），它们是箱模型的连续极限，一整个年龄谱代替四个盒子、在水中直接测量——以及最新的箱模型：2020年代的**碳循环反问题**，其中大气¹⁴CO₂与O₂/N₂观测（1990年代以来的Scripps与全球监测实验室计划）分开约束陆地与海洋吸收，盒子的通量是被求解、不是被规定。该方法对整个层级的一课：箱模型在示踪物的源与汇已知、混合被粗粒化的地方可信，而其最诚实的用法一直是**诊断性**的——说出观测关于环流已经意味着什么——而不是预测性的。
:::

::: history 储量：从Volterra的湖到冰期海洋 {#hist-boxes}
**1926–1957**：Volterra的捕食-猎物箱（1926）让隔室动力学成为一个数学对象；放射性碳的发现（Libby，1946–1949）给了碳循环它的示踪物，而Suess效应（1953–1955）与Revelle–Suess论文（1957）——海洋作为"差溶剂"——找到了箱模型的中心数字。**1961–1974**：Stommel的两箱盐引擎（1961）与Manabe–Stommel环流模型（1968）把多重平衡带进海洋动力学；Broecker、Peng等1970年代初的示踪箱（1974年*Science*"化学与现代海洋"谱系）把箱子翻过来从同位素读环流；第一批碳循环箱模型进入1970年代评估的CO₂不确定性辩论（1971–1977年Studer与1975年Oeschger–Siegenthaler的Bern气候-碳箱首次在一个可解系统里连接温度与CO₂反馈）。**1985–2001**：GCM中的灌水实验证实了箱子的翻转（1985年Manabe–Stouffer CO₂运行、1990年代THC崩溃恐慌及其安静的修订）；Bern与汉堡的脉冲响应碳模型成熟（1992–2001年Joos–Fung–Machidt线与MAGICC耦合），而核爆¹⁴C综合（1990–2000年代海气交换共识）校准了账本里最大的通量。**2009–2025**：Archer与Hall的四指数"CO₂是永恒的"结果（2009）让慢特征值成为公共知识；RAPID阵列（2004–）与AMOC减弱之辩（2019–2025，2023年Ditlevsen警告与其反驳）把箱模型分岔搬上世界上仪器最密的海洋；MAP与亚北极同位素综合（2017–2023）交付了箱子预测的冰期碳地图；而2020年代机器学习仿真器开始了最后的迁移——箱模型的角色被吸收进学习到的代理，而它们的特征值仍是每个代理必须重现的骨架。
:::

## 检验你的理解

::: quiz {#quiz-revelle}
Revelle因子上升意味着海洋碳汇：

- [ ] 增强，因为更陡的化学梯度移动更多气体
- [x] 吸收排放中下降的份额，因为每增加一摩尔碳抬升表层pCO₂比上一摩尔更多
- [ ] 不受影响，因为气体交换只依赖风速
- [ ] 在pCO₂越过450 ppm后突然饱和

::: solution :::
Revelle因子是碳酸盐缓冲的硬度：通量依赖pCO₂的*差*，而随着DIC上升，每一分添加的碳不成比例地抬升pCO₂（R ≈ 10–17且随变暖上升），所以对给定的大气上升，海洋的吸收份额下降——汇的份额在当前记录中保持在约25–30%附近但在预测中走低，一个是化学、不是生物、因此无法适应的正碳循环反馈。
:::
:::

::: quiz {#quiz-hysteresis-amoc}
如果大西洋翻转环流被淡水强迫压垮，Stommel型动力学预测恢复将需要：

- [ ] 仅仅移除淡水——系统沿原路返回
- [x] 比原始状态更有利的强迫，因为崩溃状态本身是稳定的（滞后）
- [ ] 什么都不需要：恢复在百年时间尺度上自动发生
- [ ] 只需改变风应力型

::: solution :::
三次方程的稳定分支在强迫上不重叠：崩溃发生在一个鞍结，恢复发生在另一个更温和的鞍结，所以在两者之间，崩溃的海洋是"正常"强迫唯一的稳定答案——系统对自己崩溃的记忆。这是每个严肃"AMOC可逆吗"分析（2020年代完整GCM中的滞后结果、古新世式的"传送带重启"文献）的玩具模型内核，也是"我们以后会逆转它"不是动力学所提供的原因。
:::
:::

## 练习题

::: exercise {level=1 check="12"}
**周转时间。**表层海洋溶解无机碳储量为1,020 Gt C，平均海气交换通量为85 Gt C/年。周转时间是多少年？
::: solution :::
τ = 1020/85 = **12年**——表层海洋以十年时钟与大气互换其碳，这就是Suess与核爆¹⁴C信号在那里存活数十年的原因，也是决定脉冲长期命运的深海一千年、不是这个数字的原因。
:::
:::

::: exercise {level=1 check="3600"}
**深海更新。**深海碳储量为38,100 Gt C，输出通量再矿化与混合输入之和约10.6 Gt C/年。深储量的周转时间是多少年？
::: solution :::
τ = 38,100/10.6 = **3600年**——比经典的1,000年教科书数字长一个数量级，因为现代估计只数交换最慢的一肢；练习真正的教训是"周转时间"是关于*你在除以哪个通量*的陈述，而碳循环文献的数字之争（1980–2020年代更新年龄对核示踪的调和）争的正是这个。
:::
:::

::: exercise {level=1 check="0.37"}
**一阶衰减。**一个周转时间为τ的盒子被瞬时扰动。一个τ后还剩多少比例的扰动（充分混合、线性）？
::: solution :::
exp(−1) = **0.37**——τ的一行含义：走了63%、剩37%，而因为碳与热模型是这样的指数之和，本课每条脉冲响应曲线都是按不同时钟读出的一句句"一个τ"陈述的堆叠。
:::
:::

::: exercise {level=2 check="13.9"}
**清除半个脉冲。**大气对脉冲的超额份额按0.2 + 0.8·exp(−t/20)演化（t以十年计）。多少个十年后超额少了一半？
::: solution :::
0.2 + 0.8e^(−t/20) = 0.6 → e^(−t/20) = 0.5 → t = 20 ln 2 = **13.9个十年**——注意玩具设下的陷阱：曲线永不归零（0.2的地板是最慢的盒子），所以"少一半"定义良好而"没了"永远不是；每个排放路径模型的长尾假设都是关于那个地板大小的争吵。
:::
:::

::: exercise {level=2 check="240"}
**Revelle算术。**表层DIC为2,000 µmol/kg，pCO₂ 400 µatm，Revelle因子12。要把表层pCO₂提高10%，必须加入多少DIC（µmol/kg）？
::: solution :::
ΔpCO₂/pCO₂ = R·ΔDIC/DIC → 0.10 = 12 × ΔDIC/2000 → ΔDIC = 0.10 × 2000/12 = **240 µmol/kg**——DIC增加12%换来pCO₂增加10%：缓冲在花费它的本金，同一个算术把海洋150 Gt C的人为吸收变成0.1单位的pH下降、也让增碱提案（降低R）成为碳捕集化学优先的孪生兄弟。
:::
:::

::: exercise {level=2 check="10"}
**Stommel的引擎。**在ψ = γ·(βΔS − αΔT)中，取γ = 每单位密度距平500 Sv，βΔS = 3.0 × 10⁻³，αΔT = 1.0 × 10⁻³（北更暖也更咸）。输送ψ是多少Sv？
::: solution :::
Δρ = (3.0 − 1.0) × 10⁻³ = 2.0 × 10⁻³；ψ = 500 × 2.0 × 10⁻³ = **1.0 Sv**——现代大西洋翻转环流的强度（RAPID阵列约18 Sv的总量，其中深水肢占几Sv）从两个符号相反的密度项中浮现，练习的要点：盐与热互相拉扯，环流是残差——这就是为什么淡水（盐的货币）是能掀翻引擎的杠杆、而变暖（热的）大多只是让它变慢。
:::
:::

::: exercise {level=3 check="0.54"}
**四指数拟合。**用脉冲响应0.21 + 0.36e^(−t/400) + 0.28e^(−t/55) + 0.15e^(−t/6.4)（t以年计），一个脉冲100年后还有多少比例悬在空气中？
::: solution :::
0.21 + 0.36 × e^(−0.25) + 0.28 × e^(−1.82) + 0.15 × e^(−15.6) = 0.21 + 0.28 + 0.045 + 0.000 = **0.54**——空中分数不是常数而是一条曲线：头几十年少了约一半，第100年仍有54%在空中，约21%永远在空中，这就是"汇吸收我们一半排放"对过去为真、对你叫得出名字的任何未来为假的原因。
:::
:::

::: exercise {level=3 check="5.3"}
**串联的两个时钟。**表层核爆¹⁴C超额被向温跃层混合（e倍时间8年）与同生物圈的大气交换（16年）同时移除。合并的e倍时间是多少年？
::: solution :::
速率相加：1/τ = 1/8 + 1/16 = 3/16 → τ = 16/3 = **5.3年**（仅表层）；观测的大气核爆¹⁴C下降更慢（约16年），因为*大气*看到的是生物圈与表层海洋在一个耦合网络里、不是一个盒子——练习是经典演示：在线性箱模型里串联与并联有电导相加规则，而不点名盒子就引用"那个"核爆¹⁴C时标是1990年代文献犯过两次的范畴错误。
:::
:::

::: exercise {level=3 check="0.2"}
**来自缓冲的空中分数。**在平衡态，添加的碳在大气与海洋+陆地合并缓冲之间分配，缓冲每容纳空气里1个单位的4个单位（线性机制分配系数K = 4）。平衡时一个脉冲有多少比例在空中？
::: solution :::
空中分数 = 1/(1 + K) = **0.2**——四指数地板的平衡版本，从箱模型定态一行可推导，也是每个"陆地与海洋终将缓慢地持有我们约80%的排放"陈述背后的数字；今天约45%的空中分数与这个20%终点之间世纪尺度的差距*就是*承诺问题，一个特征值的耐心以海平面计价。
:::
:::

::: warning 箱模型误导的四种方式
1. **"充分混合"是一个主张、不是一个假设。**每个盒子的单一浓度是模型为了可解而说的谎——对表层海洋数年的核爆示踪大致为真、对冰期海洋的碳为假、在边界流与涡旋干实际更新工作的地方致命地为假。诊断工具就是示踪物本身：如果第二个独立示踪物（¹⁴C对CFC对营养盐）与箱结构不符，箱子就是错的，而1990–2020年代示踪调查文献在很大程度上正是那些修正的目录。
2. **周转时间不是预测。**τ = X/Φ是关于定态的算术；真实通量随扰动共变（翻倍时的汇通量不是今天的通量——又是Revelle因子），所以把τ引作"响应时间"悄悄假设了系统保持线性，而有趣的问题（汇饱和、环流翻转、碳酸盐崩溃）恰恰是非线性的。
3. **多重平衡不是崩溃的预报。**Stommel模型证明海洋*能*有第二个状态；真实AMOC是否接近其阈值是另一个难得多的问题（2023–2025预警信号之争显示观测证据有多薄），而模型喂养的1990年代"本世纪THC崩溃"恐慌被箱子恰好缺少的复杂性——南大洋动力学、三维几何、真实噪声——向下修订。存在性定理只当观测补上句子的后半部分时才配得上头条。
4. **对一个数据集校准就继承了它的谎。**四箱模型来自核爆¹⁴C的海气通量是可靠的，因为¹⁴C与碳化学上全同；而对*风速*参数化的校准（1980–2020年代气体交换社区的Schmidt数活塞速度，其2010–2020年代高风速抑制之辩把海洋汇移动了每年数十Gt C）继承了每一个气泡与油膜假设。箱模型只和它的转移系数一样好，而它的系数只和它们藏起来的物理一样好。
:::

## 总结

::: summary
箱模型是气候科学的记账：储量、通量与守恒，从中落下组织系统里每个时标的周转时间表（生物圈的十年、表层海洋的十几年、深海的一千年、风化的百个千年）、让"CO₂是永恒的"定量化四指数脉冲响应、以及Revelle因子——化学对海洋慷慨的否决权，1957年首次测量，至今仍在决定每条排放路径的代价。它们的特征值是气候的记忆，它们的格林函数是每个评估报告内部的快速仿真器，而它们的非线性心脏是Stommel的两个盒子：盐引擎，其三次方程承认两片海洋与一个滞后环，是每个AMOC警告与每句关于不可逆性的诚实陈述的祖先。它们在假装混合的地方误导（充分混合的盒子、恒定的τ、越过饱和的线性叠加），而在那些谎可审计的地方仍是不可或缺的——示踪反演、预算闭合、分岔几何、以及用一行算术拿守恒检验百万核时模型的用法。梯队的道德再次出现：箱模型不是粗糙的GCM，而是精确仪器，用于那些只有把假设摆在明处的模型才能回答的问题——记忆、分配、承诺、阈值。
:::
