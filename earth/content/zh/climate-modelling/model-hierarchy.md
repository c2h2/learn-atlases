气候模型是用一种无法含糊的语言写下的假说：给定这些方程、这些参数、这个网格与这些边界条件，气候就*这样*。但并不存在一个单一的"气候模型"——存在的是一个**层级**，从一张纸就能解出的一行能量平衡，到每个模拟世纪要跑几百万处理器小时的地球系统模式，而本课程的核心技能是知道哪一级回答哪个问题。层级存在，是因为一条残酷的缩放律：分辨大气与海洋的计算机成本随每次分辨率翻倍大约增长十六次方，所以包罗万象的模式对除少数实验之外的所有问题永远太贵，而廉价模式不是辅助轮、是昂贵模式的解释仪器。本课为整门课设定词汇：模型是什么、能是什么（没有模型能被确认，所有模型都能被证伪，大多数是*调参的*），组织该领域的分辨率-成本-复杂度权衡，初值预报与边界条件预测之分——它决定"预报到2100年"能是什么意思——以及不同层级所服务的认识论分工：解释、归因、预测、探索。先修是[[climate-system/feedbacks-sensitivity]]一课；回报写在课程标语里：一个你亲手写过并弄坏过一次的模型，关于不确定性教给你的比一百页描述更多。

## 理想化的阶梯

::: definition 模式层级：从一行到一个行星 {#def-hierarchy}
气候模式按理想化的阶梯组织，每一级保留它需要的物理、丢弃其余。底部坐着**能量平衡模型**——全球平均温度作为一个数字，或一个带热扩散与冰-反照率反馈的一维纬度柱（1960–70年代的Budyko–Sellers类，几秒可解，至今仍是分岔分析与雪球地球问题的标准工具）。其上是**箱模型**：几个充分混合的体积交换热、碳与盐（Stommel 1961年带多重平衡的双箱温盐模型、每个"空中分数"讨论背后的四箱碳模型）。然后是**辐射-对流柱**（Manabe与Wetherald 1967年的模型，一个垂直维度，第一个显示水汽与直减率反馈起作用、并且至今仍是辐射强迫计算的主力）、**通用环流模式（GCM）**——纯大气、纯海洋、然后耦合——在三维网格上求解旋转分层流体方程、网格下物理被参数化，以及顶部的**地球系统模式（ESM）**，添加交互式碳循环、化学、气溶胶、动态植被、冰盖与生物地球化学（2020年代运行的标准CMIP6配置是每个参与建模组每个实验2,000–5,000模式年的耦合积分）。在这些级之间与旁边住着中间复杂度模式——区域气候模式、像CLIMBER与MIT模型那样跑冰期旋回的中间复杂度地球系统模式（EMIC）、以及干脆扔掉对流参数化的对流许可模式。这个阶梯不是*质量*的阶梯、而是**可负担性与可解释性**的阶梯：一个10公里耦合周花的钱等于一个100公里世纪，而领域的方法是在各级之间弹跳——在简单模式里发现什么要紧、在复杂模式里确认它、并且只在简单模式能解释结果为何如此的地方使用复杂模式的输出。
:::

::: definition 分辨率、成本、以及包罗万象的模式为何永远太贵 {#def-resolution}
层级是被湍流强制的。大气与海洋把能量从强迫的尺度级联到耗散尺度，横跨四到六个数量级，而网格必须分辨那些尺度分离要紧的能量级涡旋：自由大气大约50–100公里（大尺度动力学是准地转的、危险的尺度是行星尺），而海洋约10–20公里，因为第一斜压Rossby半径——旋转控制涡旋的尺度——在中纬度缩到10–20公里、在热带不足5公里，所以涡旋许可（1/4°）海洋模式仍然把西边界热输送弄错、只有2010年代末–2020年代涡旋分辨（"公里级"）一代（DYCOMS与HiResASM/DYAMOND互比、2020年代DYAMOND与TWINS对全球湍流海洋的模拟）才现实地捕获观测的涡动能与深水形成。分辨率的成本是复利的：网格距减半让网格点乘以8（水平两个、垂直一个）、稳定步长随之减半（下一课的CFL条件），每次翻倍带来**十六倍**的算力增长——而那个会打破步长锁的完全隐式"全尺度"梦想在每个模式中心都被争夺。后果是该领域的经济学：一个100公里耦合世纪约花10⁵核时，一个10公里的约10⁹，所以包罗万象的模式负担得起几次运行、而问题（不确定性、系综、碳循环探索）要几千次——2020年代仿真器与机器学习替代物攻击的就是这个缺口，而Levins 1966年的权衡三角（一个模式能最大化真实、通用或精确，不能全都要）早已宣布它不可避免。诚实的总结是Stevens与Schär及对流许可共同体2019年的表述：吉米尺度的世界现在可算的是周、不是世纪——层级会被摩尔定律的后继者与百亿亿次机器重组，但还没到。
:::

::: definition 预报对预测：初值与边界条件 {#def-projection}
天气预报与气候预测是穿同一套方程的两道不同数学题。**预报**是一个初值问题：大气状态被观测（不完美的）、向前积分、而当最小的误差长到流的尺度时它的有效生命就结束了——中纬度1–2周（Lorenz 1963年发现有限可预报性、2002–2020年代记录技巧每十年延长约一天的文献、以及2023–2025年GraphCast与盘古天气等机器学习预报员以最佳物理系统的技巧登场）。**预测**是一个边界条件问题：把模式跑到其统计平衡、或跑一个个成员毫无意义但均值与方差即气候的系综，然后问CO₂倍增时那个分布如何移动；初始状态在几年里被遗忘、情景接管。2007年Brankovic–Row与Hawkins–Sutton的澄清区分了"气候的预报"（十年的、初始化的、部分可预报因为海洋的记忆慢）与"气候变化的预测"（情景驱动）：它们回答不同的问题、带着不同的误差预算。整门课赖以运转的实用区分：预测**不是预报**（没人能排放路径——情景是有条件的，"若RCP8.5则X"）；十年预报对北大西洋翻转环流与2010–2020年代全球平均温度趋势可以合法地有技巧（CMIP5与CMIP6的十年预测实验、以及2010年代Mohn 1890年代欧洲增暖预报的复兴），而对某个具体的欧洲冬季无望；而预测的方差可分解——在可加性下干净地——为内部变率（可用系综缩减）、模式不确定性（可用更好的模式缓慢缩减）与情景不确定性（不可缩减，未来的一个属性），其相对份额随时间与变量移动（2009年Hawkins–Sutton的框架：对2100年温度情景主导；对2030年降水模式与噪声主导）。
:::

::: definition 模型能与不能：调参、证伪、可信度 {#def-epistemology}
没有气候模式能被**确认**——它所预测的实验（SSP5-8.7下的2080年代）不会被运行——所以该领域的认识论标准比"模式说对了"更弱也更谨慎。工作哲学是一个三部分纪律。**调参**：无法从第一性原理导出的自由参数（云量、夹卷率、拖曳系数）被设定为使模式复现一组选定的可观测量——CERES时代（2000年起）的辐射收支、季节循环、历史增暖趋势——而每个调参目标都是一个关于模式将按构造做对哪些东西的承诺；本课程的评估章节很大程度上是在模式*没有*被调参去拟合的东西上测试模式的艺术。**证伪而不抛弃**：当一个模式在某项观测上失败（CMIP3时代对北极海冰下降的低估让2007年的记录成为真正的意外、在四十年模式开发中幸存的冷偏差双ITCZ问题、CMIP6 2019年若干模式的平衡敏感度坐在历史记录约束之上的发现），回应不是丢弃模式、而是把失败定位到一个过程、一个参数化、一个分辨率——层级的诊断功能。**三角验证赢得可信度**：Oreskes等1994–2001年的论证——模式像侦探那样赢得信任，不靠任何单一检验，而靠许多预测对许多观测的一致性、驳倒其企图的失败之幸存、以及结果跨模式家族的稳健（不同的代码里同样的物理、不同层级里同样的反馈）。这就是为什么评估进程（IPCC AR6 2021的置信语言）按*证据线*——古气候、历史记录、理论、涌现约束、多模式一致——而不是按模式权威给陈述分级，也是为什么本课程反复出现的座右铭是C. C. Moore的：模式不是证据，模式是证据的解读者。这门学科的失败模式同样有教益——1970年代"算出一个新冰期"的过度自信提案被气溶胶与海洋物理的现实证伪、1990年代靠调参而非理解缩小的模式散布（2020年代"结构不确定性"文献的核心告诫）——而这门学科唯一真正的胜利，1979年Charney报告的3 ± 1.5 °C历经四十年模式代际几乎原封不动地幸存，就是接下来三个定义要展开的案例研究。
:::

::: example 一个数字、五级："每倍增3 °C"从哪里来 {#ex-ecs-rungs}
平衡气候敏感度——CO₂倍增、一切慢的东西都调整完毕后的全球平均增暖——是该领域的旗舰数字、也是层级作为一个系统运转的最干净演示。**第1级，纸笔：**无反馈的普朗克响应（对σT⁴求导）给出288 K/4 ≈ 每e倍30 K，或者当3.7 W/m²的强迫除以约3.3 W m⁻² K⁻¹的普朗克参数后每倍增约1.2 °C——每个学生都做的那道练习、以及"3 °C"意味着反馈把裸答案翻了三倍的原因。**第2级，辐射-对流柱：**Manabe与Wetherald 1967年的模式（固定相对湿度、规定50%云量）在水汽与直减率反馈活着的状态下算出2.9 °C——离2021年AR6 3 °C的最佳估计一步之遥，早五十四年、只用一个垂直维度。**第3级，过程综合：**[[climate-system/feedbacks-sensitivity]]一课的反馈算术——水汽、直减率、表面反照率、以及仍然淹没总和的云项——给出2012与2020年评估的±0.5 °C专家范围（IPCC AR6的2–5 °C"很可能"与国家科学院2019年报告的2.5–4 °C）。**第4级，GCM与ESM：**CMIP系综的平衡敏感度（CMIP5范围2.1–4.7 °C、CMIP6的1.8–5.7 °C，其上尾部引发了2019–2020年与历史记录的当面对质）供给分布的形状与失败模式——东南层积云上跑得热的模式的低云反馈。**第5级，观测与古气候：**涌现约束纲领（2012年Brient等的热带砧状云约束、2020年Sherwood等的*Nature*综述把过程知识、历史数据与末次盛冰期折进2.3–4.5 °C的可信范围）以及排除两条尾部的古气候CO₂当量论证。没有哪个单一模式产出这个数字；数字是层级的一致*意味着*什么，而关于云的分歧恰是同一层级把剩余工作集中起来的地方。
:::

::: example 率先正确的廉价模式：Budyko、Stommel、Manabe–Wetherald {#ex-cheap-models}
1960–70年代三篇二页纸的论文，比任何超算运行都更好地讲授层级的价值。**Budyko 1969年的冰-反照率模型**（独立地，Sellers 1973年的版本）把全球温度放进一个方程——带状态依赖反照率的吸收阳光对抗线性化的向外辐射、跨纬度扩散——并产出第一个定量的**多重平衡**：CO₂减半或日照温和变化时，一个完全被冰覆盖的地球成为唯一稳定状态，而无冰与雪球之间的转变是滞后的。这个预测活得比作者本人的怀疑更长（1990–2000年代雪球地球的地质证据、2010年代不得不援引比简单模型暗示的更低CO₂阈值的古气候模拟），而同一条分岔几何现在为从亚马逊到AMOC的每个翻转点讨论定框。**Stommel 1961年的双箱盐引擎**——两个箱子、一个规定的淡水通量、密度驱动的交换——显示温盐环流能有**两个稳定状态**（北沉、南沉）、能被一个越过阈值的淡水脉冲翻转，此后每个"淡水灌水"滞后实验背后的机制、也是AMOC 2020年代预警信号文献（van Westen的临界慢化统计与Ditlevsen姐妹2023年*Nature Communications*的早期预警主张、在2024–2025年统计方法辩论中有争议）根本被框成箱模型几何的原因。**Manabe与Wetherald 1967年的柱**——一个垂直维度、对流调整、固定相对湿度——找到每CO₂倍增2.9 °C、认定水汽是放大反馈、直减率是刹车、五十多年来被重跑、升级、引用而核心数字没怎么动。三者共享的教训：廉价模式不是昂贵模式的近似，它们是**带参数的定理**——证明一种行为仅凭陈述的机制就可能——而这正是昂贵模式随后为之检验现实性的东西。
:::

::: example 气候对、天气错：GCM的日输出是什么与不是什么 {#ex-weather-climate}
2018年，天气预报界对气候模式的嘲讽（"它们连明天都报不对"）遇到了它的干净回答，而值得能够用一段话给出。一个自由运行的通用环流模式漂进它自己的天气：两周后其大气状态与现实的相关性不比一副洗过的牌多，而没有诚实的建模者为任何一场模拟的风暴、季风爆发或欧洲之夏主张技巧。模式主张的——以及被检验的——是**统计量**：日温度分布、热极端的频率、风暴路径的位置与强度、ITCZ的季节循环、ENSO的方差，它们跨数千个独立模式日的复现是一个关于气候系统吸引子的、可证伪的、了不起的陈述、不是关于其轨迹的。2010–2020年代量化了这个分裂：模式的"天气"错误（日方差偏差、MJO的表达、双ITCZ的几何）恰是模式分歧最大的场，而受迫的气候信号——历史系综的年平均增暖型、热带放大、海冰流失的北极放大——跨系综稳健，即使个别成员的天气是错的（[[climate-change/projections]]一课的"信噪"框架）。有教益的失败是那个成功故事：CMIP3模式在2000年代系统性地**低估**了观测的北极海冰下降——冰太多、夏天太稳定——而2007年的极小值作为一个真正的意外到来；事后分析（2018年Stroeve–Notz的记录预测分析显示系综均值的偏差、以及观测轨迹跟踪系综中更陡的成员）既让层级难堪又演示了它的诚实：模式以一种可定位的方式错了——更薄的冰动力学、融池参数化、海洋热吸收——而修正后的CMIP6一代如今把观测括在中间。天气错、气候对，而当气候错时，错得有原因：这就是合同。
:::

::: example 2020年代重排阶梯：公里级模式与机器学习替代物 {#ex-ai-km}
2020年代的两种技术看起来要废除层级，细看之下是重新分配它。**对流许可与公里级模拟**：英国1.5公里的UKCP18夏季对流运行（2015–2019）、CMIP6 HighResMIP十年（2017–2025）、以及DYAMOND与TWINS项目全球约10公里海洋与约1–3公里大气从周到季的季节模拟（2019–2024）显示了阶梯顶级买到什么：日循环降水相位被修好、Madden–Julian振荡的组织化被锐化、海洋热输送锋面与深水属性大幅接近世界海洋图集——而关键的是，公里级运行的*气候敏感度*与其100公里祖先并无戏剧性差异，因为全球能量收支不在缺失物理所在之处（2024–2025年高分辨率云分辨研究发现的2020年代层积云瓦解，确实发现了大的云反馈变化，正是对过度推广那一结论的告诫）。**机器学习**：GraphCast（DeepMind，2023）、盘古天气及其后继者（2023–2025）在再分析上训练，现在在约7天以内的预见期以一小部分算力追平或超过基于物理的数值天气预报，而到2024–2025年，首批ML气候仿真器——对流与辐射的神经参数化、完整模式层级的学习替代物——正在GCM内部测试。层级吸收了两者，一如它吸收过一切：ML预报员是初值机器——在观测大气上训练、分布外不可信、不保证守恒能量或水——所以它们加速系综与探索，但本身不许可一个2100年的预测；而公里级物理仍然需要廉价模式来说明答案*为什么*变了。阶梯的下一个配置，在2025年的地平线上可见：ML替代物做千成员的采样、基于物理的公里模式做过程真相、而纸笔各级做它们一直在做的事——决定另外两者中哪些被允许相信。
:::

::: history 一个世纪的计算气候 {#hist-hierarchy}
**1904–1922**：Vilhelm Bjerknes提出天气是一个可通过积分求解的初值问题，而Lewis Fry Richardson的《用数值过程做天气预报》（1922）手工积分了一个六小时步——错了一个大风暴的量级、但方向是对的——并想象出那个电子计算机将在一个下午取代的六万四千人"预报工厂"。**1943–1956**：让Richardson变对的竞赛——Rossby的卑尔根与芝加哥学派、Charney 1947年让步长活下来的声波准地转过滤、Fjørtoft关于分辨率意味着什么的级联分析、以及Phillips 1956年在普林斯顿从方程产出急流的通用环流积分。**1961–1975**：层级成形——Manabe与Wetherald 1967年的辐射-对流模型、Smagorinsky 1963年的湍流闭合与1966–1969年的GCM实验、Manabe与Bryan 1969年的海洋-大气耦合模型、Budyko与Sellers的能量平衡分岔、Stommel的箱模型——而1975年首个美国国家科学院评估（Charney报告1979年跟进）固定了3 ± 1.5 °C。**1975–1995**：耦合与验证——1980年代的海冰与陆面方案、大气模式互比计划（1989年的AMIP协议）把模式*评估*发明为一种方法、1990年代耦合模式复现（并放错）ITCZ、而IPCC评估成为层级的制度性消费者。**1995–2014**：系综时代——HadCM3与ECHAM的多世纪运行、2001–2013年CMIP3与CMIP5架构、2009–2014年方差分解文献（Hawkins–Sutton框架）、2013年古气候模式互比计划对模式最大外推的末次盛冰期检验、以及让模式散布地图与地图本身一样标准的2014年CMIP5图集。**2014–2025**：地球系统与百亿亿次时代——CMIP6的DECK协议与1.8–5.7 °C的敏感度意外（2017–2019）、AR6证据层级评估（2021）、2021年COP26"有限过冲的1.5 °C"特别报告建模链、公里级DYAMOND/TWINS模拟（2019–2024）、以及机器学习预报员（2023）的到来重开了Richardson最初的问题——计算究竟是干什么的？——以行星的尺度。
:::

## 检验你的理解

::: quiz {#quiz-ivbvp}
为什么一个十年预报系统能对2020年代的全球平均温度有技巧、却无法预报下一个冬天？

- [ ] 因为海洋模式比大气模式更精确
- [x] 因为慢的海洋与冰模态在十年尺度上演化、其初始状态被观测到，而大气天气在几周里失去记忆
- [ ] 因为十年运行使用更小的步长
- [ ] 因为温室气体浓度阻尼了大气的混沌

::: solution :::
初值问题的可预报时距由最快的误差增长设定——大气斜压混沌，约2周。但气候系统还包含慢的、被观测的模态（温跃层热含量、北大西洋盐度、海冰状态），其5–10年的演化部分由初始条件决定；初始化它们为全球平均温度趋势、特别是大西洋扇区买到技巧，而个别冬季留在噪声里。边界条件预测用同样的模式、采取相反的策略：忘记初始状态、对成员平均、追问受迫响应。
:::
:::

::: quiz {#quiz-levins}
Levins三角（真实、通用、精确）解释了为什么：

- [ ] 所有气候模式最终必须收敛到一个包罗万象的模式
- [x] 为一个目的优化的模式（如分岔几何）刻意不为另一个目的（如区域降水真实性）优化
- [ ] 简单模式总是优于复杂模式
- [ ] 模式复杂度应当跟踪计算机的可用性

::: solution :::
权衡说三个追求互相竞争，所以理性策略是在一个多元阶梯上分工——每级最大化一个顶点（箱模型：通用与可解释；GCM：真实；系综：精确）、而不是一个模式最大化全部。"更多分辨率"不是"更好"而是"不同的顶点"，这就是层级在每一代超算面前幸存的原因；百亿亿次机器买到的是顶级、不是阶梯的废除。
:::
:::

## 练习题

::: exercise {level=1 check="1.2"}
**普朗克敏感度。**CO₂倍增的辐射强迫是3.7 W/m²、普朗克反馈参数是3.3 W m⁻² K⁻¹。无反馈的平衡增暖是多少？
::: solution :::
ΔT = F/λ = 3.7/3.3 = **1.2 °C**——层级每一级都从这行答案出发；著名的3 °C是这个数字乘上净反馈因子f = 1/(1 − λ_feedback·...) ≈ 2.5，而整个反馈分析领域讲的就是为什么f不是1。
:::
:::

::: exercise {level=1 check="10368"}
**网格计数。**一个2.5° × 2.5°网格单元的经纬度大气网格有多少个网格单元？
::: solution :::
(360/2.5) × (180/2.5) = 144 × 72 = **10,368**列每层——诚实的脚注是经纬度网格过度采样两极（余弦因子），这就是动力核转向单元数均匀的二十面体与立方球网格的原因；练习真正的教训是"分辨率"首先是关于几何的陈述、然后才是关于物理的陈述。
:::
:::

::: exercise {level=1 check="200"}
**步长。**一个模式的稳定步长服从CFL条件Δt < Δx/u_max，u_max = 50 m/s（重力波）、网格10公里。最大步长是多少？
::: solution :::
Δt = 10,000/50 = **200秒**——对照同样物理在100公里上约1,200秒：Δx减半则Δt减半，这是分辨率贵16倍的两个理由之一（连同8倍的点数），也是"水平隐式"、能跨过声波极限步进的动态核是打破这把锁的认真尝试的原因。
:::
:::

::: exercise {level=2 check="4096"}
**十六倍定律。**一个中心把其耦合模式从100公里移到12.5公里水平网格、垂直层数翻倍、并按CFL重新调整步长。每个模拟年的成本增长多少倍？
::: solution :::
三次分辨率翻倍：点数×8³ = 512、步长÷8，所以成本×512 × 8 = **4,096**——一个CMIP6百年系综（10⁵核时）变成一次4 × 10⁸核时的单独运行：四亿核时，一个大陆的超算跑几个月一个世纪，这就是2020年代公里级项目模拟周、而阶梯幸存的全部原因。
:::
:::

::: exercise {level=2 check="36"}
**系综定容。**内部变率让个别20年均值围绕受迫响应有0.3 °C的散布。需要多少系综成员才能让系综均值的噪声为0.05 °C？
::: solution :::
σ/√N = 0.05 → N = (0.3/0.05)² = **36个成员**——2010–2020年代每个"大系综"背后的算术（CESM与GFDL的百成员计划、英国百成员HadGEM3十年套件）：在噪声气候里检测信号是一个采样问题、而采样相对分辨率是便宜的——这正是层级赖以利用的权衡。
:::
:::

::: exercise {level=2 check="5000"}
**启动调整。**深海调整是扩散的：t ≈ z²/κ，κ ≈ 10⁻⁴ m²/s。一根4,000米水柱达到平衡要多久（以年计，3.15 × 10⁷ s/年）？
::: solution :::
t = (4×10³)²/10⁻⁴ = 1.6 × 10¹¹ s ÷ 3.15 × 10⁷ = **约5,000年**——这就是耦合模式要启动调整几千年的原因（CMIP DECK协议500年工业化前控制运行是一个折中、不是平衡）、为什么海洋吸热时标让瞬态与平衡敏感度相差约40%、以及为什么"模式已达到平衡"永远是关于快成分的陈述、绝不是关于深海的。
:::
:::

::: exercise {level=3 check="76"}
**方差预算。**按Hawkins–Sutton式分解，2080–2099平均温度的标准差是：内部0.2 °C、模式0.4 °C、情景0.8 °C。总*方差*中有多大百分比来自情景不确定性？
::: solution :::
方差：0.04 + 0.16 + 0.64 = 0.84。情景份额 = 0.64/0.84 = **76%**——对世纪末温度终结"模式不一致所以预测无用"论证（情景主导）、并对2030年代区域降水开启诚实论证（那里模式与内部噪声主导、情景几乎不登记）的数字：方差分解依赖问题、变量与时距，而把它读反是政策文件里最常见的预测素养失败。
:::
:::

::: exercise {level=3 check="100"}
**仿真器经济学。**一个GCM成员花10,000核时；一个训练好的线性仿真器每个成员花1核时。一项研究需要100个GCM成员或10,000个仿真器成员来做同样的参数探索。GCM总成本对仿真器总成本之比是多少？
::: solution :::
GCM：100 × 10,000 = 10⁶核时；仿真器：10,000 × 1 = 10⁴；比值 = **100**——一次除法里的仿真器论证，带它两个星号：仿真器只在造出它的那些昂贵运行的训练包络内有效（2020年代"分布外"文献给ML气候替代物的警告），而10,000个样本对一个20维参数空间正是维数灾难开始咬人之处——这就是高斯过程仿真器（2006–2020年代英国气候风险计划的历史匹配学派、HadCRME与DICE线）压倒蛮力的原因。
:::
:::

::: exercise {level=3 check="5.5"}
**出现时间。**一个受迫增暖信号按ΔT(t) = 0.02·t °C增长（t以年计）、年平均局部噪声σ = 0.3 °C。用"2σ/√N"准则、N = 30个系综成员，信号何时出现？
::: solution :::
阈值 = 2 × 0.3/√30 = 0.11 °C；t = 0.11/0.02 = **5.5年**——结构化公共传播的Hawkins–Sutton"出现时间"地图的一个玩具版本（热带在2020年代出现、高纬冬季降水在本世纪中叶、区域降水也许在情景散布内永不出现）：出现是信号、噪声、*以及*你带来多少成员的一个属性，这就是为什么"我们何时会看到它"部分是一个关于你看得多努力的问题。
:::
:::

::: warning 关于气候模式的四种误解
1. **"更高分辨率总是更好。"**分辨率在Levins三角的一个顶点上买到真实性、在其他每个顶点上贵十六倍；2020年代公里级实验改进了降水相位与海洋锋面、而让全球敏感度大体留在原地，而高分辨率云研究的层积云瓦解恐慌表明，如果云物理在新尺度上是错的，分辨率甚至能把答案朝错误的方向移动。正确的问题从来不是"更细吗"，而是"对哪个过程更细、以什么成本、对照哪个可观测量检验？"
2. **"调参让模式循环论证。"**对今天的平均态调参并不比给一台秤校准更循环：模式被设定为复现一组选定的可观测量，而其*可信度*来自它随后如何对待从未见过的数据——它没有被调参的季节循环、古气候状态、火山响应、独立的卫星时代。循环性批评只在调参目标与评估目标是同一个时才咬人（2020年代"为敏感度调参"文献对历史记录温度约束的ECS的真实担忧），这正是本课程的评估章节坚持留出检验的原因。
3. **"失败过一次的模式就没用了。"**每个模式都会失败——双ITCZ幸存了40年、CMIP3的北极冰太厚、CMIP6的敏感度跑得热——而这门学科真正的方法是*失败定位*：一个错误的冰-反照率参数化是一个已知的、有界的误差、不是对流体动力学的驳倒。没用的主张是靠不可证伪而幸存的那个；有用的模式是失败可定位的那个，因为那些失败会变成下一级的研究议程。
4. **"机器学习将取代物理模式。"**2023–2025年的ML预报员是在观测分布内部训练的初值机器：它们继承再分析的偏差、没有守恒保证、而在其训练生涯里从未外推过一个气候状态。ML真正接管的是阶梯的*中部*——仿真器、参数化替代物、系综采样、降尺度——而它无法取代的是层级的功能：一个其失败是关于世界的物理陈述的模式，那是唯一能以有信息的方式*对2080年犯错*的模式。
:::

## 总结

::: summary
气候建模是跨理想化阶梯的分工——能量平衡模型、箱模型、辐射-对流柱、GCM、地球系统模式、以及其间的区域、中间复杂度与对流许可变体——由一个经济学事实组织：每次分辨率翻倍贵十六倍，所以包罗万象的模式对需要采样的问题永久太贵、而廉价模式对解释昂贵模式永久必要。阶梯回答不同的问题：初值预报（两周的大气、十年的海洋）、边界条件预测（成员是无意义天气、统计量才是对象的受情景驱动的系综）、以及过程定理演示（Budyko的两个平衡、Stommel的两个状态、Manabe–Wetherald的2.9 °C——廉价模式作为存在性证明）。这个系统里的知识从来不是确认、而是校准过的可信度：对一组公开声明的可观测量的调参、靠留出检验与古气候的证伪、跨独立模式家族与层级的三角验证、以及按证据线而非模式权威给主张分级的评估实践（AR6的证据层级）。2020年代——公里级的周、ML预报员、靠观测约束而非计算机速度解决的敏感度之争——改变了阶梯的经济学、不是其逻辑：你选的模式就是其失败你能对你的问题做出解释的那个模式。本课程的下一级是最简单的一级，完整演算：能量平衡模型，分岔、滞后与雪球地球在那里第一次变成算术。
:::
