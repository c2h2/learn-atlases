地球系统模型是一个通用环流模式加上行星上那些会反过来改变它的部分。1990年代的大气-海洋GCM规定它的CO₂、它的臭氧、它的植被、它的冰盖地形与它的气溶胶——一个嵌在不变生物圈、化学与冰冻圈里的气候系统，一座壮观的怪物，服务了领域二十年，恰恰因为边界条件不是答案的一部分。地球系统时代，其奠基出版物通常被认为是Cox、Betts、Jones、Spall与Collins 2000年发在*Nature*证明碳循环反馈加速增暖的论文，其制度性诞生是2010–2025年CMIP5–CMIP6的地球系统模式运行，它转而让活的、呼吸的、脱气的、反照着的、崩解的行星回应：人类排放的CO₂被一个随增暖而增暖并减弱的碳循环分配；甲烷按它自己的日程从融化的永久冻土冒出来；植被随CO₂与气候允许在大陆上移动其反照率与气孔；气溶胶与臭氧跟随排放清单与光化学；冰盖在几千年里增厚、变薄、重新组织；而整个装配体通过一个**耦合器**连接，它守恒所传递的东西、并在不该漂移时保持不漂。本课测绘这个装配体：什么让一个ESM成为一个ESM（分量、耦合器、平衡调参与漂移文化、DECK、AFMIP与C4MIP的CMIP6协议架构）；领域现在陈述的那个被量化的碳-气候反馈——约每°C累积释放20 Pg C（2013年C4MIP综合）以及把反馈变成记账的λ_carbon项；分量家族及其旗舰争议（永久冻土碳、CESM2深云事件、ISMIP6的冰盖海平面问题、气溶胶强迫僵局）；以及这么多被调参部分的模型的认识论——"地球系统"作为一个研究纲领，其每个添加的循环既教学又污染，其涌现的漂移是其典型的失败，而其2020年代前沿（公里级孪生、耦合冰盖的世纪、氮磷约束的植被、机器学习分量）同时是模型层级的最充分表达与其最脆弱的产物。先修是[[climate-modelling/parameterisation]]与[[climate-modelling/box-models]]两课；回报是理解为什么最新一代的温度预测与2001年的差别不大，而这既不是失败也不是安慰。

::: definition ESM是什么：分量、耦合器、平衡调参 {#def-esm-anatomy}
形式上，一个地球系统模型耦合（1）一个带物理的大气动力核，（2）一个海洋-海冰模式，以及（3）一个或多个**地球系统分量**：一个碳循环（海洋生物与碳酸盐化学，1990–2010年代NPZD与2010–2020年代CoBALT和Agmon一代生态系统；陆地光合、呼吸与火，2011年LPJ-GUESS、ORCHIDEE与JULES谱系及2016–2020年代FATES与ORCHIDEE-DFJ功能多样性后继者）、大气化学与气溶胶微物理（2000–2020年代CCMVal与ACM-ESM传统，现在以2020年代CEDS与EDGAR排放清单为边界条件）、一个氮与磷循环（2010年代Qian等与2020年代CN与CNP文献约束住否则会失控的CO₂施肥）、以及——2020年代前沿——动态冰盖（2016–2025年一代的ISMIP6协议PISM与ISSM耦合）与它们返还的淡水与地形反馈。分量之间坐着**耦合器**：在不同几何的网格间重网格化通量、在交换中守恒质量与能量（共同体共享软件的2000–2020年代ESMF与CIME基础设施）、以及选择耦合频率——多数通量每日一步、短波分配每步一步、化学要求的气溶胶-辐射握手每小时一步。架构造就的文化是独特的：**平衡调参**（调整分量参数直到耦合模式的工业化前能量与碳收支闭合——2010–2020年代模式描述文献诚实承认每个ESM都始于一个小的反问题）、**漂移管理**（CMIP的DECK协议千年控制运行，其残余趋势在AMOC强度、南大洋温度与陆地碳，是模式自己的传记，而其解读——漂移还是受迫变化——是ESM用户的第一个方法论险滩）、以及**分量出身**（CMIP6模式索引对有无交互式化学、有无碳反馈模式的区分，这就是为什么"该模式"永远不是一个对象、而每个CMIP分析都按ESM标记分层）。定义的一句话版本：ESM是一个GCM加上每个纯粹主义者本来会规定的边界条件背后的循环——这正是为什么它的错误以新方式相关、而它的调参是一个以观测为含噪数据的多维反问题。
:::

::: definition 碳-气候反馈：γ、λ_carbon、与每°C 20 Pg C {#def-carbon-feedback}
碳循环是气候第一个被参数化的旁观者，后来成为它第一个被量化的反馈。经典的度量是**碳循环敏感度γ**——全球平均温度每升高一度大气CO₂的变化，以ppm/°C计——其现代谱系始于Cox等2000年的耦合实验（HadCM3中γ ≈ 2 ppm/°C，那篇通过显示反馈大约把排放的时间预算砍半而开创领域的论文：在1990年代规定循环的模式上，稳定在550 ppm需要比被动碳循环下同一目标更少的累积排放，因为增暖的世界保留其所得的越来越大的份额）。现代的度量是**碳-气候反馈参数λ_carbon**——循环的响应每度增暖产生的辐射强迫，以W m⁻² K⁻¹计，符号为负、在[[climate-system/feedbacks-sensitivity]]一课的反馈记账里与普朗克和云项相加——而其标准数字是C4MIP综合的：跨CMIP5系综的百年1%/年CO₂实验与1%/年CO₂移除镜像实验（2013年Friedlingstein等在*Nature Geoscience*对第一代C4MIP的分析及其2020年代CMIP6更新），耦合模式每°C增暖释放约**20 Pg C额外自然碳**（系综中心估计接近19 Pg/°C、散布为百分之几十、由陆地一侧主导，海洋一侧更小也更一致）。这个数字的译法，评估文献全在用：空中分数每°C上升约4–5%（2010–2020年代全球碳预算空中分数稳步上升的观测趋势，现在接近45%，与模式的一致，但其在排放路径、养分与土地利用效应之间的归因仍有争议）；一个温度目标的累积排放预算随目标变大而收缩（AR6碳预算算术对"2°C然后稳定"逻辑的一次安静修正）；而反馈自身的不确定性——CMIP5的λ_carbon散布约±0.2 W m⁻² K⁻¹、2019–2022年综合发现模型间范围给总敏感度范围添了四分之一个度——由模式分歧最大的两个过程主导：**永久冻土**（见下）与**养分限制下的CO₂施肥**（2010–2020年代约束氮与磷的文献，其中心结果是不受约束的施肥——拯救了二十世纪陆地预算的那个汇——在二十一世纪减弱，2020年代ISIMIP与ISENGA综合）。一个同时可测量（全球碳预算的记账）、涌现（耦合实验）、而过程晦暗（哪些生态系统、哪些土壤、哪些火）的反馈，就是地球系统时代的定义形式。
:::

::: definition 分量家族及其旗舰争议 {#def-components}
每个添加的循环带来它自己被测量的分歧，而2010–2020年代ESM文献最好按它们组织。**永久冻土碳**：冻结的土壤持有约1,400–1,600 Gt有机碳（2000–2020年代环极地清单），模式的任务是在融化时标上以CO₂与甲烷释放它；2010–2020年代综合（2018与2022年全球碳预算永久冻土章节、2010年代EMIC互比）收敛于高排放的二十一世纪每年几十Gt C——直接的强迫温和，但这是一个**阈值形状的**过程（2020年代突然融化与热喀斯特文献、作为其公共面孔的更新世公园巨型动物群之辩）平滑的模式低估它，冰-反照率一课在新媒介里教过的同一个结构性诚实问题。**大气化学与气溶胶**：交互式化学把臭氧的未来绑在NOx、甲烷与卤素清单上（2000–2010年代CCMVal与CCMI协议的臭氧预测机器），而气溶胶微物理（2010–2020年代模态与 sectional(分段) 方案）把账本里最大的强迫不确定性（AR6气溶胶ERF的−0.5 W/m²及其三倍范围、2020年代船舶航迹与清洁空气修订）变成排放清单（2021–2025年CEDS与EDGAR更新）与[[climate-modelling/parameterisation]]一课夹卷战争所关的同一个云微物理参数化的函数——化学与云在本世纪增暖率的层面上纠缠。**动态植被与火**：全球动态植被模式（LPJ-GUESS、ORCHIDEE、JULES与FATES家族）让森林响应气候与CO₂迁移、死亡、燃烧，而2010–2020年代文献令人清醒的结果是其碳结局由**死亡参数化**主导（2009–2020年代与2020年代论文显示树如何死——计碳的水力学对不计碳的饥饿——把亚马逊的模拟未来移动一个世纪的排放量）以及由火的方案主导，其排放反馈是模式一致承认其为真的少数陆地正反馈之一（火-EMAC与全球火图集时代的2020年代火活动归因结果）。**冰盖**：ISMIP6协议（2016–2025）把共同体的浅冰与全Stokes冰盖模式（PISM、ISSM等）耦合到CMIP6气候做海平面预测，而2020年代前沿——海洋冰盖不稳定性与冰崖失效（2018年DeConto–Pollard的Nature论文与2018–2025年关于破裂崖物理是否属于模式的辩论、ISMIP6+与2020年代Exa3D与Pleiades全Stokes实验）——是ESM最新也最有后果的参数化争论，因为事关的海平面米数使系综里每一场云反馈分歧相形见绌。
:::

::: definition 协议、验证、与多调参部分的认识论 {#def-esm-epistemics}
一个ESM的结果只和约束其自由度的协议纪律一样可信，而CMIP6架构（2017–2022年运行、2018–2021年模式描述论文系列）是该领域的宪法：**DECK**（1850控制、用于反馈诊断的150年1%/年CO₂斜坡、突变4×CO₂平衡实验、历史与SSP扰动强迫运行）、**AFMIP**（把碳循环反馈与云反馈分离的水球与纯大气实验）、**C4MIP**（带其排放驱动与浓度驱动孪生实验的耦合碳实验、2013年每°C Pg综合的机器）、**ISMIP6**、**AerChemMIP**、**PMIP4与古气候协议**（末次盛冰期与中中新世作为ESM的压力测试——2020年代结果为谁都没有调过的古世界复现了LSH的CO₂与温度的模式恰恰因此赢得可信度）、以及取代SRES故事线的**ScenarioMIP** SSP强迫框架（2016年O'Neill–Fedderson–Kriegler架构）。与这部实验宪法并置的是ESM典型的认识论状况：**相关的调参**。每个分量都对照同一观测气候态做平衡调参，所以分量错误合谋（2019–2021年关于调参诱导的散布缩减文献——调参到历史趋势的模式共享同一本补偿误差账的一页，而2020年代对CMIP6热模式的"为敏感度调参"批评是[[climate-modelling/model-hierarchy]]一课可信度定义里诊断的同一种病），而领域据此建立的验证层级明确是多线的：分量级对照过程数据的评估（植被的FLUXNET与SiteMIP通量塔、海洋碳的2010–2020年代SOCAT与GO-SHIP、陆地水文的ISMN土壤湿度网）、跨系综的涌现约束评估（2020年代用模型间散布加观测对陆地碳汇与气溶胶强迫的约束）、以及作为留出测试数据的古气候评估（PMIP4的结果：ESM的碳循环反馈在冰期CO₂下运行，落在冰芯独立显示的范围里）。诚实的总结陈述，AR6章节作者在2021年做出、每个诚实的建模者重复：ESM的中心温度预测自1990年代以来没有移动多少，**尽管**添加了那些循环——因为补偿是巨大的（更强的施肥汇对更强的永久冻土释放、更强的气溶胶冷却对更弱的云调整）——而正确的读法不是"稳健"，而是"系统的一阶答案由模式一直就有的物理设定，而二阶——区域碳、海平面、气溶胶-降雨耦合——才是地球系统时代真正挣得或输掉饭钱的地方"。
:::

::: example C4MIP：把行星跑两遍来测量一个反馈 {#ex-c4mip}
碳-气候反馈无法被直接观测——不存在对照地球——所以C4MIP在软件里造了一个。**实验一（排放驱动）**：气候模式与其碳循环都响应一条规定的排放路径；大气CO₂从互动中涌现，而耦合的CO₂与被动循环模式在同样排放下本会产出的CO₂之差就是反馈的大小。**实验二（浓度驱动）**：规定CO₂、让循环响应、直接读出每度释放的自然碳。Friedlingstein等2013年对第一代C4MIP的综合——1%/年斜坡及其镜像，跨十几个ESM——交付了领域最爱的数字：**每°C**全球增暖约19 Pg C额外自然碳，累积的，陆地贡献了大部分散布而海洋贡献的符号跨模式一致；及其伴随结果、让碳预算文献上头条的**不对称**：移除给定的累积吨数不会以添加时的速度返还CO₂（2013年分析的"碳循环在世纪时标上不可逆"、2020年代C4MIP-2一代精化的镜像实验滞后，它拆掉了天真的负排放算术——每吉吨抽回的CO₂少于让世界增暖的排放放进去的，因为增暖的海洋与生物体几十年来保持着它们的补偿）。该例的方法论教训在ESM时代普遍成立：协议不是官僚制，它们是把一群被调参的动物园部件变成一台测量仪器的实验设计——而动物园的散布（19 Pg/°C上下±30%、由亚马逊与北方土壤主导）像所有诚实的测量一样作为仪器的分辨率被报告。
:::

::: example CESM2事件：一个分量的修补如何移动整个系综 {#ex-cesm2}
2019年，美国国家大气研究中心的旗舰发布CESM2，随之带来任何CMIP模式曾摆上桌的最高平衡敏感度：5.3 °C。原因不是新的碳循环也不是新的海洋——而是一个**云的修补**。共同体的对流与云方案长期高估了东南太平洋层积云反射的阳光（2014–2017年McCaa等与2018–2019年Li等对深冷云偏差的分析）；CESM2修订的浅积云与混合相降水处理移除了把旧敏感度撑在3 °C附近的补偿，而模式的云反馈升到了过程证据——2010–2020年代CloudSat与CALIPSO时代的卫星约束文献——可以说支持的水平。该事件对地球系统建模的三个教训：**补偿误差在平衡调参的模式中是结构性的**，所以一次分量升级就能把ECS移动一度，而系综的回应（2019–2021年辩论以热模式的ECS被对照历史与过程约束收场、多个中心在2020年代一代重新调参）显示共同体的纠错机器管用、只是慢；**分量出身就是预测政治**——一个中心的云微物理移动"气候敏感度"的公共含义超过十年的评估文书；而**修补是可证伪的**——产生偏差的同一片层积云区域现在仲裁修补（2023–2025年用观测的逆温强度-云量关系对修订方案的重新评估），这是参数化一课的地球系统时代版本：每个分量是一个假说，而系综是假说与数据互相交易的论证市场。
:::

::: example ESM内部的翻转要素：永久冻土、亚马逊、冰盖 {#ex-tipping-esm}
地球系统分量把评估文献的"翻转点"从地质轶事变成被量化、被模拟的风险——并暴露了模式在阈值处多么不可信。**永久冻土**：2010–2020年代的ESM与EMIC系综在本世纪高排放下从近地表永久冻土释放30–60 Gt C（2022年全球碳预算永久冻土章节的范围，平滑方案省略的突然融化与热喀斯特过程把上界推高数倍），而甲烷份额——其观测（2010–2020年代亚北极通量网与同位素综合）最单薄的那个过程——决定释放中有多少咬人；诚实的陈述是反馈是真的、本世纪可测量、而其尾部未被充分表达。**亚马逊**：2010–2020年代的动态植被ESM（Lenton等2021年*Nature*翻转风险筛选、2020年代ESM与统计早期预警综合）只在模式的降雨-环流耦合与火的方案一致朝变干方向对齐时才产出退化——而系综的双峰性（多数模式渐进、少数突变）恰是[[climate-change/tipping-points]]一课理论预测的结构不确定性签名，2024–2025年亚马逊植被中临界慢化信号的观测主张（在2025年统计方法文献中有争议）正勉强充当仲裁。**冰盖**：ISMIP6协议耦合的预测（AR6 2021年海平面章节的中心范围与低概率高路径、2020年代纳入DeConto–Pollard崖失效争议的更新）显示南极贡献由海洋冰盖不稳定性物理是否被打开主导——一个到2300年值一米的二元参数化选择——而格陵兰的表面质量收支，账本里最干净的分量，在区域模式与ESM之间仍差几十年的融化。三个案例共享其寓意：地球系统时代最有后果的问题活在模式的平滑、调参、平均态优化的机器与阈值物理相遇之处，而领域对付它们的诚实仪器不是预测而是**风险框架**——分布、低概率分支、以及一个调参到平均态的模式家族在其被要求定价的尾部上存在结构性偏差的谦逊。
:::

::: example 气溶胶僵局：最大的不确定性是一份清单 {#ex-aerosol-esm}
地球系统时代最令人泄气的结果是：本世纪增暖率的不确定性如今不仅由云主导、还由建立起气溶胶强迫账本的人类排放主导。AerChemMIP的设计（2017–2022年协议：交互式化学与气溶胶、规定的排放、历史与扰动强迫运行）让僵局定量化：跨CMIP6，全气溶胶有效辐射强迫跨越约−0.4到−1.3 W/m²（AR6 2021年范围、气溶胶ERF的三倍之杠），而2020年代分解（2021–2024年气溶胶-云强迫归因文献）把散布大致均分给排放清单（2021–2025年CEDS与EDGAR修订把船舶硫酸盐与生物质燃烧通量移动百分之几十、船舶交通与清洁空气政策位移写进清单本身）、微物理（与[[climate-modelling/parameterisation]]一课战争相同的夹卷与活化物理）、以及气溶胶所见的天气。三个后果组织起评估时代：**历史约束纲领**（2020年代用观测温度响应加海洋热吸收比对气溶胶强迫定界的尝试——[[climate-modelling/energy-balance-models]]一课同样的双层能量平衡逻辑，其答案取决于λ、因而拿气溶胶不确定性换敏感度不确定性，2023–2025年涌现约束文献公开点名的循环）；**政策阴影问题**（清洁空气政策下的气溶胶下降是一个不得不免于建模的实验——2013–2020年东亚排放坍塌与2020年船舶硫酸盐法规是核爆脉冲以来最大的蓄意地球物理实验，而2021–2025年对其增暖与云响应的检测研究是对强迫账本最大项的首批直接检验）；以及**死亡算术**（2020年代WHO与全球疾病负担的空气质量工作，其清洁空气每年避免的数十万死亡是一项健康协同效益、其气候符号就是气溶胶强迫本身——冷却本世纪的硫酸盐正是致死的颗粒物，而ESM的气溶胶模块在其所有分量中独一无二地是一件公共卫生仪器）。该例在本课的位置：地球系统现在是一个人类系统，而模式最大的误差棒是一份关于我们排放了什么、我们将管制什么、以及云对两者做什么的账。
:::

::: history 从规定的CO₂到数字孪生的雄心 {#hist-esm}
**1967–1995**：规定边界时代——Manabe与Wetherald的CO₂实验延续到1980年代、1989–1995年碳循环关机的海洋-大气耦合模式、1990年代对照GCM气候离线运行的首批海洋生物与陆地生物地理模式（1990年代Parton等与Friend–Prentice植被模式、1990年代海洋NPZD一代）。**1997–2009**：耦合上线——1997–2000年交互式海洋碳模式与Cox等2000年*Nature*碳反馈结果、2001–2009年C4MIP与海洋碳循环互比计划、2000年代化学-气候耦合（2006–2010年CCMVal臭氧预测）、以及2006–2009年AR4一代首批耦合碳-气候-气溶胶二十一世纪预测。**2010–2019**：ESM一代交付——HadGEM2-ES与IPSL-CM5A-LR（2011–2012）、CESM1-BGC与CMIP5-ESF运行、2013年C4MIP每°C Pg综合、2014–2019年氮磷约束文献、2016年ISMIP6协议与2018年DeConto–Pollard南极冲击、2019年CESM2敏感度事件。**2017–2025**：CMIP6的协议宪法（DECK、ScenarioMIP、C4MIP-2、AerChemMIP、PMIP4的冰期与上新世压力测试）、AR6 2021年对碳预算与海平面范围的证据层级评估、2020年代永久冻土碳与亚马逊翻转综合、2022–2025年欧美数字孪生计划（2022年Destination-Earth与2024–2025年Exa3D及公里级耦合原型）——地球系统模式同时是环境科学中政策负载最重与计算雄心最大的对象，而在其碳循环里仍是一个穿着大气外套的箱模型孙辈。
:::

## 检验你的理解

::: quiz {#quiz-esm-vs-gcm}
在CMIP意义上，地球系统模型与气候模型的定义性区别在于ESM：

- [ ] 使用更细的网格与更多的垂直层
- [x] 让碳、化学、气溶胶、植被与（可选）冰盖循环响应气候，而不是规定它们的边界条件
- [ ] 排除自然变率
- [ ] 从观测初始化

::: solution :::
CMIP模式索引里的ESM标记标志着交互式生物地球化学与化学——CO₂成为一个输出、不是一个输入，随之而来的是碳-气候反馈、气溶胶-云-排放耦合、以及植被-反照率-水分反馈。动力核可以完全相同；改变的是模式被允许改变哪些边界条件，这就是为什么ESM结果携带每个添加循环调参的额外不确定性、以及为什么存在C4MIP一类协议来分离两类反馈。
:::
:::

::: quiz {#quiz-carbon-asymmetry}
C4MIP的镜像实验（先排放后移除）发现碳循环是：

- [ ] 可逆的：移除100 Gt C恰好恢复排放前的CO₂
- [x] 不对称的：抽回每吨恢复的大气CO₂少于排放添加的，因为增暖的海洋与生物体几十年来保持其补偿
- [ ] 吸收比释放更快
- [ ] 与增暖路径无关

::: solution :::
增暖的系统保持其距平：海洋在释放热量的同时脱气、受压的生物体呼吸，而镜像实验的滞后意味着一次给定的累积抽回让CO₂在几十年里高于原路径。该结果（2013年Friedlingstein综合与C4MIP-2的2020年代精化）是碳预算文献告诫负排放是部分的、延迟的补救、不是一个撤销按钮的物理基础——名义上可逆的强迫内部的路径依赖。
:::
:::

## 练习题

::: exercise {level=1 check="38"}
**碳反馈记账。**用C4MIP每°C释放19 Gt C的中心估计，到2 °C增暖时行星已释放了多少额外自然碳（Gt C）？
::: solution :::
19 × 2 = **38 Gt C**——约当前四年的排放量，被生物圈与海洋未经请求地自动交出；练习的尺度教训是碳反馈不是舍入误差、而是每度多年的排放预算，无论政策是否花费它都在被花掉。
:::
:::

::: exercise {level=1 check="203"}
**γ的强迫表达。**Cox式的碳循环敏感度γ ≈ 2 ppm/°C。用5.35 W/m²每倍增（≈ 3.7 W/m²每2倍 = 1.85 W/m²每倍增……小变化时用F = 5.35 × ppm/280），1 °C增暖仅通过CO₂增加多少强迫？
::: solution :::
ΔF = 5.35 × (2/280) ≈ **0.04 W m⁻² K⁻¹**……预期的算术：280 ppm基数上的2 ppm是一倍增的0.7%，所以ΔF ≈ 5.35 × 0.007 = 0.04 W m⁻² K⁻¹——每度很小，但在γ上升的3–4 °C世界的几个世纪里积分，反馈的累积强迫达到W/m²量级，练习显示了为什么λ_carbon按度引用、以及为什么反馈越晚越要紧。
:::
:::

::: exercise {level=1 check="45"}
**空中分数趋势。**如果排放平均10 Gt C/年而陆地加海洋汇平均5.5 Gt C/年，空中分数是多少百分比？
::: solution :::
(10 − 5.5)/10 = 0.45 = **45%**——全球碳预算2020年代的空中分数，在排放上升的五个十年里保持稳定（1960–2020年代记账最稳健也最脆弱的事实：作为平均值稳健、作为承诺脆弱，因为汇的绝对增长最终必须落后于排放的——C4MIP反馈的一阶签名）。
:::
:::

::: exercise {level=2 check="0.08"}
**从γ到λ_carbon。**取CMIP5一代中心γ = 4 ppm/°C与F = 5.35 × (ppm/280) W/m²，把碳-气候反馈以λ_carbon表示为W m⁻² K⁻¹（量级）。
::: solution :::
λ_carbon = 5.35 × 4/280 = **0.08 W m⁻² K⁻¹**——一行算术就是云反馈散布的四分之一，这就是为什么λ_carbon在反馈账本里赢得自己的一行；单位之旅继续：4 ppm/°C × 2.12 Gt/ppm = 8.5 Gt C/°C留在空中，对照C4MIP每°C总释放19 Gt C——差额是汇仍在吸收的部分，用三种货币说出来。
:::
:::

::: exercise {level=2 check="2.12"}
**每ppm的货币。**一大气ppm的CO₂等于多少吉吨碳？
::: solution :::
**每ppm 2.12 Gt C**——标准换算（每ppm 5,120 Gt空气 × CO₂中碳的质量分数12/44，共同体在碳账本与气候账本之间的固定汇率，每个碳预算头条都在用：AR6 1.5 °C预算的500 Gt C是约236 ppm蓄势待发的未来CO₂，而C4MIP每°C 19 Gt C是释放9 ppm/°C，其中空中分数决定多少ppm留下——把前两题的货币连起来的算术。
:::
:::

::: exercise {level=2 check="60"}
**永久冻土的尺度。**高排放系综本世纪从近地表永久冻土释放30–60 Gt C。在上界、80年期间，年均释放是多少（Gt C/年）？
::: solution :::
60/80 = **0.75 Gt C/年**——相对化石排放的10 Gt C/年很小，这正是永久冻土文献诚实的框架：危险不是二十一世纪的总量、而是过程的尾部（更深的1,400 Gt、甲烷份额、突然融化）平滑的模式低估它，一个风险形状而非预算形状的威胁。
:::
:::

::: exercise {level=3 check="2.4"}
**补偿误差。**一个模式的净反馈是λ_net = 1.27 W m⁻² K⁻¹，给出ECS = 3.8/1.27 = 3.0 °C。一次云方案升级移除了0.57 W m⁻² K⁻¹一直在补偿云放大的稳定净反馈。ECS移动多少°C？
::: solution :::
新的λ_net = 1.27 − 0.57 = 0.70；新的ECS = 3.8/0.70 = 5.4 °C；移动是5.4 − 3.0 = **2.4 °C**——半瓦每平方米的云变化，值两个半度的敏感度，敏感度对单个调参项的敏感度：有据可查的CESM2事件在相当的调整上移动了整整一度，而一行算术ECS = F₂ₓ/(λ₀ − Σλ_fb)就是整个CMIP6热模式辩论转动的那根门轴。
:::
:::

::: exercise {level=3 check="1"}
**海平面的二元。**ISMIP6式的预测在是否包含崖失效物理上让南极贡献到2100年相差约0.5 m。这个结构性选择跨越AR6高排放总海平面范围（0.6–1.1 m）的多少比例？
::: solution :::
0.5/0.5 = **1**——崖失效开关跨越AR6范围的全部宽度：一个二元参数化选择（2018年DeConto–Pollard争议）对这个变量与时距比所有其他结构分歧之和更值钱，这就是冰盖共同体的争论在公开场合进行、而沿海政策读低概率尾部、不读中心估计的原因。
:::
:::

::: exercise {level=3 check="4.0"}
**系综平均。**三代ESM给出ECS 3.0、3.6、4.2 °C；第四个用修正的云方案给出5.3。系综均值是多少，均值为什么误导？
::: solution :::
(3.0 + 3.6 + 4.2 + 5.3)/4 = 16.1/4 = **4.0 °C**——而误导正是要点：三个旧模式共享第四个已移除的补偿误差，所以它们的一致是一场调参阴谋、不是证据（2019–2021年热模式事件的统计学寓意）；系综均值把共享假设与独立假设等权对待，而诚实的敏感度综合（AR6 2021年跨古气候、过程与历史证据的三角验证、不是模式平均）的存在恰恰因为模式计数不是独立的抛硬币。
:::
:::

::: warning 地球系统模式的四个陷阱
1. **"模式现在包含了永久冻土，所以永久冻土反馈在预测里了。"**包含不是一一表达：系综的永久冻土碳由缓慢、深层、先有氧后缺氧的分解链主导，其速率用几十年的实验室培养标定（2010–2020年代培养到生态系统的换算之争），突然融化缺席或被参数化，而甲烷份额是账本里约束最少的数字；对ESM永久冻土释放的诚实读法是一个带机制清单的下界、不是预报。
2. **"更多分量、更多真实、更好预测。"**每个添加的循环都对照同一观测平均态添加调参，而2019–2021年调参诱导一致的文献显示分量的添加能在增加偏差的同时缩小散布——一个更差的碳循环抵消一个更差的云反馈、历史拟合因任何过程数据都不支持的理由而改善的补偿误差经济；CMIP6模式索引的分量标记存在就是为了让用户能审计什么抵消了什么，而忽略它们的分析把系综当作其成员是独立的来读，而他们不是。
3. **"古气候验证认证了未来。"**末次盛冰期与上新世是CO₂强迫的真实实验，但它们在边界条件上远离人为问题（冰盖、地理、有孔虫重建的CO₂对仪器痕量气体），而2020年代PMIP4综合的告诫很精确：古气候结果排除了最热与最冷的模式尾部、它们没有使分布居中，而一个通过冰期测试的模式仍可能因冰期世界从未探测的理由在二十二世纪失败——突然的永久冻土、崖失效、亚马逊退化，全都缺席于代用记录的分辨率。
4. **"数字孪生将终结分量战争。"**2022–2025年孪生计划（机构级成本的公里级大气-海洋-冰-生物地球化学耦合）改变分辨率与数据同化、不改变闭合问题：在1公里对流被分辨，但微物理、边界层、土壤、化学与冰盖崩解没有，而2024–2025年层积云瓦解恐慌恰恰来自有史以来最精细的模拟、照样全是参数化；地球系统时代的认识论地位——多个调参的、部分约束的、互相审计的分量——是问题的一个条件、不是其发展的一个阶段。
:::

## 总结

::: summary
地球系统模式是GCM加上行星其余的反馈：交互式碳（海洋与陆地）、化学与气溶胶、带着其有争议的死亡与火的动态植被、对施肥的养分约束、以及——2020年代前沿——动态冰盖，全部由守恒的耦合器缝合、对照观测平均态平衡调参、并由把一群被调参的动物园部件变成测量仪器的CMIP6协议宪法（DECK、AFMIP、C4MIP、ISMIP6、PMIP4、ScenarioMIP）治理。这台仪器的旗舰结果是被量化的碳-气候反馈——每°C约19 Gt额外自然碳（2013年C4MIP综合）、约0.08 W m⁻² K⁻¹的λ_carbon、必须上升的空中分数、以及让抽回成为不完美撤销的路径依赖不对称——而其旗舰病理同样有教益：CESM2事件（一个云的修补把敏感度移动一度、补偿误差被揭示为结构性）、平滑调参模式按构造低估的永久冻土与亚马逊尾部风险、以及跨越整个海平面范围的冰盖二元（崖物理开或关）。时代要求的认识论：当成员共享调参时系综均值不是证据；古气候运行是留出测试、不是证书；而二十一世纪温度预测自2001年以来几乎没动的原因不是理解的趋同、而是在二阶的翻搅中一阶物理答案的守恒——而二阶（碳、海平面、气溶胶-季风耦合、尾部）恰恰是地球系统时代尽管其全部脆弱、仍是我们唯一仪器所在的地方。
:::
