一个模式、一个未来、一个数字：这种格式站不住脚，而在1990年代之前它就是领域仅有的一切。系综革命——由Lorenz 1965年发现大气的初值问题只有两周的时距所驱动、由从1990年代初起业务化运行扰动初始条件的天气预报实践、以及由认识到对气候而言有趣的不仅是我们从哪里出发、还有我们相信哪个模式、以及这个世纪做什么——用**未来上的一个分布**取代了单一预测；而情景革命（SRES 2000、RCP 2005–2010、SSP 2014–2016、ScenarioMIP设计、以及2023–2025年关于情景现实性的争论）用一个**设计好的路径空间**取代了单一故事线。两者共同定义了预测实际如何被做出、被传达、被使用：那个说出哪个不确定性对哪个问题在哪个日期要紧的方差分解（2009年Hawkins–Sutton结果：情景不确定性主导世纪末温度、而对本世纪中叶降水几乎无关紧要）、把"北极第一个无冰九月是何时"从一个预测变成一个日期分布的大初始条件系综（2020年代百成员一代）、其散布同时是该领域诚实与其记账问题的多模式系综、以及其叙事——可持续、中庸之路、化石燃料驱动的发展——在本课程里比任何其他对象承载更多政策货物（包括2023年关于高强迫道（SSP5-8.5）是否仍应被驱动）的争论。本课是系综时代的统计与政治：不确定性的类型学及其分解；系综动物园的种种类型及各自的用途；从RCP到SSP的情景架构及其综合评估机器与其2020年代批评；以及解读规则——系综均值何时是信号、何时是伪影、其散布何时是概率、何时是装扮成百分位数的治理选择。先修是[[climate-modelling/model-hierarchy]]与[[climate-modelling/evaluation]]两课；回报是带着完全的素养阅读任何IPCC图的扇形图、缎带与须线——也就是说，确切知道每条线许可与不许可你说什么。

::: definition 不确定性类型学：初始条件、模式、情景 {#def-taxonomy}
每个预测的误差预算有三个账户，按其回答的问题命名。**内部变率**（"初始条件"账户）：气候自身的混沌——同一个模式、同样的强迫、不同的天气起点，给出不同的2040年代、以及（少一些地）不同的2090年代；靠对系综成员以σ/√N的速率平均来缩减、原则上不可消除、并在动力喧闹的变量（降水、风暴路径、季风爆发）上、在几十年以内的时距上主导。**模式不确定性**（"我们相信什么"账户）：跨结构与参数的散布——按2000–2020年代方差划分文献本身还可分解为参数扰动（便宜、宽）与结构差异（昂贵、深、通常也是更大的项，[[climate-modelling/parameterisation]]一课结构对参数4:1的比率）；只有靠更好的模式才能缩减、由多模式系综采样，而系谱文献警告其成员远非独立。**情景不确定性**（"人类做什么"账户）：排放、土地利用与气溶胶路径的选择——任何科学努力都无法缩减、随时距增长、而世纪末温度预测花掉的主要就是这个账户。组织性的结果是2009年Hawkins–Sutton方差分解（及其2010–2020年代的后代与修正）：对**全球平均温度**，内部变率主导头一二十年、模式散布主导本世纪中叶、情景散布在世纪中叶之后主导——那张图终结了"模式不一致所以预测无用"关于世纪末增暖的论证（分歧被我们的选择淹没了），同样也终结了情景对2040年代区域降水要紧的主张（在那里它们几乎不登记，而模式散布与噪声拥有整个预算）。定义的纪律说一次：**分解是按变量、按区域、按时距、按统计量的**——2010年代修正的重点——而不带这四个标签引用一个份额，是系综时代最常见的统计渎职，是每张评估幻灯片与每篇评论扇形图里首先该查的一条。
:::

::: definition 系综动物园：每种各为什么服务 {#def-zoo}
**扰动初始条件（天气）系综**——ECMWF与NCEP自1992–1994年业务运行的系统、10–50个成员、滋生向量与奇异向量——回答"这场风暴的概率多大"，而其概率校准（验证科学的可靠性图）是其后每个系综私下都要接受的标准。**扰动物理系综**（2000–2020年代HadGEM与CNRM物理套件、2010–2020年代大扰动参数实验）：同一套代码、抖动的系数；它们测绘方案的拓扑，并按[[climate-modelling/parameterisation]]一课所示，揭示结构选择主导参数选择。**大初始条件系综**——2012–2020年代一代（CESM社区大系综2012年的34个成员与2020年的一百个、GFDL与哈德莱中心从几十到六十多的套件、英国百人十年的系综计划）——为把受迫信号与噪声分离而存在：出现时间、可检测性、以及单成员预测无法产出的**时机分布**（2020年代基于百成员分析的北极无冰九月日期分布、中档情景下中位数在2030年代中期、五到九十五范围横跨十年之宽）、以及——改变极端科学的2010–2020年代用法——**多变世界里稀有事件的统计量**，2015–2025年归因快速响应论文"这次热浪被变得30倍更可能了吗"的算术，它们需要对一个五十年一遇的事件开口就要一万个夏天。**多模式系综**（CMIP的30–50个模式家族、CMIP6档案2019–2024年普查）：该领域的议会，一次性采样的散布与共享的偏差，其均值只在成员因独立理由一致处才是信号（2010–2020年代独立性审计文献），其散布只在系谱校正之后才是不确定性的度量。**受约束与加权的系综**（2010–2020年代纲领：观测加权均值、涌现约束收窄、2016–2023年加权究竟有帮助还是重复计算的辩论）：让议会以证据加权的嗓音投票的尝试，其2020年代判词是温和的——加权收窄范围而对温度几乎不改变中心估计、对区域环流改变得多一些。**十年预测系统**（NMME 2011–2019年多模式初始化运行及其后继者、2020年代CMIP6初始化加扰动物理的设计）：把真正的技巧押在海洋慢模上的混合体，而其2020年代结果（5年期全球平均温度与北大西洋海表温度的技巧、多数区域降水近零的技巧）是[[climate-modelling/model-hierarchy]]一课预测对预测之辨中"预报"的诚实边界。动物园的规则：**按问题的噪声结构选择系综**——时机问题需要初始条件采样、反馈问题需要结构采样、世纪末问题需要情景采样——而2020年代的最佳实践（AR6的章节设计、百成员加多模式加SSP矩阵实验）是完整的矩阵，作为一个设计好的实验、而不是档案的意外来运行。
:::

::: definition 情景架构：SRES、RCP、SSP {#def-scenarios}
情景是气候事业把未来作为一个设计问题的遭遇，而架构已被重建过两次。**SRES（2000）**——Nakicenovic–Swart特别报告的A1/A2/B1/B2家族——是经过排放模型运行的人口-经济故事线，按构造不含气候政策（1990年代排除"稳定化"情景的决定，其最后果的政策失败是AR4之后的悔恨）、没有概率解释、只有叙事；其中A1B的中道却因可用性的意外成为2000年代文献事实上的基线。**RCP（2003–2010）**倒转了设计：四条路径（2100年辐射强迫2.6、4.5、6.0、8.5 W/m²）由综合评估模型（IMAGE、MESSAGE、MiniCAM与AIM家族）从强迫目标逆向工程出排放来产出，而2.6道的发明（2006–2010年是否添加一个激进减排RCP的辩论、裁决为添加）让2 °C目标变得可计算——并通过2009–2011年美英委员会进程与2010年Moss等、2011年van Vuuren等的论文——给了CMIP5其四道实验设计；RCP的天才是让政策目标成为自变量，其缺陷是"路径"是浓度轨迹、脱离了世界是否可能容纳它们的任何说明。**SSP（2014–2016）**完成了分离：五条**共享社会经济路径**（2014年van Vuuren–Edmonds框架论文与2016年O'Neill等的ScenarioMIP设计）描述替代的社会道路——可持续（SSP1）、中庸之路（SSP2）、区域对抗（SSP3）、不平等（SSP4）、化石燃料驱动的发展（SSP5）——与RCP式的强迫水平交叉（ScenarioMIP的九个设计实验、SSP1-1.9与SSP5-8.5在两个角上），让叙事与强迫成为显式、可组合的设计选择；AR6 2021年的预测与此后每个国家评估都在跑这个矩阵，而2020年代政策追踪文献（UNEP排放差距与NDC综合报告）对照SSP-RCP网格读当前政策，发现世界在SSP2-4.5道附近、带着SSP3-7.0的尾部风险。架构的2020年代争论填满了一个子文献：**情景现实性之争**（2023年Hope等的PNAS分析主张SSP5-8.5的化石扩张假设在经济上未出生即死，以及2023–2025年情景科学家与社会科学家辩护高排放道是为我们未选择的政策给风险划界的唯一诚实方式的回应——"我们该不该停止驱动我们害怕的那条道"之问，领域以保留该道并标注其可信度作答）；**过冲设计问题**（2018年SR1.5特别报告的1.5 °C有限过冲路径及其对世纪末负排放的依赖、2020年代对IAM机器移除成本假设的批评）；以及**低端问题**（SSP1-1.9的2050年代净零工程是否根本能在模式里表达、2020年代ScenarioMIP一代的辩论让预测的左边缘与其右边缘同样依赖模式）。
:::

::: definition 阅读扇形图：系综统计量许可什么 {#def-fancharts}
图上的缎带是一个论证，而该领域仍在学习其语法。**系综均值**只有当成员对称地采样噪声且不共享共同偏差时才是受迫信号的合法估计量——对跨CMIP的全球平均温度近似成立且有用；对区域降水、季风时机或极端常常不然，相位错误的成员的平均产出一个成员都没有的气候态（2000–2020年代关于日循环与ITCZ位置的"系综均值作为伪影"文献）。**散布**只有在校准之下才是概率：天气系综用可靠性图与逐十年膨胀校正挣得其概率；气候系综大多没有——2010–2020年代散布对真相的研究发现多模式范围舒适地覆盖了历史增暖、但对许多变量把总误差低估一到两倍（缺失的结构家族、共享的调参、[[climate-modelling/evaluation]]一课过度自信发现的未知未知），这就是为什么AR6的范围靠证据线三角验证手工加宽、而不是从模式百分位数上读、以及为什么评估语言"很可能2.5–4 °C"是一个关于物理的判断、不是一个样本的90%区间。**扇形图与缎带图**（哈德莱中心2011–2020年代十年扇形图、全球碳预算的排放路径缎带、伴随2023年记录年辩论的2023–2025年"增暖在加速吗"缎带）把受迫响应不确定性叠在无迫变率之上，而其诚实的读法是2023年的教训：一个点离开缎带证伪的是缎带的校准、不是趋势。**系综的百分位数不是风险的百分位数**——2020年代保险与央行气候压力测试文献（NGFS情景的2020–2025年迭代）痛苦发现的区分：模式系综采样的是建模者能建造的东西、不是世界能做出的东西（冰盖、永久冻土与AMOC的尾部住在多数分布之外），所以面向风险的用法需要**故事线补充**——[[climate-change/tipping-points]]一课的低概率高影响分支方法——不是百分位外推。而**情景轴是一个政策变量、不是一个随机变量**：跨SSP的散布不是拿来平均的不确定性（2020年代对"期望增暖"框架的批评——对情景平均就是对政策选择平均），而是预测最可控的维度、方差预算里一项谈判协议能够缩小的项，这就是把本课的统计与[[climate-change/emissions-budgets]]一课的算术连起来的唯一一句话：扇形图在右边最宽，因为我们是自由的，而那里的宽度不是无知、是可能性。
:::

::: example Hawkins–Sutton图：贯穿世纪的不确定性 {#ex-hawkins-sutton}
2009年那张图——按十年堆叠的方差份额，分别给全球平均温度与区域降水——是预测科学里被转载最多的图像，值得练习让你做的细读。对**全球温度**：内部变率拥有2010年代（一个十年的噪声对抗0.2 °C/十年的趋势）、模式散布拥有2030–2050年代（反馈论战时代）、情景散布拥有2070年代起（各道的分岔，到2100年SSP1-1.9与SSP5-8.5之间约4 °C，淹没了约1 °C的模式散布）。对**萨赫勒与季风降水**：模式散布主导几乎每个十年、情景份额到中叶保持很小——图的沉默政策含义是2040年代的水问题不能靠选一条道来回答、只能靠更好的模式，而瞄准本世纪中叶降水的适应资金是在拿情景形状的预算资助一个模式不确定性问题。2010–2020年代的修正与原图同样重要：分解取决于模式散布如何估计（2010年代单模式对多模式之辩——单模式扰动物理套件低估结构散布）、取决于统计量（方差份额对均值与极端不同）、取决于区域（北极海冰的情景份额到2050年是巨大的、南大洋温度几乎为零因为各道还没到那里）、以及取决于度量的非线性（方差空间的份额与度数空间讲不同的故事，2020年代传播误差文献一次安静的修正）。图唯一持久的信息，此后每一代重新挣得：**不确定性不是一个数字，而"有多不确定？"只有在"对什么、在哪里、何时、怎么测量？"之后才可回答**——本课其余部分操练的四问反射。
:::

::: example 第一个无冰九月是何时？百成员的回答 {#ex-icefree-date}
"北极何时失去其九月海冰？"之问从一次模拟无法回答——年份取决于哪次厄尔尼诺落在何时——而百成员一代（匹配SSP情景运行的CESM2-LENS2的100个成员、2020年发布，以及英国百人十年套件）把它变成系综时代的橱窗测量。2020年代分析（2020–2024年基于LENS2的时机综合与北极无冰定义之辩——2023–2025年关于"无冰"含义的共同体论文、100万平方公里对40%覆盖，因为日期随定义移动数年）交付：在SSP2-4.5式强迫下，第一个无冰九月的**中位数在2030年代末、五到九十五范围横跨2030年代到2050年代中期**；在SSP5-8.5下早十年；在SSP1-2.6下本世纪在多数成员中避免、但不是全部——单成员叙事省略的那条尾巴。结果的结构就是微型化的本课：**时机分布**（不是日期）是科学的对象；情景轴把分布的位置移动一个十年（政策移动百分位数，一句单次运行预测无法支持的话）；内部变率的宽度（固定情景下整整一个十年）不可缩减、而正是2010年代单模式预测隐藏的误差；而定义的依赖性（1%对40%冰覆盖）是"什么算极端"的诚实公共卫生类比——指标必须先被规定，概率才谈得上有意义。下游用途——2020年代航运、政策与"无冰的北极之夏"传播文献、保险式的"2040年前首次无冰"风险报价——正是大系综的存在理由：把一个吓人的轶事转换成一个有日期、有边界、情景条件化的分布，其每个百分位都能审计回一个成员。
:::

::: example 2023年SSP5-8.5现实性之争：我们该驱动我们害怕的那条道吗？ {#ex-ssp585}
2023年3月，包括GCI的Hope等在内的一群人发表了一项PNAS分析，主张SSP5-8.5——CMIP设计的高强迫道、2100年8.5 W/m²、建立在煤炭持续、天然气爆炸的化石燃料发展世界上——即使在气候政策之前在经济上也不可信，考虑到太阳能与储能成本曲线以及烧煤的健康成本算术；论文的媒体报道（"科学家：最坏情景不现实"）与共同体的回应（2023–2025年情景科学家的答辩、CMIP指导委员会相关的声明、社会-生态文献关于"不现实"对风险边界是错误的算子的介入）是情景时代关于情景**为了什么**的最纯粹的争论。技术层次依次是：SSP5自身的建造（2016年Fujisaki等与2017年O'Neill一代SSP5论文的显式设计任务书——高化石对应道之被请求，恰恰因为RCP8.5作为基线的使用招致了2013–2016年"它正在变成自我实现的照常营业"的批评，设计意图是给风险划界、不是预报）；经济学（2023年论文的成本优化运行对反读：未定价的健康损害、能源服务不平等与地缘政治煤炭复活路径——2020年代乌克兰战争后的油气煤价格冲击作为十年的讽刺——让高排放世界保持可达）；以及统计学（一个情景的概率在一次性未来里没有定义，所以"现实"只能意味着"与某个可信的人类行为模型一致"，而SSP5-8.5靠几个可信的模型过了那道杠——停滞的气候政策、资源租金国家、供应安全政治）。领域实际达成的解决是程序性的：保留该道用于划界、停止把它用作基线（2020年代CMIP与国家评估把SSP5-8.5标注为"仅用于风险管理"的实践）、并把可信度论证与预测并列发表——情景轴终于被当作定义所要求的设计好的政策变量，而2023年之争教会一代用户：扇形图的右端是一个关于恐惧的选择、不是对恐惧的预报。
:::

::: example SR1.5的路径：谈判出一个数字的系综 {#ex-sr15}
2018年特别报告的1.5 °C有限过冲路径——成为运动口号与2020年代净零法律算术的约420 Gt CO₂剩余碳预算数字（67%置信变体）——是系综方法被推到其政治极限，而其建造是本课的综合案例。机器：IPCC的情景数据库（来自MESSAGE、IMAGE、REMIND、WITCH与GCAM家族的数千条IAM路径，对照简化气候模型运行——[[climate-modelling/box-models]]一课的MAGICC线仿真器——校准到CMIP5一代的ECS与热吸收分布），按报告的定义过滤（过冲意味着超过1.5 °C然后在2100年回落，其宽松性——2019–2025年批评指出"1.5 °C有限过冲"容许多十年、多影响的超越——活在路径选择里、不在物理里）；不确定性堆栈（预算的宽度来自ECS散布、海洋热吸收与非CO₂强迫项、以及负排放依赖——2019–2025年文献发现多数路径需要无先例规模的二氧化碳移除、AR6第三工作组2022年章节令人清醒的可行性对照）；以及解释断层（2019–2024年主张67%预算是一个装扮成目标的抛硬币、"有限过冲"使越限正常化、而预算的算术悄悄假设[[climate-modelling/earth-system-models]]一课的碳循环反馈保持线性）。系综解读的教训推广到此后每个头条预算与缎带：数字是一个**合取**——一个气候定义、一个仿真器校准、一个IAM成本结构、一个风险容忍度，各自可审计、没有一个是物理本身——而诚实的用法是说出这个合取，这是评估的决策者摘要在其压缩中结构上做不到的事。
:::

::: history 从Lorenz的蝴蝶到SSP矩阵 {#hist-ensembles}
**1963–1994**：Lorenz 1963年发现敏感依赖与其1969年"可预测性"论证找到了初值的天花板；1974年联合组织委员会的提案与1980年代CRU和GISS的多模式比较发明了模式散布采样；而ECMWF 1992与NCEP 1994的业务系综预报系统让扰动初始条件的概率成为日常业务产品。**1995–2010**：情景时代开始——1992–1997年IPCC情景进程与2000年SRES发布（无政策的叙事设计与排除稳定化的决定）、2001–2005年RCP的发明（2003年O'Neill–Lacis逆向工程概念、2006–2010年多模式设计委员会、2010年Moss等的RCP论文）、2009年Hawkins–Sutton分解、以及让系综成为两者标准货币的2009–2011年碳循环约束与检测归因扩张。**2011–2019**：大系综时代——2011–2012年社区大系综的34个成员与2011–2019年NMME十年系统、2014–2016年SSP框架论文（2014年van Vuuren–Edmonds叙事、2016年O'Neill ScenarioMIP设计与SSP5姊妹论文）、建立在百成员反事实上的2015–2019年归因快速响应时代、以及2018年SR1.5的情景数据库-仿真器机器谈判出该领域历史上被引用最多的数字。**2020–2025**：百成员与SSP矩阵一代（2020年社区大系综第2版发布、AR6 2021年全矩阵预测、2022–2025年各国与央行压力测试情景计划、2023年SSP5-8.5现实性之争与2023–2025年记录年缎带辩论）——系综时代完工，其统计在政策中承重，而其最古老的问题——散布应该意味着什么？——比以往任何时候都更有后果。
:::

## 检验你的理解

::: quiz {#quiz-ensemble-mean}
多模式系综均值是受迫响应的可信估计：
- [ ] 总是，因为平均消除一切误差
- [x] 当成员的误差对所讨论的变量独立且无偏时——对全球温度常常成立、对区域降水型常常不成立
- [ ] 从不，因为模式不独立
- [ ] 只有在按技巧加权之后

::: solution :::
平均消除噪声、不消除偏差，而且只有当噪声跨成员独立时才消除噪声——对跨CMIP家族的全球平均温度，这个近似管用（均值在几百分之一度内跟踪观测趋势），对季风位相、日循环与双ITCZ易发的降水，成员的误差相关而相位打乱的平均产出成员都没有的气候态。信任的检验是误差结构、不是样本量——"系综均值作为伪影"文献常设的警告。
:::
:::

::: quiz {#quiz-rcp-names}
RCP的名字（2.6、4.5、6.0、8.5）指的是：
- [ ] 工业化以来的年数
- [x] 2100年以W/m²计的辐射强迫目标，由综合评估模型逆向工程成排放路径
- [ ] 增暖的度数
- [ ] 年排放的Gt CO₂

::: solution :::
RCP是强迫优先设计的：综合评估模型被倒着运行以在2100年命中2.6–8.5 W/m²，而排放、土地利用与气溶胶路径随之掉出——这个倒转让政策目标成为CMIP5设计的自变量，而SSP保留了它并添加显式的社会叙事，因为一条浓度轨迹本身对产生它的世界一无所讲，而这正是SSP-RCP网格（SSP2-4.5、SSP5-8.5）现在编码的东西：一个故事与一个目标，共同设计。
:::

## 练习题

::: exercise {level=1 check="9"}
**噪声缩减。**一个区域夏季温度每个成员有0.9 °C的内部变率散布。需要多少初始条件成员才能让系综均值的噪声达到0.3 °C？
::: solution :::
N = (0.9/0.3)² = **9**——给每个大系综项目标价的平方根定律（2010–2020年代百成员一代把噪声买到十分之一度，此时模式与情景项主导、更多成员什么都买不到）；练习的职业习惯：在问"系综怎么说"之前，先问"它有多少个有效成员？"——答案常常远少于图上的点数。
:::
:::

::: exercise {level=1 check="0.5"}
**方差份额。**对一个2050年代降水预测，方差分量是：内部0.09、模式0.16、情景0.25（mm²/天²）。情景份额是多少？
::: solution :::
0.25/0.50 = **0.5**——一半方差来自排放道，而四标签纪律（变量、区域、时距、统计量）被题目的措辞满足；注意对同一区域2030年代的预测，情景项将几乎为零，这正是Hawkins–Sutton时间轴的全部要点：不确定性有一本日历。
:::
:::

::: exercise {level=1 check="4"}
**归因赔率。**一次热浪在工业化前控制系综里每年有五十分之一的概率。在当代系综里其速率是十二点五分之一。风险可归因倍数（当代/工业化前概率比）是多少？
::: solution :::
(1/12.5)/(1/50) = **4**——2015–2020年代归因快速响应信件的"风险变为四倍"陈述，作为同一模式两个系综的概率之比来计算（反事实设计的长处：模式误差在比值中大部分抵消，不像绝对预测），以及唯一进入日常语言的系综统计量——要查公开版本是否提到它是一个风险倍数、不是一个"该事件本不会发生"的主张，后者是系综说不出来的。
:::
:::

::: exercise {level=2 check="16"}
**十年预测技巧。**如果初始化的十年预报在解释北大西洋海表温度第5年观测方差的36%，异常相关是多少？
::: solution :::
r = √0.36 = **0.6**——NMME一代技巧表背后从方差到相关的算术（及其诚实的读法：第5年r = 0.6对海洋的慢模是真实的技巧、对区域降水几乎一文不值，同样的系统在那里得分近零——2020年代十年预测文献对"初始化海洋买到什么"逐变量而小心的判词）。
:::
:::

::: exercise {level=2 check="0.2"}
**有效成员。**一个25成员的多模式系综其误差的成对模式间相关为ρ = 0.8。其有效样本量N_eff = N/(1 + (N−1)ρ)是多少？
::: solution :::
N_eff = 25/(1 + 24 × 0.8) = 25/20.2 ≈ **1.2**——一个公式里的系谱校正：在80%共享误差下，25个模式携带的信息勉强多过一个，2010–2020年代独立性审计文献证明CMIP议会的投票权只是其人数的一小部分、也是系综加权与约束计划存在的原因。
:::
:::

::: exercise {level=2 check="10"}
**时机分布。**中档情景下一个100成员系综的首个无冰九月分布以2038年为中心、5–95%范围为2031–2051年。如果一份政策文件引用"2035年前北极无冰"，它隐含地主张哪个百分位？
::: solution :::
2035年位于该分布约15–20百分位附近——练习的素养要点：从时机分布摘取单日期的主张是装扮成预报的百分位选择，而每个风险报价的职业之问（"到何时、以多大置信？"）恢复那个隐藏的百分位；2020年代北极无冰传播文献的风格指南，浓缩在一个数字里。
:::
:::

::: exercise {level=3 check="0.31"}
**预算合取。**一个1.5 °C碳预算的不确定性由大致等权的项主导（敏感度、热吸收、非CO₂强迫、碳循环反馈）。把总误差当作正态，真实预算比引用的中心值低半个标准差以上的概率是多少？
::: solution :::
P(Z > 0.5) = **0.31**——三分之一的机会诚实预算明显小于头条数字，仅来自卷积、在任何结构意外之前；练习的内容是引用预算的置信陈述是物理与结构不确定性之和，而任何单项的误差（更低的ECS、[[climate-modelling/earth-system-models]]一课更强的碳反馈）就把它移动五分之一——SR1.5批评的算术显示"预算不是自然常数"是一个计算、不是口号。
:::
:::

::: exercise {level=3 check="1.5"}
**2100年情景对模式散布。**在SSP1-1.9与SSP5-8.5下，2100年增暖为1.4与4.4 °C；每个情景内的模式散布为±1.0 °C（1σ）。情景半距对模式散布之比是多少？
::: solution :::
半距(4.4 − 1.4)/2 = 1.5；比值 = 1.5/1.0 = **1.5**——在这个配置下2100年全球温度的选道超过选模1.5倍（而在方差项上多得多，(1.5/1.0)² = 2.25），Hawkins–Sutton世纪末机制表达为一个比值——以及练习的审计习惯：从图自身的数字重算这类比值，因为已发表扇形图的宽度被证据线判断手工加宽（AR6的实践），而原始模式散布比诚实范围窄。
:::
:::

::: exercise {level=3 check="2.25"}
**方差比。**对上一题的配置，2100年情景方差对模式方差之比是多少？
::: solution :::
(1.5/1.0)² = **2.25**——世纪末全球温度的情景方差是模式方差的两倍多，这个数字一次终结两个论证（"模式不一致所以预测无用"，以及"模式不确定所以情景不重要"），它们各自在错误的十年、错误的变量上是错的——四标签分解，完成。
:::
:::

::: warning 系综的四种谬误
1. **"系综散布就是不确定性。"**它是系综看得见的不确定性：共享的调参、缺失的结构家族、缺席的过程（冰盖崖、突然的永久冻土、AMOC尾部）与未知未知全都住在缎带之外，而2010–2020年代校准研究的判词——对历史记录的覆盖尚可、总误差对许多变量被低估一到两倍——意味着系综百分位数是诚实范围的下限、不是范围本身；评估的手工加宽是一个特性、不是糊弄。
2. **"更多成员缩减不确定性。"**成员以1/√N缩减噪声项、别无其他；2020年代百成员一代自己的论文写明了交叉点——超过几十个成员，初始条件采样买到的是时机精度、不是预测收窄，算力最好花在结构多样性、分辨率或情景覆盖上；谬误既是统计的也是预算形状的（那些把"1,000个成员"当作不确定性是个采样问题来许诺的经费申请）。
3. **"情景是一个预测。"**SSP5-8.5不因在图上就更可能，SSP1-1.9因在边缘就不是幻想；各道是不附概率的设计好的政策变量（2023年现实性之争持久的教训），而两个对称的错误——拿高道当基线、或斥其不现实而删掉它——都是拿一个统计量洗白一个规范性选择，而这正是情景架构被重建两次要防止的唯一一件事。
4. **"系综均值是最佳估计。"**对跨大体独立家族的全球温度，可用；但对任何有相位、型或阈值的东西——季风、日循环、无冰日期、翻转要素——相位错误的成员均值是一个成员都不产出的气候态、一个任何系统都不暗示的日期，而与阈值相关的对象是分布的形状（双峰性、尾部、首达时），平均把它摧毁；扇形图的中线是图上被读得最多、信息最少的那一笔。
:::

## 总结

::: summary
系综时代用一个对不确定性三个账户的设计采样取代了单一预测——内部变率（σ/√N、百成员一代的时机分布、归因的风险倍数）、模式不确定性（参数的、以及在方差上四比一的结构；由模式议会采样，而系谱校正把其有效规模砍到寥寥数个）、以及情景选择（SRES叙事的无政策设计、让2 °C可计算的RCP强迫目标倒转、SSP叙事交叉强迫的矩阵、以及2023年SSP5-8.5现实性之争的和解：保留该道用于划界、标注为风险管理、绝不当基线）。Hawkins–Sutton分解组织起全部：不确定性有一本日历和一幅地理——噪声拥有2010年代、模式拥有本世纪中叶、而人类的自由拥有世纪末——所以系综的统计量必须按变量、区域、时距与统计量来读：均值只在误差独立处被信任、散布靠证据线加宽而不是当作概率来读、百分位要审计回成员及其定义（"无冰"的定义一动，北极无冰日期就移动数年）。扇形图是一张把物理、计算与人类的选择装进一幅图像的论证，而本课建立的素养——四标签分解、有效成员计数、隐藏的百分位、情景作为政策变量——就是使用预测与被预测使用之间的区别。
:::
