全球气候模型以百公里网格为代价回答全球问题，而影响不住在网格上：洪泛平原、一个小麦县、城市热岛的夜晚、雷暴的列车效应，全都发生在驱动模型从未见过的尺度上，这就是本课方法要攻击的尺度问题。降尺度事业自1990年代以来以两族运行——**统计的**，从观测中建造从粗预报量到细预报元的映射（1980–1990年代的回归与"完美预报"谱系、天气生成器、以及2000–2010年代成为每个影响研究主力的分位数映射偏差校正机器），以及**动力的**，在全球模型内部运行一个区域模型、让物理自己细化画面（1990–2000年代的限制区域一代——英国的HadRM3、2005年欧洲PRUDENCE系综、2011–2015年CORDEX设计及其标准域与其2020年代25公里第二阶段）——加上正在到来的第三族：**机器学习的降尺度**，其2016–2023年超分辨率网络产出的场看起来对、而2022–2025年物理一致性批评警告，行为不总是对。2010–2020年代的对流许可一代（英国2016年CP4CIP实验与2010年代末–2020年代的4公里国家预测）交付了该领域最骄傲的结果——粗模型一直抹掉的逐小时极端降水强度的翻倍——与其最让人谦卑的结果：区域系综的散布不小于驱动它们的全球模型，所以降尺度锐化画面而不解决争论，"散布悖论"与2021年Douglas–Pendergrass质疑区域预测是否增加价值的批评构成了十年定义性的方法辩论。本课是类型学、机器与诚实的核算：每个降尺度族假设什么，CORDEX的设计买到与买不到什么，偏差校正能修好与能洗白什么，以及如何分辨——每个适应计划里每张降尺度地图底下那个问题——更多的分辨率何时是更多的信息、何时是更多的信心。先修是[[climate-modelling/numerical-methods]]一课的网格与参数化逻辑与[[climate-modelling/ensembles-scenarios]]一课的不确定性记账；回报是带着精确的感觉阅读一张影响地图的彩色小方块：其中哪些信息来自观测、哪些来自物理、哪些来自希望。

::: definition 三个家族：动力的、统计的、以及混合的 {#def-families}
**动力降尺度**运行一个区域气候模式——与全球模型相同的基本方程机器、细化的网格、复杂地形与表面、由较粗驱动者供给的侧边界（从1980年代中尺度模型经过1990–2000年代HadRM3、REMO、RCA与RegCM一代到CORDEX标准化的50公里与12公里两层、2011年Giorgi–Gutowski设计框架、以及2020年代对流许可试点域）——让重力、对流与锋面在更细尺度上被计算、不是被推断；其承诺是机制，其代价是算力与边界依赖。**统计降尺度**从观测记录学习或规定从粗状态到细响应的映射：1980–1990年代把网格箱天气对站点气候回归的"完美预报"、天气分型谱系、2000–2010年代天气生成器（STAR与CLIMGEN线及其气候变化情景、2020年代随机极端后继者）合成统计匹配受扰观测气候的逐分钟序列，以及——该族的大宗产品——**偏差校正**（2000–2010年代分位数映射谱系、2013–2020年代"偏差校正修不好趋势"文献及其2020年代多元与copula推广）重塑模式的分布到观测的分布、并悄悄假设映射是平稳的。**混合与第三条路**填充其间的空间：2000–2020年代准全球与区域敏感性方法（扰动再分析做事件归因）、影响实践的尺度变化或Δ方法（把GCM的分数变化应用到观测的细基线上——最便宜的降尺度与使用最多的），以及2016–2025年机器学习超分辨率网络（GAN与扩散模型文献、2023–2025年"物理一致深度学习降尺度"论文）从细观测学习细场、而练习显示它们统计上出色、动力学上未经验证。定义的边界说一次，因为文献不断把它抹糊：**偏差校正不是降尺度**——它校正一个粗网格箱的分布而不添加一米空间信息——而"降尺度"意味着靠物理、靠观测的细尺度结构、或靠假定的统计关系增加分辨率，一张地图用了三者中哪个是其用户该问的第一个问题、也是其方法部分通常最后才回答的问题。
:::

::: definition 统计机器：完美预报、分位数映射、天气生成器 {#def-statistical}
**完美预报回归**（1980–1990年代学派、2000–2020年代MOS后裔的实践）把站点预报元回归到粗预报量——"这里的二月降雨等于3.2 × NAO指数 − 1.1 × SLP梯度 + 噪声"——而其失败模式是非平稳：关系在历史气候中估计、在未来气候中应用，如果遥相关结构移动（2000–2020年代关于ENSO与季风联系减弱与迁移的发现），回归就在无警告的情况下在其定义域之外外推；2010–2020年代的最佳实践是按物理过程选预报量、并在一个变暖的子样本外验证，不是最大化历史R²。**分位数映射**——主力——把模式的历史分布排序到观测的分布上并对未来应用同一转移：它按构造修好均值、方差与分布形状，而2010–2020年代批评文献（从2013年Teichler与2014年Lange论文起的"偏差校正不能创造趋势"线、Cannon等的2020年代多元与copula校正）精确确立了它的极限：它修不好错误的环流（一个错过密史脱拉风的模式在任何单调校正后仍会放错其风电场）、修不好被错误动力学驱动的趋势（过弱的急流位移保留下来，只是被重新缩放），而它的单变量形式破坏变量间与站点间的依赖，除非显式重建。**天气生成器**（2000–2020年代STAR/CLIMGEN/MIMES线）完全丢弃模式的时间序列，只保留受扰的观测统计量，为水文学合成分钟分辨率的人造十年——2020年代的批评是它们继承GCM的均值与方差变化、而其时间结构一无所获（2010–2020年代关于风暴排序与多年干旱成簇的"持续性平稳性"发现，水库设计最在乎的风险）。**深度学习降尺度**（2016–2025年超分辨率文献：在再分析-观测对上训练的对抗与扩散网络、2023–2025年以RCM百万分之一算力从CMIP产出4公里日场的论文）交付锐利的统计量，而按2022–2025年物理一致性审计（水量收支与环流违背发现、"网络幻觉出从未在训练地形中出现的山的背风坡"泛化检验），会违背守恒、在未见过的强迫下不可预测地外推、以及——最深的问题——学习整个练习假设其平稳性的历史细尺度结构；2020年代的综合（含练习的算术）是：这些网络是其被训练映射的出色仿真器、却是降尺度唯一目的那件事——训练数据从未包含的气候——的未验证仪器。
:::

::: definition 区域气候模式：边界、驱动、与增加价值之问 {#def-rcm}
区域模式的大气是一个开放系统：其侧边界（1985年Davies松弛方案及其2000–2020年代嵌套连续的后继者）被驱动者按住，其内部自由发展，而该方法存在的一切理由都活在那个缝隙里——西非的中尺度对流复合体、安第斯迎风坡的地形降水、地中海海风对流、阿尔卑斯与喜马拉雅的雪线——驱动者一百公里网格箱把它们抹成单调的混合。2000–2020年代**增加价值文献**（2008–2020年代"增加价值"辩论的综合评估、2016–2023年CORDEX诊断框架）在物理需要分辨率的地方找到了它：极端降水强度及其日循环（2007–2020年代Fischer等与Wehner谱系显示粗模型对日极端的系统性低估）、复杂地形中的风与温度型、以及锚定该领域信心的2016年CP4CIP结果——在4公里对流许可分辨率（2016年Fowler等发在Nature的英国亚日极端论文），逐小时降雨强度相对参数化对流的运行上升数十个百分点到翻倍，位移集中在旧网格完全无法表达的夏季雷暴机制。该方法的结构弱点同样被测绘清楚：**边界误差传播**（2010–2020年代研究区域系综散布有多少继承自其驱动者——常常是大半，"RCM作为其驱动者的花哨偏差校正器"批评）、**单驱动问题**（一次区域运行继承其母体的环流偏差、更糟的是其母体的情景与内部变率彩票——2020年代大系综驱动设计，从数十个全球初始条件运行区域模型以分离两者）、以及**散布悖论**（2010–2020年代CORDEX发现区域系综的模型间散布系统性地小于驱动它们的全球系综——区域模式彼此比其父母更一致，而2020年代审计文献的判词是一致部分反映共享的驱动者与共享的方案、不是趋同的真相）。2021年**Douglas–Pendergrass批评**（GMD论文与其引发的2021年6月仪器之辩，附CORDEX共同体2021–2023年答辩）把问题锐化成一个决策规则：对许多影响问题——按全球平均缩放的极端、多数区域的温度——一个偏差校正的全球模型做得和贵一百倍的区域运行一样好，而区域模式挣得其算力的地方恰在本课的练习与示例所定位之处：对流许可的极端、复杂地形的风与降水型、以及统计量无法回答的过程问题。
:::

::: definition 诚实的核算：验证、不确定性与决策检验 {#def-accounting}
降尺度的评估继承[[climate-modelling/evaluation]]一课的逻辑加一个区域转折：平均态偏差比全球模式的更大（区域模式臭名昭著的双ITCZ继承、2000–2020年代非洲与季风亚洲的降水位移偏差、2019–2023年热浪文献不断重开的欧洲夏季干偏差之争），极端检验必须意识到分辨率（12公里模式的日降水极端不与4公里的相比，除非用2010–2020年代的亚日拆分校正），而验证数据恰好在降尺度要紧的地方稀疏（2020年代发现非洲与高亚洲的站与雷达覆盖无法支撑适应计划假设的验证——数据密度梯度是该领域最安静的结构性不平等）。2010–2020年代的不确定性记账（Hawkins–Sutton后代扩展到区域尺度、CORDEX系综的2020年代方差划分）添加全球分解没有的两项：**区域模式散布**（按悖论小于全球散布，因此不是更宽而是更窄的诚实范围、其覆盖必须对照全球父母与观测一起检验）以及**方法散布**——2010–2020年代"方法与模式同等重要"的发现，对偏差校正方案、天气生成器与降尺度族的选择对降水极端与水文影响贡献与模式选择本身相当的散布（2020年代多方法互比令人不适的结果：两个分析师可以靠选择不同的管道从同一个全球模型产出合法不同的2050年代洪水统计量）。2010–2020年代以决策为中心的评估文献（[[climate-change/impacts]]一课的Dessai–Brown–Lempert谱系应用到方法上）提供最终检验：降尺度的正当性不在每公里的分辨率、而在**决策价值**——更细的信息是否改变一个决定（粗模型的百分位错过的排水设计阈值、校正后的全球模型差一个容量因子之值的风电场发电量），如果不改变，最便宜的诚实方法获胜，这是对2021年算力浪费批评的职业回答，同样也是每个适应计划方法部分都应存活的审计问题：粗方法本来会决定什么，是一样的吗？
:::

::: example CP4CIP：4公里在英国的夏雨里发现了什么 {#ex-cp4cip}
2016年UKCP18对流许可实验——4.5公里HadUK模型在英国上针对现在与未来的夏季运行，2016年Fowler等发在Nature的论文是其定义领域的结果——是降尺度最干净的自然实验，因为比较是同一个模型、同样的边界、同样的物理，只有网格不同：在12公里，积云参数化处理对流并产出熟悉的粗模型签名（小雨过于频繁、大雨强度不足、日循环峰值早几个小时）；在4.5公里，对流是显式的，夏季降雨分布重新组织——亚日极端的逐小时强度相对参数化运行上升数十百分点到翻倍、虚假的毛毛雨消失、日循环峰值咔哒一声对上观测的傍晚。2016–2025后续文献（2019–2023年闪洪预见期与地表水洪水应用、2022–2024年雷暴临近预报交叉、2020年代CORDEX试点的欧洲4公里姊妹运行）把结果推广到各对流机制并且——重要的是——为它划界：强度位移对短历时暖季极端最大、对粗模型已经处理好的冬季锋面系统很小，这正是决策检验自己的算术——冬季主干管线设计者什么都不需要新东西、城市排水工程师则需要一切。实验的政策尾巴（英国2021–2022年地表水洪水规划、2023–2025年引用亚日缩放的排水标准修订）是该领域的证明：降尺度改变的不只是地图还有涵洞——以及它的告诫：参数化惯例一代的极端统计量，被嵌进一代适应指南，恰恰对适应所为的那些事件系统性地偏低。
:::

::: example 2021年算力浪费之争：区域模式挣得其运行吗？ {#ex-compute-fight}
2021年6月，Douglas、Pendergrass等在GMD的一篇论文以该领域一直回避的直白形式提出了预算问题：对美国温度与许多降水与热指标的变化预测，区域模式的答案与偏差校正的全球模型差得足以证明多一到两个数量级的算力吗——而对相当大一部分变量，回答是不，区域模式增加的空间细节大体不存在于影响研究实际消费的预测信号统计量中（该发现的媒体时刻、E&E News的报道，以及CORDEX共同体2021–2023年答辩——Fischer–Coppola领衔的回应、增加价值综合评估、对流许可的辩护——构成十年最有用的方法争论）。到2024年文献达成的和解比任何一方的头条都更有价值：批评对**大尺度温度与平均信号问题**为对（区域模式如批评者所说是一个昂贵的其驱动者的偏差校正器），对**对流极端**为错（CP4CIP一类结果，粗模型的答案不只是更粗而是错的），而对**型问题**（风资源、火险天气、物种-气候关系）规定不足，其价值取决于决定是否使用那个型——定义里的决策检验被应用到领域自身。之争的持久产出是方法论的：2020年代从多个驱动者与初始条件运行区域系综的实践（大系综驱动设计分离继承的与生成的不确定性）、CORDEX-Plus时代提案中显式的成本效益框架、以及2000–2010年代文献中12公里单驱动单情景区域运行的安静重分类——数千篇论文，其设计被争论揭示为对其声称回答的问题不可解读，本课最昂贵的一课。
:::

::: example 深度学习降尺度：出色与幻觉出来的山 {#ex-ml}
2016–2025年机器学习降尺度文献——从2016年降水场的对抗超分辨率经过2020年代扩散模型生成器到2023–2025年以笔记本一小时的推断产出公里分辨率大陆日场的论文——是该领域最壮观也最受审计的方法，而审计（2022–2025物理一致性谱系）点名了坏掉的东西。起作用的：网络重现观测的细尺度统计量——空间谱、极值分布、地形对降水的印记——好于RCM而只用其一小部分算力，而2023–2025年"降尺度大数据"计划（能源部与国家气象部门的工作）现在在CMIP数千年产品量级的再分析档案上训练。坏掉的，按审计的顺序：**守恒违背**（降尺度后的水量收不拢——被推出分布时既不对母体水汽通量、也不对地形雨影做质量平衡的生成降水场）、**外推失败**（在历史气候上训练的网络在其从未见过的高CO₂场下不均匀地退化，2023–2025年理想化扰动检验显示误差比粗模型自己的增长更快）、以及**平稳性继承**（网络学习历史的预报量-预报元映射——正是2010年代统计降尺度批评花十年记录其为遥相关之假的那个假设——以更高的容量与更令人信服的误差棒）。2024–2025年综合，练习的算术将重构它：深度学习降尺度最好被理解为细尺度映射的学习仿真器，在未来类似训练气候的地方出色、在其不像的地方未验证、而在混合服务中最可辩护——作为RCM产出的后处理器（从12公里场仿真4公里场，2023–2025年"动力产出的学习降尺度"论文）、而不是作为物理的替代，恰恰在被增暖且前所未有的机制里，统计量与映射都最不可信。
:::

::: example Δ方法与喜马拉雅水电问题 {#ex-delta}
最便宜的降尺度——尺度变化或Δ方法，把全球模型的分数变化应用到观测的细记录——也是影响实践中使用最多的，而2020年代喜马拉雅与安第斯的水电与灌溉研究显示了它诚实的长处与沉默的假设。算术（练习会让你做）：一个流域观测的月径流序列、驱动系综预测的降水变化与温度驱动的雪线位移、一个度日或简单雪模型，设计统计量就在站点分辨率上掉出来，不用RCM运行也不用偏差校正管道——对世纪中叶水库定容，常常是其不确定性内与决策相关的答案，而2020年代互比（多方法喜马拉雅水文学项目）证实Δ方法的流量在年与季总量上位于RCM驱动管道的散布之内。沉默的假设是该地区物理咬人之处：方法假设变化是对未变的变率结构的一个平滑乘子，而喜马拉雅2020年代文献的警告恰恰关于结构——融雪时机的位移（改变灌溉日历多于年总量的春季峰值提前）、乘子无法表达的冰湖与季风对流极端、以及变化的海拔依赖（随一公里海拔变化的增暖与降水位移，被流域平均的Δ抹平）。2020年代水部门实践达到的职业化解是分层的：Δ方法用于筛选与敏感性，RCM或对流许可产出用于决策对阈值与结构敏感之处（2022–2025年为大型大坝可能最大洪水修订的高分辨率喜马拉雅运行），而学习降尺度随其审计成熟进入中间层——定义的决策检验作为一条采购梯子在运行，每一层的假设都写下来，这是三个家族共享而其用户摘要很少写足的唯一要求。
:::

::: history 从完美预报到对流许可 {#hist-downscaling}
**1980–1990年代**：统计学派先到——1980–1990年代完美预报与天气分型谱系（亥姆霍兹与爱尔兰学派2000–2010年代后期的回顾把现代领域定在1990年代）、1996–2000年代天气生成器成熟、以及1990年代限制区域模型（1995–2000年HadRM2–HadRM3一代驱动各国情景研究）确立动力降尺度为大陆预测的主力。**2000–2010**：系综与标准化时代——2001–2005年PRUDENCE欧洲区域系综（第一次多模型区域互比及其散布对驱动者的发现）、2004–2010年分位数映射作为影响管道默认的采纳（及其2008–2010年代对其趋势盲视的早期批评）、以及2007–2010年代首批对流许可气候运行（2006–2009年英国与瑞士4公里可行性实验）。**2011–2019**：CORDEX（2011年Giorgi–Gutowski框架论文、2012–2020年代协调的域与50和12公里两层）让区域降尺度成为共同体实验；2013–2016年偏差校正批评文献（Teichler与Lange论文及后继）画出方法的边界；2016年CP4CIP与Fowler一代结果落地对流许可的翻倍；而2016–2019年国家对流许可计划（2019年UKCP18发布、瑞士与德国4公里业务）把方法从实验移入服务。**2020–2025**：审计与决策时代——2021年Douglas–Pendergrass算力浪费批评与2021–2023年答辩、2020年代大系综驱动区域设计与CORDEX-Plus/轻量策略、2022–2025年深度学习降尺度的物理一致性审计及其混合服务转向、以及2023–2025年决策价值框架成为适应计划方法部分的标准——领域的问题从"网格能做多细"成熟为"细度改变什么、为谁、以多少算力"，一个后果的科学本应从一开始就问的问题。
:::

## 检验你的理解

::: quiz {#quiz-spread-paradox}
区域气候系综的"散布悖论"是：
- [ ] 区域模式彼此比全球模式更不一致
- [x] 区域系综彼此比驱动它们的全球系综更一致，部分因为它们共享驱动者与方案——所以其更窄的范围不是自动更诚实的不确定性
- [ ] 区域模式根本没有散布
- [ ] 偏差校正消除了区域散布

::: solution :::
CORDEX时代的发现是区域系综散布系统性地小于喂养它的全球系综——部分是真实的物理趋同，部分是共享的出身（驱动者、情景、继承的内部变率状态）与共享的方案夸大了一致性。审计推论：一个降尺度范围的可信度必须对照父母的散布与观测一起检验，绝不能当作分辨率挣来的更紧区间——2021年算力浪费批评的统计脊梁。
:::
:::

::: quiz {#quiz-qm}
区域模式降水对观测的分位数映射不能修好：
- [ ] 模式的均值偏差
- [ ] 模式的方差偏差
- [x] 一个模拟错的环流——缺失或错位的风系统在任何单调重缩放后仍然是错的
- [ ] 模式的极值分布

::: solution :::
分位数映射按构造修好分布——均值、方差、形状、极端——这是它的吸引力也是它的欺骗：它作用于网格箱的边缘分布、不是流场。一个把密史脱拉风路径放南200公里、错过地形雨影、或搞错季风位相的模式，产出的是一个错误天气的校正分布，而2010–2020年代趋势与环流盲视批评（"偏差校正不能创造趋势"文献）把先查动力学再查校正变成了标准实践——决策检验的练习级版本。
:::

## 练习题

::: exercise {level=1 check="625"}
**网格算术。**一个100公里全球模型网格箱里能装下多少个4公里模型单元？
::: solution :::
(100/4)² = 25² = **625**——4公里一代每个母网格箱买到的单元数，以及按细化立方缩放的算力账单（625个单元配四分之一的步长：2021年算力浪费批评的分母在一个数字里），这就是领域在一个国家、不是全球上跑4公里的原因，也是学习降尺度仿真器百万倍推断加速值得审计的原因。
:::
:::

::: exercise {level=1 check="1.4"}
**尺度变化方法。**观测的流域平均径流是500 mm/年；驱动系综预测2050年代降水变化+14%、径流成比例响应。降尺度后的2050年代径流是多少mm/年？
::: solution :::
500 × 1.14 = **570**——Δ方法的全部算术，也是它全部的认识论：如果变化是一个均匀乘子就正确，对喜马拉雅文献说最要紧的融雪时机位移、海拔依赖与改变的变率则保持沉默——练习在一个乘法里同时是方法的长处与其批评。
:::
:::

::: exercise {level=1 check="2"}
**分位数映射。**模式历史的日降水95百分位是40 mm；观测把它放在80 mm。在线性分位数映射下，未来模式值60 mm变成什么？
::: solution :::
转移把模式的分位数翻倍：60 × (80/40) = **120**——乘法形式的行为让它对降水流行、对趋势危险：校正的增益也乘以模式的未来变化，所以一个极端趋势过弱的模式保持过弱（被重新缩放），一个有伪趋势的把它放大保持——2010年代批评的算术，一行可检验。
:::
:::

::: exercise {level=2 check="0.5"}
**继承的散布。**一个由单一全球模式与初始条件驱动的12成员区域系综对其2050年代季风降雨预测显示方差0.36，其中结构性（区域模式）方差为0.18。方差中有多大比例继承自驱动者？
::: solution :::
(0.36 − 0.18)/0.36 = **0.5**——一半散布是父母的，而父母自己的系综已经跨越了它：单驱动区域预测在全球答案固定处采样区域模式问题，而2020年代大系综驱动设计的存在就是为了拆开两者——练习是散布悖论机制的一次减法。
:::
:::

::: exercise {level=2 check="7.5"}
**天气生成器。**一个合成人造十年生成器匹配观测的日均值方差与观测的滞后1自相关0.6。一段30天里有效的独立天数是多少？
::: solution :::
n_eff = n(1−ρ)/(1+ρ) = 30 × 0.4/1.6 = **7.5**——2010–2020年代排序批评针对的持续性算术：匹配滞后1不匹配复合事件的成簇（2020年代发现生成器低估多周干旱连段与风暴序列，因为观测的成簇是非线性、机制驱动的），而水库设计恰恰生死于生成器抹平的那条尾巴。
:::
:::

::: exercise {level=2 check="0"}
**域外的完美预报。**1980年代一个站点降雨对两个预报量的回归解释历史方差的65%。如果未来气候把一个预报量移到其历史范围之外，外推可辩护的R²最大是多少？
::: solution :::
**0**——在训练域之外，回归是一个未经检验的线性延续，诚实可辩护的外推R²是不可量化、不是0.65；练习的要点是2000–2020年代非平稳文献的规则（按过程选预报量、在变暖子样本上验证、外推要标记），而同一条规则如今管辖着作为其高容量后裔的深度学习网络——2023–2025年审计论文的扰动检验就是工业规模的这道练习。
:::
:::

::: exercise {level=3 check="1.4"}
**决策检验。**一次4公里运行把城市排水使用的50年逐小时降雨强度从80提高到112 mm/hr。设计强度变化多少倍？
::: solution :::
112/80 = **1.4**——设计标准跳升40%就是决策价值的定义（CP4CIP一类结果的政策尾巴：排水规范修订、涵洞重新定径、参数化惯例一代的指南被揭示为恰恰对适应所为的事件系统性地偏低），而练习正确地倒转了2021年算力之问：区域运行在其百分位移动设计表的时候、在那些地方挣得其算力——对冬季锋面雨它们大多不移动、对夏季对流可证明地移动。
:::
:::

::: exercise {level=3 check="1.41"}
**方法散布。**三条管道（Δ方法、偏差校正RCM、学习降尺度）预测2050年代洪峰变化+8、+14与+24%。如果方法选择与模式选择贡献相等的方差，方法散布意味着总预测不确定性相对纯模式散布如何变化？
::: solution :::
等方差相加让方差翻倍，所以总标准差增长√2 ≈ **1.41**——2020年代多方法互比令人不适的结果浓缩在一个因子里：分析师的管道是与模式相当的不确定性来源，这就是2020年代成熟的适应评估跨方法也跨模式跑系综、而单管道影响研究的误差棒在结构上只是一半故事的原因。
:::
:::

::: exercise {level=3 check="10"}
**算力经济学。**一次对流许可区域运行花费10⁶核时；一个学习仿真器花费1核时，对温度以90%信号保真度仿真它、对未测试的极端保真度未验证。在10⁷核时预算下对20个区域情景，你能负担多少次完整RCM运行，仿真器让你改采样什么？
::: solution :::
10⁷/10⁶ = **10**次完整运行——算术逼出的2020年代混合设计：物理是问题的地方用RCM（对流极端、复杂地形、过程诊断），RCM预算禁止的大采样用仿真器（驱动系综扫描、情景矩阵、不确定性划分），以及仿真器携带的审计义务：在变量与机制上演示的保真度、不只是温度——2021年批评与2023–2025年一致性审计调和成一个组合。
:::
:::

::: warning 降尺度的四种谬误
1. **"更高分辨率意味着更好的预测。"**分辨率在物理需要之处买到信息——对流、地形、表面对比——而对大尺度温度信号，2021年批评证明区域模式常常是其驱动者昂贵的回声；谬误的破绽是一个从不说明更细网格改变了什么的方法部分，因为通常诚实的答案（对这个变量，什么都没变）本会省下这次运行——这让决策检验——粗方法本来会做出同样的决定吗——成为每个降尺度产品的第一道审计、不是最后一道。
2. **"偏差校正让模式无偏。"**分位数映射修补网格箱分布、别无其他：错误的环流、错误的趋势机制、错误的变量间结构在每次单调转移中幸存；而2010–2020年代文献最悲哀的发现是校正后序列的误差棒——用校正后的散布计算——常常比未校正模式的更窄，校正洗白了它从未碰过的不确定性；要查管道的作者是否在分布之前验证了动力学，在被证明之前假设他们没有。
3. **"区域系综更紧的范围是更紧的真相。"**散布悖论的共享出身——共同的驱动者、共同的情景、继承的变率状态、共享的方案——意味着降尺度预测之间的一致部分是其父母声明的重述，而2020年代审计的规则随之而来：一个降尺度范围只有在被父母的散布、方法散布与观测共同跨越时才可信、绝不在它仅仅排除它们时；建在单驱动单方法缎带里的适应计划买到了最窄也最不可辩护的未来版本。
4. **"一个匹配观测的学习降尺度器就通过了验证。"**它匹配的是观测气候——训练分布——而降尺度是为未观测的那个气候存在的；2022–2025年物理一致性审计（收不拢的水量、幻觉的地形效应、未见强迫下的误差增长）是六十岁完美预报一课的现代形式：一个统计映射的历史技巧只是外推的许可证、在且仅在平稳性被证明之处，而对CO₂翻倍的大气，还没有任何网络或回归证明了它，而混合服务（仿真动力产出、加速管道）是该方法诚实的尽头与价值的起点。
:::

## 总结

::: summary
降尺度用三个家族与一道审计回答模型与后果之间的尺度错配。动力降尺度——经PRUDENCE与CORDEX到对流许可4公里一代的限制区域谱系——计算细物理并在对流与地形掌握答案之处挣得其算力：CP4CIP的逐小时极端翻倍、日循环的修正、修订的排水标准；其弱点是继承的（驱动者偏差、散布悖论的假一致、边界误差），而其2021年Douglas–Pendergrass批评落在方法过度承诺之处——大尺度信号，一个偏差校正的全球模型几乎同样供给。统计降尺度——完美预报、分位数映射、天气生成器及其深度学习后裔——便宜、无处不在、且被平稳性划界：它修好分布而不碰环流，匹配统计量而不匹配序列，学习的映射在前所未有的气候中的有效性被假设、从未被展示。Δ方法筛选，RCM决定阈值问题，仿真器采样预算禁止的东西，而决策检验仲裁：更细的信息恰在其移动决定时值其代价，对夏季对流它移动、对冬季均值它不移动。诚实的管道报告哪个家族制作了哪张地图、在分布之前验证动力学、与模式散布并列跨越方法散布，并记住每张适应地图上每个降尺度方块携带其家族所假设的一切——物理、统计、或希望。
:::
