在运动方程——[[atmospheric-dynamics/equations-of-motion]]一课那些优美的、连续的、无穷可微的基本方程——与一个气候预测之间，坐着一台只会加、而且只在点上加数字的机器。**数值方法**是把导数换成差分、把积分换成求和、把光滑场换成有限个值的清单、同时让答案保持诚实的艺术：一致的（网格加密时离散方程趋近连续方程）、守恒的（质量、能量、示踪物不被算术创造或毁灭）、稳定的（误差不无界增长）、以及——那个让该领域成为一门工程学而非应用数学研讨班的要求——在真实硬件上快到能在几周内跑一个世纪。本课是层级顶几级的工作机械学：网格如何被选定、其两极要付出什么代价；**Courant–Friedrichs–Lewy条件**为何把步长锁在网格距上、从而设定上一课的十六倍成本定律；简单的平流方程被朴素离散化后，为何制造出假扩散与假振荡、污染二十年的积分（以及迎风、谱方法、半拉格朗日技巧各自如何解毒）；隐式求解器如何以椭圆求解为代价买时间步；以及**动力核**——每个中心模式里那个有名字、有基准、有争议的数值引擎，从谱变换传统到2010年代的有限体积与模仿网格——在参数化第一朵云之前如何对照标准算例检验。不假设先修数值分析课；练习要你算出决定真实模式配置的那些数字，因为在这个主题里数值从不清白：每个截断误差都是一个伪装成算术的参数化，而2010–2020年代关于对流许可模式的"灰区"之争证明，领域仍在争论算术在哪里结束、物理从哪里开始。

::: definition 离散化、截断误差、精度阶 {#def-discretisation}
把∂f/∂x换成一个差商，你就做了一个**离散化**：中心差分[f(x+Δx) − f(x−Δx)]/2Δx等于真导数加一个**截断误差**——Taylor定理给出中心格式−(Δx²/6)f‴、单侧格式−(Δx/2)f″——而格式按其误差随网格加密消失的快慢被称为**二阶**或**一阶**。后果是收敛研究的工作算术：Δx减半让二阶误差缩到四分之一，所以**Richardson外推**（把粗解与细解组合成(4·fine − coarse)/3以消去主导误差）把两次运行变成一个更好的、跨三个分辨率跑就变成一个**精度阶检验**——人造解方法与一个动力核在任何物理被信任之前必须通过的确认电池组（1990–2020年代的Jacot–Whitaker与Williamson测试套件传统）。定义里藏着两条更深的告诫。**一致不等于收敛：**一致的格式可能不稳定（下一个定义的CFL），而Lax等价定理——对适定的线性问题，一致加稳定蕴含收敛、且按格式的阶收敛——是该领域奠基的承诺与其永久的审计：非线性的、旋转的、分层的、被离散了两遍的气候动力学坐在定理假设之外，这就是为什么每个新动力核是被*检验*的、不是被证明的。以及**守恒的是什么：**一个格式可以在一个被动示踪物上是二阶精确、却在一个世纪的积分里于舍入加截断的量级上毁灭总质量或总能量——这就是现代动力核（2000–2020年代的有限体积家族、同几十年的模仿与结构保持格式）被设计成让守恒定理的离散类比按构造精确、让精度可变、让守恒成为保证的原因。前面几课的EBM与箱模型把这一切藏了起来；在一个GCM里，这就是一次模拟与一件伪影之间的区别。
:::

::: definition 稳定性：CFL条件与步长的暴政 {#def-cfl}
用时间向前、空间中心的格式离散平流方程∂q/∂t + u·∂q = 0，加上von Neumann的花招——插入一个波e^(i(kx−ωt))、盯着它的离散振幅——产出那句催生了一千台超算的判词：格式对*任何*非零步长都不稳定，因为离散相速是错的、错的方式把波自己的误差向上喂回去。修补与定律一起来：显式格式只在信息留在模板之内时稳定，**CFL：u·Δt/Δx ≤ C_max**（Courant–Friedrichs–Lewy数，许多格式为1、多阶段Runge–Kutta更低），而对可压缩大气，起约束作用的波不是风而是最快的信号——重力波与声波，每秒几十到几百米——这就是步长被以约Δx锁在网格上的原因、也是上一课十六倍成本定律成立的原因。定义的三条职业推论。**滤波是一张许可证：**半隐式与静力-声过滤（anelastic近似）公式把声波从系统里移除——1950年代让Richardson的梦想负担得起的准地转滤波，被现代半隐式动力核（ECMWF IFS传统，1990–2020年代）的水平隐式Helmholtz求解延伸——以每步一次椭圆求解为代价把Δt买到显式CFL极限之外，拿局部模板的易并行换全局线性代数——一个关于超算架构（2010–2020年代对全局求解的百亿亿次批评）与数学同样多的决定。**扩散有自己的CFL：**显式抛物项要求Δt < Δx²/2κ，那条*二次*定律让湍流闭合（边界层的Smagorinsky与湍动能方案）成为细分辨率下隐藏的步长独裁者，而隐式扩散收自己的椭圆税。**步长在实践中是一个调参参数：**每个中心的Δt都是CFL极限、物理耦合频率（物理的分裂步算子分裂——辐射每小时、对流每步、2010年代显示耦合次序有气候相关敏感性的Strang分裂误差分析）、以及百亿亿次并发下舍入积累之间谈成的折中——而诚实的模式互比（2000–2020年代的动力核比较计划、水球CMIP）部分就是为了把物理说了什么与数值允许了什么分开。
:::

::: definition 输送格式：数值扩散、频散、与半拉格朗日技巧 {#def-transport}
平流一个锋面是离散误差变成可见天气的地方：精确解平移剖面而不变，而每个格式都改变它，而它*撒谎的方式*写在其修正方程里。**一阶迎风**稳定而单调——也扩散，加上一个有效扩散率u·Δx/2，在一天的积分里把锋面抹过几十个网格长度，在20公里模式里这是一个比真实混合层更厚的假混合层。**二阶中心与Lax–Wendroff**格式杀死抹平——并用**频散**取而代之：绕着锋面鸣响的振荡，在可压缩示踪物里非物理、在变负时不稳定（水汽与云水组分的正性问题）。领域的回答至今全部在生产中运行：**受限高阶格式**（1970–2000年代的通量校正输送、2000–2020年代的单调有限体积家族——PPM、MPDATA的迭代反扩散、GFDL 2004–2020年代谱系的正定有限体积动力核——把高阶精度与限制器强制的单调性调和，在极值处接受局部降阶以放逐振铃）；**谱与半拉格朗日全球方法**（1970–2020年代ECMWF与气候模式的谱变换传统，对到截断为止的全球波场精确，自Robert 1966年的洞见与1990年代的业务采纳起与沿风步进并插值的轨迹平流配对，在远超显式CFL极限的风速下保持稳定——让约10公里全球模式配小时级步长成为例行的技术）；以及2010–2020年代的**谱元与间断Galerkin动力核**（NCAR–DUKE–ETSM高阶层级与ICON和MPAS的工作）靠提高单元内多项式阶数、而不是加密网格来抬升精度。气候相关的点睛之笔，在2000–2020年代付出代价学会：输送误差不是噪声——它们是**气候偏差**。输送格式的数值扩散决定海洋锋面与云带能保持多锐利；频散误差在梯度附近对示踪场做整流（加偏）；而2010–2020年代"涡旋饱和与涡旋扼杀"文献表明粗模式的数值耗散恰好阻尼那些其缺席随后改变热输送的海洋涡旋——数值与物理纠缠到"这个偏差是物理的吗"除了"跑细点看看"没有答案。
:::

::: definition 网格、两极、与动力核 {#def-grids}
把点放在哪里是一个有政治史的几何问题。**经纬度网格**是球面坐标的自然映射、也是谱变换方法的家（后者通过在波数空间工作绕开了经度点，ECMWF业务史从1970到2020年代的T42到T1275阶梯）——但它们以1/cosφ过度采样两极，在世界屋脊强加微小的网格单元（与微小的CFL步长），靠极地滤波器、缩减网格与聚点技巧驯服，而其伪影（1990–2020年代比较中的极地噪声）从未完全死去。**准均匀替代方案**把点均匀铺开：**二十面体六边-五边网格**（1990年代Ringler–Randall–Purser谱系，长成NCAR社区地球系统模式的HOMME核心与日本NICAM的遗产）、**立方球**（Rančić与Sadourny的1992年谱系，长成FV3，那个在NOAA各建模中心成为2016–2020年代社区与业务标准的有限体积动力核）、德国ICON的**二十面体测地网格**（马克斯·普朗克气象研究所2000–2020年代的非静力icon-atmosphere）、以及MPAS的**六棱柱网格**（美国国家大气研究中心社区2010–2020年代的MPAS跨尺度预报大气与海洋家族）。繁衍本身就是要点：到2020年代每个主要中心都有一个**动力核**——物理之下那个有名字、有版本、有基准的数值引擎——而**动力核复兴**（2000–2020年代替换1980年代的谱变换与经纬度有限差分动力核）被一个工程学事实驱动：球面上的非静力、公里级、云分辨动力学需要一个没有极点的网格、一个在锋面上没有假扩散的格式、以及一个其并行分解能扩展到百亿亿次时代十万核的求解器（FV3、ICON与MPAS在Frontier、LUMI与MareNostrum级机器上2020年代的规模研究，其中半隐式动力核的椭圆求解与自适应网格的负载均衡成了一级设计问题）。仲裁这场竞赛的标准检验——Jacot–Whitaker与Williamson斜压不稳定算例（1992年测试套件，每个新动力核都要以机器的雄心复现其参考解）、Rossby–Haurwitz与山地检验、CMIP式互比的2010–2020年代水球气候漂移——是该领域对算术的同行评审，而它们的存在就是GCM时代与Richardson时代的区别：再没有人不得不相信一个动力核的任何一面之词。
:::

::: example 公开地选步长：三个中心 {#ex-timestep}
CFL数不是抽象的：它是每次模式运行的第一个配置决定，而它的算术值得摊开来做。取一个Δx ≈ 50公里（约1°）的全球模式，显式信号的最快者：在上层大气风急流奔跑之处，重力-浮力波的相速高达u + c ≈ 100 m/s。取C_max ≈ 0.5的显式可压缩CFL给出Δt ≈ 0.5 × 50,000/100 = 250秒——而1990–2000年代的经纬度有限差分模式在这个分辨率上确实跑15–30分钟的步长，取低值是因为垂直交错与物理耦合把安全数字削得更低。现在做三个现实世界强加的变化。**半隐式滤波**移除声波与（水平）重力波约束：同一个模式每步解一个Helmholtz方程、在25公里上跑Δt = 20–30分钟，而显式模式在那里需要约5——用椭圆求解换步长的精确交易，也是ECMWF的谱变换线在2000–2020年代网格越跑越细时保持竞争力的原因。**非静力公里级：**在Δx = 2.5公里、上升气流与声波未过滤时，Δt落到秒级（2010–2020年代ICON与NICAM的配置在2.5–5公里上跑10–20秒的步长），一周模拟约五千万步——这就是全球云分辨的周（2019–2024年的DYAMOND计划）是准百亿亿次级事件、并且至今仍是该领域最昂贵积分的原因。**海洋自己的钟：**海洋模式的CFL被斜压流（约1 m/s）约束，更糟的是其显式粘性拖进Δx²/2κ定律——这就是为什么海洋模式历史上以1°配天级步长运行、而大气以100公里配分钟级，也是为什么2010–2020年代"从涡旋许可到涡旋分辨"的过渡（CMIP6 HighResMIP的1/4°与1/12°配置、2020年代数字孪生原型）让耦合模式成本的增长快过摩尔定律礼貌跟进的速度。练习的一般形式——写下最快的信号、做除法、套上格式的C_max、为物理扣减——是每封模式讨论邮件串都在争论却都不写下来的那道计算。
:::

::: example 箱子里的锋面：测量假扩散 {#ex-front}
跑那个经典实验室实验——把一个光滑台阶示踪物沿一个无散环流平流一圈、对照它出发的位置——各个格式就会招供。在一阶迎风、u = 10 m/s、Δx = 100公里下，修正方程带着一个有效扩散率u·Δx/2 = 5 × 10⁵ m²/s，是海洋观测背景混合的五十倍、与最激进的边界层方案相当：一天之后锋面梯度单凭算术减半，一个月之后锋面消失了，被一条完美守恒示踪物、却对其结构撒谎的光滑斜坡取代。这不是教学猎奇：1990–2000年代的粗海洋模式在其西边界流与混合层里携带的数值扩散率恰好是这个量级，而2000–2020年代关于"涡旋扼杀"的文献——粗网格及其输送格式阻尼中尺度涡旋，涡旋动能在1/10°与1°配置之间掉几倍（在CMIP6 HighResMIP海洋分析与2010–2020年代全球海洋模式互比中有文献记录）——是同一个实验的行星版，挂着热输送与碳吸收的后果。定量的修补就是定义里的那些格式：单调高阶有限体积（PPM的分段抛物重构、MPDATA的迭代反扩散——算出自己的主导误差再减去它，Smolarkiewicz 1980年代谱系到2020年代仍在云与大气化学模式里运行）、在锋面处牺牲阶数以保住正性的保形限制器、以及——给海洋内部——Gent–McWilliams与基于位移的公式，刻意沿等密度面而不是跨等密度面混合，因为物理在那些面上混合。课程里每个守恒标量都适用这个教训：在问"模式的混合参数化做了什么"之前，先问"其输送格式默认做了什么"，因为在粗模式里历史答案是"更多，而且它从未写进文档。"
:::

::: example 审计全世界动力核的那个斜压波 {#ex-baroclinic}
1992年Williamson与同事发表了一个简单到成为该领域测谎仪的初始条件：一个无摩擦、无陆地、无物理的水球，带一个解析给定的急流与一个微小正弦高度扰动——一个生长、破碎、辐射的斜压波，一切都能从方程本身预言。每个动力核现在都必须复现这个参考算例（测试套件的位涡与高度场在第6天与第15天、在同一插值上比较），其开发者的气候主张才会被认真读，而结果是一部数值哲学的公开普查：谱变换动力核（T42–T340阶梯）展示其全局精度与其截断噪声；经纬度有限差分动力核展示其极地滤波伪影；二十面体与立方球动力核展示其网格方向涟漪；半拉格朗日输送者展示其在急流风速下的插值抹平。这个检验真正的价值在于它分开动力核可能错的两种方式：**线性误差**（相速、振幅阻尼——在第6天的波里可见、可从修正方程算出）与**非线性误差**（破碎的波其位涡细丝如何被抹平或鸣响，没有分析能闭合、只有互比看得见——位涡梯度在每个动力核里以不同方式被侵蚀，2000–2020年代"守恒形式对平流形式"文献关于离散位涡守恒是否应建进模板的活争论）。同一套电池组扩展开来——Rossby–Haurwitz波、带虚假重力波噪声的山地检验、2010–2020年代CMIP动力核比较的水球气候漂移协议——现在仲裁上一课成本定律使其昂贵的问题：半隐式谱传统的全局求解能否在百亿亿次批评下幸存（2020年代若干中心转向局部模板、显式、网格均匀动力核的行动，部分是一个算术性能论证、先每字节浮点运算、后才是一个物理论证），以及"模式的急流偏差是动力核噪声"能否与"模式的急流偏差是物理"区分开——互比的诚实答案是在当前分辨率两者在每秒一米的急流量级上纠缠，而那正是对欧洲与季风气候要紧的信号里同样的份额。斜压检验是层级顶级做功课的地方；一个拿不出这张图的中心就是没做过算术。
:::

::: example 灰区：当数值成为对流方案 {#ex-greyzone}
在被参数化的世界（比网格单元小的云，[[climate-modelling/parameterisation]]一课的领地）与被分辨的世界（深对流云作为显式上升气流）之间躺着**灰区**——大约1–4公里的网格距，在那里输送格式的扩散与次网格混合同时太粗、无法诚实地表示对流、又太糙、无法忽略它——而2010–2020年代云许可文献不得不面对这样一个事实：模式在那里的问题取决于数值不亚于物理。有文献记录的案例是一部课程：层积云顶逆层的深度与向积云场的转变，在2010年代从250米到4公里的大涡到小涡研究阶梯上，随平流格式的扩散率移动几百米；陆地上空的日循环降水——被英国1.5公里与德国ICON-D2 2010–2020年代研究的对流许可分辨率修好——部分赢在数值不再抹平驱动午后风暴的湿静力能；而2024–2025年的层积云瓦解恐慌（约25米云分辨模拟发现低云消散的CO₂阈值比被参数化的模式携带的低得多，CMIP一代的回应尚在途中）是灰区问题最要命的形式：答案随数值变细而移动，而还没有人能说清移动它的是新数值还是新物理。方法论上的回应是该领域的最佳实践、也是本课的论点：**数值收敛是一个科学结果**、不是细节——跑那个阶梯、记录什么变了（锋面锐度、EKE、云偏度、降水相位谱），并把任何没有收敛研究的灰区主张当作临时的。同样的纪律适用于物理耦合分裂：2010–2020年代的算子分裂实验显示气候相关的差异（陆面与辐射的耦合次序把日平均通量移动几W/m²）仅仅来自各盒子被步进的顺序——Strang分裂对Lie分裂、每小时对每步辐射——是文档动力核章节里没有任何方程承认做过的算术选择。
:::

::: history 从一个手工工作日到百亿亿次的周 {#hist-numerics}
**1910–1950**：Richardson手工积分了一次六小时预报（1910年，1922年出版）、因为缺少滤波与平滑而失败；Courant–Friedrichs–Lewy定理（1928）与von Neumann对差分格式的稳定性分析（1947，与Richtmyer及洛斯阿拉莫斯的激波工作）创立了数值分析；而Charney、Fjørtoft与von Neumann 1950年在ENIAC上做的一天斜压积分——靠滤掉声波实现Richardson的梦想——用六周计算量的二十四小时机器时间证明了整个纲领。**1956–1979**：Phillips 1956年的GCM与第一代谱方法（1970年代Orszag–Bourke–Hoskins谱变换线、ECMWF 1975年起的业务谱阶梯）让球面可算；半拉格朗日平流的洞见（Robert 1966）等了十年才等到计算成熟；1970年代的通量校正输送与正性格式（Zalesak、Smolarkiewicz 1983年起的MPDATA谱系）回应了平流的诸种毒药。**1980–2000**：超参数化与首批全球云模式预告了灰区；半拉格朗日革命进入业务（1991–1993年ECMWF与加拿大的采纳）、买下了那个分辨率的十年；Williamson斜压测试套件（1992）与动力核互比确立了算术同行评审；二十面体与立方球动力核成熟（Ringler–Randall–Purser 1990–2000年代的工作、Rančić–Sadourny的遗产长成FV3）。**2000–2025**：非静力、网格均匀的复兴——NICAM的全球云分辨运行（2006年起）、ICON（2010年代起）、MPAS（2010年代起）、FV3的业务采纳（2016年起）——半隐式谱动力核守位到2020年代；DYAMOND与TWINS的周至季公里级实验（2019–2024）展示了百亿亿次体制；而2020年代的算术性能与机器学习替代物文献以GPU、混合精度与学习到的物理重新记账，重开了该领域最古老的问题——一个时间步的价格。
:::

## 检验你的理解

::: quiz {#quiz-cfl}
为什么把模式的水平网格加密一倍会（对显式格式）迫使步长缩小？

- [ ] 因为更细的网格需要更多垂直层
- [x] 因为CFL条件要求信息留在模板之内：最快的波在更小的单元里用时更短就穿过
- [ ] 因为物理参数化运行得更频繁
- [ ] 因为舍入误差随网格增大

::: solution :::
稳定性要求u·Δt/Δx低于格式的极限，所以Δt与Δx同比例：单元减半则步长减半，配上八倍的点（三维）与两倍的步数，每个模拟年的成本上升十六倍——模式层级的成本定律，在这里由一个无量纲数导出。半隐式与半拉格朗日格式为选定的波型放宽约束，而它们值得付椭圆求解与插值的税，这正是原因。
:::
:::

::: quiz {#quiz-greyzone}
对流的"灰区"指的网格距是：

- [ ] 云太小不要紧、被忽略
- [x] 对流被动力学部分分辨、而参数化仍然活跃，于是数值与参数化互相竞争
- [ ] 只有海洋混合层未被分辨
- [ ] 雷达观测太粗、无法验证模式

::: solution :::
在约1–4公里，上升气流占据几个单元：输送格式的扩散抹平对流方案同时在试图表示的东西，重复计算或互相抵消取决于双方。这就是为什么云许可结果需要跨网格距阶梯的收敛研究（2010–2020年代大涡到灰区文献），也是为什么2024–2025年层积云瓦解结果在数值-物理归因定案之前被当作临时的：在分辨率前沿，改变算术就改变气候。
:::

## 练习题

::: exercise {level=1 check="200"}
**CFL步长。**一个C_max = 1的显式格式在Δx = 10公里的网格上以u_max = 50 m/s平流。最大稳定步长是多少秒？
::: solution :::
Δt = C_max·Δx/u = 10,000/50 = **200秒**——10公里处的声波/重力波天花板；分辨率翻倍、步长减半，并注意当多级时间步长与物理耦合使C_max < 1时真实数字更低——每个中心公布的步长都是这道除法、外加细则里写明的安全裕度。
:::
:::

::: exercise {level=1 check="4"}
**精度阶。**一个二阶动力核在Δx与Δx/2上运行。截断误差范数应缩小多少倍？
::: solution :::
二阶意味着误差∝Δx²，所以网格减半让误差缩2² = **4**倍——收敛研究必须找到的比值（log-log斜率2）动力核才可信；找到1意味着你的限制器在每个锋面上吃掉精度阶，这是生产输送格式的标准头号故障。
:::
:::

::: exercise {level=1 check="50000"}
**扩散CFL。**κ = 10⁵ m²/s（一个海洋中尺度涡粘滞系数）的显式扩散在Δx = 100公里网格上要求Δt < Δx²/(2κ)。极限是多少秒？
::: solution :::
Δt = (10⁵)²/(2 × 10⁵) = 10¹⁰/2 × 10⁵ = **50000秒**（约14小时）——二次定律的现场演出：这条抛物线极限、而不是洋流，设定了一整代粗海洋模式的步长，而隐式扩散（另一次椭圆求解）是标准的逃生——带着与声波过滤同样的隐式对并行权衡。
:::
:::

::: exercise {level=2 check="5"}
**假混合比。**u = 10 m/s的一阶迎风平流在100公里网格上的有效扩散率为u·Δx/2。它是海洋典型背景扩散率10⁵ m²/s的多少倍？
::: solution :::
u·Δx/2 = 10 × 10⁵/2 = 5 × 10⁵ m²/s；比值 = **5**——粗模式在任何参数化被打开之前就混合"调好的"背景的五倍，这就是为什么1990–2000年代在粗模式里调涡旋扩散率的做法产出的数值部分是穿着物理衣服的数值，也是为什么2010–2020年代涡旋许可的一代把一切重调了一遍。
:::
:::

::: exercise {level=2 check="8192"}
**谱网格计数。**一个T42谱模式的线性网格有128经度 × 64纬度。每层多少个点？
::: solution :::
128 × 64 = **8192**——CMIP1时代模式整个大气每层的点数（约10层，全球约80,000个预报数字），对照2020年代生产模式每层10⁷–10⁸：气候建模的分辨率史就是这一千倍的历史，而成本定律说Δx每个2倍花16倍每个模拟年，两句话讲完了全部预算故事。
:::
:::

::: exercise {level=2 check="36"}
**半拉格朗日出发点。**一个30分钟的半拉格朗日步在u = 20 m/s下向后追踪风。轨迹走多远（公里）？
::: solution :::
20 m/s × 1,800 s = 36,000米 = **36公里**——越过相邻单元，这正是格式在显式CFL极限之外仍稳定的原因：它不逐单元传播信息、而是靠插值从出发点取值——以插值抹平为这张许可证付账——格式自己修正方程的扩散，2010年代单调半拉格朗日文献（FV3与ICON的输送论文）一直在试图把它省回来。
:::
:::

::: exercise {level=3 check="1.47"}
**Richardson外推。**一个二阶模式在粗分辨率上给出2.0 K当量的区域降水偏差、在网格距减半时是1.6。外推的"精确"值(4·fine − coarse)/3是多少？
::: solution :::
(4 × 1.6 − 2.0)/3 = (6.4 − 2.0)/3 = **1.47**——连续极限的两次运行估计、每个分辨率强制研究都应当报告的统计量（2010–2020年代"分辨率是一个调参参数"批评要求其报告），只有当两次运行的差异来自截断误差、而不是来自哪些参数化在细网格上醒了过来才有效——又是灰区告诫。
:::
:::

::: exercise {level=3 check="175"}
**有效分辨率。**一条经验法则：网格能分辨到约7个网格间隔的波长。Δx = 25公里处能被有效表示的最短波长是多少？
::: solution :::
7 × 25 = **175公里**——终结"我们的模式是25公里所以能看中尺度涡旋"这一说法的数字（第一斜压变形半径10–50公里是不可见的：模式在最富饶的区域至多是涡旋许可、在其余一切地方涡旋被参数化），也是为什么"网格距"与"分辨率"是两个词——模式开发者从不混淆、用户总在混淆。
:::
:::

::: exercise {level=3 check="0.01"}
**舍入积累。**一次气候积分对每个变量做10¹⁰次浮点更新，单精度（ε ≈ 10⁻⁷）舍入，按随机游走（√N·ε相对）积累。积累的相对误差是多少？
::: solution :::
√(10¹⁰) × 10⁻⁷ = 10⁵ × 10⁻⁷ = **0.01**——单凭算术就百分之一，这就是为什么气候模式历史上跑双精度（2020年代混合精度与GPU时代的重新评估，包括机器学习动力核对低精度的容忍度，正带着显式误差预算研究重审这个选择），为什么"逐位可复现"是一个人们真的会为之争吵的配置开关，以及为什么千年运行里0.5%的能量漂移是一个数值结果、不是物理结果。
:::
:::

::: warning 数值伪装成物理的四种方式
1. **"更细就是更准。"**更细对*你所解的那个离散系统*更准；如果格式的假扩散在维持一个虚假平衡（靠数值阻尼钉住的粗模式急流、由一个半网格而不是地形设定的西边界流泄漏），加密就改变气候——而2010–2020年代分辨率强制文献的意外（敏感度、ENSO偏度与降水相位都随Δx移动而物理不变）是"粗模式以一种未被建模的方式错着"的客气说法。分辨率研究是物理实验；把它们当回事。
2. **"格式是守恒的，所以示踪物安全。"**全局守恒与局部正性是两条不同的定理：一个反对称中心格式精确守恒方差、却在每股东流把负的湿度鸣响进平流层；一个单调限制器保住湿度为正、却把锋面扩散掉。你的科学能承受哪种失败是一个关于你的示踪物的问题（盐比云水更能容忍振铃对负性），而2000–2020年代正定有限体积的一代之所以存在，是因为终于有人问了。
3. **"不确定性在参数化里。"**耦合次序、步长、物理耦合频率与输送格式扩散率都会把气候相关的通量移动W/m²量级（上面的算子分裂与灰区结果）——与你正在模拟的那十年强迫同量级的误差。给物理做预算而无视数值的模式不确定性归因研究是在报告账本的一半，而动力核互比之所以存在，是因为另一半在同一批输出文件上签了名。
4. **"它通过了测试套件，所以它是对的。"**斜压与人造解检验约束的是*算术*；它们对离散方程是否是正确的方程一字不提，而每个动力核都通过某些检验、同时携带格式特有的偏差（极地噪声、网格涟漪、插值抹平），任何检验的参考解里都没有这些，因为参考解是另一个模式。确认是必要的、验证是另一回事，而该领域为这个缺口准备的诚实说法是"我们还不知道这个偏差里有多少是动力核。"
:::

## 总结

::: summary
数值方法是气候方程向有限机器纳税的地方：导数变成带截断误差的差分、其阶设定收敛速率；稳定性变成CFL数、把步长锁在网格上、并生成组织整个模式层级的十六倍成本定律；平流变成在假扩散与假振荡之间选择，由受限高阶格式、谱变换、以及越过风速步进的半拉格朗日许可证来回答；而球面本身变成一张有争议的网格——带极地税的经纬度、二十面体、立方球、六棱柱——在任何物理被相信之前由Williamson斜压检验与水球漂移仲裁。分辨率时代的深层教训是数值不是物理周围的脚手架、而是其中的参与者：粗模式的气候包含格式造成的急流、数值阻尼的涡旋与分裂步的通量，灰区把算术与对流搅成一个，而2020年代的前沿——百亿亿次公里级的周、混合精度与学习到的动力核、随数值一起移动的层积云瓦解恐慌——让收敛研究成为一个科学结果、不是脚注。层级的道德，最后一次以工程的面目说：知道你的离散化相信什么，因为它将对你问它的每个问题投票。
:::
