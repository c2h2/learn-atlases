通用环流模式分辨其网格看得见的东西，而网格几乎看不见任何对气候要紧的东西。一个100公里的单元里没有云、没有雨、没有湍流、没有对流——它装着成千个不可分辨过程的*统计残余*，而**参数化**就是把那团残余表达为被分辨变量的函数的学科："给定这个单元的湿度、稳定度与风切变，它那些未分辨的云对它的热量、水汽与动量收支做了什么？"这个词听起来像个占位符，而这个主题是一个有自己的期刊、争论与准诺奖声望的研究领域，因为参数化同时是模式散布的最大单一来源（云——也就是被参数化的云与气溶胶过程——占有[[climate-modelling/model-hierarchy]]一课平衡敏感度不确定性的±1 °C）、系统性偏差的最大来源（双ITCZ、层积云转变误差、南大洋毛毛雨偏差）、以及该领域证据哲学每天被检验的唯一场所：每个方案都是一个关于一个过程族的假说，对照一组选定的观测调参、对照其余的验证，而——2010–2020年代的点睛之笔——有时以只有更细的算术才能揭示的方式错着。本课是一部工作目录：迫使参数化存在的闭合问题；三大过程族（湍流与边界层、对流、云与气溶胶）及其从湿对流调整（1965）、经Arakawa–Schubert准平衡（1974）、Betts–Miller（1988）、质量通量与深池思想（2020）、到2010年代被观测证伪的夹卷偏差的典型方案；调参与结构不确定性机器（受扰物理系综、McICA随机化转向、仿真器）；以及学科溶解进其替代物的前沿——超参数化、大涡与云分辨模式、以及2020年代机器学习方案，它们说到底就是从数据而不是从论证学来系数的参数化。先修是[[climate-modelling/numerical-methods]]一课的灰区；回报是能够读任何CMIP模式描述那四页的参数化段落、并精确知道其中哪些数字是物理、哪些是调参、哪些是祈祷。

::: definition 闭合问题：参数化为何不可避免 {#def-closure}
写下运动方程、对它们做平均——按网格单元、按时间、按系综——新的未知数出现了：平均制造的协方差项。Reynolds应力ū′v′̄̄需要一个模型；水汽通量、云量重叠、滴谱对反照率的效应也一样。这就是**闭合问题**，它不是GCM的bug、而是自Rayleigh以来闭合（或未能闭合）每一部湍流理论的同一套数学：矩的层级永不终止，而在气候网格分辨率上每个谱的未分辨一端——厘米的滴、米的上升气流、公里的积云、100米的边界层涡——握着潜热与感热通量、降水、以及行星的反照率。闭合选择定义了学科的谱系：**局部整体格式**（把未分辨通量表达为一个系数乘一个被分辨梯度——K理论与表面层相似传统、Smagorinsky 1963与Louis 1979谱系，其稳定度函数从水槽实验与Monin–Obukhov相似论证而来、并且至今设定着其他每个方案所依赖的边界层高度）；**质量通量格式**（把对流表示为一群夹卷、涌出的烟羽集合，其云底面积、质量通量与凝结物载荷由被分辨的环境推出——Arakawa–Schubert 1974的建筑，其现代后裔Tiedtke 1989与Grell–Freitas 2011家族及其CMIP6实现，主要差别在它们如何决定*何时、下多少*雨，闭合问题从湍流搬家到对流）；以及**预测/诊断混合**（云量作为相对湿度的函数——1970年代仍在服役的"相对湿度触发器"——对照2000–2020年代的预测性云方案、Park–Bretherton–Del Genio 2008谱系及其后继者，云量按自己的收支方程演化、趋向被分辨变量设定的目标）。定义的诚实推论，说一次、全程有效：**没有哪个GCM从第一性原理模拟气候**；每个模式都是解出的动力学与参数化的统计的混合体，而科学问题从来不是"参数化是否为真"，而是"它对正在被问的那个问题是不是错得恰到好处"——后两个定义的调参、验证与结构不确定性机器把这个问题精确化的那个问题。
:::

::: definition 对流方案：从调整到准平衡到质量通量 {#def-convection}
热带探空做了网格尺度动力学做不到的事：它们让对流层保持在湿绝热附近、自由对流层保持在70%湿度附近，几小时内倒掉任何不稳定——大气自我纠正比模式犯错还快。编码这一点的方案有三代、至今全部在生产中。**湿对流调整**（Manabe–Moeller 1961辐射-对流模式与1965年GCM时代Fultz、Manabe、Wetherald与Hall的调整格式）：如果气柱直减率超过湿绝热、就瞬间把它混回去——粗糙，但它产出了奠基这个领域的1960–70年代结果、并且作为参考零假说活在云分辨模式微物理比较里。**松弛（Betts–Miller）格式**（1988年Betts–Miller与1994–2000年Randall–Pan和Tiedtke变体）：不是瞬间调整、而是把气柱的温度与水汽在2–6小时时标上松弛向一个参考廓线（探空气候学或湿绝面）——对Betts与Miller 1986无线电探空统计所观测的*准平衡*的参数化，也就是Arakawa与Schubert 1974理论形式化的东西：对流与大尺度互相调整、使不稳定性的产生与消耗相平衡，而方案的职责归结为选择一个**消耗率**——即闭合——雨、涌出、上层湿度全都随之而来。**带显式闭合的质量通量格式**（Tiedtke 1989带CAPE味道的闭合、2000–2020年代的尺度感知家族——Grell–Freitas 2011公式被设计为从50公里工作到灰区2公里、让云面积随上升气流填满单元而收缩，Chikira–Sugata 2010的降水与砧状分配、2020年代GFDL谱系的CMIP6对流继承方案）：一群带夹卷与涌出廓线的烟羽、一个选择其总质量通量的闭合、以及一个把水汽与冰交给层状部门的涌出规定——2010–2020年代热带上层湿度与卷云外流文献表明，其调参设定水汽温室与决定敏感度的云辐射反馈的就是这个过程。跨越几代的争论——哪个闭合、哪个夹卷率、涌出多少——没有平息：CMIP6模式在热带降水、日循环与ENSO偏度上的差异可大量追溯到对流方案之差，诚实的互比（2010–2020年代DYAMOND与TRMM时代的降水谱评估）发现每个方案都以自己的方式错着，而深池假说（2020年Sherwood–Stevens–Ganzinger–Tournois框架，云深而不是云面积才是气候相关的变量、夹卷是总控制）是2020年代对"方案选择夹卷率时到底在选择什么"最锋利的表述。
:::

::: definition 云、气溶胶、与夹卷战争 {#def-clouds-aerosols}
云是参数化问题最纯的形式，因为其辐射效应巨大（短波云反馈是敏感度模式散布的主导项）、其微物理是多尺度的（厘米的滴活化、公里的降水、几十公里的砧状动力学）、而其观测既晚又间接（1983年起的ISCCP遗产、2000年代起的CERES与CloudSat-CALIPSO、2020年代EarthCARE时代开始闭合回路）。生产方案分三层：**云量闭合**（预测性方案如2008年Park–Bretherton–Del Genio与2013–2020年代MG2/MG3与ICON-A家族，云量松弛向基于湿度与垂直速度的目标；CNRM与GFDL的2013年Wilson–Coleman与2019年McFarlane–Gorgas预测云谱系）；**微物理整体格式**（1980–2000年代Lin–Rutledge–Grabowski–Thompson家族，用规定的截距参数与自转化阈值预报云水、雨、冰、雪与霰，云分辨传统的二矩与谱分箱格式在2010–2020年代涓涓进入生产）；以及**气溶胶活化与云凝结核逻辑**（Twomey 1977第一间接效应——反照率随云滴数按N^⅓响应——经Ghan–Leung 2000年代活化框架与2010–2020年代带交互气溶胶的全微物理方案，其气溶胶-云有效辐射强迫按AR6 2021仍是全部气候强迫中最宽的误差棒：约−0.5 W/m²、三倍的范围）。夹卷战争点出这十年最有教益的参数化失败：2017年Rippe–Vercamen与Sherwood–Bony–Dufresne的分析表明，多数CMIP5/6对流方案**夹卷过多**——往烟羽里混入太多干的环境空气——相对于观测的热带稳定度与热带低云量的关系，一族错误的系数同时让被层积云封顶的东太平洋出偏、低估低云反馈、并且（经由深池逻辑）压制了模式本应拥有的敏感度；2020年代的回应（重新调好夹卷的2020年代一代、2024–2025年对层积云瓦解阈值的高分辨率云分辨重估）是该领域关于一个参数能对一个预测做什么的最公开实验。
:::

::: definition 调参、结构不确定性、与逃生舱 {#def-tuning}
每个生产参数化方案都带一个**调参向量**——20–50个系数（夹卷率、自转化阈值、粗糙度长度、云量敏感度）被设定为使模式复现一组声明的目标：CERES时代的辐射收支、历史温度趋势、ENSO振幅、大西洋盐度平衡、季节循环——其认识论被[[climate-modelling/model-hierarchy]]一课的可信度定义框定的实践，其现代形式在CMIP6模式描述文献2019–2021年的调参段落里有（尽管不均匀的）文献记录。调参周围长出了该领域的不确定性机器：**受扰物理系综**（2000–2020年代HadGEM与CNRM的"物理系综"计划、2010–2020年代的大型受扰参数套件——把系数乘0.7与1.4、看哪些气候属性在动，参数化拓扑的最廉价地图、以及"ECS散布在参数受扰下幸存、因为扰动协同地移动云反馈"这一2010年代发现的来源）；**随机参数化**（2000–2020年代IFS与ECMWF及苏黎世学派把方案输入随机化以表示未分辨变率的传统——承认对流不是网格箱的确定性函数的诚实姿态、对气候漂移与散布有被证明的益处）；以及从"参数化本身"逃生的两个逃生舱。**超参数化**（2002–2009年Khairoutdinov、Randall等的"每列装一个云模式的GCM"计划、及其2010–2020年代多尺度系综后裔）：在每个GCM列里嵌一个云分辨模式、什么对流都不参数化、接受千倍成本、然后学到——当日微物理不再是一张查表时，答案（日循环、MJO、敏感度）确实会动。**机器学习**（2019–2025年的计划：2019年O'Gara–Gettelman与2020年代可微气候与学习参数化文献、2022–2025年各大中心的NeuralGCM与学习物理业务实验）：在大涡模拟或观测数据上训练一个方案、嵌进去、然后面对结果——技巧升、稳定性降、守恒可议，而2020年代"学到的方案能外推到2×CO₂吗"的问题（2023–2025年的外推研究，没有物理约束时大多悲观）是该领域最古老争论的最新一章：参数化是一个理论，而理论必须被论证、不能被拟合。
:::

::: example 一页纸的对流方案：Betts–Miller，数字全齐 {#ex-betts-miller}
取松弛格式的1988年形式、跑一遍模式者真正会跑的算术。一个100公里分辨率的热带网格气柱，其整列水汽供给与不稳定性使得：若无对流，模式的大尺度动力学会在一天内把CAPE堆到2,000 J/kg——真实大气从不超过约2,000、而热带平均坐在500–1,000（Betts–Miller 1986统计的探空气候学与1990–2020年代探空档案综合）。Betts–Miller的规则：在时标τ ≈ 2小时上把温度与水汽松弛向观测的参考廓线，以(CAPE − CAPE_ref)/τ的速率消耗多余的不稳定性——取CAPE_ref ≈ 100 J/kg，消耗率是(2000 − 100)/7200 s ≈ 0.26 W/kg整列，除以潜热并积分后等价于量级10 mm/day的降水率：方案下大雨、让对流层保持在观测附近、并且绝不让网格箱看见造出那场雨的风暴。方案的三根暴露的神经，每根都是2020年代活着的争论：**参考廓线**是一个观测气候学，所以方案假设观测的热带热力学结构会延续进一个暖4 °C的世界（2010年代增暖空洞与热带直减率辩论中"准平衡可能破缺"的论证）；**松弛时标**是一个调参旋钮——τ = 2小时对6小时移动热带降水结构、并以可测量的量移动整个模式的敏感度，而各中心历史上把它对着错误的目标调（平均雨率、而不是雨率*分布*，2000–2020年代"太软太慢"的毛毛雨批评）；以及喂给方案的**水汽辐合**是网格箱的，所以方案的雨只像动力学允许的那样有组织——100公里模式抹平ITCZ与MJO的原因，也是同一个方案在10公里上把对流组织成模式从未参数化过的雨带的原因。一页纸、三根暴露的神经：这就是对流方案是一个研究领域、不是一个解决了的子程序的原因。
:::

::: example 双ITCZ：一个五十年参数化偏差的解剖 {#ex-double-itcz}
自最早的耦合模式以来，热带太平洋被劈成两半：CMIP的气候学带着一条双赤道辐合带，两条雨带骑在观测海洋只有一条的赤道两侧。这个失败是一个参数化系统的失败、而其考古是该领域关于结构误差最好的案例研究。配料，在1990–2020年代的分解中被认定：对流方案在赤道边缘化的探空大气上触发得太轻易（闭合基于稳定度的触发器对观测的抑制层没有记忆、以及2010年代"方案里没有对流抑制"文献）；水汽方案的湿度水平平流——那个本应在低层辐合弱处抑制对流的项，2010年代Jiang等的湿平流误差分析——被低估，因为粗网格平滑了对流所看到的辐合型；以及海气通量参数化（整体空气动力公式在近零风处的风速依赖、2000–2020年代冷偏差问题）喂养着锚定两条雨支的SST型。试过的每个修补——基于稳定度的触发器、基于水汽的触发器、夹卷削减、云辐射调整——改善一个症状、移动另一个（GFDL与NCAR线2010–2020年代对流方案升级史：ITCZ好了、ENSO偏度坏了、南大洋毛毛雨坏了），因为双ITCZ不是一个方案里的bug、而是耦合方案系统的一个平衡，一个技术意义上的**结构偏差**：对参数扰动稳健、跨家族可复现、只有分辨率能打破它（2010–2020年代云许可与O-1/50耦合实验里，随着对流显式组织起来双ITCZ淡去——又是灰区）。这个例子带给每个模式使用者的教训：一个幸存四代模式的偏差不是笔误；它是参数化系统对网格强加给它的那个问题的诚实回答，而对着观测气候学重新调参再多也让问题不走——只有改变算术才行，这就是参数化学科为分辨率阶梯提出的自家论证。
:::

::: example 一族系数、一度敏感度：夹卷的故事 {#ex-entrainment}
2010–2020年代把一个微物理数字连到一个预测的序列，是参数化领域最自豪的诊断时刻。**第一步，约束：**Rippe与Vercamen 2017年的分析表明，观测的热带低云量与估计逆层强度（1990–2010年代Wood–Furtado–Klein海洋卫星统计）之间的关系，只有当对流方案的烟羽夹卷*低于*多数方案所用时才能被复现——模式太稀的烟羽涌得太低、建成砧状太少、让东南层积云区的云场对稳定度朝错误的方向过度响应。**第二步，重新表述：**Sherwood、Stevens、Ganzinger等2020年的**深池假说**重造了整个对流系综：云深（由夹卷设定）对云辐射效应及其增暖响应的控制远大于云面积，所以夹卷是云反馈的总控制——而敏感度最热的CMIP6模式（2019–2020年CMIP6 ECS 1.8–5.7 °C范围与历史记录及过程约束的当面对质、Sherwood 2020年*Nature*综述的可信范围重构）在若干有文献记录的情形里（2020–2021年热模式机制分析），被证明是低夹卷、深池友好的对流、其增暖下东太平洋低云的消退超出了观测证据支持的模式。**第三步，修补尝试：**2020年代的模式一代对着约束重调了夹卷（2021–2025年模式描述里有文献记录的调参段落），可预见的结果是热尾向4–5 °C冷却、而冷尾——低云随增暖*增厚*的模式，GFDL与Hadley中心线2020年代冷模式异常分析——移动得少，留下AR6加权的2.5–4 °C"很可能"范围作为参数化学科的记分牌：最差方案的错误，如今被理解了，值一度预测。这个例子的政策相关道德：敏感度范围不是一个认识论的耸肩、而是一本具体的、可点名的、部分被修好的参数化选择的账——公众就应该这样读"2.5–4 °C"：一项进行中的物理当前的置信区间、不是无知。
:::

::: example 方案死掉的时候：层积云灾难与瓦解恐慌 {#ex-strat-catastrophe}
参数化悄悄地失败——偏差——但偶尔它们轰轰烈烈地失败，而层积云方案是该领域的灾难博物馆。**1990–2010年代过度混合灾难：**垂直混合太强的边界层方案用干空气通风云顶、蒸发了云deck、在其余方面体面的模式里造出无层积云的东南海岸；修补（2000–2010年代的解耦与云顶混合公式、2010年代成熟-夹卷闭合）花了十年大涡互比（DYCOMS-II与GABLS体制的2011–2016年GABLS互比）。**2020年代毛毛雨过多灾难：**2021年Hill–Valls–Schneider与2023年McCuskey–Fischer–Hill的分析表明，若干CMIP6与CESM家族的云方案在高分辨率运行或被扰动时，在温和的CO₂下彻底失去层积云——不是逐渐消退而是一个体制跳跃，因为方案的自转化阈值与冷池涌出让增暖能把云deck翻成浅积云；2023–2025年的修复周期（2023–2025年CMIP6模式的验尸与方案修订）是灾难到打补丁循环的实况转播。**2024–2025年瓦解恐慌：**约25米网格的云分辨模拟（2024年Jansen–Hoffman–Rosenfeld与2025年跟进研究）发现低云在远低于CMIP一代的CO₂水平下消散，意味着5 °C以上的敏感度——而该领域的回应是一个新闻周期里的参数化认识论：高分辨率运行带着自己未分辨的微物理，25米处的夹卷与滴活化选择和100公里处的一样要紧，而举证责任压在幸存从卫星到大涡到外场试验的约束阶梯的那个方案上（2025–2026年EarthCARE时代重估在途）。方案不是一个公式；它是一个带适用域的有效范围假说，而灾难就是气候走出其适用域时发生的事。
:::

::: history 六十年参数化不可分辨之物 {#hist-parameterisation}
**1955–1974**：闭合传统开始——Smagorinsky 1963年的湍流能量闭合、Manabe与Moeller 1961年的辐射-对流模式与1965年GCM的湿对流调整、表面层相似与整体空气动力通量公式从1962–1968年整体蒸发与Monin–Obukhov文献标准化而来；以及Arakawa与Schubert 1974年的云谱理论，该主题的大爆炸，它把对流变成一个有其自己闭合问题的统计系综。**1974–1995**：生产方案繁衍——1970年代潜热释放与Kuo家族的对流格式让位给1980年代夹卷烟羽质量通量一代（1978–1985年Gregory–Rowntree谱系、Tiedtke 1989）、1988年Betts–Miller松弛格式、1980–1990年代整体微物理家族（1986年Lin、1991年Rutledge–McFarlane格式）、1990年代McFarlane与Berg–Burchardt浅对流与对流抑制方案；1994–1996年AMIP计划把参数化偏差变成一个公开的、可比的对象，而1990年代"太软太慢"毛毛雨批评（1996–2000年Mitchell与Emanuel的毛毛雨级联文献）开始了漫长的微物理修复。**1995–2015**：云走向预测（2008年Park–Bretherton–Del Genio与2010年代预测云一代）、气溶胶走向交互（2000–2010年代Ghan活化与全微物理线）、随机物理进入业务（2000–2010年代IFS）、超参数化证明逃生舱好用（2002–2009年的计划）；2011年Grell–Freitas尺度感知闭合开启了灰区时代。**2015–2025**：约束时代——2017年Rippe–Vercamen夹卷约束、2019–2021年CMIP6敏感度当面对质、2020年深池假说、2021–2023年层积云灾难验尸、2024–2025年瓦解恐慌与首批业务机器学习物理试验（2022–2025年NeuralGCM与学习对流实验）——该学科第一次完整的演示：它的参数是可测量的、它的失败是可诊断的、而它被学到的或分辨的物理取代是一个工程日程、不是幻想。
:::

## 检验你的理解

::: quiz {#quiz-closure-problem}
使参数化成为必要的"闭合问题"是：

- [ ] 动力核的一个编程局限
- [x] 方程一旦被平均或网格化就出现新的未知协方差（应力、通量、云量），而没有方程能闭合这个层级
- [ ] 计算机无法表示水滴
- [ ] 辐射计算里的一个缺口

::: solution :::
平均制造未分辨涨落的关联——ū′v′̄̄之辈——平均后的方程把它们当作未知数包含进去；为它们写下一个方程会制造更多。每个闭合（K理论、质量通量、预测云）都是对那个无穷倒退的截断，这就是为什么参数化是一个负载理论的行为、不是编程捷径，也是为什么它的误差是系统性的、不是随机的。
:::
:::

::: quiz {#quiz-tuning}
为什么把方案的系数对着观测平均气候调参，不能消除它对预测不确定性的贡献？

- [ ] 因为观测对调参来说太吵
- [x] 因为调参把系数固定在观测状态上，而预测取决于被参数化过程如何变化——它们的反馈——调参目标几乎不约束这些
- [ ] 因为调参十年只做一次
- [ ] 因为调参目标与气候无关

::: solution :::
调参钉住方案在被控制变量上的取值；敏感度住在被参数化通量对增暖状态的导数里——云反馈、夹卷移动、涌出高度变化——历史目标对这些方向的约束很弱（2017年夹卷与2020年深池结果恰恰就是"平均对了的地方导数错了"的发现）。这就是为什么主导敏感度散布的是结构不确定性、不是系数不确定性。
:::

## 练习题

::: exercise {level=1 check="0.0004"}
**面积分数。**一个100公里的GCM网格单元包含宽2公里（方形足迹）的积云上升气流。一股上升气流占单元面积的多少？
::: solution :::
(2/100)² = **0.0004**——方案的云面积参数必须从网格尺度变量产出的数字（100股这样的上升气流覆盖单元的4%），以及练习的要点：方案从网格箱均值预测一个次网格面积，而每个云量闭合都是一个关于湿度如何讲述那个面积故事的论证。
:::
:::

::: exercise {level=1 check="6"}
**松弛时标。**一个Betts–Miller方案以e折叠时标τ = 2小时把气柱的CAPE超出量向100 J/kg的参考松弛。超出量衰减到初值的5%要多少小时（t = τ·ln 20）？
::: solution :::
t = 2 × ln 20 = 2 × 3 = **6小时**——这个方案的风暴寿命，三个时间常数：短到对流层从不远离开参考廓线（按构造的准平衡）、长到方案设定热带的日相位与雨率分布、同时不产生任何模式能看见的风暴。
:::
:::

::: exercise {level=1 check="26"}
**Twomey反照率。**云光学厚度按滴数的2/3幂标度，所以液态水路径固定时反照率扰动随N^⅓。若污染使云滴数翻倍，云的亮度（N^⅓）按百分比增加多少？(2^⅓ = 1.26)
::: solution :::
2^⅓ = 1.26 → **+26%**——一个指数里的Twomey第一间接效应，自1990年代以来卫星图像编目的航迹增亮背后的机制、以及气溶胶有效辐射强迫（AR6约−0.5 W/m²的中心估计配其三倍范围）仍是强迫账本中最宽误差棒背后的机制：N每翻倍26%的亮度变化比所有温室气体强迫不确定性加起来还值钱。
:::
:::

::: exercise {level=2 check="0.26"}
**不稳定性消耗。**一列持有超出100 J/kg参考的2,000 J/kg CAPE；一个方案以τ = 2小时排空超出量。初始消耗率是多少W/kg？
::: solution :::
(1,900 J/kg)/(7,200 s) = **0.26 W/kg**整列均值——乘上约10⁴ kg/m²的列质量得到约260 W/m²的地基对流功率、与喂养它的地表潜热通量相当：练习把方案的松弛时标连到能量收支，并显示为什么τ短于大尺度强迫时标（准平衡）会让闭合、而不是动力学，决定雨下在哪里。
:::
:::

::: exercise {level=2 check="60"}
**受扰物理设计。**一个一次一参的受扰物理系综给30个方案参数中每个两个扰动（×0.7与×1.4）。该设计包含多少次受扰运行（不含控制）？
::: solution :::
30 × 2 = **60次**受扰运行（含控制61个成员）——方案拓扑的廉价地图；析因替代方案（2³⁰ ≈ 10⁹次同时扰动）就是2000–2020年代的计划（HadGEM物理系综数百成员的套件）改用采样与仿真器的原因，也是为什么"你的模式有多少个参数"开启每个结构不确定性研究。
:::
:::

::: exercise {level=2 check="1000000"}
**超参数化成本。**2002–2009年的超参数化GCM比其宿主模式慢约1,000倍。若宿主GCM每个模拟世纪需要1,000核时，超参数化版本的一个世纪花多少核时？
::: solution :::
1,000 × 1,000 = **1000000核时**（10⁶）每世纪——一台大陆级机器跑几个月，这就是为什么超参数化作为诊断仪器（2010–2020年代对流分辨列实验的过程研究）、而不是生产策略幸存，也是为什么灰区与机器学习路线——在要紧处买分辨的物理、其余地方用廉价替代物——是该领域选定的逃离千倍税的出口。
:::
:::

::: exercise {level=3 check="1.25"}
**深池敏感度。**若云辐射效应按平均云深标度、而某方案的夹卷削减把系综平均涌出高度从8公里加深到10公里，深池论证预测云强迫按什么因子变化？
::: solution :::
10/8 = **1.25**——涌出高度1.25倍的变化换来深度控制的强迫项25%的移动，深池假说的定量威胁：2017年约束所暗示量级的夹卷扰动（速率几十个百分点、高度几十个百分点）移动敏感度约1 °C，这就是"一族系数、一度预测"背后的算术。
:::
:::

::: exercise {level=3 check="0.7"}
**结构对参数散布。**在一个受扰物理系综里ECS标准差是0.7 °C；在两个方案架构不同的模式家族之间是1.4 °C。结构对参数方差之比是多少？
::: solution :::
(1.4/0.7)² = **4**——结构不确定性在方差上以约4:1压过参数不确定性，2010–2020年代方差分解的结果（结构对参数文献的中心数字）带着其直接的政策解读：重调现有方案无法把敏感度范围减半；只有新架构——预测云、学习物理、分辨对流——移动要紧的那个方差，而这正是2020年代建模投资去的地方。
:::
:::

::: exercise {level=3 check="0.79"}
**参数化误差的空气传播分数。**在一个模式家族里夹卷占ECS方差的一半；一次修复把夹卷误差减半（标准差减半、方差变为四分之一）。ECS总标准差按什么因子缩小？
::: solution :::
总方差从1降到0.5 + 0.125 = 0.625，所以σ按√0.625 ≈ **0.79**缩小——把最大的已知方案误差修好一半只把敏感度散布削减约21%，不确定性预算的平方根定律：方差被许多小项合谋守护，而公众期待参数化研究给出单点修复的奇迹，独立误差的算术不允许。
:::
:::

::: warning 关于参数化的四种误解
1. **"参数化是凑数因子。"**它们是理论——Arakawa–Schubert的烟羽系综假说是一个和任何湍流闭合一样实质的物理主张——带适用域、可对照探空、卫星与大涡模拟证伪（2017年夹卷约束在一个可测量的轴上证伪了多数生产方案）。叫它们凑数贬低了该领域实际的认识论地位、更糟的是其实际的进展：约束时代的修复是假说检验、不是拧旋钮。
2. **"对着观测多调参就能降低预测不确定性。"**调参钉住取值；预测依赖导数（反馈），而2019–2021年CMIP6事件公开演示了这种脱钩——最热的模式复现了历史趋势（就是对着它调的）、同时携带过程证据不支持的云反馈。调参碰不到的不确定性是结构性的，而诚实的度量是一个方案幸存多少个独立可观测量（AR6置信语言的隐含答案）。
3. **"分辨的模式将消灭参数化。"**云许可与云分辨模式仍然参数化微物理、辐射、表面——而在2024–2025年的前沿，如瓦解恐慌所示——在它们同样不分辨的尺度上夹卷与活化；2010–2020年代灰区文献一贯的结论是参数化问题沿谱往下搬、并不消失。分辨率改变的是哪些错误可以原谅，而学科应当停止承诺消灭、开始报告收敛。
4. **"方案在今天气候上的技巧验证了它2100年的行为。"**每个方案都在观测包络内标定（探空、卫星时代、历史趋势）、在包络外外推——层积云灾难与双ITCZ是今天的外推失败，而深池与瓦解之争是被投影出来的明天的：分布外泛化是机器学习社区的术语，而参数化研究五十年来一直在实践它；2020年代的ML方案只是带着更好的统计与零守恒保证继承了这个问题。
:::

## 总结

::: summary
参数化是不可分辨之物的必要物理：闭合问题保证网格化方程会制造未知数——应力、通量、云量——它们必须被理论化、不能被编码掉，而其产物方案家族（K理论边界层、Arakawa–Schubert准平衡及其质量通量后裔、Betts–Miller松弛、预测云与交互气溶胶、2010–2020年代的尺度感知与深池一代）是该领域关于对流、云与湍流的可证伪假说。这些方案同时是模式偏差（五十年的双ITCZ，一个方案系统的结构平衡、不是bug）与预测散布（云反馈占有敏感度范围，而2017–2025年夹卷事件——约束、深池重构、热模式验尸、层积云灾难与2024年瓦解恐慌——显示一族系数移动ECS一度）的最大贡献者。学科的机器如今是名副其实的科学的：声明的调参目标、受扰物理与随机系综、结构对参数的方差分解（4:1有利于架构）、从探空到大涡到EarthCARE的约束层级、以及逃生舱——超参数化、灰区分辨率、学习物理——其2020年代试验教导参数化沿谱下移、并不消失。给每个模式使用者的阅读规则：知道模式的数字里哪些是被解的、哪些是被参数化的、哪些是被调好的——因为这个区别决定模式被允许对一个其参数化从未观测过的世界知道什么。
:::
