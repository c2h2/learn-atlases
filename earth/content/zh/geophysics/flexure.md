地壳不是局部地漂浮。当一个载荷放在岩石圈上——一个火山、一个冰盖、一个山脉带、一个沉积的棱柱——板块**弯曲**、而弯曲把凹陷横向地扩展一百公里或更多、在它之外 抬起一个**周边的隆起**、而在板块里储存一个**弯曲的力矩**、它告诉你岩石圈有多强。弯曲因此是测量岩石圈的**强度**、不是它的结构的唯一的方法、而它的结果——一个年轻的海洋之下的5–15公里、一个古老的克拉通之下的20–40公里的弹性的厚度、而一个长期的强度远低于短期的——是地球动力学里最有结果的、与最有争议的那些数。

## 弹性的板块

::: definition 弯曲的方程与它的长度标度 {#def-plate}
一个有**弯曲的刚度**$D$的薄的弹性的板块在一个密度对比$\Delta\rho$的流体上在一个载荷$q(x)$下弯曲、服从
$$
D\frac{d^{4}w}{dx^{4}} + \Delta\rho\, g\, w = q(x), \qquad
D = \frac{E\,t_e^{3}}{12(1-\nu^{2})},
$$
其中$w(x)$是挠度、$t_e$是**弹性的厚度**、而$E$与$\nu$是杨氏模量与泊松比。方程有一个内在的长度、**弯曲的参数**
$$
\lambda = \alpha = \left(\frac{4D}{\Delta\rho\, g}\right)^{1/4} = 108\ \mathrm{km}\left(\frac{t_e}{30\ \mathrm{km}}\right)^{3/4}\left(\frac{500}{\Delta\rho}\right)^{1/4},
$$
而每个弯曲的问题被它标度。对一个$Q_0$（N m⁻¹）的**线载荷**、施加在$x = 0$、$x \geq 0$的解是阻尼的振荡
$$
w(x) = \frac{2Q_0}{\Delta\rho\, g\, \lambda}\, e^{-x/\lambda}\left[\cos\left(\frac{x}{\lambda}\right) + \sin\left(\frac{x}{\lambda}\right)\right],
$$
它的**中心的凹陷**是$w_0 = 2Q_0/(\Delta\rho g\lambda)$、它的**第一个零**在$x = 3\pi\lambda/4 = 2.36\lambda$、而它的**周边的隆起**在$x = \pi\lambda = 3.14\lambda$顶部、以一个$0.043\,w_0$的幅度。三个特征——凹陷、零与隆起——是在一个等深线的、重力的或大地水准面的剖面里寻找的东西、而隆起的**波长**决定$\lambda$、由此$D$与$t_e$**独立于载荷**、它使方法成为定量的、不是仅仅暗示的。

**载荷本身**是每个弯曲的计算的最微妙的部分。板块不支撑**现在的**地形、它的大部分已经被它自己的Airy的根平衡；它支撑**原始的**或**化石的**地形$h_a$——载荷在加载的时代的古的高度、从一个前陆的盆地的**古的等深线**与从一个剥露的造山带的**温压计**计算。使用现在的地形反而把载荷高估三到十倍的因子、而由此的$t_e$被相应量的、而同一个造山带的发表的弹性的厚度之间的分歧主要是关于原始的地形的分歧。
:::

::: widget plot

labels: w/w_0
caption: 一个线载荷的弯曲的响应$w/w_0 = e^{-u}(\cos u + \sin u)$、对以弯曲的参数的单位$u = x/\lambda$的距离绘制。挠度在$u = 3\pi/4 = 2.36$穿过零、在$u = \pi = 3.14$到达一个**周边的隆起**、为$-0.043$——一个只有中心的凹陷的4百分之一的上升、这就是为什么隆起那么常常被错过、而为什么当它**被**找到时、它是对$\lambda$的最可靠的约束。同样的曲线描述一个海山的**沟**、一个造山带的**前陆的盆地**、一个去冰川化的冰盖的**抬升的图案**、与一个破裂的边缘的**铰线的**、而四个那样不同的现象共享一个无量纲的形状是岩石圈确实地表现为一个弹性的板块的最强的单一的证据。
:::

## 三个自然的实验室

::: definition 海山与$t_e$的年龄的依赖 {#def-seamount}
一个孤立火山的海山以$10^{12}$–$10^{14}\ \mathrm{N}$加载海洋的岩石圈、产生一个下沉的海底的**沟**与一个**周边的隆起**、两者都埋在它的厚度反映挠度的沉积物之下。因为载荷是**轴对称的**、**独立地**站立、几何是干净的、载荷从火山自己的体积知道、而**填充**的改正是可处理的——这就是为什么海山、与**夏威夷-皇帝**与**深渊的** 隆起 是海洋的弯曲的型产地。三十年的**大地水准面与等深线**与**自由-空气异常的**分析的系统化的结果是海洋的岩石圈的弹性的厚度**随它的年龄增长**、在加载时、从5 Myr的约5–10公里到100 Myr的20–40公里、大致跟随**热边界层的厚度**$t_e \propto \sqrt{\text{age}}$——冷却的板块的**等温线**定义强度的观察、而约40公里深度的**1200 °C的等温线**是弹性的层的底部。

两个复杂的东西保留。**屈服-强度的-包络**的模型预测$t_e$应该**饱和**在20–30公里、因为板块的底部屈服、不是弹性地弯曲、而数据与50 Myr之外的饱和一致。而**加载的速率**重要：一个海山在1 Myr里加载、它与冷的岩石圈的Maxwell的时间相比是短的、与热的软流圈的相比是长的、所以板块在其顶部表现为**弹性的**、在下面表现为**粘性的**、而"弹性的厚度"是一个**频率的依赖的**量——在载荷下弹性地弯曲的同一个岩石圈在一个10-Myr的沉积的载荷下粘性地流动。
:::

::: definition 造山带、前陆的盆地、与屈服-强度的-包络 {#def-foreland}
一个山脉带加载相邻的大陆的板块、创造一个**前陆的盆地**：瑞士与巴伐利亚的阿尔卑斯的前陆、宾夕法尼亚的阿巴拉契亚的前陆、恒河的亚喜马拉雅的前陆、玻利维亚的安第斯的前陆。盆地的**深度**、**宽度**与**沉积的填充**的历史是经典的弯曲的数据、而它们得出的弹性的厚度——北美与欧洲的克拉通的20–40公里、年轻的边缘的10–20公里——是前陆的盆地被称为一个**弯曲的**盆地的原因。它的**不对称**（盆地在造山带的一边比隆起的一边更深、更陡）记录载荷的**分布**、不是它的总量、而它随时间的**迁移**记录造山带的**推进**。

**屈服-强度的-包络**（"膝"）调和弯曲与岩石力学。一个它的强度在它的脆性的上部由**Byerlee的摩擦**、在它的延性的下部由**幂律的蠕变**设定的岩石圈、有一个强度剖面的**积分**——屈服的**力矩**$M_{yl} = \int \sigma(z)\,z\,dz$——一个30公里厚的大陆的板块的$10^{16}$–$10^{17}\ \mathrm{N}$、对应一个10–20公里的**有效的**弹性的厚度、**不是**支撑长波长的**大地水准面**与**自由-空气**的异常所需的30–100公里。这是**强度的悖论**：岩石圈在**短的**波长与持续的载荷下表现得像它是弱的（$t_e \sim 20$ km）、在**长的**波长与**瞬变的**载荷下表现得像它是强的（$t_e \sim 100$ km）。解决是岩石圈是一个**弹性的核在一个粘性的或塑性的基底之上**、强直到它屈服、之后是弱的、而**加载以来的时间**决定哪个行为被看到。
:::

::: example 一个前陆的弹性的厚度 {#ex-foreland}
一个前陆的盆地的最大的沉降的轴在离山脉的前缘120公里、它的**周边的隆起**在380公里顶部。取$\Delta\rho = 500\ \mathrm{kg\,m^{-3}}$、$E = 70\ \mathrm{GPa}$、$\nu = 0.25$、求弯曲的参数与弹性的厚度。
::: solution
隆起的顶部直接固定弯曲的参数、因为它的位置独立于载荷：
$$
\pi\lambda = 380\ \mathrm{km} \quad\Rightarrow\quad \lambda = 121\ \mathrm{km}.
$$
第一个零然后在$2.36\lambda = 285\ \mathrm{km}$被预测、而观察的**最大的沉降的轴**在120公里是一个**载荷**的效应、不是一个板块的效应——对一个线载荷最大的挠度在载荷、所以在120公里的一个最大意味着载荷**分布**在山脉的前缘的约120公里上、它是对载荷的几何的一个**一致性的检验**、不是对$\lambda$的。刚度随之：
$$
D = \frac{\Delta\rho\, g\, \lambda^{4}}{4}
   = \frac{500\times9.81\times(1.21\times10^{5})^{4}}{4} = 2.6\times10^{23}\ \mathrm{N\,m},
$$
$$
t_e = \left[\frac{12(1-\nu^2)D}{E}\right]^{1/3}
    = \left[\frac{11.25\times2.6\times10^{23}}{7.0\times10^{10}}\right]^{1/3} = 35\ \mathrm{km}.
$$
一个**35公里**的弹性的厚度是一个**前寒武纪的克拉通的**前陆的典型、在造山带一般的范围的**上端**。

三个谨慎决定数是否意味着什么。**隆起很少是可见的**：它的幅度是凹陷的4百分之一、它埋在填充盆地的同样的沉积物之下、所以在大多数前陆的盆地里隆起从**地层学****推断**——浅水的沉积物在一个**铰线**之上的上超——不是测量、而由此的$\lambda$不确定的30百分之一、$t_e$不确定的25百分之一。**载荷是分布的、不是线性的**：一个真实的造山带有一个变细的地壳的根的楔、而一个线载荷与一个同样总量的**棱柱的**载荷之间的差别是一个20–40百分之一的模型化的形状的变化。**而$t_e$是一个**有效的**的值**：同一个前陆从它的**重力**的异常、从它的**大地水准面**的异常、从它的**地层的**回剥分析给出20、35与50公里、而散布是模型的不足的一个测量、不是数据的。

数值得有的原因是$t_e$控制盆地**哪里**去、由此**哪里**石油的系统是：Alberta、Michigan与Appalachian的盆地的烃源岩、储层与圈闭都由加载它们的造山带的弯曲的波长排列。
:::
:::

::: example 一个海沟的弯曲的应力与板块的强度 {#ex-trench}
进入一个俯冲带的海洋的板块在一个100公里的弯曲的参数上下沉2.0公里。求一个30公里的弹性的厚度的板块的表面的最大的弯曲的应力、而用观察的外缘的断层作用解释它。
::: solution
对线载荷的挠度、在载荷的曲率是$|d^2w/dx^2| = 2w_0/\lambda^2$、而表面的**弯曲的应力**是
$$
\sigma_{\max} = E\,\frac{t_e}{2}\,\frac{2w_0}{\lambda^{2}} = \frac{E\,t_e\,w_0}{\lambda^{2}}
   = \frac{7.0\times10^{10}\times3.0\times10^{4}\times2.0\times10^{3}}{(1.0\times10^{5})^{2}} = 420\ \mathrm{MPa}.
$$
一个**420 MPa**的弯曲的应力加到板块自己的**脊推力**或**滑拉力**的应力的100–300 MPa、使板块的表面到**破坏**、而这正是观察到的：每个主要的海沟之外的**外缘**是**地垒与地堑**的地形、在板块向下转之前50–100公里被伸展的断层断层化、它产生大的**正断层**的地震——1933年Sanriku $M 8.5$、2006年$M 8.1$的Loailatek、2009年$M 8.1$的Macquarie、2021年$M 8.1$的Kermadec的事件——在20–40公里的深度、与**不一致**于俯冲的震源机制。

解释是**弯曲的力矩**的平衡。板块能维持一个约$10^{17}\ \mathrm{N}$的**屈服的力矩**$M_{yl}$、在它整体屈服之前、而观察的挠度要求的**弹性的**弯曲的力矩是
$$
M_{el} = D\left|\frac{d^2w}{dx^2}\right| = D\frac{2w_0}{\lambda^2},
$$
对一个$D = 5.25\times10^{22}\ \mathrm{N\,m}$（一个30公里的板块的刚度）是$2.1\times10^{17}\ \mathrm{N}$——**两倍**于屈服的力矩。板块因此在这个波长**不能**是整体的弹性、而外缘是**破裂的**：隆起的**波长**暗示的弹性的厚度是30公里、它的**幅度**暗示的是15公里、而分歧是一个在其**顶部是弹性的、在其底部是塑性的**的板块的经典签名。

对俯冲的力的收支的后果是大的。一个**强的**（弹性的）板片能跨过海沟从下沉的一肢向表面的板块传递**板片拉力**、而海沟将是**圆的**；一个**弱的**板片不能、而海沟是**线性的**、上盘做大部分的工作。一个海沟的**曲率**与俯冲的板块的**年龄和汇聚的速率**之间观察的相关——老的、快的板块给圆的、陡的倾斜的拉动的板片、年轻的、慢的板块给线性的海沟与浅的板片——是弯曲的强度的**几何的**检验、而它支持大多数俯冲带的**海沟处是弱的**的观点。
:::
:::

::: definition 冰川的后的回弹与粘弹性的地球 {#def-gia}
一个冰盖在$10^3$–$10^4$年里加载岩石圈、它与岩石圈的弹性的**Maxwell**的时间相比是**长的**、与地幔的相比是**短的**、所以响应是**粘弹性的**：板块在冰下**弹性地**弯曲、地幔在它下面**粘性地**流动、而当冰融化时表面以一个松弛的时间回弹
$$
\tau = \frac{\eta\, k}{\rho\, g}
$$
对一个波数$k = 2\pi/L$的载荷——一个1000公里的载荷、一个$10^{21}\ \mathrm{Pa\,s}$的地幔的粘度是6000年。观察的图案是一个曾经被冰川覆盖的区域的**抬升的图**：一个Fennoscandia之上的8–10 mm yr⁻¹的、Hudson Bay之上的8–12 mm yr⁻¹的中心的抬升的**前隆**、一个在1000–1500公里的抬升的**周边的隆起**、与一个在曾经的冰的边缘产生**淹没**的**前隆的塌陷**——Hudson Bay的低地与波罗的海的海岸有一个上升然后下降的全新世的**相对的**海平面的记录的原因。同样的物理产生GRACE测量的**重力**的信号、整个地球的**$J_2$**的趋势、与行星的**真正的极的漂移**、而它是在它的记录能与全球的均值比较之前必须应用于一个曾经被冰川覆盖的边缘上的每个潮汐计的**改正**。
:::

::: example 夏威夷的隆起：如何识别一个板块不能承载的载荷 {#ex-hawaii}
夏威夷的火山链站在一个宽阔的**隆起**的抬高的海底之上、它的幅度是1400米、它的半宽、从海岭到深度回到90-Myr的地壳的正常的4500米之点测量、是1200公里。取隆起的半宽为$2.36\lambda$、求一个弯曲的模型要求的弹性的厚度、而解释。
::: solution
$$
\lambda = \frac{1200}{2.36} = 508\ \mathrm{km}, \qquad
t_e = 30\left(\frac{508}{108}\right)^{4/3} = 30\times7.9 = 240\ \mathrm{km}.
$$
一个**240公里**的弹性的厚度是整个海洋的岩石圈在90 Myr的厚度的三到六倍、它到1300 °C的等温线约是80–100公里。弯曲的模型因此**失败**、而失败是要点：隆起**太宽**、不能被岩石圈的弹性的强度承载、而需要**动力的**支撑——一个地幔柱的向上的粘性的应力——加上火山自己提供的任何弯曲的支撑。

两者的**分配**是现代的辩论的实质、而它由**波长**做出。链的**短的波长**的地形、在100–300公里、被岩石圈弯曲、给出一个20–40公里的弹性的厚度、与加载时的板块的年龄一致。**长的波长**的隆起、在1000–2000公里、不是、而它的幅度与波长需要一个$10^{12}$–$10^{13}\ \mathrm{N\,m^{-1}}$的**动力的**载荷、施加在岩石圈的底部、由一个几Sverdrup的柱的通量。两个信号由大地水准面与等深线的一个**谱的**分析分开、在其中它们之间的**导纳**对波数绘制：在高的波数导纳跟随弹性的板块的预测、在低的波数它**偏离**它、而偏离的波数是弯曲的参数。

三个后果普遍化。**一个拟合到一个宽的隆起的弯曲的模型系统地高估弹性的厚度**、而同一个岩石圈的从一个100公里的海山、从一个1000公里的隆起报告的$t_e$因此差二到三倍的因子。**对弹性行为的偏离本身是一个测量**：导纳降到弹性的预测之下的波数**独立于幅度**地约束**弹性的层的厚度**、而它是**Lowry、Watts、Pérez-Gussinyé与Sandwell**的**的**相干**的方法的基础、它从重力与地形单独产生$t_e$的全球的图。**而一个宽的隆起的存在是一个柱的证据**：**非洲的**、**始新世的**与**塔斯曼的**隆起、它们的波长是1000–2000公里、它们的幅度是500–1500米、是一个板块之下的**地幔的上涌**的经典证据、而它们的**年龄的进展的**出现是**柱**的解释的热点的轨迹的两三个论据之一。
:::
:::

::: example Fennoscandia的前隆与弹性的极限 {#ex-forebulge}
Fennoscandia的现在的抬升有一个在曾经的冰盖的中心的$9\ \mathrm{mm\,yr^{-1}}$的最大、与一个次级的最大——**周边的隆起**——在离它约1200公里。取隆起的位置为$\pi\lambda$、求一个弹性的模型将要求的弹性的厚度、而解释为什么弹性的模型是错误的模型。
::: solution
$$
\lambda = \frac{1200}{\pi} = 382\ \mathrm{km}, \qquad
t_e = 30\left(\frac{382}{108}\right)^{4/3} = 30\times5.4 = 162\ \mathrm{km}.
$$
一个**162公里**的弹性的厚度又远大于岩石圈、而弯曲的模型又不仅仅是不精确、是**类别错误的**。Fennoscandia的抬升不是一个板块的弹性的弯曲；它是一个在10 000年前被移除的载荷之下的地幔的**粘性的松弛**、而"隆起"是在冰川作用期间在冰的边缘形成的**前隆的塌陷**、现在在中心上升时下陷。

正确的模型是**粘弹性的**、其中表面的位移是一个**固体地球的**松弛的时间$10^2$到$10^4$年的**正规模态**的和、其中变形的**波长**不由一个弹性的长度设定、由地幔的流动的**粘性的扩散的长度**$\sqrt{\mu\lambda_{\mathrm{flow}} t/\eta}$设定、它随松弛的进行**随时间增长**。这就是为什么冰川的后的抬升的**图案**在全新世**迁移**了、为什么现在的抬升的最大在上次冰盖的中心之下、不在**波的尼亚湾**之下、而为什么一个在离冰的中心1000公里的场地的**相对的**海平面的曲线在一个单一的全新世的序列里上升然后下降。

教训普遍化到每个长寿命的载荷。**一个应用于一个它的持续时间超过支撑的层的Maxwell的时间的载荷的弹性的模型、给出一个弹性的厚度、它是模型的失败的一个测量、不是岩石的强度的。**上地幔的Maxwell的时间、$\tau_M = \eta/\mu = 10^{21}/7\times10^{10} = 1.4\times10^{10}\ \mathrm{s} = 450\ \mathrm{yr}$、只有几个世纪、所以**任何在一个千年之上施加的载荷被地幔粘性地承载**——这就是为什么弯曲的方法对一个在冷的板块的1 Myr里加载的**海山**工作、对一个**冰盖**与一个**1000公里的隆起**失败。
:::
:::

::: warning 弹性的厚度是一个拟合的参数、不是一个的厚度的测量
弯曲的问题的五个性质使$t_e$是地球科学里最不可比的数之一。**它是一个等效的厚度**：真实的岩石圈有一个**随深度变化的**强度、而$t_e$是**均匀的弹性的板块**的厚度、它将弯曲那么多、所以一个30公里的$t_e$不意味着30公里的冷的、强的岩石。**它依赖载荷的波长**：一个宽度$W$的载荷在一个约$\sqrt{\lambda W}$的深度上采样板块的强度、所以一个小的海山测量一个**更浅的、更弱的**层、而同一个岩石圈的报告的一个海山的研究、一个大地水准面的研究的$t_e$能差二倍的因子。**它依赖载荷的年龄与持续时间**：一个在1 Myr里施加的载荷被弹性地承载、同样的载荷在30 Myr里施加粘性地松弛、而记录在一个老的盆地的地层学里的"化石的"弯曲反映一个不再存在的强度。**它依赖原始的地形**、它除了二倍的因子是不可知的、而$t_e$随假设的载荷的**四分之三次幂**标度、所以一个古的高度的50百分之一的误差是一个弹性的厚度的90百分之一的误差。**而两个经典的方法系统地不一致**：**大地水准面与等深线**的方法、使用场的**长的波长**的部分、给出**自由-空气异常**的方法的$t_e$的值的1.5到3倍、它使用**短的波长**的部分、而分歧归于隆起之下的**地幔的上涌**（它加一个长的大地水准面的信号、弹性的模型作为额外的强度吸收它）、归于在长的波长的板块的**有限的强度**。学科是发表**载荷的模型、原始的地形、使用的波长的带、密度的结构与填充的改正**与每个$t_e$、而对待使用了不同的方法的研究之间的比较作为**定性的**。
:::

::: history
弹性的板块的弯曲是**Kirchhoff**与**Love**的数学；它对地球的应用从**Barrell**在1914年开始、他论证地壳必定有**强度**、与**Jeffreys**与**Vening Meinesz**、在1926–1941年发展了Airy的地静平衡的**刚性的岩石圈**的替代、预测了周边的隆起。**Daly**在1940年提出了海洋的盆地的**通过强度的补偿**、**Vening Meinesz**在1948年计算了大西洋的第一个**网格**的弯曲的模型。**Morgan**与**Cochran**在1971–1974年确立了**夏威夷的**弯曲的签名、**Sandwell**与**Schubert**在1982年使**大地水准面与等深线**的方法成为常规的、而**Wessel**建造了全球的海山的数据库。**Walcott**在1970年发表了**屈服-强度的-包络**、**Molnar与Lyon-Caen**与**Burov与Diament**在1988–1995年发表了**强度的悖论**与**膝**、而**Watts**、**Burov**、**Lowry**与**Pérez-Gussinyé**从重力和地形的**导纳**与**相干**发表了$t_e$的全球的图。**Cathles**、**Wu与Peltier**、**Nakada与Lambeck**与**Mitrovica**建造了地幔的粘度和海平面的改正建立于其上的**粘弹性的**冰川的后的回弹的模型、而**Nakada与Lambeck**建造了全球的冰的历史的模型。**被动的边缘的弯曲的悖论**是**Watts与Thirlaway**在1992年的工作、与它的由**Pérez-Gussinyé**、**Welford与Watts**提出的解决。
:::

## 通向何处

弯曲是Airy的补偿的替代于其中的地静平衡的框架在[[geophysics/gravity-isostasy]]、预测$t_e$的地震的结构与热的模型在[[geophysics/seismic-structure]]与[[geophysics/heat-flow]]、弯曲创造的**前陆的盆地**在[[sedimentology/basins-sequences]]与[[structural-geology/orogens]]、破裂的边缘在[[structural-geology/rifts]]、冰川的后的回弹与它的冰盖在[[glaciology/ice-sheets]]与[[geomorphology/glacial-landscapes]]、俯冲的力在[[physical-geology/plate-tectonics]]、而整个方法建立于其上的重力与大地水准面的数据在[[geophysics/gravity-isostasy]]与[[remote-sensing/radar-lidar]]。

::: quiz
一个海山的沟与周边的隆起在离载荷60公里、200公里观察。若你把载荷加倍、它们的位置会怎样？
- [ ] 两者以一个二倍的因子向外移动。
- [x] 它们留在它们所在之处。
- [ ] 沟向外移动、隆起向内移动。
- [ ] 两者向内移动。
::: solution
零与隆起的位置只由弯曲的参数$\lambda$设定、它只依赖板块的刚度与密度的对比——不依赖载荷。加倍载荷加倍整个的曲线的**幅度**、包括隆起、而留下它的**波长**不变。这恰恰是为什么隆起的位置是对$t_e$的最干净的约束、而幅度不是：幅度要求知道载荷、它是问题里最不为人知的量。
:::
:::

::: summary
- 岩石圈作为一个弹性的板块弯曲、有一个长度标度、弯曲的参数、对一个15–30公里的弹性的厚度是60–110公里。
- 周边的隆起在$\pi\lambda$、只有凹陷的4百分之一、但它的位置独立于载荷、因此是强度的最好的约束。
- 海洋的岩石圈的弹性的厚度随年龄增长、大致作为热边界层、而饱和在20–30公里。
- 一个海沟的弯曲的应力达到400 MPa、它破坏外缘、在俯冲之前产生大的正断层的地震。
- 屈服-强度的-包络调和弱的（20公里）与强的（100公里）弹性的厚度：岩石圈是弹性的直到它屈服。
- 冰川的后的回弹是同样的问题的粘弹性的版本、是地幔的粘度的来源。
:::

## 练习题

::: exercise 弯曲的刚度 {level=1 check="5.25"}
求一个$t_e = 30\ \mathrm{km}$、$E = 70\ \mathrm{GPa}$、$\nu = 0.25$的板块的弯曲的刚度。
::: solution
$D = E t_e^3/[12(1-\nu^2)] = 7\times10^{10}\times2.7\times10^{13}/11.25 = 5.25\times10^{22}\ \mathrm{N\,m}$。因为$D \propto t_e^3$、一个弹性的厚度的20百分之一的误差是一个刚度的**73百分之一**的误差、这就是为什么$t_e$最多被引用到两个有效的数字。
:::
:::

::: exercise 弯曲的参数 {level=1 check="86"}
求$D = 2.0\times10^{22}\ \mathrm{N\,m}$、$\Delta\rho = 600\ \mathrm{kg\,m^{-3}}$的弯曲的参数。
::: solution
$\lambda = (4D/\Delta\rho g)^{1/4} = (8.0\times10^{22}/5886)^{1/4} = (1.36\times10^{19})^{1/4} = 86\ \mathrm{km}$。在海洋的岩石圈上密度的对比接近600、在大陆上接近500、所以同样的刚度在大陆上给出一个5百分之一更大的$\lambda$。
:::
:::

::: exercise 隆起的位置 {level=1 check="251"}
对$\lambda = 80\ \mathrm{km}$、求到周边的隆起的顶部的距离。
::: solution
$x = \pi\lambda = 251\ \mathrm{km}$。第一个零在$2.36\lambda = 189\ \mathrm{km}$、所以**沟**在190公里之内、**隆起**在它之外——每个前陆的盆地与每个火山的隆起的几何。
:::
:::

::: exercise 中心的凹陷 {level=2 check="204"}
一个$Q_0 = 5\times10^{11}\ \mathrm{N\,m^{-1}}$的线载荷施加在一个$\lambda = 100\ \mathrm{km}$、$\Delta\rho = 500\ \mathrm{kg\,m^{-3}}$的板块上。求中心的凹陷。
::: solution
$$
w_0 = \frac{2Q_0}{\Delta\rho\, g\, \lambda} = \frac{1.0\times10^{12}}{500\times9.81\times10^{5}} = 204\ \mathrm{m}.
$$
一个$5\times10^{11}\ \mathrm{N\,m^{-1}}$的线载荷——一个2公里高、20公里宽的山脉带的重量——的200米的凹陷显示一个30公里的弹性的板块多么**硬**、而为什么一个真实的2–3公里深的前陆的盆地需要一个**大得多**的载荷或一个**弱得多**的板块、比弹性的模型允许的。
:::
:::

::: exercise 弯曲的应力 {level=2 check="210"}
求$w_0 = 1000\ \mathrm{m}$、$\lambda = 100\ \mathrm{km}$、$t_e = 30\ \mathrm{km}$、$E = 70\ \mathrm{GPa}$的最大的弯曲的应力。
::: solution
$\sigma = E t_e w_0/\lambda^2 = 7\times10^{10}\times3\times10^{4}\times10^{3}/10^{10} = 210\ \mathrm{MPa}$。这**低于**一个冷的岩石圈的屈服的强度、所以板块弹性地弯曲；加倍挠度使它到420 MPa、板块**破裂**、这就是为什么外缘的断层作用在一个1–2公里的特征的挠度开始、不是逐渐地。
:::
:::

::: exercise 年龄的依赖 {level=2 check="28"}
海洋的岩石圈的弹性的厚度跟随$t_e = 3.6\sqrt{\text{age}}$公里、以Myr的年龄。求60 Myr、120 Myr的$t_e$、而评论。
::: solution
$t_e = 3.6\sqrt{60} = 27.9$公里、$3.6\sqrt{120} = 39.4$公里。**平方根的**定律是一个热模型、其中弹性的厚度是一个冷却的半空间的一个固定的**等温线**的深度、而它拟合数据到40–60 Myr；超过那个观察**饱和**在30–40公里、它是屈服-强度的-包络的预测、而岩石圈的底部**屈服**、不是弹性地弯曲的最干净的两三个证据之一。
:::
:::

::: exercise 强度的悖论 {level=3 check="8"}
一个前陆的盆地的**波长**暗示$t_e = 40\ \mathrm{km}$、它的**幅度**、对已知的载荷、暗示$t_e = 20\ \mathrm{km}$。两个模型在刚度上差多少倍的因子、而给出分歧的两个物理的理由。
::: solution
$D \propto t_e^{3}$、所以两个模型在刚度上差$(40/20)^3 = 8$。

两个最常被引用的解决都部分是对的。**塑性的屈服**：板块在大地水准面与自由-空气的异常的长的波长**弹性地**弯曲、那里的弯曲的应力是小的、但在盆地的轴的短的波长**屈服**、那里的应力是大的、所以波长的测量看到完整的板块、幅度的测量看到屈服的那个。**地幔的流动**：一个**长的波长**的大地水准面的异常有一个来自**地幔的上涌**、来自**动力的地形**的贡献、弹性的模型作为额外的板块的强度吸收它、所以从波长得出的$t_e$被**高**地偏置；这是大地水准面与等深线的方法和自由-空气异常的方法之间的系统的差别的标准的解释。

第三个、更不舒服的可能性是**载荷是错的**：原始的地形作为$h_a^{4/3}$进入幅度、所以一个古的高度的40百分之一的低估将调和两者、没有任何物理。因为一个造山带的古的高度至少那样不确定、强度的悖论从未为一个**单一的**前陆的盆地干净地证明、只从应用于**许多**的的方法之间的系统的差别论证。
:::
:::

::: exercise 被动的边缘的悖论 {level=3 check="100"}
一个非火山的被动的边缘的地形要求一个至少100公里的弹性的厚度、以被弯曲解释、然而边缘的热流与它的地震的深度暗示一个不超过20公里厚的岩石圈。估计要求的**弯曲的刚度**超过允许的多少倍的因子、而解释悖论如何解决。
::: solution
$D \propto t_e^{3}$、所以要求的刚度超过允许的$(100/20)^3 = 125$——约**两个数量级**。

悖论通过放弃两个前提之一解决、而三个解决是当前的。**边缘在加载时是强的、现在是弱的**：记录在边缘的**地层学**里的弯曲在裂谷之后的头10–20 Myr产生、在沉积的载荷有时间被它之下热的、新变薄的**地幔的流动**补偿之前、而现在的热流测量一个自从**弱化**了几千万年的松弛的岩石圈。**载荷不是我们认为的**：边缘的下沉部分由**小尺度的对流**与**动力的地形**驱动、不是由沉积的载荷、而"弯曲的"模型在拟合错误的过程。**而边缘比它的温度暗示的强、因为它是干的**：上地幔的强度由橄榄石里的**水**设定、而一个脱水的克拉通的根比流动定律假设的湿的橄榄岩强10–100倍、它提高屈服的力矩、不改变温度。

最后的解决是最支持的、而它普遍化：橄榄石的**氢的含量**控制岩石圈的强度、而一个**干的**岩石圈能携带一个它的**温度**不允许的弯曲的力矩。这就是为什么**老的、冷的、干的**克拉通的弹性的厚度是40–60公里、爱琴海与盆地山脉的**热的、水化的**边缘的是5–10公里、而为什么岩石圈的强度最终是一个**地球化学的**、不是热的性质。
:::
