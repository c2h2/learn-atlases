重力是最古老的地球物理的方法、仍然最直接的：一个重力仪测量自由的落体的局部的加速度、而那个测量对一个光滑的、旋转的、均质的地球期望的值的每个偏离是关于仪器之下的质量的分布的一个陈述。两个思想组织整个的主题。第一个是地球的形体——它的扁率、它的大地水准面、它的重力的场——是旋转与内部结构的**静水的**的结果、所以重力的数据同时测量行星的**形状与密度**。第二个、使地球物理成为地壳的科学、不是行星的科学的、是**地静平衡**：地形不是由岩石的强度承载、在下面的密的地幔上**漂浮**、所以一个山有一个根、它之上的自由-空气的异常几乎是零。

## 地球的形状与它的重力的场

::: definition 大地水准面、椭球、与正常的重力 {#def-geoid}
地球的表面由一个**扁的旋转椭球**（**参考的椭球**）近似、赤道半径$a = 6{,}378.137\ \mathrm{km}$、极半径$b = 6{,}356.752\ \mathrm{km}$、**扁率**
$
f = \frac{a-b}{a} = \frac{1}{298.257} .
$
**大地水准面**是真实的重力的场的一个等位面、它与通过大陆的表面的平均的海面重合；它偏离椭球$-106$到$+85\ \mathrm{m}$、一个在12 742公里的球上只有19厘米的起伏、它是（误导的）"地球比一个台球更光滑"的说法的来源——它在**台球自己的缺陷的标度**上比一个台球光滑、在一个测地学家有关的标度上更粗糙。

椭球上的**正常的重力**、以毫伽、由国际的重力的公式给出、
$
g(\varphi) = 978{,}032.7\left(1 + 0.0053024\sin^2\varphi - 0.0000059\sin^2 2\varphi\right),
$
它从赤道到极上升5138 mGal、有两个理由：极离质量的中心**近**21公里、而**离心的**加速度在那里消失。两个效应由**Clairaut的定理**联系、它对一个在静水的平衡的流体给出**带谐**
$
J_2 = \tfrac{2}{3}f - \tfrac{1}{3}m, \qquad m = \frac{\omega^2 a^3}{GM} = 0.003461 ,
$
预测$J_2 = 0.001082$、对着观察的$0.0010826$——一个到0.1百分之一的一致、确立地球一阶地、在**静水的平衡**、而$J_2$的**非静水的**部分（它的约1百分之一）是**地幔的**对流与最后的冰期的化石的形体。
:::

::: definition 异常与它们的改正 {#def-anomaly}
一个重力**异常**是观察的值减去同样的纬度的正常的值、在每一个移除一个已知的几何的效应的一系列的改正之后：
$
\begin{array}{l|l|l}
\text{correction} & \text{magnitude} & \text{removes} \\ \hline
\text{drift and tide} & \text{varies} & \text{instrumental drift, Earth and ocean tides} \\
\text{free-air (FA)} & +0.3086\ \mathrm{mGal\,m^{-1}} & \text{height above the datum } (\partial g/\partial r = -2g/R) \\
\text{Bouguer (BC)} & -0.1119\,\rho\ \mathrm{mGal\,m^{-1}} & \text{the slab of rock between station and datum } (2\pi G\rho h) \\
\text{terrain (TC)} & \text{up to } \pm 50\ \mathrm{mGal} & \text{nearby topographic masses (Hammer zones, digital elevation models)} \\
\text{air (AC)} & -0.0001\ \mathrm{mGal\,m^{-1}} & \text{the atmospheric column above the station}
\end{array}
$
**自由-空气的异常**$\Delta g_{\mathrm{FA}}$保留地形的质量、因此是检验**地静平衡**的异常：它在一个补偿的山之上是接近零、在一个未补偿的之上强地是正的。**Bouguer的异常**$\Delta g_{\mathrm{B}} = \Delta g_{\mathrm{FA}} - 2\pi G\rho h$也移除地壳的层、因此是成像**深部的结构**的异常：一个负的Bouguer的异常意味着一个**厚的地壳或一个浅的地幔**、一个正的意味着一个**密的矿体或一个薄的地壳**。两者一起是区域的构造的基本的数据集、而它们的联合的解释是**地静的异常**与**莫霍面的深度的估计**。
:::

::: example 一个重力的站与它的异常 {#ex-anomaly}
一个在1800米的一个高原上的重力仪读$g = 979{,}654.2\ \mathrm{mGal}$；在那个纬度的正常的重力是$979{,}956.8\ \mathrm{mGal}$。取地壳的密度为$2670\ \mathrm{kg\,m^{-3}}$、地形的改正为$+3.1\ \mathrm{mGal}$。求自由-空气的与Bouguer的异常、而解释。
::: solution
原始的差是
$
\Delta g_{\mathrm{obs}} = 979{,}654.2 - 979{,}956.8 = -302.6\ \mathrm{mGal}.
$
为1800米的高程加上自由-空气的改正、
$
\Delta g_{\mathrm{FA}} = -302.6 + 0.3086\times1800 + 3.1 = -302.6 + 555.5 + 3.1 = +256.0\ \mathrm{mGal},
$
而为站在海平面之间的地壳的板的Bouguer的改正、
$
\text{BC} = 0.1119\times1800 = 201.4\ \mathrm{mGal}, \qquad
\Delta g_{\mathrm{B}} = 256.0 - 201.4 = +54.6\ \mathrm{mGal}.
$
系数$0.1119\ \mathrm{mGal\,m^{-1}}$已经包含密度$2.67\ \mathrm{g\,cm^{-3}}$、所以不再应用密度的因子；对一个$2500\ \mathrm{kg\,m^{-3}}$的地壳系数是$0.1048$、改正是$188.6\ \mathrm{mGal}$。
两个异常是**正的**、而那是诊断的。一个**局部的Airy的地静平衡**的一个高地的区域有一个接近**零**的自由-空气的异常、一个强地**负的**Bouguer的异常、因为根用地壳替换地幔。这里自由-空气的异常是$+256$ mGal、它意味着高原的质量**不**由一个Airy的类型的根补偿、而Bouguer的异常是**正的**、它意味着根本**没有**深的地壳的根。

解释是高原由一个厚的、冷的岩石圈的**弯曲的强度**、由地幔的流动的**动力的**支撑支撑、不是由局部的地静平衡——**阿尔蒂普拉诺**、**迪纳拉**的高原与**Erta Ale**的隆起的签名、与西藏的签名的相反。替代的阅读、站坐在一个浅的深度的**密的侵入的矿体**之上、由异常的**区域的**范围、一个对应的磁的异常的缺失排除、而由莫霍面在正常的深度的**地震的**约束确认。

这个例子的算术的陷阱是抓住每个学生的：自由-空气的改正**加上**、Bouguer的改正**减去**、而自由-空气的改正是每米的**高程**的$+0.3086$、无论站在一个山上、一个矿里。一个符号的错误产生一个错了两倍的Bouguer的项的Bouguer的异常、对1800米是400 mGal——比方法能探测的任何异常大。
:::
:::

::: definition Airy、Pratt、与深度的压力 {#def-isostasy}
**地静平衡**是深的**补偿的深度**的垂直的应力（**压力**）在一个山与一个平原之下是同样的假说、所以不需要横向的应力的梯度、长期的流动以维持地形。两个经典的实现不同在低密度的质量放在**哪里**：
$
\begin{array}{ll}
\textbf{Airy (1855)}: & \text{crust of constant density and variable thickness, } r = h\,\dfrac{\rho_c}{\rho_m-\rho_c} \\[8pt]
\textbf{Pratt (1855)}: & \text{crust of constant depth and laterally varying density, } \rho_1(h_1+d) = \rho_2(h_2+d)
\end{array}
$
对$h = 5\ \mathrm{km}$、$\rho_c = 2800$、$\rho_m = 3300\ \mathrm{kg\,m^{-3}}$、Airy的根是$5\times2800/500 = 28\ \mathrm{km}$、给出约$70\ \mathrm{km}$的总的地壳的厚度——西藏与安第斯之下的莫霍面的观察的深度、而这个学科的历史上最成功的定量的预测。一个在完美的的小的地静平衡的区域之上的**观察的**自由-空气的异常**恰好是零**、而观察的自由-空气的异常偏离零测量**由地静平衡之外的别的东西支撑的载荷的分数**——由弯曲、由动力的流动、或由一个的热的异常的浮力。

**Bouguer**的改正的密度自己是一个地静的参数、而选择不是自由的：**Vening Meinesz**证明使一个区域的Bouguer的异常消失的密度是**地静的削减的密度**、经验的、大陆的$2600$–$2900\ \mathrm{kg\,m^{-3}}$、它是**平均的**地壳的密度、不是任何特别的岩石的。一个使异常在一个沉积的盆地上消失的$1600\ \mathrm{kg\,m^{-3}}$的削减的密度因此是关于盆地的**补偿**的一个陈述、不是关于它的填充的密度。
:::

caption: 对$\rho_c = 2800$、$\rho_m = 3300\ \mathrm{kg\,m^{-3}}$的Airy的根$r = h\,\rho_c/(\rho_m-\rho_c)$、给出一个**5.6**的根对高程的比。比是**密度的对比的强烈的非线性的函数**、一个50 kg m⁻³更密的地幔（3350）把它降到4.9、一个100 kg m⁻³不那么密的地壳（2700、一个花冈岩的或热液蚀变的地壳）把它降到5.4——所以从一个高程估计的一个莫霍面的深度不确定的几公里、即使高程精确地知道。线在两个方向使用：一个**高程**预测一个莫霍面的深度、一个**地震的**莫霍面的深度预测区域将在地静的平衡的高程、它偏离观察的高程的差是**动力的地形**——地幔的对流的模型实际预测的量、现在是地球动力学与观察之间的标准的比较。

## 弯曲与岩石圈的强度

::: definition 弹性的板块与弯曲的参数 {#def-flexure}
一个真实的岩石圈不局部地流动：它**弯曲**。一个**弯曲的刚度**
$
D = \frac{E\,t_e^{3}}{12(1-\nu^{2})}
$
的二维的弹性的板块、在一个密度$\Delta\rho$的流体上以一个$\Delta\rho\, g\, h$的载荷加载、给出一个服从
$
D\frac{d^4 w}{dx^4} + \Delta\rho\, g\, w = q(x)
$
的挠度$w(x)$、它对一个点载荷的解是一个**阻尼的振荡**、带**弯曲的参数**
$
\alpha = \left(\frac{4D}{\Delta\rho\, g}\right)^{1/4},
$
板块的响应衰减$1/e$的距离。对$t_e = 30\ \mathrm{km}$、$E = 70\ \mathrm{GPa}$、$\nu = 0.25$、$\Delta\rho = 500\ \mathrm{kg\,m^{-3}}$、$D = 1.68\times10^{23}\ \mathrm{N\,m}$、$\alpha = 108\ \mathrm{km}$；对$t_e = 15\ \mathrm{km}$、$\alpha = 64\ \mathrm{km}$。一个**海山**或一个**俯冲的海沟**之上的大地水准面与自由-空气的异常的**观察的**形状因此决定$t_e$——**岩石圈的弹性的厚度**——而值、年轻的海洋的板块的5–15公里、老的、冷的、前寒武纪的克拉通的20–40公里、是地球动力学里最重要的、最被误解的那些数。

**误解**是$t_e$是一个**厚度**。它不是：它是一个**等效的**板块的厚度、它将弯曲得和真实的那个一样多、而真实的岩石圈在基底的应力超过约100–300 MPa时**屈服**、所以它的长期的行为是一个**弹性的板块在一个塑性的核之上**——**Watts、Bunge、与"岩石圈的强度"的学派**的**屈服-强度的-包络**或"**膝**"。短期的强度（从**屈服的力矩的包络**、从冰川的后的回弹）远大于长期的强度（从**深海的沟的等深线**、从**俯冲**的弯曲）、而十倍的因子的分歧是这个领域的突出的问题之一。
:::

::: example 从一个海山的弹性的厚度 {#ex-te}
一个1200米高、40公里宽的火山的海山站在30 Myr老的海洋的岩石圈上、而重力和等深线的数据要求一个$\alpha = 70\ \mathrm{km}$的弯曲的参数。求弯曲的刚度与弹性的厚度、取$\Delta\rho = 600\ \mathrm{kg\,m^{-3}}$、$E = 70\ \mathrm{GPa}$、$\nu = 0.25$。
::: solution
逆弯曲的参数、
$
D = \frac{\Delta\rho\, g\, \alpha^{4}}{4}
   = \frac{600\times9.81\times(7.0\times10^{4})^{4}}{4}
   = \frac{5886\times2.401\times10^{19}}{4} = 3.54\times10^{22}\ \mathrm{N\,m},
$
逆刚度、
$
t_e = \left[\frac{12(1-\nu^2)D}{E}\right]^{1/3}
    = \left[\frac{12\times0.9375\times3.54\times10^{22}}{7.0\times10^{10}}\right]^{1/3}
    = \left(5.68\times10^{12}\right)^{1/3} = 17.8\ \mathrm{km}.
$
一个**18公里**的弹性的厚度在30 Myr在观察的范围的**低**端、而解释依赖海洋的弯曲的两个竞争的模型接受哪个。**弹性的板块**的模型给出一个随板块的年龄**增长**的$t_e$、当热边界层变厚、大致$t_e \propto \sqrt{\text{age}}$、预测5 Myr的10公里、100 Myr的30公里。**屈服-强度的-包络**的模型给出一个**饱和**在20–30公里的$t_e$、因为板块在它的底部**屈服**、预测一个近于恒定的值。观察支持老的板块的**包络**的模型、年轻的**弹性的**模型、而这里的18公里与任一个一致。

三个系统的错误主导。**载荷不是一个点**：一个40公里宽的海山加载一个与$\alpha$本身可比的区域、而点载荷的解高估$t_e$的20–30百分之一。**填充**：海山之内的沉积物填充的**沟**加不在原始的载荷里的质量、它部分地填充凹陷、而若它被忽略、模型化的挠度太浅、$t_e$太大。**而"海洋的"$\Delta\rho$不是600**：载荷、地壳与地幔之间的密度的对比随年龄与热的状态变化、而$\Delta\rho$的一个20百分之一的误差是一个$t_e$的5百分之一的误差、因为$t_e \propto \Delta\rho^{1/3}$。

数重要的原因是$t_e$控制俯冲带的大地水准面与重力的签名、驱动板内的变形的**应力**的场、与一个加载的岩石圈松弛的**速率**。一个大陆的内部的40公里的$t_e$意味着一个山脉带在几百公里上加载它的**前陆**、**前陆的盆地**是一个弯曲的特征；一个10公里的$t_e$意味着载荷局部地补偿、盆地是窄的。
:::
:::

::: example 冰川的后的回弹与地幔的粘度 {#ex-gia}
Fennoscandia在10 000年前去冰川化、留下一个约1000公里的半的波长的曾经的冰的载荷的中心。现在的抬升的速率在中心是$9\ \mathrm{mm\,yr^{-1}}$。取一个$10^{21}\ \mathrm{Pa\,s}$的地幔的粘度、一个$3300\ \mathrm{kg\,m^{-3}}$的密度、$g = 9.81\ \mathrm{m\,s^{-2}}$、求松弛的时间、去冰川化之后立即的抬升的速率、与仍然要来的抬升。
::: solution
对一个波数$k = 2\pi/L$、$L = 1000\ \mathrm{km}$的正弦的载荷、地幔的**Maxwell**的松弛的时间是
$
\tau = \frac{\eta k}{\rho g} = \frac{10^{21}\times6.283\times10^{-6}}{3300\times9.81}
    = \frac{6.283\times10^{15}}{3.237\times10^{4}} = 1.94\times10^{11}\ \mathrm{s} = 6{,}150\ \mathrm{yr}.
$
抬升指数地衰减、所以去冰川化之后立即的速率是
$
u_0 = u(t)\,e^{t/\tau} = 9\times e^{10000/6150} = 9\times5.06 = 46\ \mathrm{mm\,yr^{-1}},
$
**仍然要来的**抬升是剩余衰减的积分、
$
\Delta z_{\mathrm{remaining}} = u(t)\,\tau = 0.009\times6150 = 55\ \mathrm{m}.
$
**总的**冰川的后的抬升是$u_0\tau = 46\times6150 = 280\ \mathrm{m}$、对着北瑞典与芬兰的抬升的海岸线记录的250–300米、而剩余的55米对着现代的冰川的地静的调整的模型预测的30–40米。

一致足够好、计算是**地幔的粘度的经典的确定**、而三个警告是现代的数以一个$0.5$–$5\times10^{21}\ \mathrm{Pa\,s}$的**范围**、不是一个值引用的原因。载荷**不**是正弦的、而真实的冰的历史——它的厚度、它的边缘与它的时间——自己是一个与粘度交换的未知。地幔**不**是一个均匀的粘度的半空间：**670公里的不连续面**是一个一到两个数量级的粘度的增加、而一个在上面$10^{21}$、下面$10^{22}$的模型拟合**相对的**海平面的曲线比一个均匀的模型好得多、它是"两层的"的粘度的模型的来源。**地圈**有一个100–120公里的有限的厚度、它**延迟**早期的响应、是**Fennoscandia的**抬升的图案有一个在全新世迁移的**周边的隆起**的原因。

数远超出斯堪的纳维亚重要。同样的粘度控制现代的水平的潮汐计的记录**全球性的**的改正——必须应用于一个曾经被冰川覆盖的边缘上的每个潮汐计的**冰川的地静的调整**的改正、它把Stockholm的测量的$+1.5\ \mathrm{mm\,yr^{-1}}$变成一个全球-全球性的$+3.2\ \mathrm{mm\,yr^{-1}}$——卫星测量的**重力的场**的变化$J_2$的趋势、整个行星的**真正的极的游荡**、与冰盖的历史首先从它重建的**相对的**海平面的记录。循环性——从冰的历史的粘度、从水平的冰的历史、从粘度的水平——由GRACE的现在的重力的变化的**空间的**测量打破、它直接地、独立地测量质量的变化。
:::

::: example 载荷补偿了吗？ {#ex-compensated}
一个火山的海山在周围的海洋的地壳之上升起1200米、有一个$2600\ \mathrm{kg\,m^{-3}}$的平均的密度。求若它是（a）完全的未补偿的、（b）由一个岩石圈的弯曲的凹陷补偿的、它将产生的自由-空气的异常、而说出观察到什么。
::: solution
**(a)** 一个未补偿的载荷是一个多余的质量$\rho h$的板、它的吸引是
$
\Delta g = 2\pi G\rho h = \frac{4.193\times10^{-10}\times2600\times1200}{10^{-5}} = 131\ \mathrm{mGal}.
$
**(b)** 一个由**弯曲**支撑的载荷把岩石圈向下推$w$、用一个密度$\rho_m - \rho_{\mathrm{sw}} \approx 3200\ \mathrm{kg\,m^{-3}}$的岩石替换水与沉积物、所以补偿是**部分的**、分布在弯曲的参数$\alpha$的量级的宽度上。对一个在$\alpha = 70\ \mathrm{km}$的一个板块上、一个40公里的载荷的宽度的载荷、中心的挠度是载荷的高度的一个实质的分数、而**净**的自由-空气的异常在顶部降到几十mGal、而一个**正的环**出现在约$\alpha$的距离、**周边的隆起**抬起海底。

一个成熟的太平洋的海山之上的**观察的**的自由-空气的异常是$+10$到$+40$ mGal的一个中心的值、带一个在60–120公里的$+30$到$+60$ mGal的环——比未补偿的值少三到十倍的因子、而海洋的岩石圈由**弯曲**、不是由局部的地静平衡或强度支撑它的**大部分**的地形的经典的证明。

三个后果使观察是定量的。观察的异常对未补偿的异常的**比**是**补偿的分数**的一个直接的估计、由此、与等深线一起、是$\alpha$与$t_e$的。周边的隆起的**波长**是$\alpha$的一个**直接的**测量、独立于幅度、是重力与等深线的方法工作的原因：隆起的波长只由弯曲的参数设定、对载荷的形状与密度不敏感。而跨过沟或海山的**大地水准面**的台阶、几十厘米的量级、由卫星的测高测量到1厘米、是**岩石圈的弹性的厚度的全球的**图如何从**卫星的重力**单独制造、没有一个船的轨迹。
:::
:::

::: warning 一个重力的异常是一个积分、而积分没有唯一的答案
重力是所有的地球物理的方法里最**非唯一的**、而事实在任何解释之前值得说明。**基本的非唯一**：任何质量的分布能由一个产生同样的外部的场的另一个替换、所以一个20-mGal的Bouguer的低能是一个在2公里深度的一个5公里厚的沉积的盆地、一个在20公里的20公里厚的、一个低密度的地幔、或一个**密的**矿体的边缘——而异常的**上延**与**波长**约束它的**深度**、不是它的**性质**。**密度的问题**：Bouguer的改正要求一个密度、而地壳的密度从2500到3000 kg m⁻³变化、所以以一个单一的密度计算的Bouguer的异常的图在一个地壳的密度变化100 kg m⁻³的任何区域上包含一个多达40 mGal的**假的**长的波长的异常——它比解释的大部分信号大。**地形的问题**：一个在离站2公里的100米的悬崖产生一个20-mGal的地形的效应、而以一个粗糙的数字的高程模型制造的一个重力的图在每个陡崖包含**伪像**。**而地静平衡的问题**：自由-空气的异常在一个补偿的区域之上接近零、**无论补偿的机制**、所以一个"零的自由-空气的异常"**不**是Airy的地静平衡的证据、而Airy、Pratt、弯曲与动力的支撑之间的判别需要异常的**波长**、**大地水准面**、与莫霍面和地幔的密度的独立的约束。学科是发表**假设的密度、地形的模型与它的分辨、潮汐的与漂移的改正、与削减的密度**、而把一个重力的解释作为**与数据一致的模型的集合**、与它们的错配、从不作为单个的剖面。
:::

::: history
第一次揭示地静平衡的**铅垂线**的偏转是**Lambton**与**Everest**之下的**印度的大三角测量的调查**的工作、它们在1852年的喜马拉雅附近的垂直的偏差的测量不能用任何当时可用的地壳的模型解释；**Airy**在1855年提出根、**Pratt**在同一年提出密度的变体、而**Clarke与Airy**计算了第一个**削减的表**。**Bouguer**在1737年把第一个摆的重力的测量带到安第斯、方法以他命名；**Laplace**、**Clairaut**与**Stokes**在1743–1849年确立了地球的形状的理论、而**Stokes'**在1849年的积分仍然是物理的测地学的基础。**Vening Meinesz**在1920年代发明了从一个潜水艇测量铅垂线的垂直的偏差的**天顶的角**的方法、发现了中洋脊之上的大的自由-空气的异常、在1941年公式化了岩石圈的**弯曲**的理论。**Heiskanen与Vening Meinesz**在1958年写了标准的《The Earth and Its Gravity Field》、**Worzel**确立了大陆的**区域的地静平衡**、而**Oldenburg**与**Turcotte与Sandwell**发展了海洋的岩石圈的弹性的厚度的**重力与大地水准面**的方法。**Walcott**在1970年确立了**屈服-强度的-包络**、**Molnar与Lyon-Caen**与**Burov与Diament**确立了**膝**与**强度的悖论**、而**Watts**在2001年写了《Isostasy and Flexure of the Lithosphere》。卫星的重力法是**Tapley与GRACE的财团**、**Drinkwater与GOCE的任务**、**Pavlis、Holmes与EGM2008与XGM2019的团体**的工作。
:::

::: quiz
一个2公里高的高原有一个约零的自由-空气的异常、一个−250 mGal的Bouguer的异常。它显示什么？
- [ ] 高原之下的密的地幔。
- [x] 由一个地壳的根的局部的地静的补偿。
- [ ] 一个地幔的柱。
- [ ] 一个厚的沉积的盖层。
::: solution
一个抬升的地形之上的零的自由-空气的异常是地静的补偿的定义：高原的质量由一个低密度的根平衡、所以总的的柱有与参考的柱同样的重量。强的负的Bouguer的然后自动随之、因为Bouguer的改正移除地形、不移除根。一个密的地幔或一个柱将给出一个**正的**自由-空气的与Bouguer的异常、一个厚的沉积的盖层一个**负的**Bouguer的异常、带一个**非零的**自由-空气的异常。
:::
:::

::: summary
- 正常的重力从赤道到极上升5138 mGal、而Clairaut的定理联系扁率、旋转与带谐——它证明地球接近在静水的平衡。
- 自由-空气的异常检验地静平衡；Bouguer的异常成像深部的结构；两者一起约束莫霍面。
- Airy的补偿把低密度的质量放在高程的5.6倍的根里；Pratt把它在一个横向变化的密度里。
- 真实的岩石圈弯曲、不局部地流动、而弯曲的参数——对一个15–30公里的弹性的厚度是60–110公里——测量它的强度。
- 弹性的厚度是一个等效的厚度、不是真实的、而屈服-强度的-包络使它俯冲暗示的弱调和。
- 重力的解释是非唯一的、而每个异常的图必定与它的密度、它的地形的模型、它的可容的模型的族一起发表。
:::

## 练习题

::: exercise 正常的重力 {level=1 check="981919"}
使用$g = 978{,}032.7(1 + 0.0053024\sin^2\varphi - 0.0000059\sin^2 2\varphi)$求纬度$60^\circ$的以mGal的正常的重力。
::: solution
$\sin^2 60^\circ = 0.75$、$\sin^2 120^\circ = 0.75$、所以括号是$1 + 0.003977 - 0.0000044 = 1.003973$、
$
g = 978{,}032.7\times1.003973 = 981{,}919\ \mathrm{mGal} \approx 981.9\ \mathrm{Gal}.
$
离赤道39-Gal的差是小的半径、缺失的离心的加速度的结合的效应。
:::
:::

::: exercise 自由-空气的改正 {level=1 check="154"}
求一个在500米的站的自由-空气的改正。
::: solution
$0.3086\times500 = 154\ \mathrm{mGal}$。改正**加上**到观察的减去的正常差、因为重力随高度减少、一个在基准之上的站读得低。在一个500米的高原上放弃它产生一个154 mGal的错误、它比整个的地静的信号大。
:::
:::

::: exercise Bouguer的板 {level=1 check="201"}
求一个$\rho = 2670\ \mathrm{kg\,m^{-3}}$的1800米的地壳的Bouguer的改正。
::: solution
$2\pi G\rho h = 0.1119\times1800 = 201\ \mathrm{mGal}$。系数$0.1119\ \mathrm{mGal\,m^{-1}}$对$\rho = 2.67\ \mathrm{g\,cm^{-3}}$；对一个在$\rho = 2300$的一个沉积的盆地是$0.0965$、使用错误的密度是任何的高的区域的Bouguer的异常的14百分之一的错误。
:::
:::

::: exercise Airy的根 {level=2 check="16.8"}
求一个$\rho_c = 2800$、$\rho_m = 3300\ \mathrm{kg\,m^{-3}}$的3公里的高原之下的Airy的根、而若参考的莫霍面在35公里、由此的莫霍面的深度。
::: solution
$r = 3\times2800/500 = 16.8\ \mathrm{km}$、所以莫霍面在$35 + 16.8 = 52\ \mathrm{km}$。**总的**地壳的厚度是52公里、**根**是16.8公里；混淆两者是一个常见的错误、而阿尔蒂普拉诺之下的55–65公里的地震的莫霍面与这里假设的一个稍密的或厚的地壳一致。
:::
:::

::: exercise Pratt的补偿 {level=2 check="2.6"}
两个地壳的柱在0、2公里、在一个海平面之下30公里的共同的补偿的深度。若高的柱有$\rho = 2600\ \mathrm{kg\,m^{-3}}$、求低的密度。
::: solution
每单位的面积的质量相等：$\rho_1(2+30) = \rho_2(0+30)$、所以$\rho_2 = 2600\times32/30 = 2773\ \mathrm{kg\,m^{-3}}$——约$2.8\ \mathrm{Mg\,m^{-3}}$。一个2公里的高程的差别在Pratt的方案要求一个170 kg m⁻³的密度的对比、它是地壳的密度的**大的**分数、观察不到；这就是为什么Pratt的补偿限制在**年轻的、热的、海洋的**岩石圈、**沉积的**边缘、那里的密度确实随热的状态变化。
:::
:::

::: exercise 弯曲的刚度 {level=2 check="108"}
求$D = 1.68\times10^{23}\ \mathrm{N\,m}$、$\Delta\rho = 500\ \mathrm{kg\,m^{-3}}$的弯曲的参数。
::: solution
$\alpha = (4D/\Delta\rho g)^{1/4} = (6.72\times10^{23}/4905)^{1/4} = (1.37\times10^{20})^{1/4} = 108\ \mathrm{km}$。因为$\alpha \propto t_e^{3/4}$、一个$t_e$的二倍的因子的错误是一个1.7的$\alpha$的因子、一个$\Delta\rho$的二倍的因子只有19百分之一——这就是为什么弹性的厚度确定得好、载荷的密度不是。
:::
:::

::: exercise Clairaut与形状 {level=3 check="0.00108"}
使用$f = 1/298.257$、$m = \omega^2 a^3/GM = 0.003461$、计算静水的$J_2$、与观察的0.0010826比较。
::: solution
$
J_2 = \tfrac{2}{3}f - \tfrac{1}{3}m = 0.0022352 - 0.0011538 = 0.0010814 ,
$
对着观察的0.0010826——一个到**0.1百分之一**的一致。含义是行星科学里最重要的之一：地球的重力的场是**静水的**、所以它的形体记录它的**旋转与密度的分布**、不是它的构造的历史、而100分之1的非静水的剩余是地幔的对流、冰川的地静的调整与横向的密度的结构的信号的全部。

同样的计算在**木星**给出一个与观察一致到1百分之一的静水的$J_2$、在**泰坦**到优于1百分之一、这就是为什么泰坦被认为有一个**全球的下的海洋**——一个松弛到静水的平衡的天体、而为什么**土卫二**与**伊阿珀托斯**的**非静水的**$J_2$被认为意味着它们**不**在静水的平衡、保存一个从一个更热的过去的**化石的**形体。检验花两个数、是比较的行星学里最强大的之一。
:::
:::

::: exercise 动力的地形 {level=3 check="141"}
一个区域站在为它的莫霍面的深度与地壳的厚度的Airy的地静平衡预测的高程之上1.0公里。估计它要求的**动力的地形**、取$\rho_c = 2800$、$\rho_m = 3300\ \mathrm{kg\,m^{-3}}$、一个200公里的补偿的深度、而说出什么物理的机制能供应它。
::: solution
地静的平衡说一个多余的高程$\delta h$必定由它之下的柱里的质量的**亏损**平衡。多余的地形的质量是$\rho_c\,\delta h = 2.8\times10^{6}\ \mathrm{kg\,m^{-2}}$、而一个补偿的深度$H = 200\ \mathrm{km}$上分布的密度的异常$\delta\rho$必定满足
$
\delta\rho\, H = \rho_c\,\delta h \quad\Rightarrow\quad
\delta\rho = \frac{2.8\times10^{6}}{2\times10^{5}} = 14\ \mathrm{kg\,m^{-3}} .
$
一个地幔的上部的200公里的14 kg m⁻³的密度的亏损、以一个$3\times10^{-5}\ \mathrm{K^{-1}}$的热膨胀的系数、一个3300 kg m⁻³的地幔的密度、等效到一个温度的异常的
$
\Delta T = \frac{14}{3300\times3\times10^{-5}} = 141\ \mathrm{K}.
$
一个**地幔的上部的200公里的140-K的温度的异常**是1公里的额外的高程的动力的支撑、而它由**地幔的上涌**供应——一个柱的头、一个边缘的对流的胞、或一个裂谷之下的回流。替代的机制是一个**成分地**更轻的地幔（熔体亏损的方辉橄榄岩比肥沃的橄榄岩少约2百分之一的密度、它太多、将给出10公里的高程）、一个对流的流动的**动力的压力**、$\eta U/\ell$、对一个$10^{21}\ \mathrm{Pa\,s}$的地幔的粘度、一个$5\ \mathrm{cm\,yr^{-1}}$的速度、一个1000公里的长度只有$0.8\ \mathrm{MPa}$、支撑几十米、不是公里。

数是地球的**动力的地形**从地静的剩余只估计$\pm 500$到$\pm1000$\ \mathrm{m}$、而**非洲的**与**冰岛的**隆起与**东非**的高原归于地幔的流动、不是地壳的过程的原因。
:::
