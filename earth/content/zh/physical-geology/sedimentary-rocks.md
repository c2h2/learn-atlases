坐在大陆中央的任意一处看地面：十有八九你看的是沉积物或沉积岩。然而沉积岩只占地壳体积的约 $5\%$，其余 $95\%$ 是火成岩与变质岩。它们是一层至多几千米厚的薄皮，而它们是记录中唯一告诉我们地表的部分——关于每一个古大气、古海洋、古冰盖、古河流与生物群落，以及关于生命的全部历史，而这些在别处毫无保存。

这种不对称——体积极小而信息量极大，而记录不断被摧毁又不断被重建——正是沉积岩有趣之处。一个砂岩是一个水流的物理记录；一个灰岩是一个海洋的化学记录；一个煤是一个生物学的意外；一个条带状铁建造是大气永远改变那一天的记录。本章讲沉积岩的三个族如何形成，以及如何把它们读回来。

## 从岩石到沉积物

沉积岩开始是火成岩或变质岩，在地表被水、氧与生命侵蚀。化学风化的细节属于 [[geomorphology/weathering]] 与 [[geochemistry/weathering-chemistry]]；这里要紧的是这个过程的选择性，而正是选择性写下了那条信息。

- **机械**的破碎产生碎屑——母岩与单晶的碎片。它扩大裂缝、削薄板片、磨圆棱角，而不改变化学成分。
- **化学**的破坏摧毁在地表不稳定的矿物：橄榄石、钙斜长石、辉石、角闪石与黑云母都会消失，大致按鲍文的顺序，而黏土矿物与铁氧化物取代它们。石英幸存，而重的副矿物也幸存——锆石、电气石、金红石——这就是为什么一个砂的重矿物部分被称为"稳定矿物组合"。
- **溶解**把真正活动的元素随水带走：$\mathrm{Na^+}$、$\mathrm{K^+}$、$\mathrm{Ca^{2+}}$、$\mathrm{Mg^{2+}}$、$\mathrm{HCO_3^-}$、$\mathrm{SO_4^{2-}}$、$\mathrm{Cl^-}$，以及几十 $\mathrm{mg\,kg^{-1}}$ 的硅。

结果是一条值得记住的经验法则：**风化把元素按从最活动到最不活动排列为 $\mathrm{Na, Ca, Mg, K \gg Si > Fe, Al, Ti}$**，而强烈风化的残余是一个红土——铁与铝的氧化物，常见金属中最不活动的两个。

## 搬运：粒度就是信息

::: definition 能力、容量、分选、磨圆度 {#def-transport}
一个水流的**能力**是它能搬运的最大碎屑；它的**容量**是它能携带的总质量。**分选**描述碎屑大小的散布：如果一个大小占主导，一个沉积物分选好；如果许多大小同时存在，分选差。**磨圆度**描述一个碎屑的棱与角有多尖锐；**球度**描述整个颗粒有多接近一个球。一个沉积物可以分选好而棱角状（风暴刚过的海滩砂），或分选差而磨圆（一个砾石滩上的砾石滞留）。
:::

::: theorem 沉降速度 {#thm-settling}
一个直径 $d$、密度 $\rho_s$ 的球形颗粒，在密度 $\rho$、动力黏度 $\mu$ 的流体中下落，当阻力平衡水下重量时达到一个稳定的下落速度 $w$：
$$
\underbrace{C_D \tfrac{1}{2}\rho w^2 \tfrac{\pi d^2}{4}}_\text{drag} = \underbrace{(\rho_s - \rho)\,g\,\tfrac{\pi d^3}{6}}_\text{submerged weight} ，
$$
其中 $C_D$ 是一个依赖雷诺数 $\mathrm{Re} = w d \rho/\mu$ 的阻力系数。在黏性极限 $\mathrm{Re} < 1$，$C_D = 24/\mathrm{Re}$ 而
$$
w = \frac{(\rho_s - \rho)\,g\,d^2}{18\,\mu} \qquad \text{（斯托克斯律）} ，
$$
而对 $500 < \mathrm{Re} < 10^5$，$C_D \approx 0.44$ 而
$$
w \approx 1.1\sqrt{\frac{(\rho_s-\rho)}{\rho}\,g\,d} \qquad \text{（牛顿律）} 。
$$
:::

::: proof
把 $C_D = 24\mu/(w d\rho)$ 代入平衡给出 $12\mu w/(\rho d)\times \rho \pi d^2/4 = (\rho_s-\rho)g\pi d^3/6$，它重排即得斯托克斯律；于是下落速度按 $d^2$ 变化，所以直径减半使它减为四分之一。以 $C_D$ 常数 $0.44$，同一个平衡给出 $w^2 = 4(\rho_s-\rho)g d/(3\times0.44\rho) = 3.03(\rho_s-\rho)g d/\rho$，而 $\sqrt{3.03} = 1.74$；把系数写成 $1.1$、把 $g$ 放在根号内，是通常的工程形式的同一个陈述。要紧的结构上的差别是那个指数：在静水中细颗粒 $w \propto d^2$，粗颗粒 $w \propto d^{1/2}$。∎
:::

::: example 颗粒落得多快？ {#ex-settling}
取石英球（$\rho_s = 2650\ \mathrm{kg\,m^{-3}}$）在 $20\ ^\circ\mathrm{C}$ 的水中（$\rho = 1000\ \mathrm{kg\,m^{-3}}$、$\mu = 1.0\times10^{-3}\ \mathrm{Pa\,s}$），求 (a) 一个 $d = 1\ \mu\mathrm{m}$ 的黏片，(b) 一个 $d = 0.25\ \mathrm{mm}$ 的中砂颗粒，(c) 一个 $d = 20\ \mathrm{mm}$ 的粗砾的下落速度。
::: solution
(a) 斯托克斯：$w = 1650\times9.81\times(10^{-6})^2/(18\times10^{-3}) = 9\times10^{-7}\ \mathrm{m\,s^{-1}}$，约 $8\ \mathrm{cm\,day^{-1}}$。一个 $1\ \mu\mathrm{m}$ 的颗粒要 **140 年**才能落下 $4\ \mathrm{km}$ 的海洋——这就是为什么黏土只有先絮凝成集合体、或由风、冰、浊流搬运，才能到达深海。

(b) 斯托克斯会给 $0.056\ \mathrm{m\,s^{-1}}$，但那意味着 $\mathrm{Re} = wd\rho/\mu = 14$，超出该律的范围。以 $C_D = 24/\mathrm{Re} + 3/\sqrt{\mathrm{Re}} + 0.34$ 迭代地解阻力平衡给出 $w = 0.037\ \mathrm{m\,s^{-1}}$：斯托克斯高估 $50\%$。一个 $0.25\ \mathrm{mm}$ 的颗粒落下 $100\ \mathrm{m}$ 约需 $45$ 分钟。

(c) 牛顿：$w = 1.1\sqrt{1.65\times9.81\times0.02} = 0.63\ \mathrm{m\,s^{-1}}$（精确的阻力解对一个球给 $0.29\ \mathrm{m\,s^{-1}}$，而天然的颗粒更慢）。这三个数字的要点是这个*范围*：从黏土到砾石，下落速度变化约 $3\times10^{5}$ 倍。那个巨大的杠杆就是为什么粒度是对一个沉积物所能做的最有信息量的单一测量，而为什么一个 $10\ \mathrm{cm\,s^{-1}}$ 的水流把砂悬移、却让黏土不动，而一个 $1\ \mathrm{cm\,s^{-1}}$ 的水流把黏土永远悬着。
:::
:::

::: definition 伍登沃尺度 {#def-wentworth}
碎屑按直径命名：黏土 $<0.004\ \mathrm{mm}$、粉砂 $0.004$–$0.0625\ \mathrm{mm}$、砂 $0.0625$–$2\ \mathrm{mm}$（极细到极粗）、砾粒 $2$–$4\ \mathrm{mm}$、砾石 $4$–$64\ \mathrm{mm}$、以及以上的卵砾与漂砾。对应的岩石是泥岩（泥状岩，若易裂则为页岩）、砂岩与砾岩（若碎屑有棱角则为角砾岩）。沉积学家用 $\phi = -\log_2 d(\mathrm{mm})$，所以一个 $1\ \mathrm{mm}$ 的颗粒是 $0\ \phi$、一个 $0.25\ \mathrm{mm}$ 的颗粒是 $2\ \phi$、一个 $4\ \mathrm{mm}$ 的砾粒是 $-2\ \phi$；于是分选与平均大小是一个 $\phi$ 分布的统计量。
:::

两个进一步的概念承担了大部分解释的重量。

**成熟度**衡量一个沉积物离它的母岩旅行了多远，而它有两个成分：*结构*成熟度（分选好、磨圆好）与*成分*成熟度（不稳定的矿物与岩屑被摧毁、石英占主导）。一个石英砂岩是双重成熟的；一个富长石、富泥、棱角状的杂砂在两个意义上都是不成熟的。

**物源**是源区，而它从成分读出。富石英的砂意味着一个古老的地台或一个长的搬运历史；富长石的砂（长石砂岩）意味着一个被快速侵蚀的近源的花岗岩高地；富岩屑的砂（岩屑砂岩）意味着一个火山弧或一个正在第一次被吃掉的上隆的山带。

::: example 从一次点数得物源 {#ex-qfl}
一个砂岩在 300 个骨架颗粒上点数：$120$ 个石英、$45$ 个长石、$135$ 个火山与沉积的岩屑。分类它而解释源区。第二个砂岩给出 $135$ 个石英、$135$ 个长石、$30$ 个岩屑。
::: solution
归一化到 $100\%$：第一个是 $\mathrm{Q}_{40}\mathrm{F}_{15}\mathrm{L}_{45}$，第二个是 $\mathrm{Q}_{45}\mathrm{F}_{45}\mathrm{L}_{10}$。两者都落在 $\mathrm{Q} = 55\%$ 线之下，所以都不是石英砂岩。第一个中岩屑多于长石，所以它是一个**岩屑砂岩**（如果算入长石后岩屑低于 $25\%$ 则为亚岩屑砂岩）：一个火山弧、或一个第一次被侵蚀的混合的山带的经典特征，而因为岩屑很快被磨掉，所以沉积在靠近源处。第二个中长石占主导：一个**长石砂岩**（$45\%$ 长石时为亚长石砂岩），它意味着一个花岗岩基底正被快速剥蚀，在一个干到或冷到长石能在化学侵蚀中幸存的气候里，而搬运距离短到它没有被磨尽。

解释的纪律是三个成分各被一个不同的过程摧毁——岩屑被磨蚀、长石被化学风化、石英几乎不被任何东西——所以一次点数实际上是三个以不同的速率运行的独立的钟，而其中两个的比值告诉你哪一个运行得最久。
:::
:::

::: warning "分选好的砂意味着海滩；分选差的意味着冰川"
只从分选推环境是一次掷硬币。分选是*水流*的性质，而不是环境的性质，而同一个分选好的砂可以由一个海滩、一个沙丘、一个浅海陆棚、以及一个与其载荷平衡的河道形成。经典的"分选差等于冰川"的推断对泥石流、对浊积岩、对倒石堆、对不成熟的富长石的砂都失败。沉积环境是从*一组*特征读出的——波痕与沉积构造、古水流、化石内容、岩体的几何、以及其上与其下的岩石——而从不是从一个测量。完整的论证属于 [[sedimentology/facies]]。
:::

## 化学与生物成因的沉积物

::: proposition 海洋为什么不沉淀出盐 {#prop-evaporite}
海水每千克水约含 $35\ \mathrm{g}$ 的盐，而离石岩的饱和相差很远，后者大约需要 $300\ \mathrm{g\,kg^{-1}}$。所以蒸发岩的成因不只是蒸发，而需要一个**受限的环流**：一个只被缓慢补给的盆地，从而盐度能上升约十倍。沉淀的顺序跟随溶解度递减——先是碳酸盐，然后是石膏与硬石膏，然后是石岩，然后是钾与镁的盐——而它作为一个每当盆地重新补给就重复的垂向序列被保存下来。
:::

::: proof
这个序列是溶度积与海水中的浓度的一个结果。方解石（$K_\text{sp} \sim 10^{-8.4}$，而海水在其上在表层*过饱和*、但在深处不饱和）最先达到；石膏在约两倍海水盐度时饱和，石岩在约十倍时，而钾石盐 $\mathrm{KCl}$ 与光卤石只在卤水最后百分之几中，这就是为什么钾盐层薄、纯得惊人、而只在最大的蒸发岩堆积中被找到。因为每一种盐都在一个窄的浓度范围中沉淀，一个垂向的序列以盐度的几个百分点的分辨率记录了盆地中*水位的演化史*——这就是为什么蒸发岩被用作古气候与古水深的档案，而为什么层的顺序从无疑义。∎
:::

主导沉积记录的三个化学–生物成因的族：

**碳酸盐。**灰岩与白云岩是沉积岩中最大的单一体积，而与碎屑岩不同，它们主要*就地生产*，由建造方解石或文石（$\mathrm{CaCO_3}$）壳的生物、由微生物与非生物的沉淀。四分之三的浅海碳酸盐在热带制造，那里温暖的水、充足的光与低的营养供给有利于钙化生物；其余在冷水与湖中制造。白云岩，$\mathrm{CaMg(CO_3)_2}$，在富镁的卤水或海水重新改造灰岩之处形成，而这种交代常常保存化石与原始的结构、而摧毁大部分的同位素的记录。

**深海的硅质与化学的沉积物。**放射虫与硅藻的软泥在生产高的地方堆积，而在埋藏时变成硅质岩。锰的结核与结壳以每百万年几厘米生长。在**碳酸盐补偿深度**（现代太平洋约 $4{,}500\ \mathrm{m}$，大西洋更浅）之下碳酸盐溶解，所以深海太平洋被硅质与黏土的软泥、而不是被灰泥铺着。

**煤与有机质的黑色页岩。**煤是逃过氧化的沼泽的残余——一个需要积水、需要沉降与泥炭的堆积同步、而需要数千年的构造的安静的条件。因为碳是从大气中固定下来而后被埋藏，煤与黑色页岩正是大气有任何氧气的原因：有机碳的埋藏是地质时间尺度上 $\mathrm{O_2}$ 的唯一的大来源。

::: example 条带状铁建造：一个有日期的化学沉积物 {#ex-bif}
条带状铁建造（BIF）是交替的硅质岩与铁的氧化物的层，沉积在 $3.8$ 与 $1.8\ \mathrm{Ga}$ 之间，而在 $1.8\ \mathrm{Ga}$ 之后几乎没有、而在新元古代短暂地回归。用海水的化学与铁的氧化态解释这个时间。
::: solution
$\mathrm{Fe^{2+}}$ 在中性 pH 的无氧的水中是可溶的；$\mathrm{Fe^{3+}}$，赤铁矿与磁铁矿的状态，基本上不溶。所以一个深的、无氧的海洋能把溶解的铁从热液的来源携带到巨大的浓度，而铁只在与一个氧化剂相遇的地方与时候沉淀。所以那些大的条带建造记录了光合作用的产氧的开始，就在海洋的还原剂的库存——溶解的铁，后来是硫化物——被消耗得比供给更快的那一点。一旦海洋的铁的库被耗尽、而表层海洋永久地被氧化，这个机制就关掉了：不再有 BIF。新元古代的回归被读作深水短暂地重新变得无氧、可能富铁的证据，在一个被冰川覆盖的海洋中。

论证的定量部分是质量。取一个慷慨的量级估计的前寒武纪 BIF 的体积——$10^{7}\ \mathrm{km^3}$ 的岩石、$2500\ \mathrm{kg\,m^{-3}}$、按重量 $20\%$ 的铁——这是 $5\times10^{18}\ \mathrm{kg}$ 的铁，或 $9\times10^{19}\ \mathrm{mol}$。把 $\mathrm{Fe^{2+}}$ 氧化到 $\mathrm{Fe^{3+}}$ 每摩尔铁消耗四分之一的摩尔的 $\mathrm{O_2}$，所以 $2\times10^{19}\ \mathrm{mol}$ 的氧：约整个现代大气所持的 $3.7\times10^{19}\ \mathrm{mol}$ 的 $60\%$。显生宙根本没有 BIF。这些岩石不只是与大氧化事件*一致*；它们是确立它的两三条证据之一（[[earth-history/oxygen-proterozoic]]、[[geochemistry/stable-isotopes]]）。
:::
:::

## 埋藏：从沉积物到岩石，以及失去了什么

::: definition 成岩作用与压实 {#def-diagenesis}
**成岩作用**是一个沉积物在沉积之后、变质作用之前所经历的一切物理与化学的变化：压实、胶结、压溶、交代与生物扰动。压实大致使孔隙度随深度指数地减小，
$$
\phi(z) = \phi_0\, e^{-z/b} ，
$$
其中泥的 $\phi_0 \approx 0.5$–$0.6$、干净的砂的 $0.4$–$0.5$，而砂的 $b \approx 0.5$–$1\ \mathrm{km}$、泥的几千米，泥压实得更多但蠕变得更慢。
:::

::: example 孔隙度、深度与储层的质量 {#ex-porosity}
取一个泥岩的 $\phi_0 = 0.60$、$b = 4.5\ \mathrm{km}$，一个砂岩的 $\phi_0 = 0.45$、$b = 3.5\ \mathrm{km}$。求各自在 $2\ \mathrm{km}$ 与 $4\ \mathrm{km}$ 的孔隙度，而说出这些数字对一个石油储层意味着什么。
::: solution
泥岩：$\phi(2) = 0.60\,e^{-2/4.5} = 0.385$；$\phi(4) = 0.60\,e^{-4/4.5} = 0.247$。
砂岩：$\phi(2) = 0.45\,e^{-2/3.5} = 0.235$；$\phi(4) = 0.45\,e^{-4/3.5} = 0.123$。

由此得出两件事。第一，一个干净的砂被埋到 $4\ \mathrm{km}$ 仍保有 $12\%$ 的孔隙空间，这足以持有油与气；而一个泥，即使在 $2\ \mathrm{km}$ 有 $38\%$ 的孔隙度，其孔也小到让烃类不能移动，这就是为什么泥是一个烃源岩或一个盖层、而砂是一个储层。第二，一个好的储层与一个差的储层之间的差别主要是一个埋藏深度与胶结的问题：石英的加大与碳酸盐的胶结能摧毁压实所留下的原生孔隙度，而整个经济沉积学就是预测胶结在哪里发生、在哪里没有发生的尝试（[[earth-resources/petroleum-systems]]）。
:::
:::

::: widget plot
f: 60*exp(-x/b)
x: 0, 8
y: 0, 65
sliders: b=4.5:0.5:8:0.5
labels: porosity
caption: 对 $\phi_0 = 60\%$，孔隙度作为深度的函数，而压实常数 $b$ 作为一个滑块。把 $b = 0.5\ \mathrm{km}$（一个干净的、强烈压实的砂）与 $b = 4.5\ \mathrm{km}$（一个异常高压的泥）各设一次，而读出 $3\ \mathrm{km}$ 处的孔隙度：$0.2\%$ 对 $31\%$。这两条曲线是一个储层与一个盖层之间的差别、也是一个正常压力地层与一个必须被钻井液顶住的地层之间的差别。然后注意这个指数外推得有多糟：真实的孔隙度在 $4$–$5\ \mathrm{km}$ 之下变平，因为胶结与压溶接替了物理的压实，也因为异常高压能完全阻止压实。
:::

## 岩石循环，带着数字

三个族是一个循环：火成岩风化成沉积物，埋藏把沉积物变成沉积岩，更深的埋藏或进入一个俯冲带使它变质，而熔融重新开始。通量是极不相等的。今天河流向海洋输送约 $1.5\times10^{16}\ \mathrm{kg\,yr^{-1}}$ 的沉积物，而其中约 $0.4\times10^{15}\ \mathrm{kg\,yr^{-1}}$ 被永久地埋藏，其余的在侵蚀与再沉积的浅的机器中被再循环。整个地壳是老的、火成的；整个表面是年轻的、沉积的。这就是为什么沉积的记录既是我们唯一的表面的档案、又是一个严重有偏的档案：它由什么被快速地埋藏、在沉降空间被创造的地方、在陆地高的那些时段所主导。

::: quiz
两个砂岩有同样的粒度、分选与磨圆度。一个是 $95\%$ 石英，另一个是 $60\%$ 石英、$30\%$ 长石。哪个陈述得到最好的支持？
- [ ] 第二个沉积在一个更高能的环境。
- [x] 第二个从一个富长石的源区被侵蚀，而且比第一个搬运得更近，或风化得更少。
- [ ] 第一个是更老的岩石。
- [ ] 第二个必须是冰川的。
::: solution
粒度、分选与磨圆度描述*水流*；成分描述*源区与风化史*。所以相同的结构而不同的成分指向一个不同的物源、或一个不同的气候/搬运距离，而不是指向不同的能量。年龄完全不能从成分读出，而一个冰川的成因既不被要求也不被排除。
:::
:::

::: history
沉积岩的解释始于一个实际的问题：在十八世纪英格兰的运河挖掘中找到煤、黏土与建筑石料。威廉·史密斯在 1790 年代的洞见——英格兰的地层以一个恒定的垂向顺序出现，而每一层产出它自己的化石——是一个沉积学的观察先于一个地层的观察，而它使 1815 年的地图成为可能。理论的框架来自詹姆斯·赫顿，他在 1788 年在西卡角认识到不整合与深时；而来自查尔斯·莱尔，他在《地质学原理》（1830–1833）中论证沉积相必须通过现在观察河流与三角洲来解释。颗粒搬运的定量的物理必须等到二十世纪：G. K. 吉尔伯特的《河流的研究》（1877）设定了这个纲领，而拉尔夫·安东尼·巴格诺尔德关于砂在水中运动的实验，在他为沙漠战争后勤工作时写成的《吹动的砂与沙漠沙丘的物理》（1941）中，给出了第一个机械化的泥沙搬运理论——包括那个洞见：运动中的颗粒以跃移、以跳跃行进，而流体被它们拖着走。
:::

## 通向何处

沉积岩在 [[sedimentology/sediment-grains]]、[[sedimentology/bedforms]] 与 [[sedimentology/facies]] 中被远更详细地阅读，那里颗粒的组构、波痕与沙丘、以及瓦尔特律把一个手标本变成一个水流的再造；岩石的地层顺序是 [[sedimentology/stratigraphy]] 的主题。制造它们的水的化学属于 [[geochemistry/aqueous-geochemistry]] 与 [[geochemistry/weathering-chemistry]]，而把沉积盆地用作能量与水的储存的用途属于 [[earth-resources/petroleum-systems]] 与 [[earth-resources/groundwater-resources]]。

::: summary 关键要点
- 沉积岩按体积是地壳的 $5\%$，而基本上是表面的记录的全部；它们也是过去的表面条件与生命的唯一档案。
- 风化是有选择性的，而选择性就是信息：石英与重的副矿物幸存，镁铁质的矿物与钙斜长石不幸存。
- 下落速度对细颗粒按 $d^2$、对粗颗粒按 $d^{1/2}$ 变化，而从黏土到砾石跨五个数量级——这就是为什么粒度是对一个沉积最有信息量的测量。
- 碎屑岩按大小命名（伍登沃），用分选、磨圆度与成熟度描述，而用一个物源图（QFL）解释，其三个成分以三个不同的速率被摧毁。
- 化学与生物成因的沉积物直接记录海洋的化学：蒸发岩需要受限的环流，碳酸盐主要就地生长，而条带状铁建造为海洋的氧化定年。
- 成岩作用大致使孔隙度随深度指数地破坏；一个储层、一个盖层与一个烃源岩之间的差别主要是粒度、埋藏深度与胶结的问题。
- 沉积的岩石是一个有偏的档案：被保存的是被快速埋藏的，而从河流到永久埋藏的通量不足河流所携带的 $3\%$。
:::

::: exercise 用斯托克斯求下落速度 {level=1 check="0.4"}
用斯托克斯律，求一个直径 $0.02\ \mathrm{mm}$ 的粉砂颗粒在 $\mathrm{mm\,s^{-1}}$ 中的下落速度（水中的石英，$\mu = 10^{-3}\ \mathrm{Pa\,s}$）。
::: solution
$w = 1650\times9.81\times(2\times10^{-5})^2/(18\times10^{-3}) = 3.6\times10^{-4}\ \mathrm{m\,s^{-1}} = 0.36\ \mathrm{mm\,s^{-1}}$。（以 $\mathrm{mm\,s^{-1}}$ 输入一位小数：$0.4$。）检验雷诺数：$\mathrm{Re} = wd\rho/\mu = 3.6\times10^{-4}\times2\times10^{-5}/10^{-6} = 0.007$，所以斯托克斯有效。同一个颗粒在空气中会落下得快约六十倍，这就是为什么沙尘暴能跨洋携带粉砂，而河流在离河口远处无法将其悬移。
:::
:::

::: exercise 雷诺数的检验 {level=1 check="175"}
一个 $1\ \mathrm{mm}$ 的石英球在水中以 $0.175\ \mathrm{m\,s^{-1}}$ 下落。计算它的雷诺数，而说出 [[#thm-settling]] 的两个律中哪一个适用。
::: solution
$\mathrm{Re} = wd\rho/\mu = 0.175\times10^{-3}\times1000/10^{-3} = 175$。这在过渡的范围：斯托克斯（$\mathrm{Re}<1$）与牛顿（$\mathrm{Re}>500$）都不适用，而阻力系数必须从经验的曲线读出。斯托克斯对这个颗粒会预报 $0.90\ \mathrm{m\,s^{-1}}$，快五倍——这就是实验室所用的"斯托克斯律"粒度管被限制在粉砂与黏土部分的原因。
:::
:::

::: exercise 物源 {level=2}
三个砂岩的点数给出 (a) $\mathrm{Q}_{88}\mathrm{F}_{8}\mathrm{L}_{4}$、(b) $\mathrm{Q}_{25}\mathrm{F}_{20}\mathrm{L}_{55}$、(c) $\mathrm{Q}_{40}\mathrm{F}_{52}\mathrm{L}_{8}$。分类每一个而提出一个环境。
::: solution
(a) 石英砂岩（$\mathrm{Q} > 55\%$）：一个稳定的地台边缘、一个被再改造的风成–浅海序列、或一个长期的被动边缘；通常结构上也成熟。(b) 岩屑砂岩：一个火山弧或一个被快速剥露的山带，沉积在靠近源处。(c) 长石砂岩（亚长石砂岩）：一个正被裂谷或前陆剥蚀的花岗岩基底，在干旱或寒冷的气候，短搬运。这道练习提醒：同样的粒度能携带三个完全不同的构造的信息。
:::

::: exercise 蒸发岩的浓缩因子 {level=2 check="8.6"}
海水含 $35\ \mathrm{g\,kg^{-1}}$ 的溶解固体，而石岩在近 $300\ \mathrm{g\,kg^{-1}}$ 沉淀。水必须蒸发多少倍才能达到石岩的饱和？（输入浓缩因子。）然后求制造 $1\ \mathrm{m^3}$ 的石岩（$\rho = 2170\ \mathrm{kg\,m^{-3}}$）需要多少海水？
::: solution
浓缩因子是 $300/35 = 8.6$，所以约 $88\%$ 的水必须失去。$1\ \mathrm{m^3}$ 的石岩是 $2170\ \mathrm{kg}$ 的 $\mathrm{NaCl}$，这需要 $2170/0.035 = 6.2\times10^{4}\ \mathrm{kg}$ 的海水，约 $62\ \mathrm{m^3}$，即在每一平方米上一个 $6.2\ \mathrm{m}$ 深的水层。一个 $100\ \mathrm{m}$ 厚的石岩层因此记录了约 $6\ \mathrm{km}$ 的海水的完全蒸发——这就是为什么厚蒸发岩需要一个有浅槛的受限盆地，而不只是一个炎热的气候，而这就是为什么中新世地中海的"蒸发岩危机"、有厚达 $2\ \mathrm{km}$ 的层，意味着那个盆地几乎被隔离而反复地被重新补给。
:::
:::

::: exercise 压实与异常高压 {level=2 check="0.31"}
一个 $\phi_0 = 0.60$、$b = 4.5\ \mathrm{km}$ 的泥岩被埋到 $3\ \mathrm{km}$。求它预期的孔隙度，而解释在那个深度测得 $50\%$ 的孔隙度会被怎样解释。
::: solution
$\phi = 0.60\,e^{-3/4.5} = 0.31$。在 $3\ \mathrm{km}$ 测得 $50\%$ 的孔隙度远高于压实的趋势，这意味着颗粒上的有效应力远低于上覆岩层所意味的：孔隙流体承担着部分载荷，即这个地层是**异常高压的**。这种异常高压产生于泥被埋得比它的水能被挤出的更快时，或在一个没有排水的盖层之下，而它是使烃类的保存成为可能、也使钻井的井涌成为危险的条件。孔隙度–深度曲线因此在勘探中被用作一个压力计。
:::
:::

::: exercise 指数的推导 {level=3}
从阻力平衡证明在斯托克斯区 $w \propto d^2$、在牛顿区 $w \propto d^{1/2}$，而用两个标度解释为什么浊流能把粗砂与泥一起分选，而涨水的河流把它们分得很糟。
::: solution
斯托克斯：阻力 $\propto \mu w d$，重量 $\propto \Delta\rho g d^3$，所以 $w \propto \Delta\rho g d^2/\mu$：指数 2。牛顿：阻力 $\propto \rho w^2 d^2$，所以 $w \propto (\Delta\rho g d/\rho)^{1/2}$：指数 $1/2$。

结果是，在黏性区一个砂粒的下落速度超过一个黏土粒的 $(250)^2 \approx 10^5$，所以两者不能被同一个水流悬移、而每当一个水流减速就被有效地分开。在惯性区这个比值只有 $\sqrt{250} \approx 16$，而对自然中要紧的过渡的大小是 $50$–$100$。浊流厚重而湍流强，它把砂与泥一起携带、然后从一个衰减的单一水流中沉积它们——产生一个浊积岩的粒序层，底部粗而顶部泥质，中间没有大小的间断。一个河流的水流是浅的、而其湍流在近床处弱，所以泥被悬移到海、而砂在河道中沉积：两者被分开，而沉积物在大小上分选好、却在浊积岩所保存的泥上贫乏。
:::
:::

::: exercise 一个粒度数据集 {level=3}
一个砂岩的累积的大小分布给出 $d_{16} = 0.15\ \mathrm{mm}$、$d_{50} = 0.25\ \mathrm{mm}$、$d_{84} = 0.42\ \mathrm{mm}$。估计包含式的图解标准差 $\sigma_I \approx (\phi_{84}-\phi_{16})/4$ 与偏度 $\mathrm{Sk}_I = (d_{16} + d_{84} - 2d_{50})/[4\sigma_I^2]$（以 $\phi$ 单位），而分类分选（$\sigma_I < 0.35\ \phi$ 为分选好，$0.35$–$0.41$ 为中等，$0.41$–$0.50$ 为中等偏差）。
::: solution
转换到 $\phi$：$d_{16} = -\log_2 0.15 = 2.74\ \phi$、$d_{50} = 2.00\ \phi$、$d_{84} = -\log_2 0.42 = 1.25\ \phi$。于是
$$
\sigma_I = \frac{2.74 - 1.25}{4} = 0.37\ \phi ，
$$
这是*中等分选*。偏度：$\mathrm{Sk}_I = (2.74 + 1.25 - 4.00)/[4\times0.37^2] = -0.01/0.55 = -0.02$，基本上对称。

两个教训。第一，$\phi$ 变换的存在正是为了让这些统计量表现良好：以毫米计，同一个分布会看着强烈正偏，因为尺度是对数的。第二，一个对称的、中等分选的砂是一个海滩或一个浅海的沙坝的典型，那里波浪作用把颗粒再造成一个窄的大小带；一个强烈*细*偏的砂（$\phi$ 中正偏）暗示细的颗粒被扬弃移除，而一个强烈粗偏的暗示加入了一个粗的群体，例如一个风暴的滞留。

::: exercise 一个沉积薄皮的质量 {level=3 check="45000"}
沉积岩覆盖大陆的 $75\%$，而在存在之处平均厚 $2.5\ \mathrm{km}$。取一个 $1.5\times10^{8}\ \mathrm{km^2}$ 的大陆面积与 $2400\ \mathrm{kg\,m^{-3}}$ 的平均密度。求沉积壳的质量，以及在今天 $1.5\times10^{16}\ \mathrm{kg\,yr^{-1}}$ 的河流泥沙通量下、如果没有被摧毁，制造它所需的时间？（以年输入时间。）这个比较对记录的保存告诉你什么？
::: solution
体积 $= 0.75\times1.5\times10^{8}\times2.5 = 2.8\times10^{8}\ \mathrm{km^3} = 2.8\times10^{17}\ \mathrm{m^3}$。质量 $= 2.8\times10^{17}\times2400 = 6.7\times10^{20}\ \mathrm{kg}$。

以 $1.5\times10^{16}\ \mathrm{kg\,yr^{-1}}$，这需要 $4.5\times10^{4}\ \mathrm{yr}$——五万年，而沉积的记录延续了四十亿年。即使考虑到今天的通量因农业与道路而偏高（也许是农业之前速率的三到十倍），而大部分质量被变质或再循环、被替换了许多次，这个算术说的是同一件事：沉积的记录不是泥沙产生平均速率的一个样本，而是它的一个微小的、强烈被选择的残余。约 $0.4\times10^{15}\ \mathrm{kg\,yr^{-1}}$ 被永久地埋藏，所以保存的因子是 $1.5$–$3\%$ 的量级，而一个时段越老，幸存的部分越小。每一个关于"白垩纪的气候"的陈述，都是一个关于*恰好被保存下来的地方的*白垩纪气候的陈述（[[palaeoclimate/proxies]]）。
