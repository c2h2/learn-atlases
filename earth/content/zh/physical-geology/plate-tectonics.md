1596 年，亚伯拉罕·奥特柳斯在安特卫普看着一张世界地图写下：美洲是被"地震与洪水"从欧洲与非洲撕开的，任何手边有一张地图、又肯耐心的人，都能从海岸线看出证据。此后三百年地图越画越精，那些形状依旧看着可信，只是没有任何东西在动。这个想法失败的原因不是观察错了，而是问题无法回答：没人知道地球内部是什么、地球有多大年纪、洋底究竟有没有历史。

在 1961 到 1968 年之间、用七年时间把这件事定下来的，不是一张新地图，而是一台新仪器——一艘船后面拖着的磁力计——加上两个认识：洋底是年轻的，而洋底是一盘记录带。本章按证据必须被发现的顺序讲这些证据，也讲一个由运动块体拼成的表面的几何与算术。课程里其余的一切——火山与地震的位置、矿床的分布、白垩纪的气候、深海的形状——都是它的推论。

## 无法说服人的证据

魏格纳在 1912 到 1922 之间搭建的，是一个巧合多到不可能是巧合的案子：

- **几何。** 南美洲与非洲的海岸线吻合，但正确的拼接不该用现代海岸线，而该用陆坡折，即 200 米等深线，因为现代海岸线正被海水侵蚀，而大陆边缘没有。当布拉德、埃弗里特与史密斯在 1965 年按那种方式做拼接时，在宽 $6000\ \mathrm{km}$ 的大洋上，空隙与重叠只剩几百千米。
- **化石。** 二叠纪植物舌羊齿 *Glossopteris* 与淡水爬行动物中龙 *Mesosaurus* 见于印度、南极洲、澳大利亚、南非与南美洲，此外别无他处。中龙不可能横渡 $5000\ \mathrm{km}$ 的咸水；若是陆桥，洋底应留下它的浅海化石，而 1940 年代首次采样的大西洋洋底只有玄武岩与年轻沉积。
- **冰。** 二叠纪–石炭纪冰川擦痕与冰碛岩的方向从冈瓦纳腹地*向外*辐散，而同一套磨蚀过巴西的冰盖，在印度却覆于煤层之上。只有一块横跨南极的整块大陆能解释这种格局。
- **地质。** 加里东造山带穿过挪威与苏格兰，随后在纽约州与缅因州以同样的年龄与构造、毫无中断地再次出现；西非的前寒武纪片麻岩杂岩延续进巴西。

机制是问题所在。魏格纳提出大陆犁过洋壳，而哈罗德·杰弗里斯则正确地回应：这对洋底强度的要求荒谬至极——一块大陆以每年几厘米的速度在刚性盖层中穿行，其受到的拖曳会超过地球内部所能提供的一切。错的是关于内部的图像，不是运动本身。

::: warning "大陆像拼图一样吻合，所以它们在一起过"
吻合是真的，但它单独作为证据是弱的，有两个理由。第一，海岸线不是大陆的边缘：它们只是过去 20 000 年中升降了 $120\ \mathrm{m}$ 的海平面所在之处。第二，被撕开的两个表面未必非得吻合——大西洋边缘是一整套断块，匹配程度大部分取决于你选哪条等深线、以及 $10$–$20^\circ$ 的旋转。吻合是一个*假设的生成器*：真正让它令人信服的，是跨边缘地质匹配所预测的拼合，与磁异常所预测的拼合相一致，而两者又与转换断层的几何一致。四套互相独立的数据，同一个几何。
:::

## 洋底作为一盘记录带

::: proposition 温–马修斯–莫利：扩张加反转即得磁条带 {#prop-vine}
如果新地壳在洋中脊生成、以半速率 $v$ 对称扩张，而地磁场在时刻 $t_i$ 发生反转，那么年龄为 $t_i$ 的磁条带就位于脊两侧离脊 $x_i = v t_i$ 之处。因此一条横跨洋脊的地磁剖面读出来是一个对称的异常图案，其年龄可由陆上熔岩独立测定，而其间距直接给出扩张速率。
:::

::: proof
取一块在距今 $t$ 之前于洋脊生成的地壳。若板块自形成以来以恒定速度 $v$ 远离，则按匀速运动的定义，它离脊的距离就是 $x = vt$。它的剩余磁化在它冷却到磁铁矿的居里温度约 $580\ ^\circ\mathrm{C}$ 时被锁定，就在喷发后几百米之内——所以它的极性就是形成时地磁场的极性。对称性之所以成立，是因为同一套增生过程在两翼同样进行，而脊轴是一条线：一侧的任何一个块体，在另一侧都有一个同一瞬间形成的孪生块体。∎

把它变成证明而非模型的，是一个定量的预报：异常图案必须在两翼*完全相同*；而同一个序列必须出现在扩张速率不同的洋脊上，只是距离按速率缩放。船载磁力计发现的正是如此，先在嘉士伯海岭与东太平洋海隆（1961–1967）；这就是为什么海洋磁异常反转年表成了几乎整个新近纪地质所悬挂的骨架。
:::

::: example 测算扩张速率 {#ex-rate}
在一条洋中脊上，最年轻的正常极性计时带（始于 $0.78\ \mathrm{Ma}$）以一对关于脊轴对称、相距 $47\ \mathrm{km}$ 的异常出现。在第二条洋脊上，同一对相距 $9.8\ \mathrm{km}$。求各自的总扩张速率，以及以第一个速率张开一个 $6000\ \mathrm{km}$ 宽的大洋所需的时间。
::: solution
每个异常离脊 $23.5\ \mathrm{km}$、年龄 $0.78\ \mathrm{Myr}$，所以半速率为
$$
v = \frac{2.35\times10^{4}\ \mathrm{m}}{0.78\times10^{6}\ \mathrm{yr}} = 3.0\ \mathrm{cm\,yr^{-1}} ，
$$
而总速率 $6\ \mathrm{cm\,yr^{-1}}$——一条中等速率的洋脊。第二条洋脊给出 $4.9\ \mathrm{km}/0.78\ \mathrm{Myr} = 0.63\ \mathrm{cm\,yr^{-1}}$ 的半速率、$1.25\ \mathrm{cm\,yr^{-1}}$ 的总速率：一条像大西洋中脊那样的慢脊。今天最快的脊，纳斯卡–南极海岭，达到约 $15\ \mathrm{cm\,yr^{-1}}$。

以 $6\ \mathrm{cm\,yr^{-1}}$，一个 $6000\ \mathrm{km}$ 宽的大洋张开需要
$$
t = \frac{6\times10^{6}}{6\times10^{-2}} = 10^{8}\ \mathrm{yr} ，
$$
一亿年——大陆年龄的五分之一，因此宽 $6000\ \mathrm{km}$、自 $130\ \mathrm{Ma}$ 起张开的大西洋是个年轻大洋，而正在收缩的太平洋只是一个更大洋的残余 $6000\ \mathrm{km}$、自 $130\ \mathrm{Ma}$ 起张开的大西洋是一个年轻的大洋，而正在收缩的太平洋是一个更大大洋的残余。
:::

关于洋底还有两个事实使整个论证完成。它的**年龄**从不超过约 $180\ \mathrm{Myr}$，而大陆是四十亿年；而它的**热流**在洋脊处高而杂乱，并随年龄平方根成反比衰减，恰如冷却半空间模型所预测。

::: example 岩石圈有多厚？ {#ex-litho}
大洋岩石圈靠自下而上的传导冷却而增厚，而在时间 $t$ 之后一条等温线的深度是 $x = 2\sqrt{\kappa t/\pi}$。取 $\kappa = 10^{-6}\ \mathrm{m^2\,s^{-1}}$、若把岩石圈底界取为 $1300\ ^\circ\mathrm{C}$ 等温线，求 $1$、$60$ 与 $180\ \mathrm{Myr}$ 老的岩石圈的厚度。
::: solution
$$
x = 2\sqrt{\frac{10^{-6}\,t}{\pi}} = \{6,\ 49,\ 85\}\ \mathrm{km} \quad \text{对 } t = \{1,\ 60,\ 180\}\ \mathrm{Myr} 。
$$
大洋岩石圈的实测厚度——依据震源深度、板块在海沟处的弯曲刚度、以及地震层析成像——在老洋盆下为 $70$–$100\ \mathrm{km}$、在脊下是几千米：模型正确到 $\kappa$ 与底的定义的不确定之内。同一个 $\sqrt{t}$ 律预报洋底的深度——它从脊的约 $2500\ \mathrm{m}$ 加深到 $180\ \mathrm{Myr}$ 的 $5000\ \mathrm{m}$，因为冷却增厚的岩石圈更重——并预测热流随年龄的变化。厚度、深度、热流三项独立观测，同出一个传导解的。
:::

::: definition 板块、岩石圈、边界 {#def-plates}
**岩石圈**是刚性的外层——地壳加上最上部的地幔——它破裂成约十五个**板块**，在下方较弱的软流圈上彼此相对运动。板块相遇之处是一个**板块边界**，而只有三类：**离散型**（一个洋脊，新的岩石圈在此生成）、**汇聚型**（一个俯冲带或一个碰撞，岩石圈在此被破坏或揉皱）与**转换型**（一个断层，岩石圈在此被保存而擦身滑过）。板块的面积在一阶近似下是常数：创造与破坏相平衡，这就是为什么地球的半径在一亿年中没有可测量的变化。
:::

::: proposition 转换断层只在两个脊段之间、沿扩张方向错断洋脊 {#prop-transform}
当一个洋脊被断层错开时，断层只在两个脊段之间的那一段是活动的；错距之外两侧一同运动，那个构造是一个*断裂带*，一道不活动的疤痕。所以活动段告诉你扩张方向，而错距乘以扩张速率给出两个脊段之间的年龄差。
:::

::: proof
设洋脊在两个块体上均呈南北向、向东错开，而扩张以速度 $v$ 背离每个脊段。考虑断层上位于两个脊段之间的一点：西侧的地壳正背离东侧的脊向西运动，而东侧的地壳正离开西边的脊向东运动，所以两侧以 $2v$ 彼此滑过——断层是活动的。现在考虑同一条线上位于两个脊段*之外*的一点：两侧都是在同一个脊段形成的地壳，同向同速，所以没有相对运动、没有断层活动。错开的线作为洋底上一条线状疤痕延续下去——一个断裂带——这正是洋底图所显示的，而 J. 图佐·威尔逊在 1965 年就是这样识别出转换断层的。∎
:::

::: quiz
一条转换断层切过大陆边缘，一串火山海山沿其延长线排列，年龄离洋脊越来越老。火山作用的机制是什么？
- [ ] 板块在转换断层之下俯冲。
- [x] 一个热点：板块内部一股相对固定的熔融地幔柱，板块在其上移动，留下一条年龄递增的火山链。
- [ ] 沿转换断层的伸展致熔。
- [ ] 转换断层直接沟通了软流圈。
::: solution
沿一个板块离脊延伸、既无海沟也无扩张中心的年龄递增火山链，是热点轨迹的经典特征：夏威夷–皇帝海山链、路易斯维尔海岭、沃尔维斯海岭。转换断层本身不产生熔融（它们保持面积不变，因而没有减压），也没有俯冲板块向源区加入挥发分。"相对固定"这个限定很重要：有些热点轨迹会因为地幔柱本身在移动而弯曲，这就是为什么夏威夷–皇帝海山链在 $47\ \mathrm{Ma}$ 处的拐弯至今仍有争论，而不能简单地读作板块运动方向的改变。
:::
:::

::: example 板块的回路：速度的相加 {#ex-circuit}
太平洋板块沿圣安德烈亚斯断层相对北美以 $5.2\ \mathrm{cm\,yr^{-1}}$ 运动，而北美在大西洋中脊相对欧洲以 $2.2\ \mathrm{cm\,yr^{-1}}$ 运动。如果两个运动平行，太平洋–欧洲的速度是什么？第二个测量给出太平洋–澳大利亚的相对速度为 $6.5\ \mathrm{cm\,yr^{-1}}$；如果澳大利亚–欧洲是 $6.7\ \mathrm{cm\,yr^{-1}}$，太平洋、澳大利亚与欧洲的运动与一个刚性的地球一致吗？
::: solution
绕一个闭合回路速度相加，故两运动平行时太平洋–欧洲的速度是 $5.2 + 2.2 = 7.4\ \mathrm{cm\,yr^{-1}}$。

对第二部分，三个刚性板块的三个相对速度必须矢量闭合：$\mathbf{v}_{\text{Pa–Au}} + \mathbf{v}_{\text{Au–Eu}} + \mathbf{v}_{\text{Eu–Pa}} = 0$。取大小，$|6.5 - 6.7| \le 7.4$ 而 $6.5 + 6.7 \ge 7.4$，所以存在一个三角形——但仅当方向也合适时，而太平洋–澳大利亚与澳大利亚–欧洲运动之间的夹角由余弦定理唯一确定。对整个全球网络做这套运算、发现其闭合差在观测误差之内，正是"板块构造是一个刚性板块模型"这句话在操作上的含义。当一个回路不闭合时——而有几个不闭合，尤其是尚未纳入菲律宾海板块时的西太平洋——这一不匹配不是观测误差，而是存在一个未被识别的额外微板块、或一个"板块"内部存在弥散变形的证据（[[geophysics/palaeomagnetism]]）。
:::
:::

## 板块的驱动力

::: proposition 这些力，以及它们的大小 {#prop-forces}
有三个体积力与表面力作用在板块上。**脊推力**是岩石圈离开洋脊处逐渐变厚变冷所形成的重力势能水平梯度；对厚度 $L$、热膨胀系数 $\alpha$、温度差 $T$ 的岩石圈，其量级为
$$
F_\text{rp} \sim \tfrac{1}{2}\,\rho_m g\,\alpha T L^2 \approx 2\times10^{12}\ \mathrm{N\,m^{-1}} 。
$$
**板拉力**是冷的俯冲板块的负浮力，量级为
$$
F_\text{sp} \sim \tfrac{1}{2}\,\Delta\rho\, g\, \ell^2 \sim 10^{13}\ \mathrm{N\,m^{-1}}
$$
对长 $\ell \sim 600\ \mathrm{km}$、密度超额 $\Delta\rho \sim 30$–$50\ \mathrm{kg\,m^{-3}}$ 的板块。**底面的拖曳**来自地幔流，方向可正可负，量级与脊推力相当。板拉力最大，这就是为什么俯冲边缘最长的板块——太平洋诸板块——运动最快。
:::

::: proof
脊推力就是板块厚而冷边缘上的岩石静压力，减去薄而热的洋脊处那一份，所得的超额。把岩石圈看作一个底界按 $\sqrt{t}$ 加深、密度超额在底界为 $\Delta\rho = \rho_m \alpha T$、在顶部为零的表层；对均匀梯度把水平应力沿深度积分，给出每单位脊长的力 $\tfrac{1}{2}\rho_m g \alpha T L^2$，其中 $L$ 是岩石圈的厚度。取 $\rho_m = 3300\ \mathrm{kg\,m^{-3}}$、$\alpha = 3.2\times10^{-5}\ \mathrm{K^{-1}}$、$T = 1330\ \mathrm{K}$、$L = 60\ \mathrm{km}$，这是 $2.5\times10^{12}\ \mathrm{N\,m^{-1}}$。

板拉力用对重物体同样的论证：单位体积所受的竖直力为 $\Delta\rho g$，沿一条长 $\ell$ 的倾斜板块把水平分量积分，给出 $\tfrac{1}{2}\Delta\rho g \ell^2$；对 $\Delta\rho = 50\ \mathrm{kg\,m^{-3}}$、$\ell = 600\ \mathrm{km}$，是 $8.8\times10^{13}\ \mathrm{N\,m^{-1}}$。两个估计都只是量级估计，而相对于地壳强度两者都很大，这就是板块能够运动的原因。∎
:::

于是得到一个能解释观测速度的等级序列：最快的板块（太平洋、纳斯卡、科科斯，$7$–$15\ \mathrm{cm\,yr^{-1}}$）大多为海沟所环绕，携带古老、致密、正在俯冲的岩石圈；最慢的（大西洋的板块，$1$–$2.5\ \mathrm{cm\,yr^{-1}}$）只靠洋脊推。全球的力矩收支可以测量：地震释放的总力矩，加上稳定蠕滑释放的力矩，在误差范围内等于观测板块运动所要求的力矩——1960 年代这项检验把一套描述变成了一门动力学。

::: example 一个断层的 {#ex-momentbudget}
圣安德烈亚斯系统在一个长 $1000\ \mathrm{km}$、锁闭至 $15\ \mathrm{km}$ 深的条带内吸收约 $3.5\ \mathrm{cm\,yr^{-1}}$ 的太平洋–北美运动。取 $\mu = 30\ \mathrm{GPa}$。求构造的，以及每年一个的震级。
::: solution
$$
\dot M_0 = \mu A v = 3\times10^{10}\times(10^{6}\times1.5\times10^{4})\times3.5\times10^{-2} = 1.6\times10^{19}\ \mathrm{N\,m\,yr^{-1}} 。
$$
力矩为 $M_0$ 的地震，其震级为 $M_\text{w} = \tfrac{2}{3}(\log_{10} M_0 - 9.1)$，要在一次地震中释放全年的力矩收支，需要 $M_\text{w} = 7.3$。实际上该系统很少产生大地震——南段的上一次是 1857，北段是 1906——这意味着应变在积累，而"力矩亏损"在增长。约三分之一的收支由中段的无震蠕滑释放，其余部分就是两座城市的地震危险。这是每一项地震危险性估计背后的算术：测大地测量滑动速率，算力矩速率，再问历史目录解释了其中多少（[[natural-hazards/earthquake-hazard]]、[[geophysics/earthquake-sources]]）。
:::
:::

## 这个循环，以及它为什么是一个循环

岩石圈在洋脊生成、在海沟消亡，所以表面总体必处于稳态；但*格局*并非稳态。大陆因太轻而不能俯冲，于是不断累积，并被周期性地聚成一个超大陆、再被撕开——**威尔逊循环**，时间尺度约 $300$–$600\ \mathrm{Myr}$。岩石记录中可识别的聚合超大陆有约 $1.8$–$1.5\ \mathrm{Ga}$ 的努纳（哥伦比亚）、约 $1.1$–$0.9\ \mathrm{Ga}$ 的罗迪尼亚，以及约从 $335$ 到 $175\ \mathrm{Ma}$ 的泛大陆。

这个循环的物理，是隔热与强度之间的竞争。超大陆为其下地幔隔热，于是热量积累、岩石圈变弱并隆起，一套裂谷系统随之启动——东非裂谷是这个过程的开端，大西洋则是它的完成。一旦一条板块在新的边缘开始下沉，板拉力便接管，把大陆撕开的速度快过当初启动它的脊推力。所以大陆最终总是落在它们之间张开的那道大洋的两侧，这就是为什么地球上最老的地壳——加拿大、西伯利亚、西澳大利亚与非洲的太古宙地盾——正坐落在那些一度位于泛大陆腹地的大陆的腹地。

::: history
这段发现史值得按日期记住，因为它是地质学所能提供的最好的一个科学社会学案例。魏格纳 1912 年 1 月 6 日向德国地质学会报告大陆漂移，1915 年出版《海陆的起源》；1924 年纽约科学院的那场美国辩论以漂移说的彻底溃败告终，胜负决定于机制的缺席。阿瑟·霍姆斯在 1928–1931 年提出地幔对流作为那个机制，却被冷落了四十年。普林斯顿的岩石学家、海军预备役军官哈里·赫斯在 1961–1962 年写下海底扩张假说，称之为"一篇本该被人一笑置之、付之一笑而后忘掉的论文"，而他在 1953 年为太平洋测深时最先注意到平顶海山（盖约特）；罗伯特·迪茨在同一年独立发表了类似的观点。罗纳德·梅森与德拉蒙德·马修斯，以及独立地劳伦斯·莫利，在 1961–1963 年发现了对称的磁异常图案；弗雷德·瓦因当时是一个二十四岁的研究生。1965 年威尔逊定义了转换断层；1967 年 W. 杰森·摩根，以及另外的丹·麦肯齐与罗伯特·帕克，把板块运动表述为球面上的旋转，算出了第一个全球模型；1968 年伊萨克斯、奥利弗与赛克斯把力学合成一体。从一台拖曳式磁力计到一个固体地球的统一理论，只用了六年。
:::

## 通向何处

板块的几何在 [[geophysics/palaeomagnetism]] 中被定量地使用，视极移与磁异常直接给出旋转；也在 [[structural-geology/rifts]] 与 [[structural-geology/orogens]] 中，它们是两类边界的产物。前两章的火山与地震，在 [[physical-geology/volcanoes]] 与 [[physical-geology/earthquakes]] 中被读作边界的现象；[[#ex-litho]] 的热模型是 [[geophysics/heat-flow]] 的基础；而从中美洲海道的关闭到季风，对气候与海洋化学的种种后果，贯穿 [[palaeoclimate/deep-time]]。

::: summary 关键要点
- 大陆漂移被拒绝的理由是对的（没有机制），而被接受的理由更好（洋底是年轻的，而它记录地磁场）。
- 磁异常直接给出扩张速率：到一个已知年龄的计时带的距离是速率乘以年龄，而图案的对称性是洋底扩张的证明。
- 洋底从不老于约 $180\ \mathrm{Myr}$，它的深度、厚度与热流都服从同一个 $\sqrt{t}$ 的冷却律，而它的年龄结构正是为什么地球上最老的岩石是大陆的。
- 有三类板块边界，它们分别保持、创造或破坏面积；转换断层只在两个脊段之间是活动的，这就是为什么一个断层的走向记录一个扩张的方向。
- 板拉力量级约 $10^{13}\ \mathrm{N\,m^{-1}}$，超过量级约 $10^{12}\ \mathrm{N\,m^{-1}}$ 的脊推力；快的板块被拉，慢的板块被推。
- 一个断层的力矩收支能用两种方法测量——大地测量与地震学——而两者的差就是灾害。
- 超大陆隔热、变弱而裂开：威尔逊循环是大陆太轻而不能俯冲的后果。
- 板块构造在 1961 到 1968 之间由船、磁力计与球面几何定案，而不是由一个新的野外计划。
:::

## 练习

::: exercise 从一个异常求扩张速率 {level=1 check="2.5"}
在 $30^\circ\mathrm{N}$ 的大西洋中脊，年龄 $2.6\ \mathrm{Ma}$ 的计时带 2 异常位于离脊轴 $32\ \mathrm{km}$。以 $\mathrm{cm\,yr^{-1}}$ 求总扩张速率。
::: solution
半速率 $= 3.2\times10^{4}/2.6\times10^{6} = 1.23\ \mathrm{cm\,yr^{-1}}$，所以总速率是 $2.5\ \mathrm{cm\,yr^{-1}}$。这是一条典型的慢脊；那里的脊轴被断层切成洋核杂岩，而这是慢速扩张不同于快速扩张的方式之一。
:::
:::

::: exercise 大西洋的年龄 {level=1 check="190"}
大西洋在 $30^\circ\mathrm{N}$ 宽 $4800\ \mathrm{km}$、以 $2.5\ \mathrm{cm\,yr^{-1}}$ 扩张。它张开了多久，而那里最老的沉积预期年龄是多少？
::: solution
$t = 4.8\times10^{6}/2.5\times10^{-2} = 1.9\times10^{8}\ \mathrm{yr}$，约 $190\ \mathrm{Myr}$。北大西洋最老的洋壳实际上约 $175$–$180\ \mathrm{Ma}$、早侏罗世，而其上最老的沉积只稍年轻。这个小的不一致是有信息的：它意味着自裂谷以来平均速率略*高于*今天，而大西洋的距离–年龄曲线确实在靠近大陆处比在脊处更陡。
:::
:::

::: exercise 转换断层的几何 {level=1 check="4"}
一条洋脊被错开 $80\ \mathrm{km}$、以 $4\ \mathrm{cm\,yr^{-1}}$ 的总速率扩张。在离各自最近脊段等距处量测，活动的转换断层两侧地壳的年龄差是多少？
::: solution
同一个脊段两侧同时形成的地壳被沿转换断层错开；错距另一侧的地壳形成于另一个脊段，早晚相差 $d/v_\text{half}$。以 $2\ \mathrm{cm\,yr^{-1}}$ 的半速率，年龄差是 $8\times10^{4}/(2\times10^{-2}) = 4\times10^{6}\ \mathrm{yr}$，即 $4\ \mathrm{Myr}$。（以 Myr 输入。）
:::
:::

::: exercise 旋转极 {level=2 check="0.48"}
一条离其旋转极 $3000\ \mathrm{km}$ 的脊段以 $2.5\ \mathrm{cm\,yr^{-1}}$ 的半速率扩张。以每百万年多少度求角速度，以及离极近 $1000\ \mathrm{km}$ 处的半速率。
::: solution
对刚性旋转，$v = \omega r$，其中 $r$ 是沿大圆到极的距离，所以
$$
\omega = \frac{2.5\times10^{-2}}{3\times10^{6}} = 8.3\times10^{-9}\ \mathrm{rad\,yr^{-1}} = 0.48\ \mathrm{deg\,Myr^{-1}} 。
$$
在 $r = 2000\ \mathrm{km}$，半速率是 $2.5\times(2000/3000) = 1.7\ \mathrm{cm\,yr^{-1}}$。这就是为什么同一条洋脊的扩张速率会沿脊从一端到另一端系统变化，也是为什么在一个地方读一个速率而把它用到另一个地方是一个标准的错误。
:::
:::

::: exercise 板块受力 {level=2 check="35"}
对一条长 $600\ \mathrm{km}$、$\Delta\rho = 50\ \mathrm{kg\,m^{-3}}$ 的板块，与一个 $L = 60\ \mathrm{km}$、$\alpha = 3.2\times10^{-5}\ \mathrm{K^{-1}}$、$T = 1330\ \mathrm{K}$、$\rho_m = 3300\ \mathrm{kg\,m^{-3}}$ 的板块，板拉力超过脊推力多少倍？
::: solution
$F_\text{sp} = \tfrac{1}{2}\times50\times9.81\times(6\times10^{5})^2 = 8.8\times10^{13}$，而 $F_\text{rp} = \tfrac{1}{2}\times3300\times9.81\times3.2\times10^{-5}\times1330\times(6\times10^{4})^2 = 2.5\times10^{12}\ \mathrm{N\,m^{-1}}$。比值是 $35$。

要紧的那个保留意见是：这些是驱动力的上限估计，而两者都不是真正使板块加速的东西，因为两者在很大程度上都被底阻曳平衡。这个比较的要点不是板块在某个绝对的意义上重要三十五倍，而是一个板块的速度取决于两者的*平衡*，而增加一段长长的俯冲边缘对平衡的改变，远大于把洋脊变得更热。
:::
:::

::: exercise 冷却与洋底的深度 {level=2 check="3859"}
洋底的深度服从半空间冷却模型 $d = d_0 + c\sqrt{t}$，在脊处 $d_0 = 2600\ \mathrm{m}$、$c = 350\ \mathrm{m\,Myr^{-1/2}}$。求模型在 $60\ \mathrm{Myr}$ 与 $180\ \mathrm{Myr}$ 的深度。（以米输入 $60\ \mathrm{Myr}$ 的深度。）
::: solution
$d(60) = 2600 + 350\sqrt{60} = 3859\ \mathrm{m}$，而 $d(180) = 2600 + 350\sqrt{180} = 7296\ \mathrm{m}$。

第一个数字是对的，而第二个是荒谬的——深海平原是 $4000$–$5500\ \mathrm{m}$ 深，在海沟之外从不 $7300\ \mathrm{m}$——而这一失败颇有教益。半空间模型假设一个可以无限冷却的半无限体，而真实岩石圈有一个下界，热从下方供给进来，于是冷却与沉降在年老时减缓。取而代之的是*板块模型*：岩石圈厚度固定，深度渐近于一个常数；两个模型在 $60$–$80\ \mathrm{Myr}$ 处接合。这就是为什么近脊的太平洋底是一道陡降的深海丘陵坡，而远端的太平洋是一片平原：$\sqrt{t}$ 律只适用于年轻洋盆。
:::
:::

::: exercise 磁异常图案的推导 {level=3}
一个洋脊以总速率 $v$ 对称扩张，而地磁场瞬时反转。把磁条带写成离脊轴距离 $x$ 与时间的函数，而证明一个持续 $\Delta t$ 的计时带的波长是 $v\Delta t$。一个持续 $0.2\ \mathrm{Myr}$ 的计时带，在一翼观测为一对相距 $12\ \mathrm{km}$ 的异常，在另一条洋脊上相距 $48\ \mathrm{km}$。两个速率是多少？
::: solution
现在在距离 $x$ 的地壳形成于 $t = x/v_\text{half}$，所以 $x$ 处的极性是 $s(x) = s_0(x/v_\text{half})$，其中 $s_0(t)$ 是地磁场的极性序列。一个持续 $\Delta t$ 的计时带在每一翼占距离 $\Delta x = v_\text{half}\Delta t$，所以同一个计时带在两翼的表现之间的距离是 $2v_\text{half}\Delta t = v\Delta t$。

以 $v\Delta t = 12\ \mathrm{km}$、$\Delta t = 0.2\ \mathrm{Myr}$：$v = 6\ \mathrm{cm\,yr^{-1}}$。以 $48\ \mathrm{km}$：$v = 24\ \mathrm{cm\,yr^{-1}}$，比今天任何洋脊都快——这正是测定白垩纪太平洋扩张速率（今天的两倍）的标准方法。这道练习也显示那个陷阱：如果你不独立地知道 $\Delta t$，异常的间距单独只给出比值，而绝对的年代表必须来自陆上有定年的熔岩。
:::
:::

::: exercise 一个板块构造的能量收支 {level=3}
地球的地震力矩释放的总量约 $5\times10^{22}\ \mathrm{N\,m\,yr^{-1}}$，而板块在其上滑动的板块边界的总长度约 $7\times10^{7}\ \mathrm{m}$、典型的相对速度 $3\ \mathrm{cm\,yr^{-1}}$。对一个震源宽度 $w = 20\ \mathrm{km}$、$\mu = 30\ \mathrm{GPa}$，估计构造力矩速率 $\dot M_\text{tec} = \mu L w v$，与地震的释放比较，并解释这一比值。
::: solution
$$
\dot M_\text{tec} = 3\times10^{10}\times7\times10^{7}\times2\times10^{4}\times3\times10^{-2} = 1.3\times10^{23}\ \mathrm{N\,m\,yr^{-1}} 。
$$
地震目录只解释了其中约 $40\%$。剩余部分由断层上的无震蠕滑释放、由从不发生动态破裂的俯冲界面滑动（如今由大地测量测到的慢滑移与震颤事件）、由板内弥散变形，以及由目录仅覆盖一个世纪、而地质时间尺度为 $10^5$–$10^6$ 年、因而漏掉该循环中最大那些事件这一事实。

这个比较是地震危险性的定量的基础：若两个数字在数十万年尺度上一致，那么大地测量力矩速率就给出长期地震速率，而任何观测地震活动远低于大地测量速率的地区都在积存弹性应变。这就是用于喜马拉雅、卡斯卡迪亚与地中海的论证，它也是板块构造可用一台 GPS 接收机检验的一条预报（[[natural-hazards/risk]]）。
:::

::: exercise 重建一个洋 {level=3}
两个大陆的边缘隔一个洋相对。磁异常在一翼给出离脊轴 $2400$、$1800$、$1200$ 与 $400\ \mathrm{km}$ 处的年龄 $120$、$90$、$60$ 与 $20\ \mathrm{Ma}$。画出或描述扩张史，并说明这个洋何时开始张开、速率有无变化。
::: solution
若速率恒定，距离对年龄是一条过原点的直线：$2400/120 = 20$、$1800/90 = 20$、$1200/60 = 20$、$400/20 = 20\ \mathrm{km\,Myr^{-1}}$，即 $2.0\ \mathrm{cm\,yr^{-1}}$ 的半速率与 $4\ \mathrm{cm\,yr^{-1}}$ 的总速率，在 $120\ \mathrm{Myr}$ 中不变。外推到零的距离给出约 $120\ \mathrm{Ma}$、早白垩世的张开年龄，而洋壳上最老的沉积岩应只比大陆—大洋边界处的洋壳略老。

在真实的数据中这条线从不这样直：早期常有一段快速阶段（最初 $20\ \mathrm{Myr}$ 的"关键窗口"高速扩张），而距离—年龄曲线上的一处拐弯记录一次速率变化，可与对侧陆缘、与板块回路相互印证。外推所得的截距，而非现今速率，才是裂谷的年龄——这就是为什么南大西洋的张开时间要靠靠近大陆的最老洋壳来论证，而不是靠今天的洋脊。
