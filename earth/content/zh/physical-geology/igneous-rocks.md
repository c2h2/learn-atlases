你曾站立其上的每一块岩石，在某个时刻都曾是一种能流动的液体。地壳中火成岩体积的九成在地下几千米处缓慢地结晶，那里从来没有人看见过它；剩下的一成从一个喷口涌出，而其中大部分又落回海里。洋底的岩石——其下的玄武岩与层状的辉长岩，约 $7\ \mathrm{km}$ 厚、在 $60{,}000\ \mathrm{km}$ 的洋脊上不断更新——是这颗行星上最大的单一火成岩体，而它们正在被制造，以约 $20\ \mathrm{km^3\,yr^{-1}}$ 的速率，在 $2{,}500\ \mathrm{m}$ 深的水中、在完全的黑暗里。

火成岩岩石学对任何这样的岩石问两个问题。*液体是什么，它从哪里来？*——一个化学与热力学的问题。*它冷得多快，在哪里？*——一个热传导的问题，由你脚下的结构回答。本章按顺序处理这两个问题，而顺带解释为什么一个玄武岩与一个辉长岩能化学上相同，为什么花岗岩是最富硅的常见岩石、而不是最富硅的可能存在的岩石，而为什么同一个火山能在周二产出一个温和的熔岩喷泉、在周五产出一根 $30\ \mathrm{km}$ 高的灰柱。

## 岩石如何熔融

::: definition 岩浆、固相线、液相线、熔融程度 {#def-melting}
一个**岩浆**是一个天然的硅酸盐液体，带着它所携带的任何晶体与任何溶解的挥发分。**固相线**是（在给定的压力与挥发分含量下）一个岩石开始熔融的温度；**液相线**是它完全成为液体的温度。在两者之间，岩石是一个晶体与液体的糊状物，而**部分熔融的程度** $F$ 是已成为液体的质量分数。因为大多数岩石是几种有不同熔点的矿物的混合物，一个岩石没有*一个*熔融温度：它有一个熔融*范围*，常常宽 $200$–$300\ ^\circ\mathrm{C}$。
:::

::: proposition 熔化一块岩石只有三种方式 {#prop-threeways}
既然熔融发生在地温梯度超过固相线时，而地温梯度与固相线都是压力与温度的函数，那么一块岩石能因以下方式被熔化：(i) **降压**——沿一条近绝热线把岩石移向更低的压力，使固相线落到它之下；(ii) **加入助熔组分**——加入一个组分，主要是 $\mathrm{H_2O}$，它降低固相线；或 (iii) **加热的加入**——通过注入一个更热的岩浆、或通过来自下方的传导，提高岩石的温度。地球上每一个花岗岩与每一个玄武岩都由这三种之一、或一个组合产生。
:::

::: proof
考虑压力–温度平面。一个固定的干成分的岩石占据平面上的一个点 $(P,T)$，而熔融要求 $T$ 位于固相线曲线 $T_s(P)$ 之上。如果岩石的路径在平面中跨过那条曲线，三件事中必有一件发生：$P$ 在近常数 $T$ 下下降（路径向左移动）；$T$ 在近常数 $P$ 下上升（路径向上移动）；或者曲线本身向下移到岩石上，这在成分改变时发生——通过水的加入、或 $\mathrm{CO_2}$ 的、或一个含水矿物的丢失。在不等式 $T > T_s(P, X_\mathrm{H_2O})$ 中没有第四项。∎
:::

哪种机制起作用是一个构造环境的问题，而这三种几乎完美地对应三大岩浆类型。

- **上涌的橄榄岩的降压熔融**制造玄武岩。在洋中脊之下，地幔上升因为板块被拉开；它在绝热降压时温度只下降 $0.4\ \mathrm{K\,km^{-1}}$，而橄榄岩的固相线以约 $4\ \mathrm{K\,km^{-1}}$ 随深度上升，所以上升的岩石在 $60$–$70\ \mathrm{km}$ 跨过它自己的固相线、而连续地熔融直到它停止上升。积分的熔融是 $F \approx 0.2$–$0.25$，而被抽出的液体是一个洋中脊玄武岩（MORB）。同一个过程作用在一个更热的、更深的上涌上，制造大洋岛屿玄武岩。
- **助熔熔融**制造俯冲带的安山岩与弧玄武岩。水被板块在 $80$ 到 $150\ \mathrm{km}$ 深度从含水矿物中排出；上升进上覆的楔形它把橄榄岩的固相线降低 $100$–$200\ ^\circ\mathrm{C}$，而楔形在一个它已经具有的温度熔融。水饱和的花岗岩质的系统比干的低 $200$–$300\ ^\circ\mathrm{C}$ 熔融，这就是为什么岩浆弧之下的深地壳是湿的而容易熔融。
- **热驱动的熔融**制造大的酸性的省与地壳的花岗岩。一个上升进下地壳的玄武岩质的岩浆，仅潜热就每 $\mathrm{km^3}$ 携带约 $1\times10^{18}\ \mathrm{J}$，足以对它每就位一立方千米就熔化掉几十分之一立方千米的围岩。

::: example 制造一立方千米的岩浆需要多少能量？ {#ex-heat}
取 $500\ ^\circ\mathrm{C}$ 的地壳岩石，它必须被加热到 $750\ ^\circ\mathrm{C}$ 而熔融。用 $\rho = 2700\ \mathrm{kg\,m^{-3}}$、$c_P = 1100\ \mathrm{J\,kg^{-1}\,K^{-1}}$、熔融潜热 $L = 4\times10^{5}\ \mathrm{J\,kg^{-1}}$。求每 $\mathrm{km^3}$ 的能量，而与 $1\ \mathrm{km^3}$ 的玄武岩结晶时释放的热比较（潜热 $4\times10^{5}\ \mathrm{J\,kg^{-1}}$，加上从 $1200$ 到 $800\ ^\circ\mathrm{C}$ 的冷却）。
::: solution
每立方米的需求是
$$
\rho\left(c_P \Delta T + L\right) = 2700\times\left(1100\times250 + 4\times10^{5}\right) = 2700\times6.75\times10^{5} = 1.82\times10^{9}\ \mathrm{J\,m^{-3}} ，
$$
所以每 $\mathrm{km^3}$ $1.8\times10^{18}\ \mathrm{J}$——约世界一次能源年消耗的 $0.3\%$，由自然送进几立方千米的地壳。

一立方千米结晶的玄武岩供给 $2700\times10^{9}\times\left(4\times10^{5} + 1100\times400\right) = 2.1\times10^{18}\ \mathrm{J}$。这两个数字彼此在 $15\%$ 之内，这就是热驱动的地壳熔融可信的全部理由：一立方千米侵入的玄武岩能熔化大约一立方千米的地壳，而层状侵入体的地质、岩基的接触变质晕的地质表明它确实发生。它做不到的是熔化*十*立方千米而没有玄武岩的一个持续的供给——这就是为什么大的酸性岩浆在长命的热点与弧之上被找到，不在单一事件中。
:::
:::

## 结构：你看得见的冷却历史

::: definition 按冷却速率分的火成结构 {#def-texture}
**显晶**结构有肉眼可见的晶体（$>0.5\ \mathrm{mm}$），意味着在深处缓慢冷却。**隐晶**结构有一个显微晶体的基质，意味着在表面或近表面快速冷却。**斑状**结构在一个更细的基质中有大的晶体（*斑晶*），意味着两个冷却阶段。**玻璃质**结构意味着淬火快得让原子在能够排列之前就停止运动：黑曜岩，以及任何熔流骤冷的边缘。**火山碎屑**结构是一个从喷口吹出的碎片的集合。
:::

::: proposition 晶体大小记录时间，不记录温度 {#prop-grainsize}
在与地壳岩浆有关的扩散控制的机制中，一个晶体在时间 $t$ 内能达到的半径按
$$
R \sim \sqrt{D t}
$$
标度，其中 $D \sim 10^{-18}\ \mathrm{m^2\,s^{-1}}$ 是一个冷却的熔体或一个湿的晶体糊状物中网络形成阳离子的典型的扩散系数。所以几毫米的颗粒需要约 $10^5$ 年的生长，而厘米级的颗粒 $10^6$–$10^7$ 年。
:::

::: proof
由最慢的必需的组分的扩散控制的生长给出抛物线的律 $R^2 = kDt$，其中 $k$ 是一个量级为一的无量纲的生长因子（这种形式的扩散控制的生长律与一个热板板的傅里叶冷却是同一个数学，在[物理图集](/learn/physics/)中展开）。以 $D = 10^{-18}\ \mathrm{m^2\,s^{-1}}$、$t = 10^5\ \mathrm{yr} = 3.2\times10^{12}\ \mathrm{s}$，$R = \sqrt{3.2\times10^{-6}} = 1.8\ \mathrm{mm}$；对 $10^6\ \mathrm{yr}$，$R = 5.6\ \mathrm{mm}$。长出一个 $1\ \mathrm{cm}$ 的晶体需要约 $3\times10^6\ \mathrm{yr}$。

两个结果。第一，一个手标本有厘米的晶体，它是一个*钟*：它的寄主侵入体热了几百万年，这排除了岩基在几十年内就位的任何模型。第二，晶体大小由可用的时间设定，而不由有多热设定：一个热的岩石如果快速冷却是细粒的，而一个凉的如果缓慢冷却是粗粒的。当你在一个露头上同时看到粗的晶体与玻璃——一个斑状的黑曜岩、一个带巨晶的花岗岩——你在一个手标本中看到了两个时间尺度，而岩石学家的工作是分开它们。∎
:::

::: example 一个岩床冻结要多久？ {#ex-cooling}
用一个半厚度 $L$ 的岩浆体，以 $t \sim L^2/\kappa$、热扩散率 $\kappa = 10^{-6}\ \mathrm{m^2\,s^{-1}}$，估计 $L = 1\ \mathrm{m}$、$100\ \mathrm{m}$、$1\ \mathrm{km}$ 的传导的冷却时间。
::: solution
$$
t \approx \frac{L^2}{\kappa} = \{3\times10^{4},\ 3\times10^{8},\ 3\times10^{9}\}\ \mathrm{s} = \{0.03,\ 300,\ 30{,}000\}\ \mathrm{yr} 。
$$
一米宽的岩墙在几周内冻结，这就是为什么岩墙的边缘是玻璃质的、而它们的中心是隐晶的。一个 $200\ \mathrm{m}$ 的岩床要几个世纪，而一个 $2\ \mathrm{km}$ 的岩体要几万年——与 [[#prop-grainsize]] 的晶体大小一致，也与在大的层状侵入体上测得的 U–Pb 结晶年龄一致，后者分辨出 $10^5$ 年或更长的冷却间隔。

有用的是这个标度：冷却时间按大小的*平方*变化。一个厚十倍的体要一百倍长的时间冻结，这就是为什么只有大的侵入体是粗粒的，而为什么整个大洋地壳——其下部的 $5\ \mathrm{km}$ 是一个在几个世纪到几千年中在一条脊轴附近冷却的辉长岩——是证明那条律的例外：它在下方被重新加热的速度和它在上方失去热一样快。
:::
:::

## 给岩石命名

两个决定固定一个火成岩的名字：**结构**，它告诉你它在哪里冷却；**成分**，它告诉你它由什么构成。最要紧的成分的轴是硅的活度，因为它决定岩石是含自由的石英、还是在另一个极端含似长石。

::: definition 从基性到长英质 {#def-composition}
岩石按 $\mathrm{SiO_2}$ 含量、以及它们的铁镁质矿物的镁铁比排列。**超基性**（$<45\%$ $\mathrm{SiO_2}$，橄榄石主导：橄榄岩、科马提岩）；**基性**（$45$–$52\%$，斜长石 + 辉石：玄武岩/辉长岩）；**中性**（$52$–$63\%$：安山岩/闪长岩）；**长英质**（$>63\%$，石英 + 长石：流纹岩/花岗岩）。**镁值**是
$$
\mathrm{Mg}\# = 100\times\frac{\mathrm{Mg}}{\mathrm{Mg}+\mathrm{Fe}} \quad \text{（摩尔，全铁记为 FeO）} ，
$$
而它是一个玄武岩演化了多少的最好的单一指标：地幔来源的液体有 $\mathrm{Mg}\# \approx 65$–$75$，而一个结晶出橄榄石与辉石的玄武岩稳定地降到 50 以下。
:::

| 成分 | $\mathrm{SiO_2}$ % | 火山岩（快冷） | 深成岩（慢冷） | 典型矿物 |
|---|---|---|---|---|
| 超基性 | $<45$ | 科马提岩、苦橄岩 | 橄榄岩、辉石岩 | 橄榄石、辉石、少量斜长石 |
| 基性 | $45$–$52$ | 玄武岩 | 辉长岩、斜长岩 | 钙斜长石、辉石、橄榄石 |
| 中性 | $52$–$63$ | 安山岩 | 闪长岩 | 斜长石、角闪石、磁铁矿 |
| 长英质 | $>63$ | 流纹岩、英安岩 | 花岗岩、花岗闪长岩 | 石英、碱长石、钠斜长石、白云母 |
| 硅不饱和 | 任意，无石英 | 碧玄岩、白榴石岩 | 透长岩、似长石正长岩 | 以似长石代替长石/石英 |

::: example 镁值，以及它的含义 {#ex-mgno}
一个玄武岩含 $8.0\%$ $\mathrm{MgO}$ 与 $10.0\%$ $\mathrm{FeO}$（全铁记为 $\mathrm{FeO}$）。计算它的 $\mathrm{Mg}\#$，而说出它是不是一个原生的地幔液体。
::: solution
每 $100\ \mathrm{g}$ 的摩尔：$\mathrm{Mg} = 8.0/40.30 = 0.199$；$\mathrm{Fe} = 10.0/71.85 = 0.139$。于是
$$
\mathrm{Mg}\# = 100\times\frac{0.199}{0.199+0.139} = 59 。
$$
与地幔的橄榄石（$F_{\#}\approx0.90$）平衡的一个液体有 $\mathrm{Mg}\# \approx 70$，因为镁被橄榄石以约五倍的优选取走。在 59，这个玄武岩已把它约五分之一的镁与铁交给了橄榄石的结晶：它是一个分异了的液体，不是原生的。这道练习的要点是，一个从分析中三十秒算出的单一数字，告诉你这块岩石离它的母体有多远——这就是为什么 $\mathrm{Mg}\#$ 出现在你将见到的几乎每一张火成岩的图上。
:::
:::

::: warning "深色的岩石是基性的，浅色的岩石是长英质的"
颜色是一个有用的第一印象，也是一个常撒的谎。一个细粒的玄武岩能看着发灰，而一个粗粒的花岗岩如果富黑云母能是深的；一个完全隐晶的玄武岩能藏住橄榄石的斑晶，而一个流纹岩能是黑色的玻璃。更糟的是，这条规则在最要紧的地方完全失败：使一个岩石变深的铁镁质矿物正是要风化的那些，所以一个风化的辉长岩露头是赭色的、土状的。用模态的矿物学，或一个化学的指标如 $\mathrm{Mg}\#$，而把颜色当作一个待检验的提示。
:::

## 鲍文反应系列：为什么一个岩浆制造许多岩石

::: theorem 鲍文反应系列 {#thm-bowen}
当一个玄武岩质的液体冷却时，矿物按一个确定的序列结晶：先是橄榄石，然后是富钙的斜长石与单斜辉石，然后是铁–钛的氧化物、角闪石，最后是黑云母、白云母与石英；而残余的液体稳定地从基性的向长英质的成分移动。两个系列一起进行——铁镁质矿物的结构的一个*不连续*系列（孤立的四面体 → 链 → 层 → 架状），与斜长石的一个*连续*系列，其成分从钙长石 $\mathrm{CaAl_2Si_2O_8}$ 变到钠长石 $\mathrm{NaAlSi_3O_8}$。
:::

::: proof
这是一个实验的结果，由诺曼·鲍文在 1914 到 1928 之间通过加热与淬火磨碎的岩石、而数出现的相确立，而它从 [[physical-geology/minerals#thm-phaserule]] 的相律应用于一个多组分系统热力学地得出：在每一个温度，吉布斯能最低的组合物是稳定的，而当 $T$ 下降时，在固定的压力下稳定场按一个固定的顺序被跨过。化学演化的*方向*不用热力学也能看见。橄榄石，$(\mathrm{Mg,Fe})_2\mathrm{SiO_4}$，取走镁与铁、而不取硅、铝、钠或钾；辉石也一样，它多取一点硅。所以每一千克被从液体中移走的这类矿物，都让液体相对地富集硅与碱，而残余的熔体必须朝长石与石英的成分移动。反应系列就是那本账的逐矿物的陈述。∎
:::

结果是**分离结晶**：如果晶体沉降出来或被机械地从液体中分开，液体的成分就沿一条*液体演化线*演化，而一个母岩浆产出一套岩石。这是那些大的层状侵入体的机制——布什维尔德、斯卡尔加德、斯蒂尔沃特——那里的层的序列就是被原地冻住的反应系列，跨几十千米，而铬铁矿层与磁铁矿层是世界铬与铂的来源。

::: example 读一条液体演化线 {#ex-liquidline}
一个玄武岩质的液体是 $50\%$ $\mathrm{SiO_2}$。它结晶出成分为 $(\mathrm{Mg}_{0.9}\mathrm{Fe}_{0.1})_2\mathrm{SiO}_{4}$ 的橄榄石，它按重量含 $29.6\%$ $\mathrm{SiO_2}$。如果 $10\%$ 的液体结晶为那个橄榄石而被移除，残余液体的硅含量是多少？
::: solution
每 $100\ \mathrm{g}$ 液体计算：最初 $50\ \mathrm{g}$ 的 $\mathrm{SiO_2}$。移除 $10\ \mathrm{g}$ 的橄榄石，含 $2.96\ \mathrm{g}$ 的 $\mathrm{SiO_2}$。所以残余的 $90\ \mathrm{g}$ 液体含 $47.04\ \mathrm{g}$ 的 $\mathrm{SiO_2}$，即
$$
\mathrm{SiO_2} = \frac{47.04}{90} = 52.3\% 。
$$
百分之十的橄榄石结晶已把液体移过了基性/中性的边界。移除 $30\%$ 的橄榄石，液体达到 $57\%$；加上硅含量更高的辉石，而液体只有在其*全部*的镁铁质的部分在某个地方被移除时才能达到花岗岩的成分。这就是层状侵入体存在的质量平衡的理由，也是地球的地壳是安山质的而不是玄武质的这一观察的理由：每立方千米演化的岩浆，都有一立方千米隐藏的镁铁质的堆积体。
:::
:::

::: widget plot

x: 0, 60
y: 45, 70
sliders: s=30:10:60:1
labels: SiO2 of the residual liquid
caption: 残余液体的硅含量作为被移除的晶体的重量百分比的函数，对含 $s\%$ $\mathrm{SiO_2}$ 的晶体（滑块）。以 $s = 30$——橄榄石加一点斜长石——曲线从 $50\%$ 在 $40\%$ 结晶时升到 $60\%$。把 $s = 50$、液体本身的硅含量设上：曲线变平，而你刚刚发现了为什么如果晶体与液体有同样的成分、岩石的成分就不变。分离结晶只在晶体与熔体*不同*时才是一个分异机制。
:::

## 岩浆在哪里制造，以及它们变成什么

::: application 从一个火成岩读出构造环境 {#app-setting}
一个玄武岩的化学记录地幔的源与熔融的深度，所以一个未知的火山岩套能被归到一个环境。洋中脊玄武岩相对于高场强元素（Nb、Ta、Ti）在大离子亲石元素（K、Rb、Ba、Sr）上亏损，因为脊下的地幔已经被抽干了它们；弧玄武岩恰恰富集那些元素，由水从板块带上，而特征性地在铌与钽上亏损——那个"Nb–Ta 谷"，俯冲的指纹；大洋岛屿玄武岩在一切上富集，而来自更深的、更少亏损的地幔。这个检验的实用版本，用一小把痕量元素的比值，是地质学家决定一个已经被变形与变质了二十亿年的古老的火山带的环境的方法——也是今天关于 $3\ \mathrm{Gyr}$ 前板块构造的存在如何被争论的方法。
:::

三个进一步的要点属于一个最初的课程，因为它们是教科书的图景改变了的地方。

**岩浆体大多是糊状物。**活动弧与脊下的地震层析成像在地下壳中成像出百分之几的熔体，不是经典图景中千米尺度的充满液体的岩浆房。喷发抽取的是几立方千米的带，其中晶体与液体在 5–50 % 的熔体下共存；我们制图的那些岩体在很大程度上是这类系统的残余，以富晶体的浆状物就位。

**同化无处不在。**一个上升的岩浆溶解而反应它的围岩，而所得岩石的同位素成分记录两者。一个穿过 $5\ \mathrm{km}$ 花岗岩的玄武岩并入锶与钕、带着花岗岩的放射成的特征，这就是为什么大陆边缘的同位素图看着像它们下面的地质（[[geochemistry/radiogenic-tracers]]）。

**晶体比它们的岩石更老。**铀系与 U–Pb 对单个的锆石与磷灰石晶体的定年如今常规地表明，一个熔岩中的晶体在喷发之前已在一个糊状物中生长了几万到几十万年，而喷发本身组装了几个年龄的晶体。一个火成岩与其说是一个冷却事件的快照，不如说是一个糊状物的历史的拼图。

::: warning "花岗岩在 900 °C 熔融"
没有岩石在一个单一的温度熔融，而这一个取决于水达几百度。一个干的花岗岩质的固相线在几千米巴附近近 $950\ ^\circ\mathrm{C}$；一个水饱和的近 $700\ ^\circ\mathrm{C}$；而如果岩石是干的*而且*系统中没有水，白云母与黑云母在熔融之前分解，所以产生熔体的反应是一个脱水的熔融反应，不是一个熔点。引用一个固相线要带着它的压力与它的水活度，否则什么都不要引用。
:::

::: quiz
一个洋中脊与一个俯冲带都坐落在地幔之上，而都制造玄武岩。为什么俯冲带的玄武岩通常更富硅、而它的痕量元素的特征总是更湿？
- [ ] 因为俯冲带的地幔更热。
- [x] 因为来自板块的水降低楔形的固相线、而把板块的组分带进熔体，也因为熔体穿过厚的地壳而与之相互作用。
- [ ] 因为脊玄武岩在喷发之前被海水污染。
- [ ] 因为弧下的地幔更亏损。
::: solution
水在俯冲带同时做两件事：它压低固相线，所以熔融在更深处开始、在一个更低的温度进行、而在浅的楔形中常常到更高的程度；而它把在含水流体中可溶的元素（K、Rb、Ba、Sr、Pb）从板块带走，产生弧的痕量元素的特征，带其诊断性的负的 Nb 与 Ta 异常。弧的岩浆还被它们穿过的厚的地壳、被那部分地壳的热驱动的熔融进一步改造。俯冲带的地幔在深处*并不*比脊的地幔更热，而脊的情形才是化学上亏损的那个。
:::
:::

::: history
火成岩的问题是地质学的第一场大论争。在弗莱贝格的亚伯拉罕·维尔纳领导下的水成论者认为，一切岩石包括玄武岩与花岗岩都从一个全球的海洋中沉淀出来；而火成论者，其中詹姆斯·赫顿是第一个在 1780 年代在索尔兹伯里岩壁从野外证据论证它的人，认为花岗岩曾是熔化的。赫顿的案子是观察的——花岗岩侵入沉积的堆、把脉送进它们、而把它们烘焙——而它赢了。但机制必须等到实验室。诺曼·劳埃德·鲍文，在华盛顿的地球物理实验室用达到 $1400\ ^\circ\mathrm{C}$ 的热电偶与炉子工作，在 1914 到 1928 年间把天然与人造岩石的粉末加热、在水银中淬火、而在显微镜下数相；他的《硅酸盐熔体中的反应》（1928）是实验岩石学的奠基文本，也是极少数一个整个子学科是一个人的实验手艺的作品的例子。雷金纳德·戴利的《火成岩与地球的深度》（1933）随后把世界的化学分析汇编成那些图案——安山岩在弧中的丰度、大洋底部中性成分的稀少——而板块构造在三十五年后解释了它们。
:::

## 通向何处

结构与成分是 [[physical-geology/volcanoes]] 的词汇，那里同样的变量——硅、温度、水、晶体——被重新读作喷发的类型与灾害；也是 [[physical-geology/plate-tectonics]] 的词汇，那里岩浆类型的分布变成证据。热力学在 [[mineralogy-petrology/phase-diagrams]] 与 [[mineralogy-petrology/magma-evolution]] 中回来；痕量元素的推理在 [[geochemistry/trace-elements]] 中变成定量的；而一个冷却的地球的热收支，正是使火成活动成为可能的东西，在 [[geophysics/heat-flow]] 中被处理。

::: summary 关键要点
- 火成岩是冻住的液体，而它们的两个独立的信息是成分（源与过程）与结构（冷却速率与深度）。
- 岩石因降压、因水的助熔、或因加热而熔融——而这三种机制分别对应脊与地幔柱、俯冲带、地壳的花岗岩。
- 熔融是一个范围，不是一个温度；引用一个固相线总要说明压力与水活度。
- 晶体大小是一个钟：毫米的颗粒需要约 $10^5$ 年，厘米的颗粒 $10^6$ 年，而冷却时间按体的厚度的平方标度。
- 给一个岩石命名意味着命名结构与成分；$\mathrm{Mg}\#$ 与 $\mathrm{SiO_2}$ 承担大部分工作，而颜色两者都不可靠。
- 鲍文反应系列解释一个岩浆如何产出许多岩石：与它们的液体化学上不同的晶体被从中移除，把残余的液体推向花岗岩。
- 每立方千米演化的岩浆都有一立方千米隐藏的镁铁质堆积体——一个质量平衡的要求，不是一个猜测。
- 现代的火成岩岩石学把岩体与熔岩读作在 $10^4$–$10^6$ 年上组装的晶体糊状物，不是原地冷却的充满液体的岩浆房。
:::

## 练习

::: exercise 给岩石命名 {level=1 check="2"}
把每一个描述配上一个岩石名——玄武岩、辉长岩、流纹岩、橄榄岩——而说出你用了几个结构的、几个成分的决定：(a) 粗粒的、深的，橄榄石 + 辉石，看不见长石；(b) 隐晶的、黑的，带橄榄石的斑晶；(c) 粗粒的、粉的，石英与长石；(d) 隐晶的、玻璃质的基质，流构造的条带。
::: solution
(a) 橄榄岩——超基性的成分，显晶的。(b) 玄武岩——基性的，斑状的隐晶。(c) 花岗岩，不是流纹岩：结构是粗的，所以是深成的名字。(d) 流纹岩（如果基本上是玻璃质的则黑曜岩）——长英质的结构与玻璃质的淬火。每次两个决定：成分与结构。请注意 (c) 是陷阱："花岗岩"与"流纹岩"能有相同的化学。
:::
:::

::: exercise 一个熔流的冷却时间 {level=1 check="0.4"}
一个 $5\ \mathrm{m}$ 厚的玄武岩熔流从 $1200\ ^\circ\mathrm{C}$ 冷却；取 $\kappa = 5\times10^{-7}\ \mathrm{m^2\,s^{-1}}$，用 $t \sim L^2/\kappa$、$L$ 为半厚度，估计熔流的中心凝固的时间。以年给出答案。
::: solution
$t = 2.5^2/(5\times10^{-7}) = 1.25\times10^{7}\ \mathrm{s} = 0.40\ \mathrm{yr}$。实践中一个这个厚度的熔流在一年内就是固的，而这类熔流观测到的柱状节理记录了在那一年中冷却的收缩。与 [[#ex-cooling]] 比较：同一个岩石在 $1\ \mathrm{km}$ 的半厚度需要 $3\times10^{4}$ 年，厚度大 $400$ 倍而时间长 $10^5$ 倍。
:::
:::

::: exercise 镁值 {level=1 check="71"}
一个苦橄岩含 $16.0\%$ $\mathrm{MgO}$ 与 $7.0\%$ $\mathrm{FeO}$（全铁记为 $\mathrm{FeO}$）。计算它的 $\mathrm{Mg}\#$。
::: solution
每 $100\ \mathrm{g}$ 的摩尔：$\mathrm{Mg} = 0.397$、$\mathrm{Fe} = 0.0974$。$\mathrm{Mg}\# = 100\times0.397/0.494 = 71$。这在与地幔的橄榄石平衡的一个原生液体的范围，而与这个苦橄岩的富橄榄石的斑晶的载荷一致。
:::
:::

::: exercise 粘度与喷发 {level=2 check="4.1"}
用一个活化能 $E = 500\ \mathrm{kJ\,mol^{-1}}$ 的阿伦尼乌斯律为一个流纹岩质的熔体建模粘度。当熔体从 $1200\ ^\circ\mathrm{C}$ 冷却到 $800\ ^\circ\mathrm{C}$ 时，粘度增加多少倍？
::: solution
$$
\frac{\eta_2}{\eta_1} = \exp\left[\frac{E}{R}\left(\frac{1}{T_2} - \frac{1}{T_1}\right)\right] = \exp\left[\frac{5\times10^{5}}{8.314}\left(\frac{1}{1073} - \frac{1}{1473}\right)\right] = e^{15.2} = 4.1\times10^{6} 。
$$
下降 $400\ ^\circ\mathrm{C}$ 使粘度升高近七个数量级。这就是为什么酸性的岩浆，因为聚合在液相线温度已经比玄武岩粘 $10^4$–$10^6$ 倍，在通道中停滞而形成穹丘；为什么黑曜岩，它需要一个高到在淬火中阻止结晶的粘度，是一个酸性的产物；而为什么一个喷发的温度是火山学家想要的第一个数字（[[physical-geology/volcanoes]]）。
:::
:::

::: exercise 熔体的浮力 {level=2 check="123"}
镁铁质的熔体有 $\rho = 2650\ \mathrm{kg\,m^{-3}}$，而周围的橄榄岩地幔 $2900\ \mathrm{kg\,m^{-3}}$。求这样一个熔体 $50\ \mathrm{km}$ 的柱所产生的超额压力，而解释为什么熔体仍然积累在长命的糊状物带中，而不是以一条连续的流上升到表面。
::: solution
$$
\Delta P = \Delta\rho\, g\, h = 250\times9.81\times5\times10^{4} = 1.23\times10^{8}\ \mathrm{Pa} = 123\ \mathrm{MPa} 。
$$
这远超过地壳的断裂韧度所要求的，所以一旦一个熔体的分数是连通的，通过岩墙的上升是容易的。限制连续上升的是*抽出*：在低于约 $15$–$20\%$ 的熔体分数，液体孤立地在颗粒的角上而不能形成一个连通的网络，所以它只通过缓慢的压实或糊状物的破裂迁移。岩浆的上升因此是间歇的、而由渗透率的阈值控制，不由浮力控制，这就是为什么喷发是脉冲而不是一阵毛毛雨。
:::
:::

::: exercise 分离结晶，定量的 {level=2 check="58.7"}
用 [[#ex-liquidline]] 的方法，求从一个 $50\%$ $\mathrm{SiO_2}$ 的玄武岩质的液体中结晶出 $30\%$ 的橄榄石（$29.6\%$ $\mathrm{SiO_2}$）之后剩下的液体的硅含量。
::: solution
每 $100\ \mathrm{g}$：$50\ \mathrm{g}$ 的 $\mathrm{SiO_2}$，减去 $30\times0.296 = 8.88\ \mathrm{g}$，在 $70\ \mathrm{g}$ 的液体中留下 $41.12\ \mathrm{g}$：$58.7\%$。液体已跨进安山岩的域，而这恰恰是大陆出露的地壳所主导的成分——这是大陆地壳不是原生的地幔熔体、而是玄武岩的分异的残余的最强的单一论证。
:::
:::

::: exercise 相律的结果的推导 {level=3}
对一个 $C$ 个组分、$P$ 个相的系统，证明在固定的压力下，一个共晶（三个相、两个组分）没有自由度，而用这个解释为什么"花岗岩的熔融温度"不是一个提得好的问题，而一个指定的岩石在指定的压力与水活度下的固相线是。
::: solution
$F = C - P + 2$；固定压力移走一个自由度，所以 $F = C - P + 1$。对 $C = 2$、$P = 3$：$F = 0$，一个不变点——一个温度、一个液体成分。对一个真实的地壳岩石，$C \approx 8$–$10$（氧化物 $\mathrm{SiO_2}$、$\mathrm{Al_2O_3}$、$\mathrm{FeO}$、$\mathrm{MgO}$、$\mathrm{CaO}$、$\mathrm{Na_2O}$、$\mathrm{K_2O}$、$\mathrm{H_2O}$），而五个或六个相共存时，即使在固定的压力下 $F \approx 3$–$5$：熔融在一个温度的范围上发生，而液体的成分沿它连续地改变。

所以"花岗岩在什么温度熔融？"这个问题没有答案，除非压力、水活度、以及熔融区间上的位置被指定——最后一个是因为"熔融"能指第一滴液体或最后一个消失的晶体，而两者相差 $100\ ^\circ\mathrm{C}$ 或更多。提得好的版本是："这个已分析的岩石的固相线的温度，在 $P_\mathrm{H_2O} = 3\ \mathrm{kbar}$、水饱和"，这是一个不同的实验室能重复到几度的测量。
:::
:::

::: exercise 一个晶体大小的数据集 {level=3}
一个层状堆积岩套中的橄榄石的晶体的半径被测量，而半径的平方对着层的结晶年龄（锆石上的 U–Pb）点出。这些点定义一条过原点、斜率 $3.1\times10^{-11}\ \mathrm{m^2\,yr^{-1}}$ 的直线。解释这个斜率，而估计 $D$。
::: solution
$k$ 为一量级的 $R^2 = kDt$ 恰恰预报一条在 $R^2$ 对 $t$ 中过原点的直线，所以数据支持扩散控制的生长。斜率给出 $kD = 3.1\times10^{-11}\ \mathrm{m^2\,yr^{-1}} = 9.8\times10^{-19}\ \mathrm{m^2\,s^{-1}}$。

取 $k \approx 1$ 给出 $D \approx 1\times10^{-18}\ \mathrm{m^2\,s^{-1}}$，即 [[#prop-grainsize]] 中用的值——而那个一致是难题，不是收获。网络阳离子在岩浆温度的一个硅酸盐熔体中的扩散是 $10^{-9}$–$10^{-12}\ \mathrm{m^2\,s^{-1}}$，快一千到一百万倍，所以一个堆积岩中的晶体生长*不*受通过液体的输运限制：它受生长面上的界面反应限制，或受通过已生长的晶体的边界层的扩散限制，或者晶体在粗化（奥斯特瓦尔德熟化）而不是自由地生长。可迁移的教训是那个*指数*是稳健的信息——$R^2 \propto t$ 诊断一个扩散或界面控制的机制，无论那个常数是什么——而一个从结构测得的表观扩散系数是关于链中最慢的一步的陈述，不是关于熔体的。

::: exercise 一个岩基的热收支 {level=3 check="11"}
一个体积 $5000\ \mathrm{km^3}$ 的岩体结晶而冷却，从 $1200$ 到 $300\ ^\circ\mathrm{C}$。取 $\rho = 2600\ \mathrm{kg\,m^{-3}}$、$c_P = 1000\ \mathrm{J\,kg^{-1}\,K^{-1}}$、潜热 $4\times10^{5}\ \mathrm{J\,kg^{-1}}$。求释放的总热，以焦耳、以及以今天世界一次能源年消耗（$6\times10^{20}\ \mathrm{J}$）的单位。如果热在 $10^6$ 年中均匀地释放，它会在一个 $50{,}000\ \mathrm{km^2}$ 的区域上产生怎样的平均表面热流异常？（以 $\mathrm{mW\,m^{-2}}$ 输入异常。）
::: solution
质量 $= 2600\times5\times10^{12} = 1.3\times10^{16}\ \mathrm{kg}$。热 $= M(c_P\Delta T + L) = 1.3\times10^{16}\times(9\times10^{5} + 4\times10^{5}) = 1.7\times10^{22}\ \mathrm{J}$，这是世界一次能源年消耗的 $28$ 倍——一个关于地质的能量通量的尺度的有用的提醒。

在 $10^6\ \mathrm{yr} = 3.15\times10^{13}\ \mathrm{s}$ 上，平均的功率是 $5.4\times10^{8}\ \mathrm{W}$，铺在 $5\times10^{10}\ \mathrm{m^2}$ 上：
$$
q = \frac{5.4\times10^{8}}{5\times10^{10}} = 0.011\ \mathrm{W\,m^{-2}} = 11\ \mathrm{mW\,m^{-2}} 。
$$
对着 $60$–$70\ \mathrm{mW\,m^{-2}}$ 的背景热流，这是一个 $15$–$20\%$ 的异常，可以探测但不大——而它比真实情况小，有两个理由：热是在最初几十万年中释放的，不是均匀的，而其中许多被热液的流体带走、而不是被传导，这正是为什么一个岩基的矿床在它的变质晕中被找到（[[earth-resources/magmatic-hydrothermal]]）。
