地壳中以可测量的量出现九十一种元素。已知的矿物约六千种。而你将来捡起的几乎每一块岩石——路缘石里的花岗岩、海崖里的玄武岩、河谷里的砂岩——都由同样那二十来种构成。元素周期表与手标本之间这小小的重叠并非巧合：它是化学（哪些离子彼此相配）、宇宙化学（太阳系凝聚时哪些原子丰富）与热力学（在潮湿、氧化、不太冷的行星表面哪些结构能幸存）共同作用的结果。

学会那二十种矿物是地质学的第一项实践技能，正如识字先要学字母。本课程后面的每一章——岩浆如何结晶、沉积物如何分选、岩石被埋藏时长出什么矿物、为什么一道崖塌而另一道不塌——都是关于矿物的陈述。而你用来识别它们的每一条性质，尤其是硬度与解理，都是原子结构的直接读出，这就是本章从键合讲起、而不是从一张清单讲起的原因。

## 什么算作矿物

::: definition 矿物、晶体与准矿物 {#def-mineral}
**矿物**是一种天然产生的、化学组成相当确定的、由自然过程形成的物质，它的原子排列成有秩序的、重复的图案：它是**结晶的**。**晶体**是生长得足够自由、以致能显示外部平面晶面的矿物（或其他结晶固体）。**准矿物**是一种未能满足结晶性要求的天然物质——火山玻璃、蛋白石（它含水而只有近程有序），以及喷气孔最初几天沉淀出的自然硫。
:::

这个定义看起来像公文，因为它是国际矿物学协会公布的成果，2012 年修订过、此后又改过，而它的存在是为了裁决真实的争论。有三个推论值得直说，因为每一个都是一个常见的误解：

- **冰是矿物**，在它已知的十四种结晶形态中都是，包括只在上地幔深处稳定的那些。你在冰箱里制的水冰也是矿物，只要你接受定义中的"天然的"意思是"不是实验室反应有意制造的"，而不是"从未被人碰过"。
- **汞是矿物**，所以矿物必然是固体的想法是错的；判据是原子的有序，不是室温下的聚集状态。
- **煤不是矿物**，因为它是有机化合物的混合物，而不是一种具有确定组成与晶格的物质。花岗岩也不是，任何岩石都不是：岩石是矿物的集合体。

::: warning "它有六个平的晶面，所以它是一个晶体"
两件不同的东西都被叫作晶体。一个有**解理**的矿物颗粒有平的面，那是它沿着键合弱的面破裂时形成的，而那些面由结构控制——方解石的菱面、云母的片、石盐的立方体。严格意义的**晶体**有生长出来的晶面，而它的形状既记录生长的环境、也记录结构：晶洞中的一颗石英是一个带锥面的六方柱，而同样这个石英作为砂岩中的一颗砂粒则完全没有晶面，却有完全同样的解理与同样的晶格。晶面告诉你生长；解理告诉你结构。在你用其中任何一个做鉴定之前，先学会看出你面对的是哪一个。
:::

## 为什么结构由化学决定

几乎所有的造岩矿物都由离子键与共价键的混合维系，而在构成地壳主体的氧化物与硅酸盐中，离子成分占主导。最有用的一个定量观念是**配位数**：多少个氧阴离子围绕着给定的阳离子。

::: definition 离子半径与配位数 {#def-coordination}
离子被当作硬球处理，其半径依赖配位数与电荷状态。本图集通篇采用的数值是香农的有效离子半径，其中六配位的氧有 $r_\text{O} = 1.38\ \text{Å}$、四配位的硅 $r_\text{Si} = 0.26\ \text{Å}$、六配位的镁 $r_\text{Mg} = 0.72\ \text{Å}$、依此类推。**配位数**（CN）是阳离子周围的最近邻阴离子的数目；硅酸盐中常见的值是 CN 4（一个四面体）与 CN 6（一个八面体）。
:::

::: proposition 半径比规则 {#prop-radiusratio}
一个半径 $r_\text{c}$ 的阳离子稳定地坐在 $n$ 个半径 $r_\text{a}$ 的阴离子构成的空穴中，只有当阴离子既接触到阳离子、而彼此又不接触得太紧。由阴离子同时接触阳离子与彼此得到的极限比是

| 配位 | 几何 | $r_\text{c}/r_\text{a}$ 大于 |
|---|---|---|
| 3 | 三角形 | $0.155$ |
| 4 | 四面体 | $0.225$ |
| 6 | 八面体 | $0.414$ |
| 8 | 立方体 | $0.732$ |

:::

::: proof
在每个空穴最紧的截面上讨论，而让阴离子互相接触。

*八面体（CN 6）。* 取围绕阳离子的四个阴离子构成的正方形、边长 $2r_\text{a}$。阳离子恰好容纳时对角线等于 $2r_\text{a} + 2r_\text{c}$：
$$
2r_\text{a} + 2r_\text{c} = 2\sqrt{2}\,r_\text{a} \Longrightarrow \frac{r_\text{c}}{r_\text{a}} = \sqrt{2} - 1 = 0.414 。
$$
较小的阳离子在空穴里晃荡、没有东西把阴离子撑开、于是结构转而倾向于较低的配位。

*四面体（CN 4）。* 在一个正四面体中、阳离子到阴离子的距离是阴离子–阴离子棱的 $\sqrt{3/8}$ 倍、所以在阴离子接触时、$2r_\text{a} + 2r_\text{c} = 2\sqrt{3/8}\times 2r_\text{a}\times\sqrt{2}/\sqrt{2}$、它约化为
$$
\frac{r_\text{c}}{r_\text{a}} = \sqrt{\tfrac{3}{2}} - 1 = 0.225 。
$$

*立方体（CN 8）。* 阴离子坐在一个边长 $2r_\text{a}$ 的立方体的角上、而阳离子在中心；体对角线是 $2\sqrt{3}\,r_\text{a} = 2r_\text{a} + 2r_\text{c}$、给出 $r_\text{c}/r_\text{a} = \sqrt{3} - 1 = 0.732$。∎
:::

::: example 哪个阳离子用哪个配位？ {#ex-ratios}
使用 $r_\text{O} = 1.38\ \text{Å}$、判定 $\mathrm{Si^{4+}}$（$0.40\ \text{Å}$）、$\mathrm{Mg^{2+}}$（$0.72\ \text{Å}$）、$\mathrm{Fe^{2+}}$（$0.78\ \text{Å}$）、$\mathrm{Ca^{2+}}$（$1.00\ \text{Å}$）与 $\mathrm{K^{+}}$（$1.38\ \text{Å}$）可能的配位。
::: solution
把每个半径除以 $1.38\ \text{Å}$：

| 阳离子 | $r_\text{c}/r_\text{a}$ | 预报的配位 |
|---|---|---|
| $\mathrm{Si^{4+}}$ | $0.29$ | 4、四面体 |
| $\mathrm{Mg^{2+}}$ | $0.52$ | 6、八面体 |
| $\mathrm{Fe^{2+}}$ | $0.57$ | 6、八面体 |
| $\mathrm{Ca^{2+}}$ | $0.72$ | 6、只差一点就到 8 配位的阈值 |
| $\mathrm{K^{+}}$ | $1.00$ | 8 或更高 |

这一行算术就解释了硅酸盐矿物的整个架构。硅*总是*与氧成四配位，所以地壳的基本构件是 $\mathrm{SiO_4}$ 四面体；镁与铁进入它们之间的八面体位；钙坐在边界上，因此两种角色都能担任；而钾对这两种空穴都太大，需要架状构造里宽敞的位置——那正是它富集在少数结构开放的矿物（云母、钾长石、蒸发岩盐类）中的原因。铝在六配位时是 $0.535\ \text{Å}$、给出 $0.39$：正落在四面体与八面体的边界上。这种两可性就是为什么铝既能替代硅、也能替代镁，以及为什么它是岩石化学中最重要的次要元素。
:::
:::

### 替代与固溶体

纯端元矿物反而是例外。当阳离子的半径相差约 $15\%$ 以内、而它们的电荷能够平衡时，它们彼此替代，结果是一个**固溶体**——组成连续而结构相同的一系列矿物。

以下两种情形在本课程中处处都会遇到：

- **简单的（等价）替代。** $\mathrm{Mg^{2+}}$ 与 $\mathrm{Fe^{2+}}$ 的半径差 $8\%$、而共享一个电荷，所以橄榄石从 $\mathrm{Mg_2SiO_4}$（镁橄榄石）到 $\mathrm{Fe_2SiO_4}$（铁橄榄石）连续变化。$\mathrm{Fe^{2+}}$–$\mathrm{Mn^{2+}}$ 也是；而 $\mathrm{Na^{+}}$–$\mathrm{K^{+}}$ 只部分地如此，因为它们的半径差 $35\%$。
- **耦合的（电荷平衡的）替代。** 在斜长石中，$\mathrm{Ca^{2+}}$ 与 $\mathrm{Na^{+}}$ 占据同一个大的位置，而一个电荷之差必须有人付账。账付了：每一个进入的 $\mathrm{Na^{+}}$ 迫使一个 $\mathrm{Al^{3+}}$ 上到一个 $\mathrm{Si^{4+}}$ 的位置，所以替代是*耦合的对* $\mathrm{Ca^{3+}Si^{4+}} \rightleftharpoons \mathrm{Na^{+}Al^{3+}}$。这就是为什么占地球地壳 50–60\% 的长石是铝硅酸盐。

::: example 从一份化学分析到矿物的化学式 {#ex-formula}
一个橄榄石晶体的分析给出（wt \%、略去次要组分后总计到 98.9\%）：$\mathrm{SiO_2}\ 39.90$、$\mathrm{MgO}\ 51.30$、$\mathrm{FeO}\ 7.30$。计算它的化学式与其镁橄榄石含量 $F_{\#} = \mathrm{Mg}/(\mathrm{Mg}+\mathrm{Fe})$。
::: solution
把每个氧化物除以它的摩尔质量、得到每 $100\ \mathrm{g}$ 中的摩尔数：
$$
\mathrm{SiO_2}: \frac{39.90}{60.08} = 0.664, \qquad
\mathrm{MgO}: \frac{51.30}{40.30} = 1.273, \qquad
\mathrm{FeO}: \frac{7.30}{71.84} = 0.102 。
$$
橄榄石每个化学式单位含四个氧、而每个 $\mathrm{SiO_2}$ 贡献其中两个、所以整体乘以 $2$、使硅为每两个氧 $1.33$；或按硅 $= 1$ 归一化：
$$
\big(\mathrm{Mg}_{1.92}\ \mathrm{Fe}_{0.15}\big)\ \mathrm{SiO}_{4}, \qquad F_{\#} = \frac{1.273}{1.273 + 0.102} = 0.93 。
$$
所以这是镁橄榄石质的橄榄石、$\mathrm{Fo}_{93}$、这正是地球上地幔本身的组成。注意 $F_{\#}$ 从*阳离子的摩尔数*计算、绝不用重量百分比：$\mathrm{MgO}$ 按重量只占 $51\%$、而镁占那个位置上阳离子的 $93\%$、因为镁很轻。弄错这一步是整个课程岩石学中最常见的算术错误。
:::
:::

## 你真正能量测的性质

下面的一切都出自键合与结构，而每一个情形中，*道理*都比经验法则可靠。

**硬度**是对划伤的抵抗、由摩氏的十矿物标度排列（1 滑石 …… 10 金刚石）。这个标度只是序数、而且极非线性：刚玉（9）的维氏硬度约是黄玉（8）的四倍、而金刚石（10）约是刚玉的四倍。硬度随键长增加而下降、随电荷上升、这就是为什么石英的小而高电荷的 $\mathrm{Si^{4+}}$–O 键与金刚石的共价网络是硬的、而层状或分子的固体——石墨、云母、滑石、石盐——是软的。

**解理**是沿着键合相对弱的结晶学的面破裂的倾向。用它的*方向的数目*与它们的*角度*描述它：云母、一个方向、完全；角闪石、两个在 $56^\circ$/$124^\circ$；辉石、两个接近 $90^\circ$；石盐、三个在 $90^\circ$；方解石、三个在 $78^\circ$（菱面）；萤石、四个（八面体）；石英、*没有*、所以它以弯曲的（贝壳状的）的破裂。

**条痕**——粉末状的矿物的颜色、在无釉的瓷板上擦——胜过手标本的颜色、因为粉末消除了粒度与微量杂质的影响。赤铁矿在手标本中是灰的、红的或黑的、而条痕永远是樱桃红的、而那一个试验把它与磁铁矿分开、后者两者都是黑的。

**密度**（比重、在 $\mathrm{g\,cm^{-3}}$ 中与密度数值相等）由原子量与堆积控制。大多数造岩硅酸盐落在 2.6 与 3.4 之间；碳酸盐从 2.7（方解石）到 4.0（菱锌矿）；氧化物与硫化物是 4 到 5.5、而在手里感觉重。学会在掌中掂一个手标本、与记住的标度对照，是一项真本事。

::: definition 用阿基米德测比重 {#def-sg}
在空气中（$m_\text{air}$）与悬浮在水中（$m_\text{water}$）称标本。重量的损失等于排开的水的重量、所以
$$
\mathrm{SG} = \frac{m_\text{air}}{m_\text{air} - m_\text{water}} 。
$$
:::

::: example 一颗重的红色颗粒 {#ex-sg}
一颗透明的红色颗粒有 $m_\text{air} = 6.40\ \mathrm{mg}$ 而 $m_\text{water} = 4.80\ \mathrm{mg}$。求它的比重、而说出它可能是什么。
::: solution
$$
\mathrm{SG} = \frac{6.40}{6.40 - 4.80} = \frac{6.40}{1.60} = 4.00 。
$$
一颗红色、玻璃光泽、无解理而 $\mathrm{SG} \approx 4$ 的矿物是石榴石——最可能是铁铝石榴石、变质的片岩与重砂的–铝的硅酸盐。外观相似的矿物由数字排除：尖晶石也是 3.6–4.1、但是立方的、带贝壳状的、而很少以这种方式是红的；铁铝石榴石 7–7.5 的硬度排除了软得多的红色的矿物辰砂（2–2.5）与雄黄（1.5–2）、而两者都还要重得多。
:::
:::

::: algorithm 鉴定一个未知的手标本 {#algo-id}
1. 看一个新鲜的面。注意颜色、光泽（金属状、玻璃状、珍珠状、土状）、以及表面是结晶的、粒状的、玻璃质的还是纤维的。
2. 它是金属矿物吗？若是，就在那一小组金属矿物里逐一排查：赤铁矿（红的条痕）、磁铁矿（磁的、黑的条痕）、黄铁矿（硬的、脆的、绿黑的条痕）、黄铜矿（软的、铜黄的、绿的）、方铅矿（完全的立方的解理、非常重）。
3. 如果不是金属的、用刻划试验它。比携带的钢的（$\approx 5.5$）更硬：石英、长石、石榴石、绿柱石、磷灰石（勉强）。更软：方解石、萤石、石膏、云母、滑石。
4. 找解理、而数方向的数目与角度。对硅酸盐、这是单个的信息量最大的观察。
5. 做几条廉价的诊断试验：在新鲜的面上的冷的稀的盐酸（起泡 = 方解石；只有粉末 = 白云石）、一个磁铁、一条的板、以及为密度而掂量。
6. 把答案与上表中的性质*作为一组*来核对。单个的性质从不鉴定一个矿物；四五个性质的交集才能。
:::

- [ ] 角闪石
- [x] 普通辉石（一种单斜辉石）
- [ ] 白云母
- [ ] 方解石
::: solution
硬度大于玻璃，排除了方解石（3）与白云母（2–2.5）。两条大致 $90^\circ$ 的解理，加上暗绿至黑色与 $3.2$–$3.6\ \mathrm{g\,cm^{-3}}$、是单斜辉石的经典描述。角闪石是陷阱：它的两个解理在 $56^\circ$ 与 $124^\circ$ 相交、而它稍微更轻、手标本上通常绿色更明显。在无法量出解理角的细粒玄武岩中、用放大镜就无法可靠地区分二者、那是诚实的答案，而不是失误。
:::

## 为什么是这些元素、而这些族

::: proposition 地壳是一个硅酸盐–氧化物的世界有三个理由 {#prop-why-silicates}
(1) *丰度。* 氧与硅是在整个地球中第一与第八最丰富的元素、因为它们由恒星的核合成大量产生、而容易地从太阳的星云凝聚。(2) *分异。* 铁与镍、其他丰富的难熔的元素、早期从硅质地球中被移入核、留下地幔与地壳由 $\mathrm{O}$、$\mathrm{Si}$、$\mathrm{Al}$、$\mathrm{Fe^{3+/2+}}$、$\mathrm{Mg}$、$\mathrm{Ca}$、$\mathrm{Na}$、$\mathrm{K}$ 主导。(3) *聚合。* 四配位的 $\mathrm{Si^{4+}}$ 把 $\mathrm{SiO_4}$ 四面体连成链、片与架、所以少数几种结构就能容纳几乎所有别的阳离子。
:::

::: proof
前两个陈述是测量、不是论证：太阳光球的与 CI 球粒陨石的丰度给出 O 与 Si 在 H 与 He 之后的前四位元素之中、而硅质地球失去的铁在核中找到（质量平衡的论证见 [[earth-system/planet-earth]]）。第三个是结构的。因为 $\mathrm{Si^{4+}}$ 小而高电荷、$\mathrm{Si–O}$ 键约 $50\%$ 是共价的、而每个氧留下一个不满足的键。那个氧能键到第二个硅、形成一个桥的氧、而过程重复：孤立的四面体（橄榄石）、对（绿帘石）、环（绿柱石）、单链（辉石）、双链（角闪石）、片（云母、黏土）以及完全聚合的三维骨架（石英、长石）。聚合阶梯上每上一级用氧更省、所以氧对硅的比从橄榄石的 4 下降到石英的 2、剩余的电荷则由熔体或流体中随手可得的任何阳离子来平衡。
:::

矿物的化学的分类跟着阴离子或阴离子的、而顺序也是一个环境的顺序：

- **自然元素** —— 金、铜、金刚石、石墨、硫：还原的或不溶的种。
- **硫化物** —— 黄铁矿 $\mathrm{FeS_2}$、黄铜矿 $\mathrm{CuFeS_2}$、方铅矿 $\mathrm{PbS}$、闪锌矿 $\mathrm{ZnS}$：在低氧的熔体与热液中形成；是大多数金属的矿石。
- **氧化物与氢氧化物** —— 赤铁矿、磁铁矿、刚玉 $\mathrm{Al_2O_3}$、针铁矿 $\mathrm{FeOOH}$：在氧化的、湿的表面稳定；条带状铁建造与红土。
- **的物** —— 石盐、钾盐 $\mathrm{KCl}$、萤石 $\mathrm{CaF_2}$：高度可溶、所以限于蒸发岩。
- **碳酸盐** —— 方解石、白云石、菱铁矿 $\mathrm{FeCO_3}$：海洋的与湖泊的沉淀、而石油工业的储层岩石。
- **的盐** —— 石膏、硬石膏 $\mathrm{CaSO_4}$、重晶石 $\mathrm{BaSO_4}$：蒸发岩、而硫化物矿坑的氧化产物。
- **的盐** —— 磷灰石 $\mathrm{Ca_5(PO_4)_3(F,OH)}$：骨头、牙齿、以及磷的唯一经济来源。
- **硅酸盐** —— 其余一切、按体积约占地壳的 $90\%$。

::: example 凭矿物读一块岩石 {#ex-modal}
一个暗的、中粒的岩石按体积含 50\% 斜长石、40\% 普通辉石与 10\% 橄榄石、既无石英、也无似长石。第二个岩石是 90\% 橄榄石与 10\% 普通辉石。说出矿物的暗示：哪一块是镁铁质堆积岩、哪一块是玄武岩、而石英的缺失告诉你什么？
::: solution
第一个岩石是一个辉长岩（或、带着橄榄石存在、一个橄榄石的辉长岩）：斜长石加普通辉石是缓慢冷却的基性岩浆的特征组合。第二个、在 90\% 橄榄石、是一个橄榄岩——而因为橄榄岩不在表面的一个液体中结晶、这是堆积成因，或者——更常见得多——是由金伯利岩带上或构造就位的地幔碎块。

石英的缺失是有信息的部分。在一个硅*不饱和*的岩浆中、可用的硅全被镁铁矿物与长石耗尽、所以没有自由的 $\mathrm{SiO_2}$ 能结晶；如果存在似长石（霞石、白榴石）、它们会确认它。一个带着过量的硅的岩浆相反地结晶石英、而在火山岩中它会以玻璃或斑晶的形式可见。因此一种缺失的矿物就记录了在数千米外就位的那次熔体的整体成分；而在第二种情况，它记录的是从数十千米深处取来的样品。
:::

## 矿物记录其形成条件

::: theorem 吉布斯相律 {#thm-phaserule}
对一个在平衡的、带着 $C$ 个独立的组分与 $P$ 个相的系统、自由度的数目——你在不使某一相消失的前提下能够独立改变的变量——是
$$
F = C - P + 2 。
$$
:::

::: proof
平衡要求每个组分的化学势在每一个相中相等：$(P-1)C$ 个方程、因为因为对 $C$ 个组分中的每一个，势必须在 $P-1$ 个相界上逐一匹配。要确定状态，须给出 $T$、$P$（2 个变量）与每个相的成分、每相 $C-1$ 个摩尔分数、或总共 $P(C-1)$。减去约束数、
$$
F = \big[P(C-1) + 2\big] - (P-1)C = PC - P + 2 - PC + C = C - P + 2 。 \qquad \text{\(\blacksquare\)}
$$
:::

这条律正是变质岩能充当温度计的原因。在一组分体系 $\mathrm{Al_2SiO_5}$（$C = 1$）中、一个相能在压力–温度图上的二维区域中存在（$F = 2$）；两相只沿一条线共存（$F = 1$）；而三相只在一个点（$F = 0$）。红柱石、蓝晶石与硅线石就是那个系统、而它们在约 $0.4\ \mathrm{GPa}$ 与 $500\ ^\circ\mathrm{C}$ 附近的观测的点意味着在片岩中找到蓝晶石就把岩石钉在高压区、而红柱石叠覆蓝晶石则记录减压。

::: example 金刚石什么时候成为碳的稳定的？ {#ex-diamond}
在 $298\ \mathrm{K}$ 与 $10^5\ \mathrm{Pa}$、金刚石相对石墨的 $\Delta_\mathrm{f} G^\circ$ 是 $+2.90\ \mathrm{kJ\,mol^{-1}}$、而摩尔体积为 $V_\text{graphite} = 5.316$ 而 $V_\text{diamond} = 3.417\ \mathrm{cm^3\,mol^{-1}}$。求金刚石在 $298\ \mathrm{K}$ 变稳定的压力、而用 $S^\circ_\text{graphite} = 5.74$ 而 $S^\circ_\text{diamond} = 2.38\ \mathrm{J\,mol^{-1}\,K^{-1}}$、求在 $1200\ ^\circ\mathrm{C}$。
::: solution
在平衡时 $\Delta G^\circ(T) + (V_\text{diamond} - V_\text{graphite})(P - P^\circ) = 0$、所以
$$
P = P^\circ + \frac{\Delta G^\circ(T)}{V_\text{graphite} - V_\text{diamond}} 。
$$
在 $298\ \mathrm{K}$：$P = 10^{5} + 2900/(1.899\times 10^{-6}) = 1.53\ \mathrm{GPa}$——在 $2700\ \mathrm{kg\,m^{-3}}$ 的岩石中约合 $58\ \mathrm{km}$ 深的岩石静压。金刚石在表面是*亚稳定的*：它本欲变成石墨、只是慢得几乎察觉不到。

在 $1473\ \mathrm{K}$、取 $\Delta H^\circ \approx \Delta G^\circ + T\Delta S^\circ = 2900 + 298\times(-3.36) = 1898\ \mathrm{J\,mol^{-1}}$、所以 $\Delta G^\circ(1473) = 1898 + 1473\times 3.36 = 6852\ \mathrm{J\,mol^{-1}}$、而
$$
P = \frac{6852}{1.899\times 10^{-6}} = 3.6\ \mathrm{GPa} 。
$$
这条界线有一个正而缓的斜率、$\mathrm{d}P/\mathrm{d}T = -\Delta S/\Delta V \approx +1.8\ \mathrm{MPa\,K^{-1}}$：加热使金刚石*更不*稳定、因为石墨有更高的熵。天然宝石级金刚石来自 $4.5$–$6\ \mathrm{GPa}$、也就是克拉通根 $150$–$200\ \mathrm{km}$ 的深度、并在数小时内喷发的金伯利岩岩浆中送到地表——正是这次急冷让你能把手伸向深地幔（[[physical-geology/volcanoes]]、[[geochemistry/elements-earth]]）。
:::
:::

::: warning "在表面稳定的岩石与矿物就是稳定的那些"
相反的更接近真实。几乎每一个火成岩中的矿物在表面都是亚稳定的：橄榄石几百年就风化成黏土、辉石与钙斜长石几千年、而石英——最不活泼的常见矿物——却能幸存、被循环过十几期砂岩。地表不稳定性的次序几乎就是自熔体结晶的次序（鲍文的规则、[[physical-geology/igneous-rocks]]）、那是为什么海滩砂几乎全是石英、而它的源岩却有三分之一是长石。
:::

::: history
矿物学比地质学更老。格奥尔格乌斯·阿格里科的《论冶金》（1556）按外表性质、并按矿石在炉中的行为给矿物分类。决定性的一步是阿贝·勒内·雅斯特·阿维 1784 年的观察：一块破碎的方解石颗粒永远是角度相同的菱面体；他由此推断矿物由相同的"积分分子"堆叠成晶格——这就是晶体的原子理论，比道尔顿的原子早五年，比 X 射线直接证明这个想法早一个世纪（马克斯·冯·劳厄的衍射在 1912，布拉格父子对 NaCl 的分析在 1913，给出了第一种矿物的结构）。在阿维与布拉格之间，这门学科几乎全是测量：维尔纳的命名法（1789）、阿维的晶系、莫氏硬度标度（1812），以及到 1890 年已列出 230 个可能空间群的晶体学——一个纯数学的结果，最后却把有史以来存在过的每一种矿物都数了进去。莱纳斯·鲍林 1929 年的三条结构规则（其中 [[#prop-radiusratio]] 是第一条）第一次使矿物化学具有可预测性；成立于 1958 年的国际矿物学协会从此是裁定什么算新矿物的机构：如今已批准约 5 800 种，而其中不到四十种构成了你脚下的岩石。
:::

## 通向何处

矿物是随后四章的字母表：[[physical-geology/igneous-rocks]] 利用硅酸盐的熔融与结晶行为、[[physical-geology/sedimentary-rocks]] 利用它们在地表的不稳定性、而 [[physical-geology/metamorphic-rocks]] 认真利用 [[#thm-phaserule]] 的相律。同样的结构在 [[mineralogy-petrology/crystallography]] 带着对称性的形式体系再次出现、在 [[mineralogy-petrology/optical-mineralogy]] 在那里用偏振光而非钢刀片来测定它们、而在 [[geochemistry/trace-elements]] 离子半径变成定量的分配系数。

::: summary 关键要点
- 一个矿物是一个天然的、结晶的、组成相当确定的物质；冰与汞合格、煤与玻璃不合格、而没有一个岩石是矿物。
- 配位数从半径比跟随、而阈值 $0.225$、$0.414$ 与 $0.732$ 解释了为什么硅总是四面体的、镁与铁是八面体的、而钾只在大的位置。
- 替代由半径（约 $15\%$ 以内）与电荷控制；电荷的差由耦合的替代付出、那是为什么长石是铝硅酸盐。
- 以阳离子的摩尔数、而绝不用重量百分比计算组成：由一份橄榄石分析计算 $F_{\#} = \mathrm{Mg}/(\mathrm{Mg}+\mathrm{Fe})$ 是标准的练习。
- 以*一组性质*鉴定——硬度、解理（方向数与夹角）、条痕、比重、一条诊断试验——绝不仅凭颜色。
- 硅酸盐诸族是一条聚合的阶梯、从孤立的四面体到骨架、每一级都表现为一种解理与一种风化速率。
- 吉布斯相律、$F = C - P + 2$、正是它使矿物组合能被读作压力与温度的记录。
- 几乎每一个常见的矿物在表面是亚稳定的；正是这种亚稳定性使沉积物、土壤与地貌成为可能。
:::

## 练习

::: exercise 由半径定配位 {level=1 check="6"}
使用 $r_\text{O} = 1.38\ \text{Å}$ 而 $r_\text{Ti} = 0.605\ \text{Å}$、预报 $\mathrm{Ti^{4+}}$ 被氧的配位数。
::: solution
$0.605/1.38 = 0.438$、刚好在八面体的阈值 $0.414$ 之上、所以 CN 6。在金红石 $\mathrm{TiO_2}$ 中的钛确实是六配位的——而余量之小解释了为什么 $\mathrm{Ti^{4+}}$ 在某些硅酸盐中也能被挤进四配位。
:::
:::

::: exercise 由晶胞算密度 {level=1 check="2.16"}
石盐是立方的、$a = 5.6402\ \text{Å}$、而每个晶胞含四个 $\mathrm{NaCl}$ 化学式单位。计算它的密度（$M = 58.44\ \mathrm{g\,mol^{-1}}$）。
::: solution
$$
\rho = \frac{Z M}{N_\text{A} V} = \frac{4 \times 58.44}{6.022\times 10^{23} \times (5.6402\times 10^{-8})^3} = \frac{233.8}{108.0} = 2.16\ \mathrm{g\,cm^{-3}} 。
$$
实测值是 $2.17$。作为对离子模型的一个检验、最近的 $\mathrm{Na–Cl}$ 间距是 $a/2 = 2.82\ \text{Å}$、与离子半径之和相比 $1.02 + 1.81 = 2.83\ \text{Å}$：硬球图像准确到百分之一。
:::
:::

::: exercise 橄榄石的组成 {level=1 check="0.79"}
一个橄榄石含 $\mathrm{SiO_2}\ 38.60$、$\mathrm{MgO}\ 42.10$、$\mathrm{FeO}\ 18.60$ wt \%。求 $F_{\#}$。
::: solution
每 $100\ \mathrm{g}$ 的摩尔数：$\mathrm{SiO_2}\ 0.642$、$\mathrm{MgO}\ 1.045$、$\mathrm{FeO}\ 0.259$。然后 $F_{\#} = 1.045/(1.045 + 0.259) = 0.80$、即 $\mathrm{Fo}_{80}$。注意铁按重量只有 19\%、而占该位置阳离子的 20\%——两个数字之所以不同、是因为 $\mathrm{FeO}$ 重 71.8、而 $\mathrm{MgO}$ 只有 40.3。
:::
:::

::: exercise 重矿物的密度 {level=2 check="4.27"}
一个矿物从密度 $4.15\ \mathrm{g\,cm^{-3}}$ 的重液通过上浮分离、而从 $4.35\ \mathrm{g\,cm^{-3}}$ 的通过下沉。另做一次阿基米德测定，给出 $m_\text{air} = 8.20\ \mathrm{mg}$、$m_\text{water} = 6.28\ \mathrm{mg}$。求密度、并判断重液的结果是否相容。
::: solution
$\mathrm{SG} = 8.20/(8.20 - 6.28) = 8.20/1.92 = 4.27$。这落在 4.15 与 4.35 之间、所以两个方法一致。矿物在石榴石–十字石–绿帘石的范围、它主导重砂精矿；而密度分离法的全部意义就在于：在测量别的任何东西之前，它恰好按这一性质把颗粒分拣开。
:::
:::

::: exercise 四面体阈值的推导 {level=2}
对一个坐在四个互相接触的阴离子构成的四面体空隙中的阳离子，推导 $r_\text{c}/r_\text{a} = \sqrt{3/2} - 1 = 0.225$。
::: solution
把阳离子置于棱长 $a = 2r_\text{a}$ 的正四面体的中心。正四面体的中心至顶点的距离是 $R = a\sqrt{3/8}$，所以阳离子恰好接触阴离子时 $R = r_\text{a} + r_\text{c}$：
$$
r_\text{a} + r_\text{c} = 2r_\text{a}\sqrt{\tfrac{3}{8}} = r_\text{a}\sqrt{\tfrac{3}{2}} \Longrightarrow \frac{r_\text{c}}{r_\text{a}} = \sqrt{1.5} - 1 = 0.225 。
$$
对别的配位用同样构造给出 $\sqrt{2}-1$（八面体）与 $\sqrt{3}-1$（立方体）；规律是：阴离子越多，空穴越宽敞，这就是为什么较大的阳离子要求较高的配位数，也是为什么在固定成分下矿物密度随压力升高。
:::

::: exercise 水的相律 {level=2}
（a）液态水、（b）液态水与水汽、（c）冰、液态水与水汽一起，各有多少个自由度？（c）对水的三相点意味着什么，而 $\mathrm{Al_2SiO_5}$ 的对应物是什么？
::: solution
三种情况都是 $C = 1$，所以 $F = 3 - P$。（a）$P = 1$、$F = 2$：$T$ 与 $P$ 都可以变。（b）$P = 2$、$F = 1$：沸腾温度仅是压力的函数，这就是为什么高压锅管用，也是为什么水在一座高山上在 $85\ ^\circ\mathrm{C}$ 沸腾。（c）$P = 3$、$F = 0$：一个点，$0.01\ ^\circ\mathrm{C}$ 与 $611\ \mathrm{Pa}$，毫无自由度可言。

对 $\mathrm{Al_2SiO_5}$，对应物是红柱石–蓝晶石–硅线石的三相点，在约 $0.4\ \mathrm{GPa}$ 与 $500\ ^\circ\mathrm{C}$：铝硅酸盐的三种多晶型物只能在那里共存，所以一块三种都在其中被找到的岩石，要么就形成于那一个点，要么——更常见得多——是多个世代矿物的混合，记录了一条越过界线演化之路。
:::
:::

::: exercise 为什么金刚石在表面是亚稳定的？ {level=2 check="58"}
使用 [[#ex-diamond]] 的数据，把 $298\ \mathrm{K}$ 的平衡压力换算成密度 $2700\ \mathrm{kg\,m^{-3}}$ 的岩石中的一个深度，而解释为什么金伯利岩中的一个金刚石并不是金伯利岩从那个深度喷出的证据。
::: solution
$z = P/\rho g = 1.53\times 10^{9}/(2700 \times 9.81) = 58\ \mathrm{km}$。

这个深度只是岩石静压的当量值，而真正的论证是 [[#ex-diamond]] 中的那个：在 $1200\ ^\circ\mathrm{C}$ 界线在 $3.6\ \mathrm{GPa}$，而克拉通岩石圈地幔的地温线在 $150$–$200\ \mathrm{km}$ 跨过它。金刚石在那里结晶，只有在上升耗时数小时、而石墨–金刚石相变在低温下极其缓慢的情况下，它才能在途中幸存。亚稳定性说的是动力学，不是热力学。
:::

::: exercise 手标本鉴定钥匙 {level=3}
给你四种无色的矿物：方解石、石英、萤石与磷灰石。设计最短的试验的序列，只使用一个钢刀片（硬度 5.5）、一块玻璃板（5.5）、一个放大镜、冷的稀盐酸与一台天平，确定地把四种全部分开。说出每个试验排除了什么。
::: solution
第 1 步、在新鲜的面上的酸：起泡者即方解石，立刻排除它。第 2 步、用剩下的三种刻划玻璃：石英（7）与磷灰石（5）——磷灰石在临界处，故同时用钢刀片——而萤石（4）不能刻划玻璃。第 3 步、用萤石的完全的八面体的解理（四个方向、在碎块上以解理三角形可见）与磷灰石的贝壳状的与六方的确认；磷灰石不像方解石那样对酸起泡，但若酸温热而浓则会反应。第 4 步、以全无解理及其贝壳状断口确认石英、而检查密度：2.65（石英）、2.71（方解石）、3.18（萤石）、3.1–3.2（磷灰石）。

顺序是重要的：先酸，因为它一锤定音而只花几秒；其次硬度，因为它干净地分开剩下的三种；最后解理，因为它是小标本上最可能被误读的观察。注意颜色、光泽与味道在这里不会分开任何一对——四种都可以是无色而玻璃光泽的。
:::

::: exercise 从一个密度估计模式的比例 {level=3 check="0.93"}
一块绿色岩石测得密度 $3.35\ \mathrm{g\,cm^{-3}}$。它由橄榄石（$\mathrm{Fo}_{90}$、密度 $3.40\ \mathrm{g\,cm^{-3}}$）与斜长石（密度 $2.70\ \mathrm{g\,cm^{-3}}$）机械混合而成。估计橄榄石的体积分数，并说明你做了什么假设。
::: solution
对机械混合物，密度按体积分数加权相加、$\rho = \phi \rho_\text{ol} + (1-\phi)\rho_\text{pl}$、所以
$$
\phi = \frac{3.35 - 2.70}{3.40 - 2.70} = \frac{0.65}{0.70} = 0.93 。
$$
（以两位小数输入的比例：$0.93$；如果你相反地把问题读作问*质量*的比例、答案是 $0.96$。）假设是两个矿物都不包含另一个作为包裹体、而岩石没有的——两者通常错误。若有 $2\%$ 的孔隙，橄榄石的比例下降到 $0.93\times0.98 = 0.91$、这就是为什么基于密度的模式最多被引用到两位有效的、而为什么岩石学家在显微镜下数矿物。
:::

::: exercise 一个定量的相律问题 {level=3}
在两组分体系 $\mathrm{MgO}–\mathrm{SiO_2}$ 中，镁橄榄石 $\mathrm{Mg_2SiO_4}$ 与顽火辉石 $\mathrm{MgSiO_3}$ 与液相共存。还剩下多少个自由度？这对一块镁橄榄石加顽火辉石的岩石在固定压力下开始熔融的温度意味着什么，而如果把 $\mathrm{SiO_2}$ 作为第三组分加入，答案又如何改变？
::: solution
$C = 2$、$P = 3$（两个固体加液相），所以 $F = 2 - 3 + 2 = 1$。在固定压力下不再剩下自由度：这个组合只在一个温度开始熔融，即共熔温度，而液相的成分也是固定的。这就是为什么一块矿物组合固定的岩石有一个尖锐而可重复的固相线，也是为什么共熔的成分是被喷发得最多的成分。

加入第三个组分给出固定压力下 $F = 2$，所以熔融发生在一个温度的*范围*内，液相成分沿它连续变化。真实的地壳岩石有十种以上的组分，这就是为什么它们在上百度中熔融，也是为什么"花岗岩的熔融的温度"不是一个提得好的问题，除非说明是哪一座花岗岩、含多少水、以及你指的是熔融路径上的哪一段（[[physical-geology/igneous-rocks]]、[[mineralogy-petrology/phase-diagrams]]）（[[physical-geology/igneous-rocks]]、[[mineralogy-petrology/phase-diagrams]]）。
:::
