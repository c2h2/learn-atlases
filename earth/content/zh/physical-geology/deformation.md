在 1821 年、一个叫汉斯·康拉德·埃舍尔的教师、穿过瑞士的阿尔卑斯、注意到一个谷的一边的一个岩石的序列是另一边的镜像、而此外在错的顺序中。八十年后、大不列颠的地质调查局必须解释一幅在高地中的图、其中最老的岩石之一的古老刘易斯的片麻岩*躺在*更年轻的寒武纪的砂岩的之上。唯一的解释是一块几十千米长的大陆的地壳的板片被侧向地移动过它之下的岩石——而这个想法被拒绝了几十年作为物理上不可能的、因为每个人都知道岩石断裂、它不流动、而没有什么能把一个 $100\ \mathrm{km}$ 的岩石的板片推过一个国家。

他们对岩石能做什么错了、而纠正就是这一章的主题。给足够的时间、足够的约束、而足够的温度、岩石流动；给少一点、它按从应力的场可预测的模式断裂；而无论哪条路它保存所发生的事情的记录、在它的云母的取向、它的卵石的形状、它的褶皱的波长、而它的剪切的指向中。构造地质学是把那些记录变成一个力的历史的学科、而它是地质学最接近法医学的东西。

## 应力、应变、而为什么岩石在你不看的时候流动

::: definition 应力与应变 {#def-stress-strain}
**应力**是每单位的面积、以 MPa 测量（$1\ \mathrm{MPa} = 10\ \mathrm{bar} \approx 10\ \mathrm{kgf\,cm^{-2}}$）。它是一个张量：在一个点它由六个分量指定、或等价地由三个互相垂直的**主应力** $\sigma_1 \ge \sigma_2 \ge \sigma_3$。****岩石静压的**（约束的）应力是均值、$\sigma_\text{lith} \approx \rho g z \approx 27\ \mathrm{MPa}$ 每千米的深度、对 $\rho = 2750\ \mathrm{kg\,m^{-3}}$；**差应力**是 $\sigma_1 - \sigma_3$、而变形一个岩石的是差应力、不是总的。**应变**是形状与大小的变化、作为延伸 $e = (l - l_0)/l_0$ 测量、或、为大的变形更好地、作为自然的对数 $\ln(l/l_0)$。
:::

::: proposition 一个岩石是断裂还是流动取决于你推得多快 {#prop-brittle-ductile}
在近地表、大多数的地壳的岩石的强度由在预期的失败的面上的摩擦设定、而随深度线性上升（拜尔利定律、$\tau \approx 0.85\,\sigma_n$、对到约 $2\ \mathrm{kbar}$ 的 $\sigma_n$）。在深度、强度由热的激活的晶体的塑性设定、它随温度陡地下降、而随应变的速率上升为
$$
\dot\varepsilon = A\,\tau^{n}, \qquad n \approx 3 \text{ 对石英与橄榄石}。
$$
两个剖面交叉、而交叉的深度——脆性的–韧性的转变——如果你更快变形岩石就移动*更深*、而如果你慢地变形它就移动*更浅*、因为一个更快的速率加强韧性的机制、而留下摩擦作为两者中更弱的到更大的深度。
:::

::: proof
摩擦的强度随深度增加为 $\tau_f = \mu\rho g z$（忽略孔的压力）、一条通过原点的直线。在一个固定的应变的速率的韧性的强度是 $\tau_d = (\dot\varepsilon/A)^{1/n}$、它对一个等温的岩石是恒定的、而对一个真实的地温曲线随深度大致指数地下降、因为 $A$ 包含一个阿伦尼乌斯因子 $\exp(-Q/RT)$、而 $T$ 随 $z$ 上升。一条单调增加的线与一条单调减少的曲线交叉一次、而地壳的强度的剖面因此是一个带着在一个交叉的深度的一个峰的三角形——工程的地震学的"圣诞的树"的剖面。

现在把应变的速率改变 $10^3$ 的因子、如在一个地震与一个造山带之间。韧性的强度上升 $(10^3)^{1/3} = 10$、因为 $n = 3$、而摩擦的强度完全不变。摩擦的线然后必须爬得更远、在它削减抬高的韧性的曲线之前、所以交叉移动到更高的压力——更深。快的变形使岩石表现脆性到更大的深度；慢的变形让它流动在近地表。∎

结果是构造的地质学的单个最有用的想法：**同样的岩石是脆性的或韧性的、取决于应变的速率**。一个在 $10^{-14}\ \mathrm{s^{-1}}$（一个造山带）变形的石英岩在 $150\ ^\circ\mathrm{C}$ 流动；同样的石英岩被一个在 $10^{0}\ \mathrm{s^{-1}}$（一个地震）的断层击中就粉碎。转变的野外的证据到处是：同样的断层在浅的部分带着角砾岩与断层泥、而在下面带着糜棱岩、而边界能被后来的断层测年而偏移。
:::

::: example 地壳有多强？ {#ex-strength}
取 $\rho = 2700\ \mathrm{kg\,m^{-3}}$、拜尔利摩擦 $\mu = 0.85$ 而零孔隙压。求在 $10\ \mathrm{km}$ 的深度断裂一个岩石需要的差应力、而带着有效的流动的律的常数 $A = 2\times10^{-29}\ \mathrm{Pa^{-3}\,s^{-1}}$ 的石英岩在同样的应力流动的应变的速率。
::: solution
$$
\tau_f = 0.85\times2700\times9.81\times10^{4} = 2.3\times10^{8}\ \mathrm{Pa} = 230\ \mathrm{MPa}.
$$
带着 $\tau = 2.3\times10^{8}\ \mathrm{Pa}$ 设定 $\dot\varepsilon = A\tau^3$：
$$
\dot\varepsilon = 2\times10^{-29}\times(2.3\times10^{8})^3 = 2\times10^{-29}\times1.22\times10^{25} = 2.4\times10^{-4}\ \mathrm{s^{-1}} 。
$$
构造的应变的速率是 $10^{-15}$–$10^{-13}\ \mathrm{s^{-1}}$、小约一百亿倍。在那些速率、在 $10\ \mathrm{km}$ 的流动的应力远低于 $230\ \mathrm{MPa}$、所以岩石蠕变、而不是断裂——而地壳实际维持的应力、从地震与从钻孔的破裂测量、确实是 $10$–$100\ \mathrm{MPa}$、不是一个冷的、强的地壳暗示的几百个兆帕。这是"弱的断层"的问题在另一个形式中、而孔的压力与流体是通常的解决：带着 $\lambda = P_\text{fluid}/\sigma_\text{lith} = 0.4$、上面的摩擦的强度下降 $40\%$。
:::
:::

::: example 地壳在哪里断裂？ {#ex-bdt}
用同样的两个律：摩擦的强度 $\tau_f = 0.85(1-\lambda)\rho g z$、带着 $\rho = 2700\ \mathrm{kg\,m^{-3}}$、而一个韧性的强度 $\tau_d = 400\,e^{-z/8}\ \mathrm{MPa}$、带着以千米的 $z$。求干的岩石的脆性的–韧性的转变的深度、而带着流体的压力的因子 $\lambda = P_\text{fluid}/\sigma_\text{lith} = 0.4$ 的岩石。
::: solution
对干的岩石、$\tau_f = 22.9\,z\ \mathrm{MPa}$、而解 $22.9z = 400e^{-z/8}$ 给出
$$
z \approx 7.1\ \mathrm{km}, \qquad \tau \approx 163\ \mathrm{MPa}.
$$
带着 $\lambda = 0.4$、摩擦的线是 $13.8z$、而交叉移动到
$$
z \approx 9.3\ \mathrm{km}, \qquad \tau \approx 128\ \mathrm{MPa}.
$$
流体的压力同时做两件事：它使地壳*更弱*（峰的强度下降 $20\%$）、而它使脆性的域*更深*。两者对地震都重要。观测的大陆的地壳的地震活动通常在 $15$–$20\ \mathrm{km}$ 停止、那要求要么比这个简单模型更冷的地壳、要么一个更快的有效的应变的速率；而在西藏与盆岭之下的热的地壳中、地震在 $15$–$20\ \mathrm{km}$ 停止、而下面完全没有事件、那是主要的证据：那里的中间的地壳韧性地流动、而不是断裂。
:::
:::

## 断裂：节理与断层的几何

::: theorem 安德森的断层的理论 {#thm-anderson}
如果地球的表面是一个自由的表面（在它上没有剪切的应力）、那么一个主的应力必须是垂直的、而断层的风格由它是哪一个决定：
$$
\begin{aligned}
\sigma_1 \text{ 垂直} &\Rightarrow \text{正断层}, && \text{断层在 } \sim 30^\circ \text{ 对着 } \sigma_1,\\
\sigma_2 \text{ 垂直} &\Rightarrow \text{走滑断层}, && \text{垂直的断层},\\
\sigma_3 \text{ 垂直} &\Rightarrow \text{逆（冲）断层}, && \text{断层在 } \sim 30^\circ \text{ 对着 } \sigma_1.
\end{aligned}
$$
:::

::: proof
取一个与 $\sigma_1$ 成一个角度 $\theta$ 的预先存在的或开始的面。在它上分解应力、法向与剪切的牵引力是
$$
\sigma_n = \tfrac{1}{2}(\sigma_1+\sigma_3) + \tfrac{1}{2}(\sigma_1-\sigma_3)\cos 2\theta, \qquad
\tau = \tfrac{1}{2}(\sigma_1-\sigma_3)\sin 2\theta 。
$$
失败要求 $\tau = \tau_0 + \mu\sigma_n$（库仑的标准）。对零的黏聚力、比 $\tau/\sigma_n$ 在 $\mathrm{d}(\tau/\sigma_n)/\mathrm{d}\theta = 0$ 被最大化、那给出 $\sin 2\theta = \mu/\sqrt{1+\mu^2}$、即 $\theta = 45^\circ + \tfrac{1}{2}\arctan\mu$。带着 $\mu = 0.75$–$0.85$、这是对着 $\sigma_1$ 量的 $\theta \approx 58^\circ$–$60^\circ$、所以当 $\sigma_1$ 是垂直的、断层从 $\sigma_1$ 的方向倾斜 $30^\circ$、而从水平的 $60^\circ$。因为表面不携带剪切的牵引、$\sigma_\text{vertical}$ 必须是一个主的应力、而上面的三个选择通过把 $\sigma_1$、$\sigma_2$ 或 $\sigma_3$ 放垂直而跟随。∎
:::

节理——没有显著的剪切的延伸的断裂——是地壳中最常见的构造、而含水层、烃的储层与地热的系统能流动的整个的原因。它们形成垂直于最小的主的应力、所以一组的节理是应力的场的一个直接的读；它们常常以一个层的厚度的规则的倍数间隔、那是层与它的邻居一起变形的证据。在一个节理打开而被填充的地方、它变成一个**脉**、而一个脉是一个测年的、化学分析的、在失败的时刻存在的流体的样品。

## 褶皱

::: definition 褶皱几何 {#def-fold}
一个**褶皱**是一个弯曲的层或一叠层。**转折端**是最大曲率的点、**翼**是两侧的部分、**轴面**是平分转折端的面、而**折叠面**是轴面穿过一叠褶皱的迹线。褶皱是**直立的**（垂直的轴面）、**倾斜的**、**倒转的**（一个翼倒转）或**平卧的**（水平的轴面）。在**平行**（同心）的褶皱中、以直角对着层测量的层的厚度是恒定的、所以内的弧比外的短、而空间必须通过摊平或物质的迁移制造；在**相似**的褶皱中、以垂直测量的厚度是恒定的、而层在转折端变厚。
:::

::: proposition 褶皱的波长由弱的层的厚度设定 {#prop-wavelength}
当一个带着厚度 $h$ 的强的层在一个更弱的基质中缩短时、它以波长弯曲
$$
L \propto h\,\left(\frac{\eta_1}{\eta_0}\right)^{1/3},
$$
所以层的厚度的十倍的增长只给出波长的 2.2 倍的增长、而一列褶皱就是那个发生弯曲的层厚度的测量。
:::

::: proof
比奥的（1961）的分析平衡弯曲一个层的功与拖周围的基质的功。每单位长度的弯曲的阻力作为 $\eta_1 h^3$ 标度（一个弹性的梁的刚度作为它的厚度的立方走）、而基质对弯曲诱发的流的阻力对一个波长 $L$ 作为 $\eta_0 L$ 标度。在能量中相等两项、而对着 $L$ 最小化、给出 $L \propto h(\eta_1/\eta_0)^{1/3}$。指数 $1/3$ 是可观察的：它意味着褶皱的波长是一个*稳健的*而低分辨率的层的厚度的指标、而一个带着跨一个露头的系统的波长的改变的褶皱的列在记录某个层的厚度或黏度的改变。∎
:::

::: example 从一个剖面的缩短 {#ex-shortening}
一个标志的层能沿着一条剖面的线追溯 $42\ \mathrm{km}$、跟随它的褶皱的露头、而沿着层测量的层的平行的长度是 $98\ \mathrm{km}$。求缩短。如果层原本是水平的、而剖面的线垂直于走向、有多少地壳失去了、而它去了哪里？
::: solution
缩短 $= 1 - 42/98 = 0.57$、即 $57\%$、一个 $0.43$ 的延伸的比或一个 $2.33$ 的拉伸。$98\ \mathrm{km}$ 的原始的地壳、$56\ \mathrm{km}$ 从剖面失去。

它走了三条路、而它们之间的平衡是剖面的论证。一些被现在躺在剖面的之上而已经被侵蚀掉的**冲断的席**承担；一些沿着走向的**剖面的外的运输**、那是一个单剖面总是低估缩短的原因；而一些被**垂直的加厚**、那是使地形与根的东西。一个带着 $50\%$ 的缩短而没有侵蚀的证据的褶皱与冲断的带是一个红旗：要么剖面不平衡、要么缩短在别的地方发生。
:::
:::

另外两个构造属于同一段落、因为它们是同样的物理在一个更小的标度。**石香肠**形成一个强硬层沿自身方向被拉伸、而断成香肠的形状的段、被韧性的基质所填充的空隙分开；拉伸能从石香肠的长度 $l$ 与洞 $t$ 作为 $S = (l+t)/l$ 恢复、而典型的 $1.2$–$3$ 的值在变形的砾岩与脉中常见。**颈缩与肿物**的构造是韧性的版本、没有离散的断。两者告诉你最大的延伸的方向、那在一个褶皱的地形中常常*在*缩短的方向之内——在缩短的方向上的延伸是使构造地质值得学习的反直觉的事实之一。

切过地层向上的冲断层在它们切割的地方是陡的、而在它们沿着一个弱的层骑行的地方是平的——页岩、蒸发岩、超压的泥——而这个**坡–平的**几何有两个使山的带的几何可预测的结果。第一、一个被带过一个坡的上盘必须弯曲、所以**表面的褶皱是深度的坡的表面表现**、而一个穿过褶皱与冲断的带的剖面能逐层地平衡、来检验解释在几何上是否可能。第二、整个的叠置能在一个浅的滑脱面上被平移几十到几百千米、产生用了六十年才被接受的推覆体：格拉鲁斯的阿尔卑斯携带一个约 $40\ \mathrm{km}$ 长的赫尔维蒂推覆体的一块板片在磨拉石的之上、而西加拿大的、斯堪的纳维亚的与加里东的冲断的带在种类上是类似的。

::: example 加倍的地壳站多高？ {#ex-crustal-thickening}
西藏之下的地壳约 $70\ \mathrm{km}$ 厚、对着塔里木的盆地的正常的 $35\ \mathrm{km}$。取 $\rho_c = 2800$ 而 $\rho_m = 3300\ \mathrm{kg\,m^{-3}}$。预报高差的差、而对着高原的观测的均值的高度（$4.7\ \mathrm{km}$）比较。
::: solution
在两个柱之下的一个补偿深度平衡压力、带着莫霍面在深度 $h_c - e$、
$$
(\rho_c - \rho_m)(h_1 - h_2) + \rho_m(e_1 - e_2) = 0 \Longrightarrow \Delta e = \frac{\rho_m - \rho_c}{\rho_m}\,\Delta h_c 。
$$
带着 $\Delta h_c = 35\ \mathrm{km}$：$\Delta e = (500/3300)\times35 = 5.3\ \mathrm{km}$、对着观测的 $4.7\ \mathrm{km}$。简单的模型在 $15\%$ 内工作、而西藏是地壳的加倍的高原——一个由褶皱与冲断、加上地壳的流动的挤出而由缩短建造的高原。两个警告值得记住：第一、这个计算假设地壳与地幔的柱在均衡中、而高原的部分有热的、浮的地幔的根、贡献一部分高度；第二、如果地壳加倍而高度没有增加、那么有什么在别处支撑它、或者地壳不是你想的那样。在缩短的高原上、高度是一个均衡的论证、不是一个任意的地形。
:::
:::

## 造山带：变形去哪里

山带是汇聚的预算被花的地方、而有三种端元种类、由什么在被缩短、而什么在它之下区分。

**安第斯的类型的（弧的）带**形成于海洋的岩石圈的在一个大陆的岩石圈的之下俯冲的地方：地壳被缩短、加厚、被花岗岩侵入、而加热、而变形分布在几百千米上。安第斯是活着的例子、而北美洲的白垩纪的内部与澳大利亚的古生代是化石的那些。

**碰撞的带**形成一个大陆遇到一个大陆的地方。海洋的俯冲不能消耗大陆的岩石圈、所以汇聚通过叠置承担、通过印度的地壳在西藏的之下的冲底、而通过地壳沿着大的走滑的断层侧向的逃逸——阿尔金、鲜水河与红河的断层、每年移动几十毫米。印度与亚洲汇聚了约 $45\ \mathrm{mm\,yr^{-1}}$、也许 $50\ \mathrm{Myr}$、总共约 $2000\ \mathrm{km}$、而喜马拉雅与西藏的填图的缩短的总和只解释它的一部分：剩下的冲底了、或向东挤出、或正在被承担。

**增生的带**通过增加物质生长、而不是通过缩短在那里的东西：海洋高原的块片、海山、岛弧与沉积的棱体从一个俯冲的板块被刮掉、而粘在边缘上、在一个叫**增生**或**拼贴**的过程中。西北美洲的科迪勒拉的许多是这样的地体的一个叠置、每一个带着它自己的古地磁的纬度、而同样的过程建造了新西兰的古生代的许多与欧洲的华力西的。

三种都在汇聚停止、或高原变得太重时、被**伸展**跟随：盆岭的省、爱琴海、西藏的地堑与科罗拉多高原的核心杂岩都是崩溃的造山带、以与建造它们的缩短可比的速率伸展。山带不是永久特征；它是一个瞬变的、而它对抗侵蚀的半衰期是 $10^8$ 年的量级。

::: warning "褶皱与断层记录造成它们的应力"
它们记录*失败*、而失败至少像依赖应力那样依赖预先存在的构造的强度与取向。一个在对着最大的缩短 $40^\circ$ 的泥盆纪的弱的面上再激活的断层、除非你考虑再激活、几乎不告诉你 $\sigma_1$ 的方向；一个褶皱的形状依赖在它褶皱之前在那里的成层；而一个区域的结构是几个事件的重写本、最年轻的覆印更早的、而更早的作为继承的组构幸存。学科的中心的技术是**构造的相对的年代**——切穿的、覆印的、包含的、而一个组构在另一个之内的几何——而只有在那之后才是到应力的反演。
:::

::: quiz
一个石英的脉被拉伸成石香肠、带着 $8\ \mathrm{cm}$ 的长度与 $4\ \mathrm{cm}$ 的洞、而石香肠被韧性的云母分开。延伸的方向是
- [ ] 垂直于石香肠的长的轴
- [x] 平行于石香肠的长的轴
- [ ] 不能确定
- [ ] 对着石香肠的长的轴 $45^\circ$
::: solution
石香肠通过*沿着*层的延伸形成、所以拉伸的方向平行于石香肠的长的轴、而平行于成层。拉伸是 $S = (8+4)/8 = 1.5$。混淆产生因为石香肠常常伴随褶皱、在那个情况延伸的方向*在*缩短的方向之内——层总体上被缩短、而沿着自己拉伸、那正是一个强的层弯曲时发生的。
:::
:::

::: history
山的构造的问题是十九世纪的地质学的大争论、而它在一个问题上打：岩石能侧向移动几十千米吗？苏格兰的高地的"冲断的争论"从 1880 年代跑到约 1900、以调查局的格林与拉普沃思在一边、而更老的垂直的构造的学校在另一边；莫因的与本·莫尔的推覆体的填图通过把钻孔中的构造与图匹配解决了它。在瑞士、阿尔伯特·海姆的关于格拉鲁斯的推覆体的专著（在几十年的工作之后于 1904 年发表）与汉斯·沙尔特的在沙布莱的同样的几何的识别使阿尔卑斯成为一个冲断的带、而爱德华·修斯的《阿尔卑斯的起源》（1875）供给地壳的缩短的第一个定量的处理。力学的支撑更晚而来自实验室：欧内斯特·安德森的 1942 的关于通过内部的摩擦的断层的论文给断层的几何它的应力的基础；约翰·拜尔利的三轴的实验（1968）产生带他的名字的摩擦的律；而、决定性地、自 1970 年代在湿的与干的集合上测量的实验室的流动的律、它使说深层的地壳*为什么*流动、而计算地震学随后确认的地壳的强度成为可能。
:::

## 通向何处

应力的与应变的张量、的莫尔圆与应变的椭圆在 [[structural-geology/stress]] 与 [[structural-geology/strain]] 中适当地发展；库仑的标准、断层岩、而断层在 [[structural-geology/fractures-faults]] 中的生长；褶皱的机制与劈理在 [[structural-geology/folds]]；韧性的剪切的带与它们的运动的指标在 [[structural-geology/shear-zones]]；而图的与平衡的剖面的几何在 [[structural-geology/maps-sections]]。[[#ex-crustal-thickening]] 的均衡带着它的弯曲在 [[geophysics/gravity-isostasy]] 与 [[geophysics/flexure]] 中处理、而把变形岩石当作造山史的记录的使用在 [[structural-geology/orogens]] 中。

::: summary 关键的要点
- 差应力变形岩石；岩石静压的压力不。两者随深度增长、而它们的竞争设定变形的风格。
- 岩石是断裂还是流动依赖应变的速率至少像依赖温度：脆性–韧性转变在应力的术语中为快一千倍的变形变浅一个 $(10^3)^{1/n}$ 的因子。
- 断层通过库仑的标准在约 $30^\circ$ 对着 $\sigma_1$ 形成、而安德森的规则——哪一个主的应力是垂直的——只从应力的场预报正、走滑或冲断的断层。
- 节理垂直于 $\sigma_3$ 打开、而是大多数的储层的渗透率；脉是在失败的存在的流体的测年的样品。
- 褶皱的波长作为 $h(\eta_1/\eta_0)^{1/3}$ 标度、所以一列褶皱记录弯曲了的层的厚度；缩短通过比较层的长度与剖面的长度测量。
- 坡–平的冲断的几何连接表面的褶皱到深度的坡、使剖面可检验、而解释推覆体、飞来峰与窗。
- 加倍一个地壳抬高一个高原：$\Delta e = (\rho_m-\rho_c)\Delta h_c/\rho_m$、对一个 $35\ \mathrm{km}$ 的加厚约 $5\ \mathrm{km}$、接近西藏。
- 构造记录失败、不直接记录应力；覆印的组构的相对的年代先来、应力的反演第二。
:::

## 练习题

::: exercise 岩石静压应力 {level=1 check="135"}
求在 $5\ \mathrm{km}$ 的深度在密度 $2750\ \mathrm{kg\,m^{-3}}$ 的岩石中的岩石静压应力、以 MPa。
::: solution
$\sigma = \rho g z = 2750\times9.81\times5000 = 1.35\times10^{8}\ \mathrm{Pa} = 135\ \mathrm{MPa}$。有用的助记是每千米 $27\ \mathrm{MPa}$、或约每 $3.7\ \mathrm{km}$ 一个 $1\ \mathrm{kbar}$。
:::
:::

::: exercise 应变 {level=1 check="0.83"}
一个原本在一个方向 $3\ \mathrm{cm}$ 长的卵石现在是 $5.5\ \mathrm{cm}$。求工程的应变（输入这个）而自然的应变。
::: solution
$e = (5.5-3)/3 = 0.83$；$\varepsilon = \ln(5.5/3) = 0.61$。两个度量在这个应变差三分之一、那是构造地质学家陈述他们在用哪一个的原因；为小的应变它们一致。
:::
:::

::: exercise 安德森的规则 {level=1 check="27"}
对一个库仑摩擦系数 $0.75$、一个新的断层在一个对着 $\sigma_1$ 的什么角度形成？
::: solution
失败的面与 $\sigma_1$ 成一个角度 $45^\circ - \varphi/2$、其中 $\varphi = \arctan\mu = 36.9^\circ$：
$$
\theta = 45^\circ - 18.4^\circ = 27^\circ ,
$$
所以断层的平面坐在从 $\sigma_1$ 的 $27^\circ$、而从 $\sigma_3$ 的 $63^\circ$、而共轭的对关于 $\sigma_1$ 对称。带着 $\sigma_1$ 垂直、这给出倾斜 $63^\circ$ 的断层——正断层——而带着 $\sigma_3$ 垂直、$27^\circ$ 的倾角、那是为什么冲断层是低角度的。正断层的观测的 $55$–$65^\circ$ 的倾角、而冲断层的 $20$–$35^\circ$、是 $\mu \approx 0.75$ 被接受的原因。
:::
:::

::: exercise 再激活 {level=2 check="4.1"}
一个断层在带着 $\mu = 0.75$ 而零的黏聚力的岩石中倾斜 $30^\circ$。证明它对任何应力的比都不能作为正断层再激活、而求把它作为冲断层再激活需要的比 $\sigma_1/\sigma_3$。（输入冲断的值。）
::: solution
带着 $\beta$ 为断层的法线与 $\sigma_1$ 之间的角度、摩擦的失败的标准 $\tau = \mu\sigma_n$ 重排为
$$
\frac{\sigma_1}{\sigma_3} = \frac{D+\mu}{D-\mu}, \qquad D = \sin 2\beta - \mu\cos 2\beta 。
$$
作为一个*正*断层（$\sigma_1$ 垂直、断层倾斜 $30^\circ$）、平面的法线与 $\sigma_1$ 成 $\beta = 30^\circ$、所以 $D = 0.866 - 0.375 = 0.49 < \mu$、而比出来是负的：没有有限的水平的延伸能使这个断层滑动、而它将相反地在一个 $60^\circ$ 的断一个新面。作为一个*冲*断层（$\sigma_3$ 垂直）、法线成 $\beta = 60^\circ$、$D = 0.866 + 0.375 = 1.24$、而
$$
\frac{\sigma_1}{\sigma_3} = \frac{1.24+0.75}{1.24-0.75} = 4.1 。
$$
这是"继承的构造控制图的格局"的整个的内容：一个满是 $30^\circ$ 的冲断层的、地壳能以最小的可能的应力沿着同样的面再次缩短、而完全不能沿着它们伸展、而将相反地发展切过老的新的 $60^\circ$ 的正断层——那正是用来在一个造山带中确立伸展的与压缩的事件的相对的顺序的切穿的关系。
:::
:::

::: exercise 石香肠 {level=2 check="2.2"}
一个页岩的基质中的白云石的石香肠是 $6\ \mathrm{cm}$ 长、带着 $7.2\ \mathrm{cm}$ 的洞。求层的拉伸与工程的应变。
::: solution
$S = (l+t)/l = (6+7.2)/6 = 2.2$、所以工程的应变是 $e = S - 1 = 1.2$、或 $120\%$、而自然的应变是 $\ln 2.2 = 0.79$。一个被拉伸到比它的长度两倍更多的层、而整个的岩石可能总体上被*缩短*：石香肠是沿着层的延伸、而在一个褶皱的地形中那个方向常常是缩短的方向。
:::
:::

::: exercise 褶皱的波长 {level=2 check="2.2"}
在同一个翼的两代的褶皱在波长上差一个 2.2 的因子、带着同样的粘度的对比。强硬层的厚度的比是什么、而如果两代在同一个层中那暗示什么？
::: solution
$L \propto h^{1/3}$、所以 $h_2/h_1 = 2.2^3 = 10.6$。层的厚度的十倍的不同——或粘度的比的十倍的不同、因为 $L \propto (\eta_1/\eta_0)^{1/3}$ 也是。如果两代的褶皱在同一个层中、那么层没有改变厚度、所以粘度的对比必须改变了：层或它的基质在两个事件的一个中更粗、更湿或更热。那是一个真正的解释、而那是多期变形在野外如何被理清的方法。
:::
:::

::: exercise 推导安德森的规则 {level=3}
从一个平面的分解的牵引开始、推导库仑的失败的角度、而失败的差应的应力的表达式、
$$
\sigma_1 = \sigma_3\,\frac{1+\sin\varphi}{1-\sin\varphi} + \frac{2\tau_0\cos\varphi}{1-\sin\varphi},
$$
其中 $\varphi = \arctan\mu$ 是内部的摩擦的角度。对 $\mu = 0.75$ 而零的黏聚力评估比 $\sigma_1/\sigma_3$、而解释为什么冲断层能在远离 $30^\circ$ 的倾角再激活。
::: solution
把 $\sigma_n$ 与 $\tau$ 用 $\theta$ 写、施加 $\tau = \tau_0 + \mu\sigma_n$、而对着 $\theta$ 微分、以找到从 $\sigma_1$ 量的失败的取向 $\theta = 45^\circ + \varphi/2$。代回而使用 $\mu = \tan\varphi$ 给出引用的关系；带着 $\tau_0 = 0$ 而 $\mu = 0.75$（$\varphi = 36.9^\circ$）、
$$
\frac{\sigma_1}{\sigma_3} = \frac{1+\sin 36.9^\circ}{1-\sin 36.9^\circ} = \frac{1.6}{0.4} = 4 。
$$
冲断层能在远离 $30^\circ$ 的倾角再激活、因为再激活不需要新的失败、只需要在预先存在的面上的滑动、而一个低角度的面在一个压缩的场中已经在库仑的标准附近——继承的构造选择断层的、而应力只是执行它。
:::
:::

::: exercise 一个平衡的剖面 {level=3}
一个冲断的席在一个 $30\ \mathrm{km}$ 的剖面上填图。它的底的冲断层在 $8\ \mathrm{km}$ 的深度是水平的、在 $10\ \mathrm{km}$ 的水平距离上从 $8\ \mathrm{km}$ 坡到 $2\ \mathrm{km}$ 的深度、而在此后又是平的。上盘的层在表面是水平的、而在它之下 $2\ \mathrm{km}$。求这个坡贡献的缩短、而产生它需要的冲断层的滑动。
::: solution
一个上升 $\Delta z = 6\ \mathrm{km}$ 的坡把它的上盘带同样的高度、而水平的缩短等于坡被跨越的水平距离*减去*上盘相对于下盘已经前进的水平距离。对一个倾角 $\alpha$ 的坡、每单位的滑动的缩短是 $\cos\alpha$、而抬升是 $\sin\alpha$、所以带着滑动 $s$、抬升是 $s\sin\alpha = 6\ \mathrm{km}$、而缩短是 $s\cos\alpha$。

坡的倾角是 $\arctan(6/10) = 31^\circ$、所以 $s = 6/\sin 31^\circ = 11.6\ \mathrm{km}$、而缩短是 $11.6\cos 31^\circ = 9.9\ \mathrm{km}$——那是、缩短等于坡的水平范围、如它必须。这个练习是平衡剖面的整个的方法：测量几何、而滑动与缩短从三角跟随；如果层的长度不闭合、解释是错的、而不一致告诉你你错过了多少构造。
:::
:::

::: exercise 一个碰撞的预算 {level=3}
印度与亚洲在一个均值的 $45\ \mathrm{mm\,yr^{-1}}$ 汇聚了 $50\ \mathrm{Myr}$。喜马拉雅的填图的缩短是 $800\ \mathrm{km}$、西藏的是 $400\ \mathrm{km}$、而西藏之下的地壳的加厚解释一个 $300\ \mathrm{km}$ 的水平等价。求未说明的缩短、而列出它能被承担的方式。你会如何检验每一个？

总的汇聚 $= 45\times10^{-3}\times5\times10^{7} = 2250\ \mathrm{km}$。说明的：$800+400+300 = 1500\ \mathrm{km}$。未说明的：$750\ \mathrm{km}$、预算的三分之一。

四个候选、每一个可检验。（i）印度地壳在西藏的之下的**冲底**、由深的地震的反射、而由上的地幔中的印度的岩石圈的层析的成像检验。（ii）沿着大的走滑的断层的**向东的挤出**、由大地测量学（每一个断层每年几毫米）、而由标志的偏移检验。（iii）**造山带的侵蚀**、它移去质量、而不是缩短它、由恒河的与印度河扇中的沉积的预算检验——目前约 $10^9\ \mathrm{t\,yr^{-1}}$、而在过去大得多。（iv）**剖面的外的旋转**与垂直的轴的块旋转、由古地磁学检验、它在西藏记录了数十度的旋转。这个练习的要点是一个构造的预算、像一个碳的预算、只像它的闭合一样好——而一个 $30\%$ 的不一致不是一个失败、而是研究的纲领。
