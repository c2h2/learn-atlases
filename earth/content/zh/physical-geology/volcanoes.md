1902 年 5 月 8 日 7 时 50 分，马提尼克岛的圣皮埃尔镇——两万八千人，"加勒比的巴黎"，法属安的列斯群岛的商业首府——在两分钟之内被一团炽热气体与岩石组成的云摧毁，那团云以每小时一百多千米的速度顺山坡冲下。幸存者或许只有三十人。三天之前，在地球的另一端，夏威夷基拉韦厄火山的山顶已经喷了两周的熔岩喷泉：一道一百米高的白热岩幕，温和到一位摄影师能走到喷口跟前，而唯一的损失是几栋房子——它们后来在燃烧时被高高兴兴地拍了照。

同一个行星，同一类岩浆源，相反的行为。差别不在于是哪座火山，而在于岩浆由什么构成、含有多少气、上升多快，以及在上升途中有没有时间把这些气跑掉。本章讲这四件事，以及由它们导出的地貌、产物、灾害与气候效应。

## 为什么有的喷发会爆炸

::: definition 粘度、挥发分、碎裂 {#def-eruption}
**粘度** $\eta$ 是熔体对流动的抵抗，它在自然界中跨越十个或更多数量级：热的玄武岩约 $10$–$10^{3}\ \mathrm{Pa\,s}$，安山岩 $10^{4}$–$10^{6}$，近 $800\ ^\circ\mathrm{C}$ 的干流纹岩 $10^{10}$–$10^{13}$。它由聚合度（[[physical-geology/minerals]] 中的骨架结构）、温度、溶解的水——水能打断 Si–O–Si 键，可把 $\eta$ 降低五个数量级——以及晶体与气泡的含量控制。**挥发分**是溶解的气体，绝大多数是 $\mathrm{H_2O}$ 与 $\mathrm{CO_2}$，而 $\mathrm{S}$、$\mathrm{Cl}$、$\mathrm{F}$ 次要但重要。**碎裂**是在气泡体积分数约为 $0.7$ 的临界值处、从一个多泡液体到一团载着熔滴的气体泡沫的转变：喷发转为爆炸的临界点。
:::

::: proposition 水把岩浆保持为溶解状态直到几乎到达地表，然后它就不干了 {#prop-exsolve}
水在硅酸盐熔体中的溶解度大致随水的分压的平方根变化，所以一个含 $4\%$ 水（按重量）的流纹岩熔体能在 $100\ \mathrm{MPa}$（约 $3.5\ \mathrm{km}$ 深）把它溶解住，而压力降到几十兆帕以下就溶不住了。出溶一旦开始，气体的体积按 $1/P$ 增长，而熔体只能靠流动来扩容：如果通道窄而熔体粘，气就逃不掉，泡沫达到 $75\%$ 气泡，而岩浆柱便轰然碎裂。
:::

::: example 岩浆携带多少气？ {#ex-gas}
取 $1\ \mathrm{kg}$ 含 $1.0\%$ 溶解 $\mathrm{H_2O}$ 的流纹岩熔体（$\rho = 2500\ \mathrm{kg\,m^{-3}}$）。求它在 $1200\ ^\circ\mathrm{C}$ 能出溶的气的体积，(a) 在 $100\ \mathrm{MPa}$，(b) 在 $0.1\ \mathrm{MPa}$，并把每个结果与熔体本身的体积相比较。
::: solution
$10\ \mathrm{g}$ 的水是 $0.555\ \mathrm{mol}$，而熔体占 $1/2500 = 4\times10^{-4}\ \mathrm{m^3}$。把气体当作理想气体，
$$
V = \frac{nRT}{P} = \frac{0.555\times8.314\times1473}{P},
$$
在 $100\ \mathrm{MPa}$ 给出 $V = 6.8\times10^{-5}\ \mathrm{m^3}$——只占熔体体积的 $17\%$，尚能从容容纳——而在 $0.1\ \mathrm{MPa}$ 给出 $V = 6.8\times10^{-2}\ \mathrm{m^3}$，是熔体自身体积的 **170 倍**。

因此 $1\%$ 的水就足以在气逃不掉时把岩浆膨胀到其体积的一百七十倍，而只需那部分气中的几十个百分点就能达到碎裂的阈值。这就是爆炸性的全部，写在一行算术里：当熔体太粘、通道太窄或上升太快，气体来不及扩散出去时，喷发就是爆炸性的。它也解释了为什么含同样水的玄武岩以喷泉的形式喷发——气*确实*逃掉了，因为熔体根本兜不住气泡泡沫——以及为什么含水更少的流纹岩反倒能夷平一座城市。
:::
:::

::: warning "爆炸性的喷发比溢出的喷发更热"
它们通常更凉。玄武岩的熔岩在 $1100$–$1200\ ^\circ\mathrm{C}$ 喷出；爆炸性最强的安山质与英安质喷发在 $800$–$950\ ^\circ\mathrm{C}$ 进行；而起决定作用的根本不是温度，是粘度与气含量，它们随温度的变化方向正相反。这个误解在野外是危险的，因为它使一股暗红色的 $850\ ^\circ\mathrm{C}$ 火山碎屑密度流看起来"温度更低、因而更安全"，比一条亮橙色的熔岩流更安全。一股 $900\ ^\circ\mathrm{C}$ 的灰云用热、用窒息、用冲击杀人；一条 $1150\ ^\circ\mathrm{C}$ 的熔岩流只因为碍事而杀人，而且通常会给出预警。
:::

形态由第一节那四个变量决定，而且本身就有诊断意义：给出一座火山的形状，一位有经验的火山学家就能据以判断岩浆类型、溢出速率与喷发方式，而一个没有文字记录的死火山的历史正是这样重建出来的。

::: example 盾火山需要多快的供给？ {#ex-shield}
莫纳罗亚山大致是一个从海底量的 $110\ \mathrm{km}$ 宽、$7.5\ \mathrm{km}$ 高的锥，而其出露水面的部分不足 $0.7\ \mathrm{Myr}$。估计所要求的平均溢出速率，并与历史记录比较。
::: solution
锥体体积 $V = \tfrac{1}{3}\pi r^2 h = \tfrac{1}{3}\pi(5.5\times10^{4})^2(7.5\times10^{3}) = 2.4\times10^{13}\ \mathrm{m^3}$，约 $24{,}000\ \mathrm{km^3}$。分摊到 $0.7\ \mathrm{Myr} = 2.2\times10^{13}\ \mathrm{s}$ 上，平均速率为 $1.1\ \mathrm{m^3\,s^{-1}}$。

历史记录把它干净地框住。莫纳罗亚山 1950 年那次喷发在 23 天中产生 $0.044\ \mathrm{km^3}$，速率 $22\ \mathrm{m^3\,s^{-1}}$；基拉韦厄火山东裂谷带 1983–2018 年喷发在三十五年中平均约 $3\ \mathrm{m^3\,s^{-1}}$；而单次喷发事件峰值可达 $50$–$100\ \mathrm{m^3\,s^{-1}}$。于是长期平均值比上个世纪观测到的平均值*低*好几倍，这或者说明这座山体比其出露表面测定的年龄更老（事实正是如此：火山靠沉降与重建而生长，而深钻孔记录显示的年龄更老），或者说明当今这十年格外高产。两者都对，而算术正是你判断哪个要紧的办法。

对溢岸玄武岩做同样的计算，正是大型火成岩省令人不安之处：德干暗色岩含约 $1.5\times10^{6}\ \mathrm{km^3}$，而定年最好的几次脉动要求 $10^{3}$–$10^{4}\ \mathrm{m^3\,s^{-1}}$ 的溢出速率并持续数十年——莫纳罗亚的一千倍，喷到大陆边缘上，时间与过去 $66\ \mathrm{Myr}$ 最大的一次集群灭绝同时（[[earth-history/mass-extinctions]]）。
:::

::: definition 火山的类型 {#def-types}
一个**盾火山**是一个宽阔而低缓的火成体（$2$–$6^\circ$），由一次次流动性好的玄武岩流堆叠而成，宽数十千米、体积可达 $100{,}000\ \mathrm{km^3}$。一个**成层火山**（复合锥）是一个陡峭的（$15$–$35^\circ$）、尺度达数千米的锥体，由熔岩、火山灰与碎屑互层构成，在 $10^4$–$10^5$ 年间由溢发与爆发的交替活动堆成。一个**火山渣锥**是围绕单个喷口的弹射碎屑堆，直径很少超过几百米，坡度等于休止角。**熔岩穹丘**是一次因太粘而流不远的挤出物。**破火山口**是一个宽 $2$–$50\ \mathrm{km}$ 的塌陷洼地，形成于岩浆房被排空之时；**裂隙式喷口**则是沿一组岩墙排列的一串喷口，正是溢岸玄武岩与冰岛几次大喷发的来源。
:::

::: theorem 喷发柱的高度只对质量通量弱地标度 {#thm-column}
在静止大气中，一个浮力通量为 $B$（单位 $\mathrm{m^4\,s^{-3}}$）的持续喷发柱，其超出喷口的高度 $H$ 按
$$
H \propto B^{1/4}
$$
标度，所以质量通量增大 $10^4$ 倍，柱高只增加十倍。
:::

::: proof
一个密度亏损为 $g'$、速度为 $w$、上升穿过高度 $z$ 的烟柱，守恒其浮力通量 $B \sim g' w z^2$ 与其动能，因此在莫顿、泰勒与特纳（1956）的自相似区中，$w \sim (B^2 z)^{1/5}$、$g' \sim B^{3/5} z^{-1/5}$。柱在其密度与大气相配处停止，也就是在周围空气的持续卷入把源稀释到中性浮力之处；对同一组守恒通量做量纲分析给出 $H \propto B^{1/4} N^{-1/4}$，其中 $N$ 是大气的浮力频率。∎

实际的内容是一条关于凭照片读喷发的警告。柱高是最容易测、却是喷发强度最差的估计量之一，因为指数是 $1/4$：柱高加倍意味着质量通量增大 $2^4 = 16$ 倍，而一股强风切变能从一个仍在以恒定速率喷发的柱上削掉 $10\ \mathrm{km}$。这就是为什么火山爆发指数（它部分地建立在柱高之上）是一个对数的、备受批评的标度，也是为什么现代预报改用卫星测得的质量通量。
:::

## 喷出什么

**熔岩。** *绳状熔岩*光滑而呈绳状，由一股慢、热、已脱气、带着会起褶的薄壳的流供给；*块状熔岩*是一条覆满乱石的渣块流，更快、更凉、更粘，其表面是仍在流动的核之上参差的碎屑；安山岩与英安岩的对应物称为巨块状熔岩；*枕状熔岩*是玄武岩在水下淬火时的产物，也是地球上量最大的火山岩，构成整个洋壳顶部的那几米。熔岩管道把熔岩在数千米中带着很少的热损失送出，这就是为什么夏威夷的熔流能从 $20\ \mathrm{km}$ 外的喷口抵达大海。

**火山碎屑**按大小命名：火山灰（$<2\ \mathrm{mm}$）、火山砾（$2$–$64\ \mathrm{mm}$）、火山弹与岩块（$>64\ \mathrm{mm}$）。浮岩或火山渣是在仍是泡沫时被冻结的火山碎屑。

::: example 浮岩为什么浮在水上，那又为什么重要 {#ex-pumice}
火山玻璃的 $\rho = 2400\ \mathrm{kg\,m^{-3}}$。一块浮岩需要多少孔隙度才能浮在水上？能浮起来对浮岩筏能被找到的距离意味着什么？
::: solution
要使整体密度低于 $1000\ \mathrm{kg\,m^{-3}}$、而固体密度的变化可忽略，
$$
\rho_\text{bulk} = \rho_\text{glass}(1-\phi) < 1000 \Longrightarrow \phi > 1 - \frac{1000}{2400} = 0.58 。
$$
所以一块浮岩需要超过约 $58\%$ 的空隙，而典型浮岩则有 $60$–$80\%$。结果是一种别的岩石都没有的搬运方式：一次海底喷发产生的浮岩筏曾被人驾船航行、被卫星追踪、并在造出它的喷口 $2500\ \mathrm{km}$ 之外被发现；它们在几周之内带着珊瑚、软体动物与微生物跨越大洋盆地。因此在深海岩芯中读出一层浮岩，就给你一条风驱动的或流驱动的散布路径；如果那次喷发已被定年，还给出一个极精确的年龄。
:::

**火山碎屑密度流**既是爆炸式火山作用最致命的产物，也最不合常理。一个塌陷的喷发柱——或因密度过大、气太少，或被横向炸开——会变成一团贴地的热灰、浮岩与空气的混合物，以每小时几十到几百千米、在 $200$–$700\ ^\circ\mathrm{C}$ 行进，而它不是一团你跑得过、开车躲得开的云。圣皮埃尔就是这样一个。2019 年怀特岛与 1902、1991 年的几次事件都说明同一件事：致命产物在几分钟内到达，没有推进中的熔岩前锋可作视觉预警。

**火山泥流**是火山碎屑物与水的泥石流，而在顶盖冰川的火山上它是最常见的杀手。哥伦比亚的鲁伊斯火山，1985 年 11 月 13 日：一次规模不大的喷发融掉了峰顶冰川的足够部分，把火山泥流送下三条河谷；$47\ \mathrm{km}$ 外的阿尔梅罗镇约八小时后被席卷，其 29 000 人中约 23 000 人死亡。那座火山的灾害图早在数周前就已发表，而图上把阿尔梅罗划在红色危险区内。

::: example 火山泥流的速度与预警时间 {#ex-lahar}
鲁伊斯的火山泥流在 23 时 06 分喷发后约 $8$ 小时到达距山顶 $47\ \mathrm{km}$ 的阿尔梅罗。求平均速度，并说明它对疏散意味着什么。
::: solution
$v = 47/8 = 5.9\ \mathrm{km\,h^{-1}}$——相当于快步疾走，比任何车辆都慢。喷发在几分钟内就被地震仪捕捉到，而本可救下阿尔梅罗的预警，其时间尺度是小时，不是秒。

这是火山泥流灾害的一般规律：流是慢的，它们沿河谷而下，而且能从地形预先判断，所以问题从来不在物理，而几乎总在沟通——知道哪条河谷是流通道、装得上警报器、并演练过警报响起时该怎么办。现代的火山泥流监测在谷道本身布设地震检波器与水声流动监测仪，能为被堰塞成湖的二次泥流、或一场浇在新落火山灰上的暴雨提供几分钟的预警（[[natural-hazards/volcanic-hazards]]）。
:::

## 监测，以及它能与不能告诉你什么

火山会自我宣告。最近四十年中几乎每一次受到监测的喷发，都以可测的变化为先导，而三个要紧的信号是：

- **地震活动。** 岩浆的运动既破裂岩石也推动流体：浅源震群常带着一种独特的长周期"鼓点"信号，是最可靠的前兆。1989–1995 年云仙的活动、2018 年基拉韦厄喷发与 1991 年皮纳图博喷发都靠地震活动作出预报，而单凭地震活动就几乎足够。
- **形变。** 一个正在充注的岩浆房会把地面抬高几厘米到几米，用水准、GPS 与 InSAR 干涉测量。拉包尔、坎皮佛莱格瑞与乌图伦库长达数十年的持续膨胀都可测。
- **气体。** $\mathrm{SO_2}$ 的通量，尤其是 $\mathrm{CO_2}/\mathrm{SO_2}$ 比值：当新鲜而深部的岩浆到来时比值升高，因为 $\mathrm{CO_2}$ 比水在深得多的深度就出溶。

监测做不到的是给出一个确定的日期，或对付一座有历史以来从未喷发的火山，或一座其扰动看起来与自身背景无异的火山。它也做不到让预警真正生效：1991 年 6 月皮纳图博疏散了 6 万至 8 万人之后死亡 600 人，而六年前的阿尔梅罗手里拿着一张灾害图却死了 23 000 人——两者的差别不在仪器。

::: application 火山气体，以及灾害与扰民的分别 {#app-gas}
$\mathrm{CO_2}$ 比空气重，会积在洼地、地窖与谷底；体积分数达 $5$–$10\%$ 时几分钟内致命，而火山地带的持续脱气毒死牲畜，也不断毒死那些进入坑穴或地窖的人。十亿分之几量级的 $\mathrm{SO_2}$ 就刺激呼吸道，而在火山烟柱的浓度下会造成酸雨；1783 年冰岛拉基裂隙喷发在欧洲形成的一层霾，被归咎于英法数千人死亡，也造成了冰岛史上最惨的饥荒。吸附在火山灰上的 $\mathrm{HF}$ 正是火山灰降落有害的原因——它看上去只是脏，却能在数周之内毒死牲畜、污染水源。这些都不惊心动魄，而它们全部是同一件事的理由：一座火山喷发之后的灾害图，比它的喷发图更大、也更长久。
:::

## 火山与气候

平流层中的硫酸盐气溶胶反射阳光，而由于平流层无水而稳定，气溶胶能存留一到三年。现代的基准是 1991 年 6 月的皮纳图博：它把约 $20\ \mathrm{Mt}$ 的硫以约 $40\ \mathrm{Mt}$ 的 $\mathrm{SO_2}$ 注入热带平流层，形成一层光学厚度近 $0.15$ 的全球气溶胶层，并在 1992–93 年使全球降温约 $0.5\ ^\circ\mathrm{C}$（[[climate-system/forcing]]）。

::: example 从降温到辐射强迫到硫 {#ex-climate}
皮纳图博使全球降温约 $0.5\ \mathrm{K}$。用一个气候反馈参数 $\lambda = 0.8\ \mathrm{K\,(W\,m^{-2})^{-1}}$（[[climate-system/feedbacks-sensitivity]]），求平均辐射强迫，以及由此推出的每兆吨 $\mathrm{SO_2}$ 的强迫。然后解释为什么一次热带喷发按每吨计比一次高纬喷发更有效。
::: solution
$\Delta F = \Delta T/\lambda = -0.5/0.8 = -0.63\ \mathrm{W\,m^{-2}}$，在全球与两年上平均。按 $\mathrm{SO_2}$ 每兆吨计为 $-0.63/40 = -0.016\ \mathrm{W\,m^{-2}\,Mt^{-1}}$。

热带的优势是一个存留与分布的问题：贝克森–多布森环流与"热带管道"把一次热带注入铺成一层全球性、近乎连续的硫酸盐层而维持数年；而一次高纬注入只留在一个半球、沉降更快，同样的质量产生的全球平均强迫更小。这就是为什么近两个世纪两次最大的降温事件——1815 年的坦博拉与 1883 年的喀拉喀托，两者都在热带——出现在温度重建里、也出现在收成失败的历史记录里；也就是为什么一次同样规模的喷发若注入热带平流层，是一个全球事件而非地方事件。它也是太阳辐射管理名下讨论的平流层气溶胶方案（带着许多保留与很大的不确定性）的物理基础（[[climate-change/responses]]）。
:::
:::

在地质时间尺度上，这个平衡会反转。火山作用是地表系统 $\mathrm{CO_2}$ 的主要长期来源，而大型火成岩省与最近五亿年的几次大灭绝相关联——西伯利亚暗色岩与二叠纪末、中大西洋与卡尔鲁–费拉拉省与三叠纪末、德干与白垩纪末——机制是 $\mathrm{CO_2}$ 变暖、硫变冷、海洋酸化，以及（在熔岩烧掉煤或蒸发岩的地方）卤素与更多硫的灾难性释放。洋中脊系统，谁也不曾从空中目睹它喷发，按体积是行星上最大的火山系统，而它安静地在水下 $2500\ \mathrm{m}$ 喷出它的熔岩，约 $20\ \mathrm{km^3\,yr^{-1}}$，而全部陆地火山合计大约只有 $1\ \mathrm{km^3\,yr^{-1}}$。

::: quiz
一座已安静了 5000 年的火山在三天内出现 200 次浅源地震震群、$20\ \mathrm{cm}$ 的峰顶膨胀、以及一个从 2 升到 12 的 $\mathrm{CO_2}/\mathrm{SO_2}$ 比值。最好的解释是什么？
- [ ] 仪器漂移；什么也没发生。
- [x] 岩浆正在进入浅部系统；数日至数月内可能喷发，应清空该区。
- [ ] 热液循环发生了变化；无害。
- [ ] 火山正进入休眠期。
::: solution
三个信号同指一个方向，而它们的组合是典型的扰动模式：破裂引起的地震、加压引起的膨胀，以及来自新鲜岩浆的深部气体比值的上升。诚实的预报是概率性的——这类事件大多并不喷发，而时间尺度是数日至数月，不是数小时——但正确的行动是提升警报等级、减少暴露，因为误报的代价小，而误发解除警报的代价是阿尔梅罗。热液变化能模仿其中一部分，这就是为什么火山台站要使用若干互相独立的信号。
:::
:::

::: history
"火山"一词来自武尔卡诺岛——爱奥利亚群岛中那座古人把喷发归于武尔坎锻炉的岛；对火山的研究起初是自然史，到二十世纪成了物理学。1883 年喀拉喀托喷发是第一个全球性的地球物理事件：它的压力波在世界各地的气压计上被记录了五天；它的气溶胶造出的红色晚霞，既留在画里，也留在第一批天气尺度气候分析里；它的声波在 $4800\ \mathrm{km}$ 外被听到。1902 年培雷火山与苏弗里埃尔火山的喷发产生了那个十年中两种对立的解释——路易-费迪南·克罗瓦与阿妮·拉库瓦把"炽热云"释为火山碎屑流，对着曾亲眼看苏弗里埃尔喷发的弗兰克·佩雷的"蒸汽爆炸"说——而这场争论直到 1970 年代才告结束，当时斯彭斯等人证明 1902 年的堆积物只能由一股炽热、稠密、贴地的流动形成。哈伦·塔齐耶夫 1950 年代从尼拉贡戈发回的报道，以及托马斯·贾加 1912 年建立的夏威夷火山观测站，使火山学成为一门有仪器的科学；1991 年皮纳图博预报的成功——用地震活动、形变与气体——是它最负盛名的成果。
:::

## 通向何处

喷发方式是岩浆成分的推论，而那是 [[physical-geology/igneous-rocks]] 与 [[mineralogy-petrology/igneous-settings]] 的主题；灾害的算术在 [[natural-hazards/volcanic-hazards]] 中被推得更远，而监测的技术在 [[remote-sensing/radar-lidar]]（形变的 InSAR）与 [[remote-sensing/thermal-microwave]]（卫星热异常警报，它能在数小时内探测到地球上几乎每一次喷发）。气候的一节推广到 [[climate-system/forcing]] 与 [[climate-system/energy-budget]]，而大型火成岩省在深时中的角色见 [[earth-history/mass-extinctions]]，以及火山脱气在构建大气与海洋中的角色见 [[earth-history/early-earth]]。

::: summary 关键要点
- 爆炸性由粘度、气含量、上升速度与通道几何决定，不由温度决定：1\% 溶解的水在地表能膨胀到熔体体积的 170 倍。
- 碎裂，在约按体积 70–75\% 气泡处，是从熔岩喷泉到喷发柱的物理转变，也是同一座火山能同时做两件事的原因。
- 火成体的形状是诊断性的：盾来自高溢出速率与低粘度，成层火山来自爆发与溢发的交替，火山渣锥来自弹射的堆积，破火山口来自塌陷。
- 最致命的产物是最快的与最慢的那些：几分钟内到达的火山碎屑密度流，几小时内、而且常常在喷发很久之后的火山泥流；两者都跟着地形。
- 弹道射程、熔岩流路径与火山泥流路径都能从几何预报；火山灰的降落能从风场预报；这些都不是可以留在危险区的理由。
- 监测管用：地震活动、形变与气体比值在最近四十年几乎每一次观测良好的喷发之前都出现。失败是预警的失败，不是测量的失败。
- 火山的硫使行星变凉，而火山的二氧化碳使它变暖：皮纳图博的 40 Mt 的 $\mathrm{SO_2}$ 给出约 $-0.6\ \mathrm{W\,m^{-2}}$ 与 $-0.5\ \mathrm{K}$，而地球上最大的火山系统在海底。
- 火山灾害是教育材料：跟踪你的国家火山观测站与民防机构，并把它们的警报当作权威依据，而不是本章。
:::

## 练习

::: exercise 深处的气体体积 {level=1 check="12"}
$1\ \mathrm{kg}$ 的玄武岩熔体（$\rho = 2800\ \mathrm{kg\,m^{-3}}$）含 $0.5\%$ 溶解的 $\mathrm{H_2O}$。它在 $1200\ ^\circ\mathrm{C}$ 与 $0.1\ \mathrm{MPa}$ 下能出溶多少体积的气？再与熔体自身体积相比较。
::: solution
$5\ \mathrm{g}$ 的水是 $0.278\ \mathrm{mol}$，而 $V = nRT/P = 0.278\times8.314\times1473/10^{5} = 3.4\times10^{-2}\ \mathrm{m^3}$。熔体占 $3.6\times10^{-4}\ \mathrm{m^3}$，所以气膨胀约 **95 倍**于熔体——但玄武岩的粘度低到气能连片地跑掉，这就是为什么它喷成喷泉而不是爆炸。
:::
:::

::: exercise 火成体的几何 {level=1 check="35"}
一个火山渣锥是直径 $400\ \mathrm{m}$、高 $120\ \mathrm{m}$ 的锥。求其坡角（以度计），并与休止角作比较。
::: solution
坡角 $= \arctan(120/200) = 31^\circ$。那正是火山碎屑的休止角，而这就是判据：一个火山渣锥是被弹射的碎屑堆成的，因此它绝不可能比休止角更陡。
:::
:::

::: exercise 火山灰的负荷 {level=1 check="0.98"}
一场喷发在 $50\ \mathrm{km}$ 外落下 $10\ \mathrm{cm}$ 的松散火山灰（$\rho = 1000\ \mathrm{kg\,m^{-3}}$）。求单位面积的负荷，并把它与屋顶的设计雪载相比较。
::: solution
$0.10\ \mathrm{m}\times1000\ \mathrm{kg\,m^{-3}} = 100\ \mathrm{kg\,m^{-2}}$，约 $1\ \mathrm{kN\,m^{-2}}$。那与许多气候区的雪载同量级，而湿的火山灰重到 $1500\text{–}2000\ \mathrm{kg\,m^{-3}}$，所以一场雨就能把负荷翻倍。这就是为什么火山灰的预警中包含清扫屋顶，而它看上去只是脏而已。
:::
:::

::: exercise 粘度与流速 {level=2 check="1.78"}
一条 $5\ \mathrm{m}$ 厚的熔岩流沿 $5^\circ$ 的坡移动。对牛顿流体，平均速度是 $u = \rho g h^2 \sin\alpha/(3\eta)$。取 $\rho = 2500\ \mathrm{kg\,m^{-3}}$、$\eta = 10^{4}\ \mathrm{Pa\,s}$。以 $\mathrm{m\,s^{-1}}$ 求 $u$（输入 $u$），以及使同一条流以 $1\ \mathrm{m\,h^{-1}}$ 移动所需的粘度。
::: solution
$u = 2500\times9.81\times25\times\sin 5^\circ/(3\times10^{4}) = 2500\times9.81\times25\times0.0872/3\times10^{4} = 1.78\ \mathrm{m\,s^{-1}}$。

对 $u = 2.8\times10^{-4}\ \mathrm{m\,s^{-1}}$，所需的粘度是 $10^{4}\times(1.78/2.8\times10^{-4}) = 6.4\times10^{7}\ \mathrm{Pa\,s}$。真实的块状熔岩流以每分钟几米、而不是每秒几米移动，所以牛顿公式高估了一个数量级或更多：天然的熔岩是宾汉姆式的，带着一个 $10^2$–$10^{4}\ \mathrm{Pa}$ 的屈服强度，必须先克服它它们才会动。这道题真正的要点是 $h^2$ 的依赖——厚度加倍使流速四倍，这就是为什么厚的、被渠化的熔流比薄的危险得多。
:::
:::

::: exercise 柱的高度与质量通量 {level=2 check="4.0"}
1991 的皮纳图博的喷发柱到达海拔 $34\ \mathrm{km}$。用 $u = \sqrt{2gh}$ 作为出口速度的粗略估计，求出口速度，以及如果喷口 $25\ \mathrm{m}$ 宽、混合物的密度是 $100\ \mathrm{kg\,m^{-3}}$ 时的质量通量。（以 $\mathrm{kg\,s^{-1}}$ 输入质量通量，除以 $10^{7}$。）
::: solution
$u = \sqrt{2\times9.81\times34{,}000} = 817\ \mathrm{m\,s^{-1}}$——一个上界，因为它忽略卷入、阻力与真正驱动喷发柱的浮力。质量通量 $\dot M = \rho u A = 100\times817\times\pi\times12.5^2 = 4.0\times10^{7}\ \mathrm{kg\,s^{-1}}$，而最大的普林尼式喷发柱观测到的质量通量是 $10^{6}$–$10^{8}\ \mathrm{kg\,s^{-1}}$，所以这个估计量级正确。

诚实的版本使用浮力通量：柱的高度按 $B^{1/4}$ 标度，其中 $B$ 为浮力通量，这就是为什么柱高是喷发强度极差的估计量——质量通量增大 $10^4$ 倍只把高度改变十倍，而风切变削掉的高度可以相当于通量减半。
:::
:::

::: exercise 硫与降温 {level=2 check="0.016"}
一次喷发把 $60\ \mathrm{Mt}$ 的 $\mathrm{SO_2}$ 注入热带平流层。用 [[#ex-climate]] 的皮纳图博换算关系，估计平均辐射强迫，以及 $\lambda = 0.8\ \mathrm{K\,(W\,m^{-2})^{-1}}$ 下的降温。
::: solution
$\Delta F = -0.016\times60 = -0.96\ \mathrm{W\,m^{-2}}$，而 $\Delta T = \lambda\Delta F = -0.77\ \mathrm{K}$。（输入每兆吨的强迫：$-0.016\ \mathrm{W\,m^{-2}\,Mt^{-1}}$。）这个估计对质量是线性的，偏于宽松：气溶胶会长大、碰并，而在载荷高时沉降得更快，所以响应会饱和。它也忽略强迫在热带最大，而海洋吸热会延迟并削弱地表响应，这两点都使第一年的降温小于平衡值。
:::
:::

::: exercise 碎裂条件的推导 {level=3}
通常取碎裂发生在气泡体积分数达到 $\phi_b \approx 0.75$ 之时。证明：对一个初始溶解水含量为 $w$（重量分数）、在压力 $P$ 与温度 $T$ 下完全出溶的岩浆，碎裂压力为
$$
P_f \approx \frac{w\,R\,T\,\rho_m}{3\,\mu_\mathrm{w}} ，
$$
其中 $\mu_\mathrm{w}=0.018\ \mathrm{kg\,mol^{-1}}$ 是水的摩尔质量；并对 $w = 0.02$、$T = 1100\ \mathrm{K}$、$\rho_m = 2400\ \mathrm{kg\,m^{-3}}$ 求值。
::: solution
碎裂时气体的体积是熔体体积的 $\phi_b/(1-\phi_b) = 3$ 倍。每千克岩浆，$V_g = (w/0.018)RT/P$、$V_m = 1/\rho_m$，所以
$$
\frac{wRT}{0.018\,P} = \frac{3}{\rho_m} \Longrightarrow P_f = \frac{wRT\rho_m}{0.054} = \frac{wRT\rho_m}{3\times0.018} 。
$$
数值上：$P_f = 0.02\times8.314\times1100\times2400/(3\times0.018) = 8.1\times10^{6}\ \mathrm{Pa} \approx 8\ \mathrm{MPa}$，相当于通道内约 $300\ \mathrm{m}$ 的深度。

所以一个含水 $2\%$ 的流纹岩在几兆帕就碎裂，也就是在离地表几百米之内，而喷发整个爆炸性的阶段都发生在通道最上面那几百米。这就是为什么喷口会被摧毁，为什么堆积物的体积只占岩浆体积的百分之几，以及为什么一次大型爆发式喷发的大部分岩浆根本没有喷出、而是留在原地冷却。这也是为什么这个判据是一个*阈值*：含水 $1\%$ 的岩浆在压力减半处碎裂；而一个在上升途中就敞开脱气的岩浆——一个熔岩湖、一个敞口的安山岩喷口——无论初始含水多少都不会碎裂。
:::

::: exercise 由数字高程模型制作灾害图 {level=3}
一个源自火口湖的火山泥流被模拟为顺谷而下，其堆积范围按 $L = k\,V^{1/3}$ 衰减，其中 $V$ 是被卷动的体积。观测事件给出 $V = 5\times10^{6}\ \mathrm{m^3}$ 时 $L = 60\ \mathrm{km}$。求 $k$，以及一个 $10^{8}\ \mathrm{m^3}$ 事件的堆积范围。这个标度对灾害填图意味着什么？
::: solution
$k = 60{,}000/(5\times10^{6})^{1/3} = 60{,}000/171 = 351$。对 $V = 10^{8}\ \mathrm{m^3}$，$L = 351\times464 = 1.63\times10^{5}\ \mathrm{m} = 163\ \mathrm{km}$。

体积增大二十倍，堆积范围只增大 2.7 倍，所以危险区的最远端由最大可信事件、而非平均事件控制；又因为这条关系是用寥寥几次事件拟合出的幂律，远端的不确定性极大。这就是为什么真实的火山泥流灾害图是在数字高程模型上对一系列体积运行数值流动模型画出的淹没包络线，也为什么它们以淹没概率而非一条线来表达：地形已知到米，而一个 $10^{8}\ \mathrm{m^3}$ 碎屑流的物理连二倍精度都没有（[[natural-hazards/volcanic-hazards]]、[[remote-sensing/gis-data]]）。
:::

::: exercise 读一段喷发记录 {level=3}
一座火山下风向 $40\ \mathrm{km}$ 处的一支湖泊岩芯，在纹泥（年层状沉积）中含一层纹泥 1450 处 $12\ \mathrm{mm}$ 厚的火山灰层、下风向 $120\ \mathrm{km}$ 处 $3\ \mathrm{mm}$、$400\ \mathrm{km}$ 处 $0.5\ \mathrm{mm}$。粒度分析显示最大碎屑直径从 $30\ \mathrm{mm}$ 降到 $4\ \mathrm{mm}$ 再降到 $0.5\ \mathrm{mm}$。估计喷发的强度等级，并说出你从这些数据无法确定什么。
::: solution
厚度与碎屑大小都大致随下风向距离指数衰减，所以把厚度的衰减外推回喷口，就给出喷口处厚度的一个估计；再把厚度—距离曲线在堆积区面积上积分，就给出火山灰体积，从而一个强度等级。只有三个距离，你能拟合衰减常数，却拟合不出面积，因为你没有堆积物分布范围的图——那正是必不可少的第四项测量。

单凭岩芯无法确定的有：这次喷发是一个事件还是一年之内的三个事件（纹泥能把这一点抹掉）；柱高（它需要*喷口处*的最大碎屑大小与风向）；从岩浆房抽出的岩浆体积（它可能远大于喷出体积）；以及公元纪年——除非纹泥年代学被拴在某个已知的标志层上。你能确定的是该地点某一厚度的火山灰层的重现间隔，而那正是真正进入灾害评价的数字——也是为什么最长的记录要从湖底与海底读取，而不是从历史文献读取。
