挖过的最深的洞在 1989 年在柯拉半岛到达 $12{,}262\ \mathrm{m}$、经过二十年的钻进、而在 $180\ ^\circ\mathrm{C}$ 停止、不是在技术的任何极限。那是到地球的中心的路的 $0.19\%$——按比例、比一个苹果的皮的厚度更少。这一章中的一切都在不钻的情况下知道：核的半径到几千千米之内、它的密度、声音穿过它的速度、它是固体的还是液体的、地幔在 $600\ \mathrm{km}$ 的深度由什么矿物构成、而整个的行星在多快地冷却。

方法是一个带着听诊器的医生的方法。我们看不到内部、而内部在被敲击时响、而响告诉我们它由什么构成。在 1909 年、安德烈·莫霍洛维奇注意到来自萨格勒布的地震的地震的波以两组到达、一组快的、而一组慢的、而唯一的解释是在约 $54\ \mathrm{km}$ 的深度的地球的地壳中的一个边界。在 1926 年、本诺·古登堡用 P 波在 $103^\circ$ 之外的消失来固定核的半径在 $3480\ \mathrm{km}$、一个自那以来移动了不到 $10\ \mathrm{km}$ 的数字。在 1936 年、英格·莱曼、整理一个荷兰地震的地震记录、发现一个只能来自一个在液体的核的之内的固体的球的微弱的到达。三个推断都用秒表与纸的记录做出、而三个都幸存了。

## 层、而每一个如何找到

::: definition 一段话里的结构 {#def-layers}
**地壳**是 $5$–$10\ \mathrm{km}$ 的玄武质的洋壳岩石或 $30$–$70\ \mathrm{km}$ 的花岗质的大陆岩石、带着 $V_P = 6$–$7\ \mathrm{km\,s^{-1}}$、坐在 $V_P = 8.0\ \mathrm{km\,s^{-1}}$ 的**莫霍面**的之上。**地幔**延伸到 $2891\ \mathrm{km}$ 的深度：橄榄石与它的多晶型物下到 $660\ \mathrm{km}$、然后是布里奇曼石加铁方镁石。**外核**是液体的、$2200\ \mathrm{km}$ 厚、完全排除 S 波、而大多是铁。**内核**是固体的、半径 $1221\ \mathrm{km}$、而变形得好像它是一个单晶或接近如此。在地壳与地幔转变带之间躺着**软流圈**、一个在洋底之下 $50$–$250\ \mathrm{km}$ 的深的低速的层、在其中岩石接近它的固相线、以至于它容易地流动。

::: proposition 液体的外核只从 S 波跟随 {#prop-liquid-core}
在大于 $103^\circ$ 的震中的距离不记录直接的 S 波、而 P 波在 $142^\circ$ 之外回来。因为 S 波不能在一个流体中传播、而因为几何要求任何一个到达在 $103^\circ$ 之外的射线必须穿过$r = 3480\ \mathrm{km}$ 以内的区域、外核是液体的。在 $103^\circ$ 与 $142^\circ$ 之间的 P 波的影区随后从折射跟随：在核幔边界的 P 的速度的下降把透射的射线向法线弯曲、所以在之间的带没有 P 的能量出现。
:::

::: proof
取一个在半径 $r_c$ 刚刚擦过核幔边界的射线。在边界的正上的地幔中 $V_P = 13.7\ \mathrm{km\,s^{-1}}$；在它的正下 $V_P = 8.0\ \mathrm{km\,s^{-1}}$。在边界处给出透射角 $\theta_t$ 的斯涅尔律 $\theta_t$
$$
\frac{\sin\theta_t}{\sin\theta_i} = \frac{8.0}{13.7} = 0.584 。
$$
对掠射的射线 $\theta_i = 90^\circ$、所以 $\theta_t = 35.7^\circ$：射线向半径急剧地弯曲、而本来会在 $103^\circ$ 继续到表面的射线偏折进核。追踪在核上方转弯的射线与进入核的射线的一族在表面留下一个角度的洞——影区——它的观测的内缘 $103^\circ$ 固定 $r_c/R = 0.546$、而它的外缘 $142^\circ$ 固定速度的跳变。两个数字都测量、而两个都与 $r_c = 3480\ \mathrm{km}$ 一致。

外核是液体这一事实被独立地确认了三次：S 波不穿过它；地球的固有振荡（它在一个大地震之后的自由的鸣响）包括只在一个流体的层存在的模式；而潮汐的勒夫数 $k_2 = 0.30$ 要求一个在它的中心附近对剪切是刚性的行星。∎
:::

::: example 从从平均密度求核的半径 {#ex-core-radius}
地球的质量是 $5.974\times10^{24}\ \mathrm{kg}$、而它的平均的半径 $6371\ \mathrm{km}$、给出 $5515\ \mathrm{kg\,m^{-3}}$ 的平均密度。把地球模型为两层、一个密度 $11{,}000$ 的核、而一个 $4500\ \mathrm{kg\,m^{-3}}$ 的地幔、而求核的半径。然后用观测的转动惯量的因子 $I/MR^2 = 0.3308$ 检验模型。
::: solution
带着 $k = r_c/R$ 而体积正比于 $k^3$、
$$
5515 = 11{,}000\,k^3 + 4500(1-k^3) \Longrightarrow 1015 = 6500\,k^3 \Longrightarrow k = 0.156^{1/3} = 0.538 、
$$
所以 $r_c = 3430\ \mathrm{km}$、在地震学的值 $3480\ \mathrm{km}$ 的 $1.5\%$ 之内。两个像秒表与天平一样不同的数字给出同样的半径、那是使一个模型可信的一致。

对两个均匀球的转动惯量、
$$
\frac{I}{MR^2} = \frac{2}{5}\cdot\frac{11{,}000\,k^5 + 4500(1-k^5)}{11{,}000\,k^3 + 4500(1-k^3)} = \frac{2}{5}\cdot\frac{4818}{5563} = 0.346 、
$$
对着观测的 $0.3308$。模型把太多质量放得太靠外、所以真实的地球必须在中心比一个均匀的核*更密*：压缩把核的密度从顶部的 $9.9$ 抬到中心的 $12.8\ \mathrm{g\,cm^{-3}}$。不一致不是一个失败、而是密度梯度的一个测量。
:::
:::

## 地幔由什么构成：矿物的物理

地震学给速度；矿物的物理告诉你速度意味着什么。论证这样跑：在金刚石对顶砧腔或多面顶压机中、在地幔的压力与温度测量候选的矿物的地震的速度与密度；找到匹配的组合；而如果没有一个*成分*正确的组合匹配、那么成分是错的。

::: definition 橄榄石–尖晶石转变与转变带 {#def-olivine}
橄榄石、$(\mathrm{Mg,Fe})_2\mathrm{SiO_4}$、是上地幔的主导的矿物。在 $13.9\ \mathrm{GPa}$（$410\ \mathrm{km}$）它转变为**瓦兹利矿**、在 $17.5\ \mathrm{GPa}$（$520\ \mathrm{km}$）转变为**林伍德石**、而在 $23.8\ \mathrm{GPa}$（$660\ \mathrm{km}$）它分解为**布里奇曼石** $(\mathrm{Mg,Fe})\mathrm{SiO_3}$ 钙钛矿加**铁方镁石** $(\mathrm{Mg,Fe})\mathrm{O}$。在 $410$、$520$ 与 $660\ \mathrm{km}$ 的三个不连续面不是成分的边界、而是*同一块岩石中的相变*、而它们是地幔在 $410$ 与 $660\ \mathrm{km}$ 之间的"层"有同样的化学而不同的物理的原因。
:::

::: theorem 克拉珀龙斜率使一个不连续面成为一个温度计 {#thm-clapeyron}
相图上（$P$–$T$ 空间）的一条相线有一个斜率
$$
\frac{\mathrm{d}P}{\mathrm{d}T} = \frac{\Delta S}{\Delta V} 、
$$
所以正斜率的不连续面在地幔冷的地方坐在*更深*、而在热的地方*更浅*、而负斜率的不连续面做相反的。$410\ \mathrm{km}$ 的不连续面有 $\mathrm{d}P/\mathrm{d}T \approx +3.3\ \mathrm{MPa\,K^{-1}}$、而 $660\ \mathrm{km}$ 的约 $-2.0\ \mathrm{MPa\,K^{-1}}$、而它们的对立的符号是一对被用来检验地幔的对流是分层的还是全地幔的原因。
:::

::: proof
沿着一个相的边界两个相有相等的吉布斯的自由能、$G_1 = G_2$。微分、$-S_1\mathrm{d}T + V_1\mathrm{d}P = -S_2\mathrm{d}T + V_2\mathrm{d}P$、它重排为上面的克劳修斯–克拉珀龙关系。斜率的符号是 $\Delta S/\Delta V$ 的符号：因为对硅酸盐的这些转变、更密的相总是更有序的、$\Delta S$ 与 $\Delta V$ 有同样的符号、而斜率是正的——除了林伍德石 $\rightarrow$ 布里奇曼石的转变、它的体积的塌缩异常地大、而斜率是负的。

除以一个岩石静压的梯度 $\rho g \approx 3500\times9.8 = 34.3\ \mathrm{kPa\,m^{-1}}$、把一个斜率变成一个深度的移动：
$$
\Delta z = \frac{(\mathrm{d}P/\mathrm{d}T)\,\Delta T}{\rho g} 。
$$
对一个在比平均值冷 $200\ \mathrm{K}$ 的板块之下的 $410$、$\Delta P = 3.3\times10^{6}\times(-200) = -6.6\times10^{8}\ \mathrm{Pa}$、所以 $\Delta z = -19\ \mathrm{km}$：边界坐在*更浅*的 $19\ \mathrm{km}$。对 $660$、它的斜率是负的、同样的冷的异常给出更深的 $+12\ \mathrm{km}$。∎

观测是：在冷的海洋与俯冲的带之下、$410$ 上升、而 $660$ 加深、正如两个斜率预报的、而振幅与从层析测量的温度的异常匹配。在两个不连续面*不*这样表现的地方——在 $660$ 出现为摊平的或没有的地方——要么有一个成分的异常、要么有部分熔融。
:::

::: example 板块把 $660$ 压低多少？ {#ex-660}
在一个俯冲的带之下、板块在 $660\ \mathrm{km}$ 的深度比周围的地幔冷 $400\ \mathrm{K}$。取 $\mathrm{d}P/\mathrm{d}T = -2.0\ \mathrm{MPa\,K^{-1}}$ 而 $\rho g = 34.3\ \mathrm{kPa\,m^{-1}}$。求 $660$ 的深度移动、而说出一个到达其斜率使它*更难*进入下地幔的不连续面的板块会怎样。
::: solution
$$
\Delta P = (-2.0\times10^{6})\times(-400) = +8.0\times10^{8}\ \mathrm{Pa} = 800\ \mathrm{MPa} 、
\qquad
\Delta z = \frac{8.0\times10^{8}}{3.43\times10^{7}} = +23\ \mathrm{km} 。
$$
$660$ 在冷的板块之下被压低约 $23\ \mathrm{km}$、那在全球的地震的剖面的叠加中观测到。因为斜率是负的、冷的岩石变换到更密的下地幔的组合比暖的岩石*更晚*、所以本来会帮助板块下沉的相变在板块最冷而最密的地方延迟。这是"$660$ 作为一个板块的屏障"的假设的起源、而一些板块在 $660\ \mathrm{km}$ 摊平的观测（汤加的板块是经典的例子）而另一些——在太平洋之下、而在老的、冷的、快速俯冲的边缘之下——被层析成像在下地幔一直到 $D''$ 层。目前的共识是 $660$ 是一个部分的、瞬变的屏障、而不是一个绝对的、那意味着地幔的对流*大多*是全地幔的、而穿过转变的带的交换是缓慢的。
:::
:::

## 核与核的密度问题

::: proposition 外核轻得不足以是纯铁 {#prop-core-light}
在核幔边界的压力（$136\ \mathrm{GPa}$）纯的铁有一个约 $13.0\ \mathrm{g\,cm^{-3}}$ 的密度；外核在那里是 $9.9$–$10.0\ \mathrm{g\,cm^{-3}}$、而亏损在核的顶增长到约 $10\%$。核因此包含百分之几的轻元素。候选的、按实验排序的、是硅、氧、硫、碳与氢——而混合物重要、因为它决定核的密度、它的声速、它的粘度、它能给出多少热、而因此地球的发电机能运行多久。
:::

::: example 核的密度的亏损 {#ex-deficit}
在外的核的顶（$136\ \mathrm{GPa}$、$4000\ \mathrm{K}$）的纯的液体的铁有 $\rho = 12.4\ \mathrm{g\,cm^{-3}}$ 而 $V_P = 8.9\ \mathrm{km\,s^{-1}}$；观测到的那里的外核是 $\rho = 9.9\ \mathrm{g\,cm^{-3}}$、$V_P = 8.0\ \mathrm{km\,s^{-1}}$。冲击波与金刚石对顶砧实验给出大约每一原子百分点的氧约 $1.5$ 个百分点的密度的亏损、所以 $x$ 原子百分点的轻的元素给出 $\rho = 12.4(1 - 0.015x)$。估计 $x$、而如果它全是氧的核内轻元素的质量。
::: solution
$$
\frac{9.9}{12.4} = 0.798 = 1 - 0.015x \Longrightarrow x = 13.5\ \mathrm{at\%} 。
$$
为一个 Fe–O 的合金转换成重量百分点、$0.135\times16/(0.865\times55.85 + 0.135\times16) = 4.3\ \mathrm{wt\%}$——在被接受的范围 $5$–$10\ \mathrm{wt\%}$、虽然单独的氧使声速太低、那是现代的观点是氧、硅、硫、碳与氢的混合物的原因。轻的元素的质量然后是 $0.06\times1.85\times10^{24} \approx 1.1\times10^{23}\ \mathrm{kg}$、约整个的地壳的质量的 $20$ 倍、而它的化学的势是驱动地球的发电机的两三个事情之一：随着内核生长、轻的元素从结晶的铁中被排除、而上升、而那个成分对流至少像热对流一样重要。
:::
:::

::: warning "地幔就像地壳一样是岩石、只是更深"
在约 $200\ \mathrm{km}$ 之下、矿物不是任何的手的标本中的那些：林伍德石、布里奇曼石与铁方镁石是只在 $14\ \mathrm{GPa}$ 之上存在的高压的相、而在带到表面时变回橄榄石与顽火辉石——那是为什么地幔从来没有被*看到*、只在几乎总是浅的捕虏体的采样。相反地、地幔不是熔融的：低速的带是一个只含一两个百分点熔体的岩石、而它流动不是因为它液体的、而是因为它热的、湿的而缓慢地变形的。在这个主题中最持久的错误是把"韧性的"与"熔融的"混淆、而第二持久的是想象核为熔融的熔岩——它是液体的*铁*、在 $4000$–$6000\ \mathrm{K}$、在 $135$–$330\ \mathrm{GPa}$ 之下。
:::

## 热：地球还在冷却

::: example 地球的冷却的速率 {#ex-cooling}
地表热流总计 $47\ \mathrm{TW}$（$4.7\times10^{13}\ \mathrm{W}$）、其中约 $20\ \mathrm{TW}$ 是在地壳与地幔中产生的放射性生热、而其余的来自核、而来自长期冷却。把地幔的热容取为 $M c_p = 4.0\times10^{24}\times1200\ \mathrm{J\,K^{-1}}$。求暗示的地幔的冷却的速率、而如果那个速率是稳定的、在 $4.5\ \mathrm{Gyr}$ 的温度的下降。
::: solution
非放射性生热损失是 $27\ \mathrm{TW}$、其中也许 $10$–$12\ \mathrm{TW}$ 离开核；取 $15\ \mathrm{TW}$ 作为地幔的长期冷却：
$$
\frac{\mathrm{d}T}{\mathrm{d}t} = \frac{1.5\times10^{13}}{4.8\times10^{27}} = 3.1\times10^{-15}\ \mathrm{K\,s^{-1}} = 9.8\times10^{-8}\ \mathrm{K\,yr^{-1}} 、
$$
那是每一百万年 $0.1\ \mathrm{K}$、而地球的年龄之上 $440\ \mathrm{K}$。地球在冷却、而缓慢地：自 $3\ \mathrm{Gyr}$ 之前地幔也许冷却了几百度、那足以改变它所产生的一切地壳特征——太古代的科马提岩要求地幔位温比今天高 $200$–$300\ \mathrm{K}$、而它们在大陆变大的时候从记录中消失（[[earth-history/early-earth]]）。

热预算是这个主题有争议的原因：在一个含着 $20$ 亿分之一的不相容的元素的 $20\ \mathrm{TW}$ 的放射性生热、是"尤里比"的问题、而高值与低值之间的差别决定早期的地球比今天热得多、还是只稍微。
:::
:::

::: quiz
观测到 $410\ \mathrm{km}$ 的不连续面在一个冷的俯冲的带之下比全球的均值*浅*约 $20\ \mathrm{km}$。这是因为
- [ ] 冷的岩石更密、所以边界上升
- [x] 转变有一个正的克拉珀龙的斜率、所以在更低的温度转变在更低的压力发生
- [ ] 板块机械地把边界向上推
- [ ] $410$ 是一个成分的边界、而冷的板块更有浮力
::: solution
带着 $\mathrm{d}P/\mathrm{d}T > 0$、一个负的温度的异常要求一个更低的压力来达到转变、所以边界变浅；$660$、带着一个负的斜率、在同一个地方加深。对同样的冷的异常的两个对立的响应是使这一对成为一个温度计的东西、而观测的振幅与从层析的温度的异常匹配。
:::
:::

## 我们凭别的什么知道：其他探针

地震学不是唯一的通道。地球的**固有振荡**——整个行星在 1960 年智利地震之后以一个 $54$ 分钟的周期鸣响、首先在一个重力仪观测、然后在长周期地震仪——不依赖任何走时假设给了深的结构、而它是像 PREM 的现代的模型在深的地幔是平滑的、而不是射线的几何的伪迹的原因。**重力与转动惯量**约束密度的分布、如在 [[#ex-core-radius]]。**自由空气与布格异常**填图地壳、而**大地水准面**的数据在几千千米的波长填图地幔的对流。**地幔捕虏体**由金伯利岩带上、采样地幔到 $200\ \mathrm{km}$、而是我们有的上地幔的唯一的直接的样品；含着林伍德石的包含的**转变的带的金刚石**是地幔的转变带的唯一直接样品、而它们携带足够的水在 2014 正确地做了头条：转变的带能含着像海洋一样多的水、在一块不湿的岩石中。

**地中微子**——从岩石中的铀与钍的衰变的链的反中微子——在神冈的 KamLAND 与博雷西诺探测器计数、而给出放射的热产生的一直接的、虽然统计的薄的测量：约 $20\ \mathrm{TW}$、与地球化学预算一致。**地磁长期变化**与**古地磁记录**约束核的运动、而内核的年龄、而**高压实验**通过测量波应当如何表现而把整个链条闭合。

::: history
内部从几乎一无所有建造。奥尔德修斯在 1773 年、然后泊松与格林显示弹性波如何穿过一个球传播；实用的开始是 1890 年代地震仪的发明。安德烈·莫霍洛维奇用 1909 的萨格勒布的事件找到地壳–地幔的边界、它仍带着他的名字。里查德·迪克森·奥尔德姆从 1906 的旧金山的地震的畸变的地震图在 1906 年识别核、而本诺·古登堡在 1912 年给它的深度、而在他 1926 的专著中改进它。哈罗德·杰弗里斯的《地球》（1924、第四版 1970）把整个的主题——地震学、重力、均衡、潮汐、热——装配成一个统一的定量模型、而设定这个领域的标准。英格·莱曼的 1936 的关于内核的短文写在她是一个在哥本哈根的办公室里 48 岁的女人的时候、而推翻了杰弗里斯的一个站了十年的结论。矿物物理时代始于珀西·布里奇曼的 1940 年代的高压的工作、而对于地幔特别地、始于 1960 年代的石榴石与尖晶石的转变的合成；参考地球模型 PREM（兹维奥宁斯基与安德森、1981）仍在每天使用、而当前的前沿不是层的位置、而是它们的矿物学、它们的水的含量、而它们之间的流动。
:::

## 通向何处

波的理论、射线的追踪、而到速度的反演在 [[geophysics/elastic-waves]] 与 [[geophysics/seismic-structure]]；转动惯量、潮汐的勒夫数与均衡在 [[geophysics/gravity-isostasy]]；热的结构暗示的动力学在 [[geophysics/heat-flow]]；由核产生场在 [[geophysics/geomagnetism]]；而把地震作为灾害、而不是作为探针的使用在 [[physical-geology/earthquakes]]。行星的冷却的历史与它对早期的地壳的影响在 [[earth-history/early-earth]] 跟随。

::: summary 关键的要点
- 地壳是一个外皮：半径的 $0.19\%$ 钻过、而下面的一切从波、重力、自转与实验推断。
- 层由速度的跳变找到：莫霍面在 $8.0\ \mathrm{km\,s^{-1}}$、$410$、$520$ 与 $660\ \mathrm{km}$ 的不连续面、核幔边界在 $2891\ \mathrm{km}$、而内核边界在 $5150\ \mathrm{km}$。
- 外核是液体的、因为没有直接的 S 波穿过它；P 波的影区 $103^\circ$–$142^\circ$ 固定它的半径在 $3480\ \mathrm{km}$。
- 在 $410$ 与 $660\ \mathrm{km}$ 之间岩石是同样的、而矿物不是：橄榄石转变为瓦兹利矿、林伍德石、然后到布里奇曼石加铁方镁石。
- 克拉珀龙的斜率把不连续面变成温度计：$410$ 变浅、而 $660$ 在冷的板块之下加深、约每 $200$–$400\ \mathrm{K}$ $20\ \mathrm{km}$。
- 核是 $5$–$10\ \mathrm{wt\%}$ 的轻的元素；它在生长的内核的排除是地球发电机的主要驱动之一。
- 转动惯量的因子 $0.3308$ 要求密度向中心增加；均匀核模型给 $0.346$。
- 地球失去 $47\ \mathrm{TW}$、约 $40\%$ 是放射的、而冷却约每一百万年 $0.1\ \mathrm{K}$。
:::

## 练习题

::: exercise 地壳作为一个外皮 {level=1 check="0.19"}
求科拉超深钻孔的深度作为地球的半径的百分比。
::: solution
$12.262/6371 = 0.0019$、即 $0.19\%$。如果地球是一个半径 $7\ \mathrm{cm}$ 的苹果、洞会是 $0.14\ \mathrm{mm}$——比果皮还薄。
:::
:::

::: exercise S 波的影 {level=1 check="103"}
在什么的震中的距离直接的 S 波停止记录、而那证明什么？
::: solution
$103^\circ$、到与核相切处的角距离。任何一个到达更远的 S 射线必须穿过核、而没有穿过：外核有零的剪切强度。P 波的影从 $103^\circ$ 跑到 $142^\circ$、而 P 在它之外回来、因为 P *确实*透进液体。
:::
:::

::: exercise 层的体积 {level=1 check="16"}
地球的体积的什么部分在核中（半径 $3480\ \mathrm{km}$、$R = 6371\ \mathrm{km}$）？
::: solution
$(3480/6371)^3 = 0.546^3 = 0.163$、所以体积的 $16\%$、而质量的 $32\%$——核比整个行星的平均密度大一倍、而地幔相应地比均值更轻。
:::
:::

::: exercise 核的斯涅尔 {level=2 check="36"}
取在核幔的边界之上 $V_P = 13.7\ \mathrm{km\,s^{-1}}$、而在之下 $8.0\ \mathrm{km\,s^{-1}}$。对一条以 $90^\circ$ 掠射入射的射线、求进入核的透射的角度。
::: solution
$\sin\theta_t = 8.0/13.7 = 0.584$、所以 $\theta_t = 35.7^\circ$、约 $36^\circ$。射线在一个单步中向半径弯曲 $54^\circ$、那是有一个影区的整个的原因。
:::
:::

::: exercise 克拉珀龙等值面的起伏 {level=2 check="34"}
在一个热的地幔的柱之下、在 $410\ \mathrm{km}$ 的地幔比平均值高 $350\ \mathrm{K}$。带着 $\mathrm{d}P/\mathrm{d}T = +3.3\ \mathrm{MPa\,K^{-1}}$ 而 $\rho g = 34.3\ \mathrm{kPa\,m^{-1}}$、求 $410$ 的深度移动。
::: solution
$\Delta P = 3.3\times10^{6}\times350 = 1.16\times10^{9}\ \mathrm{Pa}$、所以 $\Delta z = 1.16\times10^{9}/3.43\times10^{7} = 34\ \mathrm{km}$ 更深。热的地幔*加深*一个正的斜率的不连续面、而*变浅* $660$、所以一个柱产生一个特征的深的 $410$ 与浅的 $660$ 的一对、那是在夏威夷与冰岛之下观测的。
:::
:::

::: exercise 转动惯量 {level=2 check="0.33"}
对一个均匀密度的地球计算 $I/MR^2$、而解释为什么真实的 $0.3308$ 排除那个模型。
::: solution
对一个均匀的球 $I = \tfrac{2}{5}MR^2$、所以 $I/MR^2 = 0.40$。地球的 $0.33$ 意味着质量向中心集中；一个带着一个 $3480\ \mathrm{km}$ 的、$11{,}000\ \mathrm{kg\,m^{-3}}$ 的核的两层的模型给 $0.346$、而只有一个密度在中心升到 $13{,}000\ \mathrm{kg\,m^{-3}}$ 的核才能重现 $0.33$。自转、从春分点的进动测量、因此是最深的 $1000\ \mathrm{km}$ 的一个探针。
:::
:::

::: exercise 热预算 {level=3}
表面的热流是 $47\ \mathrm{TW}$；在地壳的放射性生热是 $8\ \mathrm{TW}$、而在地幔是 $12\ \mathrm{TW}$；流出核的热流估计为 $10\ \mathrm{TW}$、其中 $3\ \mathrm{TW}$ 由内核生长释放、而 $2\ \mathrm{TW}$ 由轻的元素的沉降。闭合预算、而陈述剩余必须是什么。
::: solution
来源：$8 + 12 = 20\ \mathrm{TW}$ 放射性的、加 $10\ \mathrm{TW}$ 从核、其中 $5\ \mathrm{TW}$ 是核的原始热与潜热。已计入的总额：$30\ \mathrm{TW}$。剩余、$17\ \mathrm{TW}$、必须是地幔的长期冷却、加仍在释放的原始热。

剩余是有意思的数字。如果它全是地幔的冷却、地幔以 $0.11\ \mathrm{K\,Myr^{-1}}$ 冷却、而会在 $4.5\ \mathrm{Gyr}$ 之前热 $500\ \mathrm{K}$——太热、因为那会使太古代的地壳是镁铁质的、很厚的、而岩石记录并不完全支持这一点。通常的调和是一个更低的核的热流（地幔底部的一个热绝缘层、或一个稳定分层的外核层）、一个更高的放射性预算（被地中微子的测量拒绝）、或黏度随冷却而增大的地幔、所以散热随行星老化而减慢。三个都是活跃的研究、而三个都能用同样的数据检验：核的冷却速率、从元古宙的场的强度的古地磁的记录测量。
:::
:::

::: exercise 推导影区 {level=3}
对带着在半径 $r_c$ 的急剧的速度下降、而在它之上恒定的速度的半径 $R$ 的球、证明一条掠核的射线到达一个角距离 $\Delta_0 = 2\arcsin(r_c/R)$、而对 $r_c/R = 0.546$ 评估 $\Delta_0$。为什么观测的影区的内缘是 $103^\circ$、而不是这个值、而核的半径实际如何从它得到？
::: solution
对一条掠核的射线、球的几何给从源的角距离到每一边的切点为 $\arcsin(r_c/R)$、所以一条只走地幔的射线能到达的最内的距离是沿折射路径量得的 $\Delta = 2\arcsin(r_c/R)$。带着 $r_c/R = 0.546$、这给一个从不进入核的射线 $\Delta = 2\times33.1^\circ = 66^\circ$、而观测的 $103^\circ$ 更大、因为地幔的速度梯度在射线到达核之前向下弯曲射线；正确的处理穿过地幔的速度剖面积分球形的斯涅尔的不变量 $p = r\sin\theta/V(r)$。

看观测约束什么的干净的方法是把问题反演：对一个给定的地幔的速度剖面、计算 $\Delta_\text{shadow}(r_c)$、而找到再现在 $103^\circ$ 的 $r_c$。古登堡在 1926 年恰好做了这个、而得到 $3470\ \mathrm{km}$；现代自由振荡数据给 $3480.0 \pm 0.9\ \mathrm{km}$。这个练习的真正的教训是影区的角度不是一个半径的直接测量、而是一个半径*与*一个速度剖面一起的——那是为什么内部只在整个的速度剖面、不是一个不连续面、反演之后才被固定。
:::
:::

::: exercise 内核的年龄 {level=3}
核必须从它分异的时候的温度冷却了 $1000\ \mathrm{K}$ 的量级、内核才开始冻结。把核的热容取为 $Mc_p = 1.85\times10^{24}\times800\ \mathrm{J\,K^{-1}}$、而求 $10$、$15$ 与 $50\ \mathrm{TW}$ 的核热流对应的冷却时间。与地球的年龄、而发电机 $3.5\ \mathrm{Gyr}$ 的古老比较、而讨论。
::: solution
冷却的时间是 $\tau = Mc_p\Delta T/\dot Q$：
$$
\tau = \frac{1.48\times10^{27}\times1000}{\dot Q} =
\begin{cases}
4.7\ \mathrm{Gyr} & \dot Q = 10\ \mathrm{TW}\\
3.1\ \mathrm{Gyr} & \dot Q = 15\ \mathrm{TW}\\
0.9\ \mathrm{Gyr} & \dot Q = 50\ \mathrm{TW} 。
\end{cases}
$$
在低端核几乎不能冷却到足以使一个内核在今天的之前存在、那使内核比发电机年轻几倍；在高端核和地球一样老、而核本来应该现在冻结成固体、除非轻的元素与潜热供给一个补偿的能源。佯谬是真实的、而叫"内核年龄问题"：核必须冷却了约 $1000\ \mathrm{K}$、而地幔底部的导热盖限制热流到使这尴尬的值。

三个解决是当前的。核也许热得多、而液相线相应地更高、所以内核是年轻的——也许只 $0.5$–$1.5\ \mathrm{Gyr}$、那与一个强的、现代型的发电机在元古宙的记录中出现、在一段漫长的弱而神秘的磁场时期之后、是一致的。核的热传导率在过去也许更低、或轻的元素的家底更大、所以成分对流早开始、而热对流晚。或在地幔的底的"盖"也许比假设的更绝缘、在那个情况地幔冷却缓慢、而核仍然热。不确定是几倍的、而它在核之外重要：内核的年龄设定地球发电机的能量预算何时改变、那记录在古地磁长期变化、而大陆的真正极移中。
:::
