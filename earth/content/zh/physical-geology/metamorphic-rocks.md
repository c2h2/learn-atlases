1795 年，爱丁堡的医生与化学家丹尼尔·卢瑟福——那个发现了氮气的人——把一块石灰岩放进一个炉子，在高温下保持十二个小时。出来的是硬的、糖粒状而互锁的：他制造了一个大理岩，而在一个下午做了本应由自然在深时中做的事。卢瑟福的实验是变质作用的创始的演示，因为它分开了这个学科赖以存在的两件事：一块岩石的*物质*，它已经是石灰岩；与它的*结构与矿物组合*，炉子改变了它们。

变质岩是在仍然是固体的时候、在埋藏环境的成岩的炉子与熔点之间的某处被改变的岩石。它们构成了可见的大陆地壳的大部分——山系的核心、地盾、已熄灭的弧的根——而它们是我们拥有的关于深地壳的唯一直接的样品，而深地壳我们钻不进去。山坡上的一个片岩是一个来自 $20\ \mathrm{km}$ 深度的标本，由侵蚀给你送来，而它在它的矿物里带着它所经历的压力与温度的记录，而如果你细心，也带着它在那里待了多久、而它朝哪个方向移动。

## 变质作用是什么，以及不是什么

::: definition 变质作用、原岩、级 {#def-metamorphism}
**变质作用**是一个固体的岩石向与它形成时不同的温度、压力与化学环境的矿物学与结构的重新平衡。原来的岩石是**原岩**；重新平衡的强度是**级**，从低到高。这个过程在下面被**成岩作用**（埋藏的低温的、常常不可逆的物理与化学变化，约 $<100$–$150\ ^\circ\mathrm{C}$）限定，在上面被**正变质作用**限定，后者在岩石开始熔融之处结束——湿的或干的系统的**固相线**，看哪一个适用（[[physical-geology/igneous-rocks#prop-threeways]]）。在这些极限之间，岩石基本上是固体的，而其中一切可读的东西都改变。
:::

"仍然是固体"的三个结果是值得陈述的，因为它们是使变质岩可读的东西：

- **做功的是扩散，不是流动。**离子穿过颗粒与沿颗粒边界迁移几毫米，所以相隔一厘米的层能彼此反应，而相隔一千米的层不能。所以变质岩是局域的平衡系统，而一个手标本常常是一个完整的平衡组合物。
- **结构是被继承而被叠加的。**一个从砂岩来的片麻岩可能仍显示层理；一个从石灰岩来的大理岩可能仍显示化石（在重结晶抹去它们之前）。在两个组构都幸存之处，较老的那个作为包裹体、作为残余的层、或作为两组定向的矿物之间的一个角被保存。
- **岩石保有一个冷却的记忆。**许多变质的矿物在一个特征的温度停止交换（它们的*封闭温度*），所以一个变质的年龄通常是一个冷却的年龄，而同一个岩石中不同的矿物系统给出不同的年龄——[[geochemistry/geochronology]] 的基础。

## 介质

::: definition 静围压与差异应力 {#def-stress}
**静围压（静岩压力）**是平均的应力，$P \approx \rho g z$，对典型的地壳岩石它每千米深度增加约 $27\ \mathrm{MPa}$；它有利于重的矿物，而它是地质气压测定所测量的。**差异应力**是对平均的偏离，而它使矿物垂直于最大的缩短生长——也就是说，它使一个岩石变成叶理的。一个岩石能是高压而低应力的（一个俯冲通道的底）或高温而低压的（一个浅的花岗岩的顶），而这两种组合产生完全不同的岩石。
:::

四种介质供给这些变化，而它们组合：

1. **热。**在一个典型的大陆地温梯度 $25$–$30\ ^\circ\mathrm{C}\,\mathrm{km^{-1}}$ 下埋藏，在 $20\ \mathrm{km}$ 给出 $600\ ^\circ\mathrm{C}$。侵入的岩浆在局部供给多得多的热：一个 $1200\ ^\circ\mathrm{C}$ 的玄武岩对着 $200\ ^\circ\mathrm{C}$ 的围岩，以一个由热扩散设定的速率把一个传导的变质晕向外驱动。
2. **压力。**埋藏，而在碰撞带中，一个随后缓慢变热的地壳的加厚。
3. **差异应力**，来自汇聚或伸展，它产生叶理与线理，而把变形集中到剪切带中。
4. **流体**，主要是水，它以比固体的扩散快几个数量级的速率输运离子、使矿物水化，而能改变整体的化学（交代作用）。一个变质晕中的干的岩石可能改变矿物学而不改变成分；一个湿的能被化学地重写。

::: example 一个接触变质晕有多宽？ {#ex-aureole}
一个 $1200\ ^\circ\mathrm{C}$ 的板状的花岗岩被就位在 $200\ ^\circ\mathrm{C}$ 的围岩中。以热扩散率 $\kappa = 10^{-6}\ \mathrm{m^2\,s^{-1}}$、把穿透的长度取为 $x = 2\sqrt{\kappa t/\pi}$，热异常在 $10^3$、$10^4$、$10^5$ 年中穿透多远？
::: solution
$$
x = 2\sqrt{\frac{\kappa t}{\pi}} = \{200,\ 630,\ 2000\}\ \mathrm{m} 。
$$
在花岗岩的岩体周围观测到的接触变质晕典型地是几百米到几千米宽，这说的是一件比宽度更有意思的事：它说这个侵入体热了 $10^4$–$10^5$ 年，不是十年，而这个变质晕记录一个*持续时间*不亚于记录一个温度。它也解释了为什么岩墙周围的变质晕是几厘米宽，而为什么一个大的层状侵入体能把它的顶烘焙一百万年。

同一个算术反过来解释了大多数沉积盆地中没有变质作用：在 $25\ ^\circ\mathrm{C}\,\mathrm{km^{-1}}$，一个 $5\ \mathrm{km}$ 的埋藏给出 $145\ ^\circ\mathrm{C}$，充其量是一个暗带。埋藏的变质需要的不只是埋藏；它需要一个热的梯度、一个侵入体、或两者。
:::
:::

## 相：给压力–温度的框命名

::: definition 变质相 {#def-facies}
一个**变质相**是共享一个平衡的矿物组合、在一个压力与温度的范围上的一组岩石成分。一个简单 $\mathrm{K_2O\text{-}FeO\text{-}MgO\text{-}Al_2O_3\text{-}SiO_2\text{-}H_2O}$ 系统的泥质岩，例如，在绿片岩相中携带绿泥石 + 白云母 + 石英，而在更高的级上携带黑云母 + 石榴石 + 十字石 + 蓝晶石。经典的相，在中等压力下按温度递增，是**沸石**、**绿纤石–钠闪石**、**绿片岩**、**角闪岩**与**麻粒岩**；一个高压、低温的相系列，**蓝片岩**与**榴辉岩**，定义了俯冲；而极低压力、高温的**角岩**相定义了接触的变质晕。
:::

::: proposition 一个岩石有相律所允许的矿物那么多，而不多 {#prop-mincount}
对一个其化学能用 $C$ 个组分描述的岩石，在给定的压力与温度下能共存的相的数目至多是 $C$。所以一个 $C = 6$（KFMASH）的简单泥质岩至多能保持六个矿物在平衡中；一个有八个相存在的岩石不在平衡中。
:::

::: proof
由吉布斯相律，$F = C - P + 2$（[[physical-geology/minerals#thm-phaserule]]）。变质的岩石学家在固定的压力与温度下工作——那是一个 $P$–$T$ 图所假设的——这移走两个自由度，留下 $F = C - P$。平衡只能在 $F \ge 0$ 时维持，所以 $P \le C$。∎
:::

这不是为了自己的记账。这是一个薄片是一张定量的图的理由：在一个 KFMASH 的泥质岩中有六个相，这个组合是*不变的*，而每一个矿物的成分由整体的成分单独固定，所以测量它们检验平衡的假设。它也是为什么在一个岩石中找到八个矿物是一个发现：它意味着这个岩石记录一条*路径*，较早的世代在较晚的世代内部幸存，而路径能被变成一条山带的历史（[[mineralogy-petrology/pt-paths]]）。

### 巴罗的序列

在泥质的岩石中——泥岩，化学上最有反应的所有原岩——级的增加产出一个可预报的*指示矿物*的阶梯，每一个在一个特征的反应出现，而每一个定义一个**等值线**，它在一张地图上它的首次出现的线。按顺序：

$$
\text{chlorite} \to \text{biotite} \to \text{garnet} \to \text{staurolite} \to \text{kyanite} \to \text{sillimanite} ，
$$

苏格兰高地经典的巴罗分带，由乔治·巴罗在 1893 年只用手工标本与地图建立。同一个阶梯在野外是一条穿过地壳的剖面：绿泥石在几千米，蓝晶石在 $25$–$30\ \mathrm{km}$、$600\ ^\circ\mathrm{C}$ 以上。

::: example 从指示矿物到深度与热流 {#ex-kyanite}
一个泥质岩含蓝晶石、十字石、石榴石与白云母。蓝晶石在 $550\ ^\circ\mathrm{C}$ 大约需要 $0.6\ \mathrm{GPa}$。估计变质的深度，而如果表面梯度是稳定的，所意味的热流。
::: solution
从静岩压力得深度：
$$
z = \frac{P}{\rho g} = \frac{6\times10^{8}}{2800\times9.81} = 22\ \mathrm{km} 。
$$
以 $20\ ^\circ\mathrm{C}$ 的表面温度，梯度是 $(550-20)/22 = 24\ ^\circ\mathrm{C}\,\mathrm{km^{-1}}$，而传导的热流
$$
q = k\,\frac{\mathrm{d}T}{\mathrm{d}z} = 2.5\times24\times10^{-3} = 60\ \mathrm{mW\,m^{-2}} 。
$$
这接近现代全球的大陆热流的平均，这是一个有用的合理性的检验：巴罗的变质通常需要一个略高于今天的大陆平均的梯度，而它被发现于地壳被加厚而被加热的地方、或被侵入的地方、或两者。也请注意答案是*一个范围*，不是一个点：一个流体的超压会减少静岩的估计，而一个在埋藏中生长、而在减压中幸存的蓝晶石可能记录最大值，不是平均值。
:::
:::

## 温度计与气压计

::: proposition 交换反应是温度计 {#prop-thermometer}
对一个阳离子交换的反应，例如
$$
\mathrm{Fe^{2+}_{(grt)} + Mg_{(bi)} \rightleftharpoons Mg_{(grt)} + Fe^{2+}_{(bi)}} ，
$$
平衡要求 $\Delta G^\circ = -RT\ln K_d$，其中 $K_d$ 是两个阳离子在两个矿物之间的分配系数。把 $\Delta G^\circ = \Delta H^\circ - T\Delta S^\circ$ 写出、而把焓与熵的变化在变质的范围上取为与温度无关，给出
$$
T = \frac{-\Delta H^\circ / R}{\ln K_d - \Delta S^\circ/R} ，
$$
所以一个 $K_d$ 的测量是一个温度的测量。
:::

::: proof
在平衡时，交换组分的化学势在两个相中相等，所以 $\Delta G = \Delta G^\circ + RT\ln Q = 0$；在平衡时 $Q = K_d$，于是 $\ln K_d = -\Delta G^\circ/RT = -\Delta H^\circ/RT + \Delta S^\circ/R$。对 $T$ 求解给出那个表达式。整个方法依赖一个假设——两个矿物确实平衡了，而它通过检验它们是否接触、是否没有环带、而同一个岩石中其他矿物对是否给出同样的答案来检验。∎
:::

::: example 石榴石–黑云母温度计 {#ex-gbtherm}
对石榴石与黑云母之间的 Fe–Mg 交换，取 $\Delta H^\circ = -29.9\ \mathrm{kJ\,mol^{-1}}$、$\Delta S^\circ = -24.0\ \mathrm{J\,mol^{-1}\,K^{-1}}$。一个片岩有 $(\mathrm{Fe}/\mathrm{Mg})_\text{grt} = 0.35$、$(\mathrm{Fe}/\mathrm{Mg})_\text{bi} = 0.07$。求变质的温度，以及 $K_d$ 中一个 $10\%$ 的误差的效应。
::: solution
$K_d = 0.35/0.07 = 5.0$，所以
$$
T = \frac{29\,900/8.314}{\ln 5.0 + 24.0/8.314} = \frac{3596}{1.609 + 2.887} = 800\ \mathrm{K} = 527\ ^\circ\mathrm{C} ，
$$
确实地在角闪岩相中。对敏感度，微分：$\mathrm{d}T/\mathrm{d}\ln K_d = -T^2/(\Delta H^\circ/R)\approx -T^2/3596$，在 $800\ \mathrm{K}$ 是每单位的 $\ln K_d$ $-178\ \mathrm{K}$。一个 $K_d$ 中 $10\%$ 的误差是 $\ln K_d$ 中的 $0.1$，所以约 $18\ \mathrm{K}$。

这是一个好的测温确定的诚实的误差收支：$\pm 20$–$50\ ^\circ\mathrm{C}$，主导它的不是电子探针（它把 $\mathrm{Fe}/\mathrm{Mg}$ 测到百分之一），而是标定、是三价/二价铁的划分是否正确、而首先是这一对是否真的平衡了。同一个论证的结构——测量一个比值、假设平衡、传播敏感度——是这个学科中每一个温度计与气压计的基础，包括同位素的那些（[[geochemistry/isotopes-water-carbon]]）。
:::
:::

## 结构：一个岩石如何显示是什么挤压了它

::: definition 叶理、线理、变斑晶 {#def-fabric}
一个**叶理**是一个平面的组构，由板状或长状的矿物的平行排列、或由明暗层的交替（一个片麻岩中的条带）产生。它在云母与绿泥石的 $ab$ 面垂直于最大的缩短时形成，所以一个叶理是一个应力场的记录，不是层理的记录——尽管在褶皱的地形中两者常常近平行，而这个区别必须被证明。一个**线理**是线状的对应物：定向的角闪石的柱、被拉长的颗粒、或矿物的纤维。一个**变斑晶**是一个在更细的基质中生长的、类斑岩的大晶体（石榴石、十字石、蓝晶石）；它的包裹体与它的加大记录了在它生长之前与之后发生的变形。
:::

一个泥质岩随级增加的结构阶梯很好地说明一个名字携带多少：**板岩**（细的、板状劈理、看不见矿物）、**千枚岩**（发亮的、透镜下可见云母、揉皱）、**片岩**（可见的云母、强烈叶理、变斑晶常见）、**片麻岩**（成分的条带、云母被分离到暗的层中、长石与石英在明的层中），而在顶端**混合岩**，部分熔融已经开始而岩石一部分是火成的、一部分是变质的。

两个结构值得特别的注意。**糜棱岩**是韧性的剪切带的细粒的、强烈叶理的岩石，而它是深地壳吸收位移的方式；它的运动学的指示告诉你这个断层朝哪个方向移动，在你能看见的一切之下几千米。**角岩**是接触的变质晕的细的、块状的、无叶理的岩石——一个没有应力的热的产物，而卢瑟福的大理岩就是一个。

::: example 为什么榴辉岩下沉 {#ex-eclogite}
密度 $2900\ \mathrm{kg\,m^{-3}}$ 的玄武岩在高压下转变为密度 $3500\ \mathrm{kg\,m^{-3}}$ 的榴辉岩（石榴石 + 绿辉石），在 $3300\ \mathrm{kg\,m^{-3}}$ 的周围地幔中。求一个 $30\ \mathrm{km}$ 厚的榴辉岩质的板块每平方米的浮力，而解释地质的结果。
::: solution
对地幔的超额密度是 $200\ \mathrm{kg\,m^{-3}}$，给出每单位面积的向下的力
$$
\Delta\rho\, g\, h = 200\times9.81\times3\times10^{4} = 59\ \mathrm{MPa} 。
$$
（与地幔相比；对着 $2700\ \mathrm{kg\,m^{-3}}$ 的正常的地壳岩石，驱动的差是 $800\ \mathrm{kg\,m^{-3}}$，或 $235\ \mathrm{MPa}$。）几十兆帕的体力与地壳的强度、与一个俯冲界面上的摩擦相当，所以一个俯冲的大洋地壳的下部转变为榴辉岩，是一个自我维持的俯冲的一个可信的触发——板块开始把自己往下拉。

同一个数字从另一个方向解释一个难题：超高压的岩石——那些携带只在 $3$–$6\ \mathrm{GPa}$、即 $100$–$180\ \mathrm{km}$ 稳定的地壳矿物的岩石——在地表被找到，在窄的带中、而构造的厚度是米。重的岩石从地幔的深度被推上来到薄的薄片内部，这意味着俯冲的地壳被部分地折返，而机制（更年轻的、含水的、细粒的物质的浮力、通道流、或被上覆的板块拖曳）仍在争论（[[structural-geology/orogens]]、[[geophysics/flexure]]）。
:::
:::

::: warning "变质岩更硬，所以它们更强"
重结晶通常使一个岩石更难划伤、在机械上更难破碎，这就是为什么一个板岩的屋顶持久而一个土坯不持久。但在对工程与灾害要紧的方式上，变质岩常常比它们的原岩*更弱*：板岩的劈理与片理是边坡沿之破坏的薄弱面，富云母的片麻岩容易剪切，而糜棱岩与断层泥正是在活动断层中集中应变的材料。褶皱的与叶理的地形的大的滑坡——以及许多在片岩中的路堑的不稳定——沿着叶理，不沿着岩石类型（[[geomorphology/hillslopes]]、[[natural-hazards/landslides]]）。
:::

::: quiz
两个有相同整体成分的岩石，一个是在一个碰撞的高原之下被埋到 $25\ \mathrm{km}$ 的页岩，一个是在一个俯冲带之下被带到 $90\ \mathrm{km}$ 深度的玄武岩，两者最终都在 $500\ ^\circ\mathrm{C}$。它们有什么不同？
- [ ] 什么也没有：同样的温度，所以同样的矿物。
- [x] 压力非常不同，所以组合不同——页岩记录一个高温的、中等压力的相，而玄武岩记录一个高压的、低温的相。
- [ ] 玄武岩会熔融，页岩不会。
- [ ] 只有年龄不同。
::: solution
温度单独不决定一个组合；$P$ 与 $T$ 一起决定。在 $25\ \mathrm{km}$，压力约 $0.7\ \mathrm{GPa}$，而岩石坐在角闪岩相中；在 $90\ \mathrm{km}$，它近 $2.6\ \mathrm{GPa}$，而在 $500\ ^\circ\mathrm{C}$，在榴辉岩相中——重的，而以石榴石与绿辉石、不是以斜长石与角闪石为特征。两者都不一定熔融了，因为俯冲的地温线是冷的：这正是相这个概念的要点，而榴辉岩存在的理由。
:::
:::

::: history
乔治·巴罗是苏格兰地质调查局的一名测量员，在 1880 年代在格兰皮安高地工作，而通过制图哪一种指示矿物首先在何处出现——绿泥石、黑云母、石榴石、十字石、蓝晶石、而在更北的硅线石——他在没有任何热力学的情况下定义了一个碰撞的造山带的分带，因为相律只在 1876 年发表，而相的概念刚由芬兰的岩石学家雅科·塞德霍尔姆引入。他 1893 年的论文是一个基于野外的推断的模型：这些带是等值线，它们不沿着层理，而它们因此记录了在岩石沉积*之后*发生的某件事。定量的装置来得更晚、而从别处来：珀西·布里奇曼的高压实验（诺贝尔奖，1946）使在实验室中跑变质的反应成为可能；埃斯科拉，然后是法伊夫、特纳与费尔胡根把相变成一个 $P$–$T$ 的网格；而从 1960 年代起，在地壳岩石中发现柯石英与金刚石证明了实验室的网格是真实的——一些岩石确实去过 $100\ \mathrm{km}$ 而回来了。
:::

## 通向何处

相与 $P$–$T$ 路径是 [[mineralogy-petrology/metamorphic-reactions]] 与 [[mineralogy-petrology/pt-paths]] 的语言，那里 [[#prop-mincount]] 的相律被用来计算组合、而不是数它们。使叶理形成的变形是 [[structural-geology/strain]] 与 [[structural-geology/shear-zones]] 的主题；驱动区域变质的热在 [[geophysics/heat-flow]] 中被定量；而把变质的矿物用作钟的用途在 [[geochemistry/geochronology]] 中被处理。

::: summary 关键要点
- 变质作用是固体状态中的重新平衡，下面被成岩作用限定、上面被固相线限定；原岩的化学大体被保留，它的矿物与结构不被保留。
- 静围压记录深度，差异应力记录构造的力，而流体控制这些变化走多快、走多远。
- 一个相是 $P$–$T$ 空间中的一个框：同样的整体成分在不同的框中给出不同的矿物，这就是为什么一种岩石能记录两个非常不同的环境。
- 在固定的 $P$ 与 $T$ 下的相律把共存的矿物的数目封顶在 $C$；比这更多的相意味着一条路径，不是一个平衡。
- 巴罗的指示矿物的阶梯——绿泥石、黑云母、石榴石、十字石、蓝晶石、硅线石——是一条穿过地壳的剖面，而等值线是它在图上的线。
- 地质温度计是伪装成平衡常数：测一个阳离子的比值、假设平衡、传播敏感度（一个好的对是 $\pm 20$–$50\ ^\circ\mathrm{C}$）。
- 接触的变质晕按 $\sqrt{t}$ 生长，所以它们的宽度是一个持续时间不亚于一个温度；榴辉岩的密度是一个几十兆帕的体力，而这足以移动一个板块。
- 变质岩是硬的而常常是弱的：叶理是真实的边坡与真实的断层破坏所沿的面。
:::

## 练习

::: exercise 从压力得深度 {level=1 check="14"}
一个岩石显示一个在 $0.4\ \mathrm{GPa}$ 稳定的组合。取 $\rho = 2850\ \mathrm{kg\,m^{-3}}$，以千米估计变质的深度。
::: solution
$z = P/\rho g = 4\times10^{8}/(2850\times9.81) = 14\ \mathrm{km}$。如果这个岩石反而以流体压力承担着载荷的 $30\%$，静岩的估计就会按同样的分数高读，给出 $11\ \mathrm{km}$：在一个流体压力有争议的带中，两个相的解释之间的差别。
:::
:::

::: exercise 相的阅读 {level=1 check="2"}
给下列的相命名：(a) 一个蓝闪石–绿纤石–绿帘石的片岩，(b) 一个无斜长石的石榴石–角闪石的岩石，(c) 一个在辉绿岩岩床旁边的块状的细粒的岩石，(d) 一个硅线石–钾长石的片麻岩。有几个不同的 $P$–$T$ 机制被代表？
::: solution
(a) 蓝片岩——高压、低温、俯冲。(b) 榴辉岩——高压、更高的温度。(c) 角岩——接触的变质，低压、高温。(d) 麻粒岩或高角闪岩相——区域的、高温。四个机制，而这道题的要点是一个单一的手工标本的名字是一个关于 $P$ 与 $T$ 的陈述，不是关于原岩的。
:::
:::

::: exercise 相律的记账 {level=1 check="6"}
一个泥质岩在六组分的系统 KFMASH 中描述。在固定的压力与温度下，平衡的矿物的最大数目是多少？这样一个岩石的一个薄片显示石英、白云母、黑云母、石榴石、十字石、蓝晶石与绿泥石。那意味着什么？
::: solution
$P \le C = 6$。七个相意味着这个岩石不在平衡中：绿泥石几乎肯定是一个较晚的、较低的级的叠加，在蓝晶石上，或一个在石榴石内部保存的包裹体的组合。正确的阅读是一条减压的路径，不是计数中的一个错误。
:::
:::

::: exercise 测温 {level=2 check="724"}
用 [[#ex-gbtherm]] 的标定，求 $(\mathrm{Fe}/\mathrm{Mg})_\text{grt} = 0.42$、$(\mathrm{Fe}/\mathrm{Mg})_\text{bi} = 0.0525$ 的温度。
::: solution
$K_d = 0.42/0.0525 = 8.0$，所以 $T = 3596/(\ln 8.0 + 2.887) = 3596/(2.079+2.887) = 724\ \mathrm{K} = 451\ ^\circ\mathrm{C}$。一个更大的 $K_d$ 对应一个更低的温度是预期的行为：在更低的温度，两个矿物把铁与镁分得更强。如果同一个岩石从一个不同的石榴石的核给出 $800\ \mathrm{K}$，你有一条冷却的路径，而这两个数字是一条 $T$–$t$ 历史的开始。
:::
:::

::: exercise 一个巴罗地区的热流 {level=2 check="55"}
一个地区在 $25\ \mathrm{km}$ 的深度达到 $650\ ^\circ\mathrm{C}$。对 $k = 2.2\ \mathrm{W\,m^{-1}\,K^{-1}}$ 计算梯度与传导的热流，而与 $65\ \mathrm{mW\,m^{-2}}$ 的现代大陆的平均比较。
::: solution
梯度 $= (650-20)/25 = 25.2\ ^\circ\mathrm{C}\,\mathrm{km^{-1}}$；$q = 2.2\times25.2\times10^{-3} = 55\ \mathrm{mW\,m^{-2}}$。无论哪种方式，答案都在今天的大陆平均的 1.5 倍之内，这是那个标准的论证：巴罗的变质*不*需要奇异的来源——只有加厚，加上一个维持几千万年的正常梯度，就够了。在梯度更高的地方，诊断的证据是一个配对的高温、低压的组合，或一群同构造的侵入体。
:::
:::

::: exercise 变质晕的宽度 {level=2 check="2"}
用 [[#ex-aureole]] 的标度，一个保持热 $10^5$ 年的岩体周围形成多宽的变质晕（单侧的，到 $600\ ^\circ\mathrm{C}$ 的等温线）？取 $\kappa = 10^{-6}\ \mathrm{m^2\,s^{-1}}$。
::: solution
$x = 2\sqrt{\kappa t/\pi} = 2\sqrt{10^{-6}\times3.15\times10^{12}/\pi} = 2.0\times10^{3}\ \mathrm{m} = 2\ \mathrm{km}$。把持续时间加倍到 $4\times10^5$ 年使宽度加倍，因为 $x \propto \sqrt{t}$；把持续时间四倍使它再加倍。这就是为什么大的、长命的岩体周围的变质晕是几千米宽，而为什么一个 $2\ \mathrm{m}$ 的岩墙不是这样，它在一年内热上就死了。
:::
:::

::: exercise 地温线的推导 {level=3}
从化学势的相等推导 [[#prop-thermometer]] 的交换反应的温度计，而证明所得的温度对一个 $K_d$ 中的误差的敏感度是 $\mathrm{d}T/\mathrm{d}\ln K_d = -T^2 R/\Delta H^\circ$。为什么交换的温度计在很低的级的岩石中失败？
::: solution
交换组分在两个相中的化学势的相等给出 $\Delta G^\circ = -RT\ln K_d$；代入 $\Delta G^\circ = \Delta H^\circ - T\Delta S^\circ$ 而重排给出 $T = (-\Delta H^\circ/R)/(\ln K_d - \Delta S^\circ/R)$。对 $\ln K_d$ 在固定的 $\Delta H^\circ$ 下微分给出
$$
\frac{\mathrm{d}T}{\mathrm{d}\ln K_d} = \frac{\Delta H^\circ/R}{(\ln K_d - \Delta S^\circ/R)^2} = \frac{T^2 R}{\Delta H^\circ} ，
$$
它对 $\Delta H^\circ < 0$ 是负的，如所观测：一个更大的 $K_d$ 意味着一个更低的温度。

交换的温度计在低级失败，有两个在方程中可见的理由。第一，当 $T$ 下降时敏感度 $T^2R/\Delta H^\circ$ 缩小，所以温度计原则上变得*更*精确——但第二，扩散指数地减慢，所以矿物停止交换，而测得的 $K_d$ 记录的是它们最后一次平衡时的温度，不是峰值。实践中失败的模式不是标定，而是平衡的假设：在低级，而在那些通过了这一对的封闭温度而冷却的岩石中，答案是一个冒充峰值温度的冷却年龄。
:::
:::

::: exercise 一个变质的质量平衡 {level=3}
一个 $1\ \mathrm{m^3}$（密度 $2700\ \mathrm{kg\,m^{-3}}$）的泥质岩按体积含 $60\%$ 的白云母。在一个进位的变质中，全部的白云母与石英反应，
$$
\mathrm{KAl_3Si_3O_{10}(OH)_2} + \mathrm{SiO_2} \longrightarrow \mathrm{KAlSi_3O_8} + \mathrm{Al_2SiO_5} + \mathrm{H_2O} ，
$$
释放它的结构水。估计每立方米释放的水的质量，而说出它去了哪里、做了什么。
::: solution
白云母 $\mathrm{KAl_2(AlSi_3O_{10})(OH)_2}$ 有摩尔质量 $396.3\ \mathrm{g\,mol^{-1}}$、而每个式单位含一个 $\mathrm{OH}$，所以水按质量是 $18/396.3 = 4.5\%$。岩石持有 $0.60\times2700 = 1620\ \mathrm{kg}$ 的白云母，所以这个反应每立方米释放约 $74\ \mathrm{kg}$ 的 $\mathrm{H_2O}$。

质量虽小，效应却大。按质量百分之几的水就足以使岩石的流体渗流，而在一个进位的造山带中，整个变质的柱在一个窄的温度窗口中释放水，这就是为什么变质的核常与超压流体、与石英脉、与固相线降低乃至熔融相伴——也因为水携带溶解的硅、碱与金属，还与脉状矿床相伴。它还把叶理面上的有效应力降低，降低量可达静岩载荷的很大一个分数，这是一个变质的核变成一个拆离断层的一种方式（[[structural-geology/shear-zones]]、[[earth-resources/magmatic-hydrothermal]]）。
:::
:::

::: exercise 从一个薄片得一条 $P$–$T$ 路径 {level=3}
石榴石变斑晶中含有石英包裹体。石英处于可测的残余压力之下，而寄主石榴石在弹性上比石英更刚。解释为什么包裹体压力会超过石榴石生长时的压力，并描述一条从石榴石核到边的路径能告诉你什么。
::: solution
当岩石被折返时，石榴石弹性地卸载，但石英的包裹体，被囚在坚硬的寄主中，无法按自己的意愿充分膨胀：它保持"超压"，像刚性盒内的一只气球。由拉曼光谱或 X 射线衍射测得的残余压力因此是捕获时压力的一枚化石，由一个弹性的模型校正，而它是深部地壳压力的少数几个直接力学记录之一。

因为石榴石分带地生长，核、幔、边记录相继的 $P$ 与 $T$：在一个先埋藏后折返的岩石中，核的包裹体的压力高于边的，而穿过晶体的包裹体压力轨迹是一条 $P$–$T$ 的路径。与同一生长带的测温结合，这给出那个顺时针或逆时针的环，它区分碰撞造山带中先埋藏后折返、与接触变质晕中先加热后冷却——山带与岩体之别，可从一颗晶体读出（[[mineralogy-petrology/pt-paths]]）。
:::
