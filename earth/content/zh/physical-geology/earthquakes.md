
在 1755 年 11 月 1 日、诸圣日的早晨、里斯本的大教堂挤满了人。在约 09:40、地面剧烈地摇晃了、按最好的记述、三到六分钟；墙裂开而倒下；烟囱倒进壁炉、把木头的房子点着；而逃到码头的人、正确地推理开阔的场地比一个建筑更安全、看着海水退去一千米或更多、然后作为淹没他们的浪回来。三天的火跟随。在一个也许 230,000–270,000 人的城市、死亡的人数通常放在 30,000–50,000。

地震几乎在一夜之间创造了地震学作为一门学科——庞巴尔侯爵向每一个教区散发一份问卷、问摇晃持续多久、建筑朝哪个方向倒下、而海是否移动、那是一个除了名字之外的有感地震调查——而它创造了这一章的主题的问题。里斯本在我们现在画的任何一个板块的边界附近都没有；断层在一百千米的近海；而城市建在柔软的河相沉积物、作为一个文艺复兴的首都。三个世纪之后我们能从它的海啸与它的强度计算那个地震的震级、而我们能说三个因素中哪一个杀了谁。地震学是研究一个看不见的源、够不着的岩石、以及无法直接观测的时间尺度、而它的第一原则是我们知道的一切都来自地面的运动。

## 源：一个粘住而滑动的断层



::: definition 震源、震中、走向、倾角与滑动角 {#def-quake-geometry}
**震源**（发震点）是破裂开始的点；**震中**是它到表面的投影；**震源深度**是震源的距离地面的高度。一个断层的平面由它的**走向**（其内一条水平线的罗盘方位）、它的**倾角**（它与水平成的角度）而滑动的**滑动角**（滑动矢量在走向线下方、在断层面内度量的角度）定向。**破裂的面积** $A$ 是实际滑动的面、而**平均滑动** $D$ 是穿过它的位移。
:::

::: proposition 弹性回跳：一个地震是被锁断层的失稳、不是一个新断层的创造 {#prop-rebound}
在两个块体在一个被摩擦锁住的断层上互相滑过的地方、应变以大地测量学测得的速率在围岩中积累。当断层上的剪切应力超过摩擦的强度、断层失败、岩石弹性地回跳、而释放的弹性应变能作为热出现、作为破裂能、而它几个百分点、作为地震的波。1906 的旧金山的地震是证明：1906 之前而在它之后重复的大地测量的测量显示圣安德烈亚斯的两侧块体*朝*它们 1906 之前的位置移动了几米、然后跳变。
:::

::: proof
剪切应变能密度是 $u = \tau^2/(2\mu)$、其中 $\tau$ 是剪切的应力、而 $\mu$ 是刚度。如果深部的一个断层是锁住的、远场继续以板块运动速率变形、而断层上的应力上升直到 $\tau = \tau_\text{friction}$；失败把应力降到一个剩余的值、而应力降 $\Delta\tau$ 在破裂面积 $A$ 与滑动 $D$ 上释放。

做的功是初始的与最终的应力的均值乘滑动乘面积、所以可用的能量是
$$
E \approx \tfrac{1}{2}\,\Delta\tau\, D\, A 。
$$
典型的地壳地震 $\Delta\tau \sim 1$–$10\ \mathrm{MPa}$、$D \sim 1\ \mathrm{m}$、$A \sim 10^{9}\ \mathrm{m^2}$、给出 $E \sim 10^{15}\ \mathrm{J}$、其中只有几个百分点作为地震的波离开——其余的加热断层、而破碎岩石。观测到的辐射能只占可用能的一小部分是机理之所以可信的原因：一个摩擦的滑动把它的能量大部分转换成摩擦热、而只有一小部分转换成我们记录的波。∎
:::

::: example 一个 7 级地震的能量 {#ex-energy}
一个地震破裂 $1000\ \mathrm{km^2}$ 的面积、平均滑动 $2\ \mathrm{m}$、应力降 $3\ \mathrm{MPa}$。取 $\mu = 30\ \mathrm{GPa}$。求地震矩、矩震级、可用能量；若视应力为 $1.5\ \mathrm{MPa}$、再求辐射能量。
::: solution
$$
M_0 = \mu A D = 3\times10^{10}\times10^{9}\times2 = 6\times10^{19}\ \mathrm{N\,m} 、
$$
$$
M_\text{w} = \tfrac{2}{3}\left(\log_{10}M_0 - 9.1\right) = \tfrac{2}{3}(19.78-9.1) = 7.1 。
$$
可用能量 $\tfrac{1}{2}\Delta\tau D A = 0.5\times3\times10^{6}\times2\times10^{9} = 3\times10^{15}\ \mathrm{J}$、约 $700\ \mathrm{kt}$ 的 TNT。由视应力求辐射能量、
$$
E_r = \frac{\sigma_a M_0}{\mu} = \frac{1.5\times10^{6}\times6\times10^{19}}{3\times10^{10}} = 3\times10^{15}\ \mathrm{J} 、
$$
这里它恰好等于可用能量——所以 $1.5\ \mathrm{MPa}$ 的视应力意味着约 $3\ \mathrm{MPa}$ 的应力降、以及近乎完全的应力释放。真实地震的 $E_r/M_0$ 对应 $0.5$–$3\ \mathrm{MPa}$ 的视应力、而那个比值被用作一个地震辐射效率的代理量、这对地面摇晃与海啸的产生都很重要。
:::
:::

## 波：我们能测量的唯一的东西

::: definition 体波与面波 {#def-waves}
**P 波**（初至波、压缩波）最快、最先到达；它们是纵波、能穿过固体与液体。**S 波**（次至波、剪切波）更慢、是横的、不能穿过流体——液体的外核就是这样发现的（[[physical-geology/earth-interior]]）。**勒夫波**是被表层导引的水平偏振剪切波、对地基的破坏最大；**瑞利波**使地面在椭圆轨道上滚动、而主导那些摇晃高层建筑的长周期运动。地壳中的典型速度是 $V_P \approx 6\ \mathrm{km\,s^{-1}}$、$V_S \approx 3.5\ \mathrm{km\,s^{-1}}$；上地幔中是 $8.0$ 与 $4.5\ \mathrm{km\,s^{-1}}$。
:::

::: example 从一张地震记录定位震中 {#ex-locate}
一个台站记录到 P–S 的到时差为 $8\ \mathrm{s}$。取 $V_P = 6.0$、$V_S = 3.5\ \mathrm{km\,s^{-1}}$、求距离。定位震中需要多少个台站、第四个增加什么？
::: solution
对一条直线射线、$\Delta t = D/V_S - D/V_P = D(1/3.5 - 1/6.0) = D/8.4$、所以
$$
D = 8.4\times8 = 67\ \mathrm{km} 。
$$
"每秒钟的 S–P 时间八千米"的经验法则是这套算法的地壳版本、而那是一个地震学家能指着一道记录说出距离的原因。

一个台站给出一个可能的震中的圆；两个给出两个交点；**三个**给出一个唯一的点、那是经典的课堂作图。第四个台站使问题超定、而更重要的是、它使*深度*与发震时刻也能求解、因为带着四个未知数（$x$、$y$、$z$、$t_0$）你需要四个到时。现代的台网用数百个台站与一个速度模型、而在几秒内定位一个 $M_\text{w}\ 6$ 的地震——快得足以使第一批自动的警报在破坏性的 S 波到达之前抵达城市。
:::

## 震级与烈度、以及变大的两种方式

::: definition 震级与烈度 {#def-magnitude}
**震级**度量震源的尺寸。矩震级由地震矩定义、
$$
M_\text{w} = \tfrac{2}{3}\left(\log_{10} M_0 - 9.1\right), \qquad M_0 = \mu A D 、
$$
而它是唯一在大尺寸不饱和的震级标度。里克的近震震级 $M_\text{L}$ 在 1935 年为南加利福尼亚的地震定义、为在 $100\ \mathrm{km}$ 以微米为单位的最大记录振幅的 $\log_{10}$、对着距离改正。**烈度**度量*在一个场地的效应*：修订的麦卡利（MMI）与欧洲宏观地震烈度表从 I（无感）到 XII（完全的破坏）、而依赖震级、距离、深度、地质与建筑状况。一个地震有一个震级与一千个烈度。
:::

::: warning "一个 9 级的地震比一个 8 级的大一倍"
震级对振幅是对数的、而通过矩、对震源的尺寸也是对数的：一个震级相当于约的能量 $32$ 倍、而破裂面积与滑动乘积的 $10$ 倍。一个 $M_\text{w}\ 9.0$ 的地震释放约一个 $M_\text{w}\ 7.0$ 的一千倍的能——那是 2010 的海地地震（$M_\text{w}\ 7.0$、约 100,000–160,000 人死亡）与 2011 的东北的地震（$M_\text{w}\ 9.0$、约 22,000 人死于它产生的海啸）之间的差别。而因为*烈度*的格局也依赖深度、土与建造、两个数字不能互换：太子港被一个中等的、浅的、近的地震摧毁、而同样深度在日本的交通基础设施之下的一个 $M_\text{w}\ 8.0$ 会杀死少得多的人。
:::

::: example 比较两个地震 {#ex-compare}
2004 的苏门答腊地震有 $M_\text{w}\ 9.1$、而 2010 的海地地震 $M_\text{w}\ 7.0$。求地震矩的比与辐射的能量的比、而如果苏门答腊的破裂是 $1300\ \mathrm{km}$ 长、$200\ \mathrm{km}$ 宽、求给出它的矩需要的滑动。
::: solution
矩作为 $10^{1.5\Delta M}$ 标度、所以比是 $10^{1.5\times2.1} = 10^{3.15} \approx 1400$。辐射的能量类似地标度（约 $10^{3.2}$）、而经验法则是每个震级的能量 $32$ 倍、所以相差两级约等于相差一千倍。

对滑动、取 $M_0 = 10^{(1.5\times9.1+9.1)} = 10^{22.75} = 5.6\times10^{22}\ \mathrm{N\,m}$ 而 $A = 2.6\times10^{11}\ \mathrm{m^2}$：
$$
D = \frac{M_0}{\mu A} = \frac{5.6\times10^{22}}{3\times10^{10}\times2.6\times10^{11}} = 7.2\ \mathrm{m} 。
$$
发表的估计给出在最浅的部分 $10$–$15\ \mathrm{m}$ 的滑动、而一个接近 $15\ \mathrm{m}$ 的均值、所以算术低了二倍——那恰好是对一个浅的、热的、部分饱和的巨型逆冲断层取 $\mu = 30\ \mathrm{GPa}$ 的效果、那里的有效的刚度更小。把量级弄对而知道哪个假设是软的、就是全部的技术。
:::
:::

## 地震在哪里、而为什么那重要

全球的分布是使世界信服的那幅图：浅源地震描出大洋的中脊与转换的断层；浅源与深源地震描出环太平洋的环与阿尔卑斯–喜马拉雅地震带；而板块内部则几乎平静。那幅图的两个特征携带所有的力学。

瓦达蒂–贝尼奥夫带——地震从海沟向下倾斜到 $600$–$700\ \mathrm{km}$ 的深度、在 $10$–$75^\circ$ 的角度——是俯冲板块、由它自身的地震而显形。在约 $700\ \mathrm{km}$ 之下地震停止、那界定下降的板块的温度与流变学：在更大的深度、岩石已经韧到足以在不破裂的情况下变形。

板内地震是令人意外的那一类。1811–1812 年的新马德里序列在美国中部产生了三次 $M_\text{w}\ 7$ 级左右的大震、它们敲响了波士顿的教堂钟、使密西西比河倒流了数小时、并在 $10^5\ \mathrm{km^2}$ 的范围内留下了液化遗迹——在板块内部、远离任何边界。稳定的大陆内部并不强；它们只是安静、而它们的地震发生在由洋脊推力、地形以及冰川均衡调整所产生的远场应力所再激活的古老薄弱带上。因为古老的克拉通岩石冷、厚、而且在很大深度上仍是脆性的、同样的震级产生的破裂面积要大好几倍、而地面摇晃在再大上几倍的面积上：那是为什么北美洲中部与东部以及北欧地震活动中等而灾害很高。

::: example 多少大的地震、而多久一次？ {#ex-return}
对整个的地球取带着 $a = 8.3$ 而 $b = 1.0$ 的古登堡–里克特律。求在一个世纪中 $M_\text{w} \ge 8$ 的地震的期望的数目、而至少一个 $M_\text{w} \ge 9$ 的地震在五十年发生的概率。
::: solution
$N(M \ge 8) = 10^{8.3-8} = 2.0\ \mathrm{yr^{-1}}$、所以在一个世纪约 $20$ 个。对 $M \ge 9$、$N = 10^{-0.7} = 0.20\ \mathrm{yr^{-1}}$、全球的平均复发间隔 $5$ 年；至少一个在五十年、把发生作为一个泊松的过程处理的概率是
$$
P = 1 - e^{-0.20\times50} = 1 - e^{-10} \approx 1 。
$$
所以五十年内在*某处*发生一个特大地震几乎是确定的——那是要点、而也是陷阱。全球的速率不告诉你关于一个特定的断层的什么；对一个城市的有用的数字是在威胁它的那个断层上的速率、而那来自史前的地表的破裂的古地震的记录、不是来自仪器的目录、后者覆盖一个世纪、对着几个世纪到一个千年的复发的间隔。
:::
:::

## 为什么地震杀人、而什么改变那个数字

地面的运动不是一个单的数字。对一栋低的建筑重要的是峰值的地面的加速度与它的频率的内容；对一栋高的建筑或一个桥的、速度与持时；对一个坡或一个饱和的砂、强的循环的数目。四个因素在一个给定的震级乘或除破坏：

- **深度。** 一个在 $10\ \mathrm{km}$ 的深度的 $M_\text{w}\ 7.0$ 摇晃一个在 $100\ \mathrm{km}$ 的同样的事件的十分之一大的面积、而在中心的烈度几个单位更高。
- **土。** 软沉积会放大并延长摇晃、而且会共振。在 1985 年的 $M_\text{w}\ 8.0$ 米却肯地震中、距断层 $350\ \mathrm{km}$ 的墨西哥城老湖区的地面运动比基岩丘区放大了好几倍、而它的主导的约 $2\ \mathrm{s}$ 的周期匹配 10–15 层的建筑的自然的周期；超过 400 个建筑倒塌、而死亡者的估计达到 10,000。
- **建造。** 这是主导的项。2010 的 $M_\text{w}\ 7.0$ 的海地的地震、带着无筋的砌体、而一个密集的首都、也许杀死了 100,000–160,000 人；2010 的 $M_\text{w}\ 7.1$ 的青海的玉树的地震、可比的震级而浅得多、在一个人口稀少的盆地杀死约 2,200；而 2011 的 $M_\text{w}\ 5.8$ 的弗吉尼亚的地震、沿着美国东海岸被数千万人感到的、没有直接杀死人。差别在建筑状况、规范的执行力度、人口密度、而一天中的时间、不在震源的物理。
- **一天中的时间。** 1976 的唐山的地震（$M_\text{w}\ 7.5$、工业的城市、03:42、砖的建造）是本世纪最致命的地震之一、带着 242,000 人的死亡的官方数字、而更高的估计；2023 的 $M_\text{w}\ 7.8$ 与 $7.5$ 的土耳其的中南部与叙利亚的北部的地震、也在夜里、杀死了超过 50,000 人。

::: application 液化、而一种土型要付的代价 {#app-liquefaction}
饱和的、松的、冰期的砂与粉砂在摇晃时失去强度：颗粒重新排列、孔隙的压力上升、直到有效应力降到接近零、而土表现像流体。证据是清楚的——田里的喷砂冒水、在港中倾斜地立在液化粉砂里的船、以及下沉而非倾倒的建筑。工程的措施是移去土、压实它或灌浆它、或用桩穿过弱层、而它在一些国家负担得起、而在别的不、原因不是地质。液化也造成坡向一个自由的面的侧向的扩展、1964 年的新潟与 2018 年的基督城破坏管道与滨岸的正是它。
:::

::: quiz
两个同样震级的地震发生在同样的深度、一个在一个距城市 $60\ \mathrm{km}$ 的花岗岩高地之下、而另一个在一个距一座规模与建筑状况相当的城市 $60\ \mathrm{km}$ 的沉积盆地之下。哪个可能造成更多的破坏、而为什么？
- [ ] 高地下那个、因为坚硬的岩石传递更高的频率。
- [x] 盆地下那个、因为盆地沉积放大地面的运动、延长摇晃、而能液化。
- [ ] 它们会一样、因为震级与距离相等。
- [ ] 在不知道断层的类型时不可能说。
::: solution
盆地的放大是工程的地震学的记录最好的效应之一：厚的软的沉积能把地面的运动乘以二到十的因子、而延长强的摇晃、而它们还把液化与侧向扩展加进灾害清单。断层类型对辐射图案以及 P 能与 S 能之比是有影响的、但和一个场地相比它是一个二阶的效应。那是为什么地震小区划图——画的是土、不是断层——是灾害工作中对城市规划者最有用的成果。
:::
:::

::: history
地震研究始于问卷、而终于超导体。1755 年里斯本地震之后、庞巴尔侯爵的调查收集逐教区关于摇晃、火灾与海水行为的观测、而由此写成的记述是第一次宏观地震学研究；伊曼努尔·康德在同一年发表了第一篇关于地震成因的理论论文之一。东京帝国工科大学的约翰·米尔恩在 1880 年代建造了第一批实用地震仪、并凭他建立的台网、产生了第一批震中分布图；弹性回跳理论出自哈里·菲尔丁·里德发表于 1911 年、对 1906 年前后跨越圣安德烈亚斯断层的大地测量资料的分析。安德烈·莫霍洛维奇利用 1909 年的萨格勒布地震找到地壳–地幔的边界；本诺·古登堡与查尔斯·里克在 1941 年写成《地球的地震活动性》、定义了至今仍用的震级标度；釜泯宏在 1977 年用矩取代振幅、给出不饱和的震级。1990 年代的仪器革命——宽频带数字传感器、GPS、卫星干涉测量——把一门只有一张张单独记录的科学变成一门研究连续场面的科学、而使如今能为城市争取几十秒的地震预警系统成为可能。
:::

## 通向何处

波的传播、震源理论以及目录的统计连同其数学在 [[geophysics/elastic-waves]]、[[geophysics/seismic-structure]] 与 [[geophysics/earthquake-sources]] 发展；弹性回跳背后的断层力学在 [[structural-geology/fractures-faults]]；灾害的算术——概率区划图、超越概率、结构的易损性——是 [[natural-hazards/earthquake-hazard]] 的主题。影区所暗示的深部结构在 [[physical-geology/earth-interior]] 做出、而把地震当作探测地球内部的探针、而非灾害的用法、在 [[geophysics/seismic-structure]]。

::: summary 关键要点
- 一个地震是一条预先存在、被锁闭并已加载的断层的摩擦失稳；能量来自数百年积累、数秒内释放的弹性应变。
- 我们对震源的一切了解都来自波：P 与 S 的体波、勒夫波与瑞利波、以及它们的到时。
- 地壳中到一个台站的距离为 $8.4\times$（S–P 时差）；三个台站可定位震中、四个还能给出深度与发震时刻。
- 矩震级 $M_\text{w} = \tfrac{2}{3}(\log_{10}M_0 - 9.1)$、带着 $M_0 = \mu A D$；震级是对数的、所以一个单位是能量的约 32 倍。
- 烈度是一个地方实际遭受的、取决于深度、土质与建筑；震级则是震源的属性。切勿将二者混淆。
- 地震勾勒出板块边界；瓦达蒂–贝尼奥夫带是一块由自身地震活动显形的俯冲板块、而稳定的大陆内部虽然安静、却并不强。
- 古登堡–里克特律给出全球速率——一年约 $18$ 次 $M_\text{w} \ge 7$、每几年一次 $M_\text{w} \ge 9$——而灾害是特定断层的属性。
- 死亡人数取决于深度、土质、建筑质量与发生时刻、大致按可控程度排列：后两者是一个社会能够改变的。
:::

## 练习题

::: exercise 从 S–P 的距离 {level=1 check="126"}
一个台站记录到 $15\ \mathrm{s}$ 的 S–P 时差。用 [[#ex-locate]] 中的地壳速度、求震中的距离。
::: solution
$D = 8.4\times15 = 126\ \mathrm{km}$。如果同一事件在一个台站的 S–P 时差是 $15\ \mathrm{s}$、在另一个是 $22\ \mathrm{s}$、震中坐在 $126$ 与 $185\ \mathrm{km}$ 两个圆的交点上——即两个交点、由第三个台站定出唯一解。
:::
:::

::: exercise 矩与震级 {level=1 check="8.0"}
一个地震破裂 $180\times60\ \mathrm{km}$、带着 $4\ \mathrm{m}$ 的滑动；取 $\mu = 30\ \mathrm{GPa}$。求 $M_0$ 与 $M_\text{w}$。
::: solution
$M_0 = 3\times10^{10}\times1.08\times10^{10}\times4 = 1.3\times10^{21}\ \mathrm{N\,m}$、而 $M_\text{w} = \tfrac{2}{3}(21.11-9.1) = 8.0$。注意震级对滑动多么不敏感：把滑动减半为 $2\ \mathrm{m}$ 给出 $M_\text{w}\ 7.8$、这在科学上是大事、而能量的 $5.7$ 倍。
:::
:::

::: exercise 能量的比 {level=1 check="32"}
矩震级每增加一个单位、辐射能量增加多少倍？
::: solution
从 $\log_{10}M_0 = 1.5M_\text{w} + 9.1$ 而 $E_r \propto M_0$、因子是 $10^{1.5} = 32$。两个单位是 $10^3$、三个单位 $3\times10^4$。
:::
:::

::: exercise 烈度与距离 {level=2 check="4.4"}
烈度大致作为 $I = I_0 - 3\log_{10}(R/R_0)$ 下降、带着以千米的 $R$。如果一个 $M_\text{w}\ 6.5$ 的地震在 $10\ \mathrm{km}$ 产生 MMI VIII、在 $160\ \mathrm{km}$ 处、在类似的基岩上应该预期什么烈度？（输入烈度的值。）
::: solution
$\Delta I = 3\log_{10}(160/10) = 3\times1.2 = 3.6$、所以 $I \approx 8 - 3.6 = 4.4$、即 MMI IV–V——室内有感、悬挂物摇摆、没有破坏。这个练习是对""距某地 X 英里的地震""的标题的一个警告：烈度随距离衰减很快、而一个距一个中等的地震 $150\ \mathrm{km}$ 的城市是只是摇晃、并未受损。软土能抬高一到两个烈度单位、那是为什么同样的公式只作为一个第一的估计使用。
:::
:::

::: exercise 场地的放大 {level=2 check="3.4"}
1985 年的米却肯地震中、墨西哥城基岩上的峰值地速为 $3.5\ \mathrm{cm\,s^{-1}}$、而湖区地段为 $12\ \mathrm{cm\,s^{-1}}$。求放大系数、并解释为什么倒塌的正是 10–15 层的建筑。
::: solution
放大 $= 12/3.5 = 3.4$。湖区还把强烈摇晃延长到超过一分钟、并把能量集中在约 $2\ \mathrm{s}$ 的周期附近、那正是 10–15 层建筑的基本周期（对 $N$ 层混凝土框架 $T \approx 0.1 N$ 秒）。破坏结构的是共振、而不只是峰值振幅：同样的地面运动对一或两层的房子或一个 40 层的塔会做少得多的破坏。
:::
:::

::: exercise 一个区域的古登堡–里克特 {level=2 check="1.2"}
一个区域每年记录 $120$ 个 $M_\text{w} \ge 4.5$ 的地震、带着 $b = 1.0$。估计 $M_\text{w} \ge 6.5$ 的事件的每年的速率、而平均复发间隔。
::: solution
$\log_{10}N = a - bM$、带着 $a = \log_{10}120 + 4.5 = 6.58$。对 $M \ge 6.5$：$N = 10^{6.58-6.5} = 10^{0.08} = 1.2\ \mathrm{yr^{-1}}$、平均复发间隔 $1/N = 0.85\ \mathrm{年}$。

这套数字的要点在于对 $b$ 的敏感性：带着 $b = 0.8$、同样的小地震计数率给出 $N = 10^{6.58-0.8\times6.5} = 10^{1.38} = 24\ \mathrm{yr^{-1}}$、多了二十倍。任何由小地震外推到大地震的灾害估计、其主导误差都来自 $b$ 的不确定；那是为什么好的评估既用地震目录、也用断层的地质。
:::
:::

::: exercise 推导 S–P 的法则 {level=3}
对均匀地壳推导震中距与 S–P 的到时差的关系、而证明在那里关系是线性的、而在而在真实的层状地球中是弯曲的。为什么这条经验法则只在几百千米以内可靠？
::: solution
对一条穿过一个厚度 $z$ 的层的垂直入射的射线、差是 $\Delta t = z(1/V_S - 1/V_P)$；对一个入射 $i$ 的射线、两个路径的长度都乘以 $\sec i$、所以 $\Delta t$ 仍然随距离线性增长。线性因此对一个*均匀*的介质在任何几何成立、而在速度随深度增加时失效。

在一个真实的地壳与上地幔、$V_P$ 穿过莫霍面从约 $6$ 升到 $8\ \mathrm{km\,s^{-1}}$、所以走得远的射线采样了更快的岩石、而比恒速模型的预报更早到达：走时曲线比线性情形更平缓、而 S–P 的增长的速率从在震源附近的 $8.4\ \mathrm{km\,s^{-1}}$ 下降到约 $10\ \mathrm{km\,s^{-1}}$、并且继续下降。在几百千米之外、平地近似也不再成立、而球体的曲率变得重要、那是为什么地震学家使用从球状速度模型查表得到的走时曲线（IASPEI 或 ak135 的模型）、而不是一个经验的法则——而为什么经验的法则仍值得知道、因为它是判断查表何时出错的不二法门。
:::
:::

::: exercise 一个地震的空段 {level=3}
一条 $1200\ \mathrm{km}$ 长、$150\ \mathrm{km}$ 宽的巨型逆冲断层上一次完全破裂发生在 1700 年。大地测量数据显示 $7\ \mathrm{cm\,yr^{-1}}$ 的汇聚、其中 $20\%$ 由无震蠕变承担。估计累积的滑动亏损、它所代表的矩、一个将释放它的单的地震的震级、而你做的假设。
::: solution
滑动的亏损 $= 0.8\times7\times10^{-2}\times325 = 18.2\ \mathrm{m}$。带着 $A = 1.8\times10^{11}\ \mathrm{m^2}$ 而 $\mu = 30\ \mathrm{GPa}$、
$$
M_0 = 3\times10^{10}\times1.8\times10^{11}\times18.2 = 9.8\times10^{22}\ \mathrm{N\,m} 、 \qquad M_\text{w} = \tfrac{2}{3}(22.99-9.1) = 9.3 。
$$
这比 1900 年以来除 1960 年智利地震以外的任何地震都大、而这些假设承担了很重的负荷：整个宽度都是锁闭的（最浅与最深的几十千米通常发生蠕变）、$\mu$ 在 $10$–$40\ \mathrm{km}$ 深的超压沉积物中是否还是 $30\ \mathrm{GPa}$、破裂会是一次事件而非两三次局部破裂、以及 1700 年的日期与破裂范围都是正确的。诚实的说法是该地段具备 $M_\text{w}\ 9$ 的能力、而按平均复发期已经逾期——那恰好是卡斯卡迪亚与南海的预报如何做出、而为什么它们以数十年的概率、而不是以预报的形式给出。
:::
:::

::: exercise 读一个目录 {level=3}
自 1900 年以来某区域的 $M_\text{w} \ge 5.0$ 的地震的目录含着 240 个事件、而该区域的完备震级在 1964 年以后为 $M_\text{c} = 5.0$、而之前则为 $M_\text{c} = 6.0$。解释你将如何估计 $b$ 与 $a$、而为什么用一个统一的 $M_\text{c}$ 使用全部 240 个事件会使答案有偏。
::: solution
只从目录中*完备*那一部分的频度—震级分布估计 $b$——此处即 1964 年以来的 $M \ge 5.0$——通过在 $M_\text{c}$ 以上拟合 $\log_{10}N = a - bM$、用最大似然、而不是用分箱计数的最小二乘（标准的秋叶–宇津估计量、$\hat b = [\log_{10} e]^{-1}/(\bar M - (M_\text{c}-\Delta M/2))$）。至于速率 $a$、则可使用整份目录（承认 $M_\text{c}$ 随时间变化）、只需统计高于一个对全时段都完备的阈值的事件。

用一个 $M_\text{c} = 5.0$ 使用全部 240 个事件会把 1964 年以前的记录当作似乎它记录到了每一个 $M\ 5$ 的事件、而实际上其中大部分被漏掉了。记录早期小事件的缺失会使分布显得更陡、于是 $b$ 被高估——而偏高的 $b$ 会外推出*更少*的大的地震、那正是会使灾害估计显得令人放心的偏差方向。这是地震危险性工作中最常见的技术性错误、而那是为什么目录连同完备性信息发表、而不是作为一个光秃秃的清单。
:::
