夏季一天中最热的时刻是下午四点，最冷的时刻是凌晨四点半，而两者都不是太阳辐射最强的时刻。天空是蓝的、日落是红的，其中的道理可以用一行代数写完。地球每一小时从太阳接收的能量，就足以供全世界文明运行一年；然而在整个有文字记载的人类史中，它的平均温度始终停留在两三度之内——直到最近六十年。这些都是同一个题目：辐射，以及它遭遇了什么。

::: definition 两个谱 {#def-spectra}
任何物体都以仅由温度决定的谱辐射。发射最强的波长由**维恩位移定律**给出，
$$
\lambda_\text{max} = \frac{2898}{T}\ \mu\mathrm{m},
$$
总通量由**斯特藩-玻尔兹曼定律**给出，$E = \sigma T^4$，其中 $\sigma = 5.67\times10^{-8}\ \mathrm{W\,m^{-2}\,K^{-4}}$。太阳在 $5772\ \mathrm{K}$，于可见光的 $0.50\ \mu\mathrm{m}$ 处达峰，从其表面发出 $6.3\times10^{7}\ \mathrm{W\,m^{-2}}$；地球在 $288\ \mathrm{K}$，于热红外的 $10.1\ \mu\mathrm{m}$ 处达峰，发出 $390\ \mathrm{W\,m^{-2}}$。两个谱几乎不重叠，而这不重叠就是温室效应的全部。
:::

::: example 行星的能量预算 {#ex-budget}
太阳常数 $S_0 = 1361\ \mathrm{W\,m^{-2}}$，行星反照率 $0.30$。求全球年平均的吸收太阳通量、地球的有效辐射温度，以及温室效应的大小。
::: solution
地球以 $\pi R^2$ 的圆盘拦截阳光，以 $4\pi R^2$ 的球面辐射，所以平均吸收通量为
$$
\overline{F} = \frac{S_0(1-\alpha)}{4} = \frac{1361\times0.70}{4} = 238\ \mathrm{W\,m^{-2}}.
$$
令其等于发射通量，即得**有效辐射温度**，亦即行星向太空辐射的那个层次的温度：
$$
T_e = \left(\frac{238}{5.67\times10^{-8}}\right)^{1/4} = 255\ \mathrm{K}.
$$
地面为 $288\ \mathrm{K}$，故温室效应为 $33\ \mathrm{K}$。到达大气顶的 $340\ \mathrm{W\,m^{-2}}$ 阳光中，$100$ 被反射——云与气溶胶 $77$，地面 $23$——$78$ 被大气吸收，主要是水汽与臭氧，少量为云与气溶胶，$160$ 被地面吸收。地面以向上辐射损失 $396\ \mathrm{W\,m^{-2}}$，从大气收回 $342$，净长波损失仅 $54$，另有潜热 $80$、感热 $24$。大气则获得那 $160$ 的净长波、$78$ 的太阳辐射、$104$ 的湍流通量，向下送出 $342$、向太空送出 $196$。

应当记住的数是：地面接收与返回的辐射，约为其与湍流交换之量的五倍；大气返回地面的能量，几乎是地面从太阳所得的两倍。
:::
:::

## 空气让什么通过

::: proposition 选择性吸收与温室 {#prop-greenhouse}
氮与氧为同核分子，没有偶极矩，因此在整个地球辐射范围内是透明的。温室气体——水汽、二氧化碳、臭氧、甲烷、氧化亚氮、氟氯烃——以波带吸收：水汽在 $20\ \mu\mathrm{m}$ 以下的转动带以及 $6.3$ 与 $12\ \mu\mathrm{m}$，二氧化碳在 $15$ 与 $4.3\ \mu\mathrm{m}$，臭氧在 $9.6$，甲烷在 $7.7$，氧化亚氮在 $7.8$ 与 $17$。在 $8$ 与 $13\ \mu\mathrm{m}$ 之间是**大气窗区**，地面透过它直接看见太空，行星也透过它最有效地冷却。对一个处于辐射平衡的灰体大气，温度廓线为爱丁顿形式
$$
T^4 = \tfrac{1}{2}T_e^4\left(1 + \tfrac{3}{4}\tau\right),
$$
其中 $\tau$ 为自大气顶量起的红外光学厚度。地面在 $\tau = \tau_s$，比发射层暖 $\left[\tfrac{1}{2}(1+\tfrac{3}{4}\tau_s)\right]^{1/4}$ 倍，地球的 $\tau_s$ 为 $1.5$。
:::

::: proof
辐射平衡意味着在每一层，向上与向下的通量各自为常数，因此净通量 $F$ 与高度无关。在双流（爱丁顿）近似中，光学厚度 $\tau$ 处的向上通量为 $F = \sigma T^4(\tau)\left[\tfrac{1}{2} + \tfrac{\sqrt{3}}{4}\right] + \tfrac{\sqrt{3}}{4}\sigma T^4(\tau)$，与入射的漫射辐射相平衡；标准的演算给出 $T^4(\tau) = \tfrac{1}{2}T_e^4(1 + \tfrac{3}{4}\tau)$，并满足在 $\tau = \tfrac{2}{3}$ 处 $T^4 = T_e^4$，即辐射逃逸的那一层。

在顶部 $\tau = 0$，皮层温度为 $214\ \mathrm{K}$——一块置于太空的黑板的温度，也是月面在日下点的平衡温度。在地面，$\tau_s = 1.5$ 给出 $T_s = 255\times(1.625)^{1/4} = 287\ \mathrm{K}$，这正是观测值，而它只来自一个参数。

这个证明同时回答了关于温室理论最古老的那条反驳：二氧化碳的波带早已"饱和"，再多的二氧化碳也无法多吸收分毫。在灰体模型中，地面温度取决于总光学厚度，而不取决于某一条波带是否吸收了更多地面辐射；增加二氧化碳会抬高 $\tau$，行星向外辐射的那一层（位于 $\tau \approx \tfrac{2}{3}$）便上移到更冷的空气之中。由于该层仍必须发出 $238\ \mathrm{W\,m^{-2}}$，而它现在更冷，其下的气柱就必须增暖，直到发射恢复原值。二氧化碳加倍的实测辐射强迫为 $3.7\ \mathrm{W\,m^{-2}}$，如今在大气顶观测到的 $3.3\ \mathrm{W\,m^{-2}}$ 不平衡，正是迄今增幅的指纹。∎
:::

::: example 为什么天空是蓝的、日落是红的 {#ex-blue}
分子的瑞利散射，其光学厚度正比于 $\lambda^{-4}$。求 $0.42\ \mu\mathrm{m}$ 的紫光与 $0.65\ \mu\mathrm{m}$ 的红光的散射之比，并解释天空为什么不是紫的。
::: solution
其比为 $(0.65/0.42)^4 = 3.5$。在地平线处横穿整个大气的阳光，其蓝端被衰减约 $e^{-\tau_\text{blue}}$，其中 $\tau_\text{blue}\approx 0.1\times(0.55/0.42)^4\times$（气团质量）；在气团质量为 $38$（地平线）时，蓝色光学厚度约为 $9$，红色约为 $1.5$，于是直射光束几乎失去全部蓝光，到达眼睛时呈橙或红。

天空不是紫的，有三个原因：太阳辐射的紫光少于蓝光；眼睛在 $0.42\ \mu\mathrm{m}$ 的敏感度远低于 $0.47$；高层大气的臭氧在恰普伊斯带吸收。我们看到的散射光，是眼睛读作蓝的那种蓝。同样的 $\lambda^{-4}$ 定律解释了为什么火山喷发后的暮光会持续数日，为什么污染城市上空的天空是白的：气溶粒子的尺度与波长相当，其散射（米氏散射，或几何散射）几乎与波长无关——云之所以是白的、云底之所以是灰的，也是这个缘故。
:::

## 地面能量平衡

::: definition 能量平衡 {#def-surface-budget}
地面遵守能量守恒：
$$
R_n = H + LE + G,
$$
其中 $R_n$ 为净辐射（净短波加净长波），$H$ 为向大气的感热通量，$LE$ 为蒸发或升华的潜热通量（水为 $L = 2.45\ \mathrm{MJ\,kg^{-1}}$），$G$ 为向地下的传导通量。**波文比** $\beta = H/LE$ 度量地面如何在加热空气与蒸发水分之间分配其可用能量：灌溉田或湖面为 $0.1$，草地为 $0.6$，干燥裸土为 $3$，沙漠或城市为 $5$ 以上，冻结的表面为 $-1$ 到 $0$。**蒸发比** $LE/(H+LE)$ 是它的互补量，也是在同样辐射下区分湿润气候与干旱气候的那一个数。
:::

::: example 平衡的闭合 {#ex-close-budget}
在一块草地，净辐射为 $480\ \mathrm{W\,m^{-2}}$，土壤热通量 $40\ \mathrm{W\,m^{-2}}$，潜热通量 $300\ \mathrm{W\,m^{-2}}$。求感热通量、波文比，以及以 $\mathrm{mm\,day^{-1}}$ 计的蒸发速率。
::: solution
$H = 480 - 40 - 300 = 140\ \mathrm{W\,m^{-2}}$，$\beta = 140/300 = 0.47$。蒸发速率为
$$
E = \frac{LE}{L\rho_w} = \frac{300}{2.45\times10^6\times1000}\ \mathrm{m\,s^{-1}} = 1.22\times10^{-7}\ \mathrm{m\,s^{-1}} = 10.6\ \mathrm{mm\,day^{-1}}.
$$
对一块水分充足、全日照的草地或作物，这是偏高但可达的速率。同样的 $300\ \mathrm{W\,m^{-2}}$ 若在沙漠上，其中 $LE$ 可能只有 $40\ \mathrm{W\,m^{-2}}$、$H$ 有 $400$，那么每天只蒸发 $1.4\ \mathrm{mm}$，其余都去加热空气——这就是天气图上夏季干旱大陆上空的等温线向外鼓出的原因，也是灌溉使谷地变凉的原因：本会造出一个炎热下午的能量，被拿去蒸发水了。据估计，加利福尼亚中央谷地与旁遮普的灌溉带来 $0.5$–$1\ ^\circ\mathrm{C}$ 的降温，这是一个真实但局地的、对温室增暖的抵消。
:::
:::

::: warning 热、温度，以及两个都叫"温室"的东西
在这个题目上有三种混淆造成了大量混乱。**热不是温度**：一池 $40\ ^\circ\mathrm{C}$ 的水，所含的热是一粒 $1000\ ^\circ\mathrm{C}$ 火星的百万倍；热层的上千度并不是温暖。**温室效应不是天空呈蓝色的原因**：散射改变光的方向，吸收与再发射改变它的波长与停留时间，两者毫不相干。**玻璃温室也不是温室效应**：玻璃挡住雨水、阻断内外空气的交换；一块让空气流通的玻璃板，其内温度几乎同样高，因为温室的增暖主要是对流的抑制，而不是辐射的截留。大气没有玻璃，也没有盖子；它靠冷空气向下辐射来减缓能量的流失，为它辩护的论证必须用上面那条命题的语言，而不是用花园里的构筑物作类比。
:::

## 日变化与年变化

::: proposition 温度波及其滞后 {#prop-lag}
地面与空气对周期性强迫的响应都是一个衰减的波。对热扩散率 $\kappa \approx 5\times10^{-7}\ \mathrm{m^2\,s^{-1}}$ 的土壤，表面温度作周期为 $P$ 的正弦变化时，热方程的解为
$$
T(z,t) = \overline{T} + A\,e^{-z/D}\cos\left(\frac{2\pi t}{P} - \frac{z}{D}\right), \qquad D = \sqrt{\frac{\kappa P}{\pi}},
$$
其**衰减深度** $D$ 对日波为 $13\ \mathrm{cm}$、对年波为 $2.2\ \mathrm{m}$，位相滞后为 $z/D$ 弧度。在约 $10\ \mathrm{m}$ 以下，年波衰减到几个百分点，地温等于年平均气温——这就是地下室夏凉冬暖的原因，是酒窖温度即当地气候平均值的原因，也是只有到季节所及的深度以下才能测出地热梯度的原因。
:::

::: example 季节的滞后 {#ex-seasonal-lag}
夏至在六月二十一日，而北半球一年中最暖的时候是七月的最后一周。定量的解释，并说明两个半球的差别。
::: solution
地面既有必须注满、又必须再次倒空的热容量，所以在阻尼很强时，其温度比强迫滞后约强迫周期的四分之一——对年波约为六周，这正是七月下旬落后于夏至的观测滞后。同样的滞后出现在土壤波中：在深度 $z = D$ 处位相滞后为一弧度，$P/2\pi = 2$ 个月，振幅降到 $37\%$；在 $2.2\ \mathrm{m}$ 处最暖的月份是一月，与上覆空气相差六个月。

两个半球并不对称。北半球 $39\%$ 是海洋，南半球是 $81\%$；海洋混合层单位面积的热容量约为其上空气的一千倍，并且向下混合，所以南半球表面的年温度范围为 $5.7\ ^\circ\mathrm{C}$，北半球为 $11.6\ ^\circ\mathrm{C}$；南半球最暖的月份是一至二月、滞后更长，其气候在一切意义上都更海洋性。同样效应在较小尺度上使海岸夏凉冬暖；也使一座大城市——它的墙与路是数米厚、扩散率与土壤相当的热质量——有了自己的滞后，夜间 $2$–$5\ \circ\mathrm{C}$ 的热岛。
:::
:::

::: example 预报最低温 {#ex-minimum}
在一个晴朗无风的夜间，地面损失 $70\ \mathrm{W\,m^{-2}}$ 的净长波。空气在 $8\ ^\circ\mathrm{C}$，露点为 $2\ ^\circ\mathrm{C}$。会有辐射雾吗？会有地面霜冻吗？
::: solution
要成雾，空气必须冷却到露点，即 $6\ \mathrm{K}$。把最下 $50\ \mathrm{m}$ 的空气冷却 $6\ \mathrm{K}$ 需要移去
$$
\rho c_p\,\Delta z\,\Delta T = 1.2\times1005\times50\times6 = 3.6\times10^5\ \mathrm{J\,m^{-2}},
$$
以 $70\ \mathrm{W\,m^{-2}}$ 计，需要一个静止气层纯辐射冷却 $1.4$ 小时——但气层会随冷却而加深，而日落后最初几小时地面的冷却率为每小时 $1$–$2\ \mathrm{K}$，所以实用的规则是：雾需要数小时的晴朗无风，以及小于约 $5\ \mathrm{K}$ 的露点亏缺。有 $6\ \mathrm{K}$ 的亏缺与微风，黎明时在河边很可能有雾。

霜冻是另一回事：它需要*地面*、而不是空气降到 $0\ ^\circ\mathrm{C}$ 以下。一片辐射冷却的草叶与逆温之上的空气脱耦，可以比 $1.25\ \mathrm{m}$ 高处测得的气温低 $5$–$8\ ^\circ\mathrm{C}$，所以当预计百叶箱最低温将降到冰点附近几度以内时就预报霜冻。这就是为什么一个静而晴、百叶箱最低 $3\ ^\circ\mathrm{C}$ 的夜晚会冻死谷底的豆、却放过坡上的藤；也是为什么果园在凌晨两点开动防风风机与直升机，把逆温之上 $200\ \mathrm{m}$ 处可能暖 $10\ \mathrm{K}$ 的空气搅下来。
:::

::: quiz
地球在一月初离太阳最近。为什么那时北半球是冬天？
- [ ] 因为冬天大气更厚、反射更多阳光
- [x] 因为季节由自转轴的倾角、而非日地距离决定，而北方的冬季正与近日点重合
- [ ] 因为月球的引力改变了轨道
- [ ] 这是一个巧合，对气候没有影响
::: solution
日地距离在一年中变化 $3.4\%$，使日射变化 $7\%$，其效应是全球性的、在两个半球相反，因此不能产生季节。$23.4^\circ$ 的倾角同时控制太阳的高度与白昼的长度，上面控件中的日均日射曲线显示了结果：在六月至点，北冰洋每天接收的能量比赤道还多。轨道偏心率剩下的效应是南半球的季节比北半球略为强烈，以及北半球一月接收的日射比南半球七月多 $6\%$——这一事实与海陆分布结合，是[[palaeoclimate/orbital-cycles]]中冰期理论的核心。
:::

::: history
索绪尔在1760年代的阿尔卑斯山建造层层叠叠的玻璃箱，其中一个达到 $88\ ^\circ\mathrm{C}$，他不明白是什么让地球保持温暖。约瑟夫·傅里叶在1824年提交给科学院的一篇回忆录中给出了答案：地球"就像一个围栏，光线艰难地穿透它，而热在其中越来越难以逃出"，他还算出一个没有大气的地球温度远低于观测值。约翰·丁达尔在1861至1864年的一系列讲演与论文中，用温差电堆与岩盐柱测量气体的吸收，证明做到这一点的是水汽与二氧化碳，而氮与氧不能，并把水汽称为"我们的毯子"。斯凡特·阿伦尼乌斯受冰期问题的驱动，用1890年代粗糙的月值资料算出，二氧化碳减半会使全球冷却 $4$–$5\ ^\circ\mathrm{C}$，加倍会使之增暖 $5$–$6$——这个数字在此后每一次精化中都存活了下来。蓝天由瑞利在1871年解释，推翻了旧的悬浮水滴理论；爱因斯坦1910年关于临界光散射的理论证明密度涨落如何散射光线，部分地结束了这场争论。那些看不见的气体的后果，写在了雾里：1952年12月的伦敦雾在五天中杀死约一万两千人，催生了1956年的《清洁空气法》，这是世界上第一部依据化学来管制空气的法律。
:::

## 通向何处

本章以灰体近似处理的辐射传输，严格的做法在[[atmospheric-dynamics/radiative-transfer]]；同样的地面平衡，连同湍流与边界层，在[[atmospheric-dynamics/boundary-layer]]与[[hydrology/precipitation-evaporation]]；本章算术的全球平均在[[climate-system/energy-budget]]与[[climate-system/greenhouse-effect]]；散射的气溶胶在[[atmospheric-chemistry/aerosols]]；日射控件背后的轨道几何是[[palaeoclimate/orbital-cycles]]的主题。

::: summary 关键的收获
- 太阳在 5772 K 辐射、在 0.5 微米达峰；地球在 288 K、在 10.1 微米达峰。两个谱的不重叠就是温室效应。
- 行星吸收 238 W/m2、以 255 K 的有效温度辐射，并靠冷空气向下返回 342 W/m2 使地面暖 33 K。
- 只有具备偶极矩的气体才在红外吸收；8-13 微米的窗区是地球冷却的通道，温室气体靠关闭它起作用。
- "饱和"不是反驳：增加二氧化碳把发射层抬到更冷的空气中，气柱便增暖直到射出的通量恢复。
- 地面把净辐射分配给感热、潜热与土壤，波文比会告诉你自己站在沙漠、田野还是城市里。
- 温度滞后于辐射：下午四点、七月下旬、土壤下 71 厘米，因为热容量必须先被注满才能被感到。
- 瑞利散射随波长的四次方反比，给出蓝天、红日落与绵长的暮光；气溶胶的散射是灰的，给出白云与朦胧的地平线。
:::

## 练习题

::: exercise 维恩与斯特藩-玻尔兹曼 {level=1 check="9.7"}
求 $300\ \mathrm{K}$ 的表面峰值发射的波长，以微米计。
::: solution
$\lambda_\text{max} = 2898/300 = 9.7\ \mu\mathrm{m}$，正落在大气窗区之中，这就是热像仪能工作、体温计能在远处读前额的原因。
:::
:::

::: exercise 发射的通量 {level=1 check="459"}
求 $300\ \mathrm{K}$ 的表面发射的通量，以 $\mathrm{W\,m^{-2}}$ 计。
::: solution
黑体为 $E = 5.67\times10^{-8}\times300^4 = 459\ \mathrm{W\,m^{-2}}$；水或植被的发射率为 $0.97$，得 $445\ \mathrm{W\,m^{-2}}$。温度误差 $10\ \mathrm{K}$ 就是通量的 $13\%$，这就是热遥感之所以精细的原因。
:::
:::

::: exercise 反照率 {level=1 check="255"}
若行星反照率从 $0.30$ 升到 $0.35$，求新的有效辐射温度，以开尔文计。
::: solution
$\overline{F} = 1361\times0.65/4 = 221\ \mathrm{W\,m^{-2}}$，$T_e = (221/5.67\times10^{-8})^{1/4} = 250\ \mathrm{K}$。反照率变化五个点就是 $5\ \mathrm{K}$ 的冷却，这就是海冰与雪盖的增长是头等重要的反馈、而北极夏季海冰的消失据估计自1980年以来增加了 $0.2$–$0.3\ \mathrm{W\,m^{-2}}$ 的辐射强迫的原因。
:::
:::

::: exercise 散射 {level=1 check="3.5"}
求 $0.42\ \mu\mathrm{m}$ 的光与 $0.65\ \mu\mathrm{m}$ 的光的瑞利散射之比。
::: solution
$(0.65/0.42)^4 = 3.5$。眼睛的敏感度部分地补偿了它，这就是天空看起来是蓝的而不是紫的原因。
:::
:::

::: exercise 蒸发 {level=2 check="10.6"}
求与 $300\ \mathrm{W\,m^{-2}}$ 的潜热通量相当的蒸发速率，以 $\mathrm{mm\,day^{-1}}$ 计。
::: solution
$300/(2.45\times10^6) = 1.22\times10^{-4}\ \mathrm{kg\,m^{-2}\,s^{-1}} = 1.22\times10^{-7}\ \mathrm{m\,s^{-1}}$，即 $10.6\ \mathrm{mm\,day^{-1}}$。一个有用的等价关系：每天 $1\ \mathrm{mm}$ 的蒸发等于 $11.6\ \mathrm{W\,m^{-2}}$，$50\ \mathrm{W\,m^{-2}}$ 的潜热是每天四分之一毫米。
:::
:::

::: exercise 土壤波 {level=2 check="2.24"}
求 $\kappa = 5\times10^{-7}\ \mathrm{m^2\,s^{-1}}$ 的土壤中年温度波的衰减深度，以米计，以及最暖月份为一月的深度。
::: solution
$$
D = \sqrt{\frac{\kappa P}{\pi}} = \sqrt{\frac{5\times10^{-7}\times3.16\times10^{7}}{\pi}} = \sqrt{5.02} = 2.24\ \mathrm{m}.
$$
位相滞后为 $z/D$ 弧度，所以 $\pi$——半年——的滞后出现在 $z = \pi D = 7.0\ \mathrm{m}$，那里振幅为表面值的 $e^{-\pi} = 4\%$。同样土壤中的日波 $D = 12.6\ \mathrm{cm}$，这就是 $30\ \mathrm{cm}$ 处的温度计读到一个稳定的午后值、而 $1\ \mathrm{m}$ 处只读到季节的原因。
:::
:::

::: exercise 灰体大气 {level=2 check="291"}
用爱丁顿灰体模型，求红外光学厚度 $2.0$、$T_e = 255\ \mathrm{K}$ 时的地面温度。
::: solution
$T_s = 255\times\left[\tfrac12(1+1.5\times2.0)\right]^{1/4} = 255\times(2.0)^{1/4} = 255\times1.189 = 303\ \mathrm{K}$。在这个没有反馈的模型中，大气的红外不透明度增加 $33\%$ 会使地面增暖 $16\ \mathrm{K}$；真实气候的水汽与冰反馈大约把对强迫的响应放大三倍，而普朗克反馈与直减率反馈正是二氧化碳加倍的估算值不是 $16\ \mathrm{K}$ 的原因。
:::
:::

::: exercise 推导日滞后 {level=3}
把白天地面的温度建模为 $C\,\mathrm{d}T/\mathrm{d}t = a - b\cos(2\pi t/P) - cT$，其中 $a - b\cos$ 为净辐射，$cT$ 为向空气的损失。证明温度是一个位相滞后为 $\phi = \arctan(2\pi C/(cP))$ 的正弦波，并估计一个 $C = \rho c_p \times 10$、$c = 10\ \mathrm{W\,m^{-2}\,K^{-1}}$ 的十米气层的滞后。
::: solution
方程的特解为 $T = (a/c) + A\cos(2\pi t/P - \phi)$，其中 $\tan\phi = 2\pi C/(cP)$。以 $C = 1.2\times1005\times10 = 1.2\times10^4\ \mathrm{J\,m^{-2}\,K^{-1}}$、$P = 86400\ \mathrm{s}$，
$$
\tan\phi = \frac{2\pi\times1.2\times10^4}{10\times86400} = 0.087 \Longrightarrow \phi = 0.087\ \mathrm{rad},
$$
滞后 $0.087\times P/2\pi = 20$ 分钟——太小了。观测到的三到四小时滞后需要一个大二个数量级的有效 $C$，这正是土壤、水、建筑与植被的表面层所提供的：空气本身几乎没有热容量，几分钟就响应完毕，我们感到的滞后属于地面。这就是为什么干燥、多石或城市表面的日较差大于水面或植被，也是为什么晚上九点的海滩上"体感"温度属于沙子、而不属于空气的原因。
:::
:::

::: exercise 城市热岛 {level=3}
一座半径 $20\ \mathrm{km}$ 的城市，白天的净辐射为 $260\ \mathrm{W\,m^{-2}}$，周围农田为 $160$；蒸发比为 $0.15$，农田为 $0.65$；夜间释放的储存热为 $60\ \mathrm{W\,m^{-2}}$。估计白天感热通量之差，并解释热岛为什么在夜间、在风速小于 $5\ \mathrm{m\,s^{-1}}$ 时最大。
::: solution
设两种情形下土壤通量都是净辐射的 $10\%$，城市 $H = 0.9\times260\times0.85 = 199\ \mathrm{W\,m^{-2}}$，农田 $H = 0.9\times160\times0.35 = 50\ \mathrm{W\,m^{-2}}$——每平方米送进空气的热是四倍。因此城市的空气必须暖若干开尔文才能把它带走，观测到的百叶箱温度差 $2$–$5\ \mathrm{K}$ 与此相符。

夜间农田辐射冷却到它通常的最低值，而城市的墙与路整日以几十厘米的衰减深度储存着热，此时以 $50$–$100\ \mathrm{W\,m^{-2}}$ 释放出来，所以差值在黎明前最大，在一个静、晴的反气旋中可达 $8$–$10\ \mathrm{K}$。风把暖空气平流走，从而摧毁热岛：热岛的强度大致与风速成反比，而有记录的热岛都出现在静风、晴朗、四周覆雪的情形，那时 $0\ ^\circ\mathrm{C}$ 的乡村表面与 $10\ ^\circ\mathrm{C}$ 的城市的对比，在卫星图像上就是一片白色之中一座温暖的岛。
:::
