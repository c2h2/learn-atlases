理查森一边打第一次世界大战，一边用手做算术，并在1922年发表了结果：一个中欧上空低压的六小时预报，由一个 $211$ 个点、$200\ \mathrm{km}$ 间距的图解网格算出，大约花了六星期的劳动，而气压变化的误差是 $145\ \mathrm{mb}$。这个错误不是方法的过错。理查森从一个垂直结构被他手工平滑过的气压场出发，而平滑发射了一个虚假的重力波，两步就毁掉了整个计算；而这个计算无论如何都和天气一样难，因为大气信息每两天把自己的误差翻一倍。二十八年之后，查尼、福尔托夫与冯·诺伊曼在一台拥有一千个二十位数内存的 ENIAC 上，跑了一个覆盖四分之一大陆的正压模型，用五星期的机器时间做出了一个可用的十二小时预报。今天，欧洲中期天气预报中心每天五十次运行一个 $9\ \mathrm{km}$ 的全球模型，每个循环吸收一千一百万个观测，而它的十天预报和它1980年的四天预报一样好。

::: definition 观测系统 {#def-observing}
没有一台仪器看得见整个大气，而观测的艺术是安排一批互补的仪器。**地面站**：约两千个每三小时一次的地面天气报告与一万个自动站每小时一次，给出气压、温度、露点、风、云与降水——其中 $70\%$ 以上在北半球，而大洋上的网是船、浮标与采油平台。**高空**：一千一百个探空站每天两次释放携带仪器的气球，以 $5\ \mathrm{m\,s^{-1}}$ 上升、报告气压、温度、湿度与风直到 $30\ \mathrm{km}$，同时向下游漂移 $200\ \mathrm{km}$；加上巡航高度以下每天十万条商用飞机探空、风廓线雷达，以及探空仪被卫星的 GPS 无线电掩星临边探测取代。**卫星**：地球静止成像仪每十分钟拍一张圆盘的可见光、近红外、$10.8$、$12$、$13.4\ \mu\mathrm{m}$ 的热红外，以及 $6.2$ 与 $7.3\ \mu\mathrm{m}$ 的水汽带；极轨卫星携带能看穿云、测量 $2\ \mathrm{km}$ 厚各层温度与湿度的微波探测仪，从毛细波的后向散射读出海面应力的散射仪，读浪高与风的雷达高度计，以及给风与气溶胶做廓线的激光雷达。**雷达**：一个国家的多普勒网每五分钟给一次反射率与径向速度，2000年代以来是双偏振，它能把雨、冰雹、雪与一群迁徙的鸟区分开。

这些数字重要，因为模型需要 $10^7$ 到 $10^8$ 条独立的信息来确定状态，而它每天得到约 $10^7$ 个观测，其中 $95\%$ 是卫星辐射率，而辐射率并不是模型所携带的那些变量。把一条辐射率换算成一个温度廓线是**观测算子**，而整个现代数据同化就是把它们合起来这门生意。
:::

::: example 一只气球值多少 {#ex-sonde}
一个探空仪飞行一次花费 $80$ 英镑，每两秒报告一个直到 $25\ \mathrm{km}$ 的垂直廓线。一台卫星微波探测仪花费十亿英镑，每三小时每 $100\ \mathrm{km}$ 报告一条辐射率。气球在什么意义上更有价值、在什么意义上更不值？
::: solution
气球给出温度、气压与湿度的**直接**、经标定的测量，精度为 $0.3\ \mathrm{K}$、$0.1\ \mathrm{hPa}$ 与相对湿度的 $3\%$，垂直分辨率 $10\ \mathrm{m}$。它是标定卫星的标准，而二十世纪的再分析在1958年之前不可靠的原因不是缺卫星，是缺探空仪。而在模型自己的货币里它几乎一文不值：每 $100{,}000\ \mathrm{km^2}$ 一天两条廓线，对一场需要数百万条的分析只贡献几百个观测，而且没有算子就无法同化，因为它已经是模型的变量了。

卫星相反。它每天在一个半球上一百万条的探测是间接的，被表面发射率、云液态水与对大气吸收不完美的知识所偏置，而每一条只有通过一个辐射传输计算与一个协方差模型才有用。但南半球的预报技巧从2006年一台微波探测仪的发射中得到的改善，超过十年增加地面站；而南半球十天量级的预报时限在1990年落后北半球两天，现在落后不到一天。诚实的总结是：气球按每次飞行更值钱，而卫星按每英镑值钱四个数量级；观测系统是一个投资组合，其中昂贵、间接、无所不见的仪器，由廉价、直接、几乎看不见的仪器来标定与检验。
:::
:::

## 同化，与两周的墙

::: proposition 误差增长与可预报性极限 {#prop-predictability}
大气状态中的小误差按指数增长，速率由制造天气的同一个不稳定性设定。把均方根误差写为 $E(t) = E_0 e^{t/\tau}$，观测与模型实验给出大尺度的倍增时间 $\tau\ln 2$ 约为**两天**，饱和值 $E_\infty$ 等于该场的气候变率。当 $E$ 到达 $E_\infty$ 时预报便不再有意义，所以时限为
$$
t_\text{max} = \tau\ln\frac{E_\infty}{E_0},
$$
而初始误差的每一次减小只换来对数的收益：$E_0$ 减半只增加 $\tau\ln 2 \approx 2$ 天。以当前分析误差几百位势米的 $E_0$、以它一千倍的 $E_\infty$，上限约为**两周**，而这不是一个工程极限，是方程的一个性质。洛伦兹在1969年把它表述成一个关于巴西的蝴蝶与得克萨斯的龙卷的问题，而正确的回答是：蝴蝶的那个大气与龙卷的那个大气不是同一个，但大气的误差倍增时间是两天，除了把初始状态做得更好、以及预报统计量而不是状态之外，别无办法。
:::

::: example 一个更好的初始状态值多少 {#ex-assimilation}
一个中心通过同化一台新的卫星仪器把它的分析误差减小 $20\%$。这换来多少预报技巧？在一个被噪声主导的检验记录中你如何察觉这个改善？
::: solution
以 $t_\text{max} = \tau\ln(E_\infty/E_0)$、$\tau = 2.9$ 天，$E_0$ 减小 $20\%$ 增加
$$
\Delta t = \tau\ln\frac{1}{0.8} = 2.9\times0.223 = 0.65\ \mathrm{days},
$$
十五小时可用的预报——一个巨大、昂贵、完全真实的改善，而在任何短于七天的单一预报时效上，一年的检验中它都是看不见的，因为技巧的逐日散布比改善本身还大。

察觉它靠**成对 t 检验**，检验期要长到平均差的标准误小于效应本身：对十天时效的距平相关，其日标准差约 $0.15$、两次实验日得分之间的相关为 $0.9$，所需的样本量约为 $300$ 天。这就是业务中心运行"针对性观测实验"、并把结果发表在季刊上、而不是在一个月后宣布一项改善的原因，也是"一台新仪器改善了预报"这一说法是一个统计论断、而大多数关于观测系统的公开讨论并不这样表述的原因。
:::

::: definition 集合，以及一个概率的含义 {#def-ensemble}
一次单一的预报是从一个分布中抽的样，而**集合**提供这个分布：同一个模型从五十一个扰动的初始条件运行五十一次，每个扰动都与分析误差一致地抽取，而在较好的系统中物理量被随机地扰动。集合的**离散度**应当等于它的误差，而当它相等时系统是**可靠的**：在预报有 $40\%$ 降雨机会的那些日子里，百分之四十应该下雨。可靠性是必要的但不充分——每天预报气候概率是完美可靠而无用的——第二个品质是**锐度**，即分布的宽度。两者的权衡对二元事件用 **Brier 评分**度量，
$$
\text{BS} = \frac{1}{N}\sum (f_i - o_i)^2 = \text{reliability} - \text{resolution} + \text{uncertainty},
$$
对一个分布则用连续分级概率评分。一个预报如果可靠而更锐，就是"更好"。

对公众的"百分之四十的降雨机会"定义为在所声明的时段内该点落下至少 $0.2\ \mathrm{mm}$ 的概率，而它是关于集合的一个论断、不是关于你的花园：一个 $40\%$ 的日子可能是半个城市上午干、下午湿，而对洪水警报重要的数字不是降雨的概率，而是它的量与它的位置的分布。
:::

::: example 读一份预报 {#ex-reading}
06 时发布给一个点的预报说："降水概率 $40\%$，最可能在 15 时至 19 时之间；$850\ \mathrm{hPa}$ 温度 $12\ ^\circ\mathrm{C}$；集合平均 $6\ \mathrm{mm}$、离散度 $12\ \mathrm{mm}$；成员分成两组，一组让低压从该点以北经过、一组以南。"给一个必须决定是否施洒浆肥的农人解释之，已知规则是：在 $1\ \mathrm{mm}$ 以上降雨前六小时内禁止施洒。
::: solution
这个决策是不对称的，而决定它的是分布、不是平均。$40\%$ 的可测降雨概率，不是相关窗口内 $1\ \mathrm{mm}$ 阈值被超过的概率，后者集合可以直接给出，而考虑到分裂的路径与雨随北方那组下落这一事实，若该点位于平均路径以南接近 $30\%$、以北接近 $60\%$。离散度 $12\ \mathrm{mm}$ 对平均 $6\ \mathrm{mm}$ 说明分布接近指数型，而成员们争的是到底下不下雨、不是下多少。

双峰性是重要的信息，也正是平均所摧毁的东西：一个来自双峰分布的 $6\ \mathrm{mm}$ 集合平均不描述任何一个成员。预报员在这里的工作不是平均，而是识别该点处于哪个机制——而判别量是地面低压的位置，它六小时的分析误差为 $20\ \mathrm{km}$、十天误差为 $200\ \mathrm{km}$。对农人，答案是有条件的：如果确定性的与北方的聚类都把低压保持在北边，雨是可能的、施洒必须等待；如果南方的聚类在整个上午赢得成员，那个窗口是真实的。这就是一个人间预报员在一个模型之上添加的东西，也是各国业务警报系统对这种形状的决策都保留一个人在环中的原因。
:::
:::

::: example 何时发出警报 {#ex-warning}
一个 $40$ 万人的城市预报有超过 $3\ \mathrm{m}$ 的风暴潮。疏散受威胁的地区花费 $500$ 万英镑的扰动，而如果下令太频繁，还花费信誉。这样一个潮位击中一个未疏散的地区，估计造成 $5$ 亿的损失与数百人死亡。应当在预报概率多高时下令疏散？多少空报率是可以容忍的？
::: solution
对一个行动成本为 $C$、不行动损失为 $L$ 的二元决策，行动的期望成本是 $C$、不行动的是 $pL$，所以阈值为
$$
p^* = \frac{C}{C+L} = \frac{5}{505} = 1\%.
$$
只要概率超过百分之一就应发出警报。这是每一条"最坏情形"警报政策背后的算术，它也解释了为什么一个等待灾难性风暴潮 $50\%$ 概率才行动的气象台不是谨慎，而是在期望损失上疏忽了五十倍。

后果是一个高空报率，而这些数字值得直说：一个在 $p>0.01$ 报警、且标定良好的台站，会在许多不成灾的场合报警，而公众对警报的反应随空报次数衰减——从1982年"伊娃"飓风为毛里求斯带来 $90\%$ 的疏散、而风暴随后转向以来，每一项疏散研究都测到了这种"警报疲劳"。答案不是提高阈值，那会把死亡数乘上去，而是把警报做成有条件的、分级的——荷兰与孟加拉国制度中"做好准备"那一档——并传达概率、而不是结果。结束这场争论的对照是孟加拉国：1970年的波拉气旋在完全没有警报系统的情况下杀死了三十万到五十万人，而2007年的锡德气旋强度相当、提前七十二小时发布了预报、沿海疏散了一百九十万人，死了约三千五百人。预报并不比1970年的好一百倍；好的是最后一公里。
:::
:::

::: warning 模型不是大气
模型最重要的三个过程中有三个没有被分辨、也无法被分辨。**对流**由一个参数化表示，它从模型的平均廓线决定一小时内向上搬多少水——一个1974年写的方案，它的后代今天仍在运行，而在 $9\ \mathrm{km}$ 的分辨率上，它被要求去做它本是为取代显式模拟而设计的那份工作。在 $4\ \mathrm{km}$ 上模型处于**灰区**，其中一部分对流被分辨、一部分被参数化，而两者重复计算。**云与辐射**由网格盒平均湿度、加上一个假设的次网格分布来计算，因为模型看不见一朵云。**边界层**是一个扩散，其系数是分子的一百万倍。这一切都不意味着模型是错的；它意味着在一个雷暴的尺度上，它的输出是关于一个过程的猜测、不是一个过程的模拟，而对流性事件的好预报与坏预报之间的差别通常是初始条件、而不是物理。在再分析上训练的新机器学习模型，在三到七天的原始技巧评分上胜过物理模型，而它们训练于一个正在变化的气候的七十年；它们没有显式的物理，不能被问及一个过程，而它们的误差在那些要紧的极端处最大。它们会被使用，它们会与物理模型一起被使用，而2025年诚实的立场是：没有人知道它们的优势有多少能活过这个十年。
:::

::: quiz
即使有一个完美的模型与完美的观测，十天预报不能做得像一天预报那样准，其主要原因是：
- [ ] 对流的参数化
- [x] 不可避免的小误差按约两天的倍增时间指数增长
- [ ] 大洋上缺观测
- [ ] 湍流的混沌，使方程无法求解
::: solution
方程可解，模型也好；而大气以一个给出约两天倍增时间的速率放大任何误差、无论多小，所以一个完美的分析在实践中不可能，甚至 $1\ \mathrm{mm}$ 的初始误差也在两星期内饱和。更好的观测与更好的物理都有帮助，但只对数地：这就是两周的墙，它是流体的一个性质、不是计算机的。
:::

理查森1922年的《数值天气预测》除了那次失败的计算之外，还包含一个"预报工厂"的设计——一万名职员在一个皇家阿尔伯特音乐厅大小的圆顶大厅中工作，把结果互相传递，而地下室里有一个人负责在计算出错时把它停下。造出它花了二十八年与电子计算机，而第一次成功的运行在1950年4月的 ENIAC 上，是一个每一步都要手工重新编程的正压模型，用五个星期做出了它的十二小时预报。业务数值预报1955年在华盛顿与斯德哥尔摩开始；原始方程在1960年取代了正压模型；第一次全球预报1966年在美国海军天气局做出，第一颗卫星 TIROS-1 在1960年，到1972年模型已开始在没有1950年时构成其全部证据的地面观测的情况下运行。勒迪梅与勒德雷以及拉比耶学派提出的变分同化在1980年代末取代了逐次订正，而把一个窗口上的模型轨迹、而不是把瞬时的状态拟合到观测的 4D-Var，1997年在欧洲中期天气预报中心投入业务。集合预报由莫尔泰尼与帕尔默在欧洲中期天气预报中心、塞拉与托特在美国国家环境预测中心各自独立发展，1992年在两个中心投入业务，而今天集合就是预报：确定性的运行是一个被展示给公众的特例，因为它更容易印出来。预报的检验比这一切都老：美国天气局1901年就开始给它的预报员评分，而用来度量过去四十年改善的那个指标——距平相关——在1960年代被采用。
:::

## 通向何处

模型所积分的方程在[[atmospheric-dynamics/equations-of-motion]]中推导、它们的平衡近似在[[atmospheric-dynamics/balanced-flow]]中；被参数化的物理在[[atmospheric-dynamics/cloud-physics]]与[[atmospheric-dynamics/boundary-layer]]中；用同一套机器做气候投影——目标是统计量、不是状态——在[[climate-modelling/model-hierarchy]]与[[climate-modelling/ensembles-scenarios]]中；把整个二十世纪同化进来的再分析在[[palaeoclimate/last-two-millennia]]中；而这一切对风暴死亡率的影响在[[natural-hazards/risk-reduction]]中。

::: summary 关键的收获
- 观测系统是一个投资组合：2000 个地面站、每天 1100 次探空，以及每个循环 10^7 条卫星辐射率，其中 95% 不在模型的变量之中。
- 数据同化把一份六小时前的预报与新观测合并；分析是初始条件，而循环每天跑两次。
- 误差每两天翻一倍，所以时限只随初始状态的质量对数地增长：好 20% 的分析换来十五小时。
- 两周的墙是方程的性质，不是计算机的。
- 集合用分布取代单一预报；一个好的预报可靠而锐，而一个双峰分布的集合平均不描述任何成员。
- 对流、云与边界层是参数化的，这就是 9 km 的模型把风暴的环境报得好、把它的位置报得差的原因。
- 技巧每十年改善约一天，而这个改善只有用几百天的检验才测得出来。
:::

## 练习题

::: exercise 误差倍增 {level=1 check="8.6"}
以两天的倍增时间，一个 $1$ 单位的初始误差到达 $20$ 单位要多久？
::: solution
$t = 2\log_2 20 = 2\times4.32 = 8.6$ 天。（保留一位小数：$8.6$。）
:::
:::

::: exercise 探空仪的漂移 {level=1 check="80"}
一个探空仪以 $5\ \mathrm{m\,s^{-1}}$ 上升到 $20\ \mathrm{km}$，平均风为 $20\ \mathrm{m\,s^{-1}}$。它漂移多远，以公里计？
::: solution
上升耗时 $20{,}000/5 = 4000\ \mathrm{s}$，所以漂移为 $20\times4000 = 8\times10^4\ \mathrm{m} = 80\ \mathrm{km}$。气球的报告因此不是站点上空的一条垂直廓线，而是一条向下游斜了 $80\ \mathrm{km}$ 的探空，当站点靠近海岸或锋面时这很重要。
:::
:::

::: exercise 观测的价值 {level=1 check="1.4"}
一个中心把它的初始误差减小一半。两天的倍增时间换来多少天的额外预报？
::: solution
$\Delta t = \tau\ln 2 = 2\times0.693 = 1.4$ 天。（保留一位小数：$1.4$。）这就是十亿美元的卫星计划用几分之一来论证其合理性的原因。
:::
:::

::: exercise Brier 评分 {level=2 check="0.21"}
你在十天中预报 $30\%$ 的降雨机会，其中三天下雨。求 Brier 评分。
::: solution
$\text{BS} = [3(0.3-1)^2 + 7(0.3-0)^2]/10 = [3\times0.49 + 7\times0.09]/10 = [1.47+0.63]/10 = 0.21$。气候参考——总是预报 $30\%$ 的频率——在这里给出同样的值，所以这个预报没有分辨力；技巧评分为零。
:::
:::

::: exercise CFL 与时间步 {level=2 check="96"}
一个 $15\ \mathrm{km}$ 网格、对声波做半隐式处理的模型允许 $15\ \mathrm{min}$ 的时间步。积分一个二十四小时预报需要多少步？
::: solution
$24\times60/15 = 96$ 步。（取最接近的整数：$96$。）一次预报的成本按步数乘以格点数标度，而在固定预报长度下把格距减半会把成本乘上 $16$——三维中额外格点贡献四倍、更短的时间步贡献一倍——这就是业务模型的分辨率自1995年以来只翻了两倍的原因。
:::
:::

::: exercise 集合离散度 {level=2 check="0.8"}
一个集合在五天时的离散度为 $500\ \mathrm{hPa}$ 位势的 $240\ \mathrm{m}$，其均方根误差为 $300\ \mathrm{m}$。求一个可靠的系统应有的比值，并说明这个集合是过离散还是欠离散。
::: solution
一个可靠的集合离散度与误差之比为 $1$；这里为 $240/300 = 0.8$，所以集合**欠离散**、它的概率过于自信。欠离散是集合系统常见的毛病，靠放大扰动或加入随机物理来纠正。
:::
:::

::: exercise 预报工厂 {level=3}
理查森的预报工厂需要一万名职员，每人每二十秒做一次算术运算。估计一个现代 $10\ \mathrm{km}$ 全球模型预报到十天所需的运算数，以及它本会需要的职员数。
::: solution
一个 $10\ \mathrm{km}$ 的全球模型约有 $10^7$ 个气柱与 $10^2$ 层，所以每个变量 $10^9$ 个预报量、总共约 $10^{10}$ 个。以 $20\ \mathrm{min}$ 的步长，十天是 $720$ 步，而每一步在动力学中对每个值大约做 $10^2$ 次运算、加上物理约 $10^3$ 次，得
$$
10^{10}\times10^3\times720 \approx 7\times10^{15}
$$
次运算。按每名职员每二十秒一次运算，这座工厂做一次预报需要 $7\times10^{15}\times20/(86400\times365) = 1.6\times10^6$ 人年——这就是理查森的方案从未被建造、而答案是比一名职员快十亿倍的机器的原因。现代的中心在一台每秒 $10^{18}$ 次浮点运算的机器上每个预报日运行 $10^{21}$ 次运算，而五十一个成员整个十天集合大约花费一百万处理器小时。
:::
:::

::: exercise 雷暴的可预报性 {level=3}
单个的对流胞在起始位置上从一个下午到下一个下午变化好几公里，而中尺度的分析误差为温度 $2\ \mathrm{K}$、风 $2\ \mathrm{m\,s^{-1}}$。定量地解释为什么雷暴的位置不能提前几小时以上预报，而某地区某处有雷暴的概率可以提前三天预报。
::: solution
胞的位置由边界层辐合线在哪里决定，而那些特征水平尺度几公里、寿命一小时；温度上 $2\ \mathrm{K}$ 的初始条件误差把辐合线移位
$$
\delta x \sim \frac{c_p\,\delta T}{g}\frac{z}{\partial\theta/\partial x}
$$
约 $5\ \mathrm{km}$，而一个特征位置的误差按该尺度上的误差倍增速率增长，这比天气尺度的倍增快得多——量级是几小时、而不是两天。胞一旦存在，它自己的冷空气团与流出就决定下一个胞的位置，误差便复利累积。

区域的概率是另一个量：它依赖于环境——cape、切变、盖逆温、大尺度的上升——这些量的误差按天气尺度的速率增长，而它们的阈值是宽的。"全县有百分之四十的雷暴机会"是一个关于环境的论断，好几天都有技巧；"16:40 机场上空有一个风暴"是一个关于实现的论断，技巧不足一小时。世界上每一个对流警报系统都建立在这个区别之上，而每一句"你说有雷暴而我们一点没遇到"的公众抱怨，都是关于一个分布与一个样本之间的差别的抱怨。
:::
:::

::: exercise 最后一公里 {level=2 check="1.4"}
一个警报机构需要预报概率高于 $20\%$ 才疏散，而算例的成本–损失阈值给出 $p^* = 1\%$。若该机构只在概率超过 $20\%$ 时报警，它的政策在阈值概率上把期望损失的最优超出多少倍？
::: solution
$0.20/0.01 = 20$：这个机构要求的是使期望损失最小的概率的二十倍，而这样做就接受了十九倍的期望损失。这个因子是两个阈值之比，而真实的机构把它设得高的原因不是算术、是行为——一次空报的成本不只是 $500$ 万英镑的扰动，还有使下一次警报效力下降的信誉流失。处理这件事的诚实办法是把信誉的成本计入 $C$、并公布所用的值，而不是把一个未披露的、大得多的阈值留在决策里面。
:::
