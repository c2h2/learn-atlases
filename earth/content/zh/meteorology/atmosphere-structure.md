的卡门线、在$100\ \mathrm{km}$、世界同意太空开始约定的约定。它地球半径的$1.6\%$。若行星是一个篮球、到那条线的大气会是一层五的分之一的毫米厚的清漆的膜、你曾闻过的、呼吸过的、被雨淋过的、被闪电击过的所有发生在那层膜的最初的几的公里。空气的一半的质量在$5.5\ \mathrm{km}$之下；的珠峰的顶、在$8.8\ \mathrm{km}$、站在它的三分之二之上；在$11\ \mathrm{km}$巡航的客机在对流层的按质量的顶的十的分之一的、在海平面压的四分之一的、$-55\ ^\circ\mathrm{C}$的空气。

这一章关于那层膜由什么制成、如何排列——化学、压的随高度的落下、以温度上升、落下定义的层、使全的可计算的二的到三个方程。本课后来的所有——在一个可计算的高度形成的云、以一个可计算的不稳定汲取它的强度的风暴、因为地球旋转而沿着等压线吹的风——依靠这里的材料。

## 空气是什么

::: definition 组成 {#def-composition}
在约$80\ \mathrm{km}$之下的干的空气是一个以恒的比例机械的混合的气体：氮$78.08\%$、氧$20.95\%$、氩$0.93\%$、的二氧化碳$0.042\%$（当前的$420\ \mathrm{ppm}$、以一年的约$2.5\ \mathrm{ppm}$上升）、氖、氦、甲烷、氪、氢、臭氧以痕量的水平。它的平均的摩的尔的质量$28.97\ \mathrm{g\,mol^{-1}}$。水的汽是变的组成、从一个冷的南极的冬的$0.01\%$、在热带的的$4\%$、因为水的摩的尔的质量$18$、**湿的空气在同一个压的、同一个温度比干的空气轻**——一个对本课的每一个风、每一朵云有后果的事实。在约$80\ \mathrm{km}$之上混合停止、**的杂的的圈**以标度的高度自己排列、每一个气体带它自己的密的度的剖面、所以原的子的氧在$200\ \mathrm{km}$支配、氢在$1000\ \mathrm{km}$。
:::

::: example 一次呼吸里有什么？ {#ex-breath}
一次平均的呼吸在$1013\ \mathrm{hPa}$、$20\ ^\circ\mathrm{C}$是$500\ \mathrm{cm^3}$。求它的分子的数、它在按体积的$420\ \mathrm{ppm}$的二氧化碳的质量、分的子的平均的自的路的程。取空气的分的子的直径$0.37\ \mathrm{nm}$。
::: solution
$$
n = \frac{PV}{RT} = \frac{101{,}325\times5\times10^{-4}}{8.314\times293} = 0.0208\ \mathrm{mol} \Longrightarrow 1.26\times10^{22}\ \text{个分的子}.
$$
其中$420\times10^{-6}$是的二氧化碳：$5.3\times10^{18}$个分的子、$3.9\times10^{-4}\ \mathrm{g}$。平均的自的路的程是
$$
\lambda = \frac{kT}{\sqrt{2}\,\pi d^2 P} = \frac{1.38\times10^{-23}\times293}{1.414\times3.142\times(3.7\times10^{-10})^2\times101{,}325} = 6.6\times10^{-8}\ \mathrm{m},
$$
百的分之六的微的米、约二百个分的子的直径。一个在表面的分的子每秒遭受约七十亿的碰撞。在$30\ \mathrm{km}$、压的$12\ \mathrm{hPa}$、平均的自的路的程$4\ \mu\mathrm{m}$；在$100\ \mathrm{km}$它几的厘米、在$500\ \mathrm{km}$它几的公里——它一个连续的流体的、因此天气的全的思想停止工作的地方。

的二氧化碳的数值得记住。每一次呼吸包含比地球上的人的数的四的个亿的万更多的二氧化碳的分的子、整个的大气包含作为二氧化碳的$890\ \mathrm{Gt}$的碳——人的活动自1750把它增加约$40\%$、从$600$给$890\ \mathrm{Gt\ C}$。
:::
:::

## 压的、为什么它指数的落下

::: proposition 的静的的平衡、的标度的高度 {#prop-hydrostatic}
对一个静止的大气垂的的压的力平衡重力、
$$
\frac{\mathrm{d}p}{\mathrm{d}z} = -\rho g,
$$
以的理的想的气体方$p = \rho R T$这给、对一个恒的温度$T$、
$$
p = p_0\,e^{-z/H}, \qquad H = \frac{RT}{Mg} = \frac{R_d T}{g},
$$
在它的$H$**的标的度的高度**、对$T = 288\ \mathrm{K}$的$8.4\ \mathrm{km}$。真的大气不等温的、有的用的一般的形**的的静力学的方方的方程**、
$$
z_2 - z_1 = \frac{R_d \overline{T_\text{v}}}{g}\ln\frac{p_1}{p_2} = 67.4\,\overline{T_\text{v}}\log_{10}\frac{p_1}{p_2},
$$
以$\overline{T_\text{v}}$以开的文的层的均的的虚的的温度。一个压的层的厚度因此是它的空气的温度一个直接的度量、为什么高的空气的图以厚度地图绘制。
:::

::: proof
平衡在一个空气的板的上的力、面积$A$、厚度$\mathrm{d}z$：在底的向上的压的力$pA$、在顶的向的下的$(p + \mathrm{d}p)A$、重量$\rho g A\,\mathrm{d}z$。设总和给零给$\mathrm{d}p = -\rho g\,\mathrm{d}z$。代入$\rho = p/(R_d T)$、分离变的量、
$$
\int_{p_0}^{p}\frac{\mathrm{d}p}{p} = -\frac{g}{R_d}\int_0^z\frac{\mathrm{d}z}{T},
$$
它对恒的的$T$指数的、一般的以$\overline{T}$作为$1/T$的层的均的倒的置的静力学的方方的方程。∎

两个数跟随、常使用。压的在约$5.5\ \mathrm{km}$半的分、不在$8.4\ \mathrm{km}$的标度的高度、因为温度随高度落下、标的度的高度在冷的空气小的。$1000$–$500\ \mathrm{hPa}$的层的厚度$67.4\times\overline{T_\text{v}}\times0.301 = 20.3\,\overline{T_\text{v}}$的米、所以一个$0\ ^\circ\mathrm{C}$的层的均给$5540\ \mathrm{m}$、一个$+20\ ^\circ\mathrm{C}$给$6680\ \mathrm{m}$——一个冷的柱、一个温暖的柱之间超过一公里、$500\ \mathrm{hPa}$的面在一个冷的气的团之上比在一个温暖的低、它引导表面的天气的高的空气的的槽的、的脊的起源。
:::

::: example 的高度计的、它假设的温度 {#ex-altimeter}
一个的飞行员在一个压的$1013\ \mathrm{hPa}$、温度$15\ ^\circ\mathrm{C}$的站的站把它设定给读零、爬升到一个压的$700\ \mathrm{hPa}$的的水的平。的高度计假设标准的大气、在它的$700\ \mathrm{hPa}$的水的平在$3010\ \mathrm{m}$、层的均的温度每公里$-6.5\ ^\circ\mathrm{C}$。若实际的层比标准温暖$25\ ^\circ\mathrm{C}$、真的高度什么？
::: solution
的高度计读在标准的大气$700\ \mathrm{hPa}$对应的高度：$3010\ \mathrm{m}$。从表面到$700\ \mathrm{hPa}$的层的真的厚度是
$$
\Delta z = 67.4\,\overline{T_\text{v}}\log_{10}\frac{1013}{700} = 67.4\,\overline{T_\text{v}}\times0.1605 .
$$
标准的层的均的虚的温度$288 - 6.5\times1.5 = 278\ \mathrm{K}$、给$3006\ \mathrm{m}$、与的表一致。一个温暖$25\ \mathrm{K}$的层有$\overline{T_\text{v}} = 303\ \mathrm{K}$、一个$3277\ \mathrm{m}$的厚度。

飞机因此比仪器说的高的$270\ \mathrm{m}$。的飞行员的经验规则"**的热的、看下的；冷的、看上的**"——在温暖的空气真的高度大于指示的、在冷的空气飞机比盘的低、它使飞机在冷的空气的的爆的发之中撞上的高的地的。校正每$10\ ^\circ\mathrm{C}$的偏离标准的高度$4\%$、它高的海拔的机场的冷的天气的进的近以公布的校正飞行的理由。
:::
:::

::: example 的密的度的高度、为什么飞机不能离的地面的 {#ex-density-altitude}
一个在$1600\ \mathrm{m}$的海拔的机场有一个$840\ \mathrm{hPa}$的压的。求在一个$35\ ^\circ\mathrm{C}$的天、一个$5\ ^\circ\mathrm{C}$的天空气的密的度、热的天密的度的高度、对起的跑的跑的后果。
::: solution
$$
\rho_\text{hot} = \frac{84{,}000}{287\times308} = 0.950\ \mathrm{kg\,m^{-3}}, \qquad
\rho_\text{cool} = \frac{84{,}000}{287\times278} = 1.052\ \mathrm{kg\,m^{-3}},
$$
一个$11\%$的差别。在$1600\ \mathrm{m}$的标准的大气有$1.044\ \mathrm{kg\,m^{-3}}$、所以热的天比标准稀的$9\%$。的飞行员的规则——以的英尺的密的度的高度等于以英尺的压的的高度加$120$乘以以$^\circ\mathrm{C}$的对着标准的温度的偏离——给、以$1600\ \mathrm{m} = 5250\ \mathrm{ft}$、一个$4.6\ ^\circ\mathrm{C}$的ISA的温度、
$$
5250 + 120\times(35-4.6) = 8900\ \mathrm{ft} = 2700\ \mathrm{m},
$$
一个等温的计算给$2100\ \mathrm{m}$。无的论哪的条飞机必须表现像它在$2100$–$2700\ \mathrm{m}$、不$1600\ \mathrm{m}$：的机翼必须为同一个的举的力飞快$5$–$6\%$、的螺旋桨给少$11\%$的推力、的发的动机在一个自然的吸的气的一个、失去约$9\%$的它的功率。起的跑的跑作为开的升的速的度的平方、所以它长的的$10$–$12\%$、在一个热的高的天带一个满的载的的跑道可的能根本不够长的。

同一个物理在的墨的西哥的城市（$2240\ \mathrm{m}$）、在的科罗拉多的泉的的记录、球在稀的空气带得更远、短跑的运行更快、因为的阻的力小的、补偿的氧的损失使耐的力的项目更难的。空气的密的度在工程一个表现的数、在运动一个生的理的数、两者跟随$\rho = p/RT$。

::: example 空气的质量、它的水的质量 {#ex-mass}
平均的海平面压的$1013.25\ \mathrm{hPa}$、地球的半径$6371\ \mathrm{km}$。求大气的质量、在按体积的$420\ \mathrm{ppm}$的二氧化碳的质量、大气持有的行星的水的分数的数、给大气的含$12{,}900\ \mathrm{km^3}$的水、的海洋的$1{,}338{,}000{,}000\ \mathrm{km^3}$。
::: solution
每单位的面积的柱的重量表面的压的、所以
$$
M = \frac{p_\text{s}\times 4\pi R^2}{g} = \frac{101{,}325\times5.10\times10^{14}}{9.81} = 5.27\times10^{18}\ \mathrm{kg}.
$$
二氧化碳的质量那乘以体积的混合的比的乘以摩的尔的质量的比：
$$
5.27\times10^{18}\times4.2\times10^{-4}\times\frac{44}{28.97} = 3.4\times10^{15}\ \mathrm{kg} = 910\ \mathrm{Gt\ C}.
$$
大气持有行星的水的$12{,}900/1.35\times10^{9} = 0.001\%$——十的万的分的一——然而一年把那个全的的存的量翻约四十的次、给九的天的居留的时间。它大气的水的循环的悖的论：储量可忽略的、通量巨大、为什么三的天的雨的断对一个农的要紧、为什么大气、不的海洋、天气发生的地方。
:::

::: warning "热层的温度"
在$400\ \mathrm{km}$气有一个$1000\ \mathrm{K}$的"温度"、国际空间站不融的化、因为温度每的分的子的平均的动的能、几乎没的分子：每立方的厘米$10^{11}$、对着在表面的$10^{19}$。一个在那的物体以吸收太阳辐射得热、以辐射失热、平的均给它一个几十的度的温度、不一千的度。反过来说，在$-90\ ^\circ\mathrm{C}$的中间层的顶比在表面的任何东西冷的、但含如此少的热以至于一个穿过它的流星体不被它冷却。在一个稀薄的气、温度、热是不同的东西、这些词不能互换——在一个温和的方式真的、空气的温度、你感觉的东西之间的差的、它依赖湿度、风、辐射。
:::

## 练习题

::: exercise 标度的的高度 {level=1 check="6.8"}
求一个$-40\ ^\circ\mathrm{C}$的等温的大气的标度的的高度、以km。
::: solution
$H = 287\times233/9.81 = 6810\ \mathrm{m}$、约$6.8\ \mathrm{km}$。冷的的空气压缩、为什么压的的面在一个冷的的气的团之内的更靠近、为什么的的高度计读高的。
:::
:::

::: exercise 在高度的压的 {level=1 check="335"}
以对着在的的珠峰的之上的冷的的空气合适的$H = 8.0\ \mathrm{km}$、从一个海平面$1013\ \mathrm{hPa}$求$8849\ \mathrm{m}$的压的。
::: solution
$p = 1013\,e^{-8.849/8.0} = 1013\times0.331 = 335\ \mathrm{hPa}$、近观察的$337\ \mathrm{hPa}$。氧的分压的海平面的三分的的一、为什么的的顶在没的的补的的充的的氧的超出持的的续的人的工作的上限。

::: exercise 厚度 {level=1 check="5540"}
求一个$0\ ^\circ\mathrm{C}$的层的的均的虚的的温度一个$1000$–$500\ \mathrm{hPa}$的层的厚度。
::: solution
$\Delta z = 67.4\times273\times\log_{10}2 = 67.4\times273\times0.301 = 5540\ \mathrm{m}$。一个$+20\ ^\circ\mathrm{C}$的平均的温暖的的柱给$5940\ \mathrm{m}$、厚的四百的的米、厚度的那个差在高的的空气的的图作为一个的的脊出现。
:::

::: exercise 湿的空气 {level=2 check="0.988"}
一个在$1000\ \mathrm{hPa}$、$30\ ^\circ\mathrm{C}$的气块的有一个$25\ \mathrm{C}$的露的的点。以$32\ \mathrm{hPa}$估计汽的的压的、求在同一个压的、同一个温度湿的空气的的密的的度对着干的的空气的的密的的度的的比。
::: solution
虚的温度$T_\text{v} = T(1 + 0.61q)$、以$q \approx 0.622\times32/1000 = 0.02$、所以$T_\text{v} = 303\times1.012 = 306.6\ \mathrm{K}$、密的的度的的比$T/T_\text{v} = 0.988$。湿的气块的轻$1.2\%$、它在一个2 km的深的湿的空气的的层值约25 m的浮的的的的高度——够以一个滑翔的机的的飞行员、以一个雷暴要紧。
:::

::: exercise 平均的自由程 {level=2 check="4.4"}
求一个在$30\ \mathrm{km}$的空气的分子的平均的自由程、那里$p = 12\ \mathrm{hPa}$、$T = 230\ \mathrm{K}$、以微的的米。
::: solution
$\lambda = 0.066\times(1013/12)\times(230/293) = 4.4\ \mu\mathrm{m}$。云的的滴在半径$10\ \mu\mathrm{m}$、所以它们横的的几个平均的自由程——足够小的以至于在它们的的阻的的力以坎宁汉的的因子校正、为什么降水的的章的终的的速的度的的公带的滑的的移的的校正。
:::

::: exercise 的的高度测量 {level=2 check="215"}
一个在一个$3000\ \mathrm{m}$的指示的高度的飞机飞过一个比标准温暖$20\ ^\circ\mathrm{C}$的的层。以的的米的估计真的的高度误差。
::: solution
一个的的层的厚度正比于它的平均的虚的温度。从表面到$3000\ \mathrm{m}$的标准的的层有一个$288 - 6.5\times1.5 = 278\ \mathrm{K}$的平均；温暖的的层有$298\ \mathrm{K}$。真的的高度因此
$$
3000\times\frac{298}{278} = 3215\ \mathrm{m},
$$
所以飞机比指示的高$215\ \mathrm{m}$。每$10\ ^\circ\mathrm{C}$的$4\%$的经验规则给$240\ \mathrm{m}$、符的号的要紧的：在温暖的的空气飞机比盘的的高、在冷的的空气它低的、它事的的故。
:::
:::

::: exercise 推导静力学的方方的的方程 {level=3}
从一个的的层的静的平衡、理的气体方推导静力学的方方的的方程、在它的温度以高度线性的变化、$T = T_1 - \gamma z$、证明使用的层的的均的温度对数的平均、不算术的平均。对一个$1000$–$500\ \mathrm{hPa}$的层带一个$288\ \mathrm{K}$的表面温度、一个$6.5\ \mathrm{K\,km^{-1}}$的落率、用算术的平均的误差多大？
::: solution
以$T(z) = T_1 - \gamma z$、
$$
\ln\frac{p_1}{p_2} = \frac{g}{R_d}\int_0^{\Delta z}\frac{\mathrm{d}z}{T_1-\gamma z} = \frac{g}{R_d\gamma}\ln\frac{T_1}{T_1-\gamma\Delta z},
$$
所以$\Delta z = (R_d/\gamma)(T_1 - T_2)$——它算术的平均的的形一样、因为对一个线性的剖的的的的线$1/T$的积分恰$\Delta z$除以端的温度的对数的的平均。当剖的的的的线在$z$线性时算术的平均高的估厚度、因为的的层在冷的的顶花它的更多的质量。

对数：$T_2 = 288 - 6.5\times5.5 = 252\ \mathrm{K}$、算术的平均$270\ \mathrm{K}$、对数的的平均$(288-252)/\ln(288/252) = 36/0.1335 = 269.6\ \mathrm{K}$。差$270$的平均的$0.4\ \mathrm{K}$、给$5500$的$8\ \mathrm{m}$——可忽略的。误差只对很厚的的层、很强弯曲的剖的的的的线要紧、为什么业务的实践使用层的算术的平均、差忽略。
:::
:::

::: exercise 太空的边缘 {level=3}
的的卡门线常定义为一个的载具必须以太的的道的速的行走来产生足够的的举的的力以支撑它自己的高度。取密的的度以$H = 7\ \mathrm{km}$从$\rho_0 = 1.225\ \mathrm{kg\,m^{-3}}$指数的落下、在$100\ \mathrm{km}$的太的的道的速的$7.9\ \mathrm{km\,s^{-1}}$、一个的的机翼的的负的的载$W/S = 1000\ \mathrm{N\,m^{-2}}$。求在太的的道的速的举的的力等重的密的的度、对应的高度、讨论为什么答案一个约定。
::: solution
每单位的面积的举的的力$\tfrac{1}{2}\rho V^2 C_L$；以$C_L = 1$、$W/S = 1000\ \mathrm{N\,m^{-2}}$、
$$
\rho = \frac{2(W/S)}{V^2} = \frac{2000}{(7900)^2} = 3.2\times10^{-5}\ \mathrm{kg\,m^{-3}},
$$
海平面密的的度的$2.6\times10^{-5}$、在一个高度
$$
z = -H\ln(\rho/\rho_0) = 7\times\ln(3.8\times10^{4}) = 7\times10.5 = 74\ \mathrm{km}.
$$
计算给$74\ \mathrm{km}$、不$100$；西奥多·卡门的最初的的数近$83\ \mathrm{km}$、$100\ \mathrm{km}$的线国际航空的的联合会采用的整的的数、因为它一个整的的数、方使的。诚实的说法没的的的的边缘：密的的度平的的滑的的的的的的的、平均的自由程从微的的米生长给公里、航空在80到120 km之间逐渐的让位给航天的、在法律要紧的线一个政府决定的保卫的。
:::

::: exercise 一个探空 {level=3}
一个探空仪报告：表面$1006\ \mathrm{hPa}$、$18\ ^\circ\mathrm{C}$；$850\ \mathrm{hPa}$、$12\ \mathrm{C}$；$700\ \mathrm{hPa}$、$4\ ^\circ\mathrm{C}$；$500\ \mathrm{hPa}$、$-14\ ^\circ\mathrm{C}$；$300\ \mathrm{hPa}$、$-44\ ^\circ\mathrm{C}$。以厚度计算每一个的的层的平均的落率、识别标准的大气、这个探空最不同的的水的的平。
::: solution
以$\Delta z = 67.4\,\overline{T_\text{v}}\log_{10}(p_1/p_2)$、以报告的的值层的的均的温度：
$1006$–$850$：$\overline{T} = 288\ \mathrm{K}$、$\Delta z = 1350\ \mathrm{m}$、落率$(18-12)/1.35 = 4.4\ \mathrm{K\,km^{-1}}$。
$850$–$700$：$\overline{T} = 280.5$、$\Delta z = 1420$、率$(12-4)/1.42 = 5.6$。
$700$–$500$：$\overline{T} = 267.5$、$\Delta z = 2170$、率$(4+14)/2.17 = 8.3$。
$500$–$300$：$\overline{T} = 247.5$、$\Delta z = 3140$、率$30/3.14 = 9.6$。

从$700$到$500\ \mathrm{hPa}$的层的$8.3\ \mathrm{K\,km^{-1}}$近干绝热的的率$9.8$、远标准的$6.5$、最低的的层的$4.4$稳定的。探空因此在地的的面稳定的、在对流层的中间的条件稳定的、标准的大气、这个剖的的的的线在最的的一的的公里最不同、在它的真的的剖的的的的线亚绝热的、标准的不。
:::
