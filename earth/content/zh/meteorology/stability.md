取一袋空气，把它向上推一百米，然后松手。它是回来、留在原处、还是加速离去，这就是大气稳定度的全部；而从这个回答里，可以推出下午是晴还是雨、麦子会不会被冰雹打倒、城市上空的污染会在中午散掉还是要留到星期四。大气对小位移几乎总是稳定的，对大位移却常常是不稳定的——这就是"今天稳定吗"这个问题在你说明打算把空气抬多高之前没有答案的原因。

::: proposition 干稳定度与浮力频率 {#prop-dry-stability}
一个上升落得足够快、来不及与周围交换热量的气块遵守泊松方程，因此它的温度按**干绝热直减率**变化
$$
\Gamma_d = \frac{g}{c_p} = 9.8\ \mathrm{K\,km^{-1}},
$$
它的**位温** $\theta = T(1000/p)^{0.286}$ 守恒。它的浮力为 $B = g(T_p - T_\text{env})/T_\text{env} \approx -g\,\Delta z\,(\Gamma_\text{env} - \Gamma_d)/T$，于是运动方程为
$$
\frac{\mathrm{d}^2\Delta z}{\mathrm{d}t^2} = -N^2\,\Delta z, \qquad N^2 = \frac{g}{\theta}\frac{\mathrm{d}\theta}{\mathrm{d}z},
$$
其中 $N$ 是**浮力频率**。若 $\Gamma_\text{env} > \Gamma_d$ 则大气绝对不稳定，相等则中性，更小则稳定；等价地说，若 $\theta$ 随高度增加则稳定。对典型的 $N = 0.01\ \mathrm{s^{-1}}$，气块以 $2\pi/N = 10$ 分钟的周期振荡，正是这些振荡造出波状云，也让滑翔机飞行员感到平滑的升降气流而毫无热湍流。
:::

::: proof
取相距 $\Delta z$ 的两个相邻层次，环境温度分别为 $T_e(z)$ 与 $T_e(z+\Delta z)$，于是 $T_e(z+\Delta z) = T_e(z) - \Gamma_\text{env}\Delta z$。一个从 $z$ 抬升的气块到达 $z + \Delta z$ 时具有 $T_p = T_e(z) - \Gamma_d\Delta z$。它的加速度为
$$
a = g\frac{T_p - T_e(z+\Delta z)}{T_e} = g\frac{(\Gamma_\text{env}-\Gamma_d)\Delta z}{T_e},
$$
当 $\Gamma_\text{env} < \Gamma_d$ 时这是一个恢复力。用 $\theta$ 写同一件事，因为 $\mathrm{d}\ln\theta/\mathrm{d}z = (1/T)\mathrm{d}T/\mathrm{d}z + g/T = (1/T)(g - c_p\Gamma)$，一个 $\mathrm{d}\theta/\mathrm{d}z > 0$ 的环境廓线给出 $N^2 > 0$ 与 $\omega = N$ 的简谐运动。∎

这些数字值得记住。标准大气的环境直减率为 $6.5\ \mathrm{K\,km^{-1}}$，$N \approx 0.012\ \mathrm{s^{-1}}$；在一个强逆温中 $N$ 达到 $0.03\ \mathrm{s^{-1}}$，气层稳定到表面层的湍流碎裂成离散的、间歇的涡卷，夜间表现为薄云后面星光的闪烁；在一个晴朗的对流边界层中 $N$ 降到接近零，这正是"混合良好"的含义。
:::

::: definition 探空的几个层次 {#def-levels}
四个高度概括了对流预报员所关心的探空。**抬升凝结高度**（LCL）是抬升的气块饱和之处，每开尔文露点亏缺 $125\ \mathrm{m}$，也是晴好积云的底。**自由对流高度**（LFC）是气块开始具有浮力之处，它位于 LCL 之上或与之重合，地面到 LFC 之间的负面积就是对流抑制能。**平衡高度**（EL）是气块失去浮力之处，也是砧状云的高度；稍高处靠动量到达的**气块最高上升高度**是顶。**冻结高度**，即环境温度经过 $0\ ^\circ\mathrm{C}$ 之处，不是气块的层次，却决定降水的相位与冰雹增长带的高度。第五个层次在热带与冷空气爆发中很重要：**混合层顶**，边界层混合良好的位温在此让位于自由大气，其上的空气在构造上比其下任何部分都更稳定。
:::

::: example 浮力周期 {#ex-buoyancy}
一次探空给出在 $600\ \mathrm{m}$ 为 $12\ ^\circ\mathrm{C}$、$940\ \mathrm{hPa}$，在 $1100\ \mathrm{m}$ 为 $4\ ^\circ\mathrm{C}$、$890\ \mathrm{hPa}$。求位温、稳定度与浮力周期。
::: solution
$\theta_1 = 285.2\times(1000/940)^{0.286} = 285.2\times1.0183 = 290.4\ \mathrm{K}$，$\theta_2 = 277.2\times(1000/890)^{0.286} = 277.2\times1.0353 = 287.0\ \mathrm{K}$。位温随高度**递减**，五百米内减 $3.4\ \mathrm{K}$，所以这一层绝对不稳定——这是一个白天的混合层，环境直减率 $8.0\ \mathrm{K\,km^{-1}}$ 接近 $\Gamma_d$，在一个混合良好的层中本应如此。

对一个稳定的情形，取同一层而让 $\theta$ 增加 $3.4\ \mathrm{K}$：
$$
N^2 = \frac{g}{\bar\theta}\frac{\Delta\theta}{\Delta z} = \frac{9.81}{288.7}\times\frac{3.4}{500} = 2.31\times10^{-4}\ \mathrm{s^{-2}}, \qquad N = 0.0152\ \mathrm{s^{-1}},
$$
周期为 $2\pi/N = 413\ \mathrm{s}$，七分钟。在这层中向上位移 $200\ \mathrm{m}$ 的气块以 $0.03\ \mathrm{m\,s^{-2}}$ 加速返回，并越过同样量级的幅度，于是它落回一个几分钟周期的振荡——这就是一片层状云一旦形成，就能在无风无雨中持续数小时的原因。
:::
:::

## 湿稳定度：条件性的那一种

::: proposition 湿绝热线与条件性不稳定 {#prop-conditional}
一个饱和的气块在上升时比干的气块更暖，因为凝结把潜热返还给它，它的直减率为
$$
\Gamma_s = \Gamma_d\,\frac{1 + L_v w/(R_d T)}{1 + L_v^2 w/(R_v c_p T^2)},
$$
在 $30\ ^\circ\mathrm{C}$ 的饱和空气中为 $3.5\ \mathrm{K\,km^{-1}}$，$15\ ^\circ\mathrm{C}$ 为 $4.7$，$0\ ^\circ\mathrm{C}$ 为 $6.0$，$-20\ ^\circ\mathrm{C}$ 为 $8.6$：空气越冷，携带的水越少，它就越接近干的直减率。由于 $\Gamma_s < \Gamma_d$ 恒成立，存在一段环境廓区的范围，
$$
\Gamma_s < \Gamma_\text{env} < \Gamma_d ,
$$
其中空气**未饱和时稳定、饱和时不稳定**：这就是**条件性不稳定**，它描述了大部分对流层的大部分时间。它的实用度量不是直减率，而是**对流有效位能**，
$$
\text{cape} = g\int_\text{LFC}^\text{EL}\frac{T_p - T_\text{env}}{T_\text{env}}\,\mathrm{d}z \quad \left[\mathrm{J\,kg^{-1}}\right],
$$
对气块更暖的那一层积分；以及**对流抑制能** $\text{cin}$，即自由对流高度之下的负面积。
:::

::: example cape 与上升气流 {#ex-cape}
一个气块在 $2$ 至 $4\ \mathrm{km}$ 之间比环境暖 $3\ \mathrm{K}$，在 $4$ 至 $7\ \mathrm{km}$ 之间暖 $6\ \mathrm{K}$，在 $7$ 至 $10\ \mathrm{km}$ 之间暖 $2\ \mathrm{K}$，三层的环境平均温度分别为 $290$、$270$、$240\ \mathrm{K}$。求 cape 与最大上升气流。在 $2\ \mathrm{km}$ 以下气块在平均温度 $295\ \mathrm{K}$ 的层中冷 $2\ \mathrm{K}$：求 cin。
::: solution
$$
\text{cape} = 9.81\left[\frac{3\times2000}{290} + \frac{6\times3000}{270} + \frac{2\times3000}{240}\right] = 9.81\left[20.7 + 66.7 + 25.0\right] = 1100\ \mathrm{J\,kg^{-1}},
$$
以及
$$
\text{cin} = 9.81\times\frac{2\times1000}{295} = 66\ \mathrm{J\,kg^{-1}}.
$$
若全部 cape 都变成垂直速度，上升气流可达 $w = \sqrt{2\times1100} = 47\ \mathrm{m\,s^{-1}}$。观测到的上升气流是它的二分之一到三分之二，因为环境空气的夹卷使气块更重更冷，也因为加速的气块激发的气压扰动反抗它自己的加速度；还有三分之一的 cape 花在补偿的下沉气流与它驱动的冷空气团的动能上。一个 $1100\ \mathrm{J\,kg^{-1}}$ 带 $66\ \mathrm{J\,kg^{-1}}$ 抑制的日子是普通的强对流天气日：够一个有 $25\ \mathrm{m\,s^{-1}}$ 上升气流的风暴，若 $-10\ ^\circ\mathrm{C}$ 层不太高还会有冰雹，还有阵风锋；但若风切变不大，还不够一个超级单体。

抑制能是更有意思的数。每千克六十焦耳不算多的能量，但它足以阻止气块上升，直到地面增暖两三度、直到一条辐合线提供每秒一米量级的垂直速度；这也是为什么最猛烈的冰雹与最强的阵风来自那些被抑制到傍晚的风暴——cape 整天在盖子之下积累，然后一次性释放。
:::
:::

::: example 混合层，为什么云底整天在升高 {#ex-mixed-layer}
上午十点，边界层深 $1.2\ \mathrm{km}$，混合良好，位温 $292\ \mathrm{K}$，混合比 $10\ \mathrm{g\,kg^{-1}}$，上面被一个逆温盖住，盖上的自由大气 $\theta = 300\ \mathrm{K}$、$w = 2\ \mathrm{g\,kg^{-1}}$。到下午四点，这层夹卷了 $0.6\ \mathrm{km}$ 的自由空气。求新的地面温度、露点与云底高度。
::: solution
混合守恒一个守恒量的质量加权平均，所以
$$
\bar\theta = \frac{292\times1.2 + 300\times0.6}{1.8} = 294.7\ \mathrm{K}, \qquad
\bar w = \frac{10\times1.2 + 2\times0.6}{1.8} = 7.3\ \mathrm{g\,kg^{-1}}.
$$
在 $1000\ \mathrm{hPa}$ 的地面气压下温度为 $294.7\ \mathrm{K}$，即 $21.5\ ^\circ\mathrm{C}$；$7.3\ \mathrm{g\,kg^{-1}}$ 的混合比对应 $11.7\ \mathrm{hPa}$ 的汽压与 $9.2\ ^\circ\mathrm{C}$ 的露点。抬升凝结高度因此是 $125\times(21.5-9.2) = 1540\ \mathrm{m}$，只比 $1.8\ \mathrm{km}$ 的混合层顶略低：上午那些云底在 $1.2\ \mathrm{km}$ 的积云，已升到 $1.5\ \mathrm{km}$ 并稀薄成几缕残片。

这是一个大陆内部晴朗夏日的一天历程，它同时解释了三件事。云底在整个下午升高，是因为气层加深、变干，而不是因为任何东西失去了水分。地面的相对湿度从上午的九十百分之一降到傍晚的四十百分之一，而天气毫无变化。在沙漠里同一个过程会失控：混合层夹卷的空气太干，抬升凝结高度永远达不到，天空保持晴朗，地面继续增温，气层长到三四公里——这个深厚而干燥的对流层，正是撒哈拉与阿拉伯半岛的沙暴起飞的地方。

::: example 读一张探空 {#ex-sounding}
一次探空报告：地面 $28\ ^\circ\mathrm{C}$、露点 $20\ ^\circ\mathrm{C}$；$850\ \mathrm{hPa}$ 为 $22/18$；$700\ \mathrm{hPa}$ 为 $14/4$；$500\ \mathrm{hPa}$ 为 $-2/-20$；$400\ \mathrm{hPa}$ 为 $-12/-34$；在 $450\ \mathrm{hPa}$ 温度为 $-8\ ^\circ\mathrm{C}$、露点为 $-30\ ^\circ\mathrm{C}$。识别各层，并说明这个廓线是否支持深对流。
::: solution
地面层是湿的，露点亏缺 $8\ \mathrm{K}$，抬升凝结高度在 $125\times8 = 1000\ \mathrm{m}$。在 $850$ 与 $700\ \mathrm{hPa}$ 之间，温度在这两个等压面之间的 $1.5\ \mathrm{km}$ 内下降 $8\ \mathrm{K}$，直减率 $5.3\ \mathrm{K\,km^{-1}}$——稳定，而且露点亏缺在增大，这是一个夹卷层，或是一个湿边界层之上的干空气层。在 $700$ 与 $500\ \mathrm{hPa}$ 之间，直减率为 $16\ \mathrm{K}$ 比 $2.1\ \mathrm{km} = 7.6\ \mathrm{K\,km^{-1}}$，接近湿绝热，条件性不稳定。在 $500$ 与 $400\ \mathrm{hPa}$ 之间是 $10\ \mathrm{K}$ 比 $1.6\ \mathrm{km} = 6.3\ \mathrm{K\,km^{-1}}$，同样接近湿中性。

重要的特征是以太 $450\ \mathrm{hPa}$ 为中心的那一层，温度从 $-2$ 升到 $-8$ 再回到 $-12$：一个逆温，其中含着非常干的空气（露点 $-30\ ^\circ\mathrm{C}$）。这是从西边西部沙漠平流来的经典**抬升混合层**或**干槽**，它有两个效果。蒸发的降水落进那团干空气里会冷却气柱，能制造一个强冷空气团与一场破坏性的大风；而逆温本身是一个盖子，所以即使 $500\ \mathrm{hPa}$ 之上的空气条件性不稳定，地面气块仍可能被抑制。因此预报不是"cape 为 $2000\ \mathrm{J\,kg^{-1}}$，四点钟下冰雹"，而是"风暴很可能以风为主而非带冰雹，而且只在边界层湿到足以打破盖子的地方"。
:::

::: warning 三句常说而错误的话
**"暖空气上升。"** 暖空气上升不是因为它暖，而是因为它*比同一高度的空气更暖*；一个 $30\ ^\circ\mathrm{C}$ 的气块在 $35\ ^\circ\mathrm{C}$ 的环境中会下沉。浮力是一个差，不是一个温度——这就是为什么有 $30\ ^\circ\mathrm{C}$ 地面空气的热带，常常不如一个地面空气 $15\ ^\circ\mathrm{C}$、环境 $-5\ ^\circ\mathrm{C}$ 的冷锋云系不稳定。**"今天不稳定能量很多，所以会有风暴。"** 条件性不稳定在温带的对流层里几乎每个夏日都存在；制造风暴的是触发机制、湿静力能的供应，以及小到足以克服的抑制能；预报员忽视最后这一条而丢掉的预报，比任何别的错误都多。**"云在耗尽水分时停止生长。"** 积云停止生长是因为它变得比环境更密——通常因为它夹卷了干空气、蒸发掉了一些水，或者因为它到达了一个稳定层——而地球上最强的风暴靠上升气流的动量，会穿过自己的平衡高度好几公里。
:::

::: quiz
环境直减率为 $7\ \mathrm{K\,km^{-1}}$，气块未饱和。它是：
- [ ] 绝对不稳定，对流会发展
- [x] 对小位移稳定，但若抬升到饱和则可能不稳定
- [ ] 中性，因为它接近干绝热直减率
- [ ] 对任何位移都稳定
::: solution
$7\ \mathrm{K\,km^{-1}}$ 小于 $\Gamma_d = 9.8$，所以未饱和的气块会被拉回：空气对小位移稳定。但暖空气中饱和直减率为 $4$–$6\ \mathrm{K\,km^{-1}}$，小于 $7$，因此抬升到饱和的气块变得比环境更暖、自由上升。这就是条件性不稳定，是夏季对流层大部分的状态：在有什么东西把它抬起来之前，它是稳定的。
:::

空气上升时因膨胀而冷却的观念，来自对声音的研究。拉普拉斯在1816年注意到牛顿对声速的计算小了百分之四十，并通过论证声波中的压缩与稀疏快得来不及传导热量而修正了它，因此相关的弹性是绝热的弹性——这是绝热指数第一次用在大气上。泊松在1808年写下方程 $p^\gamma/\rho^\gamma = \text{常数}$，英国旧文献中的位温用的就是他的名字。湿绝热线由兰金在1855年的一张蒸汽机图件中求出，蔡纳独立地做了同样的工作；而预报员今天仍在上面作图的截角气温对数压图，由肖在1930年设计，此前他倡导了四分之一世纪。肖当过电报报务员，还提出天气预报是一个能量而非力的问题，并创建了以气块作为这门学科单元的那个学派。抬升凝结高度在1890年代由冯·贝索尔德的云底观测在现场测得，并在同一个十年由希尔得布兰德松与阿斯曼的探空给出解释。今天每一张业务探空都绘制其上的斜温对数压图，是莫克在1940年代的改造。cape 的概念通过蒙克里夫与米勒1976年的热带飑线理论进入气象学；用探空预报强对流风暴，则是1980与1990年代美英风暴预报组的工作，尤其是美国强风暴实验室的冰雹与大风指数。
:::

## 通向何处

本章的气块理论用于[[meteorology/clouds-precipitation]]中的探空与[[meteorology/storms]]中的风暴；地面气块在其中获得温度与水分的边界层在[[atmospheric-dynamics/boundary-layer]]；湿静力能与 $\theta_e$ 在[[atmospheric-dynamics/moist-thermodynamics]]中形式化；对流层的平均状态——它的直减率由辐射-对流平衡、而非任何单个气块决定——在[[atmospheric-dynamics/thermodynamics]]与[[climate-system/greenhouse-effect]]。

::: summary 关键的收获
- 位移的气块以 9.8 K/km 干绝热运动、守恒位温；位温随高度增加时大气稳定。
- 浮力频率 N 度量稳定度，位移的气块以 2 pi / N 的周期振荡，在典型的稳定层中约十分钟。
- 饱和直减率在湿热空气中为 3.5 K/km、在冷空气中为 8.6，永远低于干的直减率，所以对流层大部分是条件性不稳定的：在抬升之前是稳定的。
- Cape 是探空上的正面积，给出约 sqrt(2 cape) 的上升气流，因夹卷与气压阻力而减小一半；cin 是必须先打破的盖子。
- 探空要读它的层，而不是它的数：盖逆温、干槽、湿边界层、接近湿中性的中对流层，各自意味着一种不同的风暴。
- 浮力是温度之差，不是温度；没有触发的不稳定什么也不产生。
:::

## 练习题

::: exercise 位温 {level=1 check="302.3"}
求 $20\ ^\circ\mathrm{C}$、$900\ \mathrm{hPa}$ 的空气的位温。
::: solution
$\theta = 293.2\times(1000/900)^{0.286} = 293.2\times1.0310 = 302.3\ \mathrm{K}$。（以开尔文保留一位小数：$302.3$。）
:::
:::

::: exercise 由位温求稳定度 {level=1 check="0.014"}
位温从 $800\ \mathrm{m}$ 的 $292\ \mathrm{K}$ 升到 $1300\ \mathrm{m}$ 的 $295\ \mathrm{K}$。求浮力频率，以 $\mathrm{s^{-1}}$ 计。
::: solution
$N^2 = (9.81/293.5)\times(3/500) = 2.0\times10^{-4}$，所以 $N = 0.0141\ \mathrm{s^{-1}}$，周期 $7.4$ 分钟。
:::
:::

::: exercise 饱和直减率 {level=1 check="8.6"}
$-20\ ^\circ\mathrm{C}$ 的饱和空气混合比为 $0.8\ \mathrm{g\,kg^{-1}}$。用命题中的表达式估计 $\Gamma_s$。
::: solution
分子因子为 $1 + 2.5\times10^6\times8\times10^{-4}/(287\times253) = 1.027$，分母为 $1 + (2.5\times10^6)^2\times8\times10^{-4}/(461.5\times1005\times253^2) = 1.164$，所以 $\Gamma_s = 9.8\times1.027/1.164 = 8.6\ \mathrm{K\,km^{-1}}$。冷空气几乎是干的，冷空气中的对流几乎中性：这就是为什么冷空气爆发中的极地海面布满浅积云、却从不见雷暴。
:::
:::

::: exercise cape {level=1 check="944"}
一个气块在平均温度 $260\ \mathrm{K}$ 的 $5\ \mathrm{km}$ 层中比环境暖 $5\ \mathrm{K}$。求 cape，以 $\mathrm{J\,kg^{-1}}$ 计。
::: solution
$\text{cape} = 9.81\times5\times5000/260 = 944\ \mathrm{J\,kg^{-1}}$。（取最接近的整数：$944$。）
:::
:::

::: exercise 上升气流 {level=2 check="45"}
求 cape 为 $1000\ \mathrm{J\,kg^{-1}}$ 的理论最大上升气流，以 $\mathrm{m\,s^{-1}}$ 计。
::: solution
$w = \sqrt{2\times1000} = 45\ \mathrm{m\,s^{-1}}$；观测到的上升气流通常是它的三分之二，即 $30\ \mathrm{m\,s^{-1}}$。能在 $30\ \mathrm{m\,s^{-1}}$ 的上升气流中存活的冰雹，在气流崩溃之前可以长到五厘米半径。
:::
:::

::: exercise 盖逆温 {level=2 check="153"}
一个气块在平均温度 $288\ \mathrm{K}$、深 $1.5\ \mathrm{km}$ 的逆温中比环境冷 $3\ \mathrm{K}$。求 cin，以 $\mathrm{J\,kg^{-1}}$ 计。
::: solution
$\text{cin} = 9.81\times3\times1500/288 = 153\ \mathrm{J\,kg^{-1}}$。这样强的盖子，要么需要地面增暖若干度，要么需要一条以 $0.5\ \mathrm{m\,s^{-1}}$ 的垂直速度作用半小时的中尺度辐合线；这就是为什么有盖子的日子风暴来得突然、一齐到来、而且很晚。
:::
:::

::: exercise 夹卷 {level=2 check="0.33"}
一个 $1\ \mathrm{km^3}$ 的气块在上升时以每千克自身质量 $2\ \mathrm{kg}$ 的速率夹卷环境空气。到一阶为止，它的超额熵（它的 $T_p - T_e$）按什么因子减小？
::: solution
把气块与两倍于它质量的环境空气混合，会使它的温度落到环境值的三分之一以内，因此浮力降到 $1/(1+2) = 0.33$ 的因子。夹卷是真实的 cape 只有探空 cape 一半的主要原因，也是为什么一个具有强而连贯的上升气流的风暴（超级单体，它的上升气流被后侧下沉气流与环境隔开，因而夹卷很少）会胜过一张同样的探空但没有切变的情形。
:::
:::

::: exercise 推导干直减率 {level=3}
由热力学第一定律与静力平衡推导 $\Gamma_d = g/c_p$，并计算它在火星表面（$c_p = 850\ \mathrm{J\,kg^{-1}\,K^{-1}}$，$g = 3.72\ \mathrm{m\,s^{-2}}$）的二氧化碳上、在木星（$c_p = 14{,}300$，$g = 24.8$）的氢上的值。说明这对两个行星的直减率的后果。
::: solution
可逆绝学位移的热力学第一定律给 $c_p\,\mathrm{d}T = v\,\mathrm{d}p = \mathrm{d}p/\rho$，静力平衡给 $\mathrm{d}p = -\rho g\,\mathrm{d}z$，所以 $\mathrm{d}T/\mathrm{d}z = -g/c_p$。火星 $\Gamma_d = 3.72/850 = 4.4\ \mathrm{K\,km^{-1}}$；木星 $24.8/14300 = 1.7\ \mathrm{K\,km^{-1}}$。

干绝热线因此在火星上很陡、在木星上几乎平，这就是观测到的环境直减率差别如此之大的原因：火星的边界层在下午近地面以 $4$–$5\ \mathrm{K\,km^{-1}}$ 进行，基本上是绝热与对流的；而木星可见的云顶位于接近氢绝热线的辐射廓线附近。在水汽的存在下，地球打破了这两者之间的僵局：湿绝热线远小于 $\Gamma_d$，对流把热带对流层钉在 $6.5\ \mathrm{K\,km^{-1}}$ 附近——这就是热带对流层顶是一个冷陷阱、平流层的水汽含量由寒冷的赤道对流层顶的温度、而不是由降雨量决定的原因。
:::
:::

::: exercise 装弹的枪 {level=3}
同一站的每日探空给出：06 时地面温度 $24\ ^\circ\mathrm{C}$、露点 $21\ ^\circ\mathrm{C}$，在 $900\ \mathrm{hPa}$ 有一个温度上升 $4\ \mathrm{K}$ 的逆温；到 15 时，边界层已混合到 $600\ \mathrm{m}$，地面温度 $31\ ^\circ\mathrm{C}$、露点 $20\ ^\circ\mathrm{C}$。估计 cape 与 cin 的变化，并解释这样一天的风暴为什么在下午五点、而不是在正午到来。
::: solution
把气层混合到 $600\ \mathrm{m}$，会使地面空气的温度变为它所混合的气层的平均、露点下降，因此混合层的位温上升而水分大致守恒。抬升凝结高度从 $125\times3 = 375\ \mathrm{m}$ 升到 $125\times11 = 1375\ \mathrm{m}$，气块从一个更暖、更干、更高的起点出发。

cin 下降，因为混合层侵蚀了逆温的底：06 时那 $4\ \mathrm{K}$ 的抑制，分布在地面与混合层顶之间的 $300\ \mathrm{m}$ 上，随着混合层啃食盖子而减弱，到午后气块带着足够的浮力到达逆温并冲破它。cape 上升，因为同一次混合把一层深厚的、温暖的、条件性不稳定的空气放到近地面，而中对流层未变。结果是这样一个日子：上午晴朗，正午炎热而无风，两点出现第一朵积云，五点整个天空同时发展成一排风暴，背后是十个小时增温积累的 cape。这就是大陆中纬度强对流的日循环，也是世界上警报系统围绕下午建造的原因。
:::
