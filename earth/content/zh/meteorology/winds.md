1857年，荷兰气象学家白贝罗发表了任何水手都会用、而没有物理学家能解释的一条规则：在南半球，背风而立，低气压在你的左手边。这条规则被航海者注意了一个世纪，自电报发明以来也被风暴警报所注意，而它说了一件了不起的事。空气不是从高压流向低压的。它*横穿*气压场运动，而且准确到拿着气压图、没有风速计的预报员能把风报准到百分之二十以内。理解为什么需要旋转参考系的力学工具，这个故事从牛顿的《原理》经过欧拉与拉普拉斯到1835年的科里奥利、1856年的费雷尔，再到埃克曼，他在1905年解出了南森观察到却无法解释的冰的漂移。

::: proposition 水平力与地转风 {#prop-geostrophic}
旋转地球上水平运动的运动方程为
$$
\frac{\mathrm{d}\mathbf{u}}{\mathrm{d}t} = -\frac{1}{\rho}\nabla_h p - f\,\mathbf{k}\times\mathbf{u} + \mathbf{F}, \qquad f = 2\Omega\sin\phi = 1.03\times10^{-4}\sin\phi\ \mathrm{s^{-1}},
$$
其中 $f$ 是**科里奥利参数**：赤道为 $0.38\times10^{-4}$，$45^\circ$ 为 $1.03\times10^{-4}$，极点为 $1.46\times10^{-4}$。在远离赤道、边界层之上、尺度大于约 $20\ \mathrm{km}$ 的地方，摩擦可以忽略，加速度与前两项相比很小，于是
$$
v_g = -\frac{1}{\rho f}\frac{\partial p}{\partial x}, \qquad u_g = \frac{1}{\rho f}\frac{\partial p}{\partial y},
$$
即**地转风**：它平行于等压线吹，在北半球低压在左，其速度正比于气压梯度、反比于纬度。这个平衡在天气尺度上准确到几个百分点，这就是地面天气图是一张风图的原因。
:::

::: proof
在以角速度 $\boldsymbol\Omega$ 旋转的参考系中，惯性系中的加速度为 $\mathbf{a}_\text{in} = \mathbf{a}_\text{rot} + 2\boldsymbol\Omega\times\mathbf{u} + \boldsymbol\Omega\times(\boldsymbol\Omega\times\mathbf{r})$。最后一项被吸收进重力，因为重力是在旋转系中测量的、已经包含离心势；中间一项是科里奥利加速度。取 $\boldsymbol\Omega = \Omega(0,\cos\phi,\sin\phi)$、$\mathbf{u} = (u,v,0)$，$2\boldsymbol\Omega\times\mathbf{u}$ 的水平分量为 $(-f v, f u)$，其中 $f = 2\Omega\sin\phi$；而包含 $2\Omega\cos\phi\,u$ 的垂直分量，与水平分量之比等于垂直尺度与水平尺度之比，在静力、薄壳近似中被舍弃。

令左端与摩擦为零，用 $p_x, p_y$ 表示梯度，
$$
0 = -p_x/\rho + f v, \qquad 0 = -p_y/\rho - f u,
$$
即得上面那一对式子。∎

有两个推论每天都在用。第一，地转风要求 $f \ne 0$：在赤道约 $5^\circ$ 以内这个平衡失效，这就是热带气旋不在那里形成、赤道大气由另一套近似支配的原因。第二，风正比于气压梯度力，所以地面图上的等压线疏密就是一张风图：在 $45^\circ$ 纬度、$1000\ \mathrm{hPa}$，每 $500\ \mathrm{km}$ 相差 $5\ \mathrm{hPa}$ 的等压线给出 $10\ \mathrm{m\,s^{-1}}$，每 $500\ \mathrm{km}$ 相差 $2.5\ \mathrm{hPa}$ 给出 $5\ \mathrm{m\,s^{-1}}$，而一个深低压周围密集的等压线给出风暴级的风。
:::

::: example 读等压线 {#ex-isobars}
在 $50^\circ\mathrm{N}$ 的一张地面图上，等压线每 $5\ \mathrm{hPa}$ 画一条，在 $1:1000$ 万的比例尺上相距 $6\ \mathrm{mm}$，气压向北降低。估计地面风速与风向，以及地转风。
::: solution
水平距离为 $6\ \mathrm{mm}\times10^7 = 60\ \mathrm{km}$，所以梯度为每 $60\ \mathrm{km}$ $5\ \mathrm{hPa}$ $= 8.3\times10^{-3}\ \mathrm{Pa\,m^{-1}}$。以 $\rho = 1.2\ \mathrm{kg\,m^{-3}}$、$f = 1.0\times10^{-4}\ \mathrm{s^{-1}}$，
$$
v_g = \frac{8.3\times10^{-3}}{1.2\times1.0\times10^{-4}} = 69\ \mathrm{m\,s^{-1}}.
$$
这是一个剧烈的气压梯度——这样的疏密只出现在深气旋最快的部分——地面风会是它的 $60$–$70\%$，即 $45$–$50\ \mathrm{m\,s^{-1}}$，并向低压方向横穿等压线约 $30^\circ$，所以是西风转西北风。更典型的、相距 $30\ \mathrm{km}$ 的等压线给出地转 $14\ \mathrm{m\,s^{-1}}$、$10\ \mathrm{m}$ 高处 $9\ \mathrm{m\,s^{-1}}$。

近地面的减小不是一个细节：摩擦使风减慢，而依赖于速度的科里奥利力随之减弱，气压梯度力便把空气推过等压线流向低压。结果是：地面低压除非被高空流场动态维持就会填塞，地面高压会流散，而流入低压的空气必须去某个地方——向上，每小时几毫巴，这就是低气压是云、高气压是蓝天的原因。
:::
:::

## 这个平衡不是什么

::: definition 偏差运动、惯性振荡与边界层 {#def-ageostrophic}
对平衡的偏离 $\mathbf{F}_a = -f\mathbf{k}\times(\mathbf{u}-\mathbf{u}_g)$ 是**偏差力**，它做两件事。把它施于一个完全没有气压梯度力的气块，得到**惯性振荡**：气块以**惯性周期** $2\pi/f = 11.97/\sin\phi$ 小时绕圈——极点 $12$ 小时、$45^\circ$ 为 $17$ 小时、$15^\circ$ 为 $48$ 小时——在一个半径 $V/f$ 的**惯性圆**上，$45^\circ$ 处 $10\ \mathrm{m\,s^{-1}}$ 的风对应 $100\ \mathrm{km}$。在近地面，湍流摩擦的应力向上减小，使风在陆地上横穿等压线 $10$–$30^\circ$、在海面上 $5$–$10^\circ$；自由大气的**埃克曼层**在几百米内做同样的事：风矢量描出一条**螺线**，而它在整层上积分的输送，恰好与地转风成直角、在北半球偏右。这个输送很小——每秒一厘米——而大气靠它把自己刹停，锋靠它变锐，海洋表层靠它以四十五度角随风驱动的方向移动。
:::

::: example 惯性圆与埃克曼螺线 {#ex-inertial}
北大西洋的一艘气象船记录到，一场风暴过去、天空放晴之后，风在十七小时内稳定地顺时针转完 $360^\circ$，速度几乎不变。解释之，并求气块路径的纬度与半径。
::: solution
周期指出了纬度：$2\pi/f = 17\ \mathrm{h}$ 给出 $\sin\phi = 11.97/17 = 0.70$、$\phi = 45^\circ$。这是经典的锋后惯性振荡，在海洋上、在夜间表面层与其上空气脱耦时看得最清楚；$10\ \mathrm{m}$ 处的风在整个夜里顺时针转去又转回，而在夜间逆温之上 $300\ \mathrm{m}$ 形成的低空急流是同一现象在边界层中的版本。

对 $12\ \mathrm{m\,s^{-1}}$ 的风，半径为
$$
R = \frac{V}{f} = \frac{12}{1.0\times10^{-4}} = 1.2\times10^5\ \mathrm{m} = 120\ \mathrm{km}.
$$
与这样一场风相伴的表面层的埃克曼输送为 $u_E = \tau_y/(\rho f)$；对 $0.1\ \mathrm{N\,m^{-2}}$ 的应力，在海洋混合层中为 $0.1/(1025\times1.0\times10^{-4}) = 1\ \mathrm{m\,s^{-1}}$，而在大气边界层中为每秒几毫米，因为大气这一层厚一公里、而不是百米。南森的冰以 $22^\circ$ 的偏角、约风速的 $2\%$ 漂移，埃克曼的理论复现了它，而他把这篇论文作为结婚礼物写给了南森的女儿。
:::
:::

## 随高度的风：热成风

::: proposition 热成风 {#prop-thermal-wind}
在一个**斜压**大气中，密度既依赖于压强也依赖于温度，地转风随高度变化。对地转关系取垂直导数并使用高斯方程，
$$
\frac{\partial u_g}{\partial z} = \frac{g}{f}\frac{\partial \ln T}{\partial y}, \qquad \frac{\partial v_g}{\partial z} = -\frac{g}{f}\frac{\partial \ln T}{\partial x},
$$
所以**热成风**——两个高度上地转风之间的矢量差——正比于水平温度梯度，在北半球吹时把暖空气留在左边。应用于两个等压面之间的一层，
$$
\Delta V_g = \frac{g}{f\,\overline{T}}\left|\nabla_h \Delta z\right|,
$$
于是穿过一层的地转风的变化，可以通过把这一层的**厚度线**当作等压线来读出。由此有两条实用的规则：随高度**顺时针转**的风标志暖平流，**逆时针转**的标志着冷平流；而一张地面图的等温线，当作厚度线来读，会告诉你在哪里有一条急流。
:::

::: proof
对 $u_g = -(1/\rho f)\,\partial p/\partial y$ 关于高度坐标 $z$ 求导，并使用 $\rho = p/(R_d T)$：
$$
\frac{\partial u_g}{\partial z} = -\frac{1}{f}\frac{\partial}{\partial y}\left(\frac{1}{\rho}\frac{\partial p}{\partial z}\right) + \ldots
$$
由于 $\partial p/\partial z = -\rho g$，压强的项相互抵消，只剩下 $1/\rho = R_dT/p$ 的导数，给出 $g\,\partial T/\partial y/(fT)$。∎

数字很大。每 $100\ \mathrm{km}$ $1\ \mathrm{K}$ 的温度梯度——一个强地面斜压带两侧的数值——给出的切变为
$$
\frac{\partial u_g}{\partial z} = \frac{g}{f\overline{T}}\frac{\partial T}{\partial y} = \frac{9.81\times10^{-5}}{1.03\times10^{-4}\times280} = 3.4\times10^{-3}\ \mathrm{s^{-1}},
$$
即每公里 $3.4\ \mathrm{m\,s^{-1}}$。穿过从地面到对流层顶的 $10\ \mathrm{km}$，这就是 $34\ \mathrm{m\,s^{-1}}$，这就是急流的起源：极锋急流位于对流层下层水平温度梯度最大的那个带上，其核心高度是梯度消失、热成风停止叠加的高度。相比之下，暖心的副热带急流之所以存在，是因为对流层顶在温暖的热带之上更高，它们在任何地面锋缺失时依然存在。
:::

::: example 从厚度到急流 {#ex-jet}
在一张 $500\ \mathrm{hPa}$ 图上，$1000$–$500\ \mathrm{hPa}$ 的厚度等值线呈东西向，向北以每 $2000\ \mathrm{km}$ $60\ \mathrm{dam}$ 递减。求平均温度梯度与地面到 $5.5\ \mathrm{km}$ 之间地转风的变化。
::: solution
厚度正比于层平均温度，$\Delta z = 67.4\,\overline{T}\log_{10}2 = 20.3\,\overline{T}$ 米，所以每 $2000\ \mathrm{km}$ $60\ \mathrm{dam} = 600\ \mathrm{m}$ 对应每 $2000\ \mathrm{km}$ $29.6\ \mathrm{K}$，即每 $100\ \mathrm{km}$ $1.5\ \mathrm{K}$——一个强斜压带，也是冬季北极锋上观测到的数值。

热成风为
$$
\Delta V_g = \frac{g\,\Delta T}{f\,\overline{T}\,\Delta y} = \frac{9.81\times1.48\times10^{-5}}{1.03\times10^{-4}\times260}\times5500 = 30\ \mathrm{m\,s^{-1}},
$$
方向自西向东，冷空气在北方。把它加到 $10\ \mathrm{m\,s^{-1}}$ 的地面地转风上，得到 $500\ \mathrm{hPa}$ 约 $30\ \mathrm{m\,s^{-1}}$ 的风；继续向上算穿过对流层上层，那里温度梯度仍然很大，得到急流轴上 $50\ \mathrm{m\,s^{-1}}$ 的西风。这就是地面图与 $500\ \mathrm{hPa}$ 图形势相似而振幅不同、以及成熟气旋的地面低压位于高空槽的下游之下、而不是正下方的原因。
:::
:::

::: definition 三圈，三带 {#def-circulation}
哈得来环流在**赤道辐合带**把空气向上输送，在高空向外，在 $25$–$30^\circ$ 纬度附近向下，并以**信风**把它送回：这是一个直接的热力环流，在上升支潮湿多雨、在下沉支干燥，这就是世界沙漠位于 $20$–$30^\circ$ 的原因。费雷尔环流不是一台热机，而是一个由涡旋驱动的剩余环流，由中纬度破碎的罗斯贝波强迫，它在大洋上拖着地面的西风。极地环流在极锋上升、在冰上沉降。叠加其上的还有季节的迁移：赤道辐合带跟着太阳的赤纬走 $5$–$10^\circ$ 的纬度，而在最大的大陆上，夏季的增温用向岸的**季风**取代信风，于是印度上空的平均地面风在一月与七月之间反转。在南半球，大陆的缺失使环流几乎是纬向的，四、五十度纬圈的**南大洋西风**不间断地绕行星一周，驱动南极绕极流，并给南半球一个由风暴、涌浪与无陆之地构成的气候。
:::

::: example 作为海风的季风 {#ex-monsoon}
印度次大陆在夏季增温到表面温度比周围海洋高 $25\ \mathrm{K}$，陆地面积 $3\times10^6\ \mathrm{km^2}$。估计陆地上下方一公里空气增温所隐含的气压下降，以及由此产生的平均气压梯度力，并把季风与海风相比较。
::: solution
若陆地上方最下一公里的空气从 $300\ \mathrm{K}$ 增暖 $25\ \mathrm{K}$，它的气柱膨胀，地面气压下降大约
$$
\Delta p \approx p\,\frac{\Delta T}{T}\times\frac{1\ \mathrm{km}}{8\ \mathrm{km}} = 1013\times0.083\times0.125 = 10.5\ \mathrm{hPa},
$$
那个因子是受影响的气柱质量所占的份额。从海洋到内陆 $1500\ \mathrm{km}$ 上，这是一个 $7\times10^{-4}\ \mathrm{Pa\,m^{-1}}$ 的梯度，在 $20^\circ$ 纬度（$f = 5\times10^{-5}$）给出 $12\ \mathrm{m\,s^{-1}}$ 的地转风——正是观测到的低空索马里急流与印度夏季季风流的强度。

机制与海风相同：表面的差异增热、静力的气压变化、一个向岸的气流。差别在尺度与厚度——季风的流厚几公里、宽一千公里，所以地球自转重要，地转平衡适用，气流平行于海岸而不是横穿它，这就是东非沿岸急流平行于索马里、而降雨落在迎风的西高止山、不落在海岸上的原因。青藏高原的表面在夏季比同高度的自由空气暖 $10\ \mathrm{K}$，它加上一个感热源，加强了高空的反气旋与把季风的雨带组织成狭窄、持久、一千公里长的云线的切变，而这些云线给次大陆提供了它大部分的水、也提供了它大部分的水灾。
:::
:::

::: warning 科里奥利力与你的洗澡水
在 $45^\circ$ 纬度、$1\ \mathrm{m\,s^{-1}}$ 的速度下，科里奥利加速度为 $10^{-4}\ \mathrm{m\,s^{-2}}$；而对放水洗澡时 $0.1\ \mathrm{m\,s^{-1}}$ 的水，它是 $10^{-5}\ \mathrm{m\,s^{-2}}$——这样一个加速度在十秒的放水过程中只会把水流偏转不到一毫米。一个浴缸里水的旋转方向由盆的形状与注水的方向决定；而在一个真正做得好的实验室实验里——三米直径的水槽，放水数小时，并先静置一天——科里奥利效应确实变得可见。同样的算术也打发了科里奥利力影响子弹飞行或高尔夫球轨迹的说法，而且值得自己算一遍、而不是听人说：规则是，当运动的时间尺度比 $1/f$ 长得多时科里奥利项才重要，在 $45^\circ$ 处 $1/f$ 约为两小时。一个寿命半小时的雷暴几乎不受影响；一个寿命一天的温带气旋由它支配；而大洋的环流，其时间为几十年，完全由它设定。
:::

- [ ] 风在各层都是地转的
::: solution
随高度逆时针转——在北半球是逆时针——意味着热成风的方向正把冷空气带走；在标准情形下，穿过一个自西向东的温度梯度的西北向热成风，意味着冷空气的西北向平流。随高度顺时针转是暖平流的特征，是逼近的暖区的经典征兆；逆时针转标志着冷空气随后而来，以及带来它的那个地面低压。
:::
:::

::: history
哈雷在1686年提出信风是太阳对热带的加热、以及空气流入取代被带走的部分的结果；哈得来在1735年一篇死后发表于《哲学汇刊》的论文中给出了机制的正确形式，其中上升的空气被地球自转偏向，而地面的回流就是信风。缺失的动力学来自科里奥利，他在1835年为水车问题列出了旋转参考系的力；也来自费雷尔，俄亥俄的一位中学教师，他在1856年看出同一个项解释了中纬度的西风，并提出了以他命名的第二个反向旋转的环流圈。白贝罗定律在1857年是经验的、并且立即可用；风是地转的这一理论理解直到1870年代马古、冯·贝索尔德与亥姆霍兹的工作才出现，而皮叶克尼斯1904年的纲领把它变成了预报的基础。边界层等到1905年与埃克曼的论文，而这篇论文的约稿是因为南森的"弗拉姆"号漂向了风的来向；自由大气的波来自罗斯贝，他在1939年把温带气旋解释为西风的失稳，并与1944年由高空飞行的 B-29 机组发现、由一位最先在大西洋航线上看见它的飞行员报告的那条急流一起，给了天气图一个三维的形状。
:::

## 通向何处

本章的方程在[[atmospheric-dynamics/equations-of-motion]]中被详细推导、并用于建立[[atmospheric-dynamics/balanced-flow]]中的平衡流层级；边界层及其摩擦在[[atmospheric-dynamics/boundary-layer]]；制造天气的波在[[atmospheric-dynamics/vorticity]]与[[meteorology/fronts-cyclones]]；热带气旋的梯度风在[[meteorology/storms]]；而平均经向环流对温室增暖的响应在[[climate-system/heat-transport]]。

::: summary 关键的收获
- 科里奥利参数是 1.03×10^-4 sin phi，在远离赤道、边界层之上，风是地转的：平行于等压线，低压在左。
- 等压线的疏密就是风：45 度处每 500 km 5 hPa 给出 10 m/s。
- 摩擦使风减慢并转向低压一侧横穿等压线，这就是低压辐合上升、高压辐散下沉的原因。
- 一个脱离平衡的气块以 23.9/sin phi 小时的周期、V/f 的半径做惯性圆周运动；锋后的夜晚是看它的最好地方。
- 热成风是地转风随高度的变化，正比于水平温度梯度：把厚度线当等压线读，而急流就是一个十公里厚的锋所隐含的东西。
- 随高度顺时针转意味着暖平流，逆时针转意味着冷。
- 平均经向环流是一个哈得来环流圈、一个涡旋驱动的费雷尔剩余环流与一个极地环流圈，其地面风带随太阳迁移、并在最大的大陆上反转。
:::

## 练习题

::: exercise 科里奥利参数 {level=1 check="1.11"}
求 $50^\circ\mathrm{N}$ 的 $f$，以 $10^{-4}\ \mathrm{s^{-1}}$ 为单位。
::: solution
$f = 2\times7.29\times10^{-5}\times\sin 50^\circ = 1.11\times10^{-4}\ \mathrm{s^{-1}}$。（以 $10^{-4}$ 为单位保留两位小数：$1.11$。）
:::
:::

::: exercise 地转风 {level=1 check="31"}
在 $55^\circ\mathrm{N}$，气压向东在 $1400\ \mathrm{km}$ 上下降 $6\ \mathrm{hPa}$。求地转风速，以 $\mathrm{m\,s^{-1}}$ 计。
::: solution
$\partial p/\partial x = 600/1.4\times10^6 = 4.3\times10^{-4}\ \mathrm{Pa\,m^{-1}}$，$f = 1.17\times10^{-4}\ \mathrm{s^{-1}}$，所以
$$
v_g = \frac{4.3\times10^{-4}}{1.2\times1.17\times10^{-4}} = 31\ \mathrm{m\,s^{-1}},
$$
一个风暴级的地转风，低压在北，即吹西风。
:::
:::

::: exercise 惯性周期 {level=1 check="17"}
求 $45^\circ$ 的惯性周期，以小时计。
::: solution
$2\pi/f = 2\pi/1.03\times10^{-4} = 6.1\times10^4\ \mathrm{s} = 17\ \mathrm{h}$。在极点为 $12$ 小时，恰为一个恒星日的一半，这就是理由：在极点，地球在一昼夜内于气块之下转动，而气块只是在空间中保持它的方向。
:::
:::

::: exercise 惯性半径 {level=1 check="96"}
求 $60^\circ$ 处一个 $12\ \mathrm{m\,s^{-1}}$ 的流的惯性圆半径，以公里计。
::: solution
$R = V/f = 12/(1.25\times10^{-4}) = 9.6\times10^4\ \mathrm{m} = 96\ \mathrm{km}$。
:::
:::

::: exercise 热成风 {level=2 check="15"}
在 $50^\circ\mathrm{N}$，一个 $2\ \mathrm{km}$ 厚的层中温度向北在 $300\ \mathrm{km}$ 上增加 $6\ \mathrm{K}$。求穿过这一层的地转风的变化，以 $\mathrm{m\,s^{-1}}$ 计。
::: solution
$\partial T/\partial y = 2\times10^{-5}\ \mathrm{K\,m^{-1}}$，所以 $\partial u_g/\partial z = 9.81\times2\times10^{-5}/(1.0\times10^{-4}\times270) = 7.3\times10^{-3}\ \mathrm{s^{-1}}$，穿过 $2\ \mathrm{km}$ 为 $14.5\ \mathrm{m\,s^{-1}}$。（取最接近的整数：$15$。）
:::
:::

::: exercise 梯度风 {level=2 check="25"}
在一个 $20^\circ\mathrm{N}$ 的飓风周围，梯度风平衡是旋衡的，$v^2/r = (1/\rho)\partial p/\partial r$。求半径 $15\ \mathrm{km}$ 的眼壁处的风，那里气压从环境到眼下降 $60\ \mathrm{hPa}$。
::: solution
取 $\partial p/\partial r = 6000/1.5\times10^4 = 0.4\ \mathrm{Pa\,m^{-1}}$，$v = \sqrt{0.4\times1.5\times10^4/1.2} = 71\ \mathrm{m\,s^{-1}}$。（取最接近的整数：$71$。）这是一个四级飓风，而这个计算表明为什么在这种曲率的涡旋中正确的平衡是梯度风、而不是地转风：科里奥利项只贡献 $fvr = 10^{-4}\times70\times1.5\times10^4 = 105\ \mathrm{m^2\,s^{-2}}$，而离心项是 $5000$。
:::
:::

::: exercise 埃克曼输送 {level=2 check="1.42"}
一个 $0.15\ \mathrm{N\,m^{-2}}$ 的风应力作用在 $45^\circ$ 的海面上。求单位宽度的埃克曼输送，以 $\mathrm{m^2\,s^{-1}}$ 计。
::: solution
$M = \tau/(\rho f) = 0.15/(1025\times1.03\times10^{-4}) = 1.42\ \mathrm{m^2\,s^{-1}}$，方向在风的右方 $90^\circ$。铺在 $100\ \mathrm{m}$ 的混合层上，这是一个 $1.4\ \mathrm{cm\,s^{-1}}$ 的流，它就是沿岸上升流的机制：一支平行于海岸吹的风把表层水推离海岸，而水必须从下方得到补充。
:::
:::

::: exercise 推导热成风 {level=3}
由高斯方程与地转证明两个等压面之间的热成风为 $f\Delta\mathbf{V}_g = g\,\mathbf{k}\times\nabla_h\overline{T}/\overline{T}$，并用它证明在一个核心位于温度梯度消失之高度的西风急流中，地转风随高度增大。给定地面温度梯度为每 $100\ \mathrm{km}$ $1\ \mathrm{K}$、线性递减到对流层顶为零，估计极锋急流的高度。
::: solution
把厚度 $\Delta z = (R_d/g)\overline{T}\ln(p_1/p_2)$ 写出并取其水平梯度，两个等压面之间的地转风之差为 $\Delta\mathbf{V}_g = (g/f)\mathbf{k}\times\nabla\Delta z = (R_d/f\ln(p_1/p_2))\mathbf{k}\times\nabla\overline{T}$，这就是热成风。

以地面 $10^{-5}\ \mathrm{K\,m^{-1}}$ 的梯度线性降到 $10\ \mathrm{km}$ 处为零，切变从 $3.5\times10^{-3}\ \mathrm{s^{-1}}$ 线性降到零，所以风按抛物线增大并在对流层顶达到极大。总的增加是切变廓线下的面积，那个三角形 $\tfrac12\times3.5\times10^{-3}\times10^4 = 17.5\ \mathrm{m\,s^{-1}}$。加上 $15\ \mathrm{m\,s^{-1}}$ 的地面地转风，得到对流层顶 $33\ \mathrm{m\,s^{-1}}$ 的急流核心；把地面梯度加倍，正如冬季极锋那样，得到 $50\ \mathrm{m\,s^{-1}}$——这就是急流观测到的季节循环，北半球冬季比夏季强 $50\%$，因为温度对比正是如此。
:::
:::

::: exercise 信风 {level=3}
空气从副热带高压的 $200\ \mathrm{hPa}$、$200\ \mathrm{K}$ 下沉到地面，守恒其相当位温，地面温度为 $300\ \mathrm{K}$。估计空气到达地面时的相对湿度，并解释副热带为什么干燥、信风逆温为什么存在。
::: solution
从 $200$ 到 $1000\ \mathrm{hPa}$ 的下沉使空气干绝热增温
$$
\Delta T = \frac{g}{c_p}z \Longrightarrow T = 200\times(1000/200)^{0.286} = 200\times1.594 = 319\ \mathrm{K},
$$
所以到达的空气在 $319\ \mathrm{K}$，远比 $300\ \mathrm{K}$ 的地面暖，而它的相对湿度在 $200\ \mathrm{hPa}$、$200\ \mathrm{K}$ 时曾接近饱和，此时降到几个百分点。与边界层混合并冷却到地面温度后，它的相对湿度约为 $30\%$。

因此副热带干燥有一个热力学的原因、而不仅是一个动力学的原因：空气在赤道辐合带被雨掉了出去，随后又被 $119\ \mathrm{K}$ 的下沉烤干。$600$–$1500\ \mathrm{m}$ 的信风逆温就是这一下沉空气的底，它是一个真正的盖子：其下的边界层潮湿而对流性不稳定，其上的空气干燥而稳定，任何时刻覆盖热带三分之一的浅积云就被困在它下面。逆温的高度设定了水汽库的厚度，从而设定信风积云能产生多少雨，这就是逆温高度一百米的变化对一个热带岛屿的降雨是一件大事的原因。
:::
