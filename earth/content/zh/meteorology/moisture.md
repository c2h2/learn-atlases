水的汽按体积占大气的百分之一到四、它负责"天气"这个词的意思的约十分之九。它是空气唯一在表面发现的温度、压的之下变的相的成的组成、那单一的特异使它雷暴的燃的料、所有雨、雪的源的、湿的球温度能杀你的数、一朵云有一个在你能从一个温度读数计算的高度有的底的原因。一个手摇干湿表的两个温度、在的阴的影摇一分的钟、给你比大多数的可比价格的仪器更多的大气的故事。

::: definition 饱的和的汽的压的 {#def-es}
**汽的压的**$e$空气的水的汽的分压的、按道耳顿定律、总压是分压之和、$p = p_d + e$。在一个温度$T$的平的水的面之上与它平衡的汽有**饱的和的汽的压的**$e_s(T)$、以马格努斯方给、
$$
e_s = 6.112\,\exp\left(\frac{17.62\,T}{243.12 + T}\right)\ \mathrm{hPa}, \qquad T\ \text{以}\ ^\circ\mathrm{C},
$$
在$-10\ ^\circ\mathrm{C}$的$2.87\ \mathrm{hPa}$、在$0$的$6.11$、在$20$的$23.4$、在$25$的$31.6$、在$30$的$42.3$、在$40\ ^\circ\mathrm{C}$的$73.8$。在冰之上对应的常数$22.46$、$272.62$、在每一个零的以的下的温度给一个低的$e_s$——驱动下一章的贝吉龙过程的差。本的特征$e_s$每开的文上升约$7\%$：温暖的空气能持有的、在下面使用的宽松的意义、比冷的空气多的水、大气的水的内容因此从它来的海洋的温度标度。
:::

::: proposition 克拉珀龙–克劳修斯 {#prop-clausius}
饱和曲线的斜率从化学势的相等、等价的从克拉珀龙–克劳修斯方、
$$
\frac{\mathrm{d}e_s}{\mathrm{d}T} = \frac{L_v\,e_s}{R_v T^2}, \qquad L_v = 2.5\times10^6\ \mathrm{J\,kg^{-1}},\ R_v = 461.5\ \mathrm{J\,kg^{-1}\,K^{-1}},
$$
它积分给$-L_v/R_vT$的一个指数的。因为$L_v/R_vT \approx 19$在$288\ \mathrm{K}$、e的翻折的尺度是$T/19$、约$15\ \mathrm{K}$——每开的文$7\%$的增加。对冰的升华曲线、$L_s = 2.83\ \mathrm{MJ\,kg^{-1}}$给一个更陡的曲线、每开的文$8.3\%$、所以两条曲线在$0\ ^\circ\mathrm{C}$之下分开。
:::

::: proof
考虑一千克的汽、一千克的液体，在一块可移动、导热的边界两侧于$T$、$p$下平衡。质量转移时吉布斯自由能取驻值的条件给$\mathrm{d}\mu_v = \mathrm{d}\mu_l$、在固定的$T$的$v_v\,\mathrm{d}e = v_l\,\mathrm{d}p$；以$v_v = R_vT/e$、把$v_l$相对$v_v$忽略带温度依赖通过给$\mathrm{d}\ln e_s/\mathrm{d}T = L_v/(R_vT^2)$。以恒定的$L_v$在两的个的态之间积分、
$$
e_s(T) = e_s(T_0)\exp\left[-\frac{L_v}{R_v}\left(\frac{1}{T}-\frac{1}{T_0}\right)\right],
$$
它在$T_0 = 273.16\ \mathrm{K}$、$e_s = 6.112\ \mathrm{hPa}$在$-20$、$+40\ ^\circ\mathrm{C}$之间好于$0.4\%$再现马格努斯方。∎

证明有一个容易错过、对气候重要的后果：饱的和的汽的压的以温度独自设定、对压的、对存在的其他气体相当的独立。一个以不同的大气的压的、同一个温度的世界有同一个$e_s$；一个加热的世界以一个直接的正比一个更湿的大气、每开的文约$7\%$更多的水的汽、它气候系统最强、测量最好的反馈。
:::

## 各度量、每一个的用途

::: definition 湿度、它的守恒的量 {#def-humidity}
六个数描述空气中的水、每一个有它的用途。**汽压**$e$（hPa）是分压。**混合的比**$w = 0.622\,e/(p-e)$、**比湿**$q = 0.622\,e/p$以$\mathrm{kg\,kg^{-1}}$、在不加、不减的水时守恒、它移动的气块的对的变的量。**相对的湿度**$f = e/e_s = q/q_s$对着饱和的比、湿度计的读数、人感觉的东西的、当空气加热时它变、所以它不守恒。**露的点**$T_d$空气必须在恒定的压下冷却到饱的和的温度、$e$的一个直接的度量：$T_d$诚实的湿度数。**湿的球的温度**$T_w$以蒸发的冷却到平衡达到的温度、人的身体能达到的温度。**虚的温度**$T_\text{v} = T(1+0.61w-0.61\lambda q_l)$使理的气体方对湿的空气工作的温度、**等价的位的温度**$\theta_e$在湿抬升中守恒、因此穿过一个气旋跟踪一个气团的变的量。
:::

第一个是炎热干燥的一天，其中身体以约$200\ \mathrm{W\,m^{-2}}$蒸发汗、以一个$34\ ^\circ\mathrm{C}$的皮肤温度保持凉爽。第二个只允许缓慢的蒸发：皮肤必须接近$33\ ^\circ\mathrm{C}$才能散热的、一个$28\ ^\circ\mathrm{C}$的湿球温度，已经是一个热带城市急诊室开始挤满的门槛。持续的人的体温调节的理论上限是一个约$35\ ^\circ\mathrm{C}$的湿球温度、它由以可持续的出汗率蒸发散失代谢热量的要求设定；$35\ ^\circ\mathrm{C}$及以的上的湿球温度如今在波斯湾与印度河的十二个海岸站短暂记录过。实际的后果：热浪警报应当依据的数是露的点、不是温度、一个潮湿气候的热浪比一个更炎热而干燥的热浪杀的人多得多。

::: warning 相对的湿度不告诉你的东西
一个$0\ ^\circ\mathrm{C}$的饱的和的空气的立方的米含$4.8\ \mathrm{g}$的水；一个$30\ ^\circ\mathrm{C}$在四十百分之一的立方的米含$12.8\ \mathrm{g}$——两倍半的水、在低于一半的相对湿度。相对湿度是一个比值、它的分母在一个冬夜与一个夏日下午之间变化一百倍。它是一个正确的数、关于油漆是否会干、干草是否会霉烂、一个真菌是否会感染一片叶子、因为那些全都取决于表面与空气之间的汽压梯度。它是一个错误的数、关于问空气有多少的水、一个系统能产生多少的雨、一个雷暴会释放多少的潜的热——它误导几乎每一次关于湿度的公开讨论的那个数、包括"湿度一百百分之一、三十的度"的说法、它描述的是一场雾、不是一个蒸汽浴室。
:::

::: history

::: exercise 相对的湿度 {level=1 check="49"}
一个$30\ ^\circ\mathrm{C}$的空气有一个$18\ ^\circ\mathrm{C}$的露的点。求相对的湿度、以百分之一。
::: solution
$e = e_s(18) = 20.6\ \mathrm{hPa}$、$e_s(30) = 42.4\ \mathrm{hPa}$、所以$f = 49\%$。
:::

::: exercise 混合的比 {level=1 check="27.5"}
求在$30\ ^\circ\mathrm{C}$、$1000\ \mathrm{hPa}$的饱和的空气的混合的比、以$\mathrm{g\,kg^{-1}}$。
::: solution
$w = 0.622\times42.3/(1000-42.3) = 27.5\ \mathrm{g\,kg^{-1}}$。在海的面的热的带的饱和的空气按混合比比在$10\ ^\circ\mathrm{C}$的饱和的空气的两倍半的湿、它热带的能产生它们的降雨的理由。
:::

::: exercise 云的底 {level=1 check="1000"}
在$22\ ^\circ\mathrm{C}$的表面的空气有一个$14\ ^\circ\mathrm{C}$的露的点。估计积云的底底。
::: solution
$z = 125\times(22-14) = 1000\ \mathrm{m}$。在温带的低地在夏季下午的晴好积云在$800$–$1500\ \mathrm{m}$有底、它们的高度表面露点的一个直接读数。
:::

::: exercise 虚的温度 {level=2 check="302.4"}
求在$30\ ^\circ\mathrm{C}$带一个$22\ \mathrm{g\,kg^{-1}}$的混合的比的空气的虚的温度。
::: solution
$T_\text{v} = 303.2\times(1 + 0.61\times0.022) = 303.2\times1.0134 = 307.3\ \mathrm{K}$、它$34.1\ ^\circ\mathrm{C}$。在湿的热带边界层中虚的温度效应值$3$–$4\ \mathrm{K}$的浮力、超过一个弱切变风暴的典型CAPE、为什么信风边界层的深度由海面温度设定。
:::

::: exercise 冷却到饱和 {level=2 check="7.3"}
一个$15\ ^\circ\mathrm{C}$带60%的相对的湿度的空气在恒定的压的之下冷却。以$^\circ\mathrm{C}$、它必须冷却到多少温度才能饱和？
::: solution
$e = 0.6\times17.0 = 10.2\ \mathrm{hPa}$、露的点$e_s = 10.2$的温度：$T_d = 243.12\ln(10.2/6.112)/(17.62 - \ln(10.2/6.112)) = 243.12\times0.512/17.11 = 7.3\ ^\circ\mathrm{C}$。所以它必须冷却$7.7\ \mathrm{K}$到$7.3\ ^\circ\mathrm{C}$。
:::

::: exercise 可降水的水 {level=2 check="33"}
在表面的汽压在$25\ ^\circ\mathrm{C}$是$20.6\ \mathrm{hPa}$、水汽密度以$2.2\ \mathrm{km}$的标度高度减小。求可降水的水、以毫米。
::: solution
表面汽的密的度$\rho_v = e/(R_vT) = 2058/(461.5\times298) = 0.0150\ \mathrm{kg\,m^{-3}}$。积分指数的给一个$0.0150\times2200 = 33\ \mathrm{kg\,m^{-2}}$的柱、它$33\ \mathrm{mm}$的可降水的水。一个中纬度的气团典的型的含$15$–$25\ \mathrm{mm}$、一个热带的$40$–$55\ \mathrm{mm}$；一个强降雨的风暴在几小时之内下掉它的柱的三分之一、它可能只因为风连续地补充水汽。
:::

::: exercise 推导125 m的规则 {level=3}
从干绝热落率、马格努斯方出发、证明一个上升的气块的露的点以约$1.8\ \mathrm{K\,km^{-1}}$落下、推导$125\ \mathrm{m\,K^{-1}}$的规则。在$0\ ^\circ\mathrm{C}$、$35\ ^\circ\mathrm{C}$规则错多少？
::: solution
对一个干绝热上升的气块、$\mathrm{d}T/\mathrm{d}z = -\Gamma_d = -9.8\ \mathrm{K\,km^{-1}}$、$w$恒定、所以$e$按比例的压的落下。沿着一条混合线、
$$
\frac{\mathrm{d}\ln e}{\mathrm{d}z} = \frac{\mathrm{d}\ln p}{\mathrm{d}z} = -\frac{1}{8000}\ \mathrm{m^{-1}},
$$
而露的点跟随$\mathrm{d}\ln e_s/\mathrm{d}T = 17.62\times243.12/(243.12+T)^2$、在$15\ ^\circ\mathrm{C}$它$0.0629\ \mathrm{K^{-1}}$。因此$\mathrm{d}T_d/\mathrm{d}z = (1/8000)/0.0629 = 1.99\ \mathrm{K\,km^{-1}}$、闭合率$9.8-1.99 = 7.8\ \mathrm{K\,km^{-1}}$、给$128\ \mathrm{m\,K^{-1}}$。

在$35\ ^\circ\mathrm{C}$导数$0.0525\ \mathrm{K^{-1}}$、露的点以$2.4\ \mathrm{K\,km^{-1}}$落下、规则变成$137\ \mathrm{m\,K^{-1}}$；在$0\ ^\circ\mathrm{C}$它$0.0749$、率$1.67$、规则$1/(9.8-1.67) = 123\ \mathrm{m\,K^{-1}}$。规则在整个的范围好于约$10\%$、为什么它在世界每一个预报机构沿用、为什么它只在一个很干的空气失效、在它的恒定的$w$的假设、$L_v$的温度依赖的忽略加起来。
:::

::: exercise 湿球的极限 {level=3}
一个休息的人产生$100\ \mathrm{W}$的代谢的热、有一个$1.7\ \mathrm{m^2}$的皮肤面积。证明在一个$35\ ^\circ\mathrm{C}$的湿球温度需要的蒸发率约$0.6\ \mathrm{litre}$每小时、讨论为什么它极限。
::: solution
在一个等于皮肤的温度的湿球温度没有显热损失、没有对周围的辐射损失、所以全部的$100\ \mathrm{W}$必须作为潜热离开：
$$
\dot m = \frac{100}{2.45\times10^6} = 4.1\times10^{-5}\ \mathrm{kg\,s^{-1}} = 0.15\ \mathrm{kg\,h^{-1}},
$$
对于一个工作的全身、产生$400\ \mathrm{W}$、它是$0.6\ \mathrm{litre\,h^{-1}}$。它在人的出汗率的范围之内、但仅仅是、只在阴凉处、只对于年轻健康的人；最大的持的续的汗的率约$1.5\ \mathrm{litre\,h^{-1}}$、在没有盐与循环的损失之下它才能持续数小时。因此极限不是一道热力学硬墙、而是一道生理学的墙、观察到的死亡率上升的门槛是一个$31$–$33\ ^\circ\mathrm{C}$的湿球温度、不$35$。
