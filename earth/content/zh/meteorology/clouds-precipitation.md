一个云滴直径二十微米，在静空气中以每秒一点五厘米下落。落下一百米要一个小时，而积云内部的空气正以每秒五米上升——快三百倍。云不是飘着的，它是被托着的。这就是云物理核心的悖论，而它的解答是这门学科中最重要的一个数量事实：**云由小到落不下来的水滴构成，而雨必须由一个在质量上胜过这一事实一百万倍的过程来造成。**找不到这个机制的云，无论维持多久都不会下雨；清洁的热带海洋大气中信风积云是三千米厚的水，其中大部分到不了海面。

::: proposition 核化：云为什么需要尘埃 {#prop-nucleation}
半径为 $r$ 的水滴，其表面之上的汽压因弯曲而升高，
$$
e(r) = e_s\,\exp\left(\frac{2\sigma M_w}{\rho_w R T r}\right),
$$
所以一个 $0.01\ \mu\mathrm{m}$ 的水滴需要百分之三百的相对湿度才能存在。纯的湿空气永远达不到这一点，水滴的均质核化在大气中不发生。真实的水滴形成于**云凝结核**之上——海盐、硫酸盐、硝酸盐、有机物与尘埃的可溶或部分可溶的颗粒——其溶解的溶质降低平衡汽压，两个效应合起来给出**克勒方程**
$$
\ln\frac{e}{e_s} = \frac{2\sigma M_w}{\rho_w RT r} - \frac{n_s i M_w}{\rho_w (4\pi r^3/3 + b_s)} .
$$
$e/e_s$ 对 $r$ 的曲线有一个极大，即**临界过饱和**，对干半径 $0.05$ 至 $0.2\ \mu\mathrm{m}$ 的颗粒，典型值为 $0.1$ 到 $1\%$，出现在 $0.05$ 至 $0.1\ \mu\mathrm{m}$ 的**临界半径**处。大于临界尺寸的颗粒被活化并长成一个云滴；较小的一个保持为一个霾粒。由于穿过云底的上升气流提供过饱和度，形成的水滴数由大于临界尺寸的核数与垂直速度决定：核为 $30\ \mathrm{cm^{-3}}$ 的清洁海洋空气比核为 $1000\ \mathrm{cm^{-3}}$ 的污染空气制造更少、更大的水滴，而两者制造出反射阳光不同、降雨速率也不同的云。
:::

::: proof
克勒方程的第一项是开尔文效应：把弯曲表面上的液体的化学势与蒸气的相等，得 $\RT \ln(e/e_s) = M_w p_L$，其中拉普拉斯压 $p_L = 2\sigma/r$，由此得指数形式。第二项是溶液的拉乌尔定律：汽压按溶质的摩尔分数降低，对固定质量的溶质 $n_s$ 摩尔、范特霍夫因子 $i$、体积 $4\pi r^3/3$ 的水滴，这个分数为 $n_s i/(n_w) \approx n_s i M_w/(\rho_w V)$。

两项符号相反、$r$ 的幂次不同：开尔文项按 $1/r$，在大半径处占优；溶质项按 $1/r^3$，在小半径处占优。它们的和因此有一个极大，由令导数为零求得。对一个干半径 $0.1\ \mu\mathrm{m}$ 的硫酸铵颗粒，极大在 $r \approx 0.15\ \mu\mathrm{m}$、过饱和 $0.4\%$ 处；对同样大小的海盐颗粒在 $0.08\ \mu\mathrm{m}$ 与 $0.1\%$——这就是海盐在浅海洋云中遇到的那种小过饱和下就能活化、而一个污染颗粒必须等待更强上升气流的原因。∎
:::

::: example 临界半径 {#ex-critical}
取 $\sigma = 0.072\ \mathrm{N\,m^{-1}}$、$M_w = 0.018\ \mathrm{kg\,mol^{-1}}$、$T = 293\ \mathrm{K}$、$\rho_w = 1000\ \mathrm{kg\,m^{-3}}$。求在 $1\%$ 与 $0.1\%$ 的过饱和下能处于平衡的纯水水滴的半径，并求一个 $0.02\ \mu\mathrm{m}$ 的水滴蒸发时的相对湿度。
::: solution
反解开尔文方程，
$$
r^* = \frac{2\sigma M_w}{\rho_w R T\ln S} = \frac{2\times0.072\times0.018}{1000\times8.314\times293\times\ln S} = \frac{1.06\times10^{-9}}{\ln S}\ \mathrm{m}.
$$
$S = 1.01$ 时 $\ln S = 0.00995$、$r^* = 0.107\ \mu\mathrm{m}$；$S = 1.001$ 时 $r^* = 1.06\ \mu\mathrm{m}$。小于 $r^*$ 的水滴靠蒸发、而不是靠凝结长大——它是不稳定的——所以一个 $0.02\ \mu\mathrm{m}$ 的纯水水滴需要 $5.3\%$ 的过饱和才能存活，而任何云都达不到。

后果是：观测到的最小的云滴，$1$–$2\ \mu\mathrm{m}$，是最小的那些被活化的核的残余；而大气中 $0.05\ \mu\mathrm{m}$ 以下的整个颗粒群——污染空气或刚发生过核化的气团中数目的多数——在它们通过蒸气凝结或碰并长大之前，对云毫无贡献。这就是气溶胶的气候效应取决于气溶胶的尺寸与成分、而不只是其质量的原因，也是一份质量排放清单关于一朵云告诉不了你什么的原因。
:::
:::

## 通往雨滴的两条路

::: definition 凝结增长与碰并 {#def-growth}
生长中的水滴的半径遵守 $r\,\mathrm{d}r/\mathrm{d}t = G S$，于是 $r \propto t^{1/2}$：凝结起初很快，随后毫无希望。一个水滴一分钟到达 $10\ \mu\mathrm{m}$、一小时到达 $30\ \mu\mathrm{m}$，而单靠凝结要达到 $1\ \mathrm{mm}$ 需要几个星期——在此期间它早已掉出云外。**碰并**、或称**暖雨**过程是另一条路：一个 $25\ \mu\mathrm{m}$ 的滴相对于邻居开始以每秒几厘米下落，并以
$$
\frac{\mathrm{d}m}{\mathrm{d}t} = E\,w_L\,\pi r^2 v
$$
的速率扫走路径上更小的水滴，其中 $E$ 为收集效率，$w_L$ 为液态水含量（水云为 $0.5$–$3\ \mathrm{g\,m^{-3}}$），$v$ 为下落速度。增长率正比于 $r^2$，所以大滴长得更快：这是一个带有漫长**增长瓶颈**的不稳定过程——最初的一百微米要几十分钟——然后在另外十分钟内加速成雨。它需要一个宽的水滴谱来起步，这就是为什么少数几个大海盐滴或冰的存在如此有效。
:::

::: proposition 贝吉龙过程 {#prop-bergeron}
在 $0\ ^\circ\mathrm{C}$ 以下，冰上的饱和汽压小于水上的：$-10\ ^\circ\mathrm{C}$ 时为 $2.60$ 对 $2.87\ \mathrm{hPa}$，相差 $9\%$；$-20\ ^\circ\mathrm{C}$ 时为 $1.03$ 对 $1.26$，相差 $18\%$。因此空气不可能同时对两者饱和，若冰晶与过冷水滴共存，汽压就落在两个值之间——对水滴是欠饱和的，对冰晶是过饱和的——水从水滴蒸发、在冰晶上凝华。**一个同时含有两者的云，靠牺牲其水来养大它的冰**，冰晶在几分钟、而不是几小时内变得大到可以下落。由于差值 $e_s^\text{water} - e_s^\text{ice}$ 在 $0$ 与 $-40\ ^\circ\mathrm{C}$ 处消失、在 $-15\ ^\circ\mathrm{C}$ 附近达峰，这个过程在那里最猛烈，这就是最高产的云其顶在 $-15\ ^\circ\mathrm{C}$、在温带为 $5$–$7\ \mathrm{km}$ 的原因。
:::

::: example 冰对水 {#ex-bergeron}
一个 $-12\ ^\circ\mathrm{C}$ 的混合云液态水含量为 $0.5\ \mathrm{g\,m^{-3}}$，冰晶浓度为每升一个，上升气流为 $1\ \mathrm{m\,s^{-1}}$。饱和汽压在水上为 $2.85\ \mathrm{hPa}$、在冰上为 $2.60\ \mathrm{hPa}$。求空气最终落到的汽压，并估计云的液态水能维持多久。
::: solution
晶少水多，汽压被缓冲在冰上的值附近，于是水滴蒸发进一个对它们欠饱和 $9\%$ 的空气。整整 $0.5\ \mathrm{g\,m^{-3}}$ 的液态水要么蒸发、要么凝华到冰晶上。每升一个的晶粒提供的收集面积极小——每立方米 $10^6$ 个半径 $50\ \mu\mathrm{m}$ 的晶粒总截面为 $7.9\times10^{-3}\ \mathrm{m^2}$——而在这种条件下每个晶粒的凝华增长率约为每分钟 $10\ \mu\mathrm{m}$，所以一个晶粒十分钟内到达 $1\ \mathrm{mm}$ 并开始下落。

云的液态水按晶粒收集水汽的速率被消耗，而上升气流供给更多的水，这是一个平衡：云产生降水的速率约为
$$
P = N\,\dot m = 10^6\times\left(\rho_i 4\pi r^2\dot r\right) \approx 10^6\times 900\times4\pi(5\times10^{-5})^2\times(1.7\times10^{-7}) = 2\times10^{-8}\ \mathrm{kg\,m^{-3}\,s^{-1}},
$$
在一个 $3\ \mathrm{km}$ 厚的云层上积分，给出每小时零点几毫米的地面降水率——这是暖锋云幕稳定降雪的正确量级。这个计算的要点在于对比：同样一朵云若没有冰，在同样的温度与含水量下几乎什么也不产生，因为水滴没有生长的机制。这就是云顶到达 $-20\ ^\circ\mathrm{C}$ 的热带山区降雨率是其旁边低地十倍的原因，也是云的人工催化——在它成功的那些案例中——只在过冷云中有效的原因。
:::
:::

::: example 一朵积云的水收支 {#ex-budget}
一朵浓积云宽 $1\ \mathrm{km}$、厚 $3\ \mathrm{km}$，平均液态水含量 $1\ \mathrm{g\,m^{-3}}$，底部上升气流 $3\ \mathrm{m\,s^{-1}}$，入流层厚 $500\ \mathrm{m}$、输送含 $10\ \mathrm{g\,kg^{-1}}$ 水汽的空气。它在其面积上下 $10\ \mathrm{mm\,h^{-1}}$ 的雨。求它的水含量、上升气流供水的速率、降水效率与冲洗时间。
::: solution
体积为 $\pi(500)^2\times3000 = 2.4\times10^9\ \mathrm{m^3}$，所以云含着 $2.4\times10^6\ \mathrm{kg}$、约两千四百吨液态水——五百辆卡车的载重，悬在空中。

穿过底部的入流为 $\pi(500)^2\times3 = 2.4\times10^6\ \mathrm{m^3\,s^{-1}}$，在 $1.2\ \mathrm{kg\,m^{-3}}$ 的密度下以 $10\ \mathrm{g\,kg^{-1}}$ 的混合比输送 $2.9\times10^4\ \mathrm{kg\,s^{-1}}$ 的水。云面积上的雨量为
$$
10\times10^{-3}\times7.85\times10^5\times1000/3600 = 2200\ \mathrm{kg\,s^{-1}},
$$
所以降水效率——雨量除以供水量——为 $7\%$。冲洗时间，即空气在云中的停留时间，为 $2.4\times10^9/2.4\times10^6 = 1000\ \mathrm{s}$，一刻钟，而浓积云观测到的寿命为二十到四十分钟。

由此得出三个结论，它们是这门学科之所以困难的原因。云不是一个物体而是一个定态，像火焰：每隔几分钟它由不同的空气构成，而一朵积云的"生命史"是上升气流的生命史、不是水的生命史。单朵云的效率很低，因为凝结出来的水大部分落出去或在环境中蒸发了；只有在一个有组织的系统中——一条飑线、一个中尺度对流复合体、一个热带气旋——效率才达到五十个百分点、雨才成为洪水。而那两千四百吨水是被一个输送 $2.4\times10^6\ \mathrm{m^3\,s^{-1}}$ 的上升气流托住的；当入流被切断，无论是被扩散的冷空气团还是被地面增温的消失，云不是流干的，而是蒸发的，且在十分钟之内完成。
:::

## 云本身

::: definition 云属，以及它们的含义 {#def-clouds}
霍华德1803年的十二词命名法按形态与高度整理天空。**高云**在 $6\ \mathrm{km}$ 以上，由冰构成：*卷云*（纤维，对流层上层的风的条纹）、*卷层云*（制造 $22^\circ$ 晕、并提前十二小时预告暖锋的乳白天幕）、*卷积云*（鱼鳞天）。**中云**，$2$–$7\ \mathrm{km}$：*高层云*（灰色薄片，太阳透过它像一个模糊的圆盘，带来暖锋的稳定雨）、*高积云*（成层的绒块，以及在山上呈透镜状的山地波）。**低云**在 $2\ \mathrm{km}$ 以下：*层云*（按地面的规矩来的云，暖区的毛毛雨）、*层积云*（破碎的幕，覆盖全球五分之一的面积、反射的阳光比任何别的云都多）、*雨层云*（成熟气旋的雨云，暗、无特征、厚）。**垂直发展的云**：晴好的*淡积云*、*浓积云*，以及*积雨云*——它的砧就是对流层顶，它的底可以在 $15\ \mathrm{km}$ 的顶下方 $1\ \mathrm{km}$ 处。还有两种值得凭肉眼认识：*荚状云*，标记转子湍流的驻波云；*乳状云*，砧下方标记含云空气下沉的囊袋。
:::

::: example 雷达，以及测量落下的东西 {#ex-radar}
一部天气雷达在一个阵雨中测得反射率因子 $40\ \mathrm{dBZ}$。用 $Z = 200\,R^{1.6}$，$Z$ 以 $\mathrm{mm^6\,m^{-3}}$、$R$ 以 $\mathrm{mm\,h^{-1}}$ 计，求降雨率。若降水是干雪，$Z = 1000\,R^{1.6}$，同样的反射率意味着什么速率？
::: solution
$Z = 10^{40/10} = 10^4\ \mathrm{mm^6\,m^{-3}}$，所以 $R = (10^4/200)^{1/1.6} = 50^{0.625} = 11.7\ \mathrm{mm\,h^{-1}}$——一场强阵雨。对雪，$R = (10^4/1000)^{0.625} = 4.0\ \mathrm{mm\,h^{-1}}$ 的液态当量，但同样的 $40\ \mathrm{dBZ}$ 的干雪落下时可能是每小时四十毫米的雪深，因为雪片大、慢、大部分是空气。

这就是雷达定量降水估计的全部困难：机器测的是粒子尺寸的六次方与粒子的数目，而不是水，换算取决于相位、尺寸分布与形状。对流雨的 $Z$–$R$ 关系用 $300$–$400$ 作 $a$，层状雨用 $80$–$120$，雪再多一个数量级；双偏振雷达直接测形状与介电常数，做得好得多，这就是2020年代的雷达雨量比1990年代更可信的原因。至于翻斗式雨量计，它在风中少收 $5$–$20\%$，作为雪少收可达 $50\%$，再加上蒸发与挂在漏斗内壁上的水的百分之几。
:::
:::

::: warning 水汽是看不见的
你在壶口上、在寒冷清晨的湖面上、在云里看到的都是液态水，不是汽：水蒸气是一种无色的气体，不存在看得见的一团水汽。推论很重要。淋浴的"蒸汽"是在喷嘴上方一厘米处已经发生的凝结，那里的空气已冷到足够。潮湿的日子不是雾蒙蒙的日子：露点 $25\ ^\circ\mathrm{C}$ 的空气含着 $2\ ^\circ\mathrm{C}$ 的雾的三倍水汽，却完全清澈。而"二氧化碳可以忽略，因为水汽是主要的温室气体"这一说法混淆了两件不同的事——水汽确实造成自然温室效应的约一半、二氧化碳约五分之一——但水汽是一个由温度决定其数量的反馈，而二氧化碳是设定温度的强迫。把二氧化碳加倍是加倍一个控制变量；水汽随后每开尔文增加约 $7\%$，把响应大约加倍。
:::

::: quiz
为什么一朵在 $-12\ ^\circ\mathrm{C}$ 含有过冷水滴与冰晶的云，比一朵在同温下只含水滴的云更容易产生降水？
- [ ] 因为冰比水重、下落更快
- [x] 因为冰上的汽压更低，水汽便从水滴移向冰晶，晶粒得以长大
- [ ] 因为水滴碰到晶粒就冻结
- [ ] 因为晶粒本来就比水滴大
::: solution
在 $-12\ ^\circ\mathrm{C}$，冰上的饱和汽压比水上的低 $9\%$，所以同时容纳两者的空气对冰过饱和、对水欠饱和，水便通过汽相迁移到晶粒上。晶粒在几分钟内长到降水尺度，而水滴缩小。这就是贝吉龙–芬德艾森过程，是温带大部分降雨、以及几乎全部的雪始于冰的原因。
:::

::: history
霍华德在1802与1803年向伦敦的阿斯克西亚学会宣读了他的《云的变种》，用的是一个会员的笔名，以便论文就其本身被评判；他给了世界一些本来就在拉丁文里、并即将成为各种欧洲语言中单词的词。拉马克在几个月前于法国提出过一个同样无用的命名法，只有霍华德的那个存活下来，因为它是可塑的。冰可能与雨有关的思想来自1911年的魏格纳，来自奥地利科学家魏肯迈尔的观测；芬德艾森在1931年把它定量化，贝吉龙在1933年把它表述出来，并在同一篇论文中解释了为什么热带的云下雨而清洁的海洋边界层的云不下。这个理论被抵制了十年，最后结束它的不是争论而是一个实验：1946年11月13日，谢弗把碾碎的干冰投进斯克内克塔迪一间实验室里的过冷云，看着它造出雪；十一个月后，冯内古特用同一间实验室的耗材发现碘化银从飞机上能干同样的活。云的催化在几个月内就成了一门商业，而它从未被完全证实或证伪；在六十年的野外观测之后，诚实的总结是：对过冷的地形云做冰核催化，在有利条件下能使降雪增加约十个百分点，此外别无被证明的东西。暖雨过程的物理在1950年代由梅森在帝国理工学院的云隧道与旋转臂室中确定，他用小水滴的云去射击水滴来测量收集效率；而增长不稳定性的数值模型是戈尔茨坦与杨在1970与1980年代的工作。

## 通向何处

喂养这些云的上升气流是[[meteorology/stability]]的主题，在风暴尺度上是[[meteorology/storms]]的主题；微物理在[[atmospheric-dynamics/cloud-physics]]中详细处理；气溶胶对滴数与云反照率的控制在[[atmospheric-chemistry/aerosols]]；落到地面的降水的测量与模拟在[[hydrology/precipitation-evaporation]]；主导气候敏感度不确定性的云反馈在[[climate-system/feedbacks-sensitivity]]。

::: summary 关键的收获
- 云滴在云凝结核上形成，因为纯水需要几百个百分点的过饱和；克勒方程的极大设定一个 0.1-1% 的临界过饱和。
- 滴数由气溶胶与上升气流决定、不由供水决定，它控制云的亮度与降雨的倾向。
- 凝结遵守平方根律、在三十微米处停滞；雨需要碰并及其增长瓶颈，或者冰过程。
- 贝吉龙过程之所以工作，是因为冰上的饱和汽压低于水上的，它在 -15 C 附近最强，这就是高产的云到达 5-7 km 的原因。
- 云按形态与高度分类，而卷云、卷层云、高层云、雨层云这个序列就是一次逼近的暖锋的读数。
- 雷达测的是滴径的六次方、不是水，任何由雷达得到的雨量估计都是一个取决于降水相位的换算。
- 水汽是看不见的；你看到的一切总是液态或固态。
:::

## 练习题

::: exercise 开尔文效应 {level=1 check="1.06"}
用算例中的常数，求过饱和 $0.1\%$ 时的临界半径，以微米计。
::: solution
$r^* = 1.06\times10^{-9}/0.001 = 1.06\ \mu\mathrm{m}$。小于此的水滴会蒸发，这就是最小的云滴直径约一微米的原因。
:::
:::

::: exercise 末速度 {level=1 check="2.0"}
用控件中的表达式，求直径 $0.5\ \mathrm{mm}$ 的雨滴的下落速度，以 $\mathrm{m\,s^{-1}}$ 计。
::: solution
$v = 9.65 - 10.3\,e^{-0.3} = 9.65 - 7.63 = 2.0\ \mathrm{m\,s^{-1}}$。$5\ \mathrm{m\,s^{-1}}$ 的积云上升气流会把这样一个滴向上托走，这就是滴能在云中停留足够久以生长的方式。
:::
:::

::: exercise 冰上的饱和 {level=1 check="9.4"}
在 $-10\ ^\circ\mathrm{C}$，饱和汽压在水上为 $2.87\ \mathrm{hPa}$、在冰上为 $2.60\ \mathrm{hPa}$。求相对于水的百分差。
::: solution
$(2.87-2.60)/2.87 = 9.4\%$。这个小小的差驱动着整个冰过程，并在 $-30\ ^\circ\mathrm{C}$ 附近达到 $21\%$ 的极大，尽管液态水的可及性在那之前就已下降。
:::
:::

::: exercise 收集 {level=1 check="0.79"}
一个半径 $0.5\ \mathrm{mm}$ 的滴以 $2\ \mathrm{m\,s^{-1}}$ 穿过液态水含量 $1\ \mathrm{g\,m^{-3}}$ 的云，收集效率为 $0.5$。求其质量的增加率，以 $10^{-9}\ \mathrm{kg\,s^{-1}}$ 为单位。
::: solution
$\mathrm{d}m/\mathrm{d}t = 0.5\times10^{-3}\times\pi\times(5\times10^{-4})^2\times2 = 7.9\times10^{-10}\ \mathrm{kg\,s^{-1}}$，即 $0.79\times10^{-9}$。这滴的质量为 $5.2\times10^{-7}\ \mathrm{kg}$，所以它十一分钟翻一倍：增长对半径是指数型的，这就是那场失控。
:::
:::

::: exercise 雷达 {level=2 check="11.7"}
用 $Z = 200R^{1.6}$ 求反射率 $40\ \mathrm{dBZ}$ 的降雨率。
::: solution
$R = (10^4/200)^{1/1.6} = 11.7\ \mathrm{mm\,h^{-1}}$。
:::
:::

::: exercise 滴的浓度 {level=2 check="13"}
一个云底有 $0.5\ \mathrm{m\,s^{-1}}$ 的上升气流与 $0.3\%$ 的过饱和，活化所有大于 $0.1\ \mu\mathrm{m}$ 的核。若空气含有 $100\ \mathrm{cm^{-3}}$ 这样的核并产生 $1\ \mathrm{g\,m^{-3}}$ 的液态水含量，估计平均滴半径，以微米计。
::: solution
数浓度为 $N = 10^8\ \mathrm{m^{-3}}$，液态水总质量 $10^{-3}\ \mathrm{kg\,m^{-3}}$，所以每个滴有 $10^{-11}\ \mathrm{kg}$，半径为
$$
r = \left(\frac{3\times10^{-11}}{4\pi\times1000}\right)^{1/3} = 1.3\times10^{-5}\ \mathrm{m} = 13\ \mu\mathrm{m}.
$$
若滴数增加十倍，同样的液态水分给十倍的滴，每个只有十分之一的体积，半径按 $10^{-1/3} = 2.15$ 降到 $6\ \mu\mathrm{m}$。更小的滴用同样的水散射更多的光（第一个特沃西效应），也更不容易碰撞，这是第二个效应，也是可能使污染的云少下雨的那个。
:::
:::

::: exercise 冰雹 {level=2 check="28"}
一个直径 $2\ \mathrm{cm}$、密度 $850\ \mathrm{kg\,m^{-3}}$ 的冰雹。取阻力系数为 $0.6$，估计它的下落速度，以 $\mathrm{m\,s^{-1}}$ 计。
::: solution
平衡重力与阻力，
$$
v = \sqrt{\frac{8\rho_i g D}{3 C_D \rho_a}} = \sqrt{\frac{8\times850\times9.81\times0.02}{3\times0.6\times1.2}} = \sqrt{779} = 28\ \mathrm{m\,s^{-1}}.
$$
（取最接近的整数：$28$。）这样一个尺寸的雹落得比大多数雷暴的上升气流还快，只有在上升气流达 $25\ \mathrm{m\,s^{-1}}$ 或更多的地方才能被托住，或者它在风暴顶部附近形成、然后直接掉出去——这就是大多数大冰雹到达地面的方式，也是最大的冰雹落在砧区而不是核心里的原因。
:::
:::

::: exercise 推导克勒极大 {level=3}
对一个含 $n_s$ 摩尔完全解离溶质的水滴，把克勒方程写成 $\ln S = a/r - b/r^3$ 的形式，用 $a$ 与 $b$ 表示临界半径与临界过饱和。证明临界过饱和按 $n_s^{-1/2}$ 标度，并讨论这对不同尺寸颗粒的活化意味着什么。
::: solution
求导，$\mathrm{d}\ln S/\mathrm{d}r = -a/r^2 + 3b/r^4 = 0$ 给出 $r_c = (3b/a)^{1/2}$，且
$$
\ln S_c = \frac{a}{r_c} - \frac{b}{r_c^3} = \frac{a}{r_c} - \frac{a}{3r_c} = \frac{2a}{3r_c} = \frac{2a^{3/2}}{3\sqrt{3b}} .
$$
由于 $b \propto n_s$，$\ln S_c \propto n_s^{-1/2}$：颗粒越可溶或质量越大，它需要的过饱和越低，而这个依赖是一个平方根，所以溶质质量增加一百倍只把所需的过饱和降低十倍。

因为 $n_s$ 由颗粒固定、而 $r$ 随吸水增大，活化条件本质上是关于干尺寸的条件：对给定的可溶成分，$S_c \propto r_\text{dry}^{-3/2}$，所以气溶胶群中最大的那几个百分点主导了滴数。这就是云凝结核谱随尺寸急剧上升的原因，是滴数由积聚模态颗粒数决定的原因，也是森林与海洋上空新核化出的 $10\ \mathrm{nm}$ 模——尽管数量庞大——在长大之前几乎不贡献任何云滴的原因。
:::
:::

::: exercise 海洋层积云 {level=3}
副热带东大洋的层积云覆盖 $5\times10^6\ \mathrm{km^2}$，厚 $600\ \mathrm{m}$，液态水路径 $60\ \mathrm{g\,m^{-2}}$，反照率 $0.35$，而其下海洋为 $0.07$。求液态水含量、$N = 100\ \mathrm{cm^{-3}}$ 时的平均滴半径、反射的太阳功率，并与到达这些纬度的 $260\ \mathrm{W\,m^{-2}}$ 阳光被晴朗海洋反射的功率相比较。
::: solution
液态水含量为 $60/600 = 0.1\ \mathrm{g\,m^{-3}}$，偏低，但在顶部夹卷干空气而被蒸发的云中是典型的。以 $N = 10^8\ \mathrm{m^{-3}}$，滴半径由 $\tfrac{4}{3}\pi r^3\rho_w N = 10^{-4}$ 得 $r = 10.4\ \mu\mathrm{m}$。

云反射 $0.35\times260 = 91\ \mathrm{W\,m^{-2}}$，海洋本会反射 $18$，所以云在 $5\times10^6\ \mathrm{km^2}$ 的面积上向太空退回 $73\ \mathrm{W\,m^{-2}}$——总共 $3.7\times10^{14}\ \mathrm{W}$，约为当前二氧化碳全部辐射强迫的四分之一，而造出它的是一朵滴径与淋浴中的滴相当、其水一小时就被换掉一次的云。由此有两件事。若滴数在固定水量下增加五十个百分点，半径会减小 $11\%$、反照率上升几个百分点，这就是航迹效应，也是一个被提出的地球工程方案的依据，而它的倡导者没有考虑云的寿命、它的降水，以及同一种气溶胶还会吸收这一事实。若这层云崩解——模型对于它在 $2$–$4\ \mathrm{K}$ 的增暖下是否崩解尚有分歧——$73\ \mathrm{W\,m^{-2}}$ 就变成 $18$，是一个比二氧化碳加倍还大的强迫。这一层云幕是气候敏感度中最大的不确定性，而它只有六百米的厚度。
:::
