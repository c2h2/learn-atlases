海洋的植物固定的碳约每年五十吉吨——与行星上全部的陆地的植物一样多——来自平均五十分之一毫米、而在几天中替换自己的生物。它们固定的九十九% 在一个季度内被吃、被呼吸、而归还给表面；一% 下沉、而那一% 是光合作用自己之后地球上最大的碳的通量、大气在二氧化碳中比物理单独留下的瘦两成的原因、而存在过的每一个渔业的基础。

## 光与真光的带

::: definition 光、临界的深度、而季节的水华 {#def-light}
光合的有效辐射（PAR，$400$–$700\ \mathrm{nm}$）指数地衰减、
$$
I(z) = I_0\,e^{-K_d z}, \qquad Z_{1\%} = \frac{4.6}{K_d},
$$
$K_d$ 从贫营养的萨加索海的 $0.03\ \mathrm{m^{-1}}$ 到海岸的与浊的水的 $2\ \mathrm{m^{-1}}$——所以真光的带在一个环流中是 $150\ \mathrm{m}$、而在一个河口是 $2\ \mathrm{m}$。蓝光渗透得最远、这就是为什么开阔的海洋的水是蓝的、而把 SeaWiFS、MODIS、VIIRS 与哨兵三号辐射转换成叶绿素的海洋的颜色的算法建立在蓝与绿的波段之比上。

光合作用饱和。光合作用的–辐照的关系、
$$
P^{B} = P^{B}_{s}\left[1 - \exp\!\left(-\frac{\alpha^{B} I}{P^{B}_{s}}\right)\right] e^{-\beta I/P^{B}_{s}},
$$
以一个初始的斜率 $\alpha^{B}$（量子的产额、$0.02$–$0.08\ \mathrm{mol\,C\,mol^{-1}\,photons}$、由光系统 II的六十到八百的叶绿素的比设定、而近乎普遍的）线性地上升、在 $P^{B}_{s}$ 饱和、而在高的光下靠光抑制下降。光驯化然后重新接线细胞：低的光提高每一细胞的叶绿素、而降低 $P^{B}_{s}$、高的光做相反的事、而叶绿素对碳的比——卫星实际看到的量——只靠生理就变化五倍的因子。

斯韦德鲁普的临界的深度（1953）把这个与混合耦合。一个种群净的生长只在积分过深度的生产超过积分过深度的呼吸时、而因为光指数地下降、而混合把细胞均匀地暴露、水华需要
$$
Z_{\mathrm{mix}} < Z_{\mathrm{cr}} \approx \frac{1}{\gamma P^{B}_{s}}\ln\!\left(\frac{\gamma P^{B}_{s} I_0}{10\,R}\right),
$$
其中十的因子是经验的补偿的比。这一个不等式解释了中纬度的海洋的季节的节奏：深的冬天的混合补充营养、而使 $Z_{\mathrm{mix}} \gg Z_{\mathrm{cr}}$、所以什么都不长；在三月与四月层化使 $Z_{\mathrm{mix}}$ 在营养仍高时变浅过 $Z_{\mathrm{cr}}$、而春天的水华爆发；到六月营养消失了、而水华无论光如何都崩溃。越过的时机——不是光、不是营养的浓度——是气候的变化移动的东西、而自 1998 年北大西洋的水华的约每年 0.4 天的观察到的提前是任何地方被解决得最好的生物的气候的信号之一。
:::

::: definition 新的生产、微生物的环、而输出 {#def-export}
硝酸盐从下面靠混合、上升流、而固氮到达；铵就地被循环。新的生产 $f$ 用硝酸盐、再生的生产用铵、而 f 的比
$$
f = \frac{\text{new production}}{\text{total production}} \approx \frac{[\mathrm{NO_3^{-}}]_{\mathrm{winter\ MLD}}}{[\mathrm{NO_3^{-}}]_{\mathrm{winter\ MLD}} + [\mathrm{NH_4^{+}}]_{\mathrm{recycled}}}
$$
在贫营养的环流中是 $0.1$–$0.2$、而在上升流的与高纬度的水是 $0.4$–$0.6$。因为只有新的生产能在不剥光表面的情况下被输出、f 的比是海洋学有的最接近碳的封存的效率的东西——而它也是大多数的模型弄错的量。

在固定与输出之间坐着微生物的环、地球上最大的碳的重新加工。两成到五成的固定的碳作为溶解的有机的物质被释放；异养的细菌（每一毫升 $10^{5}$–$10^{6}$ 个细胞）吸收它、被鞭毛虫与纤毛虫牧食、而它们被桡足类牧食——所以在贫营养的海洋中大多数的生产在被呼吸或被经典的食物网吃之前经过三到五次的营养的转移。病毒每天裂解两成到四成的细菌的生产、把它作为病毒的旁路归还给溶解的物质。而剩余的、极难降解的溶解的有机的碳——约 $650\ \mathrm{PgC}$、与大气一样多、而一个 $4000$–$6000$ 年的停留的时间——是表面的地球上最大的移动的还原的碳的库、而我们不知道它为什么抵抗细菌。

输出靠重力。粪的颗粒（$100$–$1000\ \mu\mathrm{m}$、下沉 $50$–$400\ \mathrm{m\,d^{-1}}$）、水华之后的硅藻的聚集体、而按面积主导的黏的海雪把颗粒的有机的碳带下去、而通量随深度靠马丁的幂律衰减
$$
F(z) = F_{100}\left(\frac{z}{100}\right)^{-b}, \qquad b \approx 0.86\ \text{(global mean)}, \quad 0.4\text{–}1.5\ \text{range},
$$
它编码了一切：$b$ 在物质是易变的而小的时候是大的、在它是难降解的、在矿物的球内被保护的、或被碳酸盐与生物的硅稀释时是小的——压载的效应、这就是为什么南大洋与碳酸盐的大陆架每单位的生产的表面封存的碳比贫营养的环流多得多。在 $b = 0.86$ 只有 $100$ m 的通量的 $14\%$ 到达 $1000\ \mathrm{m}$、而 $4\%$ 到达 $4000\ \mathrm{m}$；从表面到中层的全球的均的转移的效率是约 10–20%、而整个的生物的泵的气候的杠杆活在那个数字里面。
:::

::: definition 营养、铁、而三个限制 {#def-nutrients}
表面的水在几乎处处是硝酸盐与磷酸盐的耗竭的、所以问题从不是营养是否限制、而是哪个营养、在哪里、而对着什么。

硝酸盐的限制主导副热带的环流、在束毛藻与单细胞的蓝细菌的固氮（全球 $1$–$5\times10^{12}\ \mathrm{g\ N\ yr^{-1}}$）把库缓冲向里德菲尔德的 N:P 的 $16:1$。磷的限制出现在反硝化剥光了氮之处——东热带的大西洋、孟加拉湾、东热带太平洋——而在悬浮的颗粒的物质的 $\delta^{15}\mathrm{N}$ 中被记录。硅酸盐的限制在海岸的上升流、而在南大洋结束硅藻的水华、而因为硅藻携带输出碳的压载、硅的循环是一个碳的循环。

铁限制约三分的高的营养的、低的叶绿素的（HNLC）海洋——亚极地的太平洋、$110\ \mathrm{^\circ W}$ 之东的赤道的太平洋、而南极的绕极的流以南的南大洋——在溶解的铁落到 $0.5\ \mathrm{nmol\,L^{-1}}$ 之下、而硝酸盐保持在 $15\ \mu\mathrm{mol\,L^{-1}}$ 之上。约翰·马丁的铁的假说（1988、1990）提出冰期的尘埃施肥了南大洋、而下抽了大气的 CO₂；1995–2011 的 SOIREE、SOFeX、SEEDS、EisenEx、EIFES 与 LOHAFEX 的富化的实验确认了生理学——几纳摩尔的铁触发一个把营养下抽一半的硅藻的水华——但显示碳的输出是无效的、所以冰期的 CO₂ 的效应、虽然是真实的、比马丁估计的两到五倍小。海洋的铁的循环如今由 GEOTRACES 测绘、它显示热液的、沉积的、尘埃的、而有机的络合的源在相当的数量上、而一个制造铁的配体以把它保持在溶液中的生物圈。

光在高纬度限制在冬天、营养限制环流在夏天、铁限制海洋的三分之一全年、而牧食限制其余。气候的变化对全部四个起作用：表面的增暖层化而使混合层变浅、减少营养的供给与 f 的比；1998–2022 的观察到的全球的叶绿素的记录显示暖的副热带每一十年约 $0.07\ \mathrm{mg\,m^{-3}}$ 的下降、而在高的北纬的增加、而净的全球的初级的生产的趋向在海洋的颜色与模型的社区之间仍有争议；而脱氧扩张氧的极小的区、那有利于氮的损失、因此进一步的氮的限制。
:::
::: example 春天的水华与临界的深度 {#ex-critical}
在一个中纬度的站、冬天的混合层深 $180\ \mathrm{m}$、而 $K_d = 0.08\ \mathrm{m^{-1}}$。求一% 的光的水准的深度、而解释为什么水华在四月、不在营养最高的三月爆发。
::: solution
$$
Z_{1\%} = \frac{4.6}{K_d} = \frac{4.6}{0.08} = 58\ \mathrm{m}.
$$
在三月混合层是 $180\ \mathrm{m}$——真光的深度的三倍——所以平均的细胞在大多数的时间看到表面的光的不到一%、呼吸超过生产、而种群被洗出、无论水多么富。四月的层化使 $Z_{\mathrm{mix}}$ 变浅过近 $50$–$60\ \mathrm{m}$ 的 $Z_{\mathrm{cr}}$、而水华在几天内开始。

斯韦德鲁普的判据是两个长度之间的一个不等式、不是任何化学物质中的一个阈值、这就是为什么水华这么难预报、而这么对风、涡度、而层化的开始敏感。五月的一场单独的风暴能把层重新加深、而取消一个水华；一个涡度能把它提前三周。1998–2020 的北大西洋的水华的日期的每年 0.4 天的观察到的提前相当于二十年中的 8 天的提前、而它与更早的春天的层化、不是直接与温度、相关。

碳的循环的后果是更早的水华不一定是一个更大的水华。更早的层化意味着一个更浅的混合层、那意味着一个更小的被卷夹的硝酸盐的清单、那意味着更少的新的生产、而更少的输出、即使光合作用的季节更长。这是模型的二十一世纪的北大西洋的输出生产约 5–10% 的下降背后的机制、而这个学科中一个生物学的反馈、它的符号与"绿化"这个词建议的相反、的最清楚的例子。
:::
:::

::: example 从冬天的混合层的新的生产 {#ex-newprod}
在百慕大的晚冬的混合层深 $80\ \mathrm{m}$、而有 $20\ \mu\mathrm{mol\,L^{-1}}$ 的硝酸盐。假设它的全部在一年中被消耗、求以 $\mathrm{g\ C\,m^{-2}\,yr^{-1}}$ 计的年的新的生产。
::: solution
硝酸盐的清单是
$$
0.020\ \mathrm{mol\,m^{-3}}\times80\ \mathrm{m} = 1.6\ \mathrm{mol\ N\,m^{-2}},
$$
而里德菲尔德的**化学计量**（$\mathrm{C}:\mathrm{N} = 106:16$）给出
$$
1.6\times\frac{106}{16} = 10.6\ \mathrm{mol\ C\,m^{-2}} = 127\ \mathrm{g\ C\,m^{-2}\,yr^{-1}} .
$$
在萨加索的站的时间序列观察到的年的新的生产是 $60$–$100\ \mathrm{g\ C\,m^{-2}\,yr^{-1}}$、所以一维的预算高估了三成到一倍。

高估是有意思的部分。不是全部的硝酸盐被用——层在下抽完成之前重新层化。供给的一些来自冬天的层之下、靠俯冲与涡度的注入、那一维的方法完全错过。而大的部分的年的硝酸盐的输入靠深的水的冬天的卷夹到达、不是靠层开始时的浓度。这就是为什么方法仍被使用：它是便宜的、它在概念上是干净的、而它的错误是系统的而已知的、那使它成为一个可用的指标、即使它不是一个测量。

将 $127\ \mathrm{g\ C\,m^{-2}\,yr^{-1}}$ 乘以世界的中营养与贫营养的环流的 $1.5\times10^{14}\ \mathrm{m^{2}}$、而暗示的新的生产是 $19\ \mathrm{PgC\,yr^{-1}}$、对着一个基于卫星的全球的总的约 $50\ \mathrm{PgC\,yr^{-1}}$、而一个新的生产的估计约 $10\ \mathrm{PgC\,yr^{-1}}$。方法之间的两倍的散布是海洋的生物的碳的封存的不确定的规模、而它在二十年中没有变窄。
:::
:::

::: example 马丁的曲线与一个输出的通量的命运 {#ex-martin}
一个沉积的陷阱的阵列记录 $F(100\ \mathrm{m}) = 100\ \mathrm{g\ C\,m^{-2}\,yr^{-1}}$。以全球的均的衰减的指数 $b = 0.86$、求在 $1000\ \mathrm{m}$、而在 $4000\ \mathrm{m}$ 的通量、而如果表面的生产是 $300\ \mathrm{g\ C\,m^{-2}\,yr^{-1}}$、被埋的表面的生产的分数。
::: solution
$$
F(1000) = 100\times\left(\frac{1000}{100}\right)^{-0.86} = 100\times10^{-0.86} = 13.8\ \mathrm{g\ C\,m^{-2}\,yr^{-1}}
$$
$$
F(4000) = 100\times40^{-0.86} = 4.2\ \mathrm{g\ C\,m^{-2}\,yr^{-1}}
$$
而埋藏的分数是 $4.2/300 = 1.4\%$。

输出的十四% 逃出中层的水；总的生产的半% 被埋。这些是设定大气的 CO₂ 的数字、而这就是生物学的泵被叫做一个漏的泵的原因。剩余的 98.6% 在水柱中被呼吸、而那个呼吸是消耗氧、而建内部的营养的东西——同一个过程、从另一面读、作为氧的极小的区与深的太平洋的碳的多余。

指数 $b$ 不是常数。它在物质是易变的硅藻的有机的物质之处是 $1.2$–$1.5$、而在它是碳酸盐的压载的或难降解的是 $0.4$–$0.6$、而比 $F(1000)/F(100)$ 从贫营养的环流的 $0.05$ 变化到一个南大洋的硅藻的水华之下的 $0.30$。六倍的范围、不是表面的生产、是决定哪些区域封存碳的东西、而它是没有一个卫星能看到的、而每一个地球系统的模型必须猜的量。
:::
:::
::: example 铁的放大 {#ex-iron}
一个开阔的海洋的铁的富化的实验添加 $3.0\ \mathrm{nmol\,L^{-1}}$ 的溶解的铁、而把硝酸盐下抽 $30\ \mu\mathrm{mol\,L^{-1}}$。求每一摩尔的铁固定的碳的摩尔数、而如果富化的层深 $100\ \mathrm{m}$、每一公顷的固定的碳的质量。
::: solution
里德菲尔德给出 $\Delta\mathrm{DIC} = 30\times106/16 = 199\ \mu\mathrm{mol\,L^{-1}}$ 的碳、所以
$$
\frac{\Delta\mathrm{C}}{\Delta\mathrm{Fe}} = \frac{199\times10^{-6}}{3.0\times10^{-9}} = 6.6\times10^{4}\ \mathrm{mol\ C\ per\ mol\ Fe}.
$$
在 **$100\ \mathrm{m}$** 上：$0.199\ \mathrm{mol\,m^{-3}}\times100\ \mathrm{m} = 19.9\ \mathrm{mol\ C\,m^{-2}} = 239\ \mathrm{g\ C\,m^{-2}}$。

每一个铁原子六万六千个碳原子是使铁在地球化学上有趣的放大：一个万亿分之一的一个痕量的金属控制着一个十万分之一的一个宏量的营养的循环。同样的比是为什么冰期的尘埃的记录——南极的冰的芯的铁与钍的浓度比全新世高四到五倍——而南极的绕极的流以南的蛋白石与碳酸盐的积累的速率能被读作一个碳的循环的记录。

然而诚实的资产负债表是六个大的富化的实验的结果。SOIREE 与 SOFeX 产生了清楚的硅藻的水华、而清楚的营养的下抽；亚极地的太平洋的 SEEDS 产生了一个小的群落的响应；EisenEx、EIFES 与 LOHAFEX 在 $100\ \mathrm{m}$ 之下产生很少或没有可测量的碳的输出。共识是铁的施肥可靠地刺激生产、而输出得不好、因为水华在表面的层被牧食而呼吸、而冰期的 CO₂ 的效应、虽然是真实的、不足以单独解释 $100\ \mu$atm 的消冰期的上升。这也是商业的海洋的铁的施肥在 2008 年在伦敦的公约之下被禁止、而它仍是对一个错的问题的错的回答的原因。

维克托·亨森在 1887 年创造了"浮游生物"这个词、而做了第一次的定量的拖网、而阿利斯泰尔·哈迪爵士在 1931 年拖着第一台连续的浮游生物的记录器过北大西洋；CPR 的调查仍在运行、而是存在的最长的连续的海洋的生物的记录。哈拉尔·乌尔里克·斯韦德鲁普在 1953 年把春天的水华化简为混合层的深度与一个临界的深度之间的一个不等式、而埃里克·斯滕曼·尼尔森在 1952 年引入了测量初级的生产的碳十四的方法、它把海洋的生物学从计数变成了测量。阿瑟·达格尔与约翰·格林在 1967 年用氮的同位素把新的与再生的生产分开、约翰·赖瑟在 1969 年把那个分离与生物的大小、而碳的命运连接、而特雷弗·普拉特与肯·登曼在 1980 年代把光合作用的–辐照的曲线与它的卫星的缩放形式化。查尔斯·延奇把体内的叶绿素的荧光变成一个流动的测量、而 NASA 的查尔斯·麦克莱恩把海岸的带的颜色的扫描器、SeaWiFS、然后 MODIS 送入轨道、所以自 1997 年全球的表面的叶绿素一直是一张日常的全球的图、而不是一条船的航迹。约翰·马丁在 1988 年从南极的营养的数据的一张单独的图提出了铁的假说；肯尼斯·科尔的 1995 年的 IronEx、SOIREE 与 SOFeX、SEEDS、EisenEx、EIFES、而维克托·斯梅塔切克的 2009 年的 LOHAFEX 检验了它六次、而确立了铁可靠地刺激生产、而不可靠地刺激输出。丹尼尔·卡尔的自 1988 年的夏威夷的海洋的时间的序列、而安东尼·迈克尔斯与尼古拉斯·贝茨的自 1984 年的百慕大的时间序列产出了首次检测到海洋的化学的对气候的响应的二十五年的生物地球化学的记录、而自 2010 年运行的 GEOTRACES 测绘了整个的海洋的溶解的铁、锌、钴、而镉的循环。丹尼尔·保利与雷格·沃森从国家的报告的伪影重建了全球的海洋的捕获、而显示了世界渔业真实的状态、而丹尼尔·博伊斯、马隆·刘易斯、而大卫·柯比在 2010 年主张一个每一年的百分之一的一个世纪的全球的浮游植物的下降——一个在标定与取样的理由上有争议的、而仍在争论的结果、而二十四年的卫星的记录还不是一个气候的趋向的最清楚的说明。
:::

::: warning 这里的一切是一个在你看不到的尺度上按数量级变化的一个量的均值
七个告诫。卫星看到顶部的光学的深度、不是海洋。海洋的颜色的算法在一个衰减的深度——顶部的 $10$–$30\ \mathrm{m}$——之内从蓝对绿的辐射的比回收叶绿素、而看不到在 $80$–$150\ \mathrm{m}$ 的含有环流的浮游植物的三分之一到一半的深的叶绿素的极大、看不到海岸的水的有色的溶解的有机的物质、而在高纬度在冬天根本看不到、那正是年的生产被决定之处。叶绿素不是碳。光驯化、物种的组成、而光使叶绿素对碳的比变化五到十倍的因子、所以叶绿素的一个五成的变化可能对生产什么都不意味着。f 的比是一个带一个已知的偏差的替代指标。野外的相互比较给出中间范围的 $\pm 0.15$ 的 $f$ 的不确定、而硝酸盐的方法系统地错过被输出的再生的生产、而没被输出的新的生产。马丁的指数是对沉积的陷阱的一个拟合、它被知道收集不足大的快下沉的颗粒、而被游泳的生物、系泊的阴影、而错过一个水华的三天的输出的事件的二十天的布设偏置。中尺度与亚中尺度的过程主导营养的供给、而不被做出预测的模型分辨：涡度的俯冲、锋的生成、混合层的不稳定、而内部的波的破碎以与垂直的扩散相当的速率供给硝酸盐、而它们每一个都需要只有最近五代模型尝试的公里尺度的分辨。生态系统的模型被调过、而它们的浮游生物的功能的类型不是生物：一个有四个浮游植物的类型、而一个浮游动物的类型的模型按构造再现观察到的叶绿素的场、而没有义务再现它的未来。而观察到的世纪的趋向未被确立。唯一的全球的记录是二十四年的海洋的颜色、它的标定改变了三次、它的原位的验证的数据偏向向阳的环流、而两个头条的主张——每一年的百分之一的全球的变褐、而没有显著的全球的趋向——来自同一组被不同处理的数据。
:::

## 通向何处

设定临界的深度的光场与混合层在[[oceanography/wind-driven]]与[[oceanography/air-sea-fluxes]]、营养的供给是[[oceanography/overturning]]的翻转、化学计量是[[oceanography/ocean-chemistry]]与[[biogeochemistry/production-decomposition]]、氮的循环是[[biogeochemistry/nitrogen]]、磷与硅的循环是[[biogeochemistry/phosphorus-sulfur]]、碳的输出是[[oceanography/ocean-chemistry]]与[[climate-system/carbon-climate]]、氧的极小的区是[[oceanography/seawater]]与[[climate-change/observed-change]]、卫星的回收是[[remote-sensing/classification]]与[[remote-sensing/em-radiation]]、渔业与生态系统的影响是[[climate-change/impacts]]、冰期的铁的记录是[[palaeoclimate/ocean-sediments]]与[[palaeoclimate/abrupt-change]]、而泵的深度时间的演化是[[earth-system/carbon-cycle]]与[[biogeochemistry/principles]]。

::: quiz
为什么春天的水华在四月、不在营养最高、而光在增加的三月开始？
- [ ] 因为浮游动物的牧食在三月达到极大。
- [x] 因为混合层必须变浅过临界的深度、而在三月它仍比真光的带深得多。
- [ ] 因为水的温度必须超过一个阈值。
- [ ] 因为铁随春天的尘埃到达。
::: solution
斯韦德鲁普的判据是 $Z_{\mathrm{mix}} < Z_{\mathrm{cr}}$。在三月混合层是 $150$–$200\ \mathrm{m}$、而真光的带 $50\ \mathrm{m}$、所以深度的均的光不能覆盖呼吸。四月的层化使层变浅过临界的深度、而水华在几天内开始、而营养仍丰富。
:::
:::

::: summary
- 海洋的植物每年固定约 50 Pg C、与陆地的植物一样多、来自在几天中翻转的细胞。
- 水华是一场光与混合的竞争：斯韦德鲁普的临界的深度、不是营养的浓度、设定它的时机。
- 只有新的生产——从硝酸盐建造的部分——能被输出；f 的比从环流的 0.1 运行到上升流的 0.5。
- 微生物的环与病毒的旁路重新加工大多数的固定的碳；难降解的溶解的有机的物质是一个与大气一样大的库。
- 输出跟着马丁的幂律；在全球的指数只有约一% 的 100-m 的通量到达 1000 m、而 1.4% 的生产被埋。
- 铁限制海洋的三分之一；六个富化的实验显示铁的施肥可靠地刺激生产、而输出得不好。
- 气候的变化使混合层变浅、那提前水华、而减少它的输出——一个更绿的表面、而一个更弱的泵。
:::

## 练习题

::: exercise 真光的带 {level=1 check="115"}
求 $K_d = 0.04\ \mathrm{m^{-1}}$ 的一% 的光的深度。
::: solution
$Z_{1\%} = 4.6/0.04 = 115\ \mathrm{m}$。这是清的贫营养的水、在它的深的叶绿素的极大坐在 $100\ \mathrm{m}$——在一些季节在冬天的混合层之下、而在另一些季节在其内、这就是副热带的水华的时机不如斯韦德鲁普的理论预测的那样整齐的一个原因。
:::
:::

::: exercise 一个浊的海岸 {level=1 check="5"}
求一个 $K_d = 0.92\ \mathrm{m^{-1}}$ 的河口的一% 的光的深度。
::: solution
$Z_{1%} = 4.6/0.92 = 5\ \mathrm{m}$。在五米的真光的带里全部的年的生产必须装下、这就是浊的海岸是光的、不是营养的限制的、为什么它们由底栖的微藻与海草主导、在光到达底之处、而为什么河的径流与疏浚的浊度不改变一个营养的浓度就杀死海草的草床。
:::
:::

::: exercise 新的生产 {level=1 check="57"}
一个 **60 m** 深的冬天的混合层含有 $12\ \mu\mathrm{mol\,L^{-1}}$ 的硝酸盐。求年的新的生产。
::: solution
$0.012\times60 = 0.72\ \mathrm{mol\ N\,m^{-2}}$；$\times106/16 = 4.8\ \mathrm{mol\ C\,m^{-2}}$；$\times12 = 57\ \mathrm{g\ C\,m^{-2}\,yr^{-1}}$。一个典型的中营养的值、而方法的假定——完全的冬天的营养的下抽、而没有从下面的供给——使它在一些区域是一个下界、在另一些是一个上界、这就是为什么时间序列的站测量整个的年的周期、不是信任它。
:::
:::

::: exercise 深处的通量 {level=2 check="50"}
以 $F(100) = 200\ \mathrm{g\ C\,m^{-2}\,yr^{-1}}$、而 $b = 0.86$、求 $F(500\ \mathrm{m})$。
::: solution
$F = 200\times5^{-0.86} = 50\ \mathrm{g\ C\,m^{-2}\,yr^{-1}}$。通量的四分之一存活四百米——而呼吸的四分之三恰恰是上中层的氧的需求与营养的清单、这就是为什么氧的极小的区的深度与营养的极大的区的深度与这条曲线的最陡的部分重合。
:::
:::

::: exercise 推断指数 {level=2 check="0.52"}
一个陷阱记录 $F(100) = 100$、而 $F(1000) = 30\ \mathrm{g\ C\,m^{-2}\,yr^{-1}}$。求 $b$。
::: solution
$b = -\log_{10}(30/100) = 0.52$。这是一个压载的、有效地输出的系统——一个硅藻的水华或一个碳酸盐的丰富的陆架——而与全球的均的 $0.86$ 的反差意味着同样的表面的生产在那里向深处交付比全球的均的建议的两倍多的碳。$b$ 的区域的差、不是生产的差、主导全球的封存。
:::
:::

::: exercise 铁的放大 {level=2 check="79500"}
一个富化添加 $2.0\ \mathrm{nmol\,L^{-1}}$ 的铁、而把硝酸盐下抽 $24\ \mu\mathrm{mol\,L^{-1}}$。求碳对铁的比。
::: solution
$\Delta\mathrm{C} = 24\times106/16 = 159\ \mu\mathrm{mol\,L^{-1}}$、而 $159\times10^{-6}/2.0\times10^{-9} = 79{,}500\ \mathrm{mol\ C\ per\ mol\ Fe}$。每一个铁原子八万个碳原子——使一个痕量的金属成为一个气候的变量的催化的放大、而一个绳子或一个泵的软管的二纳摩尔的污染能毁掉一个铁的实验的原因。
:::
:::

::: exercise 一条鱼的代价 {level=3 check="115"}
一个渔业在营养的级别 **$3.5$** 上岸 **100 万吨**的鱼。以一个 **一五%** 的营养的转移的效率、求所需的初级的生产。
::: solution
从基部的 $2.5$ 次转移：$10^{6}\times(1/0.15)^{2.5} = 10^{6}\times115 = 1.15\times10^{8}\ \mathrm{t}$——一百一十五万吨的初级的生产换一百万吨的鱼。在约 $3$ 的均的营养的级别约 $80\ \mathrm{Mt}$ 的全球的海洋的捕获因此需要几千亿吨的生产、海洋的输出的一大部分、而观察到的捕获的全球的均的营养的级别自 1950 年下降了约 $0.5$——"沿食物网向下捕"——而这是同一个算术读作一个警告。
:::
:::

::: exercise 全球的均值 {level=3 check="139"}
全球的海洋的净的初级的生产是 $50\ \mathrm{Pg\ C\,yr^{-1}}$。求面积均的速率。
::: solution
$50\times10^{15}/3.61\times10^{14} = 139\ \mathrm{g\ C\,m^{-2}\,yr^{-1}}$。均值是无意义的：副热带的环流生产 $50$–$100$、上升流的区域 $500$–$2000$、而贫营养的中心不到 $50$、而面积的加权的分布是对数的正态的。这就是全球的碳的预算依赖上升流的海洋的几% 的原因、而一个看不到海岸的或被冰覆盖的水的卫星的任务在覆盖大多数的面积时错过大多数的输出的原因。
:::
:::
