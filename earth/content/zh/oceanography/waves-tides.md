一个三米的涌浪以一个八秒的周期携带七十千瓦穿过每一米的海岸线——足够沿着葡萄牙的陆架给一个小镇供电——而抬起它的潮汐在海底上摩擦中耗散 $3.5\times10^{12}\ \mathrm{W}$、比人类在能源中用的更多。表面的重力的波与潮汐是海洋不需要风的耐心、也不需要输送带的千年而执行的两个运动、而在两者之间它们设定每一个海滩的形状、每一个海峡的混合、而每一个海啸的警告的期限。

## 表面的重力的波

::: definition 线性波的理论 {#def-airy}
在一个深度 $h$ 的水上的一个振幅 $a$、波数 $k = 2\pi/\lambda$、而频率 $\omega = 2\pi/T$ 的小的振幅的波、频散的关系是
$$
\boxed{\;\omega^{2} = gk\tanh(kh)\;}
$$
有两个极限
$$
\text{deep water } (kh \gg 1):\quad c = \frac{\omega}{k} = \frac{gT}{2\pi} = 1.56\,T\ \mathrm{m\,s^{-1}}, \qquad
\text{shallow water } (kh \ll 1):\quad c = \sqrt{gh},
$$
所以长的波走得更快、而深水的相的速度只依赖于周期。能量在其上行进的群的速度是
$$
c_g = c\,\frac{1 + 2kh}{2\sinh(2kh)} \;\longrightarrow\; \begin{cases} c/2 & \text{deep} \\ c & \text{shallow} \end{cases}
$$
——在深水中能量以波峰的速度的一半移动、这就是为什么一个涌浪的列队的能量在它的最初的波峰之后到达、而为什么一艘逆着涌浪行驶的船比静止时在一小时中遇到更多的波。

每单位的表面的面积的**均的**能量是
$$
E = \tfrac{1}{2}\rho g a^{2} = \tfrac{1}{8}\rho g H_{s}^{2},
$$
一半是势的、而一半是动的、而每单位的波峰的长度的能量的通量是
$$
P = E\,c_g = \frac{\rho g^{2} H_s^{2} T}{32\pi} \approx H_s^{2}\,T\ \mathrm{kW\,m^{-1}} .
$$
对 $H_s = 3\ \mathrm{m}$、而 $T = 8\ \mathrm{s}$、这是每一米的波峰的 $71\ \mathrm{kW}$——世界的能量的海岸也是它的侵蚀的热点的原因、而在五十年的尝试的工程之后波的的能量仍是一个小众的技术的原因。

三个运动学的后果控制海岸。折射遵守斯涅尔定律 $\sin\theta/\sqrt{gh} = \text{const}$、它把波弯进岬角、而弯出海湾、而每一个耗散的海滩近平行于深水的波峰。变浅在 $c_g$ 下降时守恒 $E c_g$、所以 $H$ 以 $h^{-1/4}$ 增长、直到破碎。而波不输运水、它们输运能量：轨道在线性的理论中是闭合的椭圆、而剩下的小的净的漂移——斯托克斯的漂移、$u_S = \omega k a^{2} e^{2kz}$——是以风的速度的百分之一到三把塑料、幼虫、而油带着顺风走的东西。
:::

::: definition 风浪、涌浪、而破碎 {#def-windwaves}
波靠从风取走动量生长、而理论有两个阶段。菲利普斯（1957）显示大气边界层中的湍流的压力的的波动与平的表面共振、而以一个与风的应力成正比的速率生成波、给出从零的指数生长。迈尔斯（1957）显示一旦波存在、风速与波的相的速度匹配的临界的层产生一个以与波的坡度成正比的速率输送能量的剪切流的不稳定——在振幅上的线性生长。两者都运行；迈尔斯的机制在波大之后主导、而在陡的波峰之上分离的气流——查诺克的粗糙度的形的阻力——在台风的风中主导。

生长被吹程、持续时间、而风速限制、而一个充分发展的海到达皮尔逊–莫斯科维茨的谱、它的无量纲的峰是普适的：
$$
H_s = 0.0246\,U_{10}^{2}, \qquad T_p = 0.66\,U_{10}, \qquad
E(f) \propto f^{-4}\exp\!\left[-\tfrac{6}{5}\left(\frac{f_p}{f}\right)^{4}\right],
$$
以 $\mathrm{m\,s^{-1}}$ 的 $U_{10}$、米的 $H_s$、而秒的 $T_p$。一个 20 m s⁻¹ 的大风因此建造一个 9.8-m 的海、以一个 13-s 的周期、而联合海的峰的增强 $\gamma = 3.3$ 描述了每一个海上的结构按其设计的受吹程限制的北海的版本。

破碎在波的轨道的速度超过相的速度时发生（在深水中 $ka \approx 0.33$、给出 $H/\lambda \approx 0.14$）、或在浅水中在达到深度限制的破浪的指数时：
$$
H_b = \gamma_b h, \qquad \gamma_b \approx 0.78\ \text{(sloping beach)},\quad 0.6\text{–}0.8\ \text{field range}.
$$
一个破浪是海洋的最有效的能量的耗散者：一个单一的 3-m 的破浪在几秒中释放 $\sim 10^{4}\ \mathrm{W\,m^{-1}}$、生成拍岸的浪的节拍、运行整个行星的低于重力的波、建造沙嘴的沿岸的流、而自泥盆纪以来使海岸听得见的声音。

一旦风减弱或吹程结束、波变成涌浪：它们按周期把自己分类、因为 $c \propto T$、而五千公里外的一个风暴交付一个干净的、近单色的列队、它的周期宣布它走过的距离。波利尼西亚的寻路者用了这个——读交叉的涌浪的格局来定位地平线之下的岛——而卫星的高度计如今把全球的涌浪的气候学测绘到 0.1 m 而 0.5 s。
:::
::: example 波的能量与一个涌浪的功率 {#ex-wavepower}
求在**深**水中一个 $H_s = 3\ \mathrm{m}$、而 $T = 8\ \mathrm{s}$ 的涌浪的能量的密度、群的速度、而能量的通量、而进入一个 **50-km** 的海岸的段的总的功率。
::: solution
$$
E = \tfrac{1}{8}\rho g H_s^{2} = \tfrac{1}{8}\times1025\times9.81\times9 = 11{,}300\ \mathrm{J\,m^{-2}}
$$
$$
c = \frac{gT}{2\pi} = 12.5\ \mathrm{m\,s^{-1}}, \qquad c_g = \frac{c}{2} = 6.25\ \mathrm{m\,s^{-1}},
$$
$$
P = E c_g = 11{,}300\times6.25 = 7.1\times10^{4}\ \mathrm{W\,m^{-1}} = 71\ \mathrm{kW\,m^{-1}},
$$
而在 50 km 的波峰之上、$3.5\times10^{9}\ \mathrm{W} = 3.5\ \mathrm{GW}$——一个大的发电站的输出、连续地到达、来自一个普通的海。

效率的问题不是资源、是它的不规则：能量成组地、在风暴中、而在在小时上改变的方向到达、而任何一个存活一个百年的风暴的装置必须在携带十倍的设计的通量的水中系泊时存活它。波的能量的变换器出于这个原因、不是缺千瓦、在五十年中反复地到达商业的失败。

对海岸要紧的数字是梯度、不是通量。在到达的 71 kW m⁻¹ 中、也许 65 kW m⁻¹ 在拍岸的带中耗散——而在一个港的防波堤拦截它的甚至五% 之处、通量在驱动沿岸的沉积的输运停止、而上游的海滩生长、而下游的海滩消失。这是入口的稳定、海滩的补给的失败、而港的淤积的全部机制、而海岸的工程是应用的波的能量梯度的原因。
:::
:::

::: example 涌浪的分类 {#ex-swell}
五千公里外的一个风暴在五天前停止生成波。如今在这里观察的涌浪由什么周期主导、而 10-s 的分量还要多久？
::: solution
在深水中 $c_g = gT/(4\pi)$、所以一个周期 $T$ 的分量在 $t = 4\pi L/(gT)$ 中走过距离 $L$。反演、
$$
T = \frac{4\pi L}{g t} = \frac{4\pi\times5\times10^{6}}{9.81\times4.32\times10^{5}} = 15\ \mathrm{s}.
$$
**10-s** 的分量以 $c_g = 7.8\ \mathrm{m\,s^{-1}}$ 行进、而花 $5\times10^{6}/7.8 = 6.4\times10^{5}\ \mathrm{s} = 7.4$ 天——**两个半**天之后。

这个分类是为什么一个在纳米比亚外的预报的浮标报告三天前一个南大西洋的风暴的一个干净的 16-s 的涌浪、为什么波的谱在远离生成的区域更窄、而为什么冲浪的预报者引用涌浪的窗口的方向与周期、不是风：能量在穿过盆地的路上已经被频散的关系分类了。

同一个的算术是海啸的警告的基础。一个海啸在浅的水中以 $\sqrt{gh}$ 行进、它是非频散的、所以它的全部分量一起到达、而它的行进的时间是一个单一的数字——一个警告能在几分钟中被发出、而可信的原因。普通的波、因为是频散的、完全不能被警告：它们的到达是盆地的全部的风的历史的一个被涂抹的函数。
:::
:::

::: definition 潮汐 {#def-tides}
月与日的潮汐的势抬起一个平衡的潮——海如果静止不动、而立刻响应会达到的高度——的振幅
$$
\eta_{\mathrm{eq}} = \frac{3}{2}\frac{M}{M_{\oplus}}\left(\frac{a}{r}\right)^{3} a ,
$$
对月是 $0.54\ \mathrm{m}$、而日是 $0.24\ \mathrm{m}$。观察到的开阔的海洋的范围是 $0.3$–$0.7\ \mathrm{m}$、接近平衡；观察到的海岸的范围在芬迪湾达到 $16\ \mathrm{m}$、而在塞文河 $15\ \mathrm{m}$。三十倍的放大不是理论的失败、是它的要点：潮是真实的盆地的一个受迫的振荡、而一切有趣的东西都在共振里。

四个频率主导。主要的月的半日的分潮 M₂ 有一个 $12.42\ \mathrm{h}$ 的周期、太阳的 S₂ 有 $12.00\ \mathrm{h}$、日月的全日的 K₁ 有 $23.93\ \mathrm{h}$、而月的全日的 O₁ 有 $25.82\ \mathrm{h}$。大潮在 M₂ 与 S₂ 在朔望对齐时发生、小潮在方照；它们的周期的 1.93 小时的差设定 14.8 天的大潮–小潮的周期。自然的周期匹配 12.42 h 的盆地是半日的（北大西洋、12.4-h 的 $3$–$5\ \mathrm{m}$ 的范围）；匹配 23.9 h 的是全日的（墨西哥湾、北美的太平洋的海岸）；地中海与波罗的海太小、而太连通、在两者都不共振、而有 $0.1$–$0.5\ \mathrm{m}$ 与 $0.02\ \mathrm{m}$ 的范围。

在深水中 M₂ 的自由的波的速度是 $\sqrt{gh} = 198\ \mathrm{m\,s^{-1}}$、而它的波长是 $\lambda = cT = 8900\ \mathrm{km}$——比大西洋更宽。一个比半个波长更窄的盆地因此不能支持一个直接的潮、而代替地围绕一个范围是零的无潮的点旋转一个共同振荡的波。地球上的每一个潮汐的表是大约一打这样的无潮的系统的图、而每一个的形状由海岸线、陆架的深度、而摩擦设定。

潮汐的摩擦做了三件延伸到岸线之外的事情。它在海洋中耗散 $\sim 3.5\ \mathrm{TW}$——所有的河的总的机械的功率的二十五倍——其中大约十分之一在粗糙的地形之上被转换成内潮、而辐射到内部、在它破碎、而供给使输送带运行的深海混合的一个大的分数。它扭动地球、把日每一世纪加长 $2.3\ \mathrm{ms}$、而把月以 $3.8\ \mathrm{cm\ yr^{-1}}$ 推开、所以泥盆纪的珊瑚在一年中保存 $400$ 天、而 $385$ 百万年的潮汐的节奏被写在生长的纹里。而它混合河口：困住混浊的极大的残余的环流、盐水楔依赖的层化、而地球上的每一个港的冲刷由潮汐的速度的立方设定、这就是为什么一个两倍的放大意味着一个八倍的耗散。
:::

::: example 潮汐的波长与无潮点 {#ex-tidewave}
求 4000-m 深的大西洋中的 M₂ 的自由的波的波长、而解释为什么大西洋有无潮的点、而北海有一个单一的旋转的系统。
::: solution
$$
c = \sqrt{gh} = \sqrt{9.81\times4000} = 198\ \mathrm{m\,s^{-1}}, \qquad
\lambda = cT = 198\times44{,}713 = 8900\ \mathrm{km}.
$$
大西洋 5000–6000 km 宽、所以它比半个潮汐的波长更窄、而不能容纳一个直接的潮：盆地代替地困住一个四分之一的波长的模、而波围绕无潮的点旋转——一个在葡萄牙外、一个在纽芬兰外、一个在北部的内部——范围从无潮点的零向外增长到芬迪湾的顶的 $16\ \mathrm{m}$。900 km 宽、而有一个 $95\ \mathrm{m}$ 的均的深度的北海、有 $\lambda = \sqrt{9.81\times95}\times44{,}713 = 1300\ \mathrm{km}$、所以它容纳勉强一个旋转的系统、从北部进入、而向南放大进浅的南部的湾——恰恰是 1953 与 1962 的洪水打击之处。

科里奥利力是使波旋转、不反射的东西、而旋转的半径是重力的波的半径 $\sqrt{gh}/f$：在深海的 $280$–$400\ \mathrm{km}$、与一个大陆陆架的宽度相当。这就是为什么海岸困住的波在两个半球都贴着西的边界、为什么孟加拉湾中的潮汐的波向北放大进恒河的三角洲、而使芬迪成为地球上最高的潮的同一个几何使孟加拉成为最致命的。
:::

::: example 内潮 {#ex-internaltide}
一个两层的海洋有一个 200-m 的混合层在 $3000\ \mathrm{m}$ 之上、有一个 $2\ \mathrm{kg\,m^{-3}}$ 的密度的跃变。求 M₂ 的内潮的相的速度、而与 $3200\ \mathrm{m}$ 中的正压的潮比较。
::: solution
约化的重力是 $g' = g\Delta\rho/\rho_0 = 9.81\times2/1025 = 1.9\times10^{-2}\ \mathrm{m\,s^{-2}}$、而长的内波的速度是
$$
c_i = \sqrt{g'\frac{h_1 h_2}{h_1 + h_2}} = \sqrt{1.9\times10^{-2}\times\frac{200\times3000}{3200}} = 1.9\ \mathrm{m\,s^{-1}},
$$
对着正压的潮的 $\sqrt{9.81\times3200} = 177\ \mathrm{m\,s^{-1}}$——慢一百倍、因此波长短一百倍：$25\ \mathrm{km}$、不是 $2800\ \mathrm{km}$。

那个短是内潮的全部故事。一个波长几千公里的 $10\ \mathrm{cm}$ 的正压的潮相干地晃过海洋；一个 $100\ \mathrm{m}$ 的振幅、而 $25\ \mathrm{km}$ 的波长的斜压的潮在正压的流跨过粗糙的地形之处——吕宋海峡、夏威夷的海脊、巴西的陆缘、而印度洋的断裂的带——被有效地强迫、而然后作为一个内波的波束辐射开、变陡、而在它出生的几百公里之外破碎。

全球的转换是 $0.3$–$1\ \mathrm{TW}$、总的潮汐的耗散的十分之一、而因为破碎在开阔的内部、不是在海岸发生、那能量被恰好处在使输送带运行的深海的混合需要它的地方交付。把南极的底层的水抬回温跃层的能量的大约一半来自月拉水下的山、而没有它们输送带会比单是风预测的慢得多。
:::

::: warning 线性的理论是一个非常好的近似、一直到它不是的那一刻
六个失败。真实的波不是正弦的。一个充分发展的海是几百个分量的随机的叠加；波峰比显著的波高暗示的更高、而更尖、而波谷更平、而一个风暴中的最大的波单靠统计是 $H_{\max} \approx 1.86\,H_s$——这就是为什么异常波不需要是异常的、只需要不走运、而为什么异常波的研究分裂成"线性的叠加"与"非线性的调制的不稳定"两个阵营、而两者都被发现运行。破碎不在方程里。线性的理论没有一个破碎的机制、没有白浪的耗散、没有拍岸的带、没有增水、而没有沿岸的流；那每一个要么需要一个经验的破浪的指数、要么需要一个空气与水的纳维–斯托克斯的模拟。风暴潮不是一个波。它是到一个压力的与风的亚惯性的、摩擦的、浅水的响应、有一个 $1$-cm-per-hPa 的倒气压计的分量、一个随 $\tau/\rho g h$ 缩放、而能在一个浅的陆架上达到 $5\ \mathrm{m}$ 的风的增水的分量、而一个使它乘倍的潮——1953 的北海与 2005 的卡特里娜的灾难都是高潮时的风暴潮的事件、而全部的灾害在相关里。潮汐不从势预测。它们从几十年的潮仪的记录的调和的分析预测、因为盆地的响应——共振、无潮点、陆架的摩擦、海峡的槛——从第一性原理不可计算、而最好的全球的潮汐的模型在陆架上仍带着 $2$–$5\ \mathrm{cm}$ 的错误。内潮不可见、而重要。在吕宋海峡、夏威夷的海脊、而巴西的陆架之上生成的斜压的潮有一个 $50$–$250\ \mathrm{m}$ 的振幅、辐射 $0.3$–$1\ \mathrm{TW}$、而在它的生成的地点之外破碎——供给输送带需要的混合的很多、而用一个在时间上相干的、因此不被平均掉用一个信号破坏每一个卫星的高度计的均的环流的测量。而海岸线不固定。波驱动的沿岸的漂移每一世纪每一米的海岸移动 $10^{5}$–$10^{6}\ \mathrm{m^{3}}$ 的沉积；一个单一的丁坝打断它；而海平面的上升使整个的系统后退、同时保持它的形状——布伦规则——这就是为什么海堤这么经常加速它们被建造来停止的侵蚀。
:::

艾萨克·牛顿在 1687 的《自然哲学的数学原理》中给出了潮汐的势；丹尼尔·伯努利在同一年写下了第一个平衡的理论、而莱昂哈德·欧拉与亚历克西·克莱罗在 1740 年代写下了第一个动力的。皮埃尔–西蒙·拉普拉斯在 1775 年为真实的盆地的受迫的振荡提出了浅水的方程、而威廉·惠威尔在 1833–1836 测绘了北大西洋的共同振荡的波、而创造了"无潮的"这个词。乔治·比德尔·艾里在 1845 年写了经典的《潮汐与波》的报告、导出了在每一个海岸的手册中仍在用的长的波的结果；约翰·斯科特·拉塞尔在 1834 年在苏格兰的一条运河中观察了孤立波、而乔治·加布里埃尔·斯托克斯在 1847 年解释了漂浮的水的净的漂移。乔治·霍华德·达尔文在 1870–1890 年代发展了潮汐的调和的分析、而潮汐的摩擦的理论、显示地球–月的系统演化、而阿尔贝特·德方特在 1961 年在《潮汐物理学》中编纂了两个世纪的潮汐的科学。哈罗德·杰弗里斯在 1925 年导出了水波的风的生成、斯韦德鲁普与蒙克在 1944 年把它变成了一个预报的方法、而欧文·菲利普斯与约翰·迈尔斯在 1957 年发表了波的生长的两个机制——共振的压力与剪切流的不稳定——在背对背的论文中。西奥多·皮尔逊与大卫·莫斯科维茨在 1964 年给出了充分发展的谱、克劳斯·哈塞尔曼与联合海的组在 1973 年给出了受吹程限制的、而迈克尔·隆盖–希金斯与罗伯特·斯图尔特在 1953–1964 发明了辐射的应力、它最终使波的增水、拍岸的浪的节拍、而沿岸的流可计算。沃尔特·蒙克与大卫·卡特赖特在 1966 年发表了"潮汐的波谱学与预测"、用一个响应的函数替换了调和的外推、而使潮汐的预测成为统计的一个问题。从海卫一号开始的卫星的高度计迫使潮汐在全球被求解、而加里·埃格伯特、理查德·雷、而卡尔·武恩施在 1990–2000 年代建造了数据同化的 TPXO 与 GOT 的模型、它们如今携带地球上的每一个高度计、重力仪、而潮仪的潮汐的修正。埃里克·昆策、吉姆·波尔津、格雷格·法伊林、埃米·沃特豪斯、而同事在 2006 年显示内潮从全球的地形辐射、而耗散约一个太瓦、闭合了月对一个海山的拉与运行输送带的深海的混合之间的环。
:::

## 通向何处

生成波的**风**是[[oceanography/air-sea-fluxes]]与[[meteorology/winds]]、波还给空气的**应力**是[[oceanography/wind-driven]]的**查诺克**的关系、内潮供给的**混合**运行[[oceanography/overturning]]与[[oceanography/seawater]]、共享浅水的方程的**海啸**是[[natural-hazards/tsunamis]]、**风暴潮**是[[natural-hazards/storms]]与[[hydrology/floods-droughts]]、波建造的**海岸**是[[geomorphology/coasts]]、潮在其上骑的**海平面**是[[oceanography/sea-level]]与[[climate-change/sea-level-rise]]、潮汐弯曲的**冰的架**是[[glaciology/ice-shelves]]、阻尼涌浪的**海冰**是[[glaciology/sea-ice]]、测量全部的**卫星**是[[remote-sensing/radar-lidar]]、而混合温跃层的**内波**属于[[oceanography/wind-driven]]。

::: quiz
一个远方的风暴生成一个宽的波的谱。为什么几天后到达的涌浪有一个单一的、长的周期？
- [ ] 因为短的波被生成得不那么强。
- [x] 因为深水的波的速度随周期增加、所以长的分量先到达、而被拉伸在其余的前面。
- [ ] 因为风选一个周期。
- [ ] 因为短的波在表面破碎。
::: solution
在深水中 $c_g = gT/(4\pi)$、所以周期按行进的时间分类。在几天的行进之后最短的分量仍在穿过盆地、而局部的谱是一个窄的带、它的周期宣布它的距离与它的风暴的年龄。
:::
:::

::: summary
- 深水的波遵守 $\omega^2 = gk$；它们的速度只依赖于周期、它们的群的速度是它们的相的速度的一半、而它们的能量的通量是每一米约 $H_s^2 T$ 千瓦。
- 波靠菲利普斯的共振的压力与迈尔斯的临界的层的不稳定生长、在 $H_s = 0.025\,U_{10}^2$ 饱和、而在浅水中在 $H/h \approx 0.78$ 破碎。
- 折射、变浅、而破碎都是在浅水中 $c = \sqrt{gh}$ 的后果、这就是为什么海岸由测深学、不是天气治理。
- 平衡的潮只有 0.5 m；15 m 的范围存在、因为盆地共振、而每一个潮汐的表是无潮的系统的图。
- 潮汐的摩擦耗散 3.5 TW、把日每一世纪加长 2.3 ms、驱动河口的混合、而辐射混合深海的内的潮。
- 风暴潮是一个压力的与风的增水、不是一个波、而它的危险是它与高潮相关。
- 线性的理论优秀直到破碎、爬高、而漫顶、在那里只剩统计与实验室的实验。
:::

## 练习题

::: exercise 深水的速度 {level=1 check="18.7"}
求深水中的一个 **12-s** 的涌浪的相的速度。
::: solution
$c = gT/2\pi = 1.56\times12 = 18.7\ \mathrm{m\,s^{-1}} = 67\ \mathrm{km\,h^{-1}}$。一个 12 秒的涌浪比大多数的海岸的交通走得快——这就是为什么涌浪在制造它的风暴之前到达、而冲浪的预报者对任何一个局部的风速计没有见过的能量有几天警告的原因。
:::
:::

::: exercise 浅水的速度 {level=1 check="17.2"}
求在 **30 m** 的水中的一个长的波的速度、而说说当深度降到 **3 m** 时它发生什么。
::: solution
$c = \sqrt{gh} = \sqrt{9.81\times30} = 17.2\ \mathrm{m\,s^{-1}}$、降到 $\sqrt{9.81\times3} = 5.4\ \mathrm{m\,s^{-1}}$。三倍的减慢是把波峰折射到与岸平行、把能量集中在岬角、而使每一米的海岸线的波的能量通量在一个等深线周围非常均匀的东西。
:::
:::

::: exercise 破浪 {level=1 check="7.8"}
求能在一个 **10 m** 的水中的一个沙坝上存在的最大的波高。
::: solution
$H_b = 0.78\times10 = 7.8\ \mathrm{m}$。任何一个更大的波破碎——这就是为什么世界上最大的冲浪（纳扎雷、 jaws、而纳扎雷的涌浪）需要近岸的深的水、而一个沙坝的深度、不是风暴的大小、设定到达一个海滩的波的上限的原因。
:::
:::

::: exercise 波的功率 {level=2 check="39"}
求一个 $H_s = 2\ \mathrm{m}$、$T = 10\ \mathrm{s}$ 的涌浪的能量的通量。
::: solution
$P = \rho g^{2}H_s^{2}T/(32\pi) = 39\ \mathrm{kW\,m^{-1}}$。一个 50-km 的前线接收 2 GW。波的的能量不是一个主要的电源的原因不是密度——它比一个风的农场的每单位的面积高——而是在年的能量穿过它的十倍的风暴中存活的代价。
:::
:::

::: exercise 海啸的跨越 {level=2 check="14"}
一个海啸要花多久穿过 10,000 km 的 4000-m 深的太平洋？
::: solution
$c = \sqrt{9.81\times4000} = 198\ \mathrm{m\,s^{-1}} = 713\ \mathrm{km\,h^{-1}}$、所以 $t = 14\ \mathrm{h}$。一个智利的或日本的海啸在十小时之内到达夏威夷、而美国的西海岸在二十小时、那是太平洋的海啸的警告的中心的全部的预算、而深海的浮标的台网（深海评估与报告海啸的台网）值得它们的代价的原因：它们在几分钟中探测波、而在海岸必须行动之前确认或取消一个警告。
:::
:::

::: exercise 格林定律 {level=2 check="3.8"}
一个在 **4000 m** 的水中的 **1 m** 的振幅的海啸接近海岸。求它在 **20 m** 的深度的振幅。
::: solution
格林定律给 $\eta \propto h^{-1/4}$、所以 $\eta = (4000/20)^{1/4} = 3.8\ \mathrm{m}$。观察到的爬高大得多、因为格林定律假定没有摩擦、没有折射、没有陆架的共振、而没有非线性——而因为最后的几米涉及波在一个倾斜的海滩上破碎、它把前锋再陡两到五倍的因子。
:::
:::

::: exercise 风暴潮 {level=3 check="68"}
一个飓风的中心的压力对着一个 **1013 hPa** 的背景是 **945 hPa**。求倒气压计的上升、而解释为什么真正的风暴潮大三倍。
::: solution
倒气压计的响应是每 hPa 1 cm、给出 $68\ \mathrm{hPa}\times1\ \mathrm{cm} = 68\ \mathrm{cm}$。真正的风暴潮达到 2–3 m、因为风的应力在陆架上驱动一个稳定的增水、$S \sim \tau L/(\rho g h)$：以 $\tau = 0.5\ \mathrm{N\,m^{-2}}$、$L = 100\ \mathrm{km}$、而 $h = 20\ \mathrm{m}$、$S = 0.5\times10^{5}/(1025\times9.81\times20) = 0.25\ \mathrm{m}$ 每尺度、而变浅的陆架、吹程长的风暴的路径、而沿岸的流使它乘倍。1953 的北海的洪水与卡特里娜飓风都是大潮的风暴潮；倒气压计是可预测的部分、而风的增水是致命的部分。
:::
:::

::: exercise 河口的共振 {level=3 check="73"}
一个 **300 km** 长的河口要在 **12.42 h** 的 **M₂** 的周期作为一个四分之一的波长共振。求所需的均的深度。
::: solution
$\lambda = 4\times300 = 1200\ \mathrm{km}$、所以 $c = \lambda/T = 1.2\times10^{6}/44{,}713 = 26.8\ \mathrm{m\,s^{-1}}$、而 $h = c^{2}/g = 73\ \mathrm{m}$。芬迪湾约 240 km 长、有一个约 60 m 的均的深度、给出一个约 11 h 的自然的周期对着 12.42 h 的强迫——足够近以一个十倍的放大、而它的范围是 16 m 的原因。计算也解释了地中海的小的潮：它的自然的周期是几小时到一天、它的槛窄、而它在 M₂ 也不在 K₁ 共振。
:::
:::
