全球的均的海平面自 1900 年上升了二十厘米、如今以 $3.7\ \mathrm{mm\,yr^{-1}}$ 上升、二十世纪初的速率的两倍半、而一个 $0.09\ \mathrm{mm\,yr^{-2}}$ 的加速度。预算的没有一个项是一个谜、而没有一个被确定：我们能从轨道上把格陵兰的融化称重到五%、用 $4000$ 个漂流的剖面的浮标测量整个的上层的海洋的增暖、而仍在 2100 年将有多少海平面上不一致两倍的因子。不确定不在物理。它在南极。

## 预算

::: definition 海平面是什么、而什么改变它 {#def-budget}
海平面不是一个表面、是一个参考。大地水准面是地球的重力的场的等位的面；均的海的表面永久地偏离它 $\pm 80\ \mathrm{m}$（静的地形、由于深的海洋的密度的差）、加上 $\pm 1\ \mathrm{m}$ 的动力的变率。海平面的上升意味着海的表面相对于大地水准面的高度的一个变化、围绕地球的质心测量——"地心的"或"绝对的"海平面、那是对海岸要紧的、而卫星测量的东西。

预算有四个独立的项：
$$
\frac{\mathrm{d}\mathrm{GMSL}}{\mathrm{d}t} = \underbrace{\frac{1}{\rho_0 A}\frac{\mathrm{d}M_{\mathrm{ocean}}}{\mathrm{d}t}}_{\text{barystatic: mass}} + \underbrace{\int \alpha\,\frac{\partial T}{\partial t}\,\mathrm{d}z}_{\text{steric: volume}} - \underbrace{\frac{\mathrm{d}V_{\mathrm{basin}}}{\mathrm{d}t}}_{\text{basin capacity: GIA, sediment}} + \underbrace{\text{fingerprint terms}}_{\text{gravity, rotation, deformation}}
$$

质量的海平面的上升是加进海洋的水：冰川与冰的帽（$0.74\ \mathrm{mm\,yr^{-1}}$、2006–2018）、格陵兰（$0.69$）、南极（$0.38$）、陆地的水的储存（$0.39$、主要是地下水的耗竭与水库的蓄积）。比容的上升是膨胀的水：热的（$0.84$）、来自增暖、而盐度的（$0.10$）、来自变淡。AR6 的 2006–2018 的观察到的分量的和是 $3.7\ \mathrm{mm\,yr^{-1}}$、与高度计符合在 $0.2$ 之内、那是使整个的大厦可信的闭合。

值得记住的换算的因子：一毫米的全球的均的海平面是 $361\ \mathrm{Gt}$ 的水；格陵兰的冰的盖持有 $7.4\ \mathrm{m}$、南极的冰的盖 $58\ \mathrm{m}$、单是西南极 $3.2\ \mathrm{m}$、全部的冰川 $0.4\ \mathrm{m}$；把整个的海洋增暖 $1\ \mathrm{^\circ C}$ 会给约 $60\ \mathrm{cm}$。

区域的格局不是全球的均值、而差不是噪声。融化一个冰的盖在局部改变三件事：它自己对其围的海洋的重力的吸引落下、所以海平面在融化的冰附近下降、而在远处上升；固体的地球回弹而倾斜；而融的水的淡水与改变的自转重新分配海洋。结果是一个海平面的"特征"：格陵兰的融水把美国的东海岸抬高全球的均的三到四倍、而在南大洋降低、而南极的融水做相反的。这不是一个修正；它是区域的尺度上主导的信号、而这就是"海平面的上升"是正在发生的东西的一个不好的名字的原因。
:::

::: definition 测量海平面、而记录说什么 {#def-measure}
三个仪器、三个时间尺度、三个系统性的误差。

验潮仪对着陆地上的一个基准测量相对的海平面。最长的记录——布列斯特、阿姆斯特丹、加来、纽约、伦杜阿瓦尔——运行 $150$ 年、而它们的价值对极值、对二十世纪、而对卫星看不到的海岸是无与伦比的。它们的问题是陆地移动：冰期的均衡的调整在哈得孙湾与斯堪的纳维亚以 $5$–$12\ \mathrm{mm\,yr^{-1}}$ 卸载、沉积的压实与地下水的抽取使三角洲的海岸以 $5$–$30\ \mathrm{mm\,yr^{-1}}$ 沉降、而潮仪不能把两者分开。从潮仪的全球的均的海平面需要一个 $\pm 0.3\ \mathrm{mm\,yr^{-1}}$ 的不确定的空间的重组、而一个 $+0.7\ \mathrm{mm\,yr^{-1}}$ 的冰川均衡的调整的修正。

从 TOPEX/Poseidon（1992–2002）、Jason-1、OSTM/Jason-2、Jason-3、而哨兵六号迈克尔·弗赖利奇（2020–）的卫星的雷达的高度计在一个 10 天的重复的轨道上把到海的表面的距离测量到几厘米、而在修正电离层、湿的对流层、海的状态、潮、而极的运动之后、给出每年 $\pm 0.4\ \mathrm{mm}$ 的全球的均。1993–2023 的趋向是 $3.4\ \mathrm{mm\,yr^{-1}}$、而一个 $0.09\ \mathrm{mm\,yr^{-2}}$ 的加速度；最大的单一个风险不是噪声、是各个任务之间的相互的标定、而两颗卫星之间的一个 $0.4\ \mathrm{mm\,yr^{-1}}$ 的偏差与被测量的加速度一样大。

阿尔戈、自 2000 年采样到 $2000\ \mathrm{m}$ 的约 $4000$ 个剖面的浮标、直接测量比容的高度、而解决了老的"闭合的问题"：上层的海洋的比容的上升是 $1.4\ \mathrm{mm\,yr^{-1}}$、在 $2000\ \mathrm{m}$ 之下的深的海洋加上约 $0.3$、而由 GRACE 与 GRACE-FO 的重力的卫星、而由冰的盖的差分的全球导航卫星系统测量的质量项使平衡闭合。剩余的开放项是在阿尔戈的深度之下的深的海洋的增暖、在它的重复的剖面显示一个把约 $0.5$–$1.0\ \mathrm{W\,m^{-2}}$ 加到地球的能量不平衡的估计的增暖。

古的与地质的记录框住了未来。在上次的消冰期、海平面在 $18{,}000$ 年中上升了 $120\ \mathrm{m}$、被每一几个世纪 $14$–$20\ \mathrm{m}$ 的融的水的脉冲打断——每一世纪的几米在物理上是可能的唯一的直接的证据、而 2100 的范围的上端不是零的原因。最后的一次间冰期、$125{,}000$ 年之前、在比前工业高 $1$–$2\ \mathrm{^\circ C}$ 的全球的均的温度、高了 $6$–$9\ \mathrm{m}$；中期的上新世、$300$ 万年之前、在 $2$–$3\ \mathrm{^\circ C}$、高了 $3$–$24\ \mathrm{m}$。两者都在任何一个二十一世纪的预测之上、而两者在几千年、不是几十年中达到。
:::

::: definition 预测、冰的盖的不稳定、而海岸 {#def-future}
预测来自两个家族、而它们之间的差就是全部的政策的问题。基于过程的家族把观察到的分量加起来、每一个从它自己的物理外推：政府间气候变化专门委员会第六次评估报告给 SSP1-2.6 的 $0.38$–$0.67\ \mathrm{m}$、而 SSP5-8.5 的 $0.63$–$1.01\ \mathrm{m}$、到 2100 年、而上尾的低置信度、因为海洋的冰的盖的不稳定"没有被很好地抓住"。专家的征询与冰的盖的模型的家族为南极的海洋的冰的崖的不稳定加上一个结构的项、而给到 $2\ \mathrm{m}$ 为高的排放的、高的不确定的情景。两者都是可辩护的；争论是关于一个比约 $250\ \mathrm{m}$ 高的崖能否在一个世纪的时间尺度上失效、那是一个观测的记录尚未回答的断裂的力学的问题。

两个机制使南极与格陵兰不同。海洋的冰的盖的不稳定（MISI）适用于底向内陆向下倾斜之处、所以撤退把接地的线放在更深的、那在那里加厚冰、那增加排放、那把线更撤退的水中——一个无条件的正的反馈、没有平衡。持有 $3.2\ \mathrm{m}$ 的西南极的冰的盖、完全是这一类的、而单是思韦茨与松树岛冰川持有 $0.65\ \mathrm{m}$、而以 $1$–$2\ \mathrm{m\,yr^{-1}}$ 变薄。海洋的冰的崖的不稳定（MICI）更推测：如果一个撤退的冰川失去它的冰的架、暴露的崖在超过约 $250$–$300\ \mathrm{m}$ 之后可能在自己的重量之下失效、而模型的南极的贡献在 2100 年跳约 $1\ \mathrm{m}$。没有现代的观测的海洋的冰的崖的不稳定的例子；在上新世与在上次的间冰期有它的地貌的证据。

在海岸、灾害不是均的水平、是尾。极的水位超过它们的长期的均、以一个随均的海平面近指数地增长的频率、
$$
\frac{N(h_0 + \Delta h)}{N(h_0)} \approx \exp\!\left(\frac{\Delta h}{x_0}\right), \qquad x_0 \approx 0.1\text{–}0.2\ \mathrm{m},
$$
所以 $0.5\ \mathrm{m}$ 的上升使如今百年的洪水在大多数低洼的海岸成为一个年的、而美国的大西洋与墨西哥湾的海岸的"讨厌的"或"潮的"洪水自 1960 年翻了三倍。加上其他的后果——许多的三角洲的与环礁的海岸的 $0.2$–$0.4$ 的永久的淹没、咸的水进海岸的含水层与稻田的入侵、在沉积的供给不能跟上之处盐的沼泽与红树林的淹死、而在新的高潮之上不能重力排水的废水与雨水的排水的失效——而一个给定的上升的代价由高程、沉降、而收入设定、不是由上升自己。住在预期的 2100 的高潮的线之下的人口是 $0.6$–$12$ 亿、其中绝大多数在恒河–布拉马普特拉、湄公、尼罗、长江、珠江、而昭披耶河的三角洲与雅加达——同一个地下水抽取使陆地以海洋上升的三倍快下沉的地方。
:::
::: example 从海洋的增暖的比容的上升 {#ex-steric}
如果海洋的上部的 **$700\ \mathrm{m}$** 以一个 $2.1\times10^{-4}\ \mathrm{K^{-1}}$ 的热膨胀的系数增暖 **$0.5\ \mathrm{^\circ C}$**、求全球的均的比容的上升。观察到的 $1.4\ \mathrm{mm\,yr^{-1}}$ 的上层的海洋的比容的上升意味着什么增暖的速率？
::: solution
$$
\Delta h = \alpha\,\Delta T\,H = 2.1\times10^{-4}\times0.5\times700 = 0.074\ \mathrm{m} = 74\ \mathrm{mm}.
$$
反演、$1.4\ \mathrm{mm\,yr^{-1}}$ 在 $700\ \mathrm{m}$ 上相当于
$$
\frac{\partial T}{\partial t} = \frac{1.4\times10^{-3}}{2.1\times10^{-4}\times700} = 0.010\ \mathrm{^\circ C\,yr^{-1}} .
$$
一年的一度的百分之一、在世界海洋的七百米的平均、是所有海平面的上升的三分之一。

要抓住的数字是比：海洋吸收了全球增暖的多余的热约九成、而使它成为这个行星的缓冲的同一个热使它成为海平面的上升的最大的单一个的贡献者。$0.01\ \mathrm{^\circ C\,yr^{-1}}$ 的速率对船上的任何一个仪器是无法察觉的、而在一个千年上是不可逆的：即使排放今天停止、单是热的项也会持续几个世纪、当热向下混合。

盐度的项部分地抵消它。海洋在高降雨的与融化的区域的表面变淡、而淡水不那么密、所以变淡也抬高海平面——两者不是对立的。部分抵消热的上升的是蒸发的副热带加的盐、而净的盐度的贡献只是 $0.1\ \mathrm{mm\,yr^{-1}}$、小而不是零、而足够区域的、所以盐度的场必须被测量、不是被推断。
:::
:::

::: example 从冰的质量到海平面 {#ex-barystatic}
GRACE 测量格陵兰的冰的盖失去 $270\ \mathrm{Gt\,yr^{-1}}$。求全球的均的海平面的贡献、而在这个速率下在一个世纪中将被释放的它的总的海平面的等价的分数。
::: solution
一毫米的全球的均的海平面是
$$
3.61\times10^{14}\ \mathrm{m^{2}}\times10^{-3}\ \mathrm{m}\times10^{3}\ \mathrm{kg\,m^{-3}} = 3.61\times10^{14}\ \mathrm{kg} = 361\ \mathrm{Gt},
$$
所以贡献是 $270/361 = 0.75\ \mathrm{mm\,yr^{-1}}$。在这个速率下一个世纪、$7400\ \mathrm{mm}$ 的等价的 $75\ \mathrm{mm}$、或一%。

两个数字一起是全部的政策的问题。格陵兰失去一个在任何人类的框架中不可想象的冰的量——一年两千七百亿吨、世界全部的注入海的河的体积的十倍——而它把海平面抬高不到一毫米。在那个速率下整个的冰的盖将需要一万年融化。速率不是最坏的情形；速率是基线、而问题是导数。

同样的算术应用到南极更有后果：$150\ \mathrm{Gt\,yr^{-1}}$ 只是 $0.4\ \mathrm{mm\,yr^{-1}}$、而西南极持有 $3200\ \mathrm{mm}$、所以南极的速率的十倍的增加是一个大陆的 $4\ \mathrm{mm\,yr^{-1}}$——比如今整个的全球的上升多。这就是每一个严肃的海平面的预测最终是一个单一的数字的预测的原因：一小撮南极的出口的冰川的接地的线的行为。
:::
:::
::: example 修正一个潮仪 {#ex-tidegauge}
一个三角洲上的一个潮仪记录一个 $4.5\ \mathrm{mm\,yr^{-1}}$ 的相对的海平面的上升。在潮仪的基准上的连续的全球导航卫星系统显示陆地下沉在 $2.5\ \mathrm{mm\,yr^{-1}}$、而冰川均衡的调整贡献进一步的 $0.3\ \mathrm{mm\,yr^{-1}}$ 的沉降。求全球的海平面的上升、而一个居民经历的速率。
::: solution
全球的（地心的、气候驱动的）的分量是
$$
4.5 - 2.5 - 0.3 = 1.7\ \mathrm{mm\,yr^{-1}} .
$$
居民经历全部的 $4.5\ \mathrm{mm\,yr^{-1}}$——全球的均的两倍半。

这是海平面的上升的中心的不义。沉降不是地质的坏的运气、是地下水与碳氢的抽取、而一个坝在上游截住的沉积：雅加达、曼谷、胡志明市、新奥尔良、威尼斯、天津、而上海都在比海洋上升更快地沉降、而都在每一米的高程上的人最多的海岸上。雅加达为此补贴了它的资本的迁移。

方法的一点同样重要。一个潮仪单独不能区分一个上升的海与一个下沉的岸、这就是全球的潮仪的网络如今与连续的全球导航卫星系统同址、而卫星的高度计对陆地的运动免疫、而对海岸盲、而两者必须与一个地球的黏度的参数本身在被冰川覆盖过过的区域在 $\pm 0.3\ \mathrm{mm\,yr^{-1}}$ 的水平上不确定的冰川均衡的调整的模型结合的原因。
:::
:::

::: example 一个百年的洪水如何变成一个年 {#ex-flood}
在一个海岸水位的超过的频率跟着 $N(h) \propto \exp(h/x_0)$、以 $x_0 = 0.15\ \mathrm{m}$。如今百年的极值的频率随 $0.5\ \mathrm{m}$ 的海平面的上升增加多少因子、而它的新的复现期是什么？
::: solution
$$
\frac{N(h_0 + 0.5)}{N(h_0)} = \exp\!\left(\frac{0.5}{0.15}\right) = e^{3.33} = 28 .
$$
一个百年的事件变成一个三年半的事件。在 $1.0\ \mathrm{m}$ 因子是 $e^{6.67} = 790$、而百年的洪水十年来十次。

结果看起来太整齐、不真、而告诫要紧。指数的形式只在静的水位的分布是指数的之处成立、它在大多数的潮控制的海岸上在大潮的范围之上是这样、而在浪主导之处不是。参数 $x_0$ 是被测量的、不是被假定的、而范围从微潮的地中海的 $0.05\ \mathrm{m}$ 到宏潮的布里斯托尔海峡的 $0.35\ \mathrm{m}$。而风暴的气候可能随同样的强迫移动、那能增加或减少频率、与均的水平无关。

尽管如此观察已经在记录中：美国的大西洋与墨西哥湾的海岸的讨厌的洪水自 1960 年翻了三倍、自 2010 年翻了两倍、而时机与空间的格局与均的水平的解释、不是风暴的频率的任何变化、相符。这是气候的科学中一个均的小的变化产生一个尾的大的变化的最干净的演示——而海平面的政策是关于几厘米、不是几米的原因。
:::

约翰·本尼迪克特·李斯特在 1872 年创造了"大地水准面"这个词、给了这个学科它的第一个本质的区分：海平面是一个重力的面、不是一个形状。在利物浦的平均的海平面的常设的服务自 1933 年收集了潮仪的月的均值、而网络的最老的连续的记录、自 1873 年的布列斯特、自 1878 年的阿姆斯特丹、是每一个二十世纪的重组的基础。理查德·费尔班克斯在 1989 年从珊瑚的 $\delta^{18}\mathrm{O}$ 与钍的年龄读出了上次的消冰期、而揭示了融的水的脉冲——几个世纪中四到二十米的台阶——彼得·克拉克与同事后来定年而归于南极与劳伦泰德的冰的盖的崩溃。杰里·米特罗维察自 1990 年代发展了海平面的特征的重力的一致理论、显示融化一个冰的盖在它旁边降低海平面、而在行星的远侧抬高它。卫星的雷达的高度计从 GEOSAT 与 SEASAT 开始、在 1992 年成为 TOPEX/Poseidon 的一个气候的记录、而由安妮·卡兹纳夫、史蒂夫·内雷姆、乔舒亚·威利斯、而法国国家空间研究中心与水文地理联合服务中心、美国国家海洋大气局、而美国国家航空航天局的在六个连续的卫星上维护记录的团队变成一个可用的全球的均。约翰·丘奇与尼尔·怀特在 2011 年从残余的潮仪的数据重组了二十世纪的全球的均、闭合了卫星之前的世纪的预算、而威利斯、迪恩·勒姆与同事在 2008 年用阿尔戈与 GRACE 闭合了卫星时代的预算。斯特凡·拉姆斯托夫在 2007 年建造了第一个半经验的预测、罗伯特·科普、乔纳森·班伯、而迈克尔·奥本海默在 2008–2013 引入了概率的与专家的征询的预测、詹姆斯·汉森自 2008 年从上新世与上次的间冰期为几米的承诺论证、而本杰明·施特劳斯与气候中心的团队测绘了暴露于高潮的线的人口、它把美国的暴露向上修正三倍的因子。冰的盖的质量的平衡的相互比较的演习、由安德鲁·谢泼德与伊莎贝拉·韦利科尼亚在 2012 年召集、而自那重复了四次、迫使冰川的与卫星的社区为每个冰的盖一个数字、而现代的海平面的预算完全闭合的原因。
:::
::: warning 均值被测量得很好、图不是、未来不是、而局部的数字是唯一要紧的一个
七个告诫。全球的均的海平面是气候的科学中确定得最好的量、而对任何一个特别的海岸最没用的。全球的均值被知道到 $\pm 0.4\ \mathrm{mm\,yr^{-1}}$；在一个给的潮仪的趋向被知道到 $\pm 1\ \mathrm{mm\,yr^{-1}}$ 或更差、在冰川均衡的调整之后、而那个潮仪在 2100 的预测跨 $0.5\ \mathrm{m}$。卫星的记录不是一条记录。六个有不同的轨道、不同的延迟的标定、而不同的回收的任务必须在海的周期上相互的标定、而其中两个之间的一个 $0.4\ \mathrm{mm\,yr^{-1}}$ 的偏差与记录被用来检测的加速度一样大；出版的加速度依赖于 Jason-1 到 OSTM 的过渡被如何处理而差两倍的因子。阿尔戈看不到深的海洋、边界的流、或极。浮标剖面到 $2000\ \mathrm{m}$、在 $70\ \mathrm{^\circ N}$ 之北、在海冰之下、而在陆架上不存在、而未测量的深的与极的比容的项是预算中最大的残余。GRACE 不能在小尺度上把冰的质量与水的储存与冰川均衡的调整分开。质量块的解在陆地与海洋之间泄漏信号、而南极的趋向带着与趋向本身相当的冰川均衡的调整的不确定。潮仪的记录是空间的混叠的。三分之二的海岸线没有比二十年更长的记录、长的记录聚集在西北欧与北美、而从潮仪的全球的均值依赖于用来填补没有人测量的海洋的空间的插值。预测不是我们有的冰的盖的预测。每一个模型都对着一个在 2002 年之后没有以观察到的速率失去海洋的基的冰的二十世纪的南极评估、而没有模型再现过一个融的水的脉冲。而决定一个海岸线的数字不是全球的均值。它是局部的高潮、局部的沉降、局部的风暴的气候、局部的沉积的供给、而局部的建一个东西的能力——而那五个之中、只有第一个在任何带预测的名字的模型里。
:::

## 通向何处

比容的项来自[[oceanography/seawater]]的密度的物理、而[[oceanography/air-sea-fluxes]]的热吸收、区域地重新分配海平面的环流是[[oceanography/wind-driven]]与[[oceanography/overturning]]、冰的盖的质量的平衡是[[glaciology/ice-sheets]]与[[glaciology/mass-balance]]、接地的线与冰的架的物理是[[glaciology/ice-shelves]]与[[glaciology/basal-sliding]]、均衡的调整是[[geophysics/flexure]]与[[geophysics/heat-flow]]、高度计是[[remote-sensing/radar-lidar]]与[[remote-sensing/sensors-orbits]]、海岸的响应是[[geomorphology/coasts]]、极值是[[natural-hazards/storms]]与[[climate-change/extremes]]、预测与影响是[[climate-change/sea-level-rise]]与[[climate-change/impacts]]、古的高的水位在[[palaeoclimate/holocene]]、[[palaeoclimate/last-two-millennia]]与[[palaeoclimate/deep-time]]、而驱动全部的能量不平衡是[[climate-system/energy-budget]]与[[climate-system/forcing]]。

::: quiz
为什么格陵兰的冰的盖的融化在美国的东海岸比在均值上抬高海平面更多？
- [ ] 因为格陵兰的融的水沿着西边界流流动。
- [x] 因为失去格陵兰的质量减少它对附近的海洋的重力的吸引、所以水从它迁移开——沿着大地水准面——抬高远处的海岸、而降低近场。
- [ ] 因为东海岸在因湾流的增暖沉降。
- [ ] 因为格陵兰的融水增暖了北大西洋。
::: solution
一个融化的冰的盖对其围的海洋拉得少。水移动开、固体的地球回弹而倾斜、而结果是一个空间的特征：在融化的附近海平面下降、而在远处它上升全球的均的三到四倍。美国的东海岸坐在格陵兰的特征的远场的极大上。
:::
:::

::: summary
- 全球的均的海平面自 1900 年上升了约 20 厘米、而以 3.7 mm yr⁻¹ 上升、以一个约 0.01 mm yr⁻² 的加速度。
- 预算闭合：比容 1.5、冰川 0.74、格陵兰 0.69、南极 0.38、陆地的水 0.39 mm yr⁻¹、与高度计相符。
- 一毫米的海平面是 361 Gt 的水；格陵兰持有 7.4 m、而南极的冰的盖 58 m 的等价。
- 海平面的上升不是均匀的：重力的、自转的、而变形的的特征使它在一个离融化的冰远的海岸上是全球的均的二到四倍。
- 潮仪测量相对的变化、而必须为均衡的调整、而为人为的沉降修正、在三角洲的海岸上后者超过海洋的上升几倍。
- 极的洪水的频率随均的海平面大致指数地增长、所以最初的分米比随后的几米代价更大。
- 未决的项是海洋的冰的盖的不稳定；它是否在本世纪运行是一个观测尚未回答的断裂的力学的问题。
:::

## 练习题

::: exercise 冰川到毫米 {level=1 check="0.15"}
山的冰川失去 $55\ \mathrm{Gt\,yr^{-1}}$。求它们的海平面的贡献。
::: solution
$55/361 = 0.15\ \mathrm{mm\,yr^{-1}}$。五十五吉吨——每二十年二十个五大湖的冰——是毫米的六分之一、而世界的冰川仍是海洋自己的膨胀之后海平面的上升的第二大的单一个的贡献者。
:::
:::

::: exercise 比容的上升 {level=1 check="63"}
如果海洋的顶部 **1000 m** 增暖 $0.3\ \mathrm{^\circ C}$（$\alpha = 2.1\times10^{-4}\ \mathrm{K^{-1}}$），求比容的上升。
::: solution
$\Delta h = 2.1\times10^{-4}\times0.3\times1000 = 0.063\ \mathrm{m} = 63\ \mathrm{mm}$。三分之一个分米来自散布在整个的上层的海洋上的三分之一个度——这就是海洋的热的内容、不是表面的温度、是已经被承诺的增暖多么多的诚实的测量的原因。
:::
:::

::: exercise 暗示的增暖 {level=2 check="0.01"}
观察到的上层的海洋的比容的上升在 $700\ \mathrm{m}$ 上是 $1.4\ \mathrm{mm\,yr^{-1}}$。求暗示的增暖的速率。
::: solution
$\partial T/\partial t = 1.4\times10^{-3}/(2.1\times10^{-4}\times700) = 0.0095 \approx 0.01\ \mathrm{^\circ C\,yr^{-1}}$。一年的一度的百分之一、在七百米的之上、在行星的四分之三之上——而那个无法察觉的数字是所有海平面的上升的三分之一、而上升在任何人类的时间尺度上不能被停止的原因。
:::
:::

::: exercise 修正一个潮仪 {level=2 check="2.3"}
一个三角洲的潮仪记录 $6.2\ \mathrm{mm\,yr^{-1}}$；全球导航卫星系统显示 $3.5\ \mathrm{mm\,yr^{-1}}$ 的人为的沉降、而模型给 $0.4\ \mathrm{mm\,yr^{-1}}$ 的冰川均衡的调整。求全球的海平面的上升。
::: solution
$6.2 - 3.5 - 0.4 = 2.3\ \mathrm{mm\,yr^{-1}}$。气候的信号是被测量的信号的一个三七% 的分数、而居民经历全部的 $6.2$。在这个海岸上停止地下水的抽取比任何一个排放的情景买的更多的时间。
:::
:::

::: exercise 洪水的频率 {level=2 check="20"}
以 $x_0 = 0.20\ \mathrm{m}$、如今的百年的洪水的频率随 $0.6\ \mathrm{m}$ 的海平面的上升增加多少因子？
::: solution
$\exp(0.6/0.20) = e^{3} = 20$——一个五年一次的百年的事件。这是每一个正在被重写的海岸的建筑规范背后的算术、而保险的市场在工程师之前离开佛罗里达、路易斯安那、而北昆士兰的原因。
:::
:::

::: exercise 格陵兰的质量 {level=2 check="2.7"}
格陵兰的冰的盖持有 $7.4\ \mathrm{m}$ 的海平面的等价。求以 $10^{21}\ \mathrm{kg}$ 计它的质量。
::: solution
$7400\ \mathrm{mm}\times361\ \mathrm{Gt\,mm^{-1}} = 2.67\times10^{6}\ \mathrm{Gt} = 2.7\times10^{21}\ \mathrm{kg}$。实际的估计是 $2.7\times10^{21}\ \mathrm{kg}$——换算按构造是精确的、那就是要点：海平面的的等价不是一个模型的输出、是一个单位、而任何一个冰的体积能在关于未来的一个单一的假定之外被换算。
:::
:::

::: exercise 闭合预算 {level=3 check="0.39"}
观察到的上升是 $3.7\ \mathrm{mm\,yr^{-1}}$；比容、冰川、格陵兰、而南极的项是 $1.5$、$0.74$、$0.69$、而 $0.38$。求所需的陆地的水的项。
::: solution
$3.7 - 3.31 = 0.39\ \mathrm{mm\,yr^{-1}}$。残余是正的、意味着水从陆地向海洋移动——地下水的抽取主导、部分被在水库后面储存的水抵消。那 $0.39$ 是环境的科学中最非凡的数字之一：人类的水的抽取如今是所有海平面的上升的一成、与南极的冰的盖相当、而它几乎完全不可逆、因为抽出的地下水不被归还。
:::
:::

::: exercise 一个世纪的上升 {level=3 check="1.7"}
全球的均的海平面在 1900 与 2020 之间上升了 $200\ \mathrm{mm}$。求均的速率、而与 2006–2018 的 $3.7\ \mathrm{mm\,yr^{-1}}$ 的比的比。
::: solution
$200/120 = 1.7\ \mathrm{mm\,yr^{-1}}$、而 $3.7/1.7 = 2.2$。速率在一个世纪中翻了一倍多。比是支持非线性的全部论证、而反对把 1900–2020 的均值外推到 2100 的全部论证：一个从二十世纪的线性的预测给 2100 的 $17\ \mathrm{cm}$、比只在过去十五年中已经发生的不到一半、而对着每一个基于过程的预测错四倍。
:::
