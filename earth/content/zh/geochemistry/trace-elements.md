一个痕量元素是一个以少于约 0.1–0.3 个百分点存在的元素，它意味着它太稀了、不能形成它自己的矿物，而因此必须生活在别的矿物的晶体结构里。那一个约束使痕量的元素是一个的岩石的最有信息的成分：因为它们进入别人的晶格，它们记录着那些晶格的身份，而因为它们稀，它们不被它们自己的相缓冲，而因此对岩石经历过的每一个熔体、每一个流体、每一个变质的反应反应着。岩石学家关于地幔的来源、壳的混染、岩浆的房、而早期的地球的化学所知道的几乎一切来自三十个左右的元素的几个百万分之一。

## 分配

::: definition 分配的系数 {#def-partition}
对一个在一个晶体里以低的浓度替代着一个主要的元素 $M$ 的痕量的元素 $X$，**能斯特的分配的定律**采取**亨利定律**的形式
$$
D^{X}_{\text{矿物/熔体}} = \frac{C^{X}_{\text{熔体}}}{C^{X}_{\text{矿物}}}\bigg|_{\text{稀的}} ,
$$
而 $D$ 于是**常数**、独立于痕量的元素自己的浓度。物理的基础是**戈尔德施密特**（戈尔德施密特）的替代的规则：一个离子按它的离子的半径与它的电荷的不匹配的程度进入一个位置，而在低的浓度上一个离子的应变的能不它的邻居的相互作用。两个后果是定量的痕量的元素的岩石学的全部分。第一，**$D$ 是压力的、温度的、熔体的成分的、而矿物的成分的函数**，不是痕量的元素的丰度的——所以在一个大气上在一个干的熔体上测量的一个分配的系数在一个地幔里可能错一个数量级。第二，一个它的离子的半径与电荷匹配着一个主要的位置的元素是**相容的**（$D > 1$：Ni 与 Mg，尖晶石与石榴石里的 Cr 与 Al，斜长石里的 Sr），而一个它的半径太大、或它的电荷错的元素是**不相容的**（$D \ll 1$：Rb、Ba、Th、U、K，轻的稀土，Nb，Ta）。一个岩石的**体的分配的系数**是模式的平均，
$$
D_{\text{体}} = \sum_i X_i\,D_i ,
$$
对带着模式的比例的 $i$ 的相求和，而控制着熔体的化学的是 $D_{\text{体}}$、不是任何一个矿物的 $D_i$。
:::

::: definition 两个极限的熔融与结晶的模型 {#def-rayleigh}
**瑞利**（瑞利）**的分离的结晶或熔融**——熔体与固体的平衡，接着熔体的完全的移走——给出
$$
\frac{C_L}{C_0} = F^{\,(D-1)},
$$
其中 $F$ 是剩余的液体的分数、而 $C_0$ 是起始的浓度。**批式（平衡的）熔融**——熔融到完成、而熔体与残渣保持在接触里——给出
$$
\frac{C_L}{C_0} = \frac{1}{D + F(1-D)} .
$$
两者在**接近 1 的 $F$ 上无法区分**、而在小的 $F$ 上剧烈地分开：对一个带着 $D = 0.1$ 的元素，一个 0.05 的熔体的分数给出一个瑞利的 **14.8 倍**的富集、而批式的只有 **6.9 倍**，而对一个带着 $D = 2$ 的相容的元素，瑞利的熔体比批式的熔体**亏减二十倍**。这个区分是一个岩石记录着的**过程**的最有力的单一约束：一个带着一个巨大的轻重的分馏的一个强地分馏的轻的稀土的图案要求**接近分离的**行为，而一个适度的与平衡一致。真实的系统在极限之间，而中间的情形——**非模式的批式熔融**，其中一个相随着熔融进行被消耗着——是适合着大多数地幔的数据的那个。
:::

::: example 瑞利对着批式 {#ex-rayleigh}
一个地幔的来源有 $12\ \mathrm{ppm}$ 的锶、一个 $0.15$ 的体的 $D_{\mathrm{Sr}}$、而 $1900\ \mathrm{ppm}$ 的镍、带着 $D_{\mathrm{Ni}} = 12$。在一个熔体的分数 $F = 0.05$ 下、在（a）批式与（b）瑞利的熔融下找出两者的熔体的浓度，而对一个洋中脊的玄武岩对着一个科马提岩解释结果。
::: solution
**锶**（$D = 0.15$，不相容的）：
$$
\text{批式：}\quad \frac{C_L}{C_0} = \frac{1}{0.15 + 0.05\times0.85} = \frac{1}{0.1925} = 5.2, \qquad C_L = 62\ \mathrm{ppm};
$$
$$
\text{瑞利：}\quad \frac{C_L}{C_0} = 0.05^{-0.85} = 12.8, \qquad C_L = 153\ \mathrm{ppm}.
$$
**镍**（$D = 12$，强相容的）：
$$
\text{批式：}\quad \frac{C_L}{C_0} = \frac{1}{12 + 0.05\times(-11)} = \frac{1}{11.45} = 0.087, \qquad C_L = 166\ \mathrm{ppm};
$$
$$
\text{瑞利：}\quad \frac{C_L}{C_0} = 0.05^{11} = 4.9\times10^{-15}, \qquad C_L \approx 0 .
$$
不相容的元素在两个模型里表现**相似**——一个 2.5 的因子——因为在 $F \ll 1$ 上批式的方程接近着 $1/D$、而瑞利接近着 $F^{D-1}$，而两者是大的。相容的元素表现**完全不同**：批式的熔融保存着来源的镍的 9%、而瑞利的熔融毁灭着它。

这是**科马提岩的问题**存在的理由。科马提岩携带着 $1000$–$3000\ \mathrm{ppm}$ 的镁、与几百个 ppm 的镍，它要求一个与一个它的橄榄石有着一个非常高的 $D_{\mathrm{Ni}}$ 的残渣平衡的、或从一个这样的残渣分离的熔体。一个热的太古代的地幔的一个**高的批式的熔体**给出 $500$–$2000\ \mathrm{ppm}$ 的 Ni、而标准的解释。一个**低的分离的熔体**基本上不给出。推论是一个**现代的洋中脊的玄武岩**，带着 $10$–$15$ 百分点的 MgO、$80$–$120\ \mathrm{ppm}$ 的 Ni，是一个亏减的地幔的一个**低的批式的熔体**、而**随后在浅的深度上被橄榄石分馏了**——原始的熔体的高的镍被在上行的路上结晶的橄榄石部分地移走了，而两个数字之间的差异是在下部的壳里累积的橄榄石的量。

一般的教训是**相容的元素是过程的指示剂、而不相容的元素是来源的指示剂**。镍、铬、钴、钪、而铂族的元素记录着橄榄石、尖晶石、石榴石、或硫化物在熔体形成之后看到了多少；铷、锶、稀土、铪、钕、钍、而铀记录着来源的亏减的历史，因为它们的 $D$ 太小，几个百分点的熔融几乎不碰它们。
:::
:::

## 稀土

::: definition 镧系的图案 {#def-ree}
稀土的元素（La–Lu，加上在 Dy 与 Ho 之间插入的 Y）在化学上几乎相同，只在八次配位里从一个 La³⁺（$1.36\ \text{Å}$）到一个 Lu³⁺（$1.03\ \text{Å}$）的离子的半径的稳定地收缩上不同。因为它们的分配的系数随着半径**平滑地而系统地**变化，一个岩石的稀土的图案是**对它的起源的矿物学的一个放大镜**，而它在对着**球粒陨石**（以显示分馏）或对着**原始地幔**（以显示绝对的富集）归一化之后被读。诊断的特征是：**轻的稀土的富集** $(\mathrm{La/Yb})_N$，它在一个石榴石或一个流体被涉及的时候高、而在一个亏减的地幔的熔体里低；**重的稀土的斜率** $(\mathrm{Dy/Yb})_N$，它在**石榴石在残渣里时是平的到轻的亏减**（石榴石保持着重的稀土，在一个 3 GPa 上带着一个 5–10 的 $D_{\mathrm{Yb}}$）、而**只在尖晶石与单斜辉石时是平的或轻的富集**；**铕的异常** $\mathrm{Eu/Eu^*} = \mathrm{Eu_N}/\sqrt{\mathrm{Sm_N\,Gd_N}}$，它在斜长石累积或分馏时是正的（Eu²⁺ 替代着 Ca）、而在斜长石被留在一个来源里或从一个熔体被移走时是负的；而**铈的异常** $\mathrm{Ce/Ce^*} = \mathrm{Ce_N}/\sqrt{\mathrm{La_N\,Pr_N}}$，它是一个**氧化的还原的**特征（Ce⁴⁺ 不溶、而从一个氧化的水被移走）、而是一个不是由火成的矿物学生产的唯一的稀土的异常。**钬–镝的比**是控制的检验：Ho 与 Dy 有着相同的化学、而没有化合价的改变，所以在一个沉积物或一个化学的沉积物里测量的一个 Ho/Dy 的异常证明着**分析的或成岩的**、不是过程相关的行为。
:::

::: example 读一个稀土的图案 {#ex-ree}
两个玄武岩有着以下的球粒陨石归一化的比：玄武岩 A，$(\mathrm{La/Sm})_N = 0.26$、$(\mathrm{Dy/Yb})_N = 1.30$、$\mathrm{Eu/Eu^*} = 1.00$；玄武岩 B，$(\mathrm{La/Sm})_N = 2.4$、$(\mathrm{Dy/Yb})_N = 0.75$、$\mathrm{Eu/Eu^*} = 1.00$。两者有 $\mathrm{Nb/Nb^*} = 1.0$、$\mathrm{Th/La} = 0.3$。解释来源与熔融。
::: solution
**玄武岩 A** 有一个**轻的稀土亏减的、重的稀土富集的**图案：$(\mathrm{La/Sm})_N = 0.26$ 是一个强地分馏的亏减、而 $(\mathrm{Dy/Yb})_N = 1.30$ 说**重的稀土对着中间的被压低**，它是**残渣里的石榴石**的诊断的签名。平的铕与一个铌或钍的异常的缺失说**没有斜长石的累积，没有壳的混染、没有俯冲的分量**。这是一个正常的**洋中脊的玄武岩**，来自一个**石榴石亏减的尖晶石–石榴石过渡**的来源，而轻的稀土的亏减测量着从来源的**先前的熔体的抽取的程度**、不是制造了这个玄武岩的熔融。

**玄武岩 B** 在重的稀土里有着相反的斜率：$(\mathrm{Dy/Yb})_N = 0.75$ 意味着**重的稀土对着中稀土富集**，它是一个它的残渣里**没有石榴石**的签名——石榴石是唯一的分配的系数在重的稀土上陡地上升的常见的相，所以它的缺失使图案的重的一端不分馏或倒置。与 $(\mathrm{La/Sm})_N = 2.4$——一个适度地富集的轻的稀土的图案——与一个俯冲的签名的缺失结合，这是一个**板内或大陆板内的玄武岩**，来自一个**在浅的深度与低的熔体的分数上的适度地富集的尖晶石–二辉橄榄岩的来源**，一个欧洲的第三纪的火山场的玄武岩或一个海洋的岛屿的系列的浅的、富集的分量的经典的化学。

**定量的**读着从重的稀土来。镱在一个石榴石里有着 $D_{\mathrm{Yb}} \approx 8$、在一个单斜辉石里 $\approx 0.2$，所以一个含着 10% 的石榴石的来源有着 $D_{\text{体,Yb}} \approx 0.9$、而它的熔体在镱上不能比来源富集超过约 **1.1 倍**、无论熔体的分数。玄武岩 B 在镱上对着原始地幔的富集因此**直接测量着来源的富集**，而它在那个镱的值之上的轻的稀土的富集测量着**熔体的分数**——来源与过程的经典的分离。

**两者里铕的异常的缺失**本身是有信息的：它排除着任何一个斜长石的控制，它反过来排除着玄武岩 B 的一个**低压的**起源、而排除着两者的一个**富斜长石的堆晶**的亲和性。一个沉积物里的一个负的铕的异常，相反地，是一个**花岗岩的上部的壳的物源**的经典证据，因为整个的大陆地壳有着 $\mathrm{Eu/Eu^*} \approx 0.6$、从制造了它的斜长石的分馏。
:::
:::

::: example 硫化物的饱和对着一个难熔的来源 {#ex-sulfide}
一个苦橄岩含着 $1800\ \mathrm{ppm}$ 的 Ni、$8\ \mathrm{ppm}$ 的硫、$2\ \mathrm{ppb}$ 的钯，而一个原始地幔归一化的图像给出 Ni 在原始地幔的 1.2 倍、硫在 0.05 倍、钯在 0.02 倍。一个同事主张来源是一个**难熔的、高的熔体的分数的残渣**。检验这个主张。
::: solution
一个**难熔的残渣**在一切相容的东西上亏减——橄榄石、辉石、尖晶石、而最重要的，**硫化物**，它在早期的熔融的事件期间从残渣被排出。这样一个来源将给出一个**同时在镍上、在硫上、在铂族的元素上低的**熔体，而亏减将**与每一个元素在残渣的相里的相容性相关**。

那不是数据说的。熔体在镍上**富集**（原始地幔的 1.2 倍）、而在硫上（0.05 倍）、在钯上（0.02 倍）**亏减**。镍在这里表现得**不相容**、而亲铜的元素表现得**相容**，而做那的唯一的过程是**硫化物的饱和**：一个不混溶的单硫化物的液体，它在熔体超过它在橄榄石的丰度上的约 $800$–$1200\ \mathrm{ppm}$ 的硫的溶解度时立刻形成，它以 $10^3$–$10^4$ 的一个硫化物/硅酸盐的分配的系数分配着钯、而在一个单一的事件里移走它的 98%，而把镍大体上留在硅酸盐里，因为镍只适度地亲铜。

**定量的检验**是硫的内容。一个在 1 GPa 上被橄榄石、斜方辉石、与尖晶石饱和的原始的熔体保持着约 $1000\ \mathrm{ppm}$ 的硫；这块岩石保持着 $8\ \mathrm{ppm}$，在饱和之下 125 倍，它意味着硫被**失去了**——而硫除了通过出溶一个硫化物的液体或一个硫化物的蒸气不能失去。**Ni–S–Pd 的三角形**因此唯一地诊断着过程：
$$
\text{高的 Ni} + \text{低的 S} + \text{低的 Pd} \Rightarrow \text{硫化物的饱和}; \qquad
\text{低的 Ni} + \text{低的 S} + \text{低的 Pd} \Rightarrow \text{难熔的来源}.
$$
这个区分不是书生的。如果钯的亏减是一个**来源**的特征，岩浆没有矿石的潜力；如果它是一个**在不采样的层位之下某处分离的一个不混溶的硫化物的液体**的产物，那么那个硫化物正坐在通道的底部或一个岩浆的房上，而它能携带着经济的镍、铜、与铂族的元素的矿床。这是巴恩斯与纳德雷特（巴恩斯）与莱特富特（莱特富特）的 **R 因子**（与它平衡的硅酸盐的岩浆的质量对硫化物的液体的质量的比）背后的推理，而它是火成的硫化物的勘探里最有价值的单一的数字。对一个携带着 $2\ \mathrm{ppb}$ 的钯、与一个 $10^4$ 的一个硫化物/熔体的分配的系数的熔体，一个 100 的 R 因子给出一个 $10^4\times2/(1+100) = 200\ \mathrm{ppb}$ 的钯的硫化物、而一个 10000 的 R 因子给出一个 $10^4\times2/(1+1) = 10^4\ \mathrm{ppb}$ 的——**富五十倍**，因为一个与大量的岩浆平衡的小量的硫化物远比它有效地清道着金属。高的 R 的硫化物是矿石的品位的，而 R 因子因此从硫化物自己的金属品位被读。
:::

## 混合、混染、而堆晶的问题

::: definition 两组分的混合与双曲线的混合 {#def-mixing}
混合两个岩浆保守着每一个元素的**质量**，所以一个混合的浓度是**线性的**组合
$$
C_m = \alpha C_A + (1-\alpha)C_B ,
$$
带着 $\alpha$ 是分量 A 的分数。一个元素对着另一个元素的图因此是**一条直线**，而混合的比例被直接地读。一个**比对着一个比**的图，然而，是一个**双曲线**，因为
$$
\frac{C^1}{C^2} = \frac{\alpha C_A^1 + (1-\alpha)C_B^1}{\alpha C_A^2 + (1-\alpha)C_B^2}
$$
是 $\alpha$ 的一个分数的函数。后果是火成的地球化学里最被使用的图：在一个 $\mathrm{Sr/Nd}$ 对着 $\mathrm{Ba/Nd}$、或 $^{87}\mathrm{Sr}/^{86}\mathrm{Sr}$ 对着 $1/\mathrm{Sr}$ 的图上，一个**样本的线性的阵列是一个混合的阵列、只有当分母被匹配着**，而一个弯曲的阵列仍然是一个混合的阵列。推论是一个**弯曲的**痕量的元素的趋势不能在被检验了替代的方案之前被归因于分离的结晶，而一个**直的** $1/x$ 对着 $x$ 的阵列是**同化–分离的结晶**的经典的检验。
:::

::: example 同化与壳的混染物 {#ex-mixing}
一个亏减的地幔的岩浆带着 La $1.2\ \mathrm{ppm}$、Sr $80\ \mathrm{ppm}$、而 $^{87}\mathrm{Sr}/^{86}\mathrm{Sr} = 0.5131$，同化着大陆的地壳，带着 La $32\ \mathrm{ppm}$、Sr $380\ \mathrm{ppm}$、而 $^{87}\mathrm{Sr}/^{86}\mathrm{Sr} = 0.7180$。一个混染的样本有 La $6.0\ \mathrm{ppm}$、Sr $145\ \mathrm{ppm}$。从每一个元素找出同化的地壳的质量的分数，而解释两个为什么不一致。
::: solution
从**镧**的质量的平衡，
$$
\alpha = \frac{6.0 - 1.2}{32 - 1.2} = \frac{4.8}{30.8} = 0.156 ;
$$
从**锶**的质量的平衡，
$$
\alpha = \frac{145 - 80}{380 - 80} = \frac{65}{300} = 0.217 .
$$
两个不一致 40%，而理由是**镧与锶不是同等地相容**：在同化期间岩浆也在结晶着橄榄石、斜长石、与单斜辉石，它比镧（$D \approx 0.05$）远更快地移走着锶（一个斜长石里的相容的元素，$D \approx 1.5$）。一个**应用于带着不同的分配的系数的元素的两组分的混合的模型给出不一致的混合的分数**，而标准的补救是使用**带着匹配的分配的系数的不相容的元素的对**（La 与 Ce，Th 与 U，Nb 与 Ta，Sm 与 Nd）或**同时**地模拟同化与结晶——德维（德维）的、与斯佩拉与博尔森（博尔森）的**能量的约束的**同化–分离的结晶的模型，其中结晶释放的热限制着能被熔化的岩石的质量，所以一个同化了 20% 的地壳的岩浆必须结晶了一个可比较的质量。

同位素的检验闭合着论证。对一个 $\alpha = 0.156$ 预言的锶的同位素的比是
$$
\frac{0.156\times380\times0.7180 + 0.844\times80\times0.5131}{0.156\times380 + 0.844\times80} = \frac{42.6+34.6}{59.3+67.5} = 0.609 ,
$$
而对一个 $\alpha = 0.217$ 它是 0.630。一个测量的 $^{87}\mathrm{Sr}/^{86}\mathrm{Sr}$ 的 0.61 因此支持着**镧**的混合的分数、而显示着锶的浓度被斜长石扰乱了——一个没有痕量的元素与同位素两者不能到达的结论。
:::
:::

::: warning 一个岩石的痕量的元素的图案不是它的岩浆的
三个过程在熔体形成之后重写着一个痕量的元素的图案，而每一个能模仿一个来源的签名。**晶体的累积**：一个带着 50% 的橄榄石的堆晶有着橄榄石的相容的元素的内容、加上**被捕获的堆间液体**，而一个只带着 10% 的被捕获的液体的堆晶有着一个 90% 由液体、10% 由晶体控制的轻的稀土的图案——所以一个带着低的稀土的"原始的"样本可能是一个**堆晶**、不是一个原始的熔体，而检验是**两个都只分配进液体的元素的比**（La/Sm，Th/La，Nb/La），它不被晶体的累积改变、而它的**绝对的数值**被改变着。**硫化物的饱和**：一个不混溶的硫化物的液体在一个单一的事件里从一个硅酸盐的熔体剥走 99% 的 Os、Ir、Ru、Rh、Pt、Pd、Re、Se、Te、As，而铂族的元素的产生的亏减**与一个难熔的来源的一个高的熔体的分数的熔体无法区分**，除非硫的内容与硫化物的结构被测量——太古代的科马提岩与玻安岩的地球化学里的经典的错误。**而流体的蚀变**：俯冲的流体携带着 Rb、Ba、Sr、Pb、U、而把 Nb、Ta、Ti、重的稀土留下，所以一个弧的玄武岩里的一个"壳的"签名可能是一个几个百分点的蚀变的海洋的地壳的一个**流体**的签名、不是几十个百分点的沉积物，而区分剂是**高度地流体活动的对流体不活动的元素的比**（Rb/Nb，Ba/Nb，Th/Nb，U/Nb，而 Cs/Rb 的比，它区分着一个板片的脱水的流体与一个板片的熔体）。纪律是对每一个痕量的元素的解释说明，**四个过程——熔融、分馏、累积、蚀变——中的哪一个被排除了、被哪一个观察**，而记住最被使用来识别一个来源的元素（Rb、Ba、Th、U、Pb、K）恰恰是在一个流体里最活动的。
:::

::: history

## 通向何处

分配的系数本身在 [[mineralogy-petrology/magma-evolution]] 与 [[mineralogy-petrology/phase-diagrams]] 背后的实验里被测量，建立在母–女的对上的同位素的系统在 [[geochemistry/radiogenic-tracers]] 与 [[geochemistry/geochronology]]，沉积的物源的应用在 [[sedimentology/stratigraphy]] 与 [[sedimentology/facies]]，矿床在 [[earth-resources/magmatic-hydrothermal]] 与 [[earth-resources/critical-minerals]]，海洋的自生的与古海洋学的应用在 [[oceanography/ocean-chemistry]] 与 [[palaeoclimate/proxies]]，而分配的定律的热力学的基础在 [[geochemistry/reactions]]。

::: quiz
一个玄武岩有着 $(\mathrm{La/Yb})_N = 4.0$、$(\mathrm{Dy/Yb})_N = 0.7$。重的稀土的斜率告诉你什么、而轻的稀土的富集不告诉你的？
- [ ] 部分熔融的程度。
- [x] 石榴石在来源或残渣里存在，因为石榴石保持着重的稀土、而使重的稀土的斜率变平或倒置。
- [ ] 熔融的温度。
- [ ] 壳的混染的程度。
::: solution
轻的稀土的富集 $(\mathrm{La/Yb})_N$ 能由一个小的熔体的分数、一个富集的来源、或壳的混染生产——它是含糊的。**重的稀土的斜率** $(\mathrm{Dy/Yb})_N$ 几乎完全由**石榴石**控制，它的分配的系数在重的稀土上陡地上升，所以一个在 1 之下的值是一个关于残渣的**矿物的**陈述、不是一个过程的陈述。石榴石是有着这个性质的常见的地幔的相里唯一的，这就是一个玄武岩的熔融的深度从重稀土的斜率被读、而它的来源的富集从轻稀土的富集被读的理由。
:::
:::

::: summary
- 一个痕量的元素稀到服从着亨利定律，所以它的矿物/熔体的分配的系数是常数、由离子的半径、电荷、压力、温度、而成分设定。
- 相容的元素记录着熔体在形成之后看到的；不相容的元素记录着来源。
- 瑞利与批式的行为在大的熔体的分数上一致、而在小的熔体的分数上分开一个数量级，尤其对相容的元素。
- 稀土的图案分离着来源（轻的稀土）与残渣的矿物学（重的稀土的斜率，石榴石）与斜长石（铕）与氧化的还原（铈）。
- 混合在浓度里是线性的、在比里是双曲线的，而一个应用于带着不同的分配的系数的元素的混合的模型给出不一致的答案。
- 堆晶的添加、硫化物的饱和、而流体的蚀变各能模仿一个来源的签名，而每一个必须被一个特定的观察排除。
:::

## 练习

::: exercise 体的分配 {level=1 check="0.018"}
一个地幔的橄榄岩含着 60% 的橄榄石（$D_{\mathrm{Sr}} = 0.001$）、25% 的斜方辉石（$D_{\mathrm{Sr}} = 0.01$）、10% 的单斜辉石（$D_{\mathrm{Sr}} = 0.15$）、5% 的尖晶石（$D_{\mathrm{Sr}} = 0.005$）。找出体的 $D_{\mathrm{Sr}}$。
::: solution
$D_{\text{体}} = 0.60(0.001) + 0.25(0.01) + 0.10(0.15) + 0.05(0.005) = 0.0006 + 0.0025 + 0.015 + 0.00025 = 0.018$。
一个相的百分之十主导着整个的预算，这就是一个几个百分点内的模式的测定比一个几个百分点内的痕量的元素的分析更重要的理由。
:::
:::

::: exercise 瑞利 {level=1 check="4.3"}
一个带着 $D = 0.1$ 的元素被分馏到一个液体的分数 $F = 0.2$。找出 $C_L/C_0$。
::: solution
$C_L/C_0 = F^{D-1} = 0.2^{-0.9} = 4.3$。这个元素被作为晶体的液体的 80% 的移走浓缩了四倍多。
:::
:::

::: exercise 异常 {level=1}
一个岩石有 $\mathrm{Sm_N} = 20$、$\mathrm{Gd_N} = 21$、$\mathrm{Eu_N} = 9$。找出铕的异常。
::: solution
$\mathrm{Eu/Eu^*} = 9/\sqrt{20\times21} = 9/20.5 = 0.44$。一个强地**负的**铕的异常，一个失去了斜长石的岩石的特征——上部的陆壳，一个花岗岩的片麻岩，或从它们导出的一个沉积物。
:::
:::

::: exercise 批式对着瑞利 {level=2 check="0.51"}
对 $D = 2$、$F = 0.05$，找出批式的熔融的 $C_L/C_0$、瑞利的熔融的、而两者的比。
::: solution
批式：$C_L/C_0 = 1/[2 + 0.05(1-2)] = 1/1.95 = 0.51$。瑞利：$C_L/C_0 = F^{D-1} = 0.05^{1} = 0.05$。比是 $0.51/0.05 = 10$。
:::
:::

::: exercise 混合 {level=2 check="0.21"}
岩浆 A 有 Th $12\ \mathrm{ppm}$、岩浆 B 有 Th $0.8\ \mathrm{ppm}$。一个混合物有 Th $3.2\ \mathrm{ppm}$。找出 A 的分数。
::: solution
$\alpha = (3.2 - 0.8)/(12 - 0.8) = 2.4/11.2 = 0.21$。A 的百分之二十一。如果同一个混合物在一个带着不同的分配的系数的元素上被分析、而给出一个不同的 $\alpha$，两组分的混合的模型是错的、而分离的结晶必须被包括。
:::
:::

::: exercise 镍与橄榄石 {level=2 check="3600"}
一个科马提岩的熔体含着 $300\ \mathrm{ppm}$ 的 Ni。取橄榄石/熔体的分配的系数 $D_{\mathrm{Ni}} = 12$，找出第一个结晶的橄榄石的镍的内容。
::: solution
$C_{\mathrm{橄榄石}} = D\times C_{\text{熔体}} = 12\times300 = 3600\ \mathrm{ppm}$。这是在太古代的科马提岩的橄榄石里测量的范围（$2000$–$4000\ \mathrm{ppm}$），而它是科马提岩是**液体**、不是一个富镁的岩石的变质的产物的经典的证据——一个变质的起源不能把镍在橄榄石里浓缩到 0.4 个百分点。
:::
:::

::: exercise 一个堆晶的稀土 {level=3 check="6.0"}
一个堆晶含着 85% 的累积的橄榄石、15% 的被捕获的堆间的液体。堆间的液体有 La $40\ \mathrm{ppm}$、橄榄石有 La $0.05\ \mathrm{ppm}$。找出岩石的 La 的内容、与来自液体的岩石的镧的分数。
::: solution
$$
C_{\text{岩石}} = 0.85\times0.05 + 0.15\times40 = 0.043 + 6.0 = 6.0\ \mathrm{ppm},
$$
而液体供给着它的 $6.0/6.04 = 99$%。一个按模式**85% 的晶体**的岩石按稀土的预算是**99% 的液体**，所以它的轻的稀土的图案、它的轻的稀土的同位素的系统学、它的元素的比是一个**熔体**的、不是一个晶体的堆晶的——而它的低的绝对的稀土的内容（对着液体的 40 是 6 ppm）是它是一个堆晶的唯一的线索。

这是**堆晶的陷阱**，而它是标准的检验是**两个同等地不相容的元素的比**（La/Sm，Th/La，Nb/La，Ce/Pr）、它被无镧的橄榄石的添加**不变**、对着**绝对的**浓度、它不被画的理由。一个堆晶在一个比的对着比的图上与它的母液体在同一个**趋势**上、而在它上面在一个不同的**沿的距离**上被画，而任何一个把趋势读成一个来源的签名、而不检验浓度的解释是不安全的。
:::
:::

::: exercise 石榴石的监测器 {level=3 check="1.5"}
一个来源含着 8% 的石榴石，带着在石榴石里的 $D_{\mathrm{Yb}} = 8$、在单斜辉石里的 0.2、在橄榄石里的 0.01、在斜方辉石里的 0.02；模式是 8、10、62、20 个百分点。找出体的 $D_{\mathrm{Yb}}$、与一个批式的熔体里镱的最大的富集，而解释重的稀土为什么测量着来源、不是熔体的分数。
::: solution
$$
D_{\text{体}} = 0.08\times8 + 0.10\times0.2 + 0.62\times0.01 + 0.20\times0.02 = 0.64+0.02+0.006+0.004 = 0.67 ,
$$
而在任何一个熔体的分数上的批式的熔体的富集被
$$
\frac{C_L}{C_0} = \frac{1}{D + F(1-D)} \le \frac{1}{D} = 1.5
$$
限制着。在 $F = 1$ 上富集是 1.0、而在 $F = 0.05$ 上它是 $1/(0.67+0.05\times0.33) = 1.4$。

要点是**范围的窄**：对一个 $D$ 接近一的元素，批式的熔体的富集在整个的熔体的分数的范围上只变化 50%，而对一个带着 $D = 0.01$ 的轻的稀土它变化一个 100 的因子。**重的稀土因此几乎对熔体的分数免疫、而只对来源的浓度、对石榴石的存在反应着**——这就是 $(\mathrm{Yb})_N$ 或 $(\mathrm{Lu})_N$ 被作为 $(\mathrm{La/Sm})_N$ 的来源的富集的归一化器使用、钐–钕的同位素的系统如此鲁棒、而一个**对着球粒陨石、不是对着重的稀土归一化的**轻的稀土的富集为基础的"富集的来源"的主张没有价值的理由。
:::
