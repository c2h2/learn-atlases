地球化学始于一个在其他任何地球科学里没有类似的事实：我们的行星的物质是银河系的一个样本，而它的成分能从一颗陨石、一个光球的谱、以及恒星燃烧的核的物理被读出。其余的一切——为什么地幔在钾上被亏减，为什么地核持有着行星的几乎全部的镍，为什么海洋是咸的而地壳是花岗的，为什么铝是不活动的而铷不是——跟着三件事：核如何被制造，它们在什么温度上从太阳的气体里凝聚，以及一旦岩石是固的而水存在时它们形成什么键。

## 什么是丰富的，以及为什么

::: definition 宇宙与太阳系的丰度 {#def-abundances}
元素的丰度被引用为**每一百万个硅的原子原子的数目**（地球化学的惯例，带 $\log\varepsilon(\mathrm{Si}) = 7.51$）或每一百万个氢的原子（光谱学的惯例，$\log\varepsilon(\mathrm{H}) = 12$）。三个特征主导着这个样式。**氢与氦**是银河的 99%，而几乎完全被排除在地球之外，所以一个地球化学家的"丰度"的表是一个主要是气体的宇宙的**耐火的残渣**的表。**奇偶的哈尔金斯规则**（哈尔金斯）是交替，1917 年哈尔金斯第一次注意到、而此后每一个质谱学家确认着，**偶数的原子序数的元素比它们的奇数的邻居更丰富**，因为质子与中子在核里配对，而任一种的偶数被更紧地束缚着、而更容易被制造。而 $Z = 26$ 的**铁峰**是一个极大，因为 $^{56}\mathrm{Ni}$ 与 $^{56}\mathrm{Fe}$ 有着任何核的最高的每个核子的束缚的能，所以恒星的燃烧向着它们运行而停下。量级是巨大的：钙（$Z = 20$）比钪（$Z = 21$）丰富 1500 倍，而铁（$Z = 26$）比锰（$Z = 25$）丰富 117 倍、比铜（$Z = 29$）丰富 2000 倍。
:::

::: example 奇偶的哈尔金斯规则 {#ex-harkins}
光球的丰度（阿斯普兰德与同事们）给出 $\log\varepsilon$：Ca 6.34，Sc 3.15，Ti 4.95，V 3.93，Cr 5.64，Mn 5.43，Fe 7.50，Co 4.99，Ni 6.22，Cu 4.19。计算丰度的比 Ca/Sc、Ti/Sc、V/Sc、Fe/Mn、Fe/Co、Ni/Cu，而辨别哪些差异是奇偶的、哪些不是。
::: solution
$$
\frac{\mathrm{Ca}}{\mathrm{Sc}} = 10^{6.34-3.15} = 1550, \quad
\frac{\mathrm{Ti}}{\mathrm{Sc}} = 10^{1.80} = 63, \quad
\frac{\mathrm{V}}{\mathrm{Sc}} = 10^{0.78} = 6.0,
$$
$$
\frac{\mathrm{Fe}}{\mathrm{Mn}} = 10^{2.07} = 117, \quad
\frac{\mathrm{Fe}}{\mathrm{Co}} = 10^{2.51} = 324, \quad
\frac{\mathrm{Ni}}{\mathrm{Cu}} = 10^{2.03} = 107 .
$$
这些对里的每一个是一个**偶–奇**的对，而每一个是一个 6 到 1500 的因子。这个样式是奇偶的哈尔金斯规则，而它的幅度是地球化学家的周期表是一个**锯齿**的理由：一个元素的化学与它的邻居的几乎相同（Sc 与 Y，Mn 与 Fe），而它的丰度可能相差三个数量级。

这些数字里的两个**不**纯粹是奇偶的。Fe/Mn 与 Fe/Co 的比被**铁峰**膨胀着——$^{56}\mathrm{Fe}$ 坐在束缚的能的曲线的极大上，所以铁是反常地丰富的、甚至对它的偶数的邻居，而 Ni（$Z = 28$）只在 Fe 之下一个 1.9 的因子、而不是单独的锯齿将给出的十的因子。而 1550 的 Ca/Sc 的比比奇偶的效应单独的大，因为钪也是一个恒星的产生是适度的**相容的**元素。

实际的后果是**痕量元素是痕量的，因为核的物理，不是因为化学**。铷比锶稀 30 倍，因为 Rb 是奇–奇的；稀土元素跨着一个化学基本上是常数的系列跨着一个 100 的因子；而同位素的地质学的整个学科依靠着一个衰变的方案的母体与子体通常在丰度上相差三个数量级的事实，这是使一个可测量的放射性的生成成为可能的东西。
:::

## 从气体到岩石

::: definition 凝聚的序列 {#def-condensation}
当太阳星云从约 $2000\ \mathrm{K}$ 冷却时，元素以一个由在 $10^{-4}\ \mathrm{atm}$ 的总的压强上的**平衡的凝聚的温度** $T_{cond}$ 设定的固定的顺序凝聚。**耐火的元素**（$T_{cond} > 1650\ \mathrm{K}$：Ca、Al、Ti、Sc、Y、稀土、Zr、Hf、U、Th、Os、Ir、Pt）最先凝聚，而是制造 **CAI**——钙铝的包裹体，太阳系的最古老的固体，在 $4567\ \mathrm{Ma}$——的残渣。**造岩的亲石的元素**（Si、Mg、Fe 作为硅酸盐与氧化物，$1400$–$1350\ \mathrm{K}$）与**金属与硫化物**（Fe–Ni 的合金与陨硫铁，$1350$–$1000\ \mathrm{K}$）跟随着。**中等的易挥发的元素**（Na、K、Rb、Zn、Ga、Ge、In、Tl、Pb、Bi、Sn、S、Se、Te、卤素；$1100$–$600\ \mathrm{K}$）最后凝聚或从未被完全地凝聚，而**高度易挥发的元素与惰性的气体**（H、C、N、Ne、Ar、Kr、Xe；$400\ \mathrm{K}$ 以下）大体上丢失给了气体。对地球的后果是一个**与 CI 球粒陨石相比的、按 $T_{cond}$ 缩放的易挥发的元素的系统的亏减**。耐火的亲石的元素基本上未被分馏：原始的地幔的 Th/U 的 1.25，它的 CaO/Al$_2$O$_3$ 与它的 Zr/Sm 在球粒的值的几个百分点之内。中等的易挥发的元素被几个因子的亏减——整体的硅酸的地球的约 $11800$ 的 K/U 在球粒的值之下几个因子。高度易挥发的元素被数量级的亏减：原始的地幔含着 $0.545\ \mathrm{ppb}$ 的铅，对 CI 球粒陨石的 $812\ \mathrm{ppb}$，一个 **1500 倍**的亏减，而惰性的气体与生命的易挥发的元素（H、C、N）被 $10^3$ 到 $10^6$ 的因子的亏减。这个**亏减–挥发性的趋势**是关于地球的整体的成分的最重要的一个观测，而它的原因——星云的挥发性，核–幔的平衡，或在形成月球的巨大撞击里的蒸发的损失——仍被争论着。
:::

::: example 易挥发性的亏减与地球的比 {#ex-depletion}
原始的地幔含着 K $240\ \mathrm{ppm}$、Rb $0.605\ \mathrm{ppm}$、Sr $19.9\ \mathrm{ppm}$、U $20.3\ \mathrm{ppb}$、Th $25.3\ \mathrm{ppb}$、Pb $0.545\ \mathrm{ppb}$；CI 球粒陨石含着 $812\ \mathrm{ppb}$ 的铅。计算原始的地幔的 Th/U、K/U 与 Rb/Sr 与铅的亏减的因子，而说出每个比记录着什么。
::: solution
$$
\frac{\mathrm{Th}}{\mathrm{U}} = \frac{25.3}{20.3} = 1.25, \qquad
\frac{\mathrm{K}}{\mathrm{U}} = \frac{240\times10^{6}}{20.3} = 11\,800, \qquad
\frac{\mathrm{Rb}}{\mathrm{Sr}} = \frac{0.605}{19.9} = 0.030,
$$
$$
\frac{\mathrm{Pb}_{CI}}{\mathrm{Pb}_{PM}} = \frac{812}{0.545} = 1490 .
$$
每个比记录着一个不同的过程。**Th/U = 1.25** 是一个**耐火对耐火**的比：两个元素是高度不相容的、而两个是耐火的，所以它们的比在吸积时被设定，而**被任何后来的熔融不变**。它是 U–Pb 的同位素的钟与 $\mu$（$^{238}\mathrm{U}/^{204}\mathrm{Pb}$）与 $\kappa$（$^{232}\mathrm{Th}/^{238}\mathrm{U}$）的参数基础。**K/U = 11800** 是一个**易挥发对耐火**的比：钾是中等的易挥发的（$T_{cond} \approx 760\ \mathrm{K}$）、而铀是耐火的，所以这个比记录着地球的**易挥发性的亏减**、而只被一个分馏挥发性的过程改变，不被熔融改变，因为两个是强不相容的。**Rb/Sr = 0.030** 是一个**相容性**的比：铷与锶有着相似的挥发性，而锶远不那么不相容，所以这个比由**熔体的抽出**设定、不是由挥发性设定。而**铅的 1500 倍的亏减**记录着铅的极端的易挥发性（$T_{cond} \approx 540\ \mathrm{K}$）与它向一个硫化物的相的部分的损失。

这个方法的力量在于三个比是**正交的**，而一个岩石在它们所定义的空间里的位置把它历史分成吸积的、易挥发的、与分异的分量。一个 K/U = 11800、Rb/Sr = 0.030 的玄武岩来自一个**原始的、未分异的**源；一个 K/U = 11800、Rb/Sr = 0.35 的麻粒岩的捕虏体经历过**形成地壳的熔融**、而没有失去挥发分；而一个 K/U = 3000 的岩石**失去了钾**给卤水、变质或风化，无论它的源是什么。

告诫是这些比只与封闭系统的行为的前提一样好。铷在水的流体里是活动的、而钾在水热的卤水里是活动的，所以 Rb/Sr 与 K/U 都被蚀变重置，而 Th/U 与耐火的比不被。这就是为什么**同位素**的比——Sr、Nd、Hf、Pb、Os——而不是元素的比在一个变质或蚀变的构造里携带着源的信息，而为什么元素的比主要在新鲜的、未蚀变的样品上被使用。
:::
:::

## 化学的族类

::: definition 戈尔德施密特的分类 {#def-goldschmidt}
**维克托·戈尔德施密特**（戈尔德施密特）按它们在一个分异的天体里进入的相来给元素分类，而这个分类仍是这个领域的工作的词汇。**亲石的元素**（"爱岩石的"：O、Si、Al、Ca、Na、K、Mg、Ti、稀土、Th、U、Zr、Hf、Nb、Ta、Ba、Sr、Rb）与氧成键、而集中在硅酸的地幔与地壳里。**亲铁的元素**（"爱铁的"：Fe、Ni、Co、Ru、Rh、Pd、Os、Ir、Pt、Re、W、Mo）溶解在金属的铁里，而被扫进了地核。**亲铜的元素**（"爱硫的"：Cu、Ag、Au、Zn、Cd、Hg、Pb、As、Sb、Bi、Se、Te、Mo）集中在硫化物的熔体里。**亲气的元素**（H、N、O，惰性的气体）是大气的大。**亲生物的元素**（C、N、O、P、S）被生物地循环着。这个分类**不是**任意的：它是**电负性**与**第一电离的电位**的后果，而它靠**金属–硅酸的分配系数**被定量地表达
$$
D^{金属-硅酸} = \frac{(\text{金属里的 } X \text{ 的 wt\%})}{(\text{硅酸的熔体里的 } X \text{ 的 wt\%})},
$$
它依赖于压强、温度、氧的逸度与硅酸的熔体的成分。**高场强的元素**（Ti、Zr、Hf、Nb、Ta、稀土、Y、P）抵抗着流体与熔体的输送，因为它们与氧形成强的键；**大离子的亲石的元素**（Rb、Ba、Sr、K、Pb、Cs）是强不相容的，而是花岗岩、伟晶岩与俯冲的流体的元素。**大的亲石的元素**——Al、Ca、Na、Ti、REE、Y——被这样命名，因为它们是丰富的、亲石的，而在一个水的流体的存在下大体上是不活动的，这使它们成为火成的与沉积的岩石的痕量元素的地球化学两者的参考的集合。
:::

::: example 镍去了哪里？ {#ex-core-ni}
地球的地核是行星的 $32.5\ \mathrm{wt\%}$、而地幔是 $67.5\ \mathrm{wt\%}$。假设地球带着一个 CI 球粒陨石的 $1.1\ \mathrm{wt\%}$ 的镍的含量吸积，而整体的硅酸的地球现在含着 $1900\ \mathrm{ppm}$ 的 Ni。找出地核的镍的含量与地球的镍住在地幔里的分数。
::: solution
在整个的行星上的一个质量平衡给出
$$
C_{核} = \frac{C_{地球} - f_{地幔}\,C_{地幔}}{f_{核}}
        = \frac{1.1 - 0.675\times0.19}{0.325} = \frac{0.972}{0.325} = 3.0\ \mathrm{wt\%}.
$$
地幔持有着
$$
\frac{0.675\times0.19}{1.1} = 0.117 = 12\ \text{per\ cent}
$$
地球的镍的，而地核持有着 **88%**——在一个是质量的 32.5% 的储层里，所以地核在镍上相对于整体的地球被富集了 2.7 倍、而相对于地幔被富集了 **16** 倍。

$3.0\ \mathrm{wt\%}$ 是地核的轻的元素的含量的一个**最小值**，因为地核的从自由的核的压缩的密度在核的压强上比纯的 Fe–Ni 低 5–10 个百分点，而亏缺要求 5–10 个百分点的轻的元素——其中的候选者是 S、Si、O、C 与 H，而这里被数的镍是同一个预算的一部分。这个计算是亲铁的分类的最简单的可能的应用，而它推广着：同样的算术应用于**铱、锇、铂、铼与钨**给出 99.5% 或更多的地核的内容，这就是**高亲铁的元素的地幔的丰度**是地球化学的核心谜题之一的理由——它们本该基本上为零，而它们不是，这要求或者在一个停止核的形成之后被添加的球粒的物质的一个**后期的薄盖**，或者在远高于任何实验的压强与温度上的金属–硅酸的平衡。
:::
:::

::: definition 离子的电位与水的行为 {#def-ionic-potential}
一旦水存在，戈尔德施密特的族类被一个基于**离子的电位** $z/r$——电荷除以以 Å 计的离子的半径（施图姆与摩根，摩根）——的分类取代。**$z/r < 2.6$**：阳离子不把它的自己的水化的壳极化到足以水解，而它作为一个**自由的水化的阳离子**在水里持续着——Na$^+$（$1/1.02 = 0.98$）、K$^+$（0.72）、Mg$^{2+}$（2.78，临界的）、Ca$^{2+}$（2.0）、Sr$^{2+}$、Ba$^{2+}$。这些是**海水**的元素。**$2.6 < z/r < 9$**：阳离子**水解**，形成不溶的氢氧化物与两性的行为——Al$^{3+}$（$3/0.535 = 5.6$）、Fe$^{3+}$（4.7）、Cr$^{3+}$、REE$^{3+}$、Th$^{4+}$、Ce$^{4+}$。这些元素**在中性的 pH 上从溶液里被移走**，而在风化的剖面里是不活动的。**$z/r > 9$**：阳离子不能作为一个未配位的物种在水里存在，而形成**氧的阴离子**——Si$^{4+}$（$4/0.26 = 15.4$）、P$^{5+}$（13.2）、S$^{6+}$（20.7）、C$^{4+}$（26.7）、Cr$^{6+}$、Mo$^{6+}$、U$^{6+}$。这个分类一行就解释了海水的成分：第一组的阳离子是它的阳离子，第三组的阴离子是它的阴离子（Cl$^-$ 与 SO$_4^{2-}$），而第二组缺席，因为它沉淀着。
:::

::: example 为什么海洋是富钠的、而贫铝的？ {#ex-ocean-chem}
离子的半径（香农，六次的配位）是 Na$^+$ 1.02、K$^+$ 1.38、Mg$^{2+}$ 0.72、Ca$^{2+}$ 1.00、Al$^{3+}$ 0.535、Fe$^{3+}$ 0.645、Si$^{4+}$ 0.26、P$^{5+}$ 0.38、S$^{6+}$ 0.29 Å。计算离子的电位，而预言海洋的成分。测量的浓度是 Na 10.8、Mg 5.3、S 2.9、Ca 1.0、K 0.39、Al $3\times10^{-6}$、Fe $4\times10^{-7}$ mmol/kg。
::: solution
$$
\begin{array}{l|cccccccc}
 & \mathrm{Na^+} & \mathrm{K^+} & \mathrm{Ca^{2+}} & \mathrm{Mg^{2+}} & \mathrm{Al^{3+}} & \mathrm{Fe^{3+}} & \mathrm{Si^{4+}} & \mathrm{S^{6+}} \\
\hline
z/r & 0.98 & 0.72 & 2.00 & 2.78 & 5.61 & 4.65 & 15.4 & 20.7
\end{array}
$$
在约 2.8 以下的 $z/r$ 的四个阳离子——Na、Mg、Ca、K——是海洋的四个阳离子，而它们一起是它的正电荷的 99.9%。Al 与 Fe，带着 4.7 与 5.6 的 $z/r$，在任何在约 4 以上的 pH 上水解，而在钠之下**七个与八个数量级**。硅与硫，带着在 9 以上的 $z/r$，作为**阴离子**的硅酸与硫酸出现。

这个分类完美地预言着**定性的**成分、而完全不预言着**定量的**成分：钾是地壳里第三个最丰富的造岩的阳离子、而在海洋里只是第四个，因为它被黏土矿物固定住，而镁尽管有它的高的离子的电位而在海洋里是丰富的，因为水镁石与富镁的方解石的沉淀是慢的。**剩余的**行为——分类的预言与海洋的实际的成分之间的差异——是**生物与矿物的控制**的记录，而这是海洋是一个**非平衡的**流体的理由，它的成分由河的输入、水热的输出、以及方解石与硅与生物泵的盐的沉淀的平衡设定着。
:::

::: history
**玛丽·莫里斯·希利**与**弗兰克·威格尔斯沃思·克拉克**（克拉克）在 1908–1924 年从几千个分析编制了**地球的地壳的第一个平均的成分**，而"克拉克值"仍是一个元素的地壳的丰度的词。**弗拉基米尔·维尔纳茨基**（维尔纳茨基）在他 1908 年的《地球化学》里把**地球化学**创立为一个学科，把元素的分布当作一个历史的问题。**弗里茨·帕内特**（帕内特）与**维克托·戈尔德施密特**（戈尔德施密特），在 1920 年代在哥廷根与奥斯陆工作，产出了 1923 年的**戈尔德施密特的分类**与十三篇论文的《元素的地球化学的分布的定律》的系列（戈尔德施密特），确立了亲石–亲铁–亲铜的族类、离子的半径的规则、以及类质同象的替代的概念。**哈尔金斯**（哈尔金斯）1917 年的奇偶的规则与**博比奇、博比奇、福勒与霍伊尔**（霍伊尔）1957 年的《现代物理评论》的核合成的综合供给着核的解释。**哈罗德·尤里**（尤里）在 1952 与 1955 年计算了太阳星云的**凝聚的序列**，而**拉勒米与安德斯**（安德斯）在 1967–70 年计算了今天被使用的平衡的凝聚的温度。**汉斯·修斯**（修斯）与**哈罗德·尤里**辨认出了"宇宙化学的"的元素，而**尤金的与利比**与**奈尔**把同位素的地球化学带进了核的时代的精度。
:::

::: warning 丰度的表不是数据，它们是模型
一本文科书里被引用的每一个"地壳的丰度"、"地幔的"、"地球的"是一个**在一个模型上的加权的平均**，而随着模型改变，数字移动着几十个百分点。**地壳的丰度**依赖于被假设的**花岗岩 : 玄武岩 : 沉积的比**与**花岗岩 : 花岗闪长岩**的争论——泰勒与麦克莱伦的安山岩的模型与巴特的花岗闪长岩的模型关于大陆的硅酸的含量与它的钠与铕的内容的长期的争吵，改变了被引用的地壳的钠 15%，而它的铕的异常一个因子二。**上部的大陆的**地壳（UCC）的成分与**平均的大陆的**地壳（ACC）的成分在不相容的元素上相差一个因子二，因为 ACC 包含着被埋的下面的地壳，而混淆两者是一个痕量元素的论文里常见的错误。**原始的地幔**的成分是一个**计算的残渣**——从一个球粒的起点移走一个被指定的量的玄武岩与熔体而得到的成分——而麦克多诺与孙（1995）、帕尔默与奥尼尔（2003、2014）、沃克曼与哈特（2005）、以及利德尔（2022）的值在 Al、Ca、稀土与高亲铁的元素上相差 10–30%，比一个痕量的元素的比与一个原始的地幔或球粒的值比较时的差异更大。规则是：**一个被归一化的痕量的元素的比必须陈述使用着哪个归一化**，两个行为相似的元素（La/Nb、Ba/Th、Sm/Nd）的比对选择是稳健的、而两个行为不同的元素（Rb/Sr、Lu/Hf、Th/U）的比不是，而在一个不相容的元素里几个百分点的“富集”或“亏减”的主张根本不是一个主张。
:::

## 通向何处

丰度背后的核的物理在 [[physical-geology/earth-interior]] 与 [[planetary-science/formation]]，凝聚与陨石的记录在 [[planetary-science/meteorites]]，熔融里被使用的分配系数在 [[mineralogy-petrology/magma-evolution]] 与 [[geochemistry/trace-elements]]，水的化学在 [[geochemistry/aqueous-geochemistry]]，风化的后果在 [[geochemistry/weathering-chemistry]] 与 [[geomorphology/weathering]]，而建立在丰度上的同位素的系统在 [[geochemistry/geochronology]] 与 [[geochemistry/radiogenic-tracers]]。

::: quiz
一个元素 X 有一个 $z/r = 12$ 的离子的电位。预言它在一个红土里的行为。
- [ ] 它作为一个自由的水化的阳离子在地下水里积累着。
- [x] 它形成一个氧的阴离子或一个可溶的阴离子的配合物，而从剖面里被淋滤。
- [ ] 它是不活动的，而留在残余的土壤里。
- [ ] 它进入橄榄石的结构。
::: solution
一个在约 9 以上的离子的电位意味着阳离子不能作为一个未配位的物种在水里存在，而形成一个**氧的阴离子**（硅酸、磷酸、硫酸、铬酸、钼酸、铀酸）。这样的物种是阴离子，所以它们不被带负的电荷的黏土的交换的复合体保持住，而它们被**淋滤**——带着磷酸与砷酸的重要的例外，它们被强烈地吸附在铁与铝的氧化物上。红土的剖面因此在 $z/r > 9$ 的元素上被亏减、而在作为残余的氧化物沉淀着的 $2.6 < z/r < 9$ 的水解的阳离子（Al、Fe、Ti、Th、REE）上被富集。
:::
:::

::: summary
- 元素的丰度由核合成设定，而奇偶的哈尔金斯规则使偶数的 $Z$ 的元素比它们的奇数的 $Z$ 的邻居丰富 10–1000 倍。
- 凝聚的序列使地球在易挥发的元素上被亏减一个按凝聚的温度缩放的因子，跨着四个数量级。
- 戈尔德施密特的分类——亲石、亲铁、亲铜、亲气——预言着一个元素进入哪个储层，而地核持有着地球的镍的 88%。
- 在水的存在下离子的电位 $z/r$ 接管着：低的值给出海水的阳离子，中间的值给出不活动的水解的产物，高的值给出氧的阴离子。
- 丰度的表是模型、不是数据，而任何被归一化的比必须陈述它的参考。
:::

## 练习

::: exercise 奇与偶 {level=1 check="14"}
用 $\log\varepsilon$：Mg 7.60、Al 6.45、Si 7.51、P 6.64、S 7.12、Cl 5.50。找出 Mg/Al 与 Si/P 的比，而辨别它们说明着的规则。
::: solution
$\mathrm{Mg/Al} = 10^{1.15} = 14$、$\mathrm{Si/P} = 10^{0.87} = 7.4$。两个是**偶–奇**的对，而两个偶数的 $Z$ 的元素更丰富——奇偶的哈尔金斯规则。效应在这里比 Ca/Sc 更小，因为 $\alpha$ 的过程的元素 Mg、Si、S 各自被增强着。
:::
:::

::: exercise 离子的电位 {level=1 check="2.8"}
找出 Mg$^{2+}$（$r = 0.72$ Å）与 Si$^{4+}$（$r = 0.26$ Å）的离子的电位，而给每一个分类。
::: solution
Mg$^{2+}$：$2/0.72 = 2.8$，临界的——它大体上作为一个自由的水化的阳离子持续着，这是镁是海洋的第二个阳离子的理由。Si$^{4+}$：$4/0.26 = 15.4$，远在 9 之上——它形成硅酸的阴离子，而从不在水里作为一个自由的阳离子出现。
:::
:::

::: exercise 亏减的因子 {level=1 check="1490"}
CI 球粒陨石含着 $812\ \mathrm{ppb}$ 的铅、而原始的地幔含着 $0.545\ \mathrm{ppb}$。找出亏减的因子，而从 $T_{cond} \approx 540\ \mathrm{K}$，给铅分类。
::: solution
$D = 812/0.545 = 1490$。铅是一个**高度易挥发的亲铜的与亲石的**元素，而它的 1500 倍的亏减是它的非常低的凝聚的温度与它向一个铁硫化物的相的部分的损失的综合的效应。它是硅酸的地球里任何非气体的元素的最大亏减。
:::
:::

::: exercise 质量百分点到原子百分点 {level=2 check="61"}
把地壳的无氧化物的成分 O 46.6、Si 27.7、Al 8.1、Fe 5.0、Ca 3.6、Na 2.6、Mg 2.1、K 2.4 wt% 转换成原子百分点。
::: solution
除以原子的质量（16.0、28.09、26.98、55.85、40.08、22.99、24.31、39.10）而归一化，原子的百分点是 **O 61、Si 21、Al 6.3、Fe 1.9、Ca 1.9、Na 2.4、Mg 1.8、K 1.3**。氧是地壳的原子的 61%、而它的质量的 47%，而地壳基本上是一个**被堆积的氧的晶格**、而阳离子在间隙的位置上——这是硅酸盐的晶体化学是一个氧的晶体化学的理由。
:::
:::

::: exercise 一个地核的质量平衡 {level=2 check="4.6"}
如果整体的硅酸的地球含着 $900\ \mathrm{ppm}$ 的硫、而地核含着 $14\ \mathrm{wt\%}$ 的 S，找出整体的地球的硫的含量，取地核为 $32.5$、地幔为 $67.5\ \mathrm{wt\%}$。
::: solution
$$
C_{地球} = 0.325\times14 + 0.675\times0.090 = 4.55 + 0.061 = 4.6\ \mathrm{wt\%}.
$$
地幔只持有着地球的硫的 $0.061/4.6 = 1.3$%，而整体的地球的 $4.6\ \mathrm{wt\%}$ 的硫——远在 CI 的 $5.4\ \mathrm{wt\%}$ 附近、而远在一个易挥发性被亏减的地球本该有的之上——是"过剩的硫"的问题：硫太丰富了，不可能作为一个易挥发的物质被失去，而太亲铁了，不可能留在地幔里。
:::
:::

::: exercise 一个锯齿的幅度 {level=2}
奇偶的哈尔金斯的幅度常被引用为一个 10 到 1000 的因子。用 Ca/Sc（1550）、Ti/Sc（63）、Fe/Mn（117）、Ni/Cu（107）、Rb/Sr（0.03）与 Y/Zr（0.30）这些对，决定哪些对是规则的干净的检验、哪些不是。
::: solution
**干净的检验**是**相邻的**、有着相似的核合成的起源的元素的对：Ca/Sc（1550）、Ti/Sc（63）、Fe/Mn（117）与 Ni/Cu（107）都显示着偶数的元素被富集，而它们的幅度跨着被引用的范围。

**不干净的**是 Rb/Sr 与 Y/Zr。铷（$Z = 37$）与锶（$Z = 38$）都是奇–偶的，但它们也是**s 的过程**的核素，它们的丰度由中子的捕获的分枝设定、不是由配对的项，而铷 还是一个在地球上被亏减的中等的易挥发的元素。钇（$Z = 39$）与锆（$Z = 40$）都是**耐火的**，而锆是一个 $r$ 的过程与 $s$ 的过程的核素，它的丰度由 $N = 50$ 的中子的魔术的壳设定。教训是奇偶的哈尔金斯规则是一个**核的结构**的效应，而它只能在两个元素的核合成的与挥发性的历史被匹配的地方被干净地读出——这就是规则在轻的元素 $6 \le Z \le 30$ 里被看得最好、而在重的元素里变成一个弱的信号的理由。
:::
:::

::: exercise 地壳、地幔与正交的比 {level=3 check="6.3"}
原始的地幔有 Rb $0.605\ \mathrm{ppm}$、Sr $19.9\ \mathrm{ppm}$；上部的大陆的地壳有 Rb $60\ \mathrm{ppm}$、Sr $313\ \mathrm{ppm}$。找出每一个的 Rb/Sr 的比与它们之间的分馏的因子，而解释为什么 K/Rb（地幔里 397、地壳里 418）基本上未被分馏。
::: solution
$$
\left(\frac{\mathrm{Rb}}{\mathrm{Sr}}\right)_{地幔} = \frac{0.605}{19.9} = 0.030, \qquad
\left(\frac{\mathrm{Rb}}{\mathrm{Sr}}\right)_{地壳} = \frac{60}{313} = 0.192,
$$
所以地壳在铷上相对于锶被富集了一个因子
$$
\frac{0.192}{0.030} = 6.3 .
$$
这个六次的分馏，在 $4.5\ \mathrm{Gyr}$ 的地壳的形成上被积分，是大陆的地壳在 $^{87}\mathrm{Sr}$ 上是放射性的、而亏损的地幔是非放射性的理由，而它是物源分析里、在年代学里、在海水的演化的研究里的锶的同位素的方法的全部的基础。

K/Rb 的比**不**被分馏，因为钾与铷在化学上几乎相同：两个是碱的阳离子，两个是每一地幔的相里最不相容的元素，而它们的分配系数相差一个二或三的因子、而不是把铷与锶分开的十或更多的因子。一个熔体比钾更有效率地取走铷 30%，使两个的比在**残渣里是不变的**，因为两个基本上被完全地抽出。这是一般的规则：**两个同样不相容的元素的比是一个源的示踪剂，而两个不相等的相容的元素的比是一个分异的示踪剂**——这就是 K/Rb、Zr/Nb、Sm/Nd、Al/Ti 与 $^{143}\mathrm{Nd}/^{144}\mathrm{Nd}$ 读着源、而 Rb/Sr、Lu/Hf、Th/U 与 Re/Os 读着熔融的理由。

例外是 K/Rb 被任何分馏碱金属本身的过程重置：蒸发岩与卤水的相互作用，钾长石在高级别上的分解，以及一个伟晶岩或一个过碱性的熔体的极端的分离的结晶，在其中 K/Rb 落到 100 以下。一个 K/Rb 为 400 的地壳的样品因此既未被强烈地蚀变、也未被强烈地分馏，而它的 0.19 的 Rb/Sr 能作为一个原生的分异的签名被读出。
:::
:::

::: exercise 后期的薄盖 {level=3 check="1.7"}
铱是这么强地亲铁，以至于在一个核的形成之后地幔本该基本上不含它，而原始的地幔含着 $3.5\ \mathrm{ppb}$ 的 Ir、CI 球粒陨石含着 $140\ \mathrm{ppb}$。如果地幔的全部的铱在一个核的形成停止之后被添加，靠一个球粒的物质的"后期的薄盖"，找出薄盖的质量作为地幔的百分点、以及整体的地球的百分点。
::: solution
简单的稀释给出
$$
f_{地幔} = \frac{3.5}{140} = 0.025 = 2.5\ \text{per\ cent of the mantle},
$$
而由于地幔是地球的 67.5%，
$$
f_{地球} = 0.025\times0.675 = 0.017 = 1.7\ \text{per\ cent of the bulk Earth}.
$$
地球的质量的 1.7% 的一个球粒的薄盖——$10^{23}\ \mathrm{kg}$，约一个大的一颗小行星的质量乘上一百，在几亿年里被输送——也将输送地幔的整个的黄金、铂、钯、铑、钌、锇与铼的预算，而供给地幔的水、碳与硫。

出版的估计是整体的地球的 **0.5 到 1%**、而不是 1.7，而差异来自三个地方。原始的地幔的铱的丰度被一个因子二地不确定着，因为 HSE 是极端的异质的、而"原始的地幔"是一个计算的成分。不是薄盖的全部的铱留在地幔里——一些被吸积本身的撞击的熔体循环进了地核，所以被要求的薄盖更大、不是更小。而地幔的 HSE 的一部分可能是**原生的**，被保留着，因为核的形成的最后的阶段发生在高压与高温上，在那里金属–硅酸的分配系数比在一个大气上低得多，在鲁比与弗罗斯特与韦德与伍德与哈里戴与里希特斯（哈里戴）的"深部的岩浆洋"或"平衡"的模型里，在其中不需要薄盖。

区分的证据是**同位素的**。锇的同位素的系统学区分着一个球粒的薄盖与一个残余的原生的地幔，因为薄盖将携带着一个球粒的 $^{187}\mathrm{Os}/^{188}\mathrm{Os}$、而一个分异的天体不会，而测量的地幔的值在几个百分点之内是球粒的。现在的共识是一个**约地球的质量的 0.5% 的一个后期的薄盖，带着一个比 CI 更接近一个亏损的、贫的挥发分的球粒的成分**，在一个吸积的结束之前被输送——而薄盖与高压的平衡的模型之间的争论未被关闭，而它是宇宙化学里最活跃的之一。
:::
