分类是课程校准的像素变成答案的地方：一个标签，一个分数，一张改变的图——因此是课程的错误变成结论的地方。统计的问题诱人地简单：用一个训练的模型把每一个像素的反射率的向量分配到一个类别（森林，玉米，沥青，水）、类别的一个比例，然后诚实地说 产生的图有多好。困难是像素不是干净的类别条件的分布的独立的样本——它们是带着相关的错误的空间的自相关的混合物，被它们的假设（高斯的，线性的，独立的，平稳的）景观按顺序违反着的模型分类着——评估的问题至少和分类的问题一样难，参考的数据花费着钱与野外的季节、分类的像素不花费着什么。本课建造着经典的机械（最大似然的统计的分类器，支持向量的机，2010 年代的随机的森林与提升的树的默认，2020 年代的卷积与基础网络的波），精度的评估的经典（错误的矩阵，生产者与用户的精度，卡帕与它的现代的批评者，样本的设计的文献，为制图的面积的主张修复着"精度"的面积调整的估计量），三个家族的改变的探测（分类后的比较，图像的差分与辐射的归一化，2015–2025 的深度学习的直接的改变的建筑），带着它们共享的报应：把改变与前一课的校准的链条的未移走的差异区分开。先决的条件是图像的课的表面反射率、条件概率的统计，回报是读一张土地覆盖的产品的精度的报告的能力——写一张在审查中幸存的。

::: definition 分类器：从似然到森林到网络 {#def-classifiers}
**统计的（似然的）家族**把分类当作密度的估计：从一个训练的像素估计每一个类别的光谱的概率的密度、靠最大的后验分配（1970 年代的最大似然的分类器，假设的高斯的——这就是它的教科书的行为、带着多峰的类别与小的训练的集合的已知的失败仍然结构化着文献的基线的理由）；它的实践的后代是辐射的一课的光谱的混合的模型（概率的解混合是分类的软的表亲）、保留着领域继续需要的不确定度的高斯过程的与贝叶斯的分类器。**间隔与核的家族**——支持向量的机（1995–2010 年代的最大间隔的分类器，它的核的技巧用少的训练的像素处理着非线性的边界，高维的与高光谱的问题的 2005–2015 的默认，2010 年代的互相比对的文献把它对 C 与伽马的超参数的敏感记录为足以悄悄地摆动几个百分点的总体的精度）——在实践中让位给**树的集成的家族**：随机的森林（带着随机的特征的子集的装袋的树，土地覆盖的 2010 年代与 2020 年代的役马，它的袋外的错误是一个免费的和诚实的验证，它的变量的重要的图是应用的遥感的最被引用、最被滥用的诊断）、梯度提升的树（XGBoost 与 LightGBM，统治着 2020 年代的国家的与全球的产品的基准的竞赛获胜的精炼）；集成的真正的礼物是对非高斯的混合物的容忍，对单一日期的光谱不能利用着的纹理、地形、物候的协变量的本地的处理，——对时间序列的分类关键的——从密的 Sentinel 与 Landsat 的堆栈的数百个特征的干净的处理（2015–2025 的连续算法与连续的平台与随机的森林的物候的研究）。**深度学习的家族**在每一个阶段进入：为空间的上下文的卷积的网络（2015–2020 的分割的时代，为建筑、路、田的 U-Net 的建筑），在图像的序列之上的循环的与变换器的模型（2020–2025 的 sPLINK 与 DeepTime 与 TTAE 的谱系，以更高的成本与梯度的提升竞争的基准），2021–2025 的基础模型（Prithvi 与 SatMAE 与 DINO 式的预训练的编码器在标签稀有时承诺着少样本的分类——承诺是真实的，2024–2025 的评价清醒的：预训练在训练的数据真正的少、领域真正的相似时最有帮助）。三个跨切的事实：分类器很少是瓶颈（2019–2024 的互相比对一贯地发现着训练的数据的质量与设计以比任何一个算法的优势大的边际统治着模型的选择）；特征与温度胜过建筑（添加雷达、DEM、物候的协变量比把随机的森林换成一个网络移动着更多的精度）；每一个家族的输出是一个精度评估然后必须诚实地对待的概率，因为一个校准的 70 个百分点的概率、一个过度自信的 99 个百分点的不是同一张穿着不同的衣服的图。
:::

::: definition 精度的评估：矩阵，统计，设计 {#def-accuracy}
**错误的（混淆的）矩阵**是领域的首要的文档：行是参考的类别，列是制图的类别，从它每一个诚实的统计是一个比——**总体的精度**（迹除以 n，遥感的最被报告、最无信息量的数字），**生产者的精度**（一行的对角的份额：一个真实的森林的像素被制图为森林的概率；遗漏的补），**用户的精度**（一列的对角的份额：一个制图的森林的像素是真实的森林的概率；委托的补）——生产者的与用户的是使"95 个百分点的精度"在类别在大小、在它们的错误的方向上不同时无意义的类别特定的对。**卡帕**（机会校正的一致 $(p_o-p_e)/(1-p_e)$）赢得了数十年的统治、为 2013 与 2020 年代的批评（斯特利–富迪、拉塞尔–古德曼的线）成为标准的好的理由失去了它：它依赖着分类自己的边际（所以两个同样好的带着不同的类别的平衡的图得到不同的卡帕），它在研究之间不可比较，它回答着一个比用户问的问题（我的制图的面积对吗？）更窄的问题（超出机会的与参考的一致）；它作为一个遗留的可比较的统计幸存着，在矩阵旁边报告着，绝不在它的替代。**面积调整的精度**是制图的面积的主张的现代的修复：因为参考的样本从图（从分层的设计）抽取，天真的逐类别的精度必须按制图的面积重新加权（2014–2016 的麦克罗伯茨与弗兰克–科达尔与奥洛夫松的分层后与分层的评估的框架，现在是全球的产品的标准：ESA WorldCover、ESRI LC、Dynamic World 的精度的报告用着它写成），精度、面积上的置信区间必须携带着抽样设计（分层的参考的数据的错误加权的二项的方差、不是天真的二项的、区间撒谎着）。**样本的设计是决定着其余的一切的预算**：评估的概率的抽样（简单的，分层的，系统的随机的）对着便利的抽样（照片解译员偏爱的站位）悄悄地偏向着每一个下流的数字；逐层的样本的大小（稳定的生产者的精度的每少数类别 30 到 50 的地板，奥洛夫分的分层的设计的分配规则）；2020 年代的众包与 VHR 图像的文献继续重新发现的参考的数据的诚实的问题——一个参考的标签自己是一个带着它的自己的错误的分类，参考与图的错误相关（两者对同一个阴影错）时，矩阵奉承着图。经典的最后的条目是**空间的结构**：分类的错误成簇（错误分类的田在它的正确分类的双子旁边），假设着独立的样本计算的精度统计低估着不确定度（2010 年代与 2020 年代的有效样本的大小的文献），图应该用错误的图与局部的精度的表面、不只是全局的标量评估——GIS 的课将对地理的每一个统计做的同一个空间的依赖的论证。
:::

::: definition 改变的探测：三个家族与它们的混淆 {#def-change}
**分类后的比较**（分类着两个日期，叠着图）是最老的、最鲁棒的家族：它对折磨着直接的比较的辐射的差异不敏感（每一个日期的大气与照明被它自己的分类器吸收），它产生可解释的从到矩阵，它的成本是两个分类的错误的复合（一个改变的探测的精度对稀有的改变大致是两个图的精度的乘积——练习的基础率的算术）、它对微妙的连续的改变的盲。**直接的图像的比较**在图像自己上工作：逐带的差分与比（1970 年代的河与裸的土壤的改变），指数的差分（dNBR 的燃烧的严重性的惯例，NDVI 的异常的文献），**辐射的归一化**的方法（1990 年代–2020 的直方图的匹配与伪不变的目标的回归，在单独的校准不能时使两个日期可比较），阈值化的差的家族，它的阈值的选择是一个基础率的谬误将惩罚着的 ROC 的决定；它的美德是对连续的与亚像素的改变的敏感，它的恶习是任何未校准的大气的、物候的、BRDF 或配准的差异与目标的改变进入同一个差分的图像——图像的课的配准的例子是典范的演示。**特征与对象的比较**逐日期提取可比较的几何的对象（海岸线的文献的雷达与光学的指数的水线，冰川的边缘，路的图，建筑的足迹），比较着对象、不是像素——因为对象在五个十年的传感器的改变中幸存着，没有任何像素的统计做得到——长历史的记录的家族（地貌与海岸的文献的 1973–2020 的 Landsat 的水线与岸线的谱系）背后的。**直接的深度学习的家族**（2018–2025 的暹罗的与全卷积的改变的建筑——在 LEVIR-CD、S2Looking、OpenChangeCD 的套件上基准化的 BIT 与 ChangeFormer 与 SiamCDN 的谱系）端到端地学习着差异，统治着建筑改变的基准，继承着每一个 2018 之前的混淆不变：在干净的共同配准的配对上训练与评估，它对配准的伪影安静地优秀、对物候安静地错，这就是 2023–2025 的操作部署的论文在增强与领域转移上花着比建筑更多的页面的理由。跨着所有的家族解释的经典是一句话，警告的一节带着牙齿重复着它：**一个差异不是一个改变**——改变要求把差异对着备择的（照明，大气，物候，几何，传感器）归因于感兴趣的表面的过程，研究的设计（季节的配对，协调化，消融）是归因。
:::

::: example 全球的土地覆盖的产品：行星规模的精度的报告 {#ex-global-products}
2020–2025 的全球的土地覆盖的波——ESA WorldCover 2020 与 2021（$10\ \mathrm{m}$，在 Sentinel-1 与 2 的堆栈上的随机的森林，面积调整的评估报告着约 73–76 个百分点的总体、发表的逐类别的表），谷歌的 $10\ \mathrm{m}$ 的年度的土地的改变（2023 与 2024 的科学论文的时代的评估，约 74 个百分点），ESRI 与卡内基与 ETH 的 $10\ \mathrm{m}$ 的年度的土地覆盖（2021 的发布与它的约 75 个百分点的独立的评估），Dynamic World 的近的实时的 $10\ \mathrm{m}$ 的概率（2021–2025 的操作的谱系）——最好作为一个精度的评估的大师课来读：全部四个由树的集成或它们的近的表亲在雷达加光学加物候的特征上建造（特征胜过建筑的发现，在规模上）；全部四个发表由带着面积调整的估计量的分层的概率的抽样计算的错误的矩阵（作为家庭的风格的定义框架）；全部四个在它们的错误里显示着同样的结构——湿地与红树林与树和草地的混淆，耕地的马赛克在每一处的混淆，精度表面追踪着参考的数据的经济（欧洲与北美的评估依靠着密的照片的解释的基础设施，中非与亚马逊在更稀的、更不确定的参考上）。用户实际需要的比较在类别的行里、标题：一个需要水对着植被的分离的洪水的研究在全部对该对约 90 个百分点的产品之间选择，一个泥炭与红树林的研究在 40–60 个百分点、彼此不同意比它们与地面同意更多的产品之间选择——发现着在标题的精度相差一个点的产品之间红树林的面积相差几十个百分点的 2022–2025 的蓝的碳的互相比对。例子一般化到每一个产品的论文：读着类别的行，读着置信区间，读着参考的数据来自何处，把总体的精度当作表里的最无信息量的数字。
:::

::: example 燃烧的面积与 dNBR：一个指数，两个职业 {#ex-burned}
火的计划的产品链在一个管道里显示着分类与改变：MODIS 与 VIIRS 的燃烧的面积的产品（MCD64A1 与它的继承者，2006–2025 的谱系）靠一个突然的短的波的红外的反射率的下降、近红外与 NDVI 的下降探测着燃烧——一个它的活的火与热点的共同输入、它的小的斑块的遗漏（2010 年代与 2020 年代的评估：地中海与北部的小的燃烧被几十个百分点少计，2020 的澳大利亚与西伯利亚的事件的互相比对）是定义的种类的记录的类别的行的改变的探测的分类器；Landsat 的 dNBR（差的归一化的燃烧比，USGS 与 MTBS 的惯例：火的前的 NDVI 减 NIR 的合成减去火的后的，缩放，按着燃烧的严重性的类别阈值化）把同样的光谱的物理变成一个严重性的图，它的精度是一个单独的、更谦逊的主张——发现着 dNBR 与野外的严重性的 0.5–0.8 的相关在最高的严重性的尾部（饱和）、在混合的冠层的林下的燃烧里削弱、在火的后的场景在敏感的头几个月里被云与阴影污染的任何地方（火的后的侵蚀的研究的配准与亮度的混淆）的 2010 年代–2025 的野外的样地的验证的文献。两个职业是课：作为一个探测器，指数是操作的、全球的，它的错误被知道与制图；作为一个严重性的测量，同一个指数是一个带着站点的依赖的校准的代理，2020 年代的管理的文献的规则（在用它分配恢复的钱之前把 dNBR 校准到本地的样地）是图像的课的指数谬误的纪律应用于改变。第三个职业是推断：喂养着气候的变化的影响的课的碳核算的燃烧严重性的图，不带误差条地继承着上面的验证的相关——空间的分析的课将明确地做的传播的问题。
:::

::: example 用深度网络的城市制图：建筑，基础率，欺骗了一个大陆的精度 {#ex-urban-deep}
从 $0.5\ \mathrm{m}$ 的图像自动的建筑提取（2018–2025 的 U-Net 与掩蔽 R-CNN 的时代，WHU 与 inDRA 与 DFC 的基准，2023–2025 的基础模型的转移）是领域最诱人的分类器、它的最有教育意义的精度故事。诱惑：在基准的城市上 0.8 以上的交并比的分数，视觉上完美的屋顶的轮廓，看来像解决的基础设施的数据的大陆规模的产品（2022–2025 的谷歌与微软与 OpenAerialMap 的建筑的层，数十亿的足迹）。有教育意义的部分是基准之外发生的：向非正式的定居点与农村的院落的转移（训练的领域的盲点——发现着用户的精度在基准的数字之下 15–30 个点的 2021–2025 的非洲城市的评价），向阴影与冠层模仿着屋顶的多山的与林地的地形，最重要的是向**稀有事件的统计**：当建筑是像素的 2 个百分点，一个带着 95 个百分点的特异性的探测器仍用错误的正淹没着图（练习的基础率的算术，洪水的制图的验证的文献在 2015–2020 学到同样的数学），这就是严肃的 2023–2025 的产品在多个阈值上发布着精确与召回的曲线、逐上下文的精度的表（世界银行与 Global HumanitySet 时代的评估）代替总体的精度、消费着建筑的层的人口与暴露的模型现在通常对探测器的错误的正率运行着敏感的分析——空间的分析的课一般化着的下流的确定度的链的理由。深度学习的波改变了在仪器化的基准上的分类的天花板；精度的评估的经典在训练的数据从未去过的地方使着波的输出诚实。
:::

::: example 毁林的警报：三个系统，三个错误的预算 {#ex-deforestation}
热带的森林的损失的监测现在运行着三个操作的改变的系统，它们的差异是改变的探测的定义的家族在生产中：Hansen 全球的森林的改变的损失年的记录（2000–2024，基于 Landsat，$30\ \mathrm{m}$，年度的——一个分类后的与轨迹的混合，它的精度从均一的北部与温带的森林的 90 以上个百分点到干的森林与马赛克的稀树草原的 60 多，它的损失信号对选择性的伐木、旱、火、清理敏感），基于 RADARSAT-2 与 Sentinel-1 的 RADD（2021–2025 的雷达的警报，设计的抗云的，周的潜伏，为亚马逊的湿的季节的清澈调着的），GLAD 与 RADD-L（Landsat 与 Sentinel-2 的光学的警报，天的潜伏，云的限制的），2022–2025 的互相比对的文献（刚果与亚马逊的警报的融合的研究）定量着家族预测着什么：雷达的警报抓住着光学的系统错过的湿的季节的清理，光学的警报抓住着雷达的阈值平滑掉的小的与部分的扰动，每一个系统的错误的正集中在同样的地方——再生的次生的森林的边缘，遮荫的咖啡与农林的马赛克，洪水的森林与伐木的痕迹的混淆，在每年的 1–2 个百分点的损失的流行率上精度的定义的基础率的算术使不可避免的混淆。机构的回报是警告的一节开着的处分的流程：警报（高的敏感性，谦逊的特异性）在野外的验证（定义的设计标准的独立的参考）之前被持续性、上下文（水文学，先前的损失，特许的边界）过滤着，在归因（地球的资源、气候的变化的影响的课消费着的供应链与治理的分析）之前——遥感的改变的产品恰恰作为一个观测的系统应该 运作地：不是一个判决，一个喂养着一个诚实的决定的充分刻画的先验。
:::

::: history 从最大似然到基础模型 {#hist-classification}
**1965–1985。** 分类作为整批进口的模式识别开始：1960 年代–1970 的最大似然与贝叶斯的分类器（Landsat 时代的高斯的假设与它的协方差的病理的文献），沉淀成经典的 1973–1979 的错误的矩阵与精度的统计（1976 的罗森菲尔德与考夫利、1979–1981 的霍恩与柯比与卡迪尔的对总体的精度的批评，1983–1985 的森林的清查的工作标准化的生产者的与用户的对），出现在 1974–1984 的文献里的改变的三元组（Landsat-I 时期的 1984 的辛格科瓦尔斯基与科恩的带的差分、1986 的分类后的比较）。**1987–2012。** 模型的旋转木马转着：神经网络的第一波（1989–1994 的多层感知机的试验），支持向量的机的 1995–2010 的统治（2005–2012 的高光谱的 SVM 的文献），1990 年代–2000 的分类的树与集成的谱系（随机的森林的 2001 的方法的论文在 2000 年代中期进入遥感），开始的精度的批评的时代（2002–2012 的卡帕的依赖的分析，2013 的斯特利–富迪的论文、2014–2016 的面积调整的估计量的论文转变成现代的评估框架）。**2012–2025。** 深度学习带着使它工作的数据到达（2012 的 ImageNet 年，2014–2018 的卷积的土地覆盖的波，2015–2020 的密的 Sentinel 的时间序列的分类器、2018–2024 的暹罗的改变的建筑），全球的产品时代强迫着开放的精度的报告（用面积调整的经典写成的 2019–2024 的 WorldCover 与谷歌与 ESRI 的评估），2021–2025 的基础模型与少样本的文献——预训练的编码器，提示与适应的转移，基准的改革的争论——重新打开着 2010 年代的随机的森林的共识关闭的问题：模型、数据，能否是瓶颈，带着 2025 的回答仍是领域最老的：它取决于标签来自何处。
:::

::: quiz {#quiz-producer-user}
一个湿地的类别有着 55 个百分点的生产者的精度、90 个百分点的用户的精度。图：

- [x] 遗漏着许多真实的湿地，它确实制图的湿地几乎总是真实的
- [ ] 制图着所有的真实的湿地、添加着许多假的
- [ ] 有着平衡的错误、中等的总体的精度
- [ ] 没有卡帕的值无法评估

::: solution :::
生产者的精度是行的份额（真实的湿地正确制图的——55 个百分点意味着 45 个百分点遗漏），用户的是列的份额（制图的湿地是真实的——90 个百分点意味着少的委托的错误）：全球的产品湿地行的经典的保守的探测者的剖面。选项 B 交换着两个精度；选项 D 把一个遗留的汇总的统计误认为它汇总着的矩阵。
:::
:::

::: quiz {#quiz-change}
一个对着野外的样地验证的 dNBR 燃烧的面积图在一个北部地区显示着 92 个百分点的总体的精度、在地中海的马赛克 61 个百分点。最可能的解释是：

- [x] 类别的流行与混合：在均一的北部的森林里稀疏的、高对比的燃烧，在破碎的地中海的景观里小的、混合的、低对比的燃烧
- [ ] 地中海的传感器有着更差的辐射的校准
- [ ] 野外的样地在地中海的地形里不可能
- [ ] 北部的地区有着更少的无云的场景

::: solution :::
精度追踪着景观的对比与尺度、不是传感器：同一个算法在同一个数据的制度里表现如其最稀有的重要的类别允许得一样好（全球的产品例子的类别行的规则，练习的基础率的算术）。校准（B）设计的区域独立；样地在地中海到处存在（C）；云（D）影响着数据的可获得性，场景被获取时的验证的设计。
:::

## 练习

::: exercise {level=1 check="90"}
一个错误的矩阵有着 1000 个参考的像素，900 个被正确地制图。总体的精度（百分点）是多少？
::: solution :::
$900/1000 = $ **$90$ 个百分点**——精度的警告在一个数字里：如果 900 个正确的像素的 850 是统治的类别，图的稀有的类别仍是灾难，这就是迹是报告的起点、绝不是结论的理由。
:::
:::

::: exercise {level=1 check="80"}
在 50 个参考的森林的像素中，40 个被制图为森林。森林的生产者的精度（百分点）是多少？
::: solution :::
$40/50 = $ **$80$ 个百分点**——行的份额，意味着 20 个百分点的真实的森林被遗漏在矩阵的非对角的某处；接下来读着列的份额，因为一个隐藏着一个 50 的用户的 80 的生产者是一张到处找到着森林、遗漏着许多的图，与湿地的测验的保守的探测者相反的错误预算。
:::
:::

::: exercise {level=1 check="75"}
在 60 个制图为耕地的像素中，45 个在参考里是耕地。耕地的用户的精度（百分点）是多少？
::: solution :::
$45/60 = $ **$75$ 个百分点**——列的份额：制图的耕地的四分之一是别的东西（2020 年代的全球的产品文献的耕地行，每一个互相比对的最委托倾向的类别），一个消费着图的碳与粮食安全的模型应该作为它的输入的不确定度携带着的数字、三行以外的总体的精度。
:::
:::

::: exercise {level=2 check="0.8"}
一个分类有着 0.90 的总体的精度、0.50 的机会的一致。计算 $kappa = (p_o-p_e)/(1-p_e)$ 到两个位的小数。
::: solution :::
$kappa = (0.90-0.50)/(1-0.50) = 0.40/0.50 = $ **0.80**——批评在一个比较里：对着一个 0.94 的机会的一致（一个统治的类别的图）的同一个 0.90 的总体的精度产生卡帕 0.17（第三级的练习），这就是卡帕的辩护者与批评者在其算术上同意、在一个数字是否应该携带着错误的矩阵完整地陈述着的判决上不同意的理由。
:::
:::

::: exercise {level=2 check="180"}
一个分层的精度的设计把至少 30 个参考的样本分配给 6 个类别的每一个。最小的总的样本的大小是多少？
::: solution :::
$6 \times 30 = $ **180**——样本的设计的地板（稳定的生产者的精度的每少数类别 30–50），精度的预算是野外的季节的预算的理由：2020 年代的全球的产品评估花费着数十万的照片解释的点，恰恰因为稀有的类别的行、标题，是置信区间生活的地方。
:::
:::

::: exercise {level=2 check="600"}
分类后的比较在日期 1 把森林制图为 $5000$ 公顷、在日期 2 为 $4400$ 公顷。表面的森林的损失（公顷）是多少？
::: solution :::
$5000-4400 = $ **$600$ 公顷**——表面的改变，定义的复合的错误的论证立即限定着：带着每日期森林用户的与生产者的精度的 90 个百分点，两个图的错误单独能把估计移动几百公顷，诚实的陈述是 $600 \pm$（错误传播的区间），2010 年代与 2020 年代的毁林的会计的文献在面积的改变上的置信区间恰恰是那传播被明确。
:::
:::

::: exercise {level=3 check="0.17"}
一个统治的类别的图有着 0.95 的总体的精度、0.94 的机会的一致。计算卡帕到两个位的小数。
::: solution :::
$kappa = (0.95-0.94)/(1-0.94) = 0.01/0.06 = 0.167$，约 **0.17**——一张 95 个百分点正确、几乎无价值的图，基础率的谬误的精度的报告的对应：每当流行高，总体的精度必须对着机会读（更好的，对着作为这张图的真实的成绩单的稀有的类别的行）。
:::
:::

::: exercise {level=3 check="0.6"}
一个平衡的 2 类别的矩阵：100 个参考的森林的像素（80 个制图为森林）、100 个参考的非森林的像素（80 个制图为非森林）。带着 $p_o = 0.80$、$p_e = 0.50$，计算卡帕。
::: solution :::
$kappa = (0.80-0.50)/(1-0.50) = $ **0.60**——在第一级的练习的不平衡的矩阵里得分 90 总体的同一个逐类别 80 个百分点的表现现在对着平衡的机会得分 0.60 卡帕：精度的定义的卡帕的批评称为对跨研究的比较致命的边际的依赖，计算着两次以使这一点忘记不可原谅。
:::
:::

::: exercise {level=3 check="0.16"}
改变占据着一个场景的 2 个百分点。一个探测器有 0.90 的真阳的率、0.10 的假阳的率。使用贝叶斯的定理，制图的改变的精确（正的预测的值）到两个位的小数是多少？
::: solution :::
精确 $= (0.90\times0.02)/(0.90\times0.02 + 0.10\times0.98) = 0.018/0.116 = 0.155$，约 **0.16**——一个"90 个百分点敏感的"探测器，它的改变图是六分之五假的正，因为 98 个百分点的未改变的像素以五十比一  压过 着目标：城市的深度学习的例子的基础率的算术，改变的探测的论文报告着精确与召回（单独的敏感性）的理由，操作 的洪水与毁林的警报在任何相信着一个像素之前用上下文的过滤器（持续性，水文学，先前的图）分检着探测。
:::

::: warning 四个分类的谬误
1. **"图是 95 个百分点准确的。"** 对谁准确，关于什么准确？全球的产品例子的结构在每一个区域的研究里重复：一个标题的总体的精度由统治的类别携带，研究的实际的主题（红树林，泥炭地，非正式的定居点）在类别的行里坐在 40–60 个百分点，消费者——一个碳的会计，一个保护的计划者，一个流行病学家——它的错误预算是稀有的类别的、标题的；发现着在感兴趣的制图的面积上相差几十个百分点、标题的精度相差一个点的产品的 2022–2025 的蓝的碳与耕地的互相比对是谬误的代价，带着发票。规则：没有一个产品被引用而不带着它的错误的矩阵，它的面积调整的类别的精度，参考的数据的来源，没有一个模型消费着一个类别而不传播着那个类别的用户的与生产者的对。
2. **"训练与测试的集合是独立的样本。"** 它们是邻居：一个单一的场景的随机的像素的分割把同一个田、同一个照明、同一个传感器的伪影的训练的像素、测试的像素放在线的两边，产生的精度被空间的自相关膨胀着（2018–2024 的块的分层的交叉验证与对象的分割的文献把膨胀测量为几个点——有时数十个点——对空间的结构化的类别），深度学习的基准的同一个城市的训练与测试在研究站位之间复合着错误（转移的评价的 15–30 点的下降）。同一个自相关的论证在精度的定义的有效样本的大小的段落、空间的分析的课的统计里重现：**独立性是一个你设计着的假设、像素拥有的性质**，一个未说明着它的样本如何被分离的每一个精度的主张是一个关于插值的陈述、关于预测的陈述。
3. **"更多的类别，更多的训练的数据，更好的图。"** 分类学与数据必须共同生长：添加一个传感器不能分离的类别（在 $10\ \mathrm{m}$ 的两个作物品种，不带激光雷达的两个林联）添加着混淆、信息——定义的似然的时代的可分离的统计仍然统治着，2020 年代的全球的产品文献的诚实的发现是在 $10\ \mathrm{m}$ 的更粗的、良好分离的分类学在每一个精度的度量上胜过雄心勃勃的；同时添加着同一个便利的站位的训练的像素添加着方差减少的偏向（参考的数据的来源的段落再一次），2010 年代与 2020 年代的样本的选择的文献的结果是十个良好设计的分层的点教着比一百个照片解译员的喜爱的更多。谬误的机构的形式——由类别的计数与像素的计数驱动的产品路线图，因为它们可资助、精度不可——是评估的经典存在、本课继续回到它的理由。
4. **"改变被探测到，因此改变发生了。"** 差分的图像是一个机会均等的信使：真实的改变，物候的转换，大气的剩余，BRDF 与照明的阶梯，配准的边缘，传感器的退化，标签的噪声全部到达在同一个数组里（图像的课的配准的算术，辐射的一课的大气），直接的改变深度网络的基准的卓越——在干净的共同配准的配对上训练——自己是一个演示，模型学着忽略着混淆只在基准移走它们的地方。经典的回答是设计、不是统计：季节匹配的对，协调化的基线，对着伪不变的目标的消融，探测的持续性与上下文的过滤器，分类后的比较作为一个独立的证人；报告的回答是一句话，总是：**检验着哪些备择的解释，用什么，剩余的置信度是什么**——因为在改变的探测里，如同在一个单一的日期的分类里，图是一个关于地面的假设，精度的报告是实验。
:::

::: summary
分类把校准的反射率变成标签与改变，整个的纪律生活在保持两个账里。**模型的账**：似然的分类器的高斯的理想，支持向量的间隔，随机的森林与提升的树的集成（2010 年代–2020 的役马，构造诚实的袋外的错误），深度的卷积与时间的网络、2020 年代的基础模型——互相比对的一致的判决是训练的数据的设计与协变量（雷达，DEM，物候）比建筑移动着更多的精度，模型最后被选择、首先被审计。**评估的账**：作为首要的文档的错误矩阵，作为使标题以最美好的方式无意义的类别特定的对的用户的与生产者的精度，作为一个边际的依赖的遗留的统计的卡帕，作为制图的面积的主张的现代的经典的面积调整的估计量与分层的设计，作为对每一个独立性的假设的税的空间的自相关，作为对忽略着流行的站着的惩罚的基础率的算术（练习的 0.16 精确的探测器）。改变的探测在三个家族里继承着两个账——分类后的比较（鲁棒的，复合的），直接的差分（敏感的，混淆的），特征与对象的比较（长记录的役马）——加上深度学习的直接的改变，直到它的混淆被设计移除。一个土地覆盖的图是一个关于地面的假设，直到它的错误的矩阵、它的设计、它的参考的数据的来源被发表。例子——由它们的类别的行读的全球的产品，dNBR 的两个职业，建筑的提取的基础率的故事——是在行星的、火线的、屋顶的规模的同一个论证，谬误（标题的精度，假的独立性，类别的计数的雄心，差异作为改变）是未保持的账。诚实地评估着图，课程转向着反射的光的机械从未碰过的波长：热的一课的发射的辐射、雷达的一课的相干的回波。
:::
