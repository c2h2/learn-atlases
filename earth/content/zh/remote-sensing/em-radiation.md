每一个卫星图像的每一个像素是一个辐射的测量的量：一个电磁的能的量，在一个定义的波长的带上被收集，从一个定义的立体的角，归属于一个定义的表面一块——整个的遥感学科建立在从那个数字对着产生它的表面向后推理上。在没有物理的情况下向后的步绝不是唯一的：离开一个像素的同一个辐射的亮度能来自一个亮的小的物体或一个暗的大的，来自反射的阳光或发射的热，来自地面、它上面的大气。本课建立着使反演可辩护的物理学——辐射的量的与它们的单位，由普朗克、维恩、斯特藩–玻尔兹曼描述的太阳的与热的来源，过滤着信号、定义着每一个传感器围绕其建造的波长的窗口的吸收与散射，植被，水，土壤，雪，岩石的、它们的混合物充满着每一个的陆地的图像的像素的光谱的签名。先决的条件是 [[earth-system/energy-balance]] 一课的辐射的记账，回报是从这里起，没有一个卫星图像是一张图画——它是一叠物理的测量，每一个有一个来源、一条路径、一个相互作用、一个传感器，每一个解释是一个关于全部四个的主张。

::: definition 辐射的度量：量，来源，窗口 {#def-radiometry}
四个量被混淆的次数比本课程其余的所有的错误加起来还多，混淆不可原谅，因为单位不同。**辐射的通量**（瓦）是功率；**辐射的亮度**（W m⁻² sr⁻¹ 每单位的波长或波数）是每单位的投影的面积、每单位的立体的角的通量——传感器测量的量，它在无损的介质里沿着一条射线守恒，这就是"亮的温度"、"在传感器的辐射的亮度"在距离上有意义的理由；**辐照度**（W m⁻²）是到达（离开）一个表面的每单位的面积的通量，驱动着能量的平衡的量；**反射率**、**发射率**（无量纲，零到一）是把一个转换成另一个的表面性质。来源是两个、只有两个：太阳，一个 $5772\ \mathrm{K}$ 的黑体，它的大气之上的光谱的辐照度在 $0.48\ \mu\mathrm{m}$ 达到峰值、总共 $1361\ \mathrm{W\,m^{-2}}$（太阳的项，在可见到短的波的红外占统治），地球，一个约 $288\ \mathrm{K}$ 的在 $9.9\ \mu\mathrm{m}$ 达到峰值的黑体（热的项，在 $3\ \mu\mathrm{m}$ 之外除了白天的短的波的红外的反射的阳光唯一的）。普朗克的定律给出光谱的形状，维恩的位移的定律（$\lambda_{\max} = 2898/T\ \mu\mathrm{m}$）峰值，斯特藩–玻尔兹曼的定律（$F = \sigma T^4$）积分；基尔霍夫的定律（在平衡里在每一个波长发射率等于吸收率）许可着每带每表面类型的一个发射率的使用。在来源与传感器之间站着大气，它的不透明度不均匀：水汽，二氧化碳，臭氧，氧，甲烷的分子的吸收把光谱刻成**大气的窗口**——可见–近红外（$0.4$–$0.9\ \mu\mathrm{m}$），在 $1.2$、$1.6$、$2.1$、$3.7\ \mu\mathrm{m}$ 附近的短的波的红外的窗口，$3.4$–$4.2$、$4.7$–$5.0\ \mu\mathrm{m}$ 的热的带，大的 $8$–$14\ \mu\mathrm{m}$ 的热的红外窗口，毫米–亚毫米的微波的窗口（带着之间的 $22\text{-GHz}$ 的水、$60\text{-GHz}$ 的氧的线），$1$-cm-到-$1$-m 的、几乎完美的雷达的窗口——而散射（瑞利的，$\lambda^{-4}$，分子的；米氏的，气溶胶的大小的、产生霾的；几何的，云的滴的、白的）衰减着、把路径的辐射的亮度加到在约 $1\ \mu\mathrm{m}$ 之外的每一样短的东西上。本课程的每一个传感器是对"哪个窗口，多宽？"的一个工程的回答、每一个大气的校准是撤销着窗口让通过的算术。
:::

::: definition 双向的反射的分布的函数，双向性，一个"反射率"是什么 {#def-brdf}
一个表面不是一个数字：它反射的光的分数依赖于光从哪个方向来、从哪个方向离开，那个依赖的完整的陈述是**双向的反射的分布的函数**（BRDF），$f_r(\theta_i, \varphi_i, \theta_v, \varphi_v)$，带着 sr⁻¹ 的单位，定义得反射的辐射的亮度等于 $f_r$ 乘以入射的辐照度在半球的积分。三个结果组织着令人惊讶的多的实践。第一，同一个地在两个太阳的角度、两个卫星被测量给出不同的辐射的亮度——推扫的仪器的偏离的天顶的视图的几何，热点的效应（在视图的方向与太阳的方向对齐时变亮，隐藏着冠层里的阴影），高的气团的气溶胶的前向的散射的霾全是 BRDF 与路径的效应，不是表面的改变，16 天的 MODIS、Sentinel-2 的时间的序列必须在"改变"意味着什么之前用一个 BRDF 的模型（MODIS 的陆地的产品的 RossThick-LiSparse 核的模型，Sentinel-2 的表面反射率的处理的基线）归一化。第二，大多数的实践的 量 是 BRDF 的方向的积分或样本：**双半球的反射率**（反照率，半球的积分，能量的平衡的数字），**天底的反射率**（一个垂直看的传感器看到的），辐射的传输的模型使用方向的–半球的反射率。第三，BRDF 是结构显示的地方：一个行的作物的地，一个针叶的森林、一个平的盐盘有着可识别地不同的形状函数、LiSparse 的模型的阴影的项字面上是一个冠层的建筑学的反演。对漫射的照明（阴天，强地散射的蓝的带）方向的记账朝着双半球的情形塌缩，这就是霾之下蓝的带的表面的类型比红的边缘的更难分离的理由。应用的遥感里最普通的定量的错误是把在一个几何采样的一个方向的反射率当作它像一个反照率；最重要的把两个几何的两个反射率当作一个改变的测量。
:::

::: definition 光谱的签名：植被，水，土壤，雪，岩石 {#def-signatures}
五个表面的类型携带着光学的图像的信息的多数，每一个有着一个训练过的眼睛可识别的签名。**绿的植被**由色素与结构统治：叶绿素 a 与 b 在 $0.45$、$0.67\ \mu\mathrm{m}$ 的强吸收、类胡萝卜素在蓝的吸收给出 $0.55\text{-}\mu\mathrm{m}$ 的绿的峰；海绵的叶肉的内部的散射把近红外的高原提升到 $0.75$–$1.3\ \mu\mathrm{m}$ 之间 40–50 个百分点的反射率（一个从 $0.67$ 到 $0.75\ \mu\mathrm{m}$ 陡到它是有仪器测量的最可靠的生命的探测的签名的"红的边缘"的转变）；液态的水的吸收的带在 $1.45$、$1.94$、$2.7\ \mu\mathrm{m}$ 刻着短的波的红外的，所以叶的水的内容、冠层的水与衰老作为带的深度的比读出（近红外对红的 NDVI，光的化学的与结构不敏感的指数，水的指数——全在 [[remote-sensing/image-processing]] 一课里被合理化）。**水**相反：清澈的开阔的水反射着几个百分点、朝着近红外指数地吸收，所以它的签名从蓝的约 5–10 个百分点落下、在 $0.7\ \mu\mathrm{m}$ 之外接近零、水的离开的信号（浊度，叶绿素，着色的溶解的有机的物质）只在蓝–绿活着、在浑浊的情形在一个适度的近红外肩活着——海洋的颜色的整个的学科存在于那个陈述之内（[[oceanography/productivity]] 一课的卫星的叶绿素）。**土壤与岩石**相对地无特征，从可见到短的波的红外的温和地、单调地上升，带着在 $0.48$、$0.86\ \mu\mathrm{m}$ 附近的诊断的铁的氧化物的吸收、亚铁与铁的、氢氧与碳酸盐在 $2.2$–$2.35\ \mu\mathrm{m}$ 的吸收（[[remote-sensing/classification]] 一课的采矿的图的蚀变的矿物学），黏土的 Al-OH 在 $2.2\ \mu\mathrm{m}$、水的带在 $1.4$、$1.9\ \mu\mathrm{m}$ 叠加在像植被的水的特征上；土壤的亮度随着干燥增加、随着有机的物质减少，所以红的–近红外的空间的土壤的线是一条直的、亮的、低的 NDVI 的线，植被的点从它生长离开。**雪**在可见–近红外亮而平，然后通过 $1.5$、$2.0\ \mu\mathrm{m}$ 的冰的吸收崩溃，这就是归一化的雪的指数把绿对着短的波的红外的配对的理由；颗粒的大小使短的波的红外变暗（变老，湿度，污染）、使雪的年龄可定年。**建造的材料**——混凝土，沥青，金属，漆的表面，屋顶——化学地迟钝、几何地响亮：低的短的波的红外的对比，高的镜面敏感，[[remote-sensing/thermal-microwave]] 一课的城市的热与亮的特征。真实的像素是混合物：一个郊区的像素是这些端母的签名按亚像素的覆盖加权的线性（大约的）和、光谱的混合的分析——为分数解着线性的系统——是任何一个粗的像素的诚实的阅读，本课程将使用着的防水的表面、分数的覆盖、燃烧的面积的产品亚像素的基础。
:::

::: example 为什么路径要紧：蓝的天空，霾的带，路径的辐射的亮度 {#ex-path}
取一个清澈的天空的 Landsat 的场景在一个暗的湖之上、一个星期后同一个湖之上的一个霾的场景。湖的真实的反射率没有改变，然而第二个场景的蓝的带的数字化的数远更亮：分子的（瑞利的）散射，带着它的 $\lambda^{-4}$ 的依赖，把从未碰着地面的阳光送进传感器的视线——**路径的辐射的亮度**，相加的、蓝重的——同时通过带的透射率衰减着表面的信号。对它的校准（图像的处理的一课的暗的对象减法，或带着测量的气溶胶的光学的厚度的一个辐射的传输的反演）是一个散射的计算的减法，不是拼凑：减去路径的项，除以透射率，湖回到它的物理的反射率。同一个物理学解释着为什么蓝的带在陆地上是最不可靠的带（最大的路径的项，最强的气溶胶的敏感），为什么在 $0.44\ \mu\mathrm{m}$ 的沿海的气溶胶的带在 Landsat-8、Sentinel-2 存在（它专门于测量其余的带必须移走的东西），为什么日落是红的（长的路径，蓝被散射走了两次），同一个表面为什么在不同气团的两个卫星看来不同。教训一般化：在可见–近红外大气不是一个带着污迹的窗口，它是一个带着可计算的点的扩散的函数的光学的元件，一个未被校准的辐射的亮度的图像是表面与天空的卷积。
:::

::: example 红的边缘：从轨道能看见的生理学 {#ex-rededge}
一个农民的灌溉的地、一个相同的受压的地在任何一个视觉的症状之前几小时在一个卫星读着的两个数字上不同：$0.67\text{-}\mu\mathrm{m}$ 的叶绿素的吸收随着叶绿素降解或变薄而减弱、$0.74\text{-}\mu\mathrm{m}$ 的近红外的高原随着叶肉的结构崩溃在位置上移动。两个效应的比是 NDVI、它的敏感不是一个实验室的珍闻：2000、2001、2012、2022 的旱的与热的异常的耕地的数据的层与 MODIS 的喂养与产量的预报的体系首先是红的边缘与红的带的异常、其次收获的估计，[[earth-resources]] 课程的食物的与水的章的整个的预警的链条建立在被缩放到轨道的红的边缘的量子生物学上。定量的链条有教益：在光谱仪测量的叶的规模的吸收的系数，一个把叶的生物化学连接着冠层的反射率的冠层的辐射的传输的模型（PROSAIL 与它的亲属），一个在传感器的光谱的响应的函数上的带通积分，一个大气的校准到表面的反射率——在一片叶与一个全球的指数之间四个物理的步骤，每一个有发表的错误的项，这就是传感器之间的 NDVI 的互相比对是一个校准的项目（2016–2020 的 CEOS 与 USGS 的工作的表面反射率的协调化）、不是一个公式。
:::

::: example 海洋的颜色：这个行业里最难的辐射的亮度 {#ex-ocean-colour}
在开阔的海洋之上的水的离开辐射的亮度在 $550\ \mathrm{nm}$ 约 $0.1\ \mathrm{mW\,cm^{-2}\,\mu m^{-1}\,sr^{-1}}$——到达卫星的总的辐射的亮度的十个百分点之下，其余是大气的路径的辐射的亮度、表面上的太阳的闪烁。检索它意味着用模型移走 90 多个百分点的信号（1980 年代–2020 的戈登–克拉克–安托万的气溶胶与闪烁的算法），残余的错误的预算是海洋的颜色的历史是一个校准的历史的理由：1978 的 CZCS，1997 的 SeaWiFS（对着海洋的光学的浮标的十年的替代的校准），2002–2025 的 MODIS、MERIS、Sentinel-3、PACE 的谱系，带着 2024 的 PACE 的高光谱的数据最终检验着二十五年的叶绿素的算法的未解决的混合的假设。回报，表面的叶绿素的全球的图、[[oceanography/productivity]] 一课的净的初级的生产的估计，是本课程里一个以一个个百分点的辐射的精度测量的物理的量（SeaWiFS 的要求）是把一张图画变成一个全球的碳的循环的约束的最清楚的个案。
:::

::: example 短的波的红外的矿物学与城市的混合物 {#ex-minerals}
短的波的红外的双重生活的两个演示。第一，蚀变的制图：热液的系统沉积着黏土，云母，碳酸盐，硫酸盐，它们的 Al-OH、Mg-OH、C-O、硫酸盐的吸收落在 $2.0$、$2.5\ \mu\mathrm{m}$ 之间、1999–2025 的 ASTER、HyMap、PRISMA、EnMAP 的斑岩与浅成的地区的线形与矿物的图（[[earth-resources]] 课程的勘探的章）正是签名的定义的吸收的带的深度与匹配的滤波的阅读——氧化的 $0.86\ \mu\mathrm{m}$ 的铁的氧化物，酸性的 $2.20\ \mu\mathrm{m}$ 的白的云母，中和的 $2.33\ \mu\mathrm{m}$ 的碳酸盐，因为涉及的光子是键自己的振动的泛频，一个整个的岩相学在反射率里可读。第二，城市的混合物：一个在郊区之上的 $30\text{-m}$ 的 Sentinel-2 的像素包含着屋顶，路，墙，树，草坪、它的光谱是定义的五个签名的线性混合物、对着端母的图书馆（亮的混凝土，暗的沥青，绿的植被，干的植被，阴影）的受约束的非负的最近平方在验证的站位把分数的覆盖恢复到真实的几个百分点，那些分数——不是原始像素——是防水的趋势、城市的热、洪水的模拟的文献实际消费的。例子的警示的一半：端母的可变性（两个混凝土的屋顶不同；一个阴影的屋顶更不同）是统治的错误项、任何一个它的错误的条不包括它的混合的结果过拟合了。
:::

::: history 从两个暗的点到校准的光子 {#hist-radiometry}
**1800–1900。** 威廉·赫歇尔（1800）在光谱的红端之外用温度计、发现着"热的线"；约翰·里特尔（1801）在紫端发现了化学的等价物；斯特藩–玻尔兹曼的定律（1879–1884，约瑟夫·斯特藩经验地，路德维希·玻尔兹曼通过热力学），威廉·维恩的位移的定律（1893）、马克斯·普朗克的辐射的定律（1900）——紫外灾难的解决、量子理论的出生的证明——在一个世纪之内供应着每一个热的红外与微波的任务仍然逐带使用的来源的项的完整的物理学。**1871–1930 年代。** 瑞利的散射的理论（1871，$\lambda^{-4}$，带着古斯塔夫·米氏的 1908 的气溶胶的一般的解）解释着蓝的天空、建造着每一个大气的校准的第一项；第一次的世界大战时期的摄影的、然后全色的航空的摄影的项目使辐射的度量成为一个操作的技艺。**1960 年代–1972。** 辐射的校准进入轨道：1960 年代在 TIROS、Nimbus 上的辐射的计测量着地球的辐射的预算、检验着黑体的近似，1969–1972 的 Landsat 的多光谱的扫描器围绕签名的定义的大气的窗口以实验室的光谱的图书馆作为它的要求的文件被设计，1972 的发射开始着连续的校准的记录，它的替代的调节的更新（2016–2024 的 Landsat 与 Sentinel-2 的互校准的文献）把 1986 的 Landsat-5 的辐射的亮度与现在的在一个十年一个百分点内连接着——这个行业里最长的光子的信任的链条。
:::

- [ ] 因为卫星的探测器在那个带之外是盲的

窗口的结构是分子的量子力学：$6.3$、$12$–$18\ \mu\mathrm{m}$ 属于 H₂O，$15\ \mu\mathrm{m}$ 属于 CO₂，$9.6\ \mu\mathrm{m}$ 属于 O₃，水与二氧化碳的复合体之间的 $8$–$14\ \mu\mathrm{m}$ 的缺口是大气相对地透明的地方——每一个热的红外的仪器（ASTER TIR，MODIS 的带 20–36，Landsat TIRS，ECOSTRESS）在它内部被建造，带着跨越着残余的水汽的梯度、正好使校准能被估计的分窗的 $10.8/12\ \mu\mathrm{m}$ 的一对。其余的选项把可探测性、气溶胶、仪器的设计与定义着窗口的分子的混浊度混淆着。
:::
:::

::: quiz {#quiz-rededge}
一个作物遭受着减少叶绿素、让冠层的结构完整的氮的缺乏。预期首先哪个光谱的改变？

- [x] 在红的（$0.67\ \mu\mathrm{m}$）的吸收的反射率增加、近红外的高原大致不变，降低着 NDVI
- [ ] 在红的、近红外的反射率同等地增加，让 NDVI 不变
- [ ] 在红的反射率减少、在短的波的红外的水的带增加
- [ ] 因为冠层变暗，到处反射率减少

::: solution :::
叶绿素控制着 $0.67\text{-}\mu\mathrm{m}$ 的吸收；结构控制着近红外的高原。叶绿素的损失带着完整的结构因此只提高着红的反射率——生理学的例子的红的边缘的移动——所以红的带上升，近红外不，NDVI（近红外减红的除以它们的和）落下。结构的损害（倒伏，干燥，衰老）是移动近红外的；水的压力移动着 $1.94\text{-}\mu\mathrm{m}$ 的带。测验的要点：NDVI 是两个不同的诊断的一个比，在不说哪个项移动了的情况下读它是红的边缘的例子警告着的解释的错误。
:::
:::

## 练习

::: exercise {level=1 check="10.1"}
使用维恩的位移的定律 $\lambda_{\max} = 2898/T$（µm，K），一个在 $288\ \mathrm{K}$ 的陆地的表面的发射的峰的波长是什么？给出一个位的小数的 µm 的值。
::: solution :::
$\lambda_{\max} = 2898/288 = 10.06$，约 **$10.1\ \mu\mathrm{m}$**——在 $8$–$14\ \mu\mathrm{m}$ 的窗口之内，它是使无源的热的遥感从轨道成为可能的设计的巧合；同一个定律把太阳的峰放在 $0.50\ \mu\mathrm{m}$、火在 $3$–$4\ \mu\mathrm{m}$，解释着 widgets 的中波的带。
:::
:::

::: exercise {level=1 check="4.3"}
瑞利的散射的截面按 $\lambda^{-4}$ 变化。在 $0.45\ \mu\mathrm{m}$（蓝）的散射比在 $0.65\ \mu\mathrm{m}$（红）强多少倍？给出一个位的小数的比。
::: solution :::
$(0.65/0.45)^4 = (1.444)^4 = 4.34$，约 **4.3** 倍——蓝的带携带着可见的带的最大的路径的辐射的亮定的定量的理由（路径的例子），为什么历史的航空的胶片在蓝里霾、通过一个红的滤光片清澈，气溶胶的检索建立在蓝的带的测量上。
:::
:::

::: exercise {level=1 check="2.48"}
光子的能是 $E = hc/\lambda$，带着 $hc = 1240\ \mathrm{eV\cdot nm}$。一个 $500\ \mathrm{nm}$ 的光子的能以 eV 是多少，到两个位的小数？
::: solution :::
$E = 1240/500 = $ **$2.48\ \mathrm{eV}$**——足以驱动叶绿素的光化学（约 $1.8\text{-}\mathrm{eV}$ 的阈值），这就是可见的窗口同时是光合的活的窗口、生命使可见的窗口的理由；一个 $10\text{-}\mu\mathrm{m}$ 的热的光子只携带 $0.124\ \mathrm{eV}$，振动的规模的能，这就是热的红外读着温度与键、不是化学的理由。
:::
:::

::: exercise {level=2 check="0.67"}
一个像素在近红外有着 0.50、在红的 0.10 的表面的反射率。计算到两个位的小数的 NDVI = (NIR − 红的)/(NIR + 红的)。
::: solution :::
NDVI = $(0.50 - 0.10)/(0.50 + 0.10) = 0.40/0.60 = 0.667$，约 **0.67**——健康的中季的耕地或草地；注意同一个值能从许多 (NIR, 红的) 的对来（0.34/0.068 也给它），它是红的边缘的测验的结束的警告一般化着的比的指数的一义性，生理学的要紧的时候两个带的文献报告着两个带。
:::
:::

::: exercise {level=2 check="1.15"}
一个黑体的总的发射的通量在 $300\ \mathrm{K}$ 的表面、同一个表面在 $290\ \mathrm{K}$ 之间改变多少倍（斯特藩–玻尔兹曼，$F = \sigma T^4$）？给出两个位的小数的 $F(300)/F(290)$ 的比。
::: solution :::
$(300/290)^4 = (1.0345)^4 = 1.149$，约 **1.15**——一个 3.4 个百分点的温度的改变移动着通量的 15 个百分点，使热的红外成为一个精确的温度计的敏感（一开尔文的陆地的表面的温度在 $11\ \mu\mathrm{m}$ 是一个约 1.4 个百分点的辐射的亮度的信号，舒适地在现代的仪器的 $0.3\text{-}\mathrm{K}$ 的噪声之上）、城市的热的小岛检索完全工作的理由。
:::
:::

::: exercise {level=2 check="31.8"}
一个带着 0.10 的反射率的朗伯的表面被一个 $1000\ \mathrm{W\,m^{-2}}$ 的下行的辐照度照明。它的辐射的亮度是 $L = E\rho/\pi$。计算到一个位的小数的 W m⁻² sr⁻¹ 的 $L$。
::: solution :::
$L = 1000 \times 0.10/\pi = 100/3.1416 = 31.83$，约 **$31.8\ \mathrm{W\,m^{-2}\,sr^{-1}}$**——$\pi$ 是 BRDF 的定义的双半球的对着方向的记账（一个朗伯的表面把 $\rho E$ 分布在出射度的 $\pi$ 个立体角上），这个单一的转换在本课程的每一个反射率到辐射的亮度的校准之下；忘记它是一个 33 个百分点的错误，比大多数的大气的校准大。
:::
:::

::: exercise {level=3 check="0.81"}
一个大气的带在表面与传感器之间有一个单向的透射率 0.90。对一个天底（垂直）的路径路径的长度是一个尺度的高度；对一个偏离的天顶 $60^\circ$ 的视图路径两倍长。假设比尔的定律（$T_{\text{斜}} = T^n$，$n$ 是路径的倍数），沿着倾斜的路径的透射率是什么？给出到两个位的小数。
::: solution :::
$T_{\text{斜}} = 0.90^2 = $ **0.81**——比尔的定律在路径里是指数的，所以透射率沿着路径的倍数相乘，传感器的整个的偏离的天顶的角度范围（Sentinel-2 观测到 $\pm50^\circ$，路径的倍数到约 1.6）必须逐带地被透射率校准；这是 BRDF 的定义说必须在改变被主张之前分离的两个视图的角度的效应之一，另一个是表面自己的方向的响应。
:::
:::

::: exercise {level=3 check="64"}
一个混合的像素的红的带的反射率是 0.14。端母：裸的土壤 0.30，密的植被 0.05。使用线性的混合 $\rho_{\text{像素}} = f\rho_{\text{植被}} + (1-f)\rho_{\text{土壤}}$，百分点的植被的分数 $f$ 是什么？
::: solution :::
$0.14 = 0.05f + 0.30(1-f) \to 0.14 = 0.30 - 0.25f \to f = 0.16/0.25 = 0.64$，即 **64 个百分点**的植被——城市的混合的例子的光谱的混合的算术，一个带只对两个知道的端母足够的理由：真实的像素需要和端母一样多的带加一，非负的、和为一的约束、被端母的可变性、不是被这个可解的代数统治的错误的条。
:::
:::

::: exercise {level=3 check="71.4"}
一个传感器在一个暗的目标之上测量着 80 个单位的总的辐射的亮度；对那个带与几何的模拟的路径的辐射的亮度是 $30$ 个单位、透射率是 $0.70$。表面反射的辐射的亮度服从 $L_{\text{测量}} = L_{\text{路径}} + T L_{\text{表面}}$。恢复到一个位的小数的单位的 $L_{\text{表面}}$。
::: solution :::
$L_{\text{表面}} = (80 - 30)/0.70 = 50/0.70 = 71.43$，约 **$71.4$ 个单位**——减去路径，除以透射率，路径的例子在算术的形式里的两步的暗的对象校准；注意除法建立的错误的放大：$T$ 的一个 10 个百分点的错误变成每一个的表面的辐射的亮度的一个 10 个百分点的错误，这就是大气的校准的质量、不是传感器的噪声设定着大多数的光学的遥感的精度的地板的理由。
:::
:::

::: warning 四个辐射的度量的谬误
1. **"像素的值是反射率。"** 原始的数字化的数是辐射的中间物——包含着路径的辐射的亮度、照明的几何、邻接、探测器的非线性、（对老的任务）退化的校准的增益与偏移的辐射的亮度的版本；2016–2024 的 Landsat 的辐射的饱和与退化的重新处理的文献存在，因为数百万的存档的场景恰恰在这一步失败了。从辐射的亮度到反射率的链条需要太阳的辐照度、太阳的角度、透射率、路径的减法，悄悄地跳过它使每一个下流的统计按气团、气溶胶、日期加权——本课程的分类的、改变的探测的一课坚持着表面的反射率作为开始的材料的理由，"我们按交付的使用了场景"属于一个方法的一节的忏悔、不是它的方法。
2. **"NDVI 测量着植被。"** 它测量着一个吸收的深度对一个散射的高原的比，它与绿的，覆盖，叶绿素，水，结构，物候，土壤的背景以按生物群系、传感器、季节变化的比例相关——日常的实践里的指数的一义性的练习的两个带的简并。2000 年代与 2020 年代的变绿与变褐的文献的最难的论证不是关于 NDVI 的计算、是关于哪个项移动了：中国与印度的变绿被解决成灌溉与集约化（2019 与 2020 的程–焦的分析对着 2019 的布雷克尔–戈什的全球模型）恰恰因为单独的比不能说，从"地球在变绿"到"亚马逊在变褐"的每一个标题继承着同样的不定，直到红的边缘、短的波的红外的水的带、微波的植被的光学深度作为独立的证人被带来。
3. **"一个更亮的热的红外的像素是一个更暖的像素。"** 热的辐射的亮度是发射率乘以黑体的函数、发射率按材料与粗糙度变化：干的土壤与岩石在 0.95 附近，植被在 0.98–0.99，水在 0.96–0.99 带着光谱的结构，抛光的或粗糙的表面 偏离更远，所以一个在 $305\ \mathrm{K}$ 的石英岩的露头能在一个带里比一个在 $310\ \mathrm{K}$ 的湿的土壤辐射得多、在另一个里辐射得少（热的一课的温度–发射率的分离的问题，分窗的对水汽的错误的回答、不是对发射率自己的）。谬误的实践的形式——把 Landsat 的陆地的表面的温度的图叫作"表面的温度"而没有 $\pm1$–$2\ \mathrm{K}$ 的发射率的项、或在白天读着一个城市的–乡的对比为纯的热、屋顶与墙的发射率、腔的几何驱动着它的多数——是城市的气候的遥感里被引用最多的错误。
4. **"大气是一个固定的校准。"** 它的光学的深度按数量级变化（清澈的海洋的边界的层到尘埃与烟的事件带着可见的带的一个之上的光学的深度），它的窗口随着水汽移动（$8$–$14\text{-}\mu\mathrm{m}$ 的窗口的透射率在干的极地的空气接近一、在湿的热带在一个分数），它的路径的辐射的亮度是场景与角度的依赖的；一个单球的校准，更糟的，一个从一个与场景不同的日期应用的校准，留下正好像被制图的特征结构化的剩余——模仿着土壤类型的边界的尘埃的羽，模仿着燃烧的痕迹的烟，模仿着土壤的湿度的梯度的可降水量水汽的梯度。诚实的实践是逐像素或逐场景的带着报告的不确定度的大气的特征化（MODIS 的气溶胶与水的汽的产品，Sentinel-2 的 Sen2Cor 与 MACCS 的配对，2020 年代的协调化的文献），诚实的结果的陈述是"给出一个大气的一个表面的反射率到 X 个百分点"。
:::

::: summary
遥感是一个带着错误的预算的反演的物理学：一个传感器记录着**辐射的亮度**（唯一的距离守恒的辐射的量、每一个任务的校准的报告被写于其中的），它是一个衰减的表面的项、一个相加的大气的路径的项的和，本课程的整个的解释的链条——反射率，分类，温度，后向的散射——通过用普朗克，基尔霍夫，比尔、一个由分子的转动的–振动的光谱写着的窗口结构（可见–近红外到 $0.9\ \mu\mathrm{m}$，短的波的红外的窗口到 $2.5$，$3$–$5$、$8$–$14\ \mu\mathrm{m}$ 的热的带，毫米与原厘米的微波的窗口）撤销那个和而开始。表面以五个方言回答——植被的叶绿素与结构的红的边缘与水的带，水的指数的吸收、海洋的颜色的十个百分点的信号，土壤与岩石的铁与氢氧的吸收，雪的结晶的在 $1.5$、$2.0\ \mu\mathrm{m}$ 的崩溃，建造的材料化学的迟钝、几何的响亮——像素是它们的线性的混合物，诚实的产品是一个带着错误的条的分数、一个带着颜色的类。BRDF 的纪律把全部它绑定到几何：反射率是太阳与视图的方向的函数，时间的序列必须在改变被主张之前归一化，两个大的混淆（方向的反射率对于反照率，两个几何对于改变）是戴着两顶帽子的同一个错误。谬误——像素作为反射率，NDVI 作为植被，亮度作为温度，大气作为常数——全是一个谬误，**被测量的量被误认为被想要的量**，前面的课里的每一个技术（[[remote-sensing/sensors-orbits]] 与 [[remote-sensing/image-processing]] 一课的校准与校准，[[remote-sensing/classification]] 一课的可分离性的统计，[[remote-sensing/thermal-microwave]] 一课的温度–发射率的分离，[[remote-sensing/radar-lidar]] 一课的电介质的物理学）是使两者分开的机器。把这课的记账做对，一个卫星图像变成一叠校准的物理的测量；做错，它仍然是无训练的称它的东西：一张图画。
:::
