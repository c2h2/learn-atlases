每一张地图是一个小心地说着的谎：地球是一个扁的椭球（非常接近一个大地水准面，局部的一个景观），每一张平的表示必须选择着哪些真理保持、哪些打破——角度，面积，距离，方向、经纬网的形状。本课使着那些选择明确的、可逆的，课程的其余的 GIS 工作沉默地继承着它们：一个在 Web 墨卡托计算的"分区的面积统计"在热带错着一个八的因子，一个在基准之间粘贴的坐标能把一个点移动一个公里，一个在两个机构之间的边界的争端常常是一个穿着法律的服装的大地基准的争端。本课有三个部分。**大地测量学：** 地球的形状的椭球与大地水准面的模型，基准与地球参考框架的机械（1984–2025 的 WGS84 与 ITRF 与 EUREF 与 REGNET 与 GDA2020 的实现，它们的板块运动的历元、厘米的维护），坐标的语言（大地测量的纬度与高度对着投影的东距与北距、海平面的与冰川的课的垂直的基准）。**投影：** 可展的表面的分类学（圆柱的，圆锥的，方位的），畸变的代数（蒂索的指示线，你不能有一切的保角–等积–等距的妥协的定理），工作的菜单（UTM 与国家的网格，兰伯特保角与阿尔伯斯等积的大陆的家族，1999 与 2017 的 Web 墨卡托现象、它的制图的结果）。**定位：** 作为坐标的生产者的卫星的导航（GPS-Galileo-Glonass-BeiDou 的星座的伪距与载波的相位的观测量，电离层–对流层–多径–轨道与钟的错误预算，1994–2025 的 RTK 与 PPP 与网络的 RTK 的从米到毫米的精度阶梯），相反的问题——在它被捕获着着的参考框架之间转换着现有的数据，2016–2025 的大地的版本化的控制的文献（澳大利亚的 GDA2020 的采用的板块的旋转的历元的记账，2024 与 2025 的 ITRF2020 与 TRF 的现实ing 的讨论）是警示的连载。先决的条件是雷达–激光雷达的课的厘米的测距的直觉、高中的三角学；回报是坐标的读写能力：看着任何一个层的元数据的一行、知道着它的数字意味着什么、花费着什么、将在哪里打破的能力。

::: definition 地球的形状，基准，坐标的语言 {#def-geodesy}
测量的等级制度从形状开始：**大地水准面**（平均的海平面将遵循着的重力的等位面的面，对着椭球的离差的 $\pm 100\ \mathrm{m}$，制图着它的 1995–2025 的 GRACE 与 GOCE 与 EGM2008 与 EGM2020 的重力模型的谱系，垂直的基准的段落重新使用着的重力的大地水准面对着椭球的高度关系 $h = H + N$），最佳拟合的**椭球**（1980 的 GRS80 与 1984 的 WGS84 的参数集的半的长轴与扁率，本地的基准的历史上最佳拟合着的椭球——1841 的印度的与 1830 的艾里的与 1924 的国际的与贝塞尔的家族，仍在困扰着更老的地图），**地心的框架**（国际的地球的参考框架的 VLBI-SLR-GNSS-DORIS 维护的实现，1988–2024 的 ITRF2014 与 ITRF2020 的版本带着它们发表的站位的速度场，板块固定的区域的框架——ETRF，GDA2020 的 2020.0 的历元，NAD83 的连续的实现，GAD——它的**历元**（坐标在一个日期上有效，板块移动着 $1$–$7\ \mathrm{cm/yr}$）是 2016–2025 的基准的现代化的波存在强制着的记账的事实）。一个**大地基准**是使纬度与经度有意义的椭球加定向加（对本地系统）的垂线的偏差的包裹；一个**坐标的参考系统**（ISO-19111 与 EPSG 的登记的正式主义，2015–2025 的 PROJ-6 与更晚的转换的引擎的时代，它使基准的移动成为一个版本化的、网格的、可审计的操作——2020 年代的移动的网格与赫尔默特的参数的元数据是一个正确的转换、一个可信的转换之间的区别）把基准加投影加单位包裹进一个 GIS 的文件应该总是携带着的一个标识符。**垂直的基准**是它自己的问题：正高的（地形图的对着大地水准面的"海平面之上的高程"，本地的平均的海水平的原点，海洋学的海平面的课继承着它的数十年的潮汐的计量的记录），椭球的（GNSS 给出的，$h = H + N$ 的转换），国家的垂直的网络（2003–2025 的 NAVD-1988 的调整、澳大利亚的 PADMS、欧盟的垂直的 EVF 时代的统一），它的不一致是洪水的区的图跨越着边界争论的理由。坐标的语言然后乘着：**大地坐标**（纬度，经度，高度——一个弯曲的表面上的角度，$1^\circ$ 的经度作为 $\cos(\text{纬度})$ 收缩，练习的算术），**投影的坐标**（课的下一个定义），**网格与分块系统**（数据的基础设施使用着的 UTM 的区与 3DEP 与 H3 与 S2 的分块的惯例），定位的定义的**带时间标签的坐标**（一个点是一个坐标在历元，2020 年代的空间的数据的基础设施的标准刚刚开始把那写进着模式）。整个的课的纪律、随后的 GIS 的课的纪律是一句话：**没有不带它的 CRS 的标识符的坐标，没有不带它的方法与网格的版本的转换，没有不带它的基准的高度**——三行元数据防止着课的谬误将收集着的错误的多数。
:::

::: definition 投影：畸变的代数，工作的菜单 {#def-projections}
一个投影是从椭球的坐标到平面的坐标的一对函数，它的畸变被**主的比例的因子** $a$ 与 $b$ 沿着最大与最小的畸变的方向完全地描述着（1843 的蒂索与 1859 的李斯廷的遗产，1980 年代与 2020 年代的制图学与 GIS 科学的畸变的分析的文献）：它们的乘积给出**面积的**畸变（$ab$），它们的比给出**角度的**畸变（椭圆的偏心率），它们的均值关系着**线性的**畸变——蒂索的指示线（一个映射到一个椭圆的无穷小的圆）是每一个好的图集用来显示着一个投影在每一个纬度做什么的可视化。**选择的定理**（1850 年代与 1912 的斯奈德与 1980 年代的制图委员会的时代的经验规则，使它们形式化着的 1990 年代与 2000 年代的错误度量的文献）是一个权衡的序列：**保角的**投影（处处 $a = b$，角度与形状保持着，面积按比例的平方膨胀着——墨卡托与兰伯特的保角的圆锥的家族，导航与天气与大比例的地形的制图的选），**等积的**（$ab = 1$，面积保持着，形状剪切着——阿尔伯斯与墨卡托等积与正弦与圆柱等积的家族，专题的制图与面积的统计的选择，2015 与 2017 的真实的大小与等积的运动的政治的制图学的论证），**等距的**（只在选着的线上——没有一个投影保持着所有的距离），**妥协的**（1921–2023 的一般的参考的图集的温克尔三重与罗宾逊与自然地球的家族，最小化着某个感知的复合）。**可展的表面的分类学**按着地图包裹在什么上组织着菜单：**圆柱的**（1569 的墨卡托与 1880 的高斯–克吕格与 UTM 的谱系——保角的，横轴的，$6^\circ$ 的区与 $8^\circ$ 的带的网格带着 $1:250$ 万的假东的惯例，多数的国家的国家的地形的图的默认，1999 的 Web 墨卡托的变体的球的捷径与无限的极的病态），**圆锥的**（1772 的兰伯特与 1805 的阿尔伯斯的家族，中纬度的东西的大陆的选择——美国的本土四十八州的州平面与阿尔伯斯的美国图集、欧洲的兰伯特 93、中国的克拉索夫斯基时代的 1980 的兰伯特的网格），**方位的**（极地的与大圆的导航与无线电的方向的测定的选择，极地的制图的默认的兰伯特的方位的等积的极地的球极的投影——冰川的课程居住着的 1990 年代与 2020 年代的南极与北极的数据中心与 BAS 的 DEM 与北极的 DEM 的惯例），**大地的边界的与法律的**网格（州平面与国家的网格的县与地块的几何，2010 年代与 2020 年代的垂直与水平的邻接的法、它们的坐标的法律的后果）。例子排演着的**选择的规则**：一个小的地区的大的比例的制图要求着一个低畸变的分区的保角的网格（UTM 与州平面与国家的网格，比例的错误在 $10^4$ 的 $1$ 份以下）；面积的大陆的专题的制图要求着一个对着大陆的取向匹配的等积的家族（阿尔伯斯为东西的中纬度，兰伯特的方位的等积为极地的）；全球的专题的制图要求着一个妥协的、等积的伪圆柱的（世界的等级着色图的文献的墨卡托等积、汉默与博格斯等距圆柱与自然地球 II 的谱系）；**跨着两个区或两个 CRS 的边界任何一个定量的分析是一个伪装的投影的决定**——2010 年代与 2020 年代的 GIS 科学在距离与面积的统计的投影引起的错误的文献（Web 墨卡托的面积的主张的揭穿，全球的航运与航线的数据集的大圆的对着恒向线的距离的错误，2016 与 2022 的平的对着大圆的面积的比较的研究）是对着元数据的一行被忽略时发生的审计。
:::

::: definition 卫星的定位，框架的转换 {#def-positioning}
全球的导航的卫星的系统（1978–1995 的 GPS 与 1982 的格洛纳斯与 2016 的伽利略与 2020 的北斗三号星座，加上区域的增强的系统）靠从对四个或更多的卫星的伪距解着四个未知（三个坐标加接收机的钟的偏移）给出一个接收机它的位置，卫星自己的位置与钟被播发着（GPS III 与伽利略 FOC 时代的分米的星历的精度，1994–2025 的国际的 GNSS 服务的谱系的在厘米与几个皮秒的水平的精密的产品与 IGS 与 CNES 与 BKG 与 WUM 时代的最终的轨道与钟的产品）。**观测量**是一个代码的伪距（C/A 与 P 与 E1 与 E5 的码，一个 $3$-m 的代码的噪声的地板加上错误的预算）、一个**载波的相位**（$19$ 与 $24$-cm 的波长测量到一个百分点——毫米的观测量，它的整数的模糊度（1985–2025 的 LAMBDA 与整数的最小的二乘的模糊度的解决的文献）是厘米与米的定位之间的区别）。**错误的预算**是课的第二个厘米的会计的练习：电离层的延迟（1998–2025 的克布霍卡与 NeQuick 与 GIM 与观测的组合的文献，在白天与赤道的米，靠双频的电离层免费的组合移走到厘米、2015–2025 的 RTK 与 PPP 的模型估计着），对流层的延迟（1975 的萨斯塔莫宁宁与 1992 的霍普菲尔德与 2000 年代的 GPT 与 GPT3 与 GPT2w 的干的与湿的模型，湿的分量的厘米的天气的噪声使气象的预报的课的水汽的层析成为一个反向的 GNSS 的应用），卫星与接收机的钟与轨道的错误（2010 年代与 2020 年代的 BKG 与 WUM 与 Trimble CenterPoint RTX 时代的 SSR 的产品的实时的服务的校准），多径与站的环境（1990 年代–2025 的抑制环与多径的缓解与恒星的过滤的文献，毫米的大地的站位的设计的规范），几何的因子（下面的练习的 DOP 与 PDOP 与 VDOP 的算术，卫星的星座的几何对每一个其余的错误的放大）。**精度的阶梯**然后排列着技术：独立的 SPP（2020 年代的多星座的智能机与接收机的时代的 $1$–$5\ \mathrm{m}$），SBAS 与 GBAS（1995–2025 的 EGNOS 与 WAAS 与 MSAS 与 GAGAN 与 Geo-Augmentation 时代的 $0.5$–$2\ \mathrm{m}$，2006 与 2020 年代的航空的进近的种类），实时的运动的（1990 年代–2025 的 RTK 与网络的 RTK 与 VRS 的时代，$1$–$2\ \mathrm{cm}$ + $1\ \mathrm{ppm}$ 带着一个基线限制的无线电与互联网的链路，测量与机器的控制和精密的农业的默认），精密的点的定位（1997–2025 的宗伯奇与 JPL SOP 与 PPP-RTK 与 PPP-B2b 与 BDS 的 PPP 时代的模糊度解决的收敛到几分钟的厘米的制度）——2020 年代的 PPP-RTK 与 NSPIRE 与 OSNOS 时代的两者的融合关闭着定义了技术的选择的决定四分之一世纪的差距。**框架的转换**是相反的问题：把一个 CRS 从现有的坐标带到另一个（2016–2025 的 PROJ-6 与 7 与 8 与 9 时代的转换的引擎的文献，网格的与赫尔默特的与莫洛坚斯基的与布尔萨–沃尔夫的参数的方法，基准的现代化的例子的板块的运动的模型的历元的记账，2024 与 2025 的 ITRF2020 与 ITRF 的现实与 TRF 的时间的依赖的讨论）——纪律是大地的定义的三行元数据，由版本化的软件执行着，它的转换的路径（2020 年代的 PROJ 的管道的语言的明确的步骤的列表，基准的移动的网格的可获得性与精度的元数据）像它坐在旁边的投影的选择一样可审计。
:::

::: example 选择一个投影：三个工作，三个答案 {#ex-choose-projection}
三个真实的工作、它们强制着的 CRS 的决定。**一个国家的洪水的风险的制图的机构**（2010 年代–2025 的 Copernicus EMS 与 FEMA 与欧盟的洪水指令的制图的实践）需要一个单一的国家的墙到墙的栅格的分析、它的面积统计必须正确地求和为自然灾害的洪水的课的暴露的计数：答案是国家官方的等积的、低畸变的网格（欧盟的 ETRS89-LAEA 兰伯特的方位的等积与 ETRS89-LCC 的惯例，2009 与 2017 的 EEA 推荐的实践的文档，美国的州平面与阿尔伯斯的选择逐区域），绝不是数据的交付的投影（图像的处理的课的 Sentinel 的颗粒的 UTM 的区的镶嵌问题恰恰是这个决定被意外地做），统计绝不是 Web 墨卡托（下一个例子）。**一个大陆的土地覆盖的图**（2017–2025 的 ESA WorldCover 与 ESRI 的土地覆盖 $10\ \mathrm{m}$ 与哥白尼全球的土地的退化时代的产品）必须按公顷报告逐国家的面积的改变：分析在一个全球的等积的网格里运行（2019 与 2022 的 FAO 的 FRA 与全球的森林的监视的面积统计的方法的墨卡托等积与多的标准纬线的阿尔伯斯的等积的大地的分块的惯例，2016 与 2022 的平的对着大圆的面积的比较的研究的对任何一个边界的面的工作流的推荐的大圆的面积的计算），产品的原生的分块（S2 与 MGRS 的分块与地理的度的网格的惯例）作为一个包装的细节、不是一个分析的 CRS 对待着。**一个沿海的城市的海平面的上升的规划的图**（2015–2025 的 CoASTLIVE 与 NYTDC 与欧盟的洪水指令与澳大利亚的国家的潮汐的基准时代的实践）首先是一个垂直的基准的决定（NAVD-88 与天文基面与 GA 的 LAT 与本地的平均的海水平的选择、它们的数十年的潮汐的计量的不确定度，NAVD-88 的 2022 与 2027 的调整与 GNA14 与 AUSGeoid2020 与 EGM2008 的转换的链），其次是一个水平的基准的决定（本地的网格的历元对着 GNSS 的坐标的历元，板块的运动的段落的每年厘米），第三个是一个投影的决定——秩序自己是课：**CRS 由地图必须回答着的问题选择着、不是由制作着第一个层的任何人的便利**，2010 年代与 2020 年代的空间的数据的基础设施的标准（OGC 与 SDI 与 EPSG 的登记与 ISO-19115 的元数据的制度）存在使那个选择成为一个文档化的、版本化的、机器可检查的事实、不是一个民间传说。

::: example Web 墨卡托与面积的神话：格陵兰的假的帝国 {#ex-mercator}
1999 与 2005–2025 的 Web 墨卡托现象（1999 的 MapQuest 与 2005 的谷歌地图的 EPSG:3857 的谱系，它的椭球的数据上的球的公式的捷径自己是一个基准的错误，它的 y 坐标在极发散着、强制着 $\pm 85.05^\circ$ 的截止）是课的教化的例子，因为它的畸变既巨大、不可见：保角的比例的因子 $\sec(\text{纬度})$ 在 $60^\circ$ 给出 $2\times$ 的线性、在 $70^\circ$ $2.9\times$、一个 $\sec^2$ 的**面积的**因子——在 $60^\circ$ $4\times$，在 $70^\circ$ $8.5\times$，在格陵兰的真实的高的纬度的均值之上 $80\times$、在赤道之下 $1.3\times$——这就是墨卡托的世界的图使格陵兰（$220$ 万 $\mathrm{km}^2$，非洲的面积的 $3.4\%$）看来像非洲的大小（$3040$ 万 $\mathrm{km}^2$）、加拿大与俄罗斯统治着气候与生物多样性的图的视觉的政治的理由（2015–2025 的真实的大小图与等积与自然地球与 AuthaGraph 的制图学的正义与批评的文献，2018 与 2021 的援助的地理与人均的排放的可视化的研究的投影的敏感的分析）。定量的 GIS 的后果比美学更残酷：**任何在 Web 墨卡托计算的面积统计是一个纬度的加权的谎**（2010 年代与 2020 年代的课程的系列对"格陵兰比非洲大"的主张的揭穿，在网络的派生的数据集里发现着 10–40 个百分点的国家面积的错误的 2016 与 2022 的研究，现代的 GIS 的堆栈的 2020 年代的大圆的面积的函数的默认），距离与方向在赤道、大圆之外是错的（2010 年代与 2020 年代的可视化的工具的恒向线对着大圆的航线的图的校准），"EPSG:4326 对面积可以因为它是地理的"的混淆（平面的度的面积对着大圆的面积，下面的练习计算着的 $\cos$ 的纬度的因子）是 2020 年代的地理的数据的科学的重复的文献的最常见的单个的 CRS 的错误。正确的习惯是便宜的：在一个对着研究的范围匹配的等积的 CRS 里分析，带着它的方法报告着面积（平的对着大圆的对着球的超额），读着每一张公开的地图的投影像分类的课读着精度的表——作为一张地图被允许主张着什么的一个陈述。
:::

::: example 基准的不匹配：同一个点移动一个公里时 {#ex-datum}
最贵的坐标的错误是沉默的——两个数据集，都"在纬度与经度"，它们的基准相差数百米。典范的家族：**本地对着全球的移动**（钉在一个原点的天文台的 1990 年代之前的国家的基准——1841 的印度的与 1971 的 WGS72 与东京的 JGD 与波茨坦的与好望角的旧 1983 与阿姆福特的 1998 的谱系——它对 WGS84 的偏移达到 $100$–$1500\ \mathrm{m}$：1990 年代与 2000 年代的印度与巴基斯坦的边界的制图与以色列–约旦的边界的校准与东南亚的殖民的时代的基准的争端，2000 与 2016 的 GDA94 到 GDA2020 与 2024 的 GDA2020 的实现时代的澳大利亚的基准的现代化的运动（2017 与 2020 的 ESC 与 ICS 与 ICC 与 IGC 时代的国家的网格与地籍的重新对齐，把国家里的每一个坐标移动了约 $1.8\ \mathrm{m}$ 的 2020.0 的历元与板块的旋转与 pv 的参数的记账——练习的算术），1980 年代与 2010 年代的日本的基准与高程的基准的修订与 2011 的东北的历元的移动与 2012 与 2014 的震后的坐标的更新）；**历元的不匹配**（板块的运动的段落的同一个事件的慢的版本：夏威夷的 NAD83 对着 ITRF 的坐标相差着米，因为框架的实现携带着不同的板块的旋转的极，2022 与 2024 的 NAD83-2024 的历元与 NSRS-2022 与 58 的重新对齐与 RTN 与 RTK 的网络时代的讨论，2020 年代的板块的运动模型与 ITRF2020 对着 ITRF2014 对着 ITRF2010 的站位的速度的比较）；**转换的方法的错误**（2016–2025 的 PROJ 与 pyproj 与 GDAL 与 esri ArcGIS 的 PROJ 的整合时代的错误的报告与校准的通知，在移动的网格粗的或缺的地方相差着米的莫洛坚斯基对着赫尔默特对着网格的方法的选择，2021 与 2023 的 PROJ-6 与 7 与 8 时代的基准的移动的网格的可获得性与精度的元数据与转换的路径的管道的语言）。2010 年代与 2020 年代的地籍与海洋的边界与大陆架与北极的海底的主张与 UNCLOS 与 CLCS 与 ITLOS 与 PCIJ 与 ICJ 的判例的文献（2002 与 2014 与 2016 与 2023 的边界的争端的判决的坐标的证据的协议）记录着故事的法律的末端：一个条约的坐标不带它的基准是无意义的，2020 年代的海洋与北极与南海的裁决与书状与专家的报告的实践现在规定着 CRS 与历元与转换的方法像 GIS 的课规定着元数据。对任何一个不带文档化的 CRS 的数据集的审计的习惯：定位两个数据集都能看见的一个特征（一座桥，一个跑道的入口，一个 GNSS 参考的基准），计算着偏移的矢量，让它的大小与方向命名着基准——雷达–激光雷达的课的参考点的纪律的同样的交叉检验的逻辑，在米里、毫米里。
:::

::: example 洪水的图的垂直的基准：$29$ 米的法律的暴露 {#ex-vertical}
2012 与 2017 与 2022 的美国洪水的保险费率图与纽约市的小组与欧盟的洪水指令的危险的图的争论（2015 与 2019 的美国 GAO 与 NRC 与 NASEM 的报告与审计长办公室的审计，2018 与 2022 的 NAVD-88 对着相邻的区域与本地的基准的边界的不连续与 GNA14 与 AUSGeoid 与 EGM2008 的转换的研究）把垂直的基准显示为一个带着附着的美元的水平的基准的问题：洪水的高程在一个本地的垂直的基准里引用着（NAVD-88 与天文基面与 GA 的 LAT 与亚得里亚与波罗的本地的平均的海水平的家族，它们的数十年的潮汐的计量的原点彼此相差着分米到米、在墨西哥湾与孟加拉湾与荷兰的案例研究里，从大地水准面的高程足够移动地块级的保险与许可的决定），$h = H + N$ 的转换（大地水准面的例子的公式，带着 2008 与 2020 的 EGM 与区域的模型、2022 与 2027 的 GEOID19 与 GNA14 与 AUSGeoid2020 与 NGS CONVERT 与 ICM GEOID 与 EU GGOS 时代的国家与大陆的执行模型执行着）是错误进入的地方，2017 与 2022 的美国垂直的基准的现代化的决定（NAVD-88 的替换为一个 NASA 的 GEOIDE 与重力的场的模型与 GRACE 与 GOCE 与表面的水准的大地水准面的辩论，2025 与 2027 的实时的时间表的调整与过渡与遗留的兼容的讨论）是一个基准是一个法律的、不是数学的基础设施的对象的最大活的演示——练习的 $3.2$-mm 的纸的移动，在洪水的保险的规模，是一个家庭的基础图的高程、一个市的责任，诚实的危险的图在说明着它的洪水的概率的同一个说明里说明着它的垂直的基准、它的大地水准面的模型、它的潮汐的原点。
:::

::: history 从度的三角测量到太空的厘米 {#hist-maps}
**1617–1955。** 经典的大地测量学：斯涅尔的 1617 的一个度的三角测量，1735–1744 的法国到拉普兰与秘鲁的远征（莫佩尔蒂与拉·孔达明的测量）确认着扁的地球，贝塞尔的 1841 的椭球，19 世纪的测量的国家的基准（嵌在更老的地图里的艾里与埃佛勒斯与贝塞尔的名字），20 世纪的统一的公约（1924 的国际的椭球，欧洲的三角测量的调整）。**1957–1994。** 太空重新构形着形状：1958 从卫星的信号的多普勒的发现，Transit 与 SECOR 与多普勒的测量的谱系，1966 以来的卫星的激光的测距，VLBI 与 DORIS，1988 起的 ITRF 的实现带着 1984 的 WGS84 与 1989 的 GRS80 的参数集——地球的形状成为一个地心的、太空的大地的、连续维护着的对象。**1994–2025。** 精度的时代：GPS 的全的操作的能力（1994），伽利略（2016）与北斗三号（2020）完成着多星座的世界；RTK 与 PPP 与网络的 RTK 把定位从米带到毫米；IGS 与精密的产品的制度使永久的 GNSS 的网络成为一个地球物理的仪器（板块的运动与 ZTD 与 GNSS 的气象学的应用）；基准的现代化的波（2020 的 GDA2020 与 2024 的 NAD83-2024 与 NSRS 的重新对齐，PROJ-6 时代的版本化的转换的网格）使本课存在教着的历元的记账制度化。
:::

::: quiz {#quiz-projection}
一个保护的 NGO 必须计算、比较每一个国家的保护地的覆盖（公顷）。分析的 CRS 的选择应该是：

- [x] 一个等积的投影（一个大圆的面积的计算）——面积的统计要求着 $ab = 1$
- [ ] Web 墨卡托，因为所有的网络的数据在它里面
- [ ] 一个保角的投影，因为形状必须保持着
- [ ] 任何 CRS，因为面积在投影下是不变的

::: solution :::
面积在投影下不是不变的（D 是墨卡托的例子记录着的谬误）；分析需要 $ab = 1$，一个对着范围匹配的等积的 CRS、直接的地理的面积的计算机。Web 墨卡托把高的纬度的国家膨胀到 $80\times$（B 是课的标题的错误），保角的投影恰恰靠牺牲着面积保持着角度（C 是导航、大的比例的制图的选择，不是面积统计的）。
:::
:::

::: quiz {#quiz-datum}
两个机构交换着同一个的边界的地区的形状文件，都标着"纬度与经度 WGS84"，但一个在一个本地的 1950 年代的基准的地图上数字化着、从未转换着。叠加显示着：

- [x] 一个系统的偏移（数百米，恒定的方向），揭示着基准的不匹配
- [ ] 一个几米的数字化错误的随机的散布
- [ ] 完美的对齐，因为 WGS84 是 WGS84
- [ ] 只有一个旋转，因为基准只按定向不同

::: solution :::
本地的基准对着地心的相差着 $100$–$1500\ \mathrm{m}$ 的平移（加上赫尔默特的意义的旋转与比例），一个未转换的层把一个不匹配携带为一个一致的偏移的矢量——基准的例子的审计的程序（在一个共同的特征测量着矢量，让它的大小与方向命名着基准）。随机的散布（B）将指示着数字化的噪声、不是基准的移动；"WGS84"的标签是元数据的主张、不是测量（C 是贵的错误）；纯的旋转（D）只描述着一般的七或十四的参数的转换的一个分量。
:::

## 练习

::: exercise {level=1 check="55.7"}
一个纬度的度约 $111.32\ \mathrm{km}$。在纬度 $60^\circ$ 一个经度的度（乘以 $\cos 60^\circ$）多少 km，一位的小数？
::: solution :::
$111.32 \times 0.5 = 55.66$，约 **$55.7\ \mathrm{km}$**——使"度"成为一个可变的大小的单位的 $\cos(\text{纬度})$ 的收缩，度数的网格的面积统计是纬度的加权的谎的理由（墨卡托的例子的平面的对着大圆的小心），每一个等积的投影必须靠构造撤销着的算术。
:::
:::

::: exercise {level=1 check="60"}
UTM 把世界分成 $6^\circ$ 的经度的宽的区。有多少个区？
::: solution :::
$360/6 = $ **$60$**——大地的定义的 $6^\circ$ 的宽与 $8^\circ$ 的高的 MGRS 与 UTM 的分块的网格，它的边界强制着图像的处理的课的跨着区的镶嵌的决定，它的假东的 $500000$ 与比例的 $0.9996$ 的惯例以一个区的跨着的 $2500$ 的 $1$ 份的比例的不和谐为代价保持着每一个坐标正的。
:::
:::

::: exercise {level=1 check="500"}
在一个 $1:50000$ 的地形的图上，地图的一厘米代表着地面的多少米？
::: solution :::
$50000\ \mathrm{cm} = $ **$500\ \mathrm{m}$**——比例式，基准的例子的 $80$-m 的基准的移动在这样一个的图上是 $0.16\ \mathrm{mm}$ 的理由（不可见的，这就是 2010 年代与 2020 年代的地籍的争端的诉讼的文献：在纸的分辨率之下的错误也在它的法律的和差之下，直到有人在 $1:5000$ 数字化着、发现着它们）。
:::
:::

::: exercise {level=2 check="8.5"}
墨卡托的面积的比例的因子是 $\sec^2(\text{纬度})$。在纬度 $70^\circ$（$\cos 70^\circ = 0.342$）计算它，一位的小数。
::: solution :::
$1/0.342^2 = 1/0.117 = $ **$8.5$**——图表的曲线在挪威与苏格兰与南阿拉斯加的纬度上读着，2015–2025 的真实的大小与批评的制图学的文献的抱怨背后的数字：一个在北方的生物多样性与专属的经济区的图在 Web 墨卡托给这些国家它们的真实视觉的重量 $8.5$ 倍，一个带着预算与政策的后果的美学的选择。
:::
:::

::: exercise {level=2 check="3.2"}
一个在一个本地的基准的数据集从 WGS84 偏移 $80\ \mathrm{m}$。在一个 $1:25000$ 的地图（$1\ \mathrm{cm} = 250\ \mathrm{m}$）上，纸的这个偏移多少毫米，一位的小数？
::: solution :::
$80/(250\ \mathrm{m/cm}) = 0.32\ \mathrm{cm} = $ **$3.2\ \mathrm{mm}$**——谨慎的眼睛可见的、在一个世纪使这样的移动成为惯例的制图与数字化的和差之下，基准的例子的沉默的错误的机制在一个的分度里，修复是元数据（CRS 的标识符）、不是视力的理由。
:::
:::

::: exercise {level=2 check="7.5"}
一个接收机的伪距的错误约 $3\ \mathrm{m}$、位置的精度的衰减（PDOP）是 $2.5$。估计三维的位置的错误米。
::: solution :::
$3 \times 2.5 = $ **$7.5\ \mathrm{m}$**——定位的定义的 DOP 的算术（几何放大着每一个其余的错误项），卫星的星座与遮挡的设计在峡谷与冠层之下重要的理由，RTK 与 PPP 的技术（解决着载波的相位的模糊度、不是收缩着 $3$-m 的代码的噪声）是精度阶梯的厘米的横档的唯一的路线的理由。
:::
:::

::: exercise {level=3 check="2"}
在一个保角的投影在纬度 $45^\circ$，线性的比例的因子是 $\sec 45^\circ = 1.414$。面积在那里畸变多少倍？
::: solution :::
保角意味着 $a = b$，所以面积的比例 $= ab = 1.414^2 = $ **$2.0$**——蒂索的代数的练习显示着为什么保角与等积在标准纬线之外互斥，为什么兰伯特的保角的州平面的网格携带着地籍的工作的发表面积的校准的因子，为什么 2016 与 2022 的平的对着大圆的面积的研究坚持着投影由统计量选择着、不是软件的默认。
:::
:::

::: exercise {level=3 check="1000000"}
一个真实的面积 $500000\ \mathrm{km}^2$ 的国家主要位于纬度 $45^\circ$。如果它的面积在 Web 墨卡托（面积的因子 $\sec^2$ 纬度）计算，产生的表观的面积多少 $\mathrm{km}^2$？
::: solution :::
$500000 \times 2 = $ **$1000000\ \mathrm{km}^2$**——墨卡托的例子的错误数字化着（面积的两倍，答案的单位是练习的：$\mathrm{km}^2$，国家真实的 $\mathrm{km}^2$），2010 年代与 2020 年代的地理的数据的重复的审计在网络派生的国家的面积的表里不断发现的确切的失败的模式，保护的例子的保护地的统计在一个等积的 CRS、大圆的面之上运行的理由。
:::
:::

::: exercise {level=3 check="1.9"}
L1（波长 $19\ \mathrm{cm}$）的 GNSS 的载波的相位的测量达到波长的约 $1$ 个百分点的精度。那个精度多少毫米？
::: solution :::
$0.01 \times 190\ \mathrm{mm} = $ **$1.9\ \mathrm{mm}$**——本课每一个毫米的主张建造其上的观测量（雷达–激光雷达的课的板块的运动的速度与火山的膨胀的序列是载波的相位的时间序列、不是伪距），只在整数的模糊度的解决与电离层–对流层–轨道–钟的错误预算被处理之后可达到，定位的定义将模糊度称为"厘米与米的定位之间的区别"的理由。
:::

::: warning 四个坐标的谬误
1. **"纬度与经度只是纬度与经度。"** 基准与历元的谬误：在不同的基准与框架的相同的数字是不同的地方（基准的例子的 $100$–$1500$-m 的本地的基准的偏移，把坐标每年移动着厘米的板块的运动的历元的记账，把国家的坐标移动了、将移动着的 GDA2020 与 NAD83-2024 的重新分配的运动），"同一个"框架的不同的实现的相同的数字相差着实现的自己的厘米到分米的不一致。2016–2025 的转换的引擎的文献的最经常重复的发现是多数的 CRS 的错误不是数学的错误、元数据的错误——文件的 CRS 的标签描述着交付的格式、坐标的真正的历史——这就是审计的习惯（大地的定义的三行元数据，偏移的矢量的检验）比把赫尔默特的方程背熟更重要的理由。
2. **"地图的投影是一个表示的选择。"** 它是一个带着算术的后果的分析的选择：面积在保角的投影计算，距离在方位的（网络的航线的图的大圆的对着恒向线的错误），方向在妥协的，每一个分区的统计在 Web 墨卡托继承着 $\sec^2$ 纬度的加权（墨卡托的例子的 $4$–$80\times$ 的范围）；2010 年代与 2020 年代的 GIS 科学的错误的文献的案例档案（2013 与 2018 与 2022 的"GIS 里的距离、面积、体积"的课程的系列，它的结论随着投影移动的保护的规划与碳的会计的研究）记录着投影由被计算的统计量选择着，2020 年代软件的默认的对话（现代的 GIS 与可视化的堆栈的大圆的面积与真实的比例的投影的默认）是社区缓慢地内化着安全的默认是告诉着用户它假设着什么的那个。
3. **"GPS 给出你一个位置。"** 它给出你一个伪距与相位的观测量，它的位置是一个带着错误的预算的解（定位的定义的电离层–对流层–多径–轨道–钟–DOP 的会计）：智能机的 $5\ \mathrm{m}$、大地的站的 $3\ \mathrm{mm}$ 是不同的错误预算的温度的同一个星座，城市的峡谷与冠层的多径的失败的模式是物理的、不是表面的（2015–2025 的非视距与多径的缓解与视觉的惯性的融合的文献），地球物理的应用的毫米的主张完全居住在模糊度的解决与产品的制度里面——一个不带解决的周期的滑动的 PPP 的解不是一个精确的位置，它是一个精确的看起来的错误，分类的课关于精度的表做的同一个信心对着精度的区别，坐标的形式。
4. **"数字化的老的地图只是一台电脑里的老的地图。"** 遗留的层的谬误：扫描与数字化的历史的地图把它们原来的图幅的经纬网与基准与制图的错误带进着现代的分析（2010 年代–2025 的历史的 GIS 与地籍与海洋的边界的文献的橡皮拉伸 与控制点的争论，它的 19 世纪的海岸线的对着现代的海岸线的比较结果成为基准的比较的 2015–2025 的沿海的图集与航海的图的参考的研究），法律的等级的坐标的争端（2002–2025 的海洋的边界的判例的坐标的证据的协议）存在，因为一个数字化的坐标继承着它的源的每一个错误、分析者的义务是传播着它们、不是把它们像两个是同一种类的数字粘贴在 GNSS 的坐标旁边。

制图是选择着哪些谎说：地球是一个被一个椭球几乎拟合着的大地水准面，基准与框架（WGS84 与 ITRF 与区域的实现的系统，带着它们的历元与板块的运动）把地方变成数字，投影在蒂索的代数下把弯曲的数字变成平的——保角保持着角度、以面积支付着（$\sec^2$ 纬度，墨卡托的例子的 $4$–$80\times$），等积保持着面积、以形状支付着，妥协最小化着地图为了什么，选择的规则是统计量、不是软件的默认（投影的例子三个工作）。定位是坐标的生产者：伪距与载波的相位的观测量，它的错误的预算（电离层，对流层，多径，轨道，钟，DOP）跨越着智能机的米到大地网络的毫米，模糊度的解决与精密的产品的制度分离着两者，框架的转换（版本化的网格的、管道明确的 PROJ 时代的纪律，基准的现代化的历元的记账）使结果的坐标对它们自己的历史诚实。例子是应用的纪律：洪水的机构与碳的会计员按着问题选择着 CRS，Web 墨卡托的面积的神话定量化着，基准的不匹配靠偏移的矢量抓住，一个星座以三个错误预算的温度服务着三个仪器——谬误（基准的盲，投影作为美学，GPS 作为真理，遗留的层作为真理）全归结为课的一个元数据的诫命：**没有不带它的 CRS 的坐标，没有不带它的方法的转换，没有不带它的高度。** 坐标的基础设定着，课程转向着持有着它们的数据结构、在它们之上计算着的分析。
