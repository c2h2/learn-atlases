反射的光的遥感在 $3\ \mu\mathrm{m}$ 结束；过去它的一切是地球用自己的声音说话。发射的辐射携带着反射的光谱不能的两个量：**温度**（热的红外的普朗克的函数的信号，一个在 $200$–$320\ \mathrm{K}$ 的辐射着、在 $10\ \mu\mathrm{m}$ 附近达到峰值的陆地或云的表面），在微波里，**表面自己的介电的状态**——液态水的约 80 的介电的常数对着干的土壤的 4、冰的 3.2，所以厘米的波长的亮度由最上面的厘米是湿的、冻结的、开阔的海洋统治着。无源的微波与热的红外的感测因此是课程的第二个物理学：同样的辐射度量，不同的源项，带着它的一套不同的超能力——微波穿过云看，看进干的土壤的上面的米，从太空测量着行星的降雨，在每一个天气的条件下保持着极地的海冰的 45 年的连续的记录；热的红外把一个开尔文测量着陆地的表面的温度，城市的热岛，火山的与火的热点，灌溉的政策依赖着的蒸散。本课建造着发射的辐射的链：普朗克与基尔霍夫到亮度温度，大气的窗口与它的水汽的校准（分窗的家族），温度/发射率的分离的问题，微波的辐射计的介电的物理学，天线的限制，穿透的深度；然后旗舰的检索——陆地的表面的温度，土壤的湿度，海冰的浓度，降水——每一个是一个选择着通道使一个变量对着其余的可见的工作的例子。先决的条件是辐射的一课的辐射度量、分类的课的错误传播的习惯；在下面运行的警告是辐射的一课的第三个谬误的一般化：**亮度绝不是温度，温度绝不是你想要的性质**，除非发射率与散射被明确地处理过。

::: definition 热的红外：亮度温度到表面的温度 {#def-tir}
在 $10$–$12\ \mu\mathrm{m}$ 窗口的在传感器的热的辐射的亮度是表面的项（发射率乘以表面的温度的普朗克的函数，被大气衰减着）加上上流的大气的路径的辐射的亮度、减去表面反射着的下流的大气的辐射的亮度（按 $1-$ 发射率缩放，基尔霍夫再一次）——整个的陆地的表面的温度的检索的文献是那四项的记账。**亮度温度**（在一个通道上测量的辐射的亮度的普朗克的函数的反演）是原始的量；**表面的温度**要求着大气的校准，靠三种方式买来：**分窗的家族**（跨越 $11$–$12\ \mu\mathrm{m}$ 的水汽的梯度的两个或三个通道，它的微分的吸收显示着路径的项——从贝克尔–李与乌利维里的公式经过 MODIS 的昼与夜的算法的 $\pm 1\ \mathrm{K}$ 的验证的统计到 2020 年代的 VIIRS 与 ECOSTRESS 的继承者的 1990–2025 的谱系），**清晰的天空的发射率与辐射的传输的家族**（带着再分析的水汽反演的 MODTRAN 与 6S 的正向的模型，Landsat 的 LST 的谱系），高光谱的与昼夜的情形**温度/发射率的分离的家族**（1990 年代–2020 的 ASTER TES 与 ICEMAND 与同时的估计的文献，它的基本的简并——辐射的亮度是两个未知的量的乘积——只靠光谱的平滑的假设、时间的变化、先验的知识打破，这就是辐射的一课的谬误 3 的警告附带着一个整个的子学科的理由）。发射率自己是一个测量的材料的性质（1970 年代–2020 的野外的分光光度法的图书馆：土壤 0.90–0.97 带着矿物的结构，植被 0.97–0.99 带着一个湿度控制的斜率，水 0.96–0.99 带着剩余射线带的结构，2010 年代的粗糙度的文献显示着纹理的表面在视图的平面里压低着方向的发射率），错误的算术是残酷的、简单的：在 $300\ \mathrm{K}$ 与 $11\ \mu\mathrm{m}$，$dT/T \approx d\varepsilon/(4\varepsilon)$，所以一个 0.02 的发射率的错误是约 $1.5\ \mathrm{K}$——比产品被要求分辨的多数的气候的信号大。应用按着那个错误的预算分层：**城市的热岛**（表面的温度的 $5$–$10\ \mathrm{K}$ 的差异，对发射率的错误鲁棒的），**蒸散**（水文学的课的 SEBAL 与双的源的能量平衡的谱系，冠层与空气之间的温度的梯度做着功），**热的异常**（自然灾害的课的火的与火山的中的波的 $3$–$4\ \mu\mathrm{m}$ 的谱系，亚像素的热的目标靠普朗克的函数的指数统治着、$1\ \mathrm{km}$ 的像素看到 $1\ \mathrm{m}^2$ 的火），**气候的记录**（2003–2025 的 MODIS 与 VIIRS 的 LST 的气候学、它的陆地的表面的物候的使用），每一个只带着说明着的发射率的项诚实。
:::

::: definition 无源的微波：亮度温度，介电的，穿透 {#def-pmw}
微波的辐射度量测量着自然的发射的瑞利–金斯的尾部：在 $1$–$100\ \mathrm{GHz}$、$200$–$300\ \mathrm{K}$，辐射的亮度对温度是线性的，所以**亮度温度** $T_b = \varepsilon T_{\text{物理}}$（一般化到一个散射与发射的介质上的积分）是一个直接的物理的通货——你能在手里、在开尔文拿着的唯一的遥感的量，带着几个十分之一开尔文好的校准的历史（1987–2025 的 SSM/I-SSMIS-AMSR-E-AMSR2-GMI 的辐射计的相互校准的谱系，绑到深的冷的空间与海洋的目标）。统治的材料的性质是**复的介电的常数**：液态水的实的部分约 80（频率与温度的依赖的），冰约 3.2，干的土壤 $3$–$5$，植被在水的充满的分数里 $10$–$30$——所以微波的发射与反射率由液态的内容统治，随之的菲涅尔的系数使开阔的海洋（$\varepsilon \approx 80$）成为一个辐射着约 $50$–$120\ \mathrm{K}$ 的几乎的镜子、干的土地（$\varepsilon \approx 4$）在它的物理的温度附近辐射着，使海冰从太空可见的对比。**光学的深度**做着其余的：从深度的发射作为 $\exp(-\tau)$ 衰减，所以感测的深度由吸收设定（液态水使湿的土壤在所有的微波的频率上几乎不透明的，干的沙子到米透明的——使干旱区的考古的雷达、水文学的课的古的水的表可能的穿透的深度的表）、由**植被的光学的深度**设定（1980 年代–2020 的三频率的 M 的文献：在 L 与 C 波段的森林的微波的透明，所以稀的冠层之下的土壤的湿度是可测量的、雨林之下的不是，植被的水的内容自己在更长的波长上成为可检索的）。仪器的物理学是天线的限制：一个辐射计的足迹是衍射的斑（波束的宽度乘以距离——从低的轨道数百公里，除非天线是大的），所以领域的几何一直是一个反对足迹的运动：锥的扫描（SSM/I 的 $25$–$85\ \mathrm{km}$ 的足迹，1987 的遗产），合成的聚焦（ESA 的 2025 的 SMOS 干涉的孔径的合成，从一个 $6\ \mathrm{m}$ 的可展开的 Y 在 L 波段的约 $40$-km 的有效分辨率），延迟–多普勒的聚焦（NASA 的 2015 的 SMAP，把 L 波段的辐射度量与失败的、恢复的雷达的后向散射结合的 $30$–$36\ \mathrm{km}$ 的辐射计的足迹），两个 L 波段的任务构成着 2015–2025 的土壤的湿度的参考的层（C 波段的 ASCAT 的散射计的 $25\ \mathrm{km}$ 的操作的无源与有源的配对，2020 年代的 C 波段与 L 波段的融合的产品）。检索的模式重复着：选择在目标的介电的或散射的特征对着混淆不同的频率（$1.4$-GHz 的土壤的湿度的通道，$6.9$-GHz 的海冰的连接点的通道，$85$-GHz 的散射敏感的降水的通道，$22$-GHz 的水汽、$60$-GHz 的氧的通道用于路径的校准与表面的压力），选择着偏振（在入射上水平的对表面的粗糙度的效应比垂直的不太敏感的，偏振的差异自己就是粗糙度与表面的取向的信息），用物理学作为先验、地面的网络（2010 年代–2025 的 ISMN 与 SMNet 与系泊与冰的浮标的验证）作为陪审团反演着。
:::

::: definition 探测着大气：压力，水汽，剖面 {#def-sounding}
隐藏或显示着表面的同样的窗口的物理学，当通道被放置在吸收的特征**内部**、不是在它们之间时，把大气自己变成目标。$60$-GHz 的氧的复合（$50$–$60$-GHz 的带的压力加宽的翼）是微波温度计：从每一个大气层的发射被压力的依赖的吸收加权，所以逐通道的亮度温度映射到逐层的温度——1998–2025 的 AMSU-A 与 ATMS 的温度探测谱系（2002 与 2020 的交叉的偏振与波束的切换的精炼）背后的**氧探测**的原则，它带着红外的 CO$_2$ 带的探测者（气象的预报的数据同化的饮食的 1978 的 HIRS 到 2002 的 AMSU 到 2006 的 AIRS 到 2012 的 CrIS 到 2023 的 CRS 与 IASI 的世代），供应着使 2002 之后的数值的天气的技能的增长可能的云独立的垂直的温度剖面——探测的**加权函数**（每一层的起源的概率的分布，在斜的光学的深度达到一时达到峰值）是检索的基本的设计对象：选择着吸收的强度，选择着你听到的压力的水平。水汽的线（$22$-GHz 的线、$183$-GHz 的转动的复合）探测着湿度与总的柱（2002 与 2012 的 AMSU-B 与 MHS 的湿度探测与云的液体的水的谱系，降水的例子的 2014 的 GMI 的 $183$-GHz 的三联），$118$-GHz 的线在全天的同化下探测着温度（2010 年代–2020 的全天的与辐射的同化的革命，直接摄入着多云的与降水的辐射），表面的压力的产品（2020 年代的 $50$–$60$-GHz 的氧的吸收的极的计，2023–2025 的商业的与 EUMETSAT 的概念）为气象的风暴的课的气旋的增强的研究关闭着热力学状态。检索是无源的微波的定义的积分被评估、不反演：亮度温度是发射乘以加权函数的层的积分，用逐线的或相关的 k 的光谱学正向地建模（1990 年代–2020 的 RT 与 CRTM 与 MIPLIN 的线，它的光谱的参数数据库——HITRAN 与 MPM 与 JPL 的目录，在十年的周期上更新着——是每一个探测的错误预算之下的安静的基础设施），同化的系统直接消费着辐射、不检索的剖面（2005–2025 的直接辐射的同化的标准），它是"为什么根本飞行着探测者"的问题的观测的系统的设计的回答：剖面是为了人，辐射是为了模型，同一个光子的两种读法都发表。
:::

::: example 城市的热岛：一个开尔文规模的不平等的图 {#ex-uhi}
Landsat 的热的带（$10.8\ \mu\mathrm{m}$，在 Landsat-8 与 9 上原生的 $100\ \mathrm{m}$，重新采样到 $30$，辐射的 12 位、开尔文的一个分数好的）把城市的热岛从一个站的天气学的概念变成一个表面的温度的场：2013–2025 的表面城市热岛的文献的爆炸（数千个研究制图着工业的核心与郊区的公园之间的 $5$–$10\ \mathrm{K}$ 的白天的陆地的表面的温度的对比）依靠着定义的分窗与发射率的记账，它诚实的错误预算是发射率的项——在 $0.85$–$0.95$ 的范围带着腔的几何的方向性测量的屋顶与沥青的发射率，意味着一个混凝土的屋顶与一个阴影的树的冠层之间的表面的温度的差异在真实的温度的差异之上携带着 $1$–$3\ \mathrm{K}$ 的发射率的伪影，这就是谨慎的研究（2018–2024 的伦敦与巴塞尔与东京的发射率的野外的运动的论文）在温度旁边制图着发射率、定义的温度的与发射率的分离的警告是"绿的屋顶是凉的"（鲁棒的）与"这个屋顶比那个凉 $2.3\ \mathrm{K}$"（乐观的）之间的区别的理由。幸存着错误的预算的应用要紧：表面的温度的合成驱动着热的风险的暴露的图（2018–2025 的城市的气候的文献的夜的岛、按收入的陆地的表面的温度的不平等的分析，自然灾害的野火–旱–热的课引用着），蒸散的产品（SEBAL 与 EEFLUX 与 SSEBop 的谱系）为地球的资源的水的章节在田的规模分配着灌溉与旱的压力，在保持位置的 ISS 上的 ECOSTRESS（2018–）添加着植物的水的压力的指数需要的超越的时间的多样性——热的一课的应用的方面日益是操作的。
:::

::: example 土壤的湿度：SMAP，SMOS、陆–气的耦合 {#ex-soilmoisture}
L 波段的微波（$1.4\ \mathrm{GHz}$，约 $21\ \mathrm{cm}$）穿过多数的植被看到土壤的上面约 $5\ \mathrm{cm}$，它的亮度温度响应着介电的常数——在 20 个百分点的体积的湿度上介电的常数相对于干的土壤加倍、亮度温度下降着数十个开尔文，使 2015–2025 的 SMAP 与 SMOS 的土壤的湿度的产品（原生的 $36$-km 与 $43$-km，$1$–$5\ \mathrm{km}$ 的 2020 年代的降尺度的、融合的 C 波段的 ASCAT 的产品）成为第一个全球的、全天候的、十年的表面的水的状态的记录的敏感性。验证的记录是定义的检索的模式在工作：ISMN 与 SMNet 与涡动的站网的比对报告着 $0.04$–$0.06\ \mathrm{m^3/m^3}$ 的无偏的 RMSE（2016–2024 的 SMOS 与 SMAP 的互相比对的文献），足够好为产品建造着服务的科学——陆–气的耦合的分析（2015–2025 的蒸散与热浪的开始的研究，湿度的预调节设定着气候的变化的极端的课的热浪依赖着的分配），洪水的预测的初始化（洪水的章节的 2020 年代的事件前的饱和的文献），旱的监测（操作的农业气象学的谱系的根区的表面的融合的产品），观测把陆地的表面的模型的状态推着的 2018–2025 的 Land-Ensemble 与 LASSO 的分析的数据同化的试验——警示的发现同样是一致的：检索在密的植被下退化（热带的光学的深度的墙），在冻结–融化的转换的区（2020 年代的冻结–融化的产品作为一个信号利用着的、不是相反的介电的不连续），在 $36$-km 的足迹的混合的陆–水–地形的边缘，恰恰是 $1$-km 的融合的产品（2023 年与以后的 NASA 与 EUMETSAT 的协调的系统的操作的层）挣着它们的报酬的地方。
:::

::: example 海冰的浓度：从一个连接点的方程的 45 年 {#ex-seaice}
海冰与开阔的海洋是自然提供的微波的对比：在 $6.9\ \mathrm{GHz}$ 的几乎的镜子的海洋（一个以入射的角依赖的 $50$–$120\ \mathrm{K}$ 的亮度辐射着的菲涅尔的反射器）对着体积散射的、卤水的口袋布满的冰（在它的物理的温度 $190$–$260\ \mathrm{K}$ 附近辐射着）给出一个两个端元的线性的混合物——**连接点的算法**（1980 年代–2025 的 NASA-Team 与 Bootstrap 与 OSSAF 的谱系：浓度从每一个通道、每一个半球、每一个季节的一个气候学的冰与水的连接点之间的观测的亮度）产生了 1979–2025 的从 SMMR、SSM/I、SSMIS 的连续的无源的微波的海冰的记录，冰川的海冰的课的观测的骨干、气候的变化的课程的最被引用的时间序列。错误的预算是定义的介电的物理学的倒退：连接点的漂移（水的连接点随着风、涌、温度移动；冰的连接点随着温度、卤水），$25$-km 的足迹的海岸与陆的污染（2010 年代–2020 的海岸的插值的文献），融化的池塘与冰上的雨的天气的效应（使夏天的浓度成为记录的最弱的季节、因此 2020 年代在融化中对 $89$-GHz 与交叉的偏振的通道的依赖的夏天的反照率与散射的文献），算法的散布（2014–2024 的互相比对：在内部的 $\pm 2$–$5$ 个百分点，在边缘的冰的区的 $\pm 15$ 个百分点，2020 与 2023 的 NASA-Team 的修订的争论定量着的记录对连接点的方法论的趋势的敏感——分类的课的方法论的选择移动着趋势的规则的一个现实世界的演示）。记录的独立的检验（2019 与 2024 的 CS2 与 SMOS 与 AMSR2 与 ICESat-2 的 L 波段与 Ka 波段的相互校准，对着系泊的、机载的、原地的传感器）关闭着无源的微波的定义开着的循环：物理学选择的通道，开尔文校准的仪器，地面的网络作为陪审团，一个它的不确定的带是一个发表的、辩护的、演化着的东西的 45 年的气候的记录。
:::

::: example GPM：从 $400$ 公里之外称着雨 {#ex-gpm}
微波的降水的感测是定义的散射的逻辑转向着大气：雨滴发射与散射着上流的辐射的亮度，在 $85\ \mathrm{GHz}$ 与以上大滴的对着冷的云的背景的散射的特征按着雨的液体的水的含量比例地压暗着亮度温度——热的红外的情形相反，卫星只看到着云顶、必须从云顶的温度推断着雨（1979–2025 的红外的算法的谱系，它的地球静止的连续性仍然供应着半小时的现在的预报）。1997–2025 的无源的微波的降水的谱系（TRMM 的 TMI，2014 的 GPM 的 GMI 带着它的 $89$ 与 $166\ \mathrm{GHz}$ 的交叉的偏振的通道，2021–2025 的 GPM 星座的相互校准的辐射计的网络）恰恰实施着检索的模式：为散射的对比选择的频率，为冰对着液体的辨别选择的偏振（2014 的 GMI 的交叉的偏振的通道的记录的高纬度的与降雪的检索的改进），约束着路径与压力的 $22$ 与 $60$-GHz 的通道，辐射的绑着的整个的星座（GPM 的校准与验证的观测站的深的空间与海洋的参考的链），一个开尔文的几个十分之一的亮度温度的差异——一个中等的阵雨的散射的信号——在 $5$-km 的分辨率上可信的。验证的陪审团是定义的最后的话：2015–2025 的 GMI 的 IMERG 的评估（双的精度的雨量计与双偏振的雷达与雨滴谱的野外的运动）报告着陆地上 10–20 个百分点的条件偏向（在地形的与冻结的制度更差，在海洋上更好），产品（水文学的降水–蒸发的课的洪水的水平衡的研究的 2014–2025 的 IMERG 半小时的全球降水的分析）携带着那些数字作为发表的误差条——整个的链，从介电的常数到洪水的警告，一个执行着的例子：选择着通道使一个变量比混淆说话得更大声、测量着多大声音。
:::

::: history 辐射计，窗口，从太空的水的循环 {#hist-thermal}
**1946–1972。** 微波的辐射度量的起源是军事的、天气的：1946–1950 的机载的微波的辐射计（罗伯特·迪克的辐射计的谱系，它的总的功率与迪克的切换的设计仍然是校准的教科书），TIROS 与 Nimbus 的 1960 的卫星的红外辐射计（维尔纳·苏奥米的旋转的扫描光度法，1969–1971 的 Nimbus 与安德森的表面温度的遗产），第一次从 $8\ \mathrm{GHz}$ 制图着海洋的风与冰的 1972–1978 的 Nimbus-5 与氢的迈瑟时代的 ESMR。**1972–2000。** 窗口的时代成熟着：1972–1984 的 SMMR、1987 的 SSM/I 的微波的探测者的谱系使海冰，水汽，云的水、（靠 1983–1990 的格罗迪与贝茨的谱系）降水成为操作的；1975–1988 的分窗的公式（1977 的普拉塔、1990 的贝克尔–李的解析的透射率的论文，1988–1990 的 MODIS 的设计时代的研究）准备着热的红外的温度的检索；1978–1986 的热的红外的野外的分光光度法的图书馆（1980 年代–1990 的 MODSPEC 与 FIELDTRIP 的运动）供应着算法除着的发射率的表。**2000–2025。** 水与能量的循环的任务到达：ASTER 的 2000 的温度与发射率的分离的仪器，2002–2023 的 MODIS 的 LST 与发射率的操作的记录，AMSR-E（2002）与 AMSR2（2012）的全球的微波的成像，SMOS（2009）与 SMAP（2015）打开着 L 波段的土壤的湿度与海洋的盐度的窗口，GPM（2014）把降水的星座全球化，ECOSTRESS（2018）、2023–2025 的 SBG 与 LDPESS 时代的热的设计把温度的记录带向亚开尔文与每小时的制度，公开的、在开放的存储库的时代演示着一个 45 年的气候的数据记录只像它的最后的相互校准一样老的 2019–2025 的海冰的记录的修订的争论。
:::

::: quiz {#quiz-tes}
为什么温度/发射率的分离的问题是基本的、不是更好的校准的问题？

- [x] 辐射的亮度是两个未知的量（发射率、温度的普朗克的函数）的乘积，所以一个通道绝不能决定两者——额外的信息必须来自光谱、时间、先验
- [ ] 因为热的探测器比可见的探测器漂移得更多
- [ ] 因为在 $11$ 微米大气比表面辐射得更多
- [ ] 因为发射率不是材料的一个物理的性质

::: solution :::
简并是代数的：一个测量，两个未知；分窗的家族统计地打破着它（水汽的微分，假设的发射率），高光谱的与昼夜的家族带着额外的独立的信息（光谱的平滑，热的惯性）打破着它，恰恰如定义说明的。探测器的漂移（A）、大气的发射（C）是校准处理着的真实的错误的项；它们不是简并。发射率非常是一个材料的性质（D）——在野外的分光光度法的图书馆里测量着——这就是假设它错如此昂贵的理由。
:::
:::

::: quiz {#quiz-pmw}
为什么 L 波段的微波的辐射度量能在热的红外不能的树冠之下检索着土壤的湿度？

- [x] 在许多冠层的 $1.4\ \mathrm{GHz}$ 的微波的植被的光学的深度是一阶或更小的（光子穿透），在 $11$ 微米的热的红外在叶的表面内几微米被吸收着
- [ ] 因为森林比空气更暖，增强着微波的信号
- [ ] 因为冠层不辐射着微波的辐射
- [ ] 因为 L 波段的波长在叶子周围散射、不吸收着

::: solution :::
穿透是一个吸收与不透明的问题：$11$-$\mu\mathrm{m}$ 的光子只看到着叶的表面的皮肤（定义的感测的深度的论证），$21$-cm 的光子带着适度的光学的深度穿过着冠层（M 频率的文献）、然后由土壤的介电的常数统治着——衰减的，可校准的，不阻塞的。冠层确实辐射着微波（C 是假的，发射是检索的混淆）；散射（D）在这些尺寸上不是机械；（B）不是一个东西。
:::

## 练习

::: exercise {level=1 check="9.7"}
使用维恩的定律（$\lambda_{\max} = 2898/T\ \mu\mathrm{m}\cdot\mathrm{K}$），一个 $300\ \mathrm{K}$ 的陆地的表面的峰值的发射的波长是多少，$\mu\mathrm{m}$ 的一个位的小数？
::: solution :::
$2898/300 = 9.66$，约 **$9.7\ \mu\mathrm{m}$**——恰好在 $8$–$14\ \mu\mathrm{m}$ 的窗口内部，热的定义的设计的巧合（窗口的两个最好的通道，$11$ 与 $12\ \mu\mathrm{m}$，坐在温度的敏感性高、水汽的微分可用的普朗克曲线的陡坡上）。
:::
:::

::: exercise {level=1 check="95"}
一个在 $11\ \mu\mathrm{m}$ 带着 0.95 的发射率的表面像一个辐射着 100 个辐射的亮度的单位的黑体在它自己的温度上辐射着。传感器从表面的项收到多少个单位？
::: solution :::
$\varepsilon \times B(T) = 0.95 \times 100 = $ **$95$ 个单位**——基尔霍夫的记账在一个乘法里，辐射的一课的谬误 3 的算术（一个 5 个百分点的发射率的错误是一个 5 个百分点的辐射的亮度的错误、在 $300\ \mathrm{K}$ 一个约 $1.3\ \mathrm{K}$ 的温度的错误）直接传播进每一个陆地的表面的温度的主张的理由。
:::
:::

::: exercise {level=1 check="21"}
一个在 $1.4\ \mathrm{GHz}$ 运行的 L 波段的微波的辐射计的波长是什么？（$c = 3\times10^8\ \mathrm{m/s}$；给出厘米的答案。）
::: solution :::
$\lambda = 3\times10^8/1.4\times10^9 = 0.214\ \mathrm{m} = $ **$21\ \mathrm{cm}$**——穿透与穿透的妥协的波长：足够长穿过着冠层、进入着干的土壤（土壤的湿度的例子），足够短一个实际的天线仍分辨着一个 $30$–$40$-km 的足迹（天线的限制的一句话），这就是 L 波段直到 SMOS 与 SMAP 的孔径的合成与延迟–多普勒的独创性（2009–2015）才成为一个土壤的湿度的仪器的理由。
:::
:::

::: exercise {level=2 check="302"}
一个分窗的检索使用 $T_{\text{表面}} = T_{11} + a(T_{11}-T_{12}) + b$、$T_{11} = 300\ \mathrm{K}$、$T_{12} = 298\ \mathrm{K}$、$a = 1.5$、$b = -1.0\ \mathrm{K}$。检索的表面的温度（K）是多少？
::: solution :::
$T = 300 + 1.5\times2 - 1.0 = $ **$302\ \mathrm{K}$**——分窗的逻辑在一行里：$11$–$12$ 的亮度差异主要是水汽的路径（大气在 $12$ 更不透明的，所以微分的项估计着、移走着路径，留下着表面比它自己的最透明的通道的亮度更暖——大气一直在减去的地方校准添加着。
:::
:::

::: exercise {level=2 check="138"}
一个微波的像素在足迹内是 60 个百分点的开阔的水（亮度温度 $50\ \mathrm{K}$）、40 个百分点的陆地（$270\ \mathrm{K}$）。足迹的平均的亮度温度是多少？
::: solution :::
$0.6\times50 + 0.4\times270 = 30 + 108 = $ **$138\ \mathrm{K}$**——瑞利–金斯制度的线性的混合（海冰的例子的连接点的方程倒读），两个例子标记着的海岸的海冰与陆–水的边缘的错误的项背后的足迹的污染的算术：一个 40 个百分点的陆的分数使一个海洋的像素看来像冰。
:::
:::

::: exercise {level=2 check="0.73"}
海冰的连接点的算法：观测的 $6.9$-GHz 的亮度温度 $150\ \mathrm{K}$，冰的连接点 $190\ \mathrm{K}$，水的连接点 $40\ \mathrm{K}$。冰的浓度（线性的混合物，两个位的小数）是多少？
::: solution :::
$C = (150-40)/(190-40) = 110/150 = 0.733$，约 **0.73**——45 年的记录的核心的方程，它在同样的数字里看得见的错误的结构：把水的连接点移动 $10\ \mathrm{K}$（一个风暴，一个涌，一个季节），浓度移动 $10/150 = 7$ 个点——2020 与 2023 的记录的修订的争论为趋势定量着的连接点的方法论的敏感，作为一个气候记录的事实上的，分类的课的"方法论的选择移动着趋势"。
:::
:::

::: exercise {level=3 check="183"}
一个微波的辐射计有一个 $15$ 度的天线的波束的宽度，在 $700\ \mathrm{km}$ 的高度飞行。它的足迹大致是弧度的波束的宽度乘以距离。给出最近的公里的足迹的直径。
::: solution :::
$15^\circ = 0.262$ 弧度；足迹 $\approx 0.262\times700 = 183$，约 **$183\ \mathrm{km}$**——无源的微波的定义的衍射的限制在一个乘法里（1987 的 SSM/I 的 $25$–$85$-km 的足迹需要着 $6$-m 的反射器、SMOS 与 SMAP 的干涉的与延迟–多普勒的聚焦从可比较的硬件买到 $30$–$40\ \mathrm{km}$ 被算作一个十年的仪器的物理学的理由）。
:::
:::

::: exercise {level=3 check="1.5"}
在 $300\ \mathrm{K}$、$11\ \mu\mathrm{m}$，线性化的错误的关系是 $\Delta T \approx T\cdot\Delta\varepsilon/(4\varepsilon)$。带着 $\varepsilon = 0.97$、一个 $\Delta\varepsilon = 0.02$ 的发射率的错误，温度的错误（K）是一个位的小数是多少？
::: solution :::
$\Delta T \approx 300\times0.02/(4\times0.97) = 6/3.88 = 1.55$，约 **$1.5\ \mathrm{K}$**——陆地的表面的温度的产品之下的发射率的错误的地板（定义的残酷的算术），在许多植被的边缘的研究里的城市–农村的差异大、比传感器的噪声大一个数量级，这就是你假设的发射率的表在实践中是你的温度的图的精度的陈述的理由。
:::
:::

::: exercise {level=3 check="0.3"}
一个微波的辐射计的噪声的等价的亮度温度是 $\Delta T = T_{\text{系统}}/\sqrt{B\tau}$、系统的噪声的温度 $T_{\text{系统}} = 600\ \mathrm{K}$、带宽 $B = 100\ \mathrm{MHz}$、积分的时间 $\tau = 0.04\ \mathrm{s}$。计算 $\Delta T$（K）。
::: solution :::
$B\tau = 10^8\times0.04 = 4\times10^6$ 个样本；$\sqrt{} = 2000$；$\Delta T = 600/2000 = $ **$0.3\ \mathrm{K}$**——辐射计的光子的计数的敏感性律（带宽乘以时间是测量的样本的预算，恰恰是传感器的课的 SNR 的算术在开尔文的单位里），一个 $0.3$-K 的噪声的地板对海冰的例子的 $150$-K 的连接点的分离微不足道的小、对降水的例子的开尔文的几个十分之一的散射的信号是决定性的理由——每一个无源的微波的任务最终是这一个方程里写成的一个积分的时间对着足迹对着条带的论证。
:::

::: warning 四个发射的辐射的谬误
1. **"亮度温度是表面的温度。"** 身份在课触及的每一个制度里失败：在热的红外，低于一的发射率，大气的路径与反射的项、（在水上）天空自己的反射的发射全坐在两者之间（$1.5$-K 的发射率的地板，分窗的存在的全部的理由）；在微波，亮度是乘以发射率与光学的深度的效应的物理的温度，所以一个 $270\ \mathrm{K}$ 的陆地的特征是一个穿透明的植被看到的 $270\ \mathrm{K}$ 的表面、一个向传感器衰减着的更暖的表面——海冰的例子的 $50$-K 的海洋的亮度强调地不是一个 $-23\ ^\circ\mathrm{C}$ 的海。2020 年代的产品文档的标准（CEOS 与 WMO 的元数据的制度）现在要求说明着一个热的产品是哪一个温度——亮度，皮肤，表面，根区加权的——因为消费者的社区（气候的模型者，水文学家，暴露的制图者）每一个把"温度"的字读为它自己的变量，气候的变化的观测的变化的课的陆地的表面的温度对着模型的空气的温度的比对是这个恰恰的谬误的机构的版本。
2. **"微波穿过着一切看。"** 云，是的——那是窗口的标题、雷达与辐射计的舰队的操作的优势；同一个窗口根据着液态的水与入射的几何是不透明的、透明的：雨在更高的微波的频率上散射与吸收着（降水的例子的整个的信号，"全天候"的降水的雷达仍失去着重的对流的单元之下的海洋的理由），开阔的水在每一个微波的频率上是一个镜子（连接点的记录的风与涌与闪烁的结构），C 波段的植被的不透明在热带是一堵墙（土壤的湿度的例子的冠层的限制）。正确的陈述是定义的：微波的窗口是一个**介电的**窗口，在液态的水缺席或束缚的地方对微波透明的、在它自由的地方不透明的——这就是技术漂亮地制图着土壤的湿度与冰、在雨林的最上面的米之下根本不制图着任何东西的理由。
3. **"更高的分辨率总是更好。"** 无源的微波的领域花费着二十年与两个旗舰的任务（天线的限制的段落）用物理学买着分辨率——孔径的合成，延迟–多普勒，无源与有源的融合——因为足迹以下的分辨率是光子未携带着的信息，2020 年代的降尺度的文献的谨慎的结果（$1$-km 的融合的土壤的湿度的产品的技能集中在粗的检索已经代表的地方，足迹的混合的像素里的假的结构）在开尔文里重复着传感器的课的超分辨率的判决：降尺度的产品是带着一个物理学的知情的先验的插值，先验知道的梯度优秀的、对它不知道的沉默的，用户的问题（"$1$-km 的网格的单元对我的田说什么？"）通常被带着它的发表的错误的 $9$-km 的检索比带着它的未发表的错误的 $100$-m 的产品更诚实地回答着。
4. **"一个校准的仪器意味着一个校准的记录。"** 辐射的校准的链（深的空间与海洋的参考的制度）把单个的仪器保持在开尔文的十分之一，海冰的记录的修订的历史（2020 与 2023 的连接点与传感器的合并的争论，移动着十年的趋势的 $\pm 2$–$5$ 个百分点的算法的散布）显示着记录的不确定度生活在检索的选择与传感器的转换、不在天线上——分类的课的收集的版本化的警告、图像的课的制度变化的谨慎的同一个教训，在气候的记录的规模：**相互校准是一个连续的科学的计划、一个发射日的证书**，这就是 GPM 的校准的观测站与 CMIR 的记录制度存在、任何一个引用着一个 45 年的记录的研究应该在同一个句子里引用着产生它的算法的版本的理由。

::: summary
发射的辐射的遥感是课程的第二个物理学：过去 $3\ \mu\mathrm{m}$ 太阳停止说话、地球说话，测量对着一个介电的世界是普朗克与基尔霍夫。**热的红外**（$8$–$14\ \mu\mathrm{m}$ 的窗口）产生着**温度**——亮度温度靠分窗的微分的吸收、辐射的传输的反演、温度/发射率的校准到表面的温度，带着发射率的项（每 $0.02$ 的 $d\varepsilon/4\varepsilon \approx 1.5\ \mathrm{K}$）作为决定着哪些应用诚实的精度的地板：城市的热岛与热的异常（鲁棒的，开尔文的规模），精细的屋顶之间的比较与亚开尔文的气候的陈述（不带发射率的野外的作业不诚实）。**无源的微波**产生着**状态**——介电的常数的统治（水 $80$，冰 $3.2$，干的土壤 $4$）使液态的水成为可见的变量：从一个两个连接点的线性的混合、作为一个 45 年的气候的记录保持着的海冰的浓度，从 L 波段的亮度穿过着可穿透的冠层的土壤的湿度（$0.04$–$0.06\ \mathrm{m^3/m^3}$ 的 SMAP 与 SMOS 的验证的制度），从 $85\ \mathrm{GHz}$ 与以上的散射的压暗的降雨（GPM 的星座的相互校准的开尔文的几个十分之一的信号），全部由使孔径的合成与延迟–多普勒的聚焦成为十年的仪器物理学的衍射的限制统治着。例子是执行着四次的定义的检索的模式——选择着通道使一个变量比混淆说话得更大声，开尔文规模的校准的链，地面的网络作为陪审团，发表的、修订着的错误的预算——谬误（亮度作为温度，微波作为全知的，分辨率作为信息，校准作为记录）是反射的光的课警告着的一切的发射的辐射的版本，现在附着着气候的记录的后果。拿着无源的谱的两半，课程转向着有源的：测量着毫米的运动的相干的回波，数着冠层的层的激光。
