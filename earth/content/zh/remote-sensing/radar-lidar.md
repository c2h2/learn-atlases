有源的感测改变着交易：仪器带来着自己的照明，带着被动传感器不能有的两样东西——**控制**（你选择着波长，偏振，入射的角，定时），**相干**（返回的波保留着相位的记录，相位是一把尺）。合成孔径雷达的相位的干涉测量从 $700\ \mathrm{km}$ 把地面的运动测量到毫米；它的幅度的后向散射穿过着云，夜、中的雨看，给 2014–2025 的 Sentinel-1 的时代它的洪水的图与冰的速度场；激光雷达的光子的计数的飞行时间把森林的垂直的结构、冰盖与海洋的高度测量到厘米。本课建造着地球科学使用着的三个有源的系统：**雷达**（相干的微波的成像者：后向散射的物理学、介电的与粗糙度的控制，从运动买着分辨率的合成孔径的聚焦，带着它的大气与轨道的错误的预算的干涉测量的相位到位移的反演），**高度计**（对表面的雷达与激光的测距，它的脉冲的形状与波形的分析给出厘米的海表面的高度，显著的波的高度，冰盖的高程，冠层的结构），**激光雷达**（激光的测距与全波形的扫描，ICESat-ATLAS 的光子的预算，GEDI 与 ATLAS 的生物量与冠层的高度的检索，光学的课的裸的地球的数字的地形的模型）。先决的条件是辐射的一课的相干与散射的讨论、图像的课的斑点与滤波、分类的课的对参考的数据的怀疑；贯穿着的警告是相位像一个尺子一样精确、像一把尺子一样脆——一个失相干的干涉图只是一张漂亮的噪声的图。

::: definition 合成孔径雷达：相干的后向散射，相位的记录 {#def-sar}
一个雷达的图像是一个**后向散射的系数** $\sigma^0$（每单位的地面的面积返回的发射的功率的分数，以分贝报告着）被系统的几何调制着的图，三个物理的控制解释着雷达的图像看来像的多数。**介电的**统治着：菲涅尔的对比（液态水的约 80 的介电的常数对着土壤的 4、植被的 $10$–$30$）使湿的表面与开阔的水在中等入射上暗（镜子的反射把能量发送离着传感器），使土壤的湿度成为 Sentinel-1 的图像的最强的幅度的信号（操作的 Copernicus EMS 产品的 2015–2025 的表面水与洪水的制图的谱系，与无源的微波的课的同样的介电的物理学、传感器选择着入射的角）。**粗糙度**对着波长决定着散射的强度：一个表面在它的高度变化在 $\lambda/(8\cos\theta)$ 的尺度下时是平滑的（暗的）、在它之上时是粗糙的（亮的）——这就是同一个泥滩在 C 波段是黑的、在 L 波段是灰的，布拉格的共振的模型（1970 年代–2020 的雷达–海洋的文献：对着 $5.5$-cm 的 C 波长的共振的厘米的波）把海的状态链接到后向散射（海洋学的海–气的通量的课的散射计的风的检索），雷达的纹理是一个物理的统计（斑点——在一个分辨率的单元上充分发展的相干的干涉——它的负的指数的与 Gamma 的分布、多视的统计被图像的课作为噪声引入、实际上是测量的基本的量子）的理由。**体的与双重的弹跳**的散射携带着结构：森林的冠层从树冠，枝、地面返回（生物量的例子的 L 波段的全极化，1990 年代–2020 的 PolInSAR 的文献的随机体森林模型），淹没的植被双重地弹跳（在冠层之下制图着淹没的亮的 C 波段的特征，2016–2025 的 S1 与 NISAR 的湿地的产品），城市地区的墙–街的角落在 HH 上发光（建筑的取向的文献）。**合成的孔径**是仪器的戏法：当平台飞行时，每一个地面目标在一个真实的波束的宽度的弧上被照明着，回波的多普勒的历史（经典的 1950 年代–1960 的威尔莫–柯尔兰德与科兹马的谱系）被匹配的滤波聚焦到条带的真实的天线的长度的一半的方位的分辨率（传感器的一课的结果），聚光的数十米或更好，距离的维度来自脉冲的带宽（$\delta R = c/(2B\sin\theta_{\text{入射}})$，每一个现代的系统的线性的调频的脉冲的压缩：Sentinel-1 的 $56.5\ \mathrm{MHz}$ 的脉冲串给出约 $20$-m 的地面的像素，2020 年代的商用的雷达的 $900\ \mathrm{MHz}$ 与更宽的波形给出亚米）。**相干**是相位的记录的脆、价值：复的返回在系统的热噪声之内保留着相位，在两个次之间干涉的相关 $\gamma$ 随着时间的改变退化（$24$ 天的 Sentinel-1 的对在森林里失相干、在沙漠里保持着），随着垂直的基线（几何的失相干），随着大气（电离层的与对流层的相位屏，2010 年代–2020 的 GNSS 与电离层的约束的 InSAR 的文献）——随后的整个的干涉测量的定义是那退化的管理，因为一个雷达的图像的幅度告诉你表面像什么，只有它的相位告诉你表面在哪里。
:::

::: definition 干涉测量：相位到毫米 {#def-insar}
干涉的 SAR 形成着同一个场景的两个（更多的）共同配准的图像的复的乘积；结果的**干涉的相位**是视线的路径的长度的差异的 $4\pi/\lambda$ 倍，路径的差异是实践者必须分离的项的和：**平的地球**（平的参考的球的二次的相位，靠轨道的基线模型移走），**地形**（高度的依赖的项，靠外部 DEM 移走、从多基线的堆栈估计着），**变形**（目标的信号，地面的位移的视线的投影），**大气**（对流层的湿的延迟的屏，千米尺度空间相关的，L 波段与以下的电离层的色散的屏），**噪声**（热的与基线的失相干的项，靠加权着每一个下流的估计的相干 $\gamma$ 定量着）。**位移的测量的方程**跟着：一个干涉图给出每一个像素一个视线的位移（C 波长的 $5.5$-cm 的波长使一个完整的相位周期 = $2.75\ \mathrm{cm}$ 的距离的改变），相位的展开的问题（恢复着整的条纹的计数，1990 年代–2020 的 SNAPHU 与最小的费用的流的文献）加上多几何的分解（在几何允许时分辨着三维的矢量的升交与降交与方位的倾斜的对）决定着矢量场的多少分数实际可观测——多数的 Sentinel-1 的获取的垂直在升交下的统治是沉降的研究容易、走滑的研究难的理由。**持久的散射体与层析的 InSAR**（1999–2025 的永久的散射体与 SqueeSAR 与 InSAR-TOMO 的谱系）通过在数百次获取上追踪着单个的相干的目标（角的反射器，暴露的屋顶，桥的桥台）解决着城市的时间的失相干的问题，检索着每一个目标的每年几个毫米的位移的时间的序列，靠分布的散射体的扩展（2015–2025 的 DS-InSAR 与 COSEME 与 MAI 与偏移的追踪的大的梯度的补充）把技术推进进植被的与农村的地形；一个现代的城市沉降的图的错误的预算（2018–2025 的欧洲与亚洲与美国的都市区的研究）是每年的几个十分之一的毫米的相对的形变的精度、一个参考的点的选择的主张、一个大气校正的方案——一个在城市的街区上每年毫米的测量，一个水准的网络从未在它的整个的历史上做到的。
:::

::: definition 高度计与激光雷达：测距着垂直 {#def-altimetry-lidar}
高度计是最老的有源的技术、最简单的陈述：测量到表面的双向的光的时间（距离 = $ct/2$，从一个 $1000$-km 的轨道的 $6\ \mathrm{ms}$ 的往返是要感觉的数字），卫星自己的精密的轨道的确定（1990 年代–2020 的精密的轨道的文献的厘米规模的卫星的激光的测距，多普勒的轨道的确定与 GNSS 的接收机的遗产，轨道的径向的错误是高度计的错误的预算的第一项）把距离转换成表面的高度。**雷达的高度计**（1973–2025 的从 Skylab 与 GEOS-3 经过 Seasat，Geosat，ERS-1 与 2，Topex-Poseidon，Jason-1-2-3，Envisat，CryoSat-2，Sentinel-3 与 Sentinel-6，ICESat-2 的光学的表亲的序列）发射着返回的**波形**是表面与仪器的卷积的脉冲：在海洋上重新追踪的第一次的返回把海表面的高度给出到几个厘米（海洋学的海平面的课的 1993–2025 的卫星的高度计的海平面的记录，它的每年 $3.3\ \mathrm{mm}$ 的平均、每年每十年 $0.4\ \mathrm{mm}$ 的加速度是气候的变化的课程的中心的测量，2020 年代的 Jason-3 与 Sentinel-6 Michael Freilich 的相互校准在每年毫米的水平上保持着记录的连续性），波形的斜率给出显著的波的高度（1980 年代–2020 的 Ku 与 Ka 的双频率的波的检索），在冰盖上脉冲限制的足迹（数百米到公里）加上斜率与各向异性的校准（2010 年代–2020 的 CryoSat-2 与 ICESat-2 的重复的轨道与光子的对的率的方）把高程的改变给出到每年数十个吉吨的质量的收支（冰川的冰盖的课的对着 GRACE 的引力的独立的估计）。**激光雷达**是光学的波长带着光子的计数与波束的结构做着科学的同样的测距的物理学：**全波形**的机载的系统（1990 年代–2020 的 NASA 与 NCF 与北极的北界的谱系）记录着激光的回波作为返回的能量的一个垂直的剖面——冠层，林下，地面——从它高度统计（森林的清查的文献的洛里与平均的冠层的高度的统计）、在足够的足迹下，地上的生物量的密度跟着（2010 年代–2020 的 GEDI 与 NISAR 与全球的生物量的卫星的任务的设计的时代，对着森林的清查的样地的 2022–2025 的 GEDI L2B 的验证的运动）；**离散的返回**的扫描的系统（2000 年代以来的地形的制图的默认，使 GIS 的课的裸的地球的数字的地形的模型的四个的返回的最后的惯例，2010 年代–2020 的国家的激光雷达的计划——美国的 3DEP 与英国与新加坡与印度的时代的连续的覆盖的运动——在整个的国家交付着亚米的垂直的精度）；**太空的光子的计数**（ICESat/GLAS 2003–2009 的 $70$-m 的足迹，ATLAS/ICESat-2 2018– 的 $10\ \mathrm{kHz}$ 的 $17$-m 的斑，2020 年代的 ATLAS 的光子的对的率与表面的高度的差异的方，用空间的密度交换着单发的精度）关闭着当前的一代，它的 2022–2025 的应用跨越着海冰的自由板（冰川的海冰的课的厚度的链），河与湖的水文学（水文学的地下的流的课的表面水的章节的 SWOT 与 ATLAS 的湖的高度的谱系），冠层的结构（从轨道的光子的噪声制图着森林的高度的 2023–2025 的 ATLAS 与 GEDI 的共同站位的研究）。所有的高度计与激光雷达的共享的纪律：**测量是一个时间，科学是一个波形，错误的预算是轨道，潮汐，大气、仪器全部以厘米定价着。**
:::

::: example 一个地震的 InSAR：条纹画出的断层 {#ex-quake-insar}
1992 的兰德斯地震的 1993 的 ERS-1 的干涉图（迪迪埃·马斯内与库尔特·法伊格尔与霍华德·泽布克与汤姆·赖特的时代的演示，创立着领域）把表面的位移的场显示为同心的干涉的条纹——每一个条纹一个半的波长（C 波长的 $2.9\ \mathrm{cm}$）的距离的改变——随后的 1993–2025 的地震 InSAR 的文献（1997 的曼齐克特–伊兹米特，2010 的莫勒与玉树，2015 的廓尔喀，2023 的卡赫拉曼马拉什与土耳其–叙利亚的事件的研究，现在由 Copernicus 与 CEOS 的服务在几小时内交付的 2015 与 2023 的 Sentinel-1 时代的快速响应的产品）标准化着流程：展开着相位，在几何地可信的断层面上反演着滑动（地球物理的地震的源的课的弹性的半空间与成层的格林函数），与测地的、地震学的解结合着——干涉的结果的唯一的贡献是**表面未破裂的地下的滑动**（2007 与 2019 的希朗加与格雷罗的慢的滑动的文献的 $M_w 7+$ 的慢的与阵发的滑动的事件，2015–2025 的 Sentinel-1 时代的全球的慢的滑动的普查）、震后的与震间的速度场（现在直接喂养着自然灾害的地震的危险的课的概率的预报的 2016–2025 的 Sentinel-1 与 GNSS 耦合的耦合的图）。错误的预算是定义的：近场的受损的植被里的相干的损失（偏移的追踪接管的地方），贯穿的山脉的对流层的屏（部分可移走的，2015–2025 的 ERA5 与 GNSS 校准的再分析），最陡的梯度上的展开的不连续（2020 年代的深度学习的展开的尝试，有用的，未解决的）——解释的纪律是投影的：一个条纹的图是视线的，垂直在升交下的统治意味着一个单一的几何对垂直的断层上的倾向的滑动几乎看不见，2010 年代与 2020 年代的多几何与 ALOS-3 与 ISBA 时代的星座的设计存在恰恰关闭着那个零空间。
:::

::: example 城市的沉降：每年毫米，按城市的街区 {#ex-subsidence}
持久的散射体的 InSAR 把土地的沉降从一个水准的网络的轶事变成一个全球的、密的覆盖的测量：2004–2025 的永久的散射体的谱系（2001–2004 的永久的散射体的干涉的方法的论文，2008–2025 的 SqueeSAR 与 DS-InSAR 的分布的散射体的扩展在城市地区把可用的目标的密度加倍、更多）现在以每一个 $10^4$–$10^6$ 个相干的目标制图着世界的主要城市的大部分，结果重写着三个文献。**地下水与压实：** 2010–2025 的墨西哥城（对着含水层的位的周期分辨着每年厘米的微分的压实的 2019 与 2023 的 Sentinel-1 与 Envisat 的时间序列的研究），雅加达（2010–2024 的数十年的 Envisat 与 Sentinel-1 的记录，驱动着迁移的论证的接近一个十年的北部地区的率），曼谷，华北平原的巨型城市的带，加利福尼亚的中央谷（2015–2025 的 InSAR 与 GRACE 耦合的农业的沉降的研究）以没有一个井的网络接近着的空间的分辨率把沉降绑到抽水，喂养着地球的资源的水资源的课的水的章节。**工程的测地学：** 2010–2025 的掘进、采矿、坝、压裂的文献（格罗宁根与荷兰的气田的沉降与倾斜的监测，2016–2024 的二叠纪与马塞勒斯的处置的注入的地震的与表面的上升的研究，现在在阿尔卑斯与挪威的岩崩的预警系统里操作的坝与采石场的稳定的监视）使用着每一个目标的时间的序列作为结构的与危险模型的形变的输入的十分之一的毫米的精度。**参考框架的诚实：** 2018–2025 的互相比对与参考的研究（GNSS 绑着的、IERS 框架的 InSAR 的对齐，参考点选择的敏感分析）记录着技术的软的下腹——相对的测量意味着基准被选择着，一个坏的参考的像素把它自己的率移动着一个整个的城市的图，地图与 GIS 的课在米里做着的同一个基准的纪律的论证，现在在决定"机场是稳定的"是否真实的毫米的规模。

::: example 从轨道的森林的结构：GEDI，NISAR，生物量的图 {#ex-biomass}
碳的会计的问题——世界的森林里有多少碳、它改变得多快——在 2010 年代–2020 成为一个激光雷达与雷达的问题，因为只有微波与激光看着结构：GEDI（2019–2023，ISS 安装的全波形的激光雷达，它的 $25$-m 的足迹在任务结束之前探测着 $110$ 亿次，2021–2025 的 L4A 的地上生物量的密度的产品、它的报告着 15–25 个百分点的区域的不确定度的森林的样地的验证的运动），ICESat-2/ATLAS（光子的计数的冠层的高度与地面的高程的层，2020 年代的 ATLAS 与 GEDI 的共同站位的研究把高度的统计延伸到 GEDI 的轨迹之外）提供着光学的图像不能的垂直的结构，L 波段的雷达（1994–2009 的 JERS 与 ALOS/PALSAR 的遗产，它的长的波长穿透到地面–树干的相互作用，2014–2025 的 ALOS-2 与 NISAR 时代的全极化与干涉的生物量的反演，把饱和限制的、相干反演成碳的密度的随机体与 RVoG 的散射的模型）在空间延伸着它——饱和的问题（C 波段在约 $100$–$150\ \mathrm{Mg/ha}$ 饱和，L 波段在约 $200$–$400$，P 波段几乎不饱和，使 2025 与以后的 NISAR 的 L 波段与生物量的 P 波段的任务设计的 2010 年代与 2020 年代的频率的选择的文献）是任务围绕建造着的物理学。2020–2025 的融合的产品（GEDI-Landsat-Sentinel-2 与 NISAR 的 SENAI 与 ABI 的谱系的 $10$–$30$-m 的全球的冠层的高度与生物量的图，2022–2025 的加蓬与刚果与加利福尼亚与缅因的运动的国家清查的调和）显示着模式的真正的价值、真正的限制：在大陆的规模上 $15$–$25$ 个百分点以内的系统的图对图的同意（足够好为气候的变化的排放的预算的课的土地使用的章节消费着的 REDD-plus 与国家的清查的会计），仍要求着野外的样地作为校准的基础的样地的不确定度——激光雷达与雷达把样地的算术延伸过着图，它们不替换着森林的生态学家的卷尺，分类的课的同样的参考的数据的来源的纪律，现在带着附着在误差条上的碳的信用。
:::

::: example 高度计的两种视图：上升的厘米，下降的公里 {#ex-altimetry}
同样的测距的物理学，对着海洋与冰，产生着世纪的两个最干净的行星的数字。**海表面的高度：** 1993–2025 的卫星的高度计的海平面的记录（Topex-Poseidon 与 Jason 与 Sentinel-3 与 Sentinel-6 的交叉的与参考的任务的合并的分析）以 3.4 mm/yr 测量着全球的平均的上升、一个测量的加速度、2020 年代的记录的年的异常在 $4.5\ \mathrm{mm}$ 之上——海洋学的海平面的课的观测的骨干——它的错误的预算是高度计的定义的逐项定价的项：轨道的径向的确定（卫星的激光的测距与 DORIS 与 GNSS 的精密的轨道的制度，厘米规模的），海的状态的偏向与湿的对流层的校准（2010 年代–2020 的 GNSS 的层析与辐射计校准的再分析），极地的轨道到极地的轨道的相互校准（把记录的阶梯保持在一毫米之下的 Jason-3 到 Sentinel-6 的参考的轨道的运动），海洋学的波与潮汐的课的潮汐与交叉的混叠的算术。**冰盖的高程：** 雷达与激光的高度计的质量的收支的谱系（1998–2009 的 ERS-2 与 ICESat 与 2010 的 CryoSat-2 的极地的重复的轨迹的时代，2018–2025 的 ICESat-2 的光子的对的率的时代）产生着格陵兰与南极的高程的改变的图，它与粒雪密度模型的积分（冰川的冰盖的课的 2019–2024 的 IMBIE 与 GRACE 与 GFC 的调和的评估）给出着统治着海平面的预算的冰的项的质量的损失——粒雪的固结的校准是例子的警示的一半：高程的改变不是质量的改变，直到你刚刚称着的东西的密度被模型化，热的一课的亮度对着温度的区分的高度计的版本，质量收支的社区发表着三个方（高度计，重力计，输入–输出），它们的同意、不是任何一个的精度，是实际的确定度的陈述的理由。
:::

::: history 相干，线性调频，光子 {#hist-radar}
**1904–1957。** 克里斯蒂安·许尔斯迈尔的 1904 的无线电的回波的碰撞的警告的专利、1930 年代–1940 的战时的雷达的计划（罗伯特·沃森–瓦特的链，MIT 的辐射的实验室的系列）供应着硬件；合成的孔径的思想被卡尔·怀利（1951）专利着、在 1950 年代的侧视与多普勒的处理的工作中形式化着（1957 的威尔莫–柯尔兰德与科兹马与施托伊贝尔的聚焦的成像的演示）；线性的调频的脉冲的压缩与匹配的滤波的理论（1950 年代–1960 的通信与雷达的文献）使距离的分辨率成为一个波形的设计的问题。**1957–1992。** 太空开始着记录：1957–1960 的 SCORE 计划 与 MIDAS 与 Transit 的测距的试验找到着轨道的确定的纪律，1969–1975 的阿波罗与 Skylab 的激光的测距、1973–1975 的 Skylab S-190 的雷达与散射计的运动演示着对地球的有用，1975–1992 的 Seasat 与 GEOS-3 与 ERS 的谱系（1978 的 Seasat 的雷达的高度计与 SAR 与散射计的十个月，1985–1992 的 ERS-1 的设计的时代）确立着海洋的雷达与雷达的成像的制度，1971–1986 的激光雷达的谱系（1960 年代–1970 的激光的测距、1980 的机载的扫描的系统）准备着光子的计数的未来。**1991–2025。** 精度的时代：ERS-1（1991）与 JERS-1 与 RadarSat（1991–1994）给出着重复的次的相干，1993 的兰德斯、1994 的北岭的干涉测量的论文证明着相位是一个地球物理的仪器，1995–2004 的永久的散射体与 TomoSAR 的方法的论文、2002 与 2006 的 Sentinel-1 与 NISAR 的计划使着它工业化；1992–2020 的高度计的继承（Topex-Poseidon 经过 Jason-3 与 Sentinel-6）、2003–2018 的 ICESat 到 ICESat-2 的激光的高度计的一代把测距变成气候的记录；2019–2025 的 GEDI 与 NISAR 与 ROCMAP 与 Comet 与 PLANETICA 时代的系统的与商业的有源的感测的舰队完成着毫米与厘米的有源的感测变得，像它之前的光学的存档，为整个的地球系统的开放的基础设施的过渡。
:::

::: quiz {#quiz-coherence}
一个在热带的雨林之上的干涉的对显示着近 0.2 的相干、一个沙漠的对显示着 0.9。对形变的测量的结果是：

- [x] 森林的对的相位主要是噪声——那里的形变需要 L 波段、更短的时间的基线、偏移的追踪
- [ ] 森林的形变比沙漠的小
- [ ] 沙漠的对必须有一个更长的时间基线
- [ ] 相干测量着形变的信号的强度

::: solution :::
相干加权着相位：在 $\gamma \approx 0.2$，相位的标准差是数十度、位移的估计是无意义的，恰恰是定义分配给 L 波段（穿透着冠层，改变得更慢）、6 或 12 天的对、基于幅度的偏移的追踪的时间的失相干的制度。其余的选项把失相干与地球物理（B），与获取的设计（C）、与信号的幅度（D）混淆着——相干是相关，不是信号。
:::
:::

::: quiz {#quiz-lidar}
机载的激光雷达在密的森林的冠层之下产生着裸地球的地的形模型，因为：

- [x] 每一个脉冲的多个的返回包含着通过着冠层的间隙到达着地面的光子，最低的干净的返回（分类之后）是地形
- [ ] 地面的返回比冠层的返回更强、不需要着处理
- [ ] 激光的波长穿透着叶子
- [ ] 冠层的返回被一个高的通过的滤波器移走

::: solution :::
它是一个数字与几何的游戏：足够的足迹（2010 年代–2020 的国家计划的每平方米的数个脉冲的密度）保证着一些光子找到着间隙，分类（地面返回的探测的文献的斜率与高程的一致性的规则，四个的返回的最后的惯例）挑选着它们——全波形的定义的垂直的剖面变成一个数字的高的模型。叶子在光学的波长上是不透明的（C 恰恰错）；地面的返回通常更弱、不是更强（B）；频率的意义的滤波（D）不是机械。
:::

## 练习

::: exercise {level=1 check="360"}
一个雷达的高度计测量着一个 $2.4$ 毫秒的双向的脉冲的传播的时间。斜的距离（km）是多少（$c = 3\times10^8\ \mathrm{m/s}$）？
::: solution :::
距离 $= ct/2 = 3\times10^8 \times 2.4\times10^{-3}/2 = 3.6\times10^5\ \mathrm{m} = $ **$360\ \mathrm{km}$**——二的因子（往返）是高度计的定义的第一的习惯，从一个 $1000$-km 的轨道的 $6$-ms 的往返是同样的算术；一个 $1$ 纳秒的定时的错误是 $15\ \mathrm{cm}$ 的距离，这就是厘米的错误预算的每一项是一个定时的路径的校准的理由。
:::
:::

::: exercise {level=1 check="2.7"}
Sentinel-1 的干涉的宽的条带的脉冲串使用着一个 $56.5\ \mathrm{MHz}$ 的线性调频的带宽。距离的分辨率是 $c/(2B)$。给出斜的距离的分辨率（米）一个位的小数。
::: solution :::
$3\times10^8/(2\times56.5\times10^6) = 2.65$，约 **$2.7\ \mathrm{m}$** 斜的（在约 $37^\circ$ 的入射上地上的约 $5.8\ \mathrm{m}$，传感器的课的 $5$ 乘 $20$-m 的 IW 的像素）——线性的调频的脉冲的压缩把一个 $10$-m 的物理的脉冲变成一个 $3$-m 的测量，"带宽是分辨率"是雷达的无源的微波的课的"孔径是足迹"的版本的理由：每一个有源的系统是一个关于一个控制的量的论证。
:::
:::

::: exercise {level=1 check="0.7"}
ICESat-2 的 ATLAS 以一个 $7\ \mathrm{km/s}$ 移动的地的轨迹上每秒发射着 $10000$ 个激光的脉冲。沿地的斑的间隔（米）是多少？
::: solution :::
$7000/10000 = $ **$0.7\ \mathrm{m}$**——高度计的定义的光子的计数的预算：$17$-m 的斑之间的 70 厘米 意味着任务用单发的精度（几个厘米，数十个光子）交换着空间的密度（光子的对的率的方的统计的高度差异），同样的分辨率对着精度的交换作为多视，现在以每平方米的支付着光子数。
:::
:::

::: exercise {level=2 check="11"}
一个 Sentinel-1 的干涉图（波长 $5.5\ \mathrm{cm}$）在一个给定的像素上显示着两个的日期之间的两个的完整的周期的（$4\pi$）的相位的改变。视线的位移（cm）是多少？
::: solution :::
一个周期 = $\lambda/2 = 2.75\ \mathrm{cm}$；两个周期 = **$11\ \mathrm{cm}$**——图表的尺子直接读着，使地震的例子条纹的图物理的规模感的练习：$12$ 天的 $11\ \mathrm{cm}$ 的距离的改变是一个滑坡，一个火山的膨胀、一个油田的注入，绝不是一个对流层的伪影（对流层的路径的延迟是厘米的规模，主要在一个条纹之下）。
:::
:::

::: exercise {level=2 check="117"}
一个干涉图的地形的相位为一个高度 $h = \lambda R/(2B_\perp)$ 完成一个完整的周期。对 $\lambda = 5.5\ \mathrm{cm}$、距离 $R = 850\ \mathrm{km}$、垂直的基线 $B_\perp = 200\ \mathrm{m}$，计算最近的米 $h$。
::: solution :::
$h = 0.055\times850000/(2\times200) = 46750/400 = 116.9$，约每一个条纹 **$117\ \mathrm{m}$**——定义的地形的项的移走变成一个设计的选择的敏感的高度数字：大的基线（小的 $h$）使陡的地形可展开着、几何地失相干着，小的基线（大的 $h$）把相位压平着、失去着地形信号，2010 年代与 2020 年代的 DEM 与合成孔径的高度系统（TanDEM-X 与 Comet 的 DEM 与波罗的项目）存在使地形的相位根本可移走着。
:::
:::

::: exercise {level=2 check="0.45"}
一个雷达的高度计发射着一个 $3$ 纳秒的脉冲。它的距离的分辨率（$ct/2$）（米）是多少？
::: solution :::
$3\times10^8\times3\times10^{-9}/2 = 0.45$，**$0.45\ \mathrm{m}$**——脉冲限制的足迹的垂直的对应（CryoSat-2 的 2010 年代的 SIRAL 与 LFM 时代的 $1.2$-m 分辨率是极地的冰的优化的带宽对着峰值的功率的权衡），冰盖的高程的改变的错误预算（高度的定义）不由距离的分辨率统治、由足迹与斜率与各向异性的相互作用统治的理由：在一个 1 个百分点的坡上的一个 $300$-m 的足迹在任何波形处理开始之前是一个 $3$-m 的高程的歧义。
:::
:::

::: exercise {level=3 check="7.9"}
一个雷达以离垂直 $38^\circ$ 的入射的角向下看着。$10\ \mathrm{cm}$ 的纯的垂直的地面的运动产生着 $d\cdot\cos(\theta)$ 的视线的距离的改变。计算 InSAR 可测量的位移（cm）一个位的小数。
::: solution :::
$10\times\cos 38^\circ = 10\times0.788 = 7.88$，约 **$7.9\ \mathrm{cm}$**——定义的位移的方程的投影的算术，它对危险的解释的推论：对着卫星的同一个 $10\ \mathrm{cm}$ 的水平运动读为 $10\times\sin 38^\circ = 6.2\ \mathrm{cm}$，一个 $40^\circ$ 的倾向的断层的滑动不同地投影着，地震的例子的"不可见的几何"（在升交的近乎的垂直的看下垂直的断层上的走滑）是这个余弦–正弦的结构、坏的数据——这就是 2020 年代的星座的设计（NISAR 的两个几何，ROCMAP 与 Comet 的升交–降交的对）作为零空间关闭的仪器出售的理由。
:::
:::

::: exercise {level=3 check="9"}
一个全波形的激光雷达的脉冲在冠层的顶的返回之后 $60$ 纳秒记录着地面的返回。冠层的高度（米）（$ct/2$）是多少？
::: solution :::
$3\times10^8\times60\times10^{-9}/2 = 9$，即 **$9\ \mathrm{m}$**——GEDI 的例子的高度统计从它建造着的读着波形的测量（洛里的高度分布恰恰是这些传播的时间的幅度加权的均值），激光雷达的生物量的检索在光学的生物的量的代理不诚实的一个方面结构地诚实的理由：仪器直接地测量着高度、只通过着一个它的错误单独说明着的异速生长的模型转换成碳。
:::
:::

::: exercise {level=3 check="3.1"}
一个 SAR 的卫星以 $7500\ \mathrm{m/s}$ 飞行、带着 $2400\ \mathrm{Hz}$ 的脉冲的重复的频率。沿的地面的采样的间隔（米）是一个位的小数是多少？
::: solution :::
$7500/2400 = 3.125$，约 **$3.1\ \mathrm{m}$**——从聚焦形成着最后的像素的原始的沿的采样（方位的平均、天线限制的把 $3.1$-m 的样本减少到 $5.4$-m 或 $20$-m 的产品的像素的处理，每一个辐射计对着成像的设计的审查的歧义与处理的历史的论证），使 2010 年代–2020 的宽的条带的 TOPS 与 ScanSAR 的模式（Sentinel-1 的旋转的天线的脉冲串的缝合，2012 与 2018 的 TOPS-InSAR 的方位的偏移的文献）的多普勒的质心与天线的操舵的校准必要的数字：精细地采样着多普勒的历史、聚焦的图像涂抹着，涂抹自己成为一个干涉测量的定义必须定价的相位错误。
:::

::: warning 四个有源的感测的谬误
1. **"暗的雷达意味着水。"** 幅度的谬误，洪水的制图的社区最艰苦学到的教训：开阔的水在中等入射上是暗的（镜子的），是的——在一定的几何下平滑的沥青与屋顶也是，风粗糙度抑制的城市的峡谷，平滑的冰川的冰，（2016–2024 的洪水的验证的文献的统治的委托的错误来源）在任何洪水之外的平静的库与避风的湾；对着高入射的风粗糙的水完全从暗的类别变亮（2018–2025 的风暴洪水的研究的遗漏的错误）。操作的制图（Copernicus EMS 与 JRC 全球的洪水的水的动力的协议）因此靠对着一个基线的水的状态的改变、介电的与几何的推理、越来越新的任务提供着的全极化与多入射的信息制图着——诚实的洪水的产品在它的说明里报告着它的风与植被的警告，因为暗的像素是一个关于散射的几何的论证、绝不是自然的一个类别。
2. **"干涉图显示着形变。"** 它显示着相位，形变加平的地球加地形加大气加电离层加噪声，2010 年代–2020 的校准的文献在厘米上记录着每一个冒充者：模仿着岩浆的膨胀的空间的平滑的对流层的屏（在千米的波长上发现着每年数厘米的未校准的大气的信号的 2013–2024 的 ERA5 与 GNSS 校准的火山的研究——寻找着的形变的确切的规模），模仿着倾向的滑动的斜坡的 L 波段的电离层的斜坡（2017–2025 的 NISAR 的设计时代的 TEC 约束的研究），在最重要的梯度上跳跃着整个的条纹的展开的错误（2020 年代的深度学习的展开的论文的诚实的失败的模式）。纪律是定义的错误的预算，发表的：相干的图，命名的校准的大气的，辩护的参考的点，——2020 年代的系统的产品（Sentinel-1 与 NISAR 时代的 InSAR 的层）逐地区引用着的对着 GNSS 与运动的验证，因为一个不带它的错误的预算的 InSAR 的图是一个多彩的暗示。
3. **"激光雷达测量着生物量。"** 它测量着高度与强度；生物量通过着异速生长进入（森林的清查的文献的高度–直径的异速生长与木的密度的方程，它的物种与林分的变异按 2021–2025 的 GEDI 的验证的研究与传感器的错误一样大），通过着把波形转换成结构的模型（2010 年代–2020 的全波形的度量对着洛里的高度的回归），通过着生物量的例子定价着的雷达的饱和的问题（$200$–$400$-Mg/ha 的 L 波长的天花板，仍在轨道的设计的 P 波长的承诺）。2022–2025 的碳的信用与国家清查的争论（遥感的生物量对着野外的清查的调和的论证，管辖区的 REDD 的支付的争议）是一个高度的测量作为一个碳的吨花费时发生的：图的 15 个百分点的大陆的不确定度只在异速生长与样地的链被传播时成为一个支付的错误的条，跳过着它的研究在会计的术语里发明着碳。
4. **"有源的意味着全天候、精确的。"** 雷达确实穿过着云看，激光雷达不穿过着云、雨、冠层看——谬误在"精确的"：高度计的错误预算（轨道，潮汐，海的状态的偏向，湿的对流层，仪器的漂移）是一个必须在海洋的厘米意味着任何东西之前减去的厘米的发表的列表（2020 年代的海平面的记录的连续性的文献本质上是这个减法的剩余的），InSAR 的毫米是相对的（沉降的例子的参考的点与参考的框架的论证），激光雷达的厘米是它单发的错误是分米的光子的一个统计的平均（ATLAS 的光子的计数的制度的整个的方法的文献）。精度是真实的——它是课程的精度的前沿——它是**微分的、模型化的、参考着的**，绝不绝对的：有源的系统漂亮地测量着改变、谨慎地测量着水平，从"火山膨胀了 $8\ \mathrm{cm}$"到"冰盖失去了 $200\ \mathrm{Gt}$"的每一个标题的数字是两个模型化的量的一个差异，它的误差条是论文的真正的主题。

有源的感测是课程的精度的前沿，建造在三个控制的照明上：**雷达的幅度**（作为介电的、粗糙度、结构的测量的后向散射——水暗，湿的土壤暗，双重的弹跳亮，风的场、洪水的水平两者从同一个菲涅尔的对比读着的布拉格的物理学），**雷达的相位**（合成孔径的相干的记录，干涉测量的半的波长的尺子，它的管理把地震的源的反演与每年毫米的沉降图从漂亮的图分离开的错误的预算——平的地球，地形，大气，电离层，失相干，展开），**测距**（高度计与激光雷达的飞行时间，读着波形的物理学，它的错误的预算以轨道，潮汐，对流层、足迹的几何的厘米定价着，然后交付着海平面的记录的 $3.4$ mm/yr、冰盖的质量的收支）。例子是它们的应用的边缘的技术：地震的条纹与慢的滑动的普查，绑到含水层的城市的街区的沉降，GEDI 与 NISAR 的森林的结构（谨慎地、异速生长地）花费为碳，两个高度计的视图——上升的厘米，下降的公里——它的不确定度作为科学发表着、不是作为营销隐藏着。谬误（暗作为水，干涉图作为形变，激光雷达作为生物量，有源的作为精确的）全是同一个用测量替换着量，课程的最精确的方言的一个经常的罪：雷达测量着相位，激光雷达测量着时间，只有错误的预算——相干的图，校准的运动，参考的框架，样地的网络，跨任务的调和——决定着你发表的是地球物理、仪器学。下面的三个课完全离开辐射、拿起最老的有源的仪器：地图。
