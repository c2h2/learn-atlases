前面的一切生产着曲面：分类，指数，高程，温度。本章关于从它们提取着意义——结合着层，摘要着区域，在什么都没测量的地方估计着值，检验着出现的模式是否真实。空间的分析有一条定律、几个诅咒。定律，1970 的托伯勒的，是一切与其他一切相关、但近的事物比远的事物更相关；诅咒跟着它——膨胀着显著性的自相关，制造着相关的聚合的选择，把猜测洗成地图的插值。学会看穿着诅咒是空间的分析者、一个运行着工具的人之间的区别。

::: definition 图的代数，叠加，邻域 {#def-map-algebra}
**图的代数**在 1960 年代在哈佛的计算机的图形与空间的分析的实验室在奥德赛的系统的谱系里形式化着、1990 年由达纳·汤姆林给出它现代的教科书的形式，把栅格当作矩阵、地图当作函数：逐像元的算术与逻辑（两个日期的 NDVI 的差），结合着几个层的同位的像元的**局部**的算子（适宜性的评分），在一个曲面上滑过一个窗口的**焦点**的算子（$3$ 乘 $3$ 的均值的滤波，从一个 $3$ 乘 $3$ 的邻域的坡度，距离的变换），在另一个定义的区之上摘要着一个栅格的**分区**的算子（每一个流域的平均的降雨，每一个土地覆盖的类的像元的计数），把整张地图当作一个区的**区域**的算子。**D8 的水流的方向**的级联——累积着排水，提取着河道，划着流域——是一个焦点的网络的算子，如此的基本，以至于它支撑着高程的多数的水文学的使用，它的变体（D-无穷，多的水流）存在，因为一个单一下坡的方向是一个弯曲的曲面的粗糙的模型。叠加，专题的层的并与交，是矢量的同样的机械，前一章的决定着结果是干净的、满是碎片的片的拓扑的课。工程的规则：每一个算子传播着它的输入的错误，五个粗心的操作的链制造着一张没有人能说明着它的不确定度的地图——保持着代数浅着、错误的项可见着。 {#def-map-algebra}

:::
::: definition 插值：估计着未采样的地方 {#def-interpolation}
插值从一个散布的样本填充着一个曲面——从站点的温度，从井的浓度，从测深的高程。**确定性的**方法强加着几何：最近邻，正则的网格的双线性与双立方的重采样，**反的距离的加权**（唐纳德·谢泼德的 1968 的公式，哈佛的实验室的系统的标准），估计是一个距离的加权的均值带着与距离的负 $p$ 次方成正比的权重——在样本附近锐的，在它们之间平的，保证着穿过每一个样本。**地统计的**方法从一个空间的协方差的模型开始：**变异函数**绘制着样本的对的平方的差的之半对着它们的分离，揭示着一个**块金**（测量的噪声加上子样本的变化），一个**基台**（总的方差），一个**变程**（样本不相关之外的距离）。**克里金**，1950 年代达尼·克里格为德兰士瓦的金矿的品位开发的、1960 年代乔治·马泰隆形式化着的，然后解着在那个变异函数下给出最好的线性无偏的估计的权重——唯一地，在每一个预测的位置返回着一个**估计的方差**，地图携带着它自己的不确定度的表。普通的克里金假设着一个未知的常数的均值；带外部漂移的克里金、普遍的克里金让着协变量（高程，到海岸的距离）承载着趋势，降雨的图集实际制作着的方式（见水文学的降水与蒸发的课）。诅咒：样本之间的插值只和采样设计的那么好；在样本的凸包之外的外推是一个带着颜色的坡道的虚构；估计的曲面的平滑系统地低估着极值的方差——一个克里金的降雨的图永不显示着网络错过的风暴的单元。 {#def-interpolation}

:::
::: definition 空间的自相关，模式的统计 {#def-autocorrelation}
制图的ing 的模式真实吗？**空间自相关**——邻域的值彼此相似的度——被**莫兰的 I** 摘要着，1950 的帕特里克·莫兰从威沙特晶格的统计与农业的田间试验的分析引入的，被彼得·哈格特的一代带到地理学、被阿瑟·盖蒂斯与 J·K·奥德带到空间的统计学：接近 $+1$ 的 $I$ 意味着相似的值的聚集，接近 $n$ 减一的负一的分之一的期望意味着随机，负的值意味着棋盘格的规则。**盖蒂斯–奥德**的统计回答着补充的问题，定位着热点、不测量着全局的倾向，**LISA**（安瑟林 1995 的局部的指标）把全局的指数分解为逐位置的贡献，地图能显示着聚集居住在哪里。**里普利的 K** 与对的相关的函数对点的模式做同样的事——地震的震中，树的茎，陨石坑的清单——跨着尺度对着完全的空间的随机检验着聚集。**地理的加权的回归**拟合着系数跨着地图变化的局部的回归，专题的图的统计的同胞。诅咒带着工具来：**伪的重复**——把自相关的样本当作独立的处理着膨胀着显著性，有效的样本的大小能是计数的一个分数；**生态的谬误**——聚合的区域的数据的相关不必对个体成立；**可修改的区域的单元问题**（斯坦利·奥彭肖 1984 命名的）——结果随着分区改变，一个只在区的规模出现的相关是一个世界的、区的属性的一个属性。纪律：报告着有效的样本的大小，检验着对聚合的敏感性，不在一个附录的变异函数、空间的回归的检验之下从空间的数据读着一个 p 值（统计在气候系统的气候统计的课里进一步发展着）。 {#def-autocorrelation}

:::
::: example NDVI 的差：最简单的改变的图 {#ex-ndvi-diff}
两个旱季的 NDVI 的场景，五年之间，逐像元地相减：地图在负的值里显示着一个湖的收缩的灌溉的周界、在新的运河的指挥的面积在正的值里。它花费着一行的代码、在四个知道的方面是错的。日期在物候上不同——"改变"包括着一个晚的季风，不是一个土地使用的决定——改变应该在同样的季节的组合上测量着、不是单个的场景（见图像的处理的课）。大气不同——一个薄的霾压低着红的波段的反射率、铸造着假的褐变，这就是地表的反射率、不是辐射的亮度是差的输入的理由。像元错配着半个像元——田地的边缘的像元在差里发光着，不管在田地里发生了什么——亚像元的共同配准在相减之前。差的噪声作为两个场景的噪声的和增长着：沿着田地的边界的类似斑点的纹理是操作的错误的预算，差的阈值必须超过着它，恰恰是分类的章的最小可检测的改变的逻辑。例子一般化着：每一个图的代数的表达式是一个错误的传播的陈述，作者写着一个、不写着。 {#ex-ndvi-diff}

:::
::: example 分区的统计：三个方式说谎的均值 {#ex-zonal}
"每一个区的平均的人口的加权的夜间的亮度的强度"看来像一个工具的调用。第一个陷阱是**区域的加权的问题**：区的边界切过像元，一个在像元的中心天真的均值把一个区的几个完全的像元与一个边界的像元的一个城市的一片 加权相同——修复是区域的加权的分区的统计、更好的、在任何一个区触碰着它之前把粗的数据重采样到一个共同的细的网格。第二个陷阱是**无数据**：一个山地的流域里的掩膜的云的像元沉默地从多数的工具的均值里掉出去，"流域的平均的高程"成为无云的部分的均值——总是数着有效的像元、在每一个分区的数字旁边报告着覆盖的分数。第三个陷阱是**区的改变**：2014 的区的边界不摘要着 2009 的普查，十年的区的分裂把一个时间序列变成不同的地理的比较——气候的趋势的分析的站点的选址的伪影的区域的表亲。专业的模式：在计算之前把一切标准化到一个网格、一个区的年份、一个掩膜的政策的，让摘要的表携带着限定着它的覆盖的统计。 {#ex-zonal}

:::
::: example 一个降雨的图集：IDW 对着地形 {#ex-rainfall-atlas}
一个气象的服务从一个有一个 $2000$ 米的沿海的山地的国家的一百二十个站点起草着它的正常的时期的降雨的图集。反的距离的加权在山顶的站点周围产生着同心圆的靶心、其余的平的平原——几何正确的，物理荒谬的，因为雨跟着着地形、地形不在距离的权重里。普通的克里金做更好，尊守着变异函数的变程，影响在 $40$ 公里消退着，它仍然看不见山：它的趋势的假设是一个平的未知的均值。带外部漂移的克里金，使用着一个数字的高的模型作为一个协变量带着一个从站点自己拟合的带符号的高度的系数，把高的降雨的等值线移到云实际破碎着的迎风的山坡——它的估计的方差的曲面诚实地显示着下风的内部作为仪器化的海岸的三倍的不确定。这是山地的降雨的气候学的标准的食谱，它的失败的模式是启发性的：当一个服务只发表着估计的层、不发表着方差的层，下游的水文学的模型把外推的沙漠当作测量的事实，在它之上建造的水的资源的分配继承着虚构。 {#ex-rainfall-atlas}

:::
::: example 在处处找到显著性的回归 {#ex-spatial-regression}
一个研究在 $300$ 个普查的街区跨着交通的密度回归着儿童的哮喘的比率、报告着 $R^2$ 的 $0.6$、每一个系数在第一个百分点显著的。一个生态的谬误在一个自相关的谬误之上在一个分区的谬误之上，全在讨论的部分之前。哮喘在个体里诊断着；街区平均着家庭，街区的斜率不必等于——这里明白地不等于——个体的。交通的密度与哮喘都空间地聚集着，残差是自相关的：残差的变异函数显示着到 $2$ 公里的结构，有效的样本的大小是 $300$ 的一个分数，真正的标准误是报告的两倍。街区的边界是行政的：把同样的数据聚合到市，系数移动了三分之一——纯的可变的区域的单元的效果。研究的可防御的版本存在、无聊：可能的个体的等级的数据，一个对着残差的变异函数拟合的空间的错误、空间的滞后的模型，两三个分区的敏感的分析，数据能承载着的等级的措辞的结论。发表的版本是在新闻里引用的；可防御的版本是不误导着下一个健康的调查的，重要的观众。 {#ex-spatial-regression}

::: history 从叠加到空间的统计 {#history-spatial-analysis}
谱系从手工的叠加到分析的立方体运行着。伊恩·麦克哈格 1960 年代的规划的生态学——透明的专题的叠加的《与自然设计》的方法——哈佛的计算机的图形与空间的分析的实验室，它的 SYMAP 的制图程序在 1960 前后、1960 年代晚期的奥德赛的 GIS 自动化着叠加、教着一代人地图是数据，创始的故事。1970 年代把定量的革命的统计的装置带进地理学——克利夫与奥德的空间自相关的理论，托伯勒的第一的定律、它的扩散的模型，1950 与 1960 年代的克里格与马泰隆的矿山的统计的综合之后的南非的第一的国家降雨的克里金的实验——遥感的社区在普渡、密歇根、戈达德建造着本书的前面的章追溯着的数字的分类与图像的增强的机械。1980 年代标准化着工具包：汤姆林的图的代数，安瑟林的空间的计量经济学的软件，在圣巴巴拉地理的信息的系统科学的爆发，使统计的小心成熟的可变的区域的单元与生态的谬误的批评。1990 与 2000 年代是栅格的时代：ArcInfo 然后 ArcGIS 使焦点的与分区的算子成为一个菜单的项目，栅格的计算器民主化着图的代数，激光雷达与干涉的合成孔径的雷达的高程把地貌的计量学的分析——水流的累积，曲率，湿度的指数——放进着地球科学的日常的使用（见地貌学的流域的课）。2010 与 2020 年代把分析带回着统计：带着明确的错误的结构的空间与时空的模型，从 GeoPandas 到谷歌地球引擎的开源的堆栈使行星规模的焦点的与分区的工作平常，重复的运动坚持着分析脚本、不是彩色的输出是发表。 {#history-spatial-analysis}

::: exercise {level=3 check="20"}
一个 $30$ m 的数字的高的模型在两个的列分开的单元的中心之间落下 $12\ \mathrm{m}$。它们之间的百分比的坡度是什么？ {#ex-slope-pct}

::: solution
水平的运行是 $2 \times 30 = 60\ \mathrm{m}$；坡度的百分比 $= 100 \times 12/60 = 20$ 个百分点，约 $11$ 度。同样的两个单元的逻辑，在完整的 $3$ 乘 $3$ 的邻域带着洪恩的核应用着，坡度与坡向的工具实际计算着的——它对高程的噪声的敏感是激光雷达派生的坡度的图在同一个网格的间隔看来比立体的派生的更平滑的理由。 {#ex-slope-pct}
:::

::: warning 四个分析的谬误 {#warning-spatial-analysis}
**"地图显示着……"——它显示着工作流。** 每一个曲面是校正、重采样、组合、插值的选择的残渣；降雨的图的平滑的梯度是变异函数的、不是大气的，锐的灌溉的边界是共同配准的。说明着链、地图什么都不说。 **"更多的样本意味着更好的估计。"** 在自相关之下，在第九十九个的 $20$ 米之外的第一百个的土壤的岩心几乎不添加信息；对着变异函数的变程序设计着间隔，报告着有效的样本的大小、样本的计数。 **"显著的意味着真实的。"** 空间的 p 值假设掉了使地图有趣的关联；不带一个空间的错误的模型、一个在实际的模式上的置换的检验，显著性是生产着数字的分区的伪影。 **"聚合隐藏着噪声。"** 它制造着新的信号：相关随着边界出现、消失（可修改的区域的单元问题），生态的谬误等待着忘记着区的均值描述着没有一个实际的区的居民的人——一个传递到应用的地球科学的每一个区域的统计的小心（比较气候系统的气候统计的课）。 {#warning-spatial-analysis}
:::

::: summary {#summary-spatial-analysis}
图的代数把曲面变成一个计算的语言——局部的、焦点的、分区的、区域的算子——在它的每一个表达式也是一个错误的传播的陈述。插值从托伯勒的定律估计着未采样的地方：几何的诚实的笨的工作的反的距离的加权，一个拟合的变异函数能承载着估计、它的方差时的克里金，物理学（地形，到海岸的距离）知道时的协变量的漂移。模式的统计——莫兰的 I，盖蒂斯–奥德，里普利的 K，局部的分解——检验着制图的结构是否超过着随机，空间的统计的诅咒（伪的重复，生态的谬误，可修改的区域的单元问题）决定着检验意味着什么。手艺是工具包的一个刻度更谦逊：说明着工作流，尊守着变异函数，限定着分区，发表着方差的层在估计旁边，一个不带它的不确定度的曲面不是一个分析、一个带着颜色的坡道的意见。 {#summary-spatial-analysis}
:::
