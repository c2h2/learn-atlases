当下的碳循环是一个物种在一颗行星上做的实验，测量记录就是实验记录本。自1850年以来，表层系统吸收了约**690吉吨化石与土地利用碳**，其中约**46%**留在了天上，超额部分把CO₂从278 ppm抬到424 ppm、让地表增温约1.45 °C、把海洋化学倒拨了0.11个pH单位——与此同时，全速运转的系统之汇尽了最大努力去追赶。本课就是**当代碳收支**：那些数字、谁测的、它们如何闭合、汇在哪里失灵，以及一个温度目标对应的剩余碳预算究竟意味着什么。它是生物地球化学课程的资产负债表，也是接下来两门课程里每个气候政策数字所继承的算术。

## 账本：排放、汇、空气分数

::: definition 现代碳收支 {#def-modern-budget}
收支的两边，按**全球碳计划**的年度账目（2023年版的中心值，±1σ）：**源**——化石与工业排放**9.3 GtC yr⁻¹**（36.8 GtCO₂，其中水泥约0.6和火炬约0.4是非燃烧余项）、土地利用变化**1.1 GtC yr⁻¹**（毁林约1.3减去再生与林地扩张汇约0.3，残差的符号仍逐区域有争议）、合计**约10.4 GtC yr⁻¹**即约38 GtCO₂；以及**去向**——大气增长**4.7 GtC yr⁻¹**（Keeling曲线每年2.5 ppm的爬升，本身以每两年0.03 ppm的速度加速——那个让"增长率没问题"成为范畴错误的二阶导数）、海洋汇**2.9 GtC yr⁻¹**（由物理驱动的溶解度与泵对人为碳的吸收，由船载DIC重复断面与GLODAP储量测量，其1850年以来的累计总量为**175 ± 35 GtC**、占全部排放约26%）、陆地汇**2.9–3.2 GtC yr⁻¹**（残差，但被清查、通量塔、大气O₂与Δ¹⁴C账目佐证：CO₂施肥加氮沉降加温带造林，减去燃烧与采伐）。**空气分数**是十年的约46%，在滤掉年际噪声（厄尔尼诺的陆地呼吸与火灾年：2015–16年破纪录的3.4 ppm跳升）后无显著趋势——收支上最令人安心也最危险的一个数字：安心因为汇迄今随排放按比例扩大，危险因为它们按**不平衡的一个分数**扩大（海洋吸收表层增温和层结允许的部分，陆地吸收养分和水分容许的部分），而不是按承诺。**收支的不确定度在后果上不对称**：化石数字知道到几个百分点（燃烧化学与燃料账），土地利用数字±0.5且背后有区域争论（2020年代"亚马逊是源、非洲是汇"的重标定），而**陆地汇的方差**——±0.5–1 GtC的厄尔尼诺与火灾摆动——将决定空气分数停在0.45还是爬升，也正是观测系统（GEOSS/GCOS碳试点卫星星座、OCO-2/3与GOSAT柱足迹、GEDI与NISAR森林结构雷达）本十年要钉住的那一项。
:::

::: example 收支闭合，带警告标签 {#ex-gcp}
用化石9.3+土地利用1.1=排放10.4、大气增长4.7、海洋2.9：求作为残差的陆地汇、每项带±0.5时其不确定度（平方和根），以及若增长保持每年2.5 ppm、从今天的424起CO₂越过450 ppm的年份。
::: solution
陆地$=10.4-4.7-2.9 = 2.8$ GtC yr⁻¹，作为四项之残差$\pm\sqrt{4\times0.5^2} = \pm1.0$——陆地汇是收支中**测得最少而减得最多**的一项，一个误差棒里装着会计警告；越年是$(450-424)/2.5 \approx 10$年，这就是让"2030年代"成为1.5 °C当前用语的算术（增长速率本身的不确定性由气候变化课程的预测、而非本课承担）。
:::
:::

## 海洋的另一本账：酸化

::: definition 碳酸盐化学与Ω账本 {#def-acidification}
海洋的碳吸收在化学上不是免费的。溶解的CO₂设定**碳酸盐系统**——本质上正比于$pCO_2 \propto [H^+][DIC]/[CO_3^{2-}]$——向一个缓冲在pH 8.1的系统加入多30%的DIC有三个被测量的后果：表层pH已下降**0.11个单位**（氢离子浓度上升30%，约5,500万年以来表层海洋经历的最大化学变化，上次是PETM）、**Revelle因子**（缓冲比，约10–15并随碳酸根被消耗而上升）意味着每加入一吨CO₂让表层$pCO_2$上升约十倍于单纯稀释——海洋继续吸收的意愿**随吸收而衰减**——而作为壳体原料的碳酸根离子全球已下降约8%，在溶解度把碳装载最重的寒冷高纬水域降得最深最快。操作性指标是**饱和态**$\Omega = [Ca^{2+}][CO_3^{2-}]/K_{sp}$：大于1壳体不溶解，小于1海水有腐蚀性。表层$\Omega_{aragonite}$已全球从约3.4降到约3.0，在**北极和南大洋的部分海域降到接近1**，那里冬季水体已经欠饱和；**翼足类**野外记录（"海蝴蝶"的壳在欠饱和水中起坑，自2007年以来在美国西海岸上升流区和北极夏季欠饱和区被记录在案）是账本上显微镜可见的一端，而**2000年代中期太平洋西北的牡蛎孵化场崩溃**（酸化上升流水杀死幼体收成，如今靠现场化学监测管理——有记录以来酸化第一笔经济损失，也是随之而来的热带珊瑚与有孔虫账本的预告）。深海的账更慢也更大：**溶解跃层与碳酸盐补偿深度自1850年以来上升约400–500米**（深海太平洋与大西洋对年轻人为碳脉冲的方解石溶解响应，在沉积记录中相对工业化前基线可测），而沉积物作为补偿将溶解的碳质量（来自下方的碱度加入对酸化的"中和"）是海洋无论我们停不停排放都将为我们执行的一项**10⁴–10⁵年**的服务——拯救过PETM气候的正是这套慢化学，而同一个时钟让今天的表层化学变化在地质上**瞬时**（DIC加入的速率比新生代记录中任何已知自然类例快一个数量级，有孔虫δ¹¹B与B/Ca证据显示PETM的碳释放即使在最快时也把pH极小值摊在几千年而不是几十年上）。
:::

::: example Revelle算术 {#ex-revelle}
缓冲（Revelle）因子定义为$RF = (\Delta pCO_2/pCO_2)/(\Delta DIC/DIC)$。表层DIC 2,000 µmol kg⁻¹、工业化前pCO₂ 280 µatm、RF = 12，求向封闭表层水团加入100 µmol kg⁻¹人为DIC引起的pCO₂上升，并用一句话解释为什么随DIC加入RF上升。
::: solution
$\Delta DIC/DIC = 100/2000 = 0.05$；$\Delta pCO_2/pCO_2 = 12\times0.05 = 0.60$，所以pCO₂上升$0.60\times280 = 168$ µatm——到约448，这就是表层海洋是一个**愿意但很快变硬**的伙伴的原因：随碳酸根离子被消耗，缓冲的分母下降，每一吨未来碳让pCO₂（以及pH和Ω）的变化比上一吨**更**大——汇的分数效率随使用而衰减，与银行相反，与矿藏相同。
:::
:::

## 陆地的账、收支的未来与移除

::: definition 陆地汇、剩余预算，以及移除的现实 {#def-rcb}
过去半个世纪的陆地汇是**一个有两处正在倒戈的四派联盟**：CO₂施肥（FACE与开顶箱证据，当前CO₂下额外吸收约0.5–1 GtC yr⁻¹，随氮磷束缚而每ppm递减）、来自人类循环的氮沉降（温带森林与北方森林的施肥，约0.4–0.6，以及同一通量的酸化与富营养化欠债）、温带与北方**再植被**（中国与欧洲的变绿、美国东南部弃耕农地的森林，约0.5–1），以及**老龄碳保持**——后者正被火灾和伐木攻击；倒戈的一方：**亚马逊的转变**（2010–2020年清查与大气证据显示东南弧已成为约0.3–0.5 GtC yr⁻¹的源，长期样地网络的死亡率上升和2015/2019/2023年的火灾干旱年记录了生物量下降），以及**北方火灾-松甲虫制度**（2014–2023年加拿大火季让整个年度国家清单转正，仅2023年大火就排放约0.4–0.7 GtC生物质碳——与一个排放大国的全年土地利用通量相当）。**剩余碳预算**（碳收支文献与IPCC特别报告的RCB：与温度上限相容的累计CO₂排放，由近乎线性的**对累计排放的瞬态气候响应**（每1,000 GtCO₂约0.45 °C）加非CO₂强迫加地球系统已承诺的部分导出）：1.5 °C、50%概率，**从2024年初约250 GtCO₂**——当前排放的十年；2 °C约1,200——一代半人——而预算诚实的注脚是它**不是配额而是概率陈述**，以每十年400 GtCO₂的速度花掉，且已被我们锁定的增温部分消耗。**二氧化碳移除**（CDR）作为闭合的算术进入收支：IPCC评估情景里每条1.5 °C路径都用到它（2050年中位数约5 GtCO₂ yr⁻¹、2100年累计约600 GtCO₂），而2020年代中期的**已部署现实**是工程移除约0.002 GtCO₂ yr⁻¹（直接空气捕集与生物质能碳捕集工厂，比模型2050年中位数差约2,000倍），加上常规陆地固碳约2–3 GtCO₂ yr⁻¹（森林与土壤，附带火灾与市场的逆转风险）——模型假设与部署曲线之间的缺口是气候政策中后果最重的单个数字，也是诚实读法的理由："**现在减排，移除按物理和土地实际能给的大小定，不做假定第三个选项的账**"。
:::

::: example 收支的钟 {#ex-rcb}
1.5 °C（50%）剩余预算250 GtCO₂；当前排放40 GtCO₂ yr⁻¹，非CO₂强迫固定。求平坦排放下的耗尽年份，以及排放以每年7%下降（巴黎一致斜率）时的年份，并说明为什么政策不采用第一个数字。
::: solution
平坦：$250/40 \approx 6$年（2030年代中期）；以每年−7%下降，累计和$40\,(1-e^{-0.07T})/0.07 = 250$给出$1-e^{-0.07T} = 0.438$、$T \approx 8.6$年——衰减买到的**有限**延展，因为预算是累计的，即使快速下降也仍在花钱。第一个数字不是政策所用的，因为预算在原则上是**概率性且可再生的**（负排放可以把预算还回来——移除问题的全部重量在一个星号里），但算术的教训成立：预算以**当前排放的年数**计量，而非规划排放的十年。
:::
:::

## 生物圈的呼吸：CO₂的季节循环

::: definition CO₂的季节循环 {#def-seasonal}
Mauna Loa的曲线是北半球生物圈画出的锯齿：每年北半球春夏，光合在三大洲上跑赢呼吸，CO₂下降约6 ppm；每年秋冬，腐烂与暗呼吸跑赢生长，CO₂回升——山顶振幅约3 ppm，而**高纬北方站点15 ppm甚至更多**（Barrow/Utqiaġvik、Alert），那里的冬季气团即起源于此。记录的两个慢变化本身即是气候发现：振幅自1960年代以来**增大约10–20%**（高纬增长增强的签名——变绿、生长季拉长、**Myneni、Running、Nemani及其同事**2002年的检测与2020年代反演模型的确认），而**春季拐点在北方站点提前了数天到数周**（曲线拐点上直接可读的物候位移，被卫星绿度与水华记录佐证，也是Keeling自己1960年代数据里潜藏的唯一一个气候信号）。季节循环也是方差教训的缩影：画锯齿的同一台光合引擎驱动陆地汇，其振幅是收支的小不平衡栖居其中的**总通量**（约3 GtC yr⁻¹的汇骑在约120 GtC yr⁻¹的季节呼吸上——这就是汇难测而易毁的原因），而厄尔尼诺年让回升变大（2015–16年的3.4 ppm增长：约7 GtC的额外热带呼吸与火碳，曲线上有记录以来最大的陆地汇失效）。前沿是循环在**未来气候下的不对称**：若暖春促进生长、而暖秋、干旱和火灾添进的呼吸多于拉长生长季固定的，振幅会增大而**年均值照样上升**——一个看起来更绿、呼吸更快、固碳更弱的陆地。
:::

::: example 用ppm写成的厄尔尼诺 {#ex-elnino}
2015–2016年厄尔尼诺在趋势之上留下了约3.4 ppm的额外CO₂增长。把异常换算成千吉吨碳，并用一句话解释为什么该事件被读作**陆地**信号而非海洋信号。
::: solution
约18个月里大气中多了$3.4\times2.12 \approx 7$ GtC的额外碳——整个年度土地利用通量的规模，由热带干旱火灾和陆地吸收减少释放（海洋对厄尔尼诺的响应小而反向：更强的风和赤道变冷略微增加其吸收）。同一些年份的δ¹³C与Δ¹⁴C异常——贫化石碳、带生物质燃烧风味的空气——以同位素签名判定陆地的罪，示踪方法当场抓住一次半球尺度的通量失效。
:::
:::

::: warning 预算是概率不是配额，汇是分数不是承诺，酸化不是"不过是pH"，移除不是抽屉里现成的B计划，而陆地汇的方差才是体系的男主角
五个错误。**"我们有250 GtCO₂，所以可以继续排到2030年代"**：剩余预算是一个**50%概率**的陈述，围绕它的中心估计自身的不确定性（气候敏感度散布、非CO₂强迫、已承诺增温）就是±250 GtCO₂——预算可能只有一半也可能是两倍，而审慎的读法是更小不是更大；"耗尽"也不是悬崖，而是每吨都在上升的概率。**"海洋和陆地会继续吸收一半"**：它们吸收一半靠的是**两个不平衡**（表层到内部的混合梯度、施肥减扰动的平衡），两者都随系统调整而减弱（Revelle因子上升、层结增强、亚马逊转向、火灾吞噬北方森林）——空气分数温和的上升趋势是减弱的第一项测量，而CMIP6系综的陆地汇散布（到2100年相差两倍）是未来的诚实陈述。**"海洋要降到pH 7"**：高排放下本世纪末的预测是**0.3–0.4个单位**，不是1.4——要点不是整数而是**饱和态和生物**：Ω文石在极地夏天越过1、翼足类起坑的壳、大堡礁1980–2020年代骨骼记录中记录了钙化下降的珊瑚、华盛顿州的幼牡蛎——酸化是一本**逐生物、逐区域**的账，不是一条全球pH头条。**"以后捕回来"**：模型的中位移除（2050年5 GtCO₂ yr⁻¹）超出部署现实三个数量级，陆地那一半要在占用账本已经超支的同一片土地上与粮食和生物多样性竞争，而持久性问题（森林是贷款、水库是租约、咸水层是唯一带地质期限的产品）意味着移除的**储存**是与**捕集**分开的工程问题；预算算术对"现在减"比"以后减加移除"更客气，而每拖一年都抬高第二个选项的价格。**还有"年际摆动是噪声"**：厄尔尼诺陆地呼吸摆动（±1 GtC yr⁻¹）和火制度是**未来气候陆地汇的信号本身**，不是围绕它的扰动——2015、2023和未来的火灾年是陆地汇的方差如期抵达，而一个只建立在均值上而不含方差的碳政策，建立在正在终结的那半个循环上。
:::

::: history
收支的测量谱系是本图谱最长的连续实验：**John Tyndall**的温室光谱学（1859–61）与**Svante Arrhenius**的第一个CO₂-气候计算（1896，他的3 °C敏感度在今天的区间倍数之内）；**Thomas Chrowder Chamberlin**对立的碳循环推理（1899，含海洋吸收的警告）；**Roger Revelle和Hans Suess**1957年证明表层海洋吸收不了化石脉冲（Revelle因子的发现，让Keeling测量既必要又充分的那个预测）；**Charles David Keeling**自1958年的Mauna Loa与南极曲线（与冰芯的工业化前对比、把锯齿读作北半球生物圈呼吸的季节解读、其子**Ralph Keeling**和Scripps/NOAA项目对曲线65年的延续）；**WOCE/CLIVAR重复断面计划与GLODAP储量**（1990年代至2020年代船上清点，直接数出了海洋的人为碳，**Sabine、Gruber、Khatiwala、Key**及其同事的独立清点方法）；**FLUXNET**通量塔（1997年至今）、全球碳计划自2006年的年度收支（**Pierre Friedlingstein、Corinne Le Quéré、Pep Canadell、Robbie Andrew**与百人作者团队——行星科学最接近季度财报的东西）；**卫星时代**（GOSAT 2009、OCO-2 2014、2020年代现在能**从轨道上探测一个国家的排放变化**的碳delta-plus与人为NO₂排放验证研究——巴黎协定强化透明度框架生来就要使用的透明度架构）；以及**剩余预算文献**（**Myles Allen**的碳-气候数学与2013–2018年碳收支综合、IPCC 1.5特别报告2018年的正式化、全球碳收支的年度更新）。酸化账本从19世纪挑战者号分析的碳酸盐化学（1880年代）延伸到**Uwe Riebesell、Ken Caldeira、Scott Doney、Victoria Fabry、Jean-Pierre Gattuso和Richard Feely**在1990–2000年代发现表层pH下降已经可测、2007–2009年的翼足类与孵化场报告，以及让pH下降像CO₂上升一样成为观测事实的**SOCEP/OSNAP与BATS/HOT**化学时间序列（1980年代至今）。
:::

Revelle因子（约12）描述的是：
- [ ] 海洋把人为碳混到多深的速度。
- [x] 给定分数的DIC加入让表层pCO₂上升多少——缓冲的硬度。
- [ ] 空气分数的十年趋势。
- [ ] 陆地汇与海洋汇之比。
::: solution
它是碳酸盐缓冲的杠杆比$(\Delta pCO_2/pCO_2)/(\Delta DIC/DIC)$：RF高意味着海洋对每单位表层pCO₂差吸收更多CO₂有抵抗——而且它随碳酸盐被消耗而**上升**，所以汇的效率随使用而衰减。
:::
:::

::: summary
当代碳收支是测出来的，不是模出来的：排放约10.4 GtC yr⁻¹（化石9.3、土地利用1.1）、46%在空中（Keeling曲线每年2.5 ppm）、约26%在海洋（1850年以来175 GtC，在船上数出来的）、约30%在陆地（残差、施肥联盟，其倒戈项是正在减弱的亚马逊与火灾年）。海洋的化学账单——pH降0.11、Revelle因子上升、文石饱和度在极海水域逼近1、溶解跃层比过去浅500米——是另一场更安静的危机，而陆地的账单是一座由暂时性补贴堆成的汇。剩余碳预算（1.5 °C掷硬币的250 GtCO₂、当前排放的六年）是一个带斜率的概率，而每条路径都假定的移除能力距部署还差三个数量级。收支今天是闭合的；本世纪的问题是它明天是否闭合，而那个问题住在汇的方差里、火灾的日历里、以及模型的移除与世界的移除之间的差额里。
:::

::: exercise {level=1 check="46"}
求排放10.4、大气增长4.7 GtC yr⁻¹的空气分数（百分比）。
::: solution
$4.7/10.4 = 0.45\text{–}0.46$——46%，海洋和陆地拒绝承担的那一份。
:::

::: exercise {level=1 check="0.11"}
自1750年以来表层海洋pH下降了几个pH单位？
::: solution
**0.11个单位**——氢离子上升30%，约5,500万年来表层海洋最快的化学变化。
:::

::: exercise {level=2 check="168"}
Revelle因子12、DIC加入5%，求从工业化前280起的pCO₂上升（µatm）。
::: solution
$12\times0.05\times280 = 168$ µatm——缓冲的杠杆在一次乘法里，也是海洋对每未来一吨的吸收越来越小的原因。
:::

::: exercise {level=2 check="10"}
以排放10.4、增长4.7、海洋2.7求作为残差的陆地汇（GtC yr⁻¹）。
::: solution
$10.4-4.7-2.7 = 3.0$ GtC yr⁻¹——四条独立线索（清查、通量、O₂、Δ¹⁴C）在约2.5–3.5佐证的那个残差。
:::
:::

::: exercise {level=3 check="8.6"}
对250 GtCO₂预算和每年下降7%的40 GtCO₂ yr⁻¹，用$40(1-e^{-0.07T})/0.07 = 250$求耗尽时间（年，一位小数）。
::: solution
$1-e^{-0.07T} = 0.438$给出$T = -\ln(0.562)/0.07 \approx 8.6$年——陡峭的下降只买到几年额外时间，因为预算是累计的：碳循环的物理是银行存款余额的物理，不是月供的物理。
:::
:::

IPCC 1.5 °C路径假定2050年工程移除约5 GtCO₂ yr⁻¹；2020年代中期的部署约0.002。求倍数缺口。
