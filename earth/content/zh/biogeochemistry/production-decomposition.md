生物圈由两台方向相反的引擎驱动：一台把可用阳光能量的四分之一固定成碳并用它造身体，另一台把身体拆开把碳还回去，快慢取决于温度、水和凋落物的化学。两者之间——生产与分解之间的缺口——坐着地球上每一单位木材、泥炭、土壤和化石燃料，以及整个"活的表面是汇还是源"的问题。**初级生产**与**分解**因此是这颗行星上最大的两个生物地球化学通量（各以每年约60吉吨碳穿过陆地，海洋的引擎几乎同样多），而它们的平衡——不是任何单独一台——在短于地质的所有时标上设定生物圈的增长、土壤的存量、空气的氧和大气CO₂储库的大小。本课就是这对引擎：什么驱动它们、什么限制它们，以及当一个变暖的世界让第二台比第一台加速更多时会发生什么。

## 生产：光与养分相遇之处

::: definition 光利用经济及其限制 {#def-production}
光合作用是一门**光利用**生意、带一个**养分**约束，全球格局就从这两者掉出来。总初级生产（GPP）陆地约123 GtC yr⁻¹、海洋约110；一半被生产者自己呼吸掉，留下**净初级生产**（NPP）陆地约56–60、海洋约45–50——其余一切可用的生物量预算。在陆地，生产遵循**Monteith光利用效率**公式（John Monteith，1972）：GPP =（吸收的光合有效辐射）×（效率，0.5–2 g C每MJ，被寒冷、干旱和养分贫瘠降级），这就是为什么陆地NPP地图呈从热带雨林（约2,000 g C m⁻² yr⁻¹）经温带森林和稀树草原（约600–1,200）到草原、北方针叶林、冻原和荒漠（<100）的梯度，也是为什么卫星时代的日光诱导叶绿素荧光与通量塔网络（FLUXNET的500多个点位）能目睹生物圈的光合**在海洋热浪和干旱中昏厥**——2015和2023年亚马逊异常从轨道上可见。在海洋，光只穿透3,700米世界的顶部约100米，而表层被自己的肥沃剥走了养分：生产因此被限制在物理让光与养分**复合**之处——高纬与海岸上升流区、赤道辐散、南大洋被铁抑制的边缘——而层结的副热带环流（海洋表面的70%）是荒漠NPP速率的蓝色沙漠，**陆架海**（8%的面积）远打超其体重（以一小部分水体产出海洋生产的四分之一到三分之一，渔业后果不言自明）。限制营养盐的地理遵循Redfield的账：高硝盐低叶绿素海里的铁（Martin铁假说及其六次混合施肥实验）、固氮微生物能缓解处的氮（氮——在固氮微生物能缓解之处——*Trichodesmium*及其亲缘，其水华追踪温暖、层结、富磷的水——而）、深时（也许还有未来）古老富氮海洋里的磷，以及极地春季水华和深层叶绿素极大里的光本身。人类对生产的印记现在已是生物圈最大的单项印记：化肥与灌溉让耕地的NPP相对其自然状态**翻倍**（"集约化省地"论点），CO₂施肥让全球GPP自1900年以来抬升约12%（卫星变绿，其一半在水而非氮约束响应率的旱地），而让陆地变绿的同一份CO₂和增温正让海洋**变褐**（层结切断养分供应；卫星记录的全球海洋NPP趋势持平到下降，其大小是一场持续的传感器记录之争）。
:::

::: example 一片森林的光预算 {#ex-lue}
一片温带森林在生长季吸收500 W m⁻²光合有效辐射、光利用效率1.0 g C每MJ、无胁迫降级。求12小时昼长的日GPP（C m⁻² d⁻¹），以及若呼吸取一半、生长季200天时的年NPP。
::: solution
PAR能量$= 500\times43{,}200 = 2.16\times10^{7}$ J $= 21.6$ MJ m⁻² d⁻¹；GPP$= 21.6\times1.0 = 21.6$ g C m⁻² d⁻¹；年GPP$= 21.6\times200 = 4{,}320$；NPP$= 2{,}160$ g C m⁻² yr⁻¹——一片高产的森林，而这个练习就是Monteith引擎的全部：阳光 × 效率 × 生长季，气候开支票（干旱、寒冷、水汽压），效率负责兑付。
:::
:::

## 分解：腐烂的引擎

::: definition 凋落物质量、气候，以及厌氧替代方案 {#def-decomposition}
分解经**异养引擎**——细菌和真菌用胞外酶开采凋落物与土壤——归还固定碳，陆地约55–60 GtC yr⁻¹、海洋水柱与沉积物约50，而其速率由三个相互牵制的因素设定。**底物质量**：活性化合物（糖、蛋白质）几天内消失，而**木质素、木栓质、蜡和单宁**抵抗酶攻击——凋落物的木质素:N比与"化学活性度"（**Yasso**衰减序列假说：质量支配快组分、以及什么能活进土壤的分子记忆）解释了针叶凋落物为何积累、粪肥为何消失；现代的转折是**Mark Bradford和Joshua Schimel学派**的**微生物效率矩阵**框架：微生物碳利用效率（CUE，消耗碳中被建成生物量而非呼吸掉的比例，约0.3–0.6）决定碳是**丢失还是转移**到土壤剖面深处，而微生物残体——死虫而非死植物——现在占了稳定土壤有机质的**大多数**（2010年代改写土壤学教科书的"残体洗牌"）。**气候**：分解的温度敏感度（van 't Hoff的**Q₁₀**，典型约1.5–2.5——速率每10 °C上升50–150%）超过光合作用的，这就是为什么**土壤是气候系统的正反馈**：让腐烂比生长加速更多的增温会抽干最大的陆地碳库；而水分把一切闸门（通气控制终点是CO₂还是湿世界的**甲烷**，渍水土壤与湿地排放约150–200 Tg CH₄ yr⁻¹，稻田与反刍动物补上现代收支的人类一半）。**深度与保护**：化学抗腐性建造长命土壤碳的老教科书观念已被**理化保护**废黜（吸附在黏土上、封在团聚体里的碳无论化学如何都逃脱酶——这就是为什么深部土壤碳老到放射性碳亏损、却以千年翻新，而表层腐殖质以年翻新），也已被"增温也许同样释放受保护碳"的认识废黜（**激发效应**：新鲜根系分泌物刺激微生物开采老碳——一个让土壤反馈**非线性**、让模型的土壤模块成为每本陆地碳循环预测最弱一环的机制）。简言之，分解引擎就是碳循环最快、最大不确定性居住之处：让一片森林生长的同一度增温也许能掏空它的土壤，而差别写在酶动力学和黏土矿物学里，不在CO₂价格里。
:::

::: example Q₁₀赌注 {#ex-q10}
土壤呼吸Q₁₀ = 2。求+3 °C的速率增幅；以及若增温让异养呼吸加速那个因子、而输入无补偿增加，一个1,200 GtC活动层土壤库（基线周转30年）在一个世纪里损失的碳。
::: solution
$2^{0.3} = 1.23$——加速23%；基线呼吸$= 1{,}200/30 = 40$ GtC yr⁻¹，变暖后到49，所以100年在无补偿极限下的额外损失是$9\times100 = 900$ GtC（真实数字小得多，因为输入也在上升、底物在耗竭——练习的要点是**赌注的规模**：即使这个极限的三分之一也是数十年的空气分数灾难，这就是为什么每个CMIP陆地模型的土壤模块先于其政治被审计）。
:::
:::

## 土壤图书馆与其永久冻土附册

::: definition 土壤碳存量与其脆弱的附册 {#def-soil-library}
土壤持有**1,500–2,400 GtC**（这个区间就是2010年代的深度与岩碳之争：2米对3米，含无机碳与否）——比植被与大气之和还多，而其中绝大部分**不在**快的表层：土壤碳的平均年龄分布是双峰的，三分之一到一半以年到十年翻新，而深的矿物保护组分以世纪到千年翻新。存量的地理就是分解的自传：泥炭地（陆地3%，约550 GtC——土壤库的四分之一装在澳大利亚大小的面积里，由**渍水对腐烂的制止**建成，全新世最慢也最可靠的碳汇）、永久冻土区**约1,500 GtC**的冻结有机质（土壤加含冰雅冰复合体，大气存量的两倍，被一个如今已经消失的气候冻住），以及草原与耕地的剖面（其命运——开垦草原在农业抵达之处释放了其碳的**一半到三分之二**——西伯利亚、北美和乌克兰粮仓的历史可以读成一层碳损失的地层）。**永久冻土**附册是本世纪最大的碳循环不确定性：当前预测（**Schuur、McGuire及其同事**实地核实的评估）把永久冻土区的释放放在**高排放下2100年每年数十GtC**（土壤CO₂与甲烷之比各模型仍相差两倍），而**突发融塌**（热喀斯特塌陷、海底甲烷）是模型低估的尾部风险，因为它们分辨的是米、不是滑塌；**全球泥炭与旱地**附册添上自己的百搭牌（降雨事件后旱地的"生物地球化学热脉冲"、2010–2020年火灾干旱年记录中亚马逊枯退从汇到源的转变）。记账的后果就是课程的核心警告：**过去60年的陆地汇（约3 GtC yr⁻¹）不是生物圈欠下的服务**——它是一个施了氮肥、部分再造林的星球上CO₂施肥的意外盈余，而同一生物圈的分解引擎、干旱和火灾已经在**削减**它的余量（2010–2020年代空气分数趋势、2023年北半球火灾与异常年）。因此一项面向气候的土壤碳战略（"千分之四"倡议的算术：土壤碳每年+0.4%可以抵消排放的四分之一）既是碳管理中最有吸引力、也是被推销过度的主意——有吸引力因为土壤广袤而农业天天触碰它们，被过度推销因为饱和、氮限制和逆转风险（耕过、烧过、排过干：碳离开比来时更快也更彻底）把承诺约束到口号的一个分数。
:::

::: example 永久冻土算术 {#ex-permafrost}
永久冻土区在顶部3米持有约1,500 GtC；模型预测高排放下2100年约10–20%融化、其中三分之一分解为CO₂/CH₄。求碳释放区间、其CO₂当量（以CO₂计的ppm），以及为什么甲烷份额让区间比看上去更宽。
::: solution
$1{,}500\times0.10\times\tfrac{1}{3} = 50$ 到 $1{,}500\times0.20\times\tfrac{1}{3} = 100$ GtC；以CO₂计为$50/2.12 \approx 24$ 到 $100/2.12 \approx 47$ ppm。甲烷份额（厌氧融塌的百分之几到约20%，每克在一个世纪里约值80个CO₂年）**把上界再拉宽几十个增温当量**、且在前50年前置抵达——这就是为什么永久冻土问题不是"多少碳"而是"多快、以哪种气体、经过哪种景观：渐进变干还是突发塌陷"。
:::
:::

## 水中间层：微生物环

::: definition 微生物环与海洋生产的归宿 {#def-microbial-loop}
在海里，光合固定的大部分从未抵达对渔业或碳汇要紧的嘴：它被**微生物环**截走（**Farooq Azam和Tom Fenchel及其同事**，1983）——溶解有机碳（海洋GPP的三分之一到一半，从健康细胞渗出、被病毒裂解从细胞上撕下，"病毒分流"在被吃掉之前回收每日生产的四分之一到一半）被自由生活细菌吸收、建成细菌生物量、被鞭毛虫和纤毛虫捕食、而它们又被桡足幼体吃掉。环的两个数字组织着海洋生物地球化学：**细菌生长效率**（海洋CUE，温暖的贫瘠水域约0.1–0.4、在寒冷富营养富硅藻的系统更高——温暖水域把碳在更靠近表层处呼吸掉的原因），以及**输出比**（NPP中沉到混合层之下的份额，约0.1–0.4，生物泵——以及它压住的大气CO₂——实际依赖的量）。环的教训可推广到每个分解系统：**分解者群落的尺寸结构、而不只是温度，设定碳是离开系统还是在系统里打转**——一周内下沉的硅藻水华把碳送到深处；同样这些碳若在暖环流里以溶解质漏出，几天内就被呼吸回来，而海洋对增温的响应（更小的细胞、更低的输出效率、更浅的呼吸——BATS和HOT自1988和1989年运行的时间序列记录的"海洋代谢变浅"）是环的重组甚于其速率的改变。
:::

::: example 输出比说了算 {#ex-export}
某海区NPP为300 g C m⁻² yr⁻¹。比较输出比0.1（温暖、微生物环主导）与0.35（硅藻水华）下每平米每年输出到混合层之下的碳，并用一句话解释为什么海洋的碳汇是一个**食物网**问题。
::: solution
$300\times0.1 = 30$ 对 $300\times0.35 = 105$ g C m⁻² yr⁻¹输出——**仅凭群落结构**、同样的光合下3.5倍的差别。碳汇取决于生产是以快沉的聚集体和粪粒离开表层、还是溶进环里就地进行呼吸：这就是"更多CO₂、更多藻类、更多汇"作为算术不成立的原因，也是本世纪海洋碳预测取决于谁吃什么、多快、多深的原因。
:::
:::

::: warning NPP不是碳故事的全部，Q₁₀不是承诺，残体改写了教科书，海洋的引擎不能豁免，而"给生物圈施肥"被氮和水约束着
五个错误。**"保护森林=保护碳"**：森林储存碳也**循环**碳——成熟森林的NPP很大而其净生态系统生产接近零，木材产品与土壤的账（加上北方针叶造林的反照率权衡，其增温可能超过碳的冷却）决定一公顷树是否有益；要紧的碳是两台引擎的**净值**，不是海报颂扬的总光合。**"增温会按Q₁₀加速分解，句号"**：适应文献（微生物群落下调酶、底物库耗竭、表观Q₁₀随增温推进而下降——"激发悖论"与2010年代增温实验显示响应小于季节Q₁₀的预测）说**有效**反馈小于朴素的那个——而深土与永久冻土文献说在底物不受限之处朴素的也许仍然对；诚实的区间横跨三倍。**"土壤有机质是化学顽固的腐殖质"**：腐殖质模型的世纪已经结束——稳定土壤碳大多是**与矿物结合的微生物残体和受表面与团聚体保护的植物源聚合物**，"腐殖化"是一个死亡与附着的过程，不是分子蒸馏；实际后果（**物理扰动——耕作、排水——破坏保护、释放老碳，无论化学如何**）就是免耕和复湿有效、而"堆肥造腐殖质"半有效的原因。**"海洋的分解引擎是另一回事"**：海洋异养呼吸在混合层**之内**消耗海洋NPP的约90%（微生物环在碳能被输出之前把它送回），而决定生物泵强度——及其在增温下减弱（更大细胞、CUE更低的暖适应群落、单位输出更多呼吸）——的输出效率是本世纪海洋碳循环的问题。**还有"CO₂施肥会让陆地持续变绿"**：施肥效应真实（GPP抬升约12%）且已随氮和水束缚它而**衰减**（FACE实验渐进的氮限制、旱地变绿对下一场干旱的敏感、亚马逊2015/2023年的反复）；陆地汇是**来自未来的临时补贴**，而分解引擎、火灾和采伐正在写账单。

::: history
生产科学始于**Joseph Priestley和Jan Ingenhousz**的植物-空气实验（1770年代）与**Julius von Liebig**的矿质与最小律学说（1840）；碳测量时代始于**Frederick Blackman**的限制因子生理学（1905）与**Daniel Arnon、Robert Emerson和William Arnold**的光合量子工作（1930–40年代，后两人同**Melvin Calvin**的循环共享1961年诺贝尔奖）。**Monteith**的光利用效率（1972–79）把生理学变成遥感，**BIOMASS/UMD与MODIS**生产模型（Running及其同事，1990–2000年代）加上FLUXNET塔网（1997年至今）与OCO-2和日光诱导荧光卫星（2010年代）把陆地引擎变成每日可观测。分解科学从**Marcelin Boullanger与Rothamsted学派**的长期粪肥与小区实验（1843年起的小区首次测量了腐殖质衰减），经**Waksman和Starkey**的土壤微生物学教科书（1924）、**Jenny和Schlesinger**的生物地球化学综合、以及**Q₁₀/Chen-Widlund**小气候之争，到2010年代的改写：**Bradford和Schimel**的微生物效率矩阵框架、**Reichstein、Janssens、Peñuelas及其同事**的增温实验综合，以及**Tarnocai、Hugelius、Schuur和McGuire**的永久冻土存量清单——过去二十年的教训是：土壤的账本必须先重写，本世纪的账才可信。海洋的引擎是**Redfield-Krogh-Stemann Nielsen**谱系（1930–50年代：**August Krogh**的呼吸测量、**Marcus Steemann Nielsen**1952年让海洋生产变得可测的¹⁴C法）、**Volk和Hoffert**（1985）的生物泵理论与**Jorge Sarmiento和Denis Gruber**的海洋生物地球化学综合（2006），以及从CZCS 1978到Sentinel-3和PACE 2024、从轨道上注视蓝色沙漠与水华的全球海洋水色计划。
:::

::: quiz
现在理解中稳定土壤有机质的大多数是：
- [ ] 化学抗腐的植物"腐殖质"。
- [x] 与矿物结合的微生物残体与受保护的残余。
- [ ] 仅黑碳。
- [ ] 溶液中的根系分泌物。
::: solution
腐殖质模型的废黜：持久的土壤碳大多是微生物死物质与植物聚合物，被矿物和团聚体**物理与化学保护**——这就是为什么损失的主要杠杆是扰动（耕作、排水）而非化学，也是为什么"培育腐殖质"的口号需要保护机制才持久。
:::

::: summary
生物圈的两台引擎——光合作用（总约230 GtC yr⁻¹，一半当场呼吸）与分解（归还约110 GtC yr⁻¹）——框住了人类时标上的每一个碳问题：生产是一门光利用经济，受水、养分和（海上）光与深层养分复合的限制；分解是一门酶经济，由凋落物质量、温度（Q₁₀约2）、水分（CO₂对CH₄），以及最重要的**保护**——残体来源碳的矿物与团聚体监护，它让土壤成为最大的陆地库——治理。脆弱的附册（泥炭、永久冻土的1,500 GtC、深层矿物土）是本世纪的正反馈观察名单，而陆地汇的未来——施肥的临时盈余减去加速的腐烂引擎——是一个帮忙的生物圈与一个向我们开账单的生物圈之别。两台引擎现在可以从塔和轨道上每日观测；科学的前沿仍藏在土里，那里的碳很老、被保护着，而且正在融化。
:::

求陆地GPP 123、自养呼吸63时的NPP（GtC yr⁻¹）。
::: solution
$123-63 = 60$ GtC yr⁻¹——总生产的一半，陆地的生物量预算。

::: exercise {level=1 check="45"}
求海洋面积3.6×10¹⁴ m²、平均125 g C m⁻² yr⁻¹时的海洋NPP（GtC yr⁻¹）。
::: solution
$3.6\times10^{14}\times125 = 4.5\times10^{16}$ g = 45 GtC yr⁻¹——蓝色沙漠的平均值，在更大的画布上取陆地总量的一半。
:::

::: exercise {level=1 check="1.23"}
求Q₁₀ = 2时+3 °C的土壤呼吸乘数。
::: solution
$2^{0.3} = 1.23$——每三度腐烂快23%，一个指数里的正反馈。
:::

::: exercise {level=1 check="0.5"}
一个碳利用效率0.5的细菌消耗200 µM葡萄糖碳。求呼吸掉的碳（µM）。
::: solution
$(1-0.5)\times200 = 100$ µM被呼吸——CUE就是微生物引擎里碳汇与碳呼吸之差。

::: exercise {level=2 check="2160"}
一片森林的GPP为21.6 g C m⁻² d⁻¹、生长季200天，自养呼吸取一半。求年NPP（g C m⁻² yr⁻¹）。

$21.6\times200/2 = 2{,}160$ g C m⁻² yr⁻¹——高产森林的光预算，被自身代谢减半。

::: exercise {level=3 check="50"}
求1,500 GtC永久冻土融化10%、分解三分之一时的低端碳释放（GtC）。
::: solution
$1{,}500\times0.10/3 = 50$ GtC——2100年区间的低端，若全为CO₂即24 ppm。

::: exercise {level=3 check="47"}
把高端永久冻土释放（1,500 GtC融化20%、分解三分之一）表示为CO₂的ppm。
::: solution
$1{,}500\times0.20/3 = 100$ GtC，而$100/2.12 \approx 47$ ppm——永久冻土附册是一个藏在景观尺度过程里的政策尺度数字的原因。
