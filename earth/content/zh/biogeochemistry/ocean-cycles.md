海洋的溶解碳存量是大气碳的五十倍，其中九成在黑暗寒冷的内部——正是这个事实让海洋生物地球化学成为气候系统最大的活机器。两台泵让深海富碳富营养、表层贫瘠：物理的**溶解度泵**（冷水吸收、高纬度俯冲、海洋碳存量在温跃层封住之处堆起）和生命的**生物泵**（表层光合、微光带下沉颗粒、黑暗中的呼吸——一条重力传送带，**John Martin**提议它是冰期CO₂的杠杆，2020年代测得每年输出约10吉吨碳，是人类海洋吸收速率的一百倍、但只有当我们让它慢下来时它才朝对我们*不利*的方向运转）。本课就是把海洋的循环当作一台机器：泵及其效率、喂养它们的营养盐阶梯与上升流、引导碳命运的硅与碳酸盐压舱物，以及如今写在水体里的人为扰动之脱氧与层结信号。

## 两台泵

::: definition 溶解度泵与生物泵，以及海洋的碳梯度 {#def-ocean-pumps}
与420 ppm CO₂平衡的表层海水会持有约2,000 µmol kg⁻¹溶解无机碳；北太平洋深海持有约2,300、大西洋深海约2,250，而赤道太平洋表层尽管肥沃却*过饱和*于CO₂——这个梯度及其悖论就是两台泵的联合产出。**溶解度泵**是物理的：CO₂在低温高压水中更易溶，所以北大西洋和南大洋——冬季冷却驱动深对流与俯冲之处——把溶解碳和人为碳（约175 GtC的储量，极大值就在同样的俯冲区）带到通风温跃层之下，全球海洋的**预存**碳存量在那里设定；该泵的气候敏感度就是它的弱点（增温与变淡让俯冲变慢，而溶解度本身每10 °C下降约10%）。**生物泵**是Redfield循环的重力部分：**新生产**（硝盐支撑的，**Dugdale和Goering**1967年的¹⁵N创新把"新"生产与"再生"生产劈开、创立了定量海洋生物地球化学）以颗粒输出碳——混合层之下约10 GtC yr⁻¹的**输出生产**，其中只有**约0.1–0.2%到达海底**（**Martin等**1987年的衰减"幂律"、中光层"微光带"的群落呼吸把其余部分以CO₂归还深处，同时维持着氧最低区和营养盐极大值）。因此泵的效能是一个**深度问题**（同一吨输出在100米处呼吸就把CO₂还给本世纪空气；在1,000米处呼吸就锁定一千年——2010年代的"封存深度"框架和**Sarmiento、Kwon与普林斯顿学派**的"每硝盐的溶解无机碳"账目）也是一个**压舱问题**（**Armstrong、Lee和Hedges**压舱假说，2001：碳酸钙和蛋白石壳给能沉到底的有机质加载重，这就是为什么到深处的碳通量追踪**碳酸盐与蛋白石甚于表层生产**——这个机制让"球石藻水华封存碳"的故事出错，因为钙化本身**释放**CO₂：$\mathrm{Ca^{2+} + 2HCO_3^- \rightarrow CaCO_3 + CO_2 + H_2O}$，**碳酸盐反泵**让一个碱度受限的海洋在造壳时变成更差的汇）。两泵的联合产品是冰期记录的头奖：**冰期低约15–20%的CO₂**（冰芯）现在由**Marchitto、Sigman与冰期铁学派**归因于一个联盟——南大洋层结增强与铁施肥的输出（**Martin铁假说**、1993年失败的IronEx-I与1995年成功的IronEx-II、其后的八次施肥实验证明了水华但大多**没证明封存**——**Smetacek与LOHAFEX**的教训是羽纹硅藻水华被浅层捕食呼吸掉，而冰期的硅藻与通量闸（**Owen及其同事**2017年南极沉积物岩芯综合：海冰驱动的"通量闸"改变了输出被埋藏的位置）在起作用），加上**大西洋翻转环流的重排**把海洋碳存量搬到南方和深处（**Sigman与"生产力与层结"的冰期CO₂争论**）。现代的问题就是反过来的同一联盟：2020年代观测到的**中光层群落变浅与输出效率减弱**（**BATS和HOT**时间序列的30年记录、**Nowicki等2022年"全球海洋生物泵"收支**——全球海洋生物地球化学阵列约10 GtC yr⁻¹的估计及其两倍误差棒）是泵对增温的响应，而其符号——更暖的海洋是否因为泵变浅、层结让通风变慢而持有更少的碳——是本世纪碳预测中最大的单项不确定性。
:::

::: example 泵的深度折扣 {#ex-pump-depth}
混合层之下的输出生产约10 GtC yr⁻¹，随深度按Martin幂律$F(z) = F_{100}(z/100)^{-2.5}$衰减，$z$为米。求到达1,000米的通量占表层输出的百分比，并解释为什么同样10 GtC yr⁻¹的输出可以是强碳汇也可以是弱碳汇，取决于它在**哪里**被呼吸。
::: solution
$F(1000)/F(100) = (10)^{-2.5} = 0.32\%$——千分之三的输活在千年尺度的深度，其余被呼吸进本世纪的空气；泵的汇强因此**不是输出速率而是再矿化的深度分布**：浅层呼吸（暖、浅群落、低压舱的制度——模型预测的未来），同样的输出几乎不扰动表层；深处呼吸（冷、压舱、硅藻水华的制度——冰期南大洋），它值几十ppm。这个练习就是一次铁施肥争论的全部在一个指数里：实验养大了分子；海洋把它花在了错误的深度。
:::
:::

## 阶梯、上升流与硅道

::: definition 营养盐阶梯、上升流引擎与硅循环 {#def-nutrient-staircase}
深海是一座**营养盐阶梯**——磷酸盐与硝酸盐从北大西洋的约0（新通风水体的贫瘠，被北大西洋水华剥走、并在特提斯关闭时随沉积物失去，**Tyrrell与"高磷损失学派"**的"大西洋贫瘠与大西洋N:P之争"） 爬升到北太平洋深海的36 µmol kg⁻¹磷酸盐（一个世纪的Redfield呼吸沿全球传送带积累）——而表层海洋的肥力地图就是阶梯的影子：**上升流**（东边界流——秘鲁、本格拉、加利福尼亚、加那利——埃克曼输运把表层水走离岸边、阶梯水涌上；赤道辐散；温带陆架的季节性水华）聚集了海洋的渔业（四个东边界系统以百分之几的面积供应四分之一的渔获）和其硝酸盐，而副热带环流在再生、淋失的表层上挨饿。**硅循环**用自己的物理跑同一套管道：**硅藻**建造快速下沉的蛋白石（$\mathrm{SiO_2\cdot nH_2O}$）壳（春季水华的"脉冲"沉降喂养深海食物网，以及**Tréguer及其同事**2018年全球硅循环综合的修正：深海约100 µM的溶解硅存量、"硅泄漏"假说即晚始新世-中新世硅藻演化**把海水硅从巨型生物水平抽低到今日的稀缺**，改组了整片海洋的营养盐场），而因为硅藻输出**优先硅化且快沉**，一个海区的硅藻-球石藻比预测其碳转移效率——**群落结构控制泵学派——Follows、Dutkiewicz与MIT生态系统模型学派的"变暖、变浅、小细胞海洋"预测——**——2020年代赤道与亚极系统硅藻份额下降的卫星与中宇宙证据，以及渔业与碳的双重后果。阶梯也是**氧账本**的另一面：建造营养盐阶梯的同一呼吸**消耗氧气**（造出200–1,000米氧最低区的氧利用，以及**Stramma及其同事**的脱氧综合——全球海洋自1960年以来失去了**约2%的氧**、氧最低区垂直扩张了几十米、向赤道扩张了几百公里，而扩张的低氧区的反硝化与氧化亚氮释放是**对氮供应和气候的负反馈**（**Deutsch与"氧与反硝化"学派**的氮循环进一步收紧预测）。阶梯、泵和氧账本是一台机器，而机器的三个刻度盘——温度、环流、群落结构——正在同时被拧动。
:::

::: example 读阶梯 {#ex-staircase}
深水样本：北大西洋深层水磷酸盐1.6 µM，北太平洋深海2.6 µM。求沿传送带添加的再生磷酸盐、其代表的再生碳（Redfield），并解释为什么北太平洋表层若不是头顶约1公里厚的温暖层结水障本应肥沃。
::: solution
再生P$= 1.0$ µM，再生C$= 106$ µM $= 1.06$ mmol kg⁻¹——一整个全球传送带环流的大西洋源水呼吸的积累，约占深海DIC存量的10%；北太平洋是海洋**焊死了门的营养仓库**（层结表层把阶梯的财富挡在阳光之外），而那扇门的开合——俯冲、混合、把硝酸盐漏进环流的涡——设定了生物泵的全球上限：这个练习就是为什么"上升流区与高营养盐低叶绿素海"是海洋碳与食物未来真正被谈判的地方。
:::
:::

## 通风、氧与海岸

::: definition 通风年龄、氧收支与大陆边缘 {#def-ventilation-margin}
深海的化学是**一只钟和一场燃烧**：水在高纬度下沉区离开表层（通风）——拉布拉多海与北欧海、南大洋——携带接近100%的氧饱和度和一只由瞬时示踪剂设定的"钟"（氟氯烃与六氟化硫年龄、**TOGA和WOCE**时代及其后继者的氚-氦计时器），而下沉颗粒通量的群落呼吸随后按Redfield比**烧氧加营养**——所以氧、营养盐和示踪年龄是同一个场的三种读法（**Gruber**的"氧、营养盐与年龄"分解：脱氧分为**热力**溶解度损失、**环流**变化与**生物化学**增强，2019年的*Science*综合把一个2%的头条变成一份诊断：开阔洋趋势约三分之一是生物的，其余是物理的）。**大陆边缘**是这些账本与人类账本相遇之处：**海岸上升流**把已经贫氧富碳的阶梯水带到表层——喂养加利福尼亚和洪堡渔业的同一股水携带着**腐蚀性的碳酸盐化学**（上升流季变浅到贝类床的文石饱和、2007与2009年华盛顿和俄勒冈的孵化场事件、**Feely与美国西海岸**的海洋酸化调查），而边缘的**季节泵**（富营养陆架的夏季层结在缺氧呼吸源之上放了一个表层碱性汇——**Borges和Cai学派**的"陆架碳汇"之争，其决议——**计入富营养化时陆架是CO₂净源，只算物理泵时是弱汇**——是海岸碳循环的停战协定）。边缘也是**甲烷与硫化前沿**：陆架陆坡沉积物的产甲烷菌与厌氧甲烷氧化菌（**Boetius学派**的冷泉群落、在甲烷逃逸前开采它的硫酸盐-甲烷转换带）、水合物存量（一至四千亿吨碳以笼形物存在，只在边缘的温度-压力窗口内稳定），以及**麻坑与泥火山渗漏**，其2020年代声学与同位素调查（斯瓦尔巴与西伯利亚陆架研究）发现当前泄漏**小而随浅层沉积物变暖在加速**——海洋自己的慢碳炸弹，其引信与本课其他一切是同一个温度刻度盘。
:::

::: example 三向氧诊断 {#ex-gruber}
一个开阔洋水团显示氧以每十年2 µmol kg⁻¹下降。溶解度（热力）项占−0.7，环流（通风年龄）项占−0.5，其余归生物呼吸。求生物份额（百分比），并用一句话解释为什么生物部分按单位增温**最**令人不安、而就可逆性**最不**令人不安。
::: solution
生物份额$= (2-0.7-0.5)/2 = 40\%$——随温度和颗粒通量上升而增强的呼吸；按单位增温令人不安是因为它把氧损失与表层生态系统**耦合**（自我强化环：更暖更产的表层、更多燃料、更少氧、更多反硝化与N₂O），而对可逆性最不令人不安因为它是**快化学**——让水柱冷却、让通量慢下来，呼吸项几十年就松弛，不像锁定在百年海洋惯性上的热力与环流项。
:::
:::

::: definition 海岸碳停战与陆架的双式记账 {#def-shelf-carbon}
大陆陆架——海洋面积的8%、其一半初级生产与其大部分渔业，1990年代之前干脆**被全球碳收支漏掉**——跑着两本重叠的账。**物理-热力账**：陆架水冷却、吸收CO₂、并在俯冲或混合时把碳侧向输出到内部（**Liu与"陆架脱气"**账目的"陆架泵"——工业化前基线中陆架作为约0.2–0.3 GtC yr⁻¹的净汇）；**呼吸账**：富营养化与上升流添加营养盐和再呼吸碳，富营养系统的夏季缺氧让陆架表层pCO₂上升（**Borges和Cai**之争的决议：**面向开阔洋的陆架的人为扰动接近中性到弱脱气**，而**海陆界面**——河流、河口、沉积物——处理约1 GtC yr⁻¹的侧向碳吞吐，一半来自氮磷两课里农业自己侵蚀的老土壤碳）。这本账两次要紧：对**碳收支**（陆架约0.2 GtC yr⁻¹的人为汇占海洋总汇的五分之一、也是对富营养化与环流未来最敏感的项），以及对**生物**（上升流腐蚀与季节缺氧循环让贝类产业现在做业务预报——NOAA西海岸海洋酸化浮标网、孵化场pH警报——本课的生物地球化学以商业信号抵达）。
:::

::: example 陆架的两本账 {#ex-shelf-books}
一个温带陆架接收0.9 GtC yr⁻¹的河流与侵蚀老碳，在其沉积物中埋藏0.25 GtC yr⁻¹，其表层水把老碳呼吸CO₂中的0.5 GtC yr⁻¹脱出。求老碳项的净大气贡献，并解释为什么同一个陆架可以同时被记为**大气的碳汇**和**大气的碳源**。
::: solution
老碳净贡献$= 0.5 - 0.25 = 0.25$ GtC yr⁻¹脱出（河流送来的陆地碳之呼吸减埋藏）；陆架对**人为与物理泵项是汇**（其冷却的水吸收现代CO₂），而对**侧向老碳项是源**（腹地农场的侵蚀土壤碳、**Marland与"缺失碳"**的侧向通量账）——只有两本账都记才闭合，这就是海岸碳循环的复式记账课，也是"海洋汇"是**四本账之和**（物理、生物、侧向、河流）、各有其驱动和未来的原因。
:::
:::

五个错误。**"施肥海洋，泵就解决排放"**：八次原位铁实验（IronEx-II到LOHAFEX，1995–2009）证实了Martin的水华生理学并驳倒了封存论——水华的碳在浅层被呼吸（LOHAFEX的羽纹硅藻几周内被吃光）、海气CO₂响应只是承诺的一个分数、**持久性**（深埋份额）约0.1%、而副作用（中层水耗氧、氧化亚氮伴生——给氮受限海洋施肥会排放273倍的气体）如今是条约级的反对（伦敦公约2008–10年科学家小组结论与CBD的暂停）；诚实的残余是**海洋自己的铁经济至今仍是冰期CO₂的玩家**——人工施肥不是同一个实验。**"海洋大就会继续吸收我们的碳"**：大小不是意愿——Revelle因子（carbon-today一课）、通风的层结减速（人为碳的俯冲在模型和重复断面趋势中**已经开始落后于排放**）、泵的变浅，是分数吸收下降的三种方式；海洋约26%的份额是一个**瞬态不平衡**，而2020年代某些海盆通风年龄趋势的观测减速是第一座瞭望塔的信号。**"脱氧是地方性、可管理的"**：2%的全球损失**不是**地方的——它是氧最低区扩张的总和，压缩金枪鱼和乌贼的栖息地（**Breitburg与"下降的氧"**的*Science*综述之渔业与死区综合）、让氧化亚氮与氮损失反馈翻倍、而在海岸版本上让富营养陆架硫化（phosphorus-sulfur一课的硫化物连续体）；通风一慢，氧是唯一**没有快非生物来源**的量，而唯一的修复是两个上游刻度盘：增温和营养盐。**"硅和碳酸盐循环是专家的事务"**：硅藻-球石藻比设定**输出效率与碱度泵**（碳酸盐反泵的CO₂释放意味着同等输出下更钙化的海洋是**更差**的汇——**Ridgwell与"钙质浮游生物与CO₂"**建模谱系）、新生代的硅抽低改组了海洋整个营养盐场（**Tréguer"硅泄漏"**论点：今日的硅藻就是海洋贫铁贫硅而中生代海不是的原因），而2020年代水坝背后河口硅截留的损失（**Tréguer与"河流硅与水坝"**账目）已经威胁海岸硅藻生产——专家的事务就是系统的刻度盘。**还有"营养盐阶梯是永久特征"**：阶梯是一个**环流产品**——其太平洋-大西洋对比是传送带年龄效应，古记录显示它会重排（冰期大西洋更深更富营养的温跃层、**Sikes与"冰期大西洋营养"学派**的烯酮与有孔虫记录；特提斯关闭造成的非洲干旱与磷损失）——而21世纪AMOC减速情景预测**变浅的大西洋营养盐阶梯与重组的热带上升流**，也就是说：世界一半渔业的肥料和泵的底座，与欧洲气候在同一条环流生命维持系统上，而两者都被同一股淡水扼着。
:::

::: history
海洋生物地球化学的谱系始于**挑战者号**与**瓦迪维亚号**深海调查（1870–90年代，第一批营养盐与碳酸盐断面）、**Alfred Redfield**1934年的比值与**Dana号**考察的营养地理，以及**George Clarke与伍兹霍尔学派**的深层散射层与马尾藻工作。泵的时代：**Dugdale和Goering**的硝酸盐吸收法（1967，新生产对再生生产）、**John Rodhe**1963年的沉积物捕获器颗粒通量（对下沉世界的第一次测量）、**Parr与GESECS**全球断面（1970年代，示踪地理）、**McAllister**关于生物泵的Sverdrup纪念讲座（1969–72，概念的命名）、**US-JGOFS时间序列研究**双生子——**BATS**（1988）与**HOT**（1989），现存最长的两条生物地球化学时间序列——以及**US-JGOFS与SOLAS**过程计划。铁革命：**John Martin、Fitzwater和Gordon**1990年的铁限制论文与Martin1994年的"半油轮"发言、**IronEx I-II**航次（1993、1995——配体教训与水华）、**SOIREE、SEEDS、Eisen、LOHAFEX与CROFEX**一代（2000年代，封存的判决），以及**GEOTRACES**铁与同位素调查（2010年至今）。现代综合：**Volk和Hoffert**1985年的泵深度理论、**Sarmiento和Gruber**的碳-硝盐账目与**普林斯顿"每硝盐溶解无机碳"**学派、**Armstrong、Lee和Hedges**压舱假说（2001）、**Martin等**1987年衰减幂律、**Stramma、Breitburg、Deutsch与脱氧综合**（2010年代）、**Tréguer与全球硅循环修正**（2016–2018）、**Owen及其同事**的南极通量闸综合（2017），以及**全球海洋生物地球化学阵列与BGC-Argo**时代（2010–2020年代）——浮标网现在每年送回约20万条生物地球化学剖面，是史上建成的最大生物地球化学观测系统，其头十年的判决是：泵是真实的、可测的，而且**在其边缘正在减弱**。
:::

::: quiz
在表层海洋制造碳酸钙壳对CO₂的作用是：
- [ ] 抽低大气CO₂，因为壳是固体碳。
- [x] 释放CO₂，因为碳酸盐的形成把两个碳酸氢根变成一个碳酸根加一个CO₂。
- [ ] 对CO₂没有影响。
- [ ] 增加碱度。
::: solution
碳酸盐反泵：$\mathrm{Ca^{2+} + 2HCO_3^- \rightarrow CaCO_3 + CO_2 + H_2O}$——钙化降低碱度、抬高表层pCO₂，这就是"更多球石藻、更多封存"不成立的原因，也是为什么压舱（壳在把有机碳**运输**到深处的帮助）是碳酸盐循环唯一的碳封存服务。
:::
:::

::: summary
海洋的碳被两台泵按在黑暗里：冷俯冲的溶解度泵（人为碳的第一居所，约175 GtC且在增长）与新生产和下沉颗粒的生物泵（输出约10 GtC yr⁻¹、埋藏千分之三、其余在深处被呼吸——既喂养氧最低区、又让大气CO₂低于其平衡值约100 ppm）。泵靠营养盐阶梯运转——一个环流产品、太平洋仓库最富、由上升流送到表层、由重力送到深处——硅和碳酸盐是决定多少碳逃出微光带的压舱物。人为扰动在每个刻度盘上都可读：增温层结让通风变慢、泵在变浅、氧降2%且最低区在扩张、硅藻份额在下降、铁施肥的逃生舱被它自己的实验关死。随着本世纪推进，海洋将继续以更慢的速度拿走我们的碳；"更慢"的大小就是各预测之间的差别，而它正在被浮标、断面和捕获器测量——海洋学史上最大的观测实验。
:::
