一撮草原土壤里的活物比地球上的人还多，装着整个生物圈三分之一的陆地碳，而——被犁开之后——装着一个文明选择的记忆。**土壤**是关键带的反应器：地球最薄的储库（全球耕层比一个街区的宽度还薄）替整个表层系统做风化、分解、供养分和滤水的化学工作，由**Hans Jenny**的五个因子用数千年建成、几十年毁掉。**湿地**是土壤的极端一章：3–4%被淹的陆地，腐烂在那里被制止，建成了泥炭档案、三分之一的土壤碳，而——被排干之后——以五十分之一的领土贡献了人类排放的百分之五。本课就是把大地本身当作一台生物地球化学引擎：土壤反应器及其碳记账、湿地的另类代谢，以及那层让陆地宜居的、正在侵蚀、碳已饱和、政治上正在抬头的薄皮。

## 土壤反应器

::: definition Jenny的机器：成土、结构与两个碳库 {#def-soil-reactor}
土壤就是**成土作用**——**Vasily Dokuchaev**1883年的洞见：土壤不是岩石而是带发生层的**自然体**，以及**Hans Jenny**1941年的公式$S = f(\mathrm{climate, organisms, relief, parent\ material, time})$——一台状态-通量机器，其速率常数是生物与气候：原生矿物的风化、蚯蚓与根的搅拌（**达尔文**1881年的《植物与腐殖土》（*Vegetable Mould*），把蚯蚓量化为地质营力的第一次，现在测得好牧场上每年10–20 t ha⁻¹经肠道转运的土壤），以及有机质在上部发生层的积累。机器的产品**土壤有机质**不再被教授为"腐殖质，一种稳定的焦油"，而是**两个物理不同的功能库**：**颗粒有机质**（碎屑与根凋落物，快，几十年，农民的肥力库）与**矿物结合有机质**（**MAOM组分**——微生物残体与聚合物吸附在黏土上、封在团聚体里，矿物每千克几克的浓度，被保护直到矿物表面饱和或团聚体破裂），以及**饱和概念**（**Stewart、Six、Conant和Paustian**2007年的发现：许多土壤已接近其碳上限——你无法向一块饱和的海绵"封存"，这个结论约束了每一句农业碳口号）。全球存量：2–3米的土壤有机碳**约1,500–2,400 GtC**（计数取决于深度与岩碳，2010年代的争论），其中**一半到三分之二在30厘米以下**——深的、老的、矿物保护的大多数，在耕作想象之外——而整个储库以年到千年的平均周转，一个双峰分布，是土壤同时握住当季肥力与千年资本的方式。反应器的服务就是本课的账：**过滤与水量调节**（土壤的下渗工作造成洪水与回补之别——纽约、柏林、哥本哈根水务的自然基础设施算术，他们发现保护高地土壤比过滤厂便宜）、**供养分**（阳离子交换与菌根经济——**丛枝菌根网络**以碳过路费供应多数陆生植物的磷，**Smith和Read**的生理学）、以及**种子与档案功能**（种子库、花粉与DNA档案让土壤成为古生态学家的书、现在正从土壤和永久冻土读取的古代DNA与沉积物DNA档案）。反应器的脆弱是算术：**成土每年造0.1–1毫米土壤**（一个犁耕寿命的发生层），所以**现代耕地侵蚀对土壤产量的2–10倍超额**（美国国家科学院2017年评估的5–10倍、欧洲**Panagos**调查的2.5 t ha⁻¹ yr⁻¹对约其十分之一的产量）不是可持续性辩论，而是**对土壤本身的采矿**——1930年代的黑风暴第一次工业规模的演示，而2015年**国际土壤年**与FAO的现状报告正式承认世界三分之一的土壤已退化（**Oldeman**1990年的地图、2015年的更新），因侵蚀、压实、盐渍、酸化、覆盖封闭与碳损失（森林转耕地随之而来的**约40%表土碳损失**，**Guo和Gifford**荟萃分析——继大气之后陆地循环第二大的扰动）。
:::

::: example 犁的算术 {#ex-soil-time}
耕地侵蚀以10 t ha⁻¹ yr⁻¹进行，而土壤产量为0.1 mm yr⁻¹（容重1.3 t m⁻³）。求年侵蚀深度（mm）、这块地的"土壤寿命"（蚀穿30厘米发生层的年数），并用一句话解释为什么2017年美国评估"5–10倍不可持续"的判词是关于千年而非十年的。
::: solution
侵蚀深度$= 10/(1.3\times100) \approx 0.077$ cm $= 0.77$ mm yr⁻¹——产量的八倍；30厘米的发生层以此速撑$300/0.77 \approx 390$年，而农业继承的是约1万年的发生层；判词关乎千年，是因为文明不在最后一粒沙离开田地时终结，而在**剖面的水与养分容量**终结时（美国南部与欧洲侵蚀土壤的产量下降曲线、**Montgomery**《土》（*Dirt*）的论点：农业史就是一部土壤采矿史，化肥是临时的输血），也因为以0.1 mm yr⁻¹的产量，每失去一毫米就是十年被预支的遗产。
:::
:::

## 湿地：没有腐烂的世界

::: definition 淹水代谢：泥炭、甲烷，以及蓝碳表亲 {#def-wetlands}
淹了土壤，氧化还原级联就短路：氧气几天内没了，硝盐和锰铁氧化物在几个季节内耗尽，而末端电子受体变成**二氧化碳本身**——产甲烷——所以湿地以比排干土壤**慢一到两个数量级**的速度跑分解引擎，并用**甲烷**支付差额（自然湿地约150–200 Tg CH₄ yr⁻¹，生物圈最大的天然温室气体源，其一半来自北方泥炭与冻原系统，其产甲烷菌与甲烷氧化菌在气泡与氧化之间分摊）。这笔交易就是湿地的契约：**碳以泥炭留存，以甲烷计费**——一个在千年上气候为正的契约（泥炭地是净冷却系统，其全新世约0.1 GtC yr⁻¹的碳汇是全新世CO₂下降背后的慢减法），而**被排水灾难性地反转**——**Joosten、Page及其同事**的排干泥炭地账目：排干泥炭地——世界土地的3%，印度尼西亚和欧盟泥炭的一半——以每年1–2毫米的地面沉降氧化其泥炭，以印度大小的面积排放**约2 Gt CO₂ yr⁻¹、占全部人为排放约5–6%**；印尼与马来西亚泥炭沼泽林为纸浆与棕榈的排水，其1997和2015年火季把十亿吨CO₂和东南亚最重的霾送进大气，而其2016年后的恢复计划（印尼泥炭地恢复局、堵渠复湿的流域）是地球上最大的泥炭-气候工程。**北方沼泽**——加拿大、西伯利亚和斯堪的纳维亚系统，由**Charman**泥炭档案学派和**Turetsky、Treat与永久冻土-泥炭**碳学派研究——添上本世纪的悬念：其当前的汇（每年几百Tg C的总积累、净约0.1 GtC）正被排水、火灾和永久冻土融塌蚕食（**Turetsky、Schuur与"北方碳"文献**的警告：永久冻土-泥炭系统本世纪可能从汇翻转为源），而CO₂与氮施肥努力让它们保持为汇——**Wieder、Vitt与Turetsky**综合的诚实回答是"仍是汇，正在减弱，由火季裁决"。**蓝碳**表亲——红树林、盐沼与海草——在盐下跑同一套淹水化学：其沉积物以**森林土壤3–5倍的密度**埋碳（**Donato、Kauffman、Nellemann、Mcleod与海岸碳**存量清单），以大陆架一小条持有海洋碳埋藏的约7–15%，而其丧失（1980年以来三分之一的红树林，**Valiela与Duke**的保护审计）把碳汇变成排放，并移除了风暴消减、育苗场与过滤服务——正是这些服务让保护它们成为教科书的自然基础设施案例。2020年代的湿地政策转折——**2022年联合国环境大会的可持续泥炭地决议**、欧盟有争议的泥炭-气候农业规则、塞舌尔、苏里南和孙德尔本斯的自愿蓝碳信用，以及**泥炭地湿地农耕**（paludiculture，用芦苇、泥炭藓和苔草耕作保持水位、留住碳的湿地农业）——让本课成为地球上每公顷碳效益最高的干预所在：复湿一块排干的泥炭地，以每公顷几千美元的成本止住30 t CO₂ ha⁻¹ yr⁻¹的排放，是整个减排组合里最便宜的一吨，也是最缺融资的一吨。
:::

::: example 泥炭地的两本账 {#ex-peat-ledger}
一块排干的泥炭草地排放30 t CO₂ ha⁻¹ yr⁻¹（氧化加沟渠氧化亚氮，排水沉降15 mm yr⁻¹）；复湿后成为0.5 t C ha⁻¹ yr⁻¹的泥炭汇，但排放20 kg CH₄ ha⁻¹ yr⁻¹。用百年CH₄乘数30（质量基准），求复湿的净气候摆动（t CO₂e ha⁻¹ yr⁻¹）。
::: solution
复湿平衡$= -0.5\times3.67 + 0.02\times30 = -1.8 + 0.6 = -1.2$ t CO₂e ha⁻¹ yr⁻¹（一个汇），对排干的$+30$ t CO₂e：摆动是**约31 t CO₂e ha⁻¹ yr⁻¹**，改变一个水位带来的25倍气候翻转——这个练习就是为什么泥炭复湿在每一张边际减排地图上居首、为什么甲烷计费（那个0.6）相对止住的氧化（那个30）只是舍入误差、而障碍是土地权属、农民补偿和二十年的草到苔的演替，不是碳算术。
:::
:::

## 土壤的水铺与气铺

::: definition 土壤作为水利工程与气体工厂 {#def-soil-water-gas}
碳之外，土壤还跑着两项其经济价值远超其自身价值的服务。**蓄水**：颗粒之间的孔隙抗重力储存雨水——**植物有效水容量**（田间持水量减凋萎系数，壤土典型为体积的10–20%，黏土持得太紧、沙土漏得太松都更低）是每一场雨养收成和每一场干旱第一个牺牲者背后的水库：一米壤土持有约150–200毫米有效水，所以本季降雨**经土壤库放大**才是世界一半食物的真正灌溉系统，而其管理（覆盖、残茬、绿肥、有机质造团聚）是发明过的最便宜的干旱保险——同一个库一旦灌满溢出，就是带走氮一课之磷与泥沙的径流，所以**土壤是没人付款、坏了才想起的防洪基础设施**。**气体工厂**：持水的同一批孔隙也持氧，而其充水比例设定氧化还原开关——干土里让氮对植物可用的硝化、湿了就以后作N₂和N₂O失去它的反硝化、稻田的甲烷工厂（淹水季的源、减半它的季中排水做法），以及施肥、湿润、耕作土壤的氧化亚氮峰值（2010年代的"N₂O热时刻与热点"文献：降雨与施肥后几天供应了年通量的大部分，来自田地百分之几的面积——这个观察让减排文献转向受控脉冲）。土壤的水铺与气铺也是它的**气候接口**：土壤水分的记忆（数周的持续性让春季水分成为夏季对流与洪水的预报因子、**Eltahir和Findell**学派的陆气耦合（毁林-季风论点）与变干-高温反馈（2003和2010年热浪的土壤水分先决条件、**Seneviratne**的土壤水分-热浪综合）让包气带成为每一次极端高温与干旱归因中的具名角色。
:::

::: example 土壤的水库 {#ex-paw}
一块壤土田间持水20%、凋萎点8%；根深0.8米。求植物有效水深（mm）；对一个雨养玉米季、季内降雨450 mm、季需水520 mm，用两句话解释为什么决定产量的是土壤水库而不是雨量计，以及2022年非洲之角和2010年俄罗斯案例在水库播种时已空的情形下展示了什么。
::: solution
有效水$=(0.20-0.08)\times800$ mm当数$= 96$ mm——**季需水约五分之一在降雨落下之前已入库**；雨量计数的是通量而作物花的是存量，所以空库上的正常季会歉收、满库上的差季能挺过去（俄罗斯和美国的农业部门正是因此发布播种前土壤水分预报），而2010和2022案例——一个没能灌满剖面的干秋、然后一个把余水抽干的干热之春——是水库的负年，是归因文献中让那两场热浪烈度翻倍土壤水分先决条件。
:::
:::

## 泥炭作为档案，与我们烧的泥炭

::: definition 泥炭档案与花盆里的泥炭 {#def-peat-archive}
泥炭是**分层的记忆**：沼泽表面每一年的毫米级生长加约0.3–0.5毫米腐解凋落物，锁住花粉与孢子（**Lindqvist与欧洲花粉雨**的定量温度重建）、壳虫与硅藻（**Charman、Booth与泥炭水文**学派定量全新世记录的水位代用指标）、大气汞与铅、以及**格陵兰与泥炭档案的硫铅同位素曲线**（罗马与冶炼污染层）、火山灰（年代锚点），以及泥炭自身的碳（放射性碳与逐层年代模型）。**来自泥炭的全新世温度与水文气候重建**（欧洲与加拿大沼泽、**Charman、Booth与欧洲泥炭古水文综合**）在大陆中纬度已与冰和湖记录分庭抗礼，且有一个独特的优势：**连续、厘米年代际的分辨率，无需钻探远征——沼泽就是档案，取芯器是一把园艺铲**。商品面就是本课的反讽：**花盆里的泥炭是同一份档案，被开采**——园艺泥炭产业（爱尔兰与波罗的海的沼泽、英国2022年园艺中心停用辩论、爱尔兰采泥炭退出及其2021年政治解决方案、德国与荷兰的恢复对园艺之争）以厘米速率收获一个**0.5 mm yr⁻¹的资源**，把千年的碳在园艺季里释放——英国的园艺泥炭账目让每年5,100万升的园艺泥炭成为一场排放小而象征大的战斗，而**泥炭藓种植与湿地农耕**替代方案（德国与丹麦的泥炭藓种植试验）是档案唯一可持续的收获：种出产品、留下矿体——而2020年代最优雅的碳事实是——一个采过又恢复的沼泽十年内回到汇，而农夫的作物是系统中唯一会重长的部分。
:::

::: example 沼泽的钟 {#ex-peat-clock}
一个北方沼泽以40 g干物质 m⁻² yr⁻¹积累泥炭（约一半是碳，容重100 kg m⁻³）。求垂直积累率（mm yr⁻¹）和建成4米矿体所需时间，并解释为什么泥炭的碳积累率（典型15–25 g C m⁻² yr⁻¹）让沼泽成为地球上最慢也最高效的碳技术。
::: solution
质量到深度：$40\ \mathrm{g\,m^{-2}} / (100\ \mathrm{kg\,m^{-3}}\times10^3\ \mathrm{g\,kg^{-1}}) = 4\times10^{-4}$ m $= 0.4$ mm yr⁻¹；4米矿体要$4{,}000/0.4 = 10{,}000$年——一个全新世的工程，整个保护论点就在这次除法里：存500 t C ha⁻¹的沼泽以20 g C m⁻² yr⁻¹花了十个千年（长期单位面积上没有任何森林接近这个速率，因为森林呼吸掉自己的碳而沼泽**留着**它的），而排水以3,000 g CO₂ m⁻² yr⁻¹销账——技术速率与其毁灭之间**150倍**的不对称。
:::
:::

五个错误。**"培育土壤碳，问题就解决了"**：饱和文献（**Stewart-Six-Conant**上限、FACE与长期小区证明MAOM库填满即停的证据）、逆转风险（土壤的碳是**微生物处的贷款，被耕作、排水或增温收回——40%的垦殖损失就是可逆性的证明**），以及氮约束（额外的碳每吨需要约20 kg N，其化学计量的氮成本让"土壤碳吸收全部排放"成为跑赢哈伯-博施预算的算术）至多把口号约束到其承诺的五分之一——真实、只在尊重水位与犁时持久，而永远不是减排的替代。**"排干泥炭一年就能复湿回汇"**：复湿在几年内止住氧化（CO₂的胜利很快），但**甲烷计费以十年时标抵达、沉降史是永久的（失去的15 mm yr⁻¹永不回来）、植被需要一代人重建造泥炭群落，而最初的复湿CH₄"爆发"可能让头十年净增温**（芬兰与德国复湿实验的复湿瞬态文献）——诚实的账目是数十年的、因地而异的、而且仍然压倒性为正，但"拧开关"的框架注定了政策的失望。**"侵蚀是农事问题，不是碳问题"**：侵蚀的碳（**Van Oost和Six**的沉积物通量发现：耕作侵蚀本身是一个约0.6 GtC yr⁻¹的碳汇——埋在山坡与水库里，一个**偶然的、漏的、花氮的**汇，沉积物文献把它记在土地利用变化收支的贷方）表明两者是一本账，而"解决"碳输出的水库淤积把洪水与营养问题送到了下游。**"永久冻土碳反正会丢，保护它干什么"**：永久冻土一课的突发融塌算术（热喀斯特的甲烷份额、渐进变干模型隐藏的几十年提前量）说**速率与气体**都是政策变量，而雅冰与泥炭系统是陆地上密度最高、最易燃的碳库——保护它们（火管理、工业选址政策，而最重要的是排放路径）是保护一个一旦融化就是任何适应都追不上的百年排放的储库。**还有"土壤退化靠技术可逆"**：有效的逆转（施灰、梯田、免耕、复湿）便宜而且是生物的；失败的逆转是把土壤当工程基质的那些（采矿与城市扩张的下部压实与表土剥离"复垦"、灌溉美索不达米亚的盐渍化——史上最大的土壤死亡事件、**Jacobsen和Adams**的考古论点：盐壳终结了苏美尔的小麦）——土壤是一个按生物时间恢复的活系统，每个忘记这一事实的文明都按同一张时间表付账。
:::

::: history
土壤科学的奠基之举是**Vasily Dokuchaev**1883年的《成土理论概论》（*Essay on the Theory of Soil Formation*，俄罗斯草原断面、土壤作为自然体），由**Hans Jenny**的《土壤形成的因素》（*Factors of Soil Formation*，1941，那个公式与伯克利学派）和**G.N. Robinson**的《土壤的塑造》（*Soil in the Making*，1922）形式化，并由美国土壤调查局用一个世纪测绘成《土壤系统分类》（1975）。反应器的生态学：**达尔文**的《腐殖土的形成与蚯蚓的作用》（1881）；**Rothamsted Park Grass**实验（1856年至今，现存最长的生态实验，其小区首次测量了垦殖的碳抽走）；**Jenny和Olson**的全球碳存量清单（1960–70年代）；**Parton与CENTURY**建模学派（1980年代至今）；以及2010年代的稳定性革命——**Liang、Schimel和Jia**的微生物碳泵（2017）、**Schimel和Liang**学派的残体账目、以及**Stewart、Six、Conant和Paustian**（2007）的碳饱和实验。侵蚀的政治：**黑风暴**与1935年土壤保护局（**Lowdermilk和Hugh Hammond Bennett**的保护回应——Bennett1933年创立美国保护政策的通告）、**Lowdermilk**的《土壤上的世界》（*World on Soils*，1953，第一次全球退化审计）、**Oldeman**的世界退化地图（1990）、**FAO全球土壤伙伴关系与2015国际土壤年**，以及**2017年美国国家科学院**关于侵蚀不可持续性的报告。湿地一章：欧洲与西伯利亚沼泽数个世纪的排水；**Charman**的泥炭档案全新世科学；**Page、Baird、Joosten及其同事**的排干泥炭排放账目（把泥炭搬进气候谈判的2008年全球估计）；**Turetsky、Schuur与Wieder-Vitt**关于永久冻土-泥炭翻转的综合；**Donato、Kauffman、Nellemann和Mcleod**的蓝碳清单（2009–2014）；以及**2022年UNEA可持续泥炭地决议**——世界环境部长们第一次正式为水下的土地立法。
:::

::: quiz
最稳定的土壤碳最好描述为：
- [ ] 化学惰性的腐殖质。
- [x] 通过与矿物表面和团聚体结合而受保护的微生物残体。
- [ ] 仅木炭。
- [ ] 带木质素的根凋落物。
::: solution
MAOM/残体综合：持久性是**保护，不是抗腐性**——这就是为什么耕作和排水（打破团聚体、暴露表面）会快速失去老碳，也是为什么单靠"添加有机质"建不起持久碳，除非矿物表面和水位配合。

::: summary
土壤是Jenny的五因子机器：一层比街区宽度还薄的皮，以两个库持有陆地碳的一半到三分之二——快的颗粒质与慢的、接近饱和上限的矿物结合残体——并提供替换起来要花掉全世界全部研究预算的过滤、养分与水服务。它的威胁是算术：5–10倍于产量的侵蚀、垦殖的40%碳抽走、覆盖封闭、盐渍化、以及让腐烂快过根系的增温。湿地是淹水的替代方案：泥炭的慢账以甲烷计费、全新世安静的汇、以3%的土地被排干到人类排放的5%，而且可以恢复——以减排地图上每公顷和每美元最高的碳效益——靠水。蓝碳海岸在盐下跑同一套化学，正以红树林的速率失去。本课的政治就是2022年UNEA决议和农夫的水位：大地是人类最便宜的气候技术，也是它唯一一直在对着立法的。
:::
