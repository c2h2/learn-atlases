1909年，在卡尔斯鲁厄的一间实验室里，**Fritz Haber**把氮和氢压缩到200个大气压，走出来时带着一柱白色氨烟——第一次由人手从天上固定的氮。二十年内**Carl Bosch**把它放大到工厂规模，一个世纪之内，哈伯-博施法正在养活——直接或间接通过动物饲料——在世人口的约**一半**。本课就是那笔空前补贴之下的氮循环：让固定氮十亿年来成为多数陆地生态系统限制营养盐的生物学瓶颈、那个瓶颈的工业断裂、以及2008年**Galloway、Townsend、Erisman、Bekunda及其同事**综合命名为氮时代标志性环境挑战的**级联**后果——粮食安全、氧化亚氮、死区、失去的生物多样性、饮用水。碳的问题是废物处理问题；氮的问题是**收获问题**——我们拿过大气中最惰性的分子把它变成活性的，而随后的一切后果都由"活性正是目的"这一事实推出。

## 固定瓶颈

::: definition 氮为什么难，以及打破瓶颈花了什么 {#def-fixation}
大气78%是氮而生命吃不下它。N₂的**三键**（945 kJ mol⁻¹，常见生物化学里最强的键）让惰性成为常态，而生物圈的回答是**固氮酶**——固氮微生物的酶复合体（蓝细菌*Trichodesmium*和*Anabaena*、豆科根瘤中的根瘤菌、桤木根瘤中的弗兰克氏菌、白蚁肠道和稻田里的分解细菌），它以**每个还原的N₂花16个ATP**的代谢代价和一个怕氧的金属簇（铁钼辅因子，其稀缺就是为什么钼、以及在某些生境里的钒或朴素的铁共同限制固氮）强行让氮过关。工业化前的陆地收支：生物固固约130–190 Tg N yr⁻¹、闪电约5–10，而损失一侧——反硝化回N₂和N₂O——与之平衡，把生物圈留在大部分陆地上**氮受限**（豆科称霸肥沃斑块的原因、园丁轮作的原因、以及施加氮是地球上多数地方单产回报最高的单项农业干预的原因）。人类的断裂：**工业固氮现在以约120–150 Tg N yr⁻¹运转**（哈伯-博施工厂，世界能源的约1–2%），化石燃烧的NOₓ再加约20，耕作刺激更多固氮——所以**人类固定的氮现在等于或超过全部自然陆地固氮**，生物圈里的活性氮大致**翻倍**（Galloway和**Smil**的估计），而海洋自身的收支（海洋固氮约100–200 Tg N yr⁻¹，2000年代经固氮微生物修正的数字，此前**Hansell及其同事**的"固定比"论点指出旧收支低估了海洋固氮一半）现在也被同样频繁地过手。人类那一半的效率就是级联的源头：**作物只吸收化肥氮的约30–50%**（全球利用效率，漫灌稻田和沙土里更低），所以从空气中挖来的一切有一半以上以硝态淋失、氨挥发、NO和N₂O离开田地——逃逸的50–70%就是下一节每个条目的物理原因。本课的经济学框架（**Vaclav Smil**的算术）：没有合成氮，地球的耕地按1900年代的单产大约只能养活**40亿人，而不是按今天养活80亿**——诚实的表述是：按人口计数，哈伯-博施是二十世纪后果最重的技术，而它的账单自那以后一直分期送达。
:::

::: example 效率算术 {#ex-nue}
某区域施加1,000 Tg...用真实尺度：全球化肥用量约110 Tg N yr⁻¹、利用效率40%。求每年离开田地的氮；并以哈伯氮养活的人口约40亿、逃逸的化肥约66 Tg，说出让氮辩论无法以"化肥有罪"进行的两个数字。
::: solution
逃逸$= 110\times0.6 = 66$ Tg N yr⁻¹——一个与整个工业化前河流氮输出相当的通量，如今以淋滤液、气体和粉尘交付；辩论的两个数字是**40亿人**（哈伯氮在工业化前循环能养活之外支撑的人口）和**66 Tg**（补贴漏掉的部分）。每项氮政策都是对第二个数字、但必须尊重第一个数字的选择：人均化肥用量最低的国家既饥饿最多、又在发展中计划增幅最大——这就是为什么氮的未来写在撒哈拉以南非洲和南亚，而不是写在欧洲已经饱和的流域里。
:::
:::

## 级联

::: definition 氮级联及其六害 {#def-cascade}
**氮级联**（**Galloway-Townsend-Erisman-Bekunda**2008年综合，建立在**Hubbard Brook**研究——**Likens、Bormann及其同事**——的**氮饱和**概念和**Vitousek、Aber、Howarth及其同事**1997年综合之上）是一个活性氮原子依次穿过多个环境滤网的旅程——每次转移都比上一次的修复便宜、每害换一个介质——而其六项有据之害就是课程的应用大纲。**1. 氧化亚氮**：约4 Tg N yr⁻¹的人为N₂O（农业约60%，土壤里微生物对化肥的硝化与反硝化），一个**每吨世纪增温为CO₂的273倍**的温室气体，且自CFC禁令以来**剩余最主要的臭氧层破坏排放**（**Ravishankara**2009年的论点，*Science*论文，把N₂O从气候脚注搬上蒙特利尔议定书候选席）；大气N₂O已从270爬到**336 ppb**且在加速，而拟议的**N₂O议定书**（**Berner及其同事**，2019）——削减蛋白质废物流、给废水和化肥立标准——2015–2020年的排放本几乎可以减半——是没有任何国家采纳的最便宜的气候政策。**2. 淡水**：饮用水中的硝酸盐（50 mg L⁻¹标准的起源是**变性血红蛋白血症**——1940–60年代"蓝婴"的证据基础，以及2020年代重开的结直肠癌与早产流行病学，让爱荷华和中央谷地私人水井的硝酸盐成为活的公共卫生案件）；**3. 河口与海岸**：富营养化链条（营养盐 → 藻类 → 水变浑 → 沉降生物质 → 微生物需氧 → 缺氧与死区季——**Nixon**"海洋富营养化：定义与成因"综合、墨西哥湾15,000 km²的缺氧足迹其大小追踪密西西比流域的春雨与化肥销量、波罗的海几个世纪的缺氧、黑海1970–80年代的崩溃及其后苏联工业停用化肥后1990年代的部分恢复——氮政策中唯一一次大规模**自然实验**，而且它奏效了）；**4. 陆地生物多样性**：耐氮物种挤掉适应不良者（英国与荷兰草地氮沉降下兰科与地衣相的丧失、**Bobbink和Hicks**的临界负荷工作、欧洲和北美约60–90%的"特殊生境"点位现已氮超载、加州硬叶灌丛的雀麦入侵——驱动因素是**空气**的生物多样性丧失）；**5. 空气**：氨的细颗粒物化学（铵-硝酸盐与-硫酸盐气溶胶造出华北平原和波河谷的冬季霾，以及2019–2023年荷兰和爱尔兰围绕限畜的政治危机——第一批明确针对氮法组织的欧洲农民运动）；**6. 土壤**：酸化与此前受限系统的"氮饱和"（**Aber、Nordin和Gundersen**样地的透落硝泄漏、微生物吃饱后不再保氮的贫生物多样性森林土壤）。级联的政策教训是它的不对称：**氮在施加时便宜、在其后每个阶段去除都贵**（荷兰的粪肥权和德国地下水指令的修复账单、切萨皮克湾1,000亿美元以上的修复中氮是最大一项），而原子的**级联路径不可预测**——给玉米田施肥的那个原子，可能在三个流域之外的饲养场地下水羽流里以N₂O现身——这就是为什么唯一稳健的政策作用于**施加环节**，在那里一部法规一次给六害定价。
:::

::: example 死区的收支 {#ex-deadzone-budget}
密西西比流域每年向墨西哥湾输出约1.9 Tg（百万吨）总氮——约为1970年代负荷的两倍——而流域投入（化肥加粪肥加固氮）约6 Tg N yr⁻¹。求流域的田到河输出系数，并解释为什么墨西哥湾的缺氧区（坏年15,000 km²）以十年的滞后和一个雨季的噪声响应。
::: solution
输出系数$= 1.9/6 \approx 32\%$——进入流域耕地的全部氮有32%到达河流——死区的收入表，且是化肥前基线通量的三倍；滞后是**地下水与暗管排水的管道**（1980年代进入含水层的硝至今还在抵达，长期河流记录记录了数十年的水质响应），噪声是设定层结的春季水文——这就是为什么墨西哥湾的大小作为逐年政策记分卡很差、作为数十年的记分卡很好，也是为什么2008年密西西比缺氧工作组45%削减目标几乎没产生可测削减：管道几十年来吃进去的东西，要慢慢吐出来。
:::
:::

## 微生物账本

::: definition 硝化、反硝化、厌氧氨氧化：跑账的微生物 {#def-microbial-ledger}
在固氮与反硝化之间，氮循环是一本**微生物氧化还原账**，其分录决定氮是留在可用状态、以气体逃逸、还是毒害水体。**硝化**——氨到亚硝酸盐（*Nitrosomonas*，且自2006年的发现以来，在多数土壤和整个海洋深层水中数量超过其细菌对手的**氨氧化古菌**，2006年宣布古菌氨氧化者的报告——**Könneke、Treusch、Wuchter和Jetten**团队——改写了海洋的氮和碳收支**），然后亚硝酸盐到硝酸盐（*Nitrobacter*、*Nitrospira*）——让氮对植物可用但**可移动**（硝酸根的负电荷被土壤排斥）且**可呼吸**，而其工程化表亲——**硝化抑制剂**（DMPP和DCD包衣、"增效肥料"，气候文献现在把其采纳视为近乎免费的N₂O减排）——是对微生物本身的杠杆。**反硝化**——硝酸根逐级还原为N₂（*Pseudomonas*、*Paracoccus*、*nir/nor/nos*酶级联）——是生态系统唯一重要的气体出口，但其最后一个酶（氧化亚氮还原酶，*nosZ*）是缓慢、对氧和碳敏感的环节，其失灵让产物是**N₂O而非N₂**：淹水、碳脉冲和不佳pH把反硝化者从气候服务变成气候源的原因，也是完全去除之梦（废水反硝化到N₂）是与那最后一个酶的工程竞赛的原因。**厌氧氨氧化**——**Gijs Mulder**1981年在荷兰反应器中发现、由**Boran Kartal、Mike Jetten及其同事**在代尔夫特自1999年命名并机制化（厌氧氨氧化体、梯烷膜、联氨中间体）——是2000年代的震惊：一条意外的第三路径（NH₄⁺ + NO₂⁻ → N₂），结果在氧最低区供应了**海洋氮损失的一半**（**Kuypers、Dalsgaard和Thamdrup**的波罗的海与秘鲁工作）、闭合了单靠反硝化留有缺口的海洋氮收支，并把最便宜的革命递给污水处理（脱氨工艺现在以旧曝气成本的一个分数在数百座工厂从泥水回流液中脱氮）。账本的前沿是**化学计量调节**：海洋固氮者是否在海洋固定氮短缺时扩张（**Hansell固定比之争**、**Deutsch、Granger及其同事**靠固氮调节的回答、2020年代支持动态、区域可变海洋氮损失的同位素与有孔虫证据），以及陆地的氮饱和（Aber-Nordin-Gundersen样地、欧洲与美国的沉降调查）是否正把世界森林从氮汇变成氮漏源——决定级联陆地一腿是自我限制还是自我放大的问题。
:::

::: example 闭合海洋氮收支 {#ex-anammox}
海洋氮损失长期被估计为仅反硝化200 Tg N yr⁻¹，而固氮输入140–240；厌氧氨氧化现在在氧最低区被测得再加约80 Tg N yr⁻¹。求总损失、与200固氮的残余不平衡，并说出两个候选闭合。
::: solution
总损失$= 280$ Tg N yr⁻¹，对固定140——140的不平衡是海洋的稳定δ¹⁵N无法长期容忍的，而该领域争论的两个闭合：**固氮被低估**（Hansell立场——小的单细胞固氮者、珊瑚礁与沉积物固氮者、修正后的卫星时代收支）和**反硝化被高估**（同位素与质量平衡学派——1970–90年代氧利用回归的旧速率、被GEOTRACES时代的测量下调）；现代共识在240–300对200–240之间折中，一本**活的收支**，其残差是氮循环海洋一半仍在测量而非仅仅管理的清楚陈述。
:::
:::

## 追踪级联

::: definition 氮同位素作为级联指纹 {#def-n-isotopes}
活性氮带着法证签名，而**稳定同位素生态学**（**DeNiro和Epstein**的分馏规则、**Peterson和Fry**的食物网综合，1978–87）把它变成级联的追踪系统。三条原理干活。**分馏区分来源与过程**：硝化和反硝化都偏爱轻同位素，让残余硝酸根在¹⁵N上**富集**（沿反硝化羽流或蒸发池塘δ¹⁵N上升），而化肥铵在0 ‰附近、**粪肥与污水氮是重的**（+10到+25 ‰，来自轻氨的挥发）——让水文学家在牲口棚与化肥袋之间分摊河流硝酸盐的梯度、**Carol Kendall和Mariotti学派**的同位素水文学分摊法，如今是流域科学的标准。**营养级富集每级加约3.4 ‰**：消费者组织比食物重，所以δ¹⁵N是食物网温度计（食物链的长度、金枪鱼的位置、你食谱里鱼的比例）——而级联应用是——一个**生态系统的氮状态表盘**：标本馆叶片、泥炭岩芯和湖沉积氨基酸的δ¹⁵N几十年来与沉降和化肥使用同步上升，人为¹⁵N信号始于1930年代。**N₂O的"位点偏好"**（¹⁵N在N-N-O链中的位置）区分硝化源与反硝化源的氧化亚氮，2010年代农业N₂O来源分摊背后的同位素工具，也是任何N₂O议定书拟议监测的骨架。同位素还是人类氮接管的**古记录**：湖沉积有机质、泥炭和冰芯硝酸盐的δ¹⁵N记录了二十世纪活性氮的翻倍——级联的地层签名，与钚和隐火山灰并列的人类世候选代用指标。
:::

::: example 读一个食物网的氮状态 {#ex-trophic}
受施肥流域的溪流无脊椎动物δ¹⁵N = 12 ‰；原始参照溪流同种读4 ‰。用每营养级约3.4 ‰的富集并假设营养位置相同，归因这个偏移，并说明8 ‰之差对流域氮源意味着什么。
::: solution
同一营养位置上富集相消，所以8 ‰是**来源与过程**：受施肥流域的硝酸盐经过硝化-反硝化（每一遍让残余变重），且很可能带着粪肥或污水（重端元）——判定流域氮超载的同位素指纹，而在一千条溪流上运行，就为国家硝酸盐分摊账提供底稿；同样每级3.4的算术让δ¹⁵N成为已部署过的最便宜的生态系统级级联传感器。
:::
:::

::: warning 氮不是碳的问题重演，"养活世界"与"修好级联"是同一个工程，效率不是免费的，海洋收支没有闭合，而级联之害不是可选项
五个错误。**"氮污染与脱碳是同一场战斗"**：物理在种类上相反——CO₂累积数千年、要求能源转型；活性氮是**短命的、地方的、农业的**，而其控制手段（利用效率、抑制剂包衣、粪肥处理、废水反硝化、蛋白质废物削减）是农场和管道尺度的、每吨便宜、且**与能源转型正交**——两个循环需要盟友，而不是同一个计划。**"减少化肥就是让人挨饿"**：正确的目标是**逃逸的66 Tg**，不是养活人的44 Tg——世界浪费的氮足够养活几十亿人两遍（**Galloway与生命周期**估计：田间到餐桌之间浪费了约60亿人份的蛋白质），而必须增施化肥的地区（萨赫勒、南亚）恰恰是级联之害（渔场崩溃、地下水硝酸盐、臭氧-气候反馈）威胁其粮食安全最重的地区；诚实的框架是**穷田多施、饱和田少施、所有田都少浪费**。**"增效肥料能解决它"**：抑制剂和缓释包衣把利用效率提高5–15个点、在**施用得当时**削减N₂O约30–50%——但它们更贵、随热量和土质退化，且修不了**过量施加**（约束淋失的是农学最优而非技术），也管不了收支的粪肥和固氮两腿；技术是良好实践的乘数而非替代品，而2020年代的采纳曲线（全球化肥的百分之几）就是政策缺口。**"海洋氮收支大体闭合"**：并没有——上面的固氮对损失不平衡（140–240对200–300 Tg N yr⁻¹）是主要生物地球化学循环中最大的未闭合项，而其解决（海洋固氮者比想象的更重要一倍，还是损失只有一半？）会以吉吨碳改变海洋的CO₂抽走与反硝化反馈估计；2020年代GEOTRACES与同位素时代仍在争论，关于海洋氮的自信陈述是关于一条移动前沿的陈述。**还有"级联之害是二阶外部性"**：饮用水浓度的硝酸盐、N₂O的臭氧与增温角色、死区渔场崩溃是**一阶、量化、已定价**之害（欧洲氮评估每年700–3,200亿欧元对化肥约100–150亿欧元的收益——在富国级联的损害超过了它的补贴，而2019年荷兰农民骚乱就是政治发票的送达）；氮是罕见的**预防已比购买收益更便宜**的环境问题，障碍不是经济学，而是十亿块田地上百万次小施加的分散性。
:::

::: history
氮的故事始于那个键：**Henry Cavendish**1760–80年代的气相化学与演示（Cavendish、Lavoisier、Berthollet）证明硝酸的氮来自大气；**Joseph Priestley和Humphry Davy**的闪电固氮实验；十九世纪的**智利硝石**地缘政治（其争夺贯穿太平洋战争的硝酸钠矿藏）与**Liebig**1840年的学说——氮限制农场。生物学的世纪：**Hellriegel和Wilfarth**1886年证明豆科-根瘤菌共生（土壤微生物学始于此年）、**Sergei Winogradsky**的硝化菌富集（1890）与**Martinus Beijerinck**的固氮学派（1901）。工业的世纪：**William Crookes**1898年在英国科学促进会的警告——氮供应是一场文明倒计时；**Fritz Haber**1909年的合成（1918年诺贝尔奖）；**Carl Bosch与BASF团队**1913–1917年的高压放大（1931年诺贝尔奖，以及1921年奥保爆炸——560人遇难，以惨痛代价写下工艺安全的第一章）；把同盟国撑下去的氨转炸药，以及让固氮遍布世界的战战间许可网络——BASF的氨出口公司、DuPont的工艺工厂；**Norman Borlaug**依赖化肥的小麦与绿色革命的氮之半（1940–60年代）。微生物账本的科学：从Winogradsky到世纪中叶硝酸与亚硝酸还原酶生物化学的经典硝化反硝化生理学；**Gijs Mulder**1981年在荷兰中试反应器中的厌氧氨氧化观察，比**Mike Jetten、Boran Kartal与代尔夫特学派**1999年的机制化早了二十年，以及让厌氧氨氧化成为海洋氮损失一半的**Kuypers、Dalsgaard和Thamdrup**海洋调查。级联的科学：**哈佛森林与Hubbard Brook**的氮饱和研究（1970–80年代，**Likens、Bormann及其同事**）、**Vitousek、Aber、Howarth及其同事**1997年的*Science*综合、**Galloway、Townsend、Erisman及其同事**2008年的级联论文、**2011年欧洲氮评估（Mark Sutton及其同事）**及其每年700–3,200亿欧元的损害账、**A.R. Ravishankara**2009年的*Science*论点——N₂O是蒙特利尔之后时代的主要臭氧消耗排放、**Berner及其同事**2019年的N₂O议定书提案，以及2019–2023年荷兰氮危机政治——第一批因氮法而垮台的欧洲执政——而联合国环境规划署与行星健康共同体仍在尝试蒙特利尔议定书之于CFC的事：把氮写进条约体系。
:::

::: quiz
人为N₂O排放的最大单一来源是：

- [x] 农业——土壤中氮的微生物硝化与反硝化。
- [ ] 废水焚烧。

::: summary
氮循环的三键让固定氮十亿年来成为生命的稀缺通货；Fritz Haber和Carl Bosch的工艺打破了瓶颈，人类固氮现在与全部自然陆地固氮匹敌——在工业化前循环的容量之外养活约40亿人，同时向一条带着六项有据之害的级联泄漏约66 Tg N yr⁻¹：N₂O（CO₂温暖的273倍、蒙特利尔之后臭氧时代的主要消耗者、唯一仍在加速的主要温室气体）、饮用水中的硝酸盐、海岸死区、氮驱动的生物多样性丧失、氨颗粒物、以及酸化饱和的土壤。微生物——硝化者（现在包括称霸海洋的古菌）、最后一个酶在N₂与N₂O之间做决定的反硝化者、以及Mulder和Jetten的厌氧氨氧化革命闭合了海洋氮损失的一半——在固氮与气体之间跑这本账，而海洋收支仍是该领域最大的未闭合账户。氮是罕见的预防比收益本身还便宜的情形，工具已存在（效率、抑制剂、反硝化废水、蛋白质废物削减），障碍是十亿次小施加的分散——级联的政治，不是它的化学。
:::
