快循环在人类时标上让行星宜居；**慢循环**在地质时标上让它宜居。在数千万年里，地表地球的碳收支由隔着岩相记录对望的两台引擎运转——**火山与变质脱气**，以约0.1 GtC yr⁻¹向大气-海洋系统输送CO₂；以及**硅酸盐风化**，以同样的平均速率抽回，把大气留下作为两者之间一小块有争议的缓冲。本课就是慢碳循环及其病理记录：Urey恒温器如何让显生宙气候在超大陆、雪球和超级地幔柱之间留在宜居窗口内；**碳同位素漂移**如何编目平衡被大火成岩省和甲烷打破时会发生什么；以及PETM——始新世那场二十万年的高烧、地质学与我们自身实验最接近的一次，其最有用的数字是一个速率：**今天的排放比PETM的碳释放快约十倍**，而这个差——不是总量——是地球系统吸收掉的一次扰动与一次它将花五十万年消化的扰动之间的区别。

## 恒温器：风化对脱气

::: definition Urey反应与硅酸盐风化恒温器 {#def-thermostat}
慢循环的记账就是**Urey反应**（Harold Urey，1952）：硅酸钙的风化$\mathrm{CaSiO_3 + 2CO_2 + H_2O \rightarrow Ca^{2+} + 2HCO_3^- + SiO_2}$，接着海洋碳酸盐沉淀$\mathrm{Ca^{2+} + 2HCO_3^- \rightarrow CaCO_3 + CO_2 + H_2O}$，净得$\mathrm{CaSiO_3 + CO_2 \rightarrow CaCO_3 + SiO_2}$——每溶解一摩尔斜长石就埋藏一摩尔大气碳，风化通量（约0.1 GtC yr⁻¹，稳态下与脱气平衡），以及大气CO₂存量被这条路径以10⁵年时标翻新的原因。**恒温器**（**Robert Berner、James Kasting、Kirk Gregory和Lee**的建模谱系，1980年代至2010年代，以及GEOCARL古CO₂综合）是闭环的负反馈：**风化速率随温度和降雨上升**（长石溶解的Arrhenius动力学、造山与地形的岩量平衡），所以更暖的世界风化更快、抽走更多CO₂、把自己冷却回去——而雪球世界反之，冰限的风化让脱出的CO₂积累数百万年直到温室破冰（新元古代雪球的逃脱，同一机制反着来）。恒温器的三个警告就是本课的前沿。**它慢**：响应时间10⁴–10⁶年（海洋和土壤化学先缓冲，风化反馈后到），这正是它帮不了人类世扰动的原因——系统最快的稳定器需要一百代人来登记一个倍增。**它的设定点随生物和地理移动**：泥盆纪根和洞穴的兴起加速了风化（维管植物之后海洋锂和锶同位素的激增、"绿圈"论点即生物风化助推了晚古生代冰期），停在赤道的超大陆风化掉它们的温室（冰期与热带大陆和山带聚类在一起，喜马拉雅问题——新生代制冷的引擎还是稳态的旁观者？**Katz、Miller、Raymo和Ruddiman**1990年代的争论及其2020年代河流地球化学的调和）。**它的增益有争议**：让反馈强或弱的降雨-风化敏感度，正是雪球和"黯淡年轻太阳"时期压力测试的东西，元古宙就是恒温器稳定性被争论之地。慢循环对当下的寓意：行星*会*修正人为扰动，在风化时钟上，靠给海洋加碱——一项需要约十万年才能完成的服务，其中间步骤（酸化、增温、缺氧）就是下面记录里每次漂移的章节。
:::

::: example 恒温器的钟 {#ex-urey}
风化目前经Urey路径以碳酸盐埋藏约0.1 GtC yr⁻¹，大气持有875 GtC。求大气CO₂的风化周转时间，并用两句话解释为什么400 GtC扰动的恢复时间比这个数字所示的*更长*，以及究竟什么过程控制它。
::: solution
周转$= 875/0.1 = 8{,}750$年——每次周转已是人类文明四个世纪，而且已经是恢复的错误数字：快汇（海洋、生物圈）会在几个世纪内把大气抽下来，但系统的**碱度**——决定海洋能以什么pH持有CO₂的碳酸盐存量——只能靠深海碳酸盐溶解和风化即**碳酸盐补偿**过程在10⁴–10⁵年上恢复；而气候回到基线，要等被抽走的CO₂被碱度重建所平衡。这就是PETM漂移的尾巴拖约100,000–200,000年的原因，也是人类世碳问题诚实的半衰期在沉积记录而不在空气的原因。
:::
:::

## 漂移目录：当平衡被打破

::: definition 碳同位素漂移及其含义 {#def-cie}
**碳同位素漂移**（CIE）是沉积记录的烽火信号：海洋碳酸盐、有机质或土壤碳酸盐δ¹³C的全球同步偏移，记录了一次带着不同于正常循环同位素风味的碳注入。逻辑是化学计量的：有机质和甲烷是**轻的**（有机碳δ¹³C ≈ −25 ‰、微生物甲烷−60到−100 ‰，而地幔CO₂和海相碳酸盐标准是0 ‰），所以负漂移意味着**轻碳被加进海洋-大气系统**，而漂移的大小和形状经同位素质量平衡一跑，就是地质学家对释放碳的估计。显生宙目录读起来是一份大火成岩省及其后果的清单：**赫南特期**（445 Ma，+4到+5 ‰的*正*漂移——奥陶纪冰期的签名，证明第一次大冰期伴随有机碳埋藏增强，一个可能的抽走触发）；**泥盆纪Kellwasser**（372 Ma，正，与缺氧和灭绝耦合）；**二叠纪-三叠纪**（252 Ma，−3到−8 ‰，西伯利亚暗色岩，最大灭绝，其漂移形状支持两阶段释放——快速火山加甲烷或煤层火的第二脉冲，伴生过去5.4亿年最酸的海洋和最荒芜的大陆）;**托阿尔期**（183 Ma，−6到−8 ‰，Karoo-Ferrar大火成岩省的火山作用，**Andy Kemp及其同事**（2005–2015）的海底甲烷假说，以及唯一一次由菊石氧同位素以季节分辨率测得起始速率的CIE：漂移让气候加速**约比背景快10倍**，正是给当下定罪的那个速率比较）；**PETM**（56 Ma，本课的主角）；**较小的早始新世高热事件**（ETM2、ETM3及其表亲——每次都是一次碳释放，其轨道周期性是一个关于偏心率预置甲烷储库的活争论）；以及**白垩纪海洋缺氧事件**（中期白垩世热最大的正漂移与黑色页岩，最热时的温室世界，约1,000–2,000 ppm CO₂，鳄鱼在南极）。元古宙补上构造尺度的事件：**Lomagundi-Jatuli正漂移**（22.2–20.6亿年，地球史上最大的δ¹³C偏离——+5到+12 ‰持续约1.6亿年，一次全球有机碳或甲烷埋藏事件的同位素指纹，其成因及其与大氧化事件的联系仍未解决），以及**成冰纪"Shuram/Denino"负漂移**（到−12 ‰，记录中最大的负值，其解释是甲烷释放、上涌与盆地尺度假说之间的活争论，其地层是雪球计时争论的骨架）。漂移记录对当下的深层教训是**速率，不是数量**：PETM释放的只是现在储量中化石碳的一个分数，其生物损伤（底栖灭绝、礁危机、有孔虫侏儒化）是严重的——而2010年代的硼同位素pH重建（**Caitlin Penman及其同事**2016、**Marcus Gutjahr及其同事**2017）显示PETM海洋酸化约0.3个单位——大约是我们本世纪在轨的幅度——却用了约5,000–20,000年而不是两年。记录里的大灭绝聚集在**速率、幅度和环境状态**重合之处；PETM是唯一速率可定量比较的事件——它被挺了过来——而当下的扰动是PETM速率乘以十，压在一个已经背着全新世负荷的生物圈上。
:::

::: example 读出一次漂移的释放量 {#ex-cie-release}
一次CIE让海洋碳酸盐δ¹³C全球偏移−5 ‰。表层海洋-大气DIC储库≈2,300,000 GtC，注入碳的δ¹³C = −60 ‰（甲烷）。用两端元近似$\Delta\delta \approx f\,(\delta_{in} - \delta_{bg})$估计释放的碳，并解释为什么这个朴素估计大得离谱。
::: solution
$-5 = f(-60-0)$给出$f = 0.083$，所以释放$\approx 0.083\times2.3\times10^{6} \approx 190{,}000$ GtC——荒谬地大，而荒谬正是重点：简单箱式忽略了**漂移自身碳的埋藏**（部分轻碳被埋为有机质或甲烷成因碳酸盐，而同位素信号被巨大的碳酸盐台地储库稀释），所以带埋藏项的完整质量平衡模型给PETM约4,500–12,000 GtC；每篇发表的CIE释放量都带着三倍的误差棒和一个关于缺失沉积记录的脚注。
:::
:::

## PETM：地质学自己的实验

::: definition 古新世-始新世极热事件，作为现代类例来读 {#def-petm}
PETM（55.9–55.6 Ma）是岩相记录中采样最充分的突变气候事件，在1990年代初的深海岩芯中被发现（**Bains及其同事**1999年的同位素型剖面工作，以及1990年代**Koch、Zachos、Gingerich、Kelly、Thomas、Wing、Behrensmeyer、Lohmann和Schrag**的里程碑式解释，由PETRNM网络在2007–2013年综合）。其清单：−3到−6 ‰的碳同位素漂移；深海升温**4–7 °C**；海洋酸化与溶解面，约35–50%的深海底栖有孔虫灭绝；一场陆地革命（Bighorn和Polecat盆地中现代灵长类、奇蹄类和啮齿类动物群的首次出现、哺乳动物侏儒化、花粉和炭屑记录中的干旱化与野火激增）；以及一次**约4,500–12,000 GtC**的碳释放，其来源是该领域旷日最久的争论：经典的**甲烷-水合物假说**（暖基线上的水合物失稳——轻同位素签名支持生物来源）、**岩床燃烧假说**（北大西洋火成岩省的岩床烘烤东格陵兰和Rockall的煤层与蒸发岩层——**Henrik Svensen及其同事**（2004–2009）的热成因碳建模、起始处火山脉冲的锇同位素证据、2017–2023年把释放与火山作用联系起来的汞异常研究），以及混合立场（火山推一把，甲烷放大）。PETM对当下的数字：起始释放速率**约0.6–1.1 GtC yr⁻¹**，而**今天约10 GtC yr⁻¹——快一个数量级**；海洋酸化约0.3个单位（硼同位素），而我们本世纪的预测是0.3–0.4；增温4–7 °C，而我们高排放情形本世纪是2–5；恢复花了**>100,000年**（漂移的碳酸盐稀释与风化尾巴），而慢循环对我们自己扰动的服务合同就是约十万年。PETM因此是**快释放之伤害的下限**：哺乳动物辐射了，海洋脱氧、酸化又恢复了，气候重置到温室状态——而2020年代浮游有孔虫生物地理学甚至主张热带表层海洋的常驻物种被部分*清空*，由来自亚热带的迁入重新填满。当下的实验在两个要紧参数上不同——**速率**（10倍）和**初始状态**（我们从冰室行星上的424 ppm出发，背着80亿人和一个被全新世塑造的海岸；PETM开始时无冰且无人）——而这个类例的诚实读法是：PETM是*温和*情形；记录里速率可比的事件——二叠纪-三叠纪、托阿尔期——才是带着大灭绝的那些。
:::

::: example 认真的速率比较 {#ex-rate}
PETM在约10,000年的起始期释放了约10,000 GtC；人类自1850年以来在175年里释放了约400 GtC化石碳。计算两个平均速率（GtC yr⁻¹）及其比值，并说出PETM较慢的速率给地球系统买到了什么、而我们没买到的东西。
::: solution
PETM：$10{,}000/10{,}000 = 1$ GtC yr⁻¹；现代：$400/175 \approx 2.3$ GtC yr⁻¹（按当前年速率约10）；比值**2.3–10倍**。较慢的速率买到的是**缓冲时间**：在1 GtC yr⁻¹下，碳酸盐化学、生物泵和（在几千年上）风化反馈部分吸收脉冲，表层海洋离腐蚀线更远，深海和土壤群落保有避难所和适应时间；在10 GtC yr⁻¹下每个缓冲都被跑赢，饱和面变浅的速度快于生物迁移——排放*速率*与累计*总量*同为政策变量，其全部物理尽在于此。
:::
:::

## 读古CO₂

::: definition 古CO₂代用指标与硼桥 {#def-paleo-co2}
慢循环的理论只与其测量一样好，而**古CO₂重建**是该领域年轻而善辩的核心。四个代用指标家族承担重担。**硼同位素**（有孔虫壳的δ¹¹B）：海水中硼酸根/硼酸之比依赖pH（硼酸根份额为$1/(1+10^{pK_a-pH})$，$pK_a \approx 8.6$），而硼酸根——唯一被并入方解石的硼形态——同位素上轻约25 ‰，所以壳δ¹¹B给出pH，pH加一个碱度估计给出pCO₂；该方法1990–2020年代的修正（生命效应校正、培养标定一代）给出了PETM的0.3个pH单位、始新世的500–1,000 ppm，以及对"高CO₂温和始新世"悖论的挑战。**烯酮δ¹³C**（定鞭藻脂质中碳同位素分馏对CO₂的依赖）和**植醇δ¹³C**把表层海洋pCO₂往回给到约40 Ma。**气孔频率**（大气CO₂与化石叶片气孔密度的反比关系）是深时陆地主力，其标定在物种特异曲线与机理模型之间有争议。**古土壤碳酸盐**（Ward-Johnson-Royer以及**Daniel Royer和Gregory Retallack**谱系）和**结核与土壤碳酸盐中的硼**把曲线延入海洋代用指标变稀的泥盆纪-三叠纪。综合曲线——**GEOCARL/BERYL/GEOCLIM**（**Yves France-Lanord、Tim Lenton、Dana Royer、Peter Berner**及其同事2001–2019年的综合）——显示显生宙CO₂从>2,000 ppm（志留纪）落到工业化前的280，两大特征是泥盆纪-石炭纪的崩落（根与煤沼的抽走）和新生代向今日低值的下滑（冰室的入场费）——而深时的误差棒是±两倍，这就是为什么该领域的争论（2020年代奥陶纪4,000对300 ppm之争、"高CO₂始新世"的调和）是穿着气候外衣的代用指标方法之争。
:::

::: example 硼桥，一环一环 {#ex-boron}
海水中硼酸根份额$f_B = 1/(1+10^{pK_a-pH})$，$pK_a = 8.6$。求pH 8.0和pH 7.7时的$f_B$，并用一句话解释为什么建立在这个比值上的代用指标在海洋pH区间异常灵敏。
::: solution
pH 8.0时：$f_B = 1/(1+10^{0.6}) = 1/4.99 = 0.20$；pH 7.7时：$1/(1+10^{0.9}) = 1/8.9 = 0.11$——0.3个pH单位的酸化几乎把硼酸根份额**减半**，而壳δ¹¹B（这一变化对应约2–3 ‰的移动，远高于分析噪声）因此能以真实分辨率读出PETM和人类世酸化：这个代用指标的天赋在于海洋的碳酸盐缓冲把硼的平衡正好放在动作发生之处——曲线最陡的一段。
:::
:::

::: warning 类例只是类比，恒温器不是安全网，"那时CO₂更高"不是论点，漂移不是同一个故事，而深远的未来不是当下的论据
五个错误。**"PETM证明我们会没事"**：PETM被一个没有人类、没有农业、没有冰盖承诺、速率只有今天的三分之一的生物圈挺了过来——而其幸存者付出了深海生物大灭绝和热带重组的代价；类例的价值在于反复出现的**过程**（酸化、脱氧、迁移、灭绝），不是在十倍速率下好结果的承诺。**"风化会修好，所以慢循环是我们的兜底"**：它会修好——在十万年后，经由酸化与增温的区间，而漂移记录显示那些区间是恢复*不可回避的中段*；恒温器保护深远未来不受快世界之害，从不反过来，而文明的时标是快的那个。**"始新世CO₂是1,000 ppm，南极有棕榈"**：真的，但这句话藏起了论点——始新世没有冰盖、没有现代季风荒漠、没有继承自全新世的75 cm海平面承诺、没有在富产海岸带的八十亿人；"那时气候不同"描述的是*另一颗行星的平衡态*，不是两个平衡态之间过渡路径的安全评级，而过渡路径才是一切活物所在之处。**"每次CIE都是火山加甲烷"**：漂移有正负之分（赫南特期和Kellwasser是*正*的——埋藏事件）、来源不同（地幔、甲烷、有机埋藏、蒸发岩硫）、历时不同（Lomagundi的1.6亿年对PETM的二十万年）、生物圈初始状态不同，而马虎的"火山干的"概括一再错定年代、错定归属（托阿尔期的来源之争、Shuram的成因之辩）——漂移科学是一门来源解析的学科，其不确定性是其诚实的特征。**还有"岩相记录显示CO₂和温度相关，所以一切都定了"**：慢循环的相关约束的是数千万年上的**平衡**敏感度（PETM和始新世确实支持IPCC的区间），但它们约束不了冰盖损失、季风重组和决定本世纪的复合极端的**速率**——未来200年的古气候不在岩相记录里，因为速率不在岩相记录里。

::: history
慢循环的理论是世纪中叶的物理：**Harold Urey**1952年的《行星》（*The Planets*）奠定了碳酸盐-硅酸盐平衡；**Robert Garrels和Henry Holland**1960年代的海洋缓冲地球化学；**Robert Berner**的GEOCARB系列（1991–2009，从岩相记录读出的CO₂曲线）与GEOCARL综合；**Kirk Gregory及其同事**和**Lee与Kasting**的恒温器与雪球逃脱建模；**James Kasting**的《如何找到一颗宜居行星》（*How to Find a Habitable Planet*，2010，恒温器的教科书）；**Paul Hoffman和Daniel Schrag**的CO₂-风化雪球论点（1998–2000）；以及**Andy Ridgwell和Lee Kump**的漂移与"黯淡年轻地球"建模。漂移目录是一门大洋钻探与陆地剖面的学问：PETM在1990年代初的发现（**Bains及其同事**与深海钻探计划的遗产岩芯）、1990年代同位素-化石革命（**Koch、Zachos、Gingerich、Kelly、Thomas、Wing、DiMichele、Behrensmeyer、Ivany、Curtis、Lohmann、Schrag**）、PETRNM综合（2007–2013）、**Henrik Svensen及其同事**的格陵兰岩床与热成因碳工作（2004年至今）、汞异常时代（2017年至今），以及硼同位素pH革命（**Spivack和Edmond**1987年的方法，由**Penman及其同事**（2016）和**Gutjahr及其同事**（2017）应用于PETM）——而**Andy Kemp**在托阿尔期用菊石做的速率工作（2005–2015）提供了唯一一次带季节分辨率起始的中生代事件。2020年代的时代是模式相互比较（**DeepMIP**的PETM与始新世协议）与速率解析——该领域关于PETM是甲烷事件、火山事件还是两者兼有的长期争论，现在正收敛到"两者，按此顺序"；而关于下一次漂移在五千万年后会被读成什么样的老争论，如今是在仪器运转中进行的。
:::

::: quiz
硅酸盐风化恒温器稳定气候，是因为：
- [x] 风化速率随温度和降雨增加，让更暖的世界更快抽走CO₂。
- [ ] 气候变暖时火山活动增强。
- [ ] 冰盖反射阳光。
- [ ] 海洋在冷的时候更快吸收CO₂。
::: solution
Urey反馈的负环：更暖更湿则风化更快，更快风化以碳酸盐埋藏更多CO₂，气候回到设定点——在10⁴–10⁶年的钟上，对人为世扰动而言慢得帮不上忙，这正是本课的全部警世之意。
:::
:::

::: summary
慢碳循环是行星的长期气候控制：火山脱气向大气供约0.1 GtC yr⁻¹，硅酸盐风化（Urey反应）以同一均值拿回，而风化对温度-降雨的依赖把这一对变成一台响应时间10⁴–10⁶年的恒温器——显生宙保持宜居的原因，也是它在我们时标上救不了我们的原因。漂移目录——赫南特期、Kellwasser、二叠纪-三叠纪、托阿尔期、PETM、海洋缺氧事件、Lomagundi和Shuram——是记录的证据：当平衡被打破（通常有大火成岩省"帮忙"），气候响应、酸化、缺氧和灭绝跟随释放的**速率**不亚于数量。PETM是应当吸取教训的实验：约10,000 GtC、约1 GtC yr⁻¹、4–7 °C、0.3个pH单位、一次深海灭绝、十万年的恢复——而现代的释放以十倍的步速跑在一颗更冷、有冰冠、拥挤的行星上。慢循环会修复我们打坏的东西，在风化钟上；接下来几个世纪的全部内容，就是那次修复的中段对等不了十万年的事物意味着什么。
:::

::: exercise {level=1 check="8750"}
求大气CO₂储库（875 GtC）对0.1 GtC yr⁻¹的Urey风化通量的风化周转时间（年）。
::: solution
$875/0.1 = 8{,}750$年——经慢循环翻新高一次大气，就是文明四个世纪。
:::

::: exercise {level=1 check="1"}
PETM在约10,000年的起始期释放了约10,000 GtC。求其平均释放速率（GtC yr⁻¹）。
::: solution
$10{,}000/10{,}000 = 1$ GtC yr⁻¹——始新世系统缓冲住的速率，现代比较的基线。
:::

::: exercise {level=1 check="0.3"}
按硼同位素记录，PETM海洋酸化了几个pH单位？
::: solution
**约0.3个单位**（Penman 2016、Gutjahr 2017）——与本世纪预测的酸化幅度相同，但用了千年而不是十年。
:::

::: exercise {level=1 check="10"}
人类自1850年以来释放了约400 GtC（175年）。求平均速率（GtC yr⁻¹，取整）。

$400/175 \approx 2.3$，而当前年化化石速率约10 GtC yr⁻¹——练习里的10是今天的速率，PETM文献做的那个比较。

::: exercise {level=3 check="10"}
PETM起始速率约1 GtC yr⁻¹；如今年化化石释放约10 GtC yr⁻¹。求速率比。
::: solution
$10/1 = 10\times$——把一次可挺过的地质事件与一场未经检验的文明实验分开的唯一数字，因为吸收PETM脉冲的那些缓冲全在现代速率跑赢的时标上响应。

::: exercise {level=3 check="6000"}
一次CIE质量平衡给出δ¹³C偏移−6 ‰对应释放12,000 GtC。估计第二次事件在−3 ‰偏移、储库与埋藏效率相同时的释放量（GtC）。
::: solution
稀释近似下的线性给出$12{,}000\times(3/6) = 6{,}000$ GtC——漂移论文里"小事件是大事件一半"每个说法背后的缩放假设，只在来源与埋藏项相符时成立，而这正是论文们争论的假设。
