一颗呼吸的行星是一道记账题。你身体里的碳曾是大气CO₂、一片叶子、一条鱼、一条冰川和一座火山——而追踪它去过哪里、现在哪里、页码翻得多快的那些账本，就是**生物地球化学**：元素穿过地球系统的循环之学，用储库、通量、以及把它们与生命耦合的化学计量语言写成。这门学科的核心领悟——**Vladimir Vernadsky**在1926年宣布生物圈是一种地质力时看到、一代之后由**Alfred Redfield**和追随他的海洋学派定量化——是生命是一台**化学引擎**，其废料改组了大气和海洋，而元素以固定比例穿过它运动，使生物学可以从化学读出。本课就是记账：储库与通量、周转时间与稳态、Redfield比及其例外，以及让我们目睹人为扰动的同位素示踪剂。

## 储库、通量、周转时间

::: definition 会计工具箱 {#def-bg-bookkeeping}
每个循环都是一组**储库**（质量$M_i$，如大气以CO₂计的875 GtC（415 ppm时，1 ppm = 2.12 GtC）；植被约450；土壤与泥炭约1,500–2,400；海洋溶解无机碳38,000，其中90%坐在深海；海洋沉积物约1.5亿；化石储量约500可采、地下约10,000）由**通量**（$F_{ij}$，如光合作用123 GtC yr⁻¹、呼吸约120、海洋吸收约9出9进、化石排放约10、土地利用约1）相连。基本定律是质量平衡$dM_i/dt = \sum F_{\mathrm{in}} - \sum F_{\mathrm{out}}$，及其两个支配概念：**周转时间**$\tau = M/F$（大气CO₂对光合而言，$875/123 \approx 7$年——快循环的翻新，而**绝不是**扰动的存续时间，一个误导了一千条标题的混淆），以及**稳态**（所有$dM/dt \approx 0$的工业化前近似，而人类的循环已经摧毁了它：大气现在每年净得约5 GtC、海洋约2.7、陆地约3，来自排放的约11，这个不平衡之所以能闭合，只因为**空气分数**——留在空中的约44%，随汇滞后而缓慢上升——小于1）。工具箱的三个微妙处：**时标层级**（快生物循环以年翻新碳、碳酸盐补偿深度以10⁴年、硅酸盐风化以10⁵–10⁶——这就是为什么我们排放的化石碳是**慢循环时钟上的扰动**：一个脉冲带着活过文明的尾巴衰减，碳循环模型的"脉冲十万年"结果）；**泵问题**（海洋对今日大气平衡的30倍碳超额由生物泵和温度/溶解度几何维持——各循环不是独立账户而是一个耦合系统）；以及**化学计量**（元素以固定比例运动——下一节——所以测一个元素的循环就约束了其余）。这门学科的现代胜利是收支**闭合**：排放减空气部分等于海洋汇与陆地汇之和，由独立测量（海洋靠船载碳重复断面与调查、陆地靠森林清查与通量塔）在误差棒内一致——地球科学史上被审计最多的实验，也是气候变化课程里每一本排放账下面的地基。
:::

::: example 大气碳收支，闭合 {#ex-budget}
化石排放10.0 GtC yr⁻¹、土地利用1.1、大气增长5.2、海洋吸收2.7。求陆地汇与空气分数；若排放以每年4%下降而汇保持其当前**分数**效率，用一句话解释为什么大气CO₂仍要上升几十年。
::: solution
陆地汇$= 11.1 - 5.2 - 2.7 = 3.2$ GtC yr⁻¹；空气分数$= 5.2/11.1 = 0.47$，近几十年观测的约45–50%。CO₂继续上升是因为空气分数**小于1但大于0**：即使排放快速下降，大气仍在积累，直到排放降到汇能力之下（约2–3 GtC yr⁻¹且随海洋和陆地饱和而下降）——"稳定排放"与"稳定气候"之差就是气候变化课程的全部主题，而它先于政策、先是算术。
:::
:::

## 化学计量：Redfield比与其下的能量

::: definition C:N:P与电子经济 {#def-redfield}
1934年，改行做渔业科学的挪威海洋学家**Alfred Redfield**在Dana号考察中发现深海水的氮:磷比（16:1）、河流输出和海洋浮游生物的是同一个数——并得出了让生物地球化学成为定量科学的那个推论：**浮游植物按固定配方建造身体，海洋化学遵从它**。经典比值C:N:P = 106:16:1（硅藻壳加Si、酶催化剂加Fe）意味着各循环**被化学计量耦合**：从表层输出的一摩尔磷带着106摩尔碳下沉，深海的营养盐梯度（N、P和CO₂随深度按同一比例增加）就是写在水体里的生物签名，而**限制营养盐**概念——哪种元素先用完谁就控制生产力，最小律应用于海——组织着海洋的肥力地图（高硝石低叶绿素带即缺铁处：赤道太平洋、亚北极、南大洋——**John Martin**"给我半油轮铁"的那些海域，其铁施肥试验SEEDS、SOIREE、Eisen、LOHAFEX给出了部分水华和大量关于碳究竟封存了多少的细节）。比值之下更深的一层是**能量学**：生命是一个电子经济——从光合到呼吸是一串氧化还原反应的级联，每个反应的自由能产率决定哪里可能有哪种代谢——而元素循环就是**生物圈的电子传递链**：碳是电子骨架，氮是氧化还原穿梭（其+5到−3的区间驱动多数厌氧代谢），磷是能量货币（ATP）和记忆分子（DNA），硫和铁是无氧时的电子载体。比值有证明规则存在的例外——蓝细菌在氮受限时固N₂（放松N:P）、硅藻硅化（解耦Si），而Redfield比本身随温度、光和物种变化（2010年代的荟萃分析：表层水N:P为13–23）——但一阶表述屹立不倒：**海洋是一台有生物配方的搅拌反应器，而配方写在深水里**。
:::

::: example 死区的化学计量 {#ex-deadzone}
一条受施肥的河流向近海输出溶解无机氮8 µM、磷0.3 µM。用Redfield（16:1）求哪种营养盐过量、过量多少，并计算若全部氮被用来造生物质然后又腐烂的耗氧量（每摩尔C约1摩尔O₂，有机物呼吸约1:1）。
::: solution
8 µM N的Redfield需求是0.5 µM P——水体只带0.3，所以**磷受限**，而0.3 µM P支撑$0.3\times106 = 32$ µM的C（过量的N，$8-0.3\times16 = 3.2$ µM，积累或反硝化）；呼吸这些碳消耗约32 µM O₂——足以（海水约含250 µM O₂）剥掉三分之一的氧、越过杀死移动动物的缺氧阈值（<64 µM）：**墨西哥湾死区**、波罗的海的死区和不断加长的名单，就是Redfield比应用于化肥，是地球上化学计量即公共卫生的最干净例子。
:::
:::

## 示踪：目睹扰动

::: definition 同位素作为指纹 {#def-tracers}
人类实验靠**同位素指纹**诊断，因为每个碳源都有签名。化石燃料**贫¹³C**（δ¹³C ≈ −25 ‰，来自C3植物）且**¹⁴C已死**（放射性碳在数百万年里衰光）；生物质燃烧贫¹³C但¹⁴C是现代的；海洋信号是质量依赖的分馏。燃烧第一种因此在CO₂上升的同时**稀释**大气的两种同位素——**Suess效应**（1850年以来δ¹³C下降约1.9 ‰，以及化石稀释导致的¹⁴C下降，两者都在定量上匹配排放史：到1980年代完成的同位素证明，CO₂上升**来自燃烧而非海洋或呼吸**，后两者会带着不同或相反的同位素符号）。**炸弹脉冲**（核试验在1963年前把大气¹⁴C翻倍，其后的下降度量的是**总**碳循环吸收速率——海洋与陆地混合之和——独立于CO₂收支，并直接给出表层碳系统的"交换时标"）是史上运行过的最大同位素实验，也是最多产的之一。**氧-碳巧合**结案：大气O₂按燃烧化石碳的确切化学计量比例下降（O₂:N₂每年约100 per meg的下降，在计入陆地汇的O₂释放后与燃烧亏缺相符），而**大气CO₂的Δ¹³C**加**海洋DIC的δ¹³C**加**空气分数**加**海洋人为CO₂储量**（瞬时示踪剂工作与GLODAP全球海洋调查测得的1850年以来约175 GtC化石碳、占排放约26%，在船上测量）构成一个超定系统，从四个方向闭合到同一答案：**约45%在空中、约26%在海洋、约30%在陆地，而陆地的份额真实却日益脆弱**（通量塔和卫星的2010–2020年代记录显示亚马逊东部枯退与火制度正把汇推向源——陆地汇是否正在终结是未来几十年的碳循环问题）。示踪方法可推广到本课程的每个循环：¹⁵N对硝化与反硝化、⁸⁷Sr/⁸⁶Sr对风化通量、δ³⁴S和δ⁷Li对氧化还原与风化强度——生物地球化学对"你没法运行一个对照行星"这一实验主义者质疑的回答。
:::

::: example Suess算术 {#ex-suess}
工业化前空气：CO₂ 280 ppm、δ¹³C −6.5 ‰。化石碳：δ¹³C −25 ‰、¹⁴C已死。若到今天425 ppm上升的145 ppm全部是化石的且留在空中，求混合物的预期δ¹³C；再对45%留在空中（保留65 ppm）重算，与观测的约−11 ‰比较。
::: solution
质量平衡：若全部排放碳未经处理留在空中，$\delta = (280\times(-6.5) + 145\times(-25))/425 = -12.8$ ‰。观测的约−10.8 ‰**同位素上更重**，因为空气分数小于1——离开大气的那部分排放碳（进海洋和生物圈）把它的−25 ‰带走了，留下较小的稀释：45%留在空中时，$(280\times(-6.5)+65\times(-25))/345 = -10.0$ ‰，在观测误差内。这个练习就是同位素收支的核心逻辑：**Suess效应用第二种独立的货币度量空气分数**——两种货币的一致就是碳收支被称为闭合的原因。
:::
:::

## 生命漏下什么：占用与循环的类别

::: definition 气体型与沉积型循环，以及人类的光合份额 {#def-appropriation}
教科书分类按主导储库给循环排序：**气体型循环**（碳、氮、氧、其活性部分的硫）穿过大气循环，耦合两个半球，对扰动的响应以年到一个世纪计；**沉积型循环**（磷、钙、金属、其长支的硅）穿过岩石循环，其活性储库的周转时间为10⁴–10⁸年，使其扰动——采矿与化肥P、金属冶炼的半循环加速——在人类时标上实际上**不可逆**，因为出口是地质学的。这个区分是图谱不动声色的结构论点：碳问题快且（原则上）可修，磷问题慢且（实际上）永久，而同一吨干预在两个系统里意味着相反的事。所有循环里人类的处境是**占用**：1986年**Vitousek、Ehrlich、Ehrlich、Nutt和Woodwell**的量化——当时人类使用陆地净初级生产的32–40%——在现代账目中已爬升到**可及NPP的大约一半**（作物、牧场收获、木材和化石部分），而同一套"转化即占领"的逻辑贯穿本课程的每个循环：一半可及活性氮现在由工业固定，三分之一的无冰土地被耕作，河流的泥沙和磷通量被水坝拦了一半，而生物圈的化学引擎日益为我们、也违背其自身旧账本地运转。这个数字的教学用途不是末日而是**尺度**：当一半的光合作用已经被认领，"用树解决气候"是算术上的不可能，而"养十亿人且不弄坏氮和磷"是同一问题戴的另一顶帽子——本课后面的章节依次就是这些帽子的故事。
:::

::: example 占用账本 {#ex-npp}
全球陆地NPP约56 GtC yr⁻¹，其中约40 GtC对人类使用"可及"；人类目前使用约19 GtC yr⁻¹。求人类的总NPP份额和可及NPP份额；若生物能源作物再认领5 GtC，可及份额是多少。
::: solution
$19/56 = 34\%$的总量、$19/40 = 48\%$的可及NPP；加上5 GtC生物能源让可及份额到$24/40 = 60\%$——把可及光合作用的其余40%留给渔业、森林、土壤，以及一颗活行星完整的营养与水平衡。这个练习就是本课程约束的一次除法：**每个生物地球化学解决方案都是对同一块40的索取**，这就是诚实的气候-农业-生物多样性文献是权衡的文献而非投资组合的文献的原因。
:::

::: warning 周转时间不是存续，收支闭合不等于安全，Redfield是倾向不是定律，而陆地汇是伙伴不是仆人
五个错误。**"CO₂的周转时间是5年，所以问题会自己解决"**：τ = M/F描述的是**储库存量经快循环的翻新**，不是扰动的衰减——5年的交换把每个分子循环许多次，而**超额部分**（总通量之间的不平衡）存续几个世纪到几千年，因为慢汇（碳酸盐补偿、风化）很小；同一个CO₂分子也许几个月就离开空气，而**多出来的**碳会留十万年。**"收支闭合，所以汇可靠"**：闭合是过去60年的会计恒等式，不是合同——亚马逊变干、北方针叶林火制度、层结之下海洋溶解度泵的减弱，全是候选的汇失效，而空气分数轻微的上升趋势（0.44 ± 0.06，每十年上升约0.5%）是合同细则的第一条提示。**"Redfield比是普适的"**：它是一个带命名例外的**均值**（固N₂者放松氮限制、硅藻解耦硅、深太平洋10–12的N:P记录了一个世纪关于比值是否被固氮者的反馈调节向16的争论——**固N₂者调节假说**，现在是该领域对海洋如何保持其比值支持最好的答案）——而例外正是气候相关意外居住之处。**"我们可以给海洋/陆地施肥把一切收回来"**：陆地汇已经在免费做约3 GtC yr⁻¹且可能正在转向；海洋铁施肥在六次试验中只给出小而短命的碳输出，并欠下深水缺氧和酸化的债（同一套封存碳的化学计量也把它呼吸进深处，让同一团水在富集的同时缺氧）；"我们能管理多少"的诚实数字是排放的一个分数，不是全部。**还有"循环是平衡的所以排放无所谓"**：工业化前的平衡是**基线**，而人类通量（向活性表层系统约11 GtC yr⁻¹）现在是工业化前全新世自然土地利用通量的**十倍**、与整个快生物循环的不平衡尺度相当——循环没有被弄坏，而是被**跑赢**了，这两个词之差就是适应与地质学之差。
:::

::: history
循环的思想早于其算术：**拉瓦锡**的呼吸即燃烧（1770年代）、**索绪尔**用植物与空气做的碳循环实验（1804），以及**傅里叶和丁铎尔**的温室光谱学搭好了舞台；**Vernadsky**1926年的《生物圈》用西方很晚才读到的语言把生命变成一种地球化学力；**G. Evelyn Hutchinson**在1940年代让湖泊化学定量化。**Alfred Redfield**1934年的比值（和1958年为其辩护的*Science*短文）是该领域的拱心石；现代碳循环综合的架构归功于**Wallace Broecker**海洋表层"微风不止、往来不绝"（1974）及其示踪剂与箱式模型学派、**Bert Bolin**开创性的碳循环模型，以及**Klaus Hasselmann**和**C. D. Keeling**的互补革命——Keeling曲线（1958年至今，Mauna Loa现在的415 ppm）和Hasselmann首次把上升归因于人类的碳循环反演建模（1979年，那篇拿下2021年诺贝尔奖的论文）。同位素工具箱：**Hans Suess**的化石稀释效应（1955）、1960–70年代的炸弹脉冲科学（**Revelle和Suess**1957年的海洋吸收预测、**Munnich和Vogel**的炸弹¹⁴C吸收测量）、**Charles David Keeling**的¹³C下降与1970–80年代¹⁴C死碳的确认；现代测量企业：全球瓶样与通量塔网络（**FLUXNET**）、海洋调查计划（**GLODAP**、CLIVAR重复断面）、卫星日光诱导叶绿素荧光时代（2010年代至今），以及**全球碳计划**的年度收支（2006年至今）——它把地球的账本变成公开的、被审计的文件，是行星尺度的科学最接近复式记账的东西，也是每场气候谈判最终为之争吵的那本账。
:::

::: summary
生物地球化学是地球系统的复式记账：储库（空中875 GtC、海中38,000、土壤1,500）、通量（123 GtC的光合引擎、10 GtC的人类引擎）、度量翻新而非存续的周转时间，以及把元素彼此并与能量耦合的化学计量（Redfield的106:16:1）。人类扰动由同位素指纹诊断——¹³C和¹⁴C的Suess稀释、炸弹脉冲的吸收钟、氧的下降——从四个独立方向闭合碳收支：约45%在空中、约26%在海洋、约30%在陆地，而陆地份额现在是全系统最令人不安的一行。这门学科对本课程之后一切的两个大教训：循环是**耦合的**（你不可能扰动碳而不挪动氮、磷和氧），而时标是**分层的**（快循环的5年钟和慢循环的十万年尾巴都是真的，而政策活在缺口里）。
:::

::: exercise {level=1 check="2.12"}
求1 ppm大气CO₂的碳质量（GtC）（空气=2.13×10¹⁵吨……用：干空气5.12×10¹⁸ kg、M_CO₂/M_air = 44/29、碳份额12/44）。
::: solution
$5.12\times10^{18}\times10^{-6}\times(12/29) = 2.12\times10^{12}$ kg = 每ppm **2.12 GtC**——本图谱每个碳数字背后的换算因子。
:::
:::

::: exercise {level=1 check="7.1"}
求大气CO₂对光合总通量的周转时间（年）（M = 875 GtC、F = 123 GtC yr⁻¹）。
::: solution
$875/123 = 7.1$年——翻新而非存续，气候科学里被误引最多的数字。
:::

::: exercise {level=1 check="0.47"}
求排放11.1、大气增长5.2 GtC yr⁻¹的空气分数。
::: solution
$5.2/11.1 = 0.47$——将将一半，文明一直没能交给海洋和陆地的那一份。

::: exercise {level=1 check="16"}
说出Redfield的N:P比。
::: solution
**16:1**——Redfield在浮游生物、河流和深水里发现的那个数，营养盐限制科学的主心骨。

::: exercise {level=2 check="0.5"}
Redfield（16:1）：求充分利用8 µM氮所需的磷（µM）。
::: solution
$8/16 = 0.5$ µM——而当水体带的更少（受施肥的近海就是这样）时，氮过量，反硝化或缺氧来处置它。
:::

::: exercise {level=2 check="32"}
若0.3 µM的磷限制生产力（Redfield C:P = 106:1），求产生的有机碳（µM）。
::: solution
$0.3\times106 = 32$ µM C——其呼吸消耗约32 µM O₂，即算例中的死区算术。
:::

::: exercise {level=3 check="10.0"}
把65 ppm的空气化石碳（δ¹³C −25 ‰）加到280 ppm、−6.5 ‰上，求混合物的δ¹³C（绝对值，一位小数）。
::: solution
$(280\times6.5 + 65\times25)/345 = (1820+1625)/345 = 10.0$ ‰（负）——45%留在空中之世界的Suess预言，与观测相符并闭合同位素收支。
:::

::: exercise {level=3 check="26"}
海洋拿走了1850年以来约670 GtC排放中的约175 GtC。求海洋的百分比份额。
::: solution
$175/670 \approx 26\%$——GLODAP的数字，在科考船上测得，也是"海洋不是无底洞"是一项测量而非模型输出的原因。
