氧是大气的第二气体、生物圈最响亮的废料，也是空气中唯一一种丰度属于**生物学成就、有地质账本**的成分。21%的O₂不是化学的默认值——非生物地球只攒得到千分之一——而这21%的历史是一部**埋藏**史：今天空气中的每一个游离氧分子，都是一个因被埋进沉积物而逃脱氧化的碳原子或硫原子的影子；而O₂曲线的起落（从一丝到35%再落回）记录的是海洋和陆架拒绝呼吸掉多少碳。本课的收官之课是完整的氧循环：现代收支（1989年以来在采样瓶里测量而非模拟）、深时的埋藏账本、晚古生代的火-氧-动物三角，以及课程一直绕着走的问题——生物圈那次伟大的氧化，是一项已完成的成就，还是一个偶然的成就。

## 现代氧收支

::: definition 被测量的大气：O₂收支与它的两只钟 {#def-o2-budget}
大气O₂（20.95%，$1.2\times10^{18}$ t）正在下降，我们知道它精确到每微份，因为**C. D. Keeling及其同事**从1989年开始在采样瓶里测O₂/N₂（Scripps和NOAA的瓶测与连续记录、以"per meg"报告的**O₂:N₂比**以区别于δ¹³C和水汽干扰、2000–2020年代的**Manning、Keeling与全球O₂观测网络**）。收支有两项和一个意外。**化石燃烧**按光合逆反应的化学计量耗氧（每吨碳约2.7吨O₂：carbon-today一课的约10 GtC yr⁻¹要花约27 Gt O₂ yr⁻¹）；**陆地和海洋的汇把它还回来**（净生态系统生产在存碳的同时释放O₂），而测得的**大气O₂下降约每微份25**（相当于全球表观耗氧约4–5 GtC yr⁻¹）与化石燃烧减陆地海洋碳汇之和相符——**与CO₂账目同一笔收支闭合，用一种独立的货币**，是地球系统科学里最优雅的两三笔佐证之一（若汇吸收全部排放，O₂下降应为零；其大小是从还原端看到的空气分数）。意外是**土地利用与海洋项的不对称**：火直接耗氧（生物质燃烧项，2020年代的火-氧研究用O₂:CO₂巧合区分化石碳与火碳——同位素一课的方法换第二个比值），而海洋的氧储量（ocean-cycles一课的2%脱氧）是**另一本更快、更独立的账**——海洋持有的O₂是大气活性翻新的约60倍，正以十年时标因温度和生物失去它，而大气库在它4万年的燃烧钟上移动。两只钟就是本课的框架：**大气O₂是安全的**（人类消耗的是一个4万年的存量；"氧气会用完"的恐惧毫无算术），而**活性氧——海洋的、土壤的、湿地的——正在可见地下降**，而生物实际赖以维生的是活性库，不是大气那座山。收支的前沿是**Δ(O₂/Ar)与δ¹⁸O-of-O₂系统**——**Kaiser、Hendricks与Tans学派**划分陆地海洋汇的O₂:CO₂与O₂:Ar双比值法——同一套超定账目用氧作第二种货币来跑——以及**平流层与中间层臭氧账**（大气化学课程的O₃一课：那个三原子表亲，其恢复是蒙特利尔议定书证明大气化学可以被驾驭）。
:::

::: example 四万年答案 {#ex-o2-safe}
大气O₂为$1.2\times10^{18}$ t；化石燃烧耗约27 Gt O₂ yr⁻¹（10 GtC × 2.7）。求按当前速率耗尽全部存量所需时间；再给定观测下降每微份25（大气持有10⁶ per meg），求**观测**的年分数下降，并用两句话解释为什么两个数字都对、而相关的问题只有一个。
::: solution
存量/燃烧$= 1.2\times10^{18}/2.7\times10^{10} \approx 44{,}000$年；观测下降$25/10^6$ per meg $= 2.5\times10^{-5}$ per meg yr⁻¹ = 每十年0.0025%——两者皆真：第一个说**总**燃烧永远耗不尽这个库（"用完"的恐惧是范畴错误），第二个说**净**汇结构正被实时测量（下降等于燃烧减汇——氧记录是碳收支的独立证人），而相关的问题两个都不是：是海洋、土壤和沉积物的**活性**氧，其翻新以年到世纪计，其下降早已是生态新闻。
:::
:::

## 埋藏账本：空气如何得到它的氧

::: definition 氧作为会计恒等式：碳埋藏、硫埋藏与恒温器 {#def-burial-ledger}
游离O₂只在其还原伴侣**被埋藏快过风化重新暴露**的地方存续，而深时氧曲线——**Robert Berner和Gregory Landis**的GEOCARB与化石炭综合（1993–2001），经硫同位素与微量金属学派修正（**Lyons、Reinhard及其同事**，2009–2014；**Kump与成冰纪氧化**学派）——是一本有三个分录的**埋藏账本**。**有机碳埋藏**是主导项：现代埋藏通量（约0.1–0.2 GtC yr⁻¹，产量的千分之一）是净O₂来源，而其古元古代的翻倍——记录在大型黑色页岩沉积和中洋缺氧中——是**大氧化事件**（24.5–22.2亿年）头号的成因候选，触发之争仍未结束（**Kump、Pavlov和Barley**2000年的镍饥饿假说——地幔镍下降饿死产甲烷菌；超大陆聚合增强的地壳与有机埋藏；**Canfield**的硫化物上涌重组）。**黄铁矿硫埋藏**是第二本账（Δ³³S和δ³⁴S记录：大氧化的黄铁矿激增、2020年代工作的成冰纪与Sturtian同位素漂移）。**风化与热液汇**是借方——在氧化矿物包住地表之前消耗O₂的还原铁和火山气体，从大氧化前奏的条带状铁建造中读出（**Konha、Posth与Isua**文献）。**恒温器**闭环：**Lenton和Watson**的O₂-火-风化反馈（2000）与**Bergman、Lenton及其同事**的火建模综合给O₂一个**下限**（火与风化抵制跌到约15%以下的崩塌）和一个**上限**（火与风化抵制约30–35%以上的失控）——显生宙曲线在这两个值之间的摆动就是恒温器的足迹。**晚古生代峰值**（**Berner和Landis**炭曲线石炭-二叠纪的30–35%）是过冲：广袤的赤道煤沼、加里东-华力西造山带的营养通量、河到陆架的埋藏一起埋了足以让空气氧翻倍的碳，而其后果就是本课的图标——**巨型昆虫**（70厘米的*Meganeura*、2.5米的*Arthropleura*；让昆虫体型成为氧计的气管-气门扩散约束，在**Kaiser和Verbeselt**的高氧饲养实验中被检验）、**第一个全球火制度**（**Scott和Glasspool**的炭综述：志留-泥盆界的第一次全球炭屑，点燃阈值在13–15% O₂附近），以及**二叠纪末下探**（**Grasby与"氧与昆虫灭绝"**的论点：崩塌的O₂帮助修剪了古生代生物群），表明这本账也会**对着**复杂生命结账。**成冰纪与寒武纪问题**——动物之前O₂是否再次上升（**Canfield和Knoll**的成冰纪氧化与**Falkowski**钼的论点），还是最早的动物本就生活在毫摩尔氧中（**Levin与氧最小区**在纳摩尔O₂中繁盛的后生动物的发现、**Gold与"缺氧动物"**学派）——是课程的收官开放问题：**动物生命也许是氧的投机者而非受益者**，而O₂曲线最深的教训也许是：没有哪个阈值是原因。
:::

::: example 火阈值 {#ex-fire-threshold}
实验与地质证据把潮湿植被燃料的点燃阈值放在约13–15% O₂（现代空气：21）。晚奥陶世（450 Ma）有了最早的陆生植物（裸的带角质层孢子，无根、无凋落物）而O₂在13–17%附近（**Edwards与"最早陆生植物"**和**Berner**曲线的重叠），第一次**全球**炭屑出现在中志留世到早泥盆世。用两句话解释为什么火的O₂恒温器让**易燃植物对陆地的占领**与**O₂的上升**成为耦合的序列，以及**Scott和Glasspool**炭记录中志留-泥盆纪最早根系与最早全球炭的巧合对风化反馈意味着什么。
::: solution
植物需要火来回收凋落物、打开生物地球化学的环（炭记录的首次全球出现与维管植物和根系同时——凋落物让火成为可能，根系让风化更快），而火需要O₂在约14%以上——所以越过阈值的O₂**使**火制度成为可能，而火制度（灰分磷、炭碳埋藏、风化加速）**同时反馈**于O₂和CO₂（**Lenton-Watson和Bergman**火恒温器模型的预言，**Berner**曲线晚古生代过冲是其检验案例）：陆地占领不是一次植物学事件而是一次**燃烧系统升级**，而石炭纪的煤——造就35%空气的那次埋藏——就是它的发票。
:::
:::

## 氧的同素异形体与氧的缺席

::: definition 臭氧：氧成盾的同素异形体 {#def-ozone-shield}
高层大气的氧是另一种元素的肉身：**Chapman化学**（Sydney Chapman，1930）在紫外通量与O₂密度共同达峰之处——平流层，15–35公里——创造并毁灭**O₃**，而造臭氧的同一个环也**就是**盾：O₃光解吸收了无盾地表生物无法存活的UV-C和大部分UV-B，而臭氧柱（**Dobson单位**，每单位2.7×10²⁰分子 m⁻²，总柱约300 DU）就是行星的防晒霜，由本课埋藏账本积累的O₂连续制造。大气化学课程拥有催化破坏环（ClO_x、NO_x、HO_x、极地硝酸盐三联与南极春季洞）；生物地球化学课程对臭氧的所有权是**演化**的：紫外屏蔽深度决定**水柱的可居深度和陆地的可居表面**（**Cockell与"紫外与陆地占领"**学派的前寒武纪UV-B致死论点——复杂生命等待平流层臭氧盾、或退到水面下10米，直到O₂曲线造出一个），而**古生代陆地占领**的年代与O₂上升暗示的晚古生代臭氧层加深吻合得可疑地好（**Berner**曲线的重叠）。现代人类世补上反向一课：**蒙特利尔议定书**（1987）——大气一次被成功驾驭的化学，臭氧洞的氯存量在2000年代初达峰、臭氧层在轨到约2066年恢复（**WMO/UNEP评估**与2018年**Ravishankara和Newman**的*Science*论文，定下约60年的恢复日期并把每年避免数百万皮肤癌记在议定书名下）——是课程对以下命题的证明：当化学已知、元凶具名、替代品存在时，大气化学可以被驾驭：三个碳循环和氮循环尚未满足的条件。
:::

::: example 防晒柱 {#ex-dobson}
总臭氧柱300 Dobson单位（1 DU = 2.7×10²⁰分子 m⁻²）。求O₃的柱丰度（分子 m⁻²）；再给定该分子在无过滤的正午紫外下只能活约100秒，用一句话解释为什么这个柱竟能持续存在，以及南极春季60%的季节损失在地表生物有效紫外上值多少。
::: solution
柱$= 300\times2.7\times10^{20} = 8.1\times10^{22}$分子 m⁻²——一个若不连续制造几天就会消失的柱，Chapman化学的**通量储库**（生产等于损失；这个柱是造与毁的驻波，像大气化学课程的自由基库）；南极春季洞在峰值把地表UV-B放大2–4倍（**Blumthaler与"紫外与臭氧洞"**的测量），足以损伤浮游植物光合（**Cullen和Neale**学派的浮游植物紫外抑制实验）——而在议定书之后，是一场关于无屏蔽生物圈会作何感受的常驻演示。
:::
:::

::: definition 现代缺氧：死区与硫化问题 {#def-modern-anoxia}
元古宙深海缺氧的回归是深时的警世故事；**现代**缺氧问题更小、更快、而且已经到来：近岸死区（墨西哥湾、波罗的海、黑海陆架、东海岸潟湖——**Diaz和Rosenberg**全球图集，2008年，约500个系统，以及**Breitburg与"下降的氧"**2018年更新：富营养化加增温加层结）、**大洋氧最低区**其变浅把亚氧化化学（反硝化、N₂O，以及——陆架够远的话——硫化物）带进渔场的深度范围，以及**硫化阈值问题**：有没有哪个现代系统从缺氧跨进真正的硫化、光合绿硫细菌水域（**Fjord与"现代分层湖"**类例——黑海浅的缺氧但非硫化水柱、硫酸盐还原与光相遇的峡湾和盐池）？诚实的答案是**大洋硫化尚未，但沉积物孔隙水和最富营养的底层水域已经是**，而本课的要点是那个**序列**：缺氧 → 反硝化与N₂O → 硫酸盐还原与硫化 → 绿水透光事件，一架二叠纪-三叠纪爬到底的梯子（最大灭绝绿水浅滩的异还原烷生物标志物），而近海正一级一级、一季一季、一区一区地往上爬。
:::

::: example 一个海盆的氧钟 {#ex-basin-clock}
一个富营养化的近岸海盆，500 km²、平均深度20米，底层水氧50 µmol kg⁻¹（缺氧阈值64、通风时间3个月、表层沉积物需氧20 mmol m⁻² d⁻¹）。求海盆阈值以下的氧存量（摩尔）、通风停止后到无氧的天数，以及富硫酸盐海洋海盆里无氧之后的生物地球化学阶段。
::: solution
底层水体积$= 500\times10^6\times20 = 10^{10}$ m³，质量$\approx 10^{13}$ kg；存量$= 10^{13}\times50\times10^{-6} = 5\times10^{8}$摩尔；此水平下全水柱需氧$\approx 5\times10^{8}$摩尔 d⁻¹，所以通风一停，从缺氧到无氧**约1天**——死区夏天的悬崖边——而下一阶段是**硫化**：硫酸盐还原接管，光到处变绿黑，缺氧阶段的鱼灾之后是硫化阶段的无脊椎动物死亡，同一架梯子，二叠纪末的记录一路爬到顶端。
:::

::: warning 氧不会用完但活性氧在下降，O₂曲线不是因果机，石炭纪"木质素缺口"是故事不是事实，氧恒温器不是承诺，而动物也许并不需要我们以为它们需要的东西
五个错误。**"CO₂升意味着O₂降——我们会窒息"**：算术（4.4万年的燃烧对着全部存量；观测下降每十年0.001%）让窒息不可能——O₂下降是**测量工具**，不是威胁，把两者混为一谈是把错的论点递给对的人。**"大氧化造就了动物生命"**：大氧化与最早动物之间20亿年的空档（以及**Levin与"氧最低区动物"**的结果——有些活动物在纳摩尔氧中繁盛，以及**Knoll与"氧与动物"**学派较软的"许可而非教导"立场）打断了简单因果链——O₂记录是一个**条件空间**，不是触发清单，诚实的表述是：动物耐受的氧区间比我们假设的宽，而利用的比我们设想窄。**"石炭纪氧峰是因为真菌还没学会腐烂木质素"**："木质素缺口"是地学最爱的巧说故事；**Floudas和Hibbett**白腐起源工作（2012）把降解木质素的真菌放在木质素植物石炭纪统治**之前**（缺口是幽灵），而峰值更应由**真实的**埋藏机制承担——广袤赤道泥炭沼（煤系）、加里东-华力西风化营养通量、以及陆架埋藏——教训是：漂亮的假说和漂亮的化石蜻蜓可以同时为真，而因果故事是错的。**"O₂恒温器永远保证15–35%"**：恒温器的边界取决于**陆生生物**（火-风化反馈预设维管植物和凋落物——志留-泥盆纪的跨越表明边界是**与生物谈判**出来的，而二叠纪末可能低于12%的短暂下探表明下限在大火成岩省事件期间可被局部突破），一个失去森林或泥炭沼的生物圈会重新谈判合同——恒温器是**过去4亿年被证明的倾向**，不是定律。**还有"海洋脱氧与大气O₂下降是同一个问题"**：它是相反的问题——大气库巨大而慢，海洋的库是活性的、已经降了2%，带着栖息地、渔业和N₂O的后果（ocean-cycles一课），两者只通过共同的驱动（增温、营养、环流）相连——而具政策意义的事实是：**要紧的氧问题是地方的、快速的、已经到来的**，而人人害怕的那个三样都不占。
:::

::: history
氧的故事始于发现者们的擦肩而过：**Carl Wilhelm Scheele**（1772）和**Joseph Priestley**（1774）各自制出"脱燃素空气"却错过其意义；**Antoine Lavoisier**的燃烧与呼吸化学（1770–80年代）为氧命名并使之成为碳的镜子；**Jean Senebier和Nicolas-Théodore de Saussure**在1804年前闭合了光合作用方程。埋藏逻辑在世纪中叶的海洋地球化学学派中成为标准（1950–60年代有机碳埋藏的氧算术、**Hutchinson和Redfield**的营养框架、1960年代白垩纪海洋缺氧事件的发现），而**Wallace Broecker和Tsung-Hung Peng**的示踪剂时代综合（1982–1991）给了氧-营养地理其现代形态。深时曲线：**Robert Berner**的GEOCARB系列（1991–2009）与**Berner和Gregory Landis**用化石炭做的氧古压力计（1993–2001，USGS的炭计数把一条模型曲线变成一项测量）；**J. Kirw. Kump、James Kasting和Joseph Crane**的成冰纪氧化论点（1992）；**Donald Canfield**的硫与氧的元古宙（1998）；**Kump、Pavlov和Barley**的镍假说（2000）；**Lyons、Reinhard与微量金属**修正（2009–2014）；以及让木质素缺口故事退休的**Floudas和Hibbett**白腐真菌起源研究（2012）。现代测量时代：**Ralph Keeling与Scripps-NOAA氧计划**（1989年起的瓶记录、**Manning和Keeling**全球网络）、**Tans、Kaiser及其同事**陆地海洋汇的O₂:CO₂与O₂:Ar双比值划分（1990年代至2020年代）、2000年代反演学派的模式反演氧收支，以及**Stramma、Breitburg、Deutsch及其同事**的海洋脱氧综合（2010年代）——氧循环现在是唯一**两个**储库（气与海）都在十年记录上被测量、而其历史用炭、硫、钼和灭绝昆虫的体型来读的主要生物地球化学循环。
:::

::: quiz
大气中每个游离O₂分子最终平衡于：
- [ ] 此刻某处正在发生的光合作用。
- [x] 一个被埋进沉积物、快过再氧化的碳原子或硫原子。
- [ ] 火山脱气。
- [ ] 臭氧光解。
::: solution
氧是一项**埋藏信用**：总光合与总呼吸相消；只有逃脱氧化的还原原子（有机碳、黄铁矿硫）把它们的氧等价物留在空气里——这就是为什么O₂曲线追踪煤、黑色页岩和黄铁矿记录，也是为什么燃烧那些矿藏就是在花这笔信用。
:::

::: summary
氧是生物圈的资产负债表：空气的21%，在Keeling瓶记录中测得每年下降每微份25——化石燃烧减碳汇的确切氧成本，碳收支的独立证人。深账本是埋藏：有机碳和黄铁矿硫逃脱氧化，建成了大氧化、晚古生代35%的峰值（煤沼、风化、第一个全球火制度、巨型昆虫）和中生代的谷；Lenton-Watson的火-风化恒温器把空气维持在约15%到35%之间，一个与生物谈判而非由物理保证的倾向。现代的悖论是两只钟：大气氧够烧4.4万年，而活性氧——海洋的已降2%、土壤的、湿地的——正处于可见的、生态上有后果的下降。课程的最后一课留下它最后的开放问题：动物崛起是因为空气被氧化了，还是仅仅因为氧化打开的那扇窗——而在一个脱氧的海洋里，这个答案是否仍比氧本身更要紧。
:::

一个海洋脱氧收支把下降项归为40（溶解度）、20（环流）和40（生物）。若增温让生物项翻倍，求其新的总量份额（百分比，取整）。
