磷和硫是碳循环和氮循环年长的兄姐——一个没有天空，一个被天空纠缠。**磷**没有重要的气相：它的循环始于岩石、穿过生命时住在运转每个细胞能量经济的磷酸酯里、终结于沉积物，在那里等待下一次造山运动数千万年。这一个设计缺陷——没有大气缓冲、没有快储库——让磷循环成为地球上**一种元素的地质稀缺与一个生态系统的局部富余能够并存**的唯一之处：我们一个世纪采出风化要一千年才送到的磷酸盐、半浪费地喂给作物、用剩下的淹死湖泊和海岸，而矿山有限的矿石（三分之二在一个国家的地下）设下了其他任何营养盐循环都没有的期限。**硫**性格相反：从硫化物到硫酸盐的四个氧化态、一个播云并携带海洋气息的生物气相（DMS），以及作为**氧的影账本**的深时角色——埋在沉积物中的黄铁矿就是大氧化事件的账簿，而其同位素指纹就是我们读出大气最初转向氧化之年代的办法。本课就是这两个循环，以及它们与课程上一课所讲氧气故事的纠缠。

## 磷：岩石循环

::: definition 没有天空，没有缓冲，没有第二次机会 {#def-phosphorus}
磷酸盐（$\mathrm{PO_4^{3-}}$）是生命的**能量货币与信息骨架**（ATP、DNA、RNA、磷脂），生物圈贪婪地持有并循环它（Redfield比的123个原子中占1、细胞与土壤内快速的再循环），但**全球供应由岩石设定**：大陆壳的火成磷灰石以约0.02–0.04 Tg P yr⁻¹的自然速率风化入河入海、埋进海洋沉积物、再按造山时钟由抬升归还。设计后果就是本课：**没有气相缓冲**意味着没有全球再分配、没有大气自我纠正，而**局部的、实际上不可逆的稀缺与过剩并存**；**没有快的非生物汇**意味着加入的磷几十年保持生物有效（不像氮会反硝化掉——淡水与湖泊管理是磷问题而海洋的是氮问题的原因）；而**有限矿石**意味着循环的人类阶段有供应侧：采矿业现在每年采出**约2.2亿吨磷矿**（约20–30 Tg P，按多数账目**比自然风化高约一个数量级**），集中得可怕——**摩洛哥与西撒哈拉持有世界储量的约70%**（约70 Gt中的50），而另两个历史支柱中国和美国已在下降——这就是**"磷峰值"**文献的原因——2009–2013年**Dana Cordell、Sten Åke Sverdrup与Cordell-White学派**的争论说的不是磷会用完，而是**地质、地缘与品质在稀缺咬人之前先恶化**（磷酸盐粉尘、贫矿的镉与铀含量、各自引发抢购恐慌的1970年代与2008年化肥价格冲击）。人类收支的另一半是浪费：**田间利用效率约20–25%、从矿山到餐桌约15%**（**Cordell和White**的"从矿山到餐桌到海洋"链条），所以加入农田的磷作为**土壤遗产**积累（几十年盈余建进大陆土壤，如今是一个**即使明天停用化肥**仍将继续向溪流泄漏几十年的储库——"遗产磷"文献对湖泊恢复的冷安慰）、经**侵蚀**流失（暗管排水、侵蚀中的玉米带以让密西西比负荷成为经典案例的速率输出溶解态与颗粒态P），并抵达水体，而那里的**营养状态算术**毫不留情：总磷超过约35 µg L⁻¹就让温带湖泊富营养（**Dillon与Vollenweider**的负荷-浓度模型、N-1000与OECD富营养化调查谱系）、蓝细菌水华（伊利湖西盆地的微囊藻毒素与类毒素季节，其2014年"请勿饮用"通告让50万托莱多居民没有水——大湖水系里最富农业的流域对一座城市做的事，正如波罗的海的富营养化对其海岸线做的事），而缺氧随水华的呼吸而来。恢复记录就是本课的希望与警告：**1972年《大水质协议》**的磷上限**奏效了**（伊利湖的清澈与渔业十年内回归——地球上最成功的一次富营养化逆转），而水华在2000年代**还是回来了**，因为源的结构从点源污水磷转向**由暗管与暴雨径流携带的溶解态化肥与粪肥磷**（溶解分数现在占主导、对藻类立即可用、任何污水厂都不处理），土壤遗产释放着1970年代盈余存下的东西——这个案例研究让磷成为其政策教训是"**点源是容易的一半；景观才是难的一半**"的循环，而其全球未来（2020年代非洲与南亚的化肥扩张、磷稀缺对富营养化的双重束缚）是氮一课的双胞胎，写在岩石里。
:::

::: example 湖泊的账 {#ex-lake-P}
一个体积$10^9$ m³的湖泊每年完全更新5次，接收总磷负荷150吨 yr⁻¹。用稳态箱式模型$C = L/(Q/V)$（无内部加载）求浓度并划分营养状态；然后用一句话解释为什么真实的湖泊会超过这个数字、而清理为何滞后。
::: solution
冲刷体积$= 5\times10^9$ m³ yr⁻¹，所以$C = 150\times10^6\ \mathrm{g}/5\times10^9\ \mathrm{m^3} = 30$ µg L⁻¹——纸面上贫到中营养；真实湖泊超过它是因为**内部加载**（厌氧夏季从沉积物释放铁结合磷——让浅湖即使外部负荷下降仍被锁在浊水蓝藻状态的内部循环、**Moss与Scheffer/Carpenter的稳态转换**框架）和**土壤遗产**（仍在流域中渗流的几十年盈余）——这就是为什么设定1972年上限的Vollenweider模型对目标是对的、对速度是乐观的，也是为什么伊利湖2010年代的复发是磷循环论证最充分的寓言。
:::
:::

## 硫：氧的影账本

::: definition 硫的四世为人：黄铁矿、硫酸盐、DMS，以及同位素档案 {#def-sulfur}
硫循环穿过**四个氧化还原态**——硫化物（S²⁻，在黄铁矿与缺氧水中）、元素硫、以及硫酸盐（$\mathrm{SO_4^{2-}}$，氧化海洋的主导阴离子，28 mM）——而其现代循环是一个**双回路系统**：**慢地质回路**（沉积物中的黄铁矿埋藏、这些沉积物在抬升处的氧化风化、控制数百万年大气O₂的净通量，因为**埋硫化物意味着埋掉本会被消耗的氧等价物**——与碳相同的有机碳埋藏逻辑，黄铁矿作为深时预算一半的还原电子载体），以及**快生物-表层回路**（硫酸盐还原菌——**脱硫弧菌谱系、Postgate学派**——呼吸海洋沉积物中一半的有机质，让硫酸盐还原成为**地球上仅次于氧的第二重要呼吸路径**，并把臭鸡蛋与泥滩化学交给海洋；其硫化物的再氧化、或以黄铁矿埋藏，就是账本的借与贷）。**气相**是生物学的贡献：浮游植物（球石藻、甲藻、以及从太空可见的**Emiliania huxleyi**水华）合成**DMSP**——二甲基巯基丙酸内盐，可以说是地球最丰富的有机硫化合物，为渗透与氧化胁迫而造——而细菌与病毒的裂解把它变成**DMS**，每年约15–30 Tg S进空气，那个给海以其气味的化合物，其氧化产物（甲烷磺酸盐、非海盐硫酸盐）**在海洋上空为云凝结核播种**——**CLAW假说**（**Charles Lovelock、Robert Charlson、Meinrat Andreae、Stephen Warren**，1987）的基础，那个带盖娅色彩的提案：DMS闭合一个稳定气候的反馈（更暖 → 更多DMS → 更多云 → 更冷），其**符号**仍未解决（2010年代的海洋增温与酸化实验显示两种符号的DMSP响应，而海洋的DMS通量尚无确认的气候反馈），其持久的贡献是被证明的事实：**生物圈在行星尺度调节一个与云有关的气溶胶前体**。人为硫的故事属于大气：煤与冶炼厂的SO₂造成了**酸雨**年代（1970–80年代——瑞典与加拿大的湖泊之死、哈尔茨山的森林退化、阿迪朗达克的化学、以及以预测成本一个分数把SO₂削减90%的1990年美国清洁空气法**总量交易**——acid-deposition一课的胜利），以及它的**无意实验**：船用燃料的**IMO 2020硫上限**（3.5%到0.5%，把海运SOx削减约80%、约4 Tg S yr⁻¹）在2020年1月移去了繁忙的太平洋与大西洋航线上空一面明亮的帷幔，而随之测得的**约0.1 W m⁻²失去的冷却**是有史以来对气溶胶辐射强迫最锋利的自然实验——这就是为什么硫循环的现代教训是**揭面纱交易**：我们一直在用我们的硫给行星降温，而每一次清洁空气的胜利都**揭开**我们存下的增温的一个分数（气溶胶强迫文献量化的**揭面纱存量**：剩余约0.4–0.5 W m⁻²的气溶胶冷却、2022年**Richardson及其同事**的*Nature*"峰值烟灰"论点——海运与清洁空气的硫削减加速，已越过气溶胶冷却的极大值，在温室气体强迫之上加了一个台阶的额外增温）。深时账本与氧气一课闭环：太古宙沉积物中保存的**非质量依赖硫同位素分馏（Δ³³S）**（**Farquhar、Johnston、Wing和London**2000–2007年的非质量硫工作）就是无氧大气指纹——只在没有臭氧盾时才运作的紫外硫光化学——而它们在24.5亿年的消失，连同黄铁矿埋藏记录与**Canfield海洋**假说（**Donald Canfield**，1998：元古宙贫硫酸盐、富硫化物的中层海），就是大氧化叙事的同位素骨架。
:::

::: example 皮纳图博的硫收支 {#ex-pinatubo}
1991年皮纳图博喷发向平流层注入了约20 Tg的SO₂（以硫计），几乎全部转化为H₂SO₄气溶胶（摩尔质量：S 32、H₂SO₄ 98）。求产生的气溶胶质量；再给定随后一年观测到的约−2 W m⁻²全球辐射强迫，用$\Delta T \approx F/3.2$（K每W m⁻²，Planck反馈值）估计全球温度响应，并与观测的约0.5 °C下探比较。
::: solution
20 Tg是SO₂，所以硫是$20\times32/64 = 10$ Tg、H₂SO₄$= 10\times98/32 \approx 30$ Tg——那个三周内环绕全球的约3,000万吨平流层硫酸盐云；强迫估计$-2/3.2 \approx -0.6$ °C，在观测约0.5 °C下探的误差内（多余的冷却被陆地与冰的几何阻尼）——这个练习就是气候敏感度的火山校准，也是为什么每个地球工程"太阳辐射管理"数字都是一次皮纳图博外推，也是为什么**非故意的**皮纳图博的酸沉降、臭氧损失与生态系统效应是SRM辩论诚实的对照组。
:::
:::

## 海洋的磷：失踪的磷问题

::: definition 海洋磷循环与其未清的账户 {#def-marine-P}
海洋的磷账本是生物地球化学课程最顽固的未闭合收支。河流溶解磷输入（约0.02–0.06 Tg P yr⁻¹，被人类翻倍）相对海洋的磷酸盐存量与其约25,000年的周转时间显得微小，而经典的谜题——**失踪的磷**——是：按Redfield比例，海洋氮反硝化（约200–300 Tg N yr⁻¹）隐含的**需求**将要求**远大于河流送到的**磷供应，而海洋除非靠抽低其存量否则无法维持——除非(a)**溶解有机磷**库（**Dale Karl及其同事**夏威夷海洋时间序列的"微生物磷泵"——让微生物在磷酸盐短缺时开采有机P的碱性磷酸酶机器，让海洋P循环在很大程度上是**开放且内部再循环**的而非河养的）、(b)**非Redfield化学计量**（区域N:P为10–30、**Granger、Deutsch及其同事**的地图）、或(c)**隐藏来源**——热液喷口、自生矿物与边界沉积物通量，2010年代量化——补上差额。现代综合——碳酸盐与边界通量地球化学的**Andrey Paytan、Gideon Goldhammer与Poulton学派**——认为河流送到的**总磷多于旧的溶解数字**（颗粒与尘埃结合的P，其大部分在贫营养热带是生物有效的、由2020年代沉降网络追踪的撒哈拉尘埃P对大西洋的施肥）、自生碳酸盐与铁磷穿梭缓冲深海记录，而海洋的磷存量比教科书周转时间暗示的**更年轻也更活跃**——一个带深时转折的结论：**成冰纪与寒武纪磷块岩矿床**——元古宙末与寒武纪初的大磷块岩矿——一个超大陆风化磷洪水的沉积记录，按**Cook与Fölling学派**传统的读法，是磷循环最有分量的一句话，也是这个元素现代稀缺对过剩的双重束缚在深时上就是微生物海洋与动物海洋之别的原因。
:::

::: example 当比值破裂：作为海洋恒温器的固氮 {#ex-np-thermostat}
东地中海表层N:P ≈ 6:1（硝盐0.3 µM、磷酸盐0.05 µM），对Redfield的16:1。求相对Redfield需求每单位磷的氮缺口，并用两句话解释为什么这个比值违背是**Deutsch调节**观点——海洋固氮响应以闭合缺口——的最强证据，以及什么限制了这个响应。
::: solution
0.05 µM P的Redfield需求是0.8 µM N——缺口$0.8-0.3 = 0.5$ µM N，一个**被自身化学计量饿氮**的海洋的签名；固氮微生物（*Trichodesmium*、单细胞蓝细菌）应在水华里用掉未用的磷、添加氮直到比值回到16附近——那个让海洋氮存量不崩溃的负反馈——而响应受**铁、磷有效性与混合**限制，同样是让调节真实但漏水的共同限制，海洋的恒温器设得松而非紧。
:::
:::

## 硫的地方账：酸性矿山排水

::: definition 酸性矿山排水：硫的采矿遗产 {#def-acid-drainage}
当采矿把含硫化物的岩石——煤系、金属矿脉与尾矿的黄铁矿（$\mathrm{FeS_2}$）——暴露给空气和水，硫循环就以实验室速度跑它的氧化回路：$\mathrm{FeS_2 + 3.75\,O_2 + 3.75\,H_2O \rightarrow Fe(OH)_3 + 2\,SO_4^{2-} + 4\,H^+}$，每吨黄铁矿产出**1.67吨石灰当量的酸**，把同一块岩石里携带的携带的铜、锌、砷和铀，并沉淀出覆盖下游溪流的橙色"黄小子"铁絮。反应是**自催化**的：pH约3以下三价铁取代氧气做氧化剂、微生物铁氧化菌（*Acidithiobacillus*与**Johnson和Kelly学派**生态生理学的嗜酸铁氧化菌）让它更快，而矿堆**无论矿还开不开**都会排水**几个世纪**——莱茵河的Abensberg、威尔士煤田、阿巴拉契亚与南非案例，全球处理负债以百亿美元计，而鲁尔区的矿坑排水泵按比二战还老的排班表运转。酸性矿山排水是硫课对磷之土壤遗产的地方双胞胎——**两个循环都用几代人的修复尾巴惩罚动员的那个世纪**——而其预防（干封盖、水下尾矿、源头加碱）只花末端处理的零头，与级联同样的经济学，学了两次。
:::

::: example 酸性矿山排水：黄铁矿的账单 {#ex-pyrite-acid}
黄铁矿氧化按$\mathrm{FeS_2 + 3.75\,O_2 + 3.75\,H_2O \rightarrow Fe(OH)_3 + 2\,SO_4^{2-} + 4\,H^+}$进行：每摩尔黄铁矿（120 g）释放4摩尔酸，相当于（每CaCO₃两个H⁺）2摩尔（200 g）石灰石。求1吨暴露的废矿黄铁矿的酸负荷（以CaCO₃当量计），并说明为什么反应的自催化（低pH下的Fe³⁺氧化剂）让废弃矿山成为硫循环最慢的遗产。
::: solution
每吨黄铁矿$200/120 = 1.67$吨CaCO₃当量的酸——而不同于一个烟囱，源头关不掉：一旦废石堆被通风、pH降到约3以下，三价铁来做氧化，反应按自己的节奏跑，排水持续**几个世纪**（莱茵河的Abensberg与威尔士、阿巴拉契亚煤田案例，每个场点的处理账单高达数十亿美元）——硫课对磷之土壤遗产的地方双胞胎：两个循环都用几代人的修复尾巴惩罚动员了它们的那个世纪。
:::

五个错误。**"我们的磷快用完了"与"磷无处不在"都真也都不完整**：矿石有限且地质上集中（以世纪计的供应侧风险、2030年代的一个地缘政治问题），而**循环的吞吐**翻倍、其废物正在富营养化海岸——危机是**分配与效率**，不只是耗竭，而解决每一半的政策（尿液回收、鸟粪石回收、粪肥对地比例、饮食）就是同一批政策，这就是为什么磷共同体的"营养盐级联"框架（**Smil、Cordell、Rockström行星边界**账目）把稀缺与富营养化当作一个中间坏了的问题。**"磷峰值意味着2030年饥荒"**：磷峰值文献诚实的主张是**价格与品质**（矿石品位下降、镉、能源与运输成本、出口集中），不是耗竭——磷矿按当前用量还能用几个世纪；饥荒框架是一个修辞错误，让严肃的供应风险文献（**Cordell和White**的效率与治理议程）倒退了十年。**"CLAW已被证明/CLAW已死"**：两个过头话——DMS到云凝结核的联系被观测到，其**气候反馈符号**未解决（增温可能增加也可能减少群落的DMS生产；2010年代海洋酸化在一些实验中抑制DMSP、在另一些里不抑制），而诚实的表述是**一个生物学产生的、有气候意义的气溶胶前体存在，而其反馈未被测量**——云物理学最大的开放问题之一，也是对任何方向上自信的地球系统陈述的常驻反驳。**"既然硫的揭面纱在增温，清洁空气对气候有害"**：算术是真的（IMO 2020的台阶约0.1 W m⁻²的额外强迫、剩余气溶胶存量约0.4–0.5），而结论既可憎又错——冷却的硫就是杀人的硫（剩余气溶胶的颗粒物死亡负担，每年以百万计，压过同一团空气里被揭开的增温的预测危害），而正确的读法是**气溶胶遮蔽从来不是一个政策选项，只是一笔债**，而唯一能同时付两笔账的杠杆是CO₂（2020年代"峰值烟灰"论点的实际用途：抬高温度目标的**紧迫与清醒**，不是为清洁空气法辩护）。**还有"深海缺氧硫化海洋是元古宙的奇闻"**：Canfield中层硫化的争论且不论，**现代海岸硫化正在扩张**（黑海150万km²的硫化水、波罗的海新的缺氧海盆、随有机雨增强先转硫酸盐还原再转硫化物积累的死区沉积物——作为富营养化到硫化连续体的**波罗的海与黑海**系统），而硫循环的深时教训——缺氧加硫酸盐加阳光造出**硫化氢**，那个杀死海岸、并在二叠纪-三叠纪也许帮着杀死行星的气体（最大灭绝硫化浅滩的绿硫细菌生物标志物与钼同位素证据）——是一条写在唯一见过其发生的档案里的警告。
:::

::: history
磷的故事始于**Hennig Brand**1669年从数千升尿液中蒸馏出磷（炼金术士的最后一次，也是营养盐循环最生动的起源传说）；**Liebig**1840年的学说以及随之而来的**鸟粪与骨粉热潮**（1840–70年代——第一次全球营养盐商品泡沫与崩盘，以及预演磷矿资源地缘的鸟粪战争）；二十世纪的**瑙鲁与巴纳巴**岛采矿悲剧，其复垦纠纷拖到2000年代；1947年后酸解过磷酸钙的工业化（田纳西流域管理局与佛罗里达硬岩带）；以及湖泊科学的觉醒——**OECD富营养化调查（1969–76）**、**Robert Vollenweider和Richard Dillon**的负荷-浓度模型（1968–75，**1972年大水质协议**背后的算术，历史上最成功的营养盐政策）、其2000年代跌入**遗产磷文献（Sharpley及其同事）**的复发、以及仍在进行的密西西比缺氧与波罗的海行动计划。硫的科学从拉瓦锡的硫化物化学与十九世纪的硫酸工业（接触法，1875），经过**酸雨的发现**——**Wright和Henriksen**的斯堪的纳维亚湖泊调查、Hubbard Brook的硫酸盐发现、1976年瑞典化学委员会报告创造了那个时代的政策词汇——以及**1990年清洁空气法第四篇的总量交易**（以远低于预测成本削减SO₂约90%的市场设计胜利）。海洋硫与DMS这条线：**贝耶林克**的*Spirillum desulfuricans*（1915）与**Postgate学派**的硫酸盐还原菌生理学；**Charlson、Lovelock、Andreae和Warren**1987年的CLAW论文；**Andreae-Crutzen**全球硫收支（1997）与**Lana及其同事**的全球DMS通量综合（2011）；以及把一项航运法规变成史上最大刻意气溶胶实验的**IMO 2020**监测论文（2020–2023）。同位素档案：**Farquhar、Johnston、Wing和London**的非质量硫发现（2000–2007，无氧大气指纹）、**Donald Canfield**1998的元古宙硫化假说，以及**Lyons、Reinhard与微量金属学派**对它的钼与硫同位素检验——深时硫循环现在是给其他世界读氧的模板，Δ³³S签名是下一代系外行星与火星地球化学的搜寻目标。
:::

::: quiz
淡水富营养化通常受磷而非氮控制，是因为：
- [x] 固氮生物能缓解氮短缺，所以加的磷会持续抬高生产力；磷没有类似的缓解。
- [ ] 湖泊里根本没有氮。
- [ ] 磷会蒸发到空气里。
- [ ] 氮对藻类有毒。
::: solution
在氮能被固定的地方（磷丰氮缺时蓝细菌水华），氮自给自足而磷仍是约束——**David Smith和David Schindler**的综合（实验湖区的全湖添加、2008年定下争论的*Science*论文）——这就是为什么湖泊管理给磷设上限，也是为什么磷一到蓝细菌水华就自己固氮。
:::

::: summary
磷从岩石循环到海洋，没有大气的绕道，而每个后果随之而来：供应由风化与采矿设定（每年2.2亿吨矿石、储量70%在一个国家的地下）、稀缺与富营养化是一个分配问题、一个在停用化肥后仍会漏几十年的土壤遗产、以及一个证明点源是容易一半的恢复记录（伊利湖1970年代的成功、2000年代的复发）。硫带一个生物气相穿过四个氧化还原态循环：黄铁矿埋藏是深时氧账本的一半（Δ³³S档案与Canfield海洋就是我们的读法）、DMS是生物圈的播云排放（CLAW的符号仍未测）、而人为SO₂既是酸雨之恶也是气溶胶面纱——其持续的移除（IMO 2020上限约0.1 W m⁻²的台阶）正是气候系统现在在付账的揭面纱。两个循环都是氮一课的镜子：磷展示了没有天空也没有出口时会怎样；硫展示了当天空是一个垃圾场、然后突然变干净时会怎样。
:::
