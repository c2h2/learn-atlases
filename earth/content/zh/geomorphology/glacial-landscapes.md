冰盖与冰川今天移动不到十分之一的陆地表面、但它们塑造了也许三分之一的陆地、而在更新世它们移动的沉积是全世界所有河流携带的三十倍。它们在底部做工作、在一个由变形的底碛与加压的水组成的薄层里、这是地球上最难接近、而后果最重大的环境之一、而它们留下一个无法混淆的、而直到最近四十年几乎完全无法解读的地表。

## 冰对冰的侵蚀

::: definition 磨蚀与拔蚀 {#def-erosion-processes}
**磨蚀**是被底碛拖曳或被冰持有的岩块对床的切割、而它产生**擦痕**（几十微米到几厘米深的沟、其方位给出流动方向）、**抛光与有棱面**的面、以及**撞痕**（角指向下游的月牙形坑）。**拔蚀**（扯取、撕裂）是床处岩块的破裂与移除、而它产生一个**羊背石**的**迎-陡**形态：一个被磨蚀、被擦痕的缓坡、冰在其上滑过、而一个陡的、被拔出的、不规则的陡坡、冰离开岩石之处。拔蚀需要**在床处等于或高于上覆压力的融水**、它以水力楔开节理、并举起冰、而它因此集中在床软、有效压力低、而冰暖且底温之处。冷底的、冻结的冰既不磨蚀、也不拔蚀、而**床的热制度**因此是冰川在哪里侵蚀的第一控制。
:::

::: definition 底部滑动与有效压力 {#def-sliding}
一个温冰川在其床上滑动当**底部剪切应力**
$$
\tau_b = \rho_i\, g\, H \sin\alpha
$$
达到50–150千帕、这是大多数结晶岩与许多沉积岩的强度。滑动被**有效压力**$N = P_i - P_w$抵抗——冰的上覆压力减去床处的水压——而滑动定律采取的形式是
$$
u_b = C\,\frac{\tau_b^{\,n}}{N^{\,m}},
$$
$n \approx 1$–$3$、$m \approx 1$。关键的后果是一个**高的水压促进滑动**：一个其床变成充水的冰川滑动更快、变薄、而失去质量更快、这就是为什么格陵兰与南极洲的海终止冰川以干摩擦模型无法解释的方式对表面融化敏感。在一个**可变形的床**上，冰可能几乎完全不滑动；而是底碛自己在0.1–1米的厚度上剪切、而冰川的底部运动是底碛的粘性流。
:::

::: example 底部的应力 {#ex-basal}
一个300米厚的冰川以一个$1.2^\circ$的表面坡度流动、其底部水压等于冰的上覆压力的85%。求底部剪切应力、有效压力、以及若水压升到上覆压力的95%、取$m = 1$，滑动速度会上升的因子。
::: solution
$$
\tau_b = 900\times9.81\times300\times\sin 1.2^\circ = 900\times9.81\times300\times0.02094 = 5.5\times10^{4}\ \mathrm{Pa} = 55\ \mathrm{kPa},
$$
$$
P_i = \rho_i g H = 900\times9.81\times300 = 2.65\ \mathrm{MPa}, \qquad
N = (1 - 0.85)\times2.65 = 0.40\ \mathrm{MPa}.
$$
在95%的水压，有效压力降到$0.05\times2.65 = 0.13\ \mathrm{MPa}$、低三倍的因子、而$m = 1$时滑动速度上升
$$
\frac{u_2}{u_1} = \frac{N_1}{N_2} = \frac{0.40}{0.13} = 3.0 .
$$
底部水压上升百分之十**使冰川的速度三倍**。这是观察到的格陵兰出口冰川在一个表面融化事件后的加速、Alpine与南极出口冰川的季节速度振荡、以及一个变暖的气候能通过**润滑其床**、不是通过融化冰来加速冰排放的假说的物理基础。

55千帕的底部应力在50–150千帕范围的低端、这告诉我们这个冰川不受床的强度限制、而受它自己的通量限制——一条**快速流动**的冰流、不是一个陡的Alpine冰川。
:::
:::

## 被雕刻的表面

::: definition 侵蚀的冰川地貌 {#def-erosional-forms}
一个**冰斗**是一个陡头的、被加深超额的盆地、在一个冰川的源头、由旋转滑动、后壁的拔蚀、与融水侵蚀的组合形成、而其后壁的后退在两个冰斗之间留下一条**刃脊**、在三个或更多之间留一个**角峰**（一个金字塔形的高峰）。一个**冰川槽谷**（U形谷）是一个横截面是一个钝的U、有一个平底与陡壁的谷、当一个冰川加宽、加深、并拉直一个先存的V时产生；它的诊断特征是**截断的**山嘴、其溪流落到干流的**悬谷**、海平面之下的**超额加深**、与口的**岩槛**。**峡湾**是一个被海淹没的冰川槽谷、通常超额加深到海平面以下一千多米、并在口被一个底碛的**槛**封闭。一个**珠串湖**是沿一个槽谷的一串超额加深的盆地之一。**冰川电锯**是观察到的在先前冰的平衡线高度附近的山峰上的**高程夹持**、它限制了在更新世被冰川作用的山脉的高度、而这是冰川、不是河流、设定冰川作用的山地的起伏的最有力的证据之一。
:::

::: example 电锯是真的吗？ {#ex-buzzsaw}
一条山脉有2100米的平均岭脊高程、与从1900到2400米的高峰高程范围。更新世平衡线高度（ELA）被重建为1850米、而这条山脉最高的高峰与另外三条ELA为1200、1600与2500米、平均岭脊高程为1450、1900与2750米的其他山脉位于同一纬度带。检验电锯假说、并估计隐含的侵蚀速率。
::: solution
四条山脉的平均岭脊高程与ELA之比是
$$
\frac{2100}{1850} = 1.14, \quad
\frac{1450}{1200} = 1.21, \quad
\frac{1900}{1600} = 1.19, \quad
\frac{2750}{2500} = 1.10,
$$
平均1.16、而在绝对高程的两倍因子上只有百分之五的散布。相关是显著的、而它是电锯的结果：**一个被冰川作用的山脉的高峰站在更新世雪线之上一个固定的量**、因为冰在最厚、最快的、即在ELA附近之处侵蚀最有效、而因为一个由构造抬到ELA之上的高峰被锯回下面。

隐含的侵蚀速率由移除的岩石的量得出。如果这条山脉在2百万年里抬升2500米——1.25 mm/yr——而它的高峰站在2100米、那么约400米的起伏被移除、平均
$$
\frac{400}{2\times10^{6}} = 0.2\ \mathrm{mm\,yr^{-1}} .
$$
这是一个典型的冰川侵蚀速率、而它舒适地在构造速率之下、这就是为什么这条山脉仍在上升。

无法仅凭高程数据排除的另一种解释是**气候的**：ELA与岭脊高程可能都由同一个第三变量设定——决定岩石在哪里强、霜在哪里工作、而碎屑能被输送的温度的与降水的场。Shuster、Tucker与建模学派表明一个没有任何特殊冰川效率的**岩石抬升与气候**模型再现图案的大部分、而判别的观察是**单个山脉内侵蚀速率作为高程的函数的宇宙成因**：电锯预测冰川侵蚀在ELA处有一个极大、并在其上下下降、而这在一些山脉被发现、在另一些没有。问题是开放的、而它是这个学科里最多产的之一。
:::
:::

::: history
冰塑造陆地的理论是地球科学的伟大争论之一。De Charpentier在1834年为Alpine的漂砾提出它、Venetz、de Saussure与Charpentier的同事L. de Charpentier在1820年代论证同样的事、而**Agassiz**在他1837年在瑞士学会面前的论文与他1840年的《Études sur les glaciers》里把它变成一个全球的理论——反对Lyell、他更偏好漂移的冰山与灾难的洪水、以及发现这个想法"不像英国"的英国地质建制。证据在十九世纪后半叶从英格兰中部、Lake District与苏格兰的冰川条痕与冰碛岩、以及Alpine的更新世地层积累、而Alpine冰川期与Milankovitch轨道周期的Brückner1901年的对比由他固定。**鼓丘**问题由Miller1842年的高地貌清单打开、而从未关闭；Johnson与Davis的地表侵蚀学派与Chamberlain与Salisbury的冰川学派之间的**冰川槽谷**之争从1880年代运行到1930年代、而由大陆架上超额加深的发现解决。**底部滑动定律**是Weertman在1957年的工作、Weertman的滑动与Alley、Blankenship、Bentley与Eccrat在1987年的底碛变形革命、以及Iverson、Engelhardt、Humphrey等人在1990年的腔水与有效压力的集成。**冰川电锯**是Brooker与Shuster、van der Woerd、Tucker、以及Egholm、Nielsen、Pedersen、Lesemann与Jenson在2009年给高程夹持的名字、而侵蚀的**冰川强化**是Harris、Herman、Hallet、Densmore与海洋沉积学派的集成。
:::

::: example 从一条清航线到一个冰盖 {#ex-trimline}
一条**清航线**——冰扫过的与冰缘风化的坡之间植被与地貌的尖锐的断裂——在一条升到1150米的山的一翼的850米处测绘。清航线位置的基岩在600米、清航线位于一个重建的冰分水岭之上60公里、而其间的冰面坡度是0.004。求清航线处与分水岭处的冰的厚度、取分水岭的基岩高程为300米。
::: solution
清航线标记**先前的冰面**、所以在清航线处冰面站在850米、而冰是
$$
850 - 600 = 250\ \mathrm{m}\ \text{thick}.
$$
在上风六十公里、冰面高$60\,000\times0.004 = 240\ \mathrm{m}$、在
$$
850 + 240 = 1090\ \mathrm{m},
$$
而在一个300米的床上冰因此是
$$
1090 - 300 = 790\ \mathrm{m}\ \text{thick}.
$$
这座山1150米的顶峰站在分水岭处冰面**之上**60米、而是一个**角峰**、而850米的清航线是其下整个山翼被碾过的证据——这意味着一个在线上看起来冰缘、在线下冰川的景观记录一个单一的事件、一个曾经覆盖顶峰区的冰盖的变薄。

三个谨慎适用。一条清航线可能记录**风化风格的改变**、不是冰面本身——例如风扬沙的极限、或一个特定的霜的制度——而检验是线下的面是否携带冰川擦痕、羊背石与底碛、而线上的携带石海与分选的条纹。一条清航线可能是**超时的**、记录几次进冰的最后一次、不是最大的范围。而0.004的冰面坡度是一个**假设**、通常取自一个流动模型或一个组构的方位；如果真正的坡度是0.002、分水岭的面只会高120米、而冰会有670米厚。这个方法真正的产品因此是冰面的**形状**、不是它的绝对厚度、而一张在许多地点的清航线图、校正了使它们倾斜的冰后均衡、是对一个消失的冰盖的剖面少数的直接约束之一。
:::
:::

## 堆积与去冰

::: definition 堆积的冰川地貌 {#def-depositional}
一个**底碛**（杂基沉积）是无分选、无层理、杂基支撑的、由冰直接沉积的沉积、而它的**组构**——其碎屑的方位与叠瓦、**a轴组构**——记录形成它的变形：一个强的、成团的、向上游倾斜的a组构指示冰下变形、而一个弱的或随机的组构指示融出或冰上的成因。一个**冰碛**是一道底碛的脊：**侧碛**在冰缘的一侧、**中碛**在两条冰川相遇之处、**终碛**或**退碛**在一个静止期、**底碛**（消融碛、漂砾）在冰的底部。一个**鼓丘**是一个流线形的、长形的、常常成群的底碛或变形床的丘、其长轴平行于冰的流动、而其迎端指向上游；其起源在170年的争论后仍未解决。一个**冰碛丘陵**、**锅穴**与**蛇形丘**是**死冰**的沉积：一个冰碛丘陵是一个有层理的融水沉积被放低进一个对着停滞冰的腔、一个锅穴是冰融出时留下的坑、而一个蛇形丘是一个在冰下或冰内融水通道里沉积的沙与砾的弯曲的脊。一个**外冲平原**是冰缘之外的辫状河流平原、而其远端是**纹泥**与**冰前湖**的沉积过渡到海洋或湖成序列之处。
:::

::: example 一个冰川的沉积物收支 {#ex-sedbudget}
一个$1200\ \mathrm{km^2}$的冰川作用的集水区以$60\ \mathrm{m^3\,s^{-1}}$输送融水、悬移质浓度$1.2\ \mathrm{g\,L^{-1}}$、溶解载荷$180\ \mathrm{mg\,L^{-1}}$。求总剥蚀速率、并与未被冰川山的全球平均比较。
::: solution
悬移通量是
$$
60\times10^{3}\ \mathrm{L\,s^{-1}}\times1.2\ \mathrm{g\,L^{-1}} = 7.2\times10^{4}\ \mathrm{g\,s^{-1}} = 2.3\times10^{12}\ \mathrm{g\,yr^{-1}} = 2.3\ \mathrm{Mt\,yr^{-1}},
$$
而溶解通量是$60\times10^{3}\times0.18 = 1.1\times10^{4}\ \mathrm{g\,s^{-1}} = 0.34\ \mathrm{Mt\,yr^{-1}}$、所以总量是$2.6\ \mathrm{Mt\,yr^{-1}}$。在$1.2\times10^{9}\ \mathrm{m^2}$上这是
$$
\frac{2.6\times10^{12}}{1.2\times10^{9}\times2700} = 8.0\times10^{-4}\ \mathrm{m\,yr^{-1}} = 0.80\ \mathrm{mm\,yr^{-1}} .
$$
**溶解载荷只占总量13%**、对一个未被冰川的集水区的20–40%、因为一个冰川的底部研磨产生岩粉比冷的、短停留时间的冰下水能溶解的更快。

一个0.8 mm/yr的剥蚀速率是**相似起伏的未被冰川的山的全球平均的三到八倍**、而在冰川作用的集水区测量的范围的低端、后者在Alps、挪威、Alaska与新西兰的南阿尔卑斯达到2–10 mm/yr。这一比较是更新世冰川作用被认为**增加**了全球剥蚀速率、而不是覆盖并保护了大陆的原因、而这也是海洋沉积记录显示从约2.8 Ma——北半球冰川作用的开始——向北大西洋、比斯开湾与Alaska湾的沉积通量显著增加的原因。
:::
:::

caption: 一个理想化的冰川槽谷横截面、$z = \exp(-x^2/2\sigma^2)$、$\sigma = 30\ \mathrm{m}$、标度到一个1.2公里宽的谷、一个河流的V形谷对照它将是一对从轴到岭脊的直线。冰川的剖面是一个**钝的U**、有一个平底与陡壁、而差别在野外是诊断的：一个V形谷的壁在一个角度上与溪流相遇、而其横截面积按高度的平方增长、而一个U形谷有一个几乎恒定宽度的底、而其面积按高度线性增长。这一区别被用于在岩石记录里识别冰川作用、那里唯一幸存的证据可能是一个截断的山嘴、一个以底碛为底的超额加深的盆地、或一个其宽深比远高于河流值的谷。

::: warning 一个冰川景观是一张羊皮卷、而最后一次冰没有写完它
一个先前被冰川作用的表面携带**几次**冰川作用的形态、而最后一次的形态重压、不是抹去更早的那些。三个后果随之。**地貌不都是同一年龄**：一个挪威或加拿大的景观可能在几百米内携带一个更新世的冰斗、一个新仙女木的退碛、一个早冰后期的岸线、与一个二十世纪的新冰川冰碛、而填图的单位必须是**土地系统**——形态的成因一致的集合、不是单个的形态。**沉积是被再工作的**：一个"底碛"可能是一个再工作的底碛、一个杂岩可能是一个泥石流、而一个鼓丘群可能是一群崩塌的死冰丘、不是亚冰下的流道；组构、体内的地层、与一个埋藏的土壤的存在是唯一的判别。**而侵蚀速率不平稳**：一个冰川的侵蚀集中在它的**冰涌**与**流动**阶段、与在一个床充水而沉积库空的**去冰**期、所以一个宇宙成因或一个沉积通量的估计平均一系列的事件、不是测量一个速率。学科规矩是在把任何形态归给任何过程之前测绘**去冰的风格**——冰缘的、冰上的、冰下的、冰前湖成的、与冰近扇的、并给每个土地系统里至少一个要素定年。
:::

::: quiz
一个景观显示擦痕的、抛光的基岩、一个拔出面朝南的羊背石、一个U形谷、而没有底碛。你能得出什么结论？
- [x] 温底的冰从北向南流过这个地点。
- [ ] 冰是冷底的。
- [ ] 谷由一条河切割、后来被冰川作用。
- [ ] 底碛由切割擦痕的同一个冰沉积。
::: solution
擦痕与抛光是磨蚀的产物、而拔蚀产生拔出的陡坡、所以冰是**温底的、湿底的**、不是冻结在其床上的。拔出的面指向**下游**、所以流动是向南。底碛的缺失只说明底碛被后来的融水移除、或从未在那里沉积——一个侵蚀的景观不必携带它自己的堆积记录。
:::
:::

## 通向何处

冰的物理在[[glaciology/ice-flow]]与[[glaciology/basal-sliding]]、设定ELA的质量平衡在[[glaciology/mass-balance]]、这些地貌变成的沉积在[[sedimentology/continental-environments]]、纹泥与冰前湖在[[sedimentology/stratigraphy]]与[[palaeoclimate/dating]]、冰盖的重建在[[glaciology/ice-sheets]]、而海平面的后果在[[climate-change/sea-level-rise]]。

::: summary
- 冰川以磨蚀与拔蚀侵蚀、两者都需要床处的融水、所以热制度控制侵蚀在哪里发生。
- 底部滑动由有效压力控制、而底部水压上升百分之十能使滑动速度三倍。
- 一个冰川槽谷是一个钝的U、有截断的山嘴、悬谷与超额加深、而它的形态使它区别于一个河流的V。
- 冰川电锯把冰川作用的高峰夹持在更新世雪线附近、而这一效应在ELA相差两倍因子的山脉之间可见。
- 冰川作用的集水区输出未被冰川的集水区的3–8倍的沉积、而溶解的分数小得多。
- 一个冰川景观是几次进冰的羊皮卷、而它必须作为一个土地系统被测绘、并被定年。
:::

## 练习题

::: exercise 底部应力 {level=1 check="123"}
求一个400米厚、在$2^\circ$坡度上的冰川的底部剪切应力。
::: solution
$\tau_b = 900\times9.81\times400\times\sin 2^\circ = 900\times9.81\times400\times0.0349 = 1.2\times10^{5}\ \mathrm{Pa} = 123\ \mathrm{kPa}$。这在范围的上端附近、所以冰川受其床的强度限制、而很可能是一个陡的Alpine冰川或一条冰流的边缘。
:::
:::

::: exercise 有效压力 {level=1 check="0.35"}
一个200米厚的冰川有一个冰上覆压力80%的底部水压。求以MPa计的有效压力。
::: solution
$P_i = 900\times9.81\times200 = 1.77\ \mathrm{MPa}$、而$N = 0.2\times1.77 = 0.35\ \mathrm{MPa}$。一个低的有效压力意味着一个弱的床、容易的滑动、与一个对拔蚀的高易感性。
:::
:::

::: exercise 地貌识别 {level=1}
一道无分选、无层理、含砂黏土的、有棱面的、擦痕的、叠瓦的石灰岩与花岗岩砾的脊横切一条谷底。说出它。
::: solution
一道**终碛或退碛的底碛**——一道**底碛**的脊。无分选、无层理、杂基支撑的结构、有棱面与擦痕的碎屑、与叠瓦是诊断的标准、而横贯谷的位置标记冰缘的一次静止。
:::
:::

::: exercise 滑动响应 {level=2 check="2.0"}
用$u_b \propto \tau_b^3/N$、求若底部剪切应力上升25%、而$N$不变，滑动速度上升的因子。
::: solution
$1.25^3 = 1.95$、约一倍。非线性的Weertman定律意味着冰的一个温和的增厚或变陡——它提高$\tau_b$——产生滑动的大增加、而这是冰川冰涌背后的两个正反馈之一；另一个是底碛的**应变弱化**、其中变形的床在变形时失去强度。
:::
:::

::: exercise 冰川剥蚀 {level=2 check="2.2"}
一个$800\ \mathrm{km^2}$的冰川作用的集水区输送$100\ \mathrm{m^3\,s^{-1}}$的融水、含$1.5\ \mathrm{g\,L^{-1}}$的悬移质。求以mm/yr计的剥蚀速率、取岩石密度$2700\ \mathrm{kg\,m^{-3}}$。
::: solution
通量是$10^5\ \mathrm{L\,s^{-1}}\times1.5 = 1.5\times10^{5}\ \mathrm{g\,s^{-1}} = 4.7\times10^{12}\ \mathrm{g\,yr^{-1}} = 4.7\ \mathrm{Mt\,yr^{-1}}$、而
$$
E = \frac{4.7\times10^{12}}{8\times10^{8}\times2700} = 2.2\times10^{-3}\ \mathrm{m\,yr^{-1}} = 2.2\ \mathrm{mm\,yr^{-1}} .
$$
这是一个快速侵蚀的冰川作用的集水区、可与新西兰的南阿尔卑斯与Alaska湾相比。
:::
:::

::: exercise 超额加深 {level=2}
一个峡湾在海平面以下900米、在其口有一个海平面以下150米的槛、而其槽谷的壁升到海平面以上1200米。超额加深与槛对你关于冰川、关于海平面历史告诉你什么？
::: solution
切割槽谷的冰川在最大超额加深的点**至少1050米厚**（海平面以下900米加上槛的水平之下移除的150米岩石）、而**床必须在侵蚀期间低于海平面**、这需要一个海水位的低、暴露架、或一个构造的下挠的海岸。**150米的槛**是一个在后退的冰的一次静止期沉积的**终碛或退碛**、而它现在坝住盆地、这就是为什么峡湾在槛的深度之下通常是**缺氧或分层的**——深水与表面、与氧切断。

海平面历史由两个深度一起得出。峡湾被去冰、槛在一次静止期沉积、而海随后上升淹没槽谷。如果槛由有孔虫或由底碛包含的壳的放射性碳定年、它给那次静止定年、而**一串沿峡湾的槛**是一次后退的已定年的记录。在峡湾的口现在低于海平面、而冰碛在亚空气沉积之处、海岸**下沉**了、而量是冰碛的原始与现在高程之差——苏格兰、挪威与Maine海岸经典的均衡与海水位的问题。
:::
:::

::: exercise 一个土地系统填图的问题 {level=3}
一个200平方公里先前被冰川作用的地区显示：一个140米的边缘冰前湖三角洲；一个120到95米之间的锅穴、冰碛丘陵与崩塌的浑丘带；一个300条对齐的脊的田、200–600米长、5–15米高、其长轴走向115°；一个95到70米之间的具槽底碛带、其槽走向118°；以及一个60米的抬升海滩。测绘土地系统、并重建去冰。
::: solution
五个土地系统、按其形成的顺序。**140米的三角洲**是一个**冰前湖三角洲**、所以冰缘站在一个冰前湖被壅到140米的位置。**120与95米之间的锅穴-冰碛丘陵-浑丘带**是一个**冰上碎屑与死冰**的地形、在冰原地停滞、而其表面碎屑在冰融出时崩塌之处形成；它的高程范围是停滞的冰存活的范围。**300条对齐的脊**是**鼓丘**（或、鉴于它们的小的尺寸与数量、条脊或横向冰碛）、其115°的长轴给出冰的流动方向。**118°槽的具槽底碛**是一个**冰下成槽**的地形、在一个接地的、后退的冰缘之下由融水或变形的底碛形成、而与鼓丘走向在3°内的一致证实流动方向。**60米的抬升海滩**是**去冰后的海洋或湖成**岸线。

重建是一个**从北到南的分期后退**（或在冰的流动的方向相反的方向）、冰缘站得足够久以在140米建造一个三角洲、然后一个**停滞带**、冰在那里回撤、并在120与95米之间留下死冰、然后一个产生95与70米之间冰下成槽的**接地的进冰或静止**、而最后是一个完全的冰撤退与一个在60米的水体的建立。

最弱的环节是**脊的解释**。鼓丘群、条脊冰碛、与崩塌的冰楔或锅穴田都能产生这个尺寸的对齐的脊、而判别需要**探槽或探地雷达**：一个鼓丘有一个基岩或底碛的核、带一个内部组构、一个条脊冰碛是一个逆冲褶皱的底碛脊、带一个近侧的叠瓦、而一个崩塌的丘有一个混乱的有层理的核、带冰接触构造。整个去冰的重建取决于它们是三者中的哪一个、因为一个鼓丘意味着接地的、流动的冰、而一个崩塌的丘意味着停滞的死冰——两种完全不同的后退风格。
:::

::: exercise 晚新生代加速 {level=3}
挪威外的海洋沉积岩芯显示沉积物质量积累率从2.8 Ma之前的$0.05\ \mathrm{g\,cm^{-2}\,kyr^{-1}}$升到之后的$0.6\ \mathrm{g\,cm^{-2}\,kyr^{-1}}$、在一个$8\times10^{5}\ \mathrm{km^2}$的源区上。求之前与之后的剥蚀速率、并讨论增加意味着什么。
::: solution
转换、$0.05\ \mathrm{g\,cm^{-2}\,kyr^{-1}} = 0.5\ \mathrm{kg\,m^{-2}\,kyr^{-1}} = 0.5\ \mathrm{g\,m^{-2}\,yr^{-1}}$、而$0.6\ \mathrm{g\,cm^{-2}\,kyr^{-1}} = 6\ \mathrm{g\,m^{-2}\,yr^{-1}}$。在$8\times10^{11}\ \mathrm{m^2}$上质量通量是
$$
4\times10^{11}\ \mathrm{g\,yr^{-1}} = 0.4\ \mathrm{Mt\,yr^{-1}} \quad\text{before}, \qquad
4.8\ \mathrm{Mt\,yr^{-1}} \quad\text{after}.
$$
在一个$2700\ \mathrm{kg\,m^{-3}}$的岩石密度，源区上的剥蚀速率是
$$
\frac{4\times10^{8}}{8\times10^{11}\times2700} = 1.9\times10^{-7}\ \mathrm{m\,yr^{-1}} = 0.19\ \mathrm{mm\,yr^{-1}} \quad\text{before}, \qquad
2.2\ \mathrm{mm\,yr^{-1}} \quad\text{after}.
$$
在2.8 Ma与主要北半球冰川作用的开始同时的剥蚀的**十二倍增加**、是侵蚀的**冰川强化**的经典证据、而它在大多数先前被冰川作用的边缘被发现——挪威、伊比利亚、巴伦支海、Alaska、巴塔哥尼亚与新西兰。

三个谨慎使解释诚实。**源区**从沉积的物源推断、而可能已经改变；**深海积累速率**与架外的通量不同、因为冰川载荷的大部分沉积在架与坡-隆上、而从不到达深海平原、所以在一个深海岩芯里测量的增加是一个**下限**；而**原因有争议**——增加可能是冰的效应、或造成冰的**抬升**的、或暴露架、并降低基准面的**下降的全球气候**的。冰川成因的最有力的证据是增加在2.8 Ma是**阶状的**、不是渐变的、而沉积的**粒度与其海冰搬运的碎屑**在同一层位增加、这证明冰到达了海。
:::
