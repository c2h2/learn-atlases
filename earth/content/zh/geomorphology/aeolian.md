空气比水稀一千倍、而粘度低五十倍，所以它只有以每秒几米吹时才能移动沙、它在沙尘暴之外完全不能移动粉沙、而它比任何其他营力更精细地分选沉积物。结果是一组地貌——沙丘——它们是行星上最大、最规则的床形、一种沉积——黄土——覆盖十分之一的陆地表面、并记录更新世最干的气候、以及一组侵蚀面——风棱石、雅丹、荒漠砾幕——它们是唯一一些其制造被争论了一个世纪的地貌。

## 风的输移能力

::: definition 阈值与两种模式 {#def-threshold}
一个表面上的颗粒在空气动力阻力克服它的重量与其邻居的摩擦时被移动。阈值表达为一个**阈值剪切速度**$u_{*th}$、而对空气中干燥、均匀的沙床它是
$$
u_{*th} = \sqrt{\theta_{th}\,R\,g\,d}, \qquad \theta_{th} \approx 0.010\text{–}0.013,
$$
其中石英在空气中$R = (\rho_s - \rho_a)/\rho_a \approx 2400$。观察曲线在**0.15–0.3毫米处有一个约0.20 m/s的极小值**、并在两端上升：向更细是因为颗粒间的黏聚力与水分束缚住颗粒、而向更粗是因为重量增长。一旦一个颗粒在移动，**撞击阈值**——维持一个跃移云所需剪切速度——只有流体阈值的约**60–80%**，因为一个在飞行中落到床上的颗粒喷出几个别的。这就是为什么一场沙暴开始所需的风比它维持自己所需的高、以及为什么短暂超过阈值的阵风能开始一个随后在更弱的风里继续的吹蚀事件。
:::

::: definition 跃移、蠕移与悬移 {#def-modes}
**跃移**是一个颗粒被一个湍流爆发发射到0.1–1毫米的高度、10–100毫米的长度、它在重力与阻力下的下降、以及它在撞击时的反弹或喷出更多颗粒的轨迹；它携带沙通量的50–80%、而它是制造波痕的过程。**表面蠕移**（爬移、拖移）是被太大而无法举起的颗粒的滚动与推动、由跃移者的撞击驱动、而它携带相当的质量。**悬移**只携带粉尘——细于约50 µm的颗粒——它可以被举到几千米的高度、并被输送几千公里、而它是制造黄土的过程。饱和跃移的**Bagnold饱和通量**是自相似定律
$$
Q = C\,\frac{\rho_a\,u_*^3}{g}, \qquad C \approx 2.8,
$$
以$\mathrm{kg\,m^{-1}\,s^{-1}}$、其**立方定律**是剪切速度加倍使沙通量提高八倍、而一个景观的风成工作由其少数最强的风完成的原因。
:::

::: example 什么风移动沙？ {#ex-threshold}
求0.2毫米沙的阈值剪切速度、相应的粗糙度长度、与跃移开始的10米处的风速、取$\theta_{th} = 0.012$、$\rho_a = 1.2\ \mathrm{kg\,m^{-3}}$、$\rho_s = 2650\ \mathrm{kg\,m^{-3}}$与$\kappa = 0.4$。
::: solution
$$
R = \frac{2650 - 1.2}{1.2} = 2207, \qquad
u_{*th} = \sqrt{0.012\times2207\times9.81\times2\times10^{-4}} = \sqrt{0.0520} = 0.23\ \mathrm{m\,s^{-1}} .
$$
对于一个跃移的床，Bagnold的粗糙度是$z_0 = u_*^2/(3g) = 0.0520/29.4 = 1.8\times10^{-3}\ \mathrm{m}$、而对数剖面$u(z) = (u_*/\kappa)\ln(z/z_0)$给出
$$
u(0.1\ \mathrm{m}) = \frac{0.23}{0.4}\ln\frac{0.1}{0.0018} = 0.575\times4.02 = 2.3\ \mathrm{m\,s^{-1}},
$$
$$
u(10\ \mathrm{m}) = 0.575\times\ln(5556) = 0.575\times8.62 = 5.0\ \mathrm{m\,s^{-1}} .
$$
中沙的跃移因此在**约以10米高度测量的5 m/s**开始——一节10海里的清劲风——这就是为什么一个海滩在海风锋到达后的几分钟内开始吹沙、而为什么一个风成砂岩只记录它的季节里最强的风。

这个练习的第二个信息是对$z_0$的敏感性。一个被砾石、植被或水分弄粗的表面有一个0.01–0.1米的$z_0$、而同一个阈值剪切速度然后需要一个8–12 m/s的10米风。这是**防护林带**与**草方格**风蚀防治的物理基础、以及一个百分之一的地面被一道栅栏或一丛灌木覆盖就能抑制一块田的大部分沙通量这一事实的基础。
:::
:::

::: history
Aristotle描述了风吹沙、而Lucretius在《物性论》里论证风的力量、但现代的学科始于**Ralph Stockman**、以及**Grove Karl Gilbert**1885年关于**Bonneville湖**沙丘的专著与他1904年关于沙丘的论文、后者确立沙丘通过颗粒沿迎坡的跃移与其沿滑面的崩塌而迁移。**Ralph Bagnold**在1930年代在埃及与利比亚的沙漠里以一台相机、一个风洞与一种从未被匹敌的物理洞察力工作、产出了《The Physics of Blown Sand and Desert Dunes》、它定义了剪切速度阈值、跃移轨迹、饱和通量、粗糙度长度$z_0 = u_*^2/3g$、以及沙丘类型的分类、而它是自然地理学的奠基文本之一。**Bagnold**的同代人**Sharpe**与**Sandford**把野外扩展到美洲与北非。**黄土**问题——粉沙是一个风成沉积、一个黄土风化产物、还是一个消融冰盖的冲刷——在欧洲由德国与俄国学派的岩相与粒度工作、在美国由**Mason**与**Ruhe**的Wisconsin样带解决、而**中国黄土**由**Willis**在1907年确立为一个连续的风成序列、并由**刘东生**、**安芷生**、**Kukla**与**Hsu**的中国学派详细作出。**立方定律**与**撞击阈值**是Bagnold与**Owen**的遗产；现代的定量学科——**Shao与Li**以及**Stout与Hunt**关于跃移云的工作、**Fryberger与Schenk**关于沙丘类型与风制、**Tsoar与Parteli**关于沙丘场与植被、以及**Thomas、Wiggs、Livingstone与Field**关于作为系统的沙漠——是二十世纪晚期的产物。**残遗沙丘**问题是1990与2000年代**光释光**定年的结果、尤其是Oxford与Aberystwyth实验室关于撒哈拉、Namib与澳大利亚沙漠的工作。
:::

## 风对风的侵蚀

::: definition 吹蚀、磨蚀及其产物 {#def-deflation}
**吹蚀**是从一个表面移除细粒部分、而其产物是一个**吹蚀穴**（坑、干盐湖、qur）、一个**荒漠砾幕**（reg、serir、hamada、砾漠）——细粒走后留下的紧密堆积的砾石滞后、它是**自我限制**的因为甲胄阻止进一步的吹蚀——以及一个**黄土源**。被跃移与悬浮颗粒的**磨蚀**限于最低的0.5–1米、因为跃移者无法升得更高、而悬浮的粉尘抛光而非切割；其产物是**风棱石**（有棱面、抛光与刻槽的砾石、其棱面记录风向）、**雅丹**（流线状的岩石脊、几十米高、几公里长、由风与其基部的喷砂切割、并与塑造它的风对齐）、**zeugen**、**gours**、以及岩石表面的**蜂窝与石穴**风化。**吹蚀对磨蚀在大多数沙漠里的支配**是始于风是一个大雕刻家这一信念的一个世纪争论的结论：美国西南部伟大的岩石雕塑几乎全是霜、盐与水的产物、而风的喷砂只贡献最低一米的抛光。
:::

::: example 一个干盐湖多快被吹低？ {#ex-deflation}
一个$400\ \mathrm{km^2}$的干盐湖是一个尘羽的源、而估计供应$5\ \mathrm{Tg\,yr^{-1}}$的粉尘。求干盐湖地面的降低速率、与一个1万年的冰期里的总吹蚀。什么限制答案？
::: solution
以一个$2.6\ \mathrm{g\,cm^{-3}} = 2600\ \mathrm{kg\,m^{-3}}$的干容重，
$$
V = \frac{5\times10^{12}\ \mathrm{g\,yr^{-1}}}{2600\ \mathrm{kg\,m^{-3}}} = 1.9\times10^{6}\ \mathrm{m^{3}\,yr^{-1}},
\qquad
\dot z = \frac{1.9\times10^{6}}{4\times10^{8}} = 4.8\times10^{-3}\ \mathrm{m\,yr^{-1}} = 4.8\ \mathrm{mm\,yr^{-1}} .
$$
在$10\,000$年里这是**48米**的吹蚀——足以移掉一个干盐湖整个全新世的充填、并深深切入其基底。

这个数字由于三个原因是一个上限。**粉尘并非全部源自干盐湖地面**：部分由周围的坡通过片流与沟蚀供应、只是储存在干盐湖上然后被举起、所以地面比质量平衡暗示的降得慢。**吹蚀是自我限制的**：一旦一个滞后砾石的荒漠砾幕形成、通量下降一个数量级、而一个已经吹蚀了几千年的干盐湖是武装的、接近稳定的。而**通量是阵发的**：一场大的沙尘暴可能输送一年的量、而年平均隐藏一个吹蚀、武装、以及在一个把细粒胶结住然后又释放的湿润事件后再活动化的循环。

下限来自**干盐湖的地层**：如果钻孔显示20米的全新世湖成与风成交互粉沙、那么自最后一个多雨湖以来的净吹蚀小于20米、即2 mm/yr、而两个数字之差是其集水区**供应**给干盐湖的沉积的量。两个界限一起——质量平衡的速率与地层的速率——是可得的最好约束、而它们的差是一个干盐湖的沉积物收支。
:::
:::

## 沙丘及其种类

::: definition 沙丘类型及其控制 {#def-dune-types}
一个沙丘的平面形态由**沙的供应**、**风制**与**障碍物**设定。**新月形沙丘**是一个角指向下风的新月、在一个有限的供应、一个硬的床、与一个单峰的风下形成、而它以下风5–100 m/yr迁移、带一个在静止角上的滑面。**新月形沙丘链**是一个过渡的新月-脊。**横向沙丘**是一条垂直于一个单峰的风与一个丰富供应的长脊。**纵向**或**seif沙丘**是一条3–10米高、可达100公里长的脊、平行于一个双峰的风的**合成**、其两个分量都有沿脊的分量。**星形沙丘**是一个多向风制与一个沉积陷阱的金字塔形、多角的沙丘、而它是最高的沙丘类型、在巴丹吉林达到500米。**反向沙丘**有角指向上风、在两个风分量强度相当之处形成。**nebka**是在一株植物的庇护下形成的小沙丘、而**draa**是一个叠加的大沙丘、波长50–300米、在其背上携带更小的沙丘。**沙丘海**（erg）是活动的沙丘的连续或近连续的覆盖、而它占世界沙漠约五分之一；最大的是Rub' al Khali、卡拉库姆与巴丹吉林。
:::

::: example 一个沙丘多快行走？ {#ex-dune-migration}
一个硬荒漠底上的新月形沙丘场在其脊上有$0.022\ \mathrm{kg\,m^{-1}\,s^{-1}}$的跃移通量、一个12米的沙丘高度、$2650\ \mathrm{kg\,m^{-3}}$的沉积物密度、与0.40的孔隙度。求沙丘的迁移速率、并说出一个3公里宽的沙丘海需要多久穿过一个景观。
::: solution
沙丘的前进等于每年穿过其每米脊的沉积物的量、除以其每米高度所含的沉积物：
$$
c = \frac{Q\,t}{\rho_s(1-\phi)H} = \frac{0.022\times3.15\times10^{7}}{2650\times0.60\times12}
  = \frac{6.9\times10^{5}}{1.91\times10^{4}} = 36\ \mathrm{m\,yr^{-1}} .
$$
一个3公里宽的沙丘海因此将在
$$
\frac{3000}{36} = 83\ \mathrm{yr}.
$$
穿过一个固定的地点。这是快的——一个在一个活动的新月形沙丘前锋路径上的村庄在一个人的寿命里被掩埋、这是塔克拉玛干、Namib的海岸、以及逼近瓦达伊与秘鲁海岸城镇的沙丘的现实——而这就是为什么迁移速率由卫星、不是由测量测量。

这个计算的弱点是它假设**整个**沙丘作为一个刚体前进、这对一个硬底上的新月形沙丘是真的、但对一个星形沙丘或一个draa不是、其内部结构是一个叠加的加积单元的堆栈、而其净迁移慢得多。它还假设通量是**年平均**、而通量由少数风暴主导、沙丘跳跃地前进。野外的检验是**重复测量或卫星图像**、而世界的新月形沙丘场测量的速率——5到100 m/yr——把这个计算括起来、这对风成过程地貌学来说已经尽可能好了。
:::
:::

## 黄土

::: definition 黄土 {#def-loess}
**黄土**是一个风成的粉沙堆积——10–50 µm的50–70%的粉沙——它**无层理**、**含钙**、**垂直节理**、**多孔隙**、有根与昆虫的洞穴、而在通常的河流意义上**不分选**。它的源是**冰川外冲平原**（中国、欧洲与美国中西部的更新世黄土、其粉沙来自冰川的粉碎）、**沙漠边缘**（黄土高原的终极源包括戈壁与鄂尔多斯）、以及**干盐湖与干湖底**。它的厚度与它的中值粒度都**沿风向下指数衰减**、而它的堆积速率是0.1–10 mm/yr。中国黄土高原覆盖$6\times10^{5}\ \mathrm{km^2}$、厚度可达340米、年龄8百万年、而其交替的黄土与**古土壤**层是更新世冰期的陆上记录、黄土标记干、有风的冰期区间、而红色的古土壤标记更暖、更湿、有植被的间冰期。
:::

::: example 读一条黄土样带 {#ex-loess}
在一个冰川外冲平原的下风，黄土厚度在40公里处是120米、160公里处是40米、300公里处是13米。求衰减长度、并预测500公里处的厚度。粒度做什么？
::: solution
假设一个指数衰减$h = h_0 e^{-x/L}$、比值给出
$$
\frac{120}{40} = 3.0 \quad\text{over }120\ \mathrm{km}: \quad L = \frac{120}{\ln 3.0} = \frac{120}{1.10} = 109\ \mathrm{km};
$$
$$
\frac{40}{13} = 3.08 \quad\text{over }140\ \mathrm{km}: \quad L = \frac{140}{1.12} = 125\ \mathrm{km}.
$$
两者一致、所以衰减长度约**115公里**、而在源处$h_0 = 120\,e^{40/115} = 170\ \mathrm{m}$、500公里处的厚度是
$$
h = 170\,e^{-500/115} = 170\times0.0130 = 2.2\ \mathrm{m}.
$$
黄土在源的500公里内变薄到几米、这就是为什么美国中西部的黄土从Iowa的30米变薄到Ohio的几米、并在阿巴拉契亚之前消失。

**粒度沿同一方向衰减、但比厚度慢**、因为粗粉沙（50–60 µm）以改性的跃移与短的悬移携带、最先掉下、而细粉沙与黏土（2–10 µm）以真正的悬移行进几千公里。中值直径通常在源附近从40–50 µm降到500公里处的15–20 µm、而**粗粉沙与细粉沙的比**被用作一个**古风与古干旱指标**、一个更粗的比意味着一个更强或更近的风。中国高原的粒度堆栈因此被用作东亚冬季风强度的一个8百万年的记录、而它是陆上最长的连续古气候记录之一。
:::
:::

::: warning 风成地貌比它们看起来更老、更残遗
沙漠地貌通常是**一个不同气候的继承**、而一个沙漠地貌由现在的风制造的假设是这个学科持续的错误之一。Basin and Range的**荒漠砾幕**正缓慢地从一个上新世或更新世的砾质覆盖之下出土、而不是今天正在被吹蚀；塔克拉玛干与埃及的**雅丹**切割在软沉积里、并朝向不再占主导的更新世的风定向；欧洲、中国与美国中西部的**黄土**是一个**冰期**沉积、现在的气候只是缓慢地重工作与侵蚀它；而撒哈拉的**活动沙丘海**、从光释光年龄看、主要是最后一个冰期的干旱事件期间活动化的**残遗**地貌、而只在局部活动、撒哈拉大部分沙丘已稳定了2–4万年。对解释的后果是一个风成砂岩的古流向玫瑰图给出**沉积时**的风向、这是安全的、而它的存在只在沙丘是活动的时给出干旱、而它可能不是——一个在湿润覆盖之下保存的**残遗沙丘海**是一个常见的地层对象、而它记录一个干的过去、不是一个干的现在。学科规矩是在把一个风成沉积归给一个气候之前给它定年——在石英上用OSL、在沙体之间的古土壤的年龄、或在被埋表面的宇宙成因核素含量——然后再归因。
:::

::: quiz
一个沙表面有一个0.002米的粗糙度长度与一个0.25 m/s的剪切速度。种一行灌木把$z_0$提高到0.05米、而剪切速度保持不变。在2米测量的风速会怎样？
- [ ] 它不变，因为$u_*$不变。
- [ ] 它上升，因为同一个剪切应力由一个更粗糙的表面附近更陡的速度梯度承担。
- [x] 它下降，因为一个更粗糙的表面给出一个更平的速度剖面、所以同一个$u_*$对应一个近地面更低的风速。
- [ ] 它无法从这两个数字预测。
::: solution
$u(z) = (u_*/\kappa)\ln(z/z_0)$，所以$z_0$更大时对数是*更小*的、而一个给定高度的风速**更低**、不是更高：$\ln(2/0.002) = 6.9$ 对 $\ln(2/0.05) = 3.7$、一个46%的减少。正确的答案因此是测量的风速下降——这正是防护林带有效的原因。陷阱是符号：一个更粗糙的表面意味着一个*更平*的剖面、所以同一个$u_*$对应一个近地面*更低*的风速、而表面因此感受到的剪切比同一个风在一个光滑的表面上产生的少。
:::

## 通向何处

风分选的粒度在[[sedimentology/sediment-grains]]、它制造的床形在[[sedimentology/bedforms]]、岩石记录里的沙丘沉积在[[sedimentology/continental-environments]]、给海洋施肥的粉尘在[[biogeochemistry/ocean-cycles]]与[[atmospheric-chemistry/aerosols]]、黄土的冰川源在[[geomorphology/glacial-landscapes]]与[[glaciology/mass-balance]]、而它记录的古气候在[[palaeoclimate/dating]]与[[palaeoclimate/abrupt-change]]。

::: summary
- 空气只在一个约0.20–0.25 m/s的阈值剪切速度之上移动沙、对应一个裸露沙表面上约5 m/s的10米风。
- 撞击阈值在流体阈值之下、所以一个跃移云维持比开始更容易。
- 沙通量按剪切速度的立方、所以一个风成景观由其少数最强的风建造。
- 风主要以吹蚀、不是磨蚀侵蚀、而它的砾幕是自我限制的甲胄。
- 沙丘的平面形态记录沙的供应与风制、而一个活动的新月形沙丘一年迁移几十米。
- 黄土的厚度与粒度沿风向下衰减、而黄土-古土壤堆栈是冰期的陆上记录。
- 大多数沙漠地貌是残遗的、而在把它们归给现在的气候之前必须给它们定年。
:::

## 练习题

::: exercise 阈值 {level=1 check="0.36"}
以$\theta_{th} = 0.012$与$R = 2200$求0.5毫米沙的阈值剪切速度。
::: solution
$u_{*th} = \sqrt{0.012\times2200\times9.81\times5\times10^{-4}} = \sqrt{0.1295} = 0.36\ \mathrm{m\,s^{-1}}$。更粗的沙需要一个更高的剪切速度、但观察曲线比方根定律更平、因为阈值$\theta$随粒度下降。
:::
:::

::: exercise 立方定律 {level=1 check="8"}
当剪切速度在阈值之上加倍时，Bagnold的跃移通量提高多少倍？
::: solution
$2^3 = 8$倍。立方定律是风的20%增强使沙通量提高73%、而风成记录是一个极端的记录的原因。
:::
:::

::: exercise 沙丘类型 {level=1}
一个沙丘场有5米高、20公里长的脊、走向平行于相隔40°的两个风的合成。说出类型。
::: solution
**纵向（seif）沙丘。**它们的长轴位于一个双峰风制的合成之上、它们在沙的供应中等、而两个风分量都有沿脊的分量之处形成、而它们是地球上最常见的沙丘类型、形成撒哈拉、阿拉伯与澳大利亚的伟大沙丘海。
:::
:::

::: exercise 高度的风速 {level=2 check="6.9"}
以0.40 m/s的剪切速度与0.01米的粗糙度长度，求10米处的风速。
::: solution
$u(10) = (0.40/0.4)\ln(10/0.01) = 1.0\times\ln 1000 = 6.9\ \mathrm{m\,s^{-1}}$。一个更粗糙的表面（更大的$z_0$）对同一个剪切速度给出一个更高的风速、这就是为什么同一个$u_*$在一个砾石沙漠上对应一个比在一个光滑的沙坪上强得多的测量风。
:::
:::

::: exercise 黄土粒度 {level=2}
一条黄土样带在源的30公里处给出42 µm的中值直径、150公里处26 µm、400公里处18 µm。拟合一个衰减、并说出它对输移机制暗示什么。
::: solution
拟合$d = d_0 e^{-x/L}$：从30到150公里、$L = 120/\ln(42/26) = 120/0.476 = 252\ \mathrm{km}$；从150到400公里、$L = 250/\ln(26/18) = 250/0.371 = 674\ \mathrm{km}$。衰减长度随距离**三倍**、所以粒度不指数衰减。

阅读是两个机制存在。粗粉沙以**短悬移与改性的跃移**携带、并在最初的100–200公里内掉下、给出陡的初始衰减；在那之外沉积物是**真正悬移里的细粉沙与黏土**、其沉降速度如此之小、以致衰减非常慢、而更多由沉积速度与湍流、不是由沉降控制。曲线在约150公里处的转折因此是**从分选主导到沉积主导的输移的转变**、而这就是为什么一个黄土的粒度比只在源附近是一个好的古风指标、而在更远处变成一个降雨或植被的指标。
:::
:::

::: exercise 合成漂移 {level=2}
一个地点在40%的小时里风能够从030°移动沙、在60%的小时里从210°、而漂移势与小时数成正比。求合成漂移方向、并说出它预测什么沙丘类型。
::: solution
以北为$+y$、东为$+x$分解、030°的分量（**吹向**210°）有$x = 0.4\sin 210^\circ = -0.20$、$y = 0.4\cos 210^\circ = -0.346$、而210°的分量（吹向030°）有$x = 0.6\sin 30^\circ = +0.30$、$y = 0.6\cos 30^\circ = +0.520$。合成是$x = +0.10$、$y = +0.174$、大小为$0.20$、方向为
$$
\mathrm{RDD} = \arctan\frac{0.10}{0.174} = 30^\circ .
$$
**合成漂移强度**是$0.20/(0.4+0.6) = 0.20$、一个低的值因为两个风大部分抵消。一个有强合成与中等多变性的双峰风制给出走向030–210°的**纵向（seif）沙丘**；一个更低的合成给出**星形沙丘**、而一个接近1的合成给出**新月形或横向沙丘**。这是Fryberger-Schenk方法、而它是从一个沙丘场的平面形态读一个古风制的标准方式。
:::
:::

::: exercise 一个沙丘场的收支 {level=3}
一个沿风60公里长的沙丘海有15米的平均厚度、0.35的孔隙度、$0.030\ \mathrm{kg\,m^{-1}\,s^{-1}}$的输入沙通量、与$0.024\ \mathrm{kg\,m^{-1}\,s^{-1}}$的输出通量。求每单位宽度的年积累、在这个速率上沙丘海被建立的时间、以及这个不平衡对沙丘海的未来意味着什么。
::: solution
净保留是$0.030 - 0.024 = 0.006\ \mathrm{kg\,m^{-1}\,s^{-1}} = 1.9\times10^{5}\ \mathrm{kg\,m^{-1}\,yr^{-1}}$。沙丘海每单位宽度的沉积库是
$$
60\,000\times15\times2650\times0.65 = 1.55\times10^{9}\ \mathrm{kg\,m^{-1}},
$$
所以在当前的不平衡下沙丘海将在
$$
\frac{1.55\times10^{9}}{1.9\times10^{5}} = 8100\ \mathrm{yr}.
$$
里建立。八千年是一个活动沙丘海一个合理的全新世年龄、所以现在的不平衡**有建立这个沙丘海的正确量级**、而沙丘海是一个**瞬态、生长**的体、不是一个稳态的。

对其未来的含义是沙丘海**在其出口处被饿住**：沙被捕获、沙丘在增厚而非迁移、而这个场将继续生长直到风制改变、直到上风源的供应耗尽、或直到沙丘海自己的表面粗到足以减少输入的通量。另一种阅读——沙丘海是一个更湿而有风的事件的**残遗**、而现在正在缓慢吹蚀——要求通量测量不具代表性、而如果它们在一个季节里做出这是可能的。检验是**通量测量在几年上的重复**、与一个在沙丘海底部与顶部的**OSL年龄**：一个年轻的底与一个年轻的顶、加上一个生长的厚度、意味着一个活动的沙丘海、而一个老的底与一个年轻的吹蚀面在顶部意味着一个正在被摧毁的残遗的。
:::
:::

::: exercise 一场沙尘暴与海洋 {level=3}
一次撒哈拉沙尘爆发在两周内把$2.5\ \mathrm{g\,m^{-2}}$的粉尘沉积在$4\times10^{6}\ \mathrm{km^2}$的北大西洋上。求总质量、与铁输入、取粉尘的铁含量为3.5%、其中1%具有生物有效性。与支撑一个$0.1\ \mathrm{Gt\,C\,yr^{-1}}$的碳抽吸所需的大气铁输入比较（假设一个$10^{-5}$ mol/mol的Fe:C比）。
::: solution
质量是
$$
2.5\ \mathrm{g\,m^{-2}}\times4\times10^{12}\ \mathrm{m^2} = 1.0\times10^{13}\ \mathrm{g} = 10\ \mathrm{Tg}
$$
两周里的粉尘。具有生物有效性的铁是
$$
10\times10^{12}\times0.035\times0.01 = 3.5\times10^{9}\ \mathrm{g} = 3.5\ \mathrm{Gg\ Fe} = 6.3\times10^{7}\ \mathrm{mol\ Fe}.
$$
在一个$10^{-5}$ mol/mol的Fe:C比，这个铁能支撑的碳固定是
$$
\frac{6.3\times10^{7}}{10^{-5}} = 6.3\times10^{12}\ \mathrm{mol\ C} = 7.6\times10^{13}\ \mathrm{g} = 0.076\ \mathrm{Gt\ C}.
$$
在同一个比上$0.1\ \mathrm{Gt\,C\,yr^{-1}}$所需的输入是$10^{-5}\times8.3\times10^{12} = 8.3\times10^{7}\ \mathrm{mol\ Fe\,yr^{-1}} = 4.7\ \mathrm{Gg\ Fe\,yr^{-1}}$、所以**一场两周的沙尘暴输送约一年的四分之三**的该抽吸所需的铁。

算术是对的而结论不是、由于三个原因。只有一部分粉尘沉积在铁能被使用的**透光表层**、而大部分沉到真光带之下。铁的**溶解度**取决于粉尘的矿物学、大气的酸度——人为的硫酸盐与硝酸盐大大增加溶解度——以及受纳水体的生物。而**养分限制**必须是真实的：铁只在铁是限制养分之处有帮助、即高硝酸盐低叶绿素的区域——南大洋、亚北极太平洋、赤道太平洋——而不是撒哈拉大部分粉尘实际落下的富铁的北大西洋副热带环流。**IronEx、SOIREE、SOFeX、EIFES与LOHAFEX**实验给出的碳响应比简单的比预测的小一个数量级、而铁施肥假说在一个海盆的尺度上仍未被证明。
:::
