流域是陆地表面的自然单元、而它是唯一一个其几何可以从上方完全测量的景观。它的面积、它的起伏、它的河道数与长度、它的网络密度、与它的高度曲线的形状、都能在一个下午从一个数字高程模型测量、而它们携带关于岩石、气候、构造与时间的信息。这个几何的定量研究始于Horton在1932年从一个河道网络预测一个流域的洪水过程线的尝试、而它仍是地貌学里定律最美丽、而最少因果的分支。

## Horton定律

::: definition 河流分级与比 {#def-horton}
**Strahler河流分级**从顶部给河道编号：一条源河道是1级、两条1级河道汇合给出2级、一条1级与一条2级汇合给出2级、而两条同级的汇合给下一级。**Horton定律**然后是经验的幂律。**分叉比**
$$
R_b = \frac{N_\Omega}{N_{\Omega+1}}
$$
是每条$(\Omega+1)$级河道的平均$\Omega$级河道数、而每级的河道数按一个几何级数下降、$N_\Omega = N_1 R_b^{1-\Omega}$。**长度比**$R_L$与**面积比**$R_A$是平均河道长度与每级平均汇水面积的相应比。自然的值是$R_b = 3$–$5$、$R_L = 1.6$–$2.5$、$R_A = 2$–$4$、而它们在两三个数量级的流域大小上的恒定是排水网络的**自相似性**。
:::

::: definition 水系密度 {#def-density}
**水系密度**是每单位集水面积的河道总长度、
$$
D = \frac{\sum L}{A} \quad [\mathrm{km\,km^{-2}}],
$$
而它是单一信息最多的形态测量数字、因为它测量**河道的延伸与给它供水的坡地面积之比**。值从干旱或透水地形的0.3–0.6、通过温湿景观的1–2、到高度切割的湿润山地或软的、易蚀的泥岩的3–5。控制是经典的五个：岩石的**可蚀性**（泥岩高、块状石灰岩或花岗岩低）、**气候**（湿润比干旱高、而湿冷气候下比暖的高、因为冻融与低的蒸散）、**植被**（某些背景下森林比草地高、而另一些相反）、**构造**（一个基岩或节理控制产生一个矩形或格状图案、在薄弱层沿向密度高）、以及**时间**（一个年轻的、近期隆起的流域密度低、并随网络向源延伸而增加）。
:::

::: example 测量一个流域 {#ex-horton}
一个流域的河道网络给出190条1级、48条2级、12条3级、3条4级、与1条5级河流。求分叉比、平均$R_b$、以及若流域恰好服从$R_b = 4$、有1条5级河流，预期的1级河流数。
::: solution
$$
R_b(1\to2) = \frac{190}{48} = 4.0, \quad
R_b(2\to3) = \frac{48}{12} = 4.0, \quad
R_b(3\to4) = \frac{12}{3} = 4.0, \quad
R_b(4\to5) = \frac{3}{1} = 3.0,
$$
所以平均是$4.0$、而网络是一个几乎教科书式的Horton式的。以恰好$R_b = 4$与一条5级河流、预期的数是
$$
N_4 = 4, \quad N_3 = 16, \quad N_2 = 64, \quad N_1 = 256,
$$
对观察的3、12、48与190。观察的网络**低级河道比理想的少**、这是偏离通常的方向、而有三个原因：源河道最难测绘、而最常被漏掉、所以低级的计数偏向低；网络的向源侵蚀的尖端**尚未与理想达到平衡**；而一个真实流域的后壁是**坡地**、不是河道、所以最低的级按构造是不完整的。

实际的数字是$R_b$、而它的值有诊断性。一个3–5的分叉比是一个由均匀的过程塑造的流域的正常范围。一个**高于6**的比意味着网络是**树枝状的、低效的**、是一个近期隆起或近期去冰的、其河道尚未连起来的地区的典型。一个**低于3**的比意味着一个**分汉或低级**的网络、是一个三角洲、一个喀斯特、或一个其河道由一个稀疏的节理组控制的流域的典型。
:::
:::

caption: 一个有$R_b = 4$与256条1级河流的流域的每级河流数、画为一个连续的指数$N = 256\times4^{1-\Omega}$。对数-线性图上的一条直线是Horton的第一定律、而其斜率是$\ln R_b$。在河流数的四个数量级上的线性是从未由一个机制导出的经验事实：没有一个河道起始的模型从第一性原理预测一个常数的分叉比、而最接近的模型——Shreve的、以及Leopold与Langbein的随机网络与最优河道理论——把它作为一个最大熵或最小功率假设的统计结果、不是一个动力学定律来再现它。$R_b$的恒定因此是一个排水网络是**统计自相似**的陈述、而它是地球科学里最稳健的图案之一。
:::

::: history
排水流域的定量描述始于**Horton**、他1933年在*Journal of the Franklin Institute*上的论文提出了河流数的几何级数、分叉比、水系密度、与入渗容量、至今仍以他的名字命名、全部服务于预测一个未设站流域的洪水过程线。**Strahler**提供了1952年的分级系统、1952年的高度分析、与1964年使整个装置成为标准的定量集成。**Shreve**在1966–69年表明Horton定律与一个网络的随机拓扑模型在统计上不可区分、这是对以比是动力学地决定的这一思想的第一次严重的挑战、而**Leopold与Langbein**1962年关于最小方差假说的论文提供了另一个选择：一个网络把自己排列成以每单位长度的均匀速率分配能量。**水系密度**的控制由**Gregory与Walling**在1968年、以及**Morisawa**确立、而**河道起始阈值**由**Smith与Von Seckach**、**Montgomery与Dietrich**、以及**Tucker与Bras**确立。**TOPMODEL**指数是Beven与Kirkby的1979年论文、它把一个地形指数变成一个预测的水文模型。**沉积物级联**与**遗留沉积**概念是**Hubble、Reid与Sear**、**Trimble**（他1974与1999年关于美国南部 跌落线库的论文创立了这个领域）、以及使用铯-137的**Van Oost、Verheggen、Heckelmann与Van Rompaey学派**的工作。河网的**自相似性**及其与临界现象的联系是**Rigon、Rodriguez-Iturbe、Maritan、La Barbera与Banavar**在1994年的工作。
:::

## 形状、起伏与高度曲线

::: definition 流域形状指数 {#def-shape}
**延伸比**是$R_e = 2\sqrt{A/\pi}/L_\text{max}$、对一个圆是1、对一个正方形是0.71；一个低的值意味着一个排水高效、给出一个**陡涨、尖峰**的洪水过程线的长形流域、而一个高的值意味着一个给出一个**宽缓、延迟**的过程线的紧凑流域。**圆形度比**是流域面积与同周长圆的面积之比、而**形状因子**是对轴长$L_c$的$A/L_c^2$。主河道的**弯曲度**是它的长度除以谷地的轴长。这些指数在工程水文学里用于给一个未设站的流域建造一个单位过程线、而它们是一个洪水能从一张地图被预报的原因。
:::

::: definition 高度曲线 {#def-hypsometry}
**高度曲线**是一个流域高程的累积分布、画为一个高于一个给定高度的面积的分数对归一化的高度。**高度积分**是其下的面积、
$$
HI = \frac{\bar{z} - z_\text{min}}{z_\text{max} - z_\text{min}},
$$
而它是流域原始质量有多少已被移除的一个度量。Strahler把$HI > 0.6$解释为**幼年**、$0.35$–$0.6$为**壮年**、$< 0.35$为**孤山**或老年、论据是一个年轻流域的大部分面积接近原始的高面、而一个老的接近基准面。这一解释被反复限定：高度积分取决于**隆升与侵蚀历史**、取决于**岩性构造**——一个由一个抗蚀的盖岩覆在软页岩之下的流域无论其年龄如何都有高的积分——以及取决于**初始表面的形状**、所以一个高的积分可能意味着一个年轻的流域、一个抗蚀的盖、或一个近期倾斜的断块。
:::

::: example 从一个流域的形状读出它的年龄 {#ex-hypsometry}
两个相似面积与气候的流域有以下数据。流域A：$z_\text{max} = 1420\ \mathrm{m}$、$z_\text{min} = 180\ \mathrm{m}$、平均高程$890\ \mathrm{m}$、水系密度$2.9\ \mathrm{km\,km^{-2}}$、$R_b = 3.6$。流域B：$z_\text{max} = 1420\ \mathrm{m}$、$z_\text{min} = 180\ \mathrm{m}$、平均高程$410\ \mathrm{m}$、水系密度$1.1\ \mathrm{km\,km^{-2}}$、$R_b = 4.4$。解释。
::: solution
$$
HI_A = \frac{890 - 180}{1420 - 180} = \frac{710}{1240} = 0.57, \qquad
HI_B = \frac{410 - 180}{1240} = 0.19 .
$$
流域A是**壮年到幼年**、大部分面积仍然高、而它有一个**密集的**河道网络与一个低的分叉比。流域B是**老的**、81%的质量被移除、而它有一个**稀疏的**网络与一个高的分叉比。

两个阅读一致、而它们讲一个故事。流域A正被**主动切割**：它高的积分与它密集的网络意味着河道已向源延伸进一个尚未被降低多少的表面、而它低的$R_b$意味着网络仍在连接。流域B是一个**残遗、低起伏的侵蚀面**——一个**准平原**或一个**剥蚀面**——其河道已切到一个低的水平、其相间已被减少到残余、而其网络稀疏因为剩下的坡地短、而河道间距宽、连接良好。

要排除的另一种阅读是**岩性**。一个在一个抗蚀的盖岩之下的流域长时间保持一个高的积分、而一个在软泥岩里的流域很快达到一个低的积分；而一个密集的网络可能意味着软的岩石、不是主动的切割。判别是**河道头的坡度与沉积物通量**：一个主动切割的流域输出一个高的沉积载荷、带一个粗的推移质、而一个残遗的输出很少、并携带一个细的、再工作的、有时是成土的载荷。第二个判别是**宇宙成因剥蚀速率**、在流域A它应当是流域B的几倍。
:::
:::

::: example 汇流时间 {#ex-tc}
一个流域的汇流时间的**Kirpich公式**是
$$
t_c = 0.0195\,L^{0.77}\,S^{-0.385} \quad \text{minutes},
$$
$L$是最长的流路（米）、$S$是平均坡度（m/m）。求一个8公里、坡度0.02的流域的$t_c$、同一个流域坡度0.005的、以及一个2公里、坡度0.02的城市流域的。结果对城市洪峰说什么？
::: solution
$$
L = 8000\ \mathrm{m},\ S = 0.02:\quad t_c = 0.0195\times1012\times4.51 = 89\ \mathrm{min};
$$
$$
S = 0.005:\quad t_c = 152\ \mathrm{min}; \qquad
L = 2000\ \mathrm{m},\ S = 0.02:\quad t_c = 31\ \mathrm{min}.
$$
汇流时间是整个流域能贡献于洪峰的时间、而在推理法里它是**设计暴雨的历时**：一个比$t_c$短的暴雨无法把整个流域带入洪峰、而一个比$t_c$长的暴雨把它后来的雨浪费在一个已经贡献了的流域上。

城市的后果立即随之。一个2公里的流域有一个31分钟的$t_c$、对一个8公里乡村的89分钟、所以一个小的城市化的流域响应一个大的乡村流域会平均掉的**短、强的对流暴雨**、而它的单位面积的洪峰流量相应更大。铺装一个流域同时做三件事：它提高径流系数、它提高洪峰、而——因为管道与涵洞比坡面流快——它**缩短**$t_c$、这把设计暴雨移到一个更短、更强、因此更罕见的事件上。一个在乡村$t_c$上设计的排水系统将被城市化流域现在最敏感的那些风暴恰好压垮。

谨慎是Kirpich的公式是对**Tennessee陡峭的乡村农业流域**拟合的、而它在平坦的、城市化的或河道主导的流域上表现很差、那里流时由管网、不是由地形设定。它在地貌学里的价值不是作为一个预测者、而是作为一个**量纲的陈述**：一个景观的响应时间按$L^{0.77}$与$S^{-0.385}$标度、所以一个流域的洪水响应由它的**形状与起伏**设定——这就是为什么上两节的形态指数既是工程水文学、也是地貌学。
:::

## 级联

::: definition 沉积物路由 {#def-cascade}
一个流域是一个**沉积物级联**、其中在坡地上产生的材料在离开之前被一个**汇**的序列——坡面洼地、谷底、河漫滩、水库、湖、河口——储存、再工作与释放。**沉积物输移比**是到达出口的侵蚀材料的分数、它在一个小的、陡的、连接良好的流域上从1降到一个大的、低地的0.01–0.1、因为河漫滩与水库拦截它。一份沉积物通过一个流域的**流时**通常是$10^2$–$10^5$年、而它由沉积物在出口相对其源的宇宙成因或放射性碳年龄测量。后果是一条河**在出口的载荷是一个时间平均、空间混合、而强烈延迟的**信号、关于其坡地上正在发生的侵蚀、而在一个水文站测量的宇宙成因剥蚀速率是整个集水区与最后几万年的平均、不是坡地现在在做什么的测量。
:::

::: example 一个沉积物收支 {#ex-cascade}
一个$600\ \mathrm{km^2}$的流域向它的出口输送$4\times10^{5}\ \mathrm{t\,yr^{-1}}$的悬移质与$2\times10^{4}\ \mathrm{t\,yr^{-1}}$的溶解载荷。坡地估计产生$3.0\times10^{6}\ \mathrm{t\,yr^{-1}}$的耕作与水蚀。求沉积物输移比、储存速率、以及若流域的河漫滩库含$10^{8}\ \mathrm{t}$、它被填满的时间。
::: solution
出口的总产沙是$4.2\times10^{5}\ \mathrm{t\,yr^{-1}}$、所以坡地源的**沉积物输移比**是
$$
\mathrm{SDR} = \frac{4\times10^{5}}{3.0\times10^{6}} = 0.13 .
$$
**储存速率**是差、
$$
3.0\times10^{6} - 4\times10^{5} = 2.6\times10^{6}\ \mathrm{t\,yr^{-1}},
$$
在$6\times10^{8}\ \mathrm{m^2}$上这是谷底与河漫滩上$4.3\ \mathrm{t\,ha^{-1}\,yr^{-1}}$的净积累。一个$10^{8}\ \mathrm{t}$的库将在
$$
\frac{10^{8}}{2.6\times10^{6}} = 38\ \mathrm{yr},
$$
里被填满、这远短于任何河漫滩的年龄——所以库**没有**在填满、而要么侵蚀的估计太高、要么河漫滩正被再工作、而其更老的沉积正被带出、要么"缺失的"沉积正去一个不在收支里的水库或湖。

那个矛盾是这个练习的要点。一个不闭合的沉积物收支是正常状态、而分歧是其中信息最多的数字。三个通常的化解是：**坡地侵蚀的估计是一个总的、小区尺度的数字**、它多计了从未离开田地的材料；**河漫滩是一个源、也是一个汇**、在弯的外侧被侵蚀、而在内侧加积；而**流域不处于平衡**、所以出口的载荷是以前一个土地利用或以前一个气候的一个储存的沉积物脉冲的遗留、在几个世纪里释放。在英格兰、法国与美国东部、最后一种主导：河流仍在排走十九世纪曲辕犁的沉积、而其现在的载荷即使在源的侵蚀今天被停止，仍将继续上升几十年。
:::
:::

::: warning 一个形态测量的定律是一个描述、不是一个机制
Horton定律、水系密度的控制、高度的解释、与坡度-面积关系全都是因果地位有争议的**经验规律**、而定量地貌学的失效模式是把它们倒过来读。一个**高的分叉比**不证明一个年轻的流域；它可能只证明源区没有被测绘。一个**高的高度积分**不证明一个年轻的景观；一个抗蚀的盖或一个近期倾斜的断块产生同一条曲线、而一个流域能把一个高的积分保持几千万年。一个**低的水系密度**不证明一个干旱的气候；它可能证明一个透水的石灰岩或一个深根的草地。而网络的**自相似性**——$R_b$在尺度上的恒定——是一个关于网络的统计的陈述、而对制造它的过程什么也不说、因为一个随机的铺砌、一个最优能量的网络、与一个临界渗流的团簇都给出同样的比。学科规矩是把每一个形态指数当作一个**假说生成器**、不是一个诊断、并用现在地貌学有的四个独立的观察检验这个假说：一个宇宙成因剥蚀速率、一个已定年的层、一个沉积物通量、与一张岩性与构造的图。在这四者与形态测量一致之处、解释成立；在不一致之处、形态测量在关于别的东西讲真话。
:::

::: quiz
一个流域有一个0.72的高度积分与一个0.5 km/km²的水系密度。哪个阅读最站得住？
- [ ] 它是一个年轻的、主动切割的景观。
- [x] 它是一个高的、轻切割的面——可能是年轻的、也可能是一个抗蚀的或干旱的、只是尚未被切的面。
- [ ] 它是一个老的准平原。
- [ ] 它的岩石是软的泥岩。
::: solution
一个高的积分说大部分面积仍然接近原始的高面、而一个低的密度说河道少。两者都与一个年轻的切割面一致、但同样与一个其河道无论年龄如何都稀疏的干旱或透水石灰岩面一致、或与一个保持起伏的抗蚀的盖一致。形态测量本身无法选择、而判别是一个独立的剥蚀速率、一个已定年的面、或一张岩性图。软的泥岩会给出一个高的、不是低的水系密度。
:::

::: summary
- Horton定律描述一个分叉比为3–5的自相似的河道网络、而这是一个尚无机制导出的经验规律。
- 水系密度测量河道长度与坡地面积之比、并响应岩石、气候、植被、构造与时间。
- 高度积分测量一个流域的质量有多少已被移除、而它既是一个岩性的、也是一个年代的指数。
- 流域形状控制洪水过程线、这就是为什么形状指数既是工程水文学、也是地貌学。
- 一个流域是一个输移比远低于1的沉积物级联、而它的载荷是延迟的、混合的、而常常是一个遗留。
- 形态定律生成假说；它们不证明机制、而必须对照年代、通量与图检验。
:::

## 练习题

::: exercise 分叉比 {level=1 check="4"}
一个流域有120条1级、30条2级、8条3级、与2条4级河流。求平均分叉比。
::: solution
$120/30 = 4.0$、$30/8 = 3.75$、$8/2 = 4.0$；平均是$3.9$、一个正常的值。网络与其过程处于平衡。
:::
:::

::: exercise 水系密度 {level=1 check="1.6"}
一个$250\ \mathrm{km^2}$的流域有400公里测绘的河道。求水系密度。
::: solution
$D = 400/250 = 1.6\ \mathrm{km\,km^{-2}}$、一个中等密集的温湿网络。
:::
:::

::: exercise 高度积分 {level=1 check="0.35"}
一个流域从120米到940米、平均高程407米。求高度积分。
::: solution
$HI = (407 - 120)/(940 - 120) = 287/820 = 0.35$。一个壮年到老的流域、其原始质量约三分之二被移除——受岩性谨慎的限制。
:::
:::

::: exercise 延伸 {level=2}
两个$400\ \mathrm{km^2}$的流域有40公里与22公里的最大长度。求它们的延伸比、并说出哪个给出更陡涨的洪水。
::: solution
对同面积的圆、$2\sqrt{A/\pi} = 2\sqrt{400/\pi} = 22.6\ \mathrm{km}$。
$$
R_{e,1} = \frac{22.6}{40} = 0.56 \quad(\text{elongate}); \qquad
R_{e,2} = \frac{22.6}{22} = 1.03 \quad(\text{circular}).
$$
**圆形**的流域给出更陡涨的洪水、因为落在其任何地方的水离出口至多一个短的距离、而贡献一起到达。长形的流域的过程线宽而延迟、因为上半的水在下游的一半的水之后几小时到达。这就是为什么形状指数被用于给未设站的流域建造单位过程线。
:::
:::

::: exercise 地形指数 {level=2 check="7.4"}
饱和溢流径流机制由TOPMODEL指数$\ln(a/\tan\beta)$驱动、其中$a$是每单位等高线长度的上坡汇水面积、$\beta$是局部坡度。求$a = 120\ \mathrm{m}$与$\beta = 4^\circ$的指数。
::: solution
$\tan 4^\circ = 0.0699$、所以$a/\tan\beta = 120/0.0699 = 1717$而$\ln 1717 = 7.4$。一个高的指数意味着一个汇合的、低坡的洼地、它最先饱和、并以饱和溢流产生径流；一个低的指数意味着一个发散的、陡的坡地、它排走入渗的水、而从不饱和。指数的空间图案因此**提前测绘汇流区**、而它是一个流域的径流能仅从其地形被预测的原因。
:::
:::

::: exercise 一个不是Horton式的网络 {level=2}
一个流域的河道网络对前三级给出$R_b = 8.5$、对最后两级给出2.1。正在发生什么？
::: solution
两个不同的制度存在。**低的级高的比8.5**意味着许多1级与2级河道给每条3级河道供水——一个**树枝状的、低效的、连接差的**源网络、是一个近期隆起或近期去冰的地区、或一个其后壁仍在延伸的软岩景观的典型。**高的高级的比2.1**意味着干流由少数大的支流供水、这是一个其低级**由构造控制**的流域的典型——一个支流沿一个节理组或一个薄弱层进入的格状或矩形图案——或一个其下部干流被**叠置**在一个更老的图案上的流域。

解释是一个在一个**由构造控制的干流**之上有一个**未完成的源网络**的流域、而检验是地图上的排水图案：下部的一个格状或矩形图案、与其上一个树枝状的图案会证实它、而一个DEM晕渲会立即显示它。
:::
:::

::: exercise 一个转变中的景观 {level=3}
一个山区前沿有三个相邻的、相似面积、岩性与气候的流域。它们的高度积分是0.71、0.52与0.28、它们的水系密度是3.4、2.1与0.9、而它们的宇宙成因剥蚀速率是1400、620与90 µm/yr。解释、并识别制造差别的过程。
::: solution
三个流域位于一个**形态与剥蚀的序列**上、它从一个高的积分、一个密集的网络、与一个高的剥蚀速率、运行到一个低的积分、一个稀疏的网络、与一个低的速率。高度积分与剥蚀速率之间的相关是**正的**、这是对于一个其河道在主动下切、而起伏正在维持的景观预期的关系：基准面切得越多、起伏越高、网络越密、而积分越高、因为高原面尚未被消耗。

制造差别的过程是**出口处的下切**、而在一个山区前沿通常的原因是一个陡崖底部的**岩石**、或其脚下的**活动断层**的差别。快的流域跨一个山前断层的一个活动段、或跨一个薄弱的组排水、它的基准面正在快速下降、而它是一个**基岩河道、输移耦合**的系统、有一个陡的纵剖面与一个高的沉积物通量。慢的流域跨一个不活动的或一个抗蚀段的脚下排水、它的基准面几乎稳定、而它是一个**解耦**的系统、其河道是河成的、其坡地缓慢地剥蚀供沙、而其高原是一个残遗面。

检验是三重的。**基岩河道**应当在快的流域出露、而在慢的流域被埋在冲积层之下。**裂点**或断层陡崖应当在快的流域的出口可见。而快的流域的高原上的**宇宙成因深度剖面**应当显示一个近期被剥去的面、而慢的流域的高原应当显示一个深的、未受扰的、老的风化层。在三者都一致之处、形态测量被从一个描述转换成对构造的一个测量。
:::
:::

::: exercise 遗留沉积 {level=3}
美国中西部一条河在其水文站的沉积载荷从1940年的$2\times10^{6}\ \mathrm{t\,yr^{-1}}$升到2000年的$8\times10^{6}\ \mathrm{t\,yr^{-1}}$、而它的坡地侵蚀、由铯-137与小区研究测量、自1980年以来**恒定**、而比1930年代低。解释。
::: solution
载荷在上升而源不是、所以额外的沉积来自**储存**。流域的河漫滩、谷底与冲沟在1850到1930年代大侵蚀事件期间被装上沉积、那时草原被开垦、而曲辕犁被施用最陡的地；那一份脉冲现在正被**再活动化**、因为河道被后来的土地利用加深与稳定、切进它们自己的冲积层。这条河在排走一个**遗留**——一个一百年库龄的沉积库——而它的载荷是那个库的连接性的度量、不是现在坡地侵蚀的度量。

三个观察证实诊断。河道的推移质的**铯-137活度**应当低、因为铯-137源自1954年、而一个低的活度意味着沉积来自1954年层之下——即来自1950年前储存的冲积层。**河道横断面**应当在测量的断面上**加深**、这是切进库的直接证据。而**沉积物水位关系曲线**应当在每次洪水里显示一个上升的滞后、浓度在涨水段更高、这是一个正在被刷出的、不是从坡地输送的供应的签名。

后果对政策是令人不适的：因为库大而释放慢、这条河的沉积载荷、以及随之而来的富营养化与生境破坏、将**继续上升几十年**、即使坡地侵蚀明天被降到零。唯一快速起作用的杠杆是打破**连接性**——重新连接河漫滩、建造退让带、把沉积保持在洼地里——而不是试图减少其源的侵蚀。
:::
