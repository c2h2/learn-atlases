一个床上的颗粒被它的重量、它邻域的摩擦保持在着那里，流体的阻力与升力超过着它们时移动着。沉积学的其余的一切——一个沙丘形态的形状，一个砂的分选，一个储层的几何，一个盆地的充填的建筑——从两个力的平衡、流在做着移动的事之后的行为跟着。本课是上一个的粒度统计背后的力学。

## 流与它的应力

::: definition 剪切的流速，边界的剪切应力 {#def-shear}
对一个宽的、均匀的、深度 $H$、能量的坡度 $S$ 的明渠的流，**边界的剪切应力**——水在一个床的每单位的面积施加着的切向的力——是
$$
\tau_0 = \rho_f\, g\, H\, S ,
$$
**剪切的流速**是
$$
u_* = \sqrt{\tau_0/\rho_f} .
$$
剪切的流速、不是均值的流速，是控制着颗粒的运动量，它是实际在一个颗粒上施加着力的黏性的子层的湍流的涡的速度尺度。对一个 $1.5$ m 的深度、$3\times10^{-5}$ 的坡度的流，它是 $0.021\ \mathrm{m/s}$，均值的流速可能是 $1.1\ \mathrm{m/s}$——一个五十的因子，一个看起来慢的河能移动着粗的砂、一个看起来快的河什么都不移动着的理由。
:::

::: definition 希尔兹的参数 {#def-shields}
**希尔兹的参数**是流体的带动的力对颗粒的抵抗的重量的比，
$$
\theta = \frac{\tau_0}{(\rho_s - \rho_f)\, g\, d} ,
$$
一个无因次的粒子的直径、一个无因次的应力。运动在一个**临界的希尔兹的参数** $\theta_{cr}$ 开始着，它是粒子的雷诺数 $\mathrm{Re}_* = u_* d/\nu$ 的一个函数：对 $0.1$ 与 $2\ \mathrm{mm}$ 之间的砂约 $0.045$，因为粒子的内聚力升到很细的砂与粗的粉砂的 $0.1$ 或更多，对它的床互相咬合着的砾再次升起。**希尔兹图**绘制着 $\theta_{cr}$ 对着 $\mathrm{Re}_*$，沉积的运输的分析使用最多的单图；**胡尔斯壮姆图**是它的祖先，以速度、不是应力的单位画着。
:::

::: example 床在移动着吗？ {#ex-shields}
一条低地的河有一个 $1.5$ m 的深度、一个 $3\times10^{-5}$ 的坡度、一个 $1.1\ \mathrm{m/s}$ 的均值的流速、一个 $d_{50} = 0.25\ \mathrm{mm}$ 的砂的床。取 $\rho_s = 2650$、$\rho_f = 1000\ \mathrm{kg\,m^{-3}}$、$\nu = 10^{-6}\ \mathrm{m^2\,s^{-1}}$。找着 $\tau_0$、$u_*$、$\theta$、流的雷诺数，说着床是否移动的、在什么模式。
::: solution
$$
\tau_0 = 1000\times9.81\times1.5\times3\times10^{-5} = 0.44\ \mathrm{Pa}, \qquad
u_* = \sqrt{0.44/1000} = 0.021\ \mathrm{m\,s^{-1}} ,
$$
$$
\theta = \frac{0.44}{1650\times9.81\times2.5\times10^{-4}} = \frac{0.44}{4.05} = 0.109 .
$$
$\theta_{cr} = 0.045$ 床在**阈值的 $2.4$ 倍**应力着，它是移动的。流的雷诺数是 $uH/\nu = 1.1\times1.5/10^{-6} = 1.7\times10^{6}$，流完全湍流着。

模式从**劳斯数**跟着，
$$
P = \frac{w}{\kappa u_*} = \frac{0.030}{0.4\times0.021} = 3.6 ,
$$
$w = 0.030\ \mathrm{m\,s^{-1}}$ 是一个 $0.25$-mm 的颗粒的弗格森–丘奇的沉降的速度。一个 $2.5$ 之上的劳斯数意味着颗粒不能被湍流的扩散保持在悬浮：它作为**推移质**移动着，滚动与跃移，在一个床旁边的几个颗粒的直径的厚的层里。河因此一个搬运着推移质的流，它的床是一个有波痕的、有沙丘的表面、不是一个上面有一个悬浮的砂的云的平的床。

这个流完全能移动着的最大的颗粒靠设着 $\theta = \theta_{cr}$ 找到：
$$
d_{cr} = \frac{\tau_0}{(\rho_s - \rho_f) g\,\theta_{cr}} = \frac{0.44}{1650\times9.81\times0.045} = 0.61\ \mathrm{mm},
$$
流能移动着到 $0.6\ \mathrm{mm}$ 的粒、更粗的什么都不。同一个河道的一个有 $20$-mm 的卵石的砾的坝因此**残余的**，一个一千年没有返回的洪水的矿层，把它作为一个现代的床读着将给出一个太一个数量级的古水力的重建。
:::

## 运输的模式

::: definition 悬浮，跃移，溶液 {#def-modes}
沉积物以三个机械的模式、一个化学的模式移动着。**溶解的载荷**是风化的离子的产物、这里使用着的意义上不是一个沉积学的过程。**悬浮**在流内部的运输，湍流的涡支撑着，要求着一个劳斯数 $P = w/(\kappa u_*) \lesssim 2.5$；悬浮的颗粒跟着着流体、只在流死去时沉积着。**跃移**是沿着床的短的跳跃的一个接续，每一次跳跃一个湍流的爆发发射着、一个撞击终止着，$0.1$ 与 $1\ \mathrm{mm}$ 之间的砂的主导的模式；跃移的颗粒做着带动的工作，一个跃移的砂的床移动着更多的砂比一个静止的有效率几倍。**推移质**滚动、滑动、爬行的与床的连续接触，粗的砂与砾主导着。经典意义的**牵引**——产生着叠瓦构造与一个砾的坝的人字形的交错层理的连续的滚动——是推移质的最粗的案例。
:::

::: proposition 劳斯的剖面 {#prop-rouse}
在一个均匀的湍流的流里悬浮的沉积物的时间的均值的浓度向上减少着作为
$$
\frac{c(z)}{c(a)} = \left(\frac{a\,(h - z)}{z\,(h - a)}\right)^{P}, \qquad P = \frac{w}{\kappa u_*},
$$
$a$ 是一个参考的高度，$h$ 流的深度，$\kappa = 0.4$ 冯·卡门的常数。**劳斯数** $P$ 因此控制着整个的垂直的分布：当 $P \to 0$ 浓度均匀的、沉积物是冲刷的载荷，当 $P$ 超过约 $2.5$ 浓度限制在一个床的薄的层。
:::

::: proof
靠沉降的颗粒的向下的通量 $w c$ 等于着向上的扩散的通量 $-\varepsilon_s\, dc/dz$，沉积物的扩散的系数取为等于着动量的涡的黏度 $\varepsilon_s = \kappa u_* z$。然后
$$
w c = \kappa u_* z\frac{dc}{dz} \quad\Longrightarrow\quad \frac{dc}{c} = -P\,\frac{dz}{z},
$$
它积分到 $c \propto z^{-P}$。应用着自由表面的净通量为零的边界的条件，$w c = \kappa u_*(h - z)\,dc/dz$，给出上面的完全的劳斯的形式。证明依靠着沉积物以动量的同一个速率扩散着的假设，对砂大致真实的、对絮凝的泥很坏的错的，它的聚集体是多孔的、在湍流里破碎着、有一个依赖于浓度自己的有效的沉降的速度。
:::

::: example 冲刷的载荷，悬浮的载荷，推移质 {#ex-rouse}
三个物质被床在移动着的例子的流携带着：一个 $2$-µm 的黏土，一个 $62$-µm 的粉砂、床的 $250$-µm 的砂。计算着劳斯数、每一个的近床的浓度对中间的深度的浓度的比，取着 $\kappa u_* = 0.0084\ \mathrm{m\,s^{-1}}$。
::: solution
弗格森–丘奇的公式的沉降的速度是 $3.4\times10^{-7}$、$3.1\times10^{-6}$、$3.0\times10^{-2}\ \mathrm{m\,s^{-1}}$，给出
$$
P_\text{clay} = \frac{3.4\times10^{-7}}{0.0084} = 4\times10^{-5}, \quad
P_\text{silt} = \frac{3.1\times10^{-6}}{0.0084} = 3.7\times10^{-4}, \quad
P_\text{sand} = \frac{0.030}{0.0084} = 3.6 .
$$
对 $P \ll 1$ 劳斯的剖面本质的均匀的，黏土与粉砂是**冲刷的载荷**：它们的浓度在每一个深度同样的、不是流的能力设定着、流域的供应设定着。砂，取着 $a = 0.05h$、$z = 0.5h$，
$$
\frac{c(0.5h)}{c(0.05h)} = \left(\frac{0.05\times0.5}{0.5\times0.45}\right)^{3.6} = (0.111)^{3.6} = 4\times10^{-4},
$$
中间的深度的砂的浓度**低两千五百倍**比近床的。砂是一个限制在流的最低的几个百分点的推移质的物质。

这是**冲刷的载荷**与**推移质**的矿层的野外区分的机械的基础。一个冲刷的载荷的矿层是一个泥，它的厚度记录着陆地的细粒的供应、铺设着它的流什么都不，这就是泥的韵律层是一个雨量计、不是一个流速计的理由。一个推移质的矿层是一个砂，它的粒度记录着床的流的应力、供应什么都不，这就是一个砂的体的粒度的趋势是一个古水力的仪器的理由。两者携带着相反的、补充的信息，一个地层的柱通过在它们之间交替着读着。
:::
:::

::: quiz
一个泥与一个细的砂并排在一个底部的应力在风暴期间达到 $0.10\ \mathrm{Pa}$、其余的 $0.01\ \mathrm{Pa}$ 的陆棚上。什么发生？
- [ ] 两者被每一场风暴侵蚀着、两者不保存着。
- [x] 砂反复地再工作着、很好的分选着；泥，它的阈值相当的、更高的、任何一个微生物的垫进一步升高的，逃避着侵蚀、保存着。
- [ ] 泥首先被侵蚀着，因为它的颗粒更小。
- [ ] 两者都不移动着，因为 $0.01\ \mathrm{Pa}$ 在两个阈值之下。
::: solution
阈值不只是粒度的一个函数。在约 $0.1\ \mathrm{mm}$ 之下临界的希尔兹的参数陡地升起，因为粒子的内聚力随着接触的面积标度着、颗粒的浸没的重量随着它的体积标度着，一个泥的侵蚀的阈值与一个细的砂的相当的、更大的，生物的粘结进一步升高着它。砂因此移动的阶段、泥存活着的那个，这就是风暴的层是一个覆盖着未扰动的泥的砂的体的理由。
:::
:::

::: history
沉积的运输的定量的研究从弗雷曼维尔与杜比松在 1860 年代关于砂与砾在一个水槽的运动的实验、1877 与 1914 的吉尔伯特的（Gilbert）专著开始着，从野外确立着一条河的能力与它的容量是分开的属性、两者穿过着一场洪水变化着。无因次的阈值的曲线由阿尔伯特·希尔兹（Shields）在他 1936 的学位论文测量着，它仍是这个学科复制最多的图；1935 的克里宁与胡尔斯壮姆（Hjulström）的经验的带动与沉积的曲线，以速度的单位画着，成为标准的教学的图。劳斯的方程来自亨特·劳斯（Rouse）1937 的论文，1948 的迈耶–彼得与穆勒（Müller）的公式拟合着瑞士的阿尔卑斯的溪流的数据、仍是工程的实践的推移质的方程。爱因斯坦的、巴格诺尔德的——它的 1941 与 1966 的书使沉积的运输成为流体力学的一个分支、不是水力工程——亚林的基于湍流的综合确立着物理学，野外的测量、声学的沉积的剖面、数值的模拟的现代的时代从 1970 年代的认识开始着，一个实验室的水槽测量着的阈值系统地预测过高着天然的床的运动，因为天然的床分选着、装甲化、生物地粘结着、满是预存的破坏。
:::

## 多少沉积物移动着

::: proposition 推移质的运输 {#prop-mpm}
对一个均匀的砂与砾的床在它的阈值之上应力着，每一个河道的宽度的推移质的通量由迈耶–彼得与穆勒的关系给出
$$
q_b = 8\,\bigl(R g d^3\bigr)^{1/2}\,\bigl(\theta - \theta_{cr}\bigr)^{3/2},
$$
$\mathrm{m^2\,s^{-1}}$。运输的速率因此一个**强烈的非线性的**超的应力的函数：在阈值之上剪切的应力的两倍把一个因子约 $2^{3/2} = 2.8$ 升高着通量、超的也两倍着，超的应力的远之上更多的。
:::

::: example 一个洪水里的一个砾的床 {#ex-mpm}
一个山地的溪流携带着一个 $10$-mm 的砾的床、在一个洪水期间一个 $10\ \mathrm{Pa}$ 的边界的剪切应力。取 $\theta_{cr} = 0.045$。找着推移质的通量，找着使它的双倍着的应力。
::: solution
$$
\theta = \frac{10}{1650\times9.81\times0.010} = 0.0618, \qquad
\theta - \theta_{cr} = 0.0168 ,
$$
$$
\bigl(R g d^3\bigr)^{1/2} = \bigl(1.65\times9.81\times10^{-6}\bigr)^{1/2} = 4.02\times10^{-3}\ \mathrm{m\,s^{-1/2}},
$$
$$
q_b = 8\times4.02\times10^{-3}\times(0.0168)^{3/2} = 8\times4.02\times10^{-3}\times2.18\times10^{-3} = 7.0\times10^{-5}\ \mathrm{m^2\,s^{-1}} .
$$
在一个 $5$-m 宽的河道上这是 $3.5\times10^{-4}\ \mathrm{m^3\,s^{-1}}$ 的砾、约每天 $30\ \mathrm{m^3}$——在一个世纪建造着一个坝、在一个千年移动着一个扇足够的。

通量的双倍着超的 $(\theta - \theta_{cr})$ 必须增加 $2^{2/3} = 1.59$ 倍，到 $0.0267$，$\theta$ 必须达到 $0.0717$、
$$
\tau_0 = 0.0717\times1650\times9.81\times0.010 = 11.6\ \mathrm{Pa}.
$$
**剪切的应力的百分之十六的增加使砾的通量双倍着**。这是一个景观的侵蚀被它的最大的、最稀有的洪水做着的理由，一条河的地貌的工作集中在十年里发生着几个小时的事件的理由：运输的定律是一个超的应力的幂，应力的分布偏斜着，两者的积由尾部统治着。
:::
:::

::: example 一个砾岩的古水力 {#ex-palaeo}
一个砾岩包含着叠瓦的砾，它们的**均值**的直径是 $60\ \mathrm{mm}$、它们的**最大的**砾是 $200\ \mathrm{mm}$。估计着边界的剪切应力、均值的流的速度，取着 $\theta_{cr} = 0.045$、一个曼宁的粗糙度 $n = 0.04$、一个水力的半径 $1\ \mathrm{m}$。
::: solution
设着 $\theta = \theta_{cr}$ 给出刚好足够移动着每一个大小的一块砾的应力：
$$
\tau = 0.045\times1650\times9.81\,d = 728\,d\ \mathrm{Pa},
$$
$60$-mm 的均值的 $\tau = 43.7\ \mathrm{Pa}$、$200$-mm 的最大的 $145.7\ \mathrm{Pa}$。结合着 $\tau_0 = \rho_f g R S$ 与曼宁的方程 $u = R^{2/3}S^{1/2}/n$ 消除着坡度，
$$
u = \frac{R^{1/6}}{n}\left(\frac{\tau_0}{\rho_f g}\right)^{1/2},
$$
$R = 1\ \mathrm{m}$
$$
u = 25\times(0.00445)^{1/2} = 1.7\ \mathrm{m\,s^{-1}} \quad\text{and}\quad u = 25\times(0.01485)^{1/2} = 3.1\ \mathrm{m\,s^{-1}} .
$$
流因此一个快的、深的、陡的山地的溪流，$u$ 只作为 $R^{1/6}$ 依赖着水力的半径的含义是估计对假设的深度不敏感：深度的两倍只把速度改变着百分之十二。

两个估计相差着一个二的因子，区别是方法的整个的困难。**均值**的砾的大小记录着移动着整个的床的应力、**最大的**砾记录着通过过的最大的洪水。一个古水力的重建应该引用着两者、说着哪一个意味着，一个由 $3\ \mathrm{m/s}$ 的洪水建造的扇、一个由 $1.7\ \mathrm{m/s}$ 的流建造的扇有一个完全不同的矿层的建筑——第一个是一个泥石流与推移质主导的冲积的扇带着厚的、差的分选的片，第二个是一个有组织的、叠瓦的、排水好的坝的辫状河。
:::
:::

::: warning 阈值的效果使岩石的记录关于平均的条件说谎
因为运动在一个阈值突然地开始着，一个矿层记录着流在它被沉积着时达到的**最大的**应力、它的平均的应力什么都不，它对太弱、不能移动着床的许多流什么都不记录着。三个系统的错误跟着。一个现代的海底的粗的砾、贝壳的**残余的滞后**记录着自最后的海平面的低水位以来的最大的事件、不是当前的制度，把它作为一个现代的过程的测量使用着产生着许多错的古水力的重建。一个**停滞的泥**关于经过着它的流什么都不记录着，因为它的阈值在它们的应力之上；一个富泥的 序列 因此能是一个安静的环境的矿层、一个它流简单地低于泥的侵蚀的阈值的环境的矿层，两者不由泥自己区分着。**一个砂岩的粒度是一个阈值的测量、不是一个平均的**：一个浊积石的层的 $d_{50}$ 记录着流的能力穿过那个大小落下着的时刻的应力，它发生在成层的阶段的末尾，层的**底部**的粒度是流的高峰的能力的更好的估计者、层的**顶部**系统地预测过低着它。每一个渐变的层是一个死去的流的记录，把它的均值的粒度作为它的平均的流的强度读着把重建预测过低着一个在应力能是二的因子。
:::

## 通向何处

这些应力产生着的沙丘形态在沙丘形态的课里；有着这些应力的流的河在陆地的环境、海洋的环境的课里；读着流使用着的粒度的统计在沉积的颗粒的课里；这些定律描述着它们的床的河在地貌学的河流的课里，它们的波与流在海洋学的波与潮汐的课里。

::: summary
- 移动着沉积物的力是边界的剪切应力 $\tau_0 = \rho_f g H S$，重要的速度尺度是剪切的流速 $u_* = \sqrt{\tau_0/\rho_f}$。
- 运动在一个砂的约 $0.045$ 的临界的希尔兹的参数开始着，泥因为内聚力更高的、砾因为互相咬合更高的。
- 劳斯数 $P = w/(\kappa u_*)$ 决定着一个颗粒是一个冲刷的载荷、悬浮的载荷、推移质，它控制着整个的垂直的浓度的剖面。
- 推移质的通量是一个超的应力的 $3/2$ 的幂，景观的侵蚀由稀有的最大的流做完了。
- 矿层记录着阈值的穿越的事件、不是平均的条件，一个渐变的层的顶部系统地预测过低着流的高峰的力量。
- 泥的高的侵蚀的阈值意味着一个泥能在一个流里积累，一个富泥的岩石不是一个静的水的证据。
:::

找一个 $2\ \mathrm{m}$ 的深在一个 $5\times10^{-5}$ 的坡度上的流的边界的剪切应力。
::: solution
$\tau_0 = 1000\times9.81\times2\times5\times10^{-5} = 0.98\ \mathrm{Pa}$。一个典型的大河的值，它足够移动着到约 $1.3\ \mathrm{mm}$ 的砂。
:::
:::

::: exercise 希尔兹的参数 {level=1 check="0.045"}
一个 $1$-mm 的砂的床被 $\tau_0 = 0.73\ \mathrm{Pa}$ 应力着。找着 $\theta$、说着床是否移动着。
::: solution
$\theta = 0.73/(1650\times9.81\times10^{-3}) = 0.73/16.2 = 0.045$。床**恰好在阈值**，定义着临界的希尔兹的曲线的条件，曲线测量着那样难的理由：在阈值床移动着那样慢，"没有运动"与"开始的运动"被几周的观察分离着。
:::
:::

::: exercise 劳斯数 {level=1 check="1.0"}
一个 $w = 0.008\ \mathrm{m\,s^{-1}}$ 的粉砂的颗粒被一个 $u_* = 0.02\ \mathrm{m\,s^{-1}}$ 的流携带着。找着劳斯数、运输的模式。
::: solution
$P = 0.008/(0.4\times0.02) = 1.0$。$P$ 在 $0.06$ 与 $1.2$ 之间颗粒**在悬浮**带着一个强的垂直的浓度的梯度——在近床集中的、在整个的流存在的。这经典的悬浮的载荷的条件。
:::
:::

::: exercise 内聚力与阈值 {level=2}
$5$-µm 的泥的临界的希尔兹的参数约 $1.0$、$100$-µm 的砂的约 $0.045$。找着侵蚀着两者需要的剪切的应力的比、解释着为什么泥坪在砂积极地移动着的环境里存活着。
::: solution
$$
\frac{\tau_{cr}(\text{mud})}{\tau_{cr}(\text{sand})} = \frac{1.0\times(\rho_s - \rho_f) g\times5\times10^{-6}}{0.045\times(\rho_s - \rho_f) g\times1\times10^{-4}} = \frac{1.0\times5\times10^{-6}}{0.045\times10^{-4}} = \frac{5\times10^{-6}}{4.5\times10^{-6}} = 1.1 .
$$
两个阈值**几乎同样的应力**，约 $0.08\ \mathrm{Pa}$，泥的颗粒二十倍更小。泥在砂的环境里存活着不是它的颗粒单独地重——它们不是——它们**粘结着**：新沉积时电化学的力，几天之内定殖着它的微生物的垫的细胞外的聚合物，它能把侵蚀的阈值升高着一个数量级。这是**沙丘形态–生物**的相互作用，前寒武纪——在动物掘穿着、破坏着微生物的垫之前——保存着显生宙不制作的巨大的叠层石的、微生物诱导的沉积的构造的区域——的理由。
:::
:::

::: exercise 运输的非线性 {level=2 check="2.8"}
如果推移质的通量作为 $(\theta - \theta_{cr})^{3/2}$ 标度着、一个砾的床上的剪切的应力从它的阈值的 $1.5$ 升到 $2.0$ 倍，通量上升着多少倍？
::: solution
在 $1.5\,\theta_{cr}$ 超的是 $0.5\,\theta_{cr}$、在 $2.0\,\theta_{cr}$ 它是 $1.0\,\theta_{cr}$，超的双倍着、通量上升着
$$
\left(\frac{1.0}{0.5}\right)^{3/2} = 2^{1.5} = 2.8 .
$$
消息是一个洪水的量的适度的增加产生着一个沉积的通量的大的增加，最大的几个百分点的洪水做着多数的地貌的工作。
:::
:::

::: exercise 残余的矿层 {level=2}
在一条大河的离岸 $30\ \mathrm{m}$ 深的内陆棚上，潜水员发现着一个 $20$-mm 的卵石、保存好的浅水的贝壳的滞后。现代的流速计记录着 $0.3\ \mathrm{Pa}$ 的底部的应力，卵石要求着 $1.5\ \mathrm{Pa}$ 移动着。解释着。
::: solution
卵石**残余的**。它们要求着现代的海洋交付着的应力的五倍，它们由一个不再存在的流放置着。两个候选是一个仪器记录没有看到规模的一场风暴、内陆棚上更可能的一个**低水位**的矿层，海平面低 $100\ \mathrm{m}$、这个地点是一个河道的床、一个海滩时铺设着。保存好的贝壳反对着贝壳自己的一个高的能量的起源，贝壳可能比卵石更年轻、自它被放弃着以来定殖着滞后。

一般的规则是一个内陆棚一个巨大的残余的表面，最后一个冰川–间冰期的循环把海岸线跨过着它移动着、把它的最粗的矿层留在后面。这样一个的陆棚上的现代的过程的研究必须首先确立着床**相现代的**，这就是标准的实践是测量着贝壳的年龄、寻找着掘穴、一个现代的动物群、把砾的叠瓦与现在的漂移的方向比较着的理由。
:::
:::

::: exercise 一个渐变的层 {level=3}
一个 $1.2\ \mathrm{m}$ 厚的浊积石的层从它的底部的 $1.0\ \mathrm{mm}$ 向上变细到它的顶部的 $0.05\ \mathrm{mm}$，在上面覆盖着 $3\ \mathrm{cm}$ 的泥。使用着 $\theta_{cr} = 0.045$，计算着底部的、顶部的边界的剪切应力、解释着为什么层的均值的粒度是流的一个差的估计者。
::: solution
$$
\tau_\text{base} = 0.045\times1650\times9.81\times10^{-3} = 0.73\ \mathrm{Pa}, \qquad
\tau_\text{top} = 0.045\times1650\times9.81\times5\times10^{-5} = 0.036\ \mathrm{Pa}.
$$
应力在层的底部与顶部之间落下着一个二十的因子。层的均值的粒度，一个线性的平均约 $0.2\ \mathrm{mm}$、一个 $\phi$ 的平均更粗的，对应着约 $0.15\ \mathrm{Pa}$ 的应力——流只短暂地达到、再没有的值，一个描述着它的峰、它的末尾都不的值。

正确的程序是使用**底部的**粒度作为高峰的能力的估计者、**层的厚度**作为流的持续时间与总的质量的估计者，接受着两者一起是一个差的约束着流的速度，除非层的厚度、流的矿层的厚度分开地知道着。这就是浊积石的定量的古水力从粒度移走着、向着流自己的直接的测量移动着的理由，它只在 1987 成为可能，一个刚果的深海扇的一个 $2000$-km 的海底的电缆的断裂的时间表揭示着引起着它的流走了约 $1400\ \mathrm{km}$ 在 $25$ 小时、达到着一个扇的头的约 $10\ \mathrm{m/s}$ 的速度——一个浊流的速度的第一直接的测量，一个来自一个电信的故障的报告。
:::
:::

::: exercise 一个综合 {level=3}
一个河流的砂的体有一个从它的轴的 $0.6\ \mathrm{mm}$ 变细到离它 $4\ \mathrm{km}$ 的 $0.1\ \mathrm{mm}$ 的 $d_{50}$、一个在同一的方向从 $1.1\ \phi$ 改善到 $0.35\ \phi$ 的分选、一个从 $-0.15$ 变到 $+0.20$ 的偏度。提出着一个沉积的模型、识别着将使它与一个海岸线的砂区分着的观察。
::: solution
三个趋势全与**离着一个河道的轴减少着的流的能力**一致：粒度落下着，分选改善着，流相对着它的总载荷变得更筛选着，偏度变正的、细粒逐渐地移走着。产生着这个模式的模型一个**河道的充填与岸外的、决口的扇的系统**，轴是活动的河道、翼是它的洪水的减弱的矿层、一个**海底的河道与它的堤和溢出的矿层**。

一个海岸线的砂在同一个的方向给出着同样的三个趋势——向着海海浪筛选着，分选改善着，偏度变粗的。区分的观察是三个。**沉积的构造**：一个河流的砂有槽的与板状的交错层理带着单向的、双峰的古水流与洪水的减弱的泥的覆盖，一个岸面的砂有垄脊的与波痕的交错层理带着振荡的分开的线理。**边界的表面**：一个河道切入着它自己的岸外的泥带着一个冲刷的底部，一个岸面的砂向上、向着陆穿过着与一个渐变的、生物扰动的底部、没有切入着。**古生物与古水流的几何**：一个岸面的有一个海洋的内底栖的动物群、一个古水流的场与古海岸线、波主导的运输的方向对齐着，一个河道有一个淡水的、半咸水的动物群、一个古水流的场与排水对齐着。粒度的趋势单独不能区分着它们，相的分析的全部是拒绝着一个粒度不带它的沉积的构造解释着。
:::
