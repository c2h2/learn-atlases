大陆与海洋之间的边缘三个的系统遇见的地方——河流交付着的沉积、大气强加着的波与潮汐、构造允许着的沉降——结果的海岸的形状它们的竞争的结局。海洋的环境保存着记录的最侧向地连续的、很好对比的、经济地最重要的地层学，它们沉积存储在一个既厚的、可预测的体的唯一的地方。

## 岸面的剖面

::: definition 海岸的分带 {#def-zonation}
一个波主导的海岸从陆地向海洋分为**障后的潟湖与海岸平原**、**障壁岛**与它的越漫的扇、**上岸面**（从低潮位到良风的波基）、**岸面的过渡带**（良风的与风暴的波基之间的"过渡带"、"下岸面"）、**近海的过渡带**与风暴的波基之下的**近海**。**良风的波基**是普通的波的轨道的运动太弱、不能移动着床的沉积的深度，风暴期间床不重新工作着的深度；**风暴的波基**是海岸接受着的最大的波的相当的深度。两者之间**岸面的过渡带**，风暴的层的带，陆棚的最独特的相的带。
:::

::: proposition 从轨道的速度到波基 {#prop-wavebase}
一个高度 $H$、周期 $T$ 的线性的波在一个水的深度 $h$ 的近床的轨道的速度是
$$
u_b = \frac{\pi H}{T\,\sinh(kh)},
$$
波数的 $k$ 由色散的关系 $\omega^2 = g k \tanh(kh)$、$\omega = 2\pi/T$ 设定着。波基 $u_b$ 落到床的沉积的临界的轨道的速度的深度，一个细的砂约 $0.15\ \mathrm{m\,s^{-1}}$。因为 $u_b$ 作为 $\sinh^{-1}$ 在 $kh$ 衰减着，波基的深度随着**深的水的波长** $L_0 = 1.56\,T^2$ 标度着，良风的波基在半个的波长附近的教科书的规则一个关于这个衰减的陈述。
:::

::: example 波基多深？ {#ex-wavebase}
找着床的轨道的速度落到 $0.15\ \mathrm{m\,s^{-1}}$ 的深度，(a) 一个 $H = 1.5\ \mathrm{m}$、$T = 8\ \mathrm{s}$ 的涌浪，(b) 一个 $H = 6\ \mathrm{m}$、$T = 14\ \mathrm{s}$ 的风暴。区别意味着什么关于陆棚的地层学？
::: solution
解着色散的关系、设着 $u_b = 0.15\ \mathrm{m\,s^{-1}}$ 给出
$$
\text{(a) 涌浪:}\ h = 32\ \mathrm{m}; \qquad \text{(b) 风暴:}\ h = 140\ \mathrm{m}.
$$
深的水的波长 $L_0 = 1.56\times64 = 100\ \mathrm{m}$、$1.56\times196 = 306\ \mathrm{m}$，两个深度 $0.32\,L_0$、$0.46\,L_0$——"半个的波长"的规则好的在一个 $1.5$ 的因子、不更好，计算着更安全。

地层学的结果**陆棚的三重的分带**。$32\ \mathrm{m}$ 之上床每天重新工作着，它的泥筛选着，完全的生物扰动着，成为一个干净的岸面的砂。$32$ 与 $140\ \mathrm{m}$ 之间床一年的多数不受扰动、几年一次风暴冲刷着、重新工作着，**风暴的岩**——垄脊的交错层理的风暴的层——的带。$140\ \mathrm{m}$ 之下床只接受着悬浮的沉降、浮游的与半浮游的沉积的慢的雨，成为一个泥。一个穿过着一个陆棚的测量的倾斜的剖面因此读着，向着海，砂，然后风暴的层的异岩的砂与泥，然后泥，同样的三重的图案保存在任何一个未扰动的浅海的序列——一个海侵的序列从一个固定的、可预测的秩序从岸面的砂穿过着进入近海的泥的理由。
:::
:::

## 潮汐，河流与三角洲的三角

::: definition 三角洲的分类 {#def-delta}
一个**三角洲**是一条河进入着一个静止的水的体的矿层，它的形状由河流的沉积、盆地的能量的竞争设定着。**加洛韦的三角**绘制着三角洲在**河流的**、**波的**、**潮汐的主导**的三个轴。一个**河流主导的**三角洲——密西西比的鸟的脚——一个高的沉积的供应、低的波的与潮汐的能量、一个厚的、突出的口门的坝、一个建造着海岸向着外的手指的分流网络。一个**波主导的**三角洲——圣弗朗西斯科的、早期历史的尼罗的——重新工作着一个光滑的、弧形的、海滩的脊的海岸、河流的砂重新分布沿着海岸线。一个**潮汐主导的**三角洲——恒河–布拉马普特拉河的、飞河的、亚马逊的口的——重新工作着一个洪的与退的取向的**砂的脊**、**潮汐的河道**的阵列、红树与泥的坪的岛之间，它的"三角洲"几乎不识别为一个河流的矿层。多数的三角洲绘在三角的内部，分类一个关于哪一个的代理在河流交付着它**之后**重新工作着沉积的陈述。
:::

::: definition 河口与它的环流 {#def-estuary}
一个**河口**是一个部分地围着的海岸的水的体、一个河流的流入、一个海洋的流入，它的内部的环流由**潮汐的棱柱**、**河流的排水**的比设定着。一个**盐水楔**的河口一个几乎静止的咸的水的层在一个淡的水的表面层之下，潮汐的搅动着弱的任何地方发生着。一个**部分混合的**河口一个向着陆的增加的盐度、一个两层的环流——表面向着海、深处向着陆——**浑浊的最大**的地点，黏土的絮凝、床的载荷的向着陆的运输截留着河流的沉积的多数的。一个**很好混合的**河口盐度的垂直均匀的、一个强的残余的环流，一个**逆的**（负的）河口它的上游的盐度在它的口的高的，干旱的海湾的蒸发超过着所有的流入的。
:::

::: example 潮汐的棱柱与入口 {#ex-prism}
一个面积 $50\ \mathrm{km^2}$ 的海岸的潟湖由单的一个入口排水着、一个 $2.0\ \mathrm{m}$ 的均值的潮汐的幅度。估计着潮汐的棱柱、通过着入口的高峰排水、保持着高峰的流在 $1.2\ \mathrm{m\,s^{-1}}$ 之下需要的入口的横截面。
::: solution
棱柱——每一个潮进入着、离开着的水的体积——是
$$
V = A\times \mathrm{range} = 50\times10^{6}\times2.0 = 1.0\times10^{8}\ \mathrm{m^3}.
$$
一个正弦的潮、$6.21$ 小时（$2.24\times10^{4}\ \mathrm{s}$）的半个的循环，高峰的排水是
$$
Q_\text{peak} = \frac{\pi V}{T_\text{half}} = \frac{3.14\times10^{8}}{2.24\times10^{4}} = 1.4\times10^{4}\ \mathrm{m^3\,s^{-1}},
$$
一个**大的河流的排水**通过着一个海滩的一个口在六个小时、一天两次交付着。保持着高峰的流在 $1.2\ \mathrm{m\,s^{-1}}$ 需要的入口的横截面是
$$
A = \frac{Q}{u} = \frac{1.4\times10^{4}}{1.2} = 1.2\times10^{4}\ \mathrm{m^2},
$$
一个 $400\ \mathrm{m}$ 宽的、$30\ \mathrm{m}$ 深的入口。

三个结果跟着、三个全记录在岩石。入口**它自己的流冲刷着深的**，一个河口的口的矿层一个粗的滞后、一个深的河道、不是一个泥的坪。入口的向着海的**退潮的三角洲**一个棱柱的量级的砂的体，入口喂养着的储层。**涨潮的三角洲**、障壁之后的潟湖泥，进入着潟湖的流扩张着、减慢着、落下着它的载荷。这个"入口的复合体"的相的组合——一个深的河道的滞后、一个向着盆地的砂的席、一个向着陆的泥的坪——一个没有入口的障壁岛的模型错的理由：一个真实的障壁岛每几十公里入口切割着，入口供应着障壁的砂的多数的到它中断着的。
:::
:::

::: example 哪一个三角洲？ {#ex-delta}
一个 $400$-m 厚的三角洲的序列显示着，在图的视图，一个 $60$-km 长的、$15$-km 宽的砂的体延长**垂直**着古海岸线，内部大的规模的交错层理的组交替着 $40^\circ$ 向着海、$35^\circ$ 向着陆倾斜着，两者泥的覆盖，一个古水力的玫瑰图带着两个模式在体的长的轴的直角。分类着它。
::: solution
几何、内部的结构一个**潮汐主导的**系统的诊断的。一个砂的体延长**垂直**着海岸线一个**潮汐的砂的脊**、一个**潮汐的入口的充填与退潮的三角洲的复合体**、不是一个河流的口门的坝，叶的，不是一个波重新工作的障壁岛，**平行**着海岸线。**双向的**交错层理带着泥的覆盖一个反转着的潮汐的流的签名，两个古水力的模式在脊的长的轴的直角涨的与退的方向。

分类重要，储层的建筑完全不同。一个河流主导的三角洲的砂一个**进积的**体，它的孔隙与渗透率离开着源减少着、它的遮挡近分流的泥。一个潮汐主导的三角洲的砂一个**长的、窄的、垂直叠置的脊**，它的渗透率沿着脊最高的、它的遮挡泥的覆盖，覆盖着每一个沙丘形态——覆盖**成因地周期性的**、在小潮铺设着，遮挡的间隔一个月的几分之一。一个设计的鸟的脚的三角洲的一个潮汐主导的储层的水驱将扫过着脊、绕过着之间的间隔。

排除的替代的读法一个**海底的河道与堤**的系统，也给着一个延长的砂的体垂直着古海岸线。区分双向性：一个河道的古水流单峰的向着坡的，一个潮汐的脊的双峰的沿着脊。泥的覆盖单独不决定着它，一个潮汐影响的深的河道存在；玫瑰图决定着。
:::
:::

::: example 布鲁恩规则：一米的海平面走多远？ {#ex-bruun}
一个海滩有一个关闭的深度 $10\ \mathrm{m}$、宽度 $6\ \mathrm{km}$ 的岸面、一个 $200\ \mathrm{m}$ 宽的碎波带、一个 $3\ \mathrm{m}$ 高的滩肩、一个 $4\ \mathrm{m}$ 高的沙丘。使用着布鲁恩（Bruun）规则，找着一个 $1$-m 的海平面的上升的海岸线的撤退、说着规则假设着什么。
::: solution
布鲁恩规则平衡着从剖面损失的沉积、在新的、更深的平衡的位置重建着岸面需要的沉积。活动的剖面从沙丘的脊到关闭的深度延伸着，每一个海岸线的长度的单位的体积守恒着，撤退是
$$
Y = \frac{L\,\ell_w}{s + b},
$$
$L$ 海平面的上升，$\ell_w$ 活动的剖面的宽度（岸面加碎波带）、$s + b$ 滩肩与沙丘的自由的高度。$\ell_w = 6200\ \mathrm{m}$、$s+b = 7\ \mathrm{m}$，
$$
Y = \frac{1\times6200}{7} = 890\ \mathrm{m}.
$$
一米的海平面的上升，给着一个能撤退的海岸，把这个海岸线退回去近一公里。规则世界的障壁的海岸地球的最威胁的地貌之一的理由，海滩的养滩的项目必须为着**剖面**设计着、不为着海滩的面。

假设在批评所在。规则假设着岸面一个**封闭的系统**剖面的意义，没有净的纵向的、向着海的损失，**砂无限的**供应在剖面的底部，剖面每一个瞬间在**平衡**，沉降零，海岸**不受保护的**——没有岬、没有礁、没有海堤、没有养滩。真实的海岸违反着五：一个海湾支持的障壁能**滚转**海侵着、不侵蚀着，海岸线撤退着、不损失着砂；一个有一个向着海的砂的席的海岸能喂养着它、前进着；一个海堤之后的海岸损失着它的海滩给剖面、不撤退着，"海岸的挤压"完全移走着海滩。岩石的记录相当的谨慎一个给定厚度的海侵的砂的席不自己记录着一个给定的海平面的上升的速率，厚度依赖着沉积的供应、预存的剖面速率一样多。
:::
:::

::: warning 海岸线是一个表面、不是一个线，它很少在相说着它的位置
盆地分析的最常见的错误等同着一个相、一个海岸线的位置。三个机制分离着它们。**重新工作**：一条河的泥能完全筛选走、它的砂重新分布一个障壁岛沿着走向 $50\ \mathrm{km}$，一个给定的地点的砂记录着河流的沉积、波的**位置**。**海侵**：一个上升的海翻译着整个的剖面向着陆与向上，现在在 $20\ \mathrm{m}$ 深度的岸面的砂曾经在海岸；**揽掠的面**切割着它的底部移走着障壁岛与潟湖，一个海侵的序列通常显示着岸面的砂直接坐在近海的泥、一个海岸的平原的泥炭，介入的相侵蚀走。**切割的河谷**：一个基准的落下的期间河向下切着、充填着它的河谷带着粗的沉积，**成因地大陆的**、**地理地海洋的**，一个河谷的充填能误认为一个井的曲线的障壁的砂、一个岩心的河道的砂，两者不。纪律解释着一个海岸线作为一个**表面**——揽掠的面、最大的淹没的面、层序的边界——把相放在它的相对，不读着海岸线从单的一个井的岩性。
:::

::: quiz
一个井的曲线的一个砂的体 $25\ \mathrm{m}$ 厚的、一个陡的底部、一个变粗着向上的粒度的趋势、上面覆盖着 $60\ \mathrm{m}$ 的海洋的页岩、它的顶部一个浓缩的海绿石的滞后。它是什么？
- [x] 一个进积的岸面的砂、顶部着一个海侵的面。
- [ ] 一个海侵的障壁的砂。
- [ ] 一个深水的河道的充填。
- [ ] 一个河流的河道的砂。
::: solution
一个变粗着向上的岸面的砂结束在一个浓缩的海绿石的滞后经典的**退进的副层序、终止着一个海洋的淹没的面**。一个海侵的障壁岛将变细、变粗着向上、坐在一个**揽掠的面**带着一个海侵的滞后在它的**底部**、不是它的顶部。一个河道的充填将变细着向上带着一个底部的滞后，一个河流的砂携带着大陆的砾、泥的碎片、不海洋的页岩。
:::

## 通向何处

塑造着这些海岸的波与潮汐在海洋学的波与潮汐、风驱动的课里，风暴的层的构造在沙丘形态的课里，碳酸盐在清澈的热带的水替换着碎屑的海岸在碳酸盐的课里，相的逻辑在相的课里，层序的地层学的框架在地层学、盆地与层序的课里。

::: summary
- 一个波主导的海岸由波的能量分为障壁岛、岸面、岸面的过渡、近海，边界两个波基。
- 波基床的轨道的速度落到床的沉积的阈值的深度，它随着深的水的波长标度着。
- 良风的、风暴的波基之间风暴的层的过渡带，一个陆棚的最独特的相的带。
- 三角洲分类着在河流交付着沉积之后什么重新工作着它：河流的、波的、潮汐。
- 潮汐的棱柱设定着入口的大小、退潮的三角洲的体积、潟湖的泥，它使河口的口的流一条河的一样大的。
- 海岸线是一个表面，相、重新工作、海侵分离着它、似乎标记着它的岩性。
:::

一个三角洲有一个光滑的弧形的海岸线、平行着海岸的海滩的脊、没有保存的分流网络。分类着它。

**波主导的**。河流的沉积波重新工作着一个海滩的脊的复合体、重新分布沿着海岸，三角洲的图的图案海岸线的、不是河流的。尼罗的、圣弗朗西斯科的与拉斯帕达尔经典的例子，勘探的结果储层**岸面与海滩的脊**、不是一个口门的坝，它沿着走向连续的、不是叶的。
:::

::: exercise 潮汐的幅度的类 {level=1}
一个海岸有一个 $6\ \mathrm{m}$ 的潮汐的幅度。它属于着哪一个类，类预测着什么关于海岸？
::: solution
**中潮的**（微潮的 $4\ \mathrm{m}$ 之下，中潮的 $4$–$8\ \mathrm{m}$，巨潮的 $8\ \mathrm{m}$ 之上）。一个中潮的海岸足够的潮汐的能量重新工作着一个三角洲一个混合的潮汐与河流主导的系统，发展着广泛的潮汐的坪、红树与盐的沼泽的泥的坪在它的障壁岛之后、保持着它的入口打开着。经典的预测一条河进入着一个中潮的、巨潮的海岸建造着一个**潮汐影响的三角洲**带着潮汐的砂的脊、不是一个鸟的脚。
:::

::: exercise 潮汐的棱柱 {level=2 check="4.2"}

::: exercise 河口的截留 {level=2}
一个部分混合的河口截留着它的河流的沉积的载荷的百分之八十在它的口 $40\ \mathrm{km}$ 之内。解释着机制、说着地层学的产品什么。
::: solution
两个机制一起作用着。**絮凝**：河流的淡的水遇见着海的水的任何地方黏土的颗粒聚集着成几十到几百微米的絮凝的团，它的沉降的速度单个的颗粒的一千，黏土落下在咸的前线、不到达着陆棚。**浑浊的最大**：河口的两层的环流驱动着床的载荷向着陆在底层，汇聚的流、床的几乎静止的点截留着它，形成一个 $1$–$10\ \mathrm{g/L}$ 的悬浮的沉积的带、河口的沉积的多数的地点。

地层学的产品一个**泥主导的河口充填**——层序的地层学的"河口的河谷充填"——一个底部的海侵的滞后的重新工作的砂、一个厚的中心的单元的异岩的薄层状的、透镜状的层、生物扰动的泥、一个薄的帽的湾的头、潮汐的坪的砂。河口**截留着**它的沉积，之外的陆棚接受着几乎不，一个淹没着一个海岸的平原的海侵转换着海岸从一个陆棚的砂的**源**进入一个**汇**。海侵的序列的砂岩集中在它的底部、海侵的滞后的理由、它们之上的陆棚泥的理由：海岸线穿过着，带着砂。
:::

::: exercise 一个陆棚的横断面 {level=3}
一个白垩纪的陆棚的穿过着的岩心的横断面，从向着陆到向着海，给出着：(A) 生物扰动的细的砂带着 *Ophiomorpha*、*Planolites* 的掘穴、海绿石；(B) 垄脊的交错的极细的砂带着 $30$-cm 的波痕、$5$-cm 的泥的覆盖；(C) 层理的、生物扰动的暗的灰的泥带着 *Nereites* 似的足迹、零散的 $20\ \mathrm{cm}$ 厚的风暴的层；(D) 黑色层理的泥、没有掘穴、$1$-cm 的粉砂的层理。解释着每一个、估计着古的水的深度。
::: solution
**(A)** 一个浅的、充氧的、波与流扫过的**岸面到岸面的过渡**的砂，*Ophiomorpha*（一个坚固的、浅的、搅动的砂的甲壳的掘穴）、海绿石，一个低的沉积的速率的海洋的背景缓慢地形成着。海绿石、掘穴的深度放在**良风的波基**附近，$25$–$45\ \mathrm{m}$。
**(B)** **岸面的过渡**，风暴的带。垄脊的交错层理、$30$-cm 的波的波痕要求着一个 $0.5\ \mathrm{m}$ 的量级的轨道的偏移在床，波的波痕与一个陆棚上的风暴的例子计算着放在 $100$–$150\ \mathrm{m}$ 一个大的风暴。$5$-cm 的泥的覆盖风暴之后的沉降。
**(C)** **近海的过渡**，风暴的波基之下、最大的事件到达着。*Nereites* 似的放牧的足迹一个安静的水的、完全的海洋的、充氧的动物群。深度 $150$–$300\ \mathrm{m}$。
**(D)** 一个**盆地的、限制的**泥、缺氧的到无氧的底水，$1$-cm 的粉砂的层理任何的流的唯一的记录。深度 $300\ \mathrm{m}$ 之下、一个限制的陆棚。

横断面一个**变深着、变细着向上与向着海**的剖面，整体一个正常的陆棚。观察将改变着解释**海绿石的位置**：一个 $40\ \mathrm{m}$ 的海绿石的砂一个正常的岸面，同样的海绿石在 $300\ \mathrm{m}$ 一个饥饿的陆棚的一个**浓缩的段**，两者相反的含意关于沉积的预算。判别**沉积的量**：一个浓缩的段薄的、一个岸面的砂厚的。
:::

::: exercise 一个综合 {level=3}
同一个的层序的 $30\ \mathrm{km}$ 的两个井全结束着它们的岩心在一个 $3$-m 的砂、一个陡的底部、一个壳与海绿石的海侵的滞后、*Ophiomorpha* 的掘穴填充着砂。井 A 坐在下面的 $40\ \mathrm{m}$ 的岸面的砂；井 B 坐在下面的 $30\ \mathrm{m}$ 的近海的泥。解释着表面、对比着两个井。
::: solution
$3$-m 的砂一个陡的底部、一个海侵的滞后、砂填充的 *Ophiomorpha* 一个**揽掠的障壁岛、岸面的砂**，它下面的表面一个**揽掠的面**——岸面的底部在海侵期间向着陆与向上移动着，侵蚀着它的路径的一切。

两个井记录着同一个的表面在不同的**位置相对着海侵之前的海岸**。井 A 下面的岸面的砂，揽掠的面那里切割**进入老的岸面**，现在坐在它之上的障壁岛在那里的一个的向着陆的延续。井 B 下面的近海的泥，揽掠的面切割**进入老的近海的泥**，它之上的砂一个**海侵的障壁岛、揽掠的滞后的砂**、直接沉积在侵蚀的陆棚。表面因此**穿时的**，海侵从北方来 B 比 A 更年轻的，一个**爬升的**表面、它的在海侵之前的沉积的表面之上的高度向着陆增加着。

跟着的对比的规则实践花费最多的钱的：**对比着揽掠的面、不砂的底部**，砂的底部同一个的表面；从不对比着**下面的岸面的砂的底部**跨着表面，B 那个相侵蚀走、不存在。检验滞后：一个海侵的滞后带着海绿石、磷块岩、重新工作的浅的水的壳在 B、坐在一个泥，证明着表面一个揽掠的面、不是一个层序的边界，一个层序的边界一条河切割着、携带着大陆的砾、不海洋的壳。
:::
