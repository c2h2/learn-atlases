海洋的十九分之九在碳酸盐溶解的深度之下，碳酸盐的工厂——一套浅的、清的、暖的、贫营养的陆棚、覆盖着海底的百分之四——生产着所有的海洋的沉积的约四分之一。碳酸盐的岩也是烃的储层的最大的单一个的库、地下水的最大的库、显生宙的礁的动物群的多数的保存的唯一的地点。它们困难的，它们由生产力依赖于着水的化学的生物制造着，它们原始的孔隙在沉积之后由不再存在的地下水破坏着、创造着，它们的分类一个争论。

## 工厂与它的产品

::: definition 碳酸盐的颗粒与顿汉分类 {#def-dunham}
一个碳酸盐的岩一个**碎屑颗粒**的骨架——颗粒——在一个**微亮晶**（$4\ \mu\mathrm{m}$ 更细的碳酸盐的泥）的基质、一个**亮晶**（更粗的结晶的方解石）的胶结物。碎屑颗粒**骨骼的**（生物的碎屑：有孔虫的、藻的、珊瑚的、腕足类的、棘皮动物的、苔藓虫的）、**非骨骼的**（鲕的、内碎屑的、团粒的、团块的）、**陆源的**（石英与云母的、它们的存在测量着离陆的距离）。**顿汉分类**由控制着它的渗透率的构造分类着岩：**泥岩**（颗粒少于百分之一、泥支持的）、**粒泥岩**（颗粒漂浮在泥中）、**泥粒岩**（颗粒接触着、泥充填着孔隙）、**颗粒岩**（颗粒支持的、无泥的）、**粘结岩**（颗粒在生长期间粘结着的）、**漂浮岩**（颗粒在骨架建造的有机体支持的、一个贫泥的基质）。**福克分类**命名着颗粒、亮晶、微亮晶，两者互补着：顿汉告诉着储层的工程师孔隙在任何地方、福克告诉着古生物学家岩由什么制造着。
:::

::: definition 碳酸盐的工厂的类型 {#def-factory}
一个**热带的（碳酸盐的砂的）工厂**建造在一个暖的、浅的、清的、贫营养的水、**文石**、**高镁的方解石**统治着，钙的碳酸盐的两个亚稳的形式、溶解着比统治着更老的岩的低镁的方解石与方解石更快。它的三个要素**平台的内部**（潮上带的坪与潟湖）、**边缘**（一个礁、一个砂的滩）、**斜坡与盆地**（边缘的台地的泥、倒石）。一个**冷水工厂**生活在一个高的纬度、一个风驱动的上升流的陆棚，水冷与富营养的，**苔藓虫的、双壳的、藤壶的、非礁的红藻**统治着，生产着**苔藓虫的与双壳的**、**胞石的**砾、不是鲕与礁、建造着**异相的**、**碳酸盐的砂的**斜坡、没有边缘。一个**丘的工厂**建造着**微生物的**、**海绵的**丘在一个波基之下的斜坡、一个太深的、太浑浊的水的光合的礁，它统治着古生代的几个间隔。三个不是一个气候的序列：冷水的碳酸盐常见的在地质记录、不一个地球比它现在更冷的一个信号，曾经认为的。
:::

::: example 一个岩在两种语言 {#ex-dunham}
一个 $300$ 点的薄片给出 $118$ 鲕、$46$ 红藻与有孔虫的骨骼的碎片、$21$ 团粒的泥岩的内碎屑、$95$ 微亮晶、$20$ 方解石的胶结物的亮晶。在两个系统分类着它、解释着环境。
::: solution
颗粒总共 $118 + 46 + 21 = 185$ 的 $300$、**百分之六十二**、微亮晶百分之三十二。颗粒**不**互相接触着——百分之六十二的颗粒的体积在约百分之六十四的随机的紧密的堆积的阈值之下、薄片显示着微亮晶在多数颗粒之间——岩**泥支持的**，超过百分之一的颗粒，在顿汉的方案里就是一个**粒泥岩**。要是点的计数给出着接触的百分之七十的颗粒，它就是**泥粒岩**；没有微亮晶则是**颗粒岩**。

福克的方案里它是**带微亮晶的团粒–鲕–生物碎屑泥粒岩到粒泥岩**，颗粒的名字携带着环境：**鲕**要求着一个浅的、扰动的、碳酸盐饱和的、贫泥的水，**红藻的碎片**要求着光、一个硬的、坚实的基底，**有孔虫**要求着正常的海洋的盐度，**团粒的泥岩的内碎屑**要求着一个泥的坪存在于附近、撕裂着。微亮晶，百分之三十二，水**不**有效地簸选着，这不是一个滩。

环境一个**浅的潮下的潟湖、一个限制的平台的内部**，鲕从一个附近的滩供应着，藻与有孔虫原地生活着，泥原地生产着由微生物与藻的活动、一个潮上带的坪的冲洗。**内碎屑**证据坪周期地露出的、它的泥周期地撕裂着的。岩**变浅着向上**的单元的底部，鲕的内容应该上升着，如果剖面跟着向上进入着滩。

## 台地，斜坡与丘

::: definition 台地的建筑 {#def-platform}
一个**边缘的（限制的）台地**有一个边缘站在相邻的盆地的地板之上、分离着台地的相与盆地的相陡地；巴哈马的、亚得里亚海的现代的例子，记录的伟大建造多数边缘的。它的带，从陆向外，**潮上带的**（潮上带的藻的层纹石与白云的泥岩、潮间带的团粒的泥粒岩、潮下的叠层石），**浅的潮下的潟湖**（团粒的泥粒岩与粒泥岩带着团块），**滩**（鲕的与核形的颗粒岩），**边缘**（粘结岩、一个颗粒岩的边缘如果没有礁），**斜坡**（砾岩、漂浮岩、倒石），**盆地**（浓缩的微亮晶、边缘的台地的楔）。一个**均斜的斜坡**没有边缘、没有坡度的断裂：它温和地、连续地加深着进入着盆地，它的相的带排列着平行的等深线，冷水与异相的陆棚的建筑。一个**孤立的台地**生长在一个深的结构的高地，它的垂直的序列记录着碳酸盐的生产、沉降之间的竞赛。
:::

::: example 跟上、赶上、后退、淹死 {#ex-keepup}
一个中侏罗纪的孤立的台地 $940\ \mathrm{m}$ 厚的、它的化石表明着它的顶部在海平面整个期间。它建造在 $168$、$160\ \mathrm{Ma}$ 之间。找着均值的沉降的速率、均值的生产的速率、比较着它们与现代的礁的最大的垂直的生长速率。如果沉降快十倍，台地将淹死吗？
::: solution
均值的沉降，因此台地生长着的均值的速率，它的顶部保持在海平面，
$$
\frac{940\ \mathrm{m}}{8\times10^{6}\ \mathrm{yr}} = 1.2\times10^{-4}\ \mathrm{m\,yr^{-1}} = 0.12\ \mathrm{mm\,yr^{-1}} .
$$
现代的礁与台地的边缘的生产范围从一个低的生产力的平台的内部约 $0.1\ \mathrm{mm\,yr^{-1}}$ 到一个高的能量的骨架的边缘 $3$–$10\ \mathrm{mm\,yr^{-1}}$，一个常见的引用的最大近一个健康的霍尔世礁 $10\ \mathrm{mm\,yr^{-1}}$。侏罗纪的台地因此生长着约**生物的最大的一百分之一**、**沉降限制的**、不是生产限制的：岩一个盆地的地板下沉着多快的一个记录、不是有机体能建造着多快。

如果沉降快十倍，$1.2\ \mathrm{mm\,yr^{-1}}$，台地将仍跟上，那远在一个骨架的边缘的能力之内。它将**淹死**在一个 $10\ \mathrm{mm\,yr^{-1}}$ 的量级的沉降、持续着比建设到光千年需要的更长，俯冲竖起的阶地之上、盐的抽拉的盆地的边缘之上的发现的速率。淹死的诊断的野外的签名一个**陡的、浓缩的、常见的铁的、硅的**面在碳酸盐的顶部，上面**贫瘠的盆地的泥、黑色的页岩**，没有通过着更深的水的相的过渡——台地比它能充填着下沉着更快、动物群埋在缺氧。

标题的四个术语这个竞赛的词汇。一个台地**跟上**如果它生产着与盆地沉降着一样快；**赶上**如果它淹死的、贫瘠的、后退的、后来恢复着；**后退着**当它的边缘向陆退着、生产失败在一个加深着的边缘；**淹死着**当沉降超过着生产、碳酸盐的工厂关闭着。四个读着从相的垂直的序列、从牙形石的与有孔虫的深度指标，四个一个不再在那里的盆地的地板的构造的陈述。

::: example 潮坪多宽？ {#ex-tidalwidth}
一个边缘的台地的内部有一个 $1:2000$ 的潮下的剖面的坡度（每公里 $0.5\ \mathrm{m}$ 的深度）。找着它的潮间带的宽度 $1.5\ \mathrm{m}$、$3\ \mathrm{m}$、$10\ \mathrm{m}$ 的潮差的，说着相在任何案例什么。
::: solution
潮间带的宽度潮差除以坡度，
$$
w = \frac{\Delta h}{s}, \qquad s = 5\times10^{-4},
$$
$$
\Delta h = 1.5\ \mathrm{m}:\ w = 3\ \mathrm{km}; \qquad
\Delta h = 3\ \mathrm{m}:\ w = 6\ \mathrm{km}; \qquad
\Delta h = 10\ \mathrm{m}:\ w = 20\ \mathrm{km}.
$$
一个 $1.5\ \mathrm{m}$ 的微潮的潮差潮间带一个 $3$-km 的带、平台的内部**潮下的团粒的泥粒岩与粒泥岩**统治着、潮上带的相——藻的层纹石、干裂的白云的泥岩、鸟眼的、窗孔的构造——薄的、限制在向陆的边缘。一个 $10\ \mathrm{m}$ 的宏潮的潮差潮间带 $20\ \mathrm{km}$ 宽的、平台的内部**潮上带的与潮间带的相统治着**：广泛的藻的粘结岩、潮坪的白云的泥岩、一个砂的坪、泥的坪、河道的镶嵌，生产着宏潮的台地的**异源的、脉的、扰动的**潮上带的相。

## 沉积之后发生着什么

::: definition 成岩的背景与孔隙 {#def-diagenesis}
一个碳酸盐的沉积后的历史写在它的胶结物、控制着由制造着它们的**流体**。**海洋的**胶结作用发生在海底、浅的海洋的埋藏的环境，生产着**纤维的、悬挂的**文石与高镁的方解石的胶结物、衬着孔隙不充填着它们、形成一个硬底。**大气的**成岩作用发生在台地暴露着，最重要的：新的、富 CO$_2$ 的地下水溶解着文石与高镁的方解石、沉淀着**低镁的方解石**，生产着**悬挂的、弯液的**胶结物、**钙结壳**古土壤、**岩溶**、**窗孔的、模孔的孔隙**。**混合带的**成岩作用淡水的–咸水的界面沉淀着**等粒的亮晶**、充填着孔隙不衬着，一个边缘的台地的翼的孔隙的破坏的经典的原因。**埋藏的**成岩作用生产着**等粒的、非铁的、然后铁的、白云石的**方解石、**白云石**，深的、热的、白云石化的、热液的流体的背景、创造着最好的碳酸盐的储层、最坏的井喷。
:::

::: example 读着一个胶结物的层序 {#ex-cements}
一个颗粒岩显示着，顺序：(1) 纤维的文石的胶结物衬着孔隙；(2) 块状的低镁的方解石的胶结物充填着孔隙、**悬挂的**胶结物悬挂从颗粒；(3) 等粒的铁的白云石菱面体、鞍的白云石在残余的孔隙；(4) 缝合线与一个溶解的缝。重建着历史、说着孔隙去了哪里。
::: solution
**(1)** 纤维的文石这个**海洋的**胶结物，沉淀在海底、浅的海洋的埋藏的环境。它**衬着**孔隙不充填着它们，它保持着孔隙完整的、降低着渗透率涂着颗粒。
**(2)** 块状的低镁的方解石带着**悬挂的**胶结物诊断的**大气的**胶结物，悬挂的形式证明着胶结物向下生长从一个**淡水的弯液面**在包气带。台地因此**暴露的**，同样的事件溶解着文石的壳、高镁的胶结物，创造着**模孔的、窗孔的孔隙**、同时充填着其他的孔隙带着亮晶。孔隙的净的效应从胶结物单独不可预测的、必须测量着。
**(3)** **铁的**白云石、**鞍的**白云石**埋藏的、热液的**胶结物。胶结物的铁意味着一个还原的、富有机物的、暖的流体；鞍的习性意味着一个约 $60^\circ\mathrm{C}$ 之上的结晶的温度。这个时期最后的原始孔隙充填着，也是**白云石化**能创造着次生的孔隙由方解石白云石替代着伴随着的体积的减少。
**(4)** **缝合线**记录着**化学的压实**几十兆帕的有效应力，几百米到一个公里的埋藏的深度，溶解的钙的碳酸盐沉淀着方解石的缝、不溶的黏土沿着它浓缩着。

孔隙去了三个地方。它**降低着**海洋的衬里的胶结物、大气的块状的亮晶、埋藏的与热液的亮晶、缝合线的压溶；它**创造着**大气的文石与高镁的方解石的溶解、可能的白云石化；它**保存着**胶结物未能连接的任何地方。净的一个岩心、一个测井测量着，胶结物的共生唯一解释着是否一个给定的样的孔隙原始的、次生的、一个残余的——一个能从它的相预测的储层、一个不能的区分。
:::
:::

::: warning 碳酸盐的岩记录着它们自己的破坏，记录不是沉积
一个碳酸盐的三分之二的原始的孔隙、它的最重要的次生的孔隙的全部创造在沉积**之后**，由一个不再存在的古地理控制着它们的分布的流体。三个结果跟着。**储层不是相**：一个边缘的台地的最好的孔隙常见的在一个古高水位的面的之下的**大气的溶解的带**，不是供应着颗粒的滩，制造着它的流跟着一个存在了几万年在一个从此移动着的海平面的一个水位。**白云石不是相**：白云石一个成岩的产品，一个白云岩的构造能保存着原始的相忠实地（一个曾经是泥的坪的**白云的泥岩**）、能完全地破坏着它（一个与沉积的任何东西没有关系的一个**鞍的白云石**的替代）。**分类一个妥协**：一个顿汉**颗粒岩**、一个福克**带亮晶的鲕的颗粒岩**同一个岩描述着两个目的，一个岩一个层的一部分泥粒岩、另一部分颗粒岩一个相带着一个构造的梯度、不是两个相。纪律描述着岩两次——一次沉积的构造、一次成岩的叠加——说着两个使用着哪个一个环境推断着。
:::

一个石灰岩显示着悬挂的方解石的胶结物、溶解的壳的模孔的孔隙、它的顶部一个钙结壳古土壤。成岩的环境什么？
- [ ] $2\ \mathrm{km}$ 的深度的海洋的埋藏。
- [x] 一个暴露的面之下的一个大的、包气的、饱水的带的环境。
- [ ] 一个热液的、深度地埋藏的、还原的流体。
- [ ] 早的、海底的海洋的胶结作用。
::: solution
悬挂的胶结物向下生长从一个淡水的弯液面、只在**包气的带**一个亚暴露的碳酸盐形成；文石与高镁的方解石的溶解的模孔的孔隙要求着一个**淡水的**透镜体的富 CO$_2$ 的酸的水；一个钙结壳一个土壤。一个热液的胶结物**鞍的白云石**、**等粒的铁的方解石**，一个早的海洋的胶结物是**纤维的**、将**衬着**孔隙而不是充填着。
:::
:::

## 通向何处

分类与沉积的构造应用着在海洋的环境、相的课里的环境；胶结物的化学在稳定的同位素、痕量的元素的课里；控制着矿物学的海水的化学在海水的、水溶液的地球化学的课里；台地竞赛着的沉降在挠曲、盆地与层序的课里；白云石化的流体在地下水的流的、水溶液的地球化学的课里。

::: summary
- 碳酸盐的工厂小的、浅的、多产的，热带亚稳的文石与高镁的方解石统治着、冷水苔藓虫与双壳统治着。
- 顿汉分类由它的沉积的构造、因此它的渗透率分类着一个碳酸盐；福克分类命名着它的颗粒。
- 一个边缘的台地有一个边缘、一个分带的内部、一个斜坡；一个斜坡两者都没有；一个丘生长在波基之下。
- 一个台地的厚度记录着生产能达到 $10\ \mathrm{mm/yr}$、沉降通常远更慢的竞赛。
- 多数的碳酸盐的孔隙成岩的，一个古暴露的面之下的大气的溶解的带常见的最好的储层。
- 白云石一个成岩的产品、不是相，一个白云岩的构造能记录、能不记录原始的沉积。
:::

## 练习

::: exercise 顿汉分类 {level=1}
一个石灰岩包含着的百分之十五的骨骼的颗粒散布在百分之八十五的微亮晶。命名着它。
::: solution
这是一个**粒泥岩**：超过百分之一的颗粒、泥支持的、颗粒不接触着。少于百分之一的颗粒就是**泥岩**，颗粒接触着、泥充填着孔隙就是**泥粒岩**。
:::
:::

::: exercise 颗粒的类型 {level=1}
一个石灰岩几乎完全由同心的涂层的颗粒组成着、一个 $20$-µm 的核。命名着颗粒、环境。
::: solution
**鲕**，环境是**一个浅的、扰动的、碳酸盐饱和的、贫泥的陆棚**——现代的例子巴哈马的、鲨的湾、波斯滩的鲕的滩。鲕要求着波与流的扰动、钙的碳酸盐的过饱和、泥的缺乏，一个鲕的颗粒岩一个**高的能量、浅的、清的水的**相、一个变浅着向上的趋势的层序的地层学的标记。
:::
:::

::: exercise 孔隙与深度 {level=1 check="0.15"}
使用着 $\phi = 0.46\,e^{-z/445}$ 一个边缘的台地，找着 $500\ \mathrm{m}$ 的颗粒间的孔隙。
::: solution
$\phi = 0.46\,e^{-500/445} = 0.46\times0.326 = 0.15$，百分之十五。这个深度一个边缘的台地的碳酸盐停止着一个好的颗粒间的孔隙的储层，除非孔隙次生的。
:::
:::

::: exercise 孔隙与深度，斜坡 {level=2 check="0.24"}
使用着 $\phi = 0.61\,e^{-z/1049}$ 一个非边缘的台地，找着 $1000\ \mathrm{m}$ 的孔隙、比较着它同样的深度的边缘的台地的值。
::: solution
$\phi = 0.61\,e^{-1000/1049} = 0.61\times0.386 = 0.24$，百分之二十四，对抗边缘的台地的 $4.9$ 百分之。斜坡的碳酸盐保持着**五倍**的孔隙同样的深度，世界的伟大碳酸盐的储层的多数的——北海的石炭纪的、中东的斜坡的侏罗纪的、西非的白垩纪的——富泥的、冷水的、异相的碳酸盐、不是干净的台地的边缘的颗粒岩的理由。
:::
:::

::: exercise 工厂的类型 {level=2}
一个白垩纪的陆棚的碳酸盐包含着苔藓虫与双壳的碎片、胞石、没有鲕、没有珊瑚、百分之二十的海绿石、它的生物碎屑低镁的方解石。哪个工厂，它说着关于水什么？
::: solution
这是**冷水的（异相的）工厂**。证据是苔藓虫与双壳对珊瑚与藻的统治、**胞石**（非球的结节的有孔虫的藻，冷的、富营养的、很好照明的水常见的）的存在、**鲕与珊瑚的缺乏**、**海绿石**（它缓慢地形成在一个低的沉积的速率的陆棚、常见的在一个氧的极小、上升流的制度）、生物碎屑的**低镁的方解石**的矿物学，冷水的生物群的特征的。

水是**冷的、富营养的、很好混合的、可能的受着风驱动的上升流**，陆棚**不是**一个边缘的热带的台地。勘探的结果储层是**苔藓虫与双壳的、胞石的砾**、颗粒间与颗粒内的模孔的孔隙，排列着**岸平行的带**在一个斜坡、不是一个边缘的台地的边缘，封盖是向上陆的泥、不是一个平台的内部的白云的泥岩。
:::
:::

::: exercise 淹死 {level=2}
一个台地的碳酸盐上面陡地 $20\ \mathrm{cm}$ 的磷的硬底带着重新工作的鲕、然后 $40\ \mathrm{m}$ 的黑色的层理的页岩。解释着、说着替代将看起来什么。
::: solution
这是一个**淹死的**、**贫瘠的**面。带着**重新工作的鲕**的硬底一个海侵的、浓缩的面切在平台的顶部，磷块岩标记着一个沉积的**贫瘠的**时期，黑色的层理的页岩记录着**缺氧的底部的水**到达一个碳酸盐的工厂不能跟上的深度。台地下沉着、海上升着，比工厂能充填着更快，碳酸盐停止着，盆地缺氧着。

替代——一个**逐渐的加深着**——将显示着一个通过着更深的水的碳酸盐的相的过渡：潮上带的、滩的相向上过去着开阔的陆棚的泥粒岩与粒泥岩、一个逐渐地更深的水的动物群、然后泥灰、最后页岩，几十米、没有硬底。那个过渡的缺乏、一个浓缩的磷的面的存在，使着淹死的解释，一个**陡的**改变——一个地震触发的沉降的事件、一个海洋的缺氧的事件的开始、一个裂谷的边缘的淹没——的野外的签名。
:::
:::

::: exercise 一个台地的综合 {level=3}
一个 $1200$-m 厚的泥盆纪的台地显示着，从底部：$200\ \mathrm{m}$ 的盆地的硅质的泥岩带着牙形石的；$60\ \mathrm{m}$ 的藻的粘结岩带着叠层石；$700\ \mathrm{m}$ 的潮上带的白云的泥岩与团粒的泥粒岩带着 $40$ 个携带着古岩溶的暴露的面；$200\ \mathrm{m}$ 的鲕的颗粒岩带着 $15$-m 的深的潮的河道；$40\ \mathrm{m}$ 的盆地的泥岩带着一个磷的硬底。解释着整体、估计着沉降的速率如果台地存在着 $12\ \mathrm{Myr}$。
::: solution
**底部**贫瘠的、浓缩的、硅质的**盆地**，台地在它上面成核着——硅石与牙形石说着一个富硅的、贫沉积的、远洋的背景。**藻的粘结岩带着叠层石**是**成核与建立**的阶段：一个微生物的坪在一个浅的滩上捕获着、粘结着沉积物；由于微生物的粘结是在一个高的能量的背景中没有骨骼的骨架也能建造的唯一方法，它是，经典的早泥盆世的工厂——还没有礁建造的珊瑚。**$700\ \mathrm{m}$ 的潮上带的白云的泥岩与泥粒岩带着 $40$ 暴露的面**是一个**成熟的边缘台地的内部**，周期地露出的，$40$ 个古岩溶的面就是 $40$ 次相对海平面的下降，每一个一个**层序的界面**、每一个一个潜在的大气的溶解的孔隙的带。**$200\ \mathrm{m}$ 的鲕的颗粒岩带着 $15$-m 潮的河道**是**滩与它的潮的入口**，它的到达标记着一个改变到一个更高的能量的、更开阔的、更扫过的台地。**顶部**淹死的面、盆地的返回。

均值的沉降 $1200/12\times10^{6} = 1.0\times10^{-4}\ \mathrm{m\,yr^{-1}} = 0.10\ \mathrm{mm\,yr^{-1}}$，舒适地低于泥盆纪的台地的生产的能力，台地整个期间都是**沉降限制的**、它的 $1200\ \mathrm{m}$ 盆地的地板的冷却与加载的一个记录。$40$ 暴露的面给出一个 $12/40 = 0.3\ \mathrm{Myr}$ 每旋回的均值的间隔，一个**四级、偏心率驱动的**旋回性，旋回潮上带的、不是加深着向上的事实意味着台地站在海平面、旋回**变浅着向上**——一个沉积供应的、低的沉降、低的地形的台地的签名。

最弱的环节**白云的泥岩**的解释。一个白云的泥岩一个原生的白云石沉淀在一个超盐的潟湖，平台的内部**限制的、蒸发的**，一个**次生的**对原生的石灰的泥岩的替代由一个后来的埋藏的、渗流的回流的白云石，原始的水可能是正常的海洋的、限制一个伪影。两个区分着**残余的构造**、白云石的有序与它的早的胶结物的替代的关系、白云石自己的同位素与痕量的元素——回答改变着整个 $700\ \mathrm{m}$ 的解释。
:::
:::

::: exercise 一个储层的预测 {level=3}
两个碳酸盐的储层同样的 $2500\ \mathrm{m}$ 的深度有着同样的颗粒岩的相、同样的鲕的内容。储层 X 有百分之四的孔隙、均质的；储层 Y 有百分之十四的孔隙、窗孔的、包含着模孔的颗粒、$2$-m 方解石充填的洞穴。解释着区分、说着你将如何绘制着 Y。
::: solution
储层 X 跟着**压实与埋藏的胶结作用**的路径：它的原始的颗粒间的孔隙逐渐地充填着海洋的、埋藏的、压溶的胶结物，百分之四指数孔隙–深度的曲线预测着 $2500\ \mathrm{m}$ 一个浅的海洋的碳酸盐。储层 Y 有一个额外的**次生的孔隙**十个孔隙单位，它的三个特征识别着过程：**模孔的颗粒**溶解的文石、高镁的方解石，**窗孔**一个大气的、埋藏的流体的溶解的空腔，**方解石充填的洞穴**一个**岩溶**系统的管道。

储层 Y 因此**暴露的**、冲洗着大气的，溶解着一个埋藏的、热液的流体，它的孔隙不是它的相的函数、它相对于它相对于一个**古水位、一个断层**的位置。绘制的结果 Y 不能预测着从颗粒岩的相的图。它必须绘制着从控制着溶解的面与管道：**古暴露的面**（一个层序的界面，绘制着地震的作为一个侵蚀的截断、一个河道的顶部），**岩溶**（绘制着作为塌陷的特征、一个速度的下降、一个地震的"管"、"塌陷的坑"的构造），引导着流体的**断层与裂缝**、**洞穴**自己，极端的案例、钻探的危险。

预测的检验**模孔的内容对抗暴露的面之下的深度**：大气的溶解最强的在**淡水的饱水的、包气的带**，古的面之下几十到几百米，它随着面之下的深度消退着，流体饱和着、咸着。一个孔隙对抗层序的界面之下的深度的图，每一个井做的，储层 Y 的图，趋势一个断层对齐着，溶解构造的、储层一个**裂缝–洞穴**系统、它的甜点在断层的损伤的带。
:::
