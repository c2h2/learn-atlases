一个相是一个描述着使得它的环境被含义着的岩石。这个词携带着两个永久地紧张着的承诺：描述的，岩石应该不解释着记录着；成因的，记录应该读回到一个水、流、动物、沉积的供应的世界。沉积学的中心的智力的操作在两者之间穿过着，管理着它的学科相的分析。跟随着的一切——一个储层的对比、一个盆地的重建、一个地震的反射的解释——建造着那个穿过着是否诚实地做出着。

## 相与联系着它们的定律

::: definition 相、相的组合 {#def-facies}
一个**相**是一个岩石的体，由岩性、粒度、沉积的构造、沉积的与生物的构造、古生物的内容、能确定着的颜色与矿物的组合特征着，它与它的邻域区分着、含义着一个单沉积的风格。一个**相的组合**是一个相的组，一起重复着出现着、共享着一个环境。一个**相的模型**是一个相的组合的概括的三维的几何——一个河道、一个障壁岛、一个碳酸盐的台地——它的预测的垂直的序列、它的侧向的过渡、它的期望的尺寸。一个**相的镶嵌**是几个的相当的大小的相交错着任何地方产生的图的图案，一个潮汐的坪、一个碳酸盐的陆棚，没有一个单的相侧向地连续的。
:::

::: theorem 瓦尔特的相的定律 {#thm-walther}
一个相的垂直的序列，每一个相穿过着下一个、没有一个侵蚀的、不沉积的间断，表示着同一个相的一个侧向的序列、同一个秩序。反面只垂直的序列完全的持续着：一个浓缩的、间断的面破坏着对应，一个**切断的**相，一个它的侧向的对应物从不沉积着、移走着的相，出现着在一个垂直的剖面、没有邻域。
:::

::: proof
瓦尔特的（Walther）论证一个运动学的。假设着沉积的系统在**渐变的平衡**，每一个的环境相对着海岸线的位置长期固定的、沉积的表面的剖面在形状不变化着作为它移动着。海岸线然后向陆地翻译着着一个大于涉及的环境的宽度的距离，海底的一个固定的点在垂直的序列经历着同一个序列的环境、它将在从一个系统的末端走到另一个的末端穿过着。两者沿着两个垂直的轴读着的同一的事件的一组，对应只在剖面翻译着保存着精确的。剖面变化着形状——一个沉积的供应、一个沉降、一个波的能量、一个相对的海平面的变化——垂直的序列是侧向的一个扭曲的版本，表面侵蚀的、浓缩的对应完全地破坏着。
:::

::: example 应用着瓦尔特的定律 {#ex-walther}
一个垂直的序列读着，向上：生物扰动的海洋的泥带着 *Thalassinoides*；薄层状的细的砂与泥；平面的交错的中的砂带着泥的覆盖；槽的交错的粗的砂带着泥的碎片；一个陡的冲刷的底部到下面的泥。这是一个退进的、海侵的序列，最上部的相的侧向的对应物是什么？
::: solution
序列**变粗着、变浅着向上**：从一个完全的海洋的、永久地亚潮的泥，穿过着一个潮汐的坪的相，进入着一个亚潮的砂的坝，最后进入着一个河道的滞后。最上部的相最粗的、水柱的最低的，环境移动着**向着海**——这是一个**退进的**（进积的、超覆的）序列，一个变粗着向上的副层序、一个被一个低水位的、晚退落期的充填覆盖着的海洋的侵蚀的退进的面。

靠瓦尔特的定律最上部的相、冲刷的粗的河道的砂的侧向的对应物躺在生物扰动的泥的**向着海的**，整个的垂直的叠置是一个穿过着一个单海岸的系统的剖面：泥的陆棚，中间的潮汐的坪，向着陆的河道与坝。**缺失的**相躺在河道的向着陆的——海岸的平原、泥炭、岸外的泥——它们的缺乏告诉你剖面截断着、海岸线从没有到达着这样远。

谨慎是陡的底部。一个变粗着向上的序列的顶部的一个冲刷的面不必要是一个层序的边界；它能是下一个的副层序的河道的底部，表面**在别处与一个海洋的淹没的面相关的**。一个层序的边界的识别要求着表面显示着区域的、切割着的、覆盖着着一个相的向着盆地的移动——三个标准，第三个瓦尔特的定律供应着。
:::
:::

## 旋回，副层序与叠置

::: definition 成因的层序 {#def-sequences}
一个**副层序**是一个相对地整合的、由一个海洋的淹没的面、它的相关的整合界限着的成因地相关的层的序列；最小的成因的层序，典型地 $1$–$30\ \mathrm{m}$ 厚的、$1$–$100\ \mathrm{km}$ 宽的。一个**副层序的组**是一个成因地相关的副层序的组、由一个最大的淹没的面、一个亚陆的不整合限着，它的**叠置的图案**记录着沉积的供应、补偿空间的平衡：**进积的**组叠置着没有垂直的粒度的间断、记录着一个供应的盈余，**加积的**组叠置着重复的淹没、没有净的变浅着，**退积的**组叠置着向着陆的移动、记录着一个亏减。一个**变深着向上**（变细着向上、退积的）的旋回结束着一个淹没的面、一个浓缩的段；一个**变浅着向上**（变粗着向上、进积的）的旋回结束着一个退进。
:::

::: example 读着一个叠置的图案 {#ex-stacking}
一个 $60$-m 的序列包含着五个变粗着向上的 $8$–$14\ \mathrm{m}$ 的副层序，每一个顶部着一个 $20$-cm 的海绿石的砂、一个带着 *Trypanites* 的钻孔的硬底，每一个上面覆盖着 $2\ \mathrm{m}$ 的暗的海洋的页岩。副层序变厚着、变粗着向上，之间的页岩从 $2\ \mathrm{m}$ 变薄到 $0.3\ \mathrm{m}$。解释着叠置、强迫着。
::: solution
每一个副层序一个**进积的**旋回：它变浅着向上、终止着一个**海洋的淹没的面**，海绿石的滞后、硬底、上面的页岩标记着。五个这样的旋回形成一个**进积的副层序的组**、整体一个退进的复合的旋回。

两个趋势信息。副层序**变厚着、变粗着向上**意味着每一个连续的旋回交付着更多的沉积，**供应的速率上升着**相对着补偿空间。中间的页岩**从 $2\ \mathrm{m}$ 变薄到 $0.3\ \mathrm{m}$**意味着淹没的事件变短的、水变浅的，**相对的上升的速率落下着**。一起记录着一个**补偿空间的创造的下降的速率**对抗着一个上升的、稳定的沉积的供应——一个高水位的接近的经典的签名，序列将期望着穿过着进入一个宽的加积的、然后最后一个下超的高水位体系域。

定量的内容值得注意着。如果每一个副层序表示着一个相对的平面的变化的旋回，一个 $60$-m 的序列带着四级层序的旋回性的五个旋回意味着一个 $0.5$–$2\ \mathrm{Myr}$ 的持续的整体，页岩从 $2\ \mathrm{m}$ 到 $0.3\ \mathrm{m}$ 的变薄在海侵的沉积的厚度近七的因子。一个恒定的沉降的速率的海侵的厚度的七的因子是海侵的**持续**的七的因子，一个关于强迫着的陈述——海平面的曲线的形状、不是它的振幅——一种能在别处的边缘导出的海平面的曲线检验着的陈述。
:::

::: history
相的概念 1838 在汝拉由格雷斯利（Gressly）引入着、冈贝尔、齐克尔形式化着；相的定律是约翰内斯·瓦尔特（Walther）的 1894 的学位论文，从德国的北海的海岸的第四纪的矿层、施泰夫福特的蒸发岩做出着垂直的、侧向的序列的对应。瓦尔特的定律忽略了七十年、1960 年代由莫尔（Moore）、维舍重新发现着，它的定量的结果由斯洛斯（Sloss）、维舍、杰维利用着，层序的地层学的综合从 1977 的韦尔、米彻姆、汤普森（Thompson）的论文开始着、1980 年代的埃克森的层序的地层学的模型使一个检验着的方法。成因的层序、副层序的术语米彻姆的（Mitchum），体系域的概念 1988 的范瓦戈纳、波森特、米彻姆、韦尔等的，替代的成因的地层学的学派 T–R–U、淹没的面的学派的加洛韦（Galloway）仍使用着的对手的框架。现代意义的相的模型来自 1976 的里丁（Reading）的关于沉积的环境的集、沃克、詹姆斯（James）的 1992 的相的模型的卷，标准的参考、明确着模型一个预测。迹相学的环境的应用赛拉赫尔（Seilacher）的工作，它的 1964 关于迹的化石的迹相的论文、1967 的书确立着深度与能量的分带，彭伯顿、弗雷、德罗瑟精炼着现代的迹相的方法。这一课命名着的迹的化石的属——*Skolithos*、*Cruziana*、*Glossifungites*、*Thalassinoides*、*Trypanites*、*Nereites*、*Zoophycos*——经典的迹的化石的命名法的形态的属、作为它们自己的权利的环境的术语使用着。
:::

::: example 三个井的一个相的镶嵌 {#ex-mosaic}
一个白垩纪的三角洲的前缘的一个倾斜的线上相距 $2\ \mathrm{km}$ 的三个井穿透着，从顶部：**井 1**——$18\ \mathrm{m}$ 的海洋的页岩，然后一个 $9$-m 变粗着向上的极细的砂与泥的单元，然后页岩。**井 2**——同样的页岩 $17\ \mathrm{m}$，然后一个 $12$-m 极细的砂没有泥、陡的底部、渐变的，然后页岩。**井 3**——同样的页岩 $18\ \mathrm{m}$，然后 $11\ \mathrm{m}$ 互层的砂与泥厘米的偶组，然后页岩。对比着它们、说着三个砂的体是否一个储层。
::: solution
三个井站在同一个**淹没的面**，下面的页岩的顶部，对比的基准；上面的页岩下一个淹没的面，之间的间隔一个副层序。内部三个相**侧向地等价的**、不叠置着：井 1 一个**远端的三角洲的前缘**的异岩的相，只旋回的通过的一部分进积着，井 2 一个**富砂的三角洲的前缘、口门的坝**的相，达到着它完全的变浅着向上，井 3 一个**潮汐影响的**的相，沉积物作为一个流体的泥、潮汐产生的撕裂的偶组供应着。

它们是否一个储层依赖着砂的**连通性**，回答从三个井不可判定的。井 2 的砂 $12\ \mathrm{m}$ 厚的、无泥的；井 1 的 $9\ \mathrm{m}$ 互层的砂与泥、也许百分之四十的净的砂；井 3 的 $11\ \mathrm{m}$ 偶组、也许百分之三十的净的砂。相在几百米之内侧向地穿过着，砂**遮挡着**、不连着的，田将从井 2 排着、留下其余的。相在几公里交错着，砂通过着富净砂的部分连着的。

决定着的观察**古水流**，给出着相的移动的方向、砂的趋势的方向；**每一个砂的底部**，井 2 的一个陡的侵蚀的底部追踪到井 1 意味着一个连着的河道、一个渐变的底部意味着一个不连着的席；**沿着古水流的趋势放置的第四、第五的井测量的净的总的比**。一个倾斜的线的三个井不能分辨着一个相的间隔 $1\ \mathrm{km}$ 的镶嵌，承认着练习的诚实的结论。
:::

## 迹的化石的解决

::: definition 迹相的构造 {#def-ichno}
一个**迹的化石**是一个生物的掘穴、足迹、取食的结构，一个身体的化石不，它在动物活着的地方找到着。**迹相的构造**一个层的迹的比例、多样性、横切的关系，一个**基质坚固着、居住着的时间**的测量——扰动指数在一个 $0$ 到 $6$ 的尺度。**经典的横穿陆棚的迹相的序列**跑着从高能量的、浅的、移动的砂的 *Skolithos* 迹相，穿过一个海平面的落下期间切割的一个硬底的 *Glossifungites* 迹相，安静的、完全的海洋的陆棚的 *Cruziana*、*Helminthoida* 迹相，深海扇的 *Nereites*、*Paleodictyon* 迹相，迹的化石是层居住着的证据的唯一。**深度速度的控制**真实的、不绝对的：*Skolithos* 迹相一个**坚硬的基质、高的能量、浅的**组合、*Glossifungites* 迹相一个能在任何的深度形成的**硬底**，两者靠 *Glossifungites*、*Trypanites* 的钻孔的存在缺乏、上面与下面的相区分着。
:::

::: example 迹相学对抗着沉积学 {#ex-ichno}
一个 $3\ \mathrm{m}$ 的极细的、水平的层的砂的单元包含着它的底部的 $3\ \mathrm{mm}$ 的横截面、$40\ \mathrm{mm}$ 的长的 *Skolithos* 的垂直的管，它的中部的 *Cruziana* 的放牧的足迹，它的顶部的 *Thalassinoides* 的画廊。层理在中部的三分之一保存着、顶部的三分之一完全的均匀化着。解释着。
::: solution
三个迹相记录着一个**变深着、变安静着向上**的序列，它们矛盾着岩性的单独的任何一个读法。*Skolithos* 一个悬浮的取食的蠕虫的迹，垂直地锚在一个移动的、充氧的、高的能量的砂——一个浅的亚潮的坝、一个风暴影响的岸面。*Cruziana* 一个移动的底栖的取食者的放牧的足迹，最经常节肢的、一个双壳的，要求着一个**稳定的、更坚固的、低的能量的**基质、沉积的里的食物的供应。*Thalassinoides* 一个十足目的甲壳的画廊的系统，要求着**坚固到硬**的沉积、永久的海洋的亚潮的条件、建造着一个分米的掘穴的系统的足够的时间。

层理以一个不同的货币说着同一个故事：它在中部的三分之一保存着，沉积定殖着太慢的、太浅的、破坏着它，顶部的三分之一破坏着，*Thalassinoides* 的制造者工作着沉积到一个几厘米的深度很长时间。**扰动指数**因此一个钟：顶部的三分之一居住着几年到几十年，中部的三分之一几周。

单元一个**海侵的**、**浓缩的**间隔，它的底部的 *Skolithos* 淹没的高能量的岸面的最后的迹。整体一个记录在动物、不沉积的淹没的事件，一个比岩性更好的对比的工具，一个极细的砂的岩性诊断着什么不、迹相诊断着。
:::
:::

::: warning 相的模型不是世界
一个相的模型一个概括，相的分析的失败的模式在岩石找到着模型、不是模型找到着岩石。四个具体的陷阱重复着出现。**模型的垂直的序列一个预测、不是一个定律**：一个障壁岛的模型预测着一个变粗着向上的障壁的砂在一个变细着向上的近海的泥之上，一个真实的障壁岛能海侵的、能被潮汐的入口切割着、能再工作着一个揽掠的面成一个滞后、剖面陡着的任何地方完全缺失。**模型的尺寸从几个测量的剖面画着**、常常错着一个数量级；一个出版的河道的宽度 $200\ \mathrm{m}$ 使用着一个它的河道 $2\ \mathrm{km}$ 宽的系统的储层的工程师继承着一个任何岩心不纠正着的错误。**模型假设着均匀的过程**：一个蜿蜒的河写着的"河流的"模型不是一个干旱的气候统治着岩石的记录的类型的暂时的、咸水的、干盐湖补给的系统的模型，"碳酸盐的台地"的模型从巴哈马写着、应用着一个冷的水的、苔藓虫主导的、没有鲕粒、没有微生物的粘结岩的台地同样。**模型时间平均着**：一个相是一个岩石的体、它的边界能几千年的穿时的，一个单的时间的切片画着的相的图、一个成因的单元画着的相的图一个不同的对象。防御是对每一个解释的环境写下着数据不能排除着的**替代**、说着什么观察将在两者之间决定着。
:::

::: quiz
一个垂直的序列显示着近海的泥直接在一个煤之下、之间没有砂。瓦尔特的定律预测着哪一个侧向的过渡？
- [x] 近海的泥向着陆穿过着一个海岸的平原与一个泥炭的沼泽、没有一个介入的岸面。
- [ ] 煤一个漂浮的、木筏的矿层在一个开阔的水。
- [ ] 接触一个断层。
- [ ] 什么都不，瓦尔特的定律不适用于煤。
::: solution
瓦尔特的定律预测着侧向的对应物，这里的侧向的对应物一个**波的、潮汐的主导的、低能量的海岸的平原**，泥炭的沼泽直接坐在一个泥的坪、近海的泥之上、没有一个岸面的砂，没有波的、潮汐的建造的砂制造着一个。经典的现代的类似物巴布亚的湾的富泥的海岸、德国的瓦登海的障壁的后，煤形成的沼泽直接邻接着潮汐的坪。替代的读法——煤一个远端的木筏——煤之下的根的层、一个古土壤排除着，它在那里生长着证明着。
:::
:::

## 通向何处

供应着相的环境在陆地的环境、海洋的环境的课里，碳酸盐在碳酸盐的课里，构造在沙丘形态的课里，粒度在沉积的颗粒的课里，层序的地层学的框架在地层学、盆地与层序的课里。

::: summary
- 一个相是一个含义着一个环境的描述，一个相的模型给出着它的预测的几何、垂直的序列。
- 瓦尔特的定律使一个完全的垂直的序列侧向的一个剖面，它在侵蚀的、浓缩的、间断的面失败着。
- 变粗着向上的旋回进积的、在一个淹没的面结束着；变细着向上的旋回退积的、记录着一个补偿空间的亏减。
- 副层序的叠置的图案记录着沉积的供应对抗着补偿空间的创造的速率的平衡。
- 迹的化石记录着基质、它居住着的时间，一个迹相能矛盾着一个岩性、对的。
- 相的模型预测、不是定律，每一个解释应该命名着它不能排除着的替代。
:::

## 练习

::: exercise 瓦尔特的定律 {level=1}
一个近海的泥的垂直的序列向上穿过着一个岸面的砂、然后一个壳与卵石的滞后在一个陡的面。瓦尔特的定律预测着什么侧向的过渡，什么破坏着它？
::: solution
它预测着近海的泥躺在岸面的砂的**向着海的**，它躺在滞后的向着海的——一个向着陆的面、**海侵的**剖面，岸面揽掠的面切割着、它的底部的滞后海侵的滞后。破坏着定律面自己：一个揽掠的面侵蚀的，它移走着在那里的相，垂直的序列因此跳过着侧向的部分。滞后一个**切断的**相、剖面的下面没有对应物。
:::
:::

::: exercise 叠置 {level=1}
一个副层序的组每一个副层序同样的厚度、淹没的面等间隔的什么种类的叠置，它记录着什么？
::: solution
**加积的**叠置。它记录着一个沉积的供应、补偿空间的创造的速率的平衡，海岸线保持在着原地、每一个淹没与进积的旋回加着一个层、没有净的向着陆、向着海的移动。实践一个稳定的相对的上升、一个稳定的供应的签名，系统的能交付着的沉积匹配着的速率的海侵最常见的。
:::
:::

::: exercise 迹相学 {level=1 check="0"}
一个层有着一个 $0$ 的扰动指数、层理完美的。它说什么关于定殖的时间，两个替代什么？
::: solution
它说层**从不定殖着**，居住的时间零。两个替代**没有氧**——层在一个缺氧的、无氧的底水之下沉积着，海洋的缺氧的事件、裂谷的湖的黑色页岩识别着使用着的解释——**太快、敌对的基质**，浊流的底流、一个泥石流、一个高咸的、热的基质没有动物群定殖着。两者相关的地球化学、上面与下面的层的动物群的存在缺乏、沉积的构造区分着：一个浊积石的底部的底痕、渐变的层说"太快"，一个黄铁矿的球粒、有机物的丰富的层理的泥说"没有氧"。
:::
:::

::: exercise 相的模型检验 {level=2}
一个"蜿蜒的河"的模型预测着一个变细着向上的河道的充填带着一个滞后、一个增积的点坝、一个岸外的决口与一个古土壤。一个测量的剖面显示着一个 $12$-m 厚的、完全无构造的、非常粗的砂、一个平的冲刷的底部、没有泥岩的互层、向东单峰的古水流。模型的哪一部分失败着，替代什么？
::: solution
除着底部的冲刷一切失败着。没有变细着向上、没有增积的层理、没有岸外的泥、没有古土壤，单元不是一个测坝的带的充填。替代一个**辫状的河的河道**——一个 $12\ \mathrm{m}$ 的厚度没有泥、没有坝的构造的辫状的河道不寻常的——无构造性、粗的粒度、平的冲刷，一个**高密度的浊流、一个泥石流的河道的充填**、一个**高浓度的洪水**的矿层。

区分的观察三个。**底痕、渐变**：一个浊积石的河道的充填有着槽的铸型、一个底部的倒粒的到正粒的渐变、一个泥的碎片的滞后，一个河流的单元不。**古水力的几何**：一个辫状的、蜿蜒的系统给出一个坝的组的跨着的流散布，一个单的一个流的方向的河道的充填给出一个紧的单峰的玫瑰图，观察着的。**边界的相**：一个河流的砂包围着它自己的岸外的泥，一个海底的河道的充填包围着它穿过的半深海的、盆地的泥。单峰的古水流、泥的缺乏争辩着一个限制的河道的一个单的高的浓度的流，练习的全部点模型的垂直的序列一个岩石自由地拒绝着的预测。
:::
:::

::: exercise 副层序的计数 {level=2 check="300"}
一个 $96$-m 的副层序的组包含着 $8$ 个副层序，每一个顶部着一个淹没的面。组表示着 $2.4\ \mathrm{Myr}$，一个副层序的均值的持续 kyr 多少，它对应着什么秩序的旋回？
::: solution
均值的厚度 $96/8 = 12\ \mathrm{m}$、均值的持续 $2.4\times10^{6}/8 = 300\ \mathrm{kyr}$。一个 $300$-kyr 的旋回一个**四级（更小的规模的）层序**，一般归于 $405$-kyr 的长的偏心率旋回、更经常的，$100$-kyr 的短的偏心率旋回、每一个副层序内部包含着几个进动的旋回。每一个 $300\ \mathrm{kyr}$ 的 $12\ \mathrm{m}$ 的厚度给出着一个 $40\ \mathrm{m\,Myr^{-1}}$ 的均值的沉积的速率，高的、三角洲的背景正常的。
:::
:::

::: exercise 碳酸盐的分带 {level=2}
一个中侏罗纪的台地的横穿着一个剖面给出着，从内部向着外：带着干燥的裂缝、藻的层纹石的微晶白云岩；带着平的砾的砾岩的鲕粒的粒石；珊瑚与藻的粘结岩、互层的团粒的粒泥岩；带着苔藓虫与有孔虫的生物碎屑的粒泥岩；然后盆地的泥岩带着浮游的动物群。重建着剖面、识别着最可能一个储层的带。
::: solution
剖面一个经典的**斜坡的到分带的碳酸盐的台地**。内部一个**局限的到萨布哈**的带：带着干燥的裂缝、藻的层纹石的微晶白云岩一个上潮间的到潮间的坪、高咸的、周期地露出的。带着平的砾的砾岩的鲕粒的粒石**浅的、高的能量的鲕粒的浅滩它的潟湖**，平的砾下面的藻的垫的碎屑的颗粒，一个风暴撕开着。粘结岩**台地的边缘的礁、珊瑚藻的格架**，互层的团粒的粒泥岩它的礁后的潟湖。带着苔藓虫的生物碎屑的粒泥岩**浅水的外的台地**，带着浮游的动物群的盆地的泥岩台地的边缘之外的**盆地**。

最好的储层**鲕粒的粒石**，它作为一个高的能量的、无泥的、很好的洗着的砂沉积在一个浅滩、最可能保存着原生的粒间的孔隙、暴露着着一个大气淡的水的时间，浅滩露出的——一个碳酸盐的浅滩之下发展着的大水的透镜体溶解、次生的孔隙的经典的位置。粘结岩能一个优秀的、不可预测的储层，它的孔隙控制着拦截、填充着格架的早的海洋的胶结；局限的微晶白云岩能一个差的、区域的广泛的储层、盖层，依赖着白云石化；盆地的泥岩烃源岩、盖层。
:::
:::

::: exercise 一个相的综合 {level=3}
同一个的地层的 $20\ \mathrm{km}$ 的两个岩心全显示着一个顶部着一个淹没的面的 $4$-m 变粗着向上的旋回。岩心 A 有旋回之下 $3\ \mathrm{m}$ 的近海的泥、之上 $1\ \mathrm{m}$；岩心 B 之下 $0.5\ \mathrm{m}$、之上 $4\ \mathrm{m}$。哪一个岩心更盆地的，上面的表面的结构什么？
::: solution
一个变粗着向上的旋回记录着海岸线**接近着**；淹没的面之上的页岩记录着它的**撤退**。旋回之下的泥、之上的泥的比因此测量着地点的位置相对着沉积的源。岩心 A 之下 $3\ \mathrm{m}$ 的泥、只之上 $1\ \mathrm{m}$，海岸线接近着、短暂地淹没着、立刻进积回到地点之上：地点**近源的**，接近着沉积的供应。岩心 B 之下 $0.5\ \mathrm{m}$、之上 $4\ \mathrm{m}$，海侵淹没着它、保持着它淹没的：地点两个更**远端的**。

上面的表面一个**海洋的淹没的面**，它的表达应该在两个岩心预测地不同着。远端的岩心 B 一个区域的广泛的**硬底、浓缩的段**带着海绿石、磷块岩、再工作的壳的滞后、一个浓缩的动物群，地点站在揽掠的区域、沉积的饥饿的区域。近源的岩心 A 一个**相关的整合**，可能带着一个海侵的滞后、切割的证据，海岸线不撤退着远、表面那里表达着一个前进的河道的底部。检验 B 的海绿石、浓缩的动物群对抗 A 的滞后、切割。
:::
:::

::: exercise 相的分析的分辨率 {level=3}
一个在一个层序的边界画的相的图显示着一个单的 $30$-km 宽的"河流的"相的带跨着整个的一个盆地。同一个的层序的一个最大的淹没的面画着的相的图显示着一个窄的"岸面的"砂、一个宽的"近海的"泥。两个图一致的，区别告诉你什么关于盆地？
::: solution
它们完全一致的，区别层序的地层学的全部内容。一个**落下与低水位**的表面海岸线移动着向着盆地，河流的系统推出去跨着以前陆棚的区域，一个单的宽的河流的带一个低水位的平原看起来什么。最大的淹没的面海岸线撤退着到它的最向着陆的位置，只一个窄的岸面的砂、一个宽的近海的泥留在同一个的区域。两个图同一个的海岸线在一个相对的平面的变化的旋回的两个点，也许分离着一百万年。

区别的信息**海岸线的移动的量的大小**，海平面的变化的振幅、沉积的剖面的**坡度**的积。一个 $30$-km 宽的河流的带坍缩到一个 $5$-km 宽的岸面意味着一个几十公里的海岸线的移动、一个 $50$–$100\ \mathrm{m}$ 的升降的振幅，一个 $10^{-2}$ 的量级的古坡度——一个陡的陆棚。一个缓的坡度的宽的陆棚将显示着同样的海平面的变化作为一个更大的移动、一个更宽的相的带，同一个升降的信号产生着非常不同的地层的建筑在不同的坡度的盆地，一个相的图必须永远画在一个时间的平行的表面、不是一个岩性的地层的。
:::
