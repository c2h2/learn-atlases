地层学深的时间的算术。它的任务把一个岩的堆变成一个历史——决定着哪些层更老的、每一表示着多少时间、多少时间缺失着、一个谷的哪个层另一个谷的同一个层。原则三个世纪老的、一张明信片陈述着的；实践一个关于着时间的连续的争论，一个层一个**岩的体**、时间不是一个岩的体，从一到另一个的每一个方法做出着在不同的地方失败的假设。

## 原则

::: definition 地层学的定律 {#def-laws}
**叠覆**：一个未变形的序列，每一个层比它下面的更年轻的。**原始的水平**：层沉积着大约水平的。**原始的侧向的连续性**：一个层侧向地继续着直到它变薄着一个尖灭、切断在一个不整合。**切穿的关系**：一个切割着一个岩的特征比它切割着的岩更年轻的。**包裹体**：一个包裹在一个岩的碎屑比那个岩更老的。**均变论**：现在操作着的过程在过去操作着在一个相似的。**生物群的演替**：化石的组合一个可确定的顺序互相更替着，一个组合识别着一个时间。前六个斯坦诺（Steno）的、赫顿、莱尔；最后的史密斯（Smith）的、居维叶的，唯一的给出着**时间**、不是**顺序**。
:::

::: definition 不整合与假整合 {#def-unconformity}
一个**不整合**一个岩之间的面、表示着一个**间断**——记录的一个间隔、沉积不沉积着、更常见的，沉积着、然后移走着。一个**角度不整合**是倾斜的、褶皱的层在下面、更年轻的、更少变形的层在上面，记录着变形、侵蚀、重新沉降。一个**平行不整合**是一个平行的面的间断，常见的标记着一个古土壤、一个硬底、一个河道、一个滞后。一个**非整合**是沉积的岩覆盖在火成的或变质的基底之上。一个**假整合**是一个没有任何物理的表达式的间断，只从化石、一个同位素的曲线检测着的，最常见的、最重要的不整合，看不见的、几千万年长的。
:::

::: example 多少时间缺失着？ {#ex-hiatus}
一个 $500$-m 的组跨越着 $12\ \mathrm{Myr}$ 从它的底部到它的顶部。详细的工作识别着四个面，每一个一个假整合、一个 $1.5\ \mathrm{Myr}$ 的间断，它们之间的层整合的。找着平均的沉积的速率、实际的沉积期间的速率、组的时间跨度实际记录着的部分。
::: solution
四个间断总共 $4\times1.5 = 6\ \mathrm{Myr}$，实际的沉积的时间 $12 - 6 = 6\ \mathrm{Myr}$。**平均的**速率整个跨度
$$
\bar{r} = \frac{500}{12} = 42\ \mathrm{m\,Myr^{-1}},
$$
**沉积期间**的速率
$$
r = \frac{500}{6} = 83\ \mathrm{m\,Myr^{-1}},
$$
高了二的因子。一半的时间跨度缺失着，这个盆地的发生着的事件的一半没有留下记录，从组的厚度、它的总的时间跨度计算着的任何速率、任何演化的速率、任何灭绝的速率、任何积累的速率**预测过低一个二的因子**。

这是地层学的中心的定量的事实，却几乎永远被忽略着。一个典型的古生代的碳酸盐、陆棚的序列，按萨德勒（Sadler）与保罗的估计，只记录了**百分之一或更少**的可用的时间：一公里的古生代的剖面的平均的速率几十米每百万年，实际沉积的时期的速率是几百，间隔不是均匀地分布着、而是集中在面上。对岩记录中每一个速率的计算而言，其结果都是事件速率的一个**下界**、持续时间的一个上界；正确的程序是把速率计算两次——一次用总跨度、一次用保存下来的持续时间之和——并把两个结果都报告出来。
:::
:::

## 时间与它的单位

::: definition 三个地层学 {#def-three}
**岩石地层学**由它们的岩性把岩分成体：组、段、舌状体、群。它的单位是**岩的体**，它的边界穿时的，它的美德没有化石能绘制着。**生物地层学**由它的化石分着岩：**分类单元的分布的带**、**间隔的带**、**组合的带**、**共存分布的带**、**血统的带**。它的单位原则上是**等时的**、实践上是穿时的，一个分类单元的首次的出现环境控制着的、演化控制着的。**年代地层学**由**时间**分着岩：宇、界、系、统、阶。它的单位由等时线界定着，它的界线层型国际地层委员会的**全球界线层型剖面和点**（GSSP，"金色的钉"），它的美德三个唯一能在盆地之间使用着的。一个**年代地层**的单位是一个岩的体，它的边界一个**面**、不是一个瞬间；相应的**地质年代**的单位是时间的间隔。
:::

::: definition 对比的方法 {#def-correlation}
对比是两个剖面的等效的建立着，它的方法按它们对岩性的独立程度排名。**生物地层的**对比一个带的化石主力着、首次出现的穿时性限制着。**磁性地层的**对比匹配着一个剖面的极性序列地磁的极性年表，最后 $330\ \mathrm{Myr}$ 一个全球的、绝对的时间的参考的唯一的方法，连续沉积的、很好采样的剖面限制着。**化学地层的**对比匹配着一个同位素的、元素的曲线——$\delta^{13}\mathrm{C}$、$\delta^{18}\mathrm{O}$、Sr、Os——一个偏移陡的、全球的能非常精确的，古新世–始新世的热的最盛期，曲线平的、信号成岩的不值钱的。**旋回地层的**对比匹配着层理的轨道的旋回、能给着一个剖面的它自己的年龄的几百分之几定年。**事件**的对比匹配着一个单的瞬间的矿层——一个斑脱岩、一个撞击的球粒的层、一个火山灰——这是可用的最强的对比，一个灰的层等时的在一年之内、放射定年着。
:::

::: example 一个斑脱岩做着工作 {#ex-bentonite}
两个海洋的剖面 $800\ \mathrm{km}$ 分离的都有着 $30$-cm 斑脱岩。剖面 A 斑脱岩位于 $120\ \mathrm{m}$ 在一个携带着菊石 *Sonneratia* 的石灰岩之上、$40\ \mathrm{m}$ 在一个携带着 *Schloenbachia* 的砂岩之下；剖面 B 它位于 $200\ \mathrm{m}$ 同一个 *Sonneratia* 层位之上、$15\ \mathrm{m}$ 一个携带着 *Schloenbachia* 的砂岩之下。斑脱岩一个 U–Pb 锆石的定年给出 $95.4 \pm 0.2\ \mathrm{Ma}$。对比着剖面、找着每一个的沉积的速率。
::: solution
斑脱岩是一个**等时的标记**：它降落在两个剖面上几天，两个同一个层位，对比精确的、独立着化石。两个剖面因此系在一个定年在 $95.4 \pm 0.2\ \mathrm{Ma}$ 的点。

生物地层学随后给出两个界定层位的年龄。*Sonneratia*、*Schloenbachia* 上森诺曼阶的指标菊石，它们的首次的出现别处定年在约 $96.5$、$95.0\ \mathrm{Ma}$。剖面 A 斑脱岩位于 *Sonneratia* 的首次的出现 $120\ \mathrm{m}$ 之上、*Schloenbachia* 的 $40\ \mathrm{m}$ 之下，两个化石层位之间的剖面 $120 + 40 = 160\ \mathrm{m}$ 厚的、跨越着 $96.5 - 95.0 = 1.5\ \mathrm{Myr}$，给出
$$
r_A = \frac{160}{1.5} = 107\ \mathrm{m\,Myr^{-1}} .
$$
剖面 B 同样的化石的间隔 $200 + 15 = 215\ \mathrm{m}$ 厚的，给出
$$
r_B = \frac{215}{1.5} = 143\ \mathrm{m\,Myr^{-1}} .
$$
剖面 B 积累沉积的速率快百分之三十四，这是关于它相对于沉积物源的位置的一个陈述；没有灰的层就得不出这个结论，因为两个剖面的岩性完全不同、化石内容又太粗而无法分辨 $1.5\ \mathrm{Myr}$。

谨慎在于**首次的出现**的穿时性。一个剖面中菊石的首次的出现是它到达**那个**盆地的第一次，可能比其任何地方的首次的出现晚四分之一个百万年，上面计算着的速率携带着那个误差。严格的方法是把灰的层作为系点、使用**末次的出现**——末次出现比首次出现远更少受相的控制——并把不确定度表述为生物带的分辨率、而不是放射定年的分辨率。
:::

::: example 建造着一个年龄的模型 {#ex-agemodel}
一个 $40$-cm 的深海的岩心包含着奥尔杜瓦伊的亚时，占据着间隔从顶部的 $32\ \mathrm{cm}$ 到 $14\ \mathrm{cm}$。岩心的底部，$40\ \mathrm{cm}$，它的有孔虫的组合定年在 $1.95\ \mathrm{Ma}$。假设着一个恒定的沉积的速率，找着速率、岩心的顶部的年龄、说着什么将使着回答错误。
::: solution
奥尔杜瓦伊的亚时跨越着 $1.95 - 1.78 = 0.17\ \mathrm{Myr}$、占据着 $32 - 14 = 18\ \mathrm{cm}$，
$$
r = \frac{18\ \mathrm{cm}}{0.17\ \mathrm{Myr}} = 106\ \mathrm{cm\,Myr^{-1}} = 1.06\ \mathrm{m\,Myr^{-1}} .
$$
岩心的底部 $40\ \mathrm{cm}$ 处为 $1.95\ \mathrm{Ma}$，$0\ \mathrm{cm}$ 处的顶部为
$$
1.95 - \frac{40}{106} = 1.95 - 0.38 = 1.57\ \mathrm{Ma}.
$$
岩心的均值年龄因此为 $1.76\ \mathrm{Ma}$、跨越着 $0.38\ \mathrm{Myr}$，其中奥尔杜瓦伊占百分之四十五——一个可疑地大的比例，也是恒定的速率这一假设承担过多工作的第一个信号。

四件事将使着回答错误。**速率不恒定的**：远洋的沉积变化着生产力、碳酸盐的溶解，一个从一的 $18$-cm 亚时导出的速率应用着超过 $40\ \mathrm{cm}$。**岩心有间隙**：单一个小的掘穴、一个流获得的硬底能移走一个 $40$-cm 的岩心的 $10\ \mathrm{cm}$，采取岩心本身就会因回采率不足而失去顶部的几厘米。**底部的组合定年是一个生物带**、不是一个点，它的不确定度为四分之一个百万年——占岩心整个跨度的三分之二。**奥尔杜瓦伊的界线自己定年在**几万年的，虽小却不可忽略。诚实的年龄的模型引用着不确定度 $\pm0.1\ \mathrm{Myr}$在顶部，改善它的方法不是争论速率，而是**增加着第二个系**——另一个极性的反转、一个灰的层、一个生物地层的数据——检验两个系之间的速率与其下方的速率是否相同。
:::

## 时间平均与分辨率

::: example 一个贝壳层多老？ {#ex-timeaverage}
一个贝壳灰岩——一层完整的、关节连接的、保存很好的贝壳——$25\ \mathrm{cm}$ 厚。背景沉积速率为 $60\ \mathrm{m\,Myr^{-1}}$，贝壳长 $2\ \mathrm{cm}$，层中没有簸选或从下部再工作的证据。估计贝壳层积累所花的时间，并说明它对某个种的分布意味着什么。
::: solution
层积累着在背景的速率，它的 $25\ \mathrm{cm}$ 表示着
$$
\frac{0.25}{60}\times10^{6} = 4200\ \mathrm{yr}.
$$
层因此这是一个**四千年的时间平均**：它是生活了四千年的时间里的贝壳的混合物，无法分辨比那更短的任何事件。层一个**浓缩的滞后**、从一个更厚的间隔簸选着的——扰动的构造的缺乏争辩着、不排除着——时间平均能长一百倍，一个滞后浓缩着一个整个的序列的贝壳进入一个面。

化石记录的结果正是萨德勒（Sadler）与米勒定量化过的。一个种的**分布**一个剖面界限着它的首次的、末次的出现，两者偏着的：首次的出现**太年轻的**、末次的**太老的**，真正的界线在一个间断、剖面的下面，种在它的分布的边缘稀有的、在那里不可能采集着的。测量的种的持续因此一个真正的持续的**预测过高**，两个连续的种的分布的测量的间隔一个真正的间隔的**预测过低**。一个百分之一的记录的剖面，一个生活了一百万年的种能记录在三个不连续的露头，它的表面的灭绝与重新出现一个采样的伪影。校正统计的，要求着丰度的数据，现在起源与灭绝速率的研究的标准实践，原始的记录否则使着无意义的。
:::
:::

::: warning 岩的记录一个过滤器，它的分辨率随着年龄变坏
沉积的速率在时间上并不恒定。萨德勒、库姆普、彼得斯、盖恩斯的估计，大陆的沉积的**平均的**保存的速率陡地下降着岩的年龄，从第四纪的每百万年几百米降到古生代的几米；这一下降并不是沉积生产量的减少，而是**记录被埋藏、侵蚀与不沉积所破坏**。三个结果跟着。**岩越老的，分辨率越粗的**：一米的第四纪的泥的层能一个十年，一米的寒武纪的页岩的层能一百万年，同样的野外方法——测量着一个剖面、数着层——给出答案它们的精度相差着五个数量级。**记录偏向着被沉积着的时间与地点**：一个海平面的高水位保存着一个陆棚、一个低水位移走着它，幸存的古生代的记录统治着恰好沉降着的间隔、地台。**表面的多样性的曲线部分一个采样的曲线**：杰克·菲利普斯 1860 看到的古生代的海洋的多样性的增加争论着一个世纪的更年轻的岩的更大的面积、更好的保存的一个伪影，劳普（Raup）的采样标准化的工作之前，争论仍不完全地关闭寒武纪的、奥陶纪的。纪律是：对于从岩得到的每一个速率与每一个持续，都说清方法的分辨率是什么、过滤器必须如何表现才能从一个不同的模式产生出观察到的模式。
:::

::: quiz
一个组 $300\ \mathrm{m}$ 厚的跨越着 $6\ \mathrm{Myr}$、不包含着可见的不整合。最好的推断什么？
- [ ] 沉积连续地、均匀地。
- [x] 剖面能包含着许多假整合，$50\ \mathrm{m/Myr}$ 的平均的速率一个真正的沉积的速率的下界。
- [ ] 剖面不完整的、缺失的时间小的。
- [ ] 沉积的速率完全不能估计着。
::: solution
一个包括着间断的一个跨度的平均的速率永远一个沉积期间的速率的**下界**，一个浅的海洋的、碳酸盐的背景缺失的部分常见的百分之五十到九十九，一个面不可见的任何地方。一个可见的不整合的缺乏意味着间断**假整合**——没有物理的表达式的面——这些化石检测着的、一个同位素的曲线、旋回地层学的，不是眼睛。
:::

## 通向何处

相对定年的原则应用着相对定年、地质时间的课里，绝对的定年来自地球化学的年代学的课里，用于对比的同位素的曲线在稳定的同位素的课里，轨道的旋回在轨道的旋回、定年的课里，层序地层的界面在盆地与层序的课里。

::: summary
- 叠覆给出着顺序；只有生物群的演替给出着时间，从岩得到时间的每一个方法建立在一个假设。
- 岩石地层学绘制着岩的体，生物地层学绘制着化石的分布，年代地层学绘制着时间；只有最后的在盆地之间可用的。
- 一个组的平均的沉积的速率预测过低沉积期间的速率由它的时间缺失的部分，部分通常大的。
- 一个等时的标记的层——一个斑脱岩、一个撞击的层——可用的最强的对比，它能定年、到处同一个层位。
- 一个化石的组合时间平均着它的层的厚度除以沉积的速率，常见的几千年。
- 记录的分辨率随着年龄退化着，多样性的曲线部分一个采样的曲线。
:::

一个砂岩包含着花岗岩的碎屑、一个玄武岩的岩墙侵入着它、岩墙自己断层切割着。给出着四个事件的顺序。
::: solution
最老到最年轻的：**花岗岩**（碎屑的源，包裹体的定律）、**砂岩的沉积**（叠覆与包裹体）、**玄武岩的岩墙**（切穿砂岩）、**断层**（它切割着岩墙，比岩墙更年轻的）。这个相对定年的整个的方法，它工作着没有一个化石。
:::
:::

::: exercise 沉积的速率 {level=1 check="80"}
一个 $400\ \mathrm{m}$ 的组跨越 $5\ \mathrm{Myr}$。求平均沉积速率（m/Myr）。
::: solution
$r = 400/5 = 80\ \mathrm{m\,Myr^{-1}}$，$0.08\ \mathrm{mm\,yr^{-1}}$。对三角洲或陆棚的序列而言这是一个高的、完全正常的速率，也是一个掩盖了间断的**平均值**。
:::
:::

::: exercise 不整合的类型 {level=1}
白垩纪的平卧砂岩坐落在直立、劈理的早石炭世地层之上。命名这个面，并重建历史。
::: solution
这是一个**角度不整合**。历史是：石炭纪的序列的沉积；**变形**——褶皱与劈理——华力西的造山期间；褶皱的堆的**隆起与侵蚀**到一个近一个平面的面；约 $150\ \mathrm{Myr}$ 的一个**间断**、褶皱的岩风化着的、它们的沉积运走着的；然后**沉降**、白垩纪的砂岩的沉积平的在侵蚀的面。面是野外最有用的构造，因为它分离着两个变形的事件、两个沉降的事件，它底部的砂岩包含着下面的劈理的页岩的卵石、因此定年着侵蚀在砂岩之前。
:::
:::

::: exercise 生物带 {level=2}
在某个区域，分类单元 A 的分布为 $101\ \mathrm{Ma}$ 至 $98\ \mathrm{Ma}$，分类单元 B 为 $99\ \mathrm{Ma}$ 至 $96\ \mathrm{Ma}$。它们的叠置定义了哪个生物带？其跨度多大？该带的弱点是什么？
::: solution
它们的**共存分布的带**——两个分类单元共同出现的间隔——跨越着 $99$ 到 $98\ \mathrm{Ma}$，一个 $1\ \mathrm{Myr}$ 的持续。它是生物带中最精确的，因为两个独立的首先的、末次的出现界定着它。

它的弱点在于两个边界都是**本地的首先的与末次的出现**，而不是全球的。如果分类单元 A 在其全球首次的出现之后 $0.4\ \mathrm{Myr}$ 才到达本区，那么共存分布的带的底部就年轻了 $0.4\ \mathrm{Myr}$，以该带底部进行对比的剖面就被对比到了错误的时间。补救的办法是用**全球演化迅速、不受相控制**的分类单元——牙形石的、笔石的、浮游有孔虫的、菊石的——来定义该带，并用独立方法检验对比。
:::
:::

::: exercise 磁性地层学 {level=2}
一个 $240\ \mathrm{m}$ 连续露出的湖相序列给出极性序列：正、反、正、反、正、反；剖面底部用火山灰定年为 $2.60\ \mathrm{Ma}$。其中存在哪些极性时？平均沉积速率是多少？
::: solution
底部 $2.60\ \mathrm{Ma}$ 位于高斯–松山反转（$2.58\ \mathrm{Ma}$）的下方不远处，六个极性单位向上读作：**高斯**正常时的顶部、倒转的**松山**、**留尼汪**正常亚时（$2.14$–$2.12\ \mathrm{Ma}$）、再次倒转的松山、**奥尔杜瓦伊**正常亚时（$1.95$–$1.78\ \mathrm{Ma}$）、奥尔杜瓦伊之上倒转的松山。模式精确地匹配着地磁的极性年表，对比是唯一的，因为一个长的倒转的时中的两个短的正常的亚时是一个指纹，没有其他间隔具有。

剖面跨越着约 $2.60\ \mathrm{Ma}$ 它的底部到约 $1.7\ \mathrm{Ma}$ 它的顶部，一个 $0.9\ \mathrm{Myr}$ 的持续，
$$
r = \frac{240}{0.9} = 267\ \mathrm{m\,Myr^{-1}} .
$$
这是一个高的速率，是沉降中的湖的裂谷的盆地的典型值，也是一个只有磁的模式才能给出的数字，因为没有化石的湖的序列完全没有生物地层学。
:::
:::

::: exercise 旋回地层学 {level=2 check="41"}
一个 $13.2\ \mathrm{m}$ 的泥灰岩–石灰岩韵律层序列包含着 $32$ 个偶组，其底部与顶部的放射定年表明它跨越着 $1.31\ \mathrm{Myr}$。求旋回的周期（kyr），识别轨道强迫，求沉积速率。
::: solution
周期为 $1.31\times10^{6}/32 = 40\,900\ \mathrm{yr}$，即 **$41\ \mathrm{kyr}$**，也就是**转轴倾角**的周期。沉积的速率 $13.2/1.31 = 10.1\ \mathrm{m\,Myr^{-1}}$，一个旋回占据着剖面的 $13.2/32 = 0.41\ \mathrm{m}$——即一个 $41\ \mathrm{cm}$ 厚的泥灰岩与石灰岩的偶组。只有当同一个剖面中的第二个替代指标也恢复出同样的 $41$-kyr 周期时，识别才是可靠的，因为一个 $32$ 旋回的序列同样可能记录的是别的什么的 $32$ 个旋回。
:::
:::

::: exercise 时间平均 {level=2 check="4300"}
一个 $15\ \mathrm{cm}$ 厚的贝壳层以 $35\ \mathrm{m\,Myr^{-1}}$ 的背景速率积累。求其时间平均（年）。
::: solution
$t = 0.15/35\times10^{6} = 4300\ \mathrm{yr}$。层是四千年间的贝壳的混合物，比那更短的任何事件——一场风暴、一个干旱、一次火山严冬、一个种的当地的群体的寿命——不可见的。
:::
:::

::: exercise 一个对比的问题 {level=3}
三个横穿一个盆地的剖面包含着同样的 $15$-cm 钾斑脱岩。剖面 A：灰的层之下 $60\ \mathrm{m}$ 处有一个牙形石 *Amorphognathus* 组合；之上 $25\ \mathrm{m}$ 处有一个笔石 *Dictyonema* 组合。剖面 B：灰的层之下 $140\ \mathrm{m}$ 处是同样的牙形石；之上 $8\ \mathrm{m}$ 处是笔石。剖面 C：灰的层位于剖面的 $200\ \mathrm{m}$ 处，牙形石缺失，笔石在之上 $90\ \mathrm{m}$ 处。进行对比，求三个沉积速率，并指出哪个剖面最完整。
::: solution
灰的层是等时的系点，两个化石的层位是第二与第三个系点。牙形石与笔石层位之间的厚度在 A 为 $60 + 25 = 85\ \mathrm{m}$，在 B 为 $140 + 8 = 148\ \mathrm{m}$；在 C 中牙形石层位缺失，因此该间隔无法直接测量；若以灰的层到笔石的距离来延伸对比，C 给出 $90\ \mathrm{m}$，而 A 为 $25\ \mathrm{m}$、B 为 $8\ \mathrm{m}$。

取生物地层的间隔为独立的笔石带给出的 $1.2\ \mathrm{Myr}$，速率分别为
$$
r_A = \frac{85}{1.2} = 71, \qquad r_B = \frac{148}{1.2} = 123\ \mathrm{m\,Myr^{-1}} .
$$
剖面 C 的灰的层到笔石的 $90\ \mathrm{m}$ 与 A 的 $25\ \mathrm{m}$ 相比，意味着 C 在灰的层之上同样的时间里积累着**三点六倍**于 A 的沉积，C 是沉降最强、最靠近物源的地点。

完整性的检验不是速率，而是**牙形石在 C 的缺失**。有两种读法：牙形石从未出现过，因为相太深、太稀释；牙形石出现过、层位被一个不整合移走了，因为岩性均匀而看不见。如果 C 的相是深水的泥岩而牙形石是浅水的动物群，第一种更可能；第二种必须通过寻找一个浓缩的面、一个磷的硬底、牙形石演化中的一个断裂来检验。诚实的结论是**B 是三个中最完整的**，它有着两个可靠的系之间最厚的剖面、没有缺失的层位它们之间，在牙形石的问题解决之前，C 无法评估。
:::
:::

::: exercise 一个错误的速率 {level=3}
一个 $900\ \mathrm{m}$ 厚的碳酸盐跨越 $466\ \mathrm{Ma}$ 至 $462\ \mathrm{Ma}$（$4\ \mathrm{Myr}$），包含着 $22$ 个层序界面的暴露面。一个以每 kyr $2\times10^{-3}$ 个形态单位演化的血统，在该组中测得的演化速率似乎只有每 kyr $1.5\times10^{-4}$ 个单位。调和这两个数字。
::: solution
整个组的表面速率为
$$
\frac{900\ \mathrm{m}}{4\times10^{6}\ \mathrm{yr}} = 0.225\ \mathrm{m\,kyr^{-1}},
$$
观察的演化速率 $1.5\times10^{-4}$ 对抗期望的 $2\times10^{-3}$ 一个
$$
\frac{1.5\times10^{-4}}{2\times10^{-3}} = 0.075
$$
过低——血统看起来演化得比它应有的**慢十三倍**。

调和的办法就是间断。$22$ 暴露的面每一个表示着一个间断、缺失的时间总共 $f$ 的 $4\ \mathrm{Myr}$，**记录的**时间 $(1-f)\times4\ \mathrm{Myr}$、超过组测量的演化的改变发生在那个更短的间隔。令观察的速率等于期望的速率乘以记录的比例，
$$
0.075 = 1 - f \quad\Longrightarrow\quad f = 0.925,
$$
**间隔的百分之九十二点五缺失着**，$4\ \mathrm{Myr}$ 中只有 $0.3\ \mathrm{Myr}$ 实际记录着。$22$ 个面每一个平均表示着 $3.7/22 = 0.17\ \mathrm{Myr}$，对层序的界面而言完全合理。

这就是萨德勒结果的缩影，也是演化的、灭绝的、碳的循环的扰动的、物种形成的速率计算着从地层学的分布在浅的海洋的碳酸盐系统错误着的理由。血统并没有缓慢地演化；岩只记录了时间三十分之一，缺失的百分之九十二中发生着的形态改变根本不在那里。校正定年着剖面一个独立的方法——牙形石的、笔石的生物带、一个同位素的曲线、一个灰的层——计算着速率对抗**独立的**时间、不是对抗厚度。
:::
