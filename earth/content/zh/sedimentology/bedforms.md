沙丘形态是流的手迹。一个在一个移动的床上移动着的流组织着那个床成波痕、沙丘、平面与反沙丘的波长的、高度，由流的深度、速度、粒度设定着，它把每一个保存着为一个独特的交错层理的风格。结果是历史的地质的最有力的工具之一：一个砂岩的内部的结构是一个制造着它的流的测量，做在任何人是在那里取着测量之前几百万年、用一个手透镜、一个卷尺读着。

## 流的制度

::: definition 弗劳德数，两个制度 {#def-froude}
**弗劳德数**是流的速度对一个长的表面的重力的波的速度的比，
$$
\mathrm{Fr} = \frac{u}{\sqrt{g h}} ,
$$
它把明渠的流分为两个动态地不同的状态。约 $0.7$ 之下流**亚临界的**（*安静的*）：一个表面的波能向上游旅行着，流深的、慢的，床塑造成波痕与沙丘。$1$ 之上流**超临界的**（*射击的*）：没有扰动能向上游旅行着，流浅的、快的，床是一个平面、塑造成反沙丘，它的表面的波与它们同相。中间的状态，**上制度平面床**，一个平的、抛光的表面、完全没有沙丘形态，流的阻力的高的状态。区分是在任何一个古水力的重建确立着的第一件事，一个相同波长的一个沙丘、一个反沙丘记录着它们的深度相差着一个三的因子的流。
:::

::: definition 制度的图 {#def-regime}
**西蒙斯–理查森–博加迪的制度图**（通常叫西蒙斯–阿尔伯特图）绘制着剪切的流速 $u_*$ 对着粒子的雷诺数 $u_* d/\nu$、地图着没有运动、波痕、沙丘、平面床、转变、反沙丘、槽与沙丘的字段。它的结构简单的、稳健的。低的应力，什么都不移动着。升高的应力床制造着波痕，然后的高的与长的波长的沙丘，然后一个平面床作为沙丘被洗掉着，然后反沙丘作为弗劳德数接近着一。一个固定的粒度序列因此跑着**下制度 → 转变 → 上制度**，一个沙丘形态在图的位置固定着 $u_*$、深度、速度。
:::

::: example 哪一个制度？ {#ex-regime}
一条 $1.5\ \mathrm{m}$ 深的河流动着 $1.1\ \mathrm{m/s}$ 在一个 $0.25$-mm 的砂的床上。找着弗劳德数、预测着沙丘形态。同一个的排水然后约束着一个 $0.4\ \mathrm{m}$ 深在 $2.0\ \mathrm{m/s}$ 的水槽：床怎么发生？
::: solution
$$
\mathrm{Fr}_1 = \frac{1.1}{\sqrt{9.81\times1.5}} = \frac{1.1}{3.84} = 0.29, \qquad
\mathrm{Fr}_2 = \frac{2.0}{\sqrt{9.81\times0.4}} = \frac{2.0}{1.98} = 1.01 .
$$
第一个流舒适地亚临界的、一个 $0.02\ \mathrm{m/s}$ 的剪切的流速、一个 $0.25$-mm 的床，躺在制度图的**沙丘**字段：床是一个不对称的沙丘的列，波长的量级 $6h = 9\ \mathrm{m}$、高度的量级 $0.1h = 0.15\ \mathrm{m}$。第二个在 Fr = 1.0，**水力的临界的**状态，床是一个洗掉的平面、一个与自由表面同相的反沙丘的列。

实际的含义是约束改变了矿层从一个**向下制度沙丘的砂、大的规模的槽的交错层理向着下游倾斜着**到一个**上制度的单元、低的角度、向着上游的层理、一个撕裂的铸型的顶部**。岩石的记录两者被一个陡的、常常冲刷的接触分离着，一对记录着一个单的事件，流变浅的、快的——一个洪水减弱着作为它从一个坝铺展开着、一个陆棚上的一个波的上冲。从结构读着制度因此不是一个分类的练习、一个关于消失了一亿年的水的深度与速度的直接的陈述。
:::
:::

## 波痕，沙丘与它们的大小

::: definition 波痕与沙丘 {#def-ripples-dunes}
一个**波痕**是一个小的沙丘形态，一个中砂的 $5$–$15\ \mathrm{cm}$ 的波长、一个 $1$–$2\ \mathrm{cm}$ 的高度，给出着一个波痕指数 $\lambda/H$ 为流的波痕的 $15$–$25$、波的波痕的 $8$–$15$。砾上波长随着颗粒的大小标度着，$\lambda \approx 6$–$7\,d$，砂上它由流设定着、几乎不依赖着 $d$。一个**沙丘**是一个河道的 $0.5$–$10\ \mathrm{m}$、沙漠的 $50$–$500\ \mathrm{m}$ 的波长、它的波长的约十分之一的高度、波长的四分之一到一半的长的迎水的坡。水下的沙丘经验的关系
$$
\lambda \approx 6\,h, \qquad H \approx 0.1\,h \approx \lambda/12
$$
持续着流的深度的两个数量级，使沙丘的波长一个**流的深度的量规**。一个**波痕**是一个它的高度由粒度限制着的沙丘；一个**沙丘**是一个它的高度由流的深度限制着的沙丘形态；一个**反沙丘**是一个它的高度由自由表面限制着的沙丘形态。
:::

::: proposition 沙丘的层理与保存的组 {#prop-set}
一个在一个加积的床上移动着的沙丘被下一个的沙丘的槽截断着，保存的交错层理的组的厚度是
$$
h_\text{set} \approx 0.08\,\lambda ,
$$
它，因为 $H \approx \lambda/12$，**沙丘的高度自己**的约等。一个交错的砂岩的组的厚度因此是一个制造着它的沙丘的高度的测量，通过上面的关系、形成着它的流的深度的测量。
:::

::: example 从一组交错层理到一条河的长度 {#ex-set}
一个砂岩显示着组 $45\ \mathrm{cm}$ 厚的槽的交错层理，组的边界凹的向上的、没有上面的层的截断的证据。估计着沙丘的波长、沙丘的高度、流的深度、说着假设。
::: solution
反转着 $h_\text{set} = 0.08\,\lambda$，
$$
\lambda = \frac{0.45}{0.08} = 5.6\ \mathrm{m}, \qquad
H = \frac{\lambda}{12} = 0.47\ \mathrm{m}, \qquad
h = \frac{\lambda}{6} = 0.94\ \mathrm{m}.
$$
流因此约一米深的、沙丘半米高的——一条小的河、一个潮汐的河道，不是一条大的辫状的溪流。

三个假设在这里做着工作、每一个检验着。第一是组**不被**一个上面的层的底部**截断着**；它们是，测量的厚度是一个最小、真正的沙丘更高的。第二是关系 $h_\text{set} = 0.08\lambda$ 适用着，它要求着**加积、不减积着**——一个被冲刷着的床给出着比沙丘薄得多的组。第三是沙丘在流的**平衡**，它在一个减弱的洪水失败着，沙丘洗掉到一个平面、最后保存的组记录着最后的沙丘、不是最大的。三个全持续着，一个悬崖的剖面的一个卷尺给出着一个石炭纪的河的长度在二的因子之内，多数古水力的方法做不到的。
:::
:::

::: example 波的波痕与一个陆棚上的风暴 {#ex-waveripple}
一个 $d = 0.25\ \mathrm{mm}$ 的细的砂包含着低的角度、对称的、分叉的交错层理的层理、一个 $60\ \mathrm{cm}$ 的波长、一个 $4\ \mathrm{cm}$ 的高度。使用着涡的波痕的间隔的关系 $\lambda/d = 5.5\,(A_{63}/d)^{0.8}$，找着近床的轨道的偏移 $A_{63}$、决定着层理是一个波的波痕、一个流的波痕。
::: solution
测量的比是 $\lambda/d = 0.60/2.5\times10^{-4} = 2400$，
$$
\frac{A_{63}}{d} = \left(\frac{\lambda/d}{5.5}\right)^{1/0.8} = \left(\frac{2400}{5.5}\right)^{1.25} = (436)^{1.25} = 1994,
$$
$A_{63} = 1994\times2.5\times10^{-4} = 0.50\ \mathrm{m}$。

一个在床之上 $63\ \mathrm{mm}$ 的半米的轨道的偏移要求着一个浅的陆棚上的风暴的波、不是一个海滩上的涌浪：正常的良风的波给出着 $5$–$20\ \mathrm{cm}$ 的 $A_{63}$、$5$–$15\ \mathrm{cm}$ 的波长的波痕。**波痕指数**确认着诊断：
$$
\frac{\lambda}{H} = \frac{60}{4} = 15,
$$
它在波的波痕的字段（$8$–$15$）的上端、流的波痕的字段（$15$–$25$）之下。结合着层理的对称、分叉的脊、$60$-cm 的波长，结构是一个**涡的（波的）波痕**在一个风暴之下形成的，床记录着一个到达着海底的波基。这是一个**风暴的层**的标准野外的识别，从波长导出的轨道的偏移是一个波的高度的一个第一的估计，能与从上面的沉积导出的深度比较着。
:::
:::

::: history
沙丘形态的分类由科罗拉多州立大学的拉尔夫·西蒙斯、伊斯梅尔·理查森、约翰·诺丁的水力的实验室的学派固定着，它们的 1965 的制度图地图着波痕、沙丘、平面床、反沙丘在剪切的流速–粒度的平面的字段、仍是每一个水槽实验室的工作着的工具。交错层理的水力的解释更老：1877 的吉尔伯特（Gilbert）显示着犹他的大白垩纪的交错层理是沙丘的移动的迹线，一个组的几何、它与制造着它的形态的关系由麦基、比加雷拉在它们的中叶的巴西的、得克萨斯的沙丘的工作为现代的砂做出着。流的波痕、波的波痕靠波痕指数的区分由于布赫尔（Bucher, 1919）、1961 的阿什利（Ashley）、1980 的米勒与科马尔（Komar）量化着；这里使用着的涡的波痕的间隔的关系是 1990 的尼尔森（Nielsen）改铸的米勒–科马尔的形式。垄脊的交错层理由哈姆斯、萨瑟德、斯佩克斯在 1975 命名着、解释着为一个风暴的结构，一篇制造着一个子领域、固定着一个十年的关于风暴的陆棚的"底流的"结构的争论的论文。保存的组的厚度、沙丘的高度的关系由英格、杰罗马克、林（Lim）在 2010 在实验室测量着，潮汐的、每天的层理的计数恢复着一个地质的天的长度回到 1960 年代的叠层石的工作，1969 的施勒德尔–亚当斯与施瓦茨哈赫尔（Schwarzacher）、1989 的乔治·威廉姆斯（Williams）应用于前寒武纪的潮汐的矿层、仍是整个的地球的历史的使用真正地定量的测量之一。
:::

## 构造与它们意味着什么

::: definition 诊断的构造 {#def-structures}
**槽的交错层理**是一个三维的沙丘的冲刷的充填、河流的、浅海的、深水的砂的常见的大的规模的结构；它的组的边界凹的向上的、它的层理以 $15$–$25^\circ$ 倾斜着。**平面的（板状的）交错层理**是一个二维的沙丘的直的脊的移动、指示着一个比相同规模的槽的交错层理更强的、更浅的流。**波痕的交错层理** $1$–$5\ \mathrm{cm}$ 厚的，它的**波痕指数** $\lambda/H$ 分离着流的波痕（$15$–$25$，不对称的、一个直的、舌状的脊）波的波痕（$8$–$15$，对称的、分叉的、在脊加厚的层理）。**垄脊的交错层理**是一个低的角度、宽的凸的与凹的、没有一致的倾斜的表面的序列，在一个良风的波基之下的一个风暴影响的陆棚上由一个风暴的联合的振荡的、单向的流形成着。**薄层状的、透镜状的、波状的层**是砂的波痕、泥的覆盖的互层、**潮汐的**流的经典的指示，它的潮–小潮的循环产生着砂的偶组的束，如果泥能在掘穴者中存活着，这个计数就记录了两次小潮之间的汛潮次数。
:::

::: example 读着一个构造的叠置 {#ex-stack}
一个 $12$-m 的序列向上变细着、从底部显示着：(1) $3\ \mathrm{m}$ 的槽的交错的粗的砂、组的厚度 $0.8\ \mathrm{m}$、零散的 $5$-cm 的泥的碎片；(2) $4\ \mathrm{m}$ 的平面层的中的砂、$60$-cm 的组、低的角度再激活的表面；(3) $3\ \mathrm{m}$ 的薄层状的细的砂、$2$-cm 的波痕、每 $13$ 到 $15$ 个砂的层理之后的泥的覆盖；(4) $2\ \mathrm{m}$ 的水平层的极细的砂与粉砂、孤立的掘穴。解释着每一个、整体。
::: solution
**(1)** 一个 $0.8\ \mathrm{m}$ 的组的厚度给出 $\lambda = 0.8/0.08 = 10\ \mathrm{m}$、$h = 10/6 = 1.7\ \mathrm{m}$：一个**深的、高的能力的河道**带着 $0.8$-m 的沙丘，泥的碎片是从河道自己的泥衬着的床撕开的滞后的物质。
**(2)** $60$-cm 的组的平面层给出 $\lambda = 7.5\ \mathrm{m}$、$h = 1.25\ \mathrm{m}$，平面的层要求在相同的深度一个**比槽的层理更高的弗劳德数**，流比 (1) 更浅的、更快的——一个坝的坪、一个减弱的洪水的河道的边缘。再激活的表面记录着流的反转、它的减弱与再增强着。
**(3)** $2$-cm 的波痕、每 $13$ 到 $15$ 个砂的层理之后的泥的覆盖的薄层状的层一个**潮汐的坪**，覆盖的周期性一个**潮汐的束**。如果每一个砂的层理是一个汛的潮、每一个覆盖一个小潮，期望的间隔是潮–小潮的循环的 $14.76$ 天以半天的、每天的层理表示着、$13$–$15$ 的计数是一个半日的、混合的系统的诊断的数字。
**(4)** 极细的砂与粉砂的水平的层理带着掘穴是一个**低能量的亚潮的、潮间的坪**在沙丘的移动的水平之下、内底栖的足够的氧。

整体一个**海侵的**序列：一个深的河道、一个更浅的、更快的坝的坪、一个潮汐的坪、一个安静的亚潮的。粒度变细着，流的深度首先落下、然后能量落下，迹相的构造只在上部出现着。这是一个海岸的上超、一个盆地的规模的背景，一个海侵的体系域的顶部——一个构造单独支持着、粒度单独不的结论。
:::
:::

::: warning 沙丘形态移动着，岩石记录着移动、不是床
一个交错层是一个沙丘形态的**保存的部分**，保存的部分依赖着床的加积的速率、它的移动的速率的比。三个系统的扭曲跟着。**组的厚度预测过低着沙丘的高度**床减积着、不加积着的任何地方，一个河道的充填多数的组截断着，剖面的最厚的组是沙丘的高度的比均值更好的估计。**沉积的构造不是沙丘形态**：一个 $1\ \mathrm{m}$ 高的沙丘能保存为一个 $5\ \mathrm{cm}$ 厚的组，两者的比是一个加积的速率的函数、岩石几乎从不测量着。一个交错层的**古水流是沉积的时刻的流的方向**，一个坝的下风的沙丘它能与区域的流相差着三十度或更多；一个从一个床的几十次的测量建造的古水流的玫瑰图是一个坝的测量、不是一个流的制度的测量。纪律是对每一个解释的流的方向、每一个解释的深度说着，结构是一个完全的组、一个截断的组、一个再激活的表面，把一个测量的群体的均值作为群体的、不是流的测量对待着。
:::

::: quiz
一个砂岩显示着 $30\ \mathrm{cm}$ 厚的槽的交错层理的组、以 $22^\circ$ 倾斜着的层理。别的看不见。最强的结论是什么？
- [x] 砂由移动着的三维的沙丘在一个亚临界的流里沉积着。
- [ ] 流约 $0.6\ \mathrm{m}$ 深的。
- [ ] 流一条河、不是一个海洋的流。
- [ ] 沙丘 $30\ \mathrm{cm}$ 高的。
::: solution
$22^\circ$ 的倾斜的槽的交错层理是三维的沙丘的移动在一个亚临界的流的诊断的，结论不需要着校准。深度不能得到，不假设着组完全的、组的厚度的关系适用着，两个假设能错着一个三的因子。流能是一条河、一个潮汐的河道、一个陆棚的流、一个浊流，环境不能从交错层理单独确定着。沙丘**至少** $30\ \mathrm{cm}$ 高的、可能更高的。
:::
:::

## 通向何处

制造着这些沙丘形态的流在沉积的运输的课里描述着、它们分选着的粒度在沉积的颗粒的课里；环境在陆地的环境、海洋的环境的课里；构造如何使用着建造着一个相的模型在相的课里；制造着束的潮汐在海洋学的波与潮汐的课里。

::: summary
- 弗劳德数分开着下制度的沙丘形态（波痕、沙丘）上制度的（平面床、反沙丘），两者记录着它们的深度相差着一个三的因子的流。
- 水下的沙丘的波长是流的深度的约六倍、它的高度的约十分之一的波长，沙丘是一个流的深度的量规。
- 保存的交错层理的组的厚度是沙丘的波长的约百分之八，沙丘的高度约等。
- 波痕指数分离着流的波痕（$15$–$25$）波的波痕（$8$–$15$），涡的波痕的波长测量着近床的轨道的偏移。
- 垄脊的交错层理记录着一个风暴的联合的流；薄层状的层、潮汐的束记录着潮汐。
- 一个交错层记录着一个沙丘形态的保存的部分、不是沙丘形态自己，组的厚度是一个最小。
:::

## 练习

::: exercise 弗劳德数 {level=1 check="0.64"}
找一个 $4\ \mathrm{m}$ 深在 $4\ \mathrm{m/s}$ 移动着的流的弗劳德数。
::: solution
$\mathrm{Fr} = 4/\sqrt{9.81\times4} = 4/6.26 = 0.64$。流亚临界的、接近着转变，床一个洗掉的沙丘、一个转变的沙丘形态。
:::

一个水下的沙丘的田有一个 $36\ \mathrm{m}$ 的波长。估计着流的深度。
::: solution
$h = \lambda/6 = 6\ \mathrm{m}$。沙丘的高度约 $36/12 = 3\ \mathrm{m}$，保存的组的厚度约 $0.08\times36 = 2.9\ \mathrm{m}$。
:::

::: exercise 波痕指数 {level=1 check="20"}
一个波痕有一个 $12\ \mathrm{cm}$ 的波长、一个 $6\ \mathrm{mm}$ 的高度。找着波痕指数、分类着它。
::: solution
$\lambda/H = 120/6 = 20$，一个**流的波痕**。相同波长的一个波的波痕 $8$–$15\ \mathrm{mm}$ 高的、对称的、双分叉的层理。

::: exercise 组的厚度 {level=2}
一个砂岩显示着 $25\ \mathrm{cm}$ 厚的槽的交错层理的组，每一个上面的组的底部截断着下面的，剖面的最大的组 $70\ \mathrm{cm}$。哪一个数应该使用着估计着沙丘的高度，它给出着什么深度？
::: solution
**最大的组**，$70\ \mathrm{cm}$，截断使每一个别的组一个最小。它给出 $\lambda = 0.70/0.08 = 8.8\ \mathrm{m}$、$h = 8.8/6 = 1.5\ \mathrm{m}$。使用 $25\ \mathrm{cm}$ 的均值将给出一个 $0.53\ \mathrm{m}$ 的深度，一个三的因子太小。一个河道的充填的一般规则是使用最大的组的厚度、把均值作为一个下界说着。
:::

::: exercise 波的波痕 {level=2 check="0.13"}
使用着波的波痕与一个陆棚上的风暴的例子的关系，找一个 $20\ \mathrm{cm}$ 的波长的一个波的波痕 $A_{63}$ 在 $0.25$-mm 的砂。
::: solution

:::

::: exercise 潮汐的束 {level=2}
一个潮汐的坪的砂岩保存着 $13$ 到 $15$ 个砂的层理的束、泥的覆盖分离着。计数意味着什么，什么将伪证着解释？
::: solution
计数是一个半日的系统**连续的潮之间的汛的潮**的数目：一个潮–小潮的循环是 $14.76$ 天，每一个阴阳历的循环两个汛、两个小潮，最大的潮的覆盖的间隔是 $13$–$15$ 个层理的对。束因此一个**阴历的月的钟**，它保存着的任何地方给出着地质过去的每一个月的天数——经典的应用是前寒武纪的、古生代的叠层石、潮汐的层的计数使用着推断着一个更短的月、一个更长的天。

三件事将伪证着它。**掘穴**：泥的覆盖生物扰动着的、层理原生的不是，计数无意义的。**风暴与洪水的覆盖**：一个泥的覆盖能由单的一场风暴、单的一场洪水沉积着、不是一个小潮，检验是覆盖是否系统地更厚的、更持久的在一个地层的水平（一个风暴的面）、在一个恒定的间隔贯穿着重复着。**层理必须是右的厚度的偶组**：一个单的砂的层理是一个潮，层理实际半潮的偶组着的计数必须双倍着。解释只存活，层理能显示着每天的、半天的、覆盖周期着的。
:::

::: exercise 一个古水力的综合 {level=3}
一个寒武纪的砂岩包含着保存的 $1.2\ \mathrm{km}$ 的波长、$60\ \mathrm{m}$ 的高度的沙丘、到 $25\ \mathrm{m}$ 厚的槽的交错层理的组。解释着、识别着使用水下的关系什么错了。
::: solution
水下的关系给出 $h = 1200/6 = 200\ \mathrm{m}$ 的水、$1200/12 = 100\ \mathrm{m}$ 的沙丘的高度，它将是一条 $200\ \mathrm{m}$ 深的河——测量的最大的河的洪水的深度、比亚马孙重建的任何更大的。组的 $25\ \mathrm{m}$ 的厚度与一个 $25$–$100\ \mathrm{m}$ 的沙丘的高度一致，内部的一致不是问题。

问题是关系 $\lambda = 6h$、$H = 0.1h$ 校准在 $0.1$–$20\ \mathrm{m}$ 深的水下的沙丘，**风成的沙丘无效着**，它的波长由跃移的云的饱和的长度、边界的层的高度设定着、不是一个水的深度。风成的沙丘有 $10$–$20$ 的 $\lambda/H$，水下的沙丘相似的，它们的波长 $50$–$500\ \mathrm{m}$、风的高度独立的。一个 $1.2$-km 的波长、$60$-m 的高度的沙丘带着 $25$-m 的组的正确的解释因此一个**风成的沙海**——一个巨大的沙丘的田的类型的保存在纳瓦霍的砂岩、科科尼诺的砂岩、寒武纪的西蒙山的——解释支持着相关的颗粒的降落的、颗粒的雪崩的层理、大的规模的交错层理带着高的角度的切线的上前缘的层、泥的缺乏、干燥与蒸发的特征。

一般的教训是每一个古水力的关系携带着它的校准的范围，一个水槽导出的公式应用到一个沙丘的田是这个学科的最常见的、最后果严重的错误。
:::

::: exercise 垄脊的交错层理 {level=3}

重建给出着一个持续着几天的风暴，在它的第一个小时筛选着、再工作着海底、几周的安静跟着着。当时的水的深度能从风暴的振荡的流到达着床的事实估计着：一个 $15\ \mathrm{s}$ 的波的周期，床的 $0.5\ \mathrm{m}$ 的轨道的偏移要求着一个几米的波的高度、把风暴的波基放在 $40$–$80\ \mathrm{m}$，这是一个**中间的陆棚**的剖面。泥的任何的三角洲的、浊积石的构造的缺乏、掘穴的贯穿着的存在，确认着背景一个低能量的完全海洋的陆棚。
