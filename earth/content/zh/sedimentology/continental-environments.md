大陆的环境占据着陆地的表面的三分之一、保存着穿过着它们的沉积的一个远更小的部分，一条河运送到海的多数的穿过着大陆运送到、不在它上面沉积着。保存的仍岩石记录的最可读的部分：矿层侧向地广泛的，它们的过程今天在地面观察着的，它们的建筑由两个变量控制着——大陆沉积学关于的——水的排水、沉积的供应、两者穿过着一年、一场洪水、一个气候的旋回变化着。

## 河流

::: definition 辫状的与蜿蜒的 {#def-braid-meander}
一个**辫状的**河是有多个的、发散与汇聚的河道的、坝分离着的、一个宽浅的床、一个陡的坡度、一个粗的推移质主导的载荷、一个重新工作它自己的床的高的能力。一个**蜿蜒的**河是一条单一的弯曲的河道、一个螺旋的流建造着一个点坝在每一个弯的内部、侵蚀着切岸在外部，一个推移质对悬浮的载荷的比近一、一个粘结的岸。判别不只是弯曲度的问题：一个弯曲度 $1.3$ 之下的河直的到弯曲的、一个 $1.5$ 之上的蜿蜒的，两个哪一个的**控制**在**床与岸的细的沉积**的部分。富黏土的岸、一个悬浮的载荷的供应给出着一个窄的、深的、蜿蜒的河道；一个不粘结的、粗的推移质的供应给出着一个宽、浅、辫状的。**网状的**河，几个互连的河道、植被的、三角洲的岛分离着、一个非常低的坡度，第三个的类型、一个净的**沉降**的速率与它的沉积的供应相当的表征着。
:::

::: proposition 曲流的几何与改道 {#prop-meander}
一个冲积的河的曲流**波长**，两个数量级的河的规模的显著地恒定的，
$$
\lambda \approx (11\text{–}16)\,W,
$$
$W$ 满槽的河道的宽度，一个曲流的带典型地 $10$–$14$ 倍的河道的宽度横穿着。一个蜿蜒的河**改道**——放弃着它的路线、捕获着一个更短的穿过着洪泛平原的路径——谷底沿着放弃的路径的坡度超过约的活动的河道的坡度的三分之一（利奥波德、牛顿），那个点更短的路线可用的能量足够侵蚀着口门的坝、捕获着流。
:::

::: example 河多大？ {#ex-meander}
一个白垩纪的曲流的带 $620\ \mathrm{m}$ 宽的、它的河道的砂岩 $11\ \mathrm{m}$ 厚的、它的古水流单峰的。估计着满槽的宽度、曲流的波长、均值的深度、满槽的排水、说着不确定度。
::: solution
一个曲流的带 $10$–$14$ 倍的满槽的宽度，
$$
W = \frac{620}{12} = 52\ \mathrm{m}, \qquad
\lambda = 12.6\times52 = 655\ \mathrm{m}.
$$
一个蜿蜒的河的宽度对深度的比 $10$–$40$，$11\ \mathrm{m}$ 的河道的砂岩的厚度一个**最小**深度，坝截断着河轴；取着一个 $20$ 的宽度对深度的比给出
$$
d = \frac{52}{20} = 2.6\ \mathrm{m},
$$

排水，一个下游的水力的几何的关系的形式 $W = aQ^b$、$b \approx 0.5$、校准在大的蜿蜒的河给出着一个满槽的排水的量级
$$
Q \approx \left(\frac{52}{3.0}\right)^{2} = 300\ \mathrm{m^3\,s^{-1}},
$$

练习之点方法的不平衡。一个曲流的带的**宽度**一个稳健的测量、一个采石场、一个地震的属性做着的、给出着河道的宽度在三分之一之内；**排水**要求着坡度，几乎从不保存着，永远一个量级的估计。几何的古水文学一个宽度的科学、不是排水的。
:::

::: example 它将改道吗？ {#ex-avulsion}

## 扇，干盐湖与湖

::: definition 冲积的扇与干盐湖 {#def-fan}
一个**冲积的扇**是一个沉积的锥、建造在一个限制的山的溪流涌出一个不受限制的盆地的地板、失去着它的能力的任何地方。它的三个过程端元**泥石流**（一个基质支持的、富漂砾的、不成层的叶、突然停止着、保存着它的形状）、**片流**（一个浅的、不受河道的、侧向地广泛的洪水、铺设着透镜的层的成层的砾与砂在一个扇的上部）、**开敞的河道的流**（一个河道的、侧向稳定的溪流、铺设着滞后、交错的坝在一个中的与下的扇）。一个扇的**顶点**坡度断裂的任何地方，它的**中扇**河道的移动的最大的带、它的**远扇**与盆地交错着。一个**干盐湖**是一个封闭的盆地的干的、咸的、泥的裂缝的地板，它的矿层层理的泥、蒸发的壳、**干裂的角砾岩**、干的泥的卷撕裂与再沉积着形成着的。
:::

::: definition 湖 {#def-lake}
一个**湖**接受着它的沉积从三个源：一个波与坝的**沿岸的**带、一个安静的悬浮的沉降与纹泥的**深湖的**带、连接着它们的**三角洲**。一个**半混合的**湖是是分层着的、它的深的水从不混合着与表面，富有机物的层理的泥、制造着一个保存特异化石库的特殊的保存的经典的位置。一个**纹泥**是一个粗的夏天的层、一个细的冬天的层的年的偶组，一个纹泥的年表第四纪可用的少数绝对的地质时钟之一。一个湖的**水位**一个降水、径流、蒸发的平衡的测量，一个湖的海侵因此是一个**气候**的信号，一个海洋的海侵主要是一个冰的体积与构造的信号、不是这样。
:::

::: example 数着纹泥、读着一个湖 {#ex-varve}
一个 $14$-m 的湖的序列显示着纹泥 $1.8\ \mathrm{mm}$ 厚的它的下部的 $9\ \mathrm{m}$、$6\ \mathrm{mm}$ 厚的它的上部的 $5\ \mathrm{m}$。下部的单元层理的石灰的泥岩、没有掘穴；上部的单元有 *Planorbis* 的腹足类的、根须、干裂。找着每一个单元的持续、解释着历史。
::: solution
下部的单元表示着 $9000/1.8 = 5000$ 年、上部的 $5000/6 = 830$ 年、总共约 $5800$ 年。沉积的速率从 $1.8\ \mathrm{mm\,yr^{-1}}$ 上升着到 $6\ \mathrm{mm\,yr^{-1}}$、一个 $3.3$ 的因子。

两个单元记录着相反的条件。下部的单元，层理的、未扰动的、钙质的，一个**深的、半混合的、季节的冰覆盖的**湖、一个沉积–水的界面的缺氧；它的低的、恒定的纹泥的厚度记录着一个稳定的流域的一个稳定的细的碳酸盐与泥灰的供应。上部的单元，腹足类的、根、干裂，一个**浅的、充氧的、周期地露出的**湖；它的更厚的纹泥记录着一个更高的生产力、一个更高的碎屑的供应、最可能的，给着变浅着，沉积的集中进入一个更小的、更多生产力的水柱。

历史一个**湖的退进**，一个湖的水位响应着降水–蒸发的平衡，退进一个**变干**的信号。这样一个的序列一个盆地充填的许多叠置的一个的任何地方，旋回海侵的类型的湖的水位的旋回、经典的例子——始新世的绿组的、侏罗纪的卡门的、三叠纪的卡斯蒂的——它们的周期性使用着测量着深的时间的米兰科维奇的旋回一个纹泥的时钟的精度。

## 风

::: definition 风成的沙丘 {#def-aeolian}
一个**风成的**矿层识别着它的粒度（一个紧的、很好分选的细的到中的砂，风分选着远更细的水）、它的**磨圆度**（颗粒的表面的毛面的、一些背景二氧化硅的包裹）、它的**大的规模的交错层理**组的厚度米、它的内部的层理三种类型：**颗粒的降落**（一个低的角度、正粒的、非常细的层理、跃移的颗粒的降落在一个下风的坡上）、**颗粒的雪崩**（一个更陡的、倒粒的层理、下风的坡过度地陡着到静止角、失败着形成着的）、**风成波痕**的层理（一个薄的、低的角度、波痕的层理、迎风的、沙丘间地板形成的）。沙丘的类型跟着**砂的供应、风的制度**：新月形的（一个新月、角向着风的，一个有限的供应、一个单峰的风），横向的沙丘（一个长的脊、法向一个单峰的风、一个丰富的供应），新月形的丘（一个过渡的新月的脊），线形的**塞伊夫**沙丘（一个脊、平行的一个双峰的风的合成），星形的沙丘（一个金字塔的沙丘、一个多方向的制度、一个沉积的陷阱，常见的在一个沙海的边缘）。
:::

::: example 一个古代的沙海 {#ex-erg}
一个砂岩显示着到 $22\ \mathrm{m}$ 厚的交错层理的组、由很好分选的 $0.20$-mm 的石英的砂、颗粒的降落与颗粒的雪崩的层理一个 $3:1$ 的比、切线的前缘的层以 $30^\circ$ 到 $33^\circ$ 倾斜着、完全没有泥。古水力的玫瑰图宽的、八峰的。估计着沙丘的高度与波长、识别着沙丘的类型。
::: solution

$$
\lambda = \frac{22}{0.08} = 275\ \mathrm{m},
$$
它把沙丘的高度放在 $\lambda/12 \approx 23\ \mathrm{m}$——与组的厚度一致的，沙丘约 $25\ \mathrm{m}$ 高的、一个 $300$-m 的波长。这个**现代的标准一个小的沙海**（纳米布的、塔克拉玛干的有 $100$–$300\ \mathrm{m}$ 高的、$1$–$2\ \mathrm{km}$ 分离的沙丘）、岩石记录的标准一个大的，多数的风成的组的厚度 $1$–$10\ \mathrm{m}$。

## 练习

::: exercise 弯曲度 {level=1 check="1.8"}
一条河的河轴在两个点之间 $36\ \mathrm{km}$ 长的、直线 $20\ \mathrm{km}$ 分离的。找着弯曲度、分类着河。
::: solution
$S = 36/20 = 1.8$，一个**蜿蜒的**河（类：直的 $< 1.05$，弯曲的 $1.05$–$1.3$，蜿蜒的 $> 1.5$）。一个 $1.8$ 的弯曲度高的、不极端的；亚马逊的在贝尼的低地的支流达到 $3$ 到 $14$。
:::
:::

::: exercise 曲流的波长 {level=1 check="780"}
一个蜿蜒的河有一个 $62\ \mathrm{m}$ 的满槽的宽度。估计着它的曲流的波长。
::: solution
$\lambda = 12.6\times62 = 780\ \mathrm{m}$。曲流的带将 $620$–$870\ \mathrm{m}$ 宽的、整个的波长约 $780\ \mathrm{m}$，一个单一的弯曲占据着大约一公里的谷。
:::
:::

::: exercise 改道 {level=1 check="0.5"}
一条河的河道的坡度 $2\times10^{-5}$、沿着它的放弃的路线的谷的坡度 $1\times10^{-5}$。找着比、说着是否期望着改道。
::: solution
比 $1/2 = 0.5$，超过着临界的 $1/3$，期望着改道。阿查法拉亚的比，老河的控制的结构存在的理由。
:::
:::

::: exercise 扇的过程 {level=2}
一个扇的剖面显示着，在一个 $20$-m 测量的柱，四个携带着漂砾的基质支持的单元、没有成层、圆的末端，八个透镜的层的成层的粗的砂与粒的滞后 $0.3$–$1.5\ \mathrm{m}$ 厚的，一个 $6$-m 厚的河道的充填、一个冲刷的底部、槽的交错层理。重建着扇。
::: solution
四个基质支持的漂砾的单元**泥石流的叶**，它们的成层的缺乏、圆的陡的边缘诊断的。八个透镜的成层的层带着粒的滞后**片流**的矿层，它们的透镜的几何、它们的侧向的尖灭没有一个单的层追踪着远。$6$-m 河道的充填一个**中扇的分流的河道**，它的冲刷、交错层理记录着一个限制的、有能力的流。

比例——泥石流厚度的百分之二十、片流百分之四十五、河道百分之三十——把测量的剖面放在**上的到中扇**，三个过程共存着，不是远扇，它将湖的泥、薄的远端的泥石流的舌统治着。带走的解释一个扇不能单一个过程描述着：正确的相的模型一个**三个过程的扇**、它们的相对贡献穿过着一个气候的旋回变化着，泥石流主导在一个湿的阶段、湿润着流域、动员着它，河道的流主导在一个干的阶段、植被走了、溪流有效率的。
:::
:::

::: exercise 风成的对抗水下的 {level=2}
一个 $15$-m 的交错的砂的组有一个古水力的玫瑰图两个模式 $90^\circ$ 分离、$28^\circ$ 的前缘的层、一些组的底部泥的碎片。它风成的吗？
::: solution
不必要，可能不。**泥的碎片**争辩着一个干的风成的系统，泥的碎片要求着一个泥的源、一个有能力撕裂着它的流，一个沙海两者都不。**$28^\circ$ 的前缘的层**在干的砂的静止角（约 $34^\circ$）之下、与一个水下的颗粒的雪崩、湿润的风成的前缘的层一致的。**$90^\circ$ 的双峰的玫瑰图**与一个**反转的、新月形的**风成的沙丘双峰的风一致的、同样地与一个它的脊横穿的流重新塑造的水下的沙丘、一个它的两个模式涨与退的潮汐的沙丘。

决定性的观察**颗粒的降落的层理**，只在空气形成；**颗粒的表面结构**，跃移在空气的麻点、二氧化硅的包裹与一个水下的颗粒的包裹不同的；**大小的分选**，风成的砂远更紧的；**任何的水生的动物群、泥的覆盖的缺乏**。这些含糊的任何地方，正确的回答"一个风成地重新工作的水下的砂、一个湿润的沙丘间的"，一个真实的、常见的环境、两个端元的模型都不描述着。
:::
:::

::: exercise 湖的水位 {level=2 check="3.3"}
使用着数着纹泥、读着一个湖的例子的纹泥的数据，沉积的速率上升着多少倍在下部的、上部的单元之间？
::: solution
$6/1.8 = 3.3$。解释不直截了当，一个纹泥的厚度的上升能意味着更多的水、更多的碎屑的供应、更多的生产力、一个更浅的、因此更集中的盆地；相关的相——腹足类的、根、干裂——显示着这个案例原因是变浅、不是变湿。
:::
:::

::: exercise 一个河流的建筑 {level=3}
一个 $300$-m 宽的、$40$-m 厚的砂岩的体有一个凹的向上的侵蚀的底部、一个内部的结构的叠置的槽的交错的组、$3$-m 的组的厚度、一个单峰的古水流、一个上部的互层的砂与泥带着根须、它包围着 $200\ \mathrm{m}$ 的岸外的泥与古土壤。重建着体、估计着古河道的宽度与深度。
::: solution
体一个**河流的河道与它的增积的矿层**，周围的泥它的岸外的。凹的向上的侵蚀的底部河道的底部的冲刷；叠置的槽的交错层理一个单峰的古水流**点坝、侧向的增积**的矿层，根须的顶部放弃的面、下一个旋回的开始。

$3$-m 的组的厚度给出一个 $3/0.08 = 37.5\ \mathrm{m}$ 的沙丘的波长、一个约 $3\ \mathrm{m}$ 的沙丘的高度，一个水下的沙丘一个 $37.5/6 = 6.3\ \mathrm{m}$ 的流的深度——一个**最小**河道的深度，沙丘形成在坝、不在河轴。**体的宽度 $300\ \mathrm{m}$ 不是河道的宽度**：一个曲流的带 $10$–$14$ 倍的河道的宽度，河道 $300/12 = 25\ \mathrm{m}$ 宽的、体的 $40$-m 的厚度许多层的和、不是一个的深度。一个 $15$ 的宽度对深度的比河道约 $2\ \mathrm{m}$ 深的、$25\ \mathrm{m}$ 宽的，一条小的河，$6.3\ \mathrm{m}$ 的沙丘导出的深度然后太大的——不一致解决着认识着 $3$-m 的组**不是**沙丘的组、坝的增积的单元，它的厚度由坝的高度设定着、不是一个沙丘。

教训每一个储层的地质学者学习着一次的：一个组的厚度一个沙丘的高度**只**结构一个沙丘的任何地方，一个河流的储层的建筑的解释在区分着坝的增积、沙丘的移动。
:::
:::

::: exercise 一个大陆的气候的重建 {level=3}
一个二叠纪–三叠纪的盆地充填是百分之七十的红的粉砂岩带着钙结壳的水平、百分之二十的很好分选的石英的砂带着颗粒的降落的层理、八峰的古水流、百分之十的层理的灰的泥岩带着鱼、淡水的泥灰。重建着气候、沉积的系统、识别着红的颜色做着什么、不证明着什么。
::: solution
三个成分一个**洪泛平原**、一个**沙海**、一个**湖**。红的粉砂岩带着钙结壳一个氧化的、季节地干的、周期地露出的洪泛平原、一个碳酸盐的土壤；很好分选的石英的砂带着颗粒的降落的层理一个**风成的沙丘的田**、它的八峰的玫瑰图指示着一个多方向的、星形的沙丘的制度；层理的灰的泥岩带着鱼与泥灰一个**淡水的湖**、床的至少季节的缺氧。系统一个**干旱到半干旱的冲积–湖–风成的复合体**、现代的塔里木的盆地的类型、特拉华斯的盆地的二叠纪的，沙海由穿过着它的河流被重新工作着而得到补给、湖站在风蚀的洼地、洪泛平原。

**红的颜色**证明着**氧化的**条件在沉积之后，它要求着沉积站在水位之上足够长的时间赤铁矿形成——一个**排水的、季节地不饱和的**洪泛平原。它**不**证明着一个干旱的气候，红床形成在很好排水的热带的、亚热带的背景、丰富的降雨，一个红床的现代的等价物常常一个红土化的、深度地风化的、湿的景观。把解释联系着干旱**钙结壳**，它要求着蒸发、一个浅的水位、**风成的砂**，它要求着一个植被的缺乏、一个干的砂的供应。移走那两个、红的颜色单独不支持着任何的结论。

重建的最弱的环节**相对的时序**。一个沙海、一个湖不明显的邻域，它们的互层能记录一个侧向的并置、一个垂直的交替由气候的旋回驱动着、打开与关闭着沙海。检验单元的侧向的连续性、它们之间存在着一个过渡的相——沙丘间的泥、重新工作的沙丘的砂带着湖的波痕——它将证明着它们并肩站着。
