站在南极点、你站在近三公里的冰之上；站在西南极的地理的中心、你将站在——若冰举起离开——一个岛屿的群岛、它的海的渠道比挪威的峡更深、它的基岩今天的海平面**之下**几百米。那个对比是冰盖的科学的最重要的事实。东南极是一个坐在高的、冷的、的陆的岩石之上的单一的巨大的冰的质量、几百万年稳定、持有足够的冰——海平面的约52米——以一个概念结束沿海的文明。西南极是一个的沉没的架之上组装的一个是的海洋的末端的冰川的马赛克、在地质的术语年轻、通过一手的冰的流移动、只持有几米的海平面——把它们支持在支持在一个海洋的变暖能**从下面**攻击的支持的架与的海底的钉住的点的系统之后、在气候的系统能不接触大气输送热的唯一的地方。两个冰盖不是一个的两个名字的问题；它们是一个以百万年测量的慢的问题、一个以世纪测量的快的问题、冰盖的科学的历史是快的那个存在的发现。

## 解剖：穹顶、床与海洋的一半

::: definition 两个冰盖 {#def-anatomy}
南极的冰——$26.5\times10^{6}\ \mathrm{km^{3}}$、的陆地的淡的冰的$90$百分之一——分成**东南极的冰盖**（EAIS：海平面的等效的约52米、厚到$4.1\ \mathrm{km}$、一个冷的底的穹顶在一个高的床之上）、**西南极的冰盖**（WAIS：几米的海平面的等效、暖的底的、它的海洋的部分——排放Pine Island与的Thwaites的阿蒙森的海的冰川、罗斯海的南极的冰的流的系统——坐在海平面之下$2.5\ \mathrm{km}$的床上）。格陵兰增加$2.9\times10^{6}\ \mathrm{km^{3}}$（7.4米）、大部分在海平面之上、从表面融化。冰盖由它们自己的流动塑形：**的分水的岭**与**穹顶**在冰辐射的地方、的槽的**槽的**冰川在基岩的低聚焦排水的地方、**冰的架**——罗斯与的Ronne-Filchner、在它们的接地的线几公里厚——冰漂浮、海洋做工作的地方。床是命运：一个**在海平面之上**接地的冰盖只能从上面侵蚀（表面的融化、在冷的气候慢），一个**在海平面之下**接地的由海洋在它最厚的、最暖的、最移动的地方攻击——接地的线、冰变漂浮的地方、下一节显示的、几何能把撤退变成一个自动驾驶的机器的地方。整个南极的冰盖是老的（它的东南极的核心追溯到的中新的世变冷、$\sim 14\ \mathrm{Ma}$）；西南极的冰盖是一个的上新世的-的更新世的组装、它的海洋的部分在最后的500万年的温暖的区间可能反复地崩溃与重建。
:::

::: example 海平面的算术 {#ex-sle}
把格陵兰的冰盖（$2.9\times10^{6}\ \mathrm{km^{3}}$的冰）、西南极的海洋的部分（$\sim 1.4\times10^{6}\ \mathrm{km^{3}}$）转换成海平面的等效（海洋的面积$3.61\times10^{8}\ \mathrm{km^{2}}$）、求若格陵兰以它的2010年代的速率（$200\ \mathrm{Gt\,yr^{-1}}$）失去质量一个世纪的海平面的上升。
::: solution
格陵兰：$2.9\times10^{6}\times917/1000 = 2.66\times10^{6}\ \mathrm{km^{3}}$的水、$2.66\times10^{6}/3.61\times10^{8} = 7.4\ \mathrm{m}$；WAIS的海洋的部分：$1.4\times10^{6}\times0.917/3.61\times10^{8} = 3.6\ \mathrm{m}$。一个$200\ \mathrm{Gt\,yr^{-1}}$的世纪移除$2\times10^{4}\ \mathrm{Gt} = 2\times10^{16}\ \mathrm{kg}$；因为$1\ \mathrm{mm}$的海平面是$3.7\times10^{14}\ \mathrm{kg}$、那是$54\ \mathrm{mm} = 5.4\ \mathrm{cm}$的一个世纪、只从那一项。算术是一行的问题的标度：**观察的**2010年代的贡献（格陵兰约$0.7\ \mathrm{mm\,yr^{-1}}$、南极约$0.4$、冰川约$0.7$）已经总和超过$3.3\ \mathrm{mm\,yr^{-1}}$的总的上升的一半、冰盖的世纪的标度的蓄水池以**米**测量——一个现在的速率不是天花板、坡道的提醒。
:::
:::

## 海洋的不稳定

::: proposition 海洋的冰盖的不稳定（MISI） {#prop-misi}
在一个**的倒退的**床——一个向内陆变深的——接地的线在一个不稳定的平衡。跨过一条接地的线的冰的通量以它的冰的厚度陡地增加（$q \propto H^{m}$、在**Schoof**与**Schoenfeld**的标准的边界的层的理论$m \approx 3/2$–$7/4$）、在一个倒退的床、**撤退使冰在接地的线变厚**：撤退增加$H$、它增加排放、它造成进一步的撤退。反馈没有一个气候的触发、一旦开始不需要变暖以继续——它是几何、不是天气。三个的限定使陈述诚实。接地的线能由钉住的点——床的脊、一个接地的带的沉积的楔——稳定、更重要的、由**架的支持**：一个压对着它的湾的漂浮的架把后应力传递给接地的线、整个的系统的稳定是架的稳定。**的冰的崖的失效**的假说扩展逻辑：若一个架失去、一个的水位之上高于约$200$–$250\ \mathrm{m}$的海洋的末端的冰的面（一个的崖的高度对浮力的比、失效的实验与2021年的Thwaites的东的侧的几何都接近）可能在它自己的重量之下断裂、让撤退以的崩解、不是融化进行、"MICI"的机制、它的观察的检验是海平面的科学的最重要的开放的问题。阿蒙森的海的区域——Pine Island与的Thwaites冰川、排放一个持有约$1.2\ \mathrm{m}$的海平面的集水区、在一个倒退的床海平面之下$1.5\ \mathrm{km}$接地、带一个以海洋驱动的底的融化约$1.7\ \mathrm{m\,yr^{-1}}$变薄的架——正在运行的自然的实验、它的接地的线自1990年代撤退到每年$1.2\ \mathrm{km}$、它的速度自1970年代加倍。
:::

## 现代的预算

::: definition IMBIE与损失的来源 {#def-budget}
**IMBIE**（冰盖的质量的平衡的相互比较的练习）的评估调和上一个课的三个方法——冰川学的、大地测量的、通量的排放的方法——成一个冰盖一个十年一个数、2010年代的数是：格陵兰失去约$200\ \mathrm{Gt\,yr^{-1}}$（约一半从表面的质量的平衡的损失、一个变暗的表面的融化与径流、一半从动力学的排放）、南极失去约$120\ \mathrm{Gt\,yr^{-1}}$、**它的80百分之一从西南极**、由阿蒙森的海的冰川支配、它们的排放自1970年代三倍。归因跟随物理：格陵兰的损失**大气驱动的**（暖的、湿的空气的质量、从尘、黑的碳与雪的藻的变暗的反照率、它的2019与2021的融化的季节的水的断裂）、西南极的**海洋驱动的**（的绕极的深的水由风的改变与的下的变暖转移到架上、在接地的线附近达到每年的米的冰的速率从下面融化架）、东南极在十年的记录**大致平衡**、带少数的海洋的部分（的Totten、的Denman、的威尔克斯的下的盆）失去、内部获得雪——一个相反的通量的巧合的零、不是稳定。预报的后果**海平面的风险的双峰性**：在低的排放之下、本世纪的上升由的热的膨胀与冰川支配、保持在半米附近；在高的排放之下冰盖的项——格陵兰与温暖成比例的表面的融化、阿蒙森的海的海洋的不稳定的动力学——接管、高的路径的发表的2100的预报的散布从远低于一米到几米、的尾部不由任何一个模型的自信设定、由Thwaites的架是否存活本世纪。
:::

::: example 暖的水如何雕刻一个腔 {#ex-cavitymelt}
比当地的冰点高$1.5\ ^\circ\mathrm{C}$的绕极的深的水淹没Pine Island的架之下的腔。以一个湍流的交换的速度$\gamma = 10^{-4}\ \mathrm{m\,s^{-1}}$、的海水$\rho c_p = 4.1\times10^{6}\ \mathrm{J\,m^{-3}\,K^{-1}}$、求底的融化热的通量、以冰的$\mathrm{m\,yr^{-1}}$的融化的速率（$\rho L = 3.06\times10^{8}\ \mathrm{J\,m^{-3}}$）、解释融化为什么集中在接地的线、不是正面。
::: solution
湍流的热通量是
$
q = \rho c_p\,\gamma\,\Delta T = 4.1\times10^{6}\times10^{-4}\times1.5 = 615\ \mathrm{W\,m^{-2}},
$
融化$615/3.06\times10^{8} = 2\times10^{-6}\ \mathrm{m\,s^{-1}} = 63\ \mathrm{m\,yr^{-1}}$的冰——最深的腔的区域观察的量级。融化集中在的水相对于它的冰点最暖的地方、水的冰点以每米的深度只有$-7.5\times10^{-4}\ ^\circ\mathrm{C}$随压上升：在表面之下$700\ \mathrm{m}$、一个$1.2\ ^\circ\mathrm{C}$的水比它的（降低的）的冰点高$0.3\ ^\circ\mathrm{C}$、强烈地融化、同样的水在正面附近、在近表面、几乎不在的冰点之上、融化得少。这就是为什么暖的深的水是一个**接地的线的武器**——它恰在融化使冰的钉住解除的地方最强烈地融化——为什么通向一个冰川的深度的预测性它的未来和它的纬度一样。
:::
:::

::: example 阿蒙森的海的实验 {#ex-amundsen}
Pine Island冰川的接地的线在1992与2017之间撤退$31\ \mathrm{km}$、它的速度自1970年代大约加倍。若跨过接地的线的通量以$q \propto H^{7/4}$成比例、冰的厚度在接地的线在它过倒退的床撤退时增加20百分之一、求只归因于几何的通量的增加、解释观察的通量的增长为什么超过它。
::: solution
$(1.20)^{7/4} = 1.37$——只从MISI的几何37百分之一的通量的增加。观察的排放上升得多得多、因为**架的节流平行地变弱**：Pine Island的架在1990与2010年代之间变薄几十米、减少后应力、两个效应复合（更少的支持提高接地的线的有效的驱动应力、更厚的冰供应它）。这是MISI的操作的现实：几何的不稳定是真实的、但它自己慢、快的十年来自**海洋的融化同时攻击支持、床的几何**——恰是暖的深的水的入侵的条件、恰是为什么阿蒙森的海、不是冷的干燥的大陆的内部、是本世纪的海平面的问题。
:::
:::

## 深的时间：冰盖的历史与未来

::: definition 新生的冰与的上新世的检验 {#def-deeptime}
现在的冰室以**的中新世的中期的变冷**（$\sim 14\ \mathrm{Ma}$）开始、当东南极的扩张与的巴拿马的地峡的关闭同时——的因果仍然争论；日期定的是冰：东南极的冰在$12$–$10\ \mathrm{Ma}$是大量的、大陆在的上新世达到近现代的范围、**的上新世的温暖的时期**（$3.3$–$3.0\ \mathrm{Ma}$、$\mathrm{CO_2}$在$400\ \mathrm{ppm}$附近、海平面比现在高$10$–$25\ \mathrm{m}$）是海洋的不稳定的假说的地质的检验：的代理的记录（的威尔克斯的下的盆的硅藻、的有孔虫的同位素的偏移、新西兰的抬升的海岸线的微的潮的记录）显示东南极的海洋的部分撤退到它们的现在的位置的内陆、西南极显著地减少——一个温暖的世界的配置、在**两个冰盖的海洋的部分只在几度的海洋的变暖之下不稳定**。的更新世然后强加100千年的节奏：北半球的伟大的晚新生的大冰盖（劳伦泰斯的、的斯堪的纳维亚的、的巴伦支-喀拉的）在露出的、倒退的床的大陆的架生长、在使海平面上升$120$–$130\ \mathrm{m}$的去冰作用崩溃、带的融的水的脉冲的事件——的融的水的脉冲1A在$14.6$–$14.2\ \mathrm{ka}$、在约$500$年$14$–$18\ \mathrm{m}$、约$3$–$4\ \mathrm{cm\,yr^{-1}}$的速率——从沉积的记录证明冰的系统**能**在几何与海洋合作时输送每年的厘米的海平面的上升。最年轻的课是**270万年老的冰**、在的Little Dome C附近恢复：南极的冰的历史比第四纪长、它的CO₂的敏感跨越它的一百万年写、它的未来——在我们的排放的轨迹——与上新世最接近地相似、今天的海岸线尚不存在的时代。
:::

::: example 一个冰盖的停留的时间 {#ex-residence}
南极的平均的表面积累在$1.37\times10^{7}\ \mathrm{km^{2}}$之上$170\ \mathrm{mm\,w.e.\,yr^{-1}}$。求以$\mathrm{km^{3}\,yr^{-1}}$的总的积累、冰的平均的停留的时间（体积$26.5\times10^{6}\ \mathrm{km^{3}}$）、与最老的日期的冰（$2.7\ \mathrm{Ma}$）比较。
::: solution
积累$= 0.17\times1.37\times10^{13} = 2.3\times10^{12}\ \mathrm{m^{3}\,yr^{-1}} = 2330\ \mathrm{km^{3}\,yr^{-1}}$、给出一个平均的停留的时间$26.5\times10^{6}/2330 = 11{,}400$年。均值是一个的流过的平均——冰的包裹遵循狂野地不同的路径、一些在快的沿海的路径在几千年再循环、一些在冷的高原的慢的内部隔离一百万年——$2.7\ \mathrm{Ma}$的底的冰是那个分布的极端的尾部、老因为它坐在流动最慢的分水的岭之上、床足够冷、冰存活、不是融化。11 000年的均值、270万年的尾部的对比是冰盖的**的周转**、它的**记忆**的差别：第一个设定它响应强迫多快、第二个是它对过去的气候记住的——它将对我们的记住的。
:::
:::

::: warning 冰盖不是以句子暗示的方式"融化"、西南极还没有"崩溃"、东南极的零不是稳定
五个错误。**格陵兰融化；西南极流动**：前者的损失是一半的表面的融化与径流、后者的几乎完全是**排放**——在床由海洋的热崩解与融化的冰——差别规定哪个预报、归因、坦率地说哪个排放的杠杆适用。**"西南极在崩溃"是一个标题、不是一个观察**：观察的是一个海洋的部分以它的1970年代的速率的3–5的倍失去质量、带以良好测量的每年的公里撤退的接地的线——一个**在一个部分开始**的不稳定、不是一个大陆的全体的崩溃、差别重要、因为时标相差一个量级。**东南极的近零的平衡是一个通量的巧合**：内部的雪的增益（自己一个更湿的气候的信号）目前抵消海洋的部分的损失、每个模型预报符号翻转作为海洋的热到达威尔克斯与的Totten的盆；"稳定的东"是一个关于2000年代的陈述、不是2100年代的。**冰盖的预报在它们不一致时不是模型的失败**：2100的散布在高的排放之下反映关于**架的存活与崖的失效**的真正的结构的的不确定、一个排除尾部的预报组不是保守的、是错误的——诚实的框架是基于风险的、像地震与洪水的统计。**均衡影响本地**：地壳仍然从最后的去冰作用回弹（在的哈德森的湾与的波的尼亚的湾周围每年的厘米）、过去冰的重力的指纹意味着**本地**的海平面能比全球的平均差几十的百分之一；在曾经冰装载的海岸附近的潮位的计的趋势不是全球的海平面的数据。
:::

::: history
海洋的原则由**Thomas Hughes**在1973年命名——他的"冰的流的群"的论文在任何人测量它们之前二十年确定了海洋的冰盖的不稳定、架的支持的角色——现代的接地的线的物理、每个冰盖的模型现在使用的边界的层的通量的渐近、由**Frank Pattyn**（2002）、**Johannes Schoof**（2007）发展。重新塑造海平面的文献的西南极的海洋的不稳定的预报来自**Robert DeConto**与**David Pollard**（2016）、它们的崖的失效与的水的断裂的力学的包含产生了多米的二十一世纪的尾部、一个激烈的、有产出的争论关于机制是否以全的标度运行——2020年代的国际的钻探与的观测台的项目现在瞄准Thwaites冰川的问题。观察的脊柱是卫星的记录：**ICESat**的测高（2003–09）、**GRACE**的重力（2002–17）、**Helmut Rott**、**Ian Joughin**与**Eric Rignot**的InSAR的速度的制图、**IMBIE**的相互比较（2012–）、把一百个矛盾的平衡变成一个数；深的时间的脊柱是冰的芯的计划、从**Vostok**（1980年代、带**Claude Lorius**的法国-苏联的1976年的温室的效应的预报）过**EPICA Dome C**（800 ka、2004）到现在的在的Little Dome C周围的一百万年老的冰的寻找。
:::

::: quiz
海洋的冰盖的不稳定需要：
- [ ] 在接地的线的表面的融化。
- [x] 一个倒退的（向内陆变深的）床、足够使接地的线的钉住解除的支持的失去。
- [ ] 到达内部的空气的变暖。
- [ ] 高于2 km的崩解的崖。
::: solution
MISI是几何的：在一个向内陆变深的床之上的撤退使冰在接地的线变厚、提高通量、驱动进一步的撤退。它不需要表面的融化、空气的温度——只床的形状、一个变弱的、失去的支持。这就是为什么海洋驱动的架的变薄、在表面不可见的、能打开它。
:::
:::

::: summary
- 南极是两个问题：EAIS（海平面的52米、冷的、大部分在海平面之上、百万年的稳定）、WAIS（几米、海洋的、暖的底的、架支持的）、加上格陵兰（7.4米、表面的融化支配的）。
- 海洋的冰盖的不稳定是几何：在倒退的床、撤退使接地的线的冰变厚、通量上升、撤退继续——自持续的、海洋触发的、架依赖的。
- 2010年代的预算（IMBIE）：格陵兰约200 Gt yr⁻¹（一半表面、一半排放）、南极约120 Gt yr⁻¹（80百分之一西、海洋驱动的）、东南极以巧合近零。
- 上新世（CO₂约400 ppm、海平面高10–25米）是地质的检验的案例：两个冰盖的海洋的部分在几度的海洋的变暖撤退。
- 融的水的脉冲1A证明每年的厘米的海平面的上升在几何与海洋合作时物理地可用；的冰的崖的失效是未解决的扩展。
- 冰盖的海平面的风险以排放双峰、以机制结构的——诚实的预报是一个分布、它的尾部写在基岩的地图。
:::

## 练习题

::: exercise 格陵兰的世纪 {level=1 check="5.4"}
以$200\ \mathrm{Gt\,yr^{-1}}$的2010年代的速率、求格陵兰在100年之内以cm的海平面的贡献（$1\ \mathrm{mm}$的海平面$= 3.7\times10^{14}\ \mathrm{kg}$）。
::: solution
$2\times10^{16}\ \mathrm{kg}/3.7\times10^{14} = 54\ \mathrm{mm} = 5.4\ \mathrm{cm}$。数故意清醒——一个以**现在的**格陵兰的速率的世纪是本世纪的可能总的上升的一半——若读成天花板故意误导：速率在上升、表面的融化的项与变暖成比例、不是与2019。
:::
:::

::: exercise IMBIE到毫米 {level=1 check="0.33"}
南极失去$120\ \mathrm{Gt\,yr^{-1}}$。求以mm yr⁻¹到两位小数的海平面的贡献。
::: solution
$1.2\times10^{11}/3.7\times10^{14} = 0.33\ \mathrm{mm\,yr^{-1}}$——观察的总的上升的约十分之一、但它的80百分之一来自一个冰盖的一个海洋暴露的角落：信号的**集中**、不是它的大小、是警告。
:::
:::

::: exercise 漂浮的厚度 {level=1 check="1120"}
一个冰川在床位于海平面之下$1000\ \mathrm{m}$的地方接地。求以米的接地的线的冰的厚度（漂浮：$H = (\rho_w/\rho_i)\,b$）、到最接近的十。
::: solution
$H = (1025/917)\times1000 = 1118\ \mathrm{m}$、到最接近的十$1120\ \mathrm{m}$。接地的线是漂浮的线、这就是为什么它们以米的变薄响应几公里地移动：一个在$-1500\ \mathrm{m}$接地的冰的流需要$1.7\ \mathrm{km}$的冰以待在原地、使它变薄十分之一、接地的线向内陆走、直到床变浅——冰再变厚、若床允许。
:::
:::

::: exercise MISI的通量的增益 {level=2 check="2.03"}
以接地的线的通量$q \propto H^{7/4}$、求若倒退的床的撤退使接地的线的冰从$1000$到$1500\ \mathrm{m}$变厚的通量的因子。
::: solution
$(1500/1000)^{7/4} = 1.5^{1.75} = 2.03$——只从几何的加倍。与阿蒙森的海的冰川自1970的观察的通量的改变（大约加倍）比较：几何的不稳定、一旦架的节流变弱、足以解释发生的大部分的、不援引任何新的气候的敏感。
:::
:::

::: exercise 崖的高度的极限 {level=2 check="24"}
结构的失效的实验与建模显示**在水位之上**高于约$250\ \mathrm{m}$的冰的崖倾向于在它们自己的重量之下失效。用漂浮、求对应的**总的**冰的厚度、以百的米（例如27代表2700米输入27）。
::: solution
的干舷是总的厚度的$1 - \rho_i/\rho_w = 0.105$、所以总的厚度$= 250/0.105 = 2380\ \mathrm{m}$、约$24$百的米。含义是鲜明的：一个$2.4\ \mathrm{km}$的冰的柱在一个$-2.1\ \mathrm{km}$的水的深度不能作为一个崖的面站立、威尔克斯与的Aurora的盆的大部分的几何恰在那个范围——这就是为什么冰的崖的失效的假说、虽然未在全的标度检验、对东南极的海洋的部分不能驳回。
:::
:::

::: exercise 融的水的脉冲的速率 {level=2 check="3.2"}
的融的水的脉冲1A在$500$年使海平面上升$16\ \mathrm{m}$。求以mm yr⁻¹到一位小数的平均的速率。
::: solution
$16\,000/5000 = 3.2\ \mathrm{mm\,yr^{-1}}$——现在的速率的十倍多、持续五个世纪、气候的系统的冰的排放的机器能以没有一个20世纪的潮位的计的记录包含的速率运行的地质的存在的证明。现代的海平面的预报以潮位的计在下限制、以的MWP-1A的珊瑚在上限制；诚实的问题是我们在接近相似于哪个世纪。
:::
:::

::: exercise 冰盖的周转 {level=3 check="11400"}
求南极的冰的平均的停留的时间（体积$26.5\times10^{6}\ \mathrm{km^{3}}$；积累在$1.37\times10^{7}\ \mathrm{km^{2}}$之上$170\ \mathrm{mm\,w.e.\,yr^{-1}}$）、以年到最接近的百。
::: solution
积累$= 0.17\times1.37\times10^{13} = 2.33\times10^{12}\ \mathrm{m^{3}\,yr^{-1}} = 2330\ \mathrm{km^{3}\,yr^{-1}}$；停留的时间$= 26.5\times10^{6}/2330 = 11{,}400$年。周转的数设定**整个的系统对持续的强迫的响应的时间**（EAIS重建它失去的需几万千年）、$2.7\ \mathrm{Ma}$的底的冰记录它的记忆——两者的不对称是一个冰盖一旦失去、在任何的政治的、甚至文明的时标不可恢复的理由。
:::
:::

::: exercise 支持的开关 {level=3 check="16"}
一个冰川的接地的线的通量以$q \propto H^{7/4}$成比例、它的架的后应力抵消驱动应力的$60$百分之一（像在[[glaciology/ice-flow]]的练习）。若架变薄直到它什么都不抵消、通量以什么的因子上升？
::: solution
驱动应力以$1/0.4 = 2.5$上升；以通量在滑动的限制大致与驱动应力的三次成比例（在变形的限制与厚度的$7/4$的幂）、通量的因子在滑动的限制$2.5^{3} \approx 16$、在变形的限制$2.5^{7/4} \approx 4$——真实的南极的冰川的真实在之间、甚至保守的端使排放**四的倍**。这是阿蒙森的海的每个"1970年代的×3"的标题背后的单一的计算、它解释为什么架的存活、不是表面的温度、是要看的变量。
:::
