在1996年9月30日、一条的火的山的裂缝在的冰岛的大的Vatnajökull的冰的帽之下打开、在几小时之内、在比欧洲的任何的河流更快地融化冰。的融的水在一个八公里宽的下的腔聚集、压对着冰的顶、直到冰开始漂浮、然后——找到一条路径——在一个多月之内跨过下面的砂的平原排放**五立方公里**的水、它的峰值的流量是莱茵的河口的排放的二十的倍、一堵灰的水的墙把新的环的岛的桥像一个玩具一样扫进海洋。的Grímsvötn的冰的洪水是这个课的关于的事实教的演示的教科书：**冰川骑在水之上**、那个水的压——不可见的、几公里深的、由一个夏季的融化、一个床的排水的平衡控制的——冰的流动的节流、刹车。在滑动曾经作为Glen的整齐的变形的物理的一个的复杂被驳回的地方、它现在理解为世界的最快的冰川的速度的支配的项、它们的最戏剧的改变的机制、海洋的变暖、表面的融化都在几个月、不是几千年到达冰盖的内部的理由。

## 摩擦、水压与滑动的定律

::: proposition 有效的压与Weertman的滑动的定律 {#prop-sliding}
冰不像一个的雪橇在雪上滑动那样在岩石上滑动；它在一个的强度由**有效的压**设定的床上滑动
$
N = \rho_i\, g\, H - \rho_w\, g\, h_w ,
$
冰的重量减去它困住的水的压——因为冰川的滑动是摩擦的**的复冰的**：冰压对着基岩的丘、在高的应力之下在上游的面融化、在下游再冻结、水的膜是润滑的、的相的改变是输送的机制。**Weertman的滑动的定律**（1957）对一个的丘的波长$\lambda$的床：
$
u_b \propto \frac{\tau_b^{\,3}}{N}, \qquad \tau_b = \rho_i g H\sin\alpha ,
$
在驱动的应力高、水的压高（小的$N$）时快、在床是干的、冰冻结在它之上时慢地滑动。定律的两个的边是冰川的速度的戏剧的全体。当$N \to 0$——水的压接近冰的覆盖的压、**漂浮的**的条件——滑动、变形都发散、在实际中床先失效：冰举起、床变形、排水的系统重新组织以排放压。当$N$在冬季上升、当融的水的供应停止、的下的系统排干、冰川**以二的倍到十的倍变慢**——1990年代第一次用雷达在格陵兰的冰测量的季节的速度的循环、现在由从阿拉斯加到斯瓦尔巴的冰川的GPS分辨。现代的实用的形式、$u_b = C\tau^m N^{-l}$、以$m \approx 1$–$3$、$l \approx 1$、每个冰川、每个季节标定、它的指数是这个学科的最诚实的承认：我们能测量滑动、还不能在每个地方推导它。
:::

::: example 节流：水的压作为一个控制的旋钮 {#ex-throttle}
一个格陵兰的出口的冰川以$u_b \propto \tau^{3}N^{-1}$滑动。在夏季、底的水的压上升、所以$N$从$300$落到$100\ \mathrm{kPa}$、驱动的应力不变。求滑动的加速的因子、解释加速为什么在几周之后**饱和**、即使融化继续。
::: solution
$u_b$以$1/N$成比例：因子是$300/100 = 3$。饱和是排水：举起冰的分散的水的膜是不稳定的——它们组织成渠道、渠道**耗散压**（一个以它的入口的水力的位流满的渠道在它的大部分长度有低的水的压）、所以$N$在渠道化的系统在仲夏成熟时恢复。观察的图案——在融化开始之后的几天内的二的倍到五的倍的春季的加速、部分地变慢作为渠道发展、秋季的崩溃到冬季的速率——冰川的水文学的年、格陵兰的冰盖的夏季的速度信号、第一次由**Humphrey与Anandakrishnan**在1994年检测、现在每个表面的融化对海平面的预报的贡献的标定的目标。
:::
:::

::: widget plot
f: 80*(x/200)^3
x: 0, 200
y: 0, 90
labels: u_b\ (\mathrm{m\,yr^{-1}})
caption: 在Weertman的三次的滑动的定律之下对着底的剪的应力的滑动的速度、归一化到$200\ \mathrm{kPa}$的$80\ \mathrm{m\,yr^{-1}}$——形状、不是标度、是信息：三次使滑动成为驱动应力的一个**像阈值的**函数、所以一个接近它的床不能再抓住的应力的带的冰川平滑地行为、直到它不。加上$1/N$的因子、阈值随着水移动——这就是为什么是的潮的、海洋的末端的冰川、它们的应力由它们自己的厚度设定、它们的水是自由的、滑动支配的系统支配新闻。
:::

## 的碛：床也流动的时候

::: definition 变形的床 {#def-till}
在20世纪的中期、把一个冰川打穿到它的床的标尺的冰川学家做了一个尴尬的发现：在许多地方**床自己在移动**——几十厘米到几十米每年——一个的磨碎的岩石与的破碎的沉积的饱和的泥、叫做**的碛**、在一个几十厘米到米的层以$1$–$100\ \mathrm{yr^{-1}}$的应变的速率剪。力学是土壤的力学：的碛的强度跟随一个的临界的状态的定律、$\tau_f = c' + \sigma'_n\tan\phi'$、以同样的水的压设定的有效的法向的应力$\sigma'_n$控制滑动、所以一个**富水的碛在几十千帕失效**——少于几乎任何一个暖的底的冰川的驱动应力——冰川的底的运动然后划分在冰-碛的界面的滑动、碛之内的**床的变形**、比例逐季节改变。变形在床是软的、界面是润滑的地方支配（南极的冰的流的大部分的骑在一到两米厚的变形的碛之上）、滑动在硬的床支配；变形的工作留下它自己的沉积——流线形的**的鼓的丘**、用于重建流动的方向的堆叠的碛的组构、冻结的碛的撕的碎屑漂浮在冰里。概念不只使滑动的定律复杂：它使床成为一个带记忆、水文与失效的判据的**地质的物体**、它解释为什么同一个冰川能脉动、停止、在它的碛在几十年建立孔的压、在一个季节排放它时再次脉动。
:::

::: example 划分运动 {#ex-partition}
一个冰川的底的速度是$50\ \mathrm{m\,yr^{-1}}$：$15\ \mathrm{m\,yr^{-1}}$的界面的滑动加$35\ \mathrm{m\,yr^{-1}}$的碛的变形在一个$1.5\ \mathrm{m}$厚的碛的层。求碛的应变的速率、解释碛的变形为什么**自我限制**、滑动不明显地。
::: solution
$\dot\gamma = 35/1.5 = 23\ \mathrm{yr^{-1}}$——一个快的流动的冰川的边缘的碛以一个与最快的实验室的土壤的试验可比的速率变形、这就是为什么的下的沉积的土壤的力学用钻孔的锤的探针、不是实验室原位测量。碛的变形自我限制、因为剪一个饱和的碛**使它膨胀**（颗粒骑过另一个、体积增加、水吸入、压下降）、提高强度、关闭变形——一个稳定的大多数的床的负的反馈；在一个硬的床的滑动没有这样一个内置的刹车、这就是为什么观察的最快的冰川的流动（的Jakobshavn的末端的$17\ \mathrm{km\,yr^{-1}}$的表面速度）结合硬的床的滑动、一个漂浮的舌、不是软的床的变形。确实存在的滑动的反馈——渠道化、有效的压的恢复——是水文的、它们在水的供应是无限的时候失败：海洋。
:::
:::

## 水：隐藏的工程师

::: definition 的下的排水、湖与洪水 {#def-drainage}
在表面产生的融的水通过**的冰的井**到达床——每年春季融化开的、把河流带到地下的竖井——然后组织成两个相反的机械的效应的排水的风格之一。**分散的排水**——冰-床的界面的薄的膜与的链接的腔——携带少的水、以**高的压**、使滑动最大；**渠道化的排水**（从上面融化进冰的**Nye的渠道**、从下面融化进床的**Rothlisberger的渠道**、流动的水的管道的经典的名字的来源）携带多的水、以**低的压**、稳定冰川。两个风格的季节的战争是冰川的水文学的年、它的极端的事件是**的冰的洪水**：一个的下的湖——南极持有几百个、最大的（的Vostok、在$3.7\ \mathrm{km}$的冰之下$250\ \mathrm{km}$长）持有超过一千立方公里的液体的淡的水——在它的上面的冰举起到漂浮、一条的裂缝打开时排干、洪水、最初几十$\mathrm{m^{3}\,s^{-1}}$、作为流动的水融化它自己的顶而增长、在的蓄水池排空、入口再冻结之前达到$10^{4}$–$10^{5}\ \mathrm{m^{3}\,s^{-1}}$。**Shreve的冰的洪水的理论**（1972）——洪水波作为一个带的摩擦的热的平衡的融化的管道——把观察的Grímsvötn的水文的曲线再现到几十百分之一、地质的预测的最精确的成功之一。洪水是灾害（冰岛的破坏道路的、扫桥的事件；的密苏拉的湖的灾难的密苏拉与的刻痕的荒原的洪水、$10^{6}\ \mathrm{m^{3}\,s^{-1}}$）、侵蚀的代理（在过去的冰盖之下钻入岩石几十米的隧道的谷是下一代的油田的含水层与隧道的灾害）、——因为每个湖在一个十年的循环排干——一个关于一个冰川能多快从它的床举起的重复的实验。
:::

::: example 数字的Grímsvötn {#ex-grims}
1996年的Grímsvötn的冰的洪水在$30$天释放$3\ \mathrm{km^{3}}$的水。求平均的流量、一个$5\times10^{4}\ \mathrm{m^{3}\,s^{-1}}$的峰值、峰值对均值的比。为什么洪水增长——什么使一个几$\mathrm{m^{3}\,s^{-1}}$的泄漏变成一个大陆的标度的事件？
::: solution
平均的流量$= 3\times10^{9}/(30\times86{,}400) = 1160\ \mathrm{m^{3}\,s^{-1}}$、峰值对均值的比43——洪水猛烈地不稳定、因为管道的增长是它自己的引擎：排放以与$Q$成比例的速率融化管道的顶、它提高容量、驱动更多的排放、一个的失控、它只在湖排空、管道的上游的端再冻结、露出时结束。这个**带的有限的蓄水池的正的反馈**是为什么冰的洪水的曲线的锯齿、它们的预报（冰岛的气象局现在在开始之后的几小时内从河的水位的计、降低的湖的卫星的测高发布）是Shreve的热的平衡的练习、不是的降雨的径流的模型的。
:::
:::

## 加速、停止与脉动：周期的冰

::: definition 冰川的时间的不稳定 {#def-episodic}
底的水文给冰川一个平滑的流动的定律不能产生的**周期的行为**的库。**脉动**：的质量的输送的、热的循环的不稳定（**Huws Clarke**与同事析的**热的机制的滑动的循环**、经典的脉动的质量输送的循环）在一个的储存的区装载几十年、然后把米的冰输送到冰舌在几个月——的Columbia冰川的1980年之后的崩溃（记录在**Meier与Post**的它的1950年代–70年代的推进、它的1982年的突然的撤退的经典的研究）、的喀喇昆仑与帕米尔的冰川的20年的脉动、它们在变暖之下的"稳定的异常"自己是一个底的水文的谜题。**停止**：在1994年、西南极的**Kamb冰的流**——以$500\ \mathrm{m\,yr^{-1}}$流动——在几年之内停止、它的水的压显然失去给一个已经脱水的碛；邻的B与C的流在世纪的时标交换流动、意味着南极的海平面的预算由**哪些流在开**设定、一个在几十年改变、每个平滑的模型缺少状态变量。**季节的加速**的10–100百分之一跨过格陵兰的影响融化的边缘、是的潮的冰川的以每小时的$10\ \mathrm{cm}$的振幅的滑动的**的潮的调制**（滑动的定律的最干净的自然的实验、因为潮是一个在$N$的已知的强迫）、**的粘的点**——高底的拖的钉住一个冰川的末端的斑块、直到它们释放——完成图像：床不是一个边界的条件、冰川的**神经的系统**、冰盖的未来部分是一个水文的预报。
:::

::: example 作为实验室的潮 {#ex-tide}
一个是的潮的冰川的滑动的速度在12.4小时的潮的循环变化20百分之一、在**高的**潮的峰值的速度。给定的末端的水的压的摆动在的接地的带改变有效的压$N$±30百分之一、估计$u_b \propto N^{-l}$的滑动的定律的指数$l$、解释的相位。
::: solution
在高的潮、海洋压对着漂浮的末端、提高沿着接地的带的水的压、**降低**$N$；滑动在$N$最小的时候峰值、恰观察的。平衡振幅、$1.2 = (1.3)^{l}$给出
$
l = \frac{\ln 1.2}{\ln 1.3} = 0.7 ,
$
这个学科的最自豪的测量：一个**已知的强迫**、潮、在真实的冰川反演滑动的定律的指数——跨过格陵兰与南极的潮的析一致地发现$l$在0.5与1.5之间、应力的指数$m$在1与3之间、行星提供的滑动的物理的一个实验室的验证的最接近的东西。
:::
:::

::: warning 滑动不是融化、床的水不是像一个油的润滑的、停止的冰的流不是健康的
五个错误。**"滑动融化冰"颠倒机制**：的复冰的滑动工作、因为压的融化与的再冻结**输送**冰过丘；膜是几纳米厚的、在压下降的那一刻再冻结——这就是为什么冻结的床冻结得快、"一个薄的水的膜润滑一切"做真正的工作的三次的应力的依赖错过。**的下的水不是油**：它的压由冰自己的重量、排水的几何设定、所以它不能任意地高——系统在漂浮自我限制、有趣的问题总是排水的拓扑、不是水的"量"。**冰的洪水的预报不是洪水的预报**：危险的曲线依赖管道的融化的增长、不是降雨、洪水能在火的山的、的地震的触发**之后几小时**开始、没有表面的警告——冰岛的桥现在建造以牺牲。**Kamb冰的流的停止是一个警告、不是一个安心**：一个流能关断、它能**开**——同一个在1994年脱水的碛的系统在补充、模型显示在一个世纪之内的重新激活在集水区之间移动米的海平面的预算。**"冰川在推进"不总是好消息**：脉动的类型的冰川在**失去**质量时推进（输送是内部的）、的喀喇昆仑类型的异常的推进是底的与的崩解的动力学的现象、不是变冷、变湿的一个的范围的证据——[[glaciology/mass-balance]]的账本、不是末端、记分。
:::

::: history
滑动的问题由**Johannes Weertman**（1957）定量的公式化、它的过丘的复冰的定律作为这个领域的默认站立了三十年；**Geoffrey Boulton**的1970年代–80年代的碛的力学的论文使变形的床成为一个阶的过程、**Bob Kamb**的Columbia冰川的计划（1990年代穿过的钻孔的测量）解决了那个冰川的快的流动的著名的问题——它的床在它的1982年的撤退开始之后在硬的岩石上滑动、记录在**Meier与Post**的经典的研究的过渡。**Robert H. Shreve**在1972年的融化的管道的冰的洪水的理论由**Helgi Björnsson**的冰岛冰川学的学派在Grímsvötn的重复的喷发发展并检验、**Humphrey与Anandakrishnan**在1994年的格陵兰的季节的加速的检测打开了滑动作为一个气候的过程的时代；**Anandakrishnan**、**Ian Joughin**与同事的2000年代的潮的调制的反演把潮变成滑动的定律的实验室、卫星的重力与测高现在近实时地追踪床的周期——它的1994年的Kamb冰的流的停止。
:::

一个它的下的水的压上升向冰的覆盖的压的冰川：

::: summary
- 冰川的滑动是由有效的压N = 冰的覆盖的压−水的压控制的复冰的摩擦；Weertman的定律u ∝ τ³/N使速度对应力的三次、对水的双曲的。
- 季节的水文学的年——春季的加速、渠道化的变慢、秋季的停止——在格陵兰测量、连接表面的融化、冰的排放的机制。
- 许多的床是软的：碛的变形在沉积富水的地方携带运动的许多、以膨胀自我限制；硬的床的滑动支配最快的冰川。
- 的下的排水在高的压的分散的膜（快的冰）、低的压的渠道（稳定的冰）之间切换；它的失败是冰的洪水、由Shreve的融化的管道的理论预测。
- 床给冰川周期：脉动、1994年的Kamb冰的流的停止与它的同类、季节的加速、潮的调制——滑动的物理的最干净的自然的实验。
- 床的水是冰川的神经的系统：最快的冰的未来主要是一个它的水文的预报。
:::

## 练习题

::: exercise 有效的压 {level=1 check="83"}
一个$400\ \mathrm{m}$厚的冰坐在一个水位高于床$350\ \mathrm{m}$的水之上。求以kPa的$N$（$\rho_i = 917$、$\rho_w = 1025\ \mathrm{kg\,m^{-3}}$）。
::: solution
$N = 917\times9.81\times400 - 1025\times9.81\times350 = 3.60\times10^{6} - 3.52\times10^{6} = 83\ \mathrm{kPa}$——干的床的值的十分之一。冰川在它的漂浮的阈值附近、以一个小于一个单一的基岩的丘的应力的集中的余量抓住：这是大多数的快的流动的、海洋的末端的冰川的大部分的时间的状态。
:::

::: exercise 冬季的变慢 {level=1 check="4"}
以$u_b \propto N^{-1}$、求从冬季（$N = 400\ \mathrm{kPa}$）到夏季的峰值（$N = 100\ \mathrm{kPa}$）的加速的因子。
::: solution
$400/100 = 4$。格陵兰的边缘观察的二的倍到五的倍的季节的振幅是这个算术；年的**均值**对海平面重要的理由是$\tau$的三次、$N$的非线性——一个每年花一个月在它的冬季的速度四的倍的冰川贡献它的年的排放的一个不成比例的份额、所以融化的季节的长度是一个阶的控制、不是一个细节。
:::

::: exercise 冰的洪水的平均的流量 {level=1 check="1160"}
$3\ \mathrm{km^{3}}$在$30$天排干。求以$\mathrm{m^{3}\,s^{-1}}$到最接近的十的平均的流量。
::: solution
$3\times10^{9}/2.59\times10^{6} = 1160\ \mathrm{m^{3}\,s^{-1}}$——一个莱茵的标度的河流持续一个月、通过一个最初几米宽的管道输送。均值是最不有趣的数：冰的洪水的峰值是均值的20–50的倍、移动巨石、桥与危险的曲线的峰值。
:::

::: exercise 漂浮的阈值 {level=2 check="358"}
对上面的$400\ \mathrm{m}$厚的冰川、求冰漂浮（$N = 0$）的水的位（米、到最接近的米）。
::: solution
$h_w = \rho_i H/\rho_w = 917\times400/1025 = 358\ \mathrm{m}$。八米的额外的水位——在集水区每天几厘米的表面的融化——使床从"抓住"切换到"漂浮"、这就是为什么漂浮的判据、任何摩擦的定律、滑动的物理的硬的极限、接地的带的钉住的点（冰在一个的脊上着地的地方）是南极的边缘的承重的结构。
:::

::: exercise 碛的应变的速率 {level=2 check="40"}
一个$1\ \mathrm{m}$厚的碛的层携带$40\ \mathrm{m\,yr^{-1}}$的变形。求以$\mathrm{yr^{-1}}$的平均的应变的速率。
::: solution
$\dot\gamma = 40/1 = 40\ \mathrm{yr^{-1}}$。在快的冰之下的下的碛以没有一个实验室能持续维持的速率剪——这就是为什么它们的强度用钻孔的探针原位测量、"冰川的速度的土壤的力学"仍然是一个实验的前沿。

::: exercise 潮的指数 {level=2 check="0.7"}
滑动的速度变化20百分之一、有效的压在一个潮变化30百分之一。估计$u \propto N^{-l}$的滑动的定律的指数$l$。
::: solution
$l = \ln(1.2)/\ln(1.3) = 0.18/0.26 = 0.7$。跨过格陵兰与南极的潮的调制的析一致地给出$l \sim 0.5$–$1.5$、$m \sim 1$–$3$：潮是底的滑动的唯一的**已知的、周期的、大陆的标度的强迫**、这些反演是滑动的定律有的现场的一个实验室的验证的最接近的东西。
:::

::: exercise 滑动的定律的粗糙的项 {level=3 check="16"}
在Weertman的标准的复冰的滑动的定律、$u_b = E\,\tau^{3}\lambda^{4}/N$、以$E$冰的软、$\lambda$床的丘的波长。若一个冰川的床在一个同样的应力与水的压从$\lambda = 0.2\ \mathrm{m}$的丘变粗到$\lambda = 0.4\ \mathrm{m}$、滑动以什么的因子改变？
::: solution
$u_b \propto \lambda^{4}$：因子是$2^{4} = 16$。的波长的依赖是定律的最不检验的、最重要的项——它说滑动由复冰的机器能协商的**最大的**丘控制、这就是为什么碛覆盖的床（没有硬的丘）以变形代替滑动、为什么的羊背石的场设定冰川的速度、为什么定律的指数在应用在不同粗糙的谱的床时散布。
:::

::: exercise Kamb的停止 {level=3 check="50"}
Kamb冰的流在1994年停止之前在$500\ \mathrm{m\,yr^{-1}}$流动；它的集水区积累现在在$100\ \mathrm{km}$的长度以$0.8\ \mathrm{m\,yr^{-1}}$使停滞的河段变厚。估计重建一个$40\ \mathrm{m}$的厚度的多余以重新开始快的流动需要的时间、以年、解释为什么答案不确定的十的倍。
::: solution
以观察的速率$40/0.8 = 50$年的变厚。不确定是十的倍、因为重新开始的判据不是厚度、**底的水的压**：重新激活要求碛再饱和、它依赖曾经喂养那个流的水的融的水现在去哪里（它观察缓慢地泄漏进邻的集水区）、脱水的碛将再变软、不可逆地固结。停止是这个学科的一个状态变量的常设的课：南极的流"在开"的哪些的5百分的改变移动海平面的预算比十年的表面的融化更多、没有一个平滑的模型包含那个开关。
:::
