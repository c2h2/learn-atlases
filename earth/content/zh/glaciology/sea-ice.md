在1898年的冬季、的别尔卡号——第一艘在南极的水域过冬的船、比任何人计划的早一年——躺在南极半岛外的冰里钉住、它的船员坏血病、疯狂的目、年轻的考察的医生**弗雷德里克·库克**、大副**罗尔德·阿蒙森**、记录冰的每一种情绪：在夜间带着步枪的爆裂的报告行走的压力脊、像承诺打开的冰的裂、他们下面的浮冰不是一个地板、一个在他们不能测量的深度的之上的筏。五万张卫星的图像之后、笔记读作地球上变化最快的生态系统的现场的协议。海冰同时是气候的系统的镜子、它的盖子——反射北极的夏季的一半的太阳、使海洋与比它自己冷$30\ ^\circ\mathrm{C}$的空气绝缘、制造通风世界的深渊的咸的稠密的水、在毫米宽的盐卤通道 孕育着极地海洋最有生产力的栖息地。它也是的冰冻圈的组成部分、它的下降最快、测量最好、预报最接近平坦：北极的9月的冰的覆盖自卫星的时代开始失去它的面积的三分之一、第一个无冰的北极的夏季现在是一个十年、不是世纪的问题。

## 从顶生长、从下面死的冰

::: definition 一个结冰的海洋的热力学 {#def-ice-thermo}
海冰在海洋的表面比混合的层能替换它更快地失去热的地方形成——在**海水的冰点**、在35 psu的$-1.9\ ^\circ\mathrm{C}$、每一个大气的压进一步降低$0.075\ ^\circ\mathrm{C}$（这就是为什么深的威德尔的海只在它的表层几百米冷之后结冰）。生长是**自上而下的、传导限制的**：冰是一个体面的绝缘的（$k = 2.1\ \mathrm{W\,m^{-1}\,K^{-1}}$、海水的五分之一）、所以逃离海洋的热必须跨过已经存在的冰、生长的速率以厚度的反比落下——**斯特藩定律**（1889、在物理理解之前从南极的船的数据推导）、
$
h \approx \left(\frac{2\, k\, \Delta T\, t}{\rho L}\right)^{1/2}, \qquad \rho L = 3.06\times10^{8}\ \mathrm{J\,m^{-3}},
$
给出$1\ \mathrm{m}$的冰在约四个月$-10\ ^\circ\mathrm{C}$、显示为什么**北极的90百分之一的冰在晚冬薄于$1\ \mathrm{m}$**、在冰的裂与的雪冰支配的地方、为什么使最终的厚度加倍需要使冷四的倍。三个复杂定义真实的冰。**冰的裂**——暴露开放的水的断裂——从下面使的群暖、局部辐射$300\ \mathrm{W\,m^{-2}}$、在几天结冰、以一些预算产生北极的冬季的冰的一半。**的雪冰**：当雪的重量使薄的冰在水位之下降低、海水淹没雪、就地结冰——南极的群的厚度的三分之一是雪的冰、对假设冰从空气生长的厚度的传感器不可见的。**盐卤**：结冰把盐排入盐度60–100 psu的盐卤米尺度通道、它们排水、冻结、留下第一年的冰在一个夏季之后的5–10 psu——使冰、它的融的水、它下面的**的盐跃层**成为极地的海洋的一个永久的分层的特征的脱盐。
:::

::: example 斯特藩的算术 {#ex-stefan}
在一个恒定的$-15\ ^\circ\mathrm{C}$的空气的温度在一个忽略雪的覆盖的冰之上、生长（a）$0.5\ \mathrm{m}$、（b）$2\ \mathrm{m}$的冰需要多长时间？为什么真实的北极的群在3月平均$1.3\ \mathrm{m}$、斯特藩的定律在一个开放的水的允许$3\ \mathrm{m}$？
::: solution
从$h = \sqrt{2k\Delta T\, t/\rho L}$、$\Delta T = 15$：$t = h^{2}\rho L/(2k\Delta T)$、所以
$
t(0.5) = \frac{0.25\times3.06\times10^{8}}{63} = 1.2\times10^{6}\ \mathrm{s} \approx 14\ \mathrm{天}, \qquad t(2) = 16\,t(0.5) \approx 225\ \mathrm{天}.
$
标度是答案：$t \propto h^{2}$、所以第二个半米花费第一个的十五的倍。真实的冰低于开放的水的理想、因为冰自己的顶使它绝缘——一个$5\ \mathrm{cm}$的雪的覆盖使生长的速率减半——因为冰的裂再冻结、不是变厚、因为秋季的海洋必须先卸下它的夏季的热。现代的3月的群的$1.3\ \mathrm{m}$的均值因此不是一个热力学的极限、一个**气候的状态**：在1950年代的潜艇的时代接近$3\ \mathrm{m}$、差别是整个北极的记录的最暖的、最可读的线。
:::
:::

caption: 在$-15\ ^\circ\mathrm{C}$的$240$天之上的斯特藩定律的冰的生长——使冰成为一个自我限制的毯子的平方根的曲线：在秋季快、在春季几乎停止。同样的平方根支配第一年的冰的季节的融化、冰的裂的再冻结、这就是为什么一个更暖的、更晚结冰的北极不只生长更薄的冰、**重新开始季节**：薄的冰绝缘得差、对冷的突然响应快地生长、然而秋季的海洋的更大的热的储存——从夏季的开放的水——延迟结冰比冷能偿还的更多。
:::

## 撤退

::: definition 卫星的记录 {#def-retreat}
自1979年、无源的微波的辐射测量在云、黑暗之中绘制海冰的浓度的地图、数存在的最干净的大标度的气候的观察。**9月的最低**——北极的每年的忏悔——从1979–80的约$7.0\times10^{6}\ \mathrm{km^{2}}$落到2012的记录$4.72\times10^{6}$、以每十年$-12.2$的三分之一的损失、带最低的十二个最低全部发生在2010之后；3月的范围以更慢的速度落下（每十年$-5$百分之一）、因为冬季的结冰是冷的限制的、不是冰的限制的。厚度讲述更深的故事：1950年代–90年代的潜艇的测深、ICESat（2003–09）、CryoSat-2（2010–）的雷达的测高显示**北冰洋的群的3月的平均的厚度从约$3.1\ \mathrm{m}$落到$2.3\ \mathrm{m}$**、带的多年的冰——老的、变形的、厚的冰、曾经填满的加拿大的盆——撤退到格陵兰与的埃尔斯米尔的北的一个薄的带、它的群的份额从约三分之一落到十分之一之下。损失的几何是机制的：第一年的冰在秋季形成、在夏季融化、只通过骑反气旋的波福特的环流足够长以变厚存活——**的跨极的漂流**现在以在一些冬季超过替换的供应的速率把冰从的弗拉姆的海峡出口。南大洋、长期的一个轻微的**增加**的例外的（风的驱动的、热的隔离的南大洋）、在2016加入撤退、带通过2023的三个连续的记录的最低、一个制度的改变、它的原因——的下的热向上释放、风的十年的摆动、两者——是这个学科移动最快的问题。
:::

::: example 一个失去的夏季的面积的预算 {#ex-areabudget}
取1980年代的9月的最低$7.0\times10^{6}\ \mathrm{km^{2}}$、2012的$4.72\times10^{6}$。把损失转换成（a）百分之一、（b）额外的开放的水吸收的额外的夏季的太阳能（冰的反照率$0.6$、海洋$0.06$；平均的夏季的日射在90天$180\ \mathrm{W\,m^{-2}}$）、与世界的海洋的年的初级的生产能量（$\sim 4\times10^{19}\ \mathrm{J}$）比较。
::: solution
损失是$2.28\times10^{6}\ \mathrm{km^{2}}$、1980年代的最低的$33$百分之一。每平方米的额外的吸收是$(0.60 - 0.06)\times180 = 97\ \mathrm{W\,m^{-2}}$、所以在失去的面积与季节
$
E = 97\times2.28\times10^{12}\times7.8\times10^{6} = 1.7\times10^{21}\ \mathrm{J},
$
世界的所有植物在一年固定的能量的四十的倍、作为**北极的夏季的海洋的热**沉积——它延迟下一个秋季的结冰、加热进入的大西洋的水、通过薄的冬季的冰渗透进大气。那个闭环、海洋的热的第一、不是空气的第一、是**大西洋-北极的放大**的机制在一个计算、它解释为什么北极的变暖（全球的均值的约$3$–$4$的倍）超过全球的平均的强迫单独将产生的任何。
:::
:::

## 为什么北极是行星的快车道

::: definition 北极的放大 {#def-amplification}
北极比地球快三到四的倍变暖、那个事实的分解比它的加权更确定。**表面的反照率的反馈**：融化暴露海洋、海洋吸收、更多的融化——在冬季、夏季都最强的单一的项、现在以**变暗**放大（的烟灰、尘、在冰与雪上的开花的雪衣藻的藻的红雪）。**的直减率与云的反馈**：北极的稳定的分层使变暖集中在表面附近、2014年重新加权这个学科发现（**皮坦与毛里森**）——地球的最清楚的云的反馈在这里操作：当海冰撤退、秋季的大气在一个无冰的、更湿的天空之下向表面发射更多的长波、恰在结冰必须开始的时候加热边界层。**海洋的热的储存、大西洋的水的层**：帽住加拿大的盆的暖的下的亚特兰大的层正在以风暴与的涡向上侵蚀、在秋季以几十的$\mathrm{W\,m^{-2}}$把热输送到冰的底面。**归因**：放大是**强迫的**——它出现在每个带观察的温室的气体的模型运行、在模型与观察与冰的损失自己相关——但它的**步调**部分内部的：最近的大西洋的经向的环流的减慢、太平洋的十年的模式以十年的任一个方向调节速率。预报的后果是本世纪的最直接的：在高的排放之下、模型把第一个9月的**无冰**的状态（惯例在$10^{6}\ \mathrm{km^{2}}$之下）放在2040年代附近、本世纪其余的一个实际的无冰的9月；在深度的减少之下、2013–2022的冰的状态大致可稳定——北极的未来、在伟大的气候的变量之中唯一的、仍然是一个带一个可见的截止的日期的政策的选择。
:::

::: example 盖子与它持有的热 {#ex-lid}
冬季的北冰洋在表面$-1.9\ ^\circ\mathrm{C}$、它上面的空气在1月平均$-25\ ^\circ\mathrm{C}$。以$1.3\ \mathrm{m}$的冰（$k = 2.1$）、求向上的热的通量、解释为什么通过**冰的裂**（2百分之一的面积、开放的水）的同样的通量支配群的冬季的热预算。
::: solution
通过固体的冰传导的通量是$k\Delta T/h = 2.1\times23.1/1.3 = 37\ \mathrm{W\,m^{-2}}$——冰的稳定的泄漏。但在一个冰的裂的开放的水以湍流与辐射以$300\ \mathrm{W\,m^{-2}}$或更多失去热、所以只覆盖2百分之一的面积的冰的裂返回$0.02\times300 = 6\ \mathrm{W\,m^{-2}}$、固体的冰的通量的六分之一、从二百分之一的面积——重要的、集中在**秋季的结冰**、海洋的夏季的热必须逃离的时候。盖子的隐喻因此是精确的：海冰不止海洋的热损失、它**安排它的日程**、使盖子变薄把日程移动得更早、更晚、更大——北极的秋季的变暖、现在超过每十年$0.5\ ^\circ\mathrm{C}$的在无冰的巴伦支的区域之上的冬季的表面的空气的变暖、正在测量的。
:::
:::

## 作为栖息地与的咸的制造者的冰

::: definition 盐卤的生态与的盐跃层 {#def-ecology-salt}
海冰不是冻结的海水、一个**几何的海绵**：当冰生长、盐卤排入一个厘米的尺度的通道的网络——盐度60–100 psu、温度到$-10\ ^\circ\mathrm{C}$——生命跟随盐卤。**的冰的藻**沿着光仍然到达的下部的通道、在冰的**之下**产生春季的藻华、在开放的水的藻华之前几周、在每升高到$10^{8}$的细胞的密度；整个的冰下的群落——的硅藻、的纤毛虫、的鞭毛虫、啃食冰的粘的底面的桡足类与的磷虾——与它定时、在高北极与南大洋的群、这个盐卤的群落的产生是**食物的网的开始**：冰的藻的碳在一个季节之后的北极的桡足类的脂质、年轻的北极鳕鱼的状况、海鸟的雏鸟的身体的状况、吃南极的磷虾的鲸的奶中发现。物理-生态的耦合是残酷的：更早的融化把藻华推得更早、与的浮游的动物的繁殖不同步——**匹配-不匹配**、与陆地同样的机制、带一个硬的物理的截止的日期、因为冰自己是栖息地。在物理的一边、结冰的**盐的通量**是一个气候的行动者：形成第一年的冰的一平方米拒绝约$30\ \mathrm{kg}$的盐、在沿海的**冰的穴**——风的冲刷的无冰的港、像罗斯海与的威德尔海的冰的穴、的东南极的丹尼尔角区域、的鄂霍次克海的大的开放的区域——这个冷的、咸的、稠密的水的生产喂养**南极的底的水**、它填满世界的深渊、通风它存储的碳。1970年代的威德尔海的冰的穴——一个$10^{6}\ \mathrm{km^{2}}$的开放的洞、出现三次、然后关闭三十年——在2017重新打开、自那时重复、那是一个风的制度的摆动、盐跃层在变暖之下变薄、关于南大洋的碳的汇的两个或三个最重要的开放的问题之一。
:::

::: example 盐、冰与底的水 {#ex-saltflux}
一个沿海的冰的穴在一个冬季在$20{,}000\ \mathrm{km^{2}}$之上产生$1.5\ \mathrm{m}$的新的冰。求以$\mathrm{kg\,s^{-1}}$计的盐通量（取每米的冰$30\ \mathrm{kg}$、四个月的冬季）、它暗示的稠密的水的生产、若的羽流在一个$0.5\ \mathrm{psu}$的盐度异常对着环境的$34.3\ \mathrm{psu}$的水（$\rho = 1027\ \mathrm{kg\,m^{-3}}$）平衡。
::: solution
盐$= 1.5\times30\times2\times10^{10} = 9\times10^{11}\ \mathrm{kg}$、在季节、一个平均的通量$9\times10^{11}/1.04\times10^{7} = 8.7\times10^{4}\ \mathrm{kg\,s^{-1}}$。以千分之$0.5$携带那个盐意味着移动$9\times10^{11}/(0.0005\times1027) = 1.8\times10^{12}\ \mathrm{kg}$的水、即一个稠密的水的生产
$
Q = \frac{1.8\times10^{12}}{1.04\times10^{7}} = 1.7\times10^{5}\ \mathrm{kg\,s^{-1}} \approx 0.17\ \mathrm{Sv},
$
从一个冰的穴的全球的南极的底的水的通量的几百分之一。在南极的沿海的冰的穴的系统相乘——一打的这个大小——海冰的工厂显然是一个深渊的通气的**主要的贡献者**：这就是为什么最近的底的水的变淡与变暖、自2010年代观察、与一个变弱的盐的工厂一致、当作整个的环流的未来的一个哨兵处理。
:::
:::

::: warning "无冰"不是标题说的、臭氧的洞不是冰离开的原因、南大洋不是北极的学生
五个错误。**"无冰"是一个惯例**（在9月的100万平方公里之下）——它不意味着在极点的开放的水、第一个这样的年仍然在的林肯的海有米厚的多年的冰的遗物；反之地、一旦跨过它将**几个月夏季无冰**、对航运、甲烷、熊重要的状态。**臭氧的洞没有冷却任何重要的**：它的风的效应（一个正的SAM的趋势）*掩盖*一些西南极与半岛的变暖——的蒙特利尔的议定书的臭氧的恢复预报**揭开**它、一个值得陈述、不是隐藏的诚实的讽刺。**南大洋的下降不是北极式的热力学**：直到2016它的范围几乎不趋势、它的**厚度、年龄的结构、生态**改变——系统是风的、热的输送支配的、2016–2023的最低可能是一个制度的摆动、十年的摆动；诚实的立场是带一个截止的日期的不确定性（下一个十年的观察将告诉）。**海冰的损失不停止的墨西哥湾的流**——那个主张混淆盐跃层的变淡（真实的、可测量的、在亚极地的北大西洋的深的混合的一个稳定的帽子）与AMOC的崩溃（一个单独的、更深的、更慢的机制）；两者连接、句子"北极融化因为墨西哥湾的流将停止"不是科学。**生态的文献的"北极的变褐"不是推测**：更早的冰的离开把生产从大的富脂的冰关联的硅藻转移到小的开放的水的浮游的植物、一个鳕鱼、一个雏鸟、一个的弓头鲸的幼崽能用的能量可测量地更低——冰的损失的食物的网的后果是最少标题、最多的引用的气候的影响。
:::

::: history
**约瑟夫·斯特藩**在1889年从奥匈的波拉考察的南极的测深推导传导的冰的生长定律——从船的数据的理论、在物理一般之前几十年——**南森**的福姆号的漂流（1893–96）证明冰自己一个移动的流体的介质、从的漂流的日志绘制跨极的流。潜艇的时代（1940年代–90年代）设定厚度的基线、**赫尔曼·梅林**与同事的冬季的系泊第一次直接测量底的生长、海洋的热的通量；**SHEBA**的计划（1997–98）、在波福特的冰冻住一艘船一年、重写北极的能量预算、**MOSAiC**（2019–20、的极地的船在北极的中部的年——历史的最大的极地的考察）是它的气候的时代的学生。卫星的记录以**SMMR**（1978）、**SSM/I**（1987）开始：**约瑟菲娜·科米索**的析记录多年的冰的崩溃、**朱利安娜·斯特罗埃夫**的2007年的论文第一次把一个无冰的北极放在预报的视野之内、**罗纳德·关**的测高的图集在ICESat（2003–09）、CryoSat-2（2010–）、ICESat-2（2018）追踪变薄、挪威的**N-ICE**、英国的冰下的计划继续剩余的老的冰之下的物理。
:::

冰-反照率的反馈的气候的背景在[[climate-system/feedbacks-sensitivity]]与[[climate-system/energy-budget]]、海洋的混合的层与盐跃层的物理在[[oceanography/seawater]]与[[oceanography/overturning]]、海冰对海平面的贡献（零、为什么）在[[oceanography/sea-level]]、北极的放大的归因在[[climate-change/attribution]]与[[climate-change/observed-change]]、失去的冰暴露给风暴的永久冻土的海岸线在[[glaciology/permafrost]]、观察在[[glaciology/observing-ice]]与[[remote-sensing/radar-lidar]]。

::: quiz
斯特藩的定律说冰的厚度以$\sqrt{t}$生长因为：
- [ ] 空气的温度随着冬季进行下降。
- [x] 现有的冰使它绝缘、所以热的通量——生长的速率——以$1/h$落下。
- [ ] 海洋的热的储存用完。
- [ ] 雪的覆盖变厚。
::: solution
生长必须把海洋的热**通过已经生长的冰**传导：通量$= k\Delta T/h$、所以$dh/dt \propto 1/h$、$h \propto \sqrt{t}$。自我限制的毯子是为什么薄的冰对冷的突然响应快地响应、为什么冰的裂在几天再冻结、为什么北极的冬季的冰不能简单地"赶上"——它建造的盖子是减慢它自己的制造的盖子。
:::
:::

::: summary
- 海冰自上而下生长、传导限制的（斯特藩定律、$h \propto \sqrt{t}$）、带冰的裂与的雪冰供应许多的真实的生长、盐卤的排出设定它的盐度与它的生态。
- 卫星的记录：北极的9月的范围自1979下降三分之一（每十年$-12\%$）、3月的厚度从约3.1落到约2.3米、多年的冰几乎从大西洋的一边的盆消失；2016以来的南大洋的制度的改变。
- 北极的放大（全球的变暖的3–4的倍）强迫、分解：反照率、秋季的云与长波、海洋的热的储存、侵蚀的亚特兰大的层；高的路径的第一个无冰的9月约2040年代。
- 冰是北极的盖子、海洋的热损失的日程的保持者；变薄把通量的日程向秋季重新安排、驱动行星的最快的冬季的变暖。
- 盐卤通道孕育着定时极地的食物的网的冰下的藻的藻华；冰的穴盐通量喂养南极的底的水——冰是一个生态系统、一个深渊的通气的工厂。
- 撤退是冰冻圈的最清楚的强迫的信号、它的终态仍然开放的少数之一：北极的夏季是本世纪的最可读的政策的成绩单。
:::

## 练习题

::: exercise 斯特藩的生长时间 {level=1 check="84"}
在一个恒定的$-10\ ^\circ\mathrm{C}$（$k = 2.1$、$\rho L = 3.06\times10^{8}$）、求生长$1\ \mathrm{m}$的冰需要的天、到最接近的天。
::: solution
$t = \rho L h^{2}/(2k\Delta T) = 3.06\times10^{8}/42 = 7.3\times10^{6}\ \mathrm{s} = 84$天。第一个米的十二周的$-10\ ^\circ\mathrm{C}$——这就是为什么一个晚的结冰使季节的冰付出二的倍：更少的时间生长、当冷最终来临时更薄的冰以绝缘。
:::
:::

::: exercise 面积的损失 {level=1 check="33"}
9月的范围从$7.0$落到$4.72\times10^{6}\ \mathrm{km^{2}}$。求以百分之一到最接近的整数的百分比的损失。
::: solution
$(7.0 - 4.72)/7.0 = 33$百分之一——一个比法国与西班牙合起来大的面积、在一个人类的一代之内从夏季的北极消失、在有史以来拍摄最多的卫星的产品。
:::
:::

::: exercise 反照率的能量 {level=1 check="97"}
以冰的反照率$0.6$、海洋$0.06$、求在开放的水的额外的吸收的通量（$\mathrm{W\,m^{-2}}$）、在$180\ \mathrm{W\,m^{-2}}$的平均的夏季的日射。
::: solution
$(0.60 - 0.06)\times180 = 97\ \mathrm{W\,m^{-2}}$——一个比任何城市的废热的通量大的辐射的强迫、恰在冰的缺席让它做最多的工作的地方输送：进入必须在秋季再冻结的混合的层。
:::
:::

::: exercise 盐的排出 {level=2 check="31"}
形成$1\ \mathrm{m^{2}}$的第一年的冰（在一个$35\ \mathrm{psu}$的水的$5\ \mathrm{psu}$的冰的盐度、冰的密度$917\ \mathrm{kg\,m^{-3}}$）拒绝多少kg的盐？
::: solution
冰保留在母亲的水的$0.035\times1025\times1 \approx 35.9\ \mathrm{kg}$的$0.005\times917 = 4.6\ \mathrm{kg}$、拒绝$31\ \mathrm{kg\,m^{-2}}$。那个盐、作为稠密的羽流带入陆架的边界流、是底的水的形成的货币——一个冰的穴的地图对物理的海洋学家是世界深的海洋的泵的地图的理由。
:::
:::

::: exercise 冰的裂的比例 {level=2 check="6"}
冰的裂覆盖冬季的群的2百分之一、失去$300\ \mathrm{W\,m^{-2}}$。求以$\mathrm{W\,m^{-2}}$的面积的平均的通量。
::: solution
$0.02\times300 = 6\ \mathrm{W\,m^{-2}}$——从二百分之一的面积的固体的冰的泄漏的五分之一、冰的裂的参数化（不是冰的厚度单独）在每个海冰的模型设定秋季的热损失的定时的理由。
:::
:::

::: exercise 无冰的外推 {level=2 check="47"}
若9月的范围从$4.7\times10^{6}\ \mathrm{km^{2}}$（2012）以$-80{,}000\ \mathrm{km^{2}\,yr^{-1}}$线性地落下、求它跨过$1.0\times10^{6}$（"无冰"的阈值）的年。
::: solution
$(4.7 - 1.0)\times10^{6}/8\times10^{4} = 46$年→$2012 + 46 \approx 2058$、即约**2060**。诚实的警告：一个非线性的过程的线性的外推在、下超过（剩余的冰是厚的、北的、难融化的种类、它论证晚；秋季的海洋的热与反照率的反馈论证早）、模型的中介在高的排放之下聚集2045–2060——线性的数是一个清醒的锚、不是一个预报。
:::
:::

::: exercise 平方根的定律 {level=3 check="4"}
在斯特藩的定律之下、从$1\ \mathrm{m}$到$2\ \mathrm{m}$生长冰的时间以什么的因子增加？
::: solution
$t \propto h^{2}$：一个因子$4$。二次的是为什么群的**年龄的结构**比它的面积重要：把第一年的冰转换成多年的冰花费冬季的四的倍、一个失去它的老的冰的系统不能通过只有一个冷的一年重建厚度——2013与2014的"恢复"的年、恢复面积、不恢复年龄、自然的实验。
:::
:::

::: exercise 盐跃层的记忆 {level=3 check="36"}
加拿大的盆的盐跃层（在一个$50\ \mathrm{m}$的层$5\ \mathrm{psu}$的盐度异常）由海冰的盐卤、河的径流维持。若有效的淡的水的供应是每平方米$0.2\ \mathrm{m\,yr^{-1}}$、求更新盐跃层的淡的水的内容需要的年、到最接近的年。
::: solution
淡的水的内容是每平方米$(5/35)\times50 = 7.1\ \mathrm{m}$的淡的水；以$0.2\ \mathrm{m\,yr^{-1}}$更新需要$7.1/0.2 = 36$年。盐跃层因此是一个**十年的记忆**的特征：它在1990年代–2000年代以更多的冰的融化与河的输入变厚、然后在2010年代作为冰的出口落下变薄——一个淡的水的电容器、它的充电状态决定多少风暴的混合能把海洋的热输送到冰、它的36年的更新时间是为什么"盐跃层将恢复若冰恢复"是一个几十年的陈述、不是一个年的一。
:::
:::
