在1841年、博物学家**Louis Agassiz**——还没有出名、已经固执——在的伯尔尼的阿尔卑斯的Unteraar冰川建造了一个的石的、的灰浆的小屋、部分作为实验室、部分以解决一个争论。在几个月之内小屋沿着它的灰浆的线裂开；在两年之内它的基础向下游走了足够远、争论结束了：冰在移动、作为一个整体移动、在中间与表面比在边缘与床更快、恰像一个粘的流体会做的。Agassiz的小屋是冰川的物理的创始的实验、自从的一切是它的教训的精确化——冰、一个在室温比你的刀更硬的矿物、在冰川的温度像厚的蜂蜜流动——流动、不是融化、把冰期排入海洋。那个流动的定量的定律、在小屋一个世纪之后在实验室测量、足够简单地写在一个明信片上、足够地重要以设定南极的高原的高度、的Jakobshavn的速度、锁在地球上的每个冰盖里的世纪的承诺。

## 作为材料的冰：Glen的流动定律

::: proposition Glen的流动定律 {#prop-glen}
冰川的冰是一个**非牛顿的流体**、它的应变的速率由一个幂的定律依赖应力。在自1960年代的每个冰盖的模型使用的形式（**Glen的流动定律**、1955），
$$
\dot{\epsilon} = A\,\tau^{n}, \qquad n \approx 3 ,
$$
联系偏的应变的速率$\dot\epsilon$（$\mathrm{s^{-1}}$）、偏的剪的应力$\tau$（Pa）、流动的参数$A$通过一个的阿伦尼乌斯的因子由温度设定——在的压力的融点附近的暖的冰比$-30\ ^\circ\mathrm{C}$的冰流动容易约**十的倍**、冰盖的动力学里最重要的单一的材料的事实。指数$n = 3$（在一个的钻孔、在试验的岩心、南极的站的钻孔的倾斜的记录测量）使冰**剪的变薄**：应力的加倍使应变的速率八的倍、所以驱动应力或温度的一个小的改变产生速度的一个大的改变——谷的冰川的响应性、冰的流的令人恐惧的不稳定的数学的根。定律是一个**蠕变**的定律、不是一个的断裂的定律：在顶部的$30$–$50\ \mathrm{m}$冰是冷的、的围压的、**脆的**、作为裂隙失效、不是流动、这就是为什么一个冰川的表面是一个破裂的筏、漂浮在它自己的慢的变形之上、为什么一个冰川的应变的速率的场能从它的裂缝的图案读出。
:::

::: example 冰变形得多快？ {#ex-strain}
取$A = 2.4\times10^{-24}\ \mathrm{Pa^{-3}\,s^{-1}}$、一个$100\ \mathrm{kPa}$的驱动剪的应力——一个谷的冰川的上半的典型。求以$\mathrm{yr^{-1}}$的表面的应变的速率、$200\ \mathrm{m}$的冰的深度的平均的变形的速度（对$n = 3$、平均的变形的速度是表面的速度的$2/(n+2) = 0.4$倍）。
::: solution
$$
\dot\epsilon = 2.4\times10^{-24}\times(10^{5})^{3} = 2.4\times10^{-9}\ \mathrm{s^{-1}} = 0.076\ \mathrm{yr^{-1}} .
$$
对一个没有滑动的变形的剖面、表面的速度是$u_s = 2\dot\epsilon H/(n+1) = 0.5\times0.076\times200 = 7.6\ \mathrm{m\,yr^{-1}}$、深度的均值的速度$2\dot\epsilon H/(n+2) = 6.1\ \mathrm{m\,yr^{-1}}$。观察的谷的冰川在表面每年移动几十米、所以超过纯的变形的多余——常常是总的一半——归因于滑动（下一个课）。练习的真正的信息是**的量级**：一个十分之一兆帕的应力——一个温和的冰的柱在一个温和的坡上的重量——足以使"固体的"岩石以一个人类可观察的速度流动、给几个世纪。
:::
:::

## 由坡驱动：驱动应力与冰盖的形状

::: definition 驱动应力 {#def-driving}
冰的流动的引擎是重力作用在表面的坡度：**驱动应力**
$$
\tau_d = \rho\, g\, H \sin\alpha
$$
一个厚度$H$、在一个坡$\alpha$的冰的柱要求的底的剪的应力、它非常**均匀**——地球上的几乎每个冰川与冰盖$50$–$150\ \mathrm{kPa}$、因为冰的质量自我组织：在坡（由此应力）超过冰能携带的地方、冰以更快的流动变薄；在它不足的地方、冰变厚、坡重建。这个"的屈服应力的"的行为是大的冰盖不是的锥、**浅的透镜**的理由——坡$0.001$–$0.01$、厚度几公里——它们的稳定的形状从Glen的定律单独随之的理由：**的通量的发散（Vialov）的剖面**给出一个冰盖的表面以$\xi^{4/7}$从边缘向的分水岭上升（对$n = 3$）、一个钝的、平的顶的穹顶、它对南极与格陵兰的观察的匹配在1950年代是冰盖是可变形的身体、不是床上的漂浮的筏的第一个证明。的推论是驱动世纪的冰盖的模型的**的浅的冰的近似**：因为坡是微小的、垂直的与水平的应力脱钩、整个的冰盖能通过平衡积累对着$\tau_d$驱动的通量以时间推进——物理光荣地简化为一个应力的定律、记账。
:::

::: widget plot
f: 3000*(1-x)^0.57

labels: h\ (\mathrm{m})
caption: $n = 3$的Vialov的通量的发散的剖面——表面的高度对从的分水岭的距离、归一化——一个钝的穹顶以$\xi^{4/7}$从一个零的厚度的边缘上升。真实的冰盖是这个形状的块的改正（床的山、的流的出口、海洋的床），但理想的剖面对南极与格陵兰的观察的剖面的阶的匹配是理论的冰川学的创始的成功：一个冰盖的形状是写在冰里的Glen的定律。
:::

## 冰去哪里快：变形、滑动与冰的流

::: definition 速度的预算 {#def-velocity-budget}
一个冰川的表面速度是**内部的变形**（Glen的定律在柱上积分、在表面最大、在一个冻结的床为零）、**底的滑动**（整个的柱骑在它的床上、在[[glaciology/basal-sliding]]讨论）的和。的比定义冰川的性格：冷的底的阿尔卑斯的冰川几乎是纯的变形；温带的冰川为它的速度的三分之一到一半滑动；南极与格陵兰的**冰的流**——几十公里宽、几百米厚、以$400$–$2000\ \mathrm{m\,yr^{-1}}$流动、喂养它们的冰的十到五十的倍的渠道——滑动支配到它们的内部根本不变形的程度。冰的流占据的软的沉积的**海洋的床**、它们的存在重新组织了冰盖的科学：1990年代的卫星的速度地图（南极的排水的系统的第一个InSAR导出的速度的地图）揭示90百分之一的到达海洋的南极的冰通过这百分之几的海岸线到达、由暖的底的、水的润滑的、的脉的走廊引导、它的边缘——**的剪的边缘**、几米的强烈的应变、举起几公里深的裂谷、由它产生的摩擦的热变暖——是行星上最壮观的应变的特征。冰的流是冰盖的释放的阀：它的速度由床、水、的架的支持、不是由表面的坡设定、由此是海洋的变暖变成冰盖的质量的损失的途径、在表面没有单一的额外的一度的空气的温度。
:::

::: example 从裂缝读速度 {#ex-crevasse}
一个冰川的表面的应变的速率横过流动从卫星的图像的相关测量为在一个拉伸的河段的$\dot\epsilon_{xx} = 0.05\ \mathrm{yr^{-1}}$。使用Nye的裂隙的深度的平衡$d = 2\tau_t/(\rho_i g)$、一个$30\ \mathrm{m}$的裂隙的尖端、估计拉的应力$\tau_t$、解释一个水的填充的裂隙能跑到床。
::: solution
重新排列、$\tau_t = d\,\rho_i g/2 = 30\times917\times9.81/2 = 1.3\times10^{5}\ \mathrm{Pa} \approx 0.13\ \mathrm{MPa}$——冰的拉的强度的量级、方法要求的。第二部分：一个裂隙以一个到深度$d_w$的水填充在它的尖端增加一个压$\rho_w g d_w$、因为水比冰密12百分之一、一个**水的填充的**裂隙以一个同样的驱动应力的干的裂隙的$12/9.17 \approx 1.3$倍的更深的深度传播——因为表面的融的水在一个变暖的冰川是丰富的、裂隙现在在以前保持干的冰盖上开到床、这是**的水的断裂**的机制、它撕开裂谷穿过冰的架（2002年的Larsen B的崩溃以正是这些水的填充的裂谷开始、在可见的与雷达的图像填图）。
:::
:::

## 架：漂浮的冰

::: definition 冰的架与的膜的应力 {#def-shelf-stress}
在一个的接地的冰盖流入海洋的一个的架的地方的冰漂浮、物理改变性格：驱动的坡的应力消失（一个架的表面坡由的挠曲、不是由的排水设定）、应力的场变成一个**的膜的力**——深度的平均的水平的应力、量级
$$
\bar\sigma_{xx} \sim \frac{\rho\, g\, H^{2}}{2}
$$
像在一个的筏的张力一样穿过架传递——在的接地的线的深度的均值应力以覆盖的压$\tfrac{1}{2}\rho g H$成比例、接地的冰的微小的坡的应力的几倍——在侧面由对着的湾的壁的**剪的边缘**抵抗、在正面由冰的舌自己的**的后应力**抵抗。那个后应力——支持——架给内部的礼物：一个压对着它的湾的架向上传递一个压缩的力、它减少它后面的接地的冰的驱动应力、节流排放。移除或使架变薄（机制是从下面的海洋的融化、从上面的表面的融的水的断裂）、节流关闭：出口的冰川在几个月之内加速、在它们的架变薄之后的Pine Island与的Thwaites冰川、整个的集水区向着一个新的、更薄的平衡重新组织。架的**的均衡的重新调整**也是它们为什么是差的海平面的计——漂浮的冰的融化不举起任何的潮、的阿基米德的保证——使它们成为完美的放大器：没有直接的海平面的信号、但对有海平面的冰的完全的指挥。
:::

::: example 剪的边缘如何保持热 {#ex-shearheat}
在一个$10\ \mathrm{km}$宽的冰的流的剪的边缘、InSAR显示速度横过它下降$400\ \mathrm{m\,yr^{-1}}$。估计应变的速率、边缘的应力是$150\ \mathrm{kPa}$的变暖的速率（$\rho c_p = 3.7\times10^{6}\ \mathrm{J\,m^{-3}\,K^{-1}}$）。为什么这对边缘坐在哪里重要？
::: solution
应变的速率是$\dot\epsilon \approx \Delta u/w = 400/(10^{4}) = 0.04\ \mathrm{yr^{-1}} = 1.3\times10^{-9}\ \mathrm{s^{-1}}$、摩擦的加热以
$$
\dot q = \tau\dot\epsilon = 1.5\times10^{5}\times1.3\times10^{-9} = 2\times10^{-4}\ \mathrm{W\,m^{-3}},
\qquad \frac{\partial T}{\partial t} = \frac{\dot q}{\rho c_p} = 1.6\times10^{-11}\ \mathrm{K\,s^{-1}} \approx 0.5\ \mathrm{K\,yr^{-1}} .
$$
每年半度、持续几个世纪、足以把边缘的冰驱动到压力的融点——软的、融化的冰流动更容易、它使边缘变窄、它集中应变、一个正的反馈、解释为什么剪的边缘观察是**窄的、热的、在它们的边缘变形的**、为什么它们作为的损伤的带、不是作为直的Glen的冰建模。边缘是冰的流花费它的能量的地方：半个大陆的摩擦的热在这几公里的慢的、热的、毁坏的冰产生。
:::
:::

::: example 架的力 {#ex-backstress}
一个$300\ \mathrm{km}$长、$40\ \mathrm{km}$宽的冰的架以一个$\tau_c = 50\ \mathrm{kPa}$的边缘的拖把它自己的重量传递给湾的壁。证明它给接地的线的后应力以$\sigma_b \sim \tau_c L/P$成比例、求值、与在它的接地的线的$600\ \mathrm{m}$厚的冰川的深度均值的驱动应力$\tfrac{1}{2}\rho g H$比较。
::: solution
作用在架的长度$L$上的边缘的拖$\tau_c$支持它每单位的宽度的重量、所以返回给接地的线的深度的均值的后应力是
$$
\sigma_b \sim \frac{\tau_c L}{P} = \frac{5\times10^{4}\times3\times10^{5}}{4\times10^{4}} = 3.8\times10^{5}\ \mathrm{Pa} = 0.38\ \mathrm{MPa},
$$
对着一个接地的线的驱动应力$\tfrac{1}{2}\rho g H = 2.7\ \mathrm{MPa}$——架在这个宽的、弱的几何抵消约七分之一的驱动。窄的、陡的壁的峡的架、以$L/P$大一个数量级、抵消**大部分**的驱动应力、详细的模型确认它：这就是为什么格陵兰的限制的架的舌使它们的冰川在一个的头部锁、南极的巨大的、不限制的架只温和地节流、小的、限制的架（Larsen A、B、的Wilkins、格陵兰的2002–2005的案例）在它们破裂时产生了记录上每个戏剧的加速。架不是一个的瓶塞、一个**的刹车**、刹车对着引擎测量、不是对着路。这就是为什么一个架的崩溃不必改变海平面一厘米、能在十年之内使一个大陆的冰的排放加倍。
:::
:::

::: warning 冰不是"固体的"、流动定律不是自然的一个定律、快不等于不稳定
五个错误。**"冰是固体的"只在一个锤的打击的时标是真的**：在几年、冰在冰川的应力的有效的粘度是10¹³的泊——的沥青、不是的花岗岩——关于冰川的每个陈述必定隐含地指定它的的德博拉数。**Glen的指数n = 3是经验的、条件的**：它保持在应力0.01–1 MPa的位错的蠕变的机制；在低的应力冰线性地蠕变（n = 1）、在高的应力它断裂、在的熔点附近、在非常冷的冰参数A变化一个数量级——对整个的冰盖使用一个单一的A是这个领域最老的、最重要的的敷衍。**冰的流的速度不是不稳定**：大部分的流是稳定的、润滑的系统、它们的快的流动与它们的积累平衡；令人恐惧的不是速度自己、**海洋的冰盖的不稳定的几何**（海平面之下向内陆倾斜的床）、它把速度变成一个气候的触发的撤退。**"冰川向山下流动"在它重要的地方失败**：冰沿着压的梯度向上流动、的劳伦泰斯的冰盖在的劳伦泰斯的高地的流动、现在的南极在的甘巴采夫的山的流动都是向上的坡的、由厚度、不是地形驱动。**Jakobshavn的加速不是未来的证明**：单个的冰川的改变是臭名昭著的误导的——格陵兰的总的排放上升2000–2010、然后稳定——速度数据的诚实的阅读是集水区的标度的通量的发散、不是的精彩的镜头的剪辑。
:::

Vialov**在1954年的解析的冰盖的剖面、苏联的在的Mirny与的Vostok的深的钻探的计划（1957–59）在$-50\ ^\circ\mathrm{C}$原位检验流动定律。**Johannes Weertman**的滑动与断裂的析（1957–1973）、**W. F. ::: summary
- 冰川的冰以Glen的流动定律变形、ε̇ = Aτ³：剪的变薄、十的倍的温度依赖、在脆的表面层与低的应力的线性的机制之外有效。
- 重力在一个温和的坡供应一个非常均匀的驱动应力50–150 kPa；冰盖自我组织以携带它、它们的穹顶的形状（∝ ξ^{4/7}）是写在冰里的Glen的定律。
- 速度=变形+滑动；冰的流是滑动支配的海洋的床的走廊、通过边缘的百分之几携带90百分之一的南极的排放。
- 裂隙标记脆的盖；水的填充的裂隙切约30百分之一更深、冰的架的破裂的水的断裂的引擎。
- 漂浮的架失去驱动应力、获得膜的力：它们在融化时不举起海平面、节流确实举起的海平面的冰、它们的后应力能抵消一个冰川的驱动的一半。
- 这个学科的历史——Agassiz的小屋、Glen的实验室、Nye的数学、卫星的速度图集——是一个材料的性质一旦测量就成为行星的改变的控制的一个的案例研究。
:::

## 练习题

::: exercise 驱动应力 {level=1 check="180"}
求一个$200\ \mathrm{m}$厚的冰川在一个坡$\sin\alpha = 0.1$的驱动应力、以kPa（$\rho = 917\ \mathrm{kg\,m^{-3}}$）。
::: solution
$\tau_d = 917\times9.81\times200\times0.1 = 1.8\times10^{5}\ \mathrm{Pa} = 180\ \mathrm{kPa}$——在全球的50–150 kPa的带之上、这就是为什么这样陡的、厚的配置是稀有的、短的命的：它们流动掉自己。
:::

::: exercise 应变的速率 {level=1 check="0.076"}
以$A = 2.4\times10^{-24}\ \mathrm{Pa^{-3}\,s^{-1}}$、$\tau = 100\ \mathrm{kPa}$、求以$\mathrm{yr^{-1}}$到三位小数的应变的速率。
::: solution
