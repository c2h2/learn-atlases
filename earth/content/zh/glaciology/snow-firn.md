每个冰川都是一台把的雪片变成冰的山、然后再变回河流的机器、关于那个转变的最奇怪的事实是它**在雪被的生命的顶部缓慢地、在底部快速地**发生：一个落在一个的积累的区的坡上的雪片可能作为雪花一千年、作为的粒雪五百年、然后只有几十年成为冰——而它成为的冰将在一个人的寿命里向山下流动。冰川学、那个转变与冰的随后的生命的物理、是陆地的最大的淡水的库（3000万立方公里的冰、世界的淡水的68百分之一）、在的冰期的循环摆动6到120米的海平面的旋钮、**古代的**空气的唯一的档案的研究——冰川的冰里的气泡是大气自己、由雪花石化。

## 从降雪到冰

::: definition 的雪花的三个年龄 {#def-snow-firn}
新的雪花以$50$–$100\ \mathrm{kg\,m^{-3}}$落下——十分之九是空气——作为的水汽生长的冰的精致的枝状的晶体。它的埋藏开始一个三阶段的致密化。**第一阶段、的沉陷**：新的雪花的重量压碎精致的枝、雪被作为一个整体下沉、颗粒在它们的点的结合的地方结合（的烧结）、在一个季节或一年之内达到约$250$–$400\ \mathrm{kg\,m^{-3}}$；这个阶段几乎独立于气候、在雪花一岁时几乎完成。**第二阶段、的粒雪的致密化**：现在冰的颗粒的边界的由重力驱动的蠕变做工作、以一个由温度与积累设定的速率——冷的、干的南极的粒雪迟钝地致密化、花几千年到达下一个阶段、海洋性的冰川在几年内封闭它们的孔。**第三阶段、的封闭与冰**：在一个临界的密度$830\ \mathrm{kg\,m^{-3}}$、剩余的孔的空间——的体积的9.5百分之一——夹闭成孤立的气泡、粒雪已成为**冰川的冰**（纯的时$917\ \mathrm{kg\,m^{-3}}$）。从封闭开始唯一的改变是弹性的：困住的空气压缩、气泡伸长、在约$650$米之下、覆盖的压超过约$6\ \mathrm{MPa}$、气体溶解、再结晶成**的包合物的水合物**——锁住空气的冰的笼的形的分子——这就是为什么最深的冰的芯必定从冷的场地钻、那里的冰还足够年轻、没有在深度融化。
:::

::: example 的孔隙度与封闭 {#ex-porosity}
求$100\ \mathrm{kg\,m^{-3}}$的新的雪花的孔隙度（空气的体积的分数）、封闭的粒雪（$830\ \mathrm{kg\,m^{-3}}$）的、封闭时困住在一立方米的冰里的空气的体积。
::: solution
孔隙度是$\phi = 1 - \rho/917$：新的雪花$\phi = 1 - 100/917 = 0.89$；封闭$\phi = 1 - 830/917 = 0.095$。一立方米的封闭的粒雪因此持有$0.095\ \mathrm{m^{3}}$的空气、因为孔在封闭的时刻还在大气压、那是**每立方米95升的过去的大气**——铺在的东南极的冰盖的$3$公里之上、这就是为什么南极单独存储一个与现代的大气的十分之一可比的空气的储备、一个用钻机与一个干净的沟可采样的。
:::
:::

labels: \rho\ (\mathrm{kg\,m^{-3}})
caption: 一个示意性的粒雪的致密化的剖面——以$25\ \mathrm{m}$的标度的深度对冰的密度的指数的接近、代表一个以约$1\ \mathrm{m}$的年积累的中的纬度的冰川。曲线的真实的形状由的埋藏（它使层变深）与蠕变（它使层致密）的竞争设定、所以冷干舷场地把曲线拉伸到$100$米以上、海洋性的冰川在几米之内达到$830\ \mathrm{kg\,m^{-3}}$——温暖潮湿的气候的气体记录压缩、分辨率差的理由、最好的冰的芯来自冷的、高的场地的理由。
:::

## 粒雪：档案的滤器

::: proposition 粒雪为一个记录花费什么 {#prop-firn-filter}
粒雪不只是一个阶段、是冰将记录的所有的东西的一个**滤器**。**的扩散**：水汽的同位素（$\delta\mathrm{D}$、$\delta^{18}\mathrm{O}$）通过互联的孔的空气平衡、以一个随年龄的平方根增长的长度的标度$\sigma = \sqrt{2Dt}$平滑季节的信号——到封闭、的同位素的比的年的振荡典型地阻尼到它的表面的量级的十分之一、这就是为什么同位素的层序学在年轻的温带的冰川工作、在老的极地的冰只有层的计数与年代学模型服务。**的痕量气体的色散与混合**：同样的开的孔让大气的信号扩散、所以一个粒雪的芯的空气的记录是真实的大气的历史的一个平滑的版本、重建快速的事件（8.2 ka的甲烷的跳跃、工业的铅的曲线）需要为粒雪的扩散的传递函数改正。**气体的-冰的年龄的差**：深度的空气比它周围的冰**年轻**——冰在雪花落下之后几个世纪到几千年封闭了它的孔——所以一个芯的气泡记录封闭的那一年的大气、冰记录降雪的那一年、的偏移、$\Delta\mathrm{age}$、从温带的冰川的几十年到东南极的高原的约$2000$年、在任何的CO₂与温度的比较之前必定移除。**融化**：在夏季的融化发生的地方、的融的水渗透、再冻结成冰的透镜与的含水层、破坏层序——这就是为什么的格陵兰的顶点的记录是连续的、低的高度的不连续、为什么在极端年份的**超过一半的格陵兰的冰盖的面积的渗透的融化**的最近的出现写入粒雪自己的、直接的地层的气候变化的一个指标。
:::

::: example 孔的关闭的压 {#ex-clathrate}
计算$650\ \mathrm{m}$的深度在平均的密度$917\ \mathrm{kg\,m^{-3}}$的冰里的覆盖的压、与空气的气泡转化成包合物的水合物的约$6\ \mathrm{MPa}$的阈值比较。为什么包合物出现在最后几十年的冰**之下**、不是每个芯的最底部？
::: solution
$
P = \rho g h = 917\times9.81\times650 = 5.8\times10^{6}\ \mathrm{Pa} \approx 58\ \mathrm{atm}.
$
转化是一个动力的、一个热力学的过程——气泡需要成核的地点与时间——所以包合物作为一个约一百米的过渡的带出现、在压超过阈值一个余量的深度完成、它的深度因此记录冰盖的**积累的历史**（冰多快到达阈值的压）、它的物理。许多的南极的芯的最深的冰是包合物的、它使气体的提取复杂（气体必定由破碎、不是融化释放）、是最老的连续的冰的记录——从的Dome C的80万年——在它的底部之上停止的理由之一：在包合物的带之下、冰也是变形的、层不再简单。
:::
:::

## 冰川的解剖

::: definition 的积累的区、的消融的区、的平衡的线 {#def-glacier-anatomy}
一个冰川与一个的雪的斑块由**流动**区分：一旦冰超过约$50\ \mathrm{m}$的厚度、它自己的重量驱动它向山下（见[[glaciology/ice-flow]]）、流动建造特征性的解剖。**的积累的区**——每年的降雪存活夏季的地方——占据头部；**的消融的区**、融化、的崩解与的升华移除冰的地方、冰舌；在它们之间**的平衡的线（ELA）**标记零的年的平衡、在的融化的季节的末尾作为覆雪的与裸露的冰的边界可见、它的海拔是冰川的气候的最敏感的单一的指标（ELA在20世纪的温暖的时期上升了几百米、它的长期的位置设定每个冰期的范围）。流动在的床变陡的地方拉伸冰：一个的冰的瀑布之上的**的裂隙的场**、一个拉伸的冰舌的横的裂隙、冰从的壁龛的后壁拉开的地方的边缘的**的上裂隙**；压缩的流动在下游关闭它们、在一个冰的瀑布遇到一个平的河段的地方、裂隙的带再冻结成配对的**弧形冰川纹**——的Nanga Parbat与的Nanda Devi的冰川的年的条纹、它的周期性第一次证明冰川像粘的流体流动。的融的水在表面的渠道流、沿着的**冰臼**流到床、在那里它作为每个冰川的前陆的乳白的、的辫状的河流出现——在冬季的粒雪里冻结与融化的正是这个水、设定雪被的强度：在一个富温度的梯度的雪之下形成的面的、的糖的**的深度霜**是大多数的板状的雪崩失效的弱的层、冰川学对人的最直接的灾害。
:::

::: example 融化的能的代价 {#ex-melt-energy}
一个干净的冰川的表面在整个夏季吸收$100\ \mathrm{W\,m^{-2}}$的净的辐射的能。求以每天的水的等效的毫米的融化的速率、解释为什么在同样的纬度脏的冰比干净的冰融化得更快。
::: solution
融化$1\ \mathrm{m^{3}}$的冰需要$\rho L = 917\times334{,}000 = 3.06\times10^{8}\ \mathrm{J}$、所以
$
\dot m = \frac{100}{3.06\times10^{8}} = 3.3\times10^{-7}\ \mathrm{m\,s^{-1}} = 28\ \mathrm{mm\,water\,equivalent\ per\ day}.
$
新的雪花反射85–90百分之一的阳光、裸露的冰40–60、脏的冰20–30：同样的$100\ \mathrm{W\,m^{-2}}$的吸收的数字在同样的日照的脏的冰将是三的倍、因为吸收是$(1-\alpha)I$。这是微型的**的冰-的反照率的反馈**、这就是为什么的尘、的黑的碳与暗的"冰川的苔"的群落加速融化——为什么格陵兰的融化的季节现在比1980年的记录早几周开始：表面变暗、吸收、融化、暴露更多的冰、进一步变暗。
:::
:::

::: example 极地持有许多冰 {#ex-sealevel}
南极的冰盖含有$26.5\times10^{6}\ \mathrm{km^{3}}$的冰、格陵兰$2.7\times10^{6}\ \mathrm{km^{3}}$。以海洋的面积的$3.61\times10^{8}\ \mathrm{km^{2}}$把它们转换成海平面的等效、解释为什么两个数携带如此不同的风险。
::: solution
的融的水的体积是$V\times917/1000$：南极$24.3\times10^{6}\ \mathrm{km^{3}}$、格陵兰$2.5\times10^{6}\ \mathrm{km^{3}}$。以海洋的面积除，
$
\Delta h = \frac{24.3\times10^{6}}{3.61\times10^{8}} = 67\ \mathrm{m}, \qquad \frac{2.5\times10^{6}}{3.61\times10^{8}} = 6.8\ \mathrm{m},
$
（接受的数字、在的均衡与的热的膨胀的改正之后、约58米与7.4米）。风险的不对称是地质的：格陵兰的冰坐在的基岩的**之上**海平面、在表面融化、而西南极的冰的许多——总的三分之一、海平面的约3–4米——坐在向内陆向下倾斜的、海平面**之下**几百米的床上、所以它的撤退是自我加深的、海洋的攻击驱动的、不是太阳驱动的。当媒体说"西南极的冰盖是气候的问题的沉睡者"、它们指的是这个几何、不是体积。
:::
:::

::: warning 粒雪不是"老的雪花"、ELA不是的雪线、冷不等于冻结
五个错误。**粒雪是一个独特的材料**、带它自己的力学与的湖的、它自己的经济学：2013年第一次在格陵兰填图的液体的水的粒雪的含水层存储将在几十年到达海洋的几十立方公里的融的水。**平衡的线不是季节的雪线**：ELA是一个存活一年的平衡的概念；一个带巨大的冬季的降雪的一个冰川的八月的雪线能坐在ELA之下很远、混淆两者误读每个历史的冰川的照片。**"冰川的冰是冻结的水"颠倒材料**：冰是一个碰巧融化的**岩石**——的多晶的、的叶理的、像热的金属一样由晶体的蠕变变形的——"像水一样流动"的隐喻在粘度上量性地错十个数量级。**冷不等于冻结**：在的压力的融点的温带的冰川存在于$0\ ^\circ\mathrm{C}$、在每个颗粒的边界有液体的水、$-30\ ^\circ\mathrm{C}$的冷的底的冰仍能在一个压力的融的水的膜上滑动；冰川的冷/热的分类是关于**床的水**、不是关于空气的温度。**冰川的质量不是它的体积**：的质量的平衡以每年的每平方米的等效的水测量、一个冰川能在它的面积几乎不变时失去它的一半的厚度；世界的冰川本世纪的撤退主要是**的变薄**、一个只追踪的末端的位置的地图看不见的。
:::

::: history
**Alfred Wegener**——在他的大陆的漂移的论文之前十一年——在1912年写了他的关于极地的冰的力学的博士的工作、从冰架的干舷计算粒雪的密度、一个提前冰川学半个世纪的极地的冰的预算的测定；**Auguste Piccard**的1930年代的测深、瑞士的**雪与雪崩的研究所**（1936年成立、**Hans Ulrich Bader**在那里解释了深度霜与板状的雪崩的物理）建造了雪的物理的基础。**的国际的地球物理的年1957–58**打开了深的钻探的时代——1960年代的Camp Century与的Byrd的冰的芯、**Cesare Emiliani**的后继者、**Willie Dansgaard**的格陵兰的剖面的第一个同位素的记录——**Herron与Langway**在1977年的粒雪的致密化的模型给了这个学科它的主力方程。**GRIP**（格陵兰、1992）、**EPICA/Dome C**（欧洲的南极的冰的钻探的计划、2004年到达80万年）在大陆的标度证明了气泡的方法、卫星的雷达与的激光的测高（ICESat、CryoSat）现在每年称冰盖的重量。
:::

::: summary
- 雪花以三个阶段致密化——沉陷到约350 kg m⁻³、由重力驱动的粒雪的蠕变、830 kg m⁻³的孔的封闭——的时标从几年（海洋性的）到几千年（冷的高原）。
- 一立方米的封闭的粒雪封闭约95升的过去的大气；在约650米之下气泡转化成包合物的水合物。
- 粒雪滤记录：扩散阻尼同位素的信号、气体分散、气体的年龄落后冰的年龄几十年到约2000年（Δage）。
- 一个冰川的解剖——的积累的区、ELA、的消融的区、裂隙、弧形条纹、的融的水的排水——是变得可见的流动；ELA是气候的最敏感的冰川的指标。
- 融化是能量限制的：100 W m⁻²融化28毫米的水的等效每天、雪花、冰与脏的冰之间的反照率的差别在同样的太阳使那个三的倍——冰-反照率的反馈。
- 冰是一个融化的岩石：一个多晶的、蠕变的固体、它的质量的平衡是一个等效的水的预算、不是一张地图的轮廓。
:::

一个雪坑显示$1.5\ \mathrm{m}$的平均的密度$80\ \mathrm{kg\,m^{-3}}$的雪。求以毫米的水的等效。

::: exercise 粒雪的孔隙度 {level=1 check="62"}
求$350\ \mathrm{kg\,m^{-3}}$的粒雪的孔隙度（空气的体积的分数、以百分之一）。
::: solution
$\phi = 1 - 350/917 = 0.62$、即62百分之一。这个阶段的粒雪仍是三分之二的空气——这就是为什么它钻起来是软的、对雷达是透明的、一个粒雪的含水层的区域的震的"冰的速度"是冰、水与气体的一个的混合物、必定作为的三相建模。

::: exercise 冰的干舷 {level=1 check="11"}
求在海水的（$1025\ \mathrm{kg\,m^{-3}}$）漂浮的冰川的冰（$917\ \mathrm{kg\,m^{-3}}$）的干舷的分数、以百分之一到最接近的整数。
::: solution

::: exercise 封闭的深度 {level=2 check="56"}
在指数的致密化的剖面$\rho(z) = 917 - 817\,e^{-z/25}$（米）、求达到封闭的密度$830\ \mathrm{kg\,m^{-3}}$的深度、到最接近的米。
::: solution
$830 = 917 - 817e^{-z/25} \Rightarrow e^{-z/25} = 87/817$、所以$z = 25\ln(9.39) = 56\ \mathrm{m}$。练习的要点是**灵敏度**：标度的深度的加倍（一个更冷的、更干的场地）使封闭的深度加倍、模型的指数是蠕变的定律的一个替身、使冷的场地的粒雪最深的档案、最难钻的。
:::

::: exercise 扩散的阻尼 {level=2 check="0.37"}
一个粒雪的季节的同位素的信号以阻尼的长度$L = 15\ \mathrm{m}$的$A = A_0 e^{-z/L}$阻尼。求$15\ \mathrm{m}$的深度的量级的比（以两位小数给出小数）。
::: solution
$A/A_0 = e^{-1} = 0.37$。一个阻尼的长度留下信号的三分之一——这就是为什么浅的粒雪的芯仍能以同位素层计数几十年、季节的信号在典型的场地的封闭之前消失、深的冰的芯的记录声称的"年的分辨率"是年代学模型的、不是测量的同位素的剖面的一个性质。
:::

::: exercise 从一个暖的气团的融化 {level=2 check="14"}
$2\ ^\circ\mathrm{C}$的暖的雨以一个海洋性的冰川$50\ \mathrm{mm\,day^{-1}}$落下。求它引起的超过它自己的（零的）热的内容的额外的融化、以每天的水的等效的毫米、给的+的潜的湍流的通量等效$50\ \mathrm{W\,m^{-2}}$（使用$\rho L = 3.06\times10^{8}\ \mathrm{J\,m^{-3}}$）。
::: solution
$50\ \mathrm{W\,m^{-2}} = 4.32\times10^{6}\ \mathrm{J\,m^{-2}\,day^{-1}}$、每天融化$4.32\times10^{6}/3.06\times10^{8} = 14\ \mathrm{mm}$的冰。来自暖的、多云的、下雨的天气的湍流的热——不是阳光——支配海洋性的冰川的融化、这就是为什么格陵兰与欧洲的阿尔卑斯的大的融化的事件在**多云的**条件下发生、融化的预报是湿度的预报、温度的预报两者。
:::

::: exercise 每立方米的空气 {level=3 check="95"}
使用9.5百分之一的封闭的孔隙度、求$1\ \mathrm{m^{3}}$的冰封闭的空气的体积（以升）、一个$200\ \mathrm{m}$的、$10\ \mathrm{cm}$的直径的芯采样的总的空气。（以每立方米的升输入。）
::: solution
每立方米$95\ \mathrm{L}$；芯的体积是$\pi\times0.05^{2}\times200 = 1.57\ \mathrm{m^{3}}$、产生约$150\ \mathrm{L}$的古代的空气——足够几十次的CO₂、甲烷与同位素的分析、冰的芯的计划围绕**采样的体积**第一、深度第二设计的原因。这里的200米的芯在一个中的纬度的场地跨越可能的两个世纪的积累：整个的工业时代的气体记录在一个气泡的桶里。
:::

::: exercise Δage的改正 {level=3 check="1000"}
在一个冷的南极的高原的场地、积累是$60\ \mathrm{mm\,w.e.\,yr^{-1}}$、封闭发生在$120\ \mathrm{m}$。估计封闭的冰的平均的年龄、取$500\ \mathrm{kg\,m^{-3}}$的平均的粒雪的密度、忽略变薄、以年。
::: solution
$60\ \mathrm{mm\,w.e.\,yr^{-1}} = 60\ \mathrm{kg\,m^{-2}\,yr^{-1}}$、在$500\ \mathrm{kg\,m^{-3}}$给出$0.12\ \mathrm{m\,yr^{-1}}$的年的层的厚度、所以$120\ \mathrm{m}$的冰在$120/0.12 = 1000$年前落下。与它封闭的气体更年轻——大约埋藏的**一半**的时间、约500年、因为在雪花落下以来的整个的区间进入孔的空气在深度封闭——给出一个约1500年的气体的年龄、冰记录现在的之前1000年的那一年。每个冰的芯的陈述"当温度是$Y$时CO₂是$X$"在减去这个偏移之后做出、最后的冰期的循环的800年的相位的滞后的问题——CO₂领先还是滞后温度？——只在Δage模型到一个世纪之内才可回答。
:::
