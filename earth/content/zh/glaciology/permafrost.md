在2020年9月、在西伯利亚的诺里尔斯克-泰梅尔的能源综合体的一个柴油储罐——三十年来支撑在它应该保持冻结的地面之上打入的桩——从它的支撑掉下、破裂、把21000吨的柴油释放进安巴尔纳亚河：历史上最坏的北极的石油的泄漏、第一个它的根本原因写在土壤的物理的语言的。同样的地面在移动阿拉斯加的纽托克村、它的居民在2019年投票把他们的整个的社区搬迁、因为岸的滑动的永久冻土在弯曲的河的侵蚀的岸吃掉场地；它使的青藏铁路弯曲、它的工程师用千计的氨的热管、碎石的路基、通风的涵洞穿过路基以保持地面在一个变暖的十年冻结；它以从未完成腐烂的死去的植物的形式存储约**比现代的大气两倍的碳**。永久冻土——北半球的陆地的永久冻结的25百分之一——是冰冻圈的最慢的组成部分、它的最不对称的威胁：它以每世纪的米融化、但它释放的带一个世纪的标度、一个千年的尾部、它的失效的模式——的热喀斯特的崩溃、的滑动、甲烷的冒泡——不连续的、本地的、在政策依赖的全球预算严重地代表性不足。

## 冻结的地面与它的冰

::: definition 永久冻土是什么 {#def-permafrost}
永久冻土是地面——土壤或岩石——保持在$0\ ^\circ\mathrm{C}$或以下**连续两年或更多**：一个温度的定义、不是冰的、虽然冰通常是使它重要的。它在北半球的$\sim 22.8\times10^{6}\ \mathrm{km^{2}}$之下（陆地的四分之一、俄罗斯的一半、加拿大的五分之一）、从亚北极的不连续带的米厚到西伯利亚的连续的冷的$1500\ \mathrm{m}$、携带一个表面的薄层——**的活动层**、$0.5$–$2\ \mathrm{m}$厚——每年冻结与融化、隔离下面的冻结的世界、上面的天气。冰是工程的、生态的事实：冻结使冰分离成透镜的体、的楔（**的冰的楔的多边形的**的垂直的冰的脉、每一个在$-40\ ^\circ\mathrm{C}$的冬季的冷裂开、在夏季再关闭、几千年来以毫米生长）、**的冰丘**的侵入的核——穹顶的山、高到$70\ \mathrm{m}$、字面上由冻结的地下水充气、融化时崩溃留下环形的湖。的地下的冰能占据富冰的永久冻土的体积的10–50百分之一、因为冰变水、水排水、**的融的沉降**是体积的：以30百分之一的冰的内容融化的地面下沉融化的深度的30百分之一——每个滑动的河岸、每个崩溃的倒下的落叶松的"的醉的森林"、每个在一夜之间在一个以前平坦的冻原的场出现的坑的湖的机制。
:::

::: example 下沉的算术 {#ex-subsidence}
一个$10\ \mathrm{m}$的富冰的永久冻土的柱以35百分之一的体积的冰的内容完全地融化、排水是自由的。求沉降、解释结果的地表的水如何使进一步的融化以一个量级加速。
::: solution
沉降$= 0.35\times10 = 3.5\ \mathrm{m}$。新的表面坐在夏季的水位或以下、所以场地变成一个池塘——水短路保护永久冻土的绝缘：雪的融的池塘的水以开放的地面从不输送的通量向下传导热、干燥的土壤、（在冬季）雪使它绝缘、黑暗的水的表面直接吸收太阳能、池塘的边缘**倒退地**崩溃、融化在岸下面掏蚀。这是**的热喀斯特**：融化不是一个慢的向前的前缘、一个自我放大的景观的标度的失效、这个学科的中心的建模者的担忧是热喀斯特的湖——已经覆盖阿拉斯加的北极的沿海的平原的约十分之一、西西伯利亚的低地的上升的分数——比"逐渐的永久冻土的失去"的任何的基于传导的预报承认的更快加深、合并。
:::
:::

## 融化的景观

::: definition 热喀斯特、亚拉与融化的词汇 {#def-thermokarst}
永久冻土的地形是一个**正在主动腐烂的遗迹的景观**、它的词汇是一个失效的模式的目录。**热喀斯特**——一般的崩溃与池塘的过程——建造融化的湖、它的岸在风暴驱动的富冰的岸的波浪的侵蚀之中快到的$1\ \mathrm{m\,day^{-1}}$推进（阿拉斯加的北极的沿海的平原的湖在几十年合并成排水的网络）。**倒退的融化的滑动**——几十公顷宽的圆形的剧场、带在一个异常的湿的夏季触发它们之后每个夏季撤退几米的壁——永久冻土的滑坡的等价、已知的每单位面积的最有效的碳的出口。**亚拉**：未冰川的西伯利亚、阿拉斯加、的育空的富冰的、同生的粉砂——$10^{5}$–$10^{6}$年的草-的猛犸的草原的沉积、在地方几百米厚、持有也许$500\ \mathrm{GtC}$以一个**不稳定的**的形式（草的根的碳比低的北极的冻原的木本的泥分解得快得多）、与20–50百分之一的体积的冰间层、即对上一个课的算术最大的脆弱。**的未冻层**——在湖、河、最终整个的活动层之下随着变暖渗透打开的未冻结的窗口——使冻结的地面与大气的宽恕断开、把深的冰承诺给几个世纪的最终的融化、不管未来的排放。的**的冻的搅动**——活动层的霜的搅拌、以每厘米的厘米混合、埋葬、再暴露碳——保持喂养新鲜的基质给融化的前缘的慢的混合者。词汇的课是永久冻土的融化**不是一个带一个平滑的答案的扩散的问题**：它是一个带阈值的景观的失效、碳的释放跟随失效的几何、不是温度的曲线。
:::

::: example 吃冻原的湖 {#ex-slump}
在的赫舍尔岛（的波福特的海岸）的一个倒退的融化的滑动——自1990年代研究的类型的例子——在一个异常的湿的夏季之后开始、暴露亚拉、在一个$200\ \mathrm{m}$宽的顶的墙跨过撤退每年$12\ \mathrm{m}$、融化一个$40\ \mathrm{m}$深的富冰的柱。估计每年的破坏的永久冻土的体积、若亚拉持有$25\ \mathrm{kg\,C\,m^{-3}}$释放的碳。
::: solution
体积$= 12\times200\times40 = 9.6\times10^{4}\ \mathrm{m^{3}\,yr^{-1}}$、碳$9.6\times10^{4}\times25 = 2.4\times10^{6}\ \mathrm{kg} = 2400\ \mathrm{tC\,yr^{-1}}$、从一个顶的墙——一个滑动每年的几千吨、对着一个全球的滑动的现在由卫星与航空的测量在**千**绘制的种群（加拿大的北极、的斯瓦尔巴、西伯利亚）、每一个带一个几十年的寿命。算术是永久冻土的学派的关于碳的释放的诚实的陈述不是一个平滑的通量、一个**种群的问题**的理由：释放设定在多少滑动、湖、崩溃的海岸线每个十年开始、开始是阈值驱动的——湿的夏季、风暴的波浪、火——事件的频率比模型使用的平均的温度上升得快。
:::
:::

## 碳的保险库与它的反馈

::: proposition 永久冻土的碳的反馈 {#prop-carbon-feedback}
北方的永久冻土的土壤在顶部的三米持有$\sim 1500\ \mathrm{GtC}$（的塔尔诺卡伊的清单、仍然标准的）、它的也许$1000$–$1400\ \mathrm{Gt}$本千年**易受**融化——对着大气的$870\ \mathrm{GtC}$、自1870已经排放的$\sim 2500\ \mathrm{GtC}$。释放是需氧的支配的：大多数的融化的地面排水、氧化它的碳成CO₂、以实验室的培养显示年轻的、不稳定的碳快、老的慢但不可逆的速率做；释放的几百分之一是甲烷从积水的融化的湖、池塘、合并的湖的缺氧的底——不是由扩散释放、由**的冒泡**、卫星与的塔的运动显示通量集中在融化的湖的出口的渠道、在西伯利亚的北极、在的东西伯利亚的北极的陆架的浅的**的海底的永久冻土**、全新世融化的近岸的地面沿着古的河的床以的串排放甲烷的气的流的。气候的后果是一个**带一个长的引信的正的反馈**：模型的相互比较把永久冻土的碳的添加放在2100的几十的ppm的CO₂的等效、2300的几百、值约本世纪的$+0.2\ ^\circ\mathrm{C}$、之外的$+1\ ^\circ\mathrm{C}$或更多——足够小、它不改变本世纪的标题、足够大、**它不在大多数的排放的预算、一旦开始不能停止**：深的融化、一旦活动层突破富冰的层、承诺它自己的未来。反馈的不对称是政策的事实：最终的释放的三分之一或更多（在模型的估计）已经由目前的变暖承诺、碳的保险库、与化石的碳不同、没有一个开关——只有普通的一个。
:::

::: example 保险库的预算 {#ex-vaultbudget}
假设$1400\ \mathrm{GtC}$易受、10百分之一在21世纪释放、它的4百分之一作为甲烷。求平均的每年的CO₂与CH₄的碳的通量、用一个100年的GWP的28比较甲烷的项、CO₂的项的变暖、陈述真实的21世纪的释放可能**相对于温度前置**、**相对于排放后置**的两个理由。
::: solution
总的释放$140\ \mathrm{GtC}$在100年：$134\ \mathrm{GtC}$作为CO₂（$1.34\ \mathrm{GtC\,yr^{-1}}$）、$5.6\ \mathrm{GtC}$作为CH₄（$0.056\ \mathrm{GtC\,yr^{-1}}$）。以CO₂的等效甲烷的项是$5.6\times28 = 157\ \mathrm{GtCO_2e}$、对着CO₂的项的$134\times(44/12) = 491$——甲烷是碳的4百分之一的总的强迫的四分之一。**相对于温度前置**、因为近表面的、不稳定的、富冰的碳先融化（容易的碳早去）；**相对于排放后置**、因为深的融化是传导限制的、在CO₂停止之后继续几个世纪——永久冻土的反馈是一个气候的过程的教科书的一个例子、它把"净零"变成"净零的*排放*"、不是净零的*变暖*、它的账单在谈判结束之后到达。
:::
:::

## 冻结的基础：建成的环境

::: definition 灾害与工程 {#def-hazards}
永久冻土是一个**基础的材料**、它的强度是它的温度、工程的文献现在读起来像一张的病历：的跨阿拉斯加的管道的100公里的的热虹吸的冷却的支撑、的青藏铁路的热管、碎石的路基、通风的涵洞（2006年以一个已经在测试的50年的永久冻土的假设建造）、俄罗斯北方的永久冻土的城市的350万的人、机场、道路、的尾矿的坝——2020年的诺里尔斯克的失效是第一个官方地归因于永久冻土的沉降的灾害。评估的数：约**北方的基础设施的一半在到2050地面的变暖将强加显著的额外的维护、失效的风险的区域**、最高的暴露在不连续的永久冻土的带——薄的、暖的、近融化、首先离开、在设计规范代表性不足的地面。生态的灾害并行：**醉的森林**（积水的、倒下的使汇变成源的林分）、遗留的污染物的释放（的沉降的放射性核素、汞、抢标题但定量地小的风险、的古老的病原体、与2016年的与一个融化的驯鹿的尸体有关的亚马尔炭疽的爆发联系）、的亚马尔半岛的甲烷的爆炸的坑、自2014的十多个的喷发穿透表面、在2014杀死千计的放牧的驯鹿。适应的工具是真实的、本地的：热虹吸、碎石的基础、带通风的腔的桩的基础、地面已经离开地方**管理的撤退**、纽托克/的梅尔塔维克是第一个美国的联邦的案例、不会是最后一个。
:::

::: example 对着一个移动的基线设计 {#ex-engineering}
在一个$-2\ ^\circ\mathrm{C}$的平均的地面的温度的富冰的永久冻土的一个铁路的路基为一个50年的寿命设计、带一个$+1\ ^\circ\mathrm{C}$的变暖的宽限。若永久冻土的台面在$8\ \mathrm{m}$之下、下面的冰的内容是25百分之一、求若变暖融化富冰的地面的顶部的$4\ \mathrm{m}$的沉降、评估变暖的宽限是否是正确的要保护的变量。
::: solution
沉降$= 0.25\times4 = 1.0\ \mathrm{m}$——对一个以厘米整平的铁路灾难的。宽限保护**空气的温度**、错的变量：重要的是**的融化的深度**、它以非线性的响应（池塘、的有机的垫的失去、排水的改变、的零的帘的存储的潜的热）、当一个场地跨过富冰的阈值时以米跳。现代的北方的工程因此对着**地面的温度、冰的内容的剖面**设计——的热敏的电阻的阵的列作为主要的仪器、热管作为主要的修理——诚实的规划的陈述是在不连续的带、没有工程修复一个它的地面离开的场地：那里、设计的问题变成纽托克的问题、移动到哪里。
:::
:::

::: warning 永久冻土的碳不是一个带一个日期的"定时炸弹"、融化不是均匀的、甲烷的数不是标题说的
五个错误。**"定时炸弹"暗示一个日程；保险库在一个传导的钟泄漏**——大多数的易受的碳在几个世纪到几千年释放、本世纪的释放是轨迹的一个乘数、不是一个悬崖。**甲烷的分数小、它的GWP争论**：释放的3–5百分之一作为CH₄是模型的一致、100年的GWP的28低估近期（20年）的影响、高估千年的——引用一个单一的数任一个方向是一个修辞的选择、不是一个测量。**"永久冻土在每个地方均匀地融化"混淆地图**：连续的带本世纪将只失去它的顶部的几十米；**不连续的**带失去它的永久冻土的大部分——不连续的带持有大多数的人民、道路、设计规范的差距。**火、不是温度、通常是接近的触发**：燃烧移除绝缘的有机的层、使夏季的融化的深度再减半、所以火的后的永久冻土的损失在几十年的气候单独的预报之前运行——北方的燃烧的面积在上升；碳的反馈、火的反馈是戴两个帽子的同一个反馈。**海底的甲烷是真实的、限制的**：的东西伯利亚的陆架的喷口集中、潮调节、大多数的在水柱再氧化——使2010年代的标题的"沉睡的巨人"的框架使浅的水合物的末日的场景夸大一个量级、永久冻土的学派自己发表、标题不携带的修正。
:::

::: history
科学从俄罗斯的**的冻土学**生长——**米哈伊尔·伊万诺维奇·苏姆金**的1927年的论文使这个学科系统化、建造西伯利亚的基础设施的地质的技术的基线、**永久冻土**的术语自己在本世纪的中期的美国-苏联的关于的冻地的研究（1952）的合作通过进入英语。**国际的永久冻土的协会**（1983）、**CALM**（的环极的活动层的监测、1995–）、**GTN-P**（全球的陆地的永冻土的网络）的钻孔的网络把一个地质的技术的专业变成一个监测的学科、碳的保险库的数是**查尔斯·塔尔诺卡伊**与同事的2009年的清单（顶部的3米的1035 GtC）、**大卫·麦圭尔**、**古斯塔夫·胡盖利乌斯**、**凯文·谢弗**的脆弱、脆弱-建模的学派、**克里斯蒂安·施奈德·冯·代姆林**与同事的反馈的相互比较（它的"每单位的易受的碳的排放的效率"的框架重组争论）、**埃莉诺·伯克**与同事的永久冻土的基线的预报的工作。工程的经典是的跨阿拉斯加的管道的热虹吸的时代（1977）、青藏铁路的永久冻土的计划（2006）、2020年的诺里尔斯克的失效——第一个官方地归因于永久冻土的沉降的灾害——开始把灾害写进保险的费率、建筑规范的慢的工作。
:::

当孔隙的水冻结它释放$334\ \mathrm{kJ\,kg^{-1}}$、保持冻结的前缘在$0\ ^\circ\mathrm{C}$几周至几个月、热排走——每个钻孔的温度记录可见的"帘"。同样的潜的热、反转、在空气跨过阈值之后使一个变暖的永久冻土的台面缓冲几年：零的帘是为什么永久冻土的温度记录显示如此顽固的平的线、为什么地面对变暖的响应作为一个步、不是一个坡到达。
:::
:::

::: summary
- 永久冻土——冻结≥2年的地面——在北半球的四分之一之下；它的冰（透镜的体、楔、冰丘的核、亚拉）能是体积的10–50百分之一、使融化一个体积的崩溃、不是一个的软化。
- 融化是景观的失效：热喀斯特的湖、倒退的滑动、亚拉的崩溃、的未冻层的形成是带一个池塘的水自我放大的阈值的过程。
- 保险库持有约1500 GtC——大气的两倍、它本千年的释放承诺；反馈值约2100的+0.2 °C、之外的约+1 °C、主要作为CO₂、带一个甲烷的项、碳的4百分之一的强迫的四分之一。
- 释放在不稳定的碳前置、在深的传导后置——使"净零的排放"不是"净零的变暖"的过程。
- 永久冻土是一个基础的材料：北方的基础设施的一半坐在到2050将显著变暖的地面之上、不连续的带——最多的人民、最薄的冰——首先失效。
- 火、排水的改变、风暴、不是单独平均的温度、设定步调；诚实的预算是一个种群的问题（滑动、湖、海岸）、不是一个平滑的通量。
:::

## 练习题

::: exercise 活动层的速率 {level=1 check="15"}
一个$1.5\ \mathrm{m}$的活动层在一个100天的夏季融化。求以$\mathrm{mm\,day^{-1}}$的平均的融化的前缘的推进。
::: solution
$1500/100 = 15\ \mathrm{mm\,day^{-1}}$——活动层的夏季对冬季的冻结的比赛、两者的**净**（长期的永久冻土的台面）是高纬度的气候的最敏感的指标之一的理由：一个每厘米的一年的不平衡、在任何单一的季节不可见的、在一个世纪破坏、建造一个景观。
:::
:::

::: exercise 保险库对着大气 {level=1 check="1.7"}
求永久冻土的土壤的碳（$1500\ \mathrm{GtC}$）对大气的碳（$870\ \mathrm{GtC}$）的比。
::: solution
$1500/870 = 1.7$。数属于每个排放的图表：北半球的冻结的土壤是一个第二的、未定价的、带阈值的、与大气自己同样阶的碳的库、每个永久冻土的论文的"大气的两倍"的标题是这个除法。
:::
:::

::: exercise 沉降 {level=1 check="2.4"}
$8\ \mathrm{m}$的30百分之一的体积的冰的永久冻土以自由的排水融化。求以米到一位小数的沉降。
::: solution
$0.30\times8 = 2.4\ \mathrm{m}$。地面表面以冰的体积、不是它的质量落下——这就是为什么富冰的场地池塘、为什么"池塘在一夜之间出现"是一个可靠的本地的证词、为什么冻原的InSAR的沉降的地图读起来像一个未来的湖的地图。
:::
:::

::: exercise 滑动的碳 {level=2 check="1125"}
一个融化的滑动以一个$150\ \mathrm{m}$的顶的墙撤退$10\ \mathrm{m\,yr^{-1}}$、融化一个$30\ \mathrm{m}$的柱以$25\ \mathrm{kg\,C\,m^{-3}}$。求以吨的碳的每年的碳的释放。
::: solution
$10\times150\times30\times25 = 1.125\times10^{6}\ \mathrm{kg} = 1125\ \mathrm{tC\,yr^{-1}}$。一个滑动、一个碳的一千吨的河流每年、千个滑动、种群变成预算的一个吉吨的标度的项。
:::
:::

::: exercise 甲烷的等效 {level=2 check="157"}
$5.6\ \mathrm{GtC}$作为一个世纪的甲烷释放。用GWP-100的$= 28$求以$\mathrm{GtCO_2e}$的CO₂的等效的强迫的总。
::: solution
$5.6\times28 = 157\ \mathrm{GtCO_2e}$——与现代的化石的排放的二十年可比、从永久冻土的释放的4百分之一。练习是学派关于GWP争论的理由：在一个20年的视野同样的甲烷值$84\times5.6 = 470$、一个反馈的政策的重依赖你在定价哪个世纪。
:::
:::

::: exercise 热管的职责 {level=2 check="630"}
一个热虹吸以连续移动$20\ \mathrm{W}$的热冷却一个铁路的路基。求以MJ的每年移除的热、陈述那个热能驱动的冰的厚度（每$\mathrm{m^{2}}$）（潜的热$3.06\times10^{8}\ \mathrm{J\,m^{-3}}$）。
::: solution
$20\times3.15\times10^{7} = 6.3\times10^{8}\ \mathrm{J} = 630\ \mathrm{MJ}$、等效于融化每平方米每年$6.3\times10^{8}/3.06\times10^{8} = 2.1\ \mathrm{m}$的冰——足够使一个米的标度的活动层在一个变暖的夏季冻结、这就是为什么每公里的几十万元的被动钢比一百万元的砾石的存活得久。
:::
:::

::: exercise 斯特藩的融化的深度 {level=3 check="23"}
若一个$+5\ \mathrm{K}$的热扰动纯地由传导进入永久冻土（土壤$k = 1.5\ \mathrm{W\,m^{-1}\,K^{-1}}$、体积的融化的潜的热$9.2\times10^{7}\ \mathrm{J\,m^{-3}}$）、求100年之后的斯特藩定律的融化的深度、以米到最接近的米。
::: solution
$d = \sqrt{2k\Delta T\,t/\rho_w L} = \sqrt{2\times1.5\times5\times3.15\times10^{9}/9.2\times10^{7}} = \sqrt{513} = 23\ \mathrm{m}$。同样的世纪的观察的气候驱动的融化是**米**、不是几十米——差距是重点：表面的能量的预算、再冻结的冬季的盖子、零的帘、排水都节流前缘、23米是**承诺的深的融化**代表的一个上限、一旦热喀斯特的池塘绕过那些刹车。两个数的差别是一个管理的世纪、一个未管理的差别。
:::
:::

::: exercise 水合物的深度 {level=3 check="130"}
甲烷的水合物在$0\ ^\circ\mathrm{C}$在$2.6\ \mathrm{MPa}$之上稳定。以覆盖的密度$2000\ \mathrm{kg\,m^{-3}}$、求在海床之下的海底的水合物的稳定的最小深度、以米到最接近的十。
::: solution
$h = 2.6\times10^{6}/(2000\times9.81) = 133\ \mathrm{m}$、即$130\ \mathrm{m}$到最接近的十。的东西伯利亚的陆架的浅的海底的水合物——在陆架在冰川的海平面是永久冻土时放置、现在在几米的水之下勉强在稳定的边缘——是"沉睡的巨人"的恐慌后面的库；同样的算术显示为什么它们**薄的、斑的、大多数的在水柱再溶解、不是排放**、学派的修正的估计它们的本世纪的贡献在标题的数之下两个量级的理由。
:::
