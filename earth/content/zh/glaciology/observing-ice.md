在2019年、一个极地的遥感的实验室的联盟发表冰川学的历史最大胆的数据集：**MEaSURE**的谱系的速度的镶嵌——的ITS_EXCHANGE的汇编——2亿的冰的流动的速度测量覆盖北极与的亚南极的每个冰川、冰的流、每一个从卫星的图像的对推导、大多数的从一个单一的30米的传感器、全部由一个花十年使它们的个人的地图兼容的国际的团队组装。二十年之前、同样的信息将填满一个职业的现场的季节、一个国家计划的预算；一代之前、世界的大多数的冰的流动简单地未知。观察在五十年内两次转变冰川学——首先从一个的标尺与的消融的杆的科学到一个卫星的、现在从卫星到一个**连续的、标定的、多的任务的测量系统**、它的产品（质量、厚度、速度、床、正面的位置）在几周到达、直接输入政策读的预报的模型。这个课是工具包：你如何称一个法国的大小的东西、测量一个从500公里之上每天移动一米的东西、看见三公里的冰之下的山。

## 称重：重力与测高

::: definition 重力与测高 {#def-weighing}
**GRACE**（2002–17）、**GRACE-FO**（2018–）编队飞行、以微米的精度交换微波的测距的信号、感觉地球的质量移动：一个失去一百吉吨的冰的格陵兰拉下面的卫星稍微少、月的重力的场的解以约300公里的分辨率报告改变、等效于**在一个冰盖展开的厘米的水**——对个人的冰川盲、对整个的系统无匹敌、IMBIE的质量的预算的脊柱。**雷达的测高**（ERS、Envisat、2010以来的**CryoSat-2**、它的干涉的SAR的模式最终分辨传统的测高仪丢失表面的陡的边缘）、**激光的测高**（**ICESat** 2003–09、2018以来的**ICESat-2**、它的光子计数的激光雷达绘制季节的雪线、海冰的融的水的池塘、以及冰川的海拔）测量**表面的高度**、它的改变乘面积密度给出质量：的大地测量的方法、现在最完整的长记录、通过链接雷达的任务追溯到1978。从测量的**的干舷**到海冰的**厚度**的转换是这本图集使用最多的反演——带一个雪的载荷的阿基米德、$H = \rho_w f/(\rho_w-\rho_i)$、对使浮冰降低的雪校正、它最弱的环节不是激光、**的雪的密度**、一个建模的数、它的2018的修订在一个单一的论文使估计的北极的海冰的体积十分之一：一个永久的课、在遥感、物理很少是不确定性；**辅助的参数**是。
:::

::: example 从干舷到浮冰 {#ex-freeboard}
CryoSat-2在北极的中部测量一个$1.2\ \mathrm{m}$的冬季的干舷。求忽略雪的冰的厚度、然后以$0.3\ \mathrm{m}$的在$300\ \mathrm{kg\,m^{-3}}$的雪（它使浮冰降低）、用$\rho_i = 917$、$\rho_w = 1025\ \mathrm{kg\,m^{-3}}$。
::: solution
没有雪、$H = \rho_w f/(\rho_w - \rho_i) = 1025\times1.2/108 = 11.4\ \mathrm{m}$。带雪、载荷的校正加雪自己的降低：浮冰骑得更低以$\rho_s d_s/(\rho_w-\rho_i) = 300\times0.3/108 = 0.83\ \mathrm{m}$的**不是**冰的干舷、所以冰的厚度是$1025\times(1.2-0.83)/108 = 3.5\ \mathrm{m}$加雪的冰的项——一个驱动体积、栖息地、航运的预报的数的三的倍的摆动。这就是为什么雪的密度的争论那么重要、为什么激光（ICESat-2、它**看见**雪的表面）、雷达（它通过C波段的散射看见雪-冰的界面）现在作为一个的对飞行：两者一起直接测量雪的深度、把这本图集的最大的辅助的误差变成一个测量的量。
:::
:::

::: widget plot
f: 9.5*x
x: 0, 3
y: 0, 30
labels: H\ (\mathrm{m})
caption: 在水的漂浮的冰的厚度对着干舷——阿基米德的线、它的斜率（$\rho_w/(\rho_w-\rho_i) \approx 9.5$）使一个厘米的精度的高度测量变成一个米的标度的厚度的产品。句子隐藏的每个假设——密度的剖面、雪的载荷、海平面、潮——是一个发表的校正的论文、整个海冰的厚度的企业是这条线加校正它的谦卑。
:::

## 测量流动：干涉与特征跟踪

::: definition 从轨道的速度 {#def-velocity}
冰的速度从太空两种方式测量。**特征跟踪**使重复的图像互相关（自1972的Landsat——从它在事后重建雅各布港与Pine Island的前卫星的时代的速度的意外的50年的档案；每天的MODIS；10米的Sentinel-2）寻找在的过境之间裂隙的图案、融的水的池塘、的岩石的露头的位移：稳健的、不依赖天气的、现在生产地球的每个冰川的每天到每周的速度的地图。**的合成的孔径的雷达的干涉**走得更远：几天拍摄的两个雷达的图像作为一个复杂的**干涉的图**组合、它的条纹的图案以厘米的精度编码沿着视线的位移（C波段的Sentinel-1、自2014自由与连续的、给出6–12天的重复的时间；ALOS与TanDEM-X的任务加在的无雪的表面保持相干的更长的波长）、**多普勒**或的偏移的跟踪的模式使方法甚至扩展到去相关的融化带。产品改变科学的问题：1990年代的**速度的地图**（InSAR的第一个南极的运动）显示90百分之一的南极的排放通过边缘的几百分之一运行；2010年代的**改变的地图**抓住Thwaites加速、Kamb冰的流停止、一百个格陵兰的出口的冰川在一个季节之内响应一个变薄的混合物。速度加厚度加宽度是**通量**、一条接地的线或一个正面的通量是每个质量的预算的排放的项——这就是为什么速度的记录、不是照片、是海平面的早的警告的系统。
:::

::: example 从一个匹配的对的速度 {#ex-trackspeed}
的海尔黑姆冰川的一个裂隙的场在一个10米的Sentinel-2的图像的像元的列12 400出现在6月1日、在6月21日的图像的列12 517出现。求以$\mathrm{m\,day^{-1}}$、$\mathrm{m\,yr^{-1}}$的沿着流动的速率、说出两个假设。
::: solution
位移$= 117\times10 = 1170\ \mathrm{m}$在20天：$58.5\ \mathrm{m\,day^{-1}}$、$2.1\times10^{4}\ \mathrm{m\,yr^{-1}}$——海尔黑姆的夏季的速度、在一个非是的潮的脉动测量的最快的之一。假设：图像的几何（的正的纠正、10米的像元的标度、亚的像元的相关的峰）在几像元的水平正确、跟踪的特征是**冰**、不是云、一个融的水的池塘的图案、一个重复的噪声的纹理——使特征跟踪的产品需要手工的、几何的（速度的连续）的筛查的失效的模式、学派的速度的镶嵌像天气的图带概率一样仔细地用自信的掩膜注释的理由。
:::
:::

## 透过冰看见：雷达、声与床

::: definition 的冰的穿透的雷达与床 {#def-radar-bed}
在100–1000 MHz的无线电波几乎不衰减弱地通过冷的冰、强烈地从**床**（岩石-冰的阻抗的对比）、从**内部的层**（古老的表面、的火山灰、冰冻的融化的表面、的冰的沉积学家的宝藏）反射：**的回声的测深**、自1960年代在飞机飞行、现在在无人机与的无人驾驶的飞机飞行、从双向的传播的时间测量厚度（$H = c\,\Delta t/2\sqrt{\varepsilon_r}$、$\varepsilon_r \approx 3.17$对冰）、成像日期的冰的地层的。汇编的产品——南极的**Bedmap2/3**、**BedMachine格陵兰**（2022）——组装百万的雷达的线、重力与的磁的船的轨迹、的地震的测深成冰下的地形、它们不是背景的地图、**预报的输入**：一个冰盖的海洋的不稳定的风险直接从床的坡在海平面之下读、的深度到床控制从的玄武岩的风化到的下的湖的一切。最后的无冰的前沿——漂浮的架**之下的腔**——现在由自主的冰下的载具（在的彼得曼冰川之下的AUV的Ran号、2012）、在Pine Island的架之下的热的水的钻孔释放的水下的滑翔的机（2019）、记录正在吃Thwaites的水的温度的**海床的着陆的**探测。模式是这个世纪的方法的道德：决定冰盖的未来的参数——床的几何、腔的温度、接地的线的位置——在冰**之下**、这个学科的前沿在一个人类不能的地方操作的仪器。
:::

::: example 雷达的深度测深 {#ex-radardepth}
一个的冰的穿透的雷达的脉冲在表面的回声之后$23.7\ \mu\mathrm{s}$返回床的回声。求冰的厚度（$\varepsilon_r = 3.17$、$c = 3\times10^{8}\ \mathrm{m\,s^{-1}}$）、若表面站在$1850\ \mathrm{m}$、说出在那个场地的床在海平面之上、之下的接地。
::: solution
在冰的波的速度是$c/\sqrt{\varepsilon_r} = 1.69\times10^{8}\ \mathrm{m\,s^{-1}}$、所以
$$
H = \frac{v\,\Delta t}{2} = \frac{1.69\times10^{8}\times23.7\times10^{-6}}{2} = 2000\ \mathrm{m}.
$$
床坐在$1850 - 2000 = -150\ \mathrm{m}$——**在海平面之下**、海洋的末端的地域：漂浮将发生在$H = 1.12\times150 = 168\ \mathrm{m}$、所以那里的冰以一个300米的多余的厚度接地、雷达的线刚刚测量过稳定与[[glaciology/ice-sheets]]海洋不稳定之间的边缘。一个单一的雷达的迹线、正确地读、是一个关于它上面的冰川的未来的句子——这就是为什么床的地图当作战略的数据。
:::
:::

## 综合：质量的预算

::: definition 三个方法与IMBIE {#def-synthesis}
一个冰的体的质量的平衡以三个独立的方式测量——**冰川学的**（标尺与的坑）、**大地测量的**（测高的差分）、**通量的排放**（速度 × 宽度 × 厚度跨过一条边界、减去崩解与融化）、它们的一致、在2000年代–2010年代区域地证明、使全球的数可信的安静的胜利。**IMBIE**（冰盖的质量的平衡的相互比较的练习）使一致正式化：对每个冰盖与时期、每个发表的方法协调到共同的定义、以的逆的方差的加权组合、生产IPCC引用的单一的数（格陵兰2010年代的$-200\ \mathrm{Gt\,yr^{-1}}$、南极$-120$、冰川$-270$）。综合也是一个**的诊断**：当方法不一致、不一致定位缺失的物理：的高亚的大地测量的-冰川学的差距暴露的覆盖的碎屑、雪的密度的问题；南极的半岛的入口的冰川的通量-重力的紧张驱动发现槽比假设的更深、因此更高的可能的排放的测量的深度的运动（的帆船的无人机的多束、BatMap的调查）。最新的综合是**的同化**：把速度、海拔、重力的数据直接输入冰的流动的模型以生产雅各布港的速度的、阿蒙森的海的排放的操作的一年预报的系统——冰川学的第一个真正的**预报**、年轻、技能谦虚、这个学科的最清楚的意图的陈述：从测量撤退到预报它。
:::

::: example 预算关闭（几乎） {#ex-budgetclose}
对一个格陵兰的集水区、积累是$400\ \mathrm{Gt\,yr^{-1}}$、表面的融化的径流$550$、冰山的崩解$350$。求以通量的方法的质量的平衡、使一个$-90 \pm 40\ \mathrm{Gt\,yr^{-1}}$的GRACE的估计、一个$-160 \pm 50$的测高的估计一致。
::: solution
通量的方法：径流与崩解移除$900\ \mathrm{Gt\,yr^{-1}}$、对着$400$的积累、给出$-500\ \mathrm{Gt\,yr^{-1}}$——对一个单一的集水区荒谬的、重点是。三个估计（$-500$、$-90 \pm 40$、$-160 \pm 50$）不能全部正确、通量的方法的失效的模式是**几何**、不是算术：一个错放的排水的分水的岭重复计算一个邻居的崩解、近岸的底的融化对正面的位置的地图不可见的、积累是一个带20百分之一的误差的模型的平均。IMBIE类型的响应是审计边界——重画分水的岭、再测量正面的厚度——不是使不一致平均离开。当数在误差之内关闭——它们现在对格陵兰与南极的大多数做——关闭是这个学科的结果、不是它的开始假设。
:::
:::

::: warning 卫星不测量新闻稿说的、分辨率不是精度、开放的数据不等于理解的数据
五个错误。**"GRACE测量融化"**：它测量总的水的柱的重力的改变——冰、雪、液体的水、**回弹的地壳**（的冰后的回弹是每个格陵兰与南极的重力的解的最大的系统、不同的回弹的模型使趋势移动三分之一）。**"ICESat-2测量冰的厚度"**：它以厘米测量表面的高度；厚度需要床（航空的雷达、几年之后）、漂浮的物理（只海冰）——"从太空的厚度"的标题通常是一个带三个模型的输入的**产品的链**。**"一个30米的地图意味着30米的知识"**：没有误差的表征的分辨率是市场——速度的镶嵌带相关的自信的掩膜、测高带依赖坡的误差的条、质量的平衡的文献的艰苦获得的课是**相关误差**（两个"独立的"方法用于的粒雪的校正的同样的模型）使一致假装比使不一致假装更经常。**"雷达在每个地方看见床"**：在温的、富水的冰之下、在咸的北极的冰川之下雷达的信号衰减、散射、最好的地图的整个的扇区**内插**——BedMachine的产品的自己的文档标记它们、海洋的不稳定的地图直接继承那个不确定性。**开放的、近实时的数据有一个社会学**：ITS_EXCHANGE的速度的地图是自由的、极好的、它们也产生一个在它的速度的加速是测量的几何的特征的一个"冰川加速"的论文的引用的生态：学科的新文的素养是读**自信的层**、不是颜色的地图。
:::

::: history
航空的**回声的测深**从1950年代–60年代的跨极的飞行开始——英国的南极的调查局的南极的计划、丹麦的技术大学的几十年的格陵兰的努力——成熟成2000年代–2020年代的大陆的床的图集（**Bedmap2** 2001与它的学生、**BedMachine格陵兰** 2022、后者由**马蒂厄·莫尔利姆**与同事从四十年的合并的测深汇编）。卫星的测高以**SEASAT**（1978）打开、通过ERS-1/2与Envisat成熟到**CryoSat-2**（2010）；雷达的干涉由**大卫·戈尔德斯坦**（1991）证明、在1990年代由**赫尔穆特·罗特**的团体、**伊恩·宾德沙德勒**的NASA的团队变成一个冰盖的速度的图集、它们的第一个绘制重力测量的时代（GRACE 2002）稍后将称的南极的冰的流。**ICESat**（2003）打开精确的极地的测高；**的冰山桥行动**（2009–19）连接两个激光的任务、在它的2012年的威尔克斯的运动、生产一个在危机的架的第一个近实时的航空的评估；**Sentinel-1**（2014）、**ICESat-2**（2018）、**GRACE-FO**（2018）、**MEaSUREs/ITS_EXCHANGE**的镶嵌（2019）定义现在的系统、**IMBIE**的练习（2012–）它的综合。冰下的前沿：在的彼得曼冰川之下的AUV的Ran号（2012、**彼得·戴维斯**与同事）、在Pine Island的架之下的热的水的部署的滑翔的机（2019、**基思·尼科尔斯**的英国-美国的计划）、在Thwaites的架的海床的测温的阵的列（2021–）。
:::

::: summary
- 质量以三种方式测量——标尺、测高的差分、通量的门——它们证明的一致（IMBIE）是每个海平面的数的可信的基础。
- 重力（GRACE/GRACE-FO）每月称整个的系统、粗糙；测高（CryoSat-2、ICESat-2）精细地绘制海拔的改变、需要密度、粒雪的校正。
- 速度来自特征跟踪（50年的Landsat的档案到每天的Sentinel）、InSAR；速度 × 几何 = 排放、海平面的早的警告的产品。
- 的冰的穿透的雷达测量厚度、地层、床——床的在海平面之下的几何决定海洋的不稳定的风险；最后的前沿是用自主的载具给腔安装仪器。
- 从干舷到厚度的反演、所有的产品的链只像它们的辅助的参数（雪的密度、回弹的模型、床的地图）一样好——物理很少是误差。
- 这个学科从测量移动到预报：数据的同化现在生产一年的冰的流动的预报、冰川学的第一个真正的预报。
:::

::: exercise GRACE的等效的厚度 {level=1 check="8.8"}
格陵兰（$1.7\times10^{6}\ \mathrm{km^{2}}$）在一年失去$150\ \mathrm{Gt}$。求以cm到一位小数的等效的水的厚度的改变。
::: solution
$1.5\times10^{14}\ \mathrm{kg}/(1.7\times10^{12}\ \mathrm{m^{2}}\times1000) = 0.088\ \mathrm{m} = 8.8\ \mathrm{cm}$——GRACE舒适地检测的数（它的月的噪声在这个标度是几厘米）、这精确是为什么技术的极限不是精度、发表的支配的**系统**（回弹、从邻接的质量的泄漏）。

::: exercise 特征跟踪的速度 {level=1 check="94"}

::: solution
$50\times30/16 = 94\ \mathrm{m\,day^{-1}}$——一个快的是的潮的冰川的步、从一个看起来静止的景观的两个的快照恢复。学科的单位的纪律在这里重要：乘给出$3.4\times10^{4}\ \mathrm{m\,yr^{-1}}$、每天的误引为每年是一个"冰川赛跑进海洋"的流行的析的最顽固的错误之一。

::: exercise 雷达的双向的时间 {level=2 check="23.7"}

::: solution

::: exercise 逆的方差的组合 {level=2 check="22"}
三个方法以一个$60$、$40$、$30\ \mathrm{Gt\,yr^{-1}}$的不确定性估计一个质量的平衡。求以$\mathrm{Gt\,yr^{-1}}$到最接近的整数的逆的方差的加权的均值的确定性。
::: solution
$1/\sigma^{2} = 1/3600 + 1/1600 + 1/900 = 2.01\times10^{-3}$、$\sigma = 22\ \mathrm{Gt\,yr^{-1}}$——比任何单一的方法好、最优的组合要求。填满IMBIE的方法的部分的警告：公式假设**独立的**误差、整个的学科关于共享的粒雪的模型、共享的速度的产品、共享的回弹的校正的诚实是保持公式做的承诺的尝试。

::: exercise 通量的方法、诚实地 {level=3 check="-500"}
一个集水区获得$400\ \mathrm{Gt\,yr^{-1}}$的积累、失去$550$给径流、$350$给崩解。求以$\mathrm{Gt\,yr^{-1}}$的通量的方法的质量的平衡。
::: solution
$400 - 550 - 350 = -500\ \mathrm{Gt\,yr^{-1}}$。数对任何真实的集水区不可信的、练习的教学：通量的预算通过**几何**（错的分水的岭、错过的近岸的融化、重复计算的邻居）失败比通过算术得多、预算的科学的工作的规则是当方法以几百吉吨不一致、你在出版均值之前审计**边界**。
:::

::: exercise 雪的密度的杠杆 {level=3 check="27"}
当雪的密度的模型修订时、北极的海冰的体积的估计落下约10百分之一。若老的密度是$320\ \mathrm{kg\,m^{-3}}$、厚度以$H \propto (f - \rho_s d_s/(\rho_w-\rho_i))$成比例、以$f = 1.2\ \mathrm{m}$、$d_s = 0.3\ \mathrm{m}$、求一个$30\ \mathrm{kg\,m^{-3}}$的密度的减少暗示的$H$的分数的改变。
::: solution
降低的项从$320\times0.3/108 = 0.889$变到$290\times0.3/108 = 0.806\ \mathrm{m}$；$H$从$(1.2-0.889) = 0.311$变到$0.394$在括号的单位——一个9百分之一的密度的改变的$27$百分之一的增加。杠杆是课：在漂浮的极限附近、辅助参数的小误差会变成产品的大误差、这就是为什么海冰的学派的2010年代引用最多的论文关于**雪**、不是激光。
:::
