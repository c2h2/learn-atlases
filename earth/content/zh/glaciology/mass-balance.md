在1894年、的苏黎世的国际的地质的大会创建了国际的冰川的委员会、它的原始的监测的冰川的名单仍然定义这个领域的基线、一个世纪之后它的后代网络、WGMS、报告它的创始者用竹的标尺与一个的水平的测量测量的同一个量：世界的冰川是在吃、在饿。那个量、**的质量的平衡**、是冷的圈产生的最直接的气候的信号——一个沉积的雪、破坏的冰的每年的账本、以每平方米的毫米的水的等效读出——过去三十年的读数是不含糊的：世界的参考的冰川自2000年以来**每年**失去约一米的水的等效、所有的山地的冰川与冰的帽的总和现在每十年贡献给海平面约和格陵兰的表面的融化一样多。的质量的平衡也是科学的最难的测量、因为一个冰川的预算必定在几公里的裂隙的、雪崩的、卫星不可见的地形上求和——然后外推到没有一个人访问的99百分之一的冰川。

## 账本：积累、消融、平衡的线

::: definition 质量的平衡与它的单位 {#def-mass-balance}
一个冰川的年的质量平衡$B$是积累减消融、以**水等效**的米（m w.e.）在一个点或在一个冰川上平均；一个带$B > 0$的冰川变厚、带$B < 0$变薄、一个在气候的平衡的一个冰川在它的面积上平均有$B = 0$。积累是存活到下一个秋天的雪（加的凇、的霜、冻结的雨）；消融是表面的融化、的崩解、的底的融化与的升华。冰川垂直地组织它的平衡：的上部总是正的、下部总是负的、**平衡的线（ELA）**分开它们。两个导出的数携带大部分的气候的信息。**平衡的梯度**$\mathrm{d}B/\mathrm{d}z$——中的纬度的冰川典型地$5$–$10\ \mathrm{mm\,w.e.\,m^{-1}\,yr^{-1}}$、因为温度与雪线都随高度改变——测量预算对一个的海拔的移动响应得多强、对气候的移动响应得多强：一个$+1\ ^\circ\mathrm{C}$的变暖使ELA上升$100$–$200\ \mathrm{m}$、在一个$7\ \mathrm{mm\,m^{-1}}$的梯度上从消融的区的整体每年移除$0.7$–$1.4\ \mathrm{m\,w.e.}$。**的积累区的比（AAR）**、冰川在积累的区的分数、在平衡的中的纬度的冰川坐在约$0.6$–$0.7$、未来的速览的诊断：一个0.3的八月的AAR、这个十年在世界的冰川的大部分观察到的、是一个说*撤退*的账本、在读取一个的标尺之前写下。
:::

::: proposition 平衡的梯度与一个冰川的灵敏度 {#prop-sensitivity}
一个冰川的平衡的几何由平衡的剖面设定：ELA坐在面积的加权的平均的平衡消失的地方、ELA对气候的**灵敏度**是平衡的梯度的倒数、
$$
\frac{\partial z_{\mathrm{ELA}}}{\partial B_{\mathrm{mean}}} = \left(\frac{\mathrm{d}B}{\mathrm{d}z}\right)^{-1} .
$$
在一个的扰动之后恢复平衡的反馈是纯的几何的：变暖使ELA上升、它缩小积累的区、扩大（更低的、更暖的、融化得更快的）消融的区、加深的赤字、直到冰川向坡上撤退得足够、它剩余的面积坐在足够高、足够冷以再次平衡。两个后果支配气候变化之下的冰川的行为。**床比它的表面更陡**的冰川——大部分的谷的冰川——有大的平衡的梯度、由此是快的、敏感的：它们以几十年的滞后记录气候。在平的床的冰川——冰盖的出口的冰川、南极的冰的流——有微小的梯度、使一个谷的冰川在一代人之内缩小的同样的变暖能使它们几个世纪准稳定、然后使它们崩溃、因为它们的平衡不由表面的融化设定、由边缘的**的通量的排放的动力学**设定、它没有稳定的梯度。这是海平面的问题不是"冰川在融化"、冰盖的**动力学**的深的原因：表面的质量的平衡的系统自我限制；通量的排放的系统不。
:::

::: example 阅读一个平衡的剖面 {#ex-profile}
一个冰川的测量的平衡的剖面是$B(z) = 0.007\,(z - z_{\mathrm{ELA}})$、以m w.e. yr⁻¹、$z$以米。若变暖使ELA上升$200\ \mathrm{m}$、冰川仍然均匀地占据$1800$–$2600\ \mathrm{m}$的面积、求平均的平衡、暗示的变薄的速率。
::: solution
在一个固定的几何的平均的平衡成为$\bar B = 0.007\times(-200) = -1.4\ \mathrm{m\,w.e.\,yr^{-1}}$、所以冰川在它的面积上平均每年失去$1.4\ \mathrm{m}$的冰的厚度（约$1.5\ \mathrm{m}$的冰）。真实的冰川响应：的末端撤退、面积的分布向坡上移动、平均的赤字在响应的时标松弛——但练习捕获为什么一个$+1\ ^\circ\mathrm{C}$的十年在全球的均值产生每米的年的损失、为什么本世纪的阿尔卑斯、挪威与高加索的冰川的观察的变薄的速率（每年0.5–1.5米）正是这个算术。
:::
:::

## 能的平衡：为什么冰在它的地方融化

::: definition 表面的能的平衡 {#def-energy-balance}
融化是能量、不是温度的一个的记账的问题：可用于融化雪或冰的热是表面的能的平衡
$$
Q^{*} = (1-\alpha)K^{\downarrow} + L^{\downarrow} - L^{\uparrow} + H + LE + G ,
$$
吸收的短波（反照率$\alpha$：0.85的新雪、0.4的裸露的冰、0.1的脏的冰）、净的长波（通常$-30$到$-70\ \mathrm{W\,m^{-2}}$、冰在冷的、干的空气之下把热辐射掉）、的湍流的感的热与的潜的热、一个小的导热的通量$G$。雪被的绝缘使下面的冰保持在接近零的年的均值、所以$Q^{*}$以每千克$334\ \mathrm{kJ}$直接积分成融化。实际的主力是**的度-日的模型**：融化与的累积的结冰的以上的天数成正比、$M = \mathrm{DDF}\times\mathrm{PDD}$、雪的度-日的因子是$5$–$20\ \mathrm{mm\,^\circ C^{-1}\,d^{-1}}$、冰的是$25$–$45$——因子的散布编码辐射的项做的、空气的温度仅仅见证的所有的东西。三个的机制使教科书复杂。**海洋性的冰川**主要在云与雨之下、由湍流的热融化、能在零之下的空气的温度融化。**大陆的与的高的山的冰川**是辐射与湿度驱动的、那里**的升华**——在湿的空气输送融化的同样的潜的项——能直接把米的冰的等效移除到干的空气、所以在的安第斯与西藏最大的冰川生在的渣与的尘、不是雪、由尘与升华的消融超过融化。**的渣覆盖的冰川**（的喜马拉雅的消融的面积的四分之一）在的渣超过几厘米的地方绝缘、在更薄的地方加速、"的无菌的覆盖"的效果使最高的渣覆盖的冰对夏季的太阳几乎免疫、阿尔卑斯的冰川的薄的尘的斑块值几十个百分点的更多的融化。
:::

::: example 升华、看不见的消融 {#ex-sublimation}
在一个$5000\ \mathrm{m}$的高的安的斯冰川、测量的年的表面的降低是$1.2\ \mathrm{m}$的冰、它的融化占$0.5\ \mathrm{m}$。求以$\mathrm{kg\,m^{-2}\,yr^{-1}}$的升华的速率、它暗示的平均的潜的热的通量（的升华的潜的热$2.83\ \mathrm{MJ\,kg^{-1}}$）、解释为什么这样的冰川作为的尘结束它们的日子。
::: solution
升华的冰是$0.7\ \mathrm{m}\times917 = 640\ \mathrm{kg\,m^{-2}\,yr^{-1}}$、暗示一个平均的潜的通量
$$
\frac{640\times2.83\times10^{6}}{3.15\times10^{7}} = 57\ \mathrm{W\,m^{-2}}
$$
全年进入干的、有风的空气——比大部分的温带的冰川的整个的夏季的融化的通量更大。升华留下每一个的杂质：的尘、的火的山的灰与的黑的碳在表面浓缩成一个**的尘的层**、随着冰在它之下升华出来而变厚、直到冰川的下部是几十分米的渣之下的冰的一个薄的壳——一个自我限制的消融的机制、高的安的斯与的喜马拉雅的冰川的撤退看起来像一个的石的场的生长、不是冰的缩小的理由。
:::
:::

## 测量账本

::: definition 称一个冰川的三个方法 {#def-measuring}
**冰川学的方法**——流动的标尺、积累的雪坑、损失的消融的标尺与融化的管、每年读取、以海拔在一个冰川上插值——是直接的测量、标定的标准、自Ahlmann的时代保持在约120个参考的冰川；它的错误是局部的（雪崩的区、尘、裂隙）、它致命的弱点是它测量我们能到达的冰川。**的大地测量的方法**差分从航空的摄影测量（几十年的）、SPOT-5（2000年代）、TanDEM-X、ICESat/ICESat-2的测高的数字的高程的模型、测量整个的冰川化的区域的体积的改变而不访问它们；转换成质量需要密度的假设（变薄的雪与冰约$850\ \mathrm{kg\,m^{-3}}$、不是$917$）、两个方法现在在两者测量的每个区域在它们的误差的条之内一致、使全球的数可信的交叉的验证。**GRACE与GRACE-FO**的重力以$300\ \mathrm{km}$的分辨率每月称整个的区域（冰盖、阿拉斯加、的亚洲的高地）、它的后代的产品、与从卫星的干涉的流动的速度结合、给出**通量的排放的方法**：质量的改变=在一个的接地的线之上的流入减流出、对一个崩解的冰川、从未见到一个标尺的冰川工作的唯一的方法。的综合——区域的标度、方法的之间的标定——海平面的预算引用的数：山地的冰川与冰的帽在2000–2019平均失去$267\ \mathrm{Gt\,yr^{-1}}$、贡献给海平面$0.74\ \mathrm{mm\,yr^{-1}}$、总的上升的超过四分之一。
:::

::: example 从重力到海平面 {#ex-grace}
GRACE测量格陵兰的表面平衡的$150\ \mathrm{Gt\,yr^{-1}}$的质量的损失。转换成每年的毫米的海平面的上升（海洋的面积$3.61\times10^{8}\ \mathrm{km^{2}}$）、解释为什么观察的总的格陵兰的贡献比这个表面的数字单独更大。
::: solution
$$
\Delta h = \frac{150\times10^{12}\ \mathrm{kg}}{3.61\times10^{14}\ \mathrm{m^{2}}\times1025\ \mathrm{kg\,m^{-3}}} = 4.1\times10^{-4}\ \mathrm{m} = 0.41\ \mathrm{mm\,yr^{-1}} .
$$
总的格陵兰的贡献更高、因为表面的平衡只是账本的一半：另一半是**动力学的排放**——在海洋的边缘作为的冰山失去的冰、在1990年代–2000年代随着变暖的海洋使支持的漂浮的舌变薄而加倍。一个的流出由在一个的崩解的前缘、在任何地方的100公里之外的海洋的温度设定的冰川的系统不是一个表面的融化的系统、任何的粒雪的数据不会告诉你它的预算：这是冰盖的标度的质量平衡的课、格陵兰与南极同时由雷达的测高、干涉与重力监测的理由。
:::
:::

## 响应的时间：隐藏未来的滞后

::: definition 响应的时间与承诺的撤退 {#def-response}
一个冰川是一个厚的、慢的系统：它的**响应的时间**——在一个气候的阶跃之后它接近一个新的平衡的区间——与厚度除以平衡成正比、$\tau \sim H(1+f)/a$（Paterson的规则、以$f \approx 0.6$考虑速度的剖面）、小的阿尔卑斯的冰川几十年、大的谷的冰川与的潮的冰川几个世纪、**冰盖10 000–100 000年**。后果是冰川科学里最误读的三个陈述。**滞后**：世界的冰川的大部分仍在从几十年前结束的变暖撤退、承诺失去它们现在的体积的进一步的20–50百分之一、即使气候在2020年的值冻结——"承诺的撤退"不是一个预报、一个已经做出的记账的条目。**的非平衡的几何**：一个的末端撤退进一个深的超深的盆的、一个稳定的床的阶之下的冰川、今天可能只是稳定、因为它还没有完成对上一个世纪的响应。**小的冰川的曲棍球的棒**：因为响应的时间与厚度成正比、支配世界的冰川的**数目**的小的冰川（它们的95百分之一在一个平方公里之下）在一个人的寿命之内响应——这就是为什么喜马拉雅、安第斯与东非的小的冰川在政策的时标消失、控制米的海平面的系统在文明的时标响应。
:::

::: example Paterson的规则的工作 {#ex-response}
求（a）一个$100\ \mathrm{m}$厚的阿尔卑斯的冰川、在它的ELA$1500\ \mathrm{mm\,w.e.\,yr^{-1}}$的积累、（b）一个$2000\ \mathrm{m}$厚的南极的冰的流的集水的$300\ \mathrm{mm}$的积累的响应的时间。的比对它们的损失的归因暗示什么？
::: solution
以$f = 0.6$：（a）$\tau = 100\times1.6/1.5 = 107$年；（b）$\tau = 2000\times1.6/0.3 = 10{,}700$年。三个数量级分开两者：阿尔卑斯的冰川在它的1980年之后的平衡的一二十年之内、所以它的最近的损失**归因于最近的变暖**、几乎没有滞后的混淆、南极的集水区在响应最后的退冰——它现在的变薄可能主要是的更新世的转变的**长的告别**、带人为的信号叠加在一个自然的松弛上、它花一千年演出。分开两者是冰盖的归因的中心的问题、"南极在失去质量因为它现在在变暖"需要上一节的通量的测量、不是温度的记录、以是可辩护的。
:::
:::

::: warning 负的平衡不是撤退、ELA不是固定的、GRACE不"测量融化"
五个错误。**一个冰川能有负的平衡、推进**——斯瓦尔巴与阿拉斯加的脉动型冰川在失去质量时在几十年的循环推进、许多的渣覆盖的冰川停滞（就地变薄）、完全不撤退它们的渣标记的末端；平衡、面积的改变、长度的改变是三个不同的滞后、三个不同的信号。**ELA不是一个固定的参考的线**：它每°C移动100–200米、在干的与湿的年份之间几百米、在不考虑调查的夏季的ELA的情况下比较几十年的冰川的面积、历史的照片的比较的最常见的错误。**GRACE测量重力、不是融化**：它的信号是包括地下水的总的水柱的质量的改变、格陵兰的数必定与基岩的退冰后的回弹、与排放分开；从GRACE引用的"表面的平衡"的数字是模型的输出、不是测量。**度-日的因子不是常数**：在一个干净的海洋性的冰川标定的一个DDF在渣覆盖的或升华支配的冰上以二的倍失败、把一个度-日的模型降尺度到一个高的起伏而不带一个辐射的项、是21世纪初的预报把亚洲的高地的损失低估一半的方式。**质量平衡对冰盖不是海平面的全部的故事**：表面的平衡、排放、盆的均衡的调整都进入、"格陵兰在失去每年270 Gt"的标题是**三个测量的项的和**、它的单独的每一个的不确定是总的三分之一。
:::

F. (Wilfrid) Paterson**的《The Physics of Glaciers》（1981）设定了响应的时间的标度、材料科学；WGMS的《Glacier Mass Balance》的综合的卷追踪全球的信号、卫星的时代——第一个GRACE的冰盖的重量（2002–）、TanDEM-X的12米的全球的DEM（2010–）、**ICESat-2**（2018）——把这个领域从一个标尺与雪坑的学科变成一个行星的学科。**全球冰川的改变的公报**（2018–）现在每年报告账本、2019–2024年的安第斯与喜马拉雅的考察队显示亚洲的高地的小的冰川比网络曾经监测的任何区域失去质量更快。

::: summary
- 质量平衡——以m w.e. yr⁻¹的积累减消融——是冰川的气候的账本；ELA分开它的两个符号、平衡的梯度（5–10 mm m⁻¹ yr⁻¹）是冰川的气候的灵敏度。
- +1 °C的变暖使ELA上升100–200米、从消融的区移除约1 m w.e. yr⁻¹——全球的变薄的速率背后的算术。
- 融化是能量限制的：辐射、湍流的热、（在干的山地）升华、以雪的5–20、冰的25–45 mm °C⁻¹ d⁻¹的度-日的因子实际地总结。
- 三个方法称冰——标尺（冰川学的）、DEM的差分（大地测量的）、重力与通量的门——它们在误差之内一致；冰川与冰的帽现在失去约每年267 Gt、海平面上升的四分之一。
- 响应的时间与厚度/平衡成正比：小的冰川几十年（20–50百分之一的承诺的撤退已经记账）、冰盖10⁴–10⁵年、它现在的损失混合人为的强迫、千年的标度的调整。
- 平衡、面积、长度是三个滞后、三个信号；阅读一个冰川的未来需要它的几何、它的梯度、它的适合的方法的测量。
:::

## 练习题

::: exercise 水的等效 {level=1 check="1.83"}
一个冰川失去$2.0\ \mathrm{m}$的密度$917\ \mathrm{kg\,m^{-3}}$的冰。求以m w.e.的损失。
::: solution
$2.0\times917/1000 = 1.83\ \mathrm{m}$的水的等效。转换是这个领域最小的、使用最多的算术：以**冰**的米、不是水的等效引用的质量平衡的数字使账本高估9百分之一、文献的标准是水。
:::
:::

::: exercise 度-日的融化 {level=1 check="15"}
一个夏季在一个裸露的冰积累$500$的正的度-日、$\mathrm{DDF} = 30\ \mathrm{mm\,^\circ C^{-1}\,d^{-1}}$。求以米的融化。
::: solution
$M = 30\times500 = 15{,}000\ \mathrm{mm} = 15\ \mathrm{m}$的冰的等效——使格陵兰的裸露的冰的区域产生河流与湖泊的夏季的总的、一个温暖的、晴朗的、有风的周能输送它的十分之一的。
:::
:::

::: exercise GRACE到海平面 {level=1 check="0.74"}
山地的冰川失去$267\ \mathrm{Gt\,yr^{-1}}$。求以每年的毫米的海平面的贡献（海洋的面积$3.61\times10^{8}\ \mathrm{km^{2}}$、水的密度$1025\ \mathrm{kg\,m^{-3}}$）。
::: solution
$267\times10^{12}/(3.61\times10^{14}\times1025) = 0.72\times10^{-3}\ \mathrm{m} = 0.72\ \mathrm{mm\,yr^{-1}}$——发表的数值、在的壳的水的存储的小的改正之后、是$0.74$。记住的转换的因子：$361\ \mathrm{Gt}$的冰的融化是$1.0\ \mathrm{mm}$的海平面。
:::
:::

::: exercise ELA的移动与平衡 {level=2 check="-1.05"}
以平衡的梯度$7\ \mathrm{mm\,m^{-1}\,yr^{-1}}$、求一个$150\ \mathrm{m}$的ELA的上升在一个固定的几何的平均的平衡的改变（m w.e. yr⁻¹）。
::: solution
$\Delta\bar B = -0.007\times150 = -1.05\ \mathrm{m\,w.e.\,yr^{-1}}$。冰川将通过向坡上缩小部分地恢复、但瞬时的打击是每年超过一米——与健康的参考的冰川的总的年的平衡可比、这就是为什么一个每年的米全球的均值是一个远离平衡的冰川的群体的签名。
:::
:::

::: exercise 净的辐射的融化 {level=2 check="25"}
裸露的冰川的冰在夏季吸收一个净的$90\ \mathrm{W\,m^{-2}}$。求以每天的毫米的水的等效的融化的速率（$\rho L = 3.06\times10^{8}\ \mathrm{J\,m^{-3}}$）。
::: solution
$90\times86{,}400/3.06\times10^{8} = 0.025\ \mathrm{m} = 25\ \mathrm{mm\,day^{-1}}$。晴朗的天空之下的干净的冰单独由辐射每周融化约四分之一米；一个温带的冰川的消融的区由正是这个量级的夏季的通量建造、曾经覆盖它的雪——带它的0.85的反照率——决定账本平衡的年份。
:::
:::

::: exercise Paterson的标度 {level=2 check="160"}
求一个$150\ \mathrm{m}$厚的冰川、ELA积累$1.5\ \mathrm{m\,w.e.\,yr^{-1}}$的响应的时间（年、Paterson的规则、$f = 0.6$）。
::: solution
$\tau = 150\times1.6/1.5 = 160$年。一个这个大小的、最后一次在1960年代平衡的冰川仍在调整1990年代的移动——这就是为什么本世纪的阿尔卑斯的冰川的撤退部分地**承诺**、的小的冰期的新冰川的"最大的冰川的范围"现在以一个任何天气不能解释的速率失去。
:::
:::

::: exercise 平衡的比 {level=3 check="0.6"}
一个在平衡的冰川在它的积累的面积有平均的积累$+1.8\ \mathrm{m\,w.e.}$、在它的消融的面积平均的消融$-2.7\ \mathrm{m\,w.e.}$。求暗示的积累区的分数（平衡的AAR）。
::: solution
平衡要求$A_c\times1.8 = (1-A_c)\times2.7$、所以$A_c = 2.7/4.5 = 0.6$。在0.6附近的平衡的AAR——积累的区以每平方米少三分之一的功在三分之一更多的面积上——全世界观察的0.3的八月的AAR那么定罪的理由：它们暗示冰川在预算的术语已经在它的平衡的面积的大约**一半**、地图最终将与账本一致。
:::
:::

::: exercise 承诺的撤退 {level=3 check="0.2"}
一个冰川的群体持有$100\ \mathrm{Gt}$的冰、它的$40\ \mathrm{Gt}$承诺在现在的气候失去。若那个承诺的异常以一个200年的响应的时间指数的松弛、求以$\mathrm{Gt\,yr^{-1}}$的初始的松弛的速率。
::: solution
一个指数的松弛的初始的速率是异常除以时间的常数：$40/200 = 0.2\ \mathrm{Gt\,yr^{-1}}$。若群体实际上观察失去每年$2.5\ \mathrm{Gt}$、承诺的调整解释现在的损失的不到十分之一、其余由**正在进行的**变暖、不是的遗产驱动。练习是承诺的损失的文献的一个的模板：响应的时间、现在的速率、承诺的体积是三个数、它的只有两个能自由地选择、每个"承诺到X米的海平面"的标题是其中一个在求解。
:::
