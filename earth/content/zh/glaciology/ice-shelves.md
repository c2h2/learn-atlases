在2002年1月31日与3月7日之间、一个的德拉威的大小的冰的架四分五裂。Larsen B冰的架站立过——也许一万二千年、自最后的去冰作用——作为一个比德拉威大的700米厚的冰的筏、支持着一百个应该流向海洋的冰川。在2002年、在一个温暖的南半球的夏季、融的水的池塘打开了冻结关闭几千年的裂缝、裂缝跑、在35天$3{,}250\ \mathrm{km^{2}}$的架崩解成一个船不能跨过它的一个如此密集的冰山场。在五年之内它后面的冰川使它们的速度加倍、它们的集水区开始变薄、海平面的信号开始。Larsen B的崩溃把冰的架的问题从南极的地理的一个的好奇变成海平面的科学的中心的动力学的问题、因为它在大陆的标度、在人类的时标证明这个课关于的原则：**漂浮的冰融化时不举起海平面、但它支持着确实举起的冰**——支持能因与冰的强度无关的理由失败。

## 架是什么、它们做什么

::: definition 漂浮的边缘 {#def-shelf-function}
一个冰的架是一个永久的漂浮的冰的平台、由冰川与雪喂养、由崩解与底的融化失去、从几米到超过$1000\ \mathrm{m}$厚、从几十平方公里到罗斯冰的架的$487{,}000$——一个比西班牙大一半的面积。南极的架总和$\sim 1.5\times10^{6}\ \mathrm{km^{2}}$——一个比阿拉斯加大的面积——它们做三个工作。它们**支持**：[[glaciology/ice-flow]]析的膜的力与边缘的拖把一个后应力传递给接地的线、它能抵消一个冰川的驱动应力的一半或更多、节流排放。它们**设定崩解的图案**：一个宽的、限制的架在它的外面的正面以缓慢的、规则的冰山的季节失效；一个窄的、不限制的灾难地失效。它们**武装海岸线**：架吸收海洋的涌浪、冰的混合物——的碎冰、冰山与海冰的僵硬的塞车、填满许多的峡的口——在峡的标度供应同样的支持、一个几百米厚的混合物压对着一个末端能像一个岩石的槛一样有效地支持一个冰川。第一个工作的定量的陈述是这本图集使用的标度：后应力$\sim \tau_c L/P$（边缘的强度 × 长度 ÷ 宽度）、这就是为什么**窄的湾的窄的、陡的架的冰建造的最强的刹车**、为什么它们的失去——Larsen A 1995、Larsen B 2002、的Wilkins 2008、从Larsen C的变弱的裂缝的$5{,}800\ \mathrm{km^{2}}$的冰山A-68的2017年的崩解——每次跟随以以月测量的冰川的加速。
:::

::: example 刹车的账本 {#ex-brakeledger}
一个$250\ \mathrm{km}$长、$50\ \mathrm{km}$宽的、带的边缘的拖$\tau_c = 40\ \mathrm{kPa}$的架支持一个接地的线的驱动应力$100\ \mathrm{kPa}$的冰川。求后应力的容量$\tau_c L/P$、注意系统稳定在边缘能携带的最大的后应力（这里、观察的类似的几何抵消驱动的约70百分之一）、求若架的变薄使后应力减半的通量的改变、取通量$\propto \tau^{3}$（滑动的限制的）。
::: solution
容量是$\sigma_b = \tau_c L/P = 4\times10^{4}\times250/50 = 200\ \mathrm{kPa}$——比驱动应力自己多、这就是为什么限制的架如此完全地支持它们的冰川；取操作的后应力在抵消的70百分之一的观察的类似。使它减半提高有效的驱动应力从$30$到$80\ \mathrm{kPa}$、一个因子$2.7$、通量以$2.7^{3} \approx 20$。算术故意残酷、因为观察是：Larsen B之后的崩溃的加速（× 2–10）、一个完全不支持的Thwaites的建模的响应（× 几到× 10）、住在这个范围。架不是一堵墙、一个**带的三次的踏板的节流**。
:::
:::

## 架如何死

::: definition 三个失效的模式 {#def-failure}
架以**表面的水**、**海洋的水**、**几何**失效。**的水的断裂**：融的水的池塘——现在覆盖Larsen与的Wilkins的架、在极端的夏季、罗斯的斑块——把水的位填满现有的裂隙、因为水传递它全部的重量给裂缝的尖、一个水的填充的裂隙传播到一个干的达到的深度的约1.3的倍、一旦水到达漂浮驱动的底的裂缝、架切成块、崩解、翻覆、粉碎：Larsen B的序列——池塘、的裂谷、在几周的崩解——**Chris Scambos**与同事在2009年通过阅读事件自己的图像发现机制。**海洋的融化**：暖的水的质量（阿蒙森的架的绕极的深的水、在一个变暖的世界逐渐地更浅的水的质量）攻击底部、使架变薄、提高它的正面、使它的钉住的点不接地、缩小它的范围——慢的模式、在阿蒙森的海以每年的几十米的冰运行、使Larsen C的冰的舌变薄足够让2017年的A-68的裂缝传播。**裂谷与混合物的失效**：裂谷以潮的弯曲与融的水增长、当一个裂谷穿过一个冰的舌、架在一天崩解一个县的大小的冰山；在峡的标度、混合物——从北极自己的撤退的更薄、更弱的海冰变弱——停止压、冰川在季节之内加速、在混合物在2010年代变薄约70百分之一之后雅各布港。三个模式互动：海洋的融化使变薄、不限制、它让池塘扩展、它断裂、它移除刹车——一个**的级联**、它的终态、对南极的半岛的架的系统、是建模、半岛自己的全新世的历史都显示在$+4\ ^\circ\mathrm{C}$的区域变暖稳定的无冰的配置、半岛已经达到一个水平。
:::

::: example 一个架的稳态的预算 {#ex-shelfbudget}
一个架以$2000\ \mathrm{m\,yr^{-1}}$的冰的流喂养、跨过$250\ \mathrm{km}$从接地的线到崩解的正面、从接地的$800\ \mathrm{m}$变薄到正面的$200\ \mathrm{m}$、获得$300\ \mathrm{mm\,w.e.\,yr^{-1}}$的雪。求深度的平均的底的融化的速率、假设稳态。
::: solution
在稳态、在架平均的厚度的预算是
$
u\,\frac{\Delta H}{L} = a + b ,
$
以$\Delta H/L = 600/2.5\times10^{5} = 2.4\times10^{-3}$、所以通量的发散移除$2000\times2.4\times10^{-3} = 4.8\ \mathrm{m\,yr^{-1}}$的冰。的降雪返回$0.3$、平衡——$4.8 - 0.3 = 4.5\ \mathrm{m\,yr^{-1}}$——必须是底的融化、在整个的架平均。数是架的科学安静的丑闻：一个健康的、"稳定的"大的架从下面以每年的米**不可见地**融化、在几万平方公里之下、只有2000年代卫星的激光与雷达的测高测量的变薄的速率显示哪个架的这个数被暖的水向上推——阿蒙森的架、同样的预算现在在接地的线附近以每年的几十米平衡。
:::
:::

::: example 从图像阅读一个崩溃 {#ex-larsenb}
Larsen B的剩余的架（$3{,}250\ \mathrm{km^{2}}$）在35天崩解、产生一个平均$50\ \mathrm{m}$厚的块的碎片场。估计平均的每天的面积的损失、平均的每天的体积的损失、解释事件的以海平面的贡献为什么**间接的**——它为什么成为冰川学的现代的历史的最重要的间接的事件。
::: solution
$3250/35 = 93\ \mathrm{km^{2}\,day^{-1}}$；体积$93\times0.05 = 4.6\ \mathrm{km^{3}\,day^{-1}}$的冰——一个莱茵的排放的二十的倍的流量每天一个月、**零**直接的海平面的上升（阿基米德：架已经在漂浮）。贡献来自之后：架后面的一百多个冰川加速二的倍到十的倍、它们的集水区变薄、区域从大致平衡到失去约$10\ \mathrm{Gt\,yr^{-1}}$——真正的海平面、从一个漂浮的架的死亡、带着年的延迟到达。那个延迟是Larsen B的教学的力量：它端到端地证明**支持→排放→海平面**的链、在卫星的记录、在实时、它自每个架的损失的场景——的Wilkins、的乔治六世、的Ronne-Filchner的思想的实验——阅读的模板。
:::
:::

## 模型的支持、地图的不稳定

::: proposition 架的崩溃的不稳定的链 {#prop-chain}
链——架的失去→加速→变薄→接地的线的撤退→进一步的失去——是一个真正的**正的反馈**、它的地理是海平面的风险的地图。最强的现实的支**冰的升**：在一个架在一个的浅滩接地（罗斯的罗斯福的岛、的Berkner的岛的升、Thwaites的东的冰的升）、钉住的点集中后应力、能单独支持一个冰川的节流；卫星的雷达测量Thwaites的东的钉住的点在2000年代–2010年代接地的线过它撤退时**失去接触**、模型实验说先于几十年的加速的一个事件。然而反馈由物理限制、界限对预报重要：一个**相对于它的喂养的冰川宽**的架在它变薄时再生支持（膜的力与厚度的平方成比例、湾的壁保留）、一个**窄的、短的**的舌——半岛的类型——变薄到失效。产生多米的2100的预报的**DeConto–Pollard**的实验通过假设半岛类型的级联传播到整个阿蒙森的海、然后到东南极的崖的顶的海洋的边缘做到；同样的模型、不带崖的失效运行、回到主流的一米到两米的范围。争论不是关于数据、关于**本世纪的海洋留下站立的哪个架的几何**——这就是为什么架的底的融化的学派现在给腔安装仪器（热的水的钻孔、水下的滑翔的机与的测温的阵的列通过600米的冰、英国-美国的在Pine Island与Thwaites的2012–2019的项目）作为建造的最直接的早的海平面的警告的系统。
:::

::: widget plot
f: 1.25*x
x: 0, 300
y: 0, 400
labels: \sigma_b\ (\mathrm{kPa})
caption: 对一个40公里宽的湾带$40\ \mathrm{kPa}$的边缘的拖的后应力对着架的长度（$\sigma_b = \tau_c L/P$）。线说一个200公里长的在一个窄的湾的架输送一个与它后面的冰川的整个的驱动应力可比的后应力——同样的冰在一个宽的、不限制的湾几乎什么都不输送。几何、不是大小、是命运：Larsen的剩余、200公里长、50公里宽、比罗斯一个更强的刹车、罗斯比法国大、但只对着它的跨南极的剪的边缘不限制地流动。
:::

## 架的未来

::: definition 预报与早的警告的几何 {#def-future}
耦合的气候-冰的模型对架的**底的融化**比关于表面的融化分歧得多得多、因为海洋的项依赖粗的模型在符号、量级弄错的区域的环流；一致的结构仍然清楚。在高的排放之下、阿蒙森的海的架（Pine Island、Thwaites）在大多数的模型在2100失去它们的支持的大部分、带完全的阿蒙森的崩溃（约$1.2\ \mathrm{m}$）的几个世纪的承诺有效地记账；的Ronne-Filchner——最大的剩余的刹车、支持着的支持的力与的基础的冰的流、一起另一个约$1.7\ \mathrm{m}$——坐在一个变深到$3\ \mathrm{km}$的床、一半的模型预报它本世纪开始撤退；半岛的剩余的架（Larsen C、的乔治六世、的Bach）在$+4\ ^\circ\mathrm{C}$的区域变暖的失效的包络、高的路径在2060达到。**早的警告的可观测量**不是空气的温度、几何：架的面积与正面的位置（卫星的光学的）、表面的池塘的范围（光学的、的水的断裂的就绪的信号）、冰的厚度（ICESat-2与的BedMachine的重建）、裂谷的传播（跨过Larsen C的175公里的裂缝、自2014观看）、钉住的点的接地的线的位置（雷达）、腔的水的温度（的系泊的阵的列）。每个现在是一个操作的、公开报告的量——地质的历史的一个地质的结构的失效提前安装仪器的第一次——诚实的总结是架不会像玻璃失效、像一个**日程的问题**：海洋先到达哪个几何、表面的水是否到达以完成工作。
:::

::: example 混合物的开关 {#ex-melange}
雅各布港的峡的混合物在2000与2016之间变薄70百分之一、冰川的速度上升约50百分之一。用混合物的后应力的标度$\sigma_m \propto H_m^{0.7}$（观察的关系）、求后应力的改变、评估若混合物一直供应$25\ \mathrm{kPa}$对着一个$100\ \mathrm{kPa}$的驱动应力、它的失去能否解释加速。
::: solution
$\sigma_m$以$1 - 0.3^{0.7} = 1 - 0.43 = 57$百分之一落下。在$25\ \mathrm{kPa}$的混合物的后应力之上那是$14\ \mathrm{kPa}$的损失、提高有效的驱动应力从$75$到$89\ \mathrm{kPa}$——19百分之一——以三次、大约使通量加倍：与观察的加速一致。混合物的课推广到每个带一个季节的僵硬的混合物的峡的冰川——东南格陵兰的大部分——连接两个看起来无关的北极的改变：**海冰的撤退移除峡的第二个刹车**、这就是为什么格陵兰的出口的冰川现在响应冬季的海冰的范围、以及夏季的融化。
:::
:::

::: warning "冰的架不重要，因为它们漂浮"是气候的科学的最贵的句子——跟随它的五个的警告
五个错误。**阿基米德的真理是真的、无用的**：是的、一个融化的架不举起海平面、是的、那个事实三十年用来争论架是不相关的——当它们全部的功能是支持确实举起的**接地的**冰。**不是所有的架同样地支持**：罗斯、最大的、支持少数的EAIS的内部（它的冰川大部分浅的底的、它自己的流动几乎不限制的）、这就是为什么"但罗斯是稳定的"的安心误读风险的地图——重要的刹车是小的、限制的、阿蒙森与的Ronne的一边的架。**Larsen类型的崩溃对厚的架未证明**：Ronne-Filchner的正面处在200米深的水、700米的厚度、使它落在每个观察的失效案例之外、诚实的陈述是我们有**没有观察的先例**关于一个深的、宽的架如何死——只有模型、它们分歧。**底的融化的速率是冰盖的科学的最不受限制的数**：腔的温度以潮的与的涡的时标变化几度、一个把2010年代的Pine Island的融化弄对的模型可能为一个错的水的质量弄对——架的存活的预报直接继承那个不确定性。**混合物的失去还不是一个证明的气候的趋势**：雅各布港的加速与混合物的变薄、一个变暖的海洋相关、两个原因不干净地分开——峡是一个我们的控制不完全设定的实验、这个学科的谨慎在那里是方法、不是混乱。
:::

::: history
支持的原则由**Thomas Hughes**（1973）与不稳定自己一起陈述、崩溃的加速的第一个观察的证明来自**Eric Rignot**与同事在Larsen B的剩余的冰川（2004）、跟随以**Roland Warner**与的Wilkins的析（2010）、**Rignot、Bindschadler与同事**的半岛全体的加速的综合（2019）。**Chris Scambos**与同事的2009年的水的断裂的论文使融的水的机制半岛的崩溃的标准的解释；175公里的Larsen C的裂谷由**Adrian Luckman**与**Daniela Jansen**的团体在2010年代追踪、2017年的A-68的崩解从裂谷的传播的速率提前几周预报。**Lena Bunge、Heinz Miller**与**H. Fritsch**的2008年的Larsen C的裂谷的系统的雷达的成像的析建立现在用于裂谷的预报的弯曲驱动的断裂的力学。腔的观察的时代由**Keith Nicholls**与英国的南极的调查局的热的水的钻探与的传感器的项目在Pine Island（2012）、美国的西南极的冰盖的观测台的运动（2019、2022–23）在Thwaites开始、把第一个系泊的测温的阵的列放在地球上最重要的架之下。
:::

::: summary
- 架是漂浮的刹车：膜的力、边缘的拖（σ_b ~ τ_c L/P）、钉住的点的后应力能抵消一个冰川的驱动应力的一半或更多；小的限制的架是最强的刹车。
- 它们以的水的断裂（池塘驱动水的填充的裂谷）、海洋的融化（变薄、使钉住解除、使不限制）、裂谷/混合物的失效失效——模式级联。
- Larsen B 2002是证明的链：崩溃→冰川加速2–10的倍→集水区的变薄→真正的海平面的上升、带一个几年的延迟。
- 支持依赖几何：宽的架在它们变薄时再生它、窄的舌不；冰的升与钉住的点集中它、它们的失去先于加速。
- 风险的地图是几何的：阿蒙森的架（Thwaites、Pine Island）先、Ronne-Filchner不确定、无先例、半岛的剩余在+4 °C的失效的包络之内。
- 架的存活现在是一个安装仪器的、可观察的问题——面积、池塘、裂谷、接地的线、腔的温度——一个地质的结构的失效的第一个早的警告的系统。
:::

## 练习题

::: exercise 罗斯的体积 {level=1 check="219000"}
罗斯冰的架覆盖$487{,}000\ \mathrm{km^{2}}$、平均的厚度$450\ \mathrm{m}$。求以$\mathrm{km^{3}}$到最接近的千的体积。
::: solution
$4.87\times10^{5}\times0.45 = 2.19\times10^{5}\ \mathrm{km^{3}}$——$219{,}000$。作为海平面同样的算术给出$219{,}000\times0.917/3.61\times10^{8}\times10^{3} = 0.56\ \mathrm{m}$：罗斯自己是半米的海平面**若它接地**、它不——架的海平面的重要完全是它支持的冰、它多几米。
:::

::: exercise 崩解的通量 {level=1 check="7.5"}
一个$50\ \mathrm{km}$长、$300\ \mathrm{m}$厚的架的正面以$500\ \mathrm{m\,yr^{-1}}$推进、在稳态崩解。求以$\mathrm{km^{3}\,yr^{-1}}$的崩解的通量。
::: solution
$Q = 5\times10^{4}\times300\times500 = 7.5\times10^{9}\ \mathrm{m^{3}\,yr^{-1}} = 7.5\ \mathrm{km^{3}\,yr^{-1}}$。稳态意味着通量等于上游的供应——这就是为什么一个在正面的**加速**（变薄、使钉住解除）立即读成一个不平衡：正面是冰川的收银机、速度 × 厚度 × 宽度是对海平面重要的唯一的审计。
:::

::: exercise 混合物的后应力 {level=2 check="57"}
