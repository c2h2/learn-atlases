辐射强迫是用来比较气候变化各成因的量尺。它用一个数字回答一个问题：这个扰动——一种气体、一团烟云、一片被砍伐的森林、一次火山喷发、十一年的太阳黑子周期——在平流层安定下来之后，把大气顶的收支挪动了多少瓦每平方米？没有这样的量，就无法判定航空、农业和煤炭谁更要紧；有了它，就有了排序、有了一本账、有了一条从排放通到温度的算术。

这个概念同时也是本领域被滥用得最厉害的量，因为"一瓦就是一瓦"的前提是气候对每一瓦的反应相同。事实并非如此。本章的两半都重要：强迫如何计算，以及它的限度在哪里。

## 定义及其订正

::: definition 辐射强迫与有效辐射强迫 {#def-forcing}
某扰动的**辐射强迫**是对流层顶净辐照度（向下减向上）的变化，计算时允许平流层温度调整到辐射平衡，而对流层温度、水汽、云和地表条件保持原值。**有效辐射强迫**（ERF）放宽最后一条，允许云、水汽和直减率在一年之内的快速调整，但仍排除地表温度变化的慢反馈。两者单位都是$\mathrm{W\,m^{-2}}$，都是全球年平均，也都不是温度。
:::

平流层调整不是技术细节。二氧化碳几乎不吸收太阳辐射，但它通过向太空发射红外而冷却平流层；这一层变冷后向下发射减少，这是一笔额外的损失。允许平流层调整，倍增强迫从$4.4$降到$3.7\ \mathrm{W\,m^{-2}}$——自1990年以来每一份评估都计入的$16\%$折减。对某些因子，对流层快速调整更大：对甲烷约增加$15\%$；对沉积在雪面上的黑碳，调整使名义强迫的温度效应翻倍还不止。

::: proposition 闭式强迫公式，以及为什么二氧化碳取对数而甲烷取平方根 {#prop-forcing-formulae}
对充分混合气体，在所关心的范围内，强迫可精确到几个百分点地写成
$$
\Delta F_{\mathrm{CO}_2} = 5.35\ln\frac{C}{C_0}, \qquad
\Delta F_{\mathrm{CH}_4} = 0.0365\left(\sqrt{M}-\sqrt{M_0}\right)\left(1 + 1.69\times10^{-5}(M-M_0) + 0.0032(\sqrt{N}-\sqrt{N_0})\right),
$$
$$
\Delta F_{\mathrm{N_2O}} = 0.12\left(\sqrt{N}-\sqrt{N_0}\right)\times(\text{同一括号因子}),
$$
二氧化碳浓度以ppm计、其余以ppb计，括号因子处理甲烷与氧化亚氮的光谱重叠（米赫雷等人，1998年）。
:::

::: proof
两种函数形式来自吸收带的形状。在压宽大气中，*孤立*谱线的光学厚度随吸收质量按平方根增长，因为随着气体增多，谱线向自己的两翼展宽；由强度相近的谱线构成的带因此按$\sqrt{C}$饱和——这就是甲烷和氧化亚氮（强度相近的窄线带）遵循平方根律的原因。$15\ \mu\mathrm{m}$二氧化碳带不同：它包含强度横跨四个数量级的谱线，因此浓度上升时依次有更弱的线参与进来，总吸收大致随量的对数增长。对数不是饱和曲线的近似；它就是极宽线强分布所导致的结果。这也是公式只在拟合范围内成立的原因：二氧化碳表达式在$200$至$1{,}200\ \mathrm{ppm}$之间精度约$10\%$，甲烷表达式在约$2{,}000\ \mathrm{ppb}$以上失效变差。
:::

::: example 工业革命时代强迫的计算 {#ex-era}
用闭式公式求1750至2019年间二氧化碳（$278 \to 410\ \mathrm{ppm}$）、甲烷（$722 \to 1{,}870\ \mathrm{ppb}$）和氧化亚氮（$270 \to 332\ \mathrm{ppb}$）的强迫。
::: solution
$$
\Delta F_{\mathrm{CO_2}} = 5.35\ln\frac{410}{278} = 2.08,\quad
\Delta F_{\mathrm{CH_4}} = 0.0365(43.2 - 26.9)\times1.025 = 0.61,\quad
\Delta F_{\mathrm{N_2O}} = 0.12(18.2 - 16.4)\times1.025 = 0.22\ \mathrm{W\,m^{-2}} .
$$

三项之和为$2.9\ \mathrm{W\,m^{-2}}$，加上卤代烃（约$0.3$且在下降，因为蒙特利尔议定书起了作用）约为$3.2$——与评估给出的2019年相对1750年充分混合温室气体总量$+3.07\ \mathrm{W\,m^{-2}}$一致（IPCC AR6，2021年）。仅二氧化碳约占其中七成。注意评估总量*并不是*各项最佳估计之和：各项是联合约束的，气溶胶与敏感度两个不确定度强负相关，这就是为什么把评估表格逐行相加永远得不到它的头条总数。
:::
:::

## 成因的账本

::: definition 强迫效能 {#def-efficacy}
某强迫因子的**效能**$\varepsilon$是：其单位强迫造成的全球平均地表温度变化，与同量级参考二氧化碳强迫之比，于是$\Delta T = \varepsilon\lambda\Delta F$，$\lambda$为气候敏感度参数。效能之所以不等于一，是因为各因子施加的地点、时刻、高度不同，因而激发出不同的反馈。
:::

::: example 成因的量级 {#ex-scale}
按强迫（$\mathrm{W\,m^{-2}}$）给下列排序：十一年太阳周期（$\Delta\text{TSI} \approx 1.7\ \mathrm{W\,m^{-2}}$）；1991年皮纳图博喷发；二氧化碳倍增；岁差极值与今天之间$65\ ^\circ\mathrm{N}$夏季日射的变化；2019年人为总强迫。
::: solution
太阳周期：$1.7\times(1 - 0.30)/4 = 0.30\ \mathrm{W\,m^{-2}}$，通常引用为$0.22$–$0.30$。皮纳图博：平流层硫酸盐云在约十八个月里造成量级$-2$至$-3\ \mathrm{W\,m^{-2}}$的强迫，全球冷却约$0.4\ \mathrm{K}$。二氧化碳倍增：$3.7\ \mathrm{W\,m^{-2}}$（AR6标定下为$3.91$）。岁差周期中$65\ \mathrm{^\circ N}$夏季日射：最高$21\ \mathrm{W\,m^{-2}}$，但只在一个季节、一个纬度。2019年人为总强迫：$+2.7\ \mathrm{W\,m^{-2}}$（可能范围$2.0$–$3.5$）。

这个排序一行字就回答了两个最常见的质疑。太阳活动周期比我们的强迫弱一个量级，而且是振荡不是趋势。轨道强迫局部巨大——是二氧化碳倍增的五倍——但它是季节性和区域性的；冰期是它的*放大后*结果，由冰盖动力学、冰-反照率反馈和碳循环产生，而不是日射本身。没有人声称$21\ \mathrm{W\,m^{-2}}$的季节性日射变化是小的；这里的论点是$2.7\ \mathrm{W\,m^{-2}}$的持续全球强迫也不是小的。
:::
:::

::: warning 一瓦不是一瓦：效能从约二分之一到四
沉积在雪面上的黑碳，施加在明亮、高海拔、覆雪的地表，在太阳高挂、地表本来是面近乎完美镜子的季节里抹掉反射；其效能评估为二氧化碳的二到四倍。对流层臭氧生成于北半球污染的边界层中，对全球平均温度的效能更接近$0.6$–$0.8$，因为它大部分悬在陆地上空且很快被雨冲走。1990年代平流层臭氧耗损对南半球的效能约为二，因为它既改变了热量也改变了风。因此纯粹以$\mathrm{W\,m^{-2}}$比较各因子只是第一级近似；对短寿命气候因子——甲烷、氢氟碳化物、黑碳、飞机尾迹——可能错出三倍。真正跨因子、跨时间可比的量，是基于模型或观测的温度响应；这就是排放政策所用指标（全球增温潜势及其后继者）积分的是响应而不是强迫的原因。
:::

::: example 三步从吨到度 {#ex-tco2}
取排放的空气分数$0.45$、每ppm对应$2.12\ \mathrm{GtC}$、每$\mathrm{GtC}$对应$3.664\ \mathrm{GtCO_2}$。求从工业化前状态排放$1{,}000\ \mathrm{GtCO_2}$的强迫，以及评估的瞬态气候响应$0.45\ ^\circ\mathrm{C}$每$1{,}000\ \mathrm{GtCO_2}$所隐含的瞬态增暖。这个比值告诉你什么？
::: solution
$1{,}000\ \mathrm{GtCO_2} = 273\ \mathrm{GtC}$；按$45\%$空气分数，$123\ \mathrm{GtC}$留在空中，即$123/2.12 = 58\ \mathrm{ppm}$，于是
$$
\Delta F = 5.35\ln\frac{336}{278} = 1.01\ \mathrm{W\,m^{-2}} .
$$

评估的瞬态响应为每$1{,}000\ \mathrm{GtCO_2}$增暖$0.45\ ^\circ\mathrm{C}$（IPCC AR6：$0.45$ [0.27–0.63]），故瞬态响应参数为$0.45/1.01 = 0.45\ \mathrm{K}$每$\mathrm{W\,m^{-2}}$，即每开尔文$2.2\ \mathrm{W\,m^{-2}}$。它恰好落在该在的位置：在无反馈普朗克响应$3.3$与平衡净反馈$1.16$之间，因为瞬态响应就是只走了一部分的反馈。整条链——吨到ppm到瓦到开尔文——是三次乘法，也是IPCC减缓章节里每一个碳预算背后的计算（[[climate-change/emissions-budgets]]）。
:::
:::

## 账本如何建成，又如何失灵

强迫账本由三类输入拼成。充分混合气体来自上面的闭式公式，它们以逐线辐射传输标定，精度几个百分点。臭氧及其前体物需要化学-传输模型，因为臭氧不是排放出来的，而是由甲烷、一氧化碳、挥发性有机物和氮氧化物在依赖温度、水汽和环流的光化学中制造的。气溶胶需要环流模型，而且是弱得多的一环：对太阳光的直接散射与吸收（气溶胶-辐射相互作用）测得还算可以，但间接效应——气溶胶粒子如何改变云滴的数目、大小、寿命和反射率，以及其中一些如何催化冰晶——只能由卫星反演，不确定度在三倍以上。

::: example 气溶胶项是过去变难的原因 {#ex-aerosol}
总人为气溶胶强迫评估约为$-1.1\ \mathrm{W\,m^{-2}}$，可能范围$-1.7$至$-0.4$。若真值是$-0.4$而不是$-1.1$，这对我们本应已经看到的温度和敏感度意味着什么？
::: solution
遮蔽少$0.7\ \mathrm{W\,m^{-2}}$，则1750年以来的净强迫约为$3.4$而不是$2.7\ \mathrm{W\,m^{-2}}$，大$25\%$。由于观测增暖固定在约$1.1\ \mathrm{K}$，单位强迫隐含的响应将*小*$20\%$——要用更大的强迫解释同样的增暖，气候就必须更不敏感。

这就是每份评估中气溶胶范围与气候敏感度范围负相关的原因，也是单独收窄其中任何一个都不可能的原因：历史记录约束的是二者的*比值*，而不是任何一项。这也是1970年代以来的清洁空气计划附带一笔令人不适的算术的原因。欧洲和北美的硫酸盐气溶胶自1980年以来大约减半，揭开了约$0.2$–$0.4\ \mathrm{W\,m^{-2}}$，为观测增暖贡献了十分之一度——这是空气质量政策真实且预期的收益，同时也移除了账本中唯一的大负项（[[climate-change/observed-change]]）。
:::
:::

::: quiz
为什么允许平流层调整会*减小*二氧化碳的辐射强迫？
- [ ] 因为平流层对红外是透明的。
- [x] 因为二氧化碳冷却平流层，而更冷的平流层向下发射更少的辐射，这是一笔部分抵消对流层截留的额外能量损失。
- [ ] 因为臭氧在平流层重新生成。
- [ ] 不会减小；调整使强迫增大。
::: solution
平流层处于辐射平衡且不对流，所以二氧化碳增多意味着它向太空辐射更多能量并冷却。冷却减少了它送回对流层顶的向下通量。净效果是倍增强迫减少$16\%$，从$4.4$到$3.7\ \mathrm{W\,m^{-2}}$——这也是观测到的平流层以每十年约$1\ \mathrm{K}$冷却的原因，而这个指纹没有任何替代假说能复现。
:::
:::

::: history
米兰科维奇1920年计算了过去的日射，这是第一个定量的强迫问题。默勒1963年与拉西斯和汉森1974年给出了包含平流层调整的二氧化碳带模型强迫。米切尔1971年以及拉斯鲁尔与施奈德1971年曾论证人为气溶胶可能占主导并导致冷却——这个结论错了，因为它忽略了气溶胶的滞留时间（几天）对二氧化碳几个世纪的悬殊比例，但它指认出了至今仍主导不确定度的那一项，是对的。汉森等人1997年和2000年在环流模型中建立了第一个包含气溶胶的完整强迫账本。米赫雷等人1998年发表了至今所有清单都在使用的闭式公式。福斯特与泰勒2006年引入了覆盖快速响应因子的*调整*强迫；赛恩等人2003年引入效能概念；IPCC第五次评估（2013年）采用有效辐射强迫作为标准指标；AR6（2021年）评估人为总ERF为$+2.7\ \mathrm{W\,m^{-2}}$，气溶胶项两侧仍各有四分之三瓦的宽度。费尔德斯等人2007年证明，蒙特利尔议定书到那时已在2100年前避免了约$1\ \mathrm{W\,m^{-2}}$的卤代烃强迫——任何单一条约带来的最大气候红利，作为保护臭氧层的副产品兑现。
:::

## 通往何处

强迫是[[climate-system/feedbacks-sensitivity]]反馈代数、[[climate-change/emissions-budgets]]排放预算算术和[[climate-change/attribution]]归因指纹的输入。气溶胶物理在[[atmospheric-chemistry/aerosols]]，臭氧化学在[[atmospheric-chemistry/tropospheric-ozone]]，平流层冷却的观测在[[climate-change/observed-change]]，冰期的轨道强迫在[[palaeoclimate/orbital-cycles]]。

::: summary
- 辐射强迫是对流层顶净辐照度在扰动态与原始态之差、平流层已调整；有效辐射强迫另外允许对流层快速调整。
- 二氧化碳强迫取对数，因为其带横跨四个数量级的线强；甲烷和氧化亚氮取平方根，因为它们的带饱和。
- 工业时代各项强迫：$+2.1$（CO$_2$）、$+0.6$（CH$_4$）、$+0.2$（N$_2$O）、约$+0.3$（卤代烃，在下降）、约$-1.1$（气溶胶，最大不确定度）、$-0.15$（土地利用反照率），净$+2.7\ \mathrm{W\,m^{-2}}$。
- 效能从对流层臭氧的约$0.6$到雪面黑碳的$2$–$4$，所以瓦之间只是近似可比。
- $65\ ^\circ\mathrm{N}$的轨道强迫是二氧化碳倍增的五倍但是季节性的；太阳周期比我们强迫弱十倍且不呈趋势。
- 吨到度是三次乘法，其隐含的瞬态响应参数（$2.2\ \mathrm{W\,m^{-2}\,K^{-1}}$）落在普朗克值与平衡值之间，恰如其分。
:::

$0.0365(\sqrt{1870} - \sqrt{722}) = 0.0365\times16.37 = 0.60\ \mathrm{W\,m^{-2}}$。计入与氧化亚氮的重叠后升到$0.61$。

::: exercise 太阳对人为 {level=2 check="0.30"}
总太阳辐照度在太阳极小与极大之间变化$1.7\ \mathrm{W\,m^{-2}}$。求该周期的有效辐射强迫，并与$1{,}000\ \mathrm{GtCO_2}$的强迫比较。

$1.7\times0.70/4 = 0.30\ \mathrm{W\,m^{-2}}$；而$1{,}000\ \mathrm{GtCO_2}$为$1.0\ \mathrm{W\,m^{-2}}$，整个工业化时代为$2.7\ \mathrm{W\,m^{-2}}$。太阳周期还只是一个周期：十一年平均为零；卫星记录显示1979年以来总辐照度没有趋势，而同期行星已变暖$0.7\ \mathrm{K}$。

::: exercise 火山作为一次实验 {level=2 check="0.85"}
皮纳图博在1992年给出$-2.8\ \mathrm{W\,m^{-2}}$的强迫。求无反馈温度响应，并解释为什么观测到的冷却只有约$0.4\ \mathrm{K}$。
::: solution
无反馈为$-2.8/3.3 = -0.85\ \mathrm{K}$，平衡时为$-2.8/1.16 = -2.4\ \mathrm{K}$。观测的$0.4\ \mathrm{K}$远低于两者，因为强迫只维持了两年多一点。混合层热容量为$4.1\times10^{8}\ \mathrm{J\,m^{-2}\,K^{-1}}$，$2.8\ \mathrm{W\,m^{-2}}$作用两年（$1.8\times10^{8}\ \mathrm{J\,m^{-2}}$）只推动$0.43\ \mathrm{K}$——与观测在误差内相符。平衡数字在两年尺度的强迫面前毫无意义；这就是短寿命因子不能以平衡效应评判的全部原因，也是甲烷的百年指标与二十年指标差别巨大的同一笔算术。
:::

::: exercise 效能 {level=2 check="0.3"}
雪面黑碳的名义强迫为$0.1\ \mathrm{W\,m^{-2}}$，效能是三。求其以二氧化碳当量$\mathrm{W\,m^{-2}}$计的温度效应，并解释为什么这个数不小。
::: solution
$0.1\times3 = 0.3\ \mathrm{W\,m^{-2}}$当量。这一个短寿命因子的价值约为二氧化碳强迫的十分之一，尽管其辐射效应小二十倍。效能之所以大，是因为强迫施加在明亮、寒冷、稳定的地表，局地反馈（雪-反照率，以及那里什么都不蒸发）把它放大；而且它施加在春季——雪地上空阳光正盛的时候。
:::

::: exercise 一项减排的强迫 {level=3}
某航运法规削减硫酸盐排放，使气溶胶强迫减少$0.15\ \mathrm{W\,m^{-2}}$。用净反馈$1.16\ \mathrm{W\,m^{-2}\,K^{-1}}$和瞬态参数$2.2$，求平衡增暖与近期增暖，并说明还有什么变了。
::: solution
平衡$0.15/1.16 = 0.13\ \mathrm{K}$；近期$0.15/2.2 = 0.07\ \mathrm{K}$，且因为强迫变化发生在北半球海洋上空、响应很快，大部分在十年内兑现。

诚实的账还要算上：同一法规也削减黑碳，而黑碳是增暖的，两者部分相消；航运还排放二氧化碳，那是永久性的；而去除颗粒物对健康的收益以每年避免的数百万例过早死亡计，除"碳的几个世纪"之外的所有指标下都压过其气候效应。这就是短寿命因子政策问题的标准结构，也是为什么"哪种气溶胶？"比"多少气溶胶？"更有用的原因。
:::

::: exercise 范围的算术 {level=3}
2019年人为总ERF为$2.72\ \mathrm{W\,m^{-2}}$，可能范围$1.96$–$3.48$；净反馈参数为$1.16\ [0.9$–$1.6]\ \mathrm{W\,m^{-2}\,K^{-1}}$。求隐含的平衡增暖范围，并解释为什么联合范围比两者相乘的范围窄。
::: solution
天真地算，低端$1.96/1.6 = 1.2\ ^\circ\mathrm{C}$，高端$3.48/0.9 = 3.9\ ^\circ\mathrm{C}$——相差三倍。评估给出的当前强迫平衡增暖要紧得多，因为两个不确定度负相关：大强迫配大反馈会产生超过观测的增暖，历史记录排除了这种组合。数据约束的是联合分布，表格印出的是边际范围——这就是为什么把最佳估计表当联合分布读会夸大最坏情形。
:::

::: exercise 蒙特利尔红利 {level=3}
若无蒙特利尔议定书，卤代烃浓度预计到2100年达2000年水平的四倍，带来约$1\ \mathrm{W\,m^{-2}}$的额外强迫。估算避免的增暖，并与《巴黎协定》的近期效应比较。
::: solution
按瞬态参数$2.2\ \mathrm{W\,m^{-2}\,K^{-1}}$，$1\ \mathrm{W\,m^{-2}}$对应2100年前$0.45\ \mathrm{K}$、平衡时约$0.9\ \mathrm{K}$。作为对照，2020年代初基于国家自主贡献的路径与2100年约$2.4\ ^\circ\mathrm{C}$增暖一致，而高排放路径为$3.6\ ^\circ\mathrm{C}$——约$1\ \mathrm{K}$的红利，与蒙特利尔议定书的同量级；但前者谈判了几十年、且只有落实才兑现，而臭氧条约1987年达成，替代品一旦设计出来红利就自动兑现。这个比较不是对气候政策的悲观论；它是证据：当物理过程清楚、替代品存在、条约有效时，臭氧问题就被解决了——而甲烷和气溶胶都有现成的廉价减排手段，正是这个问题里"卤代烃式"的机会。
:::
