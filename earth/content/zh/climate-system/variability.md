1982年，秘鲁近海的海水在七月开始变暖，比任何有记录的厄尔尼诺都早几个月；到十二月，中太平洋表面比常年高$3\ ^\circ\mathrm{C}$——一片美洲大陆大小的海域在发烧。世界最大的鳀鱼渔场一年之内崩溃、再未完全恢复；澳大利亚遭遇了本世纪最严重的干旱和有记录以来最惨的山火季；大西洋飓风季被压制到正常活动的一半，太平洋的却翻了一倍；雨落在滴雨不降的阿塔卡马，全球平均温度两年跃升$0.3\ ^\circ\mathrm{C}$。这次事件和1997–98年的孪生事件教会了气候科学界一件秘鲁渔夫早已知道并命名的事——*El Niño*，圣婴洋流——即气候的年际变化不是噪声而是一个**振荡器**：一个有记忆、有反馈、有时钟的海气耦合系统，其自然周期三到五年，恰好落在人类规划的尺度上。

## ENSO引擎

::: definition 耦合的基础状态 {#def-walker}
在信风状态下，太平洋是一盆被堆向西边的水：温跃层在新几内亚外海深$40\ \mathrm{m}$，在秘鲁外海深$150$–$200\ \mathrm{m}$，西边界海面高半米，海表温度从西部暖池到东部冷舌下降$4\ ^\circ\mathrm{C}$。引擎是**沃环流**：空气在暖池上升，在高空向东流，在冷舌下沉，并沿表面作为东南信风返回——这是一个水平方向的哈得来环流，其燃料是东西海温对比，其废气是喂养鳀鱼的上升流。系统是**稳定但接近不稳定的**：信风冷却东边、加热西边（恢复对比），但信风的任何减弱都会通过一连串后果加热东边——温跃层变浅、上涌水变暖、表面东风减弱——而这条链，**Bjerknes反馈**，是正反馈且很快。系统是否振荡取决于两者的平衡：当温跃层反馈超过风-蒸发恢复时，基础状态不稳定并长成厄尔尼诺。
:::

::: proposition 再充电振荡器与时钟 {#prop-recharge}
把反馈变成振荡器的记忆是**赤道热含量**——上层海洋的暖水体积，以温跃层深度$h$度量。Jin的再充电振荡器把耦合系统约化为两个方程，
$$
\frac{\mathrm{d}T}{\mathrm{d}t} = a\,T + b\,h, \qquad \frac{\mathrm{d}h}{\mathrm{d}t} = -c\,T - d\,h ,
$$
即海表温度$T$上的正反馈和经由$h$的正交耦合：厄尔尼诺向东偏移的暖对流驱动**下沉Rossby波**，它们在西边界反射为上升Kelvin波，排走暖水——盆地"放电"，稍后"充电"。结果是$T$与$h$相位差四分之一周期的阻尼振荡：热含量下降时最暖，重建时最冷（拉尼娜）。自然周期由赤道波的往返决定——Kelvin波以$2.5\ \mathrm{m\,s^{-1}}$两个月横穿$15{,}000\ \mathrm{km}$的盆地，Rossby波往返一两年——为**三到五年**，而为每个事件播种的随机风爆发让振荡器不规则而非周期地运转。延迟负反馈解释了厄尔尼诺为何必然消亡：加热东边的同一事件，也放掉了造就它的那块电池。
:::

::: example 时钟的齿轮 {#ex-kelvin}
一次厄尔尼诺于四月在西太平洋的西风异常中开始。增暖信号多久到达南美海岸？为什么这个数字同时决定了成熟月份（12–2月）和春季可预报性障壁？
::: solution
在西边强迫的下沉Kelvin波以$c \approx 2.5\ \mathrm{m\,s^{-1}}$横穿盆地：
$$
t = \frac{1.5\times10^{7}}{2.5} = 6\times10^{6}\ \mathrm{s} \approx 70\ \mathrm{days} \approx 2\ \mathrm{months}.
$$
增暖因此六月抵达秘鲁外海，随Bjerknes反馈就地运转而在北半球夏秋加深，在层结最弱、东边温跃层最浅的12–2月达峰。同样的波动物理制造了**春季可预报性障壁**：三到五月温跃层最深、Bjerknes反馈最弱，所以跨越北半球春季发出的、针对下个冬天的预报，必须穿过系统增长率接近零、噪声占主导的月份——这就是为什么二月发布的ENSO预报远差于十月发布的。
:::
:::

## 全球足迹

::: definition 遥相关 {#def-teleconnections}
ENSO的全球影响不是太平洋增暖本身，而是其**大气响应**：暖距平把深对流向东搬移数千公里，迁移后的降雨释放的潜热驱动一对对流层高层反气旋，向半球四周辐射**Rossby波列**——太平洋-北美型及其南半球对应型。通过这些波列，一片$2\ ^\circ\mathrm{C}$的海面决定了从加利福尼亚到萨赫勒的降雨符号、北美冬季风暴的路径、西北欧冬季洪水的频率、大西洋飓风季的强度（厄尔尼诺的高空西风把热带气旋剪碎），以及小麦的价格。对1982–83和1997–98事件的经济研究把大事件的全球损失定为数千亿美元——最糟的年份占世界产品的几个百分点——使ENSO成为气候系统中经济后果最大的单一现象，而提前两到四个月预判它的季节预报是气象学最有价值的产品。遥相关是**不对称的**：厄尔尼诺的影响比拉尼娜的更大、更全球、且与其反号程度超过对称的海温型所能暗示的，因为对流对温度非线性开启——气候对ENSO**循环**的响应是锯齿波，不是正弦波。
:::

::: example 从海洋读一年 {#ex-teleconnect}
2027年10月Niño-3.4指数为$+2.1$，暖水体积距平为$-40\ \mathrm{mm}$（已放电），对流中心位于$170\ \mathrm{W}$。请带机制地预测下列各项的符号：(a) 次年初夏的Niño-3.4，(b) 澳大利亚冬季降雨，(c) 下一个大西洋飓风季的风切变。
::: solution
(a) **转负**：盆地已放电——维持厄尔尼诺的热含量已经耗尽，暖事件发射的上涌Rossby波正到达东边；再充电振荡器的正交性说明下个冬天中性、次年初夏可能拉尼娜。(b) **干**：中太平洋的对流压制了沃环流的澳大利亚一侧；厄尔尼诺的冬天是澳大利亚最干最热、2019–20火险天气的对应物。(c) **高切变、受压制的飓风季**：厄尔尼诺加强热带大西洋对流层高层西风，把垂直切变抬到热带气旋发展阈值之上——从1982到2015到2023，大西洋在厄尔尼诺夏天的安静是有记录以来最可靠的遥相关之一。这道题是业务预报的缩影：海洋状态加振荡器的相位，而非仅海温，才是季节预报员读的东西。
:::
:::

::: example 一次厄尔尼诺搬运多少热 {#ex-wwv}
1997–98年超级厄尔尼诺期间，赤道太平洋暖水体积在$5\ \mathrm{^\circ S}$–$5\ \mathrm{^\circ N}$、$80\ \mathrm{W}$–$150\ \mathrm{E}$的带内（面积$8.6\times10^{6}\ \mathrm{km^{2}}$）平均减少相当于温跃层位移$40\ \mathrm{m}$。取被移动的水比深处周围环境暖$4\ ^\circ\mathrm{C}$，求重新分配的热含量，并与人类年能耗（$6\times10^{20}\ \mathrm{J}$）比较。
::: solution
被移动的体积$V = 40\times8.6\times10^{12} = 3.4\times10^{14}\ \mathrm{m^{3}}$，热量
$$
Q = \rho c_p\,\Delta T\,V = 1025\times4000\times4\times3.4\times10^{14} = 5.6\times10^{21}\ \mathrm{J},
$$
几乎是**人类年能耗的十倍**，被一阵风异常横向泼动，又在九个月里作为中太平洋的降雨还给大气。这个比较是自然变率的诚实尺度：气候进行的最大单年能量再分配，比文明建成的最大能量系统还高一个量级——这就是为什么对ENSO的正确回应不是控制而是预报，也是为什么对这一个振荡的季节预报，其避免的损失就超过历史上尝试过的任何天气改造工程。
:::
:::

## 其他时钟：MJO、年代际模态、QBO

::: definition 自然变率家族 {#def-other-modes}
ENSO是最大的年际模态，但不是唯一的振荡器。**Madden–Julian振荡**是对流层自己的30–60天波：一个持续$30$–$60$天、宽$10{,}000\ \mathrm{km}$的对流-抑制包络，以$5$–$7\ \mathrm{m\,s^{-1}}$东传——它组织季风的中断、大西洋和太平洋气旋簇的发作，以及半个热带未来两周的干湿，也是大气自我维持的湿度振荡最清晰的例子，直到对流被允许与自身环流相互作用之前，没有模型能重现它。**印度洋偶极子**是印度洋的ENSO对应物，一个±1 °C的东西模态、相位锁定于北半球秋季，其正位相（爪哇冷、非洲暖）使东非洪水风险翻倍并终结澳大利亚的火季。**太平洋年代际振荡**和**大西洋多年代际变率**是更慢的海洋内部模态——由副热带环流调整与翻转记忆驱动、节奏为20–30年和60–80年的型变——它们调制ENSO的全球效应、给太平洋表面温度叠加年代际趋势，并解释了为什么2000–2014的"增温停滞"是表面格局而非热量停止：消失的热进了西太平洋温跃层之下，而太平洋自己在2010年代末的年代际位相翻转把它带了回来。平流层纬向风的**准双年振荡**——由热带波破碎驱动、28个月一次的东西切变下行——是大气最规则的时钟，其位相调制极地涡旋强度、痕量气体输送，并在统计上调制ENSO遥相关本身。
:::

::: example MJO的算术 {#ex-mjo}
3月1日MJO对流包络位于海洋大陆。估算它何时到达中太平洋，以及澳大利亚雨季的爆发与加勒比海下一段安静期与它重合的概率有多大。
::: solution
包络以$6\ \mathrm{m\,s^{-1}}$从海洋大陆到中太平洋横穿$6000\ \mathrm{km}$需要
$$
t = \frac{6\times10^{6}}{6} = 10^{6}\ \mathrm{s} \approx 12\ \mathrm{days},
$$
约3月15日到达——正是压制澳大利亚降雨的中太平洋对流相位，并经由制造ENSO足迹的同一波列，在加勒比海和墨西哥湾上空设定增强切变。MJO的实际重要性恰在于此：它是全球**亚季节**（2–4周）可预报性的主导来源，知道MJO相位的预报员可以提前数周熟练预测澳大利亚的干旱、加勒比海的安静、阿拉斯加的脊和欧洲的冷空气爆发，而不知道的就做不到——这就是为什么各大中心现在都运行亚季节系统，也是为什么MJO是该领域当前的前沿。
:::
:::

## 可预报性及其极限

::: definition 为什么ENSO能预报而天气不能 {#def-predictability}
ENSO系统能提前数月预报，因为它的慢变量——海洋热含量——有一年的记忆，而且**被观测着**：锚定阵列和卫星对温跃层深度与暖水体积的记录直接给出振荡器的初始相位。天气两周后不可预报，因为它的变量没有这样的慢水库，误差倍增时间以天计。由此得出三条实际后果。**春季障壁**使必须穿过弱反馈季节的预报退化。**事件多样性重要**：东太平洋（典型）与中太平洋（Modoki）事件的遥相关不同，振幅报对而类型报错的预报会在要害处错。还有**噪声设定天花板**：为事件播种的同样西风爆发（超级云团、热带气旋）几周后不可预报，所以即使完美模型的ENSO可预报地平线也只有约8–12个月——而年代际模态的"预测"以初始化海洋状态为本，继承自己更长但更浅的地平线。对自然变率的诚实总结是：气候有**模态，没有心情**：它在诸状态间的看似游荡是少数几个阻尼振荡器的鸣响，每个都有可辨认的物理、可测的阻尼和可预报的相位——而把这些鸣响与激励这些振荡器更强烈的温室增暖趋势分开，就是 [[climate-change/attribution]] 中的归因问题的日常工作形态。
:::

::: warning 厄尔尼诺不是全球变暖，拉尼娜年不是变冷趋势，停滞不是暂停
五个错误。**ENSO是自然振荡器**，有12 000年的沉积与珊瑚记录；1982–83和1997–98的巨人以及2010–12的拉尼娜三重复极都在自然范围内，尽管**极端事件的频率**和东太平洋振幅正随背景增暖上升——模态是自然的，其激励不全是。**拉尼娜年不是变冷趋势**：最近的冷拉尼娜年仍位列非厄尔尼诺年中最暖之列，因为振荡是$+1.2\ ^\circ\mathrm{C}$斜坡上的±2 °C跷跷板——跷跷板是变率，斜坡是信号，混淆二者就是"全球变暖在1998年停止"的错误。**2000年代的停滞是再分配**：西太平洋温跃层加深，海洋在深处吸热，2010年代末太平洋的年代际位相翻转把它释放——表面记录的十年，是海洋的十年用另一种货币书写。**ENSO预报是概率产品**："70%的厄尔尼诺可能"不是推脱，而是成员在风爆发噪声下发散的集合的诚实输出；把它们当确定性读，或当抛硬币打发，是两种相等的错误。**而遥相关图是条件句**：降雨响应的符号假设季节循环、年代际位相和MJO相位如气候期望——这些图是对话的第一句，不是对话本身。
:::

::: history
振荡的大气一半由**吉尔伯特·沃克爵士**发现：他1923–1931年对印度和殖民地天气记录的分析定义了南方涛动及其海平面气压"跷跷板"，尽管他无法解释它。**特·伯格隆**和卑尔根学派的海气思想、**亨利·斯托福尔**和**克努特·维尔特基**1960–70年代对赤道太平洋的物理海洋学——Wyrtki的"笛"机制以及他关于西太平洋在**上升**而东边在下降的警告——补上了海洋的一半，而**雅各布·比耶克内斯**1966和1969年的论文命名了这种耦合：Bjerknes反馈、沃环流、ENSO作为一个系统。1982–83年事件被每个业务中心漏报，催生了TOGA和TAO观测计划、**凯恩-泽比亚克**1987年的统计-动力模型和现代ENSO预报系统；**迈克尔·麦克法登**的观测综合与**Jin** 1997年的再充电振荡器给了时钟现代的形态，而**朱莉娅·科尔**等人的珊瑚与树轮古ENSO记录展示了振荡的深时变率。
:::

::: summary
- ENSO是海气耦合振荡器：Bjerknes反馈（正）与温跃层充放电（延迟负）产生由随机风爆发播种的3–5年阻尼循环。
- 再充电振荡器的正交性——海温领先热含量四分之一周期——是为什么冬季热含量能预报明年状态，也是为什么每次厄尔尼诺都放掉造就它的电池。
- 赤道波动物理设定了钟表（Kelvin波两个月横穿）和日历（冬季达峰、春季障壁）。
- 经Rossby波列的遥相关使一个太平洋模态决定从加利福尼亚到萨赫勒的降雨、风暴、山火和飓风；影响不对称且非线性。
- 变率家族——MJO（周）、IOD、PDO/AMV（十年）、QBO（28个月）——是有可测物理和可预报相位的阻尼振荡器，不是心情。
- 自然变率是这些模态的鸣响；强迫趋势把同样的模态激励得更响、并把热重新分配进海洋内部，这就是为什么只看表面温度会同时误读停滞与暂停。
:::

## 练习

::: exercise Kelvin横穿 {level=1 check="2.3"}
以$2.5\ \mathrm{m\,s^{-1}}$行进的开尔文下沉波横穿$15{,}000\ \mathrm{km}$的太平洋需要多少个月？（保留一位小数。）
::: solution
$t = 1.5\times10^{7}/2.5 = 6\times10^{6}\ \mathrm{s} = 69\ \mathrm{days} = 2.3\ \mathrm{months}$。海洋的压力信息以周为单位横穿盆地，而大气的天气以天演化：太平洋在海面响应之前很久就"知道"了风爆发，正是这种时间尺度的不对称使ENSO可预报。
:::
:::

::: exercise 温跃层反馈 {level=1 check="2"}
在东太平洋，上涌温度距平按$\Delta T = \gamma\,\Delta h$缩放，$\gamma = 0.04\ ^\circ\mathrm{C\,m^{-1}}$。若拉尼娜期间温跃层变浅$50\ \mathrm{m}$，求上涌距平（°C）。（保留一位小数。）
::: solution
$\Delta T = 0.04\times50 = 2.0\ ^\circ\mathrm{C}$——与海温距平本身同量级：温跃层反馈不是ENSO的修正项，它**就是**ENSO；这就是为什么振荡生活在西太平洋的暖池和东太平洋的薄温跃层里，而不只在风里。
:::
:::

::: exercise MJO速度 {level=1 check="7.7"}
MJO包络60天绕热带一圈（$40{,}000\ \mathrm{km}$）。求其相速度（$\mathrm{m\,s^{-1}}$）。（保留一位小数。）
::: solution
$v = 4\times10^{7}/(60\times86{,}400) = 7.7\ \mathrm{m\,s^{-1}}$——比它所经下的中纬度西风慢一个量级，慢到其相位可以被观测、追踪和利用：2–4周的亚季节窗口在业务上属于MJO，不属于别的任何东西。
:::
:::

::: exercise ENSO增长 {level=2 check="24"}
一个耦合不稳定性以8个月的e倍时间增长。初始$0.1\ ^\circ\mathrm{C}$的噪声需要多少个月长到$2\ ^\circ\mathrm{C}$？（填月数。）
::: solution
$t = 8\ln(20) = 24\ \mathrm{months}$。增长时间解释了为什么ENSO事件从噪声到成熟需要一年，也解释了为什么系统在事件之外的**阻尼**必须强——否则噪声会被持续放大而不是像观测到的那样阵发性放大，这正是ENSO"临界稳定"的含义：一个恰好坐在不稳定性边缘的气候。
:::
:::

::: exercise 延迟振荡器 {level=2 check="4"}
在延迟负反馈振荡器中，周期是延迟的四倍（$T = 4\tau$）。若Rossby波再充电延迟为12个月，求自然周期（年）。（取整。）
::: solution
$T = 4\times12 = 48$ 个月 $= 4$ 年——正好落在观测到的2–7年ENSO带内。这个一致是"ENSO的时钟是海洋的波传播时间"的经典论证，出自**巴蒂斯蒂**和**赫斯特**1980年代后期的延迟振荡器模型，至今仍是周期由可测传播时间决定的气候振荡的最干净例子。
:::
:::

::: exercise QBO下行 {level=2 check="0.43"}
QBO的风切变型在一个28个月周期内从30 km降到18 km。求下行速率（$\mathrm{km\,month^{-1}}$，保留两位小数）。
::: solution
$12/28 = 0.43\ \mathrm{km\,month^{-1}}$。下行由波-平均流相互作用驱动——热带波对着平均切变破碎、沉积向西动量——而QBO在大型大气现象中独一无二的近乎完美规则性，使其相位成为平流层臭氧输送和极地涡旋强度的有用控制旋钮。
:::
:::

::: exercise 再充电振荡器 {level=3 check="6.3"}
对线性系统$\dot T = aT + bh$、$\dot h = -cT$（$d = 0$），证明特征值为$\lambda = (a \pm \sqrt{a^{2}-4bc})/2$，并求$a = 0$、$bc = 1\ \mathrm{yr^{-2}}$时的振荡周期（年）。（保留一位小数。）
::: solution
$a = 0$时特征值为$\lambda = \pm i\sqrt{bc}$：角频率$\sqrt{bc} = 1\ \mathrm{yr^{-1}}$的纯振荡，周期$2\pi/\sqrt{bc} = 6.3$ 年。加上真实的阻尼（$d > 0$）和季节调制会把周期移到观测的3–5年并使振荡器变为阻尼——不规则到可称"噪声驱动"，这正是现代观点：ENSO是被随机激励的阻尼模态，其"周期"是谱峰，不是钟摆。
:::
:::

::: exercise 变率对趋势 {level=3 check="0.05"}
增暖趋势为$0.2\ ^\circ\mathrm{C\,decade^{-1}}$，ENSO的年际标准差$0.2\ ^\circ\mathrm{C}$、去相关时间6个月。求15年平均中ENSO波动的标准差（°C）。（保留两位小数。）
::: solution
15年窗口包含$N_{\mathrm{eff}} \approx 15/(2\times0.5) = 15$ 个独立半年，所以平均的波动为$0.2/\sqrt{15} = 0.05\ ^\circ\mathrm{C}$，而趋势贡献$0.2\times1.5 = 0.3\ ^\circ\mathrm{C}$——大六倍。但**单年**±0.2 °C的全球平均ENSO摆动比任何单年的趋势增量高一个量级。这就是为什么15年趋势有意义而1–3年的"暂停"没有：振荡主导年际，趋势主导年代际，而每个关于增暖的诚实陈述都会说明自己在说哪一个。
:::
