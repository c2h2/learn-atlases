1958年，在一座太平洋中的火山上，**查尔斯·基林（Charles David Keeling）**开始测量空气中的二氧化碳，因为他在南极的工作需要一种校准气体，而本底值让他恼火。他开启的那条曲线走了五十年——上升，被北方森林的呼吸锯成齿状，每年都比至少两百万年中的任何一点更高——把碳循环从一门地球化学奇趣变成了环境科学的核心会计学。这门学科有一个支配性的事实：大气是一个小而快的水库，邻居们却又大又慢；关于未来CO₂的一切问题——多高、多快、多久、谁的责任——都归结为这个小水库的进出通量，以及决定邻居们会吸收多少的那套化学。

## 碳账本

::: definition 水库与通量 {#def-ledger}
活跃碳循环，以拍克碳计（$1\ \mathrm{PgC} = 1\ \mathrm{GtC}$；$1\ \mathrm{ppm} = 2.12\ \mathrm{PgC}$）：大气持有$870$（2020年代为410 ppm），陆地活体与死体生物量$2000$–$3000$（植被约$500$、土壤$1500$–$2400$、其中约$1400$是脆弱的永久冻土），表层海洋约$1000$，中层和深海$37{,}000$——化石沉积物还持有数千以上，其中经济可采部分约$1000$。总流量是巨大的：海洋每个方向呼吸约$90\ \mathrm{PgC\,yr^{-1}}$，陆地的光合与呼吸各约$120$，而人类的添加——2020年代化石燃料与水泥$9.4$加上土地利用约$1.1$——只有自然流量的十分之一。但扰动并不小，因为自然流量几乎相消：人类的添加占大气**净**自然交换的$45\%$，而且它在积累。工业化前至今的账本：1850年以来排放约$690\ \mathrm{PgC}$，大气增量约$270$，海洋汇约$175$，陆地汇约$160$——**空气分数**七十年保持在$45 \pm 5$个百分点附近，海洋和陆地迄今以跟上排放的速率吸收了其余部分——这是关于过去的事实，不是对未来的承诺。
:::

::: example 空气分数与碳预算 {#ex-budget}
2020年代排放$10.5\ \mathrm{PgC\,yr^{-1}}$，大气增量平均$2.5\ \mathrm{ppm\,yr^{-1}}$。求空气分数；若海洋和陆地合计吸收$5.6\ \mathrm{PgC\,yr^{-1}}$，核对账目。为什么空气分数比任何单一汇都更能告诉我们未来？
::: solution
大气增加$2.5\times2.12 = 5.3\ \mathrm{PgC\,yr^{-1}}$，这一对年份的空气分数为$5.3/10.5 = 50\%$（长期平均为$45\%$）。账目闭合：$10.5 = 5.3 + 5.6$，误差由吸收四项误差的残差项承担。空气分数之所以是要紧的数字，因为它是**两个相互补偿的大不确定度之比**：海洋汇和陆地汇各自的估计精度只有$\pm 0.5\ \mathrm{PgC\,yr^{-1}}$，但它们的和被大气测量钉住；决定既定排放预算有多少留在空气中的，是和而不是分配。每一个温度目标的剩余碳预算计算都建立在这个稳健的比值上。
:::
:::

## 海洋的缓冲：为什么海不会吞下我们的碳

::: proposition 雷维拉因子与海洋的吝啬 {#prop-revelle}
海水不是水桶而是缓冲液：溶解的$\mathrm{CO_2}$有90%以碳酸氢根和碳酸根离子存在，加入$\mathrm{CO_2}$会使碳酸盐平衡移动，于是分压上升得比加入量**多得多**。**雷维拉因子**度量这种吝啬：
$$
R = \left(\frac{\partial \ln p\mathrm{CO_2}}{\partial \ln \mathrm{DIC}}\right)_{T,\,A,\,C} \approx 10\text{–}15\ \ (\text{表层海洋平均} \approx 12),
$$
其中DIC是溶解无机碳：表层DIC增加1%，$p\mathrm{CO_2}$上升12%，而无缓冲溶剂的对应因子是一。后果是这个循环的大不对称：表层海洋持有的碳比大气多，却极不情愿地吸收人为增量——若只有混合层达到平衡，它连我们排放的十分之一都吃不下，空气分数将逼近90%。救我们的不是化学而是**环流**：物理泵把吸收的碳带进深海，那里$37{,}000\ \mathrm{PgC}$坐在更低的雷维拉因子和巨大的容量上，下沉颗粒的**生物泵**完成其余——海洋约$2.7\ \mathrm{PgC\,yr^{-1}}$的吸收是一个**环流现象**，因此受限于最慢的翻转，而不是最快的表面交换。让海洋成为慢汇的同一套化学也让它变酸：排出的碳已使表层pH下降$0.11$个单位——氢离子上升30%——而pH下降消耗的碳酸根，正是从翼足类、牡蛎到珊瑚礁系统本身这些造壳生物必须过饱和其体液的离子；文石饱和面自工业化前以来抬升了数百米，本世纪的预估把表层北极水的不饱和放在2060年代。
:::

::: example 雷维拉因子的代价 {#ex-revelle}
表层海洋的DIC为$2000\ \mu\mathrm{mol\,kg^{-1}}$。若$100\ \mathrm{PgC}$被吸收进面积$3.6\times10^{16}\ \mathrm{m^{2}}$、深度$70\ \mathrm{m}$的混合层，其$p\mathrm{CO_2}$上升几倍（$R = 12$）？这对进一步吸收意味着什么？
::: solution
加入的碳为$100\times10^{15}\ \mathrm{g}/12 = 8.33\times10^{15}\ \mathrm{mol}$，进入体积$2.5\times10^{18}\ \mathrm{m^{3}}$，即$\Delta\mathrm{DIC} = 33\ \mu\mathrm{mol\,kg^{-1}}$，分数增量$33/2000 = 1.7\%$。取$R = 12$，
$$
\frac{\Delta p\mathrm{CO_2}}{p\mathrm{CO_2}} = 12\times1.7\% = 20\%.
$$
海水自身$p\mathrm{CO_2}$上升20%，而大气自1750年以来上升50%——混合层已在**拒收**更多碳的路上：驱动吸收的梯度被海洋自身的响应砍半。这就是海洋吸收份额已随物理泵减速而开始下降的原因，也是"海洋会吸收它"不是处置方案、而是一张化学定了到期日的临时补贴的原因。
:::
:::

## 陆地与同位素指纹

::: definition 陆地汇与苏斯指纹 {#def-land-sink}
陆地的总流量巨大且近乎平衡——光合总量（GPP）约$120\ \mathrm{PgC\,yr^{-1}}$，呼吸与火几乎同样多——而约$3\ \mathrm{PgC\,yr^{-1}}$的净汇是一线巧合的薄片：CO₂施肥（更高$p\mathrm{CO_2}$对水分利用效率和生长的直接效应）加得比氮限制、气候压力和土地利用减去的更多，而这个平衡的符号是幼龄林效应，会随林龄耗尽。这个汇是真实的，由三种一致的独立方法测得：数树的森林清查、测交换的涡动相关塔，以及——裁判——**同位素指纹**。化石碳不含$^{14}\mathrm{C}$（早已衰光）且$^{13}\mathrm{C}$偏轻（$\delta^{13}\mathrm{C} \approx -25\permil$，空气为$-6.5\permil$），所以燃烧它会按排放总量可算的速率稀释大气中两个比值：观测到的$\delta^{13}\mathrm{C}$下降（**苏斯效应**，经海洋交换订正后较工业化前样品下降$-1.9\permil$）和$^{14}\mathrm{C}/^{12}\mathrm{C}$比的塌陷（在1960年代核爆脉冲覆盖它之前），确认CO₂上升是**我们造成的**；而大气氧的同步下降——每摩尔碳烧掉一摩尔O₂，自1989年起以千分精度由瓶采样测量——把氧化还原账也闭合了。同位素是以下两件事同样确凿的原因：CO₂上升归因于化石燃料，与增暖归因于CO₂。
:::

::: example 读懂苏斯效应 {#ex-suess}
大气$\delta^{13}\mathrm{C}$自1850年以来（经海洋交换订正）下降了$1.2\permil$。取工业化前$\delta^{13}\mathrm{C} = -6.5\permil$、化石碳$-25\permil$，估算当前大气CO₂中化石来源的分数，并与累积排放的空气分数（$270/690 = 39\%$）比较。
::: solution
双端元混合：混合物的组成是摩尔加权平均，于是
$$
-7.7 = f_{\mathrm{ff}}\times(-25) + (1 - f_{\mathrm{ff}})\times(-6.5) \;\Longrightarrow\; f_{\mathrm{ff}} = \frac{1.2}{18.5} = 6.5\ \mathrm{per\ cent} .
$$
与39%空气分数的表面矛盾正是同位素的一课：大气已经与海洋和生物圈**交换**了碳，而它们自己在吸收化石碳的过程中也在变轻——大气-海洋-陆地整个系统的$^{13}\mathrm{C}$库存记录了完整的$39\%$，而仅仅作为更大水库充分混合端头的大气，显示的是被稀释的$6.5\%$。用$^{14}\mathrm{C}$做同样的计算（"空气的放射性碳炸弹定年"）测的是造成稀释的交换的**转换速率**——两种同位素合起来给出量和速度。
:::
:::

## 移除：承诺曲线

::: definition CO₂移除的时间尺度 {#def-removal}
一股化石碳脉冲离开大气分三幕。第一幕快而不完整：十年之内海洋表层和陆地吸收大约三分之一，但海洋表层随后**变暖、层化、抗拒进一步吸收**，雷维拉因子开始咬人——空气分数稳定在四分之一附近。第二幕是环流：在$200$–$1000$年里，深海——大气库存的30倍——达到平衡并吸收剩余的大部分，其节奏由翻转环流决定，这就是为什么化石CO₂的"调整时间"是几个世纪，而单个分子的"停留时间"只有四年。第三幕是化学：海底碳酸盐的溶解中和CO₂造成的酸，在$10^{4}$–$10^{5}$年里恢复缓冲，只有到那时最后一成才能离开。后果是本世纪最未被充分传达的数字：**每排放一吨，一千年后仍有四分之一到三分之一在空气中**，一个世纪后还有一半——这条"尾巴"使气候变化成为代际承诺而不是天气尺度的问题，给海洋酸化以数千年的惯性，也让基林曲线的反向比正向慢得多。同样的不对称贯穿温度：因为海洋吸热滞后，恒定排放下的增暖承诺是真实的，而零排放承诺——排放停止后世界最终稳定到的温度——才是政策真正必须命中的数字。
:::

::: example 承诺的算术 {#ex-commit}
2020年起1.5 °C的剩余碳预算估计为$500\ \mathrm{GtCO_2}$，排放为$37\ \mathrm{GtCO_2\,yr^{-1}}$，求当前速率下的耗尽年份；又给定TCRE为每$1000\ \mathrm{GtCO_2}$ $0.45\ ^\circ\mathrm{C}$，求1870年以来排放的$\sim 2500\ \mathrm{GtCO_2}$已经承诺的增暖。
::: solution
$500/37 = 13.5$ 年——排放不变则2030年代中期耗尽。累积排放的承诺增暖为$0.45\times2500/1000 = 1.1\ ^\circ\mathrm{C}$，与观测到的$\sim 1.2\ ^\circ\mathrm{C}$一致；而这个计算的线性——增暖正比于**累积**碳，而非浓度或年速率——是碳-气候系统对政策最重要的性质：它把每条排放路径变成一个总量，每个总量变成一个温度，把每次拖延变成对一份不谈判的预算的减法。
:::
:::

::: warning 停留时间不是调整时间，汇不是服务合同，碳循环不是股票市场
五个错误。**大气CO₂四年左右的"停留时间"是对总交换通量而言的**（$870/210$），它对**扰动**离开得多快一无所知——扰动的调整时间是几个世纪，因为总通量几乎相消、剩余才是我们加入的部分；混淆两者是公共讨论中最常见的碳循环错误。**陆地和海洋汇是响应，不是承诺**：迄今它们保持了大致恒定的分数，但上升排放的恒定**分数**意味着不断上升的吸收，而物理未必支撑——亚马逊的汇自1990年代已经掉了三分之一，南大洋的已经趋平。**永久冻土和湿地碳不是世纪尺度上的"定时炸弹"**：脆弱的$\sim 1400\ \mathrm{PgC}$以几个世纪到千年融化，诚实的恐惧是轨迹上持续的乘数，而不是悬崖。**碳循环不是按平价交易抵消的市场**：存在森林里的吨是有几十年停留时间和火灾风险的吨；地质封存的吨是千年停留时间的吨；循环给两者的定价天差地别，而按平价给它们定价的政策在碳的意义上是错的。**而"CO₂只占0.04%"不是影响力的度量**：设定红外窗口的每百万420个分子，是冰室与温室之别——地球自己的深时记录，其中180和280 ppm是冰期与间冰期的恒温器，就是反驳。
:::

::: history
循环的化学始于**约瑟夫·布莱克**发现"固定空气"（1754）与**尼古拉-泰奥多尔·德·索绪尔**对植物吸收它的测量（1804）。**汉斯·E·苏斯**——与**威拉德·利比**的计划共同发现放射性碳——在1955年识别出大气中$^{13}\mathrm{C}$的下降，而**罗杰·雷维拉**与**汉斯·苏斯**1957年关于海洋碳酸盐缓冲的论文确立了以雷维拉命名的因子，并提出了碳循环至今在回答的问题：海洋为什么没有、并且不会吞下我们的碳。**查尔斯·大卫·基林**自1958年开始、1960年发表的冒纳罗亚与南极连续记录，证明上升是全球性、化石性且持续的；1960年代大气炸弹脉冲$^{14}\mathrm{C}$计划把循环变成示踪实验，**拉尔夫·基林**1989年起的大气氧计划闭合了氧化还原账。**全球碳计划**自2006年起审计年度碳账，**轨道碳观测站-2**（2014–）一直在从太空绘制汇的地图。
:::

::: summary
- 大气又小又快（870 PgC），与海洋（38,000 PgC）和陆地（~2500 PgC）交换巨大但几乎相消的通量；人类的添加（~10 PgC yr⁻¹）对流量来说小，对剩余来说巨大。
- 七十年里空气分数保持在45%附近；海洋和陆地汇迄今跟上了排放——但这是关于过去的事实。
- 雷维拉因子（~12）使海水成为吝啬的吸收者：海洋的吸收是环流驱动的补贴，不是化学权利，其代价是酸化——pH已降0.11个单位。
- 陆地汇是幼龄林与施肥驱动的一线巧合，会随林龄耗尽；同位素（¹³C、¹⁴C、O₂）证明CO₂上升是化石的，并独立测量各汇。
- 移除按三只钟走——几十年（表层交换）、几个世纪（翻转环流）、10⁵年（碳酸盐中和）：每一吨里仍有四分之一到三分之一在一千年后留在空气中。
- 增暖随**累积**CO₂定标（TCRE ≈ 每1000 GtCO₂ 0.45 °C），这把每条排放路径变成预算，把每次拖延变成减法。
:::

## 练习

::: exercise ppm到拍克 {level=1 check="890"}
把$420\ \mathrm{ppm}$换算成拍克碳（$1\ \mathrm{ppm} = 2.12\ \mathrm{PgC}$）。（填PgC数值。）
::: solution
$420\times2.12 = 890\ \mathrm{PgC}$。这个换算因子——整个大气质量的多分之一——正是本课每个CO₂数字都能相互核对的原因：排放、汇和曲线本身是同一本账的不同货币。
:::
:::

::: exercise 空气分数 {level=1 check="45"}
排放$10.7\ \mathrm{PgC\,yr^{-1}}$，大气增量$4.8\ \mathrm{PgC\,yr^{-1}}$。求空气分数的百分数。（填数字。）
::: solution
$4.8/10.7 = 45\%$。这个比值在七十年上升的排放中保持稳定——汇严格按比例跟上——是环境科学中最引人注目也最少被解释的事实之一，而它可能的崩溃是下个世纪碳循环的核心不确定度。
:::
:::

::: exercise 总停留时间 {level=1 check="4"}
已知大气$870\ \mathrm{PgC}$、陆地+海洋总交换$210\ \mathrm{PgC\,yr^{-1}}$，求大气CO₂的停留时间（年）。（取整。）
::: solution
$870/210 = 4$ 年。一个分子的地址每四年换一次；而**群体**的多余部分要几个世纪才缩小，因为进出的210几乎相消。关于"CO₂能存在10万年"或"只有5年"的每场公共争论，都是这个区别被弄丢了。
:::
:::

::: exercise 雷维拉算术 {level=2 check="36"}
若DIC上升3%，表层海洋$p\mathrm{CO_2}$上升百分之几（$R = 12$）？（填数字。）
::: solution
$12\times3 = 36\%$。缓冲把分压响应放大十二倍——这就是海洋在表层如此迅速地拒收人为碳、其真正的吸收取决于向深海广阔、寒冷、低雷维拉内部缓慢输送碳的原因。

::: exercise 苏斯混合 {level=2 check="6"}
空气的$\delta^{13}\mathrm{C}$已从$-6.5\permil$下降$1.1\permil$；化石碳为$-25\permil$。求空气碳中化石来源的分数（百分比，取整）。（填数字。）
::: solution
$f = 1.1/18.5 = 6\%$。空气自身的稀释——它的碳已经与正在变轻的海洋和生物圈混合——是为什么需要**整个**地球系统而非仅空气的同位素记录来清点排放的碳；$^{14}\mathrm{C}$和$\mathrm{O_2}$记录补上缺失的交换。
:::

::: exercise 海洋酸化 {level=2 check="30"}
表层海洋pH从8.19降到8.08。求氢离子浓度上升的百分比。（填数字。）
::: solution
$10^{0.11} - 1 = 29\%$，约30。"零点几个pH单位"的说法掩盖了氢离子尺度：海洋对造壳物质的腐蚀性已经增加了三分之一，而总碳酸盐化学不变；必须逆着梯度泵碳酸根离子的生物最先感到——南大洋的翼足类和美国太平洋沿岸的牡蛎幼体已经感到了。
:::

::: exercise 混合层的拒收 {level=3 check="91"}
若只有表层海洋（1000 PgC，$R = 12$）与大气（870 PgC）平衡，相等的$\Delta p\mathrm{CO_2}$要求$\Delta C_a/870 = R\,\Delta C_o/1000$。导出空气分数$\Delta C_a/(\Delta C_a+\Delta C_o)$并以百分数求值。（填数字。）
::: solution
由相等分压条件，$\Delta C_a/\Delta C_o = 870\times12/1000 = 10.4$，空气分数为$10.4/11.4 = 91\%$。观测到的45%因此是深海和陆地在做额外工作的**证明**，也是最干净的演示：海洋汇是环流补贴的服务，其持久性取决于翻转环流，而不是这个计算显示单靠自己几乎无望的表层化学。
:::

::: exercise 预算时钟 {level=3 check="13.5"}
2020年起，1.5 °C剩余预算为$500\ \mathrm{GtCO_2}$，排放$37\ \mathrm{GtCO_2\,yr^{-1}}$。求恒定排放下耗尽的年数（保留一位小数），并解释为什么在同样年限内线性降到零只用掉预算的一半。
::: solution
恒定排放：$500/37 = 13.5$ 年。$t$年内线性降到零排放$E_0 t/2$，所以同样的预算撑$2\times13.5 = 27$ 年——"2050年净零"的算术：目标日期不是由任何时刻的年速率决定，而是由**曲线下面积**决定，这就是为什么早期陡峭的减排回报超比例：预算是积分，而气候因为是累积的，是人类曾经谈判过的最具积分约束的对象。
