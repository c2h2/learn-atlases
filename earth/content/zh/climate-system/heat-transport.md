热带在大气顶吸收的辐射比发射的多约$60\ \mathrm{W\,m^{-2}}$，冬极夜带损失的几乎同样多，而这一差额——热带每纬度带持续约$60$太瓦的净损失——就是发动机的燃料账单。大气和海洋合计把约$5$–$6$百万兆瓦从热带送往极地，超过人类文明耗电量的百倍；没有这条传送带，热带会热上几十度，极地会冷得认不出来。这份输送如何完成——由哪些载体、在哪些纬度、什么季节，海洋承担多少——是气候系统中测得最精、也最不被理解的环节之一：凭卫星和船只我们能把收支画到百分之十以内，却仍然说不出它本世纪会如何移动。

## 观测到的收支

::: definition 极向能量输送的结构 {#def-transport-budget}
总能量（辐射加潜热加感热，大气加海洋）的纬向平均、垂直积分输送在年均上于$20^{\circ}\mathrm{N}$附近达到约$5\ \mathrm{PW}$的峰值，南半球在$20^{\circ}\mathrm{S}$附近有$3$–$4\ \mathrm{PW}$的次峰；年均上在赤道降到近零——两个半球的峰值隔着一个输送谷底相望——向极地也下降，因为驱动它的温度对比在消失。大气约承担总量的三分之二，在分点附近达峰、随季节对比迁移；海洋承担其余，其份额在大西洋最大——西边界流与翻转环流合计在$25\ ^\circ\mathrm{N}$输送约$1.3\ \mathrm{PW}$——一个海盆占了全球跨赤道能量输送的一半。这套数字的图集是**奥尔特（Adriaan Oort）**与**佩肖托（Jorge Peixoto）**的心血：他们从1950年代到1990年代编纂的水文与探空资料至今仍是标准参考，如今再由2000年以来的CERES辐射收支交叉校验。
:::

::: example 大气输送的扩散估计 {#ex-diffusive}
用涡旋扩散参数化大气能量输送：有效扩散率$D = 1\times10^{6}\ \mathrm{m^{2}\,s^{-1}}$，作用深度$H = 5\ \mathrm{km}$（$\rho c_p = 1206\ \mathrm{J\,m^{-3}\,K^{-1}}$），平均经向温度梯度$|\mathrm{d}T/\mathrm{d}y| = 6\times10^{-6}\ \mathrm{K\,m^{-1}}$（每一千公里$6\ \mathrm{K}$）。求$30^{\circ}$纬圈上的输送。
::: solution
单位面积通量$\rho c_p D\,|\mathrm{d}T/\mathrm{d}y| = 1206\times10^{6}\times6\times10^{-6} = 7.2\ \mathrm{W\,m^{-2}}$，乘以周长$2\pi a\cos30^{\circ} = 3.5\times10^{7}\ \mathrm{m}$、深度$H$的带，
$$
F = 7.2 \times (3.5\times10^{7}\times5\times10^{3}) = 1.3\times10^{15}\ \mathrm{W} = 1.3\ \mathrm{PW}.
$$
一个说得过去的扩散率给出一拍瓦——观测的大气峰值$3$–$4\ \mathrm{PW}$需要$D \sim (2\text{–}3)\times10^{6}\ \mathrm{m^{2}\,s^{-1}}$；这个比分子值高两个数量级的数字，就是**涡旋**的定量签名：输送是天气系统干的，不是分子尺度的湍流干的。扩散闭合在中纬度出奇地好用，在热带失灵——那里的输送由翻转环流圈控制——与环流本身展示的分工一致。
:::
:::

## 大气如何携热：风暴与水汽

::: definition 湿静力能与瞬态涡旋通量 {#def-mse}
风暴输送的量是**湿静力能**
$$
M = c_p T + L_v q + g z ,
$$
即感热、潜热和势能；$300\ \mathrm{K}$、含$16\ \mathrm{g\,kg^{-1}}$水汽的地表气块持有$M \approx 3.4\times10^{5}\ \mathrm{J\,kg^{-1}}$，其中潜热项占$12\%$、感热占$88\%$——但因为热带异常**湿润**，潜热涡旋通量在能量收支中与感热通量不相上下。极向输送由**瞬态涡旋**主导：中纬度气旋和反气旋在东侧把暖湿空气推向极地、在西侧把冷干空气拉向赤道，而暖空气的北上更湿、更持久，于是协方差$\overline{v'M}$又正又大。能量记账是洛伦兹的：热带产生、高纬消耗的可用位能以全球约$1.5\ \mathrm{W\,m^{-2}}$的速率转化为涡旋动能，涡旋最终死于摩擦——货物已经卸完。在热带，同样的记账由**哈得来环流与沃克环流**和**大气河**完成——后者是窄而达大陆尺度的水汽通量细带，$2000\ \mathrm{kg\,m^{-1}\,s^{-1}}$的水汽通量乘以$2000\ \mathrm{km}$的宽度就输送$4\times10^{6}\ \mathrm{m^{3}\,s^{-1}}$的水汽，是亚马逊流量的二十倍；中纬度的大部分降水和每一片位于副热带水库下风海岸的极端洪水，都由它们送达。
:::

::: example 大气河的货物 {#ex-ar}
一条水汽通量$2.5\times10^{3}\ \mathrm{kg\,m^{-1}\,s^{-1}}$、宽度$1500\ \mathrm{km}$的大气河登陆，以$12\%$的效率在$24\ \mathrm{h}$内雨出，流域面积$30{,}000\ \mathrm{km^{2}}$。求流域平均降雨量，并与该流域年均总量$800\ \mathrm{mm}$比较。
::: solution
水汽流入$2.5\times10^{3}\times1.5\times10^{6} = 3.75\times10^{9}\ \mathrm{kg\,s^{-1}}$；$12\%$凝结给$4.5\times10^{8}\ \mathrm{kg\,s^{-1}}$；在$24\ \mathrm{h}$、$3\times10^{10}\ \mathrm{m^{2}}$上，
$$
P = \frac{4.5\times10^{8}\times86{,}400}{3\times10^{10}\times1000} = 1.3\ \mathrm{m} .
$$
一天一千三百毫米——超过年总量——这就是极端事件尾部的算术：真实事件在更大的面积、更长的时间上落雨，但这个标度解释了为什么加州内华达山、智利中央谷地和新西兰南阿尔卑斯山每年三分之一的水来自冬天屈指可数的大气河日，也解释了为什么风暴路径随气候变化挪几度就能改写整个区域的供水时间表。
:::
:::

## 海洋的份额

::: definition 风生环流与翻转环流 {#def-ocean-transport}
海洋以两种方式携热。**副热带环流**以西边界流向极地输出热——墨西哥湾流、黑潮、阿古拉斯、巴西、东澳大利亚——其惯性与风生动力学把输送集中成窄而急的射流；**翻转环流**在深层支里携热，最重要的是大西洋经向翻转环流（AMOC）：它在上层一公里把暖盐水在表面送往北方，东北流途中向北大西洋西风带释放$50$–$100\ \mathrm{W\,m^{-2}}$的热，以下沉为北大西洋深层水告终，再缓缓南归。两者并不独立：风生副热带环流圈送来上层支的水，翻转环流再加处理；绕南非的阿古拉斯泄漏则决定盐的供给。海洋的输送是**跨赤道**的，而大气的（年均上）不是：大西洋与印度洋合计约$0.4\ \mathrm{PW}$向北越过赤道，因为北半球陆地比例大、平均降水低、赤道辐合带（ITCZ）位于赤道以北——这是能量框架最干净的一条预言：ITCZ位于能量必须**输入**的那个半球一侧。
:::

::: example 墨西哥湾流的热账单 {#ex-gulfstream}
佛罗里达流在$27\ ^\circ\mathrm{N}$输送$30\ \mathrm{Sv}$（$3\times10^{7}\ \mathrm{m^{3}\,s^{-1}}$），平均温度$25\ ^\circ\mathrm{C}$；同纬度周围水温$15\ ^\circ\mathrm{C}$。估算热通量，以及按$50\ \mathrm{W\,m^{-2}}$它能温暖多大面积的欧洲。
::: solution
取$\rho c_p = 4\times10^{6}\ \mathrm{J\,m^{-3}\,K^{-1}}$，
$$
F = \rho c_p\, Q\, \Delta T = 4\times10^{6}\times3\times10^{7}\times10 = 1.2\times10^{15}\ \mathrm{W} = 1.2\ \mathrm{PW}.
$$
按$50\ \mathrm{W\,m^{-2}}$——大致是欧洲相对其纬度所享有的额外温暖——可加热$2.4\times10^{13}\ \mathrm{m^{2}}$，比整个欧洲还大。老教科书说"湾流单独造就了欧洲的温和"是夸大——盛行的西风带和没有大陆冰盖更重要，湾流下游的海-气通量只有$0.3$–$0.5\ \mathrm{PW}$——但上面的算术正是这个问题被提出、以及AMOC减速在全球变暖中被当作区域温度风险盯防的原因。
:::
:::

::: proposition 整层能量约束与ITCZ {#prop-itcz}
年均上大气能量收支是闭合的：气柱的净辐射冷却$R_{\mathrm{TOA}} - R_{\mathrm{sfc}} - H_{\mathrm{sfc}}$必须由能量输送的散度平衡。因为热带大气近乎湿绝热，其辐射冷却受到严格约束，**能量框架**由此而来：ITCZ的位置、哈得来环流和沃克环流的强度、跨赤道能量输送，由平衡大气能量收支的需要决定，而不是由对流的细节决定。由此得出两条预言，且都被观测到。其一，ITCZ位于气柱辐射冷却最小、输送汇聚最强之处——位于能量**没有**被输出的那个半球。其二，跨赤道能量输送与半球间净辐射不对称成比例——对当前约$6\ \mathrm{W\,m^{-2}}$的不对称约为$0.6\ \mathrm{PW}$——而海洋必须承担大气跨赤道输送与能量收支所需之间的差额——这就是大西洋向北的海洋热输送与大气季节性向南输送相位差六个月的原因。这个框架解释了为什么对"哪里下雨"分歧巨大的气候模型，对"必须移动多少能量"却多少有一致性：能量收支是在模型不确定度中幸存下来的那个约束。
:::

::: example 北边变冷时ITCZ往哪走？ {#ex-itcz-shift}
设某扰动（火山气溶胶，或温室气体驱动的海冰损失）使北半球大气顶净辐射在北半球（$2.6\times10^{14}\ \mathrm{m^{2}}$）变化$-2\ \mathrm{W\,m^{-2}}$。估算跨赤道能量输送所需的改变，并解释ITCZ往哪移动、为什么热带雨带对它的响应比能量数字所示的更剧烈。
::: solution
该扰动从北半球取走$2\times2.6\times10^{14} = 5\times10^{14}\ \mathrm{W} = 0.5\ \mathrm{PW}$。耦合系统的响应是减少向北的海洋热输送（它一直在喂养这个变冷的半球），并把雨带**向南**推移，移向变得相对更暖的半球——ITCZ朝更暖的半球移动，因为现在必须从那个半球向外输出能量以平衡另一个。降水响应被放大，因为热带环流是能量受限的：哈得来与沃克环流的质量通量与它们必须抵消的辐射冷却成比例，于是十分之几拍瓦的能量再分配——总输送的百分之几——就能把雨带挪几千公里——过去一千年的古气候记录一再如此显示。
:::
:::

::: warning 热输送不是天气，湾流不是欧洲的暖气，输送更多也不意味着输送更多
五个错误。**"大气输送热"是能量的简称**：风暴输送的是湿静力能，潜热部分——是水，不是温度——在热带占货物的一半；把湿度算错的模式，能量输送会错两次。**湾流不是欧洲的暖气片**：欧洲温和的冬季主要是西风带读过一条变暖的东边界流、加上没有大陆冰盖的结果；在模型中移除AMOC，欧洲冷却几开尔文，远小于天真的$1.2\ \mathrm{PW}$算术所暗示的，因为那笔通量大部分释放在中纬度延伸体，而不是送到海岸。**输送峰值随季节迁移几十个纬度**，年均图像把它藏了起来；只在某一个季节比较模型可能把两个半球弄反。**海洋的"份额"不是固定比例**：大气和海洋的季节输送部分**相消**，海洋的角色在大气最弱处最大——两者是一台耦合机器，不是两家竞争的公司。**而且变暖的世界不会简单地输送更多能量**：总辐射强迫增大，但输送通过水循环的较慢节奏响应（[[climate-change/responses]]的"快/慢"物理），稳健的信号是输送系统的**极向扩张**——风暴路径和干带向极地移动——而不是简单增强。
:::

::: history
大气能量发动机的第一批定量图景来自**罗斯比（C.-G. Rossby）**芝加哥学派1939–1941年的能量循环与总环流论文；闭合地表一侧的湍流通量则由**普里斯特利（C. H. B. Priestley）**的阿斯彭代尔团队自1950年代测起。本领域的观测丰碑是**佩肖托与奥尔特**把一亿份探空和船舶报告编纂成的大气能量收支，集大成于他们1992年的《气候物理学》——也就是本课的输送图集。海洋一侧由**WOCE**重复水文调查计划（1990–2002年）闭合，该计划首次从边界到边界算平了大西洋热收支；卫星时代的CERES辐射收支（2000年起）从上方校验整个系统。ITCZ的能量框架——雨带的定位以向较冷半球输出能量为准——由**康之明（S.-M. Kang）、席尔德（M. J. Held）、弗里尔森（D. M. W. Frierson）与拉西斯（M. Lacis）**在2008年的模型与理论工作确立，并经**法苏洛（J. Fasullo）**等人的观测检验。
:::

做输送的风暴是[[meteorology/fronts-cyclones]]的气旋，其能量来源是[[atmospheric-dynamics/general-circulation]]的可用位能；它们携带的湿静力能定义在[[atmospheric-dynamics/boundary-layer]]，其凝结在[[atmospheric-dynamics/cloud-physics]]；这里点名的洋流在[[oceanography/wind-driven]]和[[oceanography/overturning]]；它们送来的水在[[climate-system/hydrological-cycle]]定量；AMOC过去的崩溃在[[palaeoclimate/abrupt-change]]；风暴路径的未来变化在[[climate-change/projections]]和[[climate-change/impacts]]。

::: quiz
年均上，大气的极向能量输送由什么主导？
- [ ] 平均经向环流圈（哈得来、费雷尔、极地）。
- [x] 瞬态涡旋——风暴路径上的气旋与反气旋。
- [ ] 红外光子的辐射扩散。
- [ ] 海洋的西边界流。
::: solution
在中高纬度，瞬态涡旋携带能量通量的绝大部分；平均经向环流圈只在热带占主导。光子的辐射扩散对经向输送可以忽略；海洋只承担总量约三分之一——但这道题提醒我们：能量收支里的"总环流"大多**不是**纬向平均环流。
:::
:::

::: summary
- 气候系统把5–6拍瓦从热带搬到极地——超过人类用电的一百倍——大气约承担三分之二、海洋三分之一。
- 中纬度的输送由携带湿静力能的瞬态涡旋完成；热带输送由翻转环流圈完成；扩散闭合在中纬度好用、在热带失灵。
- 海洋的输送集中于西边界流和翻转环流，在大西洋最强，并且在大气（年均）不跨赤道的地方跨赤道。
- 大气河是中纬度的快递车：一条就能携带亚马逊水流量二十倍的水。
- 能量框架——大气整层能量收支——预言了ITCZ的位置和跨赤道输送，是在模型不确定度中幸存的约束。
- 气候变化的稳健信号是输送系统的极向扩张和输水时间表的改写，而不是简单的增强。
:::

## 习题

::: exercise 单位面积通量 {level=1 check="7"}
涡旋扩散率$D = 10^{6}\ \mathrm{m^{2}\,s^{-1}}$，$\rho c_p = 1206\ \mathrm{J\,m^{-3}\,K^{-1}}$，温度梯度每一千公里$6\ \mathrm{K}$，求扩散能量通量（$\mathrm{W\,m^{-2}}$）。（取整数。）
::: solution
$F = \rho c_p D\,|\mathrm{d}T/\mathrm{d}y| = 1206\times10^{6}\times6\times10^{-6} = 7\ \mathrm{W\,m^{-2}}$。每平方米几瓦的面积平均通量，积分到半个半球的带上就是拍瓦——这是辐射收支的"瓦每平方米"与输送图集的"拍瓦"之间的桥。
:::
:::

::: exercise 湿静力能 {level=1 check="342"}
求$300\ \mathrm{K}$、$q = 16\ \mathrm{g\,kg^{-1}}$空气的$M = c_p T + L_v q$（$\mathrm{kJ\,kg^{-1}}$）。（取整数。）
::: solution
$M = 1005\times300 + 2.5\times10^{6}\times0.016 = 301.5 + 40 = 342\ \mathrm{kJ\,kg^{-1}}$。潜热项在地表占$12\%$，但向极地相对重要性增大——这就是为什么某个涡旋的水汽通量在冷空气爆发中的分量比温度场单独所示的更重要。
:::
:::

::: exercise 大气水的滞留时间 {level=1 check="9"}
全球降水$505{,}000\ \mathrm{km^{3}\,yr^{-1}}$，大气水含量$12{,}900\ \mathrm{km^{3}}$。求滞留时间（天）。（填数字。）
::: solution
$\tau = 12{,}900/505{,}000\times365 = 9\ \mathrm{天}$。大气只装着九天的雨：每一次干旱预报都是对一条九天传送带停摆的预报；每一个"水循环随变暖加速多快"的估计都由这个周转率决定，而不是海洋的四千年。
:::
:::

::: exercise 湾流热通量 {level=2 check="1.8"}
黑潮在$30\ ^\circ\mathrm{N}$输送$45\ \mathrm{Sv}$，相对周围环境有$10\ \mathrm{K}$的异常。求热输送（PW，$\rho c_p = 4\times10^{6}\ \mathrm{J\,m^{-3}\,K^{-1}}$）。（保留一位小数。）
::: solution
$F = 4\times10^{6}\times4.5\times10^{7}\times10 = 1.8\times10^{15}\ \mathrm{W} = 1.8\ \mathrm{PW}$。黑潮与湾流各约一拍瓦——连同阿古拉斯流，构成副热带海洋向北热输送的主体，而全部集中在百公里宽的射流里。
:::

::: exercise 跨赤道记账 {level=2 check="0.4"}
年均上大气向**南**跨赤道输送$0.2\ \mathrm{PW}$，而辐射不对称所要求的跨赤道总能量输送为向**北**$0.2\ \mathrm{PW}$。海洋必须输送多少、朝哪个方向？（填PW数值。）
::: solution
海洋必须向北输送$0.4\ \mathrm{PW}$——所需总量加上大气的向南亏欠。这正是大西洋的观测情形：大气和海洋在赤道上朝**相反**方向输能；海洋份额更大，所以ITCZ的平均位置由耦合系统的能量收支决定，而非任一环流单独决定。
:::

::: exercise 风暴路径的能量 {level=2 check="3.1"}
一个中纬度气旋存活6天，在$3\times10^{6}\ \mathrm{km^{2}}$上以平均$2\ \mathrm{W\,m^{-2}}$的速率转化可用位能。求其总能量消耗（以$10^{18}\ \mathrm{J}$为单位）。（保留一位小数。）
::: solution
$E = 2\times3\times10^{12}\times6\times86{,}400 = 3.1\times10^{18}\ \mathrm{J}$——约英国全年能耗的百分之四十，被一场风暴在六天内花掉。这个比较是大气发动机的诚实尺度：单个天气系统运行的能量流与一个国家的预算相当——这就是预报它们在科学上很难、在能量上微不足道、而控制它们毫无希望的原因。
:::

::: exercise 推导扩散闭合 {level=3 check="1.3"}
从良好混合示踪物涡流通量的$F_y = -\rho c_p D\,\partial \bar T/\partial y$出发，写出穿过有效深度$H$纬圈的总输送，证明$F = 2\pi a \cos\phi\, H\, \rho c_p D\,|\partial\bar T/\partial y|$。取$30^{\circ}$、$D=10^{6}\ \mathrm{m^{2}\,s^{-1}}$、$H=5\ \mathrm{km}$、梯度每一千公里$6\ \mathrm{K}$，以PW计。（保留一位小数。）
::: solution
单位面积通量$\rho c_p D|\partial\bar T/\partial y| = 7.2\ \mathrm{W\,m^{-2}}$；横截面积是带周长乘深度，$2\pi a\cos30^{\circ}\times H = 3.5\times10^{7}\times5\times10^{3} = 1.8\times10^{11}\ \mathrm{m^{2}}$，于是
$$
F = 7.2\times1.8\times10^{11} = 1.3\times10^{15}\ \mathrm{W} = 1.3\ \mathrm{PW}.
$$
闭合式的物理是：瞬态涡旋在行星尺度上表现得像分子——把位温沿梯度混合——而它在热带的失效（梯度小而输送大）正是热带由翻转环流而非扩散控制的证据。佩肖托与奥尔特首次定量了这个分歧，ITCZ的能量框架由此而生。
:::

::: exercise 能量受限的环流 {level=3 check="1.6"}
热带大气辐射冷却为$80\ \mathrm{W\,m^{-2}}$，作用于$8\times10^{6}\ \mathrm{km^{2}}$的对流带，由哈得来环流对抗上下层湿静力能差$\Delta M = 4\times10^{4}\ \mathrm{J\,kg^{-1}}$输出。求环流圈的质量通量（以$10^{10}\ \mathrm{kg\,s^{-1}}$为单位）。（保留一位小数。）
::: solution
待输出的功率为$80\times8\times10^{12} = 6.4\times10^{14}\ \mathrm{W}$，故质量通量为
$$
\Psi = \frac{6.4\times10^{14}}{4\times10^{4}} = 1.6\times10^{10}\ \mathrm{kg\,s^{-1}},
$$
与再分析对哈得来环流质量流函数$1$–$2\times10^{10}\ \mathrm{kg\,s^{-1}}$的估计吻合良好。这道题真正的教训是能量受限的逻辑：环流强度由它必须承载的辐射功率除以其发动机的热力学效率$\Delta M$决定；这就是为什么变暖的世界——辐射冷却升得慢而$\Delta M$几乎不变——即使环流的范围在变，其质量通量也几乎不变。
:::
