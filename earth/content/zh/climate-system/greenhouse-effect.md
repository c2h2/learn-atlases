温室效应是环境科学中被讨论最多、却最少被真正理解的概念。几乎每个人都能说出某些气体让阳光进来、把热量留住；却几乎没有人能说出行星实际上是在大气的哪个高度向太空散失热量的，为什么那个高度正是二氧化碳所控制的东西，以及为什么那些流行的反驳——吸收带已经饱和、逆辐射违反热力学第二定律、水汽是强得多的温室气体所以二氧化碳无关紧要——全都是错的。本章从一个最简单的模型出发，向上搭建起整个机制。

用一句话讲清要点：地球不是从地面向太空辐射的。它是从一个高度辐射的，那个高度很冷，而增加温室气体就是把那个高度往上推进更冷的空气里，因此下方的行星必须变暖，才能恢复支出的热流。

## 灰辐射与分层模型

::: definition 光学厚度与灰大气 {#def-optical-depth}
一层的**光学厚度**$\tau$是沿路径的积分吸收，$\mathrm{d}\tau = \rho \kappa\,\mathrm{d}z$，因此穿过它的一束光被衰减$e^{-\tau}$倍。吸收系数不随波长变化的大气称为**灰**大气。真实大气没有谁是灰的——太阳光与地球辐射的波长相差约二十倍，而大气对前者近乎透明、对后者近乎不透明——但灰的理想化恰好抓住了温室机制的精髓，这正是它自1906年施瓦西（Schwarzschild）以来一直被使用的原因。
:::

::: proposition $N$层模型 {#prop-layers}
考虑$N$层大气，对太阳辐射透明、对红外完全不透明，处于辐射平衡。每层向上下各发射$\sigma T^4$，地表发射$\sigma T_s^4$。则最上层向太空辐射$240\ \mathrm{W\,m^{-2}}$，而温度满足
$$
\sigma T_s^4 = (N+1)\,\sigma T_e^4, \qquad T_s = (N+1)^{1/4}\,T_e ,
$$
其中$T_e = 255\ \mathrm{K}$为发射温度。
:::

::: proof
从上往下算。第$N$层向上发射$240$，故$\sigma T_N^4 = 240$。它同时向下发射$240$，所以第$N-1$层必须向上发射$480$才能收支相抵，即$\sigma T_{N-1}^4 = 2\times240$。继续向下，自顶数第$k$层满足$\sigma T^4 = (k+1)\times240$；而地表——它接收到的只有最底层的向下发射、别无其他——满足$\sigma T_s^4 = (N+1)\times240 = (N+1)\sigma T_e^4$。每往下一层就更暖，因为它必须发射它之上所有层的热流*加上*自己那一份。这个结果一行字就是全部机制：不透明度迫使地表比发射温度高出"不透明层数之四次方根"倍。
:::

::: example 一层太多，两层太少 {#ex-layers}
取$T_e = 255\ \mathrm{K}$，计算$N = 1$、$2$、$5$和$20$层时的地表温度，并评论对$N$的敏感度。
::: solution
$T_s = 255(N+1)^{1/4}$给出$N = 1$时$303\ \mathrm{K}$、$N=2$时$336\ \mathrm{K}$、$N=5$时$399\ \mathrm{K}$、$N=20$时$546\ \mathrm{K}$。

单层模型给出$303\ \mathrm{K}$，偏暖十五开尔文；这正是教科书里"单层大气吸收再发射"示意图作为教学工具并不称职的原因：它碰巧能用，只是因为模型错在一个恰好过冲的方向上。再往前推它就彻底失效——二十个不透明层给出$546\ \mathrm{K}$，那是高压锅的温度。要点在*标度关系*，不在标定。真实大气在某些波段不透明、在另一些波段透明，因此倍增吸收体并不会增加整数个不透明层；它按对数加深已有的不透明层，这才是二氧化碳的响应取对数形式而非爆炸形式的原因。
:::
:::

## 灰大气与热量从哪里逃逸

::: definition 灰大气的温度廓线与表皮层 {#def-grey-profile}
对处于辐射平衡、红外光学厚度$\tau$自太空向下计量的灰大气，爱丁顿近似给出
$$
T^4(\tau) = \tfrac{3}{4}\,T_e^4\left(\tfrac{2}{3} + \tau\right).
$$
在顶部$\tau = 0$处，温度为**表皮温度**$T_e/2^{1/4} = 214\ \mathrm{K}$；行星辐射的出射层$\tau = 2/3$位于$T_e = 255\ \mathrm{K}$；而地表处总光学厚度$\tau_s \approx 1.8$（红外），温度为$288\ \mathrm{K}$。
:::

::: example 发射高度，以及为什么二氧化碳的那么高 {#ex-emission-height}
取标高$7.2\ \mathrm{km}$，地表红外光学厚度$1.8$并随高度指数递减。求$\tau = 2/3$层的高度。然后把二氧化碳当作灰吸收体处理，求倍增时$\tau = 2/3$层会升高多少，以及这会对出射热流造成什么。
::: solution
由$\tau(z) = 1.8\,e^{-z/H} = 2/3$得$z = 7.2\ln(1.8/0.667) = 7.1\ \mathrm{km}$。

若该吸收体是灰的，倍增后$\tau = 2/3$层将位于光学厚度$0.33$之处，即$z = 7.2\ln(1.8/0.333) = 12.0\ \mathrm{km}$——升高$4.9\ \mathrm{km}$，发射层冷却$6.5\times4.9 = 32\ \mathrm{K}$，热流减少$3.8\times32 = 120\ \mathrm{W\,m^{-2}}$。真实的强迫是$3.7\ \mathrm{W\,m^{-2}}$，小了三十倍。

这个差值正是对"饱和"论调诚实版本的回答。二氧化碳*不是*灰的：它的$15\ \mu\mathrm{m}$带中心不透明、两翼透明，而干边际活儿的正是两翼而非带中心。倍增气体把两翼的发射层抬高几百米而非五公里，使有效发射体冷却约$1\ \mathrm{K}$，热流减少$3.7\ \mathrm{W\,m^{-2}}$。带中心确实饱和了；但行星不从带中心辐射。
:::
:::

## 逆辐射，以及那些质疑

地面向上发射$390$–$400\ \mathrm{W\,m^{-2}}$，并从大气吸收约$340\ \mathrm{W\,m^{-2}}$的向下辐射。净结果是约$66\ \mathrm{W\,m^{-2}}$的损失（[[climate-system/energy-budget]]）。对此有两种质疑，都值得能够回应。

::: warning "逆辐射不可能使地表增温——热量不会从冷流向热"
热力学第二定律禁止的是净热流从冷到热，而这里并不存在这样的净流：红外净通量向上，从暖地表流向冷大气。向下通量所改变的不是净流的方向，而是它的*大小*。一个通过气体保温层向冷环境散热的表面，散热变慢了，并且会在大气顶支出同样总量的同时达到更高的平衡温度。这个论点的"电热毯版本"——毯子不可能让你变暖，因为你的体温比毯子高——与辐射版本一样错，而且错因相同。
:::

::: definition 可凝结与不可凝结的温室气体 {#def-condensing}
水汽是地球红外波段最强的吸收体，其含量由地表温度决定：它**会凝结**，因此无法固定在某个量上。二氧化碳、甲烷、氧化亚氮和卤代烃在大气所能达到的任何温度下都不凝结，它们的含量由源和汇决定，而不是由温度决定。它们是**不可凝结**的、或称*恒温器*温室气体的角色：它们设定温度，随后水汽提供约相当于它们自身两倍那么多的额外增暖。
:::

::: proposition 恒温器与放大器 {#prop-thermostat}
在处于辐射-对流平衡、相对湿度固定的大气中，水汽反馈——包括云所诱导的水汽变化——每开尔文地表增暖约增加$+1.5\ \mathrm{W\,m^{-2}}$的强迫，而普朗克响应为$3.3\ \mathrm{W\,m^{-2}\,K^{-1}}$。因此放大因子为
$$
\frac{\lambda_0}{\lambda_0 - f_\text{H$_2$O}} = \frac{3.3}{3.3 - 1.5} = 1.9,
$$
即水汽把仅二氧化碳所能造成的增暖放大约一倍；计入直减率、反照率和云反馈后，总放大约为$2.8$。
:::
::: proof
写出平衡式$\lambda_0\Delta T = \Delta F + f\Delta T$，取$\lambda_0 = 3.3$、$f = 1.5$，则$\Delta T = \Delta F/1.8$，放大为$3.3/1.8 = 1.9$。确立两者角色的判决性实验，是拉西斯（Lacis）等人（2010年）在模型中做的思想实验：把现代大气中的二氧化碳、甲烷、氧化亚氮和臭氧移除，让模型运行。行星冷却，水汽凝结殆尽，云层变薄，冰盖扩张，行星最终永久冻结——以今天的阳光再也回不到温暖。反过来只移除水汽、保留不可凝结气体，行星冷却约$10\ \mathrm{K}$后稳定。水汽是放大器；二氧化碳是恒温器。
:::

::: example 出射光谱实际长什么样 {#ex-spectrum}
卫星对出射长波光谱的观测（雨云号，然后是IRIS，再是AIRS）给出：$10\ \mu\mathrm{m}$窗区亮温约$280\ \mathrm{K}$，$15\ \mu\mathrm{m}$二氧化碳带中心$220\ \mathrm{K}$，其两翼$250\ \mathrm{K}$，$6.3\ \mu\mathrm{m}$水汽带$230\ \mathrm{K}$。把这些换算成高度并解释谱形。
::: solution
以$288\ \mathrm{K}$地表、$6.5\ \mathrm{K\,km^{-1}}$直减率计，亮温$280$、$250$、$230$和$220\ \mathrm{K}$大致对应$1$、$6$、$9$和$10\ \mathrm{km}$。

光谱就是大气的垂直探空：大气透明处行星显得暖（窗区，我们看到的是地表），不透明处显得冷（带中心，看到的是对流层上层），介于两者之间对应部分不透明处。二氧化碳对温室效应的贡献表现为以$15\ \mu\mathrm{m}$为中心的宽谷；而相隔三十年两幅光谱之*差*显示，恰好在这个波段和臭氧波段谷深加深了约$0.4\ \mathrm{W\,m^{-2}}$，其余地方没有变化（哈里尔斯等人，2001年；陈等人，2016年）。这是我们排放的气体被从太空直接测到的辐射指纹。
:::
:::

::: example 指纹：随高度增长的增暖 {#ex-utc}
在相对湿度固定的辐射-对流模型中，二氧化碳倍增使热带对流层上层的增暖约为地表增暖的$1.6$倍，而再分析资料中的热带中层约为$1.2$–$1.5$倍。为什么理论要求高空增暖超过地表增暖？
::: solution
因为大气近乎处于辐射-对流平衡，其温度廓线接近湿绝热线，而穿过更暖地表的湿绝热线并不是平行移动：以绝对温度计，它在高空更陡。等价地说，相对湿度固定意味着高空水汽更多，在那里截留更多向上辐射；而对流释放的潜热释放在同样冷的温度上，因此多出的能量释放在冷空气里，每焦耳的增暖效应更大。

这种"对流层上层放大"是检测与归因所用的指纹之一（[[climate-change/attribution]]）。它也曾是一场真实而有教益的争论：1997至2006年间，探空气球和卫星记录似乎显示高空增暖*少于*地表，与模型相悖。再分析和订正后的卫星记录（经过米尔斯与克里斯蒂订正的RSS和UAH，以及2020年代的ERA5、JRA-3Q等再分析）显示出预期量级的放大，而分歧被追溯到卫星轨道漂移以及微波探测仪昼夜采样处理方式。
:::
:::

::: warning "水汽是更丰富的温室气体，所以二氧化碳不可能重要"
两半句都是真的，结论却推不出来。水汽以十天为尺度响应温度，所以它的含量是气候的*结果*而非气候的*控制钮*：你排不出一吨水蒸气并让它留在大气里，也无法在不把水汽凝结出去的情况下冷却大气。二氧化碳停留几个世纪，并设定水汽凝结时的温度。定量的表述是：水汽和云贡献总温室增暖的约三分之二，而二氧化碳、甲烷、氧化亚氮、臭氧和卤代烃提供决定全局的那三分之一。移除不可凝结气体，行星将进入雪球状态；保留它们而移除水汽则不会（[[#prop-thermostat]]）。
:::

::: quiz
为什么二氧化碳的温室效应不会因其吸收带饱和而消失？
- [ ] 因为在任何浓度下吸收带都没有真正饱和。
- [x] 因为辐射从带翼和从高而冷的高度逃逸，增加气体是把那些高度往上推，而不是在地表增加吸收。
- [ ] 因为二氧化碳也吸收阳光。
- [ ] 因为水汽替它完成吸收。
::: solution
带中心在近地面确实不透明，那里多出来的吸收确实是浪费的。但行星的热量从两翼和上层大气——那里带是薄的——逃逸。增加气体把最后一次散射的面抬升到更冷的空气中，在地表温度不变时减少出射热流——这个减少量（倍增对应$3.7\ \mathrm{W\,m^{-2}}$）就是强迫。观测证明就是卫星光谱上$15\ \mu\mathrm{m}$处不断加深的谷。
:::
:::

::: history
施瓦西（Schwarzschild）在1906年解决了灰辐射平衡问题，那篇论文的最后一节还指出真实大气远非灰的。米兰科维奇（Milankovitch）1920年作为其冰期理论的一部分计算了行星的辐射收支。埃尔萨瑟（Elsasser）1942年建立了第一个地球红外的多带模型。普拉斯（Plass）1956年和默勒（Möller）1963年确立了二氧化碳的强迫在高空被接管——这正是饱和论所忽略之点。真锅与韦瑟拉德（Wetherald）1967年加入对流调整与固定相对湿度的水汽反馈，得到倍增增暖$2.9\ ^\circ\mathrm{C}$；真锅与默勒同年还计算了第一批出射光谱，与新的卫星观测吻合，说服了怀疑者。雨云号与IRIS的存档数据经哈里尔斯等人（2001年）和陈等人（2016年）重新分析，最终给出了二氧化碳波段增强温室效应的直接测量。拉西斯等人（2010年）做了移除不可凝结气体的思想实验，证明由此得到的行星永久冻结，了结了"水汽才是控制钮"的争论。辛普森—中村关于饱和大气所能承载的最大红外热流的极限——约$300\ \mathrm{W\,m^{-2}}$——导出自1927年，并经科尔与阿博特（2016年）修订；它正是"失控温室"是一道硬物理边界而非观点问题的原因。
:::

## 通往何处

本章这些数字所汇入的强迫形式体系在[[climate-system/forcing]]；反馈代数在[[climate-system/feedbacks-sensitivity]]；出射光谱与地表辐射的观测变化在[[climate-change/observed-change]]。逐波段的传输在[[atmospheric-dynamics/radiative-transfer]]展开，固定相对湿度假设背后的湿热力学在[[atmospheric-dynamics/moist-thermodynamics]]，云在[[atmospheric-dynamics/cloud-physics]]。

::: summary
- 行星从一个高度而非从地面散失热量；$N$层灰模型给出$T_s = (N+1)^{1/4}T_e$，灰廓线给出$214\ \mathrm{K}$的表皮和$\tau = 2/3$的发射层。
- 二氧化碳的带中心饱和了，但逃逸的辐射来自两翼和又高又冷的高度，所以增加气体抬高发射层，使每倍增的热流减少$3.7\ \mathrm{W\,m^{-2}}$。
- 向下红外不违反第二定律：净通量向上，温室减缓的是散失而不是逆转它。
- 水汽是放大器（约占响应的三分之二），不可凝结气体是恒温器；移除后者，行星冻结。
- 出射光谱是一次垂直探空，相隔三十年两谱之差就是增强温室效应的直接测量。
- 固定湿度的辐射-对流平衡要求增暖随高度放大：它既是一个指纹，也是历史上争论最终倒向模型的一侧。
:::

## 习题

::: exercise 两层 {level=1 check="336"}
求$T_e = 255\ \mathrm{K}$的两层灰模型的地表温度。
::: solution
$T_s = 255\times3^{1/4} = 336\ \mathrm{K}$。两层模型比单层模型暖$48\ \mathrm{K}$。每多一层所加越少：第三层给$361\ \mathrm{K}$，第十层给$464\ \mathrm{K}$——这些数字的荒谬之处正是[[#ex-layers]]的要旨。
:::
:::

::: exercise 表皮温度 {level=1 check="214"}
求$T_e = 255\ \mathrm{K}$时的表皮温度。
::: solution
$T_\text{skin} = T_e/2^{1/4} = 255/1.189 = 214\ \mathrm{K}$。当卫星沿$15\ \mu\mathrm{m}$带中心正下方俯视时，它看到的就是表皮。
:::
:::

::: exercise 地表的光学厚度 {level=2 check="1.5"}
灰廓线给出$T_s^4 = \tfrac34 T_e^4(\tfrac23 + \tau_s)$。求$T_s = 288\ \mathrm{K}$、$T_e = 255\ \mathrm{K}$所需的总红外光学厚度$\tau_s$。
::: solution
$(288/255)^4 = 1.627 = 0.75(0.667 + \tau_s)$，故$\tau_s = 1.627/0.75 - 0.667 = 1.50$。考虑到真实大气不是灰的、且地表通过窗区辐射，通常引用的红外光学厚度是$1.8$–$2.0$；这个差就是灰近似的代价。
:::
:::

::: exercise 灰吸收体的发射高度 {level=2 check="4.9"}
取$H = 7.2\ \mathrm{km}$，求灰吸收体量倍增时$\tau = 2/3$层升高多少。
::: solution
$\Delta z = H\ln 2 = 4.99\ \mathrm{km}$。观测到的二氧化碳引起的升高只有几百米，因为在相关高度上只有带翼有贡献。
:::

::: exercise 来自发射层的强迫 {level=2 check="3.8"}
若二氧化碳倍增使$15\ \mu\mathrm{m}$带的有效发射层在$6.5\ \mathrm{K\,km^{-1}}$的环境中升高$160\ \mathrm{m}$，求强迫。
::: solution
该层冷却$6.5\times0.16 = 1.04\ \mathrm{K}$，热流下降$3.8\times1.04 = 3.9\ \mathrm{W\,m^{-2}}$，与逐线计算值$3.7$很接近。这个估计粗糙但量级正确，并表明强迫本质上就是直减率乘以发射层的升高。
:::

::: exercise 亮温 {level=2 check="9"}
在水汽带测得亮温$230\ \mathrm{K}$。地表$288\ \mathrm{K}$、直减率$6.5\ \mathrm{K\,km^{-1}}$，辐射来自多高？
::: solution
$z = (288 - 230)/6.5 = 8.9\ \mathrm{km}$。亮温是伪装成温度的高度——这就是为什么卫星上的光谱仪是一台整层对流层的温度计。
:::

::: exercise 失控极限 {level=3}
饱和大气所能承载的最大红外热流的辛普森—中村极限约为$300\ \mathrm{W\,m^{-2}}$。若行星吸收的阳光超过此值会发生什么？地球的吸收热流是多少？
::: solution
地表无法把多余能量辐射出去，就会不断加热直到海洋蒸发：失控温室。地球的吸收热流是$240\ \mathrm{W\,m^{-2}}$，约为极限的$80\%$，而当前地表发射$390\ \mathrm{W\,m^{-2}}$、出射只有$240$——差额由温室保温承担。这个余量正是"微弱年轻太阳"与失控温室文献对宜居性重要的原因；而在地球上，仅凭二氧化碳不可能越过这个余量。
:::

::: exercise 随高度的放大 {level=3}
某热带探空地表为$300\ \mathrm{K}$，沿湿绝热线上升，$500\ \mathrm{hPa}$的增暖为地表增暖的$1.6$倍。若地表增暖$1.2\ \mathrm{K}$，求$500\ \mathrm{hPa}$的增暖以及$200$–$500\ \mathrm{hPa}$层厚度的变化。
::: solution
$500\ \mathrm{hPa}$增暖$1.6\times1.2 = 1.9\ \mathrm{K}$。层厚正比于层内平均温度，因此平均温度从$255$升到$256.5\ \mathrm{K}$的气层增厚$0.6\%$，即$15{,}000\ \mathrm{m}$厚的一层增厚约$90\ \mathrm{m}$；这表现为观测到的$500\ \mathrm{hPa}$位势高度每十年上升数米。探空与再分析记录都能测到，这是热带行为如模型所言的较精妙的证据之一。
:::

::: exercise 双向红外交换 {level=3}
地表发射$396\ \mathrm{W\,m^{-2}}$，吸收向下红外$342\ \mathrm{W\,m^{-2}}$。若向下通量增加$3.7\ \mathrm{W\,m^{-2}}$而地表温度暂不变化，求瞬时红外净变化以及恢复原净值所需的增暖。
::: solution
向上的净损失从$54$降到$50.3\ \mathrm{W\,m^{-2}}$，不平衡量$3.7$。要恢复原净值，地表须多发射$3.7\ \mathrm{W\,m^{-2}}$；在$288\ \mathrm{K}$处$\mathrm{d}(\sigma T^4)/\mathrm{d}T = 5.4\ \mathrm{W\,m^{-2}\,K^{-1}}$，对应$0.69\ \mathrm{K}$——但大气也必须增暖，而大气顶必须把能量排出去，所以廓线调整后实际无反馈响应为$1.0$–$1.2\ \mathrm{K}$。这道题说明了为什么只用地表导数会把地表对给定强迫的敏感度高估约一倍。
:::
