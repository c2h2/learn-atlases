反馈是一个改变引发另一个改变、后者再次改变温度的过程。气候敏感度科学的全部，就是"推行星一把之后它给自己制造了多少额外增暖"这个问题；而答案——地球把仅二氧化碳所能造成的增暖放大约三倍——正是一个红外吸收物理测量得很准的问题，却能产出宽到要命的结果区间的原因。

强迫的已知精度是几个百分点。反馈的已知精度是两倍。"气候科学的不确定度"实际指的是这个不对称，而不是红外吸收物理有任何疑点。

## 代数

::: definition 反馈参数、反馈分数与放大因子 {#def-feedback}
设$\lambda_0$为**普朗克响应**：其他一切固定时，出射辐射随地表增暖每开尔文的增量，$\lambda_0 = 4\sigma T^3 \approx 3.2$–$3.3\ \mathrm{W\,m^{-2}\,K^{-1}}$。若某过程使大气顶收支随增暖每开尔文改变$f_i\Delta T$，它就是一个参数为$f_i$的反馈，增加能量者为正（不稳定）。平衡式为
$$
(\lambda_0 - \textstyle\sum_i f_i)\,\Delta T = \Delta F, \qquad \lambda_\text{net} = \lambda_0 - \sum_i f_i ,
$$
相对无反馈响应的**放大因子**为$A = \lambda_0/\lambda_\text{net}$。**环路增益**为$g = f/\lambda_0$，故$A = 1/(1-g)$。
:::

::: definition 平衡气候敏感度、瞬态响应与已实现增暖 {#def-ecs}
**平衡气候敏感度**（ECS）是气候完全适应二氧化碳倍增之后的全球平均地表温度变化，$\mathrm{ECS} = F_{2\times}/\lambda_\text{net}$，其中$F_{2\times} = 3.7\ \mathrm{W\,m^{-2}}$（AR6标定为$3.91$）。**瞬态气候响应**（TCR）是二氧化碳每年上升$1\%$的实验中倍增时刻的增暖，约七十年。**调整比/已实现增暖比**（ACR）是此类斜坡实验中四倍时刻的增暖与ECS之比，典型为$0.7$–$0.8$。这是同一套物理的三个不同数字，把它们混为一谈是公共讨论中最常见的定量错误。
:::

::: proposition 为什么正反馈不等于失控 {#prop-runaway}
$f < \lambda_0$的正反馈产生有限、收敛的增暖：$A = 1/(1 - f/\lambda_0)$在$f < \lambda_0$时有界，只在$f \to \lambda_0$时发散。$f = \lambda_0$处的发散就是失控温室，它是一道真实的物理边界——大气在任何地表温度下都无法再把行星的热量辐射到太空之点。
:::

::: proof
迭代这个响应。强迫$\Delta F$使地表增暖$\Delta F/\lambda_0$；该增暖释放$f\Delta T$的额外强迫，再增暖$f\Delta T/\lambda_0$，如此下去，得
$$
\Delta T = \frac{\Delta F}{\lambda_0}\left(1 + g + g^2 + \cdots\right) = \frac{\Delta F}{\lambda_0}\frac{1}{1-g}, \qquad g = \frac{f}{\lambda_0} < 1 .
$$
几何级数在$g < 1$时收敛，这正是气候稳定的条件。取评估的总反馈$f = 2.0\ \mathrm{W\,m^{-2}\,K^{-1}}$、$\lambda_0 = 3.2$，得$g = 0.63$、$A = 2.7$：系统是稳定的，但它像一扇装了软闭门的重门那样稳定——要晃很久才停。地球当前状态离$g = 1$很远；辛普森—中村极限——最大红外热流约$300\ \mathrm{W\,m^{-2}}$——是对应的硬上限，而行星只发射$240$。
:::

::: example 一次加一个反馈 {#ex-decomp}
在一个标准分解中（索登等人，2008年），某模型对二氧化碳倍增的响应按反馈逐个搭建：全部关闭时$1.17\ \mathrm{K}$，加水汽$1.84$，加云$2.40$，加直减率$2.72$，加地表反照率$2.94$，全部打开$2.99$。把它换算成反馈参数和放大因子。
::: solution
由$\lambda_\text{net} = F_{2\times}/\Delta T$，逐步的净反馈参数为$3.16$、$2.01$、$1.54$、$1.36$、$1.26$、$1.24\ \mathrm{W\,m^{-2}\,K^{-1}}$，于是各个反馈为

| 加入的反馈 | $f_i\ (\mathrm{W\,m^{-2}\,K^{-1}})$ | 其后的放大因子 |
|---|---|---|
| 水汽 | $1.15$ | $1.57$ |
| 云 | $0.47$ | $2.05$ |
| 直减率 | $0.18$ | $2.32$ |
| 地表反照率 | $0.10$ | $2.51$ |
| 其余 | $0.02$ | $2.56$ |

两个教训。在一个已经失去大部分夏季海冰的模型里，水汽反馈最大、地表反照率反馈最小——排序随气候状态而变，这就是反照率在古气候中占主导、而在当前问题中云占主导的原因。而且这个分解**依赖路径**：以不同顺序加入反馈，同一总量下各项数值不同，因为它们相互作用。任何反馈强度表在说明顺序和方案之前都是约定，不是测量。
:::
:::

## 五个反馈

::: definition 水汽反馈 {#def-wv}
更暖的大气容纳更多水汽，按克劳修斯—克拉珀龙约每开尔文$7\%$，而水汽吸收地球红外。相对湿度大致守恒——环流模型和观测在全球大部分地区都如此——额外的水汽每开尔文地表增暖增加$1.0$–$1.3\ \mathrm{W\,m^{-2}}$的强迫。它是最大的单一反馈，也是理解最透的：它是增暖的热力学后果，不是关于增暖的假说。
:::

::: definition 直减率反馈与地表反照率反馈 {#def-lr-sa}
**直减率反馈**是出射辐射的变化，源于热带增暖时高空比地表更暖、沿湿绝热线移动；由于向太空的发射主要来自对流层上层，热带辐射得更有效率，于是热带给出$-0.3$至$-0.5\ \mathrm{W\,m^{-2}\,K^{-1}}$的*负*反馈。在南极和北极周围符号反转，因为地表位于逆温层中、地表在增暖而自由对流层几乎不暖；而大陆在任何高度都比海洋暖得快。因此全球净值很小、符号可正可负，评估为略正，$+0.2$至$+0.4\ \mathrm{W\,m^{-2}\,K^{-1}}$——这是教科书符号与评估符号少数不一致之处之一，也是谨慎的文献把"直减率加水汽"作为一个量来报告的原因。**地表反照率反馈**是冰雪退却后深色海洋和陆地的裸露，全球值$+0.1$至$+0.7\ \mathrm{W\,m^{-2}\,K^{-1}}$、区域值大得多；它是北极增暖比全球快二到四倍的主要原因。
:::

::: warning 云就是全部的不确定度，这是它难的原因
云同时干两件相反的工作。它们反射阳光，这是冷却；它们截留出射红外，这是增暖；今天云的净强迫约为$-16\ \mathrm{W\,m^{-2}}$，冷却以二比一胜出。变暖的世界可能让云更反射（更稳定的边界层里更多液态水），或更薄（更浅的信风积云盖），或更高更薄（那是增暖），也可能把它们推出明亮的低纬（那也是增暖）。评估的云反馈为$+0.2$至$+0.8\ \mathrm{W\,m^{-2}\,K^{-1}}$、散布约$\pm0.5$，仅此一项就解释了ECS为$2.4$的模型与ECS为$4.5$的模型之间的大部分差异。物理困难在尺度：这个反馈由干空气卷入厘米尺度的积云塔的过程控制，由模型中的云滴是否在正确数量的气溶胶粒子上活化控制——这两样在$100\ \mathrm{km}$的格网里都分辨不出来。米尺度的过程模型现在说低云反馈很可能是正的；它们还没说正多少。
:::

::: example 一个云反馈能差多少？ {#ex-cloudspread}
两个模型除云反馈外一切一致。模型A的$\lambda_\text{net} = 1.37\ \mathrm{W\,m^{-2}\,K^{-1}}$；模型B的云反馈正$0.5\ \mathrm{W\,m^{-2}\,K^{-1}}$。求两者的敏感度，以及各自在$2.9\ \mathrm{W\,m^{-2}}$强迫持续一千年后的增暖。
::: solution
模型A：$3.7/1.37 = 2.7\ ^\circ\mathrm{C}$。模型B：$3.7/0.87 = 4.3\ ^\circ\mathrm{C}$。在$2.9\ \mathrm{W\,m^{-2}}$下分别为$2.1$和$3.3\ ^\circ\mathrm{C}$。

一个未解决的物理过程，每开尔文半瓦的不确定度，就把答案挪动$1.2\ ^\circ\mathrm{C}$——这大约就是《巴黎协定》能实现与不可能实现之间的差距。还要注意非线性：同样的$0.5$若施加在$\lambda_\text{net} = 0.9$的模型上，敏感度会从$4.1$跳到$9.3$。敏感度是一个把不确定量放在分母上的比值，所以误差被不对称地放大，合理敏感度的分布上尾很肥。每一次ECS的贝叶斯评估都继承了这种偏斜。
:::

## 度量不可度量者的三条路

::: example 历史约束及其型效应偏差 {#ex-historical}
1850–1900年以来的观测增暖为$1.09\ \mathrm{K}$，2019年人为有效辐射强迫为$2.7\ \mathrm{W\,m^{-2}}$。估算已实现响应参数，并解释为什么由此得到的ECS估计偏低。
::: solution
$\Delta T/\Delta F = 1.09/2.7 = 0.40\ \mathrm{K}$每$\mathrm{W\,m^{-2}}$，相当于$\lambda = 2.5\ \mathrm{W\,m^{-2}\,K^{-1}}$——离平衡值$1.16$很远。需要两处订正。其一是瞬态亏欠：海洋尚未完成响应，而即便在四倍时刻已实现增暖比也只有$0.7$–$0.8$，所以平衡响应比观测大$25$–$40\%$。其二是**型效应**。

历史强迫的施加格局很特别：硫酸盐气溶胶盘踞在工业化北半球及其上空海洋，使该区域保持凉爽，更重要的是使热带太平洋的海表温度格局保持在*增加*低云、把热量向深层输出的状态。只改变气溶胶强迫的模型实验复现了这一格局，并给出比历史拟合大$0.4$–$0.6\ \mathrm{K}$的类ECS响应（安德鲁斯等人，2019年；舍伍德等人，2020年）。对此的订正，是历史这条曾被斥为太不确定的证据线如今与古气候线、过程线一致的主要原因。
:::
:::

::: example 古气候约束 {#ex-palaeo}
约三百万年前的上新世暖期，二氧化碳为$380$–$450\ \mathrm{ppm}$，全球平均温度比工业化前高$2.5$–$3\ ^\circ\mathrm{C}$，海平面高$5$–$25\ \mathrm{m}$。估算仅由强迫隐含的敏感度，并说明为什么这个估计不能简单地取$\Delta T/\Delta F$。
::: solution
$420\ \mathrm{ppm}$相对$278$的强迫为$5.35\ln(420/278) = 2.2\ \mathrm{W\,m^{-2}}$。取$\Delta T \approx 2.75\ \mathrm{K}$，得$\lambda_\text{net} = 0.80\ \mathrm{W\,m^{-2}\,K^{-1}}$、ECS为$4.6\ ^\circ\mathrm{C}$——高于评估的可能范围。

其一，上新世包含标准ECS定义排除的反馈：西南极和格陵兰冰盖的退却、北极海冰的消失、植被的变化和海洋碳吸收的变化。这些是"慢"或"长"反馈，计入它们会抬高表观敏感度——这就是古气候约束的敏感度高于ECS定义所设想的敏感度的原因。其二，平衡假设只是近似成立：三百万年对冰盖够长，对深海不够，深海吸热当时仍在进行。AR6对上新世、末次盛冰期、中全新世和PETM的综合评估给出ECS为$3.4\ ^\circ\mathrm{C}$、可能范围$2.2$–$5.6\ ^\circ\mathrm{C}$——三条证据线中最宽的一条，也是唯一采样了无冰盖气候的一条。
:::
:::

::: quiz
哪个单一反馈对模型间平衡气候敏感度散布的贡献最大？
- [ ] 水汽，因为湿度观测不足。
- [ ] 地表反照率，因为海冰难模拟。
- [x] 云，尤其是副热带信风区的低云。
- [ ] 直减率，因为它依赖对流。
::: solution
云。水汽被克劳修斯—克拉珀龙关系在热力学上钉死，对*散布*贡献很小；直减率和地表反照率由理论和卫星观测的季节循环约束得还算不错。东副热带海洋的低云量和反射率对稳定度、气溶胶和卷入的响应方式依赖格网参数化，模型之间不仅量级不一致、连符号都不一致。
:::

::: history
阿伦尼乌斯1896年就以"相对湿度守恒"的假设计入了水汽反馈——这个假设在此后每一个模型里都活了下来。卡伦德尔1938年从观测记录估计敏感度约$2\ ^\circ\mathrm{C}$。布迪科1969年把冰-反照率反馈推到气候理论的中心，也随之带来了滞回与双稳态的可能性。塞勒斯1973年证明，一维模型对云量和云高的敏感度大到必须先解决云反馈才能谈其他。罗博克1983年证明云响应的符号取决于固定的是云水含量还是云量——这就是这个领域互相空吵了十年的原因。1979年的查尼报告定下$1.5$–$4.5\ ^\circ\mathrm{C}$的区间，并点名云和海洋为两大未决问题。施莱辛格与真锅在1990年代和2000年代给出了首批均衡的耦合模型估计。阿伯特、科尔与施奈德在2010年代证明饱和大气能承载的最大红外热流——辛普森—中村极限，1927年首次导出——约为$300\ \mathrm{W\,m^{-2}}$，给失控问题一个硬数字。舍伍德、斯托尔洛夫莫等人2016–2020年用观测约束收窄区间；斯托尔洛夫莫的论点是：低于$2\ ^\circ\mathrm{C}$的敏感度要求任何物理模型都给不出的云反馈。CMIP6集合一度把上限推到$5.3\ ^\circ\mathrm{C}$，随后其中若干高敏感度模型被证明其低云参数化与观测季节循环不符。AR6（2021年）结论为$3.2\ ^\circ\mathrm{C}$，可能大于$2.5$、极不可能大于$5$——这是评估第一次宣布可以排除低敏感度。
:::

## 通往何处

敏感度在[[climate-system/forcing]]里把强迫变成增暖；海洋延迟答案的角色在[[climate-system/heat-transport]]和[[oceanography/overturning]]；用于约束反馈的观测在[[climate-change/observed-change]]；由此产生的预估在[[climate-modelling/ensembles-scenarios]]；主导深时的冰-反照率和慢反馈在[[palaeoclimate/deep-time]]和[[glaciology/ice-sheets]]。

::: summary
- 反馈写成$\lambda_\text{net}\Delta T = \Delta F$，$\lambda_\text{net} = \lambda_0 - \sum f_i$；放大因子为$\lambda_0/\lambda_\text{net}$，只在$\lambda_\text{net} \to 0$时发散。
- 仅普朗克响应对倍增给$1.1\ \mathrm{K}$；水汽使其近乎翻倍；云、直减率和地表反照率把总数推到约三倍。
- 云贡献了大部分散布，因为它既冷却又增暖，而决定谁占上风的物理过程在格网之下。
- ECS、TCR和已实现增暖是不同的数字：对当前分别约为$3.2$、$1.8$和$1.1\ ^\circ\mathrm{C}$；对于当前强迫承诺的增暖，海洋迄今只兑现了约一半。
- 三条独立证据线——经过型效应订正的历史记录、无冰盖与冰期世界的古气候、云的过程模型——如今一致认为敏感度约为$3\ ^\circ\mathrm{C}$、几乎肯定高于$2$。
- 正反馈不是失控：评估的环路增益为$0.63$，硬上限是辛普森—中村极限的$300\ \mathrm{W\,m^{-2}}$，而行星当前发射$240$。
:::

::: exercise 放大因子 {level=1 check="1.6"}
某反馈$f = 1.2\ \mathrm{W\,m^{-2}\,K^{-1}}$，$\lambda_0 = 3.2$。求放大因子和环路增益。
::: solution
$A = 3.2/(3.2 - 1.2) = 1.6$；$g = 1.2/3.2 = 0.38$。该反馈给增暖加了$60\%$。

::: exercise 由反馈参数求敏感度 {level=1 check="3.2"}
求$\lambda_\text{net} = 1.16\ \mathrm{W\,m^{-2}\,K^{-1}}$、$F_{2\times} = 3.7\ \mathrm{W\,m^{-2}}$时的ECS。
::: solution
$3.7/1.16 = 3.2\ ^\circ\mathrm{C}$，AR6的最佳估计。用AR6的强迫$3.91$则得$3.4\ ^\circ\mathrm{C}$；不同评估采用的标定不同——引用数字之前值得查一下。

::: exercise 克劳修斯—克拉珀龙 {level=2 check="1.07"}

::: exercise 边界附近的环路增益 {level=2 check="9.3"}
求$f = 2.8$、$\lambda_0 = 3.2$时的放大因子，再求$f = 3.0$时。
::: solution
$A = 3.2/0.4 = 8.0$，以及$3.2/0.2 = 16$。敏感度在$g = 1$附近过度敏感：同样的反馈增量在那里值$g = 0.4$处十倍以上的增暖。这就是敏感度分布长上尾的数学原因，也是排除高敏感度远比排除低敏感度困难的原因。
:::

::: exercise 承诺增暖 {level=2 check="2.5"}
2022年人为有效辐射强迫为$2.9\ \mathrm{W\,m^{-2}}$，已实现增暖$1.2\ \mathrm{K}$。用评估的反馈参数求平衡增暖，以及已实现的比例。
::: solution
$2.9/1.16 = 2.5\ ^\circ\mathrm{C}$，其中$1.2/2.5 = 48\%$已经出现。要把这个数字止住，唯一的办法是把排放降到零；排放在今天水平上保持不变只会继续增加强迫，承诺增暖随每一年拖延而增长。
:::

::: exercise 瞬态亏欠 {level=3}
在每年$1\%$的二氧化碳增长中，倍增时（第70年）增暖$1.8\ \mathrm{K}$，四倍时（第140年）增暖$4.6\ \mathrm{K}$，而ECS为每倍增$3.2\ \mathrm{K}$。求TCR和已实现增暖比，并解释为什么该比小于一。
::: solution
$\mathrm{TCR} = 1.8\ \mathrm{K}$，故$\mathrm{ACR} = 4.6/(2\times3.2) = 0.72$。比值小于一，因为海洋混合层热容量为$4\times10^{8}\ \mathrm{J\,m^{-2}\,K^{-1}}$、扩散时间尺度以世纪计：热量被埋进深层的速度超过地表把它辐射回去的速度——这与让$-2.8\ \mathrm{W\,m^{-2}}$的火山强迫只产生$0.4\ \mathrm{K}$冷却的是同一效应。
:::

::: exercise 涌现约束 {level=3}
在某模型集合中，ECS与观测的东副热带平均低云反射率的相关系数为$r = -0.72$。集合平均ECS为$3.6\ ^\circ\mathrm{C}$、散布$0.8$；观测的反射率高于集合平均$0.9$个标准差；回归斜率为每标准差$-1.4\ ^\circ\mathrm{C}$。估算受约束的ECS及其残差不确定度。
::: solution
$\mathrm{ECS} = 3.6 + (-1.4)(0.9) = 2.3\ ^\circ\mathrm{C}$。由$r^2 = 0.52$，残差散布为$0.8\sqrt{1 - 0.52} = 0.55\ ^\circ\mathrm{C}$，即约$2.3 \pm 0.6\ ^\circ\mathrm{C}$——但它的可靠性仅限于"相关是因果的、真实世界落在集合行为范围之内"这两个假设。

现代大多数敏感度约束就是这个做法，其弱点也是已知的：因同一原因出错的模型彼此相关；卫星反射率在暗海洋上空带有反演偏差；不包含真值的集合无法约束真值。AR6给出的范围比CMIP6集合散布更窄，原因恰恰是好几个使用不同观测、不同物理的此类约束指向了同一方向。
:::

::: exercise 慢反馈 {level=3}
末次盛冰期比工业化前冷约$5\ ^\circ\mathrm{C}$，二氧化碳为$190\ \mathrm{ppm}$；上新世在$420\ \mathrm{ppm}$时暖约$2.75\ ^\circ\mathrm{C}$。估算各自隐含的反馈参数，并解释为什么冰期值的量级大于现代的评估值。
::: solution
冰期：$\Delta F = 5.35\ln(190/278) = -2.0\ \mathrm{W\,m^{-2}}$，故$\lambda = 2.0/5 = 0.40\ \mathrm{W\,m^{-2}\,K^{-1}}$。上新世：$2.2/2.75 = 0.80$。两者都远低于评估的$1.16$。

原因是那两个世界都动用了现代ECS定义排除的反馈：冰期是巨大的冰盖和冰-反照率变化，上新世是冰盖、植被和永久冻土的变化。这个教训是双向的。在大冰盖或无冰盖世界里测得的敏感度，不是我们所在世界的敏感度——而我们正在进入的世界，一旦西南极和格陵兰被承诺，其表现将更接近上新世的数字而非全新世的。所谓"慢反馈使长期答案比ECS所示更糟"，说的就是这个。
:::
