气候系统只有一个总表：地球吸收什么与发射什么之间的差。其余一切——风、风暴、洋流、冰、季节、你今天早上围着安排的那场天气——都是行星把这份不平衡搬来搬去并把它消化掉的机器。本章就是把账算清楚。它是整门课程的定量骨架，而这些数字一旦记住，就能让你在十秒之内检验任何关于气候变化的说法。

记账分两层。在大气层顶，一个数字决定行星是否增暖：吸收的日光减去发射的红外。在地表，则有一大堆更大的流动——阳光进、红外出、水蒸发、空气被加热——必须平衡，而它们平衡的方式决定了地面有多热、下多少雨，以及为什么热带湿润而副热带干燥。

## 大气层顶的收支

::: definition 全球能量收支 {#def-budget}
全球年平均而言，地球在大气层顶接收$340\ \mathrm{W\,m^{-2}}$的太阳辐射（太阳常数$1{,}361\ \mathrm{W\,m^{-2}}$的四分之一，因为球面面积是圆盘面积的四倍）。其中$100\ \mathrm{W\,m^{-2}}$被反射——$23\ \mathrm{W\,m^{-2}}$由地表、$77\ \mathrm{W\,m^{-2}}$由云和空气反射，行星反照率为$0.29$——$240\ \mathrm{W\,m^{-2}}$被吸收：地表$163\ \mathrm{W\,m^{-2}}$、大气$77\ \mathrm{W\,m^{-2}}$。气候平衡时被吸收与被发射的通量相等；观测到的不平衡为$0.7$–$1.0\ \mathrm{W\,m^{-2}}$，而这个残差就是全球变暖。
:::

不平衡有两种测法，而两种方法的一致是观测海洋学最安静的胜利之一。卫星（ERBE，以及2000年以来的CERES）直接对入射与出射辐射作差，得到2010–2020年为$0.83 \pm 0.13\ \mathrm{W\,m^{-2}}$（Loeb等，2021年）。吸收了约九成多余热量的海洋则由Argo浮标独立称重，这些浮标测量上$2{,}000\ \mathrm{m}$的温度和盐度；其隐含的全球平均加热为$0.7$–$0.9\ \mathrm{W\,m^{-2}}$且在上升。其余部分加热大陆（$5\%$）、融化冰（$3\%$）、加热空气本身（$1\%$）。

::: definition 发射温度与有效温室效应 {#def-emission}
一个向太空辐射$240\ \mathrm{W\,m^{-2}}$的行星，其黑体发射温度为
$$
T_e = \left(\frac{S(1-\alpha)}{4\sigma}\right)^{1/4} = 255\ \mathrm{K},
$$
即大气中大部分向外红外辐射逃逸出去的那个高度的温度。地表为$288\ \mathrm{K}$，故**有效温室效应**为$33\ \mathrm{K}$。
:::

::: proposition 大气从下往上被加热，地表从上往下被加热 {#prop-heating}
地球吸收的太阳能中，到达地表的是大气的两倍。但地表以$84\ \mathrm{W\,m^{-2}}$的潜热、约$20\ \mathrm{W\,m^{-2}}$的感热和约$66\ \mathrm{W\,m^{-2}}$的净红外向大气损失能量，合计超过它从太阳得到的份额。因此大气的热量收支由地表通量主导，而不是由直接吸收阳光主导。
:::

::: proof
写出地表收支：吸收的太阳辐射$163$等于净红外$66$加潜热$84$加感热$20$，残差约$7\ \mathrm{W\,m^{-2}}$（"闭合问题"，[[#ex-closure]]）。写出大气收支：吸收的太阳辐射$77$加净红外$66$加潜热$84$加感热$20$等于$247$，对应向太空发射的$240$加上一个小的向下红外残差。这两个式子是同一个方程从两端读出来的。其后果是结构性的：水汽和云——两个最主要的长波吸收体——住在大气里，而大气对阳光大体透明，所以大气不能被理解成一种被太阳加热的流体。它是一种被地表加热的流体，只不过恰好对入射辐射透明。这就是为什么决定信风逆温高度和云顶高度的是边界层，而不是太阳辐射的辐射传输。
:::

::: example 蒸发是最大的单项 {#ex-evap}
全球平均潜热通量为$84\ \mathrm{W\,m^{-2}}$。汽化潜热取$2.45\ \mathrm{MJ\,kg^{-1}}$，求全球平均蒸发量，以$\mathrm{mm\,day^{-1}}$和$\mathrm{m\,yr^{-1}}$表示，并与全球平均降水$965\ \mathrm{mm\,yr^{-1}}$比较。
::: solution
$$
E = \frac{84\ \mathrm{W\,m^{-2}}}{2.45\times10^{6}\ \mathrm{J\,kg^{-1}}} = 3.4\times10^{-5}\ \mathrm{kg\,m^{-2}\,s^{-1}} = 2.96\ \mathrm{mm\,day^{-1}} = 1.08\ \mathrm{m\,yr^{-1}} .
$$

这与观测降水相差不到$12\%$，而稳态下两者必须相等，所以能量与水文互相闭合。这个比较值得细想：行星每年蒸发一米的水，每一平方米都是如此，并以潜热形式搬运$84\ \mathrm{W\,m^{-2}}$——相当于地表所吸收阳光的三分之一。蒸发而不是感热，才是地表排出热的主导方式，这就是为什么灌溉能给城市降温、为什么土壤变干时热浪会加剧、以及为什么水循环和能量收支是同一个课题（[[earth-system/water-cycle]]）。
:::
:::

## 红外到哪里去了

阳光是约$5{,}800\ \mathrm{K}$的谱，峰在$0.5\ \mu\mathrm{m}$，大气对它大体透明。地球发射约$255\ \mathrm{K}$的谱，峰在$10\ \mu\mathrm{m}$，而大气对它就并不透明：水汽在$18\ \mu\mathrm{m}$以外的转动带以及$6.3$和$2.7\ \mu\mathrm{m}$处吸收，二氧化碳在$15$和$4.3\ \mu\mathrm{m}$，臭氧在$9.6\ \mu\mathrm{m}$，甲烷在$7.7\ \mu\mathrm{m}$。在各吸收带之间，约$8$–$13\ \mu\mathrm{m}$，是**大气窗口**，地表热辐射的约$20\%$由此直接逃逸。

::: warning "二氧化碳吸收带已经饱和，所以再多二氧化碳也没用"
这个论证从十九世纪九十年代就有人提出，也错了这么久。$15\ \mu\mathrm{m}$带的中心在近地面确实几米之内就不透明，所以在*那里*加二氧化碳什么也不改变。但逃逸到太空的辐射并不是在近地面发射的。它平均从$5$–$6\ \mathrm{km}$的高处发射，那里的大气薄到带中心也透明。增加二氧化碳会把那个发射层抬高几百米，而抬到的位置更冷，于是行星辐射得更少。证明是观测性的：从1970年（Nimbus）到2000年代（IRIS，随后CERES）的卫星光谱显示，出射辐射恰好在二氧化碳和臭氧带上出现了可测量的、光谱分辨的下降，其量级与逐线辐射传输的预言一致。
:::

::: example 倍增的辐射强迫与无反馈的增暖 {#ex-forcing}
二氧化碳的辐射强迫可用$\Delta F = 5.35\ln(C/C_0)\ \mathrm{W\,m^{-2}}$很好地近似。求倍增的强迫，以及若唯一响应是$255\ \mathrm{K}$发射体的普朗克（黑体）响应时的全球平均温度变化。
::: solution
$\Delta F = 5.35\ln 2 = 3.7\ \mathrm{W\,m^{-2}}$。把$F = \sigma T_e^4$在$T_e = 255\ \mathrm{K}$附近线性化得$\mathrm{d}F/\mathrm{d}T = 4\sigma T_e^3 = 3.8\ \mathrm{W\,m^{-2}\,K^{-1}}$，故
$$
\Delta T = \frac{3.7}{3.8} = 0.97\ \mathrm{K}.
$$

标准说法是$1.0$–$1.2\ \mathrm{K}$，其差别来自导数取在发射温度还是地表温度，以及是否允许平流层调整（允许调整才是正确的，它使强迫减少约$0.7\ \mathrm{W\,m^{-2}}$，这就是引用值为$3.7$而不是$4.4$的原因）。这个无反馈增暖是本学科最有用的单个数字：观测增暖大致等于它，这意味着就"我们已经排放的东西"这笔账而言，反馈到目前为止大致中性——而评估出的反馈是正的，因此平衡响应为$2.5$–$4\ ^\circ\mathrm{C}$（[[climate-system/feedbacks-sensitivity]]）。
:::
:::

## 地表收支及其尴尬

::: definition 鲍文比与闭合问题 {#def-bowen}
**鲍文比**$\beta = H / L$是地表感热通量与潜热通量之比。海洋上$\beta \approx 0.1$；植被良好、水分充足的陆面为$0.2$–$0.5$；干燥牧场或城市为$1$–$10$。**闭合问题**指同一站点上涡动相关通量塔测得的湍流通量之和与净辐射之间的持续偏差，量级为可用能量的$10$–$20\%$。
:::

::: example 闭合问题是个真问题 {#ex-closure}
在全球尺度上，地表净太阳辐射为$163\ \mathrm{W\,m^{-2}}$，净红外$66$，潜热$84$，感热$20$：损失合计$170$，比收入多七个单位。某通量塔站点的可用能量为$400\ \mathrm{W\,m^{-2}}$，实测湍流通量之和为$330$。给出全球残差的三种可能解释，以及站点残差的一种错误解释。
::: solution
全球那$7\ \mathrm{W\,m^{-2}}$：(i) 这些图由不同数据集、不同时段拼装而成，而地表辐射（"变暗与变亮"记录）本身有$5$–$10\ \mathrm{W\,m^{-2}}$的不确定度；(ii) 储存在上层海洋和大陆地壳增暖中的能量没有计入地表收支；(iii) 海洋吸收了全球平均$0.9\ \mathrm{W\,m^{-2}}$，虽小但不为零。

站点方面，诱人的错误答案是"塔坏了"。残差几乎总是测量覆盖问题：涡动相关法对夜间和粗糙度子层中携带能量的大而稀少的涡旋采样不足，因此标准订正（Foken分类，或站点的摩擦速度阈值）丢弃三分之一的数据，而空缺由一个偏低的模型填补。能量平衡闭合度$0.85$–$0.95$是正常值，并按此报告。这一教训适用于所有地球观测：当一笔收支的两种独立测量相差百分之十时，有趣的问题不是哪一个错了，而是这个分歧在告诉你什么。
:::
:::

::: example 多余的能量到哪里去了？ {#ex-ohu}
地球能量不平衡为$0.85\ \mathrm{W\,m^{-2}}$，其中$91\%$进入海洋。若把这些热量全部用于加热全球混合层（平均深度$100\ \mathrm{m}$），升高$1\ ^\circ\mathrm{C}$需要多久？为什么观测到的混合层增暖约每十年$0.1\ ^\circ\mathrm{C}$与此并不矛盾？
::: solution
$100\ \mathrm{m}$海水的热容量为$1025\times3990\times100 = 4.1\times10^{8}\ \mathrm{J\,m^{-2}\,K^{-1}}$。按$0.85\times0.91 = 0.77\ \mathrm{W\,m^{-2}}$，
$$
\tau = \frac{4.1\times10^{8}}{0.77} = 5.3\times10^{8}\ \mathrm{s} = 17\ \mathrm{yr\ per\ kelvin}.
$$

因此把全部不平衡只用于混合层，会得到每十年$0.6\ ^\circ\mathrm{C}$。观测到的每十年$0.1\ ^\circ\mathrm{C}$之所以更小，是因为大部分热量并未留在混合层：俯冲、季节温跃层以及风生和中尺度涡环流把它带到$300$、$1{,}000$和$3{,}000\ \mathrm{m}$。近期估计把人为海洋吸热中相当大的一部分——约四分之一（Calton等，2023年）——归于中尺度涡场，而粗分辨率气候模式只能统计地表示它。这就是平衡气候敏感度如此难以从观测增暖中确定的物理原因：同样的强迫会产生不同的地表轨迹，取决于海洋把热量对大气隐藏起来的效率（[[climate-change/observed-change]]）。
:::
:::

::: warning "温室效应是33开尔文"是一个糟糕的分解
地表（$288\ \mathrm{K}$）与发射温度（$255\ \mathrm{K}$）之差$33\ \mathrm{K}$是一个真实的数字，也是一个误导人的数字。它把地球与一个假想的、没有大气*而反照率相同*的行星相比较，而这是不可能的：没有大气的地球会布满陨石坑、干燥，并且会有与$0.29$和$255\ \mathrm{K}$截然不同的反照率和温度。把这$33\ \mathrm{K}$分解成各成分的贡献——水汽约一半、云约五分之一、二氧化碳约五分之一、臭氧甲烷氧化亚氮合计其余（Li等，2013年）——依赖于约定，因为水汽会对二氧化碳作出响应，而云同时干着两份工作。诚实的说法是这两句：移去水汽会使行星冷却得比移去二氧化碳多得多，因为水汽丰富而其丰度由温度决定；而移去*不易凝结的*气体会移去那个设定大气能容纳多少水汽的恒温器，从而把行星推向冰封状态。
:::

::: quiz
地表吸收$163\ \mathrm{W\,m^{-2}}$的阳光，却向大气损失约$170\ \mathrm{W\,m^{-2}}$。这怎么可能？
- [ ] 因为这些数字不闭合，差值是个错误。
- [x] 因为地表还接收来自大气$342\ \mathrm{W\,m^{-2}}$的向下红外辐射，它已被净额到"$66\ \mathrm{W\,m^{-2}}$净红外"那一项里。
- [ ] 因为海洋提供了地热。
- [ ] 因为有些阳光被吸收了两次。
::: solution
地表向上辐射$390$–$400\ \mathrm{W\,m^{-2}}$，向下吸收约$340\ \mathrm{W\,m^{-2}}$，因此其*净*红外损失只有约$66\ \mathrm{W\,m^{-2}}$。巨大的双向红外交换才是温室效应的物理内容：大气把它收到的大部分还回去，从而在不违反能量守恒的前提下减缓地表失热。地热只有$0.09\ \mathrm{W\,m^{-2}}$，比这里需要的量小一千倍。
:::
:::

::: history
傅里叶（Fourier）在1824年提出了问题：一个被太阳照亮并向太空辐射的天体必然比实际更冷，因此大气必定像一个对可见光透明、对地球发射的"暗热"不透明的屏。丁达尔（Tyndall）1859–1861年的热电堆实验指明了哪些气体在挡。普拉斯（Plass）1956年和特勒（Möller）1963年逐带计算红外传输，证明二氧化碳带并不像通常假设的那样饱和。马纳贝（Manabe）和韦瑟拉德（Wetherald）1967年建立了第一个把水汽作为温度依赖反馈的一维辐射-对流模式，得到倍增$2.9\ ^\circ\mathrm{C}$——这个数字在六十年的精化中存活了下来。基尔（Kiehl）和特伦伯斯（Trenberth）1997年发表了标准的地表能量收支（大气层顶$355\ \mathrm{W\,m^{-2}}$），特伦伯斯、法苏洛（Fasulo）和基尔2009年作了更新，而1999年起飞行的CERES仪器此后持续测量大气层顶通量。地表辐射观测网（1996年以来的基准地表辐射网络，以及Wild等2007年发现1960–1990年的"全球变暗"已经逆转）提供了收支的地表那一半。Argo自2004年起每十天有3,900个浮标剖面到$2{,}000\ \mathrm{m}$，把海洋热含量从外推变成了测量；正是Argo使能量不平衡成为观测量而不是推论。
:::

## 由此通向何处

本章的收支是[[climate-system/forcing]]强迫形式体系的输入、[[climate-system/feedbacks-sensitivity]]反馈代数的输入，也是[[climate-system/heat-transport]]输送问题的输入。红外传输本身见[[atmospheric-dynamics/radiative-transfer]]，水汽与云物理见[[atmospheric-dynamics/moist-thermodynamics]]与[[atmospheric-dynamics/cloud-physics]]，地表通量见[[atmospheric-dynamics/boundary-layer]]，观测到的通量变化见[[climate-change/observed-change]]。

::: summary
- 行星吸收$240\ \mathrm{W\,m^{-2}}$阳光并以红外发射等量辐射；观测到的$0.7$–$1.0\ \mathrm{W\,m^{-2}}$不平衡由卫星与Argo独立测得，它就是全球变暖。
- 九成的多余热量进入海洋，$5\%$进入陆地，$3\%$用于融冰，$1\%$用于加热空气。
- 地表吸收的阳光是大气的两倍，但大气主要由地表加热：潜热$84\ \mathrm{W\,m^{-2}}$加感热约$20$加净红外约$66$。
- 每年$1.08\ \mathrm{m}$的蒸发与全球降水相当：能量收支与水收支互相闭合。
- 二氧化碳强迫按对数增长，每倍增$3.7\ \mathrm{W\,m^{-2}}$，无反馈响应约$1.1\ \mathrm{K}$。
- 地表能量收支无论在全球还是通量塔上，闭合度都不优于约$10\%$，而这个残差是有信息量的，不是丢人的。
:::

太阳常数为$1{,}361\ \mathrm{W\,m^{-2}}$。求大气层顶的全球平均入射太阳辐射。
::: solution
$1361/4 = 340\ \mathrm{W\,m^{-2}}$。这个因子是球面积与圆盘面积之比，$4\pi a^2 / \pi a^2$。
:::

::: exercise 反照率 {level=1 check="0.29"}
地球把接收到的$340\ \mathrm{W\,m^{-2}}$中的$100\ \mathrm{W\,m^{-2}}$反射回去。求行星反照率和吸收通量。
::: solution
$\alpha = 100/340 = 0.29$；吸收$= 240\ \mathrm{W\,m^{-2}}$。反照率变化百分之一是$3.4\ \mathrm{W\,m^{-2}}$——与二氧化碳倍增的强迫相当，这就是云反馈成为气候敏感度最大单一不确定度的原因。
:::
:::

::: exercise 发射温度 {level=1 check="255"}
求吸收通量为$240\ \mathrm{W\,m^{-2}}$时的黑体发射温度。
::: solution
$T_e = (240/5.67\times10^{-8})^{1/4} = 255\ \mathrm{K}$。注意这是发射层的温度而不是地表温度；若地表增暖$1\ ^\circ\mathrm{C}$而发射层温度不变，那是不可能的：发射层也必须增暖，这就是普朗克反馈的内容。
:::
:::

::: exercise 感热与潜热 {level=2 check="0.24"}
某湿地站点潜热通量$110\ \mathrm{W\,m^{-2}}$、感热通量$27\ \mathrm{W\,m^{-2}}$。求鲍文比以及用于蒸发的可用能量比例。
::: solution
$\beta = 27/110 = 0.25$；蒸发比率为$110/(110+27) = 0.80$。若该地被排水，$\beta$可升至$2$–$5$，蒸发比率降至$0.2$，白天气温升高若干开尔文——这就是"湿地丧失放大局地热浪"这一说法的物理内容。
:::
:::

::: exercise 强迫与无反馈增暖 {level=2 check="0.68"}
求$450\ \mathrm{ppm}$相对$280\ \mathrm{ppm}$的二氧化碳强迫，以及无反馈的温度响应。
::: solution
$\Delta F = 5.35\ln(450/280) = 2.6\ \mathrm{W\,m^{-2}}$；以$3.8\ \mathrm{W\,m^{-2}\,K^{-1}}$的普朗克响应计，$\Delta T = 0.68\ \mathrm{K}$。评估得到的*净*反馈参数（普朗克加上水汽、直减率、反照率和云）为$1.16\ \mathrm{W\,m^{-2}\,K^{-1}}$（IPCC AR6，2021年），据此同样的强迫在平衡时给出$2.6/1.16 = 2.2\ ^\circ\mathrm{C}$。$0.7$与$2.2$之间的差距就是反馈，这也是两个数字在公共讨论中常被混淆的原因。
:::

::: exercise 海洋吸热 {level=2 check="3.4"}
全球能量不平衡为$0.85\ \mathrm{W\,m^{-2}}$，其中$91\%$进入海洋。求海洋吸热的瓦特数，以及以$10^{19}\ \mathrm{J}$为单位的每日能量。
::: solution
$P = 0.85\times5.10\times10^{14}\times0.91 = 3.9\times10^{14}\ \mathrm{W}$，每日$3.4\times10^{19}\ \mathrm{J}$。以每枚$6\times10^{13}\ \mathrm{J}$的"广岛原子弹"计，每天约$57$万枚；这个比较公平但不说明问题。有用的比较是：这个不平衡约为人类使用能量速率（$1.9\times10^{13}\ \mathrm{W}$）的二十倍——而且与我们用的能量不同，它无法被关掉，因为它已经在大气里了。
:::

::: exercise 大气窗口 {level=3}
地表热辐射约有$20\%$通过$8$–$13\ \mu\mathrm{m}$窗口逃逸。若地表发射$390\ \mathrm{W\,m^{-2}}$，而某种新吸收体使窗口透过率降低$10\%$，求强迫并与二氧化碳倍增的强迫比较。
::: solution
窗口输送$78\ \mathrm{W\,m^{-2}}$；降低$10\%$截留$7.8\ \mathrm{W\,m^{-2}}$，是二氧化碳倍增强迫的两倍。这就是为什么CFC-12和CFC-11的吸收带恰在窗口之中使这些化合物如此强烈——几十亿分之几十就给出约$0.3\ \mathrm{W\,m^{-2}}$的强迫——也是为什么同样的窗口使矿物尘和卷云问题变得微妙。这也是为什么地基的温湿遥感必须在窗口内工作。
:::

::: exercise 黯淡的年轻太阳 {level=3}
四十亿年前太阳亮度只有现在的$70\%$。求今日反照率下的发射温度，以及雪球反照率$0.6$下的发射温度，并说明地质记录要求什么。
::: solution
今日反照率下吸收通量$= 0.7\times240 = 168\ \mathrm{W\,m^{-2}}$，得$T_e = 233\ \mathrm{K}$；$\alpha = 0.6$时吸收$= 0.7\times340\times0.4 = 95\ \mathrm{W\,m^{-2}}$，$T_e = 196\ \mathrm{K}$。两者都远低于冰点，然而地质记录显示液态水、叠层石，并且在约$24$亿年之前没有冰川沉积。

解决办法必须是强得多的温室：二氧化碳为现今的$10$–$100$倍可给出大约$20$–$30\ \mathrm{W\,m^{-2}}$的额外强迫，甲烷则伴随有机霾的难题，还可能有还原性大气中的氨。黯淡年轻太阳是"气候系统可以被温室气体维持在远离辐射平衡之处"的经典存在性证明，这与使当今问题变得严重的是同一套物理——也是使"气候本来就变过"成为对温室机制的*支持*而非反驳的同一套物理。
:::

::: exercise 站点闭合 {level=3}
某通量塔测得净辐射$R_n = 520\ \mathrm{W\,m^{-2}}$、土壤热通量$G = 40\ \mathrm{W\,m^{-2}}$、潜热$110$、感热$60$。求能量平衡闭合度和鲍文比，并指出哪个测量最可能是缺口的原因。
::: solution
可用能量$R_n - G = 480\ \mathrm{W\,m^{-2}}$；实测湍流之和$170\ \mathrm{W\,m^{-2}}$，闭合度$0.35$——远低于常见的$0.85$–$0.95$，因此这组数字不是真实站点，而是坏数据长什么样的示例。在真实观测试验中，缺口主要归因于潜热通量，因为涡动相关法在夜间和稳定层结下系统性地低估输送，而且传感器在随风向变化的脚注上作了路径平均。标准诊断是把闭合度对摩擦速度和稳定度作图，并把订正前后两个值并列报告。
:::
