大气只装着九天的雨。就这一个数字组织了整个水循环：因为大气水库相对于穿过它的通量太小，全球水循环是一个吞吐量系统——一条传送带，不是蓄水池——而它的速度，每年$5\times10^{5}\ \mathrm{km^{3}}$的水被蒸出又落下，意味着你喝下的几乎每一个水分子都在最近几周内越过一片大洋、乘过一次热气流、落过一次雨。水是气候系统的工作介质：它以潜热形式搬运太阳捕获能量的一半，它的云设定辐射收支，它的冰定义反照率，它的液态形式是唯一把大气、岩石和生物圈连进同一笔日常账目的物质。

## 全球收支

::: definition 数字化的全球水循环 {#def-budget}
按海洋盐度、水文站和同位素收支的共识，当前水循环如下运行。无冰全球（$4.95\times10^{8}\ \mathrm{km^{2}}$）平均降水$1020\ \mathrm{mm\,yr^{-1}}$（$505{,}000\ \mathrm{km^{3}\,yr^{-1}}$，$2.8\ \mathrm{mm\,d^{-1}}$）；海洋上降雨$1155\ \mathrm{mm\,yr^{-1}}$对蒸发$1269\ \mathrm{mm\,yr^{-1}}$，$114\ \mathrm{mm\,yr^{-1}}$的缺口由河流补上；陆地上降雨$657\ \mathrm{mm\,yr^{-1}}$，其中$351$经蒸散返回、$306$——三分之一——成为河川径流。水库及其滞留时间讲述着这个循环惯性的故事：海洋持有$1.33\times10^{9}\ \mathrm{km^{3}}$、四千年周转一次；冰盖$2.4\times10^{7}\ \mathrm{km^{3}}$、以千年计；地下水$2.3\times10^{7}\ \mathrm{km^{3}}$、从几百年到几千年；大气$12{,}900\ \mathrm{km^{3}}$、九天；河流$2000\ \mathrm{km^{3}}$、三周；土壤水$16{,}500\ \mathrm{km^{3}}$、两个月。落在陆地上的雨有三分之二来自海洋，三分之一来自陆地自身的蒸散——这个**循环比**使毁林和灌溉成为区域气候问题而非局地问题。
:::

::: example 滞留时间 {#ex-residence}
求河流（蓄量$2000\ \mathrm{km^{3}}$、径流量$41{,}000\ \mathrm{km^{3}\,yr^{-1}}$）和大气中水的滞留时间，并解释为什么大气那个数字使干旱预报成为环流问题而非蓄量问题。
::: solution
$$
\tau_{\mathrm{riv}} = \frac{2000}{41{,}000}\times365 = 18\ \mathrm{天}, \qquad \tau_{\mathrm{atm}} = \frac{12{,}900}{505{,}000}\times365 = 9\ \mathrm{天}.
$$
一条河流流域三周就倒空其蓄水：以河为源的系统中不存在"去年的雨还没到"造成的多年干旱——干旱是**九天传送带的持续失灵**，是不肯送来风暴的环流形态，叠加在土壤和积雪的记忆之上。这就是气象干旱（降水亏缺）、农业干旱（土壤水）和水文干旱（河川流量）之分的物理基础：三个水库滞留时间分别为周、月、月，各自按自己的时钟与彼此脱钩。
:::
:::

## 蒸发：能量上限与水分上限

::: definition 联合方程与布迪科框架 {#def-evaporation}
蒸发是大气对地表能量的最大单项用途——约占吸收阳光的四分之一，全球潜热$88\ \mathrm{W\,m^{-2}}$对感热$24\ \mathrm{W\,m^{-2}}$——而它由两个独立的诉求决定。**能量上限**：水分无限时，蒸发升至净能量供给的速率，$\lambda E \approx \alpha\,(\Delta/(\Delta+\gamma))\,(R_n-G)$，即**彭曼方程**（1948年），把热力学分配$\Delta/(\Delta+\gamma)$与空气动力学的水汽移除结合起来；在水分充足的地表，经验**普里斯特利—泰勒**系数$\alpha = 1.26$概括了干空气水平平流在当地能量收支之上追加的蒸发。**水分上限**：土壤水降到临界值以下，气孔关闭、地表变干，蒸发转为供给受限，鲍文比从$0.3$爬升到$10$。**布迪科框架**把全局组织起来：长期蒸发比$ET/P$是干燥指数$PET/P$的单一函数，从湿润气候中能量受限的$ET \to PET$升到沙漠中水分受限的$ET \to P$，全世界的流域都落在曲线一条窄带内——这是地理学中最干净的经验规律之一，也是为什么即便模型有分歧，对气候变化的水文响应预测仍是有界的。
:::

::: example 从辐射到毫米 {#ex-et}
某湿地净辐射$480\ \mathrm{W\,m^{-2}}$，向地下传导$40\ \mathrm{W\,m^{-2}}$，水分充足；取$\Delta/(\Delta+\gamma) = 0.80$，用$\alpha = 1.26$的普里斯特利—泰勒形式。求蒸发量（$\mathrm{mm\,d^{-1}}$）和一个无云星期的湖面降幅。
::: solution
$$
\lambda E = 1.26\times0.80\times(480-40) = 443\ \mathrm{W\,m^{-2}} \;\Longrightarrow\; E = \frac{443}{2.45\times10^{6}}\times86{,}400\times10^{3} = 15.6\ \mathrm{mm\,d^{-1}} .
$$
这样一周湖面下降$11\ \mathrm{cm}$——这就是干旱区水库和终端湖泊的静默危机：富营养化、深色、温暖的水面每天蒸发一厘米，是蒸发皿系数经验法则的几倍；萨赫勒或亚利桑那一座水库的设计蒸发量大于其渗漏量，常常也大于其管理损失。同样的算术倒过来解释了为什么灌溉过的沙漠会变凉：裸沙漠花在加热空气上的$443\ \mathrm{W\,m^{-2}}$，稻田花在了海洋的水汽里。
:::
:::

labels: ET/P
caption: 布迪科曲线——长期蒸发分率$ET/P$对干燥指数$PET/P$（形式$\Phi = 1 + x - (1+x^{\omega})^{1/\omega}$，$\omega = 3.7$）。湿润气候（$x < 1$）蒸发跟随能量供给，$ET \to PET$；干旱气候（$x > 1$）跟随水分供给，$ET \to P$；曲线在支点$x = 1$处过$ET/P \approx 0.8$。真实流域在这条线周围散布几个百分点——地表-大气系统的涌现规律；即使降水预估不收敛，流域产水量随气候如何变化的预测仍被它约束得很紧。

## 循环、天河与同位素显微镜

::: definition 降水循环与同位素示踪 {#def-recycling}
落在陆地上的$88{,}000\ \mathrm{km^{3}}$雨中约$29{,}000\ \mathrm{km^{3}}$——三分之一——是陆地自己蒸发的：**循环比**全球平均$0.3$，在亚马逊和刚果可达$0.5$–$0.6$——那里的森林抽送自身降雨的一半，旱季从森林返回安第斯的水汽河供应着让森林活下去的雨。这个循环之所以可读，是因为大自然给它的水贴了标签：**稳定同位素**$^{18}\mathrm{O}$和D在每一次相变处分馏——蒸发偏爱轻分子，凝结优先移除重分子——于是雨在源的下游被逐步贫化：海拔每升高$100\ \mathrm{m}$，$\delta^{18}\mathrm{O}$约降低$0.5\permil$（**海拔效应**）；凝结温度每降一度降低若干千分比（**温度效应**，为[[palaeoclimate/ice-cores]]的冰芯温度计作标定）；而沿**全球大气水线**$\delta D = 8\,\delta^{18}\mathrm{O} + 10$，其截距**氘过剩**给源区海洋的湿度和海表温度盖章。同位素把整个循环变成一次示踪实验：水汽从哪来、落下之前淋洗了多少、在什么温度凝结——这些工具让水文学家在洪水里分辨融雪与降雨，让古气候学家从石笋里读出季风。
:::

::: example 读一段水汽史 {#ex-isotope}
水汽抵达某谷地站时$\delta^{18}\mathrm{O} = -4\permil$。它被抬升$2000\ \mathrm{m}$爬过迎风坡，淋洗到原有水汽量的$40\%$。设有效分馏$\varepsilon^{*} = 10\permil$的瑞利蒸馏，估算山顶残留水汽的$\delta^{18}\mathrm{O}$，并说明残余氘过剩能告诉你什么。
::: solution
瑞利蒸馏给出$\delta = \delta_0 + \varepsilon^{*}\ln f$，残留分数$f = 0.4$：
$$
\delta = -4 + 10\times(-0.92) = -13.2\permil .
$$
沿途收集的雨在每一时刻都比残留水汽更重，所以谷地的暴雨平均雨接近$-8$至$-9\permil$、山顶接近$-14$：同位素组成随海拔变陡的观测就是逐步淋洗的指纹，这笔算术解释了为什么最高的站记录到最极端的值。水汽的**氘过剩**——偏离斜率8线的量——在蒸发时设定、此后几乎守恒，所以氘过剩接近$10\permil$的山顶雨来自正常的海洋源，而过剩$18\permil$的是从寒冷干燥的大陆源循环来的：同位素显微镜读的是水汽的传记，不只是它的温度。
:::
:::

## 循环中的人类

::: definition 取用、绿蓝水与被工程化的循环 {#def-humans}
人类截走了陆地可用水的很大比例：**绿水**——从土壤蒸散的$351\ \mathrm{mm\,yr^{-1}}$降水，养活着全部雨养农业和地球上一半的食物——和**蓝水**——河流与浅层地下水的径流，其年取用量约$2800\ \mathrm{km^{3}\,yr^{-1}}$（三分之二用于灌溉），可流量为$9000$–$14{,}000\ \mathrm{km^{3}\,yr^{-1}}$，其中**耗水**（蒸发后不返回）约$2000\ \mathrm{km^{3}}$：可径流的三分之一到一半已被认领，而在印度河、华北、科罗拉多和阿拉伯的流域，这个比例超过一。被工程化的循环有三个可见的签名：开采化石水的地方地下水位每年下降数米（高平原、华北平原、中央谷地——储存了千年的水一代人花光）；河水入海之前就被用尽（科罗拉多、黄河、墨累的低水年）；终端湖泊萎缩（咸海、乌尔米耶、死海）——而同一个循环的极端值按克劳修斯—克拉珀龙每开尔文$7\%$的可降水量速率被增暖放大，这就是为什么即便在许多年总量下降的地方，最猛的日雨量仍在全球破纪录。气候变化的水循环不是简单的"湿者更湿"：降水本身每开尔文只升$2$–$3\%$——[[climate-change/responses]]的能量约束——所以泵的**效率**在下降而其爆发在增强；诚实的概括是：循环更动荡、更极端，在副热带更干。
:::

::: example 开采地下水 {#ex-fossil}
某灌溉平原下的含水层持有$2000\ \mathrm{km^{3}}$可采化石水，水位埋深在可开采范围内；灌溉耗水$10\ \mathrm{km^{3}\,yr^{-1}}$，自然补给$1.5\ \mathrm{km^{3}\,yr^{-1}}$。求开采年限、$2000\ \mathrm{km^{2}}$平原在给水度$0.15$下的水位下降速率，并解释为什么含水层的"水峰"比石油峰值更难办。
::: solution
净开采率$8.5\ \mathrm{km^{3}\,yr^{-1}}$，按恒定速率资源可撑$2000/8.5 \approx 235$年——实际更短，因为水位下降抬高抽水成本、深层含水层排得慢。水位年降幅为
$$
\frac{8.5\ \mathrm{km^{3}\,yr^{-1}}}{2000\ \mathrm{km^{2}}\times0.15} = 0.028\ \mathrm{km\,yr^{-1}} \approx 2.8\ \mathrm{m\,yr^{-1}} .
$$
一年两到三米正是华北平原和高平原的观测速率：井越打越深，能耗攀升，地面沉降数米，沿海含水层咸水入侵。含水层枯竭比石油更难办，因为它不可见；因为补贴的是农业、政治上碰不得；因为调整手段——停止灌溉——没有替代品：干旱流域里种出的粮食没有可再生的"生物燃料"可用。这就是为什么化石含水层开采地图长期看就是世界最脆弱粮仓的地图。
:::
:::

::: warning 水循环不是饮用水循环，"缺水"通常是治理陈述，每开尔文7%不是降雨增7%
五个错误。**循环的数字是通量不是资源**：世界每年周转$500{,}000\ \mathrm{km^{3}}$水、取用其千分之一，但"缺水"是真实的，因为通量落在没人要的地方、错着季节来、或以洪水的形式来——缺水是时间、地点和质量的错配，水库和制度是错配的修补包。**蒸散大于径流**：陆地降水的三分之二返回空中；只用河川流量评判流域健康会漏掉粮食系统——粮食靠的是蒸散那三分之二（绿水）。**克劳修斯—克拉珀龙说的是大气容量不是降雨**：可降水量每开尔文升$7\%$，降水只升$2$–$3\%$，因为能量收支限制平均上升气流——两个事实合起来意味着动力学不变时风暴更强；"湿者更湿"的口号只在深热带成立，在季节性干旱的副热带根本不成立。**地下水不是向未来的借款而是一次性资产加维护成本**：上面的水位算术表明成本随使用上升；对化石含水层，诚实的词是"不可再生"。**循环的水汽在政策尺度上重要**：大陆降水的三分之一由陆地自己蒸发，所以大规模毁林或灌溉会改变下风几百到几千公里外的降雨——亚马逊—安第斯输水管道是经典且正受威胁的例子。
:::

::: history
定量循环始于**道尔顿（John Dalton）**1803年的蒸发定律和随后出现的蒸发皿；**彭曼（Howard L. Penman）**1948年的联合方程统一了能量观与空气动力学观；**普里斯特利（W. R. (Bill) Priestley）与泰勒（R. J. (John) Taylor）**1972年的系数提炼出湿面极限。**布迪科（M. I. Budyko）**1956–1974年的框架把流域的长期水量-能量平衡变成可预言的规律；1950–70年代苏联中亚与澳大利亚的流域实验提供了至今仍锚定参数化的蒸发测量。同位素示踪时代由**克雷格（Harmon Craig）**1961年发现全球大气水线、**丹斯加德（Césaire (Cec) Dansgaard）**1964年发现冰的温度效应开启——这两篇论文让水自己的同位素成为它的温度计和源示踪剂；全球收支的现代综合是2000年代以来**GSWP**、**ERA-Interim/Land**与**GRACE**重力测量计划的卫星-站点融合——人类首次从轨道上测量冰、地下水、土壤水和地表水的总蓄量。
:::

循环的凝结一侧在[[atmospheric-dynamics/cloud-physics]]；送雨中纬度的风暴在[[meteorology/fronts-cyclones]]和[[meteorology/storms]]；地表蒸发物理在[[atmospheric-dynamics/boundary-layer]]；土壤与汇流在[[hydrology/soil-water]]和[[hydrology/runoff]]；积雪水库在[[hydrology/snow]]；地下水力学在[[hydrology/groundwater-flow]]和[[hydrology/aquifers-wells]]；未来循环的能量约束在[[climate-change/responses]]和[[climate-change/projections]]；洪旱极端在[[natural-hazards/floods]]；同位素古温度计在[[palaeoclimate/ice-cores]]和[[palaeoclimate/proxies]]；循环在海洋盐度上的记录在[[oceanography/seawater]]。

::: summary
- 全球循环是吞吐量系统：降水$505{,}000\ \mathrm{km^{3}\,yr^{-1}}$对九天的大气水库——干旱是环流失灵，不是蓄量失灵。
- 陆地蒸散把陆地降水的三分之二送回空中；布迪科曲线把每个流域的长期$ET/P$约束为干燥度的函数。
- 蒸发有能量上限（彭曼、普里斯特利—泰勒）和水分上限（气孔、土壤）；干燥指数说哪条上限起作用。
- 大陆降水的三分之一由陆地循环；同位素（$\delta^{18}\mathrm{O}$、D、氘过剩）示踪水汽源、淋洗史和凝结温度——水文学与古气候学的显微镜合而为一。
- 人类已消耗可径流的三分之一到一半；化石地下水以每年数米的速度被开采，终端湖泊是透支的明账。
- 增暖按每开尔文$7\%$（容量）加速循环的极端，而平均降水只有$2$–$3\%$（能量）：更动荡、更极端、副热带更干。
:::

## 习题

::: exercise 河流滞留时间 {level=1 check="18"}
求河流水的滞留时间（天）（蓄量$2000\ \mathrm{km^{3}}$、径流量$41{,}000\ \mathrm{km^{3}\,yr^{-1}}$）。（填数字。）
::: solution
$\tau = 2000/41{,}000\times365 = 18\ \mathrm{天}$。三周：河里的水是循环中各水库里最年轻的，这就是为什么水文干旱滞后气象干旱的是土壤的两个月、而不是河流的几周。
:::

::: exercise 海洋亏缺 {level=1 check="114"}
海洋蒸发$1269$、接受$1155\ \mathrm{mm\,yr^{-1}}$。求海洋平均所需的河流输入（$\mathrm{mm\,yr^{-1}}$），并用$41{,}000\ \mathrm{km^{3}\,yr^{-1}}$除以$3.61\times10^{8}\ \mathrm{km^{2}}$验证。（填毫米数。）
::: solution
$1269 - 1155 = 114\ \mathrm{mm\,yr^{-1}}$，而$41{,}000/3.61\times10^{8}\times10^{6} = 114\ \mathrm{mm\,yr^{-1}}$——收支闭合。基于盐度的蒸发估计与全球水文站总和之间的这个闭合，是二十世纪自然地理学的成就之一。
:::

::: exercise 能量受限的蒸发 {level=1 check="14"}
净可用能量$400\ \mathrm{W\,m^{-2}}$的自由水面，求蒸发量（$\mathrm{mm\,d^{-1}}$）。（取整数。）
::: solution
$E = 400\times86{,}400/2.45\times10^{6} = 14\ \mathrm{mm\,d^{-1}}$。一天十四毫米——半英寸——这就是沙漠里的露天水库首先是蒸发损失池、其次才是蓄水池的原因，也是美国西南部的湖泊向天空流失的水比向任何水龙头流失的都多的原因。

::: exercise 普里斯特利—泰勒 {level=2 check="4.0"}
某草原$\Delta/(\Delta+\gamma) = 0.75$、可用能量$R_n - G = 120\ \mathrm{W\,m^{-2}}$、水分充足。用$\alpha = 1.26$求$ET$（$\mathrm{mm\,d^{-1}}$）。（保留一位小数。）
::: solution
$\lambda E = 1.26\times0.75\times120 = 113\ \mathrm{W\,m^{-2}}$，$ET = 113\times86{,}400/2.45\times10^{6} = 4.0\ \mathrm{mm\,d^{-1}}$。健康的温带草原夏天每天蒸腾$3$–$4\ \mathrm{mm}$：雨后放晴一星期，一米土壤就从"田间持水量"滑到"凋萎系数"的原因。
:::

::: exercise 循环比 {level=2 check="29"}
某大陆蒸发$47{,}000\ \mathrm{km^{3}\,yr^{-1}}$、接受$88{,}000\ \mathrm{km^{3}\,yr^{-1}}$的雨；$33\%$的雨源于大陆蒸发。求循环雨量（以$10^{3}\ \mathrm{km^{3}\,yr^{-1}}$计），以及本大陆蒸发落回本大陆的比例。（填雨量。）
::: solution
循环雨$= 0.33\times88 = 29$千$\mathrm{km^{3}\,yr^{-1}}$，占陆地蒸发的$29/47 = 62\%$——陆地留下自己蒸发的近三分之二，其余作为水汽输出、给下风大陆播种。亚马逊约$0.5$的循环比意味着它一半的雨是森林造的：森林是造雨机器而非雨的受害者，这是它的经典证明。
:::

::: exercise 海拔效应 {level=2 check="-12.5"}
海平面雨的$\delta^{18}\mathrm{O} = -2\permil$。用每$100\ \mathrm{m}$ $-0.5\permil$的海拔效应，求$2100\ \mathrm{m}$处降水的预期$\delta^{18}\mathrm{O}$。（保留一位小数。）
::: solution
$\delta = -2 - 0.5\times21 = -12.5\permil$。围绕这条简单线的观测散布很有信息量：比同海拔预测更湿的站落在线以下（淋洗更多），偏离量绘制的是该地的地形淋洗史——同位素版的水汽轨迹。
:::

::: exercise 瑞利蒸馏 {level=3 check="-16.5"}
$\delta^{18}\mathrm{O} = -5\permil$的水汽淋洗至残留分数$f = 0.35$，有效分馏$\varepsilon^{*} = 11\permil$。用瑞利关系$\delta = \delta_0 + \varepsilon^{*}\ln f$求残留水汽的$\delta^{18}\mathrm{O}$（千分比）。（保留一位小数。）
::: solution
$\delta = -5 + 11\times\ln 0.35 = -5 + 11\times(-1.05) = -16.5\permil$。符号纪律就是全部物理：淋洗优先移除重同位素，所以残留水汽——以及由它晚形成的任何雨——随$\ln f$越来越轻；瞬时雨比其水汽重$\varepsilon^{*}$，累积雨居中。每一条同位素水文过程线和每一段冰芯解释都建立在这三个量上。
:::

::: exercise 能量受限的泵 {level=3 check="0.96"}
可降水量每开尔文升$7\%$，全球降水每开尔文只升$2.5\%$。求比值$P/(\rho q)$——单位大气水的降水量——每开尔文的变化因子，保留两位小数。
::: solution
比值变化$1.025/1.07 = 0.96$。"泵效率"——单位大气水的降水——每开尔文**下降**百分之四，因为平均上升气流受能量限制而水汽是热力学供给的。这就是"极端更强、平均循环更弱"悖论的定量核心：同一个增暖既压满子弹（容量$+7\%$）又放慢毛毛雨（吞吐量$+2\%$）；水文未来是一个分布问题——同样的水，更多的部分落进尾部。
:::
