没有一支温度计测量过气候。每件仪器测量的是某地某时的天气，而气候是把这些测量的统计量在噪声被平均掉、缺口被诚实填补之后所呈现的样子。这就是本章成为统计学章节的原因：不是因为气候是伪装的社会科学，而是因为我们关心的信号——每天几开尔文散布之上的十年十分之一度——比噪声小三个量级，只有充分了解噪声才能把它提取出来。

标准简语是"气候是你所期望的，天气是你所得到的"。这不算错，但它的完整程度不够，而这种不完整已经在影响评估中造成了真实的损失。气候不是平均。气候是一个分布：均值的分布、方差的分布、协方差的分布、季节循环的分布、自相关的分布，以及尾部的分布——而死亡和保险理赔恰恰住在尾部。两个地方可以有相同的年平均温度，而其中一个会有冻死玉米的霜冻，另一个不会。

## 气候记录实际上是什么

::: definition 气候标准值与气候 {#def-normal}
世界气象组织把**气候标准值**定义为某变量三十年的平均，目前采用1991–2020年。形式上，某变量$X$在某地的**气候**是$X$的概率律——它的矩、季节调制、依赖结构和尾部——以在平均窗口内视为固定的缓变边界条件（温室气体浓度、日射、冰盖几何）为条件。
:::

定义的后半句才是要害。气候不是平稳的：1991–2020年标准值与1961–1990年标准值在全球相差约$0.2\ ^\circ\mathrm{C}$，而这个差不是抽样噪声。因此每一个气候统计量的估计都是对一个*移动中*的分布的估计，本门手艺的全部功夫就在于把漂移与游荡分开。

::: definition 距平、均一化处理与覆盖率 {#def-anomaly}
气候数据几乎从不使用绝对值，而使用**距平**——相对于本地参考期的偏离。距平平均之所以可行，是因为距平的空间相关程远远大于变量本身的空间相关程：一次寒潮可以在一个大洲上造成$-12\ \mathrm{K}$的距平，而同两个站之间的绝对温度相差$40\ \mathrm{K}$。**均一化处理**是利用邻近站记录统计地剔除非气候的阶跃变化（迁站、换仪器、新百叶箱、城市化环境）；**覆盖率**是网络所代表的表面积比例，二十世纪初陆上不足$30\%$，海洋更低得多。
:::

有几个实际数字值得记住。政府间气候变化专门委员会使用的全球地表温度记录（HadCRUT5、Berkeley Earth、GISTEMP、哥白尼/ERA5）由约$7{,}000$个有长记录的陆地站和$10^{8}$个海洋观测构成，后者多为船舶机舱进水温度，2010年代以来以漂流浮标为主。海表温度记录在2010年代针对从取水桶到机舱进水与漂流浮标的改变重新做了偏差校正，这一系统差约$0.3\ ^\circ\mathrm{C}$，其校正把二十世纪初的基线移动了百分之几度，并改变了早期世纪增暖速率的估计值（HadCRUT5，2020年）。

::: example 记录里到底有多少是真的？ {#ex-coverage}
陆地占表面积的$29\%$。设陆地站网以每站$250\ \mathrm{km}$影响半径代表其测量，1900年有$7{,}000$个站在报告，2000年有$30{,}000$个。估算各年陆地覆盖比例，并解释为什么1900年的全球平均比中非或北极的陆地平均更有把握。
::: solution
每站覆盖$\pi(2.5\times10^{5})^2 = 2.0\times10^{11}\ \mathrm{m^2}$，故$7{,}000$站覆盖$1.4\times10^{15}\ \mathrm{m^2}$——几乎是陆地面积$1.49\times10^{14}\ \mathrm{m^2}$的十倍。圆盘大量重叠，因此名义上的*面积*覆盖是完整的，而*代表性*不是：站点集中在北美、欧洲和东亚。1900年，撒哈拉以北的非洲、亚马逊、西伯利亚、南极和大部分海洋几乎没有站。

悖论的化解在于全球平均是一个加权平均，其中采样良好的区域通过场的协方差结构约束采样不足的区域——这就是GISTEMP和Berkeley Earth使用的**克里金**技术。若某区域没有站但其邻居有，且空间相关长度（年地表温度约$2{,}000\ \mathrm{km}$）得到尊重，该区域并非未被测量。但它的确被测得差得多，而二十世纪初不确定度带更宽正是这个原因，不是因为那时的温度计更差。
:::
:::

## 有噪声、有相关序列的统计

::: definition 红噪声与有效自由度 {#def-rednoise}
许多气候变量在一阶近似下表现为一阶自回归过程$\mathrm{AR}(1)$，
$$
x_{t+1} = \rho x_t + \sigma\epsilon_t ,
$$
滞后一阶相关$\rho > 0$：**红**谱，低频功率高于白噪声。具有滞后一阶相关$\rho$的$n$个值序列只携带
$$
n_\text{eff} \approx n\,\frac{1-\rho}{1+\rho}
$$
个独立自由度，因此其均值的标准误比$\sigma/\sqrt{n}$大$\sqrt{(1+\rho)/(1-\rho)}$倍。
:::

::: proof
平稳序列样本均值的方差为$\mathrm{Var}(\bar x) = \frac{\sigma^2}{n}\sum_{k=-n}^{n}(1-|k|/n)\rho^{|k|}\times$双侧；$n$大时该和趋于$(1+\rho)/(1-\rho)$，即得结果。$\rho > 0$的物理起源是记忆：海洋混合层、土壤水分和海冰都在积分，所以本月的距平是下月距平的部分预报量。忽略这一点是气候统计中最常见的错误，也是为什么从短的相关序列上得出的"显著趋势"往往并不显著。
:::

::: example 1998–2012年的"停滞"显著吗？ {#ex-hiatus}
年全球平均地表温度相对于平滑趋势的标准差约$0.09\ \mathrm{K}$，滞后一阶相关约$0.15$。十五年数据给出的趋势估计为$0.005\ \mathrm{K\,yr^{-1}}$，而长期趋势接近$0.019\ \mathrm{K\,yr^{-1}}$。估算15年趋势的标准误，并判断两者之差是否显著。
::: solution
对$n$个值拟合线性趋势，残差标准差$\sigma_e$、滞后一阶相关$\rho$时，标准误近似为
$$
\mathrm{SE}(b) \approx \frac{\sigma_e}{\sqrt{\sum(t-\bar t)^2}}\sqrt{\frac{1+\rho}{1-\rho}} = \frac{\sigma_e}{\sigma_t\sqrt{n}}\times1.36,
$$
$n = 15$时$\sigma_t = (n-1)/\sqrt{12} = 4.04\ \mathrm{yr}$。故$\mathrm{SE}(b) = 0.09\times1.36/(4.04\times\sqrt{15}) = 0.008\ \mathrm{K\,yr^{-1}}$。观测趋势与长期趋势之差为$0.014\ \mathrm{K\,yr^{-1}}$，即$1.8$个标准误：在$5\%$水平上不显著。

这就是关于"停滞"的全部统计学回答。1998–2012年的斜率从来不是反常的；它是一个宽标准误分布中$1.8\sigma$的低抽样，并且被一次噪声放大的自然实验推波助澜：窗口起点是极强的1998年厄尔尼诺，窗口末端附近是2010–2011年的强拉尼娜。物理解答——额外热量被风和太平洋年代际模态送入大西洋和南大洋深层——见[[climate-system/variability]]。
:::
:::

## 极端事件：损失所在

::: definition 广义极值分布与重现期 {#def-gev}
在弱条件下，区块极大值（年最高温度、年最大日降水）的分布收敛于**广义极值**族，
$$
G(x) = \exp\left\{-\left[1 + \xi\frac{x-\mu}{\sigma}\right]^{-1/\xi}\right\},
$$
含位置$\mu$、尺度$\sigma$与形状$\xi$。$\xi = 0$的成员是Gumbel分布，适用于温度类变量；$\xi > 0$（重尾）见于某些降水和风极端事件。重现期为$p$年的**重现期量值**$x_p$满足$G(x_p) = 1 - 1/p$。
:::

::: proposition 变暖的世界不只是平移均值 {#prop-tails}
若日温度距平为标准差$\sigma$的高斯分布且均值增暖$\Delta\mu$，则超过固定阈值$T$的概率变为原来的
$$
\frac{P(X > T - \Delta\mu)}{P(X > T)} = \exp\left(\frac{2\Delta\mu(T-\mu) - \Delta\mu^2}{2\sigma^2}\right)
$$
倍，且当$T$移向尾部时无界增长。$1\sigma$的平移使$2\sigma$事件频率乘以$7$、$3\sigma$事件乘以$17$、$4\sigma$事件乘以$43$。
:::

::: proof
对高斯分布，尾部有$\ln P(X > T) \approx -(T-\mu)^2/2\sigma^2$（相差缓变因子）。代入$\mu \to \mu + \Delta\mu$并相减即得上式。这个结果正是"气候只是均值"这一观点失败的原因：均值平移是一个参数的小变化，却是远尾的巨大变化。Hansen等（2012年）正是用这一点说明，全球出现$+3\sigma$夏季温度距平的面积从1950年代的约$0.2\%$增长到2010年代的约$10\%$——五十倍的增长来自约$0.8\ \mathrm{K}$的均值平移，比高斯预言更大，因为陆地比全球平均暖得快，也因为土壤水分反馈在平移分布的同时把它展宽了。
:::

::: example 百年一遇，两次 {#ex-return}
某站年最高温度用$\mu = 34.0\ ^\circ\mathrm{C}$、$\sigma = 1.4\ ^\circ\mathrm{C}$的Gumbel分布拟合。求50年和100年重现期量值。若均值增暖$1.6\ ^\circ\mathrm{C}$而$\sigma$不变，超过旧的百年一遇量值的频率增大多少倍？
::: solution
Gumbel分位数为$x_p = \mu - \sigma\ln[-\ln(1 - 1/p)]$。$p = 50$时$-\ln(1-0.02) = 0.0202$、$\ln 0.0202 = -3.90$，故$x_{50} = 34.0 + 1.4\times3.90 = 39.5\ ^\circ\mathrm{C}$。$p = 100$时$x_{100} = 34.0 + 1.4\times4.60 = 40.4\ ^\circ\mathrm{C}$。

增暖后，超过$40.4\ ^\circ\mathrm{C}$等同于增暖前超过$40.4 - 1.6 = 38.8\ ^\circ\mathrm{C}$，而后者的重现期为$1 - \exp\{-\exp[-(38.8-34)/1.4]\} = 1/31$：百年一遇事件变成三十一年一遇，频率增大$3.2$倍。

一般经验法则是，对$\sigma \approx 1.4\ ^\circ\mathrm{C}$的Gumbel型极大值，$1\ ^\circ\mathrm{C}$的增暖使历史上百年一遇极值的频率约增三倍。这个数字出现在高温预警统计和设计规范论证中，也是为什么观测到的"破纪录"事件记录并不证明分布平移之外的任何东西：平稳气候中破纪录者与立纪录者之比应约为一，而近二十年全球约为二比一。
:::
:::

::: widget plot

x: 2, 200

caption: $\mu = 34.0\ ^\circ\mathrm{C}$、$\sigma = 1.4\ ^\circ\mathrm{C}$的年最高温度Gumbel重现期曲线：平均每$p$年被超过一次的温度。注意其形状——曲线上凸，只在大$p$处陡升，因此百年一遇量值只比五十年一遇高$0.9\ ^\circ\mathrm{C}$，适度的增暖就把罕见事件变成常见事件。把$\mu$拟合为年份（或全球平均温度）的线性函数是标准的**非平稳极值**方法，也是归因文献对"气候变化是否让这次热浪更可能"给出定量回答的方式（[[climate-change/attribution]]）。

## 测量世界的均值

::: definition 不确定度与校准语言 {#def-uncertainty}
评估报告使用校准的可能性等级：*几乎确定*$>99\%$、*极有可能*$95$–$100\%$、*可能*$66$–$100\%$、*大致可能*$33$–$66\%$、*不可能*$0$–$33\%$。不确定度分解为**测量**误差（仪器、选址、采样）、**覆盖**误差（未采样区域与深度）、**方法**误差（均一化、偏差校正、插值）与**模式**误差（结构与参数）。
:::

一个半世纪测量的头条结果是：2011–2020十年的全球平均地表温度比1850–1900年高$1.09\ ^\circ\mathrm{C}$（IPCC AR6，*极有可能*，范围$0.95$–$1.20$），最近十年超过至少十二万五千年中最暖的十年，且陆地增暖（$1.59\ ^\circ\mathrm{C}$）大于海洋（$0.88\ ^\circ\mathrm{C}$），北极更大。三条独立证据——站与船上的温度计、同化它们的再分析、卫星微波探测——在每十年百分之几度以内一致，这是无法把实验做两遍的科学中所能得到的最强验证。

::: example 昼夜不对称及其诊断意义 {#ex-diurnal}
自1950年以来，全球夜间最低气温的上升快于日最高气温，陆上约多$0.25\ \mathrm{K}$。给出产生这种不对称的三个机制，以及一个会产生相反符号的机制。
::: solution
(i) 云量与水汽增多在夜间截留向外的长波辐射，而此时没有入射太阳辐射可以抵消。(ii) 土壤水分减少使地表能量平衡从潜热转向感热，其效应在干燥的午后到夜间转换时最大。(iii) 气溶胶减少与城市化不成比例地抬高最低气温，因为城市白天储热、日落后释放。相反的签名——最高温比最低温升得快——由强烈毁林或灌溉变化、或由尘埃与火山气溶胶产生，它们冷却白天的最高值。

这种不对称是诊断性的，不是偶然的：它约束了哪种强迫在起作用。纯温室气体强迫预言观测到的格局，气溶胶主导的强迫预言相反的格局。这是**指纹识别**一般逻辑的一个小例子——不同的原因不是靠增暖的多少、而是靠其空间、季节、昼夜和垂直格局来区分（[[climate-change/attribution]]）。
:::
:::

::: warning 本章统计被滥用的三种方式
第一，**挑选窗口**：15年全球趋势的标准误约$0.008\ \mathrm{K\,yr^{-1}}$，因此任何十年或二十年的趋势都能被做得看起来反常，而短于约25年的趋势断言不携带信息。第二，**把分布与均值混为一谈**："2023年是最暖的一年"和"平均已升高$1.1\ ^\circ\mathrm{C}$"是关于不同对象的陈述，前者对ENSO位相远为敏感。第三，**把重现期当作承诺**：百年一遇事件在一个世纪内至少出现一次的概率是$63\%$，完全不出现的概率是$37\%$；而在非平稳分布下这个数字每十年都在变——为一座百年一遇量值已上升$1.5\ ^\circ\mathrm{C}$的城市引用固定重现期，会悄无声息地低估危险。
:::

::: history
仪器记录始于十八世纪的系统观测，以及洪堡（Humboldt）在1820年代完成的第一次全球综合——他绘制了等温线并注意到南北半球纬度温度梯度的差别。亨利（Henry）与罗恩（Rowan）在1850年代用志愿观测者建立了第一个大陆尺度的网络；电报的发明第一次把天气变成同步的、空间延展的对象，而1873年成立的世界气象组织前身国际气象组织是第一个国际科学机构。记录本身可能被污染这一观念几乎同样古老：英国科学促进会1878年就警告过城市增暖。现代统计处理始于杰弗里斯（Jeffreys），随后是米切尔（Mitchell）1976年关于检测温室效应的论文，它引入了"信噪比"框架，以及1990年代的"检测与归因"革命。均一化处理在1990年代随美国历史气候网络成熟；当前这一代数据集（HadCRUT5，2020年；Berkeley Earth，2019年起；ERA5，2020年）以显式不确定度集合而非单一最优估计为特征。世界气象组织的三十年标准值确立于1931年并此后每十年更新，这一安静的行政约定使"气候"一词有了可测量的含义。
:::

## 由此通向何处

本章发展的统计是后续每一章的工具：[[climate-change/observed-change]]的趋势估计、[[climate-change/attribution]]的显著性检验、[[climate-change/extremes]]的重现期预估、[[climate-system/variability]]的噪声分解、[[climate-modelling/evaluation]]的模式评估以及[[palaeoclimate/dating]]的古气候类比推理。下一章回到物理，讲最初设定均值的那个能量收支。

::: summary
- 气候是一个概率律而非均值：均值、方差、依赖与尾部，以缓变边界条件为条件。
- 记录由距平构建、依邻居做均一化、用克里金插值；早期世纪的不确定度主要由覆盖率而非温度计质量决定。
- 气候序列是红色的：滞后一阶相关$\rho$下，$n$个值只携带$n(1-\rho)/(1+\rho)$个自由度，这就是趋势标准误很大、短窗口无信息的原因。
- 极大值服从Gumbel或广义极值律；$1\sigma$的均值平移使$3\sigma$事件频率增约十七倍。
- 2011–2020年全球增暖为$1.09\ ^\circ\mathrm{C}$（相对1850–1900），陆地大于海洋，北极最大，并由三个独立观测族证实。
- 夜间最低温升得比日最高温快，这是温室气体而非气溶胶的指纹。
:::

一百年年际温度序列的滞后一阶相关为$0.7$。求有效独立观测数。
::: solution
$n_\text{eff} = 100\times(1-0.7)/(1+0.7) = 17.6$，约$18$个。因此百年均值的标准误是朴素$\sigma/10$的$\sqrt{100/17.6} = 2.4$倍。
:::
:::

::: exercise 距平 {level=1 check="0.2"}
某站1961–1990年标准值为$8.4\ ^\circ\mathrm{C}$，1991–2020年为$8.6\ ^\circ\mathrm{C}$。后期相对前期的距平是多少？为什么这个数比任一个标准值更可信？
::: solution
$0.2\ ^\circ\mathrm{C}$。两个标准值都携带该站的选址与仪器偏差，而这些偏差在差值中大部分抵消；距平是同一地点的变化，不是地点之间的比较，因此对代表性误差远不敏感。
:::
:::

::: exercise 趋势标准误 {level=1 check="0.0022"}
三十年温度序列相对趋势的残差标准差为$0.10\ \mathrm{K}$，无自相关。求趋势的标准误（$\sigma_t = (n-1)/\sqrt{12}$）。
::: solution
$\sigma_t = 29/3.464 = 8.37\ \mathrm{yr}$，故$\mathrm{SE}(b) = 0.10/(8.37\times\sqrt{30}) = 0.0022\ \mathrm{K\,yr^{-1}}$。若$\rho = 0.15$，因子$\sqrt{1.15/0.85} = 1.16$给出$0.0025\ \mathrm{K\,yr^{-1}}$。$0.019\ \mathrm{K\,yr^{-1}}$的趋势因此是$8\sigma$——这就是长期增暖趋势不容怀疑的原因。
:::
:::

::: exercise 高斯尾部 {level=2 check="16.9"}
$1\sigma$的增暖使$3\sigma$事件的频率增加多少倍？分别用精确值与渐近公式。
::: solution
精确值$Q(2)/Q(3) = 0.0228/0.00135 = 16.9$。渐近指数给出$\exp[(2\times1\times3 - 1)/2] = e^{2.5} = 12.2$，低约$30\%$，因为尾部近似丢掉了$1/x$前因子。$4\sigma$的精确比为$43$。要点是阈值上的指数敏感：同样的增暖在均值中只是舍入误差，在尾部却是量级变化。
:::
:::

::: exercise 重现期量值 {level=2 check="42.7"}
Gumbel$\mu = 34.0\ ^\circ\mathrm{C}$、$\sigma = 1.4\ ^\circ\mathrm{C}$，求年最高温度的500年重现期量值。
::: solution
$-\ln(1 - 1/500) = 0.002002$；$\ln(0.002002) = -6.215$；$x_{500} = 34.0 + 1.4\times6.215 = 42.7\ ^\circ\mathrm{C}$。对数增长意味着外推到远超记录长度之处基本上不受数据约束。
:::
:::

::: exercise 重现期算术 {level=2 check="0.63"}
一个世纪内至少出现一次百年一遇事件的概率是多少？
::: solution
$1 - (1 - 0.01)^{100} = 1 - 0.366 = 0.63$。互补的$37\%$正是"我们没有遇到百年一遇洪水，所以设计标准偏高"这一推理无效的原因。
:::

::: exercise Mann–Kendall检验 {level=3}
某二十年序列有170个一致对和20个不一致对。计算Mann–Kendall统计量$S$、其在原假设下的方差与标准化统计量。
::: solution
$S = 170 - 20 = 150$。无结时$\mathrm{Var}(S) = n(n-1)(2n+5)/18 = 20\times19\times45/18 = 950$，故$Z = (150 - 1)/\sqrt{950} = 4.84$。趋势在远优于$1\%$的水平上显著。Mann–Kendall检验基于秩，因此对异常值和分布形状不敏感——这正是它在降水和水文序列上更受青睐的原因——但它假定无自相关，而序列相关会严重夸大其显著性，于是回到[[#def-rednoise]]的问题。
:::
:::

::: exercise 覆盖与平均 {level=3}
某网络观测40个格点，其中30个在报告。缺失的10个全在极地，而极地增暖速率为全球平均的两倍。若真实全球趋势为$0.20\ \mathrm{K\,decade^{-1}}$，不完整的网络报告什么趋势？一般教训是什么？
::: solution
真实全球趋势为$(30\times0.20 + 10\times0.40)/40 = 0.25\ \mathrm{K\,decade^{-1}}$；丢掉极地格点则报告$0.20$，低估$20\%$。若改用克里金由邻居填补，只要协方差模型正确，估计就是无偏的。

教训是：只有当数据随机缺失时缺失才无害，而在要紧的观测系统中它们并不随机——北极、热带、深海和南大洋恰恰是变化最大而测量最少的地方。这就是为什么1979年以后的极轨卫星时代和2004年以后的Argo浮标阵列对增暖速率和海洋吸热率的估计产生了可测量的修正，而不只是收窄了误差棒（[[climate-change/observed-change]]）。
:::
:::

::: exercise 非平稳极值 {level=3}
某站日降水极大值为Gumbel分布，$\sigma = 12\ \mathrm{mm}$。1960–2020年均值增加$0.9\ \mathrm{mm}$，形状参数$\xi = 0.12$。估算50年重现期量值的变化，并解释为什么只用均值平移是糟糕的描述。
::: solution
平稳拟合下50年量值为$\mu + 12\times3.90 = \mu + 46.8\ \mathrm{mm}$。加上$0.9\ \mathrm{mm}$的均值平移得$+0.9\ \mathrm{mm}$，即$1.9\%$。但$\xi > 0$时上尾尺度也按克劳修斯-克拉珀龙速率对增暖作出响应：若$\sigma$每开尔文增长$7\%$而相关增暖为$1.2\ \mathrm{K}$，则$\sigma$增$10\%$，另加$0.1\times12\times3.90 = 4.7\ \mathrm{mm}$——是均值平移效应的五倍。

这是重尾变量的标准结果：极端值的变化远大于集中趋势，一个只匹配平均降水的模式或偏差校正仍会严重低估五十年一遇事件。这就是为什么对流的允许尺度解析与随机参数化对降水极端如此要紧，也是为什么观测到的亚日降水强度增幅接近每开尔文$7\%$而平均降水增幅只有几个百分点（[[climate-change/extremes]]）。
:::
