地壳是 $46\%$ 的氧、$28\%$ 的硅，剩下的四分之一由其他八种元素分掉；而地球科学之所以不是一份目录，是因为这几个原子有大小。门捷列夫的元素周期表如果当作一张离子半径的清单、而不是重量的清单来读，它就能解释地幔为什么是橄榄石而不是别的东西，钾为什么在花岗岩里而不在橄榄岩里，海洋的镁为什么被黏土的钙交换掉，金刚石为什么硬而石墨是润滑剂，以及你手里那块标本里的石榴石为什么是红的。1923年与1926年，戈尔德施密特在哥廷根、借助最早可靠的 X 射线半径，发表了一套"地球化学分布定律"，说的不过是：元素按大小与电荷自行分拣，而整个岩石学随之而来。他的正确程度达到那些半径的精度，也就是相当好。

::: definition 离子半径与配位 {#def-radii}
晶体里的一个离子不是一个固定大小的球：它的半径依赖于它的**配位数**，因为一个被更多邻居围着的离子被束缚得较松、会膨胀。香农半径以埃为单位、按配位数列出，是这门学科的工作数字：

| 阳离子 | IV | VI | VIII | XII |
|---|---|---|---|---|
| $\mathrm{Si}^{4+}$ | $0.26$ | $0.40$ | — | — |
| $\mathrm{Al}^{3+}$ | $0.39$ | $0.535$ | — | — |
| $\mathrm{Mg}^{2+}$ | $0.39$ | $0.72$ | $0.96$ | — |
| $\mathrm{Fe}^{2+}$ | — | $0.78$ | — | — |
| $\mathrm{Fe}^{3+}$ | $0.49$ | $0.545$ | — | — |
| $\mathrm{Ca}^{2+}$ | — | $1.00$ | $1.12$ | $1.30$ |
| $\mathrm{Na}^{+}$ | — | $1.02$ | $1.18$ | $1.42$ |
| $\mathrm{K}^{+}$ | — | $1.38$ | $1.51$ | $1.64$ |

阴离子 $\mathrm{O}^{2-}$ 的半径在六次配位下取 $1.38\ \text{埃}$。**配位多面体**是三角形（3）、四面体（4）、八面体（6）、十二面体（8）与立方八面体（12），而紧密堆积的几何学固定了每种配位稳定的阳离子对阴离子半径比的范围。
:::

::: proposition 半径比规则 {#prop-radius-ratio}
当一个阳离子的半径足够大、能把 $n$ 个互相接触的阴离子撑开时，它就装得进这个由 $n$ 个阴离子构成的空穴。对三种几何学，这些极限是纯粹的几何：
$$
\left(\frac{r_c}{r_a}\right)_\text{triangular} = 0.155, \quad
\left(\frac{r_c}{r_a}\right)_\text{tetrahedral} = \sqrt{\tfrac32}-1 = 0.225, \quad
\left(\frac{r_c}{r_a}\right)_\text{octahedral} = \sqrt{2}-1 = 0.414, \quad
\left(\frac{r_c}{r_a}\right)_\text{cubic} = \sqrt{3}-1 = 0.732 .
$$
在一个极限之下，阳离子在它的空穴里"哐当"，阴离子彼此接触并排斥，结构便采取较低的配位；在极限之上，配位升高，直到阳离子对那个多面体来说太大。这条规则对大多数常见阳离子的配位预测正确：$\mathrm{Si}^{4+}$ 为 $0.26/1.38 = 0.19$，四次配位（而在地表只可能四次配位）；$\mathrm{Mg}^{2+}$ 为 $0.52$，六次配位；$\mathrm{K}^{+}$ 为 $1.0$，八到十二次配位。
:::

::: proof
对八面体，六个阴离子位于一个边长 $2r_a$ 的正方形的角上、阳离子在中心；阴离子沿边接触，而阳离子–阴离子的接触沿半对角线，所以
$$
2(r_a+r_c) = 2r_a\sqrt2 \Longrightarrow r_c/r_a = \sqrt2-1 = 0.414 .
$$
对立方体，八个阴离子位于一个边长 $2r_a$ 的立方体的角上、沿边接触，而阳离子在体对角线的端点：
$$
2(r_a+r_c) = 2r_a\sqrt3 \Longrightarrow r_c/r_a = \sqrt3-1 = 0.732 .
$$
对四面体，把阴离子放在一个边长 $a$ 的立方体的四个交错角上；阴离子沿面对角线接触，所以 $2r_a = a\sqrt2$，而阳离子到阴离子的距离是体对角线的一半，$r_a+r_c = a\sqrt3/2$。消去 $a$ 得 $r_c/r_a = \sqrt{3/2}-1 = 0.225$。∎

这条规则是一个一级近似，而它的失败是有教益的。$\mathrm{Si}^{4+}$ 为 $0.19$，按严格的读法应该是三次配位，而它是四次配位，因为硅–氧键有一半是共价的、而方向性的键赢了；$\mathrm{Al}^{3+}$ 为 $0.39$，在四次与六次配位的位点上都待得自在，这是地壳化学中最重要的一个事实，因为它意味着铝既能替代骨架中的硅、也能替代八面体层中的镁，因此长石、云母、角闪石与黏土的整个化学得以存在。在约 $100\ \mathrm{kbar}$ 以上，硅自己也变成六次配位，在斯石英中与过渡带的镁硅酸盐石榴石中，而硅的配位变化是地幔 $410$ 与 $520\ \mathrm{km}$ 的地震不连续面之所以是那个样子的原因。
:::

::: example 离子性与硬度 {#ex-ionic}
鲍林的电负性为 $\chi(\mathrm{Si}) = 1.90$、$\chi(\mathrm{O}) = 3.44$、$\chi(\mathrm{Na}) = 0.93$、$\chi(\mathrm{Cs}) = 0.79$、$\chi(\mathrm{F}) = 3.98$。求 $\mathrm{Si}-\mathrm{O}$、$\mathrm{Na}-\mathrm{Cl}$（$\chi_{\mathrm{Cl}} = 3.16$）与 $\mathrm{Cs}-\mathrm{F}$ 键的离子性，并把结果与石英、石盐与萤石的硬度和熔点联系起来。
::: solution
离子性的分数为 $1-\exp[-0.25(\Delta\chi)^2]$：
$$
\mathrm{Si}-\mathrm{O}: \Delta\chi = 1.54, \quad 1-e^{-0.593} = 45\%; \qquad
\mathrm{Na}-\mathrm{Cl}: \Delta\chi = 2.23, \quad 1-e^{-1.24} = 71\%; \qquad
\mathrm{Cs}-\mathrm{F}: \Delta\chi = 3.19, \quad 1-e^{-2.54} = 92\%.
$$
石英因此是一个**共价网络**：它的键有方向、强、在三维中饱和，所以它没有解理，硬度为 $7$，熔点为 $1713\ ^\circ\mathrm{C}$，并且耐酸、玻璃光泽、贝壳状断口。石盐是 $71\%$ 离子性：它的键没有方向，它的结构是等大离子的紧密堆积，因此它有完美的立方解理，硬度为 $2.5$，熔点为 $801\ ^\circ\mathrm{C}$，对一个氯化物来说密度低，并溶于高介电常数、能屏蔽离子引力的水。萤石 $\mathrm{CaF_2}$ 离子性更高，有八面体解理、硬度为 $4$；它与石盐的差别是半径比与结构，不是键型。

这个概括在放大镜前值得记住：**键越共价，矿物越硬，熔点越高，解理越差，折射率的异常越大，也越难溶**。石英、刚玉、尖晶石与金刚石是共价到中间的极端、工业上的磨料；卤化物、硫酸盐与碳酸盐是离子性的极端，软、有解理、可溶。
:::

## 替代：矿物如何混合

::: proposition 类质同象与替代机制 {#prop-solid-solution}
两个离子如果**电荷相同**、半径相差不到约 $15\%$，就自由地互相替代；如果半径相差 $15$–$40\%$，则部分替代，通常带一个溶隙；如果电荷不同，替代就需要一个保持电中性的**耦合机制**。地壳最重要的几个机制是：
$$
\begin{aligned}
&\text{斜长石:} && \mathrm{Ca^{2+} + Si^{4+}} = \mathrm{Na^{+} + Al^{3+}} && (\text{钙长石} \rightleftharpoons \text{钠长石})\\
&\text{单斜辉石:} && \mathrm{Ca^{2+} + Si^{4+}} = \mathrm{Na^{+} + Al^{3+}} && (\text{透辉石} \rightleftharpoons \text{硬玉})\\
&\text{角闪石、云母:} && \mathrm{Al^{3+} + Al^{3+}} = \mathrm{Mg^{2+} + Si^{4+}} && (\text{镁铝置换})\\
&\text{磁铁矿:} && \mathrm{Fe^{3+} + Fe^{3+}} = \mathrm{Mg^{2+} + Si^{4+}} && (\text{钛磁铁矿，橄榄石中的类质同象})\\
&\text{堇青石、长石:} && \mathrm{Al^{3+}} = \mathrm{Si^{4+}} + \mathrm{vacancy} + \mathrm{H^{+}} && (\text{结构中的水})
\end{aligned}
$$
而最后一个是云母、角闪石与电气石为什么把水带进俯冲带的原因，也是"无水"的地幔为什么在其橄榄石中含有几十到几百 ppm 的氢的原因。
:::

::: example 元素往哪边走？ {#ex-partition}
从半径比规则与电荷出发，预测镍、锶、铷与铀在地幔的矿物中是相容的还是不相容的，以及每一种富集在熔体里还是残留体里。取 $r(\mathrm{Ni}^{2+},\text{VI}) = 0.69$、$r(\mathrm{Mg}^{2+},\text{VI}) = 0.72$、$r(\mathrm{Sr}^{2+},\text{XII}) = 1.44$、$r(\mathrm{Rb}^{+},\text{XII}) = 1.72$、$r(\mathrm{K}^{+},\text{XII}) = 1.64$。
::: solution
镍与镁电荷相同、半径相差在 $4\%$ 之内：镍是**相容的**，以 $5$–$15$ 的分配系数进入地幔的橄榄石与尖晶石，这就是诺里尔斯克与坎巴尔达的镍矿床在最早期、最富镁的岩浆里、以及该元素作为一个科马提岩熔体分数的替代指标的原因。

十二次配位的锶比它替代的钙大 $14\%$、电荷相同，所以它替代斜长石与单斜辉石中的钙，而不替代橄榄石中的镁或铁；在玄武质熔体中它轻度不相容，而在麻粒岩中被不含石榴石的残留体留住。铷是一价的，而在 $1.72$ 上比钾大 $5\%$：它跟着钾进云母、碱长石与熔体，是常见元素中最不相容的，这就是 Rb/Sr 比值沿结晶序列上升得如此陡、而大陆地壳的 Rb/Sr 为 $0.4$、地幔为 $0.03$，成为整个地壳锶同位素地层学的基础的原因。

铀是六价的、在其铀酰离子中非常大，在每一种常见硅酸盐中都不相容；它只在一个氧化态变化之后才以 $\mathrm{U^{4+}}$ 进入锆石，而它在地壳中相对地幔的富集，是地壳尽管只持有这颗行星铀的十分之一、却产生其放射性热约一半的原因。戈尔德施密特的分类——相容的镍、铬、镁、钴；不相容的钾、铷、铯、钡、锶与轻稀土；高电荷、高不相容的高场强元素铌、钽、锆、铪与重稀土——不过是半径比规则与电荷平衡的要求，被用到整张元素周期表上。
:::

::: example 方解石与文石 {#ex-polymorph}
方解石是三方晶系，$a = 4.989$、$c = 17.062\ \text{埃}$（六方定向）且 $Z = 6$；文石是斜方晶系，$a = 4.960$、$b = 7.970$、$c = 5.741\ \text{埃}$ 且 $Z = 4$。两者都是 $\mathrm{CaCO_3}$，摩尔质量 $100.09\ \mathrm{g\,mol^{-1}}$。求它们的密度，并解释谁在哪里稳定。
::: solution
六方晶胞的体积为 $V = \tfrac{\sqrt3}{2}a^2c = 0.866\times24.89\times17.062 = 368.4\ \text{埃}^3$，斜方的为 $V = 4.960\times7.970\times5.741 = 226.9\ \text{埃}^3$。于是
$$
\rho_\text{calcite} = \frac{6\times100.09}{6.022\times10^{23}\times3.684\times10^{-22}} = 2.71\ \mathrm{g\,cm^{-3}}, \qquad
\rho_\text{aragonite} = \frac{4\times100.09}{6.022\times10^{23}\times2.269\times10^{-22}} = 2.93\ \mathrm{g\,cm^{-3}}.
$$
文石密 $8\%$，因为它的钙在九次而不是六次配位中、而碳酸根基团堆得更紧；所以它是高压的多晶型，在 $25\ ^\circ\mathrm{C}$ 下约 $10\ \mathrm{kbar}$ 以上、在 $400\ ^\circ\mathrm{C}$ 下 $5\ \mathrm{kbar}$ 以上稳定，这就是文石是俯冲的碳酸盐与深部地壳的矿物、而方解石是石灰岩的矿物的原因。

生物学的转折是：海洋决定你得到哪一种。海水的镁钙比控制珊瑚与钙化藻类沉淀的是文石还是高镁方解石，而地质记录显示海洋在"文石海"与"方解石海"之间、以几千万年为一个循环地交替，其驱动是海底扩张的速率与氢氧热蚀变新地壳带来的镁的通量。在一个文石海里，礁的骨骼在深洋中更容易溶解，碳酸盐补偿深度变浅，碳酸盐工厂的沉积记录在种类上改变。溶液中两种离子的一个比值——由洋中脊的化学决定——竟然控制一座礁的矿物学，这是把晶体化学规则用到了行星的尺度上。

::: example 长石中的有序与无序 {#ex-ordering}
在透长石中，铝与硅随机地分布在单斜晶系钾长石的四个四面体位点上；在微斜长石中它们是有序的，铝占据特定的位点，而结构是三斜的。这个转变发生在 $450$ 到 $550\ ^\circ\mathrm{C}$ 之间，取决于水的含量。解释为什么有序降低对称度，以及这个转变如何被使用。
::: solution
有序之所以是对称度的降低，因为有序的排列在平移下是可区分的：当铝与硅随机分布时等价的那些位点，当其中一个大部分时间持有铝时变得不等价，所以晶胞必须放大或重新定向、而对称度降低。热力学是通常那套——有序的状态焓较低、熵也较低，所以它在低温稳定，而无序的状态靠 $-T\Delta S$ 那一项在高温取胜，转变温度在 $\Delta H/\Delta S$。

它的用法是作为一支温度计与一座钟。一个在花岗岩中于 $800\ ^\circ\mathrm{C}$ 结晶的钾长石，在快速冷却时保留它的透长石无序，而如果它后来被埋到 $400\ ^\circ\mathrm{C}$，它会以铝的扩散所设定的时间尺度有序化为微斜长石，而铝的扩散很慢：所以有序温度是峰温的一个下界、以及在温时间的一个上界。同样的原理用于斜方辉石两个八面体位点之间的镁铁序，给出一个精度为 $30\ ^\circ\mathrm{C}$、在冷却太慢以致交换温度计不再有用的岩石中工作的地温计，而碱长石的铅含量是一个气压计。有序–无序转变是地壳的慢钟，也是一颗变质岩即使在其于峰温平衡的矿物早已被消耗之后仍然记得它的最高温度的原因。
:::
:::

::: warning 离子半径不是一个常数，而一个化学式不是一个分子
这两个错误每一代学生都在犯，而两者都来自把一个模型当作一个对象。**半径依赖于配位、自旋状态与压力**：$\mathrm{Fe}^{2+}$ 在六次配位、高自旋下为 $0.78\ \text{埃}$，在六次、低自旋下为 $0.61$，在四次下为 $0.77$；$\mathrm{Si}^{4+}$ 的半径在从四次到六次、过渡带的压力下增大 $0.14$，而整个 $520\ \mathrm{km}$ 的地震不连续面就是那个数字。**而矿物的化学式不是一个分子**：镁橄榄石里没有漂浮的 $\mathrm{Mg_2SiO_4}$ 分子，只有一个原子比为 $2:1:4$ 的结构，而化学式是一个关于化学计量与位点的论断。这就是一个真实矿物的化学式要写成位点明确的 $(\mathrm{Mg,Fe})_2\mathrm{SiO_4}$ 的原因，也是单个颗粒的电子探针分析要按固定氧原子数报为阳离子的原因——一个掩盖了水的含量、三价铁的比例与空位浓度全都是假设这一事实的约定。
:::

::: quiz
$\mathrm{Al}^{3+}$ 在地壳的化学中异常重要，因为：
- [ ] 它是铁之后最丰富的金属
- [x] 它的半径使它既能进入四次配位、也能进入六次配位，所以它既替代硅、也替代镁
- [ ] 它总是三价的，因此化学上是惰性的
- [ ] 它与氧形成最强的键
::: solution
在四次配位下为 $0.39\ \text{埃}$、六次配位下为 $0.535$，铝坐在四面体场与八面体场之间的边界上，两种都可以占据。仅此一个事实就使耦合替代 $\mathrm{Al^{3+} + Si^{4+}}$ 替代 $\mathrm{Mg^{2+} + Al^{3+}}$、长石、云母、角闪石、黏土矿物、地壳的整个铝硅酸盐化学，以及一个成分不同于地幔的大陆地壳的存在成为可能。
:::
:::

::: history
最早的矿物学是算术：1783年维尔纳按矿物的物理特征给矿物分类，而二十年之内，对沸石的分析产生了"沸石水"的难题——它能在低温被赶出去、又能被重新吸收，与一个水合物的水不同。格雷厄姆1833年把构成水与组成水区分开，是对一个矿物化学式并不按字面意思说话的最早认识。米希尔里希在1819年发现磷酸二氢钾与砷酸二氢钾结晶完全相同，并推断化学相似与晶形有关——类质同象定律，它直接导致了铍的化合价的订正与原子量本身。离子半径作为一个物理量等着 X 射线衍射：布拉格1913–14年的结构给出了最早的原子间距离，而戈尔德施密特在1923年到1938年间从哥廷根、然后从奥斯陆的流亡中出版的九卷《元素地球化学分布定律》中列出了半径、并陈述了以他命名的分布定律。鲍林1929年关于离子半径与离子晶体结构的论文给出了规则与电负性，而香农1976年的修订把半径统一到单一标度上、并按配位数列出，是今天仍在使用的表。色心与晶体场来自1930年代的物理，在1960与1970年代由伯纳姆、伯恩斯与尼科尔森用于矿物，其结果是一颗石榴石的吸收光谱今天可以被读作它的铁含量与它的位点几何的记录。
:::

## 通向何处

由这些多面体建造的结构在[[mineralogy-petrology/silicates]]中；显微镜如何读它们在[[mineralogy-petrology/optical-mineralogy]]中；这里定性使用的分配系数在[[geochemistry/trace-elements]]中被定量、并被用于部分熔融在[[mineralogy-petrology/magma-evolution]]中；随压力的配位变化是[[physical-geology/earth-interior]]的主题；而名义无水矿物中的氢在[[geochemistry/isotopes-water-carbon]]中处理。

::: summary 关键的收获
- 离子是半径依赖于环境的球：半径依赖于配位、电荷与自旋，而香农表按配位数列出。
- 半径比规则由几何学得出：四次配位 $0.225$、六次配位 $0.414$、八次配位 $0.732$，而它预测大多数常见阳离子的配位。
- 键型是一个连续谱：石英是 $45\%$ 离子性的，因此硬、耐火、不溶；石盐是 $71\%$，而相反。
- 类质同象要求相似的电荷与半径；在电荷不同处，像 Ca+Si = Na+Al 这样的耦合替代使长石、硬玉与云母成为可能。
- 相容性是晶体化学：镍跟着镁走，铷跟着钾走，而高场强元素谁也不跟。
- 有序–无序转变以一座扩散的钟记录地壳的热历史，而随压力的配位变化造出地幔的地震不连续面。
:::

## 练习题

::: exercise 半径比 {level=1 check="0.52"}
求 $\mathrm{Mg}^{2+}$（$0.72$）对 $\mathrm{O}^{2-}$（$1.38$）的半径比与预测的配位。
::: solution
$0.72/1.38 = 0.52$，在 $0.414$ 与 $0.732$ 之间：六次配位，八面体。镁是地球地幔的八面体阳离子，这就是地幔是一个镁–氧八面体的结构、而硅在空穴里的原因。
:::
:::

::: exercise 离子性 {level=1 check="22"}
求 $\Delta\chi = 1.00$ 的碳–氧键的离子性，以百分点计。
::: solution
$1-e^{-0.25\times1} = 22\%$。二氧化碳是一个分子气体而二氧化硅是一个三维网络，而这 $23$ 个百分点的离子性之差就是原因。
:::
:::

::: exercise 耦合替代 {level=1 check="1"}
在硬玉替代 $\mathrm{Ca^{2+} + Si^{4+}} = \mathrm{Na^{+} + Al^{3+}}$ 中，替代前的阳离子数与替代后的阳离子数之比是多少？
::: solution
阳离子数不变，二换二，所以比为 $1.0$；改变的是电荷分布与大小。这个替代之所以可能，恰恰因为它同时保持了位点数与总电荷，这就是它能在一个高压榴辉岩中进行到底的原因。
:::
:::

::: exercise 配位变化 {level=1 check="0.54"}
$\mathrm{Si}^{4+}$ 的半径在四次配位下为 $0.26$、六次配位下为 $0.40$。求其分数增量。
::: solution
$(0.40-0.26)/0.26 = 0.54$：阳离子半径增大 $54\%$，以及矿物摩尔体积相应的减小，这就是 $410\ \mathrm{km}$ 处橄榄石到尖晶石的转变使密度增大 $8\%$、并给出一条地震不连续面的原因。
:::
:::

::: exercise 鲍林规则 {level=2 check="2"}
在石英中，每个氧被两个 $\mathrm{SiO_4}$ 四面体共用。用鲍林第二规则求到达氧的静电键强。
::: solution
每条 Si–O 键的强度为 $4/4 = 1$，而两个四面体共用这个氧，总和为 $2$，恰好是氧的电荷。同一条规则也显示一个 $\mathrm{SiO_4}$ 四面体为什么不能与另一个共棱或共面：跨过一条共用棱或面的 Si–Si 排斥是未被屏蔽的，这是鲍林第三规则，也是没有一种硅石矿物把四面体聚合成少于三个一环的环的原因。
:::
:::

::: exercise 戈尔德施密特规则 {level=2 check="15"}
两个电荷相同的离子半径为 $0.72$ 与 $0.83\ \text{埃}$。求百分数之差，并说明是否预期广泛的类质同象。
::: solution
$(0.83-0.72)/0.72 = 15\%$，在规则的边界上：部分类质同象，在低温有一个溶隙。这是 $\mathrm{Fe}^{2+}$ 与 $\mathrm{Mn}^{2+}$ 的情形，以及更极端的 $\mathrm{Mg}^{2+}$ 与 $\mathrm{Fe}^{2+}$，也是出溶片晶在造岩硅酸盐中如此常见的原因。
:::
:::

::: exercise 推导四面体极限 {level=3}
从立方体的构造推导四次配位的临界半径比，然后证明阴离子紧密堆积阵列中的四面体空穴的半径比为 $0.225$、而八面体空穴为 $0.414$。$\mathrm{Si}^{4+}$ 为 $0.19$，为什么仍然取四面体？
::: solution
把阴离子放在一个立方体的角 $(0,0,0)$、$(a,0,0)$、$(0,a,0)$、$(0,0,a)$ 上——一个大立方体（边长 $a$）的四个交错角——使阴离子–阴离子距离为 $a\sqrt2$、而 $2r_a = a\sqrt2$。四面体的中心在 $(a/2,a/2,a/2)$，到每个角的距离为 $a\sqrt3/2$，所以
$$
r_a + r_c = \frac{a\sqrt3}{2} = r_a\frac{\sqrt3}{\sqrt2} \Longrightarrow \frac{r_c}{r_a} = \sqrt{1.5}-1 = 0.225 .
$$
八面体的极限由正方形照正文得出。

硅为 $0.19$，在极限之下，按严格的规则应该是三次配位，像硼在硼酸盐中那样。它是四次配位，因为键有 $45\%$ 是共价的、而共价键有方向性、偏好四个等价的 $sp^3$ 轨道；纯静理论的论证会预测 $\mathrm{SiO_3}$ 基团，而这种基团除了在下地幔的压力下并不存在。这是关于半径比规则的标准告诫：它是一个部分静理论、部分共价的对象的静理论模型，而它在共价项大的地方失败——对硅，对铍，以及对每一个涉及轻元素的键。
:::
:::

::: exercise 晶体场与颜色 {level=2 check="1.24"}
八面体位点中的 $\mathrm{Fe}^{2+}$ 离子有一个以 $1.0\ \mu\mathrm{m}$ 为中心的宽吸收带，对应 $d$ 轨道的分裂 $\Delta_o$。取 $E = hc/\lambda$、$hc = 1.24\ \mu\mathrm{m\cdot eV}$，求这个跃迁的能量，以电子伏计。（输入以电子伏计的能量。）
::: solution
$E = 1.24/1.0 = 1.24\ \mathrm{eV}$，在近红外。透射的光因此在红与红外处被耗减，这就是八面体配位的二价铁使一个矿物呈绿色或褐色、而不是呈任何我们叫得出名字的颜色。同一个离子在四面体配位中有较小的分裂、在更长的波长处吸收，给出黄晶的黄色与摩根石的玫瑰色，而那里的颜色来自一个完全不同的机制。
:::
:::

::: exercise 从分析求化学式 {level=3}
一个橄榄石的电子探针分析给出（wt%）：$\mathrm{SiO_2}\ 39.5$、$\mathrm{MgO}\ 51.0$、$\mathrm{FeO}\ 9.6$。以四个氧为基准计算阳离子比例与镁橄榄石含量 $\mathrm{Mg}/(\mathrm{Mg}+\mathrm{Fe})$。
::: solution
除以分子量——$60.08$、$40.30$、$71.85$——得摩尔比例 $0.657$、$1.266$、$0.134$。归一到两个阳离子（橄榄石结构每四个氧有两个八面体与一个四面体阳离子，所以共三个阳离子，而通常的基准是三个阳离子）：总和为 $2.057$，因子给出 $\mathrm{Si}_{0.958}\mathrm{Mg}_{1.847}\mathrm{Fe}_{0.195}$，在把硅归一到 $1.000$ 之后成为 $\mathrm{Mg}_{1.928}\mathrm{Fe}_{0.204}\mathrm{SiO_4}$。镁橄榄石含量为
$$
100\times\frac{1.928}{1.928+0.204} = 90.4\% .
$$
这个分析因此是一个 Fo 90 的橄榄石，一个正常的地幔或高镁玄武岩的成分。注意这个计算假定了什么：铁全是二价的，没有镍、锰与水，而分析是完整的——这三个假定合起来能把结果挪动一两个镁橄榄石单位，而这比地温计的精度还大。
:::
