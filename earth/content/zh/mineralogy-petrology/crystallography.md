1669年，佛罗伦萨的一位丹麦解剖学学生斯丹诺注意到，一颗石英的晶体可以大可以小、可以胖可以瘦、可以完美可以破碎，而它的任何两个对应晶面之间的夹角永远相同。1783年，阿羽伊——一位在国王陈列室的地板上摔碎了一块矿物标本的中学教师——注意到冰洲石不管你怎么敲，它只碎成菱面体，而每一个菱面体都与其他每一个有相同的角。在这两个观察之间，躺着晶体有一个内部结构、而这个结构是一个**点阵**的发现：一个在三维中重复的图案，其可能的几何学可以在任何人去看一颗晶体之前作为逻辑问题被列举出来。有十四种点阵、三十二个点群与二百三十个空间群，而永远不会出现第十五种、第三十三个或第二百三十一个。

::: definition 点阵、晶胞与晶系 {#def-lattice}
一个**空间点阵**是一个由三个不共面的平移矢量 $\mathbf{a}$、$\mathbf{b}$、$\mathbf{c}$ 生成的、具有相同环境的无限点列。**单位晶胞**是它们张成的平行六面体，而它的几何学由棱长 $a$、$b$、$c$ 与轴角 $\alpha$、$\beta$、$\gamma$ 指定。七个度量晶系穷尽了可能性：

| 晶系 | 度量 | 点阵类型 | 例子 |
|---|---|---|---|
| 立方 | $a=b=c$，全 $90^\circ$ | P, I, F | 石盐、石榴石、金刚石 |
| 四方 | $a=a\ne c$，全 $90^\circ$ | P, I | 锆石、金红石 |
| 六方 | $a=a\ne c$，$\gamma=120^\circ$ | P | 磷灰石、绿柱石、石墨 |
| 三方 | $a=b=c$，$\alpha=\beta=\gamma\ne90^\circ$ | P（菱面体） | 方解石、白云石、辰砂 |
| 斜方 | $a\ne b\ne c$，全 $90^\circ$ | P, C, I, F | 橄榄石、黄玉、文石 |
| 单斜 | $a\ne b\ne c$，$\beta\ne90^\circ$ | P, C | 石膏、正长石、普通辉石、云母 |
| 三斜 | 全不相等，全倾斜 | P | 钠长石、微斜长石、蓝晶石 |

加上可能的中心化与对称，得 $14$ 种布喇维点阵、$32$ 个晶类（点群）与 $230$ 个空间群。在约六千个已知矿物种中，约三分之一是单斜的、五分之一是斜方的；只有少数常见矿物是立方的，而除了2009年在哈特卡陨石中发现的、具有五十次衍射对称而根本没有周期点阵的天然准晶之外，没有一个已知是准晶的。
:::

::: proposition 晶体学限制定理 {#prop-restriction}
一个周期点阵中的旋转轴只能有次数 $n = 1, 2, 3, 4$ 或 $6$。设过一个点阵点 $A$ 有一个 $n$ 次旋转轴，而在最短点阵距离 $t$ 的相邻点 $B$ 有一个相同的轴。把 $B$ 绕 $A$ 转 $\theta = 2\pi/n$、把 $A$ 绕 $B$ 转 $-\theta$，生成两个点阵点，它们沿 $AB$ 直线的间距 $t'$ 必须是 $t$ 的整数倍：
$$
t' = t - 2t\cos\theta = m\,t \Longrightarrow 2\cos\theta = 1-m,
$$
是一个整数。由于 $|2\cos\theta| \le 2$，唯一的可能性是 $2\cos\theta = 2, 1, 0, -1, -2$，给出 $\theta = 0, 60, 90, 120, 180$ 度、$n = 1, 6, 4, 3, 2$。
:::

::: proof
这个论证来自弗伦克尔（1831年），而自那以来每一本结晶学教材都转载它。反过来读它：一个五次轴会要求 $2\cos 72^\circ = 0.618$ 是一个整数，而它不是，所以**没有任何点的周期排列能有五次对称**。这就是雪花有六个瓣而从来没有五个的原因，是教堂的玫瑰窗与矿物的玫瑰花饰在种类上、而不只是在工艺上不同的原因，也是谢赫特曼1982年发现一种有尖锐衍射斑与二十面体对称——五次轴一应俱全——的合金，起初无法发表、被嘲笑了两年、而获得2011年诺贝尔奖的原因。准晶不是周期的；它们是有序的，而它们的衍射需要六个指标而不是三个。在矿物中它们迄今只从一颗陨石中已知，而它们的存在结束了一场持续了一个世纪的争论。∎
:::

::: example 晶面指数，以及晶面之间的夹角 {#ex-miller}
一颗立方晶体的一个晶面在 $1a$、$-2b$ 与 $2c$ 处截轴。给它定指数。然后求立方晶胞中 $(111)$ 与 $(1\bar1 1)$ 之间的夹角，以及 $c/a = 2$ 的四方晶胞中同样指数之间的夹角。
::: solution
截距的倒数为 $1$、$-\tfrac12$、$\tfrac12$；通分得 $(2\bar1 1)$。晶面写在圆括号里，一个晶形或一组对称等价的晶面写在花括号里，方向写在方括号里，一族方向写在尖括号里；数字上方的横线表示负指标，而在六方晶系中加入第四个指标 $i = -(h+k)$，使三条等价的水平轴被同样对待。

对立方晶胞，两个晶面之间的夹角由法线的点积得出，
$$
\cos\phi = \frac{h_1h_2 + k_1k_2 + l_1l_2}{\sqrt{h_1^2+k_1^2+l_1^2}\sqrt{h_2^2+k_2^2+l_2^2}} = \frac{1-1+1}{\sqrt3\sqrt3} = \frac{1}{3},
$$
所以 $\phi = 70.53^\circ$——八面体晶面之间的夹角，也是磁铁矿或尖晶石的一颗八面体晶体看起来是那个样子的原因。在四方晶胞中法线不是简单的 $(h,k,l)$；正确的表达式是
$$
\cos\phi = \frac{h_1h_2+k_1k_2 + c^2l_1l_2/a^2}{\sqrt{h_1^2+k_1^2+c^2l_1^2/a^2}\sqrt{h_2^2+k_2^2+c^2l_2^2/a^2}},
$$
而 $c/a = 2$ 时分子为 $-1+1+4 = 4$、分母为 $\sqrt6\sqrt6 = 6$，所以 $\cos\phi = 0.667$、$\phi = 48.19^\circ$。同样三个数字，在一个不同的点阵里，给出一个不同的角：这就是给一颗晶体定指数意味着先测它的晶胞的原因，也是十九时的光学测角仪与二十时的四圆衍射仪用不同的光做同一件工作的原因。
:::

## 晶面，以及它们告诉你什么

::: definition 晶形、双晶与生长 {#def-forms}
一个**晶形**是一组由晶体的对称联系起来的晶面：在立方晶系中立方体是 $\{100\}$、八面体是 $\{111\}$、十二面体是 $\{110\}$，而六方柱 $\{10\bar10\}$ 加上两个双锥 $\{10\bar11\}$ 与 $\{10\bar1\bar1\}$ 构成了人们熟悉的"石英晶体"。一颗真实的晶体是几个晶形的交叠，而晶面的相对大小记录生长的条件、不是对称。一颗晶体若被它自己的晶面围限就是**自形的**，部分如此就是**半自形的**，若它填充了别人留下的空间就是**他形的**——一种在薄片中可以直接读作结晶顺序的结构。

**双晶**是同一种类的两颗或更多颗晶体，以一个不属于单晶对称操作、但由对称联系起来的方位交生。这些双晶律以矿物种或发现者命名，而有诊断意义：**钠长石律**在 $\{010\}$ 上给出在正交偏光下识别斜长石的聚片双晶；**肖长石律**给出格状钠长石的十字花纹；**卡尔斯巴德双晶**在正长石中常见；**方格双晶**是钠长石律与肖长石律同时作用、是微斜长石的诊断特征；**尖晶石律**在 $\{111\}$ 上使磁铁矿与铁尖晶石成双晶；石英按**道芬律**与**巴西律**成双晶，后者在变形的石英中常见到被用作应变指标；而石膏的"燕尾"接触双晶是任何人在一块手标本里看到的第一对双晶。
:::

::: example 成核，以及为什么玻璃不是矿物 {#ex-nucleation}
对从硅酸盐熔体结晶的石英，取界面能 $\sigma = 0.4\ \mathrm{J\,m^{-2}}$、熔点 $T_m = 1713\ \mathrm{K}$、熔化潜热 $L_f = 1.8\times10^6\ \mathrm{J\,kg^{-1}}$、密度 $2650\ \mathrm{kg\,m^{-3}}$。求过冷 $200\ \mathrm{K}$ 与 $20\ \mathrm{K}$ 时晶核的临界半径，并解释玄武岩为什么可以是玻璃质的、而流纹岩很少。
::: solution
转变的体积自由能为 $\Delta G_v = \rho L_f\Delta T/T_m$，而一个球形晶核停止溶解的临界半径是
$$
r^* = \frac{2\sigma}{\Delta G_v} = \frac{2\sigma T_m}{\rho L_f\,\Delta T} = \frac{2\times0.4\times1713}{2650\times1.8\times10^6\times\Delta T} = \frac{2.86\times10^{-7}}{\Delta T}\ \mathrm{m}.
$$
在 $\Delta T = 200\ \mathrm{K}$ 这是 $1.4\ \mathrm{nm}$，几个单位晶胞，而成核容易；在 $\Delta T = 20\ \mathrm{K}$ 它是 $14\ \mathrm{nm}$，而成核速率、按 $\exp[-16\pi\sigma^3/(3\Delta G_v^2kT)]$ 标度，掉了大约二十个数量级。生长另一方面由扩散控制，并随熔体聚合与变黏而变慢。

这就是黑曜石与花岗岩之间、以速率论的全部差别，也是玻璃与岩石之间、以种类论的差别。玄武岩是一个简单、低黏度的熔体，可以在晶核达到 $r^*$ 之前被淬过它的玻璃转变，所以它在冷却足够快的一切地方形成玻璃——黑曜石、玻璃质玄武岩、枕状熔岩的冷边。流纹岩是一个聚合的、贫水的、极其黏的熔体，其中什么也不扩散、什么也不成核，所以它在会让玄武岩完全结晶的速率下冷却成玻璃（松脂岩、浮岩、一条黑曜岩流的黑色条带）；而在它多少结晶的地方，它结晶得又慢又粗，因为形成的那少数晶核以离子能够到达的速度生长。一种火成岩的结构是这场成核与生长之间竞争的记录，而两者都是过冷度与黏度的函数。
:::
:::

::: example 从晶胞到密度 {#ex-density}
镁橄榄石 $\mathrm{Mg_2SiO_4}$ 是斜方的，$a = 4.756$、$b = 10.195$、$c = 5.923\ \text{埃}$、$Z = 4$ 个化学式单位每晶胞。求晶胞体积与理论密度，并与测得的 $3.22\ \mathrm{g\,cm^{-3}}$ 比较。
::: solution
斜方晶胞的体积就是三条棱的乘积，
$$
V = 4.756\times10.195\times5.923 = 287.4\ \text{埃}^3 = 2.874\times10^{-22}\ \mathrm{cm^3},
$$
而摩尔质量 $140.69\ \mathrm{g\,mol^{-1}}$，
$$
\rho = \frac{ZM}{N_A V} = \frac{4\times140.69}{6.022\times10^{23}\times2.874\times10^{-22}} = \frac{562.8}{173.1} = 3.25\ \mathrm{g\,cm^{-3}}.
$$
与测量值符合到百分之一，不是一个可以轻看的巧合：它意味着从衍射图案确定的结构、化学确定的成分、以及把一颗晶体在液体里称重确定的密度，是对同一件事的三个独立测量，而把晶体当作整数化学式单位的周期排列这个模型是对的。在它们不一致的地方，其中之一是错的，而在历史上这种不一致是矿物化学式四分之三的订正的起点——含水矿物的水、橄榄石里的铁、石榴石里的空位。

这个计算也解释了重矿物为什么在用于分选它们的重液中下沉，一颗石榴石变斑晶为什么向下长进它自己的泥里，以及一个 $3.4$ 的榴辉岩与它 $2.9\ \mathrm{g\,cm^{-3}}$ 的母辉长岩之间的密度反差，为什么足以使一个俯冲的板块下沉。
:::
:::

::: example 石盐为什么是立方体、有时是八面体 {#ex-wulff}
石盐的表面自由能在纯水中为 $\gamma_{\{100\}} = 0.20$、$\gamma_{\{111\}} = 0.19\ \mathrm{J\,m^{-2}}$，而在含硼酸盐的溶液中为 $\gamma_{\{100\}} = 0.20$、$\gamma_{\{111\}} = 0.25\ \mathrm{J\,m^{-2}}$。用伍尔夫构造求两种情形下的平衡形状。
::: solution
伍尔夫构造说，一个平衡的晶体以正比于其表面自由能的距离从中心露出每个晶面，使总表面能 $\sum\gamma_i A_i$ 在给定体积下最小。能量最低的晶面因此伸得最远、并主导形状。在纯水中 $\{111\}$ 面更便宜，晶体趋向八面体，由八个 $\{111\}$ 面围限、而 $\{100\}$ 面缩成角上的小方块；在硼酸盐中次序反转，立方体赢了。

对一颗天然晶体的真实控制很少是平衡形状，而是生长速率，而那不是一回事：一个长得快的面消失，而晶体被它最慢的面围限，那些通常是原子密度最高、而扭折位点密度最低的面——在大多数情形下是同样一些面，这就是平衡论证与生长论证常常一致的原因。它们不一致的地方是化学插手的地方：盐田与蔡希斯坦蒸发岩的八面体石盐，在一个富硼伟晶岩中变成八面体的立方磁铁矿，在手标本中是六方柱、在矿石中是薄板的板状赤铁矿，以及一个晶洞中棱面被溶蚀吃掉、只剩双锥的石英。读一颗晶体的形状就是读它的环境，而小心地做这件事的规矩，把一位矿物学家的描述与一位收藏家的描述分开。
:::

::: warning 关于晶体的三种混淆
**一颗晶体不是一个晶体形状。**冰川里的冰是一个毫无晶面的晶体集合体，而它和金刚石一样是结晶的；一个玻璃有漂亮的弯曲表面而根本不是晶体。定义的性质是内部的周期性，那是衍射仪读出的东西、也是显微镜看见的东西。**一个晶面不是一个解理。**石盐的立方晶面是生长面而它的解理也是立方的，但方解石的解理菱面体很少作为生长形态出现，而云母完美的底面解理与它的晶体形状毫无关系：解理是结构最弱面的痕迹，而晶面是生长最慢的那个面，它们只是碰巧重合。**双晶不是一个可以忽略的缺陷。**斜长石的聚片双晶是识别它最快的方式，石英与橄榄石的变形双晶是岩石记录中最好的应力指标之一，而一颗钙钛矿太阳能电池的双晶界是电流漏出去的地方。
:::

::: quiz
一颗晶体被发现有单个四次旋转轴、以及除一个垂直于它的镜面之外没有其他对称。它的晶系是：
- [ ] 立方的，因为它有一个四次轴
- [x] 四方
- [ ] 六方的，因为四除不尽六
- [ ] 三斜的，因为它对称性这么少
::: solution
单个四次轴要求 $a$ 轴与 $b$ 轴相等、$c$ 轴不同，而所有角为九十度：四方晶系。立方晶系要求沿体对角线的四个独立的三次轴，那是一个强得多的条件；单个四次轴的存在并不使一颗晶体成为立方的，而这是判定一颗未知晶体的晶系时最常见的错误。
:::

斯丹诺1669年的观察之后是一个世纪的积累：1783年罗梅德利尔证实的晶面恒定定律，以及有理指数定律——任何晶面的截距成小整数之比——隐含在阿羽伊1784年的"积分分子"中、而在埃瓦尔德的德文表述之后由惠威尔在1821年明确说出。阿羽伊的理论在细节上是错的，因为他的"分子"是一个方解石的菱面体、不是一个九个原子的单位晶胞，但它在结构上是对的，并解释了当时知道的一切。布喇维1848年对十四种点阵的列举与赫斯1830年对三十二个晶类的列举，把结晶学变成了数学；费奥多罗夫与舍恩弗利斯1891年各自独立发现的二百三十个空间群，在一篇花了三年才发表的论文中宣布，而受到的对待是冷漠。1912年2月，弗里德里希与诺平、在劳厄的建议下，把一根库利奇管的 X 射线穿过硫酸铜晶体、在照相底片上拍出斑点，晶体的结构从此变成可测量的、而不是可推断的。布拉格父子在剑桥1913年造了光谱仪，1914年解出 NaCl——那个显示并不存在一个氯化钠分子的结构——同一年解出金刚石。劳伦斯·布拉格二十五岁，至今仍是最年轻的诺贝尔科学奖得主。硅酸盐的结构等着电子数：劳伦斯·布拉格1913年的论文提出了硅酸盐中的四面体排列，而鲍林1929年的规则把矿物的整个化学变成了静理论与几何学的问题。
:::

## 通向何处

填充这些结构的化学在[[mineralogy-petrology/crystal-chemistry]]中、硅酸盐本身在[[mineralogy-petrology/silicates]]中；显微镜的光学在[[mineralogy-petrology/optical-mineralogy]]中；X 射线被地球物质的衍射以及衍射仪在地球科学中的使用在[[remote-sensing/em-radiation]]中。这里假定的手标本与岩石描述在[[physical-geology/minerals]]中，变形显微构造在[[structural-geology/shear-zones]]中，而把矿物化学用作温度计在[[mineralogy-petrology/pt-paths]]中。

::: summary 关键的收获
- 晶体由它周期性的内部结构定义、不是由它的形状定义；七个度量晶系、十四种点阵、三十二个晶类、二百三十个空间群。
- 晶体学限制禁止五次与七次轴，因为 2 cos theta 必须是一个整数；准晶靠不周期而逃脱。
- 晶面指数是轴截距的通分倒数，而晶面之间的夹角由晶胞的度量得出、不只由指数得出。
- 晶形记录对称，晶面大小记录生长，而双晶同时记录对称与变形：双晶律是一个鉴定工具。
- 成核需要过冷、并按界面能的三次方的负指数标度；生长需要扩散。它们的竞争写下每一种火成岩的结构。
- 布拉格定律把晶体变成一组峰的位置，而粉晶衍射仪是显微镜无法作答、它来回答一个矿物是什么的那台仪器。
:::

## 练习题

::: exercise 晶面指数 {level=1 check="210"}
一个晶面在 $1$ 处截 $a$、在 $2$ 处截 $b$、而平行于 $c$。把它的晶面指数写成一个三位数（hkl）。
::: solution
倒数为 $1$、$\tfrac12$、$0$；通分得 $(210)$。
:::
:::

::: exercise 晶面之间的夹角 {level=1 check="54.7"}
求立方晶体中 $(100)$ 与 $(111)$ 之间的夹角，以度计。
::: solution
$\cos\phi = 1/\sqrt3$，所以 $\phi = 54.74^\circ$——一个立方面与一个八面面之间的夹角，也是金刚石沿以解理的两个 $\{111\}$ 面之间夹角的余角。
:::
:::

::: exercise 数点阵 {level=1 check="4"}
斜方晶系属于多少种布喇维点阵？
::: solution
四种：原始、底心、体心与面心。立方晶系有三种，四方两种，三斜、六方与菱面体各一种，合起来十四种。
:::
:::

::: exercise 半径比 {level=1 check="0.29"}
已知 $r(\mathrm{Si}^{4+}) = 0.40\ \text{埃}$、$r(\mathrm{O}^{2-}) = 1.38\ \text{埃}$，求半径比与预测的配位。
::: solution
$0.40/1.38 = 0.29$，落在 $0.225$ 与 $0.414$ 之间：四次配位，四面体。同一条规则对镁给出 $0.72/1.38 = 0.52$，六次配位，对钾给出 $1.38/1.38 = 1.0$，八到十二次配位——这就是硅在四面体中、镁在八面体中、而钾只在长石与云母的大位点中的原因。
:::
:::

::: exercise 布拉格定律 {level=1 check="29.4"}
用 $\lambda = 1.5418\ \text{埃}$ 的铜辐射，求 $d = 3.035\ \text{埃}$ 的方解石 $(10\bar4)$ 反射的 $2\theta$，以度计。
::: solution
$\sin\theta = 1.5418/(2\times3.035) = 0.2541$、$\theta = 14.72^\circ$、$2\theta = 29.45^\circ$。这是方解石最强的峰，也是一台在低角度运行的衍射仪能在几分钟内把石灰岩与白云岩区分开的原因。
:::
:::

::: exercise 临界晶核 {level=2 check="7.2"}
对算例中的常数，求过冷 $40\ \mathrm{K}$ 时的临界半径，以纳米计。
::: solution
$r^* = 2.86\times10^{-7}/40 = 7.2\ \mathrm{nm}$。在 $200\ \mathrm{K}$ 与 $20\ \mathrm{K}$ 的过冷之间，临界半径增大十倍、成核速率掉了大约二十个数量级，这就是一块满是细小晶体的岩石与一块玻璃质岩石之间的差别。
:::
:::

::: exercise 鲍林第二规则 {level=2 check="3"}
在镁橄榄石 $\mathrm{Mg_2SiO_4}$ 中，每个氧与四面体配位的一个硅、以及若干八面体配位的镁成键。多少个？
::: solution
鲍林第二规则要求到达一个阴离子的静电键强之和等于它的电荷。Si–O 强度为 $4/4 = 1$、Mg–O 强度为 $2/6 = \tfrac13$，所以氧需要 $(2-1)/(1/3) = 3$ 个镁邻居，而镁橄榄石的结构恰好如此：每个氧在三个 $\mathrm{MgO_6}$ 八面体与一个 $\mathrm{SiO_4}$ 四面体的中心。同样的算术用于顽火辉石 $\mathrm{MgSiO_3}$，其中氧有两种——两个四面体共用的（桥氧，硅的贡献为 2、不需要镁）与只键到一个四面体的（需要三个镁）——预测出辉石结构的两种不同的氧位点，而 X 射线测定后来找到了它们。
:::
:::

::: exercise 推导二维的限制 {level=3}
在二维中，通过考虑一个点阵矢量的旋转证明只可能有 2、3、4 与 6 次轴，并通过加中心化列举五个二维点阵。为什么没有一个与正方点阵不同的"心正方"点阵？
::: solution
把点阵绕相距 $t$ 的两个点阵点转 $\theta$ 必须沿原来的直线给出一个点阵矢量，所以 $t(1-2\cos\theta) = mt$、而 $2\cos\theta$ 是一个整数，与三维一样：允许的旋转是 $180$、$120$、$90$ 与 $60$ 度。五个平面点阵由度量得出：斜方（斜交）、矩形、心矩形、正方与六方。

一个"心正方"点阵不是第六个，因为心正方的晶胞包含一个旋转四十五度、面积只有四分之一的更小正方晶胞：给正方加中心化不产生任何新东西。同样的论证用于矩形点阵，给出一个真正新的点阵，因为心矩形不能约化成一个更小的、带直角的原始矩形。这就是整个列举，也是十四种三维点阵为什么是十四种而不是更多的原因：每一个看似新的中心化，或者在一个更小的晶胞中约化为一个已有的点阵，或者被它本会要求的点对称排除。
:::
:::

::: exercise 极射赤面投影 {level=3}
一颗对称未知的晶体的两个晶面在测角仪上给出 $60^\circ$ 的面法线夹角，而晶体有一个水平的镜面。画出可能的对称并判定哪些晶系仍然开放。
::: solution
一个与另一个成 $60^\circ$ 的面法线，加上一个水平镜面，靠反射生成一对与铅垂成 $\pm 60^\circ$ 的面法线，而这两个反射面法线之间的角，若它们在同一个铅垂面内就是 $2\times60 = 120^\circ$，若不在则更小。可能性是单个二次轴（单斜或斜方）、一个面法线与铅垂成 $70.53^\circ$ 的三次轴（三方或六方）、一个 $60^\circ$ 的四次轴（四方）或一个 $30^\circ$ 的六次轴。

做出判定的测量是等价晶面的数目：数它们。六个由水平六次轴与一个铅垂镜面联系的等价晶面是六方的双锥；三个是三方的；四个带一个水平镜面，依铅垂镜面的存在与否是四方的或斜方的。这正是1870年到1920年之间一台反射测角仪与一个二圆台所做的事，也是达纳的经典矿物描述把测得的角给到角分的原因：角就是对称，而对称就是晶类。
:::
