一片三十微米厚、粘在载玻片上的岩石薄片，是科学中信息最密的对象之一。在一台偏光显微镜前一小时，你可以说出其中的矿物名字，说出哪个先长、哪个替换了哪个，测量它们其中两个最后平衡时的温度，判定变形它们的应力的方向与大小，并读出这块岩石从三十公里深处到地表途中走过的压力–温度轨迹。这一切都不必破坏样品，而这一切在手标本中都看不见。

原因是大多数造岩矿物是**各向异性的**：它们的光学性质依赖于方向。一种给定颜色的光在不同的方向以不同的速度穿过它们，而显微镜把这个差别变成亮度、颜色与位置。矿物光学因此是应用晶体光学，而最好的学法是推出支配你所见的那几个关系，然后看大量的薄片。

## 透明固体中的光

::: definition 折射率与突起 {#def-relief}
矿物的**折射率** $n$ 是真空中光速与它在矿物中速度之比，$n = c/v$。光穿过两种介质之间的边界时按**斯涅尔定律**折射，$n_1\sin\theta_1 = n_2\sin\theta_2$，并部分反射；反射的份额随 $n$ 之差陡峭上升。**突起**是一个颗粒边缘的表观高度与清晰程度，它随 $|n_\text{mineral} - n_\text{medium}|$ 增大。在一个普通薄片中，树胶的折射率约为 $1.54$，所以一个 $n$ 接近 $1.54$ 的矿物——石英、大多数长石——看起来几乎看不见，直到你合上偏光镜，而 $n = 2.6$–$2.9$ 的金红石以粗黑的轮廓凸显出来。
:::

::: example 突起与贝克线 {#ex-relief}
在一个标准薄片中按突起给石英（$n = 1.544$）、An$_{20}$ 的斜长石（$n = 1.537$）、Fo$_{90}$ 的橄榄石（$n = 1.66$）、普通辉石（$n = 1.70$）与榍石（$n = 1.90$）排序，并描述如何判定两个颗粒中哪个折射率更高。
::: solution
突起按 $|n - 1.54|$ 标度：斜长石 $0.003$、石英 $0.004$、橄榄石 $0.12$、普通辉石 $0.16$、榍石 $0.36$。前两个是**极低突起**——边缘勉强可见，最好在正交偏光镜下看；橄榄石与普通辉石是**中等**；榍石是**高**，有粗黑的边界与一条宽的贝克带。

要在两个颗粒之间判定，先聚焦在边界上，然后升高显微镜的镜筒（它把物镜朝载物台放下，所以焦平面*向下*穿过样品移动）。一条亮的亮线——**贝克线**——出现，而当你朝那个方向调焦时，它进入折射率**较高**的那种介质。用窄的光阑与柔和的照明时，这个效应不会看错。精确的工作是把颗粒浸在一串已知折射率的油中，记下哪一桶油使突起消失：在那一点 $n_\text{矿物} = n_\text{油}$，而折射率被列表一个世纪用的就是这个办法。
:::
:::

## 双折射

在各向同性的材料中——一个立方矿物或一个玻璃——电位移 $\mathbf{D}$ 与电场 $\mathbf{E}$ 平行，而只有一个折射率。在任何对称更低的材料中，极化率是一个张量，$\mathbf{D} = \varepsilon_0\boldsymbol{\varepsilon}_r\mathbf{E}$，而 $\mathbf{D}$ 与 $\mathbf{E}$ 不再平行。其结果——博林1669年在方解石中发现、由惠更斯解释的——是一条进入这种晶体的光线分裂成两条线偏振的光线、以不同的速度行进、而它们的振动方向成直角：**双折射**，或称重折射率。

::: definition 光率体、光轴与光性符号 {#def-indicatrix}
**光率体**是一个椭球，其半轴是三个主折射率 $n_\alpha \le n_\beta \le n_\gamma$。沿一个给定方向行进的光线看到的是垂直于该方向的一个平面截光率体所得的椭圆，并沿其半轴偏振地分裂成两条光线。
- **各向同性**（立方、玻璃）：光率体是一个球；一个折射率，无双折射，在正交偏光镜下的每一个方位都是黑的。
- **一轴晶**（三方、四方、六方）：光率体是一个回转椭球，半轴为 $n_\omega, n_\omega, n_\varepsilon$。有一条**光轴**，平行于那个唯一的轴。$\Delta n = |n_\varepsilon - n_\omega|$。若 $n_\varepsilon > n_\omega$ 矿物是**一轴晶正**的（石英，$\Delta n = 0.009$），若 $n_\varepsilon < n_\omega$ 是**负的**（方解石，$\Delta n = 0.172$）。
- **二轴晶**（斜方、单斜、三斜）：三个不等的轴。有两条光轴，而它们在晶体内部量出的夹角是 $2V$。**光轴面**包含两条轴与 $X$、$Z$ 两个振动方向；$Y$ 永远是钝角等分线。若*锐*角等分线是 $Z$，矿物是**二轴晶正**的，若是 $X$ 则是**负的**。
:::

::: proposition 重折射率、厚度与干涉色 {#prop-retardation}
一个随机方位切磨、厚度为 $t$ 的颗粒把入射光分解成两条振动方向对应折射率 $n_1'$ 与 $n_1''$ 的光线。在正交偏光镜之间，两者以一个**光程差**（推迟）重新合并
$$
\delta = t\,\Delta n = t\,(n_1'' - n_1'),
$$
而颗粒显得亮，带一个由 $\delta$、且只由 $\delta$ 决定的干涉色。同一矿物的两个不同厚度的颗粒，或两个 $t\,\Delta n$ 之积相同的不同矿物，显示同样的颜色。
:::

::: proof
两个分量以下表面的相位差 $\phi = 2\pi\delta/\lambda$ 离开。检偏镜把两者都投影到一个共同的振动方向上，而重新合并的光的强度为
$$
I = I_0\sin^2(2\phi_a)\sin^2\!\left(\frac{\pi\delta}{\lambda}\right),
$$
其中 $\phi_a$ 是第一个分量与起偏镜之间的角。第二个因子在 $\delta = (m + \tfrac12)\lambda$ 时为一、在 $\delta = m\lambda$ 时为零，所以白光中每个波长按它自己的条件被透过或被消光，而颗粒带上那些未被抵消的波长的颜色。由于 $\delta$ 只通过 $t$ 与 $\Delta n$ 的积依赖于两者，颜色固定的是那个积、不是任何一个因子——这就是一个 $30\ \mu\mathrm{m}$ 的石英薄片（$\delta = 270\ \mathrm{nm}$）看起来与一个 $\Delta n = 0.018$ 的矿物的 $15\ \mu\mathrm{m}$ 薄片同样是淡灰色的原因。
:::

::: definition 干涉色与米歇尔–莱维图 {#def-michel-levy}
**米歇尔–莱维图**把光程差 $\delta$ 对每种颜色的厚度作图。在标准的 $30\ \mu\mathrm{m}$ 薄片中读它：一级灰与白占 $\delta \approx 100$–$350\ \mathrm{nm}$，一级黄约 $480\ \mathrm{nm}$，一级红约 $560\ \mathrm{nm}$；二级蓝约 $680\ \mathrm{nm}$，二级绿约 $800\ \mathrm{nm}$，二级红约 $1030\ \mathrm{nm}$；三级色到约 $1650\ \mathrm{nm}$，四级在更远处。因为级次重复，一个看起来像一级红的颜色可能是二级或三级红，而判定它是哪一级要靠**石英楔**或一块**石膏试板**。
:::

::: example 一个 30 µm 薄片中的光程差与干涉色 {#ex-retardation}
计算石英（$\Delta n = 0.009$）、An$_{20}$ 斜长石（$0.009$）、普通辉石（$0.026$）、Fo$_{90}$ 橄榄石（$0.036$）、白云母（$0.013$）、角闪石（$0.020$）、文石（$0.015$）、方解石（$0.172$）与金红石（$0.106$）在一个标准薄片中的 $\delta$，并说出干涉色。
::: solution
以 $t = 30\ \mu\mathrm{m} = 3.0\times10^{4}\ \mathrm{nm}$，$\delta = 3\times10^{4}\Delta n$：

| 矿物 | $\Delta n$ | $\delta$ (nm) | 颜色 |
|---|---|---|---|
| 石英 | 0.009 | 270 | 一级灰到白 |
| 斜长石 | 0.009 | 270 | 一级灰，带聚片双晶 |
| 白云母 | 0.013 | 390 | 一级白到淡黄 |
| 文石 | 0.015 | 450 | 一级上部 |
| 角闪石 | 0.020 | 600 | 一级上部到二级下部 |
| 普通辉石 | 0.026 | 780 | 二级下部，常蓝绿 |
| 橄榄石 | 0.036 | 1080 | 二级下部，明亮 |
| 金红石 | 0.106 | 3180 | 四级及以上，俗艳 |
| 方解石 | 0.172 | 5160 | 高级，珍珠灰到淡粉 |

从这张表要拿走两件事。第一，常见造岩矿物的整个范围只占前两级，这就是标准薄片是 $30\ \mu\mathrm{m}$ 的原因：更厚的薄片会把一切放进令人困惑的高级，更薄的会让石英与长石难以看见。第二，方解石与金红石的重折射率如此之大，以致它们的颜色基本上不携带信息——你靠突起、解理、双晶与晶形识别它们，不靠颜色。
:::

## 显微镜，以及每件附件换来什么

一台偏光显微镜是一台标准的明视场仪器，加两个偏光镜、一个旋转载物台、和一个放附件的槽。每样添加回答一个不同的问题。

**下偏光镜（平面偏振光）。**颜色、突起、解理、双晶、断口、蚀变与多色性。转动载物台：一个多色性的矿物随着它的吸收方向转入起偏镜的振动方向而改变颜色。黑云母是经典的——三个方向上是稻草黄、橄榄褐与深红褐——随后是电气石、十字石、硬绿泥石、角闪石与钒白云母。

**上偏光镜（正交偏光）。**关于对称与方位的一切。一个各向同性的颗粒在所有方位都是黑的。一个各向异性的颗粒每转一圈明暗四次，**消光位**出现在振动方向平行于偏光镜时。在消光位之间颗粒是亮的，在 $45^\circ$ 处最亮。

**消光角。**如果消光平行于一条晶棱或解理，矿物是平行消光的；如果是斜的，量那个角。在单斜矿物中消光角 $Z \wedge c$ 有诊断意义、并随成分系统地变化——它是估计斜长石的钙长石含量与普通辉石的硬玉含量的一个经典办法，也是一个矿物统计清单之所以不只是一份名单的原因。

**石膏楔与石英楔。**一块一级红石膏试板（$\delta = 550\ \mathrm{nm}$）插入槽中，把它的光程差加上或减去颗粒的，取决于两个快方向是平行还是垂直。颗粒变亮（**相加**）或变暗（**相减**），而由此你知道光率体轴的相对方位——因而有光性符号，因而对许多矿物族，有成分。

**锥光镜（贝特朗镜）。**聚焦到物镜的后焦平面上，你看到的是**干涉图**：一轴晶矿物是一个以黑十字中心为心的黑十字，二轴晶矿物是两条弯曲的等消光线，在转台时分离成两束刷。刷的间距给出 $2V$；弯曲度与对石膏试板的响应给出符号。这是区分石英与玉髓、或分开 $\mathrm{Al_2SiO_5}$ 的多晶型的唯一常规办法。

::: example 从干涉图求光性符号 {#ex-sign}
一个颗粒给出一轴晶干涉图：一个以视域为中心的黑十字。然后插入一块一级红石膏试板，而沿试板慢方向的两个象限从灰变蓝、另外两个变黄。解释这如何给出光性符号，并说明如果蓝色的象限是沿试板*快*方向的那些，你会得出什么结论。
::: solution
试板是一个已知的延迟器，有一个已知的慢方向。在一个矿物自己的慢振动方向与试板的**平行**的象限里，两个光程差相加、颜色沿米歇尔–莱维图向上移动，从一级红到二级蓝；在两者垂直处，光程差相减、颜色向下移动，朝黄与灰。所以蓝色的象限告诉你矿物的慢方向在哪里。

在一个一轴晶干涉图中，两条光线**径向**偏振（非常光，折射率 $n_\varepsilon$）与**切向**偏振（常光，折射率 $n_\omega$）。径向方向与试板慢方向平行的那些象限，因此就是 $n_\varepsilon$ 是慢折射率时变蓝的那些。在上面观察中它们变蓝，所以 $n_\varepsilon > n_\omega$、矿物是**一轴晶正**的——石英，或某个正三方、正四方矿物。

如果蓝色的象限是被试板的*快*方向穿过的那些，径向的光线就会是快的那条，$n_\varepsilon < n_\omega$，而矿物会是**一轴晶负**的——方解石、磷灰石、电气石、刚玉。

对一个二轴晶干涉图做同样的操作用的是两条弯曲的等消光线、不是十字：插入试板后，等消光线变黑并在东北与西南象限合并成一条双曲线，对一个**正**矿物如此；在西北与东南象限则是一个**负**矿物，而同一个图中刷的分离对着一个标定的目镜分划给出 $2V$。
:::
:::

::: quiz
一个 $30\ \mu\mathrm{m}$ 薄片中的一个无色矿物显示明亮的二级蓝干涉色与中等突起，它没有解理而有贝壳状断口。最可能的鉴定是
- [ ] 石英
- [ ] 白云母
- [x] 橄榄石
- [ ] 方解石
::: solution
$30\ \mu\mathrm{m}$ 下的二级色意味着 $\Delta n \approx 0.03$，远高于石英（$0.009$）与白云母（$0.013$），而中等突起符合 $n \approx 1.66$ 的橄榄石。方解石被它高得多的突起、菱面体解理与珍珠灰的高级色排除；橄榄石高重折射率、无解理、贝壳状断口与不规则颗粒形状的组合不会认错。
:::
:::

::: warning 干涉色不等同于多色性，而两者也都不等同于突起
三样东西不断被混淆，而它们回答三个不同的问题。**突起**是一个边界效应，由矿物的与介质的折射率之*差*控制，在平面偏振光中看到。**多色性**是*选择性吸收*：矿物本身在转动时、在正交或单偏光镜之间改变颜色，因为它沿不同的振动方向不同地吸收不同颜色的光；它只发生在吸收性（通常是有色的）矿物中。**干涉色**只在正交偏光镜之间出现，由光程差、不是由吸收产生，永远不是黑的，并按一个固定的序列遵循米歇尔–莱维图。一个转动时变暗到接近黑的褐色黑云母是多色性的；同一个颗粒在正交偏光镜之间显示一级到二级的颜色、带一个异常的褐色色调，而那个色调是多色性透出来的。
:::

## 二轴晶光学，定量的

对一个二轴晶矿物，光率体有三个不等的半轴，而两条光轴位于 $X$–$Z$ 平面（**光轴面**）中、对称于 $Z$。它们的半角由垂直于一条光轴的中心截面是一个半径为 $n_\beta$ 的圆这一条件得出；结果是

$$
\tan^2 V_z = \frac{n_\alpha^{2}\left(n_\gamma^{2} - n_\beta^{2}\right)}{n_\gamma^{2}\left(n_\beta^{2} - n_\alpha^{2}\right)},
\qquad 2V_x + 2V_z \approx 180^\circ .
$$

由于对每一种常见矿物 $n_\alpha/n_\gamma$ 与一的差不到百分之二，矿物的符号几乎完全由 $n_\gamma - n_\beta$ 小于还是大于 $n_\beta - n_\alpha$ 决定：如果中间折射率坐得*更接近* $n_\gamma$，那么 $V_z < 45^\circ$、锐角等分线是 $Z$、而矿物是**正**的。

测得的 $2V$ 在几个重要的矿物组中是成分的强函数：在云母中它把白云母（$2V \approx 35$–$45^\circ$，负）与钠云母（$2V \approx 8$–$10^\circ$，负）分开；在角闪石中它把透闪石（$2V_z \approx 9^\circ$，正）与直闪石（$2V \approx 124^\circ$，负）分开；在辉石中它把斜方辉石与普通辉石分开；而在长石中它把透长石（$2V_z \approx 18^\circ$，负）与钙长石（$2V_z \approx 78^\circ$，正）分开——这就是一颗钾长石的结构状态、因而它最后平衡的温度，如何被光学地测量。

::: example 从主折射率求光轴角 {#ex-2v}
钙长石有 $n_\alpha = 1.580$、$n_\beta = 1.588$、$n_\gamma = 1.593$。计算 $2V_z$ 并说明光性符号。
::: solution
$$
n_\alpha^2 = 2.4964,\qquad n_\beta^2 = 2.5217,\qquad n_\gamma^2 = 2.5377,
$$
所以 $n_\gamma^2 - n_\beta^2 = 0.0160$、$n_\beta^2 - n_\alpha^2 = 0.0253$。于是
$$
\tan^2 V_z = \frac{2.4964\times0.0160}{2.5377\times0.0253} = \frac{0.03994}{0.06420} = 0.622,
\qquad \tan V_z = 0.789,
$$
由此 $V_z = 38.3^\circ$、$2V_z \approx 77^\circ$，与纯钙长石的表列值 $78^\circ$ 符合良好。由于 $2V_z < 90^\circ$，锐角等分线是 $Z$、而矿物是**二轴晶正**的。

现在扰动它：如果 $n_\beta$ 不是 $1.588$ 而是 $1.585$——一个小于大多数测量的可重复性的差——两个差变成 $0.008$ 与 $0.005$、$\tan^2 V_z$ 变成 $1.60$、$V_z$ 变成 $51^\circ$，而矿物翻转为**二轴晶负**。这个灵敏度是 $2V$ 在矿物之间是一个极好的定性判别量、而是一个糟糕的定量判别量的原因，也是光角数据必须总是连同获得折射率所用的方法一起引用的原因。
:::
:::

caption: $\tan V_z$ 如何响应中间折射率 $n_\beta$，而 $n_\alpha$ 与 $n_\gamma$ 保持在钙长石的值上。$\tan V_z = 1$ 处的竖直线是正（$<1$）与负（$>1$）矿物之间的边界。把滑块拖动 $0.005$——小于大多数测量能分辨的——矿物就改变符号。这就是光角数据必须连同获得折射率所用的方法一起引用，以及达到 $\pm 0.001$ 的浸油法为什么值得一百年的劳动的原因。
:::

## 结构意味着什么

矿物光学不是一个命名练习。鉴定矿物组合的意义在于读出**结构**，而结构才是记录：

- 带包裹体的**变斑晶**颗粒靠交代穿过一个先存的组合生长；包裹体告诉你被替换的是什么。
- **条纹长石文象结构**——斜长石对着一个钾长石颗粒的虫状石英生长——记录一个有流体的反应，而是一个应变标记。
- **条纹结构**的纹片及其宽度，记录穿过碱长石溶隙的冷却速率。
- 一个糜棱岩中的**云母鱼**、**σ 斑碎晶**与**书本状云母**直接给出剪切的方向。
- **压力影**与**后生合晶**给出反应路径，因而给出压力–温度路径的方向。
- **双晶**——斜长石中的聚片双晶、斜方辉石中的双晶纹片、石英中的道芬双晶——记录生长、变形或一个相变，而最后一种可以是一个古温度计。

读它们不需要比显微镜更多的东西，这也是在电子探针的时代岩石学家仍然先看薄片的原因。

::: example 一个颗粒，被鉴定了 {#ex-identify}
一个 $30\ \mu\mathrm{m}$ 薄片中一个无色的颗粒有极低突起、一级灰干涉色、只在一个方向上完美的解理、关于解理迹对称的聚片双晶、以及对解理 $6^\circ$ 的消光角。它是什么，下一个测量是什么？
::: solution
极低突起与一级灰把它放在石英–长石的范围内。聚片双晶排除石英（它在大多数岩石中无双晶、也无解理）而选入**斜长石**。关于解理小角度的对称消光，在一个有两个约 $90^\circ$ 解理的颗粒中（检查第二个不完美的那个），指示一个**钙质**的成分：钠长石在 $\{010\}$ 上的消光角可达约 $25^\circ$，而拉长石与钙长石给 $5^\circ$–$10^\circ$。

下一个测量是标准方位上的消光角，在一个垂直于 $(001)$ 切磨的颗粒上，它把成分放到标准曲线上、给出一个大致的 An 含量——这里也许是 An$_{75\pm10}$。如果精度要紧，用旋转台或电子探针确认它；并注意这个光学估计是一个*成分*的估计，只有当斜长石是无环带的，而对单个颗粒从核到边变化的仔细一看通常会告诉你事实并非如此。
:::
:::

::: history
博林在1669年描述了穿过方解石的像的加倍。惠更斯在他1690年的《光论》中用一个在一个方向上是球、在另一个方向上是椭球的波前解释了它——除了名字之外就是光率体——并创造了常光与非常光这两个术语。马吕斯1808年发现了反射起偏，而阿拉果、毕奥与菲涅耳在1811年到1822年间建造了双折射的波动理论，菲涅耳1821年关于光是横波的预言最终解释了为什么是两条光线、不是三条。索比发明了这里所用意义上的岩相显微镜：在1858年开始的一系列论文中，他把岩石磨成薄片、放到显微镜之下，并读出结晶的顺序、交代的结构，以及矿物内部的气泡与流体，从而同时创立了化学岩石学与流体包裹体显微测温。罗森布施在1870与1880年代把数千种岩石的描述岩相学系统化。矿物界的光学常数随后主要用浸油法测出，列在刘易斯、福特与舍曼的汇编以及林内的表中；两代人的标准英文参考是温切尔夫妇1927–1931年的《矿物光学要素》，以及后来迪尔、豪伊与祖斯曼的《造岩矿物导论》。光学方法本身由基希施泰因的旋转台与莫罗的五轴台补齐，它们使变形岩石中晶体方位的测量成为常规。
:::

## 通向何处

矿物光学是此后一切事情的入门方法。石英的消光与双晶是[[structural-geology/shear-zones]]的应变标记；云母与角闪石的光学性质是[[mineralogy-petrology/metamorphic-reactions]]中标志矿物与等变线如何被填图的方式；旋转台、以及如今由中子与 X 射线构造测角仪测量的优选方位函数，是[[geophysics/seismic-structure]]地震各向异性的输入；而索比第一次在薄片中看到的那些流体包裹体，是[[mineralogy-petrology/pt-paths]]中的测温与[[geochemistry/aqueous-geochemistry]]中古风流体化学的基础。

::: summary
- 突起是一个由 $|n_\text{mineral} - n_\text{medium}|$ 设定的边界效应；贝克线在调焦时进入折射率较高的介质。
- 各向异性的矿物把光分裂成两条成直角偏振的光线；光率体以 $n_\alpha \le n_\beta \le n_\gamma$ 为半轴，告诉你任一方向的光线会看到什么。
- 在正交偏光镜之间，一个颗粒的亮度与颜色只依赖于积 $\delta = t\,\Delta n$，在米歇尔–莱维图上读出；标准的 $30\ \mu\mathrm{m}$ 厚度把大多数造岩矿物放进前两级。
- 消光行为给出方位：平行、斜或对称消光，以及随成分系统地变化的消光角。
- 光性符号来自对一个试板的响应或来自一个干涉图；$2V$ 是中间折射率、因而也是成分的一个灵敏函数。
- 多色性是选择性吸收，干涉色是光程差，而突起是折射——三种不同的现象回答三个不同的问题。
- 这套方法的意义在结构：什么在什么之上生长，什么替换了什么，以及岩石朝哪个方向剪切。
:::

## 练习题

::: exercise 橄榄石的光程差 {level=1 check="1080"}
橄榄石 Fo$_{90}$ 有 $\Delta n = 0.036$。它在一个 $30\ \mu\mathrm{m}$ 薄片中的光程差是多少，以纳米计？
::: solution
$\delta = t\,\Delta n = 3.0\times10^{4}\times0.036 = 1080\ \mathrm{nm}$，这是二级下部的颜色——明亮，也是橄榄石在橄榄岩中容易挑出来的原因。
:::
:::

::: exercise 薄片的厚度 {level=1 check="76"}
一个石英颗粒（$\Delta n = 0.009$）显示二级蓝（$\delta \approx 680\ \mathrm{nm}$）而不是一级灰。薄片有多厚，以微米计？
::: solution
$t = \delta/\Delta n = 680/0.009 = 75\,600\ \mathrm{nm} \approx 76\ \mu\mathrm{m}$。这样厚的薄片对长石不可用，它们全都跑到高级去；标准是 $30\ \mu\mathrm{m}$，而检查的办法是看石英的干涉色，它应该是一级灰。（以微米计厚度，到最接近的微米。）
:::
:::

::: exercise 方解石的光性符号 {level=1 check="negative"}
方解石有 $n_\omega = 1.658$、$n_\varepsilon = 1.486$。它的光性符号与重折射率是多少？
::: solution
$n_\varepsilon < n_\omega$，所以方解石是**一轴晶负**的，而 $\Delta n = 1.658 - 1.486 = 0.172$，是任何常见造岩矿物中最大的。
:::
:::

::: exercise 是各向同性、还是只是薄？ {level=2}
一个颗粒在正交偏光镜之间的每一个方位都是消光的。列出各种可能性并说明如何判定。
::: solution
四种可能：(i) 一个立方矿物或一个玻璃——石榴石、白榴石、方钠石、黑曜岩；(ii) 在一个一轴晶矿物中垂直于一条光轴的切面，它也是消光的、但只在那一个方位；(iii) 一个不透明矿物，它在单偏光下也是黑的；(iv) 一个异常薄的、看起来各向同性的低重折射率矿物的颗粒。判定办法是 (a) 在单偏光下看——不透明的保持黑，透明的显示突起；(b) 移到同一个颗粒的邻近部分后转台——一个真正各向同性的矿物保持黑，一个锥晶切面变亮；(c) 锥光镜，各向同性的矿物给出一个暗视域，只有当它是变形的才给出一个居中的、看起来一轴晶的图。
:::
:::

::: exercise 从一个颜色求重折射率 {level=2 check="0.018"}
一个 $30\ \mu\mathrm{m}$ 的颗粒显示一级红，取 $\delta = 550\ \mathrm{nm}$。它的重折射率是多少？
::: solution
$\Delta n = \delta/t = 550/3\times10^{4} = 0.018$。小心这个歧义：一级红、二级红与三级红看起来相似，而真正的重折射率同样可能是 $0.018 + 0.037 = 0.055$（二级）或更高。石英楔解决它——楔推入时的颜色序列告诉你级次。
:::
:::

::: exercise 区分石英与方解石 {level=2}
两者都是无色的，两者都可以有双晶，而两者都出现在同一块大理岩中。给出分开它们的三个光学测试与一个化学测试。
::: solution
(1) **突起**：方解石 $n_\omega = 1.658$ 对着 $1.54$ 的介质给出中等突起；$1.544$ 的石英几乎看不见。(2) **重折射率**：方解石显示高级的珍珠灰与粉，石英一级灰。(3) **解理**：方解石有三个方向上完美的菱面体解理，表现为一个菱形的迹图案；石英没有解理而显示贝壳状断口。(4) **化学**：冷的稀盐酸与方解石剧烈起泡、与石英完全不反应——这个测试要在碎样或一块碎屑上做，绝不在薄片上做，因为酸会毁掉树胶。
:::
:::

::: exercise 消光角与成分 {level=2}
斜长石的消光角为什么有用，而在一个测量有任何意义之前，颗粒必须满足什么？
::: solution
一条给定结晶方向的迹与消光位之间的角随钙长石含量系统地变化，因为光率体的方位随钙钠比改变而相对于结晶轴旋转。所以它是在一个环带晶体上快速的光学成分估计。三个条件：颗粒必须按校准曲线所假定的方位切磨（垂直于 $\{010\}$ 或 $\{001\}$，视情形而定）；它必须在被测量的区域上是化学均一的，而一个环带晶体不是；它必须是无应变的，因为晶格的弯曲会把消光位抹开。在实践中这套方法至多给出 $\pm$An$_{10}$，而它的用法是看趋势、不是发表成分。
:::
:::

::: exercise 二轴晶符号 {level=2 check="positive"}
一个矿物有 $n_\alpha = 1.544$、$n_\beta = 1.550$、$n_\gamma = 1.553$、$2V_z = 50^\circ$。它的光性符号是什么？
::: solution
**正的。**只要 $2V_z < 90^\circ$，锐角等分线就是 $Z$，而这里 $2V_z = 50^\circ$。等价地说，$n_\beta$ 离 $n_\alpha$ 远比离 $n_\gamma$ 近（$0.006$ 对 $0.003$），这把锐角等分线放在 $Z$ 附近。如果 $2V_z$ 大于 $90^\circ$，锐角等分线就会是 $X$、而矿物是负的。
:::
:::

::: exercise 一个更薄的薄片 {level=3 check="125"}
一个矿物在标准的 $30\ \mu\mathrm{m}$ 薄片中显示一级灰（$\delta = 250\ \mathrm{nm}$）。同一块岩石的第二个薄片被意外磨到 $15\ \mu\mathrm{m}$。同一个颗粒方位现在的光程差是多少，以纳米计，而石英与长石的外观会发生什么？（以纳米输入 $\delta$。）
::: solution
光程差正比于厚度，所以 $\delta = 250\times15/30 = 125\ \mathrm{nm}$：一级淡灰，接近图的黑端。一切都变暗。石英与长石，在一个正常薄片中已经在 $\delta \approx 270\ \mathrm{nm}$，落到 $135\ \mathrm{nm}$，在灰色的背景上变得难以看见，双晶除外；高重折射率的矿物——橄榄石、方解石、金红石——仍然明亮，因为即使减半它们仍在图上几百纳米处。这就是薄片要做得尽可能接近 $30\ \mu\mathrm{m}$ 的原因，也是一个被抛光过头的薄片要按石英来评判的原因，它应该是一个清楚的一级灰、不是一块脏白。
:::
:::

::: exercise 用一个楔数级次 {level=3}
一个颗粒显示一个可能是一级、二级或三级红的颜色。描述一个石英楔如何解决它，以及在每种情形下你会看到什么。
::: solution
把楔以其慢方向平行于颗粒的一个振动方向插入并推入。如果颗粒的光程差与楔的**相加**，颜色朝图上*跑*：一级红变成二级蓝，然后绿，然后二级红，而颗粒反复地变亮变暗。如果它们**相减**，颜色朝图下*跑*：一级红穿过黄、灰、进入消光，然后在互补的序列中再次变亮。决定性的观察是颗粒先变**暗**（相减，所以颗粒的光程差小——一级）还是先变**亮、然后穿过更高的颜色**（相加）。一个一级红的颗粒在相减时几乎立刻消光，因为 $\delta = 550\ \mathrm{nm}$ 距零只有 $550\ \mathrm{nm}$；一个 $\delta \approx 1650\ \mathrm{nm}$ 的三级红颗粒要推进 $1650\ \mathrm{nm}$ 的楔才消光，而你在路上会看到十几次颜色变化。
:::
