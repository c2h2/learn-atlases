一块变质岩不记录它形成时的条件，因为不存在形成它的单一条件。它记录一系列事件，其中一些被冻结、一些被抹开，而岩石学家的任务是把它们抹平回去。两个事实使这成为可能。第一个是矿物分带生长，所以一颗几毫米大的石榴石变斑晶从它的核到边保存了这块岩石压力–温度历史的一部分。第二个是扩散是慢的、而在岩石冷却时停止，所以一个本该被压平的化学剖面并没有被压平，而扩散本来会做的与它实际做的之间的差别是一支时钟。

结果是**压力–温度–时间路径**，变质地质学的中心对象：不是"这块岩石在什么条件下形成"，而是"它取道地壳的哪条路线，多快，而什么驱动它"。

## 路径，与它们的形状

::: definition 压力–温度路径 {#def-ptpath}
一个**压力–温度路径**是单一岩石连续平衡条件画出的曲线，靠从同一个生长带或同一个组合同时取得一个压力的估计与一个温度的估计、并按共生顺序排列这些对而得到。一条路径是**顺时针的**，如果它先显示埋藏与加热、然后在高温下压力下降——地壳增厚随后伸展垮塌的签名。它是**逆时针的**，如果加热先于埋藏——一个后来被埋藏的浅部地壳被岩浆或流体驱动的加热的签名。一条在温度几乎恒定时压力下降的路径记录**靠剥蚀或伸展的折返**；一个在压力几乎恒定时温度下降的记录驱动过程停止后的**热松弛**。
:::

::: example 读一颗石榴石 {#ex-garnet-profile}
一个泥质片麻岩中一颗石榴石变斑晶，从核到边，显示 $X_{\mathrm{Mg}} = \mathrm{Mg}/(\mathrm{Mg}+\mathrm{Fe})$ 从 0.15 升到 0.30、$X_{\mathrm{Ca}}$ 从 0.10 降到 0.01，而包裹体组合从石英 + 绿泥石变为石英 + 十字石、变为石英 + 硅线石 + 钾长石。共生的黑云母从 $X_{\mathrm{Mg}} = 0.32$ 变到 $X_{\mathrm{Mg}} = 0.49$。用[[mineralogy-petrology/metamorphic-reactions]]的温度计解释这条路径。
::: solution
把三个信号一起读。

**钙陡峭地下降。**钙只在低级时容易进入石榴石；随着岩石变暖，基质中的斜长石变得更钠质的、而石榴石的钙活度下降。从 0.10 到 0.01 的下降是经典的进变签名、而排除任何后来的熔蚀事件，那会抬高边的钙。

**镁在两个相中一起上升。**石榴石 $X_{\mathrm{Mg}}$ 从 0.15 到 0.30、而黑云母 $X_{\mathrm{Mg}}$ 从 0.32 到 0.49，意味着整个岩石的铁镁比正在朝富镁的端元重新分配，而这在绿泥石分解、释放镁时发生。它也意味着两个相在生长期间保持平衡，而这正是授权使用温度计的东西。

**温度。**在核，$K_D = (0.85/0.15)/(0.68/0.32) = 5.667/2.125 = 2.67$，给出 $1166/T = \ln 2.67 + 0.410 = 1.391$、$T = 838\ \mathrm{K} = 565^\circ\mathrm{C}$。在边，$K_D = (0.70/0.30)/(0.51/0.49) = 2.333/1.041 = 2.24$，给出 $1166/T = \ln 2.24 + 0.410 = 1.217$、$T = 958\ \mathrm{K} = 685^\circ\mathrm{C}$。

所以这块岩石在它的石榴石生长期间被加热了约 $120\ \mathrm{K}$，从绿片岩相到高角闪岩相。压力来自钙与组合：核中的绿泥石意味着石榴石在低级、中等压力下生长，而边上的硅线石 + 钾长石 + 石英的组合意味着峰期在一个低到足以穿过白云母 + 石英 = 钾长石 + 硅线石 + 水的反应的压力。路径因此是**进变加热、带一个适度的压力下降**——埋藏随后是折返的开始，一条顺时针的路径被当场抓住。
:::
:::

::: warning 一条压力–温度路径不是一块岩石唯一的读法
这是这个主题中最深的结果，而它很少被这样教。英格兰与理查森在1977年表明，一块岩石中一组平衡的组合约束压力–温度空间的一个区域、不是一条曲线，而**许多不同的路径穿过那个区域**。两块有相同矿物组合的岩石能够完全遵循不同的历史。更糟的是，一条路径是"顺时针的"这个论证通常依赖于把一个来自一个反应的压力与一个来自另一个反应的温度配对、并假定两个反应记录同一个时刻——而没有热力学的原因说它们应当如此，因为一个可能强依赖压力、弱依赖温度、而另一个相反。

后果不是路径没有价值、而是它们必须被挣得。一条站得住的路径来自**在岩石精确的总体成分中的伪剖面模拟**、来自配对来自*同一个*矿物成分的压力与温度估计、以及来自一个组合处于平衡的论证。在一张空白的图上把一个气压计的点连到一个温度计的点上画出的路径是一个假说，而它四十年来一直被认为是错的。
:::

## 扩散、封闭与一个剖面的冻结

::: proposition 扩散长度 {#prop-diffusion}
一维扩散方程 $\partial C/\partial t = D\,\partial^2 C/\partial x^2$，对一个跨过一个平面的浓度的初始台阶，有解 $C = C_0 + \Delta C\,\mathrm{erf}(x/2\sqrt{Dt})$。一个剖面在时间 $t$ 内被抹去的距离因此是
$$
L \approx \sqrt{Dt},
$$
而因为大多数元素在大多数硅酸盐中的扩散系数按 $D = D_0 e^{-E/RT}$ 在 $900$ 到 $50\ ^\circ\mathrm{C}$ 之间下降十到二十个数量级，一个能够存活的剖面约束了岩石待在热中的时间。
:::

::: theorem 封闭温度 {#thm-closure}
一个矿物（半径 $a$）中的同位素或化学系统，以恒定的速率 $|\mathrm{d}T/\mathrm{d}t|$ 冷却，在**封闭温度**停止与它周围交换
$$
T_c = \frac{E}{R\,\ln\!\left(\dfrac{A R T_c^{2} D_0}{E\,a^{2}\,|\mathrm{d}T/\mathrm{d}t|}\right)} ,
$$
其中 $E$ 是扩散的活化能、$D_0$ 是频率因子、而 $A$ 是一个约三的几何常数。对冷却速率的对数求导给出有用的灵敏度
$$
\frac{\mathrm{d}T_c}{\mathrm{d}\ln|\mathrm{d}T/\mathrm{d}t|} = \frac{R T_c^{2}}{E},
$$
所以冷却速率十倍地增加把封闭温度抬高 $2.3\,R T_c^{2}/E$。
:::

::: proof
从一个冷却的球中扩散出去在 $D/a^2$ 超过冷却速率乘以 $D$ 对温度的灵敏度时是有效的、之后无效。把无量纲的"多德森数" $\alpha = E/(RT_c)$——活化能与热能的比——设定、并要求冷却期间总的扩散损失与颗粒中的量同阶，得到上面那个超越方程，而它有一个唯一的解，因为右边按对数的倒数变化。对灵敏度，取定义方程的对数，$E/T_c = R\ln(\cdots) - 2R\ln T_c + \text{const}$，对 $\ln|\mathrm{d}T/\mathrm{d}t|$ 求导，并注意 $R\ln(\cdots)$ 那一项恰好又是 $E/T_c$，所以首项相消、留下 $\mathrm{d}T_c/\mathrm{d}\ln|\mathrm{d}T/\mathrm{d}t| = RT_c^2/E$。
:::

::: example 角闪石的封闭温度 {#ex-tc}
角闪石中的钾–氩系统在 $10\ ^\circ\mathrm{C\,Myr^{-1}}$ 的冷却速率、$0.2\ \mathrm{mm}$ 的颗粒半径下约在 $500^\circ\mathrm{C}$ 封闭，活化能 $E = 263\ \mathrm{kJ\,mol^{-1}}$。估计一个以 $1000\ ^\circ\mathrm{C\,Myr^{-1}}$ 冷却的地区的封闭温度，以及一个以 $1\ ^\circ\mathrm{C\,Myr^{-1}}$ 冷却的。
::: solution
灵敏度是
$$
\frac{\mathrm{d}T_c}{\mathrm{d}\ln|\mathrm{d}T/\mathrm{d}t|} = \frac{R T_c^{2}}{E} = \frac{8.314\times773^{2}}{263\,000} = 18.9\ \mathrm{K}
$$
每 $e$ 倍，即每冷却速率的一个数量级 $2.303\times18.9 = 43.5\ \mathrm{K}$。冷却速率上 100 倍是两个数量级，所以
$$
1000\ ^\circ\mathrm{C\,Myr^{-1}}:\quad T_c \approx 500 + 87 = 587^\circ\mathrm{C};
\qquad
1\ ^\circ\mathrm{C\,Myr^{-1}}:\quad T_c \approx 500 - 87 = 413^\circ\mathrm{C}.
$$
两个后果在实践上重要。一个快速冷却的岩体的一个角闪石年龄定年的是一块比教科书数字所暗示的略热的岩石、而在一个接触变质晕中最多九十度。而一个缓慢冷却的造山带给出的年龄对被定年的冷却事件系统地太老——这就是造山作用的研究引用一个**年龄梯度**、不是一个年龄的原因，也是一组系统的封闭温度，从锆石铀–铅经过角闪石与黑云母到磷灰石裂变径迹，被一起用作一个**热年代计**、而不是单独使用的原因。

标准的封闭温度阶梯，对一个厘米级、以 $10\ ^\circ\mathrm{C\,Myr^{-1}}$ 冷却的岩石，大致是：锆石铀–铅 $900^\circ\mathrm{C}$ 以上，石榴石钐–钕约 $600^\circ\mathrm{C}$，角闪石钾–氩约 $500^\circ\mathrm{C}$，黑云母钾–氩约 $280^\circ\mathrm{C}$，锆石（铀–钍）/氦约 $180^\circ\mathrm{C}$，磷灰石裂变径迹约 $110^\circ\mathrm{C}$，磷灰石（铀–钍）/氦约 $70^\circ\mathrm{C}$。一块穿过它们全部的岩石保存七个不同的年龄，而它们之间的差别就是冷却的历史。
:::

## 从一个剖面求冷却速率

::: example 这块岩石热了多久？ {#ex-diffusion-clock}
一个半径 2 mm 的石榴石变斑晶有一个仍然陡峭的锰剖面——浓度在边上 $0.2\ \mathrm{mm}$ 内降到它核值的一半。石榴石中的锰在 $550^\circ\mathrm{C}$ 以 $D = 4\times10^{-14}\ \mathrm{m^2\,yr^{-1}}$ 扩散。石榴石停止生长之后，这块岩石能够在那个温度待多久？
::: solution
剖面会被抹去的扩散长度是 $L = \sqrt{Dt}$。设 $L = 0.2\ \mathrm{mm} = 2\times10^{-4}\ \mathrm{m}$，
$$
t = \frac{L^{2}}{D} = \frac{4\times10^{-8}}{4\times10^{-14}} = 10^{6}\ \mathrm{yr}.
$$
岩石因此在石榴石生长之后不能在 $550^\circ\mathrm{C}$ 待超过约一百万年，否则剖面会是它现在的两倍宽。如果石榴石的生长被定年为 400 Ma、而岩石在 380 Ma 冷却到 $550^\circ\mathrm{C}$ 以下，那个剖面是不可能的：两千万年、即使在那个工作温度的一小部分，也会把它抹掉。要么温度的估计太高，要么剖面是一个晚于加热的生长环带，要么石榴石是在冷却期间生长的。

这就是扩散时钟，而它是关于**变质岩石变热多快、变冷多快**为数不多的直接约束之一。经典的应用是苏格兰与纳米比亚的高温、低压地区，其中红柱石–硅线石的组合与未修改的扩散剖面一起要求岩石达到 $700^\circ\mathrm{C}$、而在一到两百万年内失去那些热——一个每百万年几百度的加热与冷却速率，远快于单靠传导能够给出的、而是一部分熔体与流体平流输热的证据。
:::
:::

::: example 从一个年龄–高程剖面求折返 {#ex-elevation}
沿一座山脉一侧的一条剖面的磷灰石裂变径迹年龄从 $500\ \mathrm{m}$ 处的 $2\ \mathrm{Myr}$ 线性增加到 $2500\ \mathrm{m}$ 处的 $10\ \mathrm{Myr}$。磷灰石裂变径迹的封闭温度是 $110^\circ\mathrm{C}$、而现在的表面温度是 $15^\circ\mathrm{C}$。求折返速率与平均的古地热梯度，并说明结果假定什么。
::: solution
如果等温线是水平的、而被剥蚀携带上来，岩石被移除的速率是高程差除以年龄差：
$$
\dot{E} = \frac{2500 - 500}{10 - 2} = \frac{2000\ \mathrm{m}}{8\ \mathrm{Myr}} = 250\ \mathrm{m\,Myr^{-1}} = 0.25\ \mathrm{mm\,yr^{-1}} .
$$
$110^\circ\mathrm{C}$ 等温线现在位于 $500\ \mathrm{m}$ 的地表、而 $8\ \mathrm{Myr}$ 前位于深 $2000\ \mathrm{m}$ 处，所以地表与那条等温线之间的古地热梯度是
$$
\frac{110 - 15}{2.0} = 48\ ^\circ\mathrm{C\,km^{-1}} ,
$$
用两点之间 $2.0\ \mathrm{km}$ 的平均深度。这大约是全球大陆平均的两倍，而它要么是一个真实的热异常——伸展、岩浆作用、或流体流动——要么是一个假象。

假定是有趣的部分。这个方法假定等温线是水平的，而在一条陡的山脉中它们不是：它们被穹起、而地形本身把年龄扭曲几公里。它假定一个恒定的折返速率，数据的线性支持这一点、但不证明。它假定一个 $110^\circ\mathrm{C}$ 的封闭温度，而那如[[#ex-tc]]中依赖冷却速率与颗粒大小。以及它假定没有断层把剖面叠置起来。在年龄对高程不是线性的地方，或暗示的梯度超过 $60\ ^\circ\mathrm{C\,km^{-1}}$ 的地方，正确的读法是这些假定中有一个失败了——通常是第一个。
:::
:::

## 超高压岩石与俯冲的速度

::: definition 超高压变质作用 {#def-uhp}
一块岩石是**超高压（UHP）**的，如果它含诊断的矿物或矿物反应、要求约 $2.6\ \mathrm{GPa}$ 以上的压力，即 $500^\circ\mathrm{C}$ 的石英–柯石英平衡。证据永远不是一个从矿物化学的计算、而是一个**结构的**：保存在石榴石内部的一个包裹体的柯石英或金刚石，一个异常高铝的绿辉石，或一个带镁硅酸盐结构的石榴石的榴辉岩。这样的岩石是被带到 90 公里以上深度、而送回地表的陆壳或岩石圈地幔的碎片——送回，因为它们现在在陆地上。
:::

::: example 一个板块必须多快回来？ {#ex-uhp-rate}
一个超高压的榴辉岩记录 $3.2\ \mathrm{GPa}$、$700^\circ\mathrm{C}$ 的峰、而它的石榴石钐–钕系统在 245 Ma 定年这个峰；一个角闪石钾–氩分析定年穿过 $500^\circ\mathrm{C}$ 在 235 Ma。估计折返速率与返回的路径，并解释为什么这个数字是惊人的。
::: solution
这块岩石从约 $105\ \mathrm{km}$ 的深度走到约 $18\ \mathrm{km}$（$500^\circ\mathrm{C}$ 在一个正常梯度下的深度、而蓝片岩到角闪岩转变的压力），用了 $10\ \mathrm{Myr}$：
$$
\dot{Z} = \frac{105 - 18}{10} \approx 9\ \mathrm{km\,Myr^{-1}} = 9\ \mathrm{mm\,yr^{-1}} .
$$
这比一个典型造山带的折返快一个数量级，而它快到足以是**一个浮力板块碎片的上升速率**、不是地表剥蚀的速率。路径是第二件惊人的事：这块岩石在 105 km 处是 $700^\circ\mathrm{C}$、在 18 km 处是 $500^\circ\mathrm{C}$，所以它在上升 90 公里时只冷却了 $200^\circ\mathrm{C}$。穿过 90 公里上升而不加热到环境的梯度意味着返回是**快速而冷的**、由浮力驱动——一个水化的、分异的大陆板块的密度低于它置换的幔——而不是靠剥蚀与热松弛那些远慢的过程。

超高压地区因此是岩石记录中陆壳俯冲、而它能够回来的最强证据。它们也是这个主题不能没有时间就做的原因：一条没有年龄的压力–温度路径是一条没有方向、没有速度的曲线。
:::
:::

::: quiz
一个地区给出角闪石钾–氩年龄 $420\ \mathrm{Ma}$、黑云母钾–氩年龄 $390\ \mathrm{Ma}$、而磷灰石裂变径迹年龄 $40\ \mathrm{Ma}$。最好的解释是什么？
- [ ] 两次造山运动，一次在 420 Ma、一次在 40 Ma，黑云母的年龄被扰动过。
- [x] 缓慢冷却穿过三个系统的封闭温度，从 420 Ma 的约 $500^\circ\mathrm{C}$ 到 40 Ma 的约 $110^\circ\mathrm{C}$。
- [ ] 这些岩石都是 420 Ma、而较年轻的年龄是分析的假象。
- [ ] 390 Ma 的快速冷却随后是 40 Ma 的再加热。
::: solution
这些年龄是一条冷却的路径、不是一份事件的清单。角闪石在接近 $500^\circ\mathrm{C}$ 封闭、黑云母接近 $280^\circ\mathrm{C}$、而磷灰石裂变径迹接近 $110^\circ\mathrm{C}$，所以三个年龄给出岩石穿过那些温度的时刻。从 500 到 $280^\circ\mathrm{C}$ 的冷却花了 30 Myr、而从 280 到 $110^\circ\mathrm{C}$ 花了 350 Myr，这是一条减速的冷却路径——深部地壳的快速折返，然后一个近于稳定的埋藏或缓慢剥蚀的长时期。40 Ma 的年龄记录最后、新近纪对几公里盖层的移除、不是一次造山运动。
:::
:::

::: history
一块变质岩记录一条路径、不是一个条件，这个想法来得很慢。约利与霍姆斯已经从热流的测量论证过一个地槽不能被一个单一的岩体加热，而蒂利1930年代的相图给出了组合的序列。现代的主题始于赫塔宁、随后是汤普森1950与1960年代对石榴石环带的工作，它们首先表明一个变斑晶保存它自己生长的一个化学记录，以及特纳、以及布朗在阿尔卑山的榴辉岩中认识到，一个单一晶体中的组合序列能够被读成一个共生。定量的仪器在1970年代从三个方向同时到来：多德森1973年的封闭温度方程，它把一个冷却速率变成一个温度、而使热年代学成为一个学科、不是一堆年龄的收集；以及格雷厄姆等人的扩散域模拟，它把剖面变成了时钟；还有在明尼苏达、剑桥与堪培拉的炉子里定标的交换温度计与气压计。挑衅来自英格兰与理查森1977年，他们证明压力–温度路径不被组合唯一确定，浇灭了一个十年的过度解释、而迫使这个领域走上伪剖面模拟的严格地基，也就是它今天占据的位置。超高压的革命，由1984年在西甘涅克地区发现柯石英、1989与1992年在哈萨克斯坦与大别山发现金刚石开启，然后提供了新的严格性必须解释的现象：下去九十公里、而回来的大陆。
:::

## 通向何处

使路径成为可能的那些反应的斜率在[[mineralogy-petrology/metamorphic-reactions]]中；矿物中扩散与溶液的热力学在[[geochemistry/reactions]]中；定年本身在[[geochemistry/geochronology]]中；记录同样变形的构造在[[structural-geology/shear-zones]]中；而一条造山带如何吸收它的热、如何失去它的质量在[[structural-geology/orogens]]中。

::: summary
- 一块岩石记录一条路径、不是一个点，而路径靠配对来自同一个矿物的同一个生长带的压力与温度估计建成。
- 石榴石是路径的一卷胶片：钙下降、镁上升在一条进变的轨迹上，而任何一个的反转记录一个不同的事件。
- 压力–温度路径不被组合唯一确定；英格兰与理查森的论证是这个主题最重要的告诫。
- 扩散按 $\sqrt{Dt}$ 抹去剖面，所以一个保存的剖面是对待在热中的时间的一个约束。
- 一个热年代学的日期是岩石穿过一个依赖颗粒大小与冷却速率的温度的时刻、不是一个事件的时刻。
- 一组具有不同封闭温度的系统给出一条冷却的路径；一个年龄–高程的剖面给出一个折返速率。
- 超高压岩石要求俯冲到 90 公里以上、以及每年厘米的返回速率，而只有浮力能够提供。
:::

## 练习题

::: exercise 扩散长度 {level=1 check="10"}
用 $D = 4\times10^{-14}\ \mathrm{m^2\,yr^{-1}}$，扩散抹去一个跨 $200\ \mu\mathrm{m}$ 的化学剖面要花多长时间？以 $10^5$ 年为单位给出你的答案。
::: solution
$t = L^2/D = (2\times10^{-4})^2/(4\times10^{-14}) = 4\times10^{-8}/4\times10^{-14} = 10^{6}$ 年，即 $10$ 个 $10^5$ 年。那个平方的杠杆是巨大的：在同样的温度一个 $2\ \mu\mathrm{m}$ 宽的剖面在人的一生中被抹去、而一个 $200\ \mu\mathrm{m}$ 宽的存活一百万年。细粒的岩石因此根本不保存任何环带、而变斑晶保存很多。
:::
:::

::: exercise 封闭的灵敏度 {level=1 check="43.5"}
对一个 $E = 263\ \mathrm{kJ\,mol^{-1}}$、在 $500^\circ\mathrm{C}$ 封闭的系统，冷却速率的一个数量级值多少开尔文？对同样的 $E$、在 $900^\circ\mathrm{C}$ 的封闭温度会是多少？
::: solution
$2.303\,RT_c^2/E = 2.303\times8.314\times773^2/263\,000 = 43.5\ \mathrm{K}$ 每数量级。在 $900^\circ\mathrm{C}$（1173 K）是 $2.303\times8.314\times1173^2/263\,000 = 96\ \mathrm{K}$。灵敏度按 $T_c^2$ 增长，这就是封闭最高的系统也是对假定的冷却速率最灵敏的、以及一个锆石年龄是一篇论文中最不稳健的温度学陈述、而一个磷灰石裂变径迹年龄是最稳健的原因。
:::
:::

::: exercise 哪支时钟 {level=1}
一个花岗岩给出锆石铀–铅年龄 420 Ma、黑云母钾–氩年龄 395 Ma。每一个定年什么？
::: solution
锆石铀–铅年龄定年**结晶**，因为锆石在 $900^\circ\mathrm{C}$ 以上封闭、远在一个花岗岩的固相线之上、而它的铀–铅系统在这些温度不被后来的冷却重置。黑云母钾–氩年龄定年**穿过约 $280^\circ\mathrm{C}$ 的冷却**，晚 2500 万年。这个差别是岩体与它的顶板冷却穿过 500 度所花的时间，而对一个大的岩体这完全正常、对一个小的则不是。
:::
:::

::: exercise 路径的几何 {level=2}
说明每一条路径是顺时针还是逆时针、并给出一个环境：(a) 压力升到 10 kbar、同时温度升到 $650^\circ\mathrm{C}$，然后压力降到 4 kbar、同时温度升到 $750^\circ\mathrm{C}$；(b) 温度在 2 kbar 升到 $700^\circ\mathrm{C}$、然后压力在 $650^\circ\mathrm{C}$ 升到 8 kbar。
::: solution
(a) **顺时针。**埋藏与加热到一个压力峰，然后减压、伴随持续的加热到一个晚于压力峰的温度峰。这是经典的碰撞路径：地壳增厚建造压力、而热晚到，来自增厚与来自岩浆作用，同时伸展的垮塌卸载这块岩石。(b) **逆时针。**先在浅部加热、然后埋藏。这是罕见而诊断的：它要求一个在载荷之前被移除的热源，而它在后来被埋进一个增生楔的、被幔源岩浆底侵的地区找到，也在一些裂离的边缘找到。
:::
:::

::: exercise 石榴石测温 {level=2 check="645"}
$X_{\mathrm{Mg}} = 0.22$ 的石榴石与 $X_{\mathrm{Mg}} = 0.40$ 的黑云母共生。用[[mineralogy-petrology/metamorphic-reactions]]的定标求以 $^\circ\mathrm{C}$ 计的温度。
::: solution
$K_D = (0.78/0.22)/(0.60/0.40) = 3.545/1.500 = 2.364$。于是 $1166/T = \ln 2.364 + 0.410 = 0.860 + 0.410 = 1.270$，所以 $T = 918\ \mathrm{K} = 645^\circ\mathrm{C}$。注意这与[[#ex-garnet-profile]]的 $565^\circ\mathrm{C}$ 相差多么少：石榴石的镁值上 $0.07$ 的变化值 $80\ \mathrm{K}$，这就是变质温度是由电子探针的剖面、不是由点位分析建成的原因。
:::
:::

::: exercise 非唯一性 {level=2}
给出两条能够产生同一个观察到的组合——石榴石 + 十字石 + 蓝晶石 + 白云母 + 石英——的不同压力–温度路径，并说明什么额外的观察能区分它们。
::: solution
**路径一：**进变的埋藏与加热穿过红柱石与十字石域进入蓝晶石域、达到 10 kbar、$600^\circ\mathrm{C}$、没有退变。**路径二：**埋藏到 11 kbar、$650^\circ\mathrm{C}$、进入蓝晶石域，随后减压到 6 kbar、$550^\circ\mathrm{C}$，在此期间十字石在返回穿过十字石域时以石榴石为代价生长。两者以同样五个相结束。

做出区分的观察是结构与化学的。如果十字石**交生**石榴石、而含蓝晶石的包裹体，十字石更年轻、而路径是退变的。如果十字石**被包在**石榴石中、而它自己的包裹体是石榴石，顺序就相反。石榴石核到边的成分剖面独立地解决它：一个进变的石榴石有下降的钙与上升的镁，而一个在减压期间生长的石榴石有一个成分由退变反应设定的边、而可能在两者中都显示一个反转。这就是变质岩岩石学从一片薄片、不是从一支温度计开始的原因。
:::
:::

::: exercise 折返速率 {level=2 check="2.7"}
一个超高压地区的含柯石英榴辉岩给出峰压年龄 150 Ma、角闪石氩年龄 120 Ma。取峰在 100 km、角闪石的封闭在 18 km，求平均的折返速率，以 $\mathrm{mm\,yr^{-1}}$ 计。
::: solution
$(100 - 18)/(150 - 120) = 82/30 = 2.7\ \mathrm{km\,Myr^{-1}} = 2.7\ \mathrm{mm\,yr^{-1}}$。按造山带的标准这是快的，但比[[#ex-uhp-rate]]的算例慢五倍，而它是更常见的数字：它与靠剥蚀与地壳尺度的伸展的折返相容、而不要求一个板块碎片的浮力返回。
:::
:::

::: exercise 部分保留带 {level=3}
磷灰石裂变径迹年龄在 1000 m 高程以下恒为 $60\ \mathrm{Ma}$、然后线性增加到 3000 m 处的 $180\ \mathrm{Ma}$。在 3000 m 以上恒为 $180\ \mathrm{Ma}$。解释，并说明两个平台意味着什么。
::: solution
这是一个**部分退火带**被一次单一的冷却或折返事件穿过的经典签名。在 1000 m 以下，岩石很久以前就穿过全退火的温度（约 $120^\circ\mathrm{C}$）之下、而年龄是 60 Ma 一个真实的冷却年龄。在 3000 m 以上，岩石从未超过部分退火的阈值（约 $60$–$70^\circ\mathrm{C}$）、而年龄定年最初的冷却，180 Ma。在中间，两条等温线在一次折返的事件中被穿过，而年龄随高程线性的增加给出速率：
$$
\dot{E} = \frac{3000 - 1000}{180 - 60} = 16.7\ \mathrm{m\,Myr^{-1}} = 0.017\ \mathrm{mm\,yr^{-1}} .
$$
这是非凡地慢——一个克拉通的边缘、不是一条山脉——而解释是一个被动边缘、在最后 1.2 亿年被折返了几公里。两个平台是这个方法工作的原因：它们界定这个带、而显示剖面的两端没有受到扰动。
:::
:::

::: exercise 推导封闭的灵敏度 {level=3}
从 $\mathrm{d}T_c/\mathrm{d}\ln|\mathrm{d}T/\mathrm{d}t| = RT_c^2/E$ 出发，积分得到 $T_c$ 作为冷却速率的函数，并对 $E = 263\ \mathrm{kJ\,mol^{-1}}$、从 $T_c = 500^\circ\mathrm{C}$ 起、在 $10$ 与 $1000\ ^\circ\mathrm{C\,Myr^{-1}}$ 之间求值结果。
::: solution
把 $E$ 当作恒定的、分离变量，
$$
\int_{T_1}^{T_2}\frac{\mathrm{d}T_c}{T_c^{2}} = \frac{R}{E}\int_{\dot T_1}^{\dot T_2}\mathrm{d}\ln\dot T
\quad\Longrightarrow\quad
\frac{1}{T_1} - \frac{1}{T_2} = \frac{R}{E}\ln\frac{\dot T_2}{\dot T_1}.
$$
$T_1 = 773\ \mathrm{K}$、$\dot T_2/\dot T_1 = 100$、$E = 263\,000\ \mathrm{J\,mol^{-1}}$：
$$
\frac{1}{T_2} = \frac{1}{773} - \frac{8.314\times4.605}{263\,000} = 1.294\times10^{-3} - 1.455\times10^{-4} = 1.148\times10^{-3},
$$
所以 $T_2 = 871\ \mathrm{K} = 598^\circ\mathrm{C}$。[[#ex-tc]]线性化的估计给出 $587^\circ\mathrm{C}$，一个 $11\ \mathrm{K}$ 的误差——可以接受，而这就是使用线性形式的原因。积分的形式对冷却速率的大变化更好，而它有一个有用的性质：$T_c$ 从不发散。当冷却速率趋于无穷，$1/T_c$ 趋于 $1/T_1 - (R/E)\ln(\dot T_2/\dot T_1)$、而它在一个有限的速率到达零。没有一个系统能够在它开放的温度之上被封闭。
:::
:::

::: exercise 整个历史 {level=3}
一个麻粒岩相的地区给出：锆石铀–铅年龄，岩浆核 1850 Ma、加大边 1820 Ma；石榴石钐–钕模式年龄 1815 Ma；角闪石氩年龄 1780 Ma；黑云母氩年龄 1700 Ma；而磷灰石裂变径迹年龄 350 Ma。重建这段历史并指出最弱的一环。
::: solution
**1850 Ma**——原岩结晶；岩浆的锆石核从源区继承、而定年最初的花岗岩。**1820 Ma**——一个变质的锆石加大边在麻粒岩相变质的峰期生长，而石榴石中 1815 Ma 的钐–钕模式年龄确认峰期的组合是同一个年龄，这是一个强的内部检验，因为两个系统在相似的温度封闭、而化学上独立。**1780 Ma**——穿过 $500^\circ\mathrm{C}$ 的冷却，在峰期之后 4000 万年：按克拉通的标准是快的、而要求快速的折返或一个大的热流。**1700 Ma**——穿过 $280^\circ\mathrm{C}$ 的冷却，平均 $30\ ^\circ\mathrm{C\,Myr^{-1}}$；麻粒岩变成了一个中地壳的角闪岩、然后一个绿片岩。**350 Ma**——最后几公里盖层最终的移除，在一次古生代的造山运动或一个相邻盆地的打开期间，它把岩石重新加热到恰好足以退火氩的径迹。

最弱的一环是 **1700 Ma 的黑云母年龄**。黑云母是常见钾–氩系统中最容易被扰动的：它细粒，它是最可能被后来的流体退变的相、而它的氩在即使温和的变形期间沿颗粒边界丢失。在一个下一个最年轻的年龄是 350 Ma 的地区一个 1700 Ma 的黑云母年龄是一个 13.5 亿年的缺口，而通常的解释不是十亿年的静止、而是一次未被认识的部分重置。检验是对黑云母做阶梯加热、寻找一个混合的释放模式，以及用石榴石中的钙同位素方法定年同一块岩石，它对流体免疫。
:::
