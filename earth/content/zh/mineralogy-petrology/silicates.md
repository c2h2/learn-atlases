百分之九十的大陆地壳，以及它下面几乎全部的地幔，都由一个结构单元构成：一个硅原子被四个氧包围。就这一个排布，以及它的角可以被共享的寥寥几种方式，解释了蛇绿岩中的橄榄岩、使一片云母片岩裂开的云母、你浴室瓷砖中的长石、保持你花园水分的高岭土、海滩中的石英，以及榴辉岩中的石榴石。地壳中其余的一切——碳酸盐、氧化物、硫化物与蒸发岩——要么是一个次要的相、要么是一个化学沉积。

原因是化学的一个巧合。硅是小的、四价的，所以它偏好四个邻居；氧是行星外层最丰富的阴离子；而 $\mathrm{SiO_4}$ 基团稳定到它从地幔到海底基本上完好无损地保存下来。变化的不是四面体、是*连接*：每个氧是属于一个四面体、还是被两个共享，以及还剩下哪些别的阳离子来平衡由此产生的电荷。跟随这一个想法，整个硅酸盐矿物学就变成一个单一的连续的论证、而不是一份清单。

## 四面体，以及它为什么聚合

::: definition 硅氧四面体 {#def-tetrahedron}
**硅氧四面体**是络离子 $\mathrm{SiO_4}^{4-}$：一个 $\mathrm{Si}^{4+}$ 阳离子在四个 $\mathrm{O}^{2-}$ 阴离子构成的一个正四面体的中心。它的 Si–O 键长是 $0.162\ \mathrm{nm}$，它的 O–Si–O 角接近理想的 $109.5^\circ$，而它的键约 $45\%$ 是共价的、$55\%$ 是离子的。每个氧在取走硅四个正电荷中的一个之后携带一个 $-1$ 的剩余电荷，所以一个孤立的四面体在硅上有一个 $4 - 4\times 2 = 0$ 的净电荷、加上分布在四个氧上的 $-4$：$\mathrm{SiO_4}^{4-}$。
:::

两个数字解释随后的一切。半径比 $r_{\mathrm{Si}^{4+}}/r_{\mathrm{O}^{2-}} = 0.026/0.138 = 0.19$ 恰好*低于*在[[mineralogy-petrology/crystal-chemistry]]中导出的四配位极限 $0.225$：按纯静电的论证硅应该是三配位的，而它不是。键是 $45\%$ 共价的，而共价性是有方向的、偏好四个等价的 $sp^3$ 轨道——这就是硅在地壳与上地幔的压力下是四配位的、而只在约 $8\ \mathrm{GPa}$ 之上、当密度取胜时，它才变成六配位的原因。而 Si–O 键能，约 $640\ \mathrm{kJ\,mol^{-1}}$，远大于大多数竞争的阳离子-氧对的键能。硅因此与其说是在争夺氧，不如说是*抓住*它已经拥有的。

但一个孤立的 $\mathrm{SiO_4}^{4-}$ 基团在静电上是难受的：四个未共享的（"非桥"）氧各携带一个完整的 $-1$ 电荷，而鲍林第二定律说，一个阴离子上这样大的剩余键强使结构不稳定、易反应。补救的办法是把氧与另一个硅共享。当两个四面体共享一个角时，两个硅各向那个氧贡献 $+1$ 的键强，所以剩余电荷从 $-1$ 降到 $0$、而结构变得稳定得多。这就是**聚合**，而它是整个大类组织的原理。

::: definition 桥氧与非桥氧 {#def-nbo}
被两个四面体阳离子共享的一个氧是一个**桥氧**（bo）；只与一个键合的是一个**非桥氧**（nbo）。一个硅酸盐熔体或矿物的**聚合程度**通常由这个比表示
$$
\mathrm{NBO/T} = \frac{\text{非桥氧的数目}}{\text{四面体阳离子的数目（T = Si, Al}^{3+}, \mathrm{Fe}^{3+})},
$$
它对孤立的四面体取 $4$、对一个完全聚合的架状结构取 $0$。
:::

::: proposition 氧硅比与结构类别 {#prop-os-ratio}
如果每个四面体共享它四个角中的 $s$ 个，那么每个硅的氧数为
$$
\frac{\mathrm{O}}{\mathrm{Si}} = 4 - \frac{s}{2},
$$
而每个硅的阴离子电荷为 $2(\mathrm{O/Si}) - 4 = 4 - s$ 个负电荷。七个结构类别因此直接从 $s$ 跟着来：
| $s$ | O/Si | 每 Si 电荷 | 类别 | 例子 |
|---|---|---|---|---|
| 0 | 4.00 | $-4$ | 岛状硅酸盐（孤立） | 橄榄石 $\mathrm{Mg_2SiO_4}$ |
| 1 | 3.50 | $-3$ | 组状硅酸盐（对） | 绿帘石族 |
| 2，环 | 3.00 | $-2$ | 环状硅酸盐（环） | 绿柱石 $\mathrm{Be_3Al_2Si_6O_{18}}$ |
| 2，链 | 3.00 | $-2$ | 单链链状硅酸盐 | 辉石 $\mathrm{MgSiO_3}$ |
| 4，共享2 | 2.75 | $-1.5$ | 双链链状硅酸盐 | 角闪石 $\mathrm{Mg_7Si_8O_{22}(OH)_2}$ |
| 3 | 2.50 | $-1$ | 层状硅酸盐（层） | 滑石 $\mathrm{Mg_3Si_4O_{10}(OH)_2}$ |
| 4 | 2.00 | 0 | 架状硅酸盐（架） | 石英 $\mathrm{SiO_2}$ |
:::

::: proof
每个四面体贡献四个氧，而每个共享的角被两个四面体数到，所以 $s$ 个共享的角每个四面体贡献 $s/2$ 个氧、总共 $4 - s/2$ 个氧属于它。电荷由离子电荷之和跟着来：硅四个键的 $4(+1)$ 不是正确的记账——改为数每个氧 $-2$ 的阴离子电荷与每个硅 $+4$ 的阳离子电荷，得 $-2(4 - s/2) + 4 = s - 4$，即每个硅 $4 - s$ 个负电荷。对一条链，$s = 2$、比是 $\mathrm{O/Si} = 3$、每个硅的电荷是 $-2$，这就是辉石有阴离子基团 $[\mathrm{SiO_3}]^{2-}_\infty$、而每个硅需要两个一价或一个二价的架外阳离子的原因。对一层，$s = 3$、$\mathrm{O/Si} = 2.5$、基团是 $[\mathrm{Si_2O_5}]^{2-}$，这就是云母与高岭土携带一个永久的负电荷、而交换阳离子的原因。对架状结构，$s = 4$、$\mathrm{O/Si} = 2$、电荷为零——纯的 $\mathrm{SiO_2}$，完全不需要任何别的阳离子。
:::

::: example 从四面体到一个化学式：辉石与角闪石 {#ex-chain-formula}
由它们的四面体排布推导一个单斜辉石与一个透闪石角闪石的理想化学式。
::: solution
在一个**辉石**中，每个四面体把它四个角中的两个与同样两个邻居共享，沿 $c$ 形成一条单链。$s = 2$、$\mathrm{O/Si} = 3$、每个硅的电荷是 $-2$，所以链的阴离子是 $[\mathrm{SiO_3}]^{2-}$、而每个硅一个 $\mathrm{Mg}^{2+}$ 平衡它：$\mathrm{MgSiO_3}$，顽火辉石。

在一个**角闪石**中链是加双的：在一条带内一些四面体共享两个角、一些共享三个，在八个硅的一个重复中比例为 4:4。平均是 $s = (4\times2 + 4\times3)/8 = 2.5$，所以 $\mathrm{O/Si} = 4 - 1.25 = 2.75$、每个硅的电荷是 $-1.5$。八个硅因此携带 $-12$ 个电荷。它们被三个八面体位点中的五个 $\mathrm{Mg}^{2+}$（$+10$）、较大 A 位点中的两个 $\mathrm{Ca}^{2+}$（$+4$）与两个羟基（$-2$）平衡：$\mathrm{Ca_2Mg_5Si_8O_{22}(OH)_2}$，透闪石。直接检验电荷：$2(2) + 5(2) + 8(4) = 46$ 个正的，对抗 $22\times2 + 2 = 46$ 个负的。检验氧的计数：$8\times2.75 = 22$，与化学式中完全一致。
:::
:::

::: quiz
一个硅酸盐矿物被发现 $\mathrm{O/Si} = 2.5$、并携带一个永久的负层电荷。它的结构类别是
- [ ] 岛状硅酸盐
- [ ] 链状硅酸盐
- [x] 层状硅酸盐
- [ ] 架状硅酸盐
::: solution
每个四面体 $s = 4 - 2 \times (4 - 2.5) = 3$ 个共享的角，这是层状结构。只有一层留下每个四面体一个未共享的氧、因而一个永久的电荷——高岭土与云母是这个大类中交换能力强、含水、滑的那一端的原因。岛状硅酸盐有 $\mathrm{O/Si} = 4$，链状硅酸盐 $3.0$ 或 $2.75$，而架状结构恰好 $2.0$、完全没有电荷。
:::

## 孤立的基团：岛状硅酸盐

橄榄石族，$\mathrm{M_2SiO_4}$，是原型：孤立的四面体由两个畸变的八面体位点 M1 与 M2 中的 $\mathrm{Mg}^{2+}$ 与 $\mathrm{Fe}^{2+}$ 维系在一起。因为四面体不必彼此共享角，除了电中性之外，结构没有任何要求去容纳架外阳离子的某个特定大小或电荷，而橄榄石因此形成一个完整的 $\mathrm{Mg_2SiO_4}$–$\mathrm{Fe_2SiO_4}$ 类质同象系列（镁橄榄石–铁橄榄石），以及与 $\mathrm{Mn_2SiO_4}$（锰橄榄石）与 $\mathrm{Ca_2SiO_4}$（镁硅钙石组分）一个有限的系列。

后果在手标本上就看得见。角共享的孤立四面体不给强度一个偏好方向，所以橄榄石没有解理、而贝壳状断裂；结构是致密的（镁橄榄石 $\rho = 3.2$–$3.4\ \mathrm{g\,cm^{-3}}$）而硬的（6.5–7）；而空的八面体使它成为地幔中镁与一半相容元素的主要储库。橄榄石在它含硅位点上的羟基缺陷 $[\mathrm{H_4O_4}]^{4-}$ 时也是地幔水的主要仓库，多达约 $1\ \mathrm{wt}\%$——过渡带中好几个大洋的量。

别的岛状硅酸盐是铝硅酸盐多晶型物与石榴石。$\mathrm{Al_2SiO_5}$ 产出为红柱石、蓝晶石与硅线石，全都有一个四配位的 $\mathrm{Si}^{4+}$、而铝被不同地打包——红柱石中五与六配位、致密的蓝晶石中只有六配位、硅线石中一半被强迫进四配位；它们的稳定域是变质级经典的压力–温度指标。石榴石，$\mathrm{X_3Y_2(SiO_4)_3}$，有孤立的四面体加上八配位的十二面体 X 位点（Ca、Mg、Fe、Mn）与八面体 Y 位点（Al、Cr、Fe），而它完整的类质同象系列——镁铝榴石、铁铝榴石、钙铝榴石、钙铁榴石、钙铬榴石、镁铬榴石——使它成为变质岩岩石学中最有信息的单一矿物。

::: example 石榴石端元与电荷平衡 {#ex-garnet}
写出六个常见的石榴石端元并证明每一个是电中性的。然后计算一个阳离子化学式为 $\mathrm{Ca_{1.20}Mg_{0.55}Fe^{2+}_{0.78}Al_{1.92}Fe^{3+}_{0.10}Si_{2.96}O_{12}}$ 的石榴石的摩尔比例。
::: solution
一般的化学式是 $\mathrm{X_3Y_2Z_3O_{12}}$，X 八配位、Y 六配位、Z 四配位。镁铝榴石 $\mathrm{Mg_3Al_2Si_3O_{12}}$：$3(2) + 2(3) + 3(4) = 6 + 6 + 12 = 24 = 12\times2$。铁铝榴石 $\mathrm{Fe_3Al_2Si_3O_{12}}$ 与钙铝榴石 $\mathrm{Ca_3Al_2Si_3O_{12}}$ 完全相同地平衡，因为 $\mathrm{Ca}$ 与 $\mathrm{Fe}^{2+}$ 在十二面体位点中都是二价的、而 $\mathrm{Al}$ 在 Y 中是三价的。钙铁榴石 $\mathrm{Ca_3Fe^{3+}_2Si_3O_{12}}$ 把铁移到 Y、而需要钙来保持电荷：$3(2) + 2(3) + 3(4) = 24$。钙铬榴石 $\mathrm{Ca_3Cr_2Si_3O_{12}}$ 与镁铬榴石 $\mathrm{Mg_3Cr_2Si_3O_{12}}$ 遵循同一条规则，而富钛与富铁的金伯利岩石榴石加上 $\mathrm{Ti^{4+}}$、配以 $\mathrm{Ca^{2+} + Si^{4+} \longrightarrow Na^{+} + Al^{3+}}$ 型的耦合替代方案，使总数保持在 24。

对那个分析，归一化到十二个氧（已经做了）与到三个 X、两个 Y 阳离子。X 总计 $1.20 + 0.55 + 0.78 = 2.53$、Y 总计 $1.92 + 0.10 = 2.02$，所以位点的占据接近满的。摩尔比例因此是镁铝榴石 $0.55/3 = 18\%$、铁铝榴石 $0.78/3 = 26\%$、钙铝榴石 $1.20/3 = 40\%$，而把 Y 上的三价铁与钙一起取，钙铁榴石 $0.10/2 = 5\%$；剩下 $11\%$ 是一个真实的分析总是携带的电荷平衡的松弛量，这里主要是一点 Mg–Fe 在位点之间的错配。
:::
:::

## 环、链与带：链状与环状硅酸盐

每个四面体共享两个角产生一个一维的物体，而结构于是有一个强的内部方向：平行于链的解理，沿 $c$ 的高正突起，以及各向异性。两种排布是可能的、而都很常见。

**单链**，$[\mathrm{SiO_3}]^{2-}_\infty$，是辉石。链坐在两条八面体阳离子的带之间，而两种八面体位点（M1 与 M2）允许一个宽泛的化学：$\mathrm{Mg}$、$\mathrm{Fe}^{2+}$、$\mathrm{Ca}$、$\mathrm{Na}$、$\mathrm{Al}$（后者既在八面体位点中、也在辉石 $\mathrm{NaAlSi_2O_6}$ 的四配位位点中）。辉石四边形顽火辉石–透辉石–钙铁辉石–铁辉石组织常见的这些；普通辉石，玄武岩的钙铝单斜辉石，是一个四或五组分的类质同象。辉石在非常接近 $93^\circ$ 与 $87^\circ$ 处解理，这在薄片上是把它们与角闪石分开的诊断特征。

**双链**，$[\mathrm{Si_4O_{11}}]^{6-}_\infty$，是角闪石，而双链中间那条额外的八面体位点带能够容纳 $\mathrm{OH}^{-}$，所以角闪石是含水的。透闪石–阳起石 $\mathrm{Ca_2(Mg,Fe)_5Si_8O_{22}(OH)_2}$ 与普通角闪石是常见的；普通角闪石以 $\mathrm{Al^{IV}}$ 替代 Si、以及 Ti、Na 与 K 的替代，使它成为一个它从中结晶的岩浆的含水量与温度的灵敏记录者。角闪石的解理在 $56^\circ$ 与 $124^\circ$ 相交。

**环**，$[\mathrm{Si_6O_{18}}]^{12-}$，是环状硅酸盐：绿柱石 $\mathrm{Be_3Al_2Si_6O_{18}}$、电气石（化学上是地壳中最复杂的矿物，报道多达 25 种元素），以及堇青石 $\mathrm{Mg_2Al_4Si_5Al_{(1)}O_{18}}$，它的环容纳使它各向异性的客体分子。六元环是绿柱石形成六方柱、而祖母绿的铬色完全可能的原因。

::: example 一个环中的电荷平衡 {#ex-tourmaline}
验证绿柱石 $\mathrm{Be_3Al_2Si_6O_{18}}$ 是电中性的，并说明铍与铝在那里做什么。然后算出如果环中一个 $\mathrm{Si}^{4+}$ 被 $\mathrm{Al}^{3+}$ 替代，环的电荷会怎样。
::: solution
绿柱石含六元环 $[\mathrm{Si_6O_{18}}]$。每个四面体 $s = 2$ 个共享的角，每个硅的电荷是 $-2$，所以环携带 $6\times(-2) = -12$、是 $[\mathrm{Si_6O_{18}}]^{12-}$。它外面的阳离子供给 $3\times\mathrm{Be}^{2+} = +6$ 与 $2\times\mathrm{Al}^{3+} = +6$，总计恰好 $+12$。直接的计数一致：$3(2) + 2(3) + 6(4) = 36$ 个正电荷对抗 $18\times2 = 36$ 个负的。

现在在四面体位点上用一个 $\mathrm{Al}^{3+}$ 替代一个 $\mathrm{Si}^{4+}$。环变成 $[\mathrm{AlSi_5O_{18}}]^{13-}$：它变得*更不*负一个单位，因为铝只给一个原本贡献四个的位置带来三个正电荷。结构中别的东西因此必须失去一个正电荷——通常靠让一个八面体或通道位点空着，或靠把一个质子取到一个邻近的氧上。这一个观察就是富铝的环硅酸盐（堇青石、莫来石、磷酸铝）有那样奇特的、部分空置的结构、而不是绿柱石的简单替代版本的原因。

关于绿柱石还要注意的另一件事是它的通道容纳什么。六元环沿 $c$ 堆叠，留下窄的隧道，容纳中性的 $\mathrm{H_2O}$ 与 $\mathrm{CO_2}$ 分子。因为那些客体不携带电荷，它们完全不进入记账：绿柱石中的"水"不是羟基，而失去它意味着打破环，这就是绿柱石在薄片中看起来是无水的、而只在很高的温度才脱水的原因。
:::

## 层：层状硅酸盐

共享三个角，你得到一个二维的阴离子，$[\mathrm{Si_2O_5}]^{2-}$，一个由六元环构成的无限层，每个四面体第四个未共享的氧指向同一个方向。仅此一个几何事实就解释了云母、高岭土、绿泥石、滑石、蛇纹石与蒙脱石的每一个性质：层堆叠起来，它们彼此只由弱的阳离子或范德华力维系，所以这些矿物完全解理、摸起来滑、能弯、而单位质量有很高的表面积。

单独一层是不稳定的，因为未共享的氧各携带 $-1$。它因此总是在一侧与一个八面体的层键合——一个**四面体（T）层**加上一个**八面体（O）层**——而两者合成一个**总四面体层**。如果八面体层被占据三分之二（被 $\mathrm{Al}^{3+}$ 或 $\mathrm{Fe}^{3+}$），它是**二八面体型**的（2:1 层状硅酸盐，如白云母）；如果被二价阳离子完全占据，它是**三八面体型**的（滑石、金云母、蛇纹石）。堆叠给出各个族：

- **1:1 层**（一个 T，一个 O），由顶氧与对层羟基之间的氢键维系在一起：高岭石族，以及蛇纹石。没有层间阳离子，除了边缘之外没有交换能力。
- **2:1 层**（T–O–T），第四个氧在两侧朝外、而层与层之间有一个层间空间。那个空间容纳 $\mathrm{K}^{+}$、$\mathrm{Na}^{+}$、$\mathrm{Ca}^{2+}$ 与水，而它使 2:1 的高岭土膨胀、交换。

一个 2:1 层的电荷来自层**内部的类质同象替代**——四面体层中 $\mathrm{Si}^{4+}$ 位置的 $\mathrm{Al}^{3+}$，或八面体层中 $\mathrm{Al}^{3+}$ 位置的 $\mathrm{Mg}^{2+}$——而它是永久的，不像依赖于 pH 的边缘电荷。**阳离子交换能力**（CEC）是实用的度量，以 $\mathrm{cmol_c\,kg^{-1}}$ 计：滑石 0（没有替代），伊利石 20–40，蒙脱石 80–150，蛭石 100–150。这些数字是一公顷蒙脱石质的土壤保持高岭石质土壤十倍植物可利用养分的原因，也是膨润土被用作垃圾填埋场衬里与钻井泥浆的原因。

::: example 层电荷与阳离子交换能力 {#ex-cec}
一个蒙脱石有理想成分 $\mathrm{Na_{0.4}Al_2(Si_{3.6}Al_{0.4})O_{10}(OH)_2}$。求每个化学式单位的层电荷与理论 CEC，以 $\mathrm{cmol_c\,kg^{-1}}$ 计，取化学式量为 $791\ \mathrm{g\,mol^{-1}}$。
::: solution
四面体层在每个化学式单位中含 $0.4$ 的 $\mathrm{Al}^{3+}$ 替代 $\mathrm{Si}^{4+}$，这移走 $0.4$ 个正电荷；八面体层被 $\mathrm{Al}^{3+}$ 完全占据、不贡献什么。层电荷因此是每个化学式单位 $-0.4$，由层间 $0.4$ 的 $\mathrm{Na}^{+}$ 平衡——与化学式一致。

一摩尔的层交换 $0.4$ 摩尔的一价阳离子，即每 $791\ \mathrm{g}$ 有 $0.4\times100 = 40\ \mathrm{cmol_c}$：
$$
\mathrm{CEC} = \frac{40}{0.791} = 51\ \mathrm{cmol_c\,kg^{-1}} .
$$
天然的蒙脱石达到 80–150，因为它们从八面体的替代（$\mathrm{Mg}$ 替代 $\mathrm{Al}$）与从边缘位点携带额外的电荷；理想的计算给出下限、不是上限。还要注意这个数字物理上意味着什么：$51\ \mathrm{cmol_c\,kg^{-1}}$ 是每 $100\ \mathrm{g}$ 有 $0.51$ 个电荷，或者说每 390 个层的化学式单位有一个可交换的阳离子。
:::
:::

::: warning 高岭土不只是"细粒的矿物"
把高岭土当作一个粒级术语是诱人的，因为高岭土主导泥。它们不是：一个高岭土是一个**结构类别**，一个具有层状结构的层状硅酸盐，而粒度是一个后果、不是定义。这个区别在实践上重要，因为层状结构正是给出表面电荷、持水能力、膨胀、可塑性与污染物吸附的东西——这些是一个细的石英粉砂没有的性质，无论它的颗粒多小。
:::

## 架：架状硅酸盐与铝的替代

共享全部四个角，电荷就消失：$\mathrm{SiO_2}$，不需要别的东西。石英、鳞石英、方石英、柯石英与斯石英是纯硅石的多晶型物，而它们的序列——1 bar 下石英在 $870^\circ\mathrm{C}$ 以下、鳞石英到 $1470^\circ\mathrm{C}$、方石英在其上、柯石英在约 $2.6\ \mathrm{GPa}$ 以上、斯石英在 $8\ \mathrm{GPa}$ 以上——是地质学中最干净的压力–温度记录之一，被用来识别撞击构造与俯冲的地壳。斯石英是证明规则的那个例外：在 $8\ \mathrm{GPa}$ 之上硅放弃四配位、取六配位，而结构变成金红石式的，$\mathrm{O/Si} = 2$ 而完全没有四面体。

架状结构在铝进入四配位位点的那一刻就变得化学上有趣。$\mathrm{Al}^{3+}$  readily 替代 $\mathrm{Si}^{4+}$，尽管四配位的香农半径相差百分之五十（$0.039$ 对 $0.026\ \mathrm{nm}$），因为键主要是共价的、而架在铝周围局部地松弛。每一次替代在架上留下一个负电荷，必须由一个架外阳离子平衡，通常是 $\mathrm{Na}^{+}$、$\mathrm{K}^{+}$ 或 $\mathrm{Ca}^{2+}$：
$$
\mathrm{NaAlSi_3O_8},\quad \mathrm{KAlSi_3O_8},\quad \mathrm{CaAl_2Si_2O_8}.
$$
这些是长石，而它们是大陆地壳中最丰富的矿物——约其中的 $60\%$。三个端元定义长石的三元溶隙，而富钠的长石析出钾长石的片晶（条纹长石）、或反之（反条纹长石）的出溶结构记录穿过溶隙的冷却路径，这就是一个长石能够同时是一支温度计与一个速度计的原因。

两条规则支配铝去哪里。**洛文斯坦（铝硅规避）规则**说，相对于 $\mathrm{Si–O–Si}$ 与 $\mathrm{Si–O–Al}$，$\mathrm{Al–O–Al}$ 的连接被强烈规避，所以只要有空间，铝就从铝有序地排开。而**戈尔德施密特替代**要求架的电荷在局部被平衡，这就是碱长石与斜长石有这样窄的、定义良好的成分、而不是一个简单的混合模型预言的连续范围的原因。

如果没有足够的硅可分——也就是说，如果比 $\mathrm{Al}/(\mathrm{Al} + \mathrm{Si})$ 超过 $0.5$——架就不能只由四面体建成，而代之以形成**似长石**：霞石 $\mathrm{NaAlSiO_4}$、白榴石 $\mathrm{KAlSi_2O_6}$、方钠石、方柱石。似长石是一个硅*不饱和*熔体的矿物签名，而它们在一熔岩中的存在与否是岩石学家判定的第一件事，因为它决定整个分类。

::: example 从一个全岩分析求硅饱和度 {#ex-saturation}
两个玄武岩有下面的分子比例（氧化物的摩尔数，由一个 wt% 分析得出，$\mathrm{FeO}$、$\mathrm{MgO}$、$\mathrm{TiO_2}$ 与 $\mathrm{P_2O_5}$ 过剩）。判定哪一个是硅不饱和的，用一个简化的标准矿物规则：$\mathrm{Ca}$、$\mathrm{Na}$ 与 $\mathrm{K}$ 按钙长石 $\mathrm{CaAl_2Si_2O_8}$、钠长石 $\mathrm{NaAlSi_3O_8}$、钾长石 $\mathrm{KAlSi_3O_8}$ 的顺序取铝与硅，而任何硅的短缺靠把钠长石转成霞石 $\mathrm{NaAlSiO_4}$ 来满足。

| 氧化物 | 玄武岩 A | 玄武岩 B |
|---|---|---|
| $\mathrm{SiO_2}$ | 1.000 | 0.500 |
| $\mathrm{Al_2O_3}$（作为 $\mathrm{Al}$） | 0.300 | 0.300 |
| $\mathrm{CaO}$ | 0.080 | 0.050 |
| $\mathrm{Na_2O}$ | 0.030 | 0.140 |
| $\mathrm{K_2O}$ | 0.010 | 0.020 |
::: solution
**玄武岩 A。**长石需要铝 $2(0.080) + 0.030 + 0.010 = 0.200$、硅 $2(0.080) + 3(0.030) + 3(0.010) = 0.280$。两者都有，剩下 $0.100$ 的铝与 $0.720$ 的硅。剩余的硅变成标准矿物石英，而剩余的铝只有在超过长石与过剩相所能取的量时才进入刚玉。玄武岩 A 因此是**硅饱和到过饱和的**：含石英的，像一个拉斑玄武岩应该的那样。

**玄武岩 B。**长石需要铝 $2(0.050) + 0.140 + 0.020 = 0.260$——有的——而硅 $2(0.050) + 3(0.140) + 3(0.020) = 0.580$。只存在 $0.500$，短缺 $0.080$。把一摩尔钠长石转成一摩尔霞石节省两摩尔的硅，所以 $0.040$ 的钠形成霞石、$0.100$ 形成钠长石。重新计算：用掉的硅 $= 0.100 + 0.300 + 0.060 + 0.040 = 0.500$，恰好是供给，而用掉的铝 $= 0.100 + 0.100 + 0.020 + 0.040 = 0.260$，在供给之内。

玄武岩 B 因此是**硅不饱和的**、而会在标准矿物中有 $0.040$ 摩尔的霞石——在岩石中，是模式的霞石或白榴石，而它必须被分类为一个霞石岩或碧玄岩、不是一个玄武岩。实际的教训是检验不是"硅多不多"，而是"硅够不够从全部的碱与钙建造长石"，而一个硅只有邻居一半的岩石可以是那个长似长石的。
:::

## 熔体：同样的化学，无序的

一个硅酸盐**熔体**是同样的四面体化学、而长程有序被毁灭，而它的性质由同样的聚合程度支配。网络**形成体**（$\mathrm{Si^{4+}}$、$\mathrm{Al^{3+}}$、$\mathrm{Ti^{4+}}$、$\mathrm{P^{5+}}$）建造四面体；网络**修饰体**（$\mathrm{Na}^{+}$、$\mathrm{K}^{+}$、$\mathrm{Ca}^{2+}$、$\mathrm{Mg}^{2+}$、$\mathrm{Fe}^{2+}$）打破桥、制造非桥氧；而四配位的 $\mathrm{Al}^{3+}$ 是一个中间体、需要一个电荷平衡的修饰体。后果是火山学中最重要的单一物理性质：

$$
\eta = \eta_0 \exp\!\left(\frac{E_a}{RT}\right),
$$

而 $E_a$ 本身是 NBO/T 的一个强函数。玄武质的熔体（$\mathrm{NBO/T} \approx 0.5$）在 $1200^\circ\mathrm{C}$ 有 $10$–$100\ \mathrm{Pa\,s}$ 的粘度；安山质的熔体约 $10^{3}$；流纹质的熔体（$\mathrm{NBO/T} \approx 0.05$）在 $800^\circ\mathrm{C}$ 有 $10^{5}$–$10^{7}\ \mathrm{Pa\,s}$。这是一百万的跨度，而它解释了为什么基拉韦厄的熔岩成河流动、而蒙特塞拉特的岩柱崩塌。

::: example 粘度、温度与喷发方式 {#ex-viscosity}
一个干的流纹质熔体粘滞流动的活化能约 $E_a = 500\ \mathrm{kJ\,mol^{-1}}$、而它在 $800^\circ\mathrm{C}$ 的粘度是 $10^{6}\ \mathrm{Pa\,s}$。求 $750^\circ\mathrm{C}$ 与 $900^\circ\mathrm{C}$ 的粘度。然后对一个 $E_a = 250\ \mathrm{kJ\,mol^{-1}}$、$1200^\circ\mathrm{C}$ 时 $100\ \mathrm{Pa\,s}$ 的玄武岩做同样的事。
::: solution
用 $\eta(T_2) = \eta(T_1)\exp[E_a R^{-1}(1/T_2 - 1/T_1)]$、$R = 8.314\ \mathrm{J\,mol^{-1}\,K^{-1}}$：

流纹岩，$800 \to 750\ ^\circ\mathrm{C}$（$1073 \to 1023\ \mathrm{K}$）：$E_a/R = 60\,140\ \mathrm{K}$、$1/1023 - 1/1073 = 4.55\times10^{-5}\ \mathrm{K^{-1}}$，所以
$$
\eta = 10^{6}\times e^{2.74} = 1.6\times10^{7}\ \mathrm{Pa\,s}.
$$
对 $800 \to 900\ ^\circ\mathrm{C}$，指数是 $-2.27$、$\eta = 1.0\times10^{5}\ \mathrm{Pa\,s}$：$100\ \mathrm{K}$ 的变化把粘度移动十六倍。

玄武岩，$1200 \to 1150\ ^\circ\mathrm{C}$（$1473 \to 1423\ \mathrm{K}$）：$E_a/R = 30\,070\ \mathrm{K}$、$1/1423 - 1/1473 = 2.38\times10^{-5}$，给出 $\eta = 100\times e^{0.716} = 205\ \mathrm{Pa\,s}$——两倍。同样 $50\ \mathrm{K}$ 的冷却把一个玄武岩的粘度改变两倍、一个流纹岩的改变四倍，而两个熔体之间的绝对差别是四到五个数量级。关于喷发方式的一切——溢流还是爆发，一条 $10$-km 的熔岩流还是一根 $200$-m 的岩脊，气泡上升与逃逸的能力——都从这些数字跟着来。
:::
:::

::: history
阿羽伊在1784年从方解石解理碎块的形状导出它的菱面体，并在1801年的《矿物学论》中提出所有晶体都由一个重复的"组成微粒"构成——单位晶胞，比 X 射线早一个世纪。贝采里乌斯引入了使离子化学式成为可能的电化学二元论，并与他的学生米歇尔利希在1819年发现了**类质同象**：$\mathrm{KH_2PO_4}$ 与 $\mathrm{KH_2AsO_4}$ 完全相同地结晶，而一个给定的结构类型容忍化学上相似的阳离子。米歇尔利希定律是本章每一个类质同象系列的直接祖先。结构的解释只随 X 射线衍射而来：布拉格在1913年解出了金刚石的结构，而威廉·布拉格与劳伦斯·布拉格，随后是鲍林与戈尔德施密特，把衍射图变成了上面使用的四面体与规则。鲍林1929年的五条规则是本章能够从头到尾用静电论证的原因。现代的综述——这里使用的按聚合状态的分类——在1930年代由蒂利、鲍林的相平衡学派，以及对于云母、由格里姆及其同事的粉晶衍射工作确定下来。
:::

## 通向何处

四面体与它的连接在图谱后面到处重现。聚合度控制熔体的粘度、因而控制喷发方式，在[[physical-geology/volcanoes]]中；微量元素在四配位与八面体位点之间的分配是[[geochemistry/trace-elements]]中微量元素地球化学的基础；地幔中橄榄石–尖晶石–硅酸盐尖晶石的转变是在[[geophysics/seismic-structure]]中读出的地震不连续面；长石风化成高岭土是[[geochemistry/weathering-chemistry]]的主题；而[[mineralogy-petrology/phase-diagrams]]的全部就是这些结构中的哪一个在给定的温度与压力下稳定的问题。

::: summary
- 每一个硅酸盐都由 $\mathrm{SiO_4}^{4-}$ 四面体建成；类别由它的角共享了几个跟着来，而氧硅比对 $s$ 个共享的角是 $4 - s/2$。
- 每个硅的电荷是 $4 - s$：孤立的四面体 $-4$，链与环 $-2$，层 $-1$、架 $0$。架不需要别的阳离子；其余一切都需要。
- 岛状硅酸盐（橄榄石、石榴石、$\mathrm{Al_2SiO_5}$）没有解理、结构致密而硬；链状硅酸盐沿链在 $93^\circ/87^\circ$（辉石）或 $56^\circ/124^\circ$（角闪石）解理；层状硅酸盐完全解理，因为它们的层键合得弱。
- 层的电荷来自层内部的类质同象替代、而表现为阳离子交换能力，从滑石的 0 到蒙脱石的 150——高岭土支配土壤肥力与污染物迁移的原因。
- $\mathrm{Al}^{3+}$ 在架中替代 $\mathrm{Si}^{4+}$，而由此产生的电荷由 $\mathrm{Na}$、$\mathrm{K}$ 与 $\mathrm{Ca}$ 平衡：长石，大陆地壳的 60%。硅太少，就代之以形成似长石。
- 熔体遵循同样的化学：NBO/T 在玄武岩与流纹岩之间把粘度控制五个数量级，因而控制喷发方式。
:::

## 练习题

::: exercise 氧的比例 {level=1 check="2.5"}
一个层状硅酸盐的层的氧硅比是多少？
::: solution
$s = 3$ 个共享的角，所以 $\mathrm{O/Si} = 4 - 3/2 = 2.5$，给出层的阴离子 $[\mathrm{Si_2O_5}]^{2-}$。
:::
:::

::: exercise 一个环的电荷 {level=1 check="-12"}
求六元环阴离子 $[\mathrm{Si_6O_{18}}]^{n-}$ 的电荷。给出 $n$（带它的符号）。
::: solution
环中每个硅共享两个角，所以每个硅的电荷是 $-2$、而环携带 $6\times(-2) = -12$：$[\mathrm{Si_6O_{18}}]^{12-}$。在绿柱石中这由三个 $\mathrm{Be}^{2+}$ 与两个 $\mathrm{Al}^{3+}$ 平衡，它们一起恰好供给 $+12$。
:::
:::

::: exercise 从一个阳离子比求橄榄石的化学式 {level=1 check="72"}
一个橄榄石按摩尔有 $\mathrm{Mg}/(\mathrm{Mg} + \mathrm{Fe}) = 0.72$。它的镁橄榄石百分比是多少？
::: solution
镁橄榄石的含量按定义是 $100\times\mathrm{Mg}/(\mathrm{Mg} + \mathrm{Fe}) = 72\%$，所以这个橄榄石是 Fo 72，一个典型的地幔或邦尼尼岩的成分。
:::
:::

::: exercise 辉石的电荷平衡 {level=2 check="2"}
透辉石是 $\mathrm{CaMgSi_2O_6}$。它每个四面体有几个共享的角，你怎么知道的？
::: solution
$\mathrm{O/Si} = 6/2 = 3$，所以 $s = 2(4 - 3) = 2$：一条单链。电荷的检验确认它：两个 $\mathrm{Si}^{4+}$ 给 $+8$，$\mathrm{Ca}$ 与 $\mathrm{Mg}$ 给 $+4$，总计 $+12$，对抗六个氧的 $-12$。链 $[\mathrm{Si_2O_6}]^{4-}$ 每两个硅需要 $+4$，恰好一个 $\mathrm{Ca}^{2+}$ 与一个 $\mathrm{Mg}^{2+}$。
:::
:::

::: exercise 白云母的层电荷 {level=2 check="1"}
白云母是 $\mathrm{KAl_2(AlSi_3)O_{10}(OH)_2}$。每个化学式单位的层电荷是多少，钾为什么在那里？
::: solution
每个化学式单位有一个 $\mathrm{Al}^{3+}$ 占据一个四配位的位点，比它替代的 $\mathrm{Si}^{4+}$ 差一个完整的负电荷，所以 2:1 层携带 $-1$。层间的 $\mathrm{K}^{+}$ 平衡它——这就是白云母在正常条件下没有交换能力、而钾只被缓慢释放给植物的原因，靠的是整层的、而不是交换的风化。
:::
:::

::: exercise 一个蒙脱石的阳离子交换能力 {level=2 check="117"}
一个铁皂石有理想的化学式 $\mathrm{Na_{0.9}Fe^{3+}_{1.66}\Box_{0.17}(Al_{0.1}Si_{3.9})O_{10}(OH)_2}$（$\Box$ 是一个空位）、化学式量 $767\ \mathrm{g\,mol^{-1}}$。计算它理论的 CEC，以 $\mathrm{cmol_c\,kg^{-1}}$ 计。（以 $\mathrm{cmol_c\,kg^{-1}}$ 输入 CEC。）
::: solution
电荷的两个来源。$0.1$ 的 $\mathrm{Al}^{3+}$ 对 $\mathrm{Si}^{4+}$ 的四配位替代贡献 $-0.1$。八面体层持有 $1.66$ 的 $\mathrm{Fe}^{3+}$、而一个满的层持有 $2$，所以 $0.17$ 个空位各移走 $+3$，贡献 $-0.51$；但层也比一个满的 $\mathrm{Fe}^{3+}_2$ 层将供给的 $+6$ 差 $0.34$ 个电荷，而层间必须平衡的亏缺是总的负电荷，$0.1 + 0.51 = 0.61$。化学式的 $0.9$ 的钠因此部分是电荷平衡的、部分是在边缘位点可交换的；把每个化学式单位 $0.9$ 个电荷的结构层电荷取作可交换的量，
$$
\mathrm{CEC} = \frac{0.9\times100}{0.767} = 117\ \mathrm{cmol_c\,kg^{-1}} .
$$
这在蒙脱石范围（80–150）的顶部，正如一个富铁的、高度替代的层所预期的。注意这个计算暴露的含糊：一个真实的高岭土引用的 CEC 取决于八面体空位的电荷——它只部分可接近——是否被计入，而不同的手册以不同的方式计入它。
:::

::: exercise 角闪石对辉石 {level=2}
证明双链阴离子 $[\mathrm{Si_8O_{22}}]^{12-}$ 与 $s = 2.5$ 一致，并解释为什么角闪石是含水的、而辉石不是。
::: solution
$s = 2.5$ 时 $\mathrm{O/Si} = 4 - 1.25 = 2.75$、$8\times2.75 = 22$ 个氧，正如要求的；电荷是 $8\times(4 - 2.5)\times(-1) = -12$，与 $[\mathrm{Si_8O_{22}}]^{12-}$ 相符。角闪石是含水的，因为加双的链围住一条八面体位点的带，其中心的阴离子位置，在八面体带的中心，不能被氧占据而不遭受来自邻近非桥氧的不合理的静电排斥：$\mathrm{OH}^{-}$，它的质子指向沿 $c$ 的空通道，是那里唯一可行的阴离子。辉石的单链没有这样一个位点，所以辉石基本上是无水的。
:::
:::

::: exercise 似长石还是长石？ {level=2 check="0.5"}
四配位位点中 $\mathrm{Al}/(\mathrm{Al} + \mathrm{Si})$ 的什么值标出了架状长石不能再被建造的理论极限？
::: solution
$0.5$。在那个比下每个四面体都将是铝、而架将处处需要 $\mathrm{Al–O–Al}$ 的连接，违反洛文斯坦规则、而耗尽电荷平衡的阳离子；结构坍缩到更密的似长石排布（霞石、白榴石），其中一些氧变成非桥的。
:::
:::

::: exercise 两个温度的熔体 {level=3 check="1.3"}
一个干的安山质熔体在 $1050^\circ\mathrm{C}$ 有 $\eta = 10^{4}\ \mathrm{Pa\,s}$、$E_a = 400\ \mathrm{kJ\,mol^{-1}}$。冷却到 $950^\circ\mathrm{C}$ 时它的粘度改变多少倍？给出这个倍的 $\log_{10}$，保留一位小数。
::: solution
$E_a/R = 4.00\times10^{5}/8.314 = 48\,110\ \mathrm{K}$，而
$$
\frac{1}{1223} - \frac{1}{1323} = 8.18\times10^{-5} - 7.56\times10^{-5} = 6.22\times10^{-5}\ \mathrm{K^{-1}} .
$$
指数是 $48\,110\times6.22\times10^{-5} = 2.99$，所以粘度上升 $e^{2.99} = 19.9$ 倍，而这个倍的 $\log_{10}$ 是 $1.3$。$100\ \mathrm{K}$ 二十倍，是一个冷却的熔岩流的硬壳能够封闭一个喷口、一个脱气的安山岩能够在通道中停下、而同一个火山能够随着它通道中的内容物冷却一两度从溢流转为爆发的原因。
:::

::: exercise 推导一个层的化学式 {level=3}
从一个 2:1 层的几何推导滑石的化学式，取一个三八面体的层、没有类质同象替代。
::: solution
取一个四配位层中的四个硅。$s = 3$ 时它们携带 $4\times2.5 = 10$ 个氧：六个层内相邻四面体之间共享的底氧，与四个指出层外的顶氧。两个这样的层构成 $\mathrm{Si_8O_{20}}$，有八个顶氧可用于键合它们之间的八面体层。

一个三八面体的层有每个重复中三个八面体位点全被占据，所以它对每四个顶氧持有三个二价阳离子、加上外表面上的羟基。把八个顶氧配给两个八面体的重复给出六个 $\mathrm{Mg}$，而层的两个外表面携带四个 $\mathrm{OH}^{-}$。除以二得

$$
\mathrm{Mg_3Si_4O_{10}(OH)_2},
$$

即滑石。电荷检验：$3\times2 + 4\times4 = 22$ 个正的，对抗 $10\times2 + 2\times1 = 22$ 个负的。层因此是电中性的，不需要层间的阳离子，而只被范德华力维系到它的邻居——这正是滑石硬度为 1、摸起来滑、而化学上几乎惰性原因。在那个结构中任何地方用 $\mathrm{Al}^{3+}$ 替代 $\mathrm{Si}^{4+}$，层就不再是中性：你造出了一个云母或一个蒙脱石，带一个层间阳离子与一个交换能力。
:::

::: exercise 石榴石作为气压计 {level=3 check="0.015"}
铁铝榴石与镁铝榴石之间的铁镁交换有 $\Delta V_r = -1.25\ \mathrm{cm^3\,mol^{-1}}$ 的体积变化、而在相关的温度上熵变接近零。在 $700^\circ\mathrm{C}$，平衡的 $\ln K$ 在 5 与 15 kbar 之间移动多少？（给出 $\Delta\ln K$，保留三位小数。）
::: solution
$\Delta S_r \approx 0$ 时，平衡常数的压力依赖是
$$
\left(\frac{\partial \ln K}{\partial P}\right)_T = -\frac{\Delta V_r}{RT}.
$$
用 $R = 83.14\ \mathrm{cm^3\,bar\,mol^{-1}\,K^{-1}}$ 使单位相消，在 $T = 973\ \mathrm{K}$、$\Delta P = 10\ \mathrm{kbar} = 10^4\ \mathrm{bar}$ 时，
$$
\Delta\ln K = \frac{1.25\times10^{4}}{83.14\times973} = 0.015 .
$$
一个很小的移动，而它正是石榴石作为气压计被使用的方式：一个负的 $\Delta V_r$ 意味着压力偏好富铁铝榴石的端元，所以随压力上升、镁在共生的橄榄石中升高、而铁在石榴石中升高。这个反应在 $700^\circ\mathrm{C}$ 每 10 kbar 只移动 $0.015$ 的 $\ln K$，这就是为什么石榴石–二辉石气压计需要严格的温度控制、而石榴石–橄榄石铁镁交换气压计在低温下几乎不可用的原因。
:::
