一块变质岩是一个不再存在的环境的记录。它的矿物在固态、在深处、在岩石此后已经往回穿过的压力与温度下生长，而它们既保存它们生长的条件、也——如果它们运气好——保存两者之间的路径。整个学科建立在上一章确立的单一事实上：对一个给定的总体成分，一个给定的压力与温度允许恰好一个平衡的组合，而那个组合可以从岩石中读出。变质岩岩石学因此是一次解码的练习，而使它成为可能的反应有两种——那些以相反的方式依赖压力与温度的，给出坐标轴的；以及那些只依赖其中一个的，给出定标的。

## 相、等值线与指标矿物

::: definition 变质作用、原岩与相 {#def-metamorphism}
**变质作用**是一块岩石在固态下的矿物学与结构的变化，由压力、温度与流体成分的变化驱动，在低于它熔融的条件、低于成岩的范围的条件下。原来的岩石是**原岩**。一个**变质相**是能够从给定压力与温度范围内任何成分的原岩形成的一组组合；相与相之间的边界因此是 $P$–$T$ 空间中的反应面、不是任意的线。一个**相系**是一个地区沿一条进变路径穿过的一系列相，而它命名大地构造的环境：布尚系是热的、低压的，阿武隈系是极热的、极低压的，巴罗系是中等的，三叶川系是冷的、高压的。
:::

::: definition 等值线、指标矿物与带 {#def-isograd}
一条**等值线**是变质地区中一个特定的矿物在一个特定的总体成分中首次出现的那个面；两条等值线之间的区域是一个**带**，而定义它的矿物是**指标矿物**。等值线是反应面，所以它们是三维的、与它们的宿主一起被褶皱，而——关键的是——它们在不同总体成分的岩石中出现在不同的位置。泥质岩中的巴罗序列，从低级到高级，是**绿泥石、黑云母、石榴石、十字石、蓝晶石、硅线石**，而它仍然是任何巴罗地区标准的野外划分。
:::

::: warning 一条等值线不是一条温度的等高线
把石榴石的首次出现读作一条 $500^\circ\mathrm{C}$ 的等温线是诱人的。它不是。一条等值线是一个反应的迹线，而一个反应依赖压力、依赖水的活度、依赖岩石的总体成分、以及依赖岩石是否真的达到了平衡。在实践中，一个泥质岩中的石榴石等值线与一个相邻的变基性岩中的阳起石–角闪石等值线不重合，因为它们是不同斜率的不同反应；而在一个快速隆起的地区，等值线系统地低于相所暗示的温度，因为岩石没有时间赶上。等值线绘制的是*岩石的*历史，不是地区的温度。
:::

## 要紧的那些反应

::: example 铝硅酸盐的三相点 {#ex-alsiv}
$\mathrm{Al_2SiO_5}$ 的三个多晶型物——红柱石、蓝晶石与硅线石——定义了地质学中最著名的单变图。三相点在约 $501^\circ\mathrm{C}$、$3.83\ \mathrm{kbar}$，而三条单变曲线从它辐射出去，每一条有约十巴每开尔文的斜率。勾画这张图并读出三条路径。
::: solution
$$
\text{andalusite} \rightleftharpoons \text{kyanite} \rightleftharpoons \text{sillimanite}
$$
红柱石占据低压的角，蓝晶石高压的角，硅线石高温的角。蓝晶石是最密的多晶型物，摩尔体积 $45.0\ \mathrm{cm^3}$、对抗红柱石的 $51.5$ 与硅线石的 $50.2$，而相律在任何一个压力与温度只允许它们之一稳定。

三条路径，三个环境。一条**低压、高温**的路径——接触变质晕、伸展的地区、布尚或阿武隈相——穿过红柱石–硅线石边界、给出红柱石然后硅线石，蓝晶石从不出现。一条**巴罗**路径在红柱石域中开始、在更高的级上穿入硅线石，同样没有蓝晶石。一条**俯冲带**的路径进入蓝晶石域，而如果它足够暖，它随后可能在榴辉岩相的顶部穿入硅线石。在一个变质地区中找到蓝晶石因此意味着这块岩石达到了比红柱石域所允许的多了几吉巴的压力——在 $500^\circ\mathrm{C}$ 约 $6\ \mathrm{kbar}$ 之上、在蓝片岩相的温度约 $10\ \mathrm{kbar}$ 之上——无论它后来的历史如何。找到红柱石与硅线石在一起、没有蓝晶石、也没有任何种类的残晶，意味着它从来没有。

因为三条边界的斜率都只有约十巴每开尔文，一条在加热路径上穿过的边界记录一个温度远比记录一个压力更锐利：一个 $50\ \mathrm{K}$ 的不确定性把压力的估计移动半个吉巴，而同样半个吉巴的不确定性只把温度的估计移动 $50\ \mathrm{K}$。
:::
:::

::: example 证明等值线就是反应的三条等值线 {#ex-three-isograds}
在三叶川带与舒克山带，变基性岩中的三条等值线——绿纤石–斜黝帘石等值线（LCC）、钠长石–绿帘石–石英等值线（AZO）与钙长石–绿帘石等值线（AO）——在几十公里上彼此落在几百米之内，在像绿片岩与角闪岩这样不同的岩类中，而它们出现在经历过 4 到 12 kbar 压力的地区的同一构造层位。这对反应要求什么？
::: solution
它要求三条反应都有一个**非常大的 $\mathrm{d}P/\mathrm{d}T$**，所以在一张压力–温度图上它们是近乎竖直的线、而无论压力如何它们基本上在同一个温度出现。而那就是它们所拥有的：LCC、AZO 与 AO 是净转移反应，其中体积变化 $\Delta V$ 与熵变 $\Delta S$ 都非常小、而恰好给出一个极小的比 $\Delta S/\Delta V$——一个几百巴每开尔文的斜率。三条因此在蓝片岩与角闪岩相整个压力范围的、彼此几十度之内，接近 $450$–$500^\circ\mathrm{C}$。

这个观察在历史上是决定性的。如果等值线仅仅是一个矿物在某种一般意义上变得稳定的那些等高线，它们就不会在变化的岩性与变化的压力上三维地重合。它们确实重合，这是它们是平衡的反应面、而变质岩确实记录平衡的条件直接的野外证明。推论是一个有用的工具：一个含绿纤石的变基性岩无论它达到什么压力都在约 $500^\circ\mathrm{C}$ 之下，而一个含斜黝帘石、没有绿纤石的在其上。这一对是一支在任何矿物化学都太细粒的岩石中工作的温度计。
:::
:::

::: example 脱碳酸作用与流体缓冲 {#ex-dqf}
在低压下不纯的含泥白云石灰岩中，反应
$$
2\,\mathrm{dolomite} + \mathrm{quartz} \longrightarrow \mathrm{forsterite} + 2\,\mathrm{calcite} + 2\,\mathrm{CO_2}
$$
（DQF 反应）对流体的成分有一个强的依赖。在 $700^\circ\mathrm{C}$、1 kbar，它与一个含约 60% $\mathrm{CO_2}$ 的流体平衡。一块含橄榄石 + 方解石 + 无 $\mathrm{CO_2}$ 流体的岩石告诉你什么，而为什么大理岩是这样好的流体活动的记录者？
::: solution
这个反应是一个**流体成分的缓冲**。如果穿过岩石的流体比平衡值更富 $\mathrm{CO_2}$，反应向左运行、靠造出白云石消耗二氧化碳；如果它更富水，反应向右运行、释放二氧化碳直到平衡的比恢复。一个这个总体成分的岩石因此不能记录流体原来的成分、只能记录被缓冲的那个——而这正是它记录了一个更好的东西的原因：流体流过了这个事实，以及朝哪个方向。

大理岩是通道化的流体活动最好的自然记录者，因为脱碳酸反应大量释放 $\mathrm{CO_2}$、而对流体的 $\mathrm{CO_2}$ 活度极其灵敏。一条几米宽的含橄榄石大理岩，被没有反应的白云石 + 石英大理岩包围，意味着一条富水的流体被聚焦穿过那条通道、而反应到底；反应带的宽度除以总的通量，给出岩石对那种流体的渗透率。在同一段地层几公里都未反应的地方，渗透率是可以忽略的、而变质流体完全在别处移动。
:::
:::

::: quiz
一个泥质岩含被硅线石交生的红柱石、而在任何阶段都没有蓝晶石。它记录什么？
- [ ] 埋藏到 10 kbar 以上然后折返。
- [x] 在低压下加热，全程在约 4 kbar 以下。
- [ ] 沿一条俯冲路径加热并同时加压。
- [ ] 这块岩石从未达到平衡，所以什么也推不出来。
::: solution
红柱石然后硅线石、完全没有蓝晶石——甚至不是一个残晶核——意味着这块岩石全程待在蓝晶石域的低压一侧，也就是约 4 kbar 以下，而它的温度穿过红柱石–硅线石边界上升。这是布尚或阿武隈地区经典的低压、高温路径，而它与俯冲或碰撞埋藏的路径相反。
:::
:::

## 温度计与气压计

::: definition 交换反应与分配系数 {#def-exchange}
一个**交换反应**在两个相之间用一个阳离子换另一个、而不改变任何组分的摩尔数：
$$
\mathrm{Mg_3Al_2Si_3O_{12}} + \mathrm{Fe\text{-}biotite} \rightleftharpoons \mathrm{Fe_3Al_2Si_3O_{12}} + \mathrm{Mg\text{-}biotite}.
$$
因为反应不涉及气体分子数目的变化、而只涉及一个小的体积变化，它的平衡常数依赖温度、而只弱弱地依赖压力——这就是使它成为一支温度计的东西。测量的量是**分配系数**
$$
K_D^{\mathrm{Fe\text{-}Mg}} = \frac{(\mathrm{Fe}/\mathrm{Mg})^{\text{garnet}}}{(\mathrm{Fe}/\mathrm{Mg})^{\text{biotite}}} .
$$
:::

::: example 石榴石–黑云母温度计 {#ex-gtbi}
石榴石–黑云母交换温度计一个简化的定标，拟合到上面反应实验与天然的资料，是
$$
\ln K_D^{\mathrm{Fe\text{-}Mg}} = \frac{1166}{T} - 0.410 ,
$$
$T$ 以开尔文计。一个泥质片麻岩的石榴石有 $X_{\mathrm{Mg}} = 0.25$、而共生的黑云母有 $X_{\mathrm{Mg}} = 0.42$。求峰期变质的温度，并估计每个分析中 $0.02$ 的误差的效应。
::: solution
$$
(\mathrm{Fe}/\mathrm{Mg})^{\text{gt}} = \frac{0.75}{0.25} = 3.00, \qquad
(\mathrm{Fe}/\mathrm{Mg})^{\text{bi}} = \frac{0.58}{0.42} = 1.381, \qquad
K_D = \frac{3.00}{1.381} = 2.17 .
$$
于是
$$
\frac{1166}{T} = \ln 2.17 + 0.410 = 0.776 + 0.410 = 1.186
\quad\Longrightarrow\quad
T = 983\ \mathrm{K} = 710^\circ\mathrm{C},
$$
这是高角闪岩相，与一个含硅线石的泥质岩一致。

对误差，求微分：$\mathrm{d}T/T = -\mathrm{d}(\ln K_D)\,T/1166$，所以石榴石 $X_{\mathrm{Mg}}$ 上 $\pm 0.02$ 的误差把 $\ln K_D$ 改变约 $0.02/0.25 = 0.08$、而把温度改变
$$
\Delta T \approx \frac{0.08\times983}{1166} = 67\ \mathrm{K}.
$$
两个这样的误差、同方向，给出 $130\ \mathrm{K}$。这是单个石榴石–黑云母对的温度诚实的精度，也是发表的变质温度被以最接近的 $10\ \mathrm{K}$ 引用、而应当以最接近的 $50\ \mathrm{K}$ 阅读的原因。系统的误差——黑云母中的三价铁、石榴石的钙含量、以及冷却期间的再平衡——还要大，这就是最好的研究报道一张石榴石核到边的剖面网格对黑云母、而不是一个单一数字的原因。
:::
:::

::: proposition 净转移反应作为气压计 {#prop-barometer}
一个**净转移反应**改变每个相的摩尔数、而通常有一个大的 $\Delta V$。由克劳修斯–克拉珀龙关系
$$
\frac{\mathrm{d}P}{\mathrm{d}T} = \frac{\Delta S}{\Delta V},
$$
这样一个反应在 $\Delta V$ 大而 $\Delta S$ 适中时有一个陡的正斜率，而它的平衡因此强依赖压力。两个例子锚定变质的压力标尺：
$$
\mathrm{albite} \rightleftharpoons \mathrm{jadeite} + \mathrm{quartz}, \qquad
\mathrm{plagioclase} + \mathrm{olivine} \rightleftharpoons \mathrm{spinel} + \mathrm{clinopyroxene}.
$$
第一个在蓝片岩相的温度下位于 $20\ \mathrm{kbar}$ 附近、而它是硬玉与文石在一个变基性岩中意味着俯冲到 40 公里以上深度的原因。第二个位于 $10\ \mathrm{kbar}$ 附近、而它是没有斜长石的石榴石二辉橄榄岩来自 30 公里以下的原因。
:::

::: example 读一个相系 {#ex-facies-series}
两个地区都在泥质岩中达到硅线石–钾长石的级。地区 A 在它最低的带中保存蓝晶石、而任何地方都没有十字石。地区 B 全程保存红柱石、在最高的级上有堇青石与尖晶石，而它的变基性岩含双辉石角岩。给出每一个的相系、大致的压力范围与环境。
::: solution
两个地区都达到约 $700$–$750^\circ\mathrm{C}$，因为两者都穿过了白云母 + 石英 = 钾长石 + 硅线石 + 水的反应。压力把它们分开。

**地区 A** 是**角闪岩相到麻粒岩相、8–11 kbar**：一个经典的**巴罗**系，由碰撞期间地壳增厚产生，蓝晶石记录高压的峰、而十字石的缺失记录一个更高的峰温、或一个在上升途中穿过的消耗十字石的反应。热到达得很慢，靠增厚与靠热从下方扩散，所以地区要花几千万年变暖、而等值线是平滑的。

**地区 B** 是**角闪石角岩相到长石角岩相、1–3 kbar**：一个**阿武隈**或接触变质的系。低压高温下的堇青石与尖晶石、变基性岩中的双辉石角岩、以及红柱石而不是蓝晶石，全都是低压的指标。热来自一个侵入体，变质晕是窄的，而持续时间是 $10^4$–$10^5$ 年、不是 $10^7$。

两个地区在野外一个下午就能区分，而它们记录相反的大地构造体制：被埋藏的地壳与被煮熟的地壳。
:::
:::

## 时间，以及一个变质晕的宽度

::: example 一个接触变质晕能够多宽？ {#ex-aureole}
一个 $800^\circ\mathrm{C}$ 的花岗岩侵入一个 $200^\circ\mathrm{C}$ 的围岩。取岩石的热扩散率 $\kappa = 10^{-6}\ \mathrm{m^2\,s^{-1}}$。$10^4$ 年后接触变质晕多宽，$10^6$ 年后呢？答案对巴罗类型的硅线石变质晕——几十公里宽的——意味着什么？
::: solution
热靠传导在一个扩散长度上传播
$$
L = \sqrt{\kappa t}.
$$
$10^4$ 年（$3.2\times10^{11}\ \mathrm{s}$）后，$L = \sqrt{3.2\times10^{5}} = 560\ \mathrm{m}$。$10^6$ 年（$3.2\times10^{13}\ \mathrm{s}$）后，$L = \sqrt{3.2\times10^{7}} = 5.7\ \mathrm{km}$。

传导因此造出几百米到几公里宽的变质晕，而这正是大多数花岗岩周围观察到的。它不能在可用的时间里造出一个五十公里宽的变质晕：那将要求 $t = L^2/\kappa = (5\times10^{4})^2/10^{-6} = 2.5\times10^{15}\ \mathrm{s}$，约八千万年一个单一岩体的完全稳定的加热。宽的区域的变质带因此**不是**接触变质晕，而从来不能被侵入体的热可信地解释。它们记录地壳本身的增厚，热靠一个被加倍的地壳中地热梯度缓慢的向上传导到达、加上部分熔融与流体的热平流。这就是把区域变质变成一个构造问题的论证，也是一个信封背面的扩散计算了结一场百年争论的干净例子。
:::
:::

::: history
乔治·巴罗在1893年到1912年间发表苏格兰高地的等值线，把一条矿物出现的线变成地质填图的工具，而"变质相"这个词由松滕（F. Zincken）在1913年引入、并由英格瓦尔·埃斯科拉在1920年定形为它现代的定义。埃斯科拉同时给出了相系的概念，把变质作用划分为四个主要的类型，而它们今天仍然在教科书中使用。铝硅酸盐的三相点由丹尼尔与理查德·罗伊在1958年实验确定，而石榴石–黑云母交换的校准在1970年代由福布斯与霍德、以及里夫金与斯科特等人完成。使一切成为可能的是热力学：范特霍夫与吉布斯的框架在1900年前就已存在，而拉明·圣哥达与拉蒙·贝雷吉在1950年代把活度模型引入天然溶液，使变质岩石学变成一个定量的学科。关键的洞察是地质学的：赫顿在1785年写道"我们今天看到的、由以前世界的历史所构成的地球"，而变质岩是这句话最直接的证据——它们是变成山脉的、被埋藏的、现在又被举到路上的海床。
:::

::: summary
- 一个变质相是一个 $P$–$T$ 域、而它的边界是反应面；一个相系命名一个构造的环境。
- 一条等值线是一个反应面的迹线，不是等温线：它依赖压力、流体与总体成分。
- 铝硅酸盐三相点在 $501^\circ\mathrm{C}$、$3.83\ \mathrm{kbar}$；蓝晶石意味着高压，红柱石加硅线石意味着低压。
- 交换反应是温度计（$\Delta V$ 小），净转移反应是气压计（$\Delta V$ 大）。
- 石榴石–黑云母给出 $T$，而诚实的精度是 $\pm 50$ 到 $\pm 75\ \mathrm{K}$。
- 脱碳酸反应缓冲流体的成分，而大理岩记录流体流动的位置与方向。
- 一个接触晕的宽度是 $\sqrt{\kappa t}$，几百米到几公里；几十公里宽的区域变质带要求地壳增厚、不是岩体。
:::

## 练习题

::: exercise 相与组合 {level=1}
一个泥质岩含石榴石 + 十字石 + 白云母 + 石英，而同一个露头的变基性岩含阳起石 + 绿泥石 + 钠长石 + 绿帘石。它们彼此一致吗，它们是什么相？
::: solution
一致——两者都是**角闪岩相**（变基性岩在它的下边界，在绿帘石–角闪岩亚相）。泥质岩中的石榴石 + 十字石是上绿片岩到角闪岩相，而变基性岩中的阳起石 + 绿帘石 + 钠长石是同样的条件。这个练习的要点是相被定义得使完全不同成分的岩石、在同一个地方，给出同一个答案；如果它们不给，要么岩石不在平衡、要么它们不是同一个年龄。
:::
:::

::: exercise 多晶型物的密度 {level=1 check="kyanite"}
哪个 $\mathrm{Al_2SiO_5}$ 多晶型物最密，而为什么它是俯冲带的诊断矿物？
::: solution
**蓝晶石**，$45.0\ \mathrm{cm^3\,mol^{-1}}$、对抗红柱石的 $51.5$ 与硅线石的 $50.2$。最密的多晶型物在最高压下稳定，而要求的压力——在 $500^\circ\mathrm{C}$ 约 $6\ \mathrm{kbar}$ 以上、在俯冲带较冷的部分 $10\ \mathrm{kbar}$ 以上——在一个冷的、快速俯冲的板块之下 25–40 公里的深度达到。蓝晶石因此标记一块既冷*又*深的岩石，这就是俯冲带环境的定义。
:::
:::

::: exercise 配平的反应 {level=1 check="2"}
配平反应 $\mathrm{Al_2Si_2O_5(OH)_4} \to \mathrm{Al_2SiO_5} + \mathrm{SiO_2} + n\,\mathrm{H_2O}$。$n$ 是多少？
::: solution
$n = 2$。高岭石 $\mathrm{Al_2Si_2O_5(OH)_4}$ 有四个羟基，它们造出两分子水；剩下的 $\mathrm{Al_2SiO_5}$ 与 $\mathrm{SiO_2}$ 解释了二个铝、二个硅与九个氧。这个反应是高铝泥质岩与长石质变质岩中关键的等值线，在 2 kbar 约 $380^\circ\mathrm{C}$ 发生、而以与变基性岩等值线相同的方式几乎不依赖压力。
:::
:::

::: exercise 石榴石–黑云母 {level=2 check="565"}
$X_{\mathrm{Mg}} = 0.20$ 的石榴石与 $X_{\mathrm{Mg}} = 0.40$ 的黑云母共生。用[[#ex-gtbi]]的定标求以 $^\circ\mathrm{C}$ 计的温度。
::: solution
$K_D = (0.80/0.20)/(0.60/0.40) = 4.00/1.50 = 2.67$。于是 $1166/T = \ln 2.67 + 0.410 = 0.981 + 0.410 = 1.391$，所以 $T = 838\ \mathrm{K} = 565^\circ\mathrm{C}$。这是石榴石等值线的级，而答案恰好在中等压力下泥质岩中黑云母出现与石榴石出现的反应发生的 $500$–$550^\circ\mathrm{C}$ 之上，是合理的。
:::
:::

::: exercise 哪个反应是哪个 {level=2}
分类为温度计或气压计，并说明为什么：(a) 石榴石与单斜辉石之间的 $\mathrm{Mg}$–$\mathrm{Fe}$ 交换；(b) $\mathrm{albite} = \mathrm{jadeite} + \mathrm{quartz}$；(c) 与石榴石、石英与铝硅酸盐平衡的斜长石的钙长石含量（GASP）。
::: solution
(a) **温度计。**一个交换反应几乎没有体积变化，所以它的平衡几乎不依赖压力、由熵项主导。(b) **气压计。**一摩尔固体变成两个，有一个大的正 $\Delta V$；平衡随压力强烈移动、而它是变基性岩标准的指示高压的指标。(c) 原则上是**气压计**：GASP 是一个涉及四个相、有一个大 $\Delta V$ 的净转移反应。在实践中它非常依赖斜长石的钙长石含量，那很难测量、而容易被后来的扩散改变，这就是 GASP 的压力带着比石榴石–黑云母的温度更大的误差的原因。
:::
:::

::: exercise 变质晕的宽度 {level=2 check="5"}
用 $\kappa = 10^{-6}\ \mathrm{m^2\,s^{-1}}$，传导把距一个岩体 $4\ \mathrm{km}$ 的岩石加热要花多长时间？以 $10^5$ 年为单位给出你的答案。
::: solution
$t = L^2/\kappa = (4000)^2/10^{-6} = 1.6\times10^{13}\ \mathrm{s}$，即 $1.6\times10^{13}/3.16\times10^{7} = 5.1\times10^{5}$ 年。五十万年足够长，一个岩体保持热的，所以公里级的变质晕与传导一致——但注意那个平方。宽度加倍要求四倍的时间，这就是变质晕的宽度是一个这样糟糕的温度计、一个这样好的时钟的原因。
:::
:::

::: exercise 退变的结构 {level=2}
一个麻粒岩相的石榴石被一个单斜辉石 + 斜长石的齿状交生体包围，而岩石的峰期组合包括斜方辉石 + 硅线石 + 钾长石 + 石英。发生了什么，而齿状交生体记录什么？
::: solution
这块岩石从麻粒岩相的条件（约 9 kbar、$800^\circ\mathrm{C}$）被抬升得足够快，使峰期的组合在颗粒的核心中被保存、而石榴石在它的边上映减压发生了反应。齿状交生体是一个
$$
\mathrm{garnet} + \mathrm{quartz} \longrightarrow \mathrm{clinopyroxene} + \mathrm{plagioclase},
$$
型反应的产物，它在更低的压力下变得稳定，而它交生的结构记录靠一个移动边界上两个相同时成核的生长——一个只在反应远离平衡时、也就是岩石在快速冷却或减压时形成的结构。齿状交生体因此不只是一个奇观：它们是**折返速率**的野外证据，而齿状交生体相的成分给出减压被记录时的压力，那是[[mineralogy-petrology/pt-paths]]中一条压力–温度路径的一端。
:::
:::

::: exercise 一个相的压力 {level=3}
蓝片岩相的岩石含蓝闪石、绿纤石、文石与硬玉。估计压力与温度的范围，解释为什么这个相被限制在地球中一条窄的带上，并解释为什么它如此罕见地比中生代更老。
::: solution
这个组合要求大约 **12–25 kbar、300–500 °C**：高压与低温。代替钠长石的硬玉 + 石英把下限定在 10–12 kbar 附近；代替方解石的文石在这些温度要求约 3 kbar 以上、而在地表亚稳地保存；绿纤石只在约 500 °C 之下存活；而蓝闪石的稳定性定义这个域。

这个相被限制，因为它要求一个 $3$–$7\ ^\circ\mathrm{C\,km^{-1}}$ 的地热梯度、对抗大陆地壳约 $25\ ^\circ\mathrm{C\,km^{-1}}$ 的全球平均。只有一个俯冲的板块，在它冷的核心中、而被携带下降得比它能变暖更快，提供那个。蓝片岩因此是冷的俯冲一个诊断的、排他的产物、而它们在时间中的分布是对地球何时开始俯冲冷的岩石圈的一个测量：报道最老的蓝片岩是古元古宙的、约 19 亿年、而争论很多，而这块岩石只在最后 7 亿年才变得常见。它在更老记录中的那种稀缺，是现代化的、冷的板块构造在一个逐渐冷却的地球中是一个晚期现象的主要证据线之一。
:::
:::

::: exercise 推导克劳修斯–克拉珀龙斜率 {level=3}
从一条平衡边界上两个相之间吉布斯自由能的相等出发，推导 $\mathrm{d}P/\mathrm{d}T = \Delta S/\Delta V$，并解释为什么一个 $\Delta V > 0$、$\Delta S > 0$ 的反应有一个正的斜率，以及为什么大多数脱水反应有陡的正斜率。
::: solution
沿一条平衡边界反应处于平衡，所以在它上面每一点 $\Delta G = 0$。从一点移到邻近的一点，
$$
\mathrm{d}(\Delta G) = 0 = -\Delta S\,\mathrm{d}T + \Delta V\,\mathrm{d}P,
$$
对每个相用 $\mathrm{d}G = -S\,\mathrm{d}T + V\,\mathrm{d}P$、然后相减。重排给出 $\mathrm{d}P/\mathrm{d}T = \Delta S/\Delta V$。

两个都正的有一个正的斜率：加热偏好高熵的相、而压力必须上升、靠偏好低体积的相来补偿。脱水反应有陡的正斜率，因为 $\Delta V$ 被释放的水那大的摩尔体积主导——几百个 $\mathrm{cm^3}$——而 $\Delta S$ 被同样那些水的熵主导，在 5 kbar、$600^\circ\mathrm{C}$ 那是大的、但不是巨大的。这个比出来是 $5$–$15\ \mathrm{bar\,K^{-1}}$，所以一个脱水等值线估计温度上 $100\ \mathrm{K}$ 的变化只把压力移动 $0.5$–$1.5\ \mathrm{kbar}$。这就是脱水等值线是好温度计、糟糕气压计的原因，也是变质地区的压力必须代之以来自一个净转移反应的原因。
:::

::: exercise 变质作用与时间 {level=3}
一个地区显示一个进变的巴罗序列、被一个低压高温的组合叠加改造，而第二个事件比第一个晚 2500 万年。提出一个构造的历史，并列出检验它的四个观察。
::: solution
经典的读法是**碰撞、然后垮塌**。汇聚期间的地壳增厚把地区埋到 9–11 kbar、并在 30–40 百万年中造出巴罗的组合。增厚变成重力不稳定：岩石圈拆沉、或根被对流移走，地壳伸展，而上升的热岩石与同构造到后构造的花岗岩从下面把已经增厚的剖面煮熟，在岩石被折返的同时于 2–4 kbar 造出红柱石、堇青石与混合岩。2500 万年的间隔是增厚达到它的极大、而岩石圈的不稳定发展所需的时间。

四个检验。**(i) 压力–温度路径**，来自石榴石环带与温压计：第二个事件在 $P$–$T$ 空间中必须是顺时针的——压力下降而温度上升——这是带加热的折返的签名，与简单的埋藏与剥蚀的逆时针路径相反。**(ii) 构造：**低压的组合必须与伸展的剪切带、与年龄合适的同构造侵入体联系在一起。**(iii) 地球物理与沉积学：**前陆盆地必须显示一次快速的沉降、然后隆起的脉冲，而碎屑的年代学必须记录折返。**(iv) 岩浆作用：**在第二个事件的年龄上一次钾质到过铝质花岗岩的爆发，带下地壳熔融的同位素签名。这四者任何一个都是暗示性的；四者一起是一个论证。
:::
