1912年魏格纳指出大西洋没有陆桥、没有沉没的大陆、也不需要：它的洋底在移动。要把这个论证变成定量的，又过了五十年、以及玄武岩的化学。证明不是来自大陆的形状、而是来自洋下的岩石——来自这样一个发现：一种单一的岩类，拉斑玄武岩，正沿一条连续的 60,000 公里长的线喷发，它的成分在各处百分之几之内是相同的，而离开那条线它逐渐变得更蚀变的、更磁性的。火成岩岩石学与板块构造是同一个主题从两端看：一个问一块岩石来自哪里，另一个问来自一个给定的地方的岩石必须在哪儿。

每个玄武岩都在它的化学中携带它的环境，因为环境固定三件事：地幔熔融的压力，是否加入了水，以及岩浆穿过了多少地壳。

## 四种玄武岩

::: definition 主要的岩浆系列与它们的环境 {#def-series}
**MORB**（洋中脊玄武岩）：拉斑质的，无斑到橄榄石斑晶的，$49$–$51\ \mathrm{wt}\%$ $\mathrm{SiO_2}$、$7$–$9\ \mathrm{wt}\%$ MgO，轻稀土**亏损**的，$^{87}\mathrm{Sr}/^{86}\mathrm{Sr} = 0.7026$–$0.7029$、$\varepsilon_\mathrm{Nd} = +8$ 到 $+10$。在脊上喷发，来自一个浅的、干的、以前亏损过的地幔。

**洋岛玄武岩（OIB）**：碱性的到拉斑玄武质的，轻稀土富集达地幔值的 50–200 倍，$^{87}\mathrm{Sr}/^{86}\mathrm{Sr} = 0.7023$–$0.7055$、$\varepsilon_\mathrm{Nd} = +1$ 到 $+10$。在热点喷发，来自一个深的、富集的、被地柱采样的地幔。

**岛弧玄武岩（IAB）**：拉斑到钙碱性与钾玄质的，特征是一个**负的铌异常**、钡、锶、钾与铅的富集，大洋弧的 $^{87}\mathrm{Sr}/^{86}\mathrm{Sr} = 0.7032$–$0.7050$、而在地壳厚的地方 $> 0.7055$。在俯冲的板块之上喷发。

**大陆与大陆边缘玄武岩**：三者一个混合物、加上一个地壳的组分、而相应地是最多变的、最不诊断的。
:::

::: example 读一张蜘蛛图 {#ex-spider}
一个玄武岩，在一张以洋中脊玄武岩归一化的、按从最不相容的（铪、钐、钛、重稀土）到最不相容的（铌、钽、钍、铀、镧、铈、锶、钡、铷）排列的不相容元素的图上，有一个从重稀土到轻稀土平滑上倾的模式，钡与钍相对于 MORB 富集八倍、而在铌与钽处一个陡的槽、模式降到它的镧与它的钍之间画的那条线以下五倍。环境是什么？
::: solution
一个弧。每一个特征携带一个特定的含义。轻稀土的富集与高的钡与钍说源区被交代过、或者在熔融期间加入了一个流体。**铌–钽的槽**是诊断的那个：铌、钽与轻稀土在地幔熔融期间与在分离结晶期间有几乎相同的分配行为，所以任何在地幔楔内或岩浆房内发生的事都不能把它们拉开。只有板块来源的流体能够：在一个俯冲环境高的氧逸度下，铌与钽以强烈水解的阴离子种属被携带、而被打滑石中的矿物保留，而钡、锶、铅与钍被轻易释放。结果是一个有稀土、而没有铌的熔体：铌与钽在一个俯冲带氧化的条件下被水解成阴离子络合物、而保留在板块中与残余的金红石中，而钡、锶、铅与钍轻易地进入流体。

另外的解释值得明确地排除。地壳的混染抬高锶的比与硅石、但不造出那个形状的铌槽。一个含石榴石的源区的低程度熔融富集轻稀土、而把铌留在它属于的地方。分离结晶不移动任何不是相容的东西。一个那个量级的负铌异常，除少数例外，是一个俯冲的指标。
:::
:::

## 脊：地球上最大的火成岩省

洋中脊每年造约 $20\ \mathrm{km^3}$ 的新地壳，这大约是这颗行星上全部火山活动的四分之三，而它们沿一条比赤道长十倍的线这样做。产物是惊人地均匀的：玻璃质的、无斑的洋中脊玄武岩的全球平均是 $49.9\ \mathrm{wt}\%$ $\mathrm{SiO_2}$、$1.6\ \mathrm{wt}\%$ $\mathrm{TiO_2}$、$14.9\ \mathrm{wt}\%$ $\mathrm{Al_2O_3}$、$10.3\ \mathrm{wt}\%$ $\mathrm{FeO^*}$、$7.9\ \mathrm{wt}\%$ MgO、$11.0\ \mathrm{wt}\%$ CaO、$2.6\ \mathrm{wt}\%$ $\mathrm{Na_2O}$ 与 $0.6\ \mathrm{wt}\%$ $\mathrm{K_2O}$，而单个的脊段在每一个那些氧化物上偏离那个平均不到半个百分点。

::: proposition 脊的熔融是绝热的、而它的产物由位温设定 {#prop-ridge}
因为干的方辉橄榄岩的固相线随压力上升得比一个上升的地幔块体冷却得快，一个上涌的地幔穿过它自己的固相线、而无需一个外部的热源熔融。把固相线写成 $T_s = T_0 + \beta P$、绝热线写成 $T = \theta_p + \alpha P$，熔融在
$$
P_\text{onset} = \frac{\theta_p - T_0}{\beta - \alpha}
$$
开始，而绝热线在熔融柱上高于固相线的平均超额温度是 $\tfrac12(\theta_p - T_0)$，所以产生的熔体分数是
$$
F \approx \frac{c_p\,(\theta_p - T_0)}{2L},
$$
$c_p$ 是热容、$L$ 是熔化潜热。熔体的分数、因而地壳的厚度，是位温异常的一个线性函数、而对其他一切相当不灵敏。
:::

::: example 脊的厚度与位温 {#ex-ridge}
取干的方辉橄榄岩固相线为 $T_s = 1200 + 130P\ (^\circ\mathrm{C},\ \mathrm{GPa})$、地幔绝热线为 $T = \theta_p + 10P$。对 $\theta_p = 1300^\circ\mathrm{C}$ 与 $\theta_p = 1400^\circ\mathrm{C}$，求熔融开始的压力与熔融柱上的平均超额温度，并从可用的焓估计地壳的厚度。
::: solution
熔融在 $\theta_p + 10P = 1200 + 130P$ 处开始，即 $P = (\theta_p - 1200)/120$。
$$
\theta_p = 1300:\ P = 0.83\ \mathrm{GPa},\ \text{excess at surface} = 100\ \mathrm{K},\ \overline{\Delta T} = 50\ \mathrm{K};
$$
$$
\theta_p = 1400:\ P = 1.67\ \mathrm{GPa},\ \text{excess at surface} = 200\ \mathrm{K},\ \overline{\Delta T} = 100\ \mathrm{K}.
$$
$c_p = 1300\ \mathrm{J\,kg^{-1}\,K^{-1}}$、$L = 4\times10^{5}\ \mathrm{J\,kg^{-1}}$，熔体的分数是 $F = c_p\overline{\Delta T}/L = 0.16$ 与 $0.33$。第二个是第一个的两倍，而更深的熔融开始强化它，所以地壳的厚度对位温 $100\ \mathrm{K}$ 的增加大致加倍。

那单一的关系解释关于大洋地壳的两个大观察。正常的大洋地壳 $6$–$7\ \mathrm{km}$ 厚、而由全球脊系统的 $1300$–$1350^\circ\mathrm{C}$ 的地幔产生。像冰岛、翁通爪哇高原与加勒比大火成岩省那样的火成岩省携带 $20$–$40\ \mathrm{km}$ 的火成地壳、而要求比正常热 $200$–$300\ \mathrm{K}$ 的地幔——这就是"地幔柱"这个短语的定量内容。线性关系在这样大的异常处高估熔体的分数，因为固相线的曲率与源区的亏损都会咬人，但方向与数量级是对的。
:::
:::

::: quiz
一个玄武岩有相对于洋中脊玄武岩富集的轻稀土、$\varepsilon_\mathrm{Nd} = +9$、$^{87}\mathrm{Sr}/^{86}\mathrm{Sr} = 0.7028$、而**没有**铌异常。哪个环境最可能？
- [ ] 一个岛弧，因为它是富集的。
- [x] 一个热点或洋岛，采样一个亏损的、深的地幔储库。
- [ ] 一个洋中脊，因为锶的比是亏损的。
- [ ] 一个大陆溢流玄武岩，因为它是富集的。
::: solution
轻稀土的富集排除一个正常的脊，而铌异常的缺失排除一个弧。亏损的锶与钕的签名连同轻稀土的富集，是一个深的、未亏损但不放射性的地幔储库——一个像夏威夷或圣赫勒拿的热点——经典的组合。大陆溢流玄武岩有富集、但从它们穿过的大陆岩石圈携带放射性的锶与钕。
:::
:::

::: warning 均匀的化学不意味着均匀的源区
MORB 的全球均匀性是地质学中最误导的事实之一。它说脊下的地幔以前被熔融过、反复地，而现在是一个残留物——在不相容元素与在可熔性上亏损的——而熔融过程本身对剩下什么惊人地不灵敏。它**不**说地幔是均一的：在单一的一个脊段内锶的比变化 0.0005，几公里宽的富集地幔的斑块喷发碱性玄武岩，而经过一个热点附近的脊继承它的化学几百公里。这种均匀性是对一个采样方案的平均——在约 15 到 60 公里深度之间对一个难熔残留物 15–25% 的熔融——它把它作用到的一切都压平。
:::

## 俯冲：大陆地壳的起源

::: definition 板块指标 {#def-slab}
一个岩浆被判断为受板块影响的，靠一些没有地幔或地壳的过程能单独造出的特征：一张以原始地幔归一化的图上**负的铌–钽异常**；高的 **Ba/La**，超过约 20、对抗亏损地幔接近 2.5 的值，因为钡比镧在流体中活动得多；高的 **Sr/Y** 与低的 **Y** 与**镱**，记录一个含石榴石的残留体；加了沉积物时高的 **Th/La** 与 **$^{206}\mathrm{Pb}/^{204}\mathrm{Pb}$**；以及在年轻的弧中，过剩的 **$^{10}\mathrm{Be}$**，一个宇宙成因的同位素、140 万年的半衰期，只能来自最近俯冲的地表物质。
:::

::: example 埃达克岩，或者熔化板块 {#ex-adakite}
秘鲁南部一个年轻弧的一套安山到英安质的熔岩有 $58\ \mathrm{wt}\%$ $\mathrm{SiO_2}$、$6\ \mathrm{wt}\%$ MgO、$\mathrm{Sr} = 900\ \mathrm{ppm}$、$\mathrm{Y} = 8\ \mathrm{ppm}$、$\mathrm{Yb} = 0.8\ \mathrm{ppm}$，给出 $\mathrm{Sr/Y} = 110$。源区的组合必须是什么，而这对板块说什么？
::: solution
锶钇比是钥匙。锶进入斜长石，所以一个失去了它斜长石的残留物把锶留在熔体中；钇与镱在**石榴石**中是相容的，所以一个保留石榴石的残留物把它们剥离。一个 $\mathrm{Sr/Y} = 110$ 的熔体（一个正常的弧值是 20–40、而 MORB 在 2 以下）因此来自一个**没有斜长石、而有石榴石**的源区——也就是说，来自榴辉岩。而俯冲带中唯一大量可用的榴辉岩是板块本身变质的玄武岩。

所以这些熔岩是**埃达克岩**、俯冲的大洋地壳的熔体、而它们的存在携带两个进一步的含义。第一，板块在它表面加热到足以熔融，这要求要么一个年轻的、热的、因而浮的板块，要么一个停滞的、被周围的地幔加热的板块。第二，熔体与一个含石榴石与金红石的残留体平衡，这就是埃达克岩有很低的重稀土与高的锶、以及它们是组成太古宙大陆地壳大部分的英云闪长岩–奥长花岗岩–花岗闪长岩套的模式材料的原因。第一批大陆是由板块熔融、而不是由分离结晶造成的论证，恰恰建立在这张图上。
:::
:::

弧的几何与它的化学一样有诊断性。弧的火山作用在板块到达约 $100\ \mathrm{km}$ 深度时开始，那正是蚀变的大洋地壳与下伏地幔的蛇纹岩中主要的含水矿物分解的地方；这把**弧–海沟的距离固定在 100–250 km**、随板块的倾角缩放。在板块陡的地方弧坐在弧前附近、而一个弧后盆地在它后面打开；在板块平坦的地方弧完全关闭、而火山作用迁移到内陆几百公里，像在落基山古山脉与今天南纬 25° 的安第斯。

::: example 火山在哪里？ {#ex-arc-geometry}
一个俯冲带在海岸有一个海沟、而一个火山前锋在内陆 140 km。如果板块以 $30^\circ$ 倾斜，它在前锋之下多深，而如果倾角变平到 $15^\circ$、脱水的深度不变，前锋的位置会怎样？
::: solution
从海沟到前锋的水平距离是 $d = z/\tan\delta$，$z$ 是脱水的深度、$\delta$ 是倾角。$d = 140\ \mathrm{km}$、$\delta = 30^\circ$，
$$
z = d\tan\delta = 140\times0.577 = 81\ \mathrm{km}.
$$
如果倾角在同样的脱水深度变平到 $15^\circ$，
$$
d = \frac{81}{\tan15^\circ} = \frac{81}{0.268} = 302\ \mathrm{km}.
$$
火山前锋向内陆迁移 160 km。这就是北美西部内陆巨大的火山碎屑岩爆发式喷发，以及现代安第斯中部火山缺失带背后的机制，也是 80–100 km 的深度是这个主题中最稳健的数字之一的原因：一条火山弧的几何，从空中填图，是板块在什么深度失去它的水一个直接的测量。
:::
:::

## 蛇绿岩：陆上一片洋底的切片

::: definition 蛇绿岩的序列 {#def-ophiolite}
一个**蛇绿岩**是一块被就位于大陆边缘或插入海沟的大洋岩石圈的碎片，而它在一个竖直剖面中保存洋底的地层。从上到下：深水的沉积与锰壳；**枕状玄武岩**与相关的火山碎屑岩；一个**席状岩墙杂岩**，由平行的、互相切割的玄武质岩墙构成，记录脊的裂隙系统；**辉长岩**，等粒的然后层状的，带一个岩墙的过渡带；一个**堆晶超基性序列**，由辉石岩、橄榄辉石岩与纯橄岩构成、底部带铬铁矿与铂族元素的矿层；最后是**亏损的方辉橄榄岩或二辉橄榄岩**、在它的底部被构造化成糜棱的橄榄岩，其下是蛇纹石化的地幔、而在少数窗状构造中是新鲜的地幔橄榄岩。阿曼的塞麦伊尔蛇绿岩与塞浦路斯的特罗多斯蛇绿岩是标准的剖面。
:::

::: example 重建一个蛇绿岩 {#ex-ophiolite}
在一条山脉中你填出，从构造最低到最高：一个含豆荚状铬铁矿的蛇纹石化橄榄岩；一个橄榄石辉长岩与纯斜长岩的层状序列、带粒序层与交错层理；一个平行的岩墙的厚体、每一个在两侧都被激冷、而切割它下面那一个；枕状熔岩带锰壳与远洋灰岩；而在它们之上一个把所有这些放到红色岩层上的逆冲断层。解释。
::: solution
这是一个蛇绿岩，靠逆掩就位的、而内部的顺序恰好就是洋底的剖面：深渊的橄榄岩，堆晶的下地壳，席状岩墙在古的脊轴上，枕状熔岩与沉积在地的表面。**激冷的边缘**与岩墙互相切割的关系是扩张机制的证明——每一道岩墙被注入到一道被前一道保持敞开的裂缝中，而每一个因此比它切割的那个更年轻。粒序与交错层理的堆晶记录晶体在一个长命的岩浆房中的沉降。逆冲断层下面的红色岩层是大陆架的沉积，所以这个蛇绿岩被逆冲到一个被动边缘之上，这意味着两个汇聚的边缘之间的海洋已经闭合。

构造的读法跟着来：一条缝合线，一个废弃的海洋，一次碰撞。蛇绿岩是一个地质学家能够行走在洋幔上的唯一地方，而每一个蛇绿岩是一个海洋已经闭合的证据。
:::

::: history
蛇绿岩的解释是1960年代构造学转动的那个铰链。休斯曾以阿尔卑山的蛇纹岩为特提斯的"蛇绿岩"命名、而把它们解释成向一个地槽的水下喷发；现代的说明来自1972年一次彭罗斯会议，在那里蛇绿岩被定义为一个大洋地壳与上地幔的剖面、而席状岩墙杂岩被认出一个扩张中心的指纹。加斯对特罗多斯与科尔曼对塞麦伊尔的工作从陆地上确立了地层；确认来自海上，当深海钻探取回枕状熔岩在席状岩墙之上、岩墙在辉长岩之上，而当1974年东太平洋隆的37航次取回一个热液循环模型曾预言的铜锌块状硫化物矿床——一个预言被1977年加拉帕戈斯裂谷的黑烟囱、1985年大西洋中脊的热液丘的发现漂亮地证实。玄武岩按构造环境的地球化学分类——皮尔斯与坎1973年的判别图，以及皮尔斯用不活动元素的比为一个来源不明的玄武岩命名源区的长期规划——使整套方法能够用于变形的、蚀变的、古老的岩石，而这是一个拿着放大镜与一台质谱仪的野外地质学家如今能够重建一个在 18 亿年前闭合的海洋的原因。
:::

## 通向何处

这里使用的化学在[[geochemistry/trace-elements]]与[[geochemistry/radiogenic-tracers]]中发展；熔融的物理在[[mineralogy-petrology/phase-diagrams]]中；俯冲的力学在[[geophysics/seismic-structure]]中；脊、弧与层状侵入体的矿床在[[earth-resources/magmatic-hydrothermal]]中；而弧的火山灾害在[[natural-hazards/volcanic-hazards]]中。

::: summary
- 玄武岩告诉你它来自哪里：脊给亏损的拉斑岩，热点给富集的碱性玄武岩，弧给带铌槽的钙碱性岩、而大陆给三者一个混合物。
- 脊的岩浆作用是绝热减压，而它造出的地壳的厚度几乎完全由上涌的位温设定。
- 弧的岩浆作用是一个板块来源流体的助熔熔融、而它的化学被那个流体主导：钡、锶、铅与钍是活动的、铌与钽不是，而由此产生的异常不能被任何其他过程伪造。
- 高 Sr/Y 加低镱意味着一个含石榴石、无斜长石的残留体，而在一个俯冲带中那意味着板块本身在熔融。
- 火山前锋坐在板块到达 80–100 km 的地方，所以弧–海沟的距离测量板块的倾角。
- 一个蛇绿岩是一个洋底的剖面、在竖直的轮廓中，而它在陆地上的存在记录一个海洋的闭合。
:::

## 练习题

::: exercise 配对 {level=1}
把每一个描述配到 MORB、OIB 或 IAB：(a) 轻稀土亏损的，$^{87}\mathrm{Sr}/^{86}\mathrm{Sr} = 0.7028$；(b) $\mathrm{Ba/La} = 60$、$\mathrm{Nb/Nb^*} = 0.2$；(c) $\varepsilon_\mathrm{Nd} = +2$、$^{87}\mathrm{Sr}/^{86}\mathrm{Sr} = 0.7045$、$^{206}\mathrm{Pb}/^{204}\mathrm{Pb} = 20.5$。
::: solution
(a) **MORB**——亏损的、非放射性的锶。(b) **IAB**——钡高于镧与一个大的铌槽都是板块流体的指标。(c) HIMU 型的 **OIB**：放射性的铅与低的钕指示一个含古老的再循环大洋地壳的源区、而铌异常的缺失排除一个弧。
:::
:::

::: exercise 地壳的厚度 {level=1 check="2"}
当上涌地幔的位温从 $1300$ 升到 $1400^\circ\mathrm{C}$ 时，大洋地壳的厚度大致增加多少倍？
::: solution
约两倍，从接近 0.16 的熔体分数到一个接近 0.33 的（见[[#ex-ridge]]）。更深的熔融开始与更大的焓的盈余都有贡献，而它们朝同一个方向作用。
:::
:::

::: exercise 什么不是板块指标 {level=1 check="Nb"}
哪个元素，符号 Nb，给出弧玄武岩中诊断的负异常，而为什么分离结晶与部分熔融都不能造出那个异常？
::: solution
因为铌、钽、镧与轻稀土在每一个无水的、地幔与地壳的矿物组合中本质上相同总分配系数：它们都是大的、高电荷的、不相容的阳离子、而它们在每一个熔融与结晶过程中作为一个单一的组行为。要把铌相对于它的邻居压低五倍，需要一个在化学上区分它们的过程——而自然界唯一可用的是在一个高氧逸度的流体中铌与钽的水解与差异保留。
:::
:::

::: exercise 石榴石与锶 {level=2}
解释为什么一个来自含石榴石源区的高压熔体有低的重稀土与低的钇含量，以及为什么那使 Sr/Y 成为一个气压计。
::: solution
石榴石的结构容易把重稀土与钇取进它的十二面体位点、而相容性从镧到镥单调地增加，所以一个含石榴石的残留体产生一个在重稀土上亏损、而相对于它轻稀土富集的熔体。钇行为像钬与铒。锶，因为是二价的、大的，在石榴石中是不相容的、而留在熔体中。随着压力上升、斜长石消失进石榴石，因此 Sr/Y 陡峭地上升——而一个 Sr/Y 在 40 以上的熔体几乎肯定来自一个 25–30 kbar 或更深的源区、或来自一个很湿的、斜长石在更低压下不稳定的源区。
:::
:::

::: exercise 弧的几何 {level=2 check="204"}
一个板块以 $25^\circ$ 倾斜、而脱水发生在 95 km。火山前锋在内陆多远？
::: solution
$d = z/\tan\delta = 95/\tan25^\circ = 95/0.466 = 204\ \mathrm{km}$。弧观察到的范围是 100–250 km、而计算复现它——这是弧的位置真的记录板块脱水的深度、而不是它之上地壳的几何的最强单一证据。
:::
:::

::: exercise 邦尼尼岩 {level=2}
邦尼尼岩是高硅（$53$–$57\ \mathrm{wt}\%$ $\mathrm{SiO_2}$）、高镁（$8$–$12\ \mathrm{wt}\%$ MgO）、极低钛（$< 0.5\ \mathrm{wt}\%$ $\mathrm{TiO_2}$）而极高铬（$> 1500\ \mathrm{ppm}$ Cr）的熔岩，只在弧前、而只在弧前最老的部分发现。它们要求什么，而它们关于俯冲的开始意味着什么？
::: solution
它们要求一个已经被熔融过的地幔——一个难熔的方辉橄榄岩——被再次熔融，在一个板块来源的流体大通量的存在下，在残留物保留斜方辉石的压力下。低的钛与高的镁说源区被一次更早的、更大的熔融事件亏损过；高的硅说残留物是热的、而熔体是湿的。因为它们出现在弧前序列的底部，它们记录**一个新俯冲带第一次岩浆活动**，在板块冷却楔之前。它们是俯冲启动的诊断岩石、而它们被发现——伴随着伴生的高镁安山岩——在几乎每一条年轻的岛弧的底部，包括伊豆–邦尼尼与马里亚纳系统。
:::
:::

::: exercise 科马提岩 {level=2}
科马提岩含 18–35 wt% 的 MgO、而几乎完全限于比 25 亿年更老的岩石。这对地幔要求什么，而它们为什么停止？
::: solution
它们要求地幔熔融到 40–60%，产生一个与 $\mathrm{Fo}_{93}$–$\mathrm{Fo}_{96}$ 的橄榄石在 $1600$–$1900^\circ\mathrm{C}$ 的喷发温度平衡的液体，比今天喷发的任何玄武岩热 $200$–$400\ \mathrm{K}$。这要求一个位温远高于现在值的地幔，而这从钾-40、铀与钍衰变在太古宙更高的热产生、以及从一个更有效的、更剧烈的对流方式跟着来。科马提岩随着地幔在古元古宙冷却而变稀、然后消失；这种岩石的消失是地球长期冷却一个直接的、岩石学的测量、而它是关于那个冷却为数不多的不依赖一个模型的约束之一。
:::
:::

::: exercise 一个有争议的玄武岩 {level=3}
一个绿岩带 27 亿年的玄武岩有 $\mathrm{Nb/Nb^*} = 0.3$、$\mathrm{Ba/La} = 55$、$\varepsilon_\mathrm{Nd} = +4$、$^{87}\mathrm{Sr}/^{86}\mathrm{Sr} = 0.7050$（未校正）而轻稀土相对于球粒陨石富集三十倍。一位同事论证这证明太古宙的板块构造。两个最强的反对是什么，而什么观察能了结它们？
::: solution
**反对一：蚀变。**绿岩带的玄武岩是绿片岩相的岩石、而钡、锶、铷与轻稀土在低级变质与海水蚀变期间都是活动的。一个 55 的钡镧比与一个 0.7050 的锶比都可能交代作用的产物，而未校正的锶比在一块这个年龄的岩石中一文不值。只有在绿片岩相条件下可证明不活动的元素——铌、钽、高场强的稀土、钛、锆、铪——能够被使用、而锶的同位素系统必须被钐–钕取代。

**反对二：铌槽不是唯一的。**一个负的铌异常也能够由金红石或角闪石在一个低程度熔融期间保留在一个残留的源区中、靠同化古老的大陆岩石圈、或靠一个富铁液体的极端分离结晶产生。

了结它的观察是**组合**、不是化学：一个带高镁安山岩与埃达克岩的钙碱性分异系列，邦尼尼岩在序列的底部，一个配对的高压地区（榴辉岩、蓝片岩），以及一个快速隆起与再循环的沉积记录。单一样品中的弧的化学是暗示性的；一整个汇聚边缘的系统，带它变质的配对带与它的弧前碎屑楔，是证据。这就是关于板块构造何时开始的争论运行了四十年、而只会被填图、不会被质谱学了结的原因。
:::
:::

::: exercise 一个海洋的质量 {level=3}
洋中脊每年造约 $20\ \mathrm{km^3}$ 的新大洋地壳、而大洋地壳 $7\ \mathrm{km}$ 厚。估计洋底创造的速率，以每年平方公里计，洋底的面积，以及洋底的平均年龄。最后一个数字对沉积的记录意味着什么？
::: solution
每年创造的面积是体积除以厚度，$20/6 = 3.3\ \mathrm{km^2\,yr^{-1}}$。洋盆覆盖约 $3.6\times10^{8}\ \mathrm{km^2}$，所以大洋地壳的停留时间是
$$
\tau = \frac{3.6\times10^{8}}{3.3} = 1.1\times10^{8}\ \mathrm{yr} = 110\ \mathrm{Myr}.
$$
现在洋底观察到的平均年龄约 64 Myr、不是 110，因为白垩纪的地壳产生大约是今天的两倍、而现在正在创造的洋底是总数中比稳态值更小的一个分数。后果是取回的最老的海洋沉积约 1.8 亿年，而在侏罗纪之前关于海洋的化学、温度与环流所知的一切必须从大陆边缘的沉积、从碳酸盐中的同位素、以及从生活在海中但保存在陆地上的生物的化石推断。海洋不保存它自己深部过去的记忆；大陆替海洋保存它。
:::
