玄武岩与花岗岩都是熔融造出来的，而谁也不是由另一个熔融造出来的。这一个事实——鲍林在1914年到1928年间一系列炉子实验中确立的——是火成岩岩石学的基础：岩石*部分*熔融，最初几滴液体与它来自的岩石成分不同，而留下的残留体控制下一个熔融的是什么。关于火成岩多样性的的一切——大洋底部为什么是玄武岩而大陆是安山岩与花岗岩，一个岩浆房为什么能造出一个层状侵入体——都跟着几张相图的几何学而来。

相图不是一张岩石的画像。它是一个化学系统的平衡状态的一张地图，而它的价值在于：对一个给定的成分与温度，它告诉你有多少相能够存在、它们是什么、它们含什么。岩石不在平衡中，而读相图要记着这一点：它们告诉你如果有时间岩石会做什么，而对此的偏离就是结构。

## 相、组分与相律

::: definition 相、组分与系统 {#def-phase}
一个**相**是一个系统中物理上可区分的、均一的、具有确定成分与结构的一部分：橄榄石的晶体、一个硅酸盐熔体、一个气泡，各是一个相。一个**组分**是定义每一个相的成分所必需的化学上独立的构成物；一个**系统**是被选定的那组组分。**镁橄榄石–铁橄榄石**系统 $\mathrm{Mg_2SiO_4}\!-\!\mathrm{Fe_2SiO_4}$ 有两个组分；**透辉石–钙长石**系统 $\mathrm{CaMgSi_2O_6}\!-\!\mathrm{CaAl_2Si_2O_8}$ 有两个；一个天然的玄武岩，若当作 $\mathrm{SiO_2}$、$\mathrm{TiO_2}$、$\mathrm{Al_2O_3}$、$\mathrm{Cr_2O_3}$、$\mathrm{FeO}$、$\mathrm{MnO}$、$\mathrm{MgO}$、$\mathrm{CaO}$、$\mathrm{Na_2O}$、$\mathrm{K_2O}$、$\mathrm{P_2O_5}$、$\mathrm{H_2O}$ 处理，有十二个，而超出任何描绘。
:::

::: theorem 吉布斯相律 {#thm-phase-rule}
对一个有 $C$ 个组分、其中 $P$ 个相平衡共存的系统，**自由度数**——可以在不改变相数的前提下变动的独立变量（温度、压力与成分）——为
$$
F = C - P + 2 .
$$
对一个**凝聚系统**，其中没有气相出现、而压力被固定（通常在 1 bar），这变成 $F = C - P + 1$。
:::

::: proof
通过说出它的相、并在每个相内说出除一个之外每个组分的量来规定一个系统，因为摩尔分数之和为一：那是 $P(C - 1)$ 个成分变量，加上 $T$ 与 $P$，总共给出 $P(C-1) + 2$ 个变量。平衡要求每个组分的化学势在每一个相中相等，$\mu_i^{(1)} = \mu_i^{(2)} = \cdots = \mu_i^{(P)}$，这对 $C$ 个组分中的每一个是 $(P-1)$ 个独立方程、总共 $C(P-1)$ 个方程。因此仍能被自由选择的变量数为
$$
F = P(C-1) + 2 - C(P-1) = C - P + 2 .
$$
固定压力去掉一个变量、而一个方程不受影响，给出凝聚形式的相律。这条律不是一个近似：它是一次计数，而它在岩石学中的力量在于它说出一个组合何时是*无变量的*——一块岩石的矿物组合何时钉住它的压力与温度，这是[[mineralogy-petrology/pt-paths]]的基础。
:::

::: example 数自由度 {#ex-phase-rule}
(a) 1 bar 下的干镁橄榄石，(b) 1 bar 下与它自己的熔体平衡的镁橄榄石，(c) 一块含橄榄石、斜方辉石、单斜辉石、尖晶石与熔体的、固定总成分的岩石，(d) 一块含橄榄石、斜方辉石、单斜辉石、尖晶石与一个气相的橄榄岩，各有多少自由度？
::: solution
(a) 一个组分（$\mathrm{Mg_2SiO_4}$）、一个相、压力固定：$F = 1 - 1 + 1 = 1$。温度可以是到熔点之前的任何值。
(b) 一个组分、两个相、压力固定：$F = 1 - 2 + 1 = 0$。熔点是单一的一个温度——1 bar 下 $1890^\circ\mathrm{C}$——而这正是"那个"熔点的意思。
(c) 取一个简化的四组分系统（$\mathrm{Mg_2SiO_4}$、$\mathrm{Fe_2SiO_4}$、$\mathrm{MgSiO_3}$、$\mathrm{CaMgSi_2O_6}$）带五个相：$F = 4 - 5 + 1 = 0$。一个四组分系统中的五个相在固定压力下只能在一个温度与一组相成分下存在——这就是一个五相组合是一个好的地温计与气压计、而五相岩石罕见的原因。
(d) 有一个气相存在时，如果气相是一个纯 $\mathrm{H_2O}$ 相，压力就不再是自由的：加入气相加入一个相，所以 $F$ 减一。这就是一个流体相在一个变质岩中的出现为什么常常标出一条等变线，也是"无气相"与"有气相"的实验为什么给出不同的反应曲线的原因。
:::
:::

## 二元共熔

::: definition 共熔、液相线与固相线 {#def-eutectic}
在一个二组分系统中，**液相线**是系统完全为液体的那个面（在二元图中是一条线），**固相线**是它完全为固体的那个面之下。一个**简单共熔**系统是两种结晶的相是纯的端元的那个系统，于是两条液相线曲线在一个单一的**共熔点**相交，温度为 $T_E$、成分为 $X_E$，在其之下没有什么能熔融。在液相线与固相线之间系统是一个**浆**：液体加一个或两个结晶相。
:::

::: proposition 杠杆规则 {#prop-lever}
在一个二元图的两相区中，若一个总成分为 $X_0$ 的系统含成分为 $X_\alpha$ 与 $X_\beta$ 的相，两个相的**重量分数**为
$$
w_\alpha = \frac{X_\beta - X_0}{X_\beta - X_\alpha}, \qquad w_\beta = \frac{X_0 - X_\alpha}{X_\beta - X_\alpha},
$$
所以两个相的量与连接线上被总成分分开的两臂长度成反比。
:::

::: proof
对被绘制的那个组分做质量平衡：一单位的系统含 $w_\alpha + w_\beta = 1$ 的两个相、以及 $X_0 = w_\alpha X_\alpha + w_\beta X_\beta$ 的该组分。代入 $w_\beta = 1 - w_\alpha$ 得 $X_0 = X_\beta - w_\alpha(X_\beta - X_\alpha)$，整理得第一个表达式；第二个由对称得出。这条规则只是质量平衡，这就是它为什么原样适用于三元图（在那里连接线变成一个三角形内的连接线）与任何两相混合物，无论这些相是否在平衡中。
:::

::: example 结晶一个透辉石–钙长石熔体 {#ex-di-an}
在 1 bar 的 $\mathrm{CaMgSi_2O_6}\!-\!\mathrm{CaAl_2Si_2O_8}$ 系统中，钙长石在 $1553^\circ\mathrm{C}$ 熔融、透辉石在 $1391^\circ\mathrm{C}$，而共熔点在 $58\ \mathrm{wt}\%$ 透辉石、$1274^\circ\mathrm{C}$。取一个 $\mathrm{Di}_{40}\mathrm{An}_{60}$ 成分的熔体，描述冷却时发生什么。然后在 $1350^\circ\mathrm{C}$ 求液体与斜长石的比例，此时液体到达 $\mathrm{Di}_{55}\mathrm{An}_{45}$、而正在结晶的斜长石是 $\mathrm{An}_{95}$。
::: solution
总成分在共熔点的钙长石一侧，所以最先出现的相是**斜长石**，在液相线上约 $1440^\circ\mathrm{C}$。当斜长石（富钙，接近 $\mathrm{An}_{95}$）分离出去时，液体在 $\mathrm{CaAl_2Si_2O_8}$ 上被耗尽、并*沿液相线朝共熔点向下*移动，逐渐富集透辉石的组分。在 $1274^\circ\mathrm{C}$ 液体到达共熔成分 $\mathrm{Di}_{58}\mathrm{An}_{42}$，此后斜长石与透辉石**都**在恒温下一起结晶，直到液体消失。这块岩石是一个半自形粒状的集合体，细粒的斜长石与透辉石交生之中嵌着斜长石的斑晶——一个辉长岩，而具体说是鲍林称为*共熔*的那个结构。

在 $1350^\circ\mathrm{C}$，连接线按透辉石的含量从结晶的斜长石 $X_\text{xtal} = 5$（斜长石是 $\mathrm{An}_{95}$，所以它只携带 $5\%$ 的透辉石组分）延伸到液体 $X_\text{liq} = 55$，而总成分在 $X_0 = 40$：
$$
w_\text{plag} = \frac{X_\text{liq} - X_0}{X_\text{liq} - X_\text{xtal}} = \frac{55 - 40}{55 - 5} = 0.30, \qquad
w_\text{liq} = \frac{X_0 - X_\text{xtal}}{X_\text{liq} - X_\text{xtal}} = \frac{40 - 5}{50} = 0.70 .
$$
百分之三十的斜长石，百分之七十的液体。每次都值得做的两个检查。组分平衡闭合：$0.30\times5 + 0.70\times55 = 1.5 + 38.5 = 40$，总成分。而几何学说的是同一件事：在 40 处的总成分比在 5 处的晶体更接近在 55 处的液体，而成分*更接近*总成分的那个相是*更*丰富的那个相。把连接线按比例画一次，代数就不再是错误的一个来源。

也注意这些数字关于这块岩石说了什么：在 $1350^\circ\mathrm{C}$ 它仍是百分之七十的液体，而迄今形成的斜长石只占它的百分之三十。大部分的结晶发生在最后几十度里，这就是火成岩由最后、最低温结晶的相主导的原因。
:::
:::

## 类质同象、环带与反应

真实的系统很少是简单共熔的。当两个端元形成一个**连续类质同象**系列时，相图在性质上改变：没有共熔点，而在液相线与固相线之间，液体与结晶溶液以*不同*的成分共存。

::: definition 分配系数与结晶路径 {#def-partition}
对一个分配在一个结晶溶液与一个液体之间的组分 $i$，**能斯特分配系数**为
$$
K_D^{i} = \frac{X_i^\text{solid}/X_j^\text{solid}}{X_i^\text{liquid}/X_j^\text{liquid}} .
$$
若 $K_D < 1$，该组分是**不相容的**、富集在液体中；若 $K_D > 1$，它是**相容的**、进入晶体。对一个二元类质同象系统，液相线与固相线在每个温度上由 $K_D$ 联系，而最先形成的晶体总是比总成分更富相容的组分。
:::

两个后果主导火成岩的结构。**环带（正环带）：**如果晶体不被扩散重新均一化，最先形成的核就比边更富钙（或更富镁），而岩石保存一份结晶路径的冷冻记录。**鲍林反应系列：**在一个不连续系列中，一个在有限范围内稳定的相与液体反应生成下一个相——橄榄石到斜方辉石到单斜辉石到角闪石到黑云母——而岩石留下反应边、被熔蚀的晶体，以及一个不是平衡的矿物组合。

::: example 一个斜长石晶体中的环带 {#ex-zoning}
一个玄武岩中的一个斜长石晶体有一个 $\mathrm{An}_{88}$ 的核与一个 $\mathrm{An}_{55}$ 的边，基质是 $\mathrm{An}_{40}$ 的玻璃。这关于结晶历史说了什么，而如果这块岩石曾在略低于固相线的温度下保持一百万年，你会预期发现什么？
::: solution
这个晶体是在被冷却时生长的：最先形成的核与一个钙与铝尚未被移走的液体平衡，而边与一个逐渐被耗尽它们的液体平衡。$\mathrm{An}_{40}$ 的玻璃是残余液体，比晶体的任何部分都更富钠，恰好是固相线曲线所要求的。从核到边到玻璃的序列是一条沿固相线向下的单调路径，而它的斜率是一个粗略的地温计。

如果这块岩石相反曾被保持得热的，长石中的体扩散会把轮廓抹平。在 $900^\circ\mathrm{C}$，钙在斜长石中的扩散系数约为 $10^{-21}\ \mathrm{m^2\,s^{-1}}$，而在 $10^6$ 年（$3\times10^{13}\ \mathrm{s}$）上的扩散长度为
$$
L = \sqrt{Dt} = \sqrt{10^{-21}\times3\times10^{13}} = 5.5\times10^{-4}\ \mathrm{m} = 0.55\ \mathrm{mm}.
$$
一个 $1\ \mathrm{mm}$ 宽的晶体会被大大均一化、而环带大部分被抹去；一个 $5\ \mathrm{mm}$ 宽的晶体会保住它的核成分、只失去它的边。环带因此是一个**热年代计**，而轮廓的宽度、拟合扩散方程，给出自最后一次加热事件以来的时间——[[mineralogy-petrology/pt-paths]]的方法。
:::
:::

::: quiz
透辉石–钙长石共熔系统中一个 $\mathrm{Di}_{70}\mathrm{An}_{30}$ 成分的熔体被缓慢冷却。哪一对描述它形成的岩石？
- [ ] 共熔交生中的斜长石斑晶，因为它在共熔点的钙长石一侧。
- [x] 共熔交生中的透辉石斑晶，因为它在共熔点的透辉石一侧。
- [ ] 只有细粒的共熔交生，因为每一个成分都在共熔温度上结晶。
- [ ] 一个分层的岩石，因为两个相靠重力分离。
::: solution
共熔点在 $\mathrm{Di}_{58}$，所以 $\mathrm{Di}_{70}$ 的成分落在**透辉石**一侧：透辉石单独结晶，而液体沿液相线朝 $\mathrm{Di}_{58}$ 向下移动，而剩下的液体随后固结成一个两相的共熔交生。只有恰好共熔的成分给出一个没有斑晶的交生，而分层需要一个岩浆体和时间、不只是一个成分。
:::
:::

::: warning 共熔点不是一个极小点，而极小点不是一个熔点
三个点不断被混淆。一个**共熔点**是一个成分，在那里两个（或更多）相从液体一起在系统中最低的熔融温度上结晶；液体在那个温度上消失。一个**类质同象极小点**是一个液相线经过一个极小、但只有一个相结晶的成分，所以液体不必具有那个成分、而岩石也不必是一个细粒交生。而一个**同熔（转熔）点**是一个*反应*点：一个固体加液体合成一个不同的固体，所以最先出现的相被消耗、而不是累积。在 $\mathrm{Mg_2SiO_4}\!-\!\mathrm{SiO_2}$ 系统中，镁橄榄石与硅石之间根本没有共熔点——顽火辉石在 $1557^\circ\mathrm{C}$ 以转熔方式形成，这就是一个硅饱和的地幔熔体从不留下橄榄石与石英共存的原因，也是 $\mathrm{Forsterite} + \mathrm{Silica} \to \mathrm{Enstatite}$ 这个反应是地球上最重要的反应之一的原因。
:::

## 熔一块岩石：固相线、液相线与三种熔法

一块岩石是一个多组分的混合物，所以它不在一个温度上熔融、而在一个**范围**上熔融，从**固相线**（第一滴液体）到**液相线**（最后一个晶体消失）。最初的液体总是系统所能产生的最富硅、最富水、最富不相容元素的，因为它在局部组合中可用的最低熔的共熔点上形成。

::: example 谁先熔？ {#ex-first-melt}
一个含石英、斜长石、钾长石、黑云母与角闪石的湿英云闪长岩，在 5 kbar 下、有大量流体存在时被缓慢加热。哪个组合先熔，大约什么时候？
::: solution
熔融从涉及所存在的相的最低温度的反应开始，而在一个含水的花岗质系统中，那通常是一个**含水矿物的助熔熔融反应**：黑云母与角闪石在长石与石英反应之前分解。最初的几滴在成分上是花岗质的——$\mathrm{Na_2O}\!-\!\mathrm{K_2O}\!-\!\mathrm{CaO}\!-\!\mathrm{Al_2O_3}\!-\!\mathrm{SiO_2}\!-\!\mathrm{H_2O}$ 系统的"极小熔体"——而在 5 kbar、水饱和的条件下固相线在 $700\ ^\circ\mathrm{C}$ 附近，在 10 kbar 下降到约 $660\ ^\circ\mathrm{C}$，而在更高的压力下随富水流体变得不那么稳定而再次上升。

在野外的两个重要后果。第一，熔体接近**花岗岩极小熔体**，这就是为什么那么多花岗岩有接近极小的成分、以及"花岗岩极小"温压计究竟为什么能用。第二，除非温度升到固相线之上很远，熔体分数是小的：在 $750\ ^\circ\mathrm{C}$ 一个英云闪长岩可能只含百分之几的液体，这足以使它部分熔融、力学上软弱，但不足以分选出岩浆。可萃取的岩浆大约需要 20–25% 的熔体，即晶体停止接触、浆变得可动的那个分数。
:::
:::

熔岩石只有三种办法，而每一种留下一个可区分的签名。

**减压熔融。**橄榄岩的固相线随压力以约 $10$–$13\ ^\circ\mathrm{C\,GPa^{-1}}$ 上升（橄榄石）、含石榴石的组合为 $5\ ^\circ\mathrm{C\,GPa^{-1}}$，而一块上升的地幔块体绝热地只冷却约 $0.3\ ^\circ\mathrm{C\,km^{-1}}$（$10\ ^\circ\mathrm{C\,GPa^{-1}}$）。一个地幔的上涌因此穿过它自己的固相线，并在不获得热量的情况下熔融。这就是洋中脊与地幔柱发生的事，而它产出玄武岩。

**助熔熔融。**水与二氧化碳把固相线压低几百度：一个含百分之几溶解水的橄榄岩在 2 GPa 下于 $1100$–$1200\ ^\circ\mathrm{C}$ 熔融、而不是干时的 $1700\ ^\circ\mathrm{C}$。水来自一个俯冲的板块。这就是岛弧为什么是安山质的。

**传热熔融。**一个大的镁铁质岩浆侵入体把冷的地壳熔化。据认为大多数体积上大的长英质省与许多岩基就是这样产生的，这也是镁铁质底侵与花岗质岩浆作用为什么常常是时间上的伙伴。

::: example 一个洋脊造出多少熔体？ {#ex-decompression}
一个洋中脊的地幔上升并在 $10\ ^\circ\mathrm{C\,GPa^{-1}}$ 下从 $3\ \mathrm{GPa}$ 绝热减压到地表。取干尖晶石橄榄岩固相线为 $T_s(P) = 1200 + 130\,P$（$^\circ\mathrm{C}$ 与 GPa），位温为 $\theta_p = 1350^\circ\mathrm{C}$。熔融在什么压力下开始，结果大约多少熔体分数？
::: solution
从位温 $\theta_p = 1350^\circ\mathrm{C}$ 出发的绝热线是 $T(P) = 1350 + 10\,P$。熔融在绝热线遇到固相线之处开始：
$$
1350 + 10P = 1200 + 130P \quad\Longrightarrow\quad 150 = 120P \quad\Longrightarrow\quad P = 1.25\ \mathrm{GPa}.
$$
熔融因此在约 $1.25\ \mathrm{GPa}$、约 $38\ \mathrm{km}$ 深处开始，并持续到地表。熔体分数由绝热线与固相线之间有多少焓可用决定。过剩的温度从 $1.25\ \mathrm{GPa}$ 处的 $0$ 线性增长到地表的 $150\ \mathrm{K}$，所以它在整个熔融柱上的平均是 $75\ \mathrm{K}$；以熔化潜热约 $L = 400\ \mathrm{kJ\,kg^{-1}}$、热容 $c_p = 1300\ \mathrm{J\,kg^{-1}\,K^{-1}}$，
$$
F \approx \frac{c_p\,\overline{\Delta T}}{L} = \frac{1300\times75}{4\times10^{5}} = 0.24 .
$$
大约四分之一的地幔熔融——与洋脊之下萃取的 20–30% 一致，也与一个 60 km 厚的大洋地壳大约需要从一个 200 km 厚的熔融区域取出那个分数这一事实一致。
:::
:::

## 微量元素：熔融作为一个分离过程

::: proposition 批式熔融与分离熔融 {#prop-melting-eqns}
设 $C_0$ 是某微量元素在源区中的浓度，$D_0 = \sum_i w_i K_D^i$ 是源区矿物与熔体之间的总分配系数，$F$ 是熔体分数。则对**批式（平衡）熔融**
$$
\frac{C_L}{C_0} = \frac{1}{D_0 + F(1 - D_0)},
$$
而对**分离熔融**，其中每一分熔体一形成就被移走，
$$
\frac{C_L}{C_0} = \frac{1}{D_0}\,(1 - F)^{(1/D_0) - 1}, \qquad
\frac{C_S}{C_0} = (1 - F)^{(1/D_0) - 1}.
$$
对一个强不相容的元素（$D_0 \ll 1$）在小 $F$ 时，批式的浓度趋于 $1/(D_0 + F)$，而两条曲线在最小的熔体分数处分歧最强。
:::

::: proof
**批式。**一单位的源区含 $F$ 的液体与 $1-F$ 的固体，处于平衡中，所以 $C_S = D_0 C_L$。质量平衡给出 $C_0 = FC_L + (1-F)C_S = C_L[F + (1-F)D_0]$，即批式的结果。

**分离式。**残留的固体持有该元素的 $(1-F)C_S$；移走一个成分为 $C_L = C_S/D_0$ 的分增量 $\mathrm{d}F$ 给出
$$
\mathrm{d}\left[(1-F)C_S\right] = -\frac{C_S}{D_0}\,\mathrm{d}F
\quad\Longrightarrow\quad
(1-F)\,\mathrm{d}C_S = C_S\,\frac{D_0 - 1}{D_0}\,\mathrm{d}F .
$$
分离变量并从 $F = 0$ 处的 $C_S = C_0$ 积分，
$$
\ln\frac{C_S}{C_0} = \frac{D_0-1}{D_0}\int_0^F\frac{\mathrm{d}F}{1-F} = \frac{1-D_0}{D_0}\ln(1-F),
$$
即固体的曲线；除以 $D_0$ 得液体。注意它与分离**结晶**的不对称，后者的对应结果是 $C_L/C_0 = D^{\,F^{(1/D)-1}}$、$F$ 是剩余液体的分数：两者常被混淆，因为它们都是瑞利过程，但被移走的质量是相反的相。
:::

::: example 部分熔融造成的富集 {#ex-batch}
一个不相容元素在一个尖晶石橄榄岩源区中有 $D_0 = 0.01$。求 $F = 0.001$、$0.01$ 与 $0.20$ 时批式熔融的 $C_L/C_0$，以及 $F = 0.01$ 时分离熔融的同样比值。
::: solution
批式：$C_L/C_0 = 1/[0.01 + F(0.99)]$。
$$
F = 0.001:\ \frac{1}{0.01 + 0.00099} = 90.9; \qquad
F = 0.01:\ \frac{1}{0.01 + 0.0099} = 50.2; \qquad
F = 0.20:\ \frac{1}{0.01 + 0.198} = 4.78 .
$$
$F = 0.01$ 时的分离式：
$$
\frac{C_L}{C_0} = \frac{1}{0.01}(0.99)^{99} = 100\times0.370 = 37.0 .
$$
三课教训。在极小的熔体分数处富集是巨大的——一块千分之一熔融的岩石造出一个比源区在其不相容元素上富九十倍的液体。一旦 $F \gg D_0$，它按 $F$ 的倒数下降，所以最极端的富集需要最小程度的熔融。而在同样的 $F$ 下分离熔融给出的富集*少于*批式，因为早期的、最富的液体被移走、无法再被浓缩；两条曲线在低 $F$ 处的分别是地球化学家判定熔融如何发生的主要办法之一。
:::
:::

::: history
吉布斯1876年在《康涅狄格学院院刊》中陈述了相律，在一篇关于多相物质平衡的论文里，而它二十年无人问津；鲁泽布姆在1880年代提供了图解法并把用于盐类系统；而这套方法是通过物理冶金——罗伯茨-奥斯汀做出的铁碳图与二十世纪初的合金表——到达地质学的。鲍林在卡内基研究所始于1913年的一系列研究中把它带入岩石学：二元系统透辉石–钙长石与镁橄榄石–硅石、反应系列，以及1928年的《火成岩的演化》，书中论证整个火成岩套可以通过部分熔融与结晶分异从一个玄武质的母岩派生。实验方法——从1960年代起达到几个吉帕的活塞圆筒装置、达到 25 GPa 的多顶压机，以及含水系统的内加热高压容器——把相图变成定量的地温计、并使地幔的岩石学成为可能。本章的后一半，微量元素的算术，在1970年代随格雷厄姆与弗雷、哈特与辛德勒、阿莱格尔与本奥曼对平衡与分离熔融的模拟而来。
:::

## 通向何处

相图是岩石学课程其余部分的语法：[[mineralogy-petrology/magma-evolution]]把它们用于真实的岩浆，[[mineralogy-petrology/igneous-settings]]把由此产生的化学读回板块构造，而[[mineralogy-petrology/metamorphic-reactions]]是同一个几何学、在压力–温度平面而不是温度–成分平面上。相图背后的热力学在[[geochemistry/reactions]]中，而造出玄武岩的地幔熔融在[[geophysics/heat-flow]]的地幔对流背景下算出。

::: summary
- 相律 $F = C - P + 2$ 是一次计数、不是一个近似；在一个固定压力的凝聚系统中它是 $F = C - P + 1$，而它告诉你一个组合何时钉住压力与温度。
- 在一个简单共熔系统中，液体在单一相结晶的同时沿液相线朝共熔成分向下移动，然后两个相在恒温下一起结晶。
- 杠杆规则是质量平衡：相的体积比是连接线上被总成分分开的两臂的反比。
- 类质同象用一个液相线与固相线之间的两相带取代共熔点，并产生环带；长时间的扩散会抹去它，这使环带成为一个热年代计。
- 岩石在一个范围上熔融，而最初的液体总是可用的最易熔的那个。熔融只有三种办法：减压、助熔与传热。
- 微量元素遵循批式与分离熔融方程；最极端的富集记录最小的熔体分数，而图案的形状记录熔融如何发生。
:::

## 练习题

::: exercise 自由度 {level=1 check="0"}
在一个固定压力的二组分凝聚系统中，三个相共存。有多少自由度？
::: solution
$F = C - P + 1 = 2 - 3 + 1 = 0$。这个组合是无变量的：它在一个温度与一个成分下存在，而这正是一个共熔点的定义。
:::
:::

::: exercise 杠杆规则 {level=1 check="0.4"}
在一个二元共熔系统中，一个总成分为 40% B 的系统落在一个两相区中，其中液体含 20% B、晶体含 80% B。系统有多少分数是液体？
::: solution
$w_\text{liq} = (X_\text{xtal} - X_0)/(X_\text{xtal} - X_\text{liq}) = (80 - 40)/(80 - 20) = 40/60 = 0.40$。
:::
:::

::: exercise 纯物质的熔点 {level=1 check="1"}
为什么一个纯矿物在固定压力下有一个尖锐的熔点、而一块岩石没有？
::: solution
对一个组分、两个相在固定压力下，$F = 1 - 2 + 1 = 0$：没有一个变量能被改变，所以熔融发生在单一的温度上。一块岩石有许多组分，所以在有液体与固体存在时 $F \ge 1$、而平衡温度依赖于成分——随着熔融进行，成分连续地改变。因此是固相线与液相线，而不是一个熔点。
:::
:::

::: exercise 读一个共熔图 {level=2}
在透辉石–钙长石系统中，一个 $\mathrm{Di}_{58}\mathrm{An}_{42}$ 成分的岩石与一个 $\mathrm{Di}_{80}\mathrm{An}_{20}$ 的都被缓慢冷却。比较它们的结构。
::: solution
第一个恰好是共熔成分：它完全在 $1274^\circ\mathrm{C}$ 结晶，斜长石与透辉石同时出现，给出一个细粒的、等粒的、紧密的交生、没有斑晶。第二个在共熔点的透辉石一侧，所以透辉石在约 $120\ \mathrm{K}$ 的冷却中先结晶、形成显眼的颗粒，而残余的液体随后在 $1274^\circ\mathrm{C}$ 固结为一个共熔交生。两种结构恰好以相图预测的方式不同：第二个是斑状或嵌晶的，第一个是粒状的共熔的——而这最初就是相图被定位的方式，通过看岩石。
:::
:::

::: exercise 分配系数 {level=2 check="115"}
镍在橄榄石与玄武质液体之间以 $K_D^{\mathrm{Ni}} = (\mathrm{Ni}/\mathrm{Mg})_\text{ol}/(\mathrm{Ni}/\mathrm{Mg})_\text{liq} = 1.6$（在 $1300^\circ\mathrm{C}$）分配，比值按质量。一个液体含 $8.0\ \mathrm{wt}\%$ 的 MgO 与 $12\ \mathrm{ppm}$ 的 Ni。与它平衡的橄榄石的 Ni 含量是多少，以 ppm 计，设橄榄石含 $48\ \mathrm{wt}\%$ 的 MgO？（以 ppm 输入 Ni 含量。）
::: solution
液体的比是 $(\mathrm{Ni}/\mathrm{Mg})_\text{liq} = 12/8.0 = 1.5\ \mathrm{ppm}$ 的 Ni 每 $\mathrm{wt}\%$ 的 MgO。与它平衡的橄榄石必须有
$$
(\mathrm{Ni}/\mathrm{Mg})_\text{ol} = 1.6\times1.5 = 2.4\ \mathrm{ppm\ per\ wt\%},
\qquad
\mathrm{Ni}_\text{ol} = 2.4\times48 = 115\ \mathrm{ppm}.
$$
天然的富镁橄榄石含 48–50 wt% 的 MgO，确实携带 1500–4000 ppm 的 Ni，所以一个含 12 ppm Ni 的液体是分异得有些多的、而不是原始的：一个原始的地幔熔体含 15 wt% 的 MgO、会携带约 150 ppm 的 Ni、而会与持有约 1400 ppm 的橄榄石平衡。这正是用来检验一个玄武岩是否是原始熔体的计算，也是橄榄石的 Ni 与 Mg# 在每一篇岩石学论文中被一起作图的原因。
:::
:::

::: exercise 洋中脊的富集 {level=2 check="10.3"}
一个不相容元素在 MORB 源区的橄榄岩中有 $D_0 = 0.05$。用批式熔融，求 $F = 0.05$ 与 $F = 0.30$ 时的 $C_L/C_0$。（给出 $F = 0.05$ 时的比值。）
::: solution
$C_L/C_0 = 1/[0.05 + 0.05\times0.95] = 1/0.0975 = 10.3$（在 $F = 0.05$），而 $1/[0.05 + 0.30\times0.95] = 1/0.335 = 3.0$（在 $F = 0.30$）。脊的玄武岩之所以亏损，恰恰因为它们是高度熔融的产物，而洋岛玄武岩来自石榴石场更深处、较小程度的熔融，是富集的。
:::
:::

::: exercise 哪个熔融模型？ {level=2}
两个模型预测一个熔体中一个不相容元素的浓度。还有什么别的观察能区分它们，为什么？
::: solution
看**两个 $D_0$ 不同的不相容元素的比**，以及熔体的**主量元素成分**。批式与分离熔融在低 $F$ 时对元素对的分馏不同：分离熔融产生的液体在最不相容的元素上相对于一个稍不不相容的元素更极端，因为最早的液体被移走、从不重新平衡。主量元素独立地约束 $F$，因为熔体的 MgO 与 SiO$_2$ 记录了多少橄榄石与辉石被留下。把两者合起来——一个要求非常小的 $F$ 的微量元素比，与一个要求大的主量元素成分——是孔隙（通道化的）流动、而不是任何一个端元模型的经典证据。
:::
:::

::: exercise 湿与干 {level=2 check="500"}
2 GPa 下干橄榄岩的固相线约 $1700^\circ\mathrm{C}$；一个被富 $\mathrm{H_2O}$ 流体饱和的橄榄岩在同样压力下约 $1200^\circ\mathrm{C}$ 熔融。水把固相线压低了多少度，而这对岛弧为什么重要？
::: solution
约 $500\ ^\circ\mathrm{C}$。水以 $\mathrm{OH}^{-}$ 进入熔体、打断 $\mathrm{Si–O–Si}$ 桥，并剧烈降低硅酸盐液体相对于固体的活度，所以熔融在低得多的温度上变得有利。在一个俯冲带中，板块在 80 到 120 公里深处脱水，水上升到它之上较冷的地幔楔中，而助熔熔融在那里开始——这就是弧火山为什么坐在海沟之后约 100 公里处，也是弧岩浆为什么是湿的、氧化的与安山质的。
:::
:::

::: exercise 一个转熔反应 {level=3}
用矿物名写出镁橄榄石–硅石的转熔反应，并解释它为什么使地球的上地幔硅不饱和、而地壳硅饱和。
::: solution
$$
\mathrm{Forsterite} + \mathrm{Silica\ (in\ liquid)} \longrightarrow \mathrm{Enstatite}, \qquad
\mathrm{Mg_2SiO_4} + \mathrm{SiO_2} \longrightarrow \mathrm{Mg_2Si_2O_6},
$$
在 $1557^\circ\mathrm{C}$、1 bar。原子平衡：两边各两个镁、两个硅与六个氧。这个反应消耗自由的硅石，所以任何通过熔融一个尖晶石二辉橄榄岩（60% 橄榄石、20% 斜方辉石、15% 石榴石或尖晶石）造出的熔体，在穿过它路过的橄榄石时立即被反应缓冲、远离硅饱和。地幔因此是强烈硅不饱和的，而它的熔体是玄武质的、石英标准矿物负的。地壳相反是许多这样的反应进行到底的产物，是移走镁与铁的分离结晶的产物，也是脱水的产物——而它最终硅饱和到过饱和，石英是其中一半以上岩石的模式矿物。
:::
:::

::: exercise 为两个组分推导批式方程 {level=3}
对一个固体相成分为 $X_S$、液体成分为 $X_L$ 的二元共熔系统，证明一个源区 $X_0$ 平衡（批式）熔融产生的熔体分数为 $F = (X_0 - X_S)/(X_L - X_S)$，并把它与杠杆规则和微量元素方程调和起来。
::: solution
对该组分做质量平衡：$X_0 = FX_L + (1-F)X_S$，所以 $F = (X_0 - X_S)/(X_L - X_S)$。这*就是*杠杆规则，为液体分数写出的、而不是从它导出的——两者是同一个论断。

要与 $C_L/C_0 = 1/[D_0 + F(1-D_0)]$ 调和，把微量元素的分配系数写成 $D_0 = C_S/C_L$，并注意微量元素稀到不改变 $X_S$、$X_L$ 或 $F$：主量元素的杠杆规则由相的成分固定 $F$，而微量元素方程随后给出该 $F$ 下液体中的浓度。两个方程按顺序使用、不是同时——这就是一个岩石学家能由主量元素算出一个熔体分数、然后用它解释微量元素的原因，也是如果微量元素浓到改变相关系（百分之几以上，那是"微量"化学停止、主量元素岩石学开始的地方）整套方法为什么失败的原因。
:::
