地球每造一颗火成岩就销毁一千颗，而那销毁的一千颗比造出的一颗更多样。洋岛玄武岩、安山岩、英安岩、流纹岩、苦橄岩、科马提岩、碳酸岩、云母岩，以及布什维尔德的层状堆晶岩——全部来自一个压倒性地是方辉橄榄岩与二辉橄榄岩的地幔。火成岩岩石学是对那个转变的研究，而它建立在四个过程之上：源区的哪一部分熔融，哪些晶体离开液体，岩浆在上涌途中熔融或反应掉什么，以及它遇到另一个岩浆时与什么混合。

描述整体的词是**分异**，而陷阱是把它当作一件事。一个玄武岩在上升穿过 30 km 的花岗岩时，可以向底板失去橄榄石、从围岩获得硅石、与第二批更热的玄武岩混合、并在路上脱气出水——而这几样每一个都在岩石中留下一个不同的、可以分开读的签名。

## 原始岩浆与液体演化线

::: definition 原始、原始性与派生岩浆 {#def-primary}
一个**原始岩浆**与它来自的地幔组合平衡——具体说，与一个地幔镁质的橄榄石（$\mathrm{Fo}_{88\pm2}$）平衡——尽管它不必是地幔的一个*总体*熔体。一个**原始岩浆**自隔离以来没有遭受分离结晶或混染，但可以是若干原始熔体的混合物。一个**派生岩浆**被修改过。**液体演化线**是一个岩浆的成分随晶体被移走所走的路径，而火成岩岩石学的大部分就是被吸引去重建它。
:::

::: definition 总分配系数 {#def-bulk-d}
对一个结晶出一组质量分数为 $w_i$ 的相的岩浆，以及一个在每个相与液体之间具有能斯特分配系数 $K_D^i$ 的微量元素 $i$，**总分配系数**为
$$
D = \sum_i w_i K_D^i .
$$
一个 $D \ll 1$ 的元素是**不相容的**、留在液体中；一个 $D \gg 1$ 的是**相容的**、被剥离。在玄武岩系统中最重要的值，在 1 atm 与玄武质的温度下，大致是：Ni 的 $K_D^{\text{ol}} \approx 10$–18，Cr 的 $K_D^{\text{crn}} > 30$，钴与钒在橄榄石中 3–8，锶在斜长石中 1.3–2.0，铕在斜长石中 1.5–2.0（这就是铕异常是一个斜长石指纹的原因），稀土在橄榄石与辉石中小于 0.1，而 Zr、Nb、Ta、Th 与轻稀土在任何无水硅酸盐中小于 0.02。
:::

::: proposition 瑞利分离结晶 {#prop-rayleigh}
设 $F$ 是剩余液体的分数、$D$ 是总分配系数、并假定其恒定。如果晶体一形成就被移走、从不重新平衡，液体中一个微量元素的浓度为
$$
\frac{C_L}{C_0} = F^{\,(D-1)} ,
$$
其中 $C_0$ 是初始液体中的浓度。相容的元素（$D > 1$）按 $F^{\,D-1}$ 衰减掉；不相容的元素（$D < 1$）按 $F^{\,1-D}$ 上升，而它们上升、并且当 $F \to 0$ 时无限地上升。
:::

::: proof
液体的质量为 $M$、浓度为 $C_L$，所以它持有该元素的 $MC_L$。结晶出质量为 $-\mathrm{d}M$、成分为 $DC_L$ 的固体，移走该元素的 $-DC_L\,\mathrm{d}M$，所以
$$
\mathrm{d}(MC_L) = -D C_L\,\mathrm{d}M
\quad\Longrightarrow\quad
M\,\mathrm{d}C_L + C_L\,\mathrm{d}M = -D C_L\,\mathrm{d}M
\quad\Longrightarrow\quad
\frac{\mathrm{d}C_L}{C_L} = -(D-1)\frac{\mathrm{d}M}{M}.
$$
从 $M_0$、$C_L = C_0$ 积分，并写 $F = M/M_0$，得 $\ln(C_L/C_0) = -(D-1)\ln F$，即所求。同样的推导、把相留在原地，给出平衡（批式）结晶律 $C_L/C_0 = 1/[D + F(1-D)]$，它与瑞利律在小 $F$ 与小 $D$ 处差别最大——同一个区别，出于同一个原因，如[[mineralogy-petrology/phase-diagrams]]中。
:::

::: example 镍作为一支橄榄石的地温-气压计 {#ex-ni}
一个玄武岩含 $250\ \mathrm{ppm}$ 的 Ni 与 $12\ \mathrm{wt}\%$ 的 MgO。$\mathrm{Fo}_{90}$ 的橄榄石结晶并被移走；橄榄石占结晶组合的 15%、而 $K_D^{\mathrm{Ni}} = 14$。求一半液体结晶时的 Ni 含量，以及只剩五分之一时的。
::: solution
总分配系数为 $D = 0.15\times14 = 2.1$。于是 $C_L/C_0 = F^{1.1}$：
$$
F = 0.50:\quad \frac{C_L}{C_0} = 0.50^{1.1} = 0.467, \qquad \mathrm{Ni} = 117\ \mathrm{ppm};
$$
$$
F = 0.20:\quad \frac{C_L}{C_0} = 0.20^{1.1} = 0.170, \qquad \mathrm{Ni} = 43\ \mathrm{ppm}.
$$
现在是有用的反演。原始的地幔熔体在 $13\ \mathrm{wt}\%$ 的 MgO 下持有约 $350\ \mathrm{ppm}$ 的 Ni，而它们的橄榄石携带 $2500$–$3500\ \mathrm{ppm}$ 的 Ni。一个 $250\ \mathrm{ppm}$ Ni、12 wt% MgO 的液体因此接近原始的，而一个 $43\ \mathrm{ppm}$ Ni 的液体仅靠橄榄石的分异就失去了它五分之四的液体。这就是镍与氧化镁为什么总是被一起作图、橄榄石的 Ni–Mg# 为什么是原始性的标准检验，以及一个玄武岩的 MgO 单独几乎不关于它的源区说什么的原因。
:::
:::

::: widget plot

x: 0.02, 1
y: 0, 12
labels: \text{compatible } D=2.1; \text{incompatible } D=0.10; \text{weakly incompatible } D=0.5
caption: 一个相容的、一个强不相容的与一个轻度不相容的元素的瑞利结晶曲线，作为 $C_L/C_0$ 对剩余液体的分数。相容的元素早期崩溃，这就是铬与镍从分异得多的派生岩中消失的原因；强不相容的元素到 $F = 0.1$ 上升一个数量级；而轻度不相容的元素几乎不动，这就是 $D$ 接近一的元素作为分异指标无用、而作为源区示踪剂极好的原因。注意三条曲线都在 $F = 1$ 处经过 1：没有结晶，就没有分馏。
:::

## 主量元素：质量平衡，不是模拟

微量元素的算术是优雅的，但液体演化线是用主量元素画的，而主量元素只服从一条定律——质量平衡。

::: example 移走百分之二十的橄榄石 {#ex-mass-balance}
一个 $50.0\ \mathrm{wt}\%$ $\mathrm{SiO_2}$、$12.0\ \mathrm{wt}\%$ MgO 的玄武岩失去 20 wt% 的 $\mathrm{Fo}_{90}$ 橄榄石。求液体的新成分，并评论结果。
::: solution
$\mathrm{Fo}_{90}$ 橄榄石是 $0.9\,\mathrm{Mg_2SiO_4} + 0.1\,\mathrm{Fe_2SiO_4}$，即 $51.6\ \mathrm{wt}\%$ 的 MgO 与 $42.7\ \mathrm{wt}\%$ 的 $\mathrm{SiO_2}$。从一个成分为 $C_0$ 的液体中移走一个成分为 $C_p$ 的相的分数 $X$，留下
$$
C_L = \frac{C_0 - X C_p}{1 - X}.
$$
所以
$$
\mathrm{MgO} = \frac{12.0 - 0.20\times51.6}{0.80} = \frac{1.68}{0.80} = 2.1\ \mathrm{wt}\%,
\qquad
\mathrm{SiO_2} = \frac{50.0 - 0.20\times42.7}{0.80} = \frac{41.5}{0.80} = 51.8\ \mathrm{wt}\%.
$$
百分之二十的橄榄石把岩浆从一个玄武岩变成一个高硅、贫镁的液体，而把硅石提高了不到两个百分点。那个不对称正是要点：**橄榄石的分异是一个移除镁的壮观办法、一个制造硅石的糟糕办法**，因为橄榄石本身含 43% 的硅石。要从玄武岩造出安山岩，你还必须移走斜长石、辉石与氧化物，而且要以没有任何一条单一的液体演化线免费提供的比例。这就是安山岩问题——大陆地壳在 $56$–$62\%$ $\mathrm{SiO_2}$ 处一个巨大的、全球的、双峰的分布、在 $50$–$53\%$ 处的亏损——在一个世纪的岩石学之后仍然存在的原因。
:::
:::

::: definition 热分界 {#def-thermal-divide}
在约 $52\ \mathrm{wt}\%$ $\mathrm{SiO_2}$ 之下，在 1 atm 结晶的玄武质液体遵循两种趋势之一。在**拉斑**趋势上，铁随着镁下降而继续在液体中富集，因为橄榄石与随后的小辉石被移走、而氧逸度低到铁保持二价的；残余液体是富铁的，而在终点硅过饱和的、长英质的。在**钙碱性**趋势上，铁在镁下降时大致保持不变，因为磁铁矿结晶并剥离 $\mathrm{Fe^{3+}}$，而残余液体是硅不饱和的、含水的。两种趋势在**热分界**处不可逆地分开，而一个岩浆遵循哪一条由它的含水量与它的氧逸度早期设定、不是由它分异了多远设定。
:::

::: example 哪个趋势？ {#ex-trend}
两个岩套都从 $50\ \mathrm{wt}\%$ $\mathrm{SiO_2}$、$10\ \mathrm{wt}\%$ MgO 与 $9\ \mathrm{wt}\%$ $\mathrm{FeO^*}$ 出发。岩套 A 在 $56\ \mathrm{wt}\%$ $\mathrm{SiO_2}$ 处有 $4.0\ \mathrm{wt}\%$ 的 $\mathrm{FeO^*}$；岩套 B 有 $9.5\ \mathrm{wt}\%$。给它们分类并说明每一个关于环境的含义。
::: solution
把 $\mathrm{FeO^*}/\mathrm{MgO}$ 对 $\mathrm{SiO_2}$ 作图（欧文-巴思指数）。岩套 A 在失去镁的同时*失去*了铁，所以它的 $\mathrm{FeO^*}/\mathrm{MgO}$ 保持低：**钙碱性**。岩套 B 在演化时富集了铁，所以它的比陡峭地爬升：**拉斑**。

环境跟着来。拉斑岩来自干的、还原的、高度熔融：洋中脊、大火成岩省、弧后盆地。钙碱性岩套来自一个板块之上地幔楔中湿的、氧化的、低程度的熔融，而它们是大陆边缘与岛弧的诊断岩石。铁的区别是一个氧化态的区别：在高二到三个对数单位的氧逸度下，铁以 $\mathrm{Fe^{3+}}$ 被带进磁铁矿、并从液体中剥离、而不是在其中累积。那个区别是从源区与板块流体继承的、不是在分异期间获得的——这就是两种趋势不能靠任何程度的晶体分选由一个产生另一个的原因。
:::
:::

## 同化：热是极限

一个岩浆上升穿过冷的围岩并把它熔化，而熔体加入岩浆。这个过程叫**同化**，而分离结晶与同化的组合叫 **AFC**。约束不是化学、是热，而它是残酷的。

::: example 一个玄武岩能同化多少围岩？ {#ex-heat}
一个 $1200^\circ\mathrm{C}$ 的玄武岩侵入一个 $50^\circ\mathrm{C}$ 的围岩。取玄武岩的 $c_p = 1200\ \mathrm{J\,kg^{-1}\,K^{-1}}$、围岩的 $1000\ \mathrm{J\,kg^{-1}\,K^{-1}}$、结晶潜热 $400\ \mathrm{kJ\,kg^{-1}}$。一公斤玄武岩如果冷却到 $1000^\circ\mathrm{C}$ 并结晶它自己的 30%，能把多少公斤围岩从 $50$ 加热到 $1000^\circ\mathrm{C}$？如果围岩要真的熔融，还有多少可用？
::: solution
一公斤玄武岩释放的热是显热与潜热两项之和：
$$
q = c_p\Delta T + X L = 1200\times200 + 0.30\times4\times10^{5} = 2.4\times10^{5} + 1.2\times10^{5} = 3.6\times10^{5}\ \mathrm{J}.
$$
把围岩从 50 加热到 $1000^\circ\mathrm{C}$ 花费 $1000\times950 = 9.5\times10^{5}\ \mathrm{J\,kg^{-1}}$，所以
$$
m = \frac{3.6\times10^{5}}{9.5\times10^{5}} = 0.38\ \mathrm{kg}
$$
的围岩每公斤玄武岩——同化比约为最终混合物的 28%。要真的*熔化*那些岩石还要多花 $150$–$200\ \mathrm{kJ\,kg^{-1}}$ 的熔化潜热，把比降到 $3.6\times10^{5}/1.13\times10^{6} = 0.32$。

三个后果。第一，一个单一的、封闭的、冷却的侵入体只能同化它自己质量的百分之几十，而同化更大的同位素证据因此是**补给**的证据：岩浆房被新鲜的热线岩浆补充过许多次。第二，最靠近侵入体的围岩是热被花掉的地方，这就是污染最多的样品在边缘、而一个分带的侵入体显示一个分带的同位素比的原因。第三，结晶潜热与整个显热预算相当，这就是结晶驱动同化、而不只是伴随同化的原因。
:::
:::

## 混合：双曲线，不是直线

::: proposition 二元混合 {#prop-mixing}
把分数为 $f$ 的岩浆 A（微量元素浓度 $C_A$、同位素比 $R_A$）与 $1-f$ 的岩浆 B（$C_B$、$R_B$）混合。则
$$
C_m = fC_A + (1-f)C_B, \qquad
R_m = \frac{fC_AR_A + (1-f)C_BR_B}{fC_A + (1-f)C_B},
$$
而同位素比是按*元素*的浓度、不是按质量的分数加权的，所以 $R_m$ 对 $1/C_m$ 的一张图是一条**双曲线**、不是直线。只有当两个端元有相似的浓度时才出现直线混合。
:::

::: example 地壳混染还是地幔非均质性？ {#ex-mixing}
亏损地幔的玄武岩有 $\mathrm{Sr} = 200\ \mathrm{ppm}$、$^{87}\mathrm{Sr}/^{86}\mathrm{Sr} = 0.7035$；它穿过的花岗岩有 $\mathrm{Sr} = 800\ \mathrm{ppm}$、$^{87}\mathrm{Sr}/^{86}\mathrm{Sr} = 0.7120$。求一个 30% 玄武岩与 70% 花岗岩混合物的锶含量与同位素比，以及把比值移到 $0.7080$ 所需的花岗岩的分数。
::: solution
对 30:70，
$$
C_m = 0.3\times200 + 0.7\times800 = 620\ \mathrm{ppm},
$$
$$
R_m = \frac{0.3\times200\times0.7035 + 0.7\times800\times0.7120}{620} = \frac{42.2 + 398.7}{620} = 0.7112 .
$$
对第二部分，设 $R_m = 0.7080$、$f$ 为玄武岩的分数：
$$
\frac{140.7f + 569.6(1-f)}{200f + 800(1-f)} = 0.7080
\quad\Longrightarrow\quad
569.6 - 428.9f = 566.4 - 424.8f
\quad\Longrightarrow\quad
f = 0.78 .
$$
所以**22% 的花岗岩同化把同位素比从 $0.7035$ 移到 $0.7080$**——一个 $0.0045$ 的移动，而分析精度约 $0.00002$——而锶含量只从 200 取到 $332\ \mathrm{ppm}$。那个不对称是同位素比是如此灵敏的污染探测器、又是如此糟糕的混合比例计的原因：一块岩石可以在岩石学上看起来未受改变、而在同位素上被毁掉。这也是对一个混合双曲线的正确解释需要比值与浓度两者、以及一条穿过同位素数据的直线通常意味着有人把比对另一个比作图的原因。
:::
:::

::: warning 岩浆混合不是一个比喻，也不是由一个散点图证明的
混合由结构、由不可能平衡共存的相的共存来证明：被熔蚀与筛状的石英，倒转的成分环带（一个富铁核上的富镁边），在一个分异宿主中的、具有地幔式 $\mathrm{Mg\#}$ 的异晶核，以及一个矿物与它周围基质之间的不平衡。经典的例子是圣海伦斯1980年的英安岩，它的浮岩含有暗的、基性的、高镁的包体，其玻璃成分落在一个安山岩与一个玄武岩之间的直线混合线上——物理的混合被当场抓住。一个哈格图上弯曲的趋势*与*混合、*与*分离结晶、*与*源区非均质性都一致，而它凭自己一个都不区分。
:::

::: quiz
一个玄武岩与它的分异产物在一张 MgO 对 $\mathrm{SiO_2}$ 的图上落在一条直线上。这证明了什么？
- [ ] 两块岩石是同源的、由分离结晶联系。
- [ ] 两块岩石是两个端元的混合物。
- [x] 凭它自己什么也不证明；这条线与几个过程都一致。
- [ ] 岩浆在喷发前混合得很好。
::: solution
哈格图的图线是一个高维历史到两个轴上的投影。分离结晶、同化、混合、变化程度的部分熔融与源区非均质性都产生平滑的图线，而其中许多在它们范围的一部分上产生直的。这条图线是一个假说；检验是矿物化学、结构、微量元素与同位素合起来。
:::
:::

## 岩浆在哪里造出，为什么种类这么少

三个事实组织整个主题。第一，地幔只靠减压、助熔或加热熔融，而每一种给出一个特征性的岩浆（见[[mineralogy-petrology/phase-diagrams]]）。第二，大多数玄武岩是 15–30% 熔融的产物，这是一个大数字：不相容的元素早已被强烈地分馏，这就是洋中脊玄武岩是*亏损*的、而不是富集的原因。第三，也是最重要的，中间与长英质岩石的绝大部分根本不是靠熔融地幔造出的，而是靠一个已经是玄武岩的东西的分异与重熔。

::: example 下地壳能被重熔造出安山岩吗？ {#ex-anatexis}
10 kbar 下的角闪岩（变玄武岩）约在 $800^\circ\mathrm{C}$ 靠反应 $\mathrm{amphibole} + \mathrm{plagioclase} \to \mathrm{clinopyroxene} + \mathrm{plagioclase}_{\text{more sodic}} + \mathrm{H_2O}_{\text{(in\ melt)}}$ 开始熔融，并产生英云闪长质的液体。如果 $10\ \mathrm{km}$ 的这样的地壳被底侵在其底部的玄武岩加热、并经历 10% 的熔融，那每平方公里的弧造出多少岩浆，而它相当于典型弧产量的多少年？
::: solution
十公里的地壳、10% 的熔体，给出一个 $1\ \mathrm{km}$ 厚的熔体层，即每平方公里的弧 $1\ \mathrm{km^3}$ 的岩浆。成熟的陆弧每公里弧走向每百万年堆积 $0.5$–$2\ \mathrm{km^3}$ 的岩浆；跨过一条 $100\ \mathrm{km}$ 宽的弧，那是每百万年 $50$–$200\ \mathrm{km^3}$，即每平方公里每百万年 $0.5$–$2\ \mathrm{km^3}$，或者说每 $100$–$200$ 平方公里每百万年 $1\ \mathrm{km^3}$。按单位面积表示，一次深部地壳 10% 熔融的事件因此供给
$$
\frac{1\ \mathrm{km^3\,km^{-2}}}{0.01\ \mathrm{km^3\,km^{-2}\,Myr^{-1}}} = 100\ \mathrm{Myr}
$$
的弧岩浆作用。预算因此是宽裕地闭合的：地壳深熔能够供给安山岩与英云闪长岩，而不必把每一块中间岩石都由一个玄武岩的分离结晶派生出来。

现代的观点是两者都对、而它们在不同的层次上运作。玄武岩被加到地壳的底部，它的一部分分异成安山岩、一部分熔化地壳造出更长的液体，而两者在上涌途中混合。喷发的安山岩是总和，而关于比例的争论在锶与钕的同位素中、在锆石的氧同位素中进行——在 $\delta^{18}\mathrm{O}$ 中高于 $+8\ \%$ 的一个值意味着这颗锆石是从熔化的地表物质中生长的，无论岩石的其余部分说什么。
:::
:::

::: history
鲍林在1913年到1928年间用实验确立了分离结晶，并在《火成岩的演化》中论证一个单一的母岩能够给出整个火成岩套——这个观点被他的后继者不断收窄，到1950年代，很少有岩石学家相信任何东西是派生的。修正来自洋底：赫斯关于脊的玄武岩是原始液体的预言被拖网采样证实、随后被洋中脊的深钻证实，而布赖恩1970年代在雷克雅内斯脊的工作把脊变成熔融与混合的一个定量实验室。这个领域的仪器分三步到达：戈尔德施密特1920年代的微量元素分配定律，1951年被波尔德法特与赫斯有影响力地用于火成岩系统；从1950年代起同位素稀释与铷锶定年，使污染成为可测量的、而不是可争论的；以及弗雷及其同事1970年代的稀土模拟，随后是德保罗1981年对同化与分离结晶联合的表述，把同位素对浓度的图线变成了定量的工具。决定性的反转来自一座炉子：当阿斯与尼斯贝特在1970年代初表明高镁的科马提岩要求 $1600$–$1900^\circ\mathrm{C}$ 的喷发温度时，长期持有的、认为它们是残余液体的观点在几年之内死去，而对太古宙高度熔融的探索取代了它。
:::

## 通向何处

这里描述的岩浆在[[mineralogy-petrology/igneous-settings]]中被读回它们的环境；微量元素与同位素的机器在[[geochemistry/trace-elements]]与[[geochemistry/radiogenic-tracers]]中发展；熔融方程被用于地幔在[[geophysics/heat-flow]]中；而分异浓缩出的矿床是[[earth-resources/magmatic-hydrothermal]]的主题。

::: summary
- 一个原始岩浆与 $\mathrm{Fo}_{88\pm2}$ 的地幔橄榄石平衡；大多数玄武岩既不是原始的、甚至不是原始性的，而在对源区说任何话之前必须重建液体演化线。
- 微量元素对分离结晶遵循瑞利律 $C_L/C_0 = F^{D-1}$、对平衡结晶遵循批式律；相容的元素早期消失、而不相容的在小 $F$ 处发散。
- 主量元素只服从质量平衡。橄榄石的移走毁灭氧化镁而不造出多少硅石，这就是造安山岩是一个真问题的原因。
- 玄武岩在热分界处分成拉斑与钙碱性两条趋势线，由含水量与氧逸度控制、不由分异的程度控制。
- 同化受热限制：一个封闭的基性侵入体只能同化它自己质量的百分之几十，所以大的同位素移动记录反复的补给。
- 混合在同位素比对浓度倒数的空间中产生双曲线；一小分数放射性的混染主导同位素签名、而几乎不改变化学。
- 大部分中间地壳既由玄武岩的分异造出、也由更早的地壳的熔融造出，其比例必须由同位素、不是结构来判定。
:::

## 练习题

::: exercise 总分配系数 {level=1 check="0.75"}
一个岩浆结晶 40% 斜长石、40% 单斜辉石与 20% 橄榄石。若 $K_D^{\mathrm{Sr}}$ 在斜长石中为 1.8、在辉石与橄榄石中均为 0.05，$D^{\mathrm{Sr}}$ 是多少？
::: solution
$D = 0.40\times1.8 + 0.40\times0.05 + 0.20\times0.05 = 0.72 + 0.02 + 0.01 = 0.75$。锶的行为几乎完全由斜长石的模量控制：把它提高到 60%，$D$ 变成 $1.11$，锶就从轻度不相容变成轻度相容。仅此一个灵敏度就是锶是一个好的斜长石示踪剂、而其他任何东西的糟糕示踪剂的原因。
:::
:::

::: exercise 铬 {level=1 check="0.5"}
铬铁矿有 $K_D^{\mathrm{Cr}} \approx 100$、占结晶组合的 2%。$D^{\mathrm{Cr}}$ 是多少，而当液体的一半结晶时，液体的铬含量被降低多少倍？
::: solution
$D = 0.02\times100 = 2.0$，所以 $C_L/C_0 = F^{\,2.0-1} = F = 0.50$：铬减半。即使在结晶组合的百分之二处，铬铁矿也完全主导铬——这就是铬铁矿层在一个岩浆首次达到氧化物饱和处沉淀、铬是一个极小氧化物分异的灵敏指标、以及一个堆晶岩中百分之一的铬铁矿能够承载一个完整矿床的原因。
:::
:::

::: exercise 铕异常 {level=1 check="positive"}
一块岩石相对于它邻近的稀土有一个正的铕异常。它记录哪个过程？
::: solution
**斜长石的累积。**铕在还原的岩浆中是二价的，行为像锶，并以 $K_D \approx 1.5$–2.0 进入斜长石，而其他所有稀土保持三价、不相容。一个铕过剩的岩石因此富堆晶斜长石；一个带*负*异常的岩石是一个斜长石被从中移走的残留体——这就是总体大陆地壳有一个负铕异常、而它被读作斜长石正被埋在下地壳中的证据的原因。
:::
:::

::: exercise 移走斜长石 {level=2 check="51.2"}
一个 $50.0\ \mathrm{wt}\%$ $\mathrm{SiO_2}$、$14.0\ \mathrm{wt}\%$ $\mathrm{Al_2O_3}$ 的玄武岩失去 15 wt% 的纯钙长石 $\mathrm{CaAl_2Si_2O_8}$（$43.2\ \mathrm{wt}\%$ $\mathrm{SiO_2}$、$36.6\ \mathrm{wt}\%$ $\mathrm{Al_2O_3}$、$20.2\ \mathrm{wt}\%$ CaO）。求残余液体的硅石与氧化铝含量，以 wt% 计。
::: solution
用 $C_L = (C_0 - XC_p)/(1-X)$：
$$
\mathrm{SiO_2} = \frac{50.0 - 0.15\times43.2}{0.85} = \frac{43.5}{0.85} = 51.2\ \mathrm{wt}\%,
\qquad
\mathrm{Al_2O_3} = \frac{14.0 - 0.15\times36.6}{0.85} = \frac{8.51}{0.85} = 10.0\ \mathrm{wt}\% .
$$
硅石只上升 $1.2$ 个百分点——钙长石在硅石含量上接近一个玄武岩，所以移走它几乎不改变那个组分——而氧化铝下降近三分之一，因为钙长石比液体富铝得多。这是标准观察背后的算术：一个在硅石几乎恒定时下降的氧化铝的图线意味着斜长石的分异。这也是没有任何单一相的移走能把一个玄武岩分异得很远的原因：从一个玄武岩结晶的相都由同样十种氧化物以略不同的比例构成。
:::
:::

::: exercise 瑞利在工作 {level=2 check="0.09"}
一个元素有 $D = 3.0$。当 70% 的液体结晶时，它在液体中的浓度被降低多少倍？如果 $D$ 是 3.5 呢？
::: solution
$F = 0.30$，所以 $C_L/C_0 = 0.30^{\,3.0-1} = 0.30^{2} = 0.090$，降低十一倍。$D = 3.5$ 时是 $0.30^{2.5} = 0.047$，二十一倍。对 $D$ 的指数灵敏度是整套方法实际的困难：总分配系数上两倍的误差——在一个氧化物相的模量不确定时这完全正常——把预测的亏损改变一个数量级。这就是微量元素模型被作为趋势、而不是作为拟合引用的原因，也是两个 $D$ 相似的元素之比总是比任何一个浓度单独更有信息的原因。
:::
:::

::: exercise 从同位素求同化比 {level=2 check="0.22"}
用[[#ex-mixing]]的端元，把混合物带到 $^{87}\mathrm{Sr}/^{86}\mathrm{Sr} = 0.7080$ 需要多少分数的花岗岩？
::: solution
22%，由 $f_\text{basalt} = 0.78$。同一个混合物有 $\mathrm{Sr} = 332\ \mathrm{ppm}$，只是玄武质值的 1.7 倍，而再多 20% 的同化只会把比值再移动 $0.0008$。同位素比在化学之前很久就朝混染端饱和。
:::
:::

::: exercise 补给 {level=2}
一个层状侵入体显示一个同位素比，在它的下半部从 0.704 上升到 0.709，然后在顶部回落到 0.705，而它的镁含量在整个剖面上稳定下降。这记录什么，而为什么分离结晶单独不能解释它？
::: solution
同位素比记录**污染与然后的补给**，不是分异。一个封闭系统的分离结晶只在被移走的相与液体有不同的比值时才改变同位素比——而对一个基性岩浆中的锶，这个差别是小的，所以一个 $0.005$ 的偏移不能由晶体的移走产生。一个先升后降、而镁稳定向下的组合意味着地壳的锶在历史的中段被加入、然后被新鲜的、地幔来源的岩浆稀释，而那个岩浆同时使氧化镁不至于崩溃。同样的结论独立地来自主量元素：镁的图线对封闭系统的分异来说太平了。这是一个**由通道控制的、开放系统**的岩浆房的标准证据，也是巨大的层状侵入体被读作反复注入的产物、而不是一个单一充填空腔的产物的原因。
:::
:::

::: exercise 安山岩问题 {level=3}
大陆地壳有一个强烈的双峰成分，极大值在 46% 与 57% $\mathrm{SiO_2}$、极小值在 51% 附近。玄武岩的分离结晶产生一个连续的系列。陈述两个解决这个悖论的假说，以及区分它们的观察。
::: solution
**(i) 热分界加水。**含水、氧化的玄武质液体不能通过低压分异穿过 51–53% 的缺口，因为磁铁矿与角闪石结晶、而液体停在安山岩的成分上；这个缺口是分异路径上一个*动力学*的缺口。**(ii) 地壳再循环。**中间的峰根本不是一个分异的产物，而是地壳被下地壳中变玄武岩的脱水熔融驱动到达的成分，其熔体成分由残留的矿物组合（石榴石、单斜辉石、金红石）、而不是由母液控制。

做出区分的观察是锆石中的氧同位素与岩浆的含水量。一个地壳来源的安山岩携带 $\delta^{18}\mathrm{O}$ 高于 $+8\ \%$ 的锆石，而常常有继承的核、带太古宙或元古宙的年龄；一个地幔来源的没有。而一个含水的、氧化的、高铝的、含 4–6 wt% 溶解水的安山岩指向地幔楔，而一个热的、干的、高硅铝的、带石榴石签名的安山岩指向下地壳。两种签名都被找到，在不同的弧、在不同的时间，这就是答案是"两者，以变化的比例"的原因。
:::
:::

::: exercise 推导批式结晶律 {level=3}
为平衡（批式）结晶推导 $C_L/C_0 = 1/[D + F(1-D)]$，并证明它在 $D \to 1$ 的极限下与瑞利律一致、而在小 $F$ 时对 $D \ll 1$ 差别最大。
::: solution
在有 $F$ 的液体与 $1-F$ 的固体存在并处于平衡时，$C_S = DC_L$，而一单位系统的质量平衡给出
$$
C_0 = FC_L + (1-F)C_S = C_L\left[F + (1-F)D\right] = C_L\left[D + F(1-D)\right],
$$
即批式律。

当 $D \to 1$ 时批式律对每个 $F$ 给 $C_L/C_0 \to 1$，而瑞利律给 $F^0 = 1$：一个在晶体与液体之间均等分配的相不受任何一个过程的影响，而它必须如此。对 $D \ll 1$，批式律给 $C_L/C_0 \approx 1/(D+F)$，在 $D \to 0$ 时于 $1/F$ 饱和，而瑞利律给 $C_L/C_0 = F^{\,D-1} \approx 1/F$——同样的极限。两者因此在两个极端一致、而在中间差别最大：在 $D = 0.05$、$F = 0.5$ 时批式律给 $1/0.525 = 1.90$、瑞利律给 $0.5^{-0.95} = 1.93$，一个 2% 的差别；而在 $F = 0.05$ 时它们给 $1/0.0975 = 10.3$ 与 $0.05^{-0.95} = 17.4$，一个 1.7 的因子。这就是实际的教训：两个模型在中等分异处无法区分、在高分异处可以清楚地区分，而那正是微量元素数据最有信息的地方。
:::
:::

::: exercise 一个混合的检验 {level=3}
两个玄武岩，A 有 $\mathrm{Sr} = 300\ \mathrm{ppm}$、$^{87}\mathrm{Sr}/^{86}\mathrm{Sr} = 0.7030$，B 有 $\mathrm{Sr} = 900\ \mathrm{ppm}$、$^{87}\mathrm{Sr}/^{86}\mathrm{Sr} = 0.7060$，是一个 $\mathrm{Sr} = 450\ \mathrm{ppm}$ 的混合岩的两个组分的候选。从锶的浓度求混合比例，预言同位素比，并说明一个测得的 0.7048、而不是预言值，意味着什么。
::: solution
从浓度，$f_A = (900 - 450)/(900 - 300) = 0.75$，所以混合岩是 75% A 与 25% B。预言的比值是
$$
R = \frac{0.75\times300\times0.7030 + 0.25\times900\times0.7060}{450} = \frac{158.18 + 158.85}{450} = 0.7045 .
$$
一个 $0.7048$ 的测量值高 $0.0003$，这是一台好的质谱仪分析精度的十五倍。三种可能，按可能性排序：第三个更放射性的组分（几十 ppm 的地壳锶即使在极小的量上也主导比值）；两个端元本身是环带的或非均质的，这在一个岩浆房中是正常的；或者混合岩在混合之后经历了同化。注意当存在第三个组分时，浓度与比值给出*不同*的比例，而这个不一致本身——不是任何一个数字——才是证据。这就是同位素工作要连同浓度一起引用的原因，也是一篇关于混合的论文中单个比值永远不够的原因。
:::
