水汽按质量占大气不到百分之四，却比任何其他成分更决定天气将是什么。它的饱和汽压每十度翻倍，所以暖两度的世界多容纳百分之十四的水汽、每场风暴多下百分之十四的雨。它的凝结每千克释放二点五兆焦，这就是一场大雷暴释放的功率超过一座核电站的原因，也是每个热带气旋、每个季风、每条中纬度风暴带的引擎不是直接的太阳、而是太阳几个月前泵进海里的潜热的原因。

## 湿度

::: definition 饱和汽压与湿度变量 {#def-humidity}
平面水面上的饱和汽压服从克劳修斯-克拉珀龙关系
$$
\frac{\mathrm{d}\ln e_s}{\mathrm{d}T} = \frac{L_v}{R_v T^{2}}, \qquad L_v = 2.50\times10^{6}\ \mathrm{J\,kg^{-1}}, \quad R_v = 461.5\ \mathrm{J\,kg^{-1}\,K^{-1}},
$$
在通常温度下即每开尔文$6$–$7\%$——一条在气象学其余部分没有匹敌者的指数线。业务形式是Magnus拟合
$$
e_s(T) = 6.112\,\exp\!\left(\frac{17.67\,T}{T + 243.5}\right)\ \mathrm{hPa}, \qquad T\ \text{以 } ^\circ\mathrm{C},
$$
在$-30\ \mathrm{^\circ C}$给出$0.51\ \mathrm{hPa}$、$0$度$6.11$、$20$度$23.4$、$40\ \mathrm{^\circ C}$给出$74.0\ \mathrm{hPa}$：跨宜居地球的温度范围一百四十倍。

四个变量描述有多少水，而混淆它们是本主题最常见的错误：
$$
e = \text{水汽分压}, \qquad
\mathrm{RH} = 100\,\frac{e}{e_s}, \qquad
r = 0.622\,\frac{e}{p-e}, \qquad
q = \frac{r}{1+r},
$$
再加上由$e = e_s(T_d)$定义的**露点**$T_d$，以及**湿球温度**$T_w$——把水绝热蒸发进空气所能达到的温度：
$$
e = e_s(T_w) - \gamma\,p\,(T - T_w), \qquad \gamma \approx 6.6\times10^{-4}\ \mathrm{K^{-1}} .
$$
相对湿度不是含水量的度量：极地冬天百分之九十的空气含着$0.5\ \mathrm{g\,kg^{-1}}$，而季风里百分之四十的空气含着$15$。位温告诉你气团的事；混合比和露点告诉你水的事；相对湿度告诉你云的事。

因为$e_s$是指数，露点是水汽压的对数，
$$
T_d = \frac{243.5\,\ln(e/6.112)}{17.67 - \ln(e/6.112)},
$$
水汽翻倍只把露点移动$11\ \mathrm{K}$。这就是露点感觉上是好的湿度度量、也是每个人类热应激指数所用变量的原因：只有皮肤处的汽压超过空气的，汗才蒸发，所以热浪里杀人的是露点不是温度，而$35\ \mathrm{^\circ C}$的露点不论气温都是人类存活的理论极限。
:::

::: definition 条件不稳定、相当位温与湿静力能 {#def-conditional}
饱和气块上升释放潜热，所以其直减率$\Gamma_m$小于$\Gamma_d$，而因为可用的水汽取决于温度，$\Gamma_m$在温暖饱和空气里是$4\ \mathrm{K\,km^{-1}}$、在寒冷里是$9\ \mathrm{K\,km^{-1}}$。这产生了真实大气核心的稳定度范畴：
$$
\Gamma < \Gamma_m < \Gamma_d:\quad \textbf{条件不稳定}
$$
——对未饱和位移稳定、对饱和位移不稳定。几乎整个湿对流层都是条件不稳定的，这就是它满是需要触发的云、而大气并非到处对流中性的原因：盖子、锋、波、山和下冲流边界，才是把条件不稳定变成雨的东西。

湿绝热过程的守恒变量是**相当位温**——气块若其全部水都凝结析出、潜热用于抬升它、然后再干绝热移到$1000\ \mathrm{hPa}$时将具有的温度：
$$
\theta_e \approx \theta\,\exp\!\left(\frac{L_v\,r}{c_p\,T_L}\right),
$$
其中$T_L$是抬升凝结温度。典型值：极地空气$300\ \mathrm{K}$、信风边界层$330$–$340\ \mathrm{K}$、热带气旋入流里$350$–$360\ \mathrm{K}$。$\theta_e$在干、湿绝热过程中都守恒，所以它是对流、信风边界层和热塔的恰当示踪物；而其垂直梯度是最弱失稳形式——第二类条件不稳定——的判据，而它正是组织起马登-朱利安振荡、非洲东风波和热带降水日循环的东西。

让整个主题成为一笔收支的能量变量是**湿静力能**，
$$
h = c_p T + L_v q + g z ,
$$
感热加潜热加位能。它被一个上升、凝结、并让凝结物落出的气块守恒，并在充分混合的信风边界层内近似均匀、在其上递减。两个推论主导热带气象学。第一，因为海面处$L_v q \approx 3.5\ \mathrm{MJ\,kg^{-1}}$而$c_p T \approx 0.3$，潜项是感项的十倍，所以热带大气由蒸发而非地表加热运转。第二，因为$h$近似守恒而$q$不是，亚云层的湿静力能设定其上一切的浮力——这就是波-条件不稳定机制和每个热带组织理论的内容。
:::

::: example 饱和汽压、相对湿度与露点 {#ex-es}
$20\ \mathrm{^\circ C}$的空气汽压为$10\ \mathrm{hPa}$。求**相对湿度**、$1000\ \mathrm{hPa}$下的**混合比**、以及**露点**。若空气在定压定汽下被加热到$30\ \mathrm{^\circ C}$，相对湿度变成什么？
::: solution
$e_s(20) = 6.112\exp(17.67\times20/263.5) = 23.4\ \mathrm{hPa}$，所以
$$
\mathrm{RH} = 100\times\frac{10}{23.4} = 43\%, \qquad
r = 0.622\times\frac{10}{1000-10} = 6.3\ \mathrm{g\,kg^{-1}} .
$$
露点：$\ln(10/6.112) = 0.492$，所以$T_d = 243.5\times0.492/(17.67 - 0.492) = 7.0\ \mathrm{^\circ C}$。
$30\ \mathrm{^\circ C}$时，$e_s = 42.4\ \mathrm{hPa}$、$\mathrm{RH} = 100\times10/42.4 = 24\%$。

空气没添一滴水，相对湿度却掉了十九个百分点。这就是冬季室内干燥、午后火险、以及云量日循环的全部：相对湿度是一个比，而分母是温度的指数。一间从$0$加热到$20\ \mathrm{^\circ C}$、不添湿气的房间，相对湿度从八十掉到五——这就是同样的室外空气在供暖建筑里感觉北极般干的原因，也是流感季是湿度季的原因。

$7\ \mathrm{^\circ C}$的露点才是对大气要紧的数字：它是空气在定压定汽下必须冷却到才能饱和的温度，因此也是上升气块到达云底时的温度。辐射雾在地表能在一夜把空气冷却到$T_d$时形成，这要求晴空、微风和小的露点亏缺——这就是雾是秋天、静风、低洼的现象而非风暴现象的原因。
:::
:::

::: example 相当位温 {#ex-thetae}
地表空气$\theta = 300\ \mathrm{K}$、$r = 15\ \mathrm{g\,kg^{-1}}$、抬升凝结温度$T_L = 280\ \mathrm{K}$。求$\theta_e$。其上方空气在相同$T_L$下有$\theta = 305\ \mathrm{K}$、$r = 5\ \mathrm{g\,kg^{-1}}$。该层对深湿对流稳定吗？
::: solution
$$
\theta_e = 300\,\exp\!\left(\frac{2.50\times10^{6}\times0.015}{1004.6\times280}\right) = 300\,e^{0.133} = 343\ \mathrm{K}
$$
而上层空气$\theta_e = 305\,\exp(2.5\times10^{6}\times0.005/281{,}288) = 305\,e^{0.0445} = 319\ \mathrm{K}$。
由于$\theta_e$随高度减少$24\ \mathrm{K}$，该层对深湿对流不稳定。

两层的对比就是要点。按干$\theta$该层是稳定层结的——$305\ \mathrm{K}$压在$300\ \mathrm{K}$上——干气块被位移后会返回。按$\theta_e$它强烈不稳定，因为低层空气携带三倍的水汽、会释放足够的潜热，让它在每个高度都比环境暖二十四开尔文。这是最有用的形态的条件不稳定，也是一份在$\theta$图上看着稳定的探空能造出超级单体原因。

数字$343\ \mathrm{K}$是典型的热带海洋边界层值，而$\theta_e$近似被把该层从地表混合到逆温的信风积云守恒。在热带气旋里，$30\ \mathrm{^\circ C}$海面上的地表$\theta_e$达到$360\ \mathrm{K}$，而风暴的最大可能强度由该值与空气若在接近对流层顶的外流温度下饱和所将具有的$\theta_e$之差设定。海表每暖一度让入流$\theta_e$上升约$6\ \mathrm{K}$——这就是每个气旋强度增强预估的热力学基础。
:::
:::

::: example 可降水量与水汽循环 {#ex-pw}
一个**2-km**深的气层空气密度$1.0\ \mathrm{kg\,m^{-3}}$、平均混合比$10\ \mathrm{g\,kg^{-1}}$。求**可降水量**。若某区域降水$2000\ \mathrm{mm\,yr^{-1}}$并净输入$800\ \mathrm{mm\,yr^{-1}}$的水汽，求其**循环比**。
::: solution
$$
\mathrm{PW} = \rho_{\mathrm{air}}\,r\,\Delta z = 1.0\times0.010\times2000 = 20\ \mathrm{kg\,m^{-2}} = 20\ \mathrm{mm}.
$$
循环比为$(2000 - 800)/2000 = 60\%$。

二十毫米是个薄而干燥的气柱——全球平均可降水量约$25\ \mathrm{mm}$，一次热带降雨事件发生在$50$–$60\ \mathrm{mm}$之上，而加州外的一条大气河在几百公里宽的带状区域里携带$40$–$50\ \mathrm{mm}$。整个大气的水相当于约$25\ \mathrm{mm}$的雨，而全球降水率约$1000\ \mathrm{mm\,yr^{-1}}$，所以大气水库每九天翻新一遍。那九天的停留时间就是天气预报何以可能、而干旱是地表和环流现象而非缺云的原因。

百分之六十的循环比正是亚马逊自己的数字，也是毁林既是碳问题也是水文问题的原因：森林蒸腾其自身降雨的四分之三，所以移除它不仅释放碳，还使下风向降水减少的量与仅凭温室增暖预估的雨量损失相当。同样的算术适用于刚果、东南亚陆地、以及美国玉米带——那里约一半的夏雨被田地自身的蒸腾循环回来。
:::
:::

::: definition 冰、水汽收支，以及湿度对大气做什么 {#def-ice}
在过冷液态水上方，饱和汽压高于同温冰上的——在$-10$到$-20\ \mathrm{^\circ C}$之间高百分之二十到二十五，最大相对差在$-12\ \mathrm{^\circ C}$附近。其推论——1933–1935年由魏格纳、贝吉龙和芬代森各自独立发现——是**贝吉龙-芬代森过程**：在混合相云里，汽压被推向冰值，而后者对水是未饱和的，所以液滴蒸发、冰晶以其为代价生长。一颗在液滴比晶核多十倍的云里的冰晶，因此能在几分钟里长到降水尺度，而单靠液滴要几小时。中纬度云的大部分雨始于冰，而人工影响天气——无论催冰与否——是在利用一条二战前发现的热力学不等式。

气柱水汽收支是一行记账：
$$
P = E + C, \qquad C = -\frac{1}{g}\int \nabla\cdot(\mathbf{v}q)\,dp ,
$$
降水等于蒸发加水汽辐合。在海洋上$P < E$，大气输入水汽；在陆地上$P > E$，大气输入差额；全球$P = E$，而给陆地的净输入约$40{,}000\ \mathrm{km^{3}\,yr^{-1}}$，就是这颗行星全部的淡水资源，每年更新九次。因为$q$随温度指数缩放而环流$\mathbf{v}$只弱弱变化，水汽辐合项一阶上是一个热力学量——这就是"湿者更湿"预估和观测到的水循环增强的物理基础。

三个大尺度效应从同一套化学推出。水汽是主导的温室气体，负责自然温室效应约一半，而因为其浓度由温度而非排放设定，它是气候系统里最强的正反馈——大约把仅二氧化碳造成的增暖翻倍。潜热释放是总环流的主要能量来源，供给驱动哈得来环流、急流和平流层布雷顿-多布森环流的热带加热。而平流层水汽负荷——由热带对流层顶冷阱温度控制——量小而后果大：冷阱暖$1\ \mathrm{^\circ C}$会让平流层水汽增加约百分之十、冷却平流层、并经由极地平流层云的化学加速极地臭氧损失。
:::

::: example 增暖上的湿度反馈 {#ex-humid}
全球平均地表温度为$15\ \mathrm{^\circ C}$。求增暖$2\ \mathrm{K}$时地表饱和汽压上升的百分数。若全球平均降水为$1000\ \mathrm{mm\,yr^{-1}}$并以同样的相对速率上升，它将变成什么——而气候模型为什么只预估每开尔文$2$–$3\%$？
::: solution
$$
\frac{e_s(17\ \mathrm{^\circ C})}{e_s(15\ \mathrm{^\circ C})} = \frac{19.4}{17.0} = 1.14 \quad (+14\%),
$$
这将给出$1140\ \mathrm{mm\,yr^{-1}}$的降水，即**每开尔文$7\%$**。

模型预估每开尔文二到三个百分点，因为降水不由湿度设定而由大气的能量收支设定。降水从气柱移走潜热，而那次释放必须由向太空的辐射冷却加上来自地表的一点点输入来平衡。辐射冷却本身对地表增暖也只有弱敏感度——大气以主要由直减率而非地表设定的发射率加权温度辐射——所以整个水循环只能以大气甩掉能量的速度那么快加速。这就是"慢水循环"结果，是少数几个仅从热力学推出、因而在所有情景下都稳健的模型结果之一。

表面矛盾的了结处正是天气居住的地方。平均降水受能量限制、缓慢上升；每场风暴可用的水受湿度限制、按每开尔文七个百分点上升。大气以下雨更少但更猛来调和两者：干期长度增加，强降水事件的强度在观测里以接近每开尔文七个百分点增加，而洪与旱的统计量在一个几乎不改变全球平均降雨的增暖下朝相反方向移动。
:::

::: history
德·索绪尔发明了毛发湿度计并于1783年出版《湿度测量试验》，把湿度从一种感觉变成一次测量。克拉珀龙1834年写下汽压关系，克劳修斯1850年从热力学第二定律把它推导出来；随之而来的那条指数线，在有人用它解释降雨之前已备好了八十年。魏格纳1911年指出冰晶以过冷液滴为代价生长，因为冰上的饱和汽压更低；贝吉龙1933年将其推广、芬代森1938年进一步做成冷点过程，解释了为什么中纬度大部分雨始于冰——一个从一行热力学做出的预言，十五年后被首次驾机穿越含冰云证实。贝吉龙和卑尔根学派在1910–1920年代围绕位温和湿度建立了气团与锋面分析，而肖1930年的温度对数压图把干绝热线和湿绝热线放在同一张纸上，直到1990年代它都是预报的业务工具。里尔和辛普森在1954–1958年间确立：热带大气由少数深厚的"热塔"而非大范围的浅云加热，信风边界层近似湿静力能混合，而海表温度设定热带对流强度——每个现代飓风强度模型的热力学核心。全球水汽收支在整个二十世纪被反复闭合，如今由卫星和再分析维持：特伦伯斯及其合作者显示海洋每年蒸发约$410{,}000\ \mathrm{km^{3}}$的水、分文不进、把全世界淡水的全部出口给陆地。强降水应按克劳修斯-克拉珀龙每开尔文七个百分点缩放、而平均降水按二到三个百分点缩放的预言，如今是观测记录已直接证实的少数定量气候预言之一，而它脚下垫着的只有上面那条曲线。
:::

::: warning 气块理论恰恰在湿度最要紧的地方最糟糕
六个失效，全部在活跃研究中。气块无视自己的气压场。浮力羽流加速周围的空气，一个约三分之一的附加质量因子因此削减其加速度，而窄上升气流里的横向气压扰动能整块抵消气块的浮力。卷夹不是小量。按观测速率把环境空气混进云的积云参数化方案造出稀薄到从不下雨的云，这就是每个业务方案使用按观测气候而非观测物理调出来的、人为偏小的卷夹率的原因。凝结物负载被惯常忽略。携带$10\ \mathrm{g\,kg^{-1}}$的云水耗掉的浮力相当于一度的冷却，而液态水与冰水的假设在冷云里把CAPE改变两倍。$\theta_e$只有在凝结物落出、且不与环境交换任何东西时才守恒——两个一起失效的假设，所以$\theta_e$是有用的示踪物而非精确的不变量。自由对流层的相对湿度不是热力学所说它应当是的样子：探空廓线显示近乎恒定的百分之四十，而非大尺度上升所将意味着的饱和，因为小尺度湍流和云边缘把水蒸掉了，而任何环流模型不靠网格云方案都无法重现观测分布。而冰物理正是不确定度居住的地方。云水冻结的份额、霰与聚合之比、相撞晶核的破碎效率、以及由此产生的雪和霰的尺度分布全被参数化，而它们控制着降水效率、砧状卷云量、云反照率，因而还有气候敏感度本身。气候模型之间离散度的最大单一来源是云反馈，而云反馈离散度的最大单一来源是冰。
:::

::: quiz
$25\ \mathrm{^\circ C}$的空气相对湿度为50%。在定压下被冷却到$15\ \mathrm{^\circ C}$。相对湿度会发生什么？
- [ ] 保持在50%，因为没有水被移除。
- [x] 升到约99%，因为饱和汽压指数下降。
- [ ] 下降，因为冷空气容纳得少。
- [ ] 升到恰好100%且凝结立即开始。
::: solution
$\mathrm{RH} = 0.50\times e_s(25)/e_s(15) = 0.50\times31.7/17.0 = 0.93$——约百分之九十三。汽压没变；分母掉了百分之四十六。那就是辐射雾、露水，以及一天中最冷的时刻最湿润的原因。
:::
:::

::: summary
- 饱和汽压每开尔文上升六到七个百分点；那条指数线是水循环敏感度的起源。
- 相对湿度是一个比，不是含水量。水用混合比和露点，气团用位温，云用相对湿度。
- 饱和气块按温度以4–9 K km⁻¹冷却，这使几乎整个对流层条件不稳定。
- 相当位温在干湿绝热过程中守恒，是深对流恰当的稳定度判据。
- 湿静力能——感热加潜热加位能——是把地表蒸发与对流层上层加热连接起来的单一收支。
- 冰的饱和汽压低于水，而那条不等式在中纬度云里造出大部分雨
- 降水受能量限制、每开尔文上升二到三个百分点；每场风暴可用的水受湿度限制、上升七个。
:::

## 练习

::: exercise 饱和汽压 {level=1 check="42.5"}
求$30\ \mathrm{^\circ C}$的$e_s$。
::: solution
$e_s = 6.112\exp(17.67\times30/273.5) = 42.5\ \mathrm{hPa}$。四十二毫巴的总压在原则上可以是水——按质量占大气的百分之四，对照$-20\ \mathrm{^\circ C}$的$0.4\ \mathrm{hPa}$。那一百倍就是属热带能运转飓风而极地不能的原因。
:::
:::

::: exercise 相对湿度 {level=1 check="47"}
求$e = 15\ \mathrm{hPa}$、$T = 25\ \mathrm{^\circ C}$时的相对湿度。
::: solution
$\mathrm{RH} = 100\times15/31.7 = 47\%$。同样十五毫巴在$5\ \mathrm{^\circ C}$将是一百四十个百分点——过饱和、有雾、在下雨。不带温度的相对湿度不是任何东西的度量。
:::
:::

::: exercise 混合比 {level=1 check="14.1"}
求$p = 900\ \mathrm{hPa}$、$e = 20\ \mathrm{hPa}$时的混合比。
::: solution
$r = 0.622\times20/(900-20) = 14.1\ \mathrm{g\,kg^{-1}}$。因子$0.622 = M_w/M_d$就是湿空气轻的原因：一千克水汽只取代$0.622\ \mathrm{kg}$干空气，所以气块在定压定温下吸湿时变轻。那是虚温的第一项，也是湿边界层先浮后暖的原因。
:::
:::

::: exercise 露点 {level=2 check="17.5"}
求$e = 20\ \mathrm{hPa}$的露点。
::: solution
$\ln(20/6.112) = 1.185$，所以$T_d = 243.5\times1.185/(17.67 - 1.185) = 17.5\ \mathrm{^\circ C}$。$17.5\ \mathrm{^\circ C}$的露点是热带闷热和显著夜间雷暴风险的阈值；超过$22\ \mathrm{^\circ C}$大气就持有极端降雨的燃料，而超过$26\ \mathrm{^\circ C}$、与高温组合就逼近人类体温调节的极限。
:::
:::

::: exercise 相当位温 {level=2 check="372"}
求$\theta = 310\ \mathrm{K}$、$r = 20\ \mathrm{g\,kg^{-1}}$、$T_L = 275\ \mathrm{K}$的$\theta_e$。
::: solution
$\theta_e = 310\exp(2.5\times10^{6}\times0.020/(1004.6\times275)) = 310\,e^{0.181} = 372\ \mathrm{K}$。这是一个极高值——在$30\ \mathrm{^\circ C}$海面上一个大型热带气旋入流里测得的那类。最大可能强度理论把它与空气若在外流温度下饱和所将具有的$\theta_e$相比较，而两者约$20\ \mathrm{K}$的差，是卡诺效率乘以热机的温度比。
:::
:::

::: exercise 可降水量 {level=2 check="26.4"}
求$\rho = 1.1\ \mathrm{kg\,m^{-3}}$、$r = 8\ \mathrm{g\,kg^{-1}}$的**3-km**层的可降水量。
::: solution
$\mathrm{PW} = 1.1\times0.008\times3000 = 26.4\ \mathrm{mm}$。一个接近平均的气柱。由于全球平均降水约$1000\ \mathrm{mm\,yr^{-1}}$，大气的水每年翻新约三十八次——九天的停留时间，也是为什么三天预报是停留时间的四分之一、而两周展望根本不是雨的预报。
:::
:::

::: exercise 水汽循环 {level=3 check="38"}
某流域降水$800\ \mathrm{mm\,yr^{-1}}$、净输入$500\ \mathrm{mm\,yr^{-1}}$。求循环比，并说若其森林被砍伐，下风向降雨会怎样。
::: solution
$(800-500)/800 = 38\%$。砍伐森林移除了供给那$300\ \mathrm{mm}$的蒸腾，所以本地降雨下降，而本会循环到下风向的水也不在那里了。亚马逊毁林的观测与模型给出百分之十到二十的区域降雨减少，而旱季延长延伸到采伐区以外数百公里——土地利用的一个水文后果，独立于其碳后果、且大小相仿。
:::
:::

::: exercise 湿度反馈 {level=3 check="22"}
求从$12$增暖到$15\ \mathrm{^\circ C}$时地表饱和汽压上升的百分数，并解释为什么全球平均降水只上升约其三分之一。
::: solution
$e_s(15)/e_s(12) = 17.04/13.99 = 1.22$，增加百分之二十二。降水每三开尔文只上升七个百分点，因为它由大气能以多快把其释放的潜热辐射掉设定，而不由有多少水可用。大气以下雨更少更猛来化解冲突——更长的干期、更强的雨、以及几乎不动的全球平均。这是关于气候变化与水最要紧的单一事项。
:::
:::
