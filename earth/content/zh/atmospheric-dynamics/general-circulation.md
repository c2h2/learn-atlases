地球的卫星电影把大气分解为少数几个从不远行的结构：赤道附近一条随季节南北呼吸的亮云带、中纬度自西向东推进的逗号状风暴，以及两极各一顶更白的帽。它们之间是$30^{\circ}$附近几乎不下雨的晴朗沙漠带——撒哈拉、索诺兰、澳洲内陆和卡拉哈里就坐在那条带上。三带面貌是一般环流的可见签名：Hadley、Ferrel和极地环流圈、急流与风暴路径，而理解大气为什么这样组织自己——以及为什么沙漠在$30^{\circ}$而不在赤道——是天气尺度动力学的封顶之石。

## 为什么是三个环流圈，各自输送什么

::: definition 经向环流圈 {#def-cells}
辐射平衡对热带的加热比极地多几十瓦每平方米，而静止的大气不可能单靠涡把随之而来的热输送到极地还不违反自身的稳定度。经向环流闭合这个回路：**Hadley环流圈**在深热带上升、高空向两极辐散、在$25$–$30^{\circ}$附近下沉、以信风东风返回——一个约$10\ \mathrm{km}$深、$3000\ \mathrm{km}$宽的直接热力环流，携带热带角动量的大部分、在其干燥下沉之下设定副热带沙漠。**极地环流圈**是它浅而弱的表亲，在$60^{\circ}$附近上升、在冰面上空下沉。两者之间是**Ferrel环流圈**，它根本不是热机而是一个**由涡驱动的反环流**：中纬度风暴输送向极的热和向赤的角动量，强迫出一个在$60^{\circ}$上升、$30^{\circ}$下沉的残余环流——一个间接环流，像一台冰箱拧在驱动它的引擎侧面。中纬度观测的热输送——$35\ \mathrm{^\circ N}$断面约$5\ \mathrm{PW}$（大气加海洋）——主要由涡而非Ferrel圈本身携带；这个圈是尾气羽，不是引擎。
:::

::: proposition 角动量与副热带急流 {#prop-mj}
绕地球自转轴的单位质量角动量为$M = (\Omega a\cos\phi + u)\,a\cos\phi$。从赤道边界层（$u \approx 0$）离开、在Hadley圈高空向极运动的空气一阶守恒$M$，所以在纬度$\phi$携带
$$
u(\phi) = \Omega a\,\frac{\sin^{2}\phi}{\cos\phi} = 465\,\frac{\sin^{2}\phi}{\cos\phi}\ \ \mathrm{m\,s^{-1}},
$$
$20^{\circ}$达$58\ \mathrm{m\,s^{-1}}$、$30^{\circ}$达$134$、$40^{\circ}$达$251\ \mathrm{m\,s^{-1}}$。观测的副热带急流为$30$–$50\ \mathrm{m\,s^{-1}}$——比守恒律允许的少三倍。差额是**涡矩**：从风暴路径辐射能量和动量的中纬度Rossby波沉积一个向西的力，移除气团到$30^{\circ}$本应保留的角动量约五分之一，而设定真实风的正是这个移除而非守恒。副热带急流因此是Hadley圈角动量供给与涡抽取之间的平衡，而**极锋急流**是它的热成风孪生，坐在极锋两侧温度反差驱动对流层每公里$7$–$8\ \mathrm{m\,s^{-1}}$切变的地面极锋之上。
:::

::: example 涡偷走多少角动量 {#ex-mj}
空气以观测纬向风$u = 40\ \mathrm{m\,s^{-1}}$到达$30\ \mathrm{^\circ N}$高空。把其角动量与从赤道静止守恒应有的值比较，并解释差额。
::: solution
$a = 6.37\times10^{6}\ \mathrm{m}$、$\Omega a = 465\ \mathrm{m\,s^{-1}}$，赤道值$M_0 = \Omega a\cdot a = 2.96\times10^{9}\ \mathrm{m^{2}\,s^{-1}}$，而来的空气有
$$
M = \Omega a^{2}\cos^{2}30^{\circ} + u\,a\cos30^{\circ} = 2.22\times10^{9} + 0.22\times10^{9} = 2.44\times10^{9}\ \mathrm{m^{2}\,s^{-1}} ,
$$
即$M_0$的$82\%$。缺失的$18\%$被破碎Rossby波的向西动量通量移除——正是造出风暴路径的同一涡搅拌。这个数字解释了高空图的观测结构：副热带急流坐在Hadley圈边缘的**赤道一侧**，残余角动量通量在那里归零；而西风向极地减弱，因为涡不断把动量再收回去。
:::
:::

caption: 从赤道静止离开的空气**角动量守恒**会产生的纬向风：$u = \Omega a\,\sin^{2}\phi/\cos\phi$陡升、到$30^{\circ}$将达飓风风速（水平线标记观测副热带急流约$45\ \mathrm{m\,s^{-1}}$）。曲线与水平线之间的缺口就是积分的**涡矩**——Rossby波从流中带回的动量。两条曲线随纬度的发散是定量表述：中纬度大气不是添了涡的Hadley环流，而是拧着一台Hadley圈引擎的涡主导系统。
:::

## 作为热机的大气

::: definition Lorenz能量循环 {#def-energy-cycle}
一般环流是一台效率极低的热机。热带高空的辐射加热与冷区地表的冷却维持着一个**可用位能**库——位能中可以通过重排质量场释放的部分——全球储量约$1.5\times10^{5}\ \mathrm{J\,m^{-2}}$，其中大尺度温度反差只占总位能的几个百分点。引擎以约$1.5\ \mathrm{W\,m^{-2}}$把它转化为涡动能，涡级串并被摩擦以约$2\ \mathrm{W\,m^{-2}}$耗散；平均流动能由同一转化供给、被同一摩擦抽走。地表（$300\ \mathrm{K}$）与辐射层（$250\ \mathrm{K}$）之间的Carnot极限是$17\%$；真实大气的运行远低于吸收阳光的百分之一，使它成为有史以来研究过的最低效的引擎之一——而这就是其行为由许多小转化（风暴）的**统计**而非一个宏伟设计设定的原因。库的**调整时标**$A/C \approx 1.5\times10^{5}/1.5 \approx 10^{5}\ \mathrm{s} \approx 1.2\ \mathrm{天}$，是大气自己的钟：可用位能一天半内造了又毁，这就是风暴路径的涡最多活一周、一般环流必须被太阳**持续加油**的原因。
:::

::: example 引擎的账本 {#ex-engine}
大气以摩擦耗散$2.2\ \mathrm{W\,m^{-2}}$的动能、把可用位能转化为动能的速率为$1.6\ \mathrm{W\,m^{-2}}$，而地表吸收$240\ \mathrm{W\,m^{-2}}$的阳光、$160\ \mathrm{W\,m^{-2}}$以潜热穿过水循环。求引擎对吸收光的效率、对潜热通量的效率，以及它达到Carnot极限的份额。
::: solution
总机械功率就是耗散，$2.2\ \mathrm{W\,m^{-2}}$：对吸收阳光效率$= 2.2/240 = 0.9\%$，对作为引擎实际工作流体的潜热通量$= 2.2/160 = 1.4\%$。$300$与$250\ \mathrm{K}$间Carnot极限$17\%$，大气达到理想值的约$5\%$。这个比较同时解释两个事实：为什么天气预报是统计而非能量的问题——引擎功率微小且剧烈间歇——以及为什么水循环而非风是大气的主导能量管道：地表$400\ \mathrm{W\,m^{-2}}$中的$160$以潜热离开地面，每一毫米雨是$2.45\ \mathrm{MJ}$引擎功的排气。
:::
:::

::: example Hadley圈的质量通量 {#ex-hadley-mass}
Hadley圈的信风入流在$1.5\ \mathrm{km}$深的边界层中以平均$8\ \mathrm{m\,s^{-1}}$向赤道返回，穿过$15\ \mathrm{^\circ N}$的纬圈（$\rho = 1.0\ \mathrm{kg\,m^{-3}}$）。估计该环流圈的质量通量，与亚马逊河比较。
::: solution
$$
\Psi = \rho\, u\, H\, 2\pi a\cos\phi = 1.0\times8\times1500\times2\pi\times6.37\times10^{6}\times0.97 \approx 5\times10^{11}\ \mathrm{kg\,s^{-1}} ,
$$
数亿立方米每秒——与再分析中计入高空补偿外流后该圈质量流函数的观测极大$10^{10}$–$10^{11}\ \mathrm{kg\,s^{-1}}$同量级。作个对比：地球上最大的河流亚马逊输水$6\times10^{4}\ \mathrm{m^{3}\,s^{-1}}$：Hadley圈的返回肢每秒搬运近亚马逊一万倍的质量，而正是这个环流——不是任何局部风——设定ITCZ的降雨、信风的跨大西洋输尘，以及喂养热带东太平洋渔场的上升流。该估计还显示这个环流圈为何是大气最大的单一相干运动：没有哪个风暴路径涡携带超过其通量几个百分点。
:::
:::

## 环状模、季节与呼吸的行星

::: definition 环状模与季节环流 {#def-annular}
温带变率的主导型态不是一个地点而是**极地和中纬度之间的气压跷跷板**：北大西洋涛动（NAO）、北极涛动（AO）及其南半球表亲南极涛动（SAM），是单一结构——**环状模**——的相位：更强的极地涡旋和更紧的绕极急流（正相位）把中纬度与北极空气隔绝，而弱、位移的涡旋（负相位）让冷空气和风暴路径向赤道倾泻。环状模是斜压不稳定纬向流的自然自由振荡：急流生成的涡反馈到急流上，耦合系统以数周到数季周期鸣响。叠在这支内源音乐上的是季节循环：Hadley圈和ITCZ随热赤道迁移$10$–$20^{\circ}$纬度，亚洲季风是由夏季陆海温度反差和喜马拉雅阻挡驱动的大陆尺度海陆风，而急流在每个半球的夏季移位并减弱。过去四十年观测到的Hadley环流圈向极加宽增强和风暴路径向极偏移——后者南半球约每十年一个纬度——是海洋和陆地人为增暖中最稳健的环流变化之列，而它们就是观测到的亚热带澳大利亚、地中海和美国西部变干的机制。
:::

::: example 大气拽动地球 {#ex-lod}
夏冬之间大气与固体地球的季节性角动量交换使大气角动量变化$\Delta\mathrm{AAM} = 3\times10^{25}\ \mathrm{kg\,m^{2}\,s^{-1}}$。固体地球角动量$I\Omega = 5.8\times10^{33}\ \mathrm{kg\,m^{2}\,s^{-1}}$、一天$86{,}400\ \mathrm{s}$，求由此产生的日长季节变化。
::: solution
总角动量守恒给出
$$
\frac{\Delta\mathrm{LOD}}{\mathrm{LOD}} = \frac{\Delta\mathrm{AAM}}{I\Omega} \;\Longrightarrow\; \Delta\mathrm{LOD} = 86{,}400\times\frac{3\times10^{25}}{5.8\times10^{33}} = 4.5\times10^{-4}\ \mathrm{s} = 0.45\ \mathrm{ms}.
$$
大气——一层质量不到地球百分之一的气体壳——每个季节可测量地把整颗行星的自转加快或减慢半毫秒——而在更短时标上，大地震和南大洋的风应力产生原子钟如今每日记录的同量级变化。同样的角动量记账支撑着**大气角动量（AAM）指数**，它提前数周预示季风爆发，并在季节预报中业务使用。
:::
:::

::: warning Ferrel圈不是引擎，ITCZ不在赤道，臭氧洞不是一个洞
五种混淆。**Ferrel圈不承担任何像样的输送**：它是一个统计定义的残余、由涡驱动，把热输送记在它账上就像把引擎的功记在排气管上。**ITCZ是一条带不是一条线，而且从不恰好在赤道上**：北半球夏季它坐在大西洋上$5$–$10^{\circ}\mathrm{N}$、在南太平洋跨到南半球——其平均位置由跨赤道能量输送设定，而把它放偏几度的气候模型会把它预报里的每个季风都放偏。**急流不是绕世界飞奔的空气河**：它们蜿蜒、有时双支、有时破碎，其"位置"是月平均的构造——单次飞行利用的是其细丝而非其气候位置图。**极地涡旋不是北极**：它是每个极夜形成的平流层环流，当它在**平流层突然增温**中变暖崩溃时，一周后的中纬度地面天气转冷——环状模语言描述的自上而下耦合的最清楚例子。**还有臭氧洞是南极春季的化学减薄不是破洞，也不是全球变暖的成因**——尽管两个问题经由同一种气体和同一个平流层环流相连。
:::

::: history
**George Hadley**在1735年为解释信风提出单一热带环流圈；**William Ferrel**在1856年补上中纬度反环流，并正确论证解释西风的是运动空气的偏转而非直接热力环流。**G. I. Taylor**在1918年证明中纬度涡向极输热，**V. W. Ekman**和卑尔根学派量化了涡通量；**C.-G. Rossby**1941年对急流的辨认闭合了运动学图像。**E. N. Lorenz**1955年的博士论文和1967年的论文定义了本课的可用位能与能量循环——那篇1963年开创混沌理论的论文正是从同一一般环流纲领中长出来的。角动量收支在1930–1950年代由高空网观测确立，而NAO、AO和SAM的环状模综合来自**J. M. Wallace**和**D. S. Gutzler**1981年以及**D. W. J. Thompson**和**J. M. Wallace**1990年代末的经验正交函数分析。
:::

::: summary
- 一般环流是三个环流圈和两套急流系统：设定雨带和沙漠的热带Hadley引擎、一个涡驱动的Ferrel反环流、一个极地圈，副热带急流和极锋急流是它们的角动量表达和热成风表达。
- 从赤道守恒角动量在$30^{\circ}$会给$134\ \mathrm{m\,s^{-1}}$；观测的$40\ \mathrm{m\,s^{-1}}$度量的正是让中纬度成为涡主导系统的涡矩。
- 大气是一台效率不到百分之一、跑在潜热管道上的热机；其可用位能约一天周转一次，设定风暴路径的时标。
- 中纬度热输送由Rossby波涡而非Ferrel圈携带；圈是尾气，不是引擎。
- 环状模（NAO/AO/SAM）是涡-急系统的自由鸣响；平流层突然增温把极地涡旋向下耦合到地面寒潮。
- 环流正在变暖和移位：Hadley圈在加宽、南半球风暴路径以每十年约一度向极移动，而副热带变干跟随环流而非天气。
:::

## 练习

::: exercise 角动量风 {level=1 check="58"}
用$u = \Omega a\,\sin^{2}\phi/\cos\phi$、$\Omega a = 465\ \mathrm{m\,s^{-1}}$，求从赤道静止守恒在$20^{\circ}$给出的风（取整$\mathrm{m\,s^{-1}}$）。
::: solution
$u = 465\times\sin^{2}20^{\circ}/\cos20^{\circ} = 465\times0.117/0.940 = 58\ \mathrm{m\,s^{-1}}$。即使在$20^{\circ}$，守恒律也比观测的信风侧流动高一个量级——涡抽取在副热带已经在工作。
:::
:::

::: exercise 引擎效率 {level=1 check="1"}
大气以$2.4\ \mathrm{W\,m^{-2}}$耗散对抗$240\ \mathrm{W\,m^{-2}}$的吸收阳光：求效率（百分点）。
::: solution
$\eta = 2.4/240 = 1\%$。这个数字就是为什么大气的要紧之处是其气候而非其功率：一台跑在每平方米四分之一千瓦上的百分之一的引擎，仍然搬运着全地球河流加起来一百倍的水。
:::
:::

::: exercise 调整时标 {level=1 check="1.2"}
可用位能$A = 1.5\times10^{5}\ \mathrm{J\,m^{-2}}$、转化率$C = 1.4\ \mathrm{W\,m^{-2}}$，求调整时标$A/C$（天，一位小数）。
::: solution
$A/C = 1.5\times10^{5}/1.4 = 1.07\times10^{5}\ \mathrm{s} = 1.2\ \mathrm{天}$。风暴燃料库的周转不到一天半——单个风暴的可预报性是天、环流季节状态的可预报性是月的物理原因。
:::
:::

::: exercise 角动量损失 {level=2 check="82"}
$30\ \mathrm{^\circ N}$、$u = 40\ \mathrm{m\,s^{-1}}$的空气：计算$M/M_0$（百分点），$M_0$为从赤道静止守恒的值（$a = 6.37\times10^{6}\ \mathrm{m}$、$\Omega a = 465\ \mathrm{m\,s^{-1}}$）。
::: solution
$M_0 = 2.96\times10^{9}\ \mathrm{m^{2}\,s^{-1}}$；$M = 2.96\times10^{9}\times0.75 + 40\times6.37\times10^{6}\times0.866 = 2.22\times10^{9} + 0.22\times10^{9} = 2.44\times10^{9}$，所以$M/M_0 = 82\%$。缺失的18个百分点是时间积分的向西涡矩——被拿走从而建起西风的动量。
:::
:::

::: exercise 日长 {level=2 check="0.45"}
一次强平流层突然增温期间大气角动量减少$3\times10^{25}\ \mathrm{kg\,m^{2}\,s^{-1}}$，求日长变化（毫秒，$I\Omega = 5.8\times10^{33}\ \mathrm{kg\,m^{2}\,s^{-1}}$，两位小数）。
::: solution
极地涡旋减弱时，高空西风减速、大气把角动量还给行星：总守恒给出
$$
\Delta\mathrm{LOD} = -\,86{,}400\times\frac{3\times10^{25}}{5.8\times10^{33}} = -4.5\times10^{-4}\ \mathrm{s},
$$
缩短$0.45\ \mathrm{ms}$——虽小，却能被原子时测得——原子时记着平流层写下的账。
:::
:::

::: exercise 热输送 {level=2 check="90"}
大气和海洋一起穿过$35\ \mathrm{^\circ N}$输送$5\ \mathrm{PW}$，大气占三分之二。若大气的份额均匀铺在$30^{\circ}$到$40^{\circ}$的纬向带（面积$2\pi a^{2}(\sin40^{\circ}-\sin30^{\circ})$）上，求平均通量（$\mathrm{W\,m^{-2}}$，取整）。
::: solution
带面积$= 2\pi\times(6.37\times10^{6})^{2}\times(0.643-0.500) = 3.7\times10^{13}\ \mathrm{m^{2}}$；大气输送$= \tfrac{2}{3}\times5\times10^{15} = 3.3\times10^{15}\ \mathrm{W}$；平均通量$= 3.3\times10^{15}/3.7\times10^{13} = 90\ \mathrm{W\,m^{-2}}$。这比引擎的耗散高一个量级，因为输送是引擎的**通量**而非其功：穿过$35^{\circ}\mathrm{N}$的$5\ \mathrm{PW}$热与$2\ \mathrm{W\,m^{-2}}$摩擦耗散的反差，是引擎搬运多少与花费多少之差。
:::

::: exercise 推导守恒律风 {level=3 check="134"}
从赤道静止空气的$M$守恒推导$u(\phi) = \Omega a\,\sin^{2}\phi/\cos\phi$，并在$30^{\circ}$求值（$\mathrm{m\,s^{-1}}$，取整）。
::: solution
$M = (\Omega a\cos\phi + u)a\cos\phi$、$M_0 = \Omega a\cdot a$：令两者相等并除以$a\cos\phi$，$\Omega a\cos\phi + u = \Omega a/\cos\phi$，所以
$$
u = \Omega a\,\frac{1 - \cos^{2}\phi}{\cos\phi} = \Omega a\,\frac{\sin^{2}\phi}{\cos\phi} = 465\times\frac{0.25}{0.866} = 134\ \mathrm{m\,s^{-1}} .
$$
观测急流的三倍：差额是积分的涡矩，而这个推导是最干净的演示——中纬度大气在动力学上被其波主导。同一公式倒过来跑，就是其他行星的赤道东风急流（和地球自己的赤道平流层）需要不同机制的原因——在beta平面意义下$\Omega a\to 0$之处，没有行星角动量梯度可以利用。
:::

::: exercise Carnot与真实引擎 {level=3 check="9"}
大气的引擎在$300\ \mathrm{K}$地表与$250\ \mathrm{K}$辐射层之间工作、以$2.4\ \mathrm{W\,m^{-2}}$耗散对抗$160\ \mathrm{W\,m^{-2}}$的潜热通量。求引擎达到Carnot极限的份额（百分点，取整）。
::: solution
Carnot：$\eta_C = (300-250)/300 = 16.7\%$；实际：$2.4/160 = 1.5\%$；比值$= 1.5/16.7 = $理想值的$9\%$——取决于把哪个通量取作输入，落在教科书常见的$5$–$10\%$区间内。更深的要点是Lorenz的：限制天气的不是引擎的效率，而是其**间歇性**。可用位能的转化集中在每条风暴路径每月寥寥几场风暴里，而气候改变所改变、预报模型必须做对的，是那种间歇性的统计而非平均效率。
:::
