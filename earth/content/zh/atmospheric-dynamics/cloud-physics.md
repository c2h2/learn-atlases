积云以最字面的意义被托住：其水以小到一阵轻微上升气流就能几乎无限期悬着的水滴携带。$10\ \mu\mathrm{m}$的水滴在静气中以约$1\ \mathrm{cm\,s^{-1}}$下落，一个上升热泡轻易超过的速度，所以云物理的核心谜题不是水如何凝结，而是一个$10\ \mu\mathrm{m}$的水滴——纯凝结唯一造出的尺寸——如何变成$2000\ \mu\mathrm{m}$的雨滴，半径两百倍、质量八百万倍。答案穿过气溶胶的物理、纯水的成核失败、碰撞的几何，以及天空冷的一半里那个非凡事实：冰和水争夺同一种汽，而冰总是赢。

## 成核与Köhler曲线

纯水汽不随叫随到地凝结。它在表面上凝结，而在洁净无尘的房间里它可以被冷却到几百个百分点的过饱和度才自发出现液滴，因为液滴的最初胚芽小到其表面能超过凝结释放的体自由能。大气从不面对这个难题，因为它满是**云凝结核**——海盐、硫酸盐、尘埃、烟尘、花粉和有机物——水在零点几个百分点的过饱和就上凝结。支配一个湿气溶胶颗粒的两个效应之争，抬高平衡汽压的曲率与压低它的溶解质，就是**Köhler曲线**，是整个学科的基石。

::: definition Kelvin项与Raoult项 {#def-kohler-terms}
半径$r$的纯水液滴在温度$T$下与一个高于平坦表面饱和值$e_s$的汽压$e_r$平衡，因为分子从凸面更容易逃出。**Kelvin（曲率）项**由表面化学势代价等于凝结收益推出，
$$
e_r = e_s\,\exp\!\left(\frac{2\,\sigma\,M_w}{\rho_w\,R\,T\,r}\right), \qquad \frac{2\sigma M_w}{\rho_w R T} \equiv a \approx 1.1\times10^{-3}\ \mu\mathrm{m}\ \ (T = 283\ \mathrm{K}),
$$
$\sigma = 0.072\ \mathrm{N\,m^{-1}}$为表面张力、$M_w = 0.018\ \mathrm{kg\,mol^{-1}}$、$\rho_w = 1000\ \mathrm{kg\,m^{-3}}$、$R = 8.314\ \mathrm{J\,mol^{-1}\,K^{-1}}$。$0.1\ \mu\mathrm{m}$的纯液滴需要$1.1\%$过饱和才能存活，$0.05\ \mu\mathrm{m}$需$2.2\%$、$0.02\ \mu\mathrm{m}$需$5.7\%$——这就是纯水在大气过饱和度下不能成核、云需要核的原因。

溶解盐反向工作。含$n_s$摩尔溶质的颗粒以**Raoult（溶质）项**压低平衡汽压，
$$
\frac{e}{e_s} = \frac{n_w}{n_w + \nu\phi\, n_s} \approx 1 - \frac{b}{r^{3}}, \qquad b = \frac{3\,\nu\phi\, n_s\, M_w}{4\pi\rho_w},
$$
$\nu$为每个式单位的离子数（硫酸铵和氯化钠$\nu = 2$）、$\phi \approx 0.85$–$1.0$为渗透系数。溶质项按$r^{-3}$衰减，快于曲率项的$r^{-1}$。
:::

::: proposition Köhler曲线与临界活化 {#prop-kohler}
合并两项，含固定溶质量的湿气溶胶的平衡过饱和度为
$$
S(r) = \frac{e}{e_s} = \exp\!\left(\frac{a}{r} - \frac{b}{r^{3}}\right).
$$
因为溶质项衰减更快，$S(r)$在**临界半径**处升至极大然后下降：令$\mathrm{d}S/\mathrm{d}r = 0$给出
$$
r_c = \sqrt{\frac{3b}{a}}, \qquad \ln S_c = \frac{2a}{3 r_c} = 2\sqrt{\frac{a^{3}}{27\,b}} .
$$
置于过饱和度$S$空气中的颗粒只在峰后大$r$分支上稳定。若环境$S$超过$S_c$，颗粒没有稳定平衡、无限制增长——它被**活化**成云滴；若$S < S_c$，它落到小$r$分支上成为一个溶胀但亚微米的**间隙**霾粒。较小的颗粒相对其尺寸有更大的$b$、因而更大的$S_c$：**核越小，活化它所需的过饱和越大**，而这一个事实解释了为什么云在最大最吸湿的颗粒上形成，以及为什么一朵云含多少液滴由气溶胶设定而非由水设定。
:::

::: example 硫酸铵颗粒的临界过饱和 {#ex-kohler}
干半径$0.05\ \mu\mathrm{m}$的硫酸铵颗粒（$\nu = 2$、$\phi = 0.85$、$\rho_s = 1770\ \mathrm{kg\,m^{-3}}$、$M_s = 0.132\ \mathrm{kg\,mol^{-1}}$）悬于$283\ \mathrm{K}$空气。求其临界半径与临界过饱和。若干半径为$0.02\ \mu\mathrm{m}$，什么会变？
::: solution
溶质量$n_s = \tfrac{4}{3}\pi r_d^{3}\rho_s/M_s = 7.0\times10^{-18}\ \mathrm{mol}$，给出$b = 3\nu\phi n_s M_w/(4\pi\rho_w) = 5.1\times10^{-5}\ \mu\mathrm{m}^{3}$。取$a = 1.1\times10^{-3}\ \mu\mathrm{m}$，
$$
r_c = \sqrt{\frac{3b}{a}} = 0.37\ \mu\mathrm{m}, \qquad \ln S_c = 2\sqrt{\frac{a^{3}}{27b}} \;\Rightarrow\; S_c - 1 = 0.20\%.
$$
典型的积云上升气流达到$0.3$–$1\%$的过饱和，所以这个颗粒**活化**。$r_d = 0.02\ \mu\mathrm{m}$时溶质项按$r_d^{3}$缩放、$b$降为$(0.02/0.05)^3 = 0.064$、$S_c - 1$升到$0.78\%$——接近普通无降水云所能达到的上限，所以这种小颗粒大多留作间隙霾。这就是"云滴数跟随**积累模**气溶胶而非多得多但太小的Aitken模颗粒"这一观测的物理基础。
:::
:::

## 靠凝结增长

活化之后液滴靠凝结增长——但凝结只在最初快，且单靠自己造不出雨。液滴增长的限制不是分子撞击表面的动力学（那极快），而是水汽穿过空气到液滴的**扩散**与释放潜热从其导走的**导热**。两者都受梯度限制，都让增长率随液滴变大而衰减。

::: definition 扩散与导热限制的凝结增长 {#def-cond-growth}
过饱和度$S$空气中半径$r$液滴的增长服从
$$
r\,\frac{\mathrm{d}r}{\mathrm{d}t} = \frac{S - 1}{F_k + F_d}, \qquad F_d = \frac{\rho_w R_v T}{e_s D}\,,\quad F_k = \frac{\rho_w L_v}{k T}\left(\frac{D L_v}{R_v T}-1\right),
$$
$F_d$和$F_k$为扩散与导热阻力、$D$为水汽扩散率、$k$为热导率。组合通常写作
$$
r\,\frac{\mathrm{d}r}{\mathrm{d}t} = G\,(S-1), \qquad G \approx 1\times10^{-8}\ \mathrm{m^{2}\,s^{-1}},
$$
即**凝结系数**，在云条件下大致恒定。积分得从$r_0$长到$r_1$的时间$t = (r_1^{2}-r_0^{2})/[2G(S-1)]$：增长由$r^{2}$支配，所以几乎所有时间花在大端。因为$G$很小，凝结增长在云滴尺寸**停滞**：$10\ \mu\mathrm{m}$时增长率已只有几$\mu\mathrm{m\,s^{-1}}$且在下降，而继续增长所需的过饱和在上升，上升气流供不起。凝结造$5$–$30\ \mu\mathrm{m}$的液滴，仅此而已；暖云的**滴谱**窄、峰在$10\ \mu\mathrm{m}$附近，而这窄恰恰是降水必须克服的障碍。
:::

::: example 凝结长出一个云滴的时间 {#ex-cond-time}
液滴在维持$0.4\%$过饱和的空气中靠凝结增长，$G = 1\times10^{-8}\ \mathrm{m^{2}\,s^{-1}}$。从临界半径$0.5\ \mu\mathrm{m}$长到（a）$5\ \mu\mathrm{m}$、（b）$10\ \mu\mathrm{m}$各需多久？$10\ \mu\mathrm{m}$时的增长率是多少？
::: solution
$$
t = \frac{r_1^{2}-r_0^{2}}{2G(S-1)} = \frac{(5\times10^{-6})^{2}-(0.5\times10^{-6})^{2}}{2\times10^{-8}\times0.004} = 0.31\ \mathrm{s},
$$
到$10\ \mu\mathrm{m}$，
$$
t = \frac{(10\times10^{-6})^{2}-(0.5\times10^{-6})^{2}}{8\times10^{-11}} = 1.2\ \mathrm{s}.
$$
$10\ \mu\mathrm{m}$处的增长率为$\mathrm{d}r/\mathrm{d}t = G(S-1)/r = 10^{-8}\times0.004/10^{-5} = 4\ \mu\mathrm{m\,s^{-1}}$。这套算术的要点是**时标反差**：液滴约一秒到$10\ \mu\mathrm{m}$，但仅靠凝结从$10\ \mu\mathrm{m}$长到$1000\ \mu\mathrm{m}$雨滴要$10^{5}\ \mathrm{s}$量级——一天——而所需的过饱和远超上升气流所能提供的任何值。凝结是造云的好办法、造雨的坏办法。
:::
:::

## 靠碰撞并合增长

暖云里的雨由**碰撞-并合**（也称冲蚀或收集）造出：大滴比小滴落得快、追上它们并合并，所以一个在大滴场中被扫过的大滴，其增长率不由扩散而由它扫起多少云水设定。这是一个几何过程，强烈地按尺寸选择，这就是暖底云能在二十分钟内降水的原因。

::: definition 收集效率与冲蚀增长率 {#def-accretion}
半径$R$、以速度$V(R)$下落穿过液态水含量$L$（单位体积质量）、液滴数浓度$n$的云中的收集滴，每秒扫过$\pi R^{2}V$的体积，并以**收集效率**$E \le 1$收集其中的液滴——$E$计入那些沿弯曲路径绕过液滴而没撞上的。$R$低于约$20\ \mu\mathrm{m}$时$E$很小（几个百分点），在$20$–$50\ \mu\mathrm{m}$随尾流增大而陡升，大滴时趋于1。半径按
$$
\frac{\mathrm{d}R}{\mathrm{d}t} = \frac{E\,\rho_a\, w\, q_l}{4\,\rho_w} \quad\text{（速度 }w\text{ 的上升气流中）}, \qquad \frac{\mathrm{d}R}{\mathrm{d}t} = \frac{E\,L\,V(R)}{4\,\rho_w}\quad\text{（静气中）},
$$
增长，因子4来自$\mathrm{d}(\tfrac{4}{3}\pi R^{3}\rho_w)/\mathrm{d}t = 4\pi R^{2}\rho_w\,\mathrm{d}R/\mathrm{d}t$。因为$E$和$V$都随$R$上升，增长是**失控的**：滴越大长得越快。这个正反馈把窄的凝结谱变成宽的降水谱，并定义一个**阈值半径**：约$20\ \mu\mathrm{m}$以下增长可忽略、以上则加速。从阈值到毛毛雨（$\sim 100\ \mu\mathrm{m}$）几分钟；从毛毛雨到雨滴（$\sim 1\ \mathrm{mm}$）再几分钟；整个过程受**液态水含量**和气块能悬多久限制。
:::

::: example 暖雨时标 {#ex-warmrain}
液态水含量$L = 3\ \mathrm{g\,m^{-3}}$（混合比$q_l = 3\ \mathrm{g\,kg^{-1}}$、$\rho_a = 1\ \mathrm{kg\,m^{-3}}$）的云以$w = 1\ \mathrm{m\,s^{-1}}$上升。取$20\ \mu\mathrm{m}$阈值以上平均收集效率$E = 0.7$，估计一滴从$20\ \mu\mathrm{m}$长到毛毛雨尺寸$100\ \mu\mathrm{m}$的时间。
::: solution
$$
\frac{\mathrm{d}R}{\mathrm{d}t} = \frac{E\,\rho_a\, w\, q_l}{4\,\rho_w} = \frac{0.7\times1\times1\times3\times10^{-3}}{4\times1000} = 5.3\times10^{-7}\ \mathrm{m\,s^{-1}} = 0.53\ \mu\mathrm{m\,s^{-1}} .
$$
增长时间$(100-20)\times10^{-6}/5.3\times10^{-7} \approx 150\ \mathrm{s} \approx 2.5\ \mathrm{min}$。加上从$10$到$20\ \mu\mathrm{m}$缓慢低效的爬行——**凝结-碰撞过渡**，限速步骤——从云滴到毛毛雨总共约**$15$–$30$分钟**，正是观测到的积云塔到首次降雨的滞后。该估计还显示过程对$L$为何如此敏感：液态水含量翻倍、时间减半，这就是深而湿的海洋性云轻易下雨、薄而干的大陆性云往往不下的原因。
:::
:::

## 冰晶与Bergeron过程

云的寒冷部分规则完全改变，因为**冰**上的饱和汽压在同温下低于**过冷水**。对水恰好饱和的空气因此对冰**过饱和**，汽以周围水滴为代价沉积到冰晶上。冰晶增长、下落，而在中纬度制造了大部分降水。

::: definition 三种饱和状态与Wegener–Bergeron–Findeisen过程 {#def-bergeron}
温度$T$的冰-水混合云中有三个相关的饱和汽压：过冷水上的$e_s^{w}(T)$、冰上的$e_s^{i}(T)$、实际汽压$e$。因为$e_s^{i} < e_s^{w}$，云分裂成几个区间：
$$
e > e_s^{w} > e_s^{i}: \text{滴长、晶也长}; \quad e_s^{w} > e > e_s^{i}: \text{滴蒸发、晶长}; \quad e_s^{w} > e_s^{i} > e: \text{两者都蒸发}.
$$
中间那个窗口就是**Wegener–Bergeron–Findeisen（冰晶）过程**：汽压坐在两条曲线之间的云蒸发其水滴、把汽沉积到其冰晶上，所以尽管总水不变，冰晶以水滴为代价增长。效应在$-15\ ^\circ\mathrm{C}$附近最强，那里比值$e_s^{w}/e_s^{i}$大、晶和液态水都够多；约$-25\ ^\circ\mathrm{C}$以下液态水消失、过程挨饿。这样长成的晶穿过云下落、收集过冷水滴，滴一触即冻——**霰化**—— 堆出霰，而当增长靠晶的碰并时就是雪花。
:::

::: example 对冰的过饱和 {#ex-bergeron}
$-15\ \mathrm{^\circ C}$的对水恰好饱和的混合云，求汽压以及该空气对冰的过饱和度。
::: solution
水上，$e_s^{w}(-15) = 6.112\exp(17.67\times(-15)/(-15+243.5)) = 1.92\ \mathrm{hPa}$。冰上，$e_s^{i}(-15) = 6.112\exp(22.46\times(-15)/(-15+272.62)) = 1.65\ \mathrm{hPa}$。空气因此对冰过饱和
$$
\frac{e}{e_s^{i}} - 1 = \frac{1.92}{1.65} - 1 = 0.16 \quad (16\%).
$$
以云的标准，$16\%$是很大的过饱和——凝结增长在零点几个百分点就停滞——所以水饱和混合云里的冰晶增长**极**快，这就是冰晶过程比凝结高产得多、以及用碘化银或干冰播云、在自然冰核太少处添冰核能增强降雪的原因。比值$e_s^{w}/e_s^{i}$在$-10\ \mathrm{^\circ C}$为$1.10$、$-15$为$1.16$、$-20\ \mathrm{^\circ C}$为$1.22$，生产力在$-15\ \mathrm{^\circ C}$附近达峰。
:::
:::

## 下落：末速度与粒子的命运

云粒子能否长成降水与其下落速度不可分割，因为下落速度既设定造雨滴的碰撞率，又决定粒子能否存活到地面。小粒子服从带滑移订正的Stokes定律；大滴被阻力拖住并扁平化，其末速度在$9\ \mathrm{m\,s^{-1}}$附近饱和。

::: definition 末沉降速度 {#def-terminal}
在空气中下落的球体达到阻力平衡重力的末速。小雷诺数下这是**Stokes定律**，半径接近空气平均自由程$\lambda \approx 0.067\ \mu\mathrm{m}$时加滑移订正，
$$
V = \frac{2\,r^{2}(\rho_w - \rho_a)g}{9\,\mu}\,C_c, \qquad C_c = 1 + \frac{\lambda}{r}\left(1.257 + 0.4\,e^{-1.1\,r/\lambda}\right),
$$
$\mu = 1.8\times10^{-5}\ \mathrm{Pa\,s}$为动力黏度。这给出$5\ \mu\mathrm{m}$时$V \approx 0.3\ \mathrm{cm\,s^{-1}}$、$10$时$1.2$、$20$时$4.9$、$40\ \mu\mathrm{m}$时$19\ \mathrm{cm\,s^{-1}}$。更大的滴适用二次阻力区、$V$只按$r^{1/2}$增长，在$R \approx 2.5\ \mathrm{mm}$附近$9\ \mathrm{m\,s^{-1}}$处饱和，再大滴就破碎。后果是该学科的两个大分水岭：$10\ \mu\mathrm{m}$的滴以$1\ \mathrm{cm\,s^{-1}}$在任何上升气流中都**悬浮**、实际上失重，而$1\ \mathrm{mm}$的雨滴以$4\ \mathrm{m\,s^{-1}}$穿过甚至强上升气流下落——两者之间的碰撞速度$V(R)-V(r)$正是驱动收集的量，本质上就是雨滴自身的速度。
:::

::: example 上升气流能托住雨滴吗 {#ex-updraft}
一个积云上升气流$w = 6\ \mathrm{m\,s^{-1}}$。$20\ \mu\mathrm{m}$的滴、$200\ \mu\mathrm{m}$的毛毛雨滴和$2\ \mathrm{mm}$的雨滴，它能托起哪些？（大滴用$V \approx 4\sqrt{R/\mathrm{mm}}\ \mathrm{m\,s^{-1}}$。）
::: solution
$20\ \mu\mathrm{m}$的滴以$0.05\ \mathrm{m\,s^{-1}} \ll w$下落，被托起。$200\ \mu\mathrm{m}$的毛毛雨滴以$4\sqrt{0.2} = 1.8\ \mathrm{m\,s^{-1}} < w$下落，也被托起，尽管滞后于空气。$2\ \mathrm{mm}$的雨滴以$4\sqrt{2} = 5.7\ \mathrm{m\,s^{-1}} \approx w$下落，勉强被托住——它悬在上升气流顶部附近。这就是雨在积云的**顶部和边缘**形成的原因——最小的、不再被托住的滴首先在那里被放下，也是更强的上升气流与其说造出更大的滴、不如说让云**长得更高、活得更久**然后才下雨的原因——上升气流强度、云寿命与雨量之间的联系。
:::
:::

::: warning 云不是汽做的，滴不单靠凝结增长，冰过程也不是冻结
六种混淆反复出现。**云是液态或固态水不是水汽**：汽看不见，云可见恰恰因为它已凝结成散射光的粒子。**凝结造云滴不造雨**：它在几十微米处停滞，暖云里的每一滴雨都是碰撞-并合造的、不是更多凝结造的。**云中的过饱和极小**：零点几个百分点而非几十个百分点，因为总有足够的核和滴把汽保持在饱和附近——密封罐里的大过饱和在播种良好的大气里不会发生。**过冷水是$0\ \mathrm{^\circ C}$以下的液体**：纯滴抵抗均质冻结直到$-40\ \mathrm{^\circ C}$，所以$-10$或$-20\ \mathrm{^\circ C}$的云满是液态水，冰只在**冰核**——尘埃、烟尘、某些生物颗粒——触发冻结处出现；好冰核的稀缺正是冰过程成为成核问题、云播种成为可能的原因。**冰晶过程不等于冻结**：它是汽以蒸发中的滴为代价**沉积**到冰上、由汽压差驱动，它能滴未直接冻结就把滴转成冰晶。**还有臭氧洞不是全球变暖**：一个常见的混为一谈，但平流层臭氧问题和温室问题共享气体和历史，不共享机制。
:::

::: history
云物理是两种雨的理论被一个数字了结的故事。**Vincent Schaefer**、**Irving Langmuir**和**Bernard Vonnegut**在通用电气实验室的**1946年**通过把干冰投进过冷云发现了**云播种**，几天后又对Berkshires上空的自然云*Crown*播种；**Vonnegut**还提出碘化银作冰核。**冰晶过程**由**Alfred Wegener**于1911年构想、**Tor Bergeron**在1930年代定量化、**Walther Findeisen**完成，其1938年的专著摆出了混合云的微物理；三者合称Wegener–Bergeron–Findeisen理论。**Köhler理论**的液滴活化由**Wilhelm Köhler**于1936年发表，建立在**Josiah Willard Gibbs**的曲率项和Kelvin勋爵十九世纪表面张力分析之上。暖雨的**碰撞-并合**理论由**Takahashi**于1961年、**Latham**、**Mason**等在1960–70年代推进，了结了这个过程为何需要$20\ \mu\mathrm{m}$附近的**阈值半径**。**Harold Jeffreys**、**Bagnold**、**Gunn和Pilcher**用1940年代的**撞击式和光学雨谱仪**测量滴尺寸与下落速度，**Hitzer**、**Atlas**、**Battersby**和**Ludlam**则用雷达和光学方法使滴谱成为常规测量。
:::

::: quiz
为什么一朵液态水充足、上升气流强劲的云在其头二十分钟仍然下不了雨？
- [ ] 因为凝结还没造出足够的液滴。
- [x] 因为液滴必须先达到约20 µm的阈值，碰撞才能有效地收集它们。
- [ ] 因为上升气流把全部水托住直到云消亡。
- [ ] 因为缺少冰核。
::: solution
凝结在几秒内造出$10\ \mu\mathrm{m}$的滴，但$20\ \mu\mathrm{m}$以下的**收集效率**只有几个百分点，所以在几滴靠随机碰撞越过阈值之前增长慢如冰。一旦滴超过$\sim 20\ \mu\mathrm{m}$，$E$和其下落速度一起上升、增长变成失控——**凝结到碰撞的过渡**是限速步骤，它解释了观测到的云形成到首次降雨的二十分钟滞后。
:::
:::

::: summary
- 云需要凝结核：纯水在大气过饱和度下不能成核，因为Kelvin曲率项对亚微米液滴要求几个百分点的过饱和。
- Köhler曲线是Kelvin项（$\propto 1/r$）与溶质项（$\propto 1/r^3$）的平衡；环境过饱和超过临界值时颗粒活化，而越小的颗粒需要越大的过饱和。
- 云滴数由气溶胶（其尺寸和吸湿性）和上升气流设定而非由水的供给——气溶胶间接效应的微物理基础。
- 凝结按$r^2$增长液滴并在几十微米处停滞；它造不出雨。
- 暖雨由碰撞-并合造出，一个有$\sim 20\ \mu\mathrm{m}$阈值的失控过程，受液态水含量和云寿命限制。
- 冷云中Bergeron过程以过冷水为代价养大冰，因为$e_s^{i} < e_s^{w}$，在$-15\ \mathrm{^\circ C}$附近最强；霰化和碰随后造就降水。
- 下落速度把云与雨分开：$10\ \mu\mathrm{m}$时$1\ \mathrm{cm\,s^{-1}}$（悬浮）对$1\ \mathrm{mm}$时$4\ \mathrm{m\,s^{-1}}$（下落），而驱动增长的碰撞速度本质上就是大滴自身的速度。
:::

## 练习

::: exercise 小液滴上的平衡过饱和 {level=1 check="1.1"}
用Kelvin项$a = 1.1\times10^{-3}\ \mu\mathrm{m}$，求保住半径$0.1\ \mu\mathrm{m}$的**纯水**液滴不蒸发所需的过饱和度（百分点）。
::: solution
$S = \exp(a/r) = \exp(1.1\times10^{-3}/0.1) = \exp(0.011) = 1.011$，所以$S - 1 = 1.1$个百分点。纯的$0.1\ \mu\mathrm{m}$液滴需要$1.1\%$过饱和才能存活——远超云能达到的——这正是纯水不能成核、云需要溶质和表面的原因。
:::
:::

::: exercise 对冰的过饱和 {level=1 check="1.10"}
$-10\ \mathrm{^\circ C}$对水饱和的混合云，求比值$e_s^{w}/e_s^{i}$（对冰的过饱和）。
::: solution
$e_s^{w}(-10) = 2.87\ \mathrm{hPa}$、$e_s^{i}(-10) = 2.60\ \mathrm{hPa}$、比值$= 1.10$。对水饱和的空气在$-10\ \mathrm{^\circ C}$对冰过饱和$10\%$，所以冰晶以滴的代价增长——冰晶过程的驱动力。
:::
:::

::: exercise Stokes沉降速度 {level=1 check="1.2"}
用带滑移的Stokes定律，求$10\ \mu\mathrm{m}$液滴的末沉降速度（$\mathrm{cm\,s^{-1}}$，$\mu = 1.8\times10^{-5}\ \mathrm{Pa\,s}$、$\lambda = 0.067\ \mu\mathrm{m}$）。
::: solution
$V = 2r^{2}(\rho_w)g/(9\mu)\,C_c$，其中$C_c = 1 + (\lambda/r)(1.257 + \dots) = 1 + 0.0067/0.01\times1.6 = 2.07$；Stokes部分为$2\times(10^{-5})^{2}\times1000\times9.81/(9\times1.8\times10^{-5}) = 6.0\times10^{-3}\ \mathrm{m\,s^{-1}}$，$V = 6.0\times2.07 = 1.2\ \mathrm{cm\,s^{-1}}$。在这个速度下，区区$10\ \mathrm{cm\,s^{-1}}$的上升气流就能把液滴无限期托住——云滴实际上失重。
:::
:::

::: exercise 临界过饱和 {level=2 check="0.37"}
硫酸铵颗粒的溶质参数$b = 5.1\times10^{-5}\ \mu\mathrm{m}^{3}$、$a = 1.1\times10^{-3}\ \mu\mathrm{m}$。求其临界半径$r_c$（$\mu\mathrm{m}$，两位小数）。
::: solution
$r_c = \sqrt{3b/a} = \sqrt{3\times5.1\times10^{-5}/1.1\times10^{-3}} = \sqrt{0.139} = 0.37\ \mu\mathrm{m}$。颗粒必须先溶胀到$0.37\ \mu\mathrm{m}$才坐在Köhler曲线顶上；任何进一步的凝结都带它下坡进入无限制增长——活化。
:::
:::

::: exercise 凝结时间 {level=2 check="1.7"}
$G = 1\times10^{-8}\ \mathrm{m^{2}\,s^{-1}}$、过饱和$0.3\%$，液滴从$1$长到$10\ \mu\mathrm{m}$要多久（秒）？
::: solution
$t = (r_1^{2}-r_0^{2})/[2G(S-1)] = (100 - 1)\times10^{-12}/(2\times10^{-8}\times0.003) = 99\times10^{-12}/6\times10^{-11} = 1.7\ \mathrm{s}$。增长在小尺寸时快、随$r$变慢；$r^{2}$依赖意味着最后几微米花掉大部分时间，这就是凝结能一秒造出云滴却永远造不出雨滴的原因。
:::
:::

::: exercise 碰撞增长 {level=2 check="15"}
$30\ \mu\mathrm{m}$的滴在液态水含量$L = 4\ \mathrm{g\,m^{-3}}$的云中靠冲蚀增长，$E = 0.8$、下落速度$V = 0.1\ \mathrm{m\,s^{-1}}$（静气）。求长到$100\ \mu\mathrm{m}$的时间（分钟）。
::: solution
SI单位下$L = 0.004\ \mathrm{kg\,m^{-3}}$，所以
$$
\frac{\mathrm{d}R}{\mathrm{d}t} = \frac{E\,L\,V}{4\rho_w} = \frac{0.8\times0.004\times0.1}{4\times1000} = 8\times10^{-8}\ \mathrm{m\,s^{-1}} = 0.08\ \mu\mathrm{m\,s^{-1}} .
$$
时间$(100-30)\times10^{-6}/8\times10^{-8} = 875\ \mathrm{s} \approx 15\ \mathrm{min}$。静气中的增长远比上升气流中慢，后者里滴还以上升气流速度迎上液滴——含水量相同的深对流云比层状云快得多下雨的原因之一。
:::
:::

::: exercise 凝结-碰撞瓶颈 {level=3 check="0.5"}
收集效率$20\ \mu\mathrm{m}$以下$E = 0.02$、以上$E = 0.7$。在暖雨示例的云中（$\mathrm{d}R/\mathrm{d}t \propto E$），从$10$到$20\ \mu\mathrm{m}$的增长每微米比从$20$到$100\ \mu\mathrm{m}$慢多少倍？（高$E$速率除以低$E$速率，一位小数。）
::: solution
速率正比于$E$，所以比值为$0.7/0.02 = 35$。阈值以下的增长每微米比阈值以上**慢35倍**。瓶颈因此是从$10$到$20\ \mu\mathrm{m}$的慢爬行：按$0.02/0.7\times0.53 = 0.015\ \mu\mathrm{m\,s^{-1}}$，头$10\ \mu\mathrm{m}$要$\sim 670\ \mathrm{s}$，与长到毛毛雨的其余全部时间相当。这就是由小滴低收集效率支配的**初始**增长控制降雨时间的原因，也是加入许多小滴（更多气溶胶）能通过让每个滴更小、更慢达到阈值而**推迟**降雨的原因——气溶胶对降水间接效应的微物理核心。
:::
:::

::: exercise 推导临界半径 {level=3 check="3"}
从$S(r) = \exp(a/r - b/r^{3})$出发，证明临界半径为$r_c = \sqrt{3b/a}$，且在临界点两项满足固定比值。溶质项$b/r_c^{3}$与曲率项$a/r_c$之比是多少？
::: solution
$\mathrm{d}/\mathrm{d}r(a/r - b/r^{3}) = -a/r^{2} + 3b/r^{4} = 0 \Rightarrow a/r^{2} = 3b/r^{4} \Rightarrow r_c^{2} = 3b/a$，所以$r_c = \sqrt{3b/a}$。在$r_c$处，$b/r_c^{3} = b/(r_c\cdot r_c^{2}) = b/(r_c\cdot 3b/a) = a/(3 r_c)$，所以溶质项是曲率项的三分之一：
$$
\frac{b/r_c^{3}}{a/r_c} = \frac{1}{3} = 0.33 .
$$
活化时曲率项总是溶质项的三倍，而$\ln S_c = a/r_c - b/r_c^{3} = \tfrac{2}{3}a/r_c$，即计算$S_c$所用的关系。该结果在Köhler理论内是精确的，并显示两项虽然符号相反、在临界点却同量级——液滴活化的全部就系于它们的近乎相消。
:::
