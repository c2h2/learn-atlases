地球吸收$240\ \mathrm{W\,m^{-2}}$、发射$240\ \mathrm{W\,m^{-2}}$，而这个数字不是有趣的部分。要紧的是入射能量以比地表自身温度高五百七十七度的可见光到来，以低于它六十度的红外离开——而大气对前者几乎完全透明、对后者几乎完全不透明。地表温度的每一度、每一朵云、每一条急流、每一单位海平面上升，都是那条不对称的推论，而它只从二氧化碳、水和臭氧分子的量子力学推出。

## 数光子

::: definition 热发射与两个窗口 {#def-planck}
温度为$T$的物体发射普朗克谱
$$
B_\nu(T) = \frac{2h\nu^{3}}{c^{2}}\,\frac{1}{e^{h\nu/kT} - 1}, \qquad
\lambda_{\max} = \frac{2898}{T}\ \mu\mathrm{m\,K}, \qquad
F = \varepsilon\sigma T^{4}, \quad \sigma = 5.67\times10^{-8}\ \mathrm{W\,m^{-2}\,K^{-4}},
$$
所以太阳（$T = 5772\ \mathrm{K}$）在$0.50\ \mu\mathrm{m}$的可见光达峰、按其自身表面每平方米发射$6.3\times10^{7}\ \mathrm{W\,m^{-2}}$，而地球（$T = 288\ \mathrm{K}$）在$10.1\ \mu\mathrm{m}$的热红外达峰、发射$390\ \mathrm{W\,m^{-2}}$。维恩定律把两者在波长上分开二十倍，而那条分离就是温室效应：一种在$0.5\ \mu\mathrm{m}$透明、在$10\ \mu\mathrm{m}$吸收的气体会加热地表，而这样的气体不可能在两个波长上同时与其自身辐射处于热力学平衡——这就是基尔霍夫定律，也是该效应无法被辩论掉的原因。

分子光谱学阴差阳错地提供了不对称。同核双原子分子——大气的$78\%$——没有偶极矩，在红外里辐射惰性。其余气体在其振动模碰巧落下的地方吸收：水汽跨$5$–$8\ \mu\mathrm{m}$和$12\ \mu\mathrm{m}$以上、加上$18\ \mu\mathrm{m}$之外的纯转动带；二氧化碳在$4.3$和$15\ \mu\mathrm{m}$；臭氧在$9.6\ \mu\mathrm{m}$；甲烷在$7.7\ \mu\mathrm{m}$；氧化亚氮在$7.8$和$17\ \mu\mathrm{m}$。在$8.5$到$13\ \mu\mathrm{m}$之间几乎无物吸收，而这条大气窗口把地球向外辐射约四分之一直接送进太空——这就是为什么它是每台热红外卫星、每台夜视设备和每位红外天文学家使用的窗口，也是为什么哪里都不吸收的CFC曾是如此高效的温室技术。

在要紧的精度上，线形决定一切。压力致宽让每条线在高压下更宽，所以低对流层的吸收是准连续谱、平流层的是一束针；二氧化碳$15\ \mu\mathrm{m}$带在整个对流层的线心已经饱和，所以浓度翻倍在那里几乎不添吸收、其全部效应来自翼和平流层——这就是下面那个对数、以及作为温室增暖指纹的平流层冷却的物理起源。
:::

::: definition 光学厚度、温室效应与辐射-对流平衡 {#def-greenhouse}
穿过吸收层的辐射服从比尔-朗伯定律，
$$
F = F_0\,e^{-\tau}, \qquad \tau = \int \kappa\rho\,\mathrm{d}z = \int \frac{\mathrm{d}z}{\ell},
$$
$\tau$是光学厚度、$\ell$是平均自由程。爱丁顿-巴比耶定理说，在任何波长逃出的辐射来自斜光学厚度达到一的高度，所以卫星在窗口里看到地表、在水汽带里看到中对流层、在二氧化碳带里看到下平流层、在十五微米带心看到中间层——这正是AIRS、IASI和CrIS探测仪每天两次从太空读出三维温度场的方式。

温室效应三行推出。行星平衡要求$240\ \mathrm{W\,m^{-2}}$的外流，按斯特藩-玻尔兹曼定律它由有效温度
$$
T_e = \left(\frac{(1-\alpha)S_0/4}{\sigma}\right)^{1/4} = \left(\frac{238.5}{5.67\times10^{-8}}\right)^{1/4} = 255\ \mathrm{K}
$$
发射。在从$288\ \mathrm{K}$地表起$6.5\ \mathrm{K\,km^{-1}}$的直减率下，$255$-K的高度在$5.1\ \mathrm{km}$、约$540\ \mathrm{hPa}$。该高度以下的一切都比辐射温度暖，而整个三十三开尔文的温室效应就是这句话：大气不透明到太空从五公里高处看它。

灰色爱丁顿大气把算术摆明：
$$
T^{4}(\tau) = \tfrac{3}{4}T_e^{4}\left(\tau + \tfrac{2}{3}\right) \;\Longrightarrow\; T_s = 255\left[\tfrac{3}{4}\left(\tau + \tfrac{2}{3}\right)\right]^{1/4},
$$
顶部给出$214\ \mathrm{K}$、$\tau = 2/3$处$255\ \mathrm{K}$、$\tau = 1.5$处$288\ \mathrm{K}$。真实大气不是灰色的，而订正就是主题：因为$8$–$13\ \mu\mathrm{m}$的窗口让地表辐射不被吸收地逃出，真实大气的光学厚度约是$1.5$而非其波段平均吸收率所暗示的$3$或$4$，而单是窗口就对温室效应约四分之一的"低效"负责。水汽供给总长波吸收的约一半，二氧化碳和其他长寿命气体各约四分之一，而云既添长波不透明又反射阳光——云的净效应接近$-0.7\ \mathrm{W\,m^{-2}}$，在全球均值里很小，却是气候敏感度最大的不确定来源。
:::

::: definition 散射、气溶胶与辐射强迫 {#def-scattering}
散射从光束中移除辐射而不吸收它，而其波长依赖是自然界最面熟的光学。对远小于波长的粒子，瑞利散射给出
$$
\tau_{\mathrm{Ray}} \propto \lambda^{-4}, \qquad
\tau(0.40\ \mu\mathrm{m}) / \tau(0.55\ \mu\mathrm{m}) = (550/400)^{4} = 3.6,
$$
所以谱端的蓝比绿强散射三倍半，这就是天空蓝、日出太阳红、晨昏带从太空可见的原因，而对自然界一种颜色的第一个定量解释在1871年就已完备。对与波长相当的粒子——云滴、海盐、多数污染——米氏理论给出弱波长依赖与强前向峰，用水滴的不对称因子$g = \langle\cos\theta\rangle \approx 0.85$参数化，这就是云为什么白、其反照率为什么取决于滴数而非液态水路径的原因。

气溶胶做三件不同的事，而其总和是辐射强迫收支最大的不确定度。**直接**：散射和吸收阳光——硫酸盐和海盐散射并冷却，黑碳吸收并加热其所在的层同时冷却其下的地表——而沉到雪上时它给表面增暗、在北极造成与二氧化碳相当的区域增暖。**半直接**：气溶胶层内的吸收稳定大气、蒸发云，一个增暖效应。**间接**：更多气溶胶意味着同样液态水下更多更小的云滴，抬高云反照率（特沃西效应）、抑制降水效率、延长云寿命并改变云量——而寿命效应的符号三十年后仍未解决。AR6对1750年以来气溶胶总有效辐射强迫的最优估计是$-0.54\ \mathrm{W\,m^{-2}}$、$\pm 0.4$的不确定度——意味着气溶胶已遮蔽了温室增暖的四分之一到全部，而必须做的空气污染治理会把其中一些揭开。

辐射强迫是平流层调整后、对流层温度保持不变时对流层顶净辐照度的变化。对二氧化碳，对数形式
$$
\Delta F = 5.35\,\ln\!\left(\frac{C}{C_0}\right)\ \mathrm{W\,m^{-2}}
$$
从饱和的线心与未饱和的翼推出，翻倍给出$3.7\ \mathrm{W\,m^{-2}}$。取气候反馈总和$\lambda \approx -0.8\ \mathrm{K\,(W\,m^{-2})^{-1}}$，就是平衡气候敏感度的$2.9\ \mathrm{K}$——气候科学的全部数值内容化约为一个光谱学上确定得很好的三点五，和一个依赖云的负零点八。
:::

::: example 有效高度与温室效应的大小 {#ex-effective}
取$S_0 = 1361\ \mathrm{W\,m^{-2}}$、$\alpha = 0.30$、地表$288\ \mathrm{K}$、环境直减率$6.5\ \mathrm{K\,km^{-1}}$。求有效发射温度、发射该辐射的高度和气压，以及大气将需要的灰色光学厚度。
::: solution
$$
T_e = \left(\frac{1361\times0.70/4}{5.67\times10^{-8}}\right)^{1/4} = 255\ \mathrm{K}, \qquad
z = \frac{288-255}{6.5} = 5.1\ \mathrm{km},
$$
而由灰色大气关系，$T_s/T_e = 288/255 = 1.129$要求
$$
\tau = \tfrac{4}{3}(1.129)^{4} - \tfrac{2}{3} = 1.53 .
$$
一点半的光学厚度。这就是温室效应的全部：大气不是毯子，而是一层薄的、部分透明的屏，三十三开尔文的地表增暖来自一块你几乎能隔着它读报的不透明度。

这个数字立刻解释了水汽反馈。增暖$1\ \mathrm{K}$让饱和汽压上升百分之六，在水汽带里让$\tau$约升百分之六，在直减率和云项响应之前让$T_s$约升一个半开尔文。水汽反馈因此值约$1.8\ \mathrm{W\,m^{-2}\,K^{-1}}$，约为$3.3\ \mathrm{W\,m^{-2}\,K^{-1}}$普朗克响应的两倍，也是气候敏感度是三度而不是一度半的原因。它也被认为确定无疑：它从克劳修斯-克拉珀龙推出、在卫星记录里被观测到、且被每个模型重现。

同样的算术解释了金星。其红外光学厚度在$10^{2}$量级而非$1.5$，有效温度$232\ \mathrm{K}$时灰色公式给出接近$680\ \mathrm{K}$的地表温度——对照观测的$737$。不透明度七十倍的差别是一片海洋与一口高压锅的差别，也是为什么失控温室是一个阈值而非一个斜率。
:::

::: example 比尔-朗伯与红日 {#ex-beer}
$0.55\ \mu\mathrm{m}$的大气光学厚度在天顶为$0.30$。求太阳天顶角$60\ \mathrm{^\circ}$时地表的直射光束；若光学厚度纯为瑞利且$\tau(0.55) = 0.10$，求$0.40\ \mu\mathrm{m}$与$0.70\ \mu\mathrm{m}$光束之比。
::: solution
$60\ \mathrm{^\circ}$的气团质量为$1/\cos 60 = 2$，所以
$$
F = 1361\times\cos 60 \times e^{-0.30\times2} = 1361\times0.500\times0.549 = 373\ \mathrm{W\,m^{-2}} .
$$
纯瑞利散射下$\tau \propto \lambda^{-4}$，所以$\tau(0.40) = 0.10\times(550/400)^{4} = 0.36$、$\tau(0.70) = 0.10\times(550/700)^{4} = 0.039$。天顶处透射率为$e^{-0.36} = 0.70$和$e^{-0.039} = 0.96$，比值为$0.73$。

红日就是那个比值，蓝天就是没直达你眼的那百分之三十的紫光。日出时气团质量是天顶值的三十八倍，蓝光光学厚度超过十三，$0.6\ \mu\mathrm{m}$以下的光几乎全被散射掉——这就是为什么地平线上的太阳不只是更红、还比天顶暗十倍，也是为什么大喷发后全球添$0.1$光学厚度的火山气溶胶，会造出观测到的红落日与1992年皮纳图博可测的一度全球冷却。

同一条比尔-朗伯定律是激光雷达可行的原因、浑浊近海水色卫星观测不了的原因、光学厚度三十的云看着白而非灰的原因，也是工业区上空气溶胶造成的能见度下降——即所谓全球变暗——是地表太阳能可测损失的原因：1950到1990年间它把地表辐照度削减约百分之四，并随清洁空气立法生效而逆转。
:::

::: example 从强迫到增暖 {#ex-totemperature}
1750年以来人为总有效辐射强迫为$2.72\ \mathrm{W\,m^{-2}}$、净气候反馈参数$\lambda = -1.0\ \mathrm{K\,(W\,m^{-2})^{-1}}$。求该强迫的**平衡**气候敏感度，以及二氧化碳**翻倍**（$5.35\ln 2$）的平衡敏感度。然后解释为什么迄今只观测到约$1.2\ \mathrm{K}$。
::: solution
$$
\Delta T_{\mathrm{eq}} = \frac{\Delta F}{-\lambda} = \frac{2.72}{1.0} = \boxed{2.7\ \mathrm{K}}, \qquad
\Delta T_{2\times} = \frac{5.35\ln 2}{1.0} = \frac{3.71}{1.0} = 3.7\ \mathrm{K}.
$$
只出现$1.2\ \mathrm{K}$是因为系统远未接近平衡。海洋吸收了约百分之九十的多余能量，大部分进上层$700\ \mathrm{m}$、三分之一进深海，而地表达到大气平衡的e倍时间由混合层热容和缓慢的卷夹速率设定，不由辐射不平衡本身设定。**响应**在170年后约为平衡值的百分之四十五，而即便排放今天停止，剩下$1.5\ \mathrm{K}$也已承诺。另请注意$2.72\ \mathrm{W\,m^{-2}}$是**净**值：温室气体贡献约$3.4$、人为气溶胶减去约$1.0$，所以我们靠给行星增亮所避免的增暖，与仍在管道里的增暖同量级。
:::

::: example 云辐射效应 {#ex-clouds}
全球平均大气顶云辐射效应在短波为$-44\ \mathrm{W\,m^{-2}}$、长波为$+29\ \mathrm{W\,m^{-2}}$。求**净**值；然后若一个扰动使云**面积**减少$10\%$、$\lambda = -0.8\ \mathrm{K\,(W\,m^{-2})^{-1}}$，求平衡增暖。
::: solution
$$
\mathrm{CRE} = -44 + 29 = -15\ \mathrm{W\,m^{-2}}, \qquad
\Delta F = 0.10 \times 15 = 1.5\ \mathrm{W\,m^{-2}}, \qquad
\Delta T = \frac{1.5}{0.8} = \boxed{1.9\ \mathrm{K}}.
$$
云净给行星降温$15\ \mathrm{W\,m^{-2}}$，冷却量为整个人为强迫的四分之三——这就是**云反馈**的符号是气候预估离散度最大单一来源的原因。这个例子是刻意粗糙的：真实的云变化除面积外还改变滴尺、液态水、高度和相态，而它们各有不同的辐射签名。亚热带的低云——明亮而对长波中性——主导短波项，且在变暖世界里预期**减少**（正反馈）；高云——稀薄而极冷——主导长波项，预期高度上升（也是正反馈）。由模型估计的净云反馈为$+0.4$到$+0.8\ \mathrm{W\,m^{-2}\,K^{-1}}$，量级上与整个水汽反馈相当、是地表反照率反馈的两倍。
:::

::: warning 四个被当作测量值引用的数字
**把$33\ \mathrm{K}$当作观测到的温室效应。**它是两个模型温度之差，$288 - 255$，其中$255\ \mathrm{K}$是按观测反照率算出的发射温度。它不是没有大气时的地表温度，因为移除大气同时也移除了水汽和云、并把反照率从$0.294$降到约$0.15$。对今天太阳输出下一个干燥、仅二氧化碳的地球，最优估计接近$230\ \mathrm{K}$，那会使反事实之差约为$58\ \mathrm{K}$而非$33$。把$33\ \mathrm{K}$当记账数字引用，永远别当预言。

**把$\tau = 1.5$当作测得的。**它是用观测的地表和有效温度从灰色公式反演出来的。一个真正按波段恰当加权、沿剖面积分的红外光学厚度是另一个数字、另一层含义，而灰色模型的有用性并不授权把它的参数叫观测。

**把$5.35\ln(C/C_0)$当作精确。**它是一个对$200$–$1200\ \mathrm{ppm}$瞬时强迫精度约$\pm 1\%$的拟合，而*有效*辐射强迫——平流层重调整后——翻倍为$3.7\ \mathrm{W\,m^{-2}}$，略有不同且自带约$13\%$的不确定度。在拟合范围之外、以及对于气体混合物，请用逐线辐射核。

**把辐射强迫当作它将产生的增暖。**强迫是瞬时的、大气顶的不平衡；增暖是几个世纪之后的$\Delta F/\lambda$。两者之间隔着海洋的热容、其三维环流、以及本身是增暖型态函数的反馈参数。$2.7\ \mathrm{W\,m^{-2}}$的强迫和$1.2\ \mathrm{K}$的增暖同时都对，而混淆它们是气候敏感度公共讨论中最常见的错误。

**还有关于"窗口"一词的一句话。**$8$–$13\ \mathrm{\mu m}$的大气窗口并不清澈。它包含$9.6\ \mathrm{\mu m}$臭氧带、$12.3\ \mathrm{\mu m}$二氧化碳带、以及随压力平方增长的水汽连续谱，所以窗口在沙漠上透过其中约$70$–$85\%$的黑体辐射、在热带太平洋也许只有$40\%$。卫星探测仪恰恰利用窗口，因为那里逃出的少许辐射对地表和最低一公里温度的敏感度极高。
:::

::: history 一层必须被发现的透明
辐射传输的故事是一种没人看得见的物质的故事。**1800年威廉·赫歇尔**让阳光穿过棱镜、把温度计放在每种颜色之外，发现红光之外有最暖的偏转，从而证明太阳发出的不只是光。**奥塞尔的傅里叶**在**1824年**写下：地球表面的温度可以由大气对太阳射线的拦截来维持，而——更深的洞见——那道屏障是*选择性的*：空气对可见光透明、对地面重新发射的隐秘热不透明。他把它比作德·索绪尔的热空气箱，并小心地不声称自己测量过任何东西。**约翰·丁铎尔**做了测量。**1859–1861年**，在一根带岩盐窗的长铜管里（玻璃本身就对热红外不透明），他把熏黑铜壶的热穿过装大气各成分瓶子照过去，发现氮和氧透明而水汽、二氧化碳、臭氧和沼气不透明。他对微量煤气吸收的引用数值大到同时代人怀疑他的仪器，但定性结论——百万分之几的一种次要气体能挡住地球自身的辐射——是对的，而那就是用一句话说出的整个二氧化碳问题。**斯凡特·阿伦尼乌斯**在**1896年**、以及独立的**托马斯·奇尔德雷恩·张伯伦**和**R·S·D·克鲁**在**1900年**尝试了算术：逐列吸收表、手工计算，给出二氧化碳翻倍增暖几度。**盖伊·卡伦德**在**1938年**用更好的波段数据重建了计算，而关键在于带着二氧化碳确实在上升的证据。**吉尔伯特·普拉斯**在**1956年**用现代波段测量取代灰色和波段模型，发现吸收在带心近乎饱和，进一步的增暖来自翼——强迫取对数的原因。**苏、古迪、真锅与韦瑟拉德**在1960年代建成首批可靠的逐线与对流-辐射模型，而**真锅与韦瑟拉德1967年**的论文把辐射与固定直减率、规定云结合，给出翻倍的$2.9\ \mathrm{K}$，至今未被实质性修订。最终了结此事的仪器于**1978年**发射：地球辐射收支实验及其后继者从太空逐波段测量外流谱，显示$15\ \mathrm{\mu m}$的二氧化碳凹口恰在逐线模型放置它的地方，并在一个十年与下一个十年之间按预言的量加深。
:::

二氧化碳的强迫是$5.35\ln(C/C_0)$，取对数而非正比。物理原因是什么？
- [ ] 二氧化碳只在普朗克函数几乎达不到的窄带里吸收。
- [ ] 大气在带的翼上已经饱和，所以只有带心能添吸收。
- [x] 吸收带的带心已经饱和，多余的分子只加厚翼，而翼面积随吸收体量约按对数增长。
- [ ] 平流层调整抵消了大部分瞬时强迫。
::: solution
$15\ \mathrm{\mu m}$带的强带心对当前负荷已不透明，所以添分子不会让它们更不透明；吸收只靠把翼变宽而增长，而翼的贡献按线强的平方根缩放，对总量积分成对数（[[atmospheric-dynamics/radiative-transfer#def-greenhouse]]）。饱和也是增暖来自更高更冷的高度而非地表层的原因。
:::

::: quiz
一个行星的皮肤温度——灰色模型中其大气顶的温度——测得$200\ \mathrm{K}$。它的有效发射温度是多少？
- [ ] $200\ \mathrm{K}$。
- [x] $238\ \mathrm{K}$。
- [ ] $168\ \mathrm{K}$。
- [ ] $283\ \mathrm{K}$。
::: solution
皮肤温度是$T_e/2^{1/4} = T_e/1.189$，所以$T_e = 200 \times 1.189 = 238\ \mathrm{K}$。这个因子的出现是因为大气顶只朝一侧向太空发射、却仍接收来自下方的向下辐射。
:::

::: summary 辐射传输
辐射是大气能量收支里唯一把行星与太空耦合的项，也是唯一支配物理完全线性、完全已知的项。每个物体以$e\sigma T^{4}$发射、峰在$\lambda_{\max} = 2898/T\ \mathrm{\mu m}$：$5778\ \mathrm{K}$的太阳把$97\%$的能量放在$0.3$到$3\ \mathrm{\mu m}$之间，$255$–$288\ \mathrm{K}$的地球把它放在$4$到$40\ \mathrm{\mu m}$之间，而大气生来对前者透明、对后者不透明。透射是比尔-朗伯，$F = F_0 e^{-\tau}$，光学厚度是分子线吸收之和；线在高空多普勒致宽、在地表压力致宽，而其翼——不是饱和的带心——是二氧化碳强迫来的地方。散射移除光束不移除能量，对小于波长的分子强烈地按$\lambda^{-4}$选择，给出蓝天、红日与白云。在长波里，吸收与发射由基尔霍夫和局域热力学平衡绑定，所以大气在每个高度按局域温度辐射，而加热或冷却一层的通量散度是会聚的上行与下行两股流之差。灰色爱丁顿大气$T^{4} = \tfrac{3}{4}T_e^{4}(\tau+\tfrac{2}{3})$重现$214\ \mathrm{K}$的皮肤温度、把发射高度放在$\tau = 2/3$、给出$T_s/T_e = (1+3\tau/2)^{1/4}$——$\tau = 1.5$时为$1.2$，即$33\ \mathrm{K}$的温室效应。加上对流调整，模型从地表到对流层顶把观测的对流层温度廓线重现到$2\ \mathrm{K}$以内，这就是辐射-对流模型受信任的原因。强迫是大气顶经平流层调整的不平衡，二氧化碳为$\Delta F = 5.35\ln(C/C_0)$，而增暖是$\Delta F/\lambda$；$2.7\ \mathrm{W\,m^{-2}}$的人为强迫产生了$1.2\ \mathrm{K}$，因为海洋拿走了其余，而另有$1.5\ \mathrm{K}$已经承诺。
:::

::: solution
地球$\lambda_{\max} = 2898/255 = 11.4\ \mu\mathrm{m}$，太阳$2898/5778 = 0.50\ \mu\mathrm{m}$。两个峰在波长上相差$23$倍，而这正是大气利用的分离：它生来放行后者、拦截前者。

::: exercise 地表的发射功率 {level=1 check="390"}
计算$288\ \mathrm{K}$表面的黑体发射功率（$\mathrm{W\,m^{-2}}$）。地表观测上行长波约$340\ \mathrm{W\,m^{-2}}$；差值对地表在热红外的发射率意味着什么？
::: solution
$E = \sigma T^{4} = 5.6704\times10^{-8} \times 288^{4} = 390\ \mathrm{W\,m^{-2}}$。观测的$340\ \mathrm{W\,m^{-2}}$是$\varepsilon\sigma T^{4}$、$\varepsilon = 340/390 = 0.87$，但更有用的读法是地表在热红外非常接近黑体（水、植被和土壤$\varepsilon > 0.95$），而缺失的通量不是低发射率而是$8$–$13\ \mu\mathrm{m}$窗口——透过它地表看到的是冷天空而非$288\ \mathrm{K}$的黑色大气。
:::

::: exercise 透射率 {level=2 check="0.135"}
一束直射阳光穿过光学厚度$2.0$的路径（霾、烟或厚云边缘）。光束的份额存活？若漫射份额是全部剩余，漫射-直射比改变了多少？
::: solution
透射率$= \exp(-2.0) = 0.135$，所以$13.5\%$的光束存活、$86.5\%$被散射或吸收。漫射-直射比变为$0.865/0.135 = 6.4$，对照洁净分子大气天顶的约$0.1$。这就是霾天拍照平淡的原因：照明几乎全是漫射、影子消失、承载地形细节的反差被移除。
:::

::: exercise 皮肤温度 {level=2 check="214"}
由爱丁顿灰色大气，计算$T_e = 255\ \mathrm{K}$时大气顶（$\tau = 0$）的温度。为什么是这个数而非$255\ \mathrm{K}$，才是无空气表面辐射同样通量所需的温度？
::: solution
$T(0)^{4} = \tfrac{3}{4}T_e^{4}(0 + \tfrac{2}{3}) = T_e^{4}/2$，所以$T(0) = 255/2^{1/4} = 255/1.189 = 214\ \mathrm{K}$。二分之一的出现是因为顶层既向上也向下辐射，其发射的一半浪费在刚离开的大气上。无空气表面从单一暴露面向各方辐射、不付这笔代价，所以同样的能量收支允许它坐在$T_e$而非$T_e/2^{1/4}$。
:::
:::

::: exercise 二氧化碳强迫 {level=2 check="3.7"}
用$\Delta F = 5.35\ln(C/C_0)$，求二氧化碳翻倍的有效辐射强迫，以及从工业化前$280\ \mathrm{ppm}$到今天$420\ \mathrm{ppm}$的强迫。
::: solution
翻倍：$\Delta F = 5.35\ln 2 = 3.71\ \mathrm{W\,m^{-2}}$。当今：$\Delta F = 5.35\ln(420/280) = 5.35 \times 0.405 = 2.17\ \mathrm{W\,m^{-2}}$。注意我们已经花掉了翻倍强迫的$58\%$，而对数意味着*下一个*翻倍与这一个恰好同样贵$3.71$——每吨的损害不随浓度上升而减轻，按$\ln C$的每单位恒定。
:::

::: exercise 真实大气的光学厚度 {level=3 check="1.5"}
反解灰色关系$T_s = T_e(1 + 3\tau/2)^{1/4}$，求$T_s = 288\ \mathrm{K}$、$T_e = 255\ \mathrm{K}$意味着的红外光学厚度。然后求在其他不变时$1\ \mathrm{K}$增暖所需的附加光学厚度。
::: solution
$1 + 3\tau/2 = (288/255)^{4} = 1.627$，所以$\tau = (1.627 - 1)\times 2/3 = 0.418 \times 2/3 = 1.50$。对$289\ \mathrm{K}$：$1 + 3\tau/2 = (289/255)^{4} = 1.650$、$\tau = 0.433$，所以$\Delta\tau = 0.033$——大气总红外不透明度增加$2.2\%$。在灰色模型里一度增暖就只花这么多，这就是$420$ppm的一种气体能移动一颗行星的定量表述。
:::

::: exercise 发射高度 {level=3 check="5.8"}
设红外光学厚度随高度按$\tau(z) = 1.5\,e^{-z/7.2\ \mathrm{km}}$衰减。灰色大气的温度在多高处处等于有效温度，即$\tau = 2/3$面在哪里？与平均对流层顶高度比较。
::: solution
$2/3 = 1.5\,e^{-z/7.2}$给出$e^{-z/7.2} = 0.444$、$z = 7.2\ln(1.5/0.667) = 7.2 \times 0.811 = 5.8\ \mathrm{km}$。它与热带约$11\ \mathrm{km}$、中纬度$8\ \mathrm{km}$的全球平均对流层顶高度的吻合比应有的更近，而且不是巧合：对流把热量送到辐射冷却能接管的层，所以对流层顶坐在发射高度附近。添加二氧化碳处处抬高$\tau$、抬起$2/3$面，而其下的地表必须增暖以恢复通量。
:::

::: exercise 作为对照的月球 {level=3 check="381"}
月球有邦德反照率$0.12$、无大气、自转周期27天。计算其日下点平衡温度与全球平均平衡温度。观测月表从正午$400\ \mathrm{K}$到夜间$100\ \mathrm{K}$；解释为什么这两个极值的均值不是你算的全球均值。
::: solution
日下点：表面接收$S_0(1-A) = 1361 \times 0.88 = 1198\ \mathrm{W\,m^{-2}}$并从同样面积辐射掉，所以$T = (1198/\sigma)^{1/4} = 381\ \mathrm{K}$。全球平均下，发射面积是截面的四倍，所以$T = (1198/4\sigma)^{1/4} = 270\ \mathrm{K}$。$400$和$100$的算术均值是$250\ \mathrm{K}$，而*发射加权*的均值才是行星实际辐射的：因为通量按$T^{4}$走，炎热的正午面主导能量收支、寒冷的夜面几乎不贡献，所以有效温度由极大值而非平均数设定。这是$T_e/2^{1/4}$皮肤温度论证的另一个化身，也是为什么无空气天体在同一轨道上平均比温室天体更冷。
:::
