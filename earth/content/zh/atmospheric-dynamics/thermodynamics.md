一个气块上升两公里、冷却二十度而不损失一焦耳，而这单一事实——不是辐射、不是摩擦、不是太阳——决定了夏日的午后是造一场雷暴还是一片蓝天，决定飞机是巡航在十一公里还是两公里的高空，决定对流层是六公里还是六十公里厚。大气动力学始于关于一种几乎全是氮气的气体的四行代数，终结于天气。

## 状态与气柱

::: definition 状态方程、虚温与静力平衡 {#def-state}
干空气在大气占据的整个范围内都是理想气体，精度优于万分之一：
$$
p = \rho R_d T, \qquad R_d = 287.05\ \mathrm{J\,kg^{-1}\,K^{-1}}, \qquad R_d = R^{*}/M_d,\ \ M_d = 0.02897\ \mathrm{kg\,mol^{-1}} .
$$
湿空气在同压同温下比干空气轻，因为水汽（$M = 18$）取代了氮和氧（$M = 29$）。虚温吸收了这一点，
$$
T_v = T\,(1 + 0.61\,r) \approx T\,(1 + 0.61\,q),
$$
其中$r$是以$\mathrm{kg\,kg^{-1}}$计的混合比。在$20\ \mathrm{^\circ C}$、$r = 10\ \mathrm{g\,kg^{-1}}$时，虚温超过实际温度$1.8\ \mathrm{K}$——不到百分之二，而一朵热带积云的全部浮力就来自那百分之二。

气柱的静力平衡精度达十万分之一——气象学里最重要的单一近似：
$$
\frac{\partial p}{\partial z} = -\rho g \quad\Longrightarrow\quad p(z) = p_0\,e^{-z/H}, \qquad H = \frac{R_d T}{g} \approx 8.4\ \mathrm{km},
$$
所以气压每$8.4\ \mathrm{km}$降为$1/e$，在$5.5\ \mathrm{km}$处减半、$11\ \mathrm{km}$处减到四分之一、$30\ \mathrm{km}$处只剩$3\%$。大气薄得是指数式的：一半质量在$5.5\ \mathrm{km}$以下，而地球上每个天气系统的飞行层，相对行星半径比地球仪上的清漆还薄。

把静力学与状态方程结合得到静力水压方程（位温厚度式），
$$
\Delta z = \frac{R_d \overline{T_v}}{g}\ln\frac{p_1}{p_2},
$$
它说一层的厚度正比于其平均温度。这就是等压面在暖空气上隆起、急流坐在极锋之上、以及一张500 hPa图其实是其下层平均温度的地图的原因。业务上每张高空预报图都是倒过来读的静力水压方程。
:::

::: definition 干绝热线、位温与静力稳定度 {#def-adiabat}
气块的热力学第一定律$c_p\,dT = \alpha\,dp + dq_{\mathrm{heat}}$（$\alpha = 1/\rho$），在绝热过程（$dq_{\mathrm{heat}} = 0$）下成为
$$
\frac{1}{T}\frac{dT}{dz} = -\frac{g}{c_p} = -\Gamma_d = -9.8\ \mathrm{K\,km^{-1}},
$$
干绝热直减率——上升气块的冷却速率，由地球引力和氮的热容决定，别无一物。积分得到泊松关系和干大气的守恒量：
$$
\theta = T\left(\frac{p_0}{p}\right)^{\kappa}, \qquad \kappa = R_d/c_p = 2/7, \qquad p_0 = 1000\ \mathrm{hPa},
$$
位温：气块干绝热移到$1000\ \mathrm{hPa}$时将具有的温度。$\theta$在绝热运动中守恒、与熵成正比，是大气大部分区域正确的垂直坐标——$\theta$的地图是气团的地图，而$T$的地图是高度的地图。

静力稳定度由环境直减率$\Gamma$与$\Gamma_d$比较得出，或等价地由布伦特-维伊萨拉频率
$$
N^{2} = \frac{g}{\theta_v}\frac{\partial \theta_v}{\partial z}, \qquad T_{\mathrm{parcel}} - T_{\mathrm{env}} = \frac{\theta_v'}{\theta_v}T \approx \frac{N^{2}}{g}\,T\,\zeta ,
$$
$$
\Gamma < \Gamma_d\ (N^2 > 0):\ \textbf{稳定，以周期 } 2\pi/N \approx 5\ \text{min 振荡}; \qquad
\Gamma > \Gamma_d\ (N^2 < 0):\ \textbf{不稳定，对流}.
$$
典型值：稳定下平流层$N \approx 10^{-2}\ \mathrm{s^{-1}}$、对流层$0.5$–$1\times10^{-2}\ \mathrm{s^{-1}}$，浮力周期五到十分钟。那就是大气的钟：它设定重力波的垂直群速度、对流云的最大高度、边界层的深度，以及晴空湍流为何成几百米厚的层出现。
:::

::: example 气压与标高 {#ex-scaleheight}
取均匀$T = 288\ \mathrm{K}$、$p_0 = 1013\ \mathrm{hPa}$的大气。求标高、$5500\ \mathrm{m}$的气压，以及$500$-hPa面的高度。
::: solution
$$
H = \frac{R_d T}{g} = \frac{287\times288}{9.81} = 8430\ \mathrm{m}, \qquad
p(5500) = 1013\,e^{-5500/8430} = 528\ \mathrm{hPa}.
$$
反解，$z = -H\ln(p/p_0) = -8430\ln(500/1013) = 5600\ \mathrm{m}$。

等温大气是个粗糙模型，却仍把$500$-hPa面定得与标准大气的$5570\ \mathrm{m}$相差不到$100\ \mathrm{m}$，因为真实对流层的层均值温度接近$288\ \mathrm{K}$。这不走运：热带和中纬度对流层被对流和动力学约束在接近$6.5\ \mathrm{K\,km^{-1}}$的直减率上，使气柱平均温度是地表温度的近常数分数。

实用的推论是静力水压的那个。整个对流层增暖$10$-K把所有气压面抬高
$$
\Delta z = \frac{R_d\,\Delta \overline{T}}{g}\ln\frac{p_1}{p_2} = \frac{287\times10}{9.81}\times0.693 = 203\ \mathrm{m},
$$
这就是热浪中$500$-hPa面为何上升、急流为何随气候变暖向极地并向上移动、以及飞机巡航高度和风机叶片间隙为何必须对气压而非对米来规定的原因。
:::
:::

::: example 位温与抬升 {#ex-theta}
地表空气$T = 288\ \mathrm{K}$、$p = 1000\ \mathrm{hPa}$。求其位温，以及干绝热抬升到$700\ \mathrm{hPa}$后的温度。
::: solution
$\theta = 288\times(1000/1000)^{2/7} = 288\ \mathrm{K}$，而
$$
T = \theta\left(\frac{p}{p_0}\right)^{\kappa} = 288\times(0.700)^{2/7} = 288\times0.9146 = 263\ \mathrm{K} = -10\ \mathrm{^\circ C}.
$$
$300$-hPa的爬升——三公里——让气块冷却$25\ \mathrm{K}$，而这冷却不是任何碰到它的东西造成的。气块做功推开邻居，而因为上升耗时几分钟、气块的辐射松弛时间是一周，热量来不及流动。绝热不是一个假设；它是一个时间尺度之比，只在热表面上方那厘米级的辐射活跃空气里才失效。

$\theta$的守恒是这个变量不可或缺的原因。两个在不同高度、有相同$\theta$的气块在同一气团里、被交换也不会抵抗；两个在不同高度、有相同$T$的气块在不同气团里、被交换就会抵抗。每张skew-T对数气压图、每次气团分析、每次位涡反演、平流层里每个化学输送模型，都因此建在$\theta$而非$T$之上。
:::
:::

::: example 静力稳定度与布伦特-维伊萨拉频率 {#ex-bv}
某层内$\theta_v = 300\ \mathrm{K}$，位温随高度增加$3\ \mathrm{K\,km^{-1}}$。求$N$、浮力周期，以及气块被向上位移$200\ \mathrm{m}$后的最大垂直加速度。
::: solution
$$
N^{2} = \frac{g}{\theta_v}\frac{\partial\theta_v}{\partial z} = \frac{9.81}{300}\times3\times10^{-3} = 9.8\times10^{-5}\ \mathrm{s^{-2}}, \qquad
N = 9.9\times10^{-3}\ \mathrm{s^{-1}},
$$
$$
\frac{2\pi}{N} = 635\ \mathrm{s} = 10.6\ \mathrm{min}.
$$
最大加速度在释放点，为
$$
a = N^{2}\zeta = 9.8\times10^{-5}\times200 = 0.020\ \mathrm{m\,s^{-2}} = 0.002\,g .
$$
千分之二个重力加速度。被位移的气块以$g$的万分之二加速，花五分钟到达第一个最大位移，而若层不湍流就会永远振荡下去。这就是稳定空气不是静止空气的原因：它是垂直运动成为微弱振荡而非流动的空气，也是夜间边界层、极地冷池、卷云盖下方的云顶湍流都成层出现、其厚度由$N$和切变设定的原因。

同一个数字解释了平流层。在对流层顶，$\theta$在$1\ \mathrm{km}$上跳变$20\ \mathrm{K}$，给出$N \approx 2.5\times10^{-2}\ \mathrm{s^{-1}}$、浮力周期四分钟——对流层值的两倍半。对流无法穿透它，这就是雷暴为何摊成砧状、火山气溶胶和水汽一旦越过就被困多年、以及混入平流层的臭氧消耗物质为何待得足够久去酿成其危害的原因。
:::
:::

::: definition 湿不稳定、凝结与对流有效位能 {#def-cape}
气块一旦饱和，凝结释放潜热，直减率降到湿绝热值$\Gamma_m$：在温暖的热带空气里是$4\ \mathrm{K\,km^{-1}}$、在寒冷的极地空气里是$9\ \mathrm{K\,km^{-1}}$——因为湿绝热线取决于有多少水汽可凝，而那通过克劳修斯-克拉珀龙方程对温度呈指数依赖。这就是湿大气里一切不对称的起源：热带被对流约束在$\Gamma \approx \Gamma_m \approx 4\ \mathrm{K\,km^{-1}}$而极地接近$\Gamma_d$；赤道对流层顶在$17\ \mathrm{km}$而极地的在$9\ \mathrm{km}$；地表增暖$1\ \mathrm{K}$使边界层的湿静力能增加百分之七。

三个高度描述一份探空。抬升凝结高度——地表气块最初饱和之处——来自温度以$9.8\ \mathrm{K\,km^{-1}}$下降而露点以$\sim 1.8\ \mathrm{K\,km^{-1}}$下降的事实：
$$
z_{\mathrm{LCL}} \approx 125\,(T - T_d)\ \mathrm{m},
$$
每度露点亏缺一百二十五米——夏日午后积云云底在整个大陆上一般高的原因，以及单个地表湿度测量能把云底预报到一百米的原因。自由对流高度是上升气块变得有浮力之处；平衡高度是它重新变为负浮力之处。两者之间是对流有效位能，
$$
\mathrm{CAPE} = g\int_{z_{\mathrm{LFC}}}^{z_{\mathrm{EL}}}\frac{T_{v,\mathrm{parcel}} - T_{v,\mathrm{env}}}{T_{v,\mathrm{env}}}\,\mathrm{d}z ,
$$
即skew-T上气块湿绝热线与探空曲线之间的面积，以每千克焦耳计。典型值：$500\ \mathrm{J\,kg^{-1}}$给零散雷暴，$2000$给强雷暴，$5000$是极端，而研究飞机在2016年巴西巴乌鲁风暴中观测到的$\sim 100\ \mathrm{m\,s^{-1}}$世界纪录上升气流意味着近$5000\ \mathrm{J\,kg^{-1}}$的CAPE。最大上升气流为$w \approx \sqrt{2\,\mathrm{CAPE}}$（无卷夹、无拖曳与液态水负载时），而让观测上升气流约为其一半的正是这些效应。

对流抑制能CIN——LFC以下的负面积，通常$10$–$100\ \mathrm{J\,kg^{-1}}$——是以能量单位计的盖帽逆温，而大CAPE与大CIN之间的张力是强对流天气爆发式而非连续式的原因。一个在一整天蓄能的区域上失效的盖子，会在一小时内释放整个下午的浮力——这就是每次龙卷爆发和每次线状风灾的热力学基础。
:::

::: example 一份对流探空 {#ex-cape}
一个气块在**$5$-km**层内有浮力、平均虚温超出**$3\ \mathrm{K}$**，环境平均$T_v = 285\ \mathrm{K}$。求CAPE和最大上升气流。邻近一份探空有相同的CAPE但有一顶**$150\ \mathrm{J\,kg^{-1}}$**的盖子；描述什么变了。
::: solution
$$
\mathrm{CAPE} = g\,\frac{\overline{\Delta T_v}}{\overline{T_v}}\,\Delta z = 9.81\times\frac{3}{285}\times5000 = 516\ \mathrm{J\,kg^{-1}}, \qquad
w = \sqrt{2\times516} = 32\ \mathrm{m\,s^{-1}} .
$$
观测上升气流因卷夹、液态水负载和气压扰动拖曳只能达到此值的一半到三分之二——所以是$15$–$20\ \mathrm{m\,s^{-1}}$，这是一个强风暴、足以把十厘米大的冰雹托在空中。

盖子对风暴的强度毫无改变，却改变它是否发生、何时、何地。$150\ \mathrm{J\,kg^{-1}}$的盖子要求地表气块比环境暖$150\ \mathrm{J\,kg^{-1}}$才能上升，这需要一小时的地表加热或一条中尺度边界把该层机械地抬起。这就是强风暴沿干线、阵风锋和海风辐合线触发、而非在最暖气团里触发的原因，也是为什么对触发时机的预报技巧远差于对触发之后强度的预报技巧——CAPE能提前一天预报，CIN的失效不能。

同一个算术解释了陆地降水的日循环：CAPE在午后晚些、地表已给边界层充满能时达峰，而夜间边界层的崩溃恢复了盖子。在海洋上盖子更弱、峰值移到清晨，那时云顶冷却从上方使层失稳。卫星同时看到两个峰值，而陆海之间的相位反转是本主题最干净的自然实验之一。
:::

::: history
罗伯特·玻意耳1662年和埃德姆·马略特1676年确立了压强-体积定律；雅克·查理1787年发现体积-温度定律，约瑟夫·盖-吕萨克1802年发表它，随后1804年乘气球飞到$7\ \mathrm{km}$去测量理论预言为$6.5\ \mathrm{K\,km^{-1}}$的直减率。德·索绪尔1770年代已带着温度计爬上阿尔卑斯山，确立了温度随高度按可复现的节律下降，而他的毛发湿度计让湿度成为一个数字。克拉珀龙1834年写下汽压关系，克劳修斯1850年从热力学把它推导出来；就是这一个对温度呈指数的方程，是热带对流、中纬度有锋面、以及更暖的世界更湿润的原因。阿尔弗雷德·魏格纳——以大陆漂移更出名——1911年写下《大气热力学》，发明了风筝探空平台，把绝热线画上了图；拿破仑·肖1930年的温度对数压图（tephigram）和1950年代成为标准的skew-T log-$p$图都是他的后裔。维伊萨拉1925年推导了以他命名的浮力频率，与布伦特1934年《物理与动力气象学》的稳定度工作并列发表，随后1936年发明了无线电探空仪——让稳定度可测的仪器和数字出自同一只芬兰的手。全球无线电探空网在1940到1960年代间建成、如今每天两次从八百个站点施放，是气象史上最重要的单一观测，而它自1997年以来覆盖的逐渐流失，是环境科学里最安静的退化之一。现代对流热力学——CAPE与对流抑制能的分离、气块理论对卷夹和气压场的订正、以及相当位温作为湿空气守恒量的使用——在1960到1990年代之间成形，如今是地球上每个强对流天气预报办公室每天的演算。
:::

::: warning 气块理论在六个具体方面是错的，而每一个方面都是一支研究文献
空气不是用气块做的。CAPE、抬升指数、K指数和skew-T上每个稳定度数字，都假设公里尺度的涡旋可以被当作一个从不与邻居说话的孤立热力学团块来处理。真实上升气流以$10^{-2}\ \mathrm{s^{-1}}$卷夹环境空气，所以一朵以$10\ \mathrm{m\,s^{-1}}$上升、一千秒里爬升$10\ \mathrm{km}$的云，已把自身体积混进来十遍，其浮力只有气块值的一半。卷夹不是订正项；它是观测上升气流系统性地弱于气块理论预言的原因。凝结物不会即时移除。标准的液态水与冰水假设在CAPE上有两倍的跨度，因为把十克云水带上一公里耗掉的浮力相当于一度的冷却。热泡周围的气压不是均匀的。一个浮力羽流要加速它自己的环境，一个量级三分之一的附加质量项因此削减它的加速度。环境不是那份探空。无线电探空仪是一公里空气里一厘米的样本，一天一次、来自一个地方，而它采到的亚云层才是决定任何东西能否上升的部分。湿空气不是理想气体加潜热。以现代探空仪和卫星探测仪的精度，水汽的非理想性、液态水的热容、过冷份额和冻结时的冰点下降都要紧，这就是共同体自1980年以来三次修订参考公式的原因。而直减率不由辐射或对流单独设定。观测到的热带$6.5\ \mathrm{K\,km^{-1}}$是对流约束、辐射冷却、大尺度上升、以及每朵云里干空气卷夹之间的平衡，而哪一项赢的问题已悬而未决六十年——这就是气候模型在对流层上层会暖多少上有分歧的原因，而那是气候敏感度离散度最大的单一来源。
:::

$dq = 0$的第一定律给出$c_p\,dT = (1/\rho)\,dp$，所以$dT/dz = -g/c_p$。气块没有向任何东西散热——辐射松弛要一周而上升只要几分钟。它消耗内能把邻居推开。
:::
:::

::: summary
- 干空气服从$p = \rho R_d T$；水汽让空气变轻，而虚温承担着云朵的全部浮力。
- 静力平衡让气压以8.4 km标高指数下降，所以一半大气在5.5 km以下。
- 静力水压方程让层厚度成为温度计：暖柱隆起，而高空图是温度图。
- 上升气块以$9.8\ \mathrm{K\,km^{-1}}$干绝热冷却，而位温守恒。
- 稳定度由布伦特-维伊萨拉频率度量，其典型的五到十分钟浮力周期是大气垂直方向的钟。
- 潜热把直减率压低到热带低至$4\ \mathrm{K\,km^{-1}}$，这就是对流层顶在热带高8 km的原因。
- CAPE是气块与探空之间的面积；$w \approx \sqrt{2\,\mathrm{CAPE}}$，而一顶盖子决定它是否被释放。
:::

## 练习

::: exercise 虚温 {level=1 check="295.7"}
求$293\ \mathrm{K}$、混合比$15\ \mathrm{g\,kg^{-1}}$空气的虚温。
::: solution
$T_v = 293(1 + 0.61\times0.015) = 295.7\ \mathrm{K}$——仅湿度就带来$2.7\ \mathrm{K}$的表观增温。那$2.7\ \mathrm{K}$就是海洋信风积云层的全部浮力，也是探空被化约成干空气会系统性低估热带不稳定性的原因。
:::
:::

::: exercise 高度上的气压 {level=1 check="710"}
求等温$288\ \mathrm{K}$、$p_0 = 1013\ \mathrm{hPa}$大气中**3000 m**处的气压。
::: solution
$p = 1013\,e^{-3000/8430} = 710\ \mathrm{hPa}$。三公里、百分之三十的质量——这就是$700$-hPa图是天气层中部地图的原因，也是$3\ \mathrm{km}$的高山天文台在静风之夜坐在行星边界层大部分之上的原因。
:::
:::

::: exercise 位温 {level=1 check="286"}
求$273\ \mathrm{K}$、$850\ \mathrm{hPa}$空气的位温。
::: solution
$\theta = 273\times(1000/850)^{2/7} = 286\ \mathrm{K}$。仅压缩就带来十三K的表观增温——这就是同温不同压的两个气团不属于同一气团的原因，也是位温而非温度首先定义气团的原因。
:::
:::

::: exercise 布伦特-维伊萨拉频率 {level=2 check="8.3"}
求$\theta_v = 310\ \mathrm{K}$、$\partial\theta_v/\partial z = 5\ \mathrm{K\,km^{-1}}$处的浮力周期。
::: solution
$N^{2} = (9.81/310)\times5\times10^{-3} = 1.58\times10^{-4}\ \mathrm{s^{-2}}$，$N = 1.26\times10^{-2}\ \mathrm{s^{-1}}$，$2\pi/N = 500\ \mathrm{s} = 8.3\ \mathrm{min}$。这是一个强稳定层——下沉逆温、夜间稳定边界层、或云顶边界层的顶部——而同样这八分钟的钟设定其中形成的任何重力波或晴空湍流层的垂直波长。
:::
:::

::: exercise 云底 {level=2 check="1000"}
地表空气$22\ \mathrm{^\circ C}$、露点$14\ \mathrm{^\circ C}$。求抬升凝结高度。
::: solution
$z_{\mathrm{LCL}} = 125\times8 = 1000\ \mathrm{m}$。一千米处的积云云底，在一百公里范围内一般高——日常生活中绝热热力学最司空见惯的确认，也是单个地表露点给出的云底预报胜过多数模型的原因。
:::
:::

::: exercise 对流有效位能 {level=2 check="271"}
气块在**4-km**层内有浮力、平均虚温超出$2\ \mathrm{K}$、环境$\overline{T_v} = 290\ \mathrm{K}$。求CAPE。
::: solution
$\mathrm{CAPE} = 9.81\times(2/290)\times4000 = 271\ \mathrm{J\,kg^{-1}}$，卷夹前给出$w = \sqrt{2\times271} = 23\ \mathrm{m\,s^{-1}}$。这是一场寻常的午后雷暴——出阵风和小冰雹、但少有龙卷的那种，龙卷需要$1500\ \mathrm{J\,kg^{-1}}$以上加上强的深层切变。
:::
:::

::: exercise 层的厚度 {level=3 check="5780"}
求平均虚温$285\ \mathrm{K}$时**1000–500-hPa**层的厚度。
::: solution
$\Delta z = (287/9.81)\times285\times\ln 2 = 5780\ \mathrm{m}$。$\overline{T_v} = 265\ \mathrm{K}$的冷层给出$5375\ \mathrm{m}$——同样气压区间上少四百米。那四百米的厚度差就是通过热成风驱动急流的压力梯度，也是急流在精确意义上是温度对比而非风的原因。
:::
:::

::: exercise 变暖的气柱 {level=3 check="203"}
若**1000–500-hPa**层均匀增暖$10\ \mathrm{K}$，其厚度增加多少？
::: solution
$\Delta(\Delta z) = (R_d/g)\,\Delta\overline{T}\,\ln(p_1/p_2) = 29.3\times10\times0.693 = 203\ \mathrm{m}$。整个对流层十度增暖让500-hPa面抬升两百米——过去六十年气压面的多年代际上升观测，是对流层真正变暖最直接、最少模型依赖的确认之一：不是温度计测的，是气压计测的。
:::
:::
