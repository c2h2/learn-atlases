你天气应用里的每一个数字——温度、风、湿度、污染预报——都来自**大气边界层**内部，那层公里厚、直接感知地面、每天把低层大气每个颗粒翻新一二十遍的空气壳层。太阳热在这里进入大气，让大风停转的摩擦在这里做功，云在这里开始，而人类对天气和空气质量的全部暴露几乎都在这里发生。它的物理是一场单一的斗争：在表面由切变和浮力诞生的湍流试图从下方混合这层，而地球自转和层结试图压制它，这场斗争的昼夜节律是气象学中最可预测的节奏。

## 湍流引擎

::: definition Reynolds分解、湍流通量与摩擦速度 {#def-fluxes}
边界层里每个量都拆成平均与脉动，$w = \bar w + w'$，平均在几分钟的湍流时标上取。两个脉动的协方差$\overline{w'\phi'}$是$\phi$的**湍流通量**——涡的垂直输送，单位是每平米每秒的$\phi$——它是边界层的核心对象，因为平均流单靠分子扩散的垂直热、汽、动量输送慢一千倍。水平动量的垂直通量定义**摩擦速度**
$$
u_* = \sqrt{\frac{|\overline{u'w'}|}{\rho}}, \qquad \tau = \rho\,u_*^{2},
$$
一个速度尺度（陆上$0.1$–$0.5\ \mathrm{m\,s^{-1}}$、风暴中可达$1\ \mathrm{m\,s^{-1}}$），它不是风而是应力的平方根：涡携带观测应力所需的速度。$\rho = 1.2\ \mathrm{kg\,m^{-3}}$、$0.1\ \mathrm{N\,m^{-2}}$的表面应力给$u_* = 0.29\ \mathrm{m\,s^{-1}}$。下面几乎每条廓线律都用$u_*$及其热通量兄弟写出，因为表面与大气交换的是通量而非风。
:::

## 对数廓线

::: proposition 由混合长闭合导出对数律 {#prop-loglaw}
假设（i）应力在表面层内随高度恒定——最低$50\ \mathrm{m}$内精确到几个百分点——（ii） **Prandtl混合长**：涡在失去身份前行进的距离正比于离壁的距离，$\ell = \kappa z$，并跨该距离混合动量，$\overline{u'w'} = -\ell^{2}|\partial U/\partial z|\,\partial U/\partial z$。取$\overline{u'w'} = -u_*^{2}$，中性层结下得
$$
\frac{\partial U}{\partial z} = \frac{u_*}{\kappa z} \;\Longrightarrow\; U(z) = \frac{u_*}{\kappa}\,\ln\frac{z}{z_0}, \qquad \kappa = 0.40,
$$
即**对数风廓线**：风每$e$倍高度增$u_*/\kappa \approx 2.5\,u_*$；$z_0$即**粗糙度长度**——海面和冰面零点几毫米、草和雪$1$–$5\ \mathrm{cm}$、农田$10$–$20\ \mathrm{cm}$、灌丛半米、森林和城市数米——是外推风消失的高度，下垫面类型的经验指纹。对数律是大气科学中被验证最多的关系，在陆地、冰、淡水冰穴和海面上都成立，这就是单个风速计读数能被订正到任何别的高度、风机立在高塔上、风在光滑表面"夜死"而森林保持其阻力的原因。
:::

::: example 读对数律 {#ex-loglaw}
$z_0 = 0.05\ \mathrm{m}$的农田上$u_* = 0.30\ \mathrm{m\,s^{-1}}$。求$2\ \mathrm{m}$（观测高度）、$10\ \mathrm{m}$（标准杆）和$80\ \mathrm{m}$（风机轮毂）的风。
::: solution
$$
U(2) = \frac{0.30}{0.40}\ln\frac{2}{0.05} = 3.0\ \mathrm{m\,s^{-1}}, \quad
U(10) = 0.75\,\ln 200 = 4.0\ \mathrm{m\,s^{-1}}, \quad
U(80) = 0.75\,\ln 1600 = 5.5\ \mathrm{m\,s^{-1}} .
$$
风机看到的风比观测高度多百分之八十五——而风机功率按$U^{3}$走，轮毂高度读错约等于功率翻倍。同样的算术订正着每条历史站点记录：网络现代化中把风杆从$25\ \mathrm{m}$降到$10\ \mathrm{m}$，若不拿对数律均一化序列，会引入约$0.8\ \mathrm{m\,s^{-1}}$的伪"风速减弱"——气候趋势分析者每天与之相处的警世故事。
:::
:::

## 稳定度：Monin–Obukhov相似

::: definition Obukhov长度与稳定度订正 {#def-obukhov}
从下方加热造出浮力涡，加在切变混合上；从下方冷却比切变造湍流更快地毁掉湍流。无量纲的平衡就是**Obukhov长度**
$$
L = -\frac{u_*^{3}}{\kappa\,\dfrac{g}{\theta_v}\,\overline{w'\theta_v'}}, \qquad \zeta = \frac{z}{L},
$$
湍流浮力产生等于切变产生时的高度：$L < 0$在白天（不稳定，热通量向上），$L > 0$在夜间（稳定），热通量消失时$|L| \to \infty$（中性）。**Monin–Obukhov相似理论**（1954）——表面层的通量和梯度对高度的依赖只通过$\zeta$——给出订正廓线，
$$
U(z) = \frac{u_*}{\kappa}\left[\ln\frac{z}{z_0} - \psi_m(\zeta)\right], \qquad
\theta(z) - \theta_0 = \frac{\theta_*}{\kappa}\left[\ln\frac{z}{z_{0h}} - \psi_h(\zeta)\right], \qquad \theta_* = -\frac{\overline{w'\theta'}}{u_*},
$$
经验稳定度函数$\psi_m \approx -5\zeta$（$\zeta > 0$，稳定：风每米高度的转向远快于对数律所说）、$\psi_m \approx 2\zeta^{1/4}$（$\zeta < 0$，不稳定：廓线向对流混合层形态压平）。理论在其假设失效处失效——夜间强稳定下、冠层上、复杂地形上——而那些失效是边界层研究和每份预报最糟时段的日常内容。
:::

::: example 稳定层有多浅 {#ex-obukhov}
黄昏时$u_* = 0.30\ \mathrm{m\,s^{-1}}$、$\theta = 300\ \mathrm{K}$、向上热通量塌缩到$\overline{w'\theta_v'} = -0.02\ \mathrm{K\,m\,s^{-1}}$（微弱向下通量，表面冷却空气）。求$L$和$\zeta = 1$的高度；然后解释为什么夜间$10\ \mathrm{m}$的风能翻倍而表面冷却$5\ \mathrm{K}$。
::: solution
$$
L = -\frac{(0.30)^{3}\times 300}{0.4\times9.81\times(-0.02)} = +103\ \mathrm{m}, \qquad z = |L| = 103\ \mathrm{m}.
$$
$103\ \mathrm{m}$以上按这个度量"不算稳定"，但其下湍流正被掐死：夜的热通量不只是小，它**逆着通量梯度**——从下方冷却让标量廓线变得下密上轻，并按单位质量$\overline{w'\theta'}/\theta < 0$的速率抽走湍流的能量。观测到的$10\ \mathrm{m}$风翻倍不是对数律在起作用而是**夜间低空急流**：夜的稳定层把表面与其上空气脱耦，不再被摩擦对抗的科里奥利力把高空的风转向地转、在日落后$1$–$3\ \mathrm{h}$加速出一股浅急流——[[atmospheric-dynamics/equations-of-motion]]的惯性振荡在一个如今绝热的表面上自由运行。
:::
:::

## 表面能量平衡

::: definition 净辐射的分配 {#def-energy-balance}
边界层由一本账驱动，**表面能量平衡**，
$$
R_n = G + H + LE ,
$$
净辐射（吸收太阳减发射红外，白天$50$–$700\ \mathrm{W\,m^{-2}}$）、地热传导$G$（植被陆地占$5$–$10\%$、裸土和水体更大）、感热$H = \rho c_p\,\overline{w'\theta'}$（湍流的热）和潜热$LE = \rho L_v\,\overline{w'q'}$（蒸散发，$L_v = 2.4\ \mathrm{MJ\,kg^{-1}}$）。**Bowen比**$\beta = H/LE$是分配钥匙：海洋和供水充足的作物$\beta \approx 0.2$–$0.5$，干旱牧场和沙漠$\beta \approx 2$–$5$，那里太阳的功几乎全用于加热空气而非蒸发水。控制既是物理的也是生物和农业的：热浪干透根区时$\beta$跳升，曾经蒸发水的同一辐射如今加热观测温度，陆地把热浪喂回给自己——正是这种陆-气耦合让2003年欧洲和2010年俄罗斯事件的致死率是海表温度单独预测的两倍。
:::

::: example 分配一个夏日正午 {#ex-bowen}
小麦站正午$R_n = 520\ \mathrm{W\,m^{-2}}$、$G = 40\ \mathrm{W\,m^{-2}}$、作物供水充足、$\beta = 0.35$。求$H$和$LE$；若正午值持续$14\ \mathrm{h}$的白天，求蒸散发率（$\mathrm{mm\,d^{-1}}$）。
::: solution
$H + LE = 480\ \mathrm{W\,m^{-2}}$、$H = 0.35\,LE$，得$LE = 480/1.35 = 356\ \mathrm{W\,m^{-2}}$、$H = 124\ \mathrm{W\,m^{-2}}$。蒸发率为
$$
E = \frac{356}{2.45\times10^{6}} = 1.45\times10^{-4}\ \mathrm{kg\,m^{-2}\,s^{-1}} = 0.52\ \mathrm{mm\,h^{-1}},
$$
正午值若持续$14\ \mathrm{h}$，作物蒸腾约$7\ \mathrm{mm}$。每天七毫米水——比多数降雨还多——是一片健康麦田在热浪一周里抽走的水量，这就是灌溉能让景观降温数开尔文、而灌溉失效是农业灾害第一步隐性棋的原因。干燥土壤$\beta = 4$的同样算术给$LE = 96\ \mathrm{W\,m^{-2}}$、$H = 384$：同一个太阳，四倍感热，四分之一的水。
:::
:::

## 对流边界层

::: definition 白天CBL的结构与增长 {#def-cbl}
白天加热让最低一公里多**绝热**：位温几乎不随高度变、静力稳定度为零、湍流旺盛到整层表现为一台有三个命名部分的对流烤箱——薄的**表面层**（对数律世界，深度的$\sim 5$–$10\%$）、标量充分混合、热泡涌动的**混合层**，以及**夹卷层**，$100$–$300\ \mathrm{m}$云顶空气交叠、从下方侵蚀顶部逆温。整层的速度尺度是**对流速度**
$$
w_* = \left(\frac{g}{\theta_v}\,\overline{w'\theta_v'}\,z_i\right)^{1/3} \approx 1.5\text{–}2.5\ \mathrm{m\,s^{-1}},
$$
其深度按表面通量对抗逆温阻力的速率夹卷上方暖自由大气而增长：
$$
\frac{\mathrm{d}z_i}{\mathrm{d}t} = \frac{1.1\left(1 + 5R_f\right)\overline{w'\theta_v'}_s}{\Delta\theta}, \qquad R_f \approx 0.2 ,
$$
$\Delta\theta$为逆温强度。表面热通量$0.12\ \mathrm{K\,m\,s^{-1}}$、盖强$3\ \mathrm{K}$的典型春日，$z_i$以$9\ \mathrm{cm\,s^{-1}}$增长——午后初$2\ \mathrm{km}$，这就是09:00在1000米勉强成云的热泡15:00顶到2500米、污染预报的混合高度是日出到日落抛物线、夜间在高空形成的逆温是明天霾出生其下的盖子的原因。
:::

::: example 烤箱注满 {#ex-cbl-growth}
08:00混合层深$400\ \mathrm{m}$、盖$3\ \mathrm{K}$顶部逆温，表面热通量线性升至13:00的$0.15\ \mathrm{K\,m\,s^{-1}}$、18:00回到零。取$R_f = 0.2$估计15:00的深度，以及夜间残留层的深度。
::: solution
通量峰值时增长率为$\mathrm{d}z_i/\mathrm{d}t = 1.1\times2\times0.15/3 = 0.11\ \mathrm{m\,s^{-1}}$；08:00–15:00三角通量窗取平均得平均表面通量$0.075\ \mathrm{K\,m\,s^{-1}}$、平均增长率$0.055\ \mathrm{m\,s^{-1}}$、深度增益$0.055\times7\times3600 \approx 1.4\ \mathrm{km}$，所以$z_i(15{:}00) \approx 1.8\ \mathrm{km}$。日落之后表面层脱耦、混合层塌缩为**残留层**——白天层结中性的遗骸，几百米厚、被新的夜间逆温盖住——次日清晨第一批热泡在那里找到昨天的尘、花粉和臭氧，而傍晚第一批风筝和无人机飞行采样的就是白天的记忆。
:::
:::

::: warning 你测到的风不是驱动天气的风，"静风"是一句通量的话，而边界层不是对流层
五种混淆。**观测高度的风是廓线里最慢的风**：驱动天气的地转风住在边界层之上，通常比地面风快$5$–$10\ \mathrm{m\,s^{-1}}$、逆时针偏开$20$–$40^{\circ}$——每个扩散、风能和飞沫计算都必须订正这个差。**"静"空气仍携带通量**：热天$0.5\ \mathrm{m\,s^{-1}}$的微风能比冷天$10\ \mathrm{m\,s^{-1}}$的大风搬运更多热，因为通量取决于协方差而非风速——风速计对引擎撒谎。**表面层不是边界层**：对数律的$10\ \mathrm{m}$世界是CBL深度的$5\%$，把它的梯度向上外推会把混合层梯度高估一个量级——早期气候模型表面通量的经典错误。**边界层不是对流层**：对流层$10\ \mathrm{km}$深、大部分不接触地面；边界层是接触的那部分，混淆两者会把每个云底、逆温和封顶的说法翻个底朝天。**还有城市边界层是另一种气候**：城市添粗糙度（阻力十倍）、蓄热（墙在夜里放热）和废热的热通量，把其混合层抬高$300$–$500\ \mathrm{m}$、最低气温比郊区高$3$–$8\ \mathrm{K}$——城市热岛是教科书意义的边界层现象，而且它正比全球均值暖得更快。
:::

::: history
混合长思想是**Ludwig Prandtl**1925年从哥廷根湍流学派来的；稳定与不稳定表面层的相似框架是**A. S. Monin**和**A. M. Obukhov**1954年来自**Obukhov**及同僚的莫斯科学派的论文，其后的二十年里稳定度函数在从**C. H. B. Priestley**和**W. Swinbank**的Aspendale塔计划到1969年**Wangara**试验（至今仍是对流层的经典数据集）的各站测得，还有大型陆面试验**FIFE**（1987–89）和**HAPEX-MOBILHY**（1987）。混合层增长律的夹卷闭合出自1970年代的混合层建模浪潮，而热浪与土壤干度的陆面耦合由1990年代的**HAOPEX**、**EFEDA**和**EVA-Grafs**分析确立。
:::

作为混合长闭合基础的湍流动能收支源自 [[atmospheric-dynamics/equations-of-motion]] 的动量方程；决定这层能否混合的稳定度在 [[meteorology/stability]]，CBL顶托的云在 [[atmospheric-dynamics/cloud-physics]] 和 [[meteorology/clouds-precipitation]]，日循环在预报中的作用在 [[meteorology/forecasting]]，夜间急流的天气尺度表亲在 [[meteorology/storms]]，表面通量的气候角色在 [[climate-system/energy-budget]] 和 [[climate-system/hydrological-cycle]]，混合层稀释的气溶胶在 [[atmospheric-chemistry/aerosols]] 和 [[atmospheric-chemistry/air-quality]]，陆面热浪机制在 [[climate-change/extremes]]。

::: quiz
晴朗平静的夜里，$10\ \mathrm{m}$的风常在日落后、表面冷却之际反而增大。主要原因是
- [ ] 空气稳定化使对数律变陡。
- [x] 与表面摩擦脱耦让科里奥利力加速一股低空急流。
- [ ] 高空空气的热膨胀。
- [ ] 海风锋抵达。
::: solution
稳定化**压制**向下传输动量的湍流，表面阻力随之塌缩；稳定层上的风不再被刹住，经历向地转的惯性振荡，在日落后$1$–$3\ \mathrm{h}$造出夜间低空急流。对数律恰恰是停止适用的东西——夜晚是Monin–Obukhov相似的失效工况，而急流就是风机能出现夜间功率峰值的原因。
:::

::: summary
- 边界层是摩擦驱动、公里厚、每日呼吸的壳层，天气在此与表面相遇；它的货币是湍流通量而非风。
- 恒定应力加Prandtl混合长给出对数律$U = u_*\kappa^{-1}\ln(z/z_0)$——本学科被验证最多的廓线、一切高度和粗糙度订正的基础。
- Monin–Obukhov相似通过$L = -u_*^{3}\theta_v/(\kappa g\,\overline{w'\theta_v'})$加入稳定度；理论把白天组织得很好，却在夜间、冠层和复杂地形上失效。
- 表面能量平衡$R_n = G + H + LE$及其Bowen比决定太阳的功是加热空气还是蒸发水——灌溉降温和热浪放大的杠杆。
- 白天对流边界层绝热、以夹卷层封顶、按$w_*$标度、以厘米每秒对抗其逆温增长——每份空气质量预报的混合高度抛物线。
- 夜间这层脱耦、残留层保存白天的空气、低空急流在绝热表面上跑惯性振荡。
:::

$\rho = 1.2\ \mathrm{kg\,m^{-3}}$、表面应力$0.15\ \mathrm{N\,m^{-2}}$，求$u_*$（$\mathrm{m\,s^{-1}}$，两位小数）。
::: solution
$u_* = \sqrt{0.15/1.2} = 0.35\ \mathrm{m\,s^{-1}}$。摩擦速度是以速度表示的应力；$0.2$–$0.5$是陆上寻常范围，而它是本课每条廓线律里出现的速度尺度。

::: exercise 观测高度风 {level=1 check="3.1"}
$u_* = 0.30\ \mathrm{m\,s^{-1}}$、$z_0 = 0.03\ \mathrm{m}$，求中性$2\ \mathrm{m}$风（$\mathrm{m\,s^{-1}}$，一位小数）。
::: solution
$U(2) = (0.30/0.40)\ln(2/0.03) = 0.75\times4.2 = 3.1\ \mathrm{m\,s^{-1}}$。观测高度的风只是廓线顶端的一小截——同一应力在$10\ \mathrm{m}$给$4.4\ \mathrm{m\,s^{-1}}$——这就是每个风能和蒸散发计算必须做的订正。

$R_n = 500\ \mathrm{W\,m^{-2}}$、$G = 20\ \mathrm{W\,m^{-2}}$、$\beta = 2$。求$LE$（$\mathrm{W\,m^{-2}}$）。
::: solution
$LE = (R_n - G)/(1+\beta) = 480/3 = 160\ \mathrm{W\,m^{-2}}$、$H = 320$。旱地分配：可用能量的三分之二直接加热空气，这就是沙漠表面烫、牧场热浪随土壤变干而增强的物理原因。

::: exercise Obukhov长度 {level=2 check="21"}
$u_* = 0.30\ \mathrm{m\,s^{-1}}$、$\theta_v = 300\ \mathrm{K}$、$\overline{w'\theta_v'} = 0.1\ \mathrm{K\,m\,s^{-1}}$（白天），求$|L|$（米，取整）。
::: solution
$L = -0.30^{3}\times300/(0.4\times9.81\times0.1) = -21\ \mathrm{m}$：加热的白天表面层全程不稳定——$21\ \mathrm{m}$以上$z/|L| > 1$——这就是白天廓线向混合层形态压平、对数律只在头几十米适用的原因。
:::

::: exercise 对流速度 {level=2 check="1.7"}
$\overline{w'\theta_v'} = 0.1\ \mathrm{K\,m\,s^{-1}}$、$\theta_v = 300\ \mathrm{K}$、$z_i = 1500\ \mathrm{m}$，求$w_*$（一位小数）。
::: solution
$w_* = (9.81\times0.1\times1500/300)^{1/3} = (4.9)^{1/3} = 1.7\ \mathrm{m\,s^{-1}}$。热泡和轻型飞机就活在这个尺度里：典型热泡上升气流核心为$1$–$2\,w_*$，而CBL的全部输送由这个速度和层深的涡组织。
:::
:::

::: exercise 廓线比 {level=2 check="1.5"}
$z_0 = 0.03\ \mathrm{m}$上的中性对数律，求比值$U(20)/U(2)$（一位小数）。
::: solution
比值为$\ln(20/0.03)/\ln(2/0.03) = 6.5/4.2 = 1.5$。高度翻十倍、风多一半——$e$倍规则（每$e$倍$2.5\,u_*$）的实际版，也是从观测数据外推轮毂高度对假定的粗糙度如此敏感的原因。
:::

::: exercise 推导对数律 {level=3 check="0.75"}
从$\overline{u'w'} = -\ell^{2}|\partial U/\partial z|(\partial U/\partial z)$、$\ell = \kappa z$、恒定应力$u_*^{2}$出发，推导$\partial U/\partial z = u_*/(\kappa z)$，并计算$u_* = 0.30\ \mathrm{m\,s^{-1}}$时每$e$倍高度的风速增量（$\mathrm{m\,s^{-1}}$，两位小数）。
::: solution
令$u_*^{2} = \kappa^{2}z^{2}(\partial U/\partial z)^{2}$、取正根，$\partial U/\partial z = u_*/(\kappa z)$；积分得$U = u_*\kappa^{-1}\ln(z/z_0)$，所以每$e$倍高度的增量为$u_*/\kappa = 0.30/0.40 = 0.75\ \mathrm{m\,s^{-1}}$——等价于每十倍高度$1.7\ \mathrm{m\,s^{-1}}$。整条对数律就是一个闭合假设的一次积分；它与观测的普适吻合是表面层气象学的经验基石。
:::
:::

::: exercise 混合层增长 {level=3 check="0.09"}
表面热通量$0.12\ \mathrm{K\,m\,s^{-1}}$、逆温强度$\Delta\theta = 3\ \mathrm{K}$、$R_f = 0.2$，由平板夹卷公式求$\mathrm{d}z_i/\mathrm{d}t$（$\mathrm{m\,s^{-1}}$，两位小数）。
::: solution
$\mathrm{d}z_i/\mathrm{d}t = 1.1(1+5\times0.2)\times0.12/3 = 2.2\times0.12/3 = 0.088 \approx 0.09\ \mathrm{m\,s^{-1}}$。保持六小时可把混合层加深$1.9\ \mathrm{km}$——观测到的春季增长率——而公式的信息是同时支配污染和对流的那个权衡：强表面通量加深这层（利于稀释、利于热泡），强盖子压制它（不利于空气质量、利于夜间霾），预报中的一天由太阳选中哪一个决定。
:::
