一个集水是一个**的非线性的、的时变的、空间的的分布的**的系统、单位水文线——它**线性的**、**时不变的**、能以一个**单一的曲线**描述的假设——是科学最成功的错误的思想之一。它使用九十年设计每一个桥、的的涵洞、的的堤、每一个的的溢洪道在地球、预报每一个警告服务发布的洪水、估计每一个从不观察的设计的洪水。它工作、因为一个集水的**非线性的**大多数的在风暴生成的径流的**量**、它以渗透、存储的计算单独计算、只温和的在水一旦移动旅行的**方式**。

## 水文的的图、它的分解

::: definition 水文的的图、单位水文线、它的三个假设 {#def-uh}
一个**风暴的水文的的图**在的的出口的排放对着时间、它分解成一个**的的直接的径流**——风暴的快的响应、地面的流动、的的的的流、快的的的管、断裂的网络——一个**的的基流的**——已经在那的存储的的慢的排干。**的的谢尔曼的**（1932）的**单位水文线**将产生的**一个单位**（1毫米、1英寸）的**的过剩的**的雨量在一个集水**均的的**落下、以一个**均的的**的持续时间的直接的径流的水文的的图、方法依靠三个假设：
$$
\begin{aligned}
&\textbf{线性的：} && Q(t) = \sum_{i} E_i\,u(t - i\,\Delta t) \\
&\textbf{时不变的：} && u \ \text{不依赖风暴什么时候落下} \\
&\textbf{的的叠加的：} && \text{过剩的连续的的爆发添加它们的响应}
\end{aligned}
$$
带一个在连续的时间的间隔的过剩$E_1, E_2, \ldots$、一个测量的直接的径流的水文的的图$Q_1, Q_2, \ldots$、单位水文线以**的的的的解卷积的**恢复、以**的的卷积的**应用给一个新的风暴。在没有测量的风暴存在的地方、**合成的**单位水文线——**USGS的三的角的**、**USACE**、**的的伽马的**、**的的纳什的的级联的**、**的的克拉克的**存储的模型——从集水的**面积**、**集中的的时间**、**滞后的时间**供应一个曲线。

假设的**失败**是系统的、知的。**线性的失败**、因为快的的的通路**饱和**只在湿润的条件、所以从一个**小的**风暴推导的一个集水的单位水文线**低估**一个**大的**的峰值以20–50百分之一——**的的变的的源的的面积**生产、英国的**的的单一的事件的集水的分析**试图移除的**非线性的**。**的时不变的失败**、因为植被、**土壤的的湿度**、**雪**季节的改变、所以一个**冬的**单位水文线在同一个集水比一个**夏的**的**更快**、**更大**。**过剩的均的的失败**最严重的：一个它的中心落在一个集水的**快的**部分的**的的对流的**的风暴给一个同一个总的深度落在**慢的**部分的峰值的**二的倍**、过剩的**空间的**的分布是一个单位水文线的预报最大的单一的误差的来源。
:::

::: definition 集中的的时间、滞后、形状的的参数 {#def-tc}
**的集中的的时间**$t_{\mathrm{c}}$是水从**水力的最远的**的点旅行到出口的时间、它设定单位水文线的**标度**。它从不测量、总**估计**、以在同一个集水的不一致是一个二的的倍的因子的经验的公式：
$$
\textbf{的的柯匹奇的：}\quad t_{\mathrm{c}} = 0.0195\,L^{0.77}S^{-0.385}\ \text{分钟}, \qquad
\textbf{的的麦克科的：}\quad t_{\mathrm{c}} = \frac{L}{670\,V}, \qquad
\textbf{FAA:}\quad t_{\mathrm{c}} = \frac{3.62\,A^{0.6}}{S^{0.3}} ,
$$
以$L$最长的的的通路以米、$S$的的坡以m m⁻¹。**的的滞后的时间**$t_{\mathrm{p}}$——从过剩的的**的的的的质心的**到**峰值**的时间**——然后以一个$t_{\mathrm{c}}$的的分数取、最常$t_{\mathrm{p}} = 0.6\,t_{\mathrm{c}}$、**USACE**的$t_{\mathrm{p}} = 0.55\,t_{\mathrm{c}} + t_{\mathrm{r}}/4$、**的的三的角的的单位水文线**有一个$t_{\mathrm{b}} = 2.01\,t_{\mathrm{p}}$的**的的底的的时间**、一个$Q_{\mathrm{p}} = 0.208\,A/t_{\mathrm{p}}$的**峰值**、以$A$以km²、$Q$以每毫米的m³ s⁻¹。

**的的纳什的的级联的**以$n$个串联的**的的线性的蓄的**的的伽马的的分布替换三的角形、
$$
q(t) = \frac{1}{K\,\Gamma(n)}\left(\frac{t}{K}\right)^{n-1} e^{-t/K}, \qquad t_{\mathrm{p}} = (n-1)K,
$$
它的两个参数有物理的的读：$K$是**旅行-时间**的标度、$n$**的的分散的**、**存储的的元素的数**、$n$观察**以集水的面积减少**——从一个的的山坡的5–8给一个大的河的1.5–2.5、因为一个更大的集水有一个**更宽的**旅行-时间的分布。**的的洪水的的波**自己是在的的渠道的**的的运动学的**、**的的扩散的**的响应、它的**的的的的速的**以一个$1/m$的因子超过**水的的速率**（以$m$速率-排放的指数、一个**的的曼宁的**的的渠道的5/3）、所以一个洪水**峰值**比携带它的**水**旅行**更快**——一个**洪水的的波**在你带它释放的**示踪的**之前到达的理由。
:::

::: example 以的的解卷积推导一个单位水文线 {#ex-deconv}
一个集水在第一个2-的的时的间隔接收$E_1 = 20\ \mathrm{mm}$的过剩、第二个$E_2 = 30\ \mathrm{mm}$、在它之后没有东西。在2-的的时的间隔的测量的直接的径流的水文的的图是$100$、$450$、$650$、$380$、$140$、$30\ \mathrm{m^{3}\,s^{-1}}$。推导2-的的时的单位水文线、集水的面积。
::: solution
卷积$Q_j = \sum_i E_i\,u_{j-i+1}$一步步倒：
$$
u_1 = \frac{Q_1}{E_1} = \frac{100}{20} = 5, \qquad
u_2 = \frac{Q_2 - E_2 u_1}{E_1} = \frac{450 - 150}{20} = 15,
$$
$$
u_3 = \frac{650 - 30\times15}{20} = 10, \qquad
u_4 = \frac{380 - 30\times10}{20} = 4, \qquad
u_5 = \frac{140 - 30\times4}{20} = 1,
$$
检查是$Q_6 = E_2 u_5 = 30\times1 = 30$ ✓。单位水文线因此$(5, 15, 10, 4, 1)\ \mathrm{m^{3}\,s^{-1}}$每毫米、它的体积必须等于一个集水之上的1毫米：
$$
A = \frac{\sum u_i\,\Delta t}{0.001} = \frac{35\times7200}{0.001} = 2.52\times10^{8}\ \mathrm{m^{2}} = 252\ \mathrm{km^{2}} .
$$

**算术**琐碎、**判断**是所有。**的的基流的**必须首先移除、分离是一个**选择**——的的直的的线的的方、**的的的的佩蒂的约翰的**与的的的的亨的的滤的的器、**的的埃克哈特的**递推的的滤的的器、**的的退水的的连续性的**的方——它改变推导的单位水文线的**体积**、因此**面积**、一个**错的**分离给一个与**地图**不一致的**面积**、标准的检查。**过剩的**必须**单独地**计算、如果它反而**拟合**、的的解卷积的**圆的的**、单位水文线没有预测的内容。**结果必须测试**：一个它的峰值**负的**、它的**到峰值的时间**小于间隔、它的**面积**与**地图**以超过10百分之一不一致的单位水文线是一个坏的基的的流、一个**空间的非均的的**的风暴的一个**数值的伪影**。

::: example 集中的的时间、的的理性的的方 {#ex-rational}
一个2-km²的城市的集水有一个5000米的最长的的的通路、一个0.02 m m⁻¹的的坡。求的的柯匹奇的集中的的时间、一个带$60\ \mathrm{mm\,h^{-1}}$的强度、一个0.40的径流的的系数的10-的的年的风暴的峰值的排放。

## 的的演算、退水、集水的记忆

::: definition 退水、集水的记忆 {#def-recession}
在风暴之间排放落下、当存储排干、对一个**的的线性的蓄的**落下是**指数的**、
$$
Q(t) = Q_0\,e^{-t/k}, \qquad k = \frac{S}{Q},
$$
以$k$以的的天的**退水的的常的的数**、$S$存储。一个对着时间的的日的排放的**的的半的的对数的**的的图因此是一个**直的的线**、它的**的的斜率的**给$k$、真实的退水在那个的的图**向上凹的**、因为**快的**存储——的的变的的饱和的的的的带、的的管的的网络——首先排干、**慢的**——的的深的的断裂、基质的的地下水——接管。**的的的的主退水的的曲线**、以叠加的事件的退水获得、是仅从的的溪可用的**集水的存储的结构**的最好的估计、**的的基的的流的的指标**——基的的流对着总的的流动的比——是集水的的的地质学的**单一的最好的指标**、从一个**的的白的的垩的**、一个**岩溶的**含水层的**0.95**、一个**粘土**、一个**的的页岩的**的**0.25**范围。

退水的的常的的数是在一个集水之下的**含水层**的一个**水力的**测量：$k$以**的的排干的的间的的间隔的的的的间距**、**的的的的导水的的度**、**的的特的的的的产量**以**的的布森的的克的**的的解关、一个带一个60的的天$k$的一个**的的白的的垩的**的集水、一个带一个3的的天$k$的一个**粘土**的集水在它们的**低的的流动**、它们的**水的的质量**、它们的**生态**、它们的**对抽取的的脆弱性**以一个单一的数预测的恰恰的方式不同。**退水**因此是世界**最便宜的**、最**使用不足的**的水力学的地质学的的信息的来源。
:::

::: definition 洪水的的演算、的的马斯京根的方法 {#def-routing}
**的的演算**传播一个水文的的图向的的下游通过一个河的的**的的河段**、一个**的的蓄的的池**、一个**的的洪泛的的平原**。**的的马斯京根的**方法假设一个的的河段的存储是一个**的的进入的的流**、**的的出去的的流**的线性的组合、
$$
S = K\left[X I + (1 - X)O\right], \qquad 0 \le X \le 0.5,
$$
它带连续性的方程给显的的的的格式
$$
O_2 = C_0 I_2 + C_1 I_1 + C_2 O_1, \qquad C_0 + C_1 + C_2 = 1,
$$
以$K$通过一个的的河段的**旅行时间**（的的时）、$X$**的的楔的的形的**参数、它对一个**的的纯的的蓄的的池**（没有楔的的形）是$0$、对一个**的的纯的的的的平移的**（没有衰减）是$0.5$、对一个自然的河是$0.05$–$0.3$。方法**使衰减**、**延迟**峰值、它的**弱点**在$K$、$X$必须从一个过去的洪水**校准**、**排放的依赖的**、它**不能**表示从一个的的支的的流、一个的的潮的的**的的回水的**、它**守恒质量**、不守恒**的的动量**、所以它在**水力的**流动**非恒的的**、**的的环的的形的**的地方严重失败——的的潮的的的的河段、带堤的的洪泛的的平原。
:::

::: example 退水的的常的的数、的的基的的流 {#ex-recession}
在一个风暴之后一条河的日的平均的排放从$20$落下在15的的天给$10\ \mathrm{m^{3}\,s^{-1}}$、以同一个的的半的的对数的的的的斜率继续落下。求退水的的常的的数、若期间的平均的排放是$14\ \mathrm{m^{3}\,s^{-1}}$的存储、流动从20落下到$2\ \mathrm{m^{3}\,s^{-1}}$的时间。
::: solution
$$
k = \frac{15}{\ln(20/10)} = \frac{15}{0.693} = 21.6\ \text{的的天},
$$
存储、以平均的排放从$S = kQ$、是
$$
S = 21.6\times14\times86{,}400 = 2.6\times10^{7}\ \mathrm{m^{3}} .
$$
落下到$2\ \mathrm{m^{3}\,s^{-1}}$的时间是
$$
t = k\ln\frac{20}{2} = 21.6\times2.303 = 50\ \text{的的天}.
$$
一个**22的的天**的退水的的常的的数是一个**的的地下水支配的**的集水——一个的的白的的垩的、一个的的砂岩的、一个岩溶、一个厚的的碛——到风暴的流动的十分之一的50的天的落下是这样的一个集水的河在一个三的的个月的干旱**流动**、一个**粘土**的集水的不流动的理由。

真实的退水的**的的凹的的的**是信息。一个在的的半的的对数的的的图的**单一的**直的的线是一个**单一的**的的线性的蓄的**的签名、没有真实的集水是；退水的**上的**部分、在最初的1–3的的天、有一个**1–5的的天**的$k$、是**的的变的的源的的面积**、**的的管的的流动**的存储、**的的低的**部分有一个**20–100的的天**的$k$、**的的深的的地下水**。分别拟合两个的的段的给集水的**二的个蓄的**的结构、两个$k$的值的**比**是快的的的通路的**的重要性**的度量——为什么一个**岩溶的**的集水的**退水的的分析**在一个风暴之后显示一个0.5的的天$k$、在一个干旱的90的的天、为什么同一个集水在一个的的时洪水、在一个的的月几乎停止流动。

::: example 通过一个的的河段的的马斯京根的的演算 {#ex-muskingum}
一个河的的河段有$K = 12\ \mathrm{h}$、$X = 0.15$、的的演算的的时间的的步是$\Delta t = 6\ \mathrm{h}$。的的进入的的流在两个的的步之间从$20$上升给$50\ \mathrm{m^{3}\,s^{-1}}$、前的的的的出去的的流是$25\ \mathrm{m^{3}\,s^{-1}}$。求系数、新的的出去的的流、说明方法对洪水的的波做了什么。
::: solution
$$
C_0 = \frac{0.5\Delta t - KX}{0.5\Delta t + K(1-X)} = \frac{3 - 1.8}{3 + 10.2} = 0.091, \quad
C_1 = \frac{3 + 1.8}{13.2} = 0.364, \quad
C_2 = \frac{-3 + 10.2}{13.2} = 0.545,
$$
它们必须总和给1.000、
$$
O_2 = 0.091\times50 + 0.364\times20 + 0.545\times25 = 4.5 + 7.3 + 13.6 = 25.5\ \mathrm{m^{3}\,s^{-1}} .
$$
的的进入的的流上升**150百分之一**、的的出去的的流上升**2百分之一**：一个的的河段**使衰减**上升几乎完全、以一个$K(1 - 2X) = 12\times0.70 = 8.4\ \mathrm{h}$的滞后**延迟**它。

格式的**的的稳定性的**是实践的的的陷。系数**正的**、格式**稳定**只若$0.5\Delta t < K(1 - X)$、这里$3 < 10.2$ ✓；一个**更长**的时间的的步使$C_2$**负的**、的的出去的的流**振荡**、**发散**、一个学生的的演算的代码标准的第一个失败。**校准**是概念的的的陷：$K$、$X$拟合给**一个**洪水、然后应用给一个不同尺寸的**另一个**、在现实$K$以排放**减少**（一个更大的洪水旅行**更快**）、$X$**增加**（一个更大的洪水**更少**使衰减）、所以一个**校准的**马斯京根的的河段**高估**一个**大的**洪水的衰减——它恰恰是使一个**向的的下游的**的的城市洪水的误差的方向。

::: exercise 马斯京根的的稳定性的 {level=3 check="20.4"}
