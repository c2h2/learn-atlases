每年，风卷起数亿吨撒哈拉沙尘，其中约1.8亿吨横渡大西洋——而有约2800万吨落在亚马逊盆地，倾下约2.2万吨雨水淋洗的土壤自产不出的磷：事实证明，这些沙尘大致抵上了河流的输出，而世界最大的雨林，在可测量的意义上，是被世界最大的热沙漠施肥的。这一个事实就装着本课的全部论据：大气不是搅拌碗，而是**一套带屏障、管道和停留时间的输送系统**——几小时冲刷一次的边界层、在$-80\ ^\circ\mathrm{C}$把水冻出去的对流层顶、空气穿越一次、五年后才离开的热带闸门，以及大约以一年为周期的半球交换——慢到工业北半球的甲烷和碳-14在南方的天空里留下一道永久的伤疤。化学发生在气块里；气块在移动；理解运动就是理解化学的一半。

## 冲刷层

::: definition 作为反应器体积的边界层 {#def-cbl}
对流边界层——晴天与地表混合的那一两公里空气——是大部分对流层化学运行的反应器，而它的两个控制体积是**高度**与**风**。在陆地上，它从$100$–$300\ \mathrm{m}$的夜间稳定层长到$1$–$2\ \mathrm{km}$的充分混合的午后深度（在沙漠上和严重污染事件里$3\ \mathrm{km}$），以其顶界每秒几十厘米卷夹自由对流层空气；在寒冷洋面上它保持在几百米以下，而在冰上可以几十米的厚度持续数周。实用的量是**通风系数**：风速×混合高度。一座有$3\ \mathrm{m\,s^{-1}}$的风穿过$1.5\ \mathrm{km}$层的城市几小时就换一遍血，而同一座城市在$1\ \mathrm{m\,s^{-1}}$的风和$200\ \mathrm{m}$的逆温之下——每一个著名灾难的构型，从1948年多诺拉烟雾和1952年伦敦事件（合计约12 000条人命）到印度河-恒河平原和圣地亚哥盆地的每个现代冬天——要几天才换一次血，把它排放制造的东西攒起来。边界层的日循环因此给化学**排班**：NOx和VOCs整夜积累，晨光在混合层上升的体积里点燃臭氧生成，光化学烟雾在午后达峰，而寒冷无光的夜间层把化学切换到硝酸根自由基与夜间氧化——这个节律在每个城市空气质量记录里都表现为叠在季节上的24小时振荡。
:::

::: example 一座城市的每日换血 {#ex-ventilation}
一座$50\ \mathrm{km}$宽的城市白天混合高度$1.4\ \mathrm{km}$、风速$4\ \mathrm{m\,s^{-1}}$。求气团替换时间；并把$200\ \mathrm{t\,day^{-1}}$的$\mathrm{NO_x}$排放（以氮计，原子氮$14\ \mathrm{g\,mol^{-1}}$）表示为稳态浓度。
::: solution
替换时间$= L/u = 5\times10^{4}/4 = 1.25\times10^{4}\ \mathrm{s} \approx 3.5\ \mathrm{h}$。排放为$2\times10^{8}\ \mathrm{g\,N\,day^{-1}} = 2.3\ \mathrm{kg\,N\,s^{-1}}$，反应器体积为$5\times10^{4}\times5\times10^{4}\times1.4\times10^{3} = 3.5\times10^{12}\ \mathrm{m^{3}}$，所以稳态下（忽略化学，对寿命一天的$\mathrm{NO_2}$算宽容）
$$
C = \frac{2.3\times10^{3}}{3.5\times10^{12}/1.25\times10^{4}} = 8\times10^{-6}\ \mathrm{g\,N\,m^{-3}} = 8\ \mu\mathrm{g\,N\,m^{-3}} \approx 26\ \mu\mathrm{g\,m^{-3}}\ \mathrm{NO_2},
$$
一个像样的城市均值——而同样算术换上冬季逆温（$200\ \mathrm{m}$、$1\ \mathrm{m\,s^{-1}}$）会把浓度乘$1.4\times10^{3}/200\times4 = 28$，让城市在**排放毫无变化**的日子里越过世卫限值。这就是空气质量政策部分是气象管理的原因：同一份清单在停滞体制下是不同的暴露。
:::
:::

x: 0, 24
y: 0, 2
labels: h\ (\mathrm{km})
caption: 理想化的日循环边界层高度——$300\ \mathrm{m}$的夜间薄膜变成$1.8$ km的午后混合层。每条城市污染时间序列都是这条曲线乘以排放时刻表：夜间积累、清晨点燃、午后稀释进一天中最深的体积。曲线的冬季版本——一条更浅的正弦、从不离开稳定体制——是地球上每个"空气末日"季的气象签名。
:::

## 屏障：ITCZ、副热带、对流层顶

::: definition 大气的慢门 {#def-barriers}
三道屏障设定对流层的混合日历。**半球之间**，赤道辐合带是一扇虚弱的混合门：半球间交换约需**一年**，所以在工业北半球排放的气体维持着南北梯度——甲烷的约$40$ ppb、一氧化碳的几百ppb——梯度的维持要求源在北方，而其测量（烧瓶网的半球差）是某种气体源半球经典的自上而下约束。**边界层与自由对流层之间**，深对流是快速电梯（数小时，对照慢卷夹的数周），这就是污染和沙尘搭**砧状云外流**的原因：雷暴的排气口在$10$–$15\ \mathrm{km}$把边界层空气连同其臭氧前体和气溶胶核直接注入中纬度西风带。**对流层与平流层之间**，对流层顶是大气最要紧的膜：穿越它需要过热带对流层顶的冷阱（$-80\ \mathrm{^\circ C}$，把水冻到约$5\ \mathrm{ppmv}$——平流层干燥的原因、其臭氧化学非水相的原因、甲烷的平流层水源小而真实的原因），而一旦穿过，空气加入**布雷顿-多布森环流**：经热带管道上升、向极地、在高空纬度下沉，平流层停留约$5$–$6$年，设定CFC、火山硫酸盐和飞机NOx被送进臭氧层并清除出去的步调。对流层顶的识别本身就是一件化学仪器：位温、臭氧和水汽一起跨过它发生阶跃，而**相当位温（$\theta_E$）**——被湿过程守恒——标记着最后与地表说过话的空气。
:::

::: example 读半球差 {#ex-hemigrid}
甲烷年均地表混合比北方比南方高$40\ \mathrm{ppb}$，而北方对南方的源超出为$30\ \mathrm{Tg\,yr^{-1}}$。设每个半球持有半个大气（每半球每ppb CH₄ $= 1.42\ \mathrm{Tg}$），求半球间交换时间。
::: solution
半球间差为$40\times1.42 = 57\ \mathrm{Tg}$，维持它的通量就是北方超出量、即过赤道的$30\ \mathrm{Tg\,yr^{-1}}$：
$$
\tau = \frac{57}{30} \approx 1.9\ \mathrm{yr}.
$$
这个方法——梯度除以源得交换时间——对任何长寿命示踪物都适用，而$\mathrm{CO_2}$的化石燃料梯度（"化石燃料$\mathrm{CO_2}$"的半球差，排放还在北方的1990年代为几个ppm）同样给出约$1$–$2$年；示踪物之间（SF₆、$^{14}\mathrm{C}$炸弹峰、$^{85}\mathrm{Kr}$）的一致性，才把这个数字从一个估计变成此后每次反演都在用的**输送约束**。
:::
:::

## 空气之河：远程输送

::: definition 羽流、沙尘与拉格朗日视角 {#def-longrange}
因为中纬度西风以$10$–$30\ \mathrm{m\,s^{-1}}$搬运空气，对流层跨洋的**平流**时间尺度是一周——短于许多化学寿命——这就是大气污染地理是大洲级而非本地的原因。经典案例：亚洲沙尘与工业羽流5–10天横渡太平洋，在羽流日把美国西部臭氧抬高几个ppb；非洲沙尘给亚马逊施肥并**削弱大西洋飓风**（撒哈拉的干空气与沙尘——沙尘的辐射冷却稳定了风暴层——一个让萨赫勒降雨成为飓风预报因子的关联）；欧洲和北美的羽流在冬季平流到北极，那里寒冷洁净的极夜让它们的硫酸盐与黑碳添加物显形为**北极霾**——其1970年的发现（苏联飞机和肖的"北极霾"论文）首次把中纬度工业牵进极地变化；以及火灾后、喷发后、爆炸后的事件（2019–20年澳大利亚的烟雾绕地球一周；2022年洪阿汤加的水汽层多年改变着全球平流层化学测量）。工作工具是**拉格朗日模型**——数百万虚拟气块由再分析风平流、带湍流扩散、湿沉降，并在耦合模式下带化学：FLEXPART及其表亲把一张羽流卫星图变成源解析，把受体模型的后向轨迹变成排放估计；而2020年代的一代（GEOS-Chem及$<10\ \mathrm{km}$的兄弟）如今**在线**跑化学，让物种随输送同行，使模型的羽流与卫星的柱成为同一个对象。拉格朗日视角也是概念性的：在一个移动的大气里，正确的问题从来不是"这里的浓度是多少"，而是"**这团空气去过哪里，它带了什么**"。
:::

::: example 跨太平洋 {#ex-pacific}
一团沙尘离开$40\ \mathrm{N}$的戈壁，在$5\ \mathrm{km}$高度被西风以平均$15\ \mathrm{m\,s^{-1}}$平流。估算它抵达冒纳罗亚（$19\ \mathrm{N}$、$155\ \mathrm{W}$——大圆路径约$9000\ \mathrm{km}$）的时间，并解释为什么观测到的羽流抵达比纯平流时间**更宽也更晚**。
::: solution
$9\times10^{6}/15 = 6\times10^{5}\ \mathrm{s} \approx 7$ 天。真实抵达更宽，因为风是一个**谱**（急流摆动，各尺度的涡旋拉伸羽流——泰勒1921年的扩散理论：羽流宽度起初按$\sqrt{t}$增长，进入大涡区后随时间线性增长），因为沙尘在途中从气柱顶部**沉降**出去（粗颗粒早早落下，所以抵达的比源更细也更老），还因为气流不是纬向的：羽流乘着经向摆动，抵达平均风从不及达的纬度。拉格朗日模型在构造上处理全部三者——这就是为什么"模型的羽流晚了两天抵达"被当作风场诊断而非模型失败。
:::
:::

## 平流层管道

::: definition 年龄、入层与空气中的时钟 {#def-age}
平流层空气有一部**年龄谱**：在25 km采到的一个气块离开对流层顶是在一个分布的时间之前，中纬度平均年龄4–6年，向极地升高（古老的下沉空气在此积累）、在热带管道里降低（年轻的空气还在上升）。年龄用地表历史已知的长寿命示踪物测量——**SF₆**（其稳定线性的增长让平流层浓度成为一只直接的时钟：SF₆比今日地表值低$2.5$ ppt的空气，是在地表低$2.5$ ppt时入层的，按当前增长率即五年前）以及**CFC**（其1990年代的峰值给入层早晚的空气一个不含糊的"出生日期"）。年龄要紧，因为平流层的化学是一个**投递问题**：CFC只在抵达之后才光解，所以臭氧层的暴露是地表历史被年龄谱**延迟并抹匀**的版本——这就是臭氧对蒙特利尔议定书的响应滞后十年、南极洞的恢复预估在2060年代（1987年的减排加上5年的管道加上缓慢的化学）的原因，也是短寿命氯替代品（甲基氯、二氯甲烷，其几个月的寿命意味着只有百分之几活过旅途）正成为21世纪晚近平流层中主导性人为氯的原因：**输送过滤器决定臭氧层能看到哪些排放**。同一个过滤器支配着火山冷却（注入对流层顶之上的硫酸盐环流两年，皮纳图博就是这样；只到对流层上层的硫酸盐几周内就下光了——气候效应与没有效应之间的区别是**源的高度**）以及飞机排放的气候影响——后者每吨巨大，恰恰因为尾气被直接送进管道的下游。
:::

::: example SF₆时钟 {#ex-sf6clock}
SF₆在地表以$0.52\ \mathrm{ppt\,yr^{-1}}$增长。德国上空$24\ \mathrm{km}$的一次气球探空测得比同期地表值低$4.7$ ppt。求所采空气的平均年龄，并说明这个数字藏起的关于年龄谱的假设。
::: solution
若地表线性增长，浓度亏空除以增长率就是空气离开地表的时间：$4.7/0.52 = 9$ 年——比4–6年的全球均值更老，因为该高度中纬度的样本空气是**偏向古老下沉空气的混合**。藏起的假设是年龄谱很窄；实际上它又宽又偏，而非线性示踪物（有峰值的CFC）从同一样本读出的"年龄"与线性示踪物（SF₆）不同——这就是平流层动力学论文谈**平均年龄**和**入层廓线**而不谈单一时钟的原因，也是普卢姆和马霍瓦尔德的形式化这套年龄谱文献成为应用数学一部小经典的原因。
:::
:::

::: warning 充分混合的模型不等于充分混合的行星，对流层顶不是墙，而"本底"是一种选择
五个错误。**"全球平均浓度"掩盖了携带信息的梯度**：南北差、边界层对自由对流层的对比、高北半球纬度的季节循环——反演模拟之所以可行**正是因为**空气没有充分混合，而只重现全球均值的模型是用许多参数去拟合一个数字。**"对流层顶阻挡一切"：它是漏的**——通过那些管道——热带上升流、温带入侵（把富臭氧平流层空气注入地表的"对流层顶折叠"，表现为山顶站的臭氧尖峰），以及暖池上深对流把边界层空气直接送进平流层的罕见但真实的事件。**"本底站测量洁净空气"：它们测量的是被过滤过的空气**——冒纳罗亚在对流层一半质量之上、在大陆的上风方，这就是其CO₂是全球均值而其气溶胶不代表人类呼吸的任何东西的原因；把一个数字叫"本底"是关于**采样设计**的陈述，不是关于纯净度的。**再分析风不是风**：建立在再分析之上的拉格朗日输送继承了再分析的对流和边界层偏差，而这个领域诚实的相互比较显示，用同一份数据驱动的各模型之间羽流时机相差数天——输送误差是**系统性的**，不是噪声。**而大气的"容量"不是固定的**：氧化能力、气候变化下的边界层深度、布雷顿-多布森环流的强度（模型里在加速、数据里含混）都在移动把排放变成浓度的输送与清洗速率——每份简单收支背后的稳态假设，正是气候变化第一个拿掉的东西。
:::

::: history
大气输送的定量研究始于**炸弹示踪物时代**——1962–63年华盛顿州克拉克的人工$^{14}\mathrm{CO_2}$释放实验，以及来自再处理和工业的意外示踪物$^{85}\mathrm{Kr}$和$\mathrm{SF_6}$，它们的扩散给出了最初的半球和平流层交换时间——以及**亨利·斯托梅尔**1949年的" spaghetti"轨迹图，让拉格朗日视角登堂入室；**埃里克·丹尼尔森**（1960年代）的凝结尾迹和入侵工作证明了平流层-对流层交换经由漏洞而非墙壁发生。**GAGE**（1977–94）和**AGAGE**（1987–）建成了连续的卤代烃计时器，让平流层年龄成为一种测量，并由**凯瑟琳·普卢姆**和**埃丽卡·马霍瓦尔德**的年龄谱数学加以形式化。北极霾由**布赖恩**在1950年代以及**拜尔斯和布赖恩（1969）**用飞机识别，而其远程的中纬度工业起源与辐射效应，在1970年代由**拉恩和麦卡弗里**的源-受体解析以及**肯德里克·肖**在阿拉斯加大学地球物理研究所的辐射工作确立。亚马逊-撒哈拉磷收支是**洪斌（Hongbin Yu）**及其合作者（2015）的成果；现代综合时代是**GEOS-Chem**、**TM5**、**EMAC**和**LMDz**的化学-输送血统、拉格朗日模型**FLEXPART**（安德烈亚斯·斯托尔及合作者），以及让移动的大气成为可以直接观看之物的输送观测卫星——MOPITT CO（2000）、CALIOP气溶胶层（2006）、TROPOMI CO与NO₂（2017）。
:::

::: summary
- 边界层是化学的反应器体积：它的日循环高度与穿过的风（通风系数）设定城市浓度，并在排放毫无变化时把停滞天气变成污染事件。
- 大气的混合日历：几小时（边界层）、一周（跨洋）、一年（半球之间）、5–6年（穿过平流层管道）。
- 屏障塑造成分：ITCZ的慢门维持半球梯度；深对流是快速电梯；热带对流层顶的冷阱使平流层干燥并过滤哪些氯能到达它。
- 远程输送是拉格朗日式的：羽流乘西风和砧状云外流；沙尘给亚马逊施肥、给大西洋风暴降温、给北极蒙霾。
- 平流层年龄（SF₆、CFC时钟）把排放变成延迟而抹匀的暴露——臭氧恢复缓慢、并将到2060年代才恢复的原因。
- "本底""充分混合"和稳态是采样与模拟的选择；梯度、输送误差和环流的漂移才携带信息与不确定度。
:::

## 练习

::: exercise 城市换血时间 {level=1 check="3.5"}
求$50$ km宽城市在$4\ \mathrm{m\,s^{-1}}$风下的空气替换时间（小时，一位小数）。（填数字。）
::: solution
$5\times10^{4}/(4\times3600) = 3.5\ \mathrm{h}$。这个数字就是巨型城市的空气为什么一个下午就对天气起反应——也是为什么一次风向转变、而不是排放政策，常常是单日暴露的最大单一控制因子。
:::
:::

::: exercise 跨太平洋 {level=1 check="7"}
求羽流以$15\ \mathrm{m\,s^{-1}}$平流$9000\ \mathrm{km}$的天数（取整）。（填数字。）
::: solution
$9\times10^{6}/15 = 6\times10^{5}\ \mathrm{s} = 7$ 天——短于臭氧前体夏季的光化学寿命，这就是北美西部背景臭氧里包含亚洲工业的原因，也是为什么"跨界污染"是一周龄的辩论、不是本地的。
:::
:::

::: exercise 沙尘份额 {level=1 check="15.4"}
撒哈拉向大西洋对岸输出$180\ \mathrm{Tg\,yr^{-1}}$沙尘，其中$27.7\ \mathrm{Tg\,yr^{-1}}$沉入亚马逊盆地。求横渡大西洋的沙尘中抵达亚马逊的百分数（一位小数）。（填数字。）
::: solution
$27.7/180 = 15.4\%$。其余沉入大西洋（点亮海洋颜色、喂养深海沉积记录，并经由沙尘的铁进入碳循环）；亚马逊的份额虽是分数中的分数，却载着抵上雨林淋洗之需的磷——让沙漠-森林耦合成为一条定量生物地球化学循环的发现。
:::
:::

::: exercise SF₆时钟 {level=2 check="9"}
SF₆地表增长$0.52\ \mathrm{ppt\,yr^{-1}}$；$24\ \mathrm{km}$的样本比地表低$4.7$ ppt。求平均年龄（年，取整）。
::: solution
$4.7/0.52 = 9$ 年。时钟一行的算术藏起了年龄谱的精微（偏斜的谱让"年龄"依赖示踪物），但数字本身——一架喷气机高度上的空气在听者上学之前离开了地表——是平流层最有用的事实：它是一座**慢反应器**，注入其中的一切都以年为单位给药。
:::
:::

::: exercise 冷阱脱水 {level=2 check="99.5"}
从热带进入平流层的空气在冷阱高度携带$1000\ \mathrm{ppmv}$水汽、离开时剩$5\ \mathrm{ppmv}$。求被移除的水的百分数（一位小数）。
::: solution
$(1000-5)/1000 = 99.5\%$。平流层近乎完全的干燥——其臭氧化学是气相的、其云是稀薄的夜光夜光云（夏季中间层顶的稀奇物而非日常天气）的原因——就是这次冻结，而它对热带对流层顶温度的敏感度（增暖一度意味着输送更多或更少的水，一个关于平流层臭氧和地表气候的反馈）让一个$-80\ ^\circ\mathrm{C}$的数字成为气候变量。
:::
:::

::: exercise 通风系数 {level=2 check="12"}
求$4\ \mathrm{m\,s^{-1}}$的风穿过$300\ \mathrm{m}$的通风系数（风速×混合高度），以$10^{2}\ \mathrm{m^{2}\,s^{-1}}$为单位。（填数字。）
::: solution
$4\times300 = 1200 = 12\times10^{2}\ \mathrm{m^{2}\,s^{-1}}$。冬季污染事件的值——$1\ \mathrm{m\,s^{-1}}$的风、$150\ \mathrm{m}$的稳定层、$1.5\times10^{2}$——低八倍，而每份冬季空气质量预报都是排放清单与这一个乘积之间的比赛。
:::
:::

::: exercise 半球间交换 {level=3 check="1.9"}
某气体南北差$40\ \mathrm{ppb}$；每半球ppb到吨的因子为$1.4\ \mathrm{Tg\,ppb^{-1}}$；北方源超出$30\ \mathrm{Tg\,yr^{-1}}$。求交换时间（年，一位小数）。
::: solution
差$= 40\times1.4 = 56\ \mathrm{Tg}$；$\tau = 56/30 = 1.9$ 年。梯度即流量计的方法可推广到任何长寿命示踪物，而甲烷、SF₆、$^{85}\mathrm{Kr}$和炸弹峰之间的一致性，是每场全球反演脚下的观测地基：先输送，后源。
:::
:::

::: exercise 平流层过滤器 {level=3 check="5"}
二氯甲烷（寿命$5$个月）和CFC-11（寿命$45$年）在地表等量排放。设从热带对流层顶起有$5$年的平流层输送时间……用存活因子$e^{-t/\tau}$计$1$年的对流层上升加平流层暴露，抵达平流层并在其中光解的CFC-11与二氯甲烷分子之比大约是多少？（填$10$的幂，取整。）
::: solution
抵达并穿过平流层的存活率：CFC-11为$e^{-6/540} \approx 0.99$；二氯甲烷为$e^{-6/0.42} \approx e^{-14} \approx 10^{-6}$——之比约为$10^{6}$倍，所以即便等量排放，送到臭氧层的CFC-11氯也**多一百万倍**。输送过滤器是蒙特利尔议定书针对长寿命卤代烃、而原则上对短寿命者无能为力的全部原因——后者的平流层投递本已接近零，而其幸存的微小份额如今矛盾地正在成为恢复了臭氧层里主导的人为氯。
:::
