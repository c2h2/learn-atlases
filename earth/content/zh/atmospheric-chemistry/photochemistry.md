1943年夏天，洛杉矶的工厂工人开始带着刺痛的眼睛和流血的肺回家，军方工业界把烟雾怪到杜邦的丁二烯工厂头上——直到工厂疏散了、烟雾却留下了。世界花了一个十年、一位名叫**阿里·豪根-斯米特**的化学家（他1950年认定臭氧是元凶，随后又找到制造它的活性碳氢化合物），以及洛杉矶盆地奇特的几何——阳光、逆温、以及没有任何控制的1950年代车流——才学会光化学烟雾的这一课：阳光是一种**试剂**，相当干净的空气也会出事（臭氧不是排放的，是制造的），而一种致命污染物的两大来源是太阳和汽车。豪根-斯米特发现的化学如今是这门科学里定量最好的反应网络——数百个反应、几个百分点内的速率常数、以毫秒计的量子产率——它是"化学机制"一词的工作模型：万亿分之几浓度的少数自由基，被光子驱动，决定其他一切东西的命运。

## 作为试剂的阳光

::: proposition 光解与光稳态 {#prop-photostationary}
吸收了一个合适波长光子的分子可能断裂，而**光解频率**$J$（$\mathrm{s^{-1}}$）——吸收截面、量子产率与 光化通量的卷积，对对流层里发生光解的一百来个物种都能算到几十个百分点内——是太阳对该物种的翻转率。城市化学的奠基反应是二氧化氮的：
$$
\mathrm{NO_2} + h\nu \rightarrow \mathrm{NO} + \mathrm{O}(^3\mathrm{P}) \quad (J \approx 10^{-2}\ \mathrm{s^{-1}}\ \text{at noon}), \qquad \mathrm{O} + \mathrm{O_2} \rightarrow \mathrm{O_3},
$$
随后是臭氧被NO销毁，$\mathrm{NO} + \mathrm{O_3} \rightarrow \mathrm{NO_2} + \mathrm{O_2}$（$k = 1.8\times10^{-14}\ \mathrm{cm^{3}\,s^{-1}}$）。这一对带着一点浪费循环——每一圈把一个光子变成一个臭氧分子——而在纯空气中达到**莱顿光稳态**，
$$
[\mathrm{O_3}] = \frac{J\,[\mathrm{NO_2}]}{k\,[\mathrm{NO}]},
$$
其中臭氧仅由$\mathrm{NO_2}/\mathrm{NO}$比设定，响应时间为**分钟**。真实的烟雾制造出**多于**光稳态所允许的臭氧，因为来自挥发性有机物的过氧自由基（$\mathrm{HO_2}$、RO₂）**不消耗臭氧地**氧化NO——这个漏洞把零循环变成泵，也是臭氧空气质量既是氮氧化物故事也是碳氢化合物故事的原因。
:::

::: example 光稳态的预言 {#ex-leighton}
某交通站点，正午$J(\mathrm{NO_2}) = 9\times10^{-3}\ \mathrm{s^{-1}}$，$[\mathrm{NO_2}]/[\mathrm{NO}] = 8$，$k = 1.8\times10^{-14}\ \mathrm{cm^{3}\,s^{-1}}$。在$2.4\times10^{19}\ \mathrm{molecules\,cm^{-3}}$下求光稳态臭氧（ppb），并解释为什么实测臭氧通常是此值的1.5–2倍。
::: solution
$$
[\mathrm{O_3}] = \frac{9\times10^{-3}\times8}{1.8\times10^{-14}} = 4\times10^{12}\ \mathrm{cm^{-3}} = 167\ \mathrm{ppb}.
$$
超出预言的部分就是过氧通量：路侧树木的异戊二烯、交通的CO和芳烃，各自经由HO₂/RO₂**免费**把NO转化为NO₂，所以真实的$\mathrm{NO_2}$源超过光稳态，臭氧一路上升，直到它自己的化学（以及活到夜间的NO）追上来。预言与测量之间的落差——"过冲"——本身就是对**自由基生成的一次测量**，是本领域漂亮的反转之一：臭氧作为自由基剂量计。
:::
:::

## 自由基引擎

::: definition OH与HOx家族 {#def-oh}
羟基自由基——一个氧、一个氢、一个未配对电子，浓度约每立方厘米$10^{6}$个分子，空气的**万亿分之一**——是大气的洗涤剂，而它的源是平流层伸进对流层的手：臭氧在320 nm以上光解为激发原子$\mathrm{O}(^1\mathrm{D})$（量子产率0.6），后者抓住水：$\mathrm{O}(^1\mathrm{D}) + \mathrm{H_2O} \rightarrow 2\,\mathrm{OH}$。从这股细流流出的是几乎全部对流层化学的氧化：甲烷的九年刑期、一氧化碳的几周、VOC的几小时、二氧化硫和DMS的几天——而自由基自身的寿命是**一秒**，其稳态丰度由源（臭氧-水路径，加上清晨的HONO光解，加上NO的再循环）与汇（它与CO、VOC和甲烷自身的反应，全球以CO为首）的平衡设定。HOx家族（OH、HO₂）及其有机亲戚（RO₂）构成一条**催化链**：OH制造HO₂，HO₂通过与NO反应再生OH，链的每一圈氧化另一个分子——所以一个只活一秒的自由基每几天就处理掉相当于自身重量的一氧化碳。引擎的油门是NOx：在清洁空气中自由基安静地终结（$\mathrm{HO_2} + \mathrm{HO_2}$、臭氧-OH），在污染空气中NO路径占主导，氧化能力**随污染上升**——"氧化能力反馈"让未来的甲烷取决于未来的NOx，其机制即在于此，周末效应（下文）的机制也在于此。
:::

::: example 自由基的受害者 {#ex-ohlifetime}
$\mathrm{OH} + \mathrm{CH_4}$的速率常数为$6.3\times10^{-15}\ \mathrm{cm^{3}\,s^{-1}}$，全球平均$[\mathrm{OH}] = 1.0\times10^{6}\ \mathrm{cm^{-3}}$。求甲烷仅对OH的寿命，并与公认的9年大气寿命相调和。
::: solution
$$
\tau = \frac{1}{k\,[\mathrm{OH}]} = \frac{1}{6.3\times10^{-15}\times10^{6}} = 1.6\times10^{8}\ \mathrm{s} \approx 5\ \mathrm{years}.
$$
剩余的清除来自平流层（与O(¹D)和OH反应，约每年4%）、土壤吸收和海洋氯原子——它们一起把5年拉长到9年。这道题是本图集核心换算的缩影：**寿命 = 1/(k × 氧化剂)**，及其对政策的推论：因为甲烷的寿命由全球氧化剂场设定，甲烷-甲烷竞争是真实的（排放更多甲烷会延长平均分子的寿命），而**增加**汇的希望同样是真实的——靠提高NOx来提高OH，是大气开出、臭氧层拒绝的一笔交易。
:::
:::

## 制造臭氧，储存自由基

::: definition VOC–NOx化学与储库 {#def-voc-nox}
净臭氧生成循环需要一条碳骨架：VOC（甲烷、CO、来自森林$10^{15}\ \mathrm{g\,yr^{-1}}$的异戊二烯、来自燃料的芳烃）被OH氧化为过氧自由基，后者在不花费臭氧的情况下把NO转化为NO₂，而每一次这样的转化留下一个臭氧分子——**每氧化一个NO一个臭氧，每个NOx分子在被储存或淋洗之前催化数百个臭氧分子**。随后大气把自身的氧化剂封存进**储库物种**：PAN（过氧乙酰硝酸酯）及其有机硝酸酯表亲，它们在地表温度下活几分钟到几天，但在对流层上层$-30\ \mathrm{^\circ C}$处近乎永久，使PAN成为**运载卡车**，把NOx在高空携带数千公里直到热分解释放——偏远的臭氧生成因此是一个硝酸盐储存的物流问题。夜间切换体制：OH消失，硝酸根自由基NO₃（来自NO₂ + O₃）成为傍晚的氧化剂，制造有机硝酸酯，以及在森林上空的萜烯二次有机气溶胶——俄勒冈蓝雾的气味是蒎烯与NO₃的反应——而清晨的HONO光解（来自同一硝酸盐储库，在表面光化再生）比臭氧-水路径早一小时点燃OH，自1990年代以来的每场外场试验都一再强调这一点。定量的政策层是**反应性**：每吨VOC生成的臭氧（其最大增量反应性）在VOC之间横跨五个数量级——甲烷在底部，活性芳烃和溶剂时代的残余在顶部——这就是为什么燃料和溶剂化学一变，臭氧"未达标"地图就改变形状，也是为什么异戊二烯丰富的美国东南部在**它不污染的热天**里仍然不达标。
:::

::: example PAN温度计 {#ex-pan}
PAN的热分解活化能约$120\ \mathrm{kJ\,mol^{-1}}$。求其寿命从$25\ ^\circ\mathrm{C}$的地表到$-40\ ^\circ\mathrm{C}$的对流层上层延长的倍数，并解释这对世界臭氧在何处制造意味着什么。
::: solution
Arrhenius比值为
$$
\exp\!\left[\frac{E_a}{R}\left(\frac{1}{233}-\frac{1}{298}\right)\right] = \exp\!\left[14{,}400\times9.36\times10^{-4}\right] = e^{13.5} \approx 7.4\times10^{5}.
$$
一个在地面只活几分钟的PAN分子在高空中活**几个月**——足够全球环流把它从污染流出带到偏远受体，那里更慢的下沉气流和更暖的温度重新释放它的NOx。后果是这个事实：对流层上层臭氧——辐射强迫意义上的臭氧、每分子辐射上最贵的那种——大多**由运来的NOx**制造，在海洋和森林上空；这也是为什么卫星NO₂图上的电厂对北海道的农民重要：臭氧问题不再局部，而PAN是它的信使。
:::
:::

## 从机制到空气质量

::: definition 周末效应与政策面 {#def-policy-surface}
因为光化学系统对NOx是非线性的，削减排放并不会单调地削减臭氧。在高NOx的城市核心，新鲜的NO**滴定**臭氧（$\mathrm{NO} + \mathrm{O_3}$）而NO₂吸收光解光子；在那里削减NOx，两重抑制都松动——**臭氧上升**。在低NOx的郊区和下风向农村，臭氧生成是NOx限制的、随削减而下降。标志性实验是**周末效应**：在许多（并非所有）北美和欧洲城市，交通减少带来的工作日NOx下降使核心的周末臭氧**更高**、下风向更低——这个结果曾经让环保局的模型难堪，如今在标定它们。机制还教出政策面的三个褶皱。**气溶胶竞争自由基**：高PM₂.₅清除HO₂/RO₂、抑制臭氧生成，所以东亚和南亚的清洁空气转型悖论性地**增加了**地面臭氧——气溶胶刹车松了——尽管NOx在削减，这是中国夏季臭氧上升的一个有记载的驱动因子。**甲烷是背景**：随着国际航空、航运和半球输送用甲烷和平流层输入筑起40 ppb的全球臭氧地板，许多下风向地区如今**仅凭背景**就达不到21世纪标准，使甲烷成为低调的城市臭氧政策。**而化学是懂气候的**：异戊二烯排放随温度（和CO₂）上升，水汽提高OH的前体输送，停滞频率随急流摆动上升——空气质量的"气候代价"，估计为大陆上每增温一度夏季臭氧几个ppb——这就是1980–2020年清洁空气收益在一个变暖世界里开始放缓的原因。
:::

::: example 一座城市的两个体制 {#ex-regimes}
某市中心$[\mathrm{NO}] = 20\ \mathrm{ppb}$、$[\mathrm{NO_2}] = 40\ \mathrm{ppb}$；其下风向郊区$[\mathrm{NO}] = 1\ \mathrm{ppb}$、$[\mathrm{NO_2}] = 4\ \mathrm{ppb}$。计算两处光稳态臭氧（正午$J = 10^{-2}\ \mathrm{s^{-1}}$，空气密度$2.5\times10^{19}$），并解释为什么全区削减30%的NOx会使核心臭氧上升、郊区臭氧下降。
::: solution
核心：光稳态公式给出$10^{-2}\times(40/1)/(1.8\times10^{-14}) = 2.2\times10^{13}\ \mathrm{cm^{-3}} = 890\ \mathrm{ppb}$——高得荒谬，而荒谬就是要点：新鲜的NO滴定臭氧快过光稳态化学制造它的速度，公式的假设崩塌，真实的核心坐在几十ppb附近，NOx饱和而**被压制**。郊区：$10^{-2}\times(4/1)/(1.8\times10^{-14}) = 2.2\times10^{12}\ \mathrm{cm^{-3}} = 90\ \mathrm{ppb}$，接近生成受NOx限制的体制。因此削减30%的NOx会松开核心的滴定刹车（臭氧升）并饿死郊区的生成（臭氧降）——周末效应与"削20%就少20%臭氧"的失灵是同一条曲率，而每份达标计划如今都跑化学模型来确定某条街坐在脊线的哪一侧。
:::
:::

::: warning 阳光制造臭氧但不解释一切，OH不是无限的，而"光化学烟雾"不是一样东西
五个错误。**"臭氧警报意味着阳光强"**：事件臭氧用数天制造并被平流输送；最强的地面臭氧常先于热峰，而平流层入侵——表现为干燥、富臭氧、无颗粒的空气下冲至山顶——能在毫无本地污染的情况下触发警报。**"OH容量无限"**：氧化剂场响应它的负载——CO和甲烷竞争OH，而工业示踪物寿命的观测延长（甲基氯仿时钟）在1990–2000年代证明了OH增长已**停滞**，很可能是因为NOx下降而CO上升；一个排放更多、NOx更少的未来是一个洗涤剂更弱、甲烷更长寿的未来。**"PAN只是又一种污染物"**：PAN是一个储库，其价值全在其**分解的地理**——同一个分子在路缘是扰民者、在12 km是气候强迫因子，而在烟囱处清点排放的政策错过了转化。**"VOC限值与NOx限值同样好"**：哪种控制见效取决于本地NOx-VOC体制，而体制**随季节和背景甲烷翻转**——同一对控制在七月互补、在八月竞争，这就是为什么一座城市的"光化学烟雾"不是另一座城市的化学对象。**而周末效应不是模型伪影**：它是真实的、区域性的，而某些城市的缺席（风或生物源VOC化学占主导之处）是诊断不是反证——大气每周都在重跑同一个实验，而没通过考试的城市在告诉我们一些事情。
:::

::: history
**阿里·豪根-斯米特**认定臭氧和活性碳氢化合物是烟雾元凶（1950–52）——证明来自其课题组的熏蒸舱，其中一棵白柏在阳光、尾气和洛杉矶空气的混合物中黄化——而**保罗·莱顿**1961年的专著《空气污染光化学》确立了仍在组织本领域的光稳态框架。自由基引擎由**杰克·莱维**（1971）认出，他算出微量OH必然控制对流层氧化，以及**保罗·克鲁岑**（1971–73），其HOx–NOx循环形式化了臭氧的光化学生成；速率常数在**JPL评估系列**（1973–）中被典律化，是本领域安静的标准模型。**马里奥·莫利纳和谢伍德·罗兰**的CFC-臭氧论文（1974）从同一光化学逻辑中生长出来，**沃尔特·查梅兹**的异戊二烯-NOx分析（1988）解释了美国乡村东南部，而卫星时代——GOME和OMI的NO₂柱（2004–）、TROPOMI（2017）——把周末效应、电厂羽流和反应性排名变成了课堂图像。
:::

::: summary
- 光解频率J是太阳的翻转率；NO₂光解（J ~ 10⁻² s⁻¹）加NO + O₃设定莱顿光稳态——臭氧由NO₂/NO比决定，以分钟计。
- 真实烟雾过冲光稳态，因为来自碳氧化的过氧自由基不花费臭氧地把NO转化为NO₂：每氧化一个NO一个臭氧，每个NOx分子数百个。
- 空气万亿分之一的OH由O₃ + hν + H₂O制造，是洗涤剂；它的寿命是一秒，其丰度是全球收支，其容量并非无限（2000年代停滞的OH增长）。
- 储库（PAN、夜间的NO₃、清晨的HONO）在时空上搬运氧化剂：PAN在对流层上层数月的寿命使偏远和高空臭氧成为一件运来的商品。
- 系统对NOx非线性：滴定、周末效应、气溶胶刹车和甲烷背景使臭氧政策是体制问题，不是比例问题。
- 气候经由异戊二烯、水汽和停滞反噬——已开始侵蚀四十年清洁空气收益的气候代价。
:::

设$J = 9\times10^{-3}\ \mathrm{s^{-1}}$、$[\mathrm{NO_2}]/[\mathrm{NO}] = 8$、$k = 1.8\times10^{-14}$，求光稳态臭氧（ppb，空气$2.4\times10^{19}\ \mathrm{cm^{-3}}$，取整）。（填数字。）
::: solution
$[\mathrm{O_3}] = 9\times10^{-3}\times8/1.8\times10^{-14} = 4\times10^{12}\ \mathrm{cm^{-3}} = 167\ \mathrm{ppb}$。真实测量坐在此值之上（过氧过冲）；**低于**光稳态的测量意味着NO滴定或缺失的NO₂源——这个比值是每场外场数据集上的工作诊断。
:::

::: exercise 甲烷的OH寿命 {level=1 check="5"}
$k(\mathrm{OH} + \mathrm{CH_4}) = 6.3\times10^{-15}\ \mathrm{cm^{3}\,s^{-1}}$，全球平均$[\mathrm{OH}] = 1.0\times10^{6}\ \mathrm{cm^{-3}}$。求寿命（年，取整）。
::: solution
$\tau = 1/(k[\mathrm{OH}]) = 1.6\times10^{8}\ \mathrm{s} \approx 5$ 年；公认的9年总数加上平流层、土壤和海洋氯。两个数字之间的差距是关于不要把寿命归给单一氧化剂的教训——而5年的OH项正是随NOx、CO和水汽、从而随其他一切变化的那一项。
:::

::: exercise 自由基柱 {level=2 check="1"}
全球OH源为$9\times10^{25}\ \mathrm{molecules\,cm^{-2}\,s^{-1}}$，全球平均OH寿命约$1\ \mathrm{s}$。若与这些源相平衡的CO、CH₄和VOC总氧化通量为$10^{26}\ \mathrm{molecules\,cm^{-2}\,s^{-1}}$，稳态**柱**OH是多少？以$10^{26}$ molecules $\mathrm{cm^{-2}}$为单位填答案。
::: solution
稳态：生成=损耗，所以柱等于源通量乘寿命。氧化（损耗）通量为$10^{26}\ \mathrm{molecules\,cm^{-2}\,s^{-1}}$、$\tau = 1\ \mathrm{s}$时，柱$= 10^{26} \times 1 = 10^{26}$ molecules $\mathrm{cm^{-2}}$——以$10^{26}\ \mathrm{cm^{-2}}$为单位即**1**。（本题为展示稳态关系 柱=源×寿命 而设；代入外场数字，空气万亿分之一的丰度自然掉出。）
:::

::: exercise 周末滴定 {level=2 check="36"}
某市中心正午$J = 10^{-2}\ \mathrm{s^{-1}}$、$[\mathrm{NO_2}]/[\mathrm{NO}] = 0.16$（新鲜NO占主导）。求光稳态臭氧（ppb，空气$2.5\times10^{19}\ \mathrm{cm^{-3}}$，取整）。（填数字。）
::: solution
$[\mathrm{O_3}] = 10^{-2}\times0.16/1.8\times10^{-14} = 8.9\times10^{11}\ \mathrm{cm^{-3}} = 36\ \mathrm{ppb}$。新鲜NO的空气容不下光稳态臭氧——低比值**就是**滴定签名，这就是为什么市中心臭氧低、为什么在那里削减NOx会抬高它、为什么周末效应是一副政策面孔的光稳态现象。

::: exercise 莱顿订正 {level=3 check="200"}
真实空气中过氧自由基以速率$P$转化NO，光稳态变为$[\mathrm{O_3}] = (J[\mathrm{NO_2}] + P)/k[\mathrm{NO}]$。设光稳态项$J[\mathrm{NO_2}]/k[\mathrm{NO}] = 100\ \mathrm{ppb}$、$P = 5\times10^{8}\ \mathrm{cm^{-3}\,s^{-1}}$、$k[\mathrm{NO}] = 2\times10^{-4}\ \mathrm{s^{-1}}$，求总臭氧（ppb，每ppb对应$2.5\times10^{10}\ \mathrm{cm^{-3}}$）。（填数字。）
::: solution
自由基项添加$P/k[\mathrm{NO}] = 5\times10^{8}/2\times10^{-4} = 2.5\times10^{12}\ \mathrm{cm^{-3}} = 100\ \mathrm{ppb}$，使光稳态值翻倍到$200\ \mathrm{ppb}$。在低NO时过氧项**就是**臭氧——NOx限制体制的代数：光稳态公式在构造上低估，而每个乡村臭氧模型都因对$P$的表征而生或死。
:::

::: exercise 气候代价 {level=3 check="0.6"}
停滞日占夏季的20%，携带104 ppb的臭氧，其余各日为74 ppb（季均80 ppb）。若变暖使停滞份额上升10%（到22%），求季均臭氧的上升（ppb，一位小数）。（填数字。）
::: solution
新均值$= 0.22\times104 + 0.78\times74 = 22.9 + 57.7 = 80.6\ \mathrm{ppb}$——停滞每上一档升$0.6\ \mathrm{ppb}$。文献里的"每度几个ppb"还在其上加上生物源项：异戊二烯排放约每$10\ ^\circ\mathrm{C}$翻倍，水汽和光解的变化提高氧化剂输送——停滞项是三个气候代价分量中最小的，而1980–2020的清洁空气收益如今要对着全部三项来衡量。
