大气在自我清洁，而洗涤剂是一种在万亿分之一的浓度下只能存活一秒的自由基——羟基，OH，其全球丰度按日照对流层平均为每立方厘米$10^{6}$个分子，少得能装进一只顶针，却又多得能决定甲烷、一氧化碳、溶剂蒸气和工业卤代烃在空气中停留多久。1971年之前，对流层的氧化能力被假定为它的稀释；随后**杰克·莱维**算出，在臭氧遭遇水汽和阳光之处生成的微量OH，一定在运转整个低层大气的化学，而该领域花了五十年去确认、校准——以及最近——为他担心。确认：激光诱导荧光如今直接数OH的光子，而AGAGE网络运行了四十年的甲基氯仿时钟，以没有任何模型预料到的精度称出了全球氧化剂场。担心：时钟显示洗涤剂的增长在2000年代停滞，其1990年代的增长由污染本身驱动，而大气的自净能力——它为地球上每份排放清单提供的服务——如今被理解为气候系统的一个变量，不是自然常数。

## 引擎的收支

::: definition OH的源与汇 {#def-oh-budget}
对流层OH以三种方式生成、一种方式销毁。主导的源（约三分之二）是臭氧-水路径：$\mathrm{O_3} + h\nu (\lambda < 320\ \mathrm{nm}) \rightarrow \mathrm{O}(^1\mathrm{D})$（量子产率0.6），$\mathrm{O}(^1\mathrm{D}) + \mathrm{H_2O} \rightarrow 2\,\mathrm{OH}$——这就是为什么OH在湿热高紫外的低纬度热带、以及在臭氧充沛的污染空气上空达峰（全球氧化剂极大值坐在南亚和东亚上空——污染供给臭氧、季风供给水汽——这个悖论）。清晨的源是**HONO光解**（$\mathrm{HONO} + h\nu \rightarrow \mathrm{OH}$，$J \sim 10^{-3}\ \mathrm{s^{-1}}$），它比臭氧路径能开工之前一小时就点燃OH，而其强度——每场城市战役的"缺失HONO"问题——设定了一天光化学的计时。夜间的源是烯烃的臭氧分解，它在无阳光下制造$\mathrm{O}(^1\mathrm{D})$，日落后在森林上空保着一烛OH不灭。汇很简单：OH与空气里的东西反应，而全球范围**一氧化碳取走约60%，甲烷35%，其余由VOC、氢和卤代烃分摊**——所以引擎的燃料也是它的刹车：更多的CO或甲烷意味着更少的OH、更长的寿命、以及一切东西的更多。稳态丰度$[\mathrm{OH}] = P/L$因此由它自己清除的那些污染物设定——对流层化学的定义性非线性。
:::

::: example 引擎的通量 {#ex-throughput}
全球平均$[\mathrm{OH}] = 10^{6}\ \mathrm{cm^{-3}}$，空气$2.5\times10^{19}\ \mathrm{cm^{-3}}$，对流层柱$2.1\times10^{25}\ \mathrm{air\,cm^{-2}}$。求OH柱和CO的全球氧化通量（$k = 1.5\times10^{-13}\ \mathrm{cm^{3}\,s^{-1}}$，CO为100 ppb），并与地表CO源（$900\ \mathrm{Tg\,yr^{-1}}$）比较。
::: solution
OH柱是平均混合比乘空气柱：$100\times10^{-12}\times2.1\times10^{25} = 2.1\times10^{15}\ \mathrm{cm^{-2}}$。CO的损耗频率是$k[\mathrm{OH}] = 1.5\times10^{-13}\times10^{6} = 1.5\times10^{-7}\ \mathrm{s^{-1}}$，寿命$6.7\times10^{6}\ \mathrm{s} = 2.1$ 个月。全球CO负荷为$100\times10^{-9}\times(2.1\times10^{25}\times5.1\times10^{18})\times28\times1.66\times10^{-24} = 500\ \mathrm{Tg}$，所以OH汇为$500/0.175 \approx 2900\ \mathrm{Tg\,yr^{-1}}$……这个比较表明**总**CO源（化石、生物质、海洋，加上高空由甲烷和VOC氧化生成的大量二次源）在两份清单各自的二倍误差内与OH汇相抵——关于OH不是自由参数的经典演示：弄错30%，CO收支就明显崩溃，这就是为什么CO与甲基氯仿并列为对氧化剂场的常设约束。
:::
:::

## 测量不可见者

::: definition 甲基氯仿时钟 {#def-mcf}
在莱维预言之后的二十年里，羟基活泼得无法直接称量，于是该领域用化学造了一座时钟：**甲基氯仿**（1,1,1-三氯乙烷，MCF），一种工业溶剂，没有自然源、没有值得一提的海洋汇、几乎完全由OH销毁。它的大气下降因此是**全球OH的直接读数**：$1/\tau_{\mathrm{obs}} = 1/\tau_{\mathrm{OH}} + 1/\tau_{\mathrm{strat}} + 1/\tau_{\mathrm{soil}}$，平流层项由环流模型约束、土壤项界定为小，所以观测到的对OH寿命——约5.6年——在输送模型精度内就是平均$[\mathrm{OH}]$的倒数。**罗纳德·普林**领导下自1987年运行的AGAGE烧瓶网络已读了这座时钟四十年，它的判词定义了本领域：OH在**1990年代以每年约1%增长**（由亚洲工业化的CO和NOx驱动——污染制造了毁灭污染的洗涤剂），在2000年代**停滞**，因为气溶胶散射了光解光子、NOx化学发生转变；而时钟本身带着一个系统误差，因为MCF的氧化产物会反馈到OH，所以原始时钟把真实氧化剂场**低估**10–20%——如今每篇趋势论文都携带这个订正。直接测量随**激光诱导荧光**（LIF）到来：飞机和气球上的激光共振激发OH并数其荧光，由**J·G·安德森**的早期系统、以及对流层方面**保罗·温伯格**的校准计划带到定量严格，其 相互比对至今定义着测量标准。而前沿方法是**总OH反应性**——把已知OH扫干净、看空气毁掉什么——其在森林和城市上空持续存在的10–30%"缺失反应性"说明大气仍在制造消耗氧化剂而我们尚未命名的化学品。
:::

::: example 读时钟 {#ex-mcfclock}
MCF观测到的总损耗频率为$0.20\ \mathrm{yr^{-1}}$；平流层汇贡献$0.05\ \mathrm{yr^{-1}}$、土壤$0.03\ \mathrm{yr^{-1}}$。求对OH的寿命；若时钟的产物反馈意味着真实OH损耗频率高15%，求订正后的寿命。
::: solution
$1/\tau_{\mathrm{OH}} = 0.20 - 0.05 - 0.03 = 0.12\ \mathrm{yr^{-1}}$，原始时钟读$\tau_{\mathrm{OH}} = 8.3\ \mathrm{yr}$……订正后为$0.138\ \mathrm{yr^{-1}}$、$7.2$ 年——比原始时钟读数**高15%**的[OH]。这道题用两个减法写出了整个方法：一种为去油污而发明的溶剂、被蒙特利尔议定书禁用，却成了有史以来最精密的全球化学仪器，而它的读数仍以每年十分之几个百分点移动——大气自净能力变化的速率。
:::
:::

## 氧化能力及其趋势

::: definition 氧化剂家族及其容量 {#def-oxidising-power}
OH约占对流层氧化容量的90%，但**氧化能力**是一个家族：臭氧（其余的大部分，也是黑暗时段唯一的氧化剂）、硝酸根自由基NO₃（NOx富集空气中夜间的劳模，制造有机硝酸酯和夜间气溶胶）、卤素原子（Cl原子对烷烃比OH活泼一百倍，如今被承认是海盐气溶胶与溴化学火热之处的海洋边界层甲烷、DMS乃至臭氧本身的重要氧化剂），以及给清洁空气记录打点的平流层臭氧入侵。这个家族的容量**并不固定**：1990–2000年代的历史（OH随亚洲的CO和NOx上升，然后趋平）表明氧化剂场以一种增益追随人类排放，而模型只有把气溶胶光学深度和异戊二烯弄对了才能重现这个增益。**未来**是争论栖身之地：多数化学-气候模型预估2100年前OH上升5–15%（发展路径中更多的NOx和CO、各处更多的水汽），这会缩短甲烷寿命并**阻尼**碳-气候反馈——一个有政策意义的负反馈——而同一批模型让OH对2020年代那场伟大的失控实验敏感：**中国的清洁空气**，其SO₂削减（2013年以来降60%）抬高了光解速率、随之抬高了华东的OH——一个 意外后果，正被蒙特利尔议定书建立的观测网此刻读取。
:::

::: example 甲烷-OH握手 {#ex-handshake}
若甲烷排放翻倍，而多出的甲烷消耗了足够的OH使全球[OH]下降5%，新的平衡负荷比线性预期高出百分之几？
::: solution
寿命与[OH]成反比，所以OH减少5%使其延长$1/0.95 = 5.3\%$，稳态负荷同样上升：这个反馈在翻倍之上**再加5%**，一个对甲烷本身微小但严格为正的反馈。同样的算术在未来反向运行：预估的OH上升10%将在排放不变时抹去甲烷负荷的十分之一——意味着甲烷强迫的十分之一可以单靠化学来抵消，也意味着**甲烷的寿命不是自然常数，而是排放世界所建氧化剂场的函数**。
:::
:::

## 竞争、氯与前沿

::: definition 还有谁在清洁，什么被漏掉 {#def-competition}
因为OH是共享的，每次氧化都是一场**竞争**：CO是OH的全球恒温器（60%的份额意味着火灾与化石的CO记录是一份OH记录），氢排第二竞争，而VOC们靠反应性——不是质量——决定谁先燃烧，这就是为什么甲烷——大气中最丰富的活性碳——被不情不愿地氧化（它的C–H键是同行里最强的）活了九年，而异戊二烯只活一小时。**氯原子**是竞争的百搭牌：由海岸和海洋边界层的海盐与溴化学生成，对烷烃和DMS比OH活泼10–100倍，它被承认为全球甲烷汇（百分之几，但随海盐排放增长）是2010年代安静的范式转换之一——其推论同样如此：**短寿命氯和溴物种**因为到不了平流层而不被蒙特利尔议定书计数，却是重要的边界层氧化剂，其排放（溶剂、阻燃剂、"未受管制物质"）如今已列入评估议程。前沿是**缺失反应性**：在森林站点和城市，总OH反应性测量发现有10–30%的OH销毁无法由已测物种解释——其中以未测的异戊二烯二代三代产物为首——意味着制造二次有机气溶胶和臭氧的氧化链仍有一部分没有写出，而大气的洗涤剂不断找到我们还叫不出名字的工作。
:::

::: example 缺失反应性 {#ex-missingreact}
某森林站点测得总OH反应性为$12\ \mathrm{s^{-1}}$；已测物种（异戊二烯、单萜、CO、NO₂和40种氧化产物）解释$8.5\ \mathrm{s^{-1}}$。求缺失份额；若缺口完全由一种未测异戊二烯氧化产物在$2\times10^{9}\ \mathrm{molecules\,cm^{-3}}$处填补，求其OH速率常数并说出其可能的化学类别。
::: solution
缺失$= 3.5/12 = 29\%$。隐含速率常数为$k = 3.5/2\times10^{9} = 1.75\times10^{-9}\ \mathrm{cm^{3}\,s^{-1}}$——碰撞极限，**羰基氧化物（Criegee中间体）与高度含氧分子（HOM）**的特征，即自我氧化产物，正是清洁森林真正的成核与气溶胶增长代理。这道题用一个除法写出了当前的研究前沿：缺失反应性不是测量误差而是**未开垦的化学**，而正是这套化学把森林的呼吸变成云凝结核。
:::
:::

::: warning OH不是大气的免疫系统，它不会被"翻转"，甲基氯仿不是完美的时钟，而清洁空气有氧化剂的后果
五个错误。**"我们排得够多OH就会崩溃"**：引擎有强负反馈——OH减少意味着甲烷和CO寿命变长，其升高的丰度经由臭氧-水路径恢复OH的生成，没有任何模型或记录显示失控；诚实的表述是氧化剂场**移动几十个百分点**、有真实的寿命后果，而不是它失灵。**"甲基氯仿精确给出OH"**：时钟假设有已知的平流层环流（它在加速，一个随时间增大的订正）、可忽略的海洋交换（近乎为真）、无产物反馈（错了10–20%）——原始时钟与订正时钟对2000年代趋势各执一词，而分歧就是那篇论文。**"更清洁的空气在化学上是免费的"**：SO₂削减改变光解从而改变OH；NOx削减改变NO₂光稳态从而改变臭氧和OH；气溶胶削减改变紫外场——中国的清洁空气计划是史上最大的**氧化剂实验**，其结果（更多OH、更快的溶剂清除、两个符号的臭氧响应）正被我们边读边到。**"缺失反应性是个校准问题"**：它在仪器不断变好的三十年里幸存下来；它是化学——自氧化、Criegee分支、卤素再循环——把它当噪声会使一切使用这些机制的二次气溶胶和臭氧预估产生偏差。**而"氧化能力保护气候"只对一半**：更多OH移走甲烷（好）但也用同样的NOx和CO制造**臭氧**（坏，而臭氧本身是温室气体和毒物）——大气的洗涤剂不是带符号的服务；它是一个损益必须逐物种清点的反应网。
:::

::: history
**杰克·莱维**（1971）预言微量OH必然主导对流层氧化——一篇两页的论文创立了本领域的核心概念；**保罗·克鲁岑**确立了使臭氧既是污染物又是氧化剂的NOx–HOx循环，这是建立在自由基上的三段准诺贝尔生涯之首（化学奖，1995，与莫利纳、罗兰共享）。测量时代分为两支：**詹姆斯·G·安德森**自1970年代开始的火箭与机载激光诱导荧光，证明了OH可以一个个光子地数；以及**保罗·温伯格**在加州理工的校准学派，其2000年代的相互比解决了关于大气OH测量标准十年的分歧，并揭示了曾使其偏差的一次VOC反应。全球时钟是**罗纳德·普林**的AGAGE网络（1987–），其甲基氯仿读数把OH从模型输出变成带趋势的观测量——而且趋势会变号，1990年代的上升与2000年代的停滞，经**约斯·莱利费尔德**等人的氧化容量综合，成为大气化学的中心问题。换言之，自净大气是一个五十岁的想法、变成了一个四十岁的测量、如今是一个活的指标——其2020年代的读数正由一场无人设计、无人控制的化学实验书写：东亚空气的快速清洁，其氧化剂后果时钟将比流行病学报告得更早。
:::

::: summary
大气的氧化能力是一个自由基收支：OH由臭氧加水生成（三分之二）、黎明由HONO、夜间由臭氧分解；被CO（60%）、甲烷（35%）及其余销毁——一台燃料即刹车的引擎，其丰度由它清除的污染物设定。甲基氯仿把全球氧化剂场变成了测量：OH在1990年代以每年约1%上升、2000年代停滞，并携带一个本身就是研究文献的10–20%时钟订正。LIF直接测量、总反应性缺失的10–30%、以及氯作为边界层氧化剂的兴起，使氧化剂家族更丰富也更不确定。氧化容量如今是地球系统的一个变量：被自己的反馈阻尼、被气溶胶和清洁空气推移、预估本世纪上升、并在我们延长对甲烷依赖的同时缩短甲烷的寿命。大气在自我清洁；大气化学的问题是，它为这项服务向我们收多少钱。
:::

某沿海站点的缺失OH反应性为$2.4\ \mathrm{s^{-1}}$，候选卤代挥发物为$1.4\times10^{9}\ \mathrm{cm^{-3}}$。求其隐含OH速率常数（$\mathrm{cm^{3}\,s^{-1}}$，两位有效数字，如 1.2e-9）。

$k = 2.4/1.4\times10^{9} = 1.7\times10^{-9}\ \mathrm{cm^{3}\,s^{-1}}$——距碰撞极限两倍以内，对含氧或卤代的短寿命物种化学上可信，也正是蒙特利尔议定书尚未计数的那一类。
:::

::: exercise {level=3 check="1.053"}
甲烷排放上升50%，结果[OH]下降5%。平衡甲烷负荷超出仅由排放上升所隐含值（即相对$1.5\times$基线的负荷）的因子是多少？
::: solution
OH反馈乘以$1/0.95 = 1.053$：负荷比线性预期高5.3%——一个小的正反馈，在碳循环模型中被反复施加，是活性气体空气分数不恒定的原因之一。
:::

::: exercise {level=1 check="0.3"}
某污染物唯一的汇是与OH反应（$k = 2\times10^{-11}\ \mathrm{cm^{3}\,s^{-1}}$）。在沿海$[\mathrm{OH}] = 2\times10^{6}\ \mathrm{cm^{-3}}$下求其寿命（天，一位小数）。
::: solution
$\tau = 1/(4\times10^{-5}\ \mathrm{s^{-1}}) = 2.5\times10^{4}\ \mathrm{s} = 0.29$ 天，即**0.3天**——一个日循环者，其氧化在下风向制造臭氧、其气候影响取决于排放地点的那一类。
:::

::: exercise {level=3 check="-0.11"}
某模型预估2100年前[OH]上升12%而甲烷排放保持不变。求甲烷负荷的符号性分数变化（两位小数）。

负荷按$1/1.12 = 0.893$缩放：负荷下降约11%，变化为$-0.11$——那个部分自我限制甲烷强迫的化学-气候反馈，也是GWP数值携带化学不确定度的原因。
