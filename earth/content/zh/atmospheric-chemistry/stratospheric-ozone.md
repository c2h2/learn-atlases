1984年8月，**约瑟夫·法曼**——英国南极调查局一位安静的英国气象学家——打开哈利湾光谱仪的打印件，发现春季臭氧比他团队1957年开始测量柱浓度时的位置低了五分之一——然后，因为数字错得太过离奇，他做了科学该做的事：检查仪器、检查校准、检查在同一台机器上受训的同事，直到又两年确认崩塌的数据之后才发表。卫星团队——其仪器覆盖了哈利湾——曾把自家低值**按算法当作仪器误差丢弃**；大气化学界的模型，用已知气相化学运行，说南极是最不可能出现臭氧洞的地方。那篇论文——法曼、加德纳和普林尼克，《Nature》1985——是本学科的创科之耻也是最大胜利：一份手工校准的地面记录、一段28年的序列，以及对坏消息在检查两遍之前拒绝相信的执拗。它揭示的臭氧洞如今是人类发现全球性威胁、在不到十年内完成归因、并立法解除它有记载最完备的案例——而恢复慢到南极臭氧层将在2060年代前后才回到1980年数值，远在采取行动的那代人离去之后。

## 查普曼的世界——以及为什么它不够

::: proposition 查普曼循环及其亏空 {#prop-chapman}
**西德尼·查普曼**（1930）给了平流层基础化学：氧在240 nm以下光解（$\mathrm{O_2} + h\nu \rightarrow 2\mathrm{O}$），原子找一个第三体结合（$\mathrm{O} + \mathrm{O_2} + M \rightarrow \mathrm{O_3} + M$），而臭氧既吸收致命的紫外（$\mathrm{O_3} + h\nu \rightarrow \mathrm{O} + \mathrm{O_2}$，盾牌的工作循环），又被两个缓慢的气相反应销毁（$\mathrm{O_3} + h\nu \rightarrow \mathrm{O}(^1\mathrm{D}) + \mathrm{O_2}$，随后$\mathrm{O}(^1\mathrm{D}) + \mathrm{O_3} \rightarrow 2\mathrm{O_2}$；以及$\mathrm{O} + \mathrm{O_3} \rightarrow 2\mathrm{O_2}$）。这个机制解释了臭氧层的**位置**——生成在35 km附近达峰，那里通量与密度相乘得宜；观测浓度在22 km附近达峰，那里由输送接管——以及它的失败：查普曼的损耗速率太慢，他的稳态预言的柱约是观测的**两倍**。这个亏空是催化作用的历史邀请函：有什么东西在平流层循环、销毁臭氧而自身不被消耗，而**保罗·克鲁岑**（1970，来自他对火箭发射尾迹的工作）点名了第一个候选者——来自氧化亚氮的NOx，其平流层氧化产出NO和NO₂、催化销毁（$\mathrm{NO} + \mathrm{O_3} \rightarrow \mathrm{NO_2} + \mathrm{O_2}$；$\mathrm{NO_2} + \mathrm{O} \rightarrow \mathrm{NO} + \mathrm{O_2}$）——而**马里奥·莫利纳和谢伍德·罗兰**（1974）点名了第二个更可怕的：人为CFC的光解——它们完好无损地抵达平流层，因为大气里没有别的东西能拆散它们——释放出氯，催化同样的销毁，**每个氯原子在储库物种HCl和ClONO₂最终把它封存之前链长十万个臭氧分子**。
:::

::: example 臭氧层的库存 {#ex-o3mass}
全球平均柱$300\ \mathrm{DU}$，覆盖地球表面（$5.1\times10^{18}\ \mathrm{cm^{2}}$）：求平流层加对流层臭氧的总质量，以及若按地表密度压缩它占大气柱的厚度（Dobson的"三毫米"）。
::: solution
每平方厘米摩尔数$= 8.1\times10^{18}/6\times10^{23} = 1.35\times10^{-5}$，质量$= 1.35\times10^{-5}\times48 = 6.5\times10^{-4}\ \mathrm{g\,cm^{-2}}$；全球范围$6.5\times10^{-4}\times5.1\times10^{18} = 3.3\times10^{15}\ \mathrm{g} = 3.3\ \mathrm{Tg}$——天空中最重要的痕量气体三百万吨，撒遍行星每平方米**半克**，而1990年代全部工业氯负荷（每年1.3 Tg的CFC-Cl）相当于**每年**其质量的三分之一。在平流层化学里，尺度是错误的直觉；催化和链长才是对的。
:::
:::

## 催化与储库

::: definition 家族及其效率 {#def-families}
四个催化家族瓜分臭氧收支。**NOx**（来自$\mathrm{N_2O}$，其平流层氧化使它成为后蒙特利尔世界里最主要的臭氧消耗排放——化肥时代的分子如今领跑制冷剂时代酿成的消耗，这个安静的讽刺）：在上平流层和中纬度下平流层最有效。**HOx**（来自甲烷和水汽）：自我限制，上平流层占主导，也是甲烷的平流层水在下平流层增加臭氧损耗、在上平流层增加臭氧生成的原因。**ClOx**（CFC、哈龙、甲基氯仿、甲基溴）：臭氧洞的家族，其链长不受化学限制而受**储库**限制——HCl和ClONO₂，在ClO遇到甲烷的OH或NO₂时生成——它们让气相氯大体闲置，**直到极夜把它重新激活**。**BrOx**（哈龙、甲基溴）：每原子效率是氯的四十倍，质量极小，也是北极沿海**臭氧耗竭事件**得以发生的原因——每年春天，被阳光激活的化学从海盐中炸出的溴把边界层臭氧滴定到零。政策指标是**臭氧消耗潜能**（ODP）：质量×卤素含量×相对CFC-11的效率，这就是为什么哈龙（ODP约10）和甲基溴（0.6）尽管吨位小却被早早排退出局，为什么含氢氯氟烃（ODP约0.02–0.06）可以作为可接受的**过渡**——它们的氢让对流层OH在平流层看到排放之前毁掉大部分，正是同一道输送过滤器赦免了短寿命溶剂。
:::

::: example 链长 {#ex-chain}
1990年代平流层的全球氯负荷在下平流层以约$3\times10^{6}\ \mathrm{cm^{-3}\,s^{-1}}$的催化速率销毁臭氧，而无机氯储库持有约$1.5\times10^{9}\ \mathrm{cm^{-3}}$。求氯原子对抗封存进HCl/ClONO₂的寿命，以及每次激活销毁的臭氧分子数。
::: solution
活性氯库存为$0.01\times1.5\times10^{9} = 1.5\times10^{7}\ \mathrm{cm^{-3}}$（任一时刻无机氯的百分之一为ClO），所以每个活性原子以$3\times10^{6}/1.5\times10^{7} = 0.2\ \mathrm{s^{-1}}$销毁臭氧——每秒其储库的五分之一，每天激活一万个分子。氯在90天日照季里在活性与储库形态之间循环，累积链长在储库贫乏的南极春天达到**每个氯原子数十万个臭氧分子**——这个算术把一个ppt的CFC变成一个大洲上空60%的臭氧损失。这道题的算术就是为什么一ppt的CFC不是一ppt的普通污染物：催化在乘，而极地机器在乘数上再乘。
:::
:::

## 南极机器

::: definition 涡旋、PSC与二氯一氧循环 {#def-hole-machine}
臭氧洞是一台**有四个部件的机器**，全部南极、全部季节性。**极地涡旋**：在极夜，行星最冷的空气被隔离在极地上空、围在一圈3–4月形成、整个冬季加深、12月崩溃的环极风环里——一间把空气（和化学）整个春天按在原地的隔离室。**极地平流层云**：在$195\ \mathrm{K}$以下——只有南极（和最冷的北极冬天）能达到，因为这块大陆的海拔和黑夜使它成为大气的冷阱——硝酸三水合物和冰粒提供**表面**，储库在其上被摧毁：$\mathrm{ClONO_2} + \mathrm{HCl} \rightarrow \mathrm{Cl_2}$，而关键在于氮被永久移出下平流层（**脱氮**，表现为气球和卫星记录里的硝酸"denox"），从而饿死了本会把氯锁起来的NOx。**阳光**：八月，第一缕光照在装满分子氯的涡旋上，**二氯一氧循环**（ClO + ClO + M → Cl₂O₂；光解 → 2Cl + O₂）在没有NOx打断的情况下运转——整个九月臭氧以每天3%的速度下跌。**地理**：洞的面积追随涡旋，在9月20日前后达到$20$–$30\times10^{6}\ \mathrm{km^{2}}$（2006年纪录$29.9$），而其深度不仅以柱损失度量，而以**总损失质量**度量——坏年份多达7 Mt臭氧，对照该层全球3.3 Tg的库存。北极以一半的强度跑同样的化学——更暖、隔离更差、只在冷冬脱氮（2011年的纪录损失；以及持久涡旋造出有测量以来最深北极臭氧损失的非凡的2020年春天）——而涡旋只是传闻的北半球中纬度，以慢方式损失臭氧：经由气相氯和输送趋势。
:::

::: example 从轨道读洞 {#ex-holearea}
九月TOMS反演的洞面积为$26\times10^{6}\ \mathrm{km^{2}}$、内部平均柱为$140\ \mathrm{DU}$而正常为$300$，求损失的臭氧气量，并与1980年代平均损失4 Mt比较。
::: solution
柱亏空为$160\ \mathrm{DU} = 160\times2.69\times10^{16} = 4.3\times10^{18}$ molecules $\mathrm{cm^{-2}}$，即$3.4\times10^{-4}\ \mathrm{g\,cm^{-2}}$；在$2.6\times10^{18}\ \mathrm{cm^{2}}$上为$8.9\times10^{14}\ \mathrm{g} = 8.9\ \mathrm{Mt}$——超过1980年代平均的两倍，而那一年涡旋寒冷、氯仍近峰值。**质量损失指标**（而非面积）是恢复评估追踪的那一个，因为它加权了化学真正发生的洞的深核——而其多年记录是对蒙特利尔议定书实际效力最干净的观测检验，目前通过：2020年代的质量损失低于2005年基线趋势，涡旋气象的噪声终于让位于氯下降的信号。
:::
:::

## 蒙特利尔与漫长的恢复

::: definition 条约体系及其记分板 {#def-montreal}
从科学到政策的弧线——罗兰与莫利纳的假说（1974）、美国的气雾剂推进剂禁令（1978）和北欧禁令倡议、维也纳公约（1985）、**蒙特利尔议定书**（1987，与法曼的论文相隔仅数月之久出台，建立在受控生产与可交易配额这一当时激进的前提上），及其 历次收紧（1990年伦敦会议定出淘汰日期、1992年哥本哈根会议加快时间表、多边基金为第5条国家的履约买单）——是唯一近乎普遍批准、且**经过测量验证成功**的环境条约：总有效卤素负荷（EESC）在1990年代中期达峰、此后已下降约15%，温带北半球的臭氧趋势在二十年损失之后**自2000年起转平**，而恢复预估（WMO/UNEP 2018）把南极回到1980年数值放在**2066**年前后、北极2045、全球中纬度2040——这些日期由已排放气体50–100年的寿命设定，不取决于任何持续排放。三个脚注让故事保持诚实。议定书意外地也是一部**气候条约**：CFC是巨大的温室气体（CFC-12，GWP 10 200），它的淘汰加上**基加利修正案**（2016，HFC——替代品的替代品，GWP数百到数千）到2100年避免约$0.5\ ^\circ\mathrm{C}$的增暖——有史以来立法的最单项气候行动。它有**漏洞**：2018年发现的CFC-11排放异常被追溯到中国东部未申报的生产——由大气记录而非申报体系发现——证明监测架构才是条约真正的执法者。而它的接班问题是**氧化亚氮**：随着CFC下降，N₂O（不受蒙特利尔管制，由化肥和废水驱动）如今是最大的人为臭氧消耗排放，而其120年的寿命意味着平流层无氯的未来仍将是一个NOx限制的未来。
:::

::: example 恢复时钟 {#ex-recovery}
有效等效平流层氯在1997年以1980年负荷的$1.6\times$达峰，以80年的e倍时间下降。求它回到1980年水平的年份，并解释为什么预估的臭氧恢复日期（南极2066）**早于**氯完全回归的日期。
::: solution
$1.6 = e^{t/80}$给出$t = 80\ln1.6 = 37$ 年——氯约在**2034**年回到1980年水平。臭氧在氯完全回归**之前**恢复，因为关系是饱和的：催化损失在高负荷下对氯大致按对数响应（储库吸收多余部分），所以氯下降的头几十年买到的臭氧多于最后几十年——也因为恢复中的臭氧正爬升于一个平流层冷却的背景（温室诱导，它在中纬度**加速**恢复却加深极地PSC化学）和变化的环流之上。2066年这个日期因此是一种下降的毒药、一种按高度或利或弊的冷却、和一个不读条约的涡旋之间的平衡：诚实的表述是洞的恢复**在轨但未担保**——每个让洞缩小的暖春节年是气象不是政策，而每个冷年也不是失败。
:::
:::

::: warning 洞还没有合拢，相关不是蒙特利尔议定书，而"臭氧是温室气体"是一把双刃剑
五个错误。**"臭氧洞已经修好"**：在冷春节年洞仍每年以接近纪录的面积形成（2020年的北极损失、2023年创纪录漫长的南极涡旋）；修好的是**氯的轨迹**，而洞的年际气象噪声将淹没恢复信号直到2040年代。**"臭氧恢复证明CO₂什么都没做"**：蒙特利尔的成功是**相反**的论据——它是唯一一个排放被测量、被归因、被模拟、被立法、被验证的案例；而平流层的冷却——没有它恢复还会更慢——本身就是温室的指纹。**"CFC已经消失"**：消失的是生产；大气负荷以50–100年的钟下降，非法生产仍在发生（CFC-11，2013–17），而旧泡沫和设备里的遗留库存还会泄漏几十年——大气的记忆比条约的长。**"臭氧是温室气体，所以洞给行星降温了"**：平流层臭氧消耗确实给地表**降温**了零点几瓦——意味着蒙特利尔议定书的臭氧救援移走了一小片遮阳板、给实测增暖**加了**分；同样的逻辑适用于气溶胶面具，这就是为什么"少污染=多增暖"偶尔、局部地为真。**而UV-B效应不全是坏消息**：白内障发病率追随UV-B预估（世卫组织的负担估计把每年数十万病例归给消耗的岁月），但反复引用的"UV导致浮游植物崩溃"之说没能熬过更好的数据——海洋生产力没有可检出的洞驱动下降，一个罕见的乐观订正。
:::

::: history
**西德尼·查普曼**推导了光化学臭氧循环（1930），并在随后的十年里争辩——错地——它不可能被扰动；**G·M·B·多布森**的分光光度计网（1920年代–）把柱变成每日的全球数字，他的Umkehr方法是第一个臭氧廓线反演。**保罗·克鲁岑**把氧化亚氮与平流层NOx催化联系起来（1970），**塞缪尔·约翰斯顿**（1971）提出超音速运输的NOx恐慌——量级错了、机制对了、且给了超音速机队致命一击——而**马里奥·莫利纳和谢伍德·罗兰**提出CFC氯催化（1974）。**法曼、加德纳和普林尼克**在两年自查仪器之后发表了洞（1985）；**苏珊·所罗门**（1986）提出极地云机制，并与加西亚、罗兰、韦伯尔斯一起提出二氯一氧循环；**詹姆斯·安德森**的气球载ClO测量（1986）和NASA GTE空中南极臭氧实验（1987–88，**迈克尔·麦克尔罗伊**主持）在不到三年里闭合了机制——大气科学从假说到证明最快的一段弧线。**TOMS**卫星图（1978–）把洞变成一张图片，而**WMO/UNEP科学评估**（1989年起每四年）成为条约的常任裁判——把法曼手测的柱变成恢复日期的那家机构。
:::

::: summary
- 查普曼（1930）解释了臭氧在哪里；其两倍的高估暴露出催化损耗——来自N₂O的NOx、HOx，以及人为的ClOx/BrOx，每个卤素原子10²–10⁵个臭氧的链长。
- 洞是一台机器：极地涡旋（隔离）、195 K以下的极地平流层云（储库摧毁与脱氮）、阳光（二氯一氧循环，每天柱的3%）、地理（每年九月两千万到三千万平方公里）。
- 北极以半强度跑同样的化学；中纬度经气相氯和输送趋势缓慢损失臭氧。
- 蒙特利尔（1987）及其修正案是唯一经过验证的成功：卤素负荷1990年代中期达峰、趋势自2000年转平、预估2040年代（北极/中纬度）到2066年（南极）恢复。
- 议定书也是立法的最宏大气候行动（CFC及经由基加利的HFC是超级温室气体）——而其漏洞（CFC-11，2013–17）表明大气监测就是执法。
- 接班威胁是氧化亚氮：不受蒙特利尔管制、由化肥驱动、如今是主导性的人为臭氧消耗排放。
:::

## 练习

::: exercise 臭氧质量 {level=1 check="3.3"}
求300 DU柱的全球臭氧质量（Tg；地表$5.1\times10^{18}\ \mathrm{cm^{2}}$，$M_{\mathrm{O_3}} = 48\ \mathrm{g\,mol^{-1}}$，一位小数）。（填数字。）
::: solution
$3.3\ \mathrm{Tg}$——三百万吨，每平方米半克，平流层全部的保护资本，而1990年代每年排放1.3 Tg氯源气体。这个质量比就是"痕量"不等于"无害"的全部论据。
:::
:::

::: exercise 多布森厚度 {level=1 check="3"}
求300 DU臭氧柱按地表密度（$2.7\times10^{19}\ \mathrm{molecules\,cm^{-3}}$）压缩的厚度（mm，取整）。
::: solution
$8.1\times10^{18}/2.7\times10^{19} = 0.3\ \mathrm{cm} = 3\ \mathrm{mm}$。三毫米对抗生物致死剂量的紫外——而洞每年春天移走一个大洲上空三分之二的厚度，这正是多布森单位发明时为了可口而写的同一事实。
:::
:::

::: exercise 洞的质量损失 {level=1 check="8.9"}
九月洞面积$26\times10^{6}\ \mathrm{km^{2}}$、柱亏空160 DU：求损失的臭氧质量（Mt，一位小数）。（填数字。）
::: solution
$4.3\times10^{18}\times48/6\times10^{23} = 3.4\times10^{-4}\ \mathrm{g\,cm^{-2}}$，乘$2.6\times10^{18}\ \mathrm{cm^{2}}$ = $8.9\times10^{14}\ \mathrm{g} = 8.9\ \mathrm{Mt}$——接近全球柱的3%，被一台美洲大小的机器每年蒸发并重造。
:::
:::

::: exercise ODP算术 {level=2 check="14"}
哈龙-1301（CBrF₃）按质量含溴54%；CFC-11（CCl₃F）含氯77%；溴原子每原子效率约为氯的45倍。估算哈龙-1301的ODP（取整；原子量：Br 80，Cl 35.5）。（填数字。）
::: solution
每克卤素原子比：$(0.54/80)/(0.77/35.5) = 0.00675/0.0217 = 0.31$；乘溴的45倍效率，$\mathrm{ODP} = 0.31\times45 = 14$——接近公布的约12（真实效率比按平流层加权），这个算术解释了为什么**几吨哈龙先于几千吨CFC被立法出局**：溴的每原子杠杆巨大，而ODP是它的政策译文。
:::
:::

::: exercise PSC阈值 {level=2 check="50"}
暖涡旋年里，低于PSC形成阈值（195 K）的极地平流层空气份额从30%降到15%。求经PSC处理空气的损失百分数。（填数字。）
::: solution
暴露减半：30→15%的下降是经PSC处理空气的**50%**损失——而观测到的氯活化陡峭地追随它，这就是为什么涡旋温度1–2 K的变化（QBO和突发性增温的噪声）让洞的面积移动数百万平方公里，也是为什么极地平流层的温室冷却（每十年几K）是唯一可能氯在下降之际**推迟**洞恢复的趋势。
:::
:::

::: exercise 氯时钟 {level=2 check="37"}
有效氯1997年以1980年水平的1.6×达峰，以80年e倍时间下降。求回到1980年水平的年数（取整）。（填数字。）
::: solution
$t = 80\ln 1.6 = 37$ 年——2030年代，比臭氧本身恢复（2066）早几十年，因为催化损失在高负荷下饱和。这座时钟是蒙特利尔议定书最重要的数字：它把1987年签署的条约变成大气会守住、无论我们是否记得的日期。
:::
:::

::: exercise 链长 {level=3 check="1000"}
南极春天活化期间，ClO达到1.5 pptv而总无机氯为1.5 ppbv。把氯的活性份额表示为$N$分之一（填$N$）。
::: solution
$1.5/1500 = 10^{-3}$——$N = 1000$分之一。尽管任一时刻只有千分之一的氯是活性的，每个活性原子每天激活销毁数千个臭氧，并在90天季节里多次重返活性池——经典"每个氯原子十万个臭氧分子"的累积链长，就是这个活性份额乘以循环速率与春天窗口。
:::
:::

::: exercise 被避免的条约 {level=3 check="0.2"}
若没有蒙特利尔议定书，不受管制的CFC和HFC排放到2100年将达到约$250\ \mathrm{GtCO_2e\,yr^{-1}}$。若议定书（连同基加利）届时避免了约$0.5\ ^\circ\mathrm{C}$的增暖，求每避免$100\ \mathrm{GtCO_2e\,yr^{-1}}$所避免的增暖（$^\circ\mathrm{C}$，两位小数）。（填数字。）
::: solution
每$100\ \mathrm{GtCO_2e\,yr^{-1}}$为$0.5/250\times100 = 0.2\ ^\circ\mathrm{C}$——与CO₂系统自己的敏感度对排放比同量级，这正是深意：蒙特利尔议定书和基加利值**数千GtCO₂e**，臭氧条约在数量上是史上最高效的气候政策——这个事实值得教授，恰恰因为臭氧故事也是大气**确认了修复有效**的唯一案例，给了CO₂事业其存在性证明与模板。
:::
