在工业时代的绝大部分时间里，人类都在温室气体实验之外平行地进行着一场不受控制的地球工程实验：向空气泵入反光的硫酸盐和烟尘，用船舶尾气和烟囱羽流增亮云层，并在此过程中**掩盖了大约一半的温室增暖**。对流层气溶胶——悬浮的液体和固体颗粒，主要是硫酸盐、有机碳、黑碳、尘埃、海盐和硝酸盐，它们让能见度成为公众抱怨、让日落成为公众艺术——是气候收支中最大的不确定度，是致死人数超过任何其他类别的污染物类别（空气污染，家庭与环境合计，每年夺去数百万条生命），也是作用最快的杠杆：硫酸盐几天内消失，所以它的掩盖随控制措施一同消失，这就是为什么正在席卷亚洲的清洁空气法正在悄悄**揭开**世界一直在借用的增暖。气溶胶也是大气化学与光学相遇之处：颗粒按其尺寸决定的米氏理论散射和吸收，按其吸湿性决定的柯勒理论播种云滴，从而把二十世纪大陆尺度的排放图变成任何温室气体都无法复制的半球尺度强迫格局。

## 气胶是什么

::: definition 成分、尺度模态、混合状态 {#def-aerosol-types}
气候相关的气溶胶在半径上横跨五个数量级，其行为分为三个**尺度模态**。**爱根模态**（约50 nm以下）持有数量——由硫酸、有机物以及（在森林和海岸上空）碘的成核爆发——但几乎没有面积，是一座育婴室：凝聚和凝结把颗粒老化进**积聚模态**（50–300 nm），后者携带**表面积**，因而携带光散射、云凝结核种群，以及能进入肺部的PM2.5；这个名字是字面意思——颗粒*长成*它、也从中移除得很慢，因为它们的尺寸对凝聚和沉降都不合适。**粗模态**（约1 µm以上）携带尘埃和海盐的质量，按几何光学散射，几天内死于雨和重力，主导沙尘暴和海浪飞沫的可见信号。成分决定符号：**硫酸盐和硝酸盐**散射（并携带酸度），**有机碳**散射（二次有机气溶胶）或弱吸收（火灾的棕碳），**黑碳**（烟灰，明火燃烧的石墨化产物）全谱段吸收、是近期最大的人为气候强迫因子之一，**尘埃**依其铁含量两者兼有，**海盐**是原始海洋的镜子、也是研究最充分的CCN。决定一切的细节是**混合状态**：一颗裹了硫酸盐的烟灰颗粒散射更多、单位质量吸收*更少*（低于内部混合物的预测），包裹层还膨胀颗粒的吸水——所以同一吨排放物，在污染平原上空老化一天，就能在模型的光学里翻转符号。表征任何气溶胶场的测量三件套：**散射仪-吸收仪**对（散射与吸收，因而有**单次散射反照率**$\omega$，消光中散射的份额——清洁硫酸盐0.95，新鲜烟灰约0.2），以及从SMPS到光学粒子计数器的粒度分布，其余一切由米氏理论算出。
:::

::: example 两个颗粒，两种气候 {#ex-two-particles}
比较一颗50 nm的烟灰颗粒和一颗500 nm的海盐颗粒：求截面积比和体积比，并用$\lambda = 0.55\ \mu\mathrm{m}$下的尺度参数$x = 2\pi r/\lambda$说明各自处于哪个区（瑞利、米氏、几何）。
::: solution
面积比$(500/50)^{2} = 100$，体积（质量）比$10^{3} = 1000$。尺度参数为$x = 0.57$和$5.7$：烟灰坐在瑞利-米氏边界附近（吸收主导、单位质量高效），海盐在米氏到几何区（高效、几乎无色的散射）。这道题就是一个比值里的气溶胶问题：**质量几乎什么都没说**——一吨50 nm的烟灰和一吨500 nm的盐在数量上差三个数量级、在面积上差两个，在气候效应的符号上差一个正负号。
:::
:::

## 光遇上颗粒：直接效应

::: definition 散射、吸收、辐射强迫 {#def-direct-effect}
深色海洋上空的气溶胶层从行星系统**移除**了阳光，移除量由光学深度$\tau$和单次散射反照率量化：在深色海洋上，纯散射层每个单位光学深度约值$-7$至$-10\ \mathrm{W\,m^{-2}}$，所以工业硫酸盐0.1的光学深度就是三分之一W m⁻²——而1991–93年的**皮纳图博**面纱（全球同温层硫酸盐$\tau \approx 0.15$）交付了约$-0.5\ \mathrm{W\,m^{-2}}$和实测**约0.4–0.5 °C**、为期两年的全球降温，其降温由**詹姆斯·汉森**的团队根据观测提前预测，是20世纪气候科学少数成功的事前预测之一。吸收性气溶胶做的事更奇怪：烟灰**加热它所在的层**，稳定边界层（"半直接效应"，把污染流出区上空的浅云烧掉），而沉到雪冰上时，它在白色就是气候资产的地方降低反照率——北极和喜马拉雅是一克烟灰买到最多增暖的两个地方。硫酸盐记录的**半球不对称**（二十世纪中叶北大西洋的"增暖坑"、清洁空气法之后北美和欧洲的变亮）是直接效应的观测指纹，而它的镜像——中国把SO₂削减60%后2013年后的东亚变亮，以及2020年航运脱硫从世界航线上移走可测量的掩盖——是每个预估都携带的**揭蔽**。气溶胶总人为强迫（全组分，直接加云相互作用）在IPCC AR6中评估为接近**−0.4 W m⁻²**、范围−0.1到−0.7：这个数字说气溶胶藏起了温室强迫的大部分，而其不确定度本身就是强迫收支中最大的单项。
:::

::: example 皮纳图博实验 {#ex-pinatubo}
皮纳图博的强迫$-0.5\ \mathrm{W\,m^{-2}}$持续约2年。取气候敏感度参数$\lambda = 0.8\ \mathrm{K\,(W\,m^{-2})^{-1}}$，求平衡降温，并解释为什么观测到的峰值降温（约0.4 °C）是合理的匹配。
::: solution
平衡值应为$0.8\times0.5 = 0.4$ °C；观测峰值与之匹配，因为火山强迫在混合层自己的时间尺度上衰减——表层海洋冷得快，深海几乎没察觉，系统骑着强迫走而不是等平衡。这道题是火山的标定价值：它们是辐射收支唯一一次大型、仪器完备、自然随机化的扰动，而皮纳图博与预测的一致，是20世纪关于气溶胶辐射传输物理精确到零点几之内的最强证据之一。
:::
:::

## 云：间接效应

::: definition 柯勒、特威米、阿尔布雷希特、船舶 {#def-indirect}
气溶胶最强的气候表演在**云**上，物理是柯勒的：过饱和空气中的可溶颗粒当环境过饱和度超过其**临界**值时被活化为云滴（越小、越难溶的颗粒需要越高），所以云的滴数由CCN种群和上升气流决定，而液态水——由空气湿度固定——在它们之间分配。**斯蒂芬·特威米（1974）**画出第一个推论：固定液态水路径下，更多液滴意味着更小半径（$r \propto N^{-1/3}$）和**更高的云反照率**——第一间接效应；**哈尔·阿尔布雷希特（1989）**补上第二个：更小的液滴少毛毛雨，所以云活得更久、覆盖更多天空（云寿命效应，符号稳健但量级不定）。卫星让两者可见：**船舶航迹**——太平洋上被增亮、被抑制毛毛雨的层云线，1960年代在卫星图像上首次注意到，二十年后在ISCCP档案中以全球尺度展示——是"船在航行处云就是人造物"被拍得最多的证据，统计意义上的增亮也出现在亚马逊羽流和南部非洲火灾的下风向。阴暗面是**半直接效应**（吸收层蒸发云）和模型间仍相差两倍的云调整：气溶胶总有效强迫的不确定度由这些云相互作用主导，这就是为什么卑微的船舶航迹仍是活跃的研究对象——云对气溶胶的响应是强迫收支中最大的未解决项，也是"我们藏起了多少增暖？"在两倍以内无法回答的原因。
:::

::: example 特威米的算术 {#ex-twomey}
污染使一朵温暖、无毛毛雨的海洋云在固定液态水下CCN翻两番。求液滴半径比和云光学深度的增倍因子。
::: solution
固定液态水意味着$r \propto N^{-1/3}$，所以半径缩小到$4^{-1/3} = 0.63$；光学深度$\tau_{\mathrm{c}} \propto \mathrm{LWP}/r$上升到$4^{1/3} = 1.59$，反射短波上升约六分之一到四分之一（增亮的云会饱和，所以两流解抑制了原始光学深度的增益）。这道题解释了为什么"海洋云增亮"方案只需把滴数翻一两倍就有效果——也解释了为什么天空的第一间接效应真实、巨大，并且**已经在全功率运行**：未来是揭开它，不是添加它。
:::
:::

## 收支、健康，与实验的收尾

::: definition 净值、致命份额与终局 {#def-aerosol-budget}
气溶胶收支是一本符号的账。**负（冷却）：**硫酸盐和硝酸盐散射（直接）、特威米与寿命云效应、以及让现有CCN更胖更湿的吸湿膨胀。**正（增暖）：**黑碳的吸收与雪反照率变暗（最大的正项，集中在北极和高山）、吸收处的棕碳、以及半直接的云烧失。净值接近**−0.4 W m⁻²**，对约+2.7 W m⁻²的温室强迫，意味着气溶胶实验藏起了强迫的大部分，而观测到的增暖是一个更大强迫减去更大掩盖后的余额。**致命份额**是同样的颗粒：PM2.5——积聚模态，小到能吸入、持久到能滞留——被评估为环境的首要健康风险，通过心血管和呼吸疾病每年造成全球数百万过早死亡，而暴露最高的正是如今正在减排的地区；队列流行病学（六城市研究和美国癌症协会研究及其后续）使气溶胶政策成为现存最快的公共卫生杠杆，美国1970–2020年的PM削减被归功于预期寿命的增加，其成本按《清洁空气法》自己的评估相对收益微不足道。**终局**是算术：硫酸盐和黑碳活几天，CO₂活几个世纪，所以每部清洁空气法都在十年内把被掩盖的增暖变成实现的增暖——中国的SO₂崩塌已经让东亚的天空变亮并加上了可测量的区域增暖信号，2020年国际海事组织航运脱硫规则移走了航线正上方的掩盖，评估文献如今把"气溶胶协同控制"当作标准情景。诚实的总结：世界无法选择**是否**结束气溶胶实验——健康迫使结束——只能选择**多快**，以及伴随揭蔽必需的CO₂和甲烷削减能否在被借的增暖到期之前到来。
:::

::: example 以强迫计清洁空气的代价 {#ex-unmasking}
若亚洲清洁空气使气溶胶强迫从$-0.4$升到$-0.2\ \mathrm{W\,m^{-2}}$，求附加强迫，并用$\Delta F = 5.35\ln(C/C_0)$以ppm CO₂当量表达。
::: solution
揭蔽为$+0.2\ \mathrm{W\,m^{-2}}$，而$e^{0.2/5.35} = 1.038$——约**21 ppm**的CO₂当量，不足当前排放一一年半。这道题就是一个对数里的政策陷阱：揭蔽每十年不大但方向不可逆，所以从现在起每一吨CO₂都要对着一个正按设计和法律被拆除的掩盖盾牌来记账。
:::
:::

::: warning 气溶胶冷却不是排放气溶胶的理由，黑碳不是CO₂式的目标，间接效应不是测出来的数字
五个错误。**"气溶胶冷却，所以清洁空气对气候有害"**：掩盖是真实的、揭蔽是测得的代价，但替代方案是每年数百万可预防的死亡，去维持一个只有温室强迫几分的强迫——政策答案是**协同控制**：狠砍黑碳这类增暖颗粒，睁着眼砍冷却颗粒，并把CO₂当作面具已摘下那样去砍，而到2050年它将会是。**"全球变暗意味着云在给世界降温"**：1950–1980年代地表太阳辐射的减少是真实的、部分由气溶胶驱动，但它的*终结*——变亮——正助推欧洲和东亚加速的增暖；变暗是气溶胶时代上半叶的一章，不是常设的气候属性。**"黑碳是速赢，所以优先于CO₂"**：黑碳的强迫真实、健康协同收益巨大，但它的寿命是几天——削减它买到的是避免峰值增暖的零点几度，不是稳定，而且常与烟灰共同排放的甲烷（火炬、家庭燃烧）通常是更大的气候红利。**"船舶航迹的照片证明了间接效应的量级"**：它们证明的是*机制*；*量级*——其跨度等于平衡敏感度高低端之差——取决于原始云的易感性，而卫星气候学仍无法钉住它。**而"气溶胶强迫是测出来的"**：它是*推断的*，常常靠把模型调向历史温度记录本身，这在统计上把掩盖估计与气候敏感度估计纠缠在一起——是气候科学中最诚实的开放问题之一，也是气溶胶-云外场试验被当作气候优先基础设施的原因。
:::

::: history
散射物理是**古斯塔夫·米**的（1908），对球形颗粒求解，至今仍是每个气溶胶模型光学的发动机；云物理是**威廉·柯勒**的（1936），他在溶质-曲率平衡上建立的液滴活化理论仍决定哪些颗粒成为云。气候后果则要等**斯蒂芬·特威米**1974年那篇"污染雾使云更亮"的短文、**哈尔·阿尔布雷希特**1989年的抑制毛毛雨推论，以及1992年**查尔森、施瓦茨、黑尔斯、罗杰斯、朗和贝里**的综合——后者把气溶胶-云问题变成全球强迫问题——而**维塔巴德兰·拉马纳坦**1970–80年代的辐射工作同时在确立：气溶胶的"隐形半球"可以与温室气体平分重要性。观测革命从**康诺弗**1966年用卫星识别船舶航迹，经由**ISCCP**云档案的全球航迹统计，到2000年代的**Aeronet**日光光度计网和卫星光学深度记录；健康论据由**六城市**和美国癌症协会队列建立，其二十年随访把一个霾问题变成了地球上首要的环境死亡率估计。皮纳图博（1991）贡献了本领域最辉煌的时刻——一次被预测、被观测、被正确归因的全球降温——而2010年代贡献了最奇特的时刻：清洁空气法对掩盖的有意移除，一场揭蔽实验，其结果正出现在2020年代的温度记录中，是没有人计划过的最重要的气溶胶测量。
:::

:::

::: summary
气溶胶是大气可见又隐形的那半个球：积聚模态颗粒散射阳光（硫酸盐、硝酸盐、有机物、海盐）、吸收它（黑碳与棕碳），而最重要的是通过播种云滴来组织云（柯勒活化、特威米增亮、阿尔布雷希特寿命）。其净强迫接近−0.4 W m⁻²，藏起了温室增暖的大部分，而它们的日子由健康政策而非气候政策倒数：PM2.5每年致死数百万，清洁空气法正逐十年拆除这层面具，而揭蔽——在东亚和航线上已经可见——是对未来增暖一项已承诺、不可逆的添加。黑碳是混合物中增暖的少数派，是唯一一条不牺牲气候就能救命的快速行动杠杆。气溶胶时代的第一幕藏起了增暖；第二幕将把它花回，剩下的唯一变量是温室气体的削减能否先到。
:::

::: exercise {level=2 check="2"}
某日光光度计在440 nm读得AOD 0.9、在550 nm读得0.6。计算Ångström指数$\alpha = -\ln(\tau_1/\tau_2)/\ln(\lambda_1/\lambda_2)$（取整）并划分模态。
::: solution
$\alpha = \ln(0.9/0.6)/\ln(550/440) = 0.405/0.223 = 1.8 \rightarrow 2$：细模态主导，是烟霾和城市霾而非矿物尘（后者$\alpha < 1$）的光学特征。
:::

::: exercise {level=2 check="0.4"}
取$\lambda = 0.8\ \mathrm{K\,(W\,m^{-2})^{-1}}$，求皮纳图博$-0.5\ \mathrm{W\,m^{-2}}$的平衡降温。
::: solution
$0.8\times0.5 = 0.4$ °C——与温度计和卫星实际测到的相差不到十分之一，两回都应验（1992–93的冷距平及其恢复）。

::: exercise {level=3 check="21"}
把$+0.2\ \mathrm{W\,m^{-2}}$的揭蔽以ppm CO₂当量表达（$\Delta F = 5.35\ln(C/C_0)$，取整）。
::: solution
$e^{0.2/5.35}-1 = 3.8\%$，约21 ppm——不足当前排放一一年半，即面具拆除的年度价签。

::: exercise {level=3 check="8"}
雪中的烟灰把雪反照率从0.85降到0.75，该区域年均日射150 W m⁻²。求强迫（W m⁻²）并说出这里最重要的地方。
::: solution
$\Delta F = 150\times0.10 = 8$ W m⁻²，在积雪季和积雪区——局部巨大，相当于一座城市的废热，这就是为什么冰冻圈把黑碳当作主要强迫因子，尽管其全球平均强迫只是CO₂的零头。
:::

::: exercise {level=1 check="1000"}
求第一题中500 nm与50 nm颗粒的体积（质量）比。
::: solution
$(500/50)^{3} = 1000$——一个大颗粒携带一千个小颗粒的质量，但按单位质量，小颗粒拦截的阳光多得多；气溶胶科学数颗粒而不称重，理由就在这个比值。
:::

::: exercise {level=2 check="0.2"}
某区域气溶胶总光学深度0.5，单次散射反照率0.9。若吸收强迫按$\tau(1-\omega)$缩放，求该气柱的吸收份额$\tau(1-\omega)$。
::: solution
$0.5\times0.1 = 0.2$——在同样光学深度下，这个数字把冷却主导的霾（硫酸盐，$\omega > 0.9$）与受增暖影响的霾（受烟影响，$\omega \sim 0.7$–$0.8$）区分开来。
:::
