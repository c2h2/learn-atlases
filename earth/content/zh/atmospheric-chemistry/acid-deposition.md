1872年，一位名叫**罗伯特·安格斯·史密斯**的苏格兰化学家向英国科学促进会提交了一本书，书里有一个短语，在一个全球性问题被解决之前一个世纪就为它命了名：*酸雨*。史密斯的职业生涯建立在曼彻斯特的空气上——他测过它的酸度、烟灰、硫，并在德福埃使"smog"一词出名之前多年就在笔记本里创造了这个词——而他的洞见至今仍在组织这门学科：一座城市烧掉什么，它的雨水就在下风几百公里处交付什么。从史密斯到1970年代的一个世纪里建起了高烟囱，把地方性酸度变成区域性酸度——高烟囱不脱硫，只把它撒遍大陆——而随后的二十年产生了环境科学最清晰的弧线之一：发现（瑞典和挪威的湖沼学家、加拿大和阿迪朗达克的湖泊调查）数百个清澈寒冷、花岗岩土壤的湖泊正在死于它们从未制造的酸；机制（强酸阴离子从土壤中剥离盐基阳离子，直到锁在每一颗长石里的毒药铝流入水中）；政策（1979年联合国公约、1990年发明总量交易制的美国酸雨计划、德国和加拿大的国家计划）；以及仍未写完的尾声（排放降了90%，湖泊缓慢恢复，土壤更慢，而如今的酸部分以氮和氨的形式来自另一大排放源——农业）。酸沉降是环境科学应当如何运作的案例研究：假说、机制、跨界条约、市场发明，以及以土壤年代而非新闻周期计量的恢复所要求的谦逊。

## 酸度的化学

::: definition pH、自然基线与强酸阴离子 {#def-acidity}
未污染的雨天然呈酸性：大气CO₂溶入碳酸，把纯水雨定在**pH 5.6**（经典数字；与现代420 ppm CO₂平衡时约5.0，在有机酸和海盐介入处更低——基线是一个移动的参照，这就是科学界测量**强酸阴离子**——硫酸根和硝酸根——而非pH的原因）。酸雨问题是**强酸**的加入——SO₂氧化而来的硫酸（气相OH攻击历时数小时到数天，以及云滴内H₂O₂和O₃的水相氧化，在多云污染空气中是更快且主导的路径）和NO₂夜间NO₃/OH化学而来的硝酸——以**湿沉降**（雨、雪、山坡森林撞击云雾清除的云水，"隐蔽沉降"，可使迎风坡的酸负荷翻倍）和**干沉降**（表面直接吸收的气体和颗粒，常占总量一半）交付。受体的命运由**酸中和容量（ANC）**决定：盐基阳离子（Ca²⁺、Mg²⁺、Na⁺、K⁺）超过强酸阴离子的部分，以及土壤中风化补充淋失物的碳酸盐和可交换基库。石灰岩流域可以中和一个世纪的酸雨；薄层花岗岩土壤毫无还手之力——这就是为什么同一股大陆气团酸化了一万个斯堪的纳维亚和阿迪朗达克湖泊却让黏土土壤的中西部大体无恙，也是为什么政策指标是**临界负荷**：一个生态系统不受损害所能接受的最大沉降量，与实际沉降制图对照，产生推动每一项欧洲和北美协定的超负荷图。要记住的算术：pH是对数的，所以pH 4.3的雨比5.6基线酸二十倍——而pH 5的湖泊不是"略微"酸化，而是坐在鱼类繁殖失败的阈值上。
:::

::: example 酸雨有多酸 {#ex-ph-factor}
求(a) pH 4.6和(b) pH 4.3的[H⁺]超过pH 5.6基线的倍数，并计算50 µeq L⁻¹的雨水年降水1米时的年酸沉降（meq m⁻² yr⁻¹）。
::: solution
每个pH单位是十倍：pH 4.6是基线[H⁺]的**10倍**，pH 4.3是**20倍**。沉降量为$50\ \mathrm{\mu eq\,L^{-1}} \times 1000\ \mathrm{L\,m^{-2}} = 50{,}000\ \mathrm{\mu eq\,m^{-2}} = 50\ \mathrm{meq\,m^{-2}\,yr^{-1}}$——敏感北方针叶林流域临界负荷（10 meq m⁻² yr⁻¹）的五倍，这一个乘法就是整个酸化问题：负荷并不极端，受体才是毫无设防。
:::
:::

## 生态账本

::: definition 铝、鱼、森林、石头 {#def-acid-effects}
把酸雨从化学故事变成死亡故事的机制贯穿**土壤**。沉降的酸通常在土壤中被风化和交换位点上的盐基阳离子中和；当酸锋耗尽可交换盐基库时，**铝**——在接近中性pH下丰富、不溶、无害——以Al³⁺溶解，对鱼是急性剧毒：它在鱼鳃上皮沉淀为凝胶状氢氧化物，破坏渗透调节，直到鱼在富氧水中窒息而死。这个格局在1970年代由斯堪的纳维亚和北美的湖沼学家一湖一湖地测绘：清澈、美丽、**无鱼**的湖泊（"清水综合征"：酸化湖泊变得晶亮，因为食草生物死亡、溶解有机碳被光漂白——酸化湖泊反直觉地比健康的更*好看*），鲑和红点鲑等敏感物种在pH ~5.5繁殖失败，~5以下彻底崩溃。陆地的账更慢但同样真实：森林土壤盐基阳离子（尤其钙）的耗竭，可见于1980年代德国的**森林死亡**恐慌——它部分是酸沉降、部分是干旱和其他胁迫，其最坏的预测并未成真，这个诚实的复杂性被该领域作为多因子归因的中心教训教授；有文献记载的影响包括菌根群落、固氮林下物种，以及食鸣禽的钙营养（著名的北美研究把鸣禽种群下降与缺钙森林和酸化昆虫猎物联系起来）。建筑的账最显眼：酸加速石灰岩和大理石的溶解（卫城的方解石表面、泰姬陵的黄化、柏林大教堂，以及欧洲每一座在20世纪重新切割的哥特立面）、石头硫化成使城市纪念碑发黑黑色石膏壳，以及美国评估定为每年数十亿美元的腐蚀成本。临界负荷图——沉降减去生态系统的耐受度——是政策武器：对欧洲，它们显示斯堪的纳维亚中南部大部、黑森林、波希米亚和波兰超负荷；对北美，阿迪朗达克、新英格兰，以及从安大略到拉布拉多的加拿大地盾。
:::

::: example 临界负荷算术 {#ex-critical-load}
一流域接受36 meq m⁻² yr⁻¹的酸沉降，其临界负荷为10 meq m⁻² yr⁻¹。求超负荷；若排控使沉降削减70%，求新负荷，并判断湖泊（在沉降降到临界负荷以下时恢复）是否在恢复之路上。
::: solution
超负荷$= 36 - 10 = 26$ meq m⁻² yr⁻¹；削减后$36\times0.30 = 10.8$——仍**高出临界负荷0.8**，所以湖泊*几乎*但尚未恢复。这道题就是1990年代至2010年代的政策现实，两个减法而已：削减90%的排放仍可能让最敏感的受体勉强压线，这就是为什么科学的最后一公里——来自农业的残余氮和氨——如今是约束性瓶颈。
:::
:::

## 恢复、工程与氮的接班

::: definition 施石灰、氮饱和与氨的时代 {#def-recovery}
在排放控制与生态系统恢复之间，横着一种世界公开用于数千水体的技术：**施石灰**——用直升机和船撒碳酸钙（实验性地也用硅灰石，一种风化成碳酸氢根同时封存CO₂的硅酸钙），施于湖泊、流域土壤乃至湖底沉积物；瑞典和挪威四十年的业务计划以每年一湖不到一公里公路的代价，让几千个酸化水体保持有鱼可钓。施石灰是分诊不是治愈——只要负荷超过景观能中和的负荷就必须重复——而它的极限界定了前沿：**氮饱和**，即森林生态系统固持氮的能力被超过、硝酸根漏入排水的状态（在哈伯德布鲁克和欧洲、中国、美国东部集约施肥平原都有记载），把养分问题一次性变成酸化与富营养化问题，并标记出即使今天降低了的沉降也不可能在人类时间尺度上恢复ANC的生态系统。而接班的污染物是**氨**：SO₂削减后，沉降的盐基阳离子对酸阴离子平衡日益由牲畜和化肥的NH₃决定，它在本地中和酸度（抬高颗粒pH、加速硫酸盐生成，以及——一个模型仍在敲定的转折——在富氨气溶胶水中增强硫酸盐水相生成），以铵的形式沉降，并在土壤中被硝化为硝酸，把质子交付到田地下游。政策后果是哥德堡议定书纳入氨，以及当前欧洲关于Natura 2000生境氮的诉讼：酸雨的终局是一场务农谈判，而世界上最清洁的空气如今携带着来自食物的、不可小觑的酸化负荷。
:::

::: example 给湖泊施石灰 {#ex-liming}
一个20公顷的湖（平均深5米）ANC为−40 µeq L⁻¹，必须抬到+50 µeq L⁻¹。求所需石灰量（kg CaCO₃，克当量50 g eq⁻¹），并解释为什么实际施用量是水柱数字的2–5倍。
::: solution
水体体积$= 2\times10^{5}\times5 = 10^{6}\ \mathrm{m^{3}} = 10^{9}$ L；需要抬升$90\ \mathrm{\mu eq\,L^{-1}} = 9\times10^{-5}$ eq L⁻¹，即$9\times10^{4}$ eq，或$4.5\times10^{6}$ g——仅水柱就要**4.5吨**CaCO₃。实际剂量大数倍，因为**沉积物和土壤才是真正的酸库**——氢氧化物和交换复合体在水柱看似治好之后很久仍在消耗盐基——这就是为什么瑞典的计划按流域诊断而非湖体积投药，也是为什么施过石灰的湖是服药的病号，不是治愈的病号。
:::
:::

## 从条约到总量交易

::: definition 政策弧线与恢复滞后 {#def-acid-policy}
酸沉降产生了现代跨界空气质量法律的模板。科学-政策循环始于**瑞典**1972年斯德哥尔摩会议代表团（第一个提交长距离酸化报告的政府），产出联合国**《长距离跨界空气污染公约》（1979年日内瓦公约）**——第一个有法律约束力的多边空气协定，及其硫议定书（1985年，排放减半）、NOx议定书（1988年）和进一步削减议定书（1994、1999年）——以及平行的**美加空气质量协定（1991年）**。美国的回应，1990年《清洁空气法》修正案第四编，发明了让深度削减变便宜的仪器：全国电力部门SO₂配额**总量交易**——对总排放的硬上限、可自由交易的许可、以及诱导燃料转换、洗涤器和任何监管者都无法规划的削减最优配置的价格信号。其结果是环境政策中记载最完备的：美国电力部门SO₂排放从1990年约16 Tg yr⁻¹降到2020年不足2 Tg yr⁻¹（削减超过85%，成本约为最初估计的十分之一，配额价格从令人担忧的数百美元崩到几十美元），湿沉降硫酸盐同步下降，**恢复**开始了——在国家大气沉降计划、阿迪朗达克和斯堪的纳维亚监测网中一湖一湖地测量：地表水ANC上升、硫酸盐下降、鱼回到了一些湖泊。但恢复有两个模型预料到而公众没预料到的滞后：**土壤滞后**（可交换阳离子库和缓慢风化通量以十年到百年尺度补充，所以即使空气已如今天般干净，许多湖泊一代人内仍不会有鱼），以及**氮抵消**（NOx的削减小于SO₂，而农业的氨——让硫酸铵和硝酸铵以颗粒形式存在的碱性反离子——一直在增长，所以在欧洲和美国东部的部分地区，氮如今占剩余酸化负荷的三分之一到一半，剩余的超负荷既是烟囱问题也是农场问题）。因此酸沉降故事是该领域的完整长篇小说：问题、机制、条约、市场、恢复——外加一个尾声警告：每个被解决的污染问题都会留下一个接班者。
:::

::: example 拯救湖泊的市场 {#ex-captrade}
酸雨计划（第二编）把SO₂上限定在8.95 Gg yr⁻¹，配额价格1995年约1500美元，十年内跌破100美元。若1000座电厂各自的减排成本在每吨200–5000美元间均匀分布，求在500美元配额价格下哪些电厂减排，并解释为什么总成本远低于"每厂削减50%"的命令控制制估计。
::: solution
减排成本**低于**500美元的电厂（最便宜的一半）减排并出售配额；昂贵的一半购买许可。总减排量是同样的吨数、**最低的**总成本，因为边际吨总是由能最便宜移除它的人移除——教科书上的证明在大陆尺度上运行：当减排成本异质（事实如此）时，价格工具优于统一标准。配额价格从1500美元崩到不足100美元，是市场发现了煤改气和选择性洗涤远比电力公司游说时的估计便宜——这个数字让总量交易成为政策出口品（也是二十年后欧盟和加州为碳市场援引的模板）。
:::

::: warning 森林死亡既错又对，"已恢复"不等于结束，自然酸度不是可以忽略的基线，氨是新的硫
五个错误。**"森林如预测般死亡"**：1980年代森林死亡的最坏情形并未成真——树木衰退被证明同样是干旱、严冬、臭氧和立地胁迫而非只是酸——但森林土壤的钙耗竭是真实的，如今是缓慢的遗产；诚实的解读是，多胁迫系统很少上演单因子的戏剧，而预测应按机制而非标题评分。**"排放降了，所以问题解决了"**：对大多数受体沉降已低于临界负荷，但对最敏感者没有；土壤盐基库需要几十年到几个世纪补充；完全的生物恢复（鱼、敏感无脊椎动物、森林养分）比化学滞后一代人——监测网最重要的发现是*恢复进行中*，而非恢复完成。**"雨天然pH 5.6，所以酸雨只是化学"**：5.6是CO₂平衡计算，不是生态基线——工业化前的强酸阴离子沉降低五到十倍，而临界负荷是对照**净酸化为零**而非今天的雨定义的。**"氮沉降是同一个问题"**：它是穿同一件衣服的*不同*问题——氮是养分，所以它的沉降同时施肥和酸化，偏爱嗜氮物种，以硫酸盐类比无法预测的方式退化石楠荒原和苔原的生物多样性；1999年哥德堡议定书纳入氨和欧盟氮临界负荷诉讼是当前前沿。**而"总量交易证明市场解决一切"**：它证明市场解决*上限明确、计量完备、成本异质*的问题——SO₂有连续烟囱监测（很大程度上正是因交易而安装）、少数大型点源、硬上限；这三个条件是它成功的原因，而它们的缺席是碳交易更难的原因——教训推广到工具，不推广到乐观。
:::

::: history
**罗伯特·安格斯·史密斯**（1872）从曼彻斯特的空气命名了酸雨；此后是八十年"稀释是解决方案"的高烟囱工程，直到1960–70年代的斯堪的纳维亚湖泊调查——挪威和瑞典的化学家与湖沼学家记录数千湖泊无鱼的清澈——让这一现象无法被忽视，而**瑞典**1972年的政府报告帮助把它列入斯德哥尔摩会议议程。在北美一侧，机制经由**哈伯德布鲁克生态系统研究**（F·赫伯特·博尔曼、吉恩·利肯斯等人，1963年起）成为教科书科学，其降水化学和钙收支工作表明酸化在几十年内耗尽森林的盐基阳离子储备。政策谱系经由**1979年日内瓦公约**（第一个有约束力的多边空气条约）、**1985年赫尔辛基硫议定书**（第一个有约束力的削减）、德国1980年代的**森林死亡**辩论、**美国国家酸降水评估计划**十年的综合及其政策成果、含SO₂总量交易的**1990年清洁空气法修正案**第四编，以及**1991年美加空气质量协定**。测量的骨干是**国家大气沉降计划**（1979–）、欧洲的**ICP Waters和ICP Forests**，以及**IAPWS**国际评估——其2016年版宣布酸化"在排放中已解决，在生态系统中未完成"——一个罕见的、其教科书结局由自己的监测网写就的环境问题。
:::

::: summary
酸沉降是环境科学的完整案例：SO₂和NOx氧化为强酸、干湿两路沉降、耗尽土壤盐基阳离子库直到铝动员、湖泊森林败落——以临界负荷制图，由1979年跨界公约和1990年总量交易发明管制，如今处于有记载但滞后的恢复中：美国SO₂降逾85%、成本为预计的十分之一，湖泊的ANC以落后空气一代人的速度上升。尾声是该领域的警告：剩余负荷是氮和农业氨，土壤的钟是几个世纪，而被解决问题的真正教训是机制比标题长寿——森林死亡夸大了戏剧、低估了钙，而监测网以耐心和不合时尚写就了诚实的结局。
:::

::: exercise {level=1 check="10"}
求pH 4.6的[H⁺]超过pH 5.6基线的倍数。
::: solution
一个pH单位 = **10**倍——正是这个对数尺度让"一点酸"成了大数字。
:::
:::

::: exercise {level=1 check="50"}
求50 µeq L⁻¹的雨水在年降水1米时的酸沉降（meq m⁻² yr⁻¹）。
::: solution
$50\ \mathrm{\mu eq\,L^{-1}}\times1000\ \mathrm{L\,m^{-2}} = 50\ \mathrm{meq\,m^{-2}\,yr^{-1}}$——敏感流域临界负荷的五倍。
:::
:::

::: exercise {level=1 check="26"}
沉降36，临界负荷10（meq m⁻² yr⁻¹）。求超负荷。
::: solution
$36-10 = 26$ meq m⁻² yr⁻¹——出现在1980年代每一张欧洲超负荷图上的数字。
:::
:::

::: exercise {level=1 check="20"}
求pH 4.3的雨相对基线的[H⁺]倍数。
::: solution
$10^{5.6-4.3} = 10^{1.3} = 20$——天然碳酸酸度的二十倍。
:::
:::

::: exercise {level=2 check="-50"}
某湖Ca+Mg+Na+K = 150 µeq L⁻¹，硫酸根+硝酸根 = 200 µeq L⁻¹。求其ANC（µeq L⁻¹）。
::: solution
$\mathrm{ANC} = 150 - 200 = -50$ µeq L⁻¹——ANC为负意味着湖泊不再中和输入的酸度；鱼类繁殖在零以下某处失败，崩溃紧随−100到−200而来。
:::
:::

::: exercise {level=2 check="10.8"}
36 meq m⁻² yr⁻¹的沉降下降70%。求新负荷。
::: solution
$36\times0.30 = 10.8$——仍勉强高于10 meq的临界负荷：减排的最后10%是一个生态系统恢复的最初10%。
:::
:::

::: exercise {level=3 check="67"}
某森林土壤的可交换盐基库以每年1.5%周转。求沉降停止后e倍恢复时间（年）。
::: solution
$1/0.015 = 67$ 年——正是这只土壤之钟，让"排放已解决、生态系统未完成"成为整个酸雨故事的准确总结。
:::
:::

::: exercise {level=3 check="2"}
把一摩尔硫酸完全中和为硫酸铵需要多少摩尔氨（NH₃）？
::: solution
**2**——H₂SO₄的两个质子需要两个碱，这就是为什么农业NH₃虽自身呈碱性却间接交付酸度：它形成的铵稍后被硝化，把质子释放到田地下游。
:::
