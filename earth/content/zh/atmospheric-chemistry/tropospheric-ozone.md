对流层臭氧是谁都没有排放的污染物：它由阳光在天空中从氮氧化物和挥发性有机物装配而成，而配方的产品——一种肺刺激物、一种作物杀手、以及大气持有过的第三重要的温室气体——降临的日子可能根本没有本地的烟囱。故事从一场伦敦雾讲起。1905年，公共卫生医生**亨利·安托万·德福**在一次化学大会上需要为一个词指称他城市里"巨大的雾或烟雾"，造出了**smog（烟雾）**；半个世纪里这个词意味着煤烟和含硫的雾——1948年的多诺拉、多诺拉杀手雾、1952年伦敦灾难——直到洛杉矶显出第二种更古怪的烟雾：烧眼睛、裂橡胶、伤树木，且不在冬天的煤烟逆温里达峰，而在交通下风向明媚的夏日午后达峰。**阿里·豪根-斯米特**——在1950年代破译了它的那位荷兰有机化学家——发现氧化剂是臭氧，而它的工厂靠阳光下的汽车碳氢化合物和NOx运转——光化学烟雾。七十年后，他命名的这个问题已经全球化，是史上最昂贵空气质量工程的靶子，且同时在赢和输：在配方成分被削减的美国和欧洲，地表臭氧在下降；在南亚和东亚在上升；而在所有地方都被甲烷、一个更暖的生物源世界、以及大火时代的烟雾悄悄地把基准抬高。

## 你没有排放的那种污染物

::: definition 为什么臭氧是二次污染物 {#def-secondary-ozone}
臭氧没有重要的原生源：引擎排放NO和碳氢化合物，不排O₃，而对流层负荷由 [[atmospheric-chemistry/photochemistry]] 的光化学引擎就地装配——带NO转NO₂欠账的莱顿循环、从VOC氧化里付账的过氧自由基、让净臭氧取决于NOx与VOC之**比**而非任一单独的零循环。因此地表混合物是三本账之和：20–40 ppb的**背景**（经对流层顶折叠的平流层入侵、中纬度约5–10 ppb；由甲烷制造并从自由对流层输送下来的臭氧；半球污染羽流）、在NOx与城市/VOC源下风向以数小时到数天建起的10–40 ppb**区域增量**、以及交通站点和火灾羽流的**本地峰值**。因为引擎是非线性的，同样1 ppb的NOx在VOC丰富的城市制造臭氧、却在城市核心区销毁它（滴定、NO₃–N₂O₅夜间化学）——这就是为什么臭氧图在最热的钟点是其他所有污染物图的反形、为什么出现"周末效应"、以及为什么臭氧标准的达标与否**取决于气象不亚于排放**：停滞的32°C微风午后是设计工况，而设计值——美国惯例里的全年第四高8小时均值、2015年标准下的70 ppb——作为气候的统计量不亚于化学的。要记住的换算：1 ppb臭氧 = 2 µg m⁻³，所以标准是140 µg m⁻³，而2021年世卫组织准则（100 µg m⁻³，8小时）约50 ppb——一个2000年之前的洛杉矶会称之为干净的水平。
:::

::: example 从ppb到微克 {#ex-ppb-conversion}
把美国2015年臭氧标准（70 ppb，8小时均值）表示为µg m⁻³，把世卫2021准则（100 µg m⁻³）表示为ppb。
::: solution
在25°C、1 atm下，1 ppb O₃ = 2 µg m⁻³，所以70 ppb = **140 µg m⁻³**；100 µg m⁻³ = **50 ppb**。这道题要紧，因为每个健康指数、每个传感器读数、每个印度和中国的空气质量指数都用µg m⁻³，而大气化学文献用ppb——也因为世卫50 ppb的准则坐在许多污染地区典型背景的**下方**，意味着对三分之一的人类来说，达到准则不仅需要本地清洁的空气，还需要一个更干净的半球。
:::
:::

## 肺、森林、面包

::: definition 伤害：气孔通量、产量、碳、健康 {#def-ozone-damage}
臭氧没有绕开其化学的排放控制，也没有逃开其氧化的受体：它在它触碰的每个表面上被销毁，而伤害就是这场销毁。在肺里，它与衬液反应，引发炎症、肺功能下降和哮喘发作——流行病学把全球每年约**40万例过早死亡**归给地表臭氧，对儿童肺发育和户外工作者的效应显著。在植物里，通路是气孔处的同一反应：臭氧为气体交换而入，死在细胞壁上，而植物**用碳来修**——从生长和籽粒挪走的光合产物，表现为烟草和菠菜叶上的点刻（最早揭示伤害的生物指示物），以及在面田（开放空气增氧）实验里不可见的**每10 ppb生长季臭氧使小麦和大豆减产5–10%**——该领域的金标准。森林付两次账：生长下降，而且因为臭氧伤害碳汇本身，在高臭氧区域**森林碳吸收被砍7%以上**——一个削弱气候系统所指望的陆地汇的反馈。农学家把剂量指数化为**A40**（白天高于40 ppb的小时数之和）和**W126**（加权累积吸收），后者更受青睐，因为它加权气孔通量——植物实际的剂量——而非空气的浓度。政策的推论是：臭氧是唯一一个控制它同时付**三重红利**的污染物：现在的健康、现在的产量、以及辐射强迫，因为臭氧本身就是温室气体，全球平均强迫近**0.4 W m⁻²**——少数几个在同一部法规里既给气候降温、又保住面包和肺的减排目标。
:::

::: example 更热的天空的产量代价 {#ex-yield}
某小麦区生长季臭氧从45升到61 ppb；面田实验给出A40尺度上每10 ppb约6%的产量损失。求产量损失比例，以及一亿吨区域作物损失的谷物。
::: solution
升幅为16 ppb，所以损失为$0.06\times1.6 = 9.6\%$——约**10%**，即**1000万吨**，是多数国家年谷物出口的几倍。这个算术就是为什么2010年代的臭氧-气候谈判开始把甲烷（背景的主变量）当作一项**农业政策**：削减20%的甲烷在所有地方买到几个ppb的背景，而几个ppb就是世界面包的几个百分点。
:::
:::

## 夜晚的另一套化学

::: definition 夜间臭氧损耗与N₂O₅关联 {#def-night-ozone}
日落时光化学工厂关门，化学却不关门：NO₂与残存的臭氧反应生成**NO₃**（$k = 1.2\times10^{-12}\ \mathrm{cm^{3}\,s^{-1}}$，在污染空气中寿命几分钟），NO₃在日光下光解——这就是它是夜晚氧化剂的原因——而NO₃与N₂O₅平衡（$\mathrm{NO_3 + NO_2 \rightleftharpoons N_2O_5}$），这个储库的非均相命运决定该区域的氮收支。N₂O₅在气溶胶上水解（$\mathrm{N₂O₅ + H₂O \rightarrow 2\,HNO₃}$）是**夜间硝酸气溶胶工厂**——华北平原和波河谷地冬季霾里的硝酸根——也是NOx以颗粒而非酸气形式离开大气的机制；而在新海盐上竞争的吸收释放ClNO₂（氯化硝基酰），它在黎明光解成氯原子，在OH引擎启动前一小时引爆清晨的氧化。夜晚还在NO高的地方**移除臭氧**（滴定，城市凌晨3点核心区臭氧稀少的原因），并在NO低的地方**重新分配**它：夜间对芳烃和异戊二烯的NO₃氧化制造有机硝酸酯，它们在早晨把NOx吐回来——这场"慢燃"让一座城市的白天臭氧取决于昨天下午的排放。给政策头脑的教训：臭氧化学不会在监测器失去信息量时停止——夜晚是硝酸气溶胶、氯、以及次日大部分NOx被制造的地方，也是臭氧和PM2.5必须作为一个耦合系统来监管的原因。
:::

::: example 夜间硝酸工厂 {#ex-nightrate}
一次冬季霾事件维持$[\mathrm{O_3}] = 20\ \mathrm{ppb}$、$[\mathrm{NO_2}] = 60\ \mathrm{ppb}$，气溶胶给出N₂O₅吸收系数$\gamma = 0.02$、表面积浓度$300\ \mathrm{\mu m^{2}\,cm^{-3}}$。估算N₂O₅对抗水解的寿命（空气270 K，平均分子速率$2.3\times10^{4}\ \mathrm{cm\,s^{-1}}$），并说明它对10小时夜晚的意味。
::: solution
伪一级损耗为$k = \gamma\,\overline{c}\,A/4 = 0.02\times2.3\times10^{4}\times3\times10^{-6}/4 = 3.5\times10^{-4}\ \mathrm{s^{-1}}$，即**约50分钟的寿命**——夜晚的十二分之一，所以气溶胶把NOx池处理了许多遍，绝大部分硝酸霾在黄昏到黎明之间制成，与观测完全一致。这道题就是中国硝酸根霾为何对**单靠**SO₂或NOx削减**都不**响应的原因：硝酸工厂靠夜晚运转、靠气溶胶面积、靠只在臭氧与NOx共存时才存在的N₂O₅——一门有讽刺感的化学。
:::
:::

## 趋势：清洁的西、污染的东，与火

::: definition 输赢的地理 {#def-ozone-trends}
全球地表臭氧记录（GAW/EMEP/CAMS网、美国EPA的AQS档案、以及不断增长的低成本传感器层）讲一个半球分异的故事。**美国和欧洲**：尽管背景持平或上升，夏季设计值在2000–2015年间以每年约1–2%下降——随着NOx下降40–50%、活性VOC控制生效，光化学增量塌缩，而"清洁空气的功劳"是美国《清洁空气法》血统最大的公共卫生成功。**南亚与东亚**：镜像——华北平原在2010年代靠NOx翻倍以每年1–2 ppb增长，恒河平原如今显示世界上最快的增长和最高的部分设计值，而2013年后东亚的减排减缓了上升、却**暴露出背景问题**：区域增量被修剪后，剩下的就是半球基线（甲烷驱动、野火点缀），而它在所有地方缓慢上升（偏远记录里每十年+0.2–0.5 ppb）。**洲际输送**让分异变成共享的账本：另一大洲NOx每变10%，某区域背景约变1 ppb，所以美国的标准如今背着几个ppb的亚洲和野火化学，而欧洲的背着非洲和北美的——这就是臭氧是第一个其管理团队必须成为**名为管理的半球条约**的主要污染物。**野火烟雾**是2020年代暴烈的新项：火积雨云把NOx和CO注入上对流层、羽流在下风向几天里添加几十个ppb（2020年北美西部和2019–20年澳大利亚的事件超过了所有传感器的记录），以及一个把臭氧问题与火灾问题耦合的反馈——烟雾臭氧如今在本地排放为零的日子里，让数百万人头顶的臭氧超过**健康**标准。而**甲烷**是基线的主变量：按每100 ppb甲烷约1 ppb背景臭氧，全球甲烷承诺的30%削减，用臭氧的话说，是对未来每个标准中最难触及部分的1–2 ppb全球折扣——"空气质量、气候与农业政策是一个主题的三顶帽子"当前最清晰的例证。
:::

::: example 达标算术 {#ex-attainment}
某城市设计值为82 ppb：背景42、区域增量40。标准为70 ppb。若本地NOx和VOC控制能把区域增量削减25%，求新设计值和残余缺口。
::: solution
新增量$= 40\times0.75 = 30$，设计值$= 42 + 30 = 72$ ppb——一个本地控制无法弥合的**2 ppb残余缺口**，因为背景不是本地的。这道题把2020年代的空气质量故事写成两行：许多少地区的可达未来是"背景加上化学允许的最小增量"，而最后几个ppb仅存的调控只剩半球性的——甲烷与洲际协定，或者没有。
:::
:::

::: warning "高处好、低处坏"作为口号并不成立，而臭氧的控制并非没有副作用
五个错误。**"平流层修复能治对流层臭氧"**：两个储库交换缓慢（一年的管道、每年几个百分点），而蒙特利尔的臭氧恢复**减少**了平流层氯对……对流层里任何东西的销毁——耦合很弱且主要是辐射的；对流层臭氧是一个光化学问题，句号。**"削NOx总是削臭氧"**：在VOC限制的核心区它会升高（周末效应、北京冬季悖论），而在夜间它恢复NO₃氧化和硝酸气溶胶——臭氧下降之际，颗粒物红利对能见度和PM2.5甚至可能为负；臭氧-PM2.5权衡是当代监管里最难的优化。**"传感器证明清洁空气"**：电化学臭氧传感器会漂移、受湿度偏置，其认证与参考级紫外光度法相去甚远——低成本层是漂亮的事件探测器、糟糕的合规仪器。**"野火臭氧是暂时的，所以不算数"**：事件是天，森林季的**气孔剂量**是累积的，而单次火积雨云事件能向对流层上层注入超过一个大洲一个月地表排放的NOx，每分子产臭氧一周而非一天。**而"臭氧-温度相关证明气候变化在制造臭氧"**：相关主要是气象（停滞、高温、生物源VOC、以及困住排放的同一股小风）；气候信号真实但更小——背景、甲烷、异戊二烯和火——而把它们分开需要恒定气象下的趋势方法，评估文献为此已投入二十年。
:::

::: history
**亨利·安托万·德福**1905年为伦敦的煤雾造了"smog"一词；杀手级的煤烟雾——**宾夕法尼亚州多诺拉（1948）**、**伦敦（1952）**——是硫和颗粒物的事，而它们的清理（英国1956年《清洁空气法》）是第一部现代空气质量法。光化学时代始于1940年代的洛杉矶事件——橡胶开裂、果园点刻、眼睛灼痛，城市起诉了一片它说不出名字的工业景观——并在十年后由**阿里·豪根-斯米特**破译，他认定了臭氧和PAN，并证明阳光下的汽车碳氢化合物加NOx就是工厂；这座工厂的化学核心、莱顿循环，来自火箭化学家**莫里斯·莱顿**，他1961年的著作把过氧乙酰硝酸酯命名为NOx隐形运输形式的角色。全球时代是**GAW**基线网（1970年代–）、美国EPA的AQS档案、让甲烷-臭氧政策明朗化的**STAOCP**评估，以及凭流行病学之力把8小时限值减半的2021年世卫准则修订——一条如今正以50 ppb之水，对照人类化学已从工业化前约10 ppb抬到30–40的全球背景来解读的准则。
:::

::: quiz
某城市在其密集核心区削减NOx排放40%。那里**峰值**夏季臭氧最可能的一阶效应是：
- [ ] 如时钟般下降40%。
- [x] 变化不大或上升，因为核心区是VOC限制的、而滴定被移除。
- [ ] 没有效应，因为臭氧是平流层的。
- [ ] 立即降到背景。
::: solution
在VOC限制的核心区，NOx对臭氧的销毁（滴定和NO₂汇）部分掩盖了生成；削减NOx可能**抬高**臭氧，除非VOC化学同步削减——周末效应与北京冬季悖论。NOx限制的远郊则见臭氧下降。非线性是臭氧控制的第一课。
:::
:::

::: summary
对流层臭氧由阳光在天空中从NOx和VOC装配而成——一种背景20–40 ppb（平流层入侵、甲烷化学、半球输送）、区域增量在城市下风向建立、设计值一半化学一半气象的二次污染物。它的伤害是同一个氧化反应在许多界面上：每年约40万例过早死亡、每10 ppb减产5–10%、受损的森林碳汇、以及0.4 W m⁻²的温室强迫——控制它就能同时给气候降温、保住收成和肺的罕见污染物。趋势分异：清洁西方下降的设计值、工业化东方上升的基线和新的极值、让每个地区的空气成为一项条约的洲际输送、以及在零排放日子里写下新记录的野火烟雾。甲烷是基线的主变量，而全球甲烷承诺在臭氧的账本里，是以削减一种我们本有理由削减的气体为代价的收成政策、健康政策和气候政策。臭氧是我们没有排放的污染物——也是我们无法独自控制它的证明。
:::

$42 + 30 = 72$；缺口$= 2$ ppb——本地政策够不着，只有半球基线管理够得着。
:::

::: exercise {level=3 check="2"}
在NOx丰富的农村地区，臭氧-温度弹性在热天为每°C +1 ppb。求热天增暖+2°C时到2100年的臭氧变化。
::: solution
$1\times2 = 2$ ppb——每度虽小、总量却大：在一个世纪的增暖里，相当于从世卫准则到美国现行标准距离的五分之一，还在甲烷更慢的抬升之上。（在VOC限制的城市核心区符号会翻转——增暖加速夜间NO₃损耗和滴定——这就是为什么评估按区域模拟该反馈而非外推。）

::: exercise {level=3 check="7"}
一次火积雨云事件把NOx注入上对流层，其寿命约7天而非边界层的约1天。若每个NOx分子的臭氧生成与寿命成正比，求该事件每分子臭氧生成超过地表排放的倍数。
::: solution
倍数就是寿命比，$7/1 = 7$——这就是为什么火烟雾、被注入边界层的雨和夜间化学之上，比同样在地表释放的NOx高效得多地制造臭氧，也是为什么特大火灾季出现在偏远背景记录里。
:::
