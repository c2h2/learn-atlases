屏住呼吸算一笔账：半升空气约含$10^{22}$个分子——大致等于可观测宇宙里的恒星数——而其中只有约$2\times10^{16}$个是二氧化碳、几十万个甲烷、几十亿个臭氧，却是宜居行星与荒芜行星之间的区别。大气化学的故事就是这些少数的故事：一个百万分之一的气体如何扛起与四百倍浓度的气体同样多的温室强迫；天空的自我清洁洗涤剂——一个寿命一秒、每立方厘米只有几个分子的自由基——如何决定甲烷和污染物能活多久；以及"大气是一座**化学反应器**不是气体博物馆"这一发现，如何从拉瓦锡的天平一路走到臭氧洞才终于站稳。本课的每个数字都离一场政策辩论只有一个停留时间计算的距离，因为在大气化学里，丰度从来不过是源与汇的商。

## 空气的配方

::: definition 成分与大气质量 {#def-composition}
干空气按体积含$78.08\%$的$\mathrm{N_2}$、$20.95\%$的$\mathrm{O_2}$、$0.93\%$的Ar和$0.06\%$的$\mathrm{CO_2}$——连同那些要紧的少数：$\mathrm{N_2O}$在$336$ ppb、甲烷在$1920$ ppb、臭氧地表$10$–$50$ ppb而平流层多得多、氯氟烃在几十到几百个**万亿**分之一。整包重$5.15\times10^{18}\ \mathrm{kg}$——每$\mathrm{m^{2}}$柱$P/g = 10{,}330\ \mathrm{kg}$，平均摩尔质量$28.97\ \mathrm{g\,mol^{-1}}$（由氮氧配比设定，可由天平和重力仪各自独立测到四位有效数字，是物理学最利落的相互印证之一），以及垂直标高$H = RT/Mg \approx 8.5\ \mathrm{km}$——使地表附近每升高一公里气压降为$1/e$。这些数字里有两个带着起源的指纹：氩是**放射成因**的（岩石中$^{40}\mathrm{K}$衰变的$^{40}\mathrm{Ar}$，这就是大气的氩重而太阳的氩轻的原因），而氧是**生物**的——游离$\mathrm{O_2}$是光合作用顶着地质学对还原剂的渴求维持的系统状态，而24亿年前它的上升是地球史上最大的污染事件（[[earth-history/oxygen-proterozoic]]）。被排除在"干空气"之外的水汽是可变成分——$0$到$4\%$、停留9天——它不在清单上是记账惯例，不是无足轻重的声明。
:::

::: example 痕量气体的质量 {#ex-tracemass}
求$420$ ppm时大气$\mathrm{CO_2}$的质量，以及$1920$ ppb时甲烷的质量。（空气总摩尔数：$1.78\times10^{20}\ \mathrm{mol}$。）
::: solution
$\mathrm{CO_2}$摩尔数$= 420\times10^{-6}\times1.78\times10^{20} = 7.5\times10^{16}\ \mathrm{mol}$，质量$7.5\times10^{16}\times44 = 3.3\times10^{18}\ \mathrm{g} = 3300\ \mathrm{Gt\,CO_2}$——熟悉的$890\ \mathrm{GtC}$换了件裙子。甲烷：$1.92\times10^{-6}\times1.78\times10^{20}\times16\ \mathrm{g} = 5.5\times10^{15}\ \mathrm{g} = 5500\ \mathrm{Tg}$，约为二氧化碳质量的**二十分之一**，但逐分子计，其百年抓握力是后者的八十倍。混合比与质量之间的换算——摩尔分数乘总摩尔数再乘分子量——是每个大气化学家下意识都在做的计算，因为源和汇以吨报价，而空气只报告比值。
:::
:::

::: widget plot
f: 1013*exp(-x/8.5)
x: 0, 30
y: 0, 1050
labels: p\ (\mathrm{hPa})
caption: 具有$8.5$ km标高的等温大气的压强随高度曲线——这条指数线把空气百分之九十的质量禁在对流层的下三分之一，让平流层的化学按地表标准近乎真空的环境中发生。同一条指数线，解释了为什么山顶天文台（冒纳罗亚在对流层一半质量之上）采到更干净、需要订正的分子更少的空气，也解释了为什么臭氧层——在气压55 hPa的20 km——把它的最大**浓度**保持在密度只有地表五十分之一的空气里。
:::

## 停留时间：丰度是一个商

::: proposition $\tau = M/F$与寿命的含义 {#prop-residence}
对任何痕量气体，**停留（或寿命）时间**$\tau = M/F$——库存除以总通量——是大气最有解释力的单一数字。二氧化碳对其巨大交换通量的总停留时间约4年；甲烷对羟基自由基OH氧化的为9年；氧化亚氮对平流层光解和土壤吸收的为120年；CFC-11对臭氧层紫外光解的为45年；二氧化硫对氧化和降雨的为**天**。三个推论组织着本领域。**充分混合对短命**：$\tau$超过一年的气体全球混合、属于整个大气（CO₂、N₂O、CH₄——京都的长寿者），而短命物种（几天到几周：臭氧、气溶胶、SO₂、DMS）是区域的、不均匀的，其影响**就在制造地**。**GWP等级**：一个气体的百年全球增温潜势按其辐射效率和寿命缩放——甲烷的28、氧化亚氮的265、CFC-12的10 200——这就是为什么一个被设计成化学**惰性**的分子（CFC作为制冷剂的德行）原来是气候罪行：惰性意味着平流层是唯一的汇，而平流层正是臭氧居住的地方。**还有政策的不对称**：削减短命物种**快地**改变气候（2020年代的黑碳和甲烷战略，以十年排放的代价买到几十年的冷却），而CO₂——其扰动寿命因海洋缓冲的抗拒而是几个世纪——需要**净零**，不只是少排。停留时间表实际上就是气候政策的元素周期表。
:::

::: example 甲烷的账本 {#ex-ch4ledger}
甲烷负荷为$5500\ \mathrm{Tg}$、其汇合计$580\ \mathrm{Tg\,yr^{-1}}$（OH氧化$510$、土壤$30$、平流层$15$、海洋边界层氯$25$）。求寿命；若排放升到$620\ \mathrm{Tg\,yr^{-1}}$并停在那里，求随之而来的负荷。
::: solution
$\tau = 5500/580 = 9.5$ 年。在$620\ \mathrm{Tg\,yr^{-1}}$的排放下，新的稳态负荷为$620\times9.5 = 5900\ \mathrm{Tg}$——但趋近是以同样9.5年为时间常数的指数过程，所以**大部分**调整在三个十年内完成。这就是甲烷的双重人格：CO₂之后的第二大温室强迫，同时是气候系统里**最快的杠杆**——今天减半排放会在2050年代把负荷带回2020年前值附近，任何千年以内的CO₂政策都给不出这样的转身。
:::
:::

## 少数物种及其源

::: definition 谁制造了什么 {#def-sources}
痕量气体收支是一张生物学、地质学与工业的地图。**甲烷**：湿地（最大的自然源，约每年$150\ \mathrm{Tg}$，也是随温暖增长的那个）、水稻与反刍动物、化石泄漏与填埋场——其同位素（$^{13}\mathrm{C}$）与乙烷的协同测量如今把最近的增长决定性地分给**生物源**，一个有饮食与农业含义的发现。**氧化亚氮**：微生物硝化与反硝化，被氮肥翻倍——化肥时代赠给气候的第二份礼（第一份是活性氮本身，[[biogeochemistry/nitrogen]]）。**一氧化碳**：不完全燃烧以及甲烷和异戊二烯的大气氧化——这就是一氧化碳这个污染标记物为何在火灾季节高悬于火灾大陆之上。**二氧化硫**：火山、船用燃料油、煤，以及海洋的**DMS**——播撒云凝结核的浮游植物硫，在**CLAW假说**（沙尔林、洛夫洛克、安德烈亚、沃伦，1987）里把海洋肥力与地球反照率耦合起来（一个强度仍有争议、存在已无争议的反馈）。森林的**异戊二烯与萜烯**：每年$10^{15}\ \mathrm{g}$碳氢化合物，制造大陆二次有机气溶胶的份额，并与NOx一起制造乡村臭氧。**海盐、沙尘、黑碳**：寿命几天的气溶胶前体。还有**工业品**：CFC、HFC、SF₆（寿命3200年、GWP 23 500——大规模生产过的最长寿温室气体）以及"永久"的PFAS，其大气分支如今是一笔测得的通量。清单的纪律——自下而上的排放因子对自上而下由观测网络反演的通量——是这些数字真正被制造的地方，也是分歧（湿地敏感度、化石泄漏率、亚洲NOx）变成文献论战的地方。
:::

::: example 多布森单位与柱 {#ex-dobson}
总臭氧以多布森单位（DU）报告：$1\ \mathrm{DU} = 2.69\times10^{16}$个每$\mathrm{cm^{2}}$垂直柱的分子。求正常$300\ \mathrm{DU}$的柱，以及**地表条件下的等效厚度**（$2.7\times10^{19}$个分子$\mathrm{cm^{-3}}$）——多布森发明这个单位就是围着这个数字转的。
::: solution
柱$= 300\times2.69\times10^{16} = 8.1\times10^{18}$个分子$\mathrm{cm^{-2}}$。按地表密度摊开，这层厚$8.1\times10^{18}/2.7\times10^{19} = 0.30\ \mathrm{cm}$——**三毫米**，就是对抗生物致死剂量的紫外的整面行星盾牌，比一枚硬币薄，却比撒哈拉所有的矿都值钱。这道题把平流层化学的全部教训装进了一次除法：重要的气体都很薄，而薄的东西会破——1985年的哈利湾上空发生的就是这件事（[[atmospheric-chemistry/stratospheric-ozone]]）。
:::
:::

## 测量混合物

::: definition 从多布森的电池组到反演 {#def-measuring}
大气化学是一门发明了自己仪器的观测科学。**G·M·B·多布森**在1920年代造出便携分光光度计、带着它们走遍世界，留下了卫星之前任何大气化学成分唯一的全球记录——臭氧柱，直到今天仍在他最初的十几个站上测量。**本生与基尔霍夫**的光谱学（1859）长成了差分光学吸收（DOAS、MAX-DOAS）网络，从散射阳光里读出NO₂、SO₂、HCHO和O₄，并飞上卫星（TROPOMI的全球NO₂日图，2020年实时显示了武汉封城）。**查尔斯·大卫·基林**的手动CO₂计划（1958–）确立了连续的烧瓶-塔台纪律，如今由全球烧瓶网络和ICOS/NOAA塔台扩展到甲烷、CO、O₂与同位素；**反演模拟**——用输送模型拟合观测浓度来估计地表通量的自上而下方法，了结了"甲烷是生物源"问题——是本学科的标志性综合，而其2010年代的继任者是**来自空间的高分辨率反演**：TROPOMI和GHGSat/Carbon Mapper星座如今能发现并量化单个甲烷超级排放者，把一场全球收支辩论变成一串地址清单。给每门测量小东西的科学的学生的一句话：多布森和基林造出的仪器活得比建造它们所要检验的理论更久，而本学科最大的争论（臭氧趋势、2000–2006的甲烷增长停滞与2007–的重启）不是被更好的模型、而是被**更长的记录**了结的。
:::

::: example 来自空间的柱 {#ex-tropomi}
一个类TROPOMI仪器在一座$2000\ \mathrm{km^{2}}$的城市上空测得对流层$\mathrm{NO_2}$柱$2\times10^{15}$个分子$\mathrm{cm^{-2}}$，空气对抗移除的寿命为$6$小时。估算该城的$\mathrm{NO_x}$排放率（$\mathrm{mol\,day^{-1}}$）及每年氮的吨数。
::: solution
稳态下，排放=库存$/\tau$。柱是按平方厘米计的，所以城市上空的库存为$2\times10^{15}\times2\times10^{12} = 4\times10^{27}$个分子（面积$2000\ \mathrm{km^{2}} = 2\times10^{12}\ \mathrm{cm^{2}}$），而$\tau = 6\ \mathrm{h}$时日排放为$4\times10^{27}/0.25 = 1.6\times10^{28}$个分子$= 2.7\times10^{4}\ \mathrm{mol\,day^{-1}}$，即
$$
2.7\times10^{4}\times14\ \mathrm{g} = 370\ \mathrm{kg\,N\,day^{-1}} \approx 140\ \mathrm{t\,N\,yr^{-1}},
$$
正好落在大城市实测$\mathrm{NO_x}$清单的范围之内。这道题就是真正的方法：卫星反演是**稳态记账**，而每一项——柱（云和气溶胶把它压向偏低）、寿命（夏季光化学6小时、冬季数天）、稳态假设（周末的下凹就违反它）——都自带一篇论文的不确定度，这就是为什么业务化排放产品标出的误差棒和中心值一样宽。
:::
:::

::: warning ppm不是重量，寿命不是命运，而大气的账本不会碰巧配平
五个错误。**"400 ppm听起来很小，所以不可能要紧"**：ppm是**摩尔比**，而10 330 kg柱的420 ppm是3300 Gt某种气体，其红外波段恰好落在地球发射的波长上——比值而非重量才是大气的自然单位，而换算只隔一次乘法。**"寿命短就没事"**：短命物种是空气的**本地**杀手（臭氧事件、PM2.5），而就雪面黑碳和甲烷而言，还是北极增暖最快的杠杆之列——寿命设定扰动作用的**地点**与**快慢**，不设定它是否作用。**"自然源意味着该怪自然"**：湿地的甲烷是真的而且在增长，但工业化前的负荷稳定了一万八千年；1800年以来的翻倍需要一个**净**源的增加，而同位素和δ¹³C数据把它安在化石与生物两个部门——自然循环是放大，不是发起。**"大气自我清洁，所以排放没事"**：OH有容量上限——CO和甲烷与它竞争，所以抬高它们会**延长它们自己的寿命**（1990年代以来测到的正反馈），而来自十年间被禁CFC生产的氯将活得比每一项禁令都久。**而"收支配平"是一个结果，不是默认值**：化石燃料CO₂收支之所以配平，只是因为大气中的二氧化碳分数被大气测量**钉住**、而残差吸收了其他所有项的误差——而当残差出现趋势（1990年代和2010年代就是这样），汇在变化，账本必须重开。
:::

::: history
空气的发现是一个气体的世纪：**丹尼尔·卢瑟福**分离出氮（1772），**约瑟夫·普里斯特利**和**卡尔·威廉·舍勒**分离出氧（1772–74），**亨利·卡文迪许**分离出氢，而关键在于他证明"燃素空气"里有百分之五的某种无法交代的东西——通往氩的线索。**瑞利勋爵和威廉·拉姆齐**靠化学氮与大气氮密度的差异发现了氩（1894），是科学史上最伟大的偶然之一；理论光化学始于**G·M·B·多布森**的臭氧分光光度法（1920年代）和**西德尼·查普曼**的臭氧循环机制（1930），而**本生与基尔霍夫**的光谱学（1859）是每台DOAS和卫星探测仪的祖先。**查尔斯·大卫·基林**的连续CO₂记录（1958–）与**拉尔夫·基林**的氧扩展、**全球大气监测**烧瓶网（WMO）、**总臭氧制图光谱仪**（1978–）和**IPCC/UNEP**评估周期完成了观测的大厦；**蒙特利尔议定书**（1987）仍是那部唯一从轨道上测量了自己成功的条约。
:::

::: summary
- 干空气是N₂+O₂+Ar+CO₂，加上ppb–ppt级、却扛起不成比例的气候与化学的少数；整柱重10 330 kg m⁻²，标高8.5 km。
- 停留时间τ = M/F组织一切：4年（CO₂总量）、9（CH₄）、120（N₂O）、45（CFC-11）、几天（SO₂、臭氧）——它设定GWP等级以及快杠杆与慢杠杆之间的政策不对称。
- 源是生物、地质与工业的；同位素与共测物种数据做分配，自上而下的反演审计自下而上的清单。
- 臭氧柱按地表密度只有三毫米厚——整面UV盾牌——这就是薄东西会破的原因。
- 本学科由仪器牵引：多布森的电池组、基林的烧瓶、TROPOMI的像元；了结争论的是长记录，不是聪明的模型。
- 是比值不是重量；寿命是何处与何时、不是是否；而收支的配平是测得的结果，从来不是假设。
:::

::: exercise 甲烷寿命 {level=2 check="9.5"}
负荷$5700\ \mathrm{Tg}$、总汇$600\ \mathrm{Tg\,yr^{-1}}$。求寿命（年，一位小数）。
::: solution
$\tau = 5700/600 = 9.5$ 年。注意这个数字**不是**什么：不是排放停止起作用的时间（负荷按指数调整，三个寿命内完成95%），也不是常数（OH随气候变化，而模型们争论变暖大气的OH是否升得足以让甲烷寿命保持稳定——大气洗涤剂的强度本身是个气候问题的罕见案例）。
:::

::: exercise 多布森柱 {level=2 check="8.1"}
求$300\ \mathrm{DU}$的臭氧柱（分子$\mathrm{cm^{-2}}$，以$\times10^{18}$计，一位小数；填系数）。
::: solution
$300\times2.69\times10^{16} = 8.1\times10^{18}$个分子$\mathrm{cm^{-2}}$。每份卫星臭氧产品都是这个乘法的逆运算，而1985年揭示臭氧洞的异常——哈利湾上空110 DU的春季柱——就是这个数字在十年里跌掉了三分之二。
:::

::: exercise 标高 {level=2 check="8.5"}
求$288\ \mathrm{K}$时空气的压标高（$M = 0.02897\ \mathrm{kg\,mol^{-1}}$、$g = 9.81$，km，一位小数）。
::: solution
$H = RT/Mg = 8.314\times288/(0.02897\times9.81) = 8.5\ \mathrm{km}$。这个数字解释了为什么对流层顶（约在$2H$）罩住大部分污染，为什么臭氧层坐在UV光解与输送相平衡之处而非空气稠密之处，以及为什么客机舱压在约$2.4$ km——哪怕飞机飞在$3H$。
:::

::: exercise 珠峰气压 {level=3 check="360"}
用$p = p_0\,e^{-z/H}$、$H = 8.5\ \mathrm{km}$，求珠峰顶（$8.85\ \mathrm{km}$）的气压（hPa，取整到十位）。（填数字。）
::: solution
$p = 1013\times e^{-1.04} = 1013\times0.354 = 359\ \mathrm{hPa}$，约$360$——海平面的三分之一，因此$8\ \mathrm{km}$之上"死亡地带"的由来，其氧分压已无法长期维持意识。真实大气的标高随温度增大，这就是为什么同样的高度在（对流层顶高达17 km的）温暖热带上空比在寒冷极地上空缺氧得轻一些。
:::

::: exercise 最长命的气体 {level=3 check="23500"}
SF₆寿命$3200$年、百年GWP为$23{,}500$。求其100年内每吨相对CO₂的GWP加权强迫，并解释为什么它微小的负荷（约$25{,}000\ \mathrm{t}$）仍让它在每份排放清单里占一行监测。（填GWP。）
::: solution
GWP**就是**百年强迫比：每吨为CO₂的$23{,}500$倍。负荷仅$25{,}000\ \mathrm{t}$时其总强迫很小（$25{,}000\times23{,}500/10^{6} \approx 0.6\ \mathrm{GtCO_2e}$），但其寿命意味着每吨排放都在人类时间尺度上是永久的，而其增长**永远累加**——"按GWP的政策和按寿命的政策是两种政策"的教科书案例，以及一个分子可以同时质量上微不足道、后果上无边无际。
:::
