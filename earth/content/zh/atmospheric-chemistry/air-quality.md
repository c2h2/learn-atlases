1952年12月5日，一股冷高压盘踞伦敦上空，城市的煤火生出升不上去的烟，四天之内"雾汤"把能见度降到几英尺、取消了肯普顿的德比大赛、装满了停尸房——而正如流行病学家半个世纪后所确立的，在那个冬天正常死亡人数之外又杀死了**一万以上**的人。四年后的《清洁空气法》是世界上第一次认真管制一座城市呼吸什么的尝试；美国1970年《清洁空气法》和环保局的成立把空气质量法变成一门由标准、监测网和成本收益分析组成的科学；2013年，看着自己的城市在直播电视上达到危险级AQI，中华人民共和国宣布了一场"污染保卫战"，其监测与执法机器此后十年把全国PM2.5砍掉约40%——本世纪任何国家取得的最快的公共健康改善。介于这两个极点之间的，就是空气质量科学的主题：AQI数字与传感器圆点的日常界面、把微克换算成生命的暴露-反应曲线、仍是世界最致命"电器"的炉灶，以及气候变化正在重开我们以为已经结案的案子的前沿——烟霾、花粉，以及先服从温度后服从政策的臭氧。

## 测量人们在呼吸什么

::: definition 污染物、监测仪、传感器、卫星 {#def-aqi-system}
受管制的"标准"空气污染物是一份短名单配着长历史：**PM2.5与PM10**（可吸入颗粒物的质量浓度，由参考方法测量——滤膜称重、锥形元件振荡微天平、带湿度控制的光散射——在美国CSN/IMPROVE和中国2000站国家控制网这类网络上）、**臭氧**（紫外光度法，整章光化学所悬挂其上的参考）、**NO₂和NOx**（化学发光，以及日益增多的低成本电化学和卫星柱浓度——Tropomi卫星出圈地捕捉到2020年封锁期间工业区上空的NO₂下降）、**SO₂**（荧光法；还有从太空看到的、地球上每一座冶炼厂和煤电厂的壮观的OMI与Tropomi羽流）、**CO**，以及四乙基铅的遗产。**空气质量指数**按最坏单一污染物的分段线性断点把这堆化学压缩成一个每日数字：美国AQI 0–50优、51–100良、101–150"对敏感人群不健康"、151–290不健康到极不健康、300以上危险；断点锚定在流行病学看到效应的浓度上（PM2.5的AQI 100是35 µg m⁻³ 24小时——是世界卫生组织2021年5 µg m⁻³年均指导值的七倍，这个差距本身就是政策辩论）。2010年代的革命是**低成本传感器**（PurpleAir及其表亲：30美元的激光散射粒子计数器，全世界已有数十万台）和**卫星反演PM2.5**（大气成分分析组的年度全球地图，融合AOD、土地利用回归和化学模型估计处处暴露，是多数全球疾病负担数字背后的数据集）。两者对暴露科学都美妙，对合规都危险：传感器会漂移、对湿度有反应、未校准不可信——长存的教训是**更多测量不能取代参考网络，而是重新分配了对它的需求**，因为每一份公民数据都必须拴在法律据以书写的质量标准上。
:::

::: example 读懂AQI {#ex-aqi}
某城市的一天：PM2.5 = 55 µg m⁻³（24小时），O₃ 8小时最大 = 118 ppb，NO₂ 1小时最大 = 90 ppb。用美国断点（PM2.5 35→100、55.4→150；O₃ 70→100、85→150 ppb；NO₂ 1小时100 ppb→100），求这天的AQI类别。
::: solution
55的PM2.5坐在101–150段的顶部（AQI ≈ 148）；118 ppb的臭氧甚至超过151–200段的底线（AQI ≈ 175）；NO₂中等。发布的AQI取**最大值**：约175，**"不健康"**——教训是一天的AQI由最坏污染物决定、臭氧和颗粒物可以各自独立地把同一天变成危险级，而"敏感人群"分档的存在，是因为哮喘患者、儿童、老人和户外工人最先到达暴露-反应曲线的陡段。
:::
:::

## 负担

::: definition 暴露-反应、死亡、室内空气、正义 {#def-burden}
空气质量科学的定量核心是**暴露-反应函数**：从数百万人的队列研究汇集的流行病学斜率（美国癌症协会与六城市队列及其后续、汇集的ESRI分析，以及不断扩大的非洲和亚洲文献），连接长期PM2.5与缺血性心脏病、卒中、慢阻肺、肺癌和下呼吸道感染死亡——大约每10 µg m⁻³慢性暴露使非意外死亡增加**6–10%**，直到监测网格上最洁净的地方都未检出安全阈值（"超线性"形状——低浓度更陡、高浓度趋平——正是让洁净国家的清洁以生命超比例回报的发现）。把曲线应用于全球暴露得到如今公共健康算术里的标准数字：环境PM2.5造成约**每年400–500万过早死亡**，固体和液体炊事燃料的家庭空气污染再增**200–300万**，合计的空气污染负担——在环境风险中仅次于铅和酒精之前、在所有风险中只排在烟草和高血压之后——**90%落在中低收入国家**。室内那一半是世界最不平等的污染问题：二十多亿人烧柴、粪、木炭或煤油做饭，一间厨房里的暴露相当于住在AQI几百的环境，负担集中在妇女和婴幼儿身上，而解决方案——正在进行的液化气、沼气和电气化炊事转型（印度的Ujjwala计划惠及数千万户；卢旺达的是有记录以来最快的）——是最便宜的大型健康干预之一，附带警告是煤气会漏甲烷、炉灶必须真正取代三石灶才算数。富国内部的分布是**环境正义**文献的主题：高速公路、港口、货运干道和历史遗留的红线政策，把少数族裔和低收入社区放在持续高出几µg m⁻³和几个ppb NO₂的位置——路易斯安那石化沿河的"癌症巷"是其被引用最多的标志——而同样的地理如今出现在预期寿命地图上，使空气质量成为化学、城市规划和伦理共享一个浓度场的领域。
:::

::: example 把微克换算成生命 {#ex-burden-calc}
一个一千万人的都市区把年均PM2.5从30降到20 µg m⁻³。用每10 µg m⁻³死亡增加7%（对数线性），求污染归因死亡的分数下降，若基线非意外死亡率为每千人年8人，求每年挽救的生命。
::: solution
归因分数按$e^{0.007\,\Delta C}$缩放：降10 µg m⁻³把污染相关的超额死亡削减$1-e^{-0.07} \approx 6.7\%$；总死亡为$10^{7}\times0.008 = 80{,}000$/年，其中30→20区间对应的超额约$80{,}000\times(1-1/1.073) \approx 5{,}400$，所以削减大约每年挽救**360条生命**——成本收益机器随后为这个数字定价，这也是一十年稳健政策胜过一个十年戏剧性事件的原因。
:::
:::

## 另一半：室内空气

::: definition 作为暴露舱的厨房 {#def-indoor}
典型的叙事把户外当作"空气"、把室内当作庇护所；暴露科学把比例倒过来——在各种环境下人们绝大部分时间都在室内度过，而在固体燃料世界里，厨房提供了多数人所经历的最大单一污染物暴露。物理是一个源-通风平衡，$C = Q/(\lambda V)$：一盏煤油灯或一个三石灶以每小时数克PM2.5向一间每小时换气一两次房间排放，稳态浓度落在数百到数千µg m⁻³——AQI 500以上，贯穿傍晚的炊事和随后在同一房间的睡眠。污染物鸡尾酒是齐备的（PM、CO、NO₂、苯、超细颗粒，以及——在烟草、熏香或樟脑丸叠加到炉灶之上时——一份受管制的致癌物清单），而受体是偏斜的：妇女和五岁以下儿童，她们的风险（幼儿的下呼吸道感染、成年女性的慢阻肺和肺癌、不良生育结局）定义了家庭负担。干预阶梯按物理排序：**消除**（电力和液化气炊事、区域供热——Ujjwala和卢旺达的案例，附带警告是液化气泄漏增加甲烷、炉灶必须取代而非补充火塘）、**通风**（烟囱、烟罩、厨房分隔——在燃料必须保留之处证据成本比最好的干预），以及死胡同：**改良生物质炉灶**，其十年外场试验表明炉头处的真实削减很少转化为个人暴露的削减，因为暴露由房间、炊事习惯和柴薪湿度决定，而不是炉灶的铭牌——现代暴露科学最有教益的失败，也是世卫组织室内指南用*个人暴露*而非炉灶性能作单位的原因。富国的室内一章不同但不空：氡（肺癌第二病因、在地下室积聚的土壤气体，其分布就是城市脚下花岗岩的一张实地图）、二手烟（以法律将其消除是本时代最大的实测健康收益之一）、煤气灶与NO₂（2022–2023年的美国荟萃估计把煤气灶归因的儿童哮喘放到全球每年数百万例的量级，重燃了一场管制之战），以及节能改造住房的霉菌、VOC和通风欠账——提醒我们"室内空气质量"既是第三世界的问题清单，也是第一世界的。
:::

::: example 煤油灯房间 {#ex-indoor}
一间30 m³的房间（通风1.5 h⁻¹）里点着两盏合计排放1.2 g h⁻¹ PM2.5的煤油灯。求稳态浓度，以及把它压到100 µg m⁻³以下所需的换气次数。
::: solution
$C = Q/(\lambda V) = 1.2/(1.5\times30) = 0.027\ \mathrm{g\,m^{-3}} = 27{,}000\ \mathrm{\mu g\,m^{-3}}$——比目标高三个数量级。要维持$100\ \mu\mathrm{g\,m^{-3}} = 10^{-4}\ \mathrm{g\,m^{-3}}$需要$\lambda = 1.2/(10^{-4}\times30) = 400$ 次换气每小时——在住宅里物理上荒谬：**没有通风策略能修好这样的污染源**，一个除法就写尽了选择消除（电力、液化气、封闭燃烧器）而非稀释的全部理由，也是为什么"打开窗户"对厨房尺度的源算不上公共卫生干预。
:::
:::

## 政策革命及其算术

::: definition 从无烟区到总量交易再到北京蓝 {#def-policy}
空气质量法有三代，每一代都在危机中发明。**第一代——烟害管制**：1952年伦敦之后的英国1956和1968年《清洁空气法》（无烟区、烟囱高度、"无烟"燃料），以及1970年前美国的州法规；它们打击**源的集中**（烧什么，在什么样的逆温碗里）靠的是把天空里的黑色拿走。**第二代——标准与技术强制**：美国1970年《清洁空气法》（国家环境空气质量标准、环保局，以及激进的部分——公民诉讼和州实施计划）、加州CARB的创立和从1975年把三效催化器强制装上汽车的催化剂令、蒙特利尔议定书式的臭氧议定书，以及**酸雨计划**的总量交易（见 [[atmospheric-chemistry/acid-deposition]]）；这一代打击**单源排放因子**，其算术是环境经济学里被引用最多的：环保局自己的评估把《清洁空气法》的货币化收益定在成本的约**30倍**，死亡人数削减占据收益栏的首位。**第三代——综合与跨界**：欧盟的国家排放上限、中国2013–2023年的战役（实时公开监测、大城市采暖燃煤清零、钢铁和电力超低排放改造、北方平原秋季逆温来临时的区域应急响应——全国PM2.5降约40%，北京的冬季雾霾季可测量地变短变浅，微信照片里的"北京蓝"就是实证），德里充满争议且漏洞百出的版本（单双号出行、秸秆焚烧罚款、作为表演的雾塔），以及伦敦的**ULEZ**——对污染车辆的每日拥堵收费把伦敦中心的NOx削减约一半，成为英国争议最大也被模仿最多的城市政策。贯穿性的教训是**柴油门**（2015）：大众的作弊装置把NOx台架测试在真实道路上骗过五到四十倍，揭露了管制管的是*测试*而不是世界，并迫使真实行驶排放（RDE）测试时代到来——而对更深的真相无能为力：交通NO₂、超细颗粒和刹车轮胎磨损仍是最难清除的城市污染物，因为它们活在总量交易从未封顶过的唯一源类别里（百万计的小型移动源）。
:::

::: example 收益成本比 {#ex-bcr}
环保局2011年的回顾把《清洁空气法》1970–2020年的货币化收益定为约30万亿美元、成本约1.5万亿（约20:1，含死亡的中央情形30:1）。若一个六千万人的中等国家考虑一项把PM2.5降4 µg m⁻³的政策包，每个统计生命年取收益3万美元，并按每年2万起空气污染过早死亡、每避免一起计15个生命年估值生命，求收益，以及一个60亿美元的计划是否通过。
::: solution
$2\times10^{4}$ 死亡 $\times$ 15生命年 = $3\times10^{5}$ 生命年，乘以每生命年$\$3\times10^{4}$ = **90亿美元**——计划以1.5:1通过，而这个例子展示了每项空气质量决策的结构：收益是弥散的、统计学的、以生命计的；成本是集中的、即期的、以美元计的——这就是该领域靠成本收益算术运转、而算术不断算出有利于清洁的答案的原因。
:::
:::

::: warning AQI不是健康，"后稀缺"空气不是清洁空气，传感器不是监测站，而气候正在重开案件
五个错误。**"AQI 100意味着安全，99意味着危险"**：指数是建在断点上的传播工具；暴露-反应曲线是平滑的、超线性的、无阈值的——分档是流行病学斜坡上的政策家具，而世卫组织2021年指导值恰恰**低于**多数国家标准，因为标准是可达的、不是无害的。**"我们的空气现在干净了"**：按世卫组织2021年水平（PM2.5年均5 µg m⁻³），地球上几乎没有城市是干净的，而富国的剩余暴露恰好集中在政治权力最稀薄之处——正义文献的要旨不是富国空气有1952年意义上的危险，而是其最后几微克分布不均、且仍能以预期寿命测量。**"30美元传感器网胜过监测站"**：在空间覆盖和暴露科学上胜过，但在一切法律和健效应用上，直到在相应湿度状态下用参考仪器校准之前都是输的——成熟的模式是混合网络，参考站把越来越多的时间用于审计人群。**"野火烟霾是新的吸烟"**：它是严重且增长的暴露（数千万美国人如今某些天呼吸危险级空气，烟霾PM按每微克计可以说比城市PM更毒——流行病学尚在争论），但这种框架淡化了仍占主导的源（交通、供暖、工业和炊事的燃烧，加上全球的家庭空气），并让气候驱动因子的排放者躲开了烟霾PM与他们共享的政策追责。**而"空气质量在富国是已解决的问题"**：路侧的NO₂、超细和非尾气交通颗粒、臭氧的气象报复（在美国西部，每一热浪和火灾添加的ppb快过十年NOx削减移走的），以及CO₂施肥、生长季变暖下拉长的花粉-过敏负荷，都说明已结案的章节只在教科书里结案了。
:::

::: history
本领域的起源故事是灾难与流行病学：**多诺拉**（1948）和**伦敦大烟雾**（1952）催生了最早的清洁空气法，而**多诺拉追踪研究**（1948–51，美国公共卫生局的移动实验室）发明了事件归因科学。监管革命经由英国**清洁空气法**（1956、1968）、加州机动车控制委员会（1960）和**机动车空气污染控制法**（1965）、含NAAQS、环保局和公民诉讼的**美国1970年清洁空气法**、**1990年修正案**（酸雨篇的总量交易、117种有害空气污染物、再配方汽油），以及欧盟 历次的大型燃烧装置和国家排放上限指令。测量谱系从滤膜称重和美国**国家空气监测战略**，到IMPROVE能见度网（1999）、Aeronet日光光度计、Tropomi的轨道NO₂和SO₂之眼（2017–），以及PurpleAir人群。流行病学论据一个队列一个队列地建成——**六城市研究**（哈佛，多克里等人，1993）和**美国癌症协会队列**（波普等人，1995），其发现在一切挑战下幸存，成为现代无阈值曲线的基础——而全球算术由**全球疾病负担**事业完成，其2010–2020年评估把空气污染推为全球前三死亡风险，并推动了世卫组织2021年指导值修订——16年来第一次——依据的正是工业界花了几十年诉讼的那些队列，把PM2.5年均限值降低了2.5倍。
:::

指导值在设计上以健康为据：暴露-反应曲线显示效应——且超线性效应——一直延伸到约5 µg m⁻³，即有足够队列数据约束风险的最洁净水平。可达性通过过渡目标进入，而非指导值本身；相比之下，国家标准是经过可行性过滤的健康信息。
:::
:::

::: summary
空气质量科学是大气的公共卫生学科：一份由参考网络、如今也由传感器人群和卫星测量的标准污染物清单，被压缩成传达平滑、无阈值流行病学的AQI数字；每年数百万生命的负担，集中在穷人的室内厨房和富人的路侧街区；以及一门有三代仪器的政策科学——烟害管制、技术强制标准与市场、综合战役——其旗舰成果（约30:1收益成本的美国清洁空气法、中国40%的十年、NOx腰斩的伦敦ULEZ）证明，只要有政治意志，空气就是环境中最可解的问题。前沿是纠缠：野火烟霾和热浪重开臭氧与PM案件、花粉季拉长、正义为最后几微克制图、传感器革命重新分配谁知道空气是什么的权力。1952年的教训双向长存：空气坏时杀得快、只是不干净时杀得慢，而移走的每一微克都以生命偿付。
:::

## 练习

::: exercise {level=1 check="100"}
在美国AQI中，哪个PM2.5 24小时浓度（µg m⁻³）划在"良"与"对敏感人群不健康"之间？
::: solution
**35 µg m⁻³** = AQI 100——世卫组织2021年年均指导值的七倍，一个数字就是政策辩论的那个差距。
:::
:::

::: exercise {level=1 check="9"}
求年均PM2.5为45 µg m⁻³的城市相对世卫组织2021年指导值的倍数。
::: solution
$45/5 = 9$ ——九倍，一个典型中型污染城市的暴露，也是世卫组织修订既是科学事件也是政治事件的原因。
:::
:::

::: exercise {level=1 check="7"}
用每10 µg m⁻³增加6–10%的范围，说出每10 µg m⁻³慢性死亡增幅的中点百分数。
::: solution
每10 µg m⁻³ **7%**——把每张浓度图变成死亡地图的那个斜率。
:::
:::

::: exercise {level=1 check="90"}
全球环境加家庭空气污染负担的百分之多少落在中低收入国家？
::: solution
**90%**——负担的地理，跟着炊事燃料、煤炭和增长最快的车队所在之处。
:::
:::

::: exercise {level=2 check="6.7"}
在每10 µg m⁻³对数线性斜率7%下，求慢性PM2.5下降10 µg m⁻³时超额死亡的削减百分数（$1-e^{-0.07}$，一位小数）。
::: solution
$1-e^{-0.07} = 6.7\%$——该浓度区间内归因超额的6.7%，大数字的小分数，正是空气政策挣得收益成本比的方式。
:::
:::

::: exercise {level=2 check="7"}
柴油门：一辆车路上排放0.70 g km⁻¹ NOx，而限值是0.10 g km⁻¹（最差的受测构型更高）。求超标倍数。
::: solution
$0.70/0.10 = 7$ ——把认证作弊变成五百万辆召回、一纸刑事和解和真实行驶排放测试时代的那个倍数。
:::
:::

::: exercise {level=3 check="9"}
用每年$2\times10^{4}$起死亡、每避免一起15个生命年、每生命年3万美元，求年度收益（十亿美元）。
::: solution
$2\times10^{4}\times15\times3\times10^{4} = 9\times10^{9}$ ——**90亿美元**，对一个60亿美元的计划：每项空气质量评估都在跑的算术，也是该领域不断在数字上赢、在标题上输的原因。
:::
:::

::: exercise {level=3 check="1.5"}
求上一题计划的收益成本比（收益90亿，成本60亿）。
::: solution
$9/6 = 1.5$ ——即使在保守估值下也稳稳为正，也是环保局计入数十年和全部污染物的完整回顾算出接近30:1的原因。
:::
:::
