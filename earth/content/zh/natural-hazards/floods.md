洪水是我们不想要水的地方、在我们不想要它的时候的水——而这句话包含整个学科，因为"哪里"与"何时"是规划者、保险者与工程师在雨落下之前很久就做出的决定。发洪水的那条河是被裁弯取直、被筑墙、被盖满的那条河；发洪水的那座城市是把自己那块海绵铺上沥青的城市；发洪水的海岸是把它的盐沼降低、而把它的海抬高的海岸。2021 年 7 月，阿尔河，德国西部一条小小的葡萄酒谷的河、它大多数居民从未见过它上涨超过一米，在一个月三分之二的雨在 36 小时内落下之后冲出河床，在阿尔县杀死约 40 人、在德国全境杀死 184 人，摧毁了舒尔德镇的中心、而损坏了沿河的几乎每一栋房子，而产生了接近 90 亿欧元的保险损失——来自一个降雨事件，其复现期的估计依水文站而从几十年到半个千年不等，而在一个拥有欧洲最好的水文学的国家里，它的警告对大多数受害者来说是以一个下游亲戚的电话到来的。阿尔河洪水是本课一切内容的案例研究：暴发的物理、尾部的统计、一个自动的警告未能变成一次疏散的失败，以及那个问题——这是气候变化吗？——归因科学谨慎地回答、而公众大声地回答。

## 洪水的种类与它们不同的钟

::: definition 河洪、暴洪、雨洪、海岸、城市 {#def-flood-types}
**河洪（河流洪水）**是经典的那种：一个流域上的降雨或融雪汇集到河网，波在几天之后在下游达到峰值，而洪泛区被充满。它的钟是几天到几周，它是最可预测的一类，而它是那些巨大的防御工程据以修筑的——莱茵河、密西西比河、长江、恒河–布拉马普特拉河，那里有一亿五千万多洪泛区的居民住在设计洪水的可及范围之内。**暴洪**是同样的物理而把钟拿掉：小的陡的流域、强而移动缓慢的风暴、饱和的或过火的土壤、以及几分钟到几小时的河道响应时间——世界上杀人的那一类，从一小份洪水损失中负责也许一半的洪水死亡，因为它们在夜间到来、没有水文站的读数、也没有预警的提前量（2015 勒吕克与 2021 阿尔河的事件、喜马偕尔的季风冲沟、火后加利福尼亚的火烧迹地泥石流）。**雨洪（地表水或降雨洪水）**发生在河流离它的河床很远的时候：降雨超过铺装的地面的入渗与排水的能力、而水沿着地表进入街道、地下室与隧道——2021 郑州的大水，7 月 20 日一小时 201.9 mm 的大陆纪录降雨在几分钟内淹了地铁、而在河南省杀死数百人，是它的标志——而雨洪如今是*成本增长最快*的一类，因为它随铺装面积、不随河流量缩放。**海岸洪水**是海平面加风暴潮加潮加浪：风的应力与低气压把海堆起来（1 hPa 的气压亏空加约 1 cm 的海平面；风的增水项主导，在一个强烈的风暴中是几米），而静水位漫过或穿过防御（1953 北海风暴潮在预报潮位之上约 3.5 m，在荷兰杀死 1,836 人、在英格兰约 300 人；卡特里娜的风暴潮高达 8.5 m，新奥尔良 70% 在堤后，2005 年杀死 1,833 人、花费 1,250 亿美元）。**地下水洪水**——几个月的潮湿天气把水位抬进地下室——是最慢的、而按每一不动产算最贵的，因为它在几周中到来、而在几个月中离开。五只钟以不同的速度走、而需要不同的仪器：一个为几天建的河流预警系统不能对一小时发出警告，而一个为一年的排水系统不能挺过一个世纪。
:::

::: definition 设计洪水、复现期、以及非平稳的问题 {#def-design-flood}
洪水的防御是按一个**设计洪水**修的：一个选定概率的、防御必须通过而不失效的事件，以一个年超越概率（AEP）或它的复现期 $T = 1/\mathrm{AEP}$ 表达。实践从城市排水的 1/2 到 1/10 年，堤与防洪墙的 1/100 到 1/1000，而溢洪道与核反应堆冷却水的**可能最大洪水**（PMP——物理上的极端事件、不是一个概率）。设计的值来自**洪水频率分析**：把一个分布（甘伯尔 I 型极值是年最大值的工作默认）拟合到水文站的记录、而读分位数 $x_T = \mu + \sigma\frac{\sqrt{6}}{\pi}\left(y_T - 0.5772\right)$，缩减变量 $y_T = -\ln(-\ln(1-1/T))$。三个诚实的告诫属于它产生的每一个数字。第一，**外推**：从一个 60 年的记录来的百年洪水是一个统计的构造、它的置信区间是宽的（在 T = 100 上约 1.5 倍是典型的），而记录本身被极值的测量所偏——记录中最大的那次洪水平均而言被*低估*。第二，**复现期不是一段等待**：一个百年一遇的洪水在一个抵押 30 年的寿命中至少发生一次的机会是 26%，而复现期是成串的——在德国的记忆中 2021 跟着 2002、2010、2013、2016、然后又是 2021。第三，而最严重的，**平稳性已死**：极值的分布是土地利用、河流工程与气候的函数、而这三者都变了；1997 奥得河的"千年洪水"被 1990 年代的排水与裁弯取直放大的程度不亚于被那场风暴，而专业的问题不再是"百年洪水是多少"，是"*未来 50 年*的百年洪水是多少、而我们在此期间做了什么"。欧盟的洪水指令（2007/60/EC）强迫这个答案在六年的周期上被重新审视——洪水灾害图、洪水风险图、与管理计划——这就是为什么一张欧洲的洪水图是一份有失效日期的法律文件。
:::

::: example 阿尔河，2021：两只钟 {#ex-ahr}
7 月 14–15 日，Vb 型气旋"贝恩德"停在艾费尔上空、而在阿尔河流域（900 km²）上投下 150–200 mm——局地 250–300 mm——它的土壤在一个潮湿的六月之后已接近饱和。阿尔河在阿尔塔纳赫的阿尔河几小时内涨了超过六米，漫过而摧毁了水文站，而测量到的洪峰以每秒几米穿过一个满是巨石的镇。在下游，自动的预警系统整夜升级；一位县的官员在午夜前后取消了一个升级的蜂窝广播警告，警笛迟来了，而在几个村里人们是从邻居或从水里得知洪水的。重建物理：以一个约 4–6 h 的流域滞时、而最猛的雨（在陡的中部流域上 6 h 约 100 mm）在午夜前后结束，波应该在什么时候到达下游 20 km 的舒尔德？而说出把一次大洪水变成 180 人死亡的三个制度的失败。
::: solution
在一个陡的、多石的山地河道中以 2–4 m s⁻¹ 的洪峰波速，20 km 在 1.5–3 h 中被跨过：舒尔德在凌晨被击中、与记录一致——物理给了它的几小时、而那几小时被花在升级上。制度的失败：(1) **从测量到警告的链条**——州的预警办公室收到了升级的水文预报，但下令疏散的政治权力分散在 10 个县、没有常设的触发；(2) **从警告到行动的鸿沟**——午夜的警笛与广播、没有"现在就走，往高处，步行"的指示；(3) **土地利用的历史**——在 1804 年洪水（这个谷的历史大事件）之后房子被重建到水边，而一张洪水灾害图的最后一次全面修订早于已经把这个情景重新上演的 2016 布劳恩斯巴赫事件。2022 年北莱茵–威斯特法伦州议会的调查委员会在警告链几乎每一个环节上编目了失败——这个案例如今在每一门欧洲的保护机构的课程中与 2021 的郑州并列讲授。
:::
:::

::: example 一个水文站的频率分析 {#ex-gumbel}
一个 60 年的年最大河流量记录有均值 $\mu = 500\ \mathrm{m^{3}\,s^{-1}}$ 与标准差 $\sigma = 150\ \mathrm{m^{3}\,s^{-1}}$。拟合一个甘伯尔分布、而求百年洪水。然后：一个气候归因研究表明未来的年最大值有同样的形状、而均值高 20%。*旧的*百年堤如今防的是多少复现期？（第一部分的百年流量以 m³ s⁻¹ 计、最接近的整数。）
::: solution
缩减变量 $y_{100} = -\ln(-\ln 0.99) = 4.600$；$x_{100} = 500 + 150\times0.7797\times(4.600-0.5772) = 500 + 470 = 970\ \mathrm{m^{3}\,s^{-1}}$。以 $\mu' = 600$：解 $970 = 600 + 116.95(y-0.5772)$ → $y = 3.74$ → $\mathrm{AEP} = 1-\exp(-e^{-3.74}) = 0.0234$，即 $T \approx 43$ 年。均值上 20% 的移动——完全在欧洲流域观察到的土地利用与气候变化的范围之内——把一百年的防御变成四十三年的防御、而一滴"前所未有"的雨都不需要；这个算术、不是下一场风暴，是设计规范必须吸收的东西。
:::
:::

## 防御工程，以及它们对河流做了什么

::: definition 硬防御、软防御、以及堤防效应 {#def-defences}
**硬的（结构的）防御**把水挡在外面或减缓它的释放：堤与海堤（土的填筑——密西西比河下游 1,500 km 的"堤"保护新奥尔良与三角洲的大部分农业），防洪墙（混凝土的、城市的），河道的拓宽与浚深，滞洪区与水库（1998 长江的三万多个水库估计吞了 200–300 亿 m³ 的洪水、而因救了江汉平原被记功），活动的屏障（泰晤士河屏障，1982–84，此后关闭了 180 多次；荷兰的马斯朗特凯尔廷，地球上最大的移动结构），而围垦地——从海中夺来、而对着海设防的土地，荷兰大多数人口的家园。**软的（基于自然的）措施**把水存在它落下的地方、而在路上减缓它：河岸带与洪泛区的重新连通（英格兰在 2000 与 2007 洪水之后的"为水腾出空间"工程；荷兰 2006–2019 年 23 亿欧元的*河流的空间*工程——34 个项目，包括两个搬迁的洪泛区、一个降低的堰、一道向内陆移的加高堤，以及把奥弗塞尔特村搬迁的那个有争议的计划），河岸林、湿地恢复、海狸坝与农场蓄水。证据基础是诚实而令人气馁的：大规模的洪泛区工程可靠地削减*频繁的*洪水、削减*极值*较少（大事件把每一个蓄存都装满），而雨洪的风险与河里的一切无关。**堤防效应**（或"安全悖论"）是理论的行为的那一半：防御降低感知的风险、抬高受保护的资产、而把设计超越的事件变成一场比未设防的洪水更大的灾难——卡特里娜之后的新奥尔良（美国土木工程师学会的报告给堤防系统一个"D"、在受保护的区域*之内*有 50 多处堤决），1887 黄河在堤后的决口，按估计的范围杀死一百万到两百万人，以及"适应洪水的"重建之后的阿尔河的村庄。现代的实践因此谈**剩余风险**（防御会被超越；为它做计划）、**超高**（在设计水位之上建）、**按设计可淹**（分隔、深的防洪墙、泵的备份、垂直的疏散），以及**洪水风险管理三角**：预防、保护、准备——而保险与土地利用规例是给这个悖论定价的两件工具。
:::

::: example 百分之一洪水的经济学 {#ex-ead}
一个堤后有 50 亿欧元资产的小镇面对一个百分之一年的洪水、损失 20 亿，二百分之一的 8 亿，十分之一的 2 亿。算出当前的期望年损失（EAD）。一个每年 4,000 万欧元、持续 25 年的加高堤会把百分之一年的损失削减到 2 亿、而让其余不变；只按 EAD 算它值吗，而 EAD 的计算藏了哪两个数字？
::: solution
$\mathrm{EAD} = 0.01\times2000 + 0.02\times800 + 0.10\times200 = 20+16+20 = 5,600$ 万欧元每年。加高每年为 4,000 万的成本移走每年 1,800 万的 EAD——效益成本比 0.45、而只按 EAD 算*不*值。隐藏的数字：(1) **剩余的分布**——EAD 对那个使小镇破产的百分之一与那个使小镇恼火的十分之一取平均，而风险规避的社会为尾部的削减付高于 BCR = 1 的价（英国的评估指南用一个风险溢价给这个定价；德国阿尔河之后的工程明确这么做）；(2) 加高的堤**诱发的开发**，用今天的资产算的 EAD 会低估堤自己造成的增长——堤防效应在成为一场灾难之前先是一个记账的错误。
:::
:::

::: example 暴发的响应：推理公式法与它的限度 {#ex-rational}
一个 5 km² 的郊区流域（径流系数 $C = 0.6$）接受一场五十年一遇、1 小时、100 mm h⁻¹ 的暴雨。用推理公式法公式 $Q = CiA$ 估计洪峰流量、而比较同一场雨在城市化之前的流域上（$C = 0.25$）产生什么。为什么推理公式法即使洪峰是对的，也*低估*暴洪预警的危险？
::: solution
$Q = 0.6\times(100/1000/3600)\times5\times10^{6} = 83\ \mathrm{m^{3}\,s^{-1}}$；城市化之前 $83\times0.25/0.6 = 35\ \mathrm{m^{3}\,s^{-1}}$——城市化把同一场雨的洪峰增加一倍以上、这是雨洪与暴洪的风险比降雨的统计增长得更快的经典原因。推理公式法假定均匀的雨、而整个流域在汇流时间上全部贡献——对一场暴洪制造者那么大的雨团，两者都不成立：真实的过程线是一个更尖、更快、局地大得多的脉冲，而在平滑的设计洪峰上做出的预警决定系统性地迟到。
:::

::: warning "百年一遇的洪水"与其他四句杀死人的话
**"这是百年一遇的洪水，所以它一个世纪发生一次。"**它是一个 1% 的年机会——一个 30 年抵押上 26%，一百年上 63%——而这个由工程师创造的短语已经变成一块责任的盾牌与一个公众的误解；美国的联邦应急管理署如今写"1% 的年风险"。**"我们在堤后 / 在画出的洪水区之外。"**堤防防到它的标准而突然失效，图落后于十年的建设与一项归因研究，而 2017 哈维与 2021 阿尔河的死亡都包括许多在画出的灾害区之外、或在失效的防御之后的人；那个区是一个定价的工具、不是一个承诺。**"这里从来没发过洪水。"**水文站的记录比尾部短（阿尔河的"从来不会"在 8 m 处结束），而在一个过火的或城市化的流域上"从来不会"描述的是上一个世纪的地表覆盖、不是这个世纪的。**"这场洪水是气候变化造成的。"**诚实的那句是归因的版本：热力学把极端降雨的强度提高约 7% K⁻¹（克劳修斯–克拉珀龙；在欧洲的数据中观察到），变暖在*一些地区*增加了河流洪水的风险、在另一些没有（2023 年的全球洪水趋势归因：在亚洲与欧洲的洪水趋势中检测到人的影响、在全球没有），而土地利用、河道的工程、以及我们选择在哪里建设，仍然是*损失*的一阶驱动——政府间气候变化专门委员会第六次评估报告明确说洪水的损失主要增长是因为我们把更多的价值放到了水的路上（[[climate-change/extremes]]）。**"基于自然的解决方案更安全。"**湿地与林地削减频繁的中小事件、而不能蓄存一场设计洪水；2021 的阿尔河把它恢复过的城市河段和没恢复的一起冲刷了——基于自然的措施*增加*韧性、买几分钟，它们不取代堤也不取代警告，而把它们当作更便宜的防御来卖就是它们被按错误的设计标准建造的方式。
:::

::: history
洪水的管理与农业一样古老——黄河的堤在两千多年前就被中国的史书记录，而尼罗河的盆地灌溉把洪水本身读作预算——但现代的学科诞生于灾难与法规。**1887 黄河的决口**与**1931 长江–淮河–黄河的洪水**（二十世纪最致命的灾害序列、死亡的估计从 145,000 到两百万）结束了纯阻挡的策略、而带来了蓄存水库与 有控制的分流的学派（黄河委员会后继的工程；苏联时代的第聂伯河与后来的三峡逻辑）。**1953 北海风暴潮**产生了荷兰的三角洲委员会、三角洲工程（1958–1997），以及英国韦弗利委员会那条在三十年后通向泰晤士河屏障的路线——以及荷兰的法律一直带到 1995 莱茵河的险情与 2007 欧洲的洪水潮才被迫转向基于风险的、多层的标准的"万年一遇"的安全标准。统计的机器有一个世纪的历史：**马尔瓦尼**1851 年在爱尔兰的推理公式实验，**富勒**1914 年的频率曲线，**谢尔曼**1932 年的单位线，**霍顿**1933 年的入渗与径流律，美国土壤保护局 1954 的曲线数方法，以及**甘伯尔**1954 的《极值的统计》。政策的转折随**1993 与 1997 美国和德国的春汛**，**1998 长江的洪水**（约 1.86 亿人受灾、直接损失接近 300 亿美元、以及产生了"退耕还林"工程的毁林与水库之争），**2000 与 2007 英国的洪水**（皮特评估与为水腾出空间），**2007 的欧盟洪水指令**（基于风险的填图、六年的周期、以及第一次法律上承认一个防御是一个风险的转移者、不是风险的消除者），以及**2021 阿尔河与郑州的洪水**，它们共同的教训——最薄弱的环节是警告的链条、不是过程线——如今驱动着 2022 年联合国的"全民早期预警"倡议。
:::

::: quiz
一个河流小镇的堤为百分之一年的洪水设计。在一个 100 年的世纪中，堤*至少一次*被漫顶的概率（忽略非平稳）最接近：
- [ ] 1%。
- [ ] 10%。
- [x] 63%。
- [ ] 100%。
::: solution
$1-(0.99)^{100} = 63\ \%$——复现期是一个年的概率、不是一张日程表；设计寿命的问题（"它能撑过我的抵押吗？"）总是超越概率的计算、这就是为什么规范在设计水位之上加上超高与剩余风险的规划。
:::
:::

::: summary
- 洪水有五种、带着五只不同的钟——河洪（几天）、暴洪（几小时）、雨洪（几分钟）、海岸（几小时、带一个几天的潮–潮位日历）、地下水（几个月）——而每一种需要它自己的观测、模型与预警的提前量。
- 设计洪水是统计的构造：把一个极值的分布拟合到记录、带着宽的置信带外推、而记住复现期是一个年的概率（"百分之一"在 30 年上是 26%）。
- 平稳性已死：土地利用、河流工程与气候都移动那个分布，而均值上升 20% 把一百年的防御变成四十三年的防御——设计的问题是未来 50 年、不是过去 60 年。
- 硬防御防到它的标准而突然失效；它们在它们*后面*也*引起*开发（堤防效应），所以现代的实践加上超高、按设计可淹、剩余风险的规划与土地利用的定价。
- 基于自然的措施削减频繁的事件、买几分钟、而共同惠及生物多样性，但不蓄存设计洪水；诚实的组合是防御 + 蓄存 + 空间的规划 + 警告。
- 2021 阿尔河与郑州的灾难既是降雨事件、也是警告链的失败：联合国的"全民早期预警"工程编码了这个教训——最后一公里，从预报到迈开的脚步，是灾害真正的瓶颈（[[natural-hazards/risk-reduction]]）。
:::

## 练习题

::: exercise {level=1 check="26"}
一处不动产在百分之一年的洪水区。在一个 30 年的抵押期间至少一次百分之一级别的洪水的概率是多少？给出百分数、最接近的整数。
::: solution
$1-0.99^{30} = 26\ \%$——每一个抵押放款人都该报、而几乎没有一个报的数字。
:::
:::

::: exercise {level=1 check="83"}
用推理公式法，$C=0.6$、$i=100\ \mathrm{mm\,h^{-1}}$、$A=5\ \mathrm{km^{2}}$，求洪峰流量，以 m³ s⁻¹ 计（最接近的整数）。
::: solution
$Q = CiA = 0.6\times2.78\times10^{-5}\times5\times10^{6} = 83\ \mathrm{m^{3}\,s^{-1}}$。
:::
:::

::: exercise {level=1 check="6.5"}
一个海岸的小镇面对 2.0 m 的大潮高潮、3.5 m 的风暴潮、1.0 m 的浪增水。沙丘必须超过的设计静水位是多少米（一位小数）？
::: solution
$2.0+3.5+1.0 = 6.5$ m——1953 年的组合是 2.0 + 3.5 + 约 1 m，而那天晚上失效的荷兰的堤比这个和矮 1–2 m；超高还要在上面加。
:::
:::

::: exercise {level=2 check="970"}
一个水文站的年最大值：$\mu = 500$、$\sigma = 150\ \mathrm{m^{3}\,s^{-1}}$。算出甘伯尔的百年洪水（最接近的 m³ s⁻¹）。
::: solution
$y_{100} = 4.600$；$x_{100} = 500+150\times0.7797\times(4.600-0.5772) = 970\ \mathrm{m^{3}\,s^{-1}}$。
:::
:::

::: exercise {level=2 check="43"}
在上一道练习题的流域均值增加 20% 之后（$\mu'=600$、同样的 $\sigma$），旧的 970 m³ s⁻¹ 的堤现在提供多少复现期？最接近的年。
::: solution
$y = (970-600)/116.95+0.5772 = 3.74$；$\mathrm{AEP} = 1-\exp(-e^{-3.74}) = 2.3\ \%$ → $T \approx 43$ 年。
:::
:::

::: exercise {level=2 check="16"}
受保护的资产 100 亿欧元面对百分之一年的洪水。一个每年 500 万欧元的工程把设计事件降到五百分之一。只按避免的期望年损失算效益成本比（一位小数）。
::: solution
避免的 EAD $=0.01\times10^{10} - 0.002\times10^{10} = 8,000$ 万欧元每年；$\mathrm{BCR} = 80/5 = 16$——一个教科书上无可争辩的情形，这就是为什么*被*建的那些工程是有看得见的受益者的那些、而没被建的通常是剩余风险与维护的措施、它们的效益是没有发生的灾难。
:::
:::

::: exercise {level=3 check="62"}
用一个 5 km 长的地表流路径、2% 的坡度，以基尔皮奇公式 $t_c = 0.0195\,L^{0.77}S^{-0.385}$（分钟；$L$ 以米、$S$ 无量纲）估计汇流时间。最接近的分钟。
::: solution
$t_c = 0.0195\times5000^{0.77}\times0.02^{-0.385} = 0.0195\times703\times4.51 = 62$ 分钟——这就是为什么一场 2 小时的雷暴在这个流域上是一个暴洪的候选、而同样总量的一场 6 小时的风暴是一场可以管理的河波：持时比雨量更要紧。
:::
:::

::: exercise {level=3 check="1.79"}
一座城市把它的铺装面积翻倍，而开发前的流域系数从 0.25 升到 0.6。假定推理公式法与同样的风暴，十分之一年的洪峰按 $0.6/0.25 = 2.4$ 倍增长；如果在一个宽的城市河道中流量按 $Q\propto h^{1.5}$ 随水位缩放，每一个设计事件的水位按多少倍增长？（两位小数。）
::: solution
因为 $h\propto Q^{2/3}$，水位的倍数是 $2.4^{2/3} = 1.79$。这一类的城市化把*每一个*洪水的深度提高约 80%，这就是为什么二十年一遇的事件过去放过的地下室如今被两年一遇的事件开始淹，以及为什么雨洪图必须随铺装、不是随河流重新绘制。
:::
:::

::: exercise {level=3 check="0.51"}
1953 北海的风暴潮把海在预报潮位之上抬了约 3.5 m。一个堤顶在潮位之上 3.8 m，浪的爬高在静水位上加 0.7 m，而漫顶的流量按 $q = C\,h_o^{1.5}$、$C = 2\ \mathrm{m^{1/2}\,s^{-1}}$ 缩放。计算每一米堤顶的漫顶流量，以 m³ s⁻¹ m⁻¹ 计。（两位小数；注意持续的漫顶超过约 1 m³ s⁻¹ m⁻¹ 会侵蚀长草的堤。）
::: solution
漫顶的深度 $h_o = 3.5+0.7-3.8 = 0.4$ m；$q = 2\times0.4^{1.5} = 0.51\ \mathrm{m^{3}\,s^{-1}\,m^{-1}}$——在约 1 m³ s⁻¹ m⁻¹ 的草皮侵蚀阈值之下，但 1953 年的堤比这个堤顶矮 1–2 m、被漫过、而从陆侧开始侵蚀：那天晚上几乎每一处荷兰堤的失败都是从陆侧的一道侵蚀的伤口开始的、不是海侧的强攻。
:::
