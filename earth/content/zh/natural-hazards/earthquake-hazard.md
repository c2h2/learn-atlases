一次大地震在几秒中释放的，是一座火山花几个世纪积累的东西，而它发生在几百万人睡觉的地方之下——这就是为什么地震灾害是图集中关于物理知识（极好：我们能定位、定震级、定日期、把破裂模拟到米）与社会结果（参差：1556 年陕西在黄土窑洞中可能杀死 83 万人，2010 年智利经历一次里氏 8.8 级只死了数百人，而差别不是地震学，是**规范的执行、土地的利用，以及断层与城市之间那四秒的预警**）之间鸿沟最纯粹的一课。本课把地震作为灾害：我们如何测量它（从里氏的尺到力矩张量），地面拿它怎么办（波、场地、液化），概率如何被组装（PSHA、空段、古登堡–里克特律），以及社会回敬什么（规范、加固、预警）——外加地震学没有礼物可给的那一个领域：预报，以及诚实承认这一点的伦理。

## 测量地震

::: definition 从里氏的尺到力矩张量 {#def-measuring}
**查尔斯·里希特**1935 年的近震震级 $M_L$（最大地震图振幅的对数、按距离校正——每一单位是振幅的十倍、**能量的 32 倍**）是一件活得比设计者意图更久的实验室仪器：在远距与大事件上饱和，它只在小报的误用中残存（"这次地震是 8 级"）。物理随**釜本与汉克斯**（1977）到来：**地震力矩** $M_0 = \mu A D$（刚度 × 破裂面积 × 平均滑动——对一个巨大的俯冲事件，$30$ GPa × $50{,}000$ km² × 10 m ≈ $1.5\times10^{22}$ N m）与**力矩震级** $M_w = \tfrac{2}{3}(\log_{10} M_0 - 9.1)$，它不饱和、就是"震级"现在的含义、而它给历史上的大事件重新定了级（1960 瓦尔迪维亚 9.5——有记录的最大；1964 阿拉斯加 9.2；2004 苏门答腊 9.1；2011 东北 9.0——全是俯冲的巨型逆冲，理由很简单：板块界面是唯一大到能滑动几百公里的断层面）。**古登堡–里克特律** $\log_{10} N = a - bM$（全球 b ≈ 1：每一个震级台阶上地震多十倍，一个临界系统的无标度指纹——**巴特、唐与维森菲尔德**的自组织临界性解释及其有争议的后继者）是灾害分析者的脊梁：它把一个记录良好的小震目录变成那个未记录的大事件的概率。**地震周期**（弹性回跳——**哈里·菲尔丁·里德**1911 年对 1906 旧金山位移的综合，锁断层上的应变积累，使**地震空段**概念（1857 特洪破裂未再充装的那些段、卡斯卡迪亚空段 1700 年的日期、马尔马拉海之下那个伊斯坦布尔空段）成为应用地震学中最危险的一句话——以及**速率–状态摩擦**框架（**迪特里希与鲁伊纳**学派的地震触发物理、余震统计的基础）补全了震源的图像。目录的现代仪器：**全球地震台网与美国地质调查局/全球力矩张量目录**（每个 M5+ 在几分钟内定位、每个 M5.5+ 有一个完整的**力矩张量**——断层面、走向、倾角、滑动角与滑动量，**日捷文斯基与力矩张量**学派使之成为常规），**GPS 与 InSAR 大地测量**（同震间锁定图——**萨维奇与"锁定深度"学派**、相模海槽那个给东京情景定规模的锁定带），以及**有限断层反演**（东北 50 m 的滑动斑由地震–大地测量联合模拟成像、**ShakeOut** 情景方法）。**b 值**本身是一个灾害变量（低 b——相对少的小震——标出马尔马拉与卡斯卡迪亚锁定的凹凸体、**维默与"低 b 凹凸体"**的填图），而**能量预算**（从震源谱的辐射能量、釜本的能量对力矩比）把脆性的浅事件与慢的和深的事件分开——灾害模型的地面运动选择如今全系于这套分类。
:::

::: example 给未记录的定规模 {#ex-moment}
一个沿走向 150 km × 倾向 80 km 的锁定的俯冲段被模拟成以 6 m 的平均滑动破裂（μ = 30 GPa）。求地震力矩与力矩震级，而——用 b = 1 的古登堡–里克特律与该地区**每年一次 M6+ 地震**的速率——估计被模拟事件的平均复发。
::: solution
$M_0 = 3\times10^{10}\times(1.2\times10^{10})\times6 = 2.16\times10^{21}$ N m；$M_w = \tfrac{2}{3}(21.33-9.1) = 8.2$；从 M6 到 M8.2 的古登堡–里克特台阶是稀 $10^{2.2} = 158$ 倍，所以复发 $\approx 158$ 年——**大地测量与统计的配对**给每一个特大城市情景定规模（东京、西雅图、加德满都、伊斯坦布尔），而它两个薄弱环节是诚实的：假定的滑动（凹凸体可能更小）与 b 律的外推（大事件的复发比律的尾部所暗示的更有规律——卡根–莫尔纳周期性争论中**维默与"特征地震"**的校正）。
:::
:::

## 地面拿它怎么办

::: definition 波、场地与放大链 {#def-ground}
地震给城市的礼物是一个**滤波问题**：同一个震源，经过路径与场地的滤波，给出迥然不同的晃动——而这些滤波器就是灾害。**体波**（P 在 $V_p=\sqrt{(\lambda+2\mu)/\rho}$，S 在 $\sqrt{\mu/\rho}$——核幔边界上的速度跃变，奥尔德姆1906年读出、古登堡测到 2,900 km；**英格·莱曼**1936 年的内核来自 P 的反射）第一第二到达；**面波**（乐夫的横剪切、瑞利的滚动椭圆——**1906 与 1911 年里德与乐夫**的波地震学）对浅的壳事件主导距离与破坏。**场地放大**是第一道滤波器：地震能被软沉积物捕获在它们的共振周期上把地面运动乘以 2–6 倍——定量的证明是**1985 年墨西哥城**（一次 350 km 外的 8.0 级俯冲事件，湖床盆地以 2 s 周期放大约 5 倍，恰好是 6–15 层楼的节奏：旧湖区 95 栋倒塌，火成岩的高地上没有一栋——**罗森布卢特与墨西哥城规范的改写**使场地反应谱成为法律）、**1989 洛马普列耶塔的滨海区**（海湾淤泥的液化与高架桥塌到塞普雷斯结构上），以及从德黑兰到加德满都每一座盆地城市、它们的微区划图直到 2000 年代才被终于画出。**液化**是第二道滤波器：饱和的松砂把自己的晃动变成有效应力的丧失（**1964 新泻**的楼房倾斜，以及**西德与伊德里斯**1971 年如今规范所实施的液化判别方法），侧向滑移、把加油站浮起来，而——2011 基督城与 2018 巴卢的事例——比晃动本身更彻底地摧毁土地价值；日本的对策产业（地基改良、深层压密、砂桩排水场）是灾害目录中在适用处最便宜的加固。**方向性与上盘**滤波器（把 1995 神户高架桥从桥墩上甩出去的法向脉冲、**布鲁内与方向性**的脉冲在 1999 集集与 2016 熊本记录中被记录）与高的柔的结构对**持时敏感**的破坏（2018 与 2023 土耳其在软土上对中层的存量造成的长周期破坏）补全了从震级到损失的链条——**地面运动预测方程**（**亚伯拉罕森与 NGA-West 与 NGA-Subduction**系列）如今把它编码成烈度的概率分布，而**情景晃动图**（美国地质调查局的 ShakeMap、**沃尔德与"ShakeMap"**的业务产品）在几分钟内给出、作为对一场灾难的第一幅共同图像。
:::

::: example 墨西哥城的滤波器 {#ex-site-amp}
一次 350 km 外的 8.0 级俯冲事件在一个基岩场地给出 0.08 g 的峰值加速度，该场地的基频周期是 2.0 s。盆地在那个周期上放大 5 倍。求地表的加速度，而用两句话解释为什么倒下的楼是 6–15 层的、而 1985 年规范的对策是一条**周期匹配**的规则（避免重合）、不是一条强度的规则。
::: solution
地表加速度 $= 5\times0.08 = 0.4$ g **在盆地的 2 s 周期上**——一把有节奏地挥动的窄带的锤；每一栋楼的自振周期接近每层 0.1 s，所以 6–15 层在 0.6–1.5 s 共振，与盆地的 2 s 足够接近（加上高阶振型与非线性土展宽）而被有选择地晃动——"湖区又软又高"的死亡图景；因此规范的对策是**谱的**：编码盆地放大峰的设计反应谱，使新建筑被推**离**共振带（更刚、更深、或隔震），而不只是被做得更强——这个洞见把抗震设计从强度变成**调谐**，即**纽马克与霍尔**的反应谱遗产（1950–1960 年代、伊利诺伊大学学派）应用于一个城市尺度的滤波器。
:::
:::

## 灾害、规范与预报问题

::: definition PSHA、空段、规范、预警——以及诱发的风险 {#def-hazard-preparedness}
**概率地震灾害分析**（**科内尔**，1968；**科内尔与"PSHA"框架**、**麦圭尔与"地震灾害与风险"**教科书）把四个成分——源区、古登堡–里克特的震级分布、地面运动预测方程、以及场地——折叠进**灾害曲线**（超过每一个烈度的年概率）与规范据以书写的**均匀灾害谱**（50 年 2% 的地面运动——一个 1/2,475 年的事件——"保命"的目标：规范是为防止**倒塌**、不是防止破坏而书写的，1971 圣费尔南多与 1989 洛马普列耶塔的教训使"不倒"成为从 UBC-1994 到 ASCE-7 一脉及其全球后裔的明确目标）。**地震空段**的逻辑（**本–梅纳赫姆与"地震空段"**的综合、**麦卡弗里与"锁定带"**的大地测量）给未破裂的斑定规模——卡斯卡迪亚的 1700 年 1 月 26 日（日本"孤儿海啸"的**佐竹与"孤儿海啸"**的定年、年轮学定死的 1700 年冬季破裂）、西雅图断层，以及马尔马拉那个 250 年的应力时钟（**勒比雄与"马尔马拉应力传递"**、来自 1999 伊兹米特地震）对着伊斯坦布尔的 1,600 万人滴答——以及**时变的复发**模型（**赖森伯格与"地震触发"**、**菲尔德与 UCERF** 的加利福尼亚预报、其 2023 年的 UCERF3-ETM 版本包含触发的断层间断裂路径），它们在数据支持的地方取代了泊松假定。**规范与加固**是兑现的灾害科学：日本从**1923 关东**的火风暴（105,000 人死亡；一个火风涡旋在一个空场上杀死 38,000 人——**片冈与"关东大火"**的分析）经 1981 与 2000 年规范到**神户 1995** 的教训（6,400 人死亡、高架桥与未加固的 1960 年代存量、规范的修订与**木造住宅加固运动**、其缓慢的接受是发达世界加固悖论的宣传画），智利从 1906 到 2010 的规范连续性（**从皮诺切特到巴切莱特的技术官僚制度**——大学的图纸审查制度使 2010 年的 8.8 级可以存活），新西兰的**基督城 2010–2011** 序列（中央商务区的倒塌、**皇家委员会**对规范与土质的调查结论、为下一次事件预付费的土地收储决定），以及**中国 2008 汶川**的对照（"豆腐渣"学校的倒塌与 2009 年的校舍安全条例——**黄与"校舍加固"**工程、2000 年代最快的大规模脆弱性削减）。**地震预警**（**纽马克**1949 年的"终端警报"提议、**埃尔迪克与伊斯坦布尔预警**的原型、日本的**气象厅预警**（2005–，2011 东北给公众的 60 秒警报使新干线停下、医院的手术停下）、墨西哥的**SAS**（1991–，2017 的重启）、美国的**ShakeAlert**（2018–，2019 里奇克雷斯特与 2024 的测试），以及**厄尔与"地震预警"**的全球综述）买的是**秒、不是预报**——自动动作的经济学（**埃格利与"预警的经济价值"**的核算：在电网、医院与交通的运行中值数十亿的秒），使它成为自气旋避难所以来最便宜的大规模风险技术。**诱发地震**是最灾害的新词：**戴维斯与"落基山兵工厂"**的确认、俄克拉何马**注水诱发**的归因（从 2008 到 2015 年每年约 2 次到约 900 次 M3+，**埃尔斯沃斯与"俄克拉何马地震活动"**被美国地质调查局认定的成因——处置井、不是压裂），**巴塞尔 2006 与圣加仑**的增强型地热刺激，**浦项 2017** 的增强型地热地震（**格里戈利与"浦项"**的归因），以及**地震活动速率的红绿灯**规例（俄克拉何马与堪萨斯的注水深度规则、2020 年代 0.001 每日的诱发风险阈值），它们如今给能源与处置的决定标上地震风险的价格——灾害目录中完全是人的、而完全可以避免的那一项。
:::
::: example 四秒的经济 {#ex-eew}
2011 年的东北巨型逆冲在海面下 130 km 处成核；气象厅的警报在离海沟 40 km 处首次 P 波检测后约 4 秒到达东京（P 以 6 km s⁻¹，S 以 3.5 km s⁻¹）。求东京在破坏性的 S 波到达之前收到的预警时间，而——用**埃格利与"预警的经济价值"**的估计，即全国平均 10 秒的预警在避免的运行损失中值约 10 亿美元每年——用两句话解释为什么预警的难处不是检测、而是**自动化**。
::: solution
S 波到东京的传播 $\approx 130/3.5 = 37$ s；在约 7 s 时检测（40 km 的 P 以 6 km s⁻¹、加上处理）留下**约 30 秒**的公众预警（报道的 4 秒是第一次原始警报；公众广播在 S 到达之前几十秒）——足够让列车减速（新干线的 17 列列车停下、无一乘客受伤）、让工厂的安全刹车启动、让手术暂停，但**只有当机器动作时**：30 秒短于一个人的决策回路，所以预警的价值只被预先编程的自动化打开（**埃格利的核算**中那数十亿住在电网的跳闸、电梯的停止、燃气的阀门里），而让机器动作的责任、误报与公平的问题，是未解决的、人的剩余——预报问题在它唯一可解的形式中。
:::
:::

## 余震的算术

::: example 大森的书本 {#ex-omori}
余震速率遵循修正大森律 $n(t) = c/(t+p)^{p'}$；对主震序列用 $c = 100$ day⁻¹·day 与 $p = p' = 1$（所以第 1 天的余震数是 100）。求 (a) 第 10 天与 (b) 第 100 天的预期余震数，而用两句话解释为什么**2016 凯库拉**的双重破裂（先 M7.4、十二小时后在相邻构造上 M7.8）与**2023 卡赫拉曼马拉什**的双联（先 M7.8、九小时后 M7.5）把这条律最大的不确定性——"这是主震吗？"——变成了救援者与预警自动化的业务危机。
::: solution
第 10 天：$100/10 = 10$ day⁻¹；第 100 天：$100/100 = 1$ day⁻¹——这个衰减让重返的日程能被写出，**前提是第一个事件是最大的**；双联打破了那个假定（第二个更大，"主震"的标签是追认的，而累积的触发——**赖森伯格与"触发的余震"**的速率–状态模型、**托达与"库仑应力传递"**学派，其计算在几年前就预告了 2016 凯库拉在相邻断层上的第二次破裂——意味着第一个事件的应力变化**加载**了第二个），所以业务规则如今带一条"可能有更大的跟来"的告诫（美国地质调查局与 GNS 2016 与 2023 的科学咨询），而为衰减序列设计的自动化必须容忍第二次、更大的撞击——大森律统计上的安慰是用它唯一诚实的告诫换来的。
:::
:::

五个错误。**"8 级比 7 级糟十倍"**：能量的比是 **32 倍**、力矩的比是 **30 倍**——这份对数的梯子小报按线性读、工程师从不；而震级本身只是灾害的一个成分：2010 海地 M7.0（浅的、盲逆冲、人口密集、毫无准备）对 2013 巴基斯坦近海 M7.7（相似的规模、海上的死亡只有十分之一）差别在**地理与准备**、不在震级。**"灾害图告诉我我的风险"**：那张图只是灾害那一项——风险在暴露（那张图的城市在图绘制之后盖的软层公寓）与脆弱性（图上每一栋结构的规范年份）中乘进来，而 2015 廓尔喀与 2023 土耳其的事件是**画了图的灾害区之内的脆弱性灾难**——图是对的、建筑不是。**"地震学家本该预报它"**：诚实的共识（**盖勒与"地震预报不能被成功地预报"**的立场、1990–2010 年代、**《柳叶刀》**的社论与 VAN 事件的余波——希腊的电方法在盲测中失败、2009 拉奎拉审判科学家之后的**《柳叶刀》**社论——**委员会与"风险交流"**的裁决：罪在交流、不在预报）是**短期预报没有被证明的方法**、长期的概率预报才是真正的交付物，而拉奎拉审判对诚实交流的寒蝉效应是对未来每一个不确定性的警世故事；取代预报的公共投资是**规范、加固、预警与保险**——不需要知道日期就能工作的四种技术。**"建筑符合规范，所以是安全的"**：规范是**保命**的文书（50 年 2% 的防倒塌；2023 土耳其与 2015 廓尔喀的教训：**符合规范不等于执行了规范**，而中层非延性的存量与软层是杀手），而合规建筑的**功能丧失**（2011 基督城的医院疏散、2020 佩特罗利亚与 2024 弗恩代尔在中等洪堡事件后的医院关闭——**加利福尼亚医院抗震安全工程**的 SB 195/SB 493 合规的漫长纠葛、州自己的医院没通过州自己的法）是每一个医院与学校业主背负的未计价的负债。**还有"俄克拉何马的地震是倒霉"**：它们是**废物处置**——注水诱发的序列（**埃尔斯沃斯的归因**、**美国地质调查局与"诱发地震"**框架）是历史上一个由工业实践造成、又被规例削减的灾害最清楚的案例（2016 年的规则在几年内把速率砍了一半——**埃利奥特与"俄克拉何马的应对"**的监测），而同样的物理如今给地热刺激、强化采油与处置选址在处处标价：**诱发地震是唯一一个完全可选的地震灾害**，这就是为什么每一次发生都是一个治理的故事、不是一个自然的故事。
:::
::: history
地震科学始于**1755 年里斯本地震**的三次震动、海啸与火灾（**庞巴尔**的重建——第一份抗震的城市规划、"笼式木框"——以及穿过伏尔泰与康德的哲学冲击），和**罗伯特·马利特**1857 年的《那不勒斯地震》（第一份宏观地震图与第一次科学的震后调查）。仪器时代：**米尔恩与日本的地震仪台网**（1880 年代、使地震学成为一门科学的东京学派），**奥尔德姆**1906 年的地核，**里德**在旧金山位移之后 1911 年的弹性回跳，**本诺·古登堡与查尔斯·里希特**1930 年代的加利福尼亚工作（震级标度、全球的速率、1944 年的古登堡–里克特律、古登堡 1954 年的《地球内部构造》），**英格·莱曼**1936 年的内核，以及**大森房吉**1894 年的余震律。工程时代：**1906 与 1923** 的灾难（日本 1923 年关东的火风暴与日本抗震设计的诞生），**纽马克与霍尔**的反应谱（1950 年代），**1971 圣费尔南多**（改写规范目标的医院倒塌），**1976 唐山**（现代最大的损失、**国家地震局**的成立），**1985 墨西哥城**（场地效应的规范改写），**1989 洛马普列耶塔与 1995 神户**（创造了交通与加固政策的基础设施失效），**1994 北岭**（创造了加利福尼亚地震局市场的保险危机——**地震局**2000 年的零售工程），以及**1999 科贾埃利与集集**（土耳其的建筑特赦政治与改写了方向性的台湾强震记录）。空间与台网时代：**GPS 大地测量与 InSAR**（锁定图、**西蒙斯与"锁定深度"**学派），**USArray 与全球台网**，**ShakeMap** 的业务，**UCERF** 的预报（2008、2015、2023），**2004 苏门答腊与 2011 东北**的大事件（破裂持时与慢滑移的教训、**ShakeOut** 的情景文化），以及**诱发地震**的科学（**希利与"落基山兵工厂"**1966 年的实验、2015 年俄克拉何马的归因、2020 年浦项的调查结论）——这个领域如今预报概率、以秒预警、而管理它自己最新的灾害，而日期，诚实地而永久地，仍然未知。
:::

::: summary
地震灾害以力矩测量（μAD、釜本–汉克斯的标度给巨大事件定规模），以古登堡–里克特的梯子计数（b ≈ 1、用记录到的事件给未记录的事件定价的统计），而被地面滤波（盆地放大、液化、方向性——墨西哥城的 5 倍与新泻的液化把震级变成局部的烈度）。灾害以概率组装（科内尔的 PSHA、空段与大地测量锁定的逻辑、UCERF 的触发破裂预报），兑现为为防倒塌而写的规范（日本从关东到神户的一脉、智利的连续性、中国的校舍加固），而以秒预警（P 波警报的价值住在自动化中）。预报不会来——诚实的科学是概率、预警与建造，而拉奎拉审判的教训是交流好的不确定性比伪造的确定性救更多的人。最新的术语是那个可选的：诱发地震，一个规例能够删掉的地震灾害。日期不可知；结果不是；这个不对称就是整个学科在一句话里。
:::

## 练习题

::: exercise {level=1 check="32"}
求相邻整数震级之间的能量比。
::: solution
$10^{1.5} = 32$——一个震级台阶是 32 倍的能量、两个是 1,000 倍。
:::
:::

::: exercise {level=1 check="100"}
在 b = 1 下，求 M6 比 M8 的地震多多少次。
::: solution
$10^{2} = 100$——古登堡–里克特梯子两个台阶的比。
:::
:::

::: exercise {level=1 check="9.5"}
说出有记录的最大地震的震级（1960 瓦尔迪维亚）。
::: solution
**Mw 9.5**——瓦尔迪维亚的巨型逆冲、迫使引入力矩标度的那个事件。
:::
:::

::: exercise {level=1 check="66"}
S 波在 P 波之后 8 s 到达（Vp 6.1、Vs 3.5 km s⁻¹）。求震中距（km，最接近的 km）。
::: solution
$d = 8/(1/3.5-1/6.1) = 8/0.1218 \approx 66$ km——初等定位者的单台估计。
:::
:::

::: exercise {level=2 check="5"}
在 b = 1、每年 20 次 M6+ 地震下，求 M8+ 事件的平均复发（年）。
::: solution
$20/100 = 0.2$ yr⁻¹ → **5 年**——梯子的算术、以及为什么 M8 复发的估计带着三倍的误差棒。
:::
:::

::: exercise {level=2 check="0.4"}
一个盆地把基岩的 0.08 g 放大 5 倍。求地表的峰值加速度，以 g 计。
::: solution
$5\times0.08 = 0.4$ g——墨西哥城的滤波器、微区划成为法律的原因。
:::
:::

::: exercise {level=3 check="7.5"}
对 M0 = 2×10²⁰ N m 求 Mw。
::: solution
$M_w = \tfrac{2}{3}(\log_{10}2\times10^{20}-9.1) = \tfrac{2}{3}(20.30-9.1) = 7.5$——1989 洛马普列耶塔的力矩、上下不差。
:::
:::

::: exercise {level=3 check="30"}
对东北的例子（S 以 3.5 km s⁻¹ 走 130 km、成核后 7 s 检测），求东京在 S 到达之前收到的预警时间（s）。
::: solution
$130/3.5 - 7 = 37-7 = 30$ s——"四秒"的标题低估了真正的余量、而整个系统的价值都在其中实现自动化。
:::
:::
