没有什么天灾——只有自然的灾害与社会的脆弱性、而在它们的交点上的灾难是被决定**建造**的：住宅区被划在哪里、学校是怎么建的、谁被警告了、堤是为多大的设计。2010 年智利近海的 8.8 级地震杀死约 500 人；几周后击中太子港的 7.0 级杀死也许 160,000 人——差别不是地质，是**混凝土、规范与贫困**，是"灾害只是分子"最干净的一次演示。本课是灾害风险科学——**伯顿–凯茨–怀特**的环境灾害学派、**维斯纳–布莱基–坎农–戴维斯**的《处于风险中》范式、**亚历山大**的教科书传统——在六十年中建立、而仙台框架（2015–2030）写进国际政策的那个风险框架：风险作为灾害、暴露与脆弱性的乘积；复现期与它们的设计寿命的陷阱；人为什么暴露的压力与释放模型；以及使风险削减成为最有成本效益的气候适应的诚实的趋势（死亡下降、资产上升、灾害正被气候重新组织）。

## 风险方程

::: definition 灾害、暴露、脆弱性——以及复现期的算术 {#def-risk-equation}
这个框架的语法是三个外行语言熔进"灾难"的词。**灾害**是一个有强度、概率与持时的物理事件（地震的峰值地面加速度、洪水的流量、气旋的风场）——一个自然的现象、由**甘伯尔与水文的极值学派**创建的极值统计量化、而**科内尔**1968 年的**概率地震灾害分析（PSHA）**为地震把它形式化：给出超过每一个烈度的年概率的灾害曲线、被分解为支配一个场地的震级–距离的组合。**暴露**是在灾害的足迹里的人和物（那张随着每一处进入洪泛区与野火–城市交界的住宅开发而改变的图——**亚历山大的"风险超周期"**论题与暴露增长的文献——**阿莱加特与未揭开面罩的暴露的经济学**——识别为损失上升的主导驱动的那种暴露的增长）。**脆弱性**是被暴露者受伤害的倾向（未加固的砖砌体、靠雨养的农场、老人的公寓楼——由**脆弱性曲线**量化：在一个资产的价值的每一灾害强度上损失的那一份、风险模型行业的**脆弱性函数**传统）。风险方程 $R = H \times E \times V$ 不是算术、是**概念的语法**：一场灾难需要全部三个因子、所以**任何一个都可以被归零**——这就是预防的全部科学基础（用地的区划把暴露归零；建筑规范把很多脆弱性归零；只有某些灾害本身能够被削减、而很少）。概率的工具是**复现期** $T = 1/p$（平均一年一次超过的那个事件的平均复发间隔——"百年一遇的洪水"是**1% 的年超越概率（AEP）**的事件、**不是**一个一百年的倒计时、而设计寿命的陷阱是公众从未被教的那个二项式：百年事件在一个一百年的结构的寿命中至少击中一次的概率是 $1-0.99^{100} = 63$ 百分、不是 1——每一次堤防失败的验尸报告与每一个"洪水来得早"的标题的范畴错误背后的算术）。这个框架的现代机器：**多灾害与系统性风险**——卡特里娜之后的**吉尔与"灾害的级联"**报告、**克罗伊比希与"朴素的雨冲击"（naive rainboom）**对 2002 易北河洪水的分析（一场百年的雨落在一条已经是百年的河上：极值相互叠加，因为底层的状态不是年平均），以及 2021 得克萨斯电网的相互依赖的基础设施的级联（冷到气到电到水到家：一次"自然的"灾难其实是一次系统的失败）——以及**风险的转移**（保险的渗透——未保险的份额是穷人的脆弱性被精算地变得可见：加勒比 CCRIF 与非洲风险能力的参数保单、按触发的测量付款、巨灾债券的市场、墨西哥的地震再保险工程——风险金融作为一种承认：剩余风险无法被工程掉）。
:::

::: example 设计寿命的陷阱 {#ex-return-period}
一条堤保护一个城市免受百年（1% AEP）的洪水。求在堤的 50 年设计寿命中至少一次漫顶级别的洪水的概率，而——在一次"不比设计事件大"的洪水仍然淹了城市之后——列出取证队伍将检验的三个不互斥的解释。
::: solution
$1-0.99^{50} = 39.5$ 百分——**只按设计标准**在堤的寿命中被漫顶的五十分之二的机会、使"百年的保护"成为"一个世纪上 63% 的保护"的误称的那个二项式；而三个解释：**灾害被低估了**（设计洪水的统计来自一个非平稳的世界——河的洪泛区被铺了、上游的冰川现在是一个湖、降雨的强度–持时曲线过时了）、**系统在设计的以下失效**（漫顶仍然淹：超高、维护、泵站自己的被淹——"设计事件"不是"无损坏"）、或**事件比设计的小、而暴露变了**（洪泛区自 1975 年以来被填满了）——每一次洪水调查实际报告的统计、工程与规划的三重。
:::
:::

## 灾难是怎么被制造出来的

::: definition 压力与释放模型，以及第二次灾难 {#def-par}
**《处于风险中》**的范式（**维斯纳、布莱基、坎农、戴维斯**，2004，建立在**伯顿–凯茨–怀特**的《作为灾害的环境》（1978）的洞见之上——灾害是**资源利用的问题、不是反常**——以及**吉尔伯特·怀特**1945 年的博士论文《人对洪水的调适》，那本奠基的文本已经说了人们之所以住进洪泛区，是因为农业的收益每年到来、而洪水的损失间歇地到来，所以**经济的逻辑是理性的，直到水来了**）把灾难定位在平常发展的**风险的创造**中：**压力与释放（PAR）模型**从**根因**（政治经济学：把工厂放在坝下游的增长模式、把佃户放在坡上的土地保有权）经过**动态的压力**（贫困、没有基础设施的快速城市化、把维护预算掏空的冲突）到**不安全的条件**（坡上的非正规居住区、没有加固的学校、带着既得权利的洪泛区公寓）的链条——"自然的"灾难作为**一条看不见的链条上最后一个可见的环节**。这个模型的经验证明是这个学科的寓言：**海地与智利，2010**（8.8 级的阿劳科地震——智利执行了的设计、隔震的医院、预先演练的疏散——约 500 死；7.0 级的太子港震动——没有规范、没有执行、没有演练、总统府与联合国总部倒塌——100,000–160,000 死、120 万人流离失所：**同一类灾害、不同的社会**）；**1985 墨西哥城地震**（1985 年湖床的放大摧毁了 1957 年的规范已经放弃的那些区、而市民 *topos* 的救援开创了现代的灾害非政府组织时代）；**博帕尔与拉伯克**的"技术–自然"混合（2005 得克萨斯拉伯克的龙卷风击中了一个区划在 1993 年龙卷风自己的足迹上许可了的氨厂厂址——危险设施选址的**第二次灾难**、**墨菲与"地震之后的技术灾害"**的文献）；以及**预防的悖论**（没有发生的灾难无法归功、所以预防的政治挨饿而救援的政治吃饱——仙台框架的五个目标按其自己 2023 的全球评估**没有一个在轨道上**，是这个学科最有雄辩力的文件）。这个范式的统计签名是**脆弱性曲线的陡度**：在同样的强度上，最穷的五分位在一场热浪中的死亡率、非正规居住区在一场洪水中的流离失所、学校建设工程失败了的受气旋袭击的县的儿童死亡比（2010 海地的学校倒塌、2023 摩洛哥的土坯村）——脆弱性不是灾难的一个修饰语；**它就是灾难**、而灾害是那张账单。
:::

::: example 二合一的课 {#ex-haiti-chile}
智利 2010：$M_w$ 8.8、释放的能量约是海地 $M_w$ 7.0 的 300 倍；死亡约 525 对 100,000–160,000。计算每一个的单位地震能量的死亡数与比值，而指出智利的情形演示而海地缺的三个政策工具（不是"财富"）。
::: solution
按能量归一：智利每单位约 1.8 死、海地约 4,000——在每一单位释放能量的致死性上**两千倍**的差别；三个工具：**可执行的抗震设计**（智利 1996 与 2009 的规范、使规范成为现实的大学图纸审查制度——即使从独裁到民主的过渡也保存下来的**皮诺切特时代的技术官僚的连续性**）、**强制的演练与海啸的警报链**（1985 的教训被制度化：海军的警报在 2010 年几分钟内到达海岸、2010 年疏散的成本以堵车而非生命计），以及**风险信息本身的维护**（微区划的图、震后的损害调查的能力、使重建保持有资金的再保险）——这些都不是"有钱"：**加利福尼亚、日本与智利在灾害上是穷的邻居、而在把晃动变成无的制度上是富的**。
:::
:::

## 趋势与账本

::: definition 灾害的记录：死亡下降、损失上升、灾害被重新组织 {#def-disaster-trends}
**EM-DAT** 数据库（鲁汶–新比利时的 CRED 的宣布灾害的登记、**古哈–萨皮尔与 EM-DAT 的方法**——使这个记录成为一个**政治的**以及物理的序列的宣布灾害的阈值）支持这个学科最违反直觉而最受攻击的事实：**每一次灾害的死亡在一个世纪中下降了**（1970 博拉气旋的约 500,000 对 2020 安攀气旋的约 100、在一个人口多 50% 的三角洲——预警、气旋避难所与红十字会的最后一刻的疏散在做这个工作），而 21 世纪地球物理与水文–气象事件的年死亡数**远低于** 20 世纪初的常态，即使人口增加三倍（**《我们的数据世界》**的叙事——灾害社会学的学派正确地指出它**排除**了缓慢的灾害——干旱的死亡、欧洲最致命的事件类别的热浪、**瓦格与"超额热的核算"**的批评——而**排除**了正在爆炸的**流离失所**的序列：2010–2020 年代极端天气的内部流离失所平均**约每年 2,000–3,000 万**，IDMC 与 NRC 的《国内流离失所全球报告》的账目、取代死亡成为本世纪灾害货币的那个数字）。不可阻挡地上升的是**暴露与损失**：经济的损失自 1960 年代以来按实际值增长约 5–7 倍（**克龙与瑞士再保险/慕尼黑再保险**的损失曲线——**克龙、"洪水的损失与资产的增长"**的分解显示增长的几乎全部是风险中的资产、不是灾害的加强，对洪水而言；2011 东北约 3,600 亿与 2017 大西洋飓风季约 3,000 亿的单一年度账目），而**保险的份额**（富国 30–50%、穷国低于 10%）使**经济保护的缺口**成为新的不平等指标（**瑞士再保险与"保护的缺口"**的核算：2020 年代每年约 2,000–3,000 亿的未保险损失）。气候的叠加如今是归因级的：**与天气有关的灾害占 1970 年以来 EM-DAT 事件数增长的约 83%**（**CRED 与"极值与气候"**的立场文件）、热浪的死亡率随变暖的信号上升、事件逐事件地被归因（气候变化课程的归因文献），而**复合与级联的**事件——千年干旱之后的 2019–20 澳大利亚的火季、2021 欧洲洪水的土壤饱和的先决条件、2024 贝丽尔飓风的连续登陆——是灾害的统计与气候的统计终于相遇之处（**策施勒与"并发、复合与级联"的《自然综述》综合**）。风险知情的未来是**适应缺口与全球评估报告**的算术：每一美元的预防节省 4–11 美元的应对与重建（多效益的研究：**美国国家标准与技术研究院的多灾害效益–成本研究**——美国每一美元的减灾补助约节省 13 美元——以及**全球减灾与恢复基金的事前**研究），以及联合国的**全民早期预警**倡议（2022、2027 的目标：地球上每一个人都被预警系统覆盖——历史上最便宜的大规模救命技术、而 2023 的中期评估发现它最偏离轨道）。
:::

::: example 保护的缺口、被量化 {#ex-protection-gap}
一个加勒比岛国的风险中的资产是 80 亿美元；一个五十年一遇的飓风造成 20 亿的损失；保险覆盖损失的 12%；国家的重建财政能力是 1.5 亿。计算期望的年损失、未保险的期望年损失、以及国家在一个五十年一遇的事件之后必须转用的社会支出的年数——而说出改变哪一个数字疼的两个风险转移的工具。
::: solution
期望的年损失 $= 2{,}000/50 = 4,000$ 万美元每年；未保险的份额 $= 0.88\times40 = 3,500$ 万美元每年——在期望上很小、在实现上是灾难性的：五十年一遇的事件使国家付出 18.5 亿的未保险、对着 1.5 亿的财政能力——**整个重建预算的 12 年在一个季度中花掉**、随之而来的债务螺旋（加勒比各国记录的飓风后的主权债务螺旋——债务对风险的陷阱）；两个工具：**参数保险**（CCRIF 的模型保单：按测得的风速在几天内付款、覆盖杀死恢复时机的流动性缺口）与**主权的风险池加巨灾债券**（非洲风险能力、太平洋联盟的份额配额——把一个五十年一遇的国家灾难变成一个五年一遇的区域保费的风险池化、"没有一个国家应该独自面对"的精算版本、以及为什么保护的缺口是一个**金融**的问题、不是一个灾害的问题）。
:::
:::

## 风险信息的行业

::: definition 从灾害图到损失模型：风险信息的栈 {#def-risk-information}
风险通过**铭写**被治理：灾害图、建筑规范、保险的费率、预警的信息——而生产它们的栈是这个学科现代的工业基础。**灾害填图**从确定的（设计风暴的洪水淹没模型、告诉一个城市哪一个区放大的地震微区划——墨西哥城的湖床区、西雅图盆地的效应）到**概率的**（在 50 年 2% 水平上的峰值地面加速度的 PSHA 图、锚定现代抗震规范的——**美国地质调查局的国家灾害图**工程、**GLOBAL-PSHA 与 GEM** 的全球协调努力）到**统计–动力学的**（风暴潮的集合、野火蔓延的元胞模型、欧洲各国调查的滑坡易发性图）。**暴露的清单**（建筑的存量普查——Achilles 与 GEM 的全球暴露数据库、2020 年代 OpenStreetMap 与卫星来源的足迹）与**脆弱性的函数**（风险模型行业的易损性曲线——**RMS/CoreLogic 的血统、RAMRISK 与 OpenQuake 的开源制衡**）补全这个栈、而它们的产品是**损失模型**：期望的年损失、给再保险定价的损失超越曲线、以及把统计变成有真实预算效果的准备演习的情景演练（ShakeOut 与 EuroQuake 的模拟、大西洋风暴的情景）。这个栈的治理的边缘是这一课最后的话：**风险模型行业的不透明**（治理公共安全的所有权的模型——卡特里娜之后与北岭之后的透明之争、使监管者审计黑箱的**欧盟偿付能力 II 与美国 SB 848 的模型验证法规**），**图的政治经济学**（成为一场抵押资格之争的联邦应急管理署洪水图的重新绘制、每一画出的区的财产价值的资本化——**风险信息的悖论**：图越好、它越有争议），以及**最后一公里**（预警文献既定的发现——印度与加勒比气旋工程的最后一公里的研究——技术的警告是便宜的、而**可行动的**警告（被理解的、被信任的、被有名字的人按照有名字的预先计划好的响应付诸行动的）是未解决的、人的那一半）。
:::

::: example 建一条损失超越曲线 {#ex-elt}
一个城市面对三个模拟的事件：一个十年一遇、损失 1 亿美元的事件，一个百年一遇、损失 15 亿的，一个五百年一遇、损失 60 亿的。计算期望的年损失、而用一句话解释**损失超越曲线**（概率对损失）告诉再保险人而期望的年损失隐藏了什么——以及财政部长真正需要哪个数字。
::: solution
期望的年损失 $= 100/10 + 1500/100 + 6000/500 = 10+15+12 = 37$ 百万美元；超越曲线的信息是**尾部**（五百年一遇的事件是期望的三分之一、而是整个偿付能力的问题——再保险人给百年之 250 与 500 的点定价、不是均值），而财政部长需要**财政的压力点**（预算能够吸收的损失——这里是 1.5 亿——以及把超过它的尾部移进保险与资本市场的工具）：三个数字、三个制度、一条曲线——风险信息的栈存在的理由。
:::
:::

caption: 灾害的经济损失、以指数计——在一个世纪中按实际值上升约六倍（每次事件的死亡数、未画出、在 1970 年代之后下降了三分之二）。这个背离就是这一课的全部论题：灾害没有增长那么多、**值得保险的东西**在灾害所及之处处处增长、而死亡在预警与建造所及之处下降——所以灾害的未来不是写在灾害的统计里、而是写在这本图集一再伸手去够的两个刻度上：**我们在哪里建、以及怎么建**。

::: warning 复现期不是一个承诺，"百年一遇的洪水"不是一份保证，下降的死亡曲线有三个星号，预防在政治上是看不见的，而灾害不是平稳的
五个错误。**"我们已经遇上了百年一遇的洪水，所以我们有 99 年是安全的"**：1% 的年概率没有记忆——二项式（一个世纪中 63%）与**成串**（由圣婴–南方涛动与海洋的模态驱动的洪水与干旱的序列意味着"独立的年份"的假定低估了连发、**卡茨与"复现期的成串"**的统计）使复现期成为一个**长期的平均、不是一份保修**、而设计界诚实的语言是"超越概率"、不是"复发"。**"百年的防洪意味着不会淹"**：防御的水平**不是损失的级别**（漫顶仍然淹；系统自己的失效方式——泵的电、堤的侵蚀、堵住的涵洞——有它们自己的、常常更高的概率），而卡特里娜之后的调查的核心结论是**系统在设计的以下失效**、而公众被把设计的数字当作一个安全的承诺卖了——洪水图的重新绘制与之搏斗的那个**风险交流**的鸿沟。**"死亡在下降、所以我们在赢"**：星号是**缓慢的灾害**（热浪的死亡率、干旱的间接死亡——EM-DAT 几乎不统计它们的归因）、**流离失所**的序列（每年 2,000–3,000 万、对福利要紧的那个数字）、以及**死亡曲线的公平**（下降的平均掩盖了富国内部穷人的相对死亡率上升——卡特里娜的堂区、欧洲热浪的年龄与阶级的梯度、**兰与"热的死亡的不平等"**的流行病学）；这条曲线是预警与规范一个真实的胜利、也是对尚未赢下的东西一个真实的面罩。**"预防划算、所以预防会发生"**：**预防的悖论**——被避免的灾难是不可见的、它的受益人是无法识别的、它的预算行是每一个财政周期中第一个被砍的、而同一天应对的预算是用团结的语言写的——这就是为什么仙台的目标尽管有 10:1 的效益–成本的算术全部偏离轨道、也是为什么这个学科诚实的策略是**把预防锁进规范、保险的定价与土地法**（能挺过预算周期的结构）、而不是向新闻周期恳求。**还有"历史的记录告诉我们未来的灾害"**：这一课里每一个复现期都是从一个**平稳的**序列算的、而平稳的世界已经结束——归因的科学（气候变化课程）如今给**分布的移动**定价（热浪的复现期在 1.5–2 °C 上从五十年一遇的事件塌缩成五年一遇、降雨的强度–持时曲线在设计周期的中途被改写、野火季的长度使火灾风险模型的 2020 年代重新标定翻倍），这意味着从现在起每一个基础设施的设计寿命都必须按**2075 年的气候、不是 1975 年的**来建（**美国土木工程师学会与"平稳性已死——然后呢？"**之争的实际解决：按非平稳来规划、按预测的分布来设计、而每十年重新审视规范）。
:::

::: history
现代的学科始于**洪堡与 1755 里斯本地震**的哲学冲击（《叙述》与康德的论文——第一次现代的灾害应对与第一次神正论的危机），以及**1883 喀拉喀托与 1902 培雷**的科学调查（火山学的灾害填图的诞生）。制度的时代：**1949 美国外交关系委员会的灾害研究工程**、**吉尔伯特·怀特**1945 的《人对洪水的调适》（创立这个领域的博士论文——"堤防效应"与灾害区的土地利用逻辑，早于这个词几十年）、**1970 年代十年**创立的**海外发展研究所与红十字会的灾害研究**、以及**伯顿、凯茨与怀特**的《作为灾害的环境》（1978、这个范式的宣言）。脆弱性的转折：1976 海外发展研究所的《人的脆弱性》卷（它第一次写下"灾害是自然的"），**维斯纳、布莱基、坎农与戴维斯**的《处于风险中》（1994/2004、压力与释放模型），饥荒死亡率的重新解读背后的**阿马蒂亚·森的权利分析**（1943 孟加拉与 1974 孟加拉国的死亡作为**交换权利**的失败、**森与"饥荒作为政治经济学"**的工作），以及**国际发展研究中心与"自然灾害与发展"**学派。统计：**甘伯尔**1958 的《极值的统计》、**科内尔**1968 的 PSHA、**EQUS** 的地震损失估计方法（1985）、**风险模型行业**（RMS/CoreLogic 的血统、1988–、给保险世界定价的巨灾模型）。国际的架构：**1987 贝尔格莱德原则与联合国的国际减灾十年**（1990 年代的国际减轻自然灾害十年——第一次全球"预防是可能的"运动）、**1994 横滨战略**、**2005 兵库框架**（第一批可测量的目标）、**2015 仙台框架**（四个优先事项、七个目标、2023 中期评估的全部偏离轨道的裁决）、**2015 巴黎协定的关于损失与损害的华沙国际机制**（承认剩余风险如今是一个气候适应的类别、2022 的**圣地亚哥损失与损害基金**的决定）、以及**2022 的全民早期预警**倡议——这个学科抵达这一课一再陈述的算术：灾害是物理、灾难是政策、而政策如今有一个全球的期限。
:::

::: quiz
"百年一遇的洪水"最好的定义是：
- [x] 在任何一个给定的年份中有 1% 的机会被达到或超过的洪水。
- [ ] 每一百年发生一次的洪水。
- [ ] 有史以来记录的最大洪水。
- [ ] 堤会挡住的洪水。
::: solution
它是一个**年的超越概率**、不是一张日程表——在一个世纪的独立的年份中这个事件有约 63% 的机会至少击中一次、而对它的防御不是对它的免疫：大多数洪水验尸报告的标题背后的两个混淆。
:::
:::

::: summary
灾害的风险是灾害（物理的事件、由极值的统计与 PSHA 量化）、暴露（我们放在它的足迹里的东西）与脆弱性（那些东西和人坏得多厉害）的乘积——一套语法，其中"自然"只贡献第一个因子、而海地–智利 2010 的一对以每一单位能量致死性上两千倍的差别证明它。压力与释放模型把每一次灾难的链条从政治经济学追到倒塌的教室；复现期的二项式（在设计寿命上 63%）是每一次堤防的验尸报告重新教授的算术。记录显示每次事件的死亡在一个世纪中下降——预警、规范与避难所的胜利——而损失随着我们不断添加到灾害足迹的资产上升、保护的缺口把损失集中在未保险的穷人身上、而所有这些东西据以设计的平稳的统计正随着气候一起死去。仙台的目标全部偏离轨道，因为预防是不可见的；这个学科诚实的总结是灾害是物理、灾难是政策、而最便宜的灾害是那个永远不与脆弱者相交的——这是一个决定、每一天做出或没有做出。
:::

## 练习题

::: exercise {level=1 check="50"}
求一个年超越概率 2% 的事件的复现期（年）。
::: solution
$T = 1/0.02 = 50$ 年——平均的复发间隔、不是一张日程表。
:::
:::

::: exercise {level=1 check="100"}
按定义说出"百年一遇的洪水"的复现期（年）。
::: solution
**100 年**——1% AEP 的事件；公众读作一个承诺、而工程师读作一个概率的那个数字。
:::
:::

::: exercise {level=1 check="0.24"}
用 $R = H\times E\times V$、$H=0.8$、$E=0.6$、$V=0.5$，求风险的指数。
::: solution
$0.8\times0.6\times0.5 = 0.24$——而把任何一个单一的因子归零就把乘积归零：这个方程是预防的证明。
:::
:::

::: exercise {level=1 check="63.4"}
求百年事件在 100 年中至少发生一次的百分概率。
::: solution
$1-0.99^{100} = 63.4$ 百分——一个指数中的设计寿命的陷阱。
:::
:::

::: exercise {level=2 check="39.5"}
求在一个 50 年的堤的寿命中至少一次 1% AEP 的洪水的概率（百分）。
::: solution
$1-0.99^{50} = 39.5$ 百分——在设计寿命内设计标准被达到或超过的五分之二的机会。
:::
:::

::: exercise {level=2 check="40"}
求一个 20 亿美元的五十年一遇的损失的期望年损失（百万美元）。
::: solution
$2{,}000/50 = 40$ 百万美元——与保费相关的期望；灾难是方差、不是均值。
:::
:::

::: exercise {level=3 check="35"}
对那个岛的例子（期望的年损失 4,000 万、保险 12%），求未保险的期望年损失，以百万美元计。
::: solution
$0.88\times40 = 35$ 百万美元——风险转移的工具把它变成一个保费的每年期望的失血。
:::
:::

::: exercise {level=3 check="12"}
那个岛国有 18.5 亿的未保险的百年之 50 的损失、与 1.5 亿的年重建能力。求这个事件消耗的能力的年数。
::: solution
$1{,}850/150 \approx 12$ 年——债务螺旋的算术、以及用一道除法写出的参数池的论据。
:::
