每一个古气候的声称都藏着一个日期、而每一个日期都藏着一场争吵。"二氧化碳在温度之前上升"——多久、而当两个信号都带着千年的年龄的不确定时你如何*知道*哪个先来？"事件持续了两个世纪"——那是一个气候的灾难还是一个调得坏的岩芯？古气候的第二门学科——在代用指标的物理之后——是**地质年代学**、而它的历史是一系列从物质中偷时间的发明：滴答是核的常数的放射性的时钟、能像页一样数的年的层、跨大陆把记录绑在一起的化学的指纹、而像把收音机调到载波一样调谐沉积物的轨道的循环。规则是不宽容的——每一个时钟都有一个范围、一个闭的系统的假定、而它自己的校准——而这门学科的诚实由它把它的误差条印多响来衡量、因为古气候问的问题（超前–滞后、因果、变化的速率）都是关于**日期之间的差**的问题、在其中的不确定相加而不抵消。

## 放射性的时钟

::: definition 衰变、放射性碳、而其他的时钟 {#def-radiometrics}
放射性的测年建立在一个指数上：$N = N_0 e^{-\lambda t}$、半衰期 $t_{1/2} = \ln2/\lambda$、而闭的系统的要求——样品自形成以来既没有获得也没有失去母体或子体。对气候第四纪科学重要的时钟有四个。**放射性碳（¹⁴C）**：宇宙射线在平流层制造 ¹⁴C、它氧化成二氧化碳而进入碳的循环、而每一个生物携带大气的比直到死亡、在死亡时 ¹⁴C 开始衰变（半衰期 5730 年；年龄"按惯例"对着更老的 5568 年的利比值报告、而对着的分馏校正——读者必须总是检查的一个惯例）。范围是约 50,000 年（过五或六个半衰期信号淹没在机器的本底中——虽然加速器的质谱数原子、不衰变、而推进边界）、而材料是任何交换过碳的东西（木头、木炭、壳、泥炭、珊瑚、有孔虫、而冰的包裹的二氧化碳）、而陷阱是一门课程：一个百分比的现代的碳的污染使一个 40-kyr 的样品年轻 6 kyr；"老的碳"的效应使硬的水的壳与火山区的植物显得几千年的古老；**储层的年龄**使海洋与湖的碳读得比喂养它的大气老几个世纪到几千年；而大气的 ¹⁴C/¹²C 的比**从未恒定**（生产随地磁的场与太阳风变化）、这就是为什么放射性碳的年不是历法的年、而为什么校准的曲线存在。**铀–钍**：²³⁴U 衰变成 ²³⁰Th（半衰期 245 kyr）、它不溶而在形成的碳酸盐中不存在、所以子体的生成直接给壳或洞穴测年——±几十年到几个世纪的精度到约 500 kyr、石笋、珊瑚、而锚定最后的冰期的循环的铀钍/放射性碳的相互校准的计时器。**氩–氩**：⁴⁰K 到透长石与黑云母中的 ⁴⁰Ar、火山灰的计时器——一个单一的火山玻璃的碎片、⁴⁰Ar/³⁹Ar 测年到 ±0.1%、能固定一个百万年的灰的层、跨一个大陆绑定海洋的岩芯、湖的沉积物、而冰。**锆石上的铀–铅**、十亿年的骨干、给别的课读的深时的剖面测年。
:::

::: example 放射性碳的算术 {#ex-frc}
木炭给出一个 11,460 ¹⁴C yr BP 的按惯例的放射性碳的年龄。用物理的半衰期 5730 年、求剩余的 ¹⁴C 的分数、而解释为什么校准的历法的年龄对于最后的冰期的大部分**更年轻**于 11,460 历法的年。
::: solution
11,460 年是两个物理的半衰期、所以 $(1/2)^{2} = 0.25$——原来的 ¹⁴C 的四分之一。历法的年龄的校正朝另一个方向运行、因为冰期的大气持有**更多**的 ¹⁴C（更强的地磁的屏蔽更弱、生产更高）：一个冰期的样品以更多的钟的燃料开始、所以它的真实的历法的年龄比它的放射性碳的年龄更年轻——IntCal 曲线的工作恰恰是这个映射、而这个练习的真正的教训是放射性碳的年与历法的年在 30 kyr BP 相差多达约 6,000 年、足以把一个整个的冰期的事件按一个相位测错年。
:::
:::

## 校准与地层的时钟

::: definition IntCal、层、指纹、反转、而轨道 {#def-stratigraphic-clocks}
**校准**：放射性碳对着 **IntCal** 转换成历法的年、一个由独立地测年的记录建立的团体的曲线——树轮的年代学（在德国的松树与狐尾松的序列中数到 13.9 kyr 的数的树的年轮、由漂浮的年代学延伸）、有纹泥的湖与海洋的沉积物、铀钍测年的珊瑚与石笋、而每一个中测量的放射性碳自己、而带着海洋的曲线（Marine20）带着区域变化的储层的校正、而南大洋的千年的标度的偏移是对每一个冰期的年代学的常存的警告。曲线的摆动在自己有用了：**摆动的匹配**把一系列测年的放射性碳的年龄匹配到 IntCal 的上下能把一个考古的地点或一个火山灰测年到一代人、而**炸弹的脉冲**——热核的试验到 1963 年把大气的 ¹⁴C 增加了一倍、而 1963 之后的下降是一个精确到一年的日期代码——给酒、象牙、法证的遗骸、而珊瑚与牙齿的生长层以一个没有自然的时钟比得上的准确度测年。**层的计数**：纹泥（夏与冬的湖的沉积物的年的对子、在纹泥的类型的湖上连续地数到 100+ kyr、而瑞典的德哈尔与芬兰的冬的沉积物的传统的骨干）、年的冰的纹层（下一节）、而珊瑚自己的带。**火山灰年代学**：火山玻璃是一个化学的条形码——主要的、微量的、而同位重的指纹把碎片匹配到一个命名的喷发、而著名的层（186 年的**陶波**的火山灰、由树的年轮与冰的硫酸盐测年；米诺斯的**阿尼亚克查克/圣托里尼**的争论；维德火山灰与把艾菲尔的火山作用与一个格陵兰的气候的事件绑定的 13-kyr 的拉阿赫的火山灰）成为将记录同步到一个人的寿命之内的等时的线。**磁性地层学**：沉积物在它们沉降时锁住场的极性；在 0.78 Ma 的松山–布容的反转与更短的事件（在约 41 ka 的拉尚、在冰与熔岩中同样测年）给几百万年的剖面粗而明确的极性带。**轨道的调谐（天体年代学）**：进动与斜度是钟的机构——它们的周期（23.7、22.1、19.1、405 kyr）从天文的解知道——所以把一个沉积物或冰的循环的格局匹配到轨道的模板把天文的精度转移到放射性的范围之外的记录、LR04 的海洋的堆栈的 5.3-Myr 的年代学与古新世–始新世的边界的 2013 的天文的重新校准背后的方法、它的循环性（假定气候响应于你调谐到的轨道）是这门学科最有纪律的假定、由解决歧义的 405-kyr 的偏心率节律计辩护。
:::

::: example 储层与最老的碳 {#ex-reservoir}
一个海洋的壳以 4,300 ¹⁴C yr BP 测年、带着一个 400 年的区域的储层的年龄；同一个的海滩的脊的一个陆地的木炭测年 3,900 ¹⁴C yr BP。显示这一对是内部一致的、而求如果壳读 5,400 而木炭读 3,900 暗示的储层的年龄。
::: solution
储层的一致：壳 $= 3900 + 400 = 4300$ ✓——壳从上升的海洋继承了 400 年的"老的"碳。第二个案例暗示 1,500 年的储层的年龄、一个上升流的强度的签名自己（东的边界的流运行 1,000–2,000 年）、而配对海洋–陆地的日期是*测量*过去的储层的年龄、不是假定它们的标准的方式的原因。
:::
:::

## 冰、而五万年的赛跑

::: definition 冰芯的年代学与深时的调谐 {#def-ice-chronology}
冰芯带着它们自己的层——在多尘的冬与干净的夏的雪的对子、在浅的岩芯中可见到毫米、在电的导率与尘土的记录中在更深处可分辨——而**层的计数**（可见与化学的年的循环的累计）给出最后的冰期的金标准的年代学：**GICC05**、通过数 60,000 年的层穿过最后的冰期而建造的格陵兰的冰的年代学、在 60 kyr 带着声明的几个世纪的计数不确定——每一个北大西洋的事件对着它计时的参考的时钟、而把下一课的突然的事件测年到人的标度的精度的仪器。在可数的之下（流动把年的层变薄到分辨率之下、而冰在底部混合）、年代学变成**流动的模型**：冰的厚度、积累、而变形在深度上积分、由与测年的喷发匹配的火山硫酸盐的尖峰、由记录在冰的自己的尘土的组构中的场的反转、而由气–冰的年龄的物理（在封闭的孔隙中包裹的空气比持有它的冰年轻、差是粒雪封闭的差、在冷的地点多达 800 年——一个对二氧化碳–温度的超前–滞后的争论极其重要的校正）。深的南极的冰芯（欧洲冰芯计划的康科迪亚站到 800 kyr、而最近的"超越欧洲冰芯计划"的延伸）靠它们的同位素与尘土的循环的轨道的调谐加上气的相的相关来测年、而最老的可回收的冰（约 1.5–2 Myr、在小康科迪亚与"蓝冰"的搜寻的区域寻求）将几乎完全靠天文学与化学来测年。在冰之下而在 50 kyr 放射性碳之外、深海的海洋运行在轨道的节律计与它的火山灰的氩上；大陆运行在铀钍、光释光（埋藏的沙的发光的光的时钟、约 200-kyr 的范围）、而火山灰的网络上；而大的交叉的检验——铀钍测年的珊瑚对放射性碳、树的年轮对纹泥、冰的硫酸盐对氩测年的火山灰——是使整个的古的时间标度成为一个一致的、虽然永久地修订的日历的互锁。
:::

::: example 数格陵兰 {#ex-gicc05}
GICC05 数约 60,000 层到 60 kyr、在底部带着声明的约 1,200 年的不确定（积累–变薄的模型化、一些段落以低置信度计数）。如果伯尔林的增暖的开始在同一个计数中的 14,642 ± 4 b2k、求单由年代学暗示的两个记录的事件的计时的可能的最大的滞后、而声明的 ±4 为什么不是相关的真正的不确定。
::: solution
开始的*地层的*精度（±4 个数的年）极好、而把一个*海洋的*或石笋的记录与它相关要引入那个记录自己的年龄的误差——通常是几个世纪到几千年——所以诚实的滞后的不确定是平方和的平方根、由伙伴的记录主导。这个练习是整个超前–滞后的文献的第一定律：**跨记录的事件的相关受更坏的时钟与相关的点限制、不受那个漂亮的时钟限制**——这就是为什么这个领域把钱花在共享的等时的线（火山灰、硫酸盐）上、不是花在更多的计数上。
:::
:::

## 年龄–深度的统计

::: definition 年龄–深度的模型与贝叶斯的年代学 {#def-agemodel}
在测年的点（放射性碳的年龄、火山灰、数的层、调谐的循环）与气候的曲线之间躺着**年龄–深度的模型**、而这个领域已经以艰难的方式学到了这个插值的步骤是名声死去的地方。在相邻的日期之间的天真的线性的插值以三个已知的方式有偏：沉积的速率是自相关的（真实的速率漫游、它们不跳）、测年的误差常常是非高斯的（老的碳的污染朝一个方向歪）、而采样恰好在变化快的地方稀疏。现代的答案是**贝叶斯的**：在 OxCal 与 Bacon 的谱系中的程序把积累速率的平滑与记忆的先验放置、折叠进每一个日期的似然、而返回的不是一个年龄、而是在每一个深度的一个**后验的分布**——带着关键的输出是每个事件的年龄的 95% 的置信的区间与模型自己的诊断（日期与平滑的先验争吵多少、数据拒绝哪一个点）。气候的论文能如何说话的后果现在被编纂：超前–滞后的声称必须比较**重叠的置信的区间**、不是最佳拟合的线；事件的持续时间必须超过年代学的分辨率才能被声称（在一个带着 800 年的置信的区间的岩芯中的一个"百年的事件"是一个等着审稿人的伪迹）；而模型的相互比较——同一个岩芯上的 Bacon 对线性的对轨道的调谐——是每一个严肃的年代学现在报告的便宜的稳健的检验。最深的教训是认识论的：年龄的模型是一个**统计的反问题**、而像它们所有的它的回答含着它的先验——这就是为什么这个领域像高能物理印系统的误差那样印先验、而为什么"年代学就是论文"是一句赞美。
:::

::: example 置信的区间决定争论 {#ex-credint}
一个石笋的氧同位重的移动测年在 16.0 ± 0.4 ka（95%）、而它被声称"触发"的海洋的同位重的转变测年在 16.3 ± 0.6 ka。求年龄的差与它的不确定（平方和的平方根）、而陈述两个记录能与不能声称什么。
::: solution
差 $= 0.3$ kyr、带着不确定 $\sqrt{0.4^{2}+0.6^{2}} = 0.72$ kyr——这个偏移**小于它自己的误差条的一半**、所以记录与同时一致、而不能支持任何因果的排序。这个练习是一个平方根中的超前–滞后的文献的审稿人的规则："A 在 B 之前"要求差超过大约两倍的平方和的不确定、而大多数出版的排序的声称之所以幸存、只因为共享的等时的线（火山灰、相关的点）缩小了误差、不是因为中心的日期相距很远。
:::
:::

::: warning 每一个时钟都有一个范围、一个闭的系统、而它自己的校准——而日期不是年龄
五个错误。**"那一层有 30,000 年"**：它是一个依赖模型的估计、带着一个声明的不确定、在一个声明的时间标度上（放射性碳的年？历法的年？b2k？带哪一个半衰期的 ka BP？）、来自一个它的情景（再搬运？老的碳？生物扰动的？）是真正的论证的样品——没有元数据的数字是噪声。**"铀钍与放射性碳不一致、所以一个是坏的"**：它们给不同的东西测年（碳酸盐的形成对比从一个储层固定的碳）、而不一致通常是科学——储层的年龄、死的碳的分数、石笋中的开系统的铀的迁移（迫使冰期的循环的年代学诚实地放大误差的"铀钍的麻烦"）。**"轨道的调谐是循环的"**：它在一种意义上是——你假定气候由轨道决定步调——而 405-kyr 的偏心率节律计、它的周期稳定而目标的循环不稳定、像一个长的波长的干涉仪打破歧义那样打破循环性；这个领域的判决是调谐的时间标度是可得的最好的、而它们的残留的误差被量化、不被忽略。**"更多的小数位 = 更好"**：最坏的年龄的模型的罪是印年代学不能承担的精度——一个贝叶斯的年龄的模型的 95% 的置信的区间、不是它的均值、是结果、而超前–滞后的声称必须用区间、不是每一个图画的中心的线。**而"测年是解决了的"**：这个领域的最大的修订是测年的修订——地磁的极性的时间标度的 2012 的重新校准、古新世–始新世的边界的 2013 的天文的重新校准（移动年龄约 800 kyr、而迫使对古新世–始新世的极暖期与撞击的相符的重新思考）、圣托里尼的喷发的日期的战争（公元前 1600 年代对比 1500 年代、在细节中仍未解决）——而这个图集中的每一个"已知的"年龄都应该被读作当前的网络的当前的最佳拟合、以它一直被改善的方式改善：由更好的时钟找到彼此的错误。

::: history
**威拉德·利比**发明了放射性碳（1946、建立在**弗朗茨·里尔**的宇宙射线应该在大气中制造 ¹⁴C 的洞见上）、在已知年龄的埃及的墓上证明了它、而拿了 1960 的诺贝尔奖；他的校准时代的后继者——**汉斯·修斯**的狐尾松的曲线（他发现了带他的名字的树的年轮的偏移、而几十年后、也带他的名字的化石的燃料的稀释）、IntCal 的合作的现在第五代的团体的曲线、而 Marine20 的海洋的曲线——把一个放射性的时钟变成了一个日历。**格利特·德哈尔**在 1910–1920 年代创立了纹泥的计数（而他的家族的年代学在瑞典的纹泥似乎把冰期压缩进一个太短的跨度时壮观地过度延伸——这个领域仍然引用的一个警告的过度延伸）；火山灰年代学从 1960–70 年代对黄石与喀斯喀特的火山灰的工作生长成现代的相关的等时的线的网络；而**地磁的极性的时间标度**——建立在 1963 的温–马修斯的洋底的扩张的反转的条纹上、而通过肯特–格拉德斯坦的编纂精炼到 2012 的重新校准——给了洋底它的条形码。**唐斯高**在 1960 年代在世纪营与他的同位素一起数了第一年的冰的纹层；格陵兰的冰芯与 GICC05 的计数的传统（**松恩·奥兰德·拉斯穆森**与同事、2006）把层的计数带到 60 kyr、而**克劳德·雷诺**与**让-罗贝尔·巴尔诺拉**在拜尔德的气的工作开始了冰期的二氧化碳的故事、它的测年的精炼仍驱动超前–滞后的争论。贯穿的线：每一代的日期是下一代的代用指标。
:::

::: quiz
一个海洋的放射性碳的日期的"储层的年龄"是：
- [ ] 壳在死之前活的时间。
- [x] 在生物固定它之前几个世纪就离开大气的碳获得的表面的年龄。
- [ ] 对海洋的盐度的衰变的校正。
- [ ] 利比与物理的半衰期的差。
::: solution
海洋的内部碳几个世纪到几千年没有大气的接触、所以表面的水（与其中的壳）以"老的"开始；储层的年龄平均约 400 年、在上升流的区域超过 1,000、而必须被减去——或用配对的陆地的日期测量——在海洋的放射性碳变成历法的时间之前。
:::
:::

::: summary
地质年代学是古气候的第二门物理：指数的时钟（放射性碳到 50 kyr、铀钍到 500 kyr、氩–氩与铀–铅在之外）、数的层（年轮、纹泥、冰的对子——GICC05 的 60,000 格陵兰的年）、化学的等时的线（火山灰的条形码、硫酸盐的尖峰、炸弹的脉冲）、而调谐放射性的测年不能触及的一切的天文的节律计。每一个时钟都有一个范围、一个闭的系统的假定、而它自己的校准、而这个领域来之不易的礼仪——置信的区间在中心的值之上、配对的日期在假定的储层之上、共享的等时的线在目测的相关之上——存在因为问题是关于日期的*差*。今天的日期是明天的代用指标：这个领域的最大的热门是测年的修订、而它的常存的邀请是在相信曲线之前检查年龄的模型。
:::

## 练习题

::: exercise {level=1 check="0.25"}
求两个半衰期之后剩余的 ¹⁴C 的分数。
::: solution
$(1/2)^{2} = 0.25$——四分之一、11,460 物理的年的算术。
:::
:::

::: exercise {level=1 check="900"}
一个壳的表面的放射性碳的年龄是 1,300 年、带着一个 400 年的储层的校正。求它的真实的年龄。
::: solution
$1300 - 400 = 900$ 年——储层的减去是记账、不是意见。
:::
:::

::: exercise {level=1 check="50000"}
以年陈述放射性碳的近似实际的测年的极限。
::: solution
约 **50,000** 年（带着加速器的质谱的本底约九个半衰期；在那之外、铀钍、光释光、而轨道的节律计接管）。
:::
:::

::: exercise {level=1 check="1963"}
在哪一年北半球的大气的炸弹的 ¹⁴C 达到峰值？
::: solution
**1963**——武器的试验的尖峰的峰值、它的上升与下降的形状把二十世纪的组织测年到一年。
:::
:::

::: exercise {level=2 check="75700"}
²³⁰Th 的生成的测年使用一个 75,700 年的半衰期。求一个它的 ²³⁰Th/²³⁴U 的活度的比恰好达到长期的平衡的一半的碳酸盐的年龄。
::: solution
一代半衰期的生成：**75,700** 年——铀钍的时钟的签名的滴答、而这个方法带着石笋的精度覆盖最后的几个冰期的循环的原因。
:::
:::

::: exercise {level=2 check="60"}
一个光释光的样品有一个 120 Gy 的当量的剂量与一个 2 Gy kyr⁻¹ 的环境的剂量的速率。以 kyr 求埋藏的年代。
::: solution
$120/2 = 60$ kyr——发光的时钟的范围恰好覆盖放射性碳与铀钍之间的第四纪的中部的缺口。
:::
:::

::: exercise {level=3 check="1500"}
一个海洋的壳读 5,400 放射性碳的年、而它相关的陆地的木炭读 3,900 放射性碳的年。求暗示的储层的年龄。
::: solution
$5400-3900 = 1500$ 年——一个上升流的签名、测量的、不是假定的。
:::
:::

::: exercise {level=3 check="800"}
在冷的南极的粒雪中、在封闭的气–冰的年龄的差能达到什么值（年）？
::: solution
约 **800** 年——气滞后冰、而每一个二氧化碳–温度的超前–滞后的声称必须在声称因果之前为它校正。
:::
