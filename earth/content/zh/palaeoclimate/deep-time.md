全新世、带着它可靠的季风与它的 280-ppm 的天花板、是地球系统的一个心情——而记录中最不典型的一个。在动物壳的五亿四千万年中、行星把它的时间的大部分作为**温室**度过：没有永久极的冰、鳄类在北极圈之上繁殖、海平面比今天高一百米、大气的二氧化碳在几千。它作为**冰室**颤抖过好几次、而至少两次——在新元古代、而在之前也许——它似乎**一路冻到赤道**、一个白色的行星、一个只在冰之下的蓝的海洋、它的火山花了几百万年泵二氧化碳、直到温室以地质上突然的方式打破冰。在这些心情之间系统抛出更快的事件：古新世–始新世的极暖期、在不到两万个千年中 5,000–10,000 吉吨的碳进入循环、灭绝跟随深海、而棕榈树殖民南极的海岸——与现在运行的这个世纪最近的地质的类似物、而深时的古气候不再是古董的原因。这一课是心情的目录：世界看起来像什么、什么强迫它们、而这些转变对我们正在编辑的那一个说什么。

## 温室的世界

::: definition 中生代–古近纪的温室与它们的争论 {#def-greenhouse-worlds}
白垩纪（145–66 Ma）与古近纪（66–34 Ma）是典型的温室的状态：远离今天的大陆的配置（南大西洋是一个海道、印度在途中、南极–澳大利亚还楔着）、没有极的冰盖（有着可能的最晚白垩纪的冰川作用的例外、仍从同位素争论）、海平面比现在高 100–250 m、而一半的大陆被浅地淹没（西部内陆海道、欧洲的陆表的海洋）、而二氧化碳的估计——从硼、烯酮的碳同位重、气孔、碳酸盐、而硼硅酸盐与古土壤的系统——聚集在 500–2,000 ppm、而白垩纪的高的端（4,000 ppm、海洋的高原的火山作用）在这个领域中是最有争议的数之一。争论是物理所在：**高的纬度的暖**（在 75–85° 的古纬度的年均的深时的温度的 10–15 °C、从化石的鳄、落羽杉的森林、而团簇的同位素）要求极端的极的放大或一个不同的热输送的状态、而**热带海表面的温度的争论**——团簇的与镁钙的代用指标曾经读 35–40 °C（接近生理的天花板）、而 2020 年代的硼、TEX86 的重新评估、而有孔虫的群落的证据读一个更适度的 29–32 °C——在很大上**反对**温室的热带解决、留下一个比任何一个模型再现的更低赤道到极的梯度："白垩纪–古近纪的气候的问题"现在诚实地是一个**直减率与云的问题**（潮湿的、低云主导的、带着弱的季节性的热带）、而它仍是我们模型能不能做远离全新世的边界条件的最尖锐的检验。**早始新世的气候的最优期**（约 52–50 Ma、古新世–始新世的极暖期的更大的兄弟：暗示 10–12 °C 的深的水、北极没有霜、可能没有永久的南极的冰的有孔虫的氧同位重）是最暖的新生代的状态与敏感性的端元；**满江红的事件**（约 49 Ma、巨大的淡水的蕨的水华在新隔离的北冰洋中埋藏碳、被提议作为即将到来的长的变冷的一个扳机）与环南极的流的慢的建造完成向 34 Ma 的冰室的阈的弧——始新世–渐新世的转变、在二氧化碳穿过**约 750 ppm** 的门落下（阿纳格诺斯托与同事在硼中测量）而南极在几十万年之内永久地长出它的冰盖。
:::

::: example 直减率的杠杆 {#ex-lapse}
一个带着的二氧化碳加倍的白垩纪的模型只在赤道到极的表面的梯度减半时再现极。取热带在 30 °C、而极在 12 °C（现代的：30 与 −18）。如果热带的增暖是 +3 °C、而极的放大是全球的均值的 2 倍、求之前与之后的梯度、而解释为什么为白垩纪的梯度援引的是**湿的绝热的**热输送与低云、不是单独的额外的二氧化碳。
::: solution
现代的梯度 $30-(-18) = 48$ °C；白垩纪的 $30-12 = 18$ °C——现代的三分之一、由一个暖的极、不是一个凉的赤道达到。二氧化碳的加倍在**模型**中把极的区域暖得更多、而从不是需要的 30 °C；需要的状态是一个接近**湿的绝热线**运行的对流层（直减率约 5 K km⁻¹、不是现代的高的纬度的 8–9）、它在上面把表面的暖耦合而强迫弱的静力的稳定、加上捕获冬的热的光学上厚的低云——它们的参数化恰恰是深时的模型的相互比较检验的东西、而代用指标（拉拉米的团簇的同位重的古高程学、TEX86 的季节性）现在最用力推的机制。
:::
:::

## 冰室的世界与它们的扳机

::: definition 四个冰室的状态与碳的联系 {#def-icehouse-worlds}
地球至少被冰川作用过五次、而扳机的格局有教益的。**休伦的**（2.4–2.1 Ga、可能多次冰川作用到低的纬度）跟随大氧化事件：甲烷——太古代的强的、短命的温室——被新的氧氧化掉、而一个暗 20% 的太阳做了其余的；第一雪球、如果它们是雪球、是一个警告：**温室的预算在一个微量的气体被移除时能崩溃**、与故意的现代的排放的倒转的最直接的深时的类似。赫南特的（奥陶纪的末、445 Ma）的冰川作用是最短而最怪的：一个完全的冰期、海平面的下降、而一个在其他方面是温室的显生宙的峰值的大灭绝、由不同的团体与塔科尼的造山的爆炸的弧的风化、深根的而掘的**陆地的植物**的出现加速大陆的风化（2020 年代的生物的风化的案例、带着它自己的异议的文献）、而冈瓦纳在南极之上的古地理学联系。**晚古生代的冰期**（360–260 Ma）是陆地的植物的冰期在它的全然的表达中：石炭纪的煤的沼泽与根渗透的大陆把碳拉下（煤自己是储存的拉下）、二氧化碳落到冰期的值、冈瓦纳的冰生长、而同样的沼泽的有机的碳的埋藏留下**氧的偏移**（约 30–35% 的氧——巨大的蜻蜓巨脉蜻蜓与 70-cm 的马陆呼吸 35% 的空气的时代）、昆虫的记录直接地读它。**新生代的冰室**（34 Ma–现在）是我们居住的：先是南极（通过 750-ppm 的门）、北半球后来（格陵兰的桥的关闭、地峡的升起、2.7 Ma 的强化的 41-kyr 然后 100-kyr 的循环——轨道的循环的一课的主题）、而每一个冰期是一个提醒：当前的状态是**双峰的**：冰期与间冰期不是反常、而冰室的两个稳定的模式、全新世是暖的模式、而人类世、可以说、是第三个。从休伦的到全新世的一贯的线是同一个变量：**二氧化碳设定心情**——750 ppm 为了南极的冰川作用、180–280 ppm 为了冰期–间冰期的摆动、425 ppm 而上升为了当前的扰动——而深时的记录是唯一一个测量了气候在整个的范围上的响应的实验。
:::

::: example 微弱的年轻的太阳与它的解决 {#ex-fys}
太古代的太阳发出今天的流的 70%。带着今天的反照率（0.30）与温室、地球的平衡的温度会是约 −15 °C、不是 15 °C——一个 30 °C 的亏缺。估计需要的额外的温室的强迫（用 $\lambda = 0.8$ K per W m⁻²……等价地 $F = \Delta T/\lambda$）、而把它表达为对现代的 390 W m⁻² 的自然的温室的二氧化碳等价的乘数。
::: solution
$F = 30/0.8 = 37.5$ W m⁻² 的额外的强迫——大约**入射的太阳的束的十分之一**、能由几个% 的二氧化碳（它的饱和的带在高浓度下使它便宜）加上一个烃的霾供给、它的 2010 年代的光化学的模型发现是足够的、如果有的机物的霾是对的；这个悖论被认为由一个气体不解决、而由**碳酸盐–硅酸盐的恒温器的耐心**（低的太阳的流 → 慢的风化 → 高的二氧化碳）与甲烷的贡献解决——表面的能量的平衡是一个能解的记账的问题的深时的证明、即使对没有冰的芯的行星。
:::
:::

## 雪球地球与碳的循环的刹车

::: definition 冰–反照率的失控、火山的救援、帽的碳酸盐 {#def-snowball}
**雪球地球**的假说——斯图特的（717–660 Ma）与马里诺的（650–635 Ma）的冰川作用到达赤道、在低的纬度有开阔的水或薄的冰——建立在三个观察与一个机制上。观察：**古赤道**的纬度的冰川的沉积（下降的石头、冰碛岩）、来自古地磁约束的剖面（纳米比亚、斯瓦尔巴、死亡谷、中国——**约瑟夫·基尔施温克**的工作、他在 1992 年命名了这个假说、而**保罗·霍夫曼、丹·施拉格**与同事的 1998–2000 的纳米比亚的样带使它成为一个纲领）；**帽的碳酸盐**——带着独特的沉积的结构与负的碳同位重的米级的白云岩、覆盖每一个大陆的冰川的沉积、被解释为极端的温室、碱度的洪水淹没的冰后的海洋；而斯图特的与马里诺的**条带的铁的建造**（拉皮坦的与同类的）、它们在 18 亿年的缺席之后回到沉积的记录暗示冰之下的缺氧的、富铁的海洋的水。机制是作为**一个单向的门的冰–反照率的反馈**：一旦冰到达赤道的太阳、行星的反照率（约 0.6）超过即使赤道的夏也不能融化它的阈、而唯一的逃脱是地质的——火山作用继续（冰之下的中部的裂、而几乎停止二氧化碳的拉下的风化刹车）**几百万年**、直到二氧化碳达到几十个百分点（经典的模型需要 0.1–0.4 bar）、而温室在也许几千年中引爆消冰、记录为帽的碳酸盐的化学的冲击。生物的尾声是这个领域最诱人的论证：埃迪卡拉的生物群的辐射、而可能的新元古代的氧的上升、跟随马里诺的融——冰川作用作为物种形成的过滤器仍有争议、而**加斯凯尔**（580 Ma）与其他雪球地球的时代的"之间"的冰川作用使实验的重复的统计有趣。雪球地球、最终、是这个学科的碳的循环的恒温器是**双稳态的**的证明——同一个行星能持有两个根本不同的能量的平衡——而"临界点"在是一个政策的词之前很久是一个地质的词的原因。
:::

::: example 用火山打破冰 {#ex-snowball-co2}
一个在 635 Ma 的雪球地球接收比今天少 6% 的阳光、有一个 0.62 的反照率（对比今天的 0.30）、而必须暖约 45 °C 来清除赤道。用 $\lambda = 0.8$、求需要的强迫、而如果它全是二氧化碳的二氧化碳的水平（用 $\Delta F = 5.35\ln(C/C_0)$、以 $C_0 = 280$ ppm）。
::: solution
单反照率的亏缺是 $0.5\times1360\times0.94\times(0.62-0.30) \approx 137$ W m⁻²；需要的增暖加 $45/0.8 = 56$ W m⁻²、所以总的 $\approx 190$ W m⁻²、而 $C = 280\,e^{190/5.35}$——天文学地荒谬、这就是要点：**没有一个对数的气体在这些剂量上工作**；真实的逃脱使用完全的辐射的传输的非线性（二氧化碳的带、在 350+ K 的水汽的反馈、甲烷）而经典的模型的 0.1–0.4 bar 的二氧化碳的值——工业化前的 150–400 倍——供给它。这个练习教为什么雪球的论文做完全的辐射的传输、而为什么帽的碳酸盐的铀与锶的同位重的异常（在融中的 10–100 倍现代的风化的速率）恰恰是那个温室的地化学的签名。
:::
:::

## 古新世–始新世的极暖期：深时的快车道

::: definition 古新世–始新世的极暖期 {#def-petm}
**古新世–始新世的极暖期**（55.9–56 Ma、典型的超热事件）是深时的记录的最良好地解析的快的碳的循环的事件：在海洋与陆地的剖面中 3–6‰ 的负的碳的同位重的偏移（全球的、在也许 4,000–20,000 年中完成的）、一个 5–8 °C 的增暖（热带的海表面的温度 +4–5 °C、高的纬度更多）、一个**底栖的有孔虫的大灭绝**（深海的物种的 30–50%——唯一已知的显生宙的软的底质的深海的生命的灭绝、来自变暖和碳酸盐腐蚀的深的水）、一个陆地的革命（现代的哺乳动物与植物的目在两个大陆上的首次出现、一个干旱化的脉冲）、而海洋中的一个碳酸盐的淹没与粘土的积累的尖峰——全都跟着同位素基础的**约 100–200 kyr 的恢复**、可见的碳的循环的停留的时间的时钟。碳：**5,000–10,000 GtC** 释放（同位重的偏移的质量平衡）、以约 0.3–1 GtC yr⁻¹ 持续的——一个把今天的 10 GtC yr⁻¹ 的化石的流在一个错误的方向上按一个数量的级括起来的速率——来自一个自己碳 13 轻的源：**甲烷的笼形物的释放**（经典的、现在被同位重的质量平衡与模拟降级：笼形物单独不能在留下其他的签名之外供给碳）对比**火山作用**——北大西洋的火成的省的岩床的省侵入富有机物的与蒸发岩的沉积、接触的变质释放热成的甲烷与二氧化碳（**斯文森、普兰克**与同事的假说、现在是共识的中心）——是这个领域最长的取证案、而它的解决（火山的扳机、可能的笼形物的放大器）是一个多同位重的质量平衡的大师课（碳同位重、氧同位重、锇、汞的异常作为火山的示踪剂、放射性碳不可得、当然、在 56 Ma）。古新世–始新世的极暖期的现代的重要性是精确的、不是修辞的：它是唯一一个带着 (i) 一个已知的碳的流、(ii) 一个测量的气候与灭绝的响应、而 (iii) 一个**酸化签名**（深海的碳酸盐的溶解的层位、底栖的灭绝的可能合著者）的地质的事件、而它的教训——对深海速率比峰值更重要、恢复花 100,000 年、生物的损害跟踪步调——是现在正在收集的那些。
:::

::: example 古新世–始新世的极暖期的碳的预算 {#ex-petm-carbon}
古新世–始新世的极暖期的碳的同位重的偏移是 −4.5‰；加入的碳约是 −60‰（甲烷/热成的）、对着约 0‰ 的沉积的交换的背景；可交换的表面的碳的储层（海洋 + 大气 + 软的生物圈）约是 40,000 GtC。估计碳的释放、而它的平均的速率（在 10 kyr 上）与现代的化石的流 10 GtC yr⁻¹ 比较。
::: solution
质量平衡：$f = 4.5/60 = 0.075$ 的储层、$0.075\times40{,}000 = 3000$ GtC 的极小（经典的估计是 5,000–10,000、一旦沉积的储层与补偿的深度的反馈被包括——这个练习的简单的盒子低估、因为它必须）。在 10 kyr 上均的流是 $3000/10{,}000 = 0.3$ GtC yr⁻¹——现代的速率的**三十分之一**；甚至完全的 10,000 GtC 在 20 kyr 上是现代的流的一半。古新世–始新世的极暖期的损害来自持续的地质的速率；现在在古新世–始新世的极暖期的步调的 30–100 倍、那恰恰是为什么现在的期望的深海响应不是古新世–始新世的极暖期的、而是更坏的、而为什么古新世–始新世的极暖期的诚实的使用是作为一个**机制与边界条件**、不是预报。
:::
:::

::: warning 深时的类似物是机制、不是预报；"二氧化碳更高过、所以不用担心"是一个范畴的错误；代用指标的极端有争议；而生物圈不是一个乘客
五个错误。**"古新世–始新世的极暖期证明 6 °C 的增暖是可生存的"**：它证明 6 °C 发生**在 0.3 GtC yr⁻¹、在 100 kyr 上**、在那个步调上迁移与适应是可能的、而它也记录了那个步调的一个深海的灭绝——现在、在流的 30–100 倍、是一个不同的实验、它的生物的回答没有写出、而它的物理（变化的速率的损害）是古新世–始新世的极暖期的最清楚的教训。**"白垩纪的二氧化碳是 2,000 ppm、而繁荣了"**：它繁荣了——对一个带着 70 Myr 的调整、没有冰盖可失去、而没有人类的农业的生物圈；相关的深时的事实不是水平、而**速率**、而白垩纪的自己的超热事件（大洋的缺氧的事件、中森诺的事件）带着它们自己的灭绝的统计。**"始新世显示极在 20 °C"**：高的纬度的数字是真实的（年均的 10–15 °C、无霜的）而**热带的**温室（35–40 °C）已被 2020 年代的代用指标的修订相当程度地走回——深时的气候的最近的最戏剧的教训是**代用指标的校准漂移**、而老的综合必须像新的数据被加入一样频繁地被重读。**"雪球地球是解决了的"**：低的纬度的冰川作用被良好地记录、而状态的细节——硬的雪球对比在赤道有开阔的水的软雪球、斯图特的 57-Myr 的持续（一个仍使每一个机制尴尬的数字）、"雪球的反照率"对比"低的斜度"的逃脱的路线——仍活跃、而这个假说的社会学（一个在一个十年中从异端生长成教科书的范式）作为好的证据如何移动的一个案例研究被教。**而"气候自然地变化了、所以归因是不可能的"**：深时的记录恰恰是**强迫**从来不是自然的加无物的证据（大的火成的省、大陆的配置、氧与甲烷的状态的改变、轨道）——地球系统没有一个安静的基线；归因的问题不是气候是否变化、而是**哪一个强迫现在在做它**、而化石的碳的同位重的指纹在现在回答它、像古新世–始新世的极暖期的碳同位重为始新世回答它一样确定。
:::

::: history
深时的气候和地层学一样老——**莱伊尔**的渐变论、十九世纪的煤的沼泽的重建、而**斯凡特·阿伦尼乌斯**的白垩纪的二氧化碳解释了白垩纪的暖的 1896 的笔记早早地设定了问题。定量的领域始于同位重的地球化学：**哈罗德·尤里、塞缪尔·爱泼斯坦、而洛文斯坦**的 1950 年代的氧的同位重的古温度学给出了第一些数字、而深海的钻探的计划给出了剖面。雪球的章节是一个科学的教科书的社会学：**布赖恩·哈兰德**的低的纬度的冰碛岩的记录（1960–80 年代）等了几十年等一个机制；**约瑟夫·基尔施温克**供给名字与古地磁的论证（1992）；而**保罗·霍夫曼、艾伦·考夫曼、加尔·哈尔弗森、而丹·施拉格**的纳米比亚的马里诺的与帽的碳酸盐的样带（1998–2004）、带着**雷蒙德·皮埃尔亨伯德**的 30% 的二氧化碳的逃脱的辐射–对流的模型、把异端转化成了标准的模型。古新世–始新世的极暖期随着海洋的钻探的计划的 1990 年代的航次与**詹姆斯·扎克斯、理查德·诺里斯、安迪·诺尔、李·卡姆普**的同位重的综合、而**菲利普·金杰里奇**的哺乳动物一侧的推论（1990–2000 年代）爆发；火山的扳机来自**塞韦雷·普朗克**与同事的岩床的省与接触的变质的研究（2004–2018）；而热带的温度的修订是**彼得·塞克斯顿、达娜·拜斯、马克·休伯**、**詹姆斯·扎克斯**、而**约翰·艾勒**的团簇的同位重的学派在 2020 年代的工作——一个实时重写它的教科书、一次一个校准的领域。
:::

::: summary
地球系统有多个稳定的心情：带着无霜的极与有争议的热带的温度的温室的世界（白垩纪–始新世、直减率的问题）、由风化与地理学触发而在约 750 ppm 附近设门的冰室的状态（休伦的甲烷的崩溃、赫南特的、石炭纪的森林的、新生代的）、而——双稳态的证明——只有百万年的二氧化碳的积累能使行星回来的雪球的状态、留下帽的碳酸盐与条带的铁作为收据。古新世–始新世的极暖期是快车道：5,000–10,000 GtC 在地质的速率、一个深海的灭绝、而 100-kyr 的恢复——现在能要求的最好的机制的研究、而在它的步调的 30–100 倍、一个边界条件、不是一个预报。深时的统一的场论是碳：二氧化碳设定心情、速率设定损害、而读古代的碳的同位重的指纹是现在读我们的那些。
:::

## 练习题

::: exercise {level=1 check="750"}
陈述硼的同位重的二氧化碳的阈（ppm）、为了始新世–渐新世的南极的冰川作用。
::: solution
约 **750 ppm**（阿纳格诺斯托与同事）——深时最接近一个政策的数字的东西：南极变成冰的它穿过的二氧化碳的门。
:::
:::

::: exercise {level=1 check="14"}
白垩纪的高的端的二氧化碳的估计约是 4,000 ppm。求工业化前的 280 ppm 的倍数、到最接近的整数。
::: solution
$4000/280 = 14$——十四个工业化前的大气、白垩纪的强迫的争论的标度。
:::
:::

::: exercise {level=1 check="38"}
把微弱的年轻的太阳的强迫的要求舍入到最接近的 W m⁻²。
::: solution
**38 W m⁻²**——能由百分之几的二氧化碳加上甲烷供给、这个悖论的公认解决。
:::
:::

::: exercise {level=1 check="48"}
求现代赤道到极的表面温度的梯度（30 °C 的热带、−18 °C 的极）。
::: solution
$30-(-18) = 48$ °C——白垩纪必须削减到三分之一的梯度。
:::
:::

::: exercise {level=2 check="0.075"}
古新世–始新世的极暖期的同位重的偏移是 −4.5‰、而源的碳 −60‰。求释放代表的可交换的碳的储层的分数。
::: solution
$f = 4.5/60 = 0.075$——表面的碳的储层的 7.5%、古新世–始新世的极暖期的碳的预算的质量平衡的核心。
:::
:::

::: exercise {level=2 check="3000"}
带着一个 40,000 GtC 的可交换的储层与 f = 0.075、求以 GtC 的古新世–始新世的极暖期的极小的碳的释放。
::: solution
$0.075\times40{,}000 = 3000$ GtC（完全的估计、加上沉积的交换、是 5,000–10,000）——深时的最大的良好地约束的快的碳的注入。
:::
:::

::: exercise {level=3 check="0.3"}
求 10,000 年中的 3,000 GtC 的古新世–始新世的极暖期的均的碳的流（GtC yr⁻¹）。
::: solution
$3000/10{,}000 = 0.3$ GtC yr⁻¹——现代的化石的流的三十分之一、定义现在的种类的差的速率的对比。
:::
:::

::: exercise {level=3 check="33"}
现代的流 10 GtC yr⁻¹ 除以古新世–始新世的极暖期的 0.3 GtC yr⁻¹：求比、最接近的整数。
::: solution
$\approx 33$——现在在以三十倍的速度运行古新世–始新世的极暖期的实验、那是"空前的速率"的声称的全部内容、以一个除法陈述。
:::
