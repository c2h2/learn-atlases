一个冰川是一个自己建造的博物馆：雪下、被埋、压缩成冰、而带着——在它的分子与在它的气泡中——它的积累的每一年的大气。钻入一个冰盖而你不是在读一个过去的大气的代用指标；在气泡中你**在读过去的大气本身**、一个 180,000 年的空气的一个气的样品、被手不能做到的压力封闭、而在冰的同位素中你在读形成雪的温度、在几万年的年的分辨率、而将近一百万年的轨道的分辨率。冰的芯的纲领——从世纪营的 1966 的第一次的试验的钻、通过格陵兰的 GRIP 与 GISP2 的柱在 1990 年代初、沃斯托克与 EPICA 的南极的横剖到 800,000 年、而 2020 年代为在小圆顶 C 的百万年的冰的竞赛——可以说是二十世纪的后期最有影响的单一的科学的基础设施：它产生了使温室气体成为一个历史的变量的冰期–间冰期的二氧化碳的循环、重写冰期的机制的突然的事件的地层学、而把工业革命变成行星自己的档案中的一个可见的尖峰的污染的考古学（铅、硫酸盐、黑碳）。

## 冰作为温度计与计时器

::: definition 蒸馏、的差值的剖面、而数的年 {#def-ice-thermometer}
极的降水是天空中的一个瑞利的蒸馏：当一个气团向极地旅行而变冷、每一个凝结的事件优先地移除重的水（H₂¹⁸O 与 HDO）、而幸存的蒸气——到达格陵兰与南极的雪——逐渐更贫化。结果是一个表面的雪的 δ¹⁸O 与 δD 的场、每 °C 的年的温度下降约 0.6–0.7‰（现代的空间的梯度、**达尔斯高与约翰森**的校准；在一个单站的时间的斜率有点更小、约 0.4–0.5‰ °C⁻¹、因为源的温度与季节性也移动——每一个冰的芯的温度重建争论的一个校正）。冰的芯的 δ 的剖面因此是**在站自己的一个古温度的曲线**：在格陵兰的中部的约 15‰ 的 δ¹⁸O 的冰期–全新世的阶（1990 年代的钻使成为气候的科学的最著名的几厘米的可见的边界）是一个约 9 °C 的变冷、而它之上的摆动——唐斯高–奥施格尔的循环、二十几个突然的增暖的 8–16‰——是突然的变化的一课的主要的数据。年代学是档案的第二个礼物：在近的表面、年的层（干净的冬的尘土的带、积累的对子、酸的火山的层的电的导率、而硝酸盐与过氧化物的循环）像树的年轮一样数——GICC05 的 60,000 数的格陵兰的年——而更深、流动的模型（冰的厚度、变形、在底部按几百倍的层的变薄）把日历向前带、由与火山的硫酸盐的尖峰与记录在尘土的组构中的古地磁的偏移的相关的点固定。价目表同样物理：冰的流动变薄而折叠深的层（GRIP 与 GISP2 的恰恰的底部是扰动的）、粒雪的柱中的扩散把同位重的信号平滑几十年到几个世纪（"十年的分辨率"是一个浅的冰的特权的原因）、而粒雪中的气的扩散把大气的气的记录平滑约 200 年、甚至在封闭的滞后之前——档案是极好的、而它是一个带着声明的截止的低通滤波器。
:::

::: example 格陵兰的大阶 {#ex-greenland-step}
格陵兰的中部的 δ¹⁸O 从 −35‰（全新世）阶到 −50‰（完全的冰期）——一个 15‰ 的变化。使用现代的**空间的**梯度 0.7‰ °C⁻¹ 给出一个温度的估计；使用公认的**时间的**斜率、为了冰期–全新世的转变、约 1.5‰ °C⁻¹、给出另一个。求两者、而说这个领域用哪一个、为什么不同。
::: solution
空间的：$15/0.7 \approx 21$ °C——不能相信地冷、比任何一个地质的证据允许的更冷。时间的：$15/1.5 = 9$ °C——教科书的值。斜率不同、因为冰期的雪来自不同的源的区域、在不同的季节、带着不同于现代的降水的雨出的历史、所以现代的空间的梯度**低估**过去的转变的敏感性——这个练习是这个领域的中心的谨慎：同位重的–温度的斜率是受状态约束的校准、而在它们之间选择把北极的冰期的严酷改变两或三倍。
:::
:::

## 气泡：大气、归档了

::: definition 温室气体的记录 {#def-gas-record}
在粒雪–冰的封闭（下面 50–150 m、约 50–100 bar 的覆盖的负荷）、孔的空气封闭进气泡、而冰变成一个化石的大气的圆柱。测量的序列——通过融化或在真空下冒泡的气的提取、释放的气的同位重的比的与激光的光谱学——产生了这个学科最被引用的曲线。**二氧化碳**：从拜尔德与沃斯托克的 1970–80 年代的侦察（第一冰期–间冰期的摆动、180→280 ppm、在南极的冰中见到）到**沃斯托克**的 420-kyr 的样带（珀蒂与同事、1999、四个冰期的循环、二氧化碳 180–300 ppm 紧贴温度的曲线）、**EPICA 的圆顶 C** 的 650-kyr 的气的记录（吕蒂与同事、2008——第一次出冰期的范围的偏移、MIS 11 的约 280 ppm 的天花板）而 800-kyr 的同位重的与尘土的编年史、带着**超越 EPICA** 的 2024–25 的在小圆顶 C 的约 1.2-Myr 的旧的冰的回收把气的记录延伸向中更新世的转变、二氧化碳的曲线是第四纪的同伴：冰期的 180、间冰期的 280、工业的 280→425 ppm——一个比气泡的 800,000 年中的任何东西更大、而在整个的自然的包络之外的跳跃。**甲烷**（冰期的 350 ppb 到工业的 700、带着它自己的突然的事件的结构——甲烷的记录跟踪格陵兰的温度如此紧密以致它用来相关的岩芯——而一个碳同位重与氢同位重的预算的解剖把湿地从火从融的永久冻土分开）、**氧化亚氮**、而卤代的烃（它们在旧的冰中的缺席自己是工业的时代的一个测量）完成气的面板。解释有一个永久的星号：**气的年龄不是冰的年龄**——空气在封闭之前自由地通过粒雪扩散、所以气泡比周围的冰年轻 200–1,000 年（站点依赖的、在冷的、慢的积累的南极大）、而二氧化碳–温度的超前–滞后的争论（关于谁先动的一个世纪的争论、由南极的气的相的分析解决为"二氧化碳在南极的消冰期中滞后南极的温度几个世纪、而两者领先格陵兰一个千年或更多"）完全是关于这个校正。气泡也带着**在溶液中的气溶胶与化学的记录**——甲烷、甲磺酸盐（一个海冰与生产力的代用指标）、铵、硝酸盐、甲酸——而冰的不溶的部分带着**尘土**（冰期的尘土的浓度运行全新世的值的 50–100 倍、带着矿物学与钕的同位重把它源到亚洲的扩大的旱地、而为了太平洋、巴塔哥尼亚——**约翰·马丁**的铁的施肥的假说、在 1990 年在这些数据上提议、仍是碳的循环的科学的最优雅的未检验的实验）、而融的水与导率的记录带着**火山的硫酸盐**与**铅、黑碳与锌**——下面的污染的考古学。
:::

::: example 温室的阶、在强迫中 {#ex-co2-forcing}
用 $\Delta F = 5.35\ln(C/C_0)$、求冰期–间冰期的二氧化碳的变化（180→280 ppm）的辐射的强迫、工业的变化（280→425 ppm）的、而两者的比。
::: solution
冰期–间冰期的：$5.35\ln(280/180) = 5.35\times0.452 = 2.4$ W m⁻²；工业的：$5.35\ln(425/280) = 5.35\times0.416 = 2.2$ W m⁻²——比是 **1.1**、即人类在 170 年中的二氧化碳的推已经是花了 10,000 年的自然的消冰期的推的十分之九、而加上甲烷与氧化亚氮工业的强迫超过完全的自然的循环。这个练习是两个对数中的整个的冰的芯的论证：气泡定义自然的实验、而比较说我们在更快地运行它、而向它的结束之外去。
:::
:::

## 突然的世界与人的世界

::: definition 唐斯高–奥施格尔的循环、海因里希的层、而污染的考古学 {#def-abrupt-human}
格陵兰的冰是**突然性**的档案。**唐斯高–奥施格尔的循环**——在冰期的 δ¹⁸O 中的二十几个锯齿的摆动、每一个在几十年内 8–16‰（区域的 8–15 °C）的增暖、跟着在几个世纪到几千年的慢的变冷——在 1992–93 的 GRIP 与 GISP2 的柱中首次解析到季节到十年的分辨率、而从过去已知的最快的大的幅度的气候的摆动；它们的南半球的镜子（"双极的跷跷板"、布吕尼耶与茹塞的气与同位重的记录的反相、而南极的温度振荡）与它们的步调（邦德的循环的约 1,500 年的心跳、而海因里希的事件——在哈得孙附近的海洋的岩芯中的巨大的冰的漂送的碎屑的层、以哈特穆特·海因里希的 1960 的发现命名、冰给它们定年到最冷的格陵兰的阶段）把冰期的机制定义为一个大西洋的环流的问题、这个图集的突然的变化的一课的主题。**年轻的德律亚得**——在上次的消冰期的中间回到冰期的冷 1,200 年、在 Dye-3 与 GRIP 中作为一个尖锐的 δ¹⁸O 与尘土的反转见到——是突然的变化的领域的现代的时代的标准、而**8.2-ka 的事件**（早全新世的冷的脉冲、在石笋中匹配而联系到冰川前的阿加西湖与它的后继者的排水的冰的湖的爆发）是它的全新世的兄弟、两者由数的层计时到几个世纪之内。人的章节现在同样可读：工业前的冰带着一个干净的基线（铅在万亿分之一万亿分之一、硫酸盐来自火山与海盐）、而工业的层记录化石的燃料的金属的兴起——**1970 年代的铅的峰值**（四乙基铅的半球的指纹、自每一个淘汰的阶段以来下降）、现在在良好地测年的格陵兰的冰中年可解析的罗马与迦太基的铅的异常（2020 的"罗马的标记"——一个匹配这个城市的帝国的冶炼的污染的峰值、从一个离矿几千公里的冰川读）、跟踪生物的与化石的燃烧的跟踪黑碳的层、而匹配可测年的喷发的硫酸盐的尖峰（1815 的坦博拉与 1883 的喀拉喀托的层、1991 的皮纳图博的层仍在粒雪中）。冰的芯的化学已成为**带着一个计时器的环境的历史**：作为古气候的仪器开始的档案现在在年的层中给工业革命的足迹测年、而它最近的革命——在蓝的冰的与小圆顶 C 的省中寻找连续的中更新世与上新世的气的记录——承诺这个学科从未在现场有的一个数：一个 3 °C 与 20 米的海平面的世界中的大气的二氧化碳、上新世的暖期、对着它将判断每一个百年的标度的预报。
:::

::: example 读污染的层 {#ex-lead}
一个格陵兰的岩芯的在 220 m 的深度的段落显示铅在 90 万亿分之一、对着工业化前的基线 0.5 ppt、而接近的表面的一个 0.22 m yr⁻¹ 的冰的等价的积累速率。如果铅的峰值在粒雪的线之下 4.4 m、求它的以年的表面的之下的日历的滞后、而对着基线的富集的因子。
::: solution
$4.4/0.22 = 20$ 年——峰值（1970 年代、在真实的记录中）深二十年、而富集是 $90/0.5 = 180$ 倍：清洁空气的法案的成功作为在那个峰值之上的下降的铅可测量、在冰中、在一个冰川上、没有监测器参与。这个练习是污染的考古学的方法：积累的速率把深度转换成日期、基线把浓度转换成故事、而两者一起使冰盖成为一个没有人建造、而没有人能削减经费的半球的监测的站。
:::
:::

## 冰中的一切其余的部分

::: definition 宇生成核素、海盐、硫酸盐、而一切的化学 {#def-ice-chemistry}
在同位重与气泡之外、冰是整个的地球系统的化学的账本、在万亿分之一的水平由在这些样品周围长大的化学读。**铍–10**（宇生成的、由平流层的输入输送）跟踪宇宙线的太阳的调制与地磁的场——树的年轮的 ¹⁴C 记录的冰的芯的双胞胎、而莫德与施珀勒的极小在两个独立的宇生的档案中可见的原因。**硫酸盐**记录爆炸的火山的活动——双峰的 1815 年坦博拉的层（在极的冰中的公元的最大的、它在两个半球的到达测年到一年之内、而用来同步冰、海洋、而树的记录跨全球）、1883 的喀拉喀托、1991 的皮纳图博——而硫酸盐的通量的序列现在是两个冰盖的最后 2,500 年的年代学的骨干、带着火山的匹配自己是一个喷发的测年的精度的检验（关于锡拉/圣托里尼的喷发的时代的长期的争论是一个硫酸盐的层的争论）。**甲磺酸盐**（MSA、来自海洋的二甲基硫）与**海盐的钠**（带着它的镁与硫酸盐的比）映射海冰的范围与源的区域的风的强度——南极的海盐与 MSA 的记录是少数直接的古海冰的代用指标之一、而它们的冰期的极大记录扩大的、更长命的海冰、使冰期的海洋成为另一个行星的。**铵、硝酸盐、甲酸与乙酸**记录生物量的燃烧与生物圈的交换（冰期的铵的峰值、与尘土相关的、是铁的施肥的争论的营养的沉积的数据）；**黑碳**的层（2019–20 的澳大利亚的火的季节与 2013 的阿尔伯塔的火记录在粒雪中、工业的化石的烟的曲线在西南极的分流的冰中年可解析）使冰的芯成为直接给烟的沉积测年的唯一档案；而**痕量的金属的组合**——铅、锌、铜、银、稀土——从污染的考古学生长成矿石的来源的考古学、带着罗马的时代的层中的铅的同位重的比指纹哪个矿——伊比利亚的黄铁的带、中欧的阿尔卑斯的区——喂养哪个帝国、一个现在叫**同位重的考古学**、而在冰、不是人造物上实践的领域。化学的章节的教训与物理的章节的相同：冰盖把大气、海洋、生物圈、而工业集成到一个每年的分层的文件、而这个领域的未来是还没有人测量的部分的化学。
:::

::: example 通过硫酸盐同步 {#ex-tambora}
1815 的坦博拉的硫酸盐的峰值出现在一个格陵兰的岩芯在 102.34 m、而在一个南极的岩芯在 61.87 m、带着在那些深度的 0.19 与 0.052 m yr⁻¹（冰的等价）的积累的速率。求如果两个层由层的计数放置、两个深度暗示的沉积的年的差、而解释为什么两个岩芯的相对的深度与它们的积累的速率的匹配比绝对的日子更重要。
::: solution
$102.34/0.19 = 539$ 年的积累在格陵兰的层之上、而 $61.87/0.052 = 1190$ 在南极的之上——不同的比只是反映不同的积累的制度、而**同时的**放置（两个峰值在它们数的 1815–16 的位置、在一两年的计数的不确定之内）是使坦博拉成为一个全球的相关的点的东西：任何带着 1815 的信号的档案——树的年轮、珊瑚、历史的记录——从冰继承它的日期。这个练习是事件的层型的方法：一个好的等时的线值过一千个本地的日期、因为它把最好的年代学转移给它触及的每一个档案。
:::
:::

::: warning 冰不是一个记录器、它是一个冰川；气泡是老的；斜率是校准；而埃姆的期不是一个简单的类似物
五个错误。**"冰的芯的二氧化碳的曲线证明二氧化碳造成了冰期"**：气泡证明耦合、而滞后的分析（在南极的消冰期中南极的温度领先二氧化碳几个世纪）使二氧化碳成为一个**放大器**、不是轨道的扳机——这个学科的谨慎的陈述是二氧化碳是把米兰科维奇的小的强迫变成冰期–间冰期的摆动的反馈、而冰的芯是恰恰那个的证据、不是更多。**"沃斯托克的温度与二氧化碳的曲线是同时的"**：气滞后冰多达一个千年、同位重的与气的记录在不同的年代学上、而使这个图出名的相关要求这个学科的最谨慎的同步的工作——这个图是**因为**校正被做而正确的、不是尽管它们。**"格陵兰的 δ¹⁸O 是全球的温度"**：它是格陵兰的（与北极的）在站的温度、带着季节性与源的区域的效应；南极的同位重的记录是一个不同的、阻尼的、不同相的故事、而全球的均值的温度的重建（沙昆等的 73 个记录的 2012 的综合）不得不离开冰来建造——冰的芯是重建的脊柱、不是重建。**"埃姆的期显示 2 °C 看起来像什么"**：最后的间冰期（129–116 ka、尼姆与南极的记录）更暖（全球的 1–2 °C、北极多得多）、带着 6–9 m 的海平面、而它的强迫是轨道的、它的二氧化碳约是 280 ppm、而它的增暖的格局（高的纬度的、季节的、太阳的照射驱动的）在对区域的影响重要的恰恰的方式上不同于温室的类似物——埃姆的期是一个海平面的警告与一个敏感性的约束、不是一个预报。**而"更深的总是更好"**：最深的冰是最薄的、变形最多的、而化学改变最多的；底的冰混合、折叠、而能对气是死的（百万年的搜索以**蓝的冰的圆顶与冷的底的冰**为目标、老的层完整地幸存、而不是简单地钻到一个流动的冰川的底的原因）——档案的前沿现在是冰自己的构造的地质学。
:::

::: history
冰的芯的时代在格陵兰的**坎普世纪营**（1966）打开、那里一个美国陆军工兵部队的 1,387 m 的冰的试验的钻孔产生了第一深的冰的岩芯、而几乎附带地、**威利·达尔斯高与谢尔·约翰森**的同位重的–温度的校准与第一地层的层的计数；**切斯特·兰格韦**在那里的化学的工作创立了冰的芯的化学。南极的横剖——**列昂尼德·科利亚科夫**的、然后法苏的**沃斯托克**的自 1957 的钻——产生了第一 2,000-m 的柱、而**克洛德·雷诺、让–罗贝尔·巴尔诺拉、让·茹塞**与同事产生了使温室气体成为一个第四纪的变量的沃斯托克的二氧化碳与温度的样带（1985–1993）。突然的事件的革命属于**GRIP**（格陵兰的冰的岩芯的项目、1992）与**GISP2**（1993）的格陵兰的柱、它们的 3-km 的岩芯以十年的分辨率解析唐斯高–奥施格尔的循环、而使年轻的德律亚得成为一个数的、测年的事件；**华莱士·布罗克、米夏埃尔·舒尔茨、杰拉德·邦德、杰里·麦克马纳斯**与同事在它们周围建造了环流的解释。深的南极的谱系——**EPICA 的圆顶 C**（800 kyr、2004；650-kyr 的气 2008）、**EPICA 毛德皇后地的**与**西南极的冰的分流的**（WDC、68-kyr 的年的年代学）的岩芯、而**尼姆**的埃姆的期的冰（2013）——把记录延伸到中更新世、而**超越 EPICA** 的 2024–25 的小圆顶 C 的钻伸手向百万年的气的记录、它将通过在气泡中测量上新世的气候制造的世界的大气闭合圆。
:::

::: quiz
一个冰的岩芯中的气泡：
- [ ] 与周围的冰在同一时间形成。
- [x] 比冰年轻几百年、在封闭之前通过粒雪扩散。
- [ ] 是钻井液的现代污染。
- [ ] 记录深部地质的甲烷。
::: solution
孔的空气在粒雪在 50–150 m 的深度封闭之前与大气交换、所以捕获的气比包围的冰年轻 200–1,000 年——每一个二氧化碳–温度的超前–滞后的研究在解释之前必须校正的气–冰的年龄的差。
:::
:::

::: summary
冰的芯是带着最好的分辨率、而其中最多的空气的气候的档案：由蒸馏的物理校准的同位重的温度计（δD、δ¹⁸O）、数到 60 kyr 的年的层、而是过去的气的直接样品的泡——第四纪的 180–280 ppm 的二氧化碳的包络、它的 425-ppm 的工业的突破、甲烷的突然的事件的解剖、而尘土、铅与硫酸盐作为旱地与工业的化学。格陵兰写了突然的章节（唐斯高–奥施格尔的锯齿、年轻的德律亚得、8.2-ka 的脉冲）；南极写了碳的循环的章节（沃斯托克到 EPICA 到超越 EPICA 的百万年的搜寻）；而在 1950 年代的冰的起源的与烧瓶的起源的二氧化碳的重叠把自然的与工业的记录焊成一条曲线。校正——气的滞后、流动的变薄、校准的斜率——是著名的图与可辩护的图之间的差、而它们是冰的芯的科学部分是现场的工程、部分是同位重的地球化学、而完全是不可缺少的原因。
:::

## 练习题

::: exercise {level=1 check="800"}
陈述寒冷南极站点处粒雪封闭的最大年龄差（年）。
::: solution
约 **800** 年——这一气–冰滞后是所有超前–滞后争论的前提。
:::
:::

::: exercise {level=1 check="2.4"}
求冰期–间冰期的二氧化碳的变化 180→280 ppm 的辐射的强迫（W m⁻²、一位小数）。
::: solution
$5.35\ln(280/180) = 2.4$ W m⁻²——自然的消冰期的放大、在一个对数中。
:::
:::

::: exercise {level=1 check="2.2"}
求以 W m⁻² 的工业的二氧化碳的强迫（280→425 ppm）、一位小数。
::: solution
$5.35\ln(425/280) = 2.2$ W m⁻²——自然的循环的推的十分之九、在两代人中供给。
:::
:::

::: exercise {level=1 check="25"}
在最后的冰期的格陵兰的记录中大约数到多少个唐斯高–奥施格尔的增暖？
::: solution
**超过 25 个**（在岩芯中标号 DO-1 到 DO-25+）——一个还没有人从第一原理说明的节拍器。
:::
:::

::: exercise {level=2 check="9"}
用公认的冰期–全新世的时间的斜率约 1.5‰ °C⁻¹、求 15‰ 的 δ¹⁸O 的阶的格陵兰的温度变化。
::: solution
$15/1.5 = 9$ °C——教科书的北极的冰期的严酷、而校准的斜率、不是同位重的数据、是论证的原因。
:::
:::

::: exercise {level=2 check="180"}
求污染的例子中的铅的对着基线的富集的因子（90 ppt 对 0.5 ppt）。
::: solution
$90/0.5 = 180$——在一个冰川中记录的一个 180 倍的半球的污染的峰值、而它的记录的铅的淘汰的法律之后的下降。
:::
:::

::: exercise {level=3 check="20"}
积累 0.22 m yr⁻¹；铅的峰值在下面 4.4 m。求它以年的年龄。
::: solution
$4.4/0.22 = 20$ 年——深度到日期的转换、污染的考古学家的第一算术。
:::
:::

冰期的尘土对格陵兰的中部超过全新世的值大约多少倍？

约 **100**（50–100 倍）——播种铁的施肥的假说、而仍是一个一阶的碳的循环的边界条件的旱地与风的强度的签名。
