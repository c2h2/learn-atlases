1993 年来自格陵兰的中部的格陵兰的冰芯给出了一个打破了均变论的和平的句子：最后的消冰期的格陵兰的增暖发生在一个人的寿命之内、好几个度——最冷的年轻的德律亚得的一个世纪让给温和的伯尔林、在层的计数说的**几十年**中。深海的记录、带着它的一千年的平滑、把冰期显示成一个慢的华尔兹；冰显示它们为一个带着的发须的扳机的锯齿、二十几个突然的增暖（**丹斯高–奥施格尔的循环**）与突然的变冷（**海因里希的事件**与年轻的德律亚得）堆在冰期之内、每一个都是大西洋的翻转的环流的一个状态的翻转。概念的革命——**双极的跷跷板**、海洋的盐的跷跷板在两个半球之间重新分配热、而气候作为一个带着的多个的稳定的状态、能在十年的时间尺度上到达的系统——是现代的突然的变化与临界点的文献的基础、而它的实际的后代是困扰气候的模型的问题：**大西洋的环流能在崩溃之前靠多近、而如果它崩溃了二十一世年会感觉像什么？**这一课是证据、机制、而从冰中的一个锯齿生长出来的警告信号的科学。

## 记录：一个带着的扳机的锯齿

::: definition 丹斯高–奥施格尔的循环、海因里希的事件、而跷跷板 {#def-do-heinrich}
格陵兰的冰中的最后的冰期（115–11.7 ka）是一个 **~25 个丹斯高–奥施格尔（D–O）事件**的阶梯：8–16 °C 格陵兰的突然的增暖（2021 的一个冰期的中部的转变的层的计数的研究把完全的上升放在**10–20 年**之内——已知的最快的大的幅度的气候的变化、跟着几个世纪到两千年的渐的变冷、每一个循环从 DO-25 向下数到伯尔林。终止间冰阶的变冷在海洋的记录中更陡：**海因里希的事件**（最后的冰期中的 H1–H6、以**哈特穆特·海因里希**的 1960 年的冰山搬运的碎屑的层的观察命名、而由**瓦利·布勒克、杰拉德·邦德、而杰里·麦克马纳斯**在 1990 年代形式化）——劳伦泰德的冰通过哈得孙海峡的灾难的排放、把冰山的石头撒满北大西洋的海底、使表面变淡、而与 D–O 的循环的最冷的、环流最弱的阶段相符。南半球讲反相的故事：南极的同位素的记录（拜尔德、然后高分辨率的西南极冰分与欧洲冰芯计划的多姆湖的冰芯）显示**南极的气候的振荡**——与格陵兰的变冷反相的增暖——而**双极的跷跷板**的机制（斯托克与约翰森、2003）定量地解释这个相位：当大西洋的输送带减弱、北变冷而南变暖、因为海洋的热输送、通常跨赤道向北约 1.3–1.5 PW、崩溃或反转、而大气以一个南大洋的慢的响应设定的一千到两千年的滞后重新分配这个亏缺。跷跷板是此后的一切的模板：**突然性不奇特、它是大西洋的正常的操作的模式**、而全新世——长期被假定为稳定的间奏——有它自己的更小的 D–O 的亲属（9.3、8.2、5.9、4.2 ka 的事件、北大西洋的冷的尖峰的"一千年"的再现）写在洞穴的石笋、湖泊、而全世界的冰川中。
:::

::: example 突然性、量化 {#ex-rates}
一个 D–O 的增暖在 20 年中给格陵兰 10 °C；现代的人为的增暖的速率在全球约 0.2 °C yr⁻¹（而北极约 0.4 °C yr⁻¹）。求以 °C yr⁻¹ 的 D–O 的速率、它与现代的全球的速率的比、而解释为什么这个比较既引人注目又危险。
::: solution
$10/20 = 0.5$ °C yr⁻¹——现代的全球的速率的 **2.5 倍**、而与北极的相当；引人注目因为地球在没有二氧化碳的情况下区域地做到了、危险因为 D–O 的事件**重新分配**了热（北大西洋得到了南失去的、全球的均值几乎没动）而人为的变化在全球而永久地**增加**能量、而因为 D–O 的暖到达了一个比全新世冷 6 °C 的世界——同样的 10 °C 对接收端的冰盖与人意味着完全不同的东西。这个练习是这个学科的诚实的规则：突然的变化的比较是关于**速率与机制**、从不关于等同。
:::
:::

## 机制：大的猜想与它的检验

::: definition 输送带、盐的跷跷板、而给北大西洋注水 {#def-amoc}
机制——**温盐的输送带**、**布勒克**的"大的猜想"（1987）——冰期的海洋的环流重新组织了、而北大西洋的表面到深的单元是它的扳机——现在是每一本教科书的**大西洋经向的翻转的环流（AMOC）**的一章：暖的咸的水向北携带、冷却、在拉布拉多的海与北欧的海下沉、在深处归还；一个携带海洋的向北的热约 15%、而大西洋的半球之间的盐的引擎的约 100% 的环流；而一个**盐的跷跷板**（布勒克的）解释冰期的北大西洋的两个状态——现代一样的"热的状态"（冰间阶）、而一个"冷的状态"、深的水的形成的地点向南移动、而北大西洋的表面被融的水与海冰封顶（把冷的状态锁住的海冰–反照率–湿气的反馈、盐的跷跷板的模型的"盐的振荡器"）。假说的证据是一幅马赛克：冰期的大西洋的**地中海的出流水**的深度变化、冰期的北大西洋的中间的水的温度的配对镁钙与氧同位重的重建（海冰之下的"冰期的北大西洋的间冰期的"暖的水——**麦克马纳斯、奥普、莱曼**的学派的关键的发现）、深的水的速度的沉积的聚焦与分选的系数的代用指标（速度的代用指标——可排序的粉砂、沉积的波——显示冰期的深的西的边界的流更弱、而更多的南的源的水）、而**注水的实验**——给亚极地的北大西洋的模型的淡水的脉冲、可靠地崩溃翻转的环流、而再现跷跷板的相位（**NA-12k** 的协议、古气候的模拟的对比的计划对年轻的德律亚得与 8.2 ka 的事件的正式的检验、在其中大多数的模型需要**比地质学能找到的更多的淡水**来保持一致——使机制在边缘有争议的"淡水的预算的问题"）。现代的观测的弧完成了这个圆：**RAPID-MOCHA** 的阵列（2004–）与它的先驱抓住了**减弱的状态**的现代的翻转的环流——仪器的记录中最强的几十年的下降——而 2021 的大西洋的"指纹"的变率的分析（**伯尔斯**）报告了与向一个分岔的接近一致的**临界的减速**（海表面的温度的格局的上升的一阶的自相关的与方差）、一个它的解释仍有争议、而它的存在定义了这个学科的现在的结果：D–O 的机制不只是地质学；它是一个带着的仪器在上面的正在进行的实验。
:::

::: example 给大西洋注水 {#ex-hosing}
一个 NA-12k 一样的实验给亚极地的北大西洋在 100 年中加入 0.1 Sv（1 Sv = 10⁶ m³ s⁻¹）的淡水。求以 m³ 的总的体积、而混合进一个 2.5×10¹⁵ m³ 的亚极地的体积的分数变淡——然后说为什么一个 13% 的变淡能翻转环流。
::: solution
$0.1\times10^{6}\times3.15\times10^{9} = 3.2\times10^{14}\ \mathrm{m^{3}}$；分数 $= 3.2\times10^{14}/2.5\times10^{15} = 0.13$、**13%**——等价于把大西洋的盐度削减约 4–5、而表面的密度削减到足以停止拉布拉多的海的开阔的海洋的冬天的对流、在下沉需要冷的咸的顶部十米到达接近结冰的密度的地方：对流是一个在密度上的**阈的过程**、而 13% 的淡水是许多个阈值深。这个练习是注水的实验为什么有效、而寻找那么多融的水的地质学的搜寻（年轻的德律亚得的脉冲的源、路径、而时间——"融的水的脉冲 1B 的问题"）为什么仍是机制的最难的证据的搜寻的原因。
:::
:::

## 年轻的德律亚得与 8.2 ka 的事件

::: definition 消冰期的两个大的跌倒 {#def-yd-82}
**年轻的德律亚得**（12.84–11.65 ka、GICC05 的计数）是突然的变化领域的罗塞塔石碑：在伯尔林–阿勒罗德的温暖的时段（自己就是一个 D–O 级的增暖、而冰中最快的消冰期的温度的变化）之后、气候**在北方向回到接近冰期的冷一千二百年**——反转记录在格陵兰的冰中（尘土、同位素、在十年的开始中）、在有纹泥的湖中（德国的与瑞士的记录把开始放在几十年内）、在委内瑞拉的海中（卡里亚科的钛的条带在几十年中从层压的翻到有纹泥的）、而大陆的花粉中。原因是**融的水的问题**：劳伦泰德的冰盖的崩溃把冰川的阿加西湖的出流路由到圣劳伦斯与亚极地的北大西洋（路由的地理学——阿加西向南通过密西西比排对比向东通过五大湖排——是争论的引擎、而 2016–2020 的消冰期的海平面的"融的水的脉冲"的海洋的指纹的研究使淡水的预算继续被争论）、而海洋的响应（翻转的环流的减弱）是机制、而**碳的循环的响应**（跨过开始的约 10–15 ppm 的大气的二氧化碳的下降、南大洋的响应、"年轻的德律亚得的二氧化碳的下降的谜"在环流、生物、而储存之间仍未解决）是放大器。**年轻的德律亚得的撞击的假说**——一个把反转播种的流星体的空爆、2007 年在黑垫、纳米钻石、而球粒上提出——是这个领域最有教益的非结果：十年的失败的重复（球粒的层被重新解释为非宇宙的、"黑垫"被解释为地方的而不同时的）、而 2018 年对它的中心的新世界的声称的撤回使它成为非凡的声称的卫生的案例研究、而适度的幸存的可能性（一个在 12.8 ka 在北美上空的地球的外的**空爆**、没有气候的作用）仍开放。**8.2-ka 的事件**是全新世的机制在冰之后幸存的演示：冰川的阿加西湖与奥吉布瓦湖的最后的排放通过哈得孙湾（约 8.29–8.18 ka、全新世的最大的之一的大水的爆发、它的特大洪水的冲刷在哈得孙湾的底上被绘制）向亚极地的北大西洋注入一个大的淡水的脉冲、而气候的响应——约 1–2 °C 的北半球的变冷、从阿曼到中国的季风的减弱——以洪水的节奏到达而离开、持续**几十年到约 160 年**在最良好地解析的记录中。8.2-ka 的事件是**自然的全新世的突然性的上界**、而每一个全新世的气候的模型都通过它运行的原因：一个能在早的全新世做到这个两次的系统、带着 60 m 少的海平面与一个残留的冰盖、是一个它的环流的状态是一个变量、不是一个常数的系统——而它的现代的减弱因此是一个一阶的问题、不是一个好奇。
:::

::: example 融的水的脉冲 1A 的算术 {#ex-mwp1a}
化石的珊瑚礁（巴巴多斯与公平班克斯与后继者的珊瑚的记录）把融的水的脉冲 1A 放在 14.6 ka 的约 500 年中的约 20 m 的海平面的上升。求以 mm yr⁻¹ 的速率、与现代的速率（约 4.5 mm yr⁻¹ 而加速）比较、而说明这个事件对年轻的德律亚得的论证为什么重要。
::: solution
$20{,}000/500 = 40$ mm yr⁻¹——**现代的速率的约 9 倍**、单从冰、没有热的膨胀的帮助；现代的对比是冰盖在被强迫过它们的边缘时能做什么的诚实的标度。这个事件对年轻的德律亚得重要因为它显示系统**在反转之前已经在以灾难的速率泵融的水**——淡水在位、路由是问题、而年轻的德律亚得是路由、不是体积、翻转了环流的论证：一个地理学如何编辑地质学的教训。
:::
:::

## 早期的警告与深时的合唱

::: definition 临界、警告、而"突然"对政策意味着什么 {#def-early-warning}
D–O 的世界是**临界点**的概念（下一课的与气候变化的图集的主题的）的模板：替代的稳定的状态、滞后的、而统计的**早期的警告的信号**的纲领——临界的减速被检测为上升的一阶的自相关的与方差、当一个系统接近一个分岔、理论在湖、生态系统、而心跳上验证、而通过大西洋的"暖的洞"的指纹应用于翻转的环流（上面的**伯尔斯 2021** 的结果；**迪特尔夫森 2023** 的一个可能的世纪的中期的崩溃的日期的统计的声称、带着它的置信的区间与它的批评者关于趋向对比波动的反对、现在是这个领域最有后果而最有争议的数）。深时的合唱供给幅度：古新世–始新世的极暖期的开始（在千年中的碳的释放、它后面的深海的灭绝）、大洋的缺氧的事件的缺氧的反转、始新世–渐新世的冰川作用的跳跃、二叠纪–三叠纪的最坏的章节、而雪球地球的终止（帽的碳酸盐的消息：碳的循环的恒温器能在最大的标度上在**几千**年中翻转）——一切都是变化的速率的损害是规则的、而生物群的脆弱性跟踪**步调**、不是水平的证据。政策的翻译是气候的评估的最难而最有争议的算术：AR4/AR5 的翻转的环流的崩溃的"在本世纪中极不可能"的语言（在任何情景下显示没有二十一世纪的崩溃的模型）对比统计的学派的警告——不崩溃的模型不能谈论真实的系统会不会（**迪特尔夫森**的声称：一个以世纪的中期为中心的、带着巨大的不确定的崩溃的窗口、被模拟的多数驳回、而被二十世纪的翻转的环流的下降是真实的、而指纹的趋向是稳健的观察锐化）。诚实的综合是这个领域自己的：**一个完全的崩溃在本世纪中不被过程的模型支持、一个持续的减弱被支持、而尾部足够肥、以致观察的成本——大西洋的持续的观测、对冰期的崩溃的更好的古的约束、而和不测试系统的排放一致——对照一个甚至不崩溃的"减弱的"状态的区域的损害都是微不足道的**、仅那一项就会在北欧相对于全球的均值变冷一到两度、移动季风、而把北大西洋的海平面提高几厘米的动力的比容的变化。突然的变化、最终、是这个学科对两个相反的自满的责备：气候是慢的、而我们确切地知道它能多快。
:::

::: example 读一个警告的信号 {#ex-ews}
一个 150 年的翻转的环流的指纹的序列显示一阶的自相关的当方差上升 2 倍时从 0.3 上升到 0.7。如果系统接近一个折叠的分岔、理论对小的扰动的恢复的速率预言什么、而批评者援引的两个非临界的解释是什么？
::: solution
临界的减速：恢复的速率 $r$ 下降、而自相关的 $\rho = e^{-r\,\Delta t}$ 上升——$\rho$ 从 0.3 到 0.7 意味着恢复的时间延长了约 3 倍（从 $-\Delta t/\ln 0.3 \approx 0.88\,\Delta t$ 到 $3.1\,\Delta t$）、系统对它的自己的稳定性的记忆在消退。批评者的替代：(1) 一个**强迫的趋向**（增暖自己同时施加趋向与自相关——去趋向改变答案、而争论是关于去趋向的）、而 (2) **外的变率**（北大西洋的振荡与火山的强迫被染成看起来像临界的减速）——这个领域现在的要求是明确的原因：警告的信号必须胜过从强迫的响应、不是从白噪声建立的零的模型。
:::
:::

:::

::: warning 突然不意味着全球的、输送带没有被证明会临界、年轻的德律亚得不是一个模板、警告的信号不是预报、而全新世不是它被卖作的那个稳定的基线
五个错误。**"D–O 的事件是全球的增暖"**：它们是**重新分配**——跷跷板的全部要点——而全球的均值的温度移动很少；人为的类似物是相反的（全球的、相加的）、而混淆它们在两个方向上都误导（D–O 们不"和我们的增暖一样"、而它们不是世界在每一处都暖得快的证据）。**"翻转的环流会/必须崩溃因为它以前做过"**：冰期的崩溃带着巨大的融的水的强迫与不同的边界条件运行；全新世的更小的事件需要一个我们不再有冰盖；而模型在本世纪中拒绝崩溃可能反映它们的分辨率、它们的淡水的阈值、或现实——这个领域真的不知道、而"模型说不"是一个关于模型的陈述。**"年轻的德律亚得显示 10 年的警告是可能的"**：年轻的德律亚得的开始在**一些**记录中是几十年、而在另一些中是几个世纪、它的原因（一个特殊的融的水的湖的路由）今天不可重复、而它的影响的模板（北大西洋的冷、热带干）只是几个突然的变化的原型之一——把它用作一般的灾难的脚本是坏的与更坏的统计的。**"上升的自相关意味着崩溃在来"**：它意味着一个接近分岔的**统计的模型**比替代更好地拟合——在强迫之下、带着染色的噪声、在一个它的"临界"是状态的一个连续体的系统中、这个推断是脆弱的、而迪特尔夫森的事件（一个发表的、被争议的、而只作为一个肥尾的警告幸存的崩溃的日期）是如何不过度读一个统计量的活的教训。**而"全新世是稳定的"**：8.2- 与 4.2-ka 的事件、中世纪的与小冰期的异常（现在读作区域的、不是全球的、但是真实的）、而全新世的自己的慢的进动的变冷说全新世是**足够稳定**的为了农业——一个程度的陈述、带着我们自己的记录现在测量的方差——而政策的诚实的框架不是"回到稳定"而是"选择你能与哪种变率一起生活。"
:::

::: history
突然的思想几乎在十九世纪出生——冰川的阿加西湖与"无漂移的"混沌对**章伯伦、厄帕姆、而美国的测量的地质学家**是明显的、而**查尔斯·莱伊尔**自己援引灾难的排水——而机制等了一个世纪等海洋。**哈特穆特·海因里希**描述了碎屑的层（1960）；**华莱士·布勒克**供给输送带（"大的猜想"、1987）、盐的跷跷板、而年轻的德律亚得的融的水的假说（1989、带着**理查德·公平班克斯**的巴巴多斯的融的水的脉冲的记录、1989–90）；**杰拉德·邦德**在海冰的代用指标中发现了 1,500 年的节奏（1993）、而**海斯、鲁迪曼、而麦金太尔**发现了北半球的冰期的步调；**唐斯高与奥施格尔**从 1966 年起读同位素的锯齿、而**奥施格尔、斯图弗**（放射性碳的校准的联系）与伯尔尼与剑桥的团体建立了事件的年代地层。格陵兰的冰芯（1993）与 GISP2（1994）的层使突然性无法忽视；**斯托克与约翰森**（2003）命名了双极的跷跷板；**麦克马纳斯、奥普、莱曼、霍尔、巴克、索恩利、钱内尔、霍德尔**的学派建立了环流的证据；**NA-12k** 与古气候的模拟的对比的计划的协议使机制可检验；**RAPID** 的阵列（2004–）使它可观测；**彼得·克拉克**的冰盖的综合、而**安德烈娅·达顿、迈克尔·曼**与 8.2-ka 的团体（2012 的特别的期号）使全新世的事件成为标准；而**伯尔斯**（2021）与**苏珊娜·卡门·迪特尔夫森、而彼得·迪特尔夫森**（2023）把警告的信号的统计——而这个领域最不舒服的问题——带到了现代的记录。打破了均变论的和平的锯齿现在是每一个气候的模型的验证的清单的基线：一个不能做一个 D–O 的事件的模型没有通过物理、只通过记账。
:::

::: quiz
双极的跷跷板描述：
- [ ] 两个半球之间的信风的反转。
- [x] 由大西洋的翻转的环流的热输送驱动的反相的格陵兰与南极的温度变化。
- [ ] 进动的季风循环。
- [ ] 冰期与间冰期的二氧化碳的差。
::: solution
当翻转的环流减弱、北大西洋变冷而南半球变暖（海洋不再向北输出的热留在南、带着南大洋设定的滞后）——把每一个 D–O 与海因里希的事件与热的一个半球的跷跷板联系起来的相位、而南极的"突然的增暖"意味着格陵兰的"突然的变冷"的原因。
:::

::: summary
最后的冰期是约 25 个丹斯高–奥施格尔的增暖（十年的开始、10 °C 的幅度）与海因里希的变冷的一个锯齿、大西洋的翻转的环流在状态之间翻转的一个记录——双极的跷跷板使两个半球轮流、布勒克的大的猜想成为教科书、而年轻的德律亚得与 8.2-ka 的事件证明机制在消冰期与全新世中幸存。现代的弧——RAPID 的观察到的减弱、指纹的临界的减速、注水的实验的淡水的预算的问题、迪特尔夫森的崩溃的日期的争论——使 D–O 的机制成为一个活的观测、不是一个古的好奇、而它对现在的教训是双重的：突然性是大西洋的正常的模式、而速率、不是水平、是杀人的东西。D–O 的世界是"临界点"带着一个记录在它后面进入气候的词汇的原因——而"它能再发生吗"的诚实的答案是"系统还没有被给说不的机会"的原因。
:::

## 练习题

::: exercise {level=1 check="0.5"}
求 20 年中 10 °C 的 D–O 的增暖的速率（°C yr⁻¹）。
::: solution
$10/20 = 0.5$ °C yr⁻¹——现代的全球的速率的两倍、在一个单一的盆地中。
:::
:::

::: exercise {level=1 check="40"}
求 500 年中的 20 m 的融的水的脉冲 1A 的速率（mm yr⁻¹）。
::: solution
$20{,}000/500 = 40$ mm yr⁻¹——现代的海平面的上升的速率的九倍、单从冰。
:::
:::

::: exercise {level=1 check="1200"}
从它的 GICC05 的边界陈述年轻的德律亚得的持续的时间（年）。
::: solution
约 **1,200** 年（12.84–11.65 ka）——在文明的时间标度上的一个完整的冷的纪元。
:::
:::

::: exercise {level=1 check="2"}
在跷跷板中南极的响应滞后格陵兰大约多少年？（以千年答。）
::: solution
约 **2** 千年（1–2 千年）——南大洋对大西洋的消息的慢的读取。
:::
:::

::: exercise {level=2 check="3.2e14"}
求持续 100 年的 0.1 Sv 的体积（m³）（0.1×10⁶ m³ s⁻¹ × 3.15×10⁹ s、在尾数中一个有效数字：例如 1.2e13）。
::: solution
$3.2\times10^{14}$ m³——注水的实验的单位中的一个阿加西湖级的脉冲。
:::
:::

::: exercise {level=2 check="13"}
求 $3.2\times10^{14}$ m³ 的淡水对一个 2.5×10¹⁵ m³ 的亚极地的体积的百分比的变淡。
::: solution
$3.2/25 = 13$%——足以给拉布拉多的海封顶、而停止驱动输送带的下沉。
:::
:::

::: exercise {level=3 check="3"}
从 0.3 上升到 0.7 的一阶的自相关意味着恢复的时间大约延长了多少倍（最接近的整数）？
::: solution
$\ln(1/0.3)/\ln(1/0.7) = 1.20/0.36 \approx 3$——系统的记忆增加了三倍、一个接近一个阈值的系统的统计的签名。
:::
:::

::: exercise {level=3 check="9"}
求融的水的脉冲 1A 的速率（40 mm yr⁻¹）与现代的海平面的速率（4.5 mm yr⁻¹）的比、最接近的整数。
::: solution
$\approx 9$——使冰盖的临界的问题成为定量的、不是修辞的速率的基准。
:::
