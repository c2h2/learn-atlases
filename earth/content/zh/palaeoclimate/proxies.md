一个温度计是一个仪器；一个有孔虫的壳、一棵松树、一个石笋、而一立方千米的冰川的冰也是温度计——不用工程师建造的、对着物理校准的、而读一个没有人记录的气候。**古气候学**是那些仪器的科学、而**代用指标**是它们的感知的元件：档案的材料的测量的性质、随着形成它们的环境变化。学科的整个的可信度依赖一个看似简单的工作流——找一个带着（i）一个连接性质与气候的物理的机制、（ii）一个年代学、不管多粗糙、而（iii）一个在两者重叠的地方对着仪器的记录检验联系的方式的档案——而它的整个的文献是尊重那个工作流、对抗档案的背叛的艺术：生物效应、成岩作用、时间平均、非类似物的气候、而把跨景观的一个梯度误认为通过历史的一个变化的诱人的空间的代替时间的捷径。这一课是工具箱；后续的课（海洋的沉积、冰的芯、深时、全新世）是工具箱建造的东西。

## 一个代用指标的逻辑

::: definition 代用指标、校准、而仪器的时代的检验 {#def-proxy-logic}
一个**代用指标**是一个测量的变量 $x$（同位重比、环的宽度、花粉的百分比、烯酮的未饱和的度）、被持有通过一个**物理的机制**跟踪一个气候的变量 $T$——同位重在不同温度的分馏、一个植物调整它的膜以在冷的水中生长的生物化学、雪的密实的物理。机制为代用指标赢得它的有效性；**校准**为它赢得数字：在现代的世界中把 $x$ 对着 $T$ 回归（网络的回归、岩芯的顶的沉积、为生物化学的指标的培养的实验）、保留独立的站来**验证**技巧、而诚实地陈述不确定——对大多数的代用指标意味着在一个单点上的几度的标准的误差、只有通过跨许多的记录平均才打到低的几分之几度。三个常备的陷阱值得早命名。**空间的代替时间的**：推断一个花粉的组在一个站的通过时间的变化等于今天的跨空间的变化——只有当物种像它们过去做的那样跟踪气候才有效、而非类似物的植被（冰川的伊利诺伊的闭合的云杉的森林、在任何地方没有现代的类似物）违反的；学科的转换的函数（CLIMAP 的 1981 的综合作为著名的第一）是不悔改的空间的代替时间的机器、由验证辩护、而被哲学家攻击从此。**时间平均**：每一个档案低通它的信号——生物扰动把几厘米的沉积抹过几千年、一个 20 年的树记录一个 20 年的均值——所以突然的事件被档案自己的物理衰减、而"证据的缺席"在一个抹过的记录中不是缺席的证据。**发散的问题**：高的纬度的密的网络中的树的环的*宽度*在约 1950 之后停止跟踪夏的温度（使"树对过去好、对现在不可靠"成为一个严肃的文献、不是一个侮辱的效应）、一个警告：校准的时期不是永远的、而每一个代用指标必须对着它声称延伸的仪器的时代重新检查。学科对它自己的怀疑的回答是**复制与等级**：从一个岩芯的一个重建是一个轶事；从一个带着机制、年代学、而验证的网络、它是物理——使曲棍球的杆的争论、带着它们全部的热、成为一个方法起作用的故事的同样的证据的逻辑。
:::

::: example 校准一个由边材做的温度计 {#ex-calibration}
一个 400 个站的网络给出环的密度对六到八月的温度：$\hat{T} = 12 + 0.02\,\mathrm{density\ index}$、残差的散度 $\sigma = 1.8$ °C。一个化石的序列平均 25 个环到一个 46 的指数。求温度的估计、它对那个单一均值的标准误差、而你需要多少个独立的这样的均值为一个 0.2 °C 的它们的均值的标准的误差。
::: solution
$\hat{T} = 12 + 0.02\times46 = 12.9$ °C、带着 1.8 °C 的标准的误差（单点的散度主导；平均 25 个环减少测量的噪声、不是气候的散度、如果年份真的是你在估计的东西）。为网络的均值：$n = (1.8/0.2)^{2} = 81$ 个独立的均值——每一个"我们取了 300 棵树的芯"的方法的部分背后的算术、而重建以几十年的均值说话的原因：噪声是每年不可减少的、而只有复制、跨树、而跨站、买到十分之一度。
:::
:::

## 同位重的基础

::: definition δ 的记法与两个大的分馏 {#def-isotopes}
古气候学以 **δ 值**说话：$\delta = \left(R_{\mathrm{sample}}/R_{\mathrm{standard}} - 1\right)\times1000$、以千分位、其中 $R$ 是一个重的到轻的同位重的比（$^{18}\mathrm{O}/^{16}\mathrm{O}$、D/H、$^{13}\mathrm{C}/^{12}\mathrm{C}$）、对着一个标准（为水的同位重的 VSMOW、为碳的 VPDB）——所以在极地的雪的 δ¹⁸O = −30 ‰ 意味着水相对于它蒸发的海洋在氧–18 是 3 贫化的。两个分馏做几乎全部的工作。**（1）水文的分馏**：蒸发偏好轻的水、冷凝首先把重的水剥出、而每一个顺风的或向极地的接续的风暴因此是同位重的更轻的——这使极地的冰是一个**古的温度计**（更冷的空气持有更少的水分、更多的蒸馏、更多的贫化：达尔斯高的经验的斜率、在格陵兰每 °C 约 0.6–0.7 ‰ 的 δ¹⁸O、是冰芯的科学的最使用的数字）、而使同样的同位重、保存在碳酸盐中、是一个混合的温度计**–与-**冰的体积的信号（有孔虫的冰期的 δ¹⁸O 比全新世的重约 2 ‰：深的水的温度的约 1 ‰、而冰川锁住轻的水时留下的氧–18 富化的海洋的约 1 ‰——IMBIE 的深海的叠置的整个解释的艺术是分开这些）。**（2）光合的分馏**：鲁比科酶与扩散歧视碳–13、C3 的植物记录约 −25 ‰、C4 的植物约 −12 ‰、而海洋浮游植物的分馏随着溶解的二氧化碳变化——所以 δ¹³C 映射植被（晚中新世的 C4 的扩张、给季风的干旱化测年的 C3/C4 的比）、记录碳的循环的扰动（每一次碳的循环的注入带着一个负的 δ¹³C 的偏移——识别古新世–始新世的极暖期与像古新世–始新世的极暖期的事件为碳的循环的事件、不是单纯的增暖的指纹）、而、在浮游的壳的硼与 δ¹³C 中、甚至约束过去的大气的二氧化碳自己。同位重的地球化学家居住的经验的规则：**没有机制就没有代用指标、没有校准就没有数字、没有年代学就没有重建**——组织下面每一个档案的三个检验。
:::

::: example 从一个石笋读温度 {#ex-delta}
一个石笋的方解石在 VSMOW 的标度上有 δ¹⁸O = +21.0 ‰、而古的滴的水估计在 −9.0 ‰ VSMOW。用方解石–水的分馏 $\Delta = 32.4 - 0.24\,T$（Δ 与 δ 以 ‰、T 以 °C）、求洞的温度。
::: solution
$\Delta = \delta_{\mathrm{calcite}} - \delta_{\mathrm{water}} = 21.0 - (-9.0) = 30.0$ ‰、所以 $T = (32.4 - 30.0)/0.24 = 10$ °C。这个练习教的两个小心：样品的 δ 值没有**水**的 δ 值是无意义的（石笋的 δ¹⁸O 读为一个*变化*、不是一个绝对的温度的原因、而带着已知海水 δ¹⁸O 的 的珊瑚与有孔虫能作为绝对的温度计）、而分馏的方程是一个校准——换错标准的标度（PDB 与 VSMOW 对碳酸盐差约 31 ‰）而洞出来是熔化的或冻结的。
:::
:::

## 档案的动物园

::: definition 生物的、洞穴与湖泊、物理的与人的档案 {#def-archive-zoo}
**树**（树木年代学、由**A. E. 道格拉斯**创立、他证明环能通过交叉的匹配测年、而把树的环带进考古学）：年的分辨率、通过把活的树与亚化石的木材重叠而跑到 12,000+ 年的绝对的年代学；为水分、而（在高的纬度的水分限制的带）为暖的环的*宽度*、为夏的温度的最晚的木材的**密度**（**凯思·布里法**的高的密度的网络背后的代用指标）、而纤维素中的同位重为了湿度；代价是短的、零散的、大陆主导的覆盖、而发散的问题。**花粉**（**法格雷与伊韦森**的定量的传统）：风的花粉的雨在区域上有代表性、而许多科的分类单元能识别到物种的水平、而转换的函数把百分比的曲线变成温度与降水、在千年的均值上带着约 1–2 °C 的技巧——第四纪的植被–气候的科学的主干、对驱动气候的海洋盲（像所有陆地的档案）。**海洋与湖的微体古生物**：有孔虫（方解石的测试：氧同位重、镁钙、锂同位重、而组合）、硅藻（硅石、湖与海、盐度与冰）、放射虫、介形虫、摇蚊（头的胶囊；北极的浅的湖的夏的温度主力、技巧约 1 °C）、而**烯酮**——鞭毛藻为膜的流动性调谐的长的链的酮、它的不饱和的指数 $U^{K'}_{37}$ 是一个液体的蒸发的温度计、精度惊人（在单个的岩芯上 ±0.5 °C）、而大多数新生代的海表温度曲线的基础（它们由**布拉塞尔、埃格灵顿**与同事在 1978 年的发现创造了这个领域）。**石笋**（2000 年代的同位重的革命）：分带的方解石、通过 600 kyr 到几十年的精度铀钍测年、跟踪水分源与量的 δ¹⁸O、微量元素与流体的包裹体增加季节性——把突然的变化的检测从冰移到大陆的档案、代价是一个混合降雨的速率、源、而路径、必须一站一站地读的 δ¹⁸O 的信号。**冰盖**（下一课的主题）、**湖的沉积**（纹泥的湖：年的带作为树的环的大陆的类似物；萨顿海、休伦、而非洲的裂谷的湖）、**珊瑚**（年的带、铀钍、在*年的*分辨率的 δ¹⁸O 与锶钙——唯一直接在化石中读 ENSO 的档案）、**钻孔**（千米的大陆的岩石的温度的记录、地球上最慢的温度计、而唯一的一个不带生物地积分几十年的）、而**人的档案**（书写的收割与冻结的记录——中国的编年史、欧洲的编年史、冰岛的编年史——它们的硬的世纪是最后的两千年的课的校准的数据）。没有单个的档案跨越范围；学科的强度是**多代用指标的收敛**——当冰、泥、洞、树与文献独立地指向同一个方向、古气候学不再是解释、而成为测量。
:::

::: example 从一个沉积的岩芯的一个年龄模型 {#ex-agemodel}
一个湖的岩芯在 2.0 m 有一个测年的火山灰（放射性碳的年龄 8,000 年）、而表面是现代的；假设之间的恒定的沉积。求在 0.5 m 的一个样品的年龄、而如果你在 2 mm 的间隔采样、年龄的分辨率（每毫米的采样的年）。
::: solution
沉积的速率 $= 2.0\ \mathrm{m}/8000\ \mathrm{yr} = 0.25\ \mathrm{mm\,yr^{-1}}$；0.5 m 的样品坐在火山灰之上 $1.5\ \mathrm{m}$ = 比表面年轻 6000 年、所以它的年龄是 $8000 - 6000 = 2000$ 年。分辨率：在 0.25 mm yr⁻¹ 的 2 mm 是**每一个样品 8 年**——对几个世纪的标度的事件好的、对单个的十年无望的、而生物扰动的顶部的几厘米会抹掉甚至那个：这个练习是每一篇论文在印一条气候的曲线之前印它的年龄的模型与它的采样的分辨率的原因。
:::
:::

## 读碳的气体自己

::: definition 二氧化碳的代用指标与温度计的问题 {#def-co2-proxies}
最难的古气候的数字是这个学科最想要的：过去的大气的二氧化碳与过去的绝对的温度、每一个因为它的代用指标恰好在它们最需要的地方最弱。**二氧化碳的代用指标**分为三个家庭。**气孔的频率**：叶在二氧化碳上升时发育每单位面积更少的气孔——一个在任何植物学的实验室可能的生理的校准、而在化石的角质层上可测量——所以从泥盆纪到新近纪的深时的二氧化碳的曲线在叶保存的地方存在、带着响应在高二氧化碳饱和、而物种特殊的偏移要求仔细的植物的识别的警告。**硼的同位重**（有孔虫的方解石的 δ¹¹B）：海水的硼酸盐的 δ¹¹B 是酸碱度的一个直接的函数、而酸碱度与一个碱度的估计一起给出二氧化碳——气体的唯一的化学的温度计、新生代的二氧化碳的曲线与今天的海洋的酸化的类似物的基础、受限于重建过去的海水的碳酸盐的化学的需要（同样困扰今天的酸碱度–碱度的系统的简并、在百万年的岩芯上反向运行）。**古植物学的与古土壤的碳酸盐**（碳同位重与叶缘的质量的平衡）填补陆地的洞。**温度计的问题**是它的孪生：绝对的温度计——团簇的同位重（Δ₄₇、碳–13 与氧–18 进入同一个碳酸盐的分子的温度的依赖的结合、由**戈什与艾勒**在 2006 年发明、而现在是一个带着成岩作用的警告的真正的地质温度计）、镁钙与锂钙的比、四醚的膜脂的指数、而鱼的耳石与生物磷灰石的氧的比——每一个带着系统的偏移、生物效应、而校准的争论、而它们在热的一端的分歧（白垩纪的热带的海洋比它们看起来暖 5 °C、还是水是同位重的重的？）是活跃的前沿。整个的课向前携带的方法的道德：**把每一个代用指标当作一个带着校准的曲线、噪声的地板、而失败的机制的仪器**——而把任何一个改变教科书的单的数字当作一个等待它的第二个档案的假设。
:::

::: example 气孔作为一个二氧化碳的刻度盘 {#ex-stomata}
一个银杏的栽培的品种发育气孔的指数 $S = 20 - 0.008\,C$（C 以 ppm、有效的 200–800 ppm）、而一片来自古新世–始新世的极暖期（56 Ma）的化石的银杏的叶有 S = 8。估计它的二氧化碳、而解释为什么估计以一个倍数、不是一个西格玛引用。
::: solution
$C = (20-8)/0.008 = 1500$ ppm——在校准的 800 ppm 的天花板之外、所以数字是一个**外推**、而诚实的陈述是"≥800 ppm、可信的 1000–2000"。这个练习是在一个减法中的整个的温度计的问题：生理在它演化的范围内漂亮地校准、而深时的气候住在那个范围之外、而学科的回答不是假装精度、而是堆叠独立的代用指标（气孔、硼、同位重的质量平衡）、直到它们的重叠将答案括起来。
:::
:::

caption: 烯酮的温度计——$U^{K'}_{37} = (1+e^{0.034(T-29.5)})^{-1}$、鞭毛藻的膜的流动性的刻度盘、由气体的色谱测量、而在培养与岩芯顶部样品中校准。在大约 −1 与 30 °C 之间指数从 0.9 平滑地移动到 0.1；在那个范围之外生物的刻度盘饱和、而代用指标、像所有的刻度盘、必须在它被建造来工作的地方使用。

::: warning 代用指标不是温度计、复制不是证明、收敛不是机制、而年代学是最弱的环节
五个错误。**"这个壳的 δ¹⁸O *就是*温度"**：它是一个带着两个控制的变量（水的 δ¹⁸O 与分馏）加生物效应、成岩作用、而物种特殊的偏移；海洋的同位重的叠置起作用、因为*全球的*冰的体积的信号在轨道的周期上使噪声相形见绌、不是因为任何一个壳是一个温度计——古气候学的单位是群体、不是标本。**"更多的代用指标 = 更好的重建"**：相关的错误——同样的季风、同样的 ENSO、同样的测年的方法——不平均掉；曲棍球的杆的时代ing的教训不是"更多的岩芯"、而是**网络的设计**：跨带着独立的年代学的独立的档案的复制。**当代用指标分歧时、平均它们"**：分歧是数据——一个树说湿而一个石笋说干的、要么是季节性的差异（树在春天生长、洞在季风滴）要么是信噪的失败、而成熟的文献现在把*分歧的格局*（全新世的温度的重建对模型的"季节性的谜"）读为它自己的发现。**"日期足够好"**：大多数的古气候的最大的预算是年代学、不是代用指标——一个 500 年的年龄的模型的误差把一个 200 年的超前–滞后变成一个 700 年的、从而可能颠倒因果；学科的大进步（洞中的铀钍、冰中的波动的匹配、泥中的贝叶斯的年龄的模型）是穿气候的衣服的测年的进步。**而"校准的时期是可能的极限"**：发散的问题警告树停止了跟踪；推论是过去的一些状态（始新世、古新世–始新世的极暖期）住在每一个现代的校准**之外**——在烯酮的刻度盘的范围之外、在转换的函数的最近的类似物之外——古气候学必须退回到基于机制的同位重的理论、而它的回答相应地更谦逊、而它对模型的比较的需要相应地更大。
:::

::: history
档案的想法比仪器更老：**拉马克**在 1800 年注意化石的气候的意义、**路易斯·阿加西**在 1830–40 年代顶着激烈的抵抗把冰川的擦痕与漂砾读成一个冰期的地球、而**米兰科维奇**的机制（1920 年代、这一课的轨道的循环的课）在存在检验它的证据之前供给理论。证据来自二十世纪的物理：**尤里**的 1947 的预测——同位重的分馏是温度的依赖的、**埃普斯坦与真木田**在同一十年在碳酸盐中的测量、**丹斯高**自 1950 年代的常规的冰芯的 δ¹⁸O 的剖面、而他在 1960 年代的发现温度的关系与格陵兰的突然的事件的地层学、而**切扎雷·埃米利亚尼**的 1950–55 的有孔虫的同位重的地层学、它把深海的岩芯变成米兰科维奇预报的冰期的编年史。**伦纳特·冯·波斯特**的花粉的图（1910 年代的瑞典）与**法格雷与伊韦森**的教科书使植被的历史定量化；**道格拉斯**使树成为绝对的；**布拉塞尔、埃格灵顿**与同事的 1978 的烯酮的发现使分子成为温度计；**CLIMAP** 的项目的 1981 的转换的函数的图集使最后的冰期的整个的地球成为一个综观的图。1990–2000 年代的方法的转折——验证的统计、贝叶斯的年龄的模型、铀钍测年的石笋、而以曼恩、布拉德利与休斯开始的重建的网络的争论——把古气候学从一个聪明的读的集合转换成一个带着误差的条的观察的科学、而它的误差的条现在对每一个模型的未来重要的那一个。
:::

::: quiz
树木气候学的"发散的问题"指的是：
- [ ] 树的环在冰期与冰的芯分歧。
- [x] 环的宽度与密度在约 1950 之后在一些高的纬度的网络中停止跟踪夏的温度。
- [ ] 树在二氧化碳富集的大气中长得更高。
- [ ] 放射性碳的校准的曲线与树的环分歧。
::: solution
在环极的北方的一部分、环的宽度在世纪的中期之后停止跟踪仪器的增暖（可能的原因：干旱的胁迫、湿度–云的改变、而可能对光合的污染的效应）——所以基于密度的与早的时期的数据小心地使用、而这个事件作为学科的常备的警告：校准是时期绑定的。（放射性碳–树的分歧是一个独立的、解决了的故事——校准的曲线自己。）
:::
:::

::: summary
代用指标是自然的仪器：同位重的分馏（水文的、光合的、矿物的）而生物的功能（环、花粉、烯酮、测试）记录温度、水、而碳、只能通过机制、对着现代的世界的校准、而一个年代学读。档案的动物园——树、花粉、微体古生物、烯酮、石笋、冰、湖的纹泥、珊瑚、钻孔、编年史——覆盖不同的跨度、分辨率、而域、而没有单个的档案足够；学科的证据的强度是带着独立的错误的多代用指标的收敛、而它的常备的警告是空间的代替时间的、时间平均、发散、而几乎总是最弱的环节的年代学。从阿加西的漂砾、到丹斯高的冰、到布拉塞尔的分子、历史是把聪明的读数变成测量的过程——使只有 150 年长的仪器的时代能被 5 亿年深的档案放在背景中。
:::

## 练习题

::: exercise {level=1 check="-10"}
求一个带着 R/Rstd = 0.990 的样品的 δ¹⁸O（‰、最接近的整数）。
::: solution
$(0.990-1)\times1000 = -10$ ‰——古气候学的本地的算术的千分位的记账。
:::
:::

::: exercise {level=1 check="2000"}
在年龄的模型的例子中（在 2.0 m 的火山灰测年 8,000 年、恒定的速率）、求在 0.5 m 的深度的年龄、以年。
::: solution
速率 0.25 mm yr⁻¹；火山灰之上 1.5 m 年轻 6,000 年：年龄 $= 2000$ 年。
:::
:::

::: exercise {level=1 check="8"}
同样的岩芯：求一个 2 mm 的样品的时间的分辨率（年）。
::: solution
$2\ \mathrm{mm} / 0.25\ \mathrm{mm\,yr^{-1}} = 8$ 每一个样品年——对几个世纪足够的、对十年盲的。
:::
:::

::: exercise {level=1 check="2.1"}
丹斯高的在格陵兰的斜率是每 °C 约 0.7 ‰。求一个 −3 °C 的变冷的 δ¹⁸O 的变化（‰、幅度）。
::: solution
$0.7\times3 = 2.1$ ‰ 的贫化——更冷的空气把它的水分蒸得更干、而冰写下算术。
:::
:::

::: exercise {level=2 check="3.5"}
陈述在丹斯高的 0.7 ‰ °C⁻¹ 的一个 5 °C 的变冷的 δ¹⁸O 的偏移（‰）。
::: solution
$3.5$ ‰——而注意符号：在极地的降水中更冷意味着*更负*的 δ¹⁸O。
:::
:::

::: exercise {level=2 check="15.3"}
有孔虫的镁钙的古的温度计：$\mathrm{Mg/Ca} = 0.38\,e^{0.09T}$。求 Mg/Ca = 1.50 的 T（°C、一位小数）。
::: solution
$T = \ln(1.50/0.38)/0.09 = \ln(3.95)/0.09 = 1.373/0.09 = 15.3$ °C——而注意为什么镁钙与 δ¹⁸O 一起使用：一个需要另一个来分开温度与冰的体积。
:::
:::

::: exercise {level=3 check="81"}
求为它们的均值的 0.2 °C 的标准误差需要的独立的重建的均值（每一个 σ = 1.8 °C）的个数。
::: solution
$n = (1.8/0.2)^{2} = 81$——在这个领域的每一张网络的图背后的复制的算术。
:::
:::

::: exercise {level=3 check="0.5"}
一个转换的函数带着现代的数据的集的技巧 σ = 4 °C；一个重建平均 64 个岩芯的顶。求均值的估计的标准误差（°C）。
::: solution
$4/\sqrt{64} = 0.5$ °C——使 CLIMAP 的冰期海表温度的图、带着它们全部的空间的代替时间的包袱、在统计上严肃的岩芯的顶的平均、即使在哲学上有争议的地方。
:::
:::
