在沉积–水的界面之下躺着行星为自己保存的气候的记录：地球的表面的 70 是海洋、它的底是水柱与大陆所输送的一切的汇、而在供给稳定、水足够深的地方、软泥像一个慢的节拍器积累——每一千年一或两厘米、每一厘米一个由壳、尘土、而化学沉积的、没有人记录过的季节的一页。那个档案的回收是二十世纪的伟大的工程与科学的合作之一：从挑战者号的 1872 的第一次的拖捞 到深海钻探计划与它的后继者的钻的船队、它们自 1968 把岩芯推过沉积的堆、而与它们一起、一个整个的地球的历史的哲学——读行星的方式是**在一个网格上采样它、而给你找到的一切测年**。这一课是沉积自己：它由什么构成、它能被说出什么、而它以最慢的动作保存的事件——缺氧的 episode、沙原、冻结在钙质的软泥中的沙尘暴。

## 沉积的背景

::: definition 四种沉积、一个化学、而溶解的过滤器 {#def-sediment-types}
海洋的沉积按源分成四个家庭、而它们的地图是气候与环流的地图。**钙质的软泥**（有孔虫与球石——白垩纪的白的白垩是它的极端）主导快速积累的、良好地冲洗的低纬度的海底；**硅质的软泥**（硅藻与放射虫）统治上升流的边缘（东部的边界、南大洋的硅藻的带）、在那里养分喂养玻璃、不是白垩；**陆源的（岩的）泥与黏土**记录大陆——河流、冰山（海因里希的事件的"冰的漂送的碎屑"、在冰山融化的地方投下）、而风（北太平洋的红黏土是亚洲的尘土、它们的积累的速率的曲线是新生代的季风与抬升的编年史之一）；而**水成的与宇生的**物质（锰的壳、地外的球粒、而从太平洋的泥回收的稀有的铁的陨石）供给地球化学的杠杆。使系统危险的过滤器是**碳酸盐的化学**：方解石的补偿的深度（约 4–5 km、在二氧化碳更贫的冰期的世纪的海洋中更浅）在它的溶解的线之下溶解每一个壳、所以一个比方解石的补偿的深度更深的海盆**不记录碳酸盐**——而因此没有氧同位重的地层学——恰恰在最好地保存缺氧与偏移的记录的海盆中；蛋白石的补偿的深度对硅质的档案玩同样的把戏。积累的速率跨越六个数量的级（开放的–远洋的约 1 cm/kyr；浊积岩的通道每一事件的年几米；深海的红黏土每一千年一毫米）、而每一个岩芯因此是一个必须声明它的截止的低通的滤波器。最后的背景是**生物扰动**：掘的生物与沉积食者在顶部的 5–20 cm——在典型的积累的速率、最后的几千年——翻搅、模糊事件的层、把年轻的壳向下、老的壳向上再循环、而设定每一个"千年的标度的稳定"的主张必须越过的分辨率的地板。
:::

::: example 质量的积累与尘土的账本 {#ex-mar}
一个北太平洋的岩芯以 4 cm kyr⁻¹ 积累、带着 0.5 g cm⁻³ 的干的容重。求以 g m⁻² yr⁻¹ 的总的质量的积累的速率、而如果 60 是陆源的非碳酸盐（尘土）的通量——注意现代的风的尘土到这个区域是约 10 g m⁻² yr⁻¹。
::: solution
$\mathrm{MAR} = 4\ \mathrm{cm\,kyr^{-1}}\times0.5\ \mathrm{g\,cm^{-3}} = 2\ \mathrm{g\,cm^{-2}\,kyr^{-1}} = 20\ \mathrm{kg\,m^{-2}\,kyr^{-1}} = 20\ \mathrm{g\,m^{-2}\,yr^{-1}}$；尘土的部分是 $0.6\times20 = 12$ g m⁻² yr⁻¹——比今天的值高几倍、冰期的尘土的主张的标准的形式（干旱的扩大的源的区域、更强的风、而一个更浅的方解石的补偿的深度同时）、而"冰期更多尘"变成一个数字、不是一个形容词的算术。
:::
:::

## 读有孔虫

::: definition 浮游的与底栖的、组合与化学 {#def-forams}
有孔虫——带着钙质的测试的单细胞的原生生物、一些生活于表面、一些爬于底——是深海的主力、因为它们丰富、物种丰富、对温度诚实、而能保存、而它们以两个记录读。**组合的记录**数物种：浮游的组合由转换的函数转换成海的表面的温度、盐度、而季节性（CLIMAP 的 1981 的现代的类似物的机器、精炼成带着约 1–2 °C 的技巧的现代的转换的函数与的方法）、底栖的组合转换成底的水的温度与氧；*厚壳壁四室虫*的卷曲的方向（左卷的极地的、右卷的亚极地的）是经典的单物种的温度计、而组合的第一条规则——**物种的生态学假设是恒定的**——是与别处一样的均变论的赌注。**化学的记录**测量测试自己：氧同位重（底栖的是冰的体积加底的水的温度、全球的冰的体积的曲线的骨干——底栖的记录被冰期–间冰期的水的信号主导、那是叠置读冰盖、不是本地的气候的原因）；镁钙、锂钙、而硼与团簇的同位重的系统为了温度与酸碱度；镉钙、而稀土为了营养的水的团的混合（大西洋的营养的冰期的重组、太平洋的碳的储层）；而碳同位重、它的深的水的梯度映射大西洋的从表面到深的翻转与太平洋的迟钝的层化之间的平衡——每一个"输送带停了吗？"的主张背后的示踪剂。两个记录互相对照、而对着沉积学（分选、冰的漂送的碎屑、稀土的格局）对照、因为有孔虫的一个常备的弱点是**溶解与选择性的保存**：记录由幸存的东西写下、而保存的指数（碎片的丰富、测试的蚀刻）必须画在每一条同位重的曲线旁边——这个学科的检查温度计有没有熔化的版本。
:::

::: example 叠置作为一个冰的计 {#ex-stack}
底栖的氧同位重的叠置 LR04 从全新世的约 3.3 ‰ 跑到冰期的极大的约 5.3 ‰。在那 2.0 ‰ 的幅度中、大约 1.0 ‰ 是**水**（冰的体积）的信号、而 0.1 ‰ 的水的同位重的变化对应约 11 m 的海平面。估计冰期–间冰期的海平面的下降、而对着珊瑚与陆架的估计（约 120 m）比较。
::: solution
1.0 ‰ 的水的半幅度暗示 $1.0/0.1\times11 = 110$ m——在从抬升的珊瑚的阶地读的 120 m 的一根头发的范围内、那是验证两个档案的交叉的检验。底栖的幅度的剩下的约 1.0 ‰ 是深的水的变冷、而分开两者（在同样的岩芯上的镁钙或团簇的同位重）是 IMBIE 的纲领的常备的任务：底栖的氧同位重是一个冰的计**在校准之后**、不是直接的。
:::
:::

## 以最慢的动作的事件

::: definition 缺氧的事件、沙原、而地中海的学校 {#def-events}
不是所有的记录都是渐变的雨：海底的档案的戏剧性的章节是**事件**。白垩纪的**海洋的缺氧的事件**——阿普特的缺氧的事件 1a（约 120 Ma）与森诺曼–土仑的缺氧的事件 2（约 93.5 Ma）、它们的黑色的页岩覆盖每一个海洋的海盆、带着巨大的碳同位重的偏移、而记录白垩纪的中期的温室的产量–缺氧–汞（缺氧的事件 2 的加勒比的大火成岩省）的反馈——是这个图集中每一个"快的碳的加入"的论证的深时的先例、而古新世–始新世的极暖期的海洋的章节（底栖的灭绝、碳酸盐的溶解、一个 −3 ‰ 的碳的同位重的偏移）是它的仪器最好的更小的兄弟、在深时的课中覆盖。**沙原**是地中海的纹泥：几十层黑的、富有机物的层（全新世的 S1、沉积在约 9–6 ka、最厚而测年最好的）交错在海通常的浅色泥灰岩中、在非洲的季风的雨把尼罗河变成一条沉积与养分的河、使表面变淡、层化海盆、而使它的底缺氧时沉积——写在海中的非洲的湿润的时期、而**一个海盆的档案记录的区域的水文的改变**的类型案例。地中海总体是这个学科的教室：**墨西拿的盐度的危机**（5.96–5.33 Ma）、当海盆蒸发成一个深的含石盐的沙漠、它的蒸发岩现在持有烃的储层、是海盆的隔离的端元；**年轻的德律亚得的沙原**与全新世的千年的标度的盐度的记录是它的突然的变化的实验室；而黑海的"沙原"——曾经是灾难性的全新世的地中海的流入的洪水的证物、现在读为一个更渐变的变淡——是警示的同伴、一个戏剧性的假设被更好的取芯与测年正确地降级的教科书的案例。现代的增加是**慢的事件**：沉积物陷阱与时间序列的系泊的记录看着海底的生物在实时中响应海洋的季节的与多年代的强迫、而**海底下的生物圈**——钻探的项目发现的千米的深的、能量饥饿的微生物的省、它的新陈代谢改变古气候的读者使用的恰恰地球化学、而它的存在在氧同位重的地层学成熟的同一个时刻改写了全球的碳的循环的预算。
:::

::: example 沙原 S1 的账本 {#ex-sapropel}
一个东地中海的岩芯中的沙原 S1 是 42 cm 厚、跨越 9.0–6.0 ka、而含 4 的有机的碳（干的密度 0.8 g cm⁻³）。求它的有机的碳的质量的积累的速率、以 g m⁻² yr⁻¹、而对着上面的泥灰岩（约 0.1 g m⁻² yr⁻¹）比较。
::: solution
积累 $= 42\ \mathrm{cm}/3000\ \mathrm{yr} = 0.14\ \mathrm{cm\,yr^{-1}}$；有机的质量的积累的速率 $= 0.14\times0.8\times0.04\times10^{4} = 4.5$……工作的单位：$0.14\ \mathrm{cm\,yr^{-1}} \times 0.8\ \mathrm{g\,cm^{-3}} = 0.112\ \mathrm{g\,cm^{-2}\,yr^{-1}} = 1120\ \mathrm{g\,m^{-2}\,yr^{-1}}$ 总的、乘 4 = **45 g m⁻² yr⁻¹** 的碳——上面的泥灰岩的约 400 倍、季风的尼罗河的数字、而 S1 在一个地震的剖面上跨海盆可见的原因：一个整个的气候的机制、记录为一条一手能拿的黑的带。
:::
:::

## 扫描的革命

::: definition X 射线的荧光的岩芯的扫描器与快的化学的革命 {#def-xrf}
2000 年代带来了档案的计算机断层的扫描：**X 射线的荧光的岩芯的扫描器**沿着一个展开的岩芯跑一个束、而返回元素的比（钙钛为了碳酸盐的内容、铁钛为了陆源的输入、锰铝为了氧化还原、锆铷为了颗粒的大小、钙硫为了硫化物与自生的碳酸盐）在亚毫米的间隔——每一个岩芯几千个分析、在采样质谱的一小部分的费用。这个方法把一个沉积的岩芯从一把同位重的点变成一个连续的化学的剖面、使没有纹泥的基准中的纹泥的标度的地层学可能、而创造了一个它自己的真正的解释的纪律：扫描器的比是**表面的与湿度敏感的**（沉积中的水衰减束；干燥改变结果）、颗粒的大小与分选的效应冒充源的改变、而每一个比必须对着船上的测量地面真值——低成本传感器的教训在地球上最干净的实验室中重演。与高光谱成像（颜色作为黏土的矿物与有机物的代用指标）、计算机断层的扫描（掘的洞、纹层、浊积岩的结构自动地数）、而原位的孔隙水与微标的同位重的采样（季节的分辨率上的有孔虫的室的激光的烧蚀）配对、扫描器的一代使**年的到十年的标度的事件的地层学**在良好地分带的背景中成为例行的——纹泥湖、沙原、缺氧的海盆——而把这个领域的前沿从"我们能测量它吗？"推到"我们能相信一个在湿的泥上的束的第五个十进位吗？"（回答：带着地面真值、是的；没有、从不）。
:::

::: example 从一个束的颗粒的大小 {#ex-zrrb}
一个扫描器的锆/铷的比（粗的部分的锆对黏土的携带的铷）在一个浊积岩的层期间从一个 0.6 的背景升到 1.4、而这个站的校准是 $\log(d\,[\mu\mathrm{m}]) = 1.0 + 1.5\,\mathrm{Zr/Rb}$。求以 µm 的背景与事件的颗粒的大小、而分类两者。
::: solution
背景：$\log d = 1.0 + 0.9 = 1.9$、$d = 10^{1.9} \approx 79$ µm——粗的粉砂、普通的半深海的雨。事件：$\log d = 1.0 + 2.1 = 3.1$、$d \approx 1260$ µm——很粗的砂、一个真正的浊流。在一个校准中的两个教训：扫描器的比是**站校准的**关系（截距与斜率来自这个海盆的筛的样品、不是从理论）、而颗粒的大小的跳——不是比自己——是地质的陈述、因为同一个比的移动在没有跑过校准的任何地方可能意味着分选、源、或流的速度。
:::
:::

::: warning 海底记录时带一个橡皮、相关不是测年、保存过滤一切、而"缺氧"不意味着"无生命"
五个错误。**"每一个站有一个连续的记录"**：海底是一个侵蚀与非沉积的地方、像一个积累的地方一样多——等深流的冲刷、浊积岩切通道、方解石的补偿的深度删除碳酸盐、而一个"空段"在露头上能是几百万年厚、在岩芯中不可见；连续记录的站是一个选择的少数、而它们的连续性是一个发现、不是一个假设。**"这个站的碳同位重的偏移给事件测年"**：它给**这个站的**偏移测年、而偏移的开始在一个海盆的环流与生物学中差几个世纪到几千年是异时的——事件的地层学需要多站、多代用指标的联系（火山灰、磁性的、生物地层的）才允许"同时的"。**"保存的差异是噪声"**：它们是信号的携带者——方解石的补偿的深度的通过时间的深度自己是一个碳的循环的记录（它的冰期的变浅记录海洋的二氧化碳的吸取）、而读一个溶解影响的同位重的曲线为纯的源的信号是这个领域的最常见的过度的解释；保存的指数属于每一条曲线旁边、恰恰因为"噪声"是论文的另一半。**"白垩纪的海洋的缺氧的事件证明从任何增暖的快的缺氧"**：海洋的缺氧的事件要求缺氧的端元的气候、省标度的火山作用、而长的停留的时间；它们是可以的包络、不是这个世纪的模板——诚实的使用是机制（产量、层化、养分的反馈）、不是速率。**而"海底下是岩石"**：它是一个生物圈、带着在一个地方与海底的输入相当的碳与能量的通量、它的新陈代谢移动碳、硫、而（对读者关键的）**在沉积之后改变同位重签名**——早成岩的铁锰的再移动、硫酸盐驱动的过程重置硫的同位重——所以档案的最近的修订是承认我们读为古老的海洋的一部分是古老的*沉积的生物学*、最好带着手中的孔隙水的化学读。
:::

::: history
档案比它的科学更老：**挑战者**的远征（1872–76）从几千个测深与拖捞命名了软泥的省（抱球虫、放射虫、红黏土）、而创立了海洋的沉积学、而从未见到一个柱。柱随着 1940–50 年代的**石油的取芯**来、而决定性地、随着**深海钻探计划**（1968–83、*格洛玛·挑战者号*）、它的第一次的航次检验板块的构造、而它的白垩纪–古近纪与南大西洋的回收改写了地层学；**大洋钻探计划**（1985–2003、*乔迪斯·决心号*）与**综合大洋钻探计划**（2003–13、带着钻塔的船*地球号*到达深的生物圈与深的过去）使网格工业化、而它们的沉积学的综合——方解石的补偿深度的曲线、尘土的通量、海洋的缺氧的事件的样带——把新生代建造为一个系统。同位重的读从**切扎雷·埃米利亚尼**的有孔虫的古温度（1950 年代）、**沙克尔顿与奥普迪克**的 1973 的论证——深海的氧同位重的波是调谐到米兰科维奇的天文学的冰盖的全球信号（使冰期的理论成为一个测年的科学的论文）、**沙克尔顿、因布里**与同事的阶段命名法与 1970–80 年代的 SPECMAP 的调谐、而**里斯伊基与雷莫**的 2005 的 LR04 的叠置——仍然在日常使用的共同体的年代学——成长。地中海的学校——从深海钻探计划第 13 航次期间的**墨西拿的蒸发岩**的发现（1968、当钻在海底之下击中石盐、而海盆的干燥成为事实）、通过赖恩的**沙原**的传统与白垩纪的海洋的缺氧的事件的综合——供给这个学科的事件的思维、而它黑海的洪水假设、被更好的岩芯向下修订、仍然是这个领域关于灾难的诱惑力的最好教学的教训。钻探的时代的最后的章节——寻找中新世与渐新世的海洋的剖面来给最后的 25 Myr 的构造–气候的转变测年、而以南极与北极的覆盖冰的海盆之下的最老的开放的海洋的沉积为目标的以远征为基础的竞赛——使档案以读的方法改进的同样速率增长。
:::

- [x] 从低于它的深度的深的海盆删除碳酸盐的档案（与它的同位重）。
- [ ] 浓缩锰的结核。
- [ ] 增加在深度的生物扰动。
::: solution
在方解石的补偿的深度之下没有钙质的软泥幸存、所以最深的水的站——常常是最好的缺氧的事件的档案——完全不带氧同位重的地层学；方解石的补偿的深度的通过时间的深度自己是一个碳的循环的代用指标、而方解石的补偿的深度在冰期的世纪的变浅是冰期的海洋的二氧化碳的再分配的证据。
:::
:::

::: summary
海洋的沉积是带着最好的时间的基础、而最坏的记忆的气候的档案：四个沉积的家庭（碳酸盐、蛋白石、陆源的、水成的）以跨越六个数量的级的速率沉积、由溶解（方解石的补偿的深度）过滤、而由掘穴的生物弄污、自 1968 由把海底变成一个测年的网格的钻探的项目回收。有孔虫在两个记录中负担载荷——作为生态学的组合、作为冰的体积、温度与环流的化学（氧同位重、镁钙、碳同位重、镉钙）——而底栖的叠置是第四纪的主的钟。事件——白垩纪的海洋的缺氧的事件、古新世–始新世的极暖期的海洋的章节、地中海的沙原与墨西拿的盐——是档案的系统改变机制的证明、而黑海的降级的洪水与海底下生物圈的事后的修订是档案必须像读它一样仔细地审计的证明。
:::

## 练习题

::: exercise {level=1 check="5"}
一个 500-cm 的活塞的岩芯跨越 100 kyr。求以 cm kyr⁻¹ 的均值的沉积的速率。
::: solution
$500/100 = 5$ cm kyr⁻¹——一个快的边缘的站；每一厘米半个世纪。
:::
:::

::: exercise {level=1 check="2"}
生物扰动混合顶部的 10 cm；沉积是 5 cm kyr⁻¹。求一个沉积的层在混合的层中的停留的时间、以 kyr。
::: solution
$10/5 = 2$ kyr——分辨率的地板：比几千年更尖锐的任何事件在这个站被衰减、不管它测年多好。
:::
:::

::: exercise {level=1 check="20"}
求以 4 cm kyr⁻¹ 在干的密度 0.5 g cm⁻³ 积累的沉积的质量的积累的速率（g m⁻² yr⁻¹）。
::: solution
$4\times0.5 = 2$ g cm⁻² kyr⁻¹ $= 20$ g m⁻² yr⁻¹——远洋的速率是小的数字；这个学科住在几十、不是几千。
:::
:::

::: exercise {level=1 check="12"}
在尘土的账本的例子中（质量的积累的速率 20 g m⁻² yr⁻¹、60 是陆源的）、求尘土的通量。
::: solution
$0.6\times20 = 12$ g m⁻² yr⁻¹——现代的风的供给的几倍、在一个乘法中的冰期的尘土的陈述。
:::
:::

::: exercise {level=2 check="110"}
用每 0.1 ‰ 的*水*的氧同位重约 11 m 的海平面、求 1.0 ‰ 的水的同位重的变化的海平面的等价。
::: solution
$1.0/0.1\times11 = 110$ m——使叠置与 120-m 的珊瑚的海平面的记录调和的 IMBIE 的水的幅度的逻辑。
:::
:::

::: exercise {level=2 check="45"}
求沙原 S1 的有机的碳的质量的积累的速率（g m⁻² yr⁻¹）：积累 0.14 cm yr⁻¹、密度 0.8 g cm⁻³、4 的碳。
::: solution
$0.14\times0.8\times10^{4}\times0.04 = 45$ g m⁻² yr⁻¹——泥灰岩的四百倍、写为黑的带的季风。
:::
:::

::: exercise {level=3 check="400"}
S1 的有机的碳的积累（45 g m⁻² yr⁻¹）超过上面的泥灰岩的（0.1 g m⁻² yr⁻¹）多少倍？
::: solution
$45/0.1 = 400$——在一个季风的日程上的海盆的富营养化、而沙原是全新世的最可见的地层的单元的原因。
:::
:::

::: exercise {level=3 check="0.5"}
一个转换的函数的海面的温度的重建带着现代的类似物的技巧 σ = 2 °C。求 16 个岩芯的顶的均值的标准的误差。
::: solution
$2/\sqrt{16} = 0.5$ °C——CLIMAP 的平均的逻辑：单点是含糊的、均值是严肃的。
:::
:::
