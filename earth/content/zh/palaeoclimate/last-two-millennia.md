在 1815 年 4 月、一个山脉的大小的火山结束了它与天空的争论、而接下来的一年——1816 的"没有夏天的年"——给了欧洲十三个月的雨、在奥尔巴尼的六月的霜、收割的失败、而西方世界的最后的生存的饥荒、而在一个日内瓦的别墅里一个颤抖的拜伦勋爵的家庭聚会因为太阳不出来而凭烛光发明了弗兰肯斯坦。坦博拉的冬天是发生**在**历史的记录**上**的最后的大气候的事件；自那以后的一切都发生**在**它**之中**、因为坦博拉之后的两个世纪建造了使最后的两千年成为一个实验室、不是一个编年史的两件东西：一个全球的温度的网络（而在它之前、像中央英格兰的温度的一直不间断地跑到 1659 的国家的序列）而一个足够精细的代用指标的科学——年的分辨率的树、洞的滴水、冰的化学、而历史的文献——来重建仪器的之前的几个世纪、而对着仪器在它们重叠的地方检验它们。结果是这个领域的在政治上最有争议的、而证据最好的章节：中世纪的与小冰期的通俗的记忆的"气候"是区域的格局、不是全球的状态的发现；二十世纪的暖在最后的两千年的自然范围的开始处就离开了它；而"曲棍球的杆"的争论在 2003–2006——环境科学的历史上最受攻击的图——不是以怀疑、而是以**一致的论证**结束的：十几个独立的代用指标的家庭在同一个形状上一致。这一课是最后的两千年说什么、而说它为什么这么难。

## 证据的基础

::: definition 仪器、文献、而高分辨率的代用指标 {#def-ltm-evidence}
最后的两千年是用**四个档案同时**读的唯一的气候的区间。**仪器的记录**（HadCRUT、伯克利地球、ERSST 的海洋的序列）在 1850 年附近稀疏地开始、而在 1900 年变得接近全球的；**中央英格兰的温度**（1659–）是世界最长的国家的序列、而**长的仪器的序列**（乌普萨拉、维也纳、帕多瓦、德比尔特、而格陵兰的丹麦的气象的站）固定 1700 年代与 1800 年代；船的日志、而现在、救援的数字化了的日志（旧日天气与国际的全面的海洋–大气的数据的集的项目）把海洋推回到 1750 年代。**历史的文献**——中国的王朝的历史的冻结与收割的记录（太湖与渤海的冰的日期跑两千年）、欧洲的编年史、饥荒的教区的登记、冰岛的编年史、勒鲁瓦拉杜里在 1960 年代变成气候的历史的"价格与收割"的序列——是定性的到半定量的、丰富地测年的、而用发明它们的学科的资料的批评读。**高分辨率的代用指标**供给文献缺的全球的覆盖：年可解析的树的环的宽度与密度的网络（几千个序列、在北半球最密的、由交叉的测年绝对地测年的）、年可解析到十年可解析的石笋的 δ¹⁸O、冰的芯的化学（每一个喷发到公元前 500 年与更早的硫酸盐的层的目录、铅的、而现在的工业的黑碳的曲线）、珊瑚（唯一的热带的年的档案、ENSO 的日记）、而有层的与年的分带的湖的沉积。**重叠的检验**——只从代用指标重建 1900 年代而对着度量比较——是这个领域的常考的考试、带着树的环的**密度**与一切的网络在十年到几十年的暖做得好、而在仪器测量的日的方差与空间的细节做得差的教训通过；而**测年的精度**（树木年代学的绝对的年、冰的芯的层的计数、石笋的铀钍）是让最后的两千年能用事件的归因、不是相关问因果的问题——536 年的尘的帷幕之后跟随什么、每一个喷发之后跟随什么、太阳的极小做了什么——的东西。
:::

::: example 重叠的检验 {#ex-overlap}
一个树的环的密度的网络重建 1970–2000 的均值的北半球的夏的温度在它的 1961–1990 的基线之上 0.35 °C、而一个独立的仪器的值是 0.42 °C。求偏差、而解释为什么"发散的问题"（一些高的纬度的网络中的环的宽度在 1950 之后停止跟踪温度）使**校准的设计**——不是相关系数——成为诚实的质量的度量。
::: solution
偏差 $= 0.42-0.35 = 0.07$ °C——小的、而系统地**冷的偏差**、重要的方向：如果宽度向下发散而密度保持、一个建立在宽度上的网络少读现代的暖、而一个建立在密度上的网络必须为相反的漂移检查。诚实的度量是样本外的技巧（在 1900–60 校准、在 1960–2000 验证、而报告两者）、因为在校准已经看过的数据上的一个高的样本内的 $R^{2}$ 测量拟合、不是看见——曲棍球的杆的争论教一代与政策相邻统计学家要求的统计的规则。
:::
:::

## 经典的事件

::: definition 罗马的气候的最优期、晚古代的小冰期、中世纪的气候的异常、小冰期 {#def-episodes}
**罗马的气候的最优期**（约公元前 200–公元 150、在它更老的、更含糊的命名中的"罗马的暖期"）：稳定的、暖的、在正确的地方的湿的地中海的条件——帝国的密度的谷物的基础——从石笋、湖的岩芯、阿尔卑斯的冰与文献读；它的结束（向晚古代的更可变的、更湿的晚的机制的转变）与**536 与 540 年的双重的喷发**——1815 之前的公元的最大的气候的扰动、它的尘的帷幕"发出它的光而没有亮度、像月亮发出它的光"（普罗科匹厄斯、一个实际的目击者的句子）、它的变冷树的环与冰的芯现在放在十年 1.5–2.5 °C、而它的 2024 的源的识别（536 的一个冰岛的喷发、540 的萨尔瓦多的伊洛潘戈）完成了目录——同时、而可能部分地反映轨道的与火山的强迫的转变、而它的人的续篇、**查士丁尼的瘟疫**（541 年、第一鼠疫杆菌的大流行、它的在 2020 年代的基于花粉的"农业的崩溃"的曲线追踪的人口学），打开了**晚古代的小冰期**（536–660 年、宾特根与同事的综合：一个由喷发、瘟疫的放弃的土地、而太阳自己的安静的世纪维持的 125 年的冷的时期）。**中世纪的气候的异常**（约 950–1250 年）是这个领域的大纠正：在北大西洋真实而戏剧性的（诺斯人的冰岛 870、格陵兰 985 与它的牧场、文兰的航行、欧洲的扩张与中世纪的阿尔卑斯的谷的耕种与小麦到 62°N）、而**不是一个全球的状态**——热带的与南半球的中世纪的世纪是不同步的、而通俗的记忆的"中世纪的暖期"是戴着一个全球的名字的一个北大西洋的格局。**小冰期**（约 1300–1850、**戈登·曼利**的 1939 的造的词、证据的基础**勒鲁瓦拉杜里**的 1967 的综合首先装配）同样是一个带着一个强迫的格局：1683–84 的泰晤士河的冻结（霜的集市）、杀死芬兰与瑞典的人口的十分之一的 1693–97 的北欧的饥荒、摧毁瑞士的村落的冰川的推进（使小冰期成为第一"重建的"气候的变化的文献的档案）、而一个 2010 年代大体闭合的强迫的预算：**1250–1500 年代的一列的热带的喷发**（1257 的萨马拉斯、1450 年代的夸艾、1600 的瓦伊纳普蒂纳、1815 的坦博拉的终曲）、**太阳的极小**（沃尔夫的、而**莫德极小**、1645–1715、以**爱德华·莫德**命名的没有太阳的斑的几十年、而**约翰·埃迪**在 1976 年使它复活、它的气候的效应——真实而小的、一瓦特左右——现在在大多数的预算中被火山的项使相形见绌）、而新冰期的慢的轨道的变冷、带着**火山作用作为扳机**（米勒与同事的 2012 的论证：一个大喷发的序列、由海冰与海洋的反馈放大、能从一个暖的状态启动小冰期的条件——使小冰期成为突然的变化的文献的全新世的案例研究的机制）。在小冰期与我们之间坐着**二十世纪**：2019 的 **PAGES2k 的"一致的论证"的综合**——717 个代用指标的序列、六个家庭、所有的大陆——把它放在**到世纪的中期在最后的两千年的范围之外、而到 2000 在记录中的一切之外**的增暖、带着中世纪的区域的极大在 1940 年代之后从不接近二十世纪的全球的均值：下一节的争论所关于的结论。
:::

::: example 火山对太阳、在一个预算中 {#ex-forcing-budget}
1815 的坦博拉的气溶胶的层强迫约 −2 W m⁻² 两年（λ = 0.8 K 每 W m⁻²）；莫德极小的总的太阳的辐射的异常是约 −1 W m⁻² 持续约 70 年。求峰值的火山的温度响应、平衡的太阳的响应、而解释为什么小冰期的冷的世纪跟踪**喷发的列**比太阳的斑的记录更好。
::: solution
坦博拉：$0.8\times2 = 1.6$ °C 的瞬态的响应（观测的北半球的夏在 1816 冷约 1–1.5 °C——"火山起作用"在历史的标度的校准）；太阳的：$0.8\times1 = 0.8$ °C 的平衡、而真实的总的太阳的辐射的异常更好地估计在 −0.1 W m⁻²（老的"1 瓦"的数字来自过度阅读太阳–气候的相关），给出约 0.1 °C——一个世纪的涟漪。喷发的列、对比、给出 −0.2 到 −0.5 W m⁻² **一个十年又一个十年**（冰的芯记录了 1450 与 1700 之间约 70 个 ≥拉基的大小的喷发）、而每一个喷发的海冰与海洋的耦合的记忆与下一个重叠：小冰期是一个**火山地步调的、海洋缓冲的**冷的状态、太阳是一个支持的演员——2010 年代的归因的结果、而"太阳造成了小冰期"只在气候的怀疑论的文献、不在气候的物理的文献中幸存的原因。
:::
:::

## 曲棍球的杆与一致的论证

::: definition 曼恩–布拉德利–休斯、批评者、而 2019 的和解 {#def-hockey-stick}
在 1998–99、**迈克尔·曼恩、雷蒙德·布拉德利、而马尔科姆·休斯**从一个当时不寻常的 358 个代用指标的序列的网络重建了 1,000（然后 600）年的北半球的温度、而产生了这个图——一个中世纪到十九世纪的变化的平的"杆"、一个从它升起的二十世纪的"刀刃"——它变成气候的辩论的图标、而科学的历史上持续的最长的攻击的目标：**国家科学院的小组**（2000 年的诺斯委员会、它的"重建过去的气候"的报告认可这个方法、而要求更多的透明度）、**韦格曼的报告**（2006、美国众议院的能源的委员会的统计学家爱德华·韦格曼的审查、它自己的错误随后由统计学的界记录）、2009 的气候的研究的单元的电邮的档案的事件（它产生了八个并行的调查、而没有科学的不端的发现、而确立科学家、像所有的科学家、写不加防护的电邮）、而曼恩的二十年的诽谤的诉讼（在 2024 以加拿大的最高法院拒绝审理这个案件、而以最严重的指控的源的和解结束）。方法的争论——基于主成分的代用指标的选择是否压低了低频的方差（"空间的主成分分析压平中世纪"、曼恩–布拉德利–休斯的批评者对它们的 1999 的估计器是正确的、而这个领域的回答是用保方差的方法重建重建、而得到同样的形状）、树的环是否过度代表二十世纪、中世纪是否暖——是真实的、可发表的、而**通过做工作解决的**：**PAGES2k** 的项目的 2013 的半球的综合（最后的 1,400 年的最暖的 30 年是最后的 30 年；中世纪的气候的异常在全球的均值中从不接近二十世纪的暖）、2019 的**一致的论证**的研究（独立的代用指标的家庭——树、珊瑚、冰、沉积、文献、而模型模拟的"虚拟的代用指标"——在误差之内在同一个全球的到区域温度历史上同意）、而**模型的–古气候的**融合（最后的两千年的耦合的集合的模式的集合再现受迫的演化：火山的变冷的事件、莫德的下降、二十世纪的起飞）现在固定归因：**1900 之前的变率可以解释为火山加太阳加内部的噪声；1950 之后的暖没有温室的强迫不能解释、而 2010–2020 年代超过每一个重建的极大**。和解不是曲棍球的杆在每一个像素上是对的——1999 的版本在中世纪太冷、而太平滑、而曼恩自己的后来的重建相应地移动——而是**结论**（二十世纪离开两千年的范围；中世纪的气候的异常是区域的；小冰期是受迫的）幸存每一个攻击、因为它是、而仍是、数据从十几个方向同时说的。
:::

::: example 多远之外？ {#ex-outside}
一个两千年的重建给出对着它的 1–1800 的均值的 ±0.2 °C 的工业化前的自然的范围（95 的包络）而一个 2010 年代的异常 +1.1 °C。求现在超过工业化前的均值多少个包络的半宽、而解释为什么正确的陈述是"在最后的两千年的范围之外"、不是"有记录的历史上最暖的一天"。
::: solution
$1.1/0.2 = 5.5$ 个半宽——现在坐在两千年的自然的包络之外很远、那是可辩护的主张。口号的版本在三项上失败：重建是**半球的到全球的年的均值**（主张是关于均值的状态、不是天的天气）、包络是一个**重建的**范围（带着它自己的不确定、那是谨慎的陈述说"可能"而引用代用指标的家庭的原因）、而"两千年来最暖"**低估**更深的结果——上新世与始新世更暖、而要点不是最高级、而是**不连续**：现在离开文明所属的纪元、那正是每一个行星的边界的全新世的比较的框架的意思。
:::
:::

## 温度之外：事件的目录

::: definition 放射性碳的偏移、太阳的日记、而自然的实验 {#def-miyake}
最后的两千年的最高分辨率的年代学在宇生成的核素上运行——而它的最奇怪的发现在它们的**尖峰**。在年的分带的树中的放射性碳显示两个突然的约 1.5–2 的跳、在 774/775 与 993/994（**三宅的事件**、由三宅与同事在 2012 年当他们以年的分辨率读日本的雪松寻找超新星的信号时发现）：全球的、单年的碳–14 的产生脉冲、它的能量的来源最可信地是**极端的太阳的粒子的事件**——从一个我们认为温顺的恒星的超级耀斑、而超新星与伽马的射线的替代被同位重的比约束而大体排除（事件的冰的镜子中的铍–10、氯–36 存在而小、支持 2020 年代的模拟的共识现在支持的太阳的解释）。它们的重要性是双重的：对于年代学、尖峰是**前所未有的精度的时间的标记**（一个单年、全球同步的——775 的层给日本的与欧洲的木材测年、而甚至通过代用指标精炼了锡拉的喷发的争论的浮动的年代学）、而对于文明、一个常备的提醒：太阳的引擎能给出一个 1859 的卡林顿的事件的粒子的通量的一千倍的事件——一个**存在的基础设施的风险**（现代的电网与卫星的层从未在 774 的标度检验、而这个事件在最后的三个千年中出现两次是复现的速率的估计）、古气候贡献给空间的天气的政策。同样的放射性碳的序列、平滑的、给出太阳的**世纪的日记**——中世纪的与现代的极大、莫德的与约 1450 年代的极小（放射性碳的产生曲线、在它们重叠的地方由太阳的斑的记录、在它们不重叠的地方由铍–10 的冰的记录地面真值的）——而**太阳–气候的相关**的诚实的标度：几十分之几瓦每平方米的辐射的变化、至多十分之一度、真实而支持的演员的强迫（2010 年代的过去千年的模拟的集合的判决）。这个类别的同伴是自然的受迫的实验：**喷发的目录**（冰的芯的硫酸盐的序列现在给 2,500 年中的约 5,000 个喷发测年、带着西格尔与同事的 2015 与 2021 的主的年代学为每一个最后的两千年的模型的运行供给强迫——而解决这个领域最喜欢的侦探案：1257 的萨马拉斯作为打开小冰期的变冷的"神秘的喷发"的候选、由 2013 年在龙目上的源的记录确认；1452/3 的夸艾；1600 的瓦伊纳普蒂纳、它的干旱的签名到达朝鲜的与中国的记录）、每一个喷发是一个**辐射的强迫的复制的实验**、它的气候的响应——耦合的集合的模式现在再现的约 0.4–0.8 °C 的北半球的变冷——校准预报依赖的快的反馈。最后的两千年不只是一个温度的故事；它们是整个的图集的**受迫的响应的实验室**。
:::

::: example 读一个三宅的年 {#ex-miyake}
树的环的碳–14 在 774/775 跳 1.9（约为一年中加入的年产量的 1.2 倍、给定与大气的小的库存的快的交换）、而在此后在一个十年内松弛约过剩的 30。求暗示的大气的碳–14 的库存的将近的停留时间的行为、而为什么尖峰的**单年的**宽度要求一个产生的机制、不是碳的循环的一个。
::: solution
快的初始的松弛（约 10 年中约 30）是海洋–表面的与生物圈的交换（在深海在它的千年的时钟接管之前见到的十年的碳的循环的时钟、同样的交换的速率化石的二氧化碳的吸收的文献测量的、从另一个方向读）。单年的上升要求一个**产生**的脉冲：碳的循环的扰动（火山、火、甚至 536 的尘的帷幕的减少的光合）在十年以上的标度在储层之间移动碳、而不能把一个全球的同位重的尖峰堆进一个环的年——只有宇宙线的产生、在树的环的分辨率上瞬时的、能。这个练习是最后的两千年的方法的同位重的端：**形状在时间中是机制**、这个图集的每一章中把一个火山的变冷（几年、跟随硫酸盐）与一个温室的增暖（几个世纪、跟随排放）分开的同样的逻辑。
:::
:::

::: warning 中世纪的气候的异常是真实的而不是全球的、小冰期是受迫的而不只是太阳的、曲棍球的杆在细节上是错的而在结论上是对的、文献是带着资料的批评的数据、而"它以前变化过"仍是错的推断
五个错误。**"维京人在格陵兰种葡萄、所以中世纪比今天暖"**：诺斯人的格陵兰（985–约 1450）是真实而气候相关的——而是一个**区域的**异常、它通过小冰期的海冰与风暴、在殖民地的灭绝中结束；没有两个千年的重建把中世纪的气候的异常的全球的均值放在二十世纪的后期值附近、而 PAGES2k 的一代用每一个可得的代用指标的家庭说了。**"小冰期是太阳造成的"**：莫德极小的辐射的效应是约 0.1 °C；喷发的列加海洋–冰的记忆做了工作（2012 的米勒等的论证）——太阳是一个真实的而次要的演员、而"太阳做了它"的叙事幸存、因为也不是唯一的一个带着预算的版本。**"曲棍球的杆被揭穿了"**：被揭穿的是具体的 1999 的估计器的选择（主成分分析的低频的问题、真实的而固定的）与具体的过度的主张（平滑）；重建的**结论**被每一个方法与档案的家庭独立地再现、包括批评者自己偏好的方法——这个事件是自我纠正起作用、而公众被告知相反的教科书案例。**"历史的文献只是故事"**：中国的冻结的记录、冰岛的编年史、而教区的饥荒的序列是**测年的、空间固定的、而能与代用指标交叉检验的**（1600 的瓦伊纳普蒂纳的干旱的信号出现在中国的收割的记录与同两年的树的环中）——它们是带着一个资料的批评的纪律的数据、比度量更难、不是更软。**而"气候以前变化过、所以今天是自然的"**：最后的两千年恰恰是反驳它的实验——工业化前的偏移是**可归因的**（喷发、太阳、内部的）、它们的全球的幅度是 ≤0.2 °C、它们的速率是现在的一个分数、而 1950 之后的信号失败每一个自然的强迫的重建、而匹配温室的那一个：历史的记录不是归因的逃生舱口；它是归因的校准的集合。
:::

::: history
这个领域的深的根在**勒鲁瓦拉杜里**的 1967 的《千年以来的气候的历史》（最后的一个千年的第一现代的气候的历史、从法国的葡萄的收割与农民的记录）、**戈登·曼利**的小冰期的 1974 的综合（他普及的名字）、而更早的自然的历史的传统（**拉维尔、而十七世纪的工具的革命的**天气的日记——皇家学会的 1660 年代的通信的网络首先提议一个全球的工具的网格）。代用指标的时代：**道格拉斯**的树的环（1900–20 年代）、**查尔斯·布鲁克斯**、然后**休伯特·兰姆**的古气候的综合（兰姆的 1977 的《气候：现在、历史与未来》是这个领域的圣经、他的 1965 的中世纪的气候的论文是它的宣言）、**埃米利亚尼**的同位重的学校的海洋的背景、而**拉马奇–斯托梅尔**的放射性碳–太阳的斑的综合（1968、太阳–气候的纲领的现代的开始）。现代的证据的基础：国际地圈–生物圈的计划的、然后 **PAGES** 的协调的重建（2000 年代的"2k"的网络）、**旧日天气**与日志的数字化项目、**冰的芯的火山的硫酸盐的目录**（齐林斯基、**西格尔**与同事的 2015 与 2021 的主的年代学——现在每一个模型使用的喷发的强迫的序列）、而**莫德–埃迪**的太阳的事件（1852/1976）。争论的文献——**曼恩、布拉德利、休斯**（1998、1999）、**诺斯**（2000）与**韦格曼**（2006）的审查、国家科学院的 2006 的"调和观测"的报告、**气候的研究的单元**的调查（2009–10）、**PAGES2k** 的半球的（2013）与**一致的论证**（2019）的综合、而**最后的一个千年的耦合的集合的模式**的集合——自己现在是一个教学的案例研究：科学如何在公众面前与它自己争论、而在这个证据上、赢。
:::

::: quiz
关于中世纪的气候的异常的现代的共识是它是：
- [ ] 一个全球同步的、比二十世纪的后期更暖的暖的状态。
- [x] 一个真实而区域不同步的格局、在北大西洋最暖、从不全球地匹配二十世纪的暖。
- [ ] 完全是十九世纪的历史学家的捏造。
- [ ] 由一个太阳的超级极大造成。
::: solution
区域的、不同步的、北大西洋强调的、而由适度的太阳的增益、低的火山的活动、而内部的变率（大西洋的多年代的模态）的混合驱动——在诺斯人耕作、而阿尔卑斯放牧的地方暖、不是处处暖、而在现代的全球的均值附近哪里都不是——"一个格局、不是一个状态"的教科书的案例。
:::
:::

::: summary
最后的两千年是用四个档案读的气候的历史——回到 1659（英格兰）与 1850（世界）的仪器、带着资料的批评的文献、高分辨率的代用指标、而冰的喷发的目录——而它们给出三个和解：中世纪的与小冰期的"气候"是**格局**（区域的、受迫的——为小冰期主要是火山——而从不是匹配现在的全球的状态）、二十世纪到世纪的中期离开两千年的自然的包络、而到 2000 离开每一个重建的极大（PAGES2k 的一致论证）、而曲棍球的杆的争论、带着它全部真正的方法的教训、以结论站立结束、因为十几个独立的档案同样地弯曲。这个纪元是归因的校准的集合：1900 之前的变率没有温室气体可以解释、1950 之后的暖排除它不能解释。没有夏天的年是纯粹自然的、历史记录的最后的气候的灾难；此后的记录是我们不再能说那个的证据、而证明它的重建的科学是这个图集的最好示范：古的与现在是同一个连续的、可审计的实验。
:::
