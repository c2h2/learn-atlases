冰期由一个工程师在一个地窖中解释。**米卢廷·米兰科维奇**、一个塞尔维亚的地球物理学家、在 1910–20 年代建造他的气候的理论——部分地作为一个在布达佩斯的战俘的项目、以手摇的坚持穿过他的时代的天文学的解——计算在过去的 600,000 年中在雪必须在夏天存活的纬度的太阳的照射、而提议地球的轨道的摆动是冰期的节拍器。气象学的建制拒绝这个想法半个世纪（数字看起来太小、相位看起来错、而冰期的年代学不存在）；然后、在 1973 与 1976 之间、深海的同位重的记录长出一个时间标度、而**赫斯、因布里与沙克尔顿**显示沉积的气候的曲线包含轨道的周期——41,000、23,000、19,000、100,000 年——像一个和弦。此后的故事是一个悖论的解决：一个十分之几瓦每平方米的一个轨道的强迫、在正确的地方是全球的与季节的、驱动一个 120-m 的海平面、1,000-GtC 的循环的行星的振荡、因为轨道不推气候——它**给做推的反馈（二氧化碳、冰、尘土、环流）定时**。这一课是那个定时的机器：三个的刻度盘、证明、而未解决的 100,000 年的问题、而同样的天文学写一个不同的气候的故事的季风的进动的世界。

## 三个刻度盘

::: definition 偏心率、斜度、而进动 {#def-orbital-elements}
轨道的三个准周期的要素、由天体力学向前与向后解（**拉斯卡尔**的天文学的解现在积分 250 Myr、带着约 5 Myr 的混沌的不确定的时间标度——行星的钟是可预测的、不是永远的、一个学科必须在约 50 Ma 之外与之共处的事实）：**（1）偏心率**——椭圆的拉长、在近零与约 0.06 之间振荡、带着约 100 kyr 的主导的周期（从木–土的相互作用）而一个稳定的 **405-kyr** 的节拍器（金–木的拍）、它的周期基本是恒定的、而因此在 100-kyr 的带是含糊的时作为地层学的调谐的锚。偏心率自己几乎不改变年的均值的太阳的照射（十分之几瓦每平方米）；它的作用是**幅度地调制进动**——没有偏心率、没有进动的季节。**（2）斜度**——自转的轴的倾斜、22.1°–24.5°、带着约 41-kyr 的周期（月亮的存在使它稳定、对抗混沌的变化、一个行星的宜居性的论证自己）；更大的倾斜在夏天把能量向极地移动、而冬天移走、而斜度主导高的纬度的年的能量的预算。**（3）进动**——自转的轴扫一个 26-kyr 的锥、所以近日点的季节旋转；与气候相关量是**气候的进动** $e\sin\varpi$（偏心率 × 近日点的经度）、带着约 19 与约 23 kyr 的功率、它决定**哪个半球的夏天得到更近的、更强的太阳的轨道**——今天北半球的夏季落在远日点附近（温和的北半球夏季、全新世的北极在七月相对于进动的均值是凉的原因）；在 11 kyr、相反的几何加残留的冰使北半球的夏季最大程度地偏弱、而非洲的湿润的时期的湖在填充。米兰科维奇选择的扳机的变量——**在 65°N 的日的均值的夏的太阳的照射**——仍是工作的假设、因为终止于陆地的冰在那里做成或失去：在 65°N 在仲夏、日的均值在进动的循环中摆动约 50 W m⁻²（当地的光束的五分之一）、而经验的规则（库尔茨巴赫、而在他之后的 SPECMAP 的相位定年）是**弱的 65°N 的夏的太阳的照射延迟融、而冰生长**——太阳的照射的极小与冰川作用的之间的相关是整个的理论的经验的主干。
:::

::: example 从一个季节的杠杆到一个全球的预算 {#ex-insolation-budget}
弱的 65°N 的夏的太阳的照射在区域与季节上跑在进动的均值之下约 50 W m⁻²。转换到一个粗的全球的年的均值的等价（为球体除以 4、因为异常是夏天的集中的除以约 2）、而带着 $\lambda = 0.8$ K (W m⁻²)⁻¹ 求平衡的温度响应——然后解释为什么实际的北半球的冰期的变冷（约 8 °C）要求反馈、而命名轨道实际招募的两个。
::: solution
$50/8 \approx 6$ W m⁻² 的全球等价的、给出 $0.8\times6 \approx 5$ °C 的直接的响应——已经慷慨的、而在 **100-kyr** 的带的真实的轨道的强迫（消冰期自己的频率）只是全球的约 0.2–0.3 W m⁻²、足够一个度数的一个分数。招募的两个放大器是**二氧化碳**（碳的循环的反馈、值冰期–间冰期的摆动的约 3–4 °C、它的相位现在解决为在北方领先的或同步的、而在南极滞后的）与**反照率**（冰自己、高的纬度的雪球制造者）、带着尘土、植被与环流作为支持的演员。这个练习在一个除法中的 100-kyr 的问题：轨道是节拍器、不是音乐家。
:::
:::

## 从轨道到冰：证明与问题

::: definition 1976、41-kyr 的世界、而 100-kyr 的问题 {#def-proof-problems}
**赫斯–因布里–沙克尔顿**的论证（1976）——在年龄来自磁性的反转与沉积的速率的模型的太平洋的与爱琴海的岩芯中的在轨道的周期的谱的峰——把米兰科维奇的理论从优雅转换为证据、而**沙克尔顿与奥普迪克**的 1973 的地层的框架加 SPECMAP 的调谐（1980 年代、因布里与同事；贝尔格 1978 的太阳的照射的表作为模板）建造了晚第四纪的第一个轨道的时间标度、仍日常使用的海洋的阶段的编号。理论的第一个皱褶是**中更新世的转变**（约 1.2–0.7 Ma）：在北半球的冰川作用的开始之后的 400 kyr、气候在 **41 kyr** 响——斜度自己的音、带着在斜度的极大的消冰期、它的机制（比阈值更暖的斜度融化小的、暖底的、斜度限制的冰盖）现在成功地模拟的"41-kyr 的世界"——然后系统降到 100-kyr、更大幅度的、锯齿的循环、它的形状（慢的建造、快的崩溃）是 **100-kyr 的问题**：偏心率在那个带的直接的强迫约弱十倍做不了工作。候选的解决——还没有一个完整的——是**非线性的积分**（冰盖作为低通的滤波器、在一个大小的阈值灾难性地失败：经典的**波拉德与德孔托**的积分的模型与**里斯伊基与雷莫**的冰的体积的综合、带着它们的 41-kyr 与 100-kyr 的动力学的"系统的模态的耦合"）、**二氧化碳作为它自己的动力学由斜度与进动定步调的放大器**（"斜度定步调的 100-kyr"的学校——最干净的陈述是 100-kyr 的音是通过碳的循环与冰的几何的 41-与 23-kyr 的强迫的**组合的音**）、而**尘土–铁与南大洋的学校**（通过南极的海冰与上升流调谐二氧化碳的杠杆）。确定了什么：消冰期在南方开始（南极的气候的振荡在消冰期 I 领先格陵兰约 1–2 kyr、双极的跷跷板的开场）、二氧化碳与南大洋一起上升、而北方然后在进动的定时上翻转；敞开的是什么是 100-kyr 的循环的**相位的律**——为什么最大的冰期在偏心率的极大结束、而不是每一个偏心率的极大结束它们、使中更新世的转变与接下来的 50 Myr 的天文学的不确定在科学上活着的问题。
:::

::: example 405-kyr 的节拍器 {#ex-405}
一个三叠纪–侏罗纪的大陆的剖面在两个灰的层之间显示 27 个长的 405-kyr 的类型的完整的偏心率循环。求跨越的持续时间、而解释为什么这个节拍器——不是 100-kyr 的循环——用于中生代与古近纪的天文的年代学。
::: solution
$27\times405 = 10{,}935$ kyr ≈ **10.9 Myr**。405-kyr 的偏心率的拍由金–木的引力的节奏设定、而基本上**对退化短的轨道的周期的混沌的扩散免疫**（23/41/100-kyr 的项在约 50 Myr 之外失去相位的相干、因为太阳系在那个时间标度上是混沌的）；它也足够长、在带着适度的沉积的速率的剖面中可解析。节拍器因此是地层学家的长的除法的工具——用它给古新世–始新世的极暖期的开始与海洋的缺氧的事件测年的同样的逻辑——而天文学的解的权威**随时间衰减**的提醒、那是深时的年龄带着"天文调谐的、±？"的限定词、而第四纪从不需要的。
:::
:::

## 一个轨道的算术

::: definition 太阳的照射的几何与调谐的工具包 {#def-insolation-geometry}
扳机的变量的算术是球的天文学加开普勒。在纬度 $\phi$ 与赤纬 $\delta$ 的日的均值的太阳的照射是 $Q = (S_0/\pi)(h_0\sin\phi\sin\delta + \cos\phi\cos\delta\sin h_0)$、带着日落的小时的角度 $h_0$；在高的纬度的夏太阳不落（$h_0 = \pi$）而 $Q = S_0\sin\phi\sin\delta$——那是高的纬度的夏对倾斜这么敏感的原因（它作为 $\sin\delta$ 标度、而 $\delta$ 直接跟踪斜度）、而进动只通过 $S_0$ 的 ±3 的偏心率的门作用（在至日的地–日的距离以距离的比的平方调制光束）。**贝尔格（1978）**的重新计算的太阳的照射的表——在 10° 的纬度的带与 10 天的增量中的 600 kyr——仍是学科的查找的引擎、而建立在它们上的**调谐的工具包**有一个标准的语法：识别**六分仪**（由斜度与进动的符号与它们的速率定义的六个轨道的状态、**沙克尔顿、贝尔格与皮西斯**的"六分仪的调谐"的方法——把每一个沉积的循环分配给一个轨道的相位而不假设哪个周期主导的干净的方法）、在长的节拍器可解析的地方匹配 **405-kyr 的锚**、在锚之间数进动的循环（使沙原与中国的洞的记录以轨道的标度的精度联系到轨道的"循环的计数"）、而携带**混沌的地平线**（在约 50 Ma 之外只有 405-kyr 的项幸存；在约 250 Ma 之外甚至那个消退）作为学科的诚实的边界。语法重要、因为调谐是地层的两个钟——天文学的相位与放射的同位重的绝对的——调和的地方、而每一次调和是一个发表的争论（2012 的地磁的与 2013 的古新世–始新世的重新校准是警示的故事：整个的事件的序列在联系的点移动时被移动几百个千年）。
:::

::: example 在 65°N 的仲夏 {#ex-q65}
求在夏的至日的在 65°N 的日的均值的太阳的照射（连续的日光、$\delta = 23.5°$、$S_0 = 1361$ W m⁻²）、而在气候的进动的极端的偏心率（$e = 0.06$、带着近日点在六月的至日、它把六月的束提高 $((1+e)/(1-e))^{2} \approx 1.27$）的值。
::: solution
带着太阳整日在上、$Q = S_0\sin\phi\sin\delta = 1361\times0.906\times0.399 = 492$ W m⁻²；在进动的极端、$492\times1.27 = 625$ W m⁻²——在轨道的极端之间的六月的束的约 130 W m⁻² 的摆动（真实的 65°N 的范围被冰盖、云、而非极端的现代的偏心率阻尼到前面算过的例子约 50 W m⁻²、而几何是同样的）。这个练习是两个正弦中的米兰科维奇的地窖的算术：天文学的幅度在重要的地方是大的、而气候的工作是阻尼或放大它——那正是下几节的反馈做的。
:::
:::

## 进动的世界：季风、湖、而南半球

::: definition 季风的理论与另一个半球 {#def-precession-world}
在热带与南半球同样的刻度盘演奏不同的乐器。**库尔茨巴赫的季风的理论**（1981）：大陆的夏的加热驱动季风、而大的北半球的大陆上的夏的太阳的照射是进动主导的——所以非洲与亚洲的季风在北半球夏季的太阳的照射高时跑得强（早全新世、11–7 ka：**非洲的湿润的时期**、撒哈拉的湖与在塔西利的岩的艺术中刻的长颈鹿、从尼罗河的淡水的排放的地中海的沙原 S1、恒河以季风的强度淹没它的平原）、而与最后的冰期同相位地跑得弱（过度干旱的、沙的海的撒哈拉、地中海一个低产量的海）。全新世的记录是一个进动的**慢动作**：在 75°N 的夏的太阳的照射在最后的 9 kyr 下降约 8 W m⁻²——一个四分之一的瓦每平方米的全球的强迫、在区域上决定性的——而"全新世的温度的悖论"（代用指标的全球的均值在全新世中**下降**、而温室气体上升、按 2020 年代的长期耦合的模拟、进动的变冷在工业的交叉之前跑过温室的增暖）是同样的物理在全球的衣服中。南半球讲跷跷板要求的反相的故事：南极暖期（约 14.7–13 ka、南极暖而年轻的德律亚得冻结北方）、与中国的石笋反相的塔斯马尼亚的与巴塔哥尼亚的记录、而**南极冷事件**（14.5–12.9 ka）作为南方自己在增暖中的突然的暂停——全都进动地照亮、跷跷板地定时。热带的湖与石笋是轨道的测年最好的档案（葫芦与萨恩扎乌洞的年的分辨率的季风的曲线、中国的洞的记录的"100-kyr 的季风"的主张——亚洲的季风带着北大西洋的淡水的脉冲携带高的纬度的冰的体积的音、进行中的**季风–冰的联系**的争论）、而轨道的最后、与政策最相关的章节是**未来**：今天的间冰期坐在一个偏心率与北半球夏季的太阳的照射的进动的**极小**——那个配置、没有二氧化碳、会保持全新世暖然后温和约 15 kyr、而然后开始下一个消冰期的长的等待（经典的**里斯伊基/Optima** 的计算：下一个冰川作用在目前的轨道的强迫下约 50 kyr 到期；**带着今天的 425 ppm 的计算**：下一个冰川作用可能根本不在 100,000 年中来——诚实的陈述是轨道的下一个冰期的约会在全新世的温室的期间被取消、而被化石的燃料的那个无限期地推迟）。
:::

::: example 取消的约会 {#ex-next-glacial}
鲁德曼与韦恩的计算把下一个大的冰的生长放在自然的强迫下约 50 kyr 之外。如果人的二氧化碳（目前 425 ppm、在简单的碳的循环的模型中在约 200 kyr 上向约 200 ppm 衰减）把气候保持在冰川作用的阈值之上至少 100 kyr、求下一个冰期开始的最小延迟、而陈述二氧化碳取消一个轨道的约会的机制。
::: solution
延迟是**在日程之外 ≥50 kyr**（对着一个 50-kyr 的约会的 100 kyr 的暖）。机制是开始的阈值的逻辑：冰的生长需要雪在 60°N 存活夏天、那需要弱的夏的太阳的照射**与**在约 300 ppm 之下的二氧化碳（开始的实验要求至少大致工业化前的二氧化碳）；轨道会按日程供给第一个、而碳的循环——在几十万年中通过风化与海洋的脱气把化石的二氧化碳漏回——扣留第二个。人类世的最深的气候的事实不是这个世纪的增暖、而是第四纪的节奏在一个十万年或更多的**取消**——一个轨道的标度的行为、写在轨道不能控制的唯一的一个变量中。
:::
:::

::: warning 轨道是一个节拍器、不是音乐家、相关不是理论、100-kyr 的问题未解决、而"下一个冰期被取消"是一个带着小字的陈述
五个错误。**"米兰科维奇的循环造成冰期"**：它们给冰期**定步调**——相关的带的轨道的强迫是全球的一瓦每平方米的几分之一、而冰期–间冰期的摆动的 3–6 °C 与 120 m 是反馈的工作（二氧化碳、反照率、尘土）；理论的内容是相位、不是幅度。**"1976 的证明结束了争论"**：它证明**周期**在气候的信号中毫无疑问；**相位的问题**（为什么最大的消冰期骑弱的偏心率、为什么 41-kyr 的世界忽略 100-kyr 的音、为什么氧 11 与 31 阶段 没有按日程消冰）是这个领域的敞开的中心——诚实的总结是"轨道的定步调确立、定步调的律未知"。**"太阳的照射是二氧化碳的强迫的小的兄弟"**：**季节的、区域的**太阳的照射的异常是巨大的（在七月的 65°N 的 50 W m⁻²）、而做全球的二氧化碳的数字不能做的季风的与冰的边缘的工作；把两者作为全球的年的均值比较——通常的话头——比较错的变量、而错过全新世为什么按日程变冷而二氧化碳平躺。**"中更新世的转变解释了"**（或"是一个谜"）：两个过度的陈述——积分的模型带着可信的成分的集合再现下降（二氧化碳的吸取、边缘的侵蚀、尘土）、观测（北大西洋的边缘的大洋钻探计划第 327 航次的底栖的记录、太平洋的底栖的叠置）约束而尚未选择、而学科自己的评论说"机制上可信的、未论证的"。**而"所以目前的增暖在轨道上是微不足道的"**：真实而离题——下一个世纪的轨道的强迫是约 −0.1 W m⁻²、而人的是 +3 W m⁻² 而上升、这个比较是气候的科学的最干净的示范：目前的扰动不是古的；深时的教训不是轨道打败二氧化碳、而是**二氧化碳是打败轨道的变量**、那恰恰是下一个冰期迟到的原因。

::: history
**克劳利**在 1870 年代勾画了冰期的第一个轨道的理论（偏心率与墨西哥湾流、带着皇家学会拒绝的算术）；**米兰科维奇**在 1913–41 建造真正的理论——600 kyr 的太阳的照射的表、作为决定的陈述的《地球的太阳的照射的典》、而几十年的礼貌的驳回（"冰期的天文学的理论"、气象学家这么叫它、像一个反转的恭维）。**弗拉基米尔·柯本与阿尔弗雷德·魏格纳**使火苗（与测年错的相位）活着；**米兰科维奇的**想法等计时器：**埃米利亚尼**的同位重的地层学（1950 年代）、**埃米利亚尼–哈罗德·尤里**的谱系的深海的曲线、**沙克尔顿–奥普迪克**的 1973 的反转测年的 V19-90 的岩芯、而**赫斯–因布里–沙克尔顿**的 1976 的谱的和弦。调谐的时代跟随——**贝尔格**的 1978 的太阳的照射的计算、SPECMAP 的时间标度（因布里、**赫伯特**、**里斯伊基**的最终 LR04 的精化）、**拉斯卡尔**的行星的解、带着它们的混沌限制的地平线（拉斯卡尔 1993 的 5-Myr 的利亚普诺夫的时间、使太阳的系统的钟出名的必死的结果）、**库尔茨巴赫**的 1981 的季风的太阳的照射的综合、而**COHMAP** 的项目的全新世的图集（1987）使进动成为标准的工作的设备。当前的章节——中更新世的转变的钻探（大洋钻探计划的第 327 航次）、中生代的 405-kyr 的天文的年代学、**里斯伊基、波拉德、德孔托**的"斜度定步调的 100-kyr"的模拟、而**佩德罗、尤斯**与南极的冰的记录的跷跷板的综合——是学科尊重米兰科维奇的最后的话：天文学从来不是难的部分；气候对它的答案是。
:::

::: quiz
65°N 的夏的太阳的照射是选择的扳机的变量的原因是：
- [ ] 它是地球任何地方的最大的太阳的照射的异常。
- [x] 高的纬度的北半球的大陆是雪必须在夏天存活、冰盖才能生长的地方。
- [ ] 它直接控制南极的温度。
- [ ] 偏心率只影响那个纬度。
::: solution
冰盖的开始需要在北方的陆地的夏天的雪的幸存（加拿大、斯堪的纳维亚、西伯利亚）；南半球、海洋主导的而隔离的、通过二氧化碳与环流响应——那是北方是轨道的扳机、而南方是碳的循环的放大器、跷跷板的两端的原因。
:::
:::

::: summary
米兰科维奇的三个刻度盘——偏心率（100/405 kyr）、斜度（41 kyr）、进动（19/23 kyr）——在高的纬度重新分配季节的太阳的照射达几十瓦每平方米、而深海的记录的轨道的周期（赫斯–因布里–沙克尔顿、1976）证明气候在听。而轨道是节拍器：100-kyr 的问题、中更新世的的的转变从 41-kyr 的响的切换、而二氧化碳–反照率的放大都显示气候供给幅度、而天空供给定时。进动写另一个故事——季风、沙原、非洲的湿润的时期、反相的南极的最优期——而同样的天文学现在预报一个不会来的冰期：下一个冰川作用的轨道的约会、约 50 kyr 之外、被一个轨道不能碰的变量取消。以一个战俘的算术开始的理论现在是每一个模型的反馈对着它判断的标准——而它敞开的中心、最大的冰期的相位的律、是这个领域保存最好的前沿。
:::

陈述斜度的循环的周期（kyr）。

::: exercise {level=1 check="6"}
把一个 50 W m⁻² 的夏天的、65°N 的太阳的照射的异常转换成一个全球的年的均值的等价（为球体除以 4、为季节性除以 2）。

$50/8 \approx 6$ W m⁻²——季节的杠杆的全球的影子、仍是 100-kyr 的强迫本身的十倍。

::: exercise {level=1 check="405"}
陈述天文的年代学的"节拍器"的周期（kyr）。

**405 kyr**——金–木的偏心率的拍、在短的周期是混沌的地方是稳定的。
:::

::: exercise {level=1 check="23"}
气候的进动（$e\sin\varpi$）在 19 与哪个别的周期（kyr）有功率？

**23 kyr**——19/23-kyr 的对、由偏心率门控的幅度。
:::

::: exercise {level=2 check="10935"}
求 27 个完整的 405-kyr 的循环的持续时间（kyr）。
::: solution
$27\times405 = 10{,}935$ kyr ≈ 10.9 Myr——中生代的调谐的算术。
:::

::: exercise {level=2 check="10"}
100-kyr 的轨道的强迫是全球的约 0.2 W m⁻²、而冰期–间冰期的二氧化碳的强迫约 2 W m⁻²。求碳的循环供给的放大的因子。
::: solution
$2/0.2 = 10$——在一个比中的 100-kyr 的问题的量级：轨道敲、二氧化碳开。

::: exercise {level=3 check="50"}
如果下一个冰川作用的开始在轨道上约 50 kyr 到期、而二氧化碳阻塞开始至少 100 kyr、求在日程之外的最小的延迟、以 kyr。

至少迟 $100-50 = 50$ kyr——人类世的轨道的标度的指纹。
