1988年6月23日，一位名叫James Hansen的NASA科学家做了任何资深政府科学家都没做过的事：他向美国参议院作证说全球变暖已经开始。"温室效应已被探测到，它正在改变我们此刻的气候，"他在华盛顿记录上最热的日子之一、在一个空调失效的听证室里对能源与自然资源委员会说——一个新闻界无法抗拒的场面。Hansen的主张，按1988年科学的标准，略微超前：观测的变暖曲线与预测相符，但*归因*——证明变暖的格局符合温室强迫预言的格局、而不符合太阳或火山或内部变率的格局——距离其成熟形态还有十年。那十年产出了本课描述的领域：**检测与归因**，把"气候变了"变成"人类造成了变化的一个量化部分"、然后在2003年之后变成"人类影响让这场具体的热浪可能性翻倍"的统计机器。这台机器如今自信到AR6第一工作组的摘要用了科学几乎从不使用的语言：自1950年代以来人类对气候系统的影响是**"明确无误的"**——评估报告可能的最高置信度词，绑定的不是变暖本身而是其*原因*。本课就是这个词为什么当之无愧：指纹逻辑、最优指纹统计、单事件归因的两个世界实验，以及最新、最有争议的延伸——不只归因变暖，而是把*特定公司的特定排放*归因给特定的损害，这个动作把归因科学从期刊带进了法庭。

## 逻辑：检测一个信号，归因一个原因

::: definition 检测与归因：统计框架及其词汇 {#def-da-framework}
这个领域的语法来自信号检测理论（1995年IPCC第二次评估报告第8章、Mitchell等人与Santer等人的论文、以及Allen 1993–1999的最优指纹线）。**检测**是关于*观测变化*的陈述：它不太可能在没有外部强迫的情况下发生——对"仅内部变率"零假设的拒绝，以概率量化（1990年代的措辞："证据的平衡表明存在可辨识的人类影响"，IPCC 1995，是一个精心限定的检测*加*归因主张，成了科学界被律师化得最厉害的一句话）。**归因**更进一步：它用**最优指纹法**（"检测与归因回归"）把检测到的变化在候选原因之间分配——温室气体、气溶胶、臭氧、土地利用、太阳、火山、内部变率——：把观测的变化向量（空间×时间×变量）对每个强迫的模型模拟*响应格局*（"指纹"）回归，并考虑模型内部变率的噪声；回归系数就是**缩放因子**——"温室气体响应以1.2 ± 0.2的幅度存在，气溶胶响应以0.8 ± 0.3的幅度存在"——而整个框架的检验是：使用正确的指纹并排除错误的指纹时，缩放因子聚集在1附近。方法的威力来自*格局信息*：标量（全球平均温度）分不开温室与太阳强迫，但**垂直格局**（对流层升、平流层降——温室；全都升——太阳）、**季节格局**（冬季的极地放大、更强的夜）、**昼夜格局**（最低温升得更快）、以及**空间格局**（北半球陆地的放大、南大洋的慢响应签名）合起来让指纹几乎是唯一的——2020年代评估报告能有高置信度地说温室气体与气溶胶指纹在观测中可分别检测、太阳强迫对1950年后约1.1 °C变暖的贡献约0.0 °C（±0.05）的原因。框架诚实的局限同样是标准内容：**多重共线性**（温室与气溶胶指纹在时间上反相关，所以其缩放因子在回归中相关——让历史数据推出的ECS估计对气溶胶强迫假设敏感的"气溶胶补偿"问题）、**模型误差**（指纹来自模型，如果模型的格局错了回归就有偏——靠多模型面板与"必要/充分"检验应对）、以及**零假设的非平稳性**（内部变率必须从模型或工业化前控制运行估计，其多个世纪样本是该领域安静的资源瓶颈）。AR6第一工作组第3章（"人类对气候系统的影响"）把所有线索——指纹、能量收支、古气候类比、过程理解——综合成"明确无误"的判词，而可归因于人类的历史变暖*量*被表述为2010–19观测1.09 °C中的1.07 °C：第一次人为变暖*就是那个数字*、自然强迫与内部变率四舍五入到小数点后的评估报告。
:::

::: definition 指纹之外的证据线：收敛论证方法 {#def-lines-of-evidence}
归因判词不建立在回归上；它建立在**独立论证的收敛**上——科学哲学家称之为最佳解释推论、评估报告称之为"多重证据线"的证明风格。(1) **物理古老而经过检验**：CO₂的辐射效应从实验室光谱学算出（HITRAN逐线数据库、2020年代瑞士PSI设施对关键CO₂波带的重新测量确认了气候模型使用的谱线参数），而2011年CO₂浓度带来的约2 W/m²强迫在计入反馈与气溶胶后与观测变暖相符。(2) **碳是我们的，同位素为证**：空气中下降的**¹³C/¹²C与¹⁴C比值**（Suess效应）证明CO₂增量带着化石碳与生物圈碳的签名——¹⁴C的下降（化石碳的¹⁴C已死）排除了海洋与火山，它们合计排放*毛*年CO₂通量的约95%但被净吸收；质量平衡论证（空气分数约排放的45%，其余被陆地和海洋吸收，而吸收与多余量*成比例*）闭合了账目。(3) **模型在反事实中工作**：仅自然强迫（太阳+火山）的模拟再现了1930年代之前的摆荡和1940–50年代的平台，但*无法*产出1970年后的变暖（"无人为强迫"系综从1990年代起以小于5%的可能性把观测括在外面——"明确无误"判词背后的数字），而全强迫系综再现了观测曲线包括其*冷却*插曲（1992–93年皮纳图博下探，被预测并被观测到约0.3 °C，该领域最优雅的单一确认）。(4) **能量收支闭合**：CERES不平衡、海洋吸热、融化能与陆地变暖加总为同一个强迫（观测对强迫的残差在误差内——"约束"文献的核心一致性检验）。(5) **古气候类比**：上新世（约400万年前，CO₂约400 ppm，海平面高10–20米）与始新世是暖态世界，其在已知地理与CO₂下的模型温度与代用记录相符——那个无法在实验室做的地球系统模型实验已经对着地质记录做过，上新世模型相互比较计划就是正式检验。本案的力量在于每条线都独立排除主要的替代解释（太阳：平流层与辐照记录；海洋循环：能量收支闭合与不对称指纹；天然碳：同位素），而替代解释的失效方式*各不相同*——坏掉的温度计、坏掉的光谱学、坏掉的同位素地球化学、坏掉的卫星与坏掉的全新世串通一气不是一个活的科学假说。
:::

::: example 1990年代：从"证据的平衡"到指纹战争 {#example-1990s}
追溯1990年代的检测与归因弧线，那个一笔创下这个领域及其政治的十年。Santer等人（1996，*Nature*）把无线电探空与卫星垂直温度廓线同模型指纹比较，报告了温室格局"积极但初步"的检测——第一个垂直归因结果，也是一个有资金支持的产业运动的靶子（要求原始探空档案的"跟着数据走"公开信，档案最终公开并确认了发现）。Mitchell、Johns、Karol等人（1995）与IPCC第三次评估报告第8章建立了最优指纹框架并产出了1995年的公式（"证据的平衡表明存在可辨识的人类影响"），触发了美国参议院的Byrd决议（95比0，反对柏林授权）——归因科学成为地缘政治事实的时刻。Allen与Stott、以及Stott等人（2000）随后交付了第一个*事件*归因——2000年12月英国洪水，"风险大约翻倍"——而2001年第三次评估报告把措辞升到"新的更强的证据"。那个年代的方法论之争（FDD/RSI用RSS通道漂移伪影重演Santer的尝试、North–Cess关于模型云反馈是否有偏的辩论、2009年"对流层变暖特洛伊木马"邮件——在全文公开后显示有争议的结论挺过了其内部批评）确立了该领域的现代性格：*以数据被攻击、以数据重跑、以数据被确认*的结果。垂直格局检测为什么比表面检测难那么多、而同一批垂直数据后来为什么成为最强证据线——唯一的统计原因是什么？
::: solution
垂直格局的信噪比在1990年代小，因为平流层冷却信号部分被臭氧损耗遮蔽（一个模型必须单独纳入的混淆指纹），也因为探空记录带着仪器漂移伪影（VTPR/MSU通道问题、RSS–GISTEMP分歧），而该领域直到2010–2020年代才靠站到站均一化（RATR/HadAT/Preussler方法）与卫星重处理（RSS 2022年自我修正）解决了它们。清理干净之后，垂直格局——平流层冷却、对流层变暖、与模型相符的幅度比——就成了任何太阳或内部变率解释都无法再现的指纹，这就是为什么1996年论文的"初步"判词是2021年评估报告的"明确无误"判词。
:::
:::

::: example 两个世界的实验：Allen等2004与2003年欧洲热浪 {#example-2003}
2003年8月热浪——欧洲七万多超额死亡、阿尔卑斯300年最糟的冰川融化、催生了法国高温预案的法国危机——在数月内被David Allen的牛津小组在一篇*Nature*论文中归因，该文创立了单事件归因这个方法（如今每份气候诉讼文件都引用的"Allen等2004"）。设计就是**反事实实验**：让Hadley中心模型（HadAM3）在1900年强迫与2003年强迫气候下各跑几千年，分别计算每个世界出现与2003年同样极端的欧洲夏季高温的概率（"风险"R），并报告**可归因风险分数** FAR = (R₁ − R₀)/R₁。发表的结果是：2003年夏季温度的风险被人为强迫**至少翻倍**，而——让论文出名的数字——*置信度*陈述"我们可以以约90%的置信度说风险增加了，以较低置信度（约75%）说风险至少翻倍"。方法的假设就是该领域反复重复的诚实告诫：事件由一个*阈值*定义（指标的选择改变FAR）、模型必须模拟事件的动态（2003年土壤水分反馈——值峰值的1–2 °C——有表征但不完美）、而反事实世界不是"自然的"而是"工业化前加自然的"，一个有法律后果的定义选择。2016年巴黎协定第八条（损失与损害）与World Weather Attribution平台（2014– ，100多个事件研究）是这篇论文的直接后裔；2021年德国法院在Saúl-Luciano案中的推理（见下文）也是。这个练习的问题：如果一场热浪的FAR是0.5而热浪死了70,000人，为什么"35,000人死亡由气候变化造成"*不*成立，可辩护的句子是什么？
::: solution
FAR是一个*人群风险*统计量，不是个体因果规则：正确的陈述是气候变化把事件风险大约翻倍，而在反事实分布下预期死亡人数会少一半——诉讼与健康归因文献使用的流行病学框架（"*风险*的可归因分数"），也是法院（德国判决的"因果链"问题）仍在费力将其操作化为赔偿责任的区别。
:::
:::

## 源、收支与法庭

::: definition 单事件归因及其不满 {#def-sea}
单事件归因（SEA）——World Weather Attribution学派、"野兽"（100多项研究的Bond事件）——回答公众和法庭真正问的问题：*这场灾难的风险有多少是人类造成的？*标准指标是**可归因风险分数**（FAR = 1 − P₀/P₁，反事实世界与现实世界之间的风险比）或其基于概率的表亲**风险比移动**（"十年一遇的热浪现在是三年一遇"）。方法的优点是真的：它*有相关性*（2021年北美西部热浪、2022年巴基斯坦洪水——三分之一的国土泡在水里，归因结论"受灾最重省份的降雨可能性高达19倍"但带复合洪水告诫、2021年郑州/2022年川渝热浪、WWA与Climate Central"气候转变指数"每日归因流的2003–24年连续记录）。其有文献的缺点同样真实且已是教科书：(1) **阈值与指标问题**——FAR取决于事件如何定义（按峰值温度、夜间最低或持续时间定义的热浪给出不同答案，2015年Beven与Kearns和2021年Bell等人的批评把这一敏感性形式化了）；(2) **模型技巧前提**——如果模型无法模拟事件动态（对流风暴、2021年郑州降雨的地形耦合），反事实就不可信，这就是为什么WWA的规程现在对此类事件*保留*归因陈述（诚实的"我们无法归因这场洪水"占其产出的三分之一）；(3) **复合事件缺口**——2022年巴基斯坦与2023年利比亚灾难是*链条*（热→冰川融化→降雨→基础设施失效），而该领域的风险比算术只处理单变量；(4) **适应混淆**——*影响*（死亡、损失）取决于暴露与防御，所以"气候变化让X的可能性翻倍"对X的损害是否翻倍一无所语（1970与2020年孟加拉气旋是双向的反例）。2020年代的方法论前沿以**气候模型"世界"系综**（HASS项目半度分辨率的反事实）、**纯观测方法**（2023年WWA地中海研究的基于风险的归因）、以及**影响归因**延伸（2022–24年归因*作物损失*与*死亡*而非天气的研究）应对这些。领域自己背书的判词：SEA是一门*风险*科学，不是*个案*科学——一个用单一灾难的语法传达变暖世界之含义的公共卫生传播工具，一个其因果权重仍由法院裁定的诉讼输入。
:::

::: definition 源归因与法律：从碳巨头到法庭 {#def-source-attribution}
归因科学的最后延伸把因果链倒着跑，从损害到排放者。**排放源归因**（"碳巨头"文献）始于Richard Heede 2013年的清单：1854–2010年工业CO₂与甲烷当量的977 GtCO₂当量中，**63%可追溯到90家投资者所有或国有的化石燃料与水泥生产商**，而33 GtC（到2010年工业时代总量的约36%）仅20家公司，ExxonMobil居首（"碳巨头数据库"，如今已公开，是多数气候诉讼文件的基础）。第二个动作——把*变暖*归因给*源*——更新也更有争议：2019年Feature、Venegas等人*Nature*研究（"2011–2020年暖温度异常的成因与含义"）发现45家公司的排放与期间观测变暖的约一半相符，这一结果既被批评（方法对同批公司伴生气溶胶的处理、以及对*所有*排放不论源的碳循环吸收）也被辩护（相对风险逻辑对批评的核心是稳健的）。**法律转向**是归因科学的认识论与举证责任认识论相遇之处：**Urgenda**案（荷兰最高法院2019年*Urgenda*判决下令2020年前减排25%——第一个基于人权责令国家减排的法院，其推理倚重审慎原则与IPCC自己的碳收支、而非事件归因）、德国**Neubauer诉RWE**线（秘鲁农民Saúl Luciano Lliaya就其家乡上方Palcaraju冰川湖起诉，2017年多特蒙德地区法院*采纳*World Weather Attribution的洪水归因证据、而2022年上级法院的驳回取决于*比例因果*问题——"历史排放的0.5%"——不取决于科学的可采性）、2021年**Milieudefensie诉Shell**命令（2030年前减排45%，判决引用IPCC碳收支与公司自身计划与它的不一致）、以及2024–25年**国际法院咨询意见**程序关于国家气候义务（第一起ICJ气候案，90多个方的书面陈述里有归因科学）。认识论断层线精确而值得教：归因科学以**人群的概率**说话（FAR、风险比、缩放因子），而侵权法要求**具体事物的因果**（这场洪水、这个农场、这个被告的份额）。领域的贡献是它让*一般*因果问题在法律上不可输——这些案件中没有一个法院否认人为变暖真实、人为、有害——而*具体*分配仍是开放问题，2020年代"从源到损害"的归因方法（碳巨头到影响的链条）就是为攻克它而建的。
:::

::: example 2022年巴基斯坦洪水：复合事件前沿的归因 {#example-pakistan}
2022年6月到9月之间，巴基斯坦三分之一国土一度泡在水里：1,739人死亡、850万人流离失所、约300亿美元损失与经济损失（世界银行-PDNA评估），Sindh与Balochistan受灾最重区间的降雨是1991–2020年8月均值的5–10倍，此前是两场致命热浪（2022年3–4月，45 °C以上，其本身被WWA在区域尺度归因为没有气候变化"几乎不可能"）在大水之前把土壤烤裂。这场灾难的归因文献是该领域双向的当前案例研究：**降雨**归因（受灾最重区一个4天750毫米的事件给出约1.5–7.5的风险比，取决于指标与域——离散度本身就是发现）、**热**归因（强）、**土壤水分预调节**（先热后雨的复合机制、2023年*Environmental Research: Climate*的分析）、以及**损失**归因（几乎没有——损害是暴露、贫困、排水与水库调度的函数，COP27新基金正式承认的链条"损失与损害"一侧）。领域发表的诚实综合：*致灾*项越来越可归因，*复合*交互是前沿，而*影响*大多根本不可归因于排放——这正是最受影响国家在COP上提出的适应资金论点。1.5–7.5的风险比离散关于指标选择教了什么？为什么WWA自己的声明以热的归因而非洪水的归因领衔？
::: solution
离散来自按1天对5天降雨、按区对省、按模型对观测定义事件——一个对流-季风事件的FAR对指标敏感，而天气尺度热浪的不是；相比之下热浪可以用模型*和*观测、跨指标归因，所以它扛起了最强的陈述。这段插曲现在是该领域规则的教科书：归因你建模得了的项，描述你建模不了的链，永远别让标题暗示方法没有检验过的因果。
:::
:::

::: example 证明规则的冷却：皮纳图博与作为仪器的模型 {#example-pinatubo}
1991年6月15日皮纳图博火山喷发（VEI 6、约2000万吨SO₂进平流层、卫星时代最大的火山强迫），气候系统跑了该领域一直没法跑的实验：一个已知的、被测量的强迫施加在真实的行星上。观测响应——1992年达峰的全球平均表面冷却约0.4–0.5 °C、更强的北半球冬季增温格局（平流层气溶胶驱动的冬季响应极地放大）、到达地表太阳辐射约1%的下降、可测量的水循环减速——被那些为温室问题调校过的模型在百分之几度内预测（Hansen等人1990年代的预测做于喷发气溶胶量已知之前而大致正确；Soden等人与后来的模型-观测综合确认了幅度）。这段插曲对归因三重重要：它在已知大小的强迫上验证了模型的**辐射传输与云响应物理**（同一套计算温室强迫的物理）；它展示了**瞬变的检测威力**（1990年代"变暖因皮纳图博而暂停"的论点本身就是对归因框架的隐含接受——火山的冷却是框架预言的阴性对照）；它校准了最优指纹必须纳入的**火山指纹**以免给气溶胶项引入偏差——2019–20年航运硫酸盐减少如今被当作气溶胶强迫自然实验的同一逻辑。问题是：如果一次2000万吨SO₂喷转让行星冷却0.4 °C一年，而人为硫酸盐气溶胶强迫（约−0.5 W/m²，AR6对气溶胶-辐射加气溶胶-云的最佳估计）大致相当于每隔几年一次持续的皮纳图博，2020年船用燃料切换的揭面纱意味着什么？为什么2023年温度尖峰并*不*需要它作为解释？
::: solution
气溶胶项真实但在温度单位上很小（遮蔽总共约0.3–0.5 °C，AR6的"气溶胶强迫是强迫收支中最大的不确定性"），其2020年的阶跃变化在数年内至多贡献约0.05–0.15 °C——足以*推动*2023年纪录的时点，不足以造成它；皮纳图博类比是该领域能从物理而非猜测界定那个贡献的原因，也是尖峰的分解（ENSO、Hunga Tonga水汽、气溶胶揭面纱、趋势）在不确定度内加出观测跳升的原因。
:::
:::

::: warning 归因主张被夸大的五种方式——被怀疑论者、被活动家、也被科学自身的成功
**1."科学家证明了这场风暴由气候变化造成。"** 没有归因研究这么说；方法的输出是一个*定义指标*的风险比，而2015–24年的头条记录（"飓风就是气候变化"，按WWA作者自己的抱怨）是该领域正用其"我们无法归因"陈述抗争的翻译失败。**2."97%共识是一个归因主张。"** 共识（Cook等人2013–2019的元分析、99%以上专家一致的研究）说的是人为因果的*事实*；归因文献是其背后的*证据*，不是一次投票。**3."FAR意味着死亡的X%由排放造成。"** FAR是风险统计量（上面Allen 2004的告诫）；个体因果的读法是法院不断拒绝、媒体不断印刷的那种。**4."碳巨头研究证明Exxon造成了半个变暖。"** Feature等人2019的结果是在陈述假设（气溶胶、吸收）下对变暖信号的*源分配*，因那些假设而有争议，不是一个法律因果认定。**5."检测1995年就完成了，所以科学几十年前就定论了。"** 1995年那句话是一个*检测加弱归因*主张；2021年的"明确无误"判词建立在1995年并不存在的25年收敛证据——垂直指纹、能量收支闭合、同位素账目、反事实模型——之上。元要点是归因的公共失败模式是*过度翻译*，而其科学失败模式就是每篇诚实论文在自己局限一节发表的同一个敏感性分析——一个自我审计的领域与一个不审计的领域之间的区别就是这个告诫的全部内容。
:::

::: history 从Arrhenius的问题到法庭：归因的一百年 {#history-attribution}
归因的史前是*问题*的历史：Arrhenius（1896）问CO₂倍增让世界暖多少；Callendar（1938）问变暖是否已经开始；Möller–Plass辐射传输重算（1960年代）重新确立了量级；1979年Charney报告回答了第一个问题的不确定范围。第二个问题——开始了么，是我们的锅么？——以三波定量化。**第一波（1991–2003）：检测。** Schlesinger–Ramankutty与Tsigaridis–Falge格局研究、Santer 1996垂直检测、IPCC 1995第8章"证据的平衡"一句及其政治冲击（Byrd决议）、2001年第三次评估报告的"新的更强的证据"、以及建立回归工具箱的Allen–Stott–Hegerl最优指纹论文——全部汇聚于2003年欧洲热浪，它杀死了限定语：你没法给一个死了70,000人的夏天加限定。**第二波（2004–2015）：事件与收支。** Allen等人2004的两个世界实验；美国国家科学院2005与2009特别报告（"气候变化的归因于人类活动"与"极端事件归因"研讨会）让SEA获得联邦使用的合法性；2010–14归因连锁（Met Office 2010巴基斯坦降雨研究、2012–13澳大利亚"千年干旱"归因）；让"剩余排放"成为政策量的2012–13 Allen等人线性TCRE论文；以及2015年巴黎协定第八条与WWA的创立。**第三波（2016– ）：法庭与复合前沿。** 碳巨头清单的法律生命（Heede 2013、2015年Exxons与2017–21年美国市政诉讼的驳回-上诉拉锯、2019年Feature等人源归因论文）、Urgenda判决（2019）与荷兰政府的遵从、Neubauer诉RWE的证据采纳（2017）与其2022年基于因果的上诉改判、Milieudefensie诉Shell命令（2021，2024–25上诉中）、2021年"明确无误"判词、2022年巴基斯坦与2023年利比亚复合事件研究、以及2023–25年ICJ咨询意见听证——一个始于一台手算CO₂倍增、终于九十个国家就一个缩放因子的含义向世界最高法院递交陈述的领域。
:::

::: quiz
在最优指纹法中，一个强迫响应格局的"缩放因子"是：
- [ ] 模型的气候敏感度
- [x] 模型响应必须乘上的以匹配观测的回归幅度
- [ ] 太阳强迫对温室强迫之比
- [ ] 留在空气中的排放分数
::: solution
**回归幅度。** 温室指纹的缩放因子1.0 ± 0.2意味着观测变化以模型强度包含那个格局；与0无法区分太阳指纹因子意味着太阳没有任何可检测贡献。检测是因子不同于0的陈述；归因是因子在各强迫间的格局——而整个方法就是一个内置模型噪声协方差的多变量回归。
:::

## 练习

::: exercise {level=1 check="50"}
一项WWA风格的研究发现一场热浪的风险比（现代/工业化前）是2.0。可归因风险分数（FAR）是多少（百分比）？
::: solution
FAR = 1 − 1/RR = 1 − 0.5 = 0.5 → 50%：今天世界里事件风险的一半可归因于世界的改变——每个"可能性翻倍"头条背后的算术，也是头条关乎*风险*、不关乎事件存在本身的理由。
:::
:::

::: exercise {level=1 check="45"}
就工业时代的CO₂与甲烷当量，Heede的清单把63%归给90家"碳巨头"公司。如果到2010年累计化石排放为977 GtCO₂当量，那90个实体落在多少（GtCO₂当量，取整到10）？
::: solution
0.63 × 977 = 615.5 → 约620 GtCO₂当量——把"排放"从一个弥散的总量变成一份被告名单的数字，也是清单的记账规则（什么算"源"、水泥和放空燃烧如何处理）本身被诉讼的理由。
:::
:::

::: exercise {level=1 check="0.18"}
每单位累计碳的瞬变气候响应（TCRE）约每1,000 GtCO₂增温0.45 °C（AR6：可能范围0.27–0.63）。按中心估计，未来排放400 GtCO₂增加多少变暖？
::: solution
0.45 × 0.4 = 0.18 °C——把每条排放路径变成温度、把每个温度目标变成收支的线性TCRE算术，其已知告诫（线性对累计总量成立、对时点不成立；每吨变暖在停排后继续只在承诺调整的意义上成立）就是碳收支一课的主题。
:::
:::

::: exercise {level=2 check="6"}
一次指纹回归给出温室缩放因子1.2、不确定度±0.2（1σ）。温室信号在5σ水平上被检测到了吗？计算检测z分数，并说明缩放因子是1.2（而非1.0）对模型敏感度或强迫意味着什么。
::: solution
z = 1.2/0.2 = 6——远超5σ粒子物理标准的检测；因子>1意味着对模型强迫的真实响应强于模型平均（更高的敏感度）或真实强迫强于假设——同一个模糊性让缩放因子文献与能量收支方法结合时成为ECS约束的来源。
:::
:::

::: exercise {level=2 check="5000"}
在2003年热浪归因中，事件风险被发现至少翻倍（RR ≥ 2）。如果工业化前这种夏季的概率是每年1/10,000，用1-N重现期表示现代概率（取整到百），并说明"万年一遇的事件反正发生了"的论证为什么失败。
::: solution
RR = 2 → 现代概率2/10,000 = 1/5,000——五千年一遇的事件；论证失败是因为万年一遇事件本来就预期每10,000年发生约一次（而记录是*变化中*分布的150年），也因为把极端概率翻倍就是发现——重现期语言与FAR是同一个统计量，只是对规划者可读。
:::
:::

::: exercise {level=2 check="0.02"}
AR6把2010–19观测变暖1.09 °C中的1.07 °C归因于人类。归给自然强迫加内部变率的残差是多少？为什么残差之小本身就是一个归因结果？
::: solution
1.09 − 1.07 = 0.02 °C——与零无法区分：*仅人类*一项就在测量与内部变率不确定度内解释了观测变暖这一事实意味着收支里*不需要*自然项，历史变暖分解的"无失踪汇"逻辑（气溶胶项的补偿是1.07如何在温室与其他人为分量之间分配的主要不确定性）。
:::
:::

::: exercise {level=3 check="0.17"}
皮纳图博喷发注入约2000万吨SO₂，让全球冷却约0.45 °C约14个月。人为气溶胶强迫（约−0.5 W/m²持续）在辐射上大致相当于每年约150万吨SO₂的持续火山强迫。作为粗略比值，人为气溶胶帷幔相当于多少个*持续*的皮纳图博（用辐射等价：皮纳图博约3 W/m²持续约1年）？
::: solution
皮纳图博强迫约3 W/m²持续约1年；人为气溶胶−0.5 W/m²持续——按*瞬时*辐射项帷幔是永远运行的六分之一个皮纳图博；按问题要的比值（每年持续气溶胶强迫折合的皮纳图博数），0.5/3 ≈ 每年0.17——大约每6年一个皮纳图博的强迫，连续不断——2020年航运切换的揭面纱（约0.1 W/m²台阶）是推动而非驱动的原因，也是清洁空气权衡真实但相对CO₂项是二阶的原因。
:::
:::

::: exercise {level=3 check="0.6"}
某城市的百年洪水在+1.5 °C下被模拟为四十年一遇。计算风险比与FAR，并用WWA声明的方式把FAR说成一句话。
::: solution
RR = (1/40)/(1/100) = 2.5；FAR = 1 − 1/2.5 = 0.6——"人类影响把这种洪水的风险提高了2.5倍；当前风险的60%可归因于气候变化"——2023–24年地中海洪水声明使用的句子结构，附上指标敏感性告诫。
:::
:::

::: exercise {level=3 check="30"}
Urgenda法院下令荷兰到2020年在1990年水平上减排25%，以IPCC碳收支的公平区间为其定量依据。如果荷兰1990年排放为213 MtCO₂而2020年排放（命令前趋势）本会是190 MtCO₂，命令迫使排放比趋势线低多少MtCO₂？
::: solution
目标 = 0.75 × 213 = 160 MtCO₂；趋势190；强制削减 = 30 MtCO₂——一个*比例性*原则（IPCC的公平区间）如何变成法院可以下令的一个*数字*的算术，也是判决倚重碳收支文献（而非事件归因）成为其后大多数气候案件复制模板的原因。
:::
:::

::: quiz
同位素证据（大气CO₂的¹³C/¹²C与¹⁴C下降）具体排除了关于CO₂上升的哪种替代解释？
- [ ] 排放超过汇
- [x] 多余CO₂来自海洋或火山
- [ ] 甲烷氧化贡献CO₂
- [ ] 土地利用变化贡献CO₂
::: solution
**海洋与火山碳带着不同的同位素比值（而毛通量是被净吸收的、不是净加入的）；化石碳贫¹³C而¹⁴C已死，而空气的比值正朝那个方向移动。**同一套同位素账目还归因出*土地利用*份额（¹³C信号把它与化石分开），让源的账目成为测量而非估计——整个归因案中最安静也最决定性的一条证据线。
:::

::: summary
- 检测说变化不是噪声；归因把它分配：最优指纹法把观测对模型强迫格局回归，而缩放因子——温室约1、气溶胶约1、太阳约0——是"明确无误"判词的定量内容（观测1.09 °C中的1.07 °C是人类的）。
- 本案是一个收敛：实验室光谱学、化石碳的同位素指纹、没有人类就做不出1970年后变暖的反事实模型、闭合的能量收支、以及上新世类比——每条线排除一个不同的替代项。
- 单事件归因（Allen 2004的两个世界设计、FAR与风险比）让科学按灾难可读；其诚实的局限——指标敏感性、模型技巧、复合链条、适应混淆——如今是该领域自己发表的规程，而其输出是风险统计量，永远不是个体因果的判决。
- 源归因（Heede的90家公司=工业时代排放的63%）与法律转向（Urgenda基于收支的命令、Neubauer被采纳的归因证据、Shell、ICJ程序）把一般因果问题从科学搬进了法学——在那里它已不再输。
- 被夸大的句子是该领域主要的公共风险："这场风暴由气候变化造成"是方法*不*说的话，而风险比的真相与因果式头条之间的区别是归因科学的最后一公里——发生在新闻编辑室与法庭、不发生在回归里的那部分。
:::
