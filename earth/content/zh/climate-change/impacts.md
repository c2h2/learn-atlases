一部图集的影响章节曾经是一份预测目录。自AR6（2022）起它换了一种开头：*观测到的影响已被归因于人为造成的气候变化*——高置信度、整整一章——而评估报告的组织概念不是"变暖"而是**风险**，致灾、暴露与脆弱的乘积。这个重构就是本课的主心骨。冰川退缩是因为致灾；一座城市水尽是因为致灾*乘*其对那条冰川的依赖*乘*其从别处引水的能力；而面对相同温度变化的两个国家可能面对无法比较的风险，因为暴露与脆弱——人口、贫困、治理、护照的颜色——在做大部分算术。本课从框架走到生物学（物种、珊瑚礁、森林：响应已被测量的系统），再到人类系统（水、食物、健康、城市），终结在评估报告终结之处：损害的分布，全部科学中最尖锐的不平等数字。

::: definition 气候风险：致灾、暴露、脆弱——以及它们的适应 {#def-risk-framework}
AR6的定义精确：气候风险产生于气候致灾（事件或趋势）、暴露（其路径上的人、资产与生态系统）、以及脆弱（遭受损害的倾向——敏感度加应对能力）的*交互*，而**适应**是同时弯曲三条曲线的中介变量。这个从2012年SREX特别报告与灾害课程风险三角（[[natural-hazards/risk]]）继承的框架有四个评估报告敲打的后果。第一，*影响的趋势不是致灾的趋势*：富裕国家人均洪水死亡在整个二十世纪下降了两个数量级、在全球也降了很大一个分数（WMO灾害图集：从1970年代约50,000洪水死亡/年到2010年代数千年/年，尽管暴露更多），因为预警、保险与水坝移动了脆弱项——影响文献中最有希望也最少被报道的事实。第二，*暴露是一个选择*：33亿人生活在高脆弱环境中（AR6头条），而同一份报告数出在洪泛平原与低洼海岸的人比一代人多几亿——关于在哪里建的决定、不是气候，产出了大部分洪水损失趋势（2020年代的损失归一化文献）。第三，*脆弱由除气候外的一切分级*：2023年WMO分析发现1970–2021记录中约90%的灾害死亡发生在低收入国家，而Kotz、Levermann与Wenz 2024年*Nature*研究发现1960年以来已承受的变暖收入损失约是全球碳定价的20倍——*现在时*的分配数字。第四，框架的前沿概念：**软极限**（适应可能但被资金、知识或制度阻挡）对**硬极限**（没有适应能保住系统——一些礁、一些岛、一些冰川），以及**损失与损害**（适应极限之后的残余损害，在2022年COP27基金获得了制度之家）。框架不是修辞：它决定哪些损害被计入、谁为哪些付账、以及为什么同样的0.5 °C在哥本哈根是可管理的麻烦、在达卡是文明事件。
:::

::: definition 移动中的生物群：分布、物候、错配与灭绝风险 {#def-biota}
生物对迄今已达约1.2 °C的响应被记录得足以定量。**分布**：元分析平均是每十年约17公里的向极地移动与每十年约11米的向海拔移动（2011年Chen及同事综合，以同号与海陆对比更新——海洋物种每十年移动比陆上远3–4倍，追踪移动更快的等温线），而每度的最强移动在热带（"热带挤压"：生活在热极限附近的物种无处可去——2022年Strugstad及同事*Global Change Biology*分析发现热带陆上变温动物已经在经历每度最大的适应度代价，让热带2 °C生理上像温带4 °C的"代谢栖息地损失"）。**物候**：春季事件（展叶、昆虫羽化、鸟类产卵、珊瑚产卵）在温带记录里每十年提前数天（Parmesan及同事2006与2018综合），而危险不是移动本身是**错配**——依赖不同线索（温度对日照长度）的相互依赖事件脱钩，经典案例是荷兰橡树-冬尺蛾-山雀系统（2006–2022年Visser线：山雀现在在暖春错过毛虫峰值，伴随可测量的繁殖失败）与2020年代珊瑚产卵对温度线索的研究。**灭绝风险**：2022年*Science*评估（Urban及同事）把约50,000个被评估物种中4–8%放在+2 °C时仅气候变化的高灭绝风险、+3 °C时8–12%、+4.3–5 °C时12–16%（对某些扩散能力差的类群升至约一半）——这些数字是*加在*IPBES 2019年约100万受威胁物种估计背后的非气候驱动之上、不是取代（栖息地损失与土地利用仍是本世纪主导的灭绝驱动；气候是增长最快的那个）。**生态系统重组**是AR6终于能自信评估的观测影响头条：北极海冰生物群（北极熊、海豹与因纽特狩猎系统）、爬上山顶"灭绝自动扶梯"终点的高山群落（2022年Steinke及同事*Nature*综合：欧洲与加州天空岛的局地植物灭绝已被记录）、海带林（2011–2016北太平洋暖块让本地海带崩溃90%以上、被牧草地取代——一个带滞后的状态转换）、以及临界点一课（[[climate-change/tipping-points]]）讲过的热带礁系统。诚实的认识论：观测影响归因比致灾归因难（生态基线嘈杂、被土地利用与开发混淆），而AR6"人类影响已促成观测到的生态系统变化"的判词建立在数千个独立地方研究的方向一致性上——指纹逻辑应用于一百万个小实验而不是一个大实验。
:::

::: example 暖块与PNE：作为生态系统实验的海洋热浪 {#example-blob}
2013–2016"暖块"——一团停在北美近海、按2016年Jaumdish及同事归因分析被放大（放大约45%）成无助力本会非常罕见的事件的200,000 km²异常暖水——与其继承者、到2023–24年已把美国西海岸近岸温度在某些地方抬高25 °C的2019–2024"暖块2.0"/太平洋节点事件（PNE），产出了海洋史上最大的无计划生态系统实验。PNE的死亡名单，在2023–25综合论文（2023年*Oceanography*专刊、2024年*PNAS*与*Science*论文）中编目：仅2015–16年就有约10亿只（估计范围0.5–20亿）普通海鸦死于阿拉斯加湾——该种群的62%，有记录以来归因于海洋热浪的最大野生动物死亡事件（2020年Piatt及同事*PNAS*分析）；2023年36,000只北方海狗幼崽在白令海饿死（2024年NOAA报告）；2023–24年PNE把阿拉斯加湾鳕鱼渔业压到关闭水平、让邓杰内斯蟹渔业反复关停、并把亚热带物种（幽灵蛸、高体若鲹）带到阿拉斯加。机制如今是教科书：热浪杀死了小的富脂桡足类、只留下果冻状低热量猎物（2023年*Science*"能量流"论文：食物网可供捕食者的能量在峰值下降约70%），暖水层结并饿死了陆架，而2023年一层前所未有的淡水盖（2023年大气河流之年）延伸了异常的范围。2024–25判词：PNE的海洋生态系统在北部边缘*没有*回到2014年前状态——海带与海鸦数据提出的状态转换问题是海洋版的临界点一课，区别在于海洋的"阈值"正以地质记录很少匹敌的速率被越过。
::: solution
海洋热浪的十年供给了影响一课最干净的因果链——致灾（被归因放大的热浪）到机制（食物网的大小与脂质错配）到影响（记录的百万级死亡、渔业关闭）——因为海洋集中了信号（热容让异常巨大）而渔业数据提供了经济尾巴。它也展示了**持续性**问题：海鸦十年未恢复、海带在不列颠哥伦比亚与塔斯马尼亚仍以牧草地为主（塔斯马尼亚部分保护区2021–24年的"绿化"逆转显示在海胆被牧回的地方恢复是可能的），而2024年海洋热浪*频率*自1982年以来全球翻倍的发现（2023–24年Oliver及同事更新）意味着恢复间隔、不是事件，如今是海洋生态系统的约束项。
:::
:::

::: example 澳大利亚2016–2020：复合事件实验室 {#example-australia}
在2016年珊瑚白化（大堡礁三分之二的珊瑚在2016–17连年事件中受影响，2018年Hughes及同事*Nature*调查——第一个有正式归因的事件：2016年白化因变暖约可能1.75倍，King及同事2016分析）与2019–20"黑色夏天"火季（1,860万公顷烧毁、约30亿动物被杀或流离——2020年Boon及同事估计，被广泛引用也有方法论争议）之间，澳大利亚在单一大陆上跑了完整的复合序列：海洋热浪与礁白化（2016–17）、千年干旱的继承者"大旱"（2017–19，东南水库到20%）、2019年破纪录热与火季（World Weather Attribution 2020分析：热、干、易燃天气因气候变化约可能30%）、灾难性的2019–20之夏、然后是2021–22年把同一些流域淹了三次的拉尼娜"三峰"（2022年悉尼洪水——一年两遇的百年一遇事件，2022年BoM与WWA分析发现强降雨因变暖强了约25–50%）。生态账簿是任何地方最完整的：2021–23研究记录了第一批气候驱动的澳大利亚哺乳动物灭绝（2016年政府将大堡礁鼠从名录除名——IUCN知情名录上第一个以气候为原因正式灭绝的哺乳动物——加上2022–23年审结认定更多特有种应被列为气候受威胁），2022–23年发现火-白化-干旱序列已把湿热带与礁流域部分地区推入新奇状态，以及恢复科学（2023–24年GBRMPA调查：礁珊瑚覆盖在部分北部海区回升，而2024年第六次白化袭来）。
::: solution
澳大利亚对框架的价值在*序列*：致灾各自可归因、各自中等到极端，而其聚集——复合事件文献（2022年Zscheischler综合）说变暖通过共享驱动（印度洋与太平洋状态、持续反气旋）让其更可能的一种现象——产出了任何单灾种分析都不会预测的影响。政策账簿两面都砍而两面都属于本课：澳大利亚人均排放在发达世界最高之列而其适应能力很高，然而礁与湿热带面对硬极限问题——脆弱与致灾不是同一轴的证明，也是"发达国家"保护资产负债表、不保护生态系统的证明。
:::

## 水、食物、健康、城市——以及谁付账

人类影响遵循同样的致灾-暴露-脆弱代数，只是数字更大、地理更难看。评估的图景：水安全与食物系统已经在旱区与热带退化；健康影响由热领跑、集中在老人、穷人与户外劳动者；城市是暴露的震中；而负担落在贡献最少的人身上——让气候成为一个正义问题不亚于环境问题的算术。

::: definition 水与食物：二十亿与四种作物 {#def-water-food}
**水。**大约10–20亿人依赖山地雪与冰川储量作为旱季供应（兴都库什-喜马拉雅评估"本世纪末三分之一"的算术；AR6高置信度陈述：冰川退缩*已经*在多个区域减少了水可用量与水电潜力——2021–23观测影响：安第斯普纳的井枯、预示2024年洪水的2022–23破纪录低喜马拉雅雪、让莱茵河驳运与受冷却水限制的反应堆停摆的2022年欧洲干旱）。旱区是致灾与暴露相遇最糟的地方：2020–23东非干旱（五个雨季失败、2023年3,600万粮食不安全——2023年WFP清点，归因文献发现*热*强烈人为影响而降水的印度洋驱动不确定）、2019–20与2023–24南部非洲、科罗拉多2020–23大干旱的算术（一半人为，在极端一课[[climate-change/extremes]]讲过）。**食物。**2019年Zhao及同事*PNAS*多模型系综的产量敏感度——每全球平均增温1 °C，全球产量下降约6%（小麦）、约7.4%（玉米）、约3.2%（稻米）、约3.1%（大豆），在CO₂施肥与适应*之前*——仍是引用锚，而2024年*Nature*归因分析（Pan及同事）发现了1961–2021已实现的效果：气候变化已让全球卡路里生产的增长相对无变化反事实慢了约三分之一，损失集中在热带、温带"绿色革命"的收获部分由气候驱动。渔业数字：2022年*Science*分析（Free及同事）发现气候变化自1930年以来已让最大可持续捕获全球减少约4–5%、热带约5–7%——对30亿人蛋白质的现在时打击。价格与冲突的尾巴：2010年俄罗斯热浪把小麦收成砍了约25–30%，随之的出口禁令促成了2010–11全球小麦价格飙升（世界银行与Headey–Fan分析），2015年May及同事*PNAS*研究估计对阿拉伯之春起义时点方差贡献约6–10%的链条中的一环——冲突文献复现辩论（2024年*Nature*气候-冲突元分析：每*全球*变暖1 °C有组织的暴力风险增加约11–14%，区域集中强烈）收窄但未打破的发现。
:::

::: definition 健康与城市：最古老的死亡与最新的暴露 {#def-health-cities}
**健康。**Lancet倒计时的2022–24清点锚定数字：2018–2022年65岁以上人群热相关死亡平均约489,000人/年，比1990年代基线增加37%（2023年报告的头条；2024年更新发现又一个纪录——比1990年代高61%），而WHO较早的2030年代预测（热、洪水、腹泻、疟疾与儿童营养不良合计每年约250,000额外死亡，不含营养不良驱动的儿童发育迟缓项）仍是政策锚。媒介地图正随等温线移动：2023–24美洲登革热纪录（超过600万报告病例，PAHO）发生在向两极与向上都扩张的范围里（2020年代*Lancet*与*PNAS*分析把1980年以来*Aedes aegypti*气候适宜性约15–20%的扩张归因于变暖，城市化是合著者），而疟疾的高地前沿（2022年埃塞俄比亚与东非高地复发）遵循同一逻辑。劳动数字是经济数字：ILO 2019评估预测热压力到2030年将让南亚与西非损失约2.2%的总工作小时（数千万全职当量岗位），而2021–24研究发现最热地区每年劳动小时已有约2–3%因热损失——"热分裂国家"增长文献背后的机制。**城市。**2021年分析：96%的城市已经或正在离开农业与基础设施在其上建造的类全新世气候生态位（Chen及同事*Environmental Research Letters*研究：平均城市的气候正朝约3.5 °C更暖的类似物移动，三分之二的城市朝23 °C更暖的类似物——"气候类似物"框架）让城市章节不言自明，而暴露堆叠在复合：热岛加热浪（2021年太平洋西北与2022年欧洲死亡）、海岸挤压（海平面一课的滋水算术）、以及非法定居点陷阱——约10亿非法定居点居民集中在正规开发避开的洪泛平原、坡地与岸线，AR6对气候脆弱最大单一集中的表述。适应红利的反向砝码也属于这里：1970年Bhola气旋（30–50万死亡、预警前的孟加拉）对2020年代（相当强度下气旋死亡以千计，WMO把下降归因于预警与避难所）是风险方程中脆弱项最可处理的被证明之证据——也是AR6关于"可行、有效、低遗憾适应"的语言比其关于致灾的语言更有希望的原因。
:::

::: example 巴基斯坦2022：一个可归因季节的分布 {#example-pakistan}
2022年巴基斯坦序列是影响一课的参照案例，因为风险方程的每一项都带着一个数字出现在其中。三四月西北部热浪（通常温带的山麓40 °C、比常年高+9 °C）在2022年Irfan及同事与WWA分析中被发现人为变暖下约可能30倍；它在季风到来之前熟化了土壤与雪堆。六月到九月的季风随后在Mekran海岸一周降下390 mm、季节总量约为30年均值的3倍（Link及同事2023分析把7月降雨增强最多一半归因于变暖），而印度河流域同时承载着热浪预激活冰川的融化与2021年"第三极"高温的湖溃——一场任何单灾种模型都没预测的复合洪水。暴露：峰值时三分之一的国土在水里、800万人流离失所、1,700多人死亡、约300亿美元损失与重建需求（2023年联合国评估）——占GDP的9%，而这个国家一生排放只贡献了大气CO₂的约0.4%。脆弱项在损害地图上明摆着：Sindh小农与卡拉奇城市贫民（其被淹的贫民窟建在2010年代开发部门已标出却未执法的洪泛侵占地上）对同一场洪水放过的Bahria Town门禁飞地。损失与损害政治随之而来：巴基斯坦财政部长主持77国集团的损失与损害组、2022年COP27创建基金的决议、以及写作时尚未解决的2023–25之争——重建同一片洪泛平原的"适应"资金是否算入其中。
::: solution
巴基斯坦2022是案例研究，因为它*同时*可归因、复合、暴露驱动、脆弱分级、正义框架——影响文献分别发展出的五个属性。其方法论教训：*降雨*（最多一半）与*热浪*（30倍）的单事件归因是稳健陈述；归因*洪水*还需要土地与河道工程史（2023年世界银行与ADB洪水报告发现多数损害发生在2010年洪泛侵占区——暴露项干着它通常干的事，即主导）。其正义算术——排放的0.4%、GDP的9%——是损失与损害运动的经验核心，也是2024–25基金谈判对影响文献比任何新预测都重要的原因。
:::
:::

::: example 开普敦"零日"：成为模板的险些失败 {#example-day-zero}
开普敦2015–18干旱——连续三个干冬、水库到2018年1月落到可用储量的14%、城市公开计算其水龙头干涸的日期（"零日"，随需求下降从2018年4月推到5月再到8月）——是城市水风险的评估参照案例（AR6第二工作组案例研究；2018–19 Weather and Climate Extremities与WWA分析）。归因判词就是本课的缩影：流域上的降雨短缺在自然变率内（多个世纪的树轮与仪器背景：可比的干旱发生在1920年代与重建的1830–40年代），而*热*项——变暖趋势加到需求侧的约1.5 °C额外蒸散——被发现把零日级事件的几率大约乘三（2018年WWA与2019–21跟进；2021年*Nature Sustainability*上该区域归因文献"热干旱、不是干干旱"的框架）。响应是世界上唯一完成的城市用水需求侧崩溃实验：累进费率、宵禁、降压与一场公众羞耻运动在十八个月内把都会区消耗砍掉一半以上——"顺便，你脑子里的那座坝"运动的数字（每户每天4.5到不足2.5立方米）如今在每本公用事业教科书里——而零日从未到来。公平账簿在记录中同样明摆着：非法定居点（Cape Flats水点住户，其人均用水本就只有富裕南部郊区的五十分之一）承受了最严格的配给，而2018–19分析把每户水龙头数的分布数作首要脆弱变量。而治理的善后是误适应目录：随后上马的紧急海水淡化与地下水项目如今是干旱驱动的基础设施是锁定高碳高成本供应（2022–24水务部门审查）、还是买来下一场干旱的韧性（2022–23冬季储量回升到60%以上显示这不是被害妄想）的案例研究。
::: solution
零日对框架的教训是各项的独立性：致灾是自然的（降雨在记录内）、放大是气候的（蒸散税，可归因）、暴露是超出1990年代水权上限的二十年水库建设与城内移民，而脆弱是每户水龙头地图。这个分解——不是"气候变化造成了干旱"——是2018年媒体周期两个方向都搞错的那句话，也是本案如今同时锚定归因置信层级（极端一课[[climate-change/extremes]]）与城市水适应文献的原因：那个十八个月把用水减半的城市证明了水方程的需求侧是整个影响一课中最有弹性的项。
:::

::: warning 影响与损害主张被扭曲的五种方式
1. **一切皆气候谬误。**洪水*损失*随海岸建筑上升，作物产量在变暖*之下*上升了五十年，而2020年代的饥荒恐慌一再化解为冲突-援助失败（2017年南苏丹与2020年代也门粮食危机是带气候副标题的政治经济事件）。归因文献故意狭窄是有原因的："气候贡献了"是一个测量主张，"气候造成了"通常不是。
2. **致灾归因偷换影响归因。**"热浪被变得可能5倍"对死亡率不自动说明什么——死亡率取决于预警系统、住房与年龄结构（2003对2015欧洲比较）。两项都真实而它们回答不同的问题；混淆它们夸大了一些主张、隐藏了适应的成功。
3. **静态脆弱框架。**2100年预测损失把2020的世界冻在原地；真实的世纪将包括收入增长、移民、技术与（有时）误适应。诚实的评估（AR6章节结构、2023–25综合更新）把损失呈现为*路径*——同一温度下SSP1对SSP5相差数倍——而"仅气候"损失数字是一个思想实验，不是预测。
4. **误适应盲点。**把损害在空间、时间或人群之间转移的适应在其自己的账上被记为成功：2023年*Nature*综述的目录（饿死下漂海滩的海堤、开采含水层的灌溉、在峰值热时给电网加载的空调）让"误适应"成为AR6的正式类别——区分起作用的适应资金与只是立项入账的适应资金的概念。
5. **不平等数字被引错。**"最穷的一半贡献排放的10%"与"前10%贡献一半"都为真（2020–22 Oxfam与Lucas及同事分配账）也都被误用：账目是按收入等级的*消费*排放，全球与累计版本相差两倍，而正义论证不需要精确的分配——它只需要符号，而每个账目对符号都是一致的。
:::

::: history 从马尔萨斯到圣地亚哥网络：影响科学的两个世纪 {#history-impacts}
影响科学比气候科学更老：十九世纪末农业化学的"CO₂让沙漠开花"猜想（Arrhenius自己1893–96年的笔记欢迎更暖的欧洲、Callendar 1938年的论文预言更丰的收成），以及中期苏联学派（Budyko纲领，其"温室暖热北方谷仓"论仍是每个收益主张的智识祖先）先于现代时代。现代领域以1970年代萨赫勒饥荒开场（1973–75灾难让"荒漠化"成为联合国类别，并通过Charney与1979年Charney报告生物地球物理让人为-反照率-植被反馈成为一个研究纲领），穿过发明现代风险评估的1980年代臭氧与酸雨学派、以及1990年代的制度化：IPCC 1995年第二工作组（第一次说"证据的平衡表明存在可辨识的人类影响"的评估——说的是影响不是温度）、1990年代损害函数之争（Nordhaus DICE谱系及其批评者）、以及2006–07年Stern回顾把影响变成经济学（主导了十年政策的"GDP的5–20%对减排的1%"框架）。2010年代是框架与归因的十年：2012年SREX特别报告（上面的风险定义）、AR5第二工作组2014"严重、普遍与不可逆影响的风险"判词、World Weather Attribution快速归因网络的影响侧应用、以及2018年SR1.5的0.5 °C差额（珊瑚70–90对99%的数字、开普敦与1.5 °C插曲）。2020年代带来观测影响转向：AR6第二工作组2022"观测与预测的表面与淡水变化"章及其归因章（第一次以高置信度宣称人类影响已促成*观测到的*生态系统与食物系统影响的评估）、33亿脆弱者头条、2022年巴基斯坦与2022–23非洲之角损失记账、COP27圣地亚哥损失与损害基金、以及2024年*Nature*分配损失论文——影响文献的数字变成赔偿文献数字的时刻。
:::

在AR6框架中，面对相同变暖的两个国家气候风险非常不同，主要因为：
- [ ] 一国的碳足迹更小
- [x] 暴露与脆弱——人住在哪里、拥有什么、应对能力——承载着大部分算术
- [ ] 致灾归因因区域而异
- [ ] 损害函数按国家标定

## 练习

::: exercise {level=1 check="85"}
元分析发现物种分布平均以每十年约17公里向极地移动。50年平均移动多少公里？
::: solution
17 × 50 = 85公里——对平均被研究的物种，半个世纪大约从伦敦到林肯郡海岸的距离；让"气候变化正在移动生物群"成为测量事实而非预测的数字，也是为静态物种设计的保护区网络需要连通走廊的原因。
:::
:::

::: exercise {level=1 check="12"}
多模型系综发现全球小麦产量每全球平均增温1 °C下降约6%。在+2 °C时、CO₂施肥与适应之前的评估下降是多少？
::: solution
6 × 2 = 12%。两个告诫是承重的：CO₂施肥加回几个百分点（净效应是田间实验测到的），而适应（早播、新品种）再加更多——6%/°C是锚定风险的*无适应*敏感度，不是预期结果。
:::
:::

::: exercise {level=1 check="1.47"}
2018–2022年65岁以上欧洲人热相关死亡平均约每年49万（Lancet倒计时）。如果比率到2100年翻三倍，那是每年多少百万死亡？
::: solution
0.49 × 3 = 147万/年。适应章节回答的预测算术：同样的三倍施于1990年代死亡率（本身更高）正是2003式事件证明适应所防止的——2015与2022欧洲热浪在更低死亡率下比2003每致死率更热，被证明的弹性。
:::
:::

::: exercise {level=2 check="15"}
俄罗斯2010年热浪把小麦收成砍了约25%。从6000万吨收成，损失了多少百万吨？
::: solution
0.25 × 60 = 15 Mt——全球产量的约1.5%，被撤到一个出口禁令之后，助推了2010–11小麦价格飙升（谷仓级联机制：单一出口国的气候冲击通过贸易政策、不只是产量传播）。
:::
:::

::: exercise {level=2 check="19"}
珊瑚礁在+1.5 °C时失去其范围的70–90%（中值80%）、在+2 °C时99%以上。用99%的数字，从1.5到2 °C的半度额外增加多少个百分点的损失？
::: solution
99 − 80 = 19个百分点——2018年SR1.5使之出名的"0.5 °C之差"：对礁（也对冰盖、大干旱与贫困），损害函数是凸的，所以最后半度比第一度更贵。
:::
:::

::: exercise {level=2 check="9600"}
2021年气候类似物研究发现96%的城市已经或正在离开类全新世气候生态位。在一个5万以上人口城市共10,000个的世界里，多少个离开生态位？
::: solution
0.96 × 10,000 = 9,600。框架的力量在于全新世生态位是*基础设施*——作物历、制冷惯例、建筑规范、水工程——被设计于其中的地方；离开它就是暴露项的定义，而留下的4%（多是凉爽的海事城市）是世界上最幸运的气候少数。
:::
:::

::: exercise {level=3 check="0.12"}
西非一季有P(热浪) = 0.30，而给定热浪，P(干旱) = 0.40。复合热旱季的概率是多少？
::: solution
0.30 × 0.40 = 0.12——八年一遇的复合季。粮食系统算术随之：主粮在复合年减产20%，期望年产量损失是0.12 × 20% = 2.4%，通过储备与价格复利——复合事件的*依赖*、不只是频率驱动适应设计的原因。
:::
:::

::: exercise {level=3 check="7.4"}
分配账目发现全球收入前10%造成约52%的消费基础排放、后50%造成约7%。前十十分位份额对后一半份额之比是多少？
::: solution
52/7 = 7.4倍——不平等数字的头条形式。保持诚实的告诫：消费（不是领土）记账、等级内人均平均、以及后一半份额在任何发展路径下*上升*的事实——这正是为什么碳空间之争[[climate-change/emissions-budgets]]是一场伪装的分配之战。
:::
:::

::: exercise {level=3 check="450"}
1米风暴潮威胁一座沿海城市50万人。没有预警时致死率是0.1%；有早期预警，0.01%。预警避免多少死亡？
::: solution
500,000 × 0.001 = 500无预警死亡；500,000 × 0.0001 = 50有预警；避免450。适应红利计算最纯粹的形式——2022年WMO发现2015年以来早期预警覆盖五倍的增长每年避免了数万死亡——是全球尺度同一个乘法，整个课程中最便宜的大数字影响削减。
:::
:::

::: quiz
AR6 2022年关于观测影响的判词具有历史意义，因为它是第一个以高置信度宣称：
- [ ] 2 °C时未来影响将是灾难性的
- [x] 人类影响已经促成了对生态系统与食物系统观测到的影响
- [ ] 适应在热带无效
- [ ] 经济损失每十年翻倍
::: solution
**观测影响归因**：从"预测风险"到"检测并归因的影响"的转变改变了该领域的证据地位——温度归因2013年做出的同一转变。它建立在数千个独立研究（分布、物候、产量趋势、礁损失）的一致性上，也是让"损失与损害"成为经验主张而非预测的东西。
:::

::: summary
- 风险 = 致灾 × 暴露 × 脆弱，适应介入全部三项：组织AR6第二工作组的框架，也是相同的致灾产出1970年Bhola与2020年代安攀气旋两种结局的原因——脆弱是方程中最可处理的项。
- 生物响应是被测量的，不是被预测的：分布移动约17公里/十年、物候错配、海洋热浪在单一事件中杀死十亿海鸟、第一个正式气候灭绝的哺乳动物——土地利用仍是更大的灭绝驱动而气候是增长最快的那个。
- 人类账簿已经翻开：依赖冰川的二十亿人水安全退化、卡路里增长被已实现变暖拖慢三分之一、每年约五十万热死亡且在上升、96%的城市在设计气候之外——而复合、级联事件（巴基斯坦2022、澳大利亚2016–22）是单灾种分析漏掉的格局。
- 分布就是头条：约90%灾害死亡在低收入国家、收入前十十分位造成约一半消费排放、现在的损失不平等已超过碳价二十倍——气候影响是历史上最大的代际与国际转移，已经在路上。
- 反向砝码真实且属于摘要：人均灾害死亡已下降五十年、适应在有资金时显然有效、而损害函数是路径不是命运——通往响应一课[[climate-change/responses]]的桥。
:::
