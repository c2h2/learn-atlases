2021年8月，北美西海岸经历了那个热穹顶，其数字十年前模型在当前排放下说还要几个世纪才会出现：利顿的49.6 °C、波特兰的46.7 °C、太平洋西北200年量级的距平在21世纪的第30年就到来了，而在其2021–40评估变暖约1.5 °C（不是事件暗示的约2.5 °C）的情景（SSP2-4.5，中间那条）之下。当事件归因与建模团队完成工作，它成了预测这一课的完美案例研究：热*不是*简单意义上的模型失败——CMIP系综的1.5 °C世界，在其分布尾部与正确的天气配置下检视，包含这样的事件作为罕见但可能，而"不可能"的说法来自把*中心*预测读成边界、而不是读成一个模型欠采样的分布的中部。这是本课描述的学科的第一条规则：**预测是一个其排版本身就是一种选择的世界上的概率陈述**，其中每个数字都带着三个分开的 不确定性——人类选哪个情景、气候如何响应（模型散布）、以及内部骰子掷出什么（变率）——并带着一个令人尴尬的性质：第一个、最大且最具政策相关性的 不确定性根本不是科学的 不确定性。因此预测文献是一栋三层的楼：情景（人类的故事，SSP-RCP设计）、模型（CMIP，那个其十万余模式年为该领域实验室的耦合模式相互比较计划）、以及统计（如何读一个范围、一个似然、和一个"最不可能之未来"）。

## 情景架构与模式实验室

::: definition 情景：从IS92到SSP-RCP设计 {#def-scenarios}
气候预测是有条件的："如果排放走这条路，气候走那条路"，而"如果"由**情景**供给——关于人口、增长、能源、土地利用与气候政策的内部一致的故事，由综合评估模型（IAM）建造、被气候模型用作强迫输入。谱系：IPCC的**IS92**组（1990，写成单线排放路径）、**SRES**家族（2000：A1、A2、B1、B2——产出仍被引用的A1B与A1FI化石燃料世界的"故事线"设计）、以及2010年以来的**RCP–SSP架构**：四条**代表性浓度路径**（RCP2.6、RCP4.5、RCP6.0、RCP8.5——以其2100年辐射强迫W/m²命名，由简单气候-碳循环模型从排放算出，而RCP8.5的重煤、无政策路径被设计为*高端边界*、不是照常营业的预测——2016年Pester–Kendall与O'Neill–Kriegler分析显示世界走在RCP4.5与RCP6.0之间，以及2020年代文献"RCP8.5作为中心路径不可信，但作为边界仍然有效、作为影响的最坏情形有用"的判词）与五条**共享社会经济路径**（SSP1可持续、SSP2中间道路、SSP3区域对抗、SSP4不平等、SSP5化石燃料驱动发展——关于*世界*的叙事加模型描述，各有自己的人口、GDP与土地利用轨迹）的交叉积。CMIP6协议运行了标准矩阵（"第一层"五条：SSP1-1.9、SSP1-2.6、SSP2-4.5、SSP3-7.0、SSP5-8.5），而AR6的头条数字是其输出：相对1850–1900，2021–40的评估变暖在*所有*情景中约1.5 °C（近期已锁定——预算一课的累积物理），而2081–2100范围跑在**1.4–1.8 °C（SSP1-1.9）、1.3–1.7（SSP1-2.6）、2.1–2.5（SSP2-4.5）、2.7–3.5（SSP3-7.0）与3.3–4.6（SSP5-8.5，可能范围）**——世纪之末五倍的散布几乎全是*情景*，是科学界对该领域主导不确定性是人类选择这一事实最清晰的演示。情景层还带着**仿真器**机器（简化模型——MAGICC、FaIR——用评估的TCRE与气候反馈参数把任何排放路径变成温度路径，上一课碳预算与NDC分诊算术背后的工具）与更新的**过冲路径**（AR6第三工作组背后1,000多个IAM情景，其中多数超过1.5 °C再回落，其对二氧化碳移除的依赖是移除怀疑论文献的主题）。
:::

::: definition 模式实验室：CMIP、气候敏感度、以及范围为何持续 {#def-cmip}
预测引擎是**耦合环流模式**——大气、海洋、海冰、陆面，以及越来越多的化学、碳循环、冰盖与动态植被——在情景强迫下积分几个世纪，并由**耦合模式相互比较计划**协调四十年（CMIP1 1996到CMIP6 2014–，约60个建模中心，发表输出超过3 PB，"DECK"协议的标准150年运行让每个模式的敏感度、变率与型直接可比）。头条诊断量是**平衡气候敏感度**（ECS——CO₂四倍后的平衡变暖）：AR6评估范围**2.5–4.0 °C（最佳估计3.0）**，一个比1979年Charney报告的1.5–4.5*更窄*的范围，不是因为物理变好了而是低高尾被三条独立线索排除了（仪器记录的约束——历史-气候"涌现约束"文献；古气候——末次盛冰期的温度-CO₂关系；以及云的过程理解，CFMIP与DYCOMS-II/EPIC观测战役钉住了海洋低云与夹卷参数）。**瞬态**响应（爬坡期间的变暖，本世纪在乎的）最佳估计约1.8 °C，而CMIP6模式的中位敏感度相对CMIP5*上升*了（几个新模式的云反馈参数化把ECS推到4–5.4 °C——Hausfather–Zelinka–Takahashi 2020年的调和显示离群值是云微物理假象而评估范围不变）——共同体审计自己系综的公开示例。模式的技巧记录是预测文献的信誉：它们重现观测的季节循环、ENSO谱、太平洋年代际型、日循环（在对流参数化调参后）、过去40年全球变暖"指纹"、南极涛动的趋势、以及——最难的检验——观测趋势的*垂直*与*区域*结构；其已知失败同样被编目（双ITCZ偏差、大西洋Niño振幅、"过于持续"的MJO、南大洋急流位置、非洲东风波的系统性低估、以及塑造了下文暂停辩论的著名热带太平洋"冷偏差"）。前沿是**高分辨率与"风暴解析"一代**（DYAMOND与百亿亿次项目运行约1–7 km全球模式，显式解析中尺度涡与热带气旋——2020年代发现更高分辨率通过改变云响应提高气候敏感度，以及2024–25首批多年1 km模拟，其气旋-气候信号如今是被*模拟*、不再是统计推断的）。
:::

::: example 成为预测的"暂停"：模式如何预测了自己的停顿 {#example-hiatus}
1998到2013年间，表面变暖率降到约0.05–0.12 °C/十年，对抗模式预测的约0.2——"暂停"或"停顿"，该领域政治史上被利用最多的距平。科学化解，2014–2018年间发表、如今是教科书，有三部分值得作为*预测方法论*一课来教。(1) **模式从不错误于热的去向**：海洋热含量（Argo）与能量收支（CERES）记录显示总热吸收没有暂停；表面暂停是一次*再分配*，太平洋的信风（正PDO/IPO位相与加强的Walker环流）通过副热带单元与南大洋风驱动俯冲把异常热泵到约700 m层以下（Meehl 2011、England 2014、Kosaka–Xie 2013"什么造成了暂停"的太平洋归因，以及显示缺失的热随2015–16厄尔尼诺重新浮出的2017–18研究）。(2) **受迫的型在正确的地方可见**：暂停时代东热带太平洋的表面变冷、深海增暖、以及西太平洋/印度洋上加快的海平面上升（太平洋封存的"海平面指纹"，Church–Godedange与Gregory研究）都是一个暂停世界的*被预测*特征，而2023–24表面变暖尖峰是其镜像。(3) **预测对预测的区分**：年代际*预报*（初始化的后报系统——英国气象局的GloSea5、GFDL与ECMWF系统——从观测海洋状态出发，因此*能*预知太平洋的位相）提前勾画了2000年代减慢（Meehl与Collins学派2009–2013论文），而非初始化的*预测*（CMIP的自由运行系综，对太平洋的骰子一无所知）只能框住它。因此暂停是该领域三层 不确定性结构最干净的演示：情景在15年上不相关，模式散布小，而内部变率——公众误当作预测的那一项——支配了一切，正如 不确定性分解数学对约20年以下时距的预测。
::: solution
分解算术：对全球表面温度的20年平均，内部变率方差与相邻情景之间的受迫信号之差相当，而对50年平均情景项占主导（Hawkins–Sutton 2009与Dessai–Lempert后续"死区"图——显示对2080年代情景 不确定性压倒一切、而对2020年代变率与模式散布压倒一切的图）。暂停十年落在诚实预报关乎*风险*、不是轨迹的死区——"这十年变暖减慢了吗"的头条不断重新进入的同一区域。
:::
:::

::: example 加速问题：变暖率本身在上升吗？ {#example-acceleration}
2023–24年，最近20年观测到的变暖率（约0.25–0.3 °C/十年）位于同期历史强迫下CM6多模式范围的顶端或略高，引出了该领域公开辩论的问题：*变暖的速率是否在模式的情景之外加速*——如Hansen等2023–24"正在加速的变暖"论文所主张（把超额归因于航运气溶胶减少、生物质燃烧黑碳降低、以及可能的云反馈加速）——还是排放更高（2023年化石CO₂路径贴着历史清单的*上部*走）、厄尔尼诺爬坡、与内部变率落在趋势上的预期组合（强迫-响应学派：Forster等的最新气候状态核算、2024年Manomaichai–Forster趋势分解发现计入气溶胶与ENSO后观测趋势在模式系综内）？这个问题是*定量*框定的：平衡反馈参数λ（模式的约0.8–1.2 W/m²/K，观测记录的约1.0–1.4）与涌现约束文献对"过于敏感的模式"问题的收窄（Sherwood 2020来自季节循环的约束与型效应文献）都允许真实ECS接近4而非2.5而不破坏任何东西，而2020年代观测趋势是第一个轻度偏好上半区的。预测后果是具体的：如果真实瞬态响应比系综中位数高20%，2081–2100 SSP2-4.5范围的上半区（2.5 °C而非2.1）就是规划数字，1.5 °C到达日期提前约5–10年，而"锁定"的近期变暖（2021–40的约1.5 °C）变成约1.6–1.7。练习：说出加速问题*实际上*关乎三个不确定性项（情景、模式、变率）中的哪一个，以及为什么答案决定辩论是由观测、还是由下一个十年的观测来定论。
::: solution
这是一个**模式散布**问题（系综的中心响应有偏低偏差吗），被一个**变率**信号（2023–24年ENSO-火山-内部的对齐）与一个**情景**事实（排放超出了历史假设输入）污染——三个项在2020年代朝同一方向移动，这就是辩论活跃的原因；该领域的化解路径是经典的那条：更多的年份数据（变率项衰减）、更好的气溶胶与云约束（模式项收窄）、以及排放账簿（情景项是我们选择什么就是什么）。诚实的预测立场：把每个评估范围的上半区当作规划默认，因为弄错的成本不对称。
:::
:::

::: example 涌现约束方法：模式散布如何变成一次测量 {#example-emergent}
平衡气候敏感度无法直接测量——没有实验把CO₂翻倍再等一千年——所以2010年代领域为它建造了代理：**涌现约束**把一个可观测的*当前气候*统计量与一个模式在整个系综中的未来敏感度联系起来，然后用该统计量的观测值收窄预测。典范的成功：**Sherwood等2020**对热带低云敏感度的约束，来自层积云覆盖对海温季节变化的观测响应（把可能ECS收窄到2.6–3.9 °C并*排除*4.5+ °C的CMIP6离群值）、**Wood等2014**南大洋云反照率/季节循环约束、**Caldwell–Bretherton**对流层上层水汽谱系、以及型效应/"敏感度不是你以为的那个反馈"学派的小心结论（Boers–Stevens与Forster–Storelvbo分析显示观测的*变暖型*——大西洋-太平洋趋势对比——若把该型当作受迫的就会让基于历史的敏感度估计偏低）。该方法的失败模式本身就是一门研究生课：回归必须*因果*、不只是跨模式相关（一个模式的敏感度与其可观测统计量可能共变，因为两者被同一个参数化bug驱动——Atwood–Allen与Sherwood–Huber有效性检验所巡查的"伪约束"问题），系综必须跨越真实物理范围（来自排除了真实物理的30成员系综的约束是一个精确的错误答案），而观测必须无偏（卫星云记录的同质化战争在此全力适用）。对读预测的普遍教训：涌现约束是一次*假设检验过的收窄*，而评估报告只有在物理机制被独立于回归理解时才接受它们——这就是AR6的ECS范围把约束与古气候和仪器线索并列引用、而不是取代它们的原因。
::: solution
认识论：涌现约束通过押注一个*跨模式*的关系反映*世界上*一个真实物理机制，把模式散布变成一次观测推断——机制被独立解释时（云-环流耦合、夹卷混合）押注兑现、不被解释时静悄悄失败，这就是该领域的约束验证论文（Schneider–O'Gorman与Caldwell–McCoy有效性框架）如今在评估报告引用约束之前先对留出的模式与历史记录检验它们的原因。
:::
:::

## 读范围：统计、降尺度、与诚实的不确定性

::: definition 不确定性分解与型缩放：如何读一个预测 {#def-reading}
一个预测范围是关于*三个*分布的陈述，而专业文献让它们保持分开。**情景不确定性**（排放选择）随时间增长、在约30年之外占主导；**模式不确定性**（响应——敏感度、云、碳循环反馈）在世纪中叶占主导；**内部变率**在10–20年、以及任何时距的区域变量上占主导（这就是为什么20年区域降水"预测"更接近*风险*陈述而非轨迹陈述——中纬度降水的"可预报性时距"在年代际尺度上实际上为零，影响文献说出这一点的次数远低于公众听到的）。分解从系综方差计算（Hawkins–Sutton方差分数法、AR6"不确定性层级"图），而其政策翻译是"气候服务"学派坚持的**决策相关框架**：不是"2.1 °C"而是"你的适应选择必须在其中保持稳健的结果范围"（Lempert–Dessai为水务与海岸防御开发的稳健决策与"深度不确定性"方法，与灾害课程风险三角一课同一逻辑）。**型缩放**是把全球数字变成区域数字的主力：每个模式的*响应型*（区域对全球变暖之比——北极2–4倍、大陆1.4–1.6倍、北大西洋"变暖坑"0.6倍、热带海洋约1.0倍）乘以全球预测，给出AR6的区域陈述（"陆地变暖约全球1.6倍；2081–2100北极表面年均约全球2–3.5倍，高置信度"）与极端的"三次缩放"精化（最热日每度变暖超过均值）。**降尺度**填补最后的尺度缺口：**动力**（区域气候模式——CORDEX计划约25 km与12 km的欧洲/非洲/美洲系综，嵌套在GCM边界中，增加中尺度真实感：地中海夏季变干、阿尔卑斯与安第斯的地形信号、西非季风降水的敏感度）与**统计/经验**（偏差校正与分位数映射、回归降尺度——便宜、无处不在、且容易出2010年代偏差校正战争记录的"方差变化"假象），而诚实判词是降尺度*增加型与极端的真实感、但不增加独立信息*——在有偏差的母体内部运行的区域模式继承偏差，这就是CORDEX系综作为条件于其母体的范围呈现的原因。最后的解释规则——每个评估章节都写明、每个头条都忽略的那条——是**范围不是栅栏**：评估的"可能"区间是关于*中心估计*的66–90%陈述，尾部在物理上有人（AR6列为其显式深度不确定性集合的低概率高影响的"冰盖、永久冻土、AMOC"告诫），而概率陈述本身建立在成员*不是*物理的独立样本的系综之上（"模式加权"与"独立性"文献——Knutti–Nichols与Sandstad有效样本量分析显示40模式系综携带约10–15个独立估计的信息量，这就是评估报告增加成员时加宽而不是收窄范围的原因）。
:::

::: definition 水、冰与碳循环的预测：模式能与不能说什么 {#def-proj-water}
预测置信层级跟随物理：**温度**（高置信度、紧范围）、**大尺度降水型**（对*符号型*高置信度——湿者更湿/季节位移/副热带变干结构，AR6陈述地中海与北美西南部夏季变干"可能"、西非季风降水在西非本身"可能"增加）、**区域降水量**（低置信度——热带与季风内部的"模式在符号上分歧"地图）、**冰冻圈**（海冰：9月减少高置信度、无冰9月世纪中叶范围；格陵兰与南极：*低置信度尾部*问题——冰盖贡献由海洋冰盖不稳定性与崖壁破坏的过程理解定界，这就是AR6的2100海平面范围顶部比单靠模式产出的更宽、在海平面一课覆盖的原因）、以及**碳循环反馈**（陆地汇减弱方向上"可能"、量级无约束；永久冻土碳-气候反馈——更深文献范围下AR6评估高排放到2100年永久冻土CO₂+CH₄合计约5–55 GtCO₂/年，被排除在碳预算之外并被标记为最大的*未量化风险*项）。**季风与环流**预测带着该领域公开教的悖论：南亚与东亚季风*热力学上*变暖变湿而*环流*分量减弱（"变暖但减弱"的印度季风文献，AR6"印度夏季季风降水可能增加"的判词立足于热力学项），而大西洋翻转流在100%的模拟中减弱（AMOC"本世纪可能减弱"加上"2100年前崩溃极不可能"——由2023年Ditlevsen–Ditlevsen早期预警统计警报与哥本哈根学派2025年重新评估校准的语言，临界点一课覆盖）。**极端**预测从分布加型缩放推出（陆上最多雨5日强度以接近克劳修斯-克拉珀龙约7%/°C增强，高置信度；热极端频率非线性缩放——"3 °C世界"陆上夏季均值+5 °C；火灾易发的地中海、加州、澳大利亚与亚马逊的复合热旱与火险天增加"可能"），而**碳预算-气候相互作用**闭环：每个情景的CO₂路径都嵌着一个碳循环模型的汇预测，而汇在变暖下减弱（"碳循环-气候反馈"，ESM反馈文献中它给高排放路径加上的约+0.3–0.8 °C额外变暖）意味着情景*不如*扇形图暗示的那样自洽——评估报告如今显式携带的二阶项。
:::

::: example 海平面低端之争：共同体如何重画一个范围 {#example-slr-range}
2014–15年海平面预测论文的序列是该领域不确定性治理最干净的案例研究。AR5（2013）的2100范围——各情景0.28–0.98 m——由过程模型与验潮站验证的半经验关系建造；随后Kopp等（2014）与Bamber等（2016）从古气候约束（上新世与末次间冰期的6–9 m海平面，以及冰消期融水脉冲记录）论证冰盖模型的结构不确定性延伸得高得多——"1–2.5 m可信，低概率高影响"——以及2019年SROCC与2021–22年AR6的过程：评估*加宽了*低可能性上界（AR6的SSP5-8.5"低可能性"附加：到2100年在可能范围之上再加约1 m、到2300年约7 m），明确是因为冰盖小组的结构不确定性（Thwaites与毛德皇后地崖壁的海洋冰盖不稳定性、2023年DeConto–Pollard-de Vries与de Vries两篇论文关于南极高原崖壁破坏项是否属于模型的争论）无法靠运行更多模式成员来采样。这个教训推广到每个"模式没覆盖它"的问题——AMOC尾部、永久冻土尾部、亚马逊转变：评估报告的概率语言（"可能""很高置信度""低置信度但可信"）是把"我们能计算一个分布"与"我们能为过程定界"分开的*刻意*工具，而2023–25年"2100年海平面：验潮站系综说0.6 m、冰机制研究表明2 m"的媒体战争是一场关于对*前所未有*的强迫该信任哪种认知工具的争论——一个没有纯科学答案的问题，这就是海岸工程标准（荷兰与英国"基于自然的解决方案加情景加余量"实践、美国ACE的"物理信息上界"指南）如今对世纪尺度资产按*上界可信*而非*可能*范围设计的原因。
::: solution
认识论：模式系综采样*结构内*不确定性；古气候与机理论证采样*结构*不确定性；当强迫超出记录（如现在，处处如此），结构不确定性占主导，诚实的范围必须靠判断加宽——"专家征询"方法（Sheffield–Lewis海平面与STC/UKCIP深度不确定性应用）2010年代的复兴是该领域承认某些21世纪问题超出了系综的成长。对每个范围读者的预测一课：先问是什么采样了它——成员、模式、情景、还是专家——再决定数字意味着什么。
:::
:::

::: history 从Manabe的柱到百亿亿次海洋：预测机器的六十年 {#history-projections}
第一批定量气候预测是**一维辐射-对流模式**：Manabe与Wetherald 1967年的模式（固定相对湿度、对流调整）产出的翻倍2.9 °C至今仍在现代范围内，而1970年代混沌革命（Lorenz 1963的决定论问题、Leith与Epstein的随机动力学框架、Thompson与Schneider 1979年GCM"气候可预报性"极限）确立了预测*为什么*必须是概率的。**耦合时代**始于地球物理流体动力学实验室的耦合海洋-大气模式（Manabe与Bryan 1969年的静止海洋原型、哈莱中心、GFDL与Bjerknes中心的1990年代耦合模式），**情景时代**始于IPCC 1990年的IS92组与1992年UNFCCC的"危险人为干扰"授权，而**相互比较时代**始于AMIP（1989）与CMIP（1995）协议——让模式*比较*（不是模式倡导）成为该领域证据标准的社会学革命。**碳循环时代**（1990–2000年代：哈莱中心HadGEM与CNRM/CSIRO谱系的耦合气候-碳循环模式、AR4 2007年"碳循环放大变暖"的判词）把模式从物理模拟器变成地球系统模拟器，而**CMIP5/CMIP6时代**（2010、2014–）增加了古气候（PMIP）、冰盖（ISOMIP/MISMIP）、排放驱动（C4MIP）与年代际预报（DCPP）子协议——一套协调的实验结构喂养三个评估传统（AR5 2013年"2100年可能1.5–4 °C"、AR6的情景扇表、以及1.5 °C特别报告的90多个路径分析）。**机器学习前沿**（2020–）：让百万成员不确定性采样成为例行的仿真器（简单气候模型的高斯过程与深度学习代理）、试运行中的ML参数化（Gentine–Schneider学派的神经网络对流、2023–25年"气候模式2.0"关于学习到的物理是否保存构成该学科的守恒律的辩论）、以及人工智能天气模式（GraphCast、Pangu与NeuralGCM一代——2024–25年发现ML天气模式在预报技巧上击败数值模式、而其*气候*行为是未决问题）——六十年争论的最新篇章：气候问题是靠把方程解得更细、采样得更宽、还是学得更便宜来攻克最好，而迄今诚实的答案是"三样都要，而预测在尾部仍然分歧"。
:::

对20年中纬度区域降水平均预测，主导的不确定性来源是：
- [ ] 排放情景
- [x] 内部变率，模式散布紧随其后——在这个时距上情景项几乎无关
- [ ] 只有降尺度方法

## 练习

::: exercise {level=1 check="3.7"}
用标准对数表达式ΔF = 5.35 × ln(C/C₀) W/m²计算CO₂翻倍的辐射强迫。
::: solution
5.35 × ln 2 = 5.35 × 0.693 = 3.71 W/m²——每个气候计算从它出发，也是"CO₂强迫是对数的、变暖不是零"的原因：每次翻倍加上同样的约3.7 W/m²，而反馈参数λ ≈ 1 W/m²/K时无反馈响应约3.7 °C，约3 °C的ECS（反馈因子约0.8）就是相对于它的参照。
:::
:::

::: exercise {level=1 check="3.7"}
在反馈参数λ = 1.0 W/m²/K下，计算CO₂翻倍的ECS。
::: solution
ΔT = ΔF/λ = 3.7/1.0 = 3.7 °C——无反馈值；评估的约3 °C ECS意味着λ ≈ 1.2（或反馈因子f ≈ 0.78），而AR6的2.5–4.0 °C范围在物理上是λ约0.9–1.5的范围——整场敏感度辩论压缩进一个数字的不确定性。
:::
:::

::: exercise {level=1 check="3.36"}
AR6的型陈述给出陆地变暖约全球平均的1.6倍。对2081–2100全球变暖2.1 °C（SSP2-4.5中心），评估的陆地表面变暖是多少？
::: solution
1.6 × 2.1 = 3.36 °C（陆上）——让"1.5/2 °C"对所有住在离海远的内陆之人感觉像"3+ °C"的数字，也是"远低于2 °C"目标在中纬度居住大陆上对夏季均值是约3 °C目标、对最热日是约4–5 °C目标的原因。
:::
:::

::: exercise {level=2 check="1.7"}
一个不确定性分解发现2080年代全球变暖的方差分数为情景65%、模式25%、内部10%。如果一项政策研究用单一情景与20个模式，相对完整的情景×模式×变率设计，它把总标准差低估了多少倍？
::: solution
完整σ² = 1.0；研究的σ² = 0.35（模式+变率）→ σ之比 = √0.35 = 0.59，即它把σ低估1/0.59 ≈ 1.7倍——标准的"单情景研究把范围砍掉三分之一"结果，也是评估报告运行完整的情景×模式×成员立方并报告扇形的原因。
:::
:::

::: exercise {level=2 check="6.3"}
型缩放：模式中2081–2100 SSP2-4.5中心（2.1 °C）下北极以全球平均3倍变暖。计算北极变暖，并说出该因子背后的两个物理放大器。
::: solution
3 × 2.1 = 6.3 °C——由(1) **直减率/普朗克项**驱动：表面能量收支被季节冰-反照率与逆温结构支配的区域里的表面放大变暖，以及(2) **冰-反照率与雪季反馈的放大**加上向北的海洋与大气热输送（"北极放大"归因文献的分解；1979年以来观测的约3–4倍位于模式历史范围的顶端，"北极比预测升得更快吗"问题在2020年代卫星时代再分析中不断被回答为"大致在范围顶端、不是超出"）。
:::
:::

::: exercise {level=2 check="7"}
陆上每度变暖下最多雨5日强度按多少百分比缩放（AR6高置信度的克劳修斯-克拉珀龙缩放）？
::: solution
约7%/°C——陆上极端日降水观测与模拟的缩放，给2 °C世界约+14%；让区域预测变难的告诫是*频率*项（风暴路径、对流组织、季风时机）是动力学的且不确定的，而*强度*项是热力学的且稳健——整个预测文献中"我们知道什么"对"我们不知道什么"最干净的例子。
:::
:::

::: exercise {level=3 check="0.26"}
Knutti–Sandstad有效样本量分析发现40成员系综携带约12个独立模式的信息。如果系综的ECS标准差是0.9 °C，系综均值的标准误是多少，为什么朴素的σ/√40会误导？
::: solution
σ_eff = 0.9/√12 = 0.26 °C，对比朴素的0.9/√40 = 0.14——系综均值的真实不确定性约是朴素值的2倍，因为成员共享参数化、代码与设计者（"模式谱系"问题）；评估报告靠加宽范围与加权方案（独立气候敏感度与"等权后筛选"之辩）处理这一点，而2020年代"系综不是概率分布"文献是每个预测头条都该携带的统计脚注。
:::
:::

::: exercise {level=3 check="2.7"}
一个沿海公用事业公司比较AR6 SSP2-4.5可能海平面中心估计（到2100年约0.55 m）与冰盖信息上界可信值（约1.5 m）。计算上界对中心估计之比，并说出在失败不可逆时稳健决策框架按哪个数字设计。
::: solution
1.5/0.55 = 2.7——而稳健决策答案是上界可信值（或更好，一条在整个范围内稳健的分阶段适应路径），因为期望值分析需要对尾部有可靠的概率，而这个尾部是*结构性*的——不受模式系综定界（上面的海平面范围示例）。"避开无界的、保持选项开放"逻辑（Lempert–Dessai与Hallegatte选项评估方法、荷兰三角洲委员会的实践）是深度不确定性的决策科学答案。
:::
:::

::: exercise {level=3 check="0.15"}
AR6近期锁定：2021–40预测变暖在所有情景中约1.5 °C，而如果今天停止排放的"当前承诺变暖"平台评估为约1.35 °C。计算差值，并解释它代表什么。
::: solution
1.5 − 1.35 = 0.15 °C——即使在温和情景下，*来自未来排放*仍在管道中的变暖，超出当前大气已承诺的部分（海洋的缓慢调整与气溶胶清理的再增暖已烤进1.35里）。一个数字里的预测一课：1.5 °C水平不再是未来目标而是带约0.1–0.2 °C余量的现在承诺，而其上每十分之一度都是纯粹的排放问题。
:::

::: quiz
对AR6"SSP2-4.5下2081–2100可能1.8–2.5 °C"范围的正确解读是：
- [ ] 在这个情景下世界将变暖1.8到2.5 °C之间
- [x] 如果SSP2-4.5排放发生，评估的中心响应有约66–90%概率落在该区间内，其外是在物理上有人、被明确标记的结果
- [ ] 90%的模式精确预测这个
- [ ] 范围是一次测量误差棒
::: solution
**中心估计的概率读法**："可能"是IPCC为66–90%校准的词，范围覆盖*情景*中心响应周围的模式散布与变率，而尾部（更高敏感度、冰盖过程、碳循环意外）在同一章别处被明确标记——AR6不确定性指南章节（2022年"如何读范围"附录）正是为强制这种读法而写的。

::: summary
- 预测是有条件的：SSP-RCP情景架构把人类选择（约30年之外占主导的不确定性——评估路径间到2080年代1.4到4.6 °C）与物理响应分开，而近期（2020–30年代的约1.5 °C）在所有路径中已锁定。
- CMIP系综是该领域的实验室：ECS由三条汇聚线索评估为2.5–4.0 °C，模式技巧在指纹、暂停与季节循环上被演示，而系综自己的尾部被公开审计（CMIP6敏感度离群事件、有效样本量校正）。
- 把每个范围读成三个分布——情景、模式、变率——变率项在10–20年与任何时距的区域降水上占主导；型缩放与降尺度增加分辨率、不增加信息。
- 置信层级是显式的：温度高，降水型高而量低，冰盖与碳循环反馈由过程判断而非系综定界——"低可能性、高影响"语言是对前所未有强迫的诚实工具。
- 前沿（风暴解析模式、仿真器、学习到的物理、年代际预报）正让机器更精细更便宜，但结构不确定性尾部——冰盖、AMOC、永久冻土、亚马逊——仍是判断问题，这就是决策科学（稳健策略、选项评估、上界可信设计）如今是预测管道本身一部分的原因。
:::
