均值是头条；尾部才是损害。人类健康、电网、河流、作物与保险损失响应的是气候分布的*边缘*——最热午后、最大湿日、最长干段——而那些边缘与中间移动得不同。分布均值的小小移动能把其远尾的概率成倍放大许多，因为尾概率是距均值距离的指数函数：暖1 °C的夏天是关于均值的一个温和事实、关于五十年一遇之周的一个革命性事实。本课围绕四个置信层级组织：高温极端记录强、以高置信度归因于人类；强降水记录强但其归因较薄；干旱记录货真价实地混杂；热带气旋记录最有争议，因为其长期数据最短也最不均一。把这些层级分清楚，就是理解极端与收集极端之间的区别。

## 分布的尾部：统计、物理与高温记录

::: definition 什么算极端：尾部、指标与重现期 {#def-tails}
极端是*特定变量、地点与季节*的尾部，从不是绝对的：35 °C在赫尔辛基是破纪录、在科威特平淡无奇，统计是在本地构建的。业务词汇是ETCCDI指标集——在世界气象组织专家组下开发的27个指标、在每个国家的气候服务中以完全相同的方式计算——它们概括尾部而非均值：TXx（年度最热日）、TNx（最暖夜）、TX90p（热日频率、超过本地基线第90百分位的天数分数）、CDD（最长干段）、RX5day（最大5日总量）、R95p（最湿5%天数的降水份额）。指标解决了一个问题——每个国家定义"热"都不同——又制造了另一个：百分位阈值在*固定基线期*上计算，所以变暖之下即使尾部的*形状*未变TX90p也会上升——"极端"指标悄悄编码了其检测的趋势（相对对绝对阈值之争，靠两者都报告解决）。极值理论是第二个框架：年极大值拟合一个参数决定尾部下降多快的广义极值分布。**重现期**由此而来：平均每$T$年超出一次的事件年超出概率为$1/T$，所以"百年一遇洪水"每年有1%的机会、并有一个世纪内至少出现一次的大约63%的机会——这里代价最大的误读。决定性的统计事实——在气候统计一章（[[climate-system/climate-statistics]]）中发展、被其后每项归因研究使用——是**移动分布逻辑**：如果整个夏季温度分布以未变的展布右移$\Delta\mu$，超出固定远尾阈值的概率增长约$\exp(z\Delta\mu/\sigma - \Delta\mu^2/2\sigma^2)$倍，其中$z$是阈值的原始标准分——对一个五十年一遇的夏季周（$z \approx 2.3$）与3 °C的展布，1.5 °C的移动把其概率乘约四倍。真实分布是否也*变宽*不重要到评估报告结论的程度：Hansen与Sato 2012年对2010年俄罗斯与2011年得州事件的分析、以及AR5的判词，都发现陆上温度的尾部变化由分布*移动*主导——高温极端预测比干旱预测更自信的原因。

:::

::: definition 观测到的高温极端：地表记录显示了什么 {#def-heat-record}
评估的图景（AR5第二工作组第2章与极端事件AR1特别报告；AR6第二工作组第11章）一句话：自1950年代以来热极端在大多数区域增加（高置信度），冷极端减少（几乎确定），而两个变化都是人类造成的（全球尺度温度极端的高置信度）。细节承载着课。在陆上，热的白天极端暖得比均值*更快*一些——AR6评估高置信度：大多数陆域的热极端以全球平均速率约1.2–1.5倍增强——而*最冷*的夜是所有量里暖得最快的，著名的昼夜不对称（最低温比最高温暖得快，其本身就是温室指纹，因为云与湿度压制夜间冷却，在归因一课[[climate-change/attribution]]中讲过）。热浪——相对本地基线的连续热日——在大多数陆域变得更频繁、更长、更强，有文献的最强增加在欧洲、北美东部、东亚与澳大利亚；Fischer及同事2021年"2040热浪"研究发现工业化前约半个世纪来一次的2003型高温在+2 °C时约频繁5倍、在+4 °C时约14倍。三个告诫管束着记录。冷极端在*减少*于所有地方，但"消失的极地涡旋"之争已被评估报告解决：严寒事件仍会发生，其频率随变暖下降，而其归因发现自然变率主导——美国1990年代以来高温对低温纪录约2:1的比例是阅读任何"冬天还在"论点的统计学正确方式。城市化混淆单个站，但均一化审计——Hansen与Wu 2012年GHCN审计与Karl及同事2010年READERs迁站实验——发现全球陆地趋势的城市污染可忽略（远低于0.01 °C/十年），因为变暖信号宽而热岛窄。而变暖比全球快二到四倍的北极失去冷极端最快，其*热*极端按绝对值仍温和——2020年西伯利亚Verkhoyansk的38 °C早于2021年热穹一年并共享其阻塞驱动。
:::

::: definition 热浪物理：阻塞、土壤湿度与湿球极限 {#def-heat-physics}
三个机制叠加造一场热浪，而其交互正是极端跑赢均值的原因。**动力学先行**：持续的反气旋"阻塞"——准静止的高压系统，空气下沉、压缩、无云——搭好舞台；Pfahl与Wernli 2012年的发现——欧洲热浪在阻塞型下比合成夏季约可能六倍——量化了扳机，而变暖是否让阻塞更频繁仍未解决（评估报告的判词：对任何阻塞频率趋势都是低置信度）。**陆面反馈放大**：土壤一旦变干，地表能量平衡翻转——有水分时，大部分入射能量蒸发水（潜热冷却）；当土壤上层几米空了，同样的能量改暖空气，热浪自食其果。Dugma及同事2011年的分析显示2010年俄罗斯热浪4月——热之前——的土壤湿度已处于数个世纪尺度的亏缺，而"土壤湿度记忆"机制——一个干春预载一个炎夏——如今支撑着业务化的季节热预报；同一机制解释为什么最热的日子坐在干异常土壤的下风向（Seneviratne及同事2010年的综合）。**平流收尾**：来自暖源区的异常气流（撒哈拉空气进欧洲、沙漠空气进大平原）一天加上几度。**城市热岛**让城市夜里也热——致命的细节，因为多数热死亡发生在身体夜里无法恢复时：2021年温哥华的死亡名单压倒性地是室内死亡，在一个几乎没有家用空调的城市经历了三天夜间19 °C以上的地板。最后是生物界限：人类体温调节靠蒸发汗液，所以相关的极端是**湿球温度**——湿表面在通风下达到的温度——而Sherwood与Huber 2010年PNAS分析论证持续远超35 °C的值（在皮肤温度与满湿度下，蒸发停止）超出我们物种的生理范围，即使年轻人静处荫凉。Raymond及同事2020年的调查发现31 °C以上的湿球值自1979年以来频率大约翻倍，波斯湾与印度河谷有报告的短暂冲到35 °C——尽管再分析伪影（2023年的重新评估）意味着可存活阈值*尚未*被可信地按持续时间越过，只是接近。+2 °C下热带大部分户外劳动季变得吃力的预测，让热成为全球南方经济上后果最重的极端。
:::

::: example 2003年欧洲热浪：极端事件归因的诞生 {#example-2003}
2003年夏天打破了当时所有大陆纪录：法国8月最高超过44 °C，九国超额死亡达到约70,000人（Robine及同事2007年*Lancet*审计——仅法国约15,000，多数是城市里75岁以上的人）。两年后Stott及同事发表了创造本课子领域的论文：使用当时新的检测与归因模型相互比较计划的多模型系综，他们把观测的法国夏季最高温分布与数千年的模型工业化前气候比较，发现2003级的温度极端在有人为温室气体的世界里比在没有它的世界里*至少可能两倍*——一个同时以模型与计算概率所用的模型年为条件的陈述，也是故意保守的，因为模型模拟的热浪变率可能超过真实大气的。研究的方法——比较观测事件在现实与反事实气候下的概率、报告比值——成为其后每个归因陈述的模板。Croisière及同事2019年的重新解读锐化了物理：当热浪按*温度本身*定义时，2003风险比升到约3.4，但按*土壤湿度*定义（陆面反馈路径）时，人为信号较弱、事件的稀有部分源于自然的春季变干——同一事件，两个可辩护的数字，因为"2003热浪"不是单个物理量。
::: solution
2003案例是本课的罗塞塔石碑：它确立了(i)方法（模型系综的现实对反事实概率比）、(ii)置信语言（校准过的"至少翻倍"，设计成主张能在模型不确定性下存活）、以及(iii)定义告诫（热浪是一个选定的指标，而不同的指标——气温、土壤湿度、体感温度——归因不同，因为其因果路径不同）。它催生的超额死亡记账就是热被评估为欧洲与北美最致命天气相关灾害的原因，也是2003事件触发全大陆高温行动计划的原因——2015与2019年欧洲热浪强度相当或更高，每度的死亡只是零头，本课关于脆弱性是一个变量而非常数的最清楚证据。
:::
:::

::: example 2021年太平洋西北热穹："不可能"的数字 {#example-heat-dome}
2021年6月底，一个准静止的反气旋"热穹"停在太平洋西北与不列颠哥伦比亚上空，让波特兰到46.7 °C、Fraser峡谷上游250公里的Lytton镇到49.6 °C——比前加拿大纪录高4.6 °C，一个按影响规划所用分辨率运行的区域气候模型在其历史气候中基本不可达的破纪录幅度。人员代价是加拿大和平时期灾害史无前例的：省验尸官五天内记录了619例热相关死亡，多数是老年人的室内死亡，而纪录两天后点燃、烧掉Lytton大半的野火就在纪录自己的热中点燃。科学反应定义了2020年代的归因辩论。World Weather Attribution组的快速分析得出结论：没有气候变化这场事件"几乎不可能"——一个由仅自然模型系综中没有任何成员产出可比之物这一事实建成的措辞——而同行评审的处理（Philip及同事2022年*SWEET*研究与Eisele及同事的树轮重建）把幅度放进背景：热穹是合并重建至少50,000年里最极端的6月温度异常，其概率随人为变暖至少增加了150倍。"几乎不可能"的措辞招致了该领域现在公开教授的方法论批评：模型系综不能把*真实*世界中的不可能事件报告成*模型*世界中的不可能，而2023年的重新评估（包括事件土壤湿度预调节的模拟研究）定在了可辩护的陈述——这种幅度的事件在工业化前气候中可能性微乎其微、而现在大约可能200倍，"五百年一遇"的措辞是被引用最多的单一数字。
::: solution
热穹的教训是关于模型局限下的概率语言。系综里的"不可能"意味着"在被采样的模型分布之外"，那是关于模型支撑的陈述、不是关于大气的——与没有GCM模拟六级飓风而六级飓风并非不可能的同一个理由。可辩护的工具是(i)物理：事件的热力学要求（静力稳定度、土壤湿度预调节、并发的"Blob 2.0"海洋热浪）全在变暖推动的方向上；(ii)重建：古气候背景（50,000年树轮）以模型运行做不到的方式界定自然变率；以及(iii)标度：对*幅度*（高于现代常态+5–6 °C）而非*事件*（一场6月热浪并非自然不可能）的归因。2021年的序列——海洋热浪、热穹、火、然后是12月淹没烧毁流域的大气河流——是本课最干净的**级联**事件，而复合事件文献（Zscheischler及同事2022年的综述）之所以存在，是因为单灾种归因低估了这样的链条。
:::
:::

## 边缘上的水：雨、干旱与气旋

如果热极端遵循移动分布逻辑，水极端必须过第二道门：湿度物理——降雨的热力学上限、干旱背后的土壤湿度记忆、热带气旋的海洋能量引擎——各自加上统计本身供不上的约束，各自有自己的置信层级。

::: definition 强降水：Clausius–Clapeyron上限与观测记录 {#def-heavy-rain}
大气的持水能力设定了雨极端的物理包络：在近地面温度下饱和水汽压每度升温上升约6.5–7%（Clausius–Clapeyron关系，在湿度一课[[meteorology/moisture]]推导），而探空与GPS气象学观测证实柱水汽及其极端正以接近该速率上升。观测记录在可测量处与上限相符：Westra及同事2013年*BAMS*综合发现亚日尺度强雨极端以近7%/°C增强，而Myhre及同事2021年的全球更新加上了对洪水重要的结构——每度增强对短的对流事件最大（接近完整CC速率）、对月度总量最小（接近3%/°C），因为即使风暴*强度*增加，风暴*频率*也不必增加。国家记录在数据长的地方毫无歧义：美国国家气候评估记录了1958年以来东北部与中西部最湿1%降水事件增加40%以上，而AR6评估*可能*自1950年代以来强降水在许多陆域增加，归因发现人类影响促成了若干破纪录降雨事件（2021年Ahr河谷洪水被评估强了3–19%；2022年巴基斯坦季风大水——四分之一的国土泡在水里——Link及同事2023年的分析把7月降雨增强最多一半归因于变暖）。三个告诫。热力学项稳健；*动力*项（风暴路径、频率、组织）是模型分歧之处，而归因判词对*某些*区域是高置信度、对其余至多中等。对流变数（风切变、冷池、风暴组织的辐合带）意味着最大的降雨——2011年泰国、2021年郑州、2022年澳大利亚东部——既是热力学必然也是天气学的偶然。而洪水*影响*记录是另一个故事：全球河流洪水损失几乎全部因暴露而上升，而水文站测得的洪水*流量*无全球增加趋势——"更雨但不更洪"的悖论由入渗损失、水库与水文滤波解决（[[hydrology/floods-droughts]]）。
:::

::: definition 干旱：四个定义，一个有争议的趋势 {#def-drought}
干旱是最难处理的极端，因为它没有单一的定义：**气象干旱**（一季的降水亏缺）、**农业干旱**（胁迫作物的土壤湿度亏缺）、**水文干旱**（径流与地下水短缺）与**社会经济干旱**（供应无法满足需求）可以彼此独立发生，而一个丰水年可以跟着一个持续十年的水文干旱，因为含水层回补缓慢（[[hydrology/groundwater-flow]]）。指标相应地繁多（SPI、SPEI、美国干旱监测），而指标的选择决定了"干旱在增加吗？"的答案——评估判词的诚实核心。AR6的立场：基于降水的干旱没有检测到全球相干的增加（全球记录由自然变率主导——ENSO、太平洋与大西洋多年代模态，见[[climate-system/variability]]），*但*蒸散驱动的土壤湿度干旱在地中海、北美西部、南美西南与南部非洲增加了，而人类影响在若干具体案例中被*检测并归因*：Cook及同事2020年*Nature Climate Change*分析发现上科罗拉多流域2000–2021"大干旱"的土壤湿度亏缺是1,200年重建中最干、约一半起因人为——它既是干旱也是变暖，大约各半；2015–16加州干旱的极端热被（Diffenbaugh及同事2015）发现被变暖变得可能许多倍，而其降雨亏缺在自然范围内；开普敦2017–18"零日"被评估为因变暖的温度项约可能三倍，而其降雨短缺平常——"热干旱"格局，一个无需任何降水趋势确认的永久蒸散税。反向砝码也属于记录：萨赫勒1970–80年代的灾难（十多万饥荒死亡）自2000年以来部分*逆转*；2020–23非洲之角五个雨季的失败处于可检测性的边缘（印度洋偶极子驱动它而模型对其未来有分歧）；而澳大利亚的归因发现千年干旱的西南变干稳健地人为、其东南对应部分是自然的。预测遵循物理：土壤湿度干旱随变暖在几乎所有地方加强，降水干旱在副热带与地中海增加（AR6"可能"）、在高纬度减少——本世纪水地理头条的两干旱未来。
:::

::: example 飓风Harvey：归因一个降雨纪录 {#example-harvey}
Harvey于2017年8月25日以四级在得州海岸登陆，然后做了那件比风杀更多美国人的事：它停住了。四天里雨带在同一片海岸平原上旋转，而微弱的引导气流把中心保持在登陆点50公里以内，在休斯顿附近一个监测水文站降下1,539毫米——美国大陆热带气旋单个事件有史记录的最大降雨量。其后的归因分析（Wang及同事与de Bono及同事2018年研究，使用有无人人为强迫的模型系综）把风暴的降雨增加放在约15–40%，中心估计约三分之一——热力学项主导（风暴近旁湿度以近10%/°C上升、对墨西哥湾0.75 °C暖异常略超CC），加上风暴移动变慢的较小贡献。该领域现在随案例教的两个复杂之处。城市信号在当地与温室信号匹敌：Gifford及同事2020年的分析发现休斯顿自己扩张的城市表面在*城市区域上空*贡献的雨约是人为气候信号的又一半，一个"气候变化让Harvey的雨更多"与"休斯顿的增长让Harvey的雨更多"都部分为真的警告。而重现期算术暴露了标签的脆弱：同一场风暴按沿海NOAA图集同时是"五百年一遇"降雨事件、按更新的Atlas-14点频率是"百年一遇"事件、按特定的滞留相似型是三年两遇事件——本课是重现期既是*数据集与定义*的属性也是大气的属性（洪水频率一课[[natural-hazards/floods]]为水文站剖析的同一个非唯一性）。
::: solution
Harvey是极端事件归因*条件*结构的参照案例：热力学分量（单位风暴的降雨）被稳健地增加、高置信度；动力分量（这场风暴为何在此停住）是归因变弱之处，因为阻塞与引导型没有确立的人为趋势（与热浪阻塞同样的低置信度判词）。风暴还锚定了"可归因*损失*"问题：2017年大西洋季节超过3,000亿美元的总额（Harvey、Irma、Maria）由得州与佛罗里达沿海的暴露增长主导，不是任何被检测到的气旋气候学变化——"极端更糟"与"损失更大"之别，适应-资金辩论依赖的区别。
:::
:::

::: example 2010年俄罗斯热浪："稀有性"之争 {#example-russia-2010}
2010年夏天是如何*不*争论极端的教科书案例。莫斯科7月比其日均暖约7 °C，小麦带歉收，泥炭火熏黑了首都，俄罗斯统计记录了七八月间约56,000超额死亡——2010年代欧洲最致命的单一极端。事件被归因时，科学在公众面前分裂。Barston及同事2012年*Nature Climate Change*论文引入了结合幅度与空间范围的"异常性"指数，结论是2010异常并不比其他地方类似规模的自然暖异常更异常——一个被媒体渲染成"科学家：俄罗斯热浪是自然的"的可辩护统计点，而土壤湿度分析（Dugma及同事2011：4月土壤湿度亏缺在千年尺度重建中无前例）与后来的归因研究（发现*热*本身强烈人为）指向另一向。解决——在Räisänen及同事与原作者的交流中做出——是一堂指标课："异常性"把幅度与面积平均，而2010事件巨大但非幅度破纪录，所以合成指标称它平常、而每个单变量统计量称它极端——单变量归因发现7月异常本身的温室贡献很大。事件另一个持久的数据点是*大气*的：2010阻塞与十年中最强的拉尼娜及一个有利于乌拉尔脊的平流层状态并发，所以诚实的陈述是多因：自然变率压上了子弹（阻塞、拉尼娜），变暖扣了扳机（幅度、土壤变干），而脆弱性决定了死亡数字（苏联解体后公共卫生能力的崩溃，一个几十年前做出的政策选择）。
::: solution
2010之争解决了极端领域现在视为已闭的两个问题。第一，"是自然还是人为？"是错误的语法：每个事件都由一切同时造成，唯一可回答的问题是反事实的——没有人为扰动，这种规模的事件会这么可能吗？——这就是归因方法的输出是概率比、从不是唯一原因的判决的原因。第二，"无前例"主张依赖指标并必须说出其指标：2010事件不是记录中最大的面积异常、是一千年里最大的土壤湿度异常、是十年最致命的极端——三个为真的陈述支持三个不同的头条。案例也是气候统计一章[[climate-system/climate-statistics]]"非平稳风险"警告的起源：如果分布在移动，每个基于纪录的频率陈述（每个"百年"标签）都是一个已不存在的气候的描述——工程规范转向以未来情景为条件的设计值的原因。
:::
:::

::: warning 极端事件主张被扭曲的五种方式——被怀疑论者、被头条、也被科学自身的成功
1. **纪录谬误。**"更多高温纪录证明变暖"与"更少高温纪录否证它"都错：纪录是有限样本的*极大值*，其统计量由覆盖与站点增长主导（美国破纪录站数在1930年代达峰）。统计学正确的信号是高温对低温纪录的*比值*（1990年代以来美国本土约2:1偏向高温、二十世纪初近乎持平）、冷纪录的*消失*、以及百分位指标——不是原始计数。
2.**"不可能"的夸大。**快速归因组的媒体语言（"没有气候变化几乎不可能"）意思是"没有仅自然模型成员产出它"，那是关于模型支撑、不是关于大气的陈述。可辩护的形式是一个说出模型系综的概率比——而2023年对"不可能"文体的方法论重新评估是该领域当众自我纠正，那是过程在运转而非失灵。
3. **干旱混淆。**热归因是高置信度；干旱归因不是，因为"干旱"依赖指标而降水变率巨大。把热归因的置信度转嫁给干旱主张（任何方向）都是误读本课围绕组织的置信层级。
4. **事件对气候的偷换。**单场热浪、洪水或气旋在证伪意义上从不是"证据"；证据是分布移动、跨事件累积的归因比值、以及物理一致性。推论两面都砍：一个凉夏或一个无登陆的大西洋季节对变暖的反对不比一个热夏对它的赞成更多——流域尺度的气旋活动在十年尺度内部嘈杂。
5. **归因-脆弱性塌缩。**"气候变化在2003年造成70,000人死亡"与"2021年不列颠哥伦比亚619人"不是可比的陈述：2021事件按每度物理上更极端，而死亡数字之差多数是*脆弱性*——年龄结构、空调、预警系统、住房存量。归因量化致灾移动；死亡率是致灾乘暴露乘脆弱，混淆它们隐藏了适应教训（2003到2015欧洲每度死亡率改善是本课最大的单一成功故事）。
:::

::: history 从沙尘碗档案到法庭：极端事件科学的长世纪 {#history-extremes}
极端的科学研究远早于归因时代。美国气象局1890–1930年代的站网做出了第一个大陆极端记录（而沙尘碗是第一个"是我们干的吗？"之争——"雨随犁来"的乐观派对保护主义者，由1935年《土壤保持法》了结、由2010年代土地利用重新分析重新打开）。极值统计本身一个世纪长——Fisher与Tippett 1928年的渐近、为洪水工程师写的Gumbel 1958年《极值统计》、仍嵌在每个设计暴雨里的1960–70年代平稳性假设——而百分位指标传统随Karl与Knight 1998年美国*最低*温度比最高温升得更快的发现进入主流。现代领域始于2003–2005年的三篇论文：Stott及同事2004年*Nature*欧洲热浪归因（"至少翻倍"论文）、2004年Meehl及同事PCCP"热点"框架、以及让模型-观测格局比较成为例行的2005年Santer及同事*Nature*指纹；2011年国家科学院报告与2012年《公报》"在变暖气候中解释极端事件"专刊（"E3"年度合集，仍在继续）把归因变成了一个带快速响应规程的行业。2010年代将其制度化：2014–15美国国家科学院认可概率事件归因的共识报告、2015年World Weather Attribution（Friederike Otto的开放科学快速组）创立、哥白尼气候变化业务的归因简报、以及2021–23年向*SWEET*系列与复合事件综合（Zscheischler、Ridder及同事2021–22多变量事件框架）的成熟。法庭在同一个十年进入：Rigo及同事2015年对2013–14加州干旱热分量的归因、2021年Neubauer及同事对排放收支法律中双重主张的批评（在德国联邦宪法法院2021气候裁决的辩论中被引用）、以及2023年Luciano及同事*Nature*对苏格兰火灾损失的归因加2023–25年引用归因证据的美国市政诉讼——极端事件概率比第一次承载法律重量，也是本课"定义告诫"段落如今被律师阅读的原因。
:::

::: quiz
某区域夏季温度分布移动+1.5 °C而展布未变。其原五十年一遇暖周的概率：
- [ ] 增加约1.5倍，与移动成比例
- [x] 增加数倍，因为尾概率对均值移动指数响应
- [ ] 保持不变——只有均值变了
- [ ] 无法改变，因为五十年一遇阈值按定义就是五十年值
::: solution
**数倍**：尾概率对以标准差计量的阈值距离是指数，所以一个均值上看不见的小移动把远尾成倍放大——对五十年一遇阈值与3 °C展布，+1.5 °C把概率约乘四。"按定义"陷阱混淆了*固定阈值*（一个温度）与*固定重现期*（一个概率）：变暖之下老的五十年温度复发得频繁得多。
:::

## 练习

::: exercise {level=1 check="14"}
用Clausius–Clapeyron速率7%/°C，大气持水能力在增温2 °C下增加百分之几？
::: solution
2 × 7% = 14%——强降水增强之下的热力学地板：同样动力强度的风暴每度多携带约1%的水。
:::
:::

::: exercise {level=1 check="200"}
一个热阈值以1/200的年概率被超出。其重现期是多少年？
::: solution
重现期是年超出概率的倒数：1/(1/200) = 200年。值得记住的伴生事实：一个两百年一遇事件在50年设计寿命内仍约有22%的机会至少发生一次（1 − (199/200)⁵⁰ ≈ 0.22）——让沿海项目收费不足的"设计寿命对重现期"混淆。
:::
:::

::: exercise {level=1 check="8"}
如果2003级热浪的风险每全球变暖1 °C翻倍，在+3 °C的世界里它可能几倍？
::: solution
每度翻倍是复利：2³ = 8。指数-于-变暖的结构（不是线性）就是1.5对2 °C之别对热浪是约2倍的*频率*之别、尽管温度之别只有三分之一度的原因——每个"零点几度很重要"评估图表背后的算术。
:::
:::

::: exercise {level=2 check="0.9"}
热浪的工业化前概率p₀ = 每年1/1000；当前概率p₁ = 每年1/100。计算可归因风险分数FAR = (p₁ − p₀)/p₁。
::: solution
FAR = (0.01 − 0.001)/0.01 = 0.009/0.01 = 0.9——今天这场热浪风险的90%可归因于人为移动，"这场热浪没有气候变化会可能十倍地小"陈述的精确形式（关于风险的陈述，不是关于单个事件存在与否的）。
:::
:::

::: exercise {level=2 check="3.3"}
归因发现一个原百年一遇的热现在平均每30年复发一次。其频率增加了多少倍？保留一位小数。
::: solution
频率比 = 100/30 = 3.3。同一事实的概率语言：年超出从1%升到3.3%，FAR为0.70——注意两种框架（"频繁3.3倍"、"当前风险的70%可归因"）描述同一个数字，这就是归因新闻稿必须说明用的是哪种的原因。
:::
:::

::: exercise {level=2 check="132.6"}
某站的R95p（最湿5%天数的年总量）在基线期为120 mm。如果它按Clausius–Clapeyron速率7%/°C标度，增温1.5 °C后的值是多少mm？
::: solution
120 × (1 + 0.07 × 1.5) = 120 × 1.105 = 132.6 mm。线性-于-CC的标度是假设不是观测——百分位总量把强度效应（近CC）与可能的频率效应（未知）混合，这就是观测的R95p趋势在世界各站0到10%/°C之间散布的原因。
:::
:::

::: exercise {level=3 check="0.9"}
对练习4的热浪（p₀ = 1/1000，p₁ = 1/100），计算必要性概率PN = (p₁ − p₀)/p₁并解读。
::: solution
PN = (0.01 − 0.001)/0.01 = 0.9——现在发生的*这一风险等级*的事件没有该强迫就不会发生（或不会这么严重）的概率为90%。领域坚持的微妙：PN是关于*事件总体*的陈述，不是关于个体的——"风险的90%"，永远不是"这场风暴的90%"。
:::
:::

::: exercise {level=3 check="0.05"}
复合事件：热浪季节的年概率是0.10，而给定热浪季节并发闪旱的概率是0.50。复合事件在一年的联合概率是多少？
::: solution
联合概率 = 0.10 × 0.50 = 0.05（二十年一遇的复合事件）。复合事件文献的警告：乘积法则假设条件量平稳，而变暖改变*两个*项及其依赖——copula相关性问题（2021年Ridder及同事框架）——所以复合事件预测携带比任一单灾种更宽的不确定性。
:::
:::

::: exercise {level=3 check="800"}
一个400万人的城市在热浪日期的热死亡率为每10万居民每天2人。一场10天热浪造成多少超额死亡？
::: solution
4,000,000/100,000 = 40个十万；40 × 2 × 10 = 800超额死亡。适应的算术：2003到2015欧洲的记录是靠预警系统、避暑中心与电网准备把这个比率每度压低约3–5倍——同一个乘法倒着跑，本课适应开支已被证明的最大回报。
:::

::: quiz
哪个极端事件趋势的观测证据基础*最弱*？
- [ ] 陆上热温度极端
- [ ] 陆上强日降水
- [x] 热带气旋强度的长期趋势
- [ ] 陆上冷极端的减少
::: solution
**热带气旋强度**：卫星时代勉强四十年，卫星前的"最佳路径"按飞机与船舶覆盖变化修正过，而2024年强度趋势论文（Kossin及同事的约15%/°C对受争议的重建）对趋势是否存在都有分歧——本课结构为之而设的第四置信层级，对热冷极端是第一层级、对强雨是第二层级。

::: summary
- 极端是尾部统计：小的均值移动把远尾概率指数放大，所以"均值动了1.2 °C"与"五十年一遇热变成十年一遇"是同一个事实说两遍——而重现期是阈值、定义与数据集的属性，从不是赤裸的自然种类。
- 置信层级就是课：热极端（强增加、归因人类、高置信度）、强降水（在7%/°C湿度上限附近的强增加、归因在成长）、干旱（依赖指标、无全球降水趋势，但土壤湿度"热干旱"日益被归因——科罗拉多大干旱一半人为）、以及热带气旋（四十年干净数据、有争议的趋势、稳健的*降雨*与*风暴潮*物理）。
- 物理解释统计：阻塞搭热浪的舞台、干土放大它；Clausius–Clapeyron把雨封顶在近7%/°C；气旋汲取海洋能量、降雨多约10%/°C，而海平面抬起每一场风暴潮。
- 归因陈述是有条件且依赖定义的：来自模型系综的概率比，对事件如何被指标化（温度对土壤湿度）、"异常"的指标、以及模型自身的支撑敏感——2003、2010与2021案例是把这件事做对的案例研究，而"不可能"文体是做错的。
- 损失不是极端：洪水与气旋损失追踪暴露与脆弱、不追踪气候学，而死亡记录（2003年的70,000对后来热浪每度小得多的数字）证明脆弱性是最快移动的变量——通往[[natural-hazards/risk-reduction]]的桥。
:::
