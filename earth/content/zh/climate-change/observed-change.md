2024年7月13日，全球平均近地面温度——地球上每个气象站、船和浮标的不可思议的平均值——达到了记录基准绝对零度之上15.10 °C、1991–2020年7月平均之上2.19 °C，而仪器记录（也许整个全新世）以来头一回，行星度过了完整十二个月、**高于1850–1900年工业化前基线1.5 °C以上**。12个月数字在当年晚些时候又晃回1.5以下——没人"突破"巴黎阈值，那是以十年计的——但整年，2024年，落在约+1.55 °C，成为做到这一点的第一个日历年，也为2023和2024以远超统计能解释的年际噪声之幅度（约0.15–0.2 °C）连破全球高温纪录的一轮画上了句点。本课就是实际测到了什么的清单，因为此后一切——归因、收支、预测、影响——的可信度都取决于观测基础是否可靠，而这个基础如今有175年长、多平台、由独立团队相互校验，并且在物理预言有信号的每个领域都毫无歧义：表面、海洋（吸收了多余能量的约90%）、冰冻圈、以及大气的成分与能量收支。气候确实变了；这场变化非凡之处在于其*格局*——夜比昼暖得快、北极比全球快四倍、平流层在一切之下变暖的同时变冷、海洋在2,000米深度以内增热——与温室强迫的指纹相符，而与任何被提出的替代解释都不符。

## 温度记录及其审计

::: definition 全球温度记录：构建、均一化，以及数字说了什么 {#def-temperature-records}
没有单一的温度计；有五个对同一套物理的独立分析——HadCRUT5（气象局/东英吉利大学）、Berkeley Earth、NOAA GlobalTemp、NASA GISTEMP v4、以及ECMWF的ERA5再分析——由不同团队用不同数据建成（均一化后约3万个站的大陆网、海洋的船与浮标、而再分析则是喂进天气模型的整个观测系统），而它们在百分之一度的范围内一致于百年尺度的趋势。构建之处就是怀疑死去之处：陆上站用邻站比较就迁站与换仪做**均一化**（产出美国HCRA数据集的方法，其"城市偏差"经检验可忽略——城与乡的站趋势一致，反直觉的结果是城市热岛相对区域信号既小又主要在夜间），而海洋在二十世纪初从**水桶改为引擎进水口**采样——原始引擎数据约0.3 °C的暖阶跃，记录用夜间船气-海温差修正（Kennedy等人与Coward–Rayner方法），其大小与符号被火山冷却的指纹独立确认。头条数字（AR6与2024年气候状况报告）：人为变暖在**2011–2020年达到1850–1900之上1.07 °C**（观测表面变暖1.09 °C，差额是气溶胶与内部变率约0.1–0.2 °C的遮蔽），过去50年的速率是**每十年约0.2 °C**（对多世纪比较至少在过去2,000年无前例——近年速率至少是Common Era重建中任何50年趋势的三倍），而2023、2024和2025年跑在1850–1900之上1.45–1.55 °C，其中2023年的跳升（比2022高约0.2 °C）被归因研究归于Hunga Tonga喷发的平流层水汽（一个小的正强迫）、拉尼娜的结束、以及也许是航运硫酸盐的下降——而诚实的科学回答是精确的分解仍在研究，而*趋势*不依赖于它。**垂直结构**就是指纹：对流层变暖（无线电探空、1979年以来的卫星——在RSS/UAH通道漂移之争由其团队自己的2022–23再分析解决之后，现在显示与地面记录一致的陆地变暖）、**平流层变冷**（20 km处每十年−0.4到−0.6 °C，而"平流层足迹"是排除太阳强迫的单一观测——太阳会暖两层）、以及**夜间最低比日间最高暖得更快**（全球陆上约0.15对约0.11 °C每十年），冷极端下降的速率约为暖极端上升的两倍——温室强迫预言的不对称签名，也是"全球变暖"是对温度分布实际所为的一个误导性名字的原因。
:::

::: definition 海洋：热、碳、氧，以及酸化算术 {#def-ocean-change}
海洋是气候系统的记忆也是它的垃圾场：1850年以来它吸收了**约90%的多余能量**和**约25–30%排放的CO₂**，而每一次吸收都被测量。**海洋热含量**（OHC，温度×热容对深度的总和，由上部700米主导，但如今由Argo浮标网——2000年以来近4,000个剖面浮标——追踪到2,000米）显示Argo时代（0–2,000米）**每年约1.5–2 × 10²² J**稳定加速的增益，相当于约1.3 W/m²的全球能量不平衡——这个数让2000–2014年的"停滞"之争成为定案，因为太平洋风型驱动的表温暂停（PDO/IPO与后来在2014–16年厄尔尼诺中释放的深海热封存）在OHC中*看不见*，而OHC从未暂停。**海表温度**工业时代上升约0.6 °C，海洋热浪频率现在占洋面每年约20–25%、对1980年代的约15–18%（2023–24年北大西洋海洋热浪，数月高于1991–2020夏季均值约1 °C，白化了佛罗里达的珊瑚礁与佛罗里达流的湾流锋），而**大西洋经向翻转环流（AMOC）**——自2004年由26.5°N的RAPID阵列以约17–20 Sv测量——没有崩溃，但与一个世纪的代用与指纹证据（作为AMOC表面签名的北大西洋"变暖坑"）并存，使AR6"本世纪可能无突然崩溃"的判词与其低置信度限定语配成一对。**碳与化学**：表层海水pH从约8.2降到约8.05——**氢离子浓度增加30%**（pH是对数，这是诚实的说法），文石饱和面变浅数百米，季节性腐蚀性水体现在抵达加州流的带壳翼足类和南大洋；**氧**在上部1,000米下降约2%（"氧最小层"向两极和垂直方向扩张数百米，波罗的海与黑海死区是物理的可见末端：每增温1 °C溶解O₂少约4%，而层结阻碍通风）。**盐度格局**——湿者更湿、干者更干，表现为ESCAPade盐度对比指数每十年上升约0.015——是水循环在全球尺度加强，"土壤全球变干趋势"是其复杂的、区域协商的表面表达。
:::

::: example 2023–24年温度尖峰与科学如何审计一个意外 {#example-2024spike}
2023年全球平均表面温度达到1850–1900之上约1.45 °C、2024年约1.55 °C——比2022高0.2 °C，一个约4–5倍于自然年际变率标准差的跳升，触发了正确的科学反应：搜寻原因而不是绕场庆祝。候选解释，每个都有证据：(1) 2020–23年拉尼娜的结束（一个压制了纪录的三峰拉尼娜，其厄尔尼诺继承者加了约0.1–0.2 °C）；(2) 2022年1月的Hunga Tonga喷发，注入了约145 Tg的水——一次不寻常的*水*注入，占平流层负载的4–5%——模型给出的全球平均2–5年增温约0.03–0.06 °C（为正因为水汽是温室气体、不像硫酸盐气溶胶，而喷发自己的硫酸盐太少太低冷不了）；(3) 2020年1月的船用燃料硫酸盐切换（IMO 2020），在航线上揭去了约0.05–0.15 °C的气溶胶冷却，其云反照率微物理响应有充分文献；(4) 南极海冰减少与印度洋变率对基线趋势的可能抬升。这些都不是"抓包"：这个练习的要点是，一旦去掉ENSO与火山项，**趋势线**（1980年以来0.19–0.27 °C/十年）与2023–24只差一根头发，而每个被提出的解释本身就是物理的一个预言（变暖世界的ENSO摆荡骑在更高的基线上；硫酸盐少意味着更暖；平流层水汽增温）。一个快速的、被部分解释的跳升的存在，对巴黎目标"每十年1.5 °C"框架的信心有什么影响？
::: solution
对*物理*没有影响，对*政治*有很大影响：巴黎协定的十年尺度阈值正是为了对这种跳升稳健才定义为20–30年平均，而2023–24尖峰真正的内容是2010年代的碳收支算术（从2020年起1.5 °C的剩余收支约500 GtCO₂）如果说错了什么那是太乐观了——每吨的变暖（每1000 GtCO₂约0.45–0.65 °C，TCRE范围）没有动，所以一个提前烧掉剩余收支一个分数的尖峰是收支事实，不是天气故事。
:::
:::

::: example 两千年温度背景：曲棍球杆之争，已定 {#example-hockeystick}
二十年来"曲棍球杆"——Mann、Bradley & Hughes 1998，第一个用年轮、冰芯、珊瑚和沉积物做的千年北半球温度重建——是科学界被攻击最多的图（2000年Wegman委员会、2009年"气候门"邮件、2005年BBC之争），而它现在是古气候中被独立重跑最多的结果：PAGES2k联盟2019年的重建（700多个代用记录、2,000年、六大洲）用现代方法确认了形状——多代用集成、贝叶斯层次模型、以及代用本身的正演模拟。当前评估的图景（AR6第2章与2019年PAGES2k专刊）：**中世纪气候异常**（约950–1250）**区域上**暖（挪威、北美与中国部分地区）但全球不相干，而**小冰期**（约1300–1850，最糟的世纪是1600–1700，以及1815年Tambora"无夏之年"）是过去两千年的最冷持续时段——两者都能用自然强迫解释（太阳极小、1257年Samalas与其他大喷发），不需要任何人为项。定量判词：记录的最后十年比至少1,000年（可能）到2,000年（北半球高置信）内任何50年时段都暖；20–21世纪变暖的*速率*超出重建中任何多年代变化数倍；而重建的**方差**在多年代尺度小于仪器变率——部分真实（没有化石强迫放大的前工业世界噪声更小），部分代用方法的"低频阻尼"问题，学界用谱调整技术（EMOS、"vt2015"）公开应对——这些技术*增大*而非减小重建的自然范围。本课推广到一切观测：仪器记录短，代用记录噪，而两者在重叠处恰好一致——这是一个被验证的测量系统的定义。
::: solution
重建的现代重跑（PAGES2k 2019、Moberg与Esper学派的不同方法）把原始结果括在其不确定带内，同时对中世纪-小冰期摆幅的幅度仍有分歧——一个领域收敛于稳健结论（20世纪的上翘在窗口内无前例）而仍在争论细节（小冰期多冷、中世纪多暖）的格局。2024年的1.5 °C坐在整个重建范围之上，在2,000年窗口内没有重叠。
:::

## 冰、雪与水循环

::: definition 冰冻圈：测量与比分 {#def-cryosphere-change}
雪和冰是气候最易读的仪器，因为它们的响应是*水平*，不是读数：质量收支把天气积分成几何。**北极海冰**是最极端的案例：9月最小范围自1979年（卫星记录）以来以**每十年约12–13%**下降，从1970年代末的约700万km²到2012年纪录的412万km²、2020年代的约430–530万km²，而**厚度**（潜艇声呐、ICESat、CryoSat）在深盆地从约3.1米降到约1.8米——体积损失约75%——以至于熬过夏季的多年冰如今只是其1980年代面积的一个零头；"无冰的9月"的定义（100万km²）在AR6所有路径上都预测在本世纪中叶，高排放轨道上第一次这样的事件可能出现在2030年代（2020年与2020年代的6–7月西伯利亚热浪、以及2022/2023/2024年的最小值纪录就是进行中的校准）。**南极海冰**打破了相反的格局：在总数近乎持平到略升之后（"南极悖论"，部分因为臭氧洞驱动的风加强把大陆隔离），它在2023和2024年崩落到低于常年150–200万km²的纪录——一次两年的状态转换，其机制（海洋热、Weddell与Ross海区的冰穴活动、可能的可预报性极限）是这一年的开放问题，也是一个提醒：冰-海系统的稳定性在十年尺度上可以是非线性的。**格陵兰**自1998年每年都在失重（GRACE与GRACE-FO重力测量加上测高与输入-输出：**2002–23年约270 Gt/年**，表面融化现在贡献损失的约60%，而Jakobshavn/Sermeq-Kujalleq出口冰川加速后退过了其锚定底床点），**南极洲**约150 Gt/年（集中在阿蒙森海扇区——Thwaites与Pine Island——其暖深层环流水在冰架下的侵入是本世纪的"海洋冰盖不稳定性"问题，2023年国防部资助的"末日冰川"调查不事张扬的发现是底床线自1992年已在Thwaites东支流后退约14公里、而冰架的融化跑在上限）。**山地冰川**在2000–19年每年损失约1.2米水当量厚度（2019和2023年"年度综述"数字），仅2022–23两个融化季欧洲阿尔卑斯就失去剩余体积的约10%（瑞士GLOSH清单2023年调查认定2022–23融化是有记录以来最糟，约阿尔卑斯剩余冰的10%），而**兴都库什-喜马拉雅**约240条补给十条大河的冰川以让"水塔"成为地球上最暴露的淡水储库的速率失重。**雪盖**：北半球春季雪盖范围自1970年以来每十年减少约1.5–2%（每个被调查大陆的季候线每十年上升约1–2米海拔），而美国西部雪库——合计70亿人储水的调节库——自1950年下降约15–20%（Sierra与Cascades 2,000–3,000米的4月1日雪水当量下降部分是*相态*效应：降水越来越多以雨落下并融化，Sierra的"雪线"自1986年上升约70米）。
:::

::: example 阿尔卑斯的两个糟糕夏天 {#example-alps}
瑞士和法国阿尔卑斯在2022和2023两个融化季合计估计损失其剩余冰川冰的约10%：2022年夏（若干站在冬季3,000米无雪、破纪录融化、以及在3,580米的Jungfraujoch站观测到的第一场雨-on-snow事件）之后是2023年夏（按国家冰川监测网初步数字，瑞士阿尔卑斯剩余体积又失约10%，"马特洪峰冰川天堂"滑雪区的多年冻土退化到通道被迫迁离冰面）。物理是一个三级放大器：(1) 冬季雪线在许多海拔升到了积累区之上，于是吸收夏季阳光约60%而非反射约80%的裸冰更早暴露；(2) 粉尘与撒哈拉吹越的变暗进一步压低反照率；(3) 岩坡多年冻土——高阿尔卑斯地形的水泥——在瑞士PERMOS钻孔（Murtèl、Scex Rouge）2008–23年升温约0.5–1 °C，驱动着向导公司如今当作经营指标追踪的落石与封路新闻。量化反照率项：在这些纬度的六月，裸冰比雪多吸收约350 W/m²的净短波；在一个100天的融化季，这足以融化大约多少米冰（潜热334 kJ/kg、冰密度900 kg/m³）？
::: solution
350 W/m² × 100天 × 86,400秒/天 = 3.0×10⁹ J/m²；÷（334,000 J/kg × 900 kg/m³）= 10米冰——这就是雪线升高300米（1970年代以来观测到的欧洲位移）为何转化为冰川每年数米的变薄，也是为什么高山"依赖海拔的变暖"是观测中对全球信号最清楚的放大之一。
:::
:::

::: definition 水循环、云与能量收支：没人谈论的测量 {#def-energy-water-change}
本课最根本的观测是记录最短的那个：地球的**能量不平衡**——大气顶吸收的太阳与发射的红外之差——由CERES辐射计自2001年测量为**约0.8–1.4 W/m²**（这个数字随气溶胶帷幔变薄、温室毯子变厚而上升），与海洋热含量收支交叉校验（两者在误差棒内一致，是气候科学最強的相容性检验）与深海增暖速率。水循环以两种速度响应：热力学上，Clausius–Clapeyron关系固定近地面每增温1 °C**约7%的水汽**，观测证实了它——总柱水汽上升约0.4–0.5 mm/年（1970年以来增加约4%，卫星与GPS掩星网），可降水与极端降水强度一起上升；动力学上，风暴路径每十年向极地移动约0.5–1°纬度（AR6对副热带变干的"高置信"判词——地中海、美国西南、Murray–Darling与南部非洲2019–24结束于2024年印度洋偶极子之雨的多十年"枯年连击"）。**云**仍是整个学科最大的不确定性——也是最大的*被观测到的*含糊：ISCCP、CALIPSO-CLOUDSAT（2006–）与MODIS记录显示区域上相干的变化（风暴路径云的极地移动、可能的热带砧状云与低海云调整），但没有全球云反馈数字的共识，这就是为什么AR6的ECS范围（最佳估计3.3 °C，可能2.5–4）相对AR5的收窄主要靠用涌现约束与过程研究*排除*极低与极高尾部、而不是直接测量云。**观测到的降水**图景（GPCC、GPCP、ERA5）：全球陆上降水略升（1980年以来强类别每十年约1–2%），最重日事件的*强度*在陆上以接近Clausius–Clapeyron的速率上升（美国东北极端降水份额自1958年上升约30%、欧洲5日极大值每十年上升约0.5–1.5 mm/天），而**干旱与土壤水分**图景区域混杂——"变干的副热带"稳健，2010年代的中纬度陆地变干（2018–22欧洲与2020–23非洲之角干旱）部分归因于动力学位移加上增温无论降雨如何都加上的蒸散需求。
:::

::: example 单个事件的归因：2021年Lytton热穹 {#example-lytton}
2021年6月29日，不列颠哥伦比亚省Lytton村——一个干燥、内陆、易燃、其2015年野火风险研究已经点名的小镇——录得49.6 °C，把加拿大纪录抬高4.6 °C；第二天，同一场干旱驱动的火穿过小镇，烧掉了90%的建筑。World Weather Attribution的快速分析在数周内发表，做出两个如今业界标准的主张：在*工业化前*气候中这场热浪没有气候变化"几乎不可能"发生（对2021年的世界也是极端，其现代气候重现期约300到1,000年一遇），而*变暖信号*——同一场大气动力学在1900年会产出的量之上超出的2–4 °C——可归因于约1.2 °C的全球变暖，而脊的动力学是自然的。让它成为模板事件的方法论要点：单个事件在*两个世界的配对*中归因（反事实气候模拟），动力学"原因"（omega阻塞）保持不归因，而*影响*——毁掉Lytton的火——是复合事件问题（热+旱+燃料），归因科学处理得较差，2023年Lahaina和2023年Derna（利比亚，Daniel风暴，约11,300人死亡）的分析暴露了这个缺口。走一遍什么被主张、什么没有，以及"事件由气候变化造成"与"事件被加剧了2–4 °C"之间的区别为什么是科学结果与新闻标题的区别。
::: solution
归因的是*强度*，不是*发生*：脊自然形成；脊的燃料——一个土壤更干、地表热2–5 °C的大陆（土壤水分反馈在模型实验中贡献Lytton峰值的约1–2 °C）——才是被归因的项。复合链条（热→旱→火→烟→进一步的辐射效应）是单事件归因止步、基于风险的归因（*整条链*的概率如何移动）开始之处——这个领域随2022–24复合事件文献抵达的前沿。
:::
:::

::: history 观测工程：从Tyndall的烧瓶到Argo的浮标 {#history-obs}
测量的故事有四幕。**第一幕——实验室里的物理（1856–1950）**：Eunice Foote 1856年的风箱与阳光实验与John Tyndall 1859年的热电堆与管测量确立了水汽和CO₂吸收地面辐射（而N₂和O₂不吸收），Svante Arrhenius 1896年的手算预言CO₂倍增约5–6 °C（与AR6中心值3 °C相差1.5倍以内——一个著名的误差相互抵消的巧合），而Guy Callendar 1938年的论文汇编了147个站一个世纪的变暖（"Callendar效应"），对抗当时假定的海洋对多余CO₂的吸收。**第二幕——曲线与网络（1958–1990）**：Charles David Keeling为1957–58国际地球物理年启动的冒纳罗亚与南极记录产出了Keeling曲线——1958年315 ppm、生物圈呼吸的锯齿、以及为化石碳按下指纹的¹³C/¹²C下降——而气象业务网、无线电探空档案、和最早的卫星辐射率测量（1969–70年VTPR试验）建起了多平台基础；1979年Charney报告敲定了*理论的*不确定范围（1.5–4.5 °C，1979和2024除尾部外未变），而第一批气候研究计划（NOAA的ERALM、美国CO2计划）把观测制度化为常设承诺。**第三幕——太空与浮标时代（1979–2010）**：卫星记录（1972/79年起的海冰、2002年GRACE重力、2006年CALIPSO/CloudSat、2001年CERES、ICESat CryoSat测高）与**Argo浮标阵**（2000–07年布放，4,000个浮标每10天给海洋做一次剖面，挑战者号以来最伟大的海洋学仪器）把海洋的热与冰盖的质量从外推变成了测量；GRACE-FO续任（2018）与Deep Argo（2024–）延伸了两条记录。**第四幕——审计时代（2010– ）**：地表记录均一化之争（美国HCRA网络的发布、Berkeley Earth 2011–12年用自己的方法确认地表变暖趋势的自查）、卫星温度通道漂移的对账（RSS 2022年修订、UAH团队自己的修正）、海洋热含量相互比较（IPCC章节主持的多团队XBT对Argo时代偏差的对账）、以及2023年尖峰之后的诸次审计——一个其最响亮的争论都是*自找的*、每一次都以原始数字被确认或略微上调告终的领域。
:::

::: quiz
最直接排除"太阳造成了近期变暖"的单一观测事实是：
- [ ] 冒纳罗亚的CO₂在上升
- [x] 平流层在对流层和地表变暖的同时变冷
- [ ] 海平面在上升
- [ ] 破高温纪录的日子多于破低温纪录的日子
::: solution
**变暖的太阳会照亮整根气柱——包括平流层。温室截留暖下冷上**（更少被截留的热从平流层逃向太空，而那里的CO₂增加辐射得比吸收更有效率）。无线电探空、卫星与臭氧探空记录都显示温室强迫预言的平流层冷却（20 km处每十年约0.5 °C），而总太阳辐照度（1978年以来卫星测量）在近期变暖中无上升趋势——指纹论证最干净的形式。
:::

## 练习

::: exercise {level=1 check="90"}
温室增加截留的多余能量中大约百分之几进入了海洋（AR6高置信度给出的数字）？为什么这让"大气是气候发生之地"成为一个误导的框架？
::: solution
约90%：大气在*能量*中微小的一份解释了为什么地表气温是嘈杂、快响应的指标，而海洋巨大的一份设定了承诺变暖与长滞后——90%那项住着惯性、"停滞"的十年、以及海平面上升的大部分。
:::
:::

::: exercise {level=1 check="30"}
大气CO₂从280升到420 ppm。把增幅表示为百分比，并说出它造成的表层海洋pH变化（从8.2起）与相应的氢离子浓度百分比变化。
::: solution
(420−280)/280 = 50%；pH 8.2 → 约8.05，即[H⁺]增加30%（10^0.15 ≈ 1.41——"多30%酸性"的数字；只说pH会低估变化，这就是酸化文献引用[H⁺]的原因）。
:::
:::

::: exercise {level=1 check="38.6"}
北极9月海冰范围从700万km²（1979–83均值）降到430万km²（2024）。计算卫星时代的总下降百分比。
::: solution
(7.0−4.3)/7.0 = 38.6%——对照教科书从完整卫星记录得到的约12–13%每十年*线性*趋势；两个数字用不同的估计量描述同一场损失，这就是为什么AR6把趋势、端点与纪录最小值（412万km²，2012）一起报告。
:::
:::

::: exercise {level=2 check="26"}
地球能量不平衡全球平均约1.0 W/m²。把总不平衡功率表示为太瓦，并计算它相当于文明总一次能源功率（约20 TW）的多少倍。
::: solution
不平衡 = 1.0 W/m² × 5.1×10¹⁴ m² = 5.1×10¹⁴ W = 510 TW；÷ 20 TW = 约26——那个标准的"我们造成的强迫压倒我们的能源系统"比较：行星在吸收二十六个文明份量的额外热，这就是为什么减排关乎*燃料*、而非瓦数。
:::
:::

::: exercise {level=2 check="7"}
近地面每增温1 °C，饱和水汽容量大约增加百分之几（极端降水文献通篇引用的Clausius–Clapeyron速率）？
::: solution
约7%/°C：在288 K处求Clausius–Clapeyron斜率 de_s/dT = L/(R_v T²) 得5,400/288² ≈ 6.5–7 %/K——设定极端降水强度之步调、观测到的大气水汽增加、以及"大气河流"降雨率的数字，也是为什么让人致命的是湿度（不是温度）这个变量。
:::
:::

::: exercise {level=2 check="1.14"}
格陵兰每年失冰约270 Gt、南极洲约150 Gt（GRACE时代）。它们合计贡献多少毫米/年的海当量（1毫米全球海当量 = 367 Gt水）？
::: solution
(270+150)/367 = 1.14 mm/年——约占观测到的约4.5 mm/年总上升的四分之一，其余是海洋热膨胀（约50%）与山地冰川和陆地水（约0.5–1 mm/年）；冰盖是每份海平面预测中带有*期权价值*（两个意义上的）的那一项。
:::
:::

::: exercise {level=3 check="4"}
2023年全球温度跳升比2022高约0.2 °C，而自然年际标准差约0.05 °C。这个跳升是几个sigma？如果1980年以来的趋势是0.22 °C/十年，一个破纪录之年代表几年的趋势？
::: solution
0.2/0.05 = 4σ（平稳分布下约三万年一遇的事件——这正是分布本身已经移动的那个论证）；0.2/0.022 = 一年顶9年的趋势——单年上头条而20年均值才是与巴黎相关的统计量的算术。
:::
:::

::: exercise {level=3 check="0.93"}
Argo测得海洋热含量增益约1.5×10²² J/年（0–2,000米）。把它换算成地球表面积（5.1×10¹⁴ m²）上的W/m²。
::: solution
1.5×10²² J/年 ÷ 3.15×10⁷ 秒/年 = 4.75×10¹⁴ W；÷ 5.1×10¹⁴ m² = 光进入海洋就0.93 W/m²——对照CERES大气顶不平衡的约1.0–1.4 W/m²，约90%的海洋份额用两套独立测量系统（天上的辐射计、海里的浮标）在不确定度内闭合了行星的能量收支，本课对温室诊断最强的单一确认。
:::
:::

::: exercise {level=3 check="12.5"}
如果从2020年起1.5 °C的剩余碳收支约500 GtCO₂（50%概率）而排放以约40 GtCO₂/年进行，收支从2020年起几年耗尽？如果2023–24尖峰约0.1 °C的"超调"部分是永久的，它对收支意味着什么？
::: solution
500/40 = 12.5年——2018年IPCC特别报告的"2032"收支付数，随着2024年排放约41.6 GtCO₂（2024年全球碳收支）已重新定标到2030年代初；如果尖峰的约0.05–0.1 °C持续，收支缩水约0.05/0.45 × 500 ≈ 55–110 GtCO₂（一年或更多的排放）——让每一个暖年都成为一个收支年的算术。
:::

::: quiz
1998–2014年变暖的"停滞"或"暂停"最终主要被什么解释（并作为伪影被退役）？
- [ ] 新站显示旧站有偏差
- [x] 海洋热含量显示没有暂停，加上SST采样修正和太平洋深热封存被2015–16年厄尔尼诺释放
- [ ] 卫星的重新标定
- [ ] 暂停真实但无害
::: solution
**OHC从未暂停**：Argo时代的海洋在表面减速的十年里持续增热（太平洋PDO/IPO相位把热存在深处、很大一部分在南大洋，2015–16年厄尔尼诺释放了其中一部分），而地表记录本身被船对桶偏差修正（Coward–Rayner/Kennedy方法）与HadISST2采样修正上调。这段插曲现在是为什么*多领域*观测基础——而非任何单条温度线——才是评估报告所评估之物的教科书案例。
:::
:::

::: summary
- 表面变暖高于1850–1900约1.07–1.09 °C（AR6），以约0.2 °C/十年上升，2023–24是头两个超过1.45–1.55 °C的年；五个独立记录团队一致，而记录自身的审计（均一化、桶对引擎修正、卫星通道漂移）各自确认或上调了趋势。
- 指纹是有格局的，不是标量：平流层在对流层之下变冷、夜比昼快、冷极端比暖极端上升落得快、北极是全球的3–4倍——温室强迫，不是太阳，也不只是内部变率。
- 海洋装着故事：约90%的多余能量（OHC以约1.5–2×10²² J/年上升，从未"暂停"）、约30%的碳（pH 8.2→8.05，[H⁺]+30%）、更少的氧（上部1,000米−2%）、以及AMOC被监测但未决的稳定性。
- 冰冻圈是可读的账簿：北极9月冰−12–13%/十年、体积−75%，格陵兰约270 Gt/年、南极洲约150 Gt/年且阿蒙森海扇区在观察名单上，山地冰川−1.2米水当量/年而阿尔卑斯两个夏天掉约10%，北半球春季雪−1.5–2%/十年。
- 水循环正以Clausius–Clapeyron的约7%/°C加强（水汽与暴雨强度同升），风暴路径与干旱带在向极地移动；能量不平衡（约1 W/m²，CERES对Argo在误差内闭合）是让整个诊断成为一次一致测量的单一数字。
:::
