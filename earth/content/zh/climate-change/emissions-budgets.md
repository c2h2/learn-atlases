2021年11月2日，就在距两百米外格拉斯哥气候协议的"逐步减少未减排煤电"仍在谈判之际，国际能源署发布了其首席经济学家宣布"在本报告任何情景中都找不到"的东西：2050年净零排放，一张400个里程碑的路线图——IEA这个1974年成立的石油供应安全守护者、全世界最受关注能源预测的出版方——把它呈现为与1.5 °C一致的窄路。文件对谈判厅外所有人都重要的头条数字是：2050净零目标所需技术组合中，**三分之二已经商业示范**——障碍不再是物理甚至不是成本，而是部署与政治。这个区别就是本课的主题，讲的是气候科学的*记账*层：我们排放什么的账目（全部气体合计每年41.6 GtCO₂当量，相当于每秒向大气倾倒1,300吨CO₂）、大气留下了什么的账目（我们历史上排放总量约45%——其余被陆地和海洋以酸化与缺氧为代价吸收）、历史账目说谁排了什么的账目（让气候政治变成一场算术之争的累计排放表）、以及还剩下什么（*剩余碳收支*——气候政策中最有分量的数字，也是最被误解的）。这个记账层之所以存在的理由是2000年代发现、如今AR6以高置信度评估的一个物理事实：**峰值变暖由累计CO₂排放决定**，不由日历上的日期决定——这把每个温度目标变成收支、每个收支变成期限、每个期限变成谁付账的问题。

## 账簿：我们排什么，留下什么

::: definition 温室气体清单：气体、指标与数字 {#def-ghg-inventory}
人为气候强迫是一组性质截然不同的气体组合。**二氧化碳**（2024年424 ppm，比工业化前280 ppm高52%，以约2.5–3.0 ppm/年增长——存量的约0.6%/年）是唯一按*累计*对峰值变暖重要的：它的寿命不是一个数字而是一条曲线（快的海洋与陆地吸收在几十年内移走一个脉冲的约四分之一；剩余约20–40%以碳酸盐化学极限存续数千年），所以它是收支的货币。**甲烷**（1,930 ppb，比730 ppb高160%，AR6有效辐射强迫约0.54 W/m²加上通过臭氧与羟基自由基的可比间接效应）是组合里化得快的冰：其大气寿命对OH氧化约11年，所以其浓度在十年内响应排放变化——"甲烷是低垂果实"的原因（2021年《全球甲烷承诺》的2030年前30%目标，而2020–21年出现了40万年冰芯/地表记录中最大的两年增长、约15–17 ppb/年，部分来自热带湿地反馈、部分来自化石与农业排放，仍是该领域最受关注的反馈警告）。**氧化亚氮**（346 ppb，+24%，寿命116年，长寿命气体中*每分子*最强的，以约1 ppb/年上升，主要来自氮肥——养活世界一半人口的哈伯-博施法是仅次于化石碳的行星第二大生物地球化学改变）、**含氟气体**（HFC、PFC、SF₆——质量上微小、每分子上巨大，《基加利修正案》的HFC逐步减少是估计到2100年避免约0.4 °C的单一议定书）、以及**短寿命气候强迫因子**（黑碳、来自NOₓ与CO的对流层臭氧、甲烷自己的臭氧效应——合计大致相抵为一个约0.5–1 W/m²的净正强迫，黑碳的北极雪面变暗是最尖锐的区域项）。为了把这些加进一本账，该领域使用**全球增温潜势**（GWP100：甲烷27–30、氧化亚氮273，AR6值；GWP20：甲烷约80）及其新表亲（GWP*，把连续甲烷排放当作*温度平台*处理的温度-时间指标——终于让"甲烷不是CO₂"变得算术可读的指标）。2019年全气体总量是**约59 GtCO₂当量/年**（AR6第三工作组：59 ± 6.6），其中化石与工业CO₂约35、土地利用CO₂约4–5、甲烷约16（CO₂当量）、氧化亚氮约4、其余是含氟气体与间接效应——而分部门分解（电力与热力30%、工业24%、农林其他用地22%、交通15%、建筑6%）是每份国家战略最终都必须涂色的地图。
:::

::: definition 全球碳收支：源、汇与空气分数 {#def-carbon-budget}
大气是一本有两个分录一个余额的账。**源**：化石燃料与水泥排放2023年为**36.8 GtCO₂**（全球碳收支2024年版——人类历史最高之年），土地利用变化排放约4.2 GtCO₂（毁林、排水、泥炭火灾——"毛"毁林项约10–12 Gt被再生长与经营抵消），人为总源约41 GtCO₂/年。**汇**：海洋吸收约2.7 GtCO₂/年（溶解度泵与生物泵，前者被层结每十年削弱1–2%——SOCAT/GO-SHIP重复水文测量计划的"汇效率"问题），陆地约3.4 GtCO₂/年（CO₂施肥效应、氮沉降、抛荒耕地的再生长——被同样的土地利用排放抵消，并日益受干旱与火灾威胁，2015、2019、2023年的异常增长年暴露了其变率）。**余额**：大气2023年增加了约5.2 GtC（约19 GtCO₂），**空气分数约45–50%**——一个*七十年恒定*的比率（"Keeling–Bacastow"结果：空气分数跟踪排放，因为汇随浓度扰动成比例——一阶线性碳循环行为），而恒定性本身就是警告：如果陆地与海洋汇以观测到的年代际变率速率失去效率，空气分数本会可测量地上升，而2020年代的高增长年（2015与2023年ENSO驱动的+3.0 ppm尖峰）按全球碳收支的分解是陆地汇的变率而非趋势。收支的测量基础设施是现代科学安静的胜利之一：约700个本底CO₂站（GAW/ICOS网）、约80条海洋表面CO₂船与系泊（SOCAT的1,400万个测量）、GOSAT与OCO-2/OCO-3卫星（后者2014–2025年的柱图现在能分辨城市尺度的羽流——让巴黎透明度框架的清单报告可核查而非只可申报的"验证与归因"能力）、以及闭合化石、陆地与海洋项之间质量平衡的¹³C/¹⁴C与O₂/N₂同位素收支。诚实的不确定性是陆地汇的*趋势*（FACE实验与自由空气加富元分析测到的CO₂施肥响应小于许多模型的假设——会抬高空气分数的"施肥消退"）、永久冻土项（约1,400–1,600 Gt土壤碳，其2020年代通量已被测量，而其世纪尺度轨迹被收支作为明示的"排除反馈"告诫携带）、以及2020年之后海洋碳吸收是否开始饱和的问题（2023年Nature Synfholt等人与全球碳收支2024年"海洋汇在2010年代停滞"的发现，模型界仍有异议）。
:::

::: example 疫情实验：一次被强加的排放暂停教会了什么 {#example-pandemic}
2020年4月，封锁让道路与工厂空荡，全球化石CO₂排放比2019基线低约17%——历史上最大的突然排放下降，大于2008年金融危机（−1.4%）或2011年福岛冲击。大气的响应是碳循环界从未能做的实验：2020年的增长率降到约2.4 ppm（对预期的约2.5–3.0），只减了约半个ppm——因为*浓度*继续爬升，而响应浓度而非排放的汇几乎没有察觉。一年里的三个教训：(1) **浓度是累计的，排放是水龙头**——17%的单年削减让大气增长率动了约5%、让浓度动了百分之几ppm，累计排放框架的物理基础；(2) **陆地汇的变率主导年际噪声**——2020年创纪录的陆地碳吸收（亚马逊的丰水年、欧亚北方火灾年的反号）在陆地项里淹没了人类信号，全球碳收支年度发布是一场分离ENSO、火山与政策的法医作业的原因；(3) **反弹和下跌一样快**——2021年排放恢复到2019的约99%（中国与印度电力部门的反弹、航空与航运的塌陷在持续），"重建更好"刺激方案把约2%的复苏资金给了清洁能源、对IEA"可持续复苏"蓝图的35%。练习的问题：如果17%的单年下降在浓度记录里不可见，什么样的排放轨迹*是*可见的？在什么时标上？
::: solution
只有持续多年的下降：空气分数的恒定性意味着大气报告*累计*排放，所以7%/年的下降（1.5 °C路径要求的2015–2030速率）在约5–10年内以*下降的增长率*变得可见（增长率趋势对ENSO噪声约需10年数据可检测——"碳循环可检测性"研究），而只在净零处才成为浓度平台。这就是为什么验证科学转向对*排放者*的卫星反演而非全球平均浓度：政策必须产出的信号在源，不在存量。
:::
:::

::: example 公平账：谁用掉了收支 {#example-equity}
1850年以来累计CO₂排放（化石加工业，全球碳收支/Carbon Brief的记账）合计约1,780 GtCO₂，大致分布：美国499 Gt、欧盟27国472 Gt（作为一个集团；仅英国75）、中国284 Gt、俄罗斯171、印度95、日本42、非洲约50。人均累计排放讲述总量隐藏的道德故事：平均每个美国人对历史存量负有约1,400 tCO₂，平均每个欧洲人约600，平均每个中国公民约190，平均每个印度人约65——人类最高与最低四分之一之间20倍的差距。现在叠上剩余收支：AR6从2020年起1.5 °C的碳收支是**510 GtCO₂（50%机会）**（2 °C：1,310 GtCO₂），而按2023年排放速率1.5 °C收支约13年花光。如果剩余收支按人口分享（发展中国家坚持的"收缩与趋同"与人均趋同框架），美国对剩余1.5 °C收支的份额将是占全人类的4%拿4%——意味着国内净零远早于2040——而印度的人口份额允许排放见顶前*增长*数倍。2015年巴黎协定对这个算术的解决方案是故意的含糊："共同但有区别的责任及各自能力"，考虑到各国国情——公平作为原则被宣示，其算术被推迟给各国自判的"国家自主贡献"。2013–15碳收支文献（Allen等人与Matthews等人的TCRE论文、Myhre等人的线性工作）让推迟变得可量化：一旦变暖是收支，任何地方的一吨都在提取一个全球公域账户，而"谁用掉了多少？"成为一个有名字的资产负债表问题。
::: solution
算术就是论点：历史账（美国与欧盟以约12%的人口占累计排放的约55%）与剩余收支账（同样这些人均提取义务）是每场COP围绕"损失与损害"、"资金"与"逐步减少"措辞之争背后的两个数字——而两者都是测量不是观点，这就是为什么本课的科学如此政治：它不选择公平原则，它用同一个有限收支给每个原则定价。
:::

## 收支、缺口与承诺的记账

::: definition 剩余碳收支与TCRE：政策中最有分量的数字 {#def-rcb}
线性碳-气候响应——峰值变暖随*累计*CO₂排放大致成比例上升（对累计排放的瞬变气候响应，**TCRE**，AR6：每1,000 GtCO₂增温0.45 [0.27–0.63] °C）——是重组气候政策的发现，其机制很优雅：随CO₂积累，海洋每吨的吸收大致与溶解度缓冲（Revelle因子）的递减成比例下降，所以空气分数保持近乎恒定、每空气吨的变暖也保持近乎恒定，两个效应在正确的方向上相互抵消。政策工具是**剩余碳收支**（RCB）：与把峰值变暖限制在选定水平一致的累计未来CO₂排放，计算为（目标 − 历史人为变暖 − 非CO₂变暖贡献）/TCRE，AR6对1.5 °C报告为**从2020年起510 GtCO₂（50%机会）**、或2,500 GtCO₂对应83%置信度等值确定性——那个范围的*宽度*（抛硬币与近乎确定之间五倍）正是政策文献通常丢掉的数字。不确定性不是统计填充：TCRE自身的范围（碳循环与气候敏感度不确定性）、非CO₂强迫项（甲烷是否持平、气溶胶是否随空气质量改善而减少，各加±0.1–0.2 °C，即收支±200–400 GtCO₂）、被故意从AR6收支排除的"永久冻土与湿地"反馈项（其省略是一个反方向的明示审慎）、以及定义本身（峰值变暖对20年均值、超出后回落对永不超出）。2018年IPCC 1.5 °C特别报告让收支成为公共物品——从2018年起1.5 °C五成机会剩420 GtCO₂，即当时排放的约10年——而2020年代的更新（Forster等人2023与2024碳收支更新、GCB的"收支已用"计数器）让算术保持最新：从2025年初起，1.5 °C/50%收支接近**约200–250 GtCO₂**，大约当前排放的五年，而诚实的科学告诫是1.5 °C*峰值*之后缓慢下降（巴黎目标的实际措辞"远低于2并追求1.5"）是一个不同的、更大的收支，不同于永不超出1.5。经济文献中对收支的批评者（"超调与依赖负排放"路径——IPCC AR6第三工作组的发现：几乎所有1.5 °C路径都使用某种二氧化碳去除，主要是土地与森林类的，其规模受土地可持续文献质疑）与其辩护者（"收支优先"学派：收支是从排放到温度唯一稳健的桥梁，而每个替代框架——温度目标、浓度目标、速率目标——都更不直接受政策控制）在用不同的风险偏好争论同一套物理，这正是本课在科学与选择之间画的那条线。
:::

::: definition 排放路径、NDC与缺口：承诺的记账 {#def-pathways}
收支与物理之间隔着人类承诺的一层，其科学是记账。**SSP–RCP路径家族**（CMIP6情景设计：SSP1-1.9、SSP1-2.6、SSP2-4.5、SSP3-7.0、SSP5-8.5——描述*世界*的"共享社会经济路径"——可持续、中间路线、碎片化、化石燃料驱动——与辐射强迫目标交叉）是预测文献的输入，下一课讲；**政策文献**（UNEP排放差距报告、IEA世界能源展望、COP关于NDC的年度综合报告）回答另一个问题：*承诺实际交付什么？*2024年的记账：2023年全球排放约57 GtCO₂当量（全气体），1.5 °C/50%路径要求2030年比2019年低约**42%**、CO₂净零在2050年前后，现行政策让2030年排放比2019年高约25，而无条件NDC（桌上的承诺）意味着到2100年**约2.6–3.1 °C**变暖——2030年承诺与路径之间约15–20 GtCO₂当量/年的"排放缺口"，比俄罗斯或美国的足迹还大。缺口的解剖有教益：承诺的覆盖（哪些部门与气体被纳入——航空与航运被许多框架排除、粪肥与水稻的甲烷常常软性）、其条件性（发展中国家承诺中以资金为条件的NDC）、其年份（许多NDC按2010年代技术预期编写，而光伏自2010年以来90%的成本下降已使其保守——IEA反复的发现：已宣布承诺*若落实*将把2030年排放大致减半、对现行政策）、以及落实记录（Pindyck–Hepburn–Ritchie 2019–22元分析发现约50%的承诺实现了，而Climate Action Tracker长期发现"承诺不是政策"）。前沿是**碳记账的细则**：生产对消费记账（贸易品中体现的约20–25%排放，把责任账从中国工厂移到欧洲消费者）、净零里的"净"（SBTi与ISO净零标准围绕抵消质量的斗争——2023–24年调查发现多数避免毁林与炉灶信用额不可追加、2023年1月卫报/时代周报/明镜调查引爆的碳信用体系诚信危机）、以及巴黎协定第六条（市场机制，其记账规则——防止重复计算的"相应调整"——在COP26–28被操作化，是一笔交易与一个漏洞之别）。这些都不是软科学：每一项都是测量或一条可被上述卫星验证系统发现违反的记账规则，这就是透明度框架代表的静默革命——第一个排放*可以从轨道上核查*的体制。
:::

::: example 甲烷的两个意外：2020–21增长尖峰与卫星清算 {#example-methane}
2020和2021年大气甲烷各增长约15–17 ppb——1983年开始测量以来最大的两年增长，大于80万年冰芯记录工业段的任何一年。源归因（全球碳计划的甲烷收支、GOSAT/TROPOMI对超级排放者羽流的卫星观测）发现一个三段的故事：热带湿地排放持续增长（模型预言的温度与降水反馈，现在测到了）、畜牧业与水稻的稳定人为排放（约人为甲烷的32%，肠道发酵项——植物性饮食转变能解决而任何技术都不能）、以及化石油气排放（约人为的36%，其中火炬与放空——卫星星座MethaneSAT（2023年发射）与Kayrros/Methane Hydespace探测服务现在按产量的3–5%找到——2021年《全球甲烷承诺》30%削减"到2100年1.3 °C"的奖赏就明摆着：IEA与联合国环境规划署2021年评估发现油气甲烷减排的约75%以*负*净成本可得——在气体价值内自我偿还的捕集利用或消灭火炬）。第二个意外是记账的：卫星的超级排放者探测（土库曼斯坦与俄罗斯管道、Perm盆地羽流、2022年北溪泄漏——测量过的最大单次甲烷事件，数日内约1–2 MtCH₄）把甲烷从清单估计（各国自报的"国家信息通报"、按排放因子构建）变成了测量量，而首批国家层面比较（2020年代美国、欧盟与各国研究）发现清单把油气甲烷*低估*30–70%——验证革命先来到物理（大气窗口中的强吸收体、短寿命、尖锐的卫星签名）让它最容易的气体。练习：用全球甲烷承诺的算术——2030年前甲烷削减30%——与AR6甲烷TCRE当量（当前甲烷强迫约0.5 °C，带约0.2 °C的*气溶胶遮蔽*告诫，让甲烷的净变暖成为最大的短寿命项），解释为什么甲烷同时是温度上最快的杠杆又不是CO₂行动的替代。
::: solution
甲烷的寿命（约11年）意味着30%的削减在十年内降低其浓度并立即减缓变暖的*速率*（2050年前半度量级的效益、模型相互比较的范围），而CO₂的持续意味着其变暖是累计的、只有净零才*停止*它——甲烷买来时间、救住产量（其臭氧前体效应），但弯的是曲线的斜率不是终点；终点是CO₂的账，这就是为什么两种气体需要不同的记账（甲烷的平台用GWP*、收支用累计CO₂），也是为什么用GWP100把两者混在一起的"CO₂当量"总量在两个方向上都误导。
:::
:::

::: example 2010年的模型没有预测到的成本革命 {#example-cost}
2010到2024年间，太阳能光伏的平准化成本下降约90%、锂离子电池组约89%、陆上风电约70%（BloombergNEF与IRENA系列），到2024年新建光伏在世界上大部分地区是史上最便宜的电力（IEA"廉价电力时代"的框架），煤电气电按经济性而非政策提前退役。对本课的意义是科学而非商业的：产出2014–18年IPCC情景的综合评估模型（IAM）嵌入了让光伏+可行储能成为2040–2050年代选项的技术成本假设，产出的路径"需要"碳捕集与核电来竞争——2020年后文献记录的"IAM悲观主义"（Pindyck对IAM损害函数的批评、Way等人2022年*Joule*论文显示学习驱动的成本下降是组件技术的*常态*、"需求侧"学派发现AR6第三工作组章节自己的组合低估了电气化与效率潜力）。记账后果：承诺与路径之间的排放*缺口*部分是知识缺口——承诺按旧成本曲线编写，而巴黎棘轮机制（每五年更新、 渐进地 更有雄心的NDC——决定1/CP.21的"棘轮"）是让承诺赶上物理*和*经济的机制。2023年全球盘点的要求——"世界不在轨道上"但"基础已具备"（仅2023年的光伏安装速率约420 GW，约为1.5 °C路径对电力部门要求速率的1.5倍）——是记账层第一次在同一句话里报告两个事实：收支说我们晚了，部署曲线说工具到了。
::: solution
对收支算术的教训：更便宜的光伏不扩大碳收支——物理对成本曲线无动于衷——但它塌缩了留在收支*内*的成本，而缺口文献2024年的"最低成本1.5 °C路径"是一台与2015年路径CCS与核电偏重的组合根本不同的机器（电气化交通、热泵、绿钢、光伏加储能基荷）。收支是固定的；票价跌了90%，而承诺的记账还没有给票价重新定价。
:::
:::

::: warning 五个记账陷阱：不是收支的收支、不是零的净、不是减排的抵消
**1."收支是为1.5 °C的"——哪一个？** 510 GtCO₂的数字是*20年均值峰值50%机会的抛硬币*；永不超出1.5的收支约其一半，而"暂时超调并回落"的收支更大但依赖有争议规模的去除。每个收支数字都必须连同其概率与其定义一起引用。**2."净零"不是零。** 净零定义（SBTi 2021、ISO 14068）允许残余排放由去除平衡；国家承诺里"净"可以由持久性怕旱怕火的土地碳记账满足（2018–19与2023年加拿大与西伯利亚森林火灾季让陆地在数周内由汇转源——去除文献定价的"缓冲逆转风险"）。**3.抵消不是减排。** 2023年自愿碳市场调查（卫报/时代周报/华尔街日报关于Verra避免毁林信用的系列、West等人与Arcusa等人森林信用研究约70%高估的发现）展示了规模化的可追加性问题：为其实并未要被砍的森林付钱。碳循环算术毫不留情——排出一吨就是加入一吨，无论账簿怎么记。**4.生产记账隐藏消费。** 中国排放的（大约）三分之一体现着欧洲与美国的最终需求；止于厂门的国家清单把责任全球错配约20–25%，而两种框架都合法——选择是规范性的，必须言明。**5.空气分数不是政策目标。** 其恒定性（好消息：汇还在工作）也是其警告（坏消息：它们*按比例*继续工作，所以无论我们排多少大气都留下约45%，而任何汇的减弱——2023年陆地汇异常、亚马逊2010/2015/2015–16干旱驱动的枯死研究、泥炭与永久冻土项——都会提高分数并同时缩水本课的每个收支）。
:::

::: history 从Keeling曲线到碳收支：记账革命 {#history-budget}
测量时代始于**Charles David Keeling**1958年冒纳罗亚基线（315 ppm）与其1960年对季节循环的发现——一个活着的、交换中的地表生物圈的证明——以及1970年代空气分数大致恒定（Houghton–Woodwell与Bolin的记账）的认识。**冰芯时代**（Bern的Friedli等人/Stauffer等人，1980；Barnola的GRIP工作；2008年EPICA Dome C 80万年记录）确立了180–300 ppm的自然范围与CO₂-温度耦合，让现代的424 ppm成为300万年的异类。**海洋与陆地汇的定量**随之而来：Key West–Tahiti船测断面与VOCES时间序列（1990年代）、全球海洋船基水文调查计划的重复断面、FLUXNET涡度通量塔网（1994–）、直接测量施肥响应的自由空气CO₂加富实验（FACE，1996–2005）、以及**全球碳计划**（2001年成立，其年度全球碳收支就是本领域的账簿）。**政策发明时代**跑在2008–2014：Meehl等人（2009）与Matthews等人（2009）*Nature*论文证明稳定变暖需要*累计*排放上限（"碳-气候响应"论文，建立在Allen等人2009累计排放实验与2008–09 Meinhausen–Allen综合之上）、Myhre等人（2013）与Macdonald等人（2009）的观测TCRE约束、**2013–14年IPCC AR5第三工作组**章节的收支表、以及2014–15"碳收支"进入巴黎谈判（Davos/Durban时代的"收支"框架、2014年IPCC综合报告为2 °C放1,000 GtCO₂的表、2015年巴黎协定第四条第一款"在可持续发展背景下"的语言悄悄采纳收支为组织装置）。**验证时代**（2009– ）：OCO-2（2014）、GOSAT-3/CO2M谱系、哥白尼人为CO₂监测系统（2023– ，第一个业务化的国家排放卫星验证）、TROPOMI甲烷图像（2018– ）与MethaneSAT（2023）、让城市清单可核查的ICOS与城市反演模型网、以及2021–24碳市场诚信危机——它教会了政策会计师们早就知道的事：在收支世界里，记账*就是*物理。
:::

::: quiz
人为CO₂排放的"空气分数"——留在大气的那份——过去七十年一直是：
- [ ] 下降的，因为汇在增强
- [ ] 急剧上升的，因为汇在饱和
- [x] 约45%大致恒定，因为汇随浓度扰动成比例
- [ ] 只与逐年ENSO相位成比例
::: solution
**约45%大致恒定**——Keeling–Bacastow结果：陆地与海洋汇年复一年吸收排放的约55%，因为其吸收由排放创造的*扰动*浓度驱动（一阶线性碳循环行为）。恒定性是累计排放如此干净地映射到累计浓度、并（经TCRE）映射到峰值变暖的原因——整个碳收支政策大厦立于这个被测量的近线性之上，其缓慢漂移与年际变率（厄尔尼诺年55–60%的空气分数）是收支文献明示的不确定性。
:::

## 练习

::: exercise {level=1 check="46"}
2023年人为排放总计约41 GtCO₂而大气增加约19 GtCO₂。把空气分数计算为百分比。
::: solution
19/41 = 46%——七十年平均约45%的结果；补数（54%）是陆地与海洋汇之和，其持续按比例吸收是每个碳收支继承的假设。
:::

::: exercise {level=1 check="279"}
用AR6的GWP100（27.9）把1000万吨甲烷排放换算成CO₂当量，答案以MtCO₂当量给出。
::: solution
10 × 27.9 = 279 MtCO₂当量；用GWP20（82.5）同一吨位是825——指标的选择是关于你在乎哪个时标的陈述，这就是甲烷记账之争围绕27对82这个数字开战的原因。
:::
:::

::: exercise {level=1 check="13"}
从2020年起1.5 °C（50%）的剩余碳收支约510 GtCO₂而排放以约40 GtCO₂/年进行。多少年耗尽？为什么答案不意味着"我们到2033年前都有时间行动"？
::: solution
510/40 ≈ 13年——但收支是一个*累计*账户：每一年的不作为都在提取它，峰值变暖物理没有宽限期，而50%概率意味着按这个收支一半的路径已经超出1.5；那个日期是收支*花光*之时，不是极限*达到*之时（峰值变暖以小滞后跟随累计排放）。
:::
:::

::: exercise {level=2 check="0.23"}
用TCRE = 每1,000 GtCO₂增温0.45 °C，计算上述510 GtCO₂剩余收支相对2020水平隐含的峰值变暖增量，再加上已达到的约1.1 °C检验收支的内部一致性。
::: solution
0.45 × 0.51 = 0.23 °C；1.1 + 0.23 ≈ 1.33——相对1.5表面上的短缺是收支内置的项：非CO₂变暖（约0.1–0.2 °C，主要是甲烷）与"高于1850–1900"对"高于2010–19"的定义之别，AR6收支算术明示携带——练习的要点是收支不是简单的(1.5 − 1.1)/TCRE。
:::
:::

::: exercise {level=2 check="115"}
大气CO₂在424 ppm存量上以约2.6 ppm/年增长。计算分数增长率与倍增时间（70法则）。
::: solution
2.6/424 = 0.61%/年；70/0.61 ≈ 115年——让2×CO₂平衡敏感度文献（2.5–4 °C的ECS范围）成为22世纪问题、而让变化*速率*成为本十年问题的"倍增时间"，变暖速率与临界点文献一直分开的区别。
:::

::: exercise {level=2 check="55"}
美国与欧盟27国合计贡献了1850年以来约1,780 Gt累计化石CO₂中的约971 Gt。把其对历史账的份额计算为百分比，其今日世界人口份额约为12%；说出这两个数字带到每场COP的公平论点。
::: solution
971/1,780 = 55%；以约12%的人类，人均历史主张是"共同但有区别的责任"条款、损失与损害基金（COP27，2022）、与资金承诺背后的算术——每场谈判的温度都由这一个比值设定。
:::

::: exercise {level=3 check="40"}
1.5 °C路径要求2030年排放比2019年低约42%（全气体，2019年约59 GtCO₂当量），而现行政策跑在比2019高约25%。在这个粗略的全气体算术里把2030"排放缺口"计算为GtCO₂当量。
::: solution
路径2030：0.58 × 59 = 34；现行政策2030：1.25 × 59 = 74；缺口是74 − 34 = 40 GtCO₂当量——比UNEP排放差距报告公布的数字大，因为那些用更窄的气体覆盖与不同的基线，这才是本课真正的要点：缺口的大小取决于记账，而报告的方法学章节是气候科学中最政治的页面。
:::
:::

::: exercise {level=3 check="2.7"}
卫星清单发现国家的油气甲烷报告把实际排放低估40%。如果报告的化石甲烷是70 MtCH₄/年，计算真实值，并以其GWP100 CO₂当量（27.9）给出GtCO₂当量（一位小数）。
::: solution
真实 = 98 MtCH₄/年；×27.9 = 2.7 GtCO₂当量——大约印度整个化石CO₂足迹藏在一个75%减排为负成本的气体里，清单中最大的近期杠杆，也是甲烷卫星革命（TROPOMI、MethaneSAT）既是科学仪器也是气候政策的原因。
:::

::: exercise {level=3 check="2.05"}
如果陆地与海洋汇减弱让空气分数从45%升到50%，2023年大气增益（19 GtCO₂）会增加多少GtCO₂？对排放恒定下收支的寿命意味着什么？
::: solution
41 × 0.05 = 2.05 GtCO₂/年的额外空气增益（每年增长多约四分之一）；收支寿命缩短约10%——每次收支更新都检验的"汇饱和"敏感性，2023年陆地汇异常使其变得具体：一个不那么慷慨10%的碳循环就是少十年的收支，没人的政策买过单。
:::

::: quiz
"碳收支"（累计排放 ↔ 峰值变暖）的物理基础是：
- [ ] CO₂在大气中的指数衰减
- [x] 下降的汇效率与大致恒定的每空气吨变暖之间的近抵消（TCRE线性）
- [ ] CO₂的线性强迫（其本身就够）
- [ ] 100年GWP惯例
::: solution
**两个线性相互抵消**：随CO₂积累，每一额外吨被海洋与陆地吸收得*更不*有效率（Revelle因子效应），但每一空气吨随基线增长变暖*更多*——两个效应相互抵消，让变暖与*累计*排放成比例（碳-气候响应文献：Matthews 2009、Allen 2009、AR6 TCRE评估）。仅有线性强迫做不到；收支存在是因为碳循环恰以让拖延不安全的方式与辐射物理合作。
:::

::: summary
- 清单：全气体约59 GtCO₂当量/年（2019），CO₂ 424 ppm（+52%）、甲烷1,930 ppb（+160%，2020–21增长尖峰是本领域的警告）、来自氮肥的N₂O 346 ppb、含氟气体小而强——而指标（GWP100/20、GWP*、累计CO₂）是必须言明的选择，不是常数。
- 碳循环保持近恒定的约45%空气分数，因为汇随扰动成比例——让累计排放成为主变量的被测量近线性（全球碳计划、同位素与卫星约束）。
- 1850年以来累计排放（化石约1,780 GtCO₂）以55%分布于占人类约12%的美国与欧洲——每场COP之争背后的公平账——而剩余1.5 °C收支（AR6：从2020年起510 GtCO₂、50%）如今约是当前排放的5年。
- 峰值变暖 ∝ 累计CO₂（TCRE约每1,000 GtCO₂ 0.45 °C）是把温度目标变成收支、收支变成期限的发现；收支的概率、定义与排除的反馈必须与数字同行。
- 政策层是记账：NDC交付约2.6–3.1 °C、2030缺口约20 GtCO₂当量、净零里的"净"与抵消市场的诚信是物理看不见的记账问题——而新的卫星验证（OCO-2、哥白尼、TROPOMI、MethaneSAT）正让账簿从轨道可核查，第一个数字可被审计而非只能被相信的气候体制。
:::
