海平面是气候记录中最诚实的仪器：它积分了行星表面上每一个热源与融水源，并被两种互相一致的独立技术——沿海验潮站与轨道雷达高度计——以毫米精度测量。全球平均海平面在1901到2018年间上升约0.20 m，速率在整个世纪翻倍有余（从约1.3 mm/年到2006–2018年的3.7 mm/年），而上升正以约0.09 mm/年²加速——这个信号把缓慢的细流变成了本世纪的海岸问题。让这一学科难得出乎意料的是"海平面"不是一个数字：每段海岸有自己的相对海平面，由全球水量加上区域比容型、融冰的引力与形变指纹、冰川均衡调整、以及——在受灾最重的城市——纯粹的地面沉降共同设定。本课建立这些项的物理、约束它们的测量链、以及如今主导该领域的冰盖预测之争。

::: definition 上升之海的物理：体积、质量、与区域指纹 {#def-slr-physics}
全球平均海平面的变化恰好只有两个原因：海水的密度变小（热膨胀，加上盐度变化的盐效应）或其质量增长（融冰与陆地蓄水）。热膨胀主导历史收支——1971–2018年上升的约40–50%——因为海洋吸收了约90%的多余热，而过去半个世纪上层海洋的增暖（2000年以来Argo浮标网络与Argo之前XBT和海洋调查综合记录的热含量变化）直接换算成厘米：顶上一公里增暖0.1 °C抬升全球海平面约2 cm（接近表面温度的热膨胀系数约2×10⁻⁴ K⁻¹，乘以深度对面积之比）。质量增加来自三个冰冻圈储量——山地冰川、格陵兰冰盖与南极冰盖——其损失与总量同步加速（AR6的2006–2018收支：冰川约0.7、格陵兰约0.7、南极约0.3–0.4 mm/年，加上比容膨胀约1.5 mm/年在误差棒内闭合收支），加上人类水文循环：水库蓄积*推迟*了二十世纪上升几厘米（2017年Kopp等审计发现蓄积抵消了总量的约6%），而地下水开采与湿地排水如今已反转了那个抵消。区域层是单一全球数字溶解成数百个地方数字的地方。**比容指纹**：风与密度型让热带大西洋西部、墨西哥湾与印度洋-太平洋暖池的上升比全球平均快20–40%，而赤道太平洋与南大洋部分区域上升更慢。**融冰指纹**：一个正在损失的冰盖在约2,000公里内*降低*当地海平面——其减弱的引力把水拉开、被压陷的地壳回弹——所以格陵兰附近的海平面即使格陵兰在融化也将比平均升得*少*，而远场（美国大西洋海岸、北欧）继承高于平均的份额；"指纹方法"（2015–2020年Wiezik等与2022年Dutrieux学派分析）利用这些空间签名把观测上升归因于特定的冰盖源。**冰川均衡调整**：消失的劳伦泰德冰盖仍在回弹的前缘隆起压低哈德逊湾周围的海平面、抬升远场——波士顿到诺福克的验潮站趋势成为全球最陡之一的原因（"纽约湾热点"，炮台公园3.2 mm/年，全球平均的两倍，一半来自GIA与动力学、一半来自海洋自己的环流变化）。以及**沉降**：地下水与烃类开采以压倒海洋上升的速率压实地面——达曼9 mm/年、威尼斯历史上2–3 mm/年、雅加达北部街区每年最多10 cm，这就是印度尼西亚政府2019–22年把首都从雅加达迁走的决定用海平面风险语言书写的原因，尽管该市的*全球性*问题并不特别。相对海平面——海岸实际经历的——是四项之和，而每个预测、防御设计与不动产地图都是关于和、不是全球平均的陈述。
:::

::: definition 测量海洋：两个世纪的验潮站，三十年的高度计 {#def-slr-observe}
观测系统是一个三级梯子，每级有自己的误差文化。**验潮站**是最古老的气候时间序列：1870–1930年代的验潮站网（1928年创立英国永久海平面平均局的利物浦站网、绑定大地基准的美国东海岸网）仍供给最长的记录，而其解读是一个大地测量问题——潮位站测量*相对于其下土地*的海面，所以每个数字都需要附上一个GPS或DORIS的垂直陆地运动测量，而世界上最快的相对上升绝大多数是陆地下沉、不是海水增长。**卫星雷达高度计**——1992年底起的Topex/Poseidon，然后Jason-1/2/3、Sentinel-6/Jason-CS——改变了论题：微波高度计在自由海洋上以厘米精度测量海面高，而多卫星记录（1993年至今，已32年多）给出约3.4 mm/年的全球平均上升、不确定度为零点几毫米，经过验潮站记录校准并在施加验潮站陆地运动与海岸动力学改正后与其一致（2000年代改正后两套系统的一致性——Church与White 2011与2019–20年Nadler/Woof学派的均一化——是该领域的胜利，也是"验潮站没显示"的回答）。**重力与质量时代**：GRACE（2002–17）与GRACE-FO（2018–）通过引力信号直接称量冰盖与冰川质量损失，闭合比容上升（Argo）与总上升（高度计）之间的收支——2020年代综合以约0.1 mm/年通过的"收支闭合"检验，地球观测中最紧的闭合。长背景来自古海平面：末次间冰期（129–116 ka）在巴哈马到百慕大的礁阶地上高出今世6–9 m——基准约束，即格陵兰与/或西南极在比工业化前暖约1 °C的温度下损失了一米多的海平面当量——早上新世高5–25 m，而末次冰消期的融水脉冲（融水脉冲1A，约14.6 ka，2010–2020年代珊瑚记录综合中每世纪数米）证明当强迫足够猛烈时冰盖*能*产出两位厘米/十年的海平面。冰消期速率是冰盖建模者尊重的物理天花板：海洋的热容、不是大气的，决定一个入海冰川能被摧毁多快，而古记录说"每世纪数是可能的"。
:::

::: definition 预测与承诺：2100意味着什么、不意味着什么 {#def-slr-projection}
海平面预测是唯一一个共同体公开使用*三个*不相容工具的气候问题，而AR6范围是它们之间的谈判结果。**过程模型**（ISMIP6的耦合冰盖-海洋-固体地球模拟与海洋/冰综合）外推观测动力学，给出"可能"范围：相对1995–2014，到2100年全球平均上升SSP1-2.6下0.28–0.55 m、SSP2-4.5下0.44–0.76 m、SSP5-8.5下0.63–1.01 m，2150与2300范围大致翻倍与翻三倍（SSP5-8.5：到2300年0.9–2.3 m）。**半经验方法**（2009年Jevrejeva–Rahmstorf与2011年Kemp–Sutton–Knutti对海平面与全球温度的校准，其"速率以十年尺度滞后跟随温度"的逻辑重现二十世纪并在高排放下预测2100年0.7–2 m）论证过程模型漏掉了未建模的冰动力学；**专家征询与古类比**（2014年Bamber–Aspinall与2016年Bamber等低端研究、2023年Pollard与de Conto崖壁破坏变体）把"可信上界"放在2100年2 m附近。AR6的结算：保留过程模型的"可能"范围，并附上显式的**低可能性、高影响**附加——高排放下大约2100年再+0.5 m、2300年再+1.5 m——来源于冰盖过程（海洋崖壁破坏、冰架崩解），模型认为其不太可能但无法排除。承诺框架是更深的事实：海平面**平衡气候敏感度**——平衡增暖每度的最终上升——评估为约2.7 m/°C（2019年Gregory–Levy与2022–23年Schneider–McCrink综合，范围约2–4），所以稳定在+1.5 °C仍将把海岸线在千年尺度上承诺给数米，而已达的约1.2 °C已承诺了无论如何都会来的约2–3 m。承诺的时间尺度因储量而异：深海的调整需要几个世纪到几千年，山地冰川几十年达到平衡（其承诺上升几乎全部"锁定"），格陵兰表面融化以世纪为单位响应，而南极冰动力学一旦海盆被排干在人类时间尺度上实际上不可逆——这就是海平面一课不像温度一课、无法靠单一稳定日期关闭的原因。
:::

::: example 加速之争：一场0.02 mm/年²的争论如何被定论 {#example-acceleration}
2018到2023年间，该领域被引用最多的数字——卫星时代海平面上升的加速度——从三个方向被攻击而存活下来。Nerem等2018年*Nature*论文从25年高度计记录报告了0.084 ± 0.018 mm/年²，加速冰融的指纹，并指出它在统计上与当时标准的长验潮站记录恒定加速度拟合所隐含的零加速度不相容。攻击：第一，验潮站记录表面上的*减速*是1991–93年皮纳图博变冷凹陷的假象（Murphy等2022年再分析：移除火山与ENSO段后验潮站与卫星加速度和解）；第二，高度计改正中未建模的11年太阳周期在冒充加速度（2021–22年Thompson–Haigh与2023年Dun–Williams太阳年代际振荡论文；改正最终把加速度移动千分之几、不是百分之几）；第三，古老的老调——Topex辐射计漂移与2016年Jason-3校准切换制造了趋势（被多任务交叉校准与独立的激光测距和DORIS大地测量联系回答）。定论值——约0.09–0.12 mm/年²，随冰损失加速而增长——之所以重要，是因为加速度是把"3 mm/年"变成"2090年代海岸"的东西：恒定3.4 mm/年到2100年给0.27 m，而观测加速度加预测融冰给AR6的0.44–1.01 m，而差额就是整个海岸工程预算。
::: solution
这场争论的教训是关于十年尺度地球物理中的信噪比：加速度项小到火山气溶胶（皮纳图博1992–93年比容凹陷）、太阳周期、辐射计漂移与基准切换——每一个都是真实的地球物理或仪器信号——全都与被争论的量同尺寸。化解协议（移除已知强迫、用独立空间大地测量联系重新拟合、检验对记录段的敏感度）如今是标准，而2025年对整个32年记录的再分析——发现速率已从1990年代中约2.1 mm/年*翻倍*到2020年代初约4.5 mm/年、且加速度本身在加速——是加速之争的最后的话：被争论的量是真实的，噪声之争关乎归因、不是存在。
:::
:::

::: example 热点与下沉城市：大西洋"异常"与雅加达 {#example-hotspots}
2020年Khan等在*Nature*的分析有孔虫微体重建了美国中大西洋陆架潮位，显示了卫星记录只是暗示过的东西：约2009到2017年间，从哈特勒斯角以北的海岸海平面以约9 cm/十年上升——超过当代全球平均的两倍——然后回落。机制是海洋动力学、不是新融冰：大西洋翻转环流减弱与陆架-斜坡海面高度跷跷板（"变暖坑"背后的同一动力学）在十年里把水堆到海岸上，叠加在该区域由冰川均衡调整造成的世纪尺度热点上。这个事件是"海平面在局部加速吗"问题的参照案例，因为它既演示了年代际热点的真实性、也演示了其不持久——水移动了、不是到来了——也因为中大西洋的*永久*特征（GIA驱动的地面下降、墨西哥湾流分离点几何）让整个世纪里该区域保持在全球平均之上。雅加达是相反的案例：一个90%是人类沉降的相对海平面问题。几十年不受管制的地下水开采让雅加达北部自1970年代以来降低了2.5–4 m（2010年代的孔隙水压计与InSAR测量），所以1990年以来30 cm的全球性上升加上数米的沉降产生了规律的米深潮淹；海堤与2019–22年把首都迁往1,300公里外努山塔拉的决定是对*沉降*项的响应——一个政策判词：当局部项主导时，即使完美的全球排放控制也让城市泡在水里，除非管理的是*地下水位*，这是南亚与东南亚下沉超大城市的核心事实（三角洲城市的2022–24年沉降图——曼谷、胡志明市、天津、拉各斯——以1–6 cm/年显示同一格局）。
::: solution
两个案例从两端教同一个分解：中大西洋热点是*暂时且动力学的*（翻转环流与环流变率，叠加在永久GIA趋势上），雅加达的是*永久且局部的*（地面压实，在世纪时间尺度上实际上不可逆，因为压实的黏土不再膨胀）。预测后果：海岸设计必须把各项连同自己的概率结构叠加——一个全球平均情景、一个区域动力学范围、一个GIA常数、以及一个是政策变量、不是气候变量的沉降轨迹。这就是"海平面升多快"是一个畸形问题、而"*这段海岸*的水位升多快、来自哪些项"是可回答的那个的原因。
:::
:::

## 冰的问题：预测、崖壁、与漫长的承诺

二十一世纪的海平面故事决定于模型仍然分歧的冰动力学，因为两大冰盖的失效方式二十世纪收支从未演练过：格陵兰从上方（表面融水润滑其底部）与西南极从下方（暖海水到达海平面以下接地的冰）。机制、有争议的崖壁破坏项、以及Thwaites案例研究占据本节——以及让本世纪的选择成为千年事实的承诺算术。

::: definition 冰盖如何失效：表面融化、海洋不稳定性、崖壁破坏 {#def-ice-fail}
三种失效模式对应三个置信层级。**格陵兰的表面融化模式**约束最好：更暖更湿的北极延长融化季，融水通过冰锅到达底部并加快排流（2001年至今观测的西部出口冰川加速、2017–19年发现动力减薄已超出2003–06爆发数十年），而表面质量平衡在全球增暖约+2–3 °C之上急转大幅负——Smith等2020年承诺分析发现+1.5 °C已锁定0.7–2 m格陵兰最终上升、+5 °C锁定5.6–13 m，而"持续净损失的阈值"评估在1.5–2 °C附近（高置信度）。**海洋冰盖不稳定性（MISI）**是物理最强的南极模式：在海平面以下、床面向内陆加深的基岩上接地的冰盖（西南极大部分、东南极Totten与Aurora盆地的一半）没有稳定平衡——一旦接地线退过一道边缘，接地点的冰厚*增加*、排出增加、后退自我维持（Weertman与Joughin–Alley定理，在松树岛冰川得到演示，其接地线仅2009年就退了31 km、2017–21年以410 m/年后退，是全大陆测得最快的）。**海洋崖壁不稳定性（MICI）**是有争议的那个：DeConto与Pollard 2016年*Nature*模型加了一条简单规则——高于约90–100 m的冰崖在数年尺度上破裂失效——产出了与末次间冰期6–9 m匹配的十七世纪速率南极损失；Pattyn等2022年*Nature*评论论证观测的崩解速率与碎屑特征的缺失表明崖壁破坏太慢、本世纪无关紧要，而2023年交锋（Pollard、DeConto等的回应；2023年Arondela等的冰架-损伤模拟）把该项恰好留在评估报告放置的位置：排除在"可能"范围外、存在于低可能性尾部。**冰架顶托**层横贯所有模式：冰架（龙尼-菲尔希纳、罗斯、拉森）拦着内陆冰，而其崩解——拉森A 1995、拉森B 2002（3,250 km²解体在数年内让残余冰川加速2–10倍，让顶托从假说变成定律的观测）、2017–23年Wilkins的减薄、2023–25年Conger–Mawson的"僵尸"崩解、与2024年半岛附近Milne冰架的崩解风险——以数年到数十年的延迟把海洋增暖传导到内陆。2023年Greenbaum等*Nature*水深测量（国际Thwaites冰川协作组研究飞行的多波束声呐）发现深入西南极内陆的深槽，意味着暖水能到达比假想深入内陆数百公里的接地带——这种加宽尾部而不是移动中位数的结构不确定性结果，也是低可能性语言存在的原因。
:::

::: example Thwaites冰川：海平面风险里唯一的名字 {#example-thwaites}
Thwaites冰川把不列颠大小的区域——约4%的南极冰量——排入阿蒙森海，其接地线自1990年代以来退了12–14 km、速率最高约1.2 km/年，其接地带在海平面下800 m且在加深，而2023年国际Thwaites冰川协作组综合（2023年12月六篇*Nature*论文集群）发现环极深水已经通过陆架上一条通道到达中央接地线，顶托冰架每十年损失数十米厚度，而基岩几何在数百公里的后退中不提供任何锚定点。预测算术：仅Thwaites今天贡献全球海平面的约4%（其自身损失若完全发生会增加约65 cm，跨越数世纪），而ITGC的模型系综将其二十一世纪贡献放在3–17 cm——南极总贡献的5–25%，每个预测中最大的具名冰盖项。2023年*Nature*论文被引用最多的结论也是其最谨慎的：除最强减缓之外的所有情景下，Thwaites西部接地线在几十年内越过最后一个实质性锚定点，此后MISI驱动的后退"在人类时间尺度上不可避免"——一个关于特定冰川几何、不是全球温度阈值的陈述，也是冰盖共同体说"问题不是是否、而是多快"的原因。2024–25年后续（松树岛加速再升级、2024年发现Thwaites东冰架正在减薄走向解体）让这个冰川的绰号——末日冰川，记者发明、科学家们不喜欢的词——继续流传。
::: solution
Thwaites之所以重要，在于它教的是*条件性*不可逆：其几何（倒退床、深槽、无锚定点、暖水通道）意味着其损失轨迹由已在途的海洋热、不是本十年的排放设定——承诺概念最干净的现实实例，也是海平面与排放预算两课[[climate-change/emissions-budgets]]必须一起读的原因。它也规训了"它在融化吗"的辩论：Thwaites的质量损失自1970年代卫星记录开始就持续不断，其贡献在每个收支里，而唯一未决的问题是速率与时间尺度——"科学已定论"的诚实版本是"方向已定论而速率是研究前沿"。
:::
:::

::: example 桑迪、风暴潮、与厘米的算术 {#example-sandy}
2012年10月29日飓风桑迪把4 m风暴潮推入上纽约湾时，水抵达的海岸线已在此前一世纪被抬高了35–40 cm——炮台公园的潮位站显示全球最陡的长期趋势之一——而工程事后分析量化了那些厘米干了什么。2013年NOAA与陆军工程兵团分析发现已经存在的海平面上升给桑迪的淹没面积增加了约65 km²、把约24,000个额外住房单元（约8万人）放进了淹没区；风暴潮频率算术更陡，因为潮位分布的尾部坐在被抬高的基座上：1900年在波士顿或纽约千年一遇的水位今天每世纪出现几次，同一场风暴大约乘二十（Sweet等学派2014–2022年风暴潮频率综合）。2017季让格局成为全国性的——哈维、厄玛与玛丽亚在同一年产生了当时美国最贵的风暴潮洪水，而2022年飓风Ian的迈尔斯堡风暴潮被评估为比1900年海平面上的同一场风暴高25–30 cm，正是这个差额在李县与科利尔县的潮位站记录上把"500年一遇"标签移到了"60年一遇"（2022–23年气候中心分析）。而同一个算术的日常版本——滋扰洪水——是公众实际经历的测量趋势：2022年NOAA报告的高潮洪水日三倍，大西洋与墨西哥湾海岸在中等范围上升下到2050年预测每年60–90天。
::: solution
风暴潮案例是海平面一课的成本效益锚，因为它们结合了本课其余部分分开的两项：一个缓慢上升的基座（厘米、确定、已承诺）与一个快速多变的危险（米、自然、趋势很弱）。物理是加性的而风险是乘性的——潮位对气候变化几乎不响应，洪水*频率*对厘米级基座强烈响应——这就是经济文献（2019–2024年海岸损失模型互比）发现暴露增长与海平面、不是风暴气候学，主导本世纪风暴潮损失轨迹的原因，也是防御设计（桑迪后的"大U"提案、荷兰河流空间哲学）是一个挂着飓风标签的海平面问题的原因。
:::
:::

::: warning 海平面主张被扭曲的五种方式——两个方向都有
1. **相对与全球混为一谈。**"雅加达海平面每年升10厘米"与"全球平均上升3.7毫米/年"都为真、描述的是不同的东西——沉降对海洋体积。每个局部数字必须说出它的项（全球性、比容、动力、GIA、沉降），而每个全球数字不附这些项就不能用到一段海岸上。
2. **把可能范围错当成可信范围。**AR6"可能"区间（SSP2-4.5到2100年0.44–0.76 m）是关于过程模型中位数的66–90%陈述；低可能性冰盖尾部在高排放下到2100年再加约0.5 m、2300年约1.5 m。两个事实在同一章；头条各引其一，而世纪尺度工程规范（荷兰、英国与美国陆军工程兵团实践）如今按上界可信、不是可能值设计。
3. **"没有加速"的故事。**加速之争是真实的且已定论：约0.09–0.12 mm/年²，在增长。反方向的推论错误——把*当前*的3.7 mm/年当恒定引用（"到2100年只有30厘米"）——无视了作为整个测量要点的加速度。
4. **把2100当成故事的终点。**世纪边界是一个核算惯例；承诺按冰盖与海洋的时间尺度运行。已达的约1.2 °C在接下来的千年承诺约2–3 m（约2.7 m/°C的平衡敏感度），而海岸暴露的"浴缸曲线"（2021年Kulp–Strauss高程模型：低可能性情景下8亿人在当代海岸高程带上低于预测的2100高潮位）是关于*长*暴露的陈述、不是2100的期限。
5. **滋扰洪水算术被误读。**美国大西洋与墨西哥湾海岸的高潮洪水从约3天/年（2000）增至约10天（2020）（2022年NOAA报告）——是几厘米上升对一个边缘事件的*频率*乘法、不是风暴潮-气候趋势的证据。正确的读法：在+0.5 m下，今天的"500年一遇"风暴潮在多数海岸变成每世纪数次的事件，这才是每个洪水保险讨论都该出现的数字。
:::

::: history 从隆起海滩到末日冰川：海平面科学的漫长记录 {#history-slr}
海平面科学始于十九世纪的大地测量与隆起海滩地质——波罗的海陆地高度测量、de Geer纹泥年表、以及在1900年前就确立了海随冰期移动数十米的更新世阶地地图——而第一个定量二十世纪综合随战后放射性碳革命到来（1920年代Brooks等与1960–70年代Mesolella等在新赫布里底的珊瑚阶地、Broecker–Cherdynzev同位素期框架）。现代观测时代以永久海平面平均局1928年的潮位汇编开场，经过1960–70年代"海平面革命"辩论（1970年代Barnett与Kates–Pearman评估、1983年美国国家科学院报告首次印出"最高1.5 m"、以及1985年NRC后续被媒体渲染成"2033年前4–6英尺"——第一次海平面恐慌与第一次尾部预测传播的教训）、以及1990年IPCC科学评估的20–140 cm/2100范围设定了仍在使用的模板（过程模型加显式上尾）。卫星时代——GEOSAT（1986）、Topex/Poseidon（1992）、Jason系列、Sentinel-6（2020）——把潮位站稀疏的估计变成32年的全球数据集，而GRACE（2002）加上了质量维度；2001–2013综合论文（Church与White 2006与2011潮位重建、2012年Vetart等与2019年Otos等冰川综合、2012年起的IMBIE冰盖互比）建立了AR5（2013，到2100年0.26–0.98 m）与AR6（2021，上面的情景表）所评估的收支。冰盖之争是该领域的重心：2002年拉森B崩解、2008–12年Rignot与VECCS加速论文、2014年DeConto–Pollard首个MISI世纪预测、2016年MICI论文及其2022–23年Pattyn交锋、2017–23年国际Thwaites冰川协作组及其2023年*Nature*集群、以及2024–25年关于Conger–Mawson与Milne冰架崩解和卫星时代速率翻倍的研究——一场公开进行的、关于冰能失效多快的五十年争论的最新篇章。
:::

## 练习

::: exercise {level=1 check="21"}
1,000 m厚的海洋层增暖0.1 °C。在热膨胀系数2.1×10⁻⁴ K⁻¹下，该层增厚多少毫米？
::: solution
Δh = β·ΔT·h = 2.1×10⁻⁴ × 0.1 × 1000 m = 0.021 m = 21 mm——"海洋吸热已占海平面上升的一半"背后的算术：仅顶上一公里的增暖就占上层海洋每0.1 °C增暖约2 cm。
:::
:::

::: exercise {level=1 check="10.2"}
卫星高度计在30年记录上测得全球平均上升3.4 mm/年。总上升是多少厘米？
::: solution
3.4 × 30 = 102 mm = 10.2 cm。锚定直觉的单位换算：1 mm/年持续一个世纪是10 cm，所以本世纪的20 cm来自平均约2 mm/年，而未来一个世纪以5 mm/年将交付50 cm。
:::
:::

::: exercise {level=1 check="25"}
一个沿海城市"百年一遇"风暴潮的年超越概率是1%。如果海平面上升让其频率翻四倍，新的重现期是多少年？
::: solution
频率翻四倍意味着年概率4%，所以重现期 = 1/0.04 = 25年。"百年一遇风暴"标签在媒体报道中幸存恰恰因为没人重新计算它——极端一课[[climate-change/extremes]]为降雨图集记录的同一个非平稳性问题。
:::
:::

::: exercise {level=2 check="1.98"}
2006–2018评估的总上升是3.7 mm/年，贡献为：冰川+0.74、格陵兰+0.66、南极+0.34、陆地水−0.02 mm/年。剩余的比容贡献是多少mm/年？
::: solution
比容 = 3.7 − (0.74 + 0.66 + 0.34 − 0.02) = 3.7 − 1.72 = 1.98 mm/年。收支闭合方法的缩影——也是Argo热含量记录与高度计记录必须一致的原因：两台独立仪器闭合到同一个数字是该领域最强的证据。
:::
:::

::: exercise {level=2 check="2.5"}
在半经验关系速率 = 0.5 + 0.8·ΔT mm/年（ΔT为工业化前基线以上的°C）下，+2.5 °C时预测的上升速率是多少？
::: solution
0.5 + 0.8 × 2.5 = 2.5 mm/年——该关系的校准（Kemp等2011）针对*总*观测速率，所以预测的总量是2.5 mm/年。该关系的强项与弱点相同：一个拟合参数重现二十世纪，而其线性恰恰是冰盖动力学家质疑的。
:::
:::

::: exercise {level=2 check="5.4"}
海平面平衡气候敏感度评估为平衡增暖每度约2.7 m。稳定在+2.0 °C的世界承诺多少最终上升？
::: solution
2.7 × 2.0 = 5.4 m，跨越二到二十个千年。让海岸政策成为代际问题的承诺数字：今天的排放轨迹已承诺数米，而适应资金是唯一能对已承诺上升起作用的工具。
:::
:::

::: exercise {level=3 check="3.3"}
美国部分海岸的高潮洪水从2000年每年3天升到2020年每年10天。频率增加了多少倍？保留一位小数。
::: solution
10/3 = 3.3倍。乘法来自二十年间约4 cm的额外上升——洪水频率曲线在阈值附近的陡度，这就是小上升产生大频率变化、而"滋扰"洪水计数是海岸气候科学最佳公众传播指标的原因。
:::
:::

::: exercise {level=3 check="1333"}
每融化360,000 Gt陆地冰，全球平均海平面上升1 m。按2010年代格陵兰约270 Gt/年的速率，多少年这样的速率能让海平面升1 m？四舍五入到整数年。
::: solution
360,000/270 = 1,333年。尺度一课：单个冰盖是巨大的，所以年度损失头条（270 Gt/年"听起来很多"）换算成毫米——反过来说，数米的古气候承诺按今天速率需要数千年、或动力学的阶跃变化，而这正是MISI与MICI之争的内容。
:::
:::

::: exercise {level=3 check="2.5"}
一个城市百年一遇洪水区今天覆盖100 km²；海平面+0.6 m后该区扩到250 km²。暴露面积增长多少倍？
::: solution
250/100 = 2.5倍，只为60 cm的上升。因为在浅陆架上洪水区面积大致随水位的*平方*缩放（Kulp–Strauss全球高程模型的暴露曲线），面积暴露是上升的强凸函数——让低可能性尾部、不是可能中位数，成为世纪尺度损失估计主导项的算术。
:::
:::

::: quiz
"把全球温度稳定在+1.5 °C就能阻止海平面上升"是错的，主要因为：
- [ ] 卫星无法足够精确地测量趋势以知晓
- [x] 热膨胀、冰川与冰盖调整在温度稳定后仍持续几个世纪到几千年
- [ ] 厄尔尼诺无论如何会不断添加厘米
- [ ] 沿海城市的沉降与温度无关
::: solution
**时间尺度错配**：海洋吸热、冰盖动力学与深海调整都积分过去的强迫几个世纪到几千年——约2.7 m/°C的平衡敏感度意味着+1.5 °C即使今天停止排放也承诺数米。稳定*限制*了承诺（2米对10米仍是选择）；它不在任何规划视野内结束上升——"阻止危险的上升"与"阻止上升"的区分正是适应资金之争的枢纽。
:::

::: summary
- 全球平均海平面自1901年上升约0.20 m，速率从约1.3翻倍到约3.7 mm/年，而观测加速度（约0.1 mm/年²，在增长）是冰损失加速的指纹——由两套独立系统（潮位站与高度计）测量，在移除陆地运动与火山凹陷后彼此一致。
- 收支闭合：大约一半热膨胀、一半质量损失（冰川、格陵兰、南极），水库蓄积与地下水开采是人类水文项；区域指纹（GIA、比容型、融冰引力信号、沉降）解释了为什么上升最快的海岸是美国中大西洋、印度洋-太平洋暖池与亚洲下沉的超大城市。
- 预测是三工具的谈判：过程模型给出AR6可能范围（SSP2-4.5下0.44–0.76 m、SSP5-8.5下0.63–1.01 m到2100），半经验与古气候论证为显式低可能性尾部（到2100年再+约0.5 m、2300年再+约1.5 m）提供正当性，而有争议的MICI崖壁破坏项就住在那个尾部里。
- 冰盖是前沿：格陵兰表面融化是高置信度且按当前变暖已承诺数米；西南极的海洋不稳定性几何（Thwaites、松树岛、2023年水深的深槽）让快速后退在物理上可能、而对Thwaites西部可能已不可避免——诚实的陈述是"方向已定论、速率有争议"。
- 承诺是本课的教训：平衡增暖每度约2.7 m意味着今天的气候在千年尺度上承诺数米，所以海平面是唯一一个适应不是减缓的后备、而是其永久伴侣的影响——通往影响与响应两课[[climate-change/impacts]]的桥。
:::
