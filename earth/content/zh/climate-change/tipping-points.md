在流行讲述中，临界点是任何要紧的阈值：冰"开始"融化、森林"开始"死亡、洋流"停下"的时刻。在动力系统语言——自2008年PNAS临界要素特刊以来气候文献实际使用的语言——里，这个词窄得多也可怕得多：临界点是一个关键阈值，在*小*扰动把系统推过一个边界、进入性质上不同的状态时，而越过是**自我维持的**（内部反馈从外部强迫接管）且在人类时间尺度上**不可逆**（当强迫降低时原状态不回来，因为系统坐在另一个吸引盆里）。两种用法的区别是"值得担忧"与"无界的担忧"的区别，而本课的第一项工作就是让它们分开。第二项工作是诚实的核算：哪些候选系统在证据中有真正的双稳态（AMOC、千年尺度上的冰盖、生态意义上的珊瑚礁、亚马逊东缘部分），哪些的阈值是粗糙物理的模式假象，而评估报告——AR6的"本世纪突然的区域性气候变化极不可能、但不排除其后的可能"——实际主张什么。第三项工作是2020年代的反转：花掉2010年代把2000年代临界点文献斥为危言耸听的领域，通过更好的统计（早期预警指标）、更好的观测（格陵兰卫星测高、RAPID阵列、亚马逊通量塔）、以及一个声称五个要素可能已注定越过的惊人2022年综合，把问题从"是否"移到了"多快与多确定"。

## 临界点是什么——以及不是什么

::: definition 临界动力学：双稳态、滞后、与早期预警信号 {#def-tipping-dynamics}
数学在教学层面是一维的，而它解释了一切。一个带**双阱势**（两个稳定平衡被一个不稳定阈值隔开）的系统在被推过阈值时翻转，而势的不对称决定哪个阱幸存；一个**鞍结（折叠）分岔**——气候临界点的典型——发生在控制参数（CO₂、淡水输入）的缓慢变化让*当前*的稳定状态彻底消失时，强制跳到剩下的那个，在该参数值上无路可回：这就是**滞后**，崩溃阈值与恢复阈值不同的环，所以被翻转后恢复到翻转前强迫的系统不回来（模型中AMOC的淡水滞后是几十Sverdrup；冰盖的海平面滞后是米）。四个签名区分真正的临界要素与仅仅非线性的要素，而评估报告像核对清单一样应用它们：(i) 翻转所需的强迫相对于系统幸存过的自然变率是*小的*；(ii) 变化在触发后通过内部反馈*自我维持*（表面反照率后退、融水润滑、植被枯死使当地气候变干）；(iii) 变化是*持续的*——在相关时间尺度上移除触发因素时不逆转；以及(iv) 系统在模式或古证据中显示**双稳态**（两个分明的吸引子、不是连续统）。2010年代加上的第五种模式是**速率诱导翻转**：完全没有分岔的系统如果强迫只是*快*也能翻转（Rataiczak与Wunderlich学派2022–23的"无分岔翻转"论文）——"变暖速率比其量更重要"文献背后的机制，也是古新世-始新世与PETM速率比较发挥其作用的理由。实证纲领是**早期预警信号**：在折叠分岔附近，从小扰动中的恢复变慢（**临界慢化**），在统计上表现为可观测量的滞后1自相关上升与方差上升——在湖泊富营养化实验、癫痫发作与气候模式AMOC模拟中得到验证的指标（Lenton与Ditlevsen学派的方法论核心），也是2020年代AMOC警报背后的仪器。诚实的告诫与该方法是旅伴：当*噪声*变化或趋势被错误设定时自相关也会上升，而还没有任何观测记录包含一个*经过验证的*气候临界点预测——该领域自己的承认，写在每篇方法综述里。
:::

::: definition AMOC：海洋传送带的稳定性、观测到的减弱、与崩溃算术 {#def-amoc}
大西洋经向翻转环流——风驱动与密度驱动的环，北大西洋表面水冷却、下沉、在深层返回南方，携带约17–20 Sv的体积与约1.3 PW的热量北上——是气候系统中折叠分岔记录最好的候选，出于一个物理理由与一个历史理由。物理理由是盐平流反馈：驱动环流的下沉需要咸水，环流自己输入盐，而减少输入让表面变淡变稳——一个Stommel在其1961年两箱模式里形式化的正反馈，它从单个淡水强迫参数产出两个稳定态（开与关）与一个滞后环。历史理由是古记录：末次冰消期被突发的北大西洋冷事件打断（Heinrich事件与博林- Allerød暖期/新仙女木冷期，在Broecker与Clark的综合中），其指纹——北大西洋变冷恰逢南半球变暖（"双极跷跷板"）——正是翻转环流停摆应该产出的，而全新世早期8.2 ka事件（劳伦泰德湖溃，模式重演中北半球约1–1.6 °C变冷）演示了机制在上一次机会时的运作。现代观测分成置信度递减的三个主张。**第一（高置信度）：AMOC在二十世纪减弱了。**2023年Thornalley等指纹分析（海温型方法，把记录延到1915）估计自世纪中叶约15%的减弱（17 ± 2 Sv），与2014年Cain等与Caesar等2018年模式-观测工作的"指纹"方法一致；26.5°N的直接RAPID阵列（2004至今）显示大的内部变率与*没有*明确的两十年趋势——两个团队都接受的"阵列太短"和解。**第二（中等置信度）：模式说AMOC本世纪将继续减弱，但2100年前完全崩溃"极不可能"**——AR6的评估措辞，对相关AMOC崩溃类别"本世纪突然发生极不可能"、2100之后低置信度；CMIP系综的滞后环是真实的，但其阈值在多数成员中位于即使SSP5-8.5的2100强迫之外。**第三（有争议）：统计早期预警文献。**Ditlevsen与Ditlevsen 2023年*Nature Communications*对二十世纪指纹记录的分析声称临界慢化信号意味着约2025到约2095之间（中心约2057）崩溃；2024年方法论批评（对记录长度、对假定的线性趋势、对噪声模型的敏感度——Woodhouse与Smith等的评论；延长后把窗口移晚的2024年哥本哈根重新评估）让警报没有日期、但让*机制*——观测到的减弱可能正在接近模式放在更远处的阈值——活着。2024年Lenton等全球综合与2025年全球临界点报告把AMOC留在1.1–1.8 °C变暖的"已经很近"名单上；AR6的"本世纪极不可能"仍是评估立场，而两者的差距是科学风险传播中最尖锐的公开争论。
:::

::: example Ditlevsen警报：一次临界点预测的解剖 {#example-ditlevsen}
2023年7月，Peter与Michael Ditlevsen发表了可能成为气候科学最重要的统计论文：把两个世纪的大西洋"变暖坑"指纹建模为一个噪声松弛振荡器，他们发现其自约1950年以来的涨落变得渐进地更持续——临界慢化——并预测确定性趋势将在2025到2095之间（95%区间）、中心估计约2057年到达历史翻转阈值。头条"AMOC崩溃最早可能在2025年到来"跑过了论文自己的谨慎，而其后的批评是临界点预测为何困难的大师课。记录是短的：指纹代理只有约160年仪器数据，而早期预警统计量在这么短、*错误设定*趋势（强迫不是线性的，1950–80气溶胶凹陷是真实结构）下的行为被2024年评论证明是脆弱的——用重建延长记录、改变去趋势、或加上太阳项，每一个都把窗口移动几十年。模式证据朝反方向切：在AMOC确实在极端强迫下崩溃的CMIP系综里，早期预警信号只在崩溃前几个世纪、不是几十年出现——如果那个物理可迁移，2023年的信号就不该存在，这要么意味着模式的分岔结构是错的、要么统计量在读别的东西。而观测计划（RAPID/SINIC与OSNAP阵列、2025–2030指纹网络扩建）正是为定论而设计：密集的盐度-输送观测系统能通过*物理*（体积与淡水输送）、不是统计量，检测逼近的阈值。
::: solution
这个案例教的是低概率高影响事件的认识论。论文的逻辑——早期预警信号加趋势外推——是对一个模式无法在世纪时间尺度上可信模拟、观测从未见过的事件唯一可用的方法；其脆弱——横跨70年的窗口、依赖机制的假设——同样是内在的。风险文献（2024年Lenton与Rose等"我们该担心吗"交锋）推荐的理性姿态是非对称损失的那种：一个无法排除、结果关乎文明量级的预测，无论点概率如何都证明监测投资是正当的（阵列每年花几千万）——与地震和大流行防范同一逻辑，也是评估报告里的"极不可能"是关于期望值的陈述、绝不是停止观察的许可的原因。
:::
:::

::: example Stommel箱模式：四个方程六十年的滞后 {#example-stommel}
Stommel 1961年的两箱模式——大西洋与一个全球海洋箱，由淡水与温度边界条件驱动，经向翻转强度对盐度差反馈——仍是物理海洋学最有影响的对象，因为四行代数包含了整场争论。其定态解一个类三次平衡：在中等淡水强迫下有*两个*稳定环流（现代北下沉的"热"模式与反向或停摆的"盐"模式）被一个不稳定的隔开；把淡水强迫增加过一个折叠会崩溃强状态，而再次减小直到第二个更低的折叠才恢复——其后每个模式都复现的滞后环，从1990年代的灌水实验（Manabe–Stouffer的GFDL CO₂翻倍运行，环流在多数1990年代一代模式中减弱或死亡，以及Stocker–Wright与Rahmstorf稳定性分析）经过2010年代的EMIC到涡许可的CMIP6成员，阈值千差万别。该模式也编码了2023–24警报与AR6的和解：观测到的15%减弱是"接近折叠"还是"远离它的近线性响应"，取决于到分岔的距离，而这恰恰是还没有观测钉住的参数——"AMOC稳定性"问题归结为测量系统势的*曲率*，为此2024–25学派（Karabatsiotis与Lenton的淡水通量方差方法、2025年哥本哈根稳定性估计）正在提出恰好的基于阵列的协议。
::: solution
Stommel的教训是*结构性*确定与*参数性*无知之别。没人质疑盐平流反馈存在——它像温室效应一样确立——所以参数空间某处的双稳态近乎确定；没人知道折叠相对于强迫轨迹坐在哪里，而那个数字由涡输送、混合与风应力设定，即使2020年代模式也在数倍的分歧中。因此历史同时是对漠视与恐慌的警告：机制是真实的（模式与古记录一致），阈值是未知的（模式分歧），而观测计划是唯一能闭合差距的工具——这就是AMOC同时是临界候选中理解最好也最不确定的原因。
:::
:::

## 其他候选：冰、碳、森林、礁

2008年PNAS清单列了十五个全球"临界要素"；2022年*Science*特刊用显式阈值与概率判断裁剪了清单，而2024–25年全球临界点报告加入了*系统性*地球系统翻转的可能性——评估报告尚未承认的情景。下面的候选按其双稳态证据的强度排序，每个带着自己的诚实置信标签。

::: definition 冰盖：千年时钟上的阈值 {#def-ice-tipping}
格陵兰与西南极是*后果*最确定（数米的已承诺海平面，海平面一课[[climate-change/sea-level-rise]]覆盖）、*时间尺度*最不可用的要素。格陵兰表面融化阈值——表面质量平衡损失永久超过积累、海拔-反照率反馈接管的变暖——从模式系综与古约束（末次间冰期的5–6 m与上新世更高的海平面）评估为大约0.8–3 °C全球变暖、中心估计在1.7 °C附近（Armstrong McKay等2022范围；Smith等承诺分析），意味着该要素很可能已注定一次数米、数千年的后退——一个时钟走一万年的"翻转"、不是本世纪。西南极是相反的结构：海洋不稳定性几何（Thwaites与松树岛的倒退床）意味着*海洋*强迫已经交付的就把阿蒙森海扇区承诺给世纪尺度的后退（Naughten等2022发现1.5 °C水平的海洋增暖已在阿蒙森锁定），而完整的西南极崩溃（5米海平面）阈值评估在1.5–2 °C、低置信度、一到几个千年的时标。2022年*Science*特刊被引用最多的判词恰是这个两层陈述：在1.5 °C，"多个临界要素成为真实风险"，格陵兰与西南极冰盖及热带珊瑚礁被列为阈值*在*巴黎协定温度下就可能被越过的要素。评估报告坚持的诚实反向砝码：阈值数字是带50%以上相对不确定度的系综中位数，"已承诺"意味着按要素自己的时钟承诺（几个世纪到几千年），而让这些系统不可逆的滞后也让它们缓慢——两个性质是同一个物理。
:::

::: definition 永久冻土、亚马逊与礁：阈值上的碳、森林与生物 {#def-bio-tipping}
永久冻土碳条目是该领域被修正最多的。储量（约1,400–1,600 Gt土壤碳，约工业化前大气的两倍）是真实的且在融化；2000年代的"定时炸弹"框架——一次突然、自我维持的全新世式释放——被综合文献取代（Schuur等2022重新评估、AR6碳循环章节）：本世纪*全球*永久冻土通量在高排放下是渐进的5–15%库损失（预测一课标记为未量化风险的约5–55 GtCO₂/年CO₂+CH₄范围[[climate-change/projections]]）、不是分岔——*但*突然的微物理是真实的（热喀斯特塌陷、湖排、2024年*Nature*分析发现突然融化已影响三分之一的冻土带）、时标不对称（无论现在做什么减缓碳都在几个世纪里出来）本身就是承诺问题，而"永久冻土不是临界点"的判词是关于*本世纪全球预算*的陈述、不是关于所涉景观的。亚马逊是最有争议的森林候选。机制——毁林下风向水分再循环减少，把东南盆地从雨林推向稀树草原状状态——有真正的双稳态证据（东弧的卫星绿度与死亡趋势、Gatti等2021年*Nature*发现亚马逊东部现在*排放*CO₂、2005、2010、2015–16与2023–24事件的火-干旱反馈），而阈值文献（Lovejoy–Nobre 2018"毁林20–25%时翻转"分析，当前毁林约17–18%）把系统放在其提议边界附近令人不安的位置；2024年Gatti等模拟情景——最大毁林与变暖下到2100年东部90%枯死——被质疑为情景驱动，而AR6级别的判词对全流域突然翻转仍是低置信度、对毁林东南部的*区域*稀树草原转变是中等置信度。热带珊瑚礁是阈值数据最干净的生态临界要素：白化死亡率按热度周缩放，2023–25事件白化了约84%的礁区——有记录以来最大（NOAA与全球珊瑚礁监测网络2024–25报告）——而AR6高置信度陈述1.5 °C意味着70–90%损失、2 °C超过99%，让礁成为第一个*生态*阈值正在当前变暖下被实时越过的要素，2024–25年Lenton综合正式将其归类为在1.2 °C已翻转。2008年清单剩下的候选（北方针叶林、西非与印度季风、巴伦支海冰缘、以及厄尔尼诺-南方涛动本身）已被模式一代代的证据渐进降级——2008清单的季风"翻转"如今评估为渐进增强、巴伦支缘评估为无半球分岔的季节冰状态变化——让幸存清单可信的安静修剪。
:::

::: example 2022年特刊：共同体把阈值写进纸面 {#example-2022-issue}
2022年11月，*Science*发表了该领域历史上最重要的风险声明：Armstrong McKay等对数十个候选要素应用标准化协议（文献综述、专家征询、模式与古气候三角验证），得出结论：五个——格陵兰与西南极冰盖、热带珊瑚礁、北极永久冻土、以及拉布拉多海对流——的阈值在已经经历的变暖（1.1–1.2 °C）之内，越过1.5 °C（很可能本十年）让"多个"进一步要素（包括AMOC与亚马逊）处于"高风险"，而概率判断无论多么主观如今是*可审计的*：显式的范围、显式的置信度、显式的征询方法。回应勾勒了该领域的断层线。怀疑的批评（2022–23年*Science*与季刊的交锋）：阈值是带宽、常为对数正态尾的模式中位数；对一万年冰盖承诺而言"阈值已越过"不是本世纪事件；而征询概率（"AMOC在1.5 °C时10–35%"）是专家先验、不是频率。辩护者的回应（Lenton等2023–25答辩与2024–25全球临界点报告）：旧评估报告的"不太可能"语言本身就是征询、只是未记录；损失的非对称性要求可审计的主观性战胜不可审计的乐观；而2024年报告真正的新主张——*耦合的*社会经济-生态反馈（食物网贸易级联、保险撤离、化石燃料搁浅）可能把*整个*地球系统推向"温室"吸引子——被刻意放在评估系统的职权之外。
::: solution
特刊的方法论教训超出临界点：当一个问题的结构决定了模式或观测无法单独回答（阈值在实验之外），选择不是"没有答案"而是"哪种产出答案的方法认识论最不坏"——而带发表范围的显式征询在2023–25评论进行的每项审计中都胜过了它取代的隐性乐观。政策一课同样尖锐：一份带数字的阈值清单把预防原则从口号变成期望值算术，这就是1.5 °C政治与"临界点是炒作"行业如今都拿同样的十一页互相引用的原因。
:::
:::

::: example 2023–25白化：目睹一个生态阈值被越过 {#example-reefs}
第四次全球白化事件2023年1月在加勒比开始，随2023–24海洋热浪全球化（+0.2 °C的厄尔尼诺台阶加上长期趋势把海洋热含量推到每个海盆的纪录距平），而到2025年初NOAA珊瑚礁观测记录显示全球约84%的造礁区经历了白化水平的热压力——37年卫星记录中最大的范围，三大洋同时（2024–25年NOAA与全球珊瑚礁监测网络报告；从佛罗里达礁岛链——2023年海面温超过38 °C、数周内即致死——到西澳大利亚宁格罗与马尔代夫的大规模死亡2025年确认）。该事件对本课逻辑有三重意义。第一，阈值不是统计的是生理的：白化到死亡的关系（热度周、4/8 DHW阈值）是实验室测量的，所以与冰盖和AMOC不同，礁阈值没有结构不确定性——只有暴露。第二，响应*不*均匀：2024–25调查发现避难所（上升流礁、深水珊瑚组合、波斯湾预适应的耐热共生藻）与首批有记录的分布扩张（2024–25年佛罗里达与日本的向极地定殖记录），古生物学在过去超热事件礁崩溃中记录的、区分生态翻转与生态灭绝的"赢家与输家"结构。第三，反馈是真实的但是局部的：礁损失移除了沿海渔业的育苗结构（2024年综合估计2.5亿人的蛋白与海岸防御暴露），而死珊瑚的侵蚀降低礁顶快于再生能重建的速度——一个在*结构*中的滞后，即使*物种*幸存。
::: solution
白化时代是本课核心区分的案例研究：礁是第一个阈值越过正在被*观测*、不是被预测的要素，因为其阈值是当前变暖下被测量的生理——AR6的1.5 °C损失70–90%是一个暴露计算、不是分岔猜测。这是否构成"临界点"取决于保留的定义：生态系统状态（框架建造的礁）在地方尺度显示真正的滞后（藻主导状态抵抗再定殖数十年），而*气候*强迫不通过礁本身自我维持——反馈是社会-生态的（渔业、海岸侵蚀、失去的碳吸收）、不是地球系统的。诚实判词：礁是第一个进行中的*生态*翻转，也是最干净的演示——在1.2 °C，问题已从"阈值会被越过吗"移到"哪些、多快、避难所在哪里"。
:::

::: warning 临界点被扭曲的五种方式——恐慌者与自满者半斤八两
1. **两个含义的互换。**口语的临界点（任何要紧的阈值）与动力学的（自我维持、不可逆的状态转换）在论证中途被交易：头条引进第一个的恐惧与第二个的权威。每次都要问：是否声称了*人类时间尺度上的不可逆性*，按什么时钟？
2. **把"已触发"读成"正在崩溃"。**2022年五要素判词意味着阈值可能已被越过——对冰盖而言，在千年尺度上承诺数米。它不意味着格陵兰本世纪就完了。时标必须双向地随主张同行："已承诺"不是"迫在眉睫"，而"不迫在眉睫"不是"可避免"。
3. **虚假的精确。**被引成点的阈值（"亚马逊在毁林20%时翻转""AMOC在0.45 Sv时崩溃"）是带两倍范围与低置信度的系综中位数；诚实的陈述是阈值上的概率分布，而任何建立在点估计上的政策都建立在猜测的中位数上。
4. **分岔对速率的盲视。**系统可以仅凭*速度*翻转而没有任何阈值（速率诱导翻转），而有阈值的系统可以在远超旧点估计的缓慢强迫下幸存。单个"变暖度数"拨盘诊断不了任何一种模式——轨迹的速率与历史是要紧的，这就是过冲-回落之辩是真实科学问题、不是语义问题的原因。
5. **"极不可能"的倒置。**AR6的"2100年前AMOC崩溃极不可能"是一个关于文明量级结果的约百分之一到百分之一的陈述——即使1%也证明监测与应急是正当的期望值领域，正如它对洪水与大流行所做。把"极不可能"引成"不会发生"、或把2023年警报引成"预测了"，是同一个概率陈述的镜像误读。
:::

::: history 从Stommel的箱到温室之问：临界点科学的六十年 {#history-tipping}
思想谱系短小而显赫：Stommel 1961年箱模式（四个方程的双稳海洋）、Broecker 1975年"气候-冰期理论"（停摆作为冰期触发器的假说与第一次灌水推测）、以及1980–90年代的机制证明时代——Manabe–Stouffer 1990–99年的CO₂翻倍与灌水实验、Rahmstorf 1995年稳定性综合、以及Broecker 1993年*Nature*"巨大温盐灾难"短讯把突变词汇引入公众。古证据并行成熟：Heinrich事件地层学（1990年代Bond循环论文）、Blunier–Jouzel与Pedro–Brooks学派的双极跷跷板冰芯年表、以及8.2 ka事件2003–12年的溃湖模拟。"临界点"一词本身经Gladwell 2000年的通俗社会学到来、被2008年PNAS特刊为地球科学俘获（Lenton、Schellnhuber等的十五要素带阈值与时标的清单——创始文档），随后是2009–2012年关于其音调的"气候战争"（2010年哥本哈根诊断、AR5 2013年"中等置信度、阈值约束很差"的判词）。观测转向随仪器到来：2002–03年起的GRACE与ICESat格陵兰质量平衡、2004年起的RAPID阵列、亚马逊通量网络2005与2010年干旱论文、以及2015–16与2023–25年全球白化记录。2019–2025阶段是仍在进行的那个：Schellnhuber 2019年"地球状态"五个临界点论文、Lenton 2019年*Nature*"翻转临界点"随笔（2019–2022"转向希望"学派，刻意从可持续转型文献引进）、2022年*Science*特刊及其征询协议、2023年Ditlevsen AMOC警报与2024年批评、2024年Gatti亚马逊枯死情景、以及2024–25年全球临界点报告的温室之问——地球系统共同体第一次正式询问整个系统、而不是其部分，是否有吸引子，也是该领域最古老的仪器（箱模式）遇见其最新问题（一个挂着文明的行星）的时刻。
:::

::: quiz
一个系统在技术意义上被"翻转"仅当变化是：
- [ ] 大而快的
- [x] 通过内部反馈自我维持、且在移除触发因素后是持续的（在相关时间尺度上不可逆）
- [ ] 仅由外部强迫越过阈值驱动
- [ ] 被至少一个模式预测
::: solution
**自我维持加持续性**：大小、速度与模式支持既不必要也不充分——一个缓慢的、小强迫驱动的变化，若反馈接管且在强迫松弛时不逆转，就是一次翻转；一个大的、快速的、外部驱动的变化，若随强迫逆转（一次ENSO极值）就不是。滞后环是签名：系统的历史是要紧的，这正是临界点实际上不可逆的原因。
:::

## 练习

::: exercise {level=1 check="2.6"}
AMOC输送约17 Sv的体积；观测与指纹暗示自1950年以来约15%的减弱。它失去了多少Sverdrup的输送？
::: solution
0.15 × 17 = 2.6 Sv——大致是亚马逊河流量再乘几倍，七十年里从翻转环流中失去；让"减弱是真实的"生动、而不回答稳定性问题的数字（26.5°N阵列的内部变率在十年尺度上是±5 Sv）。
:::
:::

::: exercise {level=1 check="1.7"}
永久冻土土持有约1,500 Gt碳；现代大气持有约900 Gt。冻土库对大气库之比是多少？
::: solution
1,500/900 = 1.7——永久冻土储量比整个大气碳还多一半以上，这就是即使评估的渐进本世纪5–15%损失对碳预算也很重要、也是"定时炸弹"框架难死的原因：库的大小在其动力学已知之前就是故事了。
:::
:::

::: exercise {level=1 check="6"}
白化开始对应约4热度周（DHW）。如果夏季海表温度在漂白阈值上运行0.5 °C、持续12周，累计DHW是多少？
::: solution
0.5 °C × 12周 = 6 DHW——过了漂白阈值（4）、接近死亡阈值（8），让1.5 °C成为"礁损失70–90%"世界的算术：这一级海洋热浪曾是十年一遇，如今在多数礁上每世纪数次。
:::
:::

::: exercise {level=2 check="1.75"}
在灌水实验中，某模式的AMOC崩溃跟随北大西洋表面盐度持续约5%的降低。从35.0 PSU基线，该降低是多少PSU？
::: solution
0.05 × 35.0 = 1.75 PSU——所需淡水距平的大小，对抗1900年以来副极地表面水已观测的约0.5 PSU变淡（"距平走了三分之一"的统计，既助长又跑过警报，取决于模式实际用了哪个阈值）。
:::
:::

::: exercise {level=2 check="0.5"}
格陵兰已承诺的5 m最终海平面上升在约10,000年里达到平衡。隐含的平均速率是多少mm/年？
::: solution
5,000 mm / 10,000年 = 0.5 mm/年——每年温和，累加灾难性：末次间冰期的海平面在冰消期上升速率是这的几倍，而承诺算术的要点是*总量*、不是年增量。
:::
:::

::: exercise {level=2 check="0.2"}
在一个Stommel型模式中，AMOC崩溃发生在淡水强迫0.45（任意单位）、恢复需要强迫低于0.25。滞后范围的宽度是多少？
::: solution
0.45 − 0.25 = 0.20单位——两个状态都稳定、由历史决定的滞后带。在其中，"AMOC安全吗"不知道系统从哪里开始就没有答案，这就是"它在模式中恢复了"与"它在模式中崩溃了"对同一强迫可以都为真的原因。
:::
:::

::: exercise {level=3 check="70"}
2023年Ditlevsen AMOC分析给出2025–2095的95%崩溃窗口。窗口的宽度是多少年？
::: solution
2095 − 2025 = 70年——一个宽到同时与"本世纪极不可能"与"世纪中叶崩溃"相容的范围，是这篇论文为何同时是当年最令人不安也最不可证伪的陈述、以及批评者为何攻击区间的构造而不是其中值的可视化。
:::
:::

::: exercise {level=3 check="0.06"}
一个风险框架评估P(2150年前AMOC崩溃 | 变暖超过2 °C) = 0.1、P(本世纪超过2 °C) = 0.6。2150年前崩溃的非条件概率是多少？
::: solution
0.1 × 0.6 = 0.06——6%的半球量级状态转换机会。期望值要点：以文明量级的损害，6%证明大量监测与预防支出是正当的，即使如果它不发生"不太可能"将是正确的事后用词——风险三角一课[[natural-hazards/risk]]为一个新危险类别形式化的决策理论。
:::
:::

::: exercise {level=3 check="3"}
亚马逊稀树草原转变阈值评估在流域毁林20–25%；当前毁林约17%。多少个百分点的额外毁林到达阈值范围的下界？
::: solution
20 − 17 = 3个百分点——大约当前砍伐速率的十年，让亚马逊成为罕见的*局部*驱动因素（毁林、火、伐木）与全球因素（变暖）同样决定性的临界候选、也是局部政策杠杆最大的一个。
:::
:::

AMOC在真实世界中有*双稳态*的最强证据来自：

- [x] 冰期-间冰期大西洋突变变化的古记录加模式滞后环
- [ ] 2023年统计早期预警信号
- [ ] 2011年以来的卫星盐度图
::: solution

::: summary
- 临界点是技术的、不是修辞的：越过关键阈值的自我维持、持续的制度性状态转换，滞后是其签名——而该领域诚实的清单把有真正双稳态证据的系统（AMOC、冰盖、礁）与阈值是模式假象的系统（季风、2008年清单的大部分环流条目）分开。
- AMOC是参照案例：盐平流反馈与古记录让双稳态近乎确定，观测到的约15%减弱是真实的，模式说本世纪崩溃极不可能，早期预警统计说窗口可能是开着的——而分歧在于折叠坐在哪里，只有不断增长的观测系统能定论。
- 2022年阈值审计改变了该领域的认识论：显式、征询、可审计的范围取代了隐性乐观，而其判词——格陵兰、西南极、珊瑚礁与永久冻土在1.1–1.2 °C可能已过其阈值——最好读作按要素时钟的承诺、不是按我们时钟的崩溃。
- 时标就是全部故事：礁正在翻转（生态的、数年），亚马逊东弧在区域性转变（数十年、毁林驱动），冰盖为千年承诺，而永久冻土"炸弹"是一根带突然引信的慢引线——一个词，五种物理。
- 在非对称损失下，"极不可能"是监测的理由、不是停止担忧的理由：监测阵列、阈值审计与早期预警计划比其所针对的结果便宜几个数量级——通往响应一课[[climate-change/responses]]的桥与[[natural-hazards/risk]]的风险逻辑。
:::
