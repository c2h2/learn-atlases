减缓是气候问题中评估报告能用工程与价格、而不是概率说话的那一部分，而2022–23年AR6第三工作组的判词因此是文献中最奇怪的文档：*科学与经济不是障碍*。章节级事实：多数低排放选项比它们取代的照常选项便宜（电力终端、效率、太阳能与风能、需求措施）；核心可再生能源的成本在2010–2019年间下降85%（太阳能）、55%（风能）、64%（电池，电芯价格）；世界在各区域的执行能力都在改善；然而2001年以来每个主要评估都记录了模型化路径与已执行政策之间不断加宽的差距——让排放曲线成为该领域最诚实图表的"部署差距"。本课按评估报告的方式读减缓组合（供给、需求、移除），然后是适应账簿（选项、资金、极限），终结在选择的算术：预算、价格与承诺实际承诺了什么、以及"净零"的语言在哪里跑赢了实现它的计划。

## 减缓账簿：选项、成本、与部署差距

::: definition 减缓经济学：成本曲线、学习、与价格差距 {#def-mitigation-economics}
边际减排成本曲线——按每吨减排成本排序的选项，负成本（省钱）选项排前——是评估报告的组织工具，而其AR6读法是曲线的左端如今是巨大的：能源效率、油气甲烷减排（2021年全球甲烷评估：约40%的化石甲烷排放可以负成本减排）、以及需求削减都在资产寿命内省钱。更深的经济学是**学习**：制造技术遵循Wright定律（成本按累计产量每次翻倍下降固定百分比——组件与电池约20%/翻倍），它以十年的滞后把部署政策变成成本政策，这就是2020年代文献把2010年代德国与中国太阳能计划读作带全球回报的气候*投资*的原因（2021–23年Mercator与能源清洁空气研究中心对早期上网电价学习外溢的分析）。政策工具经济学：碳定价使外部性内部化，而2023–25审计（世界银行碳定价报告、2023年*Science*评估）发现约70多个体系只覆盖约23%的全球排放、**中位价格低于10美元/tCO₂**，对抗50–200美元的社会成本估计（美国跨部门2024年临时数字约200美元）——让碳定价成为评估报告中利用最不足的成本有效工具的"价格差距"。而非价格工具无论如何干着主力活：可再生能源配额制、建筑规范、车辆效率标准与公共研发贡献了已实现的绝大部分减排（政策评估文献的准共识：2019–2022年*Nature Energy*与*Research Policy*对什么真正使电网脱碳的评估——是标准与授权、不是价格，在欧盟电力部门与加州干了大部分活）。前沿概念是**不作为的成本对转型的成本**：搁浅资产文献（2022–24年碳预算一致性分析：化石储量比任何1.5–2 °C路径允许的开采多值约1–4万亿美元——"不可烧碳"问题）与宏观金融学派（2017–19年Carbon Tracker与NGFS压力测试）把减缓支出重构为针对减记的保险、不是成本。
:::

::: definition 能源与需求组合：供给选项、储能、与40–70% {#def-energy-portfolio}
**供给。**AR6的供给侧排序在成本上不含糊：太阳能与风能在多数市场如今是最便宜的新电力（2023–25 LCOE数据集：公用事业太阳能20–50美元/MWh、陆上风电30–60美元，两者都低于同市场现存煤电厂大部分机组的边际运行成本），而2023–24部署证实了经济学——可再生能源在2023–24年供应了全球新增容量的约90%（IRENA与Ember记录：2023年新增约510 GW、2024年约580 GW，三分之二是太阳能），中国2023年装的太阳能比2022年全世界还多。可调性问题真实且可解决：组合是储能（锂离子电池包价格2010–2024年下降约88%，2024–25年储能新增每年三倍；2025年电网级机队逼近100 GWh）、灵活需求与输电（美国、欧洲与中国的约束是并网排队与电网建设速率、不是发电——2023–25电网研究：接入积压是装机容量的数倍）、选址许可允许的水电/地热/生物质能、以及**核能**——其评估事实是：生命周期排放约4–12 gCO₂/kWh（一切稳定电源中最低）、2022–23年兴趣重启（2023年COP28 22国"核能三倍"承诺；2021–25小型模块化反应堆热情对抗2020年代成本证据——Flamanville与Vogtle超预算2–4倍、2024–25年SMR首堆延期），而诚实判词是核能经济学是一个建设成本故事（2016–2022年Sovacool与Lovering分析）、其系统价值随可变可再生份额上升。**需求。**AR6最少被报道的数字：需求侧措施——效率、供热与交通电气化、材料效率、循环、以及更难的"充足性"措施（2022–23年*Nature Energy*文献：2022年IPCC章节把2050年终端部门减排潜力的40–70%记在需求措施上）——便宜、快、且相对供给长期资金不足（2023年IEA：效率投资在2020–23年首次下降，而太阳能投资翻了三倍）。电气化算术是本世纪的主戏：车辆与供热的直接电气化（2023–25年EV销量：2024年1,400万辆、中国份额约40%、2024–25电池价格跌破100美元/kWh包）加清洁电力是最大的单一模型化减排杠杆，而其可行性如今是工程共识（2021–25年100%可变可再生能源电网研究、丹麦/葡萄牙/英国整合示范），其残余障碍是政治经济学：许可、电网电价、以及化石产业政策的路径依赖。
:::

::: example 太阳能学习曲线：史上最便宜的技术转移 {#example-solar}
晶体硅组件1976年售价约106美元/W（美国空间太阳能与早期地面市场）、2024年约0.10美元/W——下降99.9%，能源史上最陡的持续成本下降，遵循学习率约每次累计产量翻倍降20–24%的Wright定律（2010–2023年成本经济学文献：Nemet、Wustman/Gregory-Hansen与2023–25更新）。因果史就是政策一课：需求在自持之前被制造了两次——1974–2011年的日本与德国家庭计划（1974年日本阳光计划、2000–2004年德国上网电价创造了第一个可融资的大众市场）、然后2006年起的中国产业政策（2006–09年多晶硅与晶圆扩产、2013–18中央补贴）驱动了2011–2014价格崩塌，杀死了西方补贴时代的制造商、让电网平价不可避免。到2023年，用2023年IPCC的话说，太阳能在多数阳光充足的市场是"史上最便宜的电力"，而2024–25年组件供应过剩（价格一度低于现金成本、2024–25年中国一线企业整合）是一项技术长过了自己经济学的病症。剩下的前沿是学习曲线无法单独修好的那些：制造业自身的脱碳（多晶硅与石英锭的能耗、2024–25"绿色多晶硅"水电迁移）、供应链集中度（中国在若干环节约80–95%份额——2023–25能源安全反动员）、以及太阳能份额越过约30%时到来的整合成本（鸭子曲线、储能配对、加州与澳大利亚2024–25"负电价小时"——便宜能源开始花钱的时刻，一句话的电网组合论）。
::: solution
太阳能案例是本课对"脱碳负担得起吗"的回答：对最大的单一排放源（电力）与最快扩张的技术，答案在一个十年内从否翻为是，靠政策驱动的学习——收益是全球的而成本是国家的——这个搭便车结构既解释了2010年代气候研发投资不足（2019–24年Goulder–Nordhaus谱系对清洁能源研发外溢的评估：公共清洁能源研发按外溢经济学被低估4–10倍），也解释了2022–25产业政策转向（美国IRA与欧盟绿色协议产业政策计划是第一次把外溢*定价*进部署的尝试）。评估报告直白写明的推论：单靠太阳能不能让电网脱碳，而必须跟随其后的技术（稳定储能、电网级长时储能、清洁工业热）现在就需要同样的学习补贴，趁它们的成本曲线还在太阳能1990年的位置。
:::
:::

::: example 能源转型：最大的电网脱碳实验的三十年 {#example-energiewende}
德国的上网电价（2000）及其后继工具建成了世界最大的早期可再生能源部署——2000–2014年太阳能繁荣驱动了全球组件价格下降（2021–23学习外溢分析把早期累计需求的相当份额归于德国补贴）、让陆上风电在全欧洲变便宜的风电机队、以及到2024年可再生能源供应公共净发电量约55–60%的系统（Fraunhofer与AG Energiebilanzen清点：2023年52%、2024年约59%，太阳能与风能2022年首次超过煤）。它也演示了评估报告如今编目的失败模式：2011年核电关停（福岛后的决定，短时间内移除了约15%低碳供应并延长了煤的寿命——2021–23年后评估（DIW与*Nature Energy*谱系）发现退出强加了温和但持续的排放代价与数十亿机会成本，而2023年最后三座反应堆关停因太阳能激增对电网影响微乎其微）、EEG附加费的分配政治（家庭电价涨三倍到欧盟最高、让体系累退且在法律上有争议的工业豁免）、输电瓶颈（晚了15年的南北电力走廊）、以及2022年燃气危机（快速削减了用气但暂时再煤化，而据2023–24年回顾，永久激进化了建设：2022–23"复活节一揽子"与2023年可再生能源加速法）。来自评估文献的2024判词（2023–25年Agora Energiewende与2024年*Joule*评估）：能源转型的头二十年是*部署*成功与*设计*教育——成本在全球下降，德国排放比1990下降约40%（其中三分之二来自1990年统一的去工业化与气代煤，排放核算辩论不断重新争执的事实），而2020年代再设计（经欧盟ETS传导的碳定价、2030年80%可再生目标、许可加速法）是第二个实验：一个成熟工业经济体能否以十年的日程使其热、交通与工业脱碳。
::: solution
能源转型的教训就是框架的教训：排序重要（在储能与电网就绪之前关核电，损失大于收益），设计比口号重要（上网电价的学习外溢是全球的而其附加费是累退的——协同效益与分配是政策选择、不是物理），而*示范*效应本身就是减缓工具（2013–2020媒体周期的"德国在失败"文体没有延误任何路径，而2023–25德国成功的文体——太阳能蚕食靠储能拍卖解决、煤退出立法到2038——如今是可出口的产品）。2024–25的未决问题是每个后工业化经济体面对的：电网、工业热与交通层能否以第一层（电力）经验显示可能的速度移动，还是难减排部门是不同的物理与不同的政治。
:::
:::

## 移除、适应、与选择的算术

::: definition 二氧化碳移除：组合、潜力、与道德风险 {#def-cdr}
AR6的1.5 °C中心路径全部包含二氧化碳移除——在无或有限过冲守住1.5 °C的路径中位约0.5 GtCO₂/年（到2050），而依赖过冲的组别跑到数GtCO₂/年——评估的组合分成画像相反的两族。**基于陆地的移除**（再造林与造林、土壤碳、蓝碳、避免采伐）便宜（10–100美元/tCO₂）、交付协同效益、且受土地竞争限制（AR6可持续土地潜力约2–5 GtCO₂/年，不确定性大）、受不持久限制（2020–23火灾与干旱逆转：2021–23年加拿大与西伯利亚火季在单一年份把管理森林变成净源）、以及核算诚信——2023–24年避免毁林信用的审计（West等2023年*PNAS*分析：多数基线毁林主张被夸大；2023年5月对最大登记处旗舰方法的调查系列，以及2024–25登记处改革与诉讼）如今是"如何不建一个移除市场"的案例研究。**工程移除**——生物质能碳捕集与封存（AR6可持续潜力约0.6–5 GtCO₂/年，2023–25示范机队接近零——最大的近期项目是伊利诺伊乙醇-DAC枢纽与2023年英国政府支持的Drax提案，后者违背气候变化委员会建议获批）、直接空气碳捕集与封存（DACCS在2023–25工厂经济学中300–1,000美元/tCO₂——冰岛Orca/Mammoth与2024–25美国超级站点许可记录；使选址成为约束的能源与水需求）、增强风化、生物炭、与海洋碱化（2023–25田间试验治理之争）——是永久的、原则上可扩的、且昂贵到未经验证，而2022–24"移除承诺"文献（2023年*Nature*通信：G7 2035年5 Gt移除目标超过每个可信供给估计一个数量级）记录了政治与物理可行性之间的差距。**道德风险**问题是评估的、不是修辞的：2016–2024文献（McClaren学派"牺牲区"与延误分析；2023–24计量检验）发现大规模移除承诺已经与更弱的近期目标相关——算术是任何假设未来移除的预算都在提前花掉它，而2023年综合报告的发现（按2022–2025速率，50%概率的1.5 °C预算在约三年内耗尽）就是核算校正。
:::

::: definition 适应：选项、资金差距、与极限 {#def-adaptation}
AR6适应章的结构是一份可行性目录：对每个系统（海岸、水、农业、城市、健康、保险）它列出带成本、成熟度与极限的选项，而其判词是**实施在处处落后于可行性**——2023–25年UNEP适应差距报告把发展中国家需求放在2030年约2,000–3,700亿美元/年，对抗约500亿美元/年的国际流量（4–7倍差距；2021年"适应资金翻倍"承诺后2022–23流量两位数百分比增长仍未满足倍数），而2023年*Nature Climate Change*审计（Bhag等）发现主要捐助方的适应资金大量是被错标的援助，2019年Young等组合审计发现被评估的适应项目只有约39%可测量地降低了脆弱性。选项类别：结构性的（防御工程、排水、水基础设施——荷兰"河流空间"，1993/95年莱茵-默斯洪水后23亿欧元的洪泛区再连通与"三角洲标准"风险设计，如今是顺应自然的教科书）、制度性的（早期预警——2022年WMO发现一半国家缺乏多灾种系统后的2022–23"人人享有早期预警"倡议；保险与社会保障——2023年保险未来报告：保险只覆盖发展中国家灾害损失的一小部分）、基于生态系统的（红树林与珊瑚礁保护——2021–24协同效益分析：红树林的风暴潮衰减值数十亿，但在>2–3 m潮与海平面上升所需的沉积物供给处有极限）、以及计划迁移（2019–25年太平洋与西非迁移——斐济村庄迁移的法律议定书、"有尊严的迁移"的2023–25损失与损害框架）。**极限**分类法是评估最具后果的概念产出：*软*极限（选项存在但未实施——资金、制度、信息）对*硬*极限（没有适应能保住系统——小岛的淡水透镜体、珊瑚-藻相转换、2022年第二工作组发现硬极限在最脆弱系统中*已经在被触及*、并将在更多系统于1.5 °C被越过）。适应-减缓关系是凸的：SR1.5与AR6成本章节发现适应成本与残余损失随温度陡升（2018年特别报告的头条：把变暖限制在1.5而非2 °C*减少适应需求*，逐部门量化），这就是减缓是最深适应的准确意义——而2022–23"损失与损害"的制度化（COP27基金决定、2023–25过渡委员会关于基金是新增额外还是改标援助的争执）是针对残余的第一个全球工具。
:::

::: example 孟加拉国与荷兰：两个三角洲里的适应分水岭 {#example-deltas}
1970年博拉气旋在当时的东巴基斯坦三角洲杀死30–50万人；2007年Sidr与2009年Aila风暴在同一个国家、相当或更强的风暴潮下杀死约3,500与不足500人；2020年代气旋死亡人数在相当强度下以十到百计（WMO与孟加拉国灾害管理记录）。机制是发展经济学中被复制最多的适应故事：1972–2020年建成约700座多用途气旋避难所、社区早期预警链（1980–90年代红新月会与GP20/25志愿网络）、堤坝计划（5,000多公里，以粮食援助劳动维护）、以及1991年后的常设气旋计划架构——一个48小时转移百万人的体系，其残余失败（2007年Sidr死亡集中在避难所不可达、预警迟到的地方）本身就是适应有效性文献的主题（2015–2022年*Nature Sustainability*与ICPSR评估：死亡率降了两个数量级，资产损失*上升*因为暴露增长快于防御——教科书级的危险-暴露背离）。荷兰是同一故事在收入尺度的另一端与关于极限的同一课：一千年的圩田工程（1953年死1,800人的风暴潮后的三角洲工程，然后1993–95年莱茵-默斯洪水迫使23亿欧元"河流空间"计划——降低洪泛区而不是加高堤坝，其完工后评估如今是"顺应自然"的教科书评估）、2021–25年三角洲计划的2050适应路径文档（河流空间后续计划与艾瑟尔湖淡水措施）、以及2021年RMMV/Deltares陈明硬极限的研究：在+2 m海平面下，三角洲的淡水收支、不是它的堤坝，成为约束——富裕国家版的小岛之问。
::: solution
两个三角洲教适应账簿的两半。孟加拉国证明脆弱项即使在贫困与上升的暴露下也是可解的——死亡率下降是任何地方对任何气候政策最大的已证明回报之一，也是适应资金差距（需要的数千亿对抗实际的数百亿）是文献中性价比最高的不公正的原因。荷兰证明财富买到的是时间与选项、不是免疫：荷兰三角洲标准（万年一遇洪水风险设计）是世界上最保守的，而其自己的科学家发表它的极限——高海平面下的淡水收支（2021–24年Deltares与国家评估分析）正在成为约束、先于堤坝，而2021年阿尔河谷灾难——德国一个几十年未升级防御的区里五百年一遇的洪水，紧邻万年一遇的荷兰设计哲学——落实了这一点：设计标准是关于*模型化的*未来的陈述。简言之，适应是风险方程中政策起效最快、而物理最终说不的那一项。
:::
:::

::: example 净零承诺与碳市场：诚信的十年 {#example-net-zero}
到2023年，净零承诺架构覆盖约88%的全球GDP与约83%的排放（2023年净零追踪与联合国记录）——而2023年审计发现架构是空的：2022年*Nature*研究（Hale等）发现只有少数国家承诺拥有与其目标一致的政策，2022年排放差距报告发现少数国家的2030 NDC甚至未被完全执行；2023年企业审计（Bailey等，*Climate Policy*/牛津）发现72%的企业净零目标没有任何近期计划；而2023–24"碳中和"诉讼与监管浪潮（2023年欧盟与英国漂绿裁决、2024年FCA与SEC披露之争）叠加在2023年抵消市场诚信危机之上（West等2023年*PNAS*避免毁林分析；2023年5月登记处调查；2024–25年ICVCM可信标准与2024年VCMI企业主张改革）。2024–25年校正就是活实验：2024年牛津净零主张政策指南（"超越抵消"层级——先减排、只中和残余、绝不用作主张来补偿）、2024–25年欧盟绿色主张指令、2024年第六条第2款首批签发交易（2024年1月新加坡-巴布亚新几内亚转让、2024年加纳-瑞士协定，其环境诚信被2024–25年*Nature*与Carbon Brief审计质疑）、以及2024–25年国内排放现实检查（2023–24年全球碳预算：化石CO₂在约37 GtCO₂平台——既不是2010年代上升的曲线、也不是承诺暗示的下降曲线；2024年Ember发现2023年全球电力部门排放出现第一个持续下降年，因为太阳能与EV跑赢了需求）。
::: solution
诚信十年的教训是评估报告巡查的区分：*目标*是一个模型化的未来，*路径*是一个政策组合，而没有第二者的*承诺*是一个偏好的陈述。2023–25改革（标准、披露、诉讼）是让三者可比的第一次尝试，而经济逻辑与学习曲线逻辑反着相同：资本配置、保险定价与公共政策如今都依赖主张可审计，这就是核算之争（什么算移除、什么基线、什么泄漏）不是官僚主义的原因——它们是1.5 °C预算在纸面上存在或不存在的地方。对2025状态的诚实总结：承诺覆盖了排放，政策覆盖其中三分之一，而差距是下一个十年政策科学的主题。
:::

::: warning 响应主张被扭曲的五种方式——乐观者与阻挠者半斤八两
1. **以潜力偷换部署。**"技术潜力是当前需求3倍"与"技术已就绪"都为真、且在没有部署问题——电网排队、许可、资金与在位者——时都无关。评估报告"可行且便宜"的语言关乎选项；排放曲线关乎实施，而两者之间的差距才是政策科学的真正主题。
2. **道德风险的倒置。**移除与抵消同时是必要的（每条1.5 °C路径都用它们）与危险的（对它们的承诺延误减排）。化解是算术、不是修辞：移除必须*额外、永久、并计入其声称抵消的预算*——2023–25诚信改革是执行这句话的第一次尝试。
3. **"最便宜的电源"不等于"最便宜的系统"。**太阳能的LCOE不含整合（储能、备用、电网加强、负电价小时的蚕食），而诚实的系统成本文献（2020–2024年*Joule*与*One Earth*整合成本研究）发现溢价真实但在缩小——而镜像错误（"间歇性，因此昂贵"）无视了参照级（煤加上它自己的输电、燃料价格风险与健康成本）在2020年前后已输掉争论。
4. **把承诺读成计划。**没有2030政策栈的2050净零是一个没有载具的目的地——2023年审计的发现不是承诺无价值（它们锚定资金与监管），而是*只有近期政策栈是证据*，而2024–25披露制度正是为让资本看清差别而存在。
5. **适应资金的三仙归洞。**从几十亿基数"三倍适应资金"、把改标的发展算作适应（2022–23年Bhag等*Science*与*Nature Climate Change*发现）、把灾害*响应*算作*适应*——这三个手法让4–7倍差距在声称其正在缩小的头条中存续。2023年全球适应目标指标与2024–25需求本位评估是审计工具；差距才是数字。
:::

::: history 从多伦多到第一次全球盘点：响应政策的四十年 {#history-responses}
制度史始于1985年维拉赫与1988年多伦多会议（多伦多"变化中的大气"会议的20% CO₂稳定化承诺——第一个，也是其后每个未兑现承诺的模板）、1990年IPCC第一次评估与1992年里约UNFCCC（"危险人为干扰"授权与至今仍在结构化每场资金之争的"共同但有区别的责任"交易）。1997年京都议定书发明了工具集——附件一国家的约束目标、排放交易、清洁发展机制——并因95比0的伯德决议失去了美国、欧盟ETS 2005年第一阶段（2006–07暴利与价格崩盘一课，教出了配额设计一代）、以及2009年哥本哈根崩盘（捕获了2 °C目标、作出了1,000亿美元/年资金承诺又落空、该协定的111国准共识成为2015年巴黎架构）。2010–2015十年是安静也是决定性的十年：京都第二承诺期（多哈2012，无牙）、欧盟20-20-20一揽子、没有任何条约造成的美国页岩与效率排放下降、以及做学习曲线该做之事的太阳能曲线。2015年巴黎协定的倒转——自下而上的国家自主贡献、一个棘轮、一个透明度框架、其科学操作化来自2018年SR1.5的1.5/2 °C温度目标——把问题从条约合规变成路径治理，而2018–2023浪潮（2019年欧洲绿色协议、2021年美国重返与基础设施法、2022年IRA 3,690亿美元气候产业政策、2022–25中国清洁技术出口主导）是政策科学文献当前的主题（2023–25年*Science*与*Nature*对碳定价对产业政策作为2020年代决定性工具选择之评估）。2021–23年格拉斯哥-沙姆沙伊赫-迪拜序列写下了终局语言（"逐步减少未减排煤电"（2021，第一个点名化石燃料的条约文本）、损失与损害基金（2022）、第一次全球盘点的"在能源系统中逐步脱离化石燃料"（2023，附带可再生三倍与效率翻倍承诺）——而2024–25执行周期（2025年到期的新NDC、2025年对盘点的盘点）是关于棘轮是否棘紧的活实验：2024–25年全球碳预算的平台与2024年电力部门排放下降是政策栈已把全球曲线折弯的最初数据，而2025年承诺的总量缺口说明弯曲还不是预算要求的斜率。
:::

::: quiz
"净零CO₂"在何时达到：
- [ ] CO₂排放比1990年水平下降45%
- [x] 人为CO₂排放与人为移除相抵，累计排放停止增长
- [ ] 所有能源都是可再生的
- [ ] 非CO₂气体被消除
::: solution
**排放=移除**：净零CO₂停止累计CO₂的增长、并（在其他强迫保持下）大致停止变暖——使其成为有物理意义的目标的近线性温度-预算关系。评估报告附带的告诫：残余非CO₂气体（甲烷、氧化亚氮、航空）也必须下降温度才能守住，过冲在净零之后仍留下承诺的上升，而把总减排藏在未核实抵消之后的"净"主张倒转了物理——诚信十年的一课。
:::

## 练习

::: exercise {level=1 check="1000"}
太阳能组件价格从1976年约106美元/W降到2024年约0.10美元/W。大约降了多少倍？
::: solution
106/0.10 ≈ 1,000倍——下降99.9%，能源史上最陡的成本曲线，也是2023年评估报告中每句"太阳能是史上最便宜的电力"背后的数字。
:::
:::

::: exercise {level=1 check="0.512"}
一项技术遵循学习率20%的Wright定律（累计产量每翻倍成本降20%）。如果累计产量增加八倍（三次翻倍），单位成本降到多少倍？
::: solution
0.8³ = 0.512——产量增八倍成本减半。让早期部署政策（补贴、授权）成为该技术未来价格首付的算术，也是2000年代德国太阳能计划被读作全球气候投资、不是德国能源政策的原因。
:::
:::

::: exercise {level=1 check="600"}
2023年评估报告称太阳能组件成本在2010–2019年下降85%。从2010年4,000美元/kW的成本，2019年成本是多少美元/kW？
::: solution
4,000 × 0.15 = 600美元/kW——太阳能在多数市场低于煤运行成本的水平，2023–24部署浪潮（90%新增容量是可再生）只是报告了的经济事实。

::: exercise {level=2 check="165"}
AR6把2050年终端部门减排潜力的40–70%记在需求侧措施上。用中值，一个300 GtCO₂的终端部门基线中需求措施可减排多少GtCO₂？
::: solution
55% × 300 = 165 GtCO₂——大于任何单一供给侧选项，也是让2023年发现（效率投资在太阳能投资翻三倍时*下降*）成为评估报告中最令人惊讶的错配的数字。

::: exercise {level=2 check="4"}
发展中国家适应需求估计到2030年约2,000亿美元/年，而国际适应资金流量约500亿美元/年。缺口倍数是多少？
::: solution
200/50 = 4倍（UNEP差距报告范围4–7倍）。让适应资金之争成为算术而非修辞的数字——以及2021年"适应资金翻倍"承诺的算术：从200亿翻到400亿仍未满足倍数。
:::

::: exercise {level=2 check="40"}
美国跨部门2024年临时碳社会成本约200美元/tCO₂；现存碳价中位约5美元/tCO₂。之比是多少？
::: solution
200/5 = 40倍。评估判词"碳定价是利用最不足的成本有效工具"背后的价格差距量级——以及让"定价已死、产业政策万岁"（2023–25年*Science*之辩）成为活问题而非定论的政治经济学量级。

::: exercise {level=3 check="12.5"}
从2020年初起1.5 °C（50%概率）的剩余碳预算约500 GtCO₂；全球CO₂排放跑在约40 GtCO₂/年。预算按当前排放能撑多少年？
::: solution
500/40 = 12.5年——2030年代初耗尽，2023年综合报告的头条算术。保持诚实的告诫：预算针对*全部*CO₂（37 Gt的化石份额让时间略长），非CO₂强迫让其缩短，而每条在2030年代之后"守住"1.5 °C的路径都在花尚未买到的移除或过冲。

::: exercise {level=3 check="2.5"}
1.5 °C路径到2050年使用约5 GtCO₂/年的移除中值；当前人为移除约2 GtCO₂/年（几乎全是林业）。需要多大的扩产倍数？
::: solution
5/2 = 2.5倍——直到注意到*质量*转变之前显得温和：这2 Gt是基于陆地且不持久的，而路径的后半倚重工程移除，其2025年机队约0.01 MtCO₂/年——永久部分五个数量级的扩产，G7 2035年5 Gt移除承诺（2022）从未与供给预测调和的数字。
:::

锂离子电池包价格在2010–2024年下降约88%。从2010年1,100美元/kWh的包价格，2024年价格是多少美元/kWh？
::: solution
1,100 × 0.12 = 132美元/kWh——低于长期被引为车辆燃油车平价地带的约150美元/kWh门槛，也是2024–25年EV与电网储能需求曲线、不是政策目标，成为2020年代末排放故事的原因。

- [x] 存在许多可行有效的选项，但实施处处落后，资金短缺4–7倍，而硬极限已在最脆弱系统中被触及

::: summary
- 减缓经济学在一个十年内翻转：多数核心选项（太阳能、风能、电池、效率、电气化、甲烷减排）如今成本可比或省钱，2023–24部署记录（90%新增电力容量可再生、EV每年1,400万辆）是学习曲线的兑现，而约束已移到电网、许可、资金与政治经济学。
- 差距是实施、不是可行性：承诺覆盖约83%的排放、政策只覆盖一部分、碳价比社会成本低约40倍，而2023–25诚信十年（抵消审计、净零核验、第六条之争）是让主张可审计的第一次尝试——因为纸面上花掉的预算仍是花掉了。
- 移除在同一句话里既是必要的又是危险的：每条1.5 °C路径都用它们，当前供给比永久部分的需求短四个数量级，而移除承诺与更弱近期目标之间的道德风险相关是评估的发现、不是口号。
- 适应是政策起效最快（孟加拉国两个数量级的死亡率下降）而物理最终说不（荷兰淡水极限、礁转换、已被触及的硬极限）之处——带一个4–7倍资金差距，文献中最便宜的大数字正义失败。
- 响应账簿闭合了课程的论证：预算有限且几乎花完，工具就绪而被少用，原因与损害的分布是中心政治事实，而2020年代是承诺与路径之差变成全部主题的十年——本课程不以预测、而以一次核算结尾的原因。
:::
