本课程每一堂资源课都描述过一次开采；没有一堂记过账。这就是那本账：把矿产、煤、油与气取出来的地表与地下遗留——数万座在产矿山与数十万口井，其废石、尾矿、卤水、沉降坑与无主套管定义了整片区域的水化学与土地经济学——以及试图给这笔账定价、预防与清理的年轻工程与法律科学（1970年代起）。这门学科建立在一个残酷的不对称上：开采收入在几十年里到来，而负债——产酸的废石、尾矿坝、含水层里的污染羽、没有所有者的井——持续几个世纪、并活得比造成它们的公司更久。本课走过四大影响类别（景观与废物；酸性矿山排水；溢油与采出水；沉降、甲烷与无主井遗留），每个都配上其监管弧线与标志性灾难：Brumadinho与Fundão的尾矿流、Butte的Berkeley坑与Tar Creek的铅、从Exxon Valdez到Deepwater Horizon的200亿美元清算、以及德国与英国的煤遗留水。先修是[[earth-resources/resources-reserves]]一课（负债是储量账的另一面）与[[earth-resources/groundwater-resources]]一课（多数开采影响说到底是水影响）。

## 景观、废石、尾矿

::: definition 采矿的质量平衡：扰动、废物、与尾矿问题 {#def-waste}
采矿由它的废物定义。**剥采比**（每单位产品剥离的废石）从厚煤层的1以下到斑岩铜的约10:1、露天金的100:1以上——意味着一座2020年代每年移动5亿吨岩石的铜矿产出几千万吨的磨矿给料、而把其余留下放置、排水与稳定；露天坑以立方公里级的地貌终结（Bingham Canyon约2.7 km³，其2013与2021年的边坡失稳重写了它的边坡设计），而地下矿山在地表留下沉降槽——煤长壁开采的米级凹陷，使鲁尔与约克郡的赔偿账本成为财产法的一个永久分支。两个永久遗留是**废石**——倾倒在工程化山丘里的无矿岩石，其边坡与地球化学必须保持几千年，这是1980–90年代"地貌复垦"学派（澳大利亚Hunter Valley的Bell与同事，他们由自然边坡的几何重建稳定地貌）的设计哲学——以及**尾矿**，磨矿后剩下的砂与粉砂部分，与工艺水混合、泵入围库。2019年EarthEye雷达普查数出全球约3,600座尾矿设施，而失事记录是它们现在成为董事会级风险的理由：1966年威尔士Aberfan的煤矸滑坡杀死116名儿童并创立了矸石堆法；2015年Fundão溃坝（Samarco）把4000万吨铁矿尾矿沿Doce河送到大西洋，杀死19人、终结了一个渔业经济；而2019年Brumadinho溃坝（Vale的Córrego do Feijão坝）杀死270人、掩埋了一座职工食堂与一条尾矿流，并使2020年《全球尾矿管理行业标准》（ICMM、UNEP与PRI，2020年3月）与投资人保险重定价在商业上成为决定性的东西：**上游法**筑坝的终结——把坝向上建在可液化的泥浆本身之上，最便宜也最致命的方法——ICMM成员在2020年承诺将其完全淘汰。设计的答案说起来简单、建起来昂贵：在坚实基岩上的下游法坝、压滤**干式堆存**（在放置之前把自由水压出，移除液化的燃料）、以及为残余金属再处理遗留尾矿、同时把残渣以更干更密的方式重新沉积。
:::

::: definition 酸性矿山排水：活得比矿山久的化学 {#def-amd}
开挖是一个氧化还原实验。黄铁矿（FeS₂），在地下水位之下稳定了数百万年，在采矿把它暴露于空气与水时氧化：净反应把一吨纯黄铁矿转成约1.6吨硫酸加溶解铁，而铁的进一步氧化——被嗜酸的*Acidithiobacillus ferrooxidans*催化多达一千倍，1947年Colmer与Hinkle的发现使酸性矿山排水既是一个地球化学问题也是一个微生物学问题——自催化这个级联，直到pH降到2以下、而岩石持有的每种重金属（铜、锌、镉、铝、以及宿主为花岗岩时的放射性核素）溶入渗流水。结果，**酸性矿山排水（AMD）**，是老采矿世界最大的长期水质问题：2001年美国国家研究委员会评估把废弃矿山排水放在美国200,000公里以上的溪流上，而欧洲的煤田与铀矿田运行着没有完工日期的永续处理厂。层级是预防第一：**封装与水覆盖**（1990–2020年代把产酸废石隔离在地下水位之下或氧屏障覆盖与湿地之下的实践，同一个逻辑使Greater Sudbury的100,000个酸化湖泊——1980年代起的"Sudbury模式"，施石灰、重植与烟囱控制——成为世界最大也最成功的冶金复垦）胜过**主动处理**（石灰与烧碱投加，1970年代起的高密度污泥厂），其永续运行成本活得比任何公司资产负债表都久，而两者都胜过2015年的**Gold King**演示，即修复本身就是一个危险——一次EPA对Colorado州Silverton上方老化尾矿库的溃决，把约300万加仑橙色、含金属的污泥放进Animas河与San Juan河，并使"未经表征不要扰动"成为闭坑规划者的第一诫。**被动处理**——厌氧石灰石排水沟、人工湿地与把微生物化学反着跑的硫酸盐还原生物反应器——运行便宜而对其极限诚实：在高酸负荷下它买来的是时间与美观，不是免疫。治理的要点是本课的核心：AMD是一个带500年期限、连在一家30年公司上的负债，这就是为什么财务保证金、在第一辆卡车之前提交的闭坑计划（1977年《地表采矿控制与复垦法》对美国煤的要求、2020年尾矿标准的闭坑条款）、与有资金的废弃土地项目（美国废弃矿地费，其2021年《基础设施投资与就业法》续期带了120亿美元以上给遗留煤区）是唯一挺得过破产的工具。
:::

::: definition 溢油、采出水、与海上的风险预算 {#def-spills}
石油的影响账本有两个截然不同的栏目。**急性溢油**是被拍照的那些：油轮时代始于1967年Torrey Canyon的12万吨在康沃尔海岸（以及第一个国际责任制度，1969年《民事责任公约》），经过1978年Amoco Cadiz的22.3万吨在布列塔尼外海，而由1989年Exxon Valdez重新奠基——4100万升在Prince William Sound，其法律善后（1990年《油污法》的双壳与应急规划架构）使"不再有Valdez"成为一代油轮的设计任务书：到2020年代，每吨溢油频率比1970年代峰值低了两个数量级。海上那一栏不同：2010年Deepwater Horizon井喷——490万桶（约65万吨）在87天里喷出，史上最大的海洋溢油，而2015–2016年的和解仅美国罚金与自然资源损害就接近210亿美元——证明风险分布的尾部不由油轮纪律设定、而由前沿水域的井喷概率设定，而其响应——2011–2012年的井控公约、以及监管者关于防喷器与井完整性的规则周期——是工业安全事后补救的教科书。慢性那一栏比两者都大：**采出水**——每一桶油一起上来的地层水（2020年代美国每日数十亿升，Permian在成熟油田的水油比接近十桶水一桶油）——被回注进深处置井，而那个处置就是2010年代美国中部的诱发地震故事：2011年Youngstown俄亥俄的回注背后是第一次明确归因的回注地震、俄克拉何马2009–2015年的地震百倍增加（由2015–2016年的处置量削减与USGS 2016年的综合报告回应）、以及得克萨斯2019年的许可撤销，是现在写进页岩监管的模板：对处置、不是对生产的红绿灯协议。
:::

::: definition 安静的遗留：沉降、无主井、与逸散甲烷 {#def-legacy}
在被拍照的灾难与酸的化学之间躺着账本最大的一行：时间。**沉降**在岩石被采出或孔隙压力下降之处变形地表——鲁尔与约克郡带着一百年赔偿法的煤矿槽村庄；洛杉矶的Wilmington油田，其1932–1960年代的米级凹陷与开创性的大地测量监测使沉降成为一个油藏管理变量；而荷兰的Groningen气田，2012年3.6级的Huizinge地震把一个烦扰级的诱发地震辩论变成一场关于开采的全国公民投票、强制了2014–2018年的减产、而以2023年最终关停告终——有记录以来最大的诱发地震政策逆转，3万多栋受损房屋的修复仍在进行。**无主与废弃井**是工业最老的负债、而带最新的数据：美国保有数十万口在现代监管之前钻的井，数万口已在法律上"无主"（无所有者、无基金、部分泄漏），而2024年一份同行评议的清单把历史井的总数放在380万以上，多数从未被测绘——这就是为什么2021年《基础设施投资与就业法》的11.5亿美元无主井封堵计划、这项工作的第一笔联邦拨款（其州合同在2022–2025年运行）最好读作一个世纪的拖延维护以一笔刺激开支的形态到来。这些井的**逸散甲烷**、废弃煤矿的、以及在产而未测作业的遗留，是接上气候账本的那一个：2018年Alvarez与Colomb的卫星加飞机综合研究发现美国油气排放比清单高约60%、2019–2023年Alberta、Permian与土库曼斯坦考察的超级排放者调查、以及2023年MethaneSAT与Carbon Mapper开始点名作业者、不是平均值的飞行，合起来显示少数百分比的资产排放了大部分气体、而一口未封堵的井可以每年泄漏数吨、持续几十年。2020年代的政策综合——2021年《全球甲烷承诺》的2030年减30%目标、美国EPA 2024年的超级排放者法规、欧盟甲烷法规2025–2027年的报告与进口基准——实质上是遗留工业的监管：地球上最便宜的甲烷减排是已经在泄漏的气，而找到它是一个测绘问题、不是科学问题。
:::

::: definition 清理：责任、闭坑与循环的法律科学 {#def-remediation}
修复法比采矿年轻四千年、而建立在三项发明上。**责任**：污染者付费原则（OECD 1972、欧盟条约第191条）使清理成为作业者的账单、不是纳税人的——在美国以CERCLA/超级基金（1980年，2020年代约1,300个国家优先名录场地，使其成为一门工业的追溯性连带债务责任）、欧盟《环境责任指令》（2004年）、以及采矿州的财务保证金要求（按闭坑成本定规模的保证金与担保，其长期的保证金不足——2016年美国问责局发现硬岩保证金只覆盖清理成本的一小部分、以及2020年代内华达、亚利桑那与澳大利亚的保证金改革）是这个领域核心的执法失败。**闭坑规划**：自1990年代标准的要求（南非1997年政策、欧盟《采矿废物指令》2006、ICMM 2019年闭坑指南与2020年尾矿标准），即一座矿山必须在出生证明之前提交它的死亡计划——地貌、水处理期限、监测终止日期、以及达到它的钱。**循环**：认识到遗留废物就是库存——"城市矿山"的算术（《全球电子废弃物监测》2022年产生的6200万吨、正式收集的不到四分之一、2010–2020年代Agbogbloshie与贵屿的电子废弃物中心作为警示性的摄影随笔、以及2024年欧盟电池法规的再生含量强制，是关闭回路的第一次工业尝试）与尾矿再处理工业（2020年代南非的工厂以比许多在产矿山更富的50年前品位再磨金泥、以及欧盟《关键原材料法》2024年的二次来源基准），在品位、体量与位置允许的任何地方把昨天的负债变成明天的矿体。来自三十年超级基金与矿山闭坑实践的诚实综合：清理在钱于需要之前被锁定、终态写成一个数字（一个pH、一个浓度、一种土地用途）而不是一个形容词、而含水层、不是地块，定义项目边界时有效——这三个条件正是2020年代的公正转型基金（欧盟公正转型基金2021–2027年的煤区项目、德国2020年议定的给煤区400亿欧元以上的结构方案、美国废弃矿地奖金）现在试图从场地扩展到区域的。
:::

::: example Brumadinho与Fundão：重写尾矿法的四十个月 {#ex-brumadinho}
巴西在一个采矿州里产出了尾矿工业的前与后。2015年11月5日，Samarco（Vale–BHP合资）的Fundão屏障在Minas Gerais的Bento Rodrigues村上方失事：4000万立方米的铁矿尾矿——一种湿混凝土稠度的泥浆——沿Doce河行进600公里到大西洋，杀死19人、掩埋了那个村、终结了河口渔业、并污染了五十万人的饮用水；2017年Renova基金会的20年、240亿雷亚尔的修复协议、把Samarco总负债推过1700亿雷亚尔的联邦与州诉讼、以及2021年给这座厂澳巴管理层定罪的刑事审判（定罪后来上诉，本案未决的清算本身就是一个教训）使Fundão成为巴西史上最贵的环境灾难。四十个月后，2019年1月25日，Vale自己的、距此120公里、被审核为稳定的Brumadinho Córrego do Feijão坝在一分钟之内液化：波浪漫过矿山的办公室与食堂以及一个下游社区，杀死270人，而其堆积范围画出了Fundão调查曾说不可能再被击中的那批人口的确切位置。响应的制度速度是案例研究：十四个月之内，《全球尾矿管理行业标准》由ICMM、UNEP与PRI起草、Brumadinho的家属在起草委员会里；五年之内，建造这两座坝的上游法正被主要矿业公司退役、而巴西2019年的州法直接禁止它，而Vale与Minas Gerais 2021年2月的赔偿框架——1700亿雷亚尔，当时任何地方最大的环境和解——用几十年的货币给一次尾矿流定了价。工程的残留是可迁移的部分：尾矿现在按失事物理分类（载荷下的静态液化，两次失事在全尺度上验证的Seed与Idriss土力学传统），溃坝淹没图以米与分钟绘制，而Brumadinho的幸存者描述为"本该存在的那件事"的逃生路线演习在GISTM合规场地是标准的——采矿业最便宜的安全技术，而它用了两次灾难里的289条生命才被强制。
:::

::: example Butte与Tar Creek：两种美国的遗留几何 {#ex-butte-tarcreek}
两个创始性的超级基金景观显示为什么遗留清理是一门科学、却是两个非常不同的工程问题。**蒙大拿Butte**是一个点源怪物：一个世纪的铜矿开采（"地球上最富的山头"，1864–1983，在Anaconda、然后ARCO/BP之下）留下了Berkeley坑——一个约3公里周长、数百米深的开挖，自1983年停止排水以来不受控制地淹没成一个pH约2.5的硫酸铁水湖，携带远超100,000 mg/L的溶解铜与铁，每一本地球化学教科书的酸硫化物风化栏以城市尺度运行，带砷的温地下水通过相邻的"Yankee Freedom"酸渗流上升进Clark Fork的源头。补救是一台由水处理厂与责任账本组成的永续机器——从BP 2002年1.05亿美元的超级基金和解、到EPA 2023年把工作合并到一个Butte优先办公室之下——预计以每年数千万美元运行几个世纪，使酸性矿山排水的期限成为字面意义上的，以及一个活的检验：能否由一般基金、不是公司保证金，承担一个世纪尺度的义务。**俄克拉何马Tar Creek**是弥散版本：七十年的铅锌开采（1917–1967，Tri-State矿区的锌都）留下约9,000公顷的"chat"——白色、风可搬运、富铅与镉的尾矿——散布在Picher及其邻镇的田地、院落与游乐场里，1990年代的研究发现当地三分之一的儿童高于干预血铅水平。Tar Creek是1983年最早列入的超级基金场地之一，而其补救不是化学、是土地用途：EPA 2000年代至2011年对chat与崩塌采空之上数百栋住宅的收购与拆除、以及Picher 2013年的撤销建制、留下不到二十几个居民。Tar Creek可迁移的真相：当有责任的所有者已不复存在、废物未经工程处理而位于居住区、而暴露途径就是城镇本身时，清理就变成迁移——20世纪任何一部采矿法都不包含的最后手段政策工具，也是2020年代关于超级基金改革资金的辩论实际上是谁住在哪里之争的理由。
:::

::: example 煤遗留的转向：鲁尔、卢萨蒂亚与英国煤田 {#ex-coal-legacy}
地球上最富的采矿遗留项目属于正在关闭、不是在开采煤的区域：欧洲的煤阶段——德国2020年煤电退出法带其给鲁尔、卢萨蒂亚、德国中部与Helmstedt区域的400亿欧元以上结构方案、以及英国1994年后的矿井关闭，把遗产留在国有的煤炭局手里——是史上第一次作为景观转换谈判的工业退休。**水是隐蔽的工程**：当最后的水泵停下，煤田沿自己的梯度淹没，而两个公共信托现在运行着地球上最大的矿水公用事业——英国煤炭局约70个永续处理方案（对酸性、富金属的矿水每日数亿升的投药与精处理，其2019年Cragg Vale的锌毒杀与2022–2023年环境署的起诉使遗留排放成为一个全国头条）、以及德国的RAG基金会，2007–2008年注资约22亿欧元运行两个世纪的闭坑后水管理——预资金的永续照护，其2020年代成本报告已显示账单随煤田淹过老水泵的设计期限而上升。**景观转换是可见的一半**：鲁尔的Emscher河复明与把焦化厂与井口复用为公园与博物馆（Zollverein 2001年的联合国教科文组织列入）；以及卢萨蒂亚的Fürst-Pückler-Land国际建筑展（2000–2010），把露天坑淹没成一串二十个湖——德国最新的旅游区，而2020年代关于湖水预算的争论显示即使"完成"的转换也需要永续的水文管理。德国2024年与RWE和Leag的协议把西部退出的部分提前到2030年前后，使卢萨蒂亚成为矿山关闭能否成为一个区域、不是一个场地的活的实验。比较的道德在次序上：德国与英国的项目在最后一条矿井关闭*之前*获得资金，而阿巴拉契亚的废弃煤矿积压——数万处未处理场地，许多来自早已解散的作业者——被留给1977年废弃矿地费的饥饿基金，直到2021年《基础设施投资与就业法》的120亿美元续期与2023–2025年的州奖金开始清理它。美国正在晚一代、以复利发现同一个算术。
:::

::: example 无主井与超级排放者：测绘看不见的库存 {#ex-orphan-methane}
2010–2020年代的甲烷调查完成了二十年规则制定未完成的：它们使工业最小的遗留可见、量化、可归因。测量的弧线值得作为方法记住：2013–2014年对Denver-Julesburg与San Juan盆地的飞机考察（Brandt与同事2014年《科学》综合发现盆地甲烷是清单的两倍）开启了时代；Alvarez与同事2018年《科学》的Albuquerque飞越把全国油气甲烷放在EPA估计之上约60%；而随后的超级排放者目录（Carbon Mapper 2021年起的PRISMA探测、2023年3月发射的MethaneSAT、IEA 2021年起的全球甲烷追踪器）汇聚于一条帕累托定律——少数百分比的场地产生多数泄漏，从轨道上以每减排一吨几美分就能找到。库存的无主井那一半更老也更乱：州记录（宾夕法尼亚10万处以上有档案的遗留井、2023年终于创设一个有资金无主井项目的得州立法改革、加州CalGEM的井清单数字化）、2014年Cornell与2024年多所大学的估计把美国历史井数放在数百万、而多数在任何监管存在之前钻成、以及2021年联邦11.5亿美元的封堵计划——对积压的第一次持续全国攻击，其2022–2025年州合同以每口数万美元封堵井，完成数千口，积压以数万计。政策综合在2021–2024年到来：《全球甲烷承诺》（2021年9月，150多个国家，2030年减30%）、美国EPA 2024年12月的甲烷规则（其超级排放者响应程序使卫星探测成为一个带收费表的监管触发器）、2024年生效带2025–2027年报告与进口强度基准的欧盟甲烷法规、以及加拿大2024年的收紧提案——它们全部，实质上，是遗留基础设施的规则。安静的革命是认识论的：第一次，一段生锈的套管与一条废弃煤层是公开的、卫星可核验账目里的行项——正是[[earth-resources/resources-reserves]]一课一直说缺失的那套账。
:::

::: history 从Torrey Canyon到卫星账本：六十年的开采法 {#hist-impacts}
**1966–1973**：创始灾难——Aberfan的煤矸滑坡（1966年10月，116名儿童，英国第一部矸石堆立法与一个发明了"灾难法"的赔偿法庭）、Torrey Canyon（1967年3月，第一次超级油轮失事与第一个国际责任公约，1969年）、Cuyahoga河大火（1969年，催化1972年美国《清洁水法》的那个图像）与Amoco Cadiz（1978年，布列塔尼外海22.3万吨，油轮设计与港口国控制的革命）。**1977–1980**：责任架构——《地表采矿控制与复垦法》的复垦保证金与废弃矿地费（1977年）、Love Canal听证（1978年）与CERCLA/超级基金（1980年），任何地方第一部一般的追溯清理法，其2020年代的记录（数千个被评估场地，约400个除名）是责任法能与不能做什么的诚实度量。**1983–1989**：遗留场地浮现——Tar Creek的紧急超级基金列入（1983年）、Berkeley坑停止排水（1983年，世纪尺度处理机器的开始）、与Exxon Valdez（1989年3月，4100万升，1990年《油污法》与双壳船队）。**1994–2010**：闭坑职业时代——1994年起的矿山闭坑讨论会系列、欧盟《采矿废物指令》（2006年）与财务保证金改革、Sudbury模式二十年证明区域酸化可以被逆转、以及Deepwater Horizon井喷（2010年4–7月，490万桶，约210亿美元的清算与井控公约）。**2015–2019**：尾矿的可怖教育——Fundão（2015年）、Gold King（2015年）、Brumadinho（2019年）、以及结束上游法时代的270加19条生命。**2020–2025**：综合——《全球尾矿管理行业标准》（2020年3月）、《全球甲烷承诺》（2021年9月）、美国无主井拨款与120亿美元废弃矿地续期（2021年）、德国煤电退出的结构方案（2020年法，2024年加速）、欧盟甲烷法规（2024年）与EPA超级排放者规则（2024年）、以及2024年全球盘点首次发出的逐步退出化石燃料的呼吁——第一个由开采的账本、不是它的地质或经济学设定监管前沿的十年。
:::

## 检验你的理解

::: quiz {#quiz-upstream}
为什么2020年《全球尾矿管理行业标准》使上游法尾矿坝实际上无法获得融资？

- [ ] 它们比下游设计建起来更贵
- [x] 它们的失事模式是被围泥浆本身的液化，所以一个稳定的库容是坝的结构性前提——Fundão与Brumadinho证明致命的那个倒置
- [ ] 它们无法用渗压计仪器化
- [ ] 它们比下游设计需要更多维护

::: solution :::
在上游法中，坝的每一级新堆都建在沉积尾矿之上——"坝"与"废物"共享一个身体，所以泥浆的任何液化*就是*一次溃坝，而其堆积范围穿过工人与办公室所在的沉积区。下游设计建在地基土上、并把泥浆留在一个常规路堤之后；它们花更多土方、但不能因被围材料成为失事而失事。融资的变化跟随物理：保险人与贷款人在2019年后对上游设施重定价，而标准的不新增上游加应急计划与检查的要求使这种方法在商业上死亡。
:::
:::

::: quiz {#quiz-amd-microbe}
微生物加速酸性矿山排水主要靠：

- [ ] 分泌直接溶解黄铁矿的酸
- [x] 催化Fe(II)氧化为Fe(III)，即攻击黄铁矿的快速氧化剂——把一个无机回路加快一千倍地闭合
- [ ] 把硫固定进生物量，释放热
- [ ] 比氧扩散进废石更快地消耗氧

::: solution :::
仅靠氧的黄铁矿氧化是慢的；Fe(III)氧化黄铁矿快得多，而嗜酸铁氧化菌（Acidithiobacillus及近亲）从产生的Fe(II)再生Fe(III)，在反应自己造成的低pH下——一个生物学催化地球化学的正反馈。这就是为什么AMD系统在pH 2以下自我维持、为什么1947年Colmer-Hinkle的发现改变了这个领域、以及为什么"灭菌"废石从来不是一个选项：这些微生物是环境性的，不是引入的。
:::

## 练习题

::: exercise {level=1 check="90"}
**剥采比。** 一座剥采比为6:1的露天煤矿一年采出1500万吨煤。它必须放置多少兆吨废石？
::: solution :::
15 × 6 = **90 Mt**的覆盖层——产品的六倍，这就是为什么矿山的土方船队、不是它的选厂，设定成本曲线、以及为什么倾倒山丘的形状是矿山最长寿的工程制品。
:::
:::

::: exercise {level=1 check="14.6"}
**尾矿吨位。** 一座铜选厂每天处理40,000吨矿石，而在25%的精矿产率后基本上全部矿石质量进入尾矿。年尾矿吨位是多少兆吨？
::: solution :::
尾矿≈ 40,000 × 365 = 1.46 × 10⁷ t = **14.6 Mt/年**——质量平衡的理由，一个中型铜矿首先是一家卖铜的岩石搬运公司，也是为什么尾矿设施、不是矿坑，通常是场地上最大的结构。
:::
:::

::: exercise {level=1 check="41600"}
**溢油体积。** Exxon Valdez释放了约1100万美制加仑的原油。换算成立方米（1美制加仑 = 3.785升）。
::: solution :::
11 × 10⁶ × 0.003785 = 41,635 ≈ **41,600 m³**——以及比较的直觉检验：Deepwater Horizon的490万桶是780,000 m³，十九个Exxon Valdez在三个月里喷出，这就是为什么两次溢油产生了两部不同的监管制度（油轮设计对井控）。
:::
:::

::: exercise {level=2 check="1633"}
**产酸潜力。** 黄铁矿（FeS₂，分子量120）的氧化每个黄铁矿分子产生两个硫酸分子（分子量98）。1,000吨纯黄铁矿能产生多少吨纯硫酸？
::: solution :::
每吨黄铁矿的酸 = 196/120 = 1.63。对1,000 t：**1,633 t**的H₂SO₄——这个数字使废石地球化学（每根钻心的产酸试验）成为矿山设计里最要紧的分析，而使"一点点黄铁矿"变成一座永续处理厂。
:::
:::

::: exercise {level=2 check="1233"}
**石灰需求。** 熟石灰（Ca(OH)₂，分子量74）一摩尔对一摩尔地中和硫酸（分子量98）。中和上一题的1,633吨酸需要多少吨石灰（忽略低效）？
::: solution :::
1,633 × 74/98 = 1,233 ≈ **1,233 t**——而真实数字高20–50%，因为混合不完全与溶解铝和铁的水解：世界上每一座在产AMD处理厂的运行预算就是这道算术乘以永续的流入。
:::
:::

::: exercise {level=2 check="2.4"}
**沉降。** 一个长壁工作面采出2.5 m厚的煤、采出率80%；上覆岩层把采出体积的120%作为沉降传到地表。中央地表沉降是多少？
::: solution :::
沉降 = 2.5 × 0.8 × 1.2 = **2.4 m**——这就是为什么长壁区域保留航空水准档案、为什么英国的赔偿法存在、以及为什么Groningen的决策者说这些气不值得那些地震：沉降与断层滑动是同一个移除体积的记账，一个慢，一个突然。
:::
:::

::: exercise {level=3 check="650000"}
**井喷质量。** Deepwater Horizon释放了490万桶密度约830 kg/m³的油。估算释放的质量，单位吨（1桶 = 0.159 m³）。
::: solution :::
体积 = 4.9 × 10⁶ × 0.159 = 7.8 × 10⁵ m³。质量 = 7.8 × 10⁵ × 0.83 = 6.5 × 10⁵ ≈ **650,000 t**——大于几个北海油田的全部年产量，不受控制地释放，也是210亿美元和解、11项过失致死计数与自然资源损害评估必须定价的质量。
:::
:::

::: exercise {level=3 check="29"}
**无主井变暖。** 一口未封堵的井以2 g/min泄漏甲烷。它在一年里的变暖影响是多少吨CO₂当量（GWP-100 = 28；1年 = 525,600分钟）？
::: solution :::
质量 = 2 × 525,600 g = 1.05 t CH₄/年。CO₂-e = 1.05 × 28 ≈ **29 t**——一口井等于一辆小汽车一生的排放、每年它未封堵的时候；乘以2024年美国库存里数以万计的无主井，封堵计划的11.5亿美元就气候而言是《基础设施法》里最便宜的减排一行。
:::
:::

::: exercise {level=3 check="3400"}
**城市矿山品位。** 2022年《全球电子废弃物监测》数出6200万吨被丢弃的电子产品，22%正式收集。以每收集设备一吨平均250 g的黄金含量，正式收集的流里有多少吨黄金？
::: solution :::
收集 = 62 × 0.22 = 13.6 Mt。黄金 = 13.6 × 10⁶ × 0.00025 = **3,400 t**——超过十年原生金矿产量的输出（年矿山供应约3,000 t）每年流过垃圾箱、而在一个比天然矿体五十倍的品位上，这就是整个循环经济论证在一次除法里——也是78%非正规处理的剩余（Agbogbloshie的露天焚烧）同时是资源与犯罪现场的全部理由。
:::
:::

::: warning 关于开采影响的四个误解
1. **"大溢油就是大影响。"** 被拍照的灾难驱动法律，而慢性账本更大：采出水在体积上远超溢油，酸性矿山排水比任何溢油恢复晚两个世纪结束（见widget的两条曲线），而欧洲的煤水处理账单永远重复。影响预算，像碳预算一样，应记在吨乘年里——而在那个度量上安静的条目获胜。
2. **"清理恢复基线。"** 修复工程返回*功能与风险*，不是起源：达到一个数字的处理水、不侵蚀的地貌、移除的暴露途径——但被淹的煤田不重启酸就不能再排干，chat堆只能被移动或掩埋，而卢萨蒂亚的湖是一个水文调试项目、不是一个恢复的景观。诚实的终态语言是"安全而受监测"，而2020年代尾矿标准对*可预测*长期行为的坚持是法律终于承认恢复是一个隐喻。
3. **"监管跟随灾难。"** 部分真实——Aberfan、Valdez、Brumadinho各买下一部制度——而更深的模式是监管跟随*测量*：Darcy时代的水文地质使污染羽法成为可能，InSAR使沉降可归因，卫星甲烷使作业者可点名。过去十年每一次收紧（超级排放者规则、尾矿清单、无主基金项目）都追溯到一个使一个看不见负债可见而可量化的仪器。
4. **"循环终结开采影响。"** 二次供应是真实而增长的——五十倍矿品位的电子废弃物黄金、比在产矿山更富的再处理尾矿——而2020年代二次金属的规模覆盖需求增长的一小部分，而循环有自己的残留（Agbogbloshie的非正规电子废弃物焚烧是一个戴着回收标签的开采影响）。循环流移动影响账本的栏目；它们不合上这本书，而这本书就是本课的主题。
:::

## 小结

::: summary
开采的账本平衡两个质量：在几十年里卖出的产品、与为几个世纪设计的残留。质量平衡是残酷的（十倍的剥采比、等于矿石的尾矿吨位、一吨黄铁矿产出1.6吨酸），负债在时间上是不对称的（一次溢油在十年的钟上愈合，酸性矿山排水在排水的钟上衰减，一堆chat持续到被移动为止），而法律以三项发明回应——责任（超级基金的追溯污染者付费、按闭坑成本定规模的财务保证金）、在开采开始之前提交的闭坑规划（从《地表采矿控制与复垦法》到2020年尾矿标准）、而现在是循环（遗留废物作为明天的矿体）。写下这些制度的灾难是一个名单、每个名字背后有一种物理：Aberfan的矸石堆与Torrey Canyon的油轮创立了矸石堆法与责任公约；Exxon Valdez重建了油轮而Deepwater Horizon重建了井控；Fundão与Brumadinho在四十个月里结束了上游法时代；Groningen用一个气田换了一张震动图与一次关停；Butte与Tar Creek显示了永续处理与有管理的撤退作为遗留工程的两个端点；而2013–2024年的卫星甲烷调查使最小的遗留——无主井、超级排放者——第一次公开可数。对资源经济学的比较教训是[[earth-resources/resources-reserves]]一课从另一面教的那个：一个储量只和它的资产负债表一样可靠，而一座矿山只和它的保证金基金一样闭坑。2024年全球盘点的逐步退出化石燃料措辞使这本账成为一门活的学科——数百个在产场地、数以万计的遗留场地、以及一个由记账、不是地质设定前沿的十年。
:::
