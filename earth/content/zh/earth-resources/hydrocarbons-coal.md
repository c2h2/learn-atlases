一个石油系统告诉你碳氢化合物在哪里；本课讲的是把它们取出来、诚实地数它们、并理解它们的开采对这个世界做了什么。地下的油与油轮船舱里的油之间的距离，是地质与工程之间的距离：压力驱动头几桶，水与气驱动接下来的三分之一，蒸汽与二氧化碳追逐最后的部分，而经济学决定哪一部分根本会移动。煤是陆地上的同一个故事——一个碳化的沼泽，按埋藏被分级成褐煤或无烟煤，用拉铲或长壁开采，而如今是世界上最大的单一能源相关排放来源。天然气，三者中最可移动、最过渡性的，把它的每一个优点（清洁燃烧、便宜的分子）变成一个物流问题（不变成其体积六百分之一的液体，它就无法跨越一个大洋）。本课涵盖储层驱动与采收率、使深水与页岩成为可能的井与平台技术、煤化阶梯与其开采系统、从管道到LNG列车的天然气价值链、以及关于当产量见顶会发生什么的Hubbert曲线之争——一场七十年来对日期错误、对形状正确的争论。它以[[earth-resources/resources-reserves]]一课开始之处结束：地下的东西、能以一个价格采出的东西、与气候允许的东西之间的区分。

## 取出来：驱动、波及与采收率

::: definition 驱动机制与采收率：一次、二次、三次 {#def-drive}
一个储层产油是因为有东西在推。四种天然驱动，常按顺序，设定一个田的头十年行为：**溶解气驱动**（压力降到泡点之下，脱出的气泡穿过孔隙空间并把油带上来——对轻油高效、对重油是灾难性的，随着气变得不流动它们只是停止流动）；**气顶驱动**（一个游离气顶随压力下降像活塞一样膨胀，把油向下倾方向波及——构造高点的经典机制、也是气顶在能再加压时绝不被烧掉的理由）；**水驱动**（边水或底水随压力下降膨胀进空隙，维持储层压力并给出最好的一次采收，在强含水层的案例如某些中东碳酸盐岩里是STOIIP的40–60%）；以及**压实与重力泄油**（孔隙度本身在未固结第三系砂岩里坍塌——Ekofisk的沉降故事，二十年间13米的海底沉降与平台腿缩短——而陡的倾角让油径直 向下泄）。天然驱动下的一次采收通常是STOIIP的10–25%；另外四分之三是这个行业发明存在的原因。**二次采油**——注水，1860年代在宾夕法尼亚Bradford发明、1940年代工业化、如今是全世界约一半产量背后的方法——给储层再加压并把油波及向生产井，把采收率抬到30–45%。**三次采油（EOR）**攻击水不能攻击的东西：黏度（蒸汽——1960年起的Kern River循环注汽与Cold Lake/SAGD原位油砂作业）、流度与混相（CO2驱，成为Permian盆地的第二产业、以及氮），与残余捕获力（聚合物与表面活性剂驱，自1990年代起在大庆以巨型规模部署）。EOR今天增加约全球供应的5%，而它是大多数"深十年"石油供应情景转动所系的铰链。
:::

## 井、钻机、与移动了曲线的那些技术

::: definition 作为一台机器的井；作为一个工业系统的近海 {#def-wells}
一口生产井是一根对着地球设计、承受压力的管子：一道接一道的钢套管（导管、表层、生产、尾管）固井进井眼、其密度是一次井喷屏障的钻井液（Macondo教训的重述）、以及一套计量流量的阀门井口"圣诞树"。在25年里重塑全球供应的两项技术都是老主意的全新执行。**定向井与水平井**：从1929年的Schultze井与1948年专利时代的实验，到1980–90年代的随钻测量与随钻测井工具，让钻井者能在3米的煤层或30米的页岩层里引导一条2公里的水平段，使一个地面井场泄出一个一公里宽的区域。**分段水力压裂**：隔离滑套与桥塞技术（1998–2002年的Mitchell Energy、以及1947–49年Stanolind压裂专利的后来改进）让一口水平井沿其全长放置30–40条裂缝，通过给它人造高速公路通往井眼，把基质渗透率以*毫*达西计的致密岩石变成一个经济生产井。在近海，钻机船队是一个浮力与耐天气的阶梯：浅水自升式平台、动力定位到3千米水深及以外的半潜式平台与钻井船、1990年代起墨西哥湾的张力腿平台与Spar平台、以及把生产与其100公里外一个田的水下采油树、管汇与立管解耦的FPSO（浮式生产储卸油装置——1976年在北海Argyll田首创，如今从圭亚那到巴西的开发标准）。经济学跟随工程：一口美国陆上常规井是几百万美元、一口60段的页岩井是它的五到八倍、一口深水井一亿美元、而一口前沿探井——唯一一种能找到下一个圭亚那的井——五千万到两亿美元、并有五分之四的干井概率。
:::

::: example 页岩革命：一个被重建为工厂的行业 {#ex-shale}
2007到2019年间，美国增加了约每日800万桶石油——比历史上任何国家的增长都多——几乎全部来自三个页岩区：Bakken（Williston盆地）、Eagle Ford（南得克萨斯）、与Permian盆地的Delaware与Midland区块。使能的技术栈是地质的（1980–90年代的认识，1999年由USGS的Kent Newell为Barnett论证、并由George Mitchell的团队自1991年实践：页岩是一个*连续*聚集——烃源岩与储层一体，没有溢出点、没有边水）、定向的（公里级水平段）、机械的（到2015年的60段完井）、与化学的（压裂液：99%的水与砂加上百分之一的减阻剂与杀菌剂，尽管有2011–2012年"99.5%的水"的披露之争——2010年代披露的添加剂清单显示数十种ppm级的具名化合物）。经济的签名是**双曲递减**：一口页岩井在第二年失去其首年产量的60–70%，而仅仅让一个盆地持平就需要持续钻井——这把行业的目标函数从"最大化每个田的采收、活30年"转换为"最大化每口井的资本效率、每月重复"。2014–16与2020年的价格崩溃杀死了不惜代价的增长模式、产生了2020年代的资本回报纪律，而2013年的**Zenith井**（Eagle Ford：3,000米水平段、40段、以15%的成本增产30%）设定了人人复制的模板。战略后果仍在展开：到2024年美国原油产量1,320万桶/日（世界最大生产国）、使美国到2023年成为世界最大天然气出口国的LNG出口、来自Brent的海上竞争之结构性崩塌（封顶了俄罗斯与OPEC的定价权）、以及——账本的另一面——甲烷泄漏之争（2018–2020年的EPA清单修订与2018年Brandt的PNAS研究，关于决定天然气是否在CO2当量上胜过煤的1–12%泄漏区间）与地下水污染诉讼（2010年的Dimock与2016–2023年的宾夕法尼亚与俄克拉荷马案件），它们使压裂化学品的披露成为2010年代中心的政治斗争。
:::

::: example Athabasca油砂：升级的经济 {#ex-oilsands}
Alberta油砂持有世界第三大石油储量——约1,670亿桶，仅次于委内瑞拉与沙特——而其中几乎没有任何东西表现得像油。Athabasca、Cold Lake与Peace River矿床是被生物降解冲洗到8–14 °API重油的白垩系砂岩（[[earth-resources/petroleum-systems]]一课的保存故事的大陆尺度版：一个吃掉了整个盆地充注轻组分的渗漏-微生物系统）。两种开采几何由深度导出：Fort McMurray附近的Athabasca**露天矿**（Suncor 1967年的加拿大油砂伟大工程——第一个商业作业，建在Karl Clark的热水分离工艺之上，1928年获专利，使提取成为可能：采矿、热水分离、经焦化与加氢裂化升级）、以及**原位蒸汽**作业（循环注汽，1960年代起在Cold Lake试验、1980年代商业化、以及——在Roger Butler 1978年的工艺概念与1987年Cold Lake现场试验之后——自1990年代中期起在成对水平井里的蒸汽辅助重力泄油SAGD）如今生产加拿大330多万桶/日的三分之二。经济学是一个价差交易：加拿大重油以相对WTI的折扣出售（Western Select价差，当Enbridge Line 3的瓶颈与2014–15年页岩轻甜油过剩恰逢其时时被撑开到每桶40美元），折扣是对升级商资本与制造蒸汽所耗天然气的回报、而两者随管道准入崩塌或扩张——2010–2015年"沥青大骗局"文献、使油砂三分之一产量停产两个月、2015年的Fort McMurray野火、以及2024年Trans Mountain扩建的完工——是三幕。排放账本同样结构性：升级商加上采矿使油砂桶的上游强度约为常规桶的3–5倍，这使它们成为2015–2025年在一个该部门占经济三分之一的省份里"公正转型"之争的目标。
:::

## 天然气：没有物流的分子一文不值

::: definition 天然气价值链：管道、LNG、储存、与分子的两个市场 {#def-gas-chain}
天然气是每单位排放碳中能量密度最高的清洁燃烧化石燃料（在现代联合循环汽轮机以约60%效率燃烧时，每单位热量的CO2约为煤的一半、对照亚临界煤的约35–40%），也是最难移动的。它的价值链有三个环节，每个有自己的经济学。**生产**：伴生气（石油的同伴，直到卡塔尔、挪威、以及——断断续续的——尼日利亚与伊拉克把它捕获之前被每年数百亿立方米地烧掉：全球常规火炬在2020年代初仍运行约每年1,500亿立方米，世界银行的"零常规火炬"计数）、非相关田的干气、以及非常规气——煤层气（创造了澳大利亚东海岸天然气市场的San Juan与Queensland井）、致密气、与页岩气（2010年代的游戏改变者：到2010年页岩占美国天然气产量的20%、到2024年占四分之三）。**运输**：管道（主力——1958年的跨加拿大系统与1980年代的苏联Urengoy–欧洲干线绘制了大陆天然气地图）对**LNG**：冷却到−162 °C把气缩小到其体积的1/600，代价是货物8–10%的能量成本、以及使LNG长期保持区域性的资本成本（澳大利亚–日本、卡塔尔–欧洲），直到2016年起的美国墨西哥湾沿岸浪潮（2016年Sabine Pass首船、然后是Corpus Christi、Freeport、Plaquemines）使大西洋盆地全球化并价格联动；再气化终端在远端接收货物。**储存与灵活性**：天然气独有的把戏是储层本身就是储存——枯竭田、含水层与盐穴（英国的Rough盐穴、美国400多个持有约年消费量30%作为冬季保险的美国地下储气库）——这正是让一个四月生产的分子在十一月给一个家庭供暖的东西、也是让天然气成为电网风光摆动伙伴的东西。2022年欧洲能源危机是一次同时上三个环节的课：管道依赖、与亚洲的LNG竞争、以及作为国家工具的储存填充政策（2022年欧盟90%的入冬前储存规则）。
:::

::: example North Field：一个构造如何成为世界天然气市场 {#ex-qatar-lng}
卡塔尔的North Field——一个半部属于单一构造的海上碳酸盐岩储层，其西半部North Dome供养伊朗的South Pars（两国共享一个黎巴嫩大小的气田）——持有约世界常规天然气的10%原地，而卡塔尔把它变成了市场里最可靠的供应合同。这个序列是一门建链的大师课：1991年首船LNG（Qatargas-1列车，一个当时空前的300万吨/年"mega-train"设计，使单位成本减半）、2000年代的列车扩建与2004年Ras Laffan的建设、2018–2025年经North Field East与South项目迈向1.26亿吨/年的产能竞赛、以及2022–2024年TotalEnergies与巴基斯坦和中国锁定数十年的27年合同。战略逻辑是俄罗斯的镜像：卡塔尔选择LNG（目的地灵活、成本更高、无过境国风险）而非管道（便宜、锁定、依赖邻国），恰恰因为一个卖进欧洲与日本的海湾小国无法信任一条管道。市场后果：卡塔尔货物定价锚定了2004–2014年的**油价挂钩LNG合同**时代（把气价与目的地市场的石油成本绑定十年的那个公式）、2022年危机把指数打破向现货气对气竞争、而美国墨西哥湾沿岸的回应——从最后进口国到2023年世界最大出口国，8,500多万吨/年——是从页岩分子到TTF价格的二十年反馈回路，欧洲能源部长们在一个冬天里、或祝福或责怪地发现了它。环境的平衡重量是真实的：卡塔尔的LNG带有上游甲烷泄漏与火炬的历史包袱（2010–2020年代的卫星火炬测量），而2021–2024年的OGMP 2.0报告机制与2021年的全球甲烷承诺（100多个国家、到2030年削减30%的甲烷、在COP26发起）是这个行业端到端审计链条的第一次认真尝试。
:::

## 煤：被变成燃料的地层学

::: definition 煤化阶梯与两种采矿 {#def-coal}
煤是植物物质沿**煤化阶梯**被时间、温度与压力分级的产物：泥炭 → 褐煤（干基15–20 MJ/kg，北达科他褐煤与莱茵兰褐煤，软、碎、湿、只在电站约100公里内开采，因为它自燃并在运输中贬值）→ 次烟煤（Powder River盆地的低硫煤，24–30 MJ/kg，按吨位美国最大的盆地）→ 烟煤（24–35 MJ/kg，为钢铁制造冶金焦的结煤——结黏性、自由膨胀指数，是使一种煤"炼钢"、并使冶金煤以溢价交易、全球贸易，而大多数动力煤区域移动的东西）→ 无烟煤（30–35 MJ/kg，宾夕法尼亚无烟煤区的硬、近碳燃料，自1960年代以来衰退）。地球化学的旋钮是同一个读油成熟度的镜质体反射率——煤在Ro约1.3–2.5之间从油窗煤过渡到气窗煤——这就是为什么世界的无烟煤也是它的煤层气远景区：气窗生成的甲烷在煤的微孔表面上解吸（煤按重量、而不是在孔隙里储气——CBM测井套件的Langmuir等温线），而给一个煤层排水就是释放它的东西。采矿以两种几何到来：**地表（剥离与拉铲）采矿**，覆盖层被移除并回填——Powder River盆地与德国Garzweiler坑里200吨的铲与1万吨的拉铲（一台德国的挖掘机，Bagger 288的血统，每年移动的土比巴拿马运河还多）——以深层采矿成本与死亡率的一个零头产出美国约85%、世界约65%的煤；以及**地下采矿**，自1950年代由英国发明的**长壁**工作面主导（一台300米的采煤机横切煤层，顶板在液压支架之后坍塌——使英国与澳大利亚地下煤有竞争力的地层控制几何）与房柱式（美国方法，如今日益机械化、而在含气深煤层里是一门甲烷灾害的生意：2010年Upper Big Branch爆炸，29人死亡、以及重置美国逃生避难标准的2006年Sago矿难）。煤的人类与地质账本是能源里最密集的：世界产量约88亿吨（2023年，中国约53%、印度约11%、美国约6%）、短暂使"煤回来了"成为头条的2021–2022年价格危机、以及2021年起把国家煤电增长上限（不只是强度目标）第一次写进政策的中国-欧盟"双碳"方案——[[climate-change/attribution]]与[[climate-change/emissions-budgets]]两课从另一面对待的政策架构。
:::

::: example 英国的煤：兴起、政治、与最后一千瓦 {#ex-uk-coal}
没有任何单一商品比英国煤做了更多现代史，也没有任何国家比它更好地演示完整的弧线——资源、帝国、劳工政治、撒切尔时代的决裂、以及全面淘汰。威尔士、约克郡、诺丁汉与南威尔士的石炭系煤田造就了第一个工业经济体：产量从1700年约250万吨升到1913年的2.87亿吨（世界最大的工业，雇佣一百万矿工，向全世界出口蒸汽煤），而1947年国有化为国家煤炭局——欧洲最大的单一雇主——使这个行业成为国中之国。它的终结以三幕到来。**1984–85年矿工罢工**（Orgreave的对峙、飞行纠察线、NUM的失败）打破了使煤对两党都无法治理的工业政治；采煤机关闭，自1958年起在每个政府之下持续进行，从170对矿井加速到最后一对深井Kellingley，2015年12月关闭。然后**2015–2024年的气候政策诸幕**完成了市场：碳价下限（2013年）与排放绩效标准使新煤电不经济、2015–2019年关于Winchfield露天矿的斗争与2022–2023年"别为Ratcliffe付钱"的运动使最后几座厂留在头条上、而2024年9月30日，Ratcliffe-on-Soar——这个发明了煤电的国家最后一座燃煤厂——烧完了它最后一班，在第一次之后一个半世纪。第三幕是全球的镜子：中国如今生产并燃烧比世界其余部分加起来更多的煤（2023年约88亿吨中的47亿吨）、它的煤电厂队是中位年龄14年的系统、其2021–2025年"清洁高效利用"方案与2025年煤炭达峰承诺设计来把它老化出局、而印度10亿吨拟建产能是[[climate-change/projections]]一课里每一条排放路径最大的单一不确定性。煤的故事是资源即政治的证明：建造了皇家海军的同一批分子被一个碳价与一次破罢工者的胜利核销，而下一轮煤热——越南、印度尼西亚、2023–2025年东南亚的建设潮——正按中国条款在"一带一路"的煤炭退出（2021年承诺、只部分兑现）之下融资。
:::

## 峰值：Hubbert曲线与枯竭的政治

::: definition Hubbert曲线：它预测什么、不能预测什么 {#def-hubbert}
M. King Hubbert 1956年的论文《核能与化石燃料》让一个单一的统计观察做巨大的工作：如果一个有限资源的发现遵循一个钟形序列、而如果产量以大致恒定的间隔滞后于发现，那么产量本身描绘一条钟形曲线——关于一个峰值对称，其高度与日期取决于最终可采禀赋中有多少被早期生产。Hubbert的方法（发现对产量的"钟中钟"面积匹配、后来被形式化为累计产量对产量的**Hubbert线性化**）命中了1970年美国本土48州石油峰值（960万桶/日，预测1965–71年、实际1970年）、而在OPEC的定价权、随后页岩革命重新打开曲线时如此声名扫地，以致争论变成方法论的。对这门艺术的诚实陈述：Hubbert曲线**对形状正确、对日期错误**，因为(1)禀赋不固定——储量随价格与技术增长（North Slope、墨西哥湾深水与Bakken在1956年全都"不可采"），(2)曲线是许多重叠子曲线（常规陆上、深水、非常规）之和，其顺序由资本周期、不是地质设定，(3)需求侧冲击（1973、1979、2008、2020）以任何供应渐近线都未预料的方式重置产量路径。幸存的是核心洞见，没有任何反例触及过它：**产量跟随发现约十年，而一个年消费是其年发现三倍的系统正在靠库存生活**——世界石油发现峰值在1960年代接近每年550亿桶、对照当前每年约360亿桶的消费，而常规世界自2005年以来的递减（在遗产基础上约每年3–5%，成熟田的"死亡行军"）是自2010年以来边际桶是页岩、深水或加拿大的原因。转型问题——石油需求能否在供应之前见顶，这是2015–2025年电动车与政策浪潮所意味的——是一个不同的、需求侧的峰值，Hubbert的机器无法处理；它属于[[climate-change/responses]]一课的碳预算算术。
:::

::: history 从Drake的盐井钻机到甲烷审计：生产的165年 {#hist-production}
**1859–1901**：Colonel Drake在Titusville的盐井蒸汽机于1859年8月在21米处打到油，而1870年代的Standard Oil托拉斯把一种易燃的奇物变成世界第一个全球商品（灯用的煤油、然后——在1886年Benz专利与得克萨斯1901年Spindletop喷井之后——引擎用的汽油；Standard 1911年的拆分创造了Exxon、Mobil与七姐妹的血统）。**1910年代–1940年代**：为皇家海军的燃料找油（Churchill 1914年的海军用油决定、1914年Anglo-Persian的51%收购）创造了中东租让——美索不达米亚1927年的Baba Gurgur井、伊朗1908年Masjed Soleyman的先例、以及把市场卡特尔化的1928年红线协议；1933年Ibn Saud租让、1938年Dammam No. 7发现、与1944年Aramco前身创立把重心转移到海湾。**1960–1973**：OPEC的创立（1960年9月，巴格达——委内瑞拉与伊朗的抗价主意，如Daniel Yergin 1991年《The Prize》所记载，该书获1992年普利策）与1970–71年的德黑兰与的黎波里协议结束了租让时代；1973年禁运使价格翻四倍、创建了国际能源署（1974年）与其90天库存规则、并开始了北海与阿拉斯加竞赛（Prudhoe 1968年发现、跨阿拉斯加管道1977年；Ekofisk 1969年、Forties 1970年、Brent 1971年）。**1979–2005**：第二次冲击（1979年）与1986年价格崩溃（跌到10美元）教给行业它的成本曲线；三维地震（1990年代）、水平钻井与深水（Troll 1995年、墨西哥湾1980年代的柔性塔、然后2000年代的Spar与张力腿平台）打开深处；OPEC 2000年代的富余产能摆动与中国需求激增（其2004年净进口交叉）重画地理。**2006–2020**：非常规时代——到2008年美国页岩气、到2012年页岩油、杀死100多家北美独立公司的2015–16年崩溃、OPEC+ 2016–2020年的管理递减伙伴、以及2020年4月的负价格（WTI五月期货−37美元，储存曲线倒退的那一周）。**2021–至今**：疫情后的鞭击（二月入侵乌克兰后2022年的139美元Brent、欧洲紧急的LNG重新管路、欧盟REPowerEU的天然气需求削减）、美国回到创纪录产量、以及**甲烷审计**的到来（2021年全球甲烷承诺、2024年国际甲烷排放观测站的报告、2024年COP28"逐步退出化石燃料"段落）——第一个不给分子里的碳、而给交付它的链条之泄漏定价的机制。
:::

## 检验你的理解

::: quiz
一个田的储层压力始于35 MPa，在油的泡点25 MPa之上。一旦压力降到24 MPa，在地面测得的生产油气比将：

- [ ] 随气体溶入油中而继续下降
- [x] 在孔隙里形成游离气并流动时升到其溶解值之上
- [ ] 恰好保持在溶解比上，因为气无法作为一个独立相流动
- [ ] 随气顶坍塌而降到零

::: solution
在泡点之下，脱出的气形成一个可流动的（或在重油里不可流动的）游离相；在它能流动之处，生产油气比爬到原始溶解比之上——溶解气驱动已经开始的地面签名、也是一田初级GOR曲线是其自身驱动机制第一条线索的理由。
:::
:::

::: quiz
Hubbert 1956年的方法未能预见2010年代美国产量纪录的主要原因是：

- [ ] 他的算术在1970年峰值上是错的
- [x] 他把可采禀赋当作固定的对待，而技术与价格反复扩大它（深水、盐下、页岩）并移动了钟
- [ ] OPEC故意超产以打破他的曲线
- [ ] 发现率与生产率无关

::: solution
Hubbert的面积匹配假设一个固定的最终可采资源；1970年代的墨西哥湾、1990年代的深水与2000年代的页岩各自把"不可采"变成储量、重画了钟。他的1970年预测是对的；失败在于固定禀赋假设、不是统计——这就是为什么现代评估建模技术情景、不是单一曲线。
:::

## 练习题

::: exercise {level=1 check="115"}
**注水的增量。** 一个田STOIIP 5亿桶。一次（溶解气）采出STOIIP的12%；转为注水把采收率提高到35%。注水增加多少百万桶？
::: solution
一次 = 500 × 0.12 = 6,000万桶；注水总计 = 500 × 0.35 = 1.75亿桶；增量是1.75亿 − 6,000万 = **1.15亿桶**——这就是为什么二次采油、不是勘探，历来在任何成熟区带里是最大的单一"新田"。
:::
:::

::: exercise {level=1 check="122.5"}
**页岩递减。** 一口页岩井首年平均日产1,000桶，此后每年递减65%。它在第二年末的流量是多少桶/日？
::: solution
1000 × 0.35 × 0.35 = **122.5桶/日**。陡峭的双曲递减是非常规工厂模式的签名：一口井首年产量的三分之二在它两周岁之前就消失了，所以维持一个盆地的产量是一个钻井速率问题、不是一个储量问题。
:::
:::

::: exercise {level=1 check="99"}
**LNG货物。** 一艘LNG船的货物是165,000立方米的液体。用600:1的膨胀比，一船货物代表多少百万立方米的气？
::: solution
165,000 × 600 = 9,900万立方米——大约一艘船装下英国冬季峰值日一个月的需求，这就是为什么一条被堵的管道（2022年Nord Stream的关闭）或一次美国墨西哥湾沿岸原料气的冻结中断，会移动整个大西洋的气价。
:::
:::

::: exercise {level=2 check="36.5"}
**消费规模。** 世界石油消费约每日1亿桶。一年取走多少十亿桶？
::: solution
100e6 × 365 = 365亿，即**每年365亿桶**——对照1960年代约550亿桶的年发现峰值与2010年代约100亿桶：使每一个"新常态"供应故事成为一个递减率故事的发现-对-消费缺口。
:::
:::

::: exercise {level=2 check="3.5"}
**煤的吞吐量。** 一座1 GW电站以38%净效率运行在24 MJ/kg的煤上。它一年烧多少百万吨煤（1年 = 每GW 3.154e16 J）？
::: solution
燃料能 = 3.154e16 / 0.38 = 8.3e16 J；质量 = 8.3e16 / 24e6 = 3.46e9 kg ≈ **350万吨**——一吉瓦就是世界煤产量的百分之一的一个单位、以及为什么煤电厂是史上建造的每单位电力最大点源CO2背后的算术。
:::
:::

::: exercise {level=2 check="10500"}
**一个构造的能量。** North Field持有约9,700万亿立方英尺的气。取1标准立方英尺气为1.085 MJ，把这个田的气换算成艾焦。
::: solution
每标准立方英尺1.085 MJ = 每万亿立方英尺1.085e18 J = 每万亿立方英尺1.085 EJ；9,700 × 1.085 ≈ **10,500 EJ**——大约一个构造里坐着世界一次能源总消费的1.6年，这是卡塔尔外交政策背后的地质事实。
:::
:::

::: exercise {level=3 check="139"}
**油砂的储备寿命。** 油砂持有约1,670亿桶储量、产约每日330万桶。以平坦速率，那是多少年的产量？四舍五入到最接近的年。
::: solution
167e9 / (3.3e6 × 365) ≈ **139年**——结束每一场油砂之争的储备寿命数字、以及为什么约束性限制是碳政策与水、以及制蒸汽的气，不是地质：相对于任何气候预算，这个资源实际上是无限的。
:::
:::

::: exercise {level=3 check="1.28"}
**两个钟。** 美国本土48州常规油在1970年以960万桶/日见顶；页岩时代的峰值是2018年的1,230万桶/日。第二个钟以多少倍超过第一个？给出两位小数。
::: solution
12.3 / 9.6 = **1.28**——一个高28%的峰值，48年之后，来自1970年被认为非储层的岩石：针对固定禀赋峰值理论最干净的一个数字、以及为什么下一个约束性限制是需求、不是供应。
:::
:::

::: exercise {level=3 check="0.28"}
**成熟盆地。** 英国北海已产出约270亿桶；剩余未发现与未开发资源估计为50–100亿桶。用中点，*已产出*体积的多少分数仍剩？给出两位小数。
::: solution
中点7.5 / 27 ≈ **0.28**——定义[[earth-resources/petroleum-systems]]一课北海例子所描述的经济与退役景观的成熟盆地比率。
:::

::: warning 关于化石燃料生产的四个误解
1. **"储量是一份物理库存。"** 储量是一个价格与技术的声明：同一批North Slope原油在1968年是"资源"、在1977年以一个不同的油价与管道状态是"储量"。储备寿命比（为油、气、煤引用的R/P数字）因此对生产国向上漂移、对被禁运国向下漂移，而跨制度比较它们毫无意义——阅读它们的纪律在[[earth-resources/resources-reserves]]一课里。
2. **"峰值石油被证伪了。"** 常规*石油供应*见顶没有被证伪——本土48州石油确实在1970年见顶、而常规全球基础自2005年以来持平到递减——但*总*曲线不断重新打钟，因为非常规供应比常规递减来得更快。诚实的说法是技术、价格与政策、不只是地质单独设定日期——而一个由电动车、效率与可再生驱动的需求峰值如今是起作用的那个峰值，任何资源都无法阻止它。
3. **"煤可以被快速淘汰，因为它在西方正在衰退。"** OECD煤炭需求自2012年以来下降了约30%，但非OECD（中国、印度、东南亚）持有约75%的运行机组队，亚洲电厂的中位年龄不到15年、对照35–40年的寿命、而2021–2022年电力崩溃的冬天展示了当气失败时煤份额反弹有多快。煤炭淘汰是一个*机队年龄与电网灵活性*问题、不是一个情绪问题。
4. **"甲烷在CO2面前无关紧要。"** 在20年上甲烷捕获约CO2的80倍热量（IPCC AR6的GWP-20为82.5），而链条的泄漏——2018–2024年美国EPA清单修订与IEA对每年7,000多万吨能源部门甲烷的追踪——是把天然气称为"桥梁燃料"与称其为煤的同侪之间的差别。好消息也是算术：泄漏是最便宜的减排（捕获放空的气常常自己付账），这就是为什么2021年全球甲烷承诺与2024年甲烷规则使它成为第一个针对链条、不是分子的化石监管。
:::

## 小结

::: summary
把碳氢化合物取出来是一个压力与波及的故事：天然驱动（溶解气、气顶、水、压实）交出原地油的10–25%，注水——世界一半桶背后安静的技术——把它抬到30–45%，而蒸汽、CO2与化学品为剩余部分作战，以致"采收率"是一个桶承载多少工程的诚实度量。最近二十五年的技术（可导向水平段、60段完井、水下系统与FPSO）与其说找到了新盆地，不如说重新定义了资本能够作业的岩石与水深，产生了供应曲线的两次重新打钟——深水与页岩——并把边际桶从波斯湾移到Permian、北大西洋与Athabasca。煤，仍占一次能源的27%与最大的单一排放来源，在地表运行同一个物理：一个由镜质体反射率读的煤化阶梯、两种劳动与景观足迹迥异的开采几何、以及一个如今分裂成OECD淘汰（英国从1913年的2.87亿吨到2024年的零兆瓦）与亚洲机队年龄现实的政治经济学。气，燃烧最干净、最讲物流的燃料，是转型的摆动伙伴——而它的泄漏记账、不是它的燃烧，是那个未决的问题。贯穿一切的是Hubbert诚实的幽灵：产量跟随发现、库存有限、而唯一持久的预测是曲线是一叠钟，其下一格由技术与政策使什么是可采的——或允许的——来设定。下一课把这些燃料腾出的孔隙空间变成储存资源；再下一课转向与含水层共享的水。
:::
