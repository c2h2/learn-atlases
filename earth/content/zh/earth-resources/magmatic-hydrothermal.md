现代经济里九成的金属坐在其成因涉及两个过程之一的矿床里：一个硅酸盐熔体在通往结晶的路上把金属富集起来，或一个热的水溶液把金属淋滤、搬运、并把它降落在某个可被开采的地方。读这些过程的学科——经济地质学——把世界的矿体组织成*矿床模型*、原型（斑岩、VMS、MVT、造山脉型、IOCG、层状侵入体），它们同时是成因假说与勘探清单，而模型的成功是地质学里以系统思考的最强论据：1960年代的斑岩铜模型把一个采矿奇物（美国西南部低品位的浸染状岩株）变成了找到Escondida、Grasberg与安第斯和太平洋成矿世每一个巨矿的勘探模板。本课按一个地质学家读它们的顺序——源过程、搬运、捕获——走过岩浆与热液两大家族，并用四个矿床（Bushveld、Olympic Dam、Solwara 1、Kalgoorlie）展示同一个流体与熔体的物理如何建造一个层状铬铁矿、一个角砾岩筒、一个海底丘与一个造山金矿田。

::: definition 岩浆成矿过程：相容性、分离结晶与不混溶 {#def-magmatic-processes}
岩浆矿床的形成是因为元素在熔融与结晶期间不等量地分配（[[geochemistry/trace-elements]]的分配系数与相容性逻辑应用于矿）。四个工业应用：**部分熔融富集**（地幔的不相容元素特征使碳酸岩成为本行星的REE、Nb与P富集者——Bayan Obo的REE-Fe-Nb、Palabora的Cu-磷灰石-磁铁矿、Phalaborwa磷矿的P；而地幔的高程度熔融使科马提岩成为Ni的主力——Kambalda 3,300万吨、3–5% Ni坐在2.7 Ga的科马提岩熔岩流里，因为一个亏损地幔40%的熔融产生了一个已携带正常地幔10倍Ni的熔体）。**分离结晶堆晶**（层状侵入体：在一个长寿命岩浆房里沉降的晶体建造出工业品位的单矿物层——Bushveld的铬铁矿层（在一个100公里厚的侵入体堆里0.5–2米、40–50% Cr₂O₃）、Stillwater与Norilsk含PGE的铬铁矿与硫化物层、Phalaborwa的磷灰石层、Tellnes的Fe-Ti-V磁铁矿层与White Mountain斜长岩套件）。**硫化物不混溶**——亲铜元素最重要的单一富集机制：在硫化物饱和时形成一个分离的富Fe-Ni-Cu液体（一个*硫化物熔体*，900–1,200 °C、密度约5），而对Cu、Ni、PGE、Re、Os有10²–10⁴的分配系数，把它们从数千立方公里的岩浆里剥进几立方公里的液体——Norilsk-Talnakh 4.5亿吨、1.8的Ni+Cu+PGE与1.2亿盎司伴生Pd-Pt、Kambalda的镍、以及Bushveld的Merensky与UG2的PGE矿礁（其成因——沉降的晶-液糊状物对后来的再活化——在一个世纪研究后仍是本领域最活跃的争论）。**流体出溶与晚岩浆卤水**（一个富水花岗岩或碳酸岩在2–5千米深度出溶的水把Sn、W、Li、F、Be与Nb富集成云英岩与伟晶岩（Pilbara与浙江的LCT伟晶岩、Cinovec与Zinnwald的W-Sn云英岩），而过碱性岩与含黄玉花岗岩的不混溶富盐卤水造出宜春与康嘎尔昆的Rb-Cs-Li矿田）。构造控制就是勘探地图：弧与后碰撞环境造出斑岩与浅成热液；克拉通与大火成岩省环境造出岩浆硫化物与层状侵入体；裂谷与克拉通边缘环境造出碳酸岩与碱性杂岩——全球禀赋*在时间与空间上成簇*（1970–80年代的成矿世概念：2.7、1.9、0.5 Ga的科马提岩-Ni与绿岩-金成矿世、2.06 Ga的Bushveld事件、55–25 Ma的安第斯斑岩脉）而非均匀分布的理由。
:::

::: definition 斑岩系统：本行星的铜、钼与（部分）金工厂 {#def-porphyry}
斑岩铜系统是地球上量化得最好的矿床系统、也是工业金属供应的主力：世界约60%的铜与约90%的钼来自斑岩及斑岩相关矿床（USGS与Sillitoe的综合），包括每一座前十的铜矿。原型（Bingham、Butte、El Teniente、Escondida）：一个1–3千米直径、富水、氧化、中性到长英质岩浆的穹窿（"斑岩"岩株，就位于一个层火山之下2–6千米深度）结晶并出溶一个含Cl与S的卤水（200–600 °C、1–20 wt%盐、早期石英脉的含石盐流体包裹体）；金属以氯化物络合物（CuCl₂⁻、MoO₄²⁻）被携带、并在流体冷却、沸腾或被大气水稀释处降落，产生每个勘探项目都读的签名性**蚀变分带**——钾化核（钾长石-黑云母，Cu核）、中间泥化与绢英岩化（绢云母-石英，矿石坐在其中的"壳"）、向外的高级泥化与青磐岩化（分带是一张流体流动图，而1960–70年代发现蚀变壳*先于并大于*矿石，使它成为通往被掩埋岩株的矢量）。成因要求解释了构造成簇：来自板片的、富水的、*氧化的*岩浆（高fO₂使硫保持为硫酸根，所以Cu保持活动；还原的岩浆提前饱和硫化物并早早失去Cu——2010–2020年代的"板片氧化"与弧岩浆肥力文献）、厚而不太厚的地壳（2019–2023年关于弧地壳厚度的"斑岩肥力"工作：30–50千米有利于富adakite的板片熔融机制）、以及一级地壳构造（同时聚焦岩浆与流体的断层系统——Atacama断层带在Escondida矿田的角色）。这个家族的经济学是资源一课的品位-吨位权衡之物理化：0.3–0.6% Cu、0.5–5 Gt（一个Escondida矿体含的铜比澳大利亚全部历史产量还多），以每日40万吨的吞吐量露天或崩落法开采。相关家族：**浅成热液**脉与角砾岩（100–300 °C、小于1.5千米的远端表达——像Tonopah与Hauraki平原的低硫化作用钾长石-绢云母Au-Ag矿床，由沸腾与流体混合在浅地壳里制造；像La Coipa的高硫化作用高级泥化矿床）、**斑岩金**（Lihir、Cadia与Mocoa带的高fO₂、高Cl、低Cu/Au系统）、以及**IOCG**家族（下文）其与斑岩和浅成热液系统的边界是本领域最有产出的争论。
:::

::: definition 热液矿床系统：流体、源与捕获 {#def-hydrothermal}
热液矿床由水溶液（100–600 °C，从几个wt%到40 wt%以上的盐）制造，它们从岩石里淋滤金属、以氯化物、硫氢化物或氟化物络合物携带它、并在一个捕获处沉淀——而本学科的核心方法是*流体取证*：流体包裹体显微测温（均一温度、冰点与石盐/水盐矿融化给出T与盐度）、稳定同位素（脉石英与硫酸盐的δD与δ¹⁸O区分岩浆水（δD约−20到−60、δ¹⁸O约+5到+10）、大气水（多数地体δD < −80）、变质脱水（δD约−20到−60、δ¹⁸O被围岩移动）、与海水（δ¹⁸O约0、放射成因Sr））、以及放射成因示踪剂（硫化物本身的Sr-Nd-Pb-S-Hg）。流体来源的分类组织各家族：**岩浆-热液**（斑岩、云英岩、锡卡斯特、高硫化作用端元——其水与硫主要为岩浆来源的流体）；**变质**（造山金与脉型系统：绿片岩相变沉积岩与绿岩在300–450 °C的脱水、被深部地壳断层聚焦的Au-As-Sb-W流体（2019年Hagemann与同事的综述；2019年《Nature Geoscience》的核源反题））；**盆地卤水**（Ozark与阿巴拉契亚矿区的密西西比谷型Pb-Zn与爱尔兰的碳酸盐容矿矿田：压实与地形驱动的盆地卤水在50–200 °C的迁移、矿石在基底断层与氧化碳酸岩相遇处降落、还原硫由盆地烃类的热化学硫酸盐还原提供——制造了Ozark与阿巴拉契亚矿田的"MVT机器"，以及2020年代爱尔兰碳酸盐容矿的修订）；**交代与交代置换**（花岗岩-碳酸岩接触带的矽卡岩——大盆地的Cu-W-Mo矽卡岩与阿尔金的；Biseberg与上西里西亚矿田的碳酸盐交代Pb-Zn）；以及**海底**诸家族（下文）。捕获物理是一个短清单与无限的组合：沸腾（浅成热液与造山金的沉淀机制——相分离剥走H₂S与CO₂并把金作为硫化物或自然元素降下）、流体混合（矿石品位的重晶石与萤石标记MVT与浅成热液系统的混合前锋）、氧化还原前锋（Wyoming盆地与Athabasca的铀卷前锋——[[earth-resources/sedimentary-ores]]的氧化还原捕获穿一件热液戏服）、围岩反应（使Betze-Post与Plutonic矿的断层岩形成的去硅化与硫化）、以及简单的渗透率对比（矿石壳在一个封闭层之下、使一个石油捕获成为可能的同一套地层——"地质学是一门捕获的科学"成为勘探口号的理由）。
:::

::: definition 海底与铁氧化物家族：VMS、SEDEX与IOCG {#def-submarine-iocg}
**VMS（火山成因块状硫化物）**：海底热液循环围绕活动与灭绝的扩张与弧段火山岩，从新鲜玄武岩里淋滤Cu-Zn-(Au-Ag)，并在喷口处作为多金属块状黄铁矿-黄铜矿-闪锌矿的丘与网脉状矿体降下（现代类比：TAG与Endeavour 350–400 °C的黑烟囱，其烟囱是10⁴–10⁵年的构造）、以及作为远端的沉积喷溢矿（重晶石、碧玉、锰）。古老记录——Kuroko（日本1970年代的类型例子）、Kidd Creek 15亿吨富锌堆、Flin Flon与塞浦路斯蛇绿岩矿田——供应约15%的Cu与锌的一大份额，而勘探逻辑是盆地分析：火山岩相、下盘蚀变筒、喷溢矿羽流、以及2000年代关于弧伸展速率的"VMS肥力"工作。**SEDEX（沉积喷溢矿）**：同一个喷口机器运行在盆地卤水、而不是岩浆热之上，把Pb-Zn-Ag(-Ba-F)作为纹层状硫化物页岩与丘角砾岩降进封闭或饥饿的盆地——巨大的古元古代Sullivan（1.65亿吨、9% Zn-Pb）、Broken Hill（其1917年发现与2,500万吨高品位Pb-Zn-Ag仍是这个家族的头奖、而其变质置换至今抵制一个共识模型）、Century与Mount Isa系统、以及阿拉斯加的Red Dog（6,000多万吨、约16% Zn，1968年发现、自1989年开采为世界最大的单一锌生产矿）。**IOCG（铁氧化物铜金）**：1990年代命名的家族（1992年Hitzman的提议与1995年Barton的铁氧化物(-Au-U)综合），角砾岩容矿与交代的Cu-Au(-U-REE)矿石，以磁铁矿-赤铁矿脉石、不需要明显的岩浆热源、而金属可能来自混合的盆地、变质与岩浆卤水来源——Olympic Dam、Candelaria、Carajás铁氧化物带、以及澳大利亚Gawler克拉通的Prominent Hill与Carré远景区。IOCG同时是本领域最成功的勘探模型（它找到了Prominent Hill与Kintyre矿田）与其最有争议的概念（2010–2020年代"IOCG是一个真家族还是一个收纳箱？"之争），而其2020年代的重要性是钴与稀土：Great Bear的铁氧化物系统与中元古代的带如今在每一张关键矿产远景地图上。
:::

::: example Bushveld：历史上最大的矿床系统 {#example-bushveld}
2.06 Ga的Bushveld大火成岩省（2.06 Ga事件、37万平方公里被侵蚀的侵入体与上覆Transvaal超群）是本行星的参考层状侵入体、也是行星尺度岩浆富集的案例研究：一个约9千米的镁铁质堆晶堆（Critical、Main与Merensky带），容纳世界约70%的铂族金属禀赋（USGS矿产品摘要：UG2与Merensky铬铁矿-peggmatoid矿礁，以0.5–2米的厚度与4–10 g/t的PGE品位开采、加上Platreef接触带式的矿化）、世界最大的铬资源（2023年USGS：Bushveld持有全球约5.7亿吨铬铁矿储量基础的大多数）、世界最大的锆、钒（磁铁矿层：100多万吨V₂O₅）与其最大的铪与钪富集之一。成因争论就是科学：Merensky与UG2"矿礁"（在硫化物饱和脉动处沉降的晶-液浆、1970–2020年代的文献，对铬铁矿内PGE的后来流体再活化——2011–2023年的铂族矿物学研究）、异常高的PGE与Cr通量的来源（2013–2024年关于深部地幔柱对再循环弧组分的同位素工作）、以及2020年代"Bushveld作为一个关键矿产省"的重新评估（对侵入体的Sc、Hf、V与稀土潜力的2023年《Ore Geology Reviews》调查、以及深部开采对供养Gauteng的白云岩含水层之水影响的争论）。开采现实同样有教益：120年开采浅层矿礁已把深度推过2千米（2010年代的岩爆地震、2020年代机械化对窄矿礁回采的争论），而南非自2015年以来的PGE产量下降（2022–25年的罢工、电力危机与竖井关闭）是一种转型金属的供应风险案例研究（PGE约90%用于催化转化器——2020年代电动车份额对其需求的侵蚀同时是这个省最大的价格风险、也是2023–25年PGE勘探复兴把目标对准*未充分勘探的东翼与北翼*、而不是已知矿礁的理由）。
::: solution
Bushveld是满尺度的岩浆过程一课：一个单一的地柱事件，其主侵入阶段被2021–23年的高精度年代学约束到约1百万年的脉动——建造了一个晶体沉降工厂，交付了可采层次的Cr、V、PGE、Zr与Hf，而同一个事件的侵蚀与覆盖解释了为什么70%的PGE坐在一个100 × 300公里的椭圆里。这个矿床的2020年代故事——深井、水冲突、易罢工劳工、以及一个氢经济电解槽与燃料电池PGE需求正在诞生的同时、电动车转型正在侵蚀的需求基础（柴油催化剂）——是资源一课"质量与速率、不是数量"论点的单一省份版：禀赋在规模上实际上不可撼动，而约束性限制是深度、水、电力与政治。
:::

::: example Olympic Dam与IOCG问题 {#example-olympic-dam}
Olympic Dam（南澳大利亚，1975年从一个覆盖层150米之上的地球物理异常发现——Gawler克拉通勘探地球物理的案例研究）是世界最大的铀与银资源、并位列其最大铜资源之一：38亿吨、1.1% Cu、0.3% U₃O₈与13 g/t Ag（2024年Artemis与BHP的矿产资源声明），容在一个约10千米、富赤铁矿的角砾岩杂岩里，位于一个1.6 Ga花岗岩的顶部。这个矿床是IOCG家族的类型例子与其中心的谜：金属在赤铁矿-磁铁矿-辉铜矿-黄铜矿角砾岩与交代体里、深部没有斑岩（2010–2020年代的深部钻探与大地电磁：几公里之内没有可成矿的岩浆体）、成矿流体是一个混合卤水（同位素工作：250–400 °C的盆地+岩浆+变质组分）、而事件如今被定年为约1.45 Ga（2007–2024年的年代学：角砾岩与矿化比1.59 Ga的花岗岩晚1.5亿年——"长寿命热液系统"对"短事件"之争）。开采史是资源一课开发管道案例：2012年拟议的300亿美元地下扩建（50万吨/年铜与3,500吨/年铀）之放弃、2016–19年只采铀的过渡方案、以及2021–25年将在2030年代接替1988年露天坑的更小地下设计的研究与审批程序、使其铀重新评级的2019–2024年核需求复兴、以及2023–25年认识到它的银（世界最大的单一银资源）与其钴与碲信用使它在四种商品上同时成为一个关键矿产资产。
::: solution
Olympic Dam的教训是矿床模型那一个：IOCG概念（1990年代）是围绕*它*建造的、然后这个概念找到了下一些（Prominent Hill、Carra、Kintyre矿田）——模型是勘探技术，而其力量在于它们预测看*什么*与*在哪里*（覆盖层、地球物理、角砾岩、赤铁矿）。未解决的流体来源是本领域与之共处的诚实告诫：一个矿床可以在经济与构造上被很好理解、而在五十之后成因上仍有争议，这就是为什么下面的告诫把矿床模型当作有勘探价值的假说、不是既定真理。
:::
:::

::: example Solwara 1与深海矿石试验 {#example-solwara}
2011–2016年，Bismarck海（巴布亚新几内亚的专属经济区）之下1,600米的海底被测绘、钻探与取样，作为世界第一个深海矿候选：Solwara 1，一个*现代*的活动热液丘（2011年的先导采矿——史上第一次深海块状硫化物回收——与2012–16年的取样程序），持有约18.6亿吨、1.9% Cu与8 g/t Au（2016年技术报告：3,500万吨Cu与470吨Au，品位是最好陆上斑岩的4–5倍），是Manus弧后扩张中心上约25个已知块状硫化物丘之一，那里10万年的喷口寿命（2017–2023年的Endeavour与TAG年代研究）建造出高品位富黄铜矿的烟囱与崩积，用VMS的术语说是"新鲜矿石"——未氧化、未变形、每吨的铜比陆上任何东西富100倍。2017–2025年的争议是资源一课外部性的案例：2011与2014年的环境影响评价之争（关于沉积羽流与中层水生态的2017年《Nature Geoscience》与2021年《Nature》评论、以及显示特有种喷口动物群落与多年恢复时间尺度的2023–25年生物学综合）、2021年瑙鲁"两年规则"的触发（2025年ISA的开发规章危机、20多个国家的2023–25年暂停声明、以及2024–25年欧盟与企业的采购排除）、以及2023–25年的法律架构（关于国家担保责任的2024–25年ITLOS咨询意见程序、以及停滞的2024年ISA采矿规章草案谈判）。地质学没有争议：VMS模型（本课的海底家族）在现代海底上完全像它在2.7 Ga绿岩里那样工作、而2020年代的ROV与钻船技术能开采它；未解决的是第一座矿的环境与治理成本能否被界定——同一个"外部性作为约束性限制"的判决，陆地上的矿在一代人之前达到，而它在一个海底自己的监管系统存在之前就到达海底。
::: solution
Solwara 1是本课关于*矿石*与*被允许*之差的对照实验：2020年代技术能触及的最高品位铜金资源、在无人居住的水域、不属于任何人、而仍被阻挡——因为分类系统的"经济可行性"如今包含其机构（ISA规章、ITLOS责任机制、企业采购规则）正在实时书写的环境与社会标准。它也闭合了VMS模型的环：24.5亿年前制造Kidd Creek的同一个流体系统*此刻*正在350 °C与250大气压下制造矿石，这是矿床模型是一个运行过程、不只是化石之描述的最强演示。
:::
:::

::: example Kalgoorlie：造山金与变质流体 {#example-kalgoorlie}
Kalgoorlie地体（西澳大利亚，1893年Paddy Hannan的发现、Super Pit露天坑——一个储量基础约5,000万盎司、2–3 g/t的单一坑（2023–25年矿产资源声明））是供应约30%开采金的造山金家族的类型例子（2019年Hagemann与同事的《Ore Geology Reviews》综述：从LaRonde与Timmins到Obuasi与Ashanti带的造山脉型系统）：金（伴As、Sb、W、Ag、贱金属硫化物，在石英-电气石-碳酸盐脉与交代体里）在1.9–2.7 Ga的绿岩带与相邻变沉积岩里，在3–12千米深度从一个低盐度、富CO₂、变质脱水流体沉积（流体包裹体与同位素记录：250–400 °C、δD与δ¹⁸O指向脱气的绿岩与沉积物来源）、被深部壳尺度的断层聚焦（2019–2024年"断层系统架构"勘探工作：Kalgoorlie与Kurnalpi构造走廊、Boorara与Hannan's Select矿体的弯曲-错动控制）。成因史是本领域记录最好的范式转变：二十世纪初的"岩浆"与"正长岩相关"模型（本矿区自己的地质服务）、1980–90年代的变质流体革命（1980年代Goldfarb与Groves的流体研究与1992年Groves与同事的"造山金"综合及其2013与2019年的改进）、以及2019–2025年的核源之争（2019年《Nature Geoscience》的核分异论文与2020–2024年的同位素反驳：金属的最终来源是地核、绿岩、还是两者，2023–25年的共识落在绿岩淋滤、可能有深部组分）。2020年代的勘探前沿是"500米覆盖层之下"问题（关于绿地覆盖层勘探缺口的2023年《Nature》评论、以及2024–25年Kalgoorlie组之下的深钻结果）：本矿区120年的开采找到了每一个露头表达、而下个2,000万盎司，如果它存在，在搬运覆盖层之下，而1990–2020年代的地球物理与风化层气体测量才刚刚学会看穿它。
::: solution
Kalgoorlie以一个世纪的后见之明教授流体来源的教训：矿石是一个*变质*产物（一个变形的绿岩地体在400 °C的脱水、被使它变形的同一条断层聚焦）、不是一个岩浆产物——推翻本矿区自己奠基模型的同位素与包裹体数据——而同样的物理如今指导从加纳到维多利亚的勘探。它也演示了矿床模型的生命周期：造山金模型（1990年代）组织了这个家族、驱动了1990–2010年代的发现（2014–24年西非与维多利亚的发现）、而如今正被核源之争与定义2020年代勘探前沿的覆盖层问题压力测试。
:::
:::

::: warning 关于矿床系统科学的五个误解
1. **"异常等于矿石。"** 地球化学与地球物理异常无处不在；矿石需要源、通道、捕获与保存的*结合*，而多数异常矿区从不成矿（2020年代的"省肥力"工作：少数地体供应每种金属的大部分——富集是成簇的，而异常是问题的开始、不是结束）。
2. **"矿床模型是被证明的成因。"** 斑岩、IOCG与造山金模型是*勘探工具*、边界有争议（IOCG家族之争、Olympic Dam的流体来源之争、金来源之争）：它们告诉你做哪些测量、类似系统出现在哪里，不是*必须*存在什么，而本领域的历史充满了在错误描述机制的同时组织了发现的模型。
3. **"热液意味着岩浆水。"** 同位素记录反复发现大气水、变质建造水与盆地卤水在完成搬运，即使岩浆提供热或构造（MVT的Pb-Zn系统根本没有火成岩；造山金的流体是变质脱水；Olympic Dam的卤水是混合的）——"热液"命名的是流体的温度、不是它的父体。
4. **"巨矿是典型的。"** 矿床尺寸分布是重尾的（1970–2020年代的Pareto统计：最大的1%铜矿床持有约80%的金属），而巨矿成簇在特定的构造窗口里（安第斯55–25 Ma脉、2.7 Ga绿岩、1.8–1.6 Ga的Gawler）——忽视成簇的资源评估系统性地错估勘探潜力与枯竭两者。
5. **"高品位意味着容易。"** 品位是一个包含深度、剥离、水、电力、基础设施、冶金与社会许可的可行性方程里的一项：Solwara 1是西方世界品位最高的铜资产而无法建造；Bushveld的矿礁是截止品位的100倍、在2千米处以岩爆支护开采；而2020年代"困难的"矿床（北极的、深的、缺水的、冲突邻近的）恰恰是转型情景要求的——"矿石"的定义是一个开采计划、不是一个品位。
:::

::: history 从脉矿开采到流体系统：矿床科学的三个世纪 {#history-ore-deposits}
问题比科学更老：Agricola 1556年的《De Re Metallica》已经为Harz的脉反对火山派与原地转变派、主张一个热液（泉水）成因，而18–19世纪的水成派与火成派之争、以及后来的"交代对交代置换"之争（1880–1910年代围绕Bingham与Leadville系统的Van Hise与Emmons战役）确立了矿石矿物在一个分带的生成序列里置换围岩。二十世纪提供了机制：1900–1930年代的生成与温度分带传统（1933年Lindgren的热液-中热液-浅热液矿床分类、Becke与Lindgren的脉分带研究）、1920–50年代实验的硫化物溶解度化学（1960年代Barton与Toulmin的硫化物稳定性工作）使热液搬运在热力学上定量化、以及1960–70年代成矿学的板块构造革命（1968–72年的Sillitoe与1973年的Mitchell-Garson模型把斑岩铜与VMS系于弧与扩张中心——经济地质学成为一门过程科学的时刻；1967年USGS的斑岩铜讨论会）。发现记录驱动模型：1900–10年代Bingham与Butte的大宗吨位转变、1966年Kambalda的镍（Riddell在科马提岩地体里的发现）、1960年Ertsberg与1988年Grasberg的走向区发现（最大的单一铜资源）、1975年Olympic Dam的地球物理异常发现、1970–80年代的Super Pit整合、以及1968年页岩之下的Red Dog发现、自1989年开发。流体包裹体与同位素革命（1960–70年代Roedder的包裹体显微测温、1970–80年代Taylor-Sheppard-O'Neil对矿石流体的稳定同位素测绘）把十九世纪的流体直觉变成测量，而1990–2020年代的时代是综合与工业的：1992年的造山金综合、1990年代的IOCG诸争论、2000–2020年代斑岩与盆地流体系统的数值模拟（2010–2020年代成矿的热-水-力耦合模型）、2010–2020年代的"矿床系统"远景区测绘与机器学习勘探（2019–2025年BHP与CSIRO的"发现引擎"方案）、以及2016–2025年的深海试验——书里最老的模型（VMS系统）成为最新的前沿、而其治理是本领域未决的问题。
:::

::: quiz
一个矿石流体是变质、而不是岩浆来源的最好证据是：

- [ ] 石英与硫化物矿物的存在
- [x] 低盐度、富CO₂成分的流体包裹体，其H与O同位素特征匹配脱气的围岩，在一个附近没有侵入体的地体里
- [ ] 高于500 °C的高均一温度
- [ ] 沿断层走向的矿石脉

::: solution
**同位素与包裹体的指纹**：变质脱水流体通常低盐度、含CO₂、250–450 °C、并携带正被变质之岩石的H-O-Sr同位素记忆——造山金的签名。断层走向与石英-硫化物矿物学是必要的但不是诊断性的（岩浆流体也用断层），而>500 °C指向岩浆输入。
:::

## 练习题

::: exercise {level=1 check="4"}
**含铜金属。** 一个斑岩铜矿床含8亿吨矿石、平均0.5% Cu。多少百万吨的含铜金属？
::: solution
800 × 0.005 = **4百万吨**含铜金属——大宗吨位家族的吨位乘品位的算术、也是约一个全球前十矿床的含铜规模。
:::
:::

::: exercise {level=1 check="10"}
**脉型算术。** 一个石英脉系统平均5 g/t金、200万吨矿石。多少吨含金属金？
::: solution
5 g/t × 2 × 10⁶ t = 10 × 10⁶ g = **10吨**金（约32万盎司）——脉型系统的算术：品位是斑岩的100倍、吨位小1,000倍，这就是为什么两个家族由不同的行业开采。
:::
:::

::: exercise {level=1 check="100"}
**富集因子。** 铜的地壳丰度约50 ppm。一个0.5%（5,000 ppm）的斑岩矿石代表多少倍的富集？
::: solution
5,000/50 = **100倍**——而相对于岩石可淋滤的部分，富集必须*更大*：矿石是地质作用富集的东西、而富集过程（熔体、流体、或两者）正是地质学家测绘的。
:::
:::

::: exercise {level=2 check="50"}
**镍的岩石成本。** 一个科马提岩容矿的镍矿石品位2% Ni。每吨镍金属要处理多少吨矿石？
::: solution
1/0.02 = 每吨Ni **50吨**岩石——岩浆富集的物理优势：硫化物液体过程在岩浆房里做了否则50吨磨矿必须撤销的事。
:::
:::

::: exercise {level=2 check="3.2"}
**回收率。** 一个10亿吨的斑岩矿体平均0.4% Cu而选厂回收80%。从它生产多少百万吨铜金属？
::: solution
1,000 Mt × 0.004 × 0.80 = **3.2百万吨**——回收率与品位同样重要、而是冶金（氧化物对硫化物、黄铜矿浸出的顽固性）决定含金属的哪一半变成可售的精矿。
:::
:::

::: exercise {level=2 check="41.8"}
**Olympic Dam的规模。** Olympic Dam的矿产资源是38亿吨、1.1% Cu（2024年声明）。多少百万吨含铜？
::: solution
3,800 × 0.011 = **41.8百万吨**含铜——接近世界2024年铜矿产供应（2,300万吨）的两倍在一个赤铁矿角砾岩里；使"资源"与"储量"在数十年的建矿中分道扬镳的规模。
:::
:::

::: exercise {level=3 check="10"}
**不混溶的算术。** 铜在一个不混溶硫化物液体与一个玄武质熔体之间的分配系数约1,000。如果熔体含100 ppm Cu，硫化物液体达到多少Cu浓度（%）？
::: solution
100 ppm × 1,000 = 100,000 ppm = 硫化物液体里**10% Cu**——从Norilsk到Kambalda每一个岩浆硫化物矿床背后的单一计算：一千倍的萃取进几立方公里的液体。
:::
:::

::: exercise {level=3 check="400"}
**古管道。** 金的地壳丰度约4 ppb。一个造山金矿田含1,550吨（5,000万盎司）金。如果金属从一个平均4 ppb的地壳里剥出，必须脱水和淋滤了多少十亿吨地壳？
::: solution
1,550 t ÷ (4 × 10⁻⁹ t/t) = 3.9 × 10¹¹ t ≈ **4,000亿吨**地壳——"古管道"的算术：几立方公里的矿石需要让循环流体穿过一座小山那么大的岩石，这就是为什么断层、不只是脉，是勘探目标。
:::
:::

::: exercise {level=3 check="35.3"}
**深海的数字。** Solwara 1容18.6亿吨块状硫化物、1.9% Cu。多少百万吨含铜？
::: solution
1,860 × 0.019 = **35.3百万吨**——相当于一个中等排名的斑岩、以四倍的品位、在一个活动喷口系统里；发起十年深海采矿争议与2023–25年治理冻结的那个数字。
:::
:::

::: quiz
斑岩系统的经济重要性最好表述为：

- [ ] 它们是品位最高的铜来源，因此磨矿最便宜
- [x] 它们以低品位交易巨大的吨位，供应世界大部分的铜与钼，使接近0.4%品位的开采成为可能
- [ ] 它们是小的、高品位的脉，容易找到
- [ ] 它们只容金，不容贱金属

::: solution
**规模替代品位**：约60%的铜与大部分钼来自0.3–0.6%品位、0.5–5 Gt的矿床，其蚀变分带与地球物理签名使它们在覆盖层下可被找到——使二十世纪铜负担得起、而其品位下降（资源一课）如今是这个金属的能源强度问题的系统。
:::

::: summary
- 岩浆矿床记录熔融与结晶期间的富集：科马提岩与地幔柱交付Ni与PGE（Kambalda、Norilsk、Bushveld），层状侵入体建造可沉降的铬铁矿、磁铁矿与磷灰石层，而不混溶硫化物液体把亲铜元素萃取一千倍——全都由构造环境与地体年龄严格控制。
- 斑岩系统——富水、氧化的弧岩浆出溶卤水——以0.3–0.6%的品位、数十亿吨供应世界大部分的铜与钼，以蚀变分带作为勘探矢量；其浅成热液与IOCG亲属把家族延伸进金、银与铀。
- 热液矿床是通过包裹体与同位素读的流体系统，而来源是多样的：岩浆水、变质脱水（造山金——Kalgoorlie）、盆地卤水（MVT与SEDEX的Pb-Zn）、与海水（VMS丘，在Solwara 1的现代海底上活着）——捕获物理（沸腾、混合、氧化还原、围岩反应）在它们之间共享。
- 矿床模型是成因有争议的勘探技术：斑岩、IOCG与造山金概念组织了一个世纪的发现（Olympic Dam、Red Dog、西非矿田），而其流体来源之争仍未解决——模型预测去哪里看、不是那里必须有什么。
- 2020年代的前沿是物理的与被允许的之结合：覆盖层与水下的巨矿（覆盖层问题、深海喷口、2千米的矿礁）被深度、水、电力、治理与社会许可、而不是地质限制——储量账本教过的同一个教训，如今应用于供应转型的矿床系统。
:::
