地下水是可利用淡水的隐形多数：在行星除去冰与深卤水之外的淡水里，按体积约99%在地下，而约二十亿人依赖它作为主要饮用水源、同时灌溉井为世界约40%的耕地开采它。它也是资源经济学一直分类失败的资源——既不是像降雨那样的流量资源、也不是像油那样的存量，而是一个慢吞吐的缓冲，其"可持续产量"取决于你以年、十年还是地质时间来度量。本课搭建物理（孔隙度对比出水率、Darcy定律、降落漏斗、Ghyben-Herbertz咸淡水界面），然后是超采的人文地理：Ogallala的灌溉开采、华北平原的沉降坑、在自己开采之下沉没的雅加达、以及随井而来的砷与硝酸盐羽流。它以两门有希望的文献收尾——治理（加利福尼亚的SGMA、印度的社区项目、沙特阿拉伯有意的化石地下水退出）与人工补给，把丰水年存入地下的实践，而气候波动正使它成为一种必需。先修是[[earth-resources/petroleum-systems]]一课（盆地架构与流体流动是一个主题）与[[earth-resources/resources-reserves]]一课（地下水是存量/流量混淆的终极案例）。

## 地下水的物理

::: definition 含水层、孔隙度、与Darcy定律 {#def-aquifers}
风化与沉积铺设容器；降雨与地形填充它。**孔隙度**（φ，空隙空间的分数——洁净砂岩与冰川外冲的5–15%、未固结砂的25–40%、多数结晶岩的5%以下，除非破裂或岩溶化）不同于**比出水率**（Sy，靠重力排出的分数——通常是孔隙度的三分之一到一半，因为其余作为薄膜与毛细水滞留）；在一个Sy = 0.15的100 km²含水层里，地下水位下降一米释放1500万立方米，而储存的算术总是从这个区分开始。饱和、可排出的单元是**含水层**；不可渗透的是**隔水层**（封闭压力的黏土与页岩，与盖住石油系统的同一批岩性）；当补给通过地形把地下水位推到当地地面之上时，**泉**排出，而当一个承压单元被一口其测压水头超过地面的井钻开时，井**自喷**——给了Artois其名字的承压状态、而大平原定居者在1870年代钻入它，为一代人终结了"美洲大沙漠"的神话。流动本身服从**Darcy定律**（1856年，来自Henry Darcy的Dijon砂滤实验）：比流量q = −K·∇h，其中**水力传导系数**K跨越十个数量级——黏土在10⁻¹¹ m/s、洁净砾石在10⁻² m/s——使它成为最重要也最易变的单一含水层属性。Darcy的线性（在地下缓慢层流的孔隙流速下有效）加质量守恒给出水头的扩散方程：降落漏斗按时间的平方根增长、而含水层管理在数学上是一个有人在其中的扩散问题的理由。
:::

::: definition 补给、停留时间与化石水 {#def-recharge}
含水层在降水渗入根带之下之处被填充——**补给**，在湿润高地是降雨的几个百分点、在取代了深根草的耕地之下是一缕、在沙漠下除洪水事件外实际上为零；而它们被泉、渗入河流的渗流（**基流**，维持夏季溪流、也是"一条河是一个地下水出口"是河流水文学第一句话的理由）、蒸腾植物的蒸散、以及井排空。这些项在几十年上的平衡定义**可持续产量**——而陷阱是同一个含水层有好几个可辩护的可持续时钟：一个湿润十年里重建的流动系统、潜水含水层多年的记忆、以及承压系统或化石储备其"产量"是开采。时钟是可测的：环境示踪剂给地下水定年的方式同同位素给冰定年——氚与氦-3标记1950年代核爆脉冲之后补给的水、碳-14与氯-36回溯数万年、而这些测量的全球综合（Gleeson、Jasechko与同事2010与2020年代的地下水年龄测绘项目）显示世界一半可利用的地下水比约5,000年更年轻、而一个大的少数比10,000年更老。老的尾部是**化石地下水**：撒哈拉之下的Nubian砂岩（在湿润更新世补给、停留时间数十万年、实际上不可再生）、Great Artesian Basin的澳大利亚中心、永久冻土环境的高纬卤水——其开采在严格记账上是一次含水层剥离作业、除了速度之外与采煤无法区分。年轻的头部是可再生资产——而正是年轻的头部现代开采倾向于先捕获，短路了在那套流动系统上演化的泉与湿地（Joseph Toth 1960年代综合的局部到区域流动系统层级）、早在水井区感到任何东西之前几十年。
:::

::: definition 开采、降落漏斗、与三个外部性 {#def-pumping}
一口抽水井是一个移动边界条件：以速率Q它在自己周围降低水头，形成一个**降落漏斗**，其半径大致按时间的平方根增长（1935年Theis解，此后工业的主力），捕获区域梯度的水、邻井的捕获区（使密集井区变成诉讼的**干扰**——美国合理使用的判例法、1979年《重述》的相关权利规则、以及加利福尼亚2014年的成文法转向）、以及，如果漏斗到达一条河，基流本身——现代水法的"河流消耗"条款。三个外部性随漏斗缩放。**地面沉降**：排出孔隙压力把水的载荷传给颗粒骨架，而富黏土隔水层塑性而永久地压密——威尼斯20世纪的米数、雅加达沿海带25 cm/年（2016–2018年InSAR测量显示西北部超过25 cm/年——Kamal与同事2018年《自然·通讯》的分析把它与不受管制的抽取联系起来、并帮助触发了2019年研究一个新首都的决定）、墨西哥城每十年半米的下沉、1950–70年代San Joaquin谷的9 m（美国最大的沉降灾难，谷里的井与运河按一个在其之下移动的基准设计的理由）。**咸水入侵**：浮在咸水上的淡水服从Ghyben-Herbertz关系（海平面之上每一米淡水头支撑约40米的界面深度），所以超采的沿海含水层把界面向陆侧拉动直到井氯化超标——迈阿密、曼谷、加沙地带（其人均抽取自1980年代就超过安全产量、而97%的沿海含水层现在微咸或受污染，世界银行2017年的评估）、以及使沿海盐化成为欧盟适应一项的2020年代亚得里亚与撒丁岛的入侵。**质量退化**：降落把老的、矿化的水拉进来（砷与氟在氧化还原下降、pH上升时活化——下面恒河与裂谷中毒的地球化学），而漏斗的水平范围设定了井与其上游农场或工厂之间每一个硝酸盐、溶剂与PFAS羽流的捕获半径。三者的政策教训是同一个：漏斗是隐形的、慢的、而非局地的，而这正是民主的资源管理处理得最糟的组合。
:::

::: example Ogallala：美国最大的灌溉矿 {#ex-ogallala}
High Plains含水层——Ogallala组及其姐妹单元，在从南达科他到得克萨斯的八个州之下，450,000 km²由中新世自落基山流出的河流留下的第三纪砾石与砂——是一个含水层被当作矿床使用的教科书案例，而其序列因其普遍形状值得记住。原生草之下的定居前补给，凡发生之处，是25–75 mm/年；1870–1880年代的承压钻探繁荣把平原卖给牧业帝国，崩溃跟随漏斗，而1930年代的沙尘暴干旱证明表土与水一样脆弱。起飞技术是**中心支轴喷灌机**（1950年代初获得专利），它使深而低产的含水层可大规模耕作：到1980年这个含水层承载约每年20立方公里的抽水——地球上最大的灌溉地下水集中，美国五分之一灌溉土地的麦-玉米-棉-牛综合体。开采的特征来得很快：USGS水位网络显示自1980年以来得克萨斯锅柄与堪萨斯西南数十米的下降、降落漏斗合并成区域凹陷、重灌县里饱和厚度三分之一以上消失、而2011–2013与2022–2024年干旱把抽水**拉高**、不是拉低，因为井只是更深、而含水层在变薄。治理回应是本课的后一半与其真正的新意：堪萨斯2009–2012年的地方强化管理区——堪萨斯西北的实验，灌溉者投票把自己的抽水以削减的速率封顶、而2012年州法使这样的社区所写上限可执行、内布拉斯加的地区水预算使流域用量从2000年代起大体持平、以及2019–2024年在堪萨斯、内布拉斯加与科罗拉多要求在原本无计量之处计量与报告的举措。算术不吸引人而有教益：公布的预测把重灌的西得克萨斯与堪萨斯西南的采尽在2060年代，加深井的经济性在水物理耗尽之前失效、而唯一扭转曲线的技术——滴灌转化、亏缺灌溉、休耕英亩——是穿农学外衣的水权政治。
:::

::: example 华北平原：世界上压力最大的含水层系统 {#ex-north-china}
以集约灌溉双季种植中国一半小麦的平原，把其案例研究保存在任何地方可得的最鲜明数字里。第一次全国地下水评估（由2014–2015年4,000多个监测井的调查于2015年发表）发现平原的地表与地下水系统合起来承载约每年4000亿立方米的需求、对照约3000亿的供给，地下水超采约每年70亿立方米、而亚洲最肥沃农田70,000平方公里上平均水位下降约每年1米——石家庄的漏斗加深过50米、而GRACE卫星记录（自2002年）确认平原在地球上消耗最严重的前十几个含水层系统之列（2010–2020年代GRACE与GRACE-FO质量损失重建，每年数百亿公斤、2018年《自然》的全球消耗评估把印度西北与华北平原放在开采榜首位）。沉降特征同样是工业级的：平原的城市-工业漏斗复合体（天津、石家庄、河南段）自1960年代以来累计下沉1–3米，部分由1970年代起的监测网络与人工补给试验控制、而2010年代的InSAR图集现在追踪平原整条城市走廊的厘米级沉降。北京自己的水政治是政策实验室：南水北调中线（2014年通水，从汉江向首都调集约每年100亿立方米，使城市供水水源地第一次有意关闭、以及2015–2020年的水源地关闭与水库补给已让北京几个区的水位在几十年里第一次**上升**）、2016年的水资源费改税试点（使抽水明显昂贵、而2024年全国推开的改革）、以及2019年给超采北方盆地的全国"配额管理与总量控制"制度。平原是Ogallala的对位：更快的开采、更难的政治、而——因为国家可以关闭水源地、给抽取定价、建跨流域运河——超大规模超采可以被一纸命令**遏止**的第一次演示，而未决的问题是当运河自己的水文收紧时它能否持续。
:::

::: example 雅加达：一个把自己的含水层定价到不存在的城市 {#ex-jakarta}
雅加达是三个外部性——沉降、入侵、质量崩溃——一起到来而迫使全国回应之处。这座城市坐在Ciliwung三角洲的全新世泥上，其管道供水网络长期只服务都市人口的一半不到，而家庭、饭店与工业用不受管制的井填补空缺：InSAR与精密水准网络（Abidin与同事、以及2018年《自然·通讯》Kamal与同事发表的测量）测出北部沿海村庄超过25 cm/年的沉降、自1970年代以来在Penjaringan等区累计4–5米、被其之下的地面不断超越的海堤、以及把整个社区变成季节性沼泽的潮汐洪水（"rob"）。2019年佐科总统宣布迁都计划——以2022年1月的Nusantara首都法立法，第一批部门搬迁安排在2020年代末——部分是拥堵、部分是沉降政策：一个国家首都第一次被正式与其含水层相对定价。纠正方案以其平常性而有教益：长期进行的管道供水建设（从Cisadane及以外的区域跨流域方案、2020年代的合同意在使井水先成为不必要、再成为非法）、省的井许可与计量运动（其自己的文件承认对非正规钻探的执法是约束性限制）、Great Garuda / NCICD沿海总体规划（2014年起）其海墙与填海工程，批评者指出，对城市之下的孔隙压力无所作为、以及在一个水许可在部院与法院之间有争议的国家里流域级地下水法规的缓慢到来。雅加达可迁移的发现是次序：管道的替代供水必须*先于*抽水停止到来，因为在其未到的地方，城市无论法律怎么说都继续钻——而沉降曲线只是变陡，直到海堤预算或迁都预算迫使问题摊牌。
:::

::: definition 地下水质量：安静的中毒与响亮的羽流 {#def-gw-quality}
地下水是经过过滤、清澈的、而在世界浅井的一个大少数里化学上不安全的，而两部质量文献在怪谁上不同。**天然地球化学**是更大的杀手。当抽水把地下水位推入还原的、富有机质的沉积含水层、而铁氧化物涂层溶解时，砷被释放，把吸附的砷解放进孔隙水：这个机制在恒河盆地被确立，经过西孟加拉1983年非流行性角化病的报告、1988年浅管井中砷的确认、以及1995–2002年英国地质调查局与DPHE的测绘，记录了世行所称史上最大规模的大众中毒——仅在孟加拉与西孟加拉就有数千万人暴露于准则之上、而长期进行的哥伦比亚大学与ICDDR,B队列研究在管道到来前十年记录了升高的癌症与心血管死亡。同一个还原化学标记中国河套与华北平原、阿根廷的Chaco、以及美国西部山间谷地的砷带，USGS全国水质评估在那里测绘出许多自家水井景观之下的天然砷升高。氟，从云母与萤石中被裂谷与火山高地的碱性、蒸发地下水淋出，形成第二条天然带——东非裂谷、安纳托利亚高原与德干高原的氟骨症地理。**人为羽流**更快也更可起诉：来自粪肥与化肥的硝酸盐，半个世纪的Long Island与Cape Cod记录、以及迫使欧洲最严格化肥行动计划的1990年代丹麦超标，现在在美国、欧盟与中国集约种植盆地里接近一半的浅井；来自工业的氯化溶剂，在美国超级基金程序里编纂、而由1991年Woburn马萨诸塞的《民事诉讼》审判戏剧化；以及2010年代的PFAS前沿——"永久化学品"，其分子持久性使它们成为第一个处处有源、无处有汇的污染物类别，推动美国EPA 2016年的健康建议与2024年万亿分率的饮用水标准、以及欧盟指令2020年代的限值。治理模式重复：天然污染是一个选址、混合与处理问题（孟加拉的加深与浅层含水层项目比任何管道都更快地削减暴露），而羽流是一个土地用途与责任问题——而两者在有人钻井并检测之前都不可见。
:::

::: definition 与含水层共存：治理工具与人工补给 {#def-governance}
因为地下水扩散，没有产权规则、水表或祈祷使它自我管理；有效的工具是五个，通常组合使用。**规则**（许可与执照——干旱西部的先占优先原则（"先占先得"）对照东部的河岸权原则、以及1979年《重述》的相关权利中间道路；印度的累退电力补贴使深井成为一场逐底竞赛，直到最近的州级电价改革与2019年Atal Bhujal Yojana，一个世界银行资助、跨七邦、60亿美元的社区需求项目）。**价格**（2016–2024年中国地下水税差，在超采县把税率加倍；1981年智利水市场的创设、以及2005与2022年水法修订，使宣布保护的含水层里的超采成为非法）。**计数**（计量与监测网络——2018年的发现，GRACE卫星重力测量可以直接看到流域尺度的消耗、2018年《自然》的评估给出头等部门含水层1.5 cm/年的当量水损失、以及2020年代GRACE-FO、InSAR与井数据融合成近实时的流域记账）。**储存**——**人工含水层补给（MAR）**，丰水年水的有意渗入：地表漫灌与漫滩（主力：加利福尼亚2023年的大气河之冬，其创纪录的漫灌场地与河道内作业把丰水年盈余的大部分存进地下）、沿河床的土壤-含水层处理、堰坝与渗透池在计划规模上复兴印度数千年的雨水收集几何（2000–2020年代的小流域项目，其卫星研究显示可测量的村级水位上升）、以及口渴沙漠的经典，亚利桑那中央亚利桑那项目的河道内补给（1990–2020年代的储存-回收库，为2020年代Mead湖危机储存科罗拉多河的配额）。**硬性上限**在其他一切失败之处——2014年加利福尼亚《可持续地下水管理法》（SGMA），把不受管制的公地转换为地方管理流域的最雄心尝试：27个临界超采亚流域（2017年的指定）、2020年到期的地方所写可持续计划、2040年的合规期限、到2040年代预计退出生产的约60万英亩（2020年代的经济影响研究）、以及2020年代第一批执法诉讼与州接管——以及沙特阿拉伯有意的1980–2016年化石地下水退出（1970–2016年小麦自给项目，开采古水直到2016年结束国内小麦与青饲料补贴的决定——有记录以来最大规模的灌溉含水层有意退役）。诚实的账本：治理在富裕、已计量的盆地里扭转消耗曲线；它在井多、便宜而未计数之处尚未停止开采。
:::

::: example 大人工河与以色列：一个资源，两个结局 {#ex-gmr-israel}
利比亚与以色列排干同一种资源——沙漠之下的化石水——而其两个工程是本世纪关于地下水政策最清楚的天然实验。**大人工河**（1984–2007年分阶段建成，建成的最大灌溉工程）把设计满负荷下约每日220万立方米从深撒哈拉的Nubian砂岩与Kufrah盆地用管道送到的黎波里与班加西海岸——一万到四万年前的水，补给实际上为零、而抽取速率按2000–2020年代的同位素研究是天然补给的一千倍。Gaddafi的工程在其峰值供应利比亚70%的水、在2011年战争中被争夺与破坏（2011年2–3月的关闭与2014年后民兵时代的中断，使系统的脆弱成为一个国家安全问题），而最好读作一次带纪念碑价签的数十年开采：管理局自己的估计把这些水放在本世纪耗尽，而2021年后的新井与沿海海水淡化平行建设的计划承认了转型。**以色列的转向**是相反的弧线：1950–1990年代对沿海与山地含水层的过度开发（1960–1990年代的超采、共享的加沙沿海含水层的咸化、以及国家输水道的跨流域政治），然后是2000–2020年代替代品与工具的叠加——市政废水回用至约90%的出水用于灌溉（四倍于第二名的世界领先）、海水淡化每年6亿立方米以上（2000–2020年代地中海的厂，由Sorek厂2013年创纪录的0.45美元/立方米招标价引领）、以及2000–2020年代把处理后的废水与冬季洪水人工补进沿海含水层（2010–2020年代在Sheba与Hanoteh场地的含水层储存-回收试验）——以致到2020年代以色列的含水层几十年来第一次*高于*其红线，而这个国家的地下水外交（2021–2022年约旦水换太阳能谅解备忘录、恢复的淡化换和平合同）靠盈余、不是赤字运行。成对的教训结束本课的论证：地下既不是救赎也不是无底——它是一块电池，其充电速率是地质、其深度是政治、而其最好用途，按2022年联合国水会议首次地下水总结的措辞，是作为最后手段的缓冲、不是第一手段的矿。
:::

::: history 从Dijon的滤池到卫星含水层账本 {#hist-gw}
**1856**：Henry Darcy关于Dijon供水砂滤的报告发表了仍定义这门学科的线性流动定律——一件工程制品（滤池运行数据）在一个十年内成为一个物理定律。**1863–1935**：数学装置到来——Darcy的继任者Dupuit与Forchheimer在1860年代建立承压/非承压井方程、Theis 1935年的USGS论文把热传导数学改编给降落漏斗（含水层试验的恢复方法时代开始）、而Jacob、Hantush与1950年代USGS学派完成每一个地下水模型至今仍对其校验的解析工具箱。**1890年代–1960年代**：钻探繁荣的时代——承压与涡轮泵井打开大平原、法国撒哈拉使团1940–1960年代对Iullemmeden与Nubian化石盆地的侦察（使"化石水"成为一个科学术语的IFG研究）、以及1950年代后印度的绿色革命井爆发（管井数从独立时约10万口爬到2000年代的数百万、以及随之而来的电力补贴超采）。**1972–1988**：环境的清算——美国1974年开始、1986与1996年修正的《安全饮用水法》、1980年代产生硝酸盐指令（1991年）的欧洲"酸雨与饮用水"项目、使水文学成为一门统一科学的Freeze与Cherry 1979年教材、以及开始这个领域史上最大公共卫生纠正的1983–1988年西孟加拉-孟加拉砷发现。**1990年代–2010年代**：测量与治理的十年——MODFLOW的全球标准化（1988年发布的USGS代码，每一个流域模型的事实语言）、2002年的GRACE卫星（其2010–2020年代重力测量第一次从轨道看到含水层消耗、2018年《自然》的全球消耗评估）、加利福尼亚的SGMA（2014年）与印度的社区项目转向（2019年）、以及使"实质应对水稀缺"（目标6.4）与跨界合作（6.5）成为可度量承诺的2016年联合国可持续发展目标6。**2022–2025**：地下水的外交登场——2023年3月的联合国水会议（1977年以来的第一次）把地下水位首次放在其议程上、六十年的河流流域机构实践（1972年OMVS与1978年GR4J公约）（UNESCO主导的跨界含水层评估、以及2022年国际法委员会关于含水层保护的原则草案）、以及使深层地下、再一次，成为本世纪最后手段废物的目的地的2024年美国EPA PFAS标准。
:::

## 检验你的理解

::: quiz {#quiz-sy}
一个含水层孔隙度0.30。其比出水率最可能是：

- [ ] 0.30，因为全部空隙空间都排出
- [x] 0.05–0.15，因为颗粒表面薄膜与毛细水被保留
- [ ] 0.60，因为排水增加压实体积
- [ ] 不确定——比出水率与孔隙度无关

::: solution :::
比出水率是孔隙度中靠重力可排出的分数；其余（比持水度）紧贴在在颗粒表面与细毛细管里。对洁净砂与砾石，Sy通常是孔隙度的三分之一到一半，所以对φ = 0.30，0.05–0.15是预期范围——也是"含水层持有X立方公里"高估可抽水两到三倍的理由。
:::
:::

::: quiz {#quiz-as}
恒河盆地砷危机最好的解释是：

- [ ] 排入补给管井河流的工业砷排放
- [ ] 三角洲之下的火山灰层
- [x] 在抽水降低的地下水位之下，年轻、富有机质三角洲沉积里铁氧化物的还原溶解
- [ ] 沿断层运移的深部地热卤水

::: solution :::
全新世三角洲砂含有机质与富吸附砷的铁涂层；当抽水加深地下水位、而孔隙水转为还原时，铁氧化物溶解、并把砷释放进管井所钻的同一个浅含水层。工业解释是最初的假说、而被深度与面状格局排除；地球化学机制（及其对抽水制度本身的依赖）就是为什么这场危机没有一个简单的工程终点。
:::

## 练习题

::: exercise {level=1 check="1000"}
**Darcy通量。** 一个水力传导系数10 m/day的含水层下伏一个1,000 m宽、10 m厚的垂直断面，水平梯度0.01。穿过该断面的地下水排泄量是多少 m³/day？
::: solution :::
Q = K·i·A = 10 × 0.01 × (1,000 × 10) = **1,000 m³/day**——一条小溪的全部基流来自一条一公里宽的走廊：未开采的地下水移动缓慢而量大，这就是为什么泉从不干涸、而捕获区从不微不足道。
:::
:::

::: exercise {level=1 check="15"}
**储存的算术。** 一个100 km²的潜水含水层，比出水率0.15，经历1 m的一致地下水位下降。释放了多少水（百万立方米）？
::: solution :::
V = A × Sy × Δh = 10⁸ m² × 0.15 × 1 m = 1.5 × 10⁷ m³ = **1500万立方米**——注意孔隙度从不出现：靠重力排出的分数才是井与泉能交付的，而这行方程是每一份水预算消耗估计的基础。
:::
:::

::: exercise {level=1 check="289"}
**井的任务。** 一个灌溉者需要每年250万立方米，500公顷、500毫米。一口井稳定产出0.1 m³/s。多少天的连续抽水供应一季？
::: solution :::
井产量 = 0.1 × 86,400 = 8,640 m³/day。天数 = 2,500,000 / 8,640 ≈ **289天**——使含水层灌溉成为近乎全年的工业作业、而解释为什么在世界粮仓电力补贴与地下水位在政治上焊在一起的算术。
:::
:::

::: exercise {level=2 check="30"}
**矿寿。** 一个灌溉含水层有60 m的饱和厚度、比出水率0.15。若地下水位以0.3 m/yr下降，在可采出的当量耗尽之前还剩多少年的*储存水*寿命（忽略补给与经济的提前失效）？
::: solution :::
可采出水当量 = 60 × 0.15 = 9 m。寿命 = 9 / 0.3 = **30年**——而诚实的脚注是井在水耗尽之前很久就不再经济（抽水成本随深度、套管与能源上升），所以真实矿寿比储存算术说的更短：Ogallala的经济在几十年里失效、其水文在几个世纪里。
:::
:::

::: exercise {level=2 check="5"}
**沉降预算。** 一个沿海区因抽水驱动的富黏土隔水层压密以25 cm/yr沉降。20年里累计多少沉降、为什么抽水停止时不可恢复？
::: solution :::
0.25 m/yr × 20 yr = **5 m**。在富黏土单元里传给颗粒骨架的有效应力重排片状组构、排出结构水——塑性、单向的压密——所以停止抽水阻止进一步沉降、而不恢复任何高程：海堤、排水沟与海岸线必须按新基准重建，这就是雅加达与San Joaquin谷两难的全部物理。
:::
:::

::: exercise {level=2 check="80"}
**咸水界面。** 一个沿海井区维持2 m的淡水头在海平面之上。用Ghyben-Herbertz关系（每米淡水头40米界面深度），淡水-咸水界面在海平面之下多深？
::: solution :::
z = 40 × 2 = **海平面之下80米**——以及支配沿海含水层的推论：超采把水头减半，界面向井上升40米，而抽水停止后的恢复滞后可跑几十年，因为稠的咸水必须靠慢的天然补给再冲洗。
:::
:::

::: exercise {level=3 check="1000"}
**捕获宽度。** 一口抽1,000 m³/day的井在一个K = 10 m/day、区域梯度0.005、饱和厚度20 m的含水层里。正上游的稳态捕获区宽度W = Q/(K·i·b)是多少？
::: solution :::
W = 1,000 / (10 × 0.005 × 20) = 1,000 / 1 = **1,000 m**——一口井的污染物风险足迹：上游一公里之内任何硝酸盐、溶剂或PFAS源最终都到达，这就是为什么井口保护区按这一行方程绘制、而2020年代美欧井口调查项目实际上是羽流分诊。
:::
:::

::: exercise {level=3 check="2"}
**读GRACE。** 一个流域在一年里在500,000 km²上失去10 Gt的地下水质量。当量水高损失是多少厘米（水密度1,000 kg/m³）？
::: solution :::
体积 = 10¹³ kg ÷ 10³ kg/m³ = 10¹⁰ m³。高度 = 10¹⁰ / 5 × 10¹¹ m² = 0.02 m = **2 cm/yr**——GRACE（与2018年后的GRACE-FO）的分辨率逻辑：半个百万平方公里含水层的一厘米是一百亿吨，从轨道可见，而这个从毫伽级重力变化到盆地水储量的反演，使2018年全球消耗评估在没有任何新井的情况下成为可能。
:::
:::

::: exercise {level=3 check="0.25"}
**微咸水混合。** 一口井产出2,500 mg/L TDS的微咸水；一口淡水井产出500 mg/L。为满足1,000 mg/L的供水标准，可以混合多少分数的微咸水？
::: solution :::
2,500x + 500(1−x) = 1,000 → 2,000x = 500 → x = **0.25**。混合是最便宜的淡化存在——而注意残留的算术：四分之三的淡对四分之一咸意味着*淡水*含水层是稀缺投入，而在超采盆地里混合只是把一个质量问题变成一个数量问题，除非微咸份额在扩大（而随着入侵，它在扩大——加沙、金奈与中央谷地缓慢的质量到数量的厄运循环）。
:::
:::

::: warning 关于地下水的四个误解
1. **"地下水是可再生的。"** 它在岩石的时钟上、不在政策的时钟上是可再生的：年轻的、快速循环的上几百米——按2010年代年龄汇编是全球可利用体积的一半——在人类时间尺度上更新，而老的尾部（撒哈拉的化石盆地、深Ogallala、Great Artesian中心）是一个开采矿床。致命的举动，几乎每个法律系统直到最近都在做，是把两者同样定价；SGMA的2040期限与中国的超采盆地配额是把水的年龄写进法律的第一次尝试。
2. **"当含水层耗尽，我们会转向海水淡化。"** 也许——以色列与海湾显示它在技术上真实——而替代隐藏三个成本：能源（淡化的3–10 kWh/m³、对照一个抽水含水层的0.5–2）、卤水（2020年代关于卤水制锂与卤水不制的文献仍在寻找处置答案）、以及时机（一座厂要五年；一口失败的井要一个旱季，这就是为什么2023年开普敦"零日"的险些成真靠需求配给与应急含水层储存管理、不是一座厂）。海水淡化是水供应的一个地板、不是缓冲的替代品。
3. **"沉降与消耗是暂时的不便。"** 沉降是永久的海拔损失——海堤、排水沟、运河与海岸线按一个新基准重建——而消耗的质量那一腿更糟：一旦入侵或开采把老的、矿化的水拉进井区，含水层的*可用*容量可以比其总体积更快下降，而2010年代中央谷地与印度西北的记录显示废弃井多于废弃的水。消失的资源不是水；是*可抽、可处理*的水。
4. **"地下水治理是一个技术修复。"** 水文学是容易的部分——漏斗、预算与卫星是成熟的科学。决定结果的是测量（未计数的井不可治理，这就是为什么2019–2024年堪萨斯、旁遮普与墨累-达令的计量运动比任何模型都重要）、次序（替代供应先于禁令，正如雅加达停滞的改革所示）、与分配政治（2020年代加利福尼亚的休耕之争是关于矿关闭时谁得到补偿）。含水层是本课整个里最清楚的演示：一个地下资源是一个制度，而制度，不像Darcy定律，不轻易旅行。
:::

## 小结

::: summary
地下水是液态淡水的99%、而水循环中政策必须管理的最小、最慢、最隐形的部分：孔隙度对比出水率设定岩石持有的与一口井能取的；Darcy 1856年的定律使流动成为一个扩散问题，其降落漏斗按时间的平方根增长、而其捕获区到达上游一公里；而示踪时钟（核爆脉冲氚到氯-36）把资源分成一个可再生的年轻头部与一个可开采的化石尾部——一个几乎每个法律系统都忽视到2010年代的区分。人文地理跟随算术：Ogallala的中心支轴开采与其社区所写的抽马上限、华北平原每年一米的下降被运河、税收与配额法（暂时）遏止、雅加达25 cm/年的沉降把一个国家首都的搬迁放上一行预算、以及恒河盆地的砷——史上最大的大众中毒，不由工业、而由抽水自己打开的氧化还原化学释放。起作用的工具不引人注目而累积：计数（井，然后从轨道的质量——GRACE使流域消耗成为一个卫星可观测）、定价（中国的超采盆地税差）、储存（人工补给，其时刻由2023年加利福尼亚之冬宣布）、以及在计数与定价失败之处的硬性上限（SGMA的2040期限、沙特阿拉伯对一个化石含水层的有意退役）。2023年联合国水会议的判决也是本课的：含水层最好的用途是最后手段的缓冲、不是第一手段的矿——一句恰好以Darcy写成的资源经济学陈述。本课最后一课从我们在地下取走与留下的东西，转向我们欠其之上地表的：废弃井、采出水处置、甲烷渗漏、与一个退却中工业的修复账本。
:::
