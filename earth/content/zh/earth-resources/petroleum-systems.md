一个石油系统是一个沉积盆地讲的单一故事：有机质埋藏得足够快以幸存、被烹煮到恰好正确的温度足够长的时间、在其烃源岩存在排烃通道与捕获的时刻从烃源岩排出、并从此被保存下来。世界上每一个油田——Ghawar的Permian Khuff碳酸盐岩、墨西哥湾沿岸侏罗系盐丘的侧翼、圭亚那Stabroek区块的古近系浊积岩、Bakken自己的烃源岩——都是这样一个故事里的一句话，而石油地质学这门学科是一次读懂全部语法。本课逐个元素地搭建这个系统（烃源、运移、储层、封闭、捕获、时间），跟随碳氢化合物从生油灶到捕获，把勘探对待为不确定性下的组合风险，走过塑造世界禀赋的盆地家族，并以四个案例收尾——墨西哥湾、中东大油田省、南大西洋盐与浊积岩前沿、以及北海成熟盆地的第二幕——它们合起来覆盖了人类历史上生产的大部分油气。同一套语法反过来应用，就是使地下成为一个*放东西回去*的地方——二氧化碳、氢、空气——这就是为什么本课是随后的储存一课的先修。

## 石油系统：烃源、运移、储层、封闭、捕获与时间

::: definition 石油系统：要素与过程 {#def-petroleum-system}
一个**石油系统**——1980年代Shell的概念、由Magoon与USGS形式化为"一个包含在一个盆地中发生的、与单一有效烃源岩相关的全部生成与运移碳氢化合物的系统"——需要**五个要素**：一个富有机质的**烃源岩**、一个渗透性**储层**、一个不透水的**封闭层**、至少一个**捕获**、以及运移**通道**（断层、输导层、裂缝）；以及**四个过程**：生成、运移、聚集与保存——而**时间**支配全部九个，因为捕获必须在峰值排烃之前或之中存在、封闭必须在聚集之前、而埋藏路径必须在构造史的正确时刻把烃源岩带过其生油灶。这个概念的力量在于*可证伪性*：一个盆地可以因缺失单一要素而被判定无望（没有成熟烃源使陆上东南亚大部分地区几十年被判无望、没有储层质量使南北海的石炭系只能开发天然气），而USGS世界石油评估（1995–2000年）通过用概率模型逐*区带*、而不是用递减曲线逐田评估*未发现*资源，使这个概念工业化。组织本课的推论是：**油在它生成的地方被发现**，而世界巨油田的地图是世界最好烃源岩、它们埋藏史、以及当它们开始充注时已就绪的捕获的地图。
:::

::: definition 烃源岩与干酪根：TOC、类型、成熟度、与Van Krevelen图 {#def-source-rocks}
烃源岩是细粒沉积岩——海相黑色页岩、湖相页岩、有机碳酸盐岩、煤——由三个数字评估。**总有机碳（TOC）**：0.5%以上算一般、1–3%算好、3%以上算优秀（Kimmeridge Clay平均约2%、海湾的侏罗系Kazhdumi与白垩系Mahanet泥灰岩4–8%、Bakken 4–12%）。**干酪根类型**，从1960–1970年代Tissot综合的**Van Krevelen图**上的氢碳比与氧碳比读出：**I型**（藻类、湖相——最易生油、Green River组与南大西洋盐下Barremian–Aptian的湖相烃源）、**II型**（海相藻类——Kimmeridge Clay、Mahanet、Smackover的主力生油到生气干酪根）、**III型**（木质陆源——易生气、给南北海充注的石炭系煤、德克萨斯的古近系Wilcox组）。**热成熟度**，由镜质体反射率（Ro）与Rock-Eval Tmax测量，决定烃源*此刻*在生成什么：Ro约0.5以下未成熟、Ro约0.6–1.0是**油窗**、湿气到约1.3、干气到约2.0、之外是死的石墨。Tissot与Welte的《Petroleum Formation and Occurrence》（英译本1984年）编纂了使成熟度成为一个*时间-温度*属性、不是一个温度属性的动力学：同样的油可以在60 °C下用1亿年生成、或在150 °C下用100万年生成，这就是为什么快速的第三系三角洲埋藏（墨西哥湾、尼日尔三角洲）在会把一个慢速盆地的烃源烹成气的深度造出油——以及为什么"生油灶"是一个移动的、时间特定的地方、不是一条深度等值线。
:::

::: history 从Barnard的页岩到USGS评估：系统思考的150年 {#hist-petroleum-system}
零件比概念更老。**1861**：Sophus Barnard的《论石油的成因》论证Ohio含油岩石的沥青是奥陶纪藻类变质的遗骸——烃源岩的想法比任何人能证明它早六十年，而Mendeleev的无机碳化物学派占据着讲台。**1885–1901**：背斜理论（White 1885年关于宾夕法尼亚石油区的论文）把找油从在渗漏之下挖掘变成钻构造，而1901年在Beaumont附近的Spindletop喷井——从一个读作*几何*的盐核穹窿每日约10万桶喷了九天——宣告了石油时代并在十年内使美国油价减半。**1920–1930年代**：反射地震学在钻探之前使捕获可见；1930年的东得克萨斯田，美国最大的陆上田、由地球物理找到，结束了找渗漏的时代。**1940–1960年代**：生物地层学与层序测绘建造地下地层学；Wallace Pratt 1942年关于巨田地理集中性的工作预示了省的想法、而M. King Hubbert 1956年的钟形曲线论文给同样的系统一个生产命运（[[earth-resources/hydrocarbons-coal]]一课的主题）。**1968–1988**：板块构造解释了地图——1970年代的大西洋边缘模型在西非石油被发现之前预测了它、而北海1969年Ekofisk与1971年Forties的发现证实了与中美洲的被动边缘烃源岩类比——同时Tissot与Welte、以及1984–1988年的Shell石油系统论文（Magoon、Dow）使*系统*、不是捕获，成为勘探的单位。**1990–2000年代**：三维地震、层序地层学与基于区带的USGS世界石油评估使这个概念工业化；**2000–2020年代**：前沿移到盐之下（巴西2006–2010年的盐下）、泥线之下（圭亚那扇，2015年）、以及进入烃源岩本身（2000年代的页岩革命）——石油系统概念在捕获思考说没有油的地方预测出油的三次。
:::

## 从生油灶到捕获：排烃、运移、聚集

::: definition 排烃、运移与一个捕获的充注 {#def-migration}
油只有在生成产生超压时才离开它的烃源岩。**一次运移**（排烃）在油窗开始时开始，此时生成的碳氢化合物与微裂缝把沥青推入输导层，通常在烃源已生成每克有机碳50–100毫克碳氢化合物之后。**二次运移**然后同时做两件事：*浮力*沿输导层与断层通道驱动轻相向上、对抗封闭层的毛细管**闯入压力**（一个好的泥岩封闭层持有几十到几百米的柱体——0.1–1 MPa的闯入压力对应约30–300米的油柱——而石盐与硬石膏封闭公里级），而*水流*沿输导网络的区域溢出点斜坡聚焦那个浮力流，所以运移从生油灶向盆地方向运行、并按溢出点顺序填满捕获——使一个成熟有利带成为生油灶上游一串逐渐更小、逐渐更年轻的田的**充满-溢出级联**。**充注源对比**——自1970年代实践的生物标志物、碳同位素与天然气（C1–C5、湿度指数）指纹识别、以及区分热成因气与微生物气的工具——是勘探者回答关于一个干井唯一重要问题的方式：*系统是缺失的，还是捕获错过了时间？*答案决定一个盆地被注销、还是带着一张不同的构造图被重开；2010年代纳米比亚的重开取决于生油灶与通道的论证、不是新捕获。
:::

::: definition 捕获与封闭：构造的、地层的、与组合的 {#def-traps}
一个**捕获**是一个渗透性层或体被封闭层在上倾方向封闭的任何几何，而其分类是短的，即使它的组合建造了这个行业。**构造捕获**：背斜（中东的褶皱带、北海的Forties与Brent构造、Spindletop）、断块与滚动背斜（墨西哥湾与北海的伸展断块，断层本身就是封闭层——1980–90年代的断层封闭革命把泥岩涂抹率与断层核带分析从构造地质学变成了风险评估器）、与盐相关的捕获（穹窿、焊接触、盐盖与盐檐——墨西哥湾沿岸与南大西洋的盐创造了数百个捕获，每个有其自己的封闭完整性难题）、以及反转构造。**地层捕获**：对着页岩的尖灭（深水湾的水道砂、北海的Brent三角洲）、生物礁与生物建造（Alberta的泥盆系Leduc礁，1947年发现、那个十年最伟大的勘探奖品）、碳酸盐岩台地与其侧翼礁（中东台地内部、巴西盐下的微生物丘）、以及不整合面之下的页岩。**组合捕获**混合两者：巨大的Elk Hills、以及North Slope的Prudhoe——一个不整合面之下被断层切割并倾斜的背斜、从下面的Shublik烃源充注。**封闭层**做实际的把守：泥岩（闯入压力与喉道半径成反比——1990年代的封闭能力文献）、蒸发岩（侏罗系Hith与Aptian的盐——地球上两个最伟大石油省的那些封闭层）、碳酸盐岩、以及沿断层的泥柱。而每个封闭层最终是一个*力学*对象，因为断层再活动、盐抽拉、抬升驱动的气膨胀、以及简单的超压都能打破一个满了五千万年的捕获——这就是为什么历史上生成的大部分石油、也许十分之九，渗漏出去了（2003年美国国家研究委员会《Oil in the Sea》调查估计天然渗漏为每年20–270万吨，表现为海湾"来自地下的油膜"），而我们生产的田是一场五千万年完整性测试的幸存者。
:::

## 烃源岩家族与世界的石油省

::: definition 短清单：少数几个烃源岩造出了大部分石油 {#def-source-families}
世界约90%的石油来自少数几个烃源层段，几乎全是海相缺氧事件沉积。**白垩系Mahanet/Mundii等同层位**（大洋缺氧事件1a–2，约120–90 Ma）给从安哥拉到尼日尔三角洲的几乎整个西非沿海、以及爪哇海（Mundii页岩）充注：II型海相页岩携带独特的白垩系生物标志物组合——类异戊二烯与伽马蜡烷——使地球化学家能把一个原油定年到它的生油灶。**侏罗系Kimmeridge Clay与Kazhdumi等同层位**分别给北海与中东大部分石油充注（Kazhdumi也经由Zagros运移给伊朗陆上的巨田充注）。**南大西洋的古近系湖相页岩**（Potiguar盆地的Aptian"Laje C"烃源与Tucano和Gabon盆地的冈瓦纳湖页岩）是I型藻类来源、油品非凡——TOC高达20%。**石炭系煤系烃源**（"煤系"与西里西亚碎屑岩）是南北海、荷兰、波兰气田与中国陆上大部分的易生气III型引擎。以及**阿拉斯加North Slope的泥盆系Shublik烃源与Williston盆地的白垩-侏罗系海相页岩**——Prudhoe Bay的130亿桶充注与自充注的Bakken——显示这个家族的两端：从一个海陆棚烃源的长距离充注、以及Bakken页岩同时是烃源与储层的致密油自生（[[earth-resources/hydrocarbons-coal]]一课非常规部分的主体）。对勘探的格局简单而残酷：建在白垩系海相与湖相烃源上的省是油主导而时间关键的（短寿命的捕获、第三系构造）；建在侏罗系与古生代海相烃源上的省是巨田之国（长寿命、稳定的克拉通盖层、巨大的有利带）；建在煤上的是气省。
:::

## 区带、圈闭、与勘探风险

::: definition 区带、圈闭、与成功概率 {#def-plays}
一个**区带**是一组具有同一烃源、储层、封闭、捕获与时间组合的圈闭——"区域泥岩之下中新世浊积岩里的含油滚动背斜"是一个区带；"对着二叠系硬石膏的礁侧翼"也是。一个**圈闭**是一个区带内一个具体的可钻捕获；勘探按区带优先进行，因为一口成功井使共享其系统的每个圈闭去风险。行业用**成功概率**量化搜寻：烃源、储层、封闭、捕获、地表与时间各独立机会之积（POS = Ps × Pr × Pse × Pt × Pti，地表与时间常折进"失败风险"修正项），前沿探井通常0.1–0.25、有利带内的侧探0.3–0.5。五个0.7相乘已经给出0.17——这就是为什么勘探是一个许多小票的**组合**生意、不是对确定之物的搜寻，以及为什么期望值经济学（POS × 平均采收 × 价格，对照井的成本）支配油便宜时钻什么。一个盆地的**圈闭清单**——按POS、平均尺寸、以及关键的*区分价值*（一个干井将对这个区带学到多少）排序——是一家勘探公司的战略资产；2010年代的页岩革命，用组合的术语说，是发现一些"被放弃的区带"一直含有连续的、按票面大小无法钻的气与油，把勘探风险转换成开发密度。
:::

## 盆地家族与全球地图

::: definition 四个盆地家族，四种勘探风格 {#def-basin-families}
**被动大陆边缘**（大西洋两岸、澳大利亚西北陆架、北海中央地堑）持有最大的深水系统：宽阔的陆坡边缘三角洲、在裂谷与大洋缺氧事件期间就位的世界级的海相烃源岩、以及三角洲砂、碳酸盐岩与盆底扇里的储层；盐（巴西、西非、墨西哥湾）点缀着捕获。**克拉通内坳陷盆地**（中东的Arab–Permian巨型盆地、西西伯利亚、Williston）是浅的、稳定的巨田工厂：适中的热流使生油灶晚而温和、构造宽阔而长寿命、而田是巨大、便宜而浅的——海湾地区石油开采成本为个位数美元的理由。**前陆盆地**（Zagros褶皱带、落基山山前、埃及西部沙漠的挠曲边缘）被冲断加载弯曲，所以构造与运移年轻而壮观——Zagros的捕获大多在最后1千万年增长，恰好赶上中新世–上新世的充注。**裂谷与裂谷-漂移盆地**（东非湖泊、Viking地堑、南大西洋的盐下）是窄、热而快的：生油灶来得早，而在南大西洋覆盖裂谷序列的盐同时创造了封闭层与其后一切的结构舞台。勘探风格跟随家族：边缘奖励地震成像与区带多样化；坳陷盆地奖励地层学的细腻与规模；前陆奖励构造的精深与时间；裂谷奖励大胆的首井几何——而每个家族的烃源岩年龄设定世界市场上*油的年龄*：西非是白垩系、北海与中东是侏罗系、墨西哥湾与东南亚是古近系。
:::

::: example 墨西哥湾：盐、速度、与深水实验室 {#ex-gom}
墨西哥湾是用盐写成的石油系统教科书。约160–155 Ma的裂谷在盆地自己未成熟的烃源之上铺下Louann组蒸发岩；盐后来的流动——底辟、盐盖、龟构造的容纳空间——创造了捕获目录，而真正的烃源岩来得更晚：深部的侏罗系Smackover碳酸盐岩，以及盐之上、其在中新世三角洲之下巨厚埋藏使现代海湾成为一台高热流、快烹煮机器的白垩-古近系海相页岩。后果从太空可见：海湾在渗漏。2003年的国家研究委员会调查把海洋天然渗漏估计的大部分归于这样的盆地，而2010年以来的卫星测量数出了数千个渗漏驱动的"海上油膜"在深水之上——一个充注了、并持续渗漏捕获两千年的系统的地面表达。勘探史是一次先做盐上、然后做盐下的区带大师课：1938–1950年代陆架上的盐丘侧翼；1961年Petronius与1980–90年代300–2,000米水深的盐盖下区带；2000年代的盐下成像（长偏移距地震、然后全方位三维）打破盐幕并交付了Thunder Horse（1999年发现，美国最大的田之一）、Mars-Bakhit、与Blind Faith；2010–2020年代勘探迈入新区带，如Shell 2014年宣布的白垩系"Atlauts"有利带。反面教训是**Macondo**（2010年4月20日）：一个盐焊之上上新世圈闭里压力预测的失败杀死11名工人、并在87天里释放估计319万桶（美国海岸警卫队/BSEE的最终估计，约7.8亿升）——这个行业对石油系统的*流体压力*与其地质同样是真实危险的最鲜明演示、以及井完整性与防喷器监管在全世界被重写的理由。
:::

::: example 中东：大油田省与Ghawar {#ex-middle-east}
Gondwana克拉通的Arab–Permian巨型盆地是有史以来组装的最大石油系统：Zagros前陆的侏罗系Kazhdumi与白垩系Mahanet等同层位海相页岩生成的油沿一个温和的区域倾伏运移——有些地方超过1,000公里——进入东边台地的碳酸盐岩工厂，那里的二叠系Khuff碳酸盐岩与侏罗系Arab–Hith区带持有巨田。Ghawar，沿Hasa拱的构造走向240公里长、最宽25公里，是史上发现的最大的常规油田：原地油以数千百万桶计、到2024年累计产量约600–650亿桶（约人类烧掉的全部油的7%）、而在2020年代中期仍以约每日380万桶从Arab-D碳酸盐岩生产，沿其脊部由油水界面之下的注水驱动。这个系统的馈赠是勘探者的梦：大陆边缘尺度的烃源、一个2,500公里的碳酸盐岩台地储层、1,000米的蒸发岩封闭、在古近系开始生长并持续温和生长的构造、以及使捕获数千万年保持完整的克拉通屋顶。它的挫败是镜像：巨田意味着巨大的*含水率*（Ghawar的注水程序处理约每日900–1,000万桶水）、侧翼里薄的油柱、以及使流动单元——1990–2000年代Saudi Aramco地质书里描述的Arab-D分层的白云岩与粒屑岩层——成为经济与边际之别的碳酸盐岩非均质性。这个省是[[earth-resources/resources-reserves]]一课里资源保守论点的经验基础：这样的巨田是在*省*里被找到的、不是三三两两，而这些省都已找到。
:::

::: example 圭亚那与南大西洋：一个区带概念找到的前沿 {#ex-guyana}
Stabroek区块，圭亚那近海150公里，是这个行业现代时代基于区带勘探最清楚的证实。ExxonMobil的团队2009年带着一个烃源岩类比进入这个前沿——给西非（120–100 Ma裂开分离的共轭边缘）充注的同一套Aptian–Cenomanian海相页岩会给圭亚那海岸充注——以及一个储层区带：从古亚马逊扇复合体泄入盆地的古新-始新世浊积扇。当没有一个地震振幅"亮点"在这片缺泥的区域起作用时，团队押注于以岩石物理细节成像的*干*扇、而不是碳氢化合物指标。2015年第一次尝试钻探的Liza是一个10亿桶的发现、在1,700米水深；到2024年该区块在Payara、Whiptail、Hammerhead与后继者上持有超过110亿桶可采资源、2019年12月首油在一个成为全世界深水开发模板的"每阶段一座FPSO"方案上到来、而到2025年产量超过每日60万桶——使圭亚那成为地球上增长最快的产油国、以及海湾之外最大的人均生产国。石油系统的解读：一个成熟的白垩系烃源在正确的成熟度、正确的地方，源自古近系世界最大的沉积物排放系统（原亚马逊）、储层在5–6千米深度20–25%孔隙度的盆底扇、封闭在深海泥岩、捕获在断层切割与超覆的地层几何——一个如今正在苏里南与共轭赤道的边缘测试的区带，那里同一个烃源充注、但储层有利带必须重新找到。
:::

::: example 北海：一个成熟省的第二幕 {#ex-north-sea}
北海是一个石油系统在四十年生产之后的样子：仅英国部分到2024年就生产了270亿桶、400多个田、而一个资源仍被算作50–100亿桶未发现、大多是小、大多靠近既有基础设施。系统本身是一个优雅的故事：中侏罗系Kimmeridge Clay烃源、油在中央地堑（Ekofisk 1969、Brent 1971、Forties 1970、Statfjord 1971）、气在南盆地被Zechstein盐封闭的石炭-二叠系储层、中央地堑的白垩系白垩储层、以及北部的古新世Forties砂岩与中侏罗系Brent三角洲——Brent与Forties两田本身以飞越平台的鸟群命名。勘探史是关于*圈闭耗竭*的世界最好数据集：1970年代的巨田让位于1980–90年代构造与地层的混合（1980年代的发现大多部分是地层的）、然后到2000–2020年代"近田"区带——Brent三角洲里的intra-Delfi、Shetland以西Clair的隆起构造古新世扇（按OOIP欧洲最大的田，1993年发现、直到2001年才生产，因为重油需要压力支撑）、以及Faroe–Shetland边缘2010–2020年代的盐下与白垩系区带。这个部门的第二幕如今也是储存的故事：制造了英国天然气的同一批枯竭田与咸水含水层正被改作碳储存（南气盆地的Acorn项目、爱丁堡与Teeside之下北海之下的Northern Endurance Partnership），这使本课的封闭能力与压力史纪律对随后的[[earth-resources/geothermal-storage]]一课直接承重。
:::

## 保存：生物降解、水洗、与热化学硫酸盐还原

::: definition 聚集如何死去：保存过程 {#def-preservation}
一个充注的捕获不会自动是一个田；聚集必须幸存它自己的地质未来。**生物降解**：携带硫酸盐与微生物的大气水沿区域含水层从露头进入、并按一个可预测的顺序吃掉原油——正构烷烃、然后类异戊烷、然后芳烃、然后树脂（1993–1995年Peters–Stow与后来Aepcks/Volkman的生物标志物阶梯；1993年Heinrich的框架把严重度从1标到10）——留下Alberta油砂的重、富硫、高黏度油（西加拿大沉积盆地的生物降解边缘，这个过程最大的地表表达，约1.6万亿桶OOIP被白垩-古近系渗漏与微生物攻击变重）、Orinoco带、以及许多墨西哥湾与爪哇田的重边。**水洗**由大气水或驱替的原生水剥走轻端与盐分；**气顶损失**由断层渗漏缩小一个田的溶解气、并能留下一圈沥青。**热化学硫酸盐还原（TSR）**——碳酸盐岩里的硫酸盐在约140 °C之上与油反应生成H2S与CO2（1995–2000年代的Ohmoto–Krouse与Worden工作；阿巴拉契亚Clinton的巨含硫田、Zagros的Kazhdumi源含硫油、以及北海的Ekofisk，其H2S随白垩系充注到来）——破坏油品、以黄铁矿与硬石膏胶结败坏储层、并封顶一个含硫趋势在多深仍经济。实际的勘探后果是一张*保存地图*：封闭层的露头距离、大气补给的古地理、断层再活动史、与埋藏-温度曲线一起预测一个否则已充注的盆地在何处把油保持为轻的——以及在何处只留下沥青垫、含硫气与渗漏。
:::

::: warning 系统可以是对的而井仍然是干的 {#warn-system-right}
一张完美的石油系统地图不保证一个发现，因为四个过程里有三个以要素所不具的方式是*时间关键的*：充注可以先于捕获形成（那时捕获是一个生油灶——一个在已证实盆地里的干井）、封闭可以在聚集之后打破（一个满了而渗漏的捕获——一个在毛细管边缘带里有沥青垫的干井）、而水可以在深部聚集幸存时冲走一个浅的聚集。这就是为什么现代勘探风险由*时间与保存*概率、而不是要素存在概率主导：在成熟省里，烃源、储层与封闭通常是已知的，而把2015年圭亚那的成功与1970年代同一片水域的干井分开的两个因素，是能分辨扇几何的成像、以及一个说这些扇是干充注的岩石物理论证——几何与充注时间，不是缺失的要素。
:::

## 检验你的理解

::: quiz
一个盆地有成熟烃源、好的储层与封闭、以及构造上一个简单的四向倾伏闭合。第一口探井变干的最可能剩余原因是：

- [ ] 储层从未被取样，所以其孔隙度不确定
- [x] 时间：捕获在峰值充注之后形成，所以当闭合存在时生油灶已经停止排烃
- [ ] 封闭层是泥岩而不是盐，而泥岩无法持有碳氢化合物
- [ ] 生物降解在钻探之前摧毁了整根柱体

::: solution
在一个要素已知的已证实系统里，时间是主导的剩余风险：一个在生油灶停止充注之后生长（或在充注之后被破坏并重新形成）的闭合，是一个运行中的石油系统里的空捕获。泥岩封闭层持有世界大部分石油（是闯入压力、不是岩性设定能力）；孔隙度的不确定性改变体积、不是存在；生物降解给一根柱体镶边，它不会抹去一个深的、刚充注的聚集。
:::
:::

::: quiz
同一个盆地里两个田生产具有相同生物标志物指纹的油，但田A的油是14 °API、富硫、沥青质的，而田B的是38 °API、低硫的。最一致的解释是：

- [ ] 田A从一个煤质烃源充注而田B从一个藻类烃源
- [x] 田A的聚集正在——或曾经——被大气水冲刷生物降解，而田B充注晚并封得深
- [ ] 田B的油是热成因的而田A的是非生物的
- [ ] 田A有一个更年轻、成熟度更低的烃源岩

::: solution
相同的生物标志物指纹意味着同一个烃源与生油灶；差别是保存。严重的生物降解按固定顺序移除烷烃与轻端，抬高密度与硫浓度并留下沥青质——正是田A的签名——而一个充注晚、深埋、与大气隔绝的聚集（田B）保持其原始品质。烃源类型会改变指纹；非生物油不是一个商业现实。
:::
:::

### 练习题

::: exercise {level=1 check="220"}
**STOIIP。** 估计一个滚动背斜的STOIIP：总厚30米、净毛比0.8、面积10平方公里、孔隙度0.25、含水饱和度0.30、油的体积系数1.2地下立方米每地面立方米（用每地面立方米6.29桶）。答案以百万地面桶给出，四舍五入到最接近的10 million。
::: solution
总体积 = 10e6 m² × 30 m = 3亿立方米。净孔隙体积 = 300e6 × 0.8 × 0.25 = 6,000万立方米。含烃孔隙体积 = 60e6 × (1 − 0.30) = 4,200万地下立方米。地面体积 = 42e6 / 1.2 = 3,500万地面立方米 = 35e6 × 6.29 ≈ 2.2亿桶，即约**2.2亿地面桶**。
:::
:::

::: exercise {level=1 check="0.27"}
**POS。** 一口探井的独立机会是：烃源0.8、储层0.7、封闭0.8、捕获0.75、时间0.8。总体成功概率是多少，两位小数？
::: solution
POS = 0.8 × 0.7 × 0.8 × 0.75 × 0.8 = 0.2688，即约**0.27**——四分之一概率的井，这是成熟省勘探圈闭的典型、已经高于前沿探井的赔率。
:::
:::

::: exercise {level=1 check="204"}
**封闭能力。** 一个泥岩封闭层有0.5 MPa的毛细管闯入压力。以油密度800 kg/m³与地层水1050 kg/m³（g = 9.81 m/s²），封闭层能持有的最大油柱是多少米？四舍五入到最接近的米。
::: solution
h = Pc / ((ρw − ρo) g) = 500000 / (250 × 9.81) = 500000 / 2452.5 ≈ **204米**油柱——对多数构造捕获足够，但提醒我们为什么盐（MPa量级的闯入压力）位于巨田之下。
:::
:::

::: exercise {level=2 check="340"}
**期望值。** 一个POS 0.2、平均可采1亿桶的圈闭钻探成本6,000万美元。如果勘探者把可采油按每桶20美元在地计价，这个圈闭的期望净价值是多少百万美元？
::: solution
期望毛值 = 0.2 × 100e6 × 20 = 4亿美元；减去6,000万美元的井，期望值 = **3.4亿美元**。80%失败赔率下的正期望值是勘探组合的常态——你买的是方差、不是确定性。
:::
:::

::: exercise {level=2 check="175"}
**可采。** 一个叠置砂田STOIIP 5亿桶、在注水下采收率0.35。多少百万桶是可采的？
::: solution
可采 = 500 × 0.35 = **1.75亿桶**。0.3–0.4的采收率是好的注水砂岩的典型；175与500之间的缺口是一次递减留下的"能量罚单"、也是气注入、WAG与EOR争夺的东西。
:::
:::

::: exercise {level=2 check="3.6"}
**生油灶的深度。** 一个盆地的地表温度10 °C、其埋藏地热梯度25 °C/km。100 °C等温线——按动力学是油窗中期——在多少深度（千米，一位小数）？
::: solution
深度 = (100 − 10) / 25 = **3.6千米**。在更热的35 °C/km梯度下同一条等温线坐在2.6千米，这就是为什么火山边缘与裂谷盆地使其烃源早而浅地成熟——以及为什么同一个烃源岩能在一个盆地的一半是油相、在另一半已气死。
:::
:::

::: exercise {level=3 check="3.8"}
**一个田的份额。** Ghawar在2020年代中期产约每日380万桶、对照世界约每日1亿桶的消费。这个单一田提供了世界供应的百分之几？数字给出一位小数。
::: solution
3.8 / 100 = 0.038，即**3.8%**——一个国家石油公司之外无可比拟的集中尺度：一个田、一个拱上一个构造，供应了约二十六分之一被烧掉的一切，这是"巨田在省里被发现、而这些省都已找到"论点的经验内容。
:::
:::

::: exercise {level=3 check="36667"}
**Macondo的速率。** 2010年Macondo井喷在87天里释放估计319万桶。平均释放速率是多少桶/日？四舍五入到最接近的千。
::: solution
3190000 / 87 ≈ **36,667桶/日**——当时约美国产量的1.5%，持续三个月、以及使井喷频率、不是井成本，成为全世界董事会级指标的那个数字。
:::
:::

::: exercise {level=3 check="3"}
**充满-溢出。** 一个生油灶以一个5亿桶油的溢出点级联充注。五个捕获沿溢出顺序在上倾方向，每个容量1.5亿桶；每个的溢出填满下一个。多少个捕获被完全填满？
::: solution
500 / 150 = 3.33，所以三个捕获填满并溢出（3 × 150 = 450）而第四个持有剩余的5,000万桶——使成熟有利带成为一个从下游到上游、满巨田、一个半满捕获、与上倾空构造序列的充满-溢出算术。
:::

## 小结

::: summary
一个石油系统同时是九样东西——烃源、储层、封闭、捕获、通道、以及必须在时间里互相咬合的生成、运移、聚集与保存——而这个概念的力量在于任何单一缺失要素证伪整个盆地、而每个存在的要素只是抬高赔率。生成是动力学、不是深度：干酪根类型设定生成什么、时间-温度剂量设定时机、而生油灶是一个捕获必须预期的移动之地、不是一条要钻到的等值线。运移是被水流沿溢出点级联聚焦的浮力、而它把整个盆地的产出集中进少数几个有利带——这就是为什么90%的油坐在十几个烃源岩家族与二十几个省里，从西非的白垩系海相页岩与中东的Kazhdumi–Mahanet一对、到Kimmeridge Clay、湖相盐下湖泊、以及煤系生气灶。勘探是POS乘法下的组合算术，靠区带概念取胜（圭亚那基于一个烃源岩类比的干扇之赌）、因时间与保存失败（充注先于捕获、封闭破裂、微生物与热化学对已寻获者的破坏）。系统的危险是真实的——Macondo每日36,667桶持续87天、渗漏掉生成物大部分的渗漏——而它的馈赠是有限的：大油田省的时代结束了，前沿如今是深的、盐下的、玄武岩下的与非常规连续的、而为碳氢化合物保持了五千万年的同一批封闭层、含水层与枯竭储层，正是如今被重新许可给碳、氢与空气的资产。下一课把这个故事的生产面变成它的资源与储量算术；再下一课把孔隙空间本身变成资源。
:::
