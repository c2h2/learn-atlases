在行星产出的每一桶油之下躺着一个大得多、慢得多的储层：放射性与原生能量以平均每平方米0.065瓦向上传导的热——比太阳少一万倍，而不息、不受天气影响、而在世界一半地壳里可钻探深度就热到能造蒸汽。本课讲地下服务能量的两种方式：把热*取出来*（水热发电、增强系统、以及按能量其实世界最大地热应用的直接供暖）与把东西*放进去*（二氧化碳、氢、压缩空气与天然气，储存在为石油保持了五千万年的同一批孔隙系统里）。两个方向共享一个地质——渗透率、盖层、压力、与岩石的力学——与一个政治经济学：地下是能源系统唯一大规模、长时长的储存技术、也是难减排部门唯一的碳清除伙伴。本课从热机本身开始（热流、资源类别、电厂热力学），走过定义这个领域的四个案例——冰岛的直接供暖经济、Larderello与The Geysers的170年蒸汽史、肯尼亚的裂谷电力奇迹、以及被浦项地震笼罩的增强地热前沿——然后转向储存：四种二氧化碳捕集机制与从Sleipner到Northern Lights的监管弧线、盐里的氢、以及压缩空气发电。先修是[[earth-resources/petroleum-systems]]一课：每个储存场地都是一个倒着读的石油系统，盖层做功、而时间尺度倒转。

## 热机：热流、资源类别、与电厂

::: definition 地球的热预算与地热资源阶梯 {#def-heatflow}
地表热流——大陆上平均0.065 W/m²、大洋地壳上0.10 W/m²，自19世纪矿山温度计起测量、而自1960年代Birch、Lee与Clark的热流汇编起全球测绘——三分之二是放射成因的（地壳岩石里铀-238、钍-232与钾-40的衰变）、三分之一是吸积与核形成留下的原生热。凡梯度偏离25–30 °C/km的传导背景之处——在洋脊、热点、弧后盆地、裂谷、以及在热生产率高的大型花岗岩基之下——资源阶梯从易到难：**水热对流系统**（携带大气循环已加热之水的渗透性岩石：200 °C以下的液控田、以及像The Geysers与Larderello那样一个低渗透盖层让储层沸腾的汽控田；2023年全球约13 GW电力装机，集中在环太平洋与东非裂谷）、**热沉积与异常压力盆地**（2–5 km处温暖的高盐卤水与超压含气带，莱茵地堑、巴黎盆地与Permian的供暖、而现在也是提锂的游戏）、**干热岩与增强型地热系统**（低渗透的热岩——花岗岩与玄武岩——被改造为工程储层，技术上最大而商业上最小的资源基础）、以及**地源热泵**（浅层回路与钻孔，把10–15 °C的年均地温用作热汇，瑞典与中国建筑供暖繁荣背后的安静技术、而按热输出是世界最大的地热应用——2023年全球装机超过100 GWth、对照13 GWe的电力）。勘探的逻辑是石油的倒置：地热钻探者不是为浮性流体找圈闭、而是找*热加渗透率加水*——而在三者有其二之处，第三个用改造或回注买来。
:::

::: definition 地热电厂：蒸汽、闪蒸、双循环——与容量因子的优势 {#def-plants}
电厂跟随流体。**干蒸汽电厂**（Larderello 1913年的发电机与1960年起的The Geysers）把蒸汽直接管到汽轮机——只在罕见的汽控田可能，而这行里最简单的机器。**闪蒸电厂**（Wairakei 1958年的发明，液控田的主力）在井口降压，使一部分热卤水"闪蒸"成蒸汽；双闪设计从残余卤水里取第二级、并把效率提到热量的12–15%——按设计是温和的，因为Carnot定律在200 °C对一个30 °C热汇是不宽容的。**双循环（有机朗肯循环）电厂**（使低温资源可获得融资的1980年代Ormat专利）让卤水流过一个在85–150 °C汽化异戊烷或氨的热交换器，完全闭环，这就是为什么1990年代以来每个回注的田（冰岛2008年同意时代的改革与德国慕尼黑的地理供暖）都把双循环机组与100%回注配对：储层就是工作流体，浪费它既是热力学也是监管的自杀。决定性的经济数字是**容量因子**：一个良好的地热电厂90–95%、对照风与光的25–45%，因为资源是一个基荷热流、不是一个天气事件——地热是唯一像煤电厂那样运行的可再生能源，在冬夜与干旱中以满输出运行，这就是为什么它的平准化成本（良好资源70–120美元/MWh，EGS更高）低估了它在高可再生电网里的系统价值。抵消的弱点在前端：勘探钻井占项目成本的30–50%、而带真实的干井风险——地热的勘探风险比石油的*更浅更便宜*、而其每MW资本强度高得多，而2016–2019年EGS挫折的一波（2010年代EGS初创的资金崩溃，从AltaRock 2013年暂停其Newberry井、到Desert Peak的所有权易手）就是那个风险的账本。
:::

::: example 冰岛：一个把火山接进管道的国家 {#ex-iceland}
冰岛是地热在国家尺度上的存在证明。这个岛同时坐在一个洋脊与一个热点上，其33个活火山系统以全球平均梯度十倍的速率漏热，而雷克雅未克的工程师们花了一个世纪学会礼貌地向它们询问。序列：1907年，Reykholt农舍的第一次直接供暖；1930年，雷克雅未克第一条区域供暖管道，在城外温泉里手工钻成；1970年代油价时代的国家钻探计划，把90%的冰岛住宅改接管内地热水（今天约55 °C的区域回路，从1–3 km钻孔泵出，而用过的水级联穿过种这个国家番茄的温室带、而自2010年代起也过其藻类与数据中心的热合同）；以及电站——Hengill的Svartsengi（1976年，其多余排放偶然建成了蓝湖的厂）与Nesjavellir（1990年），加上高温的Krafla田，2012年的中深（IDDP）研究井在4.5 km处打到427 °C的超临界水，任何人第一次钻入一个邻近岩浆的超临界储层、也是2016–2025年冰岛深钻计划商业试验的种籽。2023–2025年Grindavík附近的Sundhnúkur喷发系列——反复威胁Svartsengi的管道、迫使蓝湖关闭、并促成为保护电厂基础设施的冷却熔岩与加固工程——是反面的教训：在一座活火山上，资源与危险是同一个系统，而关键基础设施必须为喷发、也为温度设计。国家账本：冰岛约30%的电力来自地热（70%水电），99%住宅的供暖、其区域供暖成本在欧洲最低之列，而2024年政府转向地热驱动的绿色工业（数据中心、Svartsengi的绿色氢试验）现在与回注的地震性相撞——2009–2012年的Hengill群震（5.1级，2020年代的地震学分析归因于Nesjavellir回注）永久结束了"地热是无地震的"营销。
:::

::: example Larderello与The Geysers：170年的蒸汽、以及教会储层管理的投机周期 {#ex-larderello-geysers}
世界两个汽控田写下了工业最早也最硬的教训。**Larderello**，在托斯卡纳的含硼山丘里，是最老的：Francesco Zakelli 1827年从soffioni的蒸汽里提取硼酸的工艺创造了这个工业，Piero Ginori Conti王子1904年的发电机用蒸汽点亮五盏灯，1913年的工业厂开始为电网发电，而到1939年Larderello是欧洲最大的非水电电站——从一个被钻得太狠、到1940年代已开始下降、并在1950–60年代发现更深碳酸盐储层与受调节的补充回注纪律之前跌了60%的田里得到130 MW（1990–2010年代的回注计划，现在由Enel Green Power以约800 MW、近乎完全的流体回采运行，是这个田的第二世）。**The Geysers**，在加利福尼亚的Mayacama山里，是镜子：1846年在地表发现蒸汽，1920年代第一批浅井，1960年商业发电，1980年代税收抵免繁荣（1980年ERTA的横财在六年里建成1,400 MW），随后是1987年税法废除与2008–2009年金融危机，合起来产生了工业两次大崩溃；然后是储层管理的杰作——这个田的蒸汽是大气成因的、其自然补给慢、而到1990年代尽管钻探产量仍在下降，直到1997–2003年北加州水利局管道开始把湾区每年1,600–2,000万立方米的**处理过的城市废水**注入这个田：今天The Geysers三分之二的蒸汽是循环的污水，2008年中处理水交付被削减的干旱年实时显示了这种依赖，而这个田——仍是世界最大的地热综合体、约1,200 MW——是一个常设的证明：一个汽田是一个管理的水预算、不是一座矿。2020年代在这个田北端钻新的断块外延是当前的章节：即使是巨人也需要库存。
:::

::: definition 增强型地热系统与诱发地震 {#def-egs}
一个**增强型地热系统（EGS）**制造自己的储层：钻入热而致密的岩，改造它——沿天然裂隙的水力剪切、而不是页岩那种大规模新裂缝压裂，因为目标是已有节理上的剪切滑动、不是张性翼——支撑或维持导流能力、并让水循环通过工程渗透率。正典：1977–1984年Fenton Hill（新墨西哥）的干热岩实验，证明了概念而击败了经济性；Soultz-sous-Forêts（法国，1987年起，改造地震学的欧洲试验场）；Cooper Basin 2003–2012年在4–5 km与250 °C的Habanero尝试；以及2018–2025年的第二波——犹他FORGE国家实验室示范区（开源的改造数据，2018–2022年）、以及Fervo Energy的水平井、密级段、光纤监测的"地热作为制造"井，把钻探时间压向页岩经济性、而到2023–2025年有了私人资本与一个ExxonMobil伙伴关系测试异常压力卤水（2023年Fervo–Exxon在Permian的交易，同一批井产出含锂卤水与电力）。工业的影子是**诱发地震**：回注提高孔隙压力、松开断层、而红绿灯协议（在震级阈值处停止——2006年巴塞尔3.4级事件关停了一个瑞士EGS、2017年韩国5.4级浦项地震——2019年政府委托的调查把这次致损地震归因于改造井、以及随后的起诉与审判——是这个领域的警世故事）是治理的答案。物理是诚实的：任何在公里尺度把岩石再加压数十MPa的回注都能到达一个临界应力断层；缓解是距离、压力管理（软启动速率、低于断层再激活阈值的压力上限——McGarr与Cornell小组2020年代的"回注诱发地震率"模型，其2019年《科学》综合设定了红绿灯物理）、以及通过公开微震目录的透明。地热的社会许可建立在做*好的*回注故事上——而浦项就是监管者现在把它当作一个管理的工业风险、不是一个无害风险的理由。
:::

::: example Olkaria与东非裂谷：作为发展政策的地热 {#ex-kenya}
肯尼亚的东非裂谷一支——撕开红海的同一个构造撕裂——承载着一个地热开发公司放在近10,000 MW的技术地热潜力，坐在一个2004年只有约1,200 MW、多为受干旱暴露水电的国家之下。此后的建设是全球南方的旗舰。Olkaria，1967年起在UNDP赞助下勘探、1981年第一台5 MW机组，在KenGen之下到2020年代中期长到约800 MW，而Ormat的Olkaria III成为2010年《能源法》上网电价下独立发电的模板。三个政策动作做到了补贴单独永远做不到的工作：地热开发公司国家资助的勘探钻探，它交给私人建设者一个去风险的资源、不是一张彩票；固定电价购电协议，使商业债务对一类银行从未融资过的资源可得；以及基荷热对可变进口的明确战略选择，在两个干旱冬天（2009与2017年）水电崩溃使工厂停电之后做出。到2024年的账本：约1,000 MW装机，非洲最大的地热车队、五倍于第二名，全国发电的约40–45%，而Menengai与Tulu Moye的试验把该模式向埃塞俄比亚与跨境扩展。摩擦是标准的那些：与裂谷社区的管道与井场补偿纠纷（2011–2013年Olkaria安置案与2020年代的利益共享立法）、使新产能在北部搁浅的输电瓶颈、以及一个诚实的算术——一千瓦特的肯尼亚地热花的约等于一千瓦特的加利福尼亚地热花的钱、而服务一个需求年增6%、没有工业电价基础的电网。Olkaria的判决，在2023年内罗毕气候峰会的修辞里，是清醒的那个：地热不便宜——它是*主权的*，一种任何干旱、航道或邻居都关不掉基荷燃料。
:::

::: example 2020年代地热繁荣：华尔街发现地下 {#ex-egs-boom}
在2019与2025年之间，私人资本以1980年代税收抵免以来未见的猛烈涌入地热，而理由是一个隐喻的改变：地热不再是采矿、而成了制造。Fervo Energy在内华达与犹他的Cape与Beacon试验应用了页岩手册——公里级水平段、40个以上改造级段、永久光纤应变传感、闭环卤水循环——并报告钻探成本曲线向每井1000万美元下降，EGS电力与储能补贴的太阳能竞争的阈值；2023年Fervo–ExxonMobil合资随后把同一批井折进Permian的异常压力趋势，那里300 °F的卤水在一个包里携带油、气与含锂盐度，而2023–2025年对Smackover与Permian卤矿区的争夺（Exxon 2023年进入阿肯色锂收购最引人注目）使地热钻探者的关键矿产开采副业成为一个头条战略。在常规一侧，土耳其2007–2023年的上网电价建成了世界第三大的双循环车队（从零到约1,700 MW，几乎全是Gediz与Büyük Menderes地堑的低温ORC机组——而一个储层过度建设的警世故事，因为2023–2025年几个田的产量下降在合同到期之前到来，被忽视的经典补充回注教训）。而在没有风险投资的供暖转型里，安静的巨人是地源热泵：瑞典的斯德哥尔摩群岛（1980年代起的海水源，现在世界最大的城市热泵区域系统）、中国的西安与北京平原（2017–2021年"煤改洁"计划安装了数百GWth的浅层地热、而在2021年气荒中同时显示了缓冲与极限）、以及2021–2025年欧洲建筑法规一波（德国2024年供暖法的热泵默认、法国与荷兰的地热区域招标）全都建立在同一个15 °C常数上：大地作为行星最大的低品位热电池，由碳强度决定判决的电驱动。
:::

## 放回去：碳、氢、空气

::: definition 地质碳储存：四种捕集，一张许可 {#def-co2-storage}
在地下储存二氧化碳是石油工业的学科倒着运行：注入一个浮性的超临界流体——在其临界点31 °C与74 bar之上，CO2是一个单相，密度约为水的一半、比多数油更稀——进入一个渗透性咸水层或枯竭储层，而让把油保持了五千万年的同一个五要素逻辑无限期地保持它。四种捕集机制在递增的时间尺度与递减的可逆性上运行。**构造与地层捕集**：盖层——泥岩、盐、[[earth-resources/petroleum-systems]]一课的正是那些盖层——机械地兜住浮性的羽流；它是头几个世纪的主力、也是储存场地用石油勘探工具找到的理由。**残余捕集**：当羽流运移时，毛细管力把不可动CO2的串珠留在孔隙空间里——在一个非均质咸水层里可能是注入批次的10–30%，而在注入时间尺度上实际上是永久的。**溶解捕集**：CO2溶入地层水，直到稠密的、富CO2的卤水以对流指状下沉；2009–2015年Sleipner羽流的成像与2008–2016年德国Ketzin的监测显示，在富水系统里溶解成为主导的长期机制。**矿物捕集**：富CO2的卤水在几千年里沉淀碳酸盐矿物——除玄武质玻璃抄近路的地质之处，如冰岛Hellisheiði厂的CarbFix试验在2016年《科学》报告里演示的，溶解的CO2在不到两年里矿化。场地要求是一个区域盖层、足够的厚度与注入能力（压力累积、不是孔隙体积，通常是容量约束——2020年代关于卤水共采与压力管理的文献）、以及一个监测、核验与补救计划：定时（4D）地震与重力成像羽流（1997年起的Sleipner调查是参考数据集）、地下水与土壤气监视、以及地表场地的卫星或涡动通量检查。监管骨架在2005与2024年之间到来：2006年《伦敦议定书》修正案使海底下处置合法化、以及OSPAR 2007年给东北大西洋的决定；欧盟《储存指令》（2009/31/EC），使储存成为一项ETS抵减成本；美国EPA 2010年UIC第六类深回注规则；2018年的改革与2022年《通胀削减法》对45Q税收抵免的扩展（直接空气捕集高达每吨180美元）；以及决定一吨储存的碳离开谁的排放清单的《巴黎协定》第六条谈判（2021–2024年议定规则）。
:::

::: definition 储存分子与电子：氢、空气、与天然气 {#def-h2-caes}
同一些盐洞与孔隙储存能源系统其余的库存。**氢**自1971年起就在盐里工业储存，当时ICI的Billingham综合体开始让氢循环过一个盐矿盐洞——这项技术在50万桶以上规模已被证明（1980年Spindletop储氢设施在得州Beaumont附近，仍是美国唯一的大型氢盐洞），而2020年代欧洲的试验（法国的HyPSTER与Cavernest盐洞计划、德国长期运行的HyStock含水层实验与2020年代德国北部盐洞招标、荷兰2023年Drenthe盐洞氢决定）是走向季节性风制氢储存的第一步。盐是容易的宿主——不可渗透、自愈、99%的垫气纯度——而未来的车队也必须用**枯竭气田与咸水层**，而那个前沿带着真实的物理：氢使井筒钢脆化、喂养把H2吃成甲烷的地下产甲烷菌（英德氢储存试验背后的2010–2020年代实验室与现场示踪研究）、而需要一个保持混合物管输规格的垫气化学（掺氮）。**压缩空气储能（CAES）**把电储存为压力：1978年德国的Huntorf厂（盐洞290 MW两小时，自1978年靠燃气补燃运行）与1991年亚拉巴马McIntosh厂（110 MW、27小时、唯一的美国装置）证明了电网服务，而2017–2025年的先进绝热一代（中国2021年湖北60 MW/8小时厂、以及2022–2025年投运的营口与迁安300 MW级机组）通过在岩洞或陶瓷砖里储存压缩热追求无燃烧之梦，往返效率已从Huntorf的42%爬向60–70%。**天然气**本身是祖父：美国400多个地下储气库（枯竭田与含水层，约冬季就绪库存占全国年通量30%）、欧洲1,300多个储存作业、以及2022年欧盟法规在十年填充不足之后强制冬季前90%的填充、以及2022年后的论证：储气现在也是一项掺氢与战略储备资产。共同的线索是时间：电池做小时，地下储存做季节，而一个80%风光的电网两者都需要。
:::

::: example 从Sleipner到Northern Lights：为压力付钱的三十年 {#ex-sleipner}
世界的碳储存工业始于一个天然气处理的麻烦。挪威的Sleipner West田产出的气含9%的CO2——对欧洲管道规格2.5%太多了——而1992年挪威政府给Statoil一个选择：把CO2排掉或付碳税（1991年的CO2征费，按今天的钱约每吨50美元）。Statoil选择了回注：自1996年，一口专用井一直在把每年约100万吨分离的CO2放进Utsira砂，一个200–300 m厚的洁净咸水层，在海床下800–1,000 m，没有饮用水价值、上覆200 m页岩盖层。必要的偶然变成了科学：挪威要求监测，而由此产生的**定时（4D）地震目录**——到2024年30次调查，羽流被成像为一个增长的200公顷亮层、横向生长而变薄、没有泄漏特征、而在海床测到几厘米的地质力学抬升——是储存科学里最重要的单一现场数据集，是IPCC 2005年特别报告能够称地质储存为一个成熟选项、以及"Sleipner"出现在每一份监管提交里的理由。跟随者建造了现代市场：Snøhvit（2008年，海上北极，在液化厂捕集）、阿尔及利亚的In Salah（2004–11年，枯竭气的案例，其有档案的盖层抬升与新裂缝（2011–2015年IEAGHG与学术分析）重写了工业的注入压力设计规则）、加拿大的Weyburn-Midale（2000年起，CO2强化采油，在IEAGHG授权下监测2000万吨以上）、美国墨西哥湾的Grand Gulf与2017年Petra Nova和2014年Boundary Dam改造（第一批捕煤到储存的厂、而到2023–2025年成为45Q资助管道枢纽的模板——Summit USA的中西部项目与得州Circle集群）、以及欧洲的答案：欧盟创新基金2020–2024年轮（35个以上项目，计划的10 Mt/年容量）、荷兰的Porthos系统与2020–2024年鹿特丹与安特卫普港口集群决定）、以及挪威带**Northern Lights**的Longship计划，2020年的公开招标（2020年签署第一份商业CO2运输与储存合同，2025年在Øygarden外的一个码头接收第一批货物）最终使跨境CO2运输——经《伦敦议定书》修正、OSPAR批准、DNV认证的废气运输——成为一项带价目表的商业服务。在开始这一切的税三十年后，储存的约束性限制不再是地质或法律、而一直是同一个：必须有人按吨付费，而只有十几个辖区付。
:::

::: history 从Larderello的灯到储存许可：使用地下的两个世纪 {#hist-geo-storage}
**1827–1913**：Francesco Zakelli的硼酸厂把托斯卡纳的喷气孔用于工业，而Piero Ginori Conti王子1904年的发电机与1913年的厂在Larderello造出世界第一场地热电——一项将在半个世纪里被限制在火山蒸汽上的技术。**1947–1960**：实验时代——新西兰1949年Wairakei钻孔发现一个巨大的液控系统（1958年首次发电，成为世界标准的闪蒸厂原型）、意大利战后Larderello的重建、以及美国1960年The Geysers的投运。**1970–1987**：第一次繁荣与崩溃——1970与1975年美国《地热能法》修正案与1973年石油冲击后跟随的能源部实验室计划、1980年《能源税法》的抵免在六年里把The Geysers建成1,400 MW、以及1987年的废除结束了那个时代。**1971–1978**：储存的种子——1971年得州Frio砂的回注试验（第一次刻意向咸水层注入CO2，由得州经济地质局作为一个强化采油的类比运行）、1977–78年平行的美国与欧洲含水层回注试验、以及德国1978年的Huntorf压缩空气厂——三个定义现代储存领域及其监测科学的实验。**1991–1996**：把碳定价进岩石——挪威1991年的CO2征费迫使Statoil的Sleipner回注决定（1992年批准，1996年首次回注），而1996年《伦敦议定书》成为第一个考虑海底下处置的条约框架（2006年修正使其合法化）。**2004–2014**：示范的十年——2005年IPCC关于碳捕集与储存的特别报告（使储存成为一项家喻户晓政策选项的评估）、In Salah与Snøhvit、2007年起的CarbFix玄武岩实验、欧盟《储存指令》（2009年）、美国EPA第六类规则（2010年）、以及证明在一座在产煤电厂上捕集的2014年Boundary Dam改造。**2015–2025**：政策建设——《巴黎协定》第六条规则手册（2016–2024年谈判）给储存的吨记账、2022年《通胀削减法》的45Q扩展、使地下成为一个监测目标的《全球甲烷承诺》（2021年）、欧盟创新基金35个项目的2020–2024年CCS轮、《净零工业法》2024年到2030年欧盟50 Mt/年的基准、以及2025年第一批Northern Lights货物——储存从单个项目到一个定价服务业的过关。
:::

## 检验你的理解

::: quiz {#quiz-heatflow}
一个10 km²的田区以0.08 W/m²漏热。穿过那个面积的总传导热功率是多少？

- [ ] 8 kW
- [x] 800 kW
- [ ] 8 MW
- [ ] 80 MW

::: solution :::
0.08 W/m² × 10 km² = 0.08 × 10,000,000 m² = 800,000 W = 800 kW。注意定义地热工程的那个尺度差距：一整个田区漏的热比一台1 MW发动机还少，这就是为什么需要水热*对流*（搬运储存的热、不是传导它）与数百个回路的钻孔场才能造出有用的功率。
:::
:::

::: quiz {#quiz-trapping}
在一个富水咸水层里，哪种CO2捕集机制在最长的时间尺度上成为主导，而它在人类时间尺度上为什么实际上是不可逆的？

- [ ] 构造捕集，因为盖层随时间自愈
- [ ] 残余捕集，因为浮性CO2再溶解并重新上升
- [x] 溶解与矿物捕集，因为溶解的CO2造出下沉并沉淀碳酸盐的稠卤
- [ ] 所有捕集同样可逆，这就是储存未证明的理由

::: solution :::
一旦CO2溶解，卤水比其周围更稠，所以它向下运移（对流指状）、离开任何回去的路径，而在更长的时期里沉淀碳酸盐矿物。构造与残余捕集原则上可以被盖层失事或再加压解除；溶解与矿化的CO2不能上升。Sleipner、Ketzin与CarbFix的记录是速率的证据基础。
:::
:::

## 练习题

::: exercise {level=1 check="0.8"}
**穿过一个田区的热流。** 一个地热远景区覆盖10 km²、测得地表热流0.08 W/m²。穿过该面积的总传导热损失是多少兆瓦？
::: solution :::
0.08 W/m² × 10 × 10⁶ m² = 8 × 10⁵ W = **0.8 MW**——少于摊在十平方公里上的一栋住宅的供暖需求，这就是为什么经济的地热需要对流、深度、或钻孔场，不是传导热流。
:::
:::

::: exercise {level=1 check="100"}
**目标温度。** 一个沉积盆地地表温度10 °C、平均梯度30 °C/km。一口3 km的井应期望什么温度（°C）？
::: solution :::
10 + 30 × 3 = **100 °C**——双循环厂的领地（85–150 °C），土耳其1,700 MW的ORC容量与多数直接供暖方案背后的资源类别。
:::
:::

::: exercise {level=1 check="416"}
**容量因子红利。** 一座50 MW的地热电厂以95%的容量因子运行一年。它发出多少电，单位GWh？
::: solution :::
50 MW × 8,760 h × 0.95 = 416,100 MWh ≈ **416 GWh**——同样铭牌的太阳能在35%下约发出150 GWh：使地热较高资本成本在一个脱碳电网里站得住的基荷溢价。
:::
:::

::: exercise {level=2 check="120"}
**含水层容量。** 一个咸水储存目标覆盖40 km²、厚100 m、孔隙度20%。若CO2在储层密度600 kg/m³下占据孔隙空间的25%，储存容量是多少兆吨？
::: solution :::
孔隙体积 = 40 × 10⁶ × 100 × 0.20 = 8 × 10⁸ m³。CO2体积 = 0.25 × 8 × 10⁸ = 2 × 10⁸ m³。质量 = 2 × 10⁸ × 600 = 1.2 × 10¹¹ kg = **120 Mt**——一座煤电厂二十年的排放在一个温和的地层里，在任何压力（不是体积）通常施加的容量限制之前。
:::
:::

::: exercise {level=2 check="25"}
**Sleipner的账。** Sleipner项目自1996年起已注入约每年100万吨CO2。到2021年大约储存了多少兆吨、它代表一个120 Mt含水层容量的多少分数？
::: solution :::
1 Mt/年 × 25年 = **25 Mt**——约上一题算出的120 Mt含水层容量的五分之一，通过一口井注入：关于工业点源相对于沉积储存体积有多小的要点。
:::
:::

::: exercise {level=2 check="53"}
**盐洞氢能量。** 一个盐洞以平均8 kg/m³的氢密度储气，而200,000 m³的工作气可采出。以120 MJ/kg的低位热值，能回收多少能量（GWh）？
::: solution :::
质量 = 200,000 × 8 = 1.6 × 10⁶ kg。能量 = 1.6 × 10⁶ × 120 = 1.92 × 10⁸ MJ = 1.92 × 10¹⁴ J ÷ 3.6 × 10¹² J/GWh ≈ **53 GWh**——够一座小城的冬季一周、或一座1 GW氢涡轮机满功率两天：季节储存是一门体积生意、不是一门功率生意。
:::
:::

::: exercise {level=3 check="3.94"}
**直接利用经济学。** 一个10 MWth的地热区域供暖系统每年运行7,884小时（90%容量），替代0.05欧元/kWh_th的管道气。年燃料成本节约是多少百万欧元？
::: solution :::
7,884 h × 10 MW = 78,840 MWh = 7.884 × 10⁷ kWh × 0.05 €/kWh = 3.94 × 10⁶ € ≈ **每年394万欧元**——在这个速率上约1亿欧元资本成本的供暖双井田约25年回本、*不*计入碳价、空气质量效益、或使冰岛与慕尼黑的项目成为政策选择而非投资的气进口替代。
:::
:::

::: exercise {level=3 check="7.5"}
**捕集规模。** 一座1 GW煤电厂（38%净效率）燃烧石油系统一课算出的346万吨烟煤。以每吨煤2.42 t CO₂与90%的捕集率，每年必须储存多少兆吨CO₂？
::: solution :::
煤：3.46 Mt。CO₂：3.46 × 2.42 = 8.37 Mt。捕集的：8.37 × 0.90 = 7.53 ≈ **每年7.5 Mt**——那是7.5个Sleipner、或例子中含水层全部120 Mt容量在16年里用光：一座电厂是一个*十年尺度*的储存承诺，而这个算术——每吨年对每盆地方公里——就是为什么储存倡导者推动服务多个排放者的枢纽管道、不是一井一厂。
:::
:::

::: exercise {level=3 check="1381"}
**CAES往返。** Huntorf压缩空气厂以42%的往返效率输出290 MW两小时。给盐洞充电用了多少电（MWh）？
::: solution :::
输出 = 290 × 2 = 580 MWh。输入 = 580 / 0.42 = 1,381 MWh ≈ **1381 MWh**——581 MWh的差额是1978年的物理税；把压缩热储在岩石或砖里的先进绝热厂以60–70%为目标，而整个研究计划是关于把这笔税花在热力学上、不是花在天然气上，正如Huntorf的燃气补燃仍在做的。
:::
:::

::: warning 关于地热与储存的四个误解
1. **"地热无处不在。"** 常规水热发电确实是场地特定的（火山与裂谷环境、热花岗岩），而EGS与其说废除地质、不如说拓宽菜单：你仍需要3–6 km内可钻的热、循环的水、以及剪切而不是封闭的应力状态。2019年MIT《地热的未来》研究的诚实框架是，EGS可以*以更高的每千瓦成本*把资源基础扩大一个数量级——一个装扮成地质问题的经济问题、而在2025年仍是一个经济问题。
2. **"回注引发地震，因此储存不安全——或者，回注从不引发地震，因此不需要监测。"** 两半都错。诱发地震是应力的函数、不是流体类型的：使浦项成为可能的同一个物理使多数软启动、限压的项目无事发生，而从巴塞尔到俄克拉何马现在标准的红绿灯加目录制度——包括2016年USGS诱发地震综合报告之后俄克拉何马2015–2017年的处置量削减规则——是监测能起作用的证据。2011年后美国回注井规则制定的一波（对CO2的EPA第六类、2011年Youngstown俄亥俄回注之后扩展的第二类规则）是监管的答案、不是一个禁令。
3. **"CO2储存未证明。"** 反事实是地质本身：石油系统证明，凡有盖层之处，浮性流体就在沉积盆地里被封闭了数千万年——工业的任务是找盖层、不是发明封闭。在作业上，Sleipner的30次调查与2500万吨以上无泄漏、Weyburn二十年监测的强化采油共同优化、以及2025年Northern Lights服务合同，使储存成为负排放工具箱里*最少*投机的。在规模上真正未证明的不是岩石、是经济学：只有碳价、45Q式的抵免、与第六条市场使储存的吨值得付钱，而它们每一个都是一个政策可以撤销的政策变量。
4. **"储存的CO2是活得比公司久的负债。"** 它是——这正是要点。负债的框架就是为什么欧盟指令在关闭与核验之后把长期责任转给国家（指令强制的成员国转移实践，由英国2019年储存责任制度与挪威2020年规则在国家层面编纂）、为什么美国第六类规则要求对回注后百年的场地照护负财务责任、以及为什么记账问题——谁的吨、谁的吨数、谁的泄漏——消耗了十年的巴黎谈判。储存是一个千年的承诺；诚实的工业是在羽流到达之前给承诺定价的那个。
:::

## 小结

::: summary
地下是一个双向技术。把热取出来运行在梯度阶梯上——0.065 W/m²的传导背景、在洋脊、热点与裂谷使地壳变薄之处十倍的异常、以及一个从汽控蒸汽（Larderello 1913年的发电机、The Geysers 1,400 MW的税收繁荣、与现在造出其蒸汽三分之二的循环废水回注）经闪蒸与双循环厂、到作为地热真正大众市场的100 GWth地源热泵的资源层级。它的经济学是基荷经济学（90–95%的容量因子、高资本、国家资助的去风险钻探——肯尼亚的GDC模式——设计来社会化的勘探风险），而它的社会许可是一个地震管理问题：浦项的5.4级教训、红绿灯协议、与公开微震目录是改造的新常态。把东西放进去运行在倒着读的同一个五要素逻辑上：超临界CO2由盖层、毛细管、溶解与矿化保持（Sleipner–Ketzin–CarbFix证据链）、盐里的氢与压缩空气、枯竭田里的天然气——每一项都是一项价格不由地质、而由碳征费、容量市场与季节价差设定的储存服务。从1996年《伦敦议定书》经欧盟指令、第六类与45Q到第六条的监管弧线，把一个1971年的含水层实验变成了一个2025年有第一批商业货物的服务业，而欧盟50 Mt/年的基准使储存成为宣布的基础设施。约束的是本课每一课同一个限制：地下是有限的、有争议的、而受治理的——一个孔隙空间的公地，其租约以吨、巴与十年书写，而它最宝贵的财产，再一次，是盖层。下一课转向最浅、最有争议的地下资源：同一些沉积盆地里地下水。
:::
