## 地表作为一座矿：氧、水与时间作为成矿作用

深部地质靠熔融与沸腾富集金属；地表靠溶解、氧化、淘洗与沉淀富集它们——而工业账本把大部分功劳记在地表账上：铝（铝土矿）、钢铁铁的大部分（来自条带状铁建造的矿石）、大部分的镍（红土型）、锰、工业矿物（钾盐、磷酸盐、盐、硫）、三分之一的锂（卤水）、以及史上开采过的最大金矿床（Witwatersrand的古代砂矿）。沉积与地表矿系统也是最直接记录本行星化学史的那些：条带状铁建造*就是*以厘米级互层写下的Great Oxidation Event、黑色页岩是含氧海洋的痕量金属汇、而铀的不整合矿床之存在，只是因为大气与生物圈一起使地下水具有了氧化性。本课读四台地表机器——流水（砂矿）、深度风化（红土、铝土矿、次生富集罩）、化学沉淀（铁建造、锰、喷溢矿、蒸发岩、氧化还原捕获的铀）——以及把它们接通与切断的氧史，并用四个案例研究（Witwatersrand、Hamersley-Simandou、Atacama的盐湖、Athabasca盆地）覆盖金、铁、锂与铀。

::: definition 砂矿：作为密度分离机的水力学 {#def-placers}
一个砂矿是一条河、一个海滩或一阵风在数公里的沉积物上运行选矿第一步——重力分离——时留下的东西：重的、硬的、化学上耐久的矿物幸存搬运、并对着一条密度与水力学等价律富集（与[[sedimentology/sediment-transport]]同一个沉降逻辑：等沉降的颗粒按密度比的平方根缩放，所以一个直径约为金颗粒三倍的石英颗粒在水力学上表现得与它相当——细金随砂旅行、并在水流减弱处降落），而其他一切被反复的磨蚀与化学攻击移除（耐久性过滤器：金、锡石、铬铁矿、金红石、锆石、钛铁矿、独居石与钻石幸存；多数别的东西不幸存）。两个家族：**陆相砂矿**（古代与现代的：Witwatersrand 2.9–2.8 Ga的河湖相砾岩——"矿礁"——产出了约27亿盎司金、约地球开采过的全部金的三分之一，而其成因至今有争议的矿床（2015–2016年Barnicoat与McDonald在《Nature Geoscience》上的交锋：金与标志性的"球与条"黄铁矿结核的一个热液来源，对经典的河流-生化模型；2020年代的综合落在一个混合模型上：一个富Au与黄铁矿沉积物的河流砂矿，后来被盆地流体改造）；2020年代砂矿勘探的前沿是"埋藏河道"几何——砂与玄武岩之下的古水系测绘）。**海滩与近海砂矿**（现代重矿物砂工业：供应世界钛铁矿、金红石、白钛石与锆石的澳大利亚与南非岸线——2023–25年澳大利亚对钛原料（钛铁矿加金红石，钛链第一步约90%）的主导、来自近海疏浚的印度尼西亚与中国锡（2019–2023年Bangka-Belitung的环境审计文献）、纳米比亚与Namib的钻石砾石、以及Kerala与巴西海岸的独居石稀土砂矿）。经济学跟随几何：砂矿是唯一处理*未固结*沉积的矿（挖泥船与跳汰机，没有破碎或磨矿——每单位金属的能源是采矿业里最低的，这就是为什么锡与钛在砂矿存在之处富集），而它们的品位是资源一课逆品位-吨位律最极端的形态：一个2%钛铁矿的海滩砂是经济的因为"选厂"是一条浮式螺旋分级机，而一个0.2%的古代砂矿礁撑得起4千米的竖井。
:::

::: definition 风化矿床：红土、铝土矿、次生富集罩 {#def-weathering}
在热带、湿润、缓慢侵蚀的地形里，深度化学风化从岩石里剥走硅与碱基、并把不溶残余富集下来——一个在环境温度下运行了数百万年的天然选矿厂。三种工业产品：**铝土矿**（强烈风化的玄武岩或岩溶化石灰岩的Al残余：软铝石-一水软铝石-一水硬铝石伴铁氧化物，热带的馈赠——世界90%的铝始于铝土矿，在牙买加、几内亚（2019–2024年Boke矿区的激增使几内亚成为第二大生产国）与昆士兰以接近零的剥采比开采；2023–25年"红土-铝"的前沿是亚马逊与圭亚那铝土矿的毁林冲突、以及2024–25年的"铝土矿残渣"（赤泥）利用研究）、**镍红土矿**（科马提岩与橄榄岩之上的风化幔：一个褐铁矿-赤铁矿帽、一个蒙脱石"黏土硅酸盐"带、以及一个携带Ni-Mg硅酸盐矿石（0.8–2.5% Ni）的腐泥土核，如今约占世界镍产量的40%、而增长最快的供应来源（2020年代印度尼西亚的红土-HPAL与RKEF热潮使印度尼西亚成为头号生产国并触发了2023–25年镍价崩溃；2023–25年菲律宾的矿石出口与红土开采禁令之争；高压酸浸（HPAL）厂2020年代的记录——第一个十年里一半的厂挣扎、2021–24年的印度尼西亚浪潮成功了——红土便宜的采矿隐藏着残酷的火法冶金或酸成本这一工程教训）、以及**次生富集**（下降地下水位氧化前锋把铜从原生黄铜矿剥走、并以辉铜矿-铜蓝罩的形式再沉积，品位是原生矿石的2–10倍——使美国西南部、赞比亚与Atacama的矿盈利一个世纪的"氧化物与次生硫化物"矿石的来源，如今大体采尽（2020年代的"次生富集饥荒"：铜2023–25年回收率下降背后的原生硫化物浸出顽固性问题）、以及2020年代的勘探转折：沙漠覆盖之下的"盲"与"残遗"次生富集罩、关于干旱景观保存窗口的2020年代工作使Atacama晚中新世的湿润事件成为智利北部巨厚富集罩根本存在的理由）。残余家族的近亲：碳酸盐岩之上的次生锰帽（Groote Eylandt与Gabon的高品位矿石）、残余高岭土与耐火黏土、红土型金与钻石帽（"铁帽"指示物）、以及2020年代的"关键金属红土"（古巴与菲律宾的Sc-Co-Ni红土、2023–25年新喀里多尼亚与马达加斯加的钴红土提案）。
:::

::: definition 化学沉积矿床：铁建造、锰、蒸发岩、氧化还原捕获的金属 {#def-chemical-sedimentary}
当湖水与海水同大气、河流、热液喷口或盐本身反应时，水柱沉淀出可追溯数百公里的矿层。**条带状铁建造（BIF）**：交替的铁硅酸盐/氧化物（绿脱石-磁铁矿-赤铁矿）与硅质层，沉积于3.8–0.7 Ga、在2.7–1.8 Ga达到峰值——约90%开采铁的源头（Hamersley、Pilbara、Superior、Labrador与Krivoy Rog矿区；"天然"的25–35% Fe矿石经过选矿、或者在变质脱碳后作为60–67%的直运矿石开采，2020年代的"绿钢溢价"产品）。沉积机制是前寒武纪的氧泵：缺氧、富铁的深度水（"含铁海洋"）上涌到浅陆棚，当地方的产氧或蒸发把铁作为化学沉积降下、而巨大的BIF脉动在元古宙海洋的溶解铁储库崩溃时结束（2019–2024年"海洋铁储库与穿梭"综合——2019年Konhauser与2023年Swindlehurst与同事的《Nature Geoscience》与《Nature Reviews Earth & Environment》论文——用一个氧化还原穿梭的质量平衡取代了简单的"氧出现、铁沉淀"故事，其中BIF是一个缺氧海洋铁预算的汇项，而它们的终结是储库耗尽的证明）。**锰建造与锰帽**：同一个氧化还原逻辑在更高的Eh（Mn²⁺只在氧或微生物把水柱推到+0.4 V之上处氧化）：2.2 Ga的Kalahari矿田（世界陆地锰储量的约80%）、1.9 Ga的Griqualand West、以及2020年代的深海结核与结壳资源（Solwara 1一课从铜那一侧遇到的多金属结核问题）。**蒸发岩**：海水或湖相卤水在受限盆地蒸发过石盐饱和，沉淀出溶解度序列（碳酸盐 → 石膏 → 石盐 → 钾盐：泥盆系Prairie Evaporite 200多米的钾石盐-钾盐镁矾钾盐有利带使Saskatchewan约占世界K₂O的30%、二叠系Delaware与Zechstein的盐、2022年的钾盐价格冲击（白俄罗斯-俄罗斯制裁与2022–25年粮食-化肥地缘政治）、Searles Lake与土耳其-Karoo的纯碱-硼矿床、以及Atacama与Puna盐湖的锂-钾-铯-硼卤水（下文））。**渗透性砂岩里氧化还原捕获的金属**：氧化的（"卷前锋"）铀、富碳页岩里的钒-硒-钼（Muskox与Petrol型矿床）、以及还原剂丰富的底部砾岩里的铜-钴（中非铜矿带沉积容矿的层控矿石，世界约一半钴与上升份额的铜之来源，其矿柱恰好坐在其上氧化含水层与其下还原相之间的氧化还原前锋上——与铀卷相同的捕获几何，相隔20亿年）。**不整合相关铀**：地球上品位最高的铀矿（下面的Athabasca盆地），在氧化、富氯的盆地卤水约1.7–0.9 Ga在石墨基底不整合处被还原时造成。
:::

::: definition 作为成矿学的氧史：GOE、NOE与氧化还原堆栈 {#def-oxygen-metallogeny}
沉积矿石在深时中的分布是大气-海洋氧化还原阶梯的一份记录（[[earth-history/oxygen-proterozoic]]的古氧化还原代用指标文献应用于矿）：**太古宙（>2.45 Ga）**——缺氧大气、含铁海洋、没有氧化风化（所以没有卷前锋铀、没有次生铜、没有铝土矿），但有BIF脉、Witwatersrand砂矿、以及黑色页岩的Mo-Zn汇；**Great Oxidation Event（2.5–2.1 Ga）**——关于一个持久大气氧阈值的硫同位素与铬同位素证据（2011–2024年的S-MIF与Cr同位素记录：2011年Luo与同事的硫同位素综合、以及把GOE主阶置于约2.43–2.40 Ga的2023–25年高精度年代学），它接通了氧化风化（第一批红层、第一批卷型铀的前身、2.2 Ga的Kalahari锰——第一个大型锰建造，恰在台阶上）、并在随后的约3亿年里切断了BIF泵；**"无聊的十亿年"（1.8–0.8 Ga）**——一个部分氧合的海洋带一个持续含铁的深度储库（2010–2020年代的Fe形态与Mo同位素记录）、缓慢的风化、以及需要只有一个部分氧合的世界才提供的*中间*氧化还原状态的那些巨大Cu（铜矿带与中元古代的带）与铀（Athabasca，1.7–0.9 Ga事件）矿床；**新元古代-寒武纪的跃升（0.8–0.5 Ga）**——"第二次氧化"（2010–2024年的Ce异常、Mo与U同位素记录、以及2023–25年"氧与动物起源"之争），它产生了寒武纪第一个氧化风化剖面（第一批"现代"古土壤）、第一批大型锰台地矿床、以及古生代的氧化还原窗口成矿学（2022–24年"黑色页岩关键金属"浪潮：奥陶系与泥盆系页岩的V-Ni-Mo-Zn-U富集作为新近氧合深陆棚的汇相——2023年《Nature Reviews Earth & Environment》的评估说黑色页岩如今是一笔真正的多金属资源，因为地表矿已不经济）。对资源的实际后果是：**矿系统是时间结构化的**——你不能在一个太古宙盆地找卷前锋铀矿、也不能在一个泥盆系盆地找条带状铁建造，而每种金属的勘探目标清单是一张地球氧史的地图。
:::

::: example Witwatersrand：史上开采的最大金矿及其未解决的成因 {#example-witwatersrand}
Witwatersrand盆地2.9–2.8 Ga的Central Rand组砾岩（1886年在Main Reef的发现、2024年仍从3–4.5千米深的矿以超过每年200万盎司生产——2023–25年"6000"深钻项目的5千米岩石温度与地震工程）产出了约27亿盎司金——比任何其他矿区都多、而来自一种沉积岩。经典模型（一个河湖相三角洲系统、"矿礁"作为古代砂矿、标志性的黄铁矿"球"作为同生湖泊化学）受到2015年《Nature Geoscience》论文（Barnicoat与同事）的挑战，他们论证金、铀石与黄铁矿结核是热液的、而砾岩只是渗透性的宿主——这一主张被2016年McDonald与同事的回复与2019–2024年的矿物学研究（对矿礁黄铁矿沉积分带的2023–25年《Mineralium Deposita》与《Economic Geology》研究）大体重新平衡向一个混合模型：一个来自太古宙腹地的富Au与黄铁矿物质的沉积富集，后来在2.0 Ga的Ventersdorp与1.0 Ga的Kalahari事件期间被盆地流体再活化并再沉淀。开采的现在是资源一课"质量、不是数量"的主题：本矿区的矿石品位从1930年代约15 g/t降到约8 g/t（2023–25年深部水平的平均、以及2024年Sibanye-Stillwater与Harmony的储量声明）、这些矿是地球上最深的（4.5千米、60 °C的岩石、200人分钟的通风后勤、2022–24年的岩爆死亡、以及机械化对竖井矿礁之争）、而2020年代的"尾矿再处理"工业（对南非尾矿的2023–25年估计：Mine Waste Solutions与BCRS的再处理方案）——矿堆持有4,000–6,000万盎司金、以及一个萦绕本盆地的酸性矿山排水负债——字面上是对第一座矿之废物的第二次开采、也是关键矿产一课不断引用的循环经济案例研究。
::: solution
Witwatersrand是单一盆地里的沉积矿石一课：一个砂矿（水力学）、一个化学汇（黄铁矿）、一个热液叠覆（流体）、一个35亿年的保存奇迹（盆地的埋藏、以及*没有*摧毁它的Vredefort与Ventersdorp事件）、以及一个剩余价值取决于深度、劳动、电力与废物再开采的现代资源。未解决的成因之争不是书斋里的：砂矿模型预测金沿古河道（2020年代的"West Witbank深部"勘探）、热液模型预测它沿盆地尺度的断层——而本矿区接下来的1亿盎司取决于钻探跟随哪一个预测。
:::
:::

::: example 从Hamersley到Simandou：铁矿石的品质经济 {#example-iron-ore}
Hamersley矿区2.7–2.4 Ga的BIF（Marra Mamba与Brockman铁建造、Pilbara与Midwest各区——2023–25年的BHP、Rio Tinto与Fortescue作业：约9亿吨/年，占世界约26亿吨海运铁矿石）是BIF故事的变质、高品位一端：构造-赤铁矿的"尖峰"矿石（2020年代开采的"硬矿"与"河道铁矿"，60–67% Fe而氧化铝接近零）是钢铁工业的高级给料、而2021–2024年的价格史（2021年200美元/吨的飙升、2022–23年中国房地产低迷到80–100美元、2024–25年高品位矿石的"绿色溢价"，因为DRI-氢-钢的中试——2023–25年H2 Green Steel与HYBRIT的原料规格——要求≥65% Fe，而多数低品位Pilbara与中国的混合料无法满足）重新打开了2010年代大宗超级周期掩埋的品质问题。Simandou（几内亚——2010–2024年的Rio Tinto–Chalco–Simfer连续剧、2024年11月来自1/2区块（Winning Consortium）的首船、以及2025–26年的爬坡：55–67%天然赤铁矿的"世界最好的未开发铁矿区"（2024年声明：已开发区块约24亿吨、65%，以及预测Simandou增加海运供应10%的2025年分析））是氢-钢转型的品质之赌、而其670公里的铁路与港口建设（2019–2024年的Simandou基础设施联合体、几内亚走廊的"资源换基础设施"融资模式）是2020年代关于一座新巨矿在钢铁需求见顶的十年里究竟能否建成的案例研究（2024年"中国钢铁需求在2020年以21亿吨见顶"的共识，对照2024–25年印度尼西亚的建设潮）。低品位一端是故事的另一半：25–35%的"蓝尘"与taconite矿石（明尼苏达Mesabi的2020年代球团厂、2023–25年"精矿过剩"，因为中国的DRI建设超出球团化）需要湿磨、磁选与烧结——每吨Fe 5–10倍的处理能源——而2024–25年的"绿钢溢价"是第一个为这一差别定价的市场机制，这是资源一课品位下降曲线预测过的品质教训。
::: solution
铁矿教导"丰度"与"矿石"因氧化还原史与市场品质而分道扬镳：BIF事件交付了10¹³吨铁，但只有被构造升级的、风化的、富赤铁矿的窗口才能以65%而不需选矿地开采、而2020年代的钢铁转型恰恰为这一差别重新定价。Simandou同时是"史上最大的铁矿项目"与"对一个萎缩市场的赌注"的框架，是资源一课节奏对数量悖论的矿物形态：世界不需要更多的铁；它需要*高品位*的铁、在其氢-钢机队到来的时刻——一个吨位统计无法表达的时间与品质问题。
:::
:::

::: example Atacama的盐湖：锂、蒸发与水政治 {#example-salars}
Puna-Atacama盐湖带（智利、阿根廷与玻利维亚的"锂三角"）供应世界约30%的锂（2023–25年USGS与IEA的摘要：Salar de Atacama的SQM与Albemarle作业，0.35% Li的卤水——地球上开采的最高品位锂资源——以及2021–2022年把电池级碳酸锂从7美元/公斤带到80美元/公斤、随后2023–24年又崩回−80%的价格飙升），而其生产过程是工业形态的化学-沉积一课：全新世卤水，在超干旱Altiplano的封闭盆地里靠蒸发浓缩（锂的最终来源：10–40 Ma的火山岩（2023–25年把锂追溯到这些年轻火山岩的同位素工作）），被泵入100–3,000公顷的太阳池，18个月的蒸发（浓缩因子的算术：Li为25倍、在盐沉淀迫使分离之前为100倍）降下石盐、然后钾盐、然后运往沿海转化器的锂浓缩液。2023–25年的争议是可持续性案例研究：水文问题（关于Atacama卤水位下降的2021–2024年研究——生产区几十米、2023–24年关于卤水-地表相互作用与火烈鸟潟湖盐度变化的水文学论文）、"开采对资源比"之争（2024年CORFO的技术审计：盐湖的卤水资源是巨大的（Salar de Uyuni的900多万吨Li——世界最大的单一锂资源），但其*开采比*（Mg/Li比从Atacama的约6到许多盐湖的>1,000、蒸发损失、30–50%的回收率）使资源规模成为供应的一个糟糕指南）、2023年智利《国家锂战略》（2024年的SQM-Codelco合资与2024–25年的"锂社会主义"诉讼）、以及2024–25年的直接提锂（DLE）浪潮（2023–25年在阿根廷与内华达的中试到厂放大：DLE使回收率翻倍并终结池蒸发的说法——2025年的判决仍未定它是一场革命还是更贵的流程）。
::: solution
盐湖是本课化学-沉积系统在显微镜下：矿石由气候制造（蒸发在1千万年里每年超过补给100毫米）、以一个含水层补给无法匹敌的速率开采（"化石卤水"问题——Atacama卤水的2023–25年同位素定年：1,000–10,000年的停留时间，即开采是地下水*耗竭*、不是可再生抽水）、而其经济学由化学（Mg/Li比、硼与铍杂质）而非吨位设定。2021–24年的价格周期两次证明了这一点：2022年的飙升是一次*转化能力*短缺（矿与池都好；精炼厂不是）、而2023–24年的崩溃是对一个需求预测的供应回应——使"盐湖持有5,000万吨"（它们确实持有）对一座给定电池厂能否在2027年拿到其碳酸锂无关紧要的波动性。
:::
:::

::: example Athabasca盆地：世界最高品位的铀，两次造成 {#example-athabasca}
Athabasca盆地（Saskatchewan——1968年的"Ansell"矿点与1988年打开Cigar Lake与McArthur River矿区的"Palaeochannel"发现）容纳世界品位最高的铀矿（Cigar Lake：平均2.4% U₃O₈——约地壳丰度的10,000倍；McArthur River：史上建造的品位最高的铀矿，平均品位约10%），形成于两个叠加的事件：1.7 Ga的Athabasca组砂岩沉积在2.0–1.8 Ga的变质基底之上、以及矿石阶段本身（2023–25年的高精度年代学：约1.6–1.55 Ga的早期REE交代与约1.05–0.95 Ga的主成矿事件），当时氧化、富氯的卤水（2020年代的流体包裹体工作：盆地卤水、不是变质水）沿基底断层迁移、在石墨剪切带被还原、并把沥青铀矿与铀石降在几米宽的角砾岩里。开采史是资源一课的繁荣-崩溃-工程三部曲：2006–2007年由发现驱动的价格飙升（2007年140美元/磅的峰值为这些矿发了许可）、2008年Cigar Lake的透水（2008–2015年的冻结壁工程——史上尝试过的最大人工地层冻结工程——以及2024–25年向1,800万磅/年铭牌的产量爬坡）、2011年福岛与2018–2020年的价格低谷（2020年25美元/磅以下的底部使McArthur River与Elliot Lake闲置）、以及2021–2025年"铀回来了"的复产浪潮（2024年80美元/磅以上的长约价、2024年Cameco的复产批准、2025年的"铀供应缺口"分析与SMR需求文献），使本盆地再次成为西方的铀锚（2024年：Athabasca以两座矿供应世界约20%的铀）。
::: solution
Athabasca是氧化还原捕获一课最纯粹的形态：铀只在氧化、富氯或富碳酸盐的水里是活动的、并只在某个东西（石墨与烃）还原它时沉淀——所以矿石恰好坐在盆地卤水遇基底还原剂的不整合上、而勘探目标是一个*地球化学边界界面*、不是一种岩石类型。本矿区两次讲述的品位（地壳的10,000倍）与两次讲述的历史（1.6 Ga的交代、1.05 Ga的矿石）也携带保存的信息：盆地的盖层是矿石幸存的原因、而盖层也是为什么在500米砂岩之下钻了120年才找到它——磁岩一课在Kalgoorlie遇到的"覆盖层之下"勘探前沿，来到了铀里。
:::

::: warning 关于地表与沉积矿石的五个误解
1. **"沉积意味着浅而便宜。"** Witwatersrand的开采比地球上任何矿都深；HPAL红土厂是采矿业里最难的化学工程挑战之一；而Athabasca的品位没有冻结壁与覆盖层钻探技术就一文不值。地表制造了矿石；到它的深度与它的化学决定成本。
2. **"BIF记录铁丰盛的时期。"** 它们记录铁能*沉淀*的时期——2019–2024年的氧化还原穿梭综合显示太古宙海洋的铁储库、不是它的供给，设定了BIF脉动、而这些建造之终结是因为储库耗尽、不是因为铁变稀缺。对矿相的地球历史阅读是一个质量平衡的练习、不是一个有无的练习。
3. **"卤水锂是免费的因为它是溶解的。"** 溶解意味着*稀*：Atacama卤水是0.35% Li、而25–100倍的浓缩由需要18个月、消耗沙漠所没有的水、并在Mg/Li超过约6时彻底失败的太阳蒸发完成。硬岩与卤水两条路线是化学的权衡、不是一顿免费午餐。
4. **"砂矿是探矿者的手艺。"** 现代重矿物砂工业是一个挖泥船与螺旋的物流生意，供应钛链的大部分与三分之一的锆、而2020年代印度尼西亚与纳米比亚的案例显示其环境与治理成本是约束性限制——砂矿经济学关于*处理的便宜*与*开采的政治*，不是淘金盘。
5. **"磷与钾盐只是岩石。"** 它们是本行星的养分仓库，70%以上的储量在单一辖区（磷酸盐在摩洛哥-西撒哈拉；钾盐在加拿大、白俄罗斯与俄罗斯）、没有可替代的供应、而需求由人类食物固定（2022年的价格冲击：在制裁与粮食危机峰值时钾盐+200%、磷酸盐+300%）——战略矿产文献关于"关键性"是谁拥有矿床的函数、不是地壳丰度的函数最纯粹的案例。
:::

::: history 从铁矿区到氧曲线：沉积矿石科学的时间线 {#history-sedimentary-ores}
工业史始于伟大的沉积发现本身：1844年Marquette与1848年Mesabi铁矿区（Mesabi的露天坑转变、以及使明尼苏达成为世界铁矿区的1900年代整合）、1886年Witwatersrand的金发现（1890年代深部氰化与1900年代"Witwatersrand作为银行"的文献）、1886年Hall-Héroult工艺、以及使铝成为一个工业的牙买加、苏里南与圭亚那20世纪初的铝土矿工业、1941年Kalahari锰矿区的Postmasburg开工、以及1925年Hamersley的发现与建造了Pilbara的1960年代BHP与Hamersley Iron开发。科学以三波跟随矿山。十九至二十世纪初的地层时代把矿体当作建造来读（1896年Van Hise的Lake Superior铁建造专著、1910年代关于Mesabi的"沉积对交代"之争、以及1920年代Lindgren时代对沉积容矿矿石的分类）。世纪中叶的地球化学时代把地表变成一个反应器：1950–70年代Holland与Garrels的铁建造氧化还原沉淀模型、1966–72年Hardie与Eugster的蒸发岩化学实验、1970年代Elliot Lake与Athabasca学派的"不整合相关铀"模型、以及把BIF问题框定为一个大气史问题的1973–75年Garrels-Holland氧之争论文。同位素与古氧化还原时代（1990–2020年代）把框架变成测量：1996年"2.45 Ga的GOE"地层共识、2000–2011年硫同位素MIF革命（2000–2011年Farquhar、Johnston与Luo关于氧台阶的记录）、2004年Anbar与2009年Kendall关于海洋氧合的钼同位素记录、2010–2020年代的Fe形态与Cr同位素综合（2015年Planavsky、2017年Konhauser、以及2023–25年高精度GOE年代学）、以及2019–2024年"海洋铁储库"的BIF综合。应用的浪潮是当前的：2020年代"沉积系统中的关键金属"评估（2021–2025年《Nature Reviews Earth & Environment》与USGS关于黑色页岩V-Ni-Mo-Zn的工作、2023–25年"锂卤水可持续性"与DLE文献、2024年Simandou首船、以及粮食-化肥危机的2023–25年"磷与钾盐安全"报告），使沉积矿床地质学在一个世纪里第二次成为一门战略科学。
:::

## 检验你的理解

::: quiz
条带状铁建造在约1.8 Ga之后大体停止形成，主要因为：

- [ ] 铁在地壳里变得稀缺
- [x] 元古宙海洋的溶解铁储库随氧化还原穿梭的改变而被抽干——汇用尽了它的源
- [ ] 生命停止了沉淀铁
- [ ] 板块构造停止了输送热液铁

::: solution
**储库耗尽**：在2019–2024年的穿梭综合里，BIF是一个巨大缺氧含铁海洋储库的汇；一旦氧合的深度水与硫化物埋藏关闭了铁循环（硫化物深海），溶解铁的供给就崩溃、而BIF机器停止——一个质量平衡的终结、不是一个供给或生物的终结。
:::

### 练习题

::: exercise {level=1 check="30000"}
含300 mg/L Li的Atacama卤水被蒸发浓缩100倍。结果的锂浓度是多少mg/L？
::: solution
300 × 100 = **30000 mg/L**（3% Li）——把一种稀的天然卤水变成锂浓缩液的浓缩因子、以及为什么蒸发时间（与水权）、不是岩石吨位，是盐湖的生产约束。
:::
:::

::: exercise {level=1 check="0.4"}
一种平均25% Fe的BIF成因矿石被选成一个62% Fe的精矿而铁没有损失。多少分数的原矿吨位变成产品？
::: solution
25/62 ≈ **0.40**——60%开采的岩石变成尾矿、62%"标准"隐藏的选矿税、以及为什么65%的天然矿石（Hamersley、Simandou）享有低品位混合料无法靠加工摆脱的品质溢价。
:::
:::

::: exercise {level=1 check="0.2"}
一个海滩砂含2%钛铁矿而疏浚其中1,000万吨。生产多少钛铁矿精矿？
::: solution
10 × 0.02 = **0.2 Mt**——重矿物砂的算术：不破碎、不磨矿、只有密度——矿物工业里每吨精矿最低的能源、以及为什么钛原料是一个砂矿与海岸线的生意。
:::
:::

::: exercise {level=2 check="83.3"}
一种镍红土矿品位1.2% Ni。每吨镍金属处理多少吨矿石？
::: solution
1/0.012 ≈ 每吨Ni **83吨**矿石——可与一个斑岩铜的每金属岩石比，这就是为什么红土"便宜的采矿"之说在冶炼厂或酸厂死去：矿石以1%开采、并在*冶金上*像1%一样处理。
:::
:::

::: exercise {level=2 check="17.5"}
锂的地壳丰度约20 ppm。Atacama卤水含350 ppm Li。卤水相对平均地壳的浓缩因子是多少？
::: solution
350/20 = **17.5倍**——第一步浓缩由火山源岩与盆地完成；太阳池再加100倍；从地壳到电池级碳酸锂的完整链条跨越三个数量级，其大部分以能源、水与时间支付。
:::
:::

::: exercise {level=2 check="7500"}
Cigar Lake矿石平均2.4% U₃O₈（24,000 ppm）。平均地壳U₃O₈当量丰度约3.2 ppm。富集因子是多少？
::: solution
24,000/3.2 ≈ **7,500倍**——历史上任何一座铀矿最高的品位（一卡车Cigar Lake矿石携带一千卡车加拿大常规矿石的铀）、把盆地卤水的铀聚焦进米级基底角砾岩的回报。
:::
:::

::: exercise {level=3 check="20000"}
如果BIF沉积在一个2亿年的峰值区间里每年封存约1,000亿吨铁，那代表多少总铁（Gt）？
::: solution
100 Tg/yr = 10¹⁴ g/yr；× 2 × 10⁸ yr = 2 × 10²² g = **20,000 Gt**铁——BIF是一个海洋储库的排水管、不是一个局部矿床的通量尺度证明、以及使"储库耗尽"模型成为唯一能闭合质量平衡的模型的那个数字。
:::
:::

::: exercise {level=3 check="21000"}
Witwatersrand已生产约27亿盎司金 ≈ 84,000吨。按4 ppb的地壳丰度，必须平均多少十亿吨地壳才能得到那些金？
::: solution
84,000 t ÷ (4 × 10⁻⁹) = 2.1 × 10¹³ t = **21,000 Gt**——2.1 × 10¹³吨的平均地壳，砂矿机器淘洗的太古宙沉积系统的规模、以及为什么本矿区是一个应被测绘的*系统*、不是一个应被击中的矿床。
:::
:::

::: exercise {level=3 check="1.26"}
一条钾盐矿层（30% KCl）2米厚、1平方公里面积，以体重2.1 t/m³开采。它含多少Mt的KCl？
::: solution
10⁶ m² × 2 m × 2.1 t/m³ = 4.2 Mt矿石；× 0.30 = **1.26 Mt** KCl——蒸发岩的算术：Saskatchewan之下一条两米的矿层就是一个世界级钾盐矿区、而Prairie Evaporite的200米盐是加拿大持有约世界K₂O储量三分之一的原因。
:::
:::

::: quiz
卷前锋铀矿在太古宙岩石记录里缺席的原因是：

- [ ] 太古宙砂岩不存在
- [x] 卷前锋需要氧化、携铀的地下水，而这需要一个含氧的大气与氧化风化——两者都在GOE之后
- [ ] 铀在太古宙地壳里更稀
- [ ] 太古宙的河水流得太快，无法形成氧化还原前锋

::: solution
**它们需要一个含氧的地表**：卷前锋机器运行于O₂氧化的大气水从基底淋滤U并把它带到一个还原剂——一个2.45 Ga之后的过程，像次生铜与铝土矿。太古宙的矿石菜单（BIF、砂矿、黑色页岩）与显生宙的（卷、锰台地、次生富集罩）是用矿床类型写下的氧化还原史。
:::

::: summary
- 地表靠四台机器富集金属：流水（砂矿——密度加耐久性加水力学，从Witwatersrand到钛铁矿海滩）、深度风化（铝土矿、镍红土、次生富集罩——靠降雨的天然选矿）、化学沉淀（BIF、锰、蒸发岩——水柱作为反应器）、以及渗透性岩石里的氧化还原捕获（卷前锋铀、铜矿带Cu-Co、黑色页岩Mo-V-U）。
- 每台机器被地球的氧史接通或切断：BIF与砂矿是太古宙缺氧的产物；卷、次生矿石、铝土矿与大型锰建造需要GOE；最有价值的锰台地与现代养分循环跟随新元古代的台阶——矿系统勘探是应用深时氧化还原地层学。
- 案例研究共享一个结构：巨大的吨位、品质分级的、而如今由节奏与许可治理——4.5千米深并被再开采尾矿的Witwatersrand、Hamersley-Simandou的绿钢品质溢价、Atacama的化石卤水水政治、Athabasca冻结壁支护的10,000倍矿石。
- 2020年代为沉积矿石重新定价两次：作为转型的品质投入（高品位Fe、红土Ni、卤水Li、黑色页岩关键金属）、以及作为战略养分仓库（磷、钾盐），其辖区集中度使它们成为书里最纯粹的"因所有权而关键"的商品。
- 本课的方法是氧化还原质量平衡：在一个特定的海洋-大气状态里把一个矿系统读作一个源、一个通道、一个捕获与一个保存窗口——磁岩一课对熔体与流体问的同样四个问题，如今问空气、水与时间。
:::
