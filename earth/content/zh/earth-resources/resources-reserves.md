## "已知"与"可采"意味着什么：每一个资源头条之下的记账系统

你将读到的每一个资源故事——"只剩47年的油"、"足够转型用的锂"、"世界的X快用完了"——是一个关于账本、不是关于地球的句子。那本账本，资源与储量分类，是地球科学里被误读得最厉害的一份文件：它是刻意保守的（它只数按今天的价与技术*已证实*且*有利可图*的东西）、它每年修订（并在价格、政策或地质学家改变主意时跳升）、而它是一门学科——经济地质学——的产出，其核心洞见是地壳不是一个仓库而是一个干草堆：金属压倒性地以痕量存在，而重要的是地质过程做了采矿否则必须自己做的富集之少数几个地方。本课搭建记账词汇（分类框、品位与吨位算术、储备寿命统计及其批评者），然后读四个案例研究，它们合起来解释了公众对资源的大部分困惑：铜的品位下降、石油的政治储量冲击、稀土悖论、以及矿石的发现本身就是一种几十年前已见顶的资源这一事实。

::: definition 资源-储量分类：确定性乘盈利性 {#def-classification}
矿产禀赋沿两个独立轴排序：**地质确定性**（物质被圈定的程度——在管辖英联邦报告的JORC守则里，*勘探结果* → *推断* → *控制* → *测定*资源，由取样密度与对地质、品位与连续性的信心定义）与**经济可行性**（在修正因素——采矿、冶金、财务、市场、法律、以及日益增加的环境与社会标准——应用之后剩下的东西：*概略*与*证实储量*）。UNFC及其国家守则的"蜂窝"图在处处是同一个几何：地壳 → 未发现的推测与假想 → 已发现但不经济 → 已发现且经济 → *储量*，一个小而底层的切片，一家公司可以合法地称之为资产（SEC的S-K 1300规则，2021年生效，使美国上市规则与CRIRSCO国际模板对齐；在此之前美国公司报告SEC"储量"而世界其余部分报告JORC/PRIAM/PERC资源——一个几十年来扭曲矿业融资的可比性失败）。这个系统的三个属性解释了大多数头条错误：储量是一份**流量调整的存量声明**（它们是一个资源中经济可采的部分、*净*去矿山计划寿命期间将被采出的东西，所以一座矿的储量随其运转而*减少*，即使其资源保持不变）；它们是**价格与技术或有**的（2020年代的储量增长——数十年来世界金属储量基础有据可查的每年百分之几的平均增长——与新的地质同样是对老资源的重新分类）；而它们**不是发现的预测**（分类数已找到的东西；未发现的禀赋以USGS式的概率方法单独评估、并被刻意排除在公司账目之外）。石油版本（SPE-PRMS：证实/概略/可能3P，"证实"意味着在当前项目与价格下90%的采收确定性）带着同样的逻辑加上采收率一层——*原地*油与*可采*油之间的区分，常规储层通常20–45%，是品位的碳氢化合物类比。
:::

::: definition 品位、吨位、与切的经济 {#def-grade-tonnage}
一个矿体的算术是三个数字。**吨位**：质量 = 面积 × 真厚度 × 体重（一个500 × 300米的坑底到200米深度、2.5 t/m³，是75 Mt——一个世界级矿床的吨位是10⁸–10⁹吨，而矿体尺寸分布的*尺度不变性*——自1970年代记录在案的重尾、分形式的统计——意味着巨矿主导金属预算：少数几个智利斑岩持有的铜比地球上每一个手采矿床加起来还多）。**品位**：每吨的金属含量（wt%，贵金属用g/t）、以及真正重要的导出量，**含金属** = 吨位 × 品位——把地质学家的岩石体积变成经济学家的商品的那个数字。**切**：物料从矿石变为废石的*边界品位*，在处理收入等于成本处设定（矿石品位 × 金属价 × 回收率 ≥ 采矿 + 磨矿 + 管理 + 利润），所以**矿石不是一个地质类别而是一个价格依赖的经济类别**——铜价每吨200美元的移动能在一个新钻孔都没有的情况下使一个矿床的储量翻倍的理由、以及"开采矿石的平均品位"（全球0.45%，在下降）与"边界品位"（边际坑的0.3%）是关于同一金属的两个不同数字的理由。露天坑的伙伴是**剥采比**（废石对矿石），其经济上限设定坑界（最终露天境界在边际剥离的采矿成本等于边际矿石价值处——每一款露天设计软件作为Lerchs-Grossmann图运行的算法）、而其全球平均值（铜2–3、地下金约1、煤1–2）掩盖了一个事实：金属生产的*能源与水*强度大致与品位的倒数成比例——使脱碳金属变难的物理理由（不是枯竭理由）。同一词汇的沉积与碳氢版本：石油的*厚度 × 孔隙度 × 饱和度 × 采收率*、沉积铀与BIF铁石矿的*厚度 × 品位 × 面积范围*、以及同一个切逻辑——溶液开采的钙结铀矿0.01–0.1%的铀边界品位之所以存在，只是因为替代方案（0.1%的常规矿）被1980年代的铀价崩溃挤出价格。
:::

::: definition 储备寿命、R/P比、与Simon–Hubbert之争 {#def-reserve-life}
**R/P比**——储量除以年产量——是标准的"剩余年数"统计（按2023–24年USGS/BP数字，油约47–50、天然气约50、铜约40、锂约350），而它是本领域被误用最多的数字，理由有两个，它们是一场五十年之争的两个极点。**Hubbert的极点**（地质学家M. King Hubbert 1956年关于美国油将在1970年前后见顶的预测——早、对本土48州1970年是正确的——与其1974年USGS评估关于世界油将在本世纪之交见顶）把储量当作一个有限禀赋的抽样、把产量当作它的钟形曲线：峰值在资源烧掉一半时到来、而R/P统计毫无意义，因为它们忽视世界发现与承认新储量的*速率*。**Simon的极点**（经济学家Julian Simon 1980年对罗马俱乐部极限建模的《Science》反驳、及其著名的1980–90年代与Ehrlich关于资源价格将下降的赌约）把储量当作一个经济变量，其增长是价格、制度与技术的产出：到2024年的经验记录大多是Simon的——金属实际价格一个世纪以来趋势向下（世界银行/Bloomberg粉色表列，2000年代超级周期是最大的例外）、储量基础比耗竭增长更快（大多数金属的"储备寿命指数"在2024年*高于*1950年）、而没有任何不可再生资源曾经用完。**评估如今教授的综合**（2010–2020年代的资源经济学文献——2012年《Global Environmental Change》的"峰值资源"专刊、2018–2024年的《Resources Policy》与《Nature Sustainability》论文）是两个极点对不同的东西都是对的：绝对数量只通过*成本与能源*曲线起作用（地壳的铜在0.007%的平均丰度下从不"用完"，但把它从平均丰度重新富集回来要花费一个小国电力的当量）、R/P是一个糟糕的预测者而*速率*（发现、储量增加、品位、能源强度）是出色的预测者、而2020年代转型情景文献的约束性限制不是枯竭而是**节奏**（IEA 2021年《关键矿产》分析：2035年对锂、石墨与稀土的需求是2020年水平的4–6倍，而矿山开发管道的10–17年前置时间、不是地壳，是限制项）与**外部性**（低品位、低品质、冲突集中的供应之能源、水与治理成本）。诚实的总结句：资源实际上是无限的，*廉价*资源是历史或有，而储量账本是成本曲线的一张照片、不是一个油表。
:::

::: definition 供应风险：集中度、可替代性、再循环 {#def-supply-risk}
"关键矿产"框架（2010年欧盟《原材料倡议》、2017–20年美国国家科学院与能源部的定义、2023年欧盟《关键原材料法案》与2022年美国《通胀削减法》的配套规则）给每种商品在两个轴上打分——**供应风险**与**经济重要性**——而供应风险轴分解为可度量的项。**生产国集中度**，通常用Herfindahl–Hirschman指数（HHI，生产或储量国家份额平方之和：铜生产HHI约2,000–3,000——智利+秘鲁+刚果民主共和国约55%；稀土*精炼*HHI >5,000——2023–25年中国约占分离产能的90%；钴70%以上来自刚果民主共和国），加上政治风险的叠加（2021–25年的资源民族主义浪潮：印度尼西亚的镍矿出口禁令2022年在WTO被裁决、智利2023年关于锂的国家参与公告、津巴布韦2022年的锂矿出口禁令、以及纳米比亚2023–24年的增值税）。**可替代性风险**（替代风险指数文献——2015–2023年Saidani、Graedel与同事的工作：一种材料的功能被另一种服务的难易——稀土永磁与铂族催化剂得分很差、阴极里的钴正以工业速度被替代——LFP在电动车电池中的份额在2022–24年从约10%升到约40%的装机，是工业史上最快的材料替代）。**可再循环性与寿命终止集中度**（Graedel与CAPAM的"再循环率"记账：铅与钢90%以上、2023年稀土与锂约5%——"地上矿山"只在收集与冶金存在之处存在、而*在用存量*——已部署的6亿多吨铜、约一次年生产的25倍——是转型缓慢移动的第二本账）。以及**治理与财政条款**轴（Fraser研究所调查的投资吸引力排名；2023–25年把财政不稳定系于勘探投资的"资源诅咒"计量经济学）。这个框架的中心经验发现是*错配*：供应风险得分最差的商品（稀土、钴、石墨）是小的、不透明的市场，一次单一的政策冲击就重新为世界定价，而大的转型金属（铜、锂）在*节奏*上比在*数量*上更冒险——驱动如今重塑全世界勘探预算的2023–25年储备、许可改革与"友岸外包"政策的结论。
:::

::: example 铜：一个世纪的品位下降及其算术 {#example-copper-grade}
全球开采铜矿石的平均品位从1900年前后约1.5%（Cornwall、密歇根Keweenaw与蒙大拿Butte的脉与富矿床）经过1990年约0.65%降到2020年代约0.45%（USGS矿产品摘要与Mudd 2010年的澳大利亚品位序列），而最大的现代矿山运行在0.3–0.6%（Escondida的混合给料约0.5%，在下降；2023–25年Codelco的产量下降，因其露天坑降到0.35%以下）。驱动因素是分类系统按设计工作：1900年代的经济看不见一个0.4%的斑岩，而安第斯的斑岩带与中非的沉积容矿矿床——[[earth-resources/magmatic-hydrothermal]]与[[earth-resources/sedimentary-ores]]的低品位巨矿——只是在浮选、堆浸技术、卡车与电铲规模与需求使之成为"储量"之后才成为储量。后果是储量账本*不*记录的物理量：每吨铜的能源自1990年以来大约翻倍（Norgate与Haque 2012–2025年的更新：1%品位约100 MJ/t到0.4%约250 MJ/t，由磨矿主导——仅破碎就消耗全球电力的几个百分点）、水强度按同样方式缩放（2023年智利的干旱冲突：安第斯矿山0.4%硫化物的经济要求每矿约400 L/s的微咸水、Escondida的海水淡化建设）、而每吨金属的土地与尾矿足迹按品位的平方乘以深度的倒数缩放。2023–25年的预测文献（IEA与S&P Global的铜供应分析：即使在既定政策情景下一次生产也必须到2035年增长约40–70%，而2030年代的供应管道由尚未获许可的矿山主导）使品位下降曲线成为真正的"稀缺"信号：地壳为一百次转型持有足够的铜（USGS的未发现加已识别禀赋超过2024年累计储量一个数量级），但在0.3%的品位下，转型基础金属的能源、水与社会契约成本是储量统计掩盖的约束性限制。
::: solution
铜的案例是本课关于为什么"剩余年数"（2024年铜R/P约40）同时毫无意义、而正确阅读时令人警觉的算例。毫无意义：储量基础在每一个价格周期中增长，而已识别禀赋使它相形见绌。令人警觉：储量基础的*质量*——品位、能源强度、辖区、水——在一个任何价格信号都未逆转的趋势上恶化，而矿山管道算术（替换一个在产矿区要10–17年）意味着2023–25年情景预测的2035年缺口是一个2025年勘探预算的事实、不是一个2035年地质的地质。品位下降是以能量、不是以缺席表达的稀缺——Simon的论点无法定价消除的唯一一种用完形式。
:::
:::

::: example 1987–90年储量冲击：账本一年跳升50%之时 {#example-reserves-shock}
在《Oil & Gas Journal》1987年1月的世界储量表里，中东的证实储量上升了约50%——仅沙特阿拉伯就约70%（从1,630到2,510亿桶）、阿布扎比与伊拉克类似——没有宣布的巨发现、没有技术变化、没有新田：各国国家石油公司只是把数字让给了1980年代中期的OPEC产量配额谈判，其中每个成员的基线份额由其*报告的*储量计算（1990年Kemp与Simons的数据审计；2014–19年Barth与Simone关于Saudi Aramco档案的史学工作）。全球证实储量在一个报告年度里从约7,000跳到约1万亿桶、而1986年读作约29年的R/P统计在1987年读作约44年——"政治储量"存在性最干净的天然实验。第二幕是对让步本身的2019–2024年取证会计：2019年《Energy Policy》论文（Simone）论证Saudi Aramco报告的储量高估可采常规油约1,500亿桶（"多余"部分匹配历史产量加一个整数惯例的总和）、2021–24年对科威特与阿联酋储量增长异常的后续分析（2023年《Resources Policy》关于对几家国家公司恰好为零的"储量替代"比率的工作——从不下降因为从不被重新审计的储量）、以及使储量统计再次成为配额政治一个活工具的2023–25年OPEC+产能之争。这个教训通过分类系统的设计推广：证实储量是一个*关于项目与价格的声明*，而当声明由一个配额、上市、借款基础或债券契约取决于该数字的实体做出时，数字就漂移——这就是2010–2020年代"碳泡沫"与搁浅资产文献（Carbon Tracker与2011–2024年McGlone/Sullivan的分析）把*公司*储量当作上限、把不透明国家公司的*国家*储量当作一个应打折的先验的理由。
::: solution
储量冲击是一年版的分类教训：储量不是对地下的测量而是一个*声明*，只能对照生产史审计、而R/P统计继承塑造该声明的每一个激励。它教授的实用素养——把储量与累计产量和耗竭率比较、偏好储量替代比率与耗竭剖面而不是头条总数、以及对照价格与配额日历阅读每一个"新储量"公告——是品位下降与发现峰值案例要求的同一技能、以及专业资源评估（USGS、SPE-PRMS审计）作为一门独立于公司与国家报告的学科存在的理由。
:::
:::

::: example 稀土悖论：丰裕的元素，稀缺的矿床 {#example-rare-earth}
稀土并不稀：铈在本世纪壳最丰的25种元素之列（约66 ppm，与铜相当、约为银的1,000倍），而稀土总量超过铜或镍数倍（USGS与Wedepohl的丰度）。然而经济上有意义的稀土矿床是稀有的，理由是相容性与络合的地球化学（2011年Villanova与同事的全球矿床调查分析：稀土品位*正*空间自相关而很少超过边界浓度——这些元素被设计性地分散进多数岩浆，需要碳酸岩、过碱性花岗岩与离子吸附黏土里的极端分离结晶，而首先要求富集过程*不*被后来的稀释撤销）。2010–2023年的市场史是供应风险的教科书：中国的*采矿*份额从约97%（2010年，使价格翻三倍并发起非中国管道的出口限制危机）降到2024年占采矿的约60–70%，而中国的*分离与金属生产*份额保持在近90%——2023–25年关键矿产政策（欧盟CRMA的40%加工基准、2024–25年美国能源部的分离资助）如今瞄准的链中瓶颈，因为分离是600多道顺序溶剂萃取的酸性化学步骤，没有矿山能经济地跳过。（非中国管道：美国的Mountain Pass、澳大利亚的Mount Weld与非洲的作业。）中国南方的离子吸附型黏土——供应世界重（镝、铽）稀土、以铵盐原地浸矿开采、品位是任何硬岩矿山都不会碰的风化[[earth-resources/sedimentary-ores|沉积]]矿床——是悖论的另一半：地球上*经济可采*最富的稀土资源是亚热带风化花岗岩创造的一个风化壳、而其外部性（2010–2015年陇南与信丰的污染调查、2021–24年数十亿的修复估计）如今被计入2020年代正以5–10倍成本建造的"世界其余部分"供应链。
::: solution
稀土的案例教授*丰度*与*矿石*之别——本课的全部内容在一个元素组里：地壳富集是一个地球化学事实、矿石是一个地质巧合事实、而供应链是一个工业巧合事实（中国90%的分离份额是在环境成本的自由与国有工资之上于1980–2010年建造的、而其解绑是一个有10年学习曲线的2020年代产业政策项目）。框架词汇精确地映射它：储量（数百个稀土矿点中少数几个经济矿床）、供应风险（精炼HHI >5,000）、可替代性（2011–2015年的降镝与2022–25年的LFP/低钴替代——替代是真实的，但对磁体慢、对阴极快）、以及再循环（约5%的寿命终止回收率，使"城市矿山"成为一个2040年代的资产负债表项目、不是一个2030年代的供应来源）。
:::
:::

::: example 发现峰值：矿石作为一种可耗竭的勘探资源 {#example-discovery}
世界每年找到的大东西越来越少。巨田发现对于石油在1960–70年代见顶（USGS 2009年评估与Wood Mackenzie的数据：1965–75年发现约每年400亿桶、对照2010–2020年代约每年50–70亿桶，2020年代最大的发现——圭亚那的Stabroek开发、纳米比亚的Venus——延续一个*深水*而非*新盆地*勘探的趋势），而铜的类比是2020年代有据可查的"发现干旱"（2023–24年S&P与CRC能源/关键矿产分析：巨铜矿床的首次发现日期在1990年代见顶；新发现的平均尺寸自1990年代以来下降约40%，而每次发现的勘探支出增长数倍——2023年《Nature Reviews Earth & Environment》的资源地质综合得出的"矿产禀赋正比被找到的速度更快地被采走"结论）。机制是搜寻问题：勘探是一个针对重尾尺寸分布的顺序抽样过程，而每个造山世最大、最浅、地质上最明显的矿床最先被发现（"前沿周期"——2018–2024年Agate/Geoscience Australia与USGS的"未发现但有远景"地图：剩余的禀赋更深、在覆盖层下、在森林与保护区下、而在治理更差的辖区里——2020年代勘探文献的三个"深度、覆盖、契约"摩擦）。经济学随之而来：发现成本的上升快于品位的下降（2023–25年的面板研究：发现一个世界级铜矿床的实际成本自2000年以来大约翻了三倍）、矿山的管道损耗是残酷的（2021年TMC与2023年《Resources Policy》的清单：约每1,000个绿地远景区一个值得开发的发现、从发现到生产10–17年、而2020–24年的创纪录商品价格产生的新供应*少于*2010年代，因为管道已经空了），而储量账本愉快的增长掩盖它——因为储量增长是*已找到*物料的重新分类，而分类系统没有"我们找到东西的速率"这一格。
::: solution
发现峰值是Hubbert论点从生产到*信息*的迁移：见顶的不是禀赋而是容易的禀赋、而R/P账本对它失明，因为储量只数已找到的与有利可图的。政策与金融后果是2020年代的资源安全议程：国家地质调查局的复兴（2022–25年美国、澳大利亚、加拿大与欧盟的"测绘关键矿产"方案——国家为1,000个远景区里头900个去风险）、为转型重新论证的战略储备、以及一个令人不安的算术：IEA情景要求的2035年供应必须来自在2025年要么未发现、要么未圈定、要么未获许可的矿床——管道、不是地壳，是约束性限制，这是"用完"与"来不及"的全部区别。
:::

::: warning 资源数字被误读的五种方式
1. **把储量当油表。**"剩余年数"的算术（储量除以产量）假设没有新发现、没有重新分类、没有技术、需求恒定——它是一个关于今天*让渡*的声明、而其唯一合法的用途是跨商品比较*速率*或追踪一家公司的储量替代。每一个"X在Y年后用完"的头条都是这个错误。
2. **把资源吨位当金属。**"X国持有100亿吨含锂岩石"是地质学；"X国持有800万吨锂金属、平均品位0.6%、60%可采出"是算术；"X国持有300万吨储量"是经济学。三个数字相差一个数量级而常被互换引用——转型矿产评论里最常见的单一错误。
3. **政治与公司的储量漂移。** 1987年的中东让数、几家国家石油公司为零的储量替代比率、以及SEC上市在周期峰值把概略转为证实的激励，是有据可查的事实：储量是其审计者即声明者的声明、而专业的回应是耗竭剖面取证、不是否认。
4. **品位盲的稀缺话。**"地壳有600亿吨铜"与"世界有9亿吨储量"都是真的而都不是约束；约束是*富集分散元素的能源与制度成本*，它随品位下降而上升——21世纪的稀缺是一条成本曲线、不是数量，而品位是它的斜率。
5. **再循环与替代的免费通行证。**"我们将靠再循环达到自足"忽视了再循环对集中的、被收集的、冶金可及的存量在热力学上最容易（铅与钢成功；约5%的稀土不成功，因为物料分散在百万个小磁体里）、而替代在功能可替换处起作用（阴极）、在物理特定处失败（Nd-Fe-B磁体、Pt催化剂、电子里的Ga与In）——2023–25年的再循环潜力评估把转型金属供应的次生份额放在2050年的10–30%，不是乐观倡导的50%以上。
:::

::: history 从Agricola的矿体到关键矿产清单：把岩石与资产分开的四个世纪 {#history-reserves}
概念史始于文艺复兴的采矿文献——Agricola 1556年的《De Re Metallica》描述脉、铁帽与"矿石的标志"、以及1500–1600年萨克森的Ausbeute法令，它们把主权者的矿产主张（王权主义学说）变成地下的第一个法律框架——并延续通过十九世纪*矿床学*概念的诞生（Freiberg学派的A. G. Werner与后来使"类型"成为一个预测工具的矿床成因分类）、以及第一批国家资源调查（1830–70年代英国、加拿大、印度与美国的地质调查局，其年度报告至今仍是未发现禀赋的第一文献）。二十世纪建造了账本：美国矿业局1910–50年代的储量定义、1957年成为全球模板的测定/控制/推断三层分类、1960–70年代概率评估的兴起（USGS 1970年代"已识别与未发现资源评估"学说与Hubbert学派的供应预测）、以及1980–2000年代的守则趋同（JORC守则1989年、SAMREC 1999年、2012–13年CRIRSCO模板家族、SEC 2018年的S-K 1300现代化），最终使多伦多、悉尼、约翰内斯堡与伦敦的矿产报告逐行可比。争论史是公众仍生活在其中的那个：1972年罗马俱乐部的《增长的极限》系统模型、1975–80年的Hubbert–Laherrène"能源矿物"预测、Simon 1980年的《Science》反论与1981–90年的Simon–Ehrlich赌约（Simon在每一篮子上获胜）、1987–90年的储量冲击、以及1990年代预示2005–08年常规油平台的La Mette–Hubbert"全球石油供应与需求"数据修订、以及2000年代超级周期（2003–11年的价格飙升通过重新分类使铜与锂的储量基础翻倍、2007–08年的"万物峰值"浪潮——2009年USGS铜储量从3.4亿跳到5.2亿吨——以及2011年后的崩溃回到2014–19年的低谷，使本课发现案例描述的发现管道挨饿）。关键矿产的转向是当前一章：2010年中国稀土出口危机（WTO案件、价格飙升、欧盟2011年与美国2018–19年的关键清单）、2016–21年认识到*清洁*能源系统以化石系统所不具的方式是金属密集的（2017–21年IEA与世界银行的分析：一辆电动车的矿物需求是一辆内燃机车的6倍、一座风厂每MW是燃气厂的9倍）、以及2020–25年的政策浪潮——欧盟CRMA的2030基准、美国IRA的国内加工信用、2023–25年的矿产安全伙伴关系、以及国家调查局回归测绘——使储量账本自1970年代以来第一次成为一个治国工具、不是一个记账工具。
:::

## 检验你的理解

::: quiz
一家矿业公司的"证实储量"最好理解为：

- [ ] 公司拥有的矿化岩石总吨位
- [x] 一个资源中经济可采、紧密圈定的部分，净去计划产量，按当前价格与技术
- [ ] 矿山在其寿命期间将生产的金属量
- [ ] 许可区内该金属的地壳丰度

::: solution
**经济可采、圈定的那片切片**——储量是地质信心（测定/控制）与经济可行性（应用修正因素）的交集、*净*去计划耗竭报告、并有赖于价格与技术假设。那个或有性就是为什么储量总数随价格日历移动（1987年储量冲击、每一条储量增长曲线）、以及为什么资源、禀赋与地壳丰度是完全不同的账本。

### 练习题

::: exercise {level=1 check="75"}
一个露天坑在坑底量得500米乘300米、平均矿石深度200米；岩石密度2.5 t/m³。矿石吨位是多少百万吨（Mt）？
::: solution
500 × 300 × 200 m = 3 × 10⁷ m³，× 2.5 t/m³ = 7.5 × 10⁷ t = **75 Mt**——支撑每一份资源声明的吨位乘密度乘厚度的算术、以及为什么"十亿吨级"矿床以立方公里的岩石计。
:::
:::

::: exercise {level=1 check="0.6"}
上面75 Mt的矿床平均0.8%铜。多少百万吨含铜金属？
::: solution
75 × 0.008 = **0.6 Mt**含铜金属——把岩石变成商品的品位乘吨位一步、而一家公司实际报告的数字（含金属）不是地质学家的吨位。
:::
:::

::: exercise {level=1 check="4"}
一个坑在其寿命期间移除4亿吨废石与1亿吨矿石。平均剥采比是多少？
::: solution
400/100 = **4**（4:1）——每吨矿石移四吨废石，大宗硫化物坑的典型；该比率的经济上限（边际剥离成本 = 边际矿石价值）正是物理上画出最终坑界的东西。
:::
:::

::: exercise {level=2 check="0.33"}
一个铜业处理矿石的全成本是每吨矿石30美元；铜售9,000美元/吨，为简化取100%回收率。低于多少的边界品位（wt%）矿石就是废石？
::: solution
在收入 = 成本处切：品位 × $9,000 = $30 → 品位 = 0.0033 = **0.33%**。整课的经济铰链：在铜12,000美元/吨时同一作业的边界品位降到0.25%而其储量无需新钻就增长——价格正是通过这个算术把资源转为储量。
:::
:::

::: exercise {level=2 check="47.3"}
世界证实石油储量约17,300亿桶、年产量约366亿桶。R/P比是多少年？
::: solution
1,730/366 ≈ **47.3年**——1986年是29、在中东让数后的1987年是44的那个数字、四十年来一直在40–50附近徘徊、而其稳定性（不是其水平）才是真正的信息：储量以耗竭的速率增长，因为账本是一份价格调整的声明、不是一个油表。
:::
:::

::: exercise {level=2 check="4200"}
四个国家生产一种矿物的60%、20%、10%与10%。生产集中度的Herfindahl–Hirschman指数是多少？
::: solution
60² + 20² + 10² + 10² = 3,600 + 400 + 100 + 100 = **4,200**——在HHI标度（0–10,000）上是一个高度集中的市场，可与稀土精炼的>5,000相比、并远高于铜采矿的约2,500；把"谁在采"变成一个可打分供应风险变量的数字。
:::
:::

::: exercise {level=3 check="222"}
按今天0.45% Cu的平均开采品位，每吨铜金属必须处理多少吨岩石？
::: solution
1/0.0045 ≈ 每吨铜**222吨**岩石（1900年1.5%时约67吨）——储量账本不记录的每单位金属物理吞吐量的三倍、以及为什么铜的能源、水与尾矿强度大约翻倍而其"剩余年数"保持平坦。
:::
:::

::: exercise {level=3 check="28"}
如果矿物需求以2.5%/年增长，大约多少年翻倍（70法则）？
::: solution
70/2.5 = **28年**——每一个转型供应分析背后的复利事实：2.5%的需求趋势意味着未来28年的*平均*年增加等于今天的全部产量，所以管道必须在一代人之内大致使世界的采矿能力翻倍、同时品位还在下降——在现代稀缺文献里取代"用完"的节奏约束。
:::
:::

::: exercise {level=3 check="35"}
一个矿区的平均矿石品位在趋势上以2%/年下降。大约多少年后每吨金属处理的吨位翻倍（70法则）？
::: solution
70/2 = **35年**——按当前趋势，仅品位下降就使每吨金属的能源与水足迹以约2%/年上升、还没计入任何新矿更差的品质；储量增长统计隐藏的指数、以及2023–25年"供应质量"文献的物理基础。
:::

::: quiz
Simon–Hubbert之争最强的经验教训是：

- [ ] 价格证明资源是无限的
- [x] 储量总数随价格与技术增长，但*发现速率*与供应的*质量*（品位、能源、辖区）朝另一方向趋势——两个事实都重要而账本只记录第一个
- [ ] 发现率没有历史
- [ ] 技术从未改变过一个边界品位

::: solution
**两个极点对不同的变量都是对的**：经济极点解释储量增长与实际价格下降；地质极点解释发现峰值与品位下降。储量账本对速率与质量失明，这就是为什么现代资源安全（节奏、管道、外部性）——不是"剩余年数"——是2020年代的纪律、以及为什么本课程不断回到*在那里*的东西、*被找到*的东西与*有利可图*的东西之区别。
:::

::: summary
- 资源-储量系统用两个轴——地质信心与经济可行性——给地壳排序、而其底层切片（储量）是一个价格与技术或有的*声明*、不是测量：它随矿山运转而减少、随价格与政治跳升（1987年储量冲击）、而对未发现或不经济的禀赋什么也不说。
- 算术是吨位 × 品位 = 含金属，而边界品位——处理收入遇成本处——是在价格上涨时把岩石转为矿石的铰链；品位下降（铜在一个世纪里1.5% → 0.45%）是储量账本隐藏的稀缺，因为每吨金属的能源、水与土地与品位的倒数成比例。
- "剩余年数"（R/P）是一个范畴错误：储量以耗竭的速率增长、实际价格一个世纪以来趋势向下（Simon的极点）、而没有任何资源曾经用完——然而发现速率在几十年前见顶、而矿石品质在趋势上下降（Hubbert的极点，迁移到信息与成本），所以约束性限制是节奏与外部性、不是缺席。
- 供应风险是可度量的——集中度（HHI）、可替代性、再循环率、治理——而稀土案例展示了三层巧合：丰裕的元素、稀有的矿床、以及甚至更稀有的分离产能链中环节，这就是为什么2020年代的政策浪潮瞄准加工、找矿与储备、不是"世界有足够的X"。
- 账本是一个搜寻与生产系统的地图：勘探先找到容易的禀赋、价格把已找到的禀赋重新分类、而需求以2–3%/年复利——21世纪的资源问题不是地壳是否供应，而是发现、许可、资本与冶金能否跟上成本曲线的攀升，这是本课程随后每一课的主题。
:::
