关键性不是一个元素的属性、也不是一个市场的属性——它是两者之间*耦合*的属性。当某样社会不能轻易缺少的东西（经济重要性）穿过一条社会不能轻易改道的供应链（供应风险）时，一种材料就变得关键，而两个轴相乘：一个稀缺而有许多替代品的材料是一个价格问题，一个常见而只有一个供应者的材料是一个脆弱性问题，而两者的组合——一个在地壳里中等丰富、却集中在一个国家的精炼厂与一个国家的工厂里的材料——是现代问题。这就是为什么"关键矿产"同时是一堂地质课与一堂政治课：地质把锂放进盐湖与伟晶岩、把钴放进铜脉与红土、把稀土放进碳酸岩与离子吸附黏土；过去三十年的产业战略把*加工*放在了一个地方；而过去十五年的出口管制把这张地图变成了一件武器。本课定义关键性及其度量、逐条链走过集中度数据、读出能源转型的需求堆栈、纵览政策工具箱（清单、储备、基准、联盟、以及新的出口管制军备竞赛），而以共同定义了这个领域的四个案例收尾：2010年稀土冲击及其十五年后遗症、钴的替代周期、石墨与负极瓶颈、以及教会所有人价格冲击也是政策的2021–2025年价格过山车。

## "关键"意味着什么：两个轴，许多清单

::: definition 关键性：两个轴的定义 {#def-criticality}
一种材料是**关键的**，当（i）其**经济重要性**高——它是不能轻易替代它的部门（国防、电力、交通、计算）的一个必需投入——而（ii）其**供应风险**高——一次供应中断的概率与后果（生产或加工地理集中、政治不稳定、出口限制、贸易壁垒、资源稀缺）是重大的。这个定义由2008年美国国家研究委员会报告《矿产、关键矿产与美国经济》与2010年欧洲原材料倡议标准化，刻意把关键性与*稀缺性*分开：地壳丰度只是供应风险的一个输入、而常常不是最大的。其结果是关键性清单可以在地质零改变的情况下重画——2010年中国稀土出口暂停一夜之间把铈从"丰富"移到"战略"，而2023–2025年的管制潮对镓、锗、锑与石墨做了同样的事——而一条链上最关键的*环节*通常不是矿山而是工厂：2023–25年的评估（IEA《关键矿产概览》、USGS矿产品概要）发现，即使在开采是全球的场合，多数转型金属在中国的精炼与加工份额为60–90%。
:::

::: definition 度量关键性：HHI、进口依赖、与后果 {#def-criticality-metrics}
这些度量不起眼而决定要紧。**Herfindahl–Hirschman指数（HHI）**把生产者（或出口国）的百分比份额平方后求和：一个垄断是10,000，2,500是"高度集中"的反托拉斯阈值，而2023年IEA供应链评估给稀土*分离*打近9,000、钴*开采*5,000以上、而铁矿石开采近1,500。**进口依赖**（净进口占表观消费的份额）是暴露度量：2024年的美国评估发现美国对50种评估商品中的49种净进口依赖、而对镓、石墨与锰完全进口依赖（100%）。**国家决定的关键性**清单随后用判断给两个轴加权：2023年欧洲CRMA清单列41种"关键原材料"（27种"战略"）、2022年美国清单50种商品、日本与韩国的清单按产业结构排序——而这些清单在约十五种材料上重叠（稀土、钴、锂、石墨、镓、稀土邻近的钪），而分歧由谁买、谁加工、谁储备驱动。这些度量共同的弱点是它们度量*今日*的贸易流、不是明日的弹性：替代、回岸与回收在一个由2024年运量算出的HHI里都是不可见的，而这正是2010年稀土事件（下文）既验证又令指数尴尬的理由。
:::

::: history 从一次禁运到清单的军备竞赛 {#hist-critical-lists}
"战略矿产"一词可追溯到1970年代——1973–74年石油禁运与扎伊尔/安哥拉铜钴恐慌产生了1975年国际能源署（只管石油，令矿产政策制定者长期遗憾）的成立与1948年后美国国防储备的辩论——而现代时代始于**2010年9月15日**，中国在一次钓鱼岛附近渔船碰撞后暂停了对日本的稀土运输。镨钕氧化物在一年内从约$4/kg涨到约$130/kg，西方媒体发现每一架F-35、每一辆Prius与每一台风电机组都含稀土磁体，而政策的忙乱开始了：2010年欧盟关键原材料报告、2011年欧盟清单与原材料倡议、2012–2014年的WTO诉讼（美国、欧盟、日本诉中国）到2015年废掉了出口配额、日本2010年的JOGMEC风险局与储备计划、以及2017–2018年的美国行政令与USGS50种商品清单。然后，在价格低迷中十年缓和之后，管制作为产业政策回来了：中国**2023年7月**对镓与锗的出口许可、**2023年12月**对石墨、**2024年9月**对美国的全面锑禁运、**2025年4月**对七种中重稀土的许可、以及**2025年10月9日**的措施——对所有输美稀土出口、对开采、精炼与磁体*技术本身*的许可、以及一条域外的"0.1%含量"规则，触及任何含中国稀土的外国制造磁体。**2025年10月30日的釜山会谈与11月的休战**把10月的规则暂停一年——让地球上每个首都得出结论：暂停、而不是规则，才是临时的东西。反制现在已是信条：2022年美国《通胀削减法》的来源条件、2023年欧盟《关键原材料法》、矿产安全伙伴关系（2022年，十四成员加欧盟）、2025年美国第232条对加工关键矿产的调查、以及2025年10月的"Project Vault"——一个120亿美元的联邦加私人关键矿产储备，是1948年以来最大的储备倡议。
:::

## 集中度地图：矿山、精炼厂、工厂

::: definition 三段瓶颈：开采、加工、制造 {#def-chokepoints}
每条关键矿产链都有三个带*不同*地图的环节，而关键性住在最窄的那个里。**开采**是最全球化的环节——锂来自澳大利亚、智利、中国与十几个非洲国家；钴来自刚果民主共和国（2023年世界矿山供应的73%）、但也在印度尼西亚与菲律宾；稀土来自中国（2024年矿山产量的约70%，配额27万吨氧化物）、美国、缅甸与澳大利亚。**加工**是地图塌缩之处：2023–24年IEA评估把中国放在锂精炼的约65%（从2018年的36%上升）、钴精炼的约44%、稀土分离的约90%、锗的约68%与多数镓精炼（中国制造90%以上的原生镓，是其氧化铝帝国的副产物）、以及世界约一半的锑冶炼。**制造**更集中：中国制造世界约90%的烧结稀土磁体、约80–90%的电池级石墨产品、以及多数的电芯与正极——所以内华达州的一座矿山可以通过马来西亚的一座精炼厂进入浙江的一家磁体厂、并在原产地规则下恰好算作那座矿山被钻探要打破的那个依赖。这里的战略概念是**瓶颈**：HHI最高、而新产能建设周期最长的那个环节——对稀土是分离与磁体烧结（5–7年的建设与认证周期），对石墨是球化与提纯（寥寥几座工厂，全在中国），对钴是刚果（金）的物流走廊而不是它的矿坑。2021–2025年的西方回应——Mountain Pass分离、Lynas得州、安大略与巴伐利亚的负极厂——是1940年代以来第一次有意识地改道一张金属加工地图，而其成本是下文警告的主题。
:::

::: example 2010年稀土冲击及其十五年后遗症 {#ex-rare-earths-2010}
本课一切的对照案例。2010年之前中国以二十年下跌的价格供应世界约95%的稀土氧化物；2011–2014年的配额制度，与走私的揭露（2011–2015年的美国调查发现中国材料经第三国进入以规避配额）产生了3–30倍的价格飙升、一次WTO胜诉（2014年裁决，2015年废除配额）、以及——有教益的部分——几乎没有持久的去风险。价格飙升资助了三件事：Mountain Pass的重启（Molycorp 2012–2015年的事业在价格跌回中国国内水平时破产——经典的"价格伞"故事：一个低成本在位者只需匹配价格就能使高成本进入者破产）、日本与欧洲十年的*需求*工程（JOGMEC支持的Lynas Mount Weld股权；把镝减半的磁体重新配方；从硬盘与马达回收；2011–2020年西方每单位磁体的稀土*消耗*降低约三分之一）、以及一条幸存的矿山加精炼厂链：Lynas的Kuantan厂，在马来西亚威胁其执照时由一条不寻常的2020年澳大利亚法定契约保护。到2023年账目是：中国的*开采*份额从95%降到约70%，其*分离*份额在约90%未变，磁体制造约90%。2021–2025年这一轮扭转了行进方向：Lynas 2022年为得州重稀土设施与美国国防部的合同、MP Materials 2023–2024年Mountain Pass分离的开始、2025年7月美国国防部与MP Materials的合同、对分离的钕镨设每公斤110美元的价格下限（1960年代以来美国对稀土的第一笔生产补贴、以及美国国防部的一笔股权）、以及——数日之内，2025年10月——中国恰好针对在中国之外复制这条链的技术出口管制。十五年，而教训成立：价格飙升治好矿山，治不好精炼厂，因为精炼厂在在位者所在之处建造便宜、而在在位者能够跟随你的任何地方建造都是毁灭性的。
:::

## 需求堆栈：转型向地壳索取什么

::: definition 清洁能源技术的矿产强度 {#def-mineral-intensity}
关键性的需求侧是一个带政策面孔的材料科学事实：低碳技术每单位输送能量*更*耗材料，超过它们取代的化石系统，因为风与太阳散布了煤与气集中的能量。2021年IEA《关键矿产在清洁能源转型中的作用》量化了它：一辆电动车大约需要一辆燃油车**6倍**的矿产投入，一个陆上风电场每兆瓦当量约是燃气电厂的9倍矿产，海上风电与"公用事业规模"储能更高，光伏约2.5倍——而这个强度*集中*在一个短元素清单里：锂、钴、镍、石墨、稀土里的钕、镨、镝与铽、铜、加上硅、锰与铂族金属在更小的吨位上。到2040年在既定政策情景下的需求乘数：锂约40倍、钴约20–30倍、石墨与稀土约7–9倍、镍约20倍——这些吨位若按预测交付，使能源转型成为史上最大的金属建设，可比第二次电气化。2021年报告权重不足、而2023–2025年《关键矿产市场评论》补上的两个告诫：需求*在化学上有弹性*（LFP与钠离子的替代比任何矿山计划假设的都快得多地削减钴与镍的强度——见下文钴的例子），而需求*在价格上有弹性*、在最糟的时机（一次在建设期中到来的价格飙升摧毁边际买家——2022年锂飙升到2024年摧毁了三分之一预测的锂辉石需求响应，而随后的崩盘使飙升所许可的矿山破产，[[earth-resources/resources-reserves]]的发现滞后周期以十一年而不是其通常的三十年的节拍运行）。
:::

::: example 钴：价格周期、替代、与刚果（金）的配额牌 {#ex-cobalt-cycle}
钴是"关键"需求能多快蒸发这个主题的案例研究。2016–2018年的电动车恐慌（富钴NMC化学、2018年2月一次2倍的价格飙升到约$95,000/t）恰好触发了关键性理论预言的、而事后看被低估的响应：电池制造商重新配方。NMC正极的钴在产品各代之间从每吨正极当量20 kg降到5 kg以下，LFP——无镍、无钴、无氢氧化锂要求——从2018年占EV电池市场约5%到2024年超过40%（而中国装机的约一半），而钠离子电芯（CATL的Naxtra系列，2023年；2024–2025年中国的两轮车与储能市场）打开了一个无钴、锂可选的侧翼。同时供给在没人给它定价的地方爆发：印度尼西亚的镍HPAL厂把硫酸钴作为电池级镍的副产物生产，而到2023年印度尼西亚是世界第二大钴生产国。结果是：钴在2025年初达到有记录以来最低的实际价格（约$22,000/t），刚果（金）的出口收入减半，而金沙萨打了自己的牌——2025年2月的出口暂停，由一个配额制度取代（宣布的2026年上限近97,000 t、对照2024年产量的220,000 t），在数月内使价格翻倍。每个参与者的教训：买家学会了化学替代比矿山建设更快；卖家学会了副产物矿山完全不响应价格（只要镍的经济性成立，印度尼西亚的钴就继续出来），这正是使*配额*成为唯一剩下杠杆的东西；而分析师学会了钴2030年"短缺"的2018年预测与2025年"结构性过剩"的2024年预测都自信而都错了，因为两者都把化学保持不变。残留是一个真实的战略暴露——刚果（金）仍几乎不精炼自己的钴（中国做约44%、而把其余加工成中国的前驱体与正极），而钴仍在每一份关键性清单上——但作为一个*替代风险*属于买家所画任何清单的供应风险轴上的教训。
:::

::: quiz
Herfindahl–Hirschman指数在关键性评估中被使用、而不是一个简单的"前三份额"，因为：
- [ ] 它数生产国的数目，惩罚小生产者
- [x] 它用份额的平方加权，所以它抓住一个主导生产者的*杠杆*、不只是供应者的数目
- [ ] 它调整运输成本，使各链跨大洋可比
- [ ] 它直接度量价格波动，而简单份额做不到
::: solution
HHI把份额*平方*后求和：一个有90%单一生产者的链得约8,100以上，而一个有四个25%生产者的链得2,500，即使两者都有一个天真的计数可能同样看待的"前三份额"。平方是编码支配的东西——使中断可信的那个杠杆——这就是为什么稀土分离链（最大生产者约90%）读作关键、而前三之和相似而分布更平的链不读作关键。
:::

## 政策工具箱：储备、基准、联盟、管制

::: definition 关键矿产政策的四代 {#def-policy-toolkit}
针对供应风险的政策以雄心与成本递增的四代到来。**第一：储备。** 1939年美国《储备法》与其1948–1955年杜鲁门时期的建设创建了国防储备（只限国防，1950年代峰值75种商品，在1990年代售出）；日本的JOGMEC金属储备（2010年）、2023–2025年欧盟储备计划、以及2025年美国Project Vault（120亿美元，对汽车与电池供应链的60天应急响应，刻意*由行业管理*而不是政府仓储）是现代形态——比矿山便宜，对十年长的封锁无用。**第二：情报与清单**——USGS矿产品概要（1918年的谱系）、2011年起的欧盟清单、2018年美国清单——它们不直接改变任何东西，而给保险人、贷款人与采购重新给风险定价。**第三：产能政策**——2020年代的前沿：欧盟CRMA的2030年基准（至少10%的欧盟年消费量在欧盟境内开采、40%加工、25%回收、而任何单一第三国在任何环节不超过任何战略原材料的65%）、及其2025年十三项"战略项目"清单；美国国防部第三章与《国防生产法》工具（2020–2025年稀土与磁体授标、2025年MP Materials的价格下限与股权）；2022年《通胀削减法》的来源条件与2024–2025年"受关注外国实体"规则，它们拒绝给触及列名公司的电芯抵免——工具箱里最锋利的工具，因为它让补贴条件性做到关税做不到的事。**第四：联盟与反制政策**——矿产安全伙伴关系的项目外交（2022年）、G7与欧盟-日本-印度走廊、对等市场准入协议、以及新的负面工具，*出口管制*，现在双方都在使用（中国2023–2025年的许可与禁运链；2025年美国第232条对铜与加工矿产的关税）。工具箱的历史是在储备（为中断投保）与重塑（防止中断）之间的一个钟摆，而2020年代的判决是保险太便宜而不能跳过、重塑太慢而不能依靠：CRMA自己的2025年评估承认2030年加工基准将被错过。
:::

::: example 石墨与负极瓶颈 {#ex-graphite}
石墨是电池链里最被忽视、而瓶颈最紧的一环，而其2023–2025年的故事是一堂环节特定关键性的大师课。事实：中国开采世界约35万吨鳞片石墨的约65%，而更重要的是，它几乎拥有全部*增值*环节——提纯（化学、耗能耗水、紧邻矿山布在山东与黑龙江）、以及**球化**，把鳞片磨成电芯真正使用的球形负极粉末，中国份额约90%。负极是西方电池建设悄悄建立在中国沙子上的地方：到2022年美国约70%的负极材料从中国进口，而整个非中国电芯工业按中国条件购买球化石墨。北京2023年12月对负极级石墨的出口许可要求（名义上"两用"用于国防，在美国第301条决定把负极石墨关税到2026年提高到25%之后一个月到来）产生了两年的忙乱：2024年的许可排队、日本与韩国负极制造商把鳞片来源多样化到莫桑比克、马达加斯加与巴西、美国国防部与加拿大和欧盟的补贴项目资助魁北克、安大略与巴伐利亚的球化厂（第一批有意义的规模的非中国球形负极产能，2025–2026年）、而中国的合成（石油焦衍生）负极制造商在国内原料成本下跌时干脆*提价*——副产物陷阱又来了，因为合成石墨骑在与人造黄油与氧化铝相邻的焦炭市场上。2025年10月9日的管制把石墨加进输美许可网，而11月的休战解除一年。结构性的教训在[[earth-resources/sedimentary-ores]]的框架里：石墨不稀缺——鳞片石墨是一种普通的变质与合成品，而USGS纯按进口依赖把它列为"关键"——而瓶颈是一个*形状*，字面意义上的：一个碳球的几何、以及四十年廉价制造它的工艺诀窍。关键性，说到底，通常是一座工厂，不是一块岩石。
:::

::: warning 关于关键矿产的五个误解
1. **"关键意味着稀缺。"** 恰恰相反：镓比铜更丰富，石墨是普通的碳，而稀土并不稀——铈大约与铜一样丰富。使它们关键的是*集中的加工*（镓骑在中国的氧化铝精炼厂上）、*副产物刚性*（锗从锌与煤灰里出来；不采更多的别的东西就不能"多采"）、或*制造几何*（磁体、球化负极）。地壳丰度是这一页上最没用的数字。
2. **"清单度量风险；它们不创造风险。"** 清单是工具：2018年美国清单给采购设条件，CRMA基准给许可优先权设条件，IRA的受关注实体规则给数千亿美元规模的税收抵免设条件——而2025年的中国管制通过0.1%含量规则针对外国矿山的*所有权*来回应这些规则。每份清单现在都是棋局里的一步，这就是为什么清单方法论（谁算"加工"？）已成为一个法律战场。
3. **"价格飙升解决稀缺。"** 有时它们加深稀缺。2021–2022年的飙升许可了2024–2025年崩盘搁浅的矿山，而在位者对高价的响应是*淹没*（2015–2020年与2024–2025年中国的降价杀死了三个独立的西方锂与稀土事业——使单一供应者市场在任何价格下都不可进入的"价格伞"）。储备与价格下限之所以存在，正因为飙升的解药是暂时的。
4. **"回收很快闭环。"** 回收是真实而增长的（2024–2025年：内华达、安大略与德国的电池黑粉厂；2025年欧盟电池法规的再生含量规则），而算术是慢的：以今天的车队，报废在约2050年之前不能满足2040年的需求，因为车队本身就是矿体；而对钴与镍它已供应约10–30%的原料，对磁体里的稀土它仍是使用的约1%。回收是*第二条*供应链，不是第一条的替代品。
5. **"转型的矿产需求是命运。"** 2021–2025年的记录是反例：化学替代（LFP、钠离子、铁氧体辅助与无稀土马达）到2025年移走的钴、镍与镝需求多于每一份矿山计划增加供应安全所给的——需求是一个设计变量，而工具箱里最少被使用的政策是资助替代，那正是日本2010年之后实际做的、而人人引用而没人规模资助的。
:::

::: example 2021–2025年价格过山车与政策回旋镖 {#ex-price-cycle}
重新教授经典的那五年周期。**2021–2022年，飙升：**电池级碳酸锂从约$7/kg涨到约$80/kg（2022年末），锂辉石从约$450涨到7,000美元以上，镍因2022年3月青山LME逼仓短暂三倍，而多数转型金属的实际价格达到或接近超级周期高点——需求堆栈（EV销量逐年翻倍）、疫情后资本开支饥饿（2015–2020年勘探干旱，[[earth-resources/resources-reserves]]）、与恐慌性库存建设的碰撞。**2023–2025年，崩盘：**碳酸锂跌约90%到约$9–10/kg，锂辉石到约$800，钴到历史低位，稀土氧化物价格跌约40%——由中国过剩供给（2023–2025年非洲页岩与南美卤水的建设、印度尼西亚镍钴潮）、西方需求减速、与替代潮驱动。**政策回旋镖：**每个刚刚立法"供应安全"的政府回应的是崩盘、不是飙升——2025年美国对分离稀土的价格下限（*逆着*廉价中国材料买入）、欧盟的战略项目补贴、Project Vault的储备、以及2025年美国第232条关税在美国冶炼已在收缩时到来。经济学就是[[earth-resources/resources-reserves]]的周期加一个地缘政治叠层：飙升过度许可，崩盘维护不足，而战略储备加价格下限是*压平周期本身*的一次尝试——自被放弃的1970–80年代国际商品缓冲协定时代（1985年失败的国际锡理事会与联合国综合商品方案的缓冲储备，它们的崩溃教会西方三十年的矿产自由放任）以来的第一次认真尝试。一个民主的产业政策能否挺过一个价格周期——2025–2030年磁体与锂厂将做的检验——是本课整个的未决问题。
:::

::: history 从国防储备到Project Vault：七十年的矿产政策 {#hist-policy-pendulum}
**1939–1955：**《储备法》与杜鲁门建设——75种商品、80亿美元的铬、锰、钴与钨，1940年日本锡橡胶禁运的明确教训；储备成为冷战的沉默矿山（1950年代的"过剩"辩论立即开始而永未结束）。**1970年代：**"非金属"时刻——1973年阿拉伯石油禁运、1973–74年扎伊尔/安哥拉钴与铜恐慌（福特行动与1975年只管石油的IEA成立）、1975–1989年国际锡理事会缓冲储备实验、以及1980年代里根时代转向市场正统与储备出售。**1990年代：**出售时代——1993年国防储备管理办公室的销售资助了它们所打压的同样那些非洲与拉丁美洲矿山，而"供应安全"成为一个只有环境与采矿史学家使用的短语。**2010–2019：**稀土冲击的制度残留——欧盟原材料倡议（2010年，清单加创新伙伴关系加治理外交）、日本的JOGMEC风险局、储备与海外股权计划（2010年起）、美国2017年行政令与2018年清单、以及中国2012–2015年对其配额制度在WTO的辩护（它输了并遵守了——2023–2025年的管制悄悄放弃的一个细节）。**2020–2025：**一切的回归——欧盟《关键原材料法》（2023年）带其10/40/25/65基准与战略项目、IRA与受关注实体规则、矿产安全伙伴关系（2022年）、《国防生产法》与第三章磁体授标、2025年第232条加工矿产调查与关税、以及**Project Vault**（2025年10月）：100亿美元的进出口银行借贷加20亿私人，一个行业管理的"对电动车与电池要紧的矿产"储备——储备思想重生为不是一个金锭仓库而是一个资产负债表工具，也是1990年代空位期已结束的最清楚信号。钟摆的弧线——投保（1940年代）、投保（1970年代）、忽略（1990年代）、投保*并*重塑（2020年代）——就是本课两个轴的制度史。
:::

## 练习

::: exercise {level=1 check="3750"}
一条供应链由份额为50%、25%与25%的三个国家服务。计算这条链的Herfindahl–Hirschman指数。
::: solution
HHI = 50² + 25² + 25² = 2500 + 625 + 625 = 3750——在2,500的"高度集中"阈值之上，即使这条链有三个供应者、而一个听起来多元化的100%"前三份额"。
:::
:::

::: exercise {level=1 check="80000"}
直驱电动车牵引电机每个用约8 kg的钕镨磁体。若世界在一年里建造1000万辆这样的电动车，那需要多少吨钕镨磁体？
::: solution
1000万 × 8 kg = 8 × 10⁷ kg = 80000吨磁体——作为规模对照，世界所有稀土氧化物的矿山产量约350,000 t/年，所以在当前磁体装载下仅电动车就占其四分之一。
:::
:::

::: exercise {level=1 check="210"}
一个回收商每年加工500 kt电池黑粉，收集与交付率为60%、金属回收率为70%。这座厂产出多少千吨回收金属？
::: solution
500 × 0.60 × 0.70 = 210 kt的回收金属——两个相乘的损失（物流与化学）就是为什么"回收将供应转型"的主张既需要收集系统也需要精炼厂、不只是熔炉。
:::
:::

::: exercise {level=2 check="28000"}
世界稀土氧化物矿山产量为350 kt/年，而中国做世界约92%的分离。每年有多少吨稀土氧化物在中国*之外*分离？
::: solution
350,000 × 0.08 = 28000 t/年——整个非中国的分离工业比一个中国省级集群还小，这就是为什么"我们在Mountain Pass开采"与"我们在Mountain Pass分离"是两个不同的句子、带两个不同的日期（2018与2024）。
:::
:::

::: exercise {level=2 check="9"}
锂辉石精矿在2022年11月峰值近$7,650/t、在2025年谷底近$850/t。价格从峰到谷跌了多少倍？
::: solution
7650/850 = 9——不到三年里九倍的一个来回，而对一个矿山开发要7–10年的商品：应用于一个政策驱动需求冲击的发现滞后周期的算术。
:::
:::

::: exercise {level=2 check="12"}
欧盟CRMA基准要求到2030年至少10%的欧盟一种战略原材料年消费量在欧盟境内开采。若2030年欧盟锂消费量为120 kt（LCE），满足基准所需的欧盟开采最低产量是多少 kt（LCE）？
::: solution
0.10 × 120 = 12 kt LCE在欧盟开采——大约整个欧洲锂工业当前的产量，这就是为什么基准的实际内容是与它连在一起的许可改革与战略项目清单。
:::
:::

::: exercise {level=3 check="15000"}
直驱海上风机每MW额定容量用约100 kg稀土磁体。若世界在一年里安装150 GW新的直驱风电容量，那需要多少吨稀土磁体？
::: solution
150 GW = 150,000 MW；150,000 MW × 100 kg/MW = 1.5 × 10⁷ kg = 15000 t磁体——对照世界约350,000 t所有稀土氧化物的矿山产量，所以仅这个建设速度的风电就为磁体占氧化物产量的4%以上，还没算电动车马达。
:::
:::

::: exercise {level=3 check="3200"}
一个1,000 GWh的EV电池市场使用每MWh含8 kg钴的NMC电芯。若LFP份额（零钴）从市场的10%升到50%，钴需求下降多少吨？
::: solution
1,000 GWh = 10⁶ MWh。在10% LFP时：0.90 × 10⁶ × 8 kg = 7,200 t。在50%时：4,000 t。下降是3200 t——钴需求的44%，由不到五年的一个化学选择移除、而没有新矿山。
:::
:::

::: exercise {level=3 check="120"}
美国持有2,000 t以平均$30/kg买入的储备钴。若2025年配额冲击把钴抬到$60/kg，储备的市场价值是多少百万美元？
::: solution
2,000 t = 2 × 10⁶ kg；在$60/kg时价值是1.2 × 10⁸美元 = 120百万美元——对一个120亿美元的储备、一个300亿美元的年市场来说微不足道，这就是Project Vault规模辩论的规模教训。
:::

::: quiz
2010–2015年稀土价格飙升未能永久降低中国在稀土*加工*（对照开采）上份额的主要原因是：
- [ ] 分离化学在中国之外不可能
- [x] 2015年之后由在位者更低成本维持的价格下跌，使非中国分离厂在成熟之前就不经济
- [ ] WTO禁止在中国之外新建加工产能
- [ ] 西方政府在2020年之前拒绝资助任何分离产能
::: solution
飙升确实产生了矿山与一批分离企业（Molycorp、澳大利亚与马来西亚的初创），但当在位者匹配下跌的价格时，工厂死了或在底部被买下——资本密集、低毛利的加工没有价格下限就不能挺过一场蓄意的价格战，而这正是2025年美国每公斤110美元的合同下限试图提供的。只有Lynas的矿山到分离一体化链挺过了第一轮、而且只靠政府合同。
:::

## 小结

::: summary
- **关键性 = 经济重要性 × 供应风险**，不是稀缺：这些清单（欧盟CRMA 41/27、美国50、日本、韩国）是方法论文档，而最有用的度量是*加工*环节的HHI、不是矿山的。
- **地图在下游塌缩**：开采是宽的（锂四大洲、钴一个半、稀土四个），加工是窄的（中国约65%锂精炼、约90%稀土分离、90%以上镓、约90%磁体与球形负极），而瓶颈总是建设认证时间最长的那个环节——一座工厂，不是一块岩石。
- **需求是一个设计变量**：转型每辆车比它取代的系统耗矿6倍，但化学替代（LFP 5% → 40%、钠离子、降镝）在2021–2025年移走的关键金属需求多于每一份矿山计划增加的安全——最少被使用的政策是资助替代。
- **政策工具箱有四代**——储备（1948年储备、2025年Project Vault）、清单与情报、产能政策（CRMA 10/40/25/65基准、IRA来源与受关注实体规则、国防部价格下限与股权）、以及联盟加反制政策（MSP、第232条、出口管制）——而2023–2025年管制潮显示每件工具现在也是一件武器。
- **价格周期是最深的力**：飙升过度许可，崩盘维护不足，而在位者的价格伞在任何价格下都阻止进入——这就是为什么2025年的政策前沿是*压平周期*（下限、储备、战略采购），以1985年锡崩溃结束的缓冲协定时代以来第一次认真尝试。
:::
