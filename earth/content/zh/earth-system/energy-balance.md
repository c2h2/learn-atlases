测量全球辐射收支的卫星——云与地球辐射能量系统（CERES）仪器，自2000年起随"terra"号及其后续平台飞行——发现，就全球和全年平均而言，地球向太空送回$238.5\ \mathrm{W\,m^{-2}}$。它以同样的平均方式接收的也几乎正是这个数。收支并不严格相等：仪器现在测得地球多留下了约$0.9\ \mathrm{W\,m^{-2}}$，而其中约$90\%$进入了海洋。相对于$240$的吞吐量，每平方米零点几瓦，这就是全球变暖——千分之四的不平衡。

本章的一切都来自对辐射的计数。太阳又热又小，所以以可见光发光；地球又冷又大，所以以红外发光。大气恰好对前者透明、对后者不透明，而分子物理学这一偶然事件使地表比本来要暖几十度。我们将把收支写成算术，加上球体的几何和自转轴的倾角，然后看看当某个量改变时收支如何移动——这就是气候物理学的全部缩影。

## 到达的是什么

::: definition 太阳常数与日射 {#def-solar-constant}
**太阳常数**$S_0$是在日地平均距离处、垂直于太阳光线的表面上接收到的太阳辐照度：$S_0 = 1361\ \mathrm{W\,m^{-2}}$（由总辐照度监测实验及其后续仪器自1991年以来的测量给出）。**日射**是某个给定表面实际接收的辐照度，它取决于太阳高度、时刻、季节和纬度。
:::

因为地球是球，它以一个面积为$\pi R^2$的圆面截获阳光，却要把能量分摊到$4\pi R^2$的表面上。因此全球平均的大气层顶数值是$S_0/4 = 340\ \mathrm{W\,m^{-2}}$。地球轨道略呈椭圆（偏心率$e = 0.0167$），所以辐照度一年内有$\pm 3.4\%$的变化，在1月3日前后的近日点达到最大：近日点与远日点辐照度之比为$[(1+e)/(1-e)]^2 = 1.069$，即$7\%$。11年太阳周期使$S_0$变化约$1.3\ \mathrm{W\,m^{-2}}$，千分之一。

太阳在很好的近似下是温度$T_\odot = 5772\ \mathrm{K}$的黑体。有两个推论支配着后面的一切。

::: theorem 普朗克、维恩与斯特藩-玻尔兹曼定律 {#thm-radiation}
温度为$T$的黑体的光谱辐射亮度为

$$
B_\lambda(T) = \frac{2hc^2}{\lambda^5}\,\frac{1}{e^{hc/\lambda kT} - 1},
$$

其峰值服从**维恩位移定律**$\lambda_\text{max}T = 2898\ \mu\mathrm{m\,K}$，其总发射通量服从**斯特藩-玻尔兹曼定律**

$$
F = \varepsilon\sigma T^4, \qquad \sigma = 5.6704\times10^{-8}\ \mathrm{W\,m^{-2}\,K^{-4}},
$$

其中$\varepsilon \le 1$为发射率（黑体$\varepsilon = 1$）。
:::

::: proof
对全波段和向外半球积分$B_\lambda$即得$\sigma T^4$：令$x = hc/\lambda kT$，

$$
\int_0^\infty B_\lambda\,\mathrm{d}\lambda = \frac{2\pi (kT)^4}{h^3c^2}\int_0^\infty \frac{x^3}{e^x - 1}\,\mathrm{d}x = \frac{2\pi k^4}{h^3c^2}\cdot\frac{\pi^4}{45}\,T^4,
$$

其中用到$\int_0^\infty x^3/(e^x-1)\,\mathrm{d}x = \pi^4/45$；前面的常数算出来正是$5.6704\times10^{-8}$。至于峰值，对分母的主因子求导：$\mathrm{d}B_\lambda/\mathrm{d}\lambda = 0$给出$5(1 - e^{-x}) = x$，其中$x = hc/\lambda kT$，其解为$x = 4.965$，于是$\lambda_\text{max}T = hc/4.965k = 2898\ \mu\mathrm{m\,K}$。
:::

在$5772\ \mathrm{K}$下峰值位于$0.50\ \mu\mathrm{m}$，即绿光；太阳能量约$43\%$在可见光波段$0.4$–$0.7\ \mu\mathrm{m}$，$49\%$在更长波处，$7\%$在紫外。地球自身辐射的峰值在$2898/288 = 10.0\ \mu\mathrm{m}$。这一分离正是大气对两束辐射表现如此不同的原因：$\mathrm{H_2O}$、$\mathrm{CO_2}$、$\mathrm{O_3}$、$\mathrm{N_2O}$、$\mathrm{CH_4}$的强振动跃迁落在热红外，而主要气体——没有偶极矩的$\mathrm{N_2}$和$\mathrm{O_2}$——对两者几乎透明。

::: definition 反照率 {#def-albedo}
地表或行星的**反照率**$\alpha$是它反射的入射辐射比例。行星（邦德）反照率是整颗行星按波长积分、半球积分的数值：地球为$\alpha = 0.294 \pm 0.004$（基于CERES，Stephens等，2012年）。**地表**反照率在洋面很低（$0.06$），在森林（$0.12$–$0.15$）、雪（$0.7$–$0.9$）和新海冰（$0.6$）较高。
:::

行星反照率约三分之二来自云和大气散射，三分之一来自地表，仅云就占了总数的一半左右。乘出来：到达大气层顶的$340\ \mathrm{W\,m^{-2}}$中，$100$被反射，$240$被吸收——其中$78\ \mathrm{W\,m^{-2}}$在大气和云中（主要由水汽和臭氧吸收），$162$在地表（Trenberth、Fasullo与Kiehl，2009年）。

## 零维能量收支

::: proposition 行星的平衡温度 {#prop-ebm}
一颗在距离光度为$L$的恒星$d$处快速自转的行星，其邦德反照率为$\alpha$、发射率为$\varepsilon$，则平衡**有效辐射温度**为

$$
T_e = \left(\frac{L(1-\alpha)}{16\pi\sigma\varepsilon\, d^2}\right)^{1/4} = \left(\frac{S_0(1-\alpha)}{4\sigma\varepsilon}\right)^{1/4}.
$$
:::

::: proof
吸收功率=（轨道处辐照度）×（截面积）×（未被反射的比例）$= \frac{L}{4\pi d^2}\pi R^2(1-\alpha)$。发射功率$= \varepsilon\sigma T^4 \times 4\pi R^2$，即整个表面——前提是各处表面都同样暖，只要自转足够快、昼面能冷却到接近夜面的温度，这个前提就成立；对缓慢自转、没有大气的天体则不成立。令两者相等并约去$\pi R^2$即得结果，其中$S_0 = L/4\pi d^2$。
:::

::: example 地球的辐射温度 {#ex-te}
取$S_0 = 1361\ \mathrm{W\,m^{-2}}$、$\alpha = 0.294$，计算地球的有效辐射温度，并与观测地表温度比较。
::: solution
$$
T_e = \left(\frac{1361\times 0.706}{4\times 5.6704\times10^{-8}}\right)^{1/4} = \left(\frac{960.9}{2.268\times10^{-7}}\right)^{1/4} = (4.237\times10^{9})^{1/4} = 255.1\ \mathrm{K}.
$$

地表平均约$288\ \mathrm{K}$（1991–2020年平均为$287.5\ \mathrm{K}$，2023年又暖了约$0.5\ \mathrm{K}$；Berkeley Earth、哥白尼计划），因此地表比行星向太空辐射所对应的高度暖约$32\ \mathrm{K}$——通常记作$33\ \mathrm{K}$。这$33\ \mathrm{K}$就是自然温室效应的惯用尺度。请注意这个计算是什么、不是什么：它是关于**辐射**的陈述，$255\ \mathrm{K}$是$5\ \mathrm{km}$附近那层空气的温度，向外红外辐射大多从那里逃逸；它并不是完全没有大气时地表会有的温度（见下面的警示）。
:::
:::

::: warning "$-18\ ^\circ\mathrm{C}$：没有温室效应的地球"并不是一个预言
$255\ \mathrm{K}$这个数字常被端上来当作"没有大气时地球会有的温度，因而也没有生命"。它不是。它是说，**如果地表是唯一的发射体且在红外是黑体**，辐射掉所吸收的日光所需的地表温度。把大气去掉，你同时也去掉了水汽和云，而它们本身就是最主要的温室气体：行星反照率会从$0.294$降到约$0.15$，而水汽的消失留下的温室效应远比你打算关掉的那个更弱。对当前太阳输出下干燥、只含$\mathrm{CO_2}$的地球，最佳估计接近$230\ \mathrm{K}$；而火星——更小、更远、大气只有我们的$1\%$——停在$210\ \mathrm{K}$。$33\ \mathrm{K}$是一个有用的记账数字，不是一个反事实。
:::

## 为什么收支本身不够：温室效应

::: proposition 单层温室模型 {#prop-greenhouse}
设大气对太阳辐射完全透明、对红外完全吸收并发射，以一个等温层（温度$T_a$）表征。则

$$
T_a = T_e, \qquad T_s = 2^{1/4}T_e = 1.19\,T_e,
$$

于是$T_e = 255\ \mathrm{K}$时地表为$303\ \mathrm{K}$。
:::

::: proof
大气层顶：唯一离开的辐射是该层向上的发射，故$\varepsilon\sigma T_a^4 = (1-\alpha)S_0/4 = \sigma T_e^4$，得$T_a = T_e$。地表：它吸收太阳束$(1-\alpha)S_0/4$**以及**该层向下的发射$\sigma T_a^4$，并发射$\sigma T_s^4$，于是
$$
\sigma T_s^4 = \sigma T_e^4 + \sigma T_a^4 = 2\sigma T_e^4 .
$$
因子$2^{1/4} = 1.189$完全来自大气**向下**辐射这一事实。若有$n$个这样的层，同样的论证给出$T_s = (n+1)^{1/4}T_e$。
:::

一个理想化的层就过头了（$303\ \mathrm{K}$对$288\ \mathrm{K}$），因为真实大气既不是对阳光透明，也不是在所有红外波段都全黑。标准的灰大气结果把整数$n$换成连续的**红外光学厚度**$\tau$：对灰性、平面平行、辐射传输的大气使用爱丁顿近似，

$$
T_s^4 = \left(1 + \tfrac{3}{4}\tau\right)T_e^4,
$$

因此现今气候对应$\tau \approx 0.84$。物理上重要的不是这个数，而是结构：地表比发射层暖，是因为它必须发射足够的能量以同时供给向太空的损失和大气自身的吸收；而暖多少由气柱的不透明度决定。

::: example 大气有多不透明？ {#ex-tau}
求使$T_s = 288\ \mathrm{K}$（$T_e = 255\ \mathrm{K}$）所需的红外光学厚度，以及在其他条件不变时$1\ \mathrm{K}$增暖所需的额外光学厚度。
::: solution
$$
1 + \tfrac34\tau = \left(\frac{288}{255}\right)^4 = 1.626 \quad\Longrightarrow\quad \tau = 0.835 .
$$

在固定$T_e$下对$T_s^4 = (1 + \tfrac34\tau)T_e^4$微分得$4T_s^3\,\mathrm{d}T_s = \tfrac34 T_e^4\,\mathrm{d}\tau$，于是

$$
\mathrm{d}\tau = \frac{4T_s^3}{\tfrac34 T_e^4}\,\mathrm{d}T_s = \frac{4\times288^3}{0.75\times255^4}\times 1 = 0.115 .
$$

大气红外不透明度增加$13\%$就换来$1\ \mathrm{K}$的地表增暖。二氧化碳加倍使不透明度增加，其效应相当于$3.12\ \mathrm{W\,m^{-2}}$的强迫（IPCC第六次评估报告，2021年，第7章），而系统中流动的能量是$240\ \mathrm{W\,m^{-2}}$——这提醒我们，地表温度对一个在其最强波段上已近乎全不透明的滤层的小变化竟如此敏感。（这也正是那些波段并**未**饱和的原因：增加$\mathrm{CO_2}$会加宽吸收线的两翼，并抬高辐射逃逸所在的高度。）
:::
:::

::: definition 辐射强迫与气候敏感度 {#def-forcing}
**辐射强迫**$\Delta F$是指在平流层调整之后、但地表和对流层固定不变的条件下，对流层顶净（吸收减发射）辐照度的变化，单位$\mathrm{W\,m^{-2}}$。**有效辐射强迫**（ERF）放宽了平流层调整的条件，是现行评估所使用的量。响应为

$$
\Delta T = \frac{\Delta F}{\lambda}, \qquad \lambda = \lambda_0 + \sum_i \lambda_i ,
$$

其中$\lambda$为**气候反馈参数**（$\mathrm{W\,m^{-2}\,K^{-1}}$；负值表示稳定），$\lambda_0 \approx -3.2\ \mathrm{W\,m^{-2}\,K^{-1}}$为普朗克响应。**平衡气候敏感度**（ECS）是二氧化碳加倍引起的增暖：$\mathrm{ECS} = 3.12/|\lambda|$。
:::

::: example 从强迫到增暖 {#ex-ecs}
已知AR6的最佳估计$\mathrm{ECS} = 3.0\ ^\circ\mathrm{C}$、二氧化碳加倍的ERF为$3.12\ \mathrm{W\,m^{-2}}$，求净反馈参数。再求1850–1900至2019年总人为ERF $2.72\ \mathrm{W\,m^{-2}}$所对应的增暖，并与观测的$1.1\ ^\circ\mathrm{C}$比较。
::: solution
$$
|\lambda| = \frac{3.12}{3.0} = 1.04\ \mathrm{W\,m^{-2}\,K^{-1}} .
$$

普朗克响应本身就有$3.2$，所以其余反馈之和必约为$+2.2\ \mathrm{W\,m^{-2}\,K^{-1}}$——净**失稳**，且以水汽和云为主。$2.72\ \mathrm{W\,m^{-2}}$的平衡增暖应为$2.72/1.04 = 2.6\ ^\circ\mathrm{C}$，但迄今观测到的增暖是2011–2020年相对1850–1900年的$1.1\ ^\circ\mathrm{C}$（IPCC AR6，2021年）。差额是热惯性：海洋吸收了多余能量的$90\%$以上，地表还没有达到其强迫所对应的温度。仍在"管道中"的增暖是排放停止后气候仍会上升的原因，其量化见[[climate-change/projections]]。
:::
:::

::: quiz
地球的有效辐射温度是$255\ \mathrm{K}$，而地表是$288\ \mathrm{K}$。下面哪一句话最好地解释了这一差别？
- [ ] 地球比黑体计算所假设的更靠近太阳。
- [ ] 地表的反照率比行星的低。
- [x] 大气对入射可见光大体透明，却吸收并再发射大部分向外的红外辐射。
- [ ] 地球仍在从形成时的热量冷却，那股热量使地表变暖。
::: solution
大气把太阳束放到地表，然后阻挡地表发出的红外，因此地表必须比辐射最终逃逸出去的那一层更暖。反照率和距离已经包含在$255\ \mathrm{K}$里了；而内部热量只有太阳的$1/2800$（[[earth-system/planet-earth]]）。
:::
:::

## 季节的几何与纬度梯度

辐射的分布并不均匀，而分布格局完全由几何决定。大气层顶水平面上的日平均日射为

$$
\bar Q = \frac{S_0}{\pi}(1 + d)\left(H_0\sin\phi\sin\delta + \cos\phi\cos\delta\sin H_0\right),
\qquad \cos H_0 = -\tan\phi\tan\delta,
$$

其中$\phi$为纬度，$\delta$为太阳赤纬（在$\pm 23.44^\circ$之间，由黄赤交角决定），$H_0$为白昼半长（以弧度计），$d$为小的偏心率修正。当$|\tan\phi\tan\delta| > 1$时太阳不落下（取$H_0 = \pi/2$）或不升起（$\bar Q = 0$）。

::: example 各纬度的日射 {#ex-insolation}
计算赤道春分、$45^\circ\mathrm{N}$夏至、$65^\circ\mathrm{N}$夏至与冬至的大气层顶日平均日射，以及$0^\circ$、$65^\circ\mathrm{N}$和$90^\circ\mathrm{N}$的年平均值。
::: solution
春分赤道处$\delta = 0$、$H_0 = \pi/2$，故$\bar Q = S_0/\pi = 433\ \mathrm{W\,m^{-2}}$。$45^\circ\mathrm{N}$的6月21日，$\delta = 23.44^\circ$，$H_0 = 2.019\ \mathrm{rad}$（昼长$15.4$小时），得$\bar Q = 491\ \mathrm{W\,m^{-2}}$。$65^\circ\mathrm{N}$：六月$H_0 = 2.764\ \mathrm{rad}$（昼长$21.1$小时），$\bar Q = 486\ \mathrm{W\,m^{-2}}$；十二月太阳几乎不升起，$\bar Q \approx 3\ \mathrm{W\,m^{-2}}$。年均值：赤道$415\ \mathrm{W\,m^{-2}}$，$65^\circ\mathrm{N}$为$212$，北极为$172$。

有两点重要。高纬的季节反差极大——$486$对$3\ \mathrm{W\,m^{-2}}$——因为移动太阳的是**倾角**而不是距离。但**年均**的赤道到极地梯度只有$415 - 172 = 243\ \mathrm{W\,m^{-2}}$，约每纬度$1.5\ \mathrm{W\,m^{-2}}$。正是这个温和而永久的不平衡驱动着一般环流（[[earth-system/circulation]]）、海洋和风暴，也是天气能量的最终来源。
:::
:::

::: warning 季节不是由日地距离造成的
地球在1月初——北半球隆冬——最靠近太阳。若距离决定季节，两个半球会同时变暖，而事实并非如此。原因是自转轴$23.44^\circ$的倾角改变了太阳高度和白昼长度。距离确实略微调制了幅度：近日点多出的$7\%$辐照使南半球夏季比北半球强约$1.7\%$，而正是这种不对称、而非总量，在$23$与$19$千年周期上为冰期定拍（[[palaeoclimate/orbital-cycles]]）。
:::

## 冰、反照率与响应的形状

::: example 局部变化的全球代价 {#ex-albedo-change}
假设全球表面积的$1\%$由森林（反照率$0.12$）变为覆雪的皆伐地（反照率$0.35$）。求全球平均辐射强迫，并取$\lambda = -1.04\ \mathrm{W\,m^{-2}\,K^{-1}}$求平衡的全球温度变化。
::: solution
局部吸收太阳辐射的变化为$\Delta\alpha \times \bar S$，其中$\bar S = S_0/4 = 340\ \mathrm{W\,m^{-2}}$为全球平均日射：

$$
\Delta F_\text{local} = -(0.35 - 0.12)\times340 = -78\ \mathrm{W\,m^{-2}} .
$$

分摊到$1\%$的行星表面，全球平均强迫为$-0.78\ \mathrm{W\,m^{-2}}$——与当前甲烷的全部强迫相当。平衡响应为

$$
\Delta T = \frac{-0.78}{-1.04} = -0.75\ ^\circ\mathrm{C}.
$$

两点提醒。这一计算忽略了冰-反照率反馈，后者会放大局部的变冷；也忽略了毁林同时移除碳、改变蒸散发并影响云，而在多数真实情形中这些比反照率更重要。这道算术的意义在于量级：局限于$1\%$地表的改变就能产生与一个世纪的甲烷排放同量级的强迫。
:::
:::

::: proposition 线性反馈与失控条件 {#prop-runaway}
取线性化的向外长波响应$\lambda_0 = -4\sigma T_e^3$、反馈总强度$\lambda_f = \sum_i\lambda_i > 0$，则对强迫的平衡响应为

$$
\Delta T = \frac{\Delta F}{-(\lambda_0 + \lambda_f)},
$$

仅当$\lambda_f < |\lambda_0|$时有限。相对于无反馈响应的放大因子为$|\lambda_0|/|\lambda_0 + \lambda_f|$。
:::

::: proof
扰动能量收支为$C\,\mathrm{d}\Delta T/\mathrm{d}t = \Delta F + \lambda_f\Delta T + \lambda_0\Delta T$，其中$C$为单位面积有效热容量。令左端为零即得上述平衡值。无反馈响应为$\Delta F/|\lambda_0|$，故比值如所述。平衡要求分母为正，即$\lambda_f < |\lambda_0| = 3.2\ \mathrm{W\,m^{-2}\,K^{-1}}$。若反馈达到这一数值，普朗克响应便再无法把扰动辐射掉，地表温度将无限制上升——这就是"失控温室"的数学内容。$\lambda_f$的评估值约为$+2.2$，所以地球是稳定的，但用IPCC AR6的校准语言说，余量并不算大。
:::

::: example 太阳11年周期有多重要？ {#ex-solar-cycle}
总太阳辐照度在极小期与极大期之间变化约$1.3\ \mathrm{W\,m^{-2}}$。求相应的强迫，以及$\lambda = -1.04\ \mathrm{W\,m^{-2}\,K^{-1}}$所隐含的全球平均温度变化，并与人为ERF的$2.72\ \mathrm{W\,m^{-2}}$比较。
::: solution
$$
\Delta F = \frac{1.3\times(1 - 0.294)}{4} = 0.23\ \mathrm{W\,m^{-2}}, \qquad
\Delta T = \frac{0.23}{1.04} = 0.22\ ^\circ\mathrm{C}.
$$

这是对太阳周期完整一次摆动的平衡响应，而观测响应更小（约$0.05$–$0.1\ ^\circ\mathrm{C}$，海洋惯性削弱了11年信号）——原因与地表日较差只有约$10\ \mathrm{K}$、尽管日射在$0$到$340\ \mathrm{W\,m^{-2}}$之间摆动相同。人为强迫是太阳周期的十二倍，而自2008年以来太阳常数略有*下降*，全球温度却在上升。要把近期增暖归因于太阳，就必须让强迫与响应朝相反方向变化；这一问题在[[climate-change/attribution]]中检验。
:::
:::

::: quiz
下列哪一项改变最可能减小赤道与极地之间的年均温度差？
- [ ] 使地球轨道更扁。
- [x] 使自转轴倾角趋近于零。
- [ ] 使地球自转更快。
- [ ] 均匀地提高行星反照率。
::: solution
年均日射的纬度差由倾角决定：若黄赤交角为零，太阳将始终直射赤道，日射向两极平滑递减，季节消失，于是驱动一般环流的赤道-极地能量差会缩小（随之缩小的还有让两极保持寒冷的冰）。偏心率对两个半球同时起作用，且在半长轴固定时几乎不改变全球年总量；自转速度改变的是大气和海洋输送能量的方式，而不是到达的能量；均匀的反照率改变移动的是整颗行星的温度，而不是温差。
:::
:::

::: history
约瑟夫·傅里叶（Fourier）在1824年和1827年提出了这一问题，把地球比作盖上玻璃的箱子，并得出大气保留热量"其机制类似于索绪尔（de Saussure）的热空气箱"。约翰·丁达尔（Tyndall）在1861年用罐与热电堆实验给出了机制，证明水汽和二氧化碳吸收地球辐射的热。塞缪尔·兰利（Langley）1878年造出辐射热计，1881年在惠特尼峰把太阳常数测到百分之几以内，并测得大气吸收的地面辐射比例。然后在1900年，克努特·奥斯特罗姆（Ångström）犯了本世纪影响深远的一个错误：他依据实验室气管论证$\mathrm{CO_2}$吸收带已经饱和，再多二氧化碳也不会有作用。毛病在于气管只有一个温度、一个压强。1938年，圭·卡伦达尔（Callendar）汇编了一个世纪的气象站温度和早期大气二氧化碳分析，指出两者都在上升；1950年，弗里茨·米勒（Möller）证明压致变宽和重叠的水汽带使二氧化碳的吸收带远未饱和。现代计算始于Syukuro Manabe与Richard Wetherald 1967年的工作：他们把二氧化碳波段模式放进一维辐射-对流气柱，得到加倍增暖$2.9\ ^\circ\mathrm{C}$——第一个现代气候敏感度估计。自2000年起，CERES仪器从太空测量整个辐射收支，它报告的不平衡现已成为气候科学中确定得最好的数字之一。
:::

## 由此通向何处

能量收支是气候课程的入场券。[[climate-system/energy-budget]]在卫星记录所允许的细节上展开全球收支及其分量；[[climate-system/greenhouse-effect]]认真处理吸收、对二氧化碳的对数依赖和发射层的论证；[[climate-system/feedbacks-sensitivity]]把反馈参数变成一个关于模式与观测的证据问题；[[earth-system/circulation]]则取[[#ex-insolation]]中算出的纬度不平衡，追问大气和海洋如何把它搬运走。同样四行代数在[[planetary-science/atmospheres]]追问什么让行星宜居时会原样重现。

::: summary
- 太阳平均输送$S_0/4 = 340\ \mathrm{W\,m^{-2}}$；$100$被反射（$\alpha = 0.294$），$240$被吸收。卫星测得向外$238.5\ \mathrm{W\,m^{-2}}$，剩余不平衡约$0.9\ \mathrm{W\,m^{-2}}$。
- 平衡给出$T_e = [S_0(1-\alpha)/4\sigma]^{1/4} = 255\ \mathrm{K}$；维恩定律把太阳峰值放在$0.50\ \mu\mathrm{m}$、地球峰值放在$10\ \mu\mathrm{m}$，这一分离是温室效应的前提。
- $288\ \mathrm{K}$与$255\ \mathrm{K}$之间$33\ \mathrm{K}$的差是关于辐射层次的陈述，不是对无大气地球的预言。
- 红外光学厚度为$\tau$的灰大气给出$T_s^4 = (1 + \tfrac34\tau)T_e^4$；今日$\tau \approx 0.84$，$1\ \mathrm{K}$需要不透明度增加$13\%$。
- $\Delta T = \Delta F/\lambda$，其中$\lambda = \lambda_0 + \sum\lambda_i$；评估的$|\lambda| \approx 1.0\ \mathrm{W\,m^{-2}\,K^{-1}}$，而普朗克响应为$3.2$，因此反馈净为正但系统仍稳定。
- 日射由几何决定：$65^\circ\mathrm{N}$六月$486\ \mathrm{W\,m^{-2}}$，十二月$3\ \mathrm{W\,m^{-2}}$；但年均的赤道到极地差仅$243\ \mathrm{W\,m^{-2}}$。
- 季节来自$23.44^\circ$的倾角，而不是日地距离。
:::

## 习题

::: exercise 其他行星的辐照度 {level=1 check="586"}
火星轨道半径为$1.524\ \mathrm{AU}$。那里的太阳常数是多少（$\mathrm{W\,m^{-2}}$）？
::: solution
$S = S_0/\text{AU}^2 = 1361/1.524^2 = 1361/2.323 = 586\ \mathrm{W\,m^{-2}}$。
:::

::: exercise 维恩定律 {level=1 check="10.1"}
取$T = 288\ \mathrm{K}$，地球辐射最强的波长是多少？答案以$\mu\mathrm{m}$给出。
::: solution
$\lambda_\text{max} = 2898/288 = 10.1\ \mu\mathrm{m}$，位于热红外——正是$\mathrm{H_2O}$、$\mathrm{CO_2}$、$\mathrm{O_3}$和$\mathrm{CH_4}$吸收的区域。
:::

::: exercise 变暗冰盖的辐射温度 {level=1 check="229"}
金星的$S_0 = 2613\ \mathrm{W\,m^{-2}}$，邦德反照率$0.76$。求其有效辐射温度（开尔文）。
::: solution
$T_e = [2613\times(1-0.76)/(4\times5.6704\times10^{-8})]^{1/4} = [627.1/2.268\times10^{-7}]^{1/4} = 229\ \mathrm{K}$。其地表为$735\ \mathrm{K}$：那里的温室效应为$506\ \mathrm{K}$。
:::
:::

::: exercise 反照率的变化 {level=2 check="0.9"}
若行星反照率从$0.294$降到$0.284$，$T_e$变化多少开尔文？答案保留一位小数。
::: solution
$T_e(0.284) = [1361\times0.716/(4\sigma)]^{1/4} = 256.0\ \mathrm{K}$，而$T_e(0.294) = 255.1\ \mathrm{K}$：变化$0.9\ \mathrm{K}$。用微分也得同样结果：$\mathrm{d}T/T = \mathrm{d}\alpha/[4(1-\alpha)]$，故$\mathrm{d}T = 255.1\times0.01/2.824 = 0.9\ \mathrm{K}$。注意这有多大——行星反照率改变$0.01$，在无反馈响应上几乎相当于大气二氧化碳加倍。
:::
:::

::: exercise $n$层模型 {level=2 check="361"}
用$T_s = (n+1)^{1/4}T_e$，取$T_e = 255\ \mathrm{K}$、$n = 3$，求地表温度。
::: solution
$T_s = 4^{1/4}\times255 = 1.414\times255 = 361\ \mathrm{K}$。对小整数的强依赖说明，为什么只部分吸收的真实大气必须用连续的光学厚度而不是整层来处理。
:::
:::

::: exercise 至日的日射 {level=2}
计算$30^\circ\mathrm{N}$在6月21日和12月21日的日平均日射，并求其比值。
::: solution
取$\delta = \pm 23.44^\circ$：六月，$\cos H_0 = -\tan30^\circ\tan23.44^\circ = -0.250$，$H_0 = 1.824\ \mathrm{rad}$（昼长$13.9$小时），
$$
\bar Q = \frac{1361}{\pi}\times0.984\times(1.824\times0.5\times0.398 + 0.866\times0.918\times0.969) = 426\times(0.363 + 0.770) = 482\ \mathrm{W\,m^{-2}}.
$$
十二月，$\delta = -23.44^\circ$，$H_0 = 1.318\ \mathrm{rad}$（昼长$10.1$小时），括号变为$-0.262 + 0.770 = 0.508$；地球接近近日点，前置因子为$1361\times1.017/\pi = 441$，故$\bar Q = 441\times0.508 = 223\ \mathrm{W\,m^{-2}}$。比值为$2.2$。在$30^\circ\mathrm{N}$，太阳在两个季节都很高，因此反差远小于$65^\circ\mathrm{N}$——同一计算在那里给出$486$对$3$（见[[#ex-insolation]]）。
:::
:::

::: exercise 太阳输出变化造成的强迫 {level=2 check="0.35"}
假设太阳常数增加$2\ \mathrm{W\,m^{-2}}$。取$\alpha = 0.294$，求辐射强迫（$\mathrm{W\,m^{-2}}$）。
::: solution
$\Delta F = \Delta S(1-\alpha)/4 = 2\times0.706/4 = 0.35\ \mathrm{W\,m^{-2}}$。取$|\lambda| = 3.2$（无反馈）得$0.11\ \mathrm{K}$；取$|\lambda| = 1.04$得$0.34\ \mathrm{K}$。
:::
:::

::: exercise 发射层 {level=3}
对流层温度按环境直减率$\Gamma = 6.5\ \mathrm{K\,km^{-1}}$下降。若有效辐射层位于$5\ \mathrm{km}$、地表为$288\ \mathrm{K}$，求$5\ \mathrm{km}$处的温度。若二氧化碳加倍使有效辐射层抬高$400\ \mathrm{m}$，估计向外长波辐射的变化和强迫，并与评估值$3.12\ \mathrm{W\,m^{-2}}$比较。
::: solution
$T(5\ \mathrm{km}) = 288 - 6.5\times5 = 255.5\ \mathrm{K}$——有效辐射温度位于$5\ \mathrm{km}$附近，正符合能量收支的要求。辐射层抬高$0.4\ \mathrm{km}$使发射温度降低$2.6\ \mathrm{K}$，于是
$$
\Delta F = \sigma\left[T_e^4 - (T_e - 2.6)^4\right] \approx 4\sigma T_e^3\times2.6 = 4\times5.67\times10^{-8}\times255.5^3\times2.6 = 9.8\ \mathrm{W\,m^{-2}}.
$$
这是评估值的三倍，所以真实响应必须更弱：在起作用的波段中辐射层只抬高约$130\ \mathrm{m}$，而且平流层在此过程中变冷，抵消了一部分强迫。这道题值得做，恰恰因为粗糙的数字是错的——它说明"增加温室气体抬高了地球辐射出去的高度"是正确的*图像*，却是糟糕的*计算器*。
:::
:::

::: exercise 管道中的增暖 {level=3}
海洋混合层（$70\ \mathrm{m}$，$\rho = 1025\ \mathrm{kg\,m^{-3}}$，$c_p = 3990\ \mathrm{J\,kg^{-1}\,K^{-1}}$）的单位面积热容量为$C$。在$2.72\ \mathrm{W\,m^{-2}}$的强迫下，若无反馈、混合层以下不吸收热量，升温$1\ ^\circ\mathrm{C}$需要多久？为什么真实海洋会让答案长得多？
::: solution
$C = 70\times1025\times3990 = 2.87\times10^{8}\ \mathrm{J\,m^{-2}\,K^{-1}}$。于是
$$
\Delta t = \frac{C\,\Delta T}{\Delta F} = \frac{2.87\times10^{8}}{2.72} = 1.06\times10^{8}\ \mathrm{s} = 3.3\ \mathrm{yr}.
$$
计入反馈（$|\lambda| = 1.04$）后平衡增暖更大，时间尺度受$C|\lambda|/\Delta F$限制，约十年。真实海洋不是$70\ \mathrm{m}$的表皮：风混合层、温跃层乃至最终整个$3700\ \mathrm{m}$吸收了多余热量的大部分，而有效响应时间由内部通风速率决定——几十年到几个世纪。这就是瞬态响应（迄今$1.1\ ^\circ\mathrm{C}$）远低于平衡响应的原因，也是海洋的深度为何是人类比混合层计算所显示的有更多时间、却又比海洋总热容量所许诺的更少时间的最大理由（[[climate-system/heat-transport]]）。
:::
:::

::: exercise 不自转的行星 {level=3}
一颗在与地球相同轨道上、反照率$0.10$的无大气行星自转极慢，地表处于局部辐射平衡（无水平和垂直热量输送）。(a) 求日下点温度。(b) 若地表为黑体，求全球平均发射通量。(c) 这对[[#prop-ebm]]中所用的假设有何说明？
::: solution
(a) 日下点平衡：$\sigma T^4 = S_0(1-\alpha) = 1361\times0.90 = 1225\ \mathrm{W\,m^{-2}}$，故$T = (1225/\sigma)^{1/4} = 383\ \mathrm{K}$。
(b) 对$T(\theta) = T_\text{ss}\cos^{1/4}\theta$在日照半球平均$\sigma T^4$，得$\overline{\sigma T^4} = \tfrac12\sigma T_\text{ss}^4 = 612\\ \mathrm{W\\,m^{-2}}$，相当于一个$322\\ \mathrm{K}$的均匀黑体——但**平均温度**比这更低，因为对$T \propto \cos^{1/4}\theta$取平均时寒冷的夜面权重很大。
(c) [[#prop-ebm]]中的因子$4$假定发射**通量**（而不是温度）均匀。真实快速自转且有大气的行星接近这一极限；慢速、无大气的则不然。月面在日照下达$390\ \mathrm{K}$、夜间降到$100\ \mathrm{K}$，而其全球平均发射通量仍等于吸收通量。
:::
