在南纬$20^\circ$到北纬$20^\circ$之间，大气层顶每平方米的得热比失热多约$60\ \mathrm{W\,m^{-2}}$；而在极地附近，失热比得热多约$100\ \mathrm{W\,m^{-2}}$（据CERES能量收支不平衡，2001–2018年平均）。若什么都不流动，热带会在几千年内沸腾，两极会在几千年内封冻。确有东西在流动。卫星、船只、系留流速仪和漂流浮标显示，大气和海洋一起把大约$5$–$6$拍瓦从低纬送往极地——$1$拍瓦是$10^{15}\ \mathrm{W}$，也就是说全人类文明用的能量大约只有气候系统向北输出的三十分之一。

本章讲这种输出为什么发生、为什么呈现为这些形态——五条主要风带、六个旋转的流涡、一个全球翻转回路——以及为什么同一套环流既决定了信风，也决定了沙漠、渔场和雨林的位置。有两个观念组织全部内容。第一是**旋转**：地球在运动的空气和水下面转动，由此产生的科里奥利效应把大尺度运动约束成少数几种允许的形态。第二是大气和海洋是同一种流体的两种密度，由同一个不平衡驱动，并且时刻在彼此对话。

## 待解决的不平衡

::: definition 经向热量输送 {#def-mht}
**经向（南北）热量输送**$F(\phi)$是在$\phi$纬圈上向北穿过的总能量流，单位瓦（通常用拍瓦，$\mathrm{PW} = 10^{15}\ \mathrm{W}$）。其定义使输送的散度与当地辐射盈余相平衡：在一个纬度带上，
$$
\text{辐射盈余} = -\frac{1}{2\pi a\cos\phi}\frac{\mathrm{d}F}{\mathrm{d}y},
$$
其中$y = a\phi$为向北的距离，$a$为地球半径。
:::

大气层顶的年均净辐射在赤道到约$40^\circ$纬度之间为正，之外为负；近$20^\circ$处盈余最大，约$+60\ \mathrm{W\,m^{-2}}$；极地冬季亏空最大，达$-120\ \mathrm{W\,m^{-2}}$。把盈余从赤道向外积分就得到各纬度所需输送。观测总输送在北纬$35^\circ$附近达到峰值约$6\ \mathrm{PW}$，在南纬$15^\circ$附近约$4\ \mathrm{PW}$（Trenberth与Caron，2001年；CERES时代的再分析有所更新）。

大气和海洋并不平均分工，而分工方式正是本章最有意思的事实。

- 在$30^\circ\mathrm{N}$上，大气输送约$2.5\ \mathrm{PW}$，海洋约$1.3\ \mathrm{PW}$——大气干大头。
- 在赤道上，**海洋**向北输送约$1.3\ \mathrm{PW}$，而大气向*南*输送约$1\ \mathrm{PW}$，因此海洋的贡献比总量还大。
- 原因在于大气对加热响应极快（气块几天内即调整）且对流剧烈，而海洋缓慢、层结强、受边界约束。大气在热带接住热量，在副热带放下一些，然后海洋在大气输送耗尽之处接手——这是一次真正的交接，也是北大西洋如此温暖的原因之一。

## 旋转决定形状

::: definition 科里奥利参数 {#def-coriolis}
在随地球旋转的参考系中，以速度$\mathbf{u}$运动的气块受到一个表观加速度$-2\boldsymbol{\Omega}\times\mathbf{u}$，其中$\Omega = 7.292\times10^{-5}\ \mathrm{s^{-1}}$。其水平效应由**科里奥利参数**

$$
f = 2\Omega\sin\phi
$$

支配：在$45^\circ$为$1.03\times10^{-4}\ \mathrm{s^{-1}}$，在赤道为$0$。**罗斯贝数**$\mathrm{Ro} = U/(fL)$比较两个加速度：大尺度快速流动$\mathrm{Ro} \ll 1$，旋转占主导；小尺度快速流动则不然。
:::

::: proposition 地转平衡 {#prop-geostrophic}
对于$\mathrm{Ro} \ll 1$、摩擦可忽略且无明显加速的水平运动，气压梯度力与科里奥利力平衡，给出**地转风**

$$
v_g = \frac{1}{f\rho}\frac{\partial p}{\partial y},
$$

它平行于等压线；在北半球低压在左，在南半球低压在右。
:::

::: proof
写出旋转地球上水平动量方程，略去摩擦和气块自身加速度：
$$
0 = -\frac{1}{\rho}\nabla_h p - f\,\mathbf{k}\times\mathbf{u}.
$$
取$\mathbf{u} = (u, v)$、气压梯度沿南北方向，两个分量为$fv = -(1/\rho)\,\partial p/\partial y$和$fu = (1/\rho)\,\partial p/\partial x$。对纯南北气压梯度，$u = 0$而$v = -(1/f\rho)\,\partial p/\partial y$：风沿梯度方向横向吹，而不是顺梯度吹。其大小即所给表达式。方向由北半球$f > 0$得出：若$p$向北减小，则$v > 0$不可能，流动必须向东，即平行于等压线且低压在左。
:::

::: example 地转风有多快？ {#ex-geostrophic}
气压向北在$500\ \mathrm{km}$内下降$5\ \mathrm{hPa}$。取$\rho = 1.2\ \mathrm{kg\,m^{-3}}$，求$15^\circ$、$45^\circ$和$60^\circ$纬度处的地转风。
::: solution
由$\partial p/\partial y = 500\ \mathrm{Pa}/5\times10^{5}\ \mathrm{m} = 1.0\times10^{-3}\ \mathrm{Pa\,m^{-1}}$、$f = 1.458\times10^{-4}\sin\phi$，

$$
v_g = \frac{1.0\times10^{-3}}{1.2\times1.458\times10^{-4}\sin\phi} = \frac{5.72}{\sin\phi}\ \mathrm{m\,s^{-1}},
$$

在$15^\circ$为$22\ \mathrm{m\,s^{-1}}$，$45^\circ$为$8.1\ \mathrm{m\,s^{-1}}$，$60^\circ$为$6.6\ \mathrm{m\,s^{-1}}$。同样的气压差在$f$很小的热带驱动的风强得多：赤道附近的大气无法组织起强涡旋，这也是热带气旋从不在赤道$5^\circ$以内生成的原因之一。$\phi \to 0$时$1/\sin\phi$的发散是在警告地转近似在那里失效，而不是预言无限大的风。
:::
:::

::: proposition 热成风 {#prop-thermalwind}
若水平温度场随高度变化，地转风必须随高度切变：

$$
\frac{\partial \mathbf{v}_g}{\partial z} = \frac{g}{f\,T}\,\mathbf{k}\times\nabla_h T .
$$

因此**一条自西向东的急流位于强南北温度对比之上**，在北半球其右侧为暖空气；只要温度对比存在，急流就随高度增强。
:::

::: proof
对地转关系$f v_g = -(1/\rho)\,\partial p/\partial y$关于$z$求导，并注意$f$与高度无关：
$$
f\frac{\partial v_g}{\partial z} = -\frac{\partial}{\partial y}\left(\frac{1}{\rho}\frac{\partial p}{\partial z}\right) + \text{混合项}.
$$
利用静力平衡$\partial p/\partial z = -\rho g$，右端第一项在$\rho = p/RT$下成为$\partial g/\partial y$形式的项；两个分量合并时混合导数项相消，而对只通过层厚影响结果的水平温度场，得到
$$
\frac{\partial v_g}{\partial z} = -\frac{g}{fT}\frac{\partial T}{\partial x}, \qquad
\frac{\partial u_g}{\partial z} = \frac{g}{fT}\frac{\partial T}{\partial y},
$$
即所述的矢量形式。物理内容很简单：两个等压面之间的厚度与平均温度成正比，因此冷暖对比使等压面的倾斜随高度加大，而在某一层与之平衡的风，在上一层必须吹得更猛。
:::

::: example 从温度对比到急流 {#ex-jet}
取中纬度对流层南北$3000\ \mathrm{km}$内$25\ \mathrm{K}$的温度差，标高$H = 7\ \mathrm{km}$。假设$850\ \mathrm{hPa}$处风很弱，估算对流层顶的急流风速。
::: solution
对厚度为$H$的一层积分热成风关系，取$T = 250\ \mathrm{K}$，

$$
\Delta v_g \approx \frac{gH}{fT}\frac{\Delta T}{\Delta y} = \frac{9.81\times7000}{1.03\times10^{-4}\times250}\times\frac{25}{3\times10^{6}} = 21\ \mathrm{m\,s^{-1}} .
$$

这与平均西风急流的量级相符：观测为$30$–$50\ \mathrm{m\,s^{-1}}$，极端时达$100\ \mathrm{m\,s^{-1}}$；估算偏低是因为温度对比集中在对流层上层，也因为急流本身是极大值而非从地面到对流层顶的平均。重要的结论是结构性的：**急流是赤道-极地温度对比的直接结果**，因此任何减小该对比的环流都会削弱急流。这种平均状态与维持它的涡旋之间的耦合，是[[atmospheric-dynamics/vorticity]]的主题。
:::
:::

## 大气一般环流

::: definition 三圈环流模型 {#def-cells}
一个半球的平均经向环流用三个环流圈描述：**哈得来环流**，在热赤道附近上升、在$30^\circ$附近下沉，向上伸展到约$15\ \mathrm{km}$；**极地环流**，浅而弱，在极地下沉；两者之间是间接的**费雷尔环流**，它是风暴的统计产物，而不是热力驱动的引擎。
:::

其中只有哈得来环流可以用几个数字讲清楚。在赤道辐合带（ITCZ）上升的空气把角动量向上携带。由于地球自转，赤道地表空气具有$465\ \mathrm{m\,s^{-1}}$的向东速度$\Omega a\cos\phi$；当它在$10$–$15\ \mathrm{km}$高度向极地移动时角动量守恒，于是相对地面加速向东，达到$50$–$100\ \mathrm{m\,s^{-1}}$——这就是副热带急流。等到空气在$30^\circ$下沉时，它已失去了大部分水汽（那些雨全下在热带和迎风坡上），空气是干的。这就是为什么地球上几乎所有大沙漠都在$20^\circ$到$35^\circ$之间：撒哈拉、阿拉伯、塔尔、索诺兰、卡拉哈里、澳大利亚内陆，以及使阿塔卡马成为地球最干地方的那条干带。

::: example 哈得来环流能伸多远？ {#ex-hadley}
在$15\ \mathrm{km}$高度从赤道向极地运动的空气角动量守恒。它的向东速度在哪个纬度达到$80\ \mathrm{m\,s^{-1}}$？
::: solution
绕自转轴的角动量为$M = (u + \Omega a\cos\phi)\,a\cos\phi$，其中$a\cos\phi$是到转轴的距离。在出发地$\phi_0$（此处$u = u_0$）与纬度$\phi$之间守恒，得

$$
u(\phi) = (u_0 + \Omega a\cos\phi_0)\,\frac{\cos\phi_0}{\cos\phi} - \Omega a\cos\phi .
$$

因此从赤道以$u_0 = 0$出发的空气有$u = \Omega a(\sec\phi - \cos\phi)$。令$u = 80\ \mathrm{m\,s^{-1}}$，$\Omega a = 465\ \mathrm{m\,s^{-1}}$：

$$
\sec\phi - \cos\phi = 0.172 \quad\Longrightarrow\quad \phi = 23^\circ .
$$

观测位于$25^\circ$–$30^\circ$的副热带急流核心与位于$20^\circ$–$35^\circ$的沙漠带，都从角动量守恒和能量平衡中在大致正确的纬度上"掉出来"——这是E. N.洛伦兹（Lorenz）的经典论证，其现代表述见Held与Hou的工作。注意无粘公式会一直增长（在$40^\circ$给出$180\ \mathrm{m\,s^{-1}}$），所以真实大气必定还做了别的事：中纬度涡旋把角动量*向赤道*输送，逆着梯度输送，而这种输送的辐合限制了环流圈并把极大值放在它所在的位置。真实的哈得来环流冬季伸到$25^\circ$–$30^\circ$，夏季到$15^\circ$，并随季节移动数度；在过去40年中其边缘已向极地移动了约每十年$1^\circ$，对风暴路径和干带都有影响（[[climate-change/observed-change]]）。
:::
:::

::: warning 科里奥利效应不决定你家浴缸的水往哪个方向转
浴缸的罗斯贝数极大：取$U \sim 0.5\ \mathrm{m\,s^{-1}}$、$L \sim 0.1\ \mathrm{m}$、$f = 10^{-4}\ \mathrm{s^{-1}}$，则$\mathrm{Ro} \sim 10^4$。放水涡旋的方向由盆的形状和注水方式决定，只有在精心控制的实验水槽中、静置数日后才能重现。旋转起作用的条件是大气中$L \gtrsim 10\ \mathrm{km}$、海洋中$L \gtrsim 1\ \mathrm{km}$——这就是它主宰天气系统、海流和流涡形状，却主宰不了水槽的原因。
:::

## 海洋：先是风生，然后密度驱动

::: definition 埃克曼输送 {#def-ekman}
风稳定吹拂海面时，会驱动一个厚约$50$–$100\ \mathrm{m}$的表面层，其中海流随深度转向（**埃克曼螺旋**）。该层积分的净输送为

$$
\mathbf{M}_E = \frac{\hat{\boldsymbol{\tau}}}{\rho f},
$$

在北半球指向风的右方$90^\circ$，在南半球指向左方$90^\circ$。
:::

::: proof
在定常、密度不随深度变化的情形下，混合层内水平动量平衡为摩擦力对科里奥利力：$f\,\mathbf{k}\times\mathbf{u} = \partial\boldsymbol{\tau}/\partial z/\rho$。从层底（应力为零）到海面（应力等于风应力$\boldsymbol{\tau}$）积分，得$f\,\mathbf{k}\times\mathbf{M}_E = \boldsymbol{\tau}/\rho$。两边与$\mathbf{k}$作叉积，并用$\mathbf{k}\times(\mathbf{k}\times\mathbf{M}) = -\mathbf{M}$，得$\mathbf{M}_E = \hat{\mathbf{k}}\times\boldsymbol{\tau}/(\rho f)$，它垂直于应力。假设条件是风定常、层内$f$为常数、无水平气压梯度、垂直涡粘系数均匀；在西边界流附近和强锋面上该结果只是近似。
:::

::: example 西岸的上升流 {#ex-upwelling}
$10\ \mathrm{m\,s^{-1}}$的南风作用于南纬$15^\circ$的秘鲁海岸。取拖曳系数$C_D = 1.5\times10^{-3}$、$\rho_a = 1.2\ \mathrm{kg\,m^{-3}}$。求埃克曼输送，以及若它在$100\ \mathrm{km}$宽的大陆架上被抽升时的上升速度。
::: solution
风应力$\tau = \rho_a C_D U^2 = 1.2\times1.5\times10^{-3}\times100 = 0.18\ \mathrm{Pa}$；海岸的典型值为$0.05$–$0.15\ \mathrm{Pa}$，故平均态取$\tau = 0.05\ \mathrm{Pa}$。于是

$$
M_E = \frac{\tau}{\rho f} = \frac{0.05}{1025\times3.78\times10^{-5}} = 1.29\ \mathrm{m^2\,s^{-1}},
$$

单位为每米海岸（南半球的符号使沿岸向东为陆的海岸上、南风造成离岸输送）。质量连续要求有水补充，于是

$$
w \approx \frac{M_E}{W} = \frac{1.29}{1\times10^{5}} = 1.3\times10^{-5}\ \mathrm{m\,s^{-1}} = 1.1\ \mathrm{m\,day^{-1}} .
$$

这正是沿岸上升流的量级，也是秘鲁、本格拉、加那利和加利福尼亚流系支撑世界大渔场的原因：每天$1\ \mathrm{m}$的深层冷水——富硝酸盐——在几百千米海岸上把表层水施肥。同样的埃克曼物理应用于整个热带大洋，就是把水送进和送出副热带流涡的机制。
:::
:::

大洋盆上的风应力旋度在各处驱动缓慢的深层向西流（**斯韦德鲁普平衡**），而它必须在狭窄快速的西边界流中返回——墨西哥湾流、黑潮、厄加勒斯流、巴西流。这就是流涡不对称的原因：西边界流宽$100\ \mathrm{km}$、流速$1$–$2\ \mathrm{m\,s^{-1}}$，而其东岸对应者（加利福尼亚流、加那利流、本格拉流）宽缓、缓慢并伴随上升流。

::: definition 温盐环流 {#def-thc}
**温盐环流**，或称**经向翻转环流**（MOC），是全球由密度驱动的翻转：表层水在北大西洋（拉布拉多海和北欧海）以及绕南极变得足够密而下沉，在深层扩散进入各大洋，并在印度洋和太平洋缓慢返回表层。它以**斯维德鲁普**计量，$1\ \mathrm{Sv} = 10^{6}\ \mathrm{m^3\,s^{-1}}$。
:::

::: example 温盐翻转环流输送了什么？ {#ex-moc}
RAPID-MOCHA观测阵在北大西洋$26.5^\circ\mathrm{N}$测得2004–2014年平均翻转$18.7 \pm 2.1\ \mathrm{Sv}$。若翻转在上$1000\ \mathrm{m}$向北的水比向南的深层流暖$10\ ^\circ\mathrm{C}$，估算热量输送。$20\ \mathrm{Sv}$每年更新多大体积的全球海洋？这对深层水的年龄意味着什么？
::: solution
热量输送$Q = \rho c_p \Psi \Delta T$：

$$
Q = 1025\ \mathrm{kg\,m^{-3}}\times 3990\ \mathrm{J\,kg^{-1}\,K^{-1}}\times 1.87\times10^{7}\ \mathrm{m^3\,s^{-1}}\times 10\ \mathrm{K} = 0.77\times10^{15}\ \mathrm{W} = 0.77\ \mathrm{PW}.
$$

已发表的$26^\circ\mathrm{N}$处估计为$0.6$–$0.8\ \mathrm{PW}$，可见这个简单计算是够用的。至于更新时标，$20\ \mathrm{Sv} = 6.3\times10^{5}\ \mathrm{km^3\,yr^{-1}}$，而全球海洋体积为$1.335\times10^{9}\ \mathrm{km^3}$：

$$
\tau = \frac{1.335\times10^{9}}{6.3\times10^{5}} = 2100\ \mathrm{yr}.
$$

这与深海太平洋水的放射性碳年龄（约$2000$年，经放射性衰变校正）同量级，这是海洋学中最令人满意的一致性之一：一个由系留观测阵列测得的数字与一个由贝壳中$^{14}\mathrm{C}$测得的数字相符。它也告诉了你深海对地表变化作出响应的时间尺度——几个世纪，而不是几十年。
:::
:::

- [ ] 因为大气中的科里奥利参数较小。
::: solution
两种流体的调整时间和垂直结构差别极大。大气的输送在副热带达到峰值，那里它自己的环流（哈得来环流和风暴路径）正在倾泻能量；海洋的输送在赤道附近和西边界流处最大。在赤道上两者其实互相抵消——海洋向北输送约$1.3\ \mathrm{PW}$，大气向南约$1\ \mathrm{PW}$——所以分工是真正的交接，而不是固定的比例。
:::
:::

::: warning "墨西哥湾流使英国温暖"只对了一半
北大西洋流——墨西哥湾流的延伸——确实向北输送热量，北大西洋确实是同纬度海洋中最暖的部分，这些都是真的。但说英国气候由它解释，即"没有它英国就会像拉布拉多"，则不成立。在大西洋翻转环流被关掉的模式试验中，西北欧变冷$3$–$8\ ^\circ\mathrm{C}$（IPCC AR6，2021年，第9章），这很大，但小于伦敦与拉布拉多之间约$10\ ^\circ\mathrm{C}$的差别；后者大部分来自平均西风带来的海洋气团、来自没有大陆冰盖、以及拉布拉多位于北冰洋下游这一事实。与此相关的说法——翻转环流可能"突然崩溃并使欧洲陷入新的冰期"——并不成立：AR6评估其在2100年前*极不可能*，而且即便完全崩溃也只是使该地区变冷，不会使之结冰。
:::

::: history
风为何这样吹的问题已有四个世纪的历史。哈雷（Halley）在1686年提出信风是流向热带上升区的回流；哈得来（Hadley）在1735年把这一想法定量化并考虑了地球自转，以他命名的环流圈是最古老的大气动力学模型。牛顿（Newton）的《原理》（1687年）给出了参考系；科里奥利（Coriolis）在1835年定义了偏转项；白贝罗（Buys Ballot）在1857年把它变成预报规则（"在北半球背风而立，低压在左"）。南森（Nansen）从1893年起在北极冰区观察"弗拉姆"号随冰右偏漂流却无法解释；瓦格纳·沃尔弗里德·埃克曼（Ekman），皮叶克尼斯（Bjerknes）卑尔根学派一名二十二岁的学生，在1902年用后来冠以其名的螺旋解决了这个问题。皮叶克尼斯1904年的宣言——天气可以通过求解方程来预报——以及1918–19年的极锋理论给了气象学概念机器。罗斯贝（Rossby）在1939年识别出行星波，查尔尼（Charney）在1947年证明这些波是不稳定的，这就是中纬度大气成为一台制造风暴的机器的原因。斯韦德鲁普（Stommel）在1948年用同一个$f$随纬度的变化解释了海流涡的不对称；布勒克尔（Broecker）在1991年画出了那幅著名的传送带图；自2004年起RAPID-MOCHA阵列直接测量它。
:::

## 由此通向何处

热量输送在一个方向上是[[earth-system/energy-balance]]的主题，在另一个方向上是[[climate-system/heat-transport]]的主题：前者问不平衡是什么，后者问环流如何回答它、以及这个回答可能如何改变。海洋吸收我们的热量和碳的作用在[[oceanography/wind-driven]]和[[earth-system/carbon-cycle]]中展开；这里勾勒的环流圈、急流与波的动力学在[[atmospheric-dynamics/equations-of-motion]]、[[atmospheric-dynamics/balanced-flow]]和[[atmospheric-dynamics/vorticity]]中认真处理。这些环流所搬运的水，就是下一章的主题。

::: summary
- 大气层顶在热带得热约$60\ \mathrm{W\,m^{-2}}$、在高纬失热约$100\ \mathrm{W\,m^{-2}}$；大气与海洋合计向极地输出约$6\ \mathrm{PW}$，峰值在北纬$35^\circ$附近。
- 旋转主导大尺度运动，判据是罗斯贝数；天气系统的$\mathrm{Ro} \sim 0.1$。地转使风沿等压线吹，$v_g \propto 1/f$。
- 热成风制造急流：$3000\ \mathrm{km}$上$25\ \mathrm{K}$的对比给出$20\ \mathrm{m\,s^{-1}}$的急流，所以急流就是化为风的温度对比。
- 角动量守恒把副热带急流和沙漠带放在约$30^\circ$；卫星记录中哈得来环流边缘以约每十年$1^\circ$向极地移动。
- 埃克曼输送$\mathbf{M}_E = \hat{\boldsymbol{\tau}}/(\rho f)$垂直于风；它驱动约$1\ \mathrm{m\,day^{-1}}$的沿岸上升流，从而造就了大渔场。
- 温盐翻转环流输送约$19\ \mathrm{Sv}$、约$0.8\ \mathrm{PW}$；这一更新速率意味着深海通风时标约两千年，与深层水的放射性碳年龄相符。
:::

## 习题

::: exercise 科里奥利参数 {level=1 check="1.32e-4"}
计算$65^\circ\mathrm{N}$的$f$。
::: solution
$f = 2\times7.292\times10^{-5}\times\sin 65^\circ = 1.458\times10^{-4}\times0.9063 = 1.32\times10^{-4}\ \mathrm{s^{-1}}$。
:::
:::

::: exercise 地转风 {level=1 check="5.6"}
在$50^\circ\mathrm{N}$，气压沿东向每$400\ \mathrm{km}$下降$3\ \mathrm{hPa}$。求地转风速（$\rho = 1.2\ \mathrm{kg\,m^{-3}}$）。
::: solution
$\partial p/\partial x = 300/4\times10^{5} = 7.5\times10^{-4}\ \mathrm{Pa\,m^{-1}}$，$f = 1.115\times10^{-4}\ \mathrm{s^{-1}}$，于是
$$
v_g = \frac{7.5\times10^{-4}}{1.2\times1.115\times10^{-4}} = 5.6\ \mathrm{m\,s^{-1}}.
$$
风平行于东西向气压梯度吹，即南北向，低压在左。
:::
:::

::: exercise 罗斯贝数 {level=1 check="0.1"}
在$50^\circ\mathrm{N}$，$10\ \mathrm{m\,s^{-1}}$的风绕一个$1000\ \mathrm{km}$的低压旋转。求罗斯贝数并说明旋转是否重要。
::: solution
$\mathrm{Ro} = U/(fL) = 10/(1.115\times10^{-4}\times10^{6}) = 0.090$。$\mathrm{Ro} \ll 1$，旋转占主导，流动近于地转——这就是地面气压图与高空风场看起来如此相似的原因。
:::
:::

::: exercise 埃克曼输送 {level=2 check="0.95"}
$0.1\ \mathrm{Pa}$的风应力作用在$45^\circ\mathrm{N}$的海面上。求埃克曼输送（$\mathrm{m^2\,s^{-1}}$，$\rho = 1025\ \mathrm{kg\,m^{-3}}$）。
::: solution
$M_E = \tau/(\rho f) = 0.1/(1025\times1.03\times10^{-4}) = 0.95\ \mathrm{m^2\,s^{-1}}$，每米宽度，方向在风的右方$90^\circ$。
:::
:::

::: exercise 角动量与信风 {level=2}
$10\ \mathrm{km}$高度的空气从$30^\circ$出发（相对地转风为零）向赤道运动，角动量守恒。求它在$10^\circ$的纬向风。是东风还是西风？
::: solution
用$u = (u_0 + \Omega a\cos\phi_0)\cos\phi_0/\cos\phi - \Omega a\cos\phi$，其中$u_0 = 0$、$\phi_0 = 30^\circ$、$\phi = 10^\circ$：
$$
u = 465\left(\frac{0.866^2}{0.985} - 0.985\right) = 465(0.762 - 0.985) = -104\ \mathrm{m\,s^{-1}}.
$$
负号表示相对地面向西：从副热带向赤道运动的空气被自转更快的热带"甩在后面"，这正是信风的方向。观测到的东风弱得多（$10\ \mathrm{m\,s^{-1}}$），因为摩擦和涡旋把角动量又输送了回去。
:::
:::

::: exercise 海流输送的热量 {level=2 check="0.33"}
墨西哥湾流在$35^\circ\mathrm{N}$输送$80\ \mathrm{Sv}$，两侧温度差$10\ ^\circ\mathrm{C}$。估算其热量输送（$\mathrm{PW}$）。
::: solution
$Q = \rho c_p \Psi\Delta T = 1025\times3990\times8\times10^{7}\times10 = 3.3\times10^{14}\ \mathrm{W} = 0.33\ \mathrm{PW}$。墨西哥湾流热输送的估计为$0.3$–$0.6\ \mathrm{PW}$；注意对一条海流来说这是个大数字，却只占$35^\circ\mathrm{N}$上总输送的一小部分——后者大部分由大气承担。
:::
:::

::: exercise 两种流体之间的交接 {level=2}
在$30^\circ\mathrm{N}$上大气向北输送$2.5\ \mathrm{PW}$，海洋$1.3\ \mathrm{PW}$。若$30^\circ\mathrm{N}$到$60^\circ\mathrm{N}$之间的辐射盈余平均为$35\ \mathrm{W\,m^{-2}}$，输送是否自洽？（纬度带面积：$2\pi a^2[\sin 60^\circ - \sin 30^\circ]$。）
::: solution
带面积$= 2\pi(6.371\times10^{6})^2(0.866 - 0.5) = 2.57\times10^{14}\times0.366 = 9.4\times10^{13}\ \mathrm{m^2}$。盈余$= 35\times9.4\times10^{13} = 3.3\ \mathrm{PW}$，它必须等于输送的*散度*，即$F(30^\circ\mathrm{N}) - F(60^\circ\mathrm{N})$。取$F(30^\circ\mathrm{N}) = 3.8\ \mathrm{PW}$，则要求$F(60^\circ\mathrm{N}) = 0.5\ \mathrm{PW}$——而输送在高纬确实降到接近零，那里海洋自身的深西边界流和极地环流接过了工作。在十分之几拍瓦的不确定度内，这些数字是自洽的。
:::
:::

::: exercise 上升流与营养盐供给 {level=3}
用[[#ex-upwelling]]的结果，取$w = 1.1\ \mathrm{m\,day^{-1}}$，作用在$100\ \mathrm{km}$宽、$50\ \mathrm{m}$深的上升流区，硝酸盐$20\ \mathrm{mmol\,m^{-3}}$，而表层几乎为零。求硝酸盐供给速率，以及在雷德菲尔德计量比（$\mathrm{C}:\mathrm{N} = 106:16$）下所能支撑的初级生产。
::: solution
每米海岸每秒供给的水体积：$M_E = 1.29\ \mathrm{m^2\,s^{-1}}$。每米海岸的硝酸盐供给：
$$
1.29\ \mathrm{m^2\,s^{-1}}\times20\ \mathrm{mmol\,m^{-3}} = 25.8\ \mathrm{mmol\,m^{-1}\,s^{-1}} .
$$

按上升流区单位面积计，即$w\times[\mathrm{NO_3}] = 1.27\times10^{-5}\ \mathrm{m\,s^{-1}}\times20 = 2.5\times10^{-4}\ \mathrm{mmol\,m^{-2}\,s^{-1}} = 22\ \mathrm{mmol\,N\,m^{-2}\,d^{-1}}$。按$\mathrm{C}:\mathrm{N} = 106{:}16$，固定的碳为$22\times106/16 = 144\ \mathrm{mmol\,C\,m^{-2}\,d^{-1}} = 1.7\ \mathrm{g\,C\,m^{-2}\,d^{-1}}$。

这比全球海洋平均（$0.3$–$0.5\ \mathrm{g\,C\,m^{-2}\,d^{-1}}$）高一个量级，与东边界上升流系统的观测值相符。这就是为什么百分之几的海洋表面支撑了世界渔获的大部分，也是为什么这些系统对变暖敏感：变暖加强层结、减少营养盐通量（[[oceanography/productivity]]）。
:::
:::

::: exercise 扩散闭合方案 {level=3}
热输送的常见玩具模型写作$F = -K\,\mathrm{d}\bar T/\mathrm{d}\phi / a$。取观测$F = 6\ \mathrm{PW}$（在$35^\circ\mathrm{N}$）、地表温度南北梯度每纬度$1.2\ \mathrm{K}$，估算涡旋扩散系数$K$（单位$\mathrm{m^2\,s^{-1}}$，把输送视为发生在$10\ \mathrm{km}$厚、密度$1\ \mathrm{kg\,m^{-3}}$的整层大气中）。
::: solution
梯度换算成SI单位是$1.2\ \mathrm{K}$每$111\ \mathrm{km} = 1.08\times10^{-5}\ \mathrm{K\,m^{-1}}$。沿纬圈单位长度的输送为$F/(2\pi a\cos\phi) = 6\times10^{15}/(2\pi\times6.371\times10^{6}\times0.819) = 1.83\times10^{8}\ \mathrm{W\,m^{-1}}$。写作$F_\text{width} = \rho c_p K D\,\mathrm{d}T/\mathrm{d}y$，取$D = 10^{4}\ \mathrm{m}$、$c_p = 1004\ \mathrm{J\,kg^{-1}\,K^{-1}}$，
$$
K = \frac{1.83\times10^{8}}{1\times1004\times10^{4}\times1.08\times10^{-5}} = 1.7\times10^{6}\ \mathrm{m^2\,s^{-1}} .
$$
这就是标准结果：所需的扩散系数约$10^{6}\ \mathrm{m^2\,s^{-1}}$，是分子值的千倍，与最大的大气涡旋相当（$\sim u'\ell \approx 20\ \mathrm{m\,s^{-1}}\times10^{5}\ \mathrm{m} = 2\times10^{6}$）。因此这个闭合方案说对了也说错了：对的是风暴就是混合介质；错的是扩散律无法表现真实大气近乎无粘、由波驱动的输送，因而会把对气候变化响应的答案算错。
:::
:::

::: exercise 更暖的世界，更弱的对比 {level=3}
北极放大使赤道-极地地表温度对比减小。若$3000\ \mathrm{km}$上的$\Delta T$从$25\ \mathrm{K}$降到$21\ \mathrm{K}$，[[#ex-jet]]的热成风估算给出怎样的急流风速？你会预期哪三个可观测的变化随之发生？
::: solution
急流与温度对比成正比，故$21\times(21/25) = 17.6\ \mathrm{m\,s^{-1}}$，而原为$21\ \mathrm{m\,s^{-1}}$：减弱$16\%$。预期的后果（每一个都正在用观测检验）：(i) 平均西风减弱，风暴穿越大西洋和太平洋的移动变慢；(ii) 风暴路径和副热带干带向极地移动，与观测到的哈得来环流加宽一致；(iii) 天气型更持久，因为平均流弱时阻塞和准共振响应更有利——这就是北极放大与中纬度极端事件之间联系（仍有争议）背后的物理想法。注意地表对比不是全部：急流由**对流层上层**的对比决定，而该对比受温室气体增暖不同垂直结构的影响，模式对急流未来趋势的估计仍有分歧。
:::
