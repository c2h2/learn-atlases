这只杯子里的水曾经被喝过——被一条泥盆纪的鱼喝过，被一头在白垩纪湖边饮水的蜥脚类恐龙喝过，并且按某种比例被每一个活过的人喝过。地球的水是一个封闭的记账系统：总共约$1.386\times10^{9}\ \mathrm{km^3}$，在海洋、空气、冰、土壤、岩石和生物组织之间循环，从内部加入的几乎没有，散失到太空的也几乎没有。不封闭的是**分布**。这些水中$97.5\%$是咸水，$1.75\%$封在冰里，$0.7\%$是地下水，而承载我们文明的河流、湖泊和大气加起来只约$0.04\%$——相对于行星，这层膜比橘子皮上的漆还薄。

分布的引擎是阳光：地表吸收的$240\ \mathrm{W\,m^{-2}}$中，约$80\ \mathrm{W\,m^{-2}}$（$35\%$）没有用于加热地面，而是用于蒸发水分，这是行星表面最大的一项能量用途。本章就是这台引擎的记账——水在哪里、有多少、移动多快、人类干预之后去了哪里，以及世界变暖时它会怎样。

## 全球水量平衡

::: definition 水量平衡 {#def-water-balance}
任何确定区域——全球、一个大洲、一个流域、一块田——的**水量平衡**是收支式
$$
P = E + T + Q + \Delta S,
$$
其中$P$为降水，$E$为自由水面和土壤蒸发，$T$为植物蒸腾（$E + T$合称**蒸散发**），$Q$为地表或地下净流出（对流域而言即径流），$\Delta S$为蓄量变化。单位用单位面积水深（$\mathrm{mm\,yr^{-1}}$）或体积（$\mathrm{km^3\,yr^{-1}}$）；$1\ \mathrm{km^3}$水即$1\ \mathrm{Gt}$。
:::

::: proposition 全球水量平衡的闭合 {#prop-closure}
对海洋和陆地分别而言，若十年以上时段内蓄量无变化，则
$$
P_\text{o} = E_\text{o} - R, \qquad P_\ell = E_\ell + R,
$$
其中$R$为陆地入海的河流（加地下）径流。因此$R = E_\text{o} - P_\text{o}$：海洋蒸发必须大于其降水，而多出的部分恰好到达陆地。
:::

::: proof
海洋的输入只有降水和河流注入，输出只有蒸发；陆地的输入只有降水，输出是蒸散发和径流。对两者令$\mathrm{d}S/\mathrm{d}t = 0$即得两式。两式相加得$P_\text{o} + P_\ell = E_\text{o} + E_\ell$，即全球闭合。该论证假定冰盖和地下水没有长期趋势——而这一点已不再成立：GRACE和GRACE-FO卫星现已直接测得陆地冰和地下水每年$10^{2}$–$10^{3}\ \mathrm{Gt}$的损失。
:::

| 通量（$10^3\ \mathrm{km^3\,yr^{-1}}$） | 海洋 | 陆地 | 全球 |
|---|---|---|---|
| 降水 | 373 | 119 | 492 |
| 蒸发加蒸腾 | 413 | 73 | 486 |
| 入海径流 | $+40$ | $-45$ | — |

（什克洛马诺夫的全球水量平衡；$3\times10^{3}\ \mathrm{km^3\,yr^{-1}}$的差值是这套数据集经典的闭合误差。）因此全球平均降水为$492{,}000/5.10\times10^{8} = 965\ \mathrm{mm\,yr^{-1}}$，其中$700\ \mathrm{mm}$落在海洋，$265\ \mathrm{mm}$落在陆地。

::: example 大气一年周转四十次 {#ex-turnover}
大气持有$12{,}700\ \mathrm{Gt}$水汽，全球降水为$492{,}000\ \mathrm{Gt\,yr^{-1}}$。求滞留时间和平均可降水量。大气占水的份额与它占**流量**的份额相比如何？
::: solution
$$
\tau = \frac{12{,}700}{492{,}000} = 0.0258\ \mathrm{yr} = 9.4\ \mathrm{days},
$$

即大气储库每年被清空并重新充满约$39$次。平均可降水量为$12{,}700\ \mathrm{km^3}/5.10\times10^{8}\ \mathrm{km^2} = 24.9\ \mathrm{mm}$——这是全球平均，从寒冷沙漠和南极高原的不足$5\ \mathrm{mm}$到西太平洋暖池的$65\ \mathrm{mm}$不等。

这个比较正是要点：大气只占地球水的$0.001\%$，却承担了穿过它的年流量的$3.5\%$，因此它的周转比海洋快$3500$倍。关于天气的一切——它的猛烈、它的迅速、一场风暴一天能下完一个月的雨——都源于一个很小的储库和一个很大的通量。
:::
:::

## 雨落到地上之后

::: definition 径流系数与干旱极限 {#def-runoff}
流域的**径流系数**$C = Q/P$，即降水以河川径流流出的比例。在长时间尺度上，水分限制（干旱）流域$C \to 0$，因为植物和蒸发几乎取走一切；能量限制（湿润）流域则$C \to 1 - E_0/P$，其中$E_0$为潜在蒸散发。
:::

::: example 一个流域的收支 {#ex-catchment}
某$2{,}000\ \mathrm{km^2}$流域降水$900\ \mathrm{mm\,yr^{-1}}$，平均流量$12\ \mathrm{m^3\,s^{-1}}$。求蒸散发（$\mathrm{mm\,yr^{-1}}$）和径流系数。若灌溉引走$30\%$的流量，其中$60\%$被消耗（在田间蒸发），到达河口的流量减少多少？
::: solution
径流深度：$12\ \mathrm{m^3\,s^{-1}}\times3.156\times10^{7}\ \mathrm{s\,yr^{-1}} = 3.79\times10^{8}\ \mathrm{m^3}$，除以$2.0\times10^{9}\ \mathrm{m^2}$得$189\ \mathrm{mm\,yr^{-1}}$。于是
$$
E + T = P - Q = 900 - 189 = 711\ \mathrm{mm\,yr^{-1}}, \qquad C = \frac{189}{900} = 0.21 .
$$

这是一个典型的温带植被流域：五分之四的雨水回到大气，主要通过植物。至于引水，$12\ \mathrm{m^3\,s^{-1}}$的$30\%$是$3.6\ \mathrm{m^3\,s^{-1}}$，其中$60\%$（$2.2\ \mathrm{m^3\,s^{-1}}$）不再以径流返回。河口流量从$12$降到$9.8\ \mathrm{m^3\,s^{-1}}$，减少$19\%$；而且减少集中在取水最多的枯水期——这就是为什么"平均流量没变"和"河还流到海里"两句话都可能与一条已经停止功能的河流并存。
:::
:::

::: definition 降水回收率 {#def-recycling}
**回收率**$\rho$是某区域的降水中来自该区域自身蒸散发的比例。全球陆地平均$\rho \approx 0.33$；亚马逊流域随季节和数据集不同为$0.25$–$0.50$；撒哈拉接近$0.1$。
:::

回收率是把毁林变成一个水文问题的数字。落在内陆的雨平均三分之一来自本地、三分之二来自海洋，但本地份额是沿气流轨迹逐步累积的：一团穿越亚马逊的空气，接收的是被森林蒸发过一次、两次、三次的水。移除森林就移除了这道级联的前几级，因此下风向的降水减少数倍于本地效应。在亚马逊，对大规模毁林的模式研究发现旱季区域降水减少$10$–$40\%$，而森林-降水反馈的符号取决于移除多少（[[hydrology/precipitation-evaporation]]）。

::: example 海洋的水能深入内陆多远？ {#ex-continental}
$25\ ^\circ\mathrm{C}$、相对湿度$90\%$的空气向内陆移动并逐渐被雨除。以有效同位素分馏作为雨除的代理：$\delta = \delta_0 + \epsilon\ln f$，其中$f$为剩余水汽分数，对$\delta^{18}\mathrm{O}$取$\epsilon \approx -10$‰。求$\delta$从$0$‰（海水汽）降到$-25$‰（中纬度大陆降水的典型值）时的$f$。
::: solution
$$
\ln f = \frac{\delta - \delta_0}{\epsilon} = \frac{-25}{-10} = 2.5 \quad\Longrightarrow\quad f = e^{-2.5} = 0.082 .
$$

原来的水汽只剩$8\%$：空气在深入途中已失去$92\%$的水。这就是大陆内部干旱的原因；这就是降水$\delta^{18}\mathrm{O}$每升高$100\ \mathrm{m}$下降$0.2$–$0.3$‰（**高度效应**）、每降低$1\ ^\circ\mathrm{C}$下降$0.5$‰（**温度效应**，冰芯古温度计的基础，见[[palaeoclimate/ice-cores]]）的原因；也是最内陆盆地含盐的原因——来的水只能蒸发，盐留下了。
:::
:::

## 慢储库

::: proposition 海平面当量 {#prop-sle}
融化陆地上的体积为$V_\text{ice}$的冰，全球平均海面上升
$$
\Delta h = \frac{\rho_\text{ice}}{\rho_\text{w}}\frac{V_\text{ice}}{A_\text{ocean}},
$$
其中$\rho_\text{ice} \approx 917\ \mathrm{kg\,m^{-3}}$、$\rho_\text{w} = 1028\ \mathrm{kg\,m^{-3}}$、$A_\text{ocean} = 3.62\times10^{8}\ \mathrm{km^2}$。漂浮的冰——冰架和海冰——不贡献海平面，因为它们已经排开了等于自身融水体积的水（阿基米德）。
:::

::: proof
融水体积为$V_\text{w} = (\rho_\text{ice}/\rho_\text{w})V_\text{ice}$，铺在海洋面积上。对质量为$m$的浮冰，其排开水的体积为$m/\rho_\text{w}$，恰等于融水所占体积，故水位不变。推论很重要：北极海冰的消失作为气候信号无论多么令人警觉，本身并不抬升海平面；而格陵兰陆上冰盖的消失则逐米抬升。
:::

::: example 冰柜里的冰 {#ex-sle}
格陵兰冰盖含冰$2.85\times10^{6}\ \mathrm{km^3}$，南极冰盖$2.65\times10^{7}\ \mathrm{km^3}$，其中约$2.3\times10^{7}\ \mathrm{km^3}$位于基岩之上（接地冰）。求各自的海平面当量。
::: solution
格陵兰：
$$
\Delta h = \frac{917}{1028}\times\frac{2.85\times10^{6}}{3.62\times10^{8}} = 0.892\times7.87\times10^{-3}\ \mathrm{km} = 7.0\ \mathrm{m},
$$

用最新的体积估计通常记作$7.4\ \mathrm{m}$。南极（只计接地冰）：$0.892\times2.3\times10^{7}/3.62\times10^{8} = 57\ \mathrm{m}$，通常记作$58\ \mathrm{m}$。山地冰川和小冰帽合计约$0.4\ \mathrm{m}$。

把这些数字与观测到的2006–2015年$3.7\ \mathrm{mm\,yr^{-1}}$的海平面上升（IPCC AR6，2021年；据世界气象组织《全球气候状况》报告，2013–2022年加速到约$4.6\ \mathrm{mm\,yr^{-1}}$）放在一起，问题的尺度就清楚了：按当前速率，用完格陵兰当量需要约两百万年，但重要的是**速率**，因为每十年几十毫米就决定了有多少人、多少海岸线暴露在风险之中。
:::
:::

::: warning "水只有$2.5\%$是淡水，所以水稀缺"把稀缺这件事说错了两次
第一，那$2.5\%$大多不可用：$10.53\times10^{6}\ \mathrm{km^3}$淡地下水中，很多是半咸水或埋深太深、抽水不经济；而"地表淡水"的$69\%$在冰盖里，实际上是不可动的。第二，真正要紧的稀缺不是全球性的，而是季节性和地方性的。地球并不缺水；缺的是某些河流、某些含水层、某些月份。尼罗河流域在枯水年取水量超过其平均年径流的$100\%$；华北平原和美国大平原含水层的地下水位下降了数十米，因为开采超过补给一个量级。地下水枯竭现在可以从太空测量：GRACE和GRACE-FO追踪到的全球陆地水损失以地下水为主，自1970年代以来地下水储量的评估枯竭量约为$10^{3}\ \mathrm{Gt}$且在加速（Jasechko等，2024年）。滞留时间$10^{3}$–$10^{4}$年的含水层在几十年内被抽空：这是采矿，不是农业。
:::

::: example 开采地下水 {#ex-groundwater}
某含水层面积$50{,}000\ \mathrm{km^2}$、孔隙度$0.15$、饱和厚度$100\ \mathrm{m}$，以$5\ \mathrm{km^3\,yr^{-1}}$开采，自然补给$1\ \mathrm{km^3\,yr^{-1}}$。求初始可采体积、按恒定开采量耗尽所需时间，以及给水度为$0.12$时水位下降速率。
::: solution
储量$= 5.0\times10^{4}\ \mathrm{km^2}\times0.1\ \mathrm{km}\times0.15 = 750\ \mathrm{km^3}$。净消耗$= 5 - 1 = 4\ \mathrm{km^3\,yr^{-1}}$，故$750/4 = 190$年耗尽——而且远在那之前，抽水成本和井的干涸就已使方案不可行。

水位下降速率为
$$
\frac{\mathrm{d}h}{\mathrm{d}t} = \frac{4\ \mathrm{km^3\,yr^{-1}}}{5.0\times10^{4}\ \mathrm{km^2}\times0.12} = 6.7\times10^{-4}\ \mathrm{km\,yr^{-1}} = 0.67\ \mathrm{m\,yr^{-1}},
$$

这正是许多灌溉平原的观测量级。伴生的地面沉降——水位下降后土体压密——可用卫星雷达干涉测量，在雅加达和墨西哥城等地已达每年数厘米，并永久破坏含水层的储水能力（[[remote-sensing/radar-lidar]]）。
:::
:::

## 水循环中的人

::: definition 取水、耗水与压力 {#def-withdrawal}
**取水量**是从水源取用的水量；**耗水量**是不返回水源的部分（主要是作物蒸腾和水库蒸发）。**水资源压力**以取水量占可再生水资源量的比例衡量：超过$40\%$通常称为受压，超过$100\%$则意味着由开采储量或食物中隐含的进口供水。
:::

全球淡水取水约$4{,}000\ \mathrm{km^3\,yr^{-1}}$，其中约$70\%$用于灌溉，$20\%$用于工业和能源，$10\%$为生活用水（FAO AQUASTAT，2020年代初数值）。这只占平均河川径流$45{,}000\ \mathrm{km^3\,yr^{-1}}$的$9\%$，这就是全球平均如此误导的原因：同样的水在错误的地方、错误的时间被取用，而真正要紧的是耗水而不是取水。

::: example 虚拟水 {#ex-virtual}
生产$1\ \mathrm{kg}$牛肉大约消耗$15{,}000\ \mathrm{L}$绿水和蓝水（土壤蓄水加灌溉水），$1\ \mathrm{kg}$小麦约$1{,}000$多升；数字随气候、生产体系以及是否计入饲料用水而有数倍之差。一个$200\ \mathrm{g}$的汉堡因此携带约$2{,}400\ \mathrm{L}$水。求出口$1\ \mathrm{Mt}$小麦"输出"的水量，并与一个$1000$万人口、人均$200\ \mathrm{L\,d^{-1}}$的城市年生活供水量比较。
::: solution
小麦：$10^{6}\ \mathrm{t}\times1300\ \mathrm{m^3\,t^{-1}} = 1.3\times10^{9}\ \mathrm{m^3} = 1.3\ \mathrm{km^3}$。
城市：$10^{7}\times200\ \mathrm{L\,d^{-1}} = 2\times10^{9}\ \mathrm{L\,d^{-1}} = 2.0\times10^{6}\ \mathrm{m^3\,d^{-1}}$，即$0.73\ \mathrm{km^3\,yr^{-1}}$。

所以一百万吨小麦携带的水接近一个大都市生活年用水量的两倍。这就是"虚拟水"贸易是真正的水文策略的原因——干旱的石油出口国实际上在从加拿大、乌克兰和阿根廷进口雨水——也是为什么膳食和能源作物的水足迹必须进入任何诚实的土地与水核算（[[earth-resources/groundwater-resources]]）。
:::
:::

::: widget plot
f: if(x<400, 0, 1 - 400/x)
x: 50, 2000

caption: 一个假想流域的径流系数随年降水量的变化，潜在蒸散发固定为$400\ \mathrm{mm\,yr^{-1}}$：低于该阈值时植物和蒸发取走一切、河流断流；高于它时盈余按$1 - E_0/P$增长。真实流域的拐角是圆的而不是尖的，因为土壤蓄水、深根可以延长旱季供水——但这个形状说明了为什么半干旱区降水减少$20\%$可使径流减少$50\%$，也说明了为什么预期的地中海和美国西南部变干，其水资源后果与降水变化本身完全不成比例。

::: quiz
某地区年平均降水不变，但最强降水日变强了$15\%$，其间的干旱期变长。对径流和供水最可能的影响是什么？
- [ ] 两者都改善，因为总水量相同。
- [x] 径流增加而供水变差，因为更多的水以土壤和水库无法容纳的暴雨形式到达。
- [ ] 两者都减少，因为蒸发增加。
- [ ] 没有变化，因为平均值不变。
::: solution
同样总量中有更大比例以超过下渗能力的速率到达，因此更多的水变成地表径流和山洪，进入土壤的水更少，两次暴雨之间可供植物和水井使用的水也更少。这正是观测到的"强化"格局——由克劳修斯-克拉珀龙对大气水汽的控制可知其热力学预期约为每开尔文$7\%$——也是为什么面向水的气候适应主要在蓄水、下渗和需求侧，而不在平均降水（[[climate-change/extremes]]）。
:::
:::

::: history
水循环的轮廓在能够测量任何环节之前就已被理解。1674年，佩罗（Perrault）出版《论泉水之源》，量算了塞纳河流域的降雨，证明降雨足以解释河流的水量——当时的人们相信河流由被压力推上地下的海水涌出，因此觉得这个结论荒谬。马略特（Mariotte）用流量测量重做了塞纳河的算术；哈雷（Halley）1687年在西班牙外海测量了海面蒸发，为地中海闭合了收支。道尔顿（Dalton）1802年的蒸发定律以及随后建立的气体定律给出了水汽的物理学。达西（Darcy）1856年在第戎砂滤池上做的柱实验，给出了至今支配地下水的定律（[[hydrology/aquifers-wells]]）。同位素让水循环变得可见：1961年确立了维也纳标准，克雷格（Craig）同年的全球大气水线把$\delta^{18}\mathrm{O}$和$\delta^2\mathrm{H}$变成了示踪剂，能指出雨从何处来、在什么温度下凝结。自2002年12月起，GRACE双星每月以重力称量地球每个流域的水量，地下水枯竭、冰盖损失和大陆的季节性水储量波动第一次可以被计数而不是估算。

## 由此通向何处

水循环是能量收支（[[earth-system/energy-balance]]）与碳循环（[[earth-system/carbon-cycle]]）相遇之处：蒸散发输送的能量比大气以热量形式输送的还多，同时它也决定陆地光合作用有多大比例受水分而非光照限制。各分量在[[hydrology/precipitation-evaporation]]、[[hydrology/soil-water]]、[[hydrology/runoff]]和[[hydrology/groundwater-flow]]中展开；冰冻圈储库在[[glaciology/mass-balance]]和[[glaciology/sea-ice]]；同位素在[[palaeoclimate/proxies]]；而关于人类管理的问题——那既是价值选择也是水的问题——见[[earth-resources/groundwater-resources]]和[[earth-resources/extraction-impacts]]。

::: summary
- 全球水量平衡闭合：$P_\text{o} = E_\text{o} - R$、$P_\ell = E_\ell + R$，$R \approx 40{,}000\ \mathrm{km^3\,yr^{-1}}$，全球平均降水$965\ \mathrm{mm\,yr^{-1}}$。
- 大气只有$24.9\ \mathrm{mm}$可降水量，却每$9.4$天周转一次——比海洋快$3500$倍——这就是天气又快又猛的原因。
- 蒸散发把陆地降水约五分之四送回大气；径流系数由干旱指数$P/E_0$决定。
- 陆地降水的三分之一由本地蒸散发回收，因此移除植被使下风向变干的程度超过本地效应。
- 逐步雨除使水汽降至$-25$‰时只剩$8\%$：同位素记录是一份"已经下掉了多少水"的流水账。
- 格陵兰的海平面当量为$7.4\ \mathrm{m}$，南极为$58\ \mathrm{m}$；漂浮的冰不贡献。
- 人类取水约$4{,}000\ \mathrm{km^3\,yr^{-1}}$，为径流的$9\%$，但消耗在错误的地方和季节，并以$10^{3}\ \mathrm{Gt}$且持续增加的规模开采地下水。
:::

## 习题

::: exercise 全球平均降水 {level=1 check="965"}
全球总降水为$492{,}000\ \mathrm{km^3\,yr^{-1}}$。已知地球表面积为$5.10\times10^{8}\ \mathrm{km^2}$，求全球平均降水（$\mathrm{mm\,yr^{-1}}$）。
::: solution
$492{,}000/5.10\times10^{8} = 9.65\times10^{-4}\ \mathrm{km} = 965\ \mathrm{mm\,yr^{-1}}$。
:::
:::

::: exercise 湖泊的滞留时间 {level=1 check="2"}
某湖体积$20\ \mathrm{km^3}$，河流注入$10\ \mathrm{km^3\,yr^{-1}}$，蒸发同样多。其滞留时间为多少年？
::: solution
$\tau = 20/10 = 2\ \mathrm{yr}$。注意这里的通量是流出之**和**；若注入的一半以出流离开、一半蒸发，$\tau$仍是$20/10$，但水的年龄分布会不同。
:::
:::

::: exercise 可降水量 {level=1 check="25"}
某地区大气含有$2.5\times10^{4}\ \mathrm{Gt}$水汽，面积$10^{6}\ \mathrm{km^2}$。求可降水量（mm）。
::: solution
$2.5\times10^{4}\ \mathrm{km^3}/10^{6}\ \mathrm{km^2} = 0.025\ \mathrm{km} = 25\ \mathrm{mm}$。若一场暴雨下掉其中$40\%$，雨量为$10\ \mathrm{mm}$——这提醒我们，即使一场大暴雨也需要其上空空气的反复补充。
:::
:::

::: exercise 流域平衡 {level=2 check="0.32"}
某流域面积$5{,}000\ \mathrm{km^2}$，降水$700\ \mathrm{mm\,yr^{-1}}$，流量$35\ \mathrm{m^3\,s^{-1}}$。求径流系数。
::: solution
$Q = 35\times3.156\times10^{7} = 1.10\times10^{9}\ \mathrm{m^3\,yr^{-1}}$，除以$5.0\times10^{9}\ \mathrm{m^2}$得$221\ \mathrm{mm\,yr^{-1}}$。于是$C = 221/700 = 0.32$，蒸散发为$479\ \mathrm{mm\,yr^{-1}}$。
:::
:::

::: exercise 冰川的海平面当量 {level=2 check="74"}
山地冰体$30{,}000\ \mathrm{km^3}$完全融化。全球平均海平面上升多少毫米（$A_\text{ocean} = 3.62\times10^{8}\ \mathrm{km^2}$）？
::: solution
$\Delta h = (917/1028)\times3.0\times10^{4}/3.62\times10^{8} = 7.4\times10^{-5}\ \mathrm{km} = 74\ \mathrm{mm}$。作为对比，整个格陵兰冰盖是$7.4\ \mathrm{m}$——是这里的千倍；而本世纪观测到的上升为$3.7$–$4.6\ \mathrm{mm\,yr^{-1}}$。
:::
:::

::: exercise 回收率 {level=2}
某大陆降水$600\ \mathrm{mm\,yr^{-1}}$，蒸散发$400\ \mathrm{mm\,yr^{-1}}$，其中三分之一源自本大陆。求回收率和水汽净输入。
::: solution
回收率$\rho = (400/3)/600 = 0.22$。水汽输入$= 600 - 133 = 467\ \mathrm{mm\,yr^{-1}}$；径流$= 600 - 400 = 200\ \mathrm{mm\,yr^{-1}}$，它必须等于大气净输出的水量（流出的空气带走$267$，故净输出$467 - 267 = 200$）。若移除植被使蒸散发减少$25\%$，本地回收减少$33\ \mathrm{mm\,yr^{-1}}$；按回收率$0.22$，在其他条件不变的极端情形下下风向降水约减少$33/0.22 \approx 150\ \mathrm{mm\,yr^{-1}}$——这是一个上界，但足以说明杠杆有多大。
:::
:::

::: exercise 同位素与高度 {level=2 check="0.30"}
用$\delta = \delta_0 + \epsilon\ln f$、$\epsilon = -10$‰，求$\delta$从$-2$‰降到$-14$‰时剩余的水汽分数。
::: solution
$\ln f = (-14 + 2)/(-10) = 1.2$，故$f = e^{-1.2} = 0.30$。约$70\%$的水汽已经落下——这就是为什么山地积雪（由已失去大部分水的空气形成）的$^{18}\mathrm{O}$如此亏损。
:::
:::

::: exercise 大气中的水 {level=3}
全球平均可降水量为$24.9\ \mathrm{mm}$，气候系统的降水效率可写作$P = \rho\, E_\ell + M_\text{o}$，其中$M_\text{o}$为海洋水汽向陆地的输入。用全球水量平衡的数值求$M_\text{o}$，以及一个水分子从海洋蒸发到陆地降落的平均旅程时间。
::: solution
陆地降水$119\times10^{3}\ \mathrm{km^3\,yr^{-1}}$，其中$1/3$是本地蒸散发回收（$40\times10^{3}$），故海洋供给$M_\text{o} = 79\times10^{3}\ \mathrm{km^3\,yr^{-1}}$。大气储量为$12.7\times10^{3}\ \mathrm{km^3}$，因此蒸发到降水之间的平均时间为$12.7/492 = 0.026\ \mathrm{yr} = 9.4\ \mathrm{d}$，与降落地点无关；但一个将要落在陆地上的分子，平均要被蒸发、输送、降落若干次才被"用上"，这正是回收率所表达的内容。
:::
:::

::: exercise 变暖的水循环 {level=3}
比湿随地表增暖每度上升$7\%$。若全球降水每度增加$2\%$，大气水汽**通量**辐合必须改变多少倍？这对最强降水日的强度意味着什么？
::: solution
陆地降水由水汽通量辐合平衡。若整层水汽每度上升$7\%$而降水只增加$2\%$，环流（通量中由风驱动的部分）必须每度减弱约$5\%$——即热带环流的"减慢"。然而最强的日降水更密切地随暴雨前后数小时可用的水汽而定，因此其增幅更接近每度$5$–$7\%$（IPCC AR6，2021年，第11章对极端降水增加给出*高信度*）。这个表面上的矛盾——一个更湿的世界、更慢的平均环流、更猛烈的暴雨——是本章最有用的结果之一。
:::
:::

::: exercise 虚拟水与粮食政策 {level=3}
某国有人口$8000$万，进口小麦$8\ \mathrm{Mt}$、牛肉$1\ \mathrm{Mt}$。取小麦水足迹$1.3\ \mathrm{m^3\,kg^{-1}}$、牛肉$15\ \mathrm{m^3\,kg^{-1}}$，全国取水$80\ \mathrm{km^3\,yr^{-1}}$，求进口隐含的虚拟水及其占全国取水的比例。
::: solution
小麦：$8\times10^{9}\ \mathrm{kg}\times1.3 = 1.04\times10^{10}\ \mathrm{m^3} = 10.4\ \mathrm{km^3}$。
牛肉：$1\times10^{9}\ \mathrm{kg}\times15 = 1.5\times10^{10}\ \mathrm{m^3} = 15\ \mathrm{km^3}$。
合计$25\ \mathrm{km^3}$，占全国取水$80\ \mathrm{km^3}$的$31\%$。

两点教训。第一，少量动物产品的贸易可以隐含一个国家水资源的很大份额。第二，这套算术的精度取决于水足迹本身，而水足迹随降水、灌溉效率以及是否计入绿水（作物本来也会蒸腾掉的水）而有数倍之差——因此应把这类数字当作量级看待，并说明这一点。
:::
