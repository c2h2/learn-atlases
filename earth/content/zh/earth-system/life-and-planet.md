生命占地球质量的$0.0001\%$，却管理着地球表面。一层几米厚的生物，靠阳光，在二十五亿多年里：把大气氧从痕量提高到空气的五分之一，建造了涵养陆地水分的土壤，向海洋深处输送的碳比整个显生宙的岩石还多，触发了终结古生代温室的冰川，并且——按最近三个世纪的算术——制造了一次碳扰动，其速率是地质记录五千六百万年来所未见的。

本章不写它的奇妙，而写它的机制：一个没有中枢、没有远见的生物系统如何可测量地改变行星化学，为什么这些变化伴随反馈，以及数字对当下这一刻说了什么。

## 生命遵守的规则

::: definition 初级生产力 {#def-production}
**总初级生产力**（GPP）是光合作用固定的碳总量，全球约$125\ \mathrm{GtC\,yr^{-1}}$，其中约一半在陆地。**净初级生产力**（NPP）是生产者自身呼吸之后剩下的部分，约$60\ \mathrm{GtC\,yr^{-1}}$：可供生物圈其余部分使用的量。整个系统的效率很低——光合作用只利用到达叶片的光合有效辐射的$0.5$–$2\%$，理论上限接近$11\%$。
:::

::: definition 雷德菲尔德比 {#def-redfield}
海洋浮游植物平均元素比为$\mathrm{C}:\mathrm{N}:\mathrm{P} = 106:16:1$（原子数），硅藻另需硅，所有生物都需铁。由于下沉物质分解时深海恰好按这一比例累积营养盐，该比例可把海洋任何一处硝酸盐或磷酸盐的测量，换算成这团水还能生长多少碳、以及已经输出多少碳。
:::

::: definition 生物泵 {#def-pump}
**软组织泵**是碳随下沉有机质向海洋内部输送并在深处呼吸的过程。穿过$100\ \mathrm{m}$的输出约$11\ \mathrm{GtC\,yr^{-1}}$；沉积物埋藏$0.1$–$0.2\ \mathrm{GtC\,yr^{-1}}$，效率$1$–$2\%$。**碳酸盐（硬组织）泵**以$\mathrm{CaCO_3}$形式输出碳，短期内起的是相反作用：钙化释放$\mathrm{CO_2}$（$\mathrm{Ca^{2+}} + 2\mathrm{HCO_3^-} \to \mathrm{CaCO_3} + \mathrm{CO_2} + \mathrm{H_2O}$）并埋藏碱度。
:::

::: proposition 氧是埋藏的记录 {#prop-oxygen}
光合作用与呼吸作用平衡到百分之一以内，因此无论光合多强都无法提高大气氧。只有其产物中有一部分有机碳逃脱氧化才行：
$$
\frac{\mathrm{d}\mathrm{O_2}}{\mathrm{d}t} = \text{有机碳埋藏} - \text{还原性火山与风化汇}.
$$
因此大气氧是一份"没有烂掉的碳"的账本。
:::

::: proof
固定一摩尔碳释放一摩尔$\mathrm{O_2}$；腐烂它消耗同样多。因此净通量就是埋藏速率。现代有机碳埋藏通量为$0.1$–$0.2\ \mathrm{GtC\,yr^{-1}}$，而汇项——$\mathrm{H_2}$、$\mathrm{H_2S}$等还原性火山气体，以及$\mathrm{Fe^{2+}}$和地壳硫化物的氧化——量级相当，这就是为什么氧的收支如此紧，也是为什么元古宙和古生代那两次大跃升要求埋藏以现代数倍的速率持续数千万年，而且要在能保存有机质的盆地（缺氧陆棚、白垩纪洋壳高原体系）中进行。
:::

::: example 我们能烧掉多少氧？ {#ex-oxygen}
大气含$\mathrm{O_2}$ $1.2\times10^{6}\ \mathrm{Gt}$、$\mathrm{CO_2}$ $890\ \mathrm{GtC}$。若把约$1100\ \mathrm{GtC}$的化石燃料储量全部烧掉，会消耗百分之几的氧？这种下降可测吗？
::: solution
碳燃烧每摩尔碳消耗一摩尔$\mathrm{O_2}$：$1100\ \mathrm{GtC} = 9.2\times10^{16}\ \mathrm{mol}$，而氧储量为$3.7\times10^{19}\ \mathrm{mol}$。下降$0.25\%$——肉眼不可见，但可测，因为空气的$\mathrm{O_2}/\mathrm{N_2}$比可用干涉法测定到十亿分之几。自1989年以来大气氧含量约以$7\times10^{14}\ \mathrm{mol\,yr^{-1}}$下降，与化石燃料消耗所隐含的值在误差范围内一致；这是对排放清单的独立确认，也确认了陆地与海洋的汇并不把氧还回来。
:::
:::

## 生命在大气上做过的大实验

::: definition 硫同位素质量无关分馏 {#def-mifs}
缺氧大气中$\mathrm{SO_2}$的紫外光解会产生硫同位素异常（$\Delta^{33}\mathrm{S} \ne 0$），并被沉积物保存。一旦存在臭氧层，紫外在高处被吸收，该途径关闭，$\Delta^{33}\mathrm{S}$归零。岩石中的$\Delta^{33}\mathrm{S}$信号因此是对"无氧大气"的直接、机制特定的检验。
:::

该信号存在于约$24.5$亿年前的岩石中，而在所有更年轻的岩石中缺失。仅这一项观测就为大氧化事件定了年、把它与地表环境的不可逆氧化联系起来，并解释了为什么需要海水溶解$\mathrm{Fe^{2+}}$的条带状铁建造在同一层位从记录中消失。此后九亿年的"无聊十亿年"里，氧可能只有现代水平的百分之一到十分之一；需要靠氧才能维持低浓度下的大体型动物，只能等待。

::: example 氧、火与登陆 {#ex-fire}
木炭只在陆地植物出现之后才出现在岩石记录中，即中志留世、约$4.3$亿年前。火需要氧的阈值：体积氧低于约$15\%$时地表火无法蔓延。由碳循环模式与化石植物、木炭记录重建的显生宙氧曲线，从早古生代中期的约$15\%$到石炭纪最晚期和二叠纪最早的$30$–$35\%$。
::: solution
氧曲线与木炭丰度的相关是地质记录中最紧密的耦合之一：氧越多，火越多，木炭越多。晚古生代的峰值与巨大的煤沼泽同期——广袤的泥炭堆积，正是[[#prop-oxygen]]论证所要求的"不完全腐烂"——也与第一批广布的干旱带和史上最大的昆虫同期，后者气管系统随氧分压的变化而有利地缩放。它还与全球变冷进入晚古生代冰期同期，因为释放氧的同一批有机碳埋藏也移除了$\mathrm{CO_2}$。

这个教训可以推广。生命不只是响应古生代气候；它改变了行星的可燃性、侵蚀速率、风化速率和二氧化碳，而气候作出了回应。
:::
:::

::: definition 生物扰动与农艺革命 {#def-bioturbation}
掘穴动物以有效扩散系数$K \sim 1$–$10\ \mathrm{cm^2\,yr^{-1}}$混合沉积物，因此混合层深度按$\sqrt{Kt}$增长：十年几厘米，千年几十厘米。生物扰动破坏纹层、给海底供氧、通过胶结或松散颗粒改变侵蚀速率——而在它演化出来之前，这些都不发生。寒武纪早期深掘穴的出现被称为**农艺革命**，因为它把二维的海底变成了三维生境，终结了微生物席的统治。
:::

::: example 用扩散方程读一段沉积 {#ex-bioturb}
在某海底$K = 4\ \mathrm{cm^2\,yr^{-1}}$，一层火山灰沉积下来。峰值浓度降到原来一半需要多久？混合层有多厚？
::: solution
瞬时薄源按$c(z,t) \propto \exp(-z^2/4Kt)$扩散，其峰值按$1/\sqrt{4\pi Kt}$下降，$1/e$宽度为$2\sqrt{Kt}$。峰值减半要求$4\pi Kt$增长四倍，即时间取参考值的四倍；一般地，时间每增加四倍峰值再减半。$1000$年后的混合厚度为
$$
2\sqrt{Kt} = 2\sqrt{4\times1000} = 126\ \mathrm{cm},
$$
比多数真实混合层更深，因为掘穴深度受挖掘能耗和氧的限制；观测混合层为$5$–$30\ \mathrm{cm}$。

实际后果是生物扰动设定了沉积记录的时间分辨率。一场风暴事件可以在几小时内记录，但它尖锐的顶面接触面会在几十年内被生物抹平，因此海相剖面中最高频的气候信息是被动物毁掉的。前寒武纪在没有掘穴者之前保存了显生宙无法保存的纹层（[[sedimentology/continental-environments]]）。
:::
:::

## 没有调控者的调控

::: definition 雏菊世界 {#def-daisyworld}
盖亚假说可检验的表述是：生命倾向于调控地表环境，因为以适合自己方式改变环境的生物会留下更多后代。**雏菊世界**模型用代数说明了这一点：一颗裸岩反照率$0.5$的行星上有两种植物，深色雏菊（反照率$0.2$）和浅色雏菊（反照率$1.0$）。随着日照增强，能让行星保持凉爽的雏菊占据优势，行星温度因此几乎不变——直到雏菊无法生存，温度随即跳升。
:::

::: proposition 调控有其作用范围，然后失效 {#prop-daisy}
在雏菊世界中，只要雏菊还能生长，平衡温度就对太阳强迫免疫，因为覆盖度$f$会调整到使吸收的恒星通量近似恒定。这种缓冲是反馈的性质，不是任何意图的性质；它在雏菊耐受范围的边缘突然失效。
:::

::: proof
把行星反照率写成覆盖度加权平均$\alpha = \alpha_\text{rock}(1 - f_\text{d} - f_\text{l}) + \alpha_\text{d}f_\text{d} + \alpha_\text{l}f_\text{l}$，并令各类覆盖度的增长率为温度的钟形函数。平衡是（能量平衡、覆盖度）耦合系统的不动点。在雏菊生长受温度限制而覆盖度未饱和之处，$\mathrm{d}T/\mathrm{d}S \ll \mathrm{d}T_\text{bare}/\mathrm{d}S$：该导数被$1 + \beta$缩小，其中$\beta$衡量反照率通过生物对温度的响应强度。当$f$达到$0$或$1$，或温度超出耐受曲线，$\beta$崩溃，缓冲区间结束。这就是地球系统中一切"有作用范围的稳定反馈"论证的数学内容——包括硅酸盐风化恒温器，以及在更短时间尺度上的[[earth-system/carbon-cycle]]碳循环汇。
:::

雏菊世界不是关于地球的主张；它证明的是调控不需要远见，这正是批评者与提出者那场持续二十年的争论的实质。真正有意思的经验问题是实际地球显示了多大程度的调控，而诚实的答案是：在某些具体环节有（海洋反照率与硫、土壤水分与植被、湿地甲烷），但比1970年代那些表述所暗示的行星级调控要小得多。

::: example 海洋也许在给自己施肥 {#ex-dms}
海洋浮游植物释放二甲基巯基丙酸内盐，经细菌转化为二甲基硫（DMS）；约$15$–$25\ \mathrm{Tg\,S\,yr^{-1}}$进入大气，被氧化为硫酸盐和甲磺酸盐，成为海洋上空的云凝结核。取其中$10\ \mathrm{Tg\,S\,yr^{-1}}$，问它对气溶胶是否足够重要。
::: solution
$10\ \mathrm{Tg\,S\,yr^{-1}}$即$10^{13}\ \mathrm{g\,yr^{-1}}$，以硫酸盐计为$3\times10^{13}\ \mathrm{g\,SO_4\,yr^{-1}}$。大气中因湿沉降的寿命为$1$–$3$天，因此该通量能维持的存量约为
$$
\frac{10\ \mathrm{Tg\,S\,yr^{-1}}}{365/2.5\ \mathrm{yr^{-1}}} \approx 0.07\ \mathrm{Tg\,S},
$$
与远海海洋大气实测的非海盐硫酸盐存量同量级。因此生物源足以主导远海硫酸盐气溶胶，实测也确认了这一点：南大洋上空大部分非海盐硫酸盐是生物源的。

反馈是否闭合——水温更高是否意味着DMS更少、因而阳光更多、温度更高——就是CLAW假说，至今未决。实验与野外观测在DMS产生的温度敏感性符号上就不一致，而气溶胶对云的效应是气候敏感度中最少约束的一项（[[atmospheric-chemistry/aerosols]]、[[climate-system/feedbacks-sensitivity]]）。
:::

::: warning 亚马逊不是地球之肺，盖亚也不是神
两句半对的口号造成了很大危害。"地球之肺"暗示雨林供应我们的氧气：事实并非如此，因为成熟森林呼吸掉的氧几乎正好等于其固定的氧，而大气氧盈余来自沉积物埋藏和地质时间尺度上海洋的净群落生产。亚马逊真正供应的是水——它回收自身降水的三分之二——以及碳储量，而这两者都在流失。"盖亚"暗示地球是一个自我调控的生物体：这个概念有用的内涵是生物反馈存在且可稳定或失稳，误导的内涵是对目的性或稳健性的暗示。雏菊世界缓冲到极限，然后崩溃。
:::

::: quiz
为什么全球光合作用翻倍，单凭这一点不会改变大气氧？
- [ ] 因为氧与臭氧的反应快于生成。
- [x] 因为呼吸与分解消耗掉几乎全部产生的氧；只有埋藏的有机碳才留下净盈余。
- [ ] 因为海洋吸收了多余的氧。
- [ ] 因为光合作用只在夜间释放氧。
::: solution
光合作用与呼吸作用几乎是完全相反的过程，在全球尺度上大致平衡，因此在氧收支中通量相互抵消。氧的净源是逃过氧化的那部分初级生产——今天为$0.1$–$0.2\ \mathrm{GtC\,yr^{-1}}$的有机碳以及与之伴生的黄铁矿硫，即生产量的百分之几的百分之一。这就是为什么大氧化事件需要的是*埋藏*的改变而非生产力的改变：证据指向新形成大陆架上有机碳的稳定化，以及溶解$\mathrm{Fe^{2+}}$、火山$\mathrm{H_2}$等还原性汇的耗尽（[[earth-history/oxygen-proterozoic]]）。
:::
:::

::: warning 当前的灭绝速率是本章最不精确、也最要紧的数字
背景灭绝率由显生宙海生无脊椎动物属统计，约为每一百万物种年$0.1$–$1$次灭绝。1900年以来观测到的脊椎动物灭绝率是其$50$–$100$倍；用种-面积关系从生境丧失推算的灭绝是其$100$–$1000$倍；2019年IPBES评估结论是约一百万种受威胁。三点诚实的保留。种-面积推算假定平衡，会高估近期损失。分类学知识极不均衡，多数受威胁物种尚未被描述。而对生态系统功能真正要紧的数字不是物种数，而是功能、相互作用和生物地理分布的丧失，没有任何指数能捕捉。结论在这三点保留下依然成立；精确性则不然。
:::

::: history
"生命是地质营力"这一观念比地质学本身更老：18世纪罗班内（Robinet）和布丰（Buffon）都写过生命物质是能动的营力。维尔纳茨基（Vernadsky）在《生物圈》（1926年）中把它变成定量而行星尺度的理论，论证生物是"一种地质营力"、生物圈的化学由生物对气体的转移主导——这本书使该概念获得学术地位，却在西方被忽视了四十年。俄国土壤学传统（道库恰耶夫、苏卡乔夫）提供了土壤与生命协同演化的内容。雷德菲尔德（Redfield）1934年把海水固定的氮磷比解释为生物自身的化学计量，从而把海洋化学变成了生物学。哈钦森（Hutchinson）在1940–1950年代创立了生物地球化学循环的生态学。1965年，洛夫洛克（Lovelock）在为NASA研究如何探测火星生命时提出，有生命的行星大气处于化学不平衡状态，从轨道上即可识别；与提供了微生物代谢内容的马古利斯（Margulis）合作，这成为盖亚假说（1972–1974年）。沃森（Watson）与洛夫洛克的雏菊世界（1983年）把争论变成了模拟练习。与此同时经验基础不断积累：纽厄尔（Newell）1965年用化石记录算出背景灭绝率；劳普（Raup）与塞普科斯基（Sepkoski）在1980年代发现了引发撞击争论的周期性；路易斯·阿尔瓦雷兹与沃尔特·阿尔瓦雷兹（Alvarez）1980年在白垩系-古近系界线黏土中发现铱；法夸尔（Farquhar）等在2000年证明太古岩中的硫同位素质量无关分馏证实了早期无氧大气，给了这个领域最干净的一个数据点。
:::

## 由此通向何处

生命是物理气候所没有的那个边界条件：它设定地表反照率、粗糙度、蒸散发、土壤厚度和风化速率，也设定空气的成分。其化学见[[biogeochemistry/principles]]和[[biogeochemistry/production-decomposition]]，其深历史见[[earth-history/early-earth]]、[[earth-history/oxygen-proterozoic]]和[[earth-history/cenozoic]]，其海洋机器见[[oceanography/productivity]]，其土壤见[[geomorphology/weathering]]和[[geochemistry/weathering-chemistry]]，其当前危机见[[climate-change/impacts]]。

::: summary
- 光合作用与呼吸作用相互抵消；只有埋藏能改变大气。氧是一份"没有烂掉的碳"的账本。
- 硫同位素质量无关分馏把大氧化事件定年在$24.5$亿年前，并证明早期大气无氧；条带状铁建造在同一层位结束。
- 全球NPP约$60\ \mathrm{GtC\,yr^{-1}}$；人类使用或占用其中陆地部分的约三分之一，而人造物的质量已超过所有活生物质的质量。
- 生物泵输出$11\ \mathrm{GtC\,yr^{-1}}$、埋藏其中$1$–$2\%$；其效率随变暖下降。
- 生物扰动$K \sim 1$–$10\ \mathrm{cm^2\,yr^{-1}}$，设定了混合层深度，从而设定了沉积记录的时间分辨率。
- 没有调控者的调控是可能的（雏菊世界），但它有作用范围并会突然失效——这是理解一切生物反馈的正确框架。
- 按不同测法，灭绝速率是背景值的$50$–$1000$倍；功能的丧失比物种的丧失更难测量。
:::

## 习题

::: exercise 光合效率 {level=1 check="0.063"}
陆地GPP为$60\ \mathrm{GtC\,yr^{-1}}$，植被面积$1.3\times10^{14}\ \mathrm{m^2}$。陆地平均入射光合有效辐射为$110\ \mathrm{W\,m^{-2}}$，固定$1\ \mathrm{g\,C}$需$470\ \mathrm{kJ}$。求固定的PAR比例。
::: solution
单位面积固碳：$60\times10^{18}\ \mathrm{g\,yr^{-1}}/1.3\times10^{14}\ \mathrm{m^2} = 4.6\times10^{5}\ \mathrm{g\,m^{-2}\,yr^{-1}}$。能量：$4.6\times10^{5}\times470 = 2.2\times10^{8}\ \mathrm{J\,m^{-2}\,yr^{-1}}$，即$6.9\ \mathrm{W\,m^{-2}}$。相对于$110\ \mathrm{W\,m^{-2}}$为$6.3\%$——但注意这是把包括荒漠在内的整个陆地面积平均后的*总*固定量；按生长季的叶面积计，效率为百分之几，与冠层$0.5$–$2\%$的范围一致。
:::
:::

::: exercise 雷德菲尔德算术 {level=1 check="2120"}
一升海水含$20\ \mu\mathrm{mol}$磷酸盐。按雷德菲尔德比，可产生多少微摩尔碳？
::: solution
$20\times106 = 2120\ \mu\mathrm{mol\,C}$。反之，表层磷酸盐减少$2\ \mu\mathrm{mol\,kg^{-1}}$意味着固定并输出了$212\ \mu\mathrm{mol\,kg^{-1}}$的碳——一切生物泵估算背后的算术。
:::
:::

::: exercise 泵的效率 {level=1 check="1.4"}
穿过$100\ \mathrm{m}$的输出为$11\ \mathrm{GtC\,yr^{-1}}$，埋藏为$0.15\ \mathrm{GtC\,yr^{-1}}$。求埋藏效率。
::: solution
$0.15/11 = 1.4\%$。其余$98.6\%$在海洋内部被呼吸掉，这正是深海碳和营养盐库存高、表层贫乏的原因。
:::
:::

::: exercise 种-面积关系 {level=2 check="0.44"}
取$S/S_0 = (A/A_0)^{0.25}$，当生境缩减到$10\%$时，平衡状态下失去多少比例的物种？
::: solution
$1 - 0.1^{0.25} = 1 - 0.56 = 0.44$，即$44\%$。生境减半损失$16\%$。指数$z$的取值从$0.15$（连续、采样充分的生境）到$0.4$（岛屿、空中岛屿），而平衡假定意味着这一预测是数百年的承诺，不是明年的。
:::
:::

::: exercise 生物扰动 {level=2 check="40"}
取$K = 4\ \mathrm{cm^2\,yr^{-1}}$，求$100$年后的$1/e$混合厚度$2\sqrt{Kt}$。
::: solution
$2\sqrt{4\times100} = 40\ \mathrm{cm}$；半幅厚度约为其一半，即$\sim20\ \mathrm{cm}$，正是远洋沉积物的观测范围。
:::
:::

::: exercise 氧与碳循环 {level=2}
若全部$1100\ \mathrm{GtC}$化石储量被烧掉，大气氧的体积混合比下降多少ppm？可测吗？
::: solution
$9.2\times10^{16}\ \mathrm{mol}$的$\mathrm{O_2}$，占$3.7\times10^{19}\ \mathrm{mol}$的$2.5\times10^{-3}$。相对于$209{,}500\ \mu\mathrm{L\,L^{-1}}$，这是$520\ \mu\mathrm{L\,L^{-1}}$的下降——空气氧的五百ppm。现代干涉法可达$10$–$20\ \mu\mathrm{L\,L^{-1}}$，因此信号比噪声高两个量级，而且已被测到。于是氧的测量成为对$\mathrm{CO_2}$测量的独立检验：两者必须按燃烧化学决定的比例一降一升，而事实正是如此。
:::
:::

::: exercise 火的氧阈值 {level=3}
植被可燃性实验给出持续蔓延的临界氧浓度约$15\%$、冠火的临界值约$26\%$。若晚石炭世达到$32\%$，且火蔓延按$(p\mathrm{O_2} - 0.15)^{2}$缩放，可燃烧面积增大多少倍？
::: solution
相对于现代：$[(0.32 - 0.15)/(0.21 - 0.15)]^{2} = (0.17/0.06)^{2} = 8.0$倍；相对于低氧的早古生代大气：$[(0.32-0.15)/(0.16-0.15)]^2 = 289$倍。这个缩放是为练习虚构的——真实关系是渗流阈值，比任何幂律都陡——但结论稳健：几个百分点的氧使火制度变化一个量级。这就是为什么木炭记录、第一批大型干旱沙丘和第一批大型野火在志留纪-泥盆纪一起出现，也是为什么石炭纪煤系中与木炭层互层。
:::
:::

::: exercise 营养盐截留与泵 {level=3}
深海磷酸盐为$2.2\ \mu\mathrm{mol\,kg^{-1}}$，而表层接近零。估算软组织泵使多少碳留在大气-表层海系统之外，并与评估的泵对工业革命前$\mathrm{CO_2}$的影响比较。
::: solution
若表层（取$100\ \mathrm{m}$）拥有深海水平的营养盐，将多含$2.2\times106 = 233\ \mu\mathrm{mol\,kg^{-1}}$的碳。把这一增量摊到整个海洋（深度比$100/3800$）得约$6\ \mu\mathrm{mol\,kg^{-1}}$，即
$$
6\times10^{-6}\times1.4\times10^{21}\times12\ \mathrm{g} = 100\ \mathrm{GtC}
$$
的碳被泵保持在表层之外。由于表层海$p\mathrm{CO_2}$的变化相对大气是放大的，其对大气的影响远大于这一库存：移除软组织泵的模式实验使工业革命前大气$\mathrm{CO_2}$上升约$100$–$200\ \mathrm{ppm}$；若同时移除温度驱动的溶解度对比，则再上升数百ppm。泵在碳循环中不是可忽略项（[[climate-system/carbon-climate]]）。
:::
:::

::: exercise 生物量核算 {level=3}
全球活生物质为$550\ \mathrm{Gt\,C}$，其中植物$450$。人类$0.06\ \mathrm{Gt\,C}$，家畜$0.1$，野生哺乳动物$0.2$。人造（建筑）干质量为$1100\ \mathrm{Gt}$。求：人类与植物之比、人类加家畜与野生哺乳动物之比、人造质量与活生物质之比。
::: solution
人类为植物生物量的$0.06/450 = 1.3\times10^{-4}$，为全部生命的$0.06/550 = 1.1\times10^{-4}$。人类加家畜为$0.16/0.2 = 0.8$，即按这组特定估计占哺乳动物生物量的$45\%$（依野生哺乳动物生物量的取法，已发表数值高至$96\%$）。人造质量为全部生命质量的$1100/550 = 2$倍。

这套算术值得慢慢做，因为它是"人类是自然很小一部分"这句话的诚实版本。按个体数我们不是；按生物量我们可忽略；按我们建造物的质量和我们占用的初级生产力比例，我们是一种地质营力；而按我们改变碳循环和氮循环的速率，在相关时间尺度上我们是主导的那一种。
:::
:::

::: exercise 调控及其失效 {level=3}
裸岩反照率$0.5$、深色雏菊反照率$0.2$、浅色雏菊反照率$1.0$的雏菊世界中，地表被深色雏菊完全覆盖。若雏菊全部死亡，吸收的恒星通量改变多少？这对一个有植被行星的滞后意味着什么？
::: solution
吸收比例从$1 - 0.2 = 0.8$变为$1 - 0.5 = 0.5$：吸收能量减少$37.5\%$，按全球平均日射$341\ \mathrm{W\,m^{-2}}$计为$102\ \mathrm{W\,m^{-2}}$——与地球近代经历过的最大辐射强迫量级相当。因此在沙漠阈值附近，有植被的地面是强双稳的，而恢复要求气候比杀死植被时冷得多。同样的不对称出现在真实系统中：萨赫勒的变绿与变褐阈值不同，永久冻土-碳和北方森林-反照率反馈都有滞后，这就是为什么"临界点"是描述行星生物调控的正确词汇（[[climate-change/tipping-points]]）。
:::
