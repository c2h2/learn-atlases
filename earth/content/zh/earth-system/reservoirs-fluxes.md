大气中现在以二氧化碳形式存在的碳约有$899$吉吨（全球碳计划；冒纳罗亚2023年年均值为$421\ \mathrm{ppm}$）。每年光合作用与呼吸作用在陆地与空气之间移动约$120\ \mathrm{Gt\,C}$，海洋与大气之间交换约$90\ \mathrm{Gt\,C}$。把两者相除就会发现，一个碳原子平均在大气中停留约六年便会被吸收掉。那么，为什么人人都说我们排放的二氧化碳会在那里待上几个世纪？

答案是地球系统记账的第一课：**周转时间不是调整时间**。六年这个数字统计的是分子通过一个近乎平衡的储库的速度；而几个世纪那个数字描述的是储库中**的数量**在你增加之后恢复正常需要多久。把这两个概念分清楚，并且学会在两个数字被写进同一段话的现实中辨别它们，就是本章的目的。

地球系统科学处理的量太大而无法称量，过程太慢而无法观察。它的方法是**箱式模型**：把行星画成几个由箭头连接的盒子，写下每个盒子装了多少、每个箭头跑得多快，然后问会发生什么。有了三个数——储库、通量、滞留时间——和一个概念——反馈——你就可以讨论温室气体的寿命、珊瑚礁对营养盐径流的响应、渔场的恢复和气候的稳定性。

## 储库、通量与滞留时间

::: definition 储库、通量与收支 {#def-reservoir}
**储库**（或称**库**、**箱**）是在确定的地点、确定的时刻持有的某种物质或能量的数量，单位如$\mathrm{Gt\,C}$、$\mathrm{km^3}$、$\mathrm{TW}$或$\mathrm{mol\,N}$。**通量**是单位时间穿过某个边界的数量（$\mathrm{Gt\,C\,yr^{-1}}$、$\mathrm{Sv} = 10^{6}\ \mathrm{m^3\,s^{-1}}$、$\mathrm{W}$）。储库的**收支**（或**质量平衡**）为

$$
\frac{\mathrm{d}R}{\mathrm{d}t} = \sum \text{输入} - \sum \text{输出},
$$

其中$R$为储库的大小。
:::

收支方程就是箱式模型中全部的物理学：把质量（或能量）守恒律用于一个盒子。其余的都是测量。有两个约定值得现在就固定下来。第一，储库和通量的单位要一起给出，并检查$\mathrm{d}R/\mathrm{d}t$的单位是否与通量一致；$3.664$（$\mathrm{CO_2}$与碳的摩尔质量之比）是面向非专业读者的气候文献中最常见的错误之一，因为$1\ \mathrm{Gt\,C} = 3.664\ \mathrm{Gt\,CO_2}$。第二，通量只有配上方向才有意义："海洋碳通量为$90\ \mathrm{Gt\,C\,yr^{-1}}$"是有歧义的，因为海洋每年吸收和释放的量都接近这个数。

::: definition 滞留时间 {#def-residence}
对于一个大小为$R$、总通量为$F$（离开该储库的各通量之和，在稳态下等于进入之和）的充分混合储库，其**滞留时间**为

$$
\tau = \frac{R}{F}.
$$

**周转时间**的定义相同。某个质点的**穿行时间**是该质点单个个体在箱中停留的时间，而箱中物质的**年龄**是该物质进入箱中以来的平均时间。
:::

::: proposition 滞留时间与指数逃逸 {#prop-residence}
设大小为$R$的储库充分混合，物质以总速率$F$离开。则$t = 0$时注入的示踪剂的量为

$$
m(t) = m_0\,e^{-t/\tau}, \qquad \tau = \frac{R}{F},
$$

且$\tau$就是一个分子在储库中停留的平均时间。经过一个$\tau$剩余$37\%$；经过$3\tau$剩余$5\%$；经过$5\tau$剩余$0.7\%$。
:::

::: proof
由于储库充分混合，流出液中示踪剂的比例等于示踪剂在整个箱中所占比例$m/R$。于是示踪剂以$F \times (m/R)$的速率离开：
$$
\frac{\mathrm{d}m}{\mathrm{d}t} = -\frac{F}{R}m = -\frac{m}{\tau}.
$$
这就是衰变常数为$1/\tau$的放射性衰变方程；分离变量并从$m_0$积分得$m = m_0 e^{-t/\tau}$。平均寿命为$\int_0^\infty t\,(-\mathrm{d}m/\mathrm{d}t)\,\mathrm{d}t / m_0 = (F/R)\int_0^\infty t\,e^{-t/\tau}\mathrm{d}t = \tau$，其中用到$\int_0^\infty t e^{-t/\tau}\mathrm{d}t = \tau^2$。
:::

指数律正是滞留时间容易被误读的原因。一个$\tau = 10$年的储库在10年后并不是空的：它还留着$37\%$的扰动；一个世纪之后还留着$0.005\%$。

::: example 水的滞留时间 {#ex-water-tau}
大气持有$12{,}700\ \mathrm{Gt}$水（水汽），全球降水平均为$492{,}000\ \mathrm{Gt\,yr^{-1}}$（什克洛马诺夫的全球水量平衡）。求水在大气中的滞留时间。再与全球大洋比较：大洋持有$1.338\times10^{9}\ \mathrm{km^3}$，通过蒸发损失$413{,}000\ \mathrm{Gt\,yr^{-1}}$。
::: solution
$$
\tau_\text{atm} = \frac{12{,}700\ \mathrm{Gt}}{492{,}000\ \mathrm{Gt\,yr^{-1}}} = 0.0258\ \mathrm{yr} = 9.4\ \mathrm{days}.
$$

对大洋，$1.338\times10^{9}\ \mathrm{km^3}$海水按$1028\ \mathrm{kg\,m^{-3}}$计为$1.376\times10^{21}\ \mathrm{Gt}$，于是

$$
\tau_\text{ocean} = \frac{1.376\times10^{21}}{413{,}000} = 3.3\times10^{6}\ \mathrm{yr}.
$$

因此一个水分子大约一周就在大气中循环一次，却可能在大洋中部停留数百万年。下表为主要水体储库及其滞留时间。

| 储库 | 大小（$10^3\ \mathrm{km^3}$） | 滞留时间 |
|---|---|---|
| 海洋 | 1,338,000 | 平均约$3.3$ Myr |
| 冰盖与冰川 | 24,064 | $10^2$–$10^4$ yr（格陵兰冰平均年龄约$2$ kyr，南极约$16$ kyr） |
| 地下水（淡水） | 10,530 | $10^2$–$10^4$ yr |
| 土壤水 | 165 | 1–6个月 |
| 大气 | 12.7 | 9天 |
| 河流 | 2.1 | 16天 |

大小取自美国地质调查局和什克洛马诺夫（Shiklomanov）的全球水量平衡。按大小排列的顺序不是按滞留时间排列的顺序，也不是按通量排列的顺序。
:::
:::

::: example 大气中的碳 {#ex-co2-tau}
取大气碳储库为$899\ \mathrm{Gt\,C}$（2024年全球年均$422.8\ \mathrm{ppm}$；美国国家海洋和大气管理局全球监测实验室），陆-气交换为$120\ \mathrm{Gt\,C\,yr^{-1}}$，海-气交换为$90\ \mathrm{Gt\,C\,yr^{-1}}$。求碳在大气中的滞留时间。再求若排放$11.2\ \mathrm{Gt\,C\,yr^{-1}}$且完全不吸收时，浓度的年增长（以$\mathrm{ppm\,yr^{-1}}$计）。
::: solution
总通量$F = 120 + 90 = 210\ \mathrm{Gt\,C\,yr^{-1}}$，于是

$$
\tau = \frac{899}{210} = 4.3\ \mathrm{yr}.
$$

这个数字是真实的——它是一个碳原子在大气中停留的平均时间——同时也是气候科学中被误用得最多的数字（见下面的警示）。第二部分，大气每$\mathrm{ppm}$含$2.13\ \mathrm{Gt\,C}$（由大气质量$5.135\times10^{18}\ \mathrm{kg}$和碳与空气的摩尔质量得出），所以在完全不被吸收的情况下

$$
\frac{\mathrm{d}C}{\mathrm{d}t} = \frac{11.2\ \mathrm{Gt\,C\,yr^{-1}}}{2.13\ \mathrm{Gt\,C\,ppm^{-1}}} = 5.3\ \mathrm{ppm\,yr^{-1}} .
$$

2013–2022年观测到的年均增长为$2.5\ \mathrm{ppm\,yr^{-1}}$（全球碳计划2023；美国国家海洋和大气管理局全球监测实验室），因此陆地与海洋合计移除了我们排放量的略多于一半。
:::
:::

::: warning 周转时间不是调整时间
"大气二氧化碳的滞留时间是五年，所以排放无害。"这句话的每个部分都是错的，而错误很有教益。五年这个数是**周转时间**：它统计的是离开一个同时也在被补满的储库的分子，而且主要由与陆地生物圈之间巨大的快速交换决定——生物圈吸收碳的速度和它释放碳的速度一样快。**扰动**——我们加入的多余部分——不能沿这条路径离开，因为光合作每移除一个多余分子，呼吸与分解就归还一个。多余的部分只能靠对"多余"本身有响应的过程移除：海表的碳酸盐化学（它有缓冲，因此只吸收增量中约十分之一的分子），以及陆地上的硅酸盐风化，后者还要慢得多。这就是为什么扰动会有长达数个世纪的尾巴，尽管周转时间只有几年。同样的陷阱也会捉住别的储库：一个湖泊可能一个季节就换完所有的水，却会把磷的富集保持几十年。
:::

::: definition 稳态 {#def-steady-state}
当输入等于输出、因而$\mathrm{d}R/\mathrm{d}t = 0$、储库大小不随时间变化时，称该储库处于**稳态**。若此外通量本身也不变，则称其处于**动态平衡**。稳态不必是热力学意义上的平衡：一个箱可以远离化学平衡而仍处于稳态，氧化性大气就是如此。
:::

::: proposition 向新稳态的松弛 {#prop-relax}
设大小为$R$的充分混合储库在总输入与总输出通量均为$F$时处于稳态，故$\tau = R/F$。若输入突然增加一个常数$\Delta F$，而输出仍与存量成正比，则储库按指数趋近新的稳态：

$$
R(t) = R_\infty - \left(R_\infty - R_0\right)e^{-t/\tau}, \qquad R_\infty = R_0 + \tau\,\Delta F .
$$

扰动以相同的时间常数$\tau$衰减：走完$90\%$约需$2.3\tau$，走完$99\%$约需$4.6\tau$。
:::

::: proof
收支为$\mathrm{d}R/\mathrm{d}t = (F + \Delta F) - (F/R_0)R$，其中输出通量写成与$R$成正比，比例常数由原来的稳态确定。整理得
$$
\frac{\mathrm{d}R}{\mathrm{d}t} = \frac{1}{\tau}\left(R_0 + \tau\Delta F - R\right) = \frac{R_\infty - R}{\tau},
$$
其中$\tau = R_0/F$。令$u = R_\infty - R$，则$\mathrm{d}u/\mathrm{d}t = -u/\tau$，故$u = u_0 e^{-t/\tau}$，即所证结果。走完$90\%$所需时间满足$e^{-t/\tau} = 0.1$，即$t = \tau\ln 10 = 2.3\tau$；走完$99\%$则$t = \tau\ln 100 = 4.6\tau$。
:::

这是本章最有用的一个结果。它说明储库的记忆由$\tau$决定，而"排放停止"与"浓度恢复"之间隔着若干倍滞留时间。

::: quiz
某储库持有$200$个单位，输入为每年$20$个单位，输出为每年$10$个单位。关于它的滞留时间你能说什么？
- [ ] 用输入算，$\tau = 10$年。
- [ ] 用输出算，$\tau = 20$年。
- [x] 滞留时间没有定义，因为该储库不处于稳态。
- [ ] 用通量之和算，$\tau = 200/30$年。
::: solution
$\tau = R/F$是对处于稳态的储库定义的，此时输入等于输出，$F$没有歧义。这里储库正以每年$10$个单位增长，20年即可翻倍，因此"一个分子停留多久"在没有通量如何依赖$R$的模型时没有唯一答案。在给出滞留时间之前，先检查收支。
:::
:::

## 把箱子连起来

真实的储库是彼此相连的，而有趣的行为出现在你把两个箱子连起来的时候。

::: example 两个箱子：海洋表层与大气 {#ex-twobox}
设大气持有$C_a$，海洋表层持有$C_s = 930\ \mathrm{Gt\,C}$，双向交换与失去碳的那个箱中的存量成正比，且在工业革命前的状态下交换通量为$90\ \mathrm{Gt\,C\,yr^{-1}}$（$C_a^0 = 592\ \mathrm{Gt\,C}$）。向大气加入$11.2\ \mathrm{Gt\,C\,yr^{-1}}$的排放。最终排放的碳有多大比例留在大气中？平衡需要多久？
::: solution
交换速率常数为$k_a = 90/592 = 0.152\ \mathrm{yr^{-1}}$（大气到表层海）和$k_s = 90/930 = 0.097\ \mathrm{yr^{-1}}$。在最终稳态中，*多余*的通量每个方向必须再次平衡，因此各箱中的多余量与其大小成正比：

$$
\frac{\Delta C_a}{\Delta C_s} = \frac{k_s}{k_a} = \frac{930}{592} = 1.57 .
$$

于是大气留下多余量的$1.57/(1.57 + 1) = 61\%$，表层海洋吸收$39\%$。（真实海洋吸收得多得多，因为多余量会被环流携带到内部，并被碳酸根离子缓冲，因此整个海洋能吸收的量是表层单独所能吸收的好几倍；这也是真实空气中剩余比例接近$45\%$并随时间下降的原因。）松弛速率是两个速率常数之和，$k_a + k_s = 0.249\ \mathrm{yr^{-1}}$，故交换平衡的时间常数为$1/0.249 = 4.0\ \mathrm{yr}$，$99\%$平衡需$4.6 \times 4.0 = 18\ \mathrm{yr}$。这就是表层海洋以十年尺度与大气交换的原因——也是为什么真正决定多余碳消失时标的是需要数个世纪的深海。
:::
:::

::: example 一列箱子：慢碳循环 {#ex-chain}
碳以海相碳酸盐的形式离开大气，被埋藏进沉积物，经俯冲进入深部，再由火山返回。取通过这一回路的通量为$0.15\ \mathrm{Gt\,C\,yr^{-1}}$（碳酸盐埋藏，与火山和洋脊排放相平衡），回路经过的储库为海洋溶解无机碳$38{,}000\ \mathrm{Gt\,C}$。估算碳相对这一回路的滞留时间，并说明要移除工业时代以来已排放的$1000\ \mathrm{Gt\,C}$需要多久。
::: solution
$$
\tau = \frac{38{,}000\ \mathrm{Gt\,C}}{0.15\ \mathrm{Gt\,C\,yr^{-1}}} \approx 2.5\times10^{5}\ \mathrm{yr}.
$$

若通量不变，以$0.15\ \mathrm{Gt\,C\,yr^{-1}}$移除$1000\ \mathrm{Gt\,C}$需要$1000/0.15 = 6700$年。但通量并不会不变：风化通量对$\mathrm{CO_2}$升高的响应很弱，因此移除先是比较快（海洋和陆地碳汇在几十年内吸收多余量的一半左右），随后变得极慢，一千年后大气中可能还留着约五分之一的多余量，十万年后仍留几个百分点。这就是快循环与慢循环的区别——快循环重新分配碳，而只有慢循环能把碳真正去掉——也是"地球最终会把碳收回去"这句话成立所依赖的、任何文明都无法运作的时间尺度。
:::
:::

## 反馈

::: definition 反馈、增益与放大 {#def-feedback}
当某个系统变量的变化改变了某个通量，而该通量又反过来改变这个变量时，就存在**反馈**。若返回的变化与原始变化同号，则该反馈为**正反馈**（增强型）；若异号，则为**负反馈**（平衡型）。把总响应写成初始扰动响应加上其自身的某个分数$f$，

$$
\Delta X = \Delta X_0 + f\,\Delta X \quad\Longrightarrow\quad \Delta X = \frac{\Delta X_0}{1 - f},
$$

则$A = 1/(1 - f)$称为**放大因子**，$g = f/(1-f)$称为**增益**。对气候反馈，$f$通常写成相对于普朗克响应的各反馈参数$\lambda_i$之和：$A = -\lambda_0/(\lambda_0 + \sum_i\lambda_i)$。
:::

::: proposition 线性反馈的稳定性 {#prop-stability}
系统$\Delta X = \Delta X_0 + f\Delta X$稳定（迭代收敛）当且仅当$f < 1$。当$0 < f < 1$时响应有限但大于初始扰动；当$f < 0$时响应小于初始扰动；当$f \ge 1$时响应无界增长。
:::

::: proof
迭代：经过$n$轮后扰动为$\Delta X_0(1 + f + f^2 + \dots + f^{n-1}) = \Delta X_0(1 - f^n)/(1 - f)$。当且仅当$f^n$有极限时它有有限极限，而这要求$-1 < f < 1$（$-1 < f < 0$的反馈在衰减的同时来回摆动）。当$f \ge 1$时部分和无界增长；当$f = 1$时响应无穷大：系统完全没有恢复机制。从物理上看，$f$是反馈通量与清除扰动之通量的比值，因此$f \to 1$意味着清除通量恰好被抵消。
:::

::: example 水汽：最强的正反馈 {#ex-wv}
在变暖的世界里，更暖的大气持有更多水汽，而水汽本身是温室气体。假设二氧化碳加倍本身使地表增暖$1.2\ ^\circ\mathrm{C}$，水汽在每度地表增暖上再加$0.7\ ^\circ\mathrm{C}$，而云、直减率和地表反照率合计减去$0.5\ ^\circ\mathrm{C}$。求净反馈、放大因子和平衡增暖。
::: solution
净反馈参数为$f = 0.7 - 0.5 = 0.2\ \mathrm{K\,K^{-1}}$，于是

$$
A = \frac{1}{1 - 0.2} = 1.25, \qquad \Delta T = 1.25 \times 1.2 = 1.5\ ^\circ\mathrm{C}.
$$

迭代验证：$1.2 \to 1.2 + 0.2\times1.2 = 1.44 \to 1.464 \to \dots \to 1.5$。这里的数字是为了简单而选取的；评估值（IPCC第六次评估报告第一工作组，2021年，第7章）采用*负*参数表示稳定的约定：普朗克响应$\lambda_0 = -3.22\ \mathrm{W\,m^{-2}\,K^{-1}}$，水汽加直减率$-1.30$，*可能*范围$-1.80$至$-0.90$；云$+1.0$，*可能*范围$+0.3$至$+2.0$；地表反照率$+0.1$。要点不在算术而在结构：各个反馈量值都很大且部分相互抵消，这正是净反馈不确定的原因。
:::
:::

- [ ] 响应是未扰动响应的$0.83$倍。
::: solution
当$f > 1$时放大因子$1/(1 - f)$为负，这是级数$1 + f + f^2 + \dots$不收敛的代数信号。物理上，反馈通量超过了清除扰动的通量，因此系统没有任何可以停下来的状态：模型在告诉你，记账中被略去的某个其他过程必定变得重要。真实系统处处是这样的界限——当被略去的过程把系统带到另一个状态时，人们称之为**临界点**。
:::
:::

::: example 一个多次拯救过地球的负反馈 {#ex-weathering}
在与地质恒温器相关的范围内，硅酸盐风化移除二氧化碳的通量大约每增暖$10\ \mathrm{K}$翻倍。若全球平均地表温度为$15\ ^\circ\mathrm{C}$时移除通量为$0.3\ \mathrm{Gt\,C\,yr^{-1}}$，把通量写成$F(T) = F_0 Q^{(T - 15)/10}$，其中$Q = 2$，求增暖$5\ \mathrm{K}$时移除通量的变化。这是何种符号的反馈？在数百万年的时间尺度上意味着什么？
::: solution
$$
\frac{\Delta F}{F_0} = Q^{5/10} - 1 = 2^{0.5} - 1 = 0.41,
$$

即移除通量增加$41\%$，从$0.3$升至$0.42\ \mathrm{Gt\,C\,yr^{-1}}$——多出$0.12\ \mathrm{Gt\,C\,yr^{-1}}$，约为当前人为排放量的$1\%$。这个反馈在**符号**上是强负反馈（增暖增加了移除造成增暖的温室气体的速率），但在百年时间尺度上太慢而无用。在数百万年的时间尺度上它占主导：这就是整个显生宙要么无冰要么结冰、却从未沸腾的原因；也是工业时代多余的二氧化碳终将以同样方式在数十万年内被移除的原因。
:::
:::

::: intuition 箱式模型能与不能
箱式模型在构造上守恒质量，因此它是回答"它去哪儿了？"和"多久能消失？"的好工具。它不能告诉你通量的大小或反馈的强度：那些是测量值，或是过程模式的输出，而箱式模型因把无知藏在"充分混合"假设里而屡受批评。两点提醒。第一，真实储库并不充分混合——大气一年即可混匀；海洋需要一千年才能换气；泥炭剖面是从上往下周转的。第二，通量很少与储库大小成正比：渔场、土壤碳库或风化通量都可能改变状态、饱和或失控。当箱式模型的答案依赖线性通量律时，请明说。
:::

::: warning "系统处于平衡"并不等于"什么都没变"
稳态的意思只是$\mathrm{d}R/\mathrm{d}t = 0$，仅此而已。工业革命前的碳循环在数百$\mathrm{Gt\,C\,yr^{-1}}$的总通量下处于稳态；这一点也没有告诉我们它对排放会如何响应。反过来，一个储库可以在通量只失衡百分之几时持续增长：大气在$210$的吞吐量中净增约$5\ \mathrm{Gt\,C\,yr^{-1}}$，失衡$2\%$，而这已足以改变气候。永远要问：失衡是相对于什么的失衡？这些通量是直接测得的，还是作为残差推算的？
:::

::: history
箱式模型比数据更古老。1896年，斯凡特·阿伦尼乌斯（Arrhenius）在计算二氧化碳的温度效应时，使用了一个海洋与大气交换该气体、而海洋含量由溶解度决定的模型——一个带化学约束的双箱模型，也是第一个定量气候模型。1957年，罗杰·勒维尔（Revelle）与汉斯·苏斯（Suess）利用海水的碳酸盐化学论证，表层海洋吸收额外二氧化碳的能力很小——即"雷维尔因子"——而查尔斯·基林（Keeling）自1958年开始的测量表明这一能力正在被用掉。反馈的语言来自控制论，并随1960年代的数值模式进入气候科学：真锅淑郎（Manabe）与Richard Wetherald 1967年的模式包含了水汽反馈，给出二氧化碳加倍增暖$2.9\ ^\circ\mathrm{C}$，这个数字后来被证明惊人地稳固。美国国家科学院一个由朱尔·查尔尼（Charney）主持的顾问委员会1979年的报告把范围定为$1.5$–$4.5\ ^\circ\mathrm{C}$；四十五年、众多模式之后，IPCC第六次评估报告（2021年）仍给出最佳估计$3\ ^\circ\mathrm{C}$，*可能*范围$2.5$–$4.5\ ^\circ\mathrm{C}$。记账已经改进极多；困难的仍是反馈。
:::

## 由此通向何处

箱式模型的语言贯穿整个图谱。滞留时间组织了水循环（[[earth-system/water-cycle]]）和碳循环（[[earth-system/carbon-cycle]]），并以地下水年龄（[[hydrology/groundwater-flow]]）、冰芯气体年龄（[[palaeoclimate/ice-cores]]）和放射性同位素时钟（[[earth-history/geological-time]]）的面目重现。反馈组织了气候：上面的反馈框架在[[climate-system/feedbacks-sensitivity]]中几乎原样使用，那里由模式和观测估计参数$\lambda_i$；在[[climate-change/emissions-budgets]]中，当我们追问给定的累积排放意味着多少增暖时也会用到。下一章把同样的收支思想用于能量而不是物质。

::: summary
- **储库**储存，**通量**搬运，而**收支**$\mathrm{d}R/\mathrm{d}t = \text{入} - \text{出}$是箱式模型唯一添加的物理学。
- 对处于稳态的充分混合储库，$\tau = R/F$，扰动按$e^{-t/\tau}$衰减：一个$\tau$后剩$37\%$，三个$\tau$后剩$5\%$，五个$\tau$后剩$0.7\%$。
- 周转时间（分子循环多快）与调整时间（数量恢复多快）是两个量；对二氧化碳，二者相差一个数量级以上。
- 输入的阶跃变化之后是按指数趋近新稳态的过程，$2.3\tau$走完$90\%$，$4.6\tau$走完$99\%$。
- 连接箱子会按箱子大小比例分配扰动，而平衡速率由两个交换速率常数之和决定。
- 净强度为$f$的反馈把响应放大$1/(1 - f)$；只有$f < 1$时系统才稳定。
- 气候反馈各自很大且部分抵消，这正是净反馈——从而气候敏感度——不确定的原因。
:::

## 习题

::: exercise 处于平衡的储库 {level=1 check="579"}
某湖持有$5.0\times10^{9}\ \mathrm{m^3}$水，河流以$100\ \mathrm{m^3\,s^{-1}}$注入。稳态下其滞留时间为多少天？
::: solution
稳态下流出等于流入，$F = 100\ \mathrm{m^3\,s^{-1}}$，于是
$$
\tau = \frac{5.0\times10^{9}}{100} = 5.0\times10^{7}\ \mathrm{s} = \frac{5.0\times10^{7}}{86400} = 579\ \mathrm{days},
$$
约一年半。滞留时间这样的湖泊一场汛期就能换完水；而$\tau$达数年的湖泊会把流域信息累积多年，对富营养化敏感得多。
:::
:::

::: exercise 单位换算 {level=1 check="36.6"}
某电站在一个世纪内排放$10\ \mathrm{Gt\,C}$。以$\mathrm{Gt\,CO_2}$表示总量，并给出平均速率（$\mathrm{Gt\,CO_2\,yr^{-1}}$）。
::: solution
$1\ \mathrm{Gt\,C} = 44.01/12.011 = 3.664\ \mathrm{Gt\,CO_2}$，故$10\ \mathrm{Gt\,C} = 36.6\ \mathrm{Gt\,CO_2}$，平均速率为$0.37\ \mathrm{Gt\,CO_2\,yr^{-1}}$。
:::
:::

::: exercise 示踪剂的衰减 {level=1 check="60"}
注入$\tau = 20\ \mathrm{yr}$储库的示踪剂按$e^{-t/\tau}$衰减。多少年后剩余$5\%$？
::: solution
$e^{-t/20} = 0.05$给出$t = 20\ln 20 = 20\times3.00 = 60\ \mathrm{yr}$，即三个滞留时间。
:::
:::

::: exercise 地下水 {level=2 check="1200"}
淡水地下水持有$10.53\times10^{6}\ \mathrm{km^3}$，补给率为$8800\ \mathrm{km^3\,yr^{-1}}$（美国地质调查局估计）。求平均滞留时间（年）。
::: solution
$\tau = 10.53\times10^{6}/8800 = 1197\ \mathrm{yr}$，约$1200$年。注意这是对一个极宽分布取的均值：浅层含水层只有几十年，深部盆地可达数百万年；氚与$^{14}\mathrm{C}$测年显示的正是这种离散（[[hydrology/groundwater-flow]]）。
:::
:::

::: exercise 增长的储库 {level=2 check="80"}
某储库有$800$个单位，每年输入$50$、输出$45$个单位，两个通量均为常数。多少年后它增长$50\%$？此处$\tau = R/F$有意义吗？
::: solution
$\mathrm{d}R/\mathrm{d}t = 5\ \mathrm{units\,yr^{-1}}$，故多出的$400$个单位需要$400/5 = 80\ \mathrm{yr}$。滞留时间在通常意义下没有定义，因为储库不处于稳态；若要刻画其更新，可用输出通量，$\tau = 800/45 = 18\ \mathrm{yr}$，并说明所用的约定。
:::
:::

::: exercise 双箱松弛 {level=2}
两个箱子大小分别为$A = 600$和$B = 2400$个单位，平衡时双向交换通量均为$120\ \mathrm{units\,yr^{-1}}$。求两个速率常数和交换的时间常数，并算出向$A$加入$100$个单位后最终如何在两箱之间分配。
::: solution
$k_A = 120/600 = 0.20\ \mathrm{yr^{-1}}$，$k_B = 120/2400 = 0.05\ \mathrm{yr^{-1}}$。交换以两者之和$0.25\ \mathrm{yr^{-1}}$趋于平衡，故时间常数为$4\ \mathrm{yr}$，$99\%$平衡需$18\ \mathrm{yr}$。终态中多余通量平衡，$k_A\Delta A = k_B\Delta B$，故$\Delta B/\Delta A = k_A/k_B = 4$：箱$B$留下多余量的$80\%$，$A$只留$20\%$。"大箱子拿得多"这一直觉是对的，但比例由速率常数决定，而不只由大小决定——本例中二者成正比，是因为平衡时双向交换通量相同。
:::
:::

::: exercise 反馈算术 {level=2 check="4"}
某系统受到$2.0\ \mathrm{W\,m^{-2}}$的扰动，其净反馈为$f = 0.75$。求放大因子，以及相对于无反馈响应的响应。
::: solution
$A = 1/(1 - 0.75) = 4$。响应是无反馈响应的四倍。若无反馈响应为$0.8\ \mathrm{K}$，则实际响应为$3.2\ \mathrm{K}$。
:::
:::

::: exercise 空气中剩余比例 {level=3}
2010–2019年，化石燃料与工业排放平均为$9.6\ \mathrm{Gt\,C\,yr^{-1}}$，土地利用变化排放$1.6\ \mathrm{Gt\,C\,yr^{-1}}$；海洋吸收$2.6 \pm 0.4$，陆地吸收$3.1 \pm 0.6\ \mathrm{Gt\,C\,yr^{-1}}$（全球碳计划2022）。求在大气中积累的通量（$\mathrm{Gt\,C\,yr^{-1}}$）、空气中剩余比例，以及相应的浓度年增长率（$\mathrm{ppm\,yr^{-1}}$）。
::: solution
$$
\frac{\mathrm{d}R}{\mathrm{d}t} = (9.6 + 1.6) - (2.6 + 3.1) = 11.2 - 5.7 = 5.5\ \mathrm{Gt\,C\,yr^{-1}},
$$

两个碳汇带来的不确定度约$\pm 0.8$。空气中剩余比例为$5.5/11.2 = 49\%$。按$2.13\ \mathrm{Gt\,C\,ppm^{-1}}$换算，即$5.5/2.13 = 2.6\ \mathrm{ppm\,yr^{-1}}$，与观测到的$2.5\ \mathrm{ppm\,yr^{-1}}$接近（美国国家海洋和大气管理局全球监测实验室，冒纳罗亚）。这一微小差别的来源一如既往：碳汇项是由排放清单和大气增长速率作为残差推算的，并非直接测量，因此收支只在所述不确定度内按构造闭合。
:::
:::

::: exercise 排放停止之后要多久？ {level=3}
对多余二氧化碳以有效时间常数$\tau = 150\ \mathrm{yr}$被移除（作为海洋吸收与碳酸盐中和的粗略替代）的大气，使用[[#prop-relax]]。若排放在多余量$1000\ \mathrm{Gt\,C}$时突然停止，多余量降到$100\ \mathrm{Gt\,C}$以下需要多久？与$\tau$比较。
::: solution
$1000\,e^{-t/150} = 100$给出$t = 150\ln 10 = 345\ \mathrm{yr}$，即$2.3\tau$，与命题一致。应当比较的是大气碳的周转时间，约$4$–$5$年：两者相差约$70$倍。真实的地球系统模式会给出更陡的初始下降（浓度梯度陡时陆地和表层海洋吸收很快）以及比单一指数长得多的尾巴，因为深海与碳酸盐化学在$10^3$–$10^5$年时间尺度上响应。
:::
:::

::: exercise 有阈值的模型 {level=3}
土壤有机碳$S$以与$S$成正比的速率因分解而损失碳，$\tau = 25\ \mathrm{yr}$；通过凋落物通量$L$获得碳。(a) 若$L = 60\ \mathrm{Gt\,C\,yr^{-1}}$，稳态存量是多少？(b) 若增暖使$L$降至$50\ \mathrm{Gt\,C\,yr^{-1}}$，新存量是多少？变化的$90\%$需要多久？(c) 若改为分解加速使$\tau$降至$20\ \mathrm{yr}$而$L = 60$不变，新存量是多少？
::: solution
(a) $S_\infty = L\tau = 60\times25 = 1500\ \mathrm{Gt\,C}$，与评估的全球$1\ \mathrm{m}$深土壤碳储量相当（$1500$–$2400\ \mathrm{Gt\,C}$，取决于计入多少多年冻土）。
(b) $S_\infty = 50\times25 = 1250\ \mathrm{Gt\,C}$，损失$250\ \mathrm{Gt\,C}$；变化的$90\%$需要$2.3\tau = 58\ \mathrm{yr}$。
(c) $S_\infty = 60\times20 = 1200\ \mathrm{Gt\,C}$：仅周转时间的改变就可能再释放$300\ \mathrm{Gt\,C}$，而输入毫无变化。这就是为什么"土壤碳是碳汇"和"土壤碳是稳定的"不是同一个命题，也是为什么多年冻土融化——它改变的是$\tau$而不是$L$——属于反馈而不是强迫。
:::
