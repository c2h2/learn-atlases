1906年5月，印度的一台地震仪记录到一次说不通的震动。来自大地震的波到达了"不该有波"的距离——而且到得*太早*。理查德·奥尔登姆（Oldham）认出了这意味着什么：地球内部必有一个区域，波在其中走得更快，绕过一个核折射。二十年后，哈罗德·杰弗里斯（Jeffreys）证明同一几何还要求核是液体，因为剪切波穿不过去。1936年，年轻的丹麦地震学家英格·雷曼（Lehmann）发现，从那个液体深处反射回来的波又略微提前了，于是宣布液体内部还有一个实心球。

我们对深部地球的一切了解都来自这条计时测量的链条，一个世纪的精炼把它变成一个模型——初步参考地球模型（PREM）——其中速度和密度从地表到地心每$100\ \mathrm{km}$列表一次。本章讲固体地球由什么构成、我们怎么知道，以及一个在地震时间尺度上无疑是坚硬岩石和金属的天体，如何仍然每隔几亿年就把自己的表面彻底翻新一遍。

## 用地震波读内部

::: definition 地震波速度与弹性模量 {#def-moduli}
在一个小波时间尺度上不传热也不流动的固体中，弹性波的速度由两个模量和密度决定：
$$
V_P = \sqrt{\frac{K + \tfrac{4}{3}\mu}{\rho}}, \qquad V_S = \sqrt{\frac{\mu}{\rho}},
$$
其中$K$为不可压缩性（体积模量），$\mu$为刚度。$V_P$是压缩波（P波）速度，$V_S$是剪切波（S波）速度。二者之比给出泊松比：$V_P/V_S = \sqrt{K/\mu + 4/3}$。
:::

::: proposition 外核是液体 {#prop-liquidcore}
跨过核幔边界，$V_S$从$7.34\ \mathrm{km\,s^{-1}}$降到零，而不可压缩性几乎不变：其上$K = 647\ \mathrm{GPa}$，其下$643\ \mathrm{GPa}$。由于$V_S = 0$要求$\mu = 0$，而只有流体（在波的周期意义上）刚度为零，外核必为液体。$K$的连续性说明这个界面不是同一物质的相变，而是物质本身的改变。
:::

::: proof
$V_S = \sqrt{\mu/\rho}$只在$\mu = 0$时为零；刚度为零的物质不能承载剪切应力，这正是流体的定义。用$K = \rho(V_P^2 - \tfrac{4}{3}V_S^2)$计算两侧：上侧$\rho = 5570\ \mathrm{kg\,m^{-3}}$、$V_P = 13.71$、$V_S = 7.34\ \mathrm{km\,s^{-1}}$，得$K = 647\ \mathrm{GPa}$；下侧$\rho = 9900\ \mathrm{kg\,m^{-3}}$、$V_P = 8.06$、$V_S = 0$，得$K = 643\ \mathrm{GPa}$。相比之下密度从$5.57$跳到$9.90\ \mathrm{g\,cm^{-3}}$。同一矿物的相变会使$\rho$和$V_P$一起变化并保留部分刚度；而金属/硅酸盐界面可以在密度翻倍的同时让$K$几乎连续。这就是地球那次伟大化学分异的地球物理签名——正是这次事件使行星分成了圈层（[[earth-system/planet-earth]]）。
:::

| 深度 | 圈层 | $V_P$ $\mathrm{km\,s^{-1}}$ | $V_S$ $\mathrm{km\,s^{-1}}$ | $\rho$ $\mathrm{g\,cm^{-3}}$ |
|---|---|---|---|---|
| 0–35 | 大洋/大陆地壳 | 5.9–6.8 | 3.4–3.9 | 2.7–3.0 |
| 35–410 | 上地幔（橄榄石） | 8.08 | 4.48 | 3.32 |
| 410–660 | 过渡带（瓦兹利石、林伍德石） | 9.0–10.2 | 4.9–5.6 | 3.5–4.0 |
| 660–2891 | 下地幔（布里奇曼石加铁方镁石） | 10.2–13.7 | 5.6–7.3 | 4.0–5.6 |
| 2891–5150 | 外核（Fe–Ni加轻元素） | 8.06–10.3 | 0 | 9.9–12.2 |
| 5150–6371 | 内核（Fe–Ni） | 11.0 | 3.5 | 12.8–13.1 |

（PREM端点值；每一层内速度和密度因压缩而连续上升。）

::: definition 不连续面：相变还是成分 {#def-discontinuities}
**莫霍洛维奇不连续面**（莫霍面，5–70 km）是地壳岩石与橄榄岩之间的成分界面，1909年因巴尔干地震的P波分两列到达而发现。**410 km**和**660 km**不连续面则是同一岩石中的相界面：橄榄石先塌缩为瓦兹利石（密度上升约$8\%$），再变为林伍德石，到660 km变为布里奇曼石加铁方镁石。**核幔边界**（2891 km）和**内外核边界**（5150 km）分别是化学界面和金属/固体界面。
:::

这个区别不是装饰性的。成分界面平坦而永久；相界面随温度移动，因为两相的熵和体积不同。其斜率由克拉珀龙关系给出，而该斜率的符号使地震学家能够*看见*沉入过渡带的冷板片。

::: widget plot

x: 0.3, 6
y: 1.3, 2.7
caption: 速度比$V_P/V_S = \sqrt{K/\mu + 4/3}$随刚度比$K/\mu$的变化。普通地壳岩石$K/\mu \approx 1.5$–$2$，对应$V_P/V_S \approx 1.7$–$1.8$；下地幔$K/\mu = 2.2$，对应$1.87$。加入熔体后$\mu$趋于零，$K/\mu$和$V_P/V_S$急剧上升：含$1\%$部分熔融的岩石表现为$V_S$下降几个百分点、$V_P/V_S$上升零点几。这一个比值是寻找岩浆体、热液系统和储层中最有用的岩石物理数字，也是为什么找熔体要看$V_S$剖面而不是$V_P$剖面。
:::

::: example 不连续面往哪里弯？ {#ex-clapeyron}
410 km不连续面的克拉珀龙斜率$\gamma = \mathrm{d}P/\mathrm{d}T \approx +3\ \mathrm{MPa\,K^{-1}}$；660 km不连续面$\gamma \approx -2.5\ \mathrm{MPa\,K^{-1}}$。在比周围冷$200\ \mathrm{K}$的板片中，两者各移动多少（$\rho g \approx 3.5\times10^{4}\ \mathrm{Pa\,m^{-1}}$）？
::: solution
温度异常$\Delta T$使界面移动$\Delta P = \gamma\Delta T$的压强，对应深度变化
$$
\Delta z = \frac{\gamma\,\Delta T}{\rho g}.
$$
410面在$\Delta T = -200\ \mathrm{K}$时：$\Delta P = -0.60\ \mathrm{GPa}$，故$\Delta z = -0.60\times10^{9}/3.5\times10^{4} = -17\ \mathrm{km}$：界面向*低压*移动，即变浅。660面：$\gamma\Delta T = (-2.5\times10^{6})\times(-200) = +0.50\ \mathrm{GPa}$，故$\Delta z = +14\ \mathrm{km}$：界面向*高压*移动，即变深。由于克拉珀龙斜率符号相反，同一个冷异常把两个界面往相反方向推，观测上过渡带在冷下降流之上增厚$20$–$30\ \mathrm{km}$，在热上升流之上变薄。

更深一层的意义是现代地球动力学最重要的观测之一：若干俯冲带之下660面变平或断裂，说明下沉板片在此遇到密度和黏度的差异。板片究竟在660 km之上堆积然后崩落穿过，还是直接穿透，正是地幔对流是分层的还是全地幔的核心争论（[[physical-geology/plate-tectonics]]）。
:::
:::

## 整个地球怎么说：简正模与转动惯量

::: definition 自由振荡 {#def-modes}
特大地震会让整个地球鸣响。自引力球体的简正模是驻波：**基本球式（呼吸）模**${}_0S_0$周期$20.5\ \mathrm{min}$，测定平均不可压缩性；橄榄球形的${}_0S_2$周期$53.9\ \mathrm{min}$。扭式模使各壳层相互扭动，是探测速度随深度横向变化最干净的手段。
:::

::: proposition 地球不能是两层的 {#prop-twolayer}
设地球由密度$\rho_c$的核和密度$\rho_m$的地幔两层组成，质量和半径取观测值。要用$\rho_c = 11{,}000$、$\rho_m = 4400\ \mathrm{kg\,m^{-3}}$复现观测转动惯量因子$I/Ma^2 = 0.3308$，核半径须为$4400$–$4570\ \mathrm{km}$——远大于地震学给出的$3480\ \mathrm{km}$。因此地幔必须径向*渐变*。
:::

::: proof
对两层均匀球壳，$I = \frac{8\pi}{15}\rho_c x^5 a^5 + \frac{8\pi}{15}\rho_m(1 - x^5)a^5$，$M = \frac{4\pi}{3}[\rho_c x^3 + \rho_m(1 - x^3)]a^3$，$x$为核半径分数。消去尺度即得$I/Ma^2$作为$x$的函数；它在$x = 0.70$处取极小值$0.3307$，从不低于观测值。因此两层模型只能以极其勉强、且核远大于地震学所见的方式吻合观测。加上地幔的实际压缩——密度从中部的$3.3$升到$5.6\ \mathrm{g\,cm^{-3}}$——才能在核大小正确时把该因子降到实测值。这与[[earth-system/planet-earth]]中的论证相同，只是现在用来约束结构，而不是证明分异。
:::

::: example 地球如钟鸣响 {#ex-modes}
地球最长周期的简正模约为1小时。计算行星的动力学时间尺度$\sqrt{a^3/GM}$并与${}_0S_2$的$53.9\ \mathrm{min}$比较。
::: solution
$$
\sqrt{\frac{a^3}{GM}} = \sqrt{\frac{(6.371\times10^{6})^3}{3.986\times10^{14}}} = 805\ \mathrm{s} = 13.4\ \mathrm{min},
$$
其$2\pi$倍为$84\ \mathrm{min}$。观测的$54\ \mathrm{min}$是它的$0.64$——量级正确，因为恢复力是自引力，弹性只是修正。

其实际意义在于：简正模能测射线测不到的东西。射线给出路径平均，对最长的波长视而不见；而一个简正模是一次整地球测量，具有已知的灵敏度核。1960年瓦尔迪维亚（智利）$M_\text{w}\ 9.5$地震——有记录以来最大的一次——使自由振荡第一次可以在地面地震仪上测量，由此得到的、由自转和横向非均匀性造成的模态分裂给出了第一个足以建立PREM的一维速度剖面（Dziewonski与Anderson，1981年）。
:::
:::

::: example 给地震定大小 {#ex-moment}
2004年12月26日苏门答腊地震破裂了一条长约$1300\ \mathrm{km}$、倾向宽约$200\ \mathrm{km}$的断层，平均位错$12\ \mathrm{m}$。取$\mu = 30\ \mathrm{GPa}$。求震矩和矩震级。
::: solution
$$
M_0 = \mu A D = 3\times10^{10}\times2.6\times10^{11}\times12 = 9.4\times10^{22}\ \mathrm{N\,m},
$$
$$
M_\text{w} = \tfrac{2}{3}\left(\log_{10} M_0 - 9.1\right) = \tfrac{2}{3}(22.97 - 9.1) = 9.2 .
$$

已发表结果为$M_\text{w}\ 9.1$–$9.3$、$M_0 = (0.6$–$1.3)\times10^{23}\ \mathrm{N\,m}$，可见算法正确。两个值得记住的推论：震级对震矩取对数，因此$M_\text{w}\ 9.2$释放的震矩约为2011年东北地方太平洋近海地震（$M_\text{w}\ 9.0$，$M_0 = 4.5\times10^{22}\ \mathrm{N\,m}$）的两倍、约为2010年海地地震（$M_\text{w}\ 7.0$，$M_0 \approx 1.4\times10^{20}\ \mathrm{N\,m}$）的七百倍；另一个是区域震矩必须平衡——地震震矩之和加上无震蠕滑的震矩必须等于板块运动积累的震矩，这就是"大震缺失"地区地震危险性估计的方法（[[natural-hazards/earthquake-hazard]]、[[geophysics/earthquake-sources]]）。
:::
:::

## 深部地球的温度

::: definition 地温曲线与熔融曲线 {#def-geotherm}
**地温曲线**是温度随深度的分布。在对流的地幔中它近乎绝热，
$$
\frac{\mathrm{d}\ln T}{\mathrm{d}P} = \frac{\gamma_G}{c_P},
$$
其中$\gamma_G$为格吕奈森参数、$c_P$为比热，因此每吉帕只升高$0.3$–$0.5\ \mathrm{K}$；外推到地表，地幔位温$T_P \approx 1350\ ^\circ\mathrm{C}$。**熔融曲线**在地球熔融处位于地温曲线之下，在固体处位于其上。
:::

::: example 为什么内核是固体而外核是液体 {#ex-melting}
用锚定在$T_\text{ICB} = 5200\ \mathrm{K}$、$P_\text{ICB} = 330\ \mathrm{GPa}$处的$T_m(P) = T_\text{ICB}(P/P_\text{ICB})^{0.55}$描述铁的熔融曲线，用$T_\text{ad}(P) = 5200 - 0.5(330 - P)\ \mathrm{K}$描述核的绝热地温曲线。在核幔边界（$P = 135\ \mathrm{GPa}$）计算两者并解释。
::: solution
$135\ \mathrm{GPa}$处：$T_m = 5200\times0.409^{0.55} = 3180\ \mathrm{K}$，$T_\text{ad} = 5100\ \mathrm{K}$。核在此比铁的熔点*高*$1900\ \mathrm{K}$，故为液体。在内外核边界两曲线按构造相交，其下绝热线落到熔融曲线之下，故内核为固体。

内核之所以存在，本质上是斜率之争：铁的熔融曲线随压强急剧上升（内外核边界附近约$10\ \mathrm{K\,GPa^{-1}}$），而对流绝热线每吉帕只升约$0.5\ \mathrm{K}$。地球冷却时绝热线整体下移，首先在核的*顶部*与熔融曲线相交，因此内核由内向外生长。真正要紧的数字——核幔边界处核绝热线与熔融曲线之差，即"核的过热度"——不确定度超过$1000\ \mathrm{K}$，而它决定核能多快冷却，从而决定内核的年龄（估计为$0.5$–$1.5\ \mathrm{Gyr}$）以及地磁发电机已运行多久（[[geophysics/geomagnetism]]）。
:::
:::

::: widget plot
f: 5200*(x/330)^0.55 - (5200 - 0.5*(330-x))
x: 135, 330
y: -2200, 0
caption: 铁的熔融温度减去核的绝热地温曲线，横轴为从核幔边界（$135\ \mathrm{GPa}$）到内外核边界（$330\ \mathrm{GPa}$）的压强。整条曲线在外核内为负——金属比自身熔点更热，故为液体——只在内外核边界归零，那里固液共存。纵轴既是信号也是不确定度：指数$0.55$和锚点$5200\ \mathrm{K}$来自金刚石压砧实验和第一性原理计算，而它们彼此相差数百开尔文；内核何时开始冻结这整个问题，就悬在这个分歧上。
:::

::: warning 地幔不是熔体，外核也不是"液态岩石"
关于深部地球的公众误解，多半来自两个直觉反转。第一，地幔传递剪切波，因此有刚度，因此是固体——一个以每年几厘米流动的固体，因为它的黏度是$10^{21}$–$10^{22}\ \mathrm{Pa\,s}$而强度有限。软流圈不是熔体之海；它是橄榄岩，可能含有百分之几以下的熔体，靠晶体蠕变变形。第二，内核很可能有$5000$–$6000\ \mathrm{K}$，与太阳表面一样热，却是固体，因为那里的压强是$330\ \mathrm{GPa}$，即三百五十万个大气压。熔融是温度与压强的竞争，而深部地球是压强通常获胜的地方。
:::

::: warning 层析图不是照片
地震层析成图给出的是波速变化，地幔中通常为$0.5$–$3\%$，而图件总是在假定"速度只随温度变化"之后以温度色标显示。非洲和中太平洋下方两个巨大的低速区——大型低剪切波速省（LLSVP）——剪切波速低$2$–$3\%$，从核幔边界向上隆起数千千米。它们是热性的（热、浮力大，也许是俯冲板片残骸的堆积）、成分性的（富铁，也许是岩浆洋的残余），还是介于两者之间，至今没有定论；而答案不同，同一张图的解读就完全不同。读层析图时请记住它测的是什么：相对波速，外加一个解释（[[geophysics/seismic-structure]]）。
:::

::: quiz
为什么密度在核幔边界翻倍，而不可压缩性几乎不变？
- [ ] 因为密度的测量不如速度可靠。
- [x] 因为该界面分隔的是两种不可压缩性相近但化学不同的物质，而不是同一物质的两相。
- [ ] 因为核所受压强高得多。
- [ ] 因为地震波在金属中变慢。
::: solution
同一物质的相变会使密度和刚度一起变化，并保留刚度。这里刚度归零、密度翻倍，而$K$保持在$\sim 645\ \mathrm{GPa}$——这是金属/硅酸盐化学分界的签名。压强也不是解释：任何界面两侧压强都是*连续*的，跳变的是密度。
:::
:::

::: quiz
某层析图显示大陆之下$250\ \mathrm{km}$处剪切波速低$2\%$。哪个解释所需额外假定最少？
- [ ] 那是一个熔体囊。
- [x] 不补充信息就什么都推不出：剪切波速低$2\%$可以由几十开尔文的温度差、百分之几的熔体、各向异性或成分差异造成。
- [ ] 那是一个地幔柱。
- [ ] 那是俯冲的大洋壳。
::: solution
速度是一个数字，而原因至少有四个，因此单凭图像不构成任何证据。这就是现代研究要用*比值*（剪切与压缩异常之比$\delta\ln V_S/\delta\ln V_P$，熔体和温度造成的截然不同）、各向异性、衰减$Q$以及岩石学和大地水准面的独立约束的原因。见[[geophysics/seismic-structure]]。
:::

::: history
深部地球是在大约三十年的计时测量中建立起来的。奥尔登姆（Oldham）1906年根据穿过核的波提前到达而识别出核。莫霍洛维奇（Mohorovičić）1909年从1909年10月克尔巴瓦（Krbava）地震读出了两组P波初至，推定在约$54\ \mathrm{km}$处存在一个速度从$6$跳变到$8\ \mathrm{km\,s^{-1}}$的界面——莫霍面，上表第一个界面的发现者。古登堡（Gutenberg）1912年把核的深度定在$2900\ \mathrm{km}$，1926年又据面波路径推定$100$–$200\ \mathrm{km}$处存在一个软弱层——软流圈。杰弗里斯（Jeffreys）1926年用P波影区证明外核为液体。雷曼（Lehmann）1936年从1934年一次地震那些略微提前的初至中发现内核，这个推论大胆到杰弗里斯本人都抵制了十年。伯奇（Birch）1952年完成了决定性的综合：他在实验室测得高压下岩石的速度，证明富橄榄石地幔压缩到观测密度即可复现观测速度，而核相对铁镍合金的密度亏损要求约$10\%$的轻元素——矿物物理学由此建立，连同把岩石速度与密度联系起来的"伯奇定律"。布伦（Bullen）划出了核上方那层至今带着他字母的奇异薄层：D$''$。兰姆（Lamb）及其1880年代的后继者为自引力球体算出的自由振荡，在1960年智利地震之后成为数据；齐沃恩斯基（Dziewonski）与安德森（Anderson）1981年的PREM至今仍是标准参考地球模型。1963年《部分禁止核试验条约》需要全球地震台网监测地下爆炸，由此提供的地震目录最终确认了板块构造。
:::

## 由此通向何处

固体地球设定了其余一切的节奏：它以火山作用把碳送回大气，又通过硅酸盐风化把碳取回（[[earth-system/carbon-cycle]]）；它建造了驱动侵蚀与风化的地形（[[geomorphology/landscape-evolution]]）；它在外核产生的磁场屏蔽太阳风、保护大气（[[geophysics/geomagnetism]]、[[planetary-science/atmospheres]]）。波本身见[[geophysics/elastic-waves]]和[[geophysics/seismic-structure]]，地震见[[geophysics/earthquake-sources]]和[[natural-hazards/earthquake-hazard]]，矿物见[[mineralogy-petrology/silicates]]和[[mineralogy-petrology/phase-diagrams]]，流动见[[structural-geology/rheology]]。

::: summary
- 两个数字读出内部：$V_P = \sqrt{(K + 4\mu/3)/\rho}$与$V_S = \sqrt{\mu/\rho}$。$V_S = 0$处物质为流体。
- 跨过核幔边界密度翻倍、$V_S$归零，而$K$保持在$\sim 645\ \mathrm{GPa}$：这是化学界面，不是相变。
- 410与660 km不连续面是同一岩石的相变，克拉珀龙斜率符号相反，因此它们围绕冷热异常朝可预言的相反方向弯曲。
- 两层地球无法在观测核大小下复现$I/Ma^2 = 0.3308$：地幔必须被压缩，正如矿物物理所预言。
- 自由振荡测量射线测不到的整地球性质；1960年智利地震开启了这一领域，PREM（1981年）是其纪念碑。
- 内核是固体，因为铁的熔融曲线随压强上升快于核的绝热线；核幔边界处两者之差的不确定度超过$1000\ \mathrm{K}$，控制着核的热历史。
- 地震以$M_0 = \mu A D$定量；震级是对数，区域震矩收支必须与板块速率给出的矩源平衡。
:::

## 习题

::: exercise 由模量求速度 {level=1 check="4.5"}
上地幔橄榄岩$K = 130\ \mathrm{GPa}$、$\mu = 67\ \mathrm{GPa}$、$\rho = 3330\ \mathrm{kg\,m^{-3}}$，求$V_S$。
::: solution
$V_S = \sqrt{6.7\times10^{10}/3330} = \sqrt{2.012\times10^{7}} = 4.49\ \mathrm{km\,s^{-1}}$，与PREM的$4.48$接近。
:::
:::

::: exercise 泊松比 {level=1 check="1.83"}
某岩石$K/\mu = 2.0$，求$V_P/V_S$。
::: solution
$V_P/V_S = \sqrt{K/\mu + 4/3} = \sqrt{3.333} = 1.83$。相应泊松比$\sigma = (V_P^2/2V_S^2 - 1)/(V_P^2/V_S^2 - 1) = 0.27$。
:::
:::

::: exercise P波影区 {level=1}
震中$103^\circ$到$142^\circ$之间观测不到P波，$103^\circ$之外观测不到S波。两个影区各说明什么？
::: solution
S波影区是外核为液体的直接证据：剪切波穿不过去，因此在几何影区内没有S波。P波影区则说明核幔边界处$V_P$*下降*（从$13.7$降到$8.1\ \mathrm{km\,s^{-1}}$），使波进入核时向法线折射，留下一个只有穿过核的波（PKP）才能在$142^\circ$之外填补的空隙。注意这里的逻辑：核是靠速度下降与刚度下降的*组合*被探测到的。
:::
:::

::: exercise 核幔边界两侧的不可压缩性 {level=2 check="643"}
核幔边界之下$V_P = 8.06\ \mathrm{km\,s^{-1}}$、$V_S = 0$、$\rho = 9900\ \mathrm{kg\,m^{-3}}$。求$K$。
::: solution
$K = \rho V_P^2 = 9900\times(8060)^2 = 6.43\times10^{11}\ \mathrm{Pa} = 643\ \mathrm{GPa}$，与其上岩石的$647\ \mathrm{GPa}$基本相同。不可压缩性连续，而刚度和密度不连续。
:::
:::

::: exercise 克拉珀龙斜率 {level=2 check="17"}
取410 km不连续面$\gamma = +3\ \mathrm{MPa\,K^{-1}}$，求比周围*热*$200\ \mathrm{K}$的异常造成的深度变化（$\rho g = 3.5\times10^{4}\ \mathrm{Pa\,m^{-1}}$）。
::: solution
$\Delta z = \gamma\Delta T/\rho g = 3\times10^{6}\times200/3.5\times10^{4} = 1.7\times10^{4}\ \mathrm{m} = 17\ \mathrm{km}$，即变深。因此热地幔把410面往下推，这在洋中脊和热上升流之下已被观测到。
:::
:::

::: exercise 矩震级 {level=2 check="7.7"}
某地震破裂$200\ \mathrm{km}\times20\ \mathrm{km}$，位错$4\ \mathrm{m}$，$\mu = 30\ \mathrm{GPa}$。求$M_\text{w}$。
::: solution
$M_0 = 3\times10^{10}\times4\times10^{9}\times4 = 4.8\times10^{20}\ \mathrm{N\,m}$，故
$$
M_\text{w} = \tfrac{2}{3}(\log_{10}4.8\times10^{20} - 9.1) = \tfrac{2}{3}(20.68 - 9.1) = 7.7 .
$$
$8.0$级需要$1.3\times10^{21}\ \mathrm{N\,m}$，即同一面积上约$11\ \mathrm{m}$的位错——这就是为什么对大地震而言，*面积*和*位错*比任何一次实测位移都重要。
:::
:::

::: exercise 两层地球 {level=3}
对$\rho_c = 11{,}000$、$\rho_m = 4400\ \mathrm{kg\,m^{-3}}$的两层地球，计算核半径分数$x = 0.55$时的$I/Ma^2$，并与观测值$0.3308$比较。
::: solution
$$
\frac{I}{Ma^2} = \frac{2}{5}\cdot\frac{11000\times0.55^5 + 4400(1 - 0.55^5)}{11000\times0.55^3 + 4400(1 - 0.55^3)} = \frac{2}{5}\cdot\frac{4400 + 6600\times0.0503}{4400 + 6600\times0.1664} = \frac{2}{5}\times\frac{4732}{5498} = 0.344 .
$$

偏高$4\%$：核太小，质量向中心集中得不够。该模型只有在$x \approx 0.70$（即$4460\ \mathrm{km}$）时才能达到$0.3308$，比地球的核大$1000\ \mathrm{km}$。缺失的那部分集中由地幔内部的密度梯度提供。
:::
:::

::: exercise 核的过热度 {level=3}
用[[#ex-melting]]的曲线求熔融曲线与绝热线相差$1000\ \mathrm{K}$处的压强，并说明若整个核冷却$1000\ \mathrm{K}$内核会怎样（设压强在$1221\ \mathrm{km}$处$330\ \mathrm{GPa}$与$3480\ \mathrm{km}$处$135\ \mathrm{GPa}$之间随半径线性变化）。
::: solution
解$5200(P/330)^{0.55} = 5200 - 0.5(330 - P) - 1000$。试$P = 200$：左$3948$，右$4135$；$P = 170$：左$3630$，右$3985$；$P = 250$：左$4464$，右$4160$。差值在$P \approx 215\ \mathrm{GPa}$附近通过$1000\ \mathrm{K}$，即在今内外核边界之上约$1000\ \mathrm{km}$。

若整个核冷却$1000\ \mathrm{K}$，绝热线将在低到该压强处都落到熔融曲线之下，内核将向外长到
$$
r = 1221 + \frac{330 - 219}{330 - 135}\times(3480 - 1221) = 2500\ \mathrm{km},
$$
是现今$1221\ \mathrm{km}$的两倍多。这就是内核生长的机制，也是为什么内核年龄是一个冷却速率问题而不是成分问题。
:::
:::

::: exercise 衰减 {level=3}
周期$T = 20\ \mathrm{s}$的剪切波穿过$1000\ \mathrm{km}$品质因子$Q_S = 100$的上地幔最上部。其振幅衰减为原来的多少倍？
::: solution
振幅按$\exp(-\pi f r/V_S Q_S)$衰减。取$f = 0.05\ \mathrm{Hz}$、$r = 10^{6}\ \mathrm{m}$、$V_S = 4.5\times10^{3}\ \mathrm{m\,s^{-1}}$、$Q_S = 100$：
$$
\frac{\pi f r}{V_S Q_S} = \frac{\pi\times0.05\times10^{6}}{4.5\times10^{3}\times100} = 0.35 \quad\Longrightarrow\quad \text{因子} = e^{-0.35} = 0.70 .
$$

$1000\ \mathrm{km}$损失$30\%$的振幅——而且这种效应在软地幔和部分熔融处最强，这就是为什么$Q$成像（衰减层析）比速度成像更能显示熔体。$Q$也是远处地震高频能量消失的原因：全球台网能记录$1\ \mathrm{Hz}$的远震，记录不到$10\ \mathrm{Hz}$。
:::
:::

::: exercise 各向异性与流动 {level=3}
沿板块运动方向水平穿过上地幔最上部的地震波比垂直于该方向传播的波快$2$–$4\%$。解释这一观测并说明它测量了什么。
::: solution
橄榄石强烈各向异性：最快的P波方向$[100]$比最慢方向快约$25\%$。在软流圈中，位错蠕变使晶体快轴与流动方向对齐，于是集合体变为横向各向同性，快轴水平且平行于运动方向。因此该观测测量的是**晶格优选方位**，并由此给出板块之下地幔的现今流动方向——这是地球动力学最接近直接测量地幔流的东西。麻烦之处在于岩石圈也是各向异性的（来自过去运动的残留组构），因此必须把两者分开，通常用不同周期的剪切波分裂测量（[[structural-geology/rheology]]、[[geophysics/seismic-structure]]）。
:::
