你在山坡上捡起一块花岗岩，它的密度大约是$2700\ \mathrm{kg\,m^{-3}}$。再称一称整个地球：$5.97\times 10^{24}\ \mathrm{kg}$的质量分布在一个半径$6371\ \mathrm{km}$的球体上，得到的平均密度是$5515\ \mathrm{kg\,m^{-3}}$，是前者的两倍多。地表的岩石无法解释地球。埋藏在下面的物质必定致密得多，而其中几乎没有任何东西能被我们直接看到。我们对深部地球的全部认识——它是热的、分层的、中心以铁为主、同时既是固态又是液态——都是从这道算术题，从地震波的波速、从地球的岁差、从它的磁场和它散发的热量推断出来的。

本章是整个图谱其余部分的框架：地球是一种什么样的天体，它有多大、什么形状，从地心到地表由什么组成，内部为什么至今仍是热的，以及在行星之中它有什么特别之处。有两个观念贯穿始终。第一，地球是**分层的**，因为在行星熔融期间重物质下沉、轻物质上升。第二，地球是一台**热机**：它在形成时获得能量，通过放射性衰变不断产生新的能量，而这些热量向外散失的方式驱动了地震、火山和造山运动——而在弱得多的意义上，也驱动了天气。

## 地球是一颗吸积形成的行星

太阳和行星形成于约46亿年前一团引力坍缩的气体尘埃云。尘埃颗粒粘成砾石，砾石聚成几十千米大小的**星子**，星子再碰撞成行星。这些并非猜测：证据保存在陨石之中——它们是建造行星时剩下的原料——也保存在我们能够测定的年龄里。

最古老的陨石——从未熔融过的**球粒陨石**——给出铅-铅（Pb-Pb）等时线年龄45.67亿年（Ga），而最老的月岩和最老的地球矿物（澳大利亚杰克山（Jack Hills）的锆石，最老44.0亿年，即4.40 Ga）都要年轻一些。我们给地球本身定的年龄**4.54 Ga**，指的是吸积和核的形成基本完成的时刻，它取自同一套陨石年代学框架，因为那个时期完整的地球岩石一块也没有保存下来。大约45亿年前那次最后的大碰撞被认为形成了月球，并把年轻的地球重新熔融了一遍。

熔融是关键事件。一个天体一旦熔融就可以**分异**：铁和镍密度大，且在熔融状态下可以移动，于是穿过较轻的硅酸盐熔体向中心沉去，一路把重力势能释放为热。

::: definition 分异 {#def-differentiation}
当天体的组分按密度分离成层、平均密度向中心增大时，就称该天体已经**分异**。地球的硅酸盐地幔、致密的铁质地核和较轻的花岗质地壳，都是它在早期历史中发生分异的产物。
:::

形成月球的撞击是一连串大碰撞中的最后一次，这解释了为什么地球拥有一颗异常大的卫星：月球质量是地球的$1.2\%$，而火星的两颗小行星只及其$10^{-7}$左右，即便是巨行星最大的卫星所占比例也小得多。这颗大月球稳定了自转转轴倾角，使其免于混沌变化，这对数千万年时间尺度上的气候很重要（[[palaeoclimate/orbital-cycles]]）。

## 大小、形状与重力

地球非常接近一个球体，但并不严格如此：自转使它成为一个**旋转椭球体**，在两极被压扁。

::: definition 扁率 {#def-flattening}
对于赤道（半长）半径为$a$、两极（半短）半径为$b$的椭球，其**扁率**为

$$
f = \frac{a - b}{a}.
$$
:::

| 量 | 符号 | 数值 |
|---|---|---|
| 赤道半径 | $a$ | $6378.137\ \mathrm{km}$ |
| 极半径 | $b$ | $6356.752\ \mathrm{km}$ |
| 平均半径 | $R = 6371.00\ \mathrm{km}$ | — |
| 扁率 | $f$ | $1/298.257 = 3.353\times10^{-3}$ |
| 表面积 | $4\pi R^2$ | $5.101\times 10^{8}\ \mathrm{km^2}$ |
| 体积 | $\tfrac43\pi R^3$ | $1.083\times 10^{12}\ \mathrm{km^3}$ |
| 质量 | $M$ | $5.9722\times 10^{24}\ \mathrm{kg}$ |
| 平均密度 | $\bar\rho$ | $5515\ \mathrm{kg\,m^{-3}}$ |
| 表面重力 | $g$ | $9.82\ \mathrm{m\,s^{-2}}$（赤道$9.78$，两极$9.83$） |
| 逃逸速度 | $v_\text{esc}$ | $11.2\ \mathrm{km\,s^{-1}}$ |
| 自转角速度 | $\Omega$ | $7.292\times 10^{-5}\ \mathrm{rad\,s^{-1}}$ |

::: example 地球的平均密度 {#ex-density}
由地球的质量和平均半径计算其平均密度，并与地表岩石的密度比较。
::: solution
$$
\bar\rho = \frac{M}{\frac43\pi R^3}
= \frac{5.9722\times10^{24}\ \mathrm{kg}}{\frac43\pi\left(6.371\times10^{6}\ \mathrm{m}\right)^{3}}
= \frac{5.9722\times10^{24}}{1.0832\times10^{21}}
= 5513\ \mathrm{kg\,m^{-3}},
$$

通常写作$5515\ \mathrm{kg\,m^{-3}}$。大陆地壳平均为$2700\ \mathrm{kg\,m^{-3}}$，即使最重的地表岩石也只达到约$3000\ \mathrm{kg\,m^{-3}}$。压缩会提高密度，但硅酸盐岩石在地球内部任何压力下都远低于$5500\ \mathrm{kg\,m^{-3}}$；整个地幔的平均密度约为$4500\ \mathrm{kg\,m^{-3}}$。这个差额只能由本身就很致密的物质来补足——一个铁质地核。这一个数字，只要有了1798年卡文迪许（Cavendish）测出的$G$和公元前240年前后埃拉托色尼（Eratosthenes）测出的$R$就能算出来，是关于金属地核最古老也最简洁的论证。
:::
:::

::: example 赤道到底"扁"了多少？ {#ex-flatten}
求赤道半径与极半径之差，并解释为什么赤道上的$g$较小。
::: solution
$$
a - b = af = 6378.137\ \mathrm{km}\times 3.3528\times10^{-3} = 21.4\ \mathrm{km}.
$$

有两个效应使赤道上的$g$（$9.78\ \mathrm{m\,s^{-2}}$）小于两极的$g$（$9.83\ \mathrm{m\,s^{-2}}$）。第一，你比在两极时离地心远了$21.4\ \mathrm{km}$，相当于$(a/R)^2 \approx 0.2\%$。第二，也是更大的一个，重力的一部分要用来提供自转所需的向心加速度：在赤道上$\Omega^2 a = (7.292\times10^{-5})^2\times6.378\times10^{6} = 0.034\ \mathrm{m\,s^{-2}}$，约为$g$的$0.35\%$。实测差值$0.52\%$接近两者之和；而扁率本身就是重力场必须与之自洽的那个形状——一个**等位面**，即*大地水准面*，详见[[geophysics/gravity-isostasy]]。
:::
:::

逃逸速度还关系到一件非常实际的事：它决定一个行星能留住哪些气体。

::: proposition 留住大气 {#prop-retention}
逃逸速度为$v_\text{esc}$的行星，只有当

$$
v_\text{esc} \gtrsim 6\,v_\text{rms}, \qquad v_\text{rms} = \sqrt{\frac{3kT}{m}},
$$

时，才能在太阳系年龄这么长的时间里留住外逸层温度为$T$、分子质量为$m$的气体，其中$k$为玻尔兹曼常数。系数6是经验值：即使分子热运动的典型速率低得多，麦克斯韦-玻尔兹曼分布的高速尾部在数十亿年中也会逐渐漏失。
:::

::: proof
麦克斯韦-玻尔兹曼分布给出，速率大于$v$的分子数正比于$\left(1 + \frac{mv^2}{2kT}\right)e^{-mv^2/2kT}$向上积分。取$v = v_\text{esc}$，单次经过散逸边界时能够逃逸的分子比例按$e^{-x^2}$衰减，其中$x = v_\text{esc}/v_\text{mp}$，$v_\text{mp} = \sqrt{2kT/m}$。当$x < 5$时，45亿年间的损失十分可观；当$x > 6$时大气得以留存。把该判据用$v_\text{rms} = \sqrt{3kT/m}$写出来，就得到上面的规则。这是一条经验规则，不是定理：非热逃逸（溅射、电荷交换、极风）可以从不带磁场的行星上剥离较重的成分，太阳对火星就是这样做的。
:::

::: example 地球能留住哪些气体？ {#ex-gases}
计算$288\ \mathrm{K}$下$\mathrm{H_2}$、He、$\mathrm{H_2O}$、$\mathrm{N_2}$和$\mathrm{CO_2}$的$v_\text{rms}$，判断地球能留住哪些。
::: solution
由$v_\text{rms} = \sqrt{3kT/m}$，其中$m = \mu m_\text{u}$（$m_\text{u} = 1.6605\times10^{-27}\ \mathrm{kg}$）：

| 气体 | $\mu$ | $288\ \mathrm{K}$下的$v_\text{rms}$ | $6v_\text{rms}$ | 能否留住 |
|---|---|---|---|---|
| $\mathrm{H_2}$ | 2 | $1895\ \mathrm{m\,s^{-1}}$ | $11.4\ \mathrm{km\,s^{-1}}$ | 勉强，已丢失 |
| He | 4 | $1340\ \mathrm{m\,s^{-1}}$ | $8.0\ \mathrm{km\,s^{-1}}$ | 缓慢丢失 |
| $\mathrm{H_2O}$ | 18 | $632\ \mathrm{m\,s^{-1}}$ | $3.8\ \mathrm{km\,s^{-1}}$ | 能 |
| $\mathrm{N_2}$ | 28 | $507\ \mathrm{m\,s^{-1}}$ | $3.0\ \mathrm{km\,s^{-1}}$ | 能 |
| $\mathrm{CO_2}$ | 44 | $404\ \mathrm{m\,s^{-1}}$ | $2.4\ \mathrm{km\,s^{-1}}$ | 能 |

比较对象是$v_\text{esc} = 11.2\ \mathrm{km\,s^{-1}}$，并注意相关温度是**外逸层**（100 km以上，那里温度可达$1000\ \mathrm{K}$，紫外光还能把水分子拆开）的温度，而不是地表温度。氢在$1000\ \mathrm{K}$时$v_\text{rms} = 3.5\ \mathrm{km\,s^{-1}}$，于是$6v_\text{rms} = 21\ \mathrm{km\,s^{-1}} > v_\text{esc}$：地球自形成以来一直在漏失氢，因而也在漏失水。氮和二氧化碳则远远安全。这就是地球大气是氮气而不是氢气的原因；而木星和土星的逃逸速度分别为$60$和$35\ \mathrm{km\,s^{-1}}$，因此保住了太阳星云中的氢和氦。
:::
:::

## 分层的内部

我们钻探最深不过约$12\ \mathrm{km}$，最深的科学钻孔（苏联科拉超深钻孔，$12.265\ \mathrm{km}$，1989年完钻）遇到$180\ ^\circ\mathrm{C}$，比预期浅得多。钻孔以下的一切知识都来自地震波：波穿过物质发生变化的地方时速度会改变。由于波在速度突变的界面上会折射和反射，地震记录就给出了地球内部的一个剖面。

| 圈层 | 深度范围 | 密度 | 状态 |
|---|---|---|---|
| 海洋 | 0–11 km | 1028 | 液态 |
| 大陆地壳 | 0–70 km（平均35） | 2700 | 固态 |
| 大洋地壳 | 6–12 km | 2900–3000 | 固态 |
| 上地幔 | 至410 km | 3300–3900 | 固态 |
| 过渡带 | 410–660 km | 3900–4400 | 固态 |
| 下地幔 | 至2891 km | 4400–5500 | 固态 |
| 外核 | 2891–5150 km | 9900–12200 | 液态 |
| 内核 | 5150–6371 km | 12700–13000 | 固态 |

主要界面的名称和深度：**莫霍面**（地壳/地幔，5–70 km，安德里亚·莫霍洛维奇（Mohorovičić）1909年依据巴尔干半岛地震记录中P波的双初至发现）；410 km和660 km不连续面（橄榄石的矿物相变，而非成分变化）；**核-幔边界**位于2891 km（奥尔德姆（Oldham）1906年识别，深度由古登堡（Gutenberg）1914年确定）；**内核边界**位于5150 km（英格·莱曼（Lehmann）1936年）。S波不能穿过外核，因此外核是液态；震中距$104^\circ$到$140^\circ$之间的P波阴影区是最经典的证据。

::: definition 地震不连续面 {#def-discontinuity}
**地震不连续面**是指地震波波速发生突变、其变化量无法用平滑梯度解释的界面。不连续面要么标志成分的改变（莫霍面、核-幔边界），要么标志成分几乎不变而晶体结构的改变（410 km和660 km不连续面）。
:::

有两个彼此独立的事实证实密度向深处急剧升高。第一是**转动惯量**。

::: proposition 转动惯量与中心集中 {#prop-moi}
均匀球的转动惯量为$I = \frac{2}{5}MR^2$。对任何密度向中心增大的球体，都有$I < \frac{2}{5}MR^2$。比值

$$
\frac{I}{MR^2}
$$

称为**归一化转动惯量**，它度量质量向中心集中的程度。地球的值为$0.3307$。
:::

::: proof
对球对称物体，$I = \int_0^R \frac{2}{3}\pi\rho(r) r^4\,\mathrm{d}r$（半径为$r$、质量为$\mathrm{d}m$的薄壳贡献$\tfrac23 r^2\mathrm{d}m$），而$M = \int_0^R 4\pi\rho(r) r^2\,\mathrm{d}r$。若$\rho$为常数，则$I = \frac{2}{3}\pi\rho R^5/5$，$M = \frac{4}{3}\pi\rho R^3$，故$I/MR^2 = \frac{2}{5}$。把一小块质量$\delta m$从半径$r_2$移到更小的半径$r_1$，$I$减少$\tfrac23\delta m (r_2^2 - r_1^2) > 0$，而$M$不变。因此任何质量的向内集中都会使该比值低于$0.4$，而且它越低于$0.4$，天体的集中程度就越高。
:::

::: example 一个三层地球模型 {#ex-moi}
取一个粗略模型：内核$\rho = 13000\ \mathrm{kg\,m^{-3}}$，延伸至$1220\ \mathrm{km}$；外核$\rho = 11000\ \mathrm{kg\,m^{-3}}$，延伸至$3480\ \mathrm{km}$；地幔$\rho = 4500\ \mathrm{kg\,m^{-3}}$，延伸至$6371\ \mathrm{km}$。求它的质量和归一化转动惯量。
::: solution
各壳层质量，$m = \frac43\pi\rho(r_1^3 - r_0^3)$：

$$
m_\text{ic} = 1.00\times10^{23},\quad m_\text{oc} = 1.85\times10^{24},\quad m_\text{man} = 4.08\times10^{24}\ \mathrm{kg},
$$

合计$M = 6.04\times10^{24}\ \mathrm{kg}$，与真值相差不到$1\%$。对球壳，$I = \frac{8}{15}\pi\rho(r_1^5 - r_0^5)$，于是

$$
I = \frac{8}{15}\pi\left[13000(1.22\times10^{6})^5 + 11000\left((3.48\times10^{6})^5 - (1.22\times10^{6})^5\right) + 4500\left((6.371\times10^{6})^5 - (3.48\times10^{6})^5\right)\right],
$$

得$I = 8.47\times10^{37}\ \mathrm{kg\,m^2}$，从而

$$
\frac{I}{MR^2} = \frac{8.47\times10^{37}}{6.04\times10^{24}\times(6.371\times10^{6})^2} = 0.346 .
$$

由地球的岁差以及日月对其赤道隆起的力矩得到的观测值是$0.3307$。我们的三层模型集中得稍为过头了一点；真实地球的密度因压缩而随深度平滑上升，地幔底部的密度高于顶部。无论如何，$0.33 \ll 0.40$明白地告诉我们地球不是均匀的：它有一个沉重的核心。作为对比，月球的值是$0.393$（几乎未分异），火星是$0.366$，而水星——半径只有地球的$55\%$——却是$0.346$：水星几乎全是一个铁核。
:::
:::

第二是压力。在行星深处，上覆岩石的重量必须得到支撑。

::: proposition 静力平衡方程 {#prop-hydrostatic}
在自身重力作用下处于静止的天体内，压力随深度增加的速率为

$$
\frac{\mathrm{d}P}{\mathrm{d}z} = \rho g,
$$

其中$z$为深度，$\rho$为密度，$g$为重力加速度。
:::

::: proof
考虑深度$z$处一块水平面积为$A$、厚度为$\delta z$的岩石板。它的重量为$\rho g A\,\delta z$。它由底面上$P + \delta P$的压强支撑，顶面受到$P$的压强，因此净向上力为$\delta P A$。令力平衡，$\delta P A = \rho g A\,\delta z$，再令$\delta z \to 0$即得结果。这里的假设是物质在这些尺度上没有强度——对整个地球在地质时间尺度上这是成立的；只有承载地形重量的那层薄薄弹性层是例外（[[geophysics/gravity-isostasy]]）。
:::

::: example 地幔底部的压力 {#ex-pressure}
用[[#ex-moi]]中的三层模型估算核-幔边界和地心的压力。
::: solution
从地表到核-幔边界是$2891\ \mathrm{km}$厚的地幔，$\rho = 4500\ \mathrm{kg\,m^{-3}}$，而$g$在其中只在$9.9$到$10.8\ \mathrm{m\,s^{-2}}$之间变化，于是

$$
P_\text{CMB} \approx \rho g \Delta z = 4500 \times 10.2 \times 2.891\times10^{6} = 1.3\times10^{11}\ \mathrm{Pa} = 130\ \mathrm{GPa}.
$$

认真积分$\int\rho g\,\mathrm{d}z$（取$g(r) = Gm(r)/r^2$）得$126\ \mathrm{GPa}$；参考地震模型PREM给出$136\ \mathrm{GPa}$。继续积分到地心，那里$g$降为零（你脚下没有质量），同一积分给出$347\ \mathrm{GPa}$，而PREM给出$360\ \mathrm{GPa}$。因此地心的压力约为地表大气压的$360$万倍，温度估计为$5700$–$6000\ \mathrm{K}$，与太阳表面相当——然而内核却是固态的，因为那样大的压力把铁的熔点提升到了当地温度之上。
:::
:::

x: 0, 6400

caption: 简单分层模型中密度随距地心距离的变化（PREM的平滑曲线与之十分接近）。在$3480\ \mathrm{km}$处密度从约$5500$跳到约$10000\ \mathrm{kg\,m^{-3}}$，这就是核-幔边界：一个在行星尺度上薄如刀刃的界面上密度翻了一倍。右端那个细窄的尖峰是地壳，只占半径的$0.5\%$。

## 地球内部为什么仍然是热的

内部之所以热有两个原因。它生来就热——吸积、核的形成和月球撞击都释放能量；同时钾-40、铀-238、铀-235和钍-232的放射性衰变不断产生新的热，这些元素主要集中在地壳和地幔。地球现在正以可测量的速率向太空散热。

::: definition 热流 {#def-heatflow}
**地温梯度**是温度随深度增加的速率，大陆地壳中通常为$25$–$30\ \mathrm{K\,km^{-1}}$。地表**热流**是导热热通量

$$
q = -k\frac{\mathrm{d}T}{\mathrm{d}z},
$$

其中$k$为热导率（地壳岩石为$2.5$–$3.0\ \mathrm{W\,m^{-1}\,K^{-1}}$）。全球平均$q \approx 87\ \mathrm{mW\,m^{-2}}$，总计$47 \pm 2\ \mathrm{TW}$（$1\ \mathrm{TW} = 10^{12}\ \mathrm{W}$；Davies & Davies，2010年）。
:::

::: proposition 通过平板的导热热流 {#prop-slab}
若热量只以导热方式穿过厚度为$D$、两侧温差为$\Delta T$的一层，则热流为$q = k\,\Delta T/D$，行星的总散热量为$4\pi R^2 k\Delta T/D$。
:::

::: proof
稳态下通过该层各表面的热通量相同，因此取常热导率的傅里尔定律$q = -k\,\mathrm{d}T/\mathrm{d}z$，在边界温度$T_1$与$T_2$之间积分，得到线性温度分布：$\mathrm{d}T/\mathrm{d}z = (T_2 - T_1)/D$。取绝对值即得$q = k\Delta T/D$。乘以地球表面积就得到总散热量。假设条件是稳态、层内无内生热、且没有熔融或流体流动携带热量；在软流圈地幔对流携热的地方，穿过给定厚度的有效热通量比单纯导热所允许的大得多，而深部地幔中的地温梯度则比岩石圈中小得多。
:::

::: example 地球的热量收支 {#ex-heatflow}
估算热量通过$100\ \mathrm{km}$厚的大陆岩石圈底部的导热热流，取$\Delta T = 1300\ \mathrm{K}$，并算出整个行星的散热量。与太阳辐射比较。
::: solution
取$k = 3.0\ \mathrm{W\,m^{-1}\,K^{-1}}$，$D = 1.0\times10^{5}\ \mathrm{m}$，$\Delta T = 1300\ \mathrm{K}$，

$$
q = \frac{3.0 \times 1300}{1.0\times10^{5}} = 3.9\times10^{-2}\ \mathrm{W\,m^{-2}} = 39\ \mathrm{mW\,m^{-2}} .
$$

实测大陆热流平均约$65\ \mathrm{mW\,m^{-2}}$（大洋盆地约$54\ \mathrm{mW\,m^{-2}}$，洋脊附近更高），所以单一导热盖层低估了散热量——软流圈中的对流和地壳中的生热元素补上了差额。对整个行星，

$$
4\pi R^2 q = 5.10\times10^{14}\ \mathrm{m^2}\times 87\times10^{-3}\ \mathrm{W\,m^{-2}} = 4.4\times10^{13}\ \mathrm{W} = 44\ \mathrm{TW},
$$

与评估值$47\ \mathrm{TW}$接近。其中大约一半来自放射性衰变，一半来自形成时残留热量的冷却。现在把地表吸收的平均太阳功率（约$240\ \mathrm{W\,m^{-2}}$，见[[earth-system/energy-balance]]）与内部热通量$0.087\ \mathrm{W\,m^{-2}}$比较：太阳提供的能量约是地球内部热流的$2800$倍。火山作用和板块构造是由这一微小份额驱动的；天气则不是。就此意义而言，地热能对人类确实是一种可再生的能量流，但它十分稀薄。
:::
:::

::: warning 地心不是热是因为太阳
内部热量和地表热量几乎是彼此独立的收支。地温梯度存在是因为内部正在冷却，它不受大气中发生的事情的影响：$1\ \mathrm{K}$的地表温度变化通过扩散在一千年内只向下传播约$100\ \mathrm{m}$（[[geophysics/heat-flow]]）。反过来，从内部逸出的$47\ \mathrm{TW}$只是地表所吸收太阳能的$1/2800$，无法使气候变暖。所谓"火山释放的热量比太阳还多"或"全球变暖不过是地热"之类的说法，把两个收支搞混了，差了大约三个数量级。
:::

## 什么让地球适合居住

::: definition 宜居带 {#def-hz}
一颗恒星的**宜居带**是指其行星拥有相当大气时地表能够维持液态水的轨道距离范围。对当前的太阳而言大致是$0.95$–$1.67\ \mathrm{AU}$（Kopparapu等，2013年）；地球位于$1.00\ \mathrm{AU}$。
:::

地球并不只是"离太阳的距离刚好合适"。有好几件事必须同时成立，而其中每一件在本图谱中都是一个独立的研究领域。

- **液态水。** 地表压力和温度高于水的三相点（$0.01\ ^\circ\mathrm{C}$，$611\ \mathrm{Pa}$），因此水可以同时以液态、固态和气态存在。这种共存驱动了水循环（[[earth-system/water-cycle]]），并使行星拥有巨大的热容量。
- **二氧化碳恒温器。** 火山供给$\mathrm{CO_2}$；硅酸盐风化和碳酸盐埋藏把它移除，而风化在温暖时加快。结果是一个负反馈，它在太阳自海洋形成以来已增亮约$30\%$的情况下，仍使气候保持宜居——这就是"黯淡年轻太阳"疑难，其解答是早期地球温室气体含量更高（[[earth-system/carbon-cycle]]、[[palaeoclimate/deep-time]]）。
- **板块构造**，它循环地壳、驱动长周期碳循环，并塑造出岩石与海洋之间的地形反差。
- **磁场**，由液态外核中的对流产生（地球发电机，[[geophysics/palaeomagnetism]]），它使太阳风偏转。火星在约40亿年前失去了磁场，此后大气一直在流失。
- **一颗大月球**稳定转轴倾角；还有一颗**外部的巨行星**（木星），它在输送还是偏转撞击体方面所起的作用仍有争议。

::: example 三颗行星，三种命运 {#ex-venus-mars}
金星在大气层顶接收$2613\ \mathrm{W\,m^{-2}}$的太阳辐射，地球为$1362\ \mathrm{W\,m^{-2}}$，然而金星表面约$735\ \mathrm{K}$，地球表面平均只有$288\ \mathrm{K}$。火星接收$590\ \mathrm{W\,m^{-2}}$，表面平均温度接近$210\ \mathrm{K}$。估算没有大气时地球的温度，并说明这些差别意味着什么。
::: solution
取反照率$\alpha = 0.30$且没有大气，平衡式$\frac{S_0}{4}(1 - \alpha) = \sigma T^4$给出

$$
T = \left(\frac{1362\times0.70}{4\times5.67\times10^{-8}}\right)^{1/4} = 255\ \mathrm{K},
$$

比观测值$288\ \mathrm{K}$低$33\ \mathrm{K}$——这个差值就是现今自然温室效应的大小（[[earth-system/energy-balance]]）。金星在同样反照率下应为$328\ \mathrm{K}$，实际却是$735\ \mathrm{K}$，也就是说在它比地球厚$92$倍、几乎全由$\mathrm{CO_2}$组成的大气之下，失控温室额外增加了约$400\ \mathrm{K}$。火星的大气质量只有我们的$1\%$，温室效应微乎其微，其平均温度只略高于自身无大气时的约$215\ \mathrm{K}$。教训是：与太阳的距离决定可用的能量，而大气决定温度——大气可以让一颗行星偏离仅由日射决定的温度达**数百**开尔文。这正是本图谱所有气候课程的物理背景。
:::
:::

::: quiz
地球平均密度为$5515\ \mathrm{kg\,m^{-3}}$，而地表岩石平均只有$2700\ \mathrm{kg\,m^{-3}}$。这告诉我们什么？
- [ ] 地球必定主要由水组成。
- [x] 深部内部必定含有比地表岩石致密得多的物质。
- [ ] 地表岩石必定是被压缩过的深部岩石。
- [ ] 平均密度一定算错了，因为密度不可能随深度增加。
::: solution
压缩会提高密度，但硅酸盐岩石在地球内任何压力下都达不到$5500\ \mathrm{kg\,m^{-3}}$，而整个地幔的平均密度只有约$4500\ \mathrm{kg\,m^{-3}}$。差额只能来自本身致密的物质——富铁地核；它的存在由转动惯量、由S波无法穿过外核、由铁陨石的密度分别独立地得到证实。
:::
:::

::: quiz
内核比太阳表面还热，为什么却是固态的？
- [ ] 因为它由岩石而不是金属组成。
- [ ] 因为它太小，无法导出热量。
- [x] 因为在$360\ \mathrm{GPa}$的压力下，铁的熔点被提升到当地温度之上。
- [ ] 因为它仍在从月球撞击以来的冷却过程中，尚未达到平衡。
::: solution
熔化同时取决于温度和压力。铁的熔化曲线随压力急剧上升；在内核压力下，平衡熔化温度高于实际温度，所以那里铁是固态的，而在压力较低、紧邻其外的外核中是液态的。地震学同时显示了这两点：外核不传S波，而内核能反射和透射S波。
:::
:::

::: warning 地壳并不是托住地表的壳
地壳很薄：大洋下$5$–$10\ \mathrm{km}$，大陆下$30$–$70\ \mathrm{km}$——相对于地球半径，大约相当于一张纸相对于一个足球。大陆并不是"浮在地壳上"，而是浮在密度更高的*地幔*上，而且真正发生弯曲和漂浮的是整个岩石圈（地壳加上地幔顶部冷的刚性部分）（[[geophysics/gravity-isostasy]]）。此外地幔也不是岩浆之海：它能传播S波，所以是固态的，只在数百万年间通过蠕变缓慢流动。
:::

::: history
地球的形状早在其内部结构之前就被争论过。1671年让·皮卡尔（Picard）精确测定了1个纬度的长度；艾萨克·牛顿（Newton）在《自然哲学的数学原理》（*Principia*，1687年）中预言自转应使地球变扁，而巴黎的卡西尼（Cassini）家族却测得它是长球的形状。皮埃尔-路易·莫佩尔蒂（Maupertuis）1736–37年率队前往拉普兰，另一支队伍前往秘鲁，发现纬度1度的长度在高纬度更长：牛顿是对的，扁率为$1/298$。乔治·艾里（Airy）在苏格兰一座山上用摆做的测量（1854年）表明山体具有深部的低密度根，这是均衡现象的最早证据。随后在1909年，莫霍洛维奇发现巴尔干半岛下方的地震波有两组初至，意味着约$54\ \mathrm{km}$深处存在波速跃变；理查德·奥尔德姆（Oldham）早在1906年就已识别出核的阴影区，贝诺·古登堡（Gutenberg）在1914年把其深度定为$2891\ \mathrm{km}$，英格·莱曼（Lehmann）则于1936年从阴影区内微弱的P波初至中发现了内核。弗朗西斯·伯奇（Birch）1952年的论文《地球内部的弹性与组成》给地核的成分标上了数值，至今仍是所有现代模型的基石。
:::

## 由此通向何处

本图谱其余每一门课程都在展开这幅框架的一部分。这里描述的分层，在[[physical-geology]]和[[mineralogy-petrology]]（岩石是什么）以及[[geophysics]]（我们如何知道）中被细化。散失的热量驱动了[[structural-geology]]、[[natural-hazards]]和[[earth-resources]]。[[#ex-venus-mars]]中谈到的能量收支是[[earth-system/energy-balance]]的主题，而让金星、火星与我们如此不同的大气，将在[[meteorology]]、[[atmospheric-dynamics]]和[[climate-system]]中展开。下一章[[earth-system/reservoirs-fluxes]]给出所有课程共用的记账语言——储库、通量、滞留时间与反馈。

::: summary
- 地球由吸积形成，年龄$4.54\ \mathrm{Ga}$；最老的矿物为$4.40\ \mathrm{Ga}$，陨石给出$4.567\ \mathrm{Ga}$。熔融使重金属下沉：行星已经**分异**。
- 形状与大小：$a = 6378.1\ \mathrm{km}$，$b = 6356.8\ \mathrm{km}$，扁率$1/298.26$；质量$5.972\times10^{24}\ \mathrm{kg}$；平均密度$5515\ \mathrm{kg\,m^{-3}}$；$v_\text{esc} = 11.2\ \mathrm{km\,s^{-1}}$。
- 平均密度和转动惯量因子$I/MR^2 = 0.3307$（均匀球应为$0.4$）都要求一个致密、向中心集中的内部。
- 结构：地壳（$2700\ \mathrm{kg\,m^{-3}}$）、固态地幔至$2891\ \mathrm{km}$、液态外核、$5150\ \mathrm{km}$处以下为固态内核；核-幔边界压力$136\ \mathrm{GPa}$，地心$360\ \mathrm{GPa}$。
- 压力按$\mathrm{d}P/\mathrm{d}z = \rho g$随深度增加；热量按$q = k\,\Delta T/D$散失，全球总计$47\ \mathrm{TW}$——只是地表吸收的太阳能的$1/2800$。
- 宜居需要液态水、$\mathrm{CO_2}$恒温器、板块构造、磁场和稳定的转轴倾角，而不仅仅是与太阳的合适距离。
- 逃逸速度与分子热运动速率之比决定行星能留住哪些气体：地球留住$\mathrm{N_2}$和$\mathrm{CO_2}$，但漏失氢。
:::

## 习题

::: exercise 另一个世界的平均密度 {level=1 check="3346"}
月球质量$7.35\times10^{22}\ \mathrm{kg}$，半径$1737.4\ \mathrm{km}$。计算其平均密度（单位$\mathrm{kg\,m^{-3}}$），并说明它对月球内核意味着什么。
::: solution
$$
\bar\rho = \frac{M}{\frac43\pi R^3} = \frac{7.35\times10^{22}}{\frac43\pi\left(1.7374\times10^{6}\right)^{3}} = \frac{7.35\times10^{22}}{2.197\times10^{19}} = 3346\ \mathrm{kg\,m^{-3}} .
$$
这个值只比月壳斜长岩的密度（$2900\ \mathrm{kg\,m^{-3}}$）高一点，而远低于地球的$5515\ \mathrm{kg\,m^{-3}}$。月球不可能含有多少铁：其核至多占质量的几个百分点，而地球的地核占$32\%$。再加上它$0.393$的转动惯量因子，这就是为什么月球被描述为*几乎*没有分异——也是为什么它那很小、部分熔融的核今天已不能产生发电机磁场。
:::
:::

::: exercise 自转行星的扁率 {level=1 check="0.00669"}
某行星赤道半径$6600\ \mathrm{km}$，极半径$6556\ \mathrm{km}$。求其扁率。
::: solution
$f = (a - b)/a = (6600 - 6556)/6600 = 44/6600 = 6.69\times10^{-3}$，约为地球的两倍。
:::
:::

::: exercise 由地温梯度求热流 {level=1 check="75"}
某钻孔中温度每千米上升$30\ \mathrm{K}$。取$k = 2.5\ \mathrm{W\,m^{-1}\,K^{-1}}$。热流是多少（单位$\mathrm{mW\,m^{-2}}$）？
::: solution
$q = k\,\mathrm{d}T/\mathrm{d}z = 2.5 \times 30/1000 = 0.075\ \mathrm{W\,m^{-2}} = 75\ \mathrm{mW\,m^{-2}}$。
:::
:::

::: exercise 高空的逃逸速度 {level=2 check="10.5"}
求地面上空$800\ \mathrm{km}$处的逃逸速度（单位$\mathrm{km\,s^{-1}}$，取$GM = 3.986\times10^{14}\ \mathrm{m^3\,s^{-2}}$）。
::: solution
$v_\text{esc} = \sqrt{2GM/r}$，其中$r = 6371 + 800 = 7171\ \mathrm{km}$：
$$
v_\text{esc} = \sqrt{\frac{2\times3.986\times10^{14}}{7.171\times10^{6}}} = 10\,540\ \mathrm{m\,s^{-1}} \approx 10.5\ \mathrm{km\,s^{-1}} .
$$
:::
:::

::: exercise 哪种气体会逃逸？ {level=2}
外逸层温度可达$1000\ \mathrm{K}$。用$6v_\text{rms} < v_\text{esc}$判据判断地球能否留住原子氢（H）和原子氧（O）。
::: solution
$v_\text{rms} = \sqrt{3kT/m}$，$v_\text{esc} = 11.2\ \mathrm{km\,s^{-1}}$，故留住气体需要$v_\text{rms} < 1.87\ \mathrm{km\,s^{-1}}$，即$m > 3kT/(1.87\times10^{3})^2 = 3\times1.381\times10^{-23}\times1000/3.50\times10^{6} = 1.18\times10^{-26}\ \mathrm{kg} = 7.1\ m_\text{u}$。原子氢（$1\ m_\text{u}$）远不满足而逃逸；原子氧（$16\ m_\text{u}$）的$v_\text{rms} = 1.29\ \mathrm{km\,s^{-1}}$，按此判据可以留住。实际上氧也通过非热过程从大气顶部散失，火星上曾经的水留下的氧在地质记录中大多就是这样丢失的。
:::
:::

::: exercise 两层行星的转动惯量 {level=2}
一半径为$R$的行星有一个半径$0.5R$、密度$8000\ \mathrm{kg\,m^{-3}}$的核，外包密度$3500\ \mathrm{kg\,m^{-3}}$的地幔。求其平均密度和归一化转动惯量。它比地球更集中还是更不集中？
::: solution
$M = \frac43\pi R^3\left[8000(0.5)^3 + 3500(1 - 0.125)\right] = \frac43\pi R^3(1000 + 3063)$，故$\bar\rho = 4063\ \mathrm{kg\,m^{-3}}$。对球壳用$I = \frac{8}{15}\pi\rho(r_1^5 - r_0^5)$，
$$
\frac{I}{MR^2} = \frac{0.4\left[8000(0.5)^5 + 3500(1 - 0.03125)\right]}{4063} = \frac{0.4(250 + 3391)}{4063} = 0.358 .
$$
这个值比地球的$0.3307$更接近$0.4$，所以这颗模型行星尽管有很重的核，其集中程度却*低于*地球：地球的核既更致密，比例上也更大（半径$0.546R$）。
:::
:::

::: exercise 大洋地壳底部的压力 {level=2 check="0.23"}
估算洋底下$10\ \mathrm{km}$深处的压力，取$3\ \mathrm{km}$海水（$\rho = 1028\ \mathrm{kg\,m^{-3}}$）覆盖$7\ \mathrm{km}$玄武质地壳（$\rho = 2900\ \mathrm{kg\,m^{-3}}$），$g = 9.8\ \mathrm{m\,s^{-2}}$。答案以$\mathrm{GPa}$为单位。
::: solution
在两层中积分$\mathrm{d}P/\mathrm{d}z = \rho g$，取$g$为常数，

$$
P = g\sum_i \rho_i z_i = 9.8\left(1028\times3000 + 2900\times7000\right) = 9.8\left(3.08\times10^{6} + 2.03\times10^{7}\right) = 2.29\times10^{8}\ \mathrm{Pa} = 0.23\ \mathrm{GPa}.
$$

因此大洋地壳底部只有约零点几个吉帕——再次提醒我们地壳有多薄。在地幔中$100\ \mathrm{km}$深处压力已达$3\ \mathrm{GPa}$，而地幔底部为$136\ \mathrm{GPa}$。
:::
:::

::: exercise 黯淡的年轻太阳 {level=3}
自38亿年前以来太阳输出增加了约$30\%$。若地球的反照率和大气始终不变，以$255\ \mathrm{K}$辐射平衡温度为基准，地表温度会低多少？这对早期大气意味着什么？
::: solution
$T \propto S^{1/4}$，所以$T(3.8\ \mathrm{Ga}) = 255\times(1/1.30)^{1/4} = 255\times0.9346 = 238\ \mathrm{K}$，即低$17\ \mathrm{K}$。若温室效应增量保持$33\ \mathrm{K}$不变，地表将接近$271\ \mathrm{K}$，处于冰点或以下——然而地质证据（液态水存在，除稍晚时期外没有那时的冰川沉积）显示地表是宜居的。解答在于温室效应增量当时更大：$\mathrm{CO_2}$可能达到工业革命前的$10$–$100$倍，再加上甲烷，这就是黯淡年轻太阳疑难的标准解答。注意$T \propto S^{1/4}$只是一个零维估算；见[[earth-system/energy-balance]]。
:::

::: exercise 放射性生热 {level=3}
花岗岩含铀约$3.5\ \mathrm{ppm}$、钍$12\ \mathrm{ppm}$、钾$4\%$（按质量计）。$^{238}\mathrm{U}$、$^{232}\mathrm{Th}$和$^{40}\mathrm{K}$衰变链的释热率分别约为每千克元素$1.0\times10^{-4}$、$2.8\times10^{-5}$和$5.0\times10^{-9}\ \mathrm{W}$。求密度$2700\ \mathrm{kg\,m^{-3}}$的花岗岩的单位体积生热量，以及$15\ \mathrm{km}$厚这样一层岩石所能提供的热流。
::: solution
每千克岩石，
$$
A = 3.5\times10^{-6}\times1.0\times10^{-4} + 1.2\times10^{-5}\times2.8\times10^{-5} + 0.04\times5.0\times10^{-9}
= (3.5 + 3.4 + 2.0)\times10^{-10} = 8.9\times10^{-10}\ \mathrm{W\,kg^{-1}} .
$$

每立方米，$A_\text{v} = 8.9\times10^{-10}\times2700 = 2.4\times10^{-6}\ \mathrm{W\,m^{-3}} = 2.4\ \mu\mathrm{W\,m^{-3}}$，正是花岗岩的典型值（$1$–$4\ \mu\mathrm{W\,m^{-3}}$）。$15\ \mathrm{km}$厚的一层可提供

$$
q = A_\text{v} D = 2.4\times10^{-6}\times1.5\times10^{4} = 3.6\times10^{-2}\ \mathrm{W\,m^{-2}} = 36\ \mathrm{mW\,m^{-2}},
$$

超过全球平均热流的一半。但花岗岩并非均匀铺满地壳：大陆上地壳平均生热率只有约$1\ \mu\mathrm{W\,m^{-3}}$，$15\ \mathrm{km}$厚给出约$15\ \mathrm{mW\,m^{-2}}$，而且生热元素集中在顶部几千米。$87\ \mathrm{mW\,m^{-2}}$平均值中剩下的三分之二必须来自地幔，这正是地幔剧烈对流的经典论证。
:::

::: exercise 扩散形成的"表皮" {level=3}
热量在岩石中的热扩散率$\kappa \approx 1\times10^{-6}\ \mathrm{m^2\,s^{-1}}$。持续时间为$t$的地表温度变化大约影响到深度$d \approx \sqrt{\kappa t}$。问$1\ \mathrm{K}$的变化在(a) 1年、(b) 1000年、(c) 1亿年内能影响到多深？(c)的结果对"地表温度在决定地球内部热量方面的作用"说明了什么？
::: solution
(a) $t = 3.16\times10^{7}\ \mathrm{s}$：$d = \sqrt{10^{-6}\times3.16\times10^{7}} = 5.6\ \mathrm{m}$。
(b) $t = 3.16\times10^{10}\ \mathrm{s}$：$d = 178\ \mathrm{m}$。
(c) $t = 3.16\times10^{15}\ \mathrm{s}$：$d = 56\ \mathrm{km}$。
因此地表状况在人类时间尺度上只影响顶部几百米，即使经过整个地质代也只影响最外几十千米——那只是半径$6371\ \mathrm{km}$的行星上薄薄的一层表皮。内部热量收支由吸积、核的形成和放射性决定，而与气候无关；反过来，古气候模式必须把深部地壳和地幔当作固定的边界条件。
:::
