碳是使地球表面化学不同于我们所知任何其他行星的元素，而这一点出于两个与生物无关的理由。第一，碳能自我成键并有四个价电子，因此形成长链和环，并能携带不同数量的氧——$\mathrm{CO_2}$、$\mathrm{CH_4}$、$\mathrm{CaCO_3}$ 和 $\mathrm{C_6H_{12}O_6}$ 都是碳，而它们自由能之差大到足以驱动一颗行星。第二，在地球表面条件下碳的稳定主气相是二氧化碳，因此大气充当岩石、海洋和生命储库之间的交换柜台。

数字的不对称令人震惊。岩石储库约有$65$–$130\times10^{6}\ \mathrm{GtC}$；海洋$38{,}000\ \mathrm{GtC}$；土壤与植被$2000$–$3000\ \mathrm{GtC}$；大气$890\ \mathrm{GtC}$。快循环每年在空气、海洋和陆地之间移动$100$–$200\ \mathrm{GtC}$；慢循环每年在海洋与岩石之间移动约$0.3\ \mathrm{GtC}$。人类工业现在每年移动约$11\ \mathrm{GtC}$——是慢循环火山与风化通量的三十倍，是快循环总通量的约十分之一。这就是大气在175年间从$278\ \mathrm{ppm}$升到$420\ \mathrm{ppm}$以上的原因，也是碳循环这一章地质学、化学与政治相遇的原因。

## 两个循环

::: definition 快循环与慢循环 {#def-two-cycles}
**快（生物-表层海）循环**在大气、植被、土壤和表层海洋之间交换碳，储库周转时间为数日到数百年：光合与呼吸分别为$120$和$60\ \mathrm{GtC\,yr^{-1}}$，海气交换各向$90\ \mathrm{GtC\,yr^{-1}}$。**慢（地质）循环**通过硅酸盐风化（碳汇，以碳酸氢根形式输向海洋，约$0.3\ \mathrm{GtC\,yr^{-1}}$）、碳酸盐与有机碳埋藏（约$0.3\ \mathrm{GtC\,yr^{-1}}$）以及火山与变质脱气（约$0.1\ \mathrm{GtC\,yr^{-1}}$）在海洋-大气系统与岩石储库之间交换碳。
:::

| 储库 | $\mathrm{GtC}$ | 周转时间 |
|---|---|---|
| 大气（2024年，$422\ \mathrm{ppm}$） | 890 | 单分子9天，全库数年 |
| 植被与凋落物 | 450–650 | 数十年 |
| 土壤（至2 m） | 1500–2000 | 数世纪至千年 |
| 永久冻土（至3 m） | 1400–1600 | 数千年 |
| 表层海洋 | 900 | 数年 |
| 中层与深海 | 37 000 | 500–1000 年 |
| 化石燃料储量 | $\sim1100$（煤、油、气） | $10^{8}$ 年 |
| 沉积物与地壳 | $(65$–$130)\times10^{6}$ | $10^{8}$ 年 |

这张表一行就说清了整个问题：在人类时间尺度上交换碳的储库只有几千吉吨碳，而我们正在开采的那个约一千吉吨，且已经烧掉了一半以上。

::: proposition 空中分数与碳收支 {#prop-budget}
对任何时段，
$$
\Delta F = S_\text{air} + S_\text{ocean} + S_\text{land},
$$
其中$\Delta F$为总排放，$S$为各自的汇。**空中分数**$\chi = S_\text{air}/\Delta F$在1960–2020年平均为$0.45 \pm 0.13$，且无显著趋势，尽管排放增长了四倍。
:::

::: proof
这是质量守恒用于大气的结果，其中汇定义为净通量：陆地是总光合减去呼吸，海洋汇是海气$p\mathrm{CO_2}$差在海盆上的积分。$\chi$的稳定性是经验结果而非定理：它意味着海洋和陆地汇随排放成比例增长，这正是线性（浓度驱动）吸收应有的表现。但这并不意味汇是安全的。热带陆地汇已明显趋于饱和，且易受火灾和干旱影响；单位排放对应的海洋汇则因表层变暖、层结增强而下降（[[climate-change/attribution]]）。
:::

::: example 读全球碳收支 {#ex-budget}
2020年代初，排放约$11\ \mathrm{GtC\,yr^{-1}}$（化石燃料与水泥约$9.4$，土地利用$1.6$），大气增量约$5.2\ \mathrm{GtC\,yr^{-1}}$，海洋汇约$2.7$，陆地汇约$3.1\ \mathrm{GtC\,yr^{-1}}$。检查闭合，求空中分数，并求1850年以来排放的约$690\ \mathrm{GtC}$中有多少仍在大气中。
::: solution
$2.7 + 3.1 + 5.2 = 11.0\ \mathrm{GtC\,yr^{-1}}$：收支按构造闭合，因为汇是以残差估计的，其不确定度（海洋$\pm0.3$、陆地$\pm0.9$）才是真正的误差棒。空中分数为$5.2/11 = 0.47$。

累计收支方面，大气已获得$(422 - 278)\ \mathrm{ppm}\times2.124\ \mathrm{GtC\,ppm^{-1}} = 306\ \mathrm{GtC}$，占排放约$690\ \mathrm{GtC}$的$0.44$，与年际值一致。其余$384\ \mathrm{GtC}$在海洋和陆地中，主要在海洋，且主要在过去两个世纪还位于表层的水里。

最后这个数字正是碳循环无情之处。以$40\ \mathrm{GtCO_2\,yr^{-1}}$的排放对照剩余的$1.5\ ^\circ\mathrm{C}$碳预算约$250\ \mathrm{GtCO_2}$（IPCC AR6，2021年，表TS.3，50%概率）是当前排放水平的六年；对照$2\ ^\circ\mathrm{C}$预算约$1150\ \mathrm{GtCO_2}$则是二十九年。变暖接近于与**累计**碳量线性相关而非与浓度相关，因为空中分数大致恒定——这是气候政策中最有用的一条事实。
:::
:::

## 海洋化学：为什么海水是一块差劲的海绵

::: definition 雷维耶因子 {#def-revelle}
海水中的溶解无机碳（DIC，约$2000\ \mu\mathrm{mol\,kg^{-1}}$）有$90\%$是碳酸氢根、$10\%$是碳酸根，游离$\mathrm{CO_2}$只占$0.5\%$。**雷维耶（缓冲）因子**
$$
R = \frac{\partial\ln p\mathrm{CO_2}}{\partial\ln \mathrm{DIC}}
$$
衡量向表层海水中加入碳时其自身$\mathrm{CO_2}$分压上升多少。工业革命前的表层海$R \approx 15$，从寒冷、富碳酸盐的南大洋的约$10$到北太平洋的$20$以上。
:::

::: example 一块会吸饱的海绵 {#ex-revelle}
人类迄今排放的约$306\ \mathrm{GtC}$若全部溶入整个海洋，会使DIC上升多少？取海洋质量$1.4\times10^{21}\ \mathrm{kg}$。然后求同样这些碳在（a）混合至整个海洋、（b）仅停留在表层$100\ \mathrm{m}$（面积$3.62\times10^{14}\ \mathrm{m^2}$）时造成的表层$p\mathrm{CO_2}$上升，取$R = 15$、工业革命前$p\mathrm{CO_2} = 280\ \mu\mathrm{atm}$。
::: solution
$306\ \mathrm{GtC} = 2.55\times10^{16}\ \mathrm{mol}$。整个海洋：
$$
\Delta\mathrm{DIC} = \frac{2.55\times10^{16}}{1.4\times10^{21}\ \mathrm{kg}} = 18\ \mu\mathrm{mol\,kg^{-1}},
$$
即增加$0.9\%$，故$p\mathrm{CO_2}$上升$15\times0.9\% = 13\%$，从$280$升到$316\ \mu\mathrm{atm}$。从容。

表层$100\ \mathrm{m}$的水质量为$3.7\times10^{19}\ \mathrm{kg}$，故$\Delta\mathrm{DIC} = 686\ \mu\mathrm{mol\,kg^{-1}}$，增加$35\%$，$p\mathrm{CO_2}$将上升$15\times35\% = 525\%$——达到约$1750\ \mu\mathrm{atm}$，远高于大气。海洋不会吸收我们的碳，反而会把碳吐回来。

两个答案之差就是碳汇的整个物理海洋学。只有当碳能被埋入内部时化学才是慷慨的，而这需要[[earth-system/circulation]]和[[oceanography/overturning]]所描述的深层环流——这就是为什么海洋汇由通风速率决定，也为什么它不会随世界变暖、翻转减弱而明显增长。
:::
:::

::: definition 海洋酸化与饱和度 {#def-acidification}
向海水加入$\mathrm{CO_2}$会把碳酸根转化为碳酸氢根：$\mathrm{CO_2} + \mathrm{CO_3^{2-}} + \mathrm{H_2O} \to 2\mathrm{HCO_3^-}$。表层海pH自工业革命以来下降了$0.11$个单位（从$8.17$到$8.06$），氢离子浓度增加$30\%$，文石饱和度$\Omega_\text{ar} = [\mathrm{Ca^{2+}}][\mathrm{CO_3^{2-}}]/K'_\text{sp}$从约$3.4$降到$2.8$。
:::

饱和度之所以要紧，是因为钙化生物——翼足类、珊瑚、建造深海碳酸盐软泥的球石藻和有孔虫——必须从过饱和水中沉淀碳酸钙。在**溶解跃层**和**碳酸盐补偿深度**（大西洋约$4200\ \mathrm{m}$，太平洋$4800\ \mathrm{m}$）之下$\Omega < 1$，碳酸盐溶解；当海洋被加载碳时补偿深度变浅，这正是慢循环最终中和$\mathrm{CO_2}$扰动的机制。

::: warning "火山排放的$\mathrm{CO_2}$比人类多"这句话错了三十倍
包括海底弥散脱气在内的全球火山与洋中脊脱气总量为$0.3$–$0.4\ \mathrm{GtC\,yr^{-1}}$（Fischer与Aiuppa，2020年）。人类排放约$11\ \mathrm{GtC\,yr^{-1}}$：大三十倍，而且是在两个世纪内一次性交付。同样的算术也否定了相关的说法——"$\mathrm{CO_2}$来自海洋"：海洋与大气接近平衡，不可能是足以解释$144\ \mathrm{ppm}$上升的*净*源，而其$\delta^{13}\mathrm{C}$和氧同位素特征显示通量方向相反。第三个版本——"植物会把它全吸收"——在[[#ex-budget]]的质量平衡前失败：陆地汇确实存在，约占排放的$30\%$，而且在一些地区已在下降。
:::

::: proposition 同位素指纹 {#prop-isotopes}
化石碳亏损$^{13}\mathrm{C}$（煤和石油$\delta^{13}\mathrm{C} \approx -25$‰，热成因气$-42$‰，而工业革命前大气为$-7$‰），且不含$^{14}\mathrm{C}$。因此燃烧化石燃料必然同时降低大气的$\delta^{13}\mathrm{C}$和$^{14}\mathrm{C}/^{12}\mathrm{C}$，而任何其他可信的$\mathrm{CO_2}$源（海洋、火山、碳酸盐）都不会降低$^{14}\mathrm{C}$。自1950年代以来的直接测量，以及此前的植物标本馆标本与冰芯记录，都显示两者在下降。
:::

::: proof
质量平衡的论证就是算术。向$590\ \mathrm{GtC}$、$\delta^{13}\mathrm{C} = -7$‰的工业革命前大气加入$306\ \mathrm{GtC}$、$\delta^{13}\mathrm{C} = -25$‰的碳，将得到
$$
\delta = \frac{590\times(-7) + 306\times(-25)}{896} = -13.1\ \text{per mil} .
$$
观测值约为$-8.4$‰：大气比这*重*得多，因为汇并非不加区分地移除碳。光合作用对$^{13}\mathrm{C}$的歧视约为$18$‰（C$_3$植物），海气气体交换使残留空气重约$1.6$‰，因此留下的碳相对于进入的碳是贫轻同位素的。把排放质量、排放同位素组成和实测分馏一起输入的模式能够复现观测到的$1.4$‰下降；任何自然源组合都做不到，因为它们都不是$^{14}\mathrm{C}$空的。$^{14}\mathrm{C}$证据是决定性的，且不依赖任何排放清单：在扣除大气核试验产生的人工$^{14}\mathrm{C}$之后，大气$^{14}\mathrm{C}$自1850年以来稳定下降，其幅度恰为"被死碳稀释"所要求的量。
:::

::: example 有多快才算前所未有？ {#ex-petm}
5600万年前的古新世-始新世极热事件（PETM）是碳循环扰动最好的地质类比：块状碳酸盐中$5$–$6$‰的碳同位素漂移记录了$3000$–$10{,}000\ \mathrm{GtC}$轻碳的注入，使全球变暖$5$–$8\ ^\circ\mathrm{C}$。若释放历时$5$–$20\ \mathrm{kyr}$，其速率是多少？与今天的$11\ \mathrm{GtC\,yr^{-1}}$相比如何？
::: solution
$4500\ \mathrm{GtC}$除以$10\ \mathrm{kyr}$为$0.45\ \mathrm{GtC\,yr^{-1}}$；$10{,}000\ \mathrm{GtC}$除以$5\ \mathrm{kyr}$为$2\ \mathrm{GtC\,yr^{-1}}$。今天的$11\ \mathrm{GtC\,yr^{-1}}$快五倍到二十五倍（Zeebe等，2009年给出PETM速率$0.8$–$1.1\ \mathrm{GtC\,yr^{-1}}$，约为现代速率的十分之一）。

如果总量决定温度，为什么速率要紧？因为速率决定地球能缓冲掉多少。风化和碳酸盐补偿的作用时间是$10^{4}$–$10^{5}$年；生物泵和海洋物理吸收在数十年至数百年内响应，但受雷维耶因子和层结限制。碳加入得比缓冲机器反应更快，系统就像没有缓冲一样行事——这就是PETM的$\delta^{13}\mathrm{C}$漂移如此之大的原因，也是为什么同样的漂移正以过去5500万年从未有过的速率写进现代海洋（[[palaeoclimate/abrupt-change]]、[[earth-history/mass-extinctions]]）。
:::
:::

## 慢循环与恒温器

::: definition 硅酸盐风化恒温器 {#def-thermostat}
钙硅酸盐的风化消耗大气二氧化碳：
$$
\mathrm{CaSiO_3} + 2\mathrm{CO_2} + \mathrm{H_2O} \to \mathrm{Ca^{2+}} + 2\mathrm{HCO_3^-} \to \mathrm{CaCO_3} + \mathrm{CO_2}.
$$
该通量取决于径流、温度、岩石可蚀性以及$\mathrm{CO_2}$本身，因此更暖更湿的地球风化更快、把$\mathrm{CO_2}$抽得更低。这个负反馈被认为使显生宙保持无冰，并终结了"雪球地球"事件。
:::

::: example 消失的三个时间尺度 {#ex-timescales}
多余的$306\ \mathrm{GtC}$离开大气-海洋系统需要多久：(a) 按当前风化通量$0.3\ \mathrm{GtC\,yr^{-1}}$；(b) 按碳酸盐补偿反馈；(c) 用脉冲响应$f(t) = 0.2 + 0.3e^{-t/120} + 0.5e^{-t/1200}$，1000年后海洋还持有其中多少？
::: solution
(a) 按当前通量，$306/0.3 = 1000$年——但通量不是固定的。风化随变暖和$p\mathrm{CO_2}$升高而加速，而溶解海底和沉积物中的碳酸盐来中和多余酸度大致使容量翻倍。评估结果是约四分之三在$10^{4}$–$10^{5}$年内被移除。

(b) 完整的碳酸盐补偿——溶解碳酸盐以恢复碱度——的作用时间约$10^{5}$年，这就是"地质解决方案"在任何人类时间尺度上都不可用的原因。

(c) $f(1000) = 0.2 + 0.3\times10^{-3} + 0.5\times0.435 = 0.42$：一千年后，一次碳脉冲仍有约$40\%$留在大气-表层海系统中；而$f(\infty) = 0.2$——我们排放的五分之一在全新世时间尺度上实际上是永久的。$1000\ \mathrm{GtC}$的脉冲会留下约$200\ \mathrm{GtC}$、约$95\ \mathrm{ppm}$，持续二十四万年。

这个数字把碳循环从多数环境问题中区分出来。多数污染可以稀释或降解；今天排放的二氧化碳有一条没有开关的长尾，而这条尾巴由化学决定，不由政策决定。
:::
:::

::: warning 陆地汇不是生物圈欠我们的情
关于"解决方案"流传着两种碳循环并不支持的说法。第一，二氧化碳施肥将使陆地持续吸收我们排放的三分之一：施肥效应是真实的，在实验和卫星绿化记录中都可测，但它被变暖引起的呼吸、干旱和火灾抵消，也被养分限制抵消——设定上限的是氮和磷，不是碳（[[biogeochemistry/nitrogen]]、[[biogeochemistry/phosphorus-sulfur]]）。第二，土壤和永久冻土是把碳放回去的安全场所：$1400$–$1600\ \mathrm{GtC}$的永久冻土是靠温度而非化学锁住的，损失$10\%$就是$150\ \mathrm{GtC}$，即$70\ \mathrm{ppm}$。这两者都是方向不对的反馈，而且都已可测量。
:::

::: quiz
海洋含碳是大气的四十倍，还能溶解更多。为什么它只拿走了我们排放的四分之一？
- [ ] 因为其表层已被二氧化碳饱和。
- [x] 因为与空气接触的表层水抗拒吸收更多碳（雷维耶因子约$15$），而要进入巨大的深海储库需要缓慢的环流。
- [ ] 因为变暖使溶解度降为零。
- [ ] 因为海洋生物先把碳用掉了。
::: solution
第二个答案的两部分都要紧。化学上，表层海的碳酸氢根-碳酸盐体系意味着溶解无机碳上升$1\%$就使其自身$p\mathrm{CO_2}$上升约$15\%$，很快抹平海气梯度。物理上，海洋碳的$90\%$位于透光层之下，靠百年至千年的翻转环流更新。因此海洋汇受物理速率限制，而非化学上限限制——这就是它会继续但无法加速的原因（[[oceanography/overturning]]）。
:::
:::

- [ ] $\mathrm{CO_2}$辐射强迫近似对数增长这一事实。
::: solution
化石碳在放射性测年意义上是死的：任何与大气隔绝超过$^{14}\mathrm{C}$几个半衰期（$5730$年）的碳都已不含$^{14}\mathrm{C}$。火山碳和海洋碳携带现代$^{14}\mathrm{C}$。因此扣除核试验后$^{14}\mathrm{C}$比例下降只能意味着被死碳稀释；与之匹配的$\delta^{13}\mathrm{C}$下降$1.4$‰进一步把源锁定为$\delta^{13}\mathrm{C} \approx -25$‰的物质——煤、石油、天然气和被燃烧的生物质。季节循环和海洋DIC上升与收支一致，但不能指认来源。
:::
:::

::: history
布莱克（Black）1750年代在爱丁堡把碳确认为一种独立物质，称之为"固定空气"，并测量石灰石能释放多少。傅里叶（Fourier）1824年的温室类比和丁达尔（Tyndall）1861年的实验室测定确立了这种气体的重要性；阿伦尼乌斯（Arrhenius）1896年算出把它翻倍会使地表增暖$5$–$6\ ^\circ\mathrm{C}$——而通常被省略的细节是，他同时论证海洋会在几个世纪内吸收大部分，因此效应会很慢。碳循环作为定量科学始于三个人。苏斯（Suess）1955年注意到现代木材和大气的$\delta^{13}\mathrm{C}$相对十九世纪样品在下降：化石碳正在到来，而且它是轻的。雷维尔（Revelle）与苏斯1957年计算了如今以雷维尔命名的缓冲因子，得出表层海洋无法吸收大量人为排放，因此"一场大规模地球物理实验"正在进行——正是这句话说服查尔斯·戴维·基林（Keeling）去测量空气。基林在国际地球物理年支持下于1958年启动的冒纳罗亚记录，是地球系统科学的奠基仪器：连续、经过标定、至今仍在运行。全球碳计划自2006年成立，此后每年发布碳收支，其头条数字就是[[#ex-budget]]中的闭合误差。
:::

## 由此通向何处

碳循环是[[earth-system/reservoirs-fluxes]]中储库-通量方法的原型，是[[earth-system/energy-balance]]中碳-气候反馈的机制，也是为什么气候目标用吨而不是度来表达。其深时版本见[[biogeochemistry/carbon-deep-time]]和[[earth-history/palaeozoic]]；其现代观测科学见[[climate-system/carbon-climate]]和[[climate-change/emissions-budgets]]；其海洋机器见[[oceanography/ocean-chemistry]]和[[oceanography/overturning]]；其同位素工具见[[geochemistry/stable-isotopes]]；其移除、封存与硬约束见[[earth-resources/geothermal-storage]]和[[earth-resources/extraction-impacts]]。

::: summary
- 一个元素两个循环：$100$–$200\ \mathrm{GtC\,yr^{-1}}$、储库为数十年的快循环，与$\sim0.3\ \mathrm{GtC\,yr^{-1}}$、储库为百万年的慢循环。
- 排放约$11\ \mathrm{GtC\,yr^{-1}}$，大致$47\%$留在大气、$25\%$入海洋、$28\%$入陆地；空中分数六十年来稳定在$0.45$。
- 因为空中分数近似恒定，变暖近似与累计碳量线性相关；$250\ \mathrm{GtCO_2}$相当于当前排放的六年。
- 雷维耶因子约$15$意味着只有当碳抵达深海时海洋才是慷慨的汇，而这需要几个世纪。
- 化石碳贫$^{13}\mathrm{C}$且无$^{14}\mathrm{C}$，因此大气$\delta^{13}\mathrm{C}$与$^{14}\mathrm{C}$的下降无需任何排放清单即可证明来源。
- 加入海洋的碳降低pH和碳酸盐饱和度：已下降$0.11$个pH单位和$20\%$的$\Omega_\text{ar}$，预计再降$0.2$–$0.45$个单位。
- 多余的碳在$10^{4}$–$10^{5}$年尺度上离开；其中五分之一在全新世时间尺度上永不离开。
:::

## 习题

::: exercise 储库周转 {level=1 check="7.4"}
大气持有$890\ \mathrm{GtC}$，总光合每年移除$120\ \mathrm{GtC}$。求大气碳相对于光合作用的周转时间。
::: solution
$\tau = 890/120 = 7.4\ \mathrm{yr}$。与相对于降水和蒸发的$9$天滞留时间对比：大气碳与陆地的交换很快，但这些交换几乎相互抵消，这就是为什么净汇只是$120$总量中的$3\ \mathrm{GtC\,yr^{-1}}$。
:::
:::

::: exercise 空中分数 {level=1 check="0.45"}
1960–2020年累计排放$230\ \mathrm{GtC}$，大气增加$104\ \mathrm{GtC}$。求空中分数。
::: solution
$\chi = 104/230 = 0.45$。其余$126\ \mathrm{GtC}$进入海洋和陆地，平均汇为$2.2\ \mathrm{GtC\,yr^{-1}}$。
:::
:::

::: exercise 每ppm的碳 {level=1 check="2.12"}
已知干空气质量$5.13\times10^{18}\ \mathrm{kg}$、摩尔质量比$44/29$，证明$1\ \mathrm{ppm}$大气$\mathrm{CO_2}$约对应$2.1\ \mathrm{GtC}$。
::: solution
干空气摩尔数$= 5.13\times10^{18}/0.029 = 1.77\times10^{20}\ \mathrm{mol}$。$10^{-6}$即$1.77\times10^{14}\ \mathrm{mol}$的$\mathrm{CO_2}$，含碳$1.77\times10^{14}\times12\ \mathrm{g} = 2.12\times10^{15}\ \mathrm{g} = 2.12\ \mathrm{GtC}$。
:::
:::

::: exercise 雷维耶因子 {level=2 check="0.083"}
取$R = 12$，表层海DIC必须上升多少倍才能使其$p\mathrm{CO_2}$翻倍？
::: solution
$\Delta\mathrm{DIC}/\mathrm{DIC} = (\Delta p\mathrm{CO_2}/p\mathrm{CO_2})/R = 1/12 = 0.083$，即$8.3\%$，或$167\ \mu\mathrm{mol\,kg^{-1}}$。若$R = 15$，答案为$6.7\%$，即$133\ \mu\mathrm{mol\,kg^{-1}}$。这就是"海洋表层接近饱和"这句话背后的算术：加入少量碳就造成$p\mathrm{CO_2}$大幅上升，从而关闭进一步吸收。
:::
:::

::: exercise 火山与工业 {level=2 check="3.6"}
陆上火山排放$0.13\ \mathrm{GtC\,yr^{-1}}$，加上洋脊与弥散脱气总计$0.4\ \mathrm{GtC\,yr^{-1}}$。把它表示为人类排放$11\ \mathrm{GtC\,yr^{-1}}$的百分比。
::: solution
$0.4/11 = 3.6\%$。即便取最大的可信火山估计，人类排放仍约多二十五倍。一个有用的推论：一次特大型爆发式喷发排放$0.01$–$0.05\ \mathrm{GtC}$的$\mathrm{CO_2}$，相当于人类几天的排放，而它被记住是因为让地球*变冷*——硫酸盐气溶胶的效应超过了气体。
:::
:::

::: exercise 同位素 {level=2}
今日大气碳的$\delta^{13}\mathrm{C} = -8.4$‰，工业革命前为$-7.0$‰，其间增加了$144\ \mathrm{ppm}$。若加入的碳是化石燃料（$-25$‰）与火山$\mathrm{CO_2}$（$-5$‰）的混合，用最简单的两箱质量平衡需要怎样的配比？这个练习为何不合物理？
::: solution
对$590\ \mathrm{GtC}$、$-7.0$‰的大气与加入的$306\ \mathrm{GtC}$作质量平衡：
$$
-8.4 = \frac{590\times(-7.0) + 306\,[f(-25) + (1-f)(-5)]}{896} \Rightarrow f(-25) + (1-f)(-5) = -11.1\ \text{per mil},
$$
故$f = 0.30$：只有$30\%$是化石来源。这个练习不合物理，因为它忽略了汇的同位素分馏——汇优先移除贫$^{13}\mathrm{C}$的碳，从而使残留空气比混合值更重。正确的做法是用实测分馏和已知排放驱动碳循环模式，而只有在加入的碳几乎全部来自化石与土地利用时才能复现观测到的$-8.4$‰。$^{14}\mathrm{C}$检验独立地解决了这个问题：火山碳和海洋碳携带现代$^{14}\mathrm{C}$，化石碳不含。
:::
:::

::: exercise 永久冻土反馈 {level=3}
永久冻土在表层$3\ \mathrm{m}$内持有$1500\ \mathrm{GtC}$。若其中$10\%$被矿化，一半以$\mathrm{CO_2}$、一半以$\mathrm{CH_4}$形式释放，求增加的辐射强迫（以ppm当量表示），并与已加入的$144\ \mathrm{ppm}$ $\mathrm{CO_2}$比较。取$2.12\ \mathrm{GtC\,ppm^{-1}}$、甲烷100年全球增温潜势$28$。
::: solution
共$150\ \mathrm{GtC}$：$75\ \mathrm{GtC}$为$\mathrm{CO_2}$，即$75/2.12 = 35\ \mathrm{ppm}$；$75\ \mathrm{GtC}$为$\mathrm{CH_4}$，按$\mathrm{CO_2}$当量计为$75\times28 = 2100\ \mathrm{GtC}$，即百年尺度$990\ \mathrm{ppm}$当量。

在百年指标中甲烷以三十倍占主导，这正是永久冻土成为可怕反馈的原因，也是指标选择如此要紧的原因：千年尺度上甲烷氧化为$\mathrm{CO_2}$，其当量坍缩到约$75\times8/2.12 \approx 280\ \mathrm{ppm}$当量，而$\mathrm{CO_2}$留了下来。无论用哪个指标，这样规模的永久冻土释放都与整个工业时代的其他贡献相当，而且碳循环在任何相关时间尺度上都无法缓冲（[[climate-change/tipping-points]]）。
:::
:::

::: exercise 补偿深度 {level=3}
向海洋加碳会降低$\Omega_\text{ar}$并使溶解跃层变浅。若整个海洋的DIC上升$100\ \mu\mathrm{mol\,kg^{-1}}$而碱度不变，表层$[\mathrm{CO_3^{2-}}]$将下降多少（取工业革命前$\mathrm{DIC} = 1920$、$[\mathrm{CO_3^{2-}}] = 210\ \mu\mathrm{mol\,kg^{-1}}$）？
::: solution
加入的$\mathrm{CO_2}$几乎全部与碳酸根反应：$\mathrm{CO_2} + \mathrm{CO_3^{2-}} + \mathrm{H_2O} \to 2\mathrm{HCO_3^-}$。因此$100\ \mu\mathrm{mol\,kg^{-1}}$的加入碳会消耗接近$100\ \mu\mathrm{mol\,kg^{-1}}$的碳酸根，只剩$110\ \mu\mathrm{mol\,kg^{-1}}$：下降$48\%$。

这就是海洋酸化在生物效应上如此非线性的化学原因——控制钙化的是饱和度而不是$\mathrm{CO_2}$浓度，而DIC只增加$5\%$饱和度就减半。在真实海洋中，沉积物中的碳酸盐溶解提供碱度，可抵消其中约一半，而这正是最终移除碳的同一个反馈——代价是深海碳酸盐记录，它将在我们正塑造的未来中被溶解殆尽（[[palaeoclimate/ocean-sediments]]）。
:::
:::

::: exercise 碳预算算术 {level=3}
用恒定空中分数近似（$\chi = 0.45$）和每$100\ \mathrm{GtC}$累计排放$0.45\ ^\circ\mathrm{C}$的气候响应，求达到$1.5$和$2.0\ ^\circ\mathrm{C}$所需的累计排放，以及从2025年（2020年以来已排放$600\ \mathrm{GtCO_2}$）起、以$40\ \mathrm{GtCO_2\,yr^{-1}}$排放还能剩多少年。
::: solution
$1.5\ ^\circ\mathrm{C}$需要$1.5/0.45\times100 = 333\ \mathrm{GtC} = 1220\ \mathrm{GtCO_2}$的累计排放；$2.0\ ^\circ\mathrm{C}$需要$1630\ \mathrm{GtCO_2}$。与AR6评估的自2020年起$250$和$1150\ \mathrm{GtCO_2}$相比，差额来自瞬态响应和非$\mathrm{CO_2}$强迫的不确定度，这就是预算以50%概率和区间给出的原因。

按$40\ \mathrm{GtCO_2\,yr^{-1}}$，$250\ \mathrm{GtCO_2}$够用$6$年，$1150$够用$29$年。若排放每年下降$7\%$——许多净零承诺隐含的速率——同样的预算分别够用$40$年和$>100$年，因为几何级数要求和：$\sum_{t} E_0(0.93)^t = E_0/0.07 = 570\ \mathrm{GtCO_2}$（每一单位当年排放）。这就是使*下降速率*而非终点年份成为硬约束的算术。
:::
:::

::: exercise 风化与宜居带 {level=3}
硅酸盐风化近似按$W \propto p\mathrm{CO_2}^{0.3}\exp(0.03\,T)$变化，$T$以$^\circ\mathrm{C}$计。若$p\mathrm{CO_2}$从$280$升到$1120\ \mu\mathrm{atm}$且地表增暖$6\ \mathrm{K}$，风化增大多少倍？这对一个$4\times\mathrm{CO_2}$世界的恢复时间意味着什么？
::: solution
$p\mathrm{CO_2}$因子：$(1120/280)^{0.3} = 4^{0.3} = 1.52$。温度因子：$e^{0.03\times6} = 1.20$。合计$1.82$。

因此二氧化碳四倍及其伴随的温暖使风化汇几乎翻倍，这就是恒温器在工作。按$1.8$倍的当前通量$0.3\ \mathrm{GtC\,yr^{-1}}$，抽走$4\times$世界隐含的多余约$1200\ \mathrm{GtC}$需要$1200/0.54 = 2200$年——但这个估计快得太多，因为风化受岩石供给和新鲜活性矿物表面输送的限制，也因为生物和土壤对温暖与干旱的响应并非单调。地质记录的答案，来自PETM和白垩纪，是$10^{5}$–$10^{6}$年（[[earth-system/planet-earth]]、[[palaeoclimate/deep-time]]）。
:::
