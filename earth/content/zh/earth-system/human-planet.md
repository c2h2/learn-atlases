1864年，旅居佛罗伦萨的美国外交官乔治·珀金斯·马什（Marsh）出版了《人及其自然》。这本书视野惊人，其论点是：人类活动正在把一颗健康的行星变成废墟——毁林、土壤侵蚀、地中海港口的淤塞、景观的干涸——而"地球正迅速变得不适合其最高贵的居民居住"。十年之内此书便绝版。一百三十六年后，保罗·克鲁岑（Crutzen）给同一个论点起了一个流传下来的名字：人类世。

自马什以来变化的不是观察的质量，而是行动的量级，以及我们现在能够测量它这一事实。本章就是这本账：一个八十亿人口的文明每年移动多少物质和能量，这与行星自身的通量相比如何，行星的哪些循环被改道了，以及未来几十年的算术是什么样子。

## 人类行动的尺度

::: definition 大加速 {#def-acceleration}
在1750年至2010年的二十四条社会经济与生物物理时间序列中——人口、城市人口、GDP、外国投资、电话线、内陆用水与化肥、水电、大坝、汽车、百万以上人口城市、纸张、电视机、国际游客、渔获量、受威胁哺乳动物种数、大气$\mathrm{CO_2}$、$\mathrm{N_2O}$、甲烷、臭氧层消耗物质、海岸氮输入、全球地表温度、热带森林面积——全部二十四条都在1950年前后出现统计显著的体制转变，且此后大多接近指数增长（Steffen等，2015年）。1950年至2010年间，世界人口增至四倍，大气$\mathrm{CO_2}$增至四倍，汽车保有量增至约375倍，纸张增至430倍。
:::

::: definition IPAT与卡亚恒等式 {#def-ipat}
影响写作$I = P \times A \times T$：人口、人均富裕度，以及把消费转化为环境负荷的技术项。对碳而言该恒等式是精确的，称为**卡亚恒等式**：
$$
\mathrm{CO_2} = P \times \frac{\mathrm{GDP}}{P} \times \frac{E}{\mathrm{GDP}} \times \frac{c}{E},
$$
即人口、人均收入、单位收入的一次能源（2023年为每2017年美元$5.7\ \mathrm{MJ}$）与单位能源的碳（世界一次能源结构约$70\ \mathrm{kg\,CO_2\,GJ^{-1}}$）之积。
:::

::: definition 行星边界 {#def-boundaries}
**行星边界**框架为九个地球系统过程各定义一个控制变量、一个参考状态（通常为全新世）和一个阈值，越过阈值则状态被判定为性质不同。2023年的评估把九个中的六个置于安全空间之外：气候变化、生物圈完整性、土地利用变化、淡水变化、氮磷生物地球化学流，以及新型实体（化学品、塑料、放射性核素）。
:::

| 人类通量 | $\mathrm{Gt\,yr^{-1}}$或$\mathrm{Tg\,yr^{-1}}$ | 可比自然通量 |
|---|---|---|
| 化石碳（以$\mathrm{CO_2}$计） | $10$ Gt C | 火山$\mathrm{CO_2}$ $0.3$–$0.4$ |
| 农业移动的沉积物 | $19$（耕地，美国为$1.7$） | 河流入海泥沙 $15$–$20$ |
| 工业固氮 | $120$ Tg N | 生物固氮 $100$–$200$ Tg N |
| 磷矿开采 | $17$ Tg P | 自然风化 $0.2$ Tg P |
| 水泥产量 | $4.3$ | — |
| 塑料产量 | $0.4$ | — |
| 物质开采总量 | $95$ | — |

决定这场论证的是氮和磷两行。工业固定的活性氮已与全世界生物固定的相当，而开采的磷是自然风化释放的八十倍。

::: example 废热不是问题所在 {#ex-heat}
世界一次能源使用为$600\ \mathrm{EJ\,yr^{-1}}$，其中几乎全部最终变为热。把由此产生的全球平均能量通量与$2.72\ \mathrm{W\,m^{-2}}$的增强温室辐射强迫（IPCC AR6，2021年，2019年水平）比较。
::: solution
$$
\frac{600\times10^{18}\ \mathrm{J\,yr^{-1}}}{3.156\times10^{7}\ \mathrm{s\,yr^{-1}}\times5.10\times10^{14}\ \mathrm{m^2}} = 0.037\ \mathrm{W\,m^{-2}},
$$
而辐射强迫为$2.72\ \mathrm{W\,m^{-2}}$——相差七十四倍。以功率计，文明运行于$19\ \mathrm{TW}$，而它造成的温室不平衡为$14\ \mathrm{TW}$，且这个不平衡不是被耗散而是被积累，主要以海洋热量的形式。

由此得出两个结论。第一是防御性的："如果没有温室效应，我们电站的废热会更糟"这一说法错了两个量级。第二是令人不安的：我们制造的温室强迫在量级上已与人类使用能量的总速率相当——这等于说大气被当作能量使用副产物的倾倒场，而倾倒几乎免费，损害却不是。
:::
:::

## 被改道的循环

::: proposition 氮循环翻倍 {#prop-nitrogen}
工业合成氨固定约$120\ \mathrm{Tg\,N\,yr^{-1}}$，而全部陆地生物固氮为$100$–$200\ \mathrm{Tg\,N\,yr^{-1}}$，闪电为$5$–$10\ \mathrm{Tg\,N\,yr^{-1}}$。化肥氮的利用率为$20$–$40\%$：其余以地下水硝酸盐、氧化亚氮和氨的形式离开田间。今天一个典型的人体内，约有一半氮是工业固定的（Erisman等，2008年）。
:::

::: proof
质量平衡并不微妙。全球化肥使用约$110\ \mathrm{Tg\,N\,yr^{-1}}$，作物带走约$40$，因此每年约$70\ \mathrm{Tg\,N\,yr^{-1}}$进入环境，这还不算粪肥和豆科作物固氮的损失。其后果被这一个数字串联起来：近海富营养化与缺氧带的扩张、饮用水中的硝酸盐、酸化、欧洲喜氮草地物种的丧失，以及五分之一的增暖——因为氧化亚氮是长寿命温室气体，单分子强迫为$\mathrm{CO_2}$的273倍，而且如今已是主要的剩余臭氧层消耗物质。
:::

::: example 把八十亿人喂两遍，喂得还很糟 {#ex-nitrogen}
施肥最密集的体系中，小麦产量达$12\ \mathrm{t\,ha^{-1}}$，施氮$250\ \mathrm{kg\,N\,ha^{-1}}$。求氮利用率和盈余；并按全球平均施氮$110\ \mathrm{kg\,N\,ha^{-1}}$、利用率$30\%$，估算全球$2.4\times10^{8}\ \mathrm{ha}$耕地的盈余。
::: solution
$12\ \mathrm{t\,ha^{-1}}$小麦籽粒含氮约$1.2\ \mathrm{t\,N\,ha^{-1}}$，故$\mathrm{NUE} = 120/250 = 48\%$，盈余$130\ \mathrm{kg\,N\,ha^{-1}}$。按全球平均，
$$
0.7\times110\ \mathrm{kg\,ha^{-1}}\times2.4\times10^{8}\ \mathrm{ha} = 18\ \mathrm{Tg\,N\,yr^{-1}}
$$
仅来自耕地，尚未计入粪肥、湿地排水和豆科固氮。

利用率是农业政策中最有用的单个数字：同样的产量往往可以用少三分之一的化肥维持，只要施肥时间和位置得当，这就直接减少硝酸盐、氧化亚氮和成本。它也是"有机农业能养活所有人"和"我们必须让热带工业化"两种说法各自部分正确又都不完整的缘由：氮并非处处是约束，而对生物多样性而言，约束是土地面积而不是单产。
:::
:::

::: proposition 磷没有天空 {#prop-phosphorus}
磷循环没有重要的气相。采矿从少数矿体集中出$17\ \mathrm{Tg\,P\,yr^{-1}}$，其中约三分之一被吃掉，其余进入填埋场、污水，最终入海，在沉积物中埋藏。在人类时间尺度上没有返回通量：这是一条从矿山到深海的单向流，而资源在地质上有限、在地理上集中（西撒哈拉和中国拥有大部分储量）。
:::

与碳和氮的对照很有教益。后两者是因*增加*通量而受扰，磷则是因*集中*与*散布*而受扰。其环境效应——富营养化、湖泊与水库的蓝藻水华——发生在流的远端，而稀缺效应——撒哈拉以南非洲耗竭的土壤、化肥价格冲击——发生在近端。两端由同一个杠杆管理，那就是回收：从污水中沉淀鸟粪石、焚烧废物的灰分，以及目前在矿山到田间之间损失的$30$–$40\%$的磷。

::: example 技术圈的质量 {#ex-technosphere}
耐用品与基础设施（"技术圈")总计约$1.1\ \mathrm{Tt}$干重，而活生物质为$0.55\ \mathrm{Tt}$。混凝土年产量$30\ \mathrm{Gt}$、骨料$50\ \mathrm{Gt}$、钢$1.9\ \mathrm{Gt}$、塑料$0.4\ \mathrm{Gt}$；有史以来生产的$6.3\ \mathrm{Tt}$塑料中$79\%$已成为废物，其中大部分在填埋场或环境中（Geyer等，2017年）。估算技术圈的年物质流，并与全世界河流的泥沙量比较。
::: solution
混凝土加骨料加钢加塑料为$30 + 50 + 1.9 + 0.4 \approx 82\ \mathrm{Gt\,yr^{-1}}$，其中骨料占大头。全部河流每年向海输送$15$–$20\ \mathrm{Gt}$泥沙，而仅农业就在耕地上移动$19\ \mathrm{Gt}$土壤。因此我们每年移动固体物质是全球河流泥沙通量的四到五倍，而我们每年的建设量在质量上与地球每块农田的侵蚀量相当。

这就是"行星营力"在物理意义上的内容：不是我们排放气体，而是我们已成为第一流的地质营力，移动岩石、按化学分选它，并建造一个新的地层，其标志——塑料、铝、混凝土、放射性核素、粉煤灰——在这句话最后一份副本消失很久之后，仍将在沉积记录中清晰可辨。
:::
:::

## 剩余岁月的算术

::: example 下降速率与碳预算 {#ex-decline}
排放为$40\ \mathrm{GtCO_2\,yr^{-1}}$。在恒定比例下降$k$下，未来排放总量为$E_0/k$。对$k = 0.01$、$0.03$、$0.07$计算，并与自2020年起$1.5\ ^\circ\mathrm{C}$（$250\ \mathrm{GtCO_2}$）和$2\ ^\circ\mathrm{C}$（$1150\ \mathrm{GtCO_2}$）的剩余碳预算比较（IPCC AR6，2021年，表TS.3，50%概率）。
::: solution
$E_0/k$分别给出$4000$、$1330$和$570\ \mathrm{GtCO_2}$。前两种下降速率下$2\ ^\circ\mathrm{C}$预算耗尽（分别为$34$年和$66$年），第三种则永不耗尽。而$1.5\ ^\circ\mathrm{C}$预算在*所有*情形下都在$7$–$10$年内耗尽，因为$250\ \mathrm{GtCO_2}$只是当前排放的六年，任何现实的下降曲线都绕不过六年。

三点值得带走。第一，按评估预算，$1.5\ ^\circ\mathrm{C}$目标在算术上已经是2030年代初的事，诚实的描述是"先超过、再设法回落"成为可能路径。第二，$2\ ^\circ\mathrm{C}$目标仍可达，但需要约$7\%\ \mathrm{yr^{-1}}$的下降速率持续数十年——历史上最快的能源系统转型是木材到煤再到油气，用了约一个世纪，份额转移约$1\%\ \mathrm{yr^{-1}}$。第三，敏感的是*速率*而非目标年份：年下降$3\%$与$7\%$之间相差$760\ \mathrm{GtCO_2}$的累计排放，几乎就是$2\ ^\circ\mathrm{C}$世界与$1.8\ ^\circ\mathrm{C}$世界的差别。
:::
:::

::: definition 人类世 {#def-anthropocene}
**人类世**被提议作为一个地质年代，其中人类活动是地球系统的主导影响。工作组的候选"全球界线层型剖面和点"（金钉子）是安大略克劳福德湖的沉积，其年层携带核试验的钚峰、化石燃料燃烧产生的球形碳质颗粒的急剧增加、粉煤灰，以及氮磷信号，全部落在$1950$–$1954$年。2024年3月，国际地质科学联合会否决了该提案，因此人类世仍是对当下状态的非正式称呼，而不是地质年代表中的一个正式单位。
:::

::: warning 本章的算术不允许两种说法
第一，它不允许"人口是主要驱动力"这一说法。全球生育率已从1960年的每名妇女五个孩子降到今天的$2.3$，联合国的中位预测使世界人口在2080年代峰值约$103$亿。在排放要紧的时段，卡亚各项中富裕度与技术占主导：1990年以来最富十分之一家庭约占基于消费的累计$\mathrm{CO_2}$的一半，最穷一半约占十分之一（Lan等，2020年）。在生育率高的地区，人口是恒等式中真实且增长的项；在排放集中的地区，它是抓错的杠杆。
第二，它也不允许相反的乐观——认为增长会自己解决问题。数十个国家出现的GDP与碳的绝对脱钩是真实的，但全球单位GDP的$\mathrm{CO_2}$下降速率约$1.5\%\ \mathrm{yr^{-1}}$，正被约$3\%\ \mathrm{yr^{-1}}$的GDP增长追过，因此全球排放仍在上升。所需速率的脱钩，任何国家在任何大的总量上都未曾实现过。
:::

::: quiz
为什么"能源使用的废热"这一气候不作为的论据是错的？
- [ ] 因为电站效率很高。
- [x] 因为直接热通量为$0.037\ \mathrm{W\,m^{-2}}$，比$2.72\ \mathrm{W\,m^{-2}}$的温室强迫小约七十倍。
- [ ] 因为废热会立即辐射到太空。
- [ ] 因为大部分能源是可再生的。
::: solution
热力学第一定律保证几乎全部能源使用最终变为热，因此这个论据至少在物理上是识字的——但数字小了量级。有意思的比较是反方向的：我们制造的温室强迫已与能源使用的总速率相当，这正是大气被当作汇使用之廉价的度量。
:::
:::

::: quiz
某国承诺"2050年净零"，此前排放每年下降$2\%$。算术怎么说？
- [ ] 温度目标有保障。
- [x] 累计排放约为$E_0/k$，即当前年排放的约二十倍，可能符合也可能不符合预算。
- [ ] 只有终点重要。
- [ ] 没有模式就什么都说不出来。
::: solution
变暖跟踪累计排放，而指数下降下的累计排放为$E_0/k$：从$40\ \mathrm{GtCO_2\,yr^{-1}}$以$2\%$下降，得$2000\ \mathrm{GtCO_2}$，超过$2\ ^\circ\mathrm{C}$预算。只有日期而斜率平缓的净零承诺买到的东西很少；斜率才是要害。这就是为什么"2050年净零"和"2030年减半"不是同一个承诺，而后者信息量更大。
:::
:::

::: history
马什（Marsh）的《人及其自然》（1864年）开创了人为环境变化的观念，此后是一个世纪的地方与区域研究：地质学家在1960年代发现了"更新世之后"的哺乳动物灭绝，马丁（Martin）1966年的"过度捕杀"假说把人类狩猎变成一种地质营力。维尔纳茨基（Vernadsky）的"智慧圈"在1945年普及，以宇宙尺度提出了同样的主张。现代论证始于三本书：埃利希（Ehrlich）的《人口炸弹》（1968年）、梅多斯（Meadows）等人的《增长的极限》（1972年，把世界系统模型跑到2100年，并把若干约束的时间大致算对）、康芒纳（Commoner）的《封闭的循环》（1971年，提出了IPAT形式）。埃利希与霍尔德里安（Holdren）在1971年把IPAT形式化。麦克尼尔（McNeill）的《阳光之下有新事》（2000年）为这个世纪写出了环境史。克鲁岑与施托尔默（Stoermer）在2000年命名了人类世；维托塞克等（Vitousek）在1997年量化了人类已经占用了多少陆地净生产量；斯特芬等（Steffen）提供了大加速数据，并在2009年提出"行星边界"框架。人类世工作组2009年成立，2016年决定寻求正式认定，2019年选定克劳福德湖作为候选层型；2024年3月，该提案在联合会执行机构以压倒多数被否决——这一事件将被长期研究，作为科学无法为自身当下命名的案例。
:::

## 由此通向何处

人类行星就是前八章之和加上人类这一项：[[earth-system/carbon-cycle]]的碳循环多了$10\ \mathrm{GtC\,yr^{-1}}$的注入，[[earth-system/water-cycle]]的水循环取走了可获取径流的三分之一，[[biogeochemistry/nitrogen]]和[[biogeochemistry/phosphorus-sulfur]]的氮磷循环一个翻倍一个被集中，[[glaciology/ice-sheets]]的冰已承诺了数米海平面，[[earth-system/life-and-planet]]的生物群落在数百倍背景速率的灭绝之中。怎么办是一个关于价值、制度与技术的问题，见[[climate-change/responses]]、[[earth-resources/resources-reserves]]和[[earth-resources/extraction-impacts]]。

::: summary
- 人类每年移动$95\ \mathrm{Gt}$物质、使用$600\ \mathrm{EJ}$能量；技术圈的质量是所有活生物质的两倍。
- 工业固定的氮与全世界生物固定的相当，开采的磷是自然通量的八十倍；前者是翻倍，后者是向海的单向泵。
- 直接废热为$0.037\ \mathrm{W\,m^{-2}}$，比温室强迫小七十倍——危险在副产物，不在热。
- 大加速是一次有测量、同步的体制转变，始于1950年前后，出现在所检验的每一条社会经济与生物物理序列中。
- 指数下降下的累计排放为$E_0/k$：下降的斜率，而不是净零的年份，决定温度。
- 九个行星边界中评估有六个已被越过；该框架是启发式工具，不是一排悬崖。
- 人类世是一种真实状态，但截至2024年还不是一个正式年代。
:::

## 习题

::: exercise 每美元的能量 {level=1 check="5.7"}
世界GDP为$\$105$万亿（2017年PPP），一次能源$600\ \mathrm{EJ}$。求能源强度（$\mathrm{MJ\,\$^{-1}}$）。
::: solution
$600\times10^{18}/1.05\times10^{14} = 5.7\times10^{6}\ \mathrm{J}$每美元，即$5.7\ \mathrm{MJ\,\$^{-1}}$。1990年该值约$11\ \mathrm{MJ\,\$^{-1}}$：效率改善约$1.5\%\ \mathrm{yr^{-1}}$，这就是卡亚恒等式中的"技术"项，也是唯一稳定朝正确方向移动的项。
:::

::: exercise 碳强度 {level=1 check="62"}
一次能源$600\ \mathrm{EJ}$，能源相关$\mathrm{CO_2}$ $37\ \mathrm{Gt}$。求碳强度（$\mathrm{kg\,CO_2\,GJ^{-1}}$）。
::: solution
$37\times10^{15}\ \mathrm{kg}/6\times10^{8}\ \mathrm{GJ} = 62\ \mathrm{kg\,CO_2\,GJ^{-1}}$（对含非燃烧来源的总一次能源）；若只计燃烧的约$550\ \mathrm{EJ}$，则为$67\ \mathrm{kg\,GJ^{-1}}$。纯煤为$95$、石油$73$、天然气$56$：*供给侧*脱碳就是把这个数字压到$10$以下。
:::

::: exercise 七十法则 {level=1 check="35"}
求年增长率$2\%$的翻倍时间。
::: solution
$\ln 2/0.02 = 35\ \mathrm{yr}$（七十法则给出$35$）。140年——四次翻倍——$2\%$增长放大十六倍。这就是"可持续的指数增长"对任何物质吞吐而言自相矛盾的算术，也是"3%的经济与7%的排放下降"的复利之争成为本世纪核心较量的原因。
:::
:::

::: exercise 氮效率 {level=2 check="0.56"}
某小麦单产$8\ \mathrm{t\,ha^{-1}}$，籽粒氮浓度为干物质的$1.75\%$，施氮$250\ \mathrm{kg\,N\,ha^{-1}}$。求籽粒层面的氮利用率和盈余。
::: solution
籽粒带走氮$= 8000\times0.0175 = 140\ \mathrm{kg\,N\,ha^{-1}}$，故
$$
\mathrm{NUE} = \frac{140}{250} = 0.56, \qquad \text{盈余} = 110\ \mathrm{kg\,N\,ha^{-1}} .
$$
这些盈余不会消失：它以淋失到地下水的硝酸盐、氧化亚氮、挥发的氨和一氧化氮的形式离开。另请注意$0.56$是*作物*门口的效率；整个食物体系——从化肥到餐盘，计入饲喂牲畜的部分——的效率为$20$–$40\%$，这就是为什么膳食与施肥实践同样是氮政策工具。
:::

::: exercise 泥沙与技术圈 {level=2 check="4.6"}
人类建设每年移动固体物质$82\ \mathrm{Gt}$；全部河流年输沙$18\ \mathrm{Gt}$。求比值。
::: solution
$82/18 = 4.6$。加上农业土壤移动（耕地上$19\ \mathrm{Gt\,yr^{-1}}$），人类的固体地球通量约为天然河流通量的五倍半——这就是为什么大河的输沙量自1980年代以来一直在*下降*，既因为大坝拦截，也因为土壤被开采的速度快于其向河道输送的速度（[[geomorphology/landscape-evolution]]、[[earth-resources/extraction-impacts]]）。
:::

::: exercise 累计排放 {level=2 check="2000"}
排放$40\ \mathrm{GtCO_2\,yr^{-1}}$以$2\%\ \mathrm{yr^{-1}}$永久下降。求未来排放总量。
::: solution
$E_0/k = 40/0.02 = 2000\ \mathrm{GtCO_2}$，是自2020年起$2\ ^\circ\mathrm{C}$预算的$1.7$倍。因此只以终点年份表达的承诺，若没有斜率，几乎没有意义。
:::

::: exercise 土地 {level=3}
农业使用$103\times10^{6}\ \mathrm{km^2}$无冰土地中的$39\times10^{6}\ \mathrm{km^2}$，其中耕地$12\times10^{6}\ \mathrm{km^2}$。若全部耕地弃耕、人口由可再生能源驱动的垂直农场供养，会释放无冰土地的多大比例？问题在哪里？
::: solution
$12/103 = 12\%$的无冰土地，面积超过南美洲。问题有三。高产田正是高产的地方，若放弃最好的土地、转而耕种边际土地，单产会急剧下降。反刍动物肉无法在垂直农场生产，而放牧地（$34\times10^{6}\ \mathrm{km^2}$）大多根本不宜耕作。弃耕地的生物多样性价值取决于此前是什么：在曾经的林地上，再野化是巨大的碳和生物多样性收益；在古老草地上，先翻耕种粮再弃耕则两者皆非。
:::

::: exercise 卡亚恒等式 {level=3}
人口增长$0.7\%\ \mathrm{yr^{-1}}$、人均GDP增长$1.8\%\ \mathrm{yr^{-1}}$、能源强度改善$1.5\%\ \mathrm{yr^{-1}}$。要保持排放不变，能源供给侧需要多快的脱碳？要每年减少$3\%$呢？
::: solution
排放增长率为$0.7 + 1.8 - 1.5 - x$，其中$x$为脱碳速率。排放持平需$x = 1.0\%\ \mathrm{yr^{-1}}$；减排$3\%$需$x = 5.0\%\ \mathrm{yr^{-1}}$。作为对照，1990–2020年观测到的一次能源脱碳速率约$1\%\ \mathrm{yr^{-1}}$，这就是为什么恒等式中每一项都在改善而全球排放仍在上升。卡亚恒等式不是人类行为理论，而是一个记账恒等式，它使所需速率无法回避，并迫使争论聚焦于哪一项移动最快。
:::

::: exercise 排放不平等 {level=3}
据估计，最富十分之一家庭负责1990年以来基于消费$\mathrm{CO_2}$排放的约一半，最穷一半约十分之一。若全球排放须在2030年前比2010年下降$45\%$，求两种分配下各自的年速率：(a) 所有人按相同百分比收缩；(b) 最富十分之一在2040年前削减$95\%$、最穷一半在同样三十年内排放翻倍、中间四个十分位保持不变。
::: solution
(a) 相同百分比收缩即二十年内降$45\%$，$1 - 0.55^{1/20} = 3.0\%\ \mathrm{yr^{-1}}$。(b) 最富十分之一三十年削减$95\%$，即$1 - 0.05^{1/30} = 9.5\%\ \mathrm{yr^{-1}}$；最穷一半翻倍，$2^{1/30} - 1 = +2.3\%\ \mathrm{yr^{-1}}$。取份额为$0.5$、$0.4$、$0.1$，则2040年总量为$0.5\times0.05 + 0.4 + 0.2 = 0.625$（以2010年为1），即三十年下降$37.5\%$，全球$1.6\%\ \mathrm{yr^{-1}}$。

这套算术的要点在最后一个数字。即便走一条分配上非常激进的路径——最富十分之一几乎停止排放——只要中间四个十分位不动作，全球也只有$1.6\%\ \mathrm{yr^{-1}}$，比所需低一个量级。同一个全球目标包含截然不同的义务，而任何诚实的气候战略都隐含着一个关于分配问题的回答（[[climate-change/emissions-budgets]]、[[climate-change/responses]]）。
:::

::: exercise 作为启发式的边界 {level=3}
九个行星边界中有六个被评估为已越过。解释为什么该框架不能被单次测量证伪，并给出一个阈值约束良好的边界和一个约束不佳的边界。
::: solution
阈值是相对于参考状态（通常为全新世）和一个模拟的非线性定义的，而九个中大多数阈值的位置是从少数古气候例子推断的，并非测量得到。臭氧层消耗物质是约束良好的情形：阈值由已知化学机制设定，边界在蒙特利尔议定书生效之前就被定量。生物多样性是约束薄弱的例子：控制变量（遗传、功能与结构多样性）是一个复合指数，"安全"水平取自相对于一个很不清楚的背景灭绝率的灭绝速率目标，因此得到的边界是一条用测量外衣包装的价值判断。

该框架的正确用法是作为仪表盘，使人类占用的规模可见且可比，并促使我们追问哪些阈值临近、哪些只是推测。错误用法是借某些边界之柔软来论证所有边界都柔软。
:::
