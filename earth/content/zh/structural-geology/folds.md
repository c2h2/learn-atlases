褶皱是一叠层系在被缩短时所做的事，而沉积记录中几乎一切都是一叠层系。这就是为什么褶皱是这个星球上最丰富的构造、为什么它们是构造地质学家学会描述的第一样东西——也是为什么它们是最常被过度解读的构造，因为一个褶皱的形状同时记录着三件事：缩短量、决定了层在哪里滑动的力学地层，以及这个褶皱所经历的那一系列变形。

## 描述一个褶皱

::: definition 褶皱的几何 {#def-fold-geometry}
**枢纽线**是褶皱面上曲率最大的线，**枢纽带**是其周围的区域；**翼**是两侧曲率较低的面。**轴面**（或称轴面）是把一个褶皱大致分成对称两半的面，**轴迹**是它与填图平面的交线。**层间角**是垂直于轴面量得的两个翼之间的角，**波长** $\lambda$ 是平行于轴面量得的同向相邻枢纽之间的距离。层间角大于 $90^\circ$ 的褶皱是**开阔**的，小于 $30^\circ$ 的是**紧闭**的；而两翼为平面并以铰线相接的是**隔槽式（人字形）**褶皱。
:::

::: definition 平行、相似与切线纵向褶皱 {#def-fold-classes}
一个**平行**（同心）褶皱处处保持地层的正交厚度：层被弯曲而未被减薄，而按垂直方向量得时，枢纽比翼更厚。一个**相似**褶皱在每个层次上都保持剖面的形状，因此平行于轴面量得的层厚是恒定的，而枢纽与翼按相同比例减薄。一个**保持切线纵向长度**的褶皱则保持垂直于层理所绘之线的长度。真实的褶皱落在两个端元之间；而拉姆赛按正交厚度与平行于轴面所量厚度之比 $t_\alpha/t_\beta$ 所作的分类，把它们排在一个连续标度上，从 1A 类（枢纽显著增厚）经过 2 类（相似）到 3 类（枢纽显著减薄）。
:::

::: example 从一张图上量一个褶皱 {#ex-fold-map}
一个抗蚀的石灰岩在一片水平平原上形成一条 $900\ \mathrm{m}$ 宽的露头带，整个带上地层倾 $35^\circ$。求该层的正交厚度。在同一翼上，自该带北缘沿地面沿倾向 $1.5\ \mathrm{km}$ 处钻的一口井，在多深处钻到该层顶界？而如果这个带是一个轴面直立的隔槽式褶皱的一翼，这个倾角意味着多少缩短？
::: solution
在水平地面上，一个带的露头宽度等于厚度除以倾角的正弦，$w = t/\sin\delta$，因为这个带是一个直角三角形的斜边，而该三角形的竖直边就是厚度。因此
$$
t = w\sin\delta = 900\times\sin35^\circ = 900\times0.574 = 516\ \mathrm{m}.
$$
沿翼，地层以倾角下倾，所以地面上沿倾向 $1500\ \mathrm{m}$ 对应如下深度
$$
z = 1500\tan35^\circ = 1500\times0.700 = 1050\ \mathrm{m}.
$$
对一个轴面直立的隔槽式褶皱，缩短为 $s = 1 - \cos\delta = 1 - 0.819 = 0.18$，即百分之十八。

这些数字内建着三条告诫。露头宽度公式假设地面水平、倾角恒定；在一个山坡上，正确的做法要用构造等高线，而误差可达两倍。深度计算假设倾角在 $1.5\ \mathrm{km}$ 之内不变，而褶皱按定义就不会如此。而缩短公式假设了一个隔槽式褶皱：屈曲之前没有平行层面缩短、枢纽处没有增厚，因此真实的缩短更大。仅凭一张图，褶皱几何是不定的；而倾角等值线图、构造等高线图，或一条切穿该构造的谷地，才是解决它的东西。
:::
:::

::: quiz
一个厚层石灰岩紧闭褶皱的枢纽上布满了垂直于层理的石英脉，而其两翼上同一层却一条也没有。这记录了什么？
- [x] 枢纽处的切线纵向伸展，它使层垂直于自身张开。
- [ ] 平行层面缩短，它把流体从翼部挤了出来。
- [ ] 一条恰好穿过枢纽的较晚断层。
- [ ] 埋藏期间的压实，集中在层最厚的地方。
::: solution
在一个平行褶皱中，沿层量得的弧长是守恒的，所以一条穿过枢纽横切该层所绘的线必须按 $t/\rho$ 伸长。那个伸展垂直于层理，并集中在曲率最大之处，而它恰恰在那里张开脉体。翼部——$t/\rho$ 消失之处——没有脉体，这就是有诊断意义的观察：一个区域性的或压成的原因不会如此精确地受几何控制。
:::
:::

## 切线纵向应变

::: proposition 切线纵向伸展 {#prop-tl}
在一个**平行**褶皱中，沿一个穿过枢纽的层所量得的弧长是守恒的，因为该层既未沿自身拉伸也未沿自身缩短。因此，一条穿过枢纽、垂直于该层所绘的线——一条**切线纵向**线，即 TL 线——必须伸长以适应那个曲率，其伸展为
$$
e_{TL} = \frac{t}{\rho},
$$
其中 $t$ 是层的正交厚度、$\rho$ 是枢纽的曲率半径。伸展在曲率最大处最大，而在两翼上消失。
:::

::: proof
取一个厚度为 $t$ 的层，被弯成一个以其中面为半径 $\rho$ 的圆弧，张角为 $\phi$。内表面的弧长为 $\rho_-\phi = (\rho - t/2)\phi$、外表面为 $(\rho + t/2)\phi$，所以两个表面的弧长之差为 $t\phi$。因为中面的弧长 $\rho\phi$ 守恒，外表面相对于内表面就必须在长度 $\rho\phi$ 上被拉伸 $t\phi$，于是在相邻层之间给出一个 $t/\rho$ 的剪切。而在一叠层中，各层不能自由地相互滑过，那个剪切就表现为横切各层之线的伸长：即 TL 线。等价地说，外弧比内弧长出中面弧的 $t/\rho$，而这正是必须由 TL 拉伸来承担的那个伸展。
:::

::: example 一个褶皱枢纽会张开多少？ {#ex-tl}
一个 $60\ \mathrm{m}$ 厚的强层被褶皱成一个枢纽曲率半径为 $120\ \mathrm{m}$ 的背斜。求枢纽处的切线纵向伸展，并描述它所产生的构造。
::: solution
$$
e_{TL} = \frac{t}{\rho} = \frac{60}{120} = 0.50,
$$
枢纽处百分之五十的伸展，沿翼递减至零。这远远超过任何岩石能以均匀拉伸承受的量，所以它被局部化了：**张脉**与**张节理**在枢纽外弧上垂直于层理张开，而褶皱枢纽因此成为矿化之处、无缝合线石灰岩之处、以及渗透率增高之处。经典的例子是瑞士阿尔卑斯与阿巴拉契亚紧闭褶皱枢纽中的石英脉，而许多脉状矿床的矿柱恰恰位于 $t/\rho$ 最大之处。

这个构造还给出了一种在野外测量曲率的途径。在一个褶皱上，若其张脉的张开度可以测量、且层厚已知，$e_{TL}$ 就直接给出 $\rho$，而一个褶皱的曲率半径 本来是一件难以测量的东西。
:::
:::

caption: 一个平行褶皱枢纽处的切线纵向伸展 $e_{TL} = t/\rho$，对枢纽曲率半径 $\rho$ 作图，层厚 $t$ 由滑块设定。这个关系是一条等轴双曲线，所以一个褶皱越闭合就越难以继续紧闭：一个 $60\ \mathrm{m}$ 的层折成 $120\ \mathrm{m}$ 的半径需要百分之五十的枢纽伸展，折成 $30\ \mathrm{m}$ 的半径则需要百分之二百。超过约 $t/\rho \approx 1$ 之后，平行褶皱的假设彻底失效：枢纽必须减薄，褶皱就变成 2 类或 3 类——这就是为什么厚层强岩中的紧闭褶皱很罕见，而紧闭褶皱通常出现在薄层中或弱岩石中。
:::

::: history
褶皱是最早引起争论的构造。德·索叙尔与冯·哈勒描述了阿尔卑斯那些巨大的卧褶皱，而关于它们是原生的还是后期压扁之产物的十九世纪之争，用了一个世纪才了结。休斯（Suess）给出了第一个以收缩地球与在其自重下起皱的地壳为内容的力学解释，他用的 *Bausand* 一词——意为一种隆胀——在隆胀褶皱（流褶皱）的概念中留存下来。决定性的观察工作是在野外完成的：里奇 1934 年对宾夕法尼亚煤田的分析确立了隔槽式褶皱作为一种独立的样式；而瑞士与奥地利学派——奥贝尔、阿尔冈，尤其是施托伊贝尔与阿尔特的盐丘构造学派——确立了蒸发岩与滑脱的作用。理论工具则从工程学中于 1950 与 1960 年代到来：比奥（Biot）在 1957 与 1961 年求解了粘性基质中一个粘性层的屈曲，而他的主波长公式仍是构造地质学家首先写下的那个方程；柯里、帕特诺德与福特在 1962 年给出了弹性的处理；而拉姆赛（Ramsay）在 1967 年的《褶皱的形成》中给出了描述性词汇、切线图解构造、按 $t_\alpha/t_\beta$ 的分类，以及使褶皱定量化的那套应变分析。最后的综合、也是至今仍支配这门学科实践的那一部，是约翰逊与弗莱彻 1994 年的专著，它表明褶皱几何的全部范围都出自少数几个流变端元与一组边界条件。
:::

## 褶皱为什么有它们那个波长

::: proposition 强层的屈曲 {#prop-buckle}
一个厚度为 $h$、粘度为 $\eta_1$ 的层，嵌在粘度为 $\eta_m$ 的基质中，并沿其长度方向被缩短时，会对一个正弦扰动失稳。该扰动随时间指数增长，而增长最快的波长是
$$
\lambda_\text{max} = 2\pi h\left(\frac{\eta_1}{6\eta_m}\right)^{1/3}.
$$
因此主波长正比于层厚、正比于粘度反差的立方根，而与缩短的多少无关。
:::

::: example 估计一个粘度反差 {#ex-buckle-use}
一个石英岩中的波状层理以 $4\ \mathrm{cm}$ 的主波长被褶皱，而强层厚 $3\ \mathrm{mm}$。估计层与其基质之间的粘度反差，并加评论。
::: solution
$$
\frac{\eta_1}{\eta_m} = 6\left(\frac{\lambda}{2\pi h}\right)^{3} = 6\left(\frac{40}{2\pi\times3}\right)^{3} = 6\times(2.122)^{3} = 6\times9.56 = 57 .
$$
大约六十的反差。对一个含石英略高的层在一个云母质基质中，这是一个可信的数字，而它正是使褶皱成为一种流变仪的那类估计。

告诫是严重的，值得一说。公式给出的是**屈曲开始时生长速率最大的波长**，而褶皱会生长、相互影响并合并，所以观察到的波长通常大于初始波长，粘度反差因此被系统性地高估。理论假设一个牛顿基质、一个孤立的单层、以及没有平行层面缩短；而真实岩石有幂律基质、有间距与波长相当的多个层，以及在屈曲变得可见之前有百分之几十的缩短。诚实的说法是：该层比其基质强十倍到一百倍之间——这仍然是一次真实的测量，而且是任何其他方法都给不了的测量。
:::
:::

## 叠加与干涉

::: definition 再褶皱与干涉构造 {#def-interference}
一个使早期褶皱变形的褶皱是一个**再褶皱**或**叠加**褶皱，而干涉图案的几何记录着两个缩短方向之间的夹角以及各自的量。戈什的分类按两次事件的相对强性给这些图案排序：当两个缩短方向直交、而第二次褶皱开阔时，1 类干涉给出经典的"蛋箱"式穹盆图案；2 类给出紧闭第二次褶皱的钩状与回旋镖状图案；3 类则给出两个紧闭褶皱的复杂图案。一个**鞘褶皱**——其枢纽线位于叶理面内、褶皱自身闭合——记录着剪切带中的非同轴流动。
:::

::: example 读一个干涉图案 {#ex-interference}
一个地区填出了宽 $2\ \mathrm{km}$、向东缓倾的闭合椭圆状露头图案，其上叠加了走向近南北、波长 $5\ \mathrm{km}$、轴面向东倾 $80^\circ$ 的开阔褶皱。第一代的叶理围绕第二代的枢纽被褶皱。试解释。
::: solution
两次变形。**第一次**产生了近东西向、缓倾的紧闭褶皱与轴面叶理；闭合的椭圆状露头与缓倾使它们成为**穹盆**构造，这意味着第一次缩短大致水平、方向近南北，而褶皱群是双倾伏的。**第二次**产生了轴面陡倾向东倾的近南北向开阔褶皱，这需要一个近东西向的水平缩短，而它**再褶皱了一代叶理**，所以它更年轻。

两次缩短相互直交，而按紧闭程度不同，这个图案是戈什 1 类或 2 类。在地质上，这是直向汇聚的、或单次造山过程中边界条件改变的经典签名——阿尔卑斯、喜马拉雅与苏格兰北部的加里东都显示出它。实际的后果是：这样一个地区的图不能当作一个构造来读，因为第一代的褶皱枢纽本身也被褶皱过了，所以它们表观的走向与倾伏并不是其原始的；而一次构造分析必须先复原第二次变形，才能量第一次。
:::
:::

::: warning 褶皱的形状不是应变的估计
由一个褶皱得出的两个最诱人的推断，通常都是错的。第一个是横过褶皱的缩短等于 $1 - \cos\delta$（$\delta$ 为翼倾角）：那个公式假设一个隔槽式褶皱具有直立的轴面、没有平行层面缩短、枢纽没有增厚、没有物质转移，而它可能错上两倍。第二个是褶皱的波长记录着缩短：它记录的是层厚与粘度反差，而一旦褶皱生长起来，它基本上与发生了多少缩短无关。

通往缩短估计的可靠途径，是找一个关于原始长度的独立约束——一个古地理标志、一个能够平衡的复原剖面、与一个未变形等效地层的对比、或一次古地磁旋转——并检查褶皱几何是否与之相容。在没有这样的约束时，正确的说法是：该岩石被缩短过，缩短大于当前层长与复原层长之差，而其大小未知。
:::

## 通向何处

屈曲的力学由流变学推出，见 [[structural-geology/rheology]]；断层所产生的褶皱见 [[structural-geology/fractures-faults]]；剪切带中的褶皱见 [[structural-geology/shear-zones]]；图上图案的判读见 [[structural-geology/maps-sections]]；造山背景见 [[structural-geology/orogens]]。

::: summary
- 一个褶皱由枢纽、翼、轴面、层间角与波长来描述；平行褶皱保持层厚，相似褶皱保持剖面形状。
- 褶皱枢纽处的切线纵向伸展为 $t/\rho$，这就是褶皱枢纽成为脉体、矿柱与裂缝渗透率所在之处的原因。
- 主屈曲波长为 $2\pi h(\eta_1/6\eta_m)^{1/3}$，所以波长量的是层厚与粘度反差的立方根，而不是缩短。
- 褶皱依次经历平行层面缩短、屈曲、翼旋转与枢纽迁移而生长；其所到达的阶段记录着缩短量与流变。
- 叠加褶皱记录着缩短方向的改变，必须先加以区分，才能量其中任何一代。
- 单凭褶皱形状不能决定缩短；需要一个关于原始长度的独立约束。
:::

## 练习

::: exercise 褶皱术语 {level=1}
一个褶皱的层间角为 $25^\circ$。它是开阔的、中等闭合的还是紧闭的？它很可能属于哪一类褶皱？
::: solution
层间角 $25^\circ$，它是**紧闭**的。紧闭褶皱要么要求层厚相对于曲率半径很小，要么要求一个可以流动的软弱或活动层，要么要求一个枢纽已减薄的 2 类或 3 类几何；一个厚而强的层，若不在枢纽上伸展百分之百以上、或不断裂，就无法被折成紧闭的。
:::
:::

::: exercise 切线纵向应变 {level=1 check="0.25"}
一个 $40\ \mathrm{m}$ 的层以 $160\ \mathrm{m}$ 的枢纽半径被褶皱。求 $e_{TL}$。
::: solution
$e_{TL} = t/\rho = 40/160 = 0.25$，即枢纽处百分之二十五的伸展。
:::
:::

::: exercise 隔槽式缩短 {level=1 check="0.5"}
一个隔槽式褶皱的两翼倾 $60^\circ$、轴面直立。估计其缩短。
::: solution
$s = 1 - \cos60^\circ = 1 - 0.5 = 0.50$，即百分之五十的缩短。该公式假设屈曲之前没有平行层面缩短、枢纽处没有增厚，所以真实的缩短更大。
:::
:::

::: exercise 波长 {level=2 check="207"}
一个厚 $6\ \mathrm{mm}$、粘度为其基质一千倍的层，以什么主波长屈曲？以 mm 计。
::: solution
$\lambda = 2\pi h(\eta_1/6\eta_m)^{1/3} = 2\pi\times6\times(1000/6)^{1/3} = 37.7\times5.503 = 207\ \mathrm{mm}$，约 $21\ \mathrm{cm}$。注意立方根的杠杆作用：粘度反差变化一千倍，只相当于波长变化十倍；而层厚变化一百倍，则相当于波长变化一百倍。因此褶皱作为层厚的度量远好于作为流变的度量。
:::
:::

::: exercise 曲率半径 {level=2 check="80"}
一个褶皱的 $20\ \mathrm{m}$ 厚层枢纽上的张脉记录了百分之二十五的切线纵向伸展。枢纽的曲率半径是多少米？
::: solution
$\rho = t/e_{TL} = 20/0.25 = 80\ \mathrm{m}$。这是一件真正的曲率量具，只要那些脉确实是由切线纵向伸展张开、而不是由一次无关的后期破裂事件张开——检验的办法，是确认脉的密度沿翼递减到零，恰在 $t/\rho$ 消失之处。
:::
:::

::: exercise 褶皱分类 {level=2}
一个褶皱中量得的正交层厚在枢纽为 $1.00\ \mathrm{m}$、在翼为 $0.70\ \mathrm{m}$（垂直于轴面量得）。这是哪一类褶皱？它对机制说了什么？
::: solution
正交厚度与平行于轴面所量厚度之比 $t_\alpha/t_\beta$ 为 $1.00/0.70 = 1.43$，大于一，因此是**1 类**：枢纽按平行于轴面量得时比翼更厚，而褶皱近似平行（同心）。其机制必定涉及弯滑或弯流，因为平行褶皱不需要平行层面的伸展或缩短——各层在两翼上相互滑过；这就是为什么沿层界面的擦痕面与拖拽褶皱是 1 类褶皱的诊断证据。
:::
:::

::: exercise 弯滑 {level=2}
在一个砂岩–页岩序列的平行褶皱中，砂岩层在其与页岩的接触面上带有擦痕面，而页岩的小型不对称褶皱躺在砂岩表面上。这些擦痕面记录了什么？这些小褶皱又记录了什么？
::: solution
两者都记录**弯滑**：当一个平行褶皱紧闭时，相邻各层在两翼上相互滑过，其量随翼的倾角增大、而在枢纽处消失。擦痕面给出滑动方向，它位于层理面内、并垂直于褶皱枢纽；而页岩的那些小型不对称褶皱是**拖拽褶皱**，其枢纽指向其上方砂岩相对移动的方向。两者合起来给出每一翼上的滑动指向，因而给出枢纽的位置——这是在枢纽本身没有出露的地方确认一个褶皱解释的标准办法。
:::
:::

::: exercise 褶皱的生长 {level=3}
一个褶皱的振幅在屈曲阶段随时间按 $a = a_0 e^{t/\tau}$ 生长。若初始振幅为 $1\ \mathrm{mm}$、该褶皱今天已达 $1\ \mathrm{m}$、而缩短速率恒定，那么发生了多少个 e 倍的生长？而指数阶段为什么会结束？
::: solution
e 倍数为 $\ln(a/a_0) = \ln(1000/1) = 6.9$。六到七个 e 倍是典型的：初始扰动只需一毫米，褶皱在七个 e 倍之内就长到一米；这就是为什么褶皱的核部如此普遍地保存着早期、更大波长的残余证据。

指数阶段因三个原因而结束，而三者都在野外可见。褶皱的振幅变得与波长相当，于是给出指数生长的线性理论不再适用，生长因而减慢。两翼向缩短方向旋转，这减小了驱动屈曲的那个缩短分量，并把应变转移到两翼的平行层面缩短上。而各层可能断裂，此后褶皱就靠绕枢纽的翼旋转、而不是靠初始扰动的放大来生长。一个两翼直立而枢纽圆滑的褶皱，通常已走完全部三个阶段，而其振幅因此不是缩短的度量。
:::
:::

::: exercise 三维几何 {level=3}
一个地层在 A 点向正北倾 $40^\circ$，在 A 点正南 $3\ \mathrm{km}$ 的 B 点向正南倾 $40^\circ$，在 A 点正东 $2\ \mathrm{km}$ 的 C 点向北偏西 $5^\circ$ 倾 $40^\circ$。解释这个构造并求枢纽的倾伏。
::: solution
在一条近南北线上倾角等值而方向相反，意味着枢纽在两点之间近东西向延伸；而因为地层**背向**中间那条带倾斜，这个构造是一个**背斜**。波长至少 $6\ \mathrm{km}$，因为两个枢纽在 A 与 B 之外。

C 点位于同一翼上、位于一条平行于枢纽的线上；其倾角大小相同，而倾向偏到北偏西 $5^\circ$。因此倾角矢量有一个 $40^\circ$ 的向北分量，与一个向西的分量 $\beta$，满足
$$
\tan 5^\circ = \frac{\beta}{40} \quad\Longrightarrow\quad \beta = 40\times0.0875 = 3.5^\circ .
$$
一个翼上有向西的倾角分量意味着枢纽**向西倾伏**，约 $3.5^\circ$。这个作图就是标准的倾角矢量法或面极点法；严格的处理是把两个极点投在等角网上并量其夹角。对上述这样缓的倾伏，上面的小角度算术可精确到零点几度。

注意这三个读数**没有**给出什么：振幅、真实波长，或者这个构造究竟是背斜还是向斜。最后一点需要一个指向年轻的方位、一个层向判据或一口钻孔；而在尝试任何解释之前，这是必须建立的最要紧的单个事实。
:::
