一个造山带是一次碰撞的出露部分，而它是唯一一处把一个汇聚边缘的深部构造剥开供人填图的地方。造山带覆盖着五分之一的陆地表面，它们建造并摧毁大陆，它们控制着硅酸盐风化汇从大气中抽取二氧化碳的速率，而它们是新生代之前板块构造的记录被保存下来的主要场所。在构造上它们是这门学科中最难的问题，因为它们把本课程中的每一个机制——摩擦断裂、韧性流动、褶皱、变质作用、岩浆作用与侵蚀——同时运作在几千万年的时间上、运作在一个任何类比实验与任何单个野外观测区都无法把握的尺度上。

## 造山带的类型

::: definition 造山带类型 {#def-orogen-types}
一个**碰撞型（喜马拉雅型）造山带**形成于两个大陆块体汇聚之时，不需要大陆岩石圈的俯冲；其特征是地壳厚达正常厚度的两倍、一个中地壳的低强度层、中地壳向侧向挤出，以及白垩纪到古近纪的海相沉积被逆冲到了前陆之上。一个**增生型（科迪勒拉型）造山带**靠把俯冲板块上刮下的地体加积到边缘而生长，其特征是一条长而窄、有岩浆活动的叠瓦逆冲推覆带、大规模的深成作用，以及一套由大洋碎片、岛弧与大陆薄片的混合物构成的地层。一个**安第斯型造山带**是俯冲带之上、没有大陆碰撞的大陆边缘，其地壳增厚到一点五倍而非两倍。一个**没有缝合线的碰撞造山带**——陆上一块陆上"卡斯卡迪亚型"的增生楔——而它是什么都还没有碰撞进去的那个端元。
:::

::: definition 缝合线、地体与构造岩 {#def-suture}
一条**缝合线**是一个已闭合大洋的迹线，以一条蛇绿岩带、以两侧地层时代与相的改变、以高压变质作用，以及以两个边缘的生物群或古地磁磁极的匹配为标志。一个**地体**是一个被断层限界的、具有一段历史的地壳碎片，这段历史记录在其地层、其化石、其古地磁与其基底中，并与其邻居的不同，因而因而或是**外来的**、或至少是**发生过位移的**。一块**构造岩**是一块强烈面理的变质岩，它已被置换到其原始层理不再能够恢复的程度，而它是每一个造山带核部的特征岩石。
:::

## 一个山带的强度

::: proposition 临界锥角 {#prop-taper}
一个位于底部滑脱面之上的库仑介质楔，在一个唯一的表面坡度——**临界锥角**——上是稳定的，在此处，从背后推它的力恰好被其内部与其底部的强度所平衡。对一个没有底部强度的干楔，锥角不能超过内摩擦角，$\alpha \lesssim \varphi$；当孔隙流体具有压力比 $\lambda = P_p/(\rho g d)$ 时，有效摩擦按 $1-\lambda$ 的比例降低，所以
$$
\tan\alpha_c \approx (1-\lambda)\tan\varphi .
$$
增生楔的实测锥角为 $3^\circ$–$9^\circ$、碰撞造山带的为 $1^\circ$–$3^\circ$，而内摩擦角为 $25^\circ$–$35^\circ$——这要求高孔隙压力，或一个弱的底部滑脱，或两者兼有。
:::

::: example 为什么喜马拉雅只有 2° 的浅锥角 {#ex-taper}
取一个内摩擦角 $\varphi = 30^\circ$、其上地壳孔隙压力比 $\lambda = 0.90$ 的造山带。求临界锥角。然后取同一个造山带、令 $\lambda = 0.4$，并对结果置评。
::: solution
$$
\lambda = 0.90:\quad \tan\alpha_c = 0.10\times0.577 = 0.0577 \quad\Longrightarrow\quad \alpha_c = 3.3^\circ;
$$
$$
\lambda = 0.40:\quad \tan\alpha_c = 0.60\times0.577 = 0.346 \quad\Longrightarrow\quad \alpha_c = 19.1^\circ .
$$
喜马拉雅与西藏的观测锥角，由地形与滑脱面的深度量得，约为 $1^\circ$–$2^\circ$，而喜马拉雅前缘本身略大一点。高孔隙压力的计算复现了它；低孔隙压力的计算则不能，而它会要求一个山带在其整个内部都有二十度的坡度——而那里并不是这样。

这是这门学科中，为碰撞造山带中、上地壳存在超压流体而提供的最有力、也最一般的论证，而它被三个独立的观察所佐证：西藏地震的震源深度在 $20$–$25\ \mathrm{km}$ 处停止，而那正是地壳热到无法破裂的深度；大地测量量得的应变是分散的、而不是定域在山前断层上的；而青藏高原在 $15$–$20\ \mathrm{km}$ 深度有一个低地震波速层，它被读作部分熔融、或被读作卤水。锥角论证是关于整个造山带强度的一句陈述，是从一个地形剖面作出的；而它是地质学中少数几处由一个小测量得出一个大力学结论的地方之一。
:::
:::

::: history
山带的机械解释始于达纳与休斯的收缩地球理论——它把褶皱与逆冲解释为一颗冷却行星的皱纹——以及主张垂直运动的"固定论者"的反论。魏格纳（Wegener）在 1912 年与 1924 年给出了那个决定性的图像：喜马拉雅是印度与亚洲碰撞的产物，地壳像扫雪机的推雪波一样被皱卷起来。斯蒂勒的向斜学派与詹姆斯·凯伊的美国活动带学派在整个 1940 年代打这场争论，而终结它的不是野外地质学，而是 1960 年代的海洋地球物理。凯里（Carey）1958 年的论文提出弧形造山带假说，引入了"一个山带可以由其承载块体的旋转而弯曲"的思想，从而重新打开了几何的问题；而现代综合始于哈密顿 1966 年关于安第斯力学的论文、杜威与伯德 1970 年关于造山作用力学的论文，以及莫尔纳与塔波尼尔 1975 年的论文——后者由印度楔入的几何预言西藏应沿大型走滑断层向东挤出，而这个预言可以用地震的滑动矢量来检验——这是一个构造模型在发表一年之内即被地震学证实的罕见例子。临界锥角理论来自土壤力学，由达伦、乔丹与苏佩在 1984 年为增生楔形式化，并由巴尔与达伦推广到碰撞造山带；而侵蚀与构造的耦合则来自乔丹、克利夫特，以及博蒙、威利特与惠普尔建模学派在 1990 年代的工作。
:::

## 地壳厚度与高程

::: example 西藏应该有多高？ {#ex-tibet}
按艾里均衡，取 $\rho_c = 2700$、$\rho_m = 3300\ \mathrm{kg\,m^{-3}}$、以及一个 $30\ \mathrm{km}$ 厚、位于海平面的参考地壳，一个 $70\ \mathrm{km}$ 厚的地壳应当支撑什么高程？青藏高原位于 $5\ \mathrm{km}$。这个差意味着什么？
::: solution
$$
E = (h_c - h_0)\left(1 - \frac{\rho_c}{\rho_m}\right) = (70 - 30)\times\left(1 - \frac{2700}{3300}\right) = 40\times0.182 = 7.3\ \mathrm{km}.
$$
高原比一个简单的艾里柱所预测的低 $2.3\ \mathrm{km}$。有三种解释，而三者都部分正确。西藏之下的下地壳比正常的**更密**——或是榴辉岩化了，或是被沉入其中的致密地幔所加载——而一个致密的根把地表往下拉。高原之下的地幔是**热的**，因而更轻，这就降低了支撑高程的浮力反差。而地壳并不是一个密度均匀的柱：地球物理模型显示在 $15$–$25\ \mathrm{km}$ 处有一个低速、可能部分熔融的层，它把均衡计算从一个两层的问题变成一个三层的问题。

这个计算在每个造山带中都值得做，因为差的符号是有诊断意义的。一个比艾里预测**更高**的高原，正由对流地幔的动力地形、或由强岩石圈的挠曲强度所支撑——如阿尔蒂普拉诺，那里的俯冲板片把该区托住。一个比艾里预测**更低**的高原有一个致密的根、或一个热的根，而它在重力上是不稳定的：它会侧向扩展——而这恰恰是西藏的向东挤出与其内部伸展性地堑所记录的。
:::
:::

::: example 横过一个造山带的缩短 {#ex-shortening}
一个横过某碰撞造山带的 $600\ \mathrm{km}$ 宽剖面，从其当前状态复原到一个水平的先身。在上地壳它给出前缘逆冲上 $180\ \mathrm{km}$、一套叠瓦逆冲系上 $240\ \mathrm{km}$、以及记录于层减薄中的平行层面缩短 $90\ \mathrm{km}$。独立地，地震折射显示高原之下莫霍面在 $70\ \mathrm{km}$，而前寒武纪的先身地壳厚 $35\ \mathrm{km}$。请由两条途径各求伸展因子并使二者相洽。
::: solution
上地壳的构造给出总缩短
$$
180 + 240 + 90 = 510\ \mathrm{km},
$$
复原长度为 $600 + 510 = 1110\ \mathrm{km}$，所以
$$
\beta_\text{upper} = \frac{1110}{600} = 1.85 .
$$
地壳厚度则独立地给出
$$
\beta_\text{deep} = \frac{70}{35} = 2.00 .
$$
两者在百分之八以内相符，而这个相符正是要点所在：它意味着在脆性上地壳中量得的缩短解释了几乎全部的地壳增厚，被韧性流出该剖面所承担的很少，而从地表到莫霍面的剖面是**平衡的**。

如果这两个数严重不符——比如构造给 1.5、莫霍面给 2.0——那么缺失的 0.5 就必须去某个地方：在最深成像的逆冲之下的缩短、流出或流入该剖面的地壳流动，或一条不垂直于缩短方向的剖面。一个构造的 $\beta$ 与一个地壳厚度的 $\beta$ 的比较，是每一条造山带剖面的标准闭合检验，也是阿尔卑斯、西藏与喜马拉雅那些深反射地震剖面值得其所费的原因。
:::
:::

::: quiz
一个山带的地壳厚度为 $62\ \mathrm{km}$、平均高程为 $5.0\ \mathrm{km}$，而艾里预测为 $5.8\ \mathrm{km}$。这个差暗示什么？
- [ ] 地壳比假设的更不密。
- [x] 地壳根比正常的更密，或其下的地幔是热的。
- [ ] 该山带正被岩石圈的挠曲强度所支撑。
- [ ] 地壳厚度的测量太高了。
::: solution
一个低于预测的高程意味着该柱不如一个简单的两层艾里柱那样有浮力；而如果根是致密的——榴辉岩化的下地壳或沉入的地幔——或者支撑的地幔是热的、因而轻的，就会如此。一个*更不*密的地壳会立得*更高*。一个强岩石圈的挠曲支撑同样抬高一个造山带、而不是降低它，会使差朝反方向走。
:::
:::

## 折返与记录

::: definition 深部岩石的折返 {#def-exhumation}
高压与超高压岩石由若干过程的组合而折返，而这些过程的相对重要性是一场巨大而未解决之争的主题：地表的**侵蚀**；使地壳卸载并让其上升的**伸展断层作用**；一个比它所置换的地幔更轻的地壳碎片的**浮力上升**；一个弱的中地壳层在负载之下向外的**通道流动**；以及先掩埋、后折返的**底垫**。可观察量是一个压力–温度–时间路径，而路径的形状可以区分这些机制：浮力回返给出一个冷的、快的、近等温的减压路径；侵蚀给出一个压力与温度一道下降的路径；而通道流动则给出高温下的近等温减压、随后是快速冷却。
:::

::: example 是哪种机制折返了这些麻粒岩？ {#ex-exhume}
一个麻粒岩相地体在 $520\ \mathrm{Ma}$ 给出 $12\ \mathrm{kbar}$、$850^\circ\mathrm{C}$ 的峰期，而其压力–温度路径从 $12$ 减压到 $5\ \mathrm{kbar}$、期间只冷却了 $30^\circ\mathrm{C}$，然后在 $505$ 与 $490\ \mathrm{Ma}$ 冷却穿过角闪石与黑云母的氩封闭温度。这条路径支持哪种折返机制？平均折返速率是多少？
::: solution
该岩石在 $520$ 到 $505\ \mathrm{Ma}$ 之间从约 $40\ \mathrm{km}$ 上升到 $18\ \mathrm{km}$——$22\ \mathrm{km}$——平均速率为
$$
\frac{22\ \mathrm{km}}{15\ \mathrm{Myr}} = 1.5\ \mathrm{km\,Myr^{-1}} = 1.5\ \mathrm{mm\,yr^{-1}},
$$
然后在 $505$ 到 $490\ \mathrm{Ma}$ 之间从约 $820^\circ\mathrm{C}$ 冷却到 $500^\circ\mathrm{C}$ 以下，速率为 $22\ ^\circ\mathrm{C\,Myr^{-1}}$。

近等温的减压是有诊断意义的特征。单靠侵蚀做不到：一个以 $1.5\ \mathrm{mm\,yr^{-1}}$ 被侵蚀的柱遵循一条 $25\ ^\circ\mathrm{C\,km^{-1}}$ 的地温线，会冷却 $22\times25 = 550^\circ\mathrm{C}$、而不是 $30^\circ\mathrm{C}$。该岩石必须在一个**近绝热**的域中上升，而这要么是一个热而低密度的碎片的浮力上升，要么是负载之下中地壳的侧向通道流动——两者都比热量能扩散出去更快地把岩石向上移动。随后 $505$–$490\ \mathrm{Ma}$ 的快速冷却则是该碎片到达一个侵蚀能够作用的层位，而那 $1500$ 万年的间隔，就是浮力上升所占的时间。

在浮力与通道流动之间作出区分的观察，是折返地体的**侧向展布**。一个浮力碎片横亘几十公里、边界陡；一个通道流动的席体沿走向延伸几百公里，上下以糜棱岩限界，并在其整个长度上带着一条平行于流动方向的拉伸线理。拉达克的措木拉榴辉岩与印度南部的高压麻粒岩坐落在这场争论的两端，而它尚未了结。
:::
:::

::: warning 一个造山带的构造是其地形的记录，而其地形又是其构造的记录
这个循环是真实的，而它是这门学科的核心困难。一个造山带的构造——断层几何、锥角、应变的分布——由均衡与地壳的强度决定地形。地形决定侵蚀，侵蚀决定沉积物在哪里堆积，堆积决定地壳在哪里卸载，而卸载决定驱动断裂的应力。因此侵蚀并不是一个造山带演化的边界条件，而是其中的一个参与者；而现代造山带的构造与其水系格局相关联——南迦巴瓦与喜马拉雅东端的双鼻构造、阿尔卑斯不对称的应变、侏拉前陆褶皱与阿山岩体的生长同步迁移——这些观察正是耦合很强的证据。

对诠释的后果是令人不适的。一个构造地质人员若把一个造山带复原到其"缩短状态"而不考虑已将其一半移走的侵蚀，就是在复原到一个从未存在过的几何形态；而一个把沉积供给当作独立于构造的盆地分析者，是从另一侧犯同一个错误。处理这一点的模型——带有侵蚀定律的耦合热力–力学代码——复现了真实造山带的一阶形状；而它们也表明，同样的边界条件会因侵蚀参数的不同而给出几种非常不同的构造。这是一个警告、而不是一次失败：构造不是单由汇聚速率决定的。
:::

## 通向何处

这里描述的构造由 [[structural-geology/fractures-faults]]、[[structural-geology/folds]] 与 [[structural-geology/shear-zones]] 中的部件建造；它们所记录的变质作用在 [[mineralogy-petrology/metamorphic-reactions]] 与 [[mineralogy-petrology/pt-paths]] 中；均衡与挠曲在 [[geophysics/gravity-isostasy]] 与 [[geophysics/flexure]] 中；它们排出的沉积在 [[sedimentology/basins-sequences]] 中；而塑造它们的侵蚀在 [[geomorphology/landscape-evolution]] 中。

::: summary
- 造山带有三种主要类型——碰撞型、增生型与安第斯型——其差别在于大陆地壳是否俯冲、地体是否被加积、以及地壳增厚多少。
- 一个山带的锥角是其强度的度量，而观察到的 1°–3° 锥角要求近于静水压力的孔隙压力，或一个弱的滑脱面。
- 艾里均衡由地壳厚度预测一个高程，而差的符号告诉你那个根是致密的、热的，还是由动力地形支撑的。
- 浅部缩短与深部缩短是同一缩短在不同层位上的表现；它们必须在一个平衡剖面中合并，而不是相加。
- 近等温的减压证明一块岩石上升得比热量扩散更快，这要求浮力或通道流动、而不是侵蚀。
- 侵蚀与构造是耦合的：构造塑造地形，而地形又驱动那反过来塑造构造的侵蚀。
:::

对 $\varphi = 30^\circ$、$\lambda = 0.8$，求临界锥角。
::: solution
$\tan\alpha_c = 0.2\times0.577 = 0.115$，故 $\alpha_c = 6.6^\circ$。这在天然增生楔的范围之内，这就是为什么它们被认为处于近临界应力状态、并带有中等超压的孔隙流体。
:::

::: exercise 均衡 {level=1 check="3.6"}
按 [[#ex-tibet]] 密度的艾里均衡，一个 $50\ \mathrm{km}$ 厚的地壳支撑什么高程？
::: solution
$E = (50-30)\times0.182 = 3.6\ \mathrm{km}$。这大致是阿尔蒂普拉诺与盆岭高平原的高程，两者都有 $50$–$55\ \mathrm{km}$ 的地壳。
:::

::: exercise 地体检验 {level=2}
科迪勒拉带中一个被断层限界的块体， 携带晚侏罗世的灰岩，含特提斯动物群；一个具洋中脊化学的二叠纪玄武岩；以及一个古地磁磁极，指示 $30°$ 的古纬度，而其周围的原地系统当时在 $5°$。请列出把它确立为一个外来地体的判据，并说明哪个最强。
::: solution
这里有四条判据：**动物群的**（在其边缘地层携带北方或太平洋动物群的带中出现特提斯种）、**地层的**（一个二叠纪的洋中脊玄武岩，它要求一个否则并不存在的大洋）、**古地磁的**（古纬度上 $25°$ 的差）、以及**构造的**（一个被断层限界的块体，其边界是一条逆冲断层或走滑断层）。

古地磁的判据最强，因为它是纬度的一个测量，而不能用相的改变或动物群的迁移来解释；其余的有时可以用一次相变、用一个此后已被完全俯冲掉的大洋、或用绕垂直轴的旋转来解释。需要注意的是古地磁给出纬度、而对经度只有一个很弱的约束，所以一个地体可能向东或向西移动了几千公里而用这个方法探测不到——这就是为什么不列颠哥伦比亚与新西兰的走滑断层是由地体沿其长度的匹配、而不是由其古纬度推断的。
:::
:::

::: exercise 折返速率 {level=2 check="2.5"}
一个榴辉岩在 $130$ 到 $114\ \mathrm{Ma}$ 之间从 $60$ 折返到 $20\ \mathrm{km}$ 深。求平均折返速率（以 $\mathrm{mm\,yr^{-1}}$ 计）。
::: solution
$(60-20)\times10^{6}\ \mathrm{m}/(16\times10^{6}\ \mathrm{yr}) = 2.5\ \mathrm{mm\,yr^{-1}}$。这是快的——比典型的造山带折返快一个量级——而它要求浮力回返、而不是侵蚀，因为地球上没有任何侵蚀能在 $1600$ 万年里移走 $40\ \mathrm{km}$ 的岩石。
:::
:::

::: exercise 冷却速率 {level=2 check="15"}
用 [[#ex-exhume]] 的例子，在角闪石与黑云母的氩封闭温度 $500$ 与 $280^\circ\mathrm{C}$ 之间，平均冷却速率是多少（以 $^\circ\mathrm{C\,Myr^{-1}}$ 计）？
::: solution
$(500-280)/(505-490) = 220/15 = 14.7\ ^\circ\mathrm{C\,Myr^{-1}}$，约 $15$。与 $1.5\ \mathrm{mm\,yr^{-1}}$ 的折返速率结合，这给出冷却期间 $14.7/1.5 = 9.8\ ^\circ\mathrm{C\,km^{-1}}$ 的古地温梯度——一个低梯度，与由逆冲或由伸展对热岩石的快速剥顶相容，而与稳态传导不相容。
:::
:::

::: exercise 沉积通量与锥角 {level=3}
一个造山带以每年 $2\ \mathrm{mm}$ 充填其前陆的速率接受沉积，实际上增加了该楔的底部锥角。用临界锥角的思想，解释为什么一个正在进积的造山带的前缘逆冲，比一个正在侵蚀的要缓；并预测当沉积供给停止时内部构造会发生什么。
::: solution
输送到前陆的沉积物加载于楔的前缘，增加一个**前楔**，加大了抵抗向前扩展的力。在临界锥角的力平衡中，这相当于增大底部摩擦或减小底部坡度，而楔的回应是使其前缘变平，并把一条浅的前缘逆冲向外推覆到新沉积物之上——这就是为什么喜马拉雅、侏拉与安第斯山前带的山前逆冲是铲式的、浅的，为什么它们携带着厚达几公里的地层。

当沉积供给停止，平衡就反转。前缘不再被扶住，锥角变为超临界，而楔以**内部缩短**、而不是前缘扩展来回应：序外的逆冲重新激活带内较老的构造，前缘逆冲被切掉、被悬置，而地形变陡并向内迁移。如果随后侵蚀移走前楔，前缘可能被一条新的、更陡的逆冲截切。这个预测在野外是可检验的——从前缘扩展到内部缩短的转变，应当由前陆的生长地层定年——而它在喜马拉雅东构造结被观察到：那里中新世从前缘扩展到序外逆冲的转变，跟随着前陆侵蚀与沉积格局的一次变化。
:::
:::

::: exercise 一个综合 {level=3}
一个碰撞造山带显示：一个 $400\ \mathrm{km}$ 宽、高程 $4.8\ \mathrm{km}$、地壳厚 $68\ \mathrm{km}$ 的高原；一个 $15\ \mathrm{km}$ 厚、位于 $18$–$22\ \mathrm{km}$ 的低速层；一个 $800\ \mathrm{km}$ 宽、含 $7\ \mathrm{km}$ 新近纪沉积的前陆盆地；以及一组位于高原内部、落差 $2\ \mathrm{km}$、时代年轻于 $8\ \mathrm{Ma}$ 的近东西向伸展性地堑。请解释整体，并指出最薄弱的一环。
::: solution
$68\ \mathrm{km}$ 的地壳厚度按艾里均衡应当支撑 $6.9\ \mathrm{km}$，所以位于 $4.8\ \mathrm{km}$ 的高原低了 $2.1\ \mathrm{km}$——那个根是致密的或热的，而地壳在重力上是不稳定的。$18$–$22\ \mathrm{km}$ 的低速层就是那个中地壳通道：部分熔融或含卤水，软弱，是上地壳沿之扩展的滑脱面。前陆的 $7\ \mathrm{km}$ 沉积是生长中楔的挠曲负载、以及已从其上侵蚀掉的质量，而其厚度要求新近纪期间持续约 $1$–$2\ \mathrm{mm/yr}$ 的侵蚀速率。那些伸展性地堑是有诊断意义的构造：它们记录着过厚地壳的**重力垮塌**，上地壳近东西向伸展，而其下的中地壳同时向外流动。

最薄弱的一环是对那个低速层的解释。$18$–$22\ \mathrm{km}$ 的部分熔融要求该深度有 $700$–$800\ ^\circ\mathrm{C}$ 的温度，这暗示一条远高于传导的地壳地温线，并暗示中地壳在力学上是软弱的——而整个通道流动或挤出模型正建立在这个假设上。对同一个低速度的另一种读法，是在一块强而冷的岩石中一层含水卤水或定向的云母；若是那样，中地壳就不软弱，通道流动模型便告失败，而高原的演化必须用纯剪增厚与侵蚀驱动的垮塌来解释。这两种读法由热流、由大地电磁测深电导率、由该深度温度的捕虏体与地震证据来区分——而它们尚未被区分开。
:::
