剪切带是地壳移动过的地方，而它是地球上承担大部分位移的构造。浅地壳中的一个断层是一个面；而 10 km 之下韧性地壳中的一个剪切带是一个**带**，宽几十米到几十公里，其中的岩石被拉伸、被剪切、被重结晶，而且通常还被流体冲洗过。因为剪切带中的岩石颗粒细、致密连贯、并长满了在变形期间生长的矿物，剪切带也是构造地质学最接近于实验室的东西：它在同一个手标本中保存着一个事件的压力、温度、应力、应变、应变速率、流动几何与剪切指向。

## 断层岩

::: definition 断层岩系列 {#def-fault-rocks}
在浅部由脆性变形形成的岩石是**碎裂的**：若碎屑颗粒可见，则是颗粒状、致密的**碎裂岩**；若它们富黏土而细、且无内聚强度，则是**断层泥**。在地震滑动的断层上由摩擦熔融形成的岩石是**熔蚀岩（假流纹岩）**，一种黑色玻璃质或细晶的脉，它的存在证明该断层曾以每秒厘米的速度滑动。在深部由晶质塑性变形并伴随粒度减小而形成的岩石是**糜棱岩**：**原糜棱岩**失去不到一半的原始颗粒，**糜棱岩**是一个混合良好的细粒岩石，而**超糜棱岩**残留的斑碎晶不到百分之十。**叶糜棱岩**是一种主要在富层状硅酸盐的岩石中由晶界滑动形成的糜棱岩，而**眼状糜棱岩**在细粒基质中保存着大的斑碎晶（"眼"）。
:::

::: definition 叶理、线理与 C–S 组构 {#def-cs}
一个糜棱岩有一个**糜棱面理** $S$，由颗粒的形状优选方位与成分层理定义；另有一个**拉伸线理** $L$，由长形颗粒、或由 $S$ 与第二个组构的交线线理定义。随剪切增大，第二组面——**C 面**（取自德语 *Schiebung*，剪切，首字母 C）——作为垂直于 $S$ 的、间距很密的剪切带发育出来。$S$ 与 $C$ 之间的角 $\theta$ 随累积剪切稳定下降；而对一个由初始等轴状态经纯简单剪切变形的岩石，
$$
\gamma \approx \cot\theta .
$$
C 面在大应变时变得平行于剪切面，这就是为什么强烈变形的糜棱岩只有一个近乎平面的单一组构、而没有内部的剪切指向标志。
:::

::: example 一个手标本能给出多少剪切？ {#ex-sc}
一个长英质糜棱岩的 $S$–$C$ 斜交角为 $20^\circ$。估计剪应变，以及若剪切带宽 $40\ \mathrm{m}$ 时的位移。
::: solution
$$
\gamma = \cot 20^\circ = 2.75 .
$$
在一个 $40\ \mathrm{m}$ 宽的带上，这是 $2.75\times40 = 110\ \mathrm{m}$ 的位移。

两条告诫。关系 $\gamma = \cot\theta$ 假设岩石开始时没有任何面理、并以纯简单剪切变形；如果一开始就存在一个与剪切面成角的面理，那么观察到的斜交角就是一个复合结果，可能比简单剪切的值小，也可能比它大。而当 $\theta$ 小于约 $15^\circ$ 时，两个面相距仅几毫米、在野外无法分辨，所以这个方法在 $\gamma$ 约四之处饱和。更大的应变，唯一可靠的估计只能来自变形标志——一条脉、一条岩墙、一个鲕粒——或来自一个斑碎晶的内部组构。
:::
:::

::: widget plot

caption: 以度数表示的 $S$–$C$ 斜交角 $\theta$ 所隐含的剪应变。曲线在小 $\theta$ 处很陡，这正是其实际困难：$60^\circ$ 的斜交角记录 $0.6$ 的剪切，$20^\circ$ 的记录 $2.8$，$10^\circ$ 的记录 $5.7$；而 $10^\circ$ 与 $8^\circ$ 之间——应变相差 1.25 倍——在手标本上难以测量、在图上更是不可能。因此这个方法擅长识别中等应变、擅长指示剪切指向，而不擅长度量大的应变。
:::

::: history
这个名字来自拉普沃思（Lapworth），他 1885 年为莫因逆冲带上那些细层状、碎裂的岩石创造了"糜棱岩"一词——源自希腊语 *mylos*，磨坊——而他当即就明白，它们标记的是一个运动带、而不是一个单独的面。断层与剪切带之别在整个二十世纪上半叶被争论，而里斯 1949 年对莫因逆冲带在莫因与本莫尔穹隆中的分析，确立了该带深部的韧性性质。实验基础来自克里斯蒂 1965 年关于刘易斯片麻岩中"糜棱岩"的论文——它首次以晶质塑性变形与动态重结晶解释其显微组构——以及埃亚森与帕特森同时认识到细粒集合体的流动是粒度敏感的。运动学装置于 1970 与 1980 年代到来：贝尔泰、丘克鲁内与马尔库 1979 年工作的 $S$–$C$ 组构及其应变解释；同年利斯特与威廉姆斯的云母鱼；汉默以及辛普森与施密德编目的剪切指向判据；以及辛普森的运动学涡度函数——它首次给纯剪切与简单剪切之差一个单一的数。石英的粒度压应力计来自施蒂尼茨、赫曼与塔利斯 1980 与 1990 年代实验工作，而把它用于天然糜棱岩至今仍有争议——而这正是它应有的样子，因为争论的实质是深地壳究竟能不能被读懂。
:::

## 运动学：怎么判断它朝哪边走

::: definition 剪切指向判据 {#def-ssc}
一个**剪切指向标志**是一个其不对称性相对于流动具有确定手性的组构。可靠的有：

**$\sigma$ 型与 $\delta$ 型斑碎晶。**一个在剪切基质中的刚性斑碎晶会发育一个细粒重晶生物质的幔，它是不对称的，有一片在剪切方向上拖在后面的"翼"；$\sigma$ 型的翼与基质连续，$\delta$ 型的则脱离并旋转。

**云母鱼。**一个云母颗粒在剪切中旋转，若它连续重结晶，就采取一条鱼的形状，其"尾"逆着剪切方向后退。

**斜交面理与斜交云母。**面理的极点斜交于剪切面，且位于剪切方向的另一侧。

**$C'$ 剪切带。**与主 C 面成高角的次级剪切带，形成一个共轭组，其锐角平分线即剪切方向。

**面理鱼与 f 面理。**被褶皱的 C 面，其不对称性记录着剪切。
:::

::: proposition 涡度与流动类型 {#prop-vorticity}
一个定常的二维流动是一个无旋（同轴）部分与一个简单剪切（非同轴）部分的叠加，而其几何由**运动学涡度数**度量：
$$
\omega = \frac{\text{rotational rate}}{\text{stretching rate}}, \qquad 0 \le \omega \le 1 .
$$
纯剪切有 $\omega = 0$，简单剪切有 $\omega = 1$，而而一般的韧性剪切带介于两者之间。对定常流动，物质线以依赖于 $\omega$ 的速率向剪切面旋转，而最大拉伸方向与剪切面之间的角 $\theta_\text{max}$ 满足
$$
\cos 2\theta_\text{max} = \omega ,
$$
所以纯剪切时 $\theta_\text{max} = 45^\circ$，简单剪切时 $0^\circ$。
:::

::: example 纯剪切还是简单剪切？ {#ex-vorticity}
在一个糜棱岩中，对变形标志的有限应变分析把最大拉伸方向放在距剪切面 $30^\circ$ 处。估计 $\omega$，并说明你还会去找什么。
::: solution
由 $\theta_\text{max} = 30^\circ$，
$$
\omega = \cos 2\theta_\text{max} = \cos 60^\circ = 0.50 .
$$
因此这个流动大约一半是简单剪切、一半是纯剪切——即一般剪切，而它在壳尺度的剪切带中是常态、不是例外。

这个估计必须拿独立的观察来检验。以纯剪切为主的带应当**没有一致的剪切指向不对称**：斑碎晶的翼应当两个方向都有、没有优选的手性，而云母鱼也不应有系统的斜交。一个 $\omega = 0.5$ 的带应当在约一半的颗粒中显示不对称。在几公里范围内每个斑碎晶都显示完全一致的不对称，意味着 $\omega$ 接近一、而组构极点的估计是错的，通常是因为把"剪切面"认成了面理、而不是 C 面。反之，在一个显然搬运了几公里位移的带中到处找不到不对称，则意味着位移是由平行层面缩短、而不是由简单剪切承担的——这在深地壳中是一个真实而未被充分重视的可能。
:::
:::

::: quiz
一个糜棱岩在 5 km 的范围内、在每个斑碎晶上都显示强的、一致的向西不对称，而其 $S$–$C$ 斜交角为 $12^\circ$。最好的解释是什么？
- [x] 一个强烈非同轴、以简单剪切为主的流动，剪应变约五或更大。
- [ ] 一个以纯剪切为主、带一个小的旋转分量的流动。
- [ ] 两个方向相反的变形期。
- [ ] 斜交角太小而没有意义，所以什么也说不了。
::: solution
在几公里范围内每个颗粒都一致的不对称，意味着流动的旋转部分占主导，所以 $\omega$ 接近一、流动接近简单剪切。$12^\circ$ 的斜交角给出 $\gamma = \cot 12^\circ = 4.7$，而因为 $S$–$C$ 方法在大应变处饱和，真实应变至少是这个数。纯剪切根本不产生一致的不对称，而两个相反的期会给出一个混合的群体。
:::
:::

## 由糜棱岩求应力、应变速率与宽度

::: example 由粒度作古压应力计 {#ex-piezo}
一个糜棱岩中重结晶的石英颗粒平均 $25\ \mu\mathrm{m}$。用石英的、经流动定律标定的关系 $d = 2\times10^{3}\,\sigma^{-1.2}$（$d$ 以 $\mu\mathrm{m}$、$\sigma$ 以 MPa 计）求差应力；然后把它与一个写成归一化形式的流动定律
$$
\dot{\varepsilon} = 10^{-14}\left(\frac{\sigma}{40\ \mathrm{MPa}}\right)^{3}\ \mathrm{s^{-1}}
$$
结合，求应变速率，以及一个 $20\ \mathrm{km}$ 宽剪切带上的位移速率。
::: solution
$$
\sigma^{1.2} = \frac{2\times10^{3}}{25} = 80
\quad\Longrightarrow\quad
\sigma = 80^{1/1.2} = e^{4.382/1.2} = 39\ \mathrm{MPa}.
$$
于是
$$
\dot{\varepsilon} = 10^{-14}\left(\frac{39}{40}\right)^{3} = 9.3\times10^{-15}\ \mathrm{s^{-1}},
$$
而在一个 $20\ \mathrm{km}$ 宽的带上，位移速率为
$$
9.3\times10^{-15}\times2\times10^{4} = 1.9\times10^{-10}\ \mathrm{m\,s^{-1}} = 5.9\ \mathrm{mm\,yr^{-1}} .
$$

这是一个板块构造量级的位移速率，而这类数字正是使人不信任这个方法的原因——部分是有道理的。石英的粒度古压应力计在 20–200 MPa 的应力上标定，把实验室粒度复现到应力的约两倍之内；而应变速率继承了那个误差的三次方，所以应力上的两倍误差就是应变速率上的八倍。$37\ \mathrm{mm\,yr^{-1}}$ 的位移速率，同样可能是 $5$ 或 $300$。这个计算确实确立的、而且稳健地确立的是：该剪切带**以一个地质应变速率在主动变形**、而不是在记录一次单独的地震事件，而应力在几十兆帕的量级——而这才是对地壳强度要紧的那个数。
:::
:::

::: example 积分一个应变剖面 {#ex-profile}
横过一个糜棱岩带，剪应变自核心按 $\gamma(x) = \gamma_0\,e^{-|x|/w}$ 衰减，中心处 $\gamma_0 = 6$、$w = 300\ \mathrm{m}$。求总位移，并解释为什么剪切带的宽度按惯例由一条应变等值线、而不是由一个岩性边界来定义。
::: solution
位移是应变横过该带的积分，
$$
D = \int_{-\infty}^{\infty}\gamma_0\,e^{-|x|/w}\,\mathrm{d}x = 2\gamma_0 w = 2\times6\times300 = 3600\ \mathrm{m}.
$$
那个位移的一半——$1.8\ \mathrm{km}$——在中心两侧一个 $w$ 之内被承担，那里应变高于 $6/e = 2.2$；另一半则在外翼，那里应变低于此值。

指数剖面没有边缘：应变永远不会恰好为零，所以"剪切带的宽度"就是你选择画的那条应变等值线。惯例是报告应变超过某个阈值的宽度——通常取 $\gamma = 1$，或可见糜棱岩化岩石的宽度——并把阈值说明白，因为同一个带在 $\gamma > 2.2$ 时可报为 $600\ \mathrm{m}$ 宽、在 $\gamma > 0.5$ 时可报为 $2\ \mathrm{km}$ 宽，而两者都对。因此，一张把剪切带画成一条线的构造图，是在断言位移局部化到了一个画不出来的宽度之内；而一张把它画成 5 km 宽的带的图，则在断言相反的事。作出裁决的是应变剖面，而它是关于一个剪切带的少数几件无法从单个露头推断的事情之一。
:::
:::

::: warning 剪切带未必意味着大位移
认为一个糜棱岩带必定标记一条大断层的直觉，常在两个方向上都错。糜棱岩记录的是**有限应变**、不是位移，而一个两米宽的带上五的应变只是十米的位移，同样一个应变在二十公里宽的带上则是一百公里的位移。反之，一个几十米宽、位移只有几十米的剪切带，可以在野外非常壮观而在构造上无足轻重。

因此宽度与应变同样重要，而它恰恰是剪切带理论预测得最不好的那个量。应变局部化会失控——一个带在变形时弱化、应变集中，宽度本应塌缩到几厘米——所以观察到的几百米到几十公里的宽度，要求有一个**扩散性的反过程**把应变铺开：热传导、晶粒生长、使粒度复位的流体加入，或者被位移的块体必须在某处被容纳这一几何要求。这几者中哪一个胜出决定了宽度，而它们没有一个清楚到足以预测它。诚实的做法是横过该带的全宽、从围岩到核心测量应变剖面，并把位移作为积分值报告出来。
:::

## 通向何处

支配剪切带强度的流动定律见 [[structural-geology/rheology]]；在剪切带尖端形成的脆性构造见 [[structural-geology/fractures-faults]]；在剪切带中生长的褶皱见 [[structural-geology/folds]]；大的低角度剪切带所建造的伸展性核杂岩见 [[structural-geology/rifts]]；而俯冲通道的类比见 [[geophysics/earthquake-sources]]。

::: summary
- 断层岩记录变形机制：碎裂岩与断层泥是脆性的，糜棱岩是晶质塑性的，熔蚀岩是摩擦熔体。
- $S$–$C$ 斜交角按 $\gamma \approx \cot\theta$ 给出剪应变，并在应变约四以上饱和。
- 剪切指向判据——斑碎晶翼、云母鱼、斜交组构、$C'$ 剪切带——记录着流动的旋转部分，而需要一个一致的群体、而不是单个颗粒。
- 运动学涡度数度量简单剪切与纯剪切之比，而大多数壳尺度剪切带位于两个端元之间。
- 重结晶粒度是一个压应力计；与流动定律结合就给出应变速率。应力的可靠度为两倍，应变速率则为一个数量级。
- 一个剪切带的位移是其应变横过其宽度的积分，而宽度是三者中最难预测的。
:::

## 练习

::: exercise 断层岩 {level=1}
不用显微镜，在野外区分断层泥与糜棱岩。
::: solution
**断层泥**无层理或层理很弱，软到可以用小刀划动，通常富黏土、常常是湿的，并在细粒基质中含有围岩的棱角状碎块；它形成于几公里或更浅的深度。**糜棱岩**坚硬、致密连贯、有层理或叶理，在叶理面上常常光亮或呈银白色，并在细而结晶的基质中含有被拉伸和旋转的斑碎晶；它形成于 10 km 或更深的深度。决定性的野外检验是：该岩石是具有一片穿透性叶理、其中有被拉伸的眼——塑性——还是一块碎裂的、软的、无构造的核心——脆性。
:::
:::

::: exercise S–C 应变 {level=1 check="1.73"}
一个 $S$–$C$ 糜棱岩的斜交角为 $30^\circ$。估计剪应变。
::: solution
$\gamma = \cot30^\circ = 1.73$。在一个 $10\ \mathrm{m}$ 宽的带上，这相当于 $17\ \mathrm{m}$ 的位移。
:::
:::

::: exercise 涡度 {level=1 check="1"}
在一个流动中，物质线稳定地向剪切面旋转，而拉伸方向恰好落在剪切面上；其运动学涡度数是多少？
::: solution
$\omega = 1$：定常的简单剪切。纯剪切有 $\omega = 0$、物质线完全不旋转。
:::
:::

::: exercise 压应力计 {level=2 check="78"}
一个糜棱岩中重结晶的石英颗粒平均 $10\ \mu\mathrm{m}$。用 $d = 2\times10^{3}\sigma^{-1.2}$，求以 MPa 计的差应力。
::: solution
$\sigma^{1.2} = 2000/10 = 200$，故 $\sigma = 200^{1/1.2} = e^{5.298/1.2} = 78\ \mathrm{MPa}$。十微米的粒度对一个石英糜棱岩而言异常地细，通常指示以下情形之一：高应力、低温，或者一个继承自前驱岩石而从未被复位的细粒度。这就是为什么在使用压应力计之前，必须检查粒度分布，以及晶粒是否在变形之后生长过。
:::
:::

::: exercise 位移 {level=2 check="600"}
一个 $3\ \mathrm{km}$ 宽的剪切带有均匀的剪应变 0.2。位移是多少米？
::: solution
$D = \gamma w = 0.2\times3000 = 600\ \mathrm{m}$。一个三公里宽的糜棱岩带只有 600 m 的位移，是一个**弥散的**剪切带，而这是一个警示信号：要么应变并不均匀、位移集中在一个更窄的核心之中，要么该带记录的是一个广大地区的平行层面缩短、而不是一条不连续断层。
:::
:::

::: exercise 应变速率 {level=2 check="0.53"}
使用 [[#ex-piezo]] 的流动定律，$15\ \mathrm{MPa}$ 的差应力对应什么应变速率？答案以 $10^{-15}\ \mathrm{s^{-1}}$ 为单位给出。
::: solution
$\dot{\varepsilon} = 10^{-14}(15/40)^{3} = 10^{-14}\times0.0527 = 5.3\times10^{-16}\ \mathrm{s^{-1}} = 0.53\times10^{-15}\ \mathrm{s^{-1}}$。这个练习的要点是指数的杠杆作用：应力从 $39$ 降到 $15\ \mathrm{MPa}$——即 2.6 倍——会使应变速率下降十七倍；因此古压应力计上两倍的误差，就相当于应变速率上的一个数量级。

::: exercise 由斑碎晶判断剪切指向 {level=2}
一个石英基质中的长石斑碎晶有两片重结晶石英的翼，一片较长、向北收敛，另一片较短、较钝、在南侧，而两翼都与基质连续。这是一个 $\sigma$ 型还是一个 $\delta$ 型斑碎晶？它对剪切指向说了什么？
::: solution
连续的翼使它成为一个 **$\sigma$ 型**斑碎晶，这种类型在相对低的应变与温度下形成，并最可靠地保存剪切指向。翼沿着基质相对于斑碎晶的剪切方向拖在后面，所以较长、收敛的那片翼指向斑碎晶之上基质的移动方向——此处为向北，指示向北的剪切。

这里的告诫是：较长的那片翼并不总是拖后的那片。在高应变下两翼会变得对称，而在低应变下，不对称可能反映的是原始斑碎晶自身的形状、而不是流动。检验办法是看一个群体：量三十个颗粒的不对称并寻找一致的手性，并检查斜交面理与云母鱼是否给出同一指向。
:::

::: exercise 作为流体通道的剪切带 {level=3}
一个花岗岩质原岩中 $100\ \mathrm{m}$ 宽的糜棱岩带含百分之十二的白云母，而其围岩含百分之二。糜棱岩化发生在 $450^\circ\mathrm{C}$、6 kbar，应变为 3。估计每立方米岩石通过了多少流体的质量，并解释为什么剪切带是造山型金的通道。
::: solution
多出的云母是下述反应的产物： $\mathrm{feldspar} + \mathrm{H_2O} \to \mathrm{white\ mica} + \mathrm{quartz} + \mathrm{K^+}$ 的产物，所以所消耗的水大致正比于多出的云母。把多出的百分之十云母取为约需岩石质量百分之四的 $\mathrm{H_2O}$，并取岩石密度为 $2650\ \mathrm{kg\,m^{-3}}$，所消耗的水为
$$
0.04\times2650 = 106\ \mathrm{kg\,m^{-3}} .
$$
这是流体通量的一个**下限**，因为通过的大部分流体只是通过了而已。在一个 $100\ \mathrm{m}$ 宽的带中、在 $10^6$ 年积累的应变 3 之上维持这个反应所需的通量，量级为 $10^{3}$–$10^{4}\ \mathrm{kg\,m^{-2}}$，这占地壳水储量的相当大一部分。

与矿床的联系在于：剪切带是中、下地壳中唯一同时满足三项要求的地方——由细粒、微裂缝与连通的云母组构创造的**渗透率**；由一个深部超压源与一个浅部水静汇之间的压力梯度驱动的**通道化流动**；以及**一个化学陷阱**，因为压力与温度的降低、与较冷围岩流体的混合、或在剪切带遇到一个活性岩性之处流体硫化物活度的改变，都会使流体所携带的物质沉淀出来。世界上几乎每一个造山型金矿——阿比提比、伊尔岗与阿尔卑斯的裂隙脉——都位于一条壳尺度的剪切带上，而矿化比峰期变质更年轻，且与主期剪切同时。
:::

::: exercise 宽度与位移 {level=3}
两个剪切带有相同的峰值应变 8 与相同的位移 $20\ \mathrm{km}$。A 带宽 $200\ \mathrm{m}$、边界清晰；B 带宽 $20\ \mathrm{km}$、边界渐变。描述这两个应变剖面，并说哪一个更可能有过地震活动。
::: solution
A 带必须把其全部 $20\ \mathrm{km}$ 容纳在 $200\ \mathrm{m}$ 之内，所以其平均应变为 100——远高于所述的峰值 8。这些数字是不相容的；解决之道在于应变并不均匀：剖面强烈尖峰化，而"峰值应变 8"是在可见糜棱岩边缘的围岩中、而不是在位移实际局部化于其中的超碎裂岩核心中测得的。A 带是一个**局部化的、应变软化的**剪切带，而这种带正是会发生地震破裂的那一类，因为局部化会集中应力，而细粒、贫水的核心具有高摩擦。

B 带宽 $20\ \mathrm{km}$，平均应变 1.0、峰值 8，所以其剖面宽缓而呈网脉状：应变分布在未变形的低应变岩块周围的网脉状糜棱岩条带之间。这样的带在几百米深度以上以晶质塑性蠕变**无震地**变形，而其位移在数千万年之中积累。这个区别对灾害要紧：在发震地壳底部的一条宽阔韧性剪切带是蠕变的，而破裂的断层是其上覆盖层中的脆性断层——它们的几何受下伏韧性组构控制，但不由其决定。
