褶皱是一个力的记录，而这个力可以从它恢复出来。这就是构造地质学的抱负，而它依赖于一个值得在一开始就讲清楚的区分。力施加在一个物体上；应力施加在物体*内部的一个面*上，并且依赖于那个面的产状。同一个应力状态可以在一个面上产生五十兆帕的剪应力、在另一个面上什么也不产生，而正是所有产状上剪应力的格局决定了一块岩石是否破裂、以及朝哪个方向破裂。本章几乎一切都来自认真对待这种依赖关系。

地壳中的岩石并不强。使它们变形所需的应力只有几十兆帕，比实验室里同种岩石圆柱体的抗压强度低一个数量级，因为地质有数百万年的时间、还有孔隙中的水。其结果就是，地壳保存着一种应力的记录：这些应力小到足以由岩石的重量和对流的软流圈的拖曳产生，又大得足以从岩石本身读出来。

## 面力与应力张量

::: definition 面力与应力 {#def-traction}
法向单位矢量为 $\mathbf{n}$ 的一个内部面上的**面力**（traction）$\mathbf{T}^{(\mathbf{n})}$ 是通过该面传递的单位面积上的力。一点的**应力**是把一个法向方向映到具有该法向的面上的面力的线性映射，在选定的坐标系中它是二阶张量
$$
\boldsymbol{\sigma} = \begin{pmatrix} \sigma_{xx} & \sigma_{xy} & \sigma_{xz} \\ \sigma_{yx} & \sigma_{yy} & \sigma_{yz} \\ \sigma_{zx} & \sigma_{zy} & \sigma_{zz} \end{pmatrix},
\qquad
T_i^{(\mathbf{n})} = \sigma_{ij} n_j .
$$
对角项是**正应力**，非对角项是**剪应力**；第一个下标指明面，第二个指明方向，因此 $\sigma_{xz}$ 是法向为 $z$ 的面上沿 $x$ 方向的面力。
:::

::: proposition 应力张量是对称的 {#prop-symmetric}
在没有体力偶的情况下，$\sigma_{ij} = \sigma_{ji}$。因此一点的应力状态由六个独立的数、而不是九个数确定，并且总存在一组相互正交的三个方向，其上的面力完全垂直于该面。
:::

::: proof
对边长为 $\mathrm{d}x$、$\mathrm{d}y$、$\mathrm{d}z$ 的长方体单元绕竖直轴平衡力矩。来自两个法向为 $x$ 的面上的剪力的力偶，其力臂为 $\mathrm{d}y$、力为 $\sigma_{xy}\,\mathrm{d}y\,\mathrm{d}z$，给出扭矩 $\sigma_{xy}\,\mathrm{d}x\,\mathrm{d}y\,\mathrm{d}z$；来自法向为 $y$ 的面上的剪力的力偶为 $\sigma_{yx}\,\mathrm{d}x\,\mathrm{d}y\,\mathrm{d}z$，方向相反。平衡要求二者相等，故 $\sigma_{xy} = \sigma_{yx}$，其余各对循环同理。体积因子消掉了，这就是为什么该结论在一点上成立、且与单元的大小无关。

关于第二个结论，一个实对称矩阵具有实特征值和相互正交的特征向量：二次型 $\mathbf{n}\cdot\boldsymbol{\sigma}\mathbf{n}$ 在单位球上取得最大值，而在该最大值处面力必定平行于 $\mathbf{n}$；否则把 $\mathbf{n}$ 转向面力的切向分量就会增大法向分量。如此得到的特征向量就是一个**主方向**；把 $\boldsymbol{\sigma}$ 限制到与之正交的平面上，得到一个对称的 $2\times2$ 映射，还有两个进一步的正交特征向量。三个特征值就是**主应力** $\sigma_1 \geq \sigma_2 \geq \sigma_3$，在该基下张量是对角的，每个剪应力都为零。
:::

::: definition 主应力、平均应力与偏应力 {#def-principal}
**平均应力**（（按地质学的符号约定即岩石静压力））为
$$
\sigma_m = \tfrac13(\sigma_1 + \sigma_2 + \sigma_3),
$$
**偏应力**为 $\mathbf{s} = \boldsymbol{\sigma} - \sigma_m\mathbf{I}$。**差应力**为 $\Delta\sigma = \sigma_1 - \sigma_3$。两部分承担着完全不同的任务：平均应力改变岩石的体积并闭合其裂隙，偏应力改变其形状，而且是唯一能引起屈服或断开的部分。偏应力的第二不变量
$$
J_2 = \tfrac12 s_{ij}s_{ij} = \tfrac16\left[(\sigma_1-\sigma_2)^2 + (\sigma_2-\sigma_3)^2 + (\sigma_3-\sigma_1)^2\right],
$$
是流动定律中使用的偏应力的标尺度，$\sqrt{J_2}$ 与八面体剪应力成正比。
:::

::: example 平原之下地壳中的应力 {#ex-lithostatic}
取密度为 $\rho = 2700\ \mathrm{kg\,m^{-3}}$ 的地壳。求 $5\ \mathrm{km}$ 深度与 $30\ \mathrm{km}$ 深度处的竖直应力，并说明若该区不受构造载荷，水平应力应当是什么。
::: solution
竖直应力为上覆柱的重量，
$$
\sigma_v = \rho g z = 2700\times9.81\times5000 = 1.32\times10^{8}\ \mathrm{Pa} = 132\ \mathrm{MPa},
$$
在 $30\ \mathrm{km}$ 处为 $793\ \mathrm{MPa}$。一个值得记住的数是：地壳岩石的 $\rho g = 26.5\ \mathrm{MPa\,km^{-1}}$，橄榄岩的 $32\ \mathrm{MPa\,km^{-1}}$；而 $100\ \mathrm{MPa} = 1\ \mathrm{kbar}$，所以每公里地壳柱重约 $0.27\ \mathrm{kbar}$。

没有地形也没有构造载荷时，水平应力并不必等于竖直应力。与周围地壳的弹性耦合给出
$$
\sigma_H = \frac{\nu}{1-\nu}\,\sigma_v = 0.38\,\sigma_v
$$
（泊松比 $\nu = 0.28$），因此在 $5\ \mathrm{km}$ 处 $\sigma_H \approx 50\ \mathrm{MPa}$。在真实的上地壳中水平应力几乎总是大于此值，而且常常大于竖直应力，因为存在构造挤压；$\sigma_1$、$\sigma_2$、$\sigma_3$ 三种可能的排序正是下面安德森断层理论的主题。
:::
:::

## 莫尔圆

::: theorem 莫尔的作图 {#thm-mohr}
对于主应力为 $\sigma_1$ 与 $\sigma_3$ 的二维应力状态，法线与 $\sigma_1$ 方向成 $\theta$ 角的面上，正应力与剪应力为
$$
\sigma_n = \frac{\sigma_1+\sigma_3}{2} + \frac{\sigma_1-\sigma_3}{2}\cos 2\theta,
\qquad
\tau = \frac{\sigma_1-\sigma_3}{2}\sin 2\theta .
$$
当 $\theta$ 变化时，点 $(\sigma_n, \tau)$ 落在一个**圆**上，其半径为 $(\sigma_1-\sigma_3)/2$、圆心在 $((\sigma_1+\sigma_3)/2,\,0)$，而圆上的角是物理角的两倍。
:::

::: proof
分解该面上的面力。主面力 $\sigma_1$ 与 $\sigma_3$ 作用在相互垂直的面上；所关心的面在主基中的法向为 $\mathbf{n} = (\cos\theta, \sin\theta)$，故面力为 $\mathbf{T} = (\sigma_1\cos\theta, \sigma_3\sin\theta)$。其法向分量为 $\sigma_n = \mathbf{T}\cdot\mathbf{n} = \sigma_1\cos^2\theta + \sigma_3\sin^2\theta$，切向分量为 $\tau = |\mathbf{T} - \sigma_n\mathbf{n}| = (\sigma_1-\sigma_3)\sin\theta\cos\theta$。应用倍角公式 $\cos^2\theta = (1+\cos2\theta)/2$、$\sin^2\theta = (1-\cos2\theta)/2$ 与 $\sin\theta\cos\theta = \tfrac12\sin2\theta$ 即得两个表达式。以 $\bar\sigma = (\sigma_1+\sigma_3)/2$、$R = (\sigma_1-\sigma_3)/2$ 由 $(\sigma_n - \bar\sigma)^2 + \tau^2 = R^2$ 消去 $\theta$，即圆的方程。
:::

::: example 最大剪应力 {#ex-maxshear}
一块岩石在 $\sigma_1 = 200\ \mathrm{MPa}$、$\sigma_3 = 60\ \mathrm{MPa}$ 之下变形。求最大剪应力、其所在面的产状，以及该面上的正应力。
::: solution
莫尔圆的圆心为 $(200+60)/2 = 130\ \mathrm{MPa}$、半径为 $(200-60)/2 = 70\ \mathrm{MPa}$。最大剪应力就是半径，$\tau_{\max} = 70\ \mathrm{MPa}$，位于与 $\sigma_1$ 成 $\theta = 45^\circ$ 的面上，该面上的正应力即圆心值 $130\ \mathrm{MPa}$。

有两个对断层很重要的推论。第一，最大剪应力只由**差**应力决定，而与平均应力无关：给两个主应力都加上 100 MPa 的压强会把圆向右平移而不改变其大小，因而不会改变任何面上的剪应力。第二，最大剪面上的正应力确实改变了，而既然摩擦力与正应力成正比，最大剪面就*不是*最先破裂的面。正是这一个观察，说明了断层为什么不是在与 $\sigma_1$ 成 $45^\circ$ 的方向上形成。
:::
:::

## 破裂：莫尔–库仑与拜尔利

::: definition 莫尔–库仑破裂判据 {#def-mohrcoulomb}
当一个面上的剪应力达到
$$
\tau = \tau_0 + \mu\,\sigma_n = \tau_0 + \sigma_n\tan\varphi
$$
时，岩石发生剪切破裂，其中 $\tau_0$ 是**内聚强度**，$\varphi$ 是**内摩擦角**。在莫尔图上，该判据是一条过 $(\,-\tau_0/\tan\varphi,\,0)$、与水平轴成 $\varphi$ 角的直线，破裂在莫尔圆首次与之相切时开始。破裂面的产状由几何给出：断层与 $\sigma_1$ 方向成
$$
\theta = 45^\circ - \frac{\varphi}{2}
$$
角，因此两组共轭断层之间夹 $2\theta = 90^\circ - \varphi$。
:::

::: example 断层的角度 {#ex-fault-angle}
无内聚强度的岩石具有 $\mu = \tan\varphi = 0.68$。它与 $\sigma_1$ 成什么角度断开？破裂时的比值 $\sigma_1/\sigma_3$ 是多少？
::: solution
$\varphi = \arctan 0.68 = 34.2^\circ$，故
$$
\theta = 45^\circ - 17.1^\circ = 27.9^\circ ,
$$
共轭断层之间夹 $56^\circ$，或沿另一组量得 $124^\circ$。应力比来自与破裂线相切的圆：
$$
\frac{\sigma_1}{\sigma_3} = \frac{1+\sin\varphi}{1-\sin\varphi} = \frac{1+0.562}{1-0.562} = 3.57 .
$$
这两个数都是断层分析日常使用的本钱。天然断层观测到与 $\sigma_1$ 成 $25$–$30^\circ$、共轭两组约成 $60^\circ$，这正是 $\mu \approx 0.6$–$0.7$ 的野外直接确认；而应力比说明，在一个无内聚强度的地壳中，当最大主应力是最小主应力的三点五倍时断层才形成，这对应力场可以是什么是一个严格的约束。

拜尔利对大量岩石测得的普遍摩擦定律是
$$
\tau = 50 + 0.6\,\sigma_n\ \mathrm{MPa} \quad (\sigma_n > 200\ \mathrm{MPa}), \qquad \tau = 0.85\,\sigma_n \quad (\sigma_n < 200\ \mathrm{MPa}),
$$
它近乎普遍适用，这正是断层力学能够成立的原因：地壳的摩擦系数在百分之二十以内处处相同。
:::
:::

::: definition 有效应力 {#def-effective-stress}
孔隙流体承担着部分法向载荷，因此闭合一个裂缝并控制摩擦的应力是**有效正应力**
$$
\sigma_n^{\mathrm{eff}} = \sigma_n - P_p ,
$$
其中 $P_p$ 是孔隙流体压力。破裂在 $\tau = \tau_0 + \mu(\sigma_n - P_p)$ 时发生，孔隙压力升高 $\Delta P$ 会把莫尔圆向左平移 $\Delta P$ 而不改变其半径——也就是说，它可以在外加应力毫无变化的情况下引起破裂。
:::

::: example 断层能因流体压力而重新活化吗？ {#ex-overpressure}
一条 $5\ \mathrm{km}$ 深度的逆冲断层有 $\sigma_1 = \sigma_H = 240\ \mathrm{MPa}$、$\sigma_3 = \sigma_v = 132\ \mathrm{MPa}$，无内聚力且 $\mu = 0.75$。它在水静孔隙压力下稳定吗？多大的孔隙压力会使它重新活化？
::: solution
摩擦角为 $\varphi = \arctan 0.75 = 36.9^\circ$，故 $\sin\varphi = 0.600$，临界有效应力比为
$$
\left(\frac{\sigma_1'}{\sigma_3'}\right)_\text{crit} = \frac{1.600}{0.400} = 4.00 .
$$
$5\ \mathrm{km}$ 处的水静压力为 $\rho_w g z = 1000\times9.81\times5000 = 49\ \mathrm{MPa}$，给出 $\sigma_1' = 191$、$\sigma_3' = 83\ \mathrm{MPa}$，比值为 $2.31$。这远低于 $4.00$，所以断层是**锁住的**。

重新活化要求 $\sigma_1' = 4.00\,\sigma_3'$，而两个主应力都被同一个 $P_p$ 减小：
$$
240 - P_p = 4.00\,(132 - P_p)
\quad\Longrightarrow\quad
240 - P_p = 528 - 4.00P_p
\quad\Longrightarrow\quad
3.00P_p = 288
\quad\Longrightarrow\quad
P_p = 96\ \mathrm{MPa}.
$$
这相当于岩石静载荷的 $96/132 = 0.73$，接近水静压力的两倍，地质学家把这种状态写作 $\lambda = 0.73$。

结论正是对逆冲褶皱带重要的那一条：**除非流体是超压的，中等深度处于挤压中的地壳是稳定锁住的**。因此大型逆冲地震的复发由每次事件之后孔隙压力重建得多快来调节，而不是由板块汇聚得多快来调节。同样的算术倒过来做，就解释了为什么断层能因钻探、因注水、或因一个水库的排水而重新活化，而构造应力毫无变化。
:::
:::

::: warning 岩石圈的强度远比摩擦所预测的小
把拜尔利定律在一个竖直应力等于上覆压力的地壳上积分，会预测：支撑一个造山带或一个挠曲前隆的差应力，在冷地壳中应达到几百兆帕，在岩石圈地幔中应达到几千兆帕。观测却不答应。在海沟处由板块弯曲测得的海洋岩石圈弹性厚度表明，其不能支撑超过约 $10^{13}\ \mathrm{N\,m^{-1}}$ 的单位宽度的力，这对应于约 $10$–$30\ \mathrm{MPa}$ 的深度平均差应力；大西洋中脊的地形要求同样小的应力；而地震的震源机制给出的差应力只有几十兆帕。这个不一致就是"岩石圈强度悖论"。站得住的解释是：地壳比在洁净实验室样品上测得的拜尔利定律所给出的更弱——因为超压，因为成熟断层上的层状硅酸盐与滑石，因为摩擦存在速率强化而岩石圈在蠕变——而地幔在远低于其干摩擦强度的应力下就因幂律蠕变而弱化。对构造地质学家的实际结果是：由显微构造得出几十兆帕的应力估计并不是方法的失败，而是正确答案。
:::

::: quiz
一块岩石有 $\sigma_1 = 300\ \mathrm{MPa}$、$\sigma_3 = 100\ \mathrm{MPa}$。随后两个主应力都增大 200 MPa。岩石断开的趋势如何变化？
- [ ] 它变得容易断开得多，因为应力更大了。
- [x] 它变得不容易断开，因为更高的正应力提高了摩擦强度，而剪应力没有变。
- [ ] 什么也不变，因为只有差应力要紧。
- [ ] 它变得更可能断开，因为平均应力把莫尔圆推向右边。
::: solution
给两个主应力都加上同样的量，会把莫尔圆向右平移而不改变其半径，因此每个面上的剪应力都不变。但破裂包线随正应力上升，于是圆移到它下面更远的地方，岩石变得**更稳定**。这就是为什么深部地壳的岩石比浅部的更难断开，为什么同样的差应力会使浅部岩石破裂而不使深部岩石破裂，以及为什么莫尔圆必须总是对着破裂线来画、而不是单独地画。
:::
:::

## 安德森的断层理论

::: definition 断层作用的样式 {#def-anderson}
假设主应力取竖直与水平方向，这在地表平坦且其上无剪应力时一级近似成立。于是主应力的三种可能排序给出三种断层样式，而**应力比**
$$
R = \frac{\sigma_2 - \sigma_3}{\sigma_1 - \sigma_3}
$$
度量 $\sigma_2$ 处在另外两个之间的什么位置。

| 样式 | 排序 | $\sigma_1$ 的方向 | 断层类型 | $R$ |
|---|---|---|---|---|
| 正断 | $\sigma_v > \sigma_H > \sigma_h$ | 竖直 | 正断层，倾角约 60° | 0–1 |
| 走滑 | $\sigma_H > \sigma_v > \sigma_h$ | 水平，$\sigma_2$ 竖直 | 走滑断层 | 0 或 1 |
| 逆冲 | $\sigma_H > \sigma_h > \sigma_v$ | 水平 | 逆冲断层，倾角约 30° | 0–1 |
:::

::: example 是什么造成了这条断层？ {#ex-regime}
一条断层的倾角为 $62^\circ$，擦痕的伏卧角向下 $8^\circ$。区域应力场为 $\sigma_v = 90\ \mathrm{MPa}$、$\sigma_H = 130\ \mathrm{MPa}$、$\sigma_h = 45\ \mathrm{MPa}$。给这条断层分类，并预测其走向相对 $\sigma_H$ 的方位。
::: solution
排序为 $\sigma_H > \sigma_v > \sigma_h$，所以 $\sigma_1$ 是水平的、$\sigma_2$ 是竖直的：一个**走滑**样式，而 $62^\circ$ 倾角面上 $8^\circ$ 的浅伏卧角与以水平滑动为主是一致的。

破裂面包含 $\sigma_2$，而 $\sigma_2$ 是竖直的，所以断层是直立的，其走向就是面内的那条水平线。这条线与 $\sigma_1$ 成 $28^\circ$ 的破裂角，因此**走向位于距 $\sigma_H$ 方向 $28^\circ$ 处**。共轭的一组朝另一侧 $28^\circ$，两个走向之间夹 $56^\circ$，二者的锐角平分线即 $\sigma_H$ 方向。这是从断层群恢复古应力方向的标准做法，也是为什么擦痕数据在解释之前要先化成正–反断层配对图。

应力比取 $\sigma_1 = 130$、$\sigma_2 = 90$、$\sigma_3 = 45\ \mathrm{MPa}$，为
$$
R = \frac{\sigma_2-\sigma_3}{\sigma_1-\sigma_3} = \frac{90-45}{130-45} = 0.53 .
$$
$R$ 的中间值说明 $\sigma_2$ 与 $\sigma_1$、$\sigma_3$ 都分得开，这正是滑动接近纯走滑、断层产状聚得紧的原因；也正是为什么应力反演在 $R$ 接近 0 或 1 时稳定、而在接近 $\tfrac12$ 时不稳定——在那里两个共轭解变得难以区分。
:::
:::

力学的起点是库仑（Coulomb），他 1773 年那篇论土体对挡土墙之推力的备忘录，除了现代记号之外包含了破裂判据的一切；以及莫尔（Mohr），他 1900 年的图解作图把同样的代数变成了每个构造地质学家都手工画的圆。索拉斯，以及决定性的安德森（Anderson），把它带进了地质学：安德森 1905 年发表于《哲学杂志》的断层理论论文，从"一个主应力是竖直的"这一假设推出正断层、逆断层与走滑断层记录着三种不同的应力场，并进而预测了每一种的几何——一段早于第一次世界大战、此后无需修正的推理。英国学派的布赫尔、克洛斯，尤其是杰弗里斯（Jeffreys），其《地震与波》与《力学诸问题》确立了把地球当作一个力学问题来处理的标准，使应力分析成为正统；海姆（Heim）在 1932 年的《构造力学》中尝试的无异于整个阿尔卑斯造山带的力学。实验的基础在 1950 与 1960 年代由堪培拉的帕特森、圣巴巴拉的格里格斯、洛斯阿拉莫斯的汉丁与赫德的三轴压机给出，它们产出了 1967 年的拜尔利摩擦定律，以及使流变学定量化的橄榄石与石英岩的流动定律。休伯特（Hubbert）1951 年的洞见——控制破裂的是孔隙压力而不是总应力——是在解释油田断层为什么在远低于岩石强度的应力下就能滑动时得到的，是本章实践后果最多的单个思想，也是每一个石油圈闭、注入卤水与诱发地震的力学基础。
:::

## 通向何处

作为应力之果的应变，见下一章 [[structural-geology/strain]]；把两者联系起来的流变在 [[structural-geology/rheology]]；断层与褶皱是随之而来的几何，见 [[structural-geology/fractures-faults]] 与 [[structural-geology/folds]]；驱动它们的应力则由 [[geophysics/flexure]] 与 [[geophysics/heat-flow]] 中的过程产生。

::: summary
- 应力是从面的产状到面力的线性映射；它是对称张量，有六个独立分量与三个正交的主方向。
- 只有应力的偏量部分能引起屈服；平均应力改变体积，并通过摩擦改变强度。
- 莫尔圆携带着整个二维应力状态，物理角在圆上要折半，最大剪应力是差应力的一半。
- 摩擦破裂遵循 $\tau = \tau_0 + \mu\sigma_n$，给出与 $\sigma_1$ 成 $30^\circ$ 的断层与约 3.5 的破裂应力比。
- 孔隙压力以从正应力中减去的方式进入表达式，因此可以在外加应力毫无变化的情况下使一个断层滑动。
- 竖直与水平主应力的三种排序给出正断、走滑与逆冲断层作用（安德森理论）。
- 观测到的岩石圈强度远低于对干地壳积分拜尔利定律所得的值，而构造地质学是在那个较低的值上工作的。
:::

## 练习

::: exercise 单位 {level=1 check="27"}
取 $\rho = 2700\ \mathrm{kg\,m^{-3}}$。岩石静压力梯度是多少 $\mathrm{MPa\,km^{-1}}$？
::: solution
$\rho g = 2700\times9.81 = 2.65\times10^{4}\ \mathrm{kN\,m^{-3}}$，即每公里 $26.5\ \mathrm{MPa}$，约 $27$。以 $1\ \mathrm{kbar} = 100\ \mathrm{MPa}$ 计，这是 $0.27\ \mathrm{kbar\,km^{-1}}$，所以"每 4 公里 1 kbar"这条经验法则在地壳中的误差约百分之十，而地幔中应写作"每 3 公里 1 kbar"。
:::
:::

::: exercise 独立分量 {level=1 check="6"}
应力张量有多少个独立分量？为什么？
::: solution
六个。由角动量平衡得到的对称性把九个分量约减为六个：三个正应力与三个独立的剪应力。
:::
:::

::: exercise 莫尔圆 {level=1 check="80"}
对 $\sigma_1 = 250\ \mathrm{MPa}$、$\sigma_3 = 90\ \mathrm{MPa}$，最大剪应力是多少？
::: solution
$\tau_{\max} = (250-90)/2 = 80\ \mathrm{MPa}$，位于与 $\sigma_1$ 成 $45^\circ$ 的面上，其上的正应力为 $(250+90)/2 = 170\ \mathrm{MPa}$。
:::
:::

::: exercise 断层的角度 {level=1 check="30"}
对一个摩擦角为 $30^\circ$ 的岩石，它与 $\sigma_1$ 成什么角度断开？
::: solution
$\theta = 45^\circ - \varphi/2 = 45^\circ - 15^\circ = 30^\circ$。共轭断层之间于是夹 $60^\circ$ 与 $120^\circ$，而 $\sigma_1$ 方向平分其中的锐角。
:::
:::

::: exercise 应力比 {level=2 check="2.8"}
摩擦角为 $28^\circ$ 时，破裂时的 $\sigma_1/\sigma_3$ 是多少？
::: solution
$(1+\sin28^\circ)/(1-\sin28^\circ) = (1+0.469)/(1-0.469) = 1.469/0.531 = 2.77$，约 $2.8$。摩擦角 $28^\circ$ 对应 $\mu = 0.53$，处于拜尔利范围的低端，而所需的应力比明显低于 $\varphi = 34^\circ$ 时所需的 3.6。
:::
:::

::: exercise 样式 {level=2}
在 $3\ \mathrm{km}$ 深度测得水平应力为 $\sigma_H = 85\ \mathrm{MPa}$、$\sigma_h = 60\ \mathrm{MPa}$，竖直应力为 $81\ \mathrm{MPa}$。给断层作用样式分类并计算 $R$。
::: solution
排序为 $\sigma_H > \sigma_v > \sigma_h$，所以 $\sigma_1$ 是水平的、$\sigma_2$ 是竖直的：**走滑**。$R = (81-60)/(85-60) = 21/25 = 0.84$。$R$ 接近一意味着 $\sigma_2$ 接近 $\sigma_1$，因此断层群的产状约束很差、应力反演会不稳定——这是走滑构造区一个常见而容易被忽视的问题，也是应力反演需要同时用到断层产状与滑动方向的原因。
:::
:::

::: exercise 孔隙压力 {level=2 check="18"}
一条 $10\ \mathrm{km}$ 深度的正断层有 $\sigma_v = 270\ \mathrm{MPa}$、$\sigma_H = 90\ \mathrm{MPa}$。多大的孔隙压力能使有效应力比达到 $\varphi = 34^\circ$ 的破裂值？答案以 MPa 给出。
::: solution
破裂要求 $\sigma_v' / \sigma_H' = 3.57$：
$$
270 - P_p = 3.57(90 - P_p)
\quad\Longrightarrow\quad
270 - P_p = 321 - 3.57P_p
\quad\Longrightarrow\quad
2.57P_p = 51
\quad\Longrightarrow\quad
P_p = 20\ \mathrm{MPa}.
$$
$10\ \mathrm{km}$ 处的水静压力约为 $98\ \mathrm{MPa}$，所以在任何现实的流体压力之下，这条断层早已远远越过破裂，所假设的应力场与一个处于摩擦平衡的地壳并不相容。这个练习很好地说明了摩擦对应力所加的那个约束：在上地壳中，差应力不能超过最小主应力约三倍的值，一个违反此式的应力场必定是错的。把这个论证反过来用，就能给出正断层区的最大水平应力——钻井井壁上钻崩的破口就是这样用来约束井周应力的。
:::
:::

::: exercise 偏应力 {level=2 check="57"}
对 $\sigma_1 = 200$、$\sigma_2 = 140$、$\sigma_3 = 60\ \mathrm{MPa}$，计算八面体剪应力 $\tau_\text{oct} = \tfrac13\sqrt{(\sigma_1-\sigma_2)^2+(\sigma_2-\sigma_3)^2+(\sigma_3-\sigma_1)^2}$。
::: solution
差值：$60$、$80$、$140$；平方和 $3600 + 6400 + 19600 = 29600$；平方根 $172$；故 $\tau_\text{oct} = 172/3 = 57\ \mathrm{MPa}$。平均应力为 $(200+140+60)/3 = 133\ \mathrm{MPa}$，最大剪应力为 $(200-60)/2 = 70\ \mathrm{MPa}$，那是另一个不同的、更大的量：八面体剪应力是分解到八个等产状的面上的，因而总是较小的那一个。矿物的流动定律用 $\sqrt{J_2} = \tfrac{1}{\sqrt2}\sqrt{s_{ij}s_{ij}}$ 书写，对本应力状态它是 $59\ \mathrm{MPa}$。
:::
:::

::: exercise 地形应力 {level=2 check="79"}
一座 $3\ \mathrm{km}$ 高的高原之下的水平应力比相邻平原的高出多少？取 $\rho = 2700\ \mathrm{kg\,m^{-3}}$。
::: solution
载荷为 $\rho g h = 2700\times9.81\times3000 = 7.9\times10^{7}\ \mathrm{Pa} = 79\ \mathrm{MPa}$。这与一公里地壳的全部摩擦强度相当，这就是为什么造山带以大型逆冲系统为界，也是为什么高原之下地壳中的水平应力由地形主导、而不是由板块运动主导。这也是为什么 [[geophysics/gravity-isostasy]] 中的均衡论证与本章的应力论证其实是同一个论证，只是所取的体积不同。
:::
:::

::: exercise 共轭断层 {level=3}
一处石灰岩中含有两组共轭的正断层，走向分别为 $020^\circ$ 与 $070^\circ$，都陡倾，擦痕显示正断性质的斜向滑动。确定 $\sigma_H$ 的倾向，解释为什么答案是两可的，以及什么能把它解决。
::: solution
对共轭断层，$\sigma_1$ 方向平分两个断层面之间的夹角，$\sigma_3$ 平分另一个夹角。两个走向之间夹 $50^\circ$，因此两条平分线的倾向为 $045^\circ$ 与 $135^\circ$。因为断层是正断层且陡倾，$\sigma_1$ 是竖直的、$\sigma_3$ 是水平的，所以 $\sigma_h$ 的倾向为 $045^\circ$ 或 $135^\circ$，而与之垂直的 $\sigma_H$ 取另一个。

这个两可是经典的那一个：仅凭几何无法分辨两条平分线中哪条是 $\sigma_3$、哪条是 $\sigma_1$，因为两种选择给出同一对断层面。解决它要靠**每组断层相对于另一组的滑动方向**——锐角平分线法则要求两条断层的滑动使岩石沿钝角平分线方向缩短——实际上则要靠对伸展方向的独立约束：同裂谷沉积中心的走向、变质核杂岩中的拉伸线理、岩墙群的走向，或一条其运动性质已由探槽探明的第四纪断层的产状。
:::
:::

::: exercise 一个断层的重量 {level=3}
一条破裂面积为 $70\ \mathrm{km^2}$ 的直立正断层滑动了 $1\ \mathrm{m}$。断层上的有效正应力为 $100\ \mathrm{MPa}$，$\mu = 0.6$。求克服摩擦所做的功，并与这次破裂所代表的那次 6.8 级地震所辐射的地震能作比较。
::: solution
断层所承担的剪应力为 $\tau = 0.6\times100 = 60\ \mathrm{MPa}$，故摩擦功为
$$
W = \tau\, A\, d = 6\times10^{7}\times7\times10^{10}\times1 = 4\times10^{18}\ \mathrm{J}.
$$
6.8 级地震辐射约 $10^{15}\ \mathrm{J}$，小四千倍。这个差不是错误，也不是谜：断层上的绝对剪应力很大，它几乎全部耗在热上以及围岩的准静态应变上，只有**应力降**——断层两侧剪应力的变化量，典型为 1–10 MPa——可以被辐射出去。取 $\Delta\tau = 3\ \mathrm{MPa}$，释放的应变能为
$$
E \approx \frac{\Delta\tau\, A\, d}{2} = \frac{3\times10^{6}\times7\times10^{10}\times1}{2} = 1\times10^{17}\ \mathrm{J},
$$
其中观测到的 $10^{15}\ \mathrm{J}$ 相当于约百分之一的**辐射效率**。其余部分进入断层带的摩擦加热——这就是为什么有些断层岩记录到数秒之内数百度的温升——以及滑动面的断裂能。

这里的教训正是支配本学科每一次应力估计的那一条：一个断层所记录的量是它所承担的绝对剪应力，量级为几十兆帕；而一次地震所记录的量是它的变化量，量级为一兆帕。两者相差一个数量级，不可互换。
:::
