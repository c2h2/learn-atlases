构造地质学有一个缺失的环节。应力可以被约束、却无法在岩石中被测量；应变可以被测量、却对力什么也不说；而在两者之间横着一条关系——**流变**——它必须由实验、由对现代地球的观测、或由假设来提供。因此本章所论证的一切，一部分是测量、一部分是选择，而诚实的从业者会说清是哪一种。

选择比测量更要紧。一个在一秒内表现为弹性、在一百万年内表现为粘性、在一个断层面上表现为摩擦的地壳，不是一种材料而是三种，而同一种岩石会因你愿意等待多久而被不同的定律描述。这不是这门学科的困难；这就是这门学科。

## 弹性

::: definition 胡克定律与弹性常数 {#def-hooke}
在小应变下岩石是线性弹性的，而对各向同性的岩石，应力–应变关系有两个独立常数：
$$
\sigma_{ij} = \lambda\, e_{kk}\,\delta_{ij} + 2\mu\, e_{ij},
$$
其中 $\mu$ 是**剪切模量**，$\lambda$ 是第二个拉梅参数。其他在用的名称还有**体积模量** $K = \lambda + \tfrac23\mu$、**杨氏模量** $E$，以及**泊松比** $\nu$，定义为单轴拉伸中横向应变与轴向应变之比的负值。任意两个即可决定全部四个：
$$
E = 2\mu(1+\nu) = 3K(1-2\nu), \qquad
\nu = \frac{3K - 2\mu}{2(3K+\mu)} .
$$
典型的上地壳岩石有 $E = 50$–$90\ \mathrm{GPa}$、$\mu = 20$–$35\ \mathrm{GPa}$、$K = 40$–$70\ \mathrm{GPa}$、$\nu = 0.20$–$0.30$。
:::

::: proof
取单轴应力 $\sigma_{xx} = \sigma$、其余分量皆为零。本构定律给出 $\sigma = \lambda(e_{xx}+e_{yy}+e_{zz}) + 2\mu e_{xx}$ 与 $0 = \lambda(e_{kk}) + 2\mu e_{yy}$，故 $e_{yy} = e_{zz} = -\lambda e_{kk}/2\mu$。代入迹得 $e_{kk} = e_{xx}\,2\mu/(2\mu+3\lambda)$，于是
$$
e_{yy}/e_{xx} = -\lambda/(2\mu+3\lambda) \equiv -\nu,
\qquad
\sigma/e_{xx} = 2\mu(1+\nu) \equiv E .
$$
令 $\sigma_{xx} = \sigma_{yy} = \sigma_{zz} = -P$ 得 $P = -K e_{kk}$，其中 $K = \lambda + \tfrac23\mu$；在 $E$ 的两个表达式之间消去 $\lambda$ 得 $E = 3K(1-2\nu)$。因此五个常数中有两个就足够了；而一个 $\nu = \tfrac12$ 的岩石具有无限大的体积模量——这就是为什么下面要讨论的不可压缩塑性流动是 $\nu \to \tfrac12$ 的极限、而不是一个单独的假设。
:::

::: example 弹性应变有多大？ {#ex-elastic}
一个 $100\ \mathrm{MPa}$ 的差应力施加在一个 $E = 70\ \mathrm{GPa}$、$\nu = 0.25$ 的地壳岩石上。求轴向应变、剪切模量、体积模量，以及每立方米的弹性应变能。
::: solution
轴向应变为 $e = \sigma/E = 10^{8}/7\times10^{10} = 1.4\times10^{-3}$，七百分之一。其余常数由上面的关系得出：
$$
\mu = \frac{E}{2(1+\nu)} = \frac{70}{2.5} = 28\ \mathrm{GPa}, \qquad
K = \frac{E}{3(1-2\nu)} = \frac{70}{1.5} = 47\ \mathrm{GPa}.
$$
储存的弹性能密度为 $\tfrac12\sigma e = \tfrac12\times10^{8}\times1.4\times10^{-3} = 7\times10^{4}\ \mathrm{J\,m^{-3}}$。

有两点解读。$1.4\times10^{-3}$ 的弹性应变处于岩石破裂前所能维持的上限，而它比构造地质学家在野外测得的百分之一二的应变小一千倍。**因此几乎一切地质应变都是非弹性的**——弹性部分在载荷移除的瞬间就恢复了，这就是为什么冰盖融化之后地壳会回弹、而没有任何一个褶皱层记得它的弹性应变。而能量密度是对地震要紧的那个数：一条断层带在一个 $100\ \mathrm{km^3}$ 的破裂体积中储存 $10^{5}\ \mathrm{J\,m^{-3}}$，就持有 $10^{16}\ \mathrm{J}$，足以辐射一次大地震。
:::
:::

## 粘度与德博拉数

::: definition 牛顿粘度与麦克斯韦时间 {#def-viscosity}
**牛顿流体**以与所加应力成正比的速率变形，没有弹性应变也没有屈服强度：
$$
\dot{e}_{ij} = \frac{1}{2\eta}s_{ij}, \qquad \dot{e}_{kk} = \frac{\sigma_m}{K} ,
$$
其中 $\eta$ 是粘度、$\mathbf{s}$ 是偏应力。一个模量为 $G$ 的弹性体与一个粘度为 $\eta$ 的粘壶串联起来——**麦克斯韦体**——会在**麦克斯韦松弛时间**
$$
\tau_M = \frac{\eta}{G}
$$
之内松弛掉恒应变下的应力，并在比 $\tau_M$ 短的时间上表现为固体、在比它长的时间上表现为流体。其无量纲度量是**德博拉数**，$\mathrm{De} = \tau_M/t_\text{observation}$。
:::

::: example 地幔是固体还是流体？ {#ex-deborah}
取上地幔的剪切模量 $G = 70\ \mathrm{GPa}$、粘度 $10^{21}\ \mathrm{Pa\,s}$；取软流圈的粘度为 $5\times10^{19}\ \mathrm{Pa\,s}$。求各自的麦克斯韦时间，以及（i）周期 1 秒的地震波、（ii）$10^4$ 年斯堪的纳维亚的冰后回弹、（iii）$10^8$ 年的地幔对流的德博拉数。
::: solution
$$
\tau_M(\text{upper mantle}) = \frac{10^{21}}{7\times10^{10}} = 1.4\times10^{10}\ \mathrm{s} = 450\ \mathrm{yr};
\qquad
\tau_M(\text{asthenosphere}) = 23\ \mathrm{yr}.
$$
德博拉数随之得出：
$$
\text{(i) seismic:}\quad \mathrm{De} = \frac{1.4\times10^{10}}{1} = 10^{10}; \qquad
\text{(ii) rebound:}\quad \mathrm{De} = \frac{1.4\times10^{10}}{3\times10^{11}} = 0.05; \qquad
\text{(iii) convection:}\quad \mathrm{De} = 4.4\times10^{-6}.
$$
因此地幔对地震波是一个弹性固体、对一个冰期循环是一个粘性流体、对一个对流单元是一个极粘的流体。关于地幔的什么也没有变；变的只是观测时间。这是地质力学中最重要的单个定量思想，也是为什么同一种橄榄岩既能把剪切波输送过一百公里的上地幔、又能在百万年中流动以闭合一个褶皱。
:::
:::

::: quiz
上地幔的粘度是水的千万亿倍，为什么它在数百万年中表现为流体、在一秒中表现为玻璃？
- [ ] 因为它的粘度随变形而随时间下降。
- [x] 因为一个材料是否流动，取决于其麦克斯韦松弛时间与观测时间之比，而不是单取决于它的粘度。

:::

## 地壳与地幔的流动定律

::: definition 变形机制 {#def-mechanisms}
一块真实的岩石由若干机制叠加起来变形，每个机制对应力、温度与粒度的依赖各不相同：

**摩擦–脆性流动。**在一条已存在的断层上，$\tau = \tau_0 + \mu(\sigma_n - P_p)$，基本上与温度和应变速率无关。新的破裂则需要格里菲斯判据，且依赖于速率。

****位错（幂律）蠕变。**点缺陷的扩散使线缺陷得以穿过晶体运动，于是晶体在粒度不变的情况下改变形状：
$$
\dot{\varepsilon} = A_d\, \sigma^{n}\, \exp\!\left(-\frac{Q^{*} + PV}{RT}\right), \qquad n \approx 3 .
$$
强烈非牛顿，产生晶格优选方位，是粗粒岩石在高应力下的主导机制。

**扩散（纳巴罗–赫林与科布尔）蠕变。**物质从受压的晶面扩散到受拉的晶面，于是集合体通过颗粒改变形状而改变形状：
$$
\dot{\varepsilon} = A_\text{diff}\, \frac{\sigma}{d^{2}}\, \exp\!\left(-\frac{Q}{RT}\right), \qquad n = 1 .
$$
是牛顿型的，对粒度以 $d^{-2}$（晶界扩散为 $d^{-3}$）敏感，且不产生结晶学组构。

**派尔斯蠕变。**在近完整晶格中的低温、强应力依赖的滑移；只对近室温下的橄榄石、以及地幔最浅的部分重要。
:::

::: example 哪种机制胜出？ {#ex-mechanism}
对一个 $1200^\circ\mathrm{C}$、粒度 $1\ \mathrm{mm}$ 的橄榄石集合体，取两个流动定律为
$$
\dot{\varepsilon}_\text{diff} = 4\times10^{-15}\,\sigma\ \ \mathrm{s^{-1}}, \qquad
\dot{\varepsilon}_\text{disl} = 1\times10^{-18}\,\sigma^{3}\ \ \mathrm{s^{-1}},
$$
其中 $\sigma$ 以 MPa 计。求二者相等时的应力、二者在 $10\ \mathrm{MPa}$ 与 $100\ \mathrm{MPa}$ 各给出的应变速率，以及把粒度减小到 $0.1\ \mathrm{mm}$ 的效果。
::: solution
令二者相等，$4\times10^{-15}\sigma = 1\times10^{-18}\sigma^{3}$，故 $\sigma^{2} = 4\times10^{3}$，
$$
\sigma_\text{transition} = 63\ \mathrm{MPa}.
$$
在 $10\ \mathrm{MPa}$：扩散蠕变给出 $4\times10^{-14}\ \mathrm{s^{-1}}$、位错蠕变给出 $1\times10^{-15}\ \mathrm{s^{-1}}$，所以扩散蠕变快四十倍、占主导。在 $100\ \mathrm{MPa}$：扩散蠕变给出 $4\times10^{-13}$、位错蠕变给出 $1\times10^{-12}$，所以位错蠕变快两倍半、占主导。这个转变在如下意义上是突然的：应力变化十倍，比值就变化一百倍——这正是岩石圈为什么在一个特定深度有一个脆–韧转变、而不是一个渐变带的全部原因。

扩散蠕变按 $d^{-2}$ 变化，所以把粒度从 $1\ \mathrm{mm}$ 减到 $0.1\ \mathrm{mm}$ 会使扩散速率乘以一百，并把转变移到 $\sigma^2 = 4\times10^{-13}/10^{-18} = 4\times10^{5}$、即 $630\ \mathrm{MPa}$——没有任何岩石能维持这样高的应力。因此一个细粒岩石在任何地质应力下都几乎以扩散蠕变变形，这就是**剪切带自弱化**背后的机制：当岩石以位错蠕变变形时，它重结晶到更细的粒度，更细的粒度使扩散蠕变更容易，集合体因此弱化，应变集中到其中，粒度进一步下降。这个正反馈会在第二相的晶界钉扎处、或在晶粒开始生长使细化停止时终结——这就是为什么糜棱岩带有几百米宽、而不是几厘米宽。
:::
:::

::: history
弹性始于胡克（Hooke），他 1678 年的那个字谜——*ceiiinosssttuv*，解为 *ut tensio sic vis*，"伸长多少、力就多大"——是材料力学中的第一个定量表述，并在纳维、柯西与圣维南手中达到其现代的张量形式。粘度来自牛顿，他假设粘度是常数；对它的修正来自十九世纪的流变学家，他们给这门学科起的名字——源自希腊语 *rheo*，意为流动——记录着一种不假设物质为弹性而加以描述的抱负。格里菲斯（Griffith）在 1920 年给出了那个决定性的思想：脆性岩石在比其理论强度低一百倍的应力下就破裂，因为它含有裂缝；而破裂发生在裂缝扩展所释放的弹能超过所创建的表面能之时——这是断裂力学的起源，也是为什么一个断层能在任何完整岩石都承受不了的应力下滑动。杰弗里斯与实验上的格里格斯（Griggs）——他在 1930 与 1940 年代于加州大学洛杉矶分校建造了第一台气体介质三轴压机——开始了在受控温度与压力下变形岩石的研究纲领；帕特森（Paterson）1978 年的专著是堪培拉十五年实验的产物，为摩擦与脆性域确立了标准。幂律革命来自 1950 与 1960 年代的材料科学，以及一种认识——由克里斯蒂、由格策、尤其是由阿韦–拉勒芒与岛本提出——即橄榄石与石英岩的蠕变是一个扩散控制的过程、应力指数为三，因此地幔是一个非牛顿流体，其粘度取决于它承担的应力。柯比（Kirby）1983 年的综合把实验室流动定律与天然褶皱、糜棱岩和地震活动联系起来，使从炉子到造山带的外推成为一种标准工具，而关于其有效性的争论至今未息。
:::

## 岩石圈的强度

::: example 脆–韧转变在哪里？ {#ex-bdt}
一个密度为 $2700\ \mathrm{kg\,m^{-3}}$、具水静孔隙压力的地壳，其摩擦强度为每公里深度 $10\ \mathrm{MPa}$。在其之下，湿石英岩按一条流动定律变形：该定律在 $300^\circ\mathrm{C}$、应变速率 $10^{-14}\ \mathrm{s^{-1}}$ 下给出 $30\ \mathrm{MPa}$ 的差应力，激活能为 $135\ \mathrm{kJ\,mol^{-1}}$、应力指数为三。问在 $25\ ^\circ\mathrm{C\,km^{-1}}$ 的地温梯线上，转变发生在什么深度？该柱的积分强度是多少？
::: solution
韧性强度随岩石变冷而上升：
$$
\sigma_d(z) = 30\ \mathrm{MPa}\times\exp\left[\frac{Q}{3R}\left(\frac{1}{T(z)} - \frac{1}{573\ \mathrm{K}}\right)\right], \qquad \frac{Q}{3R} = \frac{135\,000}{3\times8.314} = 5413\ \mathrm{K}.
$$
以 $T = 298 + 25z$（开尔文）求值：
$$
z = 6\ \mathrm{km}:\ \sigma_d = 419\ \mathrm{MPa} \gg 60\ \mathrm{MPa}\ \text{(brittle)};\qquad
z = 10\ \mathrm{km}:\ \sigma_d = 46\ \mathrm{MPa} < 100\ \mathrm{MPa}\ \text{(ductile)}.
$$
两条曲线在 $z = 8.7\ \mathrm{km}$、$242^\circ\mathrm{C}$ 处相交。转变之上强度是摩擦控制的，之下则是幂律控制的。

积分强度是强度–深度曲线下的面积：
$$
\int_0^{8.7}\!\!10z\,\mathrm{d}z = \tfrac12\times87\times8.7 = 379\ \mathrm{MPa\,km}, \qquad
\int_{8.7}^{30}\!\!\sigma_d\,\mathrm{d}z \approx 214\ \mathrm{MPa\,km},
$$
总计 $5.9\times10^{2}\ \mathrm{MPa\,km} = 5.9\times10^{11}\ \mathrm{N\,m^{-1}}$。

有三点推论。强度集中在**脆性的上地壳**，它以四分之一的厚度贡献了总量的三分之二——这就是为什么地震发生在上地壳，为什么韧性的下地壳不能储存弹性应变。强度剖面是一个**顶点在转变处的三角形**，即岩石圈标准图像中那个"圣诞树"形状。而总量 $0.6\ \mathrm{TN\,m^{-1}}$ 属于一个*弱*的地壳：具有干燥的长英质下地壳与 $15\ ^\circ\mathrm{C\,km^{-1}}$ 地温梯线的古老克拉通可达几个 $\mathrm{TN\,m^{-1}}$，而由板块弯曲测得的弹性厚度要求 $1$–$10\ \mathrm{TN\,m^{-1}}$。一个在高地温梯线下的富水长英质地壳根本承载不了载荷，这正是青藏高原、盆岭与阿尔卑斯–喜马拉雅带之所以弱的原因，也是为什么同一条流动定律用到冷的克拉通上会给出相反答案的原因。
:::
:::

::: warning 流动定律被外推了十个数量级
地质学中使用的每一条流动定律，都是在 $10^{-4}$ 到 $10^{-7}\ \mathrm{s^{-1}}$ 的应变速率、$10^{2}$ 到 $10^{3}\ \mathrm{MPa}$ 的差应力下于实验室测定的，却被用于 $10^{-12}$ 到 $10^{-16}\ \mathrm{s^{-1}}$、$1$–$30\ \mathrm{MPa}$ 的自然界。这个外推在应变速率上是八到十二个数量级，而它依赖一个假设：机制——同样的位错滑移、同样的扩散路径——在实验与自然界中是相同的。有时并非如此。在低应力下，橄榄石与长石的位错蠕变显示出一个阈值、或向一个低得多的应力指数的转变；水含量对石英强度的影响可达两个数量级，却在实验中难以控制、在一个已经重结晶的岩石中无从知晓；而细粒多相集合体的流动涉及晶界滑动与溶液转移，任何单晶定律都无法刻画。
:::

这些定律所抵抗的应力，见 [[structural-geology/stress]]；它们所产生的应变，见 [[structural-geology/strain]]；粘度差所产生的褶皱，见 [[structural-geology/folds]]；应变局部化在其中走向终结的剪切带，见 [[structural-geology/shear-zones]]；岩石圈在表面载荷之下的挠曲，见 [[geophysics/flexure]]。

::: summary
- 岩石在短时间尺度上是弹性的，有两个独立常数；典型的地壳值为 $E \approx 70\ \mathrm{GPa}$、$\mu \approx 28\ \mathrm{GPa}$、$K \approx 47\ \mathrm{GPa}$、$\nu \approx 0.25$。
- 地质应力下的弹性应变约为 $10^{-3}$ 的量级，因此测得的地质应变本质上全是非弹性的。
- 地幔是固体还是流体只取决于德博拉数：上地幔的麦克斯韦时间是几个世纪。
- 变形机制在对应力、粒度与温度的依赖上各不相同；对毫米级颗粒，从扩散蠕变到位错蠕变的转变发生在几十兆帕。
- 粒度敏感的弱化是把应变局部化进糜棱岩带的那个正反馈。
- 岩石圈的强度是一个峰值位于脆–韧转变处的三角形，而在高地温梯线下的富水地壳中，该转变位于 8–10 km。
- 所有流动定律都是从实验室向自然界外推了许多个数量级，其不确定度相应地也很大。
:::

::: exercise 泊松比 {level=1 check="0.25"}
一块岩石有 $K = 47\ \mathrm{GPa}$、$\mu = 28\ \mathrm{GPa}$。求 $\nu$。
::: solution
$\nu = (3K-2\mu)/[2(3K+\mu)] = (141-56)/[2(141+28)] = 85/338 = 0.25$。泊松比为二分之一意味着材料不可压缩，橡胶接近这个值；岩石则不然。
:::

::: exercise 麦克斯韦时间 {level=1 check="23"}
求 $\eta = 5\times10^{19}\ \mathrm{Pa\,s}$、$G = 70\ \mathrm{GPa}$ 的软流圈的麦克斯韦时间，以年计。
::: solution
$\tau_M = 5\times10^{19}/7\times10^{10} = 7.1\times10^{8}\ \mathrm{s} = 23\ \mathrm{yr}$。软流圈对于任何在十年之内发生的事情是固体，对于任何耗时更久的事情则是流体——这就是为什么它既传输剪切波、又容许大陆漂移。
:::
:::

::: exercise 幂律的杠杆 {level=2 check="3.1"}
一块岩石以 $n = 3$ 的幂律变形。若应变速率增大三十倍，应力增大多少倍？
::: solution
$\sigma \propto \dot{\varepsilon}^{1/n} = 30^{1/3} = 3.11$。这个练习的要点在于，幂律材料几乎不在乎应变有多快：速率变化三十倍只相当于应力变化三倍，而对牛顿材料而言则是三十倍。这就是为什么同一种显微组构会在很宽的构造环境中被找到。
:::
:::

::: exercise 粒度敏感性 {level=2 check="100"}
在恒定应力下粒度从 $200\ \mu\mathrm{m}$ 降到 $20\ \mu\mathrm{m}$ 时，扩散蠕变的应变速率变化多少倍？
::: solution
扩散蠕变按 $d^{-2}$ 变化，故速率增大 $(200/20)^2 = 100$ 倍。粒度变化一个数量级相当于应变速率变化两个数量级，这是剪切带中粒度弱化最强的单个论据。科布尔（晶界）蠕变按 $d^{-3}$ 变化，会给出上千倍。
:::
:::

::: exercise 机制图 {level=2}
一条糜棱岩含有 $5\ \mu\mathrm{m}$ 的动态重结晶颗粒与一个强的结晶学优选方位。为什么这个组合是有诊断意义的？
::: solution
粒度敏感的扩散蠕变与晶界滑动**不**产生结晶学组构，因为颗粒是通过添加与移除原子、而不是通过开动滑移系来改变形状的。强的晶格优选方位只能由位错蠕变产生。二者同时出现意味着变形是**复合的**：位错蠕变在粗粒部分或连通相中产生了组构，而扩散蠕变在细粒基质中容纳了部分应变。这个观察把流动约束在扩散–位错转变附近、几十兆帕的应力上，而它是少数几个直接检验一条流动定律的野外观察之一。
:::
:::

::: exercise 脆–韧转变 {level=2 check="8.7"}
使用 [[#ex-bdt]] 的流动定律，在应变速率 $10^{-14}\ \mathrm{s^{-1}}$、地温梯线 $25\ ^\circ\mathrm{C\,km^{-1}}$ 下，$10\ \mathrm{MPa\,km^{-1}}$ 的摩擦强度在什么深度与湿石英岩的韧性强度相交？答案以 km 给出。
::: solution
$8.7\ \mathrm{km}$，在 $217^\circ\mathrm{C}$。其上的地壳以摩擦滑动而破裂并储存弹性应变；其下则发生蠕变、无法储存。因此转变的深度就是最深地震的深度。上面的计算给出 $8.7\ \mathrm{km}$，因为它假设了一个极湿而富石英的地壳和一个高的地温梯线；若地壳较干、地温梯线为 $15\ ^\circ\mathrm{C\,km^{-1}}$，转变就移到 $20\ \mathrm{km}$、$300^\circ\mathrm{C}$，而大陆的地震活动实际上正是在那里终止。转变深度、$300^\circ\mathrm{C}$ 等温线与两条由实验室导出的强度曲线之交点这三者的一致，是这幅图像大致正确的首要证据。
:::
:::

::: exercise 较冷地壳的效应 {level=3}
对一个 $15\ \mathrm{^\circ C\,km^{-1}}$ 的地温梯线，以及一个韧性强度在 $300^\circ\mathrm{C}$ 为 $100\ \mathrm{MPa}$、$n = 3$、$Q = 250\ \mathrm{kJ\,mol^{-1}}$ 的干燥长石质地壳，重复 [[#ex-bdt]] 的强度计算。估计新的转变深度与积分强度的变化。
::: solution
现在 $Q/3R = 250\,000/24.94 = 10\,024\ \mathrm{K}$、$T = 298 + 15z$。韧性强度为
$$
\sigma_d(z) = 100\,\exp\left[10\,024\left(\frac{1}{298+15z} - \frac{1}{573}\right)\right]\ \mathrm{MPa}.
$$
在 $z = 15\ \mathrm{km}$，$T = 523\ \mathrm{K}$，指数为 $10\,024\times1.668\times10^{-4} = 1.67$，故 $\sigma_d = 532\ \mathrm{MPa}$，而摩擦强度为 $150\ \mathrm{MPa}$——仍是脆性的。在 $z = 25\ \mathrm{km}$，$T = 673\ \mathrm{K}$，指数为 $-0.51$、$\sigma_d = 60\ \mathrm{MPa}$，而摩擦强度为 $250\ \mathrm{MPa}$——韧性的。交点在 $21\ \mathrm{km}$ 附近、约 $310^\circ\mathrm{C}$。

仅脆性部分的积分强度为 $\tfrac12\times210\times21 = 2205\ \mathrm{MPa\,km}$，接近湿地壳值的六倍，而整个柱的强度约为 $3\ \mathrm{TN\,m^{-1}}$。因此，一个冷而干的地壳比同样厚度下一个热而湿的地壳强若干倍，而这个差值大于流动定律中任何可信的不确定度。这正是下述观察的定量内涵：古老而冷的大陆内部能够支撑长波长的载荷达数亿年，而年轻而热的造山带连一座海山也支撑不了。
:::

::: exercise 褶皱作为流变仪 {level=3}
一个粘度为 $\eta_1$、厚度为 $h$ 的强层，在粘度为 $\eta_m$ 的基质中，在屈曲开始时发育出波长 $\lambda = 2\pi h(\eta_1/6\eta_m)^{1/3}$ 的褶皱（比奥–拉姆贝格）。一层 $h = 0.30\ \mathrm{m}$ 的石灰岩在页岩中显示出 $1.9\ \mathrm{m}$ 的主波长。估计粘度比，并解释为什么这个估计只和"观察到的波长就是*主*波长"这一假设一样可靠。
::: solution
重新排列，$\eta_1/\eta_m = 6\left(\dfrac{\lambda}{2\pi h}\right)^{3} = 6\left(\dfrac{1.9}{1.885}\right)^{3} = 6\times1.024 = 6.1$。

这个估计在三方面是脆弱的。公式给出的是屈曲**开始时**生长速率最大的波长；随着缩短继续，褶皱生长并相互影响，波长会因褶皱的再褶皱与平行层面的缩短而增大，所以观察到的波长一般大于初始波长，粘度比因此被高估。层的强性必须至少比基质高若干倍理论才适用，而如果这一反差是由孔隙压力或岩性的差异造成、且此后已被均衡掉，那个比值就无法恢复。而理论假设基质是牛顿的：如果页岩以摩擦滑动或压溶变形，指数 $1/3$ 就会变成别的什么，整个标度关系也随之改变。

诚实的说法是：该层比其基质粘三到三十倍，这是一个真实而有用的约束——而褶皱作为*比值*的流变仪要比作为任何事物*绝对*粘度的流变仪更可靠。
:::
:::

::: exercise 体积与质量 {level=3}
一个石灰岩以压溶变形：不溶残余在缝合线面中积累，占据岩石体积的 8 %，而岩石垂直于缝合线缩短。假设不溶组分为最初的 2 %、且不溶残余的体积守恒，求缩短量与体积损失。
::: solution
设初始岩石为单位体积，其中 $0.02$ 为不溶残余。变形后残余占新体积 $V$ 的 $0.08$，而其自身体积不变：
$$
0.08\,V = 0.02 \quad\Longrightarrow\quad V = 0.25 .
$$
岩石失去了其体积的 75 %。若缩短垂直于缝合线、而层保持其长度与宽度不变，则缩短等于体积损失，所以该层被缩短到原厚的四分之一——伸长为 $\lambda = 0.25$、自然应变为 $\ln 0.25 = -1.39$。

这个结果惊人而真实：褶皱带中的缝合线灰岩确实失去其大部分体积，而上面的算术正是其所以然。它也意味着，一个被解释为百分之七十五平行层面缩短之产物的褶皱，实际上可能是机械地缩短了百分之十、化学地缩短了百分之六十五，而这个区别无法从褶皱本身的几何恢复。压溶正是使等体积假设——本课程中几乎每一次应变计算都在使用它——不再成立的机制，而检验它的办法恰恰就是这个残余计算。
:::
