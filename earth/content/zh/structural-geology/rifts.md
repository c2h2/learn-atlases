大陆并不轻易破裂，而一旦破裂，它们留下的构造是如此有特征，以致一亿年之后还能在一张重力图上被认出来。一个裂谷是一个由正断层限界的地壳伸展带，而它是地球约十分之一沉积盆地的所在地、其大部分近海烃类的所在地，也是这个星球上每一条被动大陆边缘的由来。物理是简单的——把地壳拉伸、让它沉降、让它冷却——而复杂之处全在地壳如何说"不"——那方式的几何里。

## 伸展的几何

::: definition 裂谷的建造样式 {#def-rift}
一个**半地堑**是一个由一条边界断层倾斜的、被断层限界的盆地；一个**地堑**由两条相向的断层限界；一个**地垒**是其间抬升的块体。一条**滑脱断层**是一条长而低角度的正断层，沿它地壳已被平移了几公里；而一个**变质核杂岩**是这样一条断层的穹状顶点，其上盘已被移除，从而使中地壳的糜棱岩与片麻岩贴着其盖层而出露。一个**传递带**或**调节带**连接两个重叠的断层段，并承担其间的应变。一个**裂谷**是一个正在活动的伸展带；一个**裂谷残臂（aulacogen）**是一个失败的裂谷臂；而一个**被动边缘**是一个裂谷成功之后、洋底扩张接管之后所变成的东西。
:::

::: definition 伸展因子与减薄 {#def-beta}
**伸展因子**是伸展方向上拉伸后长度与拉伸前长度之比，
$$
\beta = \frac{L_1}{L_0} = \frac{h_0}{h_1},
$$
其中 $h_0$ 与 $h_1$ 是被减薄柱体在减薄前与减薄后的厚度。$\beta$ 为 1 意味着没有伸展，2 意味着地壳被减半，100 意味着它被拉伸到原来的百分之一。面积伸展 $e$ 与 $\beta$ 的关系为 $\beta = 1/(1-e)$，所以百分之五十的伸展是 $\beta = 2$。
:::

::: proposition 由地壳减薄造成的沉降 {#prop-subsidence}
伸展一个初始厚度为 $h_{c0}$、初始高程为零的地壳柱，并让水填满由此产生的凹陷。按艾里均衡，洋底的深度为
$$
d = \frac{(\rho_m - \rho_c)}{(\rho_m - \rho_w)}\,\frac{h_{c0}}{\beta}\,(\beta - 1) .
$$
减薄柱之下热软流圈上涌所造成的热沉降，再附加一个同量级的量，所以同裂谷期与裂谷后早期的总沉降，通常达单独地壳减薄项的两到三倍。
:::

::: proof
把两个柱体均衡到地壳底部之下的一个补偿深度。参考柱是一个厚度为 $h_{c0}$、顶面立在海平面上的地壳柱。伸展后的柱体则有厚度为 $h_c = h_{c0}/\beta$ 的地壳、其上有深度为 $d$ 的水；而由于补偿深度固定不变，剩余空间由地幔填充。单位面积质量相等给出
$$
\rho_c h_{c0} = \rho_c h_c + \rho_w d + \rho_m(h_{c0} - h_c - d).
$$
合并同类项得 $(\rho_m - \rho_c)(h_{c0} - h_c) = (\rho_m - \rho_w)d$，代入 $h_c = h_{c0}/\beta$ 即得结果。热项来自上涌的软流圈与它所替换的地幔之间的密度反差；而热的地幔既更轻、又比它所置换的柱体更厚，因此必须在温度场上积分，而不能当作一层来处理。
:::

::: example 一个裂谷会沉多深？ {#ex-subsidence}
取 $h_{c0} = 35\ \mathrm{km}$、$\rho_c = 2700$、$\rho_m = 3300$、$\rho_w = 1030\ \mathrm{kg\,m^{-3}}$。求仅由地壳减薄在 $\beta = 1.5$、$2$、$3$ 时所产生的水深，并与北海与红海的观测深度比较。
::: solution
由 $(\rho_m - \rho_c)/(\rho_m - \rho_w) = 600/2270 = 0.264$、$h_{c0} = 35\ \mathrm{km}$，
$$
d = 0.264\times\frac{35(\beta-1)}{\beta}\ \mathrm{km},
$$
于是
$$
\beta = 1.5:\ d = 0.264\times11.7 = 3.1\ \mathrm{km}; \qquad
\beta = 2:\ d = 0.264\times17.5 = 4.6\ \mathrm{km}; \qquad
\beta = 3:\ d = 0.264\times23.3 = 6.2\ \mathrm{km}.
$$
红海的 $\beta$ 接近一、地壳只是略微减薄，它在 $500\ \mathrm{m}$ 的水中有一个 $1\ \mathrm{km}$ 深的轴部洼地——大致是地壳减薄项，加上其下浅部岩浆带来的一个大的热贡献。北海在其南部盆地的 $\beta$ 为 1.5–2，它沉到了 $3$–$5\ \mathrm{km}$，那是地壳项加热项。符合之好，使这个两项模型至今仍是每一次盆地分析的起点；而那个差——通常是模型低估了总沉降——正是盆地模拟者要加一个"隆起"项或"岩浆负载"项的原因。

最有用的推论是其反用：由热流或由折射地震学量出一个裂谷之下的当前地壳厚度，$\beta$ 以及由此推出的伸展便立刻得出。横过盆岭、爱琴海与北海的伸展就是这样被定量的；而爱琴海的地壳只有 $15\ \mathrm{km}$ 厚，它之所以被公认为地球上伸展最强烈的地区之一，原因也在这里。
:::
:::

::: example 由钻井资料读一个半地堑 {#ex-halfgraben}
在一个半地堑中，一条边界断层在地表倾 $50^\circ$。三口井位于一条垂直于断层走向的线上：1 号井在下盘，高程 $400\ \mathrm{m}$，同裂谷统底界在地表下 $900\ \mathrm{m}$；2 号井在上盘，高程 $350\ \mathrm{m}$，同裂谷统底界在地表下 $1650\ \mathrm{m}$；3 号井再向上盘方向 $6\ \mathrm{km}$，高程 $300\ \mathrm{m}$，同裂谷统底界在地表下 $1900\ \mathrm{m}$。同裂谷统的底界是平坦而未变形的。求该层位在每口井之下的深度；若 1 号井与 2 号井相距 $5\ \mathrm{km}$，再求其隐含的断层倾角；以及若该断层在 $10\ \mathrm{km}$ 处变平时的伸展。
::: solution
同裂谷统底界的深度（在海平面以下计量）为
$$
400 + 900 = 1300\ \mathrm{m}\ (\text{well 1}), \quad
350 + 1650 = 2000\ \mathrm{m}\ (\text{well 2}), \quad
300 + 1900 = 2200\ \mathrm{m}\ (\text{well 3}).
$$
该层位是平坦的，所以 1 号井与 2 号井之间那整整 $700\ \mathrm{m}$ 的落差是断层距；而 2 号井与 3 号井之间的 $200\ \mathrm{m}$，则或是第二条较小的断层，或是一个铲式面造成的滚动。

在相距 $5\ \mathrm{km}$ 的 1 号井与 2 号井之间，断层必须承担 $700\ \mathrm{m}$ 的距。若断层以其地表倾角 $50^\circ$ 保持平面，则从 1 号井到断层、再从断层到 2 号井的水平距离，会把断层定位在两者之间；而断层在 2 号井处的深度将是
$$
z = \frac{700}{\tan50^\circ} = \frac{700}{1.192} = 587\ \mathrm{m}
$$
低于该层位——也就是说在约 $1.9\ \mathrm{km}$ 深处。一条在 $1.9\ \mathrm{km}$ 深处承担 $700\ \mathrm{m}$ 断层距、倾 $50^\circ$ 的断层，是完全寻常的。

而如果该断层在 $10\ \mathrm{km}$ 处铺平到一个滑脱，则它在地表与该深度之间的平均倾角远低于 $50^\circ$，而在平均倾角 $25^\circ$ 下产生 $700\ \mathrm{m}$ 落差所需的平错则为 $700/\tan25^\circ = 1500\ \mathrm{m}$、而不是 $587\ \mathrm{m}$。这个差——两口井之间 $900\ \mathrm{m}$ 没有着落的水平距离——就是铲式几何的可观察签名；这也是为什么一个由地表倾角与一组井位连线建造的剖面，若不允许断层弯曲，就不会平衡。2 号井与 3 号井之间额外 $200\ \mathrm{m}$ 的下倾台阶，与变平断层之上的一个滚动背斜相容；而这恰恰是这样的几何所预测的，也是一条横过该构造单元的地震线所会显示的。
:::
:::

::: history
大陆是伸展而非收缩的思想，比板块构造更老。达顿（Dutton）在 1880 年就把盆岭读作水平伸展的产物，以几何的清晰描述了科罗拉多地区那些"挠曲的断块"，而这一点被整整忽视了八十年；休斯则把东非裂谷描述为一个三部分系统的一条失败之臂。现代研究始于 1960 年代的洋底扩张综合——它使伸展成为一个从第一原理出发的过程，而不是一处地方性的怪异——以及麦肯齐（McKenzie）1978 年关于岩石圈伸展的论文。后者把整个盆地形成归约为两个数——伸展因子与瞬时减薄的量——并给出了至今仍支撑着每一个盆地模拟程序的、按年龄平方根沉降的定律。几何则由 1970 与 1980 年代的野外工作奠定：阿姆斯特朗以及科尼与克里奇菲尔德对北美科迪勒拉变质核杂岩的识别，戴维斯、利斯特与弗罗斯特所描述的惠普尔山低角度滑脱，米勒与阿姆斯特朗所描述的大蛇山脉滑脱，以及维尔纳与伯奇菲尔 1982 年关于伸展构造与重力驱动断层的综合。由深海钻探与大洋钻探计划第 39、48、81、103 航次发现——最早来自伊比利亚边缘与纽芬兰的大西洋边缘——许多边缘是无火山的、并在洋底出露下伏的大陆地幔；这一发现推翻了"破裂总伴随暗色玄武岩"的假设，而它至今仍在产生新的构造样式，其中以西伊比利亚裂谷的"核杂岩"边缘最为引人注目。
:::

## 深度悖论

::: warning 正断层没有足够深
伸展构造的核心难题是一道算术题。盆岭在一个 $1000\ \mathrm{km}$ 宽的区域内被伸展了两倍或更多，而这个伸展显然由地表倾 $50^\circ$–$60^\circ$ 的正断层承担。如果这些断层作为平面一直延续到 $15\ \mathrm{km}$ 的地壳底部，那么产生观察到的伸展所需的滑动量将大到使上盘悬在半空：这些断层就必须在极浅的深度相交，而其间的块体则会转过一些并未被观察到的角度。这就是盆岭的**深度问题**，而维尔纳与伯奇菲尔在 1982 年把它明确地提了出来。

有四种解决之道，而四者都在起作用。断层是**铲式的**：它们随深度变平，并在 $10$–$15\ \mathrm{km}$ 处并入一个低角度滑脱，所以地表的倾角没有代表性。应变**分散**在比填出的多得多的断层上，其中包括没有地表显示的断层。伸展的一部分是**韧性的**，由下地壳流动、而不是由上地壳断裂承担，因而在地表不可见。而在伸展最强烈的地区，低角度断层**本身就是**那些构造：爱琴海、爱达荷–蒙大拿带与不列颠科迪勒拉的变质核杂岩，在倾 $20^\circ$–$30^\circ$、在 $10$–$20\ \mathrm{km}$ 深处活动的面上承担着几十公里的位移，而其上的陡断层则是盖层被移除之后重力驱动的回应。最后这一种解决之道要求一个低角度正断层能够滑动，而在垂直的 $\sigma_1$ 之下摩擦禁止这一点，除非孔隙压力极端、或该断层被系统的几何暂时地改陡——这是一个尚未完全了结的问题，也是这门学科中最有成果的一场争论之一。
:::

::: example 由断层平错能求出多少伸展？ {#ex-heave}
一个横过某伸展省的 $220\ \mathrm{km}$ 宽剖面穿过十四条正断层，其在图上垂直于各自走向量得的平错分别为 $2.1$、$1.8$、$3.4$、$1.2$、$2.6$、$4.0$、$1.5$、$2.2$、$3.1$、$1.9$、$2.4$、$1.1$、$2.8$、$1.6\ \mathrm{km}$。这些断层走向平行于剖面的缩短方向、倾 $55^\circ$。求总缩短与伸展因子；并求若这些断层是铲式的、并入一个滑脱面时，该滑脱面所在的深度。
::: solution
平错之和为 $31.7\ \mathrm{km}$，所以该剖面从 $220 + 31.7 = 251.7\ \mathrm{km}$ 缩短到了 $220\ \mathrm{km}$，而
$$
\beta = \frac{251.7}{220} = 1.14, \qquad e = 11.5\ \% .
$$
若每条断层都以 $55^\circ$ 保持**平面**、并切深到一个深度 $z$ 处的单一水平滑脱，则其平错为 $H = z/\tan\delta$，所以每条断层所要求的深度为
$$
z_i = H_i\tan\delta = 1.428\,H_i,
$$
其范围从最小断层的 $1.1\times1.428 = 1.6\ \mathrm{km}$，到最大断层的 $4.0\times1.428 = 5.7\ \mathrm{km}$。因此这些断层就必须在 $1.6$ 到 $5.7\ \mathrm{km}$ 之间十四个不同的深度变平。

地球物理与野外的证据把大多数伸展省的主要滑脱放在 $10$–$15\ \mathrm{km}$，远低于全部十四个值；所以平面的假设失败，而这些断层必定是**铲式的**：其倾角随深度减小，一条以 $55^\circ$ 出露于地表的断层，在向下的途中正经过 $40^\circ$、$30^\circ$、$20^\circ$ 而变平，并在比同地表倾角的平面断层大得多的深度范围内承担其平错。这就是深度悖论之于上地壳的解决之道，而它在美洲西部的矿山与采石场资料中是可以直接观察到的。铲式几何所不能做到的，是免除对一个深部滑脱的需要：在约 $12\ \mathrm{km}$ 之下，伸展必须由下地壳的韧性流动承担——这就是为什么伸展省的几何不是一爿铲式面，而是流动基底之上一整套断层组的层级。
:::

::: quiz
一个裂谷盆地的裂谷后热沉降，被观察到按时间的平方根曲线演化了 $8000$ 万年，然后变慢。这条曲线量的是什么？
- [x] 岩石圈以半空间传导的冷却与增厚。
- [ ] 沉积柱的压实。
- [ ] 对沉积负载的挠曲响应。
- [ ] 全球性的海平面变化。
::: solution
瞬时伸展之后的热沉降遵循一个半空间的冷却，其中热异常的深度按 $\sqrt{\kappa t}$ 增长，沉降也随之增长。它在热异常已传导掉、或岩石圈具有一个有限厚度时变慢，这就是为什么简单的半空间模型在超过约 80–100 Ma 的年龄上会高估沉降、以及为什么改用具有固定软流圈温度的"板模型"。压实、负载与全球海面变化都会影响观察到的厚度，这就是为什么在拟合沉降曲线之前要用回剥把它们扣除。
:::

## 从裂谷到边缘

::: definition 一个裂谷的一生 {#def-rift-stages}
一个成功的裂谷会经历若干可识别的阶段。**同裂谷期**：断层控制的沉降、高热流、碱性与拉斑玄武质的火山作用，以及排入半地堑的粗粒洪积与湖相沉积。**裂谷后的热坳陷**：断层作用减弱，沉降随岩石圈冷却变为区域的与指数的，浅海沉积超覆于断块之上。**破裂**：从大陆到洋底的岩浆作用的转变，在火山型边缘以暗色玄武岩与向海倾斜的反射层为标志，在无火山型边缘则以剥露出来的下伏大陆地幔为标志。**漂移**：洋底扩张，以及一条被动边缘的形成，其沉降在此后一亿年中遵循冷却岩石圈的按年龄平方根定律。
:::

::: example 火山型还是无火山型？ {#ex-margin-type}
一个被动边缘自大陆向海依次显示：具有 $20\ \mathrm{km}$ 宽断块减薄的大陆地壳；一个 $15\ \mathrm{km}$ 厚、向海倾斜的反射层序；一条被解释为底垫物质的高振幅、高速度反射的窄带；然后是带磁异常的正常洋壳。第二个边缘显示大陆地壳，然后是一个 $30\ \mathrm{km}$ 宽、强烈断错的、地幔橄榄岩在洋底出露的带，然后是洋壳，而完全没有火山层序。请分类并比较两者。
::: solution
第一个是一个**火山型（富岩浆）被动边缘**，属于纳米比亚、巴西、东格陵兰与德干那一类：上涌的地幔是热的，减压熔融量巨大，而向洋壳的转变由岩浆作用完成。向海倾斜的反射层序是在大陆破裂时喷发、并随沉降超过供给而向海超覆的一大堆暗色玄武岩；高速度反射是减薄地壳底部的底垫镁铁质物质。

第二个是一个**无火山型（贫岩浆）边缘**，属于伊比利亚、纽芬兰与黑海西部那一类：地幔是凉的、或伸展是快的，岩浆作用极小，而伸展由把下伏大陆地幔直接剥露到洋底的滑脱断层承担。那个 $30\ \mathrm{km}$ 宽的剥露橄榄岩带是有诊断意义的特征，而它意味着在那个带中地壳已被完全移除——一个实际上是无限的 $\beta$。

两种类型在对烃类与对灾害要紧的一切方面都不同。火山型边缘有一个厚的、常常是不渗透的火山盖层，它造就好的圈闭、也造就糟糕的地震成像，而其烃源岩被火山堆埋掉。贫岩浆边缘成像优良，具有造就构造圈闭的洋底滑脱下的复杂古地形，而其地幔水化、蛇纹石化，产生氢以及随之而来的甲烷。两者都有产出；两者的勘探策略完全不同，而一个盆地分析者所做的第一件事，就是判断地震上是哪一种。
:::
:::

## 通向何处

建造一个裂谷的断层在 [[structural-geology/fractures-faults]] 中描述；在滑脱之下深部形成的剪切带在 [[structural-geology/shear-zones]] 中；支配沉降的均衡在 [[geophysics/gravity-isostasy]] 中；岩石圈在一个裂谷周围的挠曲在 [[geophysics/flexure]] 中；而充填盆地的沉积系统在 [[sedimentology/basins-sequences]] 中。

::: summary
- 一个裂谷是一个由正断层限界的地壳伸展带，而它是每一条被动边缘的前身。
- 伸展因子 $\beta$ 联系着拉伸后与拉伸前的长度，并由厚度给出地壳减薄。
- 仅地壳减薄一项就能把一个裂谷沉到几公里，而上涌软流圈的热贡献大约使它加倍。
- 在地表观察到的陡正断层本身无法解释观察到的伸展；缺失的应变存在于铲式几何中、未填出的断层中、韧性流动中、以及低角度滑脱中。
- 一个裂谷经历同裂谷断层作用、裂谷后热坳陷、破裂与漂移，而每个阶段都留下一套独特的地层。
- 火山型与无火山型被动边缘，在破裂时岩浆作用的多少、以及此后对勘探要紧的一切方面都不同。
:::

## 练习

::: exercise 伸展因子 {level=1 check="1.67"}
一个裂谷经历了百分之四十的伸展。$\beta$ 是多少？
::: solution
$\beta = 1/(1 - 0.40) = 1.67$。地壳是其原厚的三分之二。
:::
:::

::: exercise 地壳厚度 {level=1 check="21"}
若在一个裂谷前地壳厚 $35\ \mathrm{km}$ 的区域之下 $\beta = 1.7$，那么现在的地壳厚度是多少（以公里计）？
::: solution
$h = 35/1.7 = 20.6\ \mathrm{km}$，约 $21\ \mathrm{km}$。这是由重力或地震折射得出的地壳厚度模型来填绘伸展的标准做法。
:::
:::

::: exercise 地堑断层作用 {level=1}
在地震资料中区分地堑与半地堑，并说明哪一种是裂谷早期更常见的。
::: solution
一个**地堑**由两条相向倾斜的边界断层限界，两者都活动，而其充填关于轴部对称。一个**半地堑**由一条主导断层限界，对侧则在一组较小的反向断层上缓缓旋转，而其充填向边界断层一侧增厚。半地堑在裂谷早期远为常见，因为在系统发育出分散应变的成熟度之前，一条断层会把应变定域起来；对称的地堑倾向于更晚出现，或出现在伸展方向改变了的地方。
:::
:::

::: exercise 沉降 {level=2 check="6.9"}
用 [[#ex-subsidence]] 的模型，求仅由地壳减薄在 $\beta = 4$ 时所产生的水深（以公里计）。
::: solution
$d = 0.264\times35\times(4-1)/4 = 0.264\times26.25 = 6.9\ \mathrm{km}$。注意在 $\beta \approx 3$ 之外深度增加得多么少：地壳减薄项饱和了，而任何进一步的沉降必须来自地幔、来自岩浆作用、或来自沉积负载。
:::
:::

::: exercise 核杂岩 {level=2}
一个变质核杂岩在一个糜棱片麻岩之下出露石榴石–云母片岩，而该糜棱片麻岩又被不整合覆盖以无面理的白垩纪砾岩。糜棱岩显示向西的剪切，而其上的砾岩含有片岩的砾石。请重建这段历史。
::: solution
片岩与片麻岩是被一条低角度正断层——滑脱——剥露出来的中地壳岩石，其糜棱质的上盘片麻岩记录着盖层向西、离开核部的平移。砾岩之下的不整合面**就是那条滑脱断层本身、或其侵蚀面**，而砾岩是从抬升的核部排出的同构造充填。因为砾岩含有片岩的砾石，片岩在砾岩沉积之前就已经被剥露到地表，所以该滑脱到白垩纪时已承担了它的大部分位移。

这一解释的检验是：糜棱岩的组构是否沿断层面渐变为断层角砾岩；砾岩是否向上盘凹陷中增厚；以及糜棱岩中同构造长石的放射性同位素年龄是否与砾岩底部相符。当三者都相符时，这个核杂岩就为伸展定了年，而其时代就可以与板块构造的重建联系起来。
:::
:::

::: exercise 热流 {level=2 check="110"}
在一个 $\beta = 2$ 的裂谷之下，地表热流的地壳放射性组分随地壳减薄从 $60$ 的背景降到 $30\ \mathrm{mW\,m^{-2}}$，而地幔组分则随热软流圈接近地表从 $40$ 升到 $80\ \mathrm{mW\,m^{-2}}$。地表总热流是多少（以 $\mathrm{mW\,m^{-2}}$ 计）？
::: solution
$q = 30 + 80 = 110\ \mathrm{mW\,m^{-2}}$，而背景为 $100$。这道题的要点是：一个裂谷的热流异常远小于任一组分的变化，因为地壳组分与地幔组分朝相反的方向移动——这就是为什么热流是 $\beta$ 的一个糟糕的判别量，也是为什么诊断性的观察是沉降曲线的形状、而不是热流。
:::
:::

::: exercise 断层群体 {level=3}
一个裂谷的边界断层平均间距为 $8\ \mathrm{km}$、倾 $55^\circ$，而发震层厚 $12\ \mathrm{km}$。若每条断层的最大位移为其长度的百分之七，估计由出露地表的断层所承担的伸展，并说明这相当于总伸展 $\beta = 1.8$ 中的多少。
::: solution
一条倾 $55^\circ$、切过 $12\ \mathrm{km}$ 厚发震层的断层，有一个 $12/\sin55^\circ = 14.6\ \mathrm{km}$ 的下倾长度，以及至少 $12/\tan55^\circ = 8.4\ \mathrm{km}$ 的地表迹线；取 $20\ \mathrm{km}$ 作为这一间距的边界断层的典型断层长度，最大位移为 $0.07\times20 = 1.4\ \mathrm{km}$，其中平错为 $1.4\cos55^\circ = 0.80\ \mathrm{km}$。

在 $8\ \mathrm{km}$ 的间距下，每 $8\ \mathrm{km}$ 剖面有一个这样的断层，所以伸展为 $0.80/8 = 0.10$，即百分之十，给出 $\beta = 1.11$。所要求的伸展是 $\beta = 1.8$，所以填出的断层承担了
$$
\frac{1.11 - 1}{1.8 - 1} = \frac{0.11}{0.80} = 14\ \%
$$
。八分之七的伸展缺失了，而候选者还是那四个：填图分辨率之下的断层、下地壳的韧性流动、不在地表重复的低角度滑脱上的大位移、以及块体的旋转（使伸展有一部分不经新断层作用而被承担）。这个计算在每一个裂谷中都值得做，因为不符的大小本身就是一个度量——度量着那不可见的应变有多少。
:::
:::

::: exercise 边缘演化 {level=3}
一口位于被动边缘的井自上而下钻过：$400\ \mathrm{m}$ 的全新世陆架砂；$1.2\ \mathrm{km}$ 的海相页岩，其有孔虫时代自 $90$ 到 $20\ \mathrm{Ma}$ 渐新；一个 $300\ \mathrm{m}$ 的煤与三角洲砂层；$800\ \mathrm{m}$ 的非海相红层与湖相页岩；然后是断错的花岗岩。海相页岩的底部在 $1.6\ \mathrm{km}$，红层的底部在 $2.7\ \mathrm{km}$。请重建该边缘的历史，并由沉降估计伸展因子。
::: solution
这个序列是一个教科书式的被动边缘，按事件的反序。断错的花岗岩是裂谷基底。$800\ \mathrm{m}$ 的非海相红层与湖相页岩是一个半地堑的**同裂谷**充填，沉积在被断层限界的湖中。$300\ \mathrm{m}$ 的煤与三角洲砂是**破裂**序列，沉积于沉降超过沉积供给、海水漫过倒转地形之时。$1.2\ \mathrm{km}$ 的海相页岩是**裂谷后热坳陷与漂移**序列，而其自 $90$ 到 $20\ \mathrm{Ma}$ 渐新的时代记录着冷却岩石圈的连续沉降。全新世的砂是当前的陆架。

至于伸展，同裂谷的 $800\ \mathrm{m}$ 厚度加破裂的 $300\ \mathrm{m}$ 厚度，给出约 $1.1\ \mathrm{km}$ 的断层控制沉降，而破裂时的水深是浅的，所以地壳减薄项在 $1.1\ \mathrm{km}$ 的量级。以 $d = 1.1$ 反解 $d = 0.264\times35(\beta-1)/\beta$ 得 $(\beta-1)/\beta = 0.119$，故 $\beta = 1.14$。加上量级相当的热贡献，大约使该项加倍，给出 $\beta \approx 1.3$。

这是一个不大的伸展，而它是一个由单口井得出、并可能错上两倍的数。恰当的估计要用整条裂谷后沉降曲线，为沉积负载与全球海面回剥，并拟合冷却岩石圈模型；由拟合得出的 $\beta$ 一般大于由同裂谷厚度单独得出的那个，因为相当一部分减薄是在完全没有断层作用的情况下发生的。
:::
