应力无法在岩石中被测量；应变可以。没有人曾把一个应变计放进一个褶皱里，但任何有薄片的人都能测量一个变形鲕粒的长轴与短轴之比，而这个数就是应变张量的一个分量。整个构造地质学都建立在这个不对称之上：可观察量是几何，而应力只能通过一个须从别处提供的流变律进入。本章讲的是如何精确地描述几何，因为一个无法被描述的变形就无法被解释。

## 位移，以及其中哪一部分是应变

::: definition 位移梯度、旋转与应变 {#def-displacement-gradient}
设一个质点从 $\mathbf{x}$ 移动到 $\mathbf{x}' = \mathbf{x} + \mathbf{u}(\mathbf{x})$，其中 $\mathbf{u}$ 是**位移**。位移梯度为 $H_{ij} = \partial u_i/\partial x_j$，它唯一地分解为一个对称部分与一个反对称部分，
$$
H_{ij} = \underbrace{\tfrac12\left(\frac{\partial u_i}{\partial x_j} + \frac{\partial u_j}{\partial x_i}\right)}_{e_{ij}\ \text{strain}} \; + \; \underbrace{\tfrac12\left(\frac{\partial u_i}{\partial x_j} - \frac{\partial u_j}{\partial x_i}\right)}_{\omega_{ij}\ \text{rotation}} .
$$
在小位移下，**无穷小应变张量**为
$$
e_{xx} = \frac{\partial u}{\partial x}, \qquad
e_{xy} = \tfrac12\left(\frac{\partial u}{\partial y} + \frac{\partial v}{\partial x}\right),
$$
而**工程剪应变**为 $\gamma_{xy} = 2e_{xy} = \partial u/\partial y + \partial v/\partial x$。
:::

::: proposition 刚体旋转不是应变 {#prop-rotation}
一个只是刚体平移与旋转的位移场产生 $e_{ij} = 0$；反过来，若一个连通体内处处 $e_{ij} = 0$，则该变形是刚体运动。因此应变就是位移梯度在去掉旋转之后剩下的那部分，一个物体可以被位移数百公里而毫无应变。
:::

::: proof
刚体运动有 $\mathbf{u} = \mathbf{a} + \boldsymbol{\Omega}\mathbf{x}$，其中 $\boldsymbol{\Omega}$ 为常数且反对称，于是 $H_{ij} = \Omega_{ij}$，对称部分为零。反过来，若 $e_{ij} = 0$，则在场可微之处 $H_{ij} = \omega_{ij}$ 为常数，故运动是刚体的。其物理内涵是：对称部分度量的是*相邻两点之间距离*的变化——对相距 $\mathrm{d}\mathbf{x}$ 的两点，
$$
|\mathrm{d}\mathbf{x}'|^2 - |\mathrm{d}\mathbf{x}|^2 = 2\,e_{ij}\,\mathrm{d}x_i\,\mathrm{d}x_j ,
$$
所以应变恰恰是、而且只是长度的变化。这就是为什么应变能从一个变形物体测出、而应力不能：物体记住的是它形状的变化，而不是造成它的力。
:::

::: definition 主应变、体膨胀与应变椭球 {#def-principal-strain}
应变张量是对称的，因此有三个实特征值 $e_1 \geq e_2 \geq e_3$，即**主应变**，沿三个相互垂直、不受剪的方向。**体膨胀**为迹，
$$
\Delta = e_{kk} = e_1 + e_2 + e_3 = \frac{\delta V}{V},
$$
而其偏量部分 $e_{ij} - \tfrac13\Delta\delta_{ij}$ 描述等体积下的形状变化。一个物质球变成一个**应变椭球**，其半轴之比为 $\lambda_1 : \lambda_2 : \lambda_3$，其中**伸长** $\lambda_i = 1 + e_i$ 是末长与初长之比。**自然**应变或真应变为 $\varepsilon_i = \ln\lambda_i$，它的性质是两次相继变形的总应变等于相加，因而在应变量大时使用这种度量。
:::

## 纯剪与简单剪

::: definition 两种端元变形 {#def-pure-simple}
**纯剪**是同轴变形：主应变轴在变形过程中不旋转，主面上没有剪应力，应变沿固定的方向积累。它是平行层面的缩短、颈缩以及褶皱核部应变的理想化。**简单剪**是非同轴的：物质面像一副纸牌那样彼此滑过，主应变轴连续地向剪切方向旋转，而且存在一组面——剪切面——既不被拉伸也不被旋转。它是断层带、糜棱岩、以及韧性剪切带中的流动的理想化。
:::

::: proposition 简单剪中的伸长 {#prop-simpleshear}
取一个剪应变为 $\gamma$ 的简单剪切，其中点 $(x, y)$ 移到 $(x + \gamma y,\, y)$。一条初始长度为 $l$、与剪切方向成 $\theta$ 角的物质线，变为长度 $l'$、与剪切方向成 $\theta'$ 角的线，二者满足
$$
\lambda' \equiv \left(\frac{l'}{l}\right)^{2} = 1 + \gamma\sin 2\theta + \gamma^{2}\sin^{2}\theta,
\qquad
\tan\theta' = \frac{\sin\theta}{\cos\theta + \gamma\sin\theta} .
$$
起始于 $\theta = 0$ 的线不被拉伸，$\theta = 90^\circ$ 的线被拉伸 $\sqrt{1+\gamma^2}$ 倍，而变形保持面积不变：$\det\mathbf{F} = 1$。
:::

::: proof
该线的方向矢量为 $(\cos\theta, \sin\theta)$，变形梯度为 $\mathbf{F} = \begin{pmatrix} 1 & \gamma \\ 0 & 1\end{pmatrix}$，故其像为 $(\cos\theta + \gamma\sin\theta, \sin\theta)$。取平方并用 $2\sin\theta\cos\theta = \sin2\theta$ 即得 $\lambda'$；取分量之比即得 $\tan\theta'$。无论 $\gamma$ 为何值，$\mathbf{F}$ 的行列式都是 1，所以简单剪切保体积——这就是为什么一条糜棱岩带能容纳数米的位移而岩石密度毫无变化，也是为什么糜棱岩的"流劈理"是一个剪切面的迹线、而不是一个压实面。
:::

::: example $\gamma = 1$ 的简单剪切 {#ex-simple1}
一个斑晶与一组原本圆形的石英颗粒位于遭受了 $\gamma = 1$ 简单剪切的岩石中。求主伸长度及其方位、应变椭圆的轴比、一条起始于与剪切方向成 $45^\circ$ 的线的最终角度，以及等价的纯剪切。
::: solution
变形梯度为 $\mathbf{F} = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}$，伸长张量为 $\mathbf{C} = \mathbf{F}^{\mathsf T}\mathbf{F} = \begin{pmatrix} 1 & 1 \\ 1 & 2\end{pmatrix}$，特征值为 $2.618$ 与 $0.382$。因此主伸长度为
$$
\lambda_1 = \sqrt{2.618} = 1.618, \qquad \lambda_3 = \sqrt{0.382} = 0.618,
$$
其乘积为 1.000，正是保体积所要求的；其轴比为 $R_s = 1.618/0.618 = 2.62$。伸长方向与剪切方向成 $58.3^\circ$——不是 $45^\circ$；那是直觉给出的答案，而它是错的：最大伸长已经朝剪切面旋转过去了。

一条起始于 $45^\circ$ 的线终止于
$$
\tan\theta' = \frac{\sin 45^\circ}{\cos 45^\circ + 1\times\sin 45^\circ} = \frac{1}{1+1} = \tfrac12, \qquad \theta' = 26.6^\circ,
$$
其伸长为 $\lambda' = 1 + \sin 90^\circ + \sin^2 45^\circ = 2.50$，即长度变为 1.58 倍，同时朝剪切方向旋转了 $18^\circ$。

等价的纯剪切——具有同一应变椭圆的同轴变形——有 $\lambda_1/\lambda_3 = R_s = 2.62$，而由杰弗里关系，产生它的简单剪切为
$$
\gamma_s = \sqrt{R_s} - \frac{1}{\sqrt{R_s}} = 1.618 - 0.618 = 1.00,
$$
正如必须如此。这个关系值得以那个形式记住，因为它是糜棱岩中测得的剪应变与变形鲕粒中测得的轴比之间的标准换算；它表明，一个表观轴比只有 2.6 的岩石，其剪切量已与它自身的长度相当。
:::
:::

::: quiz
一条糜棱岩中一个石英颗粒的轴比为 3.0。同一岩石中还含有一个轴比为 1.3 的硅质砾。这两个数各自度量着什么？

- [x] 类鲕粒的石英颗粒近似于基质应变；而强性的砾记录的远小于基质应变。
- [ ] 砾是更好的应变标记，因为它更抗后期蚀变。
- [ ] 两者都不能用；只有劈理的间距记录应变。

一个强性的物体的变形远小于其周围的基质，因为应变被分配到较弱的相中；因此片岩中的一个硅质砾给出的是一个下限、而不是一个估计。富基质的石英颗粒在其流变上接近其周围物质，主要通过晶内塑性变形，所以其形状是一个好得多的应变标记——但要受到关于压溶与粒度敏感压扁的那些告诫的限制。劈理间距只通过一个平行层面缩短的模型来记录应变，而该模型必须单独论证。
:::
:::

## 从岩石中测量应变

::: example 变形的鲕粒 {#ex-ooids}
一个变形石灰岩中的鲕粒呈椭圆形，在垂直于褶皱轴的剖面上轴比为 $R_{fs} = 3.0$。假设它们原本是球形的、该剖面包含最大与最小主伸长度、其中的应变是平面应变且平行于褶皱轴的方向没有拉伸，求主伸长度、垂直于该剖面的缩短，以及若变形是一个剪切面平行于层理的简单剪切时的剪应变。
::: solution
$R_{fs} = \lambda_1/\lambda_3 = 3.0$，剖面内等体积给出 $\lambda_1\lambda_3 = 1$，故 $\lambda_1^2 = 3.0$，
$$
\lambda_1 = 1.732, \qquad \lambda_3 = 0.577, \qquad \lambda_2 = 1.000 .
$$
岩石在剖面内伸长了 73 %、在垂直方向上缩短到原厚度的 58 %——即缩短了 42 %。作为自然应变，$\varepsilon_1 = \ln 1.732 = +0.549$、$\varepsilon_3 = \ln 0.577 = -0.549$，等值反号，这正是使对数应变值得使用的算术便利。

若变形是一个剪切面平行于层理的简单剪切，等价的剪应变为
$$
\gamma = \sqrt{R_s} - \frac{1}{\sqrt{R_s}} = \sqrt{3.0} - \frac{1}{\sqrt{3.0}} = 1.732 - 0.577 = 1.15 .
$$
在一米宽的糜棱岩带上，这就是 1.15 m 的位移；在一公里宽的剪切带上，就是 1.15 km。这个计算的要点在于尺度不变性：只要变形是均匀的，在手标本上测得的应变就是整条带的应变，这就是在没有任何标志层幸存下来可供错断的地方，大型韧性剪切带位移量的估计方式。
:::
:::

::: example 三个剖面与一个弗林图 {#ex-flinn}
一个变形砾岩中，三个相互垂直的剖面里的椭圆状物体分别给出 $XY$ 剖面上轴比 3.0、$XZ$ 剖面上 4.5、$YZ$ 剖面上 1.5。求主伸长度、弗林参数，以及应变椭球的形状。
::: solution
三个比值是 $a/b = 3.0$、$a/c = 4.5$、$b/c = 1.5$，三者彼此相容，因为 $3.0\times1.5 = 4.5$。归一化到等体积，$\lambda_1\lambda_2\lambda_3 = 1$，且 $\lambda_1/\lambda_2 = 3$、$\lambda_2/\lambda_3 = 1.5$：写作 $\lambda_3 = t$ 得 $\lambda_2 = 1.5t$、$\lambda_1 = 4.5t$，故
$$
4.5t\times1.5t\times t = 6.75\,t^{3} = 1 \quad\Longrightarrow\quad t = 0.523,
$$
于是 $\lambda_1 = 2.35$、$\lambda_2 = 0.78$、$\lambda_3 = 0.52$。

弗林参数为
$$
k = \frac{a/b}{b/c} = \frac{3.0}{1.5} = 2.0 .
$$
因为 $k > 1$，椭球是**长轴的**——雪茄状的——应变由一个方向上的拉伸主导，而缩短分布在另外两个方向上。在弗林图上，该点画在 $k = 1$ 线（平面应变）之上，而且远离代表纯压扁的 $k = 0$。从地质上说，长轴应变是挤压样式的签名： 双倾伏的褶皱拐突的内部、一个石香肠域，或一个双向收敛区。压扁（$k < 1$）则是展布样式的签名：一个伏在其底板之上的逆冲岩席：岩石被垂直于缩短的方向挤出，而不沿缩短方向拉伸。
:::
:::

::: warning 一个变形的化石记录的是化石的应变，不是岩石的应变
上面两个例子的整个方法都依赖于两个假设：物体原本是球形的、或在某个已知剖面上原本是圆形的，并且它是**被动**变形的——也就是说，其应变与周围基质的应变完全相同。而两个假设都会以可预测的方式失效。鲕粒与鲕 通过其接触处的压溶与内部的孪生而压扁，它们可以在基质应变不过百分之几的情况下发展出二的轴比。粘度与之大不相同的基质中的球形物体，其旋转与变形都小于周围基质，所以一个强性的砾会低估应变，而一个经压溶压扁的会高估应变。而一个原本具有两侧对称的化石——菊石、腕足——其形状一开始就不是球；没有一组标本，其变形就无法与其个体发育分开。

站得住的做法是测量多种类的许多物体，考察它们之间的一致性，并优先选择在同成分的基质中以晶内塑性过程变形的物体：石英岩中的石英颗粒、纯石灰岩中的方解石颗粒、磁铁矿石英岩中的磁铁矿。在应变量大的地方，最安全的测量不是颗粒的形状，而是**组构的方位**，它即使在其大小无法恢复时，也记录着流动的几何。
:::

::: history
应变的数学属于弹性力学：纳维与柯西在 1820 年代写下了应变张量，圣维南在 1843 年证明六个应变分量不能任意选取、而必须满足相容性条件——这正是为什么地质学家不能给一个褶皱层任意指定一个应变场并指望它闭合。地质学的发现来自相反的方向，而且晚得多。索尔比在 1858 年证明北威尔士的板状劈理是一种绿泥石与云母定向排列的组构、而不是一个裂开面；与此同时，普雷斯特维奇与拉普沃思正在把志留纪笔石的变形作为地层工具来填图。决定性的一步是哈克在 1888 年的观察：某些石灰岩中椭圆的鲕粒与鲕 曾被旋转并拉伸，而它们的轴比与方位可以被测量并利用——这是地质学中第一次有限应变测量，也是整个应变分析学科的起源。克洛斯在 1921 年把应变椭球这个术语与概念引入构造岩石学，而现代的定量处理始于 1950 与 1960 年代：拉姆贝格与茨瓦特的应变网与流线网，拉姆齐（Ramsay）的注入法与图解技术——他 1967 年的《褶皱的形成》使应变椭圆成为一种常规的野外测量——以及弗林（Flinn）1962 年的弗林图，它把三维应变的形状化简为一个数。认识到非同轴流动——简单剪切——在地壳中是常态而不是例外，来自 1970 年代的糜棱岩研究与格雷与辛普森的剪切指向标志，它把构造地质学从形状的研究变成了运动的研究。
:::

## 应变速率

::: definition 应变速率 {#def-strain-rate}
应变速率是应变对时间的导数，$\dot{e}_{ij} = \partial e_{ij}/\partial t$，单位为 $\mathrm{s^{-1}}$。地质应变速率小得惊人：$1\ \mathrm{Myr^{-1}} = 3.2\times10^{-14}\ \mathrm{s^{-1}}$，而典型的板内与造山带内部的值为 $10^{-15}$ 到 $10^{-13}\ \mathrm{s^{-1}}$。以 $10^{-14}\ \mathrm{s^{-1}}$ 变形的地壳，积累大小为 1 的应变需要 $10^{14}\ \mathrm{s}$，即三百万年——这就是为什么在 $10^{-6}\ \mathrm{s^{-1}}$ 下于实验室测得的岩石强度与地壳的强度几乎毫无关系。
:::

::: example 地壳变形得有多快？ {#ex-strainrate}
一条 $20\ \mathrm{km}$ 厚的剪切带在 $5\ \mathrm{Myr}$ 内容纳了 $100\ \mathrm{km}$ 的位移。求平均应变速率；若流动定律为 $\dot{\varepsilon} = A\sigma^{n}$、$n = 3$、$A = 1.2\times10^{-13}\ \mathrm{MPa^{-3}\,s^{-1}}$，求 $400^\circ\mathrm{C}$ 下石英糜棱岩中的应力。
::: solution
应变为 $\gamma = 100/20 = 5$，历时 $5\times10^{6}\ \mathrm{yr} = 1.58\times10^{14}\ \mathrm{s}$，故
$$
\dot{\gamma} = \frac{5}{1.58\times10^{14}} = 3.2\times10^{-14}\ \mathrm{s^{-1}} .
$$
反解流动定律，
$$
\sigma = \left(\frac{\dot{\varepsilon}}{A}\right)^{1/n} = \left(\frac{3.2\times10^{-14}}{1.2\times10^{-13}}\right)^{1/3} = 0.267^{1/3} = 0.64\ \mathrm{MPa}.
$$
这是一个小得惊人的应力——比拜尔利摩擦低两个数量级——而这正是糜棱岩得以形成的原因。注意指数的杠杆作用：若应变速率高一千倍，应力也只上升 $1000^{1/3} = 10$ 倍，到 $6.4\ \mathrm{MPa}$。一个 $n = 3$ 的幂律材料因此对变形有多快极其不敏感，这就是为什么同一种糜棱岩组构既形成于活动了一百万年的剪切带，也形成于活动了十万年的剪切带。
:::
:::

## 通向何处

产生这些应变的应力、以及限制它的摩擦，见 [[structural-geology/stress]]；把两者联系起来的流动定律见 [[structural-geology/rheology]]；由此产生的几何见 [[structural-geology/folds]] 与 [[structural-geology/shear-zones]]；而应变在野外如何被填图是 [[structural-geology/maps-sections]] 的主题。

::: summary
- 应变是位移梯度的对称部分；刚体旋转与平移对它毫无贡献。
- 应变可测而应力不可测，这就是整个学科建立在几何与一个外加流变律之上的原因。
- 主伸长度 $\lambda_i$ 与自然应变 $\ln\lambda_i$ 是大变形下有用的度量；体膨胀是体积的变化。
- 纯剪是同轴的，简单剪切不是；在简单剪切中，应变椭圆在长大的同时向剪切方向旋转。
- 简单剪切保持体积，等价的同轴应变有 $\gamma = \sqrt{R_s} - 1/\sqrt{R_s}$。
- 从变形物体测得的应变假设物体原本等轴、且被动变形；两个假设都按已知的、可校正的方式失效。
- 地质应变速率约为 $10^{-14}\ \mathrm{s^{-1}}$，而在该速率下幂律蠕变所需的应力远低于岩石的摩擦强度。
:::

## 练习

::: exercise 工程剪应变与张量剪应变 {level=1 check="0.5"}
一个物质正方形被变形，使其上边侧向移动其边长的一半、而下边保持固定。工程剪应变 $\gamma$ 是多少？
::: solution
$\gamma = \tan\psi = 0.5$，其中 $\psi$ 是直角的改变量。张量分量为 $e_{xy} = \gamma/2 = 0.25$。两种约定相差二倍，把它们混用是本学科最常见的错误；本章的简单剪切几何中出现的正是工程值。
:::
:::

::: exercise 自然应变 {level=1 check="0.69"}
一个层被拉伸到原长的两倍。给出工程应变与自然应变。
::: solution
$e = 1.0$，$\varepsilon = \ln 2 = 0.69$。对数度量的优点出现在同一层随后被缩短回原长之时：自然应变是 $+0.69$ 与 $-0.69$、总和为零；而工程应变是 $+1.0$ 与 $-0.5$、总和为 $+0.5$，这是荒谬的。
:::
:::

::: exercise 体膨胀 {level=1 check="-0.1"}
一块岩石以主伸长度 $\lambda_1 = 1.4$、$\lambda_2 = 1.0$、$\lambda_3 = 0.64$ 变形。求体积变化。
::: solution
$\lambda_1\lambda_2\lambda_3 = 1.4\times1.0\times0.64 = 0.896$，所以岩石失去了其体积的 10.4 %：$\Delta V/V = -0.10$。这样的体积损失无法由弹性拉伸容纳，而需要压溶、压实或流体逸出三者之一——因此在变质岩中发现百分之十的扩容，就是物质转移的直接证据；这也是为什么 [[structural-geology/rheology]] 中的体积平衡计算与应变测量本身做得一样多。
:::
:::

::: exercise 简单剪切 {level=2 check="2.24"}
在 $\gamma = 2$ 的简单剪切中，一条原本与剪切方向成 $45^\circ$ 的线伸长了多少倍？
::: solution
$\lambda' = 1 + \gamma\sin 2\theta + \gamma^2\sin^2\theta = 1 + 2\times1 + 4\times0.5 = 5.0$，故长度比为 $\sqrt{5.0} = 2.24$。注意交叉项 $\gamma\sin2\theta$ 在 $0 < \theta < 90^\circ$ 时为正：第一象限的线被拉伸得比只看 $\gamma^2$ 项所提示的更多，而第二象限的线则被同一项缩短。正是这个不对称，使一条剪切带两侧的斑碎晶群看起来不同。
:::
:::

::: exercise 简单剪切中的旋转 {level=2 check="32"}
在 [[#ex-simple1]] 的 $\gamma = 1$ 剪切中，一条原本与剪切方向成 $60^\circ$ 的线旋转了多少角度？朝哪个方向？
::: solution
$\tan\theta' = \sin 60^\circ/(\cos 60^\circ + \sin 60^\circ) = 0.866/(0.500+0.866) = 0.634$，故 $\theta' = 32.3^\circ$。该线朝剪切方向**转过了** $27.7^\circ$，这正是有诊断意义的方向：在简单剪切中，凡是满足 $0 < \theta < 90^\circ$ 的线都朝剪切方向旋转，而第二象限的线则从另一侧朝它旋转。正是这个旋转产生了斑碎晶的"鱼"形与"σ"形，也使糜棱岩的非对称性成为一种剪切指向标志。
:::
:::

::: exercise 等价的纯剪切 {level=2 check="1.5"}
一条糜棱岩在包含线理的剖面中含有轴比 $R_s = 4.0$ 的变形鲕粒。这对应于多大的简单剪应变？
::: solution
$\gamma = \sqrt{R_s} - 1/\sqrt{R_s} = 2.0 - 0.5 = 1.5$。在一条 $200\ \mathrm{m}$ 宽的剪切带中，这就是 $300\ \mathrm{m}$ 的位移。注意答案比轴比所提示的更大：一个看起来只拉长了四倍的鲕粒，记录的剪切量却是带宽的一点五倍。
:::
:::

::: exercise 弗林参数 {level=2 check="0.5"}
一个砾岩给出 $a/b = 2.0$、$b/c = 4.0$。求 $k$ 并描述应变椭球。
::: solution
$k = (a/b)/(b/c) = 2.0/4.0 = 0.5$。因为 $k < 1$，椭球是**扁球的**——煎饼状的——应变是一种压扁：岩石在一个方向上的缩短远小于另外两个方向上的，并在另外两个轴所构成的面上被拉伸。这是逆冲岩席的经典应变，见于岩石被侧向挤出、而不是被拉伸的地方。
:::
:::

::: exercise 应变速率 {level=2 check="32"}
一个 $5\ \mathrm{km}$ 厚的地壳层在 $10\ \mathrm{Myr}$ 内缩短了 $50\ \mathrm{km}$。求以 $\mathrm{s^{-1}}$ 计的平均应变速率，以 $10^{-15}\ \mathrm{s^{-1}}$ 的倍数表示。
::: solution
$\gamma = 50/5 = 10$，历时 $10^{7}\ \mathrm{yr} = 3.16\times10^{14}\ \mathrm{s}$，故 $\dot\varepsilon = 3.2\times10^{-14}\ \mathrm{s^{-1}} = 32\times10^{-15}\ \mathrm{s^{-1}}$。这个数是一个好的标定基准：在一个几十公里厚的层中以每年几厘米计的造山缩短，其应变速率总是 $10^{-14}\ \mathrm{s^{-1}}$ 的量级，无论哪个造山带都是如此；正是这一个数，使实验变形石英岩的流动定律标定能够直接用于山脉。
:::
:::

::: exercise 被动还是不被动 {level=3}
同一构造位置的两个层，在同一剖面中含有变形的方解石鲕粒（$R_{fs} = 2.8$）与变形的硅质砾（$R_{fs} = 1.4$）。基质是一种石英云母片岩。把两个测量协调起来，并说明哪一个（如果有）给出基质的应变。
::: solution
两类物体相对于基质的粘度差别很大。**硅质砾**远比片岩强，所以它主要通过刚体旋转与弹性弯曲变形，它所承担的应变远小于基质：$R_{fs} = 1.4$ 是基质应变的一个下限，而不是它的估计。**方解石鲕粒**在成分与流变上接近基质中的方解石，主要通过晶内塑性与压溶变形，所以接近被动——但方解石鲕粒也因颗粒接触处的溶液转移而压扁出名，这会使比值虚高。

两个数都不是基质应变。站得住的路线是直接测量基质本身：石英颗粒的形状优选方位、动态重结晶颗粒的长宽比（它随应力变化，从而通过流动定律随应变速率、而不是随应变变化），而最重要的是**从流变相匹配的应变标记恢复的有限应变**——一个变形的杏仁体、一条成分相近的变形岩墙、或一条变形的缝合线。在这些东西都不存在的地方，正确的说法是：应变大于 1.4、很可能大于 2.8，而其大小未知。
:::
:::

::: exercise 相容性 {level=3}
一个野外区含有一个轴面倾角 $70^\circ$ 的褶皱，其核部有一条倾角 $10^\circ$ 的劈理。解释为什么二者不可能都是同一次均匀缩短的产物，并给出使二者协调的两种机制。
::: solution
均匀缩短产生垂直于 $\sigma_3$ 的劈理，而对一个轴面陡倾的褶皱而言，那是陡倾的。因此陡倾伏褶皱核部中的缓倾劈理，要么记录着另一次变形，要么记录着另一个应力场；二者不可能来自同一个同轴应变。

**机制一：两次变形。**陡倾劈理是早期褶皱期间平行层面缩短的产物，而平缓劈理是在第二次同轴缩短中形成的后期褶皱劈理——或者反过来，先形成平缓组构、再叠加陡倾组构。检验办法是薄片中的叠加关系：使早期劈理再褶皱的褶皱劈理更年轻；二者可以被分开，并分别测量。

**机制二：应变划分。**平缓劈理是在褶皱恰好位于其中的低角度剪切带中形成的 **S–C 或伸展**组构，而陡倾的轴面劈理形成于褶皱核部——那里的局部流动是同轴的、剪切分量很小。检验办法是运动学的：平缓组构应在数公里范围内有一致的剪切指向，而陡倾组构没有；褶皱则应被剪切带再褶皱或切截。
:::
