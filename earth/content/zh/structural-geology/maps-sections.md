一张地质图，是关于一个谁也没见过的面的形状的一个假设，而这个假设画在一个人人都能看见的面上。构造地质学中其余的一切——剖面、复原、储量估算、灾害评价——都是从这张图上作出的推断，而推断的好坏只取决于把它画出来的那个几何。本章是这门学科的算术：怎么从三个数里求出一个倾角，怎么从一张图里求出一个厚度，以及怎么画一个不会说谎的剖面。

## 面的几何

::: definition 真倾角、视倾角与走向 {#def-dip}
一个面的**真倾角** $\delta$ 是该面与水平面之间的最大夹角，在一个垂直于**走向**的铅垂面内量得。任何其他铅垂剖面给出的都是一个**视倾角** $\delta_a$，它与真倾角的关系为
$$
\tan\delta_a = \tan\delta\,\cos\beta ,
$$
其中 $\beta$ 是视倾方向与真倾方向在平面上的夹角。因为 $\cos\beta \le 1$，视倾角总是小于或等于真倾角，而真倾角永远无法在一个不垂直于走向的剖面中量得——这就是为什么在公路路堑、峡谷或矿井巷道中量得的倾角是一个下限、而不是一次测量。
:::

::: proposition 三点问题 {#prop-threepoint}
若一个面在三个已知平面坐标与高程的点上被揭露，其倾角与走向就被唯一确定。把该面的高程写成 $h = h_0 + p\,x + q\,y$，$x$ 向东、$y$ 向北，则两个水平梯度 $p$ 与 $q$ 由三个联立方程得出，而
$$
\tan\delta = \sqrt{p^{2} + q^{2}}, \qquad
\text{dip azimuth} = \left(360^\circ + \arctan\frac{-p}{-q}\right) \bmod 360^\circ,
$$
方位自正北顺时针量取，方向为该面下降最陡的方向。
:::

::: example 三口钻井 {#ex-threepoint}
三口钻井在下列位置与高程处钻到一个煤层的顶界：A 在原点，$200\ \mathrm{m}$；B 在 A 正东 $400\ \mathrm{m}$，$160\ \mathrm{m}$；C 在 A 正南 $300\ \mathrm{m}$，$110\ \mathrm{m}$。求真倾角、倾向与走向，以及第四点 D（在 A 以东 $600\ \mathrm{m}$、以北 $500\ \mathrm{m}$）之下该煤层的深度。
::: solution
取 $x$ 向东、$y$ 向北。两个梯度为
$$
p = \frac{160 - 200}{400} = -0.100, \qquad
q = \frac{110 - 200}{-300} = +0.300 .
$$
因此该煤层以每米 0.100 m 向东下降、以每米 0.300 m 向北抬升，所以它向东南倾。真倾角为
$$
\tan\delta = \sqrt{0.100^{2} + 0.300^{2}} = 0.3162 \quad\Longrightarrow\quad \delta = 17.5^\circ,
$$
而倾向有一个 0.100 的向东分量与一个 0.300 的向南分量，所以它位于
$$
\arctan\frac{0.100}{0.300} = 18.4^\circ
$$
即正南偏东：方位为 $180^\circ - 18.4^\circ = 162^\circ$。走向为 $072^\circ$。

对 D 点，该煤层的高程为
$$
h_D = 200 - 0.100\times600 + 0.300\times500 = 200 - 60 + 150 = 290\ \mathrm{m}.
$$
如果 D 点的地面高程为 $250\ \mathrm{m}$，则该煤层在那里**出露于地面之上**——算术发现 D 位于上倾一侧，煤层根本没有被埋藏。

最后一行中有两条教训。三点法对一个平面是精确的、而对任何其他情形则是无声地错误的：如果该煤层被褶皱过，它返回的"倾角"就是那个三角形范围上的平均，而这个三角形应在数据允许的范围内尽可能小。而该方法返回的带符号的答案是有意义的：一个负的深度不是错误而是一个露头，而一张与地形图相交的构造等高线图，会准确地告诉你该层在哪里出露。
:::
:::

::: quiz
一个地层在公路路堑中被量得向东倾 $22^\circ$。该路堑的方位为 N 70° E。关于真倾角你能说什么？
- [ ] 它是向东 $22^\circ$。
- [x] 它至少是 $22^\circ$，而其方向与正东相差不到 $20^\circ$。
- [ ] 它小于 $22^\circ$，因为路堑不垂直于走向。
- [ ] 什么也说不了；视倾角不提供关于真倾角的任何信息。
::: solution
视倾角总是小于或等于真倾角，所以真倾角至少是 $22^\circ$。其方向必须落在剖面方位所允许的范围内：真倾方向垂直于走向，而量得的视倾角把走向限制在路堑方位约 $20^\circ$ 之内，所以倾方向位于正东约 $20^\circ$ 之内。在另一个方位不同的路堑中作第二次测量，或在一个水平面上量一次走向，就能把这个范围收成一个点——这就是为什么一本记满同一条冲沟中所量倾角的野外记录本，远不如同样数量、但来自走向各异的冲沟的倾角有用。
:::
:::

## 由图求厚度

::: example 露头宽度与真厚度 {#ex-thickness}
一个地层倾 $42^\circ$，其在水平地面上的露头带宽 $240\ \mathrm{m}$。求真厚度。同一个带沿一条垂直于走向的路线量得；而如果这条路线以与走向成 $55^\circ$ 的角度横过该带，会量得什么宽度？
::: solution
在水平地面上，露头宽度为 $w = t/\sin\delta$，故
$$
t = w\sin\delta = 240\times\sin42^\circ = 240\times0.669 = 161\ \mathrm{m}.
$$
对一条与走向成 $\alpha$ 角横过该带的路线，量得的宽度是水平宽度除以 $\sin\alpha$：
$$
w' = \frac{t}{\sin\delta\,\sin\alpha} = \frac{161}{0.669\times\sin55^\circ} = \frac{161}{0.669\times0.819} = 294\ \mathrm{m}.
$$
在一个不垂直于走向的路线上，这个带看起来宽了百分之二十二，而这个修正是除以 $\sin\alpha$，很容易被忘记，而当路线趋于平行于走向时它会变得极大。一般的规则是：一个厚度只有在附上产生它的两个角度时才有意义；而最好的厚度测量来自一个垂直于层理钻取的岩心，或来自一个两壁直立且垂直于走向的路堑。
:::
:::

::: example 由两口井求断层距 {#ex-fault-depth}
沿一条垂直于某断层走向的线、相距 $800\ \mathrm{m}$ 的两口钻井都钻到一个煤层顶界。位于上盘一侧的 1 号井，孔口高程 $150\ \mathrm{m}$，在 $220\ \mathrm{m}$ 深处钻到该煤层。位于下盘一侧的 2 号井，孔口高程 $150\ \mathrm{m}$，在 $120\ \mathrm{m}$ 深处钻到该煤层。断层倾 $65^\circ$，煤层则向 2 号井方向倾 $10^\circ$。求铅垂距、落差与净滑距，并说煤层自身的倾角对答案有什么影响。
::: solution
煤层顶界在 1 号井中的高程为 $150 - 220 = -70\ \mathrm{m}$、在 2 号井中为 $150 - 120 = +30\ \mathrm{m}$，所以横过断层的**铅垂距**为 $100\ \mathrm{m}$，上盘一侧下降——一个正断层。

若两口井离断层足够近、以致煤层自身的倾角可以忽略，那么铅垂距就等于**落差**，而沿一个倾 $65^\circ$ 的断层面的净滑距就是
$$
|\mathbf{u}| = \frac{T}{\sin\delta} = \frac{100}{\sin65^\circ} = 110\ \mathrm{m}, \qquad
H = \frac{T}{\tan\delta} = \frac{100}{\tan65^\circ} = 47\ \mathrm{m}.
$$

但两口井相距 $800\ \mathrm{m}$，而煤层倾 $10^\circ$，所以在这段距离上该煤层凭自身倾角就下降了 $800\tan10^\circ = 141\ \mathrm{m}$。这大于观察到的距，意味着原始的 $100\ \mathrm{m}$ **不是**落差：该煤层被自身的倾角降低、又被断层抬高。对倾角作修正之后，真正的铅垂距为
$$
T = 100 + 141 = 241\ \mathrm{m},
$$
而净滑距为 $241/\sin65^\circ = 266\ \mathrm{m}$。

这是地下构造地质学中最常见的一个定量错误，而如果没人问一句控制点相距多远，它是看不见的。规则是：在两点之间量得的距，只有当这两点在同一个层上、且其间的层没有因任何其他原因改变高程时，才是一个落差；修正的办法是把两个交点沿该层自身的倾向投影到断平面上——这恰恰是一张该煤层的构造等高线图会自动做的事，而两口井加一个假设做不到。
:::
:::

::: definition 构造等高线与 V 律 {#def-structure-contour}
**构造等高线**是在一个选定的地质面上高程相等的线，其画法与地形等高线画在地面上完全一样。构造等高线直接给出倾角——倾角就是等高线场的梯度，垂直于等高线、指向高程降低的方向——而它们使一个褶皱或断层的几何无需任何关于露头的假设即可读出。当一个地质界线穿过一条谷地时，**V 律**适用：一个倾斜地层在谷地中出露时形成一个 V，若该层向上游倾、且比谷底更陡，则 V 指向上游；若它向下游倾，则指向下游；若它向上游倾、但比谷底更缓，则以上游的谷坡方向指向上游。这条律是交面几何的一个特例，也是为什么读图者能仅凭一条谷地推断出一个倾向。
:::

::: history
地质图的定量几何是在十九世纪的测绘机构办公室里弄清的，而其经典表述是希尔与贾德学派的野外填图，尤其是希奇科克 1881 年的专著，以及英国地质调查局的实用手册——安德鲁·拉姆塞对不列颠的调查在其中确立了从地面以罗盘测斜仪与平板仪填图的规范。从三口井求一个倾角的问题——"三点问题"——由采矿工程师形式化，他们需要在井筒之间预测一个煤层的位置，这是商业上的需要；而用视倾作图的图解解法在 1890 年代的手册中成了标准。V 律由美国学派以现代表述给出，而面的交线几何则在范贝梅伦与比林斯的教科书中被当作描述几何的一个分支来处理。剖面直到 1980 年代才成为一个严格分析的对象：苏佩、达尔斯特罗姆对加拿大落基山的工作，以及得克萨斯学派的霍萨克与格罗雄的工作，共同认识到一个剖面必须守恒面积与层长，而一个不守恒的剖面不只是不整洁，而是错的。把一个剖面复原到其未变形状态——它使构造解释成为一种可检验的计算——是这一认识的实际成果，而它如今是在开钻之前验证一个地下解释的标准方法。
:::

## 剖面与复原

::: definition 剖面的平衡 {#def-balancing}
一个剖面在同时满足三个条件时是**平衡的**。**线长**平衡：一个层沿其自身表面量得的长度，在复原状态与变形状态中相同，所以该层既不拉伸也不缩短。**面积**平衡：一个岩区的面积守恒，所以不出现空洞也不出现重叠。**深度**平衡：剖面与深部滑脱或基底的几何相容。违反三者之一的剖面未必是错的——它可能记录着平行层面缩短、韧性加厚、或一条尚未填出的断层——它是未完成的，而它不达标的量正是那个缺失过程的度量。
:::

::: example 一个不平衡的剖面 {#ex-balance}
一个横过褶皱–逆冲带的剖面显示，一个原始厚度 $100\ \mathrm{m}$ 的强层，现在垂直于层理量得厚 $88\ \mathrm{m}$；而一个露头带从一个解释的原始宽度 $12\ \mathrm{km}$ 缩短到了 $8\ \mathrm{km}$。请把缩短的两个分量分开。
::: solution
横过该带的**水平**缩短为 $(12 - 8)/12 = 33$ %。该层减薄了 12 %，而如果这个减薄是以等体积的平行层面缩短发生的，那么该层沿其自身长度也缩短了 12 %，所以其复原长度为 $0.88L_0$。

这两个数不是一回事，绝不应相加。褶皱使两点之间的水平距离缩短而不缩短其间的层，所以水平缩短是一个层长因子与一个褶皱因子的乘积：
$$
0.67 = 0.88 \times f \quad\Longrightarrow\quad f = 0.761,
$$
而由褶皱承担的缩短为 $1 - 0.761 = 24$ %。总缩短的三分之一是记录在该层自身中的平行层面缩短，四分之三是记录在其形状中的褶皱。

复原剖面与其变形状态之间任何残余不符，其三种解释是标准的那三种。**平行层面缩短**，发生在褶皱之前或之中，它由层减薄、由一个强标志层的石香肠化、或由一个可测量的平行层理线理的缩短记录下来。**整个剖面的韧性加厚或减薄**，它要求一个体积变化、因而要求物质转移，由压溶缝合线或脉记录下来。**一条未被识别的断层或深部滑脱**，这是最常见的答案，也是需要更深控制才能排除的答案。

这套算术值得仔细做，因为它是一个剖面所仅有的检验。一个平衡的剖面并不是几何正确的证明——几种不同的几何都能平衡——但一个不平衡的剖面则是几何不正确的证明。
:::
:::

::: warning 剖面是一个具有测量地位的诠释
两个地质人员拿到同一张图、同一批井、同一批倾角，会画出不同的剖面，而两者都说得通。原因是剖面是穿过一个三维构造的一个二维切片，而剖面线的选择并不中立：一条垂直于一个走向弯曲了 $30^\circ$ 的构造之区域走向所画的剖面，会显示一个一部分是缩短、一部分是旋转的"缩短"。井是稀疏的，而它们之间的内插是一个带形状的猜测。而每个剖面的深部都是没有约束的：10 km 深处的几何是从 2 km 深处的几何按一条规则——面积守恒、层长守恒、一个铲式剖面——推断的，而那条规则是关于一块谁也没见过的岩石的一个假设。

可辩护的做法是多画几个剖面，有意地改变假设并记录答案移动了多少，并把缩短以一个区间陈述。一个"百分之三十五到五十，取决于下部层组是按平行还是按相似复原"的缩短，是一个比"百分之四十二"更好的数，也是一个同事能够使用的数。
:::

::: summary
- 视倾角总是小于真倾角，而在一个不垂直于走向的剖面中量得的倾角是一个下限。
- 三点确定一个面；两个水平梯度以 $\sqrt{p^2+q^2}$ 给出倾角、并以最陡下降方向给出倾向。
- 露头宽度只有在附上倾角与路线角度时才给出真厚度。
- 构造等高线把一张图变成一个倾角场，并消除露头图案的含混。
- 一个平衡的剖面守恒线长、面积与深度；一个剖面不平衡的量是一个缺失过程的度量。
- 一个剖面是一个诠释，而其答案应作为改变假设所得到的一个区间来引用。
:::

## 练习

::: exercise 视倾角 {level=1 check="20.4"}
一个地层向正东倾 $30^\circ$。一个方位为 N 40° E 的铅垂公路路堑会显示什么视倾角？
::: solution
倾方向为正东、方位 $090^\circ$；路堑方位为 N 40° E、即 $040^\circ$，故 $\beta = 50^\circ$、
$$
\tan\delta_a = \tan30^\circ\cos50^\circ = 0.577\times0.643 = 0.371, \qquad \delta_a = 20.4^\circ .
$$
该路堑显示一个约 $20^\circ$、向东偏南的倾角；而把它记作真倾角的地质人员会把倾角低估三分之一。
:::
:::

::: exercise 露头宽度 {level=1 check="120"}
一个直立的层厚 $120\ \mathrm{m}$。它在水平地面上的露头宽度是多少？
::: solution
对一个直立的层，露头宽度等于真厚度，$120\ \mathrm{m}$，因为 $\sin 90^\circ = 1$。这是露头宽度等于厚度的唯一倾角，这就是为什么直立的层理在图上如此容易识别——也是为什么一条窄、直而持续的露头带是直立层序的经典签名、并如此常被误认为一条断层。
:::
:::

::: exercise 三点问题 {level=2}
三口井分别在 (0, 0) 高程 $300\ \mathrm{m}$、(500, 0) 高程 $260\ \mathrm{m}$、(0, 400) 高程 $380\ \mathrm{m}$ 处钻到一个砂岩顶界，坐标以米的东向与北向计。求倾角与走向。
::: solution
$p = (260-300)/500 = -0.080$、$q = (380-300)/400 = +0.200$。于是 $\tan\delta = \sqrt{0.080^2 + 0.200^2} = 0.2154$，故 $\delta = 12.2^\circ$。该面向东下降、向北抬升，所以它向东南倾，方位为 $180^\circ - \arctan(0.080/0.200) = 180^\circ - 21.8^\circ = 158^\circ$。走向为 $068^\circ$。
:::
:::

::: exercise 构造等高线 {level=2}
在一张断层石灰岩的构造等高线图上，等高线相距 $20\ \mathrm{m}$、在图上相距 $150\ \mathrm{m}$。求倾角。如果同一个面仍以 $20\ \mathrm{m}$ 等值线勾绘、而断层一侧的等高线在图上相距 $40\ \mathrm{m}$，什么改变了？
::: solution
$\tan\delta = 20/150 = 0.133$，故 $\delta = 7.6^\circ$。另一侧 $\tan\delta = 20/40 = 0.500$，故 $\delta = 26.6^\circ$。倾角在断层两侧发生了变化，这意味着要么两个块体绕该断层旋转过——一个带滚动背斜的同生断层——要么该断层把一个较陡的构造与一个较缓的构造拼到了一起。前者靠填绘远离断层的褶皱几何来检验，后者靠找到一次地层重复来检验。
:::
:::

::: exercise 厚度 {level=2 check="95"}
一条垂直于走向的路线横过一个倾 $50^\circ$ 的层，露头宽度 $124\ \mathrm{m}$。求真厚度（以米计）。
::: solution
$t = w\sin\delta = 124\times\sin50^\circ = 124\times0.766 = 95\ \mathrm{m}$。
:::

::: exercise 深度换算 {level=2 check="1800"}
一个来自砂岩底界的地震反射在双程走时 $1.20\ \mathrm{s}$ 到达，而到该层位的层速度为 $3000\ \mathrm{m/s}$。求深度。
::: solution
$z = v t/2 = 3000\times1.20/2 = 1800\ \mathrm{m}$。那个因子二代表往返行程，而忘记它是地下构造地质学中最常见的错误。更大的错误——也是对一个圈闭要紧的错误——是速度：速度上百分之十的误差就是深度上百分之十的误差，而一个浅了 $200\ \mathrm{m}$ 的构造，就能让一次溢出点计算变成一口干井。
:::
:::

::: exercise V 律 {level=2}
一条河向北流，水面坡度为 $3^\circ$。若一个地层 (a) 向北倾 $35^\circ$、(b) 向南倾 $35^\circ$、(c) 水平，其露头各朝什么方向 V？每种情形都假设地层平行于谷轴倾斜。
::: solution
**(a) 向下游（北）。**该层向下游倾、且比谷底更陡，所以其露头随下降而向谷下游迁移。
**(b) 向上游（南）。**该层向上游倾，而在这种情形下无论角度如何，露头总是向上游 V。
**(c) 向上游（南），其张角正等于谷坡。**一个水平的层向上游 V，其夹角的正切等于河流坡度；一个直立的层也是如此。

余下两种情形补全这一组：一个向下游倾、但**比**谷坡**更缓**的层向上游 V；而一个向下游倾、其倾角**恰等于**谷坡的层，会平行于河流出露数公里。这条律不是一个记忆口诀而是一个作图——两个面的交线，而其中一个面你是画得出来的。画出两个横剖面，十秒钟就能解决任何情形，这就是为什么它值得学一次、而不是背六个情形。
:::
:::

::: exercise 剖面平衡 {level=3}
一个复原剖面守恒面积而不守恒线长：一个原本 $5\ \mathrm{km}$ 长的石灰岩层，沿其自身表面量得现在长 $4.0\ \mathrm{km}$，而其厚度未变。需要什么过程？该层必须缩短了多少？缺失的长度去了哪里？
::: solution
该层沿其自身长度缩短了 $(5.0 - 4.0)/5.0 = 20$ %，而其厚度未变，所以这个缩短没有伴随加厚。一个在等厚度、等面积条件下缩短百分之二十的层，必定在**别处加厚了**——整个剖面的面积守恒，所以该石灰岩的缩短已被其上下层组中等量的加厚所承担。

候选者是一个流入褶皱枢纽的韧性层组、一个被挤入翼部的弱层组、或一个被断层切成叠瓦、以致其视厚度是一叠切片的层组。检验是把剖面上每个层组的厚度——复原状态与变形状态的——都量出来，找出获得了该石灰岩所失去面积的那一个。如果没有哪个层组获得面积，那么这个剖面也不守恒面积，而缺失的物质已垂直于剖面流出剖面之外——这是一个三维的陈述，需要一个三维的复原才能检验。
:::
:::

::: exercise 不确定度 {level=3}
一条断层被一口井在 $800\ \mathrm{m}$ 深处揭露，并由一个反射推断在 $1.5\ \mathrm{km}$ 之外位于 $1200\ \mathrm{m}$ 深处。如果该断层是铲式的而不是平面的，那一点的真实深度朝哪个方向偏？一个平面的解释可能错多少？
::: solution
一个铲式断层随深度变平，所以其真实倾角向下减小，而它在给定水平距离处的真实深度**小于**由浅部倾角作平面外推所预测的值。如果平面的解释把它放在 $1200\ \mathrm{m}$、而真实剖面是铲式的，该断层可能在 $900$–$1000\ \mathrm{m}$——误差 $200$–$300\ \mathrm{m}$，即百分之二十。

这个误差的大小由几何得出。一个从 $800\ \mathrm{m}$ 处的 $60^\circ$ 变平到 $1500\ \mathrm{m}$ 处 $30^\circ$ 的铲式剖面，在 $1.5\ \mathrm{km}$ 的水平距离上有一个约 $45^\circ$ 的平均倾角，而不是平面拟合会采用的恒定 $60^\circ$，而深度比为 $\tan45^\circ/\tan60^\circ = 0.577$。实际的后果是：一口按铲式正断层的平面解释布置的井会**太深、且过于深入下盘**，这正是勘探井错过滚动背斜圈闭上倾角隅的经典原因。补救办法是从一开始就把该断层解释为铲式的，把每一个反射与每一口井都用作对曲率的约束，并把深度作为一个以平面与铲式两个端元为界的区间来引用。
:::
