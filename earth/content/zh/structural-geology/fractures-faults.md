地壳上部的几乎所有伸展、以及其缩短的很大一部分，都由破裂来承担。断层在野外既是显而易见的、又是最容易被误读的构造：显而易见，因为它把本应相距一公里的两种岩石放到了一起；容易被误读，因为一个断层面是一份重写本，其上的擦痕线记录的是最后一次滑动、而不是第一次，也不一定是主要的那一次。本章讲的是破裂的几何——破裂如何形成、如何排布、移动多少，以及在上一章的应力场与摩擦定律之下它们被允许是什么样子。

## 节理与张性破裂

::: definition 破裂、节理与断层 {#def-fracture}
**破裂**是一个其上没有显著剪切位移的面；**节理**是一种两壁沿垂直于破裂面的方向张开的破裂，因而是一个张性破裂。**断层**是一个其上发生了可测量平行位移的破裂。节理在最小子主应力变为张力时形成——在地质学以压缩为正的符号约定下即 $\sigma_3 < 0$——并垂直于 $\sigma_3$ 张开；因此一组平行节理记录着最大缩短的方向，这就是为什么节理的产状在沉积盆地中被用作古应力指标。
:::

::: proposition 节理间距与层厚 {#prop-joint-spacing}
在一个层序中，若节理只在厚度为 $h$、被较弱层夹持的一个强层中形成，则节理间距 $s$ 随时间增长，直到达到一个**饱和间距**
$$
s_\text{sat} \approx 2c ,
$$
其中 $c$ 是节理尖端处破裂过程区的半长。经验上 $c \approx 0.05$–$0.15\,h$，所以饱和间距为 $s_\text{sat} \approx 0.1$–$0.3\,h$；每层的节理数目不断增加，直到间距降到层厚的零点几倍，此后新的节理便无法再形核。
:::

::: example 读一个石灰岩 {#ex-joints}
一个页岩层序中一层 $40\ \mathrm{cm}$ 厚的石灰岩含有平均间距 $8\ \mathrm{cm}$ 的节理。相邻 $12\ \mathrm{cm}$ 厚的石灰岩层的节理间距为 $2.5\ \mathrm{cm}$。这组破裂是否与层厚有关？这对节理形成的时间说了什么？
::: solution
比值为厚层的 $s/h = 8/40 = 0.20$、薄层的 $2.5/12 = 0.21$。两者在百分之五以内相同，这正是**层控的、饱和间距的**节理的经典签名：节理在间距达到层厚约五分之一时停止了形核，所以这组节理是"成熟的"、或在破裂组发育的分级中属于二级。

成因的解读随之而来。因为间距由层厚而不是由应力决定，这组节理就不能用来把变形容某一次褶皱事件定年——一组达到饱和的节理，无论造成它的应力是什么，看起来都一样，只要那个应力足以使该层破裂。这组节理*确实*记录的是其方位，即垂直于缩短方向；以及节理被限制在层内而不穿过页岩这一事实，这意味着它们形成于层理被断层破坏之前、形成于该序列被深埋之前——能穿过层理传播的节理指示一个大得多的破裂过程区与一个大得多的驱动力，是构造的或超压驱动的破裂的典型特征。
:::
:::

## 断层的几何与术语

::: definition 断层的术语 {#def-fault-terms}
**上盘**是断层面之上的块体，**下盘**是其下的块体。**位移矢量** $\mathbf{u}$ 连接原先相邻的两点；其**倾向滑动分量**是**落差**，其**走向滑动分量**是**平错**。若上盘相对于下盘向下移动，滑动是**正断**的；若向上移动，是**逆冲**的；而逆断层的倾角小于约 $45^\circ$ 时称为**逆掩**。一条**铲式**断层随深度变平；一个**坡–坪式**断层则以切穿层理的陡段与沿层理的平段相间。一点的**滑动方向**由擦痕线给出，**滑动指向**则由擦痕阶步、矿物纤维以及一个标志层的错动给出。
:::

::: example 落差、平错与净滑距 {#ex-throw}
一条断层走向 $000^\circ$、向东倾 $60^\circ$。一个曾经连续的标志层在一条水平坑道中被错断：上盘一侧的层比下盘一侧低 $40\ \mathrm{m}$，两个切点之间沿垂直于断层走向水平量得 $25\ \mathrm{m}$。求落差、平错、净滑距，以及位移矢量的伏卧角。
::: solution
一个水平层被断层错开的垂直距就是**落差**，故 $T = 40\ \mathrm{m}$。垂直于走向的水平距是**平错**，$H = 25\ \mathrm{m}$，净滑距为
$$
|\mathbf{u}| = \sqrt{T^2 + H^2} = \sqrt{1600 + 625} = 47.2\ \mathrm{m}.
$$
位移矢量在断层面内、自水平量起的伏卧角为
$$
\psi = \arctan\frac{T}{H} = \arctan\frac{40}{25} = 58.0^\circ .
$$
在一个倾角 $60^\circ$ 的断层上，$58^\circ$ 的伏卧角接近倾向滑动；而其方向——上盘下降——使它成为一个带少量走滑分量的**正断层**。这套算术值得练习，因为它恰恰就是地质人员在坑道、矿井或公路路堑中所做的事；而且只有当两个切点在*同一个*标志层上、且断层滑动是一个单一矢量时，答案才是净滑距——在不同高度再找一个标志层，是标准的检验。
:::
:::

::: definition 位移–长度标度 {#def-dl}
在九个长度数量级之上，成熟的断层服从最大位移与总长度之间一个惊人紧密的线性关系，
$$
D_\text{max} \approx 0.01\,L ,
$$
即位移–长度比约百分之一。这个关系对实验室样品、矿井尺度的断层、出露的断层带与一级地壳剪切带都成立，而它是构造地质学最接近于一条标度律的东西。
:::

::: example 这条断层有多长？ {#ex-dl-use}
一条断层以最大 $320\ \mathrm{m}$ 的位移错断了一个标志层。估计它的长度，并解释为什么对一个已停止生长的断层这个估计比对一个仍在活动的断层更好。
::: solution
$L = D_\text{max}/0.01 = 32\,000\ \mathrm{m} = 32\ \mathrm{km}$。

这个估计之所以有效，是因为一个已经走到生命终点的断层，已沿一个不再增长的距离积累了位移，其比值稳定在特征值上。一个仍在扩展的断层，其长度在早期比位移增长得更快，所以年轻的活断层的 $D/L$ 比值远低于百分之一——瓦萨奇断层与东非边界断层的长度都远长于其位移所预测的值，这也是认出它们尚有大量剩余滑动量的一种办法。这个关系还是一个很好的对比检验：如果被认为是一条断层的两段给出差别很大的比值，它们很可能是两条断层。
:::
:::

::: widget plot
f: 0.01*x
x: 0, 100
y: 0, 1.2
labels: D = 0.01L
caption: 最大位移对断层长度的关系 $D_\text{max} = 0.01L$，长度以公里计、位移以米计。这条直线正是其惊人之处：从公路路堑中一米长的断层，到地震剖面上百公里长的断层，都落在它上面，这意味着断层生长是**自相似的**——一个滑动量大千倍的断层就长千倍，而其上位移剖面的形状并不改变。偏离这条线的地方才是有意思的观察：一条在线之下的断层，要么年轻而仍在扩展，要么由若干未连接的段组成；一条在线之上的断层则被重新活化过，或者其位移被一个相邻的构造吸收了。
:::

::: quiz
一条断层走向 $090^\circ$、向北倾 $60^\circ$。当前的最大水平压应力方位为 $000^\circ$。它的滑动倾向是什么？
- [ ] 很高，因为它陡倾，而陡断层容易滑动。
- [x] 为零，因为断层面包含 $\sigma_1$ 方向。
- [ ] 中等，因为断层走向与 $\sigma_H$ 之间的角是 $90^\circ$。
- [ ] 没有摩擦系数就无法确定。
::: solution
应力 $\sigma_1$ 是水平的、方位 $000^\circ$；断层走向 $090^\circ$、向北倾 $60^\circ$，所以断层面包含一条方位 $090^\circ$ 的水平线与一条向北倾斜的线——而方位为正北、水平的 $\sigma_1$ 就在那个面内。一个位于断层面内的主应力不会在其上产生剪面力，所以 $\tau = 0$、$T_s = 0$，与摩擦无关。摩擦系数决定的是一个滑动倾向非零的断层会不会滑动；它无法凭空创造出滑动倾向。
:::
:::

## 与断层相关的褶皱

::: definition 断坡褶皱 {#def-fbf}
一个**断坡褶皱**（苏佩褶皱）形成于上盘截线从一个坪转入一个坡之处。因为平行于断层的位移沿断层是恒定的，断层倾角的变化便迫使上盘褶皱；而褶皱随上盘被搬运过这个坡而生长。对一个倾角为 $\delta$、高度为 $h$ 的坡，平行断层的位移 $D$ 产生落差
$$
T = D\sin\delta, \qquad H = D\cos\delta,
$$
所得背斜–向斜对的波长为 $\lambda = 2h/\tan\delta$。
:::

::: example 逆冲带中的一个坡 {#ex-fbf}
一条逆冲断层在 $2\ \mathrm{km}$ 深度沿一个页岩铺成坪，然后以 $30^\circ$ 上坡到 $2.5\ \mathrm{km}$ 的另一个页岩。求把上盘完全送上这个坡所需的位移、上盘水平移动的距离，以及褶皱的波长。
::: solution
坡高为 $h = 500\ \mathrm{m}$、倾角 $\delta = 30^\circ$，故
$$
D = \frac{h}{\sin\delta} = \frac{500}{0.500} = 1000\ \mathrm{m}, \qquad
H = D\cos\delta = 1000\times0.866 = 866\ \mathrm{m},
$$
而
$$
\lambda = \frac{2h}{\tan\delta} = \frac{1000}{0.577} = 1730\ \mathrm{m}.
$$
一公里的断层滑动造成一个 $1.7\ \mathrm{km}$ 宽、$500\ \mathrm{m}$ 起伏的背斜。这个几何就是逆冲带之所以是那个样子的原因：褶皱不是独立的构造，而是上盘对之下断层形状变化的回应；而它们的波长告诉你坡高，因而告诉你被切穿的、在地表本来看不见的地层的厚度。在加拿大落基山与汝拉山，这个关系被用于在没有地下控制的地方建造剖面；而剖面的闭合——要求复原之后上盘与下盘的截线相互匹配——正是几何正确的检验。
:::
:::

## 走滑系统

::: definition 里德尔剪切与走滑带的几何 {#def-riedel}
在一个走滑带的实验室模拟中，或在其脆性的上部，会形成一组特征性破裂，它们与主断层呈固定角度：**里德尔剪切** $R$ 在 $10^\circ$–$20^\circ$、与主断层同向；**共轭里德尔剪切** $R'$ 在约 $75^\circ$、反向；**张节理** $T$ 在约 $45^\circ$；以及 **Y 剪切**在 $0^\circ$、平行于断层。这些角度由内摩擦角通过 $\theta = 45^\circ - \varphi/2$ 决定，而整个图案随剪切指向旋转，从而使一个定向的手标本成为一种剪切指向标志。
:::

::: example 拉分与阶区 {#ex-pullapart}
两条重叠的走滑段各长 $12\ \mathrm{km}$，向右阶列 $3\ \mathrm{km}$、重叠 $9\ \mathrm{km}$。若断层是右行的，重叠区中会形成什么构造？若是左行的呢？
::: solution
右行断层上的右阶是一个**挤压性**（汇聚的）几何，重叠区是一个**正阶区**，产生压扭：隆起、挤压与一个挤压弯，而不是盆地。沉降的情形相反——左行断层上的右阶，或右行断层上的左阶——它会在两个断层尖端之间张开一个**拉分盆地**。

对拉分盆地而言，盆地的深度是边界阶上落差的一个分数。阶宽 $3\ \mathrm{km}$、位移–长度比为百分之一时，每段近其尖端的位移量级为 $0.01\times12/2 = 60\ \mathrm{m}$ 的走滑，其在阶上的分量为 $60\sin\alpha$，$\alpha$ 为断层与阶之间的夹角；$\alpha = 45^\circ$ 时就是 $42\ \mathrm{m}$ 的张性落差，再加上若干这样的增量与边界支上的正断层作用，一个几百米到一公里深的盆地是很典型的。萨尔顿海、死海、日本海与鲜水河断层后侧的盆地都是拉分盆地，而它们的沉积厚度记录着那条贯通断层的累积滑动量——这使得它们成为少数几个可以直接从岩心中读出一个走滑系统滑动历史的地点。
:::
:::

::: history
吉尔伯特在 1877 年定下了这个纲领：当时他把盆岭读作水平伸展的产物，并命名了地垒与地堑；1904 年他又把博尔德砾岩的倒转层描述为一次逆冲的记录。埃蒙斯，以及尤其是范海斯（Van Hise），把断层力学讲明确了：范海斯 1896 年的《论断层作用定律》从一个应力场导出预期的滑动方向，然后拿弗吉尼亚蓝岭的断层来检验，发现压缩理论失败、而重力与伸展占了上风——这是野外检验推翻一个受宠模型的一个早期而戏剧性的例子。伸展区正断层的几何由内华达学派与弗格森弄清，而按倾角与滑动指向对断层类型的分类在此后数十年间被标准化。阿尔卑斯与落基山逆冲构造的复兴，以及加拿大落基山证明薄皮逆冲骑在滑脱断层之上，使断坡与断扩展的几何成为必需；苏佩（Suppe）在 1983 年的一系列论文中给出了它们，把剖面平衡从一门手艺变成了一种算术。走滑几何的现代形式，要归功于钱伯斯与特维斯的模拟实验、继承自理德尔 1929 年关于黏土中断层作用的里德尔剪切分析，以及克里斯蒂–布利克与比德尔 1985 年关于走滑阶列的综合——后者把拉分盆地与挤压弯变成了勘探目标。普莱斯 1960 年代关于节理间距的工作，与海姆森、波拉德与塞加尔 1970 年代的破裂力学模型，把节理阵变成了古应力工具；而 1980 年代由沃特森、戈索普、肖尔茨等人的工作给出的位移–长度标度，则给了构造地质学它唯一一条稳健的经验定律。
:::

## 哪些断层会动？

::: proposition 滑动倾向 {#prop-sliptendency}
对一个其法线与 $\sigma_1$ 成 $\theta$ 角的断层，其正面力与剪面力为
$$
\sigma_n = \sigma_1\cos^{2}\theta + \sigma_3\sin^{2}\theta, \qquad
\tau = (\sigma_1-\sigma_3)\sin\theta\cos\theta,
$$
而**滑动倾向**为
$$
T_s = \frac{\tau}{\sigma_n} = \frac{(\sigma_1-\sigma_3)\sin\theta\cos\theta}{\sigma_1\cos^{2}\theta + \sigma_3\sin^{2}\theta} .
$$
它在 $\tan^{2}\theta = \sigma_3/\sigma_1$ 处取最大值，
$$
T_{s,\max} = \frac{\sigma_1-\sigma_3}{2\sqrt{\sigma_1\sigma_3}} .
$$
一个断层在 $T_s$ 达到摩擦系数 $\mu$ 时重新活化。
:::

::: example 这条断层会滑动吗？ {#ex-sliptendency}
应力场为 $\sigma_1 = 200\ \mathrm{MPa}$、$\sigma_3 = 50\ \mathrm{MPa}$，一个先存断层的摩擦系数为 $\mu = 0.6$。求最大滑动倾向、它发生在什么产状上，以及断层是否会滑动。然后判断一条走向平行于 $\sigma_1$ 的断层究竟能不能滑动。
::: solution
$$
T_{s,\max} = \frac{200-50}{2\sqrt{200\times50}} = \frac{150}{2\times100} = 0.75 .
$$
最优产状为 $\tan^{2}\theta = 50/200 = 0.25$，故断层的**法线**与 $\sigma_1$ 之间为 $\theta = 26.6^\circ$，也就是说断层面与 $\sigma_1$ 成 $63.4^\circ$——等价地说，断层面与 $\sigma_1$ 之间为 $26.6^\circ$，与安德森理论预测的那个约 $30^\circ$ 角相同。

因为 $T_{s,\max} = 0.75 > \mu = 0.6$，一个产状有利的断层**会**滑动。一条走向平行于 $\sigma_1$ 的断层，其断层面包含 $\sigma_1$；此处把 $\theta$ 取为法线与 $\sigma_1$ 之间的角，这样的断层便有 $\theta = 90^\circ$，故 $\tau = (\sigma_1-\sigma_3)\times1\times0 = 0$、$T_s = 0$。**没有滑动倾向，就没有滑动**，应力有多大都一样。这是勘探与灾害评价中最有用的单个结果：一个断层相对于当前应力场的产状决定了它是否是活动的；而一张满是第四纪断层的图上，可能既有若干条当前锁住的，也有若干条看似无辜而实则不然的。
:::
:::

::: warning 一张断层图不是一张灾害图
地表有一个年轻断层是过去滑动的证据，而没有断层并不是未来不会滑动的证据。三种效应合谋。断层不会沿其隐伏尖端的全长错断，而一条从未错断到地表的断层——盲逆冲断层——能产生一次大地震，如 1994 年的北岭与 1999 年的伊兹米特。断层陡坎被侵蚀抹除的速率，在湿润气候下超过由滑动形成它们的速率，所以一个景观可能对对一个每几千年滑动一次的断层毫无痕迹。而应力场随时间旋转：今天产状最优的断层在一百万年前可能是锁住的，反之亦然，这就是为什么西盆岭、阿尔卑斯与喜马拉雅都含有这样一些断层群：其当前滑动速率与其累积位移不相符。站得住的说法是关于滑动的**速率**、以及一个特定段在一个特定区间内破裂的**概率**，而两者都来自地质学、大地测量学与地震学的结合，而不是单凭一张野外图。
:::

- 落差与平错给出净滑距；断层的命名依据上盘相对于下盘的运动。
- 位移–长度比约百分之一，在九个数量级上成立，是构造地质学最接近标度律的关系。
- 断坡褶皱是上盘对断坡形状变化的回应，其波长给出坡高与被切穿的地层厚度。
- 走滑带发育里德尔剪切、张节理与 Y 剪切；阶列的几何决定那里是拉分盆地还是挤压弯。
- 滑动倾向 $T_s = \tau/\sigma_n$ 决定一个先存断层会不会动；平行于 $\sigma_1$ 走向的断层滑动倾向为零。
- 一张断层图不是一张灾害图：盲断层、被抹除的陡坎与旋转的应力场三者合谋。
:::

## 练习

::: exercise 断层分类 {level=1}
试分类：(a) 一个倾 $45^\circ$、上盘向上的断层；(b) 一个倾 $70^\circ$、上盘向下的断层；(c) 一个倾 $15^\circ$、上盘向上的断层。
::: solution
(a) 一个**逆**断层。(b) 一个**正**断层。(c) 一个**逆掩**断层——一个低角度的逆断层，而如果它沿一个页岩或蒸发岩铺展，具体就是一个薄皮滑脱。倾角的界限只是约定，但逆与逆掩之间那条 $45^\circ$ 线是力学上要紧的那条，因为一个倾角小于约 $30^\circ$ 的断层，在垂直的 $\sigma_1$ 之下，若没有一个反常低的摩擦系数或一个反常高的孔隙压力，就无法靠摩擦滑动。
:::
:::

::: exercise 落差与平错 {level=1 check="50"}
一个断层的落差为 $30\ \mathrm{m}$、平错为 $40\ \mathrm{m}$。净滑距是多少？
::: solution
$|\mathbf{u}| = \sqrt{30^2 + 40^2} = 50\ \mathrm{m}$，伏卧角为 $\arctan(30/40) = 36.9^\circ$。
:::
:::

::: exercise 节理间距 {level=1 check="0.2"}
一层 $25\ \mathrm{cm}$ 的砂岩有间距 $5\ \mathrm{cm}$ 的节理。给出 $s/h$，并说这组节理是否已达饱和。
::: solution
$s/h = 5/25 = 0.20$，正落在 $0.1$–$0.3$ 的饱和区间之内。这组节理已停止形核新的节理，而其间距记录的是层厚而不是应力。
:::
:::

::: exercise 位移–长度 {level=2 check="18"}
一条断层长 $1.8\ \mathrm{km}$。以米估计其最大位移。
::: solution
$D_\text{max} = 0.01\times1800 = 18\ \mathrm{m}$。若实测位移是 $60\ \mathrm{m}$，则该断层要么被重新活化过，要么其位移与一个平行构造共享，要么那两个端点并不是它真正的尖端。
:::
:::

::: exercise 断坡褶皱 {level=2 check="946"}
一个逆冲坡倾 $25^\circ$、高 $400\ \mathrm{m}$。求把上盘送过它所需的断层位移（以米计），以及上盘水平移动的距离。
::: solution
沿断层 $D = h/\sin\delta = 400/\sin25^\circ = 400/0.4226 = 946\ \mathrm{m}$，水平 $H = h/\tan25^\circ = 400/0.4663 = 858\ \mathrm{m}$。两者相差百分之十，而把二者混淆是建造剖面时的一种标准错误：位移是沿断层面量的，而横过该带的缩短是水平量的。
:::
:::

::: exercise 滑动倾向 {level=2 check="0.35"}
在 $\sigma_1 = 150$、$\sigma_3 = 75\ \mathrm{MPa}$ 下，求最大滑动倾向。
::: solution
$T_{s,\max} = (150-75)/(2\sqrt{150\times75}) = 75/(2\times106.1) = 0.354$。在 $\mu = 0.6$ 时，这个应力场中没有任何产状有利的断层能滑动，这就是所谓地壳"未处于临界应力状态"的含义。$\mu = 0.6$ 时的摩擦破裂要求 $\sigma_1/\sigma_3 \approx 3.1$，所以在 $\sigma_3 = 75\ \mathrm{MPa}$ 时，最大主应力须达到约 $235\ \mathrm{MPa}$——差应力 $160\ \mathrm{MPa}$，是当前值的两倍多——才会有任何断层滑动。
:::
:::

::: exercise 里德尔几何 {level=2}
在一个右行走滑带中，里德尔剪切、共轭里德尔剪切与张节理在与主断层成什么方位角上形成？左行滑动时这个图案如何改变？
::: solution
里德尔剪切 $R$ 在与主断层成 $10^\circ$–$20^\circ$、具同向错距处形成；共轭里德尔剪切 $R'$ 在约 $75^\circ$、反向；张节理 $T$ 在约 $45^\circ$；Y 剪切则平行于断层。左行滑动时整个图案被镜像：一条近南北断层上右行滑动时方位为 $015^\circ$ 的 $R$ 剪切，在左行滑动时方位变为 $345^\circ$。有诊断意义的一点在于：$R$ 剪切数量上远远占优，而它们**雁行式叠覆**，留下一个为张节理而张开的阶列；因此手标本中叠覆处的几何，不需要任何标志就能给出剪切指向。
:::
:::

::: exercise 一个盲断层 {level=3}
一个地震反射剖面上显示一条逆冲断层在 $6\ \mathrm{km}$ 深度铺平成一个滑脱、并不到达地表，而其上覆序列褶皱成一个 $4\ \mathrm{km}$ 宽的背斜，地表有 $300\ \mathrm{m}$ 的起伏。解释这个几何，估计滑脱上的滑动量，并说这个构造为什么是危险的。
::: solution
这是一个带断扩展褶皱的**盲逆冲**：断层向上消失于褶皱的层中，褶皱随断层滑动而生长，而褶皱的波长由滑脱的深度与力学地层决定，而不是由一个断坡决定。把褶皱波长取为 $\lambda \approx 2h/\tan\delta$、$h = 6\ \mathrm{km}$、有效倾角 $30^\circ$，得 $\lambda \approx 21\ \mathrm{km}$，远大于观察到的 $4\ \mathrm{km}$，所以这个褶皱不是一个简单的断坡褶皱；一个在 $6\ \mathrm{km}$ 深滑脱之上、波长 $4\ \mathrm{km}$ 的断扩展褶皱，要么需要一个陡得多的断层，要么需要独立控制波长的力学成层。

滑脱上的滑动量由横过背斜的缩短得出：对一个起伏 $300\ \mathrm{m}$、波长 $4\ \mathrm{km}$ 的紧闭褶皱，其量级为几百米。危险在于这个构造没有地表显示：没有陡坎可填图，没有断层可布探槽，也没有地表错断的历史记录，所以标准的概率地震危险性图——它是从填出的断层建造的——给它一个很低的权重。1994 年的北岭与 1987 的惠蒂尔–贝克的两次地震都发生在洛杉矶之下的盲逆冲上，两者都在一个其地震危险性评价建立在断层图之上的城市里造成了数十亿美元的损失。
:::
:::

::: exercise 复原 {level=3}
一个横过逆冲带的剖面显示三个叠瓦逆冲片，每个都有一个倾 $30^\circ$、高 $300\ \mathrm{m}$ 的坡，而按一个复原的层面量得的总缩短为 $4\ \mathrm{km}$。若每个片的坡贡献相同的位移，求每条逆冲断层上的位移与已得到解释的总水平收缩量。这个剖面平衡吗？
::: solution
每个坡需要一个断层位移 $D = h/\sin30^\circ = 300/0.5 = 600\ \mathrm{m}$，其水平分量为 $H = h/\tan30^\circ = 520\ \mathrm{m}$。三条逆冲断层因此解释了 $3\times520 = 1560\ \mathrm{m}$ 的水平收缩，而观察值为 $4000\ \mathrm{m}$。

这个剖面**不平衡**：$2.4\ \mathrm{km}$ 的缩短没有着落。可能的情况有：剖面上未见到的第四条更深的逆冲断层；一个在最深控制之下穿过地层的底部滑脱；由平行层面缩短造成的褶皱（这需要平行层理的断层或可测量的层厚变化）；或者下地壳的韧性加厚。检验就是去找每一种情形各自的诊断证据：深部重复的地层序列、横过该带的层厚变化、或下部剖面中的一片叶理。一个不平衡的剖面并不错，但它是未完成的，而缺失的那部分缩短总是在某处——这就是剖面必须既守恒面积、又守恒长度这条规则的内容。
:::
:::
