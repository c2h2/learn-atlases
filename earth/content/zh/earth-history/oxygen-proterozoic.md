二十亿年里海洋是绿褐色的、天空是一种暗淡的粉橙色，而没有任何呼吸氧的东西存在。然后，在$2.45\ \mathrm{Ga}$一个地质学瞬间，硫同位素记录切换了，第一批红层出现，铀与黄铁矿的碎屑颗粒不再能在搬运中幸存，而大气变成了氧化性的。负有责任的生物已经干了至少十亿年、很可能二十亿年：蓝细菌，其产氧光合作用一直在排出一个废气，而地球的化学以它产生的同样快的速度把它吸收掉，直到汇被填满、气体开始积累。

这个事件被称为大氧化，而它是自海洋凝聚以来地球表面环境最重要的化学变化。它造成了第一次大灭绝，被氧毒死的厌氧生命的大灭绝；它造成了第一次雪球地球，通过摧毁那个曾把一个暗淡的太阳暖起来的甲烷；它使真核生物、多细胞生物与动物成为可能，而它们三者，就其朴素的物理意义而言，都是利用氧的高氧化还原电位的机器；而它留下了一个矿床——条带状铁建造——供应着世界钢的大部分。本章讲为什么它花了这么久，我们如何把时间知道到几千万年以内，以及元古宙那二十亿年拿这个新大气做了什么。

## 为什么氧二十亿年都没有积累

::: definition 源与汇 {#def-o2-budget}
大气氧是一个由净通量维持的**不平衡**。源是还原碳的埋藏（未被呼吸的光合作用）、黄铁矿的埋藏（它埋掉还原硫而不是氧化它）、以及氢逃逸到太空。汇是地表岩石的氧化——铁的、硫的、其内碳的——火山与热液气体（$\mathrm{H_2}$、$\mathrm{H_2S}$、$\mathrm{SO_2}$、$\mathrm{CH_4}$、$\mathrm{CO}$）的、以及溶在海洋里的还原种的。在现代海洋里净埋藏通量约为$1\times10^{13}\ \mathrm{mol\ O_2\ yr^{-1}}$、而火山与地壳的汇约为$8\times10^{12}$，所以维持$21\%$氧的那个余量只有大约二倍的因子。
:::

::: proposition 氧只在汇被填满或缩小时积累，不在源上升时积累 {#prop-why-lag}
太古宙海洋与地壳是巨大的还原剂库，而还原气体的火山通量是现代值的几倍，因为地幔更热、地壳更多基性。一个翻倍的源在汇也翻倍时什么也不改变。地质证据是太古宙产生过氧——蓝细菌与有机碳埋藏的同位素与生物标志物证据老于$2.7\ \mathrm{Ga}$——而氧只是没有积累，因为汇比源大几倍的因子。在$2.45\ \mathrm{Ga}$改变的是平衡：地壳已成熟为一个花岗质的、较不可氧化的成分；克拉通之间盆地里陆地区域与有机碳的埋藏已经增长；而海洋溶解二价铁的库存正在被抽干。
:::

::: example 氧库有多大，它多快周转？ {#ex-o2-residence}
大气质量为$5.15\times10^{18}\ \mathrm{kg}$、平均摩尔质量为$0.029\ \mathrm{kg\,mol^{-1}}$、按体积$21\%$是氧。全球有机碳的净埋藏是$1\times10^{13}\ \mathrm{mol\ C\ yr^{-1}}$，而光合作用每埋藏一摩尔碳大约产生一摩尔$\mathrm{O_2}$。求大气氧库的大小与其停留时间。
::: solution
$$
n_\text{air} = \frac{5.15\times10^{18}}{0.029} = 1.78\times10^{20}\ \mathrm{mol}, \qquad n_{\mathrm{O_2}} = 0.21\times1.78\times10^{20} = 3.7\times10^{19}\ \mathrm{mol}.
$$
$$
\tau = \frac{3.7\times10^{19}}{1\times10^{13}} = 3.7\times10^{6}\ \mathrm{yr}.
$$
如果埋藏停止，整个氧大气会在几百万年内被消耗掉。这就是那个论点——氧不是一个有生命的行星的稳定特征、而是它一个持续的、昂贵的产物——的定量形式，而这就是为什么元古宙的氧水平能在几千万年里摆动几个数量级、以及为什么白垩纪海洋能在几十万年里缺氧。

它也给太古宙问题定了界。若汇是现代值的$3\times$，那么源在任何净积累之前就必须是现代的$4\times$，而源受限于可供有机碳埋藏的大陆陆棚面积。
:::
:::

::: example 氧化海洋的铁 {#ex-fe}
假设太古宙深海洋含有$15\ \mu\mathrm{mol\,L^{-1}}$的溶解二价铁，而海洋体积取作$1.3\times10^{18}\ \mathrm{m^3}$。给定$4\mathrm{Fe}^{2+} + \mathrm{O_2} \rightarrow 4\mathrm{Fe}^{3+} + 2\mathrm{H_2O}$，氧化它需要多少氧，而这与$3.7\times10^{19}\ \mathrm{mol}$的现今大气库相比如何？
::: solution
$$
n_\mathrm{Fe} = 1.3\times10^{18}\times10^{3}\times15\times10^{-6} = 2.0\times10^{16}\ \mathrm{mol},
\qquad
n_{\mathrm{O_2}} = \frac{n_\mathrm{Fe}}{4} = 4.9\times10^{15}\ \mathrm{mol},
$$
这是一个现今大气水平的$0.013\%$。即使在$100\ \mu\mathrm{mol\,L^{-1}}$，海洋的铁也只是库的$0.09\%$。

所以海洋的铁从来不是把氧压住的东西，条带状铁建造也不是：把一个富铁海洋的全部铁含量沉淀下来会用掉大气现在持有的氧的千分之一。要紧的汇是**通量**、不是库——来自地幔的、以及来自一个基性地壳风化的$\mathrm{H_2}$、$\mathrm{CH_4}$、$\mathrm{H_2S}$与还原铁的连续供给，Holland算出它是现代值的几倍。这是整个题目里最被误解的一点，而这就是为什么氧的上升是一个关于地球内部与大陆生长的故事、不是关于光合作用的发明。
:::
:::

## 给上升定年：五个一致的指标

大氧化不是由一个测量、而是由五个独立的测量定年的，而它们全都在$2.50$–$2.45\ \mathrm{Ga}$这个间隔内改变：

1. **非质量依赖硫同位素**（$\Delta^{33}\mathrm{S} \ne 0$）在$2.45\ \mathrm{Ga}$消失，这需要一个臭氧层、因此需要高于现今约$10^{-5}$的氧。
2. **碎屑铀石与黄铁矿**颗粒，它们在氧化性水中不能在搬运中幸存，在约$2.4\ \mathrm{Ga}$从古砂岩中消失。
3. **红层**——被赤铁矿、而不是被绿色绿泥石与黄铁矿胶结的砂岩——第一次出现在约$2.4\ \mathrm{Ga}$，尽管它们在又一个十亿年里仍然稀少。
4. 需要氧化Mn(II)的那类**锰矿沉积**出现在$2.3\ \mathrm{Ga}$，而大的出现在$2.2\ \mathrm{Ga}$（Kalahari锰矿田）。
5. **铬同位素**（$\delta^{53}\mathrm{Cr}$）变为正，这需要Cr(VI)、这需要一个氧化性的地表风化环境；这个漂移约在$2.8\ \mathrm{Ga}$开始、在$1.9\ \mathrm{Ga}$达到峰值、而它是那个暗示硫信号之前有氧的指标。

::: theorem 碳同位素质量平衡测量有机碳埋藏 {#thm-d13c}
海相碳酸盐以溶解无机碳的碳同位素组成$\delta^{13}\mathrm{C}_\text{DIC}$沉淀，而光合有机质因Rubisco对$^{13}\mathrm{C}$的判别而亏损约$25\%$。若进入海洋-沉积系统的碳有一个分数$f$作为有机质被埋藏，则
$$
\delta^{13}\mathrm{C}_\text{carb} = \delta^{13}\mathrm{C}_\text{DIC} + f\times\Delta,
$$
其中$\Delta \approx 25\%$是分馏，所以碳酸盐$\delta^{13}\mathrm{C}$的一个正漂移是有机碳埋藏增加的直接度量——因此也是一个氧的净源的度量。
:::

::: proof
沉积汇的同位素质量平衡是
$$
\delta_\text{DIC} = f\,\delta_\text{org} + (1-f)\,\delta_\text{carb},
$$
因为离开海洋的碳在两个汇之间分配。把$\delta_\text{org} = \delta_\text{carb} - \Delta$代入并整理，
$$
\delta_\text{DIC} = \delta_\text{carb} - f\Delta \Longrightarrow \delta_\text{carb} = \delta_\text{DIC} + f\Delta .
$$
取$\Delta = 25\%$、$f$在$0.1$–$0.3$范围，$f$从$0.2$翻倍到$0.4$使$\delta^{13}\mathrm{C}_\text{carb}$上升$5\%$，而这正是元古宙最大漂移的大小。赞比亚的Lomagundo-Jatuli碳酸盐，在$2.22$–$2.10\ \mathrm{Ga}$，记录了一个从$+1\%$到$+9\%$、持续$100\ \mathrm{Myr}$的上升，是地球历史里最长、也是最大的碳同位素异常之一，而其解释——一次有机碳埋藏、因此也是氧生产的大脉冲——被同时沉积的黑色页岩的钼与铀同位素记录证实。∎
:::

## 真核生物，以及能量论证

::: example 变大的能量代价 {#ex-eukaryote-energy}
一个需氧细菌以受其表面积体积比限制的速率呼吸；一个同体积的真核细胞含有线粒体，每个线粒体都是一个内化的、有其自身膜表面的细菌。取一个半径$1\ \mu\mathrm{m}$、呼吸$10^{-17}\ \mathrm{W}$的细菌，以及一个半径$10\ \mu\mathrm{m}$的真核生物。若这个真核生物是一个单一的有膜细胞、其呼吸受其自身表面积限制，它的呼吸会以什么倍数超过细菌的？而它的体积——因此其需求——会以什么倍数超过？
::: solution
面积按半径的平方缩放，所以一个大$10\times$的细胞有$100\times$的膜，而如果呼吸受膜限制，有$100\times$的呼吸。体积按立方缩放，所以它需要$1000\times$的能量。一个这个尺寸的单细胞生物因此在能量上短缺十倍。

生命找到的解是把呼吸膜内化：一个有$10^3$个线粒体的真核生物在同一个细胞内有$10^3$倍的细菌膜，而负担得起大$1000\times$。这是Nick Lane与Martin那个论点——真核生物的起源是一个**能量**事件、不是遗传事件——的定量内容，而线粒体的内共生——它提供了有其自身基因组、其自身控制的内部膜——是使地球保持微生物状态二十亿年的那个唯一瓶颈。在这个观点下，这个延迟不是化学的一个偶然、而是一个组合上的不可能：这个事件需要一个古菌吞下一个细菌而两者都活下来，而它恰好发生过一次。
:::
:::

真核生物的化石证据从有争议的$2.1\ \mathrm{Ga}$ Huronian里似疑源体的身体，经过$1.9\ \mathrm{Ga}$的*Grypania spiralis*（一个生物学地位不确定的盘绕带），加蓬$2.1\ \mathrm{Ga}$的Francevill生物群（可能是最老的多细胞生物，尽管也可能是一个矿物图案），到$1.05\ \mathrm{Ga}$的红藻*Bangiomorpha pubescens*，它是无歧义的——它有分化的细胞与看似四分孢子囊的东西——直到$575\ \mathrm{Ma}$的埃迪卡拉大化石。分子钟把现存真核生物的最后共同祖先放在$1.8$–$1.0\ \mathrm{Ga}$、把这个群起源更早，而甾烷生物标志物把真核膜放在最晚$1.65\ \mathrm{Ga}$、而在最有争议的一个测量上是$2.7\ \mathrm{Ga}$。

## 雪球，与无聊的十亿年

::: example 一个甲烷温室崩塌 {#ex-methane-collapse}
在大氧化之前大气可能持有$10^{-3}$的甲烷，给出$15$–$25\ \mathrm{K}$的温室增暖。氧通过与羟基自由基的反应把甲烷转化为二氧化碳与水，而其大气停留时间从$10^{-6}$氧时约$10$年降到更高水平的几个月。若甲烷混合比从$10^{-3}$降到$10^{-6}$，用甲烷的$\Delta F = 5.35\ln(C/C_0) + 0.036(\sqrt{C}-\sqrt{C_0})$估计辐射强迫的变化、以及在$\lambda = 3.2\ \mathrm{W\,m^{-2}\,K^{-1}}$下由此的温度变化。
::: solution
$$
\Delta F = 5.35\ln(10^{-6}/10^{-3}) + 0.036(\sqrt{1} - \sqrt{1000}) = 5.35\times(-6.91) + 0.036(1-31.6)
$$
$$
= -37.0 - 1.1 = -38\ \mathrm{W\,m^{-2}}, \qquad \Delta T = -38/3.2 = -12\ \mathrm{K}.
$$
十二度的全球变冷，加在暗淡年轻太阳那$18\ \mathrm{K}$的亏缺之上，足以把行星放进一个失控的冰-反照率反馈，而$2.45$–$2.22\ \mathrm{Ga}$的Huronian冰川沉积——Makganyene、Gowganda、Lakhaj——被发现于曾被论证接近赤道的古纬度，带着坠石与盖碳酸盐。Huronian是一个完整的雪球还是一个"类雪球"的冰川序列仍有争论，但因果链——氧上升、甲烷下降、气候崩塌、冰川埋掉本来会被呼吸的有机碳、氧进一步上升——是生物学驱动气候的第一个清楚案例，而它是此后每个关于生物圈与大气耦合的论证的模板。
:::

在$1.8$与$0.8\ \mathrm{Ga}$之间，记录以一种出了名的单调方式呈现。没有条带状铁建造，没有真正的红层，没有大的碳同位素漂移，没有动物级别的化石；叠层石达到一个多样性峰值然后下降；海洋看起来大体缺氧，而按硫与钼同位素证据，是富铁的、带一个硫化物深水库——"Canfield海洋"。真核生物在微化石记录里存在并在辐射，而最早可以被归入现生群的化石（$1.05\ \mathrm{Ga}$的红藻、可能的绿藻与约$1.0\ \mathrm{Ga}$的最早真菌）出现在其晚期。这种无聊是低氧的原因还是结果就是那个问题，而现在的答案是它们耦合的：低于现今水平几个百分点的氧给任何依赖扩散的生物的尺寸、运动性与代谢速率封顶，而元古宙的生态系统，就其字面意义而言，是被饿着的。

氧上升的第二步出现在成冰纪与拉伸纪，约在$0.8$与$0.55\ \mathrm{Ga}$之间，来自钼与铀同位素记录、来自化学沉积的铈异常、以及来自最早动物的出现——海绵，其需氧量已被测量、而无法在现今大气水平约$0.08$以下存活。埃迪卡拉生物群出现在$575\ \mathrm{Ma}$，而寒武纪动物群在$539\ \mathrm{Ma}$。

::: warning "氧的上升是一件好事"
它是地球历史里最大的大灭绝，尽管我们无法数出受害者，因为它们几乎没有一个化石化了。氧及其衍生物臭氧对厌氧生物有毒，而到那时它们是行星生物量的大部分；把行星暖起来的甲烷被摧毁了，而Huronian冰川随之而来；而新的氧化条件移除了还原性化学品——镍、溶液里的钼、溶解的铁——现存生物圈的许多都依赖它们。这个事件也是关于指标的一个警告：有二十年，蓝细菌生物标志物$2.7\ \mathrm{Ga}$的年龄建立在同年龄页岩里的2-甲基藿烷上，而在2023年Aviva Brocks与同事表明，那些老岩石里的分子是实验室里引入的污染烃类，而真正的蓝细菌信号不老于$1.65\ \mathrm{Ga}$。氧的上升没有移动，但它的发明者的时间移动了，移动了十亿年。
:::

::: quiz
条带状铁建造在约$1.8\ \mathrm{Ga}$结束。最好的解释是
- [ ] 铁的热液源因海洋化学的一个改变被关闭了
- [x] 深海洋溶解二价铁的库存终于被氧化了，而洋底不再向一个无法携带它的水柱供铁
- [ ] 与铁成带的硅被第一批泌硅生物移除了
- [ ] 更年轻年龄的条带状铁建造已被俯冲

::: solution
条带状铁建造需要一个携带大量溶解铁的水柱、以及一个在离源远处氧化它的机制。一旦深海洋变成永久氧化或硫化，溶解铁就在喷口处作为黄铁矿沉淀、而从未到达盆地，而这个沉积类型就消失了。条带状铁建造在成冰纪与马林诺斯的回归与同一个机制的反向一致：冰盖切断了氧，而热液铁再次积累。泌硅生物那个选项是关于燧石丰度改变的一个真实假说，但它不是铁建造停止的原因。
:::
:::

::: history
前寒武纪大气缺氧这个想法在被能测量之前很久就从地质学上被论证过：Preston Cloud 1968年的论文"晚前寒武纪大气氧的不充分"把红层的缺席、碎屑铀与黄铁矿、以及铁建造汇编成一个单一的论证。Heinz Lowenstam与后来的Geert Garrels和Robert Friend打下了化学沉积的基础。Erik与Marguerite Holland的《大气与海洋的氧化》（1984年，第二版2006年）是使这个题目定量化的那本书，带着它的源与汇的预算、以及它对通量而非库控制氧水平的坚持。James Farquhar、Huiming Bao与Mark Thiemens在2000年在太古宙硫化物里发现了非质量依赖硫分馏，以及随之一个臭氧上升的时钟；Reinhard、Plan与同事2009年的铬同位素工作加了第二个时钟。Joseph Kirschvink在1992年提出雪球地球，Paul Hoffman与Andy Knoll自1998年起在纳米比亚的新元古代碳酸盐中检验它，而Gideon Rothman 2003年关于波动的元古宙硫循环的模型给了无聊的十亿年一个机制。Brocks与同事2023年对蓝细菌生物标志物的重新定年，是一个提醒：在这个题目里，证据往往比岩石年轻。
:::

## 通向何处

用作氧化还原指标的同位素系统在[[geochemistry/stable-isotopes]]与[[geochemistry/radiogenic-tracers]]；硫循环与碳循环本身在[[biogeochemistry/phosphorus-sulfur]]与[[biogeochemistry/carbon-deep-time]]；海洋的化学及其控制在[[oceanography/ocean-chemistry]]；雪球机制与一个冰冻地球的气候在[[palaeoclimate/deep-time]]与[[climate-system/feedbacks-sensitivity]]；而寒武纪的结果在[[earth-history/palaeozoic]]。

::: summary 要点
- 氧是一个被维持的不平衡：大气库在几百万年里周转，所以它的积累需要一个埋藏对风化的持续盈余。
- 二十亿年的延迟由汇解释、不是由光合作用的晚发明：太古宙火山与地壳还原剂通量是现代值的几倍。
- 氧化海洋的溶解铁只值现今氧库的约万分之一；控制大气的是通量、不是库。
- 五个独立指标——非质量依赖硫、碎屑铀与黄铁矿、红层、锰矿、铬同位素——全都在2.50与2.45 Ga之间改变。
- 正碳同位素漂移靠一个简单的质量平衡测量有机碳埋藏、因此测量氧的生产。
- 大氧化摧毁了甲烷温室、并很可能造成了Huronian冰川：生物学驱动气候的第一个案例。
- 真核生物的起源是一个能量事件；线粒体供给一个大细胞需要的内部膜面积，而这个事件可能只发生过一次。
- 中元古代"无聊的十亿年"是低氧、富铁、可能硫化的，而新元古代氧的第二次上升先于、并很可能许可了动物。
:::

## 练习

::: exercise 库与通量 {level=1 check="7.4"}
若净氧源从$1\times10^{13}$减半到$5\times10^{12}\ \mathrm{mol\ yr^{-1}}$，大气氧的新停留时间是多少Myr？
::: solution
$\tau = 3.7\times10^{19}/5\times10^{12} = 7.4\times10^{6}\ \mathrm{yr}$，即$7.4\ \mathrm{Myr}$。这个库小到足以让氧水平在地质时间尺度上跟随埋藏通量，这就是为什么白垩纪与古近纪的氧水平能随缺氧海的面积升降。
:::
:::

::: exercise 指标 {level=1 check="2.45"}
哪个氧上升的指标依赖紫外光化学，而它暗示的最低氧水平是什么？
::: solution
非质量依赖硫同位素分馏（$\Delta^{33}\mathrm{S}$），它需要低于$220\ \mathrm{nm}$的紫外光到达$\mathrm{SO_2}$。它的消失暗示一个臭氧层、因此需要高于现今水平约$10^{-5}$的氧。这个信号在$2.45\ \mathrm{Ga}$关闭。
:::
:::

::: exercise 条带状铁 {level=1}
为什么条带状铁建造被视为一个缺氧海洋、而不是一个含氧海洋的证据？
::: solution
因为它们需要溶解二价铁穿过水柱搬运、并且只在它遇到氧化剂之处沉淀。在一个含氧海洋里，铁会在喷口处被氧化并就地沉淀，正如今天，而不会形成任何盆地尺度的化学沉积。这些条带是一个层化海洋的产物，有一个深的缺氧富铁库与一个浅的氧化带。
:::
:::

::: exercise 碳同位素质量平衡 {level=2 check="5"}
用[[#thm-d13c]]的关系，求作为有机质埋藏的碳的分数从$0.20$升到$0.40$、分馏为$25\%$时$\delta^{13}\mathrm{C}_\text{carb}$的变化。
::: solution
$\Delta\delta = \Delta\times\Delta f = 25\times0.20 = 5\%$。这是新元古代与古元古代最大漂移的大小，而这就是为什么一条碳同位素曲线被读作碳循环分配的记录、不是碳丰度的记录。
:::
:::

::: exercise 甲烷与气候 {level=2 check="8"}
用[[#ex-methane-collapse]]的甲烷强迫公式，求甲烷从$5\times10^{-4}$降到$5\times10^{-6}$的强迫与温度变化。
::: solution
$\Delta F = 5.35\ln(0.01) + 0.036(\sqrt{5}-\sqrt{500}) = -24.6 + 0.036(2.24-22.36) = -24.6 - 0.72 = -25.3\ \mathrm{W\,m^{-2}}$，给出$\Delta T = -7.9\ \mathrm{K}$，约$8\ \mathrm{K}$。注意对数项占主导、而平方根项只贡献$3\%$；对甲烷的大变化，简单的对数形式就够用。
:::
:::

::: exercise 延迟 {level=2 check="2.4"}
若太古宙还原剂汇是现代值的$3\times$、而现代汇是$8\times10^{12}\ \mathrm{mol\ O_2\ yr^{-1}}$，那么在氧能够积累之前，净埋藏通量必须比其$1\times10^{13}\ \mathrm{mol\ yr^{-1}}$的现代值上升多少倍？
::: solution
汇是$2.4\times10^{13}\ \mathrm{mol\ yr^{-1}}$，所以埋藏必须超过它：比现代值高$2.4$倍。若汇是现代的$4\times$，倍数就是$3.2$。要点是所需的改变是一个几倍的因子，而这通过浅海陆表海面积的增加完全可以达到——而且不需要任何新生物学的"发明"。
:::
:::

::: exercise 推导碳同位素关系 {level=3}
从两库质量平衡推导$\delta_\text{carb} = \delta_\text{DIC} + f\Delta$，然后应用它：一个古元古代碳酸盐记录$\delta^{13}\mathrm{C} = +9\%$、而同时代海相碳酸盐基线是$+1\%$。取$\Delta = 25\%$，估计$f$，作为有机质埋藏的碳的分数，并与约$0.2$的现代值比较。
::: solution
由$\delta_\text{DIC} = f\delta_\text{org} + (1-f)\delta_\text{carb}$与$\delta_\text{org} = \delta_\text{carb} - \Delta$：
$$
\delta_\text{DIC} = \delta_\text{carb} - f\Delta \Longrightarrow f = \frac{\delta_\text{carb} - \delta_\text{DIC}}{\Delta}.
$$
取基线碳酸盐记录$\delta_\text{DIC} = +1\%$，这个漂移给出
$$
f = \frac{9-1}{25} = 0.32 ,
$$
对照约$0.2$的现代值。进入海洋的碳有超过十分之三作为有机质、而不是作为碳酸盐被埋藏——比今天多一半，持续$100\ \mathrm{Myr}$。这就是为什么Lomagundo异常被读作对整个碳循环一个真实的扰动、持续$100\ \mathrm{Myr}$、以及作为产生了$2.22\ \mathrm{Ga}$冰川与第一批锰矿的氧最可能的源。
:::
:::

::: exercise 雪球的消冰 {level=3}
一个雪球地球有零风化（岩石在冰下）与零生物产氧，但继续以$0.9\times10^{12}\ \mathrm{mol\ C\ yr^{-1}}$接收火山$\mathrm{CO_2}$。估计积累足够的二氧化碳以消冰所需的时间，把所需的额外强迫取作$30\ \mathrm{W\,m^{-2}}$、并用$\Delta F = 5.35\ln(C/C_0)$。陈述假设。
::: solution
所需的浓度比是
$$
\ln(C/C_0) = 30/5.35 = 5.6 \Longrightarrow C/C_0 = 272,
$$
即$0.11\ \mathrm{bar}$的$\mathrm{CO_2}$，为$272\times4\times10^{-4}$。大气持有$1.78\times10^{20}\ \mathrm{mol}$的空气，所以所需的碳是$0.11\times1.78\times10^{20} = 2.0\times10^{19}\ \mathrm{mol}$，而在$0.9\times10^{12}\ \mathrm{mol\ yr^{-1}}$下时间是
$$
t = \frac{2.0\times10^{19}}{9\times10^{11}} = 2.2\times10^{7}\ \mathrm{yr},
$$
约两千万年。这就是那个经典的"雪球必定持续了数千万年"的论证，而这就是为什么持续了$55\ \mathrm{Myr}$的成冰纪是一个问题：在所需的消冰二氧化碳水平上，模型本应更早把它融化。

失效的假设是有意思的那些。风化在薄冰下或在无冰赤道地区不会降到零（"有避难所的雪球"或"半雪球"）。火山脱气可能更高，而海底风化汇（它不需要大陆就吸收$\mathrm{CO_2}$）在继续。而$30\ \mathrm{W\,m^{-2}}$的所需强迫取决于冰反照率、以及一个没有液态海洋的行星的云量，那是这个题目里最难的问题之一。
:::
:::

::: exercise 能量论证 {level=3}
定量地检验[[#ex-eukaryote-energy]]的论证：一个半径$10\ \mu\mathrm{m}$的真核生物含有$1000$个半径$0.3\ \mu\mathrm{m}$的线粒体。求总呼吸膜面积与细胞体积之比，对(a)细菌、(b)真核生物自身的质膜、(c)含线粒体的真核生物，并评论这个结论。
::: solution
对一个球，面积体积比是$3/r$。
(a) 细菌：$3/1 = 3\ \mu\mathrm{m^{-1}}$。
(b) 真核生物质膜：$3/10 = 0.3\ \mu\mathrm{m^{-1}}$，差十倍。
(c) 线粒体：每个有其自身表面的$3/0.3 = 10\ \mu\mathrm{m^{-1}}$，而$1000$个的总面积是$1000\times4\pi(0.3)^2 = 1130\ \mu\mathrm{m^2}$，对照$4189\ \mu\mathrm{m^3}$的细胞体积，给出线粒体的$0.27\ \mu\mathrm{m^{-1}}$加上质膜的$0.3$。

因此线粒体的贡献与细胞整个质膜相当，而总数是$0.57$对$0.3$——约是那个尺寸一个单膜细胞所能达到的两倍、是细菌的$19\%$。所以这个论证不是说真核生物每单位体积有和细菌一样多的膜（它没有），而是说它比没有内共生的所能有的多得多，而线粒体的内部嵴把面积再乘几倍——线粒体的内膜是其外表的几倍，那是使差别成立的那个细节。结论站得住：真核生物的尺寸与代谢速率由内化的呼吸买单，而付款机制需要一个内共生。
:::
