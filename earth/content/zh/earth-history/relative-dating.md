在Berwickshire海岸的Siccar Point，访问者可以站在一片平坦产出的老红砂岩——泥盆纪年龄——的台地上，俯瞰其下的杂砂岩。那些杂砂岩在四亿三千万年前的志留纪海床上作为水平的泥与砂沉积；此后某个时刻它们被埋藏、烘烤、挤成直立的褶皱、抬升、并被磨平如一条路面；然后，很久之后，它们再次沉没并被泥盆纪砂岩埋住。每个站在那里过的地质学家都有同样的反应，而那不是对岩石的赞叹。那是意识到两层岩之间的接触面是一个几亿年的时间间隔、而其上肉眼可见的全部岩层厚度只是一条脚注时的震动。

James Hutton在1788年看到了那个面，而他的反应是地球科学的奠基论证：地球必定远比任何出自经文或出自一个热球冷却的推算都古老，因为他能看见的过程——一个浪切出一个平台、一条河搬运泥沙——仍以同样的速率运行，而它们留下的记录要求一个没有日常类比的时间尺度。本章讲让你能读出这样一个面的工具：给出次序而不给出数字的那些规则，以及这个次序如何被变成一部全球时标。

## 公理

::: definition Steno原理 {#def-steno}
**叠置原理。**在一个未受扰动的沉积岩序列中，每一层都比其下的年轻、比其上的老，因为沉积向上建造。
**原始水平原理。**岩层大致水平沉积，因为沉积物在一个近乎等高的面上沉降；因此一个现在直立的岩层是后来被弄直的。
**原始侧向连续原理。**一个岩层侧向延伸直到变薄尖灭或尖入另一相；因此同一岩层两个分离的露头是一次沉积的部分。
**切穿关系。**任何切过一块岩石的构造——断层、岩墙、侵蚀面、不整合面——都比它切过的岩石年轻。
**包裹体。**包在一块岩石里的碎屑比那块岩石老。
:::

这五条不是观察、而是单个假设的推论，即沉积与变形以它们现在可见的方式工作。这个假设有一个名字与一段历史——**均变论**，在Lyell的表述里，现在是通往过去的钥匙——以及一个更审慎的现代版本，**现实论**：自然定律是恒定的，而我们看到在运行的过程与造出记录的过程是同类过程，尽管未必以同样的速率或同样的组合。

::: proposition 这些原理给出一个偏序，而对比是使它成为全序的东西 {#prop-partial-order}
在一个露头之内，叠置与切穿关系给出一条完整而无歧义的事件序列。在两个盆地之间、或两个大陆之间，它们什么也不给：威尔士的一个石炭纪砂岩与俄罗斯的一个石炭纪砂岩之间没有任何物理联系，而它们的等同是一个必须用某种独立论证来辩护的断言——同样的化石、同样的磁极性、同样的同位素漂移、同样的凝灰层。因此每一部全球时标都是一个层级：一个非常强的局部次序、一个由化石对比建成的强区域次序、以及一个较弱的洲际次序，后者随着对比的改变被反复修订。
:::

::: proof
一个剖面之内的次序是一个*偏*序，这很容易看出：两个岩层可能由叠置相关，也可能无关，因为其中一个被侵蚀移除了，或者它们同年龄、在意义上的不同地方同时沉积。要让次序成为全序，你需要一个识别同时性的关系，而同时性在岩石里不能被直接观察——只能从某个全球同步的东西推断，比如一次磁反转、一次海洋缺氧事件、一次喷发的凝灰降落、或一个化石物种的首次出现。这些每一个都是一个关于时间标志的独立假说、而每一个都可证伪：一次凝灰喷发只有一个年龄，所以若两个靠化石相似性对比的岩层给出不同的凝灰年龄，两个对比里有一个是错的。∎
:::

::: warning 叠置可以被倒转
这个原理只对未被翻转过的序列成立。紧密褶皱、冲断与推覆体就位可以把老岩放到新岩之下，而在这样的地块里，地质学家必须先把岩层的**朝向**确立起来、再把它当时钟用：粒序层理（下粗上细）、波状交错层理、泥裂、雨痕、负荷构造向下凸的方式、化石或晶体的指向、以及枕状熔岩的次序，它们从顶部向内骤冷。一个被倒转的地层读起来是一个完整的向上变新的序列、而会愉快地与其内每一个化石年龄矛盾。在朝向不明之处，切穿关系与火成侵入体的年龄是唯一可靠的仲裁者。
:::

## 不整合：缺失的记录

::: definition 不整合的类型 {#def-unconformity}
一个**不整合**是不同年龄岩石之间一个侵蚀或未沉积的面。一个**角度不整合**在其侵蚀面之下有倾斜或褶皱的岩石、被以一个角度覆以较新的岩层——Siccar Point类型。一个**假整合**（沉积间断）在其被埋藏的侵蚀面之上下都有平行岩层，只能靠化石、靠一个古土壤、靠一个被牡蛎胶结的硬底、或靠一个年龄缺口来检出。一个**非整合**是沉积岩在火成或变质岩之上、记录掉去许多公里的地壳。一个**平行不整合（伪整合）**是一个没有可见侵蚀也没有角度不协调的面，只从化石或同位素缺口得知。
:::

::: example 地球历史有多大比例是缺失的？ {#ex-missing-time}
一个沉积盆地在任何沉积之时以$0.1\ \mathrm{mm\,yr^{-1}}$的平均速率积累沉积物，而有$20\%$的时间被抬升、侵蚀与饥饿。一个$5\ \mathrm{km}$厚的序列被实测，而化石显示它跨越$500\ \mathrm{Myr}$。求实际被保存的间隔分数、以及已被移走的岩石的平均厚度。
::: solution
在$0.1\ \mathrm{mm\,yr^{-1}} = 0.1\ \mathrm{km\,Myr^{-1}}$下，$500\ \mathrm{Myr}$的连续沉积会给出$50\ \mathrm{km}$的剖面。因此保存的$5\ \mathrm{km}$是本应在之物的$10\%$，而$20\%$的不沉积时间只解释了损失的五分之一：其余的部分沉积过、然后**被侵蚀掉了**。

这就是让John Wheeler在1958年说地球历史的大部分在岩层记录中缺失的那个结果，而现代的估计更糟、不是更好：在大陆上，任何间隔被保存的分数通常是几个百分点，而在深海，古近纪的沉积记录大部分已不在，被建造陆隆上扇体的浊流移走了。推论对每个从缺席出发的论证都要紧："这个年龄的岩层里没有X的化石"作为X不曾存在的证据非常弱，而一个撞击层、一个缺氧事件或一次大灭绝的缺席同样如此。
:::
:::

## 对比，以及使它成为全球性的工具

岩性在几十公里内对比得好、在几千公里上对比得糟，因为同样的砂岩被沉积过许多次。能在一个大陆或一个大洋上工作的工具，是那些记录了某个同步之物的工具：

- **化石。**一个物种的首次出现，原则上是一个散布在其生境里的瞬间。一个好的**标准化石**有一个短的地层分布区间、一个广布的分布、在岩石里幸存下来的丰富壳体或花粉，并且独立于相——它生活在许多环境里，所以它的存在不只是泥岩的一个标志。牙形石、笔石、菊石、有孔虫与花粉正是因为这些理由才是主力。
- **磁极性。**反转在其过渡的几千年之内是全球同步的、而被记录在海相与湖相泥以及熔岩里。**磁性地层学**给出一个正与反带的模式、可与地磁极性时标配对，而它是使多数新生代剖面、以及许多更老剖面定年到百分之一以内优于的方法。
- **化学。**穿过一个剖面的碳、氧、锶、锇与硼同位素曲线给出一个化学地层指纹。古新世-始新世极热事件、二叠纪末、以及PETM的表亲们的负碳同位素漂移被用作几千公里上的连线。
- **凝灰层。**一次喷发可以用一种特征玻璃成分与锆石年龄覆盖$10^6\ \mathrm{km^2}$。**火山灰年代学**给出精确到几十公里的等时层位，而当锆石可测年时，给出岩层本身的一个绝对年龄。

::: example 用化石首次出现做对比 {#ex-fad}
一个总分布区间为$1.8\ \mathrm{Myr}$的笔石物种被用来对比相距$3000\ \mathrm{km}$的两个剖面。它的首次出现被当作一个带的底。在A剖面，这个物种产在$120\ \mathrm{m}$的泥岩里；在B剖面，最低的产出在$340\ \mathrm{m}$的砂岩里，而其上页岩的底——与A的泥岩同一相——在$300\ \mathrm{m}$。估计对比的最大误差，并说出使一个首次出现穿时的两个效应。
::: solution
若这个物种的分布区间是$1.8\ \mathrm{Myr}$、而其首次出现被当作一条等时线，那么这个对比最好也只有该物种分布区间的量级，即$\pm 0.9\ \mathrm{Myr}$，而实际上是其首次出现与其盛现之间的间隔——通常是几十万年。B里的相变是第二个问题：这个物种可能在$300\ \mathrm{m}$之下存在于砂岩里而只是没被保存、或不住在那里。

两个效应是（**i**）**演化穿时**——一个物种在其分布区的不同部分在不同时间出现，而一个边缘盆地的首次出现可以比全球首次出现晚几十万年——以及（**ii**）**保存与抽样穿时**——记录是不完整的，所以找到的最低化石比曾经生活过的最低化石年轻。两个效应都把观测到的首次出现*向上*推，从不向下，这意味着一个首次出现标志面是这个物种演化的一个最小年龄、岩层的一个最大年龄。那个不对称就是为什么一个阶的底是在一个选定的剖面上、在GSSP上定义的、而不是在任何东西的首次出现上定义的。
:::

::: example 一个剖面里的两层凝灰 {#ex-ashes}
一个湖相剖面含有两层玻璃成分相同的斑脱岩：下部在$120\ \mathrm{m}$给出CA-ID-TIMS锆石年龄$104.21 \pm 0.05\ \mathrm{Ma}$，上部在$340\ \mathrm{m}$给出$103.10 \pm 0.06\ \mathrm{Ma}$。求平均沉积速率及其不确定度，并说明成分相同能证明什么、不能证明什么。
::: solution
间隔是$220\ \mathrm{m}$、$1.11\ \mathrm{Myr}$：
$$
R = \frac{220}{1.11} = 198\ \mathrm{m\,Myr^{-1}} = 0.20\ \mathrm{mm\,yr^{-1}} .
$$
间隔的不确定度是$\sqrt{0.05^2 + 0.06^2} = 0.078\ \mathrm{Myr}$，即$7\%$，所以$R = 198 \pm 14\ \mathrm{m\,Myr^{-1}}$——一个在一百万年上平均的速率只有$7\%$的不确定度，这就是凝灰层值一次锆石分选之价的原因。

相同的主量元素成分显示两层来自**一次喷发**，所以它们是等时的、可以被用来把剖面在火山灰降落的全部范围上拴在一起，而对一次大喷发那可能是一个大陆。它不能证明的是两个剖面在其他方面等同：火山灰穿过当时在场的任何水柱或土壤剖面落下，而其间的$220\ \mathrm{m}$可以完全是不同的相、完全不同的厚度、或在第二个剖面里完全缺失。一个凝灰层是一条线、不是两条线之间一切事物的对比。
:::

## 相、Walther定律、与一次海侵的几何

::: definition 相与Walther定律 {#def-facies}
一个**相**是一个具有那些特征——岩性、沉积构造、化石、颜色、层理——记录某个特定沉积环境的岩体。**Walther定律**说，在一个整合剖面里相的垂向序列与产生它们的环境的侧向序列相同，条件是没有不整合。因此一次**海侵**——海平面相对陆地上升——把滨面砂叠在远岸泥之下、泥在潟湖泥炭之下，一个*向上变细*、*向上变深*的序列，并把海岸线逐渐铺向内陆。一次**海退**做相反的事：一个向上变粗、向上变浅的序列，海岸线向海移动。
:::

::: example 读一次海侵 {#ex-transgression}
一个实测剖面，从底部起：$12\ \mathrm{m}$的交错层理砾岩与河道砂，含根痕与煤；$8\ \mathrm{m}$的细纹层砂质粉砂，含牡蛎礁与泥裂；$25\ \mathrm{m}$的灰色海相页岩，含菊石与海绿石；$6\ \mathrm{m}$的交错层理纯净砂岩，其底为波状纹层的混合岩相；然后是$20\ \mathrm{m}$同样的灰色页岩。解释这个序列，并定位最大海泛面。
::: solution
从底到顶：一个海岸平原与河流系统（煤、根痕、河道），向上过渡为潮坪与河口（泥裂、牡蛎、粉砂），然后是开阔海陆棚（菊石页岩、海绿石）——一个**海侵的、向上变深**的序列。底部为波状交错混合岩的纯净砂岩是海岸线回来时沉积的一个滨面砂——一次**海退、向上变浅**——而回到页岩是第二次海侵。

**最大海泛面**是第二套页岩的底，海岸线最靠内陆、水最深的那个面；它通常由一个压缩段标记——一个硬底、一个磷结核或再循环磷质颗粒的富集、自生矿物的丰度、或总有机碳的一个峰值——因为在最大海泛时沉积供给处于最低、而海底正被数百万年来落在其上的一切铺成地毯。压缩段是任何盆地里时间最丰富的面、也是寻找一个伪装成层理面的不整合的最佳地点。
:::

::: history
Nicolas Steno在1669年用四十多页写下了地层学的原理，那本书真正的主题是一块舌形石头如何进到另一块石头里面。Robert Hooke与Ole Worm已经论证化石是生物的遗骸、不是自然的戏作，而Steno对一颗鲨鱼牙的描述为一代人解决了这个问题。James Hutton在1785与1788年把这个逻辑转向自身，显示记录蕴含着无限之久，而John Playfair与John Hall找到了证明它的角度不整合。William Smith，一个来自牛津郡的运河测量员，在1793至1815年间确立了地层遵循一个固定次序、并可在英格兰任何地方由其化石识别，并产出了使地层学成为一门实用科学的那幅地图；Georges Cuvier与Alexandre Brongniart同时在对巴黎盆地做同样的事，而Cuvier的灭绝论证给了两人一个理由。Charles Lyell的《地质学原理》（1830–1833）汇编了均一速率的论证，而Adam Sedgwick、Roderick Murchison与Henry De la Beche为威尔士与边界地区寒武纪与志留纪岩石的年龄激烈争吵，画出了至今仍用的大部分古生代界线。"生物地层学"这个词与这门学科的现代形式随十九世纪中叶的地质调查局到来，而国际时标随1878年第一届地质大会到来，那届大会开始了关于一个阶应当由一块岩石、一个化石还是一个年龄来定义的漫长争论。
:::

::: quiz
一个砂岩体含有它所坐落的页岩的碎屑，而被一条玄武岩岩墙切过，岩墙本身顶部被其上覆砾岩侵蚀。正确的次序，从老到新是什么？
- [ ] 砂岩、页岩、岩墙、砾岩
- [x] 页岩、砂岩、岩墙、砾岩
- [ ] 岩墙、页岩、砂岩、砾岩
- [ ] 砾岩、岩墙、砂岩、页岩
::: solution
砂岩含有页岩的包裹体，所以页岩更老。岩墙切过砂岩，所以它更年轻。砾岩侵蚀岩墙，所以它最年轻：页岩→砂岩→岩墙→砾岩。注意岩墙的*年龄*未必是岩浆喷出的年龄——它比砂岩年轻、比砾岩老，而那个夹逼区间就是野外关系给的全部；一个对岩墙的同位素年龄会把它闭合。
:::
:::

## 命名法：时标实际上如何建造

三套平行的系统描述同样的岩石、而不断被混淆。**岩石地层学**按岩性命名岩体（组、段、群）而它是地方的。**生物地层学**按其化石命名间隔（一个分布区间带、一个盛现带、一个组合带）而它是关于生物、不是关于时间的陈述。**年代地层学**把时间间隔命名为岩石——侏罗系是在侏罗纪沉积的岩石——而国际时标就是由它造成的。

一个**阶**是年代地层学的工作单位，而自1974年起每个阶都由一个**GSSP**、一颗"金钉子"定义：一个实测剖面、其中一个个层位、以及一个用该层位中某个选定化石物种的首次出现的定义，由一个小组委员会与国际地质科学联合会三分之二的票批准。这个阶于是有一个作为岩石中一个物理点的下界，而世界上其他一切剖面都靠对比被归给它。这个系统是刻意保守的：它被设计为稳定、而不是准确，这就是为什么有些阶的界线如今已知穿时百万年、也是为什么人类世的定义在2024年被否决、而不是被允许扰动时标。

::: summary 要点
- Steno原理——叠置、水平、连续、切穿、包裹体——给出一个剖面里事件的次序，而只对一个未被倒转或冲断的序列有效。
- 不整合是那些有意思的面：它们记录抬升、侵蚀与缺失的时间，而多数盆地里缺口包含的时间比岩层多。
- 岩层记录大部分是缺失的。一个典型的大陆序列保存其跨越间隔的百分之几，所以从缺席出发的论证是弱的。
- 跨盆地对比需要一个同步标志：化石、磁极性、同位素化学或一个凝灰层。单靠岩性走不远。
- 一个化石首次出现是物种的最小年龄、岩层的最大年龄，因为演化与未保存都把它向上推。
- Walther定律使一个垂向序列成为一张侧向的环境地图；海侵向上变细变深，海退向上变粗变浅，而最大海泛面就是压缩段所在。
- 时标是一个人造物：由金钉子定义的阶、由委员会批准、按设计稳定、只在票转向另一面时才被修订。
:::

## 练习

::: exercise 事件排序 {level=1 check="4"}
一个序列含有：(1) 一个砾岩坐落在褶皱页岩里一个侵蚀面上；(2) 褶皱页岩；(3) 一条花岗岩岩墙切过页岩但不切砾岩；(4) 一条正断层切过页岩与岩墙但不切砾岩。记录了几个不同的事件？哪个最年轻？（事件数填入。）
::: solution
四个：页岩的沉积与褶皱；岩墙的侵入（在褶皱之后，因为它切过页岩而自身未褶皱）；断裂（在岩墙之后，因为它切过岩墙）；侵蚀、然后砾岩的沉积，砾岩截切断层而未变形。最年轻的事件是砾岩的沉积；其下的侵蚀面比砾岩老、比断层年轻。
:::
:::

::: exercise 朝向 {level=1}
说出两个能在重结晶中幸存的变新判据，与一个不能幸存的。
::: solution
粒序层理与交错层理即使矿物已消失仍作为一个几何形态幸存，负荷构造与枕状熔岩的骤冷边也是。泥裂不能在变质中幸存，而波痕几何可以被面理转置。因此在一个高级变质地块里，可靠的证据是与侵入体的关系、与未变质盖层的地层朝向、而不是沉积构造。
:::
:::

::: exercise 不整合类型 {level=1 check="disconformity"}
两层平行产出的石灰岩被一个带铁染砾石、一个古土壤与半咸水牡蛎的面分开。这是哪种不整合？证据显示了什么？
::: solution
一个**假整合**：平行岩层，所以没有角度不协调，但土壤、氧化的砾石与半咸水牡蛎都显示海退开了、面被风化过。缺口由化石与古土壤证明、不是由几何。
:::
:::

::: exercise 完整度 {level=2 check="0.05"}
一个$2.4\ \mathrm{km}$厚的序列跨越$400\ \mathrm{Myr}$，而盆地可信的最大积累速率是$0.12\ \mathrm{mm\,yr^{-1}}$。求作为岩石保存的间隔分数。
::: solution
最大可能厚度$= 0.12\ \mathrm{mm\,yr^{-1}} \times 4\times10^{8}\ \mathrm{yr} = 4.8\times10^{7}\ \mathrm{mm} = 48\ \mathrm{km}$。保存分数$= 2.4/48 = 0.05$，即$5\%$。百分之九十五的时间由一个面、一个薄层、或什么都没有来代表。
:::
:::

::: exercise 再循环化石 {level=2 check="younger"}
一个砂岩含有保存良好的两个动物群的菊石：一个与其下岩层的同龄，另一个是只知自剖面中高$200\ \mathrm{m}$处岩层的物种。砂岩的年龄是多少？第二个动物群怎么了？
::: solution
砂岩的年龄是它所坐落岩层的年龄——较老的动物群是**自生的**、给出年龄。第二个动物群被**再循环**了：剖面中较高的含菊石岩层在砂被剥落时已经暴露并被侵蚀，而它们的化石被搬运并埋进砂里。再循环化石靠磨圆、靠破碎、靠与基质不同的矿化、以及靠产在其其他内含物与其矛盾的岩石里来识别。规则是*保存最好、搬运最少*的动物群给出的年龄获胜，而一个含两个年龄物种的动物群是某处发生过侵蚀的证据、不是两次沉积的证据。
:::
:::

::: exercise 磁性地层学 {level=2 check="2.4"}
一个湖相剖面记录了与地磁极性时标配对的极性带。剖面的底位于时带C5n.2n的底（$10.9\ \mathrm{Ma}$）、顶位于C5n.1n的顶（$7.6\ \mathrm{Ma}$），而剖面厚$8.2\ \mathrm{km}$——但这个对比有争议，而另一个方案把顶放在C5n.2n的顶（$10.0\ \mathrm{Ma}$）。求每个对比的沉积速率，并说明若盆地的其他边缘显示$3\ \mathrm{mm\,yr^{-1}}$哪个更可能。
::: solution
对比A：$8.2\ \mathrm{km}$、$3.3\ \mathrm{Myr}$，给$2.5\ \mathrm{mm\,yr^{-1}}$。对比B：$8.2\ \mathrm{km}$、$0.9\ \mathrm{Myr}$，给$9.1\ \mathrm{mm\,yr^{-1}}$。对比A更接近盆地的其他边缘、被优选；这个练习演示了为什么磁性对比必须对着可信的积累速率范围检验，因为一个极性模式可以在时标的几个位置上配对、而只有一个给出一个合理的速率。
:::
:::

::: exercise 推导Walther定律 {level=3}
精确地陈述Walther定律，并给出一个真实垂向序列即使在整合时也未能复现侧向序列的两个理由。
::: solution
Walther定律：若一个相A侧向无间断地过渡为相B，则一个穿过海侵或海退海岸线的垂向剖面将在B之下（或之上，取决于迁移方向）含有A，而垂向次序复现环境的侧向次序。

两个失效。(i) **再循环与压缩**：海侵侵蚀正在出露的剖面的下部，所以垂向序列跳过了侧向上在那里的相——一个冲刷面移走潟湖、把滨面砂直接放在海岸平原上。(ii) **速率的非等同**：海岸线可能比环境能建造的速率迁移得更快，所以一个侧向占据$50\ \mathrm{km}$的相在垂向上由$20\ \mathrm{cm}$代表，而垂向剖面是侧向剖面的一个压缩的、有偏的样本。第三个更微妙的理由是，有些环境——比如碳酸盐台地的边缘——如果海侵够快就根本不会被越过，所以它们的相从不出现在垂向序列里。
:::
:::

::: exercise GSSP问题 {level=3}
一个阶的界线由内华达一个剖面里一个牙形石物种的首次出现定义。说明中国一个剖面里同一个阶的底可能错超五十万年的三种不同方式，以及每一种如何检验。
::: solution
(i) **穿时的首次出现。**这个物种在一个地区演化并迁移；它在中国的首次出现晚于它在内华达的首次出现。用高精度CA-ID-TIMS对两个剖面夹逼界线的凝灰层定年、并同时使用若干标志来检验。(ii) **保存与抽样。**中国最低的产出不是最低的产出：这个物种更早就在一个不含化石或未抽样的相里。用更密的采样、用淘洗微体动物群、用在该盆地别处的等同相里寻找来检验。(iii) **对比误差。**两个剖面由一个本身有歧义的化石组合或同位素曲线拴住，所以中国的界线画在错误层位。用不依赖那个化石的独立标志检验——一个特征凝灰层、一次磁极性反转、一个锶同位素漂移。

三者都是真实的、而三者都移动过界线。2012年对杜内阶底的重定义、2018年对格陵兰阶底的重定义、以及关于寒武纪底线的漫长争论（从一个遗迹化石移到一个小壳化石、再移到一个组合）都是这个系统靠恰恰这个方法自我纠正的例子。
:::
:::

::: exercise 一个野外问题 {level=3}
你在填制一条造山带，而在三种岩性里发现同一个化石组合：一个石灰岩、一个页岩、一个砂岩，各厚$200\ \mathrm{m}$，在相距$40\ \mathrm{km}$的三个地点处于同一地层位置。一位同事把它们填作三个不同年龄的组。把支持与反对的论证列出，并设计检验。
::: solution
**支持同事：**三个组是岩石地层学的惯例，而如果三种岩性被可填图的尖锐接触分开，它们就是可填图的单元。**反对：**同一地层位置里相同的动物群是三个岩体是一个时间片、沉积在三个相邻环境——台地石灰岩、盆地页岩、三角洲前缘砂岩——并且侧向指状相交、而不是互相覆盖的有力证据。如果它们是相，那么把它们称作不同年龄的组将产出一个幽灵地层与一个幽灵断层，就在这些单元被放在一起接触的地方。

**检验：**走接触带。相界渐变过渡、在边缘显示相同的层理、含有相邻相的内碎屑、并携带动物的同一动物群跨过接触；一个组界是一个侵蚀面或未沉积面、其上有动物群的变化、并且可以穿过一个相的变化被追索。加上一个沉积学剖面——粒度趋势、古水流、动物群的生态耐性——而如果论证还活着，用凝灰层或牙形石带以比争议间隔更细的分辨率给每种岩性的底定年。这是地层学历史上一个常见而后果重大的论证，而相解释赢过组解释的次数更多。
:::
