1909年，美国最有影响力的古生物学家Charles Walcott第三次回到Burgess页岩，赶着一骡子的板石下山，上面以非凡的细节保存着他命名为*Hallucigenia*、*Anomalocaris*与*Opabinia*的寒武纪动物。到1925年他有六万五千件标本。他把它们全部解释为节肢动物与蠕虫、塞进已经存在的门里，而他对其中几乎每一属都错了：*Anomalocaris*是一个长着菠萝形口与关节抓握附肢的捕食者、不是虾的尾部；*Opabinia*有五只眼睛与一根吻；*Hallucigenia*被上下颠倒重建了七十年。当Harry Whittington与他的学生在1970年代重做这批收藏时，他们发现大多数动物不属于任何现生门，而寒武纪早期在身体构型上的实验比幸存下来的现代动物群陌生得多。

Burgess页岩是古生物学完美的入门，因为它一次说明两个道理。第一，化石记录是*被保存下来的东西*的记录，是对生活过的生物一个细小而无代表性的一把抓取。第二，连保存最好的化石的解释也是一个理论，可修订、并带着它那个十年的假设。本章讲化石如何形成、它们多么糟糕地抽样过去、以及尽管如此仍能被让它们告诉我们什么——包括，靠着小心的统计，那些快得无法被记录下来的灭绝的时间。

## 一个生物要被保存下来必须发生什么

::: definition 埋藏学与保存方式 {#def-taphonomy}
**埋藏学**研究从死到被发现之间发生在一个生物身上的一切：搬运、腐烂、食腐、埋藏、压实、化学改变、以及最终的被发现本身。保存方式有：
- **硅化（充填作用）**——孔隙被沉淀的硅、方解石或黄铁矿填满；解剖结构三维保留（硅化木、Rhynie硅质岩）。
- **交代**——原始物质被溶解并被替换，常常精致到毫巅（硅质对贝壳的交代、笔石里的黄铁矿）。
- **碳化（蒸馏）**——挥发元素被赶跑、留下一层碳膜；叶子、水母与软体生物的通常归宿。
- **模铸**——贝壳溶解留下空腔、然后被填充。
- **未改变的原始物质**——在琥珀、沥青、冰、盐与干燥的洞穴沉积里。
- **遗迹化石（迹化石）**——潜穴、足迹、钻孔、粪便、蛋壳、吐出的食丸：行为的证据，由生物*做出*而非由生物*构成*。
一个**特异埋藏化石库（Lagerstätte）**是一个保存异常的产地，通常把软组织与硬体结合在一起、而总是意味着一个正常腐烂被打断的环境。
:::

::: proposition 软组织靠早期矿化保存、不靠运气 {#prop-soft-parts}
软组织在几天到几周内腐烂。要让它保存，矿物必须在细菌腐烂摧毁它之前在其内与其周沉淀，而这需要抑制细菌并供给离子的条件：细粒沉积物的快速埋藏、缺氧、硫酸盐耗竭、以及一个硅、磷酸钙或硫化铁的来源。后果是特异埋藏化石库在岩层记录中的分布随时间不是随机的——它们聚集在早寒武世、志留纪、二叠纪与侏罗纪、以及黑色页岩相中——而软体生物的历史主要记录在那些条件恰好重合的时段与相里。
:::

::: example 记录有多不完整？ {#ex-incomplete}
Sepkoski与其他海洋化石记录的分析者估计，显生宙期间存在过大约$5\times10^{9}$个物种，而经描述的化石物种约$250{,}000$个。Raup估计，有合理保存机会的属里也许有一半已被找到。求被保存的物种分数；以及若一个长寿的海洋无脊椎动物物种每代产生$10^{8}$个个体、共$10^{6}$代、而知名的只是全世界博物馆里$10^{4}$件标本，求被石化的*个体*分数。
::: solution
物种：$2.5\times10^{5}/5\times10^{9} = 5\times10^{-5}$，两万个物种里描述了一个。个体：这个物种产生过$10^{14}$个个体、而$10^{4}$个在收藏里，所以$10^{-10}$——一百亿分之一——而野外真正的化石记录也许比其博物馆部分大千倍，给出一亿分之一。

这些数字不是绝望的忠告；它们正是本学科使用比值与分布、而不是存在与不存在的理由。一个个体作为一个类群存在过的证据不值多少、作为它没有存在过的证据则一文不值。信息在样本的*形状*里：分布区间的分布、属种比、每属标本数、以及它们如何随时间变化——而所有这些都必须就"那个年龄的岩石存活了多少、被采集得有多勤"加以校正。
:::
:::

::: theorem Signor–Lipps效应：灭绝总显得渐近 {#thm-signor-lipps}
若一个物种的化石产点在其真实分布区间内均匀随机分布、而已知$n$个产点，则最年轻已知化石与真实末次出现之间的期望缺口是
$$
\langle g\rangle = \frac{R}{n+1},
$$
其中$R$是分布区间的持续时间。没有有限样本能显示一次瞬时灭绝，而一次大灭绝表面上的渐进度部分是抽样的伪影。
:::

::: proof
把$n$个产点沿分布区间排序、考察它们把区间分成的$n+1$个缺口，包括从最年轻产点到真实终点的那个。由对称性、且因为产点是均匀抽取的，每个缺口的期望大小相同，为$R/(n+1)$。因此最年轻的产点期望比真实灭绝短那么多。∎

推论就是这个定理重要的原因。Signor与Lipps在1984年用它论证，经典剖面里白垩纪海洋动物群看似渐近的衰退完全可以与一个瞬时的终结相容，而对一个物种*末次*出现的搜寻永远无法证明它是渐近灭绝的。这个论证的现代版本是末次出现分布区间的一个置信区间，而这也是为什么白垩纪末之争不是靠找到更多化石、而是靠找到铱层解决的：一个独立的、全球同步的标志层，不依赖任何分布区间就把时间钉住了。
:::

::: example 抽样努力多大程度上改变一条多样性曲线？ {#ex-rarefaction}
一个群落有五个物种，相对多度为$0.50$、$0.20$、$0.15$、$0.10$与$0.05$。$N$个个体样本中期望的物种数是$S(N) = \sum_i [1-(1-p_i)^N]$。计算$N = 5$与$N = 20$的$S$。
::: solution
$N=5$时：
$$
S = 0.969 + 0.672 + 0.556 + 0.410 + 0.226 = 2.83 .
$$
$N=20$时：
$$
S = 1.000 + 0.988 + 0.961 + 0.878 + 0.642 = 4.47 .
$$
两个真实多样性完全相同、一个用五件标本另一个用二十件抽样的群落，在观测丰度上相差五个物种里的$1.6$个——总数的三分之一。这就是为什么1970年代以来古生物文献里每个比较多样性研究都做过**稀化**校正：样本要么被重新抽样到共同的个体数、要么拟合一条曲线并外推、要么用一个显式的抽样项建模。同一个校正施加到整个显生宙，改变了本学科一个核心问题的答案：海洋多样性看似指数式的上升有很大一部分是保存下来并被采集的岩石量的上升，而把岩面积考虑进去之后，增长是真实的、但远慢于原始曲线提示的。
:::
:::

::: example 一份名单里缺了多少物种？ {#ex-chao1}
来自单个采石场层位的一个定量样本产出归属20个物种的$312$件标本。其中八个物种由一件标本代表、两个恰好由两件代表。用一阶Chao估计量
$$
S_\text{Chao1} = S_\text{obs} + \frac{f_1^2}{2 f_2},
$$
估计该层位的真实物种丰度，其中$f_1$与$f_2$是单件与双件物种的数目。
::: solution
$$
S_\text{Chao1} = 20 + \frac{8^2}{2\times2} = 20 + 16 = 36 .
$$
该层位约有$36$个物种，其中$16$个还没被找到——而这个估计量在做一件相当合理的事：一个有许多稀见物种的动物群（单例相对于双例很多）是一个样本几乎没碰到稀见物种长尾的动物群，而比值$f_1^2/f_2$在单例大多不是一个抽样充分群体的幸存者时就很大。该估计量假设稀见物种同样丰富；若它们不同样丰富，它是一个下界，这也是它通常被引用的方式。

给野外的实用教训是：一份名单里的物种数是采集标本数的一个函数，而两个动物群相同、采集强度不同的采石场会报告不同的多样性。任何没处理过这一点的比较研究，测量的是地质学家。
:::
:::

::: example 一次灭绝的置信区间 {#ex-lo-ci}
一个菊石属的末次出现记录在一个连续剖面的一个层位，而这个属知自一个$4.0\ \mathrm{Myr}$实测分布区间内的$n = 6$个化石层。用Signor–Lipps框架，求到真实灭绝的期望缺口与一个$95\%$上界，并说明这个结果对一个"该属灭绝于一场$100\ \mathrm{kyr}$事件"的主张意味着什么。
::: solution
期望缺口是$R/(n+1) = 4.0/7 = 0.57\ \mathrm{Myr}$。在均匀模型下缺口$g/R$有一个类指数尾部，而一个常用的$95\%$上界是均值的三倍，$1.7\ \mathrm{Myr}$。

所以真实的灭绝位于最年轻化石与其后$1.7\ \mathrm{Myr}$之间的某处，而一个"该属挺过、或没挺过一场$100\ \mathrm{kyr}$灾难"的主张无法用六个层检验：数据的分辨率比事件粗一个数量级。这就是那句否则令人困惑的话——白垩纪末灭绝"在剖面的分辨率内是瞬时的"——背后的算术：最好的剖面里分辨率是几万年、多数剖面上是几十万年，而这个主张说的是分辨率、不是事件。
:::
:::

## 遗迹、分子、与实体化石的极限

::: definition 遗迹化石与寒武纪底质革命 {#def-traces}
一个**迹化石**以一个迹分类单元命名，一套与实体化石分开的命名系统，因为一条潜穴没有主人：*Skolithos*是一根垂直管，*Cruziana*是一种节肢动物的觅食迹线，*Palaeophycus*是一条有衬里的水平潜穴，*Glossifungites*是一个硬底钻孔。**寒武纪底质革命**是生命史中文献最充足的事件之一：约$540\ \mathrm{Ma}$之前海床是一个菌席地，一层动物在其上牧食却很少钻入的粘性微生物席，而沉积物细层纹发育、在遗迹意义上无化石。寒武纪带来了掘穴，而掘穴带来了**生物扰动**——沉积物被翻成均质的、含氧的、含水的底质——它毁灭了菌席地生态系统、改变了沉积物-水界面的化学、并第一次使内底动物群成为可能。这个事件由遗迹化石、不是由实体定年，而它是一个行为改变环境、而不是环境改变行为的例子。
:::

还有三条证据线把记录延伸到实体化石失效之点之外。**化学化石（生物标志物）**是分子化石——来自真核生物与蓝细菌膜的甾烷与藿烷，以及曾被归于蓝细菌的2-甲基藿烷——保存在古老页岩里，它们把真核生物的记录推回$1.6\ \mathrm{Ga}$乃至更早，尽管任何老于约$1.8\ \mathrm{Ga}$的主张都因后期污染而被质疑。**同位素化石**是固碳的碳同位素特征：$3.8\ \mathrm{Ga}$（Isua）与$3.7\ \mathrm{Ga}$（Nuvvuagittuq）岩石里$\delta^{13}\mathrm{C}$接近$-25\%$的有机碳提示生物固碳，但不是证明，因为有若干非生物过程以同样方式分馏碳。**分子钟**靠遗传差异的积累给谱系的分歧定年、由化石记录校准；它们通常把一个门的起源放在其第一个化石之前数千万或数亿年，而两个钟之间的分歧是本学科富有成效的争论之一——就动物而言，分子定年为$700$–$800\ \mathrm{Ma}$、对照始于$550\ \mathrm{Ma}$的化石记录。

::: warning "证据的缺席不是缺席的证据"——但它是证据
这句格言对一半。已知一个层位里$n$件某物种的标本、而你已经刻画了你的保存与抽样过程，那么这个物种存在过而未被检出的概率可以被估计，于是缺席就成了一个确定大小的定量证据。缺席做不到的是证明一个瞬时事件（因为Signor–Lipps）、或排除一个生活在未被保存的相里的谱系。这门学科真正的错误不是过度解读缺席、而是相反：把记录里的一个缺口当成自然里的一个缺口。文献里每个"首次出现"都是一个起源的最小年龄，每个"末次出现"都是一次灭绝的最大年龄。
:::

::: quiz
一个寒武纪地层不产实体化石、但富含*Skolithos*与*Cruziana*。能得出什么结论？
- [ ] 这个地层是贫瘠的、应当被填图为无化石
- [x] 动物存在过，可能在掘穴与蜕皮，而环境不利于壳体保存、却有利于留下遗迹
- [ ] 这些遗迹必由蠕虫留下，所以岩层是奥陶纪的
- [ ] 这些遗迹证明岩层是寒武纪的

::: solution
遗迹化石是行为与底质的证据、不是主人或年龄的证据：*Skolithos*由许多不同动物在许多时代留下。这个组合确实说的是：沉积物是软的、海相的，内底动物生活在其中，而实体化石要么未被保存（碳酸盐溶解了、没有硬体）、要么未被采集。迹理学也给出寒武纪底质革命唯一的直接证据，这就是为什么寒武纪的底一度由一个遗迹化石*Treptichnus pedum*、而不是由一个实体化石来定义。
:::

::: history
化石被争论了两千年：色诺芬尼认为它们是海洋曾覆盖陆地的证据，亚里士多德把它们当作自然的戏作，而"自然戏作"的观点存活到十七世纪，直到Robert Hooke对木材与硅化木的显微比较、以及Martin Lister与Edward Lhwyd的工作让生物学解释无法回避。Georges Cuvier与Alexandre Brongniart在1796至1812年间在巴黎盆地确立了灭绝以及化石在地层学中的使用。Mary Anning，莱姆里吉斯一个贫寒家庭的女儿，在1811年发现了第一个被正确解释的鱼龙、1823年发现了一个蛇颈龙，靠出售发现资助自己的工作，被地质学会拒之门外，并提供了William Buckland继而Cuvier确认灭绝爬行动物所依据的证据。Gideon Mantell、Roderick Murchison与Adam Sedgwick在同几十年里把古生代建在化石上。Charles Walcott的Burgess页岩专著（1911–1931）是描述古生物学的丰碑、而在其解释上也是它的警世故事。Adolf Seilacher自1950年代起的遗迹化石工作把迹理学创建为一门基于过程的学科，而Martin Glaessner 1984年关于埃迪卡拉动物群的著作把前寒武纪确立为生命史的一个篇章、不是一张白纸。Stephen Jay Gould的《奇妙的生命》（1989）把Burgess之争带给广大读者、而在其对偶然性的强调中，发起了一场关于进化是否可重演的、至今未结束的争论。
:::

## 通向何处

给化石与岩石定年的方法在[[earth-history/geological-time]]；寒武纪与埃迪卡拉纪在[[earth-history/palaeozoic]]；大灭绝及其度量在[[earth-history/mass-extinctions]]；化石与化石化学作为气候指标的使用在[[palaeoclimate/proxies]]；生物标志物与碳同位素化学地层学背后的同位素系统学在[[geochemistry/stable-isotopes]]。

::: summary 要点
- 化石是一个被腐烂、埋藏、化学、岩石年龄、露头与采集层层过滤的生物。每道过滤都是一个可测量、可部分校正的偏差。
- 软组织靠缺氧下的早期矿化幸存、不靠运气；特异埋藏化石库在时间与相上聚集，而软体生物的历史主要从那几扇窗口得知。
- 遗迹化石是一套有独立命名的独立记录，它们记录行为：寒武纪底质革命由潜穴、不是由贝壳定年。
- 记录保存约两万个物种里一个、一亿个个体里一个，所以存在与缺席是弱证据、分布是强证据。
- Signor–Lipps效应保证灭绝看起来渐近；只有独立的时间标志能区分突然的终结与缓慢的终结。
- 观测多样性必须就抽样校正——一个动物群内的稀化、整个显生宙的岩面积与采集努力——否则曲线测量的是地质、不是生命。
- 生物标志物、碳同位素与分子钟把记录延伸到实体化石之外，而它们提出的每个主张都只和其背后的污染控制一样好。
:::

## 练习

::: exercise 保存方式 {level=1}
一片叶子在灰色页岩上以一层薄黑膜显示叶脉。这是哪种保存方式？它对埋藏环境意味着什么？
::: solution
碳化（蒸馏）：挥发元素被赶跑、留下一层碳膜，这要求在细粒沉积物中快速埋藏、氧气有限、热改变低。以这种方式保存叶子的同一批岩层常常保存昆虫与鱼耳石，而通常是湖或潟湖沉积。
:::
:::

::: exercise Signor–Lipps {level=1 check="0.12"}
一个物种的真实分布区间是$5\ \mathrm{Myr}$、已知$40$个化石产点、均匀分布。求最年轻化石与真实灭绝之间的期望缺口。
::: solution
$\langle g\rangle = R/(n+1) = 5/41 = 0.12\ \mathrm{Myr}$。只有$4$个产点时期望缺口是$1\ \mathrm{Myr}$，比多数阶的界线还长——这就是为什么一个抽样糟糕的类群里"渐近衰退了$2\ \mathrm{Myr}$"几乎无法解读。
:::
:::

::: exercise 迹理学 {level=1}
为什么一个迹分类单元不能被归入一个生物属？这有什么好处？
::: solution
一条潜穴由动物的行为产生、而非常不同的动物在同样的底质里造出同样的潜穴——*Skolithos*由环节动物、腕足动物、甲壳类等留下。因此命名系统是分开的。好处是同一个迹分类单元可以在任何时代、任何大陆被认出，所以迹理学能在实体化石缺失或地方性的时段对比环境与海平面（*Skolithos*、*Cruziana*与*Nereites*遗迹相是深度带）。
:::
:::

::: exercise 稀化 {level=2 check="3.75"}
用[[#ex-rarefaction]]的群落，求$N = 10$个个体样本中期望的物种数。
::: solution
$$
S = (1-0.5^{10}) + (1-0.8^{10}) + (1-0.85^{10}) + (1-0.9^{10}) + (1-0.95^{10})
$$
$$
= 0.999 + 0.893 + 0.803 + 0.651 + 0.401 = 3.75 .
$$
样本从五个个体翻到十个增加$0.9$个物种，而下一次翻倍只增加$0.7$；曲线在$N = 20$处仍在上升，这就是一个抽样不足组合的定义、也是一个采石场的"物种计数"与一部博物馆专著的不可比的原因。
:::
:::

::: exercise 岩面积与多样性 {level=2 check="1.5"}
海洋属的多样性对着每个阶段存活的海相沉积岩面积作图，两者在显生宙上以$r^2 = 0.72$相关。若原始多样性曲线从寒武纪到现在上升$6$倍、而岩面积上升$4$倍，估计剩余的真实增长，并说明相关性不是抽样偏差之证明的两个理由。
::: solution
若多样性纯粹是抽样伪影，增长将是$4$；剩余是$6/4 = 1.5$，所以某种意义上一半的增长仍然存在。相关性不是证明的两个理由：岩面积本身是海平面的一个**结果**，而高海平面既淹没大陆（更多浅海岩、更多面积）、又创造增加多样性的生态空间（陆棚面积、地方性）——所以岩面积既是真实驱动力的指标、也是保存的指标。而相关是对*存活*岩石的，它是原始沉积与后期毁灭两者的函数、而只有后者是一个偏差。
:::
:::

::: exercise 分子钟 {level=2 check="180"}
一个分子钟把两个动物门的分歧定在$720\ \mathrm{Ma}$、$95\%$范围$650$–$800\ \mathrm{Ma}$；它们最老的化石是$540\ \mathrm{Ma}$与$525\ \mathrm{Ma}$。求隐含的"隐区间"的大小，并给出它可能是真实的两个理由、以及钟可能太老的两个理由。
::: solution
隐区间是$720 - 540 = 180\ \mathrm{Myr}$，跨钟自身不确定度是$110$–$260\ \mathrm{Myr}$。真实的可能：这些谱系小、深水或软体、没有留下化石；或者它们的骨骼演化得晚，所以冠群很老、而矿化的记录不是。钟的问题：一个比它所校准的分歧更老的校准化石会把整棵树推得太远；一个在真实速率变慢（如演化缓慢的海洋无脊椎动物）之处假设恒定速率会高估深部分歧；而一个饱和或建模糟糕的序列比对同样如此。诚实的说法是两个钟互相约束，而各门的起源位于$540$与$800\ \mathrm{Ma}$之间的某处。
:::
:::

::: exercise 推导Signor–Lipps缺口 {level=3}
形式地推导$\langle g\rangle = R/(n+1)$，然后推广：若产点在时间上不是均匀的、而是从分布区间最老的岩层采集得更多（一个常见的偏差，因为那些岩层露头最好），观测到的灭绝看起来比Signor–Lipps的预测更早还是更晚？在线性偏差情形下差多少？
::: solution
设$n$个产点是$[0, R]$上均匀分布的顺序统计量$U_{(1)} < \dots < U_{(n)}$。最大值的期望是$\langle U_{(n)}\rangle = nR/(n+1)$，所以缺口是$R - nR/(n+1) = R/(n+1)$。

现在让采样密度正比于$u$（线性偏向区间顶部），所以密度为$f(u) = 2u/R^2$、累积$F(u) = u^2/R^2$。$n$次抽取的最大值期望满足$F(\langle U_{(n)}\rangle) \approx n/(n+1)$，所以$\langle U_{(n)}\rangle = R\sqrt{n/(n+1)}$。$n = 40$时这是$0.988R$，缺口$0.012R$、对照均匀预测的$0.024R$：这个偏差让灭绝看起来**更晚**——更突然——在缺口上差两倍。相反的偏差，对区间顶部的采样少于底部，会让一次瞬时灭绝看起来渐近。两个偏差在野外都是真实的，而如果采集地点对地层层位有记录，两者都可以估计，这就是为什么现代数据库既记录剖面也记录化石。
:::
:::

::: exercise 一个特异埋藏化石库的语境 {level=3}
一个特异埋藏化石库在黑色页岩里保存软体生物。该地层厚$200\ \mathrm{m}$，盆地的沉降速率为$20\ \mathrm{m\,Myr^{-1}}$，而这个动物群知自均匀散布在该单元中的40个采石场层位里的3000件标本。估计整个动物群跨越的时间、以及每个层位代表$10\ \mathrm{cm}$剖面时单个采石场层位的跨度，并解释为什么这个"动物群"可能不是一个群落。
::: solution
该地层跨越$200/20 = 10\ \mathrm{Myr}$。$20\ \mathrm{m\,Myr^{-1}}$下$10\ \mathrm{cm}$的层位代表$10^{-4}/20\times10^{6} = 5\ \mathrm{kyr}$——而如果纹层真的是每年几毫米，一组$10\ \mathrm{cm}$的纹层可能只有几个世纪。

因此这个"动物群"是一个在千万年上平均、取自四十个各为几个世纪的时间片、并由水流送来的一切混合而成的群落的样本。它不能被用来论证这些物种住在一起、相互竞争、或在某一时刻共存，也不能被用来测量某个时刻的多样性。同样的告诫反向适用于一个代表单场风暴的贝壳层里的"群落"。正确的单位是**化石组合**（同地同时）对**生物群落**（活的群落）对**尸骸组合**（被发现时的死者），而古生态学里大多数有意思的争论都是关于在描述这三者中的哪一个。
:::
:::

::: exercise 识别最早的生命 {level=3}
$3.46\ \mathrm{Ga}$硅质岩里的显微丝体被解释为化石细菌，而$3.8\ \mathrm{Ga}$石墨里的碳有$\delta^{13}\mathrm{C} = -19\%$。列出每个主张据以评判的标准，以及各自最强的非生物替代解释。
::: solution
对丝体：构造是内生的（不是后期流体引入的）、在化学上区别于基质（原生碳、有拉曼光谱记录）、其形态不是已知的非生物矿物生长所能产生、其变形与寄主岩石一致而不是切过变形、并且在若干独立切片与地点被发现。最强的非生物替代是丝状矿物晶体——粘土、铁氧化物、纤维状硅——后期被碳化，而"细胞"是晶束的边界。

对碳同位素：石墨是原生的（与最早代矿物同一代、不是后期的脉）、寄主变沉积岩是一块地表或近地表的岩石、$\delta^{13}\mathrm{C}$显著轻于地幔碳（$-5\pm3\%$）、而数值的散布是生物的、不是单一蚀变产物。非生物的替代是高温下的费托型烃类合成，它分馏碳可达$25\%$，以及与蛇纹石化相关反应中的动力学分馏效应。共识立场是：各项标准的组合——同位素偏轻、结构上成细胞、地质上来自地表、并且可重复——在约$3.5\ \mathrm{Ga}$是有说服力的、在$3.8\ \mathrm{Ga}$是提示性的但不决定性的、而更老则未被证明。
:::
