中生代是想象的地球、也是我们正走向的地球：一个两极无冰的温室世界，二氧化碳在工业化前水平的四到十倍，北极圈之上有鳄类与棕榈树，海平面比今天高$100$–$170\ \mathrm{m}$，而一个某些指标放在$35$–$40\ ^\circ\mathrm{C}$的热带海洋——比现代行星上任何海都热。它持续了$1.86$亿年，从三叠纪末灭绝到那颗小行星，而它是地球最后一次处于这种状态。我们关于未来几个世纪气候所说的一切，都以这样或那样的方式锚定在我们对这一个了解得多好。

它也是我们生活在其中的世界被组装的那个时代。Pangaea碎裂，而大陆的位置、海洋的宽度、山带、石油、盐与季风都是中生代的遗产。被子植物、蜂、哺乳动物、海洋的现代动物群与珊瑚礁是中生代的发明。本章讲这次碎裂、这个温室、以及造就了生物世界的两大生物创新——被子植物与捕食的升级。

## Pangaea分开

::: example 南大西洋的盐 {#ex-salt}
当南美洲与非洲分开时，年轻的南大西洋是一个狭窄的、受限的盆地，大西洋无法完全循环进去，而在约$129$与$121\ \mathrm{Ma}$之间它沉积了一层厚达$2\ \mathrm{km}$的石盐，在$1.3\times10^{6}\ \mathrm{km^2}$的面积上。把平均盐厚取作$800\ \mathrm{m}$、石盐密度取作$2160\ \mathrm{kg\,m^{-3}}$、海水含盐取作$3.5\%$。求必须蒸发的海水体积、以及在$8\ \mathrm{Myr}$里供给它所需的通过门道的平均流入。
::: solution
盐体积是$1.3\times10^{12}\ \mathrm{m^2}\times800\ \mathrm{m} = 1.04\times10^{15}\ \mathrm{m^3}$，质量为
$$
1.04\times10^{15}\times2160 = 2.2\times10^{18}\ \mathrm{kg}.
$$
在含盐$3.5\%$下这需要$6.4\times10^{19}\ \mathrm{kg}$的海水，一个$6.2\times10^{16}\ \mathrm{m^3}$的体积，这是世界大洋的$0.005\%$。在$8\ \mathrm{Myr}$里所需的平均流入是
$$
\frac{6.2\times10^{16}}{2.5\times10^{14}\ \mathrm{s}} = 250\ \mathrm{m^3\,s^{-1}},
$$
这小于亚马逊的流量、约为现今大西洋翻转输送的$10^{-5}$。

这个练习点出真正的要点：盐不受海水供给的限制，那是实际上无限的，而受**受限**的限制——盆地必须被切断到蒸发超过流入、而盐不被冲走。所以Aptian盐给Walvis海岭与Romanche转换断层仍高于环流的那一刻定年，而其顶给海道深到大西洋淹没盆地的那一刻定年。它也把烃系统埋在其下：巴西的盐下石油就在同一层盐之下，在海水入侵之前形成的淡水湖里沉积的湖相烃源岩里。
:::

碎裂由海底的磁异常定年，它给出地壳的年龄、而一旦极点与板块运动已知，就给出任何时刻的几何。这个序列是：中大西洋在$200$–$170\ \mathrm{Ma}$，带$201.6\ \mathrm{Ma}$的中大西洋岩浆省熔岩；非洲与南美洲的分离在约$133\ \mathrm{Ma}$于南部开始、在$100\ \mathrm{Ma}$完成；赤道大西洋的打开与非洲与南极洲的分离在$160$–$130\ \mathrm{Ma}$；印度的北飞以$120\ \mathrm{mm\,yr^{-1}}$从$120\ \mathrm{Ma}$，是测过的最快的大板块，以$66\ \mathrm{Ma}$的Deccan结束；澳大利亚与南极洲的分离在$95$–$45\ \mathrm{Ma}$；以及Drake Passage的打开，其时间点是古海洋学里最被争论的数字之一。

::: example 四倍的二氧化碳 {#ex-cretaceous-co2}
白垩纪大气$\mathrm{CO_2}$从硼同位素、烯酮、土壤碳酸盐与气孔指数估计为$1000$–$2000\ \mathrm{ppm}$，对照工业化前的$280\ \mathrm{ppm}$。求辐射强迫与带一个现代反馈参数的平衡增暖，并与白垩纪深时温度重建比较，后者把全球均值放在工业化前之上$8$–$12\ \mathrm{K}$、热带海表在现代之上$5$–$10\ \mathrm{K}$。
::: solution
$$
\Delta F = 5.35\ln\frac{1400}{280} = 5.35\times1.609 = 8.6\ \mathrm{W\,m^{-2}},
$$
而带一个无反馈加现代反馈参数$0.8\ \mathrm{K\,(W\,m^{-2})^{-1}}$，
$$
\Delta T = 6.9\ \mathrm{K}.
$$
那解释了全球均值，但没解释这个模式。中生代与白垩纪的极点比今天暖$15$–$25\ \mathrm{K}$，有无霜森林到$80^\circ$纬度、而冰盖没有证据，而热带只暖了$5$–$10\ \mathrm{K}$。极地增暖对热带增暖之比——**均和性**——远大于任何现代气候模型产出的，那是"中生代均和气候问题"。

提出的解并不古怪：当没有海冰、当大气潮湿时极地放大更强，因为水汽是一个在寒冷中凝结出去的温室气体；极地的高云增暖；冰盖反照率的缺席在高纬度值几度；而进入极地盆地的海洋热输送，那些盆地形状不同、连通不同，是更大的。当边界条件被纠正、而云反馈被允许是强的时，$1120\ \mathrm{ppm}$的模型重现了记录的大部分。残差——来自TEX86古温计的热带海表$40\ ^\circ\mathrm{C}$的主张——更可能是一个校准问题、不是一个气候问题，而关于它的争论是一个指标的生物学如何变成一个地质学悖论的案例研究。
:::
:::

## 缺氧的海洋

::: definition 海洋缺氧事件 {#def-oae}
**海洋缺氧事件（OAE）**是中白垩世的一些间隔，其中OAE 1a（$120\ \mathrm{Ma}$）、OAE 1b、OAE 2（$94\ \mathrm{Ma}$）与OAE 3最出名，其中世界大洋的深水与中层水变得缺氧发黑、而富有机质的黑色泥在每个陆缘与每个陆表海里积累。每一个都由一个$1$–$2.5\%$的正碳同位素漂移、钼铀铼的富集、透光带里绿硫细菌的生物标志物（尽管后一个主张已被重检并部分撤回）、以及一个温度的上升标记。它们是世界石油很大一部分的烃源岩。
:::

::: proposition 缺氧事件需要一个暖的海洋、一个营养供给、与一个陷阱 {#prop-oae}
深海的氧供给靠从地表的通风，而氧的溶解度随温度下降：一个白垩纪海洋生来就氧较少、持有的也较少。需求是有机质的雨，它由营养供给设定，而中白垩世有大量——来自大火成岩省的、来自年轻山带的风化通量、以及从一个缺氧海底释放的磷。第三个要求是一个陷阱：一个水柱稳定层化的盆地，所以氧最小值带可以加厚而不被通风。三者去掉任何一个事件就不发生，这就是为什么中白垩世有好几次、而古近纪一次也没有。
:::

::: example 白垩纪碳扰动的大小 {#ex-oae2-carbon}
OAE 2由一个体相海相碳酸盐里$1.5\%$的正$\delta^{13}\mathrm{C}$漂移标记、持续约$800\ \mathrm{kyr}$。一个正漂移意味着比通常更多的有机碳被埋藏，使海洋的溶解无机碳在同位素上偏重。把海洋的无机碳取作$3.8\times10^{18}\ \mathrm{mol}$、分馏取作$25\%$，求额外埋藏的有机碳。
::: solution
由[[earth-history/oxygen-proterozoic]]的质量平衡，一个$\Delta\delta$的漂移对应于作为有机质埋藏的碳的分数改变$\Delta f = \Delta\delta/\Delta$。把额外埋藏写成一个作用时间$\tau$的总埋藏通量的分数、并把现代埋藏通量取作$1\times10^{13}\ \mathrm{mol\ C\ yr^{-1}}$：
$$
\Delta f = \frac{1.5}{25} = 0.06,
$$
所以有机埋藏速率上升了总碳通量的$6$个百分点。在$8\times10^{5}\ \mathrm{yr}$里、以一个$5\times10^{13}\ \mathrm{mol\ yr^{-1}}$的总埋藏通量，额外的碳是
$$
0.06\times5\times10^{13}\times8\times10^{5} = 2.4\times10^{18}\ \mathrm{mol} = 29{,}000\ \mathrm{Gt\ C}.
$$
那是海洋溶解无机碳的十分之一，在不到一百万年里埋掉，而这就是白垩纪既是最暖的、也是显生宙产烃最多的间隔的理由：同一个抽走二氧化碳的事件留下了石油。
:::
:::

## 活着的中生代

::: definition 中生代海洋革命 {#def-mmr}
Vermeij的**中生代海洋革命**是始于侏罗纪与白垩纪的捕食与防御的升级：钻蚀与压碎的捕食者（裸鳃类、蟹、真骨鱼、沧龙）选择更厚的壳、更紧的壳口、棘、掘穴、以及扁平的、表栖的、低活动性的软体动物行会的丧失，后者主导了古生代。证据在壳本身里——厚度对高度比的增加、钻孔在上升比例的软体动物壳里的出现、石燕贝类与长身贝类腕足类被内底双壳类取代——而它是化石记录里一场军备竞赛塑造整个动物群的最清楚案例。
:::

**被子植物**是另一大中生代创新，而Darwin把它们的"强烈而突然的出现"称为一个"可恶之谜"，理由与寒武纪是的一个相同：它们出现在早白垩世（在花粉与叶记录里约$130\ \mathrm{Ma}$，最老的冠群化石稍早）、而在$40\ \mathrm{Myr}$内生态上占主导。解释不是它们演化得快、而是它们为一个受扰动的、高二氧化碳的、易燃的景观而造：相对于针叶树，它们生长快、组织廉价、高效用水、带一个高的叶脉密度，而它们与它们的传粉者与传播者共同演化——蜂出现在白垩纪中点，甲虫在其前，鸟与有袋类在其后。到马斯特里赫特期高纬度的森林是落叶被子植物，而最早的禾本科存在但不重要；草原与食草哺乳动物是新生代的发明。

::: example 一个非常大的动物的骨骼 {#ex-dinosaur-bone}
一根承重骨的强度按其横截面积缩放，所以静态相似要求直径$d \propto M^{1/2}$。哺乳动物与鸟类的经验数据给出$d \propto M^{0.38}$，因为大的动物站得更直立、缩短其力臂。一个$5\ \mathrm{t}$的兽脚类有一个$10\ \mathrm{cm}$的股骨骨干中段直径。求每种缩放下一个$30\ \mathrm{t}$动物所需的直径，并说明经验指数对姿态意味着什么。
::: solution
静态相似：$d = 10\times(30/5)^{0.5} = 24.5\ \mathrm{cm}$。经验：$d = 10\times6^{0.38} = 19.9\ \mathrm{cm}$。

$20\ \mathrm{cm}$的动物比几何的那个窄$20\%$，而差别由姿态买单：一个大动物把其肢体移向垂直，这为同样质量减小骨上的弯矩，而它也加宽足部、降低相对速度。最大的兽脚类与最大的蜥脚类处于这个力学允许的极限——一个$30\ \mathrm{t}$的兽脚类接近股骨能在可用空间内建造的最大值，而$70\ \mathrm{t}$级的蜥脚类只靠四足行走、靠减小骨骼质量的气腔椎骨、以及靠一个更接近柱子而不是杠杆的柱状肢体达到它们的尺寸。平方立方律不阻止巨型化，但它写下设计任务书。
:::

::: warning "中生代是一个温室，所以它是未来的类比"
它对某些东西是一个类比、对另一些是一个坏的。中生代没有冰盖、有一个不同的海岸线、一个不同的海洋环流、其大部分时间没有南极绕极流、有不同的植被、而二氧化碳在工业化前的四到十倍，所以它的*平衡*气候不是一个在$550\ \mathrm{ppm}$的世界的预报。可传递的是敏感度：中生代说在四倍二氧化碳时世界暖$8$–$12\ \mathrm{K}$、极点暖热带两三倍、海平面高几十米、而中白垩世的缺氧事件显示当一个暖的海洋也被加载营养时会发生什么。不可传递的是时间尺度：白垩纪的改变用几十万年，而当前的改变用几十年。
:::

::: solution
记录显示$80^\circ$纬度有无霜森林、无冰，暗示极地增暖$15$–$25\ \mathrm{K}$、对照热带增暖$5$–$10\ \mathrm{K}$——一个比任何模型对一个可信的二氧化碳水平给出的都平得多的经向梯度。解是更强的极地放大（极点更多的水汽与高云、无海冰、进入极地盆地更大的海洋热输送），而残差的分歧是中温指标，特别是TEX86，正被重检的理由之一。
:::
:::

::: history
Alfred Wegener 1912年的Pangaea是一个关于大陆拼合的假说、而被拒绝了五十年；1960年代的海底扩张图把它变成一个年代学，而近三十年由转换断层的卫星测高与大洋钻探年龄驱动的板块重建，使碎裂成为一个已定年、可检验的历史。Charles Darwin在1879年给Joseph Dalton Hooker写信谈被子植物突然出现的"可恶之谜"；这个谜在1980与1990年代因认识到白垩纪的花粉与叶化石记录比任何人以为的都丰富、而辐射虽然快却不是瞬时的而被解开。Georg Wagner与Peter Franks 1990年代的气孔指标，以及Andy Ridgwell、Ellen Schrag与他人的硼同位素工作，把植物与有孔虫变成了二氧化碳计。中白垩世黑色页岩在1970年代从大西洋钻探被描述、并由Kenneth Hsu、然后由Dean、Arthur与他在1980年代综合为"海洋缺氧事件"；1992年提出的透光带绿硫细菌的生物标志物主张在2004年大部分被撤回，当时同样的分子被显示由蓝细菌制造。Gregory Vermeij 1977年的中生代海洋革命是靠壳本身的升级的经典论述，而辽宁的带羽恐龙，从1996年的*Sinosauropteryx*开始，把鸟的起源从一个比较解剖学论证变成一个直接记录。
:::

## 通向何处

碎裂及其岩浆作用在[[physical-geology/plate-tectonics]]与[[physical-geology/igneous-rocks]]；事件的碳循环在[[biogeochemistry/carbon-deep-time]]；海洋的化学与层化在[[oceanography/ocean-chemistry]]与[[oceanography/overturning]]；白垩纪气候建模在[[palaeoclimate/deep-time]]；这一切的终结在[[earth-history/mass-extinctions]]；而余波在[[earth-history/cenozoic]]。

::: summary 要点
- Pangaea从200 Ma起在一个已定年的序列里碎裂，而其间接开与关的那些海洋门道控制着这个故事其余部分的气候、环流与生物地理。
- 南大西洋的Aptian盐给年轻海洋的受限定年、而把盐下石油系统埋在其下。
- 白垩纪1000–2000 ppm的二氧化碳给出7–9 K的强迫，它解释了全球均值、但没解释极点的温暖：均和气候问题是关于极地放大的。
- 中白垩世海洋缺氧事件是一个暖的、富营养的、层化的海洋的产物，而它们是世界石油许多的烃源岩。
- 中生代海洋革命与被子植物辐射是造就现代动物群与现代植物群的两个生物事件，两者都由升级与扰动驱动、不是由进步。
- 巨型化是一个力学问题：骨直径按大约M^0.4缩放，而最大的恐龙达到了姿态与气腔化所能绕开的极限。
- 中生代是平衡气候敏感度与极地放大的一个类比、而是一个变化速率的差的类比。
:::

## 练习

::: exercise 扩张速率 {level=1 check="23"}
赤道南大西洋宽$3000\ \mathrm{km}$、在$130\ \mathrm{Ma}$前开始打开。求平均全扩张速率，单位$\mathrm{km\,Myr^{-1}}$，并解释为什么一个$140\ \mathrm{mm\,yr^{-1}}$的速率不可能是对的。
::: solution
在$130\ \mathrm{Myr}$里打开$3000\ \mathrm{km}$所需的平均全速率是
$$
\frac{3000}{130} = 23\ \mathrm{km\,Myr^{-1}} = 23\ \mathrm{mm\,yr^{-1}} .
$$
问题里的$140\ \mathrm{mm\,yr^{-1}}$会给出$18{,}200\ \mathrm{km}$，是观测宽度的六倍，而那是快速扩张的东太平洋海隆的速率、不是一个慢的、贫岩浆陆缘的。这个练习是关于半速率与全速率之别、以及慢速与快速扩张之别的警告，两者合起来是这个题目里最常见的算术错误。
:::
:::

::: exercise 强迫 {level=1 check="7.4"}
求$1120\ \mathrm{ppm}$的二氧化碳相对$280\ \mathrm{ppm}$的辐射强迫。
::: solution
$\Delta F = 5.35\ln(4) = 7.4\ \mathrm{W\,m^{-2}}$。以一个每一倍增$3\ \mathrm{K}$的敏感度，这是$6\ \mathrm{K}$的增暖，而以白垩纪每一倍增$6\ \mathrm{K}$的反馈，$12\ \mathrm{K}$。
:::
:::

::: exercise 缺氧事件 {level=1 check="0.06"}
一个OAE碳同位素漂移是$1.5\%$。以一个$25\%$的分馏，它暗示作为有机质埋藏的碳的分数改变多少？
::: solution
$\Delta f = 1.5/25 = 0.06$，即碳通量的六个百分点。因为漂移是正的，这个改变是埋藏的增加；一个同样大小的负漂移是一个减少、或一个轻碳的输入。
:::
:::

::: exercise 盐 {level=2 check="9.4"}
用[[#ex-salt]]的方法，求产生一层$1200\ \mathrm{m}$厚、在$1.3\times10^{6}\ \mathrm{km^2}$上的盐层所需的海水体积（单位$10^{16}\ \mathrm{m^3}$）。
::: solution
盐体积$1.56\times10^{15}\ \mathrm{m^3}$，质量$3.4\times10^{18}\ \mathrm{kg}$，海水$9.6\times10^{19}\ \mathrm{kg} = 9.4\times10^{16}\ \mathrm{m^3}$。这个标度对厚度是线性的，所以$1200\ \mathrm{m}$的答案是$800\ \mathrm{m}$情形的$1.5$倍。
:::
:::

::: exercise 骨的标度 {level=2 check="2.83"}
两只蜥脚类在质量上相差$8$倍。在静态相似（$d \propto M^{0.5}$）下所需股骨直径相差多少倍、在经验指数$0.38$下相差多少倍？（填入静态相似的倍数。）
::: solution
静态：$8^{0.5} = 2.83$。经验：$8^{0.38} = 2.21$。在纯几何载荷下八倍质量的较重动物必须在股骨上厚近三倍，而来自更直立姿态的$20\%$的节省是大型哺乳动物与恐龙骨头里一个真实的、可测量的差别。
:::
:::

::: exercise 被子植物的多样化 {level=2 check="0.09"}
被子植物科从$130\ \mathrm{Ma}$的约$10$个升到$90\ \mathrm{Ma}$的约$400$个。求每Myr的平均净多样化速率，并与一个典型的背景科起源速率比较。
::: solution
$r = \ln(400/10)/40 = \ln 40/40 = 3.69/40 = 0.092\ \mathrm{Myr^{-1}}$，扣除灭绝后约每百万年$9\%$。对科来说这是高的但不非凡——GOBE与灭绝后的辐射达到类似的数值——那是"可恶之谜"的诚实答案：被子植物辐射对一个植物类群是快的、但在一次灭绝之后一个适应辐射之旁是平常的。
:::
:::

::: exercise 推导均和性 {level=3}
一个水球模型里的经向温度梯度按赤道-极能量输送对辐射阻尼之比缩放。若赤道-极日照差不变于今天、而极地暖$20\ \mathrm{K}$、热带暖$7\ \mathrm{K}$，梯度改变了多少倍，而这对海洋与大气热输送要求什么？
::: solution
今天的表面梯度从赤道到极点约$30\ \mathrm{K}$；白垩纪梯度是$30 - 20 + 7 = 17\ \mathrm{K}$，一个$0.57$的因子。扩散能量预算给出输送正比于梯度除以阻尼，所以要么输送在同样阻尼下上升约$1.8$倍，要么阻尼下降（一个更潮湿、光学更厚的极地大气阻尼更少），要么两者都是。

所需输送是有意思的部分：现代海洋在$30^\circ\mathrm{N}$输送约$1.3\ \mathrm{PW}$、大气约$3\ \mathrm{PW}$。一个有开阔北大西洋、一个横贯热带的Tethys海道、与无南极屏障的白垩纪海洋可以合理地输送更多向极的热，而今天被限制在北大西洋的高纬度深水形成，可能也在北太平洋发生。重现这个梯度的模型靠增加极地的水汽与云反馈做到、不是靠发明一个海洋，那是当前的共识。
:::
:::

::: exercise 读盐下 {level=3}
一个地震剖面显示，从底部起：大陆裂谷火山岩与湖相页岩；一个带石盐与钾盐的厚蒸发岩序列；一个浅海碳酸盐台地；以及开阔海远洋白垩。解释这段历史、用可用的方法给每个阶段定年、并说明控制储层质量的是什么。
::: solution
这个序列是经典的被动陆缘碎裂：**裂陷**带大陆伸展、火山作用与封闭的淡水湖（湖相页岩是烃源岩，而它们的油是蜡状低硫的）；**海水受限**带蒸发超过流入，沉淀石盐然后钾盐，这需要一个低纬度的干旱气候与一个浅的、渗漏的门道；门道加深时的**淹没**，给出浅海碳酸盐（构成储层的微生物与包粒碳酸盐）；以及向开阔海白垩的**沉降**。

定年：裂谷火山岩靠氩-氩或铀-铅；盐的底靠第一批海相微体化石或页岩里的铼-锇；盐的顶靠海相浮游化石的首次出现、以及地壳成为洋壳后的磁异常；白垩靠颗石与有孔虫带。储层质量受原始碳酸盐相（粒度与矿物）、受造出孔洞与模孔的大气淡水和成岩、以及受盖层——盐本身，那是已知最好的盖层、也是盐下圈闭如此之大又如此难勘探的理由——控制。
:::
:::

::: exercise 作为类比的中生代 {level=3}
一份政策简报写道："白垩纪二氧化碳是$1400\ \mathrm{ppm}$而海平面高$100\ \mathrm{m}$，所以在$550\ \mathrm{ppm}$我们应当预期几十米的海平面上升。"用平衡敏感度、冰盖调整的时间尺度、以及一个无冰世界与一个有冰世界之别的概念，评估这个论证。
::: solution
这个论证把三样东西混为一谈。白垩纪比现今高$100$–$170\ \mathrm{m}$的海平面主要是一个根本没有冰盖的世界里**热膨胀与海盆几何**；可归于冰的部分是零，因为没有冰可化。今天的$550\ \mathrm{ppm}$把世界承诺给格陵兰与西南极冰盖在数千年里的融化，那是$15$–$20\ \mathrm{m}$，以及一个来自东南极在更长时间里较小的贡献。

平衡敏感度可传递：白垩纪与始新世都指示二氧化碳倍增使行星暖$3$–$6\ \mathrm{K}$，而那正是政策简报应当使用的数字。**速率**不可传递：白垩纪的改变由火山作用在几十万年里强迫，而生物地球化学与冰盖系统有时间达到平衡。正确的说法是，在$550\ \mathrm{ppm}$平衡增暖是$4$–$5\ \mathrm{K}$，已承诺的海平面上升是数千年里几米，而近一个世纪的上升由冰动力学与热惯性设定、不是由白垩纪。
:::
