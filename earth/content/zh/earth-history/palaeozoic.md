Darwin比任何人都更了解这个反对意见。若进化靠小的变异的缓慢积累工作，为什么化石记录显示主要的动物群一起出现、完全成形地在最早的寒武纪岩石里，其下没有祖先？在《物种起源》的最后一章他承认这个论证"尚未完全解决"，而一个世纪里答案是祖先必定存在过、但太小太软而无法保存——一个方便的假说，因为它无法被检验。

它们现在已被找到，而它们不是祖先。埃迪卡拉生物群，1946年在南澳大利亚的Ediacara被发现、而从1980年代起被定年为$575$与$539\ \mathrm{Ma}$之间，是大的、复杂的、而几乎与任何后来之物都不像的：绗缝的、分形的、模块的生物，没有口、没有肠、没有肛门、没有骨骼，其中大多数根本没有留下后代。在它们与寒武纪动物群之间是小壳化石、最早的潜穴与最早的礁。在$539\ \mathrm{Ma}$之后的两千五百万年里发生的事是动物发明了骨骼、眼睛、颌、潜穴、壳、游泳、爬行、捕食与滤食——而在十亿年真核静止的背景上、在一个地质学瞬间里做到了。本章讲那个事件、讲随后古生代那四亿年、以及讲这个间隔里陆地与海洋里的生命两次像氧那样果断地改变了行星化学的时刻。

## 爆发，以及它是什么

::: definition 寒武纪辐射 {#def-cambrian-radiation}
**寒武纪爆发**或**寒武纪辐射**是基本上所有现生动物门、以及若干不现生的门，在$539$与$514\ \mathrm{Ma}$之间，在海洋化石记录里的出现。它的证据有三重：**小壳化石**（$525$–$515\ \mathrm{Ma}$），是亲缘关系不确定的矿化板、刺与管；**遗迹化石革命**，潜穴第一次深入到沉积物深处、摧毁了微生物席地；以及**特异埋藏化石库**——中国的澄江与马鞍山，在$518\ \mathrm{Ma}$，Burgess页岩在$508\ \mathrm{Ma}$，格陵林的Sirius Passet在$518\ \mathrm{Ma}$——它们把软体动物群详细保存下来。**寒武纪底质革命**是海床从一个坚硬、粘、层理的席地变成一个混合、含氧、被掘的沉积物的伴随转变，而它可以说是更重要的事件，因为它改变了此后每个动物的环境。
:::

::: example 它究竟多快？ {#ex-explosion-rate}
三十个动物门在$539$与$514\ \mathrm{Ma}$之间首次出现在化石记录里。真核生物在此之前存在了约$1800\ \mathrm{Myr}$，而动物至少$85\ \mathrm{Myr}$（最老的海绵生物标志物以及Doushantuo与埃迪卡拉的候选者）。求寒武纪首次出现的速率，单位门每百万年，并与整个前寒武纪真核记录上的速率比较。
::: solution
$$
\frac{30\ \text{phyla}}{25\ \mathrm{Myr}} = 1.2\ \text{phyla per Myr}, \qquad \frac{30\ \text{phyla}}{1800\ \mathrm{Myr}} = 0.017\ \text{phyla per Myr}.
$$
寒武纪速率是前寒武纪平均的七十倍。两个告诫让这个数字诚实。第一，"首次出现"不是"起源"：每个寒武纪首次出现都是一个最小年龄，而分子钟把许多门放在埃迪卡拉纪或拉伸纪，这会把寒武纪速率降两到三倍的因子、把前寒武纪的升高。第二，门是一个人类的分类，而身体构型的数目不是一口钟；一个更公平的度量是形态的离散度，而它在早寒武纪陡峭上升、然后，值得注意地，没有再上升多少。

真正的谜不是速率高、而是这个**模式**对渐变论是错的：这些群以一个大致生态的次序出现——掘穴者，然后食草者，然后带眼的捕食者，然后最早的礁——仿佛生态系统正在以一个次序被组装，而每个创新为下一个打开一个生态位。
:::

## 为什么是那时？四个候选原因

**氧。**胶原合成，因此中胶层、角质层与真体腔，需要依赖氧的羟化，而一个厘米大小、不扁平的动物需要一个循环系统或大量的氧。新元古代氧上升到现今水平的几个百分点，由钼与铀同位素在$0.8$与$0.55\ \mathrm{Ga}$之间定年，先于爆发几千万年，而$0.55$–$0.52\ \mathrm{Ga}$处第二次较小的上升先于寒武纪动物群。相关性是好的、机制是可信的，但关系并不紧：海绵耐现今氧的几个百分点，而氧上升与爆发之间的时间差与定年不确定度同量级。

**海洋化学。**新元古代与寒武纪海洋相对于碳酸盐饱和度富含钙与镁，而最早的骨骼是高镁方解石与文石、从这样的水里更容易沉淀的矿物。这个论证因认识到"文石海"与"方解石海"的振荡不像声称的那样干净而被削弱，但论点以一个较弱的形式存活：寒武纪海洋相对于碳酸钙比现代海洋更接近饱和，所以造一个壳更便宜。

**捕食。**最早的壳在很大程度上是甲。证据是直接的：小壳化石在攻击后被修复、壳里的钻孔、最早的钻蚀捕食者、以及眼睛在约$515\ \mathrm{Ma}$在三叶虫与奇虾类里的出现，它把捕食从化学的与随机的变成视觉的与有目标的。一旦一个动物能看见并猎食，一场军备竞赛随之而来，而军备竞赛是快的。

**遗传学。**发育工具箱——Hox簇及其余——存在于最简单的动物里、而在整个动物界深度同源，所以一个身体构型的遗传能力早在身体构型之前就已存在。工具箱需要的是生态选择，而这是这个论证的现代综合：基因使爆发成为可能，生态使它发生，而时间由氧与化学设定，它们使大的、活跃的、矿化的动物值得建造。

## 古生代，按次序

::: definition Sepkoski的三个演化动物群 {#def-faunas}
Jack Sepkoski 1981年对10,500个海洋属在科级别上的分析把显生宙动物群分成三个有不同辐射历史的组合。**寒武纪演化动物群**（三叶虫、鹦鹉螺类、无铰腕足类、古杯类）在早寒武世上升、在其接近末尾处达到峰值、并以低多样性存活。**古生代演化动物群**（有铰腕足类、苔藓虫、海百合、珊瑚、笔石、头足类）在奥陶纪上升、主导了两亿五千万年、而在二叠纪末被削减到其峰值的三分之一。**现代演化动物群**（双壳类、腹足类、十足目与新颌类甲壳类、真骨鱼级别的鱼、海胆类）在二叠纪之前可以忽略、在三叠纪使其多样性份额翻倍、并在侏罗纪达到与古生代动物群的持平。三个动物群在生态上不同：现代动物群的特征是内底习性、更高的运动性、更强的捕食与啃食强度、而最重要的是中生代海洋革命所记录的那场升级。
:::

::: definition 大奥陶纪生物多样性事件 {#def-gobe}
寒武纪爆发产出了身体构型；**GOBE**，约在$485$与$450\ \mathrm{Ma}$之间，产出了其内的多样性。海洋科多样性大约翻三倍，从约$100$个属的科到约$300$个，而这个改变是生态的：寒武纪动物群由软基底上活动的表食草者与捕食者主导，而奥陶纪动物群由固着的滤食者——腕足类、苔藓虫、海百合、珊瑚、笔石、以及最早的复杂礁——在一个三维分层的、硬的、被掘的、被胶结的基底上生活。驱动力通常被取作底质革命已经走完其历程、随着Gondwana与Laurentia汇聚浅海陆表海的扩散、以及使海洋含氧的气候变冷三者的组合。
:::

**奥陶纪**以五大之一结束：Hirnantian灭绝，在$445\ \mathrm{Ma}$，与一次短暂而剧烈的Gondwana冰川、以及一个移走热带陆棚的海平面下降相关联，并带有$\delta^{13}\mathrm{C}$下降与镍下降的同位素证据，它被读作大火成岩省的火山作用。它取走了约$25\%$的海洋属。

**志留纪**与**泥盆纪**是陆地殖民的世纪。隐孢子——最早陆生植物的壁——出现在约$470\ \mathrm{Ma}$；*Cooksonia*，一个厘米高、带一个孢子囊而无叶的轴，在$425\ \mathrm{Ma}$；Rhynie硅质岩的动物群与植物群在$410\ \mathrm{Ma}$，带螨、跳虫与最早已知的寄生真菌；最早的森林（*Wattieza*，然后是前裸子植物*Archaeopteris*）在约$385\ \mathrm{Ma}$；而最早的深根与真正的土壤在约$370\ \mathrm{Ma}$。后果是全球性的。根与菌根把岩石破碎、并通过增强的风化抽走$\mathrm{CO_2}$；交付给海洋的营养负荷使其富营养化，而按Algeo与Scheckler的"营养崩溃"假说，造成了晚泥盆世的缺氧与灭绝；而最早的土壤改变了大陆的颜色、排水与化学。

**泥盆纪**也是鱼的世纪：*Dunkleosteus*这样的盾皮鱼、最早的鲨、以及走出水来的肉鳍鱼亚纲的后裔。*Tiktaalik*在$375\ \mathrm{Ma}$有一个颈、一个腕、一个胸腔；*Acanthostega*在$365\ \mathrm{Ma}$有八个趾、而四肢仍为游泳而造。这个过渡不是一次对陆地的争夺、而是对浅的、有植被的、缺氧的水的缓慢适应。

::: example 石炭纪的氧峰值 {#ex-carboniferous-o2}
化石碳的燃烧是我们呼吸的大气氧的源，因为作为煤、油与甲烷埋掉的碳没有被呼吸回来。在石炭纪与二叠纪，初级生产被埋藏的分数从其现代的$0.1\%$升到也许$1\%$，而大气氧达到$30$–$35\%$。把现代有机碳埋藏速率取作$1\times10^{13}\ \mathrm{mol\ C\ yr^{-1}}$、石炭纪速率取其十倍、而氧库取作$3.7\times10^{19}\ \mathrm{mol}$。若这个超量埋藏持续$20\ \mathrm{Myr}$，氧库会以现今大气水平的多少上升，而为什么真正的答案小得多？
::: solution
超量通量是$9\times10^{13}\ \mathrm{mol\ yr^{-1}}$，所以在$2\times10^{7}\ \mathrm{yr}$上加入量是
$$
9\times10^{13}\times2\times10^{7} = 1.8\times10^{21}\ \mathrm{mol},
$$
这是现今氧库的$49$倍。真正的答案是氧只上升了约$15$个百分点，因为产生的氧在同一批还原碳后来出露时被它的氧化消耗、被从沼泽释放的甲烷与一氧化碳的氧化消耗、而最重要的是被**火**消耗：一个高氧大气烧得更完全，而晚石炭世的木炭记录显示一个火频率的阶，恰好在氧最高之处。碳-氧循环通过火自我限制，那是David Bellocq与同事以及Timothy Scott与同事的论证，而这就是为什么石炭纪煤层也是岩层记录里最早的广泛木炭。

尽管如此生物后果是真实的。昆虫通过气管扩散呼吸，而一根气管的扩散能力以与氧分压成正比的直接关系限制身体尺寸；翼展$70\ \mathrm{cm}$的*Meganeuroid*蜻蜓、$2.5\ \mathrm{m}$的似马陆*Arthropleura*、以及最早的巨型蜻蜓稚虫与$30$–$35\%$的氧一致、与$21\%$不一致。这个关系在活昆虫里可测量，它们在高氧箱里长得更大、在低氧箱里更小，而它是化石记录里大气化学给动物设计设定上限的最清楚案例。
:::
:::

**石炭纪**与**二叠纪**也是Pangaea聚合的时期：Gondwana与Laurentia及Baltica的碰撞建造了Variscan与Appalachian山脉、闭合了曾是Iapetus的海洋、并创造一个有干旱内部、季风边缘、与地球上最大沙漠的超大陆。赤道带的煤沼泽——反复海侵与泥炭积累的旋回层，每个旋回几米厚、代表几万年——是那个格局的产物：一个低洼的、沉降的、赤道海平面处的带，还没有任何陆生植物能在干地上建造深泥炭。当气候变干、冰退却，沼泽就走了，而随之而去的是二叠纪末与现今之间碳循环最大的扰动。

::: example 一次冰川移走多少陆棚？ {#ex-shelf}
从海岸到$200\ \mathrm{m}$深度的现代大陆棚面积为$1.9\times10^{7}\ \mathrm{km^2}$，其中约$1.0\times10^{7}\ \mathrm{km^2}$浅于$100\ \mathrm{m}$。Hirnantian冰川使海平面下降了估计$80$–$100\ \mathrm{m}$。求失去的陆棚面积分数，并解释为什么这次灭绝选择性地针对地方性的陆表海类群、而不是深水动物群。
::: solution
$100\ \mathrm{m}$的下降移走$1.0\times10^{7}/1.9\times10^{7} = 53\%$的陆棚。因为一个冰室世界的陆棚在热带比今天的窄，*热带*陆棚——伟大的奥陶纪腕足类、苔藓虫与三叶虫动物群的生境——的损失更大，而幸存的陆棚更凉、更不广。

选择性从种-面积关系而来：分布区小、扩散低的地方性陆表海类群其面积被砍半而灭绝，而广适的、更深水的、育幼的类群以其更大的分布区在斜坡与避难所里幸存。这个预言可检验、而已被检验：Hirnantian幸存动物群由更深水与更广适的属主导，而灭绝集中在Gondwana邻近陆棚的热带古纬度。这是灭绝机制里最简单的一种，而难得的是，生境损失的算术足以解释这个模式。
:::
:::

::: example 一层煤里的碳 {#ex-coal-seam}
一个宾夕法尼亚亚纪煤层厚$1.5\ \mathrm{m}$、覆盖$10{,}000\ \mathrm{km^2}$、容重为$1300\ \mathrm{kg\,m^{-3}}$、含碳$60\%$。它由压实十倍的泥炭形成。求埋藏的碳的质量、它代表的氧、以及它加入现今大气氧库（$3.7\times10^{19}\ \mathrm{mol}$）的分数。
::: solution
$$
M_C = 1.5\times10^{10}\ \mathrm{m^2}\times1300\times0.60 = 1.2\times10^{13}\ \mathrm{kg} = 9.8\times10^{14}\ \mathrm{mol\ C},
$$
所以这层煤代表$9.8\times10^{14}\ \mathrm{mol}$被生产而未被消耗的氧——现今大气库的$2.6\%$，来自一层煤。欧美煤带有数百层煤、在$10^{6}\ \mathrm{km^2}$上，所以预算闭合了：在这个水平上反复埋藏$50\ \mathrm{Myr}$正是把氧从$21\%$推到$32\%$所需的扰动。

泥炭厚度是另一个有用的数字：$1.5\ \mathrm{m}$的煤是$15\ \mathrm{m}$的泥炭，而泥炭以$0.1$–$1\ \mathrm{mm\,yr^{-1}}$积累，所以这层煤代表$15{,}000$–$150{,}000$年的积累——与一个冰期-间冰期周期同量级，这就是为什么宾夕法尼亚亚纪的旋回层被读作冰川性海的：每个旋回是一个高水位或低水位期间泥炭生长的时段，被下一次海侵淹没。
:::

::: warning "复杂度在整个古生代增加"
这个说法有三处是错的。在生物的最大或平均复杂度上没有趋势，只有其范围的趋势，而范围增长是因为可能性的空角落被填上了。没有方向：每个古生代纪最丰富、最多样的动物，按任何合理的度量，都是最简单的——腕足类、海百合、有孔虫、蓝细菌。而模式不光滑：古生代以$96\%$的海洋物种消失结束，而取代寒武纪与古生代动物群的那个动物群——掘穴双壳类、腹足类、十足类甲壳类与真骨鱼级别的鱼的"现代动物群"——在其生态上不同、而不是更高级。古生代是一部环境被发明的历史、不是进步的历史。
:::

::: quiz
寒武纪底质革命是
- [ ] 最早矿化骨骼的出现
- [x] 被掘的、混合的、含氧的沉积物对微生物席地的取代
- [ ] 植物对陆地的殖民
- [ ] 礁的首次出现
::: solution
它是掘穴事件：挖掘的动物摧毁了曾把前寒武纪海床铺成地毯的层理微生物席，而这样做时使沉积物含氧并重新改造、改变其化学、并使内底生命成为可能。它由遗迹化石、而不是由躯体定年，而它是记录里行为改造环境的最清楚案例之一。
:::

::: history
寒武纪动物群首先由Joachim Barrande在1840年代从波希米亚描述，他的十一卷《下志留系系统》确立了"原始"动物群是复杂的、比志留纪更老，并帮助创建了与Roderick Murchison的、以寒武系与奥陶系的创建告终的争论。Charles Doolittle Walcott的Burgess页岩专著（1911–1931）是这个题目的基础、而在其解释上也是它最持久的尴尬。埃迪卡拉生物群由Mary Shein在1946年在Flinders山脉发现、由Martin Glaessner与James Playford在1960年代描述，而它们的年龄——前寒武纪——只在1980年代靠上覆火山岩层的铷-锶定年才定下来，那使它们成为最老复杂生命，而当寒武纪在2011年被重新定年为$538.8\ \mathrm{Ma}$时，把它们放在距爆发几百万年之内。Harry Whittington与他的学生Harry Toogood与Derek Briggs在1971至1985年间重做了Burgess动物群、并创建了进化发育生物学的化石分支这门学科；Hox簇及其深度同源的发现，由Walter Gehring的小组在1983年宣布，使遗传解释成为可能。James Valentine与Douglas Erwin关于寒武纪动物群生态组装的论述，以及Graham Budd与Sören Jensen关于什么是不是节肢动物的论证，是当前争论的框架。
:::

## 通向何处

给本章打点的灭绝及其度量在[[earth-history/mass-extinctions]]；碳与氧循环机制在[[biogeochemistry/carbon-deep-time]]与[[biogeochemistry/oxygen]]；晚古生代冰期及其冰川记录在[[palaeoclimate/deep-time]]与[[glaciology/ice-sheets]]；植物的入侵及其地球化学特征在[[geochemistry/weathering-chemistry]]；以及Pangaea聚合的构造在[[physical-geology/plate-tectonics]]与[[structural-geology/orogens]]。

::: summary 要点
- 寒武纪辐射是真实的、快的（门约25 Myr）、而不是一个祖先问题：埃迪卡拉生物群是一个独立的、多半已灭绝的实验。
- 寒武纪底质革命——掘穴取代席地——与动物本身同样重要，而由遗迹化石定年。
- 原因是四个而互不排斥：氧、海洋化学、捕食、与既有的遗传工具箱，而生态设定时间。
- GOBE在奥陶纪通过填满寒武纪留下的固着、滤食、分层的生态空间而使科的多样性翻三倍。
- 470与370 Ma之间陆地的殖民改变了行星：土壤、根、风化、二氧化碳的抽走、陆棚的营养负荷。
- 石炭纪30–35%的氧给最早的巨型昆虫定尺寸、而被火制住。
- Pangaea的聚合创造了干旱的超大陆、季风、煤沼泽、而在二叠纪末，最大灭绝的条件。
:::

## 练习

::: exercise 速率 {level=1 check="70"}
用[[#ex-explosion-rate]]，寒武纪首次出现的速率超过前寒武纪平均多少倍？
::: solution
$1.2/0.017 = 70$。这个数字对你数多少个门、以及你把多少辐射归给埃迪卡拉纪是敏感的，而任何一个方向十倍的因子都不会改变早寒武纪是反常的这个结论。
:::
:::

::: exercise GOBE {level=1 check="5.7"}
海洋科多样性在$485$与$450\ \mathrm{Ma}$之间从约$100$个科升到约$300$个。求科增加的平均净速率（科每Myr），并解释为什么总起源速率必须更高。
::: solution
$(300-100)/35 = 5.7$科每Myr。因为科在整个期间也在灭绝，总起源速率是净增加上灭绝速率；以一个同量级的背景科灭绝速率，真实的起源速率约是净数字的两倍。
:::
:::

::: exercise 氧与昆虫 {level=1 check="2.2"}
气管扩散能力按气管的横截面积与氧分压缩放。若一只蜻蜓的最大质量按氧分压的$3/2$次幂缩放（扩散限制的一个简单异速生长模型），求$35\%$氧时最大质量与$21\%$时之比。
::: solution
$(35/21)^{1.5} = 1.667^{1.5} = 2.15$，约$2.2$。氧增加$67\%$而最大身体质量翻倍，大致就是石炭纪巨型化所要求的，而这就是为什么这个模型通常被写成一个接近$1.5$的指数——但注意这个论证适用于以气管扩散呼吸的稚虫与成虫的昆虫、不适用于稚虫水生带鳃的那些。
:::
:::

::: exercise 煤与氧 {level=2 check="2.2"}
欧美的石炭纪煤层据估计含有$10^{13}\ \mathrm{t}$的碳。若其中全部被呼吸掉而不是被埋掉，那会从大气移走多少氧，单位摩尔，而这与$3.7\times10^{19}\ \mathrm{mol}$的现今库相比如何？
::: solution
$10^{13}\ \mathrm{t} = 10^{16}\ \mathrm{kg} = 8.3\times10^{17}\ \mathrm{mol\ C}$，而每摩尔碳一摩尔$\mathrm{O_2}$给出$8.3\times10^{17}\ \mathrm{mol}$，这是现今氧库的$2.2\%$。所以单个盆地的煤是预算的一个小部分；要移动氧水平几十个百分点，需要全球性的、反复的、$60\ \mathrm{Myr}$长的石炭纪埋藏，那是这个问题的尺度。
:::
:::

::: exercise 风化与变冷 {level=2 check="10"}
根增强的硅酸盐风化在植被岩石上把风化通量增加$10$倍。若风化通量是平衡一个$10^{12}\ \mathrm{mol\ C\ yr^{-1}}$的$\mathrm{CO_2}$源的汇，而风化速率按$\mathrm{CO_2}$依赖为$W \propto P_{\mathrm{CO_2}}^{0.3}$，求在通量被植物翻倍之后恢复平衡所需的$P_{\mathrm{CO_2}}$的分数下降。
::: solution
在固定气候下把风化系数翻倍使汇翻倍，所以要恢复平衡$P_{\mathrm{CO_2}}$必须按$2^{1/0.3} = 10$的因子下降。那是从，比如说，现今的$30\times$降到现今的$3\times$，而这是泥盆纪绿化造成了晚古生代冰期这个论证的标准形式。不确定度在指数$0.3$、以及有多少岩石是新暴露的；任何一个里十倍的因子就是整个论证。
:::
:::

::: exercise 读一个特异埋藏化石库 {level=2 check="30"}
一个Burgess页岩类型的动物群产出归属$120$个物种的$12{,}000$件标本，其中$30$个物种知自单件标本、$15$个恰好知自两件。用Chao1估计量估计样本未能记录的物种数。
::: solution
以$f_1 = 30$与$f_2 = 15$，估计是$S = 120 + 30^2/(2\times15) = 150$，所以缺失的数目是$30$。世界上最有名的保守特异埋藏化石库里动物群也有四分之一未被记录，当一条寒武纪多样性曲线与一条现代的相比时值得记住这一点。
:::
:::

::: exercise 推导氧上限 {level=3}
穿过一根长$L$、横截面$A$的气管的氧通量是$J = D A \Delta C/L$，其中$D$是扩散系数、$\Delta C$是浓度差。若一个昆虫的氧需求按$M^{0.75}$缩放、其气管面积按$M^{0.5}$、其气管长度按$M^{0.33}$，推导最大质量对环境氧浓度$C_a$的缩放，并求值这个指数。
::: solution
供给按$J \propto A/L \propto M^{0.5}/M^{0.33} = M^{0.17}$缩放，而需求按$M^{0.75}$。在最大尺寸处令供给等于需求，并把供给带着环境浓度显式写出，$J \propto C_a M^{0.17}$，所以
$$
C_a M^{0.17} \propto M^{0.75} \Longrightarrow M \propto C_a^{1/(0.75-0.17)} = C_a^{1.72}.
$$
最大质量按氧浓度的$1.7$次幂缩放，而那是前一个练习里使用的指数。关于活昆虫的实证文献给出$1$与$2.5$之间取决于类群与发育阶段的指数，而这个模型的价值不是它的精度、而是它做出了一个能在箱子里检验的预言。
:::
:::

::: exercise 奥陶纪末 {level=3}
$445\ \mathrm{Ma}$的Hirnantian灭绝移走了约$85\%$的海洋物种，其中多数是热带浅陆棚的腕足类、苔藓虫与三叶虫。两个候选原因是一个$50$–$100\ \mathrm{m}$的海平面下降伴陆棚面积的损失、以及在随后的海侵期间幸存陆棚上的缺氧。把每个假说需要的证据、同位素或沉积学的检验、以及为什么两者可能都为真列出。
::: solution
**海平面下降**预言灭绝烈度应与被排干的陆棚面积成比例，而幸存者应是深水与斜坡动物群。检验：幸存与灭绝动物群的古水深重建、以及灭绝与每个大陆古地理陆棚面积的相关。
**海侵期间的缺氧**预言灭绝应集中在*海侵*体系域、而不是低水位域，而应由黑色页岩、由正的$\delta^{238}\mathrm{U}$与$\delta^{98}\mathrm{Mo}$、以及由最高灭绝层位处升高的Mo、U与Re浓度记录。检验：穿过Hirnantian地层的化质地层学。

两者都有支持，而使两者调和的机制是海洋对冰川的响应：变冷使深水含氧，而它随后下沉并扩散，而冰川之后的海侵把在深盆地待着时变得缺氧与硫化的水淹上陆棚。第一次击杀是生境损失，第二次是中毒，而次序记录在地层里——这就是为什么奥陶纪末的两次击杀模型，和二叠纪末的一样，首先是一个地层学论证。
:::
:::

::: exercise 一个超大陆的气候 {level=3}
$300\ \mathrm{Ma}$的Pangaea有$60\%$的陆地在离海$500\ \mathrm{km}$以上、对照今天的$20\%$。解释对(a)大陆季节性温度循环的幅度、(b)礁的分布、(c)全球风化速率与$\mathrm{CO_2}$、(d)化石记录的保存的预期影响，并说这四个里哪个最容易检验。
::: solution
(a) **大陆度**增加：一个更大的季节循环，内部有冰缘与干旱相、边缘有季风。检验：蒸发岩、风砂与黄土的沉积记录，以及古植物叶片相貌。
(b) **礁**被限制在陆棚被淹的窄的温带到热带边缘，而超大陆的总礁面积小——那是晚古生代尽管有温暖赤道气候却少有大型礁复合体的一个理由。
(c) **风化**在干旱内部减少、而集中在碰撞带的山带上；一个在$30^\circ$纬度带季风的造山运动的净效应是一个大的风化通量与一个$\mathrm{CO_2}$的抽走，而这是冰期的标准解释。
(d) **保存**是有偏的：一个超大陆有更少的陆表海与更多的侵蚀面，所以内部的岩层记录薄、而多样性曲线被拉下。

最容易检验的是(d)，因为它是岩层记录本身上的一个计数练习，而它是必须先定下来、其他任何一个才能从多样性曲线论证的那个。
:::
