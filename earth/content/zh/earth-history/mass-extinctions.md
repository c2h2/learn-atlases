在中国南部的美川（Meishan），一个公路剖面展示了含有生命史上最大灭绝的$25\ \mathrm{cm}$岩石。界线层之下是最后的三叶虫——小的、帽贝形的、一个持续了$2.7$亿年的类群最后的幸存者——连同最后的四射珊瑚、最后的纺锤虫有孔虫与大部分腕足类科。界线层本身是一个含汞异常的粘土层，而其上是一个贫瘠的石灰岩，带微生物纹层与一小把灾难类群：腕足类*Lingula*、牙形石*Clarkina*、几个灾难双壳类。其上的岩石用了千万年才重新看起来多样。

二叠纪末灭绝移走了也许$83\%$的海洋属、$96\%$的海洋物种、而在陆地上，大部分大型动物。它是从记录里突出的五次之一、也是几乎终结了这个实验的唯一一次。本章讲灭绝如何被测量、这五次有什么共同点、是什么杀死了它们每一个、以及这个答案对当下意味着什么。

## 测量灭绝

::: definition 速率、背景、以及什么算大灭绝 {#def-extinction-rate}
灭绝速率通常以每分类单元每单位时间表达。若$t_1$时$N_1$个分类单元的一组在$t_2$时被减到$N_2$而没有起源，
$$
E = \frac{\ln(N_1/N_2)}{t_2 - t_1}
$$
每分类单元每单位时间的灭绝数。**背景速率**是大灭绝之间盛行的速率；Raup的经验法则是，一个海洋属在任何一百万年里灭绝的概率约为$0.1$，这与一个$10\ \mathrm{Myr}$的平均属寿命相同。一个**大灭绝**按惯例是一个间隔，其中超过约$60\%$的属在一个短到起源无法补偿的时间里丢失——地质学上，少于几百万年。
:::

::: theorem 灭绝定律：存活是指数 {#thm-red-queen}
若一个分类单元灭绝的概率每单位时间恒定、而与其已经存在了多久无关——Van Valen的红皇后假说——那么从一个队列存活的分类单元数是
$$
N(t) = N_0 e^{-t/T},
$$
其中$T$是平均寿命，而$\ln N$对时间的图是一条直线。等价地，分类单元不会"变老"：一个存在了$100\ \mathrm{Myr}$的科在下一百万年里存活的概率不比对一个昨天出现的更高。
:::

::: proof
设$q$为每分类单元每单位时间的灭绝概率。在一个小间隔$\mathrm{d}t$上，$\mathrm{d}N = -qN\,\mathrm{d}t$，它积分成指数。平均寿命是
$$
\langle t\rangle = \frac{1}{N_0}\int_0^\infty t\,qN_0e^{-qt}\,\mathrm{d}t = \frac{1}{q} = T .
$$
Van Valen在海洋属的化石科上检验了这个假说、发现存活曲线在对数-线性图上是线性的，正如指数所要求的，而不是凹的（那意味着分类单元随年龄变脆）或凸的（它们变结实）。∎

这个结果令人沮丧而重要。它意味着一个分类单元的正常状态是一个恒定的死亡风险，背景不是一个稳定的基线、而是一个由生物群对自己做着的任何事物驱动的稳态周转，而一次大灭绝是**风险乘数**、不是一个规则的打破。它也意味着一个类群的"年龄"对它的命运什么也不告诉你：三叶虫在二叠纪不老也不累，它们只是不走运。
:::

::: example 高有多高？ {#ex-background}
典型的背景速率是每一百万物种每一百万年一个灭绝。约有$8.7\times10^{6}$个真核物种。自1500年IUCN记录了约$400$个灭绝，而约$16{,}000$个物种目前被列为受威胁。求背景下上一个世纪预期的灭绝数、观测的倍数、以及若受威胁物种的一半在一个世纪内灭绝所暗示的倍数。
::: solution
在背景下预期数是
$$
8.7\times10^{6}\ \text{species}\times10^{-6}\ \mathrm{yr^{-1}}\times100\ \mathrm{yr} = 870\ \text{extinctions per century}.
$$
IUCN自1500年记录的$400$个灭绝比那少，但记录数是下限：它只列出灭绝已被证实的物种，而背景速率是在海洋属上校准的、在这里被用于所有真核生物。

文献做的比较是一个风险倍数。若$16{,}000$个受威胁物种的一半在一个世纪里丢失，那是$8\times10^{3}$个灭绝、对照$870$个背景预期，一个$9$倍的因子；若受威胁的类别是实际处于危险的物种的一个小样本，如多数分析所假设的，倍数是$100$–$1000$。诚实的说法是目前的速率至少比背景高一个数量级、而合理地是两个，记录的数是一个下限、不是一个估计，而与五大的比较不是我们杀死的物种比二叠纪末杀得更多——我们没有——而是我们在几个世纪里、而不是在几万年里施加同一个风险。
:::
:::

::: example 二叠纪末的二氧化碳 {#ex-perm-carbon}
在二叠纪-三叠纪界线之上，阿拉伯联合酋长国的剖面里海相碳酸盐的$\delta^{13}\mathrm{C}$在不到$100\ \mathrm{kyr}$内下降约$3\%$、而在整个漂移上最多$8\%$。把海洋的溶解无机碳取作$3.8\times10^{18}\ \mathrm{mol}$、在$\delta^{13}\mathrm{C} = 0\%$，而加入的碳取作热成因甲烷与$\mathrm{CO_2}$的混合物、来自西伯利亚暗色岩侵入蒸发岩与含煤沉积岩，$\delta^{13}\mathrm{C} = -20\%$。求产生$3\%$的偏移必须加入的碳的质量。
::: solution
混合给出，对于一个小加入量，
$$
\Delta\delta = \frac{C_a(\delta_a - \delta_o)}{C_o} \Longrightarrow C_a = \frac{C_o\,\Delta\delta}{\delta_o - \delta_a} = \frac{3.8\times10^{18}\times3}{20} = 5.7\times10^{17}\ \mathrm{mol},
$$
$$
M = 5.7\times10^{17}\times12\times10^{-15}\ \mathrm{Gt} = 6800\ \mathrm{Gt\ C}.
$$
对西伯利亚暗色岩熔岩侵入沉积岩——煤、油页岩、碳酸盐、蒸发岩——的$1.5\times10^{6}\ \mathrm{km^2}$范围上接触变质释放的碳的独立估计给出$9{,}000$–$12{,}000\ \mathrm{Gt\ C}$，连同约$10^4\ \mathrm{Gt}$的$\mathrm{SO_2}$与一个未知但大量的盐酸与有机氯化物。同位素预算与地质预算在二倍的因子内一致，而这已是古生代能达到的最接近。

后果从算术而来。九千吉吨碳作为$\mathrm{CO_2}$是整个化石燃料储量的$15$倍，而从中带反馈的模型增暖是$8$–$10\ ^\circ\mathrm{C}$——这正是牙形石磷酸盐的氧同位素记录的，热带海表达到$35$–$40\ ^\circ\mathrm{C}$。
:::

::: example 靠铱称出的一个小行星 {#ex-iridium}
白垩纪-古近纪界线粘土在一百多个地点被发现、携带一个全球铱异常。把层里过量铱的总质量取作$4\times10^{8}\ \mathrm{kg}$、一个碳质球粒陨石的铱含量取作$0.5\ \mu\mathrm{g\,g^{-1}}$、撞击体的密度取作$3000\ \mathrm{kg\,m^{-3}}$。求撞击体的质量与直径，并解释为什么铱论证要求这一层全球同步。
::: solution
若撞击体是球粒质的，
$$
M = \frac{4\times10^{8}}{5\times10^{-7}} = 8\times10^{14}\ \mathrm{kg}, \qquad V = \frac{M}{\rho} = 2.7\times10^{11}\ \mathrm{m^3},
$$
$$
r = \left(\frac{3V}{4\pi}\right)^{1/3} = 4.0\ \mathrm{km}, \qquad D \approx 8\ \mathrm{km}.
$$
那是造出$180\ \mathrm{km}$的Chicxulub坑所需的尺寸、而那是坑的标度定律独立要求的物体的尺寸。两条证据线——一层薄粘土的地球化学与一个被埋构造的几何——在同一个数字上相遇，这就是为什么撞击假说在十年、而不是一个世纪里被接受。

同步性要紧，因为铱也由普通的海底沉积与微陨石以一个背景速率交付、并由火山作用以少量交付。使这个异常成为一个撞击特征的不是它在一个地点的大小，而是同一个$1$–$10\ \mathrm{cm}$的层，带着同样的铱、同样的冲击石英、同样的富镍尖晶石与同样的微球粒，出现在每个大陆的海相与陆相剖面的同一个地层层位。没有一个在沉积物里迁移的东西做得到这一点。
:::

## 选择性：谁死了，为什么

::: proposition 灭绝选择性是杀戮机制的最好证据 {#prop-selectivity}
不同的机制杀死不同的生理。缺氧针对大的身体尺寸与高代谢率选择，因为氧需求设定临界阈值。酸化针对钙化者选择，而在其中针对那些造文石与高镁方解石的、它们溶解得更容易，以及那些壳薄、表面积对体积高的。增暖针对那些代谢需求对氧供给比高的生物、以及那些已经生活在其温度上限附近的。臭氧损耗针对暴露于紫外的地表栖息的生物。因为选择性从数千个产出测量、而机制从中推断，这个方法比在岩石里寻找一个单一异常信号更稳健。
:::

::: example 读二叠纪末的选择性 {#ex-selectivity}
Payne与同事在二叠纪-三叠纪之上给$19$个属级特征打分、发现灭绝风险与两个的相关最强：骨骼里文石或高镁方解质的存在、以及一个高的表面积对体积比。带方解石壳的腕足类比带磷酸盐或文石的幸存得更好；带硅质骨针的海绵做得不错；钙藻与礁建造者没有。用一个单一机制解释这两个相关，并陈述这个模式不排除的那个替代。
::: solution
两者都指向**高碳酸血症与酸化**：一个有高表面积对体积比、带一个薄而透的壳的动物，在周围的水被$\mathrm{CO_2}$加载时更不擅长维持一个内部的酸碱平衡，而一个文石或高镁方解石的骨骼在一个比低镁方解石更低的饱和度状态下溶解。这个模式是一个$\mathrm{CO_2}$驱动的杀戮看起来的样子，而它与同一机制的同位素与硼证据独立。

这个模式不排除的是，同样的特征也预言对缺氧与增暖的易感性，因为两者都按氧需求对供给之比缩放。三个机制不能单靠选择性分开，而在二叠纪末它们一起到来。这是灭绝因果的普遍问题：选择性识别出失效的生理，而几个机制使同一个生理失效。
:::
:::

## 恢复，以及随之而来的

恢复不是原有之物的回归。在二叠纪末之后，最早三叠世的海洋由一小把地理广布的、广食的"灾难类群"主导、以微生物岩礁取代后生动物礁、并由**利立浦特效应**主导——幸存者的侏儒化，腕足类与菊石的壳是其二叠纪尺寸的一个零头，那是对热的、缺氧的水、以及一个通过微生物环流动的食物供给的响应。**鲨类间隔**——鲨与鳐相对丰度的上升——记录硬骨鱼的崩溃与其之上捕食者的生态释放。多样性用$5$–$10\ \mathrm{Myr}$回归，而生态系统架构——分层、捕食强度、生物扰动、骨骼化的浮游生物——用$50\ \mathrm{Myr}$，而回来时不同了：现代演化动物群从灭绝里升起，而侏罗纪与白垩纪的中生代海洋革命是随之而来的升级。

大灭绝原因的复现是一个严肃的模式、不是一个阴谋论：达到大灭绝阈值的十一个间隔里，八个在年龄上，在定年误差内，与一个大火成岩省吻合。这个相关不是证明——溢流玄武岩的年龄有百万年的误差棒、而灭绝分布在几百万年上——但它是为什么二叠纪末、三叠纪末、以及与Deccan相关的马斯特里赫特晚期在碳排放的措辞里被争论、以及为什么有撞击的白垩纪末是那个证明一个杀戮可以多快的规则的例外。

::: warning "界线之下的化石是稀少的，因此灭绝是渐近的"
文献里不断犯两个错误。第一个是Signor–Lipps：一个看似渐近的衰退是从一个抽样不完全的剖面里一个瞬时事件所预期的，而一个稀见分类单元穿过到界线粘土里的分布区间两个方向上都是弱的证据。第二个是反面：一个剖面里一个尖锐的界线对全球节奏什么也不说，因为界线可能是一个沉积间断、一个被掘的面、或一个相变。一次灭绝的节奏只能靠对剖面本身的高精度地质年代学测量——美川凝灰层上$252.03 \pm 0.04\ \mathrm{Ma}$的年龄，它把主脉冲放进$60$–$200\ \mathrm{kyr}$之内——或靠一个独立的全球标志。其余一切都是对抽样的一个解读。
:::

::: history
Georges Cuvier对巴黎盆地动物群的比较在1796至1812年间确立了灭绝作为一个事实，而他对"地球革命"的论述把记录的突然性变成了一个理论问题。恰好有五次大灭绝这个想法由David Raup与Jack Sepkoski 1982年发表在《美国国家科学院院刊》上的论文固定，他们在千万年的分档里测量了显生宙属的多样性、报告了五个极小值；这篇论文引发了十年关于是分档、岩层记录还是抽样产生了这个模式的争论、并直接导致了定量古生物多样性的现代学科。Luis Alvarez、Walter Alvarez、Frank Asaro与同事在1980年报告了铱异常，而对他们的反对意见——这个异常是一个沉积间断、或火山的、或成岩的——被一个地点一个地点地回答，直到坑在1990年从地球物理被识别。Douglas Erwin的《古生代大危机》（1993）与Michael Benton的《当生命几乎死去》（2003）是二叠纪末论证的两面，前者为一个灾变论证、后者为一个持续的、多因的衰退。Paul Wignall对"死区"与微生物岩的记录、Rothman的硫循环模型、以及MIT的Sam Bowring小组与Seth Burgess的精确年龄，它们把二叠纪末从一个关于持续时间的争论变成一个关于机制的争论，是本章所依据的测量。
:::

## 通向何处

原因在各事件本身的章节里展开——[[earth-history/palaeozoic]]、[[earth-history/mesozoic]]与[[earth-history/cenozoic]]——碳与硫循环机制在[[biogeochemistry/carbon-deep-time]]，海洋化学在[[oceanography/ocean-chemistry]]，大火成岩省的火山作用在[[physical-geology/volcanoes]]与[[physical-geology/igneous-rocks]]，撞击物理在[[planetary-science/impacts]]，而当前的灭绝在[[biogeochemistry/principles]]。

::: summary 要点
- 灭绝作为一个每分类单元的风险测量；背景约为每百万年10%的属，而一次大灭绝是在一个地质学上短的间隔里那个风险的乘积。
- Van Valen定律：风险在一个分类单元的一生中是恒定的，所以存活是指数的，而年龄不赋予免疫。
- 五大在量级、在选择性、在原因上不同；四个与大火成岩省关联、一个与撞击。
- 二叠纪末最糟是因为几个杀戮机制——增暖、酸化、缺氧、硫化水、臭氧损伤——一起到来并持续。
- 选择性是机制的最强证据，而它指向二氧化碳：壳薄的、文石骨骼的、高表面积对体积的分类单元最先死。
- 一次灭绝的节奏只能靠剖面上的地质年代学测量、不能靠一个界线的表观尖锐度。
- 恢复不是复原：二叠纪末把海洋交给了现代演化动物群，而回来的生态系统更分层、更活动、更升级。
- 当前的风险倍数至少是十倍、合理地是几百倍背景，施加在几个世纪、而不是几万年上。
:::

## 练习

::: exercise 一个灭绝速率 {level=1 check="0.1"}
一个属有$10\ \mathrm{Myr}$的平均寿命。求背景灭绝速率，单位每属每Myr的灭绝数。
::: solution
$E = 1/10 = 0.1$每属每Myr。等价地，每一百万年有$10\%$的属灭绝，这就是为什么显生宙属的多样性曲线是在约同样速率的起源与这个风险之间的一个平衡。
:::
:::

::: exercise 存活 {level=1 check="0.14"}
以一个$50\ \mathrm{Myr}$的平均科寿命，一个科的队列在$100\ \mathrm{Myr}$后存活多少比例、在$450\ \mathrm{Myr}$后多少？（填入$100\ \mathrm{Myr}$的值。）
::: solution
$e^{-100/50} = e^{-2} = 0.135$，约$14\%$；在$450\ \mathrm{Myr}$之后，$e^{-9} = 1.2\times10^{-4}$。要点是陡度：一个$50\ \mathrm{Myr}$时间常数的指数在$450\ \mathrm{Myr}$之后几乎什么都不留下，这就是为什么幸存的奥陶纪科是需要解释的例外。
:::
:::

::: exercise 五大 {level=1 check="96"}
哪次大灭绝移走了最大比例的海洋物种，而那比例大约是多少？
::: solution
二叠纪末，在约$96\%$的海洋物种与$83\%$的属。白垩纪末移走了约$76\%$的物种，而奥陶纪末、晚泥盆世与三叠纪末事件各在$70$–$85\%$的范围，取决于类群与计数方法。
:::
:::

::: exercise 碳同位素质量平衡 {level=2 check="11400"}
用[[#ex-perm-carbon]]的方法，求以一个$\delta^{13}\mathrm{C} = -20\%$的加入碳产生一个$5\%$漂移所需的碳的质量（Gt）。
::: solution
$C_a = 3.8\times10^{18}\times5/20 = 9.5\times10^{17}\ \mathrm{mol}$，而$9.5\times10^{17}\times12\times10^{-15} = 11{,}400\ \mathrm{Gt\ C}$。这个关系的线性是有用的部分：碳的质量直接与漂移的大小成比例，所以同位素偏移里二倍的因子是排放里二倍的因子。
:::
:::

::: exercise 撞击能量 {level=2 check="38"}
一个直径$8\ \mathrm{km}$、密度$3000\ \mathrm{kg\,m^{-3}}$的天体以$20\ \mathrm{km\,s^{-1}}$撞击。求能量，单位百万吨TNT（$1\ \mathrm{Mt} = 4.2\times10^{15}\ \mathrm{J}$），并以$10^{6}\ \mathrm{Mt}$的单位给出答案。
::: solution
$$
M = \frac{4}{3}\pi(4000)^3\times3000 = 8.0\times10^{14}\ \mathrm{kg}, \qquad E = \tfrac{1}{2}Mv^2 = 1.6\times10^{23}\ \mathrm{J}
$$
$$
E = \frac{1.6\times10^{23}}{4.2\times10^{15}} = 3.8\times10^{7}\ \mathrm{Mt},
$$
那是$38$百万兆吨，或史上试爆的最大武器的$7.6\times10^{5}$倍。这个数字没有一个比较就没有意义：全世界的核武库比这一次撞击小几千倍，而撞击点处的地壳有几分钟表现得像一个流体。
:::
:::

::: exercise 选择性 {level=2}
说出使一个钙化生物在二叠纪末更脆弱的两种骨骼矿物，并给出机制。
::: solution
文石与高镁方解石。两者相对于低镁方解石都是亚稳的、在一个更高的饱和度状态下溶解，所以一个被二氧化碳加载、碳酸根离子浓度降低的海洋使它们最先不饱和；同一个论证解释了文石海绵与钙微生物的几乎全部损失、以及方解石腕足类与顽固的微生物岩的幸存。
:::
:::

::: exercise 推导红皇后 {level=3}
证明一个恒定风险$q$蕴含一个指数存活与一个平均寿命$1/q$，然后在数据上检验这个假说：一个$400$个科的队列在$50\ \mathrm{Myr}$后有$240$个幸存者、在$100\ \mathrm{Myr}$后有$145$个。存活是指数的吗，而暗示的寿命是多少？
::: solution
恒定风险给出$\mathrm{d}N/\mathrm{d}t = -qN$，因此$N = N_0e^{-qt}$，而$\langle t\rangle = \int_0^\infty t\,qN_0e^{-qt}\mathrm{d}t/N_0 = 1/q$。
对数据，两个间隔给出
$$
q_1 = -\ln(240/400)/50 = 0.0102\ \mathrm{Myr^{-1}}, \qquad q_2 = -\ln(145/240)/50 = 0.0107\ \mathrm{Myr^{-1}}.
$$
两个风险在$5\%$内一致，所以存活是指数的、而暗示的平均寿命是$1/0.0105 = 95\ \mathrm{Myr}$。若第二个风险更大，分类单元就在变老；若它更小，它们就在变硬。Van Valen的结果是，对多数分类单元与多数间隔两者相等，而这正是"这场竞赛要跑才能留在原地"的意义。
:::
:::

::: exercise 从地层来的节奏 {level=3}
一个界线剖面有一个在灭绝层位之下$20\ \mathrm{cm}$、定年为$252.03 \pm 0.04\ \mathrm{Ma}$的凝灰层，与一个在其上$30\ \mathrm{cm}$、定年为$252.01 \pm 0.05\ \mathrm{Ma}$的。其间的岩层是深水石灰岩，生物扰动深度$5\ \mathrm{cm}$、没有不整合。估计灭绝间隔的最大持续时间，并说明哪个假设占主导。
::: solution
两个年龄无法区分：它们的差是$0.02\ \mathrm{Myr}$、而不确定度是$0.06\ \mathrm{Myr}$，所以其间$50\ \mathrm{cm}$的剖面在$2\sigma$水平上沉积于不超过约$100\ \mathrm{kyr}$，而其中的灭绝在不超过约那。

占主导的假设是剖面是连续的。一个$50\ \mathrm{cm}$的生物扰动石灰岩间隔可能含有隐伏的沉积间断，而它不含的论证建立在掘穴深度上：若掘穴穿过那些本会标记一个间断的面，那么沉积物暴露的时间不够长到把掘穴者排除在外。第二个假设是凝灰层在地层上是紧的——锆石不是继承的、而晶体是在喷发时长成的，这就是为什么年龄是单颗粒上的CA-ID-TIMS、以及为什么实验室之间的可重复性被报告。
:::
:::

::: exercise 作为一次灭绝的当下 {level=3}
假设$8.7\times10^{6}$个真核物种、一个每物种$10^{-6}\ \mathrm{yr^{-1}}$的背景风险、与一个当前的风险倍数$300$。求下一个世纪预期的灭绝数、按那个速率在一千年里将丢失的物种分数，并解释为什么与二叠纪末的比较仍然不直接。
::: solution
风险是每物种$3\times10^{-4}\ \mathrm{yr^{-1}}$，所以一个世纪给出
$$
8.7\times10^{6}\times\left(1 - e^{-3\times10^{-4}\times100}\right) = 8.7\times10^{6}\times0.0296 = 2.6\times10^{5}\ \text{extinctions}.
$$
在一千年上丢失的分数是$1 - e^{-0.3} = 26\%$。

与二叠纪末的比较不直接的三个理由。二叠纪末的数字是关于**海洋**物种的，那里化石记录好；事件的大陆与淡水记录远不那么清楚，而当前的危机在陆地上最糟。二叠纪末的损失以属与物种计量，而其总多样性从化石估计、完整度为几个百分点。而时间尺度不同：二叠纪末脉冲是$60$–$200\ \mathrm{kyr}$，所以它每千年的损失速率与一个$26\%$的一千年大致可比，但来自一个已被摧毁的生境的*已承诺*的损失更晚到来，跨几个世纪，这就是为什么诚实的说法是当前的风险与五大的同量级、而迄今实现的损失远低于它。
:::
