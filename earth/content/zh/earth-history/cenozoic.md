五千六百万年前，在约两万年里，深海洋暖了$4$–$5\ \mathrm{K}$，全球平均温度上升$5$–$8\ \mathrm{K}$，海洋变得更酸，三分之一的深水有孔虫灭绝，而北半球大陆哺乳动物变小、北迁、并在化石记录的一代之内在整个大陆上互相取代。海相碳酸盐的碳同位素组成下降了$3$到$6$个千分点。这是古新世-始新世极热事件，PETM，而它是新生代就"当一个大量的碳以快于碳酸盐机器能吸收的速率被放进大气-海洋系统时会发生什么"提供的最好自然实验。

新生代的其余部分是行星从那个实验、以及从随后那个温室里冷却出来的故事：南极洲的冻结、西藏的隆起与中亚的变干、冰在北半球的到来、以及冰期周期的百万年，其节奏由地球轨道的几何设定、而其幅度由二氧化碳设定。它也是现代动植物群——草原、食草哺乳动物、鲸、现代浮游生物、而到最后，我们——采取其现成形态的那个间隔。

## 新生代早期的温室

::: example PETM的碳释放 {#ex-petm}
在PETM之上，海相碳酸盐的$\delta^{13}\mathrm{C}$在不到$50\ \mathrm{kyr}$里下降了$3\%$到$6\%$。把海洋的溶解无机碳取作$3.8\times10^{18}\ \mathrm{mol}$、在$\delta^{13}\mathrm{C} = 0\%$，求若源的$\delta^{13}\mathrm{C}$为（a）$-6\%$，来自北大西洋火成省侵入富有机质沉积岩的热成因碳；（b）$-20\%$，一个混合有机源；（c）$-60\%$，甲烷水合物，必须加入的碳的质量。
::: solution
混合关系给出$C_a = C_o\,\Delta\delta/(\delta_o - \delta_a)$：
$$
\begin{aligned}
\delta_a = -6\% &: \quad C_a = 1.9\times10^{18}\ \mathrm{mol} = 22{,}800\ \mathrm{Gt\ C},\\
\delta_a = -20\% &: \quad 5.7\times10^{17}\ \mathrm{mol} = 6{,}800\ \mathrm{Gt\ C},\\
\delta_a = -60\% &: \quad 1.9\times10^{17}\ \mathrm{mol} = 2{,}300\ \mathrm{Gt\ C}.
\end{aligned}
$$
同一个同位素漂移要求碳质量里十倍的因子、仅取决于源的同位素组成，这就是为什么关于PETM原因的争论跑了三十年而未定。一个水合物源需要现代化石燃料储量的四分之一；一个热成因源需要九倍。

确定的是**速率**。即使最小的估计，$2{,}300\ \mathrm{Gt\ C}$、在$20\ \mathrm{kyr}$里，是$0.1\ \mathrm{Gt\ C\ yr^{-1}}$，比现今的$10\ \mathrm{Gt\ C\ yr^{-1}}$慢一个数量级——而这个漂移的形状，一个快速开始与一个由硅酸盐风化的缓慢的、$100\ \mathrm{kyr}$长的恢复，正是一个快脉冲随后碳酸盐溶解与风化所预言的。PETM不是当下的一个预报，但它是记录最接近的东西，而它测量的恢复时间——$100\ \mathrm{kyr}$或更多——是地球清理一个碳扰动所花的时间。
:::

早始新世还要暖。在$53$与$49\ \mathrm{Ma}$之间，**早始新世气候最宜期**把棕榈树与鳄类放进德国、赤道海表$30\ ^\circ\mathrm{C}$、南极海岸$20\ ^\circ\mathrm{C}$，而二氧化碳也许在$1000$–$2000\ \mathrm{ppm}$。约$49\ \mathrm{Ma}$的**满江红事件**——淡水蕨满江红在新隔离的、表面淡化的北冰洋里大量繁殖，埋掉了足够多的有机氮，从而抽走了大量的二氧化碳——是一个预算有争议的迷人假说，而它是一个单一漂亮的观察如何跑过其同位素约束的好例子。

随后的变冷有三个候选原因，而三者很可能都有贡献。**南大洋门道的打开**——澳大利亚与南极洲之间的塔斯门通道从约$45\ \mathrm{Ma}$、南美洲与南极洲之间的Drake Passage，其时间仍在$41$与$30\ \mathrm{Ma}$之间争论——使南极绕极流得以形成，在热上隔离了这个大陆、并使海冰得以持续。**印度-亚洲碰撞**与西藏和喜马拉雅的生长提高了反照率、加强了季风、而按Raymo–Ruddiman 1992年的假说，加速了硅酸盐风化，它把二氧化碳从空气里抽走。而**有机碳与黄铁矿的埋藏**继续降低温室气体水平。风化假说被锇同位素记录严重削弱，它显示$40$–$30\ \mathrm{Ma}$没有全球风化通量的增加、也被锂同位素记录；晚始新世与渐新世的变冷现在更多归于门道、归于南极冰盖本身、以及归于一个持续的抽走。

::: example 冰期周期的增益 {#ex-ice-core-gain}
在南极冰芯记录过去$800{,}000$年里，全球平均温度在冰期与间冰期状态之间变化约$9\ \mathrm{K}$、而二氧化碳从$180$变到$290\ \mathrm{ppm}$。求仅二氧化碳变化产生的辐射强迫、一个无反馈敏感度$0.8\ \mathrm{K\,(W\,m^{-2})^{-1}}$下它产生的增暖、以及其余增暖所要求的放大因子。
::: solution
$$
\Delta F = 5.35\ln\frac{290}{180} = 2.6\ \mathrm{W\,m^{-2}}, \qquad \Delta T_\text{CO}_2 = 0.8\times2.6 = 2.1\ \mathrm{K}.
$$
观测的摆幅是$9\ \mathrm{K}$，所以放大因子是$9/2.1 = 4.3$。

这个数字用一个比值装下了整个第四纪气候动力学。二氧化碳不是冰期的恒温器——轨道强迫启动这个周期，而二氧化碳对它响应，滞后南极温度几百年——但它把轨道强迫**放大**两到三倍的因子，而放大作用的其余部分是冰盖与雪反照率、植被、粉尘与云。因果链在同一份记录里双向运行，这就是为什么"二氧化碳跟随温度"这句口号对滞后是真的、作为论证则无用：同一个使二氧化碳在一个慢轨道周期里成为跟随者的反馈，当它的浓度被直接改变时使它成为一个驱动者，正如现在。
:::

## 轨道理论，与十万年问题

::: definition 三个轨道参数 {#def-orbital}
**偏心率**$e$描述地球轨道的形状、在约$0.005$与$0.058$之间变化、主周期为$100$与$405\ \mathrm{kyr}$；它几乎完全不改变**年平均**日照、但它给季节反差的幅度定标。**转轴倾角**$\varepsilon$，自转轴的倾角，在$22.1^\circ$与$24.5^\circ$之间以$41\ \mathrm{kyr}$的周期变化；一个更大的倾角给高纬度更多夏季、更少冬季日照，而它是对冰盖要紧的参数。**岁差**是轴与轨道相对彼此的转动、主周期为$19$与$23\ \mathrm{kyr}$；它决定哪个半球在近日点倾向太阳、因此哪个半球有强烈的季节。Milankovitch以及此后本学科多数使用的强迫是**$65^\circ\mathrm{N}$的夏季日照**，选它是因为那是大冰盖生长的纬度、而夏季融化是决定性的。
:::

::: example 轨道强迫的大小 {#ex-insolation}
夏至处纬度$\phi$的日均日照是
$$
Q = \frac{S_0}{\pi}\left(\frac{d_\text{m}}{d}\right)^{2}\left[h_0\sin\phi\sin\delta + \cos\phi\cos\delta\sin h_0\right], \qquad \cos h_0 = -\tan\phi\tan\delta,
$$
其中$S_0 = 1361\ \mathrm{W\,m^{-2}}$。计算$65^\circ\mathrm{N}$在倾角$22.5^\circ$与$24.5^\circ$时的$Q$，然后对一个$24^\circ$的倾角、一个$0.055$的偏心率，分别对近日点在六月夏至与远日点在那里时计算。
::: solution
以$\delta = 22.5^\circ$，$h_0 = \arccos(-\tan 65^\circ\tan 22.5^\circ) = \arccos(-0.577) = 2.19\ \mathrm{rad}$，而
$$
Q = 478\ \mathrm{W\,m^{-2}} \quad\text{对照}\quad Q = 512\ \mathrm{W\,m^{-2}} \text{ 在 } \delta = 24.5^\circ,
$$
在倾角两端之间变化$7\%$。对$e = 0.055$的岁差，六月夏至处的距离因子$(d_\text{m}/d)^2$从$0.90$（远日点在六月）到$1.12$（近日点在六月），所以
$$
Q = 451 \rightarrow 562\ \mathrm{W\,m^{-2}},
$$
一个$25\%$的范围。在低偏心率端，$e = 0.005$，同一个岁差周期只给出$498$–$508\ \mathrm{W\,m^{-2}}$，一个$2\%$的范围。

这是**十万年问题**的钥匙。高纬度最强的日照信号是岁差的那个，但它的幅度被$100\ \mathrm{kyr}$偏心率周期接通与切断，而过去$800{,}000$年的气候由任何一条日照曲线都不包含的$100\ \mathrm{kyr}$周期主导。解决之道不是一个新强迫、而是一个非线性系统：一个冰盖缓慢生长直到它厚到不稳定、然后因任何挑逗迅速崩塌，所以周期性由冰盖自身的时间常数设定、而偏心率只是给机会计时。中更新世转换，主要周期在$1.2$与$0.7\ \mathrm{Ma}$之间从$41$变到$100\ \mathrm{kyr}$，与二氧化碳降到一个阈值之下、以及Laurentian与欧亚冰盖长到$41\ \mathrm{kyr}$周期不再能把它们移走的尺寸相吻合。
:::

## 冰期世界

::: definition 冰期、间冰期及其编号 {#def-glacial}
一个**冰期**（一个冰期阶段、一个冷期、一个偶数编号的海洋氧同位素阶段）是一个大冰盖、低海平面、低二氧化碳的间隔；一个**间冰期**（奇数编号）是其间的暖间隔，冰盖接近其现代尺寸。**海洋同位素阶段**是底栖氧同位素记录的对子，从现今往下编号：MIS 1是全新世、MIS 5e是$129$–$116\ \mathrm{ka}$的末次间冰期、MIS 2是$26\ \mathrm{ka}$的末次盛冰期、而MIS 11是$424$–$374\ \mathrm{ka}$的长间冰期。一个**间阶地**是一个冰期*之内*的暖漂移（Bølling–Allerød、Dansgaard–Oeschger事件），而一个**阶地**是一个冷的（新仙女木、Heinrich阶段）。这个区分要紧，因为末次冰期的突变事件是间阶地与阶地、不是主冰期-间冰期周期的一部分，而混淆它们是读一份更新世地层时最常见的错误。
:::

::: proposition 冰期需要冰盖不稳定与一个二氧化碳地板 {#prop-iceage}
一个无冰的行星只有当冰一旦长成就足够改变气候以维持自己时，才能被一个小强迫弄出冰来：反照率反馈、高程-气候反馈（一个厚冰盖把其表面降低到更冷的空气里，这在其生长时是一个正反馈、而一旦消失就是一个负的）、以及基底的重力均衡与动力学极限。冰盖的阈值行为——小的稳定、中的不稳定、大的不稳定——是把一个正弦强迫变成一个锯齿响应的东西，而冰期二氧化碳降到约$200\ \mathrm{ppm}$之下，是使晚更新世那些大的、不稳定的、$100\ \mathrm{kyr}$的冰盖得以存在的东西。
:::

第四纪冰期的证据从十几份一致的档案里读出。**海洋同位素地层学**给冰期-间冰期周期（海洋同位素阶段）编号、并把它们与轨道调谐配对；**珊瑚阶地**与化石礁序列直接给出海平面，而$129$–$116\ \mathrm{ka}$的末次间冰期高出现今$6$–$9\ \mathrm{m}$，其含义是格陵兰与西南极冰盖大部分已不在。**黄土-古土壤序列**在黄土高原上与深海粉尘记录给出干旱度与风力强度。**花粉**与植物大化石给出植被带，移动了几百公里的、被压缩进无类比组合的。**冰芯**给出大气本身：EPICA Dome C与Dome F记录达到$800{,}000$年，而Beyond EPICA把记录推到$120$万年，二氧化碳在$180$与$300\ \mathrm{ppm}$之间、甲烷在$350$与$700\ \mathrm{ppb}$之间、而粉尘浓度是现代的十倍。

在冰期之内，北半球的记录比南半球的更狂野：**Dansgaard–Oeschger事件**是几十年内在格陵兰$10$–$15\ \mathrm{K}$的突然增暖、随后是几百年到几千年缓慢变冷，而**Heinrich事件**是冰山舰队的排放、它们关停了大西洋翻转环流。**新仙女木**，在末次消冰之中$12.9$与$11.7\ \mathrm{ka}$之间一次向冷的回归，是这些突变里最年轻、定年最好的，也是当下增暖中一次的可能性是一个活问题的理由。

::: example 一个暖间冰期的海平面预算 {#ex-sea-level}
末次间冰期，$129$–$116\ \mathrm{ka}$，海平面在现今之上$6$–$9\ \mathrm{m}$、二氧化碳在$280\ \mathrm{ppm}$附近、而高纬度夏季日照比今天高几个百分点。格陵兰冰盖的贡献估计为$2$–$3\ \mathrm{m}$、西南极为$2$–$4\ \mathrm{m}$、而东南极为$0$–$3\ \mathrm{m}$。求残差，并解释为什么末次间冰期是海平面科学里最重要的数字。
::: solution
中心估计加起来是$4$–$10\ \mathrm{m}$，它把观测的$6$–$9\ \mathrm{m}$夹在中间：预算闭合，无需诉诸任何我们还不知道的机制。意义不在算术、而在**状态**。末次间冰期只比现今暖零点几度，而它有$6$–$9\ \mathrm{m}$的海平面上升，其中大部分来自至今仍大体完整、而此刻正在丢失质量的冰盖。因此它是一个经验证明，表明零点几度的额外增暖、持续数千年，把行星承诺给几米的海平面——而西南极的海洋基板块与格陵兰的海洋边缘是失效的那些。

反驳——末次间冰期由不再适用的轨道几何强迫——是真的而无关：轨道强迫是日照的几个百分点、而当下的二氧化碳强迫是几$\mathrm{W\,m^{-2}}$，而平衡敏感度把任何一个转成一个相似的温度。末次间冰期的正确使用是作为一个对一个暖世界的**平衡**海平面响应的约束，那正是冰盖模型们有分歧的量。
:::
:::

## 变冷的世界里的生命

白垩纪末之后的哺乳动物辐射是一个空生态位的故事：哺乳动物的体重分布在马斯特里赫特期从约$10\ \mathrm{kg}$的天花板跳到$15\ \mathrm{Myr}$内的$50\ \mathrm{t}$，而现代各目在北美与亚洲的最早始新世里以一个看似单一脉冲的方式出现——那是Cuvier与后来的Simpson当作一次创造的"首次出现"。始新世是古老各目与货币虫的时代、那些巨大有孔虫的壳建造了金字塔核心的石灰岩；渐新世与中新世见证了现代有蹄类各目的兴起，部分由**C4草原**的扩散驱动，其碳同位素特征（$\delta^{13}\mathrm{C}$在$-13\%$附近、对照C3植物的$-25\%$）首先$8$–$6\ \mathrm{Ma}$在非洲、后来在亚洲与南美洲出现在土壤以及马与牛科动物的牙釉质里。C4途径是对低二氧化碳、强光与季节性的适应，所以它的扩张既是晚新生代二氧化碳下降的一个结果、也是它的一个度量。

在陆地上，变冷与变干把雨林缩小到其现代的避难所、创造了使直立行走成为一个选项的草原、并在约$3\ \mathrm{Ma}$巴拿马地峡闭合时产生了**美洲大生物交换**，让北美洲的食肉目与有蹄类进入南美洲、而有袋类与异关节类往另一方向——那个不对称，北迁者以几比一多于南迁者，仍在争论。在海洋里，硅藻与现代浮游生物接管了硅与钙的循环、鲸随变冷与生产力辐射、而珊瑚礁从其始新世的高位退却。

这些变化里最后一个是带着我们名字的那个。晚第四纪巨型动物群灭绝在约$46\ \mathrm{ka}$从澳大利亚、在$14$–$12\ \mathrm{ka}$从美洲、在过去五千年从地中海与太平洋的岛屿上移走了大部分大型哺乳动物属；在每个案例里人类的到来先于损失，而在每个案例里气候也在改变，这就是为什么争论跑了四十年。当前的共识，来自人类与灭绝日期的贝叶斯重叠、以及来自损失在气候变化小的岛屿上远更糟这个事实，是在多数陆地上狩猎是主导驱动力、气候是一个修饰者，而食草者与食叶者的灭绝反馈进了火制度与植被。

::: warning "冰期证明了二氧化碳不驱动气候"
这个论证由两个真实的事实做出——轨道强迫启动这个周期、而二氧化碳滞后南极温度几百年——而得出一个错误的结论。这个滞后是*反馈*里的滞后、不是*因果*里的：南大洋变暖、其二氧化碳逸出、而这种气体把增暖散布到行星其余部分，这就是为什么南极记录显示滞后、而热带记录显示二氧化碳领先。而[[#ex-ice-core-gain]]的放大因子显示，没有二氧化碳的变化，冰期周期将只有其大小的三分之一。冰期实际证明的是二氧化碳反馈是强大的、系统有阈值、而对一个小强迫的响应幅度可以是巨大的——那与意图中的结论相反。
:::

::: quiz
中更新世转换是

- [x] 在1.2与0.7 Ma之间，冰期周期的主周期从41变为100 kyr的改变

- [ ] 南极冰盖最后一次大扩张

这个转换是周期*周期*的改变、不是它们的开始。北半球冰川作用在约$2.7\ \mathrm{Ma}$以$41\ \mathrm{kyr}$周期开始；在$1.2$与$0.7\ \mathrm{Ma}$之间系统切换到大的、不对称的、$100\ \mathrm{kyr}$周期，而主要的解释是二氧化碳的下降、冰盖长过一个稳定阈值、以及北半球陆棚几何的改变。
:::
:::

::: history
Milutin Milankovitch，一个在第一次世界大战期间在布达佩斯工作的塞尔维亚工程师，从当时轨道解算了过去几百万年的日照、并在1941年发表了这部理论，写在一篇为一个对它毫无用处的科学界成名的论文里；这部理论被多数地质学家驳回，直到Cesare Emiliani的深海同位素记录、然后Nicholas Shackleton与Robert Opdyke在1973年，显示气候有轨道的那些周期。Imbrie夫妇1980年代的SPECMAP项目把同位素曲线调谐到轨道、做出了过去五十万年的年表，而关于那是否是循环的——把数据调谐到数据本要检验的理论——的论证靠珊瑚的独立定年、以及靠$405\ \mathrm{kyr}$偏心率周期得到回答，后者太长而不可能是轨道之外的任何东西。Vostok冰芯，由Barnola与同事在1987年、以及Raynaud与同事在同一年报告，给出了冰期大气的第一个连续记录，而南极冰芯钻探欧洲项目2005年报告的把它扩展到$800{,}000$年、并显示二氧化碳其中全部未超过$300\ \mathrm{ppm}$。PETM在1990年代初从深海钻探计划岩芯里的同位素漂移被识别、而此后一直被作为新生代碳释放的实验来研究。Ma Raymo与Bill Ruddiman 1992年关于西藏与变冷的论文发起了十年的争论，而锇与锂同位素大体已把它否定，它是一个大胆假说即使错了也如何推进这个领域的模型。
:::

## 通向何处

指标在[[palaeoclimate/proxies]]里描述、而轨道理论在[[palaeoclimate/orbital-cycles]]里算出；冰芯在[[palaeoclimate/ice-cores]]、海洋记录在[[palaeoclimate/ocean-sediments]]；突变在[[palaeoclimate/abrupt-change]]、而过去两千年在[[palaeoclimate/holocene]]与[[palaeoclimate/last-two-millennia]]；冰盖力学在[[glaciology/ice-sheets]]、海平面记录在[[oceanography/sea-level]]；而西藏的隆起在[[physical-geology/plate-tectonics]]与[[structural-geology/orogens]]。

::: summary 要点
- PETM，在56 Ma，是新生代的碳释放实验：5–8 K的增暖、一个3–6个千分点的碳同位素漂移、一次深海灭绝、以及一个用了100 kyr的恢复。
- 早始新世是白垩纪末以来最暖的间隔，有1000–2000 ppm的二氧化碳与无极冰。
- 向现代冰室世界的变冷由南大洋门道的打开、南极冰盖的生长、与一个长期的二氧化碳抽走驱动；风化与西藏假说不被锇记录支持。
- 南极洲在34 Ma冻结，北半球在2.7 Ma，而冰期周期在1.2与0.7 Ma之间从41变为100 kyr。
- 轨道强迫在高纬度由岁差主导，其幅度被100 kyr的偏心率接通与切断；冰盖回答包络，那就是十万年问题。
- 二氧化碳在冰芯里滞后南极温度、并把轨道强迫放大两到三倍的因子；这个滞后是一个反馈、不是一个反驳。
- 末次间冰期，只比今天略暖，有6–9 m的海平面：一个对大冰盖平衡响应的经验约束。
- 新生代生物群——草原、C4食草者、现代浮游生物、鲸、以及人类驱动的巨型动物群灭绝——是变冷与变干的产物、不只是K–Pg一次清空。
:::

## 练习

::: exercise 日照 {level=1 check="9"}
用[[#ex-insolation]]的方法，求$65^\circ\mathrm{N}$六月日照在倾角$22.1^\circ$与$24.5^\circ$之间的百分比变化。
::: solution
$Q$从约$470$升到$512\ \mathrm{W\,m^{-2}}$，变化$9\%$。倾角的范围小于高偏心率下$25\%$的岁差范围，这就是为什么在偏心率高处岁差更要紧。
:::
:::

::: exercise 强迫 {level=1 check="2.6"}
求冰期-间冰期二氧化碳变化从$180$到$290\ \mathrm{ppm}$的辐射强迫。
::: solution
$\Delta F = 5.35\ln(290/180) = 2.6\ \mathrm{W\,m^{-2}}$。小到看起来不起眼，而在反馈被计入之前它解释了$9\ \mathrm{K}$摆幅的约五分之一。
:::
:::

::: exercise 冰芯增益 {level=1 check="4.3"}
若观测的冰期-间冰期温度摆幅是$9\ \mathrm{K}$、而单靠二氧化碳给出$2.1\ \mathrm{K}$，放大因子是多少？
::: solution
$9/2.1 = 4.3$。其余是冰与雪反照率、植被、粉尘、云与水汽，而冰反照率在北半球是最大的单项。
:::
:::

::: exercise PETM的源 {level=2 check="4600"}
用[[#ex-petm]]的方法，求一个$\delta^{13}\mathrm{C} = -60\%$的源产生一个$6\%$漂移所需的碳质量。
::: solution
$C_a = 3.8\times10^{18}\times6/60 = 3.8\times10^{17}\ \mathrm{mol} = 4{,}600\ \mathrm{Gt\ C}$。同位素漂移翻倍使质量翻倍、而源的亏损减半使它再翻倍——这就是为什么漂移的幅度本身无法区分一个水合物与一个热成因源。
:::
:::

::: exercise 偏心率开关 {level=2 check="22"}
在$e = 0.055$，$65^\circ\mathrm{N}$的六月日照在$451$与$562\ \mathrm{W\,m^{-2}}$之间，而在$e = 0.005$在$498$与$508$之间。求两个范围之比，以平均值的百分比，对高偏心率情形。
::: solution
高偏心率范围是$111\ \mathrm{W\,m^{-2}}$、在一个$507$的平均上，即$22\%$；低偏心率范围是$10$、在$503$上，即$2\%$。所以偏心率起一个幅度开关的作用，而冰期的$100\ \mathrm{kyr}$周期就是这个开关的周期。
:::
:::

::: exercise 海平面 {level=2 check="5"}
末次间冰期海平面在现今之上$6$–$9\ \mathrm{m}$。若格陵兰贡献是$2$–$3\ \mathrm{m}$、而西南极是$2$–$4\ \mathrm{m}$，留给东南极与其他来源的范围是多少？
::: solution
$6 - (3+4) = -1$在低端、而$9 - (2+2) = 5\ \mathrm{m}$在高端，所以$0$–$5\ \mathrm{m}$，与模型的$0$–$3\ \mathrm{m}$一致。要点是没有残差要求一个未知的机制、而即使总量的低端也意味着格陵兰与西南极冰盖都丢失了质量。
:::
:::

::: exercise 推导日照 {level=3}
从瞬时日照$S_0 (d_\text{m}/d)^2(\sin\phi\sin\delta + \cos\phi\cos\delta\cos h)$推导[[#ex-insolation]]的日均日照公式，并证明在至点处大气顶的年平均日照与倾角无关。那么，为什么倾角对冰盖要紧？
::: solution
把瞬时日照在日照时数上积分、除以$24$：日照半角$h_0$满足$\cos h_0 = -\tan\phi\tan\delta$，而日均值是
$$
Q = \frac{S_0}{\pi}\left(\frac{d_\text{m}}{d}\right)^2\left[h_0\sin\phi\sin\delta + \cos\phi\cos\delta\sin h_0\right],
$$
其中$h_0$以弧度计。在一年上平均，$\cos h$项积分为零、而$\sin\phi\sin\delta$项积分为零，因为$\delta$关于二分点对称，所以年平均只取决于纬度与距离——不取决于倾角。

倾角要紧，因为冰盖不是由年平均驱动、而是由夏季是否暖到融化冬季的雪驱动。一个更大的倾角在高纬度给一个更暖的夏季与一个更冷的冬季；设定质量平衡的夏季融化对夏季响应，而冬季积累对水汽供给响应、不是对当地温度。这是Milankovitch选择七月$65^\circ\mathrm{N}$的物理内容，而这就是为什么一个完全不改变任何年能量的参数可以给一个冰期打拍子。
:::
:::

::: exercise 四万年问题 {level=3}
在过去$300$万年里，$65^\circ\mathrm{N}$的倾角强迫幅度约$25\ \mathrm{W\,m^{-2}}$、而岁差强迫幅度约$50\ \mathrm{W\,m^{-2}}$，然而$3$与$1.2\ \mathrm{Ma}$之间的冰量记录由$41\ \mathrm{kyr}$主导。给出提出过的两个解释、以及能区分它们的观察。
::: solution
（**i**）一个带高纬度几何的线性响应。倾角强迫是全球的、而在两个半球之间总是同相，而岁差在两者之间反相；当两个半球都有冰时岁差信号相消、而倾角幸存。检验：对$3$–$1.2\ \mathrm{Ma}$间隔比较南北半球记录——若两个半球在$23\ \mathrm{kyr}$上反相，相消是真实的。
（**ii**）一个非线性的冰盖响应。早上新世尺寸的冰盖有一个$41\ \mathrm{kyr}$的稳定周期，而$100\ \mathrm{kyr}$的行为需要中更新世更大更厚的冰盖。检验：同一个强迫施加于不同初始厚度冰盖的数值实验、以及显示Laurentian与西伯利亚冰盖何时变大的冰山搬运沉积物的沉积记录。

两者都部分有支持，而现在第二个更被看好，因为这个转换也是周期*幅度*与*形状*的改变、不只是周期——一个阈值、不是一个相消的特征。
:::
:::

::: exercise 新生代背景里的人类世 {level=3}
新生代碳循环有好几次超热事件（PETM、ETM2、PETM的表亲们），碳释放速率为$0.1$–$1\ \mathrm{Gt\ C\ yr^{-1}}$、持续$10$–$100\ \mathrm{kyr}$。当前排放是$10\ \mathrm{Gt\ C\ yr^{-1}}$，其中一半留在大气里。把两者比较，并说明这个比较能确立什么、不能确立什么。
::: solution
当前向大气加入碳的*速率*，约$5\ \mathrm{Gt\ C\ yr^{-1}}$，是最快新生代超热的五到五十倍，而迄今总量约$1000\ \mathrm{Gt\ C}$，在其最小者的五分之一到一半之间。这个比较确立**速率**在过去$56\ \mathrm{Myr}$是空前的，那是一个关于汇的能力——海洋一千年的混合时间、风化的十万年——能否跟得上的陈述。

它不确立平衡结果，那取决于总量、不是速率：在$1000\ \mathrm{Gt\ C}$处，最终的增暖是几度、对照PETM的$5$–$8\ \mathrm{K}$，而PETM最糟的效应——深海灭绝、缺氧、甲烷反馈——是阈值效应，可能被越过、也可能不会。而它不传递PETM的生物响应，因为新生代动植物群从没见过一个碳脉冲、也没有从一个暖世界里躲避的避难所，而当前生物圈的问题是变化快过迁移。诚实的总结是速率是空前的那件事，而记录约束的是敏感度与恢复的时间尺度、不是预报结果。
:::
:::
