七个人在一次聚会上见面，每个人恰好与其余人中的三个人握手。这可能吗？你可以试着把它画出来——七个点，每次握手画一条线，每个点处有三条线——失败几次之后，你大概会怀疑这根本做不到。但失败的尝试什么也证明不了；也许你只是运气不好。我们需要的是一个**理由**，而这个理由原来只有一行：它就是本章的第一个定理。

这种由点和线构成的图形就是**图**。凡是由一些对象以及其中某些对象对之间的联系构成的东西，都可以用图来建模：朋友关系、道路网络、化学键、网页之间的链接、不能同时举行的考试。由于图的定义只保留了**哪些对之间有联系**，一条关于图的定理就同时适用于所有这些情形。本章建立基本词汇——度、路、连通性、同构——并证明两个基本的结构定理：一个关于二部图，一个关于树。接下来的两章将用这些词汇研究算法（[[discrete/graph-algorithms]]）以及图的画法与着色（[[discrete/colouring-planarity]]）。

## 图与度

::: definition 图 {#def-graph}
一个**图**$G = (V, E)$由一个有限非空的**顶点**集$V$和一个**边**集$E$组成，其中每条边都是由两个不同顶点构成的集合$\{u, v\}$。我们把边$\{u,v\}$记作$uv$（或$vu$），称$u$与$v$**相邻**，或互为**邻点**，并称这条边与它的**端点**$u$和$v$**关联**。$v$的**邻域**是$N(v) = \set{u \in V : uv \in E}$。
:::

同时涉及多个图时，我们写$V(G)$和$E(G)$；并且总用$n = \abs{V}$表示顶点数，用$m = \abs{E}$表示边数。上述定义排除了**自环**（从一个顶点连到它自身的边）和**重边**（连接同一对顶点的多条边）；不含自环和重边的图称为**简单**图，允许它们出现时则称为**多重图**——在[[discrete/graph-algorithms]]中讨论柯尼斯堡（Königsberg）的七座桥时就要用到多重图。在**有向图**中，边是有序对$(u,v)$，画成箭头。除非另有说明，“图”均指有限的简单无向图。

图是抽象的二元组$(V, E)$，而不是它的某幅图画。位置、长度和交叉都属于图的**画法**：画出两条对角线的正方形，和中间有一个顶点的三角形，是同一个图$K_4$的两种画法；在$K_4$中，四个顶点两两相邻。学会透过画法看到图本身，是这门学科的主要技能之一。

::: definition 度 {#def-degree}
顶点$v$的**度**$\deg(v)$是与$v$关联的边的条数，因此$\deg(v) = \abs{N(v)}$。我们用$\delta(G)$和$\Delta(G)$分别表示最小度和最大度。度为$0$的顶点称为**孤立点**，度为$1$的顶点称为**叶子**；如果每个顶点的度都是$k$，就称$G$是**$k$-正则**的。
:::

下面就是前面许诺的那个只有一行的理由。

::: theorem 握手引理 {#thm-handshake}
在任何图中，

$$
\sum_{v \in V} \deg(v) = 2m.
$$ {#eq-handshake}
:::

::: proof
我们用两种方式来数这样的对$(v, e)$：其中$e$是一条边，$v$是它的一个端点（这就是**双重计数**，见[[discrete/counting]]）。按顶点分组，$v$恰好出现在$\deg(v)$个这样的对中，总共得到$\sum_v \deg(v)$个对。按边分组，每条边恰好有两个端点，总共得到$2m$个对。两种计数的结果相等。
:::

::: corollary {#cor-odd}
在任何图中，度为奇数的顶点的个数是偶数。
:::

::: proof
把[[#eq-handshake]]中的和按度为偶数和度为奇数拆开，可知$\sum_{\deg(v)\text{ 为奇数}} \deg(v) = 2m - \sum_{\deg(v)\text{ 为偶数}} \deg(v)$是偶数。若干个奇数之和为偶数，当且仅当项数为偶数。
:::

回到那次聚会：七位客人每人握手三次，度之和将是奇数$7 \cdot 3 = 21$，所以这样的聚会不存在。更一般地，$n$个顶点的$k$-正则图有$nk/2$条边，所以当$k$为奇数时$n$必为偶数。

把一个图的各顶点的度按非增顺序排列，就得到它的**度序列**；如果一个序列是某个图的度序列，就称它是**可图的**。由握手引理，可图序列的各项之和为偶数——这是一个必要条件，但不是充分条件。

::: example 哪些序列是可图的？ {#ex-graphic}
是否存在度序列为下列序列的图：(a) $(3, 3, 3, 1)$；(b) $(3, 3, 2, 2, 2)$？
::: solution
(a) 各项之和$10$是偶数，所以握手引理不能排除它。但这样的图只有四个顶点，因此每个度为$3$的顶点都与其余**全部**三个顶点相邻——特别地，与第四个顶点$d$相邻。于是$\deg(d) \ge 3$，与$\deg(d) = 1$矛盾。所以这个序列不是可图的。

(b) 各项之和为$12$，所以需要$6$条边。把顶点记为$a, b$（度为$3$）和$c, d, e$（度为$2$），试取

$$
ab,\quad ac,\quad ad,\quad bc,\quad be,\quad de .
$$

则$N(a) = \{b, c, d\}$，$N(b) = \{a, c, e\}$，$N(c) = \{a, b\}$，$N(d) = \{a, e\}$，$N(e) = \{b, d\}$，各顶点的度依次为$3, 3, 2, 2, 2$。注意这里的不对称性：一个例子就足以说明一个序列**是**可图的，但要说明它不是可图的，就需要证明**没有任何**图满足要求。
:::
:::

- [x] $(4, 4, 4, 4, 4)$

## 常见的图

有些图族出现得非常频繁，因而有了标准的名称。

- **完全图**$K_n$：$n$个顶点，两两相邻；它有$\binom{n}{2} = \frac{n(n-1)}{2}$条边。
- **路**$P_n$：顶点为$v_1, \dots, v_n$，边为$v_1v_2, \dots, v_{n-1}v_n$这$n - 1$条。**圈**$C_n$（$n \ge 3$）是在$P_n$上再添加边$v_nv_1$所得的图。
- **完全二部图**$K_{r,s}$：顶点集为$X \cup Y$，其中$\abs{X} = r$，$\abs{Y} = s$，边为$X$与$Y$之间的全部$rs$条边（$X$内部和$Y$内部都没有边）。$K_{1,s}$称为**星**。
- **立方体图**$Q_d$：顶点为长度为$d$的$2^d$个二进制串，两个串恰好在一个位置上不同时相邻。每个串有$d$个邻点，所以$Q_d$是$d$-正则的，由握手引理它有$d\,2^{d-1}$条边；$Q_2$是一个$4$-圈，$Q_3$是立方体的骨架。
- **彼得森（Petersen）图**：顶点为$\{1, \dots, 5\}$的十个$2$元子集，两个子集不相交时相邻。每个这样的二元子集恰好与另外$\binom32 = 3$个不相交，所以该图是$3$-正则的，有$15$条边。对于图论中那些看似合理的猜想，它是标准的反例。

图$G$的**补图**$\overline{G}$与$G$有相同的顶点，并且$uv$是$\overline{G}$的边当且仅当它不是$G$的边。

如果$V(H) \subseteq V(G)$且$E(H) \subseteq E(G)$，就称图$H$是$G$的**子图**；如果还有$V(H) = V(G)$，就称$H$是$G$的**生成**子图。对于$S \subseteq V$，**导出子图**$G[S]$以$S$为顶点集，以$G$中两个端点都在$S$中的所有边为边集。我们用$G - v$表示从$G$中删去顶点$v$及与它关联的边所得的图，用$G - e$和$G + e$分别表示从$G$中删去边$e$和向$G$中添加边$e$所得的图。

## 途径、路与连通性

::: definition 途径、迹、路与圈 {#def-walk}
从$u$到$v$的长为$k$的**途径**是一个顶点序列$u = v_0, v_1, \dots, v_k = v$，满足对$i = 1, \dots, k$有$v_{i-1}v_i \in E$；若$u = v$，则称它是**闭**途径。不重复使用任何边的途径称为**迹**，不重复经过任何顶点的途径称为**路**。**圈**是长$k \ge 3$的闭途径$v_0, v_1, \dots, v_k = v_0$，其中顶点$v_0, \dots, v_{k-1}$互不相同。
:::

长度数的是边而不是顶点：有$k+1$个顶点的路长度为$k$。每条路都是迹，每条迹都是途径，但反过来不成立：在以$\{1,2,3,4\}$为顶点集的$K_4$中，途径$1,2,1,3$重复了一条边，而迹$1, 2, 3, 1, 4$重复了一个顶点。

::: lemma 每条途径都包含一条路 {#lem-walk-path}
如果存在从$u$到$v$的途径，那么存在一条只用该途径中的边的从$u$到$v$的路。
:::

::: proof
在只用给定途径中的边的所有$u$–$v$途径中，选取长度最小的一条$W = (v_0, \dots, v_k)$（由良序原理，[[proofs/induction#thm-well-ordering]]）。如果$W$重复了某个顶点，即$v_i = v_j$且$i < j$，那么剪掉两者之间闭合的一段，就得到$v_0, \dots, v_i, v_{j+1}, \dots, v_k$——由于$v_i = v_j$与$v_{j+1}$相邻，它仍是一条$u$–$v$途径，但长度为$k - (j - i) < k$。这与最小性矛盾，所以$W$是一条路。
:::

::: definition 连通性与距离 {#def-connected}
如果存在一条$u$–$v$途径（由[[#lem-walk-path]]，等价地说，存在一条$u$–$v$路），就称顶点$u$与$v$**连通**。如果图$G$的任意两个顶点都连通，就称$G$是**连通**的。**距离**$d(u,v)$是最短的$u$–$v$路的长度；若不存在这样的路，则规定为$\infty$。
:::

::: theorem 连通分支 {#thm-components}
“$u$与$v$连通”是$V$上的等价关系。设$V_1, \dots, V_c$是它的等价类，则每个导出子图$G[V_i]$都是连通的，并且没有边连接两个不同的等价类。这些子图称为$G$的**连通分支**；$G$连通当且仅当$c = 1$。
:::

::: proof
这个关系是自反的（途径$(u)$的长度为$0$）、对称的（把途径反过来走）和传递的（在一条$u$–$v$途径后面接上一条$v$–$w$途径）。所以它是等价关系（[[proofs/relations#def-equivalence-relation]]），它的等价类构成$V$的一个划分（[[proofs/relations#thm-partition]]）。若$u, v \in V_i$，则一条$u$–$v$途径上的每个顶点都与$u$连通，因而属于$V_i$；于是这条途径落在$G[V_i]$中，所以$G[V_i]$是连通的。最后，一条边的两个端点彼此连通，因而属于同一个等价类。
:::

有些边在维系图的连通方面比其他边更重要。如果$G - e$的连通分支比$G$多，就称边$e$为**桥**。

::: lemma 桥与圈 {#lem-bridge}
对$G$的边$e = xy$，下列条件等价：(i) $e$不是桥；(ii) $x$与$y$在$G - e$中连通；(iii) $e$位于$G$的某个圈上。
:::

::: proof
(i) ⇒ (ii)。如果$x$和$y$位于$G - e$的不同连通分支中，那么把$e$加回去就会把这两个连通分支合并起来，而其他连通分支保持不变，于是$G$的连通分支比$G - e$少，$e$就是桥。

(ii) ⇒ (iii)。由[[#lem-walk-path]]，$G - e$中存在一条$x$–$y$路。由于长为$1$的$x$–$y$路只有$e$本身，这条路的长度至少为$2$；因此沿它从$x$走到$y$，再沿$e$返回，就得到一个经过$e$的圈。

(iii) ⇒ (i)。如果$e$位于圈$C$上，那么$C$去掉$e$就是$G - e$中的一条$x$–$y$路。任何用到$e$的途径都可以改走这条路，所以在$G$中连通的顶点在$G - e$中仍然连通，$e$不是桥。
:::

下列哪个命题对**每个**图都成立？
- [ ] 若$G$连通，则对每条边$e$，$G - e$都连通。
- [x] 删去位于某个圈上的一条边，不会增加连通分支的个数。
- [ ] 每条长度为正的闭途径都包含一个圈。
- [ ] 不重复任何边的途径也不重复任何顶点。

第二个命题就是[[#lem-bridge]]。第一个命题对路的每条边都不成立。第三个命题对沿单独一条边走过去再走回来的闭途径$u, v, u$不成立。第四个命题对共用一个顶点$w$的两个三角形不成立：可以用一条两次经过$w$的迹走遍这两个三角形。
:::

## 同构

两个图什么时候算是“相同”的？给顶点重新标号或者重新画图，都不应该有影响。

::: definition 同构 {#def-isomorphism}
称图$G$与$H$是**同构**的，记作$G \cong H$，是指存在双射$\varphi\colon V(G) \to V(H)$（[[proofs/functions#def-bijective]]），使得对所有$u, v \in V(G)$，

$$
uv \in E(G) \iff \varphi(u)\varphi(v) \in E(H).
$$

这样的双射称为一个**同构**。
:::

同构给顶点重新命名，使边对应到边，非边对应到非边。因此，任何仅由顶点和相邻关系定义的量，对同构的图都取相同的值；这样的量称为**不变量**。

::: proposition 不变量 {#prop-invariants}
若$\varphi\colon V(G)\to V(H)$是同构，则$G$与$H$的顶点数相同，边数也相同；对每个$v$有$\deg(\varphi(v)) = \deg(v)$（因此两者的度序列相同）；并且$\varphi$把$G$中的路和圈变为$H$中长度相同的路和圈。特别地，对每个长度，$G$与$H$中该长度的圈的个数相同；并且$G$连通当且仅当$H$连通。
:::

::: proof
定义中的性质说的是$u \in N(v) \iff \varphi(u) \in N(\varphi(v))$，而$\varphi$是双射，所以$\varphi$把$N(v)$双射地映到$N(\varphi(v))$上；因此度相同，再由握手引理，边数也相同。若$v_0, \dots, v_k$是$G$中的途径，则$\varphi(v_0), \dots, \varphi(v_k)$是$H$中的途径，并且（由于$\varphi$是单射）重复的顶点出现在完全相同的位置，所以路变为路，圈变为圈。由于$\varphi^{-1}$是从$H$到$G$的同构，所有结论反过来也成立。
:::

::: example 证明不同构 {#ex-noniso}
证明下面每一对图的度序列虽然相同，但它们并不同构：(a) $C_6$与两个不相交的三角形；(b) 三棱柱（三角形$a_1a_2a_3$和$b_1b_2b_3$，再加上边$a_1b_1, a_2b_2, a_3b_3$）与$K_{3,3}$。
::: solution
(a) 两者都有六个度为$2$的顶点和六条边。但$C_6$是连通的，两个三角形却不连通，而连通性是不变量（[[#prop-invariants]]）。

(b) 两者都是连通的$3$-正则图，都有六个顶点和九条边。三棱柱包含三角形$a_1a_2a_3$。在两部分别为$X$和$Y$的$K_{3,3}$中，每条边都连接$X$与$Y$，所以途径只有在走了偶数步之后才能回到出发的那一侧，因而不存在长为$3$的圈。三角形的个数是不变量，所以这两个图不同构。
:::
:::

::: example 与补图同构的图 {#ex-self-complementary}
证明$C_5 \cong \overline{C_5}$。
::: solution
把顶点标为$0, 1, 2, 3, 4$，使得$ij$是$C_5$的边当且仅当$j - i \equiv \pm 1 \pmod 5$。十个顶点对中其余的五个，即满足$j - i \equiv \pm 2 \pmod 5$的那些，是$\overline{C_5}$的边；它们构成圈$0, 2, 4, 1, 3, 0$——也就是五边形内部的五角星。

定义$\varphi(i) = 2i \bmod 5$，它把$0, 1, 2, 3, 4$分别映为$0, 2, 4, 1, 3$，是一个双射。由于$\varphi(j) - \varphi(i) \equiv 2(j - i) \pmod 5$，我们有$j - i \equiv \pm 1$当且仅当$\varphi(j) - \varphi(i) \equiv \pm 2$（乘以$2$即得；反方向则乘以$3$，因为$2 \cdot 3 \equiv 1$）。所以$ij \in E(C_5) \iff \varphi(i)\varphi(j) \in E(\overline{C_5})$，$\varphi$是同构。
:::
:::

不变量相等**并不能**说明两个图同构——$C_6$与两个不相交的三角形有相同的顶点数、边数和度序列。要证明$G \cong H$，必须给出一个双射，并验证它保持相邻关系。要证明$G \not\cong H$，只需找到一个使两者取值不同的不变量。
:::

::: quiz
图$G$和$H$都有$8$个顶点和$12$条边，并且两者的每个顶点的度都是$3$。由此可以得出什么结论？
- [ ] $G \cong H$，因为它们的度序列相同。
- [x] 目前还无法下结论：它们可能同构，也可能不同构。
- [ ] $G \not\cong H$，因为不同的图永远不同构。
- [ ] 只要两者都连通，就有$G \cong H$。
::: solution
立方体图$Q_3$和两个不相交的$K_4$都符合这一描述，但只有前者是连通的。即使都连通，也可能不同构：$Q_3$没有三角形，而有些$8$个顶点的连通$3$-正则图含有三角形（试着构造一个）。
:::
:::

::: remark 图有多少个？
在顶点集$[n] = \{1, \dots, n\}$上，$\binom n2$个顶点对中的每一个要么是边，要么不是，所以共有$2^{\binom n2}$个标号图；在同构意义下则少得多——四个顶点上的$64$个标号图只分成$11$个同构类。快速判定两个大图是否同构是一个著名的问题：2015年，拉斯洛·巴拜（László Babai）宣布了一个比尝试全部$n!$个双射快得多的算法，但是否存在多项式时间算法仍然未知。
:::

## 二部图

::: definition 二部图 {#def-bipartite}
如果一个图的顶点集可以分成两个不相交的集合$X$和$Y$（称为一个**二部划分**），使得每条边都有一个端点在$X$中、另一个端点在$Y$中，就称这个图是**二部图**。
:::

例子有：$K_{r,s}$；偶圈，其顶点在两侧之间交替出现；以及$Q_d$，取$X$为含偶数个$1$的串，因为改变一位就会改变这个奇偶性。奇圈**不是**二部图：沿着它走一圈，所在的一侧交替变化，所以走了奇数步之后应该位于对面一侧——可我们却回到了出发点。值得注意的是，奇圈是**唯一的**障碍。

::: lemma 奇闭途径 {#lem-odd-walk}
每条长度为奇数的闭途径都包含一个长度为奇数的圈（只用该途径的顶点和边）。
:::

::: proof
对途径的长度$k$用强归纳法（[[proofs/induction#thm-strong-induction]]）。设$W = (v_0, v_1, \dots, v_k = v_0)$，$k$为奇数；由于没有自环，$k \ge 3$。若$v_0, \dots, v_{k-1}$互不相同，则$W$是一个奇圈。否则存在$0 \le i < j \le k-1$使$v_i = v_j$，于是$W$分裂为两条闭途径

$$
(v_i, v_{i+1}, \dots, v_j) \quad\text{和}\quad (v_0, \dots, v_i, v_{j+1}, \dots, v_k)
$$

它们的长度分别为$j - i$和$k - (j - i)$，都介于$1$与$k - 1$之间。这两个长度之和为奇数$k$，所以其中一条途径的长度是奇数；它比$W$短，所以由归纳假设，它包含一个奇圈。
:::

::: theorem 二部图的刻画 {#thm-bipartite}
一个图是二部图，当且仅当它不含长度为奇数的圈。
:::

::: proof
($\Rightarrow$) 设$(X, Y)$是一个二部划分，$v_0, v_1, \dots, v_k = v_0$是一个圈。相继的顶点位于相对的两侧，所以$v_i$与$v_0$在同一侧当且仅当$i$为偶数。由于$v_k = v_0$，$k$为偶数。

($\Leftarrow$) 设$G$没有奇圈。在每个连通分支中选取一个根$r$，对该分支中的顶点$v$，若$d(r,v)$为偶数就把$v$放入$X$，若为奇数就放入$Y$。边从不连接不同的连通分支（[[#thm-components]]），所以只需考虑根为$r$的连通分支中的一条边$uv$。一条到$u$的最短路后接边$uv$，表明$d(r,v) \le d(r,u) + 1$；同理$d(r,u) \le d(r,v) + 1$。如果$u$和$v$在同一侧，那么$d(r,u)$与$d(r,v)$奇偶性相同且相差至多$1$，因而相等，设都等于$d$。于是从$r$到$u$的一条最短路、边$uv$、以及从$v$回到$r$的一条最短路构成一条长为奇数$2d + 1$的闭途径，由[[#lem-odd-walk]]，它包含一个奇圈——矛盾。所以每条边都连接$X$与$Y$。
:::

这个证明本身就是一个算法：从根出发，把广度优先搜索的各层交替地染成两种颜色；要么每条边都连接两种颜色，要么有某条边连接同一层的两个顶点，此时可以从中读出一个奇圈。

::: example 判定二部图 {#ex-bipartite-test}
设$G$是$6$-圈$1, 2, 3, 4, 5, 6, 1$再加上三条长对角线$14$、$25$、$36$所得的图，$G'$是该$6$-圈再加上一条弦$13$所得的图。哪个是二部图？彼得森图是二部图吗？
::: solution
在$G$中，从根$1$出发，邻点$2, 6, 4$的距离为$1$，$3, 5$（都与$2$相邻）的距离为$2$。所以$X = \{1, 3, 5\}$，$Y = \{2, 4, 6\}$，并且每条边——无论是圈上的边还是对角线——都连接一个奇数标号和一个偶数标号：$G$是二部图（事实上$G \cong K_{3,3}$）。

在$G'$中，从根$1$出发，顶点$2$、$6$和$3$的距离为$1$，而边$23$连接了其中的两个。证明中的闭途径是$1, 2, 3, 1$，即一个三角形，所以$G'$不是二部图。

彼得森图包含$5$-圈$12, 34, 15, 23, 45$（图中外圈的五边形），所以由[[#thm-bipartite]]，它不是二部图。
:::
:::

## 树

::: definition 森林与树 {#def-tree}
没有圈的图称为**无圈**图，或称**森林**。连通的森林称为**树**。
:::

家谱树、计算机中的文件夹、烷烃分子的碳骨架都是树，路和星也是树；森林的连通分支都是树。

::: lemma 叶子 {#lem-leaves}
每棵至少有两个顶点的树$T$至少有两个叶子；并且若$v$是叶子，则$T - v$是树。
:::

::: proof
$T$连通且至少有两个顶点，所以它有边。选取一条长度最大的路$v_0, v_1, \dots, v_k$，则$k \ge 1$。如果$v_0$有邻点$w \ne v_1$，那么要么$w$不在这条路上，此时$w, v_0, \dots, v_k$是一条更长的路；要么$w = v_i$且$i \ge 2$，此时$v_0, v_1, \dots, v_i, v_0$是一个圈——两者都不可能。所以$v_0$是叶子。同理$v_k$是叶子，并且由于$k \ge 1$，$v_k \ne v_0$。

若$v$是叶子，则由于$T$无圈，$T - v$也无圈。$T - v$是连通的，因为路的内部顶点在路上有两个邻点，而$v$只有一个邻点；所以两个异于$v$的顶点之间的路不经过$v$，在$T - v$中依然存在。
:::

::: theorem 树的刻画 {#thm-trees}
对有$n$个顶点的图$G$，下列条件等价：

1. $G$是树（连通且无圈）；
2. $G$连通且恰有$n - 1$条边；
3. $G$无圈且恰有$n - 1$条边；
4. $G$的任意两个顶点之间恰有一条路相连。
:::

::: proof
**第1步：有$n$个顶点的树有$n - 1$条边。** 对$n$用数学归纳法（[[proofs/induction#thm-induction]]）：只有一个顶点的树没有边；当$n \ge 2$时，删去一个叶子（[[#lem-leaves]]）后剩下一棵有$n - 1$个顶点的树，它有$n - 2$条边，所以$T$有$n - 1$条边。这就给出了(1) ⇒ (2)和(1) ⇒ (3)。

**(2) ⇒ (1)。** 设$G$连通且有$n - 1$条边，并假设它有圈。删去圈上的一条边后$G$仍然连通（[[#lem-bridge]]）；重复这一步骤，直到没有圈为止。最后得到一棵有$n$个顶点、但边数少于$n - 1$的树，与第1步矛盾。

**(3) ⇒ (1)。** 设$G$无圈，有$n - 1$条边，各连通分支的顶点数分别为$n_1, \dots, n_c$。每个连通分支都是树，所以由第1步，$G$有$\sum_i (n_i - 1) = n - c$条边。因此$c = 1$。

**(1) ⇒ (4)。** 由连通性，至少有一条路。假设$P \ne Q$是两条$u$–$v$路。$P$中有某条边不在$Q$上——因为一条从$u$出发、只用$Q$中的边的路只能一步一步地沿着$Q$走，从而等于$Q$。设$e = xy$是这样一条边，并且在$P$上$x$位于$y$之前。从$x$沿$P$退回到$u$，再沿$Q$走到$v$，然后沿$P$倒回到$y$，这样走不经过$e$，所以$x$与$y$在$G - e$中连通，由[[#lem-bridge]]，$e$位于某个圈上——这在树中是不可能的。

**(4) ⇒ (1)。** $G$是连通的。如果它有一个圈经过相继的顶点$x, y$，那么边$xy$和圈的其余部分就是两条不同的$x$–$y$路。
:::

::: corollary 生成树 {#cor-spanning-tree}
每个连通图都有生成树，因此有$n$个顶点的连通图至少有$n - 1$条边。有$n$个顶点和$c$个连通分支的森林恰有$n - c$条边。
:::

::: proof
逐条删去位于圈上的边；每次删除都保持图连通（[[#lem-bridge]]），最后得到一个连通且无圈的生成子图，由[[#thm-trees]]，它有$n - 1$条边。关于森林边数的结论已在(3) ⇒ (1)的证明中得到。
:::

::: example 数叶子 {#ex-leaves}
一棵树有两个度为$4$的顶点、一个度为$3$的顶点，其余顶点都是叶子。它有多少个叶子？
::: solution
设有$L$个叶子，则$n = 3 + L$，并由[[#thm-trees]]得$m = n - 1 = 2 + L$。由握手引理得

$$
4 + 4 + 3 + L = 2m = 4 + 2L,
$$

所以$L = 7$。这样的树确实存在：把$a$与$b$相连，给$a$接上三个叶子，给$b$接上两个叶子和一个顶点$c$，再给$c$接上两个叶子；这棵树有$10$个顶点，各顶点的度也符合要求。
:::
:::

::: quiz
一个森林有$20$个顶点和$3$个连通分支。它有多少条边？
- [ ] $19$
- [x] $17$
- [ ] $20$
- [ ] 取决于各连通分支的形状。
::: solution
每个连通分支都是一棵树，其边数比顶点数少一，所以无论各连通分支是什么形状，这个森林都有$20 - 3 = 17$条边（[[#cor-spanning-tree]]）。
:::
:::

### 标号树的计数

以$[n]$为顶点集的树有多少棵？当$n = 3$时有三棵（选定路的中间顶点即可）；当$n = 4$时有十六棵，即$4$个星和$4!/2 = 12$条路。

::: theorem 凯莱（Cayley）公式 {#thm-cayley}
当$n \ge 2$时，以$[n]$为顶点集的树恰有$n^{n-2}$棵。
:::

::: proof {collapsed}
**证明概要：普吕弗（Prüfer）双射**。给定$[n]$上的一棵树，重复以下操作$n - 2$次：删去标号最小的叶子，并记下它的邻点的标号。由此得到的**普吕弗编码**属于$[n]^{n-2}$，并且每个顶点$v$在其中恰好出现$\deg(v) - 1$次。反过来，由$[n]^{n-2}$中的任一序列都可以重建出这棵树：每一步被删去的叶子，必定是尚未删去、且不在序列剩余部分中出现的最小标号，最后再把剩下的两个顶点连起来。所以这种编码是树与序列之间的双射，从而共有$n^{n-2}$棵树。完整的细节以及另外三种证明，见艾格纳（Aigner）和齐格勒（Ziegler）的《数学天书中的证明》（*Proofs from THE BOOK*）。
:::

例如，$[7]$上以$13, 23, 35, 45, 56, 67$为边的树依次失去叶子$1, 2, 3, 4, 5$（它们轮流成为最小的叶子），记下的编码为$(3, 3, 5, 5, 6)$：度为$3$的顶点$3$和$5$各出现两次，度为$2$的顶点$6$出现一次，而叶子根本不出现。

## 邻接矩阵

设$V = \{v_1, \dots, v_n\}$，$G$的**邻接矩阵**是$n \times n$矩阵$A$，其中当$v_iv_j \in E$时$A_{ij} = 1$，否则$A_{ij} = 0$。它是对角线全为零的对称矩阵，各行之和就是各顶点的度。矩阵乘法可以用来数途径。

::: theorem 途径与邻接矩阵的幂 {#thm-walks}
对每个$k \ge 1$，元素$(A^k)_{ij}$等于从$v_i$到$v_j$的长为$k$的途径的条数。
:::

::: proof
对$k$用归纳法。长为$1$的途径就是一条边，所以$k = 1$的情形就是$A$的定义。从$v_i$到$v_j$的长为$k+1$的途径，是一条从$v_i$到某个$v_l$的长为$k$的途径后接一条边$v_lv_j$。对每个$l$，第一部分有$(A^k)_{il}$种选法（由归纳假设），最后一步有$A_{lj} \in \{0, 1\}$种选法，所以途径的条数为$\sum_{l} (A^k)_{il}\,A_{lj} = (A^{k+1})_{ij}$。
:::

一个三角形$xyz$恰好给出六条长为$3$的闭途径（三个起点，两个方向），而每条长为$3$的闭途径都来自一个三角形，所以

$$
\text{图 } G \text{ 中三角形的个数} = \frac{\operatorname{tr}(A^3)}{6}.
$$ {#eq-triangles}

::: example 爪子图中的途径 {#ex-paw}
**爪子图**（paw）的顶点为$1, 2, 3, 4$，边为$12, 13, 23, 34$。计算$A^2$和$A^3$，并解释其中一些元素的含义。
::: solution
$$
A = \begin{pmatrix} 0&1&1&0\\ 1&0&1&0\\ 1&1&0&1\\ 0&0&1&0 \end{pmatrix},\qquad
A^2 = \begin{pmatrix} 2&1&1&1\\ 1&2&1&1\\ 1&1&3&0\\ 1&1&0&1 \end{pmatrix},\qquad
A^3 = \begin{pmatrix} 2&3&4&1\\ 3&2&4&1\\ 4&4&2&3\\ 1&1&3&0 \end{pmatrix}.
$$

$A^2$的对角线列出了各顶点的度$2, 2, 3, 1$，因为长为$2$的闭途径就是沿一条边走过去再走回来。$(A^2)_{14} = 1$数的是途径$1, 3, 4$；$(A^2)_{34} = 0$，因为$3$和$4$没有公共邻点。$(A^3)_{12} = 3$数的是$1,2,1,2$、$1,3,1,2$和$1,2,3,2$。最后，$\operatorname{tr}(A^3) = 6$，所以由[[#eq-triangles]]，爪子图恰有一个三角形，即$123$。
:::
:::

::: application 谱与随机游走
$A$的特征值，即图的**谱**，携带着图的结构信息：例如，一个连通图是二部图，当且仅当它的最大特征值的相反数也是特征值。特征值还支配着图上的随机游走，即[[probability/markov-chains]]中的马尔可夫链——按照随机浏览者在各网页停留时间的多少给网页排序，背后正是这一思想。
:::

::: history
人们通常把图论的起源追溯到18世纪30年代莱昂哈德·欧拉（Leonhard Euler）对柯尼斯堡七桥问题的解答（[[discrete/graph-algorithms]]）。树在一个世纪之后才出现：1847年，古斯塔夫·基尔霍夫（Gustav Kirchhoff）用生成树分析电网络；阿瑟·凯莱（Arthur Cayley）在1857年对有根树进行了计数，又在19世纪70年代用树来计数烷烃$\mathrm{C}_k\mathrm{H}_{2k+2}$的同分异构体。“图”（*graph*）这个词是詹姆斯·约瑟夫·西尔维斯特（James Joseph Sylvester）引入的，见于他1878年发表在《自然》（*Nature*）杂志上的一篇短文，那篇短文把化学结构图与代数作了比较。凯莱于1889年发表了公式$n^{n-2}$，不过卡尔·威廉·博尔夏特（Carl Wilhelm Borchardt）在1860年就已得到一个等价的结果；海因茨·普吕弗（Heinz Prüfer）的双射证明则发表于1918年。这门学科的第一本教科书——德内什·柯尼希（Dénes Kőnig）的《有限图与无限图的理论》（*Theorie der endlichen und unendlichen Graphen*）——于1936年问世。
:::

## 后续内容

[[discrete/graph-algorithms]]一开篇就讨论广度优先搜索，包括其正确性的证明；那一章还会讨论权最小的生成树，以及欧拉关于用到每条边的途径的定理。二部图将在[[discrete/colouring-planarity]]中再次出现：它们恰是可以用两种颜色着色的图，也是霍尔（Hall）匹配定理的背景。邻接矩阵经由[[linear-algebra/eigenvalues]]通向谱图论；而在同构意义下对图计数，是一个关于对称性的问题，那正是[[abstract-algebra/group-actions]]的主题。

::: summary
- 图是一个顶点集，连同由它的一些$2$元子集（边）构成的集合；画法只是图的一幅图画。握手引理$\sum_v \deg(v) = 2m$迫使奇度顶点的个数为偶数（[[#thm-handshake]]）。
- 途径可以重复任何东西，迹不重复边，路不重复顶点；每条途径都包含一条路。“连通”是一个等价关系，它的等价类就是连通分支（[[#thm-components]]）。
- 一条边是桥，当且仅当它不在任何圈上（[[#lem-bridge]]）。
- 同构就是保持相邻关系的重新标号。不变量可以证明两个图不同；要证明它们同构，则需要给出一个具体的双射。
- 一个图是二部图当且仅当它没有奇圈，而广度优先搜索的各层给出二部划分（[[#thm-bipartite]]）。
- 树可以刻画为：连通且无圈；连通且有$n - 1$条边；无圈且有$n - 1$条边；或者任意两点之间的路唯一（[[#thm-trees]]）。每个连通图都有生成树；$[n]$上共有$n^{n-2}$棵标号树。
- $(A^k)_{ij}$等于从$v_i$到$v_j$的长为$k$的途径的条数。
:::

::: exercise 有多少个叶子？ {level=1 check="5"}
一棵树有三个度为$3$的顶点、两个度为$2$的顶点，其余顶点都是叶子。它有多少个叶子？
::: solution
设有$L$个叶子，则$n = 5 + L$，$m = 4 + L$。由握手引理得$9 + 4 + L = 2(4 + L)$，所以$L = 5$。（例子：由三个度为$3$的顶点构成的路$a, b, c$，在$a$和$c$上各接两个叶子，再接上路$b, d, e, f$，其中$d, e$的度为$2$，$f$是叶子。）
:::
:::

::: exercise 图或其补图 {level=2}
证明：对每个图$G$，$G$与$\overline{G}$中至少有一个是连通的。
::: hint
假设$G$不连通，任取两个顶点$u, v$。它们是否在$G$的同一个连通分支中？
:::
::: solution
设$G$不连通，并设$u \ne v$。若它们位于$G$的不同连通分支中，则$uv \notin E(G)$，所以$uv$是$\overline{G}$的边。若它们位于同一个连通分支中，则在另一个连通分支中取一个顶点$w$；于是$uw, vw \notin E(G)$，所以$u, w, v$是$\overline{G}$中的一条路。无论哪种情形，$u$与$v$在$\overline{G}$中都连通，所以$\overline{G}$是连通的。
:::
:::

::: exercise 两个度相同的顶点 {level=2}
证明：每个至少有两个顶点的图都有两个度相同的顶点。
::: hint
可能的度为$0, 1, \dots, n-1$。$0$和$n-1$能同时出现吗？然后利用鸽巢原理（[[discrete/advanced-counting#thm-pigeonhole]]）。
:::
::: solution
每个顶点的度都属于$\{0, 1, \dots, n-1\}$。$0$和$n-1$这两个值不能同时出现：度为$n-1$的顶点与其他每个顶点都相邻，所以没有孤立点。因此这$n$个度至多取$n-1$个不同的值，由鸽巢原理，其中有两个相等。
:::
:::

::: exercise 顶点1为叶子的树 {level=2 check="625"}
以$[6]$为顶点集、并且以顶点$1$为叶子的树有多少棵？
::: hint
在普吕弗编码中，顶点$v$恰好出现$\deg(v) - 1$次。
:::
::: solution
顶点$1$是叶子当且仅当它不在普吕弗编码中出现。普吕弗编码是$[6]$上的树与$[6]^4$之间的双射，所以这些树对应于$\{2, \dots, 6\}^4$中的序列：在全部$6^4 = 1296$棵树中，这样的树有$5^4 = 625$棵。
:::
:::

::: exercise 用矩阵数三角形 {level=2 check="7"}
从$K_5$中去掉一条边后，所得的图包含多少个三角形？用[[#eq-triangles]]验证你的答案。
::: solution
$K_5$有$\binom53 = 10$个三角形，其中有$3$个包含被去掉的边$uv$（第三个顶点每取一个就得到一个），所以剩下$7$个。用邻接矩阵可以算出$\operatorname{tr}(A^3) = 42 = 6 \cdot 7$。
:::

::: exercise 边数多则必连通 {level=3}
证明：有$n$个顶点且边数多于$\binom{n-1}{2}$的图是连通的，并且这个界不能再降低。
::: hint
若$G$不连通，设$C$是其中一个连通分支，数一数$C$与其余部分之间的顶点对，它们都不可能是边。
:::
::: solution
设$G$不连通，$C$是某个连通分支的顶点集，$\abs{C} = k$，$1 \le k \le n-1$。$C$与$V \setminus C$之间的$k(n-k)$个顶点对都不是边，所以$m \le \binom{n}{2} - k(n-k)$。由于

$$
k(n-k) - (n-1) = (k-1)(n-1-k) \ge 0,
$$

我们得到$m \le \binom n2 - (n - 1) = \binom{n-1}{2}$。所以边数多于$\binom{n-1}2$就迫使图连通。这个界是精确的：$K_{n-1}$加上一个孤立点有$\binom{n-1}{2}$条边，而且不连通。
:::
:::

::: exercise 彼得森图没有短圈 {#exr-petersen-girth level=3}
利用以$\{1, \dots, 5\}$的$2$元子集为顶点的描述，证明彼得森图没有长为$3$或$4$的圈。
::: solution
**三角形**。三个两两相邻的顶点就是一个$5$元集合的三个两两不相交的$2$元子集，它们共含$6$个不同的元素——这不可能。

**$4$-圈**。设$A, B, C, D, A$是一个$4$-圈，则$A, B, C, D$互不相同，且$A \cap B$、$B \cap C$、$C \cap D$、$D \cap A$都是空集。$A$和$C$都与$B$不相交，所以它们是$3$元集合$\{1, \dots, 5\} \setminus B$的两个不同的$2$元子集；它们恰有一个公共元素，且$\abs{A \cup C} = 3$。而$B$和$D$都与$A \cup C$不相交，所以两者都等于$2$元集合$\{1, \dots, 5\} \setminus (A \cup C)$。于是$B = D$，矛盾。
:::
:::

::: exercise 度大则叶子多 {level=3}
设树$T$有一个度为$k \ge 2$的顶点。证明$T$至少有$k$个叶子。
::: hint
设$n_i$是度为$i$的顶点的个数。把$\sum_i i\,n_i = 2(n-1)$与$n = \sum_i n_i$结合起来。
:::
::: solution
$T$没有孤立点，所以$n = \sum_{i \ge 1} n_i$；由握手引理和[[#thm-trees]]，$\sum_{i\ge1} i\,n_i = 2n - 2 = \sum_{i \ge 1} 2n_i - 2$。整理得

$$
n_1 = 2 + \sum_{i \ge 3} (i - 2)\,n_i .
$$

和式中的各项都非负。若$k \ge 3$，和式中含有项$(k-2)n_k \ge k - 2$，所以$n_1 \ge k$；若$k = 2$，则直接有$n_1 \ge 2 = k$。
:::
:::
