在地图应用中输入两个地址，一秒钟之内它就会给出最快的路线——这条路线是从一个有数百万个路口的道路网络中天文数字般多的可能路线里选出来的。没有人会去逐一检查所有路线。程序运行的是一个**算法**，即一个精确的、逐步执行的过程；我们之所以能信任它的答案，是因为这个算法的正确性已经得到了**证明**。

本章研究基本的图算法：搜索一个图，为相互依赖的任务排序，求最短路和费用最低的连接网络，以及一笔画出一个图。对每个算法，我们都证明它的正确性，并估计它的工作量。我们还会看到一个鲜明的对比：判定一个图是否有一条恰好经过每条**边**一次的闭途径是容易的，但要判定它是否有一个恰好经过每个**顶点**一次的圈，却没有人知道高效的方法。本章通篇使用[[discrete/graphs]]中的术语。

## 图的表示

计算机存储一个图有两种标准方式。**邻接矩阵**（[[discrete/graphs#thm-walks]]）有$n^2$个元素，一步就能回答“$uv$是不是边？”。**邻接表**记录每个顶点的邻点；由握手引理（[[discrete/graphs#thm-handshake]]），它们的总长度为$2m$，所以所需的存储空间与$n + m$成正比。道路网络和社交网络都是**稀疏**的（$m$只是$n$的一个不大的倍数，远小于$\binom n2$），对于这样的图，邻接表要小得多，扫描起来也快得多。下面的算法都使用邻接表。

我们通过计数基本步骤（检查一条边、比较两个数）来衡量代价，把它表示为$n$和$m$的函数，并用$O(f)$表示“至多是$f$的常数倍”。时间$O(n + m)$意味着每个顶点和每条边都只被处理有界次——这是所能期望的最好结果。

## 广度优先搜索

系统地探索一个图的最简单的方法，是从一个起始顶点出发逐层向外扩展：先是它的邻点，然后是这些邻点的尚未访问的邻点，依此类推。等待处理的顶点保存在一个**队列**中，队列是一种从前端取出元素、从后端添加元素的列表。

::: algorithm 广度优先搜索（BFS） {#alg-bfs}
**输入：**图$G$和起始顶点$s$。

1. 标记$s$，令$\mathrm{dist}(s) = 0$，并令队列$Q$只含$s$。
2. 当$Q$非空时：取出$Q$队首的顶点$u$；对$u$的每个尚未标记的邻点$w$，标记$w$，令$\mathrm{dist}(w) = \mathrm{dist}(u) + 1$，$\mathrm{parent}(w) = u$，并把$w$加到$Q$的队尾。
:::

::: theorem 广度优先搜索的正确性 {#thm-bfs}
从$s$出发的BFS恰好标记$s$所在连通分支中的顶点，并且对其中每个顶点$v$有$\mathrm{dist}(v) = d(s,v)$；从$v$出发沿父指针回溯，就得到一条回到$s$的最短路。使用邻接表时，它的运行时间为$O(n + m)$。
:::

::: proof
**(a) $\mathrm{dist}(v) \ge d(s,v)$。** 按标记的先后顺序归纳可知，从一个已标记的顶点$v$出发沿父指针回溯，得到一条长度恰为$\mathrm{dist}(v)$的途径$v, \mathrm{parent}(v), \dots, s$。所以$v$属于$s$所在的连通分支，且$d(s,v) \le \mathrm{dist}(v)$。

**(b) 队列是有序的。** 我们断言：每当$Q = (u_1, \dots, u_r)$（从队首到队尾）时，都有

$$
\mathrm{dist}(u_1) \le \mathrm{dist}(u_2) \le \dots \le \mathrm{dist}(u_r) \le \mathrm{dist}(u_1) + 1 .
$$

开始时这成立，而且每一步都保持它：取出$u_1$，并在队尾添加$\mathrm{dist} = \mathrm{dist}(u_1) + 1$的顶点后，得到的队列中的值仍然递增，并且最后一个值至多为$\mathrm{dist}(u_1) + 1 \le \mathrm{dist}(u_2) + 1$。特别地，顶点按$\mathrm{dist}$非减的顺序离开队列。

**(c) $\mathrm{dist}(v) \le d(s,v)$。** 我们对$k$归纳证明：每个满足$d(s,v) = k$的顶点$v$都会被标记，且$\mathrm{dist}(v) \le k$。当$k = 0$时，$v = s$。设$d(s,v) = k + 1$，$u$是一条最短$s$–$v$路上$v$的前一个顶点，于是$d(s,u) = k$；由归纳假设，$u$被标记且$\mathrm{dist}(u) \le k$，而每个被标记的顶点最终都会从队列中取出。当$u$被取出时，$v$会被检查。若$v$尚未标记，则它得到$\mathrm{dist}(v) = \mathrm{dist}(u) + 1 \le k+1$。否则，$v$已在此前作为某个顶点$x$的邻点被标记，而$x$不晚于$u$被取出，所以由(b)，$\mathrm{dist}(v) = \mathrm{dist}(x) + 1 \le \mathrm{dist}(u) + 1 \le k + 1$。

综合(a)和(c)可知，被标记的顶点恰好是$s$所在连通分支中的顶点，并且$\mathrm{dist}(v) = d(s,v)$；(a)中沿父指针得到的途径长度为$d(s,v)$，所以它是一条最短路。最后，每个顶点至多进入队列一次（它在进入队列时被标记），在它离开队列时，它的邻接表被扫描一次。总工作量与$n + \sum_v \deg(v) = n + 2m$成正比。
:::

## 深度优先搜索与拓扑排序

深度优先搜索的探索方式，就像一个人带着一团线走迷宫：尽可能地向前走，走不通时，就退回到最近一个还有未探索通道的岔路口。

::: algorithm 深度优先搜索（DFS） {#alg-dfs}
**访问**顶点$u$：标记$u$；然后依次对$u$的每个邻点$w$，若$w$未被标记，则令$\mathrm{parent}(w) = u$并访问$w$。从$s$出发的深度优先搜索就是调用“访问$s$”。
:::

与BFS一样，从$s$出发的DFS恰好标记$s$所在的连通分支，父边构成该连通分支的一棵生成树（称为**DFS树**），运行时间为$O(n + m)$。树的形状有所不同，而它有一个有用的性质：如果$u$位于从$v$到$s$的树路上，就称顶点$v$是$u$的**后代**。

::: lemma 边连接祖先与后代 {#lem-dfs}
若$uv$是一条边，且DFS先标记$u$、后标记$v$，则在DFS树中$v$是$u$的后代。
:::

::: proof
在调用“访问$u$”运行期间被标记的顶点，恰好是$u$及其后代，因为它们都是通过由这次调用发起的调用到达的。“访问$u$”开始时，$v$尚未被标记，而在这次调用结束之前，它会检查$u$的每个邻点，包括$v$。在检查$v$的那一刻，要么$v$仍未被标记——此时从$u$调用“访问$v$”，$v$是$u$的子节点——要么$v$已在这次调用期间被标记。无论哪种情形，$v$都是$u$的后代。
:::

因此，每条不是树边的边都连接某个顶点与它的一个祖先，并与两者之间的树路一起围成一个圈。反过来，如果每条边都是树边，那么这个图是森林。所以，从每个未标记的顶点重新开始DFS、直到所有顶点都被标记，就能检测出圈：**一个图无圈，当且仅当DFS找不到非树边。**

### 任务排序

在**有向图**中，每条边（现在称为**弧**）都有一个方向$u \to v$。有向图可以为依赖关系建模：弧$u \to v$可以表示课程$u$必须在课程$v$之前修读，或者文件$u$必须在文件$v$之前编译。**有向圈**是沿着弧排列的互不相同的顶点序列$v_0 \to v_1 \to \dots \to v_{k-1} \to v_0$；没有有向圈的有向图称为**有向无圈图**（DAG）。

::: definition 拓扑序 {#def-topological}
有向图的**拓扑序**是它的顶点的一种排列$v_1, v_2, \dots, v_n$，使得每条弧都从前指向后：由$v_i \to v_j$可推出$i < j$。
:::

::: theorem 拓扑序与圈 {#thm-topo}
一个有向图有拓扑序，当且仅当它没有有向圈。
:::

::: proof
($\Rightarrow$) 在拓扑序中，每条弧都使位置增大，所以沿一个有向圈$v_0 \to \dots \to v_0$走一圈，就会使$v_0$的位置比它自身还大。

($\Leftarrow$) 首先，DAG有**源点**，即没有进入弧的顶点。否则，从任一顶点出发，不断沿进入弧向后退；走了$n$步之后，我们访问了$n + 1$个顶点，所以由鸽巢原理（[[discrete/advanced-counting#thm-pigeonhole]]），有某个顶点重复出现，而在第一次出现重复时，该顶点两次被访问之间的那些弧构成一个有向圈。现在对$n$用归纳法；只有一个顶点时，排序是平凡的。给定一个有$n \ge 2$个顶点的DAG，把一个源点$v$排在最前面。删去$v$后剩下一个有$n - 1$个顶点的DAG，由归纳假设它有拓扑序；把它接在$v$的后面，就得到一个拓扑序，因为与$v$关联的弧都是从$v$出发的。
:::

这个证明本身就是一个算法，由阿瑟·卡恩（Arthur Kahn）于1962年提出：反复输出一个源点并把它删去。如果某一时刻已没有源点，那么剩下的图含有有向圈，拓扑序不存在。

::: example 安排课程 {#ex-topo}
一名学生必须遵守以下先修要求：逻辑（Logic）→ 集合（Sets），集合 → 函数（Functions），集合 → 关系（Relations），函数 → 计数（Counting），关系 → 图（Graphs），计数 → 概率（Probability），计数 → 算法（Algorithms），图 → 算法。找出修读这八门课程的一种顺序。
::: solution
反复删去一个源点。先是逻辑，然后是集合；这时函数和关系都是源点。选择关系之后，图成为源点；接下来依次是图、函数和计数，此后概率和算法都可以选。一个可行的顺序是

$$
\text{逻辑},\ \text{集合},\ \text{关系},\ \text{图},\ \text{函数},\ \text{计数},\ \text{概率},\ \text{算法}.
$$

每条弧都从前指向后。过程中的选择表明拓扑序并不唯一；这个DAG共有$16$个拓扑序。
:::

## 最短路：迪杰斯特拉算法

在**带权图**中，每条边$e$都有一个权$w(e) \ge 0$——可以是长度、行程时间或费用。一条路的长度是它的各边权之和，而$d(s,v)$现在表示$s$–$v$路的最小长度。当所有权都等于$1$时，这就是原来的距离，BFS可以求出它；对于一般的权，边数最少的路可能远不是最短的。

::: algorithm 迪杰斯特拉算法 {#alg-dijkstra}
**输入：**权非负的带权图和起始顶点$s$。

1. 令$\mathrm{dist}(s) = 0$，对$v \ne s$令$\mathrm{dist}(v) = \infty$。此时还没有顶点被**确定**。
2. 当存在$\mathrm{dist}$有限的未确定顶点时：选取一个$\mathrm{dist}(u)$尽可能小的未确定顶点$u$，将它确定；然后对$u$的每个未确定的邻点$v$，若$\mathrm{dist}(u) + w(uv) < \mathrm{dist}(v)$，则令$\mathrm{dist}(v) = \mathrm{dist}(u) + w(uv)$，$\mathrm{parent}(v) = u$。
:::

值$\mathrm{dist}(v)$是一个**暂定**距离，即到目前为止找到的最好值；关键的论断是：一旦$v$被确定，这个值就是精确的。

::: theorem 迪杰斯特拉算法的正确性 {#thm-dijkstra}
若所有权都非负，则每个顶点$u$在被确定的那一刻满足$\mathrm{dist}(u) = d(s,u)$。算法停止时，对每个顶点$v$有$\mathrm{dist}(v) = d(s,v)$，并且父指针给出最短路。
:::

::: proof
在任何时刻，$\mathrm{dist}(v)$有限的顶点都可以经由一条长为$\mathrm{dist}(v)$的途径从$s$到达：沿父指针回溯即可（设置该值时父顶点已被确定，而已确定顶点的值不再改变）。因此始终有$\mathrm{dist}(v) \ge d(s,v)$。

我们对已确定顶点的个数用归纳法证明主要论断。第一个被确定的顶点是$s$，$\mathrm{dist}(s) = 0 = d(s,s)$。假设在$u$之前被确定的每个顶点被确定时其值都是真实距离，并假设（为导出矛盾）选中$u$时$\mathrm{dist}(u) > d(s,u)$。那么$d(s,u)$有限；设$P$是一条最短$s$–$u$路。它从已确定的顶点$s$出发，到未确定的顶点$u$结束，因此可设$y$是$P$上第一个未确定的顶点，$x$是$y$的前一个顶点。当$x$被确定时，$\mathrm{dist}(x) = d(s,x)$，并且边$xy$被检查过，所以

$$
\mathrm{dist}(y) \le d(s,x) + w(xy) = d(s,y) \le d(s,u) < \mathrm{dist}(u).
$$

这里$d(s,x) + w(xy) = d(s,y)$，是因为$P$直到$y$的部分是一条到$y$的最短路线（否则可以用更短的路线替换它，从而缩短$P$）；而$d(s,y) \le d(s,u)$，是因为$P$的其余部分长度非负。但$y$未被确定，所以算法会选择$y$而不是$u$——矛盾。

算法停止时，每个从$s$可达的顶点$v$都已被确定：否则，在一条从$s$到$v$的路上，第一个未确定的顶点$y$紧跟在某个已确定的顶点$x$之后，于是$\mathrm{dist}(y) \le \mathrm{dist}(x) + w(xy) < \infty$，循环就不会停止。不可达的顶点则保持$\mathrm{dist} = \infty = d(s,v)$。
:::

::: warning 负权使迪杰斯特拉算法失效
证明中用到了$d(s,y) \le d(s,u)$，这需要权非负。在有弧$s \to a$（权为$2$）、$s \to b$（权为$3$）和$b \to a$（权为$-2$）的有向图中，迪杰斯特拉算法以距离$2$确定$a$，但路线$s \to b \to a$的长度为$1$。负权需要用其他方法处理，例如贝尔曼-福特（Bellman–Ford）算法。
:::

通过扫描列表来选取下一个顶点，运行时间为$O(n^2)$；把暂定距离保存在**优先队列**（堆）中，运行时间为$O((n + m)\log n)$，足以应付整个大陆规模的道路网络。

- [ ] 到一个顶点的最短路总是使用尽可能少的边。
::: solution
暂定距离只会减小，并且由[[#thm-dijkstra]]，每个新确定的顶点到$s$的距离都不小于之前所有已确定顶点的距离。最后一个选项在[[#ex-dijkstra]]中不成立：到$G$的最短路线用了五条边，尽管三条边就足以到达$G$。
:::
:::

## 最小生成树

一家公司想用电缆把$n$个城镇连接起来，使得每个城镇都能通达其他每个城镇，其中连接$uv$的费用为$w(uv) > 0$。最便宜的网络没有圈——删去圈上的一条边后网络仍然连通（[[discrete/graphs#lem-bridge]]），而且省了钱——所以它是一棵生成树。连通带权图的**最小生成树**（MST）是总权$w(T) = \sum_{e \in T} w(e)$尽可能小的生成树$T$。最小生成树一定存在，因为连通图至少有一棵生成树（[[discrete/graphs#cor-spanning-tree]]），而且只有有限多棵。

尝试所有生成树是没有希望的（$K_n$有$n^{n-2}$棵生成树），所以我们需要一种识别好边的方法。对满足$\varnothing \ne S \ne V$的顶点集$S$，如果一条边有一个端点在$S$中、另一个端点在$S$外，就称这条边**跨越**割$(S, V \setminus S)$。

::: theorem 割性质 {#thm-cut-property}
设$F$是包含在某棵最小生成树中的边集，$S$是一个顶点集，使得$F$中没有边跨越割$(S, V\setminus S)$。若$e$是所有跨越该割的边中权最小的，则$F \cup \{e\}$包含在某棵最小生成树中。
:::

::: proof
设$T$是包含$F$的一棵最小生成树。若$e \in T$，则结论已成立；故设$e \notin T$，并设$e = xy$，$x \in S$，$y \notin S$。由[[discrete/graphs#thm-trees]]，$T$中有唯一的一条$x$–$y$路$P$。它从$S$内出发，在$S$外结束，所以$P$的某条边$f$跨越该割。于是$f \notin F$（$F$中没有边跨越该割），且$f \ne e$（因为$e \notin T$）。

令$T' = T - f + e$。它有$n - 1$条边，并且是连通的：$f$的两个端点仍然相连——沿$P$走到$x$，经过$e$到达$y$，再沿$P$走即可。所以由[[discrete/graphs#thm-trees]]，$T'$是生成树，并且

$$
w(T') = w(T) - w(f) + w(e) \le w(T),
$$

这是因为$f$也跨越该割，所以$w(e) \le w(f)$。因此$T'$是最小生成树，并且它包含$F \cup \{e\}$。
:::

有两个经典算法逐条边地构造最小生成树，只是添加边的顺序不同。

::: algorithm 普里姆（Prim）算法与克鲁斯卡尔（Kruskal）算法 {#alg-mst}
**普里姆算法。** 从$S = \{s\}$和$F = \varnothing$开始。重复$n - 1$次：选取一条跨越$(S, V \setminus S)$的权最小的边，把它加入$F$，并把它在$S$外的端点加入$S$。

**克鲁斯卡尔算法。** 把边按权从小到大排序，从$F = \varnothing$开始。按顺序逐一考察各边：只要一条边的两个端点位于森林$(V, F)$的不同连通分支中，也就是说，只要它不产生圈，就把它加入$F$。
:::

::: corollary {#cor-mst}
普里姆算法和克鲁斯卡尔算法都能求出连通带权图的一棵最小生成树。
:::

::: proof
对这两个算法，我们都证明$F$始终包含在某棵最小生成树中；开始时$F = \varnothing$，这一点成立。

**普里姆算法。** $F$中的边都连接$S$中的顶点，所以没有一条跨越$(S, V \setminus S)$，而加入的边是一条权最小的跨越边（由于$G$连通，只要$S \ne V$，跨越边就存在）。于是割性质适用。

**克鲁斯卡尔算法。** 当加入边$e = uv$时，设$S$是$(V, F)$中包含$u$的连通分支的顶点集，于是$v \notin S$，并且$F$中没有边跨越$(S, V \setminus S)$。在$e$之前考察过的边，要么已被加入$F$，要么因为两个端点位于森林的同一个连通分支中而被舍弃；连通分支只会增大，所以无论哪种情形，它的两个端点现在都位于同一个连通分支中，它不跨越该割。因此，在排好的顺序中，每条跨越边都不早于$e$，所以$e$是一条权最小的跨越边，割性质适用。

最后，$F$是一棵生成树：对普里姆算法，它有$n - 1$条边，把$S = V$中的所有顶点都与$s$连接起来；对克鲁斯卡尔算法，$F$无圈，而如果它有两个连通分支，那么$G$中连接这两个分支的边在被考察时就会被加入。包含在最小生成树$T$中的生成树与$T$的边数相同，所以它**就是**$T$。
:::

::: example 手工执行普里姆算法和克鲁斯卡尔算法 {#ex-mst}
求本章贯穿例子的一棵最小生成树。
::: solution
**克鲁斯卡尔算法。** 按权的顺序，各边依次为$BC\,(1)$、$AC\,(2)$、$DE\,(3)$、$AB\,(4)$、$BD\,(5)$、$DF\,(6)$、$EG\,(7)$、$CD\,(8)$、$EF\,(9)$、$CF\,(10)$、$FG\,(11)$。我们加入$BC$、$AC$和$DE$；舍弃$AB$（它会围成三角形$ABC$）；加入$BD$、$DF$和$EG$。这时已有$6 = n - 1$条边，其余的边都会围成圈。这棵树的权为$1 + 2 + 3 + 5 + 6 + 7 = 24$。

**从$A$出发的普里姆算法。** 离开$\{A\}$的权最小的边是$AC\,(2)$；然后是$BC\,(1)$；从$\{A, B, C\}$出发，权最小的跨越边是$BD\,(5)$；然后是$DE\,(3)$、$DF\,(6)$，最后是$EG\,(7)$。得到的是同样的六条边，只是顺序不同。

由于各边的权互不相同，这是唯一的最小生成树（[[#exr-unique-mst]]）。
:::

## 欧拉环游

柯尼斯堡（Königsberg，今加里宁格勒）城建在普雷格尔河两岸和河中的两个岛上，七座桥把这四块陆地连接起来。一位市民能否散一次步，恰好经过每座桥一次？把每块陆地作为一个顶点、每座桥作为一条边，得到一个多重图，其中克奈普霍夫（Kneiphof）岛的度为$5$，其余三块陆地的度都是$3$。

::: definition 欧拉迹与欧拉回路 {#def-euler}
多重图中的**欧拉迹**是恰好经过每条边一次的迹；**欧拉回路**是闭的欧拉迹。
:::

在多重图中，自环对其所在顶点的度贡献$2$，因此握手引理仍然成立。

::: theorem 欧拉（Euler）定理 {#thm-euler-circuit}
至少有一条边的连通多重图有欧拉回路，当且仅当每个顶点的度都是偶数。
:::

::: proof
($\Rightarrow$) 沿着回路走。每次经过一个顶点时，回路在那里用掉两条边，一条进、一条出；而在第一个顶点处的出发和结束，也以同样的方式配成一对。由于每条边恰好用一次，每个顶点的度都是偶数。

($\Leftarrow$) 设所有顶点的度都是偶数。先证明一个断言：**若多重图$H$的所有度都是偶数，且$u$的度为正，则从$u$出发、沿未用过的边尽可能长地走下去的迹，必定终止于$u$。** 事实上，每当这条迹进入一个顶点$w \ne u$时，它已经用了$w$处的奇数条边（之前每次经过用两条，再加上进入的这一条），所以由于$\deg_H(w)$是偶数，还剩下一条未用过的边，迹可以继续走下去。由于边只有有限多条，迹终将停止，所以它只能停在$u$：它是一条闭迹。

现在设$C$是$G$中长度最大的闭迹（由上述断言，闭迹存在）。假设$C$漏掉了某条边。那么有某条未用过的边与$C$上的顶点关联：如果一条未用过的边没有端点在$C$上，那么由连通性，存在一条从$C$的某个顶点到这条边的路，路上有第一条离开$C$的顶点集的边，而这条边是未用过的。设$u$是$C$上一个关联着未用过的边的顶点。在由未用过的边构成的多重图$H$中，每个顶点的度都是偶数，因为$C$在每个顶点处都用了偶数条边。由断言，$H$中存在一条从$u$出发的闭迹$C'$。在$C$经过$u$的某一处把$C'$插入$C$，就得到一条比$C$更长的闭迹，矛盾。所以$C$用到了每条边：它是一条欧拉回路。
:::

这个证明给出了一个高效的算法，即希尔霍尔策（Hierholzer）算法：一直走到走不下去为止，然后在仍有未用边的顶点处拼接进绕行的闭迹。它的运行时间为$O(m)$。

::: corollary 欧拉迹 {#cor-euler-trail}
连通多重图有一条不闭的欧拉迹，当且仅当恰有两个顶点的度为奇数；此时这条迹从其中一个顶点出发，到另一个顶点结束。
:::

::: proof
如果这样的一条迹从$u$走到$v \ne u$，那么每次经过内部顶点都用掉两条边，而$u$和$v$各多出一条边；所以恰好$u$和$v$的度为奇数。反过来，如果恰好$u$和$v$的度为奇数，就添加一条新边$uv$（必要时作为重边）。这时每个顶点的度都是偶数，由[[#thm-euler-circuit]]得到一条欧拉回路；从中删去这条新边，就得到一条从$u$到$v$的欧拉迹。
:::

::: example 柯尼斯堡与“尼古拉斯小屋” {#ex-euler}
(a) 是否存在一条恰好经过柯尼斯堡每座桥一次的散步路线？(b) “尼古拉斯小屋”——一个正方形$BL, BR, TR, TL$（左下、右下、右上、左上），画上两条对角线，再加上屋顶$TL, R, TR$——能否不提笔一笔画出？
::: solution
(a) 四块陆地的度为$5, 3, 3, 3$：有四个奇度顶点。由[[#thm-euler-circuit]]和[[#cor-euler-trail]]，既没有欧拉回路，也没有欧拉迹，所以这样的散步路线不存在。

(b) 各顶点的度为$\deg(BL) = \deg(BR) = 3$，$\deg(TL) = \deg(TR) = 4$，$\deg(R) = 2$。恰有两个奇度顶点，所以存在欧拉迹，并且它必须从底边的一个角出发，到另一个角结束。例如

$$
BL,\ BR,\ TL,\ TR,\ R,\ TL,\ BL,\ TR,\ BR
$$

恰好把八条边各用一次。
:::
:::

:::

::: application 走遍每一条街道
扫雪车必须清扫每一条街道；如果街道图有奇度顶点，某些街道就必须重复经过，而以最小代价选出重复哪些街道，就是**中国邮递员问题**。欧拉迹也出现在基因组组装中：在由相互重叠的片段构成的图中，DNA序列被重建为一条欧拉迹。

## 哈密顿圈

::: definition 哈密顿圈 {#def-hamilton}
图中经过每个顶点的圈称为**哈密顿圈**；经过每个顶点的路称为**哈密顿路**。有哈密顿圈的图称为**哈密顿图**。
:::

这个名称源于威廉·罗恩·哈密顿（William Rowan Hamilton）1857年提出的一个谜题：要求找出一条周游正十二面体二十个顶点的环路。$K_n$（$n \ge 3$）是哈密顿图，$Q_d$（$d \ge 2$）也是：像$000, 001, 011, 010, 110, 111, 101, 100$这样的**格雷码**把所有串排成一列，使得相继的两个串只有一位不同。与欧拉的问题不同，哈密顿圈没有简单的判别法，但有一个简单的障碍。

::: proposition 一个必要条件 {#prop-ham-necessary}
若$G$是哈密顿图，则对每个非空顶点集$S$，图$G - S$至多有$\abs{S}$个连通分支。
:::

::: proof
设$C$是一个哈密顿圈。从圈中删去一个顶点后剩下一条路，此后每再删去一个顶点，至多把一段分成两段，所以从$C$中删去$S$的顶点后，至多剩下$\abs{S}$条路。这些路包含$G - S$的每个顶点，并且每条路都位于$G - S$的某一个连通分支内，所以$G - S$至多有$\abs{S}$个连通分支。
:::

例如，$K_{2,3}$不是哈密顿图：删去较小一侧的两个顶点后，剩下三个孤立点。这个条件不是充分的：彼得森图对每个$S$都满足它，却没有哈密顿圈（这一事实可以通过分情形讨论或用计算机验证）。充分条件则要求每个顶点处都有很多条边。

::: theorem 狄拉克（Dirac）定理 {#thm-dirac}
若$G$有$n \ge 3$个顶点，且每个顶点的度都至少为$n/2$，则$G$有哈密顿圈。
:::

::: proof
**$G$是连通的**：两个不相邻的顶点$u, v$的邻点都在其余$n - 2$个顶点之中，而$\abs{N(u)} + \abs{N(v)} \ge n > n - 2$，所以它们有公共邻点。

设$P = v_1, v_2, \dots, v_k$是$G$中最长的一条路。$v_1$的每个邻点都在$P$上，否则$P$可以从这一端延长；$v_k$同理。由于$\deg(v_1) \ge 2$，有$k \ge 3$。

**存在一个经过$v_1, \dots, v_k$的圈。** 考虑下标集

$$
I = \set{i : v_1v_{i+1} \in E}, \qquad J = \set{i : v_iv_k \in E},
$$

它们都是$\{1, \dots, k-1\}$的子集，且$\abs{I} = \deg(v_1) \ge n/2$，$\abs{J} = \deg(v_k) \ge n/2$。由于$\abs{I} + \abs{J} \ge n > k - 1$，有某个下标$i$同时属于两者。于是

$$
v_1, v_2, \dots, v_i, v_k, v_{k-1}, \dots, v_{i+1}, v_1
$$

是一个经过$P$的全部$k$个顶点的圈：它沿$P$走到$v_i$，跳到$v_k$，再沿$P$往回走到$v_{i+1}$，最后回到$v_1$。

**这个圈是哈密顿圈。** 若$k < n$，则由连通性，有某个不在圈上的顶点$w$与圈上的某个顶点$v_j$相邻。从$w$出发，走到$v_j$，再沿圈走一周，就得到一条有$k + 1$个顶点的路，这与$P$的最大性矛盾。所以$k = n$。
:::

除了连通性和$k \ge 3$之外，这个证明只用到：当最长路的两个端点不相邻时，$\deg(v_1) + \deg(v_k) \ge n$（如果它们相邻，$P$立即闭合成圈）；而下面的条件也能保证连通性，因为位于不同连通分支中的两个不相邻顶点的度之和至多为$n - 2$。这就得到**奥尔（Ore）定理**（1960）：若对每一对不相邻的顶点$u, v$都有$\deg(u) + \deg(v) \ge n \ge 3$，则$G$是哈密顿图。狄拉克定理中的界$n/2$不能再降低（[[#exr-dirac-sharp]]）。

::: quiz
哪个图有欧拉回路但没有哈密顿圈？
- [x] 共用一个顶点的两个三角形
- [ ] $K_4$
- [ ] $C_5$
- [ ] $K_{2,3}$
::: solution
共用一个顶点的两个三角形的度为$4, 2, 2, 2, 2$，所以存在欧拉回路；但删去公共顶点后剩下两个连通分支，所以由[[#prop-ham-necessary]]，不存在哈密顿圈。$K_4$是哈密顿图，但它的顶点度都是奇数；$C_5$两者都有；$K_{2,3}$两者都没有（它有两个奇度顶点，并且不满足[[#prop-ham-necessary]]中的条件）。
:::

::: remark 容易的问题与困难的问题
本章的每个算法的运行时间都是$n$和$m$的多项式。对于判定一个图是否为哈密顿图，或者求权最小的哈密顿圈的**旅行商问题**，都还不知道这样的算法。前者是**NP完全**的，后者至少同样困难：其中任何一个问题若有多项式时间算法，就能给出其他数以千计的问题的多项式时间算法，并解决“P = NP？”这个问题——它是克雷数学研究所的千禧年大奖难题之一。在实践中，人们用巧妙的精确方法和启发式方法来处理这类问题，后者能找到很好的（即使不是最优的）环游路线。
:::

莱昂哈德·欧拉（Leonhard Euler）关于柯尼斯堡七桥的论文（1735年提交给圣彼得堡科学院，1741年发表）证明了：这样的散步路线要求至多有两块陆地连有奇数座桥。他叙述了逆命题，但没有给出证明；卡尔·希尔霍尔策（Carl Hierholzer）的证明于1873年发表，那时他已去世。最小生成树最早由奥塔卡尔·博鲁夫卡（Otakar Borůvka）于1926年为摩拉维亚的一个电力网络而研究。沃伊捷赫·亚尔尼克（Vojtěch Jarník）在1930年发现了“普里姆”算法；约瑟夫·克鲁斯卡尔（Joseph Kruskal）于1956年发表了他的算法，罗伯特·普里姆（Robert Prim）于1957年重新发现了亚尔尼克的算法，而艾兹赫尔·迪杰斯特拉（Edsger Dijkstra）1959年的论文又一次给出了这个算法，同时给出了他的最短路算法。加布里埃尔·狄拉克（Gabriel Dirac）于1952年证明了他的定理；1972年，理查德·卡普（Richard Karp）把哈密顿圈问题列入了他的二十一个NP完全问题的名单。
:::

## 后续内容

在[[discrete/colouring-planarity]]中我们将看到，匹配问题有基于增广路的快速算法，而用三种颜色着色的问题却是NP完全的。网络流问题——通过容量有限的边，从源点向汇点输送尽可能多的流量——引出最大流最小割定理；而图上的随机游走就是[[probability/markov-chains]]中的马尔可夫链。

::: summary
- 稀疏图用邻接表存储（规模为$O(n + m)$）；BFS和DFS在$O(n + m)$时间内探索一个连通分支。
- BFS用队列逐层处理顶点，并能求出无权图中的距离（[[#thm-bfs]]）；DFS优先向深处走，并且每条非树边都连接某个顶点与它的一个祖先（[[#lem-dfs]]）。
- 有向图有拓扑序当且仅当它没有有向圈；反复删去源点就能求出一个拓扑序（[[#thm-topo]]）。
- 迪杰斯特拉算法按距离的顺序确定顶点，对非负权是正确的（[[#thm-dijkstra]]）；负权会使它失效。
- 割性质——跨越一个割的权最小的边总可以加入——证明了普里姆和克鲁斯卡尔这两种最小生成树算法都是正确的（[[#thm-cut-property]]）。
- 连通多重图有欧拉回路当且仅当所有顶点的度都是偶数，有欧拉迹当且仅当至多有两个顶点的度为奇数（[[#thm-euler-circuit]]）。
- 哈密顿圈还没有已知的高效判别法；狄拉克定理（$\delta(G) \ge n/2$）是一个充分条件，而删去$k$个顶点后分裂成多于$k$块则是一个障碍。
:::

## 习题

::: exercise 彼得森图中的距离 {level=1 check="6"}
在彼得森图（顶点为$\{1, \dots, 5\}$的$2$元子集，不相交时相邻）中，从$\{1,2\}$出发执行BFS。有多少个顶点的距离为$2$？
::: solution
$\{1,2\}$的邻点是$\{3,4,5\}$内的三个二元子集。其余六个顶点是与$\{1,2\}$恰有一个公共元素的二元子集，例如$\{1,3\}$；它们的距离都是$2$，因为$\{3,4,5\} \setminus \{3\}$内的二元子集（这里是$\{4,5\}$）与两者都不相交。所以各层的大小依次为$1, 3, 6$：有$6$个顶点的距离为$2$，并且该图的直径为$2$。
:::
:::

::: exercise 一条最短路 {level=1 check="8"}
一个带权图的顶点为$S, A, B, C, D, T$，边为$SA\,(3)$、$SB\,(1)$、$AB\,(1)$、$AC\,(4)$、$BC\,(6)$、$BD\,(5)$、$CD\,(1)$、$CT\,(2)$、$DT\,(6)$。用迪杰斯特拉算法求$d(S, T)$。
::: solution
确定$S\,(0)$：$A = 3$，$B = 1$。确定$B\,(1)$：$A = \min(3, 2) = 2$，$C = 7$，$D = 6$。确定$A\,(2)$：$C = \min(7, 6) = 6$。确定$C\,(6)$（与$D$并列；先确定哪一个都可以）：$D$保持为$\min(6, 7) = 6$，$T = 8$。确定$D\,(6)$：$T$保持为$\min(8, 12) = 8$。确定$T\,(8)$。所以$d(S,T) = 8$，路线为$S, B, A, C, T$。
:::
:::

::: exercise 一棵最小生成树 {level=1 check="9"}
求上一题中的图的最小生成树的权。
::: solution
用克鲁斯卡尔算法：权为$1$的三条边（$SB$、$AB$、$CD$）不构成圈；加入$CT\,(2)$；舍弃$SA\,(3)$（会构成圈$S, A, B$）；加入$AC\,(4)$，它把$\{S, A, B\}$与$\{C, D, T\}$连接起来。这样共有$5 = n - 1$条边，总权为$1 + 1 + 1 + 2 + 4 = 9$。
:::
:::

::: exercise 完全图中的欧拉回路 {level=1}
对哪些$n \ge 2$，$K_n$有欧拉回路？对哪些$r, s \ge 1$，$K_{r,s}$有欧拉回路？
::: solution
这两种图都是连通的，所以由[[#thm-euler-circuit]]，只需所有顶点的度都是偶数。$K_n$是$(n-1)$-正则的，所以它有欧拉回路当且仅当$n$为奇数。在$K_{r,s}$中，一侧的顶点度为$s$，另一侧的顶点度为$r$，所以需要$r$和$s$都是偶数。
:::
:::

::: exercise 多米诺骨牌环 {level=2}
一副标准的多米诺骨牌有$28$张，对每一对满足$0 \le i \le j \le 6$的$\{i, j\}$各有一张（包括两端相同的“对子”$\{i, i\}$）。能否把它们全部排成一个闭合的环，使得相接的两端点数相同？
::: solution
构造一个多重图，以$0, 1, \dots, 6$为顶点，每张骨牌对应一条边$ij$（每个对子对应一个自环）。一个环恰好就是一条欧拉回路：相继的骨牌有一个共同的数，正如迹中相继的边有一个公共顶点。这个多重图是连通的，每个顶点$i$有六条边连向其他数，再加上一个计为$2$的自环，所以度为$8$。所有度都是偶数，所以欧拉回路存在——从而这样的环也存在。
:::
:::

::: exercise 完全二部图何时是哈密顿图 {level=2}
证明：$K_{r,s}$有哈密顿圈当且仅当$r = s \ge 2$。
::: solution
二部图中的圈在两侧之间交替，所以哈密顿圈中来自两侧的顶点一样多：$r = s$。另外，圈至少有$3$个顶点，这就排除了$r = s = 1$。反过来，若$r = s \ge 2$，两侧分别为$\{x_1, \dots, x_r\}$和$\{y_1, \dots, y_r\}$，则$x_1, y_1, x_2, y_2, \dots, x_r, y_r, x_1$是一个哈密顿圈，因为每个$x_i$都与每个$y_j$相邻。
:::
:::

::: exercise 狄拉克定理中的界是精确的 {#exr-dirac-sharp level=2}
对每个奇数$n = 2k + 1 \ge 3$，给出一个有$n$个顶点、最小度为$(n - 1)/2$、且没有哈密顿圈的图。
::: solution
取$K_{k,k+1}$。它有$2k + 1 = n$个顶点；较大一侧的顶点度为$k$，较小一侧的顶点度为$k + 1$，所以$\delta = k = (n-1)/2$。删去较小一侧的$k$个顶点后剩下$k + 1$个孤立点，所以由[[#prop-ham-necessary]]，不存在哈密顿圈（也可以利用上一题）。
:::
:::

::: exercise 权互不相同则最小生成树唯一 {#exr-unique-mst level=3}
证明：若连通图的各边权互不相同，则它恰有一棵最小生成树。
::: hint
设$T \ne T'$都是最小生成树。考虑恰好属于其中一棵的边中权最小的那一条。
:::
::: solution
设$T \ne T'$都是最小生成树。由于各边权互不相同，在恰好属于$T$、$T'$之一的那些边中，有唯一一条权最小的边$e$；不妨设$e \in T \setminus T'$。把$e$加入$T'$会产生一个圈$C$（由$T'$中连接$e$的两个端点的路加上$e$构成）。$C$的边不全在$T$中，因为$T$无圈；设$f \in C$是一条不在$T$中的边。于是$f \in T' \setminus T$且$f \ne e$，所以由$e$的选取，$w(f) > w(e)$。图$T' + e - f$是连通的（删去位于圈$C$上的$f$不会破坏$T' + e$的连通性），并且有$n - 1$条边，所以它是一棵生成树，其权为$w(T') + w(e) - w(f) < w(T')$。这与$T'$的最小性矛盾。
:::
:::

::: exercise 唯一的拓扑序 {level=3}
证明：有向无圈图恰有一个拓扑序，当且仅当它有一条有向哈密顿路。
::: hint
若$v_1, \dots, v_n$是唯一的拓扑序，交换$v_i$和$v_{i+1}$会怎样？
:::
::: solution
($\Leftarrow$) 设$v_1 \to v_2 \to \dots \to v_n$是一条有向哈密顿路。在任何拓扑序中，每个$v_i$都排在$v_{i+1}$之前，所以拓扑序只能是$v_1, \dots, v_n$；而DAG至少有一个拓扑序（[[#thm-topo]]），所以恰有一个。

($\Rightarrow$) 设$v_1, \dots, v_n$是唯一的拓扑序，并假设对某个$i$不存在弧$v_i \to v_{i+1}$。也不存在弧$v_{i+1} \to v_i$，因为它会从后指向前。交换$v_i$和$v_{i+1}$只改变这一对顶点的相对顺序，所以每条弧仍然从前指向后，我们得到了第二个拓扑序——矛盾。因此对每个$i$，$v_i \to v_{i+1}$都是弧，$v_1 \to \dots \to v_n$是一条有向哈密顿路。
:::
:::
