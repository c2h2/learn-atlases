十二位客人把帽子寄存在衣帽间，而服务员弄丢了存放牌，只好随机地把帽子还给客人。**没有一个人**拿回自己帽子的概率是多少？有两位客人时，这个概率是$\tfrac12$；有三位时是$\tfrac13$。随着客人数的增加，答案以惊人的速度稳定下来：十二位客人时，它与$1/e = 0.367879\ldots$在小数点后**九**位都相同，即使有一千位客人，结果也不会有什么不同。

这类问题涉及相互重叠的条件——客人$1$拿错了帽子，客人$2$拿错了帽子，等等——而[[discrete/counting]]中的加法原理要求各情形互不相交，因此不能直接应用。处理重叠条件的工具是**容斥原理**，它是本章的核心结果。我们还将介绍一个性质截然不同的原理——**鸽巢原理**，它能证明某个东西**存在**而无须把它找出来；以及用于分配相同对象的**隔板法**（又称“星与杠”方法）。

## 鸽巢原理

如果一个房间里有$13$个人，那么其中必有两人在同一个月出生。这里不需要任何计算：一年只有$12$个月，所以他们的出生月份不可能全都不同。这个简单的观察有着惊人的威力。

::: theorem 鸽巢原理 {#thm-pigeonhole}
设$A$和$B$是有限集，且$\abs{A} > \abs{B}$。则任何函数$f\colon A \to B$都不是单射：存在不同的$a, a' \in A$，使得$f(a) = f(a')$。

用文字来说：把多于$n$个对象放进$n$个盒子，则某个盒子中至少有两个对象。
:::

::: proof
对$b \in B$，令$A_b = \set{a \in A : f(a) = b}$，即盒子$b$中的对象。每个$a$恰好属于一个$A_b$，所以这些集合$A_b$两两不交，其并为$A$，于是由加法原理（[[discrete/counting#thm-sum-rule]]）

$$
\sum_{b \in B}\abs{A_b} = \abs{A} > \abs{B}.
$$

如果每个$A_b$至多有一个元素，左边至多为$\sum_{b\in B} 1 = \abs{B}$。所以某个$A_b$含有两个不同的元素$a, a'$，从而$f(a) = f(a') = b$。
:::

当对象比盒子多得多时，同样的计数能给出更多信息。回忆一下，$x$的**上取整**$\lceil x\rceil$是$\ge x$的最小整数。

::: theorem 推广的鸽巢原理 {#thm-gen-pigeonhole}
把$N$个对象放进$k$个盒子，则某个盒子中至少有$\lceil N/k\rceil$个对象。
:::

::: proof
假设每个盒子中至多有$\lceil N/k\rceil - 1$个对象。由于$\lceil N/k\rceil < N/k + 1$，每个盒子中的对象都少于$N/k$个，于是对象总数小于$k\cdot N/k = N$，矛盾。
:::

::: quiz
至少要有多少人，才能保证其中至少有三人在同一个月出生？
- [ ] $24$
- [x] $25$
- [ ] $36$
- [ ] $37$
::: solution
有$25$个人、$12$个月时，某个月中至少有$\lceil 25/12\rceil = 3$个人出生。有$24$个人时，结论可能不成立：每个月恰有两人出生。所以$25$是满足要求的最小人数。一般地，把$k(r-1) + 1$个对象放进$k$个盒子，必有一个盒子中有$r$个对象，而$k(r-1)$个对象则不能保证这一点。
:::
:::

运用这一原理的诀窍在于如何选取盒子。

::: example 一个数整除另一个数 {#ex-divides}
设$n \ge 1$。证明：从$\set{1, 2, \dots, 2n}$中任取$n+1$个数，其中必有一个数整除另一个数。
::: solution
每个正整数都可以唯一地写成$s = 2^a m$，其中$a \ge 0$，$m$为奇数：只要尽可能多次地除以$2$即可。称$m$为$s$的**奇部**。当$s \le 2n$时，奇部是$n$个数$1, 3, 5, \dots, 2n - 1$之一。这些就是我们的盒子：我们有$n + 1$个数，而可能的奇部只有$n$个，所以由鸽巢原理，所选的数中有两个不同的数具有相同的奇部，设为$s = 2^a m$和$s' = 2^b m$。由于$s \ne s'$，有$a \ne b$；若$a < b$，则$s' = 2^{b-a}s$，所以$s$整除$s'$。

这个结果是最优的：$n$个数$n+1, n+2, \dots, 2n$中就没有这样的一对，因为其中最小者的两倍已经大于$2n$。
:::
:::

::: example 相等的和 {#ex-equal-sums}
证明：从任意十个互不相同的两位数中，可以选出两个**不相交**的非空子集，使它们的元素之和相等。（这是1972年国际数学奥林匹克的第1题。）
::: solution
设$S$是这十个数构成的集合。它有$2^{10} = 1024$个子集。一个子集的元素和是介于$0$与最大可能总和$90 + 91 + \dots + 99 = 945$之间的整数，所以至多有$946$种可能的和。由于$1024 > 946$，由鸽巢原理，存在两个**不同的**子集$X \ne Y$，它们的和相等。

它们未必不相交，但从两者中都去掉公共元素$X\cap Y$，两个和减少的量相同，所以$X' = X\setminus Y$与$Y' = Y \setminus X$不相交，而且和相等。它们都不是空集：由于$X \neq Y$，它们不可能都是空集；而如果恰有一个是空集，它的和$0$就会等于另一个（由正数组成的非空集合）的和，这是不可能的。
:::
:::

注意，这个证明并没有告诉我们应选**哪**两个子集；要找到它们可能需要进行搜索。这是鸽巢原理的典型特点：它确立存在性，却不给出构造。

一个更精巧的应用与序列中的模式有关。$a_1, a_2, \dots, a_N$的一个**子列**是满足$i_1 < i_2 < \dots < i_r$的序列$a_{i_1}, a_{i_2}, \dots, a_{i_r}$；若$a_{i_1} < a_{i_2} < \dots < a_{i_r}$，则称它是**递增**的；若不等号反向，则称它是**递减**的。

::: theorem 埃尔德什-塞凯赖什定理 {#thm-erdos-szekeres}
由$n^2 + 1$个互不相同的实数组成的每个序列，都含有长为$n + 1$的递增子列或长为$n+1$的递减子列。
:::

::: proof
设序列为$a_1, \dots, a_{n^2+1}$，对每个下标$i$，令$L_i$为以$a_i$**开头**的最长递增子列的长度。若某个$L_i \ge n+1$，则结论已经成立，故设对每个$i$都有$1 \le L_i \le n$。于是按$L_i$的值把$n^2 + 1$个下标分放到$n$个盒子中，由[[#thm-gen-pigeonhole]]，某个值$\ell$至少被$\lceil (n^2+1)/n\rceil = n + 1$个下标$i_1 < i_2 < \dots < i_{n+1}$取到。

我们断言$a_{i_1} > a_{i_2} > \dots > a_{i_{n+1}}$，这就给出了一个长为$n+1$的递减子列。取$i < j$，使$L_i = L_j$。若$a_i < a_j$，则把$a_i$放在以$a_j$开头的一个最长递增子列之前，就得到一个以$a_i$开头、长为$L_j + 1$的递增子列，于是$L_i \ge L_j + 1$，矛盾。由于各项互不相同，所以$a_i > a_j$，断言得证。
:::

这个界是最好的：$9$个数$3, 2, 1, 6, 5, 4, 9, 8, 7$既没有长为$4$的递增子列，也没有长为$4$的递减子列；用$n$个各含$n$个数的块作同样的构造，对每个$n$都适用。

## 容斥原理

对于两个可能有重叠的有限集，把$\abs{A}$与$\abs{B}$相加时，$A\cap B$中的元素被数了两次，所以要把它们减去一次：

$$
\abs{A \cup B} = \abs{A} + \abs{B} - \abs{A \cap B}.
$$ {#eq-ie2}

（形式上：$A\cup B$是$A$与$B\setminus A$的不交并，而$B$是$B\setminus A$与$A\cap B$的不交并；对两者应用加法原理即可。）对三个集合，减去三个两两交集时，同时属于三个集合的元素被多减了一次，所以必须把它们加回来：

$$
\abs{A\cup B\cup C} = \abs A + \abs B + \abs C - \abs{A\cap B} - \abs{A\cap C} - \abs{B \cap C} + \abs{A\cap B\cap C}.
$$ {#eq-ie3}

::: widget venn
sets: 3
expr: A | B | C
caption: 图中阴影部分是并集$A\cup B\cup C$。依次输入`A & B`和`A & B & C`，可以看到[[#eq-ie3]]减去又加回的重叠部分。逐个区域检验：恰属于其中两个集合的点被计数$2 - 1 = 1$次，属于全部三个集合的点被计数$3 - 3 + 1 = 1$次——并集中的每个点都恰好被计数一次。
:::

::: example 能被2、3或5整除 {#ex-235}
从$1$到$1000$的整数中，有多少个能被$2$、$3$、$5$中的至少一个整除？
::: solution
设$A_2$，$A_3$，$A_5$分别是$[1000]$中$2$，$3$，$5$的倍数构成的集合。$[1000]$中$d$的倍数有$\lfloor 1000/d\rfloor$个。一个数同时被$2$和$3$整除，当且仅当它被$6$整除；由于这些素数互不相同，其他交集的情形也类似。所以

$$
\begin{aligned}
\abs{A_2\cup A_3\cup A_5} &= \lfloor\tfrac{1000}{2}\rfloor + \lfloor\tfrac{1000}{3}\rfloor + \lfloor\tfrac{1000}{5}\rfloor - \lfloor\tfrac{1000}{6}\rfloor - \lfloor\tfrac{1000}{10}\rfloor - \lfloor\tfrac{1000}{15}\rfloor + \lfloor\tfrac{1000}{30}\rfloor \\
&= 500 + 333 + 200 - 166 - 100 - 66 + 33 = 734.
\end{aligned}
$$

因此，有$1000 - 734 = 266$个数不能被$2, 3, 5$中的任何一个整除。
:::
:::

::: warning 交集并不总是对应于乘积
要数$[100]$中能被$4$或$6$整除的数，重叠部分由同时能被二者整除的数组成，即$\lcm(4, 6) = 12$的倍数，而不是$4\cdot 6 = 24$的倍数。正确的计数是$25 + 16 - 8 = 33$；用$24$会得到错误答案$25 + 16 - 4 = 37$。在[[#ex-235]]中用乘积是对的，只是因为那些数两两互素。
:::

为了叙述一般的原理，对非空下标集$I$，记$A_I = \bigcap_{i\in I}A_i$，并使用**示性**记号$[P]$：当命题$P$为真时它等于$1$，为假时等于$0$。

::: theorem 容斥原理 {#thm-inclusion-exclusion}
设$A_1, \dots, A_n$是有限集$U$的子集，并令$A_\varnothing = U$。$U$中**不**属于任何$A_i$的元素个数为

$$
\abs{U \setminus (A_1\cup\dots\cup A_n)} = \sum_{I\subseteq[n]}(-1)^{\abs{I}}\abs{A_I},
$$ {#eq-ie-none}

等价地，

$$
\abs{A_1\cup\dots\cup A_n} = \sum_{\varnothing\neq I\subseteq[n]}(-1)^{\abs I+1}\abs{A_I} = \sum_i\abs{A_i} - \sum_{i<j}\abs{A_i\cap A_j} + \sum_{i<j<k}\abs{A_i\cap A_j\cap A_k} - \dots
$$ {#eq-ie-union}
:::

::: proof
对$x \in U$，令$T(x) = \set{i : x\in A_i}$为含有$x$的那些集合的下标构成的集合。则$x \in A_I$当且仅当$I\subseteq T(x)$（当$I = \varnothing$时这总成立）。把每个$\abs{A_I}$写成示性记号之和，再交换这两个有限和的求和次序：

$$
\sum_{I\subseteq[n]}(-1)^{\abs I}\abs{A_I} = \sum_{I\subseteq [n]}(-1)^{\abs I}\sum_{x\in U}\bigl[I\subseteq T(x)\bigr] = \sum_{x\in U}\ \sum_{I\subseteq T(x)}(-1)^{\abs I}.
$$

若$T(x)$有$t$个元素，则它有$\binom tj$个大小为$j$的子集，所以内层和为$\sum_{j=0}^t(-1)^j\binom tj$。由[[discrete/counting#cor-row-sums]]，当$t \ge 1$时它为$0$，当$t = 0$时它为$1$。因此，若$x$不属于任何$A_i$，它贡献$1$，否则贡献$0$，这就证明了[[#eq-ie-none]]。用$\abs U = \abs{A_\varnothing}$减去[[#eq-ie-none]]，即得[[#eq-ie-union]]。
:::

这个证明揭示了“容斥”实际上在做什么：它给每个元素赋予权重$\sum_j (-1)^j\binom tj$，由二项式定理，这个权重等于$(1-1)^t$——对至少属于一个集合的每个元素，它都是零。在大多数应用中，$\abs{A_I}$的大小只依赖于相交的集合的个数，于是公式化简为一个单重和。

::: corollary 对称形式的容斥原理 {#cor-symmetric}
若在[[#thm-inclusion-exclusion]]中，只要$\abs{I} = k$就有$\abs{A_I} = N_k$，则不属于任何$A_i$的元素个数为

$$
\sum_{k=0}^n (-1)^k\binom nk N_k.
$$
:::

::: proof
把[[#eq-ie-none]]中的各项按$k = \abs I$分组：大小为$k$的集合$I$有$\binom nk$个，每个贡献$(-1)^kN_k$。
:::

### 两个应用

**欧拉函数。**对$n \ge 1$，令$\varphi(n)$为$[n]$中与$n$互素的整数的个数。若$n = p_1^{e_1}\cdots p_r^{e_r}$，其中$p_i$是互不相同的素数，则一个整数与$n$互素当且仅当没有一个$p_i$整除它。令$A_i$为$[n]$中$p_i$的倍数构成的集合。对$I \subseteq [r]$，一个数能被所有$p_i$（$i\in I$）整除，当且仅当它能被它们的乘积$d_I$整除（由分解的唯一性），而$d_I$整除$n$，所以$\abs{A_I} = n/d_I$。由[[#eq-ie-none]]，

$$
\varphi(n) = \sum_{I\subseteq[r]}(-1)^{\abs I}\frac{n}{d_I} = n\prod_{i=1}^r\Bigl(1 - \frac{1}{p_i}\Bigr),
$$ {#eq-phi}

这是因为把乘积展开（从每个因子中选取$1$或$-1/p_i$）恰好得到和式中的各项。例如$\varphi(360) = 360\cdot\frac12\cdot\frac23\cdot\frac45 = 96$。这个函数在[[number-theory/fermat-euler]]中处于核心地位。

**满射。**从$m$元集合到$n$元集合的满射有多少个？

::: proposition 满射的计数 {#prop-surjections}
对$m, n \ge 1$，满射$[m]\to[n]$的个数为

$$
\sum_{k=0}^{n}(-1)^k\binom nk (n-k)^m.
$$
:::

::: proof
令$U$为全部$n^m$个函数$[m] \to [n]$构成的集合，$A_i$为像中不含值$i$的函数构成的集合。一个函数属于$A_I$当且仅当它在$[n]\setminus I$中取值，所以$\abs{A_I} = (n - \abs I)^m$。满射就是不属于任何$A_i$的函数，对$N_k = (n-k)^m$应用[[#cor-symmetric]]即得该公式。
:::

例如，把六件不同的玩具分给三个孩子，使每个孩子至少得到一件，共有$3^6 - 3\cdot 2^6 + 3\cdot 1^6 - 0 = 540$种方式。取$m = n$，满射$[n]\to[n]$就是一个排列，所以该公式给出一个奇妙的恒等式$\sum_k(-1)^k\binom nk(n-k)^n = n!$；而当$m < n$时不存在满射，所以这个和为$0$。

## 错排

::: definition 错排 {#def-derangement}
$[n]$的一个**错排**是$[n]$的一个没有不动点的排列$\sigma$：对每个$i$都有$\sigma(i)\neq i$。我们用$D_n$表示$[n]$的错排的个数，并规定$D_0 = 1$（空排列没有不动点）。
:::

手算可得：$D_1 = 0$；$D_2 = 1$（交换两个元素）；$D_3 = 2$（两个“轮转”$1\to2\to3\to1$和$1\to3\to2\to1$）。存帽问题要求的是$D_n/n!$，即错排在全部排列中所占的比例。

::: theorem 错排的计数 {#thm-derangements}
对每个$n \ge 0$，

$$
D_n = n!\sum_{k=0}^n\frac{(-1)^k}{k!} = n!\Bigl(1 - \frac1{1!} + \frac{1}{2!} - \frac{1}{3!} + \dots + \frac{(-1)^n}{n!}\Bigr).
$$
:::

::: proof
令$U$为$[n]$的全部$n!$个排列构成的集合，$A_i = \set{\sigma : \sigma(i) = i}$。当$\abs I = k$时，固定$I$中每个元素的排列与其余$n - k$个元素的排列一一对应，所以$\abs{A_I} = (n-k)!$。错排就是不属于任何$A_i$的排列，所以由[[#cor-symmetric]]，

$$
D_n = \sum_{k=0}^n(-1)^k\binom nk(n-k)! = \sum_{k=0}^n(-1)^k\frac{n!}{k!\,(n-k)!}(n-k)! = n!\sum_{k=0}^n\frac{(-1)^k}{k!}. \qquad
$$
:::

由该公式得$D_4 = 24 - 24 + 12 - 4 + 1 = 9$，$D_5 = 44$，$D_6 = 265$。它还给出递推关系$D_n = nD_{n-1} + (-1)^n$（$n \ge 1$）：$D_n$的和式等于$D_{n-1}$的和式加上单独一项$(-1)^n/n!$，再乘以$n! = n\cdot(n-1)!$，就得到$D_n = nD_{n-1} + (-1)^n$。这个和式是指数级数$e^{-1} = \sum_{k=0}^\infty (-1)^k/k!$（见[[calculus-2/taylor-series]]）的开头部分，这就解开了存帽问题之谜。

::: corollary 错排与1/e {#cor-nearest-e}
对每个$n \ge 1$，$D_n$是最接近$n!/e$的整数。特别地，当$n\to\infty$时$D_n/n! \to 1/e$。
:::

::: proof
由该定理和指数级数，

$$
\frac{n!}{e} - D_n = n!\sum_{k=n+1}^{\infty}\frac{(-1)^k}{k!} = \pm\Bigl(\frac{1}{n+1} - \frac{1}{(n+1)(n+2)} + \frac{1}{(n+1)(n+2)(n+3)} - \dots\Bigr).
$$

括号中是一个交错级数$t_1 - t_2 + t_3 - \dots$，其各项为正、严格递减且趋于$0$；把它的项两两分组可知，它的值严格介于$0$和首项$t_1 = \frac{1}{n+1}$之间。所以$\bigl\lvert n!/e - D_n\bigr\rvert < \frac{1}{n+1} \le \frac12$，从而整数$D_n$就是最接近$n!/e$的整数。两边除以$n!$，得$\abs{1/e - D_n/n!} < \frac{1}{(n+1)!} \to 0$。
:::

::: example 信与信封 {#ex-envelopes}
把五封信随机地装入写好地址的五个信封。在$120$种装法中，有多少种装法使得没有一封信装对信封？有多少种装法恰好有两封信装对？
::: solution
没有一封信装对，意味着这个排列是错排，所以第一个答案是

$$
D_5 = 120\Bigl(1 - 1 + \frac12 - \frac16 + \frac1{24} - \frac1{120}\Bigr) = 60 - 20 + 5 - 1 = 44,
$$

对应的概率为$44/120 \approx 0.367$，已经很接近$1/e$。

对于恰好两封信装对的情形，先选出装对的是哪两封，有$\binom52 = 10$种方式；其余三封信必须全部装错，即这三封信的一个错排：$D_3 = 2$种方式。每个这样的排列恰好出现一次，所以答案是$10\cdot 2 = 20$。（穷举全部$120$个排列，证实了这两个计数。）
:::

caption: 排列$1\mapsto 2$，$2 \mapsto 3$，$3\mapsto 1$，$4 \mapsto 5$，$5\mapsto 4$没有不动点：没有一个箭头回到它的起点，它的轮换表示$(1\,2\,3)(4\,5)$中没有长为$1$的轮换。一个排列是错排，当且仅当它的所有轮换的长度都至少为$2$。当$n = 4$时，$D_4 = 9$个错排就是六个$4$-轮换，以及三个由两个不相交的对换构成的乘积。
:::

::: quiz
从$[4]$的排列中均匀随机地选取一个。它是错排的概率是多少？
- [x] $3/8$
- [ ] $1/e$
- [ ] $1/4$
- [ ] $(3/4)^4$
::: solution
在$4! = 24$个排列中有$D_4 = 9$个是错排，所以概率为$9/24 = 3/8 = 0.375$，接近但不等于$1/e \approx 0.368$。如果事件“$i$不是不动点”相互独立，答案$(3/4)^4$就是对的，但它们并不独立：若$1, 2, 3$都被移动了，这会影响$4$可以去的位置。
:::
:::

## 分配相同的对象：隔板法

把$6$颗相同的糖分给$4$个孩子，有多少种分法？等价地，$x_1 + x_2 + x_3 + x_4 = 6$有多少组非负整数解？这里$x_i$是孩子$i$得到的糖的颗数。把糖画成一排星号，并用$3$根竖杠（隔板）把各个孩子的份额隔开：

$$
\star\star\,\big|\,\big|\,\star\star\star\,\big|\,\star \qquad\longleftrightarrow\qquad (x_1, x_2, x_3, x_4) = (2, 0, 3, 1).
$$

每种分法都是$6$个星号和$3$根竖杠按某种顺序排成的一行，所以共有$\binom{9}{3} = 84$种分法。

::: theorem 隔板法 {#thm-stars-bars}
设$n \ge 0$和$k \ge 1$为整数。

1. $x_1 + x_2 + \dots + x_k = n$的非负整数解的个数为$\dbinom{n+k-1}{k-1}$。
2. 若$n \ge 1$，则正整数解的个数为$\dbinom{n-1}{k-1}$。
:::

::: proof
1. 把解$(x_1, \dots, x_k)$映为这样的单词：$x_1$个星号、一根竖杠、$x_2$个星号、一根竖杠、……、一根竖杠、$x_k$个星号。它含有$n$个星号和$k - 1$根竖杠，所以长为$n + k - 1$。反过来，由$n$个星号和$k - 1$根竖杠组成的任何单词都恰好来自一个解：$x_i$是第$(i-1)$根与第$i$根竖杠之间的星号个数（$i = 1$时是第一根竖杠之前的个数，$i = k$时是最后一根竖杠之后的个数）。这个双射表明，解的个数等于单词的个数，而单词由$k-1$根竖杠在$n+k-1$个位置中所占的位置决定：共$\binom{n+k-1}{k-1}$个。

2. 代换$y_i = x_i - 1$是从$\sum x_i = n$的正整数解到$\sum y_i = n - k$的非负整数解的双射。若$n \ge k$，由第1部分得$\binom{(n-k)+k-1}{k-1} = \binom{n-1}{k-1}$。若$1 \le n < k$，则不存在正整数解，而由于$n - 1 < k - 1$，确实有$\binom{n-1}{k-1} = 0$。
:::

$x_1 + \dots + x_k = n$的一个解，等同于从$k$种类型中取出的一个大小为$n$的**多重集**——即允许重复、不计顺序的选取，其中$x_i$是第$i$种类型的物品个数。所以一家有$4$种甜甜圈的面包店可以卖出$\binom{6+3}{3} = 84$种不同的六个装礼盒。继允许重复的序列、不允许重复的序列和子集之后，这是第四种基本计数。

::: quiz
把$8$枚相同的硬币分给$3$个孩子，使每个孩子至少得到一枚，有多少种分法？
- [x] $\binom72 = 21$
- [ ] $\binom{10}{2} = 45$
- [ ] $3^8 = 6561$
- [ ] $\binom83 = 56$
::: solution
我们需要$x_1 + x_2 + x_3 = 8$的正整数解，由[[#thm-stars-bars]]的第2部分得$\binom{8-1}{3-1} = \binom72 = 21$。答案$45$还允许孩子一枚也得不到，而$3^8$则把硬币当作可区分的（每枚硬币选择一个孩子）。
:::
:::

变量的上界用容斥原理来处理：令$A_i$为违反第$i$个上界的解构成的集合，再数出不属于任何$A_i$的解。

::: example 掷出总点数10 {#ex-dice}
三枚可区分的骰子掷出总点数$10$，有多少种方式？
::: solution
我们要求$x_1 + x_2 + x_3 = 10$满足$1 \le x_i \le 6$的解。令$y_i = x_i - 1$：需要求$y_1 + y_2 + y_3 = 7$满足$0 \le y_i\le 5$的解。

不考虑上界时有$\binom{7+2}{2} = 36$个解。令$A_i$为满足$y_i \ge 6$的解构成的集合。令$y_i = 6 + z_i$，就把这些解变成和为$1$的非负整数解，所以$\abs{A_i} = \binom{1+2}{2} = 3$。总和为$7$时，不可能有两个变量都$\ge 6$，所以所有交集都是空集。由容斥原理，解的个数为

$$
36 - 3\cdot 3 + 0 - 0 = 27.
$$

所以掷出总点数$10$的概率为$27/216 = 1/8$。（用计算机列出全部$216$种结果，证实了$27$这个数。）
:::
:::

::: warning 相同还是可区分？
隔板法数的是**相同**对象的分配方式。如果对象是可区分的——比如是六件不同的玩具而不是六颗糖——每个对象各自独立地选择一个接受者，得到$k^n$种分配方式（$4^6 = 4096$种，而不是$84$种）。计数之前，一定要先判定对象以及盒子是否可以区分。
:::

### 分配问题一览表

许多计数问题都归结为把$n$个球放进$k$个盒子。答案取决于球和盒子是否可区分，以及盒子是否可以空着或装多个球。记$S(n,k)$为**第二类斯特林数**，即把$n$元集合划分为$k$个非空块的方法数。一个满射$[n]\to[k]$就是把$[n]$划分为$k$个块（同在一个盒子中的球构成的集合），再把$k$个盒子标号分配给这些块，后者有$k!$种方式；所以由除法原理（[[discrete/counting#lem-division]]）和[[#prop-surjections]]，

$$
S(n,k) = \frac{1}{k!}\sum_{j=0}^{k}(-1)^j\binom kj(k-j)^n, \qquad\text{例如}\quad S(5,3) = \frac{150}{6} = 25.
$$

| $n$个球放进$k$个盒子 | 每盒球数任意 | 每盒至多一球 | 每盒至少一球 |
|---|---|---|---|
| 球可区分，盒子可区分 | $k^n$ | $P(k,n)$ | $k!\,S(n,k)$ |
| 球相同，盒子可区分 | $\binom{n+k-1}{k-1}$ | $\binom kn$ | $\binom{n-1}{k-1}$ |
| 球可区分，盒子相同 | $S(n,1) + \dots + S(n,k)$ | 若$n\le k$则为$1$，否则为$0$ | $S(n,k)$ |
| 球相同，盒子相同 | $n$分成至多$k$个部分的分拆数 | 若$n \le k$则为$1$，否则为$0$ | $n$分成恰好$k$个部分的分拆数 |

前两行已在本章和[[discrete/counting]]中证明。在第三行中，盒子不可区分，所以一种分配方式就是把球划分到各个非空盒子中的一个划分。最后一行引出整数分拆，它没有封闭形式的公式；我们将在[[discrete/generating-functions]]中用生成函数研究它。（这张含十二个条目的表称为“十二重计数法”（twelvefold way）。）

::: history
存帽问题可以追溯到皮埃尔·雷蒙·德蒙莫尔（Pierre Rémond de Montmort）：他在《机会博弈分析》（*Essay d'analyse sur les jeux de hazard*，1708年）中分析了纸牌游戏*treize*（法语意为“十三”），在这种游戏中，只要某张牌恰好出现在它自己的位置上，玩家就获胜。他在1713年的第二版中解决了这个问题，大约同一时期尼古拉·伯努利（Nicolaus Bernoulli）也解决了它，实际上都得到了$1/e$的级数。亚伯拉罕·棣莫弗（Abraham de Moivre）在《机会的学说》（*The Doctrine of Chances*，1718年）中使用了容斥的思想，而一般的原理由丹尼尔·达席尔瓦（Daniel da Silva，1854年）和詹姆斯·约瑟夫·西尔维斯特（James Joseph Sylvester，1883年）叙述。鸽巢原理常被称为“狄利克雷原理”（德语称为*Schubfachprinzip*，即“抽屉原理”），因为彼得·古斯塔夫·勒热纳·狄利克雷（Peter Gustav Lejeune Dirichlet）在他的数论工作中使用了它，见于他1842年起发表的著作；常被引用的1834年这一年份在他的著作中找不到依据。保罗·埃尔德什（Paul Erdős）和乔治·塞凯赖什（George Szekeres）于1935年证明了他们关于单调子列的定理，这篇论文推动了拉姆齐理论的兴起。
:::

## 后续内容

鸽巢原理是**拉姆齐理论**最简单的情形；拉姆齐理论的主题是：完全的无序是不可能的——每个足够大的结构都含有一个有规律的子结构。经典的入门例子是：任意六个人中，必有三人互相认识，或者有三人互不认识。（固定一个人$P$。由鸽巢原理，其余五人中至少有三人认识$P$，或者至少有三人不认识$P$；不妨设有三人认识$P$。如果这三人中有两人互相认识，他们就与$P$组成一个互相认识的三人组；否则这三人互不认识。相反的情形是对称的。）五个人是不够的：让他们围坐在一张桌旁，并让每个人只认识自己的两个邻座。容斥原理是概率论的基本工具，在概率论中，它由各交集的概率算出$\Prob(A_1 \cup\dots\cup A_n)$（[[probability/probability-spaces]]）；它也是数论的基本工具，$\varphi(n)$和筛法都依赖于它（[[number-theory/fermat-euler]]）。递推关系$D_n = nD_{n-1} + (-1)^n$和$D_n = (n-1)(D_{n-1}+D_{n-2})$是[[discrete/recurrences]]中递推关系的例子，而隔板法将在[[discrete/generating-functions]]中以$(1-x)^{-k}$的系数的形式再次出现。

::: summary
- **鸽巢原理**（[[#thm-pigeonhole]]）：把多于$n$个对象放进$n$个盒子，必有一个盒子中有两个对象；把$N$个对象放进$k$个盒子，必有一个盒子中有$\lceil N/k\rceil$个对象。技巧在于如何选取盒子。
- 鸽巢原理证明存在性而不给出构造，例如埃尔德什-塞凯赖什定理：$n^2 + 1$个互不相同的数中含有长为$n+1$的单调子列。
- **容斥原理**（[[#thm-inclusion-exclusion]]）：$\abs{\bigcup A_i} = \sum\abs{A_i} - \sum\abs{A_i\cap A_j} + \dots$；每个元素以权重$(1-1)^t$被计数。
- 当任意$k$个集合的交集大小都为$N_k$时，不属于任何一个集合的元素个数为$\sum_k(-1)^k\binom nkN_k$。由此得到$\varphi(n) = n\prod_{p\mid n}(1 - 1/p)$以及满射的个数$\sum_k(-1)^k\binom nk(n-k)^m$。
- **错排**：$D_n = n!\sum_{k=0}^n (-1)^k/k!$是最接近$n!/e$的整数，所以随机排列没有不动点的概率接近$1/e$。
- **隔板法**（[[#thm-stars-bars]]）：$x_1 + \dots + x_k = n$有$\binom{n+k-1}{k-1}$组非负整数解和$\binom{n-1}{k-1}$组正整数解；上界用容斥原理处理。
- 一定要先判定对象和盒子是否可区分；分配问题一览表汇总了各种情形的答案。
:::

## 习题

::: exercise 蓝袜子 {level=1 check="14"}
一个抽屉里有$12$只红袜子和$12$只蓝袜子。在黑暗中取袜子，至少要取多少只，才能确保至少取到两只蓝袜子？
::: solution
在最坏的情况下，前$12$只袜子都是红的，接下来的两只是蓝的，所以取$14$只就足够了。取十三只则不够：可能是$12$只红的和$1$只蓝的。因此答案是$14$。（如果只要确保取到同色的一双，不论哪种颜色，那么由两个盒子的鸽巢原理，只需取$3$只。）
:::
:::

::: exercise 语言 {level=1 check="45"}
在一群学生中，有$25$人学法语，$18$人学德语，$20$人学西班牙语；$8$人学法语和德语，$7$人学法语和西班牙语，$6$人学德语和西班牙语，$3$人三种语言都学。有多少人至少学这三种语言中的一种？
::: solution
由[[#eq-ie3]]，$25 + 18 + 20 - 8 - 7 - 6 + 3 = 45$。
:::

::: exercise 非负整数解 {level=1 check="455"}
$x_1 + x_2 + x_3 + x_4 = 12$有多少组非负整数解？
::: solution
由隔板法，取$n = 12$，$k = 4$：$\binom{12+3}{3} = \binom{15}{3} = 455$。
:::

::: exercise 避开7、11和13 {level=2 check="720"}
从$1$到$1000$的整数中，有多少个不能被$7$、$11$、$13$中的任何一个整除？
::: solution
这三个素数互不相同，所以交集对应于乘积。$[1000]$中各倍数的个数为$\lfloor 1000/7\rfloor = 142$，$\lfloor 1000/11\rfloor = 90$，$\lfloor 1000/13\rfloor = 76$，$\lfloor 1000/77\rfloor = 12$，$\lfloor 1000/91\rfloor = 10$，$\lfloor 1000/143\rfloor = 6$和$\lfloor 1000/1001\rfloor = 0$。由[[#eq-ie-none]]，答案为

$$
1000 - 142 - 90 - 76 + 12 + 10 + 6 - 0 = 720.
$$
:::

::: exercise 恰好两封装对 {level=2 check="135"}
把六封信随机地装入写好地址的六个信封。在$720$种装法中，有多少种装法恰好有两封信装对？
::: solution
选出装对的两封信，有$\binom62 = 15$种方式；其余四封必须构成一个错排，有$D_4 = 9$种方式。答案是$15\cdot 9 = 135$。
:::

::: exercise 给三个孩子分玩具 {level=2 check="540"}
把$6$件不同的玩具分给$3$个孩子，使每个孩子至少得到一件玩具，有多少种分法？
::: solution
这就是从$6$件玩具构成的集合到$3$个孩子构成的集合的满射的个数。由[[#prop-surjections]]，它等于$3^6 - \binom31 2^6 + \binom32 1^6 - \binom33 0^6 = 729 - 192 + 3 - 0 = 540$。
:::

::: exercise 有界的解 {level=2 check="10"}
$x_1 + x_2 + x_3 = 15$有多少组满足$0 \le x_i \le 6$的整数解？
::: solution
不考虑上界时有$\binom{17}{2} = 136$个解。令$A_i$为满足$x_i \ge 7$的解构成的集合；代入$x_i = 7 + z_i$后和变为$8$，所以$\abs{A_i} = \binom{10}{2} = 45$。若有两个变量违反上界，由$x_i, x_j \ge 7$，剩下的和为$1$：$\abs{A_i\cap A_j} = \binom32 = 3$。三个变量都违反上界需要总和至少为$21$，所以$A_1 \cap A_2\cap A_3 = \varnothing$。因此解的个数为$136 - 3\cdot 45 + 3\cdot 3 - 0 = 10$。列举验证：$(6,6,3)$，$(6,5,4)$和$(5,5,5)$的排列共有$3 + 6 + 1 = 10$个。
:::
:::

::: exercise 相同的朋友数 {level=2}
证明：在任意一群$n \ge 2$个人中，必有两人在这群人中的朋友数相同。（朋友关系是相互的，并且没有人是自己的朋友。）
::: hint
可能的朋友数是$0, 1, \dots, n-1$。$0$和$n - 1$能同时出现吗？
:::
::: solution
每个人在这群人中的朋友数介于$0$与$n-1$之间，于是$n$个人有$n$个可能的值——仅凭这一点还不足以应用鸽巢原理。但$0$和$n-1$这两个值不可能同时出现：有$n - 1$个朋友的人与所有人都是朋友，所以没有人的朋友数为$0$。因此这$n$个人至多取$n - 1$个不同的值，由鸽巢原理，其中必有两人的朋友数相同。（用[[discrete/graphs]]的语言来说：至少有两个顶点的每个简单图都有两个度数相等的顶点。）
:::
:::

::: exercise 能被n整除的和 {level=3}
证明：对任意整数$a_1, a_2, \dots, a_n$（$n \ge 1$），存在下标$1 \le i \le j \le n$，使得$a_i + a_{i+1} + \dots + a_j$能被$n$整除。
::: hint
考察$n + 1$个部分和$s_0 = 0, s_1 = a_1, s_2 = a_1 + a_2, \dots, s_n$以及它们除以$n$的余数。
:::
::: solution
令$s_0 = 0$，并对$1 \le k \le n$令$s_k = a_1 + \dots + a_k$。这是$n+1$个整数，每个除以$n$的余数都是$n$个余数$0, 1, \dots, n-1$之一。由鸽巢原理，其中有两个余数相同，设为$s_{i-1}$和$s_j$，$i - 1 < j$。则$n$整除$s_j - s_{i-1} = a_i + a_{i+1} + \dots + a_j$，并且$1 \le i \le j \le n$。
:::
:::

::: exercise 错排的一个递推关系 {level=3}
给出$D_n = (n-1)\bigl(D_{n-1} + D_{n-2}\bigr)$（$n \ge 2$）的组合证明。
::: hint
设$\sigma$是满足$\sigma(n) = i$的错排。区分$\sigma(i) = n$和$\sigma(i) \neq n$两种情形。
:::
::: solution
对$[n]$的错排$\sigma$，值$i = \sigma(n)$是$1, \dots, n-1$之一。我们证明：对每个固定的$i$，满足$\sigma(n) = i$的错排恰有$D_{n-1} + D_{n-2}$个；再对$i$的$n-1$个值应用加法原理，即得该公式。

*情形1：$\sigma(i) = n$。*此时$\sigma$交换$i$和$n$，而在其余$n-2$个元素上，它是这些元素的一个错排。反过来，$[n]\setminus\set{i,n}$的任何错排，补充上$i$与$n$的交换之后，都是$[n]$的一个属于这种情形的错排。所以这样的$\sigma$有$D_{n-2}$个。

*情形2：$\sigma(i)\neq n$。*令$j = \sigma^{-1}(n)$，则$j \ne i$且$j \ne n$。在$[n-1]$上定义$\tau$：$\tau(j) = i$，当$x \neq j$时$\tau(x) = \sigma(x)$；也就是把$j \to n \to i$“短路”为$j\to i$。则$\tau$是$[n-1]$的一个排列，并且没有不动点，因为$\tau(j) = i \ne j$，而其他的值都是$\sigma$的值。反过来，由$[n-1]$的错排$\tau$可以恢复$\sigma$：令$j = \tau^{-1}(i)$（于是$j \neq i$），并令$\sigma(j) = n$，$\sigma(n) = i$，在其他点上$\sigma(x) = \tau(x)$；这个$\sigma$是满足$\sigma(n) = i$且$\sigma(i)\neq n$的错排。这两个构造互逆，所以情形2包含$D_{n-1}$个错排。

因此$D_n = (n-1)(D_{n-1} + D_{n-2})$。验算：$D_4 = 3(2 + 1) = 9$，$D_5 = 4(9 + 2) = 44$。
:::
:::
