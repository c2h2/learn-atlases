有界闭区间$[a, b]$上的连续函数能取到最大值和最小值。在开区间$(0, 1)$上，函数$f(x) = x$没有最大值（它的值逐渐逼近$1$，却达不到$1$），而$1/x$甚至是无界的；在$\R$上，函数$x$无界。$[a, b]$有什么特别之处？在实分析中，答案是波尔查诺-魏尔斯特拉斯定理：$[a, b]$中的每个数列都有一个收敛子列，**并且极限属于$[a, b]$**。拓扑学给出了另一个不借助序列表述的答案，而事实表明它更为有力：用开集对$[a, b]$所作的每个覆盖，都可以约简为一个有限覆盖。

这一性质——**紧性**——是有限性在拓扑学中的替代物。有限集显然是紧的，而许多对有限集适用的论证——取最大值、从有限多个半径中选出最小的一个——对紧空间也适用。本章定义紧性；证明**海涅-博雷尔定理**，它把$\R^n$的紧子集刻画为有界闭集；证明紧空间的连续像是紧的（由此得到最一般形式的最值定理）；证明从紧空间到豪斯多夫空间的连续双射自动是同胚；并在度量空间中建立紧性与序列的联系。

## 开覆盖与紧性

::: definition 紧性 {#def-compact}
拓扑空间$X$的一个**开覆盖**是指一族并集为$X$的开集$\mathcal U$。**子覆盖**是指仍然覆盖$X$的子族。若$X$的每个开覆盖都有有限子覆盖，则称空间$X$是**紧的**（也称紧致的）。若空间的一个子集在子空间拓扑下是紧的，就称这个子集是紧的。
:::

由于子空间$A$的开集形如$U\cap A$，子集$A\subseteq X$是紧的，当且仅当每一族并集包含$A$的**$X$中的**开集都有一个并集仍包含$A$的有限子族。我们将不加说明地使用这种形式。

::: example 紧空间与非紧空间 {#ex-compact-examples}
(a) 证明每个有限空间和每个平凡拓扑空间都是紧的，而无限离散空间不是紧的。(b) 证明$\R$和$(0, 1)$不是紧的。(c) 证明$K = \set0\cup\set{1/n : n\ge1}\subseteq\R$是紧的。
::: solution
(a) 有限空间只有有限多个开集，所以每个开覆盖本身就是有限的。在平凡拓扑空间中，开覆盖必定含有$X$本身，而它就是只含一个集合的子覆盖。在无限离散空间中，由单点集构成的覆盖$\set{\set x}$没有真子覆盖，更不用说有限子覆盖了。

(b) 区间$(-n, n)$（$n\ge1$）覆盖$\R$，但其中有限多个的并是$(-N, N)$（$N$为所用的最大的$n$），它不是$\R$。类似地，$(\frac1n, 1)$（$n\ge2$）覆盖$(0, 1)$，但任何有限子族的并都是$(\frac1N, 1)\neq(0,1)$。

(c) 设$\mathcal U$是由$\R$中的开集构成的$K$的覆盖。某个$U_0\in\mathcal U$含有$0$，由于$U_0$是开集，它包含一个区间$(-\eps, \eps)$，从而包含所有满足$n > 1/\eps$的$1/n$。剩下的有限多个点$1, \frac12,\dots,\frac1N$（$N\le1/\eps$）分别属于$\mathcal U$的某个成员$U_1,\dots,U_N$。所以$U_0, U_1,\dots,U_N$是一个有限子覆盖。点$0$是必不可少的：$K\setminus\set0$不是紧的（用开区间$(\frac{1}{n} - \frac{1}{n^2+n}, \frac1n + \frac{1}{n^2+n})$覆盖它，这些区间把各点彼此隔开）。
:::
:::

紧性是拓扑性质，而且不止于此：它在连续映射下保持。

::: theorem 紧空间的连续像 {#thm-image}
若$X$是紧的，$f\colon X\to Y$连续，则$f(X)$是紧的。
:::

::: proof
设$\mathcal V$是由$Y$中的开集构成的$f(X)$的覆盖。原像$f^{-1}(V)$（$V\in\mathcal V$）都是开集并且覆盖$X$，所以其中有限多个$f^{-1}(V_1),\dots,f^{-1}(V_n)$覆盖$X$。于是$V_1,\dots,V_n$覆盖$f(X)$：若$y = f(x)$，则对某个$k$有$x\in f^{-1}(V_k)$，所以$y\in V_k$。
:::

## 紧集、闭集与豪斯多夫性质

紧性与闭性密切相关，但这种关系还需要空间具有另一个性质，我们将在[[topology/quotient-spaces]]一章中正式讨论它：若空间$X$中任意两个不同的点都有不相交的开邻域，则称$X$是**豪斯多夫空间**。度量空间都是豪斯多夫空间（取半径为两点间距离一半的球即可）。

::: theorem 闭子集与紧子集 {#thm-closed-compact}
1. 紧空间的闭子集是紧的。
2. 豪斯多夫空间的紧子集是闭的。
:::

::: proof
(1) 设$C$是紧空间$X$中的闭集，$\mathcal U$是覆盖$C$的一族$X$中的开集。加上开集$X\setminus C$，就得到$X$的一个开覆盖，它有有限子覆盖。从这个子覆盖中去掉$X\setminus C$（如果它在其中），剩下的就是覆盖$C$的有限多个$\mathcal U$的成员。

(2) 设$K$是豪斯多夫空间$X$中的紧集，$x\notin K$。对每个$y\in K$，取不相交的开集$U_y\ni x$和$V_y\ni y$。这些$V_y$覆盖$K$，所以其中有限多个$V_{y_1},\dots,V_{y_n}$覆盖$K$。于是$U = U_{y_1}\cap\dots\cap U_{y_n}$是含有$x$的开集，并且与$V_{y_1}\cup\dots\cup V_{y_n}\supseteq K$不相交。所以$K$外的每一点都有一个位于$K$外的邻域：$K$的补集是开集。
:::

(2)的证明展示了紧性的一种典型用法：无穷多个邻域$U_y$不能取交，但有限多个可以。

::: warning 紧集未必是闭集
(2)需要豪斯多夫假设。在无限集上的余有限拓扑中，**每个**子集都是紧的（$A$的覆盖中含有一个与$A$相交的集合$U_0$；它只漏掉空间中的有限多个点，而每个这样的点都属于覆盖中的另外某个成员），然而只有有限子集和整个空间才是闭集。同样，在平凡拓扑空间中，每个子集都是紧的。在非豪斯多夫空间中，紧性与闭性就分道扬镳了。
:::

## 海涅-博雷尔定理

最基本的紧空间是闭区间。

::: theorem 闭区间是紧的 {#thm-interval}
每个有界闭区间$[a, b]\subseteq\R$都是紧的。
:::

::: proof
设$\mathcal U$是由$\R$的开子集构成的$[a, b]$的覆盖，令

$$
S = \set{x\in[a, b] : [a, x]\text{ 能被 }\mathcal U\text{ 中有限多个成员覆盖}}.
$$

则$a\in S$（一个含有$a$的成员就够了），并且$S$以$b$为上界；令$s = \sup S\in[a,b]$。取$U\in\mathcal U$使$s\in U$，再取$\eps > 0$使$(s - \eps, s + \eps)\subseteq U$。由上确界的定义，存在$x\in S$使得$s - \eps < x\le s$。$\mathcal U$中有限多个成员覆盖$[a, x]$；再加上$U$，对每个满足$y < s + \eps$的$y\in[a, b]$，有限多个成员就覆盖了$[a, y]$。取$y = s$，可知$s\in S$。若$s < b$，取$y = \min(s + \eps/2, b) > s$，可知$y\in S$，与$s = \sup S$矛盾。因此$s = b$，$[a, b]$被$\mathcal U$中有限多个成员覆盖。
:::

与[[topology/connectedness#thm-intervals]]中的连通性一样，起作用的是$\R$的确界原理；在$\Q$中，“闭区间”$[0, 2]\cap\Q$不是紧的（用集合$\set{q : \abs{q^2 - 2} > 1/n}$覆盖它）。

为了推广到更高维，我们需要积空间，而关键的引理与“管子”有关。

::: lemma 管状引理 {#lem-tube}
设$Y$是紧的，$x\in X$，$W$是$X\times Y$中包含切片$\set x\times Y$的开子集。则存在开集$U\ni x$，使得$U\times Y\subseteq W$。
:::

::: proof
对每个$y\in Y$，点$(x, y)\in W$属于某个基元素$U_y\times V_y\subseteq W$。这些$V_y$覆盖紧空间$Y$，所以其中有限多个$V_{y_1},\dots,V_{y_n}$覆盖$Y$。令$U = U_{y_1}\cap\dots\cap U_{y_n}$，它是含有$x$的开集。若$(x', y')\in U\times Y$，则对某个$k$有$y'\in V_{y_k}$，且$x'\in U\subseteq U_{y_k}$，所以$(x', y')\in U_{y_k}\times V_{y_k}\subseteq W$。
:::

::: theorem 紧空间的乘积 {#thm-product}
若$X$和$Y$都是紧的，则$X\times Y$是紧的。
:::

::: proof
设$\mathcal W$是$X\times Y$的开覆盖。对每个$x\in X$，切片$\set x\times Y$同胚于$Y$，因而是紧的，所以$\mathcal W$中有限多个成员覆盖它；设$W_x$是这些成员的并（它是开集）。由管状引理，存在开集$U_x\ni x$，使得$U_x\times Y\subseteq W_x$。这些$U_x$覆盖$X$，所以其中有限多个$U_{x_1},\dots,U_{x_m}$覆盖$X$。于是管子$U_{x_k}\times Y$覆盖$X\times Y$，而每个管子都被$\mathcal W$中有限多个成员覆盖；总起来，$\mathcal W$中有限多个成员覆盖了$X\times Y$。
:::

::: theorem 海涅-博雷尔定理 {#thm-heine-borel}
$\R^n$的子集是紧的，当且仅当它是有界闭集。
:::

::: proof
设$K\subseteq\R^n$是紧的。由于$\R^n$是度量空间，因而是豪斯多夫空间，由[[#thm-closed-compact]](2)，$K$是闭集。$K$是有界的，因为开球$B(0, m)$（$m\ge1$）覆盖$K$，从而其中有限多个——因而其中最大的那一个——必定覆盖$K$。

反之，设$K$是有界闭集，比如$K\subseteq[-M, M]^n$。由[[#thm-interval]]和[[#thm-product]]（对$n$归纳；由[[topology/continuous-maps]]，$\R^n$上的积拓扑就是标准拓扑），立方体$[-M, M]^n$是紧的。所以$K$作为紧空间的闭子集，由[[#thm-closed-compact]](1)是紧的。
:::

所以闭圆盘、球面$S^n$、闭立方体以及$\R^3$中的环面都是紧的，而开圆盘、$\R^n$以及去掉一点的闭圆盘都不是紧的。

::: example 正交群是紧的 {#ex-orthogonal}
把$n\times n$实矩阵看作$\R^{n^2}$中的点。证明正交矩阵构成的群$O(n) = \set{A : A\T A = I}$是紧的，而可逆矩阵构成的群$GL_n(\R)$不是紧的。
::: solution
从$\R^{n^2}$到$\R^{n^2}$的映射$A\mapsto A\T A$是连续的，因为$A\T A$的每个元素都是$A$的元素的多项式。所以$O(n)$作为闭集$\set I$的原像，是闭集。它是有界的：$A\T A = I$说明$A$的各列都是单位向量，所以每个元素的绝对值都不超过$1$，并且在$\R^{n^2}$中$\norm A_2\le\sqrt n$。由海涅-博雷尔定理，$O(n)$是紧的。$GL_n(\R)$不是紧的：它是无界的（对所有$t\neq0$，它含有$tI$），也不是闭集，因为$\frac1kI\to0\notin GL_n(\R)$。这类紧性论证在线性代数中很常见：对于对称矩阵$A$，连续函数$x\mapsto x\T Ax$在紧的单位球面上取到最大值，而最大值在一个特征向量处取到——这是谱定理的一种证明的第一步（[[linear-algebra/spectral-theorem]]）。
:::
:::

::: quiz
下列$\R^2$的子集中哪些是紧的？（可能有多个正确选项。）
- [x] 单位圆周$S^1$
- [ ] 开单位圆盘
- [x] $\set{(x, y) : x^4 + y^4\le1}$
- [ ] 双曲线$\set{(x, y) : xy = 1}$
- [x] 有限集$\set{(0,0), (1, 2)}$
::: solution
由海涅-博雷尔定理，要找的是有界闭集。圆周、区域$x^4 + y^4\le1$（它作为$(-\infty, 1]$在一个连续函数下的原像是闭集，又由于$\abs x, \abs y\le1$而有界）以及有限集都符合条件。开圆盘有界但不是闭集；双曲线是闭集但无界。
:::
:::

::: warning 一般而言，有界闭集未必是紧的
海涅-博雷尔定理是关于$\R^n$的定理，而不是关于一般度量空间的定理。在带有有界度量$d(x, y) = \min(\abs{x - y}, 1)$的$\R$中，整个空间是闭的，并且（以$1$为界）是有界的，但它不是紧的，因为其拓扑就是通常的拓扑。在平方可和序列构成的空间$\ell^2$中，闭单位球是有界闭集，但不是紧的（[[#exr-ell2]]）。正确的一般性结论是：度量空间是紧的，当且仅当它**完备且完全有界**。
:::

## 紧性与连续映射

::: corollary 最值定理 {#cor-evt}
若$X$是非空紧空间，$f\colon X\to\R$连续，则$f$有界，并且取到最大值和最小值：存在$p, q\in X$，使得对所有$x\in X$有$f(p)\le f(x)\le f(q)$。
:::

::: proof
由[[#thm-image]]，$f(X)$是$\R$的紧子集，所以由海涅-博雷尔定理，它是有界闭集。非空有界实数集有上确界$s$，而$s$属于该集合的闭包；由于$f(X)$是闭集，$s\in f(X)$，即对某个$q$有$s = f(q)$。最小值可以同样处理。
:::

这就是[[calculus-1/continuity]]一章中的最值定理，而现在它对球面、环面、闭球、闭区间的乘积以及任何其他紧空间上的连续函数都成立。

::: widget plot
f: atan(x); 1/x
x: -6, 6
y: -3, 3
labels: \arctan x; 1/x
hlines: pi/2; -pi/2
caption: 非紧定义域上的两个连续函数。在$\R$上，$\arctan x$有界，但它的上确界$\pi/2$（虚线）只能被逼近，永远取不到。在$(0, 1]$上，$1/x$甚至无界。把任一函数限制到一个有界闭区间上，最值定理就保证它有最大值和最小值。
:::

::: example 距离与范数 {#ex-distance}
(a) 设$K\subseteq\R^n$是非空紧集，$p\in\R^n$。证明$K$中存在离$p$最近的点。(b) 证明$\R^n$上的任意两个范数都等价：若$\norm{\cdot}$是一个范数，则存在$c, C > 0$，使得$c\norm x_2\le\norm x\le C\norm x_2$。
::: solution
(a) 函数$f(x) = \norm{x - p}$在$K$上连续，所以由[[#cor-evt]]，它在某个$q\in K$处取到最小值；$q$就是一个最近点。（对于闭但无界的集合，先把它与一个大的闭球取交。）

(b) 记$x = \sum x_ie_i$。由三角不等式和柯西-施瓦茨（Cauchy–Schwarz）不等式，$\norm x\le\sum\abs{x_i}\norm{e_i}\le C\norm x_2$，其中$C = \big(\sum\norm{e_i}^2\big)^{1/2}$。这也说明$\abs{\norm x - \norm y}\le\norm{x - y}\le C\norm{x - y}_2$，所以$\norm\cdot$关于欧几里得度量是连续的。在单位球面$S^{n-1} = \set{\norm x_2 = 1}$上（由海涅-博雷尔定理，它是紧的），它取到最小值$c$，并且$c > 0$，因为范数只在$0$处为零。对$x\neq0$，$\norm x = \norm x_2\,\big\lVert x/\norm x_2\big\rVert\ge c\norm x_2$。因此$\R^n$上的所有范数都定义同一个拓扑——这一结论对无穷维空间不成立。
:::
:::

下一个定理是拓扑学中最常用的定理之一：有了它，就不必再检验逆映射的连续性。

::: theorem 从紧空间到豪斯多夫空间 {#thm-compact-hausdorff}
设$f\colon X\to Y$是从紧空间$X$到豪斯多夫空间$Y$的连续双射。则$f$是同胚。
:::

::: proof
我们证明$f$把闭集映成闭集；这样，对$g = f^{-1}$和$X$中的闭集$C$，$g^{-1}(C) = f(C)$是闭集，所以$g$连续。设$C\subseteq X$是闭集。由[[#thm-closed-compact]](1)，$C$是紧的，所以由[[#thm-image]]，$f(C)$是紧的，从而由[[#thm-closed-compact]](2)，它是豪斯多夫空间$Y$中的闭集。
:::

例如，映射$[0, 2\pi]\to S^1$，$t\mapsto(\cos t, \sin t)$是连续的满射，但不是单射；它在$[0, 2\pi)$上的限制是双射，却不是同胚（[[topology/continuous-maps#ex-not-homeo]]）——定义域$[0, 2\pi)$不是紧的。在[[topology/quotient-spaces]]一章中，这个定理将说明把$[0, 2\pi]$的两端粘合起来恰好得到圆周。它还立即说明，[[topology/continuous-maps#ex-product]]中从$S^1\times S^1$到甜甜圈形曲面的映射是同胚：它是从紧空间到$\R^3$的子空间的连续双射，而$\R^3$的子空间是豪斯多夫空间。

::: quiz
设$f\colon X\to Y$是连续双射。在下列哪种情形下可以断定$f$是同胚？
- [x] $X$是紧的，$Y$是豪斯多夫空间
- [ ] $X$是豪斯多夫空间，$Y$是紧的
- [ ] $X$和$Y$都是度量空间
- [ ] $X = [0, 2\pi)$，$Y = S^1$
::: solution
[[#thm-compact-hausdorff]]要求**定义域**是紧的、**目标空间**是豪斯多夫空间。其他选项都不成立：从带离散拓扑的$[0,1]$（豪斯多夫空间）到带通常拓扑的$[0,1]$（紧空间）的恒等映射是连续双射，但不是同胚；[[topology/continuous-maps#ex-not-homeo]]中的映射$[0,2\pi)\to S^1$是度量空间之间的连续双射，但不是同胚。
:::
:::

## 度量空间中的序列紧性

对于度量空间，紧性可以用序列来表述，在分析学中人们通常最先接触的就是这种形式。

::: definition 序列紧性 {#def-seq-compact}
若空间$X$中的每个序列都有一个收敛于$X$中某点的子列，则称$X$是**序列紧的**。
:::

::: lemma 勒贝格数引理 {#lem-lebesgue}
设$\mathcal U$是序列紧度量空间$X$的开覆盖。则存在$\delta > 0$（称为该覆盖的一个**勒贝格数**），使得$X$中每个直径小于$\delta$的子集都含于$\mathcal U$的某个成员中。
:::

::: proof
若不然，则对每个$n$，存在一个直径小于$1/n$的集合$A_n$，它不含于$\mathcal U$的任何成员。取$x_n\in A_n$。由序列紧性，某个子列$x_{n_k}$收敛于某个$x\in X$。取含有$x$的$U\in\mathcal U$，以及$\eps > 0$使$B(x, \eps)\subseteq U$。当$k$充分大时，$d(x_{n_k}, x) < \eps/2$且$1/n_k < \eps/2$；于是每一点$y\in A_{n_k}$都满足$d(y, x)\le d(y, x_{n_k}) + d(x_{n_k}, x) < \eps$，所以$A_{n_k}\subseteq B(x,\eps)\subseteq U$，矛盾。
:::

::: theorem 对度量空间，紧等价于序列紧 {#thm-sequential}
度量空间是紧的，当且仅当它是序列紧的。
:::

::: proof
**紧 ⇒ 序列紧。**设$(x_n)$是紧度量空间$X$中的序列，并假设它没有收敛的子列。那么没有一点$x$是某个子列的极限，所以每个$x$都有一个球$B(x, r_x)$，它只对有限多个$n$含有$x_n$（否则可以选取$n_1 < n_2 < \dots$使$x_{n_k}\in B(x, 1/k)$，得到一个收敛于$x$的子列）。这些球覆盖$X$，其中有限多个就覆盖$X$，于是总共只出现有限多个下标$n$——这对无穷序列是不可能的。

**序列紧 ⇒ 紧。**设$\mathcal U$是一个开覆盖，$\delta$是它的一个勒贝格数。我们断言$X$可以被有限多个半径为$\delta/3$的球覆盖。若不然，任取$y_1$，并归纳地选取$y_{k+1}\notin B(y_1,\delta/3)\cup\dots\cup B(y_k, \delta/3)$；则对所有$j\neq k$有$d(y_j, y_k)\ge\delta/3$，所以$(y_k)$没有一个子列是柯西列，更不用说收敛了——矛盾。所以$X = B(y_1,\delta/3)\cup\dots\cup B(y_m, \delta/3)$。每个球的直径至多为$2\delta/3 < \delta$，所以它含于某个$U_k\in\mathcal U$，从而$U_1,\dots,U_m$是一个有限子覆盖。
:::

与海涅-博雷尔定理结合，就得到**波尔查诺-魏尔斯特拉斯定理**（致密性定理）：$\R^n$中的每个有界序列都有收敛子列（因为它位于一个紧的立方体中）。下面这个数列可以很好地检验直觉。

::: widget sequence
a: sin(n)
N: 200
mode: terms
y: -1.2, 1.2
caption: $a_n = \sin n$的各项在$[-1, 1]$中游荡，始终不会稳定下来——事实上，由于$\pi$是无理数，它们可以任意接近$[-1,1]$中的每一点。这个数列发散，但由于$[-1,1]$是紧的，由波尔查诺-魏尔斯特拉斯定理，它有收敛子列；实际上，对每个$c\in[-1,1]$，都有某个子列收敛于$c$。
:::

紧性的第二个经典推论是一致连续性。

::: theorem 紧空间上的一致连续性 {#thm-uniform}
设$f\colon X\to Y$是度量空间之间的连续映射，且$X$是紧的。则$f$一致连续：对每个$\eps > 0$，存在$\delta > 0$，使得由$d(x, x') < \delta$可推出$d(f(x), f(x')) < \eps$。
:::

::: proof
给定$\eps > 0$，集合$U_y = f^{-1}\big(B(y, \eps/2)\big)$（$y\in Y$）构成$X$的一个开覆盖。设$\delta$是它的一个勒贝格数（由[[#thm-sequential]]，[[#lem-lebesgue]]在此适用）。若$d(x, x') < \delta$，则集合$\set{x, x'}$的直径小于$\delta$，所以它含于某个$U_y$：$f(x)$和$f(x')$到$y$的距离都小于$\eps/2$，从而$d(f(x), f(x')) < \eps$。
:::

::: example 一个勒贝格数 {#ex-lebesgue}
求$[0, 1]$的覆盖$\set{[0, 0.6),\ (0.5, 1]}$的最大勒贝格数。
::: solution
设$A\subseteq[0,1]$的直径小于$0.1$。若$A$含有某点$a\le0.5$，则$A$的每一点都小于$a + 0.1\le0.6$，所以$A\subseteq[0, 0.6)$；否则$A\subseteq(0.5, 1]$。所以$\delta = 0.1$是一个勒贝格数。任何$\delta > 0.1$都不行：集合$[0.5, 0.6]$的直径为$0.1 < \delta$，却不含于任何一个成员中，因为$0.5\notin(0.5, 1]$，$0.6\notin[0, 0.6)$。最大勒贝格数是$0.1$——正如两个相互重叠的区间的图形所提示的，它就是重叠部分的长度。
:::
:::

::: remark 吉洪诺夫定理与紧化
[[#thm-product]]可以推广到任意乘积：**吉洪诺夫定理**断言，任意多个紧空间的乘积在积拓扑下是紧的。对于无穷乘积，它的证明很微妙（它与选择公理等价），但它的推论深入到分析学的许多领域，例如泛函分析中的巴拿赫-阿劳格鲁（Banach–Alaoglu）定理。反过来，一个非紧空间常常可以通过添加点而变成紧的。$\R^n$的**单点紧化**添加一个点$\infty$，以紧集的补集作为它的邻域，所得的空间通过球极投影同胚于球面$S^n$——当$n = 2$时，这就是[[complex-analysis/complex-numbers]]一章中的黎曼球面。
:::

::: application 最优解的存在性
经济学、工程学和统计学中的许多问题，都要求在无穷多个选择中找出最好的一个：最便宜的设计、可能性最大的参数、最短的路线。最值定理保证了：在运行任何算法之前，紧的选择集合上的连续代价函数就已经有最小值点；当选择集合不是紧集时（价格可以任意大，参数可以漂向无穷），最小值点可能不存在，而证明一个极小化序列始终位于某个紧集中，就是标准的第一步。在无穷维问题中——寻找一条曲线或一个函数——阿尔泽拉-阿斯科利（Arzelà–Ascoli）定理之类的紧性定理起着同样的作用，例如在微分方程的皮亚诺（Peano）存在定理中（[[ode/existence-uniqueness]]）。
:::

::: history
紧性产生于19世纪的分析学。爱德华·海涅（Eduard Heine）在1872年用一个涉及覆盖的论证证明了有界闭区间上的连续函数是一致连续的。埃米尔·博雷尔（Émile Borel）在1895年的博士论文中证明了：用开区间对有界闭区间所作的每个可数覆盖都有有限子覆盖；不久之后，经由皮埃尔·库赞（Pierre Cousin）、亨利·勒贝格（Henri Lebesgue）等人的工作，这一结论被推广到任意覆盖。莫里斯·弗雷歇（Maurice Fréchet）在1906年引入了“紧”（compact）这个词，用来指我们现在所说的序列紧性。帕维尔·亚历山德罗夫（Pavel Alexandrov）和帕维尔·乌雷松（Pavel Urysohn）在他们关于紧空间的长篇论文中，把开覆盖定义确立为核心定义，这篇论文写于20世纪20年代初，发表于1929年；安德烈·吉洪诺夫（Andrey Tychonoff）在1930—1935年间证明了乘积的紧性。
:::

## 后续内容

紧性是点集拓扑的两大支柱之一，在本课程余下的部分中将被反复使用。在[[topology/quotient-spaces]]一章中，[[#thm-compact-hausdorff]]把圆周、环面和射影平面等商空间与具体的模型等同起来。在[[topology/fundamental-group]]一章中，勒贝格数引理是道路提升论证的引擎，而这一论证计算出了圆周的基本群。在分析学中，紧性带来了一致连续性、最大值和最小值的存在性以及子列的收敛性——而在[[real-analysis/metric-spaces]]和[[measure-theory/lp-spaces]]中，紧性在无穷维情形下的失效是许多微妙之处的根源。

::: summary
- 若每个开覆盖都有有限子覆盖，则空间是紧的；有限集、闭区间和$\set0\cup\set{1/n}$是紧的，而$\R$、$(0,1)$和无限离散空间不是紧的。
- 紧空间的连续像是紧的；紧空间的闭子集是紧的；豪斯多夫空间的紧子集是闭的。
- $[a, b]$是紧的，紧空间的乘积是紧的（管状引理），因此$\R^n$的子集是紧的当且仅当它是有界闭集（海涅-博雷尔定理）。在一般的度量空间中，有界闭还不够。
- 最值定理：非空紧空间上的连续实函数取到最大值和最小值。
- 从紧空间到豪斯多夫空间的连续双射是同胚。
- 在度量空间中，紧性等价于序列紧性；每个开覆盖都有勒贝格数，并且紧空间上的连续映射是一致连续的。
:::

## 习题

::: exercise 一个非紧的区间 {level=1}
直接由定义证明$(0, 1]$不是紧的，并证明空间中有限多个紧子集的并是紧的。
::: solution
开集$(\frac1n, 2)$（$n\ge1$）覆盖$(0, 1]$，但其中有限多个的并是$(\frac1N, 2)$，它漏掉了$(0, \frac1N]$。对于紧集的并$K_1\cup\dots\cup K_m$：给定一个由开集构成的覆盖，其中有限多个成员覆盖每个$K_i$，而这有限多个有限族的并就是一个有限子覆盖。
:::
:::

::: exercise 识别紧集 {level=1}
下列集合中哪些是紧的：$[0,1]\cap\Q$；$\Z$；$\R^2$中的闭单位圆盘；$\set{(x, \sin x) : 0\le x\le\pi}$；$\set{(x,y) : x^2 - y^2 = 1}$？
::: solution
$[0,1]\cap\Q$有界，但在$\R$中不是闭集（它的闭包是$[0,1]$），所以不是紧的。$\Z$是闭集但无界，不是紧的。闭圆盘是有界闭集，所以是紧的。$\sin$在$[0,\pi]$上的图像是$[0,\pi]$在$x\mapsto(x,\sin x)$下的连续像，所以是紧的。双曲线$x^2 - y^2 = 1$是闭集但无界，不是紧的。
:::
:::

::: exercise 有保证的最大值 {level=1 check="sqrt(2)"}
解释为什么$f(x, y) = x + y$在单位圆周$S^1$上取到最大值，并求出这个最大值。
::: solution
$S^1$是紧的（有界闭集），$f$连续，所以由[[#cor-evt]]，最大值存在。令$(x, y) = (\cos t, \sin t)$，则$f = \cos t + \sin t = \sqrt2\sin(t + \frac\pi4)$，其最大值为$\sqrt2$，在$t = \frac\pi4$处取到，即在点$(\frac{1}{\sqrt2},\frac1{\sqrt2})$处。
:::
:::

::: exercise 一个勒贝格数 {level=2 check="1/10"}
区间$[0, 0.4)$、$(0.3, 0.8)$和$(0.7, 1]$覆盖$[0, 1]$。求这个覆盖的最大勒贝格数。
::: solution
仿照[[#ex-lebesgue]]的论证，障碍来自重叠部分：直径小于$\delta$的集合必须能放进某一个成员之中。重叠部分$(0.3, 0.4)$的长度为$0.1$，$(0.7, 0.8)$的长度也是$0.1$。取$\delta = 0.1$，设$A$的直径小于$0.1$，$a = \inf A$。若$a\le0.3$，则$A\subseteq[a, a + 0.1)\subseteq[0, 0.4)$。若$0.3 < a\le0.7$，则$A\subseteq[a, a + 0.1)\subseteq(0.3, 0.8)$。若$a > 0.7$，则$A\subseteq(0.7, 1]$。所以$0.1$是一个勒贝格数。当$\delta > 0.1$时，集合$[0.3, 0.4]$的直径为$0.1 < \delta$，却不含于任何成员中。最大勒贝格数是$0.1$。
:::
:::

::: exercise 不存在连续满射 {level=2}
证明不存在从$[0, 1]$到$(0, 1)$上的连续满射，但存在从$(0, 1)$到$[0, 1]$上的连续满射。
::: solution
紧空间$[0,1]$的连续像是紧的，但$(0,1)$不是紧的，所以不存在连续满射$[0,1]\to(0,1)$。另一方面，$f(x) = \frac12\big(1 + \sin(4\pi x)\big)$把$(0, 1)$连续地映满$[0, 1]$：它在$x = \frac18$处取值$1$，在$x = \frac38$处取值$0$，并由介值定理取到两者之间的一切值。
:::
:::

::: exercise 分离紧集 {level=2}
设$K$和$L$是豪斯多夫空间$X$的两个不相交的紧子集。证明存在不相交的开集$U\supseteq K$和$V\supseteq L$。
::: solution
对每个$x\in K$，把[[#thm-closed-compact]](2)的证明应用于紧集$L$和点$x\notin L$，就得到不相交的开集$U_x\ni x$和$V_x\supseteq L$。这些$U_x$覆盖$K$，所以其中有限多个$U_{x_1},\dots,U_{x_n}$覆盖$K$。令$U = U_{x_1}\cup\dots\cup U_{x_n}$，$V = V_{x_1}\cap\dots\cap V_{x_n}$。则$U\supseteq K$；$V\supseteq L$是开集（有限多个开集的交）；并且$U\cap V = \emptyset$，因为每个$U_{x_k}$都与$V_{x_k}\supseteq V$不相交。
:::
:::

::: exercise 余有限拓扑是紧的 {level=2}
证明带余有限拓扑的空间的每个子集都是紧的。由此推出：非豪斯多夫空间的紧子集未必是闭集。
::: solution
设$A\subseteq X$，$\mathcal U$是覆盖$A$的一族开集。若$A = \emptyset$，则无需证明。否则取$U_0\in\mathcal U$使$U_0\cap A\neq\emptyset$；则$U_0$非空，所以$X\setminus U_0$是有限集，从而$A\setminus U_0 = \set{a_1,\dots,a_k}$也是有限集。取含有$a_i$的$U_i\in\mathcal U$；则$U_0,\dots,U_k$覆盖$A$。当$X$是无限集时，任何无限真子集（例如$X$去掉一个点）都是紧的但不是闭集，因为闭集只有有限集和$X$。
:::
:::

::: exercise 紧度量空间是完备且完全有界的 {level=3}
若对每个$\eps > 0$，度量空间都能被有限多个半径为$\eps$的球覆盖，则称它是**完全有界的**。证明紧度量空间是完备且完全有界的。
::: solution
**完全有界：**球$B(x, \eps)$（$x\in X$）覆盖$X$，所以其中有限多个就覆盖$X$。**完备：**设$(x_n)$是柯西列。由[[#thm-sequential]]，它有子列$x_{n_k}\to x$。给定$\eps > 0$，取$N$使得当$m, n\ge N$时$d(x_n, x_m) < \eps/2$，再取$k$使得$n_k\ge N$且$d(x_{n_k}, x) < \eps/2$。则当$n\ge N$时，$d(x_n, x)\le d(x_n, x_{n_k}) + d(x_{n_k}, x) < \eps$。所以$x_n\to x$。（逆命题也成立：完备且完全有界的度量空间是紧的——在每个尺度上利用有限多个球作对角线论证，可知每个序列都有柯西子列。）
:::
:::

::: exercise 有界闭但不紧 {#exr-ell2 level=3}
设$\ell^2$是满足$\sum x_i^2 < \infty$的实数列$x = (x_1, x_2,\dots)$构成的空间，带有度量$d(x, y) = \big(\sum(x_i - y_i)^2\big)^{1/2}$。证明闭单位球$\set{x : d(x, 0)\le1}$是有界闭集，但不是紧的。
::: solution
按定义它是有界的；它是闭集，因为$x\mapsto d(x, 0)$连续，而这个球是$[0, 1]$的原像。设$e_n$是第$n$个位置为$1$、其余位置为$0$的数列；所有$e_n$都在这个球中，并且当$m\neq n$时$d(e_m, e_n) = \sqrt2$。所以$(e_n)$没有一个子列是柯西列，因而没有一个子列收敛，这个球不是序列紧的；由[[#thm-sequential]]，它不是紧的。（它不是完全有界的：每个半径为$\frac12$的球至多含有一个$e_n$。）
:::
:::

::: exercise 从紧空间出发的连续映射是闭映射 {level=3}
设$X$是紧的，$Y$是豪斯多夫空间，$f\colon X\to Y$连续。证明$f$是闭映射（它把闭集映成闭集），并由此推出连续单射$S^1\to\R^2$是嵌入。举例说明$X$是紧的这一假设不能去掉。
::: solution
若$C\subseteq X$是闭集，则它是紧的（[[#thm-closed-compact]](1)），所以$f(C)$是紧的（[[#thm-image]]），从而在$Y$中是闭集（[[#thm-closed-compact]](2)）。连续单射$f\colon S^1\to\R^2$是从紧空间$S^1$到豪斯多夫子空间$f(S^1)$上的连续双射，所以由[[#thm-compact-hausdorff]]，它是到其像上的同胚：即嵌入。没有紧性时：投影$\R^2\to\R$，$(x,y)\mapsto x$把闭的双曲线$xy = 1$映成$\R\setminus\set0$，而后者不是闭集。
:::
