数一数立方体的顶点、棱和面：$8 - 12 + 6 = 2$。对于四面体，$4 - 6 + 4 = 2$；对于八面体，$6 - 12 + 8 = 2$；对于足球，$60 - 90 + 32 = 2$。莱昂哈德·欧拉（Leonhard Euler）在1750年注意到，每个凸多面体都满足$V - E + F = 2$。但对于一个中间穿有方形隧道的“画框”多面体，同样的计数给出$0$。数$V - E + F$与形状和面数都无关；它探测的是曲面有多少个洞。这是我们遇到的第一个**通过计数算出的拓扑不变量**——**欧拉示性数**。

本章汇集了本课程的全部内容。我们定义曲面，利用三角剖分和[[topology/quotient-spaces]]一章中的多边形表示计算它们的欧拉示性数，引入**可定向性**（默比乌斯带所缺乏的性质），并通过**连通和**构造新的曲面。高潮是**闭曲面的分类**：每个紧连通曲面都是球面、若干环面的连通和或者若干射影平面的连通和，并且它仅由两项数据决定——它的可定向性和它的欧拉示性数。最后我们讨论可平面图的欧拉公式及其经典推论：恰有五种柏拉图立体。

## 曲面

::: definition 曲面 {#def-surface}
**曲面**是一个第二可数的豪斯多夫拓扑空间，其中每一点都有一个同胚于$\R^2$中开圆盘的开邻域。**闭曲面**是紧的连通曲面。
:::

这个局部条件是说：生活在曲面上的小生物在每一点周围看到的都是一小片平面。豪斯多夫条件排除了像有两个原点的直线（[[topology/quotient-spaces#ex-two-origins]]）这样的例子，第二可数性则排除了一些奇特的、“太大”的空间。闭曲面的例子有[[topology/quotient-spaces]]一章中的球面$S^2$、环面$T = S^1\times S^1$、克莱因瓶$K$和射影平面$\R P^2$。平面、开圆盘和开默比乌斯带都是曲面，但不是闭曲面（它们不是紧的）。闭圆盘和闭默比乌斯带是**带边曲面**：边界圆周上的点所具有的邻域则形如半圆盘。

::: example 不是曲面的例子 {#ex-double-cone}
证明双锥面$C = \set{(x, y, z)\in\R^3 : x^2 + y^2 = z^2}$不是曲面。
::: solution
在原点之外，$C$局部上是光滑曲面。假设锥顶$0$有一个同胚于开圆盘$D$的开邻域$W\subseteq C$，设同胚为$h\colon W\to D$。取以$0$为中心的小球$B$，使$B\cap C\subseteq W$；则$h(B\cap C)$是包含$h(0)$的开集，所以它包含一个以$h(0)$为中心的小开圆盘$D'$，而$V = h^{-1}(D')$是$0$的一个同胚于圆盘的开邻域。$D'\setminus\set{h(0)}$是连通的（去心圆盘是道路连通的），但$V\setminus\set0$不连通：它位于$C\setminus\set0$中，而后者是两个不相交的开的部分$z > 0$与$z < 0$的并，并且$V$与这两部分都相交（它在两侧都含有$C$中任意接近$0$的点）。这与$V\setminus\set0$和$D'\setminus\set{h(0)}$之间的同胚矛盾。所以锥顶没有圆盘状的邻域，$C$不是曲面。（与此相反，单锥面$z = \sqrt{x^2 + y^2}$**是**曲面：向$xy$平面的投影就是一个同胚。）
:::
:::

## 三角剖分与欧拉示性数

为了在曲面上计数顶点、边和面，我们把曲面切成三角形。

::: definition 三角剖分与欧拉示性数 {#def-euler}
紧曲面$S$的一个**三角剖分**是$S$的有限个闭子集（称为**三角形**）构成的族，其中每个三角形都配有一个从平面上的三角形到它的同胚（由此确定它的三个**顶点**和三条**边**），使得这些三角形覆盖$S$，并且任意两个不同的三角形或者不相交，或者恰交于一个公共顶点，或者恰交于一条公共边。若该三角剖分有$V$个顶点、$E$条边和$F$个三角形，则$S$的**欧拉示性数**为

$$
\chi(S) = V - E + F .
$$ {#eq-euler}
:::

两条基本定理保证了这是一个好的定义。我们不加证明地叙述它们；它们的证明确实很难，可以在阿姆斯特朗（Armstrong）的《基础拓扑学》（*Basic Topology*）第8章或莫伊斯（Moise）的《二维与三维几何拓扑》（*Geometric Topology in Dimensions 2 and 3*）中找到。

::: theorem 存在性与不变性 {#thm-invariance}
1. （拉多（Radó），1925年）每个紧曲面都有三角剖分。
2. 对给定紧曲面的所有三角剖分，数$V - E + F$都相同；并且同胚的紧曲面有相同的欧拉示性数。
:::

第(2)部分通常是这样证明的：证明$V - E + F$等于各同调群的秩的交错和，而同调群是拓扑不变量。第(1)部分出人意料地微妙（对某些四维流形，相应的命题不成立）。

实际上我们并不需要**三角形**。设一个紧曲面被切成有限个沿边粘合的多边形，每个多边形都是一个闭圆盘，其边界是由边构成的一个圈。那么$V - E + F$（其中$F$是多边形的个数）仍然等于$\chi$。理由是：把这样的分解变成三角剖分的细分操作永远不会改变$V - E + F$：

- 在一条边的中间添加一个新顶点：$V$和$E$都增加$1$；
- 在一个多边形面上添加一条对角线：$E$和$F$都增加$1$；
- 在一个面的内部添加一个顶点，并把它与该面的$k$个顶点相连：$V$增加$1$，$E$增加$k$，$F$增加$k - 1$（一个面被换成$k$个三角形），净变化为$1 - k + (k - 1) = 0$。

::: example 通过计数求欧拉示性数 {#ex-chi}
计算下列曲面的欧拉示性数：(a) 球面；(b) 环面；(c) 克莱因瓶；(d) 射影平面。
::: solution
(a) 立方体的表面同胚于球面（通过从中心出发的径向投影），并且$V - E + F = 8 - 12 + 6 = 2$。所以$\chi(S^2) = 2$。正如不变性定理所预言的，四面体、八面体、二十面体（$12 - 30 + 20$）和十二面体（$20 - 30 + 12$）也都给出$2$。

(b) 把边界词为$aba^{-1}b^{-1}$的正方形用作只有一个面的分解。它的两条边是$a$和$b$，而正方形的四个顶点全都等同为一个顶点（[[topology/quotient-spaces]]）：$V = 1$，$E = 2$，$F = 1$，所以$\chi(T) = 0$。（单个各边被等同的正方形并不是合格的三角剖分，但把它细分成$3\times3$的正方形网格，再分成三角形，由上述操作就得到一个值同为$0$的三角剖分。）

(c) 克莱因瓶$aba^{-1}b$：沿边界依次把正方形的顶点记为$v_0, v_1, v_2, v_3$。标记为$a$的两条边分别是$v_0\to v_1$和（由于是逆向经过的）$v_3\to v_2$，所以$v_0\sim v_3$，$v_1\sim v_2$；标记为$b$的两条边分别是$v_1\to v_2$和$v_3\to v_0$，所以$v_1\sim v_3$，$v_2\sim v_0$。四个顶点是同一个顶点，$\chi(K) = 1 - 2 + 1 = 0$。

(d) $\R P^2$是$abab$：两条$a$边是$v_0\to v_1$和$v_2\to v_3$，两条$b$边是$v_1\to v_2$和$v_3\to v_0$，由此得$v_0\sim v_2$和$v_1\sim v_3$——两个顶点。所以$\chi(\R P^2) = 2 - 2 + 1 = 1$。
:::
:::

::: example 环面的一个真正的三角剖分 {#ex-torus-triangulation}
把正方形分成$3\times3$的小正方形网格，并用从左下角到右上角的对角线把每个小正方形切成两个三角形。在环面的等同关系下，证明这是一个三角剖分，并计算$V - E + F$。
::: solution
网格有$4\times4$个格点，但等同关系$(0, y)\sim(1, y)$和$(x, 0)\sim(x, 1)$把最后一列格点粘到第一列上，把最上一行粘到最下一行上，剩下$3\times3 = 9$个顶点。边：$3$行顶点中每一行有$3$条水平边，共$9$条水平边；同样有$9$条竖直边；还有$9$条对角线，每个小正方形一条。所以$E = 27$，并且共有$F = 2\cdot9 = 18$个三角形。每个三角形有三个不同的顶点，每对顶点至多由一条边相连，并且有两个公共顶点的两个三角形必有连接这两点的公共边（这就是需要$3\times3$网格的原因：在$2\times2$网格上，不同的边会连接同一对顶点，有些不同的三角形甚至会有相同的三个顶点）。所以这是一个三角剖分，并且

$$
V - E + F = 9 - 27 + 18 = 0,
$$

与[[#ex-chi]](b)中用一个正方形计数得到的$1 - 2 + 1 = 0$一致。
:::
:::

## 可定向性

环面和克莱因瓶有相同的欧拉示性数$0$，但它们并不同胚（环面在$\R^3$中有两侧；克莱因瓶只有一侧）。我们需要第二个不变量。

::: definition 可定向性 {#def-orientable}
如果曲面包含一个同胚于默比乌斯带的子空间，就称它是**不可定向的**；否则称它是**可定向的**。
:::

直观地说，可定向曲面允许在每一点处一致地选定“顺时针”方向。在默比乌斯带上，把一个顺时针的小圆圈沿中心闭路移动一圈，它回来时就变成了逆时针的。对于三角剖分的曲面，可定向性等价于：可以给所有三角形定向，使得每条边被包含它的两个三角形沿相反的方向经过。

对于由多边形词给出的曲面，有一个简单的判别法：**曲面不可定向，当且仅当某个字母以相同的指数出现两次**（两次都是$x$，或两次都是$x^{-1}$）。事实上，如果标记为$x$的两条边以“同样的走向”粘合，那么横跨多边形、连接这两条边的一条细带就被粘成一条默比乌斯带，这与把默比乌斯带定义为满足$(0, y)\sim(1, 1 - y)$的正方形完全一样。反过来，如果每个字母都以$x$出现一次、以$x^{-1}$出现一次，那么所有的边都以相反的定向粘合，多边形的定向可以一致地越过每一条边。所以球面$aa^{-1}$和环面$aba^{-1}b^{-1}$是可定向的，而射影平面$abab$和克莱因瓶$aba^{-1}b$（它的两条$b$边有相同的指数）是不可定向的。

::: quiz
具有下列多边形词的曲面中，哪些是可定向的？（可能有多个正确答案。）
- [x] $aba^{-1}b^{-1}cdc^{-1}d^{-1}$
- [ ] $abab^{-1}$
- [x] $abca^{-1}b^{-1}c^{-1}$
- [ ] $aabb$
::: solution
由上面的判别法，一个词给出可定向曲面，当且仅当每个字母以指数$+1$出现一次、以指数$-1$出现一次。第一个和第三个词满足这一条件。在$abab^{-1}$中，字母$a$以指数$+1$出现两次；在$aabb$中，两个字母都是如此。（第一个词给出亏格为二的曲面，第三个词是环面的一个六边形表示。）
:::
:::

## 连通和

::: definition 连通和 {#def-connected-sum}
设$M$和$N$是闭曲面。从每个曲面中挖去一个小闭圆盘的内部，再用一个同胚把由此得到的两个边界圆周粘合起来。所得的闭曲面称为**连通和**$M\# N$。
:::

可以证明，在同胚的意义下，结果与圆盘和粘合映射的选取无关（这要用到如下事实：曲面上任意两个嵌入圆盘都可以通过曲面的一个同胚互相重合；对于不可定向曲面，还要考虑对粘合映射作反射的情形）。球面是单位元：$M\# S^2\cong M$，因为从$S^2$中挖去一个圆盘后剩下的仍是一个圆盘，它恰好把洞重新填上。

::: proposition 连通和的欧拉示性数 {#prop-connected-sum}
对闭曲面$M$和$N$，有$\chi(M\# N) = \chi(M) + \chi(N) - 2$。
:::

::: proof
取$M$和$N$的三角剖分，并取挖去的圆盘分别为各自某个三角形的内部。挖去一个三角形的内部使$F$减少$1$，而$V$和$E$不变，所以两个挖了洞的曲面的$V - E + F$分别等于$\chi(M) - 1$和$\chi(N) - 1$。把两个边界三角形按顶点和边对应地粘合起来：在所得结果中，有$3$对顶点和$3$对边被等同，所以与不交并相比，$V$和$E$各减少$3$，交错和在粘合下不变。（如果粘合后的三角剖分还不是合格的三角剖分——因为现在有两个三角形有两条公共边——就进行细分；由$\chi$在细分下的不变性，这不改变计数。）因此$\chi(M\# N) = (\chi(M) - 1) + (\chi(N) - 1) - 3 + 3 = \chi(M) + \chi(N) - 2$。
:::

反复作连通和，就得到两个无穷族。**亏格为$g$的可定向曲面**是$\Sigma_g = T\# T\#\cdots\# T$（$g$个环面），即“有$g$个洞的甜甜圈”；**亏格为$k$的不可定向曲面**是$N_k = \R P^2\#\cdots\#\R P^2$（$k$个射影平面）。由[[#prop-connected-sum]]和归纳法，

$$
\chi(\Sigma_g) = 2 - 2g, \qquad \chi(N_k) = 2 - k .
$$ {#eq-chi-families}

它们的标准多边形词分别是$a_1b_1a_1^{-1}b_1^{-1}\cdots a_gb_ga_g^{-1}b_g^{-1}$（一个$4g$边形）和$a_1a_1a_2a_2\cdots a_ka_k$（一个$2k$边形）；在每种情形下，所有顶点都被等同为一个顶点（当$g, k\ge1$时），所以计数$1 - 2g + 1$和$1 - k + 1$验证了[[#eq-chi-families]]。

## 分类定理

::: theorem 闭曲面的分类 {#thm-classification}
每个闭曲面都恰好同胚于下列曲面之一：

1. 球面$S^2$；
2. $g\ge1$个环面的连通和$\Sigma_g$；
3. $k\ge1$个射影平面的连通和$N_k$。

因此，两个闭曲面同胚，当且仅当它们有相同的欧拉示性数，并且同为可定向的或同为不可定向的。
:::

::: proof
我们给出一个详细的证明概要；完整的证明见阿姆斯特朗的《基础拓扑学》（*Basic Topology*）第7章，以及Lee的《拓扑流形引论》（*Introduction to Topological Manifolds*）第6章和第10章。

**第1步：一个多边形。**由拉多定理，曲面$S$有三角剖分。由于$S$是连通的，可以把这些三角形排成一列，使每个三角形都与排在它前面的某个三角形有一条公共边。沿这样的边把它们逐个粘合起来，就得到单独一个多边形，它边界上的边两两等同（三角剖分的闭曲面的每条边都恰好位于两个三角形中）。所以$S$是一个多边形按某个词得到的商空间，词中每个字母恰好出现两次。

**第2步：标准形。**沿一条对角线把多边形剪开，再沿一对相配的边重新粘合，这会改变词但不改变曲面；用这种方法来化简词。依次进行：(a) 相邻的一对$xx^{-1}$可以消去（把多边形折起来），除非整个词就是$xx^{-1}$，这时曲面是球面；(b) 通过剪开和粘贴，可以把所有顶点都归入同一个等价类；(c) 每一对指数相同的字母都可以凑到一起，成为一个**交叉帽**$xx$；(d) 其余的字母以相反的指数出现，它们成对地相互交错，可以凑到一起成为**环柄**$xyx^{-1}y^{-1}$。结果是形如$x_1x_1\cdots x_kx_k\,a_1b_1a_1^{-1}b_1^{-1}\cdots a_gb_ga_g^{-1}b_g^{-1}$的词，它表示$N_k\#\Sigma_g$。

**第3步：迪克定理。**如果环柄和交叉帽同时出现，就利用同胚$T\#\R P^2\cong\R P^2\#\R P^2\#\R P^2$（通过对相应的词进行剪开和粘贴来证明），把每个环柄换成两个交叉帽。所以$S$是球面、某个$\Sigma_g$或某个$N_k$。

**第4步：唯一性。**欧拉示性数和可定向性都是拓扑不变量（[[#thm-invariance]]；可定向性是用拓扑的方式定义的）。在上述列表中，球面和各$\Sigma_g$是可定向的，$\chi = 2, 0, -2, -4,\dots$；各$N_k$是不可定向的，$\chi = 1, 0, -1,\dots$——两两不同。所以列表中没有两个曲面是同胚的，并且（可定向性，$\chi$）这一对数据决定了曲面。
:::

| 曲面 | 词 | $\chi$ | 可定向 |
|---|---|---|---|
| 球面$S^2$ | $aa^{-1}$ | $2$ | 是 |
| 环面$T = \Sigma_1$ | $aba^{-1}b^{-1}$ | $0$ | 是 |
| 亏格$g$，$\Sigma_g$ | $\prod_{i=1}^g a_ib_ia_i^{-1}b_i^{-1}$ | $2 - 2g$ | 是 |
| 射影平面$\R P^2 = N_1$ | $aa$或$abab$ | $1$ | 否 |
| 克莱因瓶$K = N_2$ | $aabb$或$aba^{-1}b$ | $0$ | 否 |
| $N_k$ | $a_1a_1\cdots a_ka_k$ | $2 - k$ | 否 |

::: quiz
一个闭曲面可定向，且欧拉示性数为$-6$。它是哪个曲面？
- [ ] $\Sigma_3$，亏格为$3$的可定向曲面
- [x] $\Sigma_4$，亏格为$4$的可定向曲面
- [ ] $N_8$，八个射影平面的连通和
- [ ] 由这些数据无法确定
::: solution
对可定向闭曲面，$\chi = 2 - 2g$，所以由$2 - 2g = -6$得$g = 4$。由分类定理，可定向性和$\chi$决定了曲面。$N_8$也满足$\chi = 2 - 8 = -6$，但它不可定向。
:::
:::

特别地，克莱因瓶就是$\R P^2\#\R P^2$：两者都不可定向，且$\chi = 0$。要识别由任一多边形词给出的曲面，只需数出顶点类的个数，计算$\chi = V - E + 1$，再应用可定向性判别法即可。

::: example 由词识别曲面 {#ex-identify}
识别由下列六边形词给出的闭曲面：(a) $abca^{-1}b^{-1}c^{-1}$；(b) $abacb^{-1}c^{-1}$。
::: solution
把顶点记为$v_0,\dots,v_5$，第$i$条边从$v_i$走到$v_{i+1}$（下标按模$6$计）；指数为$-1$的边是逆着箭头经过的，所以它的箭头从$v_{i+1}$指向$v_i$。

(a) 各箭头为：$a\colon v_0\to v_1$和$v_4\to v_3$；$b\colon v_1\to v_2$和$v_5\to v_4$；$c\colon v_2\to v_3$和$v_0\to v_5$。把起点与起点、终点与终点对应起来：$v_0\sim v_4$，$v_1\sim v_3$，$v_1\sim v_5$，$v_2\sim v_4$，$v_2\sim v_0$，$v_3\sim v_5$。等价类为$\set{v_0, v_2, v_4}$和$\set{v_1, v_3, v_5}$，所以$V = 2$，$E = 3$，$F = 1$，$\chi = 0$。每个字母都以两种指数出现，所以曲面是可定向的：它是**环面**。（这就是镶嵌图案中常见的环面的六边形图景：六边形的对边通过平移粘合。）

(b) 各箭头为：$a\colon v_0\to v_1$和$v_2\to v_3$；$b\colon v_1\to v_2$和$v_5\to v_4$；$c\colon v_3\to v_4$和$v_0\to v_5$。由此得$v_0\sim v_2$，$v_1\sim v_3$，$v_1\sim v_5$，$v_2\sim v_4$，$v_3\sim v_0$，$v_4\sim v_5$，六个顶点全部落入同一个类：$V = 1$，所以$\chi = 1 - 3 + 1 = -1$。字母$a$以指数$+1$出现两次，所以曲面不可定向。由分类定理，它是$N_3 = \R P^2\#\R P^2\#\R P^2$（由迪克定理，等价地也是$T\#\R P^2$）。
:::
:::

::: warning 仅有欧拉示性数是不够的
环面和克莱因瓶都有$\chi = 0$；带三个交叉帽的球面$N_3$与“环面加一个交叉帽”$T\#\R P^2$都有$\chi = -1$（而在这一情形，由迪克定理，它们**确实**同胚）。务必同时判定可定向性。另一方面，不要忘记分类定理讨论的是**闭**曲面：开圆盘和平面、圆环和默比乌斯带都不在它的范围之内，而带边曲面还需要以边界圆周的个数作为第三个不变量。
:::

## 欧拉公式与柏拉图立体

对于画在平面上的图，欧拉公式可以直接证明。

::: theorem 平面图的欧拉公式 {#thm-euler-planar}
设$G$是画在平面上、有$V$个顶点和$E$条边的连通图，其边是直线段或折线，且边与边只在端点处相交；并设$F$是它把平面分成的区域个数（包括无界区域）。则$V - E + F = 2$。
:::

::: proof
对位于圈上的边的条数作归纳。若$G$没有圈，则它是一棵树，所以$E = V - 1$；树不分割平面，所以$F = 1$；于是$V - E + F = V - (V - 1) + 1 = 2$。否则，取$G$的某个圈$Z$上的一条边$e$。这个圈是一个闭多边形，由（折线情形的）若尔当曲线定理，它把平面分成内部和外部，而$e$位于$Z$内部的某个区域与$Z$外部的某个区域的公共边界上。这两个区域是不同的，删去$e$就把它们合并为一个，而图仍然连通（圈的其余部分仍连接着$e$的两个端点）。所以删去$e$使$E$和$F$各减少$1$，$V - E + F$保持不变，而新图中位于圈上的边更少。由归纳法，$V - E + F = 2$。
:::

把一个凸多面体从紧靠某个面外侧的一点投影到该面所在的平面上，它就变成这样的一个平面图（用来投影的那个面变成无界区域），由此便得到欧拉多面体公式$V - E + F = 2$。用本章的语言来说，它就是$\chi(S^2) = 2$。这个公式也是[[discrete/colouring-planarity]]一章中研究可平面图的基本工具。

::: theorem 五种柏拉图立体 {#thm-platonic}
设球面的一个多边形分解中所有的面都是$p$边形，所有顶点的度都是$q$，其中$p, q\ge3$。则$(p, q)$是$(3,3)$、$(3,4)$、$(4,3)$、$(3,5)$、$(5,3)$之一，分别由四面体、八面体、立方体、二十面体和十二面体实现。
:::

::: proof
计数边与面的关联以及边与顶点的关联，得$pF = 2E$和$qV = 2E$。把$V = 2E/q$和$F = 2E/p$代入$V - E + F = 2$，再除以$2E$，得

$$
\frac1q + \frac1p = \frac12 + \frac1E > \frac12 .
$$

若$p, q\ge4$，则左边至多为$\frac12$；若$p = 3$，则$\frac1q > \frac16$迫使$q < 6$，即$q\in\set{3, 4, 5}$；类似地，若$q = 3$，则$p\in\set{3,4,5}$。于是只剩下所列的五对，由$\frac1E = \frac1p + \frac1q - \frac12$得$E = 6, 12, 12, 30, 30$，再由$V = 2E/q$，$F = 2E/p$得$(V, E, F)$依次为$(4, 6, 4)$、$(6, 12, 8)$、$(8, 12, 6)$、$(12, 30, 20)$、$(20, 30, 12)$。每一种都由相应的正多面体实现。
:::

::: application 足球、富勒烯与曲率
足球由五边形和六边形缝制而成，每个顶点处有三个面。欧拉公式决定了五边形的个数：设有$P$个五边形和$H$个六边形，则$2E = 5P + 6H = 3V$，而$V - E + F = 2$变为$\frac{2E}{3} - E + P + H = 2$，即$-\frac{5P + 6H}{6} + P + H = 2$，所以$P = 12$——无论六边形有多少个。同样的计数也支配着称为富勒烯的碳分子（巴克敏斯特富勒烯$C_{60}$有$12$个五边形和$20$个六边形），并解释了为什么由六边形构成的薄片不可能无缺陷地闭合成一个球。更深层的原因是[[differential-geometry/geodesics-gauss-bonnet]]一章中的高斯-博内定理：闭曲面的总曲率是$2\pi\chi$，而在多面体上，全部曲率都集中在顶点处。
:::

::: history
欧拉（Euler）在1750年致克里斯蒂安·哥德巴赫（Christian Goldbach）的一封信中陈述了多面体公式，并在1758年发表的论文中给出了证明；勒内·笛卡儿（René Descartes）在1630年前后就发现了一个关于角的等价关系，但它直到1860年才得以发表。奥古斯丁-路易·柯西（Augustin-Louis Cauchy）于1813年给出了一个证明；同年，西蒙·吕利耶（Simon Lhuilier）指出，这个公式对带有隧道的多面体不成立，这是高亏格曲面的欧拉示性数的最初端倪。奥古斯特·费迪南德·默比乌斯（August Ferdinand Möbius，1863年前后）和卡米耶·若尔当（Camille Jordan，1866年）对可定向曲面进行了分类，瓦尔特·冯·迪克（Walther von Dyck）于1888年处理了不可定向曲面；分类定理的第一个严格证明（针对三角剖分的曲面）由马克斯·德恩（Max Dehn）和波尔·黑加德（Poul Heegaard）于1907年给出；亨利·布拉哈纳（Henry Brahana）1921年借助多边形词的标准形给出的证明，就是上面概述的那个证明。蒂博尔·拉多（Tibor Radó）于1925年证明了每个曲面都可以三角剖分，从而使这个定理得以完整。
:::

## 后续内容

曲面的分类是现代拓扑学中许多工作的范本：人们寻找既可计算、又能区分一切对象的不变量（这里是可定向性和欧拉示性数）。在更高维数中，这一纲领要困难得多；对于三维流形，直到2003年佩雷尔曼（Perelman）证明了瑟斯顿（Thurston）的几何化猜想，它才得以完成；而在四维，完全的分类是不可能的。在任意维数中，欧拉示性数都推广为各同调群的秩的交错和；而曲面的基本群（借助塞弗特-范坎彭定理由它们的多边形词算出）则推广了[[topology/fundamental-group]]一章中的计算。在[[differential-geometry/geodesics-gauss-bonnet]]一章中，欧拉示性数以总曲率的形式再次出现；在复分析中，代数函数的黎曼曲面恰好就是可定向闭曲面$\Sigma_g$，而它们的亏格起着核心作用。

::: summary
- 曲面是局部同胚于平面的第二可数豪斯多夫空间；闭曲面是紧的、连通的（球面、环面、克莱因瓶、射影平面）。
- 三角剖分（或任何多边形分解）的欧拉示性数$\chi = V - E + F$是拓扑不变量：$\chi(S^2) = 2$，$\chi(T) = \chi(K) = 0$，$\chi(\R P^2) = 1$。
- 曲面不可定向当且仅当它包含默比乌斯带；对于多边形词，这当且仅当某个字母以相同的指数出现两次。
- 连通和：$\chi(M\# N) = \chi(M) + \chi(N) - 2$，所以$\chi(\Sigma_g) = 2 - 2g$，$\chi(N_k) = 2 - k$。
- 分类：每个闭曲面都是$S^2$、某个$\Sigma_g$或某个$N_k$，由可定向性和$\chi$决定（证明：作三角剖分，粘合成一个多边形，把词化为标准形，再利用迪克定理$T\#\R P^2\cong N_3$）。
- 对连通平面图和凸多面体有$V - E + F = 2$；因此恰好有五种柏拉图立体，而由五边形和六边形构成的球恰好有$12$个五边形。
:::

## 习题

::: exercise 二十面体 {level=1 check="2"}
正二十面体有$20$个三角形面，每个顶点处有$5$个面相交。由这些数据计算$V$和$E$，进而计算$V - E + F$。
::: solution
每个面有$3$条棱，每条棱位于$2$个面上：$E = \frac{3\cdot20}{2} = 30$。每个面有$3$个顶点，每个顶点位于$5$个面上：$V = \frac{3\cdot20}{5} = 12$。所以$V - E + F = 12 - 30 + 20 = 2$。
:::
:::

::: exercise 亏格为三的曲面 {level=1 check="-4"}
亏格为$3$的可定向闭曲面的欧拉示性数是多少？通过计数它的标准多边形表示中的顶点、边和面来检验你的答案。
::: solution
由[[#eq-chi-families]]，$\chi(\Sigma_3) = 2 - 2\cdot3 = -4$。标准词$a_1b_1a_1^{-1}b_1^{-1}a_2b_2a_2^{-1}b_2^{-1}a_3b_3a_3^{-1}b_3^{-1}$有$12$个字母，所以这个多边形是$12$边形（有一个顶点类、$6$条边和一个面：$1 - 6 + 1 = -4$）。
:::
:::

::: exercise 克莱因瓶 {level=1 check="0"}
计算词为$aabb$的曲面的欧拉示性数，并说明为什么它是克莱因瓶。
::: solution
在词为$aabb$的正方形中考察顶点：第一个$a$是$v_0\to v_1$，第二个$a$是$v_1\to v_2$，所以$v_0\sim v_1\sim v_2$；第一个$b$是$v_2\to v_3$，第二个$b$是$v_3\to v_0$，所以$v_2\sim v_3\sim v_0$。一个顶点、两条边、一个面：$\chi = 1 - 2 + 1 = 0$。两个字母都以相同的指数出现两次，所以曲面不可定向。由分类定理，$\chi = 0$的不可定向闭曲面是$N_2$，即克莱因瓶；词$aabb$正是$\R P^2\#\R P^2$的标准形。
:::
:::

::: exercise 识别曲面 {level=2 check="1"}
识别六边形词为$abcabc$的闭曲面。它的欧拉示性数是多少？
::: solution
把顶点记为$v_0,\dots,v_5$。各箭头为：$a\colon v_0\to v_1$和$v_3\to v_4$；$b\colon v_1\to v_2$和$v_4\to v_5$；$c\colon v_2\to v_3$和$v_5\to v_0$。由$a$、$b$、$c$各对边的起点和终点得$v_0\sim v_3$，$v_1\sim v_4$，$v_2\sim v_5$，而这就是全部的等同：三个顶点类$\set{v_0, v_3}$、$\set{v_1, v_4}$、$\set{v_2, v_5}$。因此$\chi = 3 - 3 + 1 = 1$。每个字母都以指数$+1$出现两次，所以曲面不可定向：它是射影平面。（事实上，$abcabc$就是把每个边界点与其对径点粘合的六边形，也就是把边界上的对径点等同起来的圆盘。）
:::
:::

::: exercise 十二个五边形 {level=2 check="12"}
一个同胚于球面的闭多面体曲面只有五边形面和六边形面，并且每个顶点处恰有三个面相交。它有多少个五边形？
::: solution
与上面的应用一样：设有$P$个五边形和$H$个六边形，计数边与面的关联得$2E = 5P + 6H$，计数边与顶点的关联得$2E = 3V$。欧拉公式$V - E + F = 2$（其中$F = P + H$）变为$\frac{2E}{3} - E + P + H = 2$，即$P + H - \frac{5P + 6H}{6} = 2$，所以$\frac{P}{6} = 2$，$P = 12$，与$H$无关。
:::
:::

::: exercise K₅不是可平面图 {level=2}
用欧拉公式证明：有$V\ge3$个顶点的简单连通平面图至多有$3V - 6$条边，并由此推出完全图$K_5$不能无交叉地画在平面上。
::: solution
至少有三个顶点的简单平面图的每个区域都至少由$3$条边围成，而每条边至多是$2$个区域的边界，所以$3F\le2E$。于是$2 = V - E + F\le V - E + \frac{2E}{3}$，即$E\le3V - 6$。对于$K_5$，$V = 5$，$E = 10 > 3\cdot5 - 6 = 9$，所以它不是可平面图。（用$4F\le2E$作同样的论证可以证明，没有三角形的$K_{3,3}$也不是可平面图：$9 > 2\cdot6 - 4$。）
:::
:::

::: exercise 可定向性与欧拉示性数 {level=2}
证明可定向闭曲面的欧拉示性数是偶数。不可定向闭曲面的$\chi$可以取哪些值？是否存在$\chi = 3$的闭曲面？
::: solution
由分类定理，可定向闭曲面是$S^2$或$\Sigma_g$，$\chi = 2 - 2g$（$g\ge0$），总是偶数。不可定向闭曲面是$N_k$，当$k\ge1$时$\chi = 2 - k$，可以取遍每个$\le1$的整数。没有闭曲面满足$\chi\ge3$：最大的值是$\chi(S^2) = 2$。
:::
:::

::: exercise 不存在七条棱的多面体 {level=3}
证明：不存在恰有$7$条边的球面多边形分解（每个面至少有$3$条边，每个顶点的度至少为$3$），尽管存在有$6$条边和$8$条边的这种分解。
::: solution
计数关联得$3F\le2E$和$3V\le2E$。当$E = 7$时：$F\le\frac{14}{3}$，所以$F\le4$；同理$V\le4$。于是$V - E + F\le4 - 7 + 4 = 1 < 2$，与欧拉公式矛盾。有$6$条和$8$条边的例子：四面体（$V = 4$，$E = 6$，$F = 4$）和四棱锥（$V = 5$，$E = 8$，$F = 5$）。（对除$7$以外的每个$E\ge6$，这样的多面体都存在。）
:::
:::

::: exercise 环面的三角剖分至少需要七个顶点 {level=3 check="7"}
证明环面的每个三角剖分都至少有$7$个顶点。（恰有$7$个顶点的三角剖分是存在的，所以$7$是最小值。）
::: hint
在三角剖分中，每条边恰好位于两个三角形中，并且两个顶点之间至多有一条边。
:::
::: solution
每个三角形有$3$条边，每条边恰好位于$2$个三角形中，所以$3F = 2E$。由于$\chi(T) = 0$，$V - E + \frac{2E}{3} = 0$，即$E = 3V$。在（[[#def-euler]]中定义的）三角剖分中，两个不同的顶点之间至多有一条边，所以$E\le\binom V2 = \frac{V(V-1)}{2}$。因此$3V\le\frac{V(V - 1)}{2}$，即$V - 1\ge6$，所以$V\ge7$。最小的$7$顶点三角剖分有$V = 7$，$E = 21$，$F = 14$，并且每对顶点之间都有一条边：完全图$K_7$被无交叉地画在了环面上。
:::
:::

::: exercise 连通和与可定向性 {level=3}
利用分类定理确定曲面$T\#K$和$\R P^2\#K$，其中$K$是克莱因瓶。再证明：对$g\ge0$，$k\ge1$，有$\Sigma_g\#N_k\cong N_{2g+k}$。
::: solution
$\chi(T\# K) = 0 + 0 - 2 = -2$，并且$T\# K$包含一条默比乌斯带（在$K$中），所以它是$\chi = -2$的不可定向曲面：它是$N_4$。类似地，$\chi(\R P^2\# K) = 1 + 0 - 2 = -1$，且不可定向：它是$N_3$。一般地，$\Sigma_g\# N_k$是不可定向的（它包含$N_k$中的默比乌斯带，因为挖去的圆盘可以选得远离其中一条默比乌斯带），并且$\chi(\Sigma_g\# N_k) = (2 - 2g) + (2 - k) - 2 = 2 - (2g + k)$。由分类定理，它同胚于$N_{2g+k}$。（当$g = 1$，$k = 1$时，这就是迪克定理$T\#\R P^2\cong N_3$。）
:::
:::
