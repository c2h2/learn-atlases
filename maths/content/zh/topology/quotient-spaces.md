取一张正方形的纸，把它的左边与右边粘合起来，就得到一个圆柱面。再把圆柱面顶部的圆周与底部的圆周粘合起来，就得到一个环面——甜甜圈的表面。如果在粘合第一对边之前先把纸带扭转半圈，得到的就是默比乌斯带，一个只有一侧的曲面。粘合是构造新空间最有力的方法，几何与拓扑中几乎每一个有趣的空间都可以描述为把某些点等同起来的多边形、圆盘或立方体。

为了使粘合精确化，我们需要**商拓扑**：用一个等价关系把点等同起来，并规定一组等价类构成的集合是开集，当且仅当这些等价类中所有点构成的集合是开集。这个简单的定义具有一个与积空间的泛性质对偶的泛性质；再结合[[topology/compactness]]一章中“从紧空间到豪斯多夫空间”的定理，它使我们能够把商空间识别为熟悉的空间。但粘合也可能造出怪物——在这样的空间中，一个序列会收敛到两个不同的点，或者开集只有$\emptyset$和整个空间。为了把握哪些空间性质良好，我们先研究**分离公理**，其中最重要的是豪斯多夫性质。

## 分离公理

在度量空间中，不同的点可以用不相交的球分离开。一般的拓扑空间未必具有这一性质（[[topology/topological-spaces#ex-many-limits]]）；点与闭集能在多大程度上被开集分离开，由一系列层层递进的条件来衡量。

::: definition 分离公理 {#def-separation}
称拓扑空间$X$为

1. **$T_1$空间**，如果对任意两个不同的点$x, y$，每一点都有一个不含另一点的开邻域；
2. **豪斯多夫空间**（或$T_2$空间），如果任意两个不同的点都有**不相交的**开邻域；
3. **正则空间**，如果它是$T_1$空间，并且任一点$x$与任一闭集$C\not\ni x$都有不相交的开邻域；
4. **正规空间**，如果它是$T_1$空间，并且任意两个不相交的闭集都有不相交的开邻域。
:::

每个条件都蕴涵前面的条件（在$T_1$空间中单点集是闭集，所以正则蕴涵豪斯多夫，正规蕴涵正则）。度量空间满足全部四个条件：就正规性而言，给定不相交的闭集$A$和$B$，函数$f(x) = \frac{d(x, A)}{d(x, A) + d(x, B)}$连续，在$A$上等于$0$，在$B$上等于$1$，而$f^{-1}([0, \frac12))$与$f^{-1}((\frac12, 1])$就是不相交的开邻域。反过来，乌雷松（Urysohn）引理断言，每个正规空间都有这样的分离函数。

::: proposition T₁即单点集都是闭集 {#prop-t1}
空间$X$是$T_1$空间，当且仅当每个单点集$\set x$都是闭集。
:::

::: proof
若$X$是$T_1$空间且$x\in X$，则每个$y\neq x$都有一个不含$x$的开邻域；这些邻域的并就是$X\setminus\set x$，因此它是开集。反过来，若所有单点集都是闭集且$x\neq y$，则$X\setminus\set y$是$x$的一个不含$y$的开邻域；交换两点的位置亦然。
:::

::: example 分离公理不成立的情形 {#ex-separation}
判断下列空间满足哪些分离性质：(a) 赋予余有限拓扑的无限集；(b) 谢尔宾斯基（Sierpiński）空间；(c) 索根弗里（Sorgenfrey）直线$\R_\ell$。
::: solution
(a) 单点集是有限集，因而是闭集：该空间是$T_1$空间。它不是豪斯多夫空间，因为任意两个非空开集的补集都是有限集，从而它们必定相交。(b) 在谢尔宾斯基空间$\set{0,1}$（开集为$\emptyset$、$\set1$、$\set{0,1}$）中，包含$0$的开集只有整个空间，而它包含$1$：不是$T_1$空间。(c) $\R_\ell$是豪斯多夫空间，因为它的拓扑比标准拓扑更细：在$\R$中分离两点的不相交区间在$\R_\ell$中也是开集。（事实上它是正规空间，尽管积空间$\R_\ell\times\R_\ell$不是——这是一个著名的例子，说明正规性在取乘积时不一定保持。）
:::
:::

豪斯多夫性质是其中最重要的一个，首要的原因是极限的唯一性。

::: theorem 豪斯多夫空间中的极限 {#thm-unique-limits}
在豪斯多夫空间中，一个序列至多收敛到一个点。
:::

::: proof
设$x_n\to x$且$x_n\to y$，其中$x\neq y$。取不相交的开集$U\ni x$和$V\ni y$。则对所有$n\ge N_1$有$x_n\in U$，对所有$n\ge N_2$有$x_n\in V$，于是当$n\ge\max(N_1, N_2)$时$x_n\in U\cap V = \emptyset$——这不可能。
:::

::: theorem 豪斯多夫空间的子空间与积空间 {#thm-hausdorff-products}
豪斯多夫空间的每个子空间都是豪斯多夫空间，两个豪斯多夫空间的积空间也是豪斯多夫空间。此外，$X$是豪斯多夫空间当且仅当**对角线**$\Delta = \set{(x, x) : x\in X}$在$X\times X$中是闭集。
:::

::: proof
**子空间。**若$x\neq y$是$A\subseteq X$中的点，则$X$中不相交的开集$U\ni x$和$V\ni y$给出$A$中不相交的开集$U\cap A$和$V\cap A$。

**积空间。**设$(x_1, y_1)\neq(x_2, y_2)$是$X\times Y$中的点；不妨设$x_1\neq x_2$（另一种情形是对称的）。在$X$中取不相交的开集$U_1\ni x_1$、$U_2\ni x_2$。则$U_1\times Y$和$U_2\times Y$是这两点的不相交的开邻域。

**对角线。**点$(x, y)\notin\Delta$意味着$x\neq y$。基本开集$U\times V$包含$(x, y)$且与$\Delta$不相交，当且仅当$x\in U$、$y\in V$且$U\cap V = \emptyset$。因此，$\Delta$的补集是开集（$\Delta$外的每一点周围都有这样一个方块）当且仅当任意两个不同的点都有不相交的邻域。
:::

::: quiz
下列空间中哪些是豪斯多夫空间？（可能有多个正确答案。）
- [x] 任意度量空间
- [ ] 赋予余有限拓扑的$\R$
- [x] 索根弗里直线$\R_\ell$
- [x] $\R^n$的任意子空间
- [ ] 含两个点的平凡拓扑空间
::: solution
度量空间是豪斯多夫空间（用半径为两点间距离一半的球来分离），因此$\R^n$的子空间也是。$\R_\ell$的拓扑比$\R$的更细，所以它继承了那些起分离作用的开集。无限集上的余有限拓扑中不存在两个不相交的非空开集，而含两个点的平凡拓扑空间只有一个非空开集。
:::
:::

## 商拓扑

::: definition 商空间 {#def-quotient}
设$X$是拓扑空间，$\sim$是$X$上的等价关系。记$X/{\sim}$为等价类的集合，并称$q\colon X\to X/{\sim}$，$q(x) = [x]$为**商映射**。$X/{\sim}$上的**商拓扑**规定：$U\subseteq X/{\sim}$是开集当且仅当$q^{-1}(U)$是$X$中的开集。
:::

这确实是一个拓扑，因为取原像与并、交运算可交换：$q^{-1}(\bigcup U_\alpha) = \bigcup q^{-1}(U_\alpha)$，$q^{-1}(U\cap V) = q^{-1}(U)\cap q^{-1}(V)$。它是$X/{\sim}$上使$q$连续的**最细**的拓扑。注意$q^{-1}(U)$总是**饱和的**——即若干等价类的并——因此商空间的开集恰好与$X$中的饱和开集一一对应。

一种常见的特殊情形：若$A\subseteq X$，则$X/A$表示把$A$的所有点等同为一个点、其余各点保持不动所得的商空间（“把$A$捏成一点”）。

::: theorem 商空间的泛性质 {#thm-quotient-universal}
设$q\colon X\to X/{\sim}$是商映射。映射$g\colon X/{\sim}\to Z$连续当且仅当$g\circ q\colon X\to Z$连续。因此，每个在各等价类上取常值的连续映射$f\colon X\to Z$都诱导出一个连续映射$\bar f\colon X/{\sim}\to Z$，满足$\bar f\circ q = f$。
:::

::: proof
若$g$连续，则由于$q$连续，$g\circ q$也连续。反过来，设$g\circ q$连续，$W\subseteq Z$是开集。则$q^{-1}\big(g^{-1}(W)\big) = (g\circ q)^{-1}(W)$是$X$中的开集，于是由商拓扑的定义，$g^{-1}(W)$是$X/{\sim}$中的开集。至于第二个结论：由于$f$在各等价类上取常值，$\bar f([x]) = f(x)$是良定义的；又$\bar f\circ q = f$连续，所以由第一部分，$\bar f$连续。
:::

对比[[topology/continuous-maps#thm-product]]：**映入**积空间的映射连续，当且仅当它的各分量都连续；从商空间**映出**的映射连续，当且仅当它与$q$的复合连续。为了把商空间识别为熟悉的空间，我们把这一点与紧性结合起来。

::: theorem 商空间的识别 {#thm-recognise}
设$X$是紧空间，$Y$是豪斯多夫空间，$f\colon X\to Y$是连续满射。当$f(x) = f(x')$时规定$x\sim x'$。则诱导映射$\bar f\colon X/{\sim}\to Y$是同胚。
:::

::: proof
由[[#thm-quotient-universal]]，$\bar f$连续；由于$f$是满射，它也是满射；它是单射，因为$\bar f([x]) = \bar f([x'])$意味着$f(x) = f(x')$，即$[x] = [x']$。商空间$X/{\sim} = q(X)$作为紧空间的连续像是紧的（[[topology/compactness#thm-image]]）。所以$\bar f$是从紧空间到豪斯多夫空间的连续双射，从而由[[topology/compactness#thm-compact-hausdorff]]，它是同胚。
:::

::: example 两个基本的商空间 {#ex-basic-quotients}
证明：(a) 把区间$[0, 1]$的两个端点等同起来，所得空间同胚于圆周$S^1$；(b) 把闭圆盘$D^2$的边界圆周捏成一点，所得空间同胚于球面$S^2$。
::: solution
(a) 令$f(t) = (\cos2\pi t, \sin2\pi t)$，它是从紧空间$[0, 1]$到豪斯多夫空间$S^1$上的连续满射。两点有相同的像，当且仅当它们相等，或者它们是两个端点$0, 1$。所以[[#thm-recognise]]中的等价关系就是“把$0$与$1$等同”，从而$[0, 1]/\set{0,1}\cong S^1$。

(b) 对$x\in D^2$，记$r = \norm x$，定义

$$
f(x) = \Big(\sin(\pi r)\,\frac{x}{r},\ \cos(\pi r)\Big)\ (x\neq0), \qquad f(0) = (0, 0, 1).
$$

它把半径为$r$的圆周映到与北极$N = (0,0,1)$的角距离为$\pi r$的纬线圈上；它是连续的（在$0$处连续是因为$\norm{\sin(\pi r)\,x/r}\le\sin(\pi r)\to0$），像落在$S^2$中（因为$\sin^2 + \cos^2 = 1$），并且是满射。它在开圆盘上是单射，并把整个边界圆周$r = 1$映到南极$(0, 0, -1)$。由[[#thm-recognise]]，$D^2/S^1\cong S^2$。同理，对所有$n$都有$D^n/S^{n-1}\cong S^n$。
:::
:::

## 粘合多边形：环面、默比乌斯带、克莱因瓶和射影平面

许多重要的曲面都是单位正方形$Q = [0, 1]^2$的商空间：边界上的点两两等同，内部的点保持不动。

- **圆柱面**：$(0, y)\sim(1, y)$。
- **环面**$T$：$(0, y)\sim(1, y)$且$(x, 0)\sim(x, 1)$。
- **默比乌斯带**$M$：$(0, y)\sim(1, 1 - y)$——左右两边扭转半圈后粘合。
- **克莱因瓶**$K$：$(0, y)\sim(1, y)$且$(x, 0)\sim(1 - x, 1)$——把圆柱面两端的圆周经一个反射粘合起来。
- **实射影平面**$\R P^2$：$(0, y)\sim(1, 1 - y)$且$(x, 0)\sim(1 - x, 1)$——每个边界点都与它关于正方形中心对称的点粘合。

一种方便的简记法是用字母和箭头标记正方形的各条边，并沿边界依次读出。从顶点$(0, 0)$出发沿顺时针方向读，以左边为$a$（箭头朝上）、上边为$b$（箭头朝右），则环面是$aba^{-1}b^{-1}$，克莱因瓶是$aba^{-1}b$，射影平面是$abab$，其中取逆表示逆着箭头方向经过这条边。这些**多边形表示**是[[topology/surfaces]]一章中曲面分类所用的语言。

::: example 环面是两个圆周的积 {#ex-torus}
证明：按上述方式把对边等同起来的正方形同胚于$S^1\times S^1$。
::: solution
令$f\colon Q\to S^1\times S^1$，$f(x, y) = \big((\cos2\pi x, \sin2\pi x), (\cos2\pi y, \sin2\pi y)\big)$。由[[topology/continuous-maps#thm-product]]，它是连续的；它是满射；并且$Q$是紧的，而$S^1\times S^1$是豪斯多夫空间（[[#thm-hausdorff-products]]）。$f(x, y) = f(x', y')$当且仅当$x - x'\in\Z$且$y - y'\in\Z$，对$[0,1]^2$中的点而言，这意味着：$x' = x$或$\set{x, x'} = \set{0, 1}$，对$y$也类似。这些恰好就是定义环面的那些等同关系（包括四个顶点，它们全都变成同一个点）。由[[#thm-recognise]]，$T\cong S^1\times S^1$，而由[[topology/continuous-maps#ex-product]]，这就是$\R^3$中的甜甜圈曲面。
:::
:::

在$\R^3$中构造默比乌斯带的方法是：让一条短线段沿一个圆周移动一圈，同时使它旋转半圈。

::: widget surface
fx: (1 + v*cos(u/2))*cos(u)
fy: (1 + v*cos(u/2))*sin(u)
fz: v*sin(u/2)
u: 0, 2pi
v: -0.4, 0.4
color: height
caption: 默比乌斯带：当$u$沿圆周绕行一圈时，（以$v$为参数的）线段转过半圈，所以$u = 2\pi$处的线段是$u = 0$处的线段翻转过来的：$(0, y)\sim(1, 1 - y)$。旋转它，并用目光沿着边缘走一圈——这条带子只有一条边界曲线，也只有一侧。
:::

克莱因瓶和射影平面根本无法嵌入$\R^3$（$\R^3$中的闭曲面把空间分成内部和外部，而这两个曲面都只有一侧）。可以把它们画成带自交的样子。下面克莱因瓶的“8字形”图像沿一个圆周穿过自身；而在抽象的商空间中并没有相交。

::: widget surface
fx: (2 + cos(u/2)*sin(v) - sin(u/2)*sin(2*v))*cos(u)
fy: (2 + cos(u/2)*sin(v) - sin(u/2)*sin(2*v))*sin(u)
fz: sin(u/2)*sin(v) + cos(u/2)*sin(2*v)
u: 0, 2pi
v: 0, 2pi
color: height
caption: 克莱因瓶在$\R^3$中的一个浸入：一个8字形截面沿一个圆周移动，同时旋转半圈。绕行一圈之后，这个8字与自身重合，但参数为$v$的点落到了参数为$-v$的点出发时的位置，所以两端的圆周是经一个反射粘合起来的，正如克莱因瓶那样。这个曲面与自身相交，但抽象的克莱因瓶——正方形按$aba^{-1}b$得到的商空间——并不自交；它可以无自交地存在于$\R^4$中。
:::

射影平面有几种同样有用的描述，它们彼此同胚：

1. 边界词为$abab$的正方形（或者把边界上的对径点等同起来的闭圆盘：对$\norm x = 1$，$x\sim-x$）；
2. 把对径点等同起来的球面$S^2$：$x\sim-x$；
3. $\R^3$中过原点的直线的全体，方向相近的直线视为彼此接近。

(2)与(3)的等价性是显然的（每条直线与球面交于一对对径点）。至于(1)与(2)：$S^2$上的每一对对径点在闭北半球面上都有代表元，并且除了在赤道上（那里一对点都落在赤道上）之外，代表元是唯一的；而半球面就是一个圆盘。把半球面投影到圆盘上并利用[[#thm-recognise]]，就可以把这一想法变成证明（[[#exr-rp2]]）。

::: application 周期性边界条件
物理和化学中的模拟常用一个盒子来模拟无限晶体或流体中的一小块：粒子从盒子的一个面离开，就从相对的面重新进入。从数学上看，盒子被换成了商空间$\R^3/\Z^3$，即三维环面，它没有边界，也没有特殊的点。同样的等同方式也出现在一些经典电子游戏中：物体从屏幕右侧离开，就从左侧重新出现；从顶部离开，就从底部重新出现——屏幕是一个环面。传送带有时被做成默比乌斯带，使“两侧”磨损均匀——其实它只有一侧。
:::

## 性质不好的商空间

性质非常好的空间，其商空间的性质可能非常差。

::: example 有两个原点的直线 {#ex-two-origins}
设$X = \R\times\set{0, 1}$（直线的两个不相交的副本），并对每个$x\neq0$令$(x, 0)\sim(x, 1)$。证明：商空间$L$的每一点都有一个同胚于开区间的邻域，但$L$不是豪斯多夫空间。
::: solution
记$0_a$和$0_b$分别为$(0,0)$和$(0,1)$的等价类，即“两个原点”。对每个副本$i\in\set{0,1}$，令$j_i\colon\R\to L$，$j_i(x) = q(x, i)$；它是连续的单射。对开集$W\subseteq\R$，

$$
q^{-1}\big(j_i(W)\big) = \big(W\times\set i\big)\cup\big((W\setminus\set0)\times\set{1 - i}\big),
$$

它是$X$中的开集；所以$j_i(W)$是$L$中的开集。取$W = \R$可知像$L_i = j_i(\R)$是开集，而一般情形表明$j_i$把开集映为开集。因此$j_i$是从$\R$到开集$L_i$上的同胚，并且$L$的每一点都落在$L_0$或$L_1$中。但对任意开集$U\ni0_a$和$V\ni0_b$，它们的原像分别包含区间$(-\eps,\eps)\times\set0$和$(-\eps', \eps')\times\set1$，而满足$0 < \delta < \min(\eps,\eps')$的点$(\delta, 0)\sim(\delta, 1)$给出了$U$与$V$的一个公共点。所以$0_a$与$0_b$无法分离；事实上，序列$[(1/n, 0)]$同时收敛到这两个原点。
:::
:::

::: example 具有平凡拓扑的商空间 {#ex-r-mod-q}
在$\R$上，当$x - y\in\Q$时规定$x\sim y$。证明$\R/\Q$上的商拓扑是平凡拓扑。
::: solution
设$U\subseteq\R/\Q$是非空开集。则$W = q^{-1}(U)$是$\R$的一个饱和的非空开子集：若$x\in W$，则对每个有理数$r$都有$x + r\in W$。$W$包含某个区间$(a, b)$，从而包含它的所有平移$(a + r, b + r)$，$r\in\Q$。每个实数都落在其中某个平移区间中（取有理数$r$使$x - b < r < x - a$），所以$W = \R$，$U$就是整个空间。尽管这个商空间有不可数多个点，它的开集却只有$\emptyset$和整个商空间。
:::
:::

::: warning 商映射不一定是开映射，商空间也不一定是豪斯多夫空间
人们很容易以为开集在商映射下的像是开集；但这往往不成立。在$[0,1]\to[0,1]/\set{0,1}\cong S^1$中，$[0,1]$的开集$[0, \frac12)$被映成一段半开弧，它在圆周中不是开集，因为它的原像$[0,\frac12)\cup\set1$不是开集。检验商空间中的集合是否为开集时，总要取饱和集的**原像**来判断。也绝不要想当然地认为商空间是豪斯多夫空间：只有当各等价类都是$X$中的闭集时，商空间$X/{\sim}$才可能是豪斯多夫空间；而即使各等价类都是闭集也还不够，有两个原点的直线就说明了这一点。[[#thm-recognise]]是最稳妥的途径：找出一个从紧空间到某个已知豪斯多夫空间上的连续满射。
:::

::: quiz
把子集$A\subseteq\R$捏成一点。对哪些$A$，$\R/A$是豪斯多夫空间？
- [x] $A = [0, 1]$
- [ ] $A = (0, 1)$
- [ ] $A = \Q$
- [x] $A = \set{0}$
::: solution
若$A$不是闭集，则点$[A]$在商空间中不是闭集（它的原像$A$不是闭集），所以商空间甚至不是$T_1$空间：这就排除了$(0,1)$和$\Q$。当$A = \set0$时，没有任何点被等同。当$A = [0,1]$时，映射$f(x) = x$（$x\le0$时）、$0$（$0\le x\le1$时）、$x - 1$（$x\ge1$时）由粘接引理是连续的，它是满射，并且恰好把$[0,1]$中的点等同起来；可以验证，诱导映射$\R/[0,1]\to\R$有连续的逆映射：$y\le0$时为$y\mapsto q(y)$，$y\ge0$时为$q(y + 1)$。所以$\R/[0,1]\cong\R$，它是豪斯多夫空间。
:::
:::

::: history
默比乌斯带于1858年由奥古斯特·费迪南德·默比乌斯（August Ferdinand Möbius）和约翰·贝内迪克特·利斯廷（Johann Benedict Listing）各自独立发现；费利克斯·克莱因（Felix Klein）于1882年描述了他的单侧闭曲面。射影平面来自射影几何，它是17世纪吉拉尔·笛沙格（Girard Desargues）和19世纪让-维克托·彭赛列（Jean-Victor Poncelet）的工作所处的背景。1914年，豪斯多夫（Hausdorff）把他的分离公理纳入了拓扑空间的定义。更细致的分离公理体系由海因里希·蒂策（Heinrich Tietze）于1923年整理而成，而帕维尔·乌雷松（Pavel Urysohn）关于正规空间中分离闭集的连续函数的引理发表于1925年。从20世纪20年代起，人们开始系统地研究粘合空间，其中尤以罗伯特·李·穆尔（Robert Lee Moore）关于平面分解的工作最为突出。
:::

## 后续内容

商空间是本课程余下部分中例子的主要来源。在[[topology/fundamental-group]]一章中，我们把圆周看作商空间$\R/\Z$来计算它的基本群，并给出环面和射影平面的基本群。在[[topology/surfaces]]一章中，每个闭曲面都表示为一个各边两两等同的多边形，而分类定理断言：球面、环面、射影平面以及它们的连通和是仅有的可能。群作用下的商空间——例如$\R^n/\Z^n$和$S^n/\set{\pm1}$这样的轨道空间——在几何中处于核心地位，并把拓扑学与[[abstract-algebra/group-actions]]一章联系起来。

::: summary
- $T_1$：单点集是闭集；豪斯多夫：不同的点有不相交的邻域；正则空间和正规空间能分离点与闭集。度量空间满足所有这些条件；无限集上的余有限拓扑是$T_1$的，但不是豪斯多夫的。
- 在豪斯多夫空间中，序列的极限是唯一的；豪斯多夫空间的子空间和积空间仍是豪斯多夫空间；$X$是豪斯多夫空间当且仅当对角线在$X\times X$中是闭集。
- 在$X/{\sim}$的商拓扑中，$U$是开集当且仅当$q^{-1}(U)$是开集；商空间的开集与$X$的饱和开集一一对应。
- 泛性质：$g\colon X/{\sim}\to Z$连续当且仅当$g\circ q$连续；在各等价类上取常值的连续映射可以下降为商空间上的映射。
- 从紧空间到豪斯多夫空间上的连续满射把按“像相同”得到的商空间与目标空间等同起来（[[#thm-recognise]]）：$[0,1]/\set{0,1}\cong S^1$，$D^2/S^1\cong S^2$，正方形$/aba^{-1}b^{-1}\cong S^1\times S^1$。
- 默比乌斯带、克莱因瓶和射影平面都是正方形的商空间；商空间可能不是豪斯多夫空间（有两个原点的直线），甚至可能具有平凡拓扑（$\R/\Q$）。
:::

## 习题

::: exercise 再谈谢尔宾斯基空间 {level=1}
证明谢尔宾斯基空间不是$T_1$空间，并且每个有限$T_1$空间都是离散空间。由此推出每个有限豪斯多夫空间都是离散空间。
::: solution
在谢尔宾斯基空间中，单点集$\set0$是闭集（它的补集$\set1$是开集），但$\set1$不是闭集，因为它的补集$\set0$不是开集。所以并非每个单点集都是闭集，由[[#prop-t1]]，该空间不是$T_1$空间。在有限$T_1$空间中，每个子集都是有限个闭的单点集的并，因而是闭集；所以每个子集也都是开集（它的补集是闭集）：拓扑是离散的。有限豪斯多夫空间是$T_1$空间，因此由同样的论证，它是离散的。
:::
:::

::: exercise 正方形的顶点 {level=1 check="4"}
在把正方形粘合成环面的等同中，正方形上有多少个点与顶点$(0, 0)$等同（包括该顶点本身）？
::: solution
$(0,0)\sim(1,0)$（左右粘合），$(0,0)\sim(0,1)$（上下粘合），因此还有$\sim(1,1)$：全部$4$个顶点变成环面上的同一个点。作为比较，一条边的中点（例如$(\frac12, 0)$）只与$(\frac12, 1)$等同——构成含$2$个点的等价类——而内部的点各自构成只含$1$个点的等价类。
:::
:::

::: exercise 把直线对折 {level=1}
在$\R$上，当$y = \pm x$时规定$x\sim y$。证明$\R/{\sim}$同胚于$[0, \infty)$。
::: solution
$f(x) = \abs x$是一个连续满射$\R\to[0,\infty)$，它恰好把$x$与$-x$等同起来，所以由[[#thm-quotient-universal]]，它诱导出一个连续双射$\bar f\colon\R/{\sim}\to[0,\infty)$。它的逆映射是$g(t) = q(t)$（$t\ge0$），即包含映射$[0,\infty)\to\R$与$q$的复合，它是连续的。所以$\bar f$是同胚。（[[#thm-recognise]]不能直接应用，因为$\R$不是紧的；而这里的逆映射很容易写出来。）
:::
:::

::: exercise 两个连续映射相等的点集 {level=2}
设$f, g\colon X\to Y$连续，且$Y$是豪斯多夫空间。证明$E = \set{x : f(x) = g(x)}$是闭集。由此推出：若$f$与$g$在$X$的一个稠密子集上相等，则$f = g$。说明豪斯多夫假设是必需的。
::: solution
$E$是对角线$\Delta\subseteq Y\times Y$在连续映射$x\mapsto(f(x), g(x))$下的原像，而由[[#thm-hausdorff-products]]，$\Delta$是闭集；所以$E$是闭集。若$E$包含一个稠密集$D$，则$E\supseteq\overline D = X$。没有豪斯多夫性质时的反例：设$Y = \set{0,1}$赋予平凡拓扑，$X = \R$，$f\equiv0$，$g$是$\R\setminus\Q$的示性函数。两者都是连续的（映入平凡拓扑空间的每个映射都连续），它们在稠密集$\Q$上相等，但$f\neq g$。
:::
:::

::: exercise 圆周作为直线的商空间 {level=2}
在$\R$上，当$x - y\in\Z$时规定$x\sim y$。证明$\R/\Z\cong S^1$。
::: solution
$p(t) = (\cos2\pi t, \sin2\pi t)$连续且在各等价类上取常值，所以它诱导出一个连续映射$\bar p\colon\R/\Z\to S^1$；它是双射，因为$p(t) = p(t')$当且仅当$t - t'\in\Z$。商空间$\R/\Z$是紧的：每个等价类在$[0, 1]$中都有代表元，所以$\R/\Z = q([0,1])$是紧集的连续像。$S^1$是豪斯多夫空间。由[[topology/compactness#thm-compact-hausdorff]]，$\bar p$是同胚。
:::
:::

::: exercise 锥是圆盘 {level=2}
空间$X$上的**锥**是$CX = (X\times[0,1])/(X\times\set1)$。证明$S^1$上的锥同胚于闭圆盘$D^2$。
::: solution
定义$f\colon S^1\times[0,1]\to D^2$为$f(z, t) = (1 - t)z$。它是连续的满射（每个$w\neq0$都等于$f(w/\norm w, 1 - \norm w)$，并且$0 = f(z, 1)$），而且$f(z, t) = f(z', t')$当且仅当$(z,t) = (z',t')$或$t = t' = 1$——这恰好是定义锥的等同关系。$S^1\times[0,1]$是紧的，$D^2$是豪斯多夫空间，所以由[[#thm-recognise]]得$CS^1\cong D^2$。
:::
:::

::: exercise 把闭集捏成一点 {level=3}
设$X$是紧豪斯多夫空间，$A\subseteq X$是非空闭子集。证明$X/A$是豪斯多夫空间。
::: hint
需要分离两类点对：两个不在$A$中的点；以及一个不在$A$中的点与点$[A]$。利用[[topology/compactness]]一章中关于分离紧集的习题。
:::
::: solution
$X/A$的开集对应于$X$中那些或者包含$A$、或者与$A$不相交的开集（这些就是饱和开集）。**两个点$x, y\notin A$。**在$X$中取不相交的开集$U\ni x$、$V\ni y$。则$U\setminus A$和$V\setminus A$是开集（因为$A$是闭集），它们互不相交，且都与$A$不相交，因而是饱和的；它们的像就是$[x]$与$[y]$的不相交的开邻域。**一个点$x\notin A$与点$[A]$。**集合$\set x$与$A$不相交且都是紧的（$A$是紧空间中的闭集），所以存在不相交的开集$U\ni x$和$V\supseteq A$（豪斯多夫空间中紧集的分离，见[[topology/compactness]]一章的习题）。$U$与$V\supseteq A$不相交，所以是饱和的；$V$包含$A$，所以也是饱和的。它们的像把$[x]$与$[A]$分离开。
:::
:::

::: exercise 射影平面的两种描述 {#exr-rp2 level=3}
证明：把对径点等同起来的球面$S^2$，同胚于把边界上的对径点等同起来的闭圆盘$D^2$。
::: solution
设$D' = D^2/{\sim}$，其中对$\norm x = 1$令$x\sim-x$，并设$q\colon D^2\to D'$为商映射。定义$h\colon D^2\to S^2/\set{\pm1}$为$h(x) = \big[\big(x, \sqrt{1 - \norm x^2}\big)\big]$：把$x$提升到闭北半球面上，再取它所在的对径点类。$h$是连续的（它是连续映射的复合），并且是满射，因为每一对对径点中都有一个点满足$x_3\ge0$。$D^2$中的两点$x\neq x'$有相同的像，当且仅当它们的提升互为对径点；由于两个提升都满足$x_3\ge0$，这当且仅当两者都有$x_3 = 0$，即$\norm x = \norm{x'} = 1$，并且$x' = -x$。所以$h$恰好把$D'$中被等同的点等同起来，从而诱导出一个连续双射$\bar h\colon D'\to S^2/\set{\pm1}$。定义域$D'$是紧的。目标空间是豪斯多夫空间：两个不同的类$\set{\pm u}$、$\set{\pm v}$可以由小球$B(\pm u, r)\cap S^2$和$B(\pm v, r)\cap S^2$的像分离开，其中$r$小于集合$\set{\pm u}$与$\set{\pm v}$之间距离的一半——这两个并集是饱和的、开的，并且互不相交。由[[topology/compactness#thm-compact-hausdorff]]，$\bar h$是同胚。
:::
