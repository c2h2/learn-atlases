介值定理为什么成立？如果$[a, b]$上的连续函数在$a$处为负、在$b$处为正，那么它必定在两者之间的某处取零值——因为区间是“连成一片的”，连续函数不可能在定义域中不留空隙的情况下跳过$0$。同样的函数如果定义在$[0,1]\cup[2,3]$上，完全可以在第一段上取$-1$、在第二段上取$+1$。这个定理的真正内容是定义域的性质，而不是函数的性质：区间不能被拆分成两个彼此分离的部分。

这一性质称为**连通性**。本章对任意拓扑空间定义连通性，证明$\R$的连通子集恰好是区间，并证明连通性在连续映射下保持——由此得到一般而透彻的介值定理。接着我们介绍更直观的**道路连通性**，通过一个著名的例子看到这两个概念并不相同，并把空间分解为**连通分支**。最后，我们把连通性用作拓扑不变量：例如，它能证明直线与平面不同胚，以及字母X、Y、O中任意两个都不同胚。

## 连通空间

::: definition 连通空间 {#def-connected}
拓扑空间$X$的一个**分割**是指一对不相交的非空开子集$U, V$，满足$X = U\cup V$。若$X$没有分割，则称$X$是**连通的**。若空间的一个子集在子空间拓扑下是连通的，就称这个子集是连通的。
:::

若$U, V$是一个分割，则$U = X\setminus V$也是闭集。所以$X$连通当且仅当它仅有的**开闭**（既开又闭的）子集是$\emptyset$和$X$。第三种表述在证明中往往最为方便。

::: proposition 连通性的三种形式 {#prop-connected}
对拓扑空间$X$，下列条件等价：

1. $X$连通；
2. $X$中既开又闭的子集只有$\emptyset$和$X$；
3. 每个连续映射$f\colon X\to\set{0, 1}$都是常值映射，其中$\set{0,1}$带离散拓扑。
:::

::: proof
(1) ⇔ (2)：分割$U, V$给出开闭集$U\neq\emptyset, X$；反之，开闭集$U\neq\emptyset, X$给出分割$U, X\setminus U$。(2) ⇔ (3)：连续映射$f\colon X\to\set{0,1}$给出开闭集$f^{-1}(\set1)$，它是$\emptyset$或$X$当且仅当$f$是常值映射；反之，开闭集$U$给出$U$的连续示性函数，当$U\neq\emptyset, X$时它不是常值的。
:::

下面这个观察几乎在每个关于连通集的证明中都会用到。

::: lemma 连通子集只落在一侧 {#lem-one-side}
设$U, V$是$X$的不相交的开子集，$A\subseteq U\cup V$是连通的。则$A\subseteq U$或$A\subseteq V$。
:::

::: proof
$A\cap U$与$A\cap V$不相交，在$A$中都是开集，并且覆盖$A$。由于$A$连通，其中之一是空集。
:::

::: example 连通空间与不连通空间 {#ex-connected-examples}
判断下列空间中哪些是连通的：(a) 平凡拓扑空间；(b) 至少含两个点的离散空间；(c) $\Q\subseteq\R$；(d) 带余有限拓扑的无限集；(e) 索根弗里直线$\R_\ell$。
::: solution
(a) 连通：仅有的开集是$\emptyset$和$X$，所以不存在分割。(b) 不连通：$\set x$与$X\setminus\set x$构成一个分割。(c) 不连通，而且是极度不连通。对任意两个有理数$p < q$，在它们之间取一个无理数$r$；则$(-\infty, r)\cap\Q$与$(r,\infty)\cap\Q$把$\Q$分割开，并且$p$和$q$分别落在两侧。所以$\Q$的连通子集只有单点集：$\Q$是**完全不连通的**。(d) 连通：两个非空开集的补集都有限，所以它们相交（它们的交在无限集中的补集有限），因而不存在两个不相交的非空开集。(e) 不连通：在$\R_\ell$中，$[0,\infty)$是开集（它是各$[0, n)$的并），也是闭集（它的补集$(-\infty, 0) = \bigcup[-n, 0)$是开集）。
:::
:::

最基本的例子是实直线。回忆一下：如果只要$a, b\in I$且$a < c < b$，就有$c\in I$，则称子集$I\subseteq\R$为**区间**。

::: theorem 直线的连通子集 {#thm-intervals}
$\R$的子集是连通的，当且仅当它是区间。特别地，$\R$本身是连通的。
:::

::: proof
**连通集是区间。**若$A\subseteq\R$不是区间，则存在$a, b\in A$和$c\notin A$，使得$a < c < b$。于是$A\cap(-\infty, c)$与$A\cap(c, \infty)$不相交，在$A$中都是开集，覆盖$A$，并且都非空（分别含有$a$和$b$）：这是一个分割。

**区间是连通的。**假设区间$I$有一个分割$I = U\cup V$，其中$U, V$在$I$中是开集，不相交且非空。取$a\in U$，$b\in V$，不妨设$a < b$（否则交换两者的名称）。则$[a, b]\subseteq I$。令

$$
s = \sup\big(U\cap[a, b]\big),
$$

它是存在的，因为这个集合含有$a$且以$b$为上界；并且$s\in[a, b]\subseteq I$，所以$s$属于$U$或属于$V$。

若$s\in U$：则$s\neq b$（因为$b\in V$），所以$s < b$。由于$U$在$I$中是开集且$[a,b]\subseteq I$，存在$\delta > 0$，使得$[s, s + \delta)\subseteq U$且$s + \delta\le b$。于是存在$U\cap[a,b]$中大于$s$的点，与$s$的定义矛盾。

若$s\in V$：则$s\neq a$，所以$s > a$。由于$V$在$I$中是开集，存在$\delta > 0$，使得$(s - \delta, s]\subseteq V$且$s - \delta\ge a$。这些点都不属于$U$，所以$U\cap[a,b]$的每个元素都不超过$s - \delta$，从而$s$不是上确界——又得到矛盾。

所以不存在分割，$I$是连通的。
:::

这个证明本质地用到了$\R$的确界原理，而且也必须如此：在不具备这一性质的$\Q$中，“区间”是不连通的。

::: quiz
下列$\R$的子集中哪些是连通的？（可能有多个正确选项。）
- [x] $[0, 1)$
- [ ] $[0,1]\cup[2, 3]$
- [x] $\set{5}$
- [ ] $\R\setminus\set0$
- [x] $(0, \infty)$
::: solution
由[[#thm-intervals]]，$\R$的连通子集就是区间：$[0, 1)$、单点集$\set5$（退化的区间）和$(0,\infty)$。并集$[0,1]\cup[2,3]$与$\R\setminus\set0$都不是区间（它们分别缺少$1.5$和$0$），所以它们不连通。
:::
:::

## 连续像与介值定理

::: theorem 连通空间的连续像 {#thm-image}
若$X$连通，$f\colon X\to Y$连续，则$f(X)$连通。
:::

::: proof
设$g\colon f(X)\to\set{0,1}$连续。则$g\circ f\colon X\to\set{0,1}$连续（由[[topology/continuous-maps#thm-subspace]]，可把$f$看作映到子空间$f(X)$的映射），所以由[[#prop-connected]]，它是常值映射。由于$f\colon X\to f(X)$是满射，$g$是常值映射。再由[[#prop-connected]]，$f(X)$连通。
:::

特别地，连通性是拓扑性质：与连通空间同胚的空间是连通的。

::: corollary 介值定理 {#cor-ivt}
设$X$连通，$f\colon X\to\R$连续。若$f$取到值$a$和$b$，其中$a < b$，则它取到每个值$c\in(a, b)$。
:::

::: proof
由[[#thm-image]]，$f(X)$是$\R$的连通子集，因而由[[#thm-intervals]]，它是区间；它含有$a$和$b$，所以含有$c$。
:::

取$X = [a, b]$，这就是[[calculus-1/continuity]]一章中的介值定理；但现在它对圆盘、球面、环面或任何连通空间上的函数都同样成立。

::: example 不动点与对径点 {#ex-ivt-applications}
(a) 证明每个连续映射$f\colon[0, 1]\to[0,1]$都有**不动点**，即满足$f(x) = x$的点。(b) 证明在任一时刻，赤道上都有位于直径两端、温度完全相同的两个点（假设温度连续变化）。
::: solution
(a) 令$g(x) = f(x) - x$，它在连通空间$[0,1]$上连续。由于$0\le f(x)\le1$，有$g(0) = f(0)\ge0$，$g(1) = f(1) - 1\le0$。若其中有一个为$0$，我们就得到了不动点；否则$g(0) > 0 > g(1)$，由[[#cor-ivt]]，存在$x$使得$g(x) = 0$。

(b) 用角度$\theta$参数化赤道，设$T(\theta)$为温度，它是以$2\pi$为周期的连续函数，因而是圆周$S^1$上的连续函数。令$g(\theta) = T(\theta) - T(\theta + \pi)$，它在连通空间$S^1$（$[0, 2\pi]$的连续像）上连续。于是$g(\theta + \pi) = T(\theta + \pi) - T(\theta + 2\pi) = -g(\theta)$。所以$g$取到值$g(0)$和$-g(0)$，这两个值异号或同为零；由[[#cor-ivt]]，$g$在某点$\theta_0$处为零，即$T(\theta_0) = T(\theta_0 + \pi)$。这是博苏克-乌拉姆（Borsuk–Ulam）定理的一维情形；二维情形（地球表面上有两个对径点，温度相同**并且**气压也相同）需要用到基本群（[[topology/fundamental-group]]），用它给出的证明见Hatcher的《代数拓扑》（*Algebraic Topology*）定理1.10。
:::
:::

## 构造连通空间

::: theorem 并、闭包与乘积 {#thm-building}
1. 若$\set{A_\alpha}$是$X$的一族有公共点的连通子集，则$\bigcup_\alpha A_\alpha$连通。
2. 若$A\subseteq X$连通，且$A\subseteq B\subseteq\overline A$，则$B$连通；特别地，$\overline A$连通。
3. 若$X$和$Y$都连通，则$X\times Y$也连通。
:::

::: proof
(1) 设$p$是一个公共点，$f\colon\bigcup A_\alpha\to\set{0,1}$连续。它在每个$A_\alpha$上的限制都是常值的，并且由于$p\in A_\alpha$，这个常值等于$f(p)$。所以$f$是常值映射，由[[#prop-connected]]，这个并是连通的。

(2) 设$f\colon B\to\set{0,1}$连续。它在连通集$A$上是常值的，不妨设等于$0$。集合$f^{-1}(\set0)$在$B$中是闭集且包含$A$，所以它包含$\overline A\cap B = B$（$A$在子空间$B$中的闭包是$\overline A\cap B$）。所以在$B$上$f\equiv0$。

(3) 固定$(x_0, y_0)\in X\times Y$。对每个$x\in X$，由(1)，“十字形”$C_x = (\set x\times Y)\cup(X\times\set{y_0})$是连通的：$\set x\times Y\cong Y$与$X\times\set{y_0}\cong X$都连通（同胚分别为$y\mapsto(x, y)$和$x\mapsto(x, y_0)$，由[[topology/continuous-maps#thm-product]]它们连续，而它们的逆就是投影，也连续），并且它们有公共点$(x, y_0)$。所有的十字形都含有$(x_0, y_0)$，它们的并是$X\times Y$，所以再由(1)，$X\times Y$连通。
:::

由(3)和归纳法，$\R^n$连通；由[[#thm-image]]，圆周$S^1$（$[0, 2\pi]$的像）、环面$S^1\times S^1$以及每个$n\ge1$的球面$S^n$都是连通的（关于球面，见下面的[[#ex-path-connected]]）。

## 道路连通性

“连成一片”的直观含义是：任意两点都可以用一条曲线连接起来。这是一个不同的、更强的概念。

::: definition 道路连通空间 {#def-path-connected}
$X$中从$x$到$y$的一条**道路**是指满足$\gamma(0) = x$和$\gamma(1) = y$的连续映射$\gamma\colon[0, 1]\to X$。若$X$中任意两点都可以用道路连接，则称空间$X$是**道路连通的**。
:::

::: theorem 道路连通空间是连通的 {#thm-path-connected}
每个道路连通空间都是连通的。
:::

::: proof
设$X$道路连通，固定$x_0\in X$。对每个$x\in X$，取一条从$x_0$到$x$的道路$\gamma_x$。由[[#thm-intervals]]和[[#thm-image]]，它的像$\gamma_x([0,1])$连通，并且含有$x_0$和$x$。所有这些像的并是$X$，而它们有公共点$x_0$，所以由[[#thm-building]](1)，$X$连通。
:::

::: example 道路连通空间 {#ex-path-connected}
证明：(a) $\R^n$的每个凸子集都是道路连通的；(b) 当$n\ge2$时，$\R^n\setminus\set0$是道路连通的；(c) 当$n\ge1$时，球面$S^n = \set{x\in\R^{n+1} : \norm x = 1}$是道路连通的。
::: solution
(a) 若$C$是凸集，$x, y\in C$，则直线道路$\gamma(t) = (1 - t)x + ty$始终位于$C$中。

(b) 设$x, y\neq0$。若从$x$到$y$的线段不经过$0$，就用这条线段。否则对某个$\lambda > 0$有$y = -\lambda x$；由于$n\ge2$，存在一个不在过$x$的直线上的点$z\neq0$（例如一个与$x$不平行的向量），而从$x$到$z$以及从$z$到$y$的线段都不经过$0$。把它们连接起来（利用粘接引理，[[topology/continuous-maps#lem-pasting]]）就得到一条道路。

(c) 映射$r(x) = x/\norm x$是从$\R^{n+1}\setminus\set0$到$S^n$上的连续满射，而由于$n + 1\ge2$，由(b)知$\R^{n+1}\setminus\set0$是道路连通的；道路在连续映射下的像仍是道路，所以$S^n$是道路连通的。
:::
:::

对于欧几里得空间的开子集，这两个概念是一致的。

::: proposition 连通开集是道路连通的 {#prop-open-path}
$\R^n$的每个连通开子集$U$都是道路连通的。
:::

::: proof
若$U = \emptyset$，则无需证明。否则固定$x_0\in U$，设$P$是$U$中能用$U$内的道路与$x_0$连接的点的集合；$x_0 \in P$。**$P$是开集：**若$x\in P$，取球$B(x, r)\subseteq U$；球中每一点都可以用球内的一条线段与$x$连接，先沿一条从$x_0$到$x$的道路走、再沿这条线段走，就把该点与$x_0$连接起来了。**$U\setminus P$是开集：**若$y\in U\setminus P$且$B(y, r)\subseteq U$，则$B(y, r)$中没有点属于$P$，否则就可以经由那个点到达$y$。由于$U$连通且$P\neq\emptyset$，有$P = U$。
:::

没有开集的条件，连通性并不蕴涵道路连通性。下面这个标准的反例值得仔细研究。

::: example 拓扑学家的正弦曲线 {#ex-sine-curve}
设$G = \set{(x, \sin(1/x)) : 0 < x\le1}$，$S = G\cup\big(\set0\times[-1, 1]\big)$。证明$S$连通但不道路连通。
::: solution
**连通。**$G$是连通区间$(0, 1]$在连续映射$x\mapsto(x, \sin(1/x))$下的像，所以是连通的。每个满足$\abs y\le1$的点$(0, y)$都是$G$中点的极限：取$x_n\to0^+$使$\sin(1/x_n) = y$（例如$1/x_n = \arcsin y + 2\pi n$）。所以$G\subseteq S\subseteq\overline G$，由[[#thm-building]](2)，$S$连通。

**不道路连通。**假设$\gamma = (\gamma_1, \gamma_2)\colon[0, 1]\to S$是从线段上某点$(0, y_0)$到$G$中某点的道路。集合$\set{t : \gamma_1(t) = 0}$是闭集且含有$0$；设$t_0$是它的最大元。则$t_0 < 1$，$\gamma_1(t_0) = 0$，且当$t > t_0$时$\gamma_1(t) > 0$。由连续性，存在$\delta > 0$，使得当$t_0\le t\le t_0 + \delta$时$\abs{\gamma_2(t) - \gamma_2(t_0)} < \frac12$。现在$\gamma_1([t_0, t_0 + \delta])$是一个区间（由连通性），它含有$0 = \gamma_1(t_0)$和$c = \gamma_1(t_0 + \delta) > 0$，所以包含$[0, c]$。对所有充分大的$n$，这个区间都含有点$x = \frac{1}{\pi/2 + 2\pi n}$和$x' = \frac{1}{3\pi/2 + 2\pi n}$，在这些点处$\sin(1/x) = 1$，$\sin(1/x') = -1$。由于$S$中第一个坐标为正的点都在$G$上，$\gamma_2$在$[t_0, t_0 + \delta]$上既取到$1$又取到$-1$，这是不可能的，因为它在那里的所有值与$\gamma_2(t_0)$的距离都小于$\frac12$。因此没有道路把线段上的点与$G$中的点连接起来。
:::
:::

::: warning 连通并不意味着道路连通
许多论证默默地假定连通空间是道路连通的，例如“在集合内用一条道路连接这两点”。这对$\R^n$的开子集（[[#prop-open-path]]）以及大多数由良好的部分拼成的空间是成立的，但对拓扑学家的正弦曲线就不成立。拿不准时，要么直接证明道路连通性——它是更强的性质——要么用分割来论证。
:::

## 连通分支

每个空间都可以分解为若干极大的连通部分。

::: definition 连通分支 {#def-components}
对$x, y\in X$，若$X$的某个连通子集同时含有$x$和$y$，就记$x\sim y$。这是一个等价关系，它的等价类称为$X$的**连通分支**（简称分支）。把“连通子集”换成“道路”，就得到**道路连通分支**。
:::

$\sim$的自反性和对称性是显然的（单点集是连通的），传递性则由[[#thm-building]](1)得到：若$A\ni x, y$和$B\ni y, z$都连通，则$A\cup B$也连通。含有$x$的连通分支$C$是所有含有$x$的连通集的并，所以它是连通的（仍由[[#thm-building]](1)），并且是含有$x$的最大连通集；它是闭集，因为$\overline C$连通且含有$x$，所以$\overline C\subseteq C$。连通分支未必是开集：$\Q$的连通分支是它的单点集，而其中没有一个在$\Q$中是开集。

道路连通分支包含在连通分支之中（由[[#thm-path-connected]]），并且可能更小：拓扑学家的正弦曲线只有一个连通分支，却有两个道路连通分支，即$G$和那条线段。

## 区分空间

连通性和连通分支都是拓扑不变量，去掉一个点后空间的连通分支也是如此。同胚$h\colon X\to Y$限制为同胚$X\setminus\set x\to Y\setminus\set{h(x)}$，所以**$X\setminus\set x$的连通分支个数（作为$x$的函数）在同胚下保持不变**。若连通空间$X$中的点$x$使$X\setminus\set x$不连通，则称$x$为**割点**。

::: theorem 直线不是平面 {#thm-line-plane}
对任何$n\ge2$，$\R$都不同胚于$\R^n$。类似地，$(0, 1)$、$[0, 1)$、$[0,1]$和$S^1$中任意两个都不同胚。
:::

::: proof
假设$h\colon\R\to\R^n$是同胚。则$\R\setminus\set0$同胚于$\R^n\setminus\set{h(0)}$。前者不连通（它不是区间），后者道路连通，因而连通（[[#ex-path-connected]](b)，经平移）。这与[[#thm-image]]矛盾。

对于第二个结论，数一数非割点：在$(0, 1)$中每一点都是割点；在$[0, 1)$中恰有一个点（$0$）不是割点；在$[0, 1]$中恰有两个点（$0$和$1$）不是割点；而从$S^1$中去掉任何一点后得到的空间都同胚于$\R$（[[topology/continuous-maps#ex-homeo]]），它是连通的，所以$S^1$根本没有割点。同胚把割点映成割点，把非割点映成非割点，所以对于同胚的空间，这四个数目（$0$、$1$、$2$和“每一点”）必须相同。
:::

::: example 字母表中的字母 {#ex-letters}
把大写字母X、Y、T、O和L看作平面的子空间，它们由宽度为零的直笔画和弧线画成。其中哪些是同胚的？
::: solution
对每一点，数一数去掉它之后剩下的连通分支个数。在**X**中，去掉交叉点后剩下$4$个连通分支；Y、T、O或L中没有一个点有这种性质。在**Y**和**T**中，去掉交汇点后剩下$3$个连通分支；事实上Y和T是同胚的（把T的两臂弯折即可）。在**O**（一个圆周）中，去掉任何一点后都剩下$1$个连通分支。在**L**（一条折线段，同胚于$[0, 1]$）中，去掉一个内点后剩下$2$个连通分支，去掉一个端点后剩下$1$个。由于这些计数在同胚下保持不变，同胚类为$\set{X}$、$\set{Y, T}$、$\set{O}$和$\set{L}$；特别地，O与L不同胚，因为L有割点而O没有。
:::
:::

::: quiz
字母X去掉交叉点后有几个连通分支？这证明了什么？
- [ ] $2$；这证明X不连通
- [x] $4$；Y中没有点具有这一性质，所以X与Y不同胚
- [ ] $4$；这证明X同胚于$\R^2$中两条相交的直线，而后者不连通
- [ ] $3$；因此X与Y同胚
::: solution
去掉X的中心后，剩下四条互不相交的开臂，每条都是一个区间：$4$个连通分支。从Y中去掉任何一点后，剩下$1$个、$2$个或$3$个连通分支。同胚$X\to Y$会把X的中心映到Y中这样一个点：去掉它后剩下$4$个连通分支——而这样的点并不存在。（X本身是连通的，因为它是两条有公共点的线段之并。）
:::
:::

::: remark 若尔当曲线定理
关于连通分支，一个深刻得多的事实是**若尔当曲线定理**：若$C\subseteq\R^2$同胚于圆周，则$\R^2\setminus C$恰有两个连通分支，一个有界（内部），一个无界，并且$C$是其中每一个的边界。这听起来显而易见，但曲线可以是分形的、处处不光滑的，其证明需要代数拓扑的工具。在[[complex-analysis/residues]]一章中叙述留数定理时，我们用过它针对围道的一种形式。
:::

::: application 运动规划
对机器人来说，两个位形可以通过一个运动连接起来，当且仅当它们位于机器人的**自由**位形空间（避开障碍物的位形构成的空间）的同一个道路连通分支中。概率路线图之类的运动规划算法对这个空间进行采样，并构造一个图，用图的连通分支来近似空间的道路连通分支；如果起点和终点落在不同的分支中，那么无论控制器多么巧妙，都不存在这样的运动。对由不等式给出的空间计数并计算其连通分支，是计算拓扑学中的一项基本任务。
:::

::: history
伯纳德·波尔查诺（Bernard Bolzano）在1817年证明了介值定理，这是最早用纯算术手段给出证明的分析学定理之一。格奥尔格·康托尔（Georg Cantor，1883）用步长任意小的链提出了点集连通的一种概念，它仅对紧集与现代的概念一致。今天所用的基于分割的定义，是由伦内斯（N. J. Lennes）在1911年、费利克斯·豪斯多夫（Felix Hausdorff）在他1914年的著作中给出的。20世纪20年代的波兰拓扑学家，特别是布罗尼斯瓦夫·克纳斯特（Bronisław Knaster）和卡齐米日·库拉托夫斯基（Kazimierz Kuratowski），探索了大量存在的奇特连通空间，拓扑学家的正弦曲线是其中最简单的一个。卡米尔·若尔当（Camille Jordan）在1887年叙述了他的曲线定理；第一个被公认为完整的证明是奥斯瓦尔德·维布伦（Oswald Veblen）在1905年给出的。
:::

## 后续内容

连通性是第一个也是最简单的拓扑不变量。它的伙伴——紧性——是[[topology/compactness]]一章的主题：正如连通性推广了介值定理，紧性推广了最值定理。道路连通分支是代数拓扑的起点：[[topology/fundamental-group]]一章中的基本群由道路构造而成，它不仅问两点能否连接，还问有多少种本质上不同的连接方式。割点只能区分一维的图形；要证明$\R^2\not\cong\R^3$，需要从两者中各去掉一个点，然后比较它们的基本群。

::: summary
- 若一个空间不能分割为两个不相交的非空开集，则它是连通的；等价地，除$\emptyset$和$X$之外没有开闭集，或者每个到$\set{0,1}$的连续映射都是常值映射。
- $\R$的连通子集恰好是区间（[[#thm-intervals]]）；证明用到了确界原理，而$\Q$是完全不连通的。
- 连通空间的连续像是连通的，由此得到任意连通空间上实函数的介值定理。
- 有公共点的连通集之并、连通集的闭包以及连通空间的乘积都是连通的。
- 道路连通空间是连通的；$\R^n$的连通开子集是道路连通的；拓扑学家的正弦曲线连通但不道路连通。
- 连通分支（极大连通子集）构成空间的一个划分，并且都是闭集；去掉点之后的连通分支个数可以区分$\R$与$\R^2$，以及$[0,1]$与$S^1$。
:::

## 习题

::: exercise 直线的一个子集的连通分支 {level=1 check="3"}
$A = \set{x\in\R : x^2\neq1}$有几个连通分支？描述它们。
::: solution
$A = \R\setminus\set{-1, 1} = (-\infty, -1)\cup(-1, 1)\cup(1, \infty)$。每一段都是区间，因而连通，并且每一段在$A$中都是开闭集（它在$A$中是开集，而它在$A$中的补集是另外两个开段的并）。所以每一段都是一个连通分支：共$3$个连通分支。
:::
:::

::: exercise 去掉X的中心 {level=1 check="4"}
设X是$\R^2$中从$(-1, -1)$到$(1, 1)$的线段与从$(-1, 1)$到$(1, -1)$的线段之并。X去掉原点后有几个连通分支？
::: solution
去掉原点后剩下四条半开线段（“臂”），每条都同胚于一个区间，因而连通。每条臂在X去掉原点后的空间中都是开集（它是该空间与一个开象限的交），并且它们互不相交，所以它们就是连通分支：共$4$个。
:::
:::

::: exercise 离散拓扑与余有限拓扑 {level=1}
证明离散空间连通当且仅当它至多有一个点。带余有限拓扑的$\R$是道路连通的吗？
::: hint
关于道路连通性，考虑由任意单射给出的道路$\gamma\colon[0,1]\to\R_{\text{cof}}$，例如$\gamma(t) = t$，问一问它是否连续。
:::
::: solution
在含有两个点$x\neq y$的离散空间中，$\set x$是开闭集，且既不是$\emptyset$也不是$X$；若至多只有一个点，则不存在分割。对于$\R$上的余有限拓扑：由[[#ex-connected-examples]](d)，它是连通的。它也是道路连通的：给定$x\neq y$，设$\gamma\colon[0,1]\to\R$是满足$\gamma(0) = x$，$\gamma(1) = y$的任意单射（例如$\gamma(t) = x + t(y - x)$）。余有限拓扑中的闭集是$\R$或有限集；有限集在单射下的原像是有限集，因而在$[0,1]$中是闭集。所以由[[topology/continuous-maps#thm-continuity]]，$\gamma$作为映到$\R_{\text{cof}}$的映射是连续的，从而这个空间是道路连通的。（出人意料的空间需要验证，而不能靠猜！）
:::
:::

::: exercise 圆周不是区间 {#exr-circle-interval level=2}
证明$S^1$不同胚于$\R$的任何子集。
::: solution
假设$h\colon S^1\to A\subseteq\R$是同胚。$A$连通，因而是区间；它含有不止一个点，所以含有一个内点$h(p)$，即一个既不是最大元也不是最小元的点。于是$A\setminus\set{h(p)}$不是区间，因而不连通，而$S^1\setminus\set p\cong\R$是连通的——矛盾。
:::
:::

::: exercise 一般线性群 {level=2}
证明由$n\times n$可逆实矩阵构成的群$GL_n(\R)$（看作$\R^{n^2}$的子空间）不连通。证明旋转群$SO(2)$是连通的。
::: solution
$\det\colon GL_n(\R)\to\R\setminus\set0$是连续的（它是矩阵元素的多项式），并且是满射（考虑$\diag(t, 1, \dots, 1)$）。如果$GL_n(\R)$连通，那么由[[#thm-image]]，它的像$\R\setminus\set0$也连通，而这是错误的。（事实上，$GL_n(\R)$恰有两个连通分支，由行列式的符号区分。）$SO(2)$由矩阵$\begin{pmatrix}\cos\theta & -\sin\theta\\ \sin\theta & \cos\theta\end{pmatrix}$组成，它是连通空间$\R$在一个连续映射下的像，所以是连通的。
:::
:::

::: exercise 粘合连通集 {level=2}
设$A, B\subseteq X$连通，且$A\cap\overline B\neq\emptyset$。证明$A\cup B$连通。并由此再次推出拓扑学家的正弦曲线是连通的。
::: solution
设$f\colon A\cup B\to\set{0,1}$连续。它在连通集$A$上是常值的，设等于$c$；在$B$上也是常值的，设等于$d$。集合$f^{-1}(d)$在$A\cup B$中是闭集且包含$B$，所以它包含$B$在子空间$A\cup B$中的闭包，即$\overline B\cap(A\cup B)$。取$p\in A\cap\overline B$；则$f(p) = d$，同时$f(p) = c$，所以$c = d$，$f$是常值映射。对于正弦曲线，取$A$为线段$\set0\times[-1,1]$，$B = G$；$A$的每一点都属于$\overline G$。
:::
:::

::: exercise 对径点的温度 {level=2}
设$f\colon S^1\to\R$连续。证明$f$不是单射。（换句话说，不存在从圆周到直线的连续单射。）
::: solution
对$T = f$（把$f$看作角度的函数）应用[[#ex-ivt-applications]](b)，可知存在点$\theta_0$使得$f(\theta_0) = f(\theta_0 + \pi)$，而这是圆周上两个不同的点。因此$f$不是单射。（另一种方法：[[#exr-circle-interval]]表明$S^1$不同胚于它的像；但由[[topology/compactness]]，从紧空间$S^1$到$\R$的连续单射是到其像上的同胚。）
:::
:::

::: exercise 穿孔平面是道路连通的 {level=3}
证明：对每个可数集$C\subseteq\R^2$，$\R^2\setminus C$都是道路连通的。
::: hint
给定$C$之外的两点$x\neq y$，考虑从$x$到$y$的不可数多条道路，每条都由经过$[x, y]$的垂直平分线上某点$z$的两条线段组成。
:::
::: solution
设$x, y\in\R^2\setminus C$，$x\neq y$，$L$是线段$[x, y]$的垂直平分线。对每个$z\in L$，设$\gamma_z$是沿两条线段$[x, z]$和$[z, y]$从$x$经$z$到$y$的道路。点$x$和$y$严格地位于$L$的两侧，所以$[x, z]\setminus\set z$位于含有$x$的开半平面$H_x$中，$[z, y]\setminus\set z$位于含有$y$的半平面$H_y$中；这条道路只在$z$处与$L$相交。当$z\neq z'$时，从$x$出发经过$z$的射线与经过$z'$的射线不同（从$x$出发的射线与直线$L$至多相交一次），所以$[x, z]\cap[x, z'] = \set x$；类似地，$[z, y]\cap[z', y] = \set y$。因此$\gamma_z\cap\gamma_{z'} = \set{x, y}$。$C$中的每一点都异于$x$和$y$，所以它至多位于一条道路$\gamma_z$上。由于$C$可数而$L$不可数，必有某条$\gamma_z$与$C$完全不相交，它就是$\R^2\setminus C$中从$x$到$y$的一条道路。
:::
:::

::: exercise 连通的度量空间很大 {level=3}
设$(X, d)$是至少含两个点的连通度量空间。证明$X$不可数。
::: solution
在$X$中取$x_0\neq x_1$，令$r = d(x_0, x_1) > 0$。函数$f(x) = d(x_0, x)$在$X$上连续（由三角不等式，$\abs{f(x) - f(y)}\le d(x, y)$）。由[[#thm-image]]和[[#thm-intervals]]，$f(X)$是区间；它含有$f(x_0) = 0$和$f(x_1) = r$，所以含有$[0, r]$，而后者不可数。可数集的像是可数的，所以$X$不可数。（特别地，每个含有不止一个点的可数度量空间都是不连通的，$\Q$也再一次是不连通的。）
:::
