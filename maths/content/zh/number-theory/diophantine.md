**不定方程**（又称**丢番图方程**）是要求其解为整数（有时为有理数）的多项式方程。丢番图方程这一名称是为了纪念亚历山大的丢番图（Diophantus），他的《算术》（*Arithmetica*）在公元3世纪前后汇集了这类问题；但这些问题的历史要古老得多——约公元前1800年的一块巴比伦泥板就列出了与边长为整数的直角三角形有关的数。不定方程的难度往往出人意料。方程$x^n + y^n = z^n$看似平淡无奇，但证明它当$n \ge 3$时没有正整数解却花了358年。1900年，戴维·希尔伯特（David Hilbert）在他著名的问题中，以第十个问题提出：求一个一般方法，用来判定任意给定的不定方程是否有解；1970年，尤里·马季亚谢维奇（Yuri Matiyasevich）在马丁·戴维斯（Martin Davis）、希拉里·普特南（Hilary Putnam）和朱莉娅·罗宾逊（Julia Robinson）工作的基础上证明了：**这样的方法不可能存在**。

因此不存在一般的理论，每一类方程都需要自己的想法。本章将完全解决四类最重要的经典方程，每一类都有一种特有的技巧：**一次方程**（裴蜀等式）、**勾股数组**（唯一分解）、**两平方和**（二次剩余与鸽巢原理），以及**佩尔方程**（形如$x + y\sqrt d$的数的算术）。在此过程中，我们将遇到费马的**无穷递降法**，并证明费马大定理中$n = 4$的情形。

## 一次不定方程

方程$ax + by = c$有整数解当且仅当$\gcd(a, b) \mid c$（[[number-theory/divisibility#cor-bezout]]）。现在我们求出它的全部解。

::: theorem 一次不定方程 {#thm-linear-diophantine}
设$a, b$是不全为零的整数，$d = \gcd(a, b)$，并设$d \mid c$。若$(x_0, y_0)$是$ax + by = c$的一个解，则全部整数解为

$$
x = x_0 + \frac bd\,t, \qquad y = y_0 - \frac ad\,t \qquad (t \in \Z).
$$
:::

::: proof
这些都是解：$a\left(x_0 + \frac bdt\right) + b\left(y_0 - \frac adt\right) = ax_0 + by_0 + \frac{ab}{d}t - \frac{ab}dt = c$。反之，设$(x, y)$是任意一个解。减去$ax_0 + by_0 = c$得$a(x - x_0) = -b(y - y_0)$，再除以$d$，得

$$
\frac ad(x - x_0) = -\frac bd(y - y_0).
$$

由于$\gcd\!\left(\frac ad, \frac bd\right) = 1$，由[[number-theory/divisibility#thm-coprime-divides]]得$\frac bd \mid x - x_0$（若$b = 0$，结论是显然的），设$x - x_0 = \frac bd t$。代回得$\frac ad\cdot\frac bdt = -\frac bd(y - y_0)$，所以$y - y_0 = -\frac ad t$（约去$\frac bd \ne 0$；若$b = 0$，则$a \neq 0$，$x$可以直接确定）。
:::

所以这些解位于一条直线上，以步长$\left(\frac bd, -\frac ad\right)$等距排列。

::: example 用欧几里得算法解一次方程 {#ex-linear-diophantine}
求$1071x + 462y = 105$的全部整数解。
::: solution
由[[number-theory/divisibility#ex-gcd]]，$\gcd(1071, 462) = 21$，且$21 = 7\cdot 462 - 3\cdot 1071$。由于$105 = 5\cdot 21$，乘以$5$便得到特解$x_0 = -15$，$y_0 = 35$：确实$1071\cdot(-15) + 462\cdot 35 = -16065 + 16170 = 105$。由$\frac bd = \frac{462}{21} = 22$和$\frac ad = \frac{1071}{21} = 51$，全部解为

$$
x = -15 + 22t, \qquad y = 35 - 51t \qquad (t \in \Z).
$$
:::
:::

在应用中我们通常需要**非负**解；当$a, b > 0$时，非负解构成一个有限集。

::: example 鸡与鸭 {#ex-hens-ducks}
一位农民用恰好71英镑买鸡和鸭，鸡每只3英镑，鸭每只5英镑。有多少种买法？
::: solution
我们需要满足$x, y \ge 0$的$3x + 5y = 71$。一个解是$x = 2$，$y = 13$，所以通解为$x = 2 + 5t$，$y = 13 - 3t$。条件$x \ge 0$和$y \ge 0$意味着$t \ge 0$且$t \le 4$。所以共有五种可能：

$$
(x, y) = (2, 13),\ (7, 10),\ (12, 7),\ (17, 4),\ (22, 1) .
$$
:::
:::

用面值分别为$a$和$b$（二者互素）的两种硬币，究竟能支付哪些金额？小的金额可能无法支付，但每个足够大的金额都能支付。

::: theorem 两种硬币问题 {#thm-coin}
设$a, b$是互素的正整数。每个整数$n > ab - a - b$都可以写成$n = ax + by$，其中$x, y \ge 0$是整数，但$ab - a - b$不能。
:::

::: proof
给定$n$，选取满足$0 \le x \le b - 1$且$ax \equiv n \pmod b$的$x$（由于$a$模$b$可逆，这是可能的）。则$y = (n - ax)/b$是整数，且$n = ax + by$；此外，由[[#thm-linear-diophantine]]，每个解的$x$坐标模$b$都与这个解的相同，所以只要有某个解满足$x, y \ge 0$，这个解就满足（它的$x$是最小的非负值，因而$y$最大）。若$n > ab - a - b$，则$n - ax \ge n - a(b - 1) > -b$，所以$y > -1$，即$y \ge 0$。

现在假设$ab - a - b = ax + by$，其中$x, y \ge 0$。则$a(x + 1) + b(y + 1) = ab$，所以$b \mid a(x + 1)$，从而$b \mid x + 1$；类似地，$a \mid y + 1$。所以$x + 1 \ge b$，$y + 1 \ge a$，于是$ab = a(x+1) + b(y+1) \ge 2ab$，矛盾。
:::

用面值为$5$和$8$的硬币，无法支付的最大金额是$40 - 5 - 8 = 27$；无法支付的金额为$1, 2, 3, 4, 6, 7, 9, 11, 12, 14, 17, 19, 22, 27$，共$14 = \frac{(5-1)(8-1)}2$个；詹姆斯·约瑟夫·西尔维斯特（James Joseph Sylvester）在1884年证明了：一般地，恰有$\frac{(a-1)(b-1)}{2}$个金额无法支付。对于三种或更多种面值，无法支付的最大金额还没有已知的封闭形式公式。

::: quiz
$6x + 10y = 15$有整数解吗？
- [ ] 有，无穷多个
- [ ] 有，恰好一个
- [x] 没有
::: solution
$\gcd(6, 10) = 2$不整除$15$（左边总是偶数），所以无解。如果$c$能被$2$整除，就会有无穷多个解。
:::
:::

## 勾股数组

**勾股数组**是$x^2 + y^2 = z^2$的正整数解，例如$(3, 4, 5)$或$(5, 12, 13)$。把一个勾股数组乘以$k$就得到另一个，所以只需求出**本原**勾股数组，即满足$\gcd(x, y, z) = 1$的勾股数组。

::: theorem 本原勾股数组 {#thm-pythagorean}
$y$为偶数的本原勾股数组$(x, y, z)$恰好是

$$
x = m^2 - n^2, \qquad y = 2mn, \qquad z = m^2 + n^2,
$$

其中$m > n > 0$是一奇一偶的互素整数。不同的数对$(m, n)$给出不同的勾股数组。
:::

::: proof
**预备事实。**在本原勾股数组中，$x$与$y$互素：同时整除二者的素数会整除$z^2$，从而整除$z$。它们不同为偶数（因为互素），也不同为奇数，否则$z^2 = x^2 + y^2 \equiv 2 \pmod 4$，而它不是模$4$的平方（[[number-theory/divisibility#ex-squares-mod-4]]）。所以恰有一条直角边是偶数；记它为$y$。于是$x$和$z$都是奇数。

**每个本原勾股数组都具有这种形式。**写$y^2 = z^2 - x^2 = (z - x)(z + x)$。两个因子都是偶数；令$u = \frac{z+x}{2}$，$v = \frac{z-x}2$，它们是满足$\left(\frac y2\right)^2 = uv$的正整数。$u$与$v$的公因数整除$u + v = z$和$u - v = x$，所以$\gcd(u, v) = 1$。如果两个互素正整数之积是完全平方数，那么这两个因子都必须是完全平方数（比较素因数分解中的指数，[[number-theory/primes#thm-fta]]）。所以$u = m^2$，$v = n^2$，其中$m > n$是正整数，于是

$$
z = u + v = m^2 + n^2,\qquad x = u - v = m^2 - n^2, \qquad y = 2\sqrt{uv} = 2mn .
$$

此外，由于$\gcd(u, v) = 1$，所以$\gcd(m, n) = 1$；由于$z = m^2 + n^2$是奇数，所以$m, n$一奇一偶。

**反之**，这样的$m, n$给出一个勾股数组，因为$(m^2 - n^2)^2 + (2mn)^2 = m^4 + 2m^2n^2 + n^4 = (m^2 + n^2)^2$。它是本原的：同时整除$x$和$z$的素数$p$整除$z + x = 2m^2$和$z - x = 2n^2$；由于$z$是奇数，$p$是奇数，所以$p \mid m$且$p \mid n$，与$\gcd(m,n) = 1$矛盾。最后，$(m, n)$可以由勾股数组通过$m^2 = \frac{z+x}2$，$n^2 = \frac{z-x}2$还原出来。
:::

前几个本原勾股数组如下：

| $(m, n)$ | $(2,1)$ | $(3,2)$ | $(4,1)$ | $(4,3)$ | $(5,2)$ | $(5,4)$ | $(6,1)$ | $(6,5)$ |
|---|---|---|---|---|---|---|---|---|
| $(x, y, z)$ | $(3,4,5)$ | $(5,12,13)$ | $(15,8,17)$ | $(7,24,25)$ | $(21,20,29)$ | $(9,40,41)$ | $(35,12,37)$ | $(11,60,61)$ |

::: intuition 圆上的有理点
除以$z^2$后，一个勾股数组就是单位圆$X^2 + Y^2 = 1$上一个坐标为有理数的点$\left(\frac xz, \frac yz\right)$。过有理点$(-1, 0)$作斜率为$t$的直线：它与圆的另一个交点是

$$
\left(\frac{1 - t^2}{1 + t^2},\ \frac{2t}{1 + t^2}\right),
$$

它是有理点当且仅当$t$是有理数（若第二个交点是有理点，则它与$(-1, 0)$的连线的斜率也是有理数）。令$t = \frac nm$，就得到$\left(\frac{m^2-n^2}{m^2+n^2}, \frac{2mn}{m^2+n^2}\right)$——这正是从几何角度看到的[[#thm-pythagorean]]中的参数化。同样的“弦法”可以求出其他二次曲线上的有理点，而把它推广到三次曲线，就导向了椭圆曲线的理论。
:::

## 无穷递降法与费马大定理

1637年前后，皮埃尔·德·费马（Pierre de Fermat）在他那本丢番图著作的页边写道：当$n \ge 3$时，$x^n + y^n = z^n$没有正整数解；他还补充说，他有一个绝妙的证明，可惜页边太窄，写不下。他唯一留下证明的情形是$n = 4$，用的是他的**无穷递降法**：从任意一个解出发，构造出一个**更小**的解；由于正整数不能无限地减小下去，所以根本没有解。

::: theorem x⁴ + y⁴ = z²没有正整数解 {#thm-descent-4}
不存在满足$x^4 + y^4 = z^2$的正整数$x, y, z$。
:::

::: proof
假设存在解，取其中$z$最小的一个。

**第1步：$\gcd(x, y) = 1$。**若素数$p$同时整除$x$和$y$，则$p^4 \mid z^2$，所以$p^2 \mid z$，从而$\left(\frac xp, \frac yp, \frac z{p^2}\right)$会是一个$z$更小的解。

**第2步：一个勾股数组。**现在$(x^2)^2 + (y^2)^2 = z^2$，且$\gcd(x^2, y^2) = 1$，所以$(x^2, y^2, z)$是本原勾股数组。必要时交换$x$和$y$，可设$y^2$是偶数直角边，于是由[[#thm-pythagorean]]，

$$
x^2 = m^2 - n^2, \qquad y^2 = 2mn, \qquad z = m^2 + n^2,
$$

其中$m > n > 0$互素且一奇一偶。

**第3步：第二个勾股数组。**由$x^2 + n^2 = m^2$及$\gcd(m, n) = 1$，$(x, n, m)$也是本原勾股数组。由于$x$是奇数（$x^2 = m^2 - n^2$是奇数），偶数直角边是$n$，所以

$$
x = r^2 - s^2, \qquad n = 2rs, \qquad m = r^2 + s^2,
$$

其中$r > s > 0$互素。

**第4步：三个平方数。**现在$y^2 = 2mn = 4rs(r^2 + s^2)$，所以$\left(\frac y2\right)^2 = rs(r^2 + s^2)$。三个因子$r$、$s$、$r^2 + s^2$两两互素（同时整除$r$和$r^2 + s^2$的素数整除$s^2$，从而整除$s$）。如果两两互素的正整数之积是平方数，那么每个因子都是平方数，所以$r = u^2$，$s = v^2$，$r^2 + s^2 = w^2$，其中$u, v, w$是正整数。但这样一来，

$$
u^4 + v^4 = r^2 + s^2 = w^2,
$$

这是一个新的解，且$w \le w^2 = m \le m^2 < m^2 + n^2 = z$。这与$z$的最小性矛盾。
:::

::: corollary n = 4时的费马大定理 {#cor-flt-4}
不存在满足$x^4 + y^4 = z^4$的正整数。因此，只要$4 \mid n$，$x^n + y^n = z^n$就没有正整数解。
:::

::: proof
$x^4 + y^4 = z^4$的解会给出[[#thm-descent-4]]中方程的解$(x, y, z^2)$。若$n = 4k$，则$x^n + y^n = z^n$的解给出$(x^k)^4 + (y^k)^4 = (z^k)^4$。
:::

所以要证明费马大定理，只需处理指数为奇素数的情形。欧拉（Euler）基本上解决了$n = 3$的情形（1770年）；19世纪，索菲·热尔曼（Sophie Germain）、狄利克雷（Dirichlet）、勒让德（Legendre）、拉梅（Lamé）和库默尔（Kummer）处理了更多的情形，其中库默尔的工作奠定了代数数论的基础。完整的定理由安德鲁·怀尔斯（Andrew Wiles）于1994年证明，其中关键的一步是与理查德·泰勒（Richard Taylor）合作完成的；证明的思路是把一个假想的解与一条不可能是模椭圆曲线的椭圆曲线联系起来。

## 两平方和

哪些数是两个平方数之和？$5 = 1 + 4$，$13 = 4 + 9$，$25 = 9 + 16$，但$3$、$7$、$21$不是。由于平方数$\equiv 0$或$1 \pmod 4$，没有一个$\equiv 3 \pmod 4$的数是两个平方数之和。乘积的性质很好，这要归功于婆罗摩笈多（Brahmagupta）以及后来的斐波那契（Fibonacci）都知道的一个恒等式：

$$
(a^2 + b^2)(c^2 + d^2) = (ac - bd)^2 + (ad + bc)^2 .
$$ {#eq-brahmagupta}

（它就是对$z = a + bi$，$w = c + di$成立的$\abs{z}^2\abs{w}^2 = \abs{zw}^2$。）所以问题归结为素数的情形。

::: theorem 费马二平方和定理 {#thm-two-squares}
奇素数$p$是两个平方数之和当且仅当$p \equiv 1 \pmod 4$。
:::

::: proof
若$p = a^2 + b^2$，则$p \equiv 0, 1$或$2 \pmod 4$，所以$p \equiv 1 \pmod 4$（因为$p$是奇数）。

反之，设$p \equiv 1 \pmod 4$。由[[number-theory/quadratic-reciprocity#thm-first-supplement]]，存在整数$x_0$使$x_0^2 \equiv -1 \pmod p$。令$k = \lfloor\sqrt p\,\rfloor$；由于$p$是素数，它不是完全平方数，所以$k < \sqrt p < k + 1$。考虑如下$(k + 1)^2 > p$个数：

$$
u + x_0v, \qquad 0 \le u, v \le k .
$$

它们的个数多于模$p$的剩余类的个数，所以由鸽巢原理（[[discrete/advanced-counting]]），其中有两个来自不同数对$(u_1, v_1) \neq (u_2, v_2)$的数同余：$u_1 + x_0v_1 \equiv u_2 + x_0v_2 \pmod p$。令$a = u_1 - u_2$，$b = v_1 - v_2$。则$(a, b) \neq (0, 0)$，$\abs a, \abs b \le k < \sqrt p$，且$a \equiv -x_0b \pmod p$。因此

$$
a^2 + b^2 \equiv x_0^2b^2 + b^2 = (x_0^2 + 1)b^2 \equiv 0 \pmod p,
$$

而$0 < a^2 + b^2 < 2p$。严格介于$0$与$2p$之间的$p$的倍数只有$p$，所以$a^2 + b^2 = p$。
:::

::: example 把素数写成两个平方数之和 {#ex-two-squares}
利用$-1$的平方根，把$29$和$13$表示成两个平方数之和。
::: solution
对$p = 29$：$12^2 = 144 = 5\cdot 29 - 1$，所以$x_0 = 12$。证明中要找满足$\abs a, \abs b < \sqrt{29} \approx 5.4$的$a \equiv -12b \pmod{29}$。对$b = 1$，$-12 \equiv 17$，而$17$和$17 - 29 = -12$都不够小；对$b = 2$，$-24 \equiv 5$，它足够小。所以$(a, b) = (5, 2)$，$29 = 5^2 + 2^2$。对$p = 13$：$5^2 = 25 \equiv -1$，$b = 1$给出$a \equiv -5 \equiv 8$，太大；$b = 2$给出$a \equiv -10 \equiv 3$，所以$13 = 3^2 + 2^2$。（一个巧妙的替代方法：对$p$和$x_0$施行欧几里得算法；最先出现的两个小于$\sqrt p$的余数就给出所求的表示。对$29, 12$，余数依次为$5, 2, 1$，而$5^2 + 2^2 = 29$。）
:::
:::

::: theorem 哪些数是两个平方数之和？ {#thm-sum-two-squares}
正整数$n$是两个平方数之和，当且仅当每个素数$p \equiv 3 \pmod 4$在$n$的分解式中的指数都是偶数。
:::

::: proof
($\Leftarrow$) 写$n = 2^a\prod p_i^{e_i}\prod q_j^{2f_j}$，其中$p_i \equiv 1$，$q_j \equiv 3 \pmod 4$。每个因子都是两个平方数之和：$2 = 1^2 + 1^2$，每个$p_i$由[[#thm-two-squares]]，而$q_j^2 = q_j^2 + 0^2$。由[[#eq-brahmagupta]]（反复应用），它们的乘积也是两个平方数之和。

($\Rightarrow$) 我们要用到一个引理：**若$q \equiv 3 \pmod 4$是素数且$q \mid a^2 + b^2$，则$q \mid a$且$q \mid b$。**事实上，若$q \nmid b$，设$b'$是$b$模$q$的逆，则$(ab')^2 \equiv -1 \pmod q$，与$\bigl(\frac{-1}{q}\bigr) = -1$矛盾。所以$q \mid b$，从而$q \mid a^2$，所以$q \mid a$。

现在对$n$用强归纳法证明($\Rightarrow$)。设$n = a^2 + b^2$，并设$q \equiv 3 \pmod 4$是整除$n$的素数。由引理，$q \mid a$且$q \mid b$，所以$q^2 \mid n$，而$\frac n{q^2} = \left(\frac aq\right)^2 + \left(\frac bq\right)^2$是一个更小的两平方和。由归纳假设，每个$\equiv 3 \pmod 4$的素数在$\frac n{q^2}$中的指数都是偶数，因而在$n$中也是偶数。
:::

例如$2026 = 2\cdot 1013$，其中$1013 \equiv 1 \pmod 4$是素数，所以它是两个平方数之和：$2026 = 45^2 + 1^2$。但$2027 \equiv 3 \pmod 4$不是，$21 = 3\cdot 7$也不是；而$245 = 5\cdot 7^2 = 14^2 + 7^2$是，因为$7$是以平方的形式出现的。

::: quiz
下列哪些数是两个平方数之和？（选出所有正确的选项。）
- [ ] $21$
- [x] $50$
- [x] $245$
- [ ] $2027$
::: solution
$21 = 3\cdot 7$中$\equiv 3 \pmod 4$的素数的指数是奇数。$50 = 2\cdot 5^2 = 7^2 + 1^2 = 5^2 + 5^2$。$245 = 5\cdot 7^2 = 14^2 + 7^2$。$2027 \equiv 3 \pmod 4$，所以它不可能是两个平方数之和。
:::
:::

::: remark 三平方和与四平方和
拉格朗日（Lagrange）在1770年证明了：**每个**正整数都是四个平方数之和；例如$7 = 4 + 1 + 1 + 1$。三个平方数恰好足以表示不具有$4^a(8b + 7)$形式的数——这是勒让德和高斯的一个定理。容易的那一半是[[number-theory/congruences#exr-3-6]]：平方数只能是$0, 1, 4 \pmod 8$，所以没有一个$\equiv 7 \pmod 8$的数是三个平方数之和。
:::

## 佩尔方程

设正整数$d$不是完全平方数，**佩尔方程**是指

$$
x^2 - dy^2 = 1 .
$$

它总有平凡解$(1, 0)$。它的非平凡解给出$\sqrt d$的极好的有理逼近：若$x^2 - dy^2 = 1$，则$\frac xy - \sqrt d = \frac{1}{y(x + y\sqrt d)}$，这个量非常小。对$d = 2$，解$(3, 2), (17, 12), (99, 70)$给出$\frac{99}{70} = 1.414285\ldots$，它很接近$\sqrt2 = 1.414213\ldots$。

关键在于考虑形如$x + y\sqrt d$的数及其**范数**$N(x + y\sqrt d) = x^2 - dy^2 = (x + y\sqrt d)(x - y\sqrt d)$。直接计算（婆罗摩笈多的“合成”）表明范数是积性的：

$$
(x_1 + y_1\sqrt d)(x_2 + y_2\sqrt d) = (x_1x_2 + dy_1y_2) + (x_1y_2 + x_2y_1)\sqrt d, \qquad N(\alpha\beta) = N(\alpha)N(\beta) .
$$ {#eq-pell-composition}

所以解的乘积仍是解。满足$x, y > 0$的解称为**正解**；$x$最小的正解（等价地，$y$最小，或$x + y\sqrt d$最小的正解，因为$x^2 = 1 + dy^2$）称为**基本解**。

::: theorem 佩尔方程的解 {#thm-pell}
设$d > 0$不是平方数。则$x^2 - dy^2 = 1$有正解。若$(x_1, y_1)$是基本解，则全部正解恰好是由下式给出的数对$(x_k, y_k)$，$k \ge 1$：

$$
x_k + y_k\sqrt d = (x_1 + y_1\sqrt d)^k .
$$
:::

::: proof
**存在性**（概要）。由狄利克雷逼近定理，有无穷多对正整数$(x, y)$满足$\abs{x - y\sqrt d} < \frac 1y$。对这些数对，$\abs{x^2 - dy^2} = \abs{x - y\sqrt d}\,(x + y\sqrt d) < \frac1y(2y\sqrt d + 1) \le 2\sqrt d + 1$。所以某个非零整数$N$对无穷多个数对等于$x^2 - dy^2$，而在这些数对中，有两对$(x, y) \ne (x', y')$满足$x \equiv x'$，$y \equiv y' \pmod{\abs N}$。于是可以验证$\frac{x + y\sqrt d}{x' + y'\sqrt d}$的坐标是整数且范数为$1$，从而给出一个非平凡解。完整的细节见Niven、Zuckerman与Montgomery的书第7.8节。实际中，解是通过$\sqrt d$的连分数展开求出的。

**所有解都是幂。**令$\eps = x_1 + y_1\sqrt d > 1$。由[[#eq-pell-composition]]，每个$\eps^k$的范数都是$1$，且其坐标是正整数，所以$(x_k, y_k)$是正解。反之，设$(x, y)$是正解，$\alpha = x + y\sqrt d$。则$\alpha \ge \eps$，所以存在$k \ge 1$使$\eps^k \le \alpha < \eps^{k+1}$。令$\beta = \alpha\eps^{-k}$；由于$\eps^{-1} = x_1 - y_1\sqrt d$，有$\beta = \alpha(x_1 - y_1\sqrt d)^k = u + v\sqrt d$，其中$u, v$是整数，且$N(\beta) = 1$。又$1 \le \beta < \eps$。假设$\beta > 1$。则$0 < \beta^{-1} = u - v\sqrt d < 1$，所以$u = \frac{\beta + \beta^{-1}}2 > 0$，$v = \frac{\beta - \beta^{-1}}{2\sqrt d} > 0$：$(u, v)$是满足$u + v\sqrt d < \eps$的正解，与基本解的最小性矛盾。因此$\beta = 1$，$\alpha = \eps^k$。
:::

把$(x_1 + y_1\sqrt d)^{k+1} = (x_1 + y_1\sqrt d)(x_k + y_k\sqrt d)$展开，就得到递推关系

$$
x_{k+1} = x_1x_k + dy_1y_k, \qquad y_{k+1} = x_1y_k + y_1x_k .
$$

::: example 解佩尔方程 {#ex-pell}
求$x^2 - 2y^2 = 1$和$x^2 - 3y^2 = 1$的前几个解。
::: solution
对$d = 2$，依次尝试$y = 1, 2$：$1 + 2 = 3$不是平方数，$1 + 8 = 9 = 3^2$，所以基本解是$(3, 2)$。于是$(3 + 2\sqrt2)^2 = 17 + 12\sqrt2$，$(3 + 2\sqrt 2)^3 = 99 + 70\sqrt 2$：解为$(3, 2), (17, 12), (99, 70), (577, 408), \dots$。验算：$17^2 - 2\cdot 12^2 = 289 - 288 = 1$。

对$d = 3$：$y = 1$给出$1 + 3 = 4 = 2^2$，所以$(2, 1)$是基本解，而递推关系$x_{k+1} = 2x_k + 3y_k$，$y_{k+1} = x_k + 2y_k$给出$(7, 4), (26, 15), (97, 56), \dots$。

基本解可能大得惊人：对$d = 7$，它是$(8, 3)$，但对$d = 61$，它是$(1766319049, 226153980)$。
:::
:::

::: warning 负佩尔方程
方程$x^2 - dy^2 = -1$的情况不同：对某些$d$它可解，对另一些则不可解。对$d = 2$，$(1, 1)$是解；对$d = 3$则根本无解，因为$x^2 \equiv -1 \pmod 3$是不可能的。更一般地，若$d$有素因数$q \equiv 3 \pmod 4$，则$x^2 \equiv -1 \pmod q$无解，所以$x^2 - dy^2 = -1$也无解。不要以为关于$+1$的结果可以照搬到$-1$上。
:::

::: application 平方三角形数
哪些三角形数$\frac{n(n+1)}{2}$是完全平方数？令$\frac{n(n+1)}2 = m^2$并乘以$8$，得到$(2n + 1)^2 - 8m^2 = 1$，这是$d = 8$的佩尔方程（[[#exr-8-10]]）。它的解给出平方三角形数$1$、$36$、$1225$、$41616$、……，对应的$n = 1, 8, 49, 288, \dots$——这是由一个二次无理数产生的无穷族。
:::

::: history
泥板普林顿322（Plimpton 322，约公元前1800年）上列出的数，大多数历史学家都认为是由勾股数组导出的，其中有些数大到$(12709, 13500, 18541)$。欧几里得（Euclid）的《几何原本》（*Elements*）给出了勾股数组的参数化，丢番图（Diophantus）的《算术》（*Arithmetica*，3世纪）是第一部专门研究有理数方程的著作。婆罗摩笈多（Brahmagupta，628年）发现了$x^2 - Ny^2$的合成法则，而婆什迦罗第二（Bhāskara II，1150年）所描述的循环法（*chakravala*）可以解佩尔方程，包括$d = 61$的情形。费马（Fermat）于1640年陈述了二平方和定理，并于1657年以佩尔方程向欧洲数学家发起挑战；欧拉（Euler）证明了二平方和定理（发表于1752—1755年），拉格朗日（Lagrange）于1768年证明了每个佩尔方程都有解。“佩尔”这一名称源于欧拉误将这一方程归功于约翰·佩尔（John Pell）。这里给出的二平方和定理的证明用到了阿克塞尔·图厄（Axel Thue）的一个想法（1902年）。
:::

## 后续内容

本章的方法通向现代数论的许多领域。两平方和就是高斯整数$\Z[i]$的算术（[[abstract-algebra/rings]]）：素数$p \equiv 1 \pmod 4$可分解为$(a + bi)(a - bi)$。佩尔方程描述了$\Z[\sqrt d]$的单位，这是代数数论中狄利克雷单位定理的第一个情形。圆的弦法可以推广到椭圆曲线$y^2 = x^3 + ax + b$，椭圆曲线的有理点构成一个群，它们在怀尔斯对费马大定理的证明以及椭圆曲线密码（[[number-theory/cryptography]]）中都处于核心地位。

::: summary
- $ax + by = c$可解当且仅当$d = \gcd(a,b) \mid c$；此时全部解为$x = x_0 + \frac bdt$，$y = y_0 - \frac adt$（[[#thm-linear-diophantine]]）。
- 对于互素的硬币面值$a, b$，大于$ab - a - b$的每个金额都可以支付，而$ab - a - b$不能（[[#thm-coin]]）。
- 本原勾股数组是$(m^2 - n^2, 2mn, m^2 + n^2)$，其中$m > n$互素且一奇一偶——等价地说，就是单位圆上的有理点。
- **无穷递降法**：$x^4 + y^4 = z^2$没有正整数解，所以费马大定理对$n = 4$（以及$4$的所有倍数）成立。
- **费马二平方和定理**：奇素数是两个平方数之和当且仅当$p \equiv 1 \pmod 4$——可由$x_0^2 \equiv -1$和鸽巢原理证明。
- $n$是两个平方数之和当且仅当$\equiv 3 \pmod 4$的素数在它的分解式中的指数都是偶数；证明用到$(a^2+b^2)(c^2+d^2) = (ac-bd)^2 + (ad+bc)^2$。
- **佩尔方程**$x^2 - dy^2 = 1$总有正解，并且全部正解都是基本解的幂$(x_1 + y_1\sqrt d)^k$。
:::

如果鸡每只3英镑，鸭每只5英镑，[[#ex-hens-ducks]]中的农民恰好花掉71英镑有多少种方法？（数一数满足$x, y \ge 0$的$3x + 5y = 71$的解。）
::: solution

::: exercise 无法支付的最大金额 {level=1 check="27"}
用面值为$5$个单位和$8$个单位的硬币，不能恰好支付的最大金额是多少？
::: solution
由[[#thm-coin]]，取$a = 5$，$b = 8$：$ab - a - b = 40 - 13 = 27$。

::: exercise 由m和n得到的勾股数组 {level=1 check="53"}
求$m = 7$，$n = 2$对应的本原勾股数组。填入斜边。
::: solution
$x = 49 - 4 = 45$，$y = 2\cdot 7\cdot 2 = 28$，$z = 49 + 4 = 53$。验算：$45^2 + 28^2 = 2025 + 784 = 2809 = 53^2$。（$\gcd(7,2) = 1$，且$7, 2$一奇一偶，所以这个勾股数组是本原的。）
:::

::: exercise 斜边为65的三角形 {level=2 check="4"}
斜边为$65$、边长都是整数的直角三角形有多少个？
::: hint
求出$z = 65 = m^2 + n^2$的本原勾股数组，以及斜边为$5$和$13$的勾股数组的倍数。
:::
::: solution
$65 = 8^2 + 1^2 = 7^2 + 4^2$，两对数都互素且一奇一偶，给出本原勾股数组$(63, 16, 65)$和$(33, 56, 65)$。非本原的勾股数组是满足$kz' = 65$的倍数$k(x', y', z')$：$13\cdot(3, 4, 5) = (39, 52, 65)$和$5\cdot(5, 12, 13) = (25, 60, 65)$。所以共有$4$个三角形。
:::

::: exercise 是否是两平方和 {level=2}
把$2026$写成两个平方数之和，并证明$2027$不是两个平方数之和。
::: solution
$2026 = 2025 + 1 = 45^2 + 1^2$。（这是[[#thm-sum-two-squares]]所预言的，因为$2026 = 2\cdot 1013$，而$1013 \equiv 1 \pmod 4$是素数。）而$2027 = 4\cdot 506 + 3 \equiv 3 \pmod 4$，但两个平方数之和$\equiv 0, 1, 2 \pmod 4$。
:::
:::

::: exercise 一个负佩尔方程 {level=2}
证明$x^2 - 3y^2 = -1$没有整数解，而$x^2 - 2y^2 = -1$有无穷多个整数解。
::: solution
模$3$时，$x^2 - 3y^2 \equiv x^2 \in \set{0, 1}$，永远不会是$-1 \equiv 2$。对$d = 2$：$1 - 2 = -1$，所以$(1, 1)$是一个解，而把$1 + \sqrt 2$乘以$+1$方程的解，范数$-1$保持不变（[[#eq-pell-composition]]）：$(1 + \sqrt2)(3 + 2\sqrt 2) = 7 + 5\sqrt2$，而$49 - 50 = -1$。$3 + 2\sqrt 2$的各次幂给出无穷多个这样的解。
:::
:::

::: exercise 下一个佩尔方程的解 {level=2 check="26"}
在$x^2 - 3y^2 = 1$满足$y > 10$的解中，求最小的那个。填入$x$。
::: solution
由[[#ex-pell]]，正解为$(2, 1), (7, 4), (26, 15), \dots$，所以答案是$(26, 15)$：$676 - 3\cdot 225 = 676 - 675 = 1$。
:::

::: exercise 勾股数组中的整除性 {level=3}
证明：在每个勾股数组中，有一条直角边能被$3$整除，有一条直角边能被$4$整除，并且三个数中有一个能被$5$整除。
::: solution
只需处理本原勾股数组$(m^2 - n^2, 2mn, m^2 + n^2)$，因为倍数会继承这一性质。**被$4$整除：**$m, n$中有一个是偶数，所以$4 \mid 2mn$。**被$3$整除：**若$3 \mid m$或$3 \mid n$，则$3 \mid 2mn$；否则$m^2 \equiv n^2 \equiv 1 \pmod 3$，从而$3 \mid m^2 - n^2$。**被$5$整除：**若$5 \mid mn$，则$5 \mid 2mn$。否则$m^2, n^2 \in \set{1, 4} \pmod 5$（模$5$的非零平方数）；若$m^2 \equiv n^2$，则$5 \mid m^2 - n^2$；若不然，则$\set{m^2, n^2} \equiv \set{1, 4}$，从而$5 \mid m^2 + n^2$。
:::
:::

::: exercise 互素的两平方和 {level=3}
设$n = a^2 + b^2$，其中$\gcd(a, b) = 1$。证明$n$没有素因数$q \equiv 3 \pmod 4$，并且$4 \nmid n$。
::: solution
若$q \equiv 3 \pmod 4$整除$n$，则[[#thm-sum-two-squares]]证明中的引理给出$q \mid a$且$q \mid b$，与$\gcd(a, b) = 1$矛盾。若$4 \mid n$，则$a^2 + b^2 \equiv 0 \pmod 4$，这迫使两个平方数都$\equiv 0$，即$a, b$都是偶数——同样与互素矛盾。（反之，可以证明：没有这样的素因数且满足$4 \nmid n$的每个$n$都是两个互素整数的平方和。）
:::
:::

::: exercise 平方三角形数 {level=3 check="1225"}
证明$\frac{n(n+1)}{2} = m^2$当且仅当$(2n + 1)^2 - 8m^2 = 1$。利用$X^2 - 8Y^2 = 1$的基本解$(3, 1)$，求出前三个平方三角形数，并填入第三个。
::: solution
把$\frac{n(n+1)}2 = m^2$乘以$8$得$4n^2 + 4n = 8m^2$，即$(2n + 1)^2 - 1 = 8m^2$；这些步骤都是可逆的。所以我们需要$X^2 - 8Y^2 = 1$的满足$X$为奇数的解$(X, Y) = (2n + 1, m)$。基本解是$(3, 1)$（$9 - 8 = 1$），由[[#thm-pell]]，其余的解来自$(3 + \sqrt 8)^k$：$(3 + \sqrt8)^2 = 17 + 6\sqrt 8$，$(3 + \sqrt 8)^3 = 99 + 35\sqrt 8$。所有的$X$都是奇数。由此得到$(n, m) = (1, 1), (8, 6), (49, 35)$，以及平方三角形数$1$、$36$和$1225 = 35^2 = \frac{49\cdot 50}{2}$。
:::
