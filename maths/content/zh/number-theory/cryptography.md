在历史上的大部分时期，两个想要秘密通信的人必须先见面，或者托付一位信使，才能商定一个秘密密钥。1976年，惠特菲尔德·迪菲（Whitfield Diffie）和马丁·赫尔曼（Martin Hellman）提出了一个听起来不可能的设想：两个素不相识的人完全公开地交谈，就能商定一个窃听者无法推算出来的共享秘密。一年后，罗恩·李维斯特（Ron Rivest）、阿迪·沙米尔（Adi Shamir）和伦纳德·阿德尔曼（Leonard Adleman）找到了一种方法，让任何人都能加密一条只有一个人能解密的消息。这两项发明都是纯粹的初等数论，建立在前面各章的结果之上：欧几里得算法、中国剩余定理、费马定理与欧拉定理，以及原根。

关键在于容易的问题与困难的问题之间的一种**不对称性**。计算$a^e \bmod n$是容易的，即使对几百位的数也是如此；检验一个大数是否为素数也是容易的。但逆转这些运算——由幂求出指数（离散对数问题），或者求出两个大素数之积的素因数——看来是不可行的。本章将介绍快速求幂、迪菲-赫尔曼密钥交换、RSA密码体制（连同其正确性的完整证明），以及使寻找大素数成为可能的概率素性检验。为了能用手算核对每一步，玩具例子使用的是小数；实际系统使用的是几百位的数。

## 快速模幂运算

把$7$自乘$85$次来计算$7^{86} \bmod 101$会很慢，而对于几百位的指数则根本不可能。窍门在于反复平方。

::: algorithm 平方-乘算法 {#alg-square-multiply}
为对$e \ge 1$计算$a^e \bmod n$，把$e$写成二进制：$e = \sum_{i=0}^{k} b_i2^i$，其中$b_k = 1$。

1. 计算$a_0 = a \bmod n$，并对$i = 1, \dots, k$依次计算$a_{i} = a_{i-1}^2 \bmod n$，于是$a_i \equiv a^{2^i}$。
2. 把满足$b_i = 1$的那些$a_i$模$n$相乘。
:::

::: proposition 平方-乘算法的计算量 {#prop-square-multiply}
[[#alg-square-multiply]]正确地算出$a^e \bmod n$，至多用$2\lfloor\log_2 e\rfloor$次模$n$乘法，并且参与乘法的每个数都小于$n$。
:::

::: proof
由归纳法，$a_i \equiv a^{2^i} \pmod n$，因为$a_i \equiv a_{i-1}^2 \equiv (a^{2^{i-1}})^2 = a^{2^i}$。因此第2步中的乘积模$n$为$\prod_{b_i = 1}a^{2^i} = a^{\sum_i b_i2^i} = a^e$。二进制展开有$k + 1$位，其中$k = \lfloor \log_2 e\rfloor$，所以第1步用$k$次平方，第2步至多用$k$次乘法（比数字$1$的个数少一次）。所有因子都已模$n$约化，所以每个乘积在约化之前都小于$n^2$。
:::

对于$2048$比特的指数，这至多是大约$4000$次$2048$比特数的乘法——在笔记本电脑上只需几毫秒。

::: example 模101的一个幂 {#ex-square-multiply}
计算$7^{86} \bmod 101$。
::: solution
$86 = 64 + 16 + 4 + 2 = 1010110_2$。模$101$反复平方：

| $i$ | $0$ | $1$ | $2$ | $3$ | $4$ | $5$ | $6$ |
|---|---|---|---|---|---|---|---|
| $7^{2^i} \bmod 101$ | $7$ | $49$ | $78$ | $24$ | $71$ | $92$ | $81$ |

例如$49^2 = 2401 = 23\cdot 101 + 78$，$78^2 = 6084 = 60\cdot 101 + 24$。于是

$$
7^{86} = 7^{64}\cdot7^{16}\cdot7^4\cdot7^2 \equiv 81\cdot 71\cdot 78\cdot 49 \pmod{101}.
$$

逐步相乘：$81\cdot 71 = 5751 \equiv 95$，$95\cdot 78 = 7410 \equiv 37$，$37 \cdot 49 = 1813 \equiv 96$。所以$7^{86} \equiv 96 \pmod{101}$，只用了$6$次平方和$3$次乘法，而不是$85$次乘法。
:::
:::

::: quiz
用从左到右的平方-乘算法计算$a^{1000}$，需要多少次模乘法（包括平方）？
- [x] $14$
- [ ] $20$
- [ ] $500$
- [ ] $999$
::: solution
$1000 = 1111101000_2$有$10$个二进制位，其中六个是$1$。从左边开始逐位处理：对首位之后的$9$位中的每一位平方一次，对其余$5$个为$1$的位中的每一位乘一次$a$：共$9 + 5 = 14$次乘法。
:::

## 迪菲-赫尔曼密钥交换

设$p$是一个大素数，$g$是模$p$的原根（[[number-theory/primitive-roots]]）。由$a$计算$A = g^a \bmod p$很快；由$A$求回$a$则是**离散对数问题**，当$p$很大且选择得当时，还不知道解决它的有效算法。容易计算但难以求逆的函数称为**单向函数**。

::: algorithm 迪菲-赫尔曼密钥交换 {#alg-diffie-hellman}
Alice和Bob公开商定一个素数$p$和一个原根$g$。

1. Alice选取秘密的$a$，发送$A = g^a \bmod p$。
2. Bob选取秘密的$b$，发送$B = g^b \bmod p$。
3. Alice计算$K = B^a \bmod p$；Bob计算$K = A^b \bmod p$。
:::

他们得到相同的密钥，因为$B^a \equiv g^{ba} = g^{ab} \equiv A^b \pmod p$。窃听者能看到$p$、$g$、$A$和$B$，而要求出$K = g^{ab}$，看来必须求解一个离散对数。

::: example 一个玩具密钥交换 {#ex-diffie-hellman}
取$p = 101$，$g = 2$（模$101$的一个原根），Alice选取$a = 37$，Bob选取$b = 61$。求双方发送的消息和共享密钥。
::: solution
用平方-乘算法，Alice发送$A = 2^{37} \bmod 101 = 55$，Bob发送$B = 2^{61} \bmod 101 = 73$。Alice计算$K = 73^{37} \bmod 101 = 74$，Bob计算$K = 55^{61} \bmod 101 = 74$。作为验算，$K = 2^{37\cdot 61} = 2^{2257}$，而由于$2^{100} \equiv 1$（费马小定理），$2^{2257} \equiv 2^{57} \equiv 74 \pmod{101}$。只知道$101$、$2$、$55$和$73$的窃听者在这里只需尝试所有指数即可，但对于$2048$比特的素数，这是根本不可能的。
:::
:::

::: warning 密钥交换不等于认证
迪菲-赫尔曼密钥交换能防范窃听者，却不能防范截获消息的主动攻击者。在**中间人攻击**中，Mallory用她自己的值$g^{m}$替换$A$和$B$，与Alice共享一个密钥，与Bob共享另一个密钥，并转发（同时阅读）所有消息。因此，TLS等实际协议把密钥交换与数字签名结合起来，用数字签名证明每条消息是谁发送的。
:::

## RSA密码体制

迪菲-赫尔曼密钥交换用于商定密钥；RSA则让任何人都能用公钥**加密**，而只有私钥的持有者才能逆转这一过程——这是一个陷门单向函数。

::: algorithm RSA {#alg-rsa}
**密钥生成。**选取不同的大素数$p, q$；令$n = pq$，$\varphi(n) = (p-1)(q-1)$。选取满足$\gcd(e, \varphi(n)) = 1$的$e$，并用扩展欧几里得算法求出满足$ed \equiv 1 \pmod{\varphi(n)}$的$d$。公开**公钥**$(n, e)$；对$d$（以及$p$、$q$、$\varphi(n)$）保密。

**加密。**消息是满足$0 \le m < n$的整数$m$；它的密文是$c = m^e \bmod n$。

**解密。**计算$m = c^d \bmod n$。
:::

::: theorem RSA能正确解密 {#thm-rsa}
沿用上面的记号，对**每个**整数$m$，$(m^e)^d \equiv m \pmod n$。
:::

::: proof
记$ed = 1 + k\varphi(n) = 1 + k(p-1)(q-1)$，其中$k \ge 0$。我们证明$m^{ed} \equiv m$对模$p$和模$q$都成立。

模$p$：若$p \nmid m$，由费马小定理（[[number-theory/fermat-euler#thm-fermat]]）得$m^{p-1} \equiv 1$，所以

$$
m^{ed} = m\cdot\bigl(m^{p-1}\bigr)^{k(q-1)} \equiv m \pmod p .
$$

若$p \mid m$，则$m^{ed}$和$m$都$\equiv 0 \pmod p$。所以在所有情形下都有$m^{ed} \equiv m \pmod p$，同理$m^{ed} \equiv m \pmod q$。由于$p$和$q$是不同的素数，$n = pq$整除$m^{ed} - m$（由中国剩余定理，[[number-theory/congruences#thm-crt]]）。因此$(m^e)^d = m^{ed} \equiv m \pmod n$。
:::

注意，这个证明也涵盖了$\gcd(m, n) \neq 1$的消息，而对这样的消息，单靠欧拉定理是不够的。

::: example 一个玩具RSA密钥 {#ex-rsa}
取$p = 73$，$q = 97$，$e = 5$。求私钥指数$d$，加密$m = 2026$，并验证解密。
::: solution
$n = 73\cdot97 = 7081$，$\varphi(n) = 72\cdot 96 = 6912$。由于$6912 = 2^8\cdot 3^3$，$\gcd(5, 6912) = 1$。欧几里得算法：$6912 = 1382\cdot 5 + 2$，$5 = 2\cdot 2 + 1$，所以

$$
1 = 5 - 2\cdot 2 = 5 - 2(6912 - 1382\cdot 5) = 2765\cdot 5 - 2\cdot 6912,
$$

从而$d = 2765$（验算：$5\cdot 2765 = 13825 = 2\cdot 6912 + 1$）。公钥是$(7081, 5)$。加密得$c = 2026^5 \bmod 7081 = 1424$，解密得$1424^{2765} \bmod 7081 = 2026$，两者都用平方-乘算法计算。
:::
:::

::: remark 用中国剩余定理加速解密
私钥持有者知道$p$和$q$，可以分别模每个素数进行计算，从而把解密速度提高到大约四倍（[[number-theory/congruences#ex-crt-split]]）。由费马小定理，模$p$时的指数可以模$p - 1$约化：令$d_p = d \bmod (p-1)$，$d_q = d \bmod (q-1)$，计算$m_p = c^{d_p} \bmod p$和$m_q = c^{d_q} \bmod q$，再把它们组合起来。对于玩具密钥，$d_p = 2765 \bmod 72 = 29$，$d_q = 2765 \bmod 96 = 77$；于是$m_p = 1424^{29} \bmod 73 = 55$，$m_q = 1424^{77} \bmod 97 = 86$，而模$7081$下满足$\equiv 55 \pmod{73}$且$\equiv 86 \pmod{97}$的唯一剩余是$2026$，与预期一致。
:::

**签名。**RSA也可以反过来使用。为了对消息$m$签名，私钥持有者计算$s = m^d \bmod n$；任何人都可以通过检验$s^e \equiv m \pmod n$来验证签名，这由同一定理（把$e$和$d$的角色互换）保证。只有持有$d$的人才能生成$s$。对于玩具密钥，$m = 100$的签名是$s = 100^{2765} \bmod 7081 = 6159$，任何人都可以验证$6159^5 \equiv 100 \pmod{7081}$。（实际中签名的是消息的密码学哈希值，而不是消息本身。）

**安全性。**任何能分解$n$的人都能算出$\varphi(n)$，进而算出$d$，所以破解RSA至多和因数分解一样难。反过来，知道$\varphi(n)$就能得出因数：$p + q = n - \varphi(n) + 1$，$pq = n$，所以$p$和$q$是一个二次方程的根。对于玩具密钥，$p + q = 7081 - 6912 + 1 = 170$，而$x^2 - 170x + 7081 = 0$的根为$\frac{170 \pm \sqrt{28900 - 28324}}{2} = \frac{170 \pm 24}{2}$，即$97$和$73$。截至2026年，被分解的最大RSA挑战数是RSA-896（一个$270$位、$896$比特的数），它于2026年9月借助在大批GPU上运行的数域筛法被分解；实际中使用的密钥长度为$2048$比特或更长。

::: warning 教科书式RSA本身并不安全
上面这个原始方案有一些弱点，实际实现必须加以避免。它是**确定性的**：同一消息总是给出同一密文，因此攻击者可以检验自己的猜测。它是**可延展的**：由于$(m_1m_2)^e = m_1^em_2^e$，两个密文相乘就得到乘积的密文。若$m$和$e$都很小，$m^e$可能小于$n$，这时$m$就只是$c$的普通$e$次方根。非常小的私钥指数$d$可以借助连分数由$(n, e)$求出（维纳攻击）。因此，实用的RSA会用随机数据填充消息（如OAEP标准），并谨慎地选取参数。
:::

## 素性检验

RSA需要几百位的素数。这样的素数很多：由素数定理（[[number-theory/primes#thm-pnt]]），$2^{1024}$附近的随机数是素数的概率约为$1/\ln(2^{1024}) \approx 1/710$，所以在这种大小的随机奇数中，大约每$355$个就有一个素数。问题在于如何**识别**它们，因为试除法毫无希望。

### 费马检验与卡迈克尔数

由费马小定理，若对某个满足$\gcd(a, n) = 1$的$a$有$a^{n-1} \not\equiv 1 \pmod n$，则$n$是合数；这样的$a$称为**费马证据**。若$a^{n-1} \equiv 1$但$n$是合数，则称$n$为**以$a$为底的伪素数**——例如$341$是以$2$为底的伪素数（[[number-theory/fermat-euler]]）。对给定的底，伪素数是稀少的，所以这个检验对随机数很有效；但有些合数能骗过每一个底。

::: definition 卡迈克尔数 {#def-carmichael}
若合数$n$对每个满足$\gcd(a, n) = 1$的$a$都有$a^{n-1} \equiv 1 \pmod n$，则称它为**卡迈克尔数**。
:::

::: theorem 科塞尔特判别法 {#thm-korselt}
合数$n$是卡迈克尔数，当且仅当$n$无平方因子，且对整除$n$的每个素数$p$都有$p - 1 \mid n - 1$。
:::

::: proof
($\Leftarrow$) 设$\gcd(a, n) = 1$，$p \mid n$。则$p \nmid a$，又由于$p - 1 \mid n - 1$，由费马小定理得$a^{n-1} = (a^{p-1})^{(n-1)/(p-1)} \equiv 1 \pmod p$。由于$n$无平方因子，它是其互不相同的素因数之积，而这些素因数两两互素，所以$a^{n-1} \equiv 1 \pmod n$。

($\Rightarrow$) 设$n$是卡迈克尔数。首先，$n$是奇数：若$n$是偶数，则$a = -1$与$n$互素，而由于$n - 1$是奇数，$(-1)^{n-1} = -1$，但因为$n > 2$，$-1 \not\equiv 1 \pmod n$。现在设$p$是整除$n$的素数——它必然是奇数——并设$p^k$是整除$n$的$p$的最高次幂。设$g$是模$p^k$的原根，由于$p$是奇数，它是存在的（[[number-theory/primitive-roots#thm-primitive-root-classification]]）。由中国剩余定理，选取$a$使$a \equiv g \pmod{p^k}$且$a \equiv 1 \pmod{n/p^k}$。则$\gcd(a, n) = 1$，所以$a^{n-1} \equiv 1 \pmod n$，特别地，$g^{n-1} \equiv 1 \pmod{p^k}$。因此$\ord_{p^k}(g) = \varphi(p^k) = p^{k-1}(p-1)$整除$n - 1$。若$k \ge 2$，则$p$既整除$n - 1$又整除$n$，这是不可能的；所以$k = 1$，$n$无平方因子，且$p - 1 \mid n - 1$。
:::

对$561 = 3\cdot 11\cdot 17$，数$2$、$10$和$16$都整除$560$，所以$561$是卡迈克尔数——而且是最小的一个。其他的例子有$1105 = 5\cdot 13\cdot 17$和$1729 = 7\cdot 13\cdot 19$。1994年，奥尔福德（Alford）、格兰维尔（Granville）和波梅朗斯（Pomerance）证明了卡迈克尔数有无穷多个，所以单靠费马检验永远不可能完全可靠。

### 米勒-拉宾检验

费马检验的缺陷在于它忽略了$1$的平方根。模素数时，$1$只有平方根$\pm 1$（[[number-theory/fermat-euler#lem-square-roots-one]]）；模合数时可能有更多的平方根，而它们会暴露出这个合数。

::: theorem 强可能素数 {#thm-miller-rabin}
设$p$为奇素数，记$p - 1 = 2^sd$，其中$d$为奇数。若$p \nmid a$，则或者

$$
a^d \equiv 1 \pmod p \qquad\text{或}\qquad a^{2^rd} \equiv -1 \pmod p \ \text{ 对某个 } 0 \le r < s \text{ 成立} .
$$
:::

::: proof
考虑序列$a^d, a^{2d}, a^{4d}, \dots, a^{2^sd}$，其中每一项都是前一项的平方。由费马小定理，最后一项$a^{p-1} \equiv 1$。若第一项$\equiv 1$，结论成立。否则，设$a^{2^{r+1}d}$是第一个$\equiv 1$的项，其中$0 \le r < s$。则$x = a^{2^rd}$满足$x^2 \equiv 1$但$x \not\equiv 1$，由于模素数时$1$只有平方根$\pm1$，所以$x \equiv -1$。
:::

::: algorithm 米勒-拉宾检验 {#alg-miller-rabin}
输入：奇数$n > 3$。记$n - 1 = 2^sd$，其中$d$为奇数。随机选取满足$2 \le a \le n - 2$的底$a$，计算$x = a^d \bmod n$。若$x \equiv \pm 1$，报告“可能是素数”。否则把$x$反复平方至多$s - 1$次；若某个平方$\equiv -1$，报告“可能是素数”；若没有，报告“合数”。用几个相互独立的底重复这一过程。
:::

由[[#thm-miller-rabin]]，素数永远不会被报告为合数。使合数$n$看起来像素数的底称为**强伪证**；迈克尔·拉宾（Michael Rabin）和路易·莫尼耶（Louis Monier）在1980年证明了：对奇合数$n$，至多四分之一的底是强伪证。所以用$k$个独立的随机底时，合数被误判为通过的概率至多为$4^{-k}$——当$k = 40$时，小于$10^{-24}$。

::: example 米勒-拉宾检验揭穿561 {#ex-miller-rabin-561}
以$a = 2$为底，对$n = 561$施行米勒-拉宾检验。
::: solution
$560 = 2^4\cdot 35$，所以$s = 4$，$d = 35$。用平方-乘算法得$2^{35} \equiv 263 \pmod{561}$。反复平方：

$$
263 \;\to\; 263^2 \equiv 166 \;\to\; 166^2 \equiv 67 \;\to\; 67^2 \equiv 1 \pmod{561} .
$$

序列$263, 166, 67, 1$未经过$-1 \equiv 560$就到达了$1$，所以$561$是合数——尽管对与它互素的每个底，它都能通过费马检验。事实上，$67$是$1$的一个不同于$\pm 1$的平方根，而$\gcd(67 - 1, 561) = 33$是$561$的一个真因数（[[#exr-7-9]]）。
:::
:::

::: quiz
在公钥为$(n, e)$的RSA中，下列哪些必须保密？（选出所有正确的选项。）
- [ ] $n$
- [ ] $e$
- [x] $d$
- [x] $\varphi(n)$
- [x] 素数$p$和$q$
::: solution
$(n, e)$是公钥。$d$、$\varphi(n)$以及分解式$p, q$中的任何一个都能用来解密：由$p, q$可以算出$\varphi(n)$，进而算出$d$；由$\varphi(n)$可以通过解一个二次方程求回$p, q$。
:::
:::

2002年，马宁德拉·阿格拉沃尔（Manindra Agrawal）、尼拉吉·卡亚尔（Neeraj Kayal）和尼廷·萨克塞纳（Nitin Saxena）实现了多项式时间的确定性素性检验。他们的AKS检验基于这样一个事实：对与$n$互素的$a$，多项式同余式$(x + a)^n \equiv x^n + a \pmod n$成立当且仅当$n$是素数。这是一个理论上的突破，但在实际中，米勒-拉宾检验（有时辅以专门的素性证明）仍是首选方法。

## 因数分解与未来

RSA的安全性依赖于分解$n = pq$的困难性。最简单的方法是试除法（大约需要$\sqrt n$步）和**费马方法**：后者依次尝试$x = \lceil\sqrt n\,\rceil, \lceil\sqrt n\,\rceil + 1, \dots$，直到$x^2 - n$是平方数为止，从而找到$n = x^2 - y^2 = (x - y)(x + y)$。当$p$和$q$彼此接近时，这一方法很快：对于玩具密钥$n = 7081$，第一次尝试$x = 85$就得到$85^2 - 7081 = 144 = 12^2$，所以立刻得出$7081 = (85 - 12)(85 + 12) = 73\cdot 97$。因此，实际的RSA素数不能太接近。现代的因数分解算法——波拉德（Pollard）ρ方法、二次筛法和一般数域筛法——比试除法快得多，但所需时间的增长仍快于位数的任何幂。

::: application 量子威胁与后量子密码
1994年，彼得·肖尔（Peter Shor）证明了大型量子计算机能够在多项式时间内分解整数和计算离散对数，这将攻破RSA和迪菲-赫尔曼密钥交换。所需规模的量子计算机目前尚不存在，但2024年8月，美国国家标准与技术研究院（NIST）发布了首批后量子密码标准，它们基于关于格和哈希函数的问题，人们相信这些问题能够抵御量子攻击。初等数论仍是当今互联网的核心，而向新体制的过渡正在进行之中。
:::

::: history
惠特菲尔德·迪菲（Whitfield Diffie）和马丁·赫尔曼（Martin Hellman）于1976年发表了《密码学的新方向》（“New Directions in Cryptography”），提出了公钥密码学和他们的密钥交换协议；拉尔夫·默克尔（Ralph Merkle）曾独立地发展出相关的思想。罗恩·李维斯特（Ron Rivest）、阿迪·沙米尔（Adi Shamir）和伦纳德·阿德尔曼（Leonard Adleman）于1977年发明了RSA，同年马丁·加德纳（Martin Gardner）在《科学美国人》（*Scientific American*）的专栏中介绍了它，使之广为人知；该专栏提出了分解一个$129$位数的挑战（这个数于1994年被分解）。后来人们才知道，英国情报机构政府通信总部（GCHQ）的詹姆斯·埃利斯（James Ellis）、克利福德·科克斯（Clifford Cocks）和马尔科姆·威廉森（Malcolm Williamson）在1970—1974年间就已发现了等价的方案，这些工作一直保密到1997年。加里·米勒（Gary Miller）于1976年在假定广义黎曼猜想成立的前提下提出了他的素性检验，迈克尔·拉宾（Michael Rabin）于1980年把它改造成了概率性的、无条件的检验。
:::

## 后续内容

椭圆曲线密码把群$(\Z/p\Z)^\times$换成有限域（[[abstract-algebra/fields-galois]]）上椭圆曲线的点构成的群，在那里离散对数似乎更难计算，从而可以使用短得多的密钥。二次剩余（[[number-theory/quadratic-reciprocity]]）给出了拉宾密码体制和索洛韦-施特拉森检验；而连分数——它在[[number-theory/diophantine]]中还用来解佩尔方程——给出了针对私钥指数较小的RSA的维纳攻击。

::: summary
- **平方-乘算法**利用$e$的二进制展开，至多用$2\log_2 e$次乘法算出$a^e \bmod n$。
- **迪菲-赫尔曼密钥交换**：公开模$p$的$g^a$和$g^b$；双方都算出$g^{ab}$。安全性依赖于离散对数问题；要防范中间人，还需要认证。
- **RSA**：$n = pq$，$ed \equiv 1 \pmod{\varphi(n)}$，加密$m \mapsto m^e$，解密$c \mapsto c^d$；对所有$m$的正确性由费马小定理和中国剩余定理得到（[[#thm-rsa]]）。
- 知道$\varphi(n)$、$d$或因数就能攻破RSA；教科书式RSA需要填充才能安全，并且$p, q$不能太接近（费马分解法）。
- **费马检验**：$a^{n-1} \not\equiv 1$证明了合数性，但卡迈克尔数（$561$、$1105$、……）能骗过每一个底；**科塞尔特判别法**：$n$是卡迈克尔数当且仅当它无平方因子，且对所有$p \mid n$都有$p - 1 \mid n - 1$。
- **米勒-拉宾检验**：素数满足$a^d \equiv 1$或$a^{2^rd} \equiv -1$；合数对一个随机底通过检验的概率至多为$1/4$。
- 肖尔的量子算法将攻破RSA和迪菲-赫尔曼密钥交换，这推动了后量子密码标准的制定。
:::

## 习题

::: exercise 数乘法次数 {level=1 check="8"}
用从左到右的平方-乘算法计算$a^{100}$，要用多少次模乘法（包括平方）？
::: solution
$100 = 1100100_2$有$7$位，其中三位是$1$。共有$6$次平方（首位之后每一位一次）和$2$次乘$a$（首位之后的两个$1$各一次），总共$8$次。
:::
:::

::: exercise 一个小型密钥交换 {level=1 check="15"}
Alice和Bob使用$p = 29$和原根$g = 2$。Alice的秘密是$a = 5$，Bob的秘密是$b = 11$。他们的共享密钥是什么？
::: solution
Alice发送$A = 2^5 = 32 \equiv 3$；Bob发送$B = 2^{11} = 2048 = 70\cdot 29 + 18 \equiv 18$。密钥是$K = B^a = 18^5 \bmod 29$。由于$18^2 = 324 \equiv 5$，$18^4 \equiv 25$，所以$18^5 \equiv 25\cdot 18 = 450 = 15\cdot 29 + 15 \equiv 15$。Bob得到同样的结果：$3^{11} \equiv 15 \pmod{29}$。所以$K = 15$。
:::
:::

::: exercise 一个解密指数 {level=1 check="27"}
对于$p = 5$，$q = 11$，$e = 3$的RSA，求$d$。
::: solution
$\varphi(55) = 4\cdot 10 = 40$，我们需要$3d \equiv 1 \pmod{40}$：$3\cdot 27 = 81 = 2\cdot 40 + 1$，所以$d = 27$。
:::
:::

::: exercise 用小密钥加密 {level=2 check="13"}
使用上一题的密钥（$n = 55$，$e = 3$，$d = 27$）加密$m = 7$，并验证解密后恢复出$7$。
::: solution
$c = 7^3 = 343 = 6\cdot 55 + 13$，所以$c = 13$。解密时计算$13^{27} \bmod 55$。模$5$：$13 \equiv 3$，$3^4 \equiv 1$，所以$3^{27} \equiv 3^3 = 27 \equiv 2$。模$11$：$13 \equiv 2$，$2^{10} \equiv 1$，所以$2^{27} \equiv 2^7 = 128 \equiv 7$。满足$\equiv 2 \pmod 5$且$\equiv 7 \pmod{11}$的剩余是$7$。所以解密得到$m = 7$。
:::
:::

::: exercise 另一个卡迈克尔数 {level=2}
用科塞尔特判别法证明$1105$是卡迈克尔数。
::: solution
$1105 = 5\cdot 13\cdot 17$无平方因子，且$1104 = 2^4\cdot 3\cdot 23$。数$p - 1 = 4, 12, 16$都整除$1104$（$1104 = 4\cdot 276 = 12\cdot 92 = 16\cdot 69$）。由[[#thm-korselt]]，$1105$是卡迈克尔数。
:::
:::

::: exercise 费马分解法 {level=2 check="47"}
用费马方法分解$2491$，并填入较小的因数。
::: solution
$\sqrt{2491} \approx 49.9$，所以从$x = 50$开始：$50^2 - 2491 = 9 = 3^2$。因此$2491 = 50^2 - 3^2 = (50 - 3)(50 + 3) = 47\cdot 53$。
:::
:::

::: exercise φ(n)泄露因数 {level=2}
某个RSA模数为$n = 3127$，而你得知$\varphi(n) = 3016$。分解$n$。
::: solution
$p + q = n - \varphi(n) + 1 = 3127 - 3016 + 1 = 112$，$pq = 3127$，所以$p, q$是$x^2 - 112x + 3127 = 0$的根：$x = \frac{112 \pm\sqrt{12544 - 12508}}{2} = \frac{112\pm 6}{2}$，即$59$和$53$。验算：$53\cdot 59 = 3127$。
:::
:::

::: exercise 卡迈克尔数至少有三个素因数 {level=3}
证明每个卡迈克尔数都是奇数，并且至少有三个素因数。
::: solution
奇数性已在[[#thm-korselt]]的证明中证明过（取$a = -1$）。由科塞尔特判别法，$n$无平方因子。假设$n = pq$，其中$p < q$是素数。则$q - 1 \mid n - 1 = pq - 1 = p(q - 1) + (p - 1)$，所以$q - 1 \mid p - 1$。但$0 < p - 1 < q - 1$，矛盾。素数不是合数，所以$n$至少有三个素因数。
:::
:::

::: exercise 1的平方根给出因数 {level=3}
设$x^2 \equiv 1 \pmod n$，但$x \not\equiv \pm 1 \pmod n$。证明$\gcd(x - 1, n)$是$n$的一个大于$1$的真因数。把这一结论应用于[[#ex-miller-rabin-561]]。
::: solution
$n \mid x^2 - 1 = (x - 1)(x + 1)$，但$n \nmid x - 1$且$n \nmid x + 1$。若$\gcd(x - 1, n) = 1$，则由[[number-theory/divisibility#thm-coprime-divides]]得$n \mid x + 1$，矛盾；所以这个最大公因数大于$1$。若$\gcd(x - 1, n) = n$，则$n \mid x - 1$，同样矛盾。所以$1 < \gcd(x-1, n) < n$。对$n = 561$和$x = 67$：$\gcd(66, 561) = 33$，由此得$561 = 33\cdot 17$。（这就是为什么一次未通过的米勒-拉宾检验常常能顺带给出一个因数。）
:::
:::

::: exercise 为什么e必须与φ(n)互素 {level=3}
设$n = pq$，其中$p, q$是不同的奇素数。证明：若$\gcd(e, \varphi(n)) > 1$，则$m \mapsto m^e \bmod n$不是单射，因而RSA解密是不可能的。
::: hint
若素数$r$同时整除$e$和$p - 1$，求满足$x^r \equiv 1 \pmod p$的$x \not\equiv 1 \pmod p$。
:::
::: solution
设$r$是整除$\gcd(e, (p-1)(q-1))$的素数；不妨设$r \mid p - 1$（否则交换$p$与$q$）。设$g$是模$p$的原根，令$x = g^{(p-1)/r}$，它的阶为$r$，所以$x \not\equiv 1$但$x^r \equiv 1 \pmod p$，从而$x^e \equiv 1 \pmod p$。由中国剩余定理，选取$m$使$m \equiv x \pmod p$且$m \equiv 1 \pmod q$。则$m \not\equiv 1 \pmod n$，但$m^e \equiv 1$对模$p$和模$q$都成立，所以$m^e \equiv 1 = 1^e \pmod n$。两个不同的消息$m$和$1$有相同的密文。
:::
:::
