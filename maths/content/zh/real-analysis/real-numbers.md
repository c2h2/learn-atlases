微积分作出了一些信心十足的承诺。一个连续函数如果在某一点处为负、在另一点处为正，那么它在两点之间的某处必定为零。一个永远不超过$10$的递增数列必定会稳定到一个极限。闭区间上的连续函数能取到最大值。这些承诺没有一个仅仅关乎函数本身：每一个都依赖于函数所在的数系。

为了看清这一点，不妨暂且假设世上只有有理数$\Q$。函数$f(x) = x^2 - 2$是$\Q$上一个完全正常的连续函数；它满足$f(1) = -1 < 0$和$f(2) = 2 > 0$，然而不存在有理数$x$使$f(x) = 0$，因为（我们将在下面证明）没有哪个分数的平方等于$2$。从两边向这个“根”逼近，就能看出问题出在哪里：

| $x$ | $1.4$ | $1.41$ | $1.414$ | $1.4142$ |
|---|---|---|---|---|
| $x^2$ | $1.96$ | $1.9881$ | $1.999396$ | $1.99996164$ |

| $x$ | $1.5$ | $1.42$ | $1.415$ | $1.4143$ |
|---|---|---|---|---|
| $x^2$ | $2.25$ | $2.0164$ | $2.002225$ | $2.00024449$ |

有理数从两侧向一个点逼近，而那个点上什么也没有。$f$在$\Q$上的图像是从一个洞中穿过坐标轴的。所以介值定理在$\Q$上**不成立**，它的任何证明都必须用到$\R$具有而$\Q$不具有的某种性质。

这一性质就是**完备性**，本章讨论的正是它。我们用公理来描述$\R$——熟悉的算术运算法则和序的法则，再加上一条——然后从这条额外的公理推出整个分析学赖以建立的那些事实：上确界的存在性、阿基米德性质、有理数的稠密性、区间套定理以及$\R$的不可数性。

## 有空隙的数系

人们发现的第一个空隙至今仍是最好的例子。我们采用约定$\N = \set{1, 2, 3, \dots}$，这一约定贯穿整个课程。

::: theorem √2是无理数 {#thm-sqrt2-irrational}
不存在有理数$x$使得$x^2 = 2$。
:::

::: proof
用反证法。假设$x = p/q$，其中$p, q \in \Z$，$q \ge 1$，且$x^2 = 2$。约去公因数后，可以假定$p$与$q$不全为偶数。由$p^2 = 2q^2$可知$p^2$是偶数。奇数的平方是奇数（$(2k+1)^2 = 2(2k^2 + 2k) + 1$），所以$p$本身是偶数，设$p = 2r$。于是$4r^2 = 2q^2$，从而$q^2 = 2r^2$是偶数，由同样的论证，$q$也是偶数。这样$p$与$q$都是偶数，与我们的选取矛盾。因此这样的$x$不存在。
:::

类似的论证表明$\sqrt3$、$\sqrt5$和$\sqrt[3]{2}$都是无理数；一般地，除非$n$是完全平方数，否则$\sqrt{n}$是无理数，这是因子分解唯一性的推论（[[number-theory/primes]]）。有理数虽然密密麻麻地挤在一起，却处处是洞：任意两个有理数$a < b$之间还有另一个有理数$(a+b)/2$，从而有无穷多个。“稠密”与“没有空隙”是两种不同的性质，而分析学需要的是后者。

::: intuition “没有空隙”应当是什么意思
想象用一把刀切开数轴。在$\R$中，刀总会切在一个数上：要么左边那段有最大元素，要么右边那段有最小元素。在$\Q$中，我们可以在$\sqrt2$处下刀——把满足$x < 0$或$x^2 < 2$的每个有理数$x$都放在左边——这时左边那段没有最大元素，右边那段也没有最小元素。下面的完备性公理把“刀总会切在一个数上”转化为一个关于上界的命题，使我们能在证明中使用它。
:::

## 有序域

我们在代数中对实数所做的一切运算，都可以从一小组法则推出。值得把它们完整地写一次，因为它们恰好是$\Q$与$\R$的共同之处。

::: definition 有序域 {#def-ordered-field}
**域**是一个带有加法和乘法两种运算的集合$F$，使得对所有$x, y, z \in F$：

1. $x + y = y + x$，$(x + y) + z = x + (y + z)$，存在元素$0$使$x + 0 = x$，并且每个$x$都有负元$-x$，使$x + (-x) = 0$；
2. $xy = yx$，$(xy)z = x(yz)$，存在元素$1 \neq 0$使$1x = x$，并且每个$x \neq 0$都有逆元$x^{-1} = 1/x$，使$x x^{-1} = 1$；
3. $x(y + z) = xy + xz$。

**有序域**是带有一个关系$<$的域，使得对所有$x, y, z \in F$：

4. （三歧性）$x < y$、$x = y$、$y < x$三者中恰有一个成立；
5. （传递性）若$x < y$且$y < z$，则$x < z$；
6. 若$x < y$，则$x + z < y + z$；
7. 若$x < y$且$0 < z$，则$xz < yz$。
:::

我们用$x \le y$表示“$x < y$或$x = y$”，用$y > x$表示$x < y$；若$x > 0$，则称$x$是**正的**。$\Q$和$\R$都是有序域。复数构成一个根本无法定序的域（[[#exr-1-5]]），任何有限域也都无法定序。

处理不等式时所有熟悉的法则都可以从公理4–7推出。下面是我们最常用的几条；把它们推导一遍，就能看出这些公理是如何使用的。

::: proposition 不等式的运算法则 {#prop-order}
在任何有序域中：

1. $x > 0$当且仅当$-x < 0$；
2. 若$x \neq 0$，则$x^2 > 0$；特别地，$1 > 0$；
3. 若$x < y$且$z < 0$，则$xz > yz$；
4. 若$0 < x < y$，则$0 < 1/y < 1/x$。
:::

::: proof
(1) 若$x > 0$，两边同加$-x$（公理6）得$0 + (-x) < x + (-x)$，即$-x < 0$。反之，若$-x < 0$，两边同加$x$得$0 < x$。

(2) 若$x > 0$，在公理7中取$z = x$得$x\cdot x > 0\cdot x = 0$。若$x < 0$，则由(1)得$-x > 0$，再由第一种情形得$x^2 = (-x)^2 > 0$。由于$1 \neq 0$且$1 = 1^2$，得$1 > 0$。

(3) 由$z < 0$及(1)得$-z > 0$，于是由公理7得$x(-z) < y(-z)$，即$-xz < -yz$。两边同加$xz + yz$（公理6）得$yz < xz$。

(4) 首先，$1/x > 0$：它不为零（因为$x\cdot(1/x) = 1 \neq 0$），而如果它是负的，那么在公理7中取$z = x > 0$将得到$1 = (1/x)\,x < 0\cdot x = 0$，与(2)矛盾。同理$1/y > 0$，所以由公理7，$(1/x)(1/y) > 0$。用这个正数乘$x < y$的两边，得$1/y < 1/x$。
:::

$x$的**绝对值**定义为：当$x \ge 0$时$\abs{x} = x$，当$x < 0$时$\abs{x} = -x$。它满足$\abs{x} \ge 0$，$\abs{xy} = \abs{x}\,\abs{y}$以及$-\abs{x} \le x \le \abs{x}$；并且当$a \ge 0$时，不等式$\abs{x} \le a$等价于$-a \le x \le a$。我们把$\abs{x - y}$看作$x$与$y$之间的**距离**；下面的不等式是说，绕道永远不会缩短路程。

::: theorem 三角不等式 {#thm-triangle}
对有序域中的所有$x, y$，

$$
\abs{x + y} \le \abs{x} + \abs{y} \qquad\text{以及}\qquad \bigl\lvert \abs{x} - \abs{y} \bigr\rvert \le \abs{x - y}.
$$
:::

::: proof
把$-\abs{x} \le x \le \abs{x}$与$-\abs{y} \le y \le \abs{y}$相加，得$-(\abs{x} + \abs{y}) \le x + y \le \abs{x} + \abs{y}$，这就是第一个不等式。对于第二个不等式，把第一个不等式应用于$x = (x - y) + y$：$\abs{x} \le \abs{x - y} + \abs{y}$，所以$\abs{x} - \abs{y} \le \abs{x - y}$。交换$x$与$y$得$\abs{y} - \abs{x} \le \abs{y - x} = \abs{x - y}$。两者合起来就是$\bigl\lvert\abs{x} - \abs{y}\bigr\rvert \le \abs{x-y}$。
:::

写成$\abs{a - c} \le \abs{a - b} + \abs{b - c}$的形式（令$x = a - b$，$y = b - c$）后，三角不等式是分析学中用得最多的一个不等式。还有一条小原理经常用来证明两个数相等。

::: lemma ε原理 {#lem-eps-principle}
若对每个$\eps > 0$都有$a \le b + \eps$，则$a \le b$。因此，若对每个$\eps > 0$都有$\abs{x - y} < \eps$，则$x = y$。
:::

::: proof
假设相反，$a > b$，取$\eps = (a - b)/2 > 0$（注意$2 = 1 + 1 > 0$）。那么$b + \eps = (a + b)/2 < a$，因为$a + b < 2a$等价于$b < a$。这与假设矛盾。对于第二个结论，由对所有$\eps>0$都有$\abs{x-y} \le 0 + \eps$得$\abs{x - y} \le 0$，所以$x = y$。
:::

## 上确界与下确界

一个数集可以有最大元素，如$\set{1, 2, 3}$；也可以没有最大元素，却仍被限制在某个数之下，如区间$(0, 1)$；还可以是无界的，如$\N$。驾驭中间这种情形的概念是最小上界。

::: definition 上界、上确界与下确界 {#def-sup}
设$A$是有序域的一个子集。

- 若对每个$a \in A$都有$a \le M$，则称数$M$是$A$的一个**上界**；若$A$有上界，则称$A$**有上界**。
- 若 (i) $s$是$A$的上界，并且 (ii) 对$A$的每个上界$M$都有$s \le M$，则称数$s$是$A$的**上确界**或**最小上界**，记作$s = \sup A$。
- 把不等号反向，可以同样地定义**下界**、**有下界**以及**下确界**或**最大下界**$\inf A$。

若$A$既有上界又有下界，则称$A$**有界**。若$\sup A$属于$A$，则称它为$A$的**最大值**，记作$\max A$；类似地，当$\inf A \in A$时，称它为最小值，记作$\min A = \inf A$。
:::

一个集合至多有一个上确界：如果$s$和$s'$都符合条件，那么两者都是上界，并且都不超过任何一个上界，所以$s \le s'$且$s' \le s$。上确界不一定属于该集合，而这正是关键所在——它描述的是一个可能没有顶端元素的集合的“上边缘”。条件(ii)很难直接验证，因为它同时涉及所有的上界；实际中我们使用下面这个等价的表述。

::: lemma 逼近性质 {#lem-sup-approx}
设$s$是集合$A$的一个上界。则$s = \sup A$当且仅当对每个$\eps > 0$，存在元素$a \in A$使得$a > s - \eps$。

类似地，若$m$是$A$的一个下界，则$m = \inf A$当且仅当对每个$\eps > 0$，存在$a \in A$使得$a < m + \eps$。
:::

::: proof
设$s = \sup A$，并设$\eps > 0$。由于$s - \eps < s$，而$s$是**最小**上界，所以$s - \eps$不是$A$的上界；于是某个$a \in A$满足$a > s - \eps$。

反之，设该条件成立，并设$M$是$A$的任一上界。若$M < s$，令$\eps = s - M > 0$；由该条件，存在$a \in A$使$a > s - \eps = M$，这与$M$是上界矛盾。因此对每个上界$M$都有$M \ge s$，从而$s = \sup A$。关于下确界的结论可以同样证明，只需把所有不等号反向。
:::

用文字来说：$A$中没有任何元素在$s$之上，但$A$中的元素可以从下方任意接近$s$。

::: example 开区间 {#ex-sup-interval}
设$A = (0, 1) = \set{x : 0 < x < 1}$。证明$\sup A = 1$，$\inf A = 0$，并且$A$既没有最大值也没有最小值。
::: solution
每个$a \in A$都满足$a < 1$，所以$1$是一个上界。设$\eps > 0$。若$\eps \ge 1$，则元素$a = \tfrac12$满足$a > 0 \ge 1 - \eps$。若$\eps < 1$，取$a = 1 - \eps/2$；则$0 < a < 1$，所以$a \in A$，并且$a > 1 - \eps$。由[[#lem-sup-approx]]，$\sup A = 1$。

由于$1 \notin A$，这个上确界不是最大值。事实上，没有哪个元素$m \in A$是最大的：中点$(m+1)/2$也在$A$中，并且大于$m$。$\inf A = 0$的论证与此对称：$0$是一个下界，并且当$0 < \eps < 1$时，元素$\eps/2 \in A$满足$\eps/2 < 0 + \eps$（当$\eps \ge 1$时用$\tfrac12$）。
:::
:::

::: example 上确界的可加性 {#ex-sup-sum}
设$A$和$B$是有上确界的非空集合，令$A + B = \set{a + b : a \in A,\ b \in B}$。证明$\sup(A + B) = \sup A + \sup B$。
::: solution
记$\alpha = \sup A$，$\beta = \sup B$。对$a \in A$和$b \in B$，有$a \le \alpha$和$b \le \beta$，所以$a + b \le \alpha + \beta$：因此$\alpha + \beta$是$A + B$的一个上界。

设$\eps > 0$。对$\eps/2$应用[[#lem-sup-approx]]，存在$a \in A$使$a > \alpha - \eps/2$，以及$b \in B$使$b > \beta - \eps/2$。于是$a + b \in A + B$，并且

$$
a + b > (\alpha - \tfrac{\eps}{2}) + (\beta - \tfrac{\eps}{2}) = (\alpha + \beta) - \eps.
$$

再由[[#lem-sup-approx]]，$\sup(A + B) = \alpha + \beta$。把$\eps$分成两半、每个集合各用一半，这种手法你在下一章几乎每个证明中都会遇到。
:::
:::

::: quiz
设$A = \set{x \in \R : x^2 < 4}$。下列哪个说法正确？
- [ ] $\sup A = 2$，并且$2$是$A$的最大值
- [x] $\sup A = 2$，并且$A$没有最大值
- [ ] $\sup A = 4$
- [ ] $A$没有上界
::: solution
$x^2 < 4$意味着$-2 < x < 2$，所以$A$是开区间$(-2, 2)$。与[[#ex-sup-interval]]完全一样，$2$是一个上界，并且$A$中的点可以任意接近它，所以$\sup A = 2$；但$2 \notin A$，所以没有最大值。数$4$是一个上界，但不是**最小**上界。
:::
:::

## 完备性公理

到目前为止，还没有任何东西能区分$\R$与$\Q$。区别它们的是一条公理。

::: axiom 完备性（确界原理） {#ax-completeness}
$\R$的每个有上界的非空子集在$\R$中都有上确界。
:::

**完备有序域**是这样一个有序域：其中每个有上界的非空集合都有上确界。我们以“**$\R$是一个完备有序域**”作为出发点：它满足[[#def-ordered-field]]中的公理以及[[#ax-completeness]]。本课程的每个定理都是从这些公理推出的。

::: remark 这样的域存在吗？它唯一吗？
这两个问题的答案都正如人们所期望的那样。完备有序域可以从$\Q$出发**构造**出来。在戴德金（Dedekind）的构造中，一个实数就是一个“分割”：即一个没有最大元素的非空集合$L \subsetneq \Q$，满足由$q \in L$和$p < q$可推出$p \in L$（可以把$L$想象成位于这个数左边的全体有理数）。分割按自然的方式相加和相乘，$L \le L'$的意思是$L \subseteq L'$，而一族有界的分割的上确界就是它们的并——这正是完备性在这里变得容易证明的原因。康托尔（Cantor）的另一种构造使用有理数的柯西列。此外，任意两个完备有序域都通过唯一一个保持加法、乘法和序的双射而同构，所以这些公理完整地刻画了$\R$。完整的细节见斯皮瓦克（Spivak）《微积分》（*Calculus*）的最后几章，以及陶哲轩（Tao）《分析I》（*Analysis I*）的第5章。
:::

关于上确界的完备性蕴涵关于下确界的完备性：我们不需要另立一条公理。

::: corollary 下确界的存在性 {#cor-inf}
每个有下界的非空子集$A \subseteq \R$都有下确界，并且$\inf A = -\sup(-A)$，其中$-A = \set{-a : a \in A}$。
:::

::: proof
若$m$是$A$的一个下界，则$-m$是$-A$的一个上界（因为由$a \ge m$可得$-a \le -m$），并且$-A$非空。由[[#ax-completeness]]，$s = \sup(-A)$存在。对每个$a \in A$有$-a \le s$，所以$a \ge -s$：因此$-s$是$A$的一个下界。若$m$是$A$的任一下界，则$-m$是$-A$的上界，所以$s \le -m$，即$m \le -s$。因此$-s$是最大下界：$\inf A = -s$。
:::

现在我们可以填补开头发现的那个空隙了。这个证明是运用完备性的一个范例：定义一个集合，取它的上确界，再通过排除其他一切可能来证明这个上确界正是我们想要的。

::: theorem √2的存在性 {#thm-sqrt2}
恰有一个正实数$s$满足$s^2 = 2$。
:::

::: proof
我们要用到如下事实：对正数而言，由$0 < x < y$可推出$x^2 < xy < y^2$。

令$A = \set{x \in \R : x > 0 \text{ 且 } x^2 < 2}$。则$1 \in A$，所以$A \neq \varnothing$。又，$2$是$A$的一个上界：若$x \ge 2$，则$x^2 \ge 4 > 2$，所以$x \notin A$。由完备性公理，$s = \sup A$存在，且$s \ge 1 > 0$。我们来证明$s^2 < 2$和$s^2 > 2$都是不可能的。

**假设$s^2 < 2$。**我们来找$h > 0$使得$(s + h)^2 < 2$。当$0 < h \le 1$时有$h^2 \le h$，所以

$$
(s + h)^2 = s^2 + 2sh + h^2 \le s^2 + h(2s + 1).
$$

取$h = \tfrac12\min\bigl(1, \tfrac{2 - s^2}{2s+1}\bigr)$。则$0 < h \le 1$，且$h(2s+1) \le \tfrac12(2 - s^2) < 2 - s^2$，所以$(s+h)^2 < 2$。于是$s + h \in A$，而$s + h > s$——这与$s$是$A$的上界矛盾。

**假设$s^2 > 2$。**令$h = \dfrac{s^2 - 2}{2s} > 0$。则$h < \dfrac{s^2}{2s} = \dfrac{s}{2}$，所以$s - h > 0$，并且

$$
(s - h)^2 = s^2 - 2sh + h^2 > s^2 - 2sh = s^2 - (s^2 - 2) = 2.
$$

这时$s - h$是$A$的一个上界：如果某个$x \in A$满足$x > s - h > 0$，那么$x^2 > (s-h)^2 > 2$，与$x \in A$矛盾。但$s - h < s$，这与$s$是**最小**上界矛盾。

由三歧性，$s^2 = 2$。至于唯一性，若$s, t > 0$且$s^2 = t^2 = 2$，则$0 = s^2 - t^2 = (s - t)(s + t)$，其中$s + t > 0$，所以$s = t$。
:::

我们把这个数记作$\sqrt2$。同样的方法可以对每个$a > 0$和$n \in \N$得到$\sqrt[n]{a}$（[[#exr-1-10]]）。回顾这个证明，注意两种情形只用到了有序域公理；完备性只出场了一次，用来保证$s$存在。这一观察证明了$\Q$不是完备的。

::: example 有理数域不是完备的 {#ex-q-incomplete}
令$B = \set{x \in \Q : x > 0 \text{ 且 } x^2 < 2}$。证明$B$是$\Q$的一个非空子集，在$\Q$中有上界，但在$\Q$中没有上确界。
::: solution
$1 \in B$，并且与前面一样，$2$是一个有理上界。假设$r \in \Q$是$B$在有理数中的最小上界。把[[#thm-sqrt2]]的证明中的$s$换成$r$，重走一遍。若$r^2 < 2$，则数$h = \tfrac12\min\bigl(1, \tfrac{2-r^2}{2r+1}\bigr)$是**有理数**，所以$r + h$是$B$中一个大于$r$的有理元素——这不可能。若$r^2 > 2$，则$h = (r^2 - 2)/(2r)$是有理数，而$r - h$是$B$的一个小于$r$的**有理**上界——这也不可能。所以$r^2 = 2$，这与[[#thm-sqrt2-irrational]]矛盾。因此$B$在$\Q$中没有上确界。（当然，在$\R$中$\sup B = \sqrt2$：见下面的小测验。）
:::
:::

::: warning 有界集不一定包含它的上确界
完备性公理保证的是$\sup A$**存在**，而不是它属于$A$。不要写“令$a = \sup A$为$A$中的一个元素”——对$A = (0, 1)$来说这是错的。当你需要$A$中一个靠近上确界的元素时，请用[[#lem-sup-approx]]：对每个$\eps > 0$，存在$a \in A$使$\sup A - \eps < a \le \sup A$。此外，这条公理的两个前提缺一不可：空集没有上确界（每个实数都是$\varnothing$的上界，而其中没有最小的），$\N$也没有上确界，因为它没有上界。
:::

## 阿基米德性质与稠密性

我们的下一个推论听起来显然得似乎无需证明：自然数没有上界。但它确实需要证明，而且证明需要用到完备性——有些有序域中它并不成立（见下面的注记）。

::: theorem 阿基米德性质 {#thm-archimedean}
$\N$在$\R$中没有上界。等价地：

1. 对每个$x \in \R$，存在$n \in \N$使$n > x$；
2. 对每个$\eps > 0$，存在$n \in \N$使$1/n < \eps$。
:::

::: proof
假设$\N$有上界。由于$\N$非空，由完备性公理得$s = \sup\N$存在。数$s - 1$小于$s$，所以它不是$\N$的上界：存在$n \in \N$使$n > s - 1$。但这样一来$n + 1 \in \N$且$n + 1 > s$，与$s$是上界矛盾。所以$\N$无上界，这就是命题1。

对于命题2，设$\eps > 0$，对$x = 1/\eps$应用命题1：存在$n \in \N$使$n > 1/\eps > 0$，再由[[#prop-order]](4)得$1/n < \eps$。
:::

::: remark 非阿基米德域
阿基米德性质不能仅由有序域公理推出。考虑由有理函数$p(t)/q(t)$构成的域$\R(t)$，当$p$与$q$的首项系数同号时，称这样的函数为正的。这使$\R(t)$成为一个有序域，在其中对每个$n \in \N$，$t - n$都是正的：元素$t$是“无穷大”，而$1/t$是一个比每个$1/n$都小的正“无穷小”。由[[#thm-archimedean]]，这样的域不可能是完备的。
:::

正是阿基米德性质使我们能够断言“对每个$n$都有$\abs{x} < 1/n$，所以$x = 0$”——这一步把它与[[#lem-eps-principle]]结合起来，今后我们将把它视为理所当然。它还能给出许多上确界和下确界的精确值。

::: example 有最大值但没有最小值的集合 {#ex-sup-alternating}
设$A = \set{(-1)^n + \tfrac1n : n \in \N}$。求$\sup A$和$\inf A$，并判断它们是否能取到。
::: solution
前几个元素是$0, \tfrac32, -\tfrac23, \tfrac54, -\tfrac45, \tfrac76, \dots$。当$n$为偶数时，元素为$1 + \tfrac1n \le 1 + \tfrac12 = \tfrac32$，等号在$n = 2$时成立；当$n$为奇数时，元素为$-1 + \tfrac1n \le 0$。所以$\tfrac32$是属于$A$的一个上界：$\sup A = \max A = \tfrac32$。

每个元素都大于$-1$：下标为奇数的元素为$-1 + \tfrac1n > -1$，下标为偶数的元素大于$1$。所以$-1$是一个下界。给定$\eps > 0$，由阿基米德性质，存在$m \in \N$使$1/m < \eps$；于是$n = 2m + 1$是奇数，并且$-1 + \tfrac1n < -1 + \tfrac1m < -1 + \eps$。由[[#lem-sup-approx]]，$\inf A = -1$。它取不到，因为每个元素都严格大于$-1$。
:::
:::

::: widget sequence
a: 1 - 1/n
N: 40
limit: 1
epsilon: 0.1
y: 0, 1.1
caption: 集合$\set{1 - 1/n : n \in \N}$的上确界是$1$，但集合永远达不到它。把$\eps$拖小：无论$1$下方的带形多么窄，集合中总有一些点进入其中——这就是逼近性质[[#lem-sup-approx]]。第一个进入的下标是满足$1/n < \eps$的第一个$n$，而阿基米德性质恰好保证了这样的$n$存在。
:::

::: example 为什么0.999…等于1 {#ex-decimal}
无限小数$0.999\ldots$是什么意思？它为什么等于$1$？
::: solution
无限小数$0.d_1 d_2 d_3 \ldots$被**定义**为它的各个有限截断$0.d_1\ldots d_n$的上确界；这个集合以$1$为上界，所以由完备性，上确界存在。对于$0.999\ldots$，截断为$t_n = 1 - 10^{-n}$，所以我们要证明$\sup\set{1 - 10^{-n} : n \in \N} = 1$。

显然$1$是一个上界。设$\eps > 0$。由阿基米德性质，存在$n$使$1/n < \eps$，而$10^n \ge n$（由归纳法：$10^{n+1} = 10\cdot 10^n \ge 10n \ge n + 1$），所以$10^{-n} \le 1/n < \eps$，从而$t_n > 1 - \eps$。由[[#lem-sup-approx]]，上确界为$1$。所以$0.999\ldots$和$1$是同一个实数的两个名字——这不是近似，而是恒等。
:::
:::

任意两个实数之间，无论它们多么接近，都有一个有理数。正因如此，我们才能用分数来逼近实数（计算机则用有限的二进制小数来逼近它们）。

::: theorem 有理数的稠密性 {#thm-q-dense}
若$a, b \in \R$且$a < b$，则存在有理数$q$使$a < q < b$。
:::

::: proof
由阿基米德性质，取$n \in \N$使$1/n < b - a$。我们要找一个整数$m$使$a < m/n < b$，即$na < m < nb$；由于$nb - na > 1$，区间$(na, nb)$的长度大于$1$，理应包含一个整数。

令$S = \set{k \in \Z : k > na}$。由阿基米德性质，$S$非空；并且$S$有下界：取$j \in \N$使$j > -na$，则每个$k \in S$都满足$k > na > -j$。有下界的非空整数集有最小元素（这就是良序原理，它与归纳法等价：见[[proofs/induction]]）。设$m$是$S$的最小元素。则$m > na$，而由$m - 1 \notin S$得$m - 1 \le na$。因此

$$
na < m \le na + 1 < na + n(b - a) = nb,
$$

两边除以$n$，得$a < m/n < b$。取$q = m/n$即可。
:::

无理数也是稠密的：任意两个实数之间都有一个无理数（[[#exr-1-7]]）。所以$\Q$和$\R \setminus \Q$都散布在每一个区间之中，无论区间多么短——这一事实将在[[real-analysis/continuity]]中产生一些引人注目的函数。

::: quiz
设$B = \set{x \in \Q : x > 0,\ x^2 < 2}$，即[[#ex-q-incomplete]]中的集合，现在把它看作$\R$的子集。$\sup B$是多少？
- [x] $\sqrt2$
- [ ] 不存在，因为$\sqrt2$不是有理数
- [ ] $1.4142$
- [ ] $2$
::: solution
$\sqrt2$是一个上界：若$x > 0$且$x \ge \sqrt2$，则$x^2 \ge 2$。给定$\eps > 0$（不妨设$\eps < \sqrt2$），由[[#thm-q-dense]]，存在有理数$q$使$\sqrt2 - \eps < q < \sqrt2$；于是$q > 0$且$q^2 < 2$，所以$q \in B$。由[[#lem-sup-approx]]，$\sup B = \sqrt2$。这个上确界在$\R$中存在，尽管它不在$\Q$中——这恰恰就是完备性所填补的空隙。
:::
:::

## 区间套与不可数性

完备性有一个很有用的几何形式：一列不断收缩的闭区间总能套住至少一个点。

::: theorem 区间套定理 {#thm-nested-intervals}
对每个$n \in \N$，设$I_n = [a_n, b_n]$是一个有界闭区间（$a_n \le b_n$），并设$I_1 \supseteq I_2 \supseteq I_3 \supseteq \cdots$。则$\bigcap_{n=1}^\infty I_n \neq \varnothing$。如果还满足：对每个$\eps > 0$，有某个区间的长度$b_n - a_n < \eps$，那么这个交恰好由一个点组成。
:::

::: proof
区间相套意味着$a_1 \le a_2 \le a_3 \le \cdots$和$b_1 \ge b_2 \ge b_3 \ge \cdots$，并且对每个$n$有$a_n \le b_n$。首先，每个左端点都不超过每个右端点：若$m \le n$，则$a_m \le a_n \le b_n$；若$m > n$，则$a_m \le b_m \le b_n$。所以集合$A = \set{a_m : m \in \N}$非空，并且每个$b_n$都是它的上界。令$x = \sup A$，由完备性它存在。于是，由于$x$是$A$的上界，对所有$n$有$a_n \le x$；又由于$x$是**最小**上界而每个$b_n$都是上界，对所有$n$有$x \le b_n$。因此对每个$n$都有$x \in I_n$。

若$x$和$y$都属于每个$I_n$，则对每个$n$有$\abs{x - y} \le b_n - a_n$。在附加假设下，对每个$\eps > 0$，可以取$n$使$b_n - a_n < \eps$，所以对每个$\eps > 0$有$\abs{x - y} < \eps$，由[[#lem-eps-principle]]得$x = y$。
:::

::: warning “闭”和“有界”都不可少
开区间$(0, \tfrac1n)$是相套的，但没有一个实数属于所有这些区间：一个公共点$x$将对每个$n$满足$0 < x < 1/n$，这与阿基米德性质矛盾。闭但无界的区间$[n, \infty)$也是相套的，而它们的交同样为空。而在$\Q$中，即使对有界闭区间，定理也不成立：通过二分逼近$\sqrt2$所得到的有理区间没有公共的有理点。
:::

解方程的二分法就是区间套定理的实际应用。从一个使$f(x) = x^2 - 2$变号的区间$[a_1, b_1]$出发；每一步检验中点，保留符号仍然改变的那一半。

::: widget newton
f: x^2 - 2
method: bisection
x0: 1
x1: 2
steps: 8
x: 0.8, 2.2
caption: 在$[1, 2]$上对$x^2 - 2$使用二分法。逐步执行迭代：每个区间都是前一个区间的一半，并且仍包含一次变号，所以这些区间是相套的，长度为$2^{-n}$。[[#thm-nested-intervals]]表明它们恰好收缩到一个实数——$\sqrt2$。在$\Q$中执行同样的过程，这些区间收缩到的地方什么也没有。
:::

::: application 计算机上的二分法
区间套定理是[[numerical-analysis/root-finding]]中二分法背后的理论保证。每一步都把区间减半，因而精度增加一个二进制位：从$[1, 2]$出发，经过$50$步后区间长度为$2^{-50} \approx 8.9\times10^{-16}$，大约就是双精度运算的精度。与牛顿法相比，这种方法很慢，但一旦找到了变号，它就不会失败——这种稳健性归根结底来自$\R$的完备性以及[[real-analysis/continuity]]中的介值定理。
:::

我们的最后一个定理表明，完备性使$\R$比$\Q$大得多。回忆[[proofs/cardinality]]：如果一个集合的元素可以排成一个有限或无限的序列$x_1, x_2, x_3, \dots$，就称这个集合是**可数的**；并且$\Q$是可数的。

::: theorem 实数集不可数 {#thm-r-uncountable}
对每个实数列$x_1, x_2, x_3, \dots$，都存在一个实数$x$，它与每个$x_n$都不同。因此$\R$不可数。
:::

::: proof
我们构造一列有界闭区间$I_1 \supseteq I_2 \supseteq \cdots$，每个区间的长度都为正，并且$x_n \notin I_n$。

令$I_1 = [x_1 + 1, x_1 + 2]$，它不包含$x_1$。假设已经选好了$I_n = [a_n, b_n]$，其中$a_n < b_n$，令$\ell = b_n - a_n > 0$。两端的闭三分之一段

$$
J = \bigl[a_n,\ a_n + \tfrac{\ell}{3}\bigr] \qquad\text{和}\qquad K = \bigl[a_n + \tfrac{2\ell}{3},\ b_n\bigr]
$$

互不相交，所以$x_{n+1}$至多属于其中一个。令$I_{n+1}$为$J$、$K$中不包含$x_{n+1}$的一个。则$I_{n+1} \subseteq I_n$，它的长度$\ell/3$为正，并且$x_{n+1} \notin I_{n+1}$。

由[[#thm-nested-intervals]]，存在一个属于每个$I_n$的实数$x$。对每个$n$，$x \in I_n$而$x_n \notin I_n$，所以$x \neq x_n$。因此序列$(x_n)$漏掉了$x$，没有任何序列能列出全部实数。
:::

::: widget cantor
mode: diagonal
size: 8
caption: 康托尔对[[#thm-r-uncountable]]的另一个证明。用十进制展开式列出$(0,1)$中任意一些实数，并构造一个新数，使它的第$n$位数字与表中第$n$个数的第$n$位数字不同。这个新数在$(0,1)$中，却不在任何人列出的表中。试着编辑这张表：对角线构造出的数总能逃脱。（为了避免像$0.0999\ldots = 0.1000\ldots$这样的双重展开，选取的新数字既不是$0$也不是$9$。）
:::

由于$\Q$可数而$\R$不可数，无理数是不可数的：在基数的意义下，几乎每个实数都是无理数。在[[measure-theory/lebesgue-measure]]中，同样的结论以长度的语言出现：$\Q$可以被总长度任意小的一族区间覆盖。

::: quiz
下列哪个命题在**每个**有序域中都成立，因而即使在不满足完备性公理的域中也成立？
- [ ] 对每个$\eps > 0$，存在$n \in \N$使$1/n < \eps$。
- [x] 任意两个不同元素之间都有第三个元素。
- [ ] 每个有上界的非空集合都有上确界。
- [ ] 每个正元素都有平方根。
::: solution
在任何有序域中，若$a < b$，则$a < (a+b)/2 < b$——这只用到[[#def-ordered-field]]中的公理。其余三个命题都在某个有序域中不成立：阿基米德性质在$\R(t)$中不成立（在那里$1/t$小于每个$1/n$），完备性和平方根的存在性在$\Q$中都不成立（在$\Q$中$2$没有平方根）。
:::
:::

::: history
正方形的对角线与其边长不可公度——即$\sqrt2$不是两个整数之比——这一事实是公元前五世纪在希腊发现的，传统上归功于毕达哥拉斯学派（Pythagoreans）。尼多斯的欧多克索斯（Eudoxus of Cnidus）用一种比例理论回应了这场危机：通过比较两个量的所有有理倍数来比较这两个量；这一理论保存在欧几里得（Euclid）《几何原本》（*Elements*，约公元前300年）的第五卷中。此后两千年间，数学家们一直在使用实数，却没有给它下过定义。1858年秋，理查德·戴德金（Richard Dedekind）在苏黎世理工学院讲授微积分时，对于在证明有界递增的量有极限时诉诸几何直观感到不满；他给出的答案——用分割构造实数——发表在《连续性与无理数》（*Stetigkeit und irrationale Zahlen*，1872年）中。同一年，格奥尔格·康托尔（Georg Cantor）独立于夏尔·梅雷（Charles Méray，1869年），用有理数的柯西列构造了实数。康托尔于1874年证明了$\R$不可数，所用的论证与上面基于区间套的证明相近；1891年他又给出了对角线论证。1900年，大卫·希尔伯特（David Hilbert）提出用公理来描述实数，即把实数描述为满足完备性公理的有序域——这正是本章的观点。
:::

## 后续内容

完备性是整个课程的引擎。在[[real-analysis/sequences]]中，它变成单调收敛定理（[[real-analysis/sequences#thm-monotone]]）——有界的递增数列收敛于它的上确界——进而变成波尔查诺-魏尔斯特拉斯定理和柯西收敛准则，它们都是同一条公理的等价形式。在[[real-analysis/continuity]]中，它导出介值定理和最值定理，从而解决了本章开头的那个例子；在[[real-analysis/riemann-integral]]中，它保证了上积分和下积分的存在。在[[real-analysis/metric-spaces]]中，完备性从$\R$推广到由点、数列和函数构成的空间；而可数与不可数的区别将在[[measure-theory/lebesgue-measure]]中再次出现，在那里可数集的长度原来为零。

::: summary
- $\Q$有空隙：没有哪个有理数的平方等于$2$（[[#thm-sqrt2-irrational]]），所以介值定理在$\Q$上不成立。
- $\R$是一个**完备有序域**：满足[[#def-ordered-field]]中的域公理和序公理，再加上完备性公理——每个有上界的非空集合都有最小上界。
- $s = \sup A$的意思是：$s$是一个上界，并且对每个$\eps > 0$，有某个$a \in A$大于$s - \eps$（[[#lem-sup-approx]]）。上确界不一定属于$A$。
- 完备性的典型用法：定义一个集合，取它的上确界，排除其他可能——如$\sqrt2$的存在性（[[#thm-sqrt2]]）。
- 阿基米德性质（$\N$无上界；对某个$n$有$1/n < \eps$）由完备性推出，并给出$\Q$的稠密性（[[#thm-q-dense]]）。
- 相套的有界闭区间有公共点（[[#thm-nested-intervals]]）；这是二分法的基础，并证明了$\R$不可数（[[#thm-r-uncountable]]）。
- ε原理：若对每个$\eps > 0$都有$\abs{x - y} < \eps$，则$x = y$（[[#lem-eps-principle]]）。
:::

## 习题

::: exercise 取不到的上确界 {level=1 check="1"}
求$\sup\set{\dfrac{n}{n+1} : n \in \N}$，证明你的答案，并判断这个集合是否有最大值和最小值。
::: solution
由于$\dfrac{n}{n+1} = 1 - \dfrac{1}{n+1} < 1$，数$1$是一个上界。给定$\eps > 0$，由阿基米德性质，存在$n$使$\tfrac1n < \eps$；于是$\tfrac{1}{n+1} < \tfrac1n < \eps$，所以$\tfrac{n}{n+1} > 1 - \eps$。由[[#lem-sup-approx]]，上确界为$1$。它不是最大值，因为每个元素都严格小于$1$。元素随$n$增大而增大，所以最小值是第一个元素$\tfrac12$，从而$\inf = \min = \tfrac12$。
:::
:::

::: exercise 解集的上确界 {level=1 check="2"}
设$A = \set{x \in \R : x^2 - 3x + 2 < 0}$。求$\sup A$。
::: solution
$x^2 - 3x + 2 = (x - 1)(x - 2)$为负，当且仅当一个因子为正而另一个为负，即$1 < x < 2$。所以$A = (1, 2)$。与[[#ex-sup-interval]]一样，$2$是一个上界，并且当$0 < \eps < 1$时，元素$2 - \eps/2 \in A$大于$2 - \eps$（当$\eps \ge 1$时用$\tfrac32$）。因此$\sup A = 2$，且取不到。
:::
:::

::: exercise 最小值 {level=1 check="2"}
求$\inf\set{x + \dfrac1x : x > 0}$，并证明它是最小值。
::: solution
对$x > 0$，

$$
x + \frac1x - 2 = \frac{x^2 - 2x + 1}{x} = \frac{(x-1)^2}{x} \ge 0,
$$

所以$2$是一个下界。它在$x = 1$处取到，此时$1 + \tfrac11 = 2$。属于集合的下界就是集合的最小值，所以下确界为$2$。
:::
:::

::: exercise 用绝对值表示最大值 {level=1}
证明：对所有实数$x, y$，$\max(x, y) = \dfrac{x + y + \abs{x - y}}{2}$，$\min(x, y) = \dfrac{x + y - \abs{x - y}}{2}$。
::: solution
若$x \ge y$，则$\abs{x - y} = x - y$，所以$\tfrac12(x + y + \abs{x-y}) = \tfrac12(2x) = x = \max(x, y)$，且$\tfrac12(x + y - \abs{x - y}) = y = \min(x,y)$。若$x < y$，则$\abs{x - y} = y - x$，同样的公式分别给出$y$和$x$。
:::
:::

::: exercise 不能定序的域 {level=2}
(a) 证明：在有序域中，无论有多少项，都有$1 + 1 + \cdots + 1 \neq 0$。由此推出有限域不能定序。
(b) 证明：复数域$\C$不能成为有序域。
::: hint
利用[[#prop-order]]：$1 > 0$，并且非零元素的平方是正的。
:::
::: solution
(a) 由[[#prop-order]]，$1 > 0$。若$s_k = 1 + \cdots + 1$（$k$项）是正的，则由公理6和传递性，$s_{k+1} = s_k + 1 > s_k > 0$。由归纳法，每个$s_k > 0$，所以$s_k \neq 0$。在有限域中，元素$s_1, s_2, s_3, \dots$不可能两两不同，所以对某个$j < k$有$s_j = s_k$，从而$s_{k-j} = s_k - s_j = 0$，而这在有序域中是不可能的。

(b) 假设$\C$上有一个满足公理4–7的序。由于$i \neq 0$，由[[#prop-order]](2)得$i^2 > 0$，即$-1 > 0$。但同时$1 > 0$，而由[[#prop-order]](1)，$-1 > 0$迫使$1 < 0$。由三歧性，$1 < 0$与$1 > 0$不能同时成立——矛盾。
:::
:::

::: exercise 集合的伸缩 {level=2}
设$A \subseteq \R$非空且有界，$cA = \set{ca : a \in A}$。证明：若$c > 0$，则$\sup(cA) = c\sup A$；若$c < 0$，则$\sup(cA) = c\inf A$。
::: solution
设$c > 0$，$s = \sup A$。对$a \in A$，由$a \le s$得$ca \le cs$，所以$cs$是$cA$的一个上界。给定$\eps > 0$，取$a \in A$使$a > s - \eps/c$（[[#lem-sup-approx]]）；则$ca > cs - \eps$。因此$\sup(cA) = cs$。

设$c < 0$，$m = \inf A$。对$a \in A$，由$a \ge m$得$ca \le cm$（[[#prop-order]](3)），所以$cm$是$cA$的一个上界。给定$\eps > 0$，取$a \in A$使$a < m + \eps/\abs{c}$（[[#lem-sup-approx]]的下确界形式）；两边乘以$c = -\abs{c}$得$ca > cm - \eps$。因此$\sup(cA) = cm = c\inf A$。
:::
:::

::: exercise 无理数是稠密的 {level=2}
证明：任意两个实数$a < b$之间都有一个无理数。
::: hint
对区间$(a - \sqrt2, b - \sqrt2)$应用[[#thm-q-dense]]。
:::
::: solution
由于$a - \sqrt2 < b - \sqrt2$，由[[#thm-q-dense]]，存在有理数$q$使$a - \sqrt2 < q < b - \sqrt2$。于是$x = q + \sqrt2$满足$a < x < b$。若$x$是有理数，则$\sqrt2 = x - q$（两个有理数之差）也是有理数，与[[#thm-sqrt2-irrational]]矛盾。所以$x$是无理数。
:::
:::

::: exercise 上确界与下确界的比较 {level=2}
设$A \subseteq \R$非空且有界。证明$\inf A \le \sup A$，并且等号成立当且仅当$A$恰有一个元素。
::: solution
任取$a \in A$（由于$A \neq \varnothing$，这是可以做到的）。则$\inf A \le a \le \sup A$。若$A = \set{a}$，则$a$既是最大元素又是最小元素，所以$\inf A = \sup A = a$。反之，设$\inf A = \sup A = c$。对每个$a \in A$有$c \le a \le c$，所以$a = c$；因此$A = \set{c}$。
:::
:::

::: exercise 元素向上确界聚集 {level=2}
设$A$非空且有上界，并且$s = \sup A \notin A$。证明：对每个$\eps > 0$，区间$(s - \eps, s)$包含$A$的无穷多个元素。
::: solution
假设对某个$\eps > 0$，区间$(s - \eps, s)$只包含$A$的有限多个元素。由[[#lem-sup-approx]]，它至少包含一个；设$a^*$是这有限多个元素中最大的一个。由于$s \notin A$，$A$的每个元素都$< s$，所以$a^* < s$。令$\eps' = s - a^* > 0$。由[[#lem-sup-approx]]，存在$a \in A$使$a > s - \eps'= a^*$。于是$a^* < a < s$且$a > s - \eps$，所以$a$是$A$在$(s - \eps, s)$中的一个比$a^*$大的元素，与$a^*$的选取矛盾。
:::
:::

::: exercise n次方根 {level=3}
设$a > 0$，$n \in \N$。证明恰有一个$x > 0$满足$x^n = a$。
::: hint
令$A = \set{x > 0 : x^n < a}$，$s = \sup A$。当$0 < h \le 1$时，由二项式定理得$(s+h)^n - s^n \le hK$，其中$K = (s+1)^n - s^n$；当$0 < t < s$时，由因式分解$s^n - t^n = (s - t)(s^{n-1} + s^{n-2}t + \cdots + t^{n-1})$得$s^n - t^n \le (s - t)\,n s^{n-1}$。
:::
::: solution
当$0 < x < y$时有$x^n < y^n$（把$n$个不等式$x < y$相乘），这给出了唯一性，下面也要用到。令$A = \set{x > 0 : x^n < a}$。

**$A$非空且有上界。**数$t = a/(1 + a)$满足$0 < t < 1$且$t < a$，所以$t^n \le t < a$，从而$t \in A$。若$x \ge 1 + a$，则$x \ge 1$，所以$x^n \ge x \ge 1 + a > a$，从而$x \notin A$；因此$1 + a$是一个上界。令$s = \sup A > 0$。

**提示中的不等式。**当$0 < h \le 1$时，由于$h^k \le h$，有$(s + h)^n - s^n = \sum_{k=1}^n \binom{n}{k} s^{n-k}h^k \le h\sum_{k=1}^n \binom nk s^{n-k} = hK$，其中$K = (s+1)^n - s^n > 0$。当$0 < t < s$时，$s^{n-1} + s^{n-2}t + \cdots + t^{n-1}$的$n$个项中每一项都不超过$s^{n-1}$。

**$s^n < a$不可能。**令$h = \min\bigl(1, \tfrac{a - s^n}{2K}\bigr) > 0$。则$(s + h)^n \le s^n + hK \le s^n + \tfrac12(a - s^n) < a$，所以$s + h \in A$，与$s$是上界矛盾。

**$s^n > a$不可能。**令$h = \min\bigl(\tfrac s2, \tfrac{s^n - a}{2ns^{n-1}}\bigr) > 0$，$t = s - h \in (0, s)$。则$t^n \ge s^n - h\,n s^{n-1} \ge s^n - \tfrac12(s^n - a) > a$。如果某个$x \in A$满足$x > t$，那么$x^n > t^n > a$，这不可能；所以$t$是$A$的一个比$s$小的上界，矛盾。

因此$s^n = a$，$s$就是$a$的唯一的正$n$次方根。
:::
:::

::: exercise 区间套蕴涵完备性 {level=3}
设$F$是一个具有阿基米德性质的有序域，并且在$F$中区间套性质（[[#thm-nested-intervals]]，包括唯一性部分）成立。证明$F$的每个有上界的非空子集都有上确界。（因此，对于阿基米德有序域，区间套性质与完备性等价。）
::: hint
用二分法：从$[a_1, b_1]$出发，其中$a_1$不是上界而$b_1$是上界。每次保留左端点不是上界而右端点是上界的那一半。
:::
::: solution
设$A \subseteq F$非空，且有上界$b_1$。取$a \in A$，令$a_1 = a - 1$，它不是上界（因为$a > a_1$）。给定$[a_n, b_n]$，其中$a_n$不是$A$的上界而$b_n$是上界，令$c = (a_n + b_n)/2$。若$c$是上界，则令$[a_{n+1}, b_{n+1}] = [a_n, c]$；否则令$[a_{n+1}, b_{n+1}] = [c, b_n]$。这些区间是相套的，上述不变性得以保持，并且$b_n - a_n = (b_1 - a_1)/2^{n-1}$。

这些长度可以小于任意$\eps > 0$：由阿基米德性质，取$n$使$n > (b_1 - a_1)/\eps$，再利用$2^{n-1} \ge n$。由区间套性质，恰有一个$s$属于每个$[a_n, b_n]$。我们来证明$s = \sup A$。

**$s$是上界。**如果某个$x \in A$满足$x > s$，取$n$使$b_n - a_n < x - s$；则$b_n \le a_n + (b_n - a_n) < s + (x - s) = x$（利用$a_n \le s$），所以$b_n$不是上界——矛盾。

**逼近。**给定$\eps > 0$，取$n$使$b_n - a_n < \eps$。由于$a_n$不是上界，存在$x \in A$使$x > a_n \ge b_n - \eps \ge s - \eps$。由[[#lem-sup-approx]]（它的证明只用到有序域公理），$s = \sup A$。
:::
:::

::: exercise 二进有理数是稠密的 {level=3}
形如$m/2^k$（其中$m \in \Z$，$k \in \N$）的数称为**二进有理数**。证明：任意两个实数$a < b$之间都有一个二进有理数；并由此推出，每个实数都是小于它的全体二进有理数的上确界。
::: solution
由阿基米德性质，取$k \in \N$使$1/k < b - a$；由于$2^k \ge k$，也有$1/2^k < b - a$。现在取$n = 2^k$，重复[[#thm-q-dense]]的证明：满足$m > 2^k a$的最小整数$m$满足$2^k a < m \le 2^k a + 1 < 2^k b$，所以$a < m/2^k < b$。

对于第二部分，设$x \in \R$，$D_x = \set{d \text{ 为二进有理数} : d < x}$。它非空（对$(x - 1, x)$应用第一部分），并且以$x$为上界。给定$\eps > 0$，由第一部分，存在二进有理数$d$使$x - \eps < d < x$，所以$d \in D_x$且$d > x - \eps$。由[[#lem-sup-approx]]，$\sup D_x = x$。（计算机中的二进制小数正是这样逼近每个实数的。）
:::
