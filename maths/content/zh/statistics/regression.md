十名学生记录了他们为一次考试复习所花的小时数以及所得的分数：

| 小时数$x$ | 2 | 3 | 5 | 6 | 8 | 9 | 10 | 12 | 13 | 15 |
|---|---|---|---|---|---|---|---|---|---|---|
| 分数$y$ | 52 | 55 | 61 | 58 | 70 | 68 | 75 | 79 | 77 | 88 |

分数显然随着复习时间的增加而上升，大致沿着一条直线。哪一条直线拟合得最好？多复习一小时，分数会增加多少？我们对此能有多大把握？对一名复习七小时的学生，我们会预测他得多少分？这个预测可能偏离多远？还有一个人们真正想知道答案的问题：复习是不是分数提高的**原因**？

**回归**研究响应变量$y$如何依赖于解释变量$x$。本章讲述**一元线性回归**：用**最小二乘**法拟合直线、其背后的统计模型、斜率的推断、置信区间与预测区间、定义$R^2$的变差分解、用残差检验模型，以及使回归得名的现象——**向均值回归**。最后我们介绍矩阵形式，它把所有这些推广到多个解释变量的情形，并与[[linear-algebra/least-squares]]一章联系起来。

## 最小二乘直线 {#least-squares}

给定数据点$(x_1,y_1),\ldots,(x_n,y_n)$，直线$y = b_0 + b_1x$在$x_i$处的预测值为$b_0 + b_1x_i$，相应的**残差**为$y_i - b_0 - b_1x_i$。最小二乘法选取使残差平方和尽可能小的直线。本章始终使用记号

$$
S_{xx} = \sum_i(x_i-\bar x)^2,\qquad S_{xy} = \sum_i(x_i-\bar x)(y_i-\bar y),\qquad S_{yy} = \sum_i(y_i-\bar y)^2 .
$$

::: theorem 最小二乘估计 {#thm-least-squares}
设各$x_i$不全相等。平方和$Q(b_0,b_1) = \sum_i(y_i - b_0 - b_1x_i)^2$在且仅在下列取值处达到最小：

$$
\hat\beta_1 = \frac{S_{xy}}{S_{xx}},\qquad\hat\beta_0 = \bar y - \hat\beta_1\bar x .
$$ {#eq-ls}
:::

::: proof
令偏导数为零（[[multivariable/extrema]]），得到**正规方程**

$$
\frac{\partial Q}{\partial b_0} = -2\sum_i(y_i - b_0 - b_1x_i) = 0,\qquad\frac{\partial Q}{\partial b_1} = -2\sum_ix_i(y_i - b_0 - b_1x_i) = 0 .
$$

第一个方程说明$\bar y = b_0 + b_1\bar x$，所以$b_0 = \bar y - b_1\bar x$。代入第二个方程，并利用$\sum_ix_i(y_i - \bar y) = S_{xy}$和$\sum_ix_i(x_i-\bar x) = S_{xx}$，得到$S_{xy} - b_1S_{xx} = 0$，所以$b_1 = S_{xy}/S_{xx}$（由于各$x_i$不全相等，$S_{xx}>0$）。为了说明这个临界点是唯一的最小值点，记$u_i = x_i - \bar x$，并写$y_i - b_0 - b_1x_i = (y_i - \bar y - b_1u_i) + (\bar y - b_0 - b_1\bar x)$。由于$\sum_iu_i = 0$，对平方求和时交叉项为零：

$$
Q(b_0,b_1) = \sum_i(y_i-\bar y - b_1u_i)^2 + n(\bar y - b_0 - b_1\bar x)^2 = S_{yy} - 2b_1S_{xy} + b_1^2S_{xx} + n(\bar y - b_0 - b_1\bar x)^2 .
$$

前三项构成$b_1$的一个首项系数为正的二次函数，仅在$b_1 = S_{xy}/S_{xx}$处取得最小值；而最后一项仅当$b_0 = \bar y - b_1\bar x$时为零。
:::

第一个正规方程表明，拟合直线经过均值点$(\bar x,\bar y)$，并且**残差**$e_i = y_i - \hat y_i$之和为零，其中$\hat y_i = \hat\beta_0 + \hat\beta_1x_i$称为**拟合值**；第二个正规方程表明还有$\sum_ix_ie_i = 0$。

::: example 复习与考试分数 {#ex-revision}
对上面的复习数据拟合最小二乘直线。
::: solution
由数据得$\bar x = 8.3$，$\bar y = 68.3$，$S_{xx} = 168.1$，$S_{xy} = 444.1$，$S_{yy} = 1228.1$。因此

$$
\hat\beta_1 = \frac{444.1}{168.1} = 2.642,\qquad\hat\beta_0 = 68.3 - 2.642\times8.3 = 46.37,
$$

拟合直线为$\hat y = 46.37 + 2.642x$。每多复习一小时，分数相应地大约多$2.6$分；对复习了七小时的学生，预测分数为$46.37 + 2.642\times7 = 64.9$。截距$46.4$是完全不复习时的预测分数——这是稍稍超出数据范围的外推（最小的$x$为$2$），应当谨慎对待。
:::
:::

## 线性模型 {#model}

要说明拟合直线有多可靠，我们需要一个描述数据如何产生的模型。

::: definition 一元线性回归模型 {#def-linear-model}
**一元线性回归模型**假定

$$
Y_i = \beta_0 + \beta_1x_i + \eps_i,\qquad i = 1,\ldots,n,
$$ {#eq-model}

其中各$x_i$是固定的（非随机的）数，且不全相等；$\beta_0$，$\beta_1$是未知参数；**误差**$\eps_i$是互不相关的随机变量，其均值（数学期望）为$0$，方差同为$\sigma^2$。在**正态线性模型**中，还要求误差相互独立且服从$\Normal(0,\sigma^2)$。
:::

这个模型是说，$Y$在$x$处的均值是直线$\beta_0 + \beta_1x$，并且围绕这条直线的散布程度处处相同（**同方差性**）。最小二乘估计量是各$Y_i$的线性组合：由于$\sum_i(x_i - \bar x) = 0$，

$$
\hat\beta_1 = \frac{\sum_i(x_i-\bar x)Y_i}{S_{xx}} = \sum_ic_iY_i,\qquad c_i = \frac{x_i-\bar x}{S_{xx}},
$$ {#eq-slope-linear}

并且这些权重满足$\sum_ic_i = 0$，$\sum_ic_ix_i = 1$，$\sum_ic_i^2 = 1/S_{xx}$。

::: theorem 斜率估计量的均值与方差 {#thm-slope}
在线性模型下，$\hat\beta_1$是无偏的，且$\Var\hat\beta_1 = \dfrac{\sigma^2}{S_{xx}}$。$\hat\beta_0$也是无偏的，且$\Var\hat\beta_0 = \sigma^2\Bigl(\dfrac1n + \dfrac{\bar x^2}{S_{xx}}\Bigr)$。
:::

::: proof
由[[#eq-slope-linear]]和线性性，$\E\hat\beta_1 = \sum_ic_i(\beta_0 + \beta_1x_i) = \beta_0\sum_ic_i + \beta_1\sum_ic_ix_i = \beta_1$。由于各$Y_i$互不相关且方差为$\sigma^2$，$\Var\hat\beta_1 = \sum_ic_i^2\sigma^2 = \sigma^2/S_{xx}$。对于截距，$\E\hat\beta_0 = \E\bar Y - \bar x\E\hat\beta_1 = (\beta_0 + \beta_1\bar x) - \bar x\beta_1 = \beta_0$；又由于$\Cov(\bar Y,\hat\beta_1) = \frac{\sigma^2}{n}\sum_ic_i = 0$，

$$
\Var\hat\beta_0 = \Var\bar Y + \bar x^2\Var\hat\beta_1 = \frac{\sigma^2}{n} + \frac{\bar x^2\sigma^2}{S_{xx}}.
$$
:::

当$S_{xx}$较大，即各$x$值比较分散时，斜率的估计更精确：要把斜率测准，观测点之间应当相距较远。在所有这类估计量中，最小二乘估计是最好的。

::: theorem 高斯-马尔可夫（Gauss–Markov）定理（斜率的情形） {#thm-gauss-markov}
在线性模型下，$\beta_1$的每个线性无偏估计量$\tilde\beta_1 = \sum_ia_iY_i$都满足$\Var\tilde\beta_1\ge\Var\hat\beta_1$。最小二乘估计是**最佳线性无偏估计量**（BLUE）。
:::

::: proof
要使$\sum_ia_iY_i$对一切$\beta_0$和$\beta_1$都是无偏的，需要$\sum_ia_i(\beta_0 + \beta_1x_i) = \beta_1$恒成立，即$\sum_ia_i = 0$且$\sum_ia_ix_i = 1$。记$a_i = c_i + d_i$。则$\sum_id_i = 0$，$\sum_id_ix_i = 0$；又由于$c_i$是$1$与$x_i$的线性组合，还有$\sum_ic_id_i = 0$。因此

$$
\Var\tilde\beta_1 = \sigma^2\sum_ia_i^2 = \sigma^2\Bigl(\sum_ic_i^2 + 2\sum_ic_id_i + \sum_id_i^2\Bigr) = \Var\hat\beta_1 + \sigma^2\sum_id_i^2\ge\Var\hat\beta_1 .
$$

等号仅当所有$d_i = 0$，即$\tilde\beta_1 = \hat\beta_1$时成立。
:::

误差方差$\sigma^2$由残差来估计。**残差平方和**为$\mathrm{SSE} = \sum_ie_i^2$，而

$$
S^2 = \frac{\mathrm{SSE}}{n-2}
$$ {#eq-residual-variance}

是$\sigma^2$的无偏估计：估计$\beta_0$和$\beta_1$用掉了两个自由度，正如在样本方差中$\bar X$用掉了一个自由度一样。对于复习数据，$\mathrm{SSE} = 54.84$，所以$s^2 = 54.84/8 = 6.86$，$s = 2.62$分：这是分数围绕直线的典型散布幅度。

## 斜率的推断与预测 {#inference}

对于正态线性模型，抽样分布是精确的。下面的定理是[[statistics/sampling#thm-normal-sample]]在回归中的类比，其证明方法也相同，即作正交变量替换（参见 Rice 一书第14章）。

::: theorem 正态线性模型中的抽样分布 {#thm-regression-t}
在正态线性模型中，$\hat\beta_1\sim\Normal(\beta_1,\sigma^2/S_{xx})$，$(n-2)S^2/\sigma^2\sim\chi^2_{n-2}$，且两者相互独立。因此

$$
T = \frac{\hat\beta_1 - \beta_1}{S/\sqrt{S_{xx}}}\sim t_{n-2} .
$$ {#eq-slope-t}
:::

量$\operatorname{se}(\hat\beta_1) = s/\sqrt{S_{xx}}$称为**斜率的标准误**。与[[statistics/confidence-intervals]]一章中一样，由枢轴量[[#eq-slope-t]]可得置信区间$\hat\beta_1\pm t_{n-2,\alpha/2}\operatorname{se}(\hat\beta_1)$；而$H_0$：$\beta_1 = 0$（“$x$对$y$没有线性影响”）的检验使用$t = \hat\beta_1/\operatorname{se}(\hat\beta_1)$。

::: example 复习与更高的分数有关联吗？ {#ex-slope-test}
对复习数据，求斜率的$95\%$置信区间，并检验$H_0$：$\beta_1 = 0$。
::: solution
$\operatorname{se}(\hat\beta_1) = 2.618/\sqrt{168.1} = 0.202$。由$t_{8,0.025} = 2.306$，$95\%$置信区间为

$$
2.642\pm2.306\times0.202 = 2.642\pm0.466,\qquad\text{即 }[2.18,\ 3.11]\text{ 分/小时}.
$$

检验统计量为$t = 2.642/0.202 = 13.1$，自由度为$8$，得到$p\approx1\times10^{-6}$。这种关联是压倒性的。至于它是否是因果关系，那是另一个问题（见下面的警示）。
:::
:::

在一个新的值$x_0$处，有两个不同的问题。**均值响应**$\mu_0 = \beta_0 + \beta_1x_0$由$\hat y_0 = \hat\beta_0 + \hat\beta_1x_0 = \bar Y + \hat\beta_1(x_0-\bar x)$来估计，由于$\bar Y$与$\hat\beta_1$不相关，其方差为$\sigma^2\bigl(\frac1n + \frac{(x_0-\bar x)^2}{S_{xx}}\bigr)$。**新观测值**$Y_0 = \mu_0 + \eps_0$还带有一个额外的独立误差，所以$Y_0 - \hat y_0$的方差为$\sigma^2\bigl(1 + \frac1n + \frac{(x_0-\bar x)^2}{S_{xx}}\bigr)$。由此得到

$$
\begin{aligned}
\mu_0\text{ 的置信区间}&:\quad\hat y_0\pm t_{n-2,\alpha/2}\,s\sqrt{\tfrac1n + \tfrac{(x_0-\bar x)^2}{S_{xx}}},\\
Y_0\text{ 的预测区间}&:\quad\hat y_0\pm t_{n-2,\alpha/2}\,s\sqrt{1 + \tfrac1n + \tfrac{(x_0-\bar x)^2}{S_{xx}}}.
\end{aligned}
$$ {#eq-intervals}

::: example 预测分数 {#ex-prediction}
对一名复习$7$小时的学生，求所有这类学生平均分数的$95\%$置信区间，以及这名学生分数的$95\%$预测区间。
::: solution
$\hat y_0 = 64.87$，$(x_0 - \bar x)^2/S_{xx} = 1.69/168.1 = 0.010$。置信区间为$64.87\pm2.306\times2.618\sqrt{0.110}$，即$64.87\pm2.00 = [62.9, 66.9]$。预测区间为$64.87\pm2.306\times2.618\sqrt{1.110}$，即$64.87\pm6.36 = [58.5, 71.2]$。复习七小时的学生的平均分数可以确定到大约两分以内，但单个学生的分数有超过六分的不确定性，因为个体会围绕直线散布。收集更多的数据会使第一个区间的宽度向零收缩，但第二个区间不会。
:::
:::

::: quiz
为什么在同一个$x_0$处，新观测值的预测区间总是比均值响应的置信区间更宽？
- [ ] 因为它使用了更大的 t 临界值。
- [x] 因为除了所估计的直线本身的不确定性之外，新观测值还会围绕真实直线波动$\eps_0$。
- [ ] 因为预测区间的置信水平更高。

:::

## 相关系数与 R² {#r-squared}

$y$的变差中有多少能由这条直线来解释？总变差$\mathrm{SST} = S_{yy}$可以分解为被解释的部分$\mathrm{SSR} = \sum_i(\hat y_i - \bar y)^2$和残差部分$\mathrm{SSE}$。

::: theorem 平方和分解 {#thm-anova}
对最小二乘拟合，

$$
\sum_i(y_i-\bar y)^2 = \sum_i(\hat y_i-\bar y)^2 + \sum_i(y_i-\hat y_i)^2,\qquad\text{即}\qquad\mathrm{SST} = \mathrm{SSR} + \mathrm{SSE} .
$$

此外，**决定系数**$R^2 = \mathrm{SSR}/\mathrm{SST}$等于$r^2$，即样本相关系数$r = S_{xy}/\sqrt{S_{xx}S_{yy}}$的平方。
:::

::: proof
写$y_i - \bar y = (\hat y_i - \bar y) + e_i$。两边平方后求和，交叉项为$2\sum_i(\hat y_i - \bar y)e_i = 2\sum_i\bigl(\hat\beta_0 - \bar y + \hat\beta_1x_i\bigr)e_i = 0$，这是因为由正规方程，$\sum_ie_i = 0$且$\sum_ix_ie_i = 0$。这就得到了上述分解。其次，$\hat y_i - \bar y = \hat\beta_1(x_i - \bar x)$，所以

$$
\mathrm{SSR} = \hat\beta_1^2S_{xx} = \frac{S_{xy}^2}{S_{xx}},\qquad R^2 = \frac{S_{xy}^2}{S_{xx}S_{yy}} = r^2 .
$$
:::

$R^2$介于$0$与$1$之间，它是$y$的方差中由其与$x$的线性关系所“解释”的比例。对于复习数据，$\mathrm{SSR} = 444.1^2/168.1 = 1173.3$，所以$R^2 = 1173.3/1228.1 = 0.955$，$r = 0.977$：**在这个样本中**，复习时间解释了分数变差的$95.5\%$。样本相关系数$r$是[[probability/joint-distributions#def-covariance]]中的相关系数在数据上的类比；和后者一样，它只度量线性关联。

::: quiz
成年人体重对身高的回归（斜率为正）的$R^2 = 0.49$。下列哪个说法是正确的？
- [ ] 样本中$49\%$的人落在拟合直线上。
- [x] 样本相关系数为$0.7$，这条直线解释了体重方差的$49\%$。
- [ ] 一个人体重的$49\%$是由身高造成的。
- [ ] 直线的斜率为$0.49$。
::: solution
$R^2 = r^2$，所以$r = \sqrt{0.49} = 0.7$（取正值，因为斜率为正），而$R^2$是$S_{yy}$中由直线解释的比例。它不能说明有多少点落在直线上，不能说明因果关系，也不能直接说明斜率——斜率依赖于测量单位。
:::
:::

::: warning 相关不等于因果
$x$与$y$之间的强关联并不能表明改变$x$就会改变$y$。复习数据是观察性数据：复习得多的学生可能也更有学习动力、听课更多，或者本来基础就更好，这些**混杂**变量中的任何一个都可能产生这种关联。冰淇淋销量与溺水人数是相关的，因为两者都在炎热天气里上升。只有随机化实验——其中$x$是随机分配的——才能切断与混杂变量的联系，从而允许得出因果结论。另外还有两点需要注意：超出数据范围的**外推**假定直线会延续下去，而数据中没有任何东西支持这一点；高的$R^2$并不意味着模型是正确的——对于一个弯曲的关系，直线拟合的$R^2$也可能很高，而每个残差讲述的却是另一回事。
:::

::: remark 安斯库姆四重奏
1973年，弗朗西斯·安斯库姆（Francis Anscombe）构造了四个小数据集，它们的均值、方差、相关系数（$r = 0.816$）和最小二乘直线（$\hat y = 3.00 + 0.500x$）基本相同。然而把它们画出来，却几乎是天差地别：一个是合理的线性散点，一个是一条光滑的曲线，一个是一条完美的直线加上单独一个离群点，还有一个是一列竖直堆叠的点，外加一个远处的点，斜率完全由这一个点决定。教训是：一定要把数据和残差画出来；概括统计量是不够的。
:::

## 用残差检验模型 {#residuals}

上面的推断依赖于一些假设：均值呈直线、方差恒定、相互独立，以及（对精确的 t 区间而言）误差服从正态分布。残差$e_i$是我们观察不可观测的误差$\eps_i$的窗口，把残差对$x$（或对拟合值）作图是主要的诊断工具。

- **弯曲**：系统性的 U 形或拱形模式意味着均值呈直线的假设是错误的；可以尝试作变换（例如取$\ln y$），或加入$x^2$项。
- **漏斗形**：随着$x$增大而越来越分散的残差表明方差不恒定；对$y$作对数变换通常会有帮助。
- **离群点与强影响点**：残差很大的点，或位于极端$x$处（**杠杆值**高）、把直线拉向自己的点，都值得调查；去掉它重新拟合，看看结论在多大程度上依赖于它。
- **相依性**：对于按时间顺序收集的数据，如果残差成串地漂移，就提示存在自相关，这会使标准误失效。

::: example 复习数据的残差 {#ex-residuals}
计算复习数据相对于拟合直线$\hat y = 46.37 + 2.642x$的残差，并加以评论。
::: solution
按$x$从小到大的顺序，残差$e_i = y_i - \hat y_i$近似为

$$
0.34,\ 0.70,\ 1.42,\ -4.22,\ 2.49,\ -2.15,\ 2.21,\ 0.93,\ -3.72,\ 2.00 .
$$

正如应当的那样，它们之和（在舍入误差范围内）为零。正值与负值相互穿插，没有系统性的趋势或弯曲，其散布程度也没有随$x$明显变化。绝对值最大的残差是复习了$6$小时、得了$58$分的那名学生的$-4.22$，它是$s = 2.62$的$1.6$倍——在十个观测值中，这并不值得注意。所以方差恒定的直线模型看来是合理的，尽管只有十个点，这种检验并不十分灵敏。
:::
:::

## 向均值回归 {#regression-to-the-mean}

为什么叫“回归”？弗朗西斯·高尔顿（Francis Galton）注意到，非常高的父母，其子女平均而言也较高，但没有那么极端；非常矮的父母，其子女较矮，但更接近平均水平。他把这称为“向平庸回归”。这是相关不完全的结果，而不是任何生物学力量的作用。如果$x$和$y$都已标准化（均值为$0$，标准差为$1$），那么最小二乘直线为$\hat y = r\,x$，因为$\hat\beta_1 = S_{xy}/S_{xx} = r\sqrt{S_{yy}/S_{xx}} = r$。当$\lvert r\rvert<1$时，以标准单位计，预测的$y$总是比$x$更接近均值——正如我们在[[probability/joint-distributions#prop-bivariate-normal]]中对二元正态分布所看到的那样。

::: example 成绩最差者的“进步” {#ex-regression-mean}
一个班级参加了两次难度相同的考试，以标准单位计，两次考试分数的相关系数为$0.6$。第一次考试中低于均值$2$个标准差的学生接受了额外的辅导。在第二次考试中，他们的平均分低于均值$1.2$个标准差。这能说明辅导起了作用吗？
::: solution
不能——至少单凭这一点不能。即使没有任何辅导，回归直线$\hat y = 0.6x$也预测：在第一次考试中低于均值$2$个标准差的学生，在第二次考试中平均得分为$0.6\times(-2) = -1.2$个标准差。他们第一次的低分部分是由于运气不好，而坏运气不会重演。观察到的“进步”恰好是向均值回归所预测的。公正的评估需要一个**对照组**：从类似的低分学生中随机选出一些人，不给他们辅导。向均值回归在许多场合都会造成误导——在症状最严重时入组试验的患者，在事故多发的一年之后安装的测速摄像头，一支运动队在其最佳赛季之后的状态。
:::
:::

## 矩阵形式与多元回归 {#matrix-form}

当有多个解释变量时，$Y_i = \beta_0 + \beta_1x_{i1} + \dots + \beta_px_{ip} + \eps_i$，把模型写成如下形式会很方便：

$$
\mathbf Y = X\boldsymbol\beta + \boldsymbol\eps,
$$

其中$\mathbf Y\in\R^n$，$X$是$n\times(p+1)$的**设计矩阵**，其第$i$行为$(1, x_{i1},\ldots,x_{ip})$，而$\boldsymbol\beta = (\beta_0,\ldots,\beta_p)\T$。最小二乘法使$\lVert\mathbf Y - X\mathbf b\rVert^2$最小，由[[linear-algebra/least-squares]]，最小值点满足正规方程$X\T X\mathbf b = X\T\mathbf Y$。若$X$列满秩，则

$$
\hat{\boldsymbol\beta} = (X\T X)^{-1}X\T\mathbf Y .
$$ {#eq-normal-equations}

从几何上看，拟合值向量$X\hat{\boldsymbol\beta}$是$\mathbf Y$在$X$的列空间上的正交投影，残差向量与该空间正交——这就是正规方程以及分解$\mathrm{SST} = \mathrm{SSR} + \mathrm{SSE}$（勾股定理）的矩阵形式。$\hat{\boldsymbol\beta}$的协方差矩阵为$\sigma^2(X\T X)^{-1}$，$\sigma^2$由$\mathrm{SSE}/(n-p-1)$来估计，每个系数都有一个自由度为$n-p-1$的 t 检验。高斯-马尔可夫定理以同样的形式成立。多元回归使我们能够在对其他变量进行**调整**的同时估计某一个变量的效应——不过，调整只能消除由已测量的变量所造成的混杂。

::: quiz
一位飞行教练注意到，学员在一次异常平稳的着陆后受到表扬，下一次通常就表现得差一些；而在一次异常粗糙的着陆后受到批评，下一次通常就会有所改进。最可能的解释是什么？
- [ ] 表扬使学员自满，批评使他们更加努力。
- [x] 向均值回归：一次异常好或异常差的着陆部分是运气所致，下一次着陆很可能更接近该学员的平均水平。
- [ ] 各次着陆是相互独立的，所以不应该有任何规律；是教练记错了。
- [ ] 学员们越来越疲劳了。
::: solution
相继几次着陆的质量是正相关的，但相关并不完全，所以平均而言，极端的表现之后会跟着不那么极端的表现——无论教练说了什么。表扬和批评也许确有效果，但这种规律无法揭示它们；需要与没有得到任何反馈的学员进行比较。
:::
:::

::: history
最小二乘法由阿德里安-马里·勒让德（Adrien-Marie Legendre）于1805年发表，见于他关于彗星轨道的一部著作的附录。卡尔·弗里德里希·高斯（Carl Friedrich Gauss）于1809年发表了这一方法，声称自己自1795年起就一直在使用它，并通过假定误差服从正态分布来论证其合理性；19世纪20年代，他证明了这一方法在线性无偏估计量中的最优性，这一结果后来由安德烈·马尔可夫（Andrey Markov）重新表述，现在称为高斯-马尔可夫定理。“回归”一词来自弗朗西斯·高尔顿（Francis Galton）1886年对$928$名成年子女及其父母身高的研究。卡尔·皮尔逊（Karl Pearson）发展了相关的数学理论，乔治·乌德尼·尤尔（George Udny Yule）于1897年把回归推广到多个变量的情形。罗纳德·费希尔（Ronald Fisher）在20世纪20年代推导出回归系数的精确抽样分布，并引入了方差分析。
:::

## 后续内容 {#where-next}

回归是通往大部分应用统计学的门户。方差分析在同一个线性模型框架内比较多个组的均值；**广义线性模型**（用于二值结果的逻辑斯谛回归、用于计数的泊松回归）借助最大似然（[[statistics/estimation]]）把它推广到非正态的响应；而当解释变量很多时，岭回归和 lasso（套索）等正则化方法会像[[statistics/estimation#thm-mse]]中那样，有意地以偏差换取方差。对线性模型的贝叶斯处理——给$\boldsymbol\beta$赋予一个先验——是[[statistics/bayesian]]一章的直接推广。在数值上，最小二乘问题不是通过求$X\T X$的逆来求解的，而是借助 QR 分解或奇异值分解（[[linear-algebra/svd]]）。

::: summary
- 最小二乘法使$\sum(y_i - b_0 - b_1x_i)^2$最小：$\hat\beta_1 = S_{xy}/S_{xx}$，$\hat\beta_0 = \bar y - \hat\beta_1\bar x$；残差之和为零，直线经过$(\bar x,\bar y)$。
- 在模型$Y_i = \beta_0 + \beta_1x_i + \eps_i$下，若误差互不相关且方差为$\sigma^2$，则$\hat\beta_1$是无偏的，方差为$\sigma^2/S_{xx}$，并且它是最佳线性无偏估计量（高斯-马尔可夫定理）。
- $s^2 = \mathrm{SSE}/(n-2)$是$\sigma^2$的估计；当误差服从正态分布时，$(\hat\beta_1-\beta_1)/(s/\sqrt{S_{xx}})\sim t_{n-2}$，由此得到斜率的区间估计和检验。
- 均值响应的置信区间比新观测值的预测区间窄得多；两者在远离$\bar x$处都会变宽。
- $\mathrm{SST} = \mathrm{SSR} + \mathrm{SSE}$，$R^2 = r^2$是由直线解释的变差所占的比例。
- 用残差图检验各项假设；要警惕离群点、高杠杆点、弯曲和非恒定方差。
- 相关不等于因果，外推有风险，向均值回归可能伪装成处理效应。
:::

## 习题

::: exercise 手算斜率 {level=1 check="1.9"}
对点$(1,3)$，$(2,5)$，$(3,6)$，$(4,9)$，计算$\hat\beta_1$和$\hat\beta_0$。请输入斜率。
::: solution
$\bar x = 2.5$，$\bar y = 5.75$。离差$x_i - \bar x$为$-1.5, -0.5, 0.5, 1.5$，$y_i - \bar y$为$-2.75, -0.75, 0.25, 3.25$，所以$S_{xx} = 2.25 + 0.25 + 0.25 + 2.25 = 5$，$S_{xy} = 4.125 + 0.375 + 0.125 + 4.875 = 9.5$。因此$\hat\beta_1 = 9.5/5 = 1.9$，$\hat\beta_0 = 5.75 - 1.9\times2.5 = 1$：直线为$\hat y = 1 + 1.9x$。
:::
:::

::: exercise 由相关系数求 R² {level=1 check="0.64"}
两个变量之间的相关系数为$r = -0.8$。$y$的方差中有多大比例能由最小二乘直线解释？
::: solution
$R^2 = r^2 = 0.64$：无论$r$的符号如何，都是$64\%$。
:::
:::

::: exercise 斜率的单位 {level=1 check="2.642/60"}
在[[#ex-revision]]中，斜率为每小时$2.642$分。如果复习时间以分钟计，斜率是多少？
::: solution
一分钟是一小时的$1/60$，所以斜率变为每分钟$2.642/60\approx0.044$分。一般地，把$x$乘以因子$a$，斜率就除以$a$；拟合值、残差和$R^2$都不变。
:::
:::

::: exercise 斜率的检验 {level=2}
对$n = 20$个观测值所作的回归给出$\hat\beta_1 = 1.5$，标准误为$0.6$。在$5\%$的水平下检验$H_0$：$\beta_1 = 0$（$t_{18,0.025} = 2.101$），并给出$\beta_1$的$95\%$置信区间。
::: solution
$t = 1.5/0.6 = 2.5>2.101$，所以拒绝$H_0$（双侧 p 值约为$0.022$）。置信区间为$1.5\pm2.101\times0.6 = [0.24, 2.76]$，它不包含$0$，与检验结果一致。
:::
:::

::: exercise 直接写出回归直线 {level=2 check="56"}
对一组成对的测量值，$\bar x = 20$，$\bar y = 50$，$s_x = 4$，$s_y = 10$，$r = 0.6$。求由$x$预测$y$的最小二乘直线，以及$x = 24$时$y$的预测值。
::: solution
$\hat\beta_1 = S_{xy}/S_{xx} = r\,s_y/s_x = 0.6\times10/4 = 1.5$，$\hat\beta_0 = 50 - 1.5\times20 = 20$，所以$\hat y = 20 + 1.5x$。在$x = 24$处（比$\bar x$高一个标准差），$\hat y = 56$，比$\bar y$高$0.6$个标准差：这正是向均值回归的体现。
:::
:::

::: exercise x 对 y 的回归 {level=2}
证明：由$y$预测$x$的最小二乘直线一般与由$x$预测$y$的最小二乘直线不是同一条直线：以标准单位计，当两条直线都画在$(x, y)$平面上时，它们的斜率分别为$r$和$1/r$。它们何时重合？
::: solution
以标准单位计，$y$对$x$的回归直线为$\hat y = rx$。由对称性，$x$对$y$的回归直线为$\hat x = ry$，画在$(x,y)$平面上就是$y = x/r$，斜率为$1/r$。两条直线仅当$r = 1/r$，即$r = \pm1$时重合，此时所有点都恰好落在一条直线上。否则，两条直线都经过均值点，而$y$对$x$的直线较为平缓：每条直线都向被预测变量的均值回归。
:::
:::

::: exercise 残差与 x 不相关 {level=3}
证明：对带截距的最小二乘拟合，残差满足$\sum_ie_i = 0$和$\sum_i(x_i - \bar x)e_i = 0$，因此残差与$x$的样本相关系数为零。解释为什么这意味着残差图能揭示弯曲，却永远不会显示出线性趋势。
::: solution
[[#thm-least-squares]]中的正规方程说的正是$\sum_ie_i = 0$和$\sum_ix_ie_i = 0$。于是$\sum_i(x_i-\bar x)e_i = \sum_ix_ie_i - \bar x\sum_ie_i = 0$，所以$x$与$e$的样本协方差为零，从而样本相关系数也为零。数据中的任何线性趋势都已被拟合直线吸收，所以按构造，残差关于$x$没有线性趋势；在残差图中仍然可见的是**非线性**模式（弯曲）、散布程度的变化以及孤立的离群点。
:::
:::

::: exercise 拟合值的方差 {level=3}
在线性模型下，证明$\Var(\hat\beta_0 + \hat\beta_1x_0) = \sigma^2\Bigl(\dfrac1n + \dfrac{(x_0-\bar x)^2}{S_{xx}}\Bigr)$，并由此推出均值响应在$x_0 = \bar x$处估计得最精确。
::: solution
$\hat\beta_0 + \hat\beta_1x_0 = \bar Y + \hat\beta_1(x_0-\bar x)$。由[[#eq-slope-linear]]，$\Cov(\bar Y,\hat\beta_1) = \sum_i\frac1nc_i\sigma^2 = \frac{\sigma^2}{n}\sum_ic_i = 0$。因此

$$
\Var\bigl(\bar Y + \hat\beta_1(x_0-\bar x)\bigr) = \frac{\sigma^2}{n} + (x_0-\bar x)^2\frac{\sigma^2}{S_{xx}},
$$

它在$x_0 = \bar x$时最小，等于$\sigma^2/n$，并且随着$x_0$远离数据的中心而按二次方增长。
:::
:::
