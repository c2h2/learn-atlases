20世纪20年代，在洛桑（Rothamsted）农业试验站的一次下午茶上，罗纳德·费希尔（Ronald Fisher）的同事缪丽尔·布里斯托（Muriel Bristol）声称，她能凭味道分辨出杯中的奶是在茶之前还是在茶之后倒进去的。费希尔后来用这个故事来说明应当如何检验这样的说法。准备八杯茶，两种各四杯，按随机顺序端给她，并告诉她两种各有四杯。如果她根本没有这种分辨能力，她就只不过是从$8$杯中随机选出$4$杯，而恰好选中正确的那四杯的机会是$1/\binom84 = 1/70\approx0.014$。所以，如果她八杯全都判断正确，那么要么她运气非常好——机会只有$1.4\%$——要么她真的能分辨出其中的差别。

这就是**显著性检验**的逻辑：为了论证，先假定没有发生任何值得注意的事情（**原假设**），然后追问在这一假定下数据会有多么出人意料。如果数据会非常出人意料，我们就有了不利于原假设的证据。本章用**p 值**把这一逻辑形式化，考察检验可能犯的两类错误以及检测出真实效应的**功效**，建立标准的 z 检验、t 检验和卡方检验，证明关于最优检验的**奈曼-皮尔逊（Neyman–Pearson）引理**，最后讨论检验常见的误用方式。

## 显著性检验的逻辑 {#logic}

::: definition 假设与检验统计量 {#def-hypotheses}
**统计假设**是关于数据分布的陈述，通常是关于某个参数$\theta$的陈述。检验把**原假设**$H_0$（通常是“没有效应”，例如$\theta = \theta_0$）与**备择假设**$H_1$（例如$\theta\ne\theta_0$，这是**双侧**备择假设；或$\theta>\theta_0$，这是**单侧**备择假设）进行比较。**检验统计量**$T$是按如下方式选取的统计量：它的值若远离$H_0$所预测的值，就构成支持$H_1$的证据。
:::

::: definition p 值 {#def-p-value}
设$T$的大值是不利于$H_0$的证据，$t$为观测值。**p 值**定义为

$$
p = \Prob_{H_0}(T\ge t),
$$

即在假定$H_0$为真的前提下计算出的、得到至少与观测值一样极端的检验统计量的概率。（对双侧检验，“极端”包括两侧的尾部。）
:::

p 值小，意味着如果$H_0$为真，这样的数据就是不寻常的。按照惯例，$p<0.05$的结果常被称为**统计显著**的，$p<0.01$的结果则称为高度显著的；但 p 值是对证据的一种连续的度量，这些阈值只是惯例，而不是定律。

::: example 一枚可疑的硬币 {#ex-coin-test}
将一枚硬币抛掷$100$次，出现了$60$次正面。这枚硬币是均匀的吗？
::: solution
设$\theta$为出现正面的概率（字母$p$留给 p 值）。取$H_0$：$\theta = \tfrac12$，对双侧备择假设$H_1$：$\theta\ne\tfrac12$，并以正面次数$X$作为检验统计量。在$H_0$下，$X\sim\Bin(100,\tfrac12)$，至少与$60$一样极端的结果是$X\ge60$或$X\le40$。由对称性，

$$
p = 2\,\Prob_{H_0}(X\ge60) = 2\times0.0284 = 0.057 .
$$

（带连续性修正的正态近似给出$2(1-\Phi(1.9)) = 0.057$，与此一致。）用一枚均匀的硬币做这样的试验，大约$6\%$的试验会出现至少与六十次正面一样极端的结果：这是硬币有偏的一些证据，但不是强有力的证据。在$5\%$的水平下，我们不会拒绝“硬币是均匀的”这一假设。
:::
:::

## 错误、显著性水平与功效 {#errors}

p 值度量的是证据。耶日·奈曼（Jerzy Neyman）和埃贡·皮尔逊（Egon Pearson）的方法则把检验看作一种**决策规则**，并追问它犯错的频率有多高。

::: definition 检验、错误与功效 {#def-errors}
$H_0$对$H_1$的一个**检验**是这样一条规则：当数据落入**拒绝域**$R$时拒绝$H_0$。**第一类错误**是在$H_0$为真时拒绝了它；**第二类错误**是在$H_0$为假时没有拒绝它。如果对$H_0$中的每个$\theta$都有$\Prob_\theta(\text{拒绝 }H_0)\le\alpha$，就称该检验的**显著性水平**为$\alpha$。检验在$H_1$中的参数值$\theta$处的**功效**是$\Prob_\theta(\text{拒绝 }H_0)$，即1减去在$\theta$处犯第二类错误的概率。
:::

| | $H_0$为真 | $H_0$为假 |
|---|---|---|
| 拒绝$H_0$ | 第一类错误（概率$\le\alpha$） | 正确（概率 = 功效） |
| 不拒绝$H_0$ | 正确 | 第二类错误 |

两类错误此消彼长：缩小拒绝域会降低$\alpha$，但也会降低功效。通常的做法是先固定$\alpha$（常取$0.05$），再选择检验方法和样本量，使功效尽可能大。两种观点之间的联系很简单：当$p\le\alpha$时拒绝，就得到一个显著性水平为$\alpha$的检验。

::: theorem 原假设下 p 值服从均匀分布 {#thm-p-uniform}
设在$H_0$下检验统计量$T$具有连续的分布函数$F$，且大值是不利于$H_0$的证据，从而 p 值为$P = 1 - F(T)$。那么在$H_0$下，$P$服从$[0,1]$上的均匀分布。特别地，对每个$\alpha\in[0,1]$，都有$\Prob_{H_0}(P\le\alpha) = \alpha$。
:::

::: proof
由概率积分变换（[[probability/continuous-random-variables#thm-inverse-transform]]），在$H_0$下$F(T)\sim\operatorname{U}(0,1)$。（那个定理还假定$F$在$0<F<1$的范围内严格递增，但只要$F$连续就够了：对$u\in(0,1)$，令$x_u$为满足$F(x) = u$的最大的$x$，由于$F$连续且两端的极限分别为$0$和$1$，这样的$x_u$存在；于是$F(T)\le u$当且仅当$T\le x_u$，所以$\Prob(F(T)\le u) = F(x_u) = u$。）若$U$服从均匀分布，则$1-U$也服从均匀分布，所以$P = 1-F(T)$服从均匀分布，且$\Prob(P\le\alpha) = \alpha$。
:::

所以当原假设为真时，p 值不过是一个均匀分布的随机数：按其构造方式，为真的原假设中有$5\%$会产生$p<0.05$。（对于离散的统计量，例如上面的二项计数，$\Prob_{H_0}(P\le\alpha)\le\alpha$，因此检验是保守的。）

### z 检验及其功效

对于$\sigma$已知时正态总体的均值（数学期望），检验$H_0$：$\mu = \mu_0$使用统计量

$$
Z = \frac{\bar X - \mu_0}{\sigma/\sqrt n},
$$ {#eq-z-stat}

它在$H_0$下服从$\Normal(0,1)$。对$H_1$：$\mu>\mu_0$，当$Z>z_\alpha$时拒绝；对$H_1$：$\mu\ne\mu_0$，当$\lvert Z\rvert>z_{\alpha/2}$时拒绝。对于[[statistics/sampling#ex-bolts]]中的螺栓，$z = (50.08 - 50)/0.04 = 2.0$，所以双侧 p 值为$2(1-\Phi(2)) = 0.046$：在$5\%$的水平下是显著的，但只是勉强显著。

若真实均值为$\mu>\mu_0$，则$Z$服从均值为$\delta\sqrt n/\sigma$的正态分布，其中$\delta = \mu-\mu_0$，单侧检验的功效为

$$
\Prob_\mu(Z>z_\alpha) = 1 - \Phi\Bigl(z_\alpha - \frac{\delta\sqrt n}{\sigma}\Bigr).
$$ {#eq-power}

功效随**效应量**$\delta/\sigma$的增大而增大，也随$\sqrt n$的增大而增大。令功效等于$1-\beta$，就得到样本量公式

$$
n = \Bigl(\frac{(z_\alpha + z_\beta)\,\sigma}{\delta}\Bigr)^2 .
$$ {#eq-sample-size}

::: example 规划一项研究 {#ex-power}
预计一种新的教学方法能使成绩提高半个标准差。要使$\alpha = 0.05$的单侧 z 检验的功效达到$0.8$，需要多少名学生？
::: solution
这里$\delta/\sigma = 0.5$，$z_{0.05} = 1.645$，$z_{0.2} = 0.842$，所以由[[#eq-sample-size]]，

$$
n = \Bigl(\frac{1.645 + 0.842}{0.5}\Bigr)^2 = 24.7,
$$

所以需要$25$名学生；此时功效为$1-\Phi(1.645 - 2.5) = 0.80$。对双侧检验（$z_{0.025} = 1.96$），所需人数增加到$32$。要检测出只有一半大小的效应，需要四倍的学生。规模太小、无法检测出合理大小的效应的研究，是浪费精力和产生误导性结果的一个主要根源。
:::
:::

::: widget hypothesis
test: z
tail: right
alpha: 0.05
effect: 0.5
n: 25
caption: z 统计量在$H_0$下（以$0$为中心）和在备择假设下（以$\delta\sqrt n/\sigma = 2.5$为中心）的抽样分布。原假设曲线右尾的阴影部分面积为$\alpha$；备择假设曲线在临界值以外的部分就是功效，这里约为$0.80$。增大$n$或效应量，两条曲线就会分开；降低$\alpha$，临界值就向右移动，第一类错误的概率和功效都随之减小。
:::

::: quiz
某检验给出$p = 0.03$。下列哪个说法是正确的？
- [ ] $H_0$为真的概率是$0.03$。
- [ ] 该结果是由偶然因素造成的概率为$3\%$。
- [x] 如果$H_0$为真，至少如此极端的结果出现的概率为$0.03$。
- [ ] $H_1$为真的概率为$97\%$。
::: solution
p 值是在**假定**$H_0$为真的前提下计算的，所以它是关于数据的概率，而不是关于假设的概率。要把它转化为$\Prob(H_0\mid\text{数据})$，需要用到贝叶斯定理以及$H_0$的先验概率，正如[[probability/conditional-probability#ex-diagnostic]]中诊断检测的计算那样；两者可能相差悬殊。
:::
:::

## 均值的检验 {#mean-tests}

当$\sigma$未知时，用$S$代替它，并使用学生氏分布（[[statistics/sampling#cor-t-statistic]]）。$H_0$：$\mu = \mu_0$的**单样本 t 检验**使用统计量

$$
T = \frac{\bar X-\mu_0}{S/\sqrt n},
$$

对正态数据，它在$H_0$下服从$t_{n-1}$分布。

::: example 咖啡比广告说的更浓吗？ {#ex-t-test}
[[statistics/confidence-intervals#ex-caffeine]]中的咖啡馆宣称每杯咖啡含$95$ mg咖啡因。测量的八杯咖啡有$\bar x = 100.75$，$s = 5.55$。检验$H_0$：$\mu = 95$对$H_1$：$\mu\ne95$。
::: solution
检验统计量为

$$
t = \frac{100.75 - 95}{5.55/\sqrt8} = \frac{5.75}{1.962} = 2.93,
$$

自由度为$7$，双侧 p 值为$2\,\Prob(t_7>2.93) = 0.022$。有相当有力的证据表明，咖啡因的平均含量不同于$95$ mg（看来要更高）。与此一致的是，$95$落在前面求出的$95\%$置信区间$[96.1, 105.4]$之外。
:::
:::

::: widget hypothesis
test: t
tail: two
alpha: 0.05
effect: 1
n: 8
observed: 2.93
caption: 咖啡检验在原假设下的$t_7$分布，图中标出了双侧拒绝域$\lvert t\rvert>2.365$和观测到的统计量$t = 2.93$；p 值是$\pm2.93$以外的总面积，约为$0.022$。改为单侧检验，p 值就减半——这正是备择假设必须在查看数据之前选定的原因。
:::

这个例子中检验与区间的一致并非偶然。

::: theorem 检验与置信区间的对偶性 {#thm-duality}
设对每个$\theta_0$，都有$H_0$：$\theta = \theta_0$的一个显著性水平为$\alpha$的检验，其接受域为$A(\theta_0)$（即使$H_0$不被拒绝的那些数据）。则$C(x) = \{\theta_0 : x\in A(\theta_0)\}$是$\theta$的一个$1-\alpha$置信集。反之，若$C$是一个$1-\alpha$置信集，则当$\theta_0\notin C(x)$时拒绝$\theta = \theta_0$的检验的显著性水平为$\alpha$。
:::

::: proof
对真值$\theta$，由$C$的定义，事件$\{\theta\in C(X)\}$与$\{X\in A(\theta)\}$是同一个事件。因此$\Prob_\theta(\theta\in C(X)) = \Prob_\theta(X\in A(\theta))\ge1-\alpha$，这是因为$\theta_0 = \theta$的检验的水平为$\alpha$。逆命题是把同一个恒等式反过来读：$\Prob_{\theta_0}(\text{拒绝}) = \Prob_{\theta_0}(\theta_0\notin C(X))\le\alpha$。
:::

所以水平为$0.05$的双侧 t 检验拒绝$\mu = \mu_0$，当且仅当$\mu_0$落在$95\%$ t 区间之外。报告区间比报告检验结果传达的信息更多：它既表明效应是否能被检测出来，也表明效应可能有多大。

当数据成对出现时，正确的检验是对差值应用单样本 t 检验。

::: example 配对比较 {#ex-paired}
八名患者在服用一种新药一个月之前和之后的收缩压（mmHg）如下：

| 患者 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 服药前 | 142 | 150 | 138 | 160 | 147 | 155 | 149 | 152 |
| 服药后 | 135 | 148 | 136 | 150 | 145 | 147 | 146 | 144 |

检验这种药物是否能降低血压。
::: solution
差值（服药前减服药后）为$7, 2, 2, 10, 2, 8, 3, 8$，其均值$\bar d = 5.25$，标准差$s_d = 3.33$。检验$H_0$：$\mu_d = 0$，

$$
t = \frac{5.25}{3.33/\sqrt8} = 4.46,
$$

自由度为$7$，双侧 p 值为$0.003$：这是血压下降的有力证据。如果错误地把两组数据当作独立样本，两样本 t 检验将给出$t = 1.67$和$p = 0.12$，因为患者**之间**的巨大差异会淹没每位患者**自身**一致的变化。配对（以及在实验中采用随机化设计）是提高功效最有效的方法之一。
:::
:::

## 卡方检验 {#chi-square}

对于分类数据，卡尔·皮尔逊（Karl Pearson）的统计量把$k$个类别中的观测频数$O_j$与$H_0$下的期望频数$E_j$进行比较：

$$
X^2 = \sum_{j=1}^k\frac{(O_j - E_j)^2}{E_j}.
$$ {#eq-pearson}

大值表明拟合不佳。皮尔逊（于1900年）证明了：如果$H_0$完全确定了各类别的概率，那么随着样本量的增大，$X^2$在$H_0$下的分布收敛于$\chi^2_{k-1}$；之所以损失一个自由度，是因为各频数之和必须等于$n$。如果为了计算$E_j$而从数据中估计了$m$个参数，自由度就减少为$k-1-m$（这一修正归功于费希尔）。通常认为，当所有$E_j\ge5$时，这一近似就足够好。证明要用到多元中心极限定理，可参看弗格森（Ferguson）的《大样本理论教程》（A Course in Large Sample Theory，1996）第9章。

::: example 这颗骰子均匀吗？ {#ex-die-test}
将一颗骰子掷$120$次，点数$1$到$6$出现的次数分别为$15, 22, 18, 26, 17, 22$。检验这颗骰子是否均匀。
::: solution
在$H_0$下，每一面出现的概率都是$\tfrac16$，所以$E_j = 20$。于是

$$
X^2 = \frac{25 + 4 + 4 + 36 + 9 + 4}{20} = \frac{82}{20} = 4.1,
$$

自由度为$6 - 1 = 5$。$5\%$临界值为$\chi^2_{5,0.05} = 11.07$，p 值为$0.54$。这些偏差完全在偶然因素所能造成的范围之内；没有证据表明这颗骰子是有偏的。（这并不能证明它是均匀的——掷$120$次很可能发现不了微小的偏差。）
:::
:::

::: example 孟德尔的豌豆 {#ex-mendel}
格雷戈尔·孟德尔（Gregor Mendel）在他1866年的论文中报告了$15$株杂种豌豆植株自交所结的$556$粒种子：圆粒黄色$315$粒，圆粒绿色$108$粒，皱粒黄色$101$粒，皱粒绿色$32$粒。他的理论预测的比例为$9:3:3:1$。检验拟合的好坏。
::: solution
期望频数为$556\times\tfrac{9}{16} = 312.75$、$104.25$、$104.25$和$34.75$。于是

$$
X^2 = \frac{2.25^2}{312.75} + \frac{3.75^2}{104.25} + \frac{3.25^2}{104.25} + \frac{2.75^2}{34.75}\approx0.47,
$$

自由度为$3$，得到$p = 0.93$。拟合得非常好。1936年，费希尔综合了孟德尔的许多实验，论证说拟合好得**过分**，令人难以置信——也就是说，像孟德尔所得到的那样小的$X^2$值，仅凭偶然很少会出现——这一论断至今仍有争议。
:::
:::

::: widget distribution
dist: chisq
params: k=3
a: 7.815
b: 20
caption: $\chi^2_3$分布，阴影部分是$5\%$拒绝域$X^2>7.815$。孟德尔的$X^2 = 0.47$远远偏在左边，处于几乎完全吻合的区域。把自由度改为$5$，找出骰子的$X^2 = 4.1$：它稳稳地落在分布的主体部分之内。
:::

同一个统计量也可以检验列联表中的**独立性**。如果把$n$个个体按两个分类变量归入一个$r\times c$表，其行合计为$R_i$，列合计为$C_j$，那么在独立性假设下，单元格$(i,j)$中的期望频数的估计值为$E_{ij} = R_iC_j/n$，而$X^2 = \sum_{i,j}(O_{ij}-E_{ij})^2/E_{ij}$近似服从$\chi^2_{(r-1)(c-1)}$。

::: example 一项疫苗试验 {#ex-contingency}
在一项试验中，$200$人接种了疫苗，$200$人接种了安慰剂；接种疫苗者中有$10$人感染，安慰剂组中有$30$人感染。检验感染与否是否独立于所接受的处理。
::: solution
频数表（连同边缘合计）为

| | 感染 | 未感染 | 合计 |
|---|---|---|---|
| 疫苗组 | $10$ | $190$ | $200$ |
| 安慰剂组 | $30$ | $170$ | $200$ |
| 合计 | $40$ | $360$ | $400$ |

在独立性假设下，每组的期望频数为感染$200\times40/400 = 20$人、未感染$180$人，所以

$$
X^2 = \frac{10^2}{20} + \frac{10^2}{180} + \frac{10^2}{20} + \frac{10^2}{180} = 11.1,
$$

自由度为$(2-1)(2-1) = 1$，得到$p = 0.0009$。感染与处理有关的证据很强；估计的感染率分别为$5\%$和$15\%$，降低了三分之二。由于处理是随机分配的，这种相依关系可以解释为因果关系。
:::
:::

## 奈曼-皮尔逊引理 {#neyman-pearson}

应该使用哪一个检验统计量？对最简单的情形——两个完全确定的假设——有一个明确的答案。

::: theorem 奈曼-皮尔逊引理 {#thm-neyman-pearson}
设数据$X$在$H_0$下的密度（或概率质量函数）为$f_0$，在$H_1$下为$f_1$。对$k>0$，令$R = \{x : f_1(x)>kf_0(x)\}$，$\alpha = \Prob_0(X\in R)$。则每个拒绝域为$R'$且满足$\Prob_0(X\in R')\le\alpha$的检验，其功效都不超过$R$的功效：$\Prob_1(X\in R')\le\Prob_1(X\in R)$。
:::

::: proof
考虑函数$g(x) = \bigl(\mathbf{1}_R(x) - \mathbf{1}_{R'}(x)\bigr)\bigl(f_1(x) - kf_0(x)\bigr)$。若$x\in R$，则第一个因子$\ge0$，第二个因子$>0$；若$x\notin R$，则第一个因子$\le0$，第二个因子也$\le0$。所以处处有$g\ge0$，积分（或求和）得

$$
0\le\int g = \bigl(\Prob_1(R) - \Prob_1(R')\bigr) - k\bigl(\Prob_0(R) - \Prob_0(R')\bigr).
$$

由于$k>0$且$\Prob_0(R')\le\alpha = \Prob_0(R)$，第二个括号非负，所以$\Prob_1(R)\ge\Prob_1(R')$。
:::

因此，最大功效检验在**似然比**$f_1(x)/f_0(x)$较大时拒绝原假设。这为如下直觉提供了形式上的依据：证据的强弱取决于备择假设对数据的解释比原假设好多少。

::: example z 检验是最大功效检验 {#ex-np-normal}
设$X_1,\ldots,X_n\iid\Normal(\mu,\sigma^2)$，其中$\sigma$已知。求$H_0$：$\mu = \mu_0$对$H_1$：$\mu = \mu_1$的水平为$\alpha$的最大功效检验，其中$\mu_1>\mu_0$。
::: solution
似然比为

$$
\frac{f_1(x)}{f_0(x)} = \exp\Bigl(-\frac{1}{2\sigma^2}\sum_i\bigl[(x_i-\mu_1)^2 - (x_i-\mu_0)^2\bigr]\Bigr) = \exp\Bigl(\frac{n(\mu_1-\mu_0)}{\sigma^2}\bar x - \frac{n(\mu_1^2-\mu_0^2)}{2\sigma^2}\Bigr),
$$

由于$\mu_1>\mu_0$，它是$\bar x$的增函数。所以“$f_1/f_0>k$”等价于对某个$c$成立的“$\bar x>c$”，而取$c = \mu_0 + z_\alpha\sigma/\sqrt n$就使检验的真实水平为$\alpha$：这正是单侧 z 检验。由于这个检验不依赖于$\mu_1>\mu_0$的具体取值，它对所有这样的备择假设同时是最大功效的——它是$H_0$对$H_1$：$\mu>\mu_0$的一个**一致最大功效**检验。
:::
:::

对于复合假设，通常不存在单一的最优检验，通用的方法是**似然比检验**，它比较在$H_0$下和在$H_1$下似然函数的最大值。由塞缪尔·威尔克斯（Samuel Wilks）的一个定理（1938年），在大样本下，对该比值取$2\ln$后近似服从卡方分布，其自由度等于$H_0$所固定的参数个数；皮尔逊的$X^2$是它的一个很好的近似。

## 正确使用检验 {#pitfalls}

::: warning 对 p 值的五种误读
1. p 值不是$H_0$为真的概率，也不是“该结果是由偶然因素造成的”的概率。
2. $p>0.05$并不表明$H_0$为真：没有证据并不等于有证据证明不存在，在功效低的小型研究中尤其如此。
3. 统计显著性不等于实际重要性。有一百万个观测值时，$0.1$个智商分的差异也可能是高度显著的；应当用置信区间报告效应的大小。
4. 一项研究中 p 值为$0.04$，另一项研究中为$0.06$，两者并不“矛盾”：证据几乎是一样的。
5. 根据数据来选择分析方式（选哪个结局指标、哪个子群体、哪种检验）之后再计算出的 p 值是无效的。尝试许多种分析，然后只报告“奏效”的那一种，这种做法称为**p 值操纵**（p-hacking）。
:::

最后一点是**多重检验**问题的一个例子。如果对$20$个为真的原假设分别独立地在水平$0.05$下进行检验，那么至少出现一个“显著”结果的机会为$1 - 0.95^{20}\approx0.64$。最简单的补救办法是控制出现任何错误拒绝的概率。

::: theorem 邦费罗尼（Bonferroni）校正 {#thm-bonferroni}
如果对$m$个假设分别在水平$\alpha/m$下进行检验，那么无论各检验之间有怎样的相依关系，至少拒绝一个为真的原假设的概率（**族错误率**）都至多为$\alpha$。
:::

::: proof
设$A_j$是第$j$个为真的原假设被拒绝这一事件；这样的假设至多有$m$个，且每个都满足$\Prob(A_j)\le\alpha/m$。由并集界（[[probability/probability-spaces#thm-union-bound]]），$\Prob\bigl(\bigcup_jA_j\bigr)\le\sum_j\Prob(A_j)\le m\cdot\frac{\alpha}{m} = \alpha$。
:::

当$m$很大时，邦费罗尼校正是保守的；在基因组学中，要同时检验成千上万个基因，人们转而控制错误发现的期望比例，这就是本雅明尼（Benjamini）和霍赫贝格（Hochberg）于1995年提出的方法。

::: quiz
一项小型研究发现某种疗法能减轻症状，但$p = 0.20$。最合理的结论是什么？
- [ ] 该疗法无效。
- [ ] 该疗法有效，但只对$20\%$的患者有效。
- [x] 数据没有为任何一方提供令人信服的证据；这项研究可能只是规模太小了。
- [ ] 该疗法有效的机会为$80\%$。
::: solution
结果不显著意味着数据与“没有效应”相容——但如果研究的功效很低，数据也可能与相当大的效应相容。看一看效应的置信区间：如果它很宽，既包含零，又包含具有临床意义的值，那么诚实的结论是“信息不足”。
:::
:::

::: history
约翰·阿巴斯诺特（John Arbuthnot）于1710年发表了一个早期的显著性检验：从1629年到1710年的$82$年中，每一年在伦敦受洗的男孩都多于女孩；如果每一年两种情形出现的可能性相同，这种情况发生的概率就是$(1/2)^{82}$，他把这看作神意的证据。卡尔·皮尔逊（Karl Pearson）的卡方检验（1900年）和学生氏（Student）t 检验（1908年）开创了现代理论。罗纳德·费希尔（Ronald Fisher）的《研究工作者的统计方法》（Statistical Methods for Research Workers，1925年）使 p 值和$5\%$的惯例成为科学研究中的标准做法，他的《实验设计》（The Design of Experiments，1935年）则介绍了女士品茶的实验。耶日·奈曼（Jerzy Neyman）和埃贡·皮尔逊（Egon Pearson）把检验重新表述为一个带有两类错误的决策问题，其顶点是他们于1933年提出的引理；费希尔从未接受他们的方法，而现代的做法是这两种观点之间一种并不融洽的混合。出于对 p 值被误用的担忧，美国统计协会于2016年发布了一份关于 p 值的正式声明。
:::

## 后续内容 {#where-next}

回归系数的检验与置信区间将在[[statistics/regression]]一章中展开；用于比较嵌套回归模型的 F 检验以[[statistics/sampling#def-f]]中的 F 分布为基础，是超出本课程范围的自然的下一步。显著性检验的贝叶斯替代方案以贝叶斯因子和假设的后验概率为基础，将在[[statistics/bayesian]]一章中介绍；它回答的是“给定数据后，$H_0$成立的可能性有多大？”这个问题，而 p 值常常被误读为在回答这个问题。本课程之外，还有不假定正态性的非参数检验（秩检验、置换检验）、用于比较多个组的方差分析，以及序贯检验理论。

::: summary
- 检验先假定$H_0$成立，再追问数据有多么出人意料；p 值是在$H_0$成立时，出现至少与观测结果一样极端的结果的概率。
- 第一类错误：拒绝了为真的$H_0$（概率$\le\alpha$）；第二类错误：漏掉了真实存在的效应；功效$=\Prob(\text{拒绝}\mid H_1)$随效应量和$\sqrt n$的增大而增大。
- 在$H_0$下，连续型的 p 值服从均匀分布，所以$\Prob(p\le\alpha) = \alpha$。
- $\sigma$已知时用 z 检验；$\sigma$需要估计时用 t 检验；配对数据通过其差值来分析。
- 检验与置信区间是对偶的：$\theta_0$在水平$\alpha$下被拒绝，当且仅当它落在$1-\alpha$区间之外。
- 皮尔逊的$X^2 = \sum(O-E)^2/E$近似服从卡方分布：拟合优度检验的自由度为$k-1$，独立性检验的自由度为$(r-1)(c-1)$。
- 奈曼-皮尔逊引理：对简单假设，在似然比较大时拒绝原假设的检验是最大功效检验。
- p 值不是$\Prob(H_0\mid\text{数据})$；不显著不能证明没有效应；要对多重检验进行校正（邦费罗尼校正：每个检验都在水平$\alpha/m$下进行）。
:::

## 习题

::: exercise z 统计量 {level=1 check="1.2"}
从$\sigma = 15$的正态总体中抽取容量为$36$的样本，得到$\bar x = 103$。对$H_0$：$\mu = 100$计算 z 统计量和双侧 p 值。
::: solution
$z = (103-100)/(15/6) = 3/2.5 = 1.2$，$p = 2(1-\Phi(1.2)) = 0.23$：没有不利于$H_0$的证据。
:::
:::

::: exercise 检验的真实水平 {level=1 check="11/1024"}
如果抛掷$10$次中至少有$9$次正面，就判定硬币偏向正面。求犯第一类错误的概率。
::: solution
在$H_0$：$p = \tfrac12$下，$\Prob(X\ge9) = \bigl(\binom{10}{9}+\binom{10}{10}\bigr)2^{-10} = 11/1024\approx0.011$。
:::
:::

::: exercise 自由度 {level=1 check="6"}
对$3\times4$列联表进行卡方独立性检验，自由度是多少？
::: solution
$(3-1)(4-1) = 6$。
:::
:::

::: exercise t 统计量 {level=2 check="2.3"}
一个含$16$个观测值的样本有$\bar x = 52.3$，$s = 4$。对$H_0$：$\mu = 50$计算 t 统计量，并判断在$5\%$的水平下，对双侧备择假设是否拒绝$H_0$（$t_{15,0.025} = 2.131$）。
::: solution
$t = (52.3 - 50)/(4/4) = 2.3>2.131$，所以在$5\%$的水平下拒绝$H_0$（p 值约为$0.036$）。
:::
:::

::: exercise z 检验的功效 {level=2}
$H_0$：$\mu = 100$对$H_1$：$\mu>100$的单侧 z 检验使用$n = 25$个观测值，$\sigma = 10$，$\alpha = 0.05$。求$\mu = 104$时该检验的功效。
::: solution
由[[#eq-power]]，其中$\delta\sqrt n/\sigma = 4\times5/10 = 2$，功效为$1-\Phi(1.645 - 2) = \Phi(0.355)\approx0.64$。有$36\%$的机会漏掉大小为$4$的真实增量。
:::
:::

::: exercise 高功效所需的样本量 {level=2 check="169"}
$\alpha = 0.05$的双侧 z 检验要以$0.9$的功效检测出四分之一个标准差的效应，需要多少个观测值？（取$z_{0.025} = 1.96$，$z_{0.1} = 1.2816$，并忽略小到可以不计的另一侧尾部。）
::: solution
$n = \bigl((1.96 + 1.2816)/0.25\bigr)^2 = 12.966^2 = 168.1$，所以$n = 169$。
:::
:::

::: exercise 多次检验 {level=2 check="1-0.95^10"}
对十个相互独立且为真的原假设分别在$5\%$的水平下进行检验。求至少出现一次错误拒绝的概率，以及为使这一概率低于$5\%$，邦费罗尼方法对每个检验所用的水平。
::: solution
$1 - 0.95^{10}\approx0.401$。邦费罗尼方法会把每个检验的水平取为$0.05/10 = 0.005$。
:::
:::

::: exercise 阿巴斯诺特的论证 {level=3 check="0.5^82"}
计算阿巴斯诺特所用的概率：假如每一年都独立地以概率$\tfrac12$偏向任何一方，那么在$82$年中的每一年里受洗的男孩都多于女孩的概率是多少？它是一个 p 值吗？它能确立什么，又不能确立什么？
::: solution
$(1/2)^{82}\approx2.1\times10^{-25}$。它是对$H_0$：“每一年男孩多或女孩多的可能性相同”所作的**符号检验**的单侧 p 值，因为$82$年中$82$年都如此，是可能出现的最极端的结果。它以压倒性的证据确立了出生的婴儿为男孩的概率超过$\tfrac12$（我们现在知道，约为$0.51$到$0.52$）。它对**原因**只字未提：拒绝原假设支持的是“并非偶然”，而不是任何特定的解释，例如阿巴斯诺特诉诸神意的解释。
:::
:::

::: exercise 指数寿命的奈曼-皮尔逊检验 {level=3}
寿命$X_1,\ldots,X_n$独立同分布于$\operatorname{Exp}(\lambda)$。证明$H_0$：$\lambda = 1$对$H_1$：$\lambda = 2$的最大功效检验在$\sum_iX_i$较小时拒绝原假设，并用卡方分位数表示$\alpha = 0.05$时的临界值。
::: hint
利用[[statistics/confidence-intervals]]一章习题中的枢轴量$2\lambda\sum X_i\sim\chi^2_{2n}$。
:::
::: solution
似然比为$\dfrac{f_1(x)}{f_0(x)} = \dfrac{2^ne^{-2\sum x_i}}{e^{-\sum x_i}} = 2^ne^{-\sum x_i}$，它是$s = \sum x_i$的减函数。由[[#thm-neyman-pearson]]，最大功效检验在$s<c$时拒绝原假设。在$H_0$（$\lambda = 1$）下，$2\sum X_i\sim\chi^2_{2n}$，所以当$2c = \chi^2_{2n,0.95}$（即下$5\%$分位点）时，$\Prob_0(\sum X_i<c) = 0.05$。因此当$\sum X_i<\tfrac12\chi^2_{2n,0.95}$时拒绝原假设。正如直觉所提示的，寿命短是失效率较高的证据；引理表明，没有任何检验能胜过这个检验。
:::
:::

::: exercise 离散型 p 值是保守的 {level=3}
设$T$是一个取整数值的检验统计量（例如一个计数），其大值是不利于$H_0$的证据，并令$G(t) = \Prob_{H_0}(T\ge t)$，从而 p 值为$P = G(T)$。证明：对每个$\alpha\in(0,1)$，都有$\Prob_{H_0}(P\le\alpha)\le\alpha$。
::: solution
$G$是非增的，且当$t\to\infty$时$G(t)\to0$，所以存在使$G(t_0)\le\alpha$的最小整数$t_0$。由于$G$非增，对整数$t$，$G(t)\le\alpha$当且仅当$t\ge t_0$（若$t<t_0$，则由$t_0$的最小性，$G(t)>\alpha$）。因此$\{P\le\alpha\} = \{G(T)\le\alpha\} = \{T\ge t_0\}$，并且

$$
\Prob_{H_0}(P\le\alpha) = \Prob_{H_0}(T\ge t_0) = G(t_0)\le\alpha .
$$

等号通常不成立，所以基于离散型 p 值的检验是保守的。对于[[#ex-coin-test]]中的硬币检验，在双侧 p 值至多为$0.05$时拒绝，就意味着在$X\le39$或$X\ge61$时拒绝，这个检验的真实水平为$0.035$。
:::
:::
