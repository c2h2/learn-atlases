一项对$1000$名选民的民意调查发现，有$52\%$的人支持某项提案，报告还补充说“误差幅度为$3$个百分点”。单个数字$52\%$是一个点估计，仅就它本身而言，它几乎肯定是错的：总体中真实的支持率并不恰好是$52.0\%$。误差幅度所补充的，是对它可能错多少的如实说明。从$49\%$到$55\%$的区间是一个**置信区间**，在使用产生它的这种方法的所有民意调查中，大约有$95\%$会捕获到真值。

本章介绍如何构造置信区间，以及同样重要的——置信区间的含义。关键工具是**枢轴量**：数据和参数的一个函数，其分布完全已知。[[statistics/sampling]]一章中的抽样分布为正态均值（方差已知或未知）和正态方差提供了枢轴量；中心极限定理则为比例以及其他大样本问题提供了近似枢轴量。我们还将看到如何选择样本量，如何比较两组，以及为什么最常用的比例区间可能错得很厉害。

## 什么是置信区间 {#definition}

设$X = (X_1,\ldots,X_n)$是来自某个含未知参数$\theta$的分布的样本。

::: definition 置信区间 {#def-ci}
设$L(X)\le U(X)$是两个统计量，$0<\alpha<1$。如果

$$
\Prob_\theta\bigl(L(X)\le\theta\le U(X)\bigr)\ge1-\alpha\qquad\text{对每个 }\theta\in\Theta .
$$ {#eq-coverage}

则称随机区间$[L(X), U(X)]$为**$\theta$的置信水平为$1-\alpha$的置信区间**。左边的概率称为**覆盖概率**。观测到数据$x$之后，数值区间$[L(x), U(x)]$也称为置信区间。
:::

在[[#eq-coverage]]中，参数$\theta$是固定的，而**区间**是随机的：随样本而变化的是区间的端点。一个$95\%$置信程序是这样一种方法：在新样本上反复使用时，它所产生的区间在（至少）$95\%$的情形下包含真实的$\theta$。常用的选择是$1-\alpha = 0.90$、$0.95$和$0.99$。

::: widget confidence

method: t
caption: 总体均值的五十个$95\%$ t 区间，每个都来自一个新的、容量为$15$的模拟样本；竖线是真实均值。大约$95\%$的区间覆盖了它，未覆盖的区间（高亮显示）可能落在任一侧；点击“重新抽样”可以看到更多例子。这些区间的中心不同，宽度**也**不同，因为$\bar x$和$s$都在变化。把置信水平降到$0.8$，区间会变短，而未覆盖的情况会变得更频繁。
:::

::: warning 95% 置信度不意味着什么
一旦数据到手、区间算出——比如说$[96.1, 105.4]$——人们很容易说“$\mu$落在$96.1$与$105.4$之间的概率为$95\%$”。在本章的框架下，这句话没有意义：$\mu$是一个固定的数，它要么落在这个区间里，要么不在。$95\%$描述的是这种**方法**的长期成功率，而不是这个特定的区间。（形如“$\Prob(\mu\in[a,b]\mid\text{数据}) = 0.95$”的陈述在贝叶斯推断中确实有意义，在那里这样的区间称为可信区间；见[[statistics/bayesian]]。）均值的$95\%$置信区间也并不包含$95\%$的**数据**：它是关于$\mu$的区间，会随着$n$增大而缩短，而单个数值的散布程度则不会缩小。
:::

## 枢轴量与 z 区间 {#pivots}

构造区间的标准方法是找到这样一个量：它含有$\theta$，但它的分布不含$\theta$。

::: definition 枢轴量 {#def-pivot}
**枢轴量**（简称**枢轴**）是数据和参数的一个函数$Q(X,\theta)$，它的分布对$\theta$（以及其他任何未知参数）的每个取值都相同。
:::

给定一个枢轴量，选取数$a<b$，使$\Prob(a\le Q(X,\theta)\le b) = 1-\alpha$；那么使$a\le Q(X,\theta)\le b$成立的$\theta$的集合——通常是一个区间，通过对$\theta$解这些不等式求得——的覆盖概率恰好为$1-\alpha$。我们用$z_p$表示标准正态分布的上$p$分位点，即$\Prob(Z>z_p) = p$，于是$z_{0.05} = 1.645$，$z_{0.025} = 1.960$，$z_{0.005} = 2.576$。

::: theorem 方差已知时正态均值的 z 区间 {#thm-z-interval}
若$X_1,\ldots,X_n\iid\Normal(\mu,\sigma^2)$，其中$\sigma$已知，则

$$
\Bigl[\bar X - z_{\alpha/2}\frac{\sigma}{\sqrt n},\ \bar X + z_{\alpha/2}\frac{\sigma}{\sqrt n}\Bigr]
$$ {#eq-z-interval}

是$\mu$的置信水平恰为$1-\alpha$的置信区间。
:::

::: proof
$Q = \dfrac{\bar X-\mu}{\sigma/\sqrt n}$是一个枢轴量：无论$\mu$取何值，它都服从$\Normal(0,1)$分布（[[statistics/sampling]]）。因此

$$
1-\alpha = \Prob\bigl(-z_{\alpha/2}\le Q\le z_{\alpha/2}\bigr) = \Prob\Bigl(\bar X - z_{\alpha/2}\frac{\sigma}{\sqrt n}\le\mu\le\bar X + z_{\alpha/2}\frac{\sigma}{\sqrt n}\Bigr),
$$

这是因为两组不等式描述的是同一事件，只是经过整理把$\mu$单独分离了出来。
:::

由中心极限定理，当$n$很大时，对于非正态总体，同一区间的覆盖概率也**近似**正确。量$z_{\alpha/2}\sigma/\sqrt n$称为**误差幅度**，区间具有如下形式

$$
\text{估计值}\ \pm\ (\text{临界值})\times(\text{标准误}),
$$

这一模式在整个统计学中反复出现。

::: example 螺栓长度 {#ex-bolts-ci}
对于[[statistics/sampling#ex-bolts]]中的螺栓（$\sigma = 0.2$ mm，$n = 25$，$\bar x = 50.08$ mm），求平均长度的$95\%$置信区间，以及使误差幅度为$0.05$ mm所需的样本量。
::: solution
标准误为$0.2/\sqrt{25} = 0.04$，所以区间为$50.08\pm1.96\times0.04 = 50.08\pm0.078$，即$[50.002, 50.158]$ mm。目标值$50$恰好落在区间之外。要使误差幅度为$E$，需要$1.96\,\sigma/\sqrt n\le E$，即

$$
n\ge\Bigl(\frac{1.96\,\sigma}{E}\Bigr)^2 = \Bigl(\frac{1.96\times0.2}{0.05}\Bigr)^2 = 61.5,
$$

所以需要$62$个螺栓。由于误差幅度与$1/\sqrt n$成正比，要使它减半，就需要四倍的观测值。
:::
:::

::: quiz
基于$100$个观测值的均值的$95\%$置信区间宽度为$4$。基于来自同一总体的$400$个观测值的$95\%$置信区间，宽度大约是多少？
- [ ] $1$
- [x] $2$
- [ ] $4$
- [ ] $8$
::: solution
宽度与$\sigma/\sqrt n$成正比。把$n$乘以$4$，$1/\sqrt n$就乘以$\tfrac12$，所以宽度变为约$2$。精度的代价很高：每多一位小数的精度，样本量就要增加到一百倍。
:::
:::

## 均值的 t 区间 {#t-interval}

实际上$\sigma$是未知的。用样本标准差$S$代替它，就得到学生化均值；对正态数据，它的精确分布是学生氏$t$分布（[[statistics/sampling#cor-t-statistic]]）。记$t_{k,p}$为$t_k$的上$p$分位点。

::: theorem 正态均值的 t 区间 {#thm-t-interval}
若$X_1,\ldots,X_n\iid\Normal(\mu,\sigma^2)$，其中两个参数都未知，则

$$
\Bigl[\bar X - t_{n-1,\alpha/2}\frac{S}{\sqrt n},\ \bar X + t_{n-1,\alpha/2}\frac{S}{\sqrt n}\Bigr]
$$ {#eq-t-interval}

是$\mu$的置信水平恰为$1-\alpha$的置信区间。
:::

::: proof
对每个$\mu$和$\sigma$，$T = \dfrac{\bar X - \mu}{S/\sqrt n}$都服从$t_{n-1}$分布，所以它是一个枢轴量。与[[#thm-z-interval]]一样，$\Prob(-t_{n-1,\alpha/2}\le T\le t_{n-1,\alpha/2}) = 1-\alpha$，整理不等式把$\mu$单独分离出来，即得该区间。
:::

::: example 咖啡因含量 {#ex-caffeine}
同一家咖啡馆的八杯咖啡的咖啡因含量（mg）为$98, 105, 92, 110, 101, 97, 104, 99$。假设服从正态模型，求平均咖啡因含量的$95\%$置信区间。
::: solution
这里$n = 8$，$\bar x = 806/8 = 100.75$，$s = 5.55$，所以估计的标准误为$s/\sqrt8 = 1.962$。利用$t_{7,0.025} = 2.365$，

$$
100.75\pm2.365\times1.962 = 100.75\pm4.64,\qquad\text{即 }[96.1,\ 105.4]\text{ mg}.
$$

若用$1.96$代替$2.365$，会得到较窄的区间$[96.9, 104.6]$，但它的真实覆盖概率只有约$91\%$：在小样本下，忽略$s$的不确定性会使我们过于自信。
:::
:::

t 区间相当**稳健**：当$n$适中时，即使数据不服从正态分布，只要它们不是严重偏斜或受到离群值污染，它的覆盖概率仍接近名义水平，因为中心极限定理使$\bar X$近似服从正态分布。当$n$很大时，$t$临界值与$z$临界值几乎相等。

::: remark 新观测值的区间
区间[[#eq-t-interval]]是关于**均值**$\mu$的。要预测来自同一正态总体的一个新观测值$X_{n+1}$，注意$X_{n+1} - \bar X$的方差为$\sigma^2(1 + \frac1n)$，且与$S$相互独立，由此得到**预测区间**$\bar X\pm t_{n-1,\alpha/2}\,S\sqrt{1 + 1/n}$。对于咖啡数据，它是$100.75\pm2.365\times5.55\times1.061 = [86.8, 114.7]$ mg，比均值的区间宽得多，而且当$n\to\infty$时，它的宽度不会缩小到零。
:::

## 比例的区间 {#proportions}

对于用$\hat p = X/n$（其中$X\sim\Bin(n,p)$）来估计的比例$p$，不存在精确的枢轴量，但中心极限定理提供了一个近似的枢轴量：当$n$很大时，$\dfrac{\hat p - p}{\sqrt{p(1-p)/n}}$近似服从$\Normal(0,1)$。把标准误中的未知$p$换成$\hat p$，就得到广泛使用的**沃尔德（Wald）区间**

$$
\hat p\pm z_{\alpha/2}\sqrt{\frac{\hat p(1-\hat p)}{n}}.
$$ {#eq-wald}

当$n\to\infty$时，它的覆盖概率趋于$1-\alpha$。论证这一点还需要一个极限定理，即**斯卢茨基（Slutsky）定理**：若$Y_n\xrightarrow{d}\Normal(0,1)$且$V_n\xrightarrow{\Prob}1$，则$Y_n/V_n\xrightarrow{d}\Normal(0,1)$。取$V_n = \sqrt{\hat p(1-\hat p)/\bigl(p(1-p)\bigr)}$应用这一定理即可；由大数定律，它依概率趋于$1$。同样的论证表明，对任何渐近正态的估计量（例如[[statistics/estimation#thm-mle-asymptotic]]中的最大似然估计量），$\hat\theta\pm z_{\alpha/2}\operatorname{se}(\hat\theta)$都是一个近似的置信区间。

::: example 速率的近似区间与精确区间 {#ex-rate-ci}
对于[[statistics/estimation#ex-mle-exponential]]中的八个指数等待时间（$\sum x_i = 16$分钟，$\hat\lambda = 0.5$次/分钟），把大样本区间$\hat\lambda\pm1.96\operatorname{se}(\hat\lambda)$与基于枢轴量$2\lambda\sum X_i\sim\chi^2_{2n}$（在习题中推导）的精确区间进行比较。
::: solution
基于费希尔信息的标准误为$\hat\lambda/\sqrt n = 0.5/\sqrt8 = 0.177$，所以大样本区间为$0.5\pm0.35 = [0.15, 0.85]$。对于精确区间，$2\lambda\times16\sim\chi^2_{16}$，它的$2.5\%$分位点和$97.5\%$分位点分别为$6.91$和$28.85$；解$6.91\le32\lambda\le28.85$得$[0.216, 0.901]$。精确区间向右偏移，并且关于$\hat\lambda$不对称，这反映了样本量为八时$\hat\lambda$的抽样分布的偏斜性。在小样本下，应谨慎对待近似区间；若有数百个观测值，两者会非常接近。
:::
:::

::: example 民意调查 {#ex-poll-ci}
在$1000$名选民的随机样本中，有$520$人支持某项提案。求总体比例的近似$95\%$置信区间。
::: solution
$\hat p = 0.52$，$\sqrt{0.52\times0.48/1000} = 0.0158$，所以区间为$0.52\pm1.96\times0.0158 = 0.52\pm0.031$，即$[0.489, 0.551]$。这就是本章开头所说的“误差幅度为$3$个百分点”。由于区间包含$0.5$，这次民意调查并不能确定多数人支持该提案。
:::
:::

对于小样本或接近$0$或$1$的比例，沃尔德区间表现很差。$20$次试验中有$2$次成功时，它给出$[-0.031, 0.231]$，其中包含不可能出现的负值；$0$次成功时，它退化为单点$[0, 0]$。它的实际覆盖概率可能远低于$95\%$（见习题）。埃德温·威尔逊（Edwin Wilson，1927年）提出了一个更好的区间：它对近似枢轴量求逆，但**不**把标准误中的$p$换成$\hat p$，即取满足$\lvert\hat p - p\rvert\le z_{\alpha/2}\sqrt{p(1-p)/n}$的$p$的集合，这是关于$p$的一个二次不等式。对于$20$次中成功$2$次，它给出$[0.028, 0.301]$；对于$20$次中成功$0$次，它给出$[0, 0.161]$；对于$1000$人中$520$人支持，它与沃尔德区间在小数点后三位上一致。

::: widget confidence

::: application 三法则
如果一种新疗法在$n$名患者身上没有产生严重的副作用，关于副作用的发生率$p$，我们能说些什么？精确的$95\%$置信上限是使“观察到零次事件”的概率为$0.05$的$p$值：$(1-p)^n = 0.05$，所以$p = 1 - 0.05^{1/n}$。由于$\ln 0.05\approx-3$，它近似等于$3/n$。若$300$名患者中没有发生任何事件，我们可以有$95\%$的把握说发生率低于约$1\%$——而不是说它为零。
:::

::: remark 单侧置信限
有时只有一个方向是重要的：监管机构想知道咖啡因含量**至少**有多少，或者故障率**至多**有多少。把全部尾部概率$\alpha$放在一侧，就得到**单侧置信限**；对于正态均值，$\bar X - t_{n-1,\alpha}S/\sqrt n$是置信水平为$1-\alpha$的置信下限，因为$\Prob(T\le t_{n-1,\alpha}) = 1-\alpha$。对于咖啡数据，利用$t_{7,0.05} = 1.895$，我们可以有$95\%$的把握说平均咖啡因含量至少为$100.75 - 1.895\times1.962 = 97.0$ mg。上面的三法则给出的是单侧置信上限。
:::

## 方差的区间 {#variance}

对于正态总体，[[statistics/sampling#thm-normal-sample]]提供了枢轴量$(n-1)S^2/\sigma^2\sim\chi^2_{n-1}$。记$\chi^2_{k,p}$为$\chi^2_k$的上$p$分位点。

::: theorem 正态方差的卡方区间 {#thm-variance-interval}
若$X_1,\ldots,X_n\iid\Normal(\mu,\sigma^2)$，则

$$
\Bigl[\frac{(n-1)S^2}{\chi^2_{n-1,\alpha/2}},\ \frac{(n-1)S^2}{\chi^2_{n-1,1-\alpha/2}}\Bigr]
$$

是$\sigma^2$的置信水平为$1-\alpha$的置信区间。对端点取平方根，就得到$\sigma$的区间。
:::

::: proof
$\Prob\bigl(\chi^2_{n-1,1-\alpha/2}\le(n-1)S^2/\sigma^2\le\chi^2_{n-1,\alpha/2}\bigr) = 1-\alpha$。不等式$(n-1)S^2/\sigma^2\le\chi^2_{n-1,\alpha/2}$等价于$\sigma^2\ge(n-1)S^2/\chi^2_{n-1,\alpha/2}$，另一个不等式也类似，由此即得该区间。由于所有的量都是正的，取平方根不改变这一事件。
:::

::: example 灌装机的波动性 {#ex-variance-ci}
从一台灌装机灌装的瓶子中抽取$10$瓶作为样本，其样本方差为$s^2 = 4$ ml$^2$。求灌装量标准差的$95\%$置信区间。
::: solution
自由度为$9$时，$\chi^2_{9,0.975} = 2.700$，$\chi^2_{9,0.025} = 19.023$。$\sigma^2$的区间为

$$
\Bigl[\frac{9\times4}{19.023},\ \frac{9\times4}{2.700}\Bigr] = [1.89,\ 13.33],
$$

所以$\sigma$的区间为$[1.38, 3.65]$ ml。由于卡方分布是偏斜的，这个区间关于$s = 2$不对称；而且它很宽：十个观测值只能把标准差确定到约$2.7$倍的范围之内。
:::
:::

::: widget distribution
dist: chisq
params: k=9
a: 2.70
b: 19.02
caption: $\chi^2_9$分布，中间的$95\%$（介于$2.70$与$19.02$之间）已涂上阴影。这两个数就是方差区间中的两个临界值。由于该分布右偏，$\sigma^2$的区间在$s^2$上方延伸得比下方远得多。
:::

与 t 区间不同，这个区间**不稳健**：如果总体的尾部比正态分布更重或更轻，即使是大样本，它的覆盖概率也可能与$95\%$相差甚远，因为$S^2$的方差依赖于总体的四阶矩。

## 比较两个均值 {#two-sample}

问题常常不是关于单个均值，而是关于差异：一种新的教学方法能否提高成绩？一种肥料是否比另一种更好？设$X_1,\ldots,X_m\iid\Normal(\mu_1,\sigma^2)$，并且与之独立地，$Y_1,\ldots,Y_n\iid\Normal(\mu_2,\sigma^2)$，两者有**共同的**未知方差。**合并方差**

$$
S_p^2 = \frac{(m-1)S_X^2 + (n-1)S_Y^2}{m+n-2}
$$

把两个样本方差结合了起来，并且$(m+n-2)S_p^2/\sigma^2\sim\chi^2_{m+n-2}$，因为它是相互独立的$\chi^2_{m-1}$变量与$\chi^2_{n-1}$变量之和。由于$\bar X - \bar Y\sim\Normal\bigl(\mu_1-\mu_2,\sigma^2(\frac1m+\frac1n)\bigr)$与$S_p^2$相互独立，

$$
\frac{(\bar X - \bar Y) - (\mu_1-\mu_2)}{S_p\sqrt{\frac1m+\frac1n}}\sim t_{m+n-2},
$$

从而$\mu_1 - \mu_2$的置信区间为$\bar X - \bar Y\pm t_{m+n-2,\alpha/2}\,S_p\sqrt{\frac1m+\frac1n}$。

::: example 两种教学方法 {#ex-two-sample}
用方法 A 教学的十二名学生的平均成绩为$24.3$，$s = 3.1$；用方法 B 教学的十名学生的平均成绩为$21.8$，$s = 2.8$。假设成绩服从正态分布且方差相等，求总体均值之差的$95\%$置信区间。
::: solution
$s_p^2 = \dfrac{11\times3.1^2 + 9\times2.8^2}{20} = 8.81$，所以$s_p = 2.97$，差的标准误为$2.97\sqrt{\frac1{12}+\frac1{10}} = 1.27$。利用$t_{20,0.025} = 2.086$，区间为

$$
2.5\pm2.086\times1.27 = 2.5\pm2.65,\qquad\text{即 }[-0.15,\ 5.15].
$$

该区间包含$0$，所以数据与两种方法之间没有差异相容，尽管它们也与方法 A 高出五分的差异相容。要作出判断，需要更大规模的研究。
:::
:::

如果不能假定方差相等，**韦尔奇（Welch）区间**用$\sqrt{S_X^2/m + S_Y^2/n}$作为标准误，并使用近似的自由度；对上面的数据，它给出几乎相同的结果$[-0.13, 5.13]$。当观测值天然成对出现时——同一名患者治疗前后、双胞胎、左眼与右眼——它们就不是独立样本，正确的方法是计算每对之内的差值，再对这些差值应用单样本 t 区间。配对消除了个体之间的差异，往往能给出短得多的区间。

::: quiz
均值差的一个$95\%$置信区间为$[1.2, 4.8]$。下列哪种说法是正确的？
- [ ] 真实差值介于$1.2$与$4.8$之间的概率为$95\%$。
- [ ] $95\%$的个体差值介于$1.2$与$4.8$之间。
- [x] 产生这个区间的方法在$95\%$的样本中能捕获真实差值，并且该区间不包含$0$。
- [ ] 如果重复这项研究，新的估计值有$95\%$的可能性介于$1.2$与$4.8$之间。
::: solution
置信水平是程序的性质。第一种说法是常见的误解（它是一个贝叶斯式的陈述，需要先验分布）。第二种说法把均值的区间与单个数值的散布混为一谈。第四种说法也是错的：由于两个估计值都在变化，重复研究得到的估计值平均只有约$83\%$的时候落在原来的区间内。这里有用的结论是区间不包含$0$——它与检验的联系将在[[statistics/hypothesis-testing]]中建立。
:::
:::

::: history
19世纪初，皮埃尔-西蒙·拉普拉斯（Pierre-Simon Laplace）计算了比例的近似区间，实际上用的就是[[#eq-wald]]中的正态近似；天文学家和测量员也经常给出“概差”。现代的频率学派概念是由耶日·奈曼（Jerzy Neyman）创立的：他在1934年一篇关于抽样方法的论文中提出这一概念，并创造了“置信区间”这一术语，随后在《基于经典概率论的统计估计理论概要》（*Outline of a Theory of Statistical Estimation Based on the Classical Theory of Probability*，1937年）中系统阐述了这一理论，并坚持用长期覆盖率来解释它。埃德温·比德韦尔·威尔逊（Edwin Bidwell Wilson）在1927年提出了他的比例区间；查尔斯·克洛珀（Charles Clopper）和埃贡·皮尔逊（Egon Pearson）在1934年给出了基于二项分布的精确（保守）区间。罗纳德·费希尔（Ronald Fisher）与之对立的“信仰”区间理论试图在没有先验的情况下给参数赋予概率，这导致他与奈曼之间展开了一场旷日持久的激烈争论。
:::

## 后续内容 {#where-next}

置信区间与假设检验是一枚硬币的两面：正如[[statistics/hypothesis-testing]]中所示，值$\theta_0$落在$95\%$置信区间之外，当且仅当相应的检验在$5\%$水平下拒绝$\theta = \theta_0$。回归系数和预测的区间出现在[[statistics/regression]]一章中。贝叶斯可信区间（[[statistics/bayesian]]）回答的，正是置信区间常被误认为在回答的那个问题。当没有可用的枢轴量而样本量又不太大时，**自助法**通过对数据重抽样来近似抽样分布。

::: summary
- $1-\alpha$置信区间是一个随机区间，它以至少$1-\alpha$的概率覆盖固定的真实参数；置信水平描述的是方法，而不是某一个算出来的区间。
- 对枢轴量（分布已知的、数据与参数的函数）求逆即得区间：估计值$\pm$临界值$\times$标准误。
- 正态均值：$\sigma$已知时用$\bar x\pm z_{\alpha/2}\sigma/\sqrt n$，$\sigma$未知时用$\bar x\pm t_{n-1,\alpha/2}s/\sqrt n$；t 区间对非正态性相当稳健。
- 区间宽度与$1/\sqrt n$成正比：要使宽度减半，样本量需增至四倍；$n\ge(z\sigma/E)^2$可使误差幅度达到$E$。
- 比例：沃尔德区间$\hat p\pm z\sqrt{\hat p(1-\hat p)/n}$对大样本适用，但当$n$较小或$p$接近极端值时不可靠；威尔逊区间更好。$n$次试验中零次事件给出约为$3/n$的上限。
- 正态方差：对$(n-1)S^2/\sigma^2\sim\chi^2_{n-1}$求逆；所得区间不对称，也不稳健。
- 两个独立样本：对$\mu_1-\mu_2$使用合并方差 t 区间或韦尔奇 t 区间；对配对数据，则分析其差值。
:::

## 习题

::: exercise z 区间 {level=1 check="1.96"}
来自$\sigma = 6$的正态总体的$36$个观测值组成的样本，其均值为$72.4$。求$\mu$的$95\%$置信区间；请输入它的半宽（即误差幅度）。
::: solution
标准误为$6/\sqrt{36} = 1$，所以误差幅度为$1.96\times1 = 1.96$，区间为$[70.44, 74.36]$。
:::
:::

::: exercise 样本量 {level=1 check="97"}
若$\sigma = 10$，要以$95\%$的置信度把均值估计到$\pm2$以内，需要多大的样本？
::: solution
$n\ge(1.96\times10/2)^2 = 96.04$，所以$n = 97$（总是向上取整）。
:::
:::

::: exercise 缩短区间 {level=1 check="1/2"}
（其他条件不变时）样本量从$100$增加到$400$，均值的置信区间的宽度会乘以什么因子？
::: solution
宽度与$1/\sqrt n$成正比，所以它乘以$\sqrt{100/400} = \tfrac12$。
:::
:::

::: exercise 由概括量求 t 区间 {level=2}
来自正态总体的$16$个测量值组成的样本有$\bar x = 15.2$，$s = 2.4$。求$\mu$的$95\%$置信区间（$t_{15,0.025} = 2.131$）。
::: solution
标准误为$2.4/4 = 0.6$，所以区间为$15.2\pm2.131\times0.6 = 15.2\pm1.28$，即$[13.92, 16.48]$。
:::
:::

::: exercise 比例的区间 {level=2}
在$400$名成年人的样本中，有$180$人说自己经常锻炼。求总体比例的近似$95\%$置信区间。它是否支持“经常锻炼的成年人不到一半”这一说法？
::: solution
$\hat p = 0.45$，$\sqrt{0.45\times0.55/400} = 0.0249$，所以区间为$0.45\pm0.049$，即$[0.401, 0.499]$。它完全位于$0.5$以下，所以在这一置信水平下，数据支持这一说法（但只是勉强支持）。
:::
:::

::: exercise 没有副作用 {level=2 check="1-0.05^(1/300)"}
给$300$名患者服用一种药物，没有出现严重的副作用。求副作用发生率$p$的精确$95\%$置信上限，即使$\Prob(\text{无事件发生}) = 0.05$的$p$值。
::: solution
由$(1-p)^{300} = 0.05$得$p = 1 - 0.05^{1/300}\approx0.00994$，接近三法则给出的值$3/300 = 0.01$。
:::
:::

::: exercise 标准差的区间 {level=2}
一个容量为$15$的正态样本有$s^2 = 9$。利用$\chi^2_{14,0.975} = 5.629$和$\chi^2_{14,0.025} = 26.119$，求$\sigma$的$95\%$置信区间。
::: solution
对于$\sigma^2$：$\bigl[\frac{14\times9}{26.119},\frac{14\times9}{5.629}\bigr] = [4.82, 22.38]$。取平方根得$\sigma\in[2.20, 4.73]$。
:::
:::

::: exercise 指数分布均值的精确区间 {level=3}
设$X_1,\ldots,X_n\iid\operatorname{Exp}(\lambda)$。证明$2\lambda\sum_iX_i\sim\chi^2_{2n}$，并利用它构造平均寿命$1/\lambda$的置信水平为$1-\alpha$的精确置信区间。
::: hint
先证明$2\lambda X_1\sim\operatorname{Exp}(\tfrac12)$，它就是$\chi^2_2$。
:::
::: solution
若$X\sim\operatorname{Exp}(\lambda)$，则$\Prob(2\lambda X>t) = \Prob(X>t/(2\lambda)) = e^{-t/2}$，所以$2\lambda X\sim\operatorname{Exp}(\tfrac12)$，这就是$\chi^2_2$分布（它的密度$\tfrac12e^{-x/2}$是卡方密度在$k = 2$时的情形）。$n$个相互独立的$\chi^2_2$变量之和服从$\chi^2_{2n}$，所以对每个$\lambda$都有$Q = 2\lambda\sum X_i\sim\chi^2_{2n}$：这是一个枢轴量。于是

$$
1-\alpha = \Prob\bigl(\chi^2_{2n,1-\alpha/2}\le2\lambda\textstyle\sum X_i\le\chi^2_{2n,\alpha/2}\bigr) = \Prob\Bigl(\dfrac{2\sum X_i}{\chi^2_{2n,\alpha/2}}\le\dfrac1\lambda\le\dfrac{2\sum X_i}{\chi^2_{2n,1-\alpha/2}}\Bigr),
$$

所以$\Bigl[\dfrac{2\sum X_i}{\chi^2_{2n,\alpha/2}},\ \dfrac{2\sum X_i}{\chi^2_{2n,1-\alpha/2}}\Bigr]$是均值$1/\lambda$的置信水平为$1-\alpha$的精确区间。
:::
:::

::: exercise 联合置信区间 {level=3}
$I_1$和$I_2$分别是参数$\theta_1$和$\theta_2$的置信区间，置信水平都是$1-\alpha/2$，它们由同一组数据计算得到（因而可能不独立）。证明两个区间都覆盖各自参数的概率至少为$1-\alpha$。
::: solution
设$A_j$为$I_j$未能覆盖$\theta_j$这一事件，则$\Prob(A_j)\le\alpha/2$。由并集界（[[probability/probability-spaces#thm-union-bound]]），$\Prob(A_1\cup A_2)\le\alpha$，所以$\Prob(\text{两者都覆盖}) = 1 - \Prob(A_1\cup A_2)\ge1-\alpha$。更一般地，无论它们之间的相依关系如何，$k$个置信水平都为$1-\alpha/k$的区间同时覆盖的概率至少为$1-\alpha$（邦费罗尼（Bonferroni）方法）。
:::
:::

::: exercise 沃尔德区间何时失效 {level=3}
设$X\sim\Bin(20, 0.01)$。证明$95\%$沃尔德区间[[#eq-wald]]仅当$X\in\{1,2,3\}$时覆盖$p = 0.01$，并由此推出它的覆盖概率约为$0.18$。
::: solution
若$X = 0$，则$\hat p = 0$，区间为$[0,0]$，没有覆盖$0.01$。对于$X = k\ge1$，$\hat p = k/20$，区间的下端点为$\hat p - 1.96\sqrt{\hat p(1-\hat p)/20}$：当$k = 1, 2, 3$时，它分别为$-0.046$、$-0.031$、$-0.006$（都低于$0.01$），而上端点都超过$0.01$；当$k = 4$时，下端点为$0.2 - 1.96\sqrt{0.16/20} = 0.025>0.01$，并且此后随$k$增大而增大。所以覆盖概率为$\Prob(1\le X\le3)$，它等于$1 - 0.99^{20} - \Prob(X\ge4)\approx1 - 0.818 - 0.00004\approx0.182$。名义上为$95\%$的区间覆盖真值的时候还不到五分之一，这几乎完全是因为在没有观察到成功时区间退化了。
:::
