整数与多项式之间有着惊人的相似之处。二者都可以作带余除法；二者都有最大公因子，并且都可以用欧几里得算法求出；正如每个整数都能唯一地分解为素数之积，域上的每个多项式也都能唯一地分解为**不可约**多项式之积。这种相似还不止于此。把整数模素数$p$约化，得到域$\F_p$；把多项式模一个不可约多项式约化，同样得到一个域。复数就是这样从实系数多项式中产生的；我们也将用这种方法构造有$4$、$8$或$9$个元素的域——这些域**不**具有$\Z_n$的形式。

本章建立域$F$上多项式环$F[x]$的算术：带余除法及其推论、唯一因式分解，以及判断$\Q$上不可约性的实用方法——有理根检验、高斯（Gauss）引理、艾森斯坦（Eisenstein）判别法和模素数约化。本章最后介绍克罗内克（Kronecker）定理，它保证每个多项式在**某个**域中有根。这个定理是[[abstract-algebra/fields-galois]]中域论和伽罗瓦理论的出发点。

## 多项式环

设$R$是交换环。$R$上的**多项式**是形如

$$
f = a_0 + a_1x + a_2x^2 + \dots + a_nx^n \qquad (a_i \in R),
$$

的形式表达式，其中只有有限多个系数非零。多项式按系数相加；乘法则由规则$x^ix^j = x^{i+j}$按分配律推广而得：

$$
\Bigl(\sum_i a_ix^i\Bigr)\Bigl(\sum_j b_jx^j\Bigr) = \sum_k \Bigl(\sum_{i + j = k} a_ib_j\Bigr)x^k .
$$

在这些运算下，多项式构成一个交换环$R[x]$，它以常数多项式的形式包含$R$。若$a_n \neq 0$，则称$n$为$f$的**次数**，记作$\deg f$，称$a_n$为**首项系数**；若$a_n = 1$，则称$f$是**首一**的。零多项式没有次数（方便起见，可以规定$\deg 0 = -\infty$）。

::: warning 多项式不是函数
两个不同的多项式可以定义同一个函数。在$\F_p$上，费马小定理表明对每个$a \in \F_p$有$a^p = a$（[[abstract-algebra/lagrange#cor-fermat]]），所以多项式$x^p - x$不是零，但它所定义的函数$\F_p \to \F_p$恒等于零。在代数中，多项式就是它的系数序列；$x$是一个形式符号，而不是一个数。
:::

::: proposition 整环上多项式的次数 {#prop-degree}
若$D$是整环，$f, g \in D[x]$非零，则$\deg(fg) = \deg f + \deg g$。因此$D[x]$是整环，它的单位就是$D$的单位（作为常数多项式）。特别地，对域$F$，$F[x]$的单位就是非零常数。
:::

::: proof
若$f$的首项为$a_mx^m$，$g$的首项为$b_nx^n$，则$fg$中$x^{m+n}$的系数为$a_mb_n \neq 0$（没有零因子），并且没有更高次的项。所以$fg \neq 0$，$\deg fg = m + n$。若$fg = 1$，则$\deg f + \deg g = 0$，所以二者都是常数，并且是$D$中互逆的单位。
:::

没有整环这一假设，结论就不成立：在$\Z_4[x]$中，$(2x + 1)^2 = 4x^2 + 4x + 1 = 1$，所以一次多项式$2x + 1$是单位。从现在起，$F$表示一个域。

## 带余除法

::: theorem 带余除法 {#thm-poly-division}
设$F$是域，$f, g \in F[x]$，$g \neq 0$。则存在唯一的多项式$q, r \in F[x]$，使得

$$
f = qg + r \qquad\text{且}\qquad r = 0 \text{ 或 } \deg r < \deg g .
$$
:::

::: proof
**存在性。**对$\deg f$用强归纳法。若$f = 0$或$\deg f < \deg g$，取$q = 0$，$r = f$。否则，设$f$的首项为$a_mx^m$，$g$的首项为$b_nx^n$，其中$m \ge n$。由于$F$是域，$b_n^{-1}$存在，并且在

$$
f_1 = f - a_mb_n^{-1}x^{m-n}g
$$

中$x^m$项被消去，所以$f_1 = 0$或$\deg f_1 < m$。由归纳假设，$f_1 = q_1g + r$，其中$r = 0$或$\deg r < \deg g$，于是$f = (a_mb_n^{-1}x^{m-n} + q_1)g + r$。

**唯一性。**若$qg + r = q'g + r'$，其中两个余式的次数都小于$\deg g$（或为零），则$(q - q')g = r' - r$。若$q \neq q'$，则由[[#prop-degree]]，左边的次数至少为$\deg g$，而右边的次数小于$\deg g$——这不可能。所以$q = q'$，进而$r = r'$。
:::

这个证明就是普通的长除法。证明中只用到了$g$的首项系数的逆，所以当$g$是首一多项式时，同样的算法对任意交换环$R$上的$R[x]$都适用。

::: example 在ℚ上与在𝔽₅上作长除法 {#ex-long-division}
在$\Q[x]$中用$g = x^2 + x + 1$除$f = x^4 + 3x^3 - 2x + 5$，然后在$\F_5[x]$中做同样的除法。
::: solution
在$\Q$上：商的第一项是$x^2$，$f - x^2g = 2x^3 - x^2 - 2x + 5$。下一项是$2x$，$(2x^3 - x^2 - 2x + 5) - 2xg = -3x^2 - 4x + 5$。再下一项是$-3$，$(-3x^2 - 4x + 5) + 3g = -x + 8$，其次数为$1 < 2$。所以

$$
x^4 + 3x^3 - 2x + 5 = (x^2 + 2x - 3)(x^2 + x + 1) + (8 - x).
$$

在$\F_5$上，把每个系数都模$5$约化，同样的计算依然成立（由于$g$是首一的，计算中没有出现除以$5$的倍数的情形）：商为$x^2 + 2x + 2$，余式为$4x + 3$。
:::
:::

::: theorem 余数定理与因式定理 {#thm-factor}
设$f \in F[x]$，$c \in F$。用$x - c$除$f$所得的余式是常数$f(c)$。因此，$c$是$f$的根（即$f(c) = 0$）当且仅当$x - c$整除$f$。
:::

::: proof
作除法：$f = q\cdot(x - c) + r$，其中$r$是常数（次数小于$1$，或为零）。在$c$处求值——求值是环同态$F[x] \to F$——得$f(c) = q(c)\cdot 0 + r = r$。
:::

::: corollary 根的个数 {#cor-root-count}
域（或整环）上的$n$次非零多项式在该域（或整环）中至多有$n$个根。
:::

::: proof
对$n$用归纳法。次数为$0$时：非零常数没有根。若$\deg f = n \ge 1$且$c$是一个根，则$f = (x - c)q$，其中$\deg q = n - 1$。若$d \ne c$是另一个根，则$0 = f(d) = (d - c)q(d)$；由于$d - c \neq 0$且没有零因子，$q(d) = 0$。所以$f$的异于$c$的根都是$q$的根，而$q$至多有$n - 1$个根。（对整环$D$，在它的分式域中应用域的情形即可。）
:::

::: warning 零因子会带来额外的根
在有零因子的环上，这个计数不成立。在$\Z_8$中，多项式$x^2 - 1$有四个根$1, 3, 5, 7$，因为它们的平方模$8$都等于$1$；证明在“由$(d - c)q(d) = 0$推出$q(d) = 0$”这一步失效，例如$(3 - 1)(3 + 1) = 8 = 0$。没有交换性，这个计数也不成立：$x^2 + 1$在四元数中有无穷多个根，其中包括$\pm i, \pm j, \pm k$。
:::

根的个数的这一上界有重要的推论：它是证明$U(p)$为循环群（[[number-theory/primitive-roots]]）的关键一步，更一般地，也是证明任何有限域的乘法群都是循环群（[[abstract-algebra/fields-galois]]）的关键一步。

## F[x]是主理想整环

::: theorem F[x]的理想 {#thm-fx-pid}
$F[x]$的每个理想都是主理想。具体地说，对非零理想$I$，任取次数最小的非零元$g \in I$，$I$都等于$(g)$；并且这样的$g$中恰有一个是首一的。
:::

::: proof
若$I = \set{0}$，则$I = (0)$。否则，取次数最小的$g \in I$，$g \neq 0$。显然$(g) \subseteq I$。反过来，设$f \in I$，作除法：$f = qg + r$，其中$r = 0$或$\deg r < \deg g$。于是$r = f - qg \in I$，由$\deg g$的最小性，$r = 0$，从而$f \in (g)$。用$g$的首项系数的逆乘$g$，就得到一个首一的生成元；两个首一生成元互相整除，所以它们次数相同，只相差一个常数因子，而这个因子必定是$1$。
:::

所以$F[x]$与$\Z$一样，是主理想整环。与整数的情形完全一样，（不全为零的）多项式的**最大公因式**$\gcd(f, g)$定义为理想$(f, g) = \set{uf + vg}$的首一生成元$d$。它整除$f$和$g$，每个公因式都整除它，并且对某些$u, v \in F[x]$，**裴蜀等式**$d = uf + vg$成立。**欧几里得算法**可以求出它：把$(f, g)$换成$(g, r)$，其中$r$是$f$除以$g$的余式，如此反复，直到余式为$0$；最后一个非零余式化为首一后就是$\gcd(f, g)$。其理由与整数的情形相同（[[number-theory/divisibility]]）：$(f, g) = (g, f - qg)$。

::: example 用欧几里得算法求最大公因式 {#ex-poly-gcd}
在$\Q[x]$中求$f = x^3 - 2x^2 - x + 2$与$g = x^3 - x^2 - 4x + 4$的$\gcd(f, g)$，并把它写成裴蜀等式的形式。
::: solution
第一次除法：$f = 1\cdot g + (-x^2 + 3x - 2)$。第二次：用$-x^2 + 3x - 2$除$g$，或者等价地，用$x^2 - 3x + 2$除$g$：

$$
x^3 - x^2 - 4x + 4 = (x + 2)(x^2 - 3x + 2) + 0 .
$$

最后一个非零余式是$-x^2 + 3x - 2$；化为首一后得$\gcd(f, g) = x^2 - 3x + 2 = (x-1)(x-2)$。由第一步，$x^2 - 3x + 2 = -(f - g) = g - f$，这就是$u = -1$，$v = 1$时的裴蜀等式。（事实上$f = (x-1)(x+1)(x-2)$，$g = (x - 1)(x - 2)(x + 2)$。）
:::
:::

## 不可约多项式与唯一因式分解

::: definition 不可约多项式 {#def-irreducible}
如果非常数多项式$f \in F[x]$不能写成$f = gh$，其中$g, h \in F[x]$的次数都至少为$1$，则称$f$**在$F$上不可约**；否则称$f$是**可约**的。
:::

不可约性依赖于所在的域。每个次数为$1$的多项式都是不可约的。多项式$x^2 - 2$在$\Q$上不可约（因为$\sqrt 2 \notin \Q$），但在$\R$上等于$(x - \sqrt2)(x + \sqrt 2)$；$x^2 + 1$在$\R$上不可约，但在$\C$上等于$(x - i)(x + i)$。在有限域上，我们可以直接检验：$x^2 + 1$在$\F_2$上分解为$(x + 1)^2$，在$\F_5$上分解为$(x - 2)(x - 3)$，但在$\F_3$上不可约，因为$0^2 + 1, 1^2 + 1, 2^2 + 1$分别为$1, 2, 2$，都不为零。

::: proposition 二次与三次的情形 {#prop-deg23}
次数为$2$或$3$的多项式$f \in F[x]$在$F$上不可约，当且仅当它在$F$中没有根。
:::

::: proof
若$f = gh$，其中$\deg g, \deg h \ge 1$且$\deg g + \deg h \in \set{2, 3}$，则有一个因式的次数为$1$，比如说$g = a(x - c)$，于是$c$是一个根。反过来，由[[#thm-factor]]，一个根$c$给出因式$x - c$，与之相配的另一个因式的次数为$1$或$2$。
:::

::: warning 对四次多项式不成立
对次数为$4$或更高的多项式，没有根**并不**意味着不可约：一个四次多项式可以分解为两个二次多项式之积。在$\R$上，$(x^2 + 1)^2$没有实根；在$\Q$上，$x^4 + 4 = (x^2 + 2x + 2)(x^2 - 2x + 2)$没有有理根（[[#exr-8-7]]）。
:::

不可约多项式就是$F[x]$中的“素数”，它们具有素数的关键性质。

::: proposition 不可约多项式是素的 {#prop-irreducible-prime}
若$p \in F[x]$不可约且$p \mid fg$，则$p \mid f$或$p \mid g$。
:::

::: proof
令$d = \gcd(p, f)$。它整除$p$，所以（由于它是首一的）它要么是$1$，要么是$p$的常数倍。若$d$是$p$的倍数，则$p \mid f$。若$d = 1$，由裴蜀等式得$1 = up + vf$；两边乘以$g$，得$g = upg + v(fg)$，而$p$整除这两项，所以$p \mid g$。
:::

::: theorem F[x]中的唯一因式分解 {#thm-poly-ufd}
每个非常数多项式$f \in F[x]$都可以写成

$$
f = c\,p_1p_2\cdots p_k
$$

的形式，其中$c \in F^\times$，$p_1, \dots, p_k$是首一不可约多项式。除因式的次序外，这种分解是唯一的。
:::

::: proof
**存在性。**对$\deg f$用强归纳法。若$f$不可约，则$f = c\cdot(c^{-1}f)$，其中$c$是$f$的首项系数。否则$f = gh$，其中$1 \le \deg g, \deg h < \deg f$；由归纳假设，$g$和$h$都可以分解，把这两个分解乘起来即可。

**唯一性。**设$c\,p_1\cdots p_k = d\,q_1\cdots q_l$，其中所有$p_i, q_j$都是首一不可约多项式。比较首项系数得$c = d$。现在$p_1$整除$q_1\cdots q_l$，所以由[[#prop-irreducible-prime]]（并对因式的个数用归纳法），对某个$j$有$p_1 \mid q_j$。由于$q_j$不可约且二者都是首一的，$p_1 = q_j$。把它消去（我们是在整环中），然后重复这一过程；对$k$用归纳法可知，其余的因式在不计次序的意义下相同，并且$k = l$。
:::

哪些多项式不可约，在很大程度上取决于$F$：

- 在$\C$上，不可约多项式恰好是次数为$1$的多项式。这就是**代数基本定理**：每个非常数复系数多项式都有复根（[[complex-analysis/cauchy-theorem]]中给出了一个用复分析的证明）。
- 在$\R$上，不可约多项式是次数为$1$的多项式以及满足$b^2 < 4ac$的二次多项式$ax^2 + bx + c$。事实上，实系数多项式的非实根成共轭对$z, \bar z$出现，而$(x - z)(x - \bar z) = x^2 - 2\operatorname{Re}(z)x + \abs{z}^2$是实系数的。
- 在$\Q$上和在有限域上，任何次数的不可约多项式都存在（关于$\Q$，见下文的艾森斯坦判别法）。

::: example 同一个多项式在五个域上的分解 {#ex-x4-minus-1}
把$x^4 - 1$分别在$\Q$、$\R$、$\C$、$\F_3$和$\F_5$上分解为不可约多项式之积。
::: solution
总有$x^4 - 1 = (x^2 - 1)(x^2 + 1) = (x - 1)(x + 1)(x^2 + 1)$，所以问题在于$x^2 + 1$会怎样。在$\Q$和$\R$上它不可约（没有根），于是得到$(x-1)(x+1)(x^2+1)$。在$\C$上它可以分解：$(x - 1)(x + 1)(x - i)(x + i)$。在$\F_3$上它没有根（见上文），所以$x^4 - 1 = (x - 1)(x + 1)(x^2 + 1)$。在$\F_5$上，$2^2 = 4 = -1$，所以$x^2 + 1 = (x - 2)(x + 2)$，$x^4 - 1 = (x-1)(x-2)(x-3)(x-4)$。最后这个分解也可以由费马小定理得出：$\F_5$的四个非零元都满足$a^4 = 1$，所以它们是一个$4$次多项式的四个根。
:::
:::

## ℚ上的不可约性

判定$\Q$上的不可约性是一个真正的难题，通常要把几种工具结合起来使用。第一种工具找出所有可能的有理根。

::: theorem 有理根定理 {#thm-rational-roots}
设$f = a_nx^n + \dots + a_1x + a_0 \in \Z[x]$，$a_n \neq 0$。若$r/s$是$f$的根，其中$r, s \in \Z$，$s > 0$且$\gcd(r, s) = 1$，则$r \mid a_0$且$s \mid a_n$。
:::

::: proof
用$s^n$乘$f(r/s) = 0$的两边：

$$
a_nr^n + a_{n-1}r^{n-1}s + \dots + a_1rs^{n-1} + a_0s^n = 0 .
$$

除$a_0s^n$外，每一项都能被$r$整除，所以$r \mid a_0s^n$；由于$\gcd(r, s) = 1$，$r \mid a_0$（[[number-theory/divisibility#thm-coprime-divides]]）。同理，除$a_nr^n$外，每一项都能被$s$整除，所以$s \mid a_nr^n$，从而$s \mid a_n$。
:::

::: example 一个不可约的三次多项式 {#ex-cubic}
证明$f = x^3 - 3x - 1$在$\Q$上不可约。
::: solution
由有理根定理，有理根$r/s$满足$r \mid -1$且$s \mid 1$，所以它只能是$\pm 1$。但$f(1) = 1 - 3 - 1 = -3$，$f(-1) = -1 + 3 - 1 = 1$。所以$f$没有有理根；由于它的次数为$3$，由[[#prop-deg23]]，它在$\Q$上不可约。注意$f$有三个**实**根（见图）：在$\Q$上不可约并不意味着没有实根。它的根是$2\cos 20^\circ$、$2\cos 140^\circ$和$2\cos 260^\circ$，这正是用尺规不可能三等分$60^\circ$角的原因（[[abstract-algebra/fields-galois]]）。
:::
:::

:::

对于更高次的多项式，我们还需要排除分解为非一次因式之积的可能。高斯引理表明，只需寻找**整**系数的分解即可。非零多项式$f \in \Z[x]$的**容度**$c(f)$是它各系数的最大公因数；若$c(f) = 1$，则称$f$是**本原**的。

::: theorem 高斯（Gauss）引理 {#thm-gauss-lemma}
1. $\Z[x]$中两个本原多项式的乘积是本原的。
2. 若$f \in \Z[x]$可以分解为$f = gh$，其中$g, h \in \Q[x]$的次数$m, n \ge 1$，则$f = GH$，其中$G, H \in \Z[x]$的次数分别为$m$和$n$。特别地，本原多项式在$\Q$上不可约，当且仅当它在$\Z[x]$中不可约。
:::

::: proof
1. 设$g, h$是本原的，并假设某个素数$p$整除$gh$的每个系数。把系数模$p$约化是一个环同态$\Z[x] \to \F_p[x]$，$u \mapsto \bar u$，所以$\bar g\,\bar h = \overline{gh} = 0$。但$\F_p[x]$是整环（[[#prop-degree]]），所以$\bar g = 0$或$\bar h = 0$，这意味着$p$整除$g$的所有系数或$h$的所有系数——这与本原性矛盾。

2. 每个非零的$u \in \Q[x]$都可以写成$u = \alpha u_1$，其中$\alpha \in \Q_{>0}$，$u_1 \in \Z[x]$是本原的：先通分去掉分母，再除以容度即可。按这种方式写$g = \alpha g_1$，$h = \beta h_1$。于是$f = \alpha\beta\, g_1h_1$，并且由第1部分，$g_1h_1$是本原的。写成既约分数$\alpha\beta = u/v$，其中$v > 0$。于是$vf = u\,g_1h_1$，两边取容度得$v\,c(f) = \abs{u}\,c(g_1h_1) = \abs{u}$。所以$v$整除$\abs u$；又因为$\gcd(u, v) = 1$，所以$v = 1$：$\alpha\beta = u$是整数。因此$f = (ug_1)h_1$，其中$G = ug_1$和$H = h_1$属于$\Z[x]$，次数分别与$g$和$h$相同。
:::

::: theorem 艾森斯坦（Eisenstein）判别法 {#thm-eisenstein}
设$f = a_nx^n + a_{n-1}x^{n-1} + \dots + a_0 \in \Z[x]$，$n \ge 1$，$p$是满足

$$
p \nmid a_n, \qquad p \mid a_i \ \ (0 \le i \le n-1), \qquad p^2 \nmid a_0 .
$$

的素数，则$f$在$\Q$上不可约。
:::

::: proof
假设结论不成立。由高斯引理，$f = gh$，其中$g = b_kx^k + \dots + b_0$和$h = c_lx^l + \dots + c_0$属于$\Z[x]$，$k, l \ge 1$，$k + l = n$。模$p$约化。$f$除首项系数外的所有系数都变为零，所以

$$
\bar a_n x^n = \bar f = \bar g\,\bar h \qquad\text{在 } \F_p[x] \text{ 中},
$$

其中$\bar a_n \neq 0$。由于$b_kc_l = a_n$不能被$p$整除，$b_k$和$c_l$也都不能被$p$整除，所以$\deg\bar g = k$，$\deg \bar h = l$。由$\F_p[x]$中的唯一因式分解（[[#thm-poly-ufd]]），$\bar a_nx^n$唯一的首一不可约因式是$x$，所以$\bar g = \bar b_kx^k$，$\bar h = \bar c_lx^l$。由于$k, l \ge 1$，$\bar g$和$\bar h$的常数项都为零：$p \mid b_0$且$p \mid c_0$。但这样一来$p^2 \mid b_0c_0 = a_0$，矛盾。
:::

::: example 艾森斯坦判别法的应用 {#ex-eisenstein}
证明下列多项式在$\Q$上不可约：(a) $x^n - 2$，其中$n \ge 1$任意；(b) $x^5 - 6x + 3$；(c) 分圆多项式$\Phi_p(x) = x^{p-1} + x^{p-2} + \dots + x + 1$，其中$p$是素数。
::: solution
(a) 取$p = 2$应用艾森斯坦判别法：$2 \nmid 1$，$2$整除其余所有系数（$0$和$-2$），且$4 \nmid -2$。所以$\Q$上任何次数的不可约多项式都存在，并且对每个$n \ge 2$，$\sqrt[n]2$都是无理数。

(b) 取$p = 3$应用艾森斯坦判别法：$3 \nmid 1$，$3 \mid -6$，$3 \mid 3$（其余系数为$0$），且$9 \nmid 3$。这个多项式将在[[abstract-algebra/fields-galois]]中再次出现，作为一个不能用根式求解的方程。

(c) 艾森斯坦判别法不能直接应用，但代换$x \mapsto x + 1$不改变不可约性（它是$\Q[x]$的保持次数的环自同构）。由于$\Phi_p(x) = \frac{x^p - 1}{x - 1}$，

$$
\Phi_p(x + 1) = \frac{(x+1)^p - 1}{x} = \sum_{k=1}^{p}\binom pk x^{k-1} = x^{p-1} + \binom{p}{p-1}x^{p-2} + \dots + \binom p2 x + p .
$$

首项系数为$1$；其余每个系数$\binom pk$（$1 \le k \le p-1$）都能被$p$整除；而常数项$p$不能被$p^2$整除。所以$\Phi_p(x+1)$不可约，从而$\Phi_p(x)$不可约。当$p = 5$时：$\Phi_5(x+1) = x^4 + 5x^3 + 10x^2 + 10x + 5$。
:::
:::

::: widget complexplane
mode: roots
n: 5
z: 1,0
caption: 五次单位根是$x^5 - 1 = (x - 1)\Phi_5(x)$的根。根$1$属于有理因式$x - 1$；另外四个是$\Phi_5(x) = x^4 + x^3 + x^2 + x + 1$的根，而对$\Phi_5(x+1)$应用艾森斯坦判别法可知，$\Phi_5(x)$在$\Q$上不可约。没有任何次数小于$4$的非零有理系数多项式以$e^{2\pi i/5}$为根。
:::

第三种检验方法把问题归结到有限域上，在那里可以通过有限次检查来解决。

::: proposition 模p约化 {#prop-mod-p}
设$f \in \Z[x]$的首项系数不能被素数$p$整除。若约化所得的$\bar f \in \F_p[x]$在$\F_p$上不可约，则$f$在$\Q$上不可约。
:::

::: proof
若$f$在$\Q$上可约，则由高斯引理，在$\Z[x]$中$f = gh$，其中$\deg g, \deg h \ge 1$。$g$与$h$的首项系数之积不能被$p$整除，所以约化保持两者的次数，这样$\bar f = \bar g\bar h$就会是$\bar f$分解为次数至少为$1$的多项式之积的一个分解。
:::

例如，$f = x^4 + 10x^3 + 7x + 1$模$2$约化为$x^4 + x + 1$。它在$\F_2$上没有根（$0$和$1$代入都得$1$），而$\F_2$上唯一的不可约二次多项式是$x^2 + x + 1$，它的平方$x^4 + x^2 + 1$与之不同；所以$x^4 + x + 1$在$\F_2$上不可约，从而$f$在$\Q$上不可约。

::: warning 模p检验的逆命题不成立
在$\Q$上不可约的多项式，可能模**每个**素数都可约。标准的例子是$x^4 + 1$：它在$\Q$上不可约（取$p = 2$，对$(x+1)^4 + 1 = x^4 + 4x^3 + 6x^2 + 4x + 2$应用艾森斯坦判别法），然而它模$3$等于$(x^2 + x - 1)(x^2 - x - 1)$，模$5$等于$(x^2 + 2)(x^2 - 2)$，事实上它模每个素数都可以分解（[[#exr-8-8]]）。所以模$p$检验失败并不能证明任何结论。
:::

::: quiz
下列多项式中哪些在$\Q$上不可约？（选出所有正确的选项。）
- [x] $x^2 - 2$
- [ ] $x^2 - 4$
- [x] $x^3 - 3x - 1$
- [ ] $x^4 + 4$
- [x] $x^5 - 6x + 3$
::: solution
$x^2 - 2$没有有理根。$x^2 - 4 = (x - 2)(x + 2)$。[[#ex-cubic]]已证明$x^3 - 3x - 1$不可约。$x^4 + 4 = (x^2 + 2x + 2)(x^2 - 2x + 2)$没有有理根，但可以分解为二次多项式之积。$x^5 - 6x + 3$对$p = 3$满足艾森斯坦判别法的条件。
:::
:::

## 用不可约多项式构造域

现在我们可以确切地说出$F[x]$的商环何时是域。

::: theorem 模不可约多项式的商环 {#thm-quotient-field}
设$p \in F[x]$的次数为$n \ge 1$，则下列条件等价：

1. $p$在$F$上不可约；
2. 理想$(p)$是极大理想；
3. $F[x]/(p)$是域。

此时，$K = F[x]/(p)$的每个元素都可以唯一地写成$a_0 + a_1\alpha + \dots + a_{n-1}\alpha^{n-1}$的形式，其中$a_i \in F$，$\alpha = x + (p)$；所以$K$是$F$上的$n$维向量空间，并且若$F$是有$q$个元素的有限域，则$\abs{K} = q^n$。
:::

::: proof
(1) ⇔ (2)：由于$F[x]$是主理想整环，每个包含$(p)$的理想都形如$(d)$，其中$d \mid p$。若$p$不可约，则这样的$d$要么是非零常数（此时$(d) = F[x]$），要么是$p$的常数倍（此时$(d) = (p)$）；因此$(p)$是极大理想（由于$\deg p \ge 1$，它是真理想）。若$p = gh$，其中$1 \le \deg g < n$，则$(p) \subsetneq (g) \subsetneq F[x]$，所以$(p)$不是极大理想。

(2) ⇔ (3)就是[[abstract-algebra/rings#thm-maximal-field]]。

再看元素的描述：由带余除法，每个$f \in F[x]$都满足$f = qp + r$，其中$r = 0$或$\deg r < n$，并且$f + (p) = r + (p) = r(\alpha)$。若两个次数小于$n$的余式$r, r'$给出同一个陪集，则$p \mid r - r'$，由次数可知必有$r = r'$。所以陪集与次数小于$n$的$q^n$个多项式一一对应。
:::

在$K = F[x]/(p)$中，我们用$\alpha$的多项式进行计算，并利用关系式$p(\alpha) = 0$来化简幂$\alpha^n, \alpha^{n+1}, \dots$。域$F$以常数所在陪集的形式包含在$K$中。

::: example 有4、8和9个元素的域 {#ex-finite-fields}
(a) 证明$x^2 + x + 1$在$\F_2$上不可约，并描述$\F_4 = \F_2[x]/(x^2 + x + 1)$。(b) 构造一个有$8$个元素的域，并证明它的非零元都是同一个元素的幂。(c) 构造一个有$9$个元素的域。
::: solution
(a) $x^2 + x + 1$在$\F_2$中没有根（$0$和$1$代入都得$1$），所以由[[#prop-deg23]]，它是不可约的，并且$\F_4 = \set{0, 1, \alpha, \alpha + 1}$，其中$\alpha^2 = \alpha + 1$（记住在特征$2$中$-1 = 1$）。例如$\alpha(\alpha + 1) = \alpha^2 + \alpha = 2\alpha + 1 = 1$，所以$\alpha^{-1} = \alpha + 1$。乘法群$\set{1, \alpha, \alpha+1}$是由$\alpha$生成的$3$阶循环群。

(b) $x^3 + x + 1$在$\F_2$中没有根，所以它不可约，$\F_8 = \F_2[x]/(x^3 + x + 1)$有$2^3 = 8$个元素，其中$\alpha^3 = \alpha + 1$。依次计算各次幂：

$$
\alpha^3 = \alpha + 1,\quad \alpha^4 = \alpha^2 + \alpha,\quad \alpha^5 = \alpha^3 + \alpha^2 = \alpha^2 + \alpha + 1,\quad \alpha^6 = \alpha^3 + \alpha^2 + \alpha = \alpha^2 + 1,\quad \alpha^7 = \alpha^3 + \alpha = 1 .
$$

所以$\alpha, \alpha^2, \dots, \alpha^7 = 1$就是全部七个非零元：$\F_8^\times$是由$\alpha$生成的$7$阶循环群。

(c) $x^2 + 1$在$\F_3$上不可约，所以$\F_9 = \F_3[x]/(x^2+1) = \set{a + bi : a, b \in \F_3}$，其中$i^2 = -1$。这里$i$的阶为$4$，而$1 + i$的阶为$8$：$(1+i)^2 = 2i$，$(1 + i)^4 = (2i)^2 = -4 = -1$。所以乘法群同样是循环群。
:::
:::

::: warning F₄不是ℤ₄
有四个元素的域**不是**$\Z_4$：在$\Z_4$中$2 \cdot 2 = 0$，所以$\Z_4$甚至不是整环。在$\F_4$中$1 + 1 = 0$（特征为$2$），而元素$\alpha$、$\alpha + 1$是新的元素。一般地，$\Z_n$只在$n$为素数时才是域，而素数幂阶$p^k$（$k \ge 2$）的域必须构造为商环$\F_p[x]/(p(x))$。
:::

::: quiz
$\F_3[x]/(x^3 + 2x + 1)$是什么？
- [ ] 一个有$9$个元素、但不是域的环
- [ ] 一个有$9$个元素的域
- [x] 一个有$27$个元素的域
- [ ] 一个有$27$个元素、但不是域的环
::: solution
三次多项式$x^3 + 2x + 1$在$0, 1, 2$处的值分别为$1$、$1 + 2 + 1 = 4 \equiv 1$和$8 + 4 + 1 = 13 \equiv 1$，所以它在$\F_3$中没有根，由[[#prop-deg23]]，它不可约。由[[#thm-quotient-field]]，这个商环是域，其元素为$a_0 + a_1\alpha + a_2\alpha^2$，其中$a_i \in \F_3$：共$3^3 = 27$个元素。
:::
:::

[[#thm-quotient-field]]中的构造使每个多项式都能在某处有根。

::: theorem 克罗内克（Kronecker）定理 {#thm-kronecker}
设$f \in F[x]$不是常数，则存在一个包含$F$（的一个同构副本）的域$K$，使$f$在$K$中有根。
:::

::: proof
由[[#thm-poly-ufd]]，$f$有一个不可约因式$p$。令$K = F[x]/(p)$，由[[#thm-quotient-field]]，它是域。映射$F \to K$，$a \mapsto a + (p)$，是单的环同态（它的核是域$F$的一个不含$1$的理想，因而为零），所以我们把$F$与它的像等同起来。令$\alpha = x + (p)$。由于$a \mapsto a + (p)$与环运算相容，对$p = \sum c_ix^i$，我们得到$p(\alpha) = \sum c_i\alpha^i = \bigl(\sum c_i x^i\bigr) + (p) = p + (p) = 0$。所以$\alpha$是$p$的根，从而也是$f$的根。
:::

这是“发明$i$，使$x^2 + 1$有根”的抽象版本：$\R[x]/(x^2+1) \cong \C$（[[abstract-algebra/rings#ex-quotients-rings]]）。反复应用这个定理可知，每个多项式都能在某个域上分解为一次因式之积——这正是[[abstract-algebra/fields-galois]]的出发点。

::: history
16世纪，西蒙·斯蒂文（Simon Stevin）就利用了整数与多项式之间的这种相似性，他用欧几里得算法计算多项式的最大公因式。卡尔·弗里德里希·高斯（Carl Friedrich Gauss）在1799年的博士论文中证明了代数基本定理（他一生共给出了四个证明），而他的《算术研究》（*Disquisitiones Arithmeticae*，1801）中包含了关于本原多项式乘积的引理。这一不可约性判别法由特奥多尔·舍内曼（Theodor Schönemann）于1846年发表，戈特霍尔德·艾森斯坦（Gotthold Eisenstein）又于1850年独立地发表；它有时也被称为舍内曼-艾森斯坦判别法。利奥波德·克罗内克（Leopold Kronecker）通过模一个不可约多项式进行计算来构造根（1887），这为添加根提供了纯代数的基础；而埃瓦里斯特·伽罗瓦（Évariste Galois）早在1830年就已经用模$p$的多项式来构造有限域了。
:::

## 后续内容

[[abstract-algebra/fields-galois]]一章把域$F[x]/(p)$作为$F$的**域扩张**来研究：它们的扩张次数是$\deg p$，而比较扩张次数可以证明经典的尺规作图问题是不可能完成的。这里构造的有限域将在那里得到完全的分类——每个素数幂阶的域恰有一个。模素数的多项式也是关于多项式同余方程的拉格朗日定理的背景，这一定理在[[number-theory/primitive-roots]]中要用到；而分圆多项式$\Phi_n$支配着单位根的算术。

::: summary
- 在整环上，$\deg(fg) = \deg f + \deg g$；$F[x]$的单位是非零常数。
- **带余除法**：$f = qg + r$，其中$\deg r < \deg g$；因此$f(c)$是模$x - c$的余式，$c$是根当且仅当$(x - c) \mid f$，并且$n$次多项式在整环中至多有$n$个根（在$\Z_8$中则不然！）。
- $F[x]$是**主理想整环**；最大公因式满足裴蜀等式，并可用欧几里得算法求出。
- 不可约多项式是素的，分解为首一不可约多项式之积的分解是**唯一**的（[[#thm-poly-ufd]]）。次数为$2$或$3$时：不可约当且仅当没有根。
- 在$\Q$上：有理根$r/s$满足$r \mid a_0$，$s \mid a_n$；**高斯引理**把问题归结为整系数分解；**艾森斯坦判别法**（$p \mid a_i$，$p \nmid a_n$，$p^2 \nmid a_0$）和**模$p$约化**可以证明不可约性。
- $F[x]/(p)$是域当且仅当$p$不可约；它有基$1, \alpha, \dots, \alpha^{n-1}$，由此得到$\C$、$\F_4$、$\F_8$、$\F_9$这样的域。
- **克罗内克定理**：每个非常数多项式都在某个扩域中有根。
:::

## 习题

::: exercise 求余式 {level=1 check="-4"}
求$f(x) = x^{100} + 3x^{51} - 2$除以$x + 1$所得的余式。
::: solution
由余数定理，余式为$f(-1) = 1 - 3 - 2 = -4$。
:::
:::

::: exercise 根太多了 {level=1 check="4"}
$x^2 - 1$在$\Z_{15}$中有多少个根？为什么这与[[#cor-root-count]]不矛盾？
::: solution
逐一检验$a = 0, \dots, 14$：当$a = 1, 4, 11, 14$时$a^2 \equiv 1 \pmod{15}$（例如$4^2 = 16$，$11^2 = 121 = 8\cdot 15 + 1$）。所以共有$4$个根。这并不矛盾，因为$\Z_{15}$不是整环（$3 \cdot 5 = 0$）；例如$(4-1)(4+1) = 15 = 0$，而两个因子都不为零。
:::
:::

::: exercise 一个三次多项式，两个域 {level=1}
$x^3 + x + 1$在$\F_2$上不可约吗？在$\F_3$上呢？在可能的情况下把它分解。
::: solution
在$\F_2$上：在$0$和$1$处的值分别为$1$和$3 = 1$，所以没有根；由[[#prop-deg23]]，这个三次多项式不可约。在$\F_3$上：在$1$处的值为$3 = 0$，所以$x - 1$是一个因式，作除法得到在$\F_3[x]$中$x^3 + x + 1 = (x - 1)(x^2 + x + 2)$。二次多项式$x^2 + x + 2$在$0, 1, 2$处的值为$2, 1, 2$，所以它在$\F_3$上不可约。
:::
:::

::: exercise 多项式的裴蜀等式 {level=2}
在$\Q[x]$中求$d = \gcd(x^4 - 1,\ x^3 + 2x^2 + 2x + 1)$，并求多项式$u, v$，使$d = u(x^4 - 1) + v(x^3 + 2x^2 + 2x + 1)$。
::: hint
与整数的情形一样，先执行欧几里得算法，再逐步回代。
:::
::: solution
令$f = x^4 - 1$，$g = x^3 + 2x^2 + 2x + 1$。作除法得$f = (x - 2)g + (2x^2 + 3x + 1)$；验证：$(x-2)g = x^4 - 2x^2 - 3x - 2$，而$f - (x-2)g = 2x^2 + 3x + 1$。所以第一个余式为$r_1 = 2x^2 + 3x + 1 = (2x + 1)(x + 1)$。其次，$g = (x + 1)(x^2 + x + 1)$，用$r_1$除$g$：$g = \left(\tfrac12x + \tfrac14\right)r_1 + \left(\tfrac34x + \tfrac34\right)$。于是$r_1 = \tfrac43(2x+1)\cdot\tfrac34(x + 1)$，余式为$0$。所以最后一个非零余式是$\tfrac34(x + 1)$，$d = x + 1$。回代：$\tfrac34(x+1) = g - \left(\tfrac12x + \tfrac14\right)r_1 = g - \left(\tfrac12x + \tfrac14\right)\bigl(f - (x-2)g\bigr)$，所以

$$
x + 1 = -\frac{2x + 1}{3}\,f + \frac{2x^2 - 3x + 2}{3}\,g ,
$$

即$u = -\frac{2x+1}{3}$，$v = \frac{2x^2 - 3x + 2}{3}$。（展开即可验证这个恒等式。）
:::
:::

::: exercise 一个艾森斯坦多项式 {level=2}
证明$3x^5 + 15x^4 - 20x^3 + 10x + 20$在$\Q$上不可约。
::: solution
取$p = 5$：$5 \nmid 3$；$5$整除$15$、$-20$、$0$（$x^2$的系数）、$10$和$20$；且$25 \nmid 20$。由艾森斯坦判别法，这个多项式在$\Q$上不可约。
:::
:::

::: exercise 不可约二次多项式的计数 {level=2 check="10"}
$\F_5[x]$中有多少个首一不可约二次多项式？
::: hint
数一数能写成两个首一一次因式之积的首一二次多项式有多少个。
:::
::: solution
首一二次多项式$x^2 + bx + c$共有$5^2 = 25$个。可约的形如$(x - r)(x - s)$；$r = s$的有$5$个，$r \neq s$的有$\binom52 = 10$个（无序对）。所以有$15$个可约，$25 - 15 = 10$个不可约。一般地，$\F_p$上共有$p^2 - p - \binom p2 = \frac{p(p-1)}{2}$个首一不可约二次多项式。
:::
:::

::: exercise 索菲·热尔曼（Sophie Germain）恒等式 {level=2}
验证$x^4 + 4 = (x^2 + 2x + 2)(x^2 - 2x + 2)$，并证明$x^4 + 4$没有有理根。为什么这与[[#prop-deg23]]不矛盾？
::: solution
$(x^2 + 2 + 2x)(x^2 + 2 - 2x) = (x^2 + 2)^2 - (2x)^2 = x^4 + 4x^2 + 4 - 4x^2 = x^4 + 4$。由于对所有实数$x$有$x^4 + 4 \ge 4 > 0$，它没有实根，更不用说有理根了。[[#prop-deg23]]只适用于次数为$2$和$3$的情形；四次多项式可以在没有任何根的情况下分解为两个二次多项式之积。
:::
:::

::: exercise x⁴ + 1模每个素数都可约 {level=3}
证明：尽管$x^4 + 1$在$\Q$上不可约，但对每个素数$p$，它在$\F_p$上都可约。
::: hint
利用两个非平方元之积是平方元这一事实（[[number-theory/quadratic-reciprocity]]），证明（对奇数$p$）$-1$、$2$、$-2$中有一个是模$p$的平方，并在每种情形下找出一个分解。
:::
::: solution
当$p = 2$时：在$\F_2[x]$中$x^4 + 1 = (x + 1)^4$。设$p$是奇素数。非零平方元构成$\F_p^\times$中指数为$2$的子群，所以两个非平方元之积是平方元；因此$-1$、$2$、$-2 = (-1)\cdot 2$不可能都是非平方元。在每种情形下：

- 若$-1 = a^2$：$x^4 + 1 = x^4 - a^2 = (x^2 - a)(x^2 + a)$；
- 若$2 = b^2$：$(x^2 + bx + 1)(x^2 - bx + 1) = (x^2 + 1)^2 - b^2x^2 = x^4 + (2 - b^2)x^2 + 1 = x^4 + 1$；
- 若$-2 = c^2$：$(x^2 + cx - 1)(x^2 - cx - 1) = (x^2 - 1)^2 - c^2x^2 = x^4 - (2 + c^2)x^2 + 1 = x^4 + 1$。

所以$x^4 + 1$模每个素数都可以分解。在$\Q$上它不可约，因为$(x + 1)^4 + 1 = x^4 + 4x^3 + 6x^2 + 4x + 2$对$2$满足艾森斯坦判别法的条件。
:::
:::

::: exercise 𝔽₉ˣ的一个生成元 {level=3 check="4"}
在$\F_9 = \F_3[x]/(x^2 + 1)$中（其中$i = x + (x^2+1)$），求$i$和$1 + i$的阶，并列出所有$8$阶元。共有多少个？
::: solution
$i^2 = -1$，$i^4 = 1$，所以$\ord(i) = 4$。由[[#ex-finite-fields]]，$(1 + i)^2 = 2i$，$(1+i)^4 = -1$，所以$\ord(1+i) = 8$，$\F_9^\times = \langle 1 + i\rangle$是$8$阶循环群。由[[abstract-algebra/subgroups#thm-order-of-power]]，$(1 + i)^k$的阶为$8$当且仅当$\gcd(k, 8) = 1$，即$k \in \set{1, 3, 5, 7}$：这些元素是$(1+i)^1 = 1 + i$，$(1+i)^3 = 1 - i = 1 + 2i$，$(1+i)^5 = -1 - i = 2 + 2i$和$(1+i)^7 = -1 + i = 2 + i$。共有$\varphi(8) = 4$个。
:::
:::

::: exercise 无穷多个不可约多项式 {level=3}
证明：对每个域$F$，$F[x]$中都有无穷多个首一不可约多项式。
::: hint
仿照欧几里得关于素数有无穷多个的证明（[[number-theory/primes]]）。
:::
::: solution
假设$p_1, \dots, p_k$就是全部的首一不可约多项式。令$f = p_1p_2\cdots p_k + 1$，它的次数至少为$1$。由[[#thm-poly-ufd]]，$f$有一个首一不可约因式，它必定是某个$p_j$。但$p_j$整除$p_1\cdots p_k$，从而整除$f - p_1\cdots p_k = 1$，这对次数至少为$1$的多项式是不可能的。（对无限域$F$，结论是显然的，因为所有$x - a$都不可约；这个论证对有限域才有意义。）
:::
