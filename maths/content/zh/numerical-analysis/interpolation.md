在电子计算机出现以前，科学家要在印刷的数表中查找对数、正弦和贝塞尔（Bessel）函数的值，并且常常需要表中所列数值**之间**的值。今天，同样的问题随处可见：一个函数只在少数几个点上已知——测量值、代价高昂的模拟的输出、常微分方程求解器在网格上的值——而我们希望有一个经过这些点的公式，可以在任何地方求值、求导或积分。最简单的这类公式就是多项式。

**多项式插值**问题是：给定$n + 1$个点$(x_0, y_0), \dots, (x_n, y_n)$，其中**节点**$x_i$互不相同，求次数至多为$n$的多项式$p$，使得对每个$i$都有$p(x_i) = y_i$。本章证明这样的多项式恰有一个，给出两种实用的写法（拉格朗日形式和牛顿形式），并在数据来自光滑函数时证明一个误差公式。这个误差公式会引出一个意外——在更多的等距点上插值反而可能使结果**更糟**（龙格现象）——以及它的补救办法：切比雪夫节点，或者称为**样条**的分段多项式。插值也是后面几章的基础：求积公式对插值多项式积分，而许多常微分方程求解器则对插值多项式作外推。

## 存在性、唯一性与拉格朗日形式

用$\mathcal P_n$表示次数至多为$n$的实系数多项式的集合。

::: theorem 插值多项式的存在唯一性 {#thm-interp-unique}
设$x_0, x_1, \dots, x_n$是互不相同的实数，$y_0, \dots, y_n$是任意实数。则恰有一个多项式$p \in \mathcal P_n$，使得$p(x_i) = y_i$，$i = 0, \dots, n$。
:::

::: proof
**唯一性。**若$p, q \in \mathcal P_n$都对这些数据插值，则$p - q \in \mathcal P_n$在$n + 1$个不同的点$x_i$处为零。次数至多为$n$的非零多项式至多有$n$个根，所以$p - q = 0$。

**存在性。**对每个$j$，定义**拉格朗日基函数**

$$
\ell_j(x) = \prod_{k \ne j}\frac{x - x_k}{x_j - x_k} = \frac{(x - x_0)\cdots(x - x_{j-1})(x - x_{j+1})\cdots(x - x_n)}{(x_j - x_0)\cdots(x_j - x_{j-1})(x_j - x_{j+1})\cdots(x_j - x_n)} .
$$ {#eq-lagrange-basis}

它是$n$个一次因式的乘积，所以$\ell_j \in \mathcal P_n$；它在除$x_j$以外的每个节点处都为零，而在$x_j$处等于$1$：$\ell_j(x_i) = \delta_{ij}$。因此

$$
p(x) = \sum_{j=0}^n y_j\,\ell_j(x)
$$ {#eq-lagrange-form}

满足$p(x_i) = \sum_j y_j\delta_{ij} = y_i$。
:::

公式[[#eq-lagrange-form]]称为插值多项式的**拉格朗日形式**。当数据来自某个函数，即$y_i = f(x_i)$时，记$p = p_n$，并称之为$f$的插值多项式。

::: example 过三点的二次多项式 {#ex-lagrange}
求经过$(0, 1)$、$(1, 3)$和$(2, 2)$的次数至多为$2$的多项式。
::: solution
拉格朗日基函数为

$$
\ell_0(x) = \frac{(x-1)(x-2)}{(0-1)(0-2)} = \frac{(x-1)(x-2)}{2}, \quad \ell_1(x) = \frac{x(x-2)}{(1)(-1)} = -x(x-2), \quad \ell_2(x) = \frac{x(x-1)}{2\cdot1}.
$$

所以$p(x) = 1\cdot\frac{(x-1)(x-2)}{2} - 3x(x-2) + 2\cdot\frac{x(x-1)}{2}$。展开得$p(x) = \frac12x^2 - \frac32x + 1 - 3x^2 + 6x + x^2 - x = -\frac32x^2 + \frac72x + 1$。验证：$p(0) = 1$，$p(1) = -\frac32 + \frac72 + 1 = 3$，$p(2) = -6 + 7 + 1 = 2$。
:::
:::

::: remark 为什么不直接求解系数？
若写$p(x) = a_0 + a_1x + \cdots + a_nx^n$，则条件$p(x_i) = y_i$构成一个线性方程组$V\mathbf a = \mathbf y$，其系数矩阵是**范德蒙德矩阵**$V_{ij} = x_i^j$。[[#thm-interp-unique]]表明$V$可逆，但它是极端病态的：对$[0, 1]$上$n + 1$个等距节点，它的条件数（[[numerical-analysis/direct-methods]]）在$n = 5$时约为$4.9\times10^3$，在$n = 10$时约为$1.2\times10^8$，在$n = 20$时约为$9\times10^{16}$，所以在双精度下，$n = 20$时的单项式系数可能完全错误。拉格朗日形式和牛顿形式则根本不需要计算这些系数。
:::

## 牛顿形式与差商

拉格朗日形式有一个缺点：每增加一个数据点，所有的基函数都要改变。**牛顿形式**则逐个节点地构造插值多项式：

$$
p_n(x) = c_0 + c_1(x - x_0) + c_2(x - x_0)(x - x_1) + \cdots + c_n(x - x_0)(x - x_1)\cdots(x - x_{n-1}) .
$$

增加一个节点$x_{n+1}$只需添加一项。这些系数原来就是**差商**。

::: definition 差商 {#def-divided}
$f$在互不相同的节点上的差商递归地定义为$f[x_i] = f(x_i)$以及

$$
f[x_i, x_{i+1}, \dots, x_{i+k}] = \frac{f[x_{i+1}, \dots, x_{i+k}] - f[x_i, \dots, x_{i+k-1}]}{x_{i+k} - x_i} .
$$
:::

于是$f[x_0, x_1] = \frac{f(x_1) - f(x_0)}{x_1 - x_0}$是割线的斜率，$f[x_0, x_1, x_2]$是斜率之差除以一段距离，依此类推。

::: theorem 牛顿插值公式 {#thm-newton-form}
$f$在互不相同的节点$x_0, \dots, x_n$上的插值多项式为

$$
p_n(x) = \sum_{k=0}^n f[x_0, \dots, x_k]\prod_{j=0}^{k-1}(x - x_j) .
$$ {#eq-newton-form}

特别地，$p_n$中$x^n$的系数为$f[x_0, \dots, x_n]$。
:::

::: proof
对$0 \le i$且$i + k \le n$，设$p_{i,k} \in \mathcal P_k$是$f$在$x_i, \dots, x_{i+k}$上的插值多项式。我们先证明**艾特肯（Aitken）公式**：对$k \ge 1$，

$$
p_{i,k}(x) = \frac{(x - x_i)\,p_{i+1,k-1}(x) - (x - x_{i+k})\,p_{i,k-1}(x)}{x_{i+k} - x_i} .
$$

右端的次数至多为$k$。在$x = x_i$处，它等于$\frac{-(x_i - x_{i+k})f(x_i)}{x_{i+k} - x_i} = f(x_i)$；在$x = x_{i+k}$处，它等于$f(x_{i+k})$；而在中间的节点$x_j$处，$p_{i+1,k-1}$和$p_{i,k-1}$都等于$f(x_j)$，所以它等于$\frac{(x_j - x_i) - (x_j - x_{i+k})}{x_{i+k} - x_i}f(x_j) = f(x_j)$。由唯一性，它就是$p_{i,k}$。

比较艾特肯公式中$x^k$的系数，可知首项系数$L_{i,k}$满足$L_{i,k} = \frac{L_{i+1,k-1} - L_{i,k-1}}{x_{i+k} - x_i}$，这与差商的递推关系相同，且$L_{i,0} = f(x_i)$。对$k$用归纳法，得$L_{i,k} = f[x_i, \dots, x_{i+k}]$。

现在，$p_{0,k} - p_{0,k-1}$的次数至多为$k$，且在$x_0, \dots, x_{k-1}$处为零，所以它等于$c\,(x - x_0)\cdots(x - x_{k-1})$；比较首项系数，得$c = L_{0,k} = f[x_0, \dots, x_k]$。对$k = 1, \dots, n$把$p_{0,k} - p_{0,k-1}$相加，再加上$p_{0,0} = f(x_0)$，即得[[#eq-newton-form]]。
:::

差商在一张三角形的表中逐列计算，而牛顿形式则像霍纳（Horner）法则那样用嵌套乘法求值。

```python
def divided_differences(x, y):
    """返回牛顿系数 c[k] = f[x_0, ..., x_k]。"""
    c = list(y)
    n = len(x)
    for k in range(1, n):                     # 差商表的第 k 列
        for i in range(n - 1, k - 1, -1):     # 自下而上更新
            c[i] = (c[i] - c[i-1]) / (x[i] - x[i-k])
    return c

def newton_eval(c, x, t):
    """用嵌套乘法计算牛顿形式在 t 处的值。"""
    p = c[-1]
    for k in range(len(c) - 2, -1, -1):
        p = p * (t - x[k]) + c[k]
    return p
```

::: example 差商表 {#ex-divided}
以$1, 2, 4$为节点对$f(x) = \frac1x$插值，并用所得结果估计$f(3)$。
::: solution
差商表为

| $x_i$ | $f[x_i]$ | 一阶差商 | 二阶差商 |
|---|---|---|---|
| $1$ | $1$ | | |
| | | $f[1,2] = \frac{1/2 - 1}{2 - 1} = -\frac12$ | |
| $2$ | $\frac12$ | | $f[1,2,4] = \frac{-1/8 - (-1/2)}{4 - 1} = \frac18$ |
| | | $f[2,4] = \frac{1/4 - 1/2}{4 - 2} = -\frac18$ | |
| $4$ | $\frac14$ | | |

表中最上方的斜线给出牛顿形式

$$

在$x = 3$处：$p_2(3) = 1 - 1 + \frac18\cdot2\cdot1 = \frac14$，而$f(3) = \frac13$。误差$\frac1{12} \approx 0.083$很大，因为$\frac1x$在$[1, 4]$上弯曲得很厉害；下面的误差公式将精确地解释这一点。

## 插值误差

当数据来自光滑函数时，插值多项式的误差有一个与泰勒定理（[[calculus-2/taylor-series#thm-taylor]]）中的余项惊人相似的公式。事实上，泰勒多项式正是所有节点重合时的极限情形。

::: theorem 插值误差 {#thm-interp-error}
设$f$在$[a, b]$上$n + 1$阶连续可导，$p_n$是$f$在$[a, b]$中互不相同的节点$x_0, \dots, x_n$上的插值多项式。则对每个$x \in [a, b]$，存在$\xi \in (a, b)$，使得

$$
f(x) - p_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}\,\omega_{n+1}(x), \qquad \omega_{n+1}(x) = \prod_{i=0}^n(x - x_i) .
$$ {#eq-interp-error}
:::

::: proof
若$x$是节点，则两边都为$0$。否则$\omega_{n+1}(x) \ne 0$，对$t \in [a, b]$定义

$$
g(t) = f(t) - p_n(t) - \bigl(f(x) - p_n(x)\bigr)\frac{\omega_{n+1}(t)}{\omega_{n+1}(x)} .
$$

则$g$在$n + 1$个节点处（那里$f = p_n$且$\omega_{n+1} = 0$）以及在$t = x$处为零：它在$[a, b]$中有$n + 2$个不同的零点。由罗尔定理，$g'$至少有$n + 1$个严格位于这些零点之间的零点，$g''$至少有$n$个，依此类推：$g^{(n+1)}$有一个零点$\xi \in (a, b)$。由于$p_n^{(n+1)} = 0$，且$\omega_{n+1}^{(n+1)} = (n+1)!$（它是$n + 1$次首一多项式），

$$
0 = g^{(n+1)}(\xi) = f^{(n+1)}(\xi) - \bigl(f(x) - p_n(x)\bigr)\frac{(n+1)!}{\omega_{n+1}(x)},
$$

整理即得[[#eq-interp-error]]。
:::

::: corollary 误差界 {#cor-interp-bound}
若在$[a, b]$上$\abs{f^{(n+1)}} \le M_{n+1}$，则$\displaystyle\max_{[a,b]}\abs{f - p_n} \le \frac{M_{n+1}}{(n+1)!}\max_{[a,b]}\abs{\omega_{n+1}}$。对于相距为$h$的两点之间的线性插值，$\abs{f - p_1} \le \frac{M_2h^2}{8}$。
:::

::: proof
第一个结论由[[#eq-interp-error]]得出。对$n = 1$，节点为$x_0$和$x_0 + h$，$\abs{\omega_2(x)} = \abs{(x - x_0)(x - x_0 - h)}$在中点处最大，等于$\frac{h^2}{4}$；除以$2! = 2$即得$\frac{M_2h^2}{8}$。
:::

比较这两个公式可知，差商是乘了一个比例因子的导数：在点$x = x_n$处应用把$n$换成$n - 1$的[[#eq-interp-error]]，并利用[[#thm-newton-form]]，就得到$f[x_0, \dots, x_n] = \frac{f^{(n)}(\xi)}{n!}$，其中$\xi$是节点所张成的区间中的某个数（[[#exr-dd-derivative]]）。

::: example 函数表的插值 {#ex-table}
一张函数表以间距$h = 0.1$列出$\sin x$的值。在相邻表值之间作线性插值的精度如何？什么样的间距能给出六位正确的小数？
::: solution
由于$\abs{(\sin)''} \le 1$，[[#cor-interp-bound]]给出：当$h = 0.1$时，误差至多为$\frac{h^2}{8} = \frac{0.01}{8} = 1.25\times10^{-3}$，所以只有大约两位小数是可靠的。要使误差小于$5\times10^{-7}$，需要$\frac{h^2}{8} \le 5\times10^{-7}$，即$h \le \sqrt{4\times10^{-6}} = 0.002$。印刷的数表正是基于这样的计算来选择间距，或者提供二阶差分以供二次插值之用。
:::
:::

对[[#ex-divided]]，该公式给出$f(3) - p_2(3) = \frac{f'''(\xi)}{6}\omega_3(3)$，其中$f'''(x) = -\frac{6}{x^4}$，$\omega_3(3) = (3-1)(3-2)(3-4) = -2$，所以误差为$\frac{2}{\xi^4}$，这里$\xi \in (1, 4)$。实际误差$\frac1{12}$对应于$\xi = 24^{1/4} \approx 2.21$。

::: quiz
对互不相同的节点$x_0, \dots, x_n$，拉格朗日基函数之和$\sum_{j=0}^n\ell_j(x)$等于什么？
- [ ] $0$
- [x] 对每个$x$都等于$1$
- [ ] $n + 1$
- [ ] 取决于节点。
::: solution
$\sum_j\ell_j(x) = \sum_j 1\cdot\ell_j(x)$是常值函数$f = 1$的插值多项式。由唯一性（[[#thm-interp-unique]]），这个插值多项式就是$1$本身。等价地，由于$f^{(n+1)} = 0$，[[#eq-interp-error]]给出的误差为$0$。更一般地，插值能精确地再现每个次数至多为$n$的多项式。
:::
:::

## 龙格现象

误差公式似乎表明，节点越多误差就越小：分母中的因子$(n+1)!$增长得非常快。1901年，卡尔·龙格（Carl Runge）证明，即使对于一个看似无害的函数，这种期望也可能彻底落空。考虑函数

$$
f(x) = \frac{1}{1 + 25x^2} \qquad\text{定义于 } [-1, 1]
$$

在$n + 1$个等距节点$x_i = -1 + \frac{2i}{n}$上对它进行插值。在$[-1, 1]$上的最大误差为：

| 次数$n$ | $5$ | $10$ | $15$ | $20$ | $40$ |
|---|---|---|---|---|---|
| 等距节点 | $0.43$ | $1.92$ | $2.11$ | $59.8$ | $1.0\times10^{5}$ |
| 切比雪夫节点 | $0.56$ | $0.11$ | $0.083$ | $0.015$ | $2.9\times10^{-4}$ |

采用等距节点时，插值多项式在区间中部与$f$吻合得很好，但在两端附近剧烈振荡，振幅随$n$呈指数增长。这就是**龙格现象**。

::: widget interpolation
f: 1/(1 + 25x^2)
n: 11
nodes: equispaced
caption: 在$11$个等距节点上对龙格函数插值（次数为$10$）。在中心附近拟合得很好，但在$\pm1$附近严重过冲。增加节点数：两端的振荡**变大**。再把节点切换为切比雪夫节点，看着振荡消失。
:::

[[#eq-interp-error]]中的两个因子解释了这一现象。第一，$f$的各阶导数增长得非常快：$\max\abs{f^{(n+1)}}$大致像$(n+1)!\,5^{n+1}$那样增长，因为$f$在$\pm\frac{i}{5}$处有复极点，离实区间很近。第二，对等距节点，节点多项式$\omega_{n+1}(x)$在区间两端附近比在中部大得多：节点在$\pm1$附近太稀疏了。第二个因子是我们可以通过选择节点来控制的。

::: warning 数据点越多并不总是越好
对于在等距点上的多项式插值，即使函数是光滑的（甚至是解析的），提高次数也可能使近似发散。在等距点上的高次插值还是严重病态的：数据中的微小误差会被极大地放大。如果你的数据是等距的，请使用低次的分段多项式（样条）或最小二乘拟合（[[linear-algebra/least-squares]]），而不要用一个高次插值多项式。
:::

## 切比雪夫节点

为了使误差界最小，我们应当选取使$\max_{[-1,1]}\abs{\omega_{n+1}}$尽可能小的节点。答案涉及**切比雪夫多项式**

$$
T_n(x) = \cos(n\arccos x), \qquad -1 \le x \le 1 .
$$

令$x = \cos\theta$，由恒等式$\cos((n+1)\theta) + \cos((n-1)\theta) = 2\cos\theta\cos(n\theta)$得到递推关系

$$
T_0(x) = 1, \quad T_1(x) = x, \quad T_{n+1}(x) = 2xT_n(x) - T_{n-1}(x),
$$

于是$T_2 = 2x^2 - 1$，$T_3 = 4x^3 - 3x$；一般地，$T_n$是首项系数为$2^{n-1}$的$n$次多项式（$n \ge 1$）。由余弦形式可知：在$[-1, 1]$上$\abs{T_n(x)} \le 1$；$T_n$在$n + 1$个点$\eta_k = \cos\frac{k\pi}{n}$（$k = 0, \dots, n$）处交替取值$\pm1$；它的$n$个零点为$\cos\frac{(2k+1)\pi}{2n}$，$k = 0, \dots, n-1$。

::: theorem 切比雪夫多项式的极小极大性质 {#thm-chebyshev}
对$n \ge 1$，首一多项式$\tilde T_n = 2^{1-n}T_n$满足$\max_{[-1,1]}\abs{\tilde T_n} = 2^{1-n}$，而每个$n$次首一多项式$q$都满足$\max_{[-1,1]}\abs{q} \ge 2^{1-n}$。
:::

::: proof
第一个结论由$\abs{T_n} \le 1$（在点$\eta_k$处取等号）得出。假设某个$n$次首一多项式$q$对所有$x \in [-1, 1]$都有$\abs{q(x)} < 2^{1-n}$。则$r = \tilde T_n - q$的次数至多为$n - 1$（首项相互抵消）。在$n + 1$个点$\eta_0 > \eta_1 > \cdots > \eta_n$处，$\tilde T_n(\eta_k) = (-1)^k2^{1-n}$，而$\abs{q(\eta_k)} < 2^{1-n}$，所以$r(\eta_k)$的符号为$(-1)^k$。因此$r$在相邻的$\eta_k$之间变号，由介值定理，它至少有$n$个零点。次数至多为$n - 1$而有$n$个零点的多项式只能是$0$，所以$q = \tilde T_n$，这与$\max\abs q < 2^{1-n} = \max\abs{\tilde T_n}$矛盾。
:::

::: corollary 在切比雪夫节点上插值 {#cor-chebyshev-nodes}
若节点取为$T_{n+1}$的零点，即**切比雪夫节点**$x_k = \cos\frac{(2k+1)\pi}{2n+2}$，$k = 0, \dots, n$，则$\omega_{n+1} = \tilde T_{n+1}$，并且对$f \in C^{n+1}[-1, 1]$有

$$
\max_{[-1,1]}\abs{f - p_n} \le \frac{\max\abs{f^{(n+1)}}}{2^n\,(n+1)!} .
$$

任何其他节点选取都不能使$\max\abs{\omega_{n+1}}$的值更小。
:::

::: proof
$\omega_{n+1}$是$n + 1$次首一多项式，与$\tilde T_{n+1}$有相同的$n + 1$个零点，所以两者相等；由[[#thm-chebyshev]]，$\max\abs{\omega_{n+1}} = 2^{-n}$；把它代入[[#cor-interp-bound]]即可。最优性就是[[#thm-chebyshev]]的第二部分。在一般区间$[a, b]$上，对节点作仿射变换：$x_k = \frac{a+b}{2} + \frac{b-a}{2}\cos\frac{(2k+1)\pi}{2n+2}$。
:::

改进是惊人的。当$n = 10$时，$\abs{\omega_{11}}$的最大值对等距节点为$8.5\times10^{-3}$，对切比雪夫节点为$9.8\times10^{-4}$；当$n = 20$时，两者之比约为$245$。切比雪夫节点聚集在区间两端附近——就像半圆上等距分布的点在$x$轴上的投影——而那里正是等距节点过于稀疏的地方。对龙格函数，切比雪夫插值多项式以几何速度收敛（见上表第二行）。

::: remark 稳定的求值方法：重心公式
在现代软件中（例如 Chebfun 系统），$1000$次的切比雪夫插值是家常便饭，但前提是使用稳定的求值公式。用常数$1$的插值多项式去除拉格朗日形式，就得到**重心公式**$p(x) = \sum_j\frac{w_j}{x - x_j}y_j\Big/\sum_j\frac{w_j}{x - x_j}$，其中$w_j = 1/\prod_{k\ne j}(x_j - x_k)$。每次求值只需$O(n)$次运算，而且数值稳定；对于切比雪夫极值点$\cos\frac{k\pi}{n}$，权可以简单地取为$(-1)^k$，并在两个端点处减半。参见 Trefethen 的《逼近理论与逼近实践》（*Approximation Theory and Approximation Practice*）。
:::

## 三次样条

不用一个高次多项式，而用许多低次多项式。最简单的做法是用直线段连接各数据点；由[[#cor-interp-bound]]，间距为$h$时其误差至多为$\frac{M_2h^2}{8}$，所以当$h \to 0$时它总是收敛的，但它的图像有尖角。三次样条既保持了收敛性，又消除了尖角。

::: definition 三次样条 {#def-spline}
设$a = x_0 < x_1 < \cdots < x_n = b$。以这些点为节点的**三次样条**是这样一个函数$s$：它在每个区间$[x_{i-1}, x_i]$上是三次多项式，并且在$[a, b]$上二阶连续可导。若对所有$i$都有$s(x_i) = y_i$，则称它对数据$y_i$**插值**。若$s''(a) = s''(b) = 0$，则称它是**自然**样条。
:::

数一数条件：$n$个三次多项式共有$4n$个系数；在每个区间的两个端点处插值给出$2n$个条件，$s'$和$s''$在$n - 1$个内节点处的连续性又给出$2n - 2$个条件。还剩下两个条件可以自由选取，自然样条用端点处$s'' = 0$来确定它们。（其他选择：**固支**样条给定$s'(a)$和$s'(b)$；**非扭结**（not-a-knot）样条要求$s'''$在$x_1$和$x_{n-1}$处连续。）

::: theorem 自然三次样条 {#thm-spline}
对等距节点$x_i = a + ih$和任意数据$y_0, \dots, y_n$，恰有一个自然三次插值样条。它的二阶导数$M_i = s''(x_i)$满足$M_0 = M_n = 0$以及

$$
M_{i-1} + 4M_i + M_{i+1} = \frac{6}{h^2}\left(y_{i+1} - 2y_i + y_{i-1}\right), \qquad i = 1, \dots, n-1 ,
$$ {#eq-spline-system}

并且在$[x_{i-1}, x_i]$上

$$
s(x) = M_{i-1}\frac{(x_i - x)^3}{6h} + M_i\frac{(x - x_{i-1})^3}{6h} + \left(y_{i-1} - \frac{M_{i-1}h^2}{6}\right)\frac{x_i - x}{h} + \left(y_i - \frac{M_ih^2}{6}\right)\frac{x - x_{i-1}}{h} .
$$ {#eq-spline-piece}
:::

::: proof
设$s$是自然插值样条。在$[x_{i-1}, x_i]$上，$s''$是线性的（因为$s$是三次的），所以它是$M_{i-1}$与$M_i$之间的线性插值。积分两次，并选取两个积分常数使$s(x_{i-1}) = y_{i-1}$且$s(x_i) = y_i$，就恰好得到[[#eq-spline-piece]]（求两次导数并在端点处取值即可验证）。由构造，$s$和$s''$是连续的。对[[#eq-spline-piece]]求导，得$x_i$处的单侧导数为

$$
s'(x_i^-) = \frac{y_i - y_{i-1}}{h} + \frac{h}{6}M_{i-1} + \frac{h}{3}M_i, \qquad s'(x_i^+) = \frac{y_{i+1} - y_i}{h} - \frac h3M_i - \frac h6M_{i+1},
$$

令两者相等（$s'$的连续性），即得[[#eq-spline-system]]。反之，[[#eq-spline-system]]的任何满足$M_0 = M_n = 0$的解$M_1, \dots, M_{n-1}$都通过[[#eq-spline-piece]]定义了一个自然插值样条。所以只需证明这个线性方程组恰有一个解。它的系数矩阵$A$是三对角矩阵，对角元为$4$，与之相邻的元素为$1$，所以每一行都有$\abs{a_{ii}} = 4 > 2 \ge \sum_{j\ne i}\abs{a_{ij}}$：它是**严格对角占优**的。这样的矩阵是可逆的：若$A\mathbf z = \mathbf 0$且$\mathbf z \ne \mathbf 0$，取$i$使$\abs{z_i}$最大，则$\abs{a_{ii}}\abs{z_i} = \abs{\sum_{j\ne i}a_{ij}z_j} \le \sum_{j\ne i}\abs{a_{ij}}\abs{z_i} < \abs{a_{ii}}\abs{z_i}$，矛盾。
:::

三对角方程组只需$O(n)$次运算即可求解（[[numerical-analysis/direct-methods]]），所以即使有数百万个点，样条的计算代价也很低。对于非等距节点，同样的推导给出一个以间距$h_i$为权的三对角、对角占优的方程组。

::: example 过三点的自然样条 {#ex-spline}
求经过$(0, 0)$、$(1, 1)$、$(2, 0)$的自然三次样条。
::: solution
这里$h = 1$，$M_0 = M_2 = 0$，[[#eq-spline-system]]在$i = 1$时为$4M_1 = 6(0 - 2 + 0) = -12$，所以$M_1 = -3$。由[[#eq-spline-piece]]，在$[0, 1]$上

$$
s(x) = -3\cdot\frac{x^3}{6} + 0 + \left(1 + \frac36\right)x = -\frac{x^3}{2} + \frac32x,
$$

由对称性，在$[1, 2]$上$s(x) = s(2 - x)$。验证：$s(0) = 0$，$s(1) = 1$，$s''(0) = 0$，且$s'(1) = -\frac32 + \frac32 = 0$，与镜像的那一段相吻合。与插值抛物线$x(2 - x)$比较：样条在两端附近更平坦，因为在那里它的曲率必须为零。
:::
:::

f: 1/(1 + 25x^2)
n: 11
method: spline
caption: 经过龙格函数同样$11$个等距样本点的自然三次样条——正是这些样本点给出了那个剧烈振荡的$10$次多项式。样条处处都紧贴函数（最大误差约为$0.02$）。增加点数：现在误差**减小**了，在远离端点处大致像$h^4$那样减小。

样条的收敛是可靠的。对于四阶导数连续的函数，固支三次样条满足$\max\abs{f - s} \le \frac{5}{384}h^4\max\abs{f^{(4)}}$，而自然样条在远离端点处也达到同样的$O(h^4)$收敛速度（在端点附近，人为施加的条件$s'' = 0$把它限制为$O(h^2)$，除非$f''$在那里为零）；参见 de Boor 的《样条实用指南》（*A Practical Guide to Splines*）。对龙格函数取$n + 1$个等距点，自然样条的误差为$0.022$（$n = 10$）、$0.0032$（$n = 20$）和$0.000\,28$（$n = 40$）。在 Python 中，`scipy.interpolate.CubicSpline(x, y, bc_type='natural')`构造的就是[[#thm-spline]]中的样条。

::: quiz
用单个多项式在越来越多的等距点上对龙格函数$f$插值会失败，而在相同点上的三次样条却能成功。这是为什么？
- [ ] 样条用到了关于$f$的更多信息。
- [x] 样条的误差只涉及$h^4$和四阶导数，而多项式的误差涉及增长极快的$(n+1)$阶导数，以及一个在两端附近很大的节点多项式。
- [ ] 高次多项式无法在浮点运算中精确计算。
- [ ] 龙格函数不光滑。
::: solution
两种方法用的是相同的数据。多项式的误差[[#eq-interp-error]]含有因子$f^{(n+1)}/(n+1)!$——对龙格函数，它像$5^{n+1}$那样增长——再乘以$\omega_{n+1}$，而对等距节点，后者在$\pm1$附近很大。样条使用固定的低次数，所以只有$f^{(4)}$进入误差，并且乘以$h^4 \to 0$。（舍入误差会使高次等距插值的情况更糟，但即使在精确运算下也会发散；而且龙格函数是无穷次可导的。）
:::
:::

::: application 设计中的样条
“样条”（spline）一词原指一种薄而有弹性的木条，用压铁（“鸭子”）把它固定在选定的点上，造船工人和绘图员用它来画光滑的曲线。弯曲的弹性木条会使其弯曲能量最小，而弯曲能量近似等于$\int(s'')^2$；自然三次样条恰好是所有光滑插值函数中使这个积分最小的那一个（[[#exr-min-curvature]]）。样条及其同类——理论可追溯到20世纪40年代舍恩伯格（Schoenberg）的 B 样条，以及20世纪60年代在雪铁龙（Citroën）和雷诺（Renault）为汽车车身设计而发展起来的贝塞尔曲线——如今已成为计算机辅助设计、计算机图形学和数字字体中表示曲线与曲面的标准方式。
:::

::: history
插值公式是为编制天文表和航海表而发展起来的。艾萨克·牛顿（Isaac Newton）在《自然哲学的数学原理》（*Principia*，1687年）和《微分法》（*Methodus differentialis*，1711年）中描述了用差商进行插值的方法。拉格朗日形式由爱德华·华林（Edward Waring）于1779年发表，欧拉（Euler）于1783年用过它，约瑟夫-路易·拉格朗日（Joseph-Louis Lagrange）则于1795年给出了它。帕夫努蒂·切比雪夫（Pafnuty Chebyshev）于1854年在研究机械连杆机构时引入了以他命名的多项式。卡尔·龙格（Carl Runge）于1901年发表了他著名的例子，表明在等距点上的插值未必收敛。艾萨克·舍恩伯格（Isaac Schoenberg）于1946年引入了样条这一名称，并建立了样条的数学理论。
:::

## 后续内容

对插值多项式积分，就得到[[numerical-analysis/numerical-integration]]中的求积公式；高斯求积建立在正交多项式的根之上，正如切比雪夫插值建立在$T_n$的根之上。对插值多项式求导得到有限差分公式，对其外推则得到理查森外推和常微分方程的多步法（[[numerical-analysis/numerical-odes]]）。最小二乘逼近对含噪声的数据进行拟合而非插值，见[[linear-algebra/least-squares]]；多项式插值在三角函数中的类比是离散傅里叶变换（[[pde/fourier-transform]]）。

::: summary
- 对互不相同的节点$x_0, \dots, x_n$，在$\mathcal P_n$中存在唯一的插值多项式；其拉格朗日形式为$\sum y_j\ell_j(x)$，其中$\ell_j(x_i) = \delta_{ij}$。
- 牛顿形式$\sum f[x_0, \dots, x_k]\prod_{j<k}(x - x_j)$使用差商，可以逐个节点地构造，并用嵌套乘法求值。应避免求解病态的范德蒙德方程组。
- 误差：$f(x) - p_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}\prod(x - x_i)$；线性插值的误差至多为$M_2h^2/8$。
- 龙格现象：在等距节点上，光滑函数的高次插值多项式可能在两端附近发散。
- 切比雪夫节点$\cos\frac{(2k+1)\pi}{2n+2}$使$\max\abs{\prod(x - x_i)}$达到最小（等于$2^{-n}$），并对光滑函数给出快速收敛的插值多项式。
- 三次样条是具有连续二阶导数的分段三次多项式；自然样条通过求解一个三对角、对角占优的方程组得到，它（在远离端点处）像$h^4$那样收敛，且不会振荡。
:::

求经过$(-1, 2)$、$(0, 1)$、$(1, 2)$的次数至多为$2$的多项式，并计算它在$x = 2$处的值。
::: solution
由对称性，这条抛物线是偶函数：$p(x) = ax^2 + 1$，且$a + 1 = 2$，所以$p(x) = x^2 + 1$（由唯一性，这就是**那个**插值多项式）。于是$p(2) = 5$。
:::

::: exercise 三次函数的差商 {level=1 check="3"}
对$f(x) = x^3$计算$f[0, 1, 2]$。
::: solution
$f(0) = 0$，$f(1) = 1$，$f(2) = 8$。一阶差商：$f[0,1] = 1$，$f[1,2] = 7$。二阶差商：$f[0,1,2] = \frac{7 - 1}{2 - 0} = 3$。（一般地，对$f(x) = x^3$有$f[a, b, c] = a + b + c$；并且在$\xi = 1$处$\frac{f''(\xi)}{2} = 3\xi = 3$。）
:::

::: exercise 正弦函数表的线性插值 {level=1 check="1/800"}
对$\sin x$在相距$0.1$的节点之间作线性插值，[[#cor-interp-bound]]给出的误差界是多少？
::: solution
$M_2 = \max\abs{\sin''} \le 1$，所以误差至多为$\frac{h^2}{8} = \frac{0.01}{8} = \frac{1}{800} = 1.25\times10^{-3}$。
:::

::: exercise 指数函数的二次插值 {level=2}
设$p_2$是$e^x$在$0$、$\frac12$和$1$上的插值多项式。用[[#eq-interp-error]]给出$\abs{e^{0.25} - p_2(0.25)}$的上界，并与实际误差$0.0123$比较。
::: solution
在$[0, 1]$上$f''' = e^x \le e$，且$\omega_3(0.25) = 0.25\times(-0.25)\times(-0.75) = 0.046\,875$。所以$\abs{e^{0.25} - p_2(0.25)} \le \frac{e}{6}\times0.046\,875 \approx 0.0212$。实际误差$0.0123$对应于$f'''(\xi) = e^\xi \approx 1.57$，即$\xi \approx 0.45$，正如定理所说，它位于$(0, 1)$内。
:::

::: exercise 三个切比雪夫节点 {level=2 check="1/4"}
求$[-1, 1]$上的三个切比雪夫节点，以及对这组节点$\abs{\omega_3}$的最大值。并与等距节点$-1, 0, 1$比较。
::: solution
$T_3(x) = 4x^3 - 3x$的零点为$0$和$\pm\frac{\sqrt3}{2}$。于是$\omega_3 = x\left(x^2 - \frac34\right) = \frac14T_3$，它在$[-1, 1]$上绝对值的最大值为$\frac14$。对$-1, 0, 1$：$\omega_3 = x^3 - x$，其绝对值在$x = \pm\frac{1}{\sqrt3}$处取最大值$\frac{2}{3\sqrt3} \approx 0.385$。切比雪夫节点使误差界减小了一个约为$1.54$的因子；这种改进随次数呈指数增长。
:::

$s\left(\frac12\right) = -\frac{1}{16} + \frac34 = \frac{11}{16} = 0.6875$。抛物线$x(2-x)$在$x = \frac12$处的值为$\frac34$。

::: exercise 多项式的再现 {level=2}
证明：对互不相同的节点$x_0, \dots, x_n$（$n \ge 1$），对所有$x$有$\sum_{j=0}^nx_j\ell_j(x) = x$；更一般地，对$0 \le k \le n$有$\sum_jx_j^k\ell_j(x) = x^k$。当$k = n + 1$时会出现什么问题？
::: solution
$\sum_jx_j^k\ell_j(x)$是$f(x) = x^k$在这些节点上的插值多项式。当$k \le n$时，$f \in \mathcal P_n$对自身插值，所以由唯一性，插值多项式就是$x^k$。当$k = n + 1$时，[[#eq-interp-error]]给出$x^{n+1} - p_n(x) = \frac{(n+1)!}{(n+1)!}\omega_{n+1}(x)$，所以$\sum_jx_j^{n+1}\ell_j(x) = x^{n+1} - \omega_{n+1}(x)$，它除了在节点处以外都与$x^{n+1}$不同。
:::
:::

::: exercise 差商是乘了比例因子的导数 {level=3 #exr-dd-derivative}
设$f \in C^n[a, b]$，$x_0, \dots, x_n$是$[a, b]$中互不相同的点。证明：在包含这些节点的最小区间中存在某个$\xi$，使得$f[x_0, \dots, x_n] = \frac{f^{(n)}(\xi)}{n!}$。
::: hint
设$p_{n-1}$是$f$在$x_0, \dots, x_{n-1}$上的插值多项式，用牛顿形式写出$p_n(x_n) - p_{n-1}(x_n)$。
:::
::: solution
由[[#thm-newton-form]]，$p_n(x) = p_{n-1}(x) + f[x_0, \dots, x_n]\,\omega_n(x)$，其中$\omega_n(x) = \prod_{j<n}(x - x_j)$。在$x = x_n$处，$p_n(x_n) = f(x_n)$，所以$f(x_n) - p_{n-1}(x_n) = f[x_0, \dots, x_n]\,\omega_n(x_n)$。另一方面，把$n$换成$n - 1$应用[[#thm-interp-error]]（在包含这些节点的最小区间上），得$f(x_n) - p_{n-1}(x_n) = \frac{f^{(n)}(\xi)}{n!}\omega_n(x_n)$。由于$\omega_n(x_n) \ne 0$，比较两式即得$f[x_0, \dots, x_n] = \frac{f^{(n)}(\xi)}{n!}$。
:::
:::

::: exercise 样条使曲率最小 {level=3 #exr-min-curvature}
设$s$是在节点$a = x_0 < \cdots < x_n = b$上对数据插值的自然三次样条，$g$是任一二阶连续可导、且对所有$i$满足$g(x_i) = s(x_i)$的函数。证明$\int_a^b(s'')^2\,dx \le \int_a^b(g'')^2\,dx$。
::: hint
写$g = s + e$，展开$\int(g'')^2$，并在每个子区间上分部积分，证明$\int_a^b s''e''\,dx = 0$。
:::
::: solution
令$e = g - s$，则$\int(g'')^2 = \int(s'')^2 + 2\int s''e'' + \int(e'')^2$，所以只需证明$\int_a^bs''e'' = 0$。分部积分，得

$$
\int_a^bs''e''\,dx = \Bigl[s''e'\Bigr]_a^b - \sum_{i=1}^n\int_{x_{i-1}}^{x_i}s'''e'\,dx .
$$

由于$s''(a) = s''(b) = 0$，边界项为零。在每个子区间上$s$是三次多项式，所以$s''' = c_i$在那里是常数，而$\int_{x_{i-1}}^{x_i}c_ie'\,dx = c_i\bigl(e(x_i) - e(x_{i-1})\bigr) = 0$，因为$e$在每个节点处都为零。（由于$s''e'$连续，在$[a, b]$上的分部积分是成立的；我们只把第二个积分拆开。）因此$\int(g'')^2 = \int(s'')^2 + \int(e'')^2 \ge \int(s'')^2$，等号仅当$e'' = 0$即$e$为线性函数时成立，而此时由于$e$在两个或更多节点处为零，$e = 0$。
:::

::: exercise 切比雪夫多项式 {level=3}
利用$T_n(\cos\theta) = \cos(n\theta)$证明递推关系$T_{n+1} = 2xT_n - T_{n-1}$，由此推出当$n \ge 1$时$T_n$是首项系数为$2^{n-1}$的$n$次多项式，并证明它的零点为$\cos\frac{(2k+1)\pi}{2n}$，$k = 0, \dots, n - 1$。
::: solution
由和角公式得$\cos((n+1)\theta) + \cos((n-1)\theta) = 2\cos\theta\cos(n\theta)$。令$x = \cos\theta \in [-1, 1]$，上式即$T_{n+1}(x) + T_{n-1}(x) = 2xT_n(x)$。由于$T_0 = 1$，$T_1 = x$，用归纳法可知$T_n$是$n$次多项式；若它的首项系数为$2^{n-1}$，则$2xT_n$的首项系数为$2^n$，减去$T_{n-1}$（次数为$n - 1$）不改变首项系数，所以$T_{n+1}$的首项系数为$2^n$。归纳的起点是$T_1 = x$，其首项系数为$2^0 = 1$。最后，$T_n(\cos\theta) = 0$当且仅当$n\theta = \frac\pi2 + k\pi$；角$\theta_k = \frac{(2k+1)\pi}{2n}$（$k = 0, \dots, n-1$）位于$(0, \pi)$内，给出$n$个不同的值$\cos\theta_k$；而$n$次多项式不可能再有其他零点。
:::
