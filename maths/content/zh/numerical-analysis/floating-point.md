在 Python 中输入`0.1 + 0.2 == 0.3`，得到的回答是`False`：计算机给出的`0.1 + 0.2`是`0.30000000000000004`。把十个`0.1`相加，得到的是`0.9999999999999999`。这些都不是程序错误。计算机用固定位数的二进制数字存储实数，因此它处理的几乎每一个数——包括$0.1$——都略有偏差，而几乎每一次算术运算都会再添上一点微小的误差。

这些误差通常在$10^{-16}$左右，无关紧要。但有时它们关系重大。1991年，部署在达兰（Dhahran）的一个“爱国者”导弹连未能拦截一枚来袭的“飞毛腿”导弹，造成28名士兵死亡，原因是系统以十分之一秒为单位计时，而$0.1$没有精确的二进制表示：连续运行约$100$小时后，时钟的累积误差约为三分之一秒，足以使雷达搜索错误的位置。数值分析的起点，就是充分理解这些误差，以便预测它们何时无害、何时致命。

本章解释实数在浮点运算中如何表示，证明舍入误差的基本界，并引入贯穿本课程其余部分的两个概念：问题的**条件**（问题的答案对数据的微小变化有多敏感）和算法的**稳定性**（算法引入的误差是否超出了问题本身应有的程度）。

## 浮点数

科学记数法把数写成$6.022\times10^{23}$或$-1.6\times10^{-19}$的形式：固定位数的有效数字乘以基数的一个幂。浮点数系以固定的精度做同样的事。

::: definition 浮点数系 {#def-float}
基数为$\beta \ge 2$、精度为$p \ge 1$、指数范围为$e_{\min} \le e \le e_{\max}$的**浮点数系**由$0$和如下形式的数组成：

$$
x = \pm\,(d_0.d_1d_2\ldots d_{p-1})_\beta\times\beta^{e} = \pm\left(d_0 + \frac{d_1}{\beta} + \cdots + \frac{d_{p-1}}{\beta^{p-1}}\right)\beta^e ,
$$

其中各位数字$d_i \in \set{0, 1, \dots, \beta - 1}$，$d_0 \ne 0$（称这样的数是**规格化**的），且$e_{\min} \le e \le e_{\max}$。满足$1 \le m < \beta$的数$m = (d_0.d_1\ldots d_{p-1})_\beta$称为**尾数**，$e$称为**指数**（阶码）。
:::

几乎所有计算机都采用 IEEE 754 标准的二进制格式。在基数$2$下，规格化数的首位数字总是$1$，因此无需存储。

| 格式 | 位数 | 精度$p$ | 指数范围 | 单位舍入误差$u = 2^{-p}$ | 最大数 |
|---|---|---|---|---|---|
| 单精度 | $32$ | $24$ | $-126 \le e \le 127$ | $5.96\times10^{-8}$ | $3.40\times10^{38}$ |
| 双精度 | $64$ | $53$ | $-1022 \le e \le 1023$ | $1.11\times10^{-16}$ | $1.80\times10^{308}$ |

因此，双精度（Python、MATLAB、Julia 和大多数科学计算软件的默认精度）大约有$16$位有效十进制数字。该标准还定义了**次正规数**（在最小指数处取$d_0 = 0$），用以填补$0$与最小规格化数$2^{-1022} \approx 2.2\times10^{-308}$之间的空隙；此外还定义了特殊值$\pm\infty$和`NaN`（“非数”，即$0/0$或$\sqrt{-1}$的结果）。

::: example 一个微型浮点数系 {#ex-toy}
列出$p = 3$、$e_{\min} = -1$、$e_{\max} = 2$的二进制浮点数系中的全部正数。
::: solution
尾数为$(1.00)_2 = 1$、$(1.01)_2 = 1.25$、$(1.10)_2 = 1.5$和$(1.11)_2 = 1.75$。对$e = -1, 0, 1, 2$分别乘以$2^e$，得到：

| 指数 | 数 | 间距 |
|---|---|---|
| $e = -1$ | $0.5,\ 0.625,\ 0.75,\ 0.875$ | $0.125$ |
| $e = 0$ | $1,\ 1.25,\ 1.5,\ 1.75$ | $0.25$ |
| $e = 1$ | $2,\ 2.5,\ 3,\ 3.5$ | $0.5$ |
| $e = 2$ | $4,\ 5,\ 6,\ 7$ | $1$ |

总共只有$16$个正数。它们的分布并不均匀：每经过$2$的一个幂，间距就加倍，但**相对**间距（间距除以数的大小）始终介于$\frac18$与$\frac14$之间。大于$7$的数发生上溢，小于$0.5$的正数发生下溢（变为次正规数或$0$）。
:::
:::

::: widget floatline

emax: 2
value: 2.3
caption: [[#ex-toy]]中的微型浮点数系在数轴上的分布。值$2.3$位于相邻的两个数$2$与$2.5$之间，舍入为$2.5$，相对误差为$0.087 < u = 2^{-3}$。移动该值并改变精度$p$：每多一个二进制位，每个间距都减半，而最大的**相对**舍入误差始终不超过$u = 2^{-p}$。
:::

[[#ex-toy]]中的规律具有一般性。在$\beta^e$与$\beta^{e+1}$之间，浮点数是等距分布的，间距为$\beta^{e - p + 1}$。特别地，$1$与下一个更大的浮点数之间的间距为

$$
\eps_M = \beta^{1-p} ,
$$

称为**机器精度**（机器ε）：在双精度下它等于$2^{-52} \approx 2.22\times10^{-16}$。它的一半是**单位舍入误差**$u = \frac12\beta^{1-p}$，对双精度数而言为$2^{-53} \approx 1.11\times10^{-16}$。

像$0.1$这样的数具有无限的二进制展开式$0.1 = (0.000110011001100\ldots)_2$，所以它不是浮点数。与它最接近的双精度数是

$$
\operatorname{fl}(0.1) = 0.1000000000000000055511151231257827021181583404541015625 ,
$$

这就解释了本章开头那些令人意外的结果：$\operatorname{fl}(0.1)$、$\operatorname{fl}(0.2)$和$\operatorname{fl}(0.3)$中的误差并不能恰好相互抵消。

## 舍入与标准模型

::: definition 舍入 {#def-rounding}
对浮点数系范围内的实数$x$，用$\operatorname{fl}(x)$表示与$x$最接近的浮点数（**就近舍入**；若有两个这样的数，IEEE 运算选取末位数字为偶数的那一个）。近似值$\hat x$相对于$x$的**绝对误差**为$\abs{\hat x - x}$；当$x \ne 0$时，其**相对误差**为$\abs{\hat x - x}/\abs x$。
:::

::: theorem 舍入的相对误差 {#thm-rounding}
若$x$位于单位舍入误差为$u = \frac12\beta^{1-p}$的浮点数系的范围内（即$\beta^{e_{\min}} \le \abs x \le$最大浮点数），则

$$
\operatorname{fl}(x) = x(1 + \delta) \qquad\text{对某个 } \abs\delta \le u .
$$ {#eq-fl}
:::

::: proof
由对称性，不妨设$x > 0$。取指数$e$使得$\beta^e \le x < \beta^{e+1}$。在这个范围内，浮点数为$m\beta^e$，其中$m = (d_0.d_1\ldots d_{p-1})_\beta$，所以相邻两数相差$\beta^{e - p + 1}$，而$x$位于其中某两个数之间（这里把$\beta^{e+1}$本身也算在内，它也是浮点数；除非$x$靠近上溢阈值，那时由最大数充当这一角色）。最近的那个数与$x$的距离至多为间距的一半：

$$
\abs{\operatorname{fl}(x) - x} \le \tfrac12\beta^{e - p + 1}.
$$

除以$x \ge \beta^e$，得$\dfrac{\abs{\operatorname{fl}(x) - x}}{x} \le \tfrac12\beta^{1-p} = u$。令$\delta = \frac{\operatorname{fl}(x) - x}{x}$，即得[[#eq-fl]]。
:::

这个定理表明，在浮点运算中一致地小的是**相对**误差，而不是绝对误差。IEEE 标准更进一步，要求基本运算是**正确舍入**的：$x + y$、$x - y$、$x\times y$、$x/y$或$\sqrt x$的计算结果，就是精确结果舍入到最近的浮点数。结合[[#thm-rounding]]，就得到一切舍入误差分析赖以建立的模型。

::: axiom 浮点运算的标准模型 {#ax-standard-model}
对浮点数$x$、$y$以及$\circ \in \set{+, -, \times, /}$，若不发生上溢或下溢，则

$$
\operatorname{fl}(x \circ y) = (x\circ y)(1 + \delta), \qquad \abs\delta \le u ,
$$ {#eq-standard-model}

类似地，$\operatorname{fl}(\sqrt x) = \sqrt x\,(1 + \delta)$，其中$\abs\delta \le u$。
:::

因此，**单独**一次运算几乎是完美的。麻烦来自长串的运算，以及那些会放大已有误差的运算。

::: warning 浮点运算不是实数运算
许多代数运算律不再成立。加法不满足结合律：在双精度下$(1 + 10^{16}) - 10^{16} = 0$，因为$1 + 10^{16}$被舍入为$10^{16}$（$10^{16}$附近双精度数的间距为$2$），而$1 + (10^{16} - 10^{16}) = 1$。对计算结果作相等性判断是靠不住的：应当检验$\abs{a - b} \le \text{tol}\cdot\abs b$，而不是`a == b`。此外，$\eps_M$**并不是**最小的正数——最小的正数约为$5\times10^{-324}$（一个次正规数）；$\eps_M$是$1$附近数的相对间距。
:::

::: quiz
在双精度下，关于机器精度$\eps_M = 2^{-52} \approx 2.2\times10^{-16}$的下列说法中，哪一个是正确的？
- [ ] 它是最小的正浮点数。
- [x] 它是$1$到下一个更大的浮点数的距离。
- [ ] 每个计算结果的绝对误差都不超过$\eps_M$。
- [ ] 小于$\eps_M$的数被舍入为$0$。
::: solution
$\eps_M$是紧挨在$1$上方的间距。在$x$附近，间距大约为$\eps_M\abs x$，所以绝对误差随数的大小按比例变化：在$10^{16}$附近间距为$2$，在$10^{-16}$附近间距约为$10^{-32}$。远小于$\eps_M$的数，直到约$10^{-308}$（若计入次正规数，则直到$5\times10^{-324}$），都能很好地表示。
:::
:::

## 抵消

两个几乎相等的数相减，是小误差变成大误差最常见的途径。

::: theorem 减法中的误差放大 {#thm-cancellation}
设$\hat x = x(1 + \delta_1)$，$\hat y = y(1 + \delta_2)$，其中$\abs{\delta_1}, \abs{\delta_2} \le \delta$，且$x \ne y$。则

$$
\frac{\abs{(\hat x - \hat y) - (x - y)}}{\abs{x - y}} \le \frac{\abs x + \abs y}{\abs{x - y}}\,\delta .
$$ {#eq-cancellation}
:::

::: proof
$(\hat x - \hat y) - (x - y) = x\delta_1 - y\delta_2$，其绝对值至多为$\abs x\abs{\delta_1} + \abs y\abs{\delta_2} \le (\abs x + \abs y)\delta$。再除以$\abs{x - y}$即可。
:::

当$x \approx y$时，因子$\frac{\abs x + \abs y}{\abs{x-y}}$非常大：前面的若干位数字相互抵消，剩下的部分主要由末尾几位数字中的误差构成。这就是**灾难性抵消**。注意减法本身是无害的——它通常甚至是精确的（[[#exr-sterbenz]]）；它只是把先前产生的误差**暴露**出来。

::: example 一个简单公式中的抵消 {#ex-cos}
在双精度下，对较小的$x$计算$f(x) = \dfrac{1 - \cos x}{x^2}$。其真值趋于$\frac12$。
::: solution
下面列出按原公式计算的值，以及按等价公式$g(x) = \dfrac{2\sin^2(x/2)}{x^2}$（利用$1 - \cos x = 2\sin^2\frac x2$）计算的值：

| $x$ | $10^{-2}$ | $10^{-4}$ | $10^{-5}$ | $10^{-6}$ | $10^{-7}$ | $10^{-8}$ |
|---|---|---|---|---|---|---|
| $f(x)$（按原公式） | $0.499\,995\,833\,347$ | $0.499\,999\,996\,96$ | $0.500\,000\,041$ | $0.500\,044$ | $0.499\,600$ | $0$ |
| $g(x)$ | $0.499\,995\,833\,347$ | $0.499\,999\,999\,58$ | $0.499\,999\,999\,996$ | $0.500\,000\,000\,000$ | $0.500\,000\,000\,000$ | $0.5$ |

当$x = 10^{-8}$时，$\cos x = 1 - 5\times10^{-17}$恰好被舍入为$1$，分子变成$0$，**全部**数字都丢失了。当$x = 10^{-6}$时，$\operatorname{fl}(\cos x)$带有至多约$10^{-16}$的绝对误差，而$1 - \cos x \approx 5\times10^{-13}$：由[[#eq-cancellation]]，相对误差可达$\frac{2}{5\times10^{-13}}\times 10^{-16} \approx 4\times10^{-4}$，实际上也确实只有四位数字是正确的。改写后的公式不涉及几乎相等的量相减，对每个$x$都能达到满精度。
:::
:::

::: example 二次方程求根公式 {#ex-quadratic}
在双精度下求$x^2 - 10^8x + 1 = 0$的根。
::: solution
两根为$x_{1,2} = \frac{10^8 \pm\sqrt{10^{16} - 4}}{2}$，近似为$10^8$和$10^{-8}$。用加号计算$x_1$没有问题。但较小的根$x_2 = \frac{10^8 - \sqrt{10^{16} - 4}}{2}$要把两个约有$16$位数字相同的数相减，计算机返回的结果是$7.450\,580\,596\,923\,828\times10^{-9}$——连第一位数字都是错的（真值为$1.000\ldots\times10^{-8}$）。

补救的办法是避免这次减法。由于$x_1x_2 = c/a = 1$（韦达（Vieta）定理），可以计算$x_2 = \frac{c}{a x_1}$，或者等价地用$x_2 = \frac{2c}{-b + \sqrt{b^2 - 4ac}}$，后者是两个正数相加。这样得到$1.000\,000\,000\,000\,000\times10^{-8}$，所显示的各位数字全部正确。稳健的二次方程求解程序用能避免抵消的符号计算绝对值较大的根，再由两根之积求出另一个根。
:::
:::

```python
import math

def quadratic_roots(a, b, c):
    """a x^2 + b x + c = 0 的实根（假定 b*b >= 4ac），避免抵消。"""
    d = math.sqrt(b*b - 4*a*c)
    q = -0.5 * (b + math.copysign(d, b))   # b 与 copysign(d, b) 同号
    return q / a, c / q
```

## 截断误差与舍入误差

大多数数值方法用有限的计算代替极限，因此即使在精确运算下也会产生**截断误差**。在浮点运算中，舍入误差又叠加在它上面，而这两种误差往往朝相反的方向起作用。求导数就是一个经典的例子。

::: theorem 向前差商的误差 {#thm-forward-difference}
设$f$在$x$附近二阶连续可导，且在那里$\abs{f''} \le M$；又设函数的计算值满足$\hat f(t) = f(t)(1 + \delta_t)$，其中$\abs{\delta_t} \le u$，并且在$x$附近$\abs{f} \le F$。那么，忽略减法和除法本身的（小得多的）误差，有

$$
\abs{\frac{\hat f(x + h) - \hat f(x)}{h} - f'(x)} \le \frac{Mh}{2} + \frac{2uF}{h} .
$$ {#eq-fd-error}

当$h_* = 2\sqrt{uF/M}$时右端最小，此时它等于$2\sqrt{uFM}$。
:::

::: proof
由泰勒定理（[[calculus-2/taylor-series#thm-taylor]]），$f(x + h) = f(x) + hf'(x) + \frac{h^2}{2}f''(\xi)$，其中$\xi$是介于$x$与$x + h$之间的某个数，所以精确的差商满足

$$
\abs{\frac{f(x+h) - f(x)}{h} - f'(x)} = \frac h2\abs{f''(\xi)} \le \frac{Mh}{2}.
$$

舍入误差使分子改变$f(x+h)\delta_{x+h} - f(x)\delta_x$，其绝对值至多为$2uF$，因而使差商的改变至多为$\frac{2uF}{h}$。由三角不等式即得[[#eq-fd-error]]。最后，$\phi(h) = \frac{Mh}{2} + \frac{2uF}{h}$的导数为$\phi'(h) = \frac M2 - \frac{2uF}{h^2}$，它在$h_* = 2\sqrt{uF/M}$处为零，此时$\phi(h_*) = \sqrt{uFM} + \sqrt{uFM}$。
:::

对$f = \exp$在$x = 1$处，有$M \approx F \approx e$，所以$h_* \approx 2\sqrt u \approx 2\times10^{-8}$，可达到的最佳误差约为$2e\sqrt u \approx 6\times10^{-8}$——只有可用的十六位数字中的一半。实际计算得到的误差如下：

| $h$ | $10^{-1}$ | $10^{-2}$ | $10^{-4}$ | $10^{-6}$ | $10^{-8}$ | $10^{-10}$ | $10^{-12}$ | $10^{-14}$ | $10^{-16}$ |
|---|---|---|---|---|---|---|---|---|---|
| 误差 | $1.4\times10^{-1}$ | $1.4\times10^{-2}$ | $1.4\times10^{-4}$ | $1.4\times10^{-6}$ | $6.6\times10^{-9}$ | $1.5\times10^{-6}$ | $4.3\times10^{-4}$ | $9.3\times10^{-3}$ | $2.7$ |

当$h$较大时，误差$\approx\frac{e}{2}h$，即截断误差；当$h$较小时，由于舍入，误差像$\frac1h$那样增长；当$h = 10^{-16}$时，计算机得到$1 + h = 1$，于是返回导数值$0$。（$h = 10^{-8}$处的误差碰巧比误差界小。）

## 问题的条件

有些问题无论我们计算得多么巧妙，都对数据很敏感。如果输入$x$只知道到相对精度$\delta$（因为它是测量得到的，或者仅仅是因为它以浮点形式存储），那么$f(x)$能有多精确？

::: definition 条件数 {#def-condition}
设$f$在$x$处可导，且$x \ne 0$，$f(x) \ne 0$。$f$在$x$处的**相对条件数**为

$$
\kappa_f(x) = \abs{\frac{x\,f'(x)}{f(x)}} .
$$

若$\kappa_f(x)$大小适中，则称问题在$x$处是**良态**的；若$\kappa_f(x)$很大，则称问题在$x$处是**病态**的。
:::

::: theorem 条件数支配误差的传播 {#thm-conditioning}
设$f$在$x$附近二阶连续可导。若$\hat x = x(1 + \delta)$，则

$$
\frac{f(\hat x) - f(x)}{f(x)} = \frac{x f'(x)}{f(x)}\,\delta + O(\delta^2) , \qquad\text{从而}\qquad \frac{\abs{f(\hat x) - f(x)}}{\abs{f(x)}} \le \kappa_f(x)\abs\delta + O(\delta^2).
$$
:::

::: proof
由泰勒定理，$f(\hat x) = f(x + x\delta) = f(x) + f'(x)\,x\delta + \frac12f''(\xi)\,x^2\delta^2$，其中$\xi$介于$x$与$\hat x$之间。两边除以$f(x)$；由于$f''$在$x$附近有界，最后一项为$O(\delta^2)$。
:::

所以，条件数就是数据中的相对误差（在一阶近似下）被放大的倍数。由于双精度数据本身已带有大小为$u \approx 10^{-16}$的相对误差，条件数为$10^k$意味着我们预计会损失大约$k$位数字，**无论使用什么算法**。

::: example 条件数 {#ex-condition}
计算下列函数的条件数：(a) $f(x) = \sqrt x$；(b) $f(x) = x - 1$；(c) $f(x) = \ln x$；(d) $f(x) = e^x$。
::: solution
(a) $\kappa = \abs{\frac{x\cdot\frac{1}{2\sqrt x}}{\sqrt x}} = \frac12$：开平方使相对误差减半，条件极好。

(b) $\kappa = \abs{\frac{x}{x - 1}}$，它在$x = 1$附近非常大：几乎相等的数相减是病态的，这与[[#thm-cancellation]]一致。在$x = 1.000\,001$处，$\kappa \approx 10^6$。

(c) $\kappa = \abs{\frac{x\cdot\frac1x}{\ln x}} = \frac{1}{\abs{\ln x}}$，它在$x = 1$附近很大，因为那里$\ln x$接近$0$。（这就是函数库提供`log1p(t)` $= \ln(1 + t)$的原因：它直接以小量$t$本身作为输入。）

(d) $\kappa = \abs x$：对大小适中的$x$，指数函数是良态的；但在$x = 700$处，$x$中$10^{-16}$的相对误差会变成$e^x$中约$7\times10^{-14}$的相对误差。
:::
:::

::: quiz
$f(x) = \tan x$的相对条件数为$\kappa(x) = \abs{\frac{x}{\sin x\cos x}}$。计算$\tan x$在何处是病态的？
- [ ] 在$x = 0$附近
- [x] 在$x = \frac\pi2$附近
- [ ] 在$x = \frac\pi4$附近
- [ ] 任何地方都不是；$\tan$是标准函数
::: solution
当$x\to0$时，$\kappa \to 1$（因为$\frac{x}{\sin x}\to1$且$\cos x \to 1$），所以$x$较小时没有问题。在$\frac\pi2$附近，$\cos x \to 0$，$\kappa \to\infty$：$x$的微小相对变化会使$\tan x$发生巨大的变化，因为那里的图像几乎是竖直的。在$\frac\pi4$处，$\kappa = \frac{\pi/4}{1/2} \approx 1.57$。
:::
:::

## 算法的稳定性

条件是**问题**的性质；稳定性则是我们用来求解问题的**算法**的性质。[[#ex-quadratic]]中的求根公式和[[#ex-cos]]中$f(x)$的公式，都是求解良态问题的不稳定方法。

::: definition 向前误差与向后误差；稳定性 {#def-stability}
设某算法算出$\hat y$作为$y = f(x)$的近似值。**向前误差**是$\abs{\hat y - y}$（或其相对形式）。**向后误差**是使$\hat y = f(x + \Delta x)$成立的最小的$\abs{\Delta x}/\abs x$，即能使计算结果恰好成为精确答案的数据相对改变量。若一个算法的向后误差总是$u$的量级，则称该算法是**向后稳定**的。
:::

向后稳定性是对算法所能提出的最高要求：它表明计算结果是一个受到轻微扰动的问题的精确答案；既然数据本身就经过了舍入，这已是我们所能期望的全部。由[[#thm-conditioning]]，

$$
\text{相对向前误差} \lesssim \kappa_f(x)\times\text{向后误差} ,
$$

所以，把向后稳定的算法用于良态问题会得到精确的答案；而对于病态问题，即使算法完美，也可能得到不精确的答案。

::: quiz
把一个向后稳定的算法（向后误差约为$10^{-16}$）用于条件数为$\kappa = 10^{10}$的问题。应当预期多大的相对向前误差？
- [ ] 约为$10^{-16}$，因为算法是稳定的
- [x] 可达约$10^{-6}$
- [ ] 约为$10^{-26}$
- [ ] 无法作出任何判断
::: solution
向前误差$\lesssim \kappa\times$向后误差$= 10^{10}\times10^{-16} = 10^{-6}$：大约还剩六位正确数字。稳定性保证算法不会在数据本身的舍入所带来的误差之外再增加误差；但它无法消除问题本身的敏感性。
:::
:::

### 求和

求和是误差分析不平凡的最简单的算法。我们需要一个关于累积因子$1 + \delta$的引理。

::: lemma 舍入因子之积 {#lem-gamma}
若对$i = 1, \dots, n$有$\abs{\delta_i} \le u$，且$nu < 1$，则

$$
\prod_{i=1}^n(1 + \delta_i) = 1 + \theta_n, \qquad \abs{\theta_n} \le \gamma_n := \frac{nu}{1 - nu} .
$$
:::

::: proof
把乘积展开，得$\abs{\prod(1 + \delta_i) - 1} \le \prod(1 + \abs{\delta_i}) - 1 \le (1 + u)^n - 1$（左边展开式的每一项都以右边相应的项为界）。由于$1 + u \le e^u$，且当$0 \le t < 1$时$e^{t} \le \frac{1}{1 - t}$（它等价于$1 - t \le e^{-t}$），我们得到$(1 + u)^n \le e^{nu} \le \frac{1}{1 - nu}$，所以$\abs{\theta_n} \le \frac{1}{1 - nu} - 1 = \gamma_n$。
:::

例如，当$n = 10^6$、$u = 2^{-53}$时，$\gamma_n \approx 1.1\times10^{-10}$；在一阶近似下$\gamma_n \approx nu$。

::: theorem 递推求和的误差 {#thm-summation}
设$\hat s$是按$((x_1 + x_2) + x_3) + \cdots + x_n$的顺序计算出的$x_1, \dots, x_n$的浮点和。则

$$
\hat s = \sum_{i=1}^n x_i(1 + \theta^{(i)}), \quad \abs{\theta^{(i)}} \le \gamma_{n-1}, \qquad\text{因此}\qquad \abs{\hat s - s} \le \gamma_{n-1}\sum_{i=1}^n\abs{x_i} .
$$
:::

::: proof
令$\hat s_1 = x_1$，$\hat s_k = \operatorname{fl}(\hat s_{k-1} + x_k) = (\hat s_{k-1} + x_k)(1 + \delta_k)$，由[[#eq-standard-model]]，$\abs{\delta_k} \le u$。把递推逐层展开，得

$$
\hat s_n = x_1\prod_{k=2}^n(1 + \delta_k) + x_2\prod_{k=2}^{n}(1 + \delta_k) + x_3\prod_{k=3}^n(1 + \delta_k) + \cdots + x_n(1 + \delta_n).
$$

每个$x_i$至多乘上$n - 1$个因子$1 + \delta_k$，所以由[[#lem-gamma]]，它的总因子为$1 + \theta^{(i)}$，其中$\abs{\theta^{(i)}} \le \gamma_{n-1}$（因子个数更少的乘积满足更小的界）。减去$s = \sum x_i$并利用三角不等式，即得$\abs{\hat s - s}$的界。
:::

第一个结论表明递推求和是向后稳定的：计算出的和是受到轻微扰动的各项的精确和。向前误差界则表明它何时是精确的：若所有$x_i$同号，则$\sum\abs{x_i} = \abs s$，相对误差至多为$\gamma_{n-1} \approx nu$；若存在抵消，$\sum\abs{x_i}$可能比$\abs s$大得多。证明还表明，最先加入的项受舍入的影响最大，这提示我们应当先加小的项。在**单**精度下计算$\sum_{k=1}^{10^6}\frac1{k^2}$，从$k = 1$往上加得到$1.644\,725\,3$，从$k = 10^6$往下加得到$1.644\,933\,0$；真值为$1.644\,933\,07$。按顺序往上加时，一旦部分和接近$1.64$，小于约$10^{-8}$的项就干脆被舍入掉了。

卡汉（Kahan）提出的一个巧妙算法把每次加法的舍入误差保存下来，再把它补回去。

```python
def kahan_sum(xs):
    """补偿求和：误差界约为 2u * sum|x_i|，与 n 无关。"""
    s = 0.0          # 累加和
    c = 0.0          # 对丢失的低位的累积补偿
    for x in xs:
        y = x - c    # 用上一步的误差修正下一项
        t = s + y    # 大数 + 小数：y 的低位数字丢失……
        c = (t - s) - y   # ……并在这里找回（代数上 c = 0）
        s = t
    return s
```

用普通的循环把$0.1$累加一千万次，得到$999\,999.999\,838\,975\,4$；`kahan_sum`给出$1\,000\,000.0$，Python 中精确舍入的`math.fsum`也给出同样的结果。

### 一个不稳定的递推

::: example 一个会“爆炸”的递推 {#ex-recurrence}
积分$I_n = \int_0^1 x^ne^{x-1}\,dx$满足$I_0 = 1 - e^{-1}$，并且由分部积分法得$I_n = 1 - nI_{n-1}$。计算$I_{20}$。
::: solution
由于在$(0, 1]$上$0 < x^ne^{x-1} \le x^n$，真值满足$0 < I_n < \frac{1}{n+1}$；它们缓慢地递减到$0$。在双精度下向前运行这一递推，得到：

| $n$ | $5$ | $10$ | $15$ | $17$ | $18$ | $20$ | $25$ |
|---|---|---|---|---|---|---|---|
| 向前递推 | $0.145\,533$ | $0.083\,877\,07$ | $0.059\,034$ | $0.057\,19$ | $-0.029\,45$ | $-30.19$ | $1.93\times10^{8}$ |
| 真值 | $0.145\,533$ | $0.083\,877\,10$ | $0.059\,018$ | $0.052\,77$ | $0.050\,12$ | $0.045\,54$ | $0.037\,09$ |

$n = 18$处的负值是不可能出现的。原因在于：$I_0$在存储时带有约$10^{-17}$的误差$\eps_0$，而每一步都把当前的误差乘以$-n$，所以$I_n$的误差为$(-1)^n n!\,\eps_0$；而$20! \approx 2.4\times10^{18}$。**问题**本身没有毛病；是**算法**把误差放大了$n!$倍。

**向后**运行这一递推，即$I_{n-1} = \frac{1 - I_n}{n}$，每一步都把误差除以$n$。从粗略的猜测值$I_{40} = 0$（误差小于$\frac{1}{41}$）出发向下递推，到达$n = 20$时，误差已被除以$40\cdot39\cdots21 \approx 3.4\times10^{29}$，向后递推给出$I_{20} = 0.045\,544\,884\,075\,818$，十六位数字全部正确。
:::
:::

::: warning 稳定的算法挽救不了病态问题
稳定性与条件是相互独立的。把$1 - \cos x$改写为$2\sin^2\frac x2$之所以奏效，是因为“由$x$计算$1 - \cos x$”这个**问题**是良态的，只是算法不好。但如果输入就是已舍入到双精度的$c = \cos x$本身，那么当$c \approx 1$时计算$1 - c$是病态的，任何重新排列都无法找回丢失的数字。在指责算法之前，先计算问题的条件数。
:::

::: application 浮点为何胜过定点
早期的计算机常常采用**定点**运算，即二进制小数点后的位数固定。这使**绝对**误差保持一致，适用于金额计算，却不适用于科学计算——在科学中，量的大小可以从$10^{-30}$ kg 一直到$10^{30}$ kg。浮点运算在超过$600$个数量级的范围内使**相对**误差保持一致（[[#thm-rounding]]），这正是它胜出的原因。本章开头提到的“爱国者”导弹事故就是一个定点误差：$0.1$被截断为$24$位，每个计时周期产生约$9.5\times10^{-8}$秒的误差，再乘以$100$小时内的$3.6$百万个计时周期。
:::

::: history
康拉德·楚泽（Konrad Zuse）的继电器计算机 Z3（1941年）就已经使用二进制浮点数。算法的误差分析是随着电子计算机的出现才真正开始的：约翰·冯·诺伊曼（John von Neumann）和赫尔曼·戈德斯坦（Herman Goldstine）于1947年分析了高斯消去法，艾伦·图灵（Alan Turing）于1948年引入了“条件数”这一术语。詹姆斯·威尔金森（James Wilkinson）在20世纪50年代发展了向后误差分析，并在《代数过程中的舍入误差》（*Rounding Errors in Algebraic Processes*，1963年）一书中作了系统阐述。直到20世纪80年代，每个厂商都有各自的浮点格式和各自的怪癖，以致同一程序在不同机器上给出不同的答案；1985年的 IEEE 754 标准结束了这种局面，它主要由威廉·卡汉（William Kahan）设计，卡汉也因在浮点计算方面的工作获得了1989年的图灵奖。卡汉还在1965年发表了补偿求和算法。
:::

## 后续内容

此后的每一章都把截断误差分析（通常以泰勒定理为基础）与对舍入的关注结合起来：重根附近求根所能达到的精度（[[numerical-analysis/root-finding]]）、插值公式的稳定性（[[numerical-analysis/interpolation]]），尤其是矩阵的条件数以及带选主元的高斯消去法的向后稳定性（[[numerical-analysis/direct-methods]]）。不稳定性这一主题在微分方程中会再次出现：在那里，不稳定的方法会使误差呈指数增长，很像[[#ex-recurrence]]中的递推（[[numerical-analysis/numerical-odes]]）。

::: summary
- 计算机把实数表示为$\pm m\times\beta^e$，带有$p$位有效数字；IEEE 双精度的$p = 53$位，单位舍入误差为$u = 2^{-53} \approx 1.1\times10^{-16}$，表示范围可达约$10^{308}$。
- 舍入的相对误差至多为$u$，每次正确舍入的运算都满足$\operatorname{fl}(x\circ y) = (x\circ y)(1 + \delta)$，$\abs\delta \le u$。
- 几乎相等的数相减会把先前的相对误差放大$\frac{\abs x + \abs y}{\abs{x - y}}$倍（灾难性抵消）；应改写公式以避免它。
- 截断误差与舍入误差相互竞争：向前差商在$h \approx \sqrt u$时达到最佳精度，约为$\sqrt u$。
- 条件数$\kappa_f(x) = \abs{xf'(x)/f(x)}$度量问题的敏感性；预计会损失约$\log_{10}\kappa$位数字。
- 若一个算法算出的是受到轻微扰动的数据的精确答案，则它是向后稳定的；向前误差$\lesssim$条件数$\times$向后误差。
- 递推求和是向后稳定的，误差至多为$\gamma_{n-1}\sum\abs{x_i}$；不稳定的递推可能把误差放大$n!$这样量级的倍数。
:::

## 习题

::: exercise 微型浮点数系的机器精度 {level=1 check="1/4"}
在[[#ex-toy]]中$p = 3$的二进制浮点数系里，机器精度（即$1$到下一个浮点数的距离）是多少？
::: solution
$1 = (1.00)_2$之后的下一个数是$(1.01)_2 = 1.25$，所以$\eps_M = 2^{1-p} = 2^{-2} = \frac14$。单位舍入误差为$u = \frac18$。
:::
:::

::: exercise 求条件数 {level=1 check="3"}
求$f(x) = x^3$在任一点$x \ne 0$处的相对条件数。
::: solution
$\kappa = \abs{\frac{x\cdot3x^2}{x^3}} = 3$。$x$中的相对误差$\delta$在$x^3$中大约变为$3\delta$，这与$(1 + \delta)^3 \approx 1 + 3\delta$一致。
:::
:::

::: exercise 单精度的单位舍入误差 {level=1 check="2^(-24)"}
单精度的$p = 24$。它的单位舍入误差$u$是多少？它大约有多少位有效十进制数字？
::: solution
$u = 2^{-p} = 2^{-24} \approx 5.96\times10^{-8}$，所以单精度大约有$-\log_{10}u \approx 7.2$位有效十进制数字。
:::
:::

::: exercise 消除抵消 {level=2}
当$x$很大时，表达式$\sqrt{x + 1} - \sqrt x$会出现抵消。求一个不出现抵消的等价表达式，并说明在双精度下$x = 10^{16}$时两个公式各自会发生什么。
::: solution
乘以共轭式，得$\sqrt{x+1} - \sqrt x = \dfrac{1}{\sqrt{x + 1} + \sqrt x}$，它是两个正数相加，结果精确。在$x = 10^{16}$处，$x + 1$被舍入为$x$（那里双精度数的间距为$2$），所以原公式返回$0$，而改写后的公式返回$\frac{1}{2\times10^8} = 5\times10^{-9}$，达到满精度（真值为$5\times10^{-9}(1 - 2.5\times10^{-17} + \cdots)$）。
:::
:::

::: exercise 1附近的对数 {level=2 check="1/ln(1.001)"}
求$f(x) = \ln x$在$x = 1.001$处的相对条件数。若已知$x$的相对误差为$10^{-16}$，$\ln x$大约能有多少位正确数字？
::: solution
$\kappa = \frac{1}{\abs{\ln x}} = \frac{1}{\ln 1.001} \approx 1000.5$。相对误差约被放大$10^3$倍，所以$\ln x$的相对误差可达约$10^{-13}$：大约只有$13$位正确数字，而不是$16$位。
:::
:::

::: exercise 中心差商 {level=2}
证明：当$\abs{f'''} \le M_3$时，中心差商$\frac{f(x + h) - f(x - h)}{2h}$的截断误差至多为$\frac{M_3h^2}{6}$；若计入[[#thm-forward-difference]]中那样的舍入误差，总误差至多为$\frac{M_3h^2}{6} + \frac{uF}{h}$。求最优的$h$和最佳误差，并对$f = \exp$在$x = 1$处求出它们的值。
::: hint
把$f(x \pm h)$展开到三阶，并用介值定理把两个余项合并。
:::
::: solution
由泰勒定理，$f(x \pm h) = f(x) \pm hf'(x) + \frac{h^2}{2}f''(x) \pm \frac{h^3}{6}f'''(\xi_\pm)$。两式相减，得$f(x+h) - f(x-h) = 2hf'(x) + \frac{h^3}{6}\left(f'''(\xi_+) + f'''(\xi_-)\right)$，所以截断误差为$\frac{h^2}{12}\abs{f'''(\xi_+) + f'''(\xi_-)} \le \frac{M_3h^2}{6}$。舍入误差使分子的改变至多为$2uF$，因而使差商的改变至多为$\frac{2uF}{2h} = \frac{uF}{h}$。求$\phi(h) = \frac{M_3h^2}{6} + \frac{uF}{h}$的最小值：由$\phi'(h) = \frac{M_3h}{3} - \frac{uF}{h^2} = 0$得$h_* = \left(\frac{3uF}{M_3}\right)^{1/3}$，且$\phi(h_*) = \frac{M_3h_*^2}{6} + \frac{M_3h_*^2}{3} = \frac{M_3h_*^2}{2}$。对$\exp$在$1$处，$F \approx M_3 \approx e$，所以$h_* \approx (3u)^{1/3} \approx 6.9\times10^{-6}$，最佳误差约为$\frac e2h_*^2 \approx 6.5\times10^{-11}$——大约有$10$位正确数字，而不是$8$位。
:::
:::

::: exercise 稳定的二次方程求解程序 {level=2}
针对上面的函数`quadratic_roots`，说明它为什么从不把几乎相等的量相减，并手算验证它能给出$x^2 - 5x + 6 = 0$的正确根。
::: solution
量$q = -\frac12\left(b + \operatorname{sign}(b)\sqrt{b^2 - 4ac}\right)$是把$b$与一个**同号**的数相加，所以不会出现抵消（平方根本身是良态的，除非$b^2 \approx 4ac$，即几乎是二重根的情形，而这本身就是一个病态问题）。两根为$q/a$和$c/q$，因为$q$等于$a$乘以其中一个根，而两根之积为$c/a$。对$a = 1$，$b = -5$，$c = 6$：$\sqrt{25 - 24} = 1$，$\operatorname{sign}(b)\cdot1 = -1$，$q = -\frac12(-5 - 1) = 3$。两根为$q/a = 3$和$c/q = 2$。
:::
:::

::: exercise 内积 {level=3}
设$\hat s$是$s = \sum_{i=1}^n x_iy_i$的计算值（先在浮点运算中求出各乘积，再递推求和）。利用[[#eq-standard-model]]和[[#lem-gamma]]证明$\abs{\hat s - s} \le \gamma_n\sum_{i=1}^n\abs{x_iy_i}$。
::: solution
每个乘积的计算结果为$x_iy_i(1 + \epsilon_i)$，其中$\abs{\epsilon_i} \le u$。像[[#thm-summation]]的证明中那样对这$n$个数递推求和，第$i$项还要再乘上至多$n - 1$个因子$(1 + \delta_k)$。所以$\hat s = \sum_i x_iy_i\prod_{j}(1 + \delta_{ij})$，其中每个乘积至多有$n$个因子，且$\abs{\delta_{ij}} \le u$。由[[#lem-gamma]]，每个乘积等于$1 + \theta^{(i)}$，其中$\abs{\theta^{(i)}} \le \gamma_n$（因子越少，界越小，因为$\gamma_k$随$k$递增）。因此$\abs{\hat s - s} = \abs{\sum_ix_iy_i\theta^{(i)}} \le \gamma_n\sum_i\abs{x_iy_i}$。这个界是矩阵乘法和高斯消去法误差分析的基础。
:::
:::

::: exercise 斯特本茨（Sterbenz）引理 {level=3 #exr-sterbenz}
设$x$和$y$是精度为$p$的二进制浮点数系中的正浮点数（不考虑下溢），且满足$\frac y2 \le x \le 2y$。证明$x - y$是浮点数，从而它能被精确地计算出来。
::: hint
设$y \le x \le 2y$。把两个数都写成较小那个数处的间距$2^{e - p + 1}$的整数倍，其中$2^e \le y < 2^{e+1}$。
:::
::: solution
由对称性，不妨设$y \le x \le 2y$（否则交换两者的角色并改变符号）。设$2^e \le y < 2^{e+1}$。则$y = M_y2^{e-p+1}$，其中$M_y$是满足$2^{p-1} \le M_y < 2^p$的整数。由于$x \ge y \ge 2^e$，$x$的指数至少为$e$，所以$x$也是$2^{e - p + 1}$的整数倍：$x = M_x2^{e-p+1}$。于是$x - y = (M_x - M_y)2^{e-p+1}$，其中$0 \le M_x - M_y$；又由$x - y \le 2y - y = y < 2^{e+1}$得$M_x - M_y < 2^{p}$。小于$2^p$的整数乘以$2$的幂，是至多有$p$个有效二进制位的浮点数（规格化数或零）。所以$x - y$可以精确表示，正确舍入会精确地返回它。
:::
:::

::: exercise 递推中的误差增长 {level=3}
在[[#ex-recurrence]]中，设计算得到的$\hat I_0 = I_0 + \eps_0$，并设此后所有运算都是精确的。证明$\hat I_n - I_n = (-1)^nn!\,\eps_0$。再证明：从$N$开始、初始误差为$\eps_N$的向后递推$I_{n-1} = (1 - I_n)/n$，在下标$n < N$处产生的误差的绝对值为$\frac{n!}{N!}\abs{\eps_N}$。
::: solution
令$E_n = \hat I_n - I_n$。从$\hat I_n = 1 - n\hat I_{n-1}$中减去$I_n = 1 - nI_{n-1}$，得$E_n = -nE_{n-1}$，所以由归纳法，$E_n = (-n)(-(n-1))\cdots(-1)E_0 = (-1)^nn!\,\eps_0$。向后递推时，$\hat I_{n-1} - I_{n-1} = -\frac{1}{n}(\hat I_n - I_n)$，所以$E_{n-1} = -E_n/n$，从而$\abs{E_n} = \frac{\abs{E_N}}{N(N-1)\cdots(n+1)} = \frac{n!}{N!}\abs{\eps_N}$。取$N = 40$，$n = 20$，$\abs{\eps_N} < \frac{1}{41}$，它小于$\frac{20!}{40!\cdot 41} \approx 7\times10^{-32}$。
:::
