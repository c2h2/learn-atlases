1669年，艾萨克·牛顿（Isaac Newton）以如下三次方程为例，演示了一种新方法：

$$
x^3 - 2x - 5 = 0 .
$$

三次方程有求根公式，但它很笨拙；而对于五次及五次以上的多项式，根本不存在一般的根式求解公式（阿贝尔-鲁菲尼（Abel–Ruffini）定理）。像$x = \cos x$这样的方程，或者确定行星位置的开普勒（Kepler）方程$M = E - e\sin E$，则完全没有封闭形式的解。然而计算机能在几微秒内把它们的根求到十六位数字。它靠的是**迭代**：从一个猜测值出发，反复加以改进，得到一个收敛到根的数列$x_0, x_1, x_2, \dots$。

本章研究四种基本的迭代法——二分法、不动点迭代、牛顿法和割线法。对每一种方法，我们都要证明它在什么条件下收敛、收敛得**有多快**，并认识比较迭代法的关键概念——**收敛阶**。本章始终讨论这样的问题：给定连续函数$f$，求$x^*$使得$f(x^*) = 0$。贯穿全章的例子是牛顿的三次方程，它的实根为

$$
x^* = 2.094\,551\,481\,542\,326\,591\ldots
$$

## 二分法

介值定理（[[calculus-1/continuity]]）保证：连续函数在哪里变号，哪里就有根。**二分法**把这个存在性证明变成了一个算法：把区间一分为二，保留函数仍然变号的那一半，如此重复。

::: algorithm 二分法 {#alg-bisection}
给定在$[a, b]$上连续且$f(a)f(b) < 0$的函数$f$，以及容许误差$\tau > 0$：当$b - a > 2\tau$时，令$c = \frac{a+b}{2}$；若$f(a)f(c) \le 0$，则用$c$代替$b$，否则用$c$代替$a$。最后返回中点$\frac{a+b}{2}$。
:::

```python
def bisection(f, a, b, tol=1e-12):
    fa = f(a)
    assert fa * f(b) < 0, "f must change sign on [a, b]"
    while b - a > 2 * tol:
        c = (a + b) / 2
        fc = f(c)
        if fa * fc <= 0:
            b = c                  # 根在 [a, c] 中
        else:
            a, fa = c, fc          # 根在 [c, b] 中
    return (a + b) / 2
```

::: theorem 二分法的收敛性 {#thm-bisection}
设$f$在$[a, b]$上连续，且$f(a)f(b) < 0$。设$[a_k, b_k]$是经过$k$次二分后的区间，$c_k = \frac{a_k + b_k}{2}$。则$f$在$[a, b]$中有一个根$x^*$，满足

$$
\abs{c_k - x^*} \le \frac{b - a}{2^{k+1}} \qquad (k = 0, 1, 2, \dots).
$$ {#eq-bisection}
:::

::: proof
由构造，$f(a_k)f(b_k) \le 0$，$[a_{k+1}, b_{k+1}] \subseteq [a_k, b_k]$，且$b_k - a_k = (b - a)/2^k$。左端点构成以$b$为上界的递增数列，右端点构成以$a$为下界的递减数列，所以两者都收敛（[[calculus-2/sequences#thm-mct]]）；又因为$b_k - a_k \to 0$，它们有相同的极限$x^*$，且$x^*$属于每一个$[a_k, b_k]$。由连续性，$f(a_k)f(b_k) \to f(x^*)^2$，而每个$f(a_k)f(b_k) \le 0$，所以$f(x^*)^2 \le 0$，从而$f(x^*) = 0$。最后，$x^*$和$c_k$都位于$[a_k, b_k]$中，而$c_k$是该区间的中点，所以$\abs{c_k - x^*} \le \frac12(b_k - a_k) = \frac{b-a}{2^{k+1}}$。
:::

二分法很慢，但绝对可靠：每一步恰好得到一位二进制数字，因此每得到一位十进制数字大约需要$3.3$步；而且达到给定精度所需的步数是事先就知道的。

::: example 用二分法解牛顿的三次方程 {#ex-bisection}
在$[2, 3]$上对$f(x) = x^3 - 2x - 5$应用二分法。经过多少次二分可以保证误差小于$10^{-6}$？
::: solution
由于$f(2) = -1 < 0$，$f(3) = 16 > 0$，所以$[2, 3]$中有根。第一个中点是$c_0 = 2.5$，$f(2.5) = 5.625 > 0$，所以根位于$[2, 2.5]$中；接着$c_1 = 2.25$，$f(2.25) = 1.89 > 0$，所以根位于$[2, 2.25]$中；依此类推：

| $k$ | $0$ | $1$ | $2$ | $3$ | $4$ | $5$ | $10$ | $15$ | $20$ |
|---|---|---|---|---|---|---|---|---|---|
| $c_k$ | $2.5$ | $2.25$ | $2.125$ | $2.0625$ | $2.093\,75$ | $2.109\,375$ | $2.094\,238$ | $2.094\,558\,7$ | $2.094\,551\,56$ |
| $\abs{c_k - x^*}$ | $0.41$ | $0.16$ | $0.030$ | $0.032$ | $0.000\,80$ | $0.015$ | $3.1\times10^{-4}$ | $7.2\times10^{-6}$ | $8.2\times10^{-8}$ |

误差并不是单调减小的——在$k = 4$时，中点恰好落在根的附近——但它始终低于[[#eq-bisection]]给出的界$2^{-(k+1)}$。当$2^{k+1} > 10^6$，即$k + 1 \ge 20$时，这个界小于$10^{-6}$：经过$k = 19$次二分后，无论$f$是什么样子，都能保证中点与根的距离在$10^{-6}$以内。
:::

## 不动点迭代

许多方程天然就具有$x = g(x)$的形式，而任何方程$f(x) = 0$也都可以改写成这种形式，例如写成$x = x - f(x)$或$x = x - \lambda f(x)$。$x = g(x)$的解称为$g$的**不动点**，最直接的算法就是迭代：

$$
x_{n+1} = g(x_n), \qquad n = 0, 1, 2, \dots
$$ {#eq-fixed-point}

若$g$连续且$x_n \to x^*$，则令$n\to\infty$得$x^* = g(x^*)$，所以极限是不动点。问题在于迭代何时收敛，答案是一个压缩条件。

::: theorem 压缩映射定理 {#thm-contraction}
设$g$把闭区间$[a, b]$映入自身，且存在常数$L < 1$，使得

$$
\abs{g(x) - g(y)} \le L\abs{x - y} \qquad\text{对所有 } x, y \in [a, b].
$$

则$g$在$[a, b]$中恰有一个不动点$x^*$；对每个$x_0 \in [a, b]$，迭代序列[[#eq-fixed-point]]都收敛到$x^*$；并且

$$
\abs{x_n - x^*} \le L^n\abs{x_0 - x^*}, \qquad \abs{x_n - x^*} \le \frac{L}{1 - L}\abs{x_n - x_{n-1}} .
$$ {#eq-contraction}
:::

::: proof
**存在性。**$g$是连续的（这由压缩条件推出）。由于$g(a), g(b) \in [a, b]$，函数$h(x) = g(x) - x$满足$h(a) = g(a) - a \ge 0$和$h(b) = g(b) - b \le 0$，所以由介值定理，$h$有一个零点$x^*$。

**唯一性。**若$x^*$和$y^*$都是不动点，则$\abs{x^* - y^*} = \abs{g(x^*) - g(y^*)} \le L\abs{x^* - y^*}$；由于$L < 1$，这迫使$\abs{x^* - y^*} = 0$。

**收敛性。**所有迭代值都停留在$[a, b]$中，且$\abs{x_{n+1} - x^*} = \abs{g(x_n) - g(x^*)} \le L\abs{x_n - x^*}$。由归纳法，$\abs{x_n - x^*} \le L^n\abs{x_0 - x^*} \to 0$。

**事后误差界。**由三角不等式，$\abs{x_{n-1} - x^*} \le \abs{x_{n-1} - x_n} + \abs{x_n - x^*} \le \abs{x_n - x_{n-1}} + L\abs{x_{n-1} - x^*}$，所以$\abs{x_{n-1} - x^*} \le \frac{1}{1 - L}\abs{x_n - x_{n-1}}$，进而$\abs{x_n - x^*} \le L\abs{x_{n-1} - x^*} \le \frac{L}{1 - L}\abs{x_n - x_{n-1}}$。
:::

[[#eq-contraction]]中的第二个界在实践中很有用：它用最后两个迭代值之差这个可以计算的量来估计未知的误差。若$g$可导，则由中值定理，在$[a, b]$上$\abs{g'(x)} \le L$蕴涵压缩条件。在不动点附近，这给出一个局部判据。

::: corollary 局部收敛性 {#cor-local}
设$g$在不动点$x^*$附近连续可导。若$\abs{g'(x^*)} < 1$，则对每个充分接近$x^*$的$x_0$，迭代都收敛到$x^*$，并且

$$
\lim_{n\to\infty}\frac{x_{n+1} - x^*}{x_n - x^*} = g'(x^*)
$$

（只要对所有$n$都有$x_n \ne x^*$）。若$\abs{g'(x^*)} > 1$，则除非迭代恰好落在$x^*$上，否则没有任何迭代序列收敛到$x^*$。
:::

::: proof
取$L$使$\abs{g'(x^*)} < L < 1$。由$g'$的连续性，存在$\delta > 0$，使得在$I = [x^* - \delta, x^* + \delta]$上$\abs{g'(x)} \le L$。对$x \in I$，由中值定理，$\abs{g(x) - x^*} = \abs{g(x) - g(x^*)} \le L\abs{x - x^*} \le \delta$，所以$g$把$I$映入自身，并且在$I$上是压缩映射；于是[[#thm-contraction]]适用。此外，$x_{n+1} - x^* = g'(\xi_n)(x_n - x^*)$，其中$\xi_n$介于$x_n$与$x^*$之间；由于$\xi_n \to x^*$，比值趋于$g'(x^*)$。反之，若$\abs{g'(x^*)} > 1$，则在$x^*$附近$\abs{g'} \ge L' > 1$，同一个恒等式表明，一旦迭代值靠近$x^*$，每一步都会使到$x^*$的距离**增大**到至少$L'$倍，所以除非某个$x_n = x^*$，否则迭代不可能收敛到$x^*$。
:::

::: example 求解 x = cos x {#ex-cos-fixed}
证明$x_{n+1} = \cos x_n$从任何初始点出发都收敛，并预测其收敛速度。
::: solution
迭代一步之后，每个迭代值都位于$[-1, 1]$中；两步之后则位于$[\cos 1, 1] = [0.540, 1]$中。在$[0.5, 1]$上，$\cos$的值域为$[\cos1, \cos0.5] = [0.540, 0.878] \subset [0.5, 1]$，且$\abs{g'(x)} = \sin x \le \sin 1 \approx 0.841$。所以[[#thm-contraction]]在$L = 0.841$时适用：存在唯一的不动点$x^* = 0.739\,085\,133\ldots$，并且迭代从任何初始点出发都收敛。

渐近收敛速度为$\abs{g'(x^*)} = \sin x^* = 0.674$，所以误差每一步大约乘以这个因子：

| $n$ | $0$ | $1$ | $2$ | $3$ | $5$ | $10$ | $20$ | $30$ |
|---|---|---|---|---|---|---|---|---|
| $x_n$ | $1$ | $0.540\,30$ | $0.857\,55$ | $0.654\,29$ | $0.701\,37$ | $0.744\,24$ | $0.739\,184$ | $0.739\,087\,0$ |
| $\abs{x_n - x^*}$ | $0.26$ | $0.20$ | $0.12$ | $0.085$ | $0.038$ | $5.2\times10^{-3}$ | $9.9\times10^{-5}$ | $1.9\times10^{-6}$ |

由于$g'(x^*) < 0$，迭代值在$x^*$两侧交替出现。每得到一位十进制数字需要$\frac{1}{-\log_{10}0.674} \approx 5.8$步——甚至比二分法还慢。
:::

$g$的选取至关重要。

::: example 同一方程的两种改写 {#ex-rearrange}
牛顿的三次方程$x^3 - 2x - 5 = 0$可以改写为$x = g_1(x) = (2x + 5)^{1/3}$，也可以改写为$x = g_2(x) = \frac{x^3 - 5}{2}$。哪一个不动点迭代收敛到$x^* \approx 2.0946$？
::: solution
两个函数都以$x^*$为不动点，所以由[[#cor-local]]，结论取决于那里导数的大小。对第一个函数，$g_1'(x) = \frac{2}{3(2x + 5)^{2/3}}$，所以$g_1'(x^*) \approx 0.152 < 1$：迭代线性收敛，每步大约得到$-\log_{10}0.152 \approx 0.8$位数字。从$x_0 = 2$出发，它给出$2.0801,\ 2.0924,\ 2.0942,\ 2.0945, \dots$，而$x_7$的误差为$1.8\times10^{-7}$。

对第二个函数，$g_2'(x) = \frac32x^2$，所以$g_2'(x^*) \approx 6.6 > 1$：不动点是排斥的，从$x_0 = 2$出发，迭代产生$1.5,\ -0.81,\ -2.77,\ -13.1,\ -1128, \dots$。同一个方程用两种方式改写，得到的一个是好方法，另一个则毫无用处。系统地选取满足$g'(x^*) = 0$的$g$的方法，正是下面要讲的牛顿法。
:::
:::

## 收敛阶

二分法每一步获得固定数量的精度；而在下文牛顿法的表格中，每一步获得的是已有正确数字的**固定比例**。收敛阶的概念使这一点精确化。

::: definition 收敛阶 {#def-order}
设$x_n \to x^*$，且误差$e_n = x_n - x^*$都不为零。如果

$$
\lim_{n\to\infty}\frac{\abs{e_{n+1}}}{\abs{e_n}^p} = C ,
$$

（其中当$p = 1$时还要求$C < 1$），就称收敛的**阶**为$p \ge 1$，**渐近常数**为$C > 0$。$1$阶收敛称为**线性收敛**，$2$阶收敛称为**平方收敛**；满足$\abs{e_{n+1}}/\abs{e_n} \to 0$的收敛称为**超线性收敛**。
:::

对线性收敛，正确数字的位数每一步大约增加$-\log_{10}C$。对$p > 1$阶收敛，正确数字的位数每一步大约乘以$p$：若$\abs{e_n} \approx 10^{-k}$，则$\abs{e_{n+1}} \approx C\,10^{-pk}$。平方收敛把$3$位正确数字变成$6$位，再变成$12$位，然后达到满精度。

::: theorem 不动点迭代的收敛阶 {#thm-fp-order}
设$g$在不动点$x^*$附近$p$阶连续可导，$g'(x^*) = g''(x^*) = \cdots = g^{(p-1)}(x^*) = 0$，且$g^{(p)}(x^*) \ne 0$，其中$p \ge 2$。则当$x_0$充分接近$x^*$时，迭代恰好以$p$阶收敛，渐近常数为$\dfrac{\abs{g^{(p)}(x^*)}}{p!}$。
:::

::: proof
由于$g'(x^*) = 0$，由[[#cor-local]]，当$x_0$靠近$x^*$时迭代收敛。若某个$x_n = x^*$，迭代就停在那里，所以不妨设所有$e_n \ne 0$。在$x^*$处应用泰勒定理（[[calculus-2/taylor-series#thm-taylor]]），并注意前$p - 1$阶导数都为零，得

$$
x_{n+1} = g(x_n) = g(x^*) + \frac{g^{(p)}(\xi_n)}{p!}(x_n - x^*)^p
$$

其中$\xi_n$是介于$x_n$与$x^*$之间的某个数。由于$g(x^*) = x^*$，上式即$e_{n+1} = \frac{g^{(p)}(\xi_n)}{p!}e_n^p$。因为$\xi_n \to x^*$且$g^{(p)}$连续，所以$\frac{\abs{e_{n+1}}}{\abs{e_n}^p} \to \frac{\abs{g^{(p)}(x^*)}}{p!} \ne 0$。
:::

::: quiz
某迭代的误差依次为$10^{-2}$、$10^{-4}$、$10^{-8}$、$10^{-16}$。它的收敛阶是多少？
- [ ] 线性收敛，常数为$10^{-2}$
- [x] 平方收敛
- [ ] 三阶收敛
- [ ] $4$阶收敛
::: solution
每个误差都是前一个误差的平方：$\abs{e_{n+1}} = \abs{e_n}^2$，所以$p = 2$，$C = 1$。正确数字的位数每一步加倍（$2, 4, 8, 16$）。线性收敛每一步增加固定位数的数字，而三阶收敛会使位数每一步变为原来的三倍。
:::
:::

## 牛顿法

在当前猜测值$x_n$附近，用切线$y = f(x_n) + f'(x_n)(x - x_n)$代替$f$的图像，并取切线的零点作为下一个猜测值：

$$
x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)} .
$$ {#eq-newton}

这就是**牛顿法**（又称牛顿-拉弗森法）。它是以$g(x) = x - \frac{f(x)}{f'(x)}$为迭代函数的不动点迭代，并且

$$
g'(x) = 1 - \frac{f'(x)^2 - f(x)f''(x)}{f'(x)^2} = \frac{f(x)f''(x)}{f'(x)^2},
$$

它在满足$f'(x^*) \ne 0$的根处为零。由[[#thm-fp-order]]，我们预期至少是平方收敛。下面的定理给出一个直接的证明，并给出误差的显式递推关系。

::: theorem 牛顿法的平方收敛性 {#thm-newton}
设$f$在根$x^*$周围的某个区间上二阶连续可导，且$f'(x^*) \ne 0$。则存在$\delta > 0$，使得对每个满足$\abs{x_0 - x^*} \le \delta$的$x_0$，牛顿法都收敛到$x^*$，并且误差满足

$$
e_{n+1} = \frac{f''(\xi_n)}{2f'(x_n)}\,e_n^2 \quad\text{其中 } \xi_n \text{ 介于 } x_n \text{ 与 } x^*, \qquad \lim_{n\to\infty}\frac{e_{n+1}}{e_n^2} = \frac{f''(x^*)}{2f'(x^*)} .
$$ {#eq-newton-error}
:::

::: proof
取$\delta_0 > 0$，使得在$I = [x^* - \delta_0, x^* + \delta_0]$上$\abs{f'(x)} \ge m > 0$（由于$f'$连续且$f'(x^*) \ne 0$，这是可以做到的），并令$M = \max_I\abs{f''}$。设$x_n \in I$。在$x_n$处展开泰勒公式并在$x^*$处取值，得

$$
0 = f(x^*) = f(x_n) + f'(x_n)(x^* - x_n) + \tfrac12f''(\xi_n)(x^* - x_n)^2 .
$$

除以$f'(x_n)$，并利用[[#eq-newton]]整理，得$x_n - \frac{f(x_n)}{f'(x_n)} - x^* = \frac{f''(\xi_n)}{2f'(x_n)}(x_n - x^*)^2$，这就是误差公式。因此$\abs{e_{n+1}} \le K\abs{e_n}^2$，其中$K = \frac{M}{2m}$。

现在令$\delta = \min\left(\delta_0, \frac{1}{2K}\right)$。若$\abs{e_n} \le \delta$，则$\abs{e_{n+1}} \le K\abs{e_n}\cdot\abs{e_n} \le \frac12\abs{e_n}$，所以$x_{n+1}$仍在该区间内，并且更接近$x^*$。由归纳法，所有迭代值与$x^*$的距离都不超过$\delta$，且$\abs{e_n} \le 2^{-n}\abs{e_0} \to 0$。最后，$\xi_n \to x^*$且$x_n \to x^*$，所以由连续性，$\frac{e_{n+1}}{e_n^2} \to \frac{f''(x^*)}{2f'(x^*)}$。
:::

::: example 牛顿的三次方程 {#ex-newton-cubic}
从$x_0 = 2$出发，对$f(x) = x^3 - 2x - 5$应用牛顿法。
::: solution
这里$f'(x) = 3x^2 - 2$，所以$x_{n+1} = x_n - \frac{x_n^3 - 2x_n - 5}{3x_n^2 - 2}$。第一步为$x_1 = 2 - \frac{-1}{10} = 2.1$，恰好就是牛顿本人的第一次修正。用高精度计算，得到：

| $n$ | $x_n$ | $\abs{x_n - x^*}$ |
|---|---|---|
| $0$ | $2$ | $9.5\times10^{-2}$ |
| $1$ | $2.1$ | $5.4\times10^{-3}$ |
| $2$ | $2.094\,568\,121\,104\,185$ | $1.7\times10^{-5}$ |
| $3$ | $2.094\,551\,481\,698\,199$ | $1.6\times10^{-10}$ |

正确数字的位数每一步大约加倍：$1, 2, 5, 10, 20, 40$。比值$e_{n+1}/e_n^2$趋于$\frac{f''(x^*)}{2f'(x^*)} = \frac{6x^*}{2(3(x^*)^2 - 2)} \approx 0.563$，正如[[#eq-newton-error]]所预言的（例如$1.66\times10^{-5}/(5.45\times10^{-3})^2 \approx 0.56$）。在双精度下，迭代$4$步后就达到满精度。

对$f(x) = x^2 - a$，牛顿法成为$x_{n+1} = x_n - \frac{x_n^2 - a}{2x_n} = \frac12\left(x_n + \frac{a}{x_n}\right)$，这正是[[calculus-2/sequences#exr-heron]]中古老的巴比伦-海伦（Heron）开平方法；在那里我们直接证明了$x_{n+1} - \sqrt a = \frac{(x_n - \sqrt a)^2}{2x_n}$，这是[[#eq-newton-error]]的一个特例。

```python
def newton(f, fprime, x0, tol=1e-14, maxit=50):
    x = x0
    for k in range(maxit):
        dx = f(x) / fprime(x)
        x -= dx
        if abs(dx) <= tol * abs(x):      # 步长相对于 x 已很小：停止
            return x
    raise RuntimeError("Newton's method did not converge")
```

### 牛顿法何时失效

[[#thm-newton]]是一个**局部**结果：它只保证从充分接近根的初始点出发时收敛，而且只适用于单根。

- **初始点不好。**对$f(x) = \arctan x$（根为$0$），从$x_0 = 1.3$出发的牛顿法收敛：$-1.162,\ 0.859,\ -0.374,\ 0.034, \dots$。从$x_0 = 1.5$出发则发散：$-1.694,\ 2.321,\ -5.114,\ 32.3, \dots$，因为在远离$0$处切线几乎是水平的，会把迭代值抛得越来越远。
- **循环。**对$f(x) = x^3 - 2x + 2$和$x_0 = 0$：$x_1 = 0 - \frac{2}{-2} = 1$，$x_2 = 1 - \frac{1}{1} = 0$；迭代在$0$与$1$之间永远循环下去。
- **导数为零。**若$f'(x_n) = 0$，该方法无定义；若$f'(x_n)$很小，步长就会非常大。
- **重根。**若$f'(x^*) = 0$，收敛只是线性的（见下文）。

在实践中，牛顿法要与某种保护措施结合使用，例如一旦牛顿步会跳出含根区间，就改用二分步。布伦特（Brent）方法（1973年）就是以这种方式把二分法、割线法和逆二次插值结合起来的，它是各种函数库中的标准求根程序，例如 SciPy 的`brentq`。

::: warning 残差小并不意味着误差小
如果函数非常平坦，那么$\abs{f(x_n)}$的值很小并不能保证$x_n$接近根，步长$\abs{x_{n+1} - x_n}$很小也不能。在单根附近$e_n \approx \frac{f(x_n)}{f'(x^*)}$，所以残差必须用导数加以标度。在重根附近，问题是病态的：对于二重根，$f$中大小为$u$的舍入误差会使根产生大小为$\sqrt u \approx 10^{-8}$的不确定性，无论使用什么方法。
:::

::: example 二重根 {#ex-double-root}
从$x_0 = 2$出发，对$f(x) = x^3 - 3x + 2 = (x - 1)^2(x + 2)$应用牛顿法。
::: solution
迭代值为$1.556,\ 1.298,\ 1.155,\ 1.080,\ 1.040,\ 1.020,\ 1.010, \dots$：误差每一步减半，这是常数为$\frac12$的线性收敛。原因在于：在$m$重根处，$f(x) = (x - x^*)^mh(x)$，其中$h(x^*) \ne 0$，计算可得$g'(x^*) = 1 - \frac1m$（[[#exr-multiplicity]]），这里即为$\frac12$。

如果重数已知，**修正牛顿法**$x_{n+1} = x_n - m\frac{f(x_n)}{f'(x_n)}$可以恢复平方收敛：取$m = 2$，误差依次为$0.11,\ 1.9\times10^{-3},\ 6.3\times10^{-7},\ 1.6\times10^{-10}$。然而下一步又**跳回**到$4.8\times10^{-7}$的误差：此时$f(x_n)$已经小到被舍入误差所主导，这正说明了上面警示中的$\sqrt u$极限。
:::
:::

## 割线法

牛顿法需要导数，而导数的计算可能代价高昂，甚至无法得到。**割线法**用过最后两个迭代点的割线代替切线：

$$
x_{n+1} = x_n - f(x_n)\,\frac{x_n - x_{n-1}}{f(x_n) - f(x_{n-1})} .
$$ {#eq-secant}

它需要两个初始值，但每一步只需计算一次新的函数值。

::: theorem 割线法的收敛性 {#thm-secant}
设$f$在单根$x^*$（$f'(x^*) \ne 0$）附近二阶连续可导。当初始值充分接近$x^*$时，割线法收敛，其误差满足

$$
e_{n+1} = \frac{f''(\eta_n)}{2f'(\zeta_n)}\,e_ne_{n-1}
$$

其中$\eta_n, \zeta_n$是包含$x_{n-1}, x_n, x^*$的最小区间中的某两个数；并且若$f''(x^*) \ne 0$，则收敛阶为$\varphi = \frac{1 + \sqrt5}{2} \approx 1.618$。
:::

::: proof {collapsed}
**证明概要。**割线是$f$在$x_{n-1}, x_n$处的线性插值多项式$p$，而$x_{n+1}$是它的零点。由[[numerical-analysis/interpolation]]中的插值误差公式，$f(x^*) - p(x^*) = \frac{f''(\eta_n)}{2}(x^* - x_n)(x^* - x_{n-1})$，即$-p(x^*) = \frac{f''(\eta_n)}{2}e_ne_{n-1}$。由于$p$是线性的，其斜率为$\frac{f(x_n) - f(x_{n-1})}{x_n - x_{n-1}} = f'(\zeta_n)$（中值定理），且$p(x_{n+1}) = 0$，所以$p(x^*) = f'(\zeta_n)(x^* - x_{n+1}) = -f'(\zeta_n)e_{n+1}$，由此即得误差公式。与[[#thm-newton]]一样，它蕴涵了从充分接近的初始值出发时的收敛性，进而$e_{n+1} \approx Ce_ne_{n-1}$，其中$C = \frac{f''(x^*)}{2f'(x^*)}$。若对某个阶$p$有$\abs{e_{n+1}} \approx K\abs{e_n}^p$，则$\abs{e_n} \approx (\abs{e_{n+1}}/K)^{1/p}$，代入$\abs{e_{n+1}} \approx \abs C\,\abs{e_n}\abs{e_{n-1}}$便迫使$p = 1 + \frac1p$，即$p^2 = p + 1$，其正根为$\varphi$。要使最后一步严格化还需要更细致一些；参见 Süli 与 Mayers 的《数值分析引论》（*An Introduction to Numerical Analysis*）第1章。
:::

::: example 用割线法解牛顿的三次方程 {#ex-secant}
取$x_0 = 2$，$x_1 = 3$，对$x^3 - 2x - 5$应用割线法，并考察其误差。
::: solution
由$f(2) = -1$和$f(3) = 16$，第一步为$x_2 = 3 - 16\cdot\frac{3 - 2}{16 - (-1)} = 3 - \frac{16}{17} = 2.058\,82$。继续用高精度计算，误差为

| $n$ | $2$ | $3$ | $4$ | $5$ | $6$ | $7$ | $8$ |
|---|---|---|---|---|---|---|---|
| $\abs{x_n - x^*}$ | $3.6\times10^{-2}$ | $1.3\times10^{-2}$ | $2.7\times10^{-4}$ | $2.1\times10^{-6}$ | $3.2\times10^{-10}$ | $3.6\times10^{-16}$ | $6.4\times10^{-26}$ |

从$n = 4$起，指数（取绝对值为$3.6$、$5.7$、$9.5$、$15.4$、$25.2$）大致像斐波那契数列那样增长：每一个约等于前两个之和，这与$e_{n+1} \approx Ce_ne_{n-1}$的预言完全一致。相邻指数之比趋于$\varphi \approx 1.6$，而牛顿法的这一比值为$2$。
:::
:::

**哪一个更快？**按**每一步**计，牛顿法（$2$阶）胜过割线法（$1.618$阶）。但牛顿法的一步要计算一次$f$和一次$f'$，而割线法的一步只需计算一次$f$。如果计算$f'$的代价与$f$差不多，那么按每次函数求值计，牛顿法的阶为$\sqrt2 \approx 1.414$（误差每平方一次需要两次求值），而割线法的阶为$1.618$。当导数的计算代价高昂时，割线法胜出。

::: quiz
$f(x) = (x-1)^2$的图像与轴相切而不穿过它。哪种方法能求出它的根？
- [ ] 二分法，从$[0, 3]$出发
- [x] 牛顿法（线性收敛）
- [ ] 都不能，因为$f$从不变号
- [ ] 只有割线法
::: solution
二分法需要变号，而处处有$f \ge 0$，所以它连第一步都无法开始。牛顿法从附近的初始点出发仍然收敛，但只是线性收敛，误差每一步减半（这个根的重数为$2$）。割线法也收敛，只是很慢。在这里，所有方法的精度都被限制在约$\sqrt u \approx 10^{-8}$，因为只与轴相切的函数的根是病态的。
:::
:::

::: application 硬件中的除法与开平方
牛顿法如此有效，以至于算术运算本身也用它来实现。为了不做除法而算出$1/a$，可以对$f(x) = \frac1x - a$应用牛顿法：迭代化简为$x_{n+1} = x_n(2 - ax_n)$，它只用到乘法和一次减法，并且每一步使正确的二进制位数加倍（[[#exr-reciprocal]]）。从一个精确到$8$位的小型查找表出发，三步就得到$64$位。类似的计算$1/\sqrt a$的迭代被用于图形处理器和数值函数库中。
:::

::: history
迭代求根的历史十分悠久：巴比伦人的开平方法就是用于$x^2 - a$的牛顿法。艾萨克·牛顿（Isaac Newton）在《运用无穷多项方程的分析》（*De analysi*，1669年）中以$x^3 - 2x - 5 = 0$为例描述了他的方法，但不是作为对$x$的迭代，而是通过逐次修正多项式展开式来进行的；约瑟夫·拉弗森（Joseph Raphson）于1690年发表了更简单的迭代形式，托马斯·辛普森（Thomas Simpson）则于1740年借助导数把它表述为适用于一般方程的方法。约瑟夫·傅里叶（Joseph Fourier）和奥古斯丁-路易·柯西（Augustin-Louis Cauchy）在19世纪初研究了它的收敛性。适用于完备度量空间的一般形式的压缩映射定理，是斯特凡·巴拿赫（Stefan Banach）在1922年的学位论文中证明的。割线法源于古老得多的“试位法”，古埃及和中国都已知道这种方法。理查德·布伦特（Richard Brent）稳健的混合算法发表在他的著作《无导数最小化算法》（*Algorithms for Minimization without Derivatives*，1973年）中。
:::

## 后续内容

牛顿法可以推广到方程组$\mathbf F(\mathbf x) = \mathbf 0$，此时导数换成雅可比矩阵：每一步都要求解一个线性方程组，这正是[[numerical-analysis/direct-methods]]的用武之地；同样的思想在最优化中用于求函数的极小值（[[multivariable/extrema]]）。求解刚性微分方程的隐式方法在每个时间步都要解一个非线性方程，通常用牛顿法（[[numerical-analysis/numerical-odes]]）。压缩映射定理还会作为线性方程组迭代解法的收敛判据再次出现（[[numerical-analysis/iterative-methods]]），并在函数空间中用于证明微分方程解的存在性（[[ode/existence-uniqueness]]）。求多项式的全部根，最好的办法是把它化为其友矩阵的特征值问题。

::: summary
- 二分法只需要变号和连续性；它每一步确保得到一位二进制数字：$\abs{c_k - x^*} \le (b - a)/2^{k+1}$。
- 当$g$是压缩映射（$\abs{g'} \le L < 1$）时，不动点迭代$x_{n+1} = g(x_n)$收敛；此时误差像$L^n$那样缩小，渐近地每一步乘以因子$g'(x^*)$。
- 收敛阶$p$：$\abs{e_{n+1}} \approx C\abs{e_n}^p$。线性收敛以恒定的速率增加数字位数；$p$阶收敛使正确数字的位数乘以$p$。
- 若$g'(x^*) = \cdots = g^{(p-1)}(x^*) = 0 \ne g^{(p)}(x^*)$，则不动点迭代是$p$阶收敛的。
- 从好的初始值出发，牛顿法$x_{n+1} = x_n - f(x_n)/f'(x_n)$平方收敛到单根，且$e_{n+1} \approx \frac{f''}{2f'}e_n^2$；从不好的初始值出发，它可能发散或循环；在重根处它只是线性收敛的。
- 割线法不需要导数，收敛阶为$\varphi \approx 1.618$；按每次函数求值计，它往往比牛顿法更快。
- 实用的求解程序把安全的含根区间方法与快速的局部方法结合起来。
:::

::: exercise 二分的次数 {level=1 check="20"}
区间$[1, 2]$需要二分多少次，其长度才能不超过$10^{-6}$？

二分$k$次后，区间长度为$2^{-k}$。需要$2^{-k} \le 10^{-6}$，即$k \ge 6\log_2 10 \approx 19.93$，所以$k = 20$。（此时中点与某个根的距离在$\frac12\cdot10^{-6}$以内。）

::: exercise 一步牛顿迭代 {level=1 check="7/4"}
从$x_0 = 2$出发，对$f(x) = x^2 - 3$做一步牛顿迭代。
::: solution
$x_1 = 2 - \frac{f(2)}{f'(2)} = 2 - \frac{1}{4} = \frac74 = 1.75$。（与$\sqrt3 = 1.732\,05$比较：误差从$0.27$降到了$0.018$。）

::: exercise 一个线性收敛的迭代 {level=1}
证明当$x_0$靠近$x^*$时，$x_{n+1} = e^{-x_n}$收敛到$x = e^{-x}$的解$x^* \approx 0.5671$，并求误差每一步所乘的渐近因子。
::: solution
$g(x) = e^{-x}$的导数为$g'(x) = -e^{-x}$，所以$g'(x^*) = -e^{-x^*} = -x^*$（因为$x^* = e^{-x^*}$），且$\abs{g'(x^*)} \approx 0.567 < 1$。由[[#cor-local]]，迭代局部线性收敛，误差每一步大约乘以$-0.567$（符号交替变化）。
:::

::: exercise 选择改写方式 {level=2}
方程$x^2 - x - 2 = 0$有根$x^* = 2$。对$g_1(x) = x^2 - 2$、$g_2(x) = \sqrt{x + 2}$和$g_3(x) = 1 + \frac2x$中的每一个，判断从附近的初始值出发，不动点迭代是否收敛到$2$；若收敛，求出收敛速度。
::: solution
三者都以$2$为不动点。$g_1'(2) = 4$，所以迭代远离$2$而发散。由$g_2'(x) = \frac{1}{2\sqrt{x+2}}$得$g_2'(2) = \frac14$：线性收敛，误差每一步大约乘以$\frac14$（单调地）。由$g_3'(x) = -\frac{2}{x^2}$得$g_3'(2) = -\frac12$：以因子$\frac12$线性收敛，迭代值在$2$的两侧交替出现。
:::
:::

::: exercise 两步割线法 {level=2 check="7/5"}
取$x_0 = 1$，$x_1 = 2$，对$f(x) = x^2 - 2$做两步割线法。$x_3$是多少？
::: solution
$x_2 = 2 - f(2)\frac{2 - 1}{f(2) - f(1)} = 2 - 2\cdot\frac{1}{2 - (-1)} = \frac43$。于是$f(\frac43) = \frac{16}{9} - 2 = -\frac29$，并且

$$
x_3 = \frac43 - \left(-\frac29\right)\frac{\frac43 - 2}{-\frac29 - 2} = \frac43 - \left(-\frac29\right)\cdot\frac{-2/3}{-20/9} = \frac43 + \frac29\cdot\frac{3}{10} = \frac43 + \frac{1}{15} = \frac75 .
$$

所以$x_3 = 1.4$，误差为$0.014$（与$\sqrt2 = 1.414\,21$相比）。
:::
:::

::: exercise 不用除法求倒数 {level=2 #exr-reciprocal}
证明对$f(x) = \frac1x - a$（$a > 0$）的牛顿法为$x_{n+1} = x_n(2 - ax_n)$，相对误差$r_n = 1 - ax_n$满足$r_{n+1} = r_n^2$，并由此推出迭代收敛到$\frac1a$当且仅当$0 < x_0 < \frac2a$。
::: solution
$f'(x) = -\frac{1}{x^2}$，所以$x_{n+1} = x_n - \frac{1/x_n - a}{-1/x_n^2} = x_n + x_n - ax_n^2 = x_n(2 - ax_n)$。于是$1 - ax_{n+1} = 1 - 2ax_n + a^2x_n^2 = (1 - ax_n)^2$，即$r_{n+1} = r_n^2$，所以$r_n = r_0^{2^n}$。它趋于$0$（从而$x_n \to \frac1a$）当且仅当$\abs{r_0} < 1$，即$0 < ax_0 < 2$。关系式$r_{n+1} = r_n^2$是平方收敛最纯粹的形式。
:::
:::

::: exercise 重根处的牛顿法 {level=2 #exr-multiplicity}
设$f(x) = (x - x^*)^mh(x)$，其中$m \ge 2$，$h$可导且$h(x^*) \ne 0$。证明牛顿迭代函数$g(x) = x - f(x)/f'(x)$满足$g(x) - x^* = (x - x^*)\left(1 - \frac{h(x)}{mh(x) + (x - x^*)h'(x)}\right)$，并由此推出牛顿法以常数$1 - \frac1m$线性收敛。
::: solution
$f'(x) = (x - x^*)^{m-1}\left[mh(x) + (x - x^*)h'(x)\right]$，所以当$x$靠近$x^*$且$x \ne x^*$时，

$$
\frac{f(x)}{f'(x)} = \frac{(x - x^*)h(x)}{mh(x) + (x - x^*)h'(x)},
$$

用$x - x^*$减去它即得所求公式。当$x \to x^*$时，括号中的量趋于$1 - \frac{h(x^*)}{mh(x^*)} = 1 - \frac1m$，所以$\frac{e_{n+1}}{e_n} \to 1 - \frac1m \in (0, 1)$：线性收敛。当$m = 2$时，误差每一步减半，与[[#ex-double-root]]一致。
:::
:::

::: exercise 事后误差界 {level=3}
对$[0.5, 1]$上的$g(x) = \cos x$，取$L = \sin 1$，[[#ex-cos-fixed]]中的迭代值满足$\abs{x_{30} - x_{29}} \approx 4.7\times10^{-6}$。用[[#thm-contraction]]给出$\abs{x_{30} - x^*}$的界，并解释为什么这个界偏于悲观。再证明：若$g$是常数为$L$的压缩映射，且在包含所有迭代值和$x^*$的某个区间上$\abs{g'(x)} \le \ell$，则对任何满足$\ell < 1$的$\ell$，这个界可以改进为$\frac{\ell}{1 - \ell}\abs{x_n - x_{n-1}}$。
::: solution
取$L = \sin1 \approx 0.841$，则$\frac{L}{1-L} \approx 5.3$，所以$\abs{x_{30} - x^*} \le 5.3\times4.7\times10^{-6} \approx 2.5\times10^{-5}$。实际误差为$1.9\times10^{-6}$，比这个界小十倍以上，因为在$x^*$附近压缩因子是$\sin x^* \approx 0.674$，而不是最坏情形下的$0.841$。

关于改进：事后误差界的证明只用到了所涉及的迭代值满足$\abs{x_{n+1} - x^*} \le L\abs{x_n - x^*}$。若在包含所有迭代值和$x^*$的区间上$\abs{g'} \le \ell$，则由中值定理，在那里有$\abs{x_{k+1} - x^*} \le \ell\abs{x_k - x^*}$，同样的论证给出$\abs{x_n - x^*} \le \frac{\ell}{1 - \ell}\abs{x_n - x_{n-1}}$。对$x^*$附近的迭代值，可以取$\ell$接近$0.674$，得到$\frac{\ell}{1-\ell} \approx 2.1$以及界$9.8\times10^{-6}$（这仍然是高估，因为迭代值在$x^*$两侧交替出现，使得$\abs{x_n - x_{n-1}}$是相邻两个误差之**和**）。
:::

::: exercise 凸函数的单调收敛 {level=3}
设$f$在$[x^*, b]$上二阶可导，$f(x^*) = 0$，且在该区间上$f' > 0$，$f'' > 0$。证明从任意$x_0 \in (x^*, b]$出发的牛顿法产生一个收敛到$x^*$的递减数列。
::: hint
用归纳法证明$x^* < x_{n+1} < x_n$，其中下界部分要用到误差公式[[#eq-newton-error]]。
:::
::: solution
设$x^* < x_n \le b$。由于$f$递增且$f(x^*) = 0$，有$f(x_n) > 0$；又$f'(x_n) > 0$，所以$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)} < x_n$。由[[#eq-newton-error]]，$x_{n+1} - x^* = \frac{f''(\xi_n)}{2f'(x_n)}(x_n - x^*)^2 > 0$（推导这个公式时只用到了$[x^*, x_n]$上的泰勒定理）。所以$x^* < x_{n+1} < x_n$，由归纳法，该数列递减且以$x^*$为下界。由单调收敛定理，它收敛到某个$L \ge x^*$；在$x_{n+1} = x_n - f(x_n)/f'(x_n)$中令$n \to\infty$，并利用连续性（注意$f'(L) > 0$），得$f(L) = 0$；由于$f$严格递增，$L = x^*$。从几何上看：凸函数的图像位于其切线的上方，所以每条切线与轴的交点都位于根与当前点之间。
:::
:::
