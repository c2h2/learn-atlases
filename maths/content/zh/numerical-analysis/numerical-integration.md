一个服从正态分布的测量值落在其均值一个标准差范围内的概率为$\frac{2}{\sqrt{2\pi}}\int_0^1 e^{-t^2/2}\,dt$。函数$e^{-x^2}$没有初等原函数，所以微积分基本定理在这里派不上直接用场；椭圆的弧长、物理和统计中的大多数积分，以及只通过测量值得知的函数的每一个积分，情况都是如此。这些积分必须用数值方法计算。

**求积公式**用函数值的加权和来近似积分：

$$
\int_a^b f(x)\,dx \approx \sum_{i=0}^n w_i\,f(x_i),
$$

其中$x_i$称为**节点**，$w_i$称为**权**（求积系数）。黎曼和（[[calculus-1/integrals]]）是最粗糙的例子。本章通过对插值多项式（[[numerical-analysis/interpolation]]）积分来推导好得多的求积公式，证明它们的误差公式，把它们组合成复化公式，用理查森外推加速（龙贝格求积），最后以最优方式选取节点（高斯求积）。我们的检验积分是

$$
I = \int_0^1 e^{-x^2}\,dx = 0.746\,824\,132\,812\,427\ldots
$$

## 插值型求积公式

::: definition 代数精度 {#def-exactness}
如果一个求积公式能精确地积分每个次数至多为$d$的多项式，但不能精确地积分所有$d + 1$次多项式，就称它具有$d$次**代数精度**。如果一个求积公式是通过对$f$在节点上的插值多项式$p_n$积分而得到的，从而$w_i = \int_a^b\ell_i(x)\,dx$（$\ell_i$为拉格朗日基函数），就称它是**插值型**的。
:::

由于积分和求积公式都关于$f$是线性的，一个求积公式的代数精度至少为$d$，当且仅当它对$1, x, \dots, x^d$都精确成立。具有$n + 1$个节点的插值型求积公式的代数精度至少为$n$，因为次数$\le n$的多项式的插值多项式就是它本身。对等距节点上的插值多项式积分，就得到**牛顿-科茨公式**；其中最重要的三个分别使用一个、两个和三个节点。记$m = \frac{a+b}{2}$：

| 求积公式 | 表达式 | 代数精度 | 误差 |
|---|---|---|---|
| 中点公式 | $(b - a)\,f(m)$ | $1$ | $\dfrac{(b-a)^3}{24}f''(\xi)$ |
| 梯形公式 | $\dfrac{b - a}{2}\bigl(f(a) + f(b)\bigr)$ | $1$ | $-\dfrac{(b-a)^3}{12}f''(\xi)$ |
| 辛普森公式 | $\dfrac{b - a}{6}\bigl(f(a) + 4f(m) + f(b)\bigr)$ | $3$ | $-\dfrac{(b-a)^5}{2880}f^{(4)}(\xi)$ |

这里的“误差”是指$\int_a^b f - (\text{求积公式})$，$\xi$是$(a, b)$中的某个点。中点公式虽然只用一个节点，却对线性函数精确成立；辛普森公式虽然用抛物线插值，却对**三次**多项式精确成立：在这两种情形下，对称性都白白多送了一次代数精度，因为当$k$为奇数时$\int_a^b(x - m)^k\,dx = 0$。

::: theorem 基本求积公式的误差 {#thm-basic-errors}
设$f$在$[a, b]$上二阶连续可导。则存在$\xi, \xi' \in [a, b]$，使得

$$
\int_a^bf - (b - a)f(m) = \frac{(b-a)^3}{24}f''(\xi), \qquad \int_a^bf - \frac{b-a}{2}\bigl(f(a) + f(b)\bigr) = -\frac{(b-a)^3}{12}f''(\xi') .
$$

若$f$四阶连续可导，则辛普森公式满足$\int_a^bf - \frac{b-a}{6}\bigl(f(a) + 4f(m) + f(b)\bigr) = -\frac{(b-a)^5}{2880}f^{(4)}(\eta)$，其中$\eta \in [a, b]$。
:::

::: proof
设$\mu_k$和$M_k$分别是$f^{(k)}$在$[a, b]$上的最小值和最大值。三个证明遵循同一模式：把误差表示为$\int(\text{取值介于 } \mu_k \text{ 和 } M_k)\times(\text{不变号的权})$，对它进行估计，最后对$f^{(k)}$应用介值定理。

**中点公式。**由泰勒定理，$f(x) = f(m) + f'(m)(x - m) + \frac12f''(\eta_x)(x - m)^2$。积分时，由对称性，一次项的积分为零，所以误差为$E = \int_a^b\frac12f''(\eta_x)(x - m)^2\,dx$。由于$(x - m)^2 \ge 0$且$\int_a^b(x - m)^2\,dx = \frac{(b-a)^3}{12}$，得$\mu_2\frac{(b-a)^3}{24} \le E \le M_2\frac{(b-a)^3}{24}$，从而$E = \frac{(b-a)^3}{24}c$，其中$c \in [\mu_2, M_2]$。由介值定理，存在$\xi$使$c = f''(\xi)$。

**梯形公式。**该公式是对$f$在$a$和$b$处的线性插值多项式$p_1$积分，由插值误差公式（[[numerical-analysis/interpolation#thm-interp-error]]），$f(x) - p_1(x) = \frac12f''(\xi_x)(x - a)(x - b)$。这里权$(x - a)(x - b) \le 0$，且$\int_a^b(x-a)(x-b)\,dx = -\frac{(b-a)^3}{6}$，所以与前面一样，误差为$-\frac{(b-a)^3}{12}c$，其中$c \in [\mu_2, M_2]$，并且$c = f''(\xi')$。

**辛普森公式。**令$h = \frac{b-a}{2}$，并对$0 \le t \le h$令

$$
F(t) = \int_{m-t}^{m+t}f(x)\,dx - \frac t3\bigl(f(m - t) + 4f(m) + f(m + t)\bigr),
$$

于是$F(h)$就是辛普森公式的误差。求三次导数（这是常规的计算），得

$$
F'''(t) = -\frac t3\bigl(f'''(m + t) - f'''(m - t)\bigr) = -\frac{2t^2}{3}g(t), \qquad g(t) = \frac{f'''(m+t) - f'''(m-t)}{2t},
$$

且$F(0) = F'(0) = F''(0) = 0$。由中值定理，$g(t) = f^{(4)}(\eta_t)$位于$[\mu_4, M_4]$中。由带积分型余项的泰勒定理（[[calculus-2/taylor-series#thm-integral-remainder]]）得

$$
F(h) = \int_0^h\frac{(h - t)^2}{2}F'''(t)\,dt = -\frac13\int_0^h t^2(h - t)^2g(t)\,dt .
$$

权$t^2(h - t)^2$非负，其积分为$\frac{h^5}{30}$，所以$F(h) = -\frac{h^5}{90}c$，其中$c \in [\mu_4, M_4]$，因此$c = f^{(4)}(\eta)$。最后，$\frac{h^5}{90} = \frac{(b-a)^5}{32\cdot90} = \frac{(b-a)^5}{2880}$。
:::

::: example 用基本公式计算检验积分 {#ex-basic}
在单个区间$[0, 1]$上，对$\int_0^1e^{-x^2}\,dx$应用中点公式、梯形公式和辛普森公式。
::: solution
由$f(0) = 1$，$f(\frac12) = e^{-1/4} = 0.778\,801$，$f(1) = e^{-1} = 0.367\,879$，得：

- 中点公式：$0.778\,801$，误差$I - M = -0.031\,98$；
- 梯形公式：$\frac12(1 + 0.367\,879) = 0.683\,940$，误差$+0.062\,88$；
- 辛普森公式：$\frac16(1 + 4\times0.778\,801 + 0.367\,879) = 0.747\,180$，误差$-0.000\,356$。

中点公式的误差约为梯形公式误差的一半，且符号相反，正如误差公式所预言的（若$f''$为常数，则两者分别对应$\frac{1}{24}$和$-\frac{1}{12}$）。这并非巧合：辛普森公式恰好就是使两个主误差项相互抵消的组合$\frac{2M + T}{3}$，它的精度要高得多。
:::

::: warning 高阶牛顿-科茨公式是个陷阱
人们很容易想到一次性地对许多等距节点上的插值多项式积分。但龙格现象（[[numerical-analysis/interpolation]]）会延续到这里：当等距节点达到$9$个或更多时，某些权会变成负的，权的绝对值会增大，即使被积函数是解析的，这些公式也可能不收敛，同时还会放大舍入误差。提高精度的正确途径是细分区间（复化公式）或选取更好的节点（高斯求积）。
:::

为什么负权会带来问题？因为函数值从来都不是精确的：它们带有舍入误差或测量误差。下面的命题表明，正的权使求积公式不会放大这类误差。

::: proposition 正权求积公式的稳定性 {#prop-quad-stability}
设求积公式$Q(f) = \sum_iw_if(x_i)$在$[a, b]$上对常数精确成立，并把函数值$f(x_i)$换成受扰动的值$\hat f_i$，其中$\abs{\hat f_i - f(x_i)} \le \eps$。则$\abs{\sum_iw_i\hat f_i - Q(f)} \le \eps\sum_i\abs{w_i}$；若所有权都是正的，则$\sum_i\abs{w_i} = b - a$。
:::

::: proof
由三角不等式，$\abs{\sum_iw_i(\hat f_i - f(x_i))} \le \sum_i\abs{w_i}\,\eps$。由对$f = 1$精确成立得$\sum_iw_i = \int_a^b1 = b - a$；若每个$w_i > 0$，则$\sum\abs{w_i} = \sum w_i = b - a$。
:::

因此，对于正权的求积公式——复化中点公式、复化梯形公式、复化辛普森公式以及高斯求积——无论使用多少个节点，数据中的误差都不会被放大到超过$(b - a)\eps$。而对于具有许多等距节点的牛顿-科茨公式，$\sum\abs{w_i}$随节点数呈指数增长。

## 复化求积公式

把$[a, b]$分成$n$个宽为$h = \frac{b-a}{n}$的子区间，分点为$x_i = a + ih$，并在每个子区间上应用一个基本公式。这样就得到**复化中点公式**、**复化梯形公式**和**复化辛普森公式**（对辛普森公式，$n$必须是偶数，子区间两两成组）：

$$
\begin{aligned}
M_h &= h\sum_{i=1}^{n}f\!\left(x_{i-1} + \tfrac h2\right), \\
T_h &= h\left(\tfrac12f(x_0) + f(x_1) + f(x_2) + \cdots + f(x_{n-1}) + \tfrac12f(x_n)\right), \\
S_h &= \frac h3\left(f(x_0) + 4f(x_1) + 2f(x_2) + 4f(x_3) + \cdots + 2f(x_{n-2}) + 4f(x_{n-1}) + f(x_n)\right).
\end{aligned}
$$

```python
import numpy as np

def trapezoid(f, a, b, n):
    x = np.linspace(a, b, n + 1)
    y = f(x)
    return (b - a) / n * (y.sum() - 0.5 * (y[0] + y[-1]))

def simpson(f, a, b, n):          # n 必须为偶数
    x = np.linspace(a, b, n + 1)
    w = np.ones(n + 1); w[1:-1:2] = 4; w[2:-1:2] = 2
    return (b - a) / (3 * n) * (w * f(x)).sum()
```

::: theorem 复化公式的误差 {#thm-composite}
若$f \in C^2[a, b]$，则存在$\xi, \xi' \in [a, b]$，使得

$$
I - M_h = \frac{(b-a)h^2}{24}f''(\xi), \qquad I - T_h = -\frac{(b-a)h^2}{12}f''(\xi') ,
$$

若$f \in C^4[a, b]$且$n$为偶数，则$I - S_h = -\frac{(b-a)h^4}{180}f^{(4)}(\eta)$，其中$\eta \in [a, b]$。
:::

::: proof
对梯形公式，在每个子区间上应用[[#thm-basic-errors]]，得到误差$-\frac{h^3}{12}f''(\xi_i)$，$i = 1, \dots, n$。它们的和为$-\frac{h^3}{12}\sum_if''(\xi_i) = -\frac{h^3n}{12}\bar c$，其中平均值$\bar c = \frac1n\sum f''(\xi_i)$介于$f''$的最小值与最大值之间，所以由介值定理，$\bar c = f''(\xi')$。由于$nh = b - a$，误差为$-\frac{(b-a)h^2}{12}f''(\xi')$。中点公式的论证完全相同，只是系数换成$\frac1{24}$。对辛普森公式，共有$\frac n2$组宽为$2h$的子区间，每组的误差为$-\frac{(2h)^5}{2880}f^{(4)}(\eta_i) = -\frac{h^5}{90}f^{(4)}(\eta_i)$，同样取平均，得$-\frac{n}{2}\cdot\frac{h^5}{90}f^{(4)}(\eta) = -\frac{(b-a)h^4}{180}f^{(4)}(\eta)$。
:::

所以复化中点公式和复化梯形公式像$h^2$那样收敛，而辛普森公式像$h^4$那样收敛：把$h$减半，误差大约分别除以$4$和$16$。对检验积分：

## 理查森外推与龙贝格求积

梯形公式的误差不只是以$h^2$的某个倍数为界；对于光滑的$f$，它有一个按$h$的偶次幂的精确展开式，即**欧拉-麦克劳林公式**：

$$
T_h = I + c_1h^2 + c_2h^4 + c_3h^6 + \cdots, \qquad c_1 = \frac{f'(b) - f'(a)}{12},\quad c_2 = -\frac{f'''(b) - f'''(a)}{720}, \ \dots
$$ {#eq-euler-maclaurin}

（这些常数涉及伯努利数和端点处的奇数阶导数；证明见 Süli 与 Mayers 的书第7章。）这些常数与$h$无关，这一点可以加以利用。对检验积分，$c_1 = \frac{-2e^{-1} - 0}{12} = -0.0613$；事实上，当$n = 64$时，预测值$T_h - I \approx c_1h^2 = -1.497\times10^{-5}$与表中的数值有四位吻合。

**理查森外推。**由于$T_h = I + c_1h^2 + O(h^4)$，$T_{h/2} = I + \frac14c_1h^2 + O(h^4)$，组合

$$
\frac{4T_{h/2} - T_h}{3} = I + O(h^4)
$$

消去了$h^2$项。简短的计算（[[#exr-simpson-richardson]]）表明，这个组合恰好就是辛普森公式$S_{h/2}$。重复这一思想，可以依次消去$h^4$、$h^6$、…各项。

::: algorithm 龙贝格求积 {#alg-romberg}
对$k = 0, 1, \dots, K$，令$R_{k,0} = T_{h_k}$，其中$h_k = (b - a)/2^k$（每个新的梯形和都可以重复利用此前所有的函数值）。对$j = 1, \dots, k$，令

$$
R_{k,j} = R_{k,j-1} + \frac{R_{k,j-1} - R_{k-1,j-1}}{4^j - 1}.
$$

对光滑的$f$，$R_{k,j} = I + O(h_k^{2j+2})$。返回$R_{K,K}$。
:::

```python
def romberg(f, a, b, K):
    R = [[trapezoid(f, a, b, 1)]]
    for k in range(1, K + 1):
        row = [trapezoid(f, a, b, 2**k)]          # （可以重复利用旧的函数值）
        for j in range(1, k + 1):
            row.append(row[j-1] + (row[j-1] - R[k-1][j-1]) / (4**j - 1))
        R.append(row)
    return R[K][K]
```

::: remark 当展开式不成立时
理查森外推以误差展开式[[#eq-euler-maclaurin]]为前提。若$f$在$[a, b]$上不光滑——例如$\int_0^1\sqrt x\,dx$，其中$f'$在$0$处为无穷大——误差的表现就像$h^{1.5}$而不是$h^2$（对$\sqrt x$，辛普森公式的误差每次把$h$减半只按因子$2^{1.5} \approx 2.8$缩小：$3.6\times10^{-3}$、$1.3\times10^{-3}$、$4.5\times10^{-4}$），而假定展开式按$h^2, h^4, \dots$进行的外推也就无济于事。反过来，若$f$光滑且是以$b - a$为周期的**周期**函数，则[[#eq-euler-maclaurin]]中所有的端点项都为零，普通的梯形公式比$h$的任何幂次收敛得都快：对$\int_0^{2\pi}e^{\cos x}\,dx = 7.954\,926\,521\ldots$，用$4$个点时误差为$3.4\times10^{-2}$，用$8$个点时为$1.3\times10^{-6}$，用$16$个点时为$2\times10^{-15}$。这就是梯形公式成为周期被积函数和傅里叶系数计算的首选方法的原因（[[#exr-periodic]]）。
:::

::: widget quadrature
f: exp(cos(x))
a: 0
b: 2pi
methods: trap; simpson; gauss
caption: 周期被积函数$e^{\cos x}$在一个完整周期上的积分。在这里，不起眼的梯形公式成了冠军：它的误差比$n$的任何幂次下降得都快，在$n = 16$个子区间（也就是$16$个函数值）时就达到了舍入误差的水平。复化$2$点高斯公式要达到同样的精度，大约需要两倍的函数值；而对各点不等权加权的辛普森公式，则远远落后于它本想改进的梯形公式。
:::

::: example 消除奇点 {#ex-singular}
精确地计算$\displaystyle\int_0^1\frac{\cos x}{\sqrt x}\,dx$。
::: solution
被积函数在$x = 0$处为无穷大，所以梯形公式和辛普森公式根本无法应用（它们需要$f(0)$），而中点公式由于奇点的存在只像$h^{1/2}$那样收敛。作代换$x = t^2$，$dx = 2t\,dt$，就可以消除奇点：

$$
\int_0^1\frac{\cos x}{\sqrt x}\,dx = \int_0^1\frac{\cos(t^2)}{t}\,2t\,dt = 2\int_0^1\cos(t^2)\,dt ,
$$

新积分的被积函数是光滑的。对新积分用复化辛普森公式，取$16$、$32$和$64$个子区间时误差分别为$2.9\times10^{-8}$、$2.4\times10^{-9}$和$1.6\times10^{-10}$，每次减半时的缩小因子逐渐趋于预期的$16$；积分值为$1.809\,048\,475\,8\ldots$。在积分之前先分析被积函数——并通过变换消除奇点——通常比选择哪个求积公式更重要。
:::

## 高斯求积

到目前为止，所有求积公式的节点都是事先固定的。具有$n$个节点的求积公式有$2n$个自由参数——$n$个节点和$n$个权——所以我们可以期望它对次数不超过$2n - 1$的多项式精确成立，这些多项式构成一个$2n$维空间。高斯证明了这是可以做到的，而且这已是最好的结果。

::: proposition 代数精度的上限 {#prop-gauss-limit}
任何具有$n$个节点的求积公式$\sum_{i=1}^nw_if(x_i)$都不能在$[a, b]$上精确地积分所有$2n$次多项式。
:::

::: proof
令$q(x) = \prod_{i=1}^n(x - x_i)^2$，其次数为$2n$。由于$q \ge 0$且$q$不恒为零，有$\int_a^bq > 0$；但求积公式给出$\sum w_iq(x_i) = 0$。
:::

最优的节点是**勒让德多项式**$P_0 = 1$，$P_1 = x$，$P_2 = \frac12(3x^2 - 1)$，$P_3 = \frac12(5x^3 - 3x)$，…的零点，这些多项式在$[-1, 1]$上**正交**：

$$
\int_{-1}^1P_m(x)P_n(x)\,dx = 0 \qquad (m \ne n).
$$

它们可以通过对$1, x, x^2, \dots$在内积$\inner fg = \int_{-1}^1fg$下施行格拉姆-施密特正交化过程得到（[[linear-algebra/inner-products]]）。特别地，$P_n$的次数为$n$，且与每个次数小于$n$的多项式正交。

::: theorem 高斯-勒让德求积 {#thm-gauss}
对$n \ge 1$，勒让德多项式$P_n$有$n$个不同的零点$x_1, \dots, x_n$，且都位于$(-1, 1)$内。取权$w_i = \int_{-1}^1\ell_i(x)\,dx$，则求积公式

$$
G_n(f) = \sum_{i=1}^nw_if(x_i)
$$

在$[-1, 1]$上精确地积分每个次数至多为$2n - 1$的多项式，并且所有的权都是正的。
:::

::: proof
**零点。**设$t_1 < \cdots < t_k$是$(-1, 1)$中$P_n$变号的点。若$k < n$，则多项式$P_n(x)\prod_j(x - t_j)$在$(-1, 1)$上不变号且不恒为零，所以它的积分不为零；但$\prod_j(x - t_j)$的次数为$k < n$，所以由正交性，该积分为$0$。因此$k \ge n$；又因为$P_n$的次数为$n$，所以它恰有$n$个单零点，且都位于$(-1, 1)$内。

**精确性。**设$f$是次数至多为$2n - 1$的多项式。用$P_n$去除：$f = qP_n + r$，其中$q$和$r$的次数都至多为$n - 1$。由正交性，$\int_{-1}^1qP_n = 0$，所以$\int f = \int r$。另一方面，由于$P_n(x_i) = 0$，有$f(x_i) = r(x_i)$，所以$G_n(f) = G_n(r)$。最后，$G_n$是具有$n$个节点的插值型求积公式，因而对次数至多为$n - 1$的$r$精确成立：$G_n(f) = G_n(r) = \int r = \int f$。

**权为正。**$\ell_i^2$的次数为$2n - 2 \le 2n - 1$，所以它被精确地积分：$0 < \int_{-1}^1\ell_i^2 = \sum_jw_j\ell_i(x_j)^2 = w_i$。
:::

对一般区间，作代换$x = \frac{a+b}{2} + \frac{b-a}{2}t$：$\int_a^bf(x)\,dx \approx \frac{b-a}{2}\sum_iw_if\left(\frac{a+b}{2} + \frac{b-a}{2}x_i\right)$。$[-1, 1]$上的前几个求积公式为：

| $n$ | 节点$x_i$ | 权$w_i$ | 代数精度 |
|---|---|---|---|
| $1$ | $0$ | $2$ | $1$（中点公式） |
| $2$ | $\pm\frac{1}{\sqrt3}$ | $1,\ 1$ | $3$ |
| $3$ | $0,\ \pm\sqrt{3/5}$ | $\frac89,\ \frac59,\ \frac59$ | $5$ |

在实践中，节点和权是作为一个对称三对角矩阵的特征值和特征向量的分量计算出来的（戈卢布-韦尔施（Golub–Welsch）算法）；`numpy.polynomial.legendre.leggauss(n)`会返回它们。对$f \in C^{2n}[a, b]$，误差为

$$
\int_a^bf - G_n(f) = \frac{(b-a)^{2n+1}(n!)^4}{(2n+1)\bigl((2n)!\bigr)^3}f^{(2n)}(\xi),
$$

当$f$的各阶导数大小适中时，随着$n$的增大，它会以惊人的速度缩小。

::: example 用高斯求积计算检验积分 {#ex-gauss}
对$n = 1, \dots, 6$，把$n$点高斯-勒让德公式应用于$\int_0^1e^{-x^2}\,dx$。
::: solution
把$[-1, 1]$映射到$[0, 1]$之后，计算值和误差$G_n - I$如下：

| $n$ | $1$ | $2$ | $3$ | $4$ | $5$ | $6$ |
|---|---|---|---|---|---|---|
| $G_n$ | $0.778\,801$ | $0.746\,594\,7$ | $0.746\,814\,58$ | $0.746\,824\,468$ | $0.746\,824\,126\,8$ | $0.746\,824\,132\,89$ |
| 误差 | $3.2\times10^{-2}$ | $-2.3\times10^{-4}$ | $-9.6\times10^{-6}$ | $3.4\times10^{-7}$ | $-6.0\times10^{-9}$ | $7.8\times10^{-11}$ |

六次函数求值就给出了十位正确数字——与用约$28\,000$个子区间的梯形公式一样精确，也比用$64$个子区间的辛普森公式（$65$次求值，误差$4.9\times10^{-10}$）更好。在这里，每增加一个节点就多得到一位半到两位数字。
:::

::: quiz
$3$点高斯-勒让德公式的代数精度是多少？同样使用$3$个点的辛普森公式的代数精度又是多少？
- [ ] $2$和$2$
- [ ] $3$和$3$
- [x] $5$和$3$
- [ ] $6$和$4$
::: solution
$n$点高斯公式对次数不超过$2n - 1 = 5$的多项式精确成立（[[#thm-gauss]]），而且任何$3$点公式都不可能做得更好（[[#prop-gauss-limit]]）。节点预先规定为等距的辛普森公式达到$3$次代数精度——得益于对称性，比它的插值抛物线高一次。
:::
:::

::: quiz
对某个积分，复化梯形公式在$n = 64$时的误差为$1.5\times10^{-5}$。假定被积函数是光滑的，在$n = 128$时你预期误差大约是多少？理查森组合$\frac{4T_{128} - T_{64}}{3}$的误差又应当是多少？
- [ ] $7.5\times10^{-6}$，以及约$10^{-6}$
- [x] $3.75\times10^{-6}$，以及小得多（$h^4$量级）
- [ ] $3.75\times10^{-6}$，以及恰好为$0$
- [ ] $1.5\times10^{-5}$，因为误差与$n$无关
::: solution
梯形公式的误差为$c_1h^2 + O(h^4)$，所以把$h$减半，误差大约除以$4$。理查森组合消去了$c_1h^2$项，剩下$O(h^4)$的误差（它就是$128$个子区间的辛普森公式），通常要小几个数量级——但由于$c_2h^4$项的存在，它并不恰好为零。
:::

::: application 软件中的自适应求积
像`scipy.integrate.quad`（建立在1983年的 QUADPACK 软件包之上）这样的库函数，以自适应的方式把这些思想结合起来。它们在每个子区间上应用一对精度不同的求积公式——例如一个$10$点高斯公式和一个重复利用其节点的$21$点高斯-克朗罗德（Gauss–Kronrod）公式——并把两者之差作为误差估计。估计误差过大的子区间被一分为二并重新处理，于是计算量集中在被积函数难以处理的地方（奇点、尖峰或快速振荡附近），而光滑的区域只需少量求值即可处理。
:::

::: history
梯形公式和中点公式由来已久。牛顿（Newton）在《微分法》（*Methodus differentialis*，1711年）中、罗杰·科茨（Roger Cotes）在其身后于1722年出版的《度量的和谐》（*Harmonia mensurarum*）中，推导出了通过对等距点上的插值多项式积分而得到的求积公式。如今以托马斯·辛普森（Thomas Simpson）命名的公式由他于1743年发表，但早在17世纪，博纳文图拉·卡瓦列里（Bonaventura Cavalieri）和詹姆斯·格雷戈里（James Gregory）就已经使用过它。卡尔·弗里德里希·高斯（Carl Friedrich Gauss）于1814年找到了最优的求积公式，卡尔·雅可比（Carl Jacobi）则于1826年把它们与正交多项式联系起来。欧拉（Euler）（约1735年）和麦克劳林（Maclaurin）（1742年）发现了[[#eq-euler-maclaurin]]背后的求和公式。刘易斯·弗赖伊·理查森（Lewis Fry Richardson）于1927年以“延迟逼近极限”之名倡导外推法，维尔纳·龙贝格（Werner Romberg）则于1955年提出了系统的外推表。
:::

## 后续内容

多维积分可以用一维求积公式的乘积来计算，但计算量随维数呈指数增长；在高维情形，取而代之的是蒙特卡罗方法，其误差无论维数多少都像$N^{-1/2}$那样减小（[[probability/limit-theorems]]）。求积公式是求解微分方程的龙格-库塔法的引擎——龙格-库塔法就是把求积公式应用于$y(t + h) = y(t) + \int_t^{t+h}f(s, y(s))\,ds$（[[numerical-analysis/numerical-odes]]）——也是有限元方法的引擎。高斯求积背后的正交多项式还会在施图姆-刘维尔理论中再次出现（[[pde/sturm-liouville]]）。

::: summary
- 若求积公式$\sum w_if(x_i)$能精确地积分次数不超过$d$的多项式，就称它具有$d$次代数精度；对插值多项式积分就得到牛顿-科茨公式。
- 基本公式的误差：中点公式为$\frac{(b-a)^3}{24}f''$，梯形公式为$-\frac{(b-a)^3}{12}f''$，辛普森公式为$-\frac{(b-a)^5}{2880}f^{(4)}$；对称性使中点公式和辛普森公式多得一次代数精度。
- 复化公式像$h^2$（中点公式、梯形公式）和$h^4$（辛普森公式）那样收敛；把$h$减半时，应检验观察到的比值是否为$4$和$16$。
- 对光滑的$f$，$T_h = I + c_1h^2 + c_2h^4 + \cdots$（欧拉-麦克劳林公式）；理查森外推逐项消去这些项，龙贝格求积把这一过程组织成一张表。对周期被积函数，梯形公式本身就具有谱精度。
- 高斯-勒让德公式以勒让德多项式的零点为节点；具有$n$个节点时，它的代数精度为$2n - 1$（可能的最大值），并且权都是正的。
- 应避免高阶的等距节点公式；自适应程序把高斯-克朗罗德公式对与局部细分结合起来。
:::

::: exercise 对三次函数用梯形公式 {level=1 check="8"}
对$\int_0^2x^3\,dx$应用基本梯形公式，并与精确值$4$比较。
::: solution
$\frac{2}{2}\bigl(0^3 + 2^3\bigr) = 8$。误差$4 - 8 = -4$与$-\frac{(b-a)^3}{12}f''(\xi) = -\frac{8}{12}\cdot6\xi = -4\xi$在$\xi = 1$时的值一致。
:::

::: exercise 对三次函数用辛普森公式 {level=1 check="4"}
对$\int_0^2x^3\,dx$应用辛普森公式。
::: solution
$\frac{2}{6}\bigl(0 + 4\cdot1^3 + 2^3\bigr) = \frac13\cdot12 = 4$，正是精确值：辛普森公式具有$3$次代数精度（而且这里确实有$f^{(4)} = 0$）。
:::

::: exercise 一个复化梯形和 {level=1 check="3/8"}
取$h = \frac12$，用复化梯形公式计算$\int_0^1x^2\,dx$的近似值。
::: solution
$T_{1/2} = \frac12\left(\frac12\cdot0 + \frac14 + \frac12\cdot1\right) = \frac12\cdot\frac34 = \frac38$。误差为$\frac13 - \frac38 = -\frac1{24}$，与$-\frac{(b-a)h^2}{12}f'' = -\frac{1\cdot\frac14}{12}\cdot2 = -\frac1{24}$完全一致（这里$f''$是常数）。
:::
:::

::: exercise 为中点公式选取 n {level=2 check="289"}
对$\int_1^2\frac{dx}{x}$，复化中点公式需要多少个子区间才能保证误差小于$10^{-6}$？
::: solution
在$[1, 2]$上$f''(x) = \frac{2}{x^3} \le 2$，所以由[[#thm-composite]]，误差至多为$\frac{1\cdot h^2}{24}\cdot2 = \frac{h^2}{12}$。需要$h^2 \le 1.2\times10^{-5}$，即$h \le 0.003\,464$，所以$n \ge 288.7$：取$n = 289$。
:::
:::

::: exercise 设计两点求积公式 {level=2 check="1/sqrt(3)"}
求$\alpha > 0$和$w$，使得$\int_{-1}^1f(x)\,dx \approx w\bigl(f(-\alpha) + f(\alpha)\bigr)$对所有次数至多为$3$的多项式精确成立。
::: solution
由对称性，对任意$\alpha, w$，该公式对奇函数（$x$和$x^3$）都精确成立。由对$1$精确得$2w = 2$，所以$w = 1$；由对$x^2$精确得$2\alpha^2 = \frac23$，所以$\alpha = \frac{1}{\sqrt3}$。这就是$2$点高斯-勒让德公式，而$\pm\frac1{\sqrt3}$正是$P_2 = \frac12(3x^2 - 1)$的零点。
:::
:::

::: exercise 对指数函数用两点高斯公式 {level=2}
用$2$点高斯公式近似计算$\int_0^1e^x\,dx = e - 1$，并把它的误差与使用三个点的辛普森公式（同样对三次多项式精确）的误差相比较。
::: solution
把$t \in [-1, 1]$映射为$x = \frac{1 + t}{2}$：$\int_0^1e^x\,dx \approx \frac12\left(e^{(1 - 1/\sqrt3)/2} + e^{(1 + 1/\sqrt3)/2}\right) = \frac12(1.235\,314 + 2.200\,479) = 1.717\,896$，误差为$(e - 1) - 1.717\,896 = 3.9\times10^{-4}$。辛普森公式：$\frac16(1 + 4e^{1/2} + e) = 1.718\,861$，误差为$-5.8\times10^{-4}$。只用两次求值的高斯公式比用三次求值的辛普森公式更精确。
:::
:::

::: exercise 手算龙贝格外推 {level=2}
对$\int_0^1e^{-x^2}\,dx$，$T_1 = 0.683\,940$，$T_{1/2} = 0.731\,370$。计算理查森外推值$\frac{4T_{1/2} - T_1}{3}$，验证它等于$h = \frac12$的辛普森公式，并估计$T_{1/2}$的误差。
::: solution
$\frac{4(0.731\,370) - 0.683\,940}{3} = \frac{2.925\,480 - 0.683\,940}{3} = 0.747\,180$，这正是[[#ex-basic]]中辛普森公式的值。由于$T_h - I \approx c_1h^2$，$T_{h/2} - I \approx \frac14c_1h^2$，有$T_h - T_{h/2} \approx \frac34c_1h^2$，所以$T_{1/2}$的误差的大小约为$\frac{T_{1/2} - T_1}{3} = 0.0158$，即$I \approx T_{1/2} + 0.0158$。（真实误差为$0.0155$。）
:::
:::

::: exercise 辛普森公式是外推后的梯形公式 {level=3 #exr-simpson-richardson}
证明：对任何函数，$\frac{4T_{h/2} - T_h}{3} = S_{h/2}$都精确成立，其中$T_h$使用$n$个子区间，$S_{h/2}$是使用$2n$个子区间的复化辛普森公式。
::: solution
对$j = 0, \dots, 2n$，令$y_j = f(a + jh/2)$。则$T_h = h\left(\frac12y_0 + y_2 + y_4 + \cdots + y_{2n-2} + \frac12y_{2n}\right)$，$T_{h/2} = \frac h2\left(\frac12y_0 + y_1 + y_2 + \cdots + y_{2n-1} + \frac12y_{2n}\right)$。因此

$$
4T_{h/2} - T_h = h\Bigl(y_0 + 2\sum_{j \text{ 为奇数}}y_j + 2\sum_{\substack{j \text{ 为偶数}\\ 0<j<2n}}y_j + y_{2n}\Bigr) - h\Bigl(\tfrac12y_0 + \sum_{\substack{j \text{ 为偶数}\\0<j<2n}}y_j + \tfrac12y_{2n}\Bigr) = h\Bigl(\tfrac12y_0 + 2\sum_{\text{奇数}}y_j + \sum_{\text{内部偶数}}y_j + \tfrac12y_{2n}\Bigr).
$$

除以$3$，得$\frac{h}{6}\left(y_0 + 4\sum_{\text{奇数}}y_j + 2\sum_{\text{内部偶数}}y_j + y_{2n}\right)$，这正是间距为$\frac h2$的$S_{h/2}$（因为$\frac{h/2}{3} = \frac h6$）。
:::
:::

::: exercise 周期函数的梯形公式 {level=3 #exr-periodic}
令$T_n(f) = \frac{2\pi}{n}\sum_{j=0}^{n-1}f\left(\frac{2\pi j}{n}\right)$。证明：只要$k$是满足$0 \le k < n$的整数，对$f(x) = \cos(kx)$和$f(x) = \sin(kx)$都精确地有$T_n(f) = \int_0^{2\pi}f(x)\,dx$；并解释为什么这使梯形公式对光滑周期函数极其精确。
::: hint
利用$e^{ikx}$，并对公比为$\omega = e^{2\pi ik/n}$的几何级数求和。
:::
::: solution
当$k = 0$时，两边都等于$2\pi$（对$\cos 0 = 1$）或$0$。当$1 \le k < n$时，$\int_0^{2\pi}e^{ikx}\,dx = 0$，而$T_n(e^{ikx}) = \frac{2\pi}{n}\sum_{j=0}^{n-1}\omega^j$，其中$\omega = e^{2\pi ik/n} \ne 1$（因为$n$不整除$k$）；由于$\omega^n = e^{2\pi ik} = 1$，这个几何级数的和为$\frac{\omega^n - 1}{\omega - 1} = 0$。取实部和虚部，即得对$\cos kx$和$\sin kx$的精确性。光滑周期函数的傅里叶级数的系数比$k$的任何幂次衰减得都快（若$f$解析，则呈指数衰减）（[[pde/fourier-series]]）；梯形公式能精确地积分前$n$个谐波，所以它的误差只来自迅速衰减的高频系数。
:::

::: exercise 高斯求积的权与代数精度 {level=3}
直接验证：节点为$0, \pm\sqrt{3/5}$、权为$\frac89, \frac59, \frac59$的$3$点公式在$[-1, 1]$上能精确地积分$1, x^2$和$x^4$，但不能精确地积分$x^6$；并解释为什么它因此对所有次数至多为$5$的多项式精确成立。
::: solution
由对称性，奇次幂被精确地积分（两边都为零）。对$1$：$\frac89 + \frac59 + \frac59 = 2 = \int_{-1}^11$。对$x^2$：$2\cdot\frac59\cdot\frac35 = \frac23 = \int x^2$。对$x^4$：$2\cdot\frac59\cdot\frac{9}{25} = \frac25 = \int x^4$。对$x^6$：$2\cdot\frac59\cdot\frac{27}{125} = \frac{6}{25} = 0.24$，而$\int_{-1}^1x^6 = \frac27 \approx 0.286$。由线性性，该公式对$1, x, \dots, x^5$的所有线性组合，即所有次数至多为$5$的多项式都精确成立，但对$x^6$不成立：它的代数精度为$5 = 2\cdot3 - 1$。
:::
