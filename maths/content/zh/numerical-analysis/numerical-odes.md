大幅摆动的单摆的运动、传染病的传播、化工厂中的化学反应、航天器的轨道：它们都由初值问题

$$
\mathbf y'(t) = \mathbf f\bigl(t, \mathbf y(t)\bigr), \qquad \mathbf y(t_0) = \mathbf y_0,
$$ {#eq-ivp}

所支配，而其中几乎没有一个能用公式求解。当$\mathbf f$关于$\mathbf y$利普希茨连续时，存在唯一性定理（[[ode/existence-uniqueness]]）保证了解的存在，但要知道解**究竟是什么**，就必须把它计算出来。数值方法在**步长**为$h$的网格$t_n = t_0 + nh$上给出近似值$\mathbf y_n \approx \mathbf y(t_n)$。

在[[calculus-2/intro-odes]]一章中，我们见过最简单的方法——欧拉法，并看到它的误差与$h$成正比。本章将系统地建立这方面的理论。我们定义局部截断误差，并证明它控制着整体误差；我们推导龙格-库塔法，直到一个世纪以来一直是默认选择的经典四阶方法；我们还将遇到使这门学科变得微妙的现象——**刚性**：此时显式方法被迫采用小得荒谬的步长，不是为了精度，而是为了**稳定性**，而隐式方法则能解决这一困难。为简单起见，我们只写出标量方程；把绝对值换成范数，一切都可以推广到方程组。

## 单步法及其误差

::: definition 单步法、截断误差与阶 {#def-one-step}
**单步法**按$y_{n+1} = y_n + h\,\Phi(t_n, y_n; h)$进行计算，其中$\Phi$是某个增量函数。它在第$n + 1$步的**局部截断误差**是**精确**解不满足该方法的程度（按单位步长计）：

$$
\tau_{n+1} = \frac{y(t_{n+1}) - y(t_n)}{h} - \Phi\bigl(t_n, y(t_n); h\bigr).
$$

如果当$h \to 0$时$\max_n\abs{\tau_n} \to 0$，就称该方法是**相容**的；如果对每个充分光滑的$f$，对所有$n$和所有充分小的$h$都有$\abs{\tau_n} \le Ch^p$，就称该方法的**阶**为$p$。**整体误差**定义为$e_n = y(t_n) - y_n$。
:::

对于**欧拉法**，$\Phi = f(t_n, y_n)$，由泰勒定理（[[calculus-2/taylor-series#thm-taylor]]）得$y(t_{n+1}) = y(t_n) + hy'(t_n) + \frac{h^2}{2}y''(\xi_n)$，其中$y'(t_n) = f(t_n, y(t_n))$，所以

$$
\tau_{n+1} = \frac h2y''(\xi_n), \qquad \abs{\tau_{n+1}} \le \frac{M_2h}{2}, \quad M_2 = \max\abs{y''} .
$$

欧拉法是相容的，并且是$1$阶的。关键问题在于：每一步的小截断误差累加起来，是否仍是小的整体误差，还是可能被放大？下面的定理表明，当增量函数满足利普希茨条件时，它们至多被放大一个固定的倍数。

::: theorem 单步法的收敛性 {#thm-convergence}
设$\Phi$关于$y$利普希茨连续：$\abs{\Phi(t, u; h) - \Phi(t, v; h)} \le L\abs{u - v}$，并设对所有满足$t_n \le t_{\text{end}}$的$n$都有$\abs{\tau_n} \le T$。若$y_0 = y(t_0)$，则对所有这样的$n$，

$$
\abs{e_n} \le \frac{T}{L}\left(e^{L(t_n - t_0)} - 1\right).
$$ {#eq-global-bound}

特别地，增量函数满足利普希茨条件的$p$阶方法在每个有界区间上的整体误差为$O(h^p)$。
:::

::: proof
由$\tau_{n+1}$的定义，精确解满足$y(t_{n+1}) = y(t_n) + h\Phi(t_n, y(t_n); h) + h\tau_{n+1}$。减去$y_{n+1} = y_n + h\Phi(t_n, y_n; h)$，得

$$
e_{n+1} = e_n + h\bigl[\Phi(t_n, y(t_n); h) - \Phi(t_n, y_n; h)\bigr] + h\tau_{n+1}, \qquad \abs{e_{n+1}} \le (1 + hL)\abs{e_n} + hT .
$$

由于$e_0 = 0$，用归纳法得$\abs{e_n} \le hT\sum_{k=0}^{n-1}(1 + hL)^k = hT\frac{(1 + hL)^n - 1}{hL} = \frac TL\bigl((1 + hL)^n - 1\bigr)$。最后，$1 + hL \le e^{hL}$，所以$(1 + hL)^n \le e^{nhL} = e^{L(t_n - t_0)}$。
:::

因子$e^{L(t_n - t_0)}$反映了微分方程本身的敏感性：相邻的解至多像$e^{Lt}$那样相互分离。对于欧拉法，$L$就是$f$的利普希茨常数，$T = \frac{M_2h}{2}$，所以

$$
\abs{y(t_n) - y_n} \le \frac{M_2h}{2L}\left(e^{L(t_n - t_0)} - 1\right).
$$

::: example 欧拉法的误差界 {#ex-euler-bound}
对$y' = y$，$y(0) = 1$，给出欧拉法在$t = 1$处的误差界，并与实际误差比较。
::: solution
这里$f(t, y) = y$满足利普希茨条件，$L = 1$，并且在$[0, 1]$上$\abs{y''} = e^t \le e = M_2$。误差界为

$$
\abs{e(1)} \le \frac{eh}{2}\left(e^1 - 1\right) \approx 2.34h .
$$

欧拉法给出$y_n = (1 + h)^n$，在$t = 1$处即为$(1 + h)^{1/h}$；当$h = 0.1$、$0.05$和$0.025$时，实际误差$e - (1 + h)^{1/h}$分别为$0.125$、$0.065$和$0.033$：约为误差界$0.234$、$0.117$、$0.058$的一半，并且正如定理所预言的那样，随$h$减半而减半。这个界悲观了一个常数倍，但它给出的阶是对的——而这正是选取$h$时最重要的。
:::
:::

::: warning 局部阶与整体阶相差一
欧拉法**单独一步**所产生的误差为$\frac{h^2}{2}y''$，是$h^2$阶的；但到达一个固定的时刻需要$\frac{t - t_0}{h}$步，所以整体误差是$h$阶的。各书的约定不尽相同：有些书把$h\tau_n$称为局部误差，并说它是$O(h^{p+1})$。按照这里使用的定义（按单位步长计的截断误差），$p$阶方法的$\tau = O(h^p)$，**并且**整体误差也是$O(h^p)$。用数值实验估计阶时，一定要在固定的时刻测量整体误差。
:::

::: remark 舍入误差决定了误差的下限
[[#thm-convergence]]假定运算是精确的。在浮点运算中，每一步还会引入相对大小约为$u$的舍入误差，经过$\frac{t - t_0}{h}$步，这些误差累积起来大约为$\frac{u}{h}$（如果它们表现得像随机误差，则约为$\frac{u}{\sqrt h}$）。因此总误差的表现形如$Ch^p + \frac{u}{h}$，这与[[numerical-analysis/floating-point#thm-forward-difference]]中差商的截断误差与舍入误差之间的竞争如出一辙。对于双精度下的欧拉法，所能达到的最佳误差约为$10^{-8}$，需要大约$10^8$步；而对于 RK4，截断误差下降得非常快，舍入误差很少会成为问题。这是宁可采用高阶方法、也不采用极小步长的又一个理由。
:::

## 龙格-库塔法

欧拉法只用到每一步起点处的斜率。龙格-库塔法在一步之内的若干点处取样斜率，并把这些样本组合起来，使之与精确解的泰勒展开在更高的阶上吻合——而且完全不需要对$f$求导。

::: definition 显式龙格-库塔法 {#def-rk}
显式$s$级**龙格-库塔法**按下式计算：

$$
k_i = f\Bigl(t_n + c_ih,\ y_n + h\sum_{j<i}a_{ij}k_j\Bigr), \quad i = 1, \dots, s, \qquad y_{n+1} = y_n + h\sum_{i=1}^sb_ik_i ,
$$

其系数通常列成**布彻（Butcher）表**：左边是$c_i$，它们旁边是严格下三角矩阵$(a_{ij})$，下面是权$b_i$。
:::

对欧拉法最简单的改进是**休恩（Heun）法**（显式梯形法）：先用一步欧拉法预测终点，再取两端斜率的平均，

$$
k_1 = f(t_n, y_n), \qquad k_2 = f(t_n + h,\ y_n + hk_1), \qquad y_{n+1} = y_n + \frac h2(k_1 + k_2).
$$

另一个改进是**中点法**：$k_2 = f\left(t_n + \frac h2, y_n + \frac h2k_1\right)$，$y_{n+1} = y_n + hk_2$。两者都是二阶的，下面的定理解释了其中的原因。

::: theorem 二级方法的阶条件 {#thm-rk2}
二级方法$y_{n+1} = y_n + h(b_1k_1 + b_2k_2)$（其中$k_1 = f(t_n, y_n)$，$k_2 = f(t_n + c_2h, y_n + a_{21}hk_1)$）对每个光滑的$f$都是$2$阶的，当且仅当

$$
b_1 + b_2 = 1, \qquad b_2c_2 = \tfrac12, \qquad b_2a_{21} = \tfrac12 .
$$
:::

::: proof
用$f$、$f_t$、$f_y$表示在$(t_n, y(t_n))$处的值。用链式法则对$y' = f(t, y)$求导得$y'' = f_t + f_yf$，所以由泰勒定理，

$$
\frac{y(t_{n+1}) - y(t_n)}{h} = f + \frac h2\left(f_t + f_yf\right) + O(h^2).
$$

用二元泰勒定理展开$k_2$，得$k_2 = f + c_2hf_t + a_{21}hff_y + O(h^2)$，所以$\Phi = b_1k_1 + b_2k_2 = (b_1 + b_2)f + b_2h\left(c_2f_t + a_{21}f_yf\right) + O(h^2)$。两式相减，得

$$
\tau = (1 - b_1 - b_2)f + h\left[\left(\tfrac12 - b_2c_2\right)f_t + \left(\tfrac12 - b_2a_{21}\right)f_yf\right] + O(h^2).
$$

如果三个条件都成立，那么对每个$f$它都是$O(h^2)$。反之，分别取$f = 1$、$f = t$和$f = y$（它们使$f_t$或$f_yf$单独非零），可知每个条件都是必要的。
:::

休恩法的系数为$b_1 = b_2 = \frac12$，$c_2 = a_{21} = 1$；中点法的系数为$b_1 = 0$，$b_2 = 1$，$c_2 = a_{21} = \frac12$。要吻合更多的项，就需要更多的级。库塔的**经典四阶方法**是其中最著名的结果：

$$
\begin{aligned}
k_1 &= f(t_n, y_n), & k_2 &= f\left(t_n + \tfrac h2,\ y_n + \tfrac h2k_1\right), \\
k_3 &= f\left(t_n + \tfrac h2,\ y_n + \tfrac h2k_2\right), & k_4 &= f(t_n + h,\ y_n + hk_3), \\
y_{n+1} &= y_n + \tfrac h6\left(k_1 + 2k_2 + 2k_3 + k_4\right). & &
\end{aligned}
$$ {#eq-rk4}

当$f$不依赖于$y$时，它就化为计算$\int_{t_n}^{t_{n+1}}f(t)\,dt$的辛普森公式（[[numerical-analysis/numerical-integration]]）。要验证它对一般的$f$是$4$阶的，就要吻合泰勒展开中的八项（布彻的有根树理论把这项工作组织得井井有条；参见 Hairer、Nørsett 和 Wanner 的《常微分方程解法 I》（Solving Ordinary Differential Equations I）第 II 章）。对于线性方程$y' = \lambda y$，验证很容易：记$z = h\lambda$，则$k_1 = \lambda y_n$，$k_2 = \lambda y_n\left(1 + \frac z2\right)$，$k_3 = \lambda y_n\left(1 + \frac z2 + \frac{z^2}{4}\right)$，$k_4 = \lambda y_n\left(1 + z + \frac{z^2}{2} + \frac{z^3}{4}\right)$，并且

$$
y_{n+1} = \left(1 + z + \frac{z^2}{2} + \frac{z^3}{6} + \frac{z^4}{24}\right)y_n ,
$$

这是$e^{z}$的$4$次泰勒多项式，而$e^{z}$正是精确的增长因子$y(t_{n+1})/y(t_n)$。

```python
def rk4(f, t0, y0, t_end, n):
    """经典龙格-库塔法，取 n 个等长的步；y 可以是 NumPy 数组。"""
    h = (t_end - t0) / n
    t, y = t0, y0
    for _ in range(n):
        k1 = f(t, y)
        k2 = f(t + h/2, y + h/2 * k1)
        k3 = f(t + h/2, y + h/2 * k2)
        k4 = f(t + h, y + h * k3)
        y = y + h/6 * (k1 + 2*k2 + 2*k3 + k4)
        t = t + h
    return y
```

::: example 手算一步 RK4 {#ex-rk4-step}
对$y' = y$，$y(0) = 1$，用 RK4 走一步，步长为$h = 0.1$。
::: solution
$k_1 = 1$；$k_2 = 1 + 0.05\cdot1 = 1.05$；$k_3 = 1 + 0.05\cdot1.05 = 1.0525$；$k_4 = 1 + 0.1\cdot1.0525 = 1.105\,25$。于是

$$
y_1 = 1 + \frac{0.1}{6}\left(1 + 2.1 + 2.105 + 1.105\,25\right) = 1 + \frac{0.1}{6}\cdot6.310\,25 = 1.105\,170\,833 .
$$

精确值为$e^{0.1} = 1.105\,170\,918$，所以一步之后的误差为$8.5\times10^{-8}$——约等于泰勒展开中略去的第一项$\frac{0.1^5}{120} \approx 8.3\times10^{-8}$。欧拉法则会给出$1.1$，误差为$5\times10^{-3}$。
:::
:::

在实践中，步长并不是固定的。**自适应**求解器使用一对共享相同各级、阶分别为$p$和$p + 1$的**嵌入式**龙格-库塔公式；二者之差给出局部误差的估计，从而在解变化快的地方缩小步长，在解光滑的地方增大步长。阶为$4$和$5$的多尔曼德-普林斯（Dormand–Prince）公式对（1980年）是 MATLAB 的`ode45`以及 SciPy 中`solve_ivp`的默认方法`RK45`背后的算法。

## 稳定性与刚性

收敛性（[[#thm-convergence]]）讨论的是$h \to 0$的情形。在实践中$h$是固定的，于是产生了另一个问题：在我们负担得起的步长下，方法能否再现解的**定性**行为？用来检验的是线性方程

$$
y' = \lambda y, \qquad \lambda \in \C,\ \operatorname{Re}\lambda < 0,
$$ {#eq-test}

它的解$y = y_0e^{\lambda t}$衰减到$0$。（复数$\lambda$来自方程组$\mathbf y' = A\mathbf y$：正如[[ode/linear-systems]]一章所述，这种方程组沿$A$的特征向量解耦为这样的方程；而在平衡点附近，每个光滑的方程组看起来都像它的线性化。）

::: definition 稳定函数与稳定域 {#def-stability-region}
把单步法应用于[[#eq-test]]，得到$y_{n+1} = R(z)\,y_n$，其中$z = h\lambda$，$R$是某个函数，称为**稳定函数**。方法的**绝对稳定域**为$\mathcal S = \set{z \in \C : \abs{R(z)} \le 1}$。如果$\mathcal S$包含整个左半平面$\operatorname{Re}z \le 0$，就称该方法是**A-稳定**的。
:::

由于$y_n = R(z)^ny_0$，数值解像精确解一样衰减当且仅当$\abs{R(h\lambda)} < 1$；而若$\abs{R(h\lambda)} > 1$，无论每一步看上去多么精确，数值解都会无界地增长。我们讨论过的各方法的稳定函数如下：

| 方法 | $R(z)$ | 负实轴上的稳定区间 |
|---|---|---|
| 欧拉法 | $1 + z$ | $-2 \le z \le 0$ |
| 休恩法 | $1 + z + \frac{z^2}{2}$ | $-2 \le z \le 0$ |
| RK4 | $1 + z + \frac{z^2}{2} + \frac{z^3}{6} + \frac{z^4}{24}$ | $-2.785 \le z \le 0$ |
| 后退欧拉法 | $\dfrac{1}{1 - z}$ | 所有$z \le 0$ |
| 梯形法 | $\dfrac{1 + z/2}{1 - z/2}$ | 所有$z \le 0$ |

对于欧拉法，$\mathcal S$是以$-1$为圆心、半径为$1$的圆盘；对于实数$\lambda < 0$，它要求$h \le \frac{2}{\abs\lambda}$。

::: example 显式方法的爆炸 {#ex-instability}
用欧拉法求解$y' = -50(y - \cos t)$，$y(0) = 0$，直到$t = 2$。
::: solution
精确解为$y = \frac{2500}{2501}\cos t + \frac{50}{2501}\sin t - \frac{2500}{2501}e^{-50t}$：经过一段持续约$0.1$的短暂过渡阶段之后，它只是跟随缓慢变化的函数$\approx\cos t$。如果只考虑精度，相当大的步长都是允许的。但误差（近似地）服从$e' = -50e$，所以欧拉法只在$h \le \frac{2}{50} = 0.04$时才稳定。在$t = 2$处的误差如下：

|---|---|---|---|
| 欧拉法 | $0.01$ | $200$ | $-3.8\times10^{-5}$ |
| 欧拉法 | $0.02$ | $100$ | $-7.7\times10^{-5}$ |
| 欧拉法 | $0.04$ | $50$ | $-1.0$ |
| 欧拉法 | $0.05$ | $40$ | $-1.1\times10^{7}$ |
| RK4 | $0.05$ | $40$ | $3.2\times10^{-4}$ |
| RK4 | $0.0625$ | $32$ | $-8.3\times10^{6}$ |
| 后退欧拉法 | $0.1$ | $20$ | $3.5\times10^{-4}$ |
| 后退欧拉法 | $0.5$ | $4$ | $1.1\times10^{-3}$ |

当$h = 0.04$时，$R(h\lambda) = 1 - 2 = -1$：过渡分量永不衰减，而是每一步都改变符号。当$h = 0.05$时，$\abs R = 1.5$，误差增长为原来的$1.5^{40} \approx 10^7$倍。RK4 直到$h = \frac{2.785}{50} = 0.0557$都是稳定的，超过这个值就失败了。隐式的后退欧拉法（见下文）对每个$h$都稳定，只用四步就给出了有用的答案。

::: quiz
对于$y' = -100y$，欧拉法给出衰减的数值解所允许的最大步长是多少？
- [ ] $h < 0.1$
- [ ] $h < 0.01$
- [x] $h < 0.02$

::: example 振子的能量漂移 {#ex-oscillator}
谐振子$y'' = -y$可以化为一阶方程组$y' = v$，$v' = -y$，其能量$E = y^2 + v^2$保持不变。用欧拉法和 RK4 求解，每个周期取$63$步（$h = 2\pi/63 \approx 0.0997$），$E$会怎样变化？
::: solution
欧拉法给出$y_{n+1} = y_n + hv_n$，$v_{n+1} = v_n - hy_n$，所以

$$
E_{n+1} = (y_n + hv_n)^2 + (v_n - hy_n)^2 = (1 + h^2)(y_n^2 + v_n^2) = (1 + h^2)E_n .
$$

能量每个周期增长为原来的$(1 + h^2)^{63} = 1.87$倍，十个周期后增长为$510$倍：无论$h$多小，算出的轨道都会向外螺旋扩张（改变的只是扩张的速率）。用稳定域的语言来说，这个方程组的特征值为$\lambda = \pm i$，而$\abs{R(\pm ih)} = \abs{1 \pm ih} = \sqrt{1 + h^2} > 1$：虚轴位于欧拉法的稳定圆盘之外。对于 RK4，$\abs{R(ih)}^2 = 1 - \frac{h^6}{72} + \frac{h^8}{576}$，所以能量**减小**，但每个周期的相对减小量只有$8.6\times10^{-7}$。所有常微分方程软件都是像这样把高阶方程化为一阶方程组来处理二阶问题的。
:::
:::

### 隐式方法

**后退欧拉法**（隐式欧拉法）在一步的**终点**处计算斜率：

$$
y_{n+1} = y_n + h\,f(t_{n+1}, y_{n+1}).
$$

未知量$y_{n+1}$出现在等式两边，所以每一步都要解一个方程——对于方程组则是一个非线性方程组，通常用牛顿法（[[numerical-analysis/root-finding]]）求解，并对$I - h\frac{\partial\mathbf f}{\partial\mathbf y}$作 LU 分解（[[numerical-analysis/direct-methods]]）。这使得每一步的代价更高，但对于[[#eq-test]]，它给出$y_{n+1} = \frac{y_n}{1 - h\lambda}$。**梯形法**$y_{n+1} = y_n + \frac h2\bigl(f(t_n, y_n) + f(t_{n+1}, y_{n+1})\bigr)$也是隐式的，并且是二阶的。

::: theorem A-稳定性 {#thm-a-stability}
后退欧拉法和梯形法都是 A-稳定的。任何显式龙格-库塔法都不是 A-稳定的。
:::

::: proof
对于后退欧拉法，若$\operatorname{Re}z \le 0$，则$\abs{1 - z} \ge \operatorname{Re}(1 - z) \ge 1$，所以$\abs{R(z)} = \frac{1}{\abs{1 - z}} \le 1$。对于梯形法，当$\operatorname{Re}z \le 0$时，$\abs{1 + \frac z2}^2 - \abs{1 - \frac z2}^2 = 2\operatorname{Re}z \le 0$，所以$\abs{R(z)} \le 1$。

把显式$s$级方法应用于[[#eq-test]]时，每个$k_i$都是$\lambda y_n$乘以$z$的一个多项式（对$i$用归纳法，因为$k_i$只涉及$k_1, \dots, k_{i-1}$），所以$R(z) = 1 + z\sum_ib_i(\ldots)$是次数至多为$s$的多项式。相容性迫使$\sum_ib_i = 1$，所以$R(z) = 1 + z + \cdots$不是常数；而非常数多项式当$x \to -\infty$（沿实轴）时满足$\abs{R(x)} \to \infty$。所以$\mathcal S$不包含整个负实轴。
:::

如果一个问题中我们关心的解变化缓慢，但方程还含有迅速衰减的分量（雅可比矩阵$\partial\mathbf f/\partial\mathbf y$有实部为绝对值很大的负数的特征值），以致显式方法的步长受稳定性而非精度的限制，就称这个问题是**刚性**的。刚性很常见：既有快速反应又有慢速反应的化学反应、时间常数相差悬殊的电路，尤其是扩散方程的空间离散化（[[pde/heat-equation]]）——其特征值像网格间距平方的倒数那样增长，因此加密网格会使显式方法的步长上限按平方缩小。对于刚性问题，应使用隐式方法：向后差分公式（BDF，吉尔（Gear）1971年；SciPy 中的`method='BDF'`），或者隐式龙格-库塔法，例如 Radau IIA（`method='Radau'`）。

::: quiz
某化学反应模型的雅可比矩阵的特征值为$-0.5$和$-10^6$，需要求出直到$t = 100$的解，而所有值得关注的行为都发生在量级为$1$的时间尺度上。下列哪种做法是合理的？
- [ ] 取$h = 0.1$的经典 RK4，因为解是光滑的
- [ ] 取$h = 2\times10^{-6}$的经典 RK4
- [x] 按精度要求选取步长（例如$h \approx 0.1$）的隐式 A-稳定方法或 BDF 方法
- [ ] 取$h = 0.1$的欧拉法，因为它最稳健
::: solution
这个问题是刚性的。取$h = 0.1$的 RK4 有$h\lambda = -10^5$，远在其稳定区间$[-2.785, 0]$之外，会爆炸。取$h \le 2.785\times10^{-6}$的 RK4 是稳定的，但需要大约$4\times10^7$步。隐式方法在这个问题上对任何步长都稳定，所以可以按慢变分量的精度要求来选取$h$，大约需要$1000$步（每一步都要解一个线性方程组，对于小型方程组这很便宜）。欧拉法是显式的，存在与 RK4 相同的问题。
:::
:::

::: warning 稳定不等于精确
A-稳定的方法在衰减问题上永远不会爆炸，但大步长仍然可能不精确。大步长的后退欧拉法能正确地衰减快速的过渡分量，但它只有一阶；梯形法虽然是 A-稳定的，但当$z \to -\infty$时$R(z) \to -1$：非常快的分量没有被衰减，而是每一步都改变符号，产生缓慢衰减的振荡。应当根据慢变解所需的精度来选择步长，根据稳定性来选择方法。
:::

::: application 模拟太阳系
长时间模拟还有进一步的要求：有些问题具有守恒量，例如行星系统的能量。普通方法，即使是高阶方法，也会让能量缓慢漂移，以致模拟中的行星在数百万圈的轨道运动中向内或向外螺旋运动。**辛**积分方法，例如分子动力学和天体力学中使用的斯托默-韦尔莱（Störmer–Verlet）方法（蛙跳法），保持了哈密顿系统的几何结构，能在指数长的时间内使能量误差保持有界。选择尊重问题定性特征——衰减、振荡、守恒——的方法，是现代常微分方程数值理论的中心主题。
:::

::: history
莱昂哈德·欧拉（Leonhard Euler）在《积分学原理》（Institutiones calculi integralis，1768年）中描述了他的方法。弗朗西斯·巴什福思（Francis Bashforth）和约翰·库奇·亚当斯（John Couch Adams）于1883年在一项关于毛细液滴的研究中引入了多步法。卡尔·龙格（Carl Runge）（1895年）提出在每一步之内取样斜率，卡尔·休恩（Karl Heun）（1900年）和马丁·威廉·库塔（Martin Wilhelm Kutta）（1901年）发展了这一思想，库塔的论文中就包含了经典四阶方法。查尔斯·柯蒂斯（Charles Curtiss）和约瑟夫·赫希菲尔德（Joseph Hirschfelder）于1952年在化学动力学中识别出了“刚性”方程。格尔蒙德·达尔奎斯特（Germund Dahlquist）于1956年证明了多步法的收敛性等价于相容性加稳定性，并于1963年引入了 A-稳定性，指出了它的局限。约翰·布彻（John Butcher）关于龙格-库塔法阶条件的代数理论（始于1963年）使得系统地构造高阶方法成为可能。
:::

## 后续内容

线性多步法（亚当斯方法和 BDF 方法）重复利用以前的值，而不是增加级数，它们是许多自适应刚性求解器的基础。边值问题的条件给在区间的两端，可以用打靶法（对未知的初始数据用牛顿法，反复求解初值问题）求解，也可以用有限差分法求解，后者会归结为[[numerical-analysis/direct-methods]]一章中的线性方程组。把常微分方程求解器应用于经过空间离散化的热方程和波动方程——即**线方法**——把本章与[[pde/heat-equation]]和[[pde/wave-equation]]联系起来；在那里，显式方法的稳定性限制$h \le C(\Delta x)^2$就成为著名的库朗-弗里德里希斯-列维（Courant–Friedrichs–Lewy）型条件。所模拟的方程组的定性理论见[[ode/nonlinear-systems]]。

::: summary
- 单步法$y_{n+1} = y_n + h\Phi(t_n, y_n; h)$的阶为$p$，是指它按单位步长计的截断误差为$O(h^p)$；欧拉法是$1$阶的。
- 若$\Phi$满足利普希茨条件，常数为$L$，且$\abs\tau \le T$，则整体误差至多为$\frac TL(e^{L(t - t_0)} - 1)$：局部为$p$阶，整体也为$p$阶。
- 龙格-库塔法在一步之内取样斜率；休恩法和中点法是二阶的（条件为$b_1 + b_2 = 1$，$b_2c_2 = b_2a_{21} = \frac12$），经典的 RK4 是四阶的。可以由误差之比$2^p$通过数值实验验证阶。
- 对于$y' = \lambda y$，方法给出$y_{n+1} = R(h\lambda)y_n$；区域$\abs{R} \le 1$限制了显式方法的步长（欧拉法：对实数$\lambda < 0$，$h \le 2/\abs\lambda$）。
- 刚性问题含有快速衰减的分量，尽管解是光滑的，它们也迫使显式方法采用极小的步长；后退欧拉法和梯形法等隐式方法是 A-稳定的，能高效地求解刚性问题。
- 任何显式龙格-库塔法都不是 A-稳定的；隐式方法每一步都要求解（非）线性方程，通常使用牛顿法。
:::

::: solution
$R(-1) = 1 - 1 + \frac12 = \frac12$。所以当$h\lambda = -1$时，每一步把解乘以$0.5$，而精确的因子是$e^{-1} \approx 0.368$。

::: exercise 增长问题的一步 RK4 {level=2 check="1 + 0.1 + 0.01/2 + 0.001/6 + 0.0001/24"}
证明：对$y' = y$，$y(0) = 1$，步长为$h = 0.1$的一步 RK4 恰好给出$1 + 0.1 + \frac{0.1^2}{2} + \frac{0.1^3}{6} + \frac{0.1^4}{24}$。
::: solution
由[[#eq-rk4]]之后的计算，一步把$y_n$乘以$R(z) = 1 + z + \frac{z^2}{2} + \frac{z^3}{6} + \frac{z^4}{24}$，其中$z = h\lambda = 0.1$。这与[[#ex-rk4-step]]的结果$1.105\,170\,833$一致。
:::

::: exercise 试验方程上的休恩法 {level=2}
证明：把休恩法应用于$y' = \lambda y$，得到$y_{n+1} = \left(1 + z + \frac{z^2}{2}\right)y_n$，其中$z = h\lambda$；并由此推出它在负实轴上的稳定区间。
::: solution
$k_1 = \lambda y_n$，$k_2 = \lambda(y_n + hk_1) = \lambda y_n(1 + z)$，所以$y_{n+1} = y_n + \frac h2\lambda y_n(2 + z) = \left(1 + z + \frac{z^2}{2}\right)y_n$。对实数$z$，$R(z) = \frac12\left((z + 1)^2 + 1\right) > 0$，并且$R(z) \le 1$当且仅当$(z + 1)^2 \le 1$，当且仅当$-2 \le z \le 0$。
:::
:::

::: exercise 刚性方程上的后退欧拉法 {level=2 check="1/6"}
对$y' = -50y$，$y(0) = 1$，用后退欧拉法以$h = 0.1$走一步，并与向前欧拉法比较。
::: solution
后退欧拉法：$y_1 = y_0 + h(-50y_1)$，所以$y_1 = \frac{y_0}{1 + 5} = \frac16 \approx 0.167$（精确值为$e^{-5} \approx 0.0067$；不精确，但在衰减）。向前欧拉法：$y_1 = (1 - 5)y_0 = -4$，$n$步之后为$(-4)^n$：爆炸。
:::
:::

::: exercise 由数据估计阶 {level=2 check="4"}
把 RK4 应用于逻辑斯谛方程$y' = y(1 - y)$，$y(0) = \frac12$，当$h = 0.2$、$0.1$和$0.05$时，得到$y(1)$的近似值$0.731\,058\,283\,7$、$0.731\,058\,560\,1$和$0.731\,058\,577\,5$。假定误差的表现形如$Ch^p$，不利用精确解，由比值$\frac{y^{(0.2)} - y^{(0.1)}}{y^{(0.1)} - y^{(0.05)}}$估计阶$p$。
::: solution
若$y^{(h)} = y + Ch^p$，则$y^{(2h)} - y^{(h)} = C(2^p - 1)h^p$，所以相邻差值之比为$2^p$。这里两个差值为$0.731\,058\,560\,1 - 0.731\,058\,283\,7 = 2.764\times10^{-7}$和$0.731\,058\,577\,5 - 0.731\,058\,560\,1 = 1.74\times10^{-8}$，其比值约为$15.9 \approx 2^4$。所以$p = 4$，与对 RK4 的预期一致。（精确值为$\frac{1}{1 + e^{-1}} = 0.731\,058\,578\,6$；实际误差$-2.9\times10^{-7}$、$-1.8\times10^{-8}$和$-1.2\times10^{-9}$证实了这一点。）这个技巧不需要精确解，实践中正是这样检验阶的。
:::
:::

::: exercise 梯形法 {level=3}
证明：梯形法$y_{n+1} = y_n + \frac h2\bigl(f(t_n, y_n) + f(t_{n+1}, y_{n+1})\bigr)$的稳定函数为$R(z) = \frac{1 + z/2}{1 - z/2}$；$\abs{R(z)} < 1$当且仅当$\operatorname{Re}z < 0$；并且它的截断误差为$O(h^2)$。
::: solution
对于$f = \lambda y$：$y_{n+1}\left(1 - \frac z2\right) = y_n\left(1 + \frac z2\right)$，由此得到$R$。记$z = x + iy$，则$\abs{1 + z/2}^2 - \abs{1 - z/2}^2 = (1 + x/2)^2 - (1 - x/2)^2 = 2x$，所以$\abs R < 1$当且仅当$x < 0$。至于截断误差，$\tau = \frac{y(t_{n+1}) - y(t_n)}{h} - \frac12\bigl(y'(t_n) + y'(t_{n+1})\bigr)$（因为$f(t, y(t)) = y'(t)$）。由泰勒定理，$\frac{y(t_n + h) - y(t_n)}{h} = y' + \frac h2y'' + \frac{h^2}{6}y''' + O(h^3)$，$\frac12(y'(t_n) + y'(t_n + h)) = y' + \frac h2y'' + \frac{h^2}{4}y''' + O(h^3)$，所以$\tau = -\frac{h^2}{12}y''' + O(h^3)$：二阶。（这其实就是[[numerical-analysis/numerical-integration#thm-basic-errors]]中梯形求积公式的误差，只是换了个面目。）
:::
:::

::: exercise 离散格朗沃尔不等式 {level=3}
设$a_n \ge 0$对$n \ge 0$满足$a_{n+1} \le (1 + hL)a_n + hT$，其中$h, L, T > 0$。证明$a_n \le e^{nhL}a_0 + \frac TL\left(e^{nhL} - 1\right)$，并说明如何由此把[[#thm-convergence]]推广到$e_0 \ne 0$的情形（例如初值被舍入到机器精度）。
::: solution
用归纳法证明$a_n \le (1 + hL)^na_0 + hT\sum_{k=0}^{n-1}(1 + hL)^k$：$n = 0$时成立；若对$n$成立，则$a_{n+1} \le (1 + hL)\left[(1 + hL)^na_0 + hT\sum_{k<n}(1 + hL)^k\right] + hT = (1 + hL)^{n+1}a_0 + hT\sum_{k\le n}(1 + hL)^k$。等比数列之和为$\frac{(1 + hL)^n - 1}{hL}$，又$(1 + hL)^n \le e^{nhL}$，即得所证。取$a_n = \abs{e_n}$，整体误差界就变为$\abs{e_n} \le e^{L(t_n - t_0)}\abs{e_0} + \frac TL\left(e^{L(t_n - t_0)} - 1\right)$：初始误差至多被放大$e^{L(t - t_0)}$倍，与截断误差的放大倍数相同，所以该方法对数据的扰动是稳定的。
:::
:::

::: exercise 显式方法不是 A-稳定的：一个具体例子 {level=3}
求使 RK4 在$[-r, 0]$上稳定的最大的$r$，即对$R(z) = 1 + z + \frac{z^2}{2} + \frac{z^3}{6} + \frac{z^4}{24}$数值求解$R(-r) = 1$，精确到三位小数。对于$y' = -1000y$，$h$必须多小？
::: hint
$R(z) - 1 = z\left(1 + \frac z2 + \frac{z^2}{6} + \frac{z^3}{24}\right)$；用牛顿法求三次因式的实根。

::: solution
我们需要求$q(z) = 1 + \frac z2 + \frac{z^2}{6} + \frac{z^3}{24}$的负实根，即$z^3 + 4z^2 + 12z + 24 = 0$的负实根。从$z_0 = -3$出发，牛顿法给出$z_1 = -2.8$，$z_2 = -2.785\,37$，$z_3 = -2.785\,293\,6$，二次收敛到$z = -2.785\,29$。可以验证，当$-2.785 < z < 0$时$\abs{R(z)} < 1$（在这个区间上$R$为正，其最小值$0.270$在$z = -1.60$附近取到）。所以 RK4 在$[-2.785, 0]$上稳定；对于$\lambda = -1000$，它要求$h \le 0.002\,785$——即使我们关心的解是在以秒计的时间尺度上变化的。
