把前几个奇数加起来：

$$
1 = 1, \qquad 1 + 3 = 4, \qquad 1 + 3 + 5 = 9, \qquad 1 + 3 + 5 + 7 = 16, \qquad 1 + 3 + 5 + 7 + 9 = 25.
$$

结果都是平方数，于是很自然地猜想：对每个$n$，$1 + 3 + \dots + (2n - 1) = n^2$。但[[proofs/proof-techniques]]一章开头的那个规律对$n$的四十个值都成立，随后却失效了，所以逐一检验情形不能解决问题。我们需要一种方法，用有限多步证明无穷多个命题——每个$n = 1, 2, 3, \dots$各对应一个命题。

其思想就像一排多米诺骨牌。如果第一块骨牌倒下，并且每一块骨牌都会推倒下一块，那么所有骨牌都会倒下。对于奇数之和：公式在$n = 1$时成立；而**如果**它对某个$n = k$成立，那么加上下一个奇数$2k + 1$就得到$k^2 + 2k + 1 = (k+1)^2$，所以它对$n = k+1$也成立。真实性从$n = 1$传到$2$，从$2$传到$3$，如此永远继续下去。

这一原理就是**数学归纳法**，它是证明关于全体自然数的命题的主要工具，其用途远不止于求和公式：不等式、整除性、算法的正确性，以及任何逐步构造出来的对象的性质。本章将仔细地叙述这一原理，介绍它的变体——强归纳法和良序原理——并用它来研究递归定义的数列。回忆$\N = \set{1, 2, 3, \dots}$，$\N_0 = \set{0, 1, 2, \dots}$。

## 归纳原理

::: axiom 数学归纳原理 {#thm-induction}
设$P(n)$是论域为$\N$的谓词。假设

1. **（归纳基础）**$P(1)$为真，并且
2. **（归纳步骤）**对每个$k \in \N$，若$P(k)$为真，则$P(k+1)$为真。

则$P(n)$对每个$n \in \N$都为真。
:::

为什么应当相信这一点？对于任何一个**特定的**$n$，比如$n = 4$，结论可以纯粹用逻辑从假设推出：$P(1)$是已知的；由$P(1) \Rightarrow P(2)$，用肯定前件式得到$P(2)$；然后得到$P(3)$，再得到$P(4)$。但要一下子对**所有**$n$得出$P(n)$，我们需要某种东西来保证：从$1$出发、反复加$1$，就能到达每个自然数。这是$\N$的一个基本性质——是我们所说的“自然数”的含义的一部分——在皮亚诺（Peano）的算术公理中，它恰好以归纳原理的形式出现。我们把它当作公理；本章后面将看到，它与良序原理等价。

在归纳步骤中，假定“$P(k)$为真”称为**归纳假设**。我们**并不**假定$P(k)$对所有$k$成立——那就等于假定了我们要证明的结论。我们证明的是一个蕴涵：对任意的$k$，**如果**$P(k)$成立，**那么**$P(k+1)$也成立。

归纳法证明有固定的格式，把这种格式清楚地展示出来是一个好习惯。

::: example 前n个奇数之和 {#ex-odd-sum}
证明对每个$n \in \N$，

$$
1 + 3 + 5 + \dots + (2n - 1) = n^2.
$$
::: solution
对$n \in \N$，令$P(n)$表示命题$\sum_{i=1}^{n} (2i - 1) = n^2$。

**归纳基础。**当$n = 1$时，左边为$1$，右边为$1^2 = 1$，所以$P(1)$为真。

**归纳步骤。**设$k \in \N$，并假定$P(k)$成立，即$\sum_{i=1}^{k}(2i-1) = k^2$。则

$$
\sum_{i=1}^{k+1}(2i - 1) = \sum_{i=1}^{k}(2i - 1) + \bigl(2(k+1) - 1\bigr) = k^2 + 2k + 1 = (k+1)^2,
$$

其中第二个等号用到了归纳假设。这就是$P(k+1)$。

**结论。**由归纳原理，$P(n)$对每个$n \in \N$都成立。
:::
:::

归纳步骤中的关键一步，是在$n = k+1$的情形**之中**找到$n = k$的情形：到$k+1$为止的和，等于到$k$为止的和再加上一项。几乎每个归纳法证明中都有这样的一刻，而寻找这一刻正是找到证明的途径。

::: intuition 归纳步骤的图示
把$k^2$个点排成$k\times k$的正方形。要把它扩大成$(k+1)\times(k+1)$的正方形，就沿两条边添上一圈由$k + 1 + k = 2k+1$个点组成的L形边。所以，平方数是通过逐圈添加奇数$1, 3, 5, \dots$构造出来的——归纳步骤就是添加一圈边的图示。
:::

### 从别处开始

有些命题只是从某一点起才成立，或者自然地从$0$开始编号。这时归纳基础可以是任意整数$n_0$。

::: corollary 从任意起点开始的归纳法 {#cor-induction-n0}
设$n_0$是整数，$P(n)$是定义在整数$n \ge n_0$上的谓词。如果$P(n_0)$为真，并且对每个$k \ge n_0$，$P(k)$蕴涵$P(k+1)$，那么$P(n)$对每个整数$n \ge n_0$都为真。
:::

::: proof
对$m \in \N$，令$Q(m)$表示命题$P(m + n_0 - 1)$。则$Q(1)$就是$P(n_0)$，它为真。若$m \in \N$且$Q(m)$成立，则对$k = m + n_0 - 1 \ge n_0$，$P(k)$成立，所以$P(k+1)$成立，而这就是$Q(m+1)$。由[[#thm-induction]]，$Q(m)$对每个$m \in \N$都为真；当$m$取遍$\N$时，$n = m + n_0 - 1$取遍所有整数$n \ge n_0$。
:::

::: example 指数胜过平方 {#ex-power-square}
证明对每个整数$n \ge 5$，$2^n > n^2$。
::: solution
令$P(n)$为“$2^n > n^2$”。

**归纳基础。**$2^5 = 32 > 25 = 5^2$。

**归纳步骤。**设$k \ge 5$，并假定$2^k > k^2$。则

$$
2^{k+1} = 2\cdot 2^k > 2k^2.
$$

要完成证明，我们需要$2k^2 \ge (k+1)^2$，它等价于$k^2 - 2k - 1 \ge 0$，即$(k-1)^2 \ge 2$；由于$k - 1 \ge 4$，这是成立的。因此$2^{k+1} > 2k^2 \ge (k+1)^2$，这就是$P(k+1)$。

由[[#cor-induction-n0]]（取$n_0 = 5$），对所有$n \ge 5$都有$2^n > n^2$。归纳基础不能再往前移：$2^4 = 4^2$，$2^3 < 3^2$。注意，归纳步骤只是通过$(k-1)^2 \ge 2$用到了$k \ge 5$，而这一点在$k \ge 3$时就已成立；对$n = 3$和$4$不成立的是归纳基础。
:::
:::

caption: $2^x$和$x^2$的图像在$x = 2$和$x = 4$处相交；在两者之间，$x^2$较大（例如$3^2 = 9 > 8 = 2^3$）。从$x = 4$起，指数函数遥遥领先，归纳步骤解释了其中的原因：每前进一步，$2^n$乘以$2$，而$n^2$只乘以$\bigl(\tfrac{n+1}{n}\bigr)^2$，当$n \ge 3$时这个因子小于$2$。
:::

::: example 一个整除命题 {#ex-divisibility}
证明对每个$n \in \N_0$，$8 \mid 9^n - 1$。
::: solution
令$P(n)$为“$8 \mid 9^n - 1$”。

**归纳基础。**$9^0 - 1 = 0 = 8 \cdot 0$，所以$P(0)$成立。

**归纳步骤。**设$k \ge 0$，并假定$8 \mid 9^k - 1$，比如$9^k - 1 = 8m$，其中$m \in \Z$。为了用上归纳假设，把$9^{k+1} - 1$用$9^k - 1$表示出来：

$$
9^{k+1} - 1 = 9\cdot 9^k - 1 = 9\,(9^k - 1) + 8 = 72m + 8 = 8(9m + 1).
$$

所以$8 \mid 9^{k+1} - 1$。由归纳法（从$n_0 = 0$开始），$P(n)$对所有$n \ge 0$都成立。
:::
:::

下一个结果是分析学中极为常用的工具；它的证明是一个很好的例子，说明归纳步骤中处理不等式时需要小心。

::: theorem 伯努利（Bernoulli）不等式 {#thm-bernoulli}
对每个实数$x \ge -1$和每个$n \in \N$，

$$
(1 + x)^n \ge 1 + nx.
$$
:::

::: proof
固定$x \ge -1$，对$n$用归纳法。当$n = 1$时，两边都等于$1 + x$。设对某个$k \in \N$有$(1 + x)^k \ge 1 + kx$。由于$1 + x \ge 0$，把这个不等式两边同乘以$1 + x$，不等号方向不变，所以

$$
(1+x)^{k+1} = (1+x)^k (1+x) \ge (1 + kx)(1 + x) = 1 + (k+1)x + kx^2 \ge 1 + (k+1)x,
$$

因为$kx^2 \ge 0$。这就是$k + 1$时的命题，由归纳法即得结论。
:::

假设$x \ge -1$恰好用到了一次，即把不等式乘以$1 + x$的时候；这个假设不能去掉：当$x = -4$，$n = 3$时，$(1+x)^3 = -27$小于$1 + 3x = -11$。

::: quiz
在证明$P(n)$对所有$n \in \N$成立的归纳步骤中，你究竟可以假定什么？
- [ ] $P(n)$对每个$n \in \N$都为真。
- [x] 对一个任意但固定的$k \in \N$，$P(k)$为真，并以此证明$P(k+1)$。
- [ ] $P(k+1)$为真，并以此证明$P(k)$。
- [ ] 什么也不能假定：归纳步骤必须在没有任何假定的情况下证明。
::: solution
归纳步骤是对任意的$k$证明蕴涵$P(k) \Rightarrow P(k+1)$；要证明一个蕴涵，我们假定它的假设$P(k)$。假定$P(n)$对所有$n$成立就是循环论证；第三个选项证明的是错误的蕴涵（它会让真实性向下传递，而不是向上传递）。
:::
:::

## 强归纳法

在普通归纳法中，$P(k+1)$仅由$P(k)$推出。有时$P(k+1)$依赖于一个更早的、并非紧挨着的前一个情形——例如，把$n$分解为$ab$，就引出了$a$和$b$的情形，而它们可能比$n$小得多。强归纳法允许归纳假设包含**所有**更早的情形。

::: theorem 强归纳法 {#thm-strong-induction}
设$P(n)$是$\N$上的谓词。假设$P(1)$为真，并且对每个$k \in \N$，

$$
\bigl(P(1) \land P(2) \land \dots \land P(k)\bigr) \Rightarrow P(k+1).
$$

则$P(n)$对每个$n \in \N$都为真。
:::

::: proof
我们对下面的谓词应用普通归纳法：

$$
Q(n):\quad P(1) \land P(2) \land \dots \land P(n),
$$

它是说$P$对从$1$到$n$的每个数都成立。$Q(1)$就是$P(1)$，它为真。设对某个$k \in \N$，$Q(k)$成立。则$P(1), \dots, P(k)$都成立，所以由假设，$P(k+1)$成立，因此$Q(k+1) = Q(k) \land P(k+1)$成立。由[[#thm-induction]]，$Q(n)$对每个$n$都为真，特别地，$P(n)$也为真。
:::

所以强归纳法并不比普通归纳法更强——它是普通归纳法的推论——但它常常方便得多。与普通归纳法一样，归纳基础可以是任意整数$n_0$；当归纳步骤要回溯不止一步时，可能需要多个归纳基础。

::: theorem 素因数分解的存在性 {#thm-factorisation}
每个整数$n \ge 2$都是一个或多个素数之积。
:::

::: proof
我们对$n \ge 2$用强归纳法。令$P(n)$为“$n$是素数之积”。归纳基础$P(2)$成立，因为$2$是素数。设$k \ge 2$，并假定$P(2), \dots, P(k)$成立；我们来证明$P(k+1)$。

如果$k + 1$是素数，它就是一个素数之积。否则，存在整数$a, b$，满足$1 < a < k+1$和$1 < b < k+1$，使得$k + 1 = ab$，所以$2 \le a, b \le k$。由归纳假设，$a$和$b$都是素数之积，所以$k + 1 = ab$也是素数之积（先写出$a$的素因数，再接着写出$b$的素因数）。由强归纳法，$P(n)$对所有$n \ge 2$都成立。
:::

这种分解在不计因数次序的意义下是**唯一的**——这就是算术基本定理——它的证明需要一个额外的想法，将在[[number-theory/primes]]一章中给出。注意，普通归纳法在这里行不通：知道$k$是素数之积，对$k + 1$说明不了任何东西。

::: example 邮票 {#ex-stamps}
证明：任何$n \ge 12$便士的金额，都可以只用$4$便士和$5$便士的邮票恰好凑出。
::: solution
令$P(n)$为“存在$a, b \in \N_0$，使得$n = 4a + 5b$”。归纳步骤将通过添加一张$4$便士的邮票从$n - 4$走到$n$，它要回溯四步，所以我们需要四个归纳基础：

$$
12 = 4\cdot 3, \qquad 13 = 4\cdot 2 + 5, \qquad 14 = 4 + 5\cdot 2, \qquad 15 = 5\cdot 3.
$$

**归纳步骤。**设$k \ge 15$，并假定$P(12), \dots, P(k)$成立。则$(k+1) - 4 = k - 3$满足$12 \le k - 3 \le k$，所以$k - 3 = 4a + 5b$，其中$a, b \ge 0$，从而$k + 1 = 4(a + 1) + 5b$。因此$P(k+1)$成立。

由强归纳法，$P(n)$对所有$n \ge 12$都成立。这个界是精确的：$11$便士凑不出来，因为$11$、$11 - 5 = 6$和$11 - 10 = 1$都不是$4$的倍数。
:::
:::

::: quiz
你想用强归纳法证明每个整数$n \ge 8$都可以写成$3a + 5b$（其中$a, b \in \N_0$），所用的归纳步骤是“$n - 3$可以这样写，所以再加一个$3$”。你必须直接验证多少个归纳基础？
- [ ] $1$
- [ ] $2$
- [x] $3$
- [ ] $5$
::: solution
从$n - 3$到$n$的这一步只有在$n - 3 \ge 8$，即$n \ge 11$时才有效。所以$8$、$9$和$10$必须直接验证：$8 = 3 + 5$，$9 = 3\cdot 3$，$10 = 5\cdot 2$。于是每个$n \ge 11$都可以从其中之一出发、不断加$3$而得到。
:::
:::

::: warning 归纳步骤必须对每个k都有效
在邮票问题中，从$k - 3$到$k + 1$的这一步只有在$k - 3 \ge 12$，即$k \ge 15$时才有效。这就是四个值$12, 13, 14, 15$都必须直接验证的原因。一般地，要考察你的归纳步骤应当适用的最小的$k$，并确保它所依赖的每个情形要么是归纳基础，要么已被涵盖。
:::

## 良序原理

归纳法从最小的情形开始向上构建。同一件事的一种等价说法是：不存在无穷递降——每个非空的自然数集合都有最小的成员。

::: theorem 良序原理 {#thm-well-ordering}
$\N$的每个非空子集都有最小元素。
:::

::: proof
设$S \subseteq \N$是一个没有最小元素的集合；我们证明$S$是空集，这就通过逆否命题证明了定理。令$P(n)$表示命题“$n \notin S$”，并使用强归纳法。

*归纳基础*。如果$1 \in S$，那么$1$就是$S$的最小元素，因为没有比$1$更小的自然数。所以$1 \notin S$。

*归纳步骤*。设$1, 2, \dots, k \notin S$。如果$k + 1$属于$S$，它就是$S$的最小元素，因为每个比它小的自然数都不在$S$中。所以$k + 1 \notin S$。

由[[#thm-strong-induction]]，对每个$n \in \N$都有$n \notin S$，所以$S = \varnothing$。
:::

反过来，归纳原理也可以由良序原理证明（见习题），所以两者逻辑等价：任何一个都可以作为关于$\N$的基本公理。良序原理是**最小反例**证法的天然工具：假设一个命题对某些自然数不成立，取使它不成立的**最小的**$n$，然后推出矛盾——通常是构造出一个更小的不成立的情形。我们在[[proofs/proof-techniques]]一章中就用这种方法证明了$\sqrt 2$是无理数，以及每个整数$n \ge 2$都有素因数。

::: example 提出2的幂 {#ex-wop}
用良序原理证明：每个$n \in \N$都可以写成$n = 2^a m$，其中$a \in \N_0$，$m$为奇数。
::: solution
假设不然。则不能写成这种形式的自然数构成的集合$S$非空，所以由[[#thm-well-ordering]]，它有最小元素$n$。如果$n$是奇数，那么$n = 2^0 n$就具有所要求的形式；所以$n$是偶数，$n = 2n'$，其中$n' \in \N$且$n' < n$。由于$n$是$S$的最小元素，$n' \notin S$，所以$n' = 2^a m$，其中$m$为奇数。但这样一来$n = 2^{a+1} m$，所以$n \notin S$——矛盾。因此$S$是空集。
:::
:::

::: quiz
下列哪个集合有最小元素？
- [ ] $\set{x \in \Q : x > 0}$
- [ ] $\set{n \in \Z : n < 5}$
- [x] $\set{n \in \N : n^2 > 1000}$
- [ ] 区间$(0, 1)$
::: solution
第三个集合是一个非空的自然数集合，所以由良序原理，它有最小元素——即$32$，因为$31^2 = 961$，$32^2 = 1024$。正有理数集和$(0,1)$没有最小元素（$x/2$总是更小），$\set{n \in \Z : n < 5}$也没有最小元素：它不是$\N$的子集，而且没有下界。
:::
:::

::: remark 良序性是ℕ特有的
良序原理对其他熟悉的数系不成立：$\Z$没有最小元素，正有理数集和区间$(0, 1)$也没有（对任意$x \in (0,1)$，数$x/2$都更小）。这就是为什么归纳法是用于自然数（或以自然数为指标的任何对象）的方法，也是为什么对实数不能使用“取最小反例”的方法。
:::

## 递归定义

归纳法证明关于每个自然数的命题；**递归**则为每个自然数定义对象。两者相辅相成。

::: definition 递归定义 {#def-recursive}
给定一个或多个初始项，以及一条用前面的项$a_0, \dots, a_n$表示后面每一项$a_{n+1}$的规则，就称数列$a_0, a_1, a_2, \dots$是**递归定义**的。
:::

一些重要的例子：

- **阶乘：**$0! = 1$，$(n+1)! = (n+1)\cdot n!$，所以当$n \ge 1$时，$n! = 1\cdot 2\cdots n$。
- **求和：**$\sum_{i=1}^{0} a_i = 0$，$\sum_{i=1}^{n+1} a_i = \bigl(\sum_{i=1}^{n} a_i\bigr) + a_{n+1}$。这就是“$a_1 + a_2 + \dots + a_n$”的精确含义，也是归纳法对求和如此有效的原因。
- **斐波那契（Fibonacci）数：**$F_0 = 0$，$F_1 = 1$，且当$n \ge 1$时$F_{n+1} = F_n + F_{n-1}$，由此得到$0, 1, 1, 2, 3, 5, 8, 13, 21, \dots$。

这样的定义确实定义了唯一的数列，这一点本身也是用归纳法证明的（**递归定理**）；我们把它当作已知。关于递归定义的数列的证明，遵循定义的格式：由前一项定义的数列适合用普通归纳法，由前两项定义的数列适合用带两个归纳基础的强归纳法。

::: example 一个斐波那契恒等式 {#ex-fibonacci}
证明对每个$n \in \N$，$F_1 + F_2 + \dots + F_n = F_{n+2} - 1$。
::: solution
**归纳基础。**当$n = 1$时：$F_1 = 1$，$F_3 - 1 = 2 - 1 = 1$。

**归纳步骤。**假定对某个$k \in \N$有$\sum_{i=1}^{k} F_i = F_{k+2} - 1$。则

$$
\sum_{i=1}^{k+1} F_i = \bigl(F_{k+2} - 1\bigr) + F_{k+1} = (F_{k+2} + F_{k+1}) - 1 = F_{k+3} - 1,
$$

这里用到了递归定义$F_{k+3} = F_{k+2} + F_{k+1}$。这就是$k + 1$时的命题，所以由归纳法，恒等式对所有$n$成立。
:::
:::

::: example 汉诺塔 {#ex-hanoi}
有三根柱子，$n$个大小各不相同的圆盘全部套在第一根柱子上，从下往上由大到小排列。每一步把某根柱子最上面的圆盘移到另一根柱子上，并且绝不能放在比它小的圆盘上。证明：把所有圆盘移到第三根柱子上所需的最少步数$T_n$为$2^n - 1$。
::: solution
*递推关系*。要移动最大的圆盘，必须先把$n - 1$个较小的圆盘叠放到剩下的那根柱子上（最大的圆盘上面必须没有东西，而它的目标柱子必须是空的），这至少需要$T_{n-1}$步。在最大的圆盘最后一次移动之后，还必须把$n-1$个较小的圆盘移到它上面，这至少还需要$T_{n-1}$步。所以$T_n \ge 2T_{n-1} + 1$。反过来，先把上面$n - 1$个圆盘移到中间的柱子上，再把最大的圆盘移到第三根柱子上，然后把这$n - 1$个圆盘移回到它上面，就恰好用了这么多步，所以$T_n = 2T_{n-1} + 1$，且$T_1 = 1$。

*求解*。我们用归纳法证明$T_n = 2^n - 1$。当$n = 1$时，$T_1 = 1 = 2^1 - 1$。若$T_k = 2^k - 1$，则$T_{k+1} = 2(2^k - 1) + 1 = 2^{k+1} - 1$。因此对所有$n$都有$T_n = 2^n - 1$：对$64$个圆盘，需要超过$1.8 \times 10^{19}$步。像这样的递推关系将在[[discrete/recurrences]]一章中系统地研究。
:::
:::

## 归纳法出错的时候

归纳法证明的两个部分都必不可少，而两者都可能以富有启发性的方式出错。

**缺少归纳基础。**令$P(n)$为“$n^2 + n$是奇数”。如果$k^2 + k$是奇数，那么$(k+1)^2 + (k+1) = (k^2 + k) + 2(k+1)$是奇数加偶数，因而是奇数：归纳步骤完全有效。但$P(1)$是假的（$1 + 1 = 2$），事实上$n^2 + n = n(n+1)$**总是**偶数。骨牌摆得完全正确，却没有一块倒下。

::: warning 所有的马都是同一种颜色
下面是一个著名的伪证明。*断言*：在任意由$n \ge 1$匹马组成的集合中，所有马的颜色都相同。*归纳基础*：一匹马与它自己颜色相同。*归纳步骤*：给定$k + 1$匹马，拿走一匹；由假设，剩下的$k$匹颜色相同。把它放回去，再拿走另一匹；剩下的$k$匹同样是一种颜色。这两组马有重叠，所以全部$k+1$匹马颜色相同。

错误在于：两组各$k$匹马只有在$k \ge 2$时才有重叠。当$k = 1$（两匹马）时，每组只有一匹马，两组不相交，所以没有任何东西把它们的颜色联系起来。$P(1) \Rightarrow P(2)$这一步不成立，整条链也就随之断开。归纳步骤必须对从归纳基础开始的**每个**$k$都有效，包括最小的那个。
:::

::: application 循环不变式
程序员正是用归纳法来证明循环确实完成了它应做的事情。**循环不变式**是这样一个命题：它在第一次迭代之前成立（归纳基础），并且每次迭代都保持它成立（归纳步骤）；由归纳法，它在任意多次迭代之后都成立。例如，在一个把列表各项相加的循环中，不变式“经过$i$次迭代后，累计和等于前$i$项之和”表明最终的总和就是整个列表之和。递归程序的正确性则通过对输入规模用强归纳法来证明，正如[[#thm-factorisation]]那样。
:::

::: history
类似归纳法的论证出现在卡拉吉（al-Karaji，约公元1000年）的著作中，他用这类论证处理立方和与二项式系数；1321年列维·本·热尔松（Levi ben Gershon）的著作中也有这类论证。弗朗切斯科·毛罗利科（Francesco Maurolico）的《算术两卷》（*Arithmeticorum libri duo*，1575年）通过从每个情形过渡到下一个情形，证明了前$n$个奇数之和为$n^2$；布莱兹·帕斯卡（Blaise Pascal）的《论算术三角形》（*Traité du triangle arithmétique*，1654年写成，1665年出版）则清楚地把这一方法表述为一个基础情形，加上一个说明每个情形蕴涵下一个情形的“引理”。“数学归纳法”这一名称是奥古斯塔斯·德摩根（Augustus De Morgan）在1838年提出的。随后，理查德·戴德金（Richard Dedekind，1888年）和朱塞佩·皮亚诺（Giuseppe Peano，1889年）把归纳法作为定义自然数的公理之一，这也就是它今天的地位。
:::

## 后续内容

归纳法在数学的每个分支中都有应用。在[[proofs/sets]]和[[proofs/cardinality]]两章中，它证明了含$n$个元素的集合有$2^n$个子集，并且是有限集理论的基础。[[discrete/counting]]一章中的计数公式和二项式系数恒等式都用归纳法证明，而[[discrete/recurrences]]一章则把汉诺塔、斐波那契数之类的递归定义解成封闭形式。在分析学中，伯努利不等式和归纳论证被用来控制数列（[[real-analysis/sequences]]）；在代数学中，对群的阶或多项式的次数作归纳随处可见（[[abstract-algebra/groups]]、[[abstract-algebra/polynomials]]）。结构归纳法——按公式、树或程序的构造方式进行归纳——把这一思想推广到数以外的对象，[[proofs/propositional-logic]]一章的最后一道习题就是一例。

::: summary
- 要证明$P(n)$对所有$n \ge n_0$成立：先证明**归纳基础**$P(n_0)$，再对任意的$k \ge n_0$证明**归纳步骤**$P(k) \Rightarrow P(k+1)$（[[#thm-induction]]，[[#cor-induction-n0]]）。
- 在归纳步骤中，要在情形$k+1$之中找到情形$k$，并在那里使用归纳假设；绝不要假定$P(n)$对所有$n$成立。
- **强归纳法**假定$P(n_0), \dots, P(k)$来证明$P(k+1)$（[[#thm-strong-induction]]）；它可由普通归纳法推出，用于归纳步骤需要回溯得更远的情形，例如素因数分解。回溯$r$步的归纳步骤需要$r$个归纳基础。
- **良序原理**——$\N$的每个非空子集都有最小元素——与归纳法等价，它为最小反例证法提供了依据。
- 递归定义（阶乘、求和、斐波那契数、汉诺塔）与归纳法相伴而行：证明遵循定义的格式。
- 两个部分都很重要：没有归纳基础，一切都无从开始；归纳步骤必须对每个$k$都有效，包括最小的那个（“马”的谬误）。
:::

## 习题

::: exercise 和1 + 2 + … + n {level=1}
用归纳法证明对每个$n \in \N$，$1 + 2 + \dots + n = \dfrac{n(n+1)}{2}$。
::: solution
当$n = 1$时，两边都等于$1$。假定$\sum_{i=1}^{k} i = \frac{k(k+1)}{2}$。则

$$
\sum_{i=1}^{k+1} i = \frac{k(k+1)}{2} + (k+1) = \frac{(k+1)(k + 2)}{2},
$$

这就是$n = k+1$时的公式。由归纳法，公式对所有$n \in \N$成立。
:::
:::

::: exercise 十个圆盘 {level=1 check="1023"}
解决有$10$个圆盘的汉诺塔问题，最少需要多少步？
::: solution
由[[#ex-hanoi]]，$T_{10} = 2^{10} - 1 = 1023$。
:::
:::

::: exercise 阶乘增长得更快 {level=1}
证明对每个整数$n \ge 4$，$n! > 2^n$。
::: solution
**归纳基础。**$4! = 24 > 16 = 2^4$。

**归纳步骤。**设$k \ge 4$，并假定$k! > 2^k$。则

$$
(k+1)! = (k+1)\cdot k! > (k+1)\, 2^k \ge 2\cdot 2^k = 2^{k+1},
$$

因为$k + 1 \ge 2$。由[[#cor-induction-n0]]（取$n_0 = 4$），不等式对所有$n \ge 4$成立。（它对$n = 1, 2, 3$不成立，所以归纳基础不能再往前移。）
:::
:::

::: exercise 一个整除性证明 {level=2}
证明对每个$n \in \N_0$，$7 \mid 3^{2n+1} + 2^{n+2}$。
::: hint
写$3^{2(k+1)+1} = 9\cdot 3^{2k+1}$和$2^{(k+1)+2} = 2\cdot 2^{k+2}$，然后加上并减去$2^{k+2}$的一个适当倍数。
:::
::: solution
当$n = 0$时：$3 + 4 = 7$。假定$7 \mid 3^{2k+1} + 2^{k+2}$。则

$$
3^{2k+3} + 2^{k+3} = 9\cdot 3^{2k+1} + 2\cdot 2^{k+2} = 9\bigl(3^{2k+1} + 2^{k+2}\bigr) - 7\cdot 2^{k+2}.
$$

右边两项都能被$7$整除，所以左边也能被$7$整除（由[[proofs/proof-techniques#prop-divides]]）。由归纳法，论断对所有$n \ge 0$成立。
:::
:::

::: exercise 立方和 {level=2}
证明对每个$n \in \N$，$1^3 + 2^3 + \dots + n^3 = \left(\dfrac{n(n+1)}{2}\right)^2$。
::: solution
当$n = 1$时，两边都是$1$。假定公式对$k$成立，则

$$
\sum_{i=1}^{k+1} i^3 = \frac{k^2(k+1)^2}{4} + (k+1)^3 = \frac{(k+1)^2\bigl(k^2 + 4k + 4\bigr)}{4} = \left(\frac{(k+1)(k+2)}{2}\right)^2,
$$

这就是$k+1$时的公式。结合第一道习题，这表明了一个奇妙的事实：$1^3 + \dots + n^3 = (1 + \dots + n)^2$。
:::
:::

::: exercise 裂项求和 {level=2 check="99/100"}
用归纳法证明对所有$n \in \N$，$\displaystyle\sum_{i=1}^{n}\frac{1}{i(i+1)} = \frac{n}{n+1}$，并由此求出$\displaystyle\sum_{i=1}^{99}\frac{1}{i(i+1)}$的值。
::: solution
当$n = 1$时：$\frac{1}{2} = \frac{1}{1+1}$。假定公式对$k$成立，则

$$
\sum_{i=1}^{k+1}\frac{1}{i(i+1)} = \frac{k}{k+1} + \frac{1}{(k+1)(k+2)} = \frac{k(k+2) + 1}{(k+1)(k+2)} = \frac{(k+1)^2}{(k+1)(k+2)} = \frac{k+1}{k+2}.
$$

由归纳法，公式对所有$n$成立，取$n = 99$，和为$\frac{99}{100}$。（不用归纳法也可以：$\frac{1}{i(i+1)} = \frac1i - \frac{1}{i+1}$，裂项相消后和为$1 - \frac{1}{n+1}$。）
:::
:::

::: exercise 斐波那契数的一个上界 {level=2}
证明对每个$n \in \N_0$，$F_n < 2^n$。
::: hint
使用带两个归纳基础的强归纳法，因为$F_{n}$是由前两项定义的。
:::
::: solution
当$n = 0$和$n = 1$时：$F_0 = 0 < 1$，$F_1 = 1 < 2$。设$k \ge 1$，并假定对所有$j \le k$都有$F_j < 2^j$。则

$$
F_{k+1} = F_k + F_{k-1} < 2^k + 2^{k-1} < 2^k + 2^k = 2^{k+1}.
$$

由强归纳法（从$k \ge 1$出发的归纳步骤用到情形$k$和$k - 1 \ge 0$，两者都已涵盖），对所有$n \ge 0$都有$F_n < 2^n$。
:::
:::

::: exercise 二进制表示 {level=3}
证明每个$n \in \N$都是$2$的若干个不同的幂之和（例如$13 = 8 + 4 + 1$）。
::: hint
设$2^a$是满足$2^a \le n$的最大的$2$的幂，对$n - 2^a$应用强归纳法。
:::
::: solution
我们对$n$用强归纳法。当$n = 1 = 2^0$时，论断成立。设$n \ge 2$，并假定每个小于$n$的自然数都是$2$的若干个不同的幂之和。设$2^a$是满足$2^a \le n$的最大的$2$的幂（它存在，因为$2^0 = 1 \le n$，而当$m$很大时$2^m > n$）。则$n < 2^{a+1}$，所以$0 \le n - 2^a < 2^a$。

若$n = 2^a$，证明已完成。否则$1 \le n - 2^a < n$，所以由归纳假设，$n - 2^a$是$2$的若干个不同的幂之和。这些幂都不超过$n - 2^a < 2^a$，所以其中没有一个等于$2^a$，从而

$$
n = 2^a + (n - 2^a)
$$

是$2$的若干个不同的幂之和。（这种表示的唯一性也可以用类似的归纳法证明。）
:::
:::

::: exercise 用L形骨牌铺满棋盘 {level=3}
L形三格骨牌（L-tromino）是由一个$2\times 2$方块中的三个小方格组成的图形。证明对每个$n \in \N$，挖去任意一个方格的$2^n \times 2^n$棋盘都可以用L形三格骨牌铺满。
::: hint
把$2^{k+1}\times 2^{k+1}$的棋盘分成四个$2^k \times 2^k$的四分之一块。其中一块含有缺失的方格；在棋盘中心放一个三格骨牌，使其余三块各去掉一个方格。
:::
::: solution
当$n = 1$时，挖去一个方格的$2\times 2$棋盘**本身就是**一个L形三格骨牌。假定结论对$2^k\times 2^k$的棋盘成立，取一个挖去一个方格的$2^{k+1}\times 2^{k+1}$棋盘。把它分成四个$2^k\times 2^k$的四分之一块；被挖去的方格恰好位于其中一块中。四块在棋盘中心相会，每块在那里有一个角上的方格。放一个L形三格骨牌，盖住**不**含被挖去方格的那三块在中心处的三个角方格。现在四块中的每一块都是恰好去掉（或盖住）了一个方格的$2^k\times 2^k$棋盘，由归纳假设，每一块都可以铺满。再加上中心的那个三格骨牌，就铺满了整个棋盘，归纳完成。（数目检验：$4^n - 1$能被$3$整除，这是必然的。）
:::

::: exercise 良序原理蕴涵归纳原理 {level=3}
假定良序原理成立，证明归纳原理（[[#thm-induction]]）。
::: solution
设$P(n)$是$\N$上的谓词，$P(1)$为真，且对所有$k \in \N$有$P(k) \Rightarrow P(k+1)$。用反证法，假设$P(n)$对某个$n$为假。则$S = \set{n \in \N : P(n) \text{ 为假}}$非空，所以由良序原理，它有最小元素$m$。由于$P(1)$为真，$m \neq 1$，所以$m \ge 2$且$m - 1 \in \N$。由于$m - 1 < m$，而$m$是$S$的最小元素，所以$m - 1 \notin S$，即$P(m-1)$为真。对$k = m - 1$应用归纳步骤，$P(m)$为真，这与$m \in S$矛盾。因此$P(n)$对所有$n$为真。
:::
