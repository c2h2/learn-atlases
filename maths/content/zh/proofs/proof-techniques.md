考虑$n = 0, 1, 2, \dots$时的数$n^2 + n + 41$：

$$
41,\ 43,\ 47,\ 53,\ 61,\ 71,\ 83,\ 97,\ 113,\ 131,\ 151,\ \dots
$$

这些数个个都是素数——直到$n = 39$为止的每个值也都是素数，一连四十个素数。人们很容易由此断定$n^2 + n + 41$总是素数。然而并非如此：当$n = 40$时，$40^2 + 40 + 41 = 40\cdot 41 + 41 = 41^2$。四十个支持性的例子并没有确立一个对每个$n$都成立的规律，而且无论多少个例子都做不到这一点。

这就是数学坚持要求**证明**的原因。证明是由有限多个命题构成的一条链，其中每个命题或者是假设、定义、公理或此前已证明的结果，或者由前面的命题通过有效的推理规则（[[proofs/propositional-logic#thm-inference]]）推出；链中的最后一个命题就是要证明的结果。证明用有限多步确立了一个关于无穷多种情形的论断，而且任何人都可以逐行检验它。

本章介绍基本的证明方法——直接证明、逆否证法、反证法、分情况证明——以及存在性证明和反例，最后就如何写出别人能够读懂的证明给出一些建议。用[[proofs/quantifiers]]一章的工具分析命题的逻辑形式，通常就能看出应当尝试哪种方法。

## 从定义出发

关于一个概念的证明，要从它的精确定义出发。我们将以整数的一些熟知性质为练习对象，所以先确定有关的定义。

::: definition 偶数、奇数、整除、素数与有理数 {#def-integers}
设$a$、$b$和$n$是整数。

- 如果对某个整数$k$有$n = 2k$，就称$n$是**偶数**；如果对某个整数$k$有$n = 2k+1$，就称$n$是**奇数**。
- 如果对某个整数$k$有$b = ak$，就称$a$**整除**$b$，记作$a \mid b$。这时我们说$a$是$b$的**因数**（或因子），$b$是$a$的**倍数**。
- 如果整数$p \ge 2$的正因数只有$1$和$p$，就称$p$是**素数**；不是素数的整数$n \ge 2$称为**合数**。
- 如果实数$x$可以写成$x = a/b$，其中$a, b$是整数且$b \neq 0$，就称$x$是**有理数**，否则称为**无理数**。有理数集记为$\Q$。
:::

我们把整数的算术当作已知：整数的和、差、积都是整数，并且通常的代数运算法则成立。我们还要用到这样一个事实：**每个整数或者是偶数，或者是奇数，但不能两者都是**；这可以由带余除法得出（[[number-theory/divisibility]]）。所以“不是偶数”就意味着“是奇数”，反之亦然。

任何证明的良好第一步都是**展开定义**：把“$m$是奇数”换成“对某个整数$k$有$m = 2k+1$”，把“$a \mid b$”换成“对某个整数$k$有$b = ak$”。这样，命题就变成了一个代数问题。

## 直接证明

要**直接**证明蕴涵$p \Rightarrow q$，就假定$p$，然后推出$q$。对于形如$\forall x,\ (P(x) \Rightarrow Q(x))$的命题，以“设$x$使$P(x)$成立”开头，以“$Q(x)$成立”结束。由于假设为假的蕴涵自动为真，$p$为假的情形无须考虑。

::: proposition 两个奇数之和是偶数 {#prop-odd-sum}
若$m$和$n$是奇数，则$m + n$是偶数。
:::

::: proof
设$m$和$n$是奇数。由定义，存在整数$k$和$l$，使得$m = 2k + 1$，$n = 2l + 1$。于是

$$
m + n = 2k + 2l + 2 = 2(k + l + 1).
$$

由于$k + l + 1$是整数，$m + n$是偶数。
:::

::: warning 使用不同的字母
在这个证明中，一个常见的错误是写成“$m = 2k+1$且$n = 2k+1$”。这等于说$m = n$，于是这个“证明”只涵盖了一个奇数与它自身之和。定义中的每个“存在”都产生各自的见证，来自不同假设的见证必须取不同的名字。
:::

::: proposition 整除的性质 {#prop-divides}
设$a$、$b$、$c$是整数。

1. 若$a \mid b$且$b \mid c$，则$a \mid c$。
2. 若$a \mid b$且$a \mid c$，则对所有整数$x$和$y$，$a \mid (bx + cy)$。
:::

::: proof
1. 设$b = ak$，$c = bl$，其中$k, l \in \Z$。则$c = (ak)l = a(kl)$，且$kl \in \Z$，所以$a \mid c$。
2. 设$b = ak$，$c = al$，其中$k, l \in \Z$，并设$x, y \in \Z$。则$bx + cy = akx + aly = a(kx + ly)$，其中$kx + ly \in \Z$，所以$a \mid (bx + cy)$。
:::

::: example 有理数对加法封闭 {#ex-rational-sum}
证明两个有理数之和是有理数。
::: solution
设$x$和$y$是有理数。则存在整数$a, b, c, d$，其中$b \neq 0$且$d \neq 0$，使得$x = a/b$，$y = c/d$。因此

$$
x + y = \frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}.
$$

这里$ad + bc$和$bd$都是整数，并且$bd \neq 0$，因为非零整数之积不为零。所以$x + y$是分母非零的两个整数之商，即有理数。
:::
:::

直接证明并不总是按照书写的方向找到的。我们常常在草稿中从结论出发**倒推**，然后再正向地写出证明，[[calculus-1/limits]]一章中的ε–δ证明就是如此。

::: example 算术-几何平均值不等式 {#ex-amgm}
证明对所有实数$x, y \ge 0$，

$$
\sqrt{xy} \le \frac{x + y}{2},
$$

并且等号成立当且仅当$x = y$。
::: solution
*草稿*。我们希望得到$\frac{x+y}{2} - \sqrt{xy} \ge 0$。由于$x = (\sqrt x)^2$，$y = (\sqrt y)^2$，左边等于$\frac12\bigl((\sqrt x)^2 - 2\sqrt x\sqrt y + (\sqrt y)^2\bigr)$，这是一个完全平方。

*证明*。设$x, y \ge 0$，于是$\sqrt x$和$\sqrt y$有定义，且$\sqrt{xy} = \sqrt x\,\sqrt y$。则

$$
\frac{x + y}{2} - \sqrt{xy} = \frac{(\sqrt x)^2 - 2\sqrt x\sqrt y + (\sqrt y)^2}{2} = \frac{(\sqrt x - \sqrt y)^2}{2} \ge 0,
$$

因为平方是非负的。等号恰好在$\sqrt x - \sqrt y = 0$，即$\sqrt x = \sqrt y$时成立；由于平方根函数在$[0, \infty)$上是单射，这当且仅当$x = y$时发生。
:::
:::

## 逆否证法

由[[proofs/propositional-logic#thm-contrapositive]]，蕴涵$p \Rightarrow q$与它的逆否命题$\neg q \Rightarrow \neg p$逻辑等价。所以要证明$p \Rightarrow q$，可以假定$q$为假，然后推出$p$为假。当$\neg q$给了我们一些具体的东西可以处理、而$p$没有时，这种方法很有帮助。

::: lemma 平方与奇偶性 {#lem-square-even}
设$n$是整数。若$n^2$是偶数，则$n$是偶数。
:::

::: proof
直接证明很别扭：从$n^2 = 2k$出发，没有明显的办法得到关于$n$的信息。所以我们证明逆否命题“若$n$是奇数，则$n^2$是奇数”。（由于每个整数是偶数或奇数，但不能两者都是，“不是偶数”就意味着“是奇数”。）设$n$是奇数，比如$n = 2k + 1$，其中$k \in \Z$。则

$$
n^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1,
$$

且$2k^2 + 2k \in \Z$，所以$n^2$是奇数。这就证明了逆否命题，从而证明了引理。
:::

::: corollary {#cor-square-even}
整数$n$是偶数当且仅当$n^2$是偶数。
:::

::: proof
双条件命题要从两个方向证明。（$\Rightarrow$）若$n = 2k$，则$n^2 = 2(2k^2)$是偶数。（$\Leftarrow$）这就是[[#lem-square-even]]。
:::

::: example 整数的乘积 {#ex-product-even}
设$a$和$b$是整数。证明：若$ab$是偶数，则$a$是偶数或$b$是偶数。
::: solution
由德摩根律，结论“$a$是偶数或$b$是偶数”的否定是“$a$是奇数且$b$是奇数”。所以逆否命题是“若$a$和$b$都是奇数，则$ab$是奇数”。设$a = 2k+1$，$b = 2l+1$，其中$k, l \in \Z$。则

$$
ab = 4kl + 2k + 2l + 1 = 2(2kl + k + l) + 1
$$

是奇数。这就证明了逆否命题，从而证明了原命题。
:::
:::

同样的想法在远离整数的地方也适用。要证明“若$x \ge 0$是无理数，则$\sqrt{x}$是无理数”，只需证明其逆否命题：若$\sqrt x = a/b$是有理数，则$x = a^2/b^2$是有理数。

::: quiz
要用逆否证法证明“对每个整数$n$，若$n^2 + 3$是偶数，则$n$是奇数”，应当假定什么？又必须证明什么？
- [ ] 假定$n$是奇数；证明$n^2 + 3$是偶数。
- [x] 假定$n$是偶数；证明$n^2 + 3$是奇数。
- [ ] 假定$n^2 + 3$是奇数；证明$n$是偶数。
- [ ] 假定$n^2 + 3$是偶数且$n$是偶数；推出矛盾。
::: solution
$p \Rightarrow q$的逆否命题是$\neg q \Rightarrow \neg p$：在这里就是“若$n$不是奇数（即是偶数），则$n^2 + 3$不是偶数（即是奇数）”。确实，若$n = 2k$，则$n^2 + 3 = 2(2k^2 + 1) + 1$。第一个选项是逆命题；第三个是否命题；第四个是反证法，它也行得通，但不是逆否证法。
:::
:::

## 反证法

要用**反证法**证明命题$S$，就假定$S$为假，然后推出某种不可能的东西——形如$r \land \neg r$的命题。由于真的假定经过有效的推理步骤不可能导出假的结论，假定$\neg S$必定为假，所以$S$为真。用逻辑的语言来说，$(\neg S \Rightarrow \bot) \equiv S$。这种方法（也称为**归谬法**，reductio ad absurdum）对于断言某种东西**不**存在或**不**具有某种性质的命题尤其自然，因为假定其反面就给了我们一个可以处理的对象。

我们的证明将用到**良序原理**：正整数的每个非空集合都有最小元素。[[proofs/induction#thm-well-ordering]]将讨论这一原理，并证明它与归纳法等价。

::: theorem 2的平方根是无理数 {#thm-sqrt2}
不存在满足$x^2 = 2$的有理数$x$。换句话说，$\sqrt 2$是无理数。
:::

::: proof
用反证法，假设$\sqrt 2$是有理数，比如$\sqrt 2 = a/b$，其中$a, b \in \Z$且$b \neq 0$。必要时同时改变$a$和$b$的符号，可以假定$b > 0$。于是集合

$$
S = \set{ q \in \N : q\sqrt 2 \in \Z }
$$

包含$b$，因而非空；由良序原理，它有最小元素$q$。令$p = q\sqrt 2$，这是一个整数。两边平方得$p^2 = 2q^2$，所以$p^2$是偶数，由[[#lem-square-even]]，$p$是偶数：$p = 2c$，其中$c \in \Z$。于是$4c^2 = 2q^2$，所以$q^2 = 2c^2$是偶数，再由[[#lem-square-even]]，$q$是偶数：$q = 2d$，其中$d \in \N$且$d < q$。但是

$$
d\sqrt 2 = \frac{q\sqrt 2}{2} = \frac{p}{2} = c \in \Z,
$$

所以$d \in S$，这与$q$的最小性矛盾。因此$\sqrt 2$是无理数。
:::

更常见的版本是这样说的：“写$\sqrt 2 = a/b$，其中的分数是既约分数；则$a$和$b$都是偶数，矛盾。”这是同一个论证；保证既约分数存在的正是良序原理。

我们的第二个经典例子需要一个引理，而这个引理本身也是用反证法证明的。

::: lemma 素因数 {#lem-prime-divisor}
每个整数$n \ge 2$都有素因数。
:::

::: proof
由$n$的满足$d \ge 2$的因数$d$构成的集合$D$非空，因为$n \in D$。由良序原理，它有最小元素$p$。用反证法，假设$p$不是素数。则$p$有一个因数$e$，满足$1 < e < p$。由于$e \mid p$且$p \mid n$，由[[#prop-divides]]得$e \mid n$，所以$e \in D$且$e < p$，这与$p$的最小性矛盾。因此$p$是$n$的一个素因数。
:::

::: theorem 欧几里得（Euclid）定理 {#thm-primes}
素数有无穷多个。
:::

::: proof
用反证法，假设素数只有有限多个，把它们全部列出：$p_1, p_2, \dots, p_k$（这个列表非空，因为$2$是素数）。考虑

$$
N = p_1 p_2 \cdots p_k + 1.
$$

由于$N \ge 3$，由[[#lem-prime-divisor]]，存在整除$N$的素数$p$。每个素数都在我们的列表中，所以对某个$i$有$p = p_i$，于是$p$也整除乘积$p_1 p_2\cdots p_k$。由[[#prop-divides]]（取$x = 1$，$y = -1$），$p$整除$N - p_1 p_2 \cdots p_k = 1$。但素数$p \ge 2$不整除$1$。这个矛盾表明素数有无穷多个。
:::

::: warning 欧几里得数未必是素数
这个证明**并没有**说$N = p_1 p_2\cdots p_k + 1$是素数。对前六个素数，$2\cdot3\cdot5\cdot7\cdot11\cdot13 + 1 = 30031 = 59 \times 509$。证明只需要$N$有**某个**素因数，并且这个素因数不可能在列表中。（在反证法的证明中，我们是在一个不可能的世界里工作，在那里列表包含了所有素数；在那里得出的结论，比如“$N$必定是素数”，不应被带出那个世界。）
:::

::: remark 反证法还是逆否证法？
用反证法证明$p \Rightarrow q$时，我们假定$p$**并且**$\neg q$，然后寻找矛盾。如果找到的矛盾仅仅是$\neg p$，那么这个论证实际上是在证明逆否命题$\neg q \Rightarrow \neg p$，把它写成逆否证法会更清楚。当导出的不可能之事是别的东西时，才使用反证法，就像上面两个定理那样。
:::

::: quiz
要用反证法证明“不存在最大的素数”，你应当首先假定：
- [ ] 每个数都有比它大的素数
- [x] 存在最大的素数
- [ ] 不存在最大的素数
- [ ] 有些数不是素数
::: solution
用反证法证明$S$，要假定$\neg S$。这里$S$是“不存在最大的素数”，所以$\neg S$是“存在最大的素数”——记它为$P$——然后推出矛盾（例如利用$P! + 1$，或者利用欧几里得的论证）。假定$S$本身就会陷入循环论证。
:::
:::

## 分情况证明

如果由假设可知若干情形中必有一种发生，我们就可以在每种情形下分别证明结论；这就是有效的推理规则$p \lor q,\ p \Rightarrow r,\ q \Rightarrow r \;\therefore\; r$。这些情形必须是**穷尽的**——它们合起来涵盖了所有可能——但它们不必互相排斥。

回忆实数的**绝对值**：当$a \ge 0$时$\abs{a} = a$，当$a < 0$时$\abs{a} = -a$。它的定义分两种情形，所以关于它的证明也常常分两种情形。

::: lemma {#lem-abs}
对实数$a$和$b$，$\abs{a} \le b$当且仅当$-b \le a \le b$。特别地，$-\abs{a} \le a \le \abs{a}$。
:::

::: proof
*情形1：$a \ge 0$*。这时$\abs{a} = a$。若$a \le b$，则$b \ge a \ge 0$，所以$-b \le 0 \le a$，从而$-b \le a \le b$。反之，若$-b \le a \le b$，则$\abs{a} = a \le b$。

*情形2：$a < 0$*。这时$\abs{a} = -a$。若$-a \le b$，则$a \ge -b$，并且$a < 0 < -a \le b$；所以$-b \le a \le b$。反之，若$-b \le a$，则$\abs{a} = -a \le b$。

这两种情形是穷尽的，这就证明了等价性。取$b = \abs{a}$即得最后的结论。
:::

::: theorem 三角不等式 {#thm-triangle}
对所有实数$x$和$y$，$\abs{x + y} \le \abs{x} + \abs{y}$。
:::

::: proof
由[[#lem-abs]]，$-\abs{x} \le x \le \abs{x}$且$-\abs{y} \le y \le \abs{y}$。把这两个不等式相加，得

$$
-\bigl(\abs{x} + \abs{y}\bigr) \le x + y \le \abs{x} + \abs{y},
$$

再由[[#lem-abs]]（取$a = x + y$，$b = \abs{x} + \abs{y}$），这就是$\abs{x + y} \le \abs{x} + \abs{y}$。
:::

三角不等式是分析学中用得最多的不等式；它最早的用途之一，是在[[calculus-1/limits]]一章中证明极限的唯一性。

分情况讨论对整数同样有用：我们可以按照除以某个数所得的余数来划分情形。

::: proposition 模4的平方 {#prop-squares-mod4}
对每个整数$n$，$n^2$具有$4k$或$4k + 1$的形式，其中$k$是某个整数。
:::

::: proof
*情形1：$n$为偶数*，$n = 2m$。这时$n^2 = 4m^2$，具有$4k$的形式，其中$k = m^2$。

*情形2：$n$为奇数*，$n = 2m + 1$。这时$n^2 = 4m^2 + 4m + 1 = 4(m^2 + m) + 1$，具有$4k+1$的形式。

每个整数都是偶数或奇数，所以这两种情形是穷尽的。
:::

::: example 两个平方数之和 {#ex-two-squares}
证明形如$4k + 3$的整数（例如$2023 = 4\cdot 505 + 3$）都不是两个整数的平方和。
::: solution
设$a, b \in \Z$。由[[#prop-squares-mod4]]，$a^2$和$b^2$都具有$4k$或$4k + 1$的形式，所以（不计$a$与$b$的次序）它们的和有三种情形：

$$
a^2 + b^2 = \begin{cases} 4k + 4l = 4(k+l), \\ 4k + (4l + 1) = 4(k + l) + 1, \\ (4k+1) + (4l+1) = 4(k+l) + 2. \end{cases}
$$

因此$a^2 + b^2$除以$4$的余数是$0$、$1$或$2$，永远不会是$3$。由于除以$4$的余数是唯一的（[[number-theory/divisibility]]），对每个整数$m$都有$a^2 + b^2 \neq 4m + 3$。
:::
:::

caption: 模$4$的乘法表。它的对角线列出了各个平方：$0, 1, 0, 1$——恰好是[[#prop-squares-mod4]]中的两种情形。把$n$改为$8$：奇数$1, 3, 5, 7$的平方都是$1$，这就证明了每个奇数的平方都具有$8k + 1$的形式（每个奇剩余对应一种情形）。
:::

有时两种情形是对称的，这时我们可以说**不失一般性**（英文缩写为“WLOG”），我们处于其中一种情形。

::: example 不失一般性 {#ex-wlog}
证明对所有实数$x, y$，$\max(x, y) = \dfrac{x + y + \abs{x - y}}{2}$。
::: solution
交换$x$与$y$时，两边都不变（注意$\abs{x - y} = \abs{y - x}$）。所以不失一般性，可以假定$x \ge y$：$x < y$的情形只不过是交换了名字的同一个命题。若$x \ge y$，则$\abs{x - y} = x - y$，并且

$$
\frac{x + y + (x - y)}{2} = x = \max(x, y).
$$

只有当被省略的情形确实是互换角色后的同一个论证时，写“不失一般性”才是一种正当的简略；否则，每一种情形都必须写出来。
:::
:::

## 存在性、唯一性与反例

要证明$\exists x,\ P(x)$，最令人信服的方法是**构造性的**：给出一个具体的$x$，并验证$P(x)$。有时，一个**非构造性的**论证能证明存在性，却不告诉我们哪个对象满足要求。

::: theorem 无理数的无理数次幂可以是有理数 {#thm-irrational-power}
存在无理数$a$和$b$，使得$a^b$是有理数。
:::

::: proof
考虑$x = \sqrt{2}^{\sqrt 2}$。$x$要么是有理数，要么不是。

*情形1：$x$是有理数*。这时取$a = b = \sqrt 2$即可，因为由[[#thm-sqrt2]]，两者都是无理数。

*情形2：$x$是无理数*。这时取$a = x$，$b = \sqrt 2$：

$$
a^b = \left(\sqrt{2}^{\sqrt 2}\right)^{\sqrt 2} = \sqrt{2}^{\sqrt 2 \cdot \sqrt 2} = \sqrt 2^{\,2} = 2,
$$

这是有理数。无论哪种情形，所要求的$a$和$b$都存在。
:::

这个证明没有告诉我们出现的是哪种情形。（事实上，由1934年的盖尔范德-施奈德（Gelfond–Schneider）定理，$\sqrt 2^{\sqrt 2}$是无理数，但上面的证明并不需要这一知识；习题中给出了一对明确的$a$、$b$。）

**唯一性**论断——“至多有一个$x$满足$P(x)$”——通常这样证明：假定$P(x)$和$P(y)$，然后推出$x = y$，如[[proofs/quantifiers#def-unique]]所示。

要**否证**一个全称命题，一个**反例**就够了，不需要别的：不需要一般性的论证，也不需要解释这个命题为什么“应当”不成立。本章开头的例子就是用$n = 40$否证了“对所有$n \ge 0$，$n^2 + n + 41$都是素数”。

::: example 证明或否证 {#ex-prove-disprove}
判断下列各命题是否为真，并证明你的结论。

1. 对每个实数$x$，若$x^2 > 1$，则$x > 1$。
2. 若$x$是有理数，$y$是无理数，则$x + y$是无理数。
3. 两个无理数之和是无理数。
::: solution
1. **假。**反例：$x = -2$满足$x^2 = 4 > 1$，但$x < 1$。
2. **真。**用反证法，假设$x$是有理数，$y$是无理数，而$x + y = r$是有理数。则$y = r - x$是两个有理数之差，因而是有理数（由[[#ex-rational-sum]]，因为$-x$是有理数）——这与$y$是无理数矛盾。
3. **假。**$\sqrt 2$是无理数，$-\sqrt 2$也是（若$-\sqrt 2 = a/b$，则$\sqrt 2 = (-a)/b$）。但它们的和$0$是有理数。
:::
:::

::: quiz
哪一对$(x, y)$是“对所有实数$x$和$y$，若$x < y$，则$x^2 < y^2$”的反例？
- [ ] $x = 1$，$y = 2$
- [x] $x = -3$，$y = 1$
- [ ] $x = 2$，$y = 1$
- [ ] $x = 0$，$y = 0$
::: solution
蕴涵的反例必须使假设为真而结论为假。对$x = -3$，$y = 1$，有$x < y$，但$x^2 = 9 > 1 = y^2$。数对$(1, 2)$满足该命题；数对$(2, 1)$和$(0, 0)$不满足假设$x < y$，所以对它们而言蕴涵（空）真。
:::
:::

## 书写证明

证明是写给读者看的，读者应当能够检验每一步，而不必猜测你的意思。下面是一些准则：

- **说明你要证明什么，以及如何证明。**“我们证明逆否命题。”“用反证法，假设……”“我们分两种情形讨论。”
- **用句子来写。**$\Rightarrow$和$\therefore$之类的符号不能代替“所以”“因此”“由于”。由一列公式构成的证明，把逻辑推理留给了读者。
- **引入每一个符号。**“设$n$是奇数。则对某个整数$k$有$n = 2k+1$。”绝不要使用未经定义的字母。
- **区分已知的和想要的。**绝不要从待证的命题出发，对它进行变形，直到得出某个真命题。
- **清楚地结束**——写上“这就证明了论断”，或者符号∎——让读者知道证明已经结束。

::: warning 从结论出发论证
下面是一个无效的“证明”，它要证明对所有实数$x$有$x^2 + 1 \ge 2x$：“$x^2 + 1 \ge 2x$，所以$x^2 - 2x + 1 \ge 0$，所以$(x-1)^2 \ge 0$，这是成立的。”它**从**论断推出了一个真命题，这什么也证明不了：用同样的方法，“$-1 = 1$，所以$(-1)^2 = 1^2$，所以$1 = 1$，这是成立的”就会证明$-1 = 1$。正确的证明是正向进行的：“对每个实数$x$，$(x-1)^2 \ge 0$；展开得$x^2 - 2x + 1 \ge 0$，所以$x^2 + 1 \ge 2x$。”那段草稿对于**找到**证明是有用的，但写出来的证明必须从已知的东西出发。（在这里，在各步之间写上$\iff$也是有效的，因为每一步都是可逆的——但那样你就必须验证每一步确实可逆。）
:::

::: history
我们今天所理解的证明始于古希腊。欧几里得（Euclid）的《几何原本》（*Elements*，约公元前300年）从一小串定义和公设出发，推导出了几何学和算术中的数百个结果；第九卷命题20就是素数有无穷多个这一定理，所用的论证与上面给出的基本相同。$\sqrt 2$的无理性——用希腊人的说法，即正方形的边与对角线不可公度——是毕达哥拉斯学派在公元前5世纪发现的（后世的传说将其归功于梅塔蓬图姆的希帕索斯（Hippasus of Metapontum）），亚里士多德（Aristotle）在《前分析篇》（*Prior Analytics*）中把它的证明作为归谬法（reductio ad impossibile）的标准例子加以引用：如果对角线是可公度的，那么奇数就会等于偶数。非构造性的存在性证明在20世纪初引起了争议：布劳威尔（L. E. J. Brouwer）和直觉主义者主张，“$x$要么是有理数，要么不是”这样的推理不能用于关于无穷集合的命题；大多数数学家接受这类论证，但构造性数学至今仍是一个活跃的领域。
:::

## 后续内容

此后的每一章都会用到这些方法。[[proofs/induction]]一章将补充关于全体自然数的命题最重要的证明方法。在[[proofs/sets]]一章中，要证明两个集合相等，就要证明两个包含关系，这是双条件的直接应用。数论建立在本章的定义之上：欧几里得定理和素因数的存在性引出了[[number-theory/primes]]一章中的唯一分解，而对模$4$的平方的分情况讨论则是通向[[number-theory/congruences]]一章中同余理论的第一步。三角不等式和反证法是[[real-analysis/sequences]]和[[real-analysis/continuity]]两章中的日常工具。

::: summary
- 证明是由有限多个有根据的命题构成的链；例子无论多少，都不能证明一个全称论断（$n^2 + n + 41$对$n \le 39$是素数，但对$n = 40$不是）。
- 从展开定义开始，并给每个见证取各自的名字。$p \Rightarrow q$的**直接证明**假定$p$并推出$q$；草稿可以倒推，但写出来的证明要正向进行。
- **逆否证法：**改为证明$\neg q \Rightarrow \neg p$，例如证明“$n^2$为偶数 $\Rightarrow$ $n$为偶数”时。双条件命题需要证明两个方向。
- **反证法：**假定命题为假，推出不可能之事。经典例子：$\sqrt 2$是无理数（[[#thm-sqrt2]]），素数有无穷多个（[[#thm-primes]]）。
- **分情况证明**中的情形必须是穷尽的：奇偶性、数的正负号、余数。三角不等式$\abs{x+y}\le\abs{x}+\abs{y}$以及平方数模$4$余$0$或$1$这一事实，都是这样证明的。
- 存在性证明可以是构造性的，也可以是非构造性的；唯一性是指任意两个解都相等；一个反例就能否证一个全称命题。
- 用句子书写证明，说明所用的方法，定义每一个符号，绝不从结论出发进行论证。
:::

## 习题

::: exercise 一个直接证明 {level=1}
证明：若$n$是奇数，则$3n + 5$是偶数。
::: solution
设$n$是奇数，则对某个整数$k$有$n = 2k + 1$。于是$3n + 5 = 6k + 3 + 5 = 6k + 8 = 2(3k + 4)$，而$3k + 4$是整数，所以$3n + 5$是偶数。
:::
:::

::: exercise 一个反例 {level=1}
否证：对所有整数$a$和$b$，若$a \mid b$且$b \mid a$，则$a = b$。正确的结论是什么？
::: solution
取$a = 2$，$b = -2$。则$b = a\cdot(-1)$，$a = b \cdot (-1)$，所以$a \mid b$且$b \mid a$，但$a \neq b$。正确的结论是$a = \pm b$。（若$b = ak$且$a = bl$，则$a = akl$。若$a = 0$，则$b = 0 = a$；否则$kl = 1$，所以$k = l = \pm 1$。）
:::
:::

::: exercise 欧拉（Euler）的素数生成多项式 {level=1 check="40"}
使$n^2 + n + 41$不是素数的最小整数$n \ge 0$是多少？
::: solution
$n = 0, 1, \dots, 39$时的值都是素数（这可以用计算机验证，也可以耐心地手算验证）。当$n = 40$时，$40^2 + 40 + 41 = 40(40 + 1) + 41 = 41\cdot 41$，是合数。所以答案是$40$。（$n = 41$也不行：$41^2 + 41 + 41 = 41 \cdot 43$。）
:::
:::

::: exercise 逆否命题 {level=2}
设$a$和$b$是整数。证明：若$a + b \ge 15$，则$a \ge 8$或$b \ge 8$。
::: solution
我们证明逆否命题。“$a \ge 8$或$b \ge 8$”的否定是“$a < 8$且$b < 8$”，即$a \le 7$且$b \le 7$（因为$a, b$是整数）。于是$a + b \le 14$，所以$a + b < 15$，这正是假设的否定。
:::
:::

::: exercise 3的平方根 {level=2}
证明$\sqrt 3$是无理数。
::: hint
先按$n$除以$3$的余数分情况，证明：若$3 \mid n^2$，则$3 \mid n$。
:::
::: solution
*引理：若$3 \mid n^2$，则$3 \mid n$*。我们证明逆否命题。若$3 \nmid n$，则$n = 3m + 1$或$n = 3m + 2$。在前一种情形，$n^2 = 9m^2 + 6m + 1 = 3(3m^2 + 2m) + 1$；在后一种情形，$n^2 = 9m^2 + 12m + 4 = 3(3m^2 + 4m + 1) + 1$。无论哪种情形，$n^2$除以$3$都余$1$，所以$3 \nmid n^2$。

*定理*。假设$\sqrt 3$是有理数。与[[#thm-sqrt2]]的证明一样，设$q$是使$q\sqrt 3 \in \Z$的最小正整数，令$p = q \sqrt 3$。则$p^2 = 3q^2$，所以$3 \mid p^2$，由引理得$p = 3c$。于是$9c^2 = 3q^2$，所以$q^2 = 3c^2$，从而$3 \mid q$：$q = 3d$，其中$0 < d < q$。但$d\sqrt3 = p/3 = c \in \Z$，这与$q$的最小性矛盾。
:::
:::

::: exercise 模3分情况 {level=2}
证明对每个整数$n$，$n^3 - n$都能被$3$整除。
::: solution
因式分解：$n^3 - n = (n-1)n(n+1)$。每个整数$n$都具有$3m$、$3m+1$或$3m+2$的形式。

- 若$n = 3m$，则因子$n$能被$3$整除。
- 若$n = 3m + 1$，则因子$n - 1 = 3m$能被$3$整除。
- 若$n = 3m + 2$，则因子$n + 1 = 3(m+1)$能被$3$整除。

在每种情形下，都有一个因子是$3$的倍数，所以乘积也是$3$的倍数：若$3 \mid u$，则对任意整数$v$有$3 \mid uv$。（归纳法给出了另一种证明；见[[proofs/induction]]。）
:::
:::

::: exercise 奇数的平方 {level=2}
证明：若$n$是奇数，则$n^2 - 1$能被$8$整除。
::: hint
写$n = 2k+1$，进行因式分解，再分情况证明$k(k+1)$是偶数。
:::
::: solution
设$n = 2k + 1$。则$n^2 - 1 = 4k^2 + 4k = 4k(k+1)$。而$k(k+1)$是偶数：若$k$是偶数，则$k(k+1)$是偶数；若$k$是奇数，则$k + 1$是偶数，$k(k+1)$也是偶数。记$k(k+1) = 2j$，得$n^2 - 1 = 8j$。（这正是模运算图中观察到的现象：每个奇数的平方都具有$8j + 1$的形式。）
:::
:::

::: exercise 有理数乘以无理数 {level=2}
设$x$是非零有理数，$y$是无理数。证明$xy$是无理数。两个无理数之积总是无理数吗？
::: solution
用反证法，假设$xy = r$是有理数。由于$x = a/b \neq 0$，其中$a, b \in \Z$，有$a \neq 0$且$b \neq 0$，所以$1/x = b/a$是有理数，而$y = r \cdot (1/x)$是两个有理数之积，因而是有理数（若$r = c/d$，则$y = cb/(da)$，且$da \neq 0$）。这与$y$是无理数矛盾。

两个无理数之积可以是有理数：$\sqrt 2 \cdot \sqrt 2 = 2$。（假设$x \neq 0$也是必需的：$0 \cdot \sqrt 2 = 0$。）
:::
:::

::: exercise 一个构造性的例子 {level=3}
证明$\log_2 3$是无理数。由此推出$a = \sqrt 2$和$b = \log_2 9$是使$a^b$为有理数的无理数，从而给出[[#thm-irrational-power]]的一个构造性证明。
::: hint
若$\log_2 3 = p/q$，其中$p, q$是正整数，则把两边作为$2$的指数，再取$q$次幂。
:::
::: solution
由于$1 < 3 < 4$，有$0 < \log_2 3 < 2$，所以如果它是有理数，它就等于某个$p/q$，其中$p, q \in \N$。于是$2^{p/q} = 3$，两边取$q$次幂得$2^p = 3^q$。左边是偶数（因为$p \ge 1$），右边是奇数（由[[#ex-product-even]]中的论证，奇数之积是奇数）。这个矛盾表明$\log_2 3$是无理数。

而$b = \log_2 9 = 2\log_2 3$是无理数（若$2\log_2 3 = r$是有理数，则$\log_2 3 = r/2$也是有理数），且由[[#thm-sqrt2]]，$a = \sqrt 2$是无理数。最后，

$$
a^b = \left(2^{1/2}\right)^{\log_2 9} = 2^{\frac12 \log_2 9} = 2^{\log_2 3} = 3,
$$

这是有理数。
:::
:::

::: exercise 形如4k + 3的素数 {level=3}
证明形如$4k + 3$的素数有无穷多个。可以利用每个整数$n \ge 2$都是素数之积这一事实（[[proofs/induction]]）。
::: hint
模仿欧几里得：如果$p_1, \dots, p_r$就是所有这样的素数，考虑$N = 4p_1 p_2 \cdots p_r - 1$。如果$N$的素因数都具有$4k + 1$的形式，你能得出什么结论？
:::
::: solution
首先，形如$4k+1$的整数之积仍具有这种形式：$(4k+1)(4l+1) = 4(4kl + k + l) + 1$；反复运用这一点可知，有限多个这样的数之积都具有$4m+1$的形式。

用反证法，假设$p_1, \dots, p_r$是所有形如$4k+3$的素数（至少有一个，即$3$）。令$N = 4p_1 p_2\cdots p_r - 1 = 4(p_1\cdots p_r - 1) + 3$。则$N \ge 11$是奇数，所以它的素因数都是奇数，而每个奇素数都具有$4k+1$或$4k+3$的形式。如果$N$的素因数都具有$4k+1$的形式，那么由第一段，$N$也具有这种形式；但$N$具有$4m + 3$的形式，而除以$4$的余数是唯一的。所以有某个形如$4k + 3$的素数$q$整除$N$。于是对某个$i$有$q = p_i$，所以$q \mid 4p_1\cdots p_r$，由[[#prop-divides]]，$q$整除$4p_1 \cdots p_r - N = 1$，这是不可能的。因此形如$4k + 3$的素数有无穷多个。
:::
