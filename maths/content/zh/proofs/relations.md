如果时钟现在指向9点，那么100小时后它指向几点？从12点算起，那时时针走过了$9 + 100 = 109 = 9\cdot 12 + 1$小时：转了九整圈又多一小时，所以时钟指向1点。时钟无法区分数$1, 13, 25, \dots, 109$；对时钟而言它们是相同的，因为它们相差$12$的倍数。分数也是如此：$\frac12$、$\frac24$和$\frac{50}{100}$用不同的整数对写成，却表示同一个有理数。

数学中经常把不同的对象看作“就当前目的而言是相同的”，而**等价关系**正是使这一点精确化的工具。我们将看到，等价关系总是把一个集合分成互不相交的类，然后这些类本身又可以当作新的对象来处理——模$n$的整数，乃至有理数和实数，都是这样构造出来的。另一类重要的关系是**序**，它说明一个对象何时“排在”另一个对象之前。两者都是一般的关系概念的特例，我们就从关系讲起。

## 关系

::: definition 关系 {#def-relation}
从集合$A$到集合$B$的**关系**是一个子集$R\subseteq A\times B$。当$(a,b)\in R$时，我们写$a\mathrel{R}b$，读作“$a$与$b$有关系”。从$A$到$A$的关系称为$A$**上**的关系。
:::

熟悉的符号$=$、$<$、$\le$、$\subseteq$和$\mid$（“整除”）都表示关系。例如，$\R$上的$\le$是集合$\set{(x,y)\in\R^2 : x\le y}$，即直线$y = x$上及其上方的半平面；$\N$上的整除关系是满足$b = ka$（对某个$k\in\Z$）的数对$(a,b)$组成的集合。“是……的父亲或母亲”是全体人的集合上的一个关系。每个函数$f\colon A\to B$都是一个关系——即它的图像（[[proofs/functions]]）——并具有特殊的性质：每个$a\in A$恰与一个$b\in B$有关系。一般的关系去掉了这一要求：一个元素可以与许多元素有关系，也可以与任何元素都没有关系。

小的有限集上的关系可以画成**有向图**：每个元素画一个点，每当$a\mathrel{R}b$时就从$a$画一个箭头指向$b$（若$a \mathrel{R} a$，则在$a$处画一个环）。它也可以记录成一个由$0$和$1$组成的**矩阵**：第$a$行第$b$列的元素为$1$当且仅当$a\mathrel{R}b$。

## 关系的性质

::: definition 自反、对称、反对称、传递 {#def-relation-properties}
集合$A$上的关系$R$称为

- **自反的**，如果对每个$a\in A$都有$a\mathrel{R}a$；
- **对称的**，如果对所有$a,b\in A$，由$a\mathrel{R}b$可推出$b\mathrel{R}a$；
- **反对称的**，如果对所有$a,b\in A$，由$a\mathrel{R}b$且$b\mathrel{R}a$可推出$a = b$；
- **传递的**，如果对所有$a,b,c\in A$，由$a\mathrel{R}b$且$b\mathrel{R}c$可推出$a\mathrel{R}c$。
:::

每个性质都有直观的图示。自反：每个点都有环，矩阵的对角线上全是$1$。对称：每个箭头都伴有反向的箭头，矩阵是对称矩阵。反对称：没有两个**不同的**点由两个方向的箭头相连。传递：只要有箭头$a\to b\to c$，捷径$a\to c$也一定存在。

| 关系 | 自反 | 对称 | 反对称 | 传递 |
|---|---|---|---|---|
| 任意集合上的$=$ | 是 | 是 | 是 | 是 |
| $\R$上的$\le$ | 是 | 否 | 是 | 是 |
| $\R$上的$<$ | 否 | 否 | 是 | 是 |
| $\N$上的整除 | 是 | 否 | 是 | 是 |
| $\mathcal{P}(X)$上的$\subseteq$，$X\neq\varnothing$ | 是 | 否 | 是 | 是 |
| $\R$上的$\abs{x-y}\le 1$ | 是 | 是 | 否 | 否 |
| 人群上的“是……的兄弟姐妹” | 否 | 是 | 否 | 否 |

注意$<$是**空真地**反对称的：前提“$a<b$且$b<a$”永远不成立，所以这个蕴涵式总是成立。

::: example 检验各项性质 {#ex-properties}
判断下列每个关系具有四个性质中的哪些。
(a) $\R$上：$x\sim y$当且仅当$x^2 = y^2$。
(b) $\Z$上：$a\mathrel{R}b$当且仅当$a+b$是奇数。
(c) 集合$A = \set{1,2}$上的空关系$R = \varnothing$。
::: solution
(a) *自反*：$x^2 = x^2$。*对称*：若$x^2 = y^2$，则$y^2 = x^2$。*传递*：若$x^2 = y^2$且$y^2 = z^2$，则$x^2 = z^2$。*不反对称*：$1\sim -1$且$-1\sim 1$，但$1\neq -1$。成立的三个性质都继承自相等关系的相应性质——下面我们将利用这一模式。

(b) *不自反*：$a + a = 2a$是偶数，所以实际上没有一个整数与自身有关系。*对称*，因为$a+b = b+a$。*不反对称*：$1\mathrel{R}2$且$2\mathrel{R}1$，而$1\neq2$。*不传递*：$1\mathrel{R}2$且$2\mathrel{R}1$，但$1 + 1 = 2$是偶数，所以$1\mathrel{R}1$不成立。

(c) 空关系*不自反*，因为$(1,1)\notin R$。它是*对称的*、*反对称的*和*传递的*，而且都是空真的：每个条件都形如“若某些有序对属于$R$，则……”，而没有任何有序对属于$R$。
:::
:::

::: warning 对称且传递不能推出自反
下面是一个诱人的“证明”，声称每个对称且传递的关系都是自反的：任给$a$，若$a\mathrel{R}b$，则由对称性得$b\mathrel{R}a$，于是由传递性得$a\mathrel{R}a$。错误出在“若”字上：这个论证需要**存在**某个$b$使$a\mathrel{R}b$，而这样的$b$可能根本不存在。[[#ex-properties]]的(c)就是一个反例。类似地，**对称**与**反对称**并不是对立的：相等关系两者都是，而$\set{1,2,3}$上的关系$\set{(1,2),(2,1),(1,3)}$两者都不是。
:::

::: quiz
设$R$是$\R$上的关系：$x\mathrel{R}y$当且仅当$\abs{x-y}\le 1$。$R$不具有哪个性质？
- [ ] 自反性
- [ ] 对称性
- [x] 传递性
- [ ] 都不缺——三个性质它都有
::: solution
$\abs{x - x} = 0\le 1$，所以$R$是自反的；$\abs{x-y} = \abs{y-x}$，所以它是对称的。但$0\mathrel{R}1$且$1\mathrel{R}2$，而$\abs{0-2} = 2 > 1$，所以$0\mathrel{R}2$不成立：$R$不是传递的。“与……接近”不是等价关系，因为微小的差异可以累积起来。
:::
:::

## 等价关系与划分

::: definition 等价关系 {#def-equivalence-relation}
集合$A$上的**等价关系**是$A$上自反、对称且传递的关系。等价关系通常写成$a\sim b$，读作“$a$等价于$b$”。
:::

例子比比皆是。

- 任意集合上的相等关系——这是最细的等价关系；以及关系$A\times A$，在它之下任何元素都与任何元素等价，这是最粗的等价关系。
- $\Z$上：若$a$与$b$的奇偶性相同，则$a\sim b$。
- $\R$上：若$x^2 = y^2$，则$x\sim y$（[[#ex-properties]]）。
- 在一群人的集合上：“与……生日相同”。
- 平面几何中：三角形的全等，以及三角形的相似。
- 对任意函数$f\colon A\to B$：若$f(a) = f(b)$，则$a\sim_f b$。自反性、对称性和传递性都继承自相等关系，正如[[#ex-properties]](a)那样，那里就是$f(x) = x^2$的情形。

::: definition 等价类与商集 {#def-equivalence-class}
设$\sim$是$A$上的等价关系。$a\in A$的**等价类**是

$$
[a] = \set{x\in A : x\sim a}.
$$

等价类中的任一元素都称为该类的一个**代表元**。所有等价类组成的集合$A/{\sim} = \set{[a] : a\in A}$称为$A$关于$\sim$的**商集**。
:::

对于$\Z$上的“奇偶性相同”，恰有两个等价类：$[0]$（偶数）和$[1]$（奇数），并且$[0] = [2] = [-4]$——一个类有许多名字，每个代表元对应一个。所以$\Z/{\sim} = \set{[0],[1]}$有两个元素，每个元素都是一个无限集。对于$x\sim y \iff x^2 = y^2$，$x$的等价类是$[x] = \set{x,-x}$，除非$x = 0$，它都有两个元素。

关于等价类的关键事实是：两个等价类决不会部分重叠。

::: lemma 两个等价类何时相等？ {#lem-classes}
设$\sim$是$A$上的等价关系，$a,b\in A$。下列命题等价：

1. $a\sim b$；
2. $[a] = [b]$；
3. $[a]\cap[b]\neq\varnothing$。
:::

::: proof
*1 ⇒ 2*。设$a\sim b$。若$x\in[a]$，则$x\sim a$且$a\sim b$，所以由传递性得$x\sim b$，即$x\in[b]$。因此$[a]\subseteq[b]$。由对称性得$b\sim a$，交换$a$与$b$的位置，同样的论证给出$[b]\subseteq[a]$。

*2 ⇒ 3*。由自反性，$a\in[a]$，所以$a\in[a] = [b]$，从而$a\in[a]\cap[b]$。

*3 ⇒ 1*。设$x\in[a]\cap[b]$，则$x\sim a$且$x\sim b$。由对称性得$a\sim x$，再由传递性得$a\sim b$。
:::

::: definition 划分 {#def-partition}
集合$A$的一个**划分**是由$A$的子集组成的一个集合族$\mathcal{P}$，其中的子集称为**块**，满足

1. 每个块都非空；
2. $A$的每个元素都属于某个块；
3. 不同的块互不相交。
:::

例如，$\set{\set{1,2},\set{3},\set{4,5,6}}$是$[6]$的一个划分，偶数和奇数构成$\Z$的一个划分。$A$的每个元素都属于**恰好**一个块：由条件2，至少属于一个；由条件3，至多属于一个。

::: theorem 等价关系与划分 {#thm-partition}
设$A$是集合。

1. 若$\sim$是$A$上的等价关系，则它的等价类构成$A$的一个划分。
2. 若$\mathcal{P}$是$A$的划分，则关系“若$a$与$b$属于同一个块，则$a\sim_{\mathcal P} b$”是$A$上的等价关系，并且它的等价类恰好就是$\mathcal{P}$的块。
3. 这两种构造互逆。因此，$A$上的等价关系与$A$的划分一一对应。
:::

::: proof
*1*。每个等价类都非空，因为由自反性，$a\in[a]$。每个$a\in A$都属于某个等价类，即$[a]$。若两个等价类$[a]$与$[b]$相交，则由[[#lem-classes]]，$[a] = [b]$；所以不同的等价类互不相交。因此这些等价类构成一个划分。

*2*。每个$a$都属于某个块，所以$a\sim_{\mathcal P} a$：该关系是自反的。条件“$a$与$b$属于同一个块”与$a$、$b$的先后顺序无关，所以该关系是对称的。关于传递性，设对块$P, P'\in\mathcal{P}$有$a, b\in P$且$b, c\in P'$。则$b\in P\cap P'$，所以$P$与$P'$相交，从而$P = P'$。所以$a$和$c$都属于$P$，$a\sim_{\mathcal P} c$。

现在设$a\in A$，$P$是包含$a$的唯一的块。元素$x$满足$x\sim_{\mathcal P} a$当且仅当$x$属于包含$a$的那个块，即$x \in P$。所以$[a] = P$：每个等价类都是一个块。反过来，每个块$P$都非空，并且对任意$a\in P$有$P = [a]$：每个块都是一个等价类。

*3*。从等价关系$\sim$出发，作出它的等价类划分，再作出关系“属于同一个等价类”。若$a$与$b$属于同一个等价类$[c]$，则$a\sim c$且$b\sim c$，所以由对称性和传递性得$a\sim b$；反过来，若$a\sim b$，则$a$和$b$都属于$[b]$。所以我们重新得到了$\sim$。从划分$\mathcal{P}$出发，第2部分表明$\sim_{\mathcal P}$的等价类恰好就是那些块，所以我们重新得到了$\mathcal P$。
:::

::: intuition 分装进盒子
划分把$A$的元素分装进一个个盒子，而相应的等价关系就是规则“与……在同一个盒子里”。[[#thm-partition]]说的是，这是对同一事物的两种描述，所以我们可以选用更方便的那一种：逐个元素地检验性质时用关系，计数和画图时用划分。
:::

::: example 从划分到关系，再回到划分 {#ex-partition}
设$\mathcal{P} = \set{\set{1,2},\set{3},\set{4,5,6}}$是$[6]$的一个划分。把相应的等价关系列为有序对的集合。它包含多少个有序对？
::: solution
两个元素有关系当且仅当它们属于同一个块。块$\set{1,2}$贡献$2^2 = 4$个有序对$(1,1)$、$(1,2)$、$(2,1)$、$(2,2)$；块$\set3$贡献$(3,3)$；块$\set{4,5,6}$贡献满足$a,b\in\set{4,5,6}$的全部$3^2 = 9$个有序对$(a,b)$。总共有$4+1+9 = 14$个有序对。一般地，块的大小为$k_1,\dots,k_r$的划分对应于一个含有$k_1^2+\cdots+k_r^2$个有序对的等价关系。

反过来，这个关系的等价类是$[1] = \set{1,2}$、$[3] = \set{3}$和$[4] = \set{4,5,6}$，这就重新得到了$\mathcal{P}$。
:::
:::

::: quiz
集合$\set{1,2,3}$上有多少个不同的等价关系？
- [ ] $3$
- [x] $5$
- [ ] $8$
- [ ] $9$
::: solution
由[[#thm-partition]]，等价关系与划分一一对应，所以我们计算$\set{1,2,3}$的划分的个数：一个块$\set{1,2,3}$；一个二元块加一个单元素块（$\set{1,2},\set3$，或$\set{1,3},\set2$，或$\set{2,3},\set1$）；或者三个单元素块。共计$1 + 3 + 1 = 5$个。（对更大的集合计算划分的个数，就得到贝尔（Bell）数$1, 2, 5, 15, 52, \dots$）
:::
:::

数学家正是用商集来构造新的数系的：取旧数的数对，当两个数对“应当”表示同一个新数时，就规定它们等价，然后把新数**定义**为这些等价类。

::: example 构造有理数 {#ex-fractions}
设$S = \Z\times(\Z\setminus\set{0})$，若$ad = bc$，则定义$(a,b)\sim(c,d)$。证明$\sim$是$S$上的等价关系，并证明等价类的乘法$[(a,b)]\cdot[(c,d)] = [(ac,bd)]$是良定义的。
::: solution
把$(a,b)$看作分数$\frac ab$；这个关系表达的就是法则$\frac ab = \frac cd \iff ad = bc$。

*自反*：$ab = ba$。*对称*：若$ad = bc$，则$cb = da$。*传递*：设$(a,b)\sim(c,d)$且$(c,d)\sim(e,f)$，即$ad = bc$且$cf = de$。把第一个等式乘以$f$，再利用第二个等式，得

$$
adf = bcf = b(cf) = b(de) = bde,
$$

所以$d(af - be) = 0$。由于$d\neq0$，得$af = be$，即$(a,b)\sim(e,f)$。注意条件$d \neq 0$用在了哪里：如果允许“分母”为零，传递性就会被破坏，因为$(1,2)\sim(0,0)\sim(1,3)$，但$(1,2)\not\sim(1,3)$。

*良定义性*。这个公式是借助所选的代表元来定义两个等价类的乘积的，所以我们必须验证所得的等价类与代表元的选取无关。首先，$bd\neq 0$，所以$(ac, bd)\in S$。现在设$(a,b)\sim(a',b')$且$(c,d)\sim(c',d')$，即$ab' = a'b$且$cd' = c'd$。则

$$
(ac)(b'd') = (ab')(cd') = (a'b)(c'd) = (a'c')(bd),
$$

这说明$(ac,bd)\sim(a'c',b'd')$。所以$[(ac,bd)] = [(a'c',b'd')]$，这正是所要证明的。

商集$S/{\sim}$连同这个乘法以及加法$[(a,b)]+[(c,d)] = [(ad+bc,\ bd)]$（它也是良定义的），**就是**有理数域$\Q$：等价类$[(a,b)]$就是我们写作$\frac ab$的那个数。
:::
:::

同样的想法可以由自然数对构造出整数（见习题），由有理数列构造出实数（[[real-analysis/real-numbers]]）。

## 模 n 同余

初等数学中最重要的等价关系，就是时钟算术的形式化。

::: definition 模 n 同余 {#def-congruence}
设$n\in\N$。如果$n$整除$a-b$，即对某个$k\in\Z$有$a - b = kn$，就称整数$a$与$b$**模$n$同余**，记作$a\equiv b\pmod n$。数$n$称为**模**。
:::

例如$109\equiv 1\pmod{12}$，$-3\equiv 9\pmod{12}$，并且$a\equiv 0\pmod n$当且仅当$n\mid a$。在下面的证明中，我们要用到**带余除法**：对每个$a\in\Z$和$n\in\N$，存在唯一的整数$q$和$r$，使$a = qn + r$且$0\le r<n$；数$r$称为$a$除以$n$的**余数**（见[[number-theory/divisibility]]）。

::: theorem 同余类 {#thm-congruence}
设$n\in\N$。模$n$同余是$\Z$上的等价关系。每个整数都恰与$0, 1, \dots, n-1$中的一个模$n$同余，即它除以$n$的余数。因此恰有$n$个同余类：$[0], [1], \dots, [n-1]$。
:::

::: proof
*自反*：$a - a = 0 = 0\cdot n$。*对称*：若$a - b = kn$，则$b - a = (-k)n$。*传递*：若$a - b = kn$且$b - c = ln$，则$a - c = (a-b) + (b-c) = (k+l)n$。

设$a\in\Z$，写成$a = qn + r$，其中$0\le r<n$。则$a - r = qn$，所以$a\equiv r\pmod n$。关于唯一性，设$a\equiv r$且$a\equiv r'$，其中$0\le r,r' < n$。则由对称性和传递性，$r\equiv r'$，所以$n$整除$r - r'$。但$-n < r - r' < n$，而严格介于$-n$与$n$之间的$n$的倍数只有$0$；因此$r = r'$。所以等价类$[0],\dots,[n-1]$互不相同，并且每个整数都属于其中之一。
:::

这个商集记作$\Z_n$（也写作$\Z/n\Z$）：

$$
\Z_n = \set{[0],[1],\dots,[n-1]}.
$$

当$n = 12$时，这十二个等价类就是钟面上的十二个位置，其中$12$写作$0$。$\Z_n$之所以有用，是因为我们可以用它的元素进行计算。

::: theorem 模 n 算术 {#thm-zn}
设$n\in\N$。若$a\equiv a'\pmod n$且$b\equiv b'\pmod n$，则

$$
a+b\equiv a'+b'\pmod n \qquad\text{以及}\qquad ab\equiv a'b'\pmod n.
$$

因此，$\Z_n$上的运算$[a]+[b] = [a+b]$和$[a]\cdot[b] = [ab]$是良定义的。
:::

::: proof
写$a' = a + kn$，$b' = b + ln$，其中$k,l\in\Z$。则

$$
a'+b' = (a+b) + (k+l)n \qquad\text{以及}\qquad a'b' = ab + (al + bk + kln)\,n,
$$

所以$n$整除$(a'+b') - (a+b)$和$a'b' - ab$。第二个结论随之成立，因为这恰好是良定义性所要求的：把$a$和$b$换成同一等价类中的其他代表元$a'$和$b'$，不会改变等价类$[a+b]$和$[ab]$。
:::

反复应用乘法法则（形式上，对$k$用归纳法）可知，对每个$k \in \N$，由$a\equiv b$可推出$a^k\equiv b^k\pmod n$。这使我们可以在计算的任何阶段把一个数换成较小的代表元。

::: example 用同余进行计算 {#ex-congruence}
(a) 用$\Z_{12}$回答本章开头的问题。(b) 求$2^{100}$除以$7$的余数。(c) 证明$10^{100}+2$能被$3$整除。
::: solution
(a) 由于$100 = 8\cdot12+4$，在$\Z_{12}$中有$[9]+[100] = [9]+[4] = [13] = [1]$：时钟指向1点。

(b) 寻找一个与$1$同余的$2$的较小的幂：$2^3 = 8\equiv1\pmod7$。由于$100 = 3\cdot33+1$，

$$
2^{100} = \bigl(2^3\bigr)^{33}\cdot 2 \equiv 1^{33}\cdot2 = 2 \pmod 7.
$$

由于$0 \le 2 < 7$，余数是$2$。

(c) $10\equiv1\pmod3$，所以$10^{100}\equiv1^{100} = 1$，从而$10^{100}+2\equiv 1+2 = 3\equiv0\pmod 3$。同样的推理表明，由于$10^k\equiv1$，每个数都与它的各位数字之和模$3$（以及模$9$）同余：这就是大家熟悉的整除判别法。
:::
:::

::: warning 不要做除法，也不要把指数模 n 约化
加法、减法和乘法都与同余相容，但除法不然：$2\cdot3\equiv2\cdot0\pmod6$，然而$3\not\equiv0\pmod 6$。模$n$的同余式两边的公因子$a$可以消去，当且仅当$a$与$n$没有大于$1$的公因数（[[number-theory/congruences]]）。指数也不能模$n$约化：$2^5 = 32\equiv2\pmod3$，但$5\equiv 2 \pmod 3$，而$2^2 = 4\equiv1\pmod3$。在[[#ex-congruence]]中，我们约化的是**底数**，这是[[#thm-zn]]所允许的；对指数则使用了精确的等式$100 = 3\cdot 33 + 1$。
:::

## 偏序

关系的第二大家族描述的是诸如“不超过”“包含于”和“整除”之类的比较。

::: definition 偏序 {#def-partial-order}
集合$A$上的**偏序**是$A$上自反、反对称且传递的关系$\preceq$。二元组$(A,\preceq)$称为**偏序集**（partially ordered set，简称 **poset**）。若$a\preceq b$或$b\preceq a$，则称元素$a, b$**可比较**；若任意两个元素都可比较，则称$\preceq$为**全序**（或**线性序**）。我们用$a\prec b$表示“$a\preceq b$且$a\neq b$”。
:::

- $\N$、$\Z$、$\Q$或$\R$上通常的$\le$是全序。
- $\mathcal{P}(X)$上的包含关系$\subseteq$是偏序（[[proofs/sets#def-subset]]），而当$X$有两个不同元素$a,b$时，它不是全序：$\set a$与$\set b$互不包含。
- $\N$上的整除关系是偏序。它是自反的（$a = 1\cdot a$）和传递的（若$b = ka$且$c = lb$，则$c = (lk)a$）。它是反对称的，因为对$a,b \in \N$，$a\mid b$迫使$a\le b$，所以由$a\mid b$和$b\mid a$得$a \le b\le a$。它不是全序：$2$和$3$不可比较。在$\Z$上，整除关系**不是**反对称的，因为$2\mid-2$且$-2\mid 2$。
- $\R^2$上的**字典序**：若$a<c$，或$a = c$且$b\le d$，则$(a,b)\preceq(c,d)$。它是全序。

有限偏序集可以画成**哈塞图**（Hasse diagram）。若$a\prec b$，且不存在$c$使$a\prec c\prec b$，则称$b$**覆盖**$a$。把每个元素画成一个点，每当$a\prec b$时就把$b$画在比$a$高的位置，并且当且仅当$b$覆盖$a$时用线段连接$a$与$b$。环和捷径都省略不画，因为自反性和传递性可以把它们恢复出来：$a\preceq b$成立当且仅当$a = b$，或者存在一条从$a$到$b$的向上的路径。

nodes: 1@0,0; 2@-1,1; 3@1,1; 4@-2,2; 6@0,2; 12@-1,3
edges: 1>2; 1>3; 2>4; 2>6; 3>6; 4>12; 6>12
algorithm: topo
caption: $12$的因数在整除关系下的哈塞图，每条线段都向上定向，从一个数指向覆盖它的数。七条线段编码了全部$18$个有关系的有序对。逐步执行拓扑排序：它每次列出一个元素，总是选择下方没有其他元素的元素，最终得到一个与整除关系相容的全序——即该偏序的一个**线性扩张**。
:::

::: definition 极小元、极大元、最小元与最大元 {#def-extremal}
设$(A,\preceq)$是偏序集，$m\in A$。称$m$为

- **极小元**，如果不存在$x\in A$使$x\prec m$；称$m$为**极大元**，如果不存在$x\in A$使$m\prec x$；
- **最小元**，如果对每个$x\in A$都有$m\preceq x$；称$m$为**最大元**，如果对每个$x\in A$都有$x\preceq m$。
:::

“极小”是说没有元素在$m$之下；“最小”是说$m$在一切元素之下。在哈塞图中，极小元就是没有线段从下方连到它的那些元素。

::: proposition 关于极值元素的事实 {#prop-extremal}
设$(A,\preceq)$是偏序集。

1. $A$至多有一个最小元。最小元是极小元，而且这时它是唯一的极小元。
2. 若$A$是非空有限集，则它有极小元。
3. 若$\preceq$是全序，则每个极小元都是最小元。

关于极大元和最大元的相应结论同样成立。
:::

::: proof
1. 若$m$和$m'$都是最小元，则$m\preceq m'$且$m'\preceq m$，所以由反对称性得$m = m'$。设$m$是最小元。若$x\prec m$，则$x\preceq m$，同时（由于$m$是最小元）$m\preceq x$，所以$x = m$，与$x\neq m$矛盾；因此$m$是极小元。若$m'$是任一极小元，则$m\preceq m'$，而由于$m'$是极小元，$m\prec m'$是不可能的，所以$m = m'$。

2. 对$\abs A\ge1$用归纳法。单元素的偏序集有极小元。假设每个含$n\ge 1$个元素的偏序集都有极小元，并设$\abs A = n+1$。取$a\in A$；集合$A' = A\setminus\set a$在同一序关系下有极小元$m'$。若$a\prec m'$不成立，则$m'$是$A$中的极小元：$A'$中没有元素严格位于$m'$之下，$a$也不严格位于$m'$之下。若$a\prec m'$，则$a$是$A$中的极小元：如果某个$x\in A'$满足$x\prec a$，那么由传递性得$x\preceq m'$，并且$x \neq m'$（否则由$m' \prec a \prec m'$和反对称性将得到$a = m'$），所以$x\prec m'$，这与$m'$在$A'$中的极小性矛盾。

3. 设$m$是极小元，$x\in A$。由于该序是全序，$x\preceq m$或$m\preceq x$。若$x\preceq m$，则$x = m$，因为$x\prec m$是不可能的；无论哪种情形，都有$m\preceq x$。所以$m$是最小元。

把这些结论应用于反向的序$a\succeq b$（它仍是偏序），即得关于极大元和最大元的结论。
:::

::: example 极小元不同于最小元 {#ex-extremal}
求以整除关系为序的$A = \set{2,3,4,6,8,12}$的极小元、极大元、最小元和最大元。
::: solution
一个元素是极小元，当且仅当$A$中没有其他元素整除它。除$2$和$3$外，每个元素在$A$中都有真因数（$2\mid4$，$2\mid6$，$2\mid8$，$2\mid12$），而$2$和$3$没有。所以极小元是$2$和$3$。不存在最小元，因为最小元必须同时整除$2$和$3$；而且由[[#prop-extremal]]，最小元会是唯一的极小元。

一个元素是极大元，当且仅当它不整除$A$中的其他元素。$2,3,4,6$都整除$12$，而$8$和$12$不整除$A$中的其他元素（$8\nmid12$）。所以极大元是$8$和$12$，不存在最大元。

作为对比：在整除关系下，$\N$本身有最小元$1$，却根本没有极大元；而$(\Z,\le)$没有极小元——[[#prop-extremal]]的第2条需要有限性。
:::
:::

::: application 排程与先修要求
一个项目中的各项任务——或一门课程的各章——按“必须排在……之前”构成偏序。本站的各章就构成这样一个偏序集：每一章都列出了它所需要的先修章节，取这些要求的全部推论（即**自反传递闭包**）就得到一个偏序——它是反对称的，因为没有一章会依赖于自身，即使是间接依赖也没有。完成这些任务的一个可行顺序就是一个**线性扩张**：包含该偏序的一个全序。对有限偏序集而言，线性扩张总是存在的：反复取出一个极小元（由[[#prop-extremal]]，它存在），并把它追加到列表末尾。这一过程称为**拓扑排序**，构建系统、电子表格和软件包管理器都要用到它，[[discrete/graph-algorithms]]中将对它进行研究。
:::

::: quiz
把$\set{a,b,c}$的六个非空真子集按包含关系排序。这个偏序集有多少个极大元？
- [ ] $1$
- [x] $3$
- [ ] $6$
- [ ] 没有，因为不存在最大元
::: solution
二元子集$\set{a,b}$、$\set{a,c}$和$\set{b,c}$是极大元：$\set{a,b,c}$的子集中严格包含它们之一的只有$\set{a,b,c}$本身，而它已被去掉。单元素集不是极大元，因为每个单元素集都包含在某个二元集合中。不存在最大元——没有一个集合包含所有其他集合——但这并不妨碍极大元的存在。
:::

::: history
记号$a\equiv b\pmod n$是卡尔·弗里德里希·高斯（Carl Friedrich Gauss）在《算术研究》（*Disquisitiones Arithmeticae*，1801）中引入的，这部著作使同余计算成为数论的核心工具。把新对象构造为等价类，在19世纪成为一种标准的构造方法：夏尔·梅雷（Charles Méray，1869）和格奥尔格·康托尔（Georg Cantor，1872）各自独立地由有理数列构造出了实数；1884年，戈特洛布·弗雷格（Gottlob Frege）通过能与一个概念建立一一对应的那些概念所组成的类，来定义该概念的数。有序集的一般理论是由里夏德·戴德金（Richard Dedekind）和费利克斯·豪斯多夫（Felix Hausdorff）发展起来的：戴德金对格的研究始于1897年，豪斯多夫的工作则见于他的《集论基础》（*Grundzüge der Mengenlehre*，1914）。哈塞图得名于赫尔穆特·哈塞（Helmut Hasse），他在代数中卓有成效地使用了这种图，尽管类似的图在19世纪90年代就已出现。
:::

## 后续内容

同余是初等数论的基础（[[number-theory/congruences]]），而$\Z_n$是有限环的第一个例子（[[abstract-algebra/rings]]）。商的构造在代数和拓扑中反复出现：子群的陪集是一个等价关系的等价类，这是拉格朗日（Lagrange）定理（[[abstract-algebra/lagrange]]）的关键；把一个空间中的点粘合起来，就得到[[topology/quotient-spaces]]中的商空间。在图中，“有路径相连”是一个等价关系，它的等价类就是连通分支（[[discrete/graphs]]）。偏序在[[discrete/graph-algorithms]]中以拓扑排序的形式出现，而在[[proofs/cardinality]]中，“元素个数不多于”的表现就像集合大小上的一个序。

::: summary
- 从$A$到$B$的关系是$A\times B$的子集；有限集上的关系可以画成有向图或$0$–$1$矩阵。函数就是每个元素恰与一个元素有关系的那种关系。
- 关键的性质是自反、对称、反对称和传递。每个性质都必须单独检验；特别地，对称且传递不能推出自反。
- 等价关系是自反、对称且传递的关系。两个等价类或者相等，或者不相交（[[#lem-classes]]），并且$A$上的等价关系与$A$的划分恰好一一对应（[[#thm-partition]]）。
- 商集用等价类构造新的对象；等价类上的运算必须验证是良定义的，即与所选的代表元无关。
- $a\equiv b\pmod n$是指$n\mid a-b$。共有$n$个同余类，$\Z_n$继承了良定义的加法和乘法（[[#thm-zn]]）——但一般没有除法。
- 偏序是自反、反对称且传递的关系；有限偏序集可以画成哈塞图。极小元与最小元不同：最小元是唯一的，并且是唯一的极小元；每个非空有限偏序集都有极小元。
:::

## 习题

::: exercise 整数上的四个关系 {level=1}
判断下列$\Z$上的每个关系具有自反、对称、反对称、传递中的哪些性质。
(a) 若$a+b$是偶数，则$a\mathrel{R}b$。
(b) 若$\abs{a-b}\le1$，则$a\mathrel{R}b$。
(c) 若$ab>0$，则$a\mathrel{R}b$。
(d) 若$a\mid b$，则$a\mathrel{R}b$。
::: solution
(a) $a+b$是偶数当且仅当$a$与$b$的奇偶性相同，所以$R$是等价关系：自反、对称且传递。它不是反对称的：$0\mathrel{R}2$且$2\mathrel{R}0$。

(b) 自反且对称。不是反对称的（$0\mathrel{R}1$且$1\mathrel{R}0$），也不是传递的（$0\mathrel{R}1$，$1\mathrel{R}2$，但$0\mathrel{R}2$不成立）。

(c) 不是自反的，因为$0\cdot0 = 0$。是对称的，因为$ab = ba$。是传递的：$ab > 0$意味着$a$和$b$都非零且同号，如果$b$与$c$也同号，那么$a$与$c$同号。不是反对称的：$1\mathrel{R}2$且$2\mathrel{R}1$。

(d) 自反（$a = 1\cdot a$）且传递，但不是对称的（$1\mid2$，$2\nmid1$），并且在$\Z$上不是反对称的（$2\mid-2$且$-2\mid2$）。
:::

::: exercise 一个大的幂 {level=1 check="4"}
求$3^{100}$除以$7$的余数。
::: hint
计算$3^1, 3^2, \dots$模$7$的值，直到得到$1$为止。
:::
::: solution
模$7$：$3^2 = 9\equiv2$，所以$3^3\equiv 6$，而$3^6 = (3^3)^2\equiv 36\equiv1$。由于$100 = 6\cdot16+4$，

$$
3^{100} = \bigl(3^6\bigr)^{16}\cdot3^4\equiv 3^4 = 81 = 11\cdot7+4\equiv 4\pmod 7.
$$

余数是$4$。

::: exercise 模1的实数 {level=2}
在$\R$上，若$x-y\in\Z$，则定义$x\sim y$。证明$\sim$是等价关系，并证明每个等价类恰好包含$[0,1)$中的一个数。
::: solution
*自反*：$x - x = 0\in\Z$。*对称*：若$x-y\in\Z$，则$y-x = -(x-y)\in\Z$。*传递*：若$x-y$和$y-z$都是整数，则它们的和$x-z$也是整数。

给定$x\in\R$，令$n = \lfloor x\rfloor$为满足$n\le x$的最大整数，于是$n\le x<n+1$。则$r = x-n$属于$[0,1)$，并且$x - r = n\in\Z$，所以$r\in[x]$。若$r, r'\in[0,1)$都属于$[x]$，则$r\sim r'$，所以$r-r'$是整数；但$-1 < r-r' < 1$，所以$r - r' = 0$。因此每个等价类与$[0,1)$恰好交于一点。（商集$\R/{\sim}$可以想象成把$[0,1]$的两端粘合起来——得到一个圆周；见[[topology/quotient-spaces]]。）
:::
:::

::: exercise 构造整数 {level=2}
在$\N_0\times\N_0$上，若$a+d = b+c$，则定义$(a,b)\sim(c,d)$。证明$\sim$是等价关系，描述$(a,b)$的等价类，并证明$[(a,b)]+[(c,d)] = [(a+c,\ b+d)]$是良定义的。
::: hint
把$(a,b)$看作整数$a - b$。
:::
::: solution
*自反*：$a + b = b + a$。*对称*：若$a+d = b+c$，则$c+b = d+a$。*传递*：若$a+d = b+c$且$c+f = d+e$，两式相加得$a+d+c+f = b+c+d+e$；消去$c+d$得$a+f = b+e$，所以$(a,b)\sim(e,f)$。

$(c,d)\sim(a,b)$意味着$c - d = a - b$，所以$(a,b)$的等价类由差相同的所有数对组成：例如$[(5,2)] = \set{(3,0),(4,1),(5,2),\dots}$代表整数$3$，而$[(0,2)] = \set{(0,2),(1,3),\dots}$代表$-2$。

*良定义性*。若$(a,b)\sim(a',b')$且$(c,d)\sim(c',d')$，则$a+b' = b+a'$且$c+d' = d+c'$。两式相加得$(a+c)+(b'+d') = (b+d)+(a'+c')$，这说明$(a+c,\ b+d)\sim(a'+c',\ b'+d')$。
:::
:::

::: exercise 四元集的划分 {level=2 check="15"}
$\set{1,2,3,4}$上有多少个等价关系？
::: hint
由[[#thm-partition]]，按块的大小分类计算划分的个数。
:::
::: solution
按块的大小对$\set{1,2,3,4}$的划分计数：

- 一个大小为$4$的块：$1$个划分；
- 大小为$3+1$：选出单元素块，$4$种方法；
- 大小为$2+2$：包含$1$的块是$\set{1,x}$，$x$有$3$种选法，另一个块随之确定：$3$种方法；
- 大小为$2+1+1$：选出二元块，$\binom42 = 6$种方法；
- 四个单元素块：$1$种方法。

总数为$1+4+3+6+1 = 15$，所以共有$15$个等价关系。

::: exercise 对称关系的计数 {level=2 check="64"}
含$3$个元素的集合上有多少个对称关系？
::: hint
对称关系由其矩阵的对角线元素和对角线上方的元素确定。
:::
::: solution
对$A = \set{a,b,c}$，一个对称关系由以下决定所确定：对$3$个对角线上的有序对$(x,x)$中的每一个，决定是否包含它；对满足$x\neq y$的$3$个无序对$\set{x,y}$中的每一个，决定是否同时包含$(x,y)$和$(y,x)$（对称性要求两者同时包含或同时不包含）。这$6$个相互独立的是/否决定给出$2^6 = 64$个对称关系。（一般地，$n$元集上共有$2^{n^2}$个关系，其中对称关系有$2^{n(n+1)/2}$个。）
:::
:::

::: exercise 每个等价关系都来自一个函数 {level=3}
设$\sim$是$A$上的等价关系，$q\colon A\to A/{\sim}$是**商映射**$q(a) = [a]$。证明$q$是满射，并且$a\sim b$当且仅当$q(a) = q(b)$。由此得出结论：$A$上的等价关系恰好就是形如$a\sim_f b \iff f(a) = f(b)$的关系，其中$f$是定义域为$A$的函数。
::: solution
$A/{\sim}$的每个元素都形如$[a]$（对某个$a\in A$），而$[a] = q(a)$，所以$q$是满射。由[[#lem-classes]]，$a\sim b$当且仅当$[a] = [b]$，即当且仅当$q(a) = q(b)$。所以$\sim$就是关系$\sim_q$。

反过来，对任意定义域为$A$的函数$f$，关系$\sim_f$是等价关系，因为$\sim_f$的自反性、对称性和传递性可由相等关系的相同性质得出：$f(a) = f(a)$；由$f(a) = f(b)$可推出$f(b) = f(a)$；由$f(a) = f(b)$和$f(b) = f(c)$可推出$f(a) = f(c)$。综合起来，$A$上的等价关系恰好就是各个关系$\sim_f$。
:::
:::

::: exercise 对称和传递何时足够 {level=3}
设$R$是集合$A$上对称且传递的关系，并且每个$a\in A$都至少与$A$的一个元素有关系。证明$R$是等价关系。举出$\set{1,2,3}$上一个对称、传递、但不自反且非空的关系的例子。
::: solution
只需证明自反性。设$a\in A$。由假设，存在$b\in A$使$a\mathrel{R}b$。由对称性得$b\mathrel{R}a$；再由传递性，从$a\mathrel{R}b$和$b\mathrel{R}a$得$a\mathrel{R}a$。

例子：$\set{1,2,3}$上的$R = \set{(1,1),(1,2),(2,1),(2,2)}$。它是对称的；它也是传递的，因为它的有序对只涉及$1$和$2$，而$\set{1,2}$中任意两个元素都有关系。它不是自反的，因为$(3,3)\notin R$——事实上$3$与任何元素都没有关系，而这正是上面的论证失效之处。
:::
:::

::: exercise 唯一的极小元 {level=3}
设$(A,\preceq)$是有限偏序集，恰有一个极小元$m$。证明$m$是最小元。说明对无限偏序集这一结论可能不成立。
::: hint
对$x\in A$，把[[#prop-extremal]]应用于$x$之下的元素组成的集合。
:::
::: solution
设$x\in A$，令$D = \set{y\in A : y\preceq x}$，这是一个有限集，并且由于$x\in D$，它非空。在从$A$继承的序下，$D$是偏序集，所以由[[#prop-extremal]]，它有极小元$y_0$。我们断言$y_0$是$A$中的极小元。若$z\in A$且$z\prec y_0$，则$z\preceq y_0\preceq x$，所以$z\in D$，这与$y_0$在$D$中的极小性矛盾。由于$m$是$A$唯一的极小元，$y_0 = m$，因此$m\preceq x$。由于$x$是任意的，$m$是最小元。

无限的反例：取$A = \Z\cup\set{\ast}$，其中$\ast$是一个新元素，在$\Z$上用通常的$\le$排序，而$\ast$只与自身可比较。没有整数是极小元（因为$n - 1 < n$），而$\ast$是极小元，所以$\ast$是唯一的极小元；但$\ast$不是最小元，因为它不在$0$之下。
:::
:::
