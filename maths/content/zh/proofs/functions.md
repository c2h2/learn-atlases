**替换密码**把字母表中的每个字母替换成一个字母来给消息加密：A 换成 Q，B 换成 W，C 换成 E，依此类推。为了让接收者能够解密，两个不同的字母绝不能被替换成同一个字母——否则收到的 Q 可能代表其中任何一个。而如果字母表中的每个字母都被用作替换字母，那么收到的每个字母都可以被解密。规则“字母 ↦ 替换字母”的这两个性质，即单射性与满射性，以及这样的规则何时可以倒过来执行的问题，正是本章的核心。

函数是仅次于集合的数学中最重要的概念。在中学里，函数通常是像$x^2 + 1$这样的公式。但是，给每个人指定其出生年份的规则，或者给每个非空有限整数集指定其最大元素的规则，同样都是函数，而其中并不涉及任何公式。本章用集合（[[proofs/sets]]）来定义函数，介绍单射、满射和双射等术语，研究复合与逆，并了解函数如何通过像与原像作用于其定义域的整个子集。

## 什么是函数？

::: definition 函数 {#def-function}
设$A$和$B$是集合。从$A$到$B$的**函数**（或**映射**）$f$，记作$f\colon A\to B$，是指给每个元素$a\in A$指定恰好一个元素$f(a)\in B$，$f(a)$称为$f$在$a$处的**值**，或$a$的**像**。集合$A$称为$f$的**定义域**，$B$称为$f$的**陪域**。$f$的**值域**（或**像**）是$f$实际取到的值组成的集合，

$$
f(A) = \set{f(a) : a\in A}\subseteq B.
$$
:::

“指定”一词可以用集合来精确化。形式上，函数$f\colon A\to B$是一个子集$f\subseteq A\times B$（[[proofs/sets#def-cartesian-product]]），使得对每个$a\in A$，恰有一个$b\in B$满足$(a,b)\in f$，这时我们写$b = f(a)$。这个子集就是我们所画的$f$的**图像**，所以形式定义是说：函数**就是**它的图像——或者更准确地说，是它的图像连同陪域$B$，因为仅凭图像并不能确定陪域。在实际中，我们把函数看作一个规则，写成$a \mapsto f(a)$（“$a$映为$f(a)$”）；例如$x\mapsto x^2+1$是函数$\R\to\R$，其图像是抛物线$\set{(x, x^2+1) : x\in\R}$。

如果两个函数$f$和$g$有相同的定义域、相同的陪域，并且对定义域中的每个$a$都有$f(a) = g(a)$，就称它们**相等**。陪域是函数的组成部分：把$x\mapsto x^2$看作函数$\R\to\R$和看作函数$\R\to[0,\infty)$，得到的是不同的函数，我们将会看到其中一个是满射而另一个不是。另一方面，公式不是函数的组成部分：$x\mapsto (x+1)^2$与$x\mapsto x^2+2x+1$是同一个函数$\R \to \R$。

有些函数出现得如此频繁，以至于有专门的名称。

- **恒等函数**$\id_A\colon A\to A$，$\id_A(a) = a$。
- **常值**函数$A\to B$，$a\mapsto b_0$，其中$b_0\in B$是固定的。
- 子集$S\subseteq A$的**包含映射**$S \to A$，$s\mapsto s$。
- 子集$S\subseteq A$的**特征函数**$\chi_S\colon A\to\set{0,1}$：若$a\in S$，则$\chi_S(a) = 1$，否则$\chi_S(a) = 0$。
- **投影**$A\times B\to A$，$(a,b)\mapsto a$，以及$A\times B\to B$，$(a,b)\mapsto b$。
- 实数**数列**$(x_n)$是一个函数$\N\to\R$，$n\mapsto x_n$。

对于小的有限集之间的函数，**箭头图**能展示一切：画出定义域和陪域，再从每个$a$画一个箭头指向$f(a)$。定义是说：**定义域的每个元素恰好发出一个箭头**。对陪域则没有任何要求：$B$的一个元素可以接收许多个箭头、一个箭头，或者一个也不接收。

::: widget mapping
domain: 1; 2; 3; 4
codomain: a; b; c; d
map: 1>b; 2>a; 3>d; 4>b
caption: 从$\set{1,2,3,4}$到$\set{a,b,c,d}$的一个函数的箭头图。有两个箭头指向$b$，没有箭头指向$c$，所以这个函数既不是单射也不是满射。改变$4$的去向，使函数成为双射；注意当两边各有四个元素时，消除一个缺陷也就消除了另一个缺陷（[[#thm-finite]]）。
:::

### 是不是函数？

要验证所提出的规则确实定义了一个函数$A\to B$，必须检查两件事：$A$的每个元素都被指定了一个值，并且这个值属于$B$；没有元素被指定两个不同的值。第二个条件称为**良定义**，它是容易被忽视的那一个。

::: example 是不是函数？ {#ex-is-function}
下列规则中哪些定义了函数？
(a) $f\colon\R\to\R$，$f(x) = 1/x$。
(b) $g\colon[0,\infty)\to\R$，$g(x) = $“满足$y^2 = x$的实数$y$”。
(c) $h\colon\Q\to\Z$，$h(p/q) = p$，其中$p$、$q$为整数且$q \neq 0$。
(d) $k\colon\Q\to\Q$，$k(p/q) = p^2/q^2$，其中$p$、$q$为整数且$q \neq 0$。
::: solution
(a) 不是函数：$0$属于定义域，但$1/0$没有定义。把定义域限制为$\R\setminus\set{0}$即可补救。

(b) 不是函数：对$x = 4$，$y = 2$和$y = -2$都满足$y^2 = x$，所以这个规则没有确定唯一的值。若要求$y \ge 0$，就得到平方根函数$x \mapsto \sqrt x$，它是一个函数。

(c) 不是函数，因为它不是良定义的。一个有理数可以有许多种分数表示：$\frac12 = \frac24$，但按这个规则，$h(\frac12) = 1$而$h(\frac24) = 2$。所给出的值取决于输入的写法，而不是输入本身。

(d) 是函数。若$\frac pq = \frac{p'}{q'}$，则$\frac{p^2}{q^2} = \bigl(\frac pq\bigr)^2 = \bigl(\frac{p'}{q'}\bigr)^2 = \frac{p'^2}{q'^2}$，所以值不依赖于表示方式：$k$就是$\Q$上的$x\mapsto x^2$。
:::
:::

只要定义域的元素有多个名字，就会出现良定义性的问题——例如这里的分数，以及[[proofs/relations]]一章中的等价类。

## 单射、满射与双射

::: definition 单射 {#def-injective}
如果$A$的不同元素有不同的像，就称函数$f\colon A\to B$是**单射**（也称**一对一的**）；等价地，

$$
\forall a_1,a_2\in A\quad \bigl(f(a_1) = f(a_2) \Rightarrow a_1 = a_2\bigr).
$$ {#eq-injective}
:::

::: definition 满射 {#def-surjective}
如果$B$的每个元素都是$A$的某个元素的像，就称函数$f\colon A\to B$是**满射**（也称**映上的**）：

$$
\forall b\in B\ \ \exists a\in A\quad f(a) = b.
$$

等价地，值域等于陪域：$f(A) = B$。
:::

::: definition 双射 {#def-bijective}
如果一个函数既是单射又是满射，就称它是**双射**（也称**一一对应**）。等价地，对每个$b\in B$，**恰有一个**$a\in A$使$f(a) = b$。
:::

在箭头图中：单射是指$B$中没有元素接收两个箭头；满射是指$B$的每个元素至少接收一个箭头；双射是指$B$的每个元素恰好接收一个箭头，从而这些箭头把$A$的元素与$B$的元素一一配对。

条件[[#eq-injective]]是“$a_1\neq a_2\Rightarrow f(a_1)\neq f(a_2)$”的逆否命题，后者是更直观的形式；而在证明中应当使用定义中的形式，因为等式比不等关系更容易处理。这些定义也决定了证明的样子。

- **单射：**设$a_1, a_2\in A$满足$f(a_1) = f(a_2)$，推出$a_1 = a_2$。
- **满射：**任取$b\in B$；找出一个满足$f(a) = b$的元素$a$（通常是在草稿中解方程$f(a) = b$），并验证它属于$A$。
- **非单射：**举出$a_1\neq a_2$，使$f(a_1) = f(a_2)$。
- **非满射：**举出一个$b\in B$，并证明对每个$a\in A$都有$f(a) \ne b$。

::: example 一个线性双射 {#ex-linear}
证明$f\colon\R\to\R$，$f(x) = 3x - 5$是双射。
::: solution
*单射*。设$x_1,x_2\in\R$满足$f(x_1) = f(x_2)$，则$3x_1 - 5 = 3x_2 - 5$，所以$3x_1 = 3x_2$，$x_1 = x_2$。

*满射*。设$y\in\R$。草稿：$3x - 5 = y$意味着$x = (y+5)/3$。于是令$x = (y+5)/3$；这是一个实数，并且$f(x) = 3\cdot\frac{y+5}{3} - 5 = y$。

因此$f$是双射。只要$m\neq0$，同样的论证对$x\mapsto mx+c$也适用。
:::
:::

::: example 平方函数与陪域的作用 {#ex-square}
考虑规则$x\mapsto x^2$，分别取下列定义域和陪域：(a) $\R\to\R$；(b) $\R\to[0,\infty)$；(c) $[0,\infty)\to\R$；(d) $[0,\infty)\to[0,\infty)$。哪些是单射？哪些是满射？
::: solution
*单射性*。在定义域$\R$上，该函数不是单射，因为$(-1)^2 = 1^2$而$-1\neq 1$。在定义域$[0,\infty)$上它是单射：若$x_1^2 = x_2^2$且$x_1,x_2\ge0$，则$0 = x_1^2 - x_2^2 = (x_1 - x_2)(x_1+x_2)$，所以$x_1 = x_2$或$x_1 + x_2 = 0$；在后一种情形下，两个数都非负且和为零，所以$x_1 = x_2 = 0$。无论哪种情形，都有$x_1 = x_2$。

*满射性*。陪域为$\R$时，该函数不是满射，因为$-1$不是任何实数的平方。陪域为$[0,\infty)$时它是满射：每个$y\ge0$都等于$(\sqrt y)^2$，而$\sqrt y$属于两种可能的定义域。

所以 (a) 既不是单射也不是满射，(b) 是满射但不是单射，(c) 是单射但不是满射，(d) 是双射。同一个规则给出了四个不同的函数，它们具有四种不同的性质组合。
:::
:::

对于函数$f\colon\R\to\R$，这些定义有直观的图示。$f(x) = c$的解就是图像与水平直线$y = c$的交点。所以$f$是单射当且仅当每条水平直线与图像**至多**相交一次，是满射当且仅当每条水平直线与图像**至少**相交一次，而当每条水平直线与图像恰好相交一次时，$f$是双射：这就是**水平线检验**。

caption: 对$f(x) = x^3 - ax$做水平线检验。移动$c$使水平直线上下滑动，并数一数交点的个数。当$a = 1.5$时，有些直线（即$\lvert c\rvert < 1/\sqrt2\approx 0.71$的那些）与图像相交三次，所以$f$不是单射；但每条直线都与图像至少相交一次，所以$f$是满射。现在令$a \le 0$：图像变成递增的，每条直线都与它恰好相交一次，$f$是$\R$上的双射。

::: quiz
设$f\colon\Z\to\Z$由$f(n) = 2n$给出，$g\colon\Z\to\Z$由$g(n) = \lfloor n/2\rfloor$给出，即不超过$n/2$的最大整数。下列哪个说法正确？
- [ ] 两者都是双射。
- [x] $f$是单射但不是满射；$g$是满射但不是单射。
- [ ] $f$是满射但不是单射；$g$是单射但不是满射。
- [ ] 两者都不是单射。
::: solution
若$2n_1 = 2n_2$，则$n_1 = n_2$，所以$f$是单射；但$f(n)$总是偶数，所以$1$不是它的值，$f$不是满射。对于$g$，每个$m\in\Z$都等于$g(2m)$，所以$g$是满射；但$g(0) = g(1) = 0$，所以$g$不是单射。在无限集上，单射性与满射性是相互独立的——与[[#thm-finite]]对比。
:::
:::

### 有限集之间的函数

对于大小相同的有限集，这两个条件是一致的，这常常能省去一半的工作。

::: theorem 等大有限集之间单射等价于满射 {#thm-finite}
设$A$和$B$是有限集，$\abs A = \abs B$，$f\colon A\to B$。则$f$是单射当且仅当$f$是满射，从而也当且仅当$f$是双射。
:::

::: proof
设$n = \abs A = \abs B$，把$A$的元素列为$a_1,\dots,a_n$。值域为$f(A) = \set{f(a_1),\dots,f(a_n)}$。

若$f$是单射，则$n$个值$f(a_1),\dots,f(a_n)$互不相同，所以$\abs{f(A)} = n = \abs B$。有限集$B$的满足$\abs S = \abs B$的子集$S$就是整个$B$：否则$B\setminus S$非空，从而$\abs S = \abs B - \abs{B\setminus S} < \abs B$。因此$f(A) = B$，$f$是满射。

若$f$不是单射，则值$f(a_1),\dots,f(a_n)$中有两个相同，所以这个列表中至多有$n-1$个不同的元素，$\abs{f(A)}\le n-1 < \abs B$。于是$f(A)\neq B$，$f$不是满射。这正是“满射蕴涵单射”的逆否命题。
:::

同样的计数表明，若$\abs A > \abs B$，则不存在单射$A\to B$——这就是**鸽巢原理**（[[discrete/advanced-counting#thm-pigeonhole]]）；若$\abs A < \abs B$，则不存在满射$A \to B$。[[#thm-finite]]对无限集不成立：上面的小测验给出了一个不是满射的单射$\Z\to\Z$。事实上，能与自身的一个真子集建立双射，正是无限集的特征，我们将在[[proofs/cardinality]]一章中看到这一点。

::: example 函数的计数 {#ex-counting}
从$A = \set{1,2,3}$到$B = \set{a,b,c,d}$的函数有多少个？其中有多少个是单射，多少个是满射？
::: solution
一个函数由独立地选取$f(1)$、$f(2)$和$f(3)$确定，每个都有$4$种选法，所以共有$4^3 = 64$个函数。对于单射，$f(1)$有$4$种选法，然后$f(2)$必须不同于$f(1)$（$3$种选法），$f(3)$必须与两者都不同（$2$种选法）：共有$4\cdot3\cdot2 = 24$个单射。满射一个也没有，因为值域至多有$3$个元素，不可能是整个$B$。

一般地，从$m$元集到$n$元集的函数共有$n^m$个，其中有$n(n-1)\cdots(n-m+1)$个是单射。满射的计数比较困难，要在[[discrete/advanced-counting]]一章中用容斥原理来完成。
:::
:::

## 复合

::: definition 复合 {#def-composition}
设$f\colon A\to B$，$g\colon B\to C$。**复合**$g\circ f\colon A\to C$是函数

$$
(g\circ f)(a) = g\bigl(f(a)\bigr)\qquad(a\in A).
$$
:::

$g\circ f$读作“$f$之后作用$g$”：先作用$f$，再作用$g$。要使$g\circ f$有意义，$f$的值必须属于$g$的定义域。复合不满足交换律：对$\R$上的$f(x) = x+1$和$g(x) = x^2$，$(g\circ f)(x) = (x+1)^2$，而$(f\circ g)(x) = x^2+1$，两者在$x = 1$处不同，分别为$4$和$2$。不过，复合满足结合律。

::: proposition 结合律与恒等函数 {#prop-associative}
设$f\colon A\to B$，$g\colon B\to C$，$h\colon C\to D$。则$h\circ(g\circ f) = (h\circ g)\circ f$，并且$f\circ\id_A = f = \id_B\circ f$。
:::

::: proof
$h\circ(g\circ f)$和$(h\circ g)\circ f$都是从$A$到$D$的函数，并且对每个$a\in A$，

$$
\bigl(h\circ(g\circ f)\bigr)(a) = h\bigl((g\circ f)(a)\bigr) = h\bigl(g(f(a))\bigr) = (h\circ g)\bigl(f(a)\bigr) = \bigl((h\circ g)\circ f\bigr)(a).
$$

类似地，对每个$a \in A$，$(f\circ\id_A)(a) = f(a) = (\id_B\circ f)(a)$。
:::

由于结合律，我们可以不加括号地写$h\circ g\circ f$。

::: theorem 复合与单射性、满射性 {#thm-composition}
设$f\colon A\to B$，$g\colon B\to C$。

1. 若$f$和$g$都是单射，则$g\circ f$也是单射。
2. 若$f$和$g$都是满射，则$g\circ f$也是满射。
3. 若$f$和$g$都是双射，则$g\circ f$也是双射。
4. 若$g\circ f$是单射，则$f$是单射。
5. 若$g\circ f$是满射，则$g$是满射。
:::

::: proof
1. 设$(g\circ f)(a_1) = (g\circ f)(a_2)$，即$g(f(a_1)) = g(f(a_2))$。由于$g$是单射，$f(a_1) = f(a_2)$；由于$f$是单射，$a_1 = a_2$。
2. 设$c\in C$。由于$g$是满射，存在$b\in B$使$g(b) = c$；由于$f$是满射，存在$a\in A$使$f(a) = b$。于是$(g\circ f)(a) = g(b) = c$。
3. 结合1和2即得。
4. 设$f(a_1) = f(a_2)$。作用$g$得$(g\circ f)(a_1) = (g\circ f)(a_2)$，由于$g\circ f$是单射，$a_1 = a_2$。
5. 设$c\in C$。存在$a\in A$使$g(f(a)) = c$，所以$b = f(a)$是$B$中满足$g(b) = c$的元素。
:::

第4条和第5条不能加强：即使$g\circ f$是双射，$f$也未必是满射，$g$也未必是单射。例如，设$A = \set{1}$，$B = \set{1,2}$，$C = \set{1}$，$f(1) = 1$，$g(1) = g(2) = 1$。则$g\circ f = \id_A$是双射，但$f$取不到$2$，而$g$把$1$和$2$映到同一点。

## 反函数

双射可以倒过来执行：由于每个$b\in B$都来自恰好一个$a\in A$，我们可以把$b$送回这个$a$。

::: definition 逆 {#def-inverse}
设$f\colon A\to B$，$g\colon B\to A$是函数。若$g\circ f = \id_A$，则称$g$为$f$的**左逆**；若$f\circ g = \id_B$，则称$g$为$f$的**右逆**；若两者兼具，则称$g$为$f$的**逆**（或双边逆）：

$$
g\bigl(f(a)\bigr) = a \ \text{ 对所有 } a\in A \qquad\text{以及}\qquad f\bigl(g(b)\bigr) = b \ \text{ 对所有 } b\in B.
$$

若$f$有逆，则称$f$**可逆**。
:::

::: theorem 双射恰好就是可逆函数 {#thm-inverse}
函数$f\colon A\to B$是双射当且仅当它有逆。此时逆是唯一的，记作$f^{-1}\colon B\to A$，而$f^{-1}(b)$是满足$f(a) = b$的唯一的$a\in A$。此外，$f^{-1}$本身也是双射，并且$(f^{-1})^{-1} = f$。
:::

::: proof
设$g$是$f$的逆。则$g\circ f = \id_A$是单射，所以由[[#thm-composition]]的第4条，$f$是单射；又$f\circ g = \id_B$是满射，所以由第5条，$f$是满射。因此$f$是双射。

反过来，设$f$是双射。对每个$b\in B$，恰有一个$a\in A$使$f(a) = b$——由满射性至少有一个，由单射性至多有一个——我们定义$g(b)$为这个$a$。则$g\colon B\to A$是一个函数，并且由构造，对每个$b \in B$都有$f(g(b)) = b$。对$a\in A$，元素$g(f(a))$是$A$中被$f$映为$f(a)$的唯一元素；由于$a$本身就是这样的元素，所以$g(f(a)) = a$。因此$g$是$f$的逆。

*唯一性*。若$g$和$h$都是$f$的逆，则由结合律（[[#prop-associative]]），

$$
g = g\circ\id_B = g\circ(f\circ h) = (g\circ f)\circ h = \id_A\circ h = h.
$$

最后，等式$f^{-1}\circ f = \id_A$和$f\circ f^{-1} = \id_B$恰好是说$f$是$f^{-1}$的逆。所以$f^{-1}$可逆，从而由第一部分知它是双射，并且由唯一性，$(f^{-1})^{-1} = f$。
:::

在实际中，要求双射$f$的逆，就从方程$y = f(x)$中解出$x$；作为$y$的函数，这个解就是$f^{-1}(y)$。

::: example 求分式线性函数的逆 {#ex-mobius}
证明$f\colon\R\setminus\set3\to\R\setminus\set2$，$f(x) = \dfrac{2x+1}{x-3}$是良定义的双射，并求$f^{-1}$。
::: solution
*良定义*。当$x \ne 3$时分母不为零。我们还必须验证每个值都属于陪域，即$f(x)\neq 2$：若$\frac{2x+1}{x-3} = 2$，则$2x+1 = 2x-6$，这是不可能的。

*求逆*。对$y\neq 2$，解方程$y = \frac{2x+1}{x-3}$：

$$
y(x-3) = 2x+1 \iff yx - 2x = 3y+1 \iff x(y-2) = 3y+1 \iff x = \frac{3y+1}{y-2}.
$$

于是定义$g\colon\R\setminus\set2\to\R\setminus\set3$为$g(y) = \frac{3y+1}{y-2}$。它是良定义的：分母不为零，而$g(y) = 3$将意味着$3y+1 = 3y-6$，这是不可能的。

*验证*。我们不依赖于那一串等价关系，而是直接验证两个复合。对$x\neq 3$，把分子和分母同乘以$x - 3$，得

$$
g(f(x)) = \frac{3\cdot\frac{2x+1}{x-3} + 1}{\frac{2x+1}{x-3} - 2} = \frac{3(2x+1) + (x-3)}{(2x+1) - 2(x-3)} = \frac{7x}{7} = x,
$$

对$y\neq 2$，同乘以$y - 2$，得

$$
f(g(y)) = \frac{2\cdot\frac{3y+1}{y-2}+1}{\frac{3y+1}{y-2} - 3} = \frac{2(3y+1) + (y-2)}{(3y+1) - 3(y-2)} = \frac{7y}{7} = y.
$$

所以$g$是$f$的逆；由[[#thm-inverse]]，$f$是双射且$f^{-1} = g$。注意被除去的点是如何对应的：$f$的定义域除去了$3$，$f$在那里趋于无穷；陪域除去了$2$，即水平渐近线对应的值，$f$永远取不到它。
:::
:::

::: warning f⁻¹ 的两种含义
只有当$f$是双射时，符号$f^{-1}$才表示反**函数**，而且它从不表示倒数$1/f$：$\sin^{-1}$是$\sin$在$[-\frac\pi2,\frac\pi2]$上的限制的反函数，而不是$1/\sin$。更麻烦的是，同一个符号还用于原像：对**集合**$T$，$f^{-1}(T)$对每个函数都有意义，无论它是否为双射（见下文）。只有在验证了$f$是双射之后，才能用$f^{-1}$表示反函数。
:::

### 单侧逆

那么只是单射或只是满射的函数又如何呢？

::: theorem 单侧逆 {#thm-one-sided}
设$f\colon A\to B$，且$A\neq\varnothing$。

1. $f$有左逆当且仅当$f$是单射。
2. $f$有右逆当且仅当$f$是满射。
:::

::: proof
1. 若$g\circ f = \id_A$，则由[[#thm-composition]]的第4条，$f$是单射。反过来，设$f$是单射。取定某个$a_0\in A$（由于$A\neq\varnothing$，这是可以做到的），并定义$g\colon B\to A$为

$$
g(b) = \begin{cases} \text{唯一的 } a\in A \text{ 使 } f(a) = b, & \text{若 } b\in f(A),\\ a_0, & \text{若 } b\notin f(A).\end{cases}
$$

由于$f$是单射，第一种情形是明确无歧义的。对每个$a\in A$，有$f(a)\in f(A)$且$g(f(a)) = a$，所以$g\circ f = \id_A$。

2. 若$f\circ g = \id_B$，则由[[#thm-composition]]的第5条，$f$是满射。反过来，设$f$是满射。对每个$b\in B$，集合$\set{a\in A : f(a) = b}$非空；从中选取一个元素，记为$g(b)$。则对每个$b$都有$f(g(b)) = b$，所以$f\circ g = \id_B$。
:::

第2部分的证明同时为每个$b\in B$做了一次选择。当$B$是无限集，并且没有规则告诉我们该选哪个元素时，作无穷多次任意选择的权利正是**选择公理**，它是[[proofs/sets]]一章中提到的 ZFC 公理之一；事实上，命题“每个满射都有右逆”与选择公理等价。第1部分中的假设$A\ne\varnothing$排除了一种退化情形：空函数$\varnothing\to B$是单射，但若$B\neq\varnothing$，则根本不存在从$B$到$\varnothing$的函数。

::: example 移位映射的单侧逆 {#ex-shift}
设$s\colon\N\to\N$，$s(n) = n+1$。证明$s$有无穷多个左逆，但没有右逆。
::: solution
$s$是单射，因为$n_1+1 = n_2+1$蕴涵$n_1 = n_2$；但它不是满射，因为$1$不是它的值。由[[#thm-one-sided]]，它有左逆而没有右逆。左逆可以明确地写出来：对每个$k\in\N$，定义

$$
g_k(n) = \begin{cases} n-1, & n\ge 2,\\ k, & n = 1.\end{cases}
$$

则对每个$n\in\N$都有$g_k(s(n)) = g_k(n+1) = n$，所以每个$g_k$都是左逆，并且不同的$k$值给出不同的函数。在$1$处的值是任意的，因为$1$不在$s$的值域中，所以方程$g\circ s = \id_\N$对它没有任何限制。没有一个$g_k$是右逆：$s(g_k(1)) = k+1\neq 1$。
:::
:::

::: quiz
设$f\colon A\to B$和$g\colon B\to A$满足$g\circ f = \id_A$。下列哪个结论是有根据的？
- [x] $f$是单射，$g$是满射。
- [ ] $f$是满射，$g$是单射。
- [ ] $f$和$g$都是双射。
- [ ] $f\circ g = \id_B$。
::: solution
由于$g\circ f$是单射，由[[#thm-composition]]的第4条，$f$是单射；由于$g\circ f$是满射，由第5条，$g$是满射。除此之外推不出更多：[[#ex-shift]]中的移位映射$s$及其左逆$g_1$满足$g_1\circ s = \id_\N$，但$s$不是满射，$g_1$不是单射（$g_1(1) = g_1(2) = 1$），并且$s\circ g_1\neq\id_\N$。
:::
:::

## 像与原像

函数不仅作用于元素，也作用于整个子集。

::: definition 像与原像 {#def-image-preimage}
设$f\colon A\to B$。对$S\subseteq A$，$S$的**像**是

$$
f(S) = \set{f(a) : a\in S}\subseteq B,
$$

对$T\subseteq B$，$T$的**原像**（或**逆像**）是

$$
f^{-1}(T) = \set{a\in A : f(a)\in T}\subseteq A.
$$
:::

原像对每个函数都有定义；$f^{-1}(T)$是一个集合的记号，并不预设反函数的存在。当$f$是双射时，$T$在$f$下的原像与$T$在反函数$f^{-1}$下的像一致，所以这个记号不会引起冲突。

::: example 平方映射的像与原像 {#ex-images}
设$f\colon\R\to\R$，$f(x) = x^2$。求$f([-1,2])$、$f^{-1}([1,4])$、$f^{-1}(\set{-1})$和$f^{-1}\bigl(f([0,1])\bigr)$。
::: solution
- 当$x$取遍$[-1,1]$时，$x^2$取遍$[0,1]$；当$x$取遍$[1,2]$时，$x^2$取遍$[1,4]$。所以$f([-1,2]) = [0,4]$。
- $x\in f^{-1}([1,4])$意味着$1\le x^2\le 4$，即$1\le\abs x\le2$。所以$f^{-1}([1,4]) = [-2,-1]\cup[1,2]$。
- 没有实数的平方等于$-1$，所以$f^{-1}(\set{-1}) = \varnothing$。
- $f([0,1]) = [0,1]$，而$f^{-1}([0,1]) = \set{x : 0 \le x^2\le 1} = [-1,1]$。所以$f^{-1}(f([0,1])) = [-1,1]$，它严格大于$[0,1]$。先取像再取原像未必回到原来的集合，因为$f$不是单射。
:::
:::

像和原像与集合运算之间有什么关系？原像表现得完美无缺；像则只是部分如此。

::: theorem 并与交的像和原像 {#thm-image-preimage}
设$f\colon A\to B$，$S_1,S_2\subseteq A$，$T, T_1,T_2\subseteq B$。则

1. $f(S_1\cup S_2) = f(S_1)\cup f(S_2)$；
2. $f(S_1\cap S_2)\subseteq f(S_1)\cap f(S_2)$，当$f$是单射时等号成立；
3. $f^{-1}(T_1\cup T_2) = f^{-1}(T_1)\cup f^{-1}(T_2)$；
4. $f^{-1}(T_1\cap T_2) = f^{-1}(T_1)\cap f^{-1}(T_2)$；
5. $f^{-1}(B\setminus T) = A\setminus f^{-1}(T)$。
:::

::: proof
1. $b\in f(S_1\cup S_2)$是说$b = f(a)$，其中$a$是属于$S_1$或属于$S_2$的某个元素，这恰好是说$b\in f(S_1)$或$b\in f(S_2)$。
2. 若$b\in f(S_1\cap S_2)$，则$b = f(a)$，其中$a\in S_1$且$a \in S_2$，所以$b\in f(S_1)$且$b\in f(S_2)$。现在设$f$是单射且$b\in f(S_1)\cap f(S_2)$，不妨设$b = f(a_1) = f(a_2)$，其中$a_1\in S_1$，$a_2\in S_2$。由单射性得$a_1 = a_2$，因此它属于$S_1\cap S_2$，所以$b\in f(S_1\cap S_2)$。
3. 对$a\in A$：$a\in f^{-1}(T_1\cup T_2) \iff f(a)\in T_1\cup T_2 \iff \bigl(f(a)\in T_1 \text{ 或 } f(a)\in T_2\bigr) \iff a\in f^{-1}(T_1)\cup f^{-1}(T_2)$。
4. 把“或”换成“且”，用同样的等价链即可。
5. 对$a\in A$：$a\in f^{-1}(B\setminus T)\iff f(a)\notin T\iff a\notin f^{-1}(T) \iff a\in A\setminus f^{-1}(T)$。
:::

第2条中的包含关系可以是严格的。对$\R$上的$f(x) = x^2$，取$S_1 = \set{-1}$，$S_2 = \set{1}$：则$f(S_1\cap S_2) = f(\varnothing) = \varnothing$，但$f(S_1)\cap f(S_2) = \set1$。具有相同像的两个不同点，恰恰是单射性所禁止的。像也不保持补集：$f\bigl((-\infty,0)\bigr) = (0,\infty)$，它不是$f\bigl([0,\infty)\bigr) = [0,\infty)$的补集。

::: remark 原像为何重要
原像与**所有**集合运算都可交换——包括任意集族的并与交，证明同样只需一行。这就是为什么后续课程中许多核心定义都用原像来表述：拓扑空间之间的函数称为连续的，是指每个开集的原像都是开集（[[topology/continuous-maps]]）；函数称为可测的，是指可测集的原像都可测（[[measure-theory/measurable-functions]]）；而随机变量$X$在$T$中取值的概率，就是事件$X^{-1}(T)$的概率（[[probability/discrete-random-variables]]）。
:::

caption: 从五元集到三元集的一个满射。$\set{b}$的原像是$\set{2,3}$，而$\set a$、$\set b$和$\set c$的原像把定义域分成三个不相交的部分。试着通过修改箭头使这个函数成为单射：这是做不到的，因为五个箭头必须落在三个点上（鸽巢原理）。

::: history
从17世纪70年代起，戈特弗里德·威廉·莱布尼茨（Gottfried Wilhelm Leibniz）就用“函数”（*function*）一词来称呼与曲线相关联的量，例如斜率和切线长；莱昂哈德·欧拉（Leonhard Euler）于1734年引入了记号$f(x)$。欧拉在《无穷分析引论》（*Introductio*，1748）中把函数定义为解析表达式——即一个公式——这在当时是通行的观点，尽管到1755年他已允许任何依赖于另一个量的量。对傅里叶（Fourier）级数的研究迫使人们采取更宽泛的观点：1837年，彼得·古斯塔夫·勒热纳·狄利克雷（Peter Gustav Lejeune Dirichlet）强调，只要对区间中的每个$x$都按某种规则指定了一个$y$值，$y$就是$x$的函数，无论这是什么规则，也不一定是单个公式。里夏德·戴德金（Richard Dedekind）的《数是什么，数应当是什么？》（*Was sind und was sollen die Zahlen?*，1888）把任意集合之间的映射当作基本对象，而把函数定义为有序对集合的做法在20世纪初成为标准。单射、满射和双射这几个词是由法国数学家团体布尔巴基（Bourbaki）在20世纪中叶引入的。
:::

## 后续内容

对于无限集，双射是“大小相同”的恰当概念，[[proofs/cardinality]]一章以本章的全部内容为基础；例如，康托尔（Cantor）定理说的是：任何函数$A\to\mathcal{P}(A)$都不是满射。去掉“恰有一个输出”这一条件，函数就变成了关系（[[proofs/relations]]）。一个集合到自身的双射在复合运算下构成一个群（[[abstract-algebra/groups]]），对有限集而言，它们就是[[abstract-algebra/permutation-groups]]一章中的置换。在线性代数中，线性映射是单射当且仅当它的核为零，方阵可逆当且仅当它的行列式不为零（[[linear-algebra/linear-maps]]，[[linear-algebra/determinants]]）。对各类函数进行计数是[[discrete/counting]]的一项基本任务。

::: summary
- 函数$f\colon A\to B$给定义域$A$的每个元素指定陪域$B$中恰好一个值；形式上，它是$A\times B$的一个子集，即它的图像。定义域和陪域都是函数的组成部分；对所提出的规则，必须验证它是良定义的。
- 若$f(a_1) = f(a_2)$蕴涵$a_1 = a_2$，则$f$是单射；若每个$b\in B$都是$f$的值，则$f$是满射；两者兼备则是双射。对实函数而言，这就是水平线检验。
- 证明单射性时，假设$f(a_1) = f(a_2)$；证明满射性时，对任意$b$解方程$f(a) = b$；否定其中任何一个，只需一个明确的反例。
- 对于大小相同的有限集，单射$\iff$满射（[[#thm-finite]]）；对于无限集，这两个性质相互独立。
- 复合满足结合律，但不满足交换律。复合保持单射性、满射性和双射性；若$g\circ f$是单射，则$f$是单射；若$g\circ f$是满射，则$g$是满射。
- 函数有双边逆当且仅当它是双射，并且逆是唯一的（[[#thm-inverse]]）；左逆对应于单射性，右逆对应于满射性。
- 原像保持并、交和补；像保持并，但一般只有$f(S_1\cap S_2)\subseteq f(S_1)\cap f(S_2)$。
:::

## 习题

::: exercise 哪些规则是函数？ {level=1}
判断下列哪些规则定义了函数，并说明理由。
(a) $f\colon\R\to\R$，$f(x) = \dfrac{1}{x^2+1}$。
(b) $g\colon\R\to\R$，$g(x) = \sqrt{x}$。
(c) $h\colon\Q\to\Q$，$h\bigl(\frac pq\bigr) = \dfrac{p+1}{q}$，其中$p$、$q$为整数且$q\ne 0$。
(d) $k\colon\Z\to\N$，$k(n) = n^2+1$。
::: solution
(a) 是：$x^2+1\ge1 > 0$，所以对每个实数$x$，该公式给出恰好一个实数。

(b) 不是：$g(-1)$不是实数。（在定义域$[0,\infty)$上它是函数。）

(c) 不是，它不是良定义的：$\frac12 = \frac24$，但按这个规则，第一种表示给出$\frac{2}{2} = 1$，第二种表示给出$\frac34$。

(d) 是：对每个整数$n$，$n^2 + 1$都是正整数，所以它属于$\N$。
:::
:::

::: exercise 单射还是满射？ {level=1}
对下列每个函数，判断它是否为单射，是否为满射。
(a) $f\colon\Z\to\Z$，$f(n) = n+3$。
(b) $g\colon\Z\to\Z$，$g(n) = 3n$。
(c) $h\colon\R\to\R$，$h(x) = x^3$。
(d) $k\colon\R\to[-1,1]$，$k(x) = \sin x$。
::: solution
(a) 双射：由$n_1+3 = n_2+3$得$n_1 = n_2$，并且每个$m\in\Z$都等于$f(m-3)$。

(b) 是单射，因为$3n_1 = 3n_2$蕴涵$n_1 = n_2$；但不是满射：$1$不是$3$的倍数。

(c) 双射。若$x_1^3 = x_2^3$，则$0 = x_1^3 - x_2^3 = (x_1 - x_2)(x_1^2 + x_1x_2 + x_2^2)$。第二个因子等于$\bigl(x_1 + \frac{x_2}{2}\bigr)^2 + \frac34x_2^2$，它仅当$x_1 = x_2 = 0$时为零；所以无论哪种情形都有$x_1 = x_2$。每个$y\in\R$都等于$h\bigl(\sqrt[3]{y}\bigr)$。

(d) 是满射，因为$\sin$取遍$[-1,1]$中的每个值（在$[-\frac\pi2,\frac\pi2]$上就已经如此）；但不是单射：$\sin 0 = \sin\pi = 0$。
:::
:::

::: exercise 单射的计数 {level=1 check="60"}
从$[3]$到$[5]$的单射有多少个？
::: solution
$f(1)$有$5$种选法，然后满足$f(2)\neq f(1)$的$f(2)$有$4$种选法，再然后与两者都不同的$f(3)$有$3$种选法：共有$5\cdot4\cdot3 = 60$个单射。
:::

::: exercise 像与原像 {level=2}
设$f\colon\R\to\R$，$f(x) = x^2 - 2x$。求$f([0,3])$、$f^{-1}([-1,3])$和$f^{-1}(\set{-2})$。
::: hint
配方。
:::
::: solution
写成$f(x) = (x-1)^2 - 1$。

- 在$[0,3]$上，$x-1$取遍$[-1,2]$，所以$(x-1)^2$取遍$[0,4]$，$f(x)$取遍$[-1,3]$。因此$f([0,3]) = [-1,3]$。
- 不等式$f(x)\ge -1$对每个$x$都成立，而$f(x)\le 3 \iff (x-1)^2\le 4\iff -2\le x-1\le 2\iff -1\le x\le 3$。所以$f^{-1}([-1,3]) = [-1,3]$。
- $f(x) = -2$要求$(x-1)^2 = -1$，这是不可能的，所以$f^{-1}(\set{-2}) = \varnothing$。
:::

::: exercise 两个复合 {level=2}
设$f,g\colon\R\to\R$为$f(x) = 2x+1$和$g(x) = x^2-3$。求$g\circ f$和$f\circ g$的表达式，并证明对每个实数$x$都有$(g\circ f)(x)\neq(f\circ g)(x)$。
::: solution
$(g\circ f)(x) = (2x+1)^2 - 3 = 4x^2+4x-2$，$(f\circ g)(x) = 2(x^2-3)+1 = 2x^2-5$。两者相等当且仅当$4x^2+4x-2 = 2x^2-5$，即$2x^2+4x+3 = 0$。但对每个实数$x$，$2x^2+4x+3 = 2(x+1)^2+1 \ge 1$（等价地说，判别式$16 - 24 = -8$为负），所以这两个复合在每一点处都不相等。
:::
:::

::: exercise 从四元集到三元集的满射 {level=2 check="36"}
从$[4]$到$[3]$的满射有多少个？
::: hint
在满射$[4]\to[3]$中，恰有一个值被取到两次。
:::
::: solution
四个元素被映到三个值上，每个值至少被取到一次，所以恰有一个值被取到两次，另外两个值各被取到一次。选出被取到两次的值（$3$种方法），选出$[4]$中映到它的两个元素（$\binom42 = 6$种方法），再把剩下的两个元素双射地映到剩下的两个值上（$2$种方法）。总数为$3\cdot6\cdot2 = 36$。
:::

::: exercise 一个部分逆命题 {level=2}
设$f\colon A\to B$，$g\colon B\to C$。证明：若$g\circ f$是满射且$g$是单射，则$f$是满射。
::: solution
设$b\in B$。由于$g\circ f$是满射，存在$a\in A$使$g(f(a)) = g(b)$。由于$g$是单射，$f(a) = b$。所以每个$b \in B$都是$f$的值。
:::

::: exercise 一个整数线性映射 {level=3}
证明$f\colon\Z\times\Z\to\Z\times\Z$，$f(m,n) = (2m+n,\ m+n)$是双射，并求它的逆。$g\colon\Z\times\Z\to\Z\times\Z$，$g(m,n) = (2m+n,\ n)$是双射吗？
::: hint
从$u = 2m+n$，$v = m+n$中解出$m$和$n$，并验证解是整数。
:::
::: solution
解$u = 2m+n$和$v = m+n$：两式相减得$m = u-v$，进而$n = v - m = 2v - u$。定义$h\colon\Z\times\Z\to\Z\times\Z$为$h(u,v) = (u-v,\ 2v-u)$。则

$$
f(h(u,v)) = \bigl(2(u-v)+(2v-u),\ (u-v)+(2v-u)\bigr) = (u, v),
$$

$$
h(f(m,n)) = \bigl((2m+n)-(m+n),\ 2(m+n)-(2m+n)\bigr) = (m,n).
$$

所以$h$是$f$的逆，由[[#thm-inverse]]，$f$是双射，且$f^{-1}(u,v) = (u-v,\ 2v-u)$。

映射$g$是单射——若$(2m+n,\ n) = (2m'+n',\ n')$，则$n = n'$，进而$m = m'$——但不是满射：在$g(m,n)$中，第一个坐标$2m+n$与第二个坐标$n$的奇偶性相同，所以例如$(1, 0)$就不是它的值。与在$\R$上不同，在$\Z$上行列式非零的线性映射未必是满射；可以证明，它是$\Z^2$上的双射当且仅当其行列式为$\pm1$，$f$正是如此。
:::
:::

::: exercise 原像的像 {level=3}
设$f\colon A\to B$。证明对每个$T\subseteq B$都有$f(f^{-1}(T))\subseteq T$，并且等号对每个$T$都成立当且仅当$f$是满射。再证明对每个$S\subseteq A$都有$S\subseteq f^{-1}(f(S))$，并且等号对每个$S$都成立当且仅当$f$是单射。
::: solution
*原像的像*。若$b\in f(f^{-1}(T))$，则对某个$a\in f^{-1}(T)$，即某个满足$f(a)\in T$的$a$，有$b = f(a)$；所以$b\in T$。若$f$是满射且$b\in T$，取$a$使$f(a) = b$；则$a\in f^{-1}(T)$，所以$b = f(a)\in f(f^{-1}(T))$，等号成立。反过来，若等号对每个$T$都成立，取$T = B$：则$f(A) = f(f^{-1}(B)) = B$，所以$f$是满射。

*像的原像*。若$a\in S$，则$f(a)\in f(S)$，所以$a\in f^{-1}(f(S))$。设$f$是单射且$a\in f^{-1}(f(S))$；则对某个$s\in S$有$f(a) = f(s)$，所以$a = s\in S$，等号成立。反过来，设等号对每个$S$都成立，并设$f(a_2) = f(a_1)$。取$S = \set{a_1}$，得$a_2\in f^{-1}(f(\set{a_1})) = \set{a_1}$，所以$a_2 = a_1$，$f$是单射。
:::

::: exercise 有限集上双射的迭代 {level=3}
设$A$是有限集，$f\colon A\to A$是单射，记$f^k = f\circ\cdots\circ f$（$k$个因子）。证明存在某个$k\ge1$使$f^k = \id_A$。说明对单射$s\colon\N\to\N$，$s(n) = n+1$，这一结论不成立。
::: hint
函数$A\to A$只有有限多个，所以迭代$f, f^2, f^3,\dots$不可能全都不同。
:::
::: solution
由[[#thm-finite]]，$f$是双射，所以它有逆$f^{-1}$（[[#thm-inverse]]）。从$A$到$A$的函数只有$N = \abs A^{\abs A}$个，所以在$N+1$个函数$f^1, f^2, \dots, f^{N+1}$中必有两个相同：对某个$1\le i<j$有$f^i = f^j$。在两边的左侧复合$f^{-1}$，共$i$次。利用结合律和$f^{-1}\circ f = \id_A$，左边变为$\id_A$，右边变为$f^{j-i}$。所以$f^k = \id_A$，其中$k = j-i\ge1$。

对于移位映射，$s^k(n) = n+k$，所以对每个$k\ge1$都有$s^k(1) = k+1\neq1$，没有一个迭代是恒等函数。这并不矛盾：$s$是单射但不是满射，这只有在$\N$为无限集时才可能。
:::
