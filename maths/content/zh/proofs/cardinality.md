自然数比偶数多吗？偶数只是自然数的一个真部分，所以偶数比自然数少，这似乎是显然的。然而规则$n\mapsto 2n$把每个自然数恰与一个偶数配对，两边都没有剩余：

$$
\begin{array}{cccccc}
1 & 2 & 3 & 4 & 5 & \cdots\\
\updownarrow & \updownarrow & \updownarrow & \updownarrow & \updownarrow & \\
2 & 4 & 6 & 8 & 10 & \cdots
\end{array}
$$

伽利略（Galileo）在1638年就针对完全平方数注意到了同样的现象，并得出结论：“相等”“大于”和“小于”根本不适用于无穷的总体。两个半世纪之后，格奥尔格·康托尔（Georg Cantor）采取了相反的观点：当两个集合的元素能够恰好一一配对时，就**定义**它们大小相同，然后看看会得出什么。答案令人震惊。自然数、整数和有理数的大小都相同；实数构成一个严格更大的无穷；而且根本不存在最大的无穷。本章将证明所有这些结论，所用的只是[[proofs/functions]]一章中的函数。

## 比较大小

::: definition 等势的集合 {#def-equinumerous}
如果存在双射$A\to B$，就称集合$A$与$B$**等势**，或者说它们具有**相同的基数**，记作$\abs A = \abs B$。如果存在单射$A\to B$，就写$\abs A\le\abs B$；如果$\abs A\le\abs B$但$\abs A\neq\abs B$，就写$\abs A<\abs B$。
:::

对有限集而言，这与计数是一致的：两个有限集的元素个数相同，当且仅当它们的元素能够一一配对。注意，“$\abs A = \abs B$”和“$\abs A\le\abs B$”是作为关于函数存在性的命题来**定义**的；我们无需知道$\abs A$本身是什么意思。这个定义具有我们对“大小相同”所期望的那些性质。

::: proposition 基本性质 {#prop-equinumerous}
对任意集合$A$、$B$和$C$：

1. $\abs A = \abs A$；
2. 若$\abs A = \abs B$，则$\abs B = \abs A$；
3. 若$\abs A = \abs B$且$\abs B = \abs C$，则$\abs A = \abs C$；
4. $\abs A\le\abs A$，并且若$\abs A\le\abs B$且$\abs B\le\abs C$，则$\abs A\le\abs C$；
5. 若$A\subseteq B$，则$\abs A\le\abs B$。
:::

::: proof
- 对于1：恒等函数$\id_A$是双射。
- 对于2：双射的逆是双射（[[proofs/functions#thm-inverse]]）。
- 对于3和4：双射的复合是双射，单射的复合是单射（[[proofs/functions#thm-composition]]），而$\id_A$是单射。
- 对于5：包含映射$A\to B$，$a\mapsto a$是单射。
:::

所以等势的表现就像一个等价关系。但在[[proofs/relations]]一章的意义下，它严格说来并不是等价关系，因为它必须是全体集合组成的集合上的关系，而这样的集合并不存在（[[proofs/sets#thm-russell]]）。

::: example 大小相同的无限集 {#ex-same-size}
证明下列各对集合等势：(a) $\N$与偶自然数集$E$；(b) 区间$(0,1)$与$(a,b)$，其中$a<b$是任意实数；(c) 区间$(0,1)$与$(1,\infty)$。
::: solution
(a) 设$f\colon\N\to E$，$f(n) = 2n$。它是单射，因为$2n = 2n'$蕴涵$n = n'$；它是满射，因为每个偶自然数都形如$2k$，其中$k\in\N$，而$2k = f(k)$。

(b) 设$g(x) = a + (b-a)x$。若$0<x<1$，则$a < g(x) < b$，所以$g$把$(0,1)$映入$(a,b)$；而$y\mapsto (y-a)/(b-a)$把$(a,b)$映入$(0,1)$，并且从两侧抵消$g$的作用。具有双边逆的函数是双射。

(c) 设$h(x) = 1/x$。若$0<x<1$，则$1/x>1$；若$y>1$，则$0<1/y<1$；并且$h(h(x)) = x$。所以$h$是从$(0,1)$到$(1,\infty)$的双射，其逆为$y\mapsto 1/y$。

在(a)中，一个集合与它自身的一个真子集等势；在(b)中，每个开区间，无论多短，都与其他任何开区间有同样多的点；在(c)中，一个有界区间与一个无界区间一一对应。
:::
:::

::: warning 来自有限集的直觉不再适用
对有限集而言，真子集总是严格更小。对无限集来说这是错的——见[[#ex-same-size]](a)——诸如“$E$只是$\N$的一半，所以它更小”的论证根本站不住脚。同样，找到一个不是双射的函数$A\to B$并不能证明什么：从$\N$到$E$的$n\mapsto 4n$不是满射，但$n\mapsto 2n$是双射。要证明$\abs A\neq\abs B$，必须排除**每一个**可能的双射，这正是下面那些不可数性证明的趣味所在。
:::

::: quiz
下列哪一项能证明$\abs\N\neq\abs\R$？
- [ ] 证明包含映射$\N\to\R$，$n\mapsto n$不是满射。
- [ ] 证明$\N$是$\R$的真子集。
- [x] 证明没有一个函数$\N\to\R$是满射。
- [ ] 举出一个不是自然数的实数。
::: solution
$\abs\N = \abs\R$是说**存在某个**双射$\N\to\R$，所以要驳倒它，必须排除每一个双射。证明根本没有函数是满射，恰好做到了这一点——这也正是下面的对角线论证所完成的。其他选项涉及的只是某个特定的函数或子集关系，用同样的推理还能“证明”偶数集$E$满足$\abs E\neq\abs\N$，而这是错误的。
:::
:::

::: intuition 希尔伯特旅馆
设想一家旅馆，房间编号为$1, 2, 3, \dots$，每间都已住满。来了一位新客人。经理请每位客人从$n$号房间搬到$n+1$号房间；每个人仍然有房间住，而$1$号房间空了出来。当一辆载有无穷多位新客人的大巴到达时，经理让每位客人从$n$号房间搬到$2n$号房间，于是所有奇数号房间都空了出来。移位映射$n\mapsto n+1$是从$\N$到$\N\setminus\set1$的双射，而$n\mapsto 2n$是到偶数集的双射。这个故事源于大卫·希尔伯特（David Hilbert）在20世纪20年代所做的讲座。
:::

### 有限集

一个集合是有限的，这是什么意思？对$n\in\N_0$，记$[n] = \set{1,\dots,n}$，其中$[0] = \varnothing$。若一个集合与$[n]$等势，就称它是**含$n$个元素的有限集**；若一个集合不是有限集，就称它是**无限集**。为了使每个有限集都有唯一确定的元素个数，我们需要鸽巢原理的严格形式（[[discrete/advanced-counting#thm-pigeonhole]]）。

::: lemma 鸽巢原理 {#lem-pigeonhole}
设$m, n\in\N_0$。若存在单射$[m]\to[n]$，则$m\le n$。
:::

::: proof
对$n$用归纳法。若$n = 0$，则$[n] = \varnothing$，而函数$[m]\to\varnothing$仅当$[m] = \varnothing$，即$m = 0$时才存在。

假设结论对某个$n\ge0$成立，并设$f\colon[m]\to[n+1]$是单射。若$m = 0$，则无需证明，所以设$m\ge1$。设$\tau\colon[n+1]\to[n+1]$是交换$f(m)$与$n+1$、并保持其他每个元素不动的双射（若$f(m) = n+1$，则$\tau = \id$）。则$g = \tau\circ f$是单射，并且$g(m) = n+1$。对$i\in[m-1]$，有$g(i)\neq g(m) = n+1$，所以$g$限制为一个单射$[m-1]\to[n]$。由归纳假设，$m-1\le n$，即$m\le n+1$。
:::

::: corollary 有限集与无限集 {#cor-finite}
1. 若$[m]$与$[n]$等势，则$m = n$。所以有限集的元素个数是良定义的。
2. 有限集不与它自身的任何真子集等势。
3. $\N$是无限集。
:::

::: proof
1. 双射$[m]\to[n]$及其逆都是单射，所以$m\le n$且$n\le m$。

2. 设$h\colon A\to[n]$是双射，$S\subsetneq A$，取$a\in A\setminus S$。假设$\psi\colon A\to S$是双射；那么它是从$A$到$A\setminus\set a$的单射。把$h$与交换$h(a)$和$n$的映射复合，可以假定$h(a) = n$，从而$h$把$A\setminus\set a$映入$[n-1]$。于是$h\circ\psi\circ h^{-1}$是单射$[n]\to[n-1]$，与[[#lem-pigeonhole]]矛盾。

3. 移位映射$n\mapsto n+1$是从$\N$到它的真子集$\N\setminus\set1$的双射，所以由第2条，$\N$不是有限集。
:::

## 可数集

::: definition 可数与不可数 {#def-countable}
若$\abs A = \abs\N$，则称集合$A$是**可数无穷的**；若$A$是有限的或可数无穷的，则称它是**可数的**；若$A$不是可数的，则称它是**不可数的**。$\N$的基数记作$\aleph_0$（读作“阿列夫零”）。
:::

双射$f\colon\N\to A$把$A$的元素排成一个列表$f(1), f(2), f(3),\dots$，其中每个元素恰好出现一次。所以一个集合是可数无穷的，当且仅当它的元素可以排成一个序列——即可以“数”：一、二、三……尽管永远数不完。

::: example 整数集是可数的 {#ex-integers}
把$\Z$排成$0, 1, -1, 2, -2, 3, -3,\dots$；也就是说，定义$f\colon\N\to\Z$：对偶数$n$，$f(n) = n/2$；对奇数$n$，$f(n) = -(n-1)/2$。证明$f$是双射。
::: solution
对偶数$n = 2k$（$k\ge1$），得$f(n) = k\ge1$；对奇数$n = 2k-1$（$k \geq 1$），得$f(n) = -(k-1)\le0$。所以$f$把偶数映为正整数，把奇数映为非正整数。

*单射*。设$f(n) = f(n')$。由于函数值为正当且仅当自变量为偶数，$n$与$n'$的奇偶性相同。若两者都是偶数，由$n/2 = n'/2$得$n = n'$；若两者都是奇数，由$-(n-1)/2 = -(n'-1)/2$得$n = n'$。

*满射*。对$k\ge1$，$f(2k) = k$。对$k\le0$，数$1-2k$是奇数且至少为$1$，并且$f(1-2k) = -\frac{(1-2k)-1}{2} = k$。

所以$\abs\Z = \abs\N$，尽管$\Z$“看起来有两倍大”。
:::
:::

用明确的双射来证明可数性往往很麻烦。下面两个结果使我们只需证明少得多的东西就够了。

::: theorem 可数集的子集 {#thm-subset-countable}
可数集的每个子集都是可数的。
:::

::: proof
设$A$是可数集，$S\subseteq A$。存在单射$\varphi\colon A\to\N$：若$A$是可数无穷的，取一个双射；若$A$是有限的，取一个到某个$[n]\subseteq\N$上的双射。于是$S$与$T = \varphi(S)\subseteq\N$等势，所以只需证明$\N$的每个子集$T$都是可数的。

若$T$是有限的，则无需证明，所以设$T$是无限的。定义$t_1 = \min T$，并递归地定义$t_{k+1} = \min\set{t\in T : t>t_k}$。由良序原理（[[proofs/induction#thm-well-ordering]]），这些最小值都存在，因为相应的集合非空：如果$T$中没有元素大于$t_k$，那么$T\subseteq[t_k]$就是有限的。映射$k\mapsto t_k$是严格递增的，因而是单射，并且用简单的归纳法可得$t_k\ge k$。它也是满射。给定$t\in T$，满足$t_k\le t$的下标$k$构成一个非空集合（它包含$1$），其中的数都不超过$t$；设$k$是其中最大的一个。则$t_k\le t<t_{k+1}$，并且$t = t_k$，因为若$t>t_k$，则由$t_{k+1}$的定义将有$t\ge t_{k+1}$。所以$k\mapsto t_k$是双射$\N\to T$。
:::

::: lemma 可数性的判别准则 {#lem-countable-criteria}
对非空集合$A$，下列命题等价：

1. $A$是可数的；
2. 存在单射$A\to\N$；
3. 存在满射$\N\to A$。
:::

::: proof
*1 ⇒ 2与1 ⇒ 3*。若$A$是可数无穷的，则双射$\N\to A$是满射，它的逆是单射$A\to\N$。若$A$是非空有限集，则双射$h\colon A\to[n]$（$n\ge1$）是到$\N$中的单射，而$k\mapsto h^{-1}(\min(k,n))$是满射$\N\to A$。

*2 ⇒ 1*。若$f\colon A\to\N$是单射，则$A$与$f(A)\subseteq\N$等势，而由[[#thm-subset-countable]]，$f(A)$是可数的；因此$A$也是可数的。

*3 ⇒ 2*。设$g\colon\N\to A$是满射。对每个$a\in A$，集合$\set{n\in\N : g(n) = a}$非空，所以由良序原理，它有最小元，记为$f(a)$。则对每个$a$都有$g(f(a)) = a$，所以$g\circ f = \id_A$，由[[proofs/functions#thm-composition]]，$f$是单射。
:::

自然数对构成一个无穷的网格，看起来比$\N$大得多。其实不然。

::: theorem 数对网格是可数的 {#thm-nxn}
映射$\N\times\N\to\N$，$(m,n)\mapsto 2^{m-1}(2n-1)$是双射。特别地，$\N\times\N$是可数无穷的。
:::

::: proof
*满射*。设$k\in\N$，并设$2^a$是整除$k$的$2$的最高次幂（它存在，因为$2^0 = 1$整除$k$，而整除$k$的每个幂都不超过$k$）。则$k = 2^a u$，其中$u$是奇数，因为若$u$是偶数，$2^{a+1}$就会整除$k$。写$u = 2n-1$（$n\in\N$），并令$m = a+1$，就得到$k = 2^{m-1}(2n-1)$。

*单射*。设$2^a u = 2^b v$，其中$a, b\ge0$，$u,v$是奇数。若$a<b$，则$u = 2^{b-a}v$将是偶数，这不可能；同理$b<a$也不可能。所以$a = b$，消去$2^a$得$u = v$。因此相等的值来自相等的数对。
:::

康托尔本人对网格的枚举方式是依次沿对角线$m+n = 2, 3, 4,\dots$行走：$(1,1)$；然后$(1,2), (2,1)$；然后$(1,3), (2,2), (3,1)$；依此类推。由于每条对角线都是有限的，每个数对都会在有限步之后到达。

caption: 康托尔沿对角线逐条走遍网格$\N\times\N$的方式。每个数对都在有限步之后到达，因而在列表中获得一个编号。对比逐行列出的方式$(1,1), (1,2), (1,3),\dots$：它永远离不开第一行，因而无法列出所有数对。
:::

::: corollary 乘积、有理数与并 {#cor-countable}
1. 若$A$和$B$是可数的，则$A\times B$是可数的。
2. $\Q$是可数的。
3. 若$A_1, A_2, A_3,\dots$都是可数集，则$\bigcup_{n=1}^\infty A_n$是可数的。
:::

::: proof
1. 若$A$或$B$是空集，则$A\times B$也是空集。否则由[[#lem-countable-criteria]]，取单射$f\colon A\to\N$和$g\colon B\to\N$。则$(a,b)\mapsto(f(a),g(b))$是单射$A\times B\to\N\times\N$，再与[[#thm-nxn]]中的双射复合，就得到单射$A\times B\to\N$。

2. 由第1条和[[#ex-integers]]，$\Z\times\N$是可数的，所以存在满射$\N\to\Z\times\N$。映射$\Z\times\N\to\Q$，$(p,q)\mapsto p/q$是满射，因为每个有理数都可以写成分母为正的分数。两者复合就得到满射$\N\to\Q$。

3. 去掉其中的空集$A_n$；若它们全是空集，则并集是空集。设$I\subseteq\N$是剩下的下标组成的集合。对每个$n\in I$，选取一个满射$g_n\colon\N\to A_n$。则$(n,k)\mapsto g_n(k)$是从$I\times\N$到并集上的满射。由于$I\times\N$是可数的且非空，存在满射$\N\to I\times\N$，两者复合就得到从$\N$到并集上的满射。
:::

::: remark 隐蔽地使用了选择公理
第3条同时为每个$n$选取了一个满射$g_n$：这是无穷多次任意的选择，其合理性由**选择公理**（[[proofs/functions]]）保证。这并非吹毛求疵。所罗门·费弗曼（Solomon Feferman）和阿兹列尔·莱维（Azriel Lévy）在1963年证明：如果没有选择公理，“$\R$是可数个可数集的并”这一命题是相容的。在具体情形中，我们通常可以通过写出具体的枚举来避免使用选择公理。
:::

::: widget cantor

size: 8
caption: 沿对角线逐条走遍分数$p/q$的网格，从而列出全部正有理数。不是最简形式的分数，如$2/2$或$2/4$，重复了已经列出的值；跳过它们之后，每个正有理数恰好出现一次。任意两个有理数之间都有无穷多个有理数，但它们全都能排进同一个列表。
:::

::: example 代数数 {#ex-algebraic}
如果一个实数是某个非零整系数多项式的根，就称它是**代数数**——例如$\sqrt2$是$x^2-2$的根，每个有理数$p/q$是$qx-p$的根——否则称它是**超越数**。证明代数数集是可数的。
::: solution
对每个$d\in\N$，次数不超过$d$的整系数多项式$a_0+a_1x+\cdots+a_dx^d$由元组$(a_0,\dots,a_d)\in\Z^{d+1}$确定，而反复使用[[#cor-countable]]的第1条可知$\Z^{d+1}$是可数的。所以全体非零整系数多项式组成的集合$P$是可数个可数集的并，由第3条，它是可数的。$d$次非零多项式至多有$d$个实根（[[abstract-algebra/polynomials]]），所以代数数集是这样一些有限集的并：对可数多个$p \in P$中的每一个，取$p$的有限根集。再由第3条，它是可数的。

结合$\R$的不可数性（下面即将证明），这就表明超越数是存在的——事实上，除可数多个之外，所有实数都是超越数——而无需举出任何一个具体的超越数。这就是康托尔1874年的论证。约瑟夫·刘维尔（Joseph Liouville）早在1844年就构造出了明确的超越数，而$e$和$\pi$的超越性分别由夏尔·埃尔米特（Charles Hermite，1873）和费迪南德·冯·林德曼（Ferdinand von Lindemann，1882）证明。
:::
:::

## 不可数集

### 对角线论证

我们要用到关于十进制小数的两个事实，它们在[[real-analysis/series]]中由$\R$的完备性证明。每个$x\in[0,1)$都有十进制展开$x = 0.d_1d_2d_3\ldots = \sum_{k\ge1}d_k10^{-k}$，其中数字$d_k\in\set{0,\dots,9}$。有些数有两种展开，例如$0.5000\ldots = 0.4999\ldots$，但如果禁止以无穷多个$9$结尾的展开，那么每个$x\in[0,1)$都**恰有一种**展开。

::: theorem 实数集是不可数的 {#thm-reals-uncountable}
区间$(0,1)$是不可数的。因此$\R$是不可数的。
:::

::: proof
由[[#lem-countable-criteria]]，只需证明没有一个函数$f\colon\N\to(0,1)$是满射。为此设$f$是任一这样的函数，把每个函数值写成不以$9$结尾的十进制展开：

$$
\begin{aligned}
f(1) &= 0.\,\mathbf{d_{11}}\,d_{12}\,d_{13}\,d_{14}\ldots\\
f(2) &= 0.\,d_{21}\,\mathbf{d_{22}}\,d_{23}\,d_{24}\ldots\\
f(3) &= 0.\,d_{31}\,d_{32}\,\mathbf{d_{33}}\,d_{34}\ldots\\
&\ \ \vdots
\end{aligned}
$$

改变对角线上的数字，定义$x = 0.e_1e_2e_3\ldots$：

$$
e_n = \begin{cases} 4, & \text{若 } d_{nn} = 5,\\ 5, & \text{若 } d_{nn}\neq 5.\end{cases}
$$

$x$的所有数字都是$4$或$5$，所以$0 < \frac49 = 0.444\ldots\le x\le 0.555\ldots = \frac59 < 1$，$x\in(0,1)$；并且$x$的这个展开不以$9$结尾，所以它就是$x$的**那个**允许的展开。对每个$n$，由于$e_n\neq d_{nn}$，$x$与$f(n)$的允许展开在第$n$位数字上不同。由允许展开的唯一性，$x\neq f(n)$。所以$x$不是$f$的值，$f$不是满射。

因此$(0,1)$是不可数的；由于可数集的子集是可数的（[[#thm-subset-countable]]），$\R$也是不可数的。
:::

选用数字$4$和$5$是有意为之。如果把数字改成$0$或$9$，那么$x$可能恰好是，比如说，$0.0999\ldots$，它等于$0.1000\ldots$，从而可能以后一种形式出现在列表中。避开$0$和$9$，就完全绕开了双重展开的问题。

::: widget cantor
mode: diagonal
size: 8
caption: 康托尔的对角线论证。无论显示的是怎样的展开列表，新数都是通过改变第$n$项的第$n$位数字构造出来的，所以它与每一项至少在一个位置上不同。无论从哪个列表出发，这个构造都能击败它：任何实数列表都不可能是完整的。
:::

由于$\R = \Q\cup(\R\setminus\Q)$，而两个可数集的并是可数的，所以无理数集是不可数的：在基数的意义下，几乎每个实数都是无理数。同样，由[[#ex-algebraic]]，几乎每个实数都是超越数。

### 康托尔定理

对角线的想法远不止适用于实数。

::: theorem 康托尔定理 {#thm-cantor}
对每个集合$A$，不存在满射$A\to\mathcal{P}(A)$。因此$\abs A<\abs{\mathcal{P}(A)}$。
:::

::: proof
设$f\colon A\to\mathcal{P}(A)$是任一函数，考虑集合

$$
D = \set{a\in A : a\notin f(a)}.
$$

则$D\subseteq A$，所以$D\in\mathcal{P}(A)$。假设对某个$d\in A$有$D = f(d)$。若$d\in D$，则由$D$的定义，$d\notin f(d) = D$。若$d\notin D = f(d)$，则$d$满足定义$D$的条件，所以$d\in D$。两种情形都导致矛盾，所以$D$不是$f$的值，$f$不是满射。

特别地，不存在双射$A\to\mathcal{P}(A)$，所以$\abs A\neq\abs{\mathcal{P}(A)}$。由于$a\mapsto\set a$是单射$A\to\mathcal{P}(A)$，有$\abs A\le\abs{\mathcal{P}(A)}$，因此$\abs A < \abs{\mathcal{P}(A)}$。
:::

集合$D$是乔装打扮的对角线构造。设想一张表格，每个$a\in A$对应一行，每个$b \in A$对应一列，当$b\in f(a)$时表中的元素为“是”。$a$所在的行描述了集合$f(a)$；$D$是读出对角线并把每个答案反转而得到的，所以它与每一行$f(a)$在$(a,a)$处的元素不同。把同样的技巧用于“全体集合组成的集合”，就产生了罗素（Russell）悖论（[[proofs/sets#thm-russell]]）。

反复应用康托尔定理，得$\abs\N<\abs{\mathcal{P}(\N)}<\abs{\mathcal{P}(\mathcal{P}(\N))}<\cdots$：无穷有无穷多种不同的大小，而且没有最大的。对含$n$个元素的有限集，这个定理说的是$n<2^n$。

::: quiz
下列哪个集合是不可数的？
- [ ] $\Z\times\Z\times\Z$
- [ ] $\N$的所有有限子集组成的集合
- [ ] $\Q\cap(0,1)$
- [x] $\N$的所有子集组成的集合
::: solution
两次应用[[#cor-countable]]可知$\Z\times\Z\times\Z = (\Z\times\Z)\times\Z$是可数的。$\N$的有限子集组成的集合是有限集$\mathcal{P}([n])$（$n\in\N$）的并，即可数个有限集的并。$\Q\cap(0,1)$是可数集$\Q$的子集。但$\mathcal{P}(\N)$是不可数的：由康托尔定理，甚至不存在从$\N$到它上面的满射。
:::
:::

## 施罗德-伯恩斯坦定理

若$\abs A\le\abs B$且$\abs B\le\abs A$，那么$A$与$B$的大小相同吗？对有限集而言，通过计数可知答案是肯定的。对无限集而言，这两个单射并不能直接给出一个双射，因为它们都未必是满射——想一想两个方向上都取从$\N$到$\N$的$n\mapsto 2n$。尽管如此，答案仍是肯定的，而这个定理是证明两个集合等势的最有用的工具。

::: theorem 施罗德-伯恩斯坦（Schröder–Bernstein）定理 {#thm-schroder-bernstein}
若存在单射$f\colon A\to B$和$g\colon B\to A$，则存在双射$h\colon A\to B$。换言之，若$\abs A\le\abs B$且$\abs B\le\abs A$，则$\abs A = \abs B$。
:::

::: proof
令$C_0 = A\setminus g(B)$，即$A$中不被$g$取到的元素；对$n\ge0$，令$C_{n+1} = g(f(C_n))$；再令$C = \bigcup_{n\ge0}C_n$。若$a\in A\setminus C$，则特别地$a\notin C_0$，所以$a\in g(B)$；由于$g$是单射，恰有一个$b\in B$使$g(b) = a$，记为$g^{-1}(a)$。定义

$$
h(a) = \begin{cases} f(a), & a\in C,\\ g^{-1}(a), & a\notin C.\end{cases}
$$

*$h$是单射*。设$h(a) = h(a')$。若$a, a'\in C$，则$f(a) = f(a')$，由于$f$是单射，$a = a'$。若$a, a'\notin C$，则$g^{-1}(a) = g^{-1}(a')$，作用$g$得$a = a'$。最后设$a\in C$而$a'\notin C$。则$f(a) = g^{-1}(a')$，所以$a' = g(f(a))$。但对某个$n$有$a\in C_n$，所以$a' = g(f(a))\in C_{n+1}\subseteq C$，矛盾。所以这种情形不会出现。

*$h$是满射*。设$b\in B$。若$g(b)\notin C$，则$h(g(b)) = g^{-1}(g(b)) = b$。若$g(b)\in C$，则$g(b)\notin C_0$（因为$g(b)\in g(B)$），所以对某个$n\ge0$有$g(b)\in C_{n+1} = g(f(C_n))$；即对某个$a\in C_n$有$g(b) = g(f(a))$。由于$g$是单射，$b = f(a)$，其中$a\in C$，所以$b = h(a)$。
:::

::: intuition 沿着链条追踪
从任一元素出发，向前交替地作用$f$和$g$，向后交替地作用$g^{-1}$和$f^{-1}$，能走多远就走多远。$A$和$B$的元素就分成了一条条互不相交的链。向后追溯时起始于$A$中不被$g$取到的元素的链，用$f$来配对；这些链组成了集合$C$。其他每条链——起始于$B$的、没有起点的，或者首尾相接成环的——都用$g^{-1}$来配对。上面的证明就是这幅图景的严格版本。
:::

::: example 闭区间与开区间 {#ex-closed-open}
证明$\abs{[0,1]} = \abs{(0,1)}$。
::: solution
包含映射$(0,1)\to[0,1]$是单射。映射$x\mapsto(x+1)/3$是单射，并且把$[0,1]$映成$[\frac13,\frac23]\subseteq(0,1)$，所以它是单射$[0,1]\to(0,1)$。由施罗德-伯恩斯坦定理，存在双射。

按照希尔伯特旅馆的思路，也可以写出明确的双射：令$0\mapsto\frac12$，$1\mapsto\frac13$，对$n\ge2$令$\frac1n\mapsto\frac1{n+2}$，其他每个点保持不动。但这个定理使我们不必去寻找它。
:::
:::

::: example 实数与 ℕ 的子集 {#ex-continuum}
证明$\abs\R = \abs{\mathcal{P}(\N)}$。
::: solution
*$\abs{\mathcal{P}(\N)}\le\abs\R$*。把$S\subseteq\N$映为数$x_S = \sum_{n\in S}10^{-n}\in[0,1)$，它的十进制展开在第$n$位上的数字当$n\in S$时为$1$，否则为$0$。这个展开不含数字$9$，所以它是$x_S$唯一的允许展开；不同的集合给出不同的展开，从而给出不同的数。所以$S\mapsto x_S$是单射。

*$\abs\R\le\abs{\mathcal{P}(\N)}$*。把$x\in\R$映为小于它的有理数组成的集合$L_x = \set{q\in\Q : q<x}$。若$x<y$，则存在有理数$q$使$x<q<y$（[[real-analysis/real-numbers]]），从而$q\in L_y\setminus L_x$；所以$x\mapsto L_x$是单射$\R\to\mathcal{P}(\Q)$。双射$\varphi\colon\Q\to\N$（[[#cor-countable]]）诱导出双射$\mathcal{P}(\Q)\to\mathcal{P}(\N)$，$T\mapsto\varphi(T)$，复合起来就得到单射$\R\to\mathcal{P}(\N)$。

由施罗德-伯恩斯坦定理，$\abs\R = \abs{\mathcal{P}(\N)}$。
:::
:::

::: quiz
下列哪一对集合的基数**不**相同？
- [ ] $\N$与$\Q$
- [ ] $(0,1)$与$\R$
- [ ] $\R$与$\mathcal{P}(\N)$
- [x] $\N$与$\mathcal{P}(\N)$
::: solution
由[[#cor-countable]]，$\abs\N = \abs\Q$；由本章末尾的一道习题，$\abs{(0,1)} = \abs\R$；由[[#ex-continuum]]，$\abs\R = \abs{\mathcal{P}(\N)}$。但由康托尔定理（[[#thm-cantor]]），$\abs\N<\abs{\mathcal{P}(\N)}$。
:::
:::

$\R$的基数称为**连续统的基数**，记作$\mathfrak{c}$。由[[#ex-continuum]]，它也是$\mathcal{P}(\N)$的基数，这就是它常被写作$2^{\aleph_0}$的原因。

::: remark 连续统假设
是否存在集合$S$满足$\aleph_0<\abs S<\mathfrak c$，即一个严格介于可数与连续统之间的无穷？康托尔猜想不存在——这就是**连续统假设**——并为证明它努力了多年；大卫·希尔伯特把它列为他1900年那份著名问题清单中的第一个问题。答案出人意料：库尔特·哥德尔（Kurt Gödel）在1940年证明，连续统假设不能由集合论的标准公理（ZFC）否证；保罗·科恩（Paul Cohen）在1963年证明，它也不能由这些公理证明。数学的通常公理根本无法判定它。
:::

::: application 大多数函数是不可计算的
计算机程序是由有限字母表中的字符组成的有限字符串，所以全体程序组成的集合是可数个有限集的并，因而是可数的。但由康托尔定理，函数$\N\to\set{0,1}$组成的集合——等价地，$\N$的子集组成的集合——是不可数的。所以几乎所有这样的函数都不能由任何程序计算。艾伦·图灵（Alan Turing）在1936年精确地刻画了程序的概念，并用对角线论证证明了有些关于程序的问题不能由任何程序判定；最著名的例子是判定一个给定的程序最终是否会停机。
:::

::: history
伽利略·伽利莱（Galileo Galilei）在《两门新科学》（*Two New Sciences*，1638）中指出，完全平方数可以与全体自然数一一配对，并由此断言“大于”和“小于”不适用于无穷的总体。格奥尔格·康托尔（Georg Cantor）采取了相反的观点。1874年，他证明了代数数是可数的，而实数不是；1877年，他发现正方形所含的点与线段所含的点恰好一样多，这连他自己都感到惊讶；1891年，他发表了对角线论证以及现在以他的名字命名的定理。1888年，里夏德·戴德金（Richard Dedekind）把“与一个真子集等势”作为无限集的定义。康托尔的思想遭到了激烈的反对，尤其是来自利奥波德·克罗内克（Leopold Kronecker）的反对，但到了1926年，大卫·希尔伯特（David Hilbert）已经可以宣称：没有人能把数学家从康托尔为他们创造的乐园中驱逐出去。
:::

## 后续内容

可数与不可数的区别贯穿于整个分析学。每个可数的实数集的勒贝格（Lebesgue）测度都为零，而区间则不然；康托尔集是一个测度为零的不可数集（[[measure-theory/lebesgue-measure]]）。概率论允许可数可加性，但不允许不可数可加性（[[probability/probability-spaces]]），而诸如可分性之类的可数性条件是拓扑学中的基本概念（[[topology/topological-spaces]]）。有限基数是[[discrete/counting]]的主题，在那里，双射成为证明两个总体大小相同的主要工具。

::: summary
- $\abs A = \abs B$是指存在双射$A\to B$，$\abs A\le\abs B$是指存在单射。无限集可以与其真子集等势（$\N$与偶数集，希尔伯特旅馆）；由鸽巢原理，有限集则不能。
- 若一个集合是有限的，或与$\N$之间存在双射，即它的元素可以排成一列，则称它是可数的。要证明可数性，只需找到一个到$\N$中的单射或一个从$\N$出发的满射（[[#lem-countable-criteria]]）。
- $\Z$、$\N\times\N$、$\Q$、代数数集以及可数个可数集的并都是可数的。
- $\R$是不可数的：对角线论证构造出一个不在任何给定列表中的数（[[#thm-reals-uncountable]]）。因此无理数集和超越数集都是不可数的。
- 康托尔定理：不存在满射$A\to\mathcal{P}(A)$，所以$\abs A<\abs{\mathcal{P}(A)}$，并且不存在最大的无穷。
- 施罗德-伯恩斯坦定理：两个方向上的单射给出一个双射。例如$\abs{[0,1]} = \abs{(0,1)}$，$\abs{\R} = \abs{\mathcal{P}(\N)} = \mathfrak c$。
- 是否有某个基数严格介于$\aleph_0$与$\mathfrak c$之间，通常的公理无法判定。
:::

## 习题

::: exercise 明确的双射 {level=1}
写出明确的双射：(a) $\N\to\N\setminus\set{1,2,3}$；(b) $(0,1)\to(3,8)$；(c) $\N\to\Z\setminus\set0$。
::: solution
(a) $n\mapsto n+3$，其逆为$m\mapsto m-3$。

(b) $x\mapsto 3+5x$，其逆为$y\mapsto(y-3)/5$；若$0<x<1$，则$3<3+5x<8$，反之亦然。

(c) 对偶数$n$，$f(n) = n/2$；对奇数$n$，$f(n) = -(n+1)/2$。这给出列表$-1, 1, -2, 2, -3, 3,\dots$。偶数双射地映到正整数（$2k\mapsto k$），奇数双射地映到负整数（$2k-1\mapsto -k$），所以$f$是双射。
:::
:::

::: exercise 可数还是不可数？ {level=1}
下列集合中哪些是可数的？(a) $\Z\times\Z$；(b) 无理数集；(c) 由$\set{a,b,\dots,z}$中的字母组成的所有有限字符串的集合；(d) $\set{x\in\R : x^2\in\Q}$；(e) 由$0$和$1$组成的所有无穷序列的集合。
::: solution
(a) 可数，由[[#cor-countable]]的第1条。

(b) 不可数：如果无理数集是可数的，那么$\R$就是两个可数集的并，因而是可数的。

(c) 可数：对每个长度$n$，字符串有$26^n$个，是有限多个；而所有字符串的集合是这些有限集的可数并。

(d) 可数：这个集合是$\set{\pm\sqrt q : q\in\Q,\ q\ge0}$，即可数集$\set{q \in \Q : q \geq 0} \times\set{1,-1}$在$(q,s)\mapsto s\sqrt q$下的像，而可数集在任何函数下的像都是可数的（与一个从$\N$出发的满射复合即可）。

(e) 不可数：这样的序列与$\N$的子集一一对应（一个序列就是它取值为$1$的位置组成的集合的特征函数），而由[[#thm-cantor]]，$\mathcal{P}(\N)$是不可数的。
:::
:::

::: exercise 在康托尔列表中的位置 {level=1 check="18"}
康托尔对$\N\times\N$的对角线枚举给$(m,n)$指定的编号是$\pi(m,n) = \frac{(m+n-2)(m+n-1)}{2} + m$。验证$\pi(1,1) = 1$，$\pi(1,2) = 2$，$\pi(2,1) = 3$，并计算$\pi(3,4)$。
::: solution
$\pi(1,1) = 0 + 1 = 1$，$\pi(1,2) = \frac{1\cdot2}{2}+1 = 2$，$\pi(2,1) = 1 + 2 = 3$。对$(3,4)$，有$m+n = 7$，所以$\pi(3,4) = \frac{5\cdot6}{2}+3 = 15+3 = 18$。（第一项计算的是此前各条对角线$m+n = 2,\dots,6$上的$1+2+\cdots+5 = 15$个数对，而$m = 3$是在对角线$m+n = 7$上的位置。）
:::
:::

::: exercise 区间与实数轴 {level=2}
证明$g\colon(-1,1)\to\R$，$g(x) = \dfrac{x}{1-\abs x}$是双射，并由此推出$\abs{(0,1)} = \abs\R$。
::: hint
通过解$y = x/(1-\abs x)$来猜出逆，注意$x$与$y$同号。
:::
::: solution
设$k\colon\R\to(-1,1)$，$k(y) = \dfrac{y}{1+\abs y}$；注意$\abs{k(y)} = \frac{\abs y}{1+\abs y}<1$，所以$k$确实映入$(-1,1)$。对$x\in(-1,1)$，$g(x)$与$x$同号，且$\abs{g(x)} = \frac{\abs x}{1-\abs x}$，所以$1+\abs{g(x)} = \frac{1}{1-\abs x}$，从而

$$
k(g(x)) = \frac{x}{1-\abs x}\cdot(1-\abs x) = x.
$$

对$y\in\R$，$k(y)$与$y$同号，$1-\abs{k(y)} = \frac{1}{1+\abs y}$，并且$g(k(y)) = \frac{y}{1+\abs y}\cdot(1+\abs y) = y$。所以$g$有双边逆，是双射。与双射$(0,1)\to(-1,1)$，$x\mapsto 2x-1$复合，就得到双射$(0,1)\to\R$。
:::
:::

::: exercise 自然数集的有限子集 {level=2}
设$\mathcal{F}$是$\N$的所有有限子集组成的集合。证明$F(S) = 1 + \sum_{k\in S}2^{k-1}$定义了一个单射$\mathcal F\to\N$，并由此得出$\mathcal F$是可数的。$F$是满射吗？
::: solution
$F(S) - 1 = \sum_{k\in S}2^{k-1}$是这样一个数：它的二进制表示在第$k-1$位（从$0$开始计数）上为$1$当且仅当$k\in S$。每个非负整数都恰有一种二进制表示，所以不同的有限集给出不同的数，$F$是单射。由[[#lem-countable-criteria]]，$\mathcal F$是可数的。事实上$F$是满射：每个$m\in\N$都满足$m-1\ge0$，而$m-1$有二进制表示，它的各个$1$所在的位置（平移一位后）构成一个有限集$S$，满足$F(S) = m$。（例如$F(\varnothing) = 1$，$F(\set{1,3}) = 1 + 1 + 4 = 6$。）所以$F$是双射。
:::
:::

::: exercise 二进制序列 {level=2}
用对角线论证直接证明：每个$s_k\in\set{0,1}$的所有无穷序列$(s_1, s_2, s_3,\dots)$组成的集合是不可数的。
::: solution
这个集合非空，所以由[[#lem-countable-criteria]]，只需证明从$\N$到序列集合的任何函数$F$都不是满射。写$F(n) = (s_{n1}, s_{n2}, s_{n3},\dots)$，并用$t_n = 1-s_{nn}$定义序列$t$。对每个$n$，序列$t$与$F(n)$在第$n$项上不同，所以$t\neq F(n)$。因此$t$不是$F$的值。（这里不会出现双重表示的问题，因为两个序列相等当且仅当它们的每一项都相同。）
:::
:::

::: exercise 自然数序列 {level=2}
如果对所有充分大的$n$都有$a_n = 1$，就称自然数序列$(a_1, a_2, \dots)$**最终恒为$1$**。证明这样的序列组成的集合是可数的，而全体自然数序列组成的集合是不可数的。
::: hint
对于第一部分，对每个固定的$N$，考虑对所有$n > N$都有$a_n = 1$的序列。
:::
::: solution
对固定的$N\in\N$，满足对所有$n>N$都有$a_n = 1$的序列由$(a_1,\dots,a_N)\in\N^N$确定，而反复应用[[#cor-countable]]的第1条可知$\N^N$是可数的。最终恒为$1$的序列组成的集合是这些可数集（每个$N$对应一个）的可数并，所以由第3条，它是可数的。

全体自然数序列组成的集合包含每一项都属于$\set{1,2}$的序列，这些序列与$0$–$1$序列一一对应（把每一项减去$1$），因此由上一题，它们构成一个不可数集。由[[#thm-subset-countable]]，含有不可数子集的集合是不可数的。
:::

::: exercise 不存在反方向的单射 {level=3}
证明对每个集合$A$，都不存在单射$\mathcal{P}(A)\to A$。
::: hint
把康托尔定理与施罗德-伯恩斯坦定理结合起来。
:::
::: solution
假设$j\colon\mathcal{P}(A)\to A$是单射。映射$i\colon A\to\mathcal{P}(A)$，$a\mapsto\set a$也是单射，所以由施罗德-伯恩斯坦定理（[[#thm-schroder-bernstein]]），将存在双射$A\to\mathcal{P}(A)$。双射是满射，这与康托尔定理（[[#thm-cantor]]）矛盾。所以这样的$j$不存在。
:::
:::

::: exercise 正方形与线段 {level=3}
证明$\abs{(0,1)\times(0,1)} = \abs{(0,1)}$，并由此推出$\abs{\R\times\R} = \abs\R$。
::: hint
把$x$和$y$的允许十进制展开的数字交错排列，并利用施罗德-伯恩斯坦定理。
:::
::: solution
映射$x\mapsto(x,\frac12)$是单射$(0,1)\to(0,1)\times(0,1)$。另一个方向上，把$x$和$y$写成不以$9$结尾的展开$x = 0.x_1x_2x_3\ldots$和$y = 0.y_1y_2y_3\ldots$，并令$\Phi(x,y) = 0.x_1y_1x_2y_2x_3y_3\ldots$。这个展开也不以$9$结尾，否则奇数位和偶数位上的数字，即$x$的数字和$y$的数字，最终都将全是$9$。它也不是$0.000\ldots$，因为$x \neq 0$。所以它是某个数$\Phi(x,y)\in(0,1)$的允许展开，并且从中可以读出$x$和$y$的展开；因此$\Phi$是单射。由施罗德-伯恩斯坦定理，$\abs{(0,1)\times(0,1)} = \abs{(0,1)}$。

最后，双射$\beta\colon(0,1)\to\R$（见前面的习题）给出从$(0,1)\times(0,1)$到$\R\times\R$的双射$(x,y)\mapsto(\beta(x),\beta(y))$，所以$\abs{\R\times\R} = \abs{(0,1)\times(0,1)} = \abs{(0,1)} = \abs\R$。（映射$\Phi$不是满射——展开为$0.x_1 9 x_2 9 x_3 9\ldots$的数都不是它的值——这就是为什么施罗德-伯恩斯坦定理在这里如此方便。）
:::
:::

::: exercise 总能再住下一位 {level=3}
设集合$A$包含一个可数无穷子集$C = \set{c_1, c_2, c_3,\dots}$，其中各$c_n$互不相同。证明$A$与$A\setminus\set{c_1}$等势。（利用选择公理可以证明，每个无限集都有可数无穷子集；所以一个集合是无限集，当且仅当它与自身的某个真子集等势。）
::: solution
定义$h\colon A\to A\setminus\set{c_1}$：对每个$n\in\N$，$h(c_n) = c_{n+1}$；对$a\notin C$，$h(a) = a$。函数值都属于$A\setminus\set{c_1}$：$C$以外的元素不等于$c_1$，而由于各$c_n$互不相同，$c_{n+1}\neq c_1$。

*单射*。$C$以外的元素被映为自身，仍在$C$以外，而$C$中的元素被映入$C$；所以只需在每一部分内部进行比较。在$A\setminus C$上，$h$是恒等映射。在$C$上，$c_{n+1} = c_{m+1}$蕴涵$n = m$。

*满射*。元素$a\in A\setminus\set{c_1}$或者在$C$以外，此时$a = h(a)$；或者对某个$m\ge2$等于$c_m$，此时$a = h(c_{m-1})$。

所以$h$是双射——这就是任意无限集内部的希尔伯特旅馆。
:::
