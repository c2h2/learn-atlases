在弹簧上挂一个质量为$m$的物体，把它向下拉。松手后它会振动；如果有摩擦，振动会逐渐消失。设$x(t)$为偏离平衡位置的位移。弹簧以力$-kx$把物体拉回（胡克（Hooke）定律），摩擦以力$-cx'$阻碍运动，于是由牛顿（Newton）第二定律得

$$
m\,x'' + c\,x' + k\,x = 0 .
$$ {#eq-spring}

这是一个**常系数二阶线性方程**，它所描述的远不止弹簧：同一个方程支配着电路中的电荷、建筑物的摇晃，并且在一阶近似下支配着每一个处于稳定平衡点附近的系统。物体应该上下弹跳，还是缓缓回到静止？汽车压过坑洼之后，悬架会不会晃个不停？答案就藏在一个二次方程里。

本章发展二阶线性方程的理论。核心事实是：**线性齐次方程的解构成一个二维向量空间。**我们利用存在性定理、叠加原理和朗斯基行列式证明这一点；然后对常系数方程、柯西-欧拉（Cauchy–Euler）方程，以及——在已知一个解的情况下——任意二阶线性方程，求出解空间的显式的基。

## 二阶线性方程

::: definition 二阶线性方程 {#def-linear2}
标准形式的**二阶线性方程**为

$$
y'' + p(t)\,y' + q(t)\,y = g(t),
$$ {#eq-linear2}

其中系数$p, q$和强迫项$g$在开区间$I$上连续。若$g \equiv 0$，则称它是**齐次**的。记$L[y] = y'' + py' + qy$，方程就写成$L[y] = g$。
:::

方程$P(t)y'' + Q(t)y' + R(t)y = G(t)$可以通过除以$P$化为标准形式，但这只有在$P(t) \neq 0$处才允许。使$P$为零的点称为方程的**奇点**；下面的理论适用于避开奇点的区间，而[[ode/series-solutions]]一章研究在奇点处会发生什么。

对于二阶方程，自然要规定两个初始条件：$y(t_0) = y_0$和$y'(t_0) = y_1$——对弹簧来说，就是初始位置和初始速度。有了它们，解在所有时刻都被确定了。

::: theorem 线性方程的存在唯一性 {#thm-eu2}
若$p$、$q$和$g$在开区间$I$上连续，则对每个$t_0 \in I$以及所有$y_0, y_1 \in \R$，初值问题

$$
y'' + p(t)y' + q(t)y = g(t), \qquad y(t_0) = y_0, \quad y'(t_0) = y_1
$$

恰有一个解，并且它在**整个**区间$I$上有定义。
:::

::: proof
令$\mathbf{x}(t) = \bigl(y(t), y'(t)\bigr)$。则$y$是该初值问题的解，当且仅当$\mathbf{x}$是下面的一阶**方程组**的解：

$$
\mathbf{x}' = A(t)\,\mathbf{x} + \mathbf{b}(t), \qquad A(t) = \begin{pmatrix} 0 & 1 \\ -q(t) & -p(t)\end{pmatrix},\quad \mathbf{b}(t) = \begin{pmatrix} 0 \\ g(t)\end{pmatrix}, \qquad \mathbf{x}(t_0) = \begin{pmatrix} y_0 \\ y_1\end{pmatrix}.
$$

在包含$t_0$的闭区间$[\alpha,\beta] \subseteq I$上，右端$\mathbf{F}(t,\mathbf{x}) = A(t)\mathbf{x} + \mathbf{b}(t)$满足$\norm{\mathbf{F}(t,\mathbf{x}) - \mathbf{F}(t,\mathbf{z})} = \norm{A(t)(\mathbf{x}-\mathbf{z})} \le L\norm{\mathbf{x} - \mathbf{z}}$，其中$L$是$A(t)$的算子范数在$[\alpha,\beta]$上的最大值，由于各元素连续，它是有限的。皮卡-林德勒夫（Picard–Lindelöf）定理和带形区域上整体存在性的证明（[[ode/existence-uniqueness#thm-picard]]，[[ode/existence-uniqueness#thm-global]]）只用到了三角不等式和$\norm{\int \mathbf{v}} \le \int\norm{\mathbf{v}}$，所以它们可以逐字逐句地推广到向量值函数。因此在$[\alpha,\beta]$上恰有一个解；由于$I$的每一点都位于这样的区间中，唯一性使我们可以把这些解拼接成$I$上的一个解。方程组情形的细节在[[ode/linear-systems]]一章中给出。
:::

一个有用的推论：**满足$y(t_0) = y'(t_0) = 0$的齐次方程的唯一解是$y \equiv 0$**，因为零函数是这个初值问题的解。

::: warning 先除以首项系数
对于$t^2y'' - 3ty' + 4y = 0$，标准形式中的$p = -3/t$，$q = 4/t^2$，它们在$t = 0$处不连续。于是[[#thm-eu2]]分别在$(0,\infty)$和$(-\infty,0)$上适用，但对包含$0$的区间什么也没有说。确实，$t^2$和$0$都是这个方程满足$y(0) = y'(0) = 0$的解，所以唯一性在奇点处确实不成立。
:::

## 叠加原理与朗斯基行列式

::: theorem 叠加原理 {#thm-superposition}
算子$L[y] = y'' + py' + qy$是线性的：对二阶可导的$y_1, y_2$和常数$c_1, c_2$，

$$
L[c_1y_1 + c_2y_2] = c_1L[y_1] + c_2L[y_2].
$$

因此，齐次方程$L[y] = 0$的解的任意线性组合仍是解：这些解构成一个向量空间。
:::

::: proof
求导是线性的，所以$(c_1y_1 + c_2y_2)'' = c_1y_1'' + c_2y_2''$，一阶导数也类似。因此

$$
L[c_1y_1 + c_2y_2] = c_1y_1'' + c_2y_2'' + p\,(c_1y_1' + c_2y_2') + q\,(c_1y_1 + c_2y_2) = c_1L[y_1] + c_2L[y_2].
$$

若$L[y_1] = L[y_2] = 0$，则右边为$0$。解的集合包含$0$，并且对线性组合封闭，所以它是$I$上二阶可导函数构成的向量空间的一个子空间。
:::

这个向量空间有多大？如果在$I$上两个解$y_1, y_2$中的一个是另一个的常数倍（确切地说：存在不全为零的常数，使得$c_1y_1 + c_2y_2 \equiv 0$），就称它们在$I$上**线性相关**，否则称它们**线性无关**。检测线性无关性的工具是一个行列式。

::: definition 朗斯基行列式 {#def-wronskian}
两个可导函数$y_1, y_2$的**朗斯基行列式**为

$$
W[y_1, y_2](t) = \begin{vmatrix} y_1(t) & y_2(t) \\ y_1'(t) & y_2'(t)\end{vmatrix} = y_1(t)\,y_2'(t) - y_1'(t)\,y_2(t).
$$
:::

朗斯基行列式是为了拟合初始条件而必须求解的线性方程组的行列式，这就是它能控制一切的原因。

::: theorem 基本解组 {#thm-general}
设$y_1, y_2$是$y'' + py' + qy = 0$在$I$上的解，并且对某个$t_0 \in I$有$W[y_1,y_2](t_0) \neq 0$。则$I$上的每个解都可以写成

$$
y = c_1\,y_1 + c_2\,y_2
$$

其中常数$c_1, c_2$是唯一确定的。这样的一对解称为**基本解组**，而$c_1y_1 + c_2y_2$称为**通解**。
:::

::: proof
设$y$是任意一个解。我们要找常数，使得$c_1y_1(t_0) + c_2y_2(t_0) = y(t_0)$且$c_1y_1'(t_0) + c_2y_2'(t_0) = y'(t_0)$。这是一个$2\times2$线性方程组，其系数行列式为$W[y_1,y_2](t_0) \neq 0$，所以它恰有一个解$(c_1, c_2)$（克拉默（Cramer）法则，[[linear-algebra/determinants]]）。取这些常数，由[[#thm-superposition]]，$z = c_1y_1 + c_2y_2$是解，并且在$t_0$处与$y$有相同的初值。由[[#thm-eu2]]的唯一性部分，在$I$上$z = y$。这些常数是唯一的，因为任何一种表示都必须满足同一个线性方程组。
:::

这个假设只要求在一点处$W \neq 0$。为什么这就足够了？这可以由两个解的朗斯基行列式的一个奇妙公式来解释，而这个公式**无需知道解**就能计算。

::: theorem 阿贝尔（Abel）公式 {#thm-abel}
若$y_1, y_2$在$I$上是$y'' + p(t)y' + q(t)y = 0$的解，则对任意$t_0 \in I$，

$$
W[y_1,y_2](t) = W[y_1,y_2](t_0)\,\exp\left(-\int_{t_0}^{t} p(s)\,ds\right) \qquad (t \in I).
$$ {#eq-abel}

特别地，$W$要么在$I$上恒为零，要么在$I$上处处不为零。
:::

::: proof
对$W = y_1y_2' - y_1'y_2$求导；其中的$y_1'y_2'$项相互抵消：

$$
W' = y_1y_2'' - y_1''y_2 = y_1\bigl(-py_2' - qy_2\bigr) - \bigl(-py_1' - qy_1\bigr)y_2 = -p\,\bigl(y_1y_2' - y_1'y_2\bigr) = -p\,W.
$$

所以$W$是一阶线性方程$W' + pW = 0$的解，由[[ode/first-order#thm-linear]]即得[[#eq-abel]]。指数因子永远不为零，所以对某个$t$有$W(t) = 0$当且仅当$W(t_0) = 0$。
:::

::: corollary 解的朗斯基行列式判别法 {#cor-wronskian}
$y'' + py' + qy = 0$在$I$上的两个解$y_1, y_2$线性无关，当且仅当对某个（等价地，对每个）$t\in I$有$W[y_1,y_2](t) \neq 0$。因此解空间恰好是二维的。
:::

::: proof
若$y_1, y_2$线性相关，比如$y_2 = cy_1$（或$y_1 \equiv 0$），则朗斯基矩阵的两列成比例，$W \equiv 0$。反过来，设$W(t_0) = 0$。则线性方程组$c_1y_1(t_0) + c_2y_2(t_0) = 0$，$c_1y_1'(t_0) + c_2y_2'(t_0) = 0$有非零解$(c_1,c_2)$。函数$y = c_1y_1 + c_2y_2$是方程的解，并且$y(t_0) = y'(t_0) = 0$，所以由唯一性，$y\equiv 0$，从而$y_1,y_2$线性相关。

关于维数：设$y_1, y_2$是满足$(y_1, y_1')(t_0) = (1, 0)$和$(y_2, y_2')(t_0) = (0,1)$的解，由[[#thm-eu2]]，它们存在。它们在$t_0$处的朗斯基行列式为$1$，所以它们线性无关，而由[[#thm-general]]，它们张成解空间。所以它们构成一组基。
:::

::: quiz
下列哪些函数对构成$y'' - y = 0$在$\R$上的基本解组？（选出所有符合条件的选项。）
- [x] $e^t,\ e^{-t}$
- [x] $\cosh t,\ \sinh t$
- [ ] $e^t,\ 2e^t$
- [x] $e^t,\ e^t + e^{-t}$
::: solution
所列的函数都是解。$W[e^t, e^{-t}] = -2$，$W[\cosh t,\sinh t] = \cosh^2 t - \sinh^2 t = 1$，$W[e^t, e^t + e^{-t}] = -2$都不为零，所以这些函数对是基本解组。函数对$e^t, 2e^t$线性相关（$W \equiv 0$）：它只张成一个一维子空间，无法同时拟合$y(0)$和$y'(0)$。
:::
:::

::: warning 朗斯基行列式判别法只适用于解
对于任意的函数，$W \equiv 0$**并不**蕴涵线性相关。函数$t^3$和$\lvert t\rvert^3$在$\R$上满足$W \equiv 0$，但它们在$\R$上线性无关（见[[#exr-3-10]]）。[[#cor-wronskian]]本质地用到了微分方程——通过唯一性——而结论是：这样的两个函数不可能同时是同一个在$\R$上系数连续的方程$y'' + py' + qy = 0$的解。
:::

## 常系数方程

对于$a\,y'' + b\,y' + c\,y = 0$（其中$a \neq 0$、$b$、$c$是实常数），我们寻找形如$y = e^{rt}$的解，因为对指数函数求导只是把它乘以一个常数。代入，得

$$
a\,r^2e^{rt} + b\,r\,e^{rt} + c\,e^{rt} = (ar^2 + br + c)\,e^{rt} = 0,
$$

由于$e^{rt}\neq 0$，$e^{rt}$是解当且仅当$r$是下面的**特征方程**的根：

$$
a\,r^2 + b\,r + c = 0 .
$$ {#eq-characteristic}

二次方程或者有两个相异实根，或者有一个二重实根，或者有一对共轭复根，每种情形都给出一个基本解组。

::: theorem 常系数方程 {#thm-constant}
设$r_1, r_2$是[[#eq-characteristic]]的根。$ay'' + by' + cy = 0$在$\R$上的一个基本解组为：

1. 若$r_1 \neq r_2$是实数，则为$e^{r_1t},\ e^{r_2t}$；
2. 若$r_1 = r_2 = r$，则为$e^{rt},\ t\,e^{rt}$；
3. 若$r_{1,2} = \lambda \pm i\mu$，$\mu \neq 0$，则为$e^{\lambda t}\cos\mu t,\ e^{\lambda t}\sin\mu t$。
:::

::: proof
在每种情形下，我们证明两个函数都是解，并且它们的朗斯基行列式不为零；其余的由[[#thm-general]]完成。记$P(r) = ar^2 + br + c$，$L[y] = ay'' + by' + cy$，于是$L[e^{rt}] = P(r)e^{rt}$。

1. 两个指数函数都是解，并且$W = e^{r_1t}\,r_2e^{r_2t} - r_1e^{r_1t}e^{r_2t} = (r_2 - r_1)\,e^{(r_1+r_2)t} \neq 0$。

2. 重根满足$P(r) = 0$和$P'(r) = 2ar + b = 0$。对$y = te^{rt}$，有$y' = (1 + rt)e^{rt}$和$y'' = (2r + r^2t)e^{rt}$，所以

$$
L[te^{rt}] = \bigl(a(2r + r^2t) + b(1 + rt) + ct\bigr)e^{rt} = \bigl(t\,P(r) + P'(r)\bigr)e^{rt} = 0 .
$$

朗斯基行列式为$e^{rt}(1 + rt)e^{rt} - re^{rt}\,te^{rt} = e^{2rt} \neq 0$。

3. 对复数$r = \lambda + i\mu$，定义$e^{rt} = e^{\lambda t}(\cos\mu t + i\sin\mu t)$（欧拉公式，[[complex-analysis/elementary-functions]]）。用乘积法则对实部和虚部分别求导可知，对复数$r$同样有$\frac{d}{dt}e^{rt} = re^{rt}$，所以$L[e^{rt}] = P(r)e^{rt} = 0$。由于$a, b, c$是实数，$L$把实函数映为实函数，所以

$$
L[\operatorname{Re} e^{rt}] = \operatorname{Re} L[e^{rt}] = 0, \qquad L[\operatorname{Im} e^{rt}] = \operatorname{Im}L[e^{rt}] = 0 .
$$

因此$e^{\lambda t}\cos\mu t$和$e^{\lambda t}\sin\mu t$是实解，而直接计算得$W = \mu\,e^{2\lambda t} \neq 0$。
:::

::: intuition $t e^{rt}$从何而来？
当根$r_1 \neq r_2$相异时，$\dfrac{e^{r_2t} - e^{r_1t}}{r_2 - r_1}$是一个解。现在令$r_2 \to r_1 = r$（通过扰动系数）。这个商趋于$e^{rt}$**对$r$**的导数，即$t\,e^{rt}$。重根情形下的第二个解，就是两个正在合并的解的差商的极限。
:::

::: example 两个相异实根 {#ex-distinct}
求解$y'' + y' - 6y = 0$，$y(0) = 1$，$y'(0) = 0$。
::: solution
特征方程$r^2 + r - 6 = (r + 3)(r - 2) = 0$的根为$2$和$-3$，所以$y = c_1e^{2t} + c_2e^{-3t}$。由初始条件得$c_1 + c_2 = 1$和$2c_1 - 3c_2 = 0$，所以$c_1 = \tfrac35$，$c_2 = \tfrac25$：

$$
y = \tfrac35\,e^{2t} + \tfrac25\,e^{-3t}.
$$

衰减的部分很快消失，解像$\tfrac35e^{2t}$那样增长。只有满足$y'(0) = -3y(0)$的初值才产生衰减的解。
:::
:::

::: example 重根 {#ex-repeated}
求解$y'' + 4y' + 4y = 0$，$y(0) = 1$，$y'(0) = 0$。
::: solution
$r^2 + 4r + 4 = (r+2)^2$有二重根$r = -2$，所以$y = (c_1 + c_2t)e^{-2t}$。于是由$y(0) = c_1 = 1$和$y'(0) = c_2 - 2c_1 = 0$得$c_2 = 2$：

$$
y = (1 + 2t)\,e^{-2t}.
$$

因子$1 + 2t$在增长，但指数函数占了上风，$y\to 0$，并且当$t > 0$时从不穿过零。
:::
:::

::: example 复根 {#ex-complex}
求解$y'' + 2y' + 5y = 0$，$y(0) = 1$，$y'(0) = 1$，并把答案写成单个衰减正弦波的形式。
::: solution
由$r^2 + 2r + 5 = 0$得$r = -1 \pm 2i$，所以$y = e^{-t}(c_1\cos 2t + c_2\sin 2t)$。由$y(0) = c_1 = 1$和$y'(0) = -c_1 + 2c_2 = 1$得$c_2 = 1$：

$$
y = e^{-t}(\cos 2t + \sin 2t) = \sqrt2\,e^{-t}\sin\left(2t + \frac{\pi}{4}\right),
$$

这里用到了$\sin(A + B) = \sin A\cos B + \cos A\sin B$以及$\cos\frac\pi4 = \sin\frac\pi4 = \frac{1}{\sqrt2}$。解在包络线$\pm\sqrt2\,e^{-t}$之内以角频率$2$振动。
:::
:::

::: remark 高阶方程
一切都可以推广到常系数方程$a_ny^{(n)} + \dots + a_1y' + a_0y = 0$：特征多项式的$m$重实根$r$贡献$e^{rt}, te^{rt}, \dots, t^{m-1}e^{rt}$，而每一对$m$重的根$\lambda\pm i\mu$贡献$t^ke^{\lambda t}\cos\mu t$和$t^ke^{\lambda t}\sin\mu t$（$k < m$）；解空间的维数为$n$。例如，$y''' - y = 0$的特征根为$1$和$-\tfrac12 \pm \tfrac{\sqrt3}{2}i$，所以它的通解为$c_1e^t + e^{-t/2}\bigl(c_2\cos\tfrac{\sqrt3}{2}t + c_3\sin\tfrac{\sqrt3}{2}t\bigr)$。最简洁的证明要用到[[ode/linear-systems]]一章中线性代数的观点。
:::

## 降阶法与柯西-欧拉方程

对于变系数方程，没有求解的一般方法。但如果已知一个解$y_1$——无论是观察出来的、由级数得到的，还是由物理得到的——那么总能求出第二个解。其思想（可以追溯到达朗贝尔（d'Alembert））是寻找形如$y_2 = v\,y_1$的解；代入后得到关于$v'$的一阶方程，**降阶法**因此得名。阿贝尔公式可以直接给出答案。

::: proposition 降阶法 {#prop-reduction}
设$y_1$是$y'' + p(t)y' + q(t)y = 0$的解，并且在$I$上$y_1(t)\neq 0$。则

$$
y_2(t) = y_1(t)\int\frac{e^{-\int p(t)\,dt}}{y_1(t)^2}\,dt
$$ {#eq-reduction}

是第二个解，并且$y_1, y_2$在$I$上构成基本解组。
:::

::: proof
设$y_2$是任意一个满足$W[y_1,y_2] \neq 0$的解（由[[#cor-wronskian]]，这样的解存在）。由商的求导法则和[[#thm-abel]]，

$$
\left(\frac{y_2}{y_1}\right)' = \frac{y_1y_2' - y_1'y_2}{y_1^2} = \frac{W}{y_1^2} = \frac{C\,e^{-\int p}}{y_1^2}
$$

其中$C\neq 0$是常数，所以$y_2/y_1$是$Ce^{-\int p}/y_1^2$的一个原函数。反过来，用[[#eq-reduction]]定义$y_2$，并令$v = y_2/y_1$，于是$v' = e^{-\int p}/y_1^2$。则$y_2' = v'y_1 + vy_1'$，$y_2'' = v''y_1 + 2v'y_1' + vy_1''$，并且

$$
L[y_2] = v\,L[y_1] + y_1v'' + (2y_1' + py_1)v' = 0 + \bigl(y_1^2v'\bigr)'/y_1 + p\,y_1v' = \frac{1}{y_1}\Bigl(\bigl(e^{-\int p}\bigr)' + p\,e^{-\int p}\Bigr) = 0 .
$$

最后，$W[y_1, y_2] = y_1^2v' = e^{-\int p} \neq 0$。
:::

::: example 勒让德方程的第二个解 {#ex-legendre-q}
函数$y_1 = t$在$(-1,1)$上是勒让德（Legendre）方程$(1 - t^2)y'' - 2ty' + 2y = 0$的解（验证：$0 - 2t + 2t = 0$）。求第二个解。
::: solution
化为标准形式，$p(t) = -\dfrac{2t}{1-t^2}$，所以$-\int p\,dt = \int\frac{2t}{1-t^2}\,dt = -\ln(1 - t^2)$，$e^{-\int p} = \dfrac{1}{1-t^2}$。在$y_1 \neq 0$的$(0,1)$上，由[[#eq-reduction]]和部分分式得

$$
y_2 = t\int\frac{dt}{t^2(1-t^2)} = t\int\left(\frac{1}{t^2} + \frac{1}{2(1+t)} + \frac{1}{2(1-t)}\right)dt = t\left(-\frac1t + \frac12\ln\frac{1+t}{1-t}\right) = \frac t2\ln\frac{1+t}{1-t} - 1 .
$$

这个公式在整个$(-1,1)$上（包括$t = 0$）都有意义，直接验证可知它在那里满足方程。由阿贝尔公式，$W[y_1,y_2] = C/(1-t^2)$，而确实有$W = ty_2' - y_2 = \frac{1}{1-t^2}$。第二个解在$t = \pm1$处以对数的方式爆破，这两点正是方程的奇点。它就是勒让德函数$Q_1$，我们将在[[ode/series-solutions]]一章中再次遇到它。
:::
:::

一类容易求出第一个解的方程是**柯西-欧拉方程**（或等维方程）

$$
a\,t^2y'' + b\,t\,y' + c\,y = 0 \qquad (t > 0),
$$

其中每一阶导数都乘以$t$的相应次幂。试探$y = t^r$，得$\bigl(ar(r-1) + br + c\bigr)t^r = 0$，所以当$r$满足**指标方程**$ar(r-1) + br + c = 0$时，$t^r$是解。代换$t = e^s$把方程化为常系数方程（因为$t\frac{d}{dt} = \frac{d}{ds}$），所以[[#thm-constant]]的三种情形可以直接转译过来：相异实根给出$t^{r_1}, t^{r_2}$；重根给出$t^r, t^r\ln t$；复根$\lambda\pm i\mu$给出$t^\lambda\cos(\mu\ln t)$和$t^\lambda\sin(\mu\ln t)$。

::: example 柯西-欧拉方程的降阶 {#ex-reduction}
在$t > 0$上求解$t^2y'' - 3ty' + 4y = 0$。
::: solution
指标方程$r(r-1) - 3r + 4 = r^2 - 4r + 4 = (r-2)^2 = 0$有二重根$r = 2$，只给出$y_1 = t^2$。化为标准形式，$p(t) = -3/t$，所以$e^{-\int p} = e^{3\ln t} = t^3$，由[[#eq-reduction]]得

$$
y_2 = t^2\int\frac{t^3}{t^4}\,dt = t^2\int\frac{dt}{t} = t^2\ln t .
$$

$(0,\infty)$上的通解为$y = c_1t^2 + c_2t^2\ln t$，并且$W[t^2, t^2\ln t] = t^3$，与阿贝尔公式一致（$W = Ce^{-\int p} = Ct^3$）。
:::
:::

## 自由机械振动

我们回到弹簧方程[[#eq-spring]]，$mx'' + cx' + kx = 0$，其中质量$m > 0$，刚度$k > 0$，阻尼系数$c \ge 0$。

**无阻尼。**若$c = 0$，则特征根为$\pm i\omega_0$，其中$\omega_0 = \sqrt{k/m}$称为**固有频率**，并且

$$
x(t) = A\cos\omega_0t + B\sin\omega_0t = R\cos(\omega_0t - \delta), \qquad R = \sqrt{A^2+B^2},\quad \cos\delta = \frac AR,\ \sin\delta = \frac BR .
$$

这是振幅为$R$、相位为$\delta$、周期为$2\pi/\omega_0$的**简谐运动**。周期与振幅无关——正是这一性质使摆钟成为可能（对于小幅摆动而言；见[[ode/nonlinear-systems]]一章）。

::: warning 正确地确定相位
人们很容易写成$\delta = \arctan(B/A)$，但$\arctan$只返回$(-\frac\pi2,\frac\pi2)$中的角。若$A < 0$，必须加上$\pi$。对于$x = -\cos t + \sin t$，正确的形式是$\sqrt2\cos\bigl(t - \frac{3\pi}{4}\bigr)$，而$\arctan(B/A) = -\frac\pi4$会给出$\sqrt2\cos(t + \frac\pi4) = \cos t - \sin t$，恰好是正确答案的相反数。一定要检查$\cos\delta = A/R$和$\sin\delta = B/R$的符号。
:::

**有阻尼。**特征根为$r = \dfrac{-c\pm\sqrt{c^2 - 4mk}}{2m}$，判别式的符号给出三种情形。

| 情形 | 条件 | 解 |
|---|---|---|
| 过阻尼 | $c^2 > 4mk$ | $c_1e^{r_1t} + c_2e^{r_2t}$，其中$r_2 < r_1 < 0$ |
| 临界阻尼 | $c^2 = 4mk$ | $(c_1 + c_2t)\,e^{-ct/(2m)}$ |
| 欠阻尼 | $c^2 < 4mk$ | $R\,e^{-ct/(2m)}\cos(\mu t - \delta)$，$\ \mu = \dfrac{\sqrt{4mk - c^2}}{2m}$ |

在每种$c > 0$的情形下，解都趋于$0$：当特征根为实数时，它们都是负的（它们的和为$-c/m < 0$，积为$k/m > 0$）；当特征根为复数时，它们的实部为$-c/(2m) < 0$。过阻尼或临界阻尼的系统至多穿过平衡位置一次；欠阻尼的系统则在一条衰减的指数包络线之内以**准频率**$\mu < \omega_0$振动。衰减的物理原因是阻尼耗散了能量。

::: proposition 能量耗散 {#prop-energy}
对于$mx'' + cx' + kx = 0$的解，总能量$E(t) = \tfrac12 m\,x'(t)^2 + \tfrac12 k\,x(t)^2$（动能加势能）满足

$$
E'(t) = -c\,x'(t)^2 \le 0 .
$$

所以当$c = 0$时能量守恒，当$c > 0$时能量不增。
:::

::: proof
由链式法则和方程，$E' = m\,x'x'' + k\,x\,x' = x'\,(mx'' + kx) = x'\,(-cx') = -c\,(x')^2$。
:::

::: example 欠阻尼弹簧 {#ex-underdamped}
一个弹簧系统的$m = 1$，$c = 2$，$k = 10$，它从$x = 1$处由静止开始运动。求它的运动、准周期以及振幅-相位形式。
::: solution
特征方程$r^2 + 2r + 10 = 0$给出$r = -1\pm3i$：这是欠阻尼的，因为$c^2 = 4 < 40 = 4mk$。所以$x = e^{-t}(c_1\cos3t + c_2\sin3t)$，其中$x(0) = c_1 = 1$，$x'(0) = -c_1 + 3c_2 = 0$，即$c_2 = \tfrac13$：

$$
x(t) = e^{-t}\left(\cos 3t + \tfrac13\sin 3t\right) = \frac{\sqrt{10}}{3}\,e^{-t}\cos(3t - \delta), \qquad \delta = \arctan\tfrac13 \approx 0.322,
$$

其中$\delta$在第一象限，因为两个系数都是正的。准频率为$\mu = 3$，所以相邻两个极大值相隔$2\pi/3 \approx 2.09$个时间单位，而无阻尼时的周期为$2\pi/\sqrt{10}\approx 1.99$。每经过一个准周期，振幅缩小为原来的$e^{-2\pi/3}\approx 0.12$倍。
:::
:::

相平面提供了另一种观点。记$v = x'$，方程就变成方程组$x' = v$，$v' = -\frac km x - \frac cm v$，每个解在$(x,v)$平面上描出一条曲线。无阻尼运动给出闭合的椭圆（能量的等值线）；欠阻尼运动螺旋式地趋向原点；过阻尼和临界阻尼运动趋向原点而不绕圈。

::: quiz
一个系统的$m = 2$，$c = 4$，$k = 2$。它被偏离平衡位置之后会如何运动？
- [ ] 它以缓慢减小的振幅振动。
- [x] 它是临界阻尼的：它不振动地回到平衡位置，至多穿过零一次。
- [ ] 它是过阻尼的，即使在极限意义下也永远回不到平衡位置。
- [ ] 它以不变的振幅永远振动下去。
::: solution
$c^2 = 16$与$4mk = 16$相等，所以系统是临界阻尼的：特征方程$2r^2 + 4r + 2 = 2(r+1)^2$有二重根$-1$，$x = (c_1 + c_2t)e^{-t}$。它趋于$0$，并且至多在一个$t$值处为零。
:::

::: application 悬架、电路与建筑
汽车悬架和防火门上的闭门器都被设计成接近临界阻尼的：它们以尽可能快的速度回到平衡位置而不越过它。在电感$L$、电阻$R$和电容$C$串联的电路中，电荷满足$Lq'' + Rq' + q/C = 0$——这恰好就是[[#eq-spring]]，其中电感扮演质量的角色，电阻扮演摩擦的角色，$1/C$扮演刚度的角色。工程师们在力学图景和电学图景之间自由切换。高层建筑使用调谐质量阻尼器——安装在楼顶附近、连接着弹簧和阻尼器的大质量块——来耗散由风和地震引起的摇晃的能量。
:::

::: history
欧拉（Euler）于1739年在与约翰·伯努利（Johann Bernoulli）的通信中发现了求解常系数线性方程的指数代换，并于1743年发表了这一方法，其中包括重根的情形以及给出正弦和余弦的复根情形。关于朗斯基行列式的阿贝尔公式出现在尼尔斯·亨里克·阿贝尔（Niels Henrik Abel）1827年的一篇论文中，约瑟夫·刘维尔（Joseph Liouville）在1838年把它推广到任意阶的方程。这个行列式本身是由波兰数学家约瑟夫·霍内-朗斯基（Józef Hoene-Wroński）于1812年引入的；“朗斯基行列式”（Wronskian）这个名称是托马斯·缪尔（Thomas Muir）在1882年起的。
:::

## 后续内容

当弹簧受到外力推动时，方程变成非齐次的，$mx'' + cx' + kx = F(t)$；由叠加原理，它的解等于一个特解加上本章求出的通解，而[[ode/nonhomogeneous]]一章将说明如何求出这个特解，并解释共振。[[ode/laplace-transform]]一章处理间断的和脉冲式的外力。像相平面图那样把方程改写为一阶方程组，就引出[[ode/linear-systems]]一章，在那里特征方程变成矩阵的特征多项式。对于有奇点的变系数方程，[[ode/series-solutions]]一章中的幂级数接过了任务，而解的振动性是[[pde/sturm-liouville]]一章的出发点。

::: summary
- 线性初值问题$y'' + py' + qy = g$，$y(t_0) = y_0$，$y'(t_0) = y_1$在$p, q, g$连续的整个区间上有唯一解（[[#thm-eu2]]）。
- 齐次方程的解构成一个向量空间（叠加原理），其维数恰好为二（[[#thm-superposition]]，[[#cor-wronskian]]）。
- 两个解的朗斯基行列式$W = y_1y_2' - y_1'y_2$满足阿贝尔公式$W(t) = W(t_0)e^{-\int p}$；它要么处处不为零（基本解组），要么恒为零（线性相关）。
- 对于$ay'' + by' + cy = 0$，由$ar^2 + br + c = 0$的根得到$e^{r_1t}, e^{r_2t}$，或$e^{rt}, te^{rt}$，或$e^{\lambda t}\cos\mu t, e^{\lambda t}\sin\mu t$（[[#thm-constant]]）。
- 已知一个处处不为零的解$y_1$，降阶法给出$y_2 = y_1\int e^{-\int p}/y_1^2$；柯西-欧拉方程用$t^r$求解。
- 有阻尼的弹簧按$c^2 - 4mk$为正、为零或为负，分别是过阻尼、临界阻尼或欠阻尼的；当$c > 0$时能量减少，一切运动最终都会消失。
:::

## 习题

::: exercise 相异实根 {level=1 check="12"}
求解$y'' - 5y' + 6y = 0$，$y(0) = 1$，$y'(0) = 4$，并求$y(\ln 2)$的值。
::: solution
$r^2 - 5r + 6 = (r-2)(r-3)$，所以$y = c_1e^{2t} + c_2e^{3t}$，其中$c_1 + c_2 = 1$，$2c_1 + 3c_2 = 4$。因此$c_2 = 2$，$c_1 = -1$，$y = -e^{2t} + 2e^{3t}$。在$t = \ln 2$处：$y = -4 + 2\cdot 8 = 12$。
:::
:::

::: exercise 朗斯基行列式 {level=1 check="3"}
计算$W[\cos 3t, \sin 3t]$。这两个函数是哪个方程的解？所得答案与阿贝尔公式一致吗？
::: solution
$W = \cos3t\cdot3\cos3t - (-3\sin3t)\sin3t = 3(\cos^2 3t + \sin^2 3t) = 3$。两个函数都是$y'' + 9y = 0$的解，这时$p = 0$，所以阿贝尔公式预言朗斯基行列式是常数——与所求得的结果一致。
:::
:::

::: exercise 振幅 {level=1 check="sqrt(5)"}
求解$y'' + 9y = 0$，$y(0) = 2$，$y'(0) = -3$，并求振动的振幅。
::: solution
$y = A\cos 3t + B\sin 3t$，其中$A = 2$，$3B = -3$，所以$y = 2\cos3t - \sin3t$。振幅为$R = \sqrt{2^2 + (-1)^2} = \sqrt5$。（写成相位形式，$y = \sqrt5\cos(3t - \delta)$，其中$\cos\delta = 2/\sqrt5 > 0$，$\sin\delta = -1/\sqrt5 < 0$，所以$\delta = -\arctan\frac12$。）
:::
:::

::: exercise 柯西-欧拉方程 {level=1 check="5/3"}
在$t > 0$上求解$t^2y'' - 2y = 0$，$y(1) = 1$，$y'(1) = 0$，并求$y(2)$的值。
::: solution
指标方程$r(r-1) - 2 = r^2 - r - 2 = (r-2)(r+1) = 0$给出$y = c_1t^2 + c_2t^{-1}$。于是$c_1 + c_2 = 1$，$2c_1 - c_2 = 0$，所以$c_1 = \frac13$，$c_2 = \frac23$，$y = \frac{t^2}{3} + \frac{2}{3t}$。因此$y(2) = \frac43 + \frac13 = \frac53$。
:::
:::

::: exercise 不解方程而用阿贝尔公式 {level=2 check="1/2"}
设$y_1, y_2$是$t\,y'' + 2y' + te^{t}y = 0$在$t > 0$上的解，并且$W[y_1,y_2](1) = 2$。求$W[y_1,y_2](2)$。
::: solution
化为标准形式，$p(t) = 2/t$，所以由[[#thm-abel]]，$W(t) = W(1)\exp\bigl(-\int_1^t \frac2s\,ds\bigr) = 2t^{-2}$。因此$W(2) = \frac12$。我们根本不需要解本身——这很幸运，因为它们不是初等函数。
:::
:::

::: exercise 降阶法 {level=2}
验证$y_1 = e^t$是$t\,y'' - (t+1)\,y' + y = 0$在$t > 0$上的解，并求第二个与之线性无关的解。
::: solution
$L[e^t] = te^t - (t+1)e^t + e^t = 0$。化为标准形式，$p = -\frac{t+1}{t} = -1 - \frac1t$，所以$e^{-\int p} = e^{t + \ln t} = te^t$。由[[#eq-reduction]]，

$$
y_2 = e^t\int\frac{te^t}{e^{2t}}\,dt = e^t\int te^{-t}\,dt = e^t\bigl(-(t+1)e^{-t}\bigr) = -(t + 1).
$$

所以$y_2 = t + 1$（去掉负号）是第二个解；验证：$t\cdot 0 - (t+1)\cdot1 + (t+1) = 0$。通解为$c_1e^t + c_2(t+1)$。
:::
:::

::: exercise 临界阻尼 {level=2 check="6"}
一个质量为$1$ kg的物体挂在刚度为$9$ N/m的弹簧上。阻尼系数$c$为多少时，系统是临界阻尼的？对于这个$c$，求解初值问题$x(0) = 1$，$x'(0) = 0$，并求$t \ge 0$时$\lvert x\rvert$的最大值。
::: solution
临界阻尼要求$c^2 = 4mk = 36$，所以$c = 6$。于是$r^2 + 6r + 9 = (r+3)^2$，$x = (c_1 + c_2t)e^{-3t}$，其中$c_1 = 1$，$c_2 - 3c_1 = 0$：$x = (1 + 3t)e^{-3t}$。当$t > 0$时，$x' = -9te^{-3t} < 0$，所以$x$从$1$递减趋于$0$而不穿过零，$\max\lvert x\rvert = 1$，在$t = 0$处取到。
:::
:::

::: exercise 公共零点 {level=3}
设$y_1, y_2$是$y'' + p(t)y' + q(t)y = 0$在$I$上的解（$p, q$连续），它们在同一点$t_0\in I$处为零。证明它们线性相关。由此推出：$\sin t$和$\sin 2t$不可能在任何包含$0$的区间上同时是这样一个方程的解。
::: solution
$W(t_0) = y_1(t_0)y_2'(t_0) - y_1'(t_0)y_2(t_0) = 0 - 0 = 0$，所以由[[#cor-wronskian]]，它们线性相关。由于$\sin t$和$\sin 2t$都在$0$处为零，但在$0$附近的任何区间上都不成比例（它们的比$2\cos t$不是常数），所以它们不可能是同一个系数在包含$0$的区间上连续的这类方程的解。
:::
:::

::: exercise 施图姆（Sturm）分离定理 {level=3}
设$y_1, y_2$是$y'' + p(t)y' + q(t)y = 0$在$I$上的线性无关的解，$a < b$是$y_1$在$I$中的相邻零点。证明$y_2$在$(a,b)$中恰有一个零点。（线性无关的解的零点是**交错**分布的，就像$\sin t$和$\cos t$的零点那样。）
::: hint
$W$的符号不变。计算它在$a$和$b$处的值，并比较$y_1'(a)$与$y_1'(b)$的符号。
:::
::: solution
由[[#cor-wronskian]]，$W = y_1y_2' - y_1'y_2$在$I$上处处不为零，所以它的符号不变。在$y_1$的零点处，$W = -y_1'y_2$；因此$y_1'(a)$、$y_1'(b)$、$y_2(a)$、$y_2(b)$都不为零。由于$y_1$在$(a,b)$中没有零点，它在那里的符号不变，不妨设为正；于是$y_1'(a) > 0$，$y_1'(b) < 0$（它们不为零，并且$y_1$在$a$处从$0$上升、在$b$处下降到$0$）。由于$W(a) = -y_1'(a)y_2(a)$与$W(b) = -y_1'(b)y_2(b)$同号，$y_2(a)$与$y_2(b)$异号，所以由介值定理，$y_2$在$(a,b)$中有一个零点。

如果$y_2$在$(a,b)$中有两个零点，那么交换$y_1, y_2$的角色、作同样的论证，就会在这两个零点之间严格地得到$y_1$的一个零点，这与$a, b$是$y_1$的相邻零点相矛盾。所以$y_2$在$(a,b)$中恰有一个零点。
:::

::: exercise 朗斯基行列式为零却线性无关 {level=3}
设$y_1(t) = t^3$，$y_2(t) = \lvert t\rvert^3$。证明两者都在$\R$上二阶连续可导，$W[y_1,y_2]\equiv 0$，但$y_1, y_2$在$\R$上线性无关。解释为什么这与[[#cor-wronskian]]并不矛盾。
::: solution
当$t \ge 0$时$y_2 = t^3$，当$t \le 0$时$y_2 = -t^3$；所以$y_2' = 3t\lvert t\rvert$，$y_2'' = 6\lvert t\rvert$，它们都是连续的。在$t \ge 0$上两个函数相同，所以$W = 0$；在$t \le 0$上$y_2 = -y_1$，所以同样有$W = 0$。因此$W \equiv 0$。但如果在$\R$上$c_1t^3 + c_2\lvert t\rvert^3 \equiv 0$，那么取$t = 1$得$c_1 + c_2 = 0$，取$t = -1$得$-c_1 + c_2 = 0$，所以$c_1 = c_2 = 0$：它们在$\R$上线性无关。

这并不矛盾，因为[[#cor-wronskian]]讲的是$p, q$在$\R$上连续的方程$y'' + py' + qy = 0$的**解**。事实上，$y_1$和$y_2$不可能同时是这样一个方程的解：否则它们都满足$y(0) = y'(0) = 0$，于是由唯一性，两者都恒为零。（它们确实都是$t^2y'' - 4ty' + 6y = 0$的解，但这个方程的标准形式在$t = 0$处是奇异的。）
