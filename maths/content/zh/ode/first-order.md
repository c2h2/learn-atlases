一杯咖啡倒出时是$90\,^\circ\mathrm{C}$，放在$20\,^\circ\mathrm{C}$的房间里。五分钟后，它冷却到了$70\,^\circ\mathrm{C}$。你喜欢在$50\,^\circ\mathrm{C}$时喝它：你还要等多久？仅凭两个时刻的温度计读数，本身无法回答这个问题。能回答它的是一条**关于变化率的规律**：咖啡散失热量的速率与它比室温高出多少成正比。记$T(t)$为$t$分钟后的温度，这条规律就是

$$
\frac{dT}{dt} = -k\,(T - 20)
$$

其中$k > 0$是某个常数。这是一个**微分方程**：它是关于未知**函数**$T$的方程，并且含有$T$的导数。它的解告诉我们这杯咖啡的全部未来，我们将在[[#ex-coffee]]中回答上面的问题。

你已经在[[calculus-2/intro-odes]]一章中见过斜率场、可分离变量方程和逻辑斯谛模型。本章为这些概念奠定坚实的基础，并加以推广。我们先精确地定义什么是解、什么是初值问题，然后讲述一阶方程的四种经典方法：分离变量法、线性方程的积分因子法、恰当方程，以及把新方程化为已知方程的变量代换。在此过程中，我们会遇到一个将在下一章占据中心位置的现象：看上去完全无害的方程，其解可能在有限时间之后就不复存在。

## 微分方程及其解

::: definition 常微分方程 {#def-ode}
关于单变量$t$的未知函数$y$的**常微分方程**（ODE）是一个方程

$$
F\bigl(t, y, y', \dots, y^{(n)}\bigr) = 0
$$

它把$t$、$y(t)$以及$y$的有限多个导数联系起来。方程中出现的最高阶导数的阶数$n$称为方程的**阶**。开区间$I$上的**解**是这样一个函数$\varphi\colon I \to \R$：它在$I$上$n$次可导，并且对每个$t \in I$都满足$F\bigl(t, \varphi(t), \varphi'(t), \dots, \varphi^{(n)}(t)\bigr) = 0$。
:::

“常”（ordinary）这个字把这类方程与**偏**微分方程区分开来：在偏微分方程中，未知函数依赖于多个变量，方程中出现的是偏导数（见[[pde]]课程）。本章研究一阶方程，并且几乎总是把它写成**正规形式**

$$
y' = f(t, y),
$$ {#eq-normal}

即导数用$t$和$y$表示出来。从几何上看，[[#eq-normal]]在平面的每一点处规定了一个斜率$f(t,y)$，而解就是在其每一点处都具有规定斜率的曲线。

如果$n$阶方程具有$a_n(t)y^{(n)} + \dots + a_1(t)y' + a_0(t)y = g(t)$的形式，就称它是**线性**的：未知函数及其各阶导数都只以一次幂出现，并且乘以的是$t$的函数。所以$y'' + t^2 y = \sin t$是二阶线性方程，而$y' = y^2$和$y'' + \sin y = 0$是非线性的。

单独一个微分方程通常有无穷多个解——对每个常数$C$，$T = 20 + Ce^{-kt}$都满足咖啡的冷却规律。为了从中挑出一个解，我们规定某一时刻的状态。

::: definition 初值问题 {#def-ivp}
一阶方程的**初值问题**（IVP）由方程$y' = f(t,y)$以及**初始条件**$y(t_0) = y_0$组成。初值问题的解是指方程在某个包含$t_0$的开区间$I$上的解$\varphi$，并且$\varphi(t_0) = y_0$。
:::

含有一个任意常数、能给出（本质上）全部解的公式称为**通解**。解并不总是以$y = \varphi(t)$的形式显式给出：我们得到的常常是**隐式解**，即一个关系式$G(t, y) = C$，它只在局部把$y$确定为$t$的函数。公式和区间都很重要，第一个例子就说明了这一点。

::: example 只存在于半直线上的解 {#ex-blowup-intro}
证明$y = \dfrac{1}{1-t}$是初值问题$y' = y^2$，$y(0) = 1$的解，并求它作为解的最大区间。
::: solution
当$t \neq 1$时，$y' = \dfrac{d}{dt}(1-t)^{-1} = (1-t)^{-2} = y^2$，并且$y(0) = 1$。这个公式在$(-\infty, 1)$和$(1, \infty)$上都有定义，但解必须存在于一个**包含$t_0 = 0$的区间**上，所以该初值问题的解是$(-\infty, 1)$上的$y = 1/(1-t)$。当$t \to 1^-$时$y(t) \to \infty$：解在有限时间内**爆破**，尽管右端函数$f(t,y) = y^2$是一个多项式，处处有定义并且光滑。图像在$(1,\infty)$上的那一段也是该方程的解，但它是另一个初值问题的解。

更一般地，对每个常数$C$，$y = 1/(C - t)$都是$y' = y^2$的解；$y \equiv 0$也是解，但它对任何$C$都不具有这种形式。因此，“通解”可能会漏掉个别的解；我们将在[[#warn-lost]]中再讨论这一点。
:::
:::

::: quiz
下列哪个方程是线性的？
- [x] $y' + t^2 y = \sin t$
- [ ] $y' + y^2 = t$
- [ ] $y\,y' = 1$
- [ ] $y' = \sin y$
::: solution
只有第一个方程中的$y$和$y'$都以一次幂出现，并且系数只依赖于$t$。其他方程分别含有$y^2$、乘积$y\,y'$和$\sin y$，它们关于未知函数都是非线性的。
:::

## 可分离变量方程

如果一个方程的右端可以分解为$t$的函数与$y$的函数的乘积，就称它是**可分离变量**的：

$$
y' = f(t)\,g(y).
$$ {#eq-separable}

[[calculus-2/intro-odes]]一章中的非正式做法是写出$dy/g(y) = f(t)\,dt$，然后两边积分。下面的定理确切地说明了这种做法何时合理，以及为什么它得到的恰好是**那个**解。

::: theorem 分离变量法 {#thm-separable}
设$f$在开区间$I$上连续，$g$在开区间$J$上连续，$t_0 \in I$，$y_0 \in J$。

1. 若$g(y_0) = 0$，则常数函数$y \equiv y_0$是初值问题$y' = f(t)g(y)$，$y(t_0) = y_0$的解。
2. 若$g(y_0) \neq 0$，令
$$
G(y) = \int_{y_0}^{y}\frac{d\eta}{g(\eta)}, \qquad F(t) = \int_{t_0}^{t} f(s)\,ds .
$$
则在包含$t_0$的某个开区间上，该初值问题恰有一个满足$g(y(t)) \neq 0$的解，它由$G(y(t)) = F(t)$隐式地给出。
:::

::: proof
第1部分是显然的：常数函数的导数为$0 = f(t)g(y_0)$。

对于第2部分，设$J_0 \subseteq J$是包含$y_0$、并且$g$在其上没有零点的最大开区间。在$J_0$上，$g$的符号保持不变（由介值定理），所以$G' = 1/g$连续且符号不变，从而$G$是从$J_0$到某个包含$G(y_0) = 0$的开区间$G(J_0)$上的严格单调可导函数。它的反函数$G^{-1}$可导，并且$(G^{-1})'(u) = 1/G'(G^{-1}(u)) = g(G^{-1}(u))$。由于$F$连续且$F(t_0) = 0$，存在开区间$I_0 \ni t_0$，使得在其上$F(t) \in G(J_0)$。

**存在性。**对$t \in I_0$定义$y(t) = G^{-1}(F(t))$。则$y(t_0) = G^{-1}(0) = y_0$，并且由链式法则，

$$
y'(t) = g\bigl(G^{-1}(F(t))\bigr)\,F'(t) = g(y(t))\,f(t).
$$

**唯一性。**设$z$是在$t_0$附近某个区间上满足$g(z(t)) \neq 0$的任意一个解，从而$z(t) \in J_0$。则

$$
\frac{d}{dt}\,G(z(t)) = \frac{z'(t)}{g(z(t))} = f(t),
$$

所以$G(z(t)) - F(t)$是常数；它在$t = t_0$处等于$0$。因此$G(z(t)) = F(t)$，从而$z(t) = G^{-1}(F(t)) = y(t)$。
:::

在实际计算中，我们求带有任意常数的原函数，$\int dy/g(y) = \int f(t)\,dt + C$，再由初始条件确定$C$。这个定理告诉我们这种计算的含义：它就是把链式法则倒过来用。

::: example 逐渐冷却的咖啡 {#ex-coffee}
求解本章开头的冷却问题：$T' = -k(T - 20)$，$T(0) = 90$，$T(5) = 70$。咖啡何时降到$50\,^\circ\mathrm{C}$？
::: solution
这里$f(t) = -k$，$g(T) = T - 20$，它在$T_0 = 90$处不为零。分离变量，得

$$
\int\frac{dT}{T - 20} = -\int k\,dt \quad\Longrightarrow\quad \ln\lvert T - 20\rvert = -kt + c .
$$

取指数，得$\lvert T - 20\rvert = e^{c}e^{-kt}$，所以$T - 20 = Ae^{-kt}$，其中$A = \pm e^c$（而$A = 0$给出定理第1部分中的平衡解$T \equiv 20$）。由条件$T(0) = 90$得$A = 70$：

$$
T(t) = 20 + 70e^{-kt}.
$$

测量值$T(5) = 70$确定了$k$：$70e^{-5k} = 50$，所以$k = \tfrac15\ln\tfrac75 \approx 0.0673$（单位：每分钟）。最后，当$e^{-kt} = \tfrac37$时$T(t) = 50$，即

$$
t = \frac{\ln(7/3)}{k} = \frac{5\ln(7/3)}{\ln(7/5)} \approx 12.6 \text{ 分钟}.
$$

温差$T - 20$按指数衰减：每经过五分钟，它都按同一比例缩小为原来的$5/7$。
:::
:::

::: example 存在区间有限的解 {#ex-xy2}
求解$y' = x\,y^2$，$y(0) = 1$，并求解存在的区间。
::: solution
分离变量（因为$y_0 = 1 \neq 0$，这样做是合理的）：$\displaystyle\int y^{-2}\,dy = \int x\,dx$，所以$-\dfrac1y = \dfrac{x^2}{2} + c$。由$x = 0$时$y = 1$得$c = -1$，因此

$$
y = \frac{1}{1 - x^2/2} = \frac{2}{2 - x^2}.
$$

分母在$x = \pm\sqrt2$处为零，而解必须定义在一个包含$0$的区间上，所以解的存在区间是$(-\sqrt2, \sqrt2)$。在两个端点处都有$y \to +\infty$。方程本身丝毫没有暗示$\sqrt2$这个数；只有求解之后才能发现它。
:::
:::

::: example 隐式解 {#ex-implicit}
求解$y' = \dfrac{1 + 2x}{\cos y}$，$y(0) = 0$，并求解的存在区间。
::: solution
分离变量，$\int \cos y\,dy = \int (1 + 2x)\,dx$，所以$\sin y = x + x^2 + c$，由$y(0)=0$得$c = 0$。隐式解为$\sin y = x + x^2$。为了把它化为显式，我们在经过$y = 0$的那一支上求正弦函数的反函数，即取$y \in (-\pi/2, \pi/2)$，在那里$\cos y > 0$：

$$
y = \arcsin\bigl(x + x^2\bigr).
$$

这要求$-1 < x + x^2 < 1$。左边的不等式总是成立（$x + x^2$的最小值是$-\tfrac14$）；右边的不等式给出$x^2 + x - 1 < 0$，即

$$
\frac{-1-\sqrt5}{2} < x < \frac{-1+\sqrt5}{2}.
$$

在两个端点处$x + x^2 \to 1$，所以$y \to \pi/2$，此时$\cos y = 0$，斜率$y' = (1+2x)/\cos y$变为无穷大：解曲线变成竖直的，无法再作为函数的图像延拓下去。解的存在区间约为$(-1.618, 0.618)$——黄金分割比出人意料地出现了。
:::
:::

::: warning 除以零会丢掉解 {#warn-lost}
对$y' = 2x\,y^2$分离变量，得$-1/y = x^2 + C$，即$y = -1/(x^2 + C)$。但$y \equiv 0$也是解，而它对任何$C$都不具有这种形式：它是在我们除以$y^2$时丢掉的。每当除以$g(y)$时，都要单独检查$g$的零点——每个零点$y^*$都给出一个**平衡解**$y \equiv y^*$。[[#thm-separable]]的第1部分正是为此而设的。
:::

## 线性方程与积分因子

::: definition 一阶线性方程 {#def-linear}
**标准形式**的**一阶线性方程**为

$$
y' + p(t)\,y = q(t),
$$ {#eq-linear}

其中$p$和$q$是$t$的函数。若$q \equiv 0$，则称它是**齐次**的。
:::

线性方程只有在特殊情形下才是可分离变量的，所以我们需要一个新的想法。左边的$y' + p y$看起来几乎就是某个乘积的导数。如果把它乘以一个正函数$\mu(t)$，并选取$\mu$使得$\mu' = p\,\mu$，那么由乘积法则，

$$
\mu\,(y' + p\,y) = \mu y' + \mu' y = (\mu y)'.
$$

条件$\mu' = p\mu$本身是一个可分离变量方程，它的解为$\mu(t) = \exp\bigl(\int p(t)\,dt\bigr)$。这样的$\mu$称为**积分因子**：乘以它之后，方程变为$(\mu y)' = \mu q$，可以直接积分。

::: theorem 线性方程的解 {#thm-linear}
设$p$和$q$在开区间$I$上连续，$t_0 \in I$，$y_0 \in \R$。则初值问题$y' + p(t)y = q(t)$，$y(t_0) = y_0$在**整个**区间$I$上恰有一个解，即

$$
y(t) = \frac{1}{\mu(t)}\left( y_0 + \int_{t_0}^{t}\mu(s)\,q(s)\,ds \right), \qquad \mu(t) = \exp\left(\int_{t_0}^{t} p(s)\,ds\right).
$$ {#eq-linear-solution}
:::

::: proof
函数$\mu$在$I$上可导，并且$\mu' = p\mu$（由微积分基本定理和链式法则），$\mu(t_0) = 1$，$\mu > 0$，所以[[#eq-linear-solution]]在整个$I$上定义了一个可导函数。

**存在性。**把[[#eq-linear-solution]]写成$\mu y = y_0 + \int_{t_0}^t \mu q$。由于$\mu q$连续，右边可导，并且导数为$\mu q$。因此

$$
\mu y' + \mu' y = \mu q \quad\Longrightarrow\quad \mu\,(y' + p y) = \mu q \quad\Longrightarrow\quad y' + py = q,
$$

其中最后一步除以了$\mu > 0$。此外，$y(t_0) = y_0/\mu(t_0) = y_0$。

**唯一性。**设$z$是该初值问题在某个包含$t_0$的区间$I' \subseteq I$上的任意一个解。则在$I'$上$(\mu z)' = \mu z' + p\mu z = \mu q$，所以由微积分基本定理，$\mu(t)z(t) - \mu(t_0)z(t_0) = \int_{t_0}^t \mu q$，这恰好就是[[#eq-linear-solution]]。所以在两者都有定义的地方，$z$与$y$重合。
:::

这个定理有两个特点值得强调，因为正是它们把线性方程与非线性方程区分开来。

- **整体存在性。**解在系数连续的整个区间上存在。与上面$y' = y^2$和$y' = xy^2$的解不同，它不可能在$I$的中间爆破。
- **结构。**公式[[#eq-linear-solution]]可以分解为$y = y_p + C\,y_h$，其中$y_h = 1/\mu$是齐次方程$y' + py = 0$的解，$y_p$是完整方程的一个特解。[[#eq-linear]]的两个解之差是齐次方程的解。这种“特解加齐次解”的结构是所有线性方程的组织原则，它将在[[ode/second-order-linear]]和[[ode/nonhomogeneous]]两章中再次出现。

::: warning 先把方程化为标准形式
积分因子是由$y$的系数$p$构造的，而这个系数要**在除以$y'$的系数之后**才能读出。对于$t\,y' + 2y = 4t^2$，标准形式为$y' + \frac{2}{t}y = 4t$，所以$p = 2/t$，$\mu = t^2$——而不是$e^{2t}$。做了除法也就揭示出定理在哪里适用：这里$p$在$t = 0$处不连续，所以只能保证解在$(0,\infty)$或$(-\infty, 0)$上存在。
:::

::: example 系数有奇点的方程 {#ex-tlinear}
求解$t\,y' + 2y = 4t^2$，$y(1) = 2$。
::: solution
化为标准形式：$y' + \dfrac{2}{t}y = 4t$，其中$p(t) = 2/t$，$q(t) = 4t$，它们都在$(0, \infty)$上连续，而这个区间包含$t_0 = 1$。一个积分因子是$\mu = \exp\int \frac2t\,dt = t^2$（对$t > 0$）。乘以它，得

$$
t^2 y' + 2t\,y = 4t^3 \quad\Longrightarrow\quad (t^2 y)' = 4t^3 \quad\Longrightarrow\quad t^2 y = t^4 + C .
$$

所以$y = t^2 + C/t^2$，由$y(1) = 2$得$C = 1$：

$$
y = t^2 + \frac{1}{t^2}, \qquad t > 0.
$$

由[[#thm-linear]]，这是$(0,\infty)$上的唯一解。它不能越过$t = 0$延拓，因为它在那里爆破。在所有的解$t^2 + C/t^2$中，只有$C = 0$的那个解在$t = 0$处有定义——这与唯一性是相容的，因为在$t = 0$处方程本身就迫使$2y(0) = 0$。
:::

只要一个量的变化率线性地依赖于现有的量，就会出现线性方程。最常见的来源是**房室模型**：一个水箱、一个器官、一个湖泊或一个银行账户，满足

$$
\text{总量的变化率} = \text{流入速率} - \text{流出速率}.
$$

::: example 边注水边混合的水箱 {#ex-tank}
一个水箱最初装有$100$升水，其中溶有$10$ kg盐。每升含盐$0.5$ kg的盐水以每分钟$3$升的速率流入，充分搅拌后的混合液以每分钟$2$升的速率流出。当水箱中有$200$升液体时，箱内有多少盐？那时的浓度是多少？
::: solution
体积以每分钟$3 - 2 = 1$升的速率增加，所以$V(t) = 100 + t$，在$t = 100$时水箱中有$200$升液体。设$Q(t)$为盐的量（单位：kg）。盐以$0.5 \times 3 = 1.5$ kg/min的速率流入。流出的液体以每分钟$2$升的速率带走浓度为当前浓度$Q/V$的盐。因此

$$
Q' = 1.5 - \frac{2Q}{100 + t}, \qquad Q(0) = 10.
$$

化为标准形式$Q' + \frac{2}{100+t}Q = 1.5$，积分因子为$\mu = \exp\int\frac{2\,dt}{100+t} = (100+t)^2$。于是

$$
\bigl((100+t)^2 Q\bigr)' = 1.5\,(100+t)^2 \quad\Longrightarrow\quad (100+t)^2 Q = 0.5\,(100+t)^3 + C .
$$

在$t = 0$时：$10^4 \cdot 10 = 0.5\cdot 10^6 + C$，所以$C = -4\times 10^5$，从而

$$
Q(t) = 0.5\,(100 + t) - \frac{4\times 10^5}{(100+t)^2}.
$$

在$t = 100$时，$Q = 100 - \dfrac{4\times10^5}{4\times 10^4} = 90$ kg，浓度为$90/200 = 0.45$ kg/L。作为合理性检验，浓度$Q/V = 0.5 - 4\times10^5/(100+t)^3$递增并趋于流入液的浓度$0.5$ kg/L，这正是应有的结果。
:::
:::

::: application 电路、药物与贷款
同一个线性方程以许多不同的名目出现。在由电压$E(t)$驱动、含有电阻$R$和电容$C$的电路中，电荷满足$Rq' + q/C = E(t)$，乘积$RC$是该电路的**时间常数**。以速率$r(t)$输注入血液、并以与现存量成正比的速率被清除的药物，满足$A' = r(t) - kA$。金额为$L$、按连续复利利率$\rho$计息、以恒定速率$P$偿还的贷款，满足$L' = \rho L - P$。在每种情形下，[[#thm-linear]]都给出完整的答案，而长期行为可以从积分因子中读出。
:::

## 恰当方程

许多一阶方程写成对称的**微分形式**

$$
M(x,y)\,dx + N(x,y)\,dy = 0, \qquad\text{即}\qquad M(x,y) + N(x,y)\,\frac{dy}{dx} = 0.
$$ {#eq-differential-form}

假设方程的解恰好是某个函数$F$的等值线$F(x,y) = C$。用链式法则对$F(x, y(x)) = C$求导，得$F_x + F_y\,y' = 0$。所以，如果能找到满足$F_x = M$和$F_y = N$的$F$，那么方程恰好是说$F$沿解保持不变。

::: definition 恰当方程 {#def-exact}
称方程[[#eq-differential-form]]在开集$R \subseteq \R^2$上是**恰当**的，如果在$R$上存在一个连续可微函数$F$（称为**势函数**），使得

$$
\frac{\partial F}{\partial x} = M, \qquad \frac{\partial F}{\partial y} = N \qquad\text{于 } R.
$$

这时，每个解都满足$F(x, y(x)) = C$，其中$C$是某个常数；反过来，满足$F(x,y(x)) = C$且$N(x,y(x)) \ne 0$的可导函数$y$是方程的解。
:::

用[[multivariable/line-integrals]]一章的语言来说，当向量场$(M, N)$是保守场时方程是恰当的，而$F$就是它的势函数。和那里一样，在矩形上有一个简单的判别法可以判定这个问题。

::: theorem 恰当性判别法 {#thm-exact}
设$M$、$N$以及偏导数$M_y$、$N_x$在开矩形$R = (a,b)\times(c,d)$上连续。则[[#eq-differential-form]]在$R$上是恰当的，当且仅当

$$
\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x} \qquad\text{于 } R.
$$ {#eq-exact-test}
:::

::: proof
($\Rightarrow$) 若$F_x = M$且$F_y = N$，则$F_{xy} = M_y$和$F_{yx} = N_x$都连续，于是由混合偏导数的对称性（克莱罗（Clairaut）定理，见[[multivariable/partial-derivatives]]一章），它们相等。

($\Leftarrow$) 固定$(x_0, y_0) \in R$，对$(x, y) \in R$定义

$$
F(x, y) = \int_{x_0}^{x} M(s, y_0)\,ds + \int_{y_0}^{y} N(x, s)\,ds .
$$

由于$R$是矩形，两条积分线段上的每一点都在$R$中。第一个积分与$y$无关，所以由微积分基本定理，$F_y(x,y) = N(x, y)$。为了求$F_x$，我们在积分号下对第二个积分求导——由于$N_x$在闭线段上连续，这是允许的（莱布尼茨（Leibniz）法则）——然后利用[[#eq-exact-test]]：

$$
F_x(x,y) = M(x, y_0) + \int_{y_0}^{y} N_x(x, s)\,ds = M(x, y_0) + \int_{y_0}^{y} M_y(x, s)\,ds = M(x,y_0) + \bigl(M(x,y) - M(x,y_0)\bigr) = M(x,y).
$$

所以$F$是势函数，方程是恰当的。
:::

::: remark 区域的形状很重要
在有洞的区域上，[[#eq-exact-test]]是必要的，但不是充分的。方程$-\dfrac{y}{x^2+y^2}\,dx + \dfrac{x}{x^2+y^2}\,dy = 0$在去心平面上满足$M_y = N_x$，它的势函数在局部就是极角$\theta$，但在整个去心平面上不存在单值的势函数。上面的证明利用矩形，使积分所沿的线段都留在$R$中。该定理在任何单连通区域上仍然成立，但这时证明必须沿其他路径（例如折线）积分，并利用格林公式说明结果与路径无关（比较[[multivariable/greens-theorem]]一章）。
:::

::: example 求解恰当方程 {#ex-exact}
求解$(2xy + 3x^2) + (x^2 + 2y)\,y' = 0$，$y(1) = 1$。
::: solution
这里$M = 2xy + 3x^2$，$N = x^2 + 2y$，并且处处有$M_y = 2x = N_x$，所以方程在$\R^2$上是恰当的。为了求$F$，把$y$看作常数，将$M$对$x$积分：

$$
F(x,y) = \int (2xy + 3x^2)\,dx = x^2 y + x^3 + h(y),
$$

其中积分“常数”$h$可以依赖于$y$。再令$F_y = N$：$x^2 + h'(y) = x^2 + 2y$，所以$h'(y) = 2y$，$h(y) = y^2$。于是$F = x^2y + x^3 + y^2$，方程的解满足$x^2y + x^3 + y^2 = C$。由初始条件得$C = 1 + 1 + 1 = 3$。

这是关于$y$的二次方程：$y^2 + x^2 y + (x^3 - 3) = 0$，所以

$$
y = \frac{-x^2 + \sqrt{x^4 - 4x^3 + 12}}{2},
$$

其中取$+$号是为了使$y(1) = (-1 + 3)/2 = 1$。只要判别式$x^4 - 4x^3 + 12$保持为正，解就存在，而这对$x < x^* \approx 1.746$成立。在$x^*$处两个根重合，$y = -x^2/2$，并且$N = x^2 + 2y = 0$：等值线$F = 3$在那里有竖直切线，解无法再延拓。
:::
:::

::: quiz
$(y\cos x + 2x e^y) + (\sin x + x^2 e^y - 1)\,y' = 0$是恰当方程吗？
- [x] 是
- [ ] 不是，因为$M$含有$\cos x$，而$N$含有$\sin x$
- [ ] 不是，因为$N$中的$-1$在$M$中没有对应项
- [ ] 不解方程就无法判定
::: solution
$M_y = \cos x + 2x e^y$，$N_x = \cos x + 2x e^y$，两者在整个$\R^2$上相等，所以由[[#thm-exact]]，方程是恰当的。一个势函数是$F = y\sin x + x^2 e^y - y$。
:::
:::

### 非恰当方程的积分因子

方程$y\,dx - x\,dy = 0$不是恰当的（$M_y = 1$，$N_x = -1$），但乘以$1/x^2$后得到$\frac{y}{x^2}dx - \frac{1}{x}dy = 0$，即$-d(y/x) = 0$，它是恰当的。一般地，如果$\mu M\,dx + \mu N\,dy = 0$是恰当的，就称非零函数$\mu(x,y)$为**积分因子**；在$\mu \neq 0$处，两个方程有相同的解。求$\mu$需要解偏微分方程$(\mu M)_y = (\mu N)_x$，这通常比原来的问题更难——但在两种常见的情形下，存在只依赖于一个变量的积分因子。

::: proposition 只依赖于一个变量的积分因子 {#prop-mu}
设$M, N, M_y, N_x$连续。

1. 若$\dfrac{M_y - N_x}{N} = h(x)$只依赖于$x$，则$\mu(x) = \exp\int h(x)\,dx$是积分因子。
2. 若$\dfrac{N_x - M_y}{M} = k(y)$只依赖于$y$，则$\mu(y) = \exp\int k(y)\,dy$是积分因子。
:::

::: proof
对$\mu = \mu(x)$，恰当性条件$(\mu M)_y = (\mu N)_x$成为$\mu M_y = \mu' N + \mu N_x$，即$\mu' = \mu\,\dfrac{M_y - N_x}{N} = \mu\,h(x)$。函数$\mu = \exp\int h$满足这一条件，所以由[[#thm-exact]]，$\mu M\,dx + \mu N\,dy = 0$是恰当的。第2部分是同样的计算，只需交换$x$与$y$的角色（见[[#exr-1-9]]）。
:::

::: example 求积分因子 {#ex-intfactor}
求解$(3xy + y^2) + (x^2 + xy)\,y' = 0$。
::: solution
$M_y = 3x + 2y$与$N_x = 2x + y$不相等，所以方程不是恰当的。但

$$
\frac{M_y - N_x}{N} = \frac{x + y}{x(x + y)} = \frac{1}{x}
$$

只依赖于$x$，所以$\mu = \exp\int \frac{dx}{x} = x$（对$x > 0$）是积分因子。新方程$(3x^2y + xy^2) + (x^3 + x^2y)\,y' = 0$是恰当的：两个混合偏导数都等于$3x^2 + 2xy$。将$3x^2y + xy^2$对$x$积分，得$F = x^3 y + \tfrac12 x^2y^2 + h(y)$，而由$F_y = x^3 + x^2 y$可知$h' = 0$。方程的解为

$$
x^3 y + \tfrac12 x^2 y^2 = C .
$$

乘以$\mu = x$可能会引入虚假的“解”$x = 0$；由于$x = 0$不是$x$的函数的图像，这里既没有丢失解，也没有增加解。
:::
:::

## 变量代换

变量代换可以把一个陌生的方程化为上述某种类型。两个经典的例子是伯努利（Bernoulli）方程和齐次方程。

::: proposition 伯努利方程 {#prop-bernoulli}
设实数$n \neq 0, 1$，$p, q$连续。在**伯努利方程**

$$
y' + p(t)\,y = q(t)\,y^n
$$

的解$y$为正（或者，当$y^{1-n}$对负的$y$有意义时，不为零）的任一区间上，函数$v = y^{1-n}$满足**线性**方程

$$
v' + (1-n)\,p(t)\,v = (1-n)\,q(t).
$$
:::

::: proof
由链式法则和方程本身，$v' = (1-n)\,y^{-n}\,y' = (1-n)\,y^{-n}\bigl(q\,y^n - p\,y\bigr) = (1-n)\bigl(q - p\,y^{1-n}\bigr) = (1-n)(q - p\,v)$。
:::

[[calculus-2/intro-odes]]一章中的逻辑斯谛方程$P' = rP(1 - P/K)$是$n = 2$的伯努利方程：代换$v = 1/P$把它化为线性方程$v' + rv = r/K$，其解$v = 1/K + Ce^{-rt}$又给出了我们熟悉的逻辑斯谛曲线。

::: example 解会爆破的伯努利方程 {#ex-bernoulli}
求解$y' + y = e^{t}y^2$，$y(0) = 1$。
::: solution
这里$n = 2$，所以令$v = y^{-1}$。由[[#prop-bernoulli]]，$v' - v = -e^{t}$。积分因子为$e^{-t}$：

$$
(e^{-t}v)' = -1 \quad\Longrightarrow\quad e^{-t}v = C - t \quad\Longrightarrow\quad y = \frac1v = \frac{e^{-t}}{C - t}.
$$

由初始条件得$C = 1$，所以$y = \dfrac{e^{-t}}{1-t}$，它在$(-\infty, 1)$上成立，并且当$t\to1^-$时$y \to \infty$。关于$v$的线性方程对所有$t$都有解，但$v = e^{t}(1-t)$在$t = 1$处经过零，而$y = 1/v$正是在那里爆破的。若改为$y(0) = \tfrac12$，则得$C = 2$，并在$t = 2$处爆破；若$y(0) = -1$，则得$y = -e^{-t}/(1+t)$，它对所有$t > -1$都存在，并且趋于$0$。此外，$y \equiv 0$也是解，它在作代换$v = 1/y$时丢掉了。
:::
:::

::: widget slopefield
f: exp(x)*y^2 - y
x: -1, 3
y: -2, 4
points: 0, 1; 0, 0.5; 0, -1
caption: $y' = e^{t}y^2 - y$的斜率场（横轴为$t$）。经过$(0, 1)$和$(0, \tfrac12)$的解分别在$t = 1$和$t = 2$附近冲向无穷大，而经过$(0,-1)$的解衰减到$0$。分别在$t$轴的下方和上方点击：正的解最终都会爆破，因为$e^t y^2$项占了上风。
:::

右端只依赖于比值$y/x$的方程$y' = F(y/x)$称为**齐次**方程（这与线性方程中“齐次”的含义不幸地发生了冲突）。代换$v = y/x$，即$y = xv$，给出$y' = v + xv'$，方程变为

$$
x\,v' = F(v) - v,
$$

这是可分离变量的。例如，$y' = \dfrac{x^2 + y^2}{xy} = \dfrac{1}{v} + v$变为$x v' = 1/v$，所以$v^2/2 = \ln\lvert x\rvert + C$，$y^2 = 2x^2\ln\lvert x\rvert + Cx^2$。

## 建模：检查清单

写出方程往往是实际问题中最难的部分。好的模型来自少数几条原则。

1. **确定状态和变化率规律。**确定用哪个量$y(t)$来描述系统，并根据平衡律（流入速率$-$流出速率）、物理定律（牛顿第二定律、牛顿冷却定律、基尔霍夫（Kirchhoff）定律）或经验假设（增长与规模成正比）写出它的变化率。
2. **检查单位。**方程中每一项的单位都必须是$y$的单位除以时间的单位。在[[#ex-tank]]中，$1.5$ kg/min和$2Q/(100+t)$（L/min乘以kg/L）都是盐的变化速率。
3. **求解，或作定性分析。**能用本章的方法时就用这些方法，不能用时就借助斜率场。
4. **解释并检验。**长期极限、平衡点和时间尺度都应该在物理上说得通，而像[[#ex-coffee]]中$k$这样的参数要用数据来拟合。

例如，质量为$m$的物体在重力作用下下落，所受空气阻力与速率成正比，则它满足$mv' = mg - bv$。这是线性的（也是可分离变量的）；满足$v(0) = 0$的解为

$$
v(t) = \frac{mg}{b}\left(1 - e^{-bt/m}\right),
$$

它趋近于**终端速度**$mg/b$，即阻力与重力相平衡时的速率。对于更大、更快的物体，阻力更接近于二次的，$mv' = mg - cv^2$，这仍是可分离变量方程，但答案中会出现$\tanh$。

::: history
最早的一般方法在微积分发明后的短短几年内就出现了。莱布尼茨（Leibniz）在1691年发现了分离变量法，不久之后约翰·伯努利（Johann Bernoulli）用*separatio indeterminatarum*这个名称来称呼它。1695年，雅各布·伯努利（Jacob Bernoulli）提出了现在以他的名字命名的方程；1696年，莱布尼茨证明了通过变量代换可以把它化为线性方程。牛顿（Newton）冷却定律于1701年匿名发表在《哲学汇刊》（*Philosophical Transactions*）上，那篇论文描述了一种温标。欧拉（Euler）在他的《积分学原理》（*Institutionum calculi integralis*，1768—1770年）中首次系统地阐述了这些方法，其中包括积分因子。
:::

## 后续内容

本章的每种方法都给出了一个公式，而在每种情形下，公式都引出了同样的问题：解在哪个区间上存在？它是唯一的解吗？[[ode/existence-uniqueness]]一章用皮卡（Picard）定理一般地回答了这些问题，并说明在没有公式可用时如何数值地近似求解。[[#thm-linear]]中“特解加齐次解”的结构将成为[[ode/second-order-linear]]和[[ode/nonhomogeneous]]两章的主题。平衡解及其稳定性（在这里以[[#ex-coffee]]中的室温出现）将发展为[[ode/nonlinear-systems]]一章中的相图。

::: summary
- 常微分方程把未知函数与它的导数联系起来；解必须在一个**区间**上满足方程，而初值问题再加上一个条件$y(t_0) = y_0$（[[#def-ode]]，[[#def-ivp]]）。
- 可分离变量方程$y' = f(t)g(y)$通过$\int dy/g(y) = \int f(t)\,dt$求解；$g$的零点给出平衡解，而这个公式会漏掉它们（[[#thm-separable]]）。
- 线性方程$y' + py = q$用积分因子$\mu = e^{\int p}$求解；解在$p$和$q$连续的整个区间上存在（[[#thm-linear]]）。
- $M + Ny' = 0$在矩形上是恰当的当且仅当$M_y = N_x$；这时方程的解就是势函数$F$的等值线（[[#thm-exact]]）。积分因子$\mu(x)$或$\mu(y)$可以使方程变为恰当方程（[[#prop-mu]]）。
- 变量代换把伯努利方程（$v = y^{1-n}$）化为线性方程，把齐次方程（$v = y/x$）化为可分离变量方程。
- 右端光滑的非线性方程可能有在有限时间内爆破的解；解的存在区间必须求出来，而不能想当然。
- 模型来自平衡律；要检查单位、平衡点和时间尺度。
:::

## 习题

::: exercise 可分离变量的初值问题 {level=1 check="2*e"}
求解$y' = 3t^2 y$，$y(0) = 2$，并给出$y(1)$。
::: solution
由于$y_0 \neq 0$，可以分离变量：$\int dy/y = \int 3t^2\,dt$，所以$\ln\lvert y\rvert = t^3 + c$，$y = Ae^{t^3}$。由初始条件得$A = 2$，所以$y = 2e^{t^3}$（对所有$t$有定义），$y(1) = 2e$。
:::
:::

::: exercise 积分因子 {level=1 check="3/2"}
求解$y' + 2y = 4$，$y(0) = 0$，并求$y(\ln 2)$。
::: solution
取$\mu = e^{2t}$：$(e^{2t}y)' = 4e^{2t}$，所以$e^{2t}y = 2e^{2t} + C$，$y = 2 + Ce^{-2t}$。由$y(0) = 0$得$C = -2$，所以$y = 2 - 2e^{-2t}$。在$t = \ln 2$处，$e^{-2t} = \tfrac14$，$y = 2 - \tfrac12 = \tfrac32$。
:::
:::

::: exercise 恰当方程 {level=1}
证明$(2x + y) + (x + 2y)\,y' = 0$是恰当方程，求满足$y(1) = 1$的解，并求显式解的存在区间。
::: solution
$M_y = 1 = N_x$，所以方程在$\R^2$上是恰当的。将$M$对$x$积分：$F = x^2 + xy + h(y)$，由$F_y = x + h'(y) = x + 2y$得$h = y^2$。所以$x^2 + xy + y^2 = C$，由$y(1) = 1$得$C = 3$。解关于$y$的二次方程$y^2 + xy + (x^2 - 3) = 0$，并选取满足$y(1) = 1$的根，得

$$
y = \frac{-x + \sqrt{12 - 3x^2}}{2}.
$$

这要求$12 - 3x^2 > 0$，即$-2 < x < 2$。在$x = \pm 2$处，解曲线（一个椭圆）有竖直切线，在那里$N = x + 2y = 0$。
:::
:::

::: exercise 终端速度 {level=1 check="5*ln(10)"}
一名跳伞者的$m/b = 5$ s，他从静止开始在线性阻力下下落，满足$mv' = mg - bv$。他需要多少秒才能达到终端速度的$90\%$？
::: solution
解为$v = \frac{mg}{b}\bigl(1 - e^{-bt/m}\bigr) = \frac{mg}{b}(1 - e^{-t/5})$。当$e^{-t/5} = 0.1$，即$t = 5\ln 10 \approx 11.5$ s时，它等于$0.9\,mg/b$。注意答案与$g$无关。
:::
:::

::: exercise 死亡时间 {level=2 check="ln(1.7)/ln(1.25)"}
中午时，在一间保持$20\,^\circ\mathrm{C}$的房间里发现了一具尸体，其温度为$30\,^\circ\mathrm{C}$。一小时后，温度为$28\,^\circ\mathrm{C}$。假设牛顿冷却定律成立，并且死亡时的体温为$37\,^\circ\mathrm{C}$，问死亡发生在中午之前多少小时？
::: solution
以小时为单位、从中午开始计时$t$。和[[#ex-coffee]]一样，$T = 20 + 10e^{-kt}$，由$T(1) = 28$得$e^{-k} = 0.8$，所以$k = \ln 1.25$。死亡发生在满足$T(t_d) = 37$的时刻$t_d < 0$：$10e^{-kt_d} = 17$，所以$-t_d = \ln(1.7)/k = \ln 1.7/\ln 1.25 \approx 2.38$小时。死亡发生在中午之前约2小时23分钟，即上午9:37左右。
:::

::: exercise 伯努利方程 {level=2 check="2"}
求解$t\,y' + y = t^2y^2$，$y(1) = 1$。解在$t > 1$的哪个时刻爆破？
::: hint
除以$t$，并作代换$v = 1/y$。
:::
::: solution
当$t > 0$时，方程为$y' + \frac1t y = t\,y^2$，这是$n = 2$的伯努利方程。令$v = 1/y$，由[[#prop-bernoulli]]得$v' - \frac1t v = -t$。积分因子为$1/t$：$(v/t)' = -1$，所以$v = Ct - t^2$，$y = \dfrac{1}{Ct - t^2}$。由$y(1) = 1$得$C = 2$：

$$
y = \frac{1}{t(2 - t)},
$$

它在$(0, 2)$上是该初值问题的解，并且当$t \to 2^-$时爆破（当$t \to 0^+$时也爆破）。
:::

::: exercise 水箱排水 {level=2 check="10"}
由托里拆利（Torricelli）定律，通过底部小孔排水的圆柱形水箱中的水深$h$（单位：m）满足$h' = -0.2\sqrt{h}$（$t$以分钟计）。若$h(0) = 1$，水箱何时排空？解释为什么仅凭“水箱在$t = 20$时是空的”这一信息，方程无法告诉你水箱是何时排空的。
::: solution
当$h > 0$时分离变量：$\int h^{-1/2}\,dh = -\int 0.2\,dt$，所以$2\sqrt h = -0.2t + c$，由$h(0) = 1$得$c = 2$。因此在$0 \le t \le 10$上，$\sqrt{h} = 1 - 0.1t$，$h = (1 - 0.1t)^2$；水箱在$t = 10$分钟时排空，此后$h \equiv 0$。

对于第二部分，对每个$T \le 20$，在$t \le T$时等于$\bigl(0.1(T - t)\bigr)^2$、在$t \ge T$时等于$0$的函数都是满足$h(20) = 0$的解：初值问题$h' = -0.2\sqrt h$，$h(20) = 0$有无穷多个解。出现这种情况是因为$\sqrt h$在$h = 0$处不可导（事实上也不满足利普希茨条件）；[[ode/existence-uniqueness]]一章解释了唯一性为什么恰好在这里失效。
:::

::: exercise 齐次方程 {level=2 check="15"}
对$x > 0$求解$y' = \dfrac{x^2 + 3y^2}{2xy}$，$y(1) = 1$，并计算$y(5)$。
::: solution
令$y = xv$：$v + xv' = \dfrac{1 + 3v^2}{2v}$，所以$xv' = \dfrac{1 + v^2}{2v}$。分离变量，$\displaystyle\int\frac{2v\,dv}{1+v^2} = \int\frac{dx}{x}$，即$\ln(1 + v^2) = \ln x + c$，$1 + v^2 = Ax$。在$x = 1$处$v = 1$，所以$A = 2$。于是$y^2 = x^2v^2 = 2x^3 - x^2$，取正根，得

$$
y = x\sqrt{2x - 1}, \qquad x > \tfrac12 .
$$

所以$y(5) = 5\sqrt9 = 15$。
:::

::: exercise 只依赖于 y 的积分因子 {level=3}
(a) 证明[[#prop-mu]]的第2部分：若$(N_x - M_y)/M = k(y)$只依赖于$y$，则$\mu(y) = \exp\int k(y)\,dy$是积分因子。
(b) 用它求解$y + (3x + y^3)\,y' = 0$。
::: solution
(a) 对$\mu = \mu(y)$，$\mu M + \mu N y' = 0$为恰当方程意味着$(\mu M)_y = (\mu N)_x$，即$\mu' M + \mu M_y = \mu N_x$，即$\mu' = \mu\,\dfrac{N_x - M_y}{M} = \mu\,k(y)$。函数$\mu = \exp\int k$满足这个常微分方程，所以乘以它之后，由[[#thm-exact]]，方程是恰当的。

(b) $M = y$，$N = 3x + y^3$：$\dfrac{N_x - M_y}{M} = \dfrac{3 - 1}{y} = \dfrac{2}{y}$，所以$\mu = y^2$。方程$y^3 + (3xy^2 + y^5)y' = 0$是恰当的（$\partial_y y^3 = 3y^2 = \partial_x(3xy^2 + y^5)$）。将$y^3$对$x$积分，得$F = xy^3 + h(y)$，由$F_y = 3xy^2 + h'(y) = 3xy^2 + y^5$得$h = y^6/6$。解满足

$$
xy^3 + \frac{y^6}{6} = C,
$$

另外还有解$y \equiv 0$（在那里$\mu = 0$；请直接验证它满足原方程）。
:::

::: exercise 逐渐消失的强迫项 {level=3}
设$a > 0$，$q$在$[0, \infty)$上连续，并且当$t \to\infty$时$q(t) \to 0$。证明$y' + a\,y = q(t)$的每个解都满足：当$t\to\infty$时$y(t) \to 0$。
::: hint
用[[#eq-linear-solution]]写出解，并在某个时刻$T$处把积分拆开，使得在$T$之后$\lvert q\rvert < \eps$。
:::
::: solution
由[[#thm-linear]]（取$t_0 = 0$），$\mu = e^{at}$，并且

$$
y(t) = e^{-at}y(0) + \int_0^t e^{-a(t-s)}q(s)\,ds .
$$

第一项趋于$0$。设$\eps > 0$，选取$T$，使得当$s \ge T$时$\lvert q(s)\rvert < a\eps/2$；令$B = \max_{[0,T]}\lvert q\rvert$。对$t > T$，

$$
\left\lvert \int_0^t e^{-a(t-s)}q(s)\,ds\right\rvert \le B\int_0^T e^{-a(t-s)}\,ds + \frac{a\eps}{2}\int_T^t e^{-a(t-s)}\,ds \le \frac{B}{a}\,e^{-a(t-T)} + \frac{a\eps}{2}\cdot\frac1a .
$$

对所有充分大的$t$，第一项都小于$\eps/2$，所以该积分的绝对值最终小于$\eps$。因此$y(t) \to 0$。（从物理上看：一个具有回复趋势的系统会忘记它的初始状态而跟随输入，所以逐渐消失的输入产生逐渐消失的响应。）
:::
