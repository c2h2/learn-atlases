$y = x^2$的图像可以一笔画出，笔尖不必离开纸面；下取整函数$\lfloor x\rfloor$的图像则不能，因为它在每个整数处都有跳跃。本章把这种“铅笔检验”变成数学。如果函数在某点附近的值都接近它在该点处的值，就说函数在该点处**连续**——这样，输入的小误差只会引起输出的小误差。

连续性之所以重要，既有实际的原因，也有理论的原因。从实际上说，每次测量都有误差，而只有对连续函数，近似的输入才能给出近似正确的输出：计算器用$\sin(1.4142)$代替$\sin(\sqrt2)$，依靠的正是这一点。从理论上说，区间上的连续函数有两个了不起的性质。它们不会跳过任何值（**介值定理**），这保证了方程有解；在有界闭区间上，它们能取到最大值和最小值（**最值定理**），这保证了最优化问题有答案。这两个定理在本课程的其余部分会经常用到。

## 一点处的连续性

在[[calculus-1/limits]]一章中，计算$\lim_{x\to a} f(x)$时我们小心地忽略了值$f(a)$。连续性要求的正是极限与函数值一致。

::: definition 一点处的连续性 {#def-continuous}
设$f$在某个包含$a$的开区间上有定义。如果下式成立，就称$f$**在**$a$**处连续**：

$$
\lim_{x\to a} f(x) = f(a).
$$ {#eq-continuity}

等价地说：对任意$\eps > 0$，存在$\delta > 0$，使得$\abs{x - a} < \delta \implies \abs{f(x) - f(a)} < \eps$。
:::

这个定义把三个要求压缩进一个等式：$f(a)$有定义，极限$\lim_{x\to a} f(x)$存在，并且两者相等。在ε–δ形式中，我们不再需要[[calculus-1/limits#def-limit]]中的限制$0 < \abs{x-a}$，因为在$x = a$处不等式$\abs{f(a) - f(a)} < \eps$自动成立。

这个定义还给出了一个实用的结论：**连续函数的极限可以通过代入来计算**。多项式和有理函数的直接代入法则（[[calculus-1/limits#cor-substitution]]）恰好是说，这些函数在其有定义的每一点处都连续。

在区间的端点处只有一侧可用，所以我们需要单侧的版本。

::: definition 单侧连续性与区间上的连续性 {#def-continuous-interval}
若$\lim_{x\to a^+} f(x) = f(a)$，则称$f$在$a$处**右连续**；若$\lim_{x\to a^-} f(x) = f(a)$，则称$f$在$a$处**左连续**。如果函数在区间$I$的每个内点处都连续，在左端点处（若它属于$I$）右连续，在右端点处（若它属于$I$）左连续，则称它**在区间**$I$**上连续**。**连续函数**是指在这一意义下在其定义域的每一点处都连续的函数。
:::

::: example 平方根函数是连续的 {#ex-sqrt}
证明$f(x) = \sqrt{x}$在$[0, \infty)$上连续。
::: solution
*在点$a > 0$处*。对$x\ge 0$，乘以共轭式得

$$
\abs{\sqrt{x} - \sqrt{a}} = \frac{\abs{x - a}}{\sqrt{x} + \sqrt{a}} \le \frac{\abs{x-a}}{\sqrt{a}}.
$$

设$\eps > 0$，取$\delta = \min(a, \eps\sqrt{a})$。若$\abs{x - a} < \delta$，则$x > a - \delta \ge 0$，所以$\sqrt{x}$有定义，并且$\abs{\sqrt x - \sqrt a} \le \abs{x-a}/\sqrt a < \delta/\sqrt a \le \eps$。

*在$0$处（右侧）*。设$\eps > 0$，取$\delta = \eps^2$。若$0 \le x < \delta$，则$\abs{\sqrt{x} - 0} = \sqrt{x} < \sqrt{\delta} = \eps$。

因此$\sqrt{x}$在每个$a > 0$处连续，在$0$处右连续，所以它在$[0, \infty)$上连续。
:::
:::

注意，在$a$处可行的$\delta$既依赖于$\eps$，也依赖于$a$：$a$越接近$0$，图像越陡，$\delta$就必须越小。能否用同一个$\delta$同时适用于所有的点，这是**一致连续性**的问题，将在[[real-analysis/continuity]]中研究。

::: quiz
当$x\neq0$时令$f(x) = \dfrac{\sin x}{x}$，并令$f(0) = c$。$c$取哪些值时$f$在$0$处连续？
- [ ] $c = 0$
- [x] $c = 1$
- [ ] 每个$c$都可以，因为$\sin x/x$在$0$处本来就没有定义
- [ ] 任何$c$都不行
::: solution
由[[calculus-1/limits#thm-sinx]]，$\lim_{x\to0}\frac{\sin x}{x} = 1$。在$0$处连续要求$f(0)$等于这个极限，所以恰好$c = 1$可行。对其他任何$c$，函数在$0$处有一个**可去**间断点。
:::
:::

## 间断点的类型

如果$f$在$a$周围的某个开区间上有定义（在$a$本身处可以没有定义），而$f$在$a$处不连续，我们就说$f$在$a$处**间断**，或者说$a$是$f$的一个**间断点**。间断点分为几种不同的类型，按单侧极限来分类。

::: definition 间断点的类型 {#def-discontinuities}
设$a$是$f$的间断点。这个间断点称为

1. **可去间断点**，如果$\lim_{x\to a}f(x)$（作为实数）存在：把$f(a)$重新定义为这个极限，就使$f$在$a$处连续；
2. **跳跃间断点**，如果两个单侧极限都存在但不相等；
3. **无穷间断点**，如果至少有一个单侧极限是$\infty$或$-\infty$；
4. **本性间断点**（或振荡间断点），如果属于其他所有情形，即两个单侧极限都不是无穷，并且至少有一个不存在。
:::

标准的例子：

- $f(x) = \dfrac{x^2-1}{x-1}$在$1$处有可去间断点（极限是$2$，而$f(1)$没有定义）；
- $\lfloor x\rfloor$和$\sgn x$分别在各整数处和$0$处有跳跃间断点；
- $1/x^2$在$0$处有无穷间断点；
- $\sin(1/x)$在$0$处有本性间断点（[[calculus-1/limits#exr-sin-reciprocal]]）。

::: widget plot
f: if(abs(x - 1) < 0.004, sqrt(-1), if(x < 1, x^2 + k, 3 - x))
sliders: k=-1:-2:3:0.1

caption: 这个函数在$x<1$时等于$x^2 + k$，在$x \ge 1$时等于$3 - x$；圆点标出了值$f(1) = 2$。在$1$处的左极限是$1 + k$，右极限是$2$，所以对大多数$k$都有一个跳跃间断点。找出能弥合缺口、使$f$在$1$处连续的那个唯一的$k$值。
:::

::: widget plot
f: sin(1/x); x*sin(1/x)
x: -0.5, 0.5
y: -1.2, 1.2

caption: 在$0$附近，$\sin(1/x)$在$-1$与$1$之间振荡无穷多次——振荡如此频繁，以致图像变成一片模糊——两个单侧极限都不存在。这个本性间断点无论在$0$处取什么值都无法修补。乘以$x$可以抑制振荡：$\lvert x\sin(1/x)\rvert \le \lvert x\rvert$，所以由夹逼定理$x\sin(1/x)\to0$，在$0$处给它赋值$0$就得到一个连续函数。
:::

::: remark 1/x是连续函数吗？
是的：它在其定义域$\R\setminus\set{0}$的每一点处都连续。它在$0$处还有一个无穷间断点，而$0$是其定义域**之外**的点。这并不矛盾，因为“连续函数”只涉及函数有定义的点，而间断点是$f$在其附近有定义的点的一种性质。$1/x$的图像分成两支，是因为它的定义域分成两部分，而不是因为函数在其有定义的某处断开了。
:::

## 连续函数的组合

每次都从ε–δ定义出发证明连续性会很繁琐。我们转而证明：用[[calculus-1/real-functions]]中构造函数的那些方式，连续性得以保持；再亲手验证少数几个基本函数。

::: theorem 连续函数的四则运算 {#thm-cont-algebra}
若$f$和$g$在$a$处连续，$c$为常数，则$f + g$、$f - g$、$cf$和$fg$都在$a$处连续；只要$g(a) \neq 0$，$f/g$也在$a$处连续。
:::

::: proof
由假设，当$x\to a$时$f(x) \to f(a)$，$g(x)\to g(a)$。由极限运算法则（[[calculus-1/limits#thm-laws]]）得$f(x) + g(x) \to f(a) + g(a)$、$f(x)g(x) \to f(a)g(a)$等等；当$g(a)\neq 0$时，还有$f(x)/g(x)\to f(a)/g(a)$。每一条都是说，组合而成的函数的极限等于它在$a$处的值。
:::

更深一层的事实是：连续性在复合运算下得以保持。我们证明一个关于极限的稍强一些的命题，它也为[[calculus-1/limits#ex-sin3x]]中在$\frac{\sin u}{u}$里作$u = 3x$这样的代换提供了依据。

::: theorem 复合函数的极限与连续性 {#thm-composition}
设$\lim_{x\to a} g(x) = b$。

1. 若$f$在$b$处连续，则$\displaystyle\lim_{x\to a} f\bigl(g(x)\bigr) = f(b)$。特别地，若$g$在$a$处连续，$f$在$g(a)$处连续，则$f\circ g$在$a$处连续。
2. 若改设$\lim_{y\to b} f(y) = L$，并且在$a$周围的某个开区间内对所有$x \neq a$都有$g(x) \neq b$，则$\displaystyle\lim_{x\to a} f\bigl(g(x)\bigr) = L$。
:::

::: proof
(1) 设$\eps > 0$。由于$f$在$b$处连续，存在$\eta > 0$，使得由$\abs{y - b} < \eta$可推出$\abs{f(y) - f(b)} < \eps$。由于$g(x) \to b$，以$\eta$代替$\eps$应用极限的定义，存在$\delta>0$，使得由$0<\abs{x-a}<\delta$可推出$\abs{g(x) - b} < \eta$。于是当$0 < \abs{x-a} < \delta$时，可以取$y = g(x)$，从而得到$\abs{f(g(x)) - f(b)} < \eps$。若$g$在$a$处连续，取$b = g(a)$：结论就是$f(g(x)) \to f(g(a))$，这正是$f\circ g$在$a$处的连续性。

(2) 设$\eps>0$。选取$\eta>0$，使得只要$0<\abs{y - b} < \eta$，就有$\abs{f(y) - L} < \eps$；再选取足够小的$\delta>0$，使得由$0<\abs{x-a}<\delta$既可推出$\abs{g(x) - b} < \eta$，又可推出$g(x)\neq b$。对这样的$x$，$y = g(x)$满足$0 < \abs{y-b} < \eta$，因此$\abs{f(g(x)) - L} < \eps$。
:::

::: warning 复合法则离不开它的假设
人们很容易想“把极限移到里面去”：$\lim f(g(x)) = f(\lim g(x))$。这恰好就是第1部分，它要求$f$在$b$处连续。不满足这一条件时的反例如下：当$y\neq0$时令$f(y) = 0$，并令$f(0) = 1$；对所有$x$令$g(x) = 0$。则$g(x)\to 0$，$\lim_{y\to0} f(y) = 0$，但对每个$x$都有$f(g(x)) = 1$，所以$\lim_{x\to0}f(g(x)) = 1$。第2部分不适用，因为对所有$x$都有$g(x) = 0 = b$。
:::

例如，取$g(x) = x^2$（当$x\neq0$时它不为零）和$f(y) = \frac{\sin y}{y}$，由第2部分得$\lim_{x\to0}\dfrac{\sin(x^2)}{x^2} = 1$。

### 基本的连续函数

由直接代入法则，多项式和有理函数在其定义域上连续。对三角函数，我们需要一个不等式：对所有实数$t$，$\abs{\sin t} \le \abs{t}$。当$0<\abs{t}<\pi/2$时，它可由[[calculus-1/limits#thm-sinx]]的证明中的面积比较得出；当$\abs{t}\ge\pi/2$时，它成立是因为$\abs{\sin t}\le 1 < \abs{t}$。

::: proposition 正弦和余弦是连续的 {#prop-trig-continuous}
对所有实数$x$和$a$，$\abs{\sin x - \sin a} \le \abs{x-a}$，$\abs{\cos x - \cos a} \le \abs{x-a}$。因此$\sin$和$\cos$在$\R$上连续，$\tan$、$\sec$、$\cot$、$\csc$在其定义域上连续。
:::

::: proof
令$u = \frac{x+a}{2}$，$v = \frac{x-a}{2}$，则$x = u + v$，$a = u - v$。由和差角公式（[[calculus-1/real-functions#thm-addition]]），

$$
\sin x - \sin a = \sin(u+v) - \sin(u-v) = 2\cos u\sin v, \qquad \cos x - \cos a = -2\sin u\sin v.
$$

由于$\abs{\cos u}\le1$，$\abs{\sin u} \le 1$，$\abs{\sin v}\le\abs{v}$，两个差的绝对值都不超过$2\abs{v} = \abs{x - a}$。因此，给定$\eps>0$，在每一点处取$\delta = \eps$都满足[[#def-continuous]]。其余四个函数是$\sin$、$\cos$和$1$的商，所以由[[#thm-cont-algebra]]，它们在分母不为零处连续。
:::

::: example 函数在哪里连续？ {#ex-where-continuous}
求$f(x) = \dfrac{\ln(4 - x^2)}{\sqrt{x} - 1}$在哪里连续，并计算$\lim_{x\to0^+} f(x)$。
::: solution
我们用连续的部件来搭建$f$（要用到$\ln$的连续性，它将在下面的[[#cor-elementary]]中证明）。多项式$4 - x^2$处处连续，$\ln$在$(0, \infty)$上连续，所以由[[#thm-composition]]，$\ln(4 - x^2)$在满足$4 - x^2 > 0$的地方，即在$(-2, 2)$上连续。由[[#ex-sqrt]]，函数$\sqrt{x} - 1$在$[0,\infty)$上连续，并且除$x = 1$外都不为零。由[[#thm-cont-algebra]]，商在下列集合的每一点处连续：

$$
[0, 1)\cup(1, 2),
$$

其中在$0$处是右连续。这个集合恰好是$f$的自然定义域，所以$f$是连续函数。特别地，极限可以通过代入求得：

$$
\lim_{x\to0^+} f(x) = f(0) = \frac{\ln 4}{0 - 1} = -\ln 4.
$$
:::
:::

## 介值定理

如果你从山脚走到山顶，那么在某个时刻你一定恰好位于半山腰的高度。连续函数也是如此：它们从一个值变到另一个值时，不可能不经过两者之间的每一个值。

::: theorem 介值定理 {#thm-ivt}
设$f$在闭区间$[a, b]$上连续，$N$是严格介于$f(a)$与$f(b)$之间的任意一个数。则存在数$c \in (a, b)$，使得$f(c) = N$。
:::

这个命题看上去显而易见，但它依赖于实数的一个深刻性质。在有理数范围内它是不成立的：$f(x) = x^2 - 2$在$[1, 2]$上连续，在$1$处为负，在$2$处为正，但不存在满足$c^2 = 2$的**有理数**$c$。实数具有而有理数缺乏的性质是**完备性**：每个有上界的非空实数集都有最小上界（上确界）。下面的证明概要显示了完备性在哪里起作用；完整的证明见[[real-analysis/continuity]]。

::: proof {collapsed}
*概要*。用$f - N$代替$f$，可以假设$N = 0$；必要时用$-f$代替$f$，可以假设$f(a) < 0 < f(b)$。令$[a_0, b_0] = [a, b]$。给定满足$f(a_n) < 0 \le f(b_n)$的区间$[a_n, b_n]$，设$m$是它的中点：若$f(m) < 0$，令$[a_{n+1}, b_{n+1}] = [m, b_n]$；否则令$[a_{n+1}, b_{n+1}] = [a_n, m]$。无论哪种情形都有$f(a_{n+1}) < 0 \le f(b_{n+1})$，并且区间长度满足$b_n - a_n = (b-a)/2^n$。

左端点$a_0 \le a_1 \le a_2 \le \cdots$递增，且以$b$为上界。由完备性，它们收敛于某个极限$c\in[a,b]$（即它们的最小上界）；又因为$b_n - a_n\to0$，右端点也收敛于$c$。由$f$在$c$处的连续性，$f(a_n) \to f(c)$，$f(b_n)\to f(c)$。由于每个$f(a_n)$都是负的，$f(c)\le 0$；由于每个$f(b_n)$都是非负的，$f(c)\ge0$。因此$f(c) = 0$；又因为$f(a)\neq0\neq f(b)$，所以$c\neq a, b$。（这里用到的关于数列极限的事实在[[calculus-2/sequences]]中证明。）
:::

最常见的用途是证明方程有解。

::: corollary 波尔查诺定理 {#cor-bolzano}
若$f$在$[a, b]$上连续，且$f(a)$与$f(b)$异号，则存在某个$c\in(a, b)$，使得$f(c) = 0$。
:::

上面的证明概要同时也是一个实用的算法。它不能精确地找出$c$，但能把$c$困在一个每步减半的区间里。

::: algorithm 二分法 {#alg-bisection}
输入：在$[a,b]$上连续且满足$f(a)f(b) < 0$的函数$f$，以及容许误差$\tau > 0$。

1. 令$m = \frac{a+b}{2}$。若$f(m) = 0$，停止：$m$是一个根。
2. 若$f(a)f(m) < 0$，用$m$代替$b$；否则用$m$代替$a$。新区间的两端仍然异号，所以由[[#cor-bolzano]]，它含有一个根。
3. 若$b - a < \tau$，停止并返回$m = \frac{a+b}{2}$；否则转到第1步。

经过$n$次减半后，含根区间的长度为$(b-a)/2^n$，所以它的中点与某个根的距离不超过$(b-a)/2^{n+1}$。
:::

::: example 解方程cos x = x {#ex-ivt-cos}
证明方程$\cos x = x$在$(0, \pi/2)$内有解，并把它定位到误差$0.1$以内。
::: solution
令$g(x) = \cos x - x$，由[[#prop-trig-continuous]]和[[#thm-cont-algebra]]，它在$\R$上连续。由于$g(0) = 1 > 0$，$g(\pi/2) = -\pi/2 < 0$，由[[#cor-bolzano]]，存在$c \in (0, \pi/2)$，使得$g(c) = 0$，即$\cos c = c$。

为了定位$c$，我们使用二分法，为方便起见从$[0, 1]$开始（因为$g(1) = \cos 1 - 1 \approx -0.460 < 0$）：

| 区间 | 中点$m$ | $g(m)$ |
|---|---|---|
| $[0, 1]$ | $0.5$ | $0.378 > 0$ |
| $[0.5, 1]$ | $0.75$ | $-0.018 < 0$ |
| $[0.5, 0.75]$ | $0.625$ | $0.186 > 0$ |
| $[0.625, 0.75]$ | $0.6875$ | $0.085 > 0$ |

所以$c \in [0.6875, 0.75]$，这个区间的长度为$0.0625 < 0.1$。（根是$c = 0.739085\ldots$；二分法每一步获得一位二进制数字的精度。）
:::
:::

x0: 0

x: -0.2, 1.8
caption: 对$[0, \pi/2]$上的$g(x) = \cos x - x$使用二分法。每一步都把含根区间减半，同时保持区间两端异号，所以根$c\approx 0.739085$被困在越来越小的区间里——这正是[[#thm-ivt]]的证明中的构造。逐步执行迭代，并把区间的宽度与$(\pi/2)/2^n$作比较。

::: example 奇数次多项式 {#ex-odd-degree}
证明每个奇数次多项式至少有一个实根。
::: solution
除以首项系数不改变根，所以可以假设$p(x) = x^n + c_{n-1}x^{n-1} + \dots + c_0$，其中$n$为奇数。对$x\neq0$，写成

$$
p(x) = x^n\bigl(1 + r(x)\bigr), \qquad r(x) = \frac{c_{n-1}}{x} + \frac{c_{n-2}}{x^2} + \dots + \frac{c_0}{x^n}.
$$

当$x\to\pm\infty$时，$r(x)$的每一项都趋于$0$，所以存在$R > 0$，使得只要$\abs{x}\ge R$，就有$\abs{r(x)} < \frac12$。对这样的$x$，因子$1 + r(x)$为正，所以$p(x)$与$x^n$同号，而（由于$n$是奇数）$x^n$与$x$同号。于是$p(-R) < 0 < p(R)$。由于$p$连续，由[[#cor-bolzano]]，在$(-R, R)$中有一个根。

对偶数次多项式，结论不成立：$x^2 + 1$没有实根。
:::
:::

::: quiz
设$f$在$[0, 2]$上连续，$f(0) = 3$，$f(2) = -1$。下列哪些说法**必定**成立？（选出所有正确选项。）
- [x] 存在某个$c\in(0,2)$，使$f(c) = 0$。
- [x] 存在某个$c \in (0, 2)$，使$f(c) = 2.5$。
- [ ] $f(1) = 1$。
- [ ] $f$在$(0,2)$内恰有一个零点。
- [ ] 不存在$c\in[0,2]$使$f(c) = 4$。
::: solution
$0$和$2.5$都严格介于$f(2) = -1$与$f(0) = 3$之间，所以介值定理保证它们会被取到。没有什么迫使$f(1) = 1$（图像不必是直线）；该定理也没有说零点有**多少个**（图像可能三次穿过横轴）；而$f$完全可能在中间某处超过$3$——没有什么阻止它取到值$4$。
:::
:::

::: warning 每个假设都不可缺少
该定理要求在**整个**闭区间上连续。函数$1/x$在$-1$处为负，在$1$处为正，但从不等于$0$：它在$[-1, 1]$上不连续（它在$0$处甚至没有定义）。同样，$\sgn x$在$[-1,1]$上取值$-1$和$1$，但从不取值$\frac12$。还要记住，该定理只断言存在性：它既没有说$c$在哪里，也没有说$c$是唯一的。
:::

::: application 温度相同的两个对跖点
在任一时刻，赤道上都有两个径向相对的点，它们的温度完全相同。用经度$\theta$来描述赤道上的点，设$T(\theta)$是该处的温度，假设它连续变化，且$T(\theta + 2\pi) = T(\theta)$。令$g(\theta) = T(\theta) - T(\theta + \pi)$。则$g$连续，且$g(\pi) = T(\pi) - T(2\pi) = -g(0)$。所以要么$g(0) = 0$，要么$g(0)$与$g(\pi)$异号，从而$g$在$(0,\pi)$内某处为零。$g$的一个零点就对应一对温度相等的对跖点。二维的版本（博苏克-乌拉姆定理，见[[topology]]）说的是：在地球表面上的任何地方，对温度**和**气压两者同时成立同样的结论。
:::

### 反函数的连续性

介值定理表明，连续函数把区间映成区间：若$y_1 < y < y_2$，其中$y_1 = f(x_1)$和$y_2 = f(x_2)$是函数值，则在$x_1$与$x_2$之间应用该定理可知$y$也是函数值。把这一点与下一个结果结合起来，就得到[[calculus-1/real-functions]]中遇到的所有反函数的连续性。

::: theorem 值域没有空隙的单调函数是连续的 {#thm-monotone-continuous}
设$f$在区间$I$上单调，并设它的值域$f(I)$是一个区间。则$f$在$I$上连续。
:::

::: proof
设$f$递增（否则对$-f$应用这一论证，它的值域$-f(I)$也是区间）。设$a\in I$，$\eps > 0$。假设$a$不是$I$的右端点，我们来找$\delta_+>0$，使得对所有满足$a \le x < a + \delta_+$的$x\in I$，都有$f(a) \le f(x) < f(a) + \eps$。

任取$b \in I$，$b > a$。若$f(b) < f(a) + \eps$，则$\delta_+ = b - a$可行，因为当$a\le x\le b$时$f(a)\le f(x)\le f(b)$。否则$f(b) \ge f(a) + \eps$，此时数$y = f(a) + \eps/2$介于两个值$f(a)$与$f(b)$之间。由于$f(I)$是区间，存在某个$x_1\in I$，使得$y = f(x_1)$；又因为$f(x_1) > f(a)$且$f$递增，所以$x_1 > a$。于是$\delta_+ = x_1 - a$可行：当$a\le x< x_1$时，$f(a) \le f(x) \le f(x_1) = f(a) + \eps/2$。

同理，除非$a$是$I$的左端点，存在$\delta_- > 0$，使得对满足$a - \delta_- < x \le a$的$x \in I$有$f(a) - \eps < f(x) \le f(a)$。取$\delta$为现有的$\delta_\pm$中较小的一个，则每个满足$\abs{x - a} < \delta$的$x\in I$都满足$\abs{f(x) - f(a)} < \eps$。所以$f$在$a$处连续（若$a$是端点，则是单侧连续）。
:::

::: corollary 反函数的连续性 {#cor-inverse-continuous}
若$f$在区间$I$上连续且严格单调，则$f(I)$是区间，并且反函数$f^{-1}\colon f(I)\to I$连续。
:::

::: proof
由介值定理，$f(I)$包含它的任意两个元素之间的每一个数，这正是区间的含义。由[[calculus-1/real-functions#thm-monotone-inverse]]，$f^{-1}$在$f(I)$上严格单调，且其值域是区间$I$。所以[[#thm-monotone-continuous]]适用于$f^{-1}$。
:::

::: corollary 初等函数是连续的 {#cor-elementary}
方根$x^{1/n}$、指数函数$a^x$、对数函数$\log_a x$以及反三角函数$\arcsin$、$\arccos$、$\arctan$在其定义域上连续。因此，由这些函数、多项式和三角函数经过四则运算与复合构造出来的每个函数，都在其定义域的每一点处连续（在端点处为单侧连续）。
:::

::: proof
方根$x^{1/n}$是$[0,\infty)$上（$n$为奇数时是$\R$上）连续且严格递增的函数$x^n$的反函数，所以由[[#cor-inverse-continuous]]它连续。指数函数$a^x$（$a > 0$）在$\R$上单调，其值域是区间$(0,\infty)$（当$a = 1$时为$\set{1}$），所以由[[#thm-monotone-continuous]]它连续；$\log_a$是连续严格单调函数的反函数，因而连续。类似地，$\arcsin$、$\arccos$和$\arctan$分别是$\sin$、$\cos$、$\tan$在$[-\frac\pi2,\frac\pi2]$、$[0,\pi]$和$(-\frac\pi2,\frac\pi2)$上的限制的反函数，而这些限制是连续的（[[#prop-trig-continuous]]）且严格单调。最后的结论由[[#thm-cont-algebra]]和[[#thm-composition]]得出。
:::

## 最值定理

连续函数的第二个重要性质涉及最大值和最小值。如果对所有$x\in D$都有$f(x)\le f(d)$，就说$f$在集合$D$上于$d\in D$处**取到最大值**；最小值的情形类似。

::: theorem 最值定理 {#thm-evt}
若$f$在有界闭区间$[a, b]$上连续，则$f$在$[a,b]$上取到最大值和最小值：存在$c, d\in[a,b]$，使得

$$
f(c) \le f(x) \le f(d) \qquad\text{对所有 } x\in[a,b].
$$
:::

::: proof {collapsed}
*概要*。证明分两步，两步都依赖于完备性；细节见[[real-analysis/continuity]]。

*第1步：$f$有界*。若不然，则对每个$n$，存在$x_n\in[a,b]$，使得$\abs{f(x_n)} > n$。由波尔查诺-魏尔斯特拉斯定理（完备性的一个推论，在[[real-analysis/sequences]]中证明），某个子列$x_{n_k}$收敛于一点$p$；由于区间是闭的，$p$属于$[a,b]$。由$f$在$p$处的连续性得$f(x_{n_k}) \to f(p)$，而这是不可能的，因为$\abs{f(x_{n_k})} > n_k \to\infty$。

*第2步：上确界可以取到*。由第1步和完备性，函数值的集合有最小上界$M$。假设对每个$x$都有$f(x) < M$。则$h(x) = 1/(M - f(x))$在$[a,b]$上连续，因而由第1步它有界，设$h(x)\le K$，其中$K>0$。由此得对所有$x$有$f(x)\le M - 1/K$，所以$M - 1/K$是一个比$M$小的上界——矛盾。因此对某个$d$有$f(d) = M$。把这一结论用于$-f$，就得到最小值。
:::

下面的例子表明，每个假设都是必需的。

- **闭区间**。$(0, 1)$上的$f(x) = x$连续且有界，但既没有最大值也没有最小值：它可以任意接近$1$和$0$，却取不到它们。
- **有界区间**。$[0,\infty)$上的$f(x) = x$没有最大值。
- **连续性**。当$0\le x< 1$时$f(x) = x$，且$f(1) = 0$，这个函数在$[0,1]$上有定义，但它的值趋近$1$却取不到$1$。
- **有界性也可能不成立**。$(0, 1]$上的$1/x$连续，但无上界。

::: quiz
下列函数中，哪些在所给的区间上取到最大值？（选出所有正确选项。）
- [x] $[-1, 2]$上的$x^2$
- [ ] $(0,1)$上的$x$
- [x] $(0, \pi)$上的$\sin x$
- [ ] $(0, 1]$上的$1/x$
::: solution
$[-1,2]$上的$x^2$属于最值定理所涵盖的情形；最大值是$4$，在$x=2$处取到。$(0,1)$上的恒等函数没有最大值。$(0,\pi)$上的$\sin x$**确实**在$\pi/2$处取到最大值$1$，尽管区间是开的——该定理给出的是充分条件，而不是必要条件。$(0,1]$上的$1/x$无上界，不过它确实在$x = 1$处取到最小值$1$。
:::
:::

最值定理只断言最值存在；求出它们是[[calculus-1/curve-sketching]]的任务，在那里我们将看到，最值出现在端点处，或者出现在导数为零或导数不存在的点处。它在理论上最重要的推论是罗尔定理，这是通往中值定理（[[calculus-1/mean-value-theorem]]）的第一步。

::: history
直到19世纪初，“连续”函数指的还是由单个公式给出的函数，而且人们想当然地认为这样的函数不经过零就不能改变符号。1817年，布拉格的神父兼数学家伯纳德·波尔查诺（Bernard Bolzano）发表了介值定理的一个“纯分析的”证明，并顺带给出了一个与我们的定义等价的连续性定义。奥古斯丁-路易·柯西（Augustin-Louis Cauchy）的《分析教程》（*Cours d'analyse*，1821年）借助无穷小增量来定义连续性，并通过反复细分区间证明了这个定理，做法与二分法颇为相似。这两个论证都在没有明言的情况下依赖于实数的完备性。直到1872年，这一点才被明确提出：理查德·戴德金（Richard Dedekind）在一本题为《连续性与无理数》（*Stetigkeit und irrationale Zahlen*）的小册子中，从有理数出发构造了实数。最值定理由波尔查诺在19世纪30年代证明，但这项工作在一个世纪里都未发表；卡尔·魏尔斯特拉斯（Karl Weierstrass）在1860年前后独立地证明了它。
:::

## 后续内容

连续性是微积分中几乎每个定理都要假设的最低限度的正则性。在[[calculus-1/derivatives]]中我们将看到，可导函数自动是连续的；最值定理推动着中值定理（[[calculus-1/mean-value-theorem]]）；闭区间上的每个连续函数都可积（[[calculus-1/integrals]]）。在[[real-analysis/continuity]]中，这里只给出概要的定理将得到完整的证明，同时还会讨论一致连续性。拓扑学则揭示了问题的实质：介值定理是关于连通性的命题（[[topology/connectedness]]），最值定理是关于紧性的命题（[[topology/compactness]]）。

::: summary
- 当$\lim_{x\to a}f(x) = f(a)$时，$f$在$a$处连续；在区间的端点处只使用单侧极限。
- 根据单侧极限的表现，间断点分为可去间断点、跳跃间断点、无穷间断点和本性间断点。
- 连续函数的和、积、商（在分母不为零处）以及复合都是连续的；当$f$在内层极限处连续时，$\lim f(g(x)) = f(\lim g(x))$。
- 所有初等函数在其定义域上连续，所以它们在定义域中的点处的极限可以通过代入求得。
- 介值定理：在$[a,b]$上连续的函数取到$f(a)$与$f(b)$之间的每一个值。它保证方程有解，而二分法可以逼近这些解。
- 区间上连续且严格单调的函数有连续的反函数。
- 最值定理：在有界闭区间上连续的函数取到最大值和最小值。这两个定理都依赖于$\R$的完备性。
:::

## 习题

::: exercise 选取常数 {level=1 check="1"}
求$k$的值，使得

$$
f(x) = \begin{cases} kx + 1, & x \le 2,\\ x^2 - k, & x > 2\end{cases}
$$

在$\R$上连续。
::: solution
每一段都是多项式，所以$f$在每个$x\neq2$处连续。在$2$处：$f(2) = 2k+1$，左极限是$2k + 1$，右极限是$4 - k$。连续性要求$2k + 1 = 4 - k$，所以$k = 1$。
:::
:::

::: exercise 间断点的分类 {level=1}
当$x\neq0$时令$g(x) = \dfrac{\sin x}{\abs{x}}$。$g$在$0$处有哪种间断点？能否选取$g(0)$的值使$g$连续？
::: solution
当$x>0$时，$g(x) = \frac{\sin x}{x}\to1$（$x\to0^+$）；当$x<0$时，$g(x) = -\frac{\sin x}{x}\to-1$（$x\to0^-$）。两个单侧极限都存在但不相等，所以$g$在$0$处有跳跃间断点。由于双侧极限不存在，$g(0)$取任何值都不能使$g$连续。
:::
:::

::: exercise 通过连续函数代入 {level=1 check="e^3"}
求$\displaystyle\lim_{x\to0}\exp\Bigl(\frac{\sin 3x}{x}\Bigr)$。
::: solution
内层函数趋于$3$（[[calculus-1/limits#ex-sin3x]]），而$\exp$在$3$处连续，所以由[[#thm-composition]]，极限为$e^3$。
:::
:::

::: exercise 三个实根 {level=2}
证明$x^3 - 3x + 1 = 0$恰有三个实数解，并对每个解找出一个包含它的长度为$1$的区间。
::: solution
令$p(x) = x^3 - 3x + 1$，它是连续的。它在从$-2$到$2$的各整数处的值为

$$
p(-2) = -1,\quad p(-1) = 3,\quad p(0) = 1,\quad p(1) = -1,\quad p(2) = 3.
$$

在$(-2,-1)$、$(0,1)$和$(1,2)$上都有符号变化，所以由[[#cor-bolzano]]，在这三个互不相交的区间中各有一个根。三次多项式至多有三个根（[[calculus-1/real-functions#cor-roots]]），所以恰有三个根。（它们近似为$-1.879$、$0.347$和$1.532$。）
:::
:::

::: exercise 绝对值函数的连续性 {#exr-abs level=2}
由ε–δ定义证明$f(x) = \abs{x}$在每个$a\in\R$处连续。
::: hint
利用反向三角不等式$\bigl\lvert\abs{x} - \abs{a}\bigr\rvert \le \abs{x-a}$。
:::
::: solution
先证这个不等式：由三角不等式，$\abs{x} = \abs{(x - a) + a} \le \abs{x-a} + \abs{a}$，所以$\abs{x} - \abs{a} \le \abs{x-a}$；交换$x$和$a$得$\abs{a}-\abs{x}\le\abs{x-a}$。合起来就是$\bigl\lvert\abs{x}-\abs{a}\bigr\rvert\le\abs{x-a}$。

现在设$\eps>0$，取$\delta = \eps$。若$\abs{x-a}<\delta$，则$\bigl\lvert\abs{x}-\abs{a}\bigr\rvert \le \abs{x-a} < \eps$。所以$\abs{\cdot}$在$a$处连续。
:::
:::

::: exercise 需要多少步二分？ {level=2 check="20"}
从$[1, 2]$开始使用二分法。需要多少步，含根区间的长度才会小于$10^{-6}$？
::: solution
经过$n$步后，区间长度为$2^{-n}$。我们需要$2^{-n} < 10^{-6}$，即$2^n > 10^6$。由于$2^{19} = 524\,288 < 10^6 < 1\,048\,576 = 2^{20}$，满足条件的最小的$n$是$20$。
:::
:::

::: exercise 一个不动点定理 {level=2}
设$f\colon[0,1]\to[0,1]$连续。证明$f$有一个**不动点**，即满足$f(c) = c$的数$c\in[0,1]$。
::: hint
对$g(x) = f(x) - x$应用介值定理。
:::
::: solution
令$g(x) = f(x) - x$，它在$[0,1]$上连续。由于$f$的值属于$[0,1]$，$g(0) = f(0) \ge 0$，$g(1) = f(1) - 1 \le 0$。若$g(0) = 0$或$g(1) = 0$，则$0$或$1$就是不动点。否则$g(0) > 0 > g(1)$，由[[#cor-bolzano]]，存在$c\in(0,1)$使$g(c) = 0$，即$f(c) = c$。（从几何上看：$f$的图像必定穿过单位正方形的对角线$y = x$。）
:::
:::

::: exercise 半周期弦 {level=3}
设$f$在$[0, 1]$上连续，且$f(0) = f(1)$。证明存在数$c\in[0,\frac12]$，使得$f(c) = f\bigl(c + \frac12\bigr)$。（如果你走的路线终点与起点高度相同，那么在某个时刻，你所处的高度与再过一半时间后你所处的高度相同。）
::: solution
在$[0,\frac12]$上定义$g(x) = f\bigl(x + \frac12\bigr) - f(x)$；它是连续的。于是

$$
g(0) + g\bigl(\tfrac12\bigr) = \bigl(f(\tfrac12) - f(0)\bigr) + \bigl(f(1) - f(\tfrac12)\bigr) = f(1) - f(0) = 0.
$$

所以$g(\frac12) = -g(0)$。若$g(0) = 0$，取$c = 0$。否则$g(0)$与$g(\frac12)$都不为零且异号，由[[#cor-bolzano]]，存在$c\in(0,\frac12)$使$g(c) = 0$，这正是所要证的。
:::
:::

::: exercise 连续的单射是单调的 {level=3}
设$f$在区间$I$上连续且是单射。证明$f$在$I$上严格单调。
::: hint
设$x_1 < x_2$且$f(x_1) < f(x_2)$，$y_1 < y_2$且$f(y_1) > f(y_2)$。对$t\in[0,1]$，考虑$u(t) = (1-t)x_1 + ty_1$、$v(t) = (1-t)x_2 + ty_2$以及$g(t) = f(v(t)) - f(u(t))$。
:::
::: solution
由于$f$是单射，对$I$中的每一对$x<y$，要么$f(x)<f(y)$，要么$f(x)>f(y)$。只需证明对所有的点对出现的都是同一种情形。假设不然：$I$中存在$x_1 < x_2$满足$f(x_1) < f(x_2)$，又存在$y_1 < y_2$满足$f(y_1) > f(y_2)$。

对$t\in[0,1]$，令$u(t) = (1-t)x_1 + ty_1$，$v(t) = (1-t)x_2 + ty_2$。这些点都属于$I$，因为区间包含其中任意两点之间的每一个点；并且

$$
v(t) - u(t) = (1-t)(x_2 - x_1) + t(y_2 - y_1) > 0,
$$

所以$u(t)<v(t)$。函数$g(t) = f(v(t)) - f(u(t))$在$[0,1]$上连续（它由连续函数经复合与相减得到），且$g(0) = f(x_2) - f(x_1) > 0$，$g(1) = f(y_2) - f(y_1) < 0$。由[[#cor-bolzano]]，对某个$t_0$有$g(t_0) = 0$，即$f(u(t_0)) = f(v(t_0))$，尽管$u(t_0) \neq v(t_0)$。这与单射性矛盾。因此$f$严格递增或严格递减。
:::

::: exercise 恰在一点处连续 {level=3}
当$x$为有理数时令$f(x) = x$，当$x$为无理数时令$f(x) = 0$。证明$f$在$0$处连续，而在每个$a\neq0$处不连续。可以利用这一事实：每个开区间既含有有理数，也含有无理数。
::: solution
*在$0$处*。对每个$x$，$\abs{f(x) - f(0)} = \abs{f(x)} \le \abs{x}$。给定$\eps>0$，取$\delta = \eps$：则由$\abs{x}<\delta$可推出$\abs{f(x) - f(0)} < \eps$。

*在$a\neq0$处*。假设$f$在$a$处连续。取$\eps = \abs{a}/4 > 0$，则存在$\delta>0$，使得只要$\abs{x-a}<\delta$，就有$\abs{f(x) - f(a)} < \abs{a}/4$。令$\delta' = \min(\delta, \abs{a}/4)$，并在$(a - \delta', a + \delta')$中选取一个有理数$q$和一个无理数$x$。则$f(q) = q$，$f(x) = 0$。一方面，$\abs{q} \ge \abs{a} - \abs{q - a} > \abs{a} - \abs{a}/4 = \tfrac34\abs{a}$。另一方面，

$$
\abs{q} = \abs{f(q) - f(x)} \le \abs{f(q) - f(a)} + \abs{f(a) - f(x)} < \frac{\abs{a}}{4} + \frac{\abs a}{4} = \frac{\abs{a}}{2}.
$$

两者合起来给出$\tfrac34\abs{a} < \tfrac12\abs{a}$，由于$\abs{a} > 0$，这是不可能的。因此$f$在$a$处不连续。
:::
