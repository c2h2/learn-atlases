计算机几乎可以瞬间画出任何函数的图像，那么为什么还要学习手工描绘图像呢？因为画出来的图只显示一个窗口和有限个采样点。它可能漏掉一个狭窄的尖峰，掩盖$x$很大时发生的情况，把一条渐近线模糊成一条陡峭的直线，而且它从不解释图像**为什么**是这个样子。导数精确地告诉我们函数在哪里上升、在哪里下降，二阶导数告诉我们它如何弯曲，而极限描述它在定义域边缘处的行为。把这些结合起来，就能完全确定图像的形状。

同样的思想也能解决**最优化**问题：一个盒子所能达到的最大容积，成本最低的罐头形状，光线用时最短的路径。每个这样的问题都是求某个函数的最大值或最小值，而本章的工具——临界点、一阶与二阶导数判别法以及闭区间法——就能求出它们。这一切都建立在中值定理及其推论（[[calculus-1/mean-value-theorem]]）的基础之上。

## 临界点与一阶导数判别法

由费马定理（[[calculus-1/mean-value-theorem#thm-fermat]]），若局部极值出现在$f$可导的内点处，则必有$f'(c) = 0$。极值也可能出现在$f'$不存在的地方，例如$\abs{x}$在$0$处。这促使我们给这些候选点起一个名字。

::: definition 临界点 {#def-critical}
$f$的**临界点**（或临界数）是指$f$的定义域内部满足$f'(c) = 0$或$f'(c)$不存在的点$c$。此时值$f(c)$称为**临界值**。
:::

所以内部的局部极值**只能**出现在临界点处。反之则不然——$x^3$在$0$处有临界点，却没有极值——所以必须逐一检验每个临界点。最简单的方法是考察$f'$在临界点两侧的符号。

::: theorem 一阶导数判别法 {#thm-first-derivative-test}
设$c$是$f$的临界点，$f$在$c$处连续，且对某个$\delta > 0$，$f$在$(c-\delta, c)$和$(c, c+\delta)$上可导。

1. 若在$(c-\delta, c)$上$f'>0$，在$(c, c+\delta)$上$f'<0$，则$f$在$c$处取得局部极大值。
2. 若在$(c-\delta, c)$上$f'<0$，在$(c, c+\delta)$上$f'>0$，则$f$在$c$处取得局部极小值。
3. 若$f'$在两侧同号，则$f$在$c$处没有局部极值。
:::

::: proof
函数$f$在$(c-\delta, c]$上连续（它在$(c - \delta, c)$上可导，从而连续，并且在$c$处连续），类似地在$[c, c+\delta)$上也连续。在情形1中，由单调性判别法（[[calculus-1/mean-value-theorem#thm-monotonicity]]），$f$在$(c-\delta, c]$上严格递增，在$[c, c+\delta)$上严格递减。因此对$(c-\delta, c+\delta)$中每个$x\neq c$有$f(x) < f(c)$：这是一个（严格的）局部极大值。情形2与此相同，只是不等号反向。在情形3中，不妨设两侧都有$f' > 0$，则$f$在$(c - \delta, c]$和$[c, c+\delta)$上都严格递增，从而在整个区间上严格递增，所以当$x<c$时$f(x) < f(c)$，当$x > c$时$f(x)>f(c)$，$c$不是极值点。
:::

实际操作时，我们把$f'$因式分解，求出它的零点和它没有定义的点，并把它在这些点之间各区间上的符号记录在一张**符号表**中。

::: example 不是极值点的临界点 {#ex-first-test}
求$f(x) = x^4 - 4x^3$的临界点并加以分类。
::: solution
$f'(x) = 4x^3 - 12x^2 = 4x^2(x - 3)$，它处处存在，并在$x = 0$和$x = 3$处为零。因子$4x^2$除在$0$处外都是正的，所以$f'$的符号就是$x - 3$的符号：

| 区间 | $(-\infty, 0)$ | $(0, 3)$ | $(3, \infty)$ |
|---|---|---|---|
| $f'$的符号 | $-$ | $-$ | $+$ |
| $f$ | 递减 | 递减 | 递增 |

在$x = 3$处符号由$-$变为$+$：这是一个局部极小值，$f(3) = 81 - 108 = -27$。由于$f$在$(-\infty, 3]$上递减，在$[3,\infty)$上递增，这实际上就是全局最小值。在$x = 0$处符号不变，所以没有极值：图像在那里短暂地变平，然后继续下降。
:::
:::

::: quiz
设对所有$x$有$f'(x) = (x-1)^2(x+2)$。下列哪些说法正确？（选出所有正确选项。）
- [ ] $f$在$1$处取得局部极大值。
- [ ] $f$在$1$处取得局部极小值。
- [x] $f$在$-2$处取得局部极小值。
- [x] $f$在$1$处没有局部极值。
::: solution
因子$(x-1)^2$永不为负，所以$f'$的符号与$x + 2$的符号相同（$x=1$处除外，那里$f' = 0$）。符号在$-2$处由$-$变为$+$，所以那里是局部极小值。在$1$的两侧符号都是$+$，所以由[[#thm-first-derivative-test]]的情形3，尽管$f'(1) = 0$，那里也没有极值。
:::
:::

## 凹凸性与二阶导数判别法

两个函数可以在同一区间上都递增，样子却大不相同：$x^2$在$(0,\infty)$上向上弯曲，越来越陡；而$\sqrt{x}$向下弯曲，越来越平。区别在于**凹凸性**。

::: definition 凹凸性 {#def-concave}
设$f$在开区间$I$上可导。若$f$的图像在$I$上位于它的每一条切线的上方，即

$$
f(x) \ge f(a) + f'(a)(x - a) \qquad\text{对所有 } x, a\in I,
$$ {#eq-convex}

则称$f$在$I$上是**下凸**的（或**凸**的）；若对所有$x, a\in I$都有相反的不等式成立，则称$f$在$I$上是**上凸**的。
:::

用切线给出的定义抓住了几何图景，而且便于使用：例如，它立即表明下凸函数位于它的线性近似的上方，正如我们在$e^x \ge 1 + x$中所见。[[#exr-chords]]给出了一个用弦来表述的等价定义，它在不可导时也适用。导数可以判断凹凸性。

::: theorem 凹凸性与导数 {#thm-concavity}
设$f$在开区间$I$上可导。则$f$在$I$上是下凸的，当且仅当$f'$在$I$上递增。因此，若$f$在$I$上二阶可导，则在$I$上$f''\ge0$蕴涵$f$是下凸的，在$I$上$f''\le0$蕴涵$f$是上凸的。
:::

::: proof
设$f'$递增，$a, x\in I$。若$x > a$，由中值定理，存在$c\in(a,x)$使$f(x) - f(a) = f'(c)(x - a)$；由于$f'(c)\ge f'(a)$且$x - a>0$，上式$\ge f'(a)(x - a)$。若$x<a$，则$c\in(x,a)$，所以$f'(c)\le f'(a)$，乘以负数$x - a$后同样得到$f'(c)(x-a)\ge f'(a)(x-a)$。无论哪种情形，[[#eq-convex]]都成立。

反之，设[[#eq-convex]]成立，$I$中的$a < b$。分别在$a$处（取$x = b$）和在$b$处（取$x = a$）应用它，得

$$
f(b) \ge f(a) + f'(a)(b-a), \qquad f(a) \ge f(b) + f'(b)(a - b).
$$

两式相加得$0\ge (b-a)\bigl(f'(a) - f'(b)\bigr)$，由于$b - a > 0$，得$f'(a)\le f'(b)$。所以$f'$递增。

最后，若在$I$上$f''\ge0$，则对$f'$应用单调性判别法知$f'$递增，所以$f$是下凸的。关于上凸的结论，只需把上述结果应用于$-f$即可。
:::

::: definition 拐点 {#def-inflection}
若$f$在$c$处连续，并且对某个$\delta>0$，$f$在$(c-\delta, c)$上是下凸的而在$(c, c+\delta)$上是上凸的，或者反过来，则称点$c$为$f$的**拐点**。
:::

若$f''$连续，则在拐点处$f''$变号，所以$f''(c) = 0$。但$f''(c) = 0$并不能保证是拐点：$f(x) = x^4$满足$f''(0) = 0$，但它在整个$\R$上都是下凸的。

在满足$f'(c) = 0$的临界点处，凹凸性往往能决定问题：在水平切线附近向上弯曲的图像，正处在一个谷底。

::: theorem 二阶导数判别法 {#thm-second-derivative-test}
设$f'(c) = 0$且$f''(c)$存在。

1. 若$f''(c) > 0$，则$f$在$c$处取得局部极小值。
2. 若$f''(c) < 0$，则$f$在$c$处取得局部极大值。
3. 若$f''(c) = 0$，则该判别法不能给出任何信息。
:::

::: proof
要使$f''(c)$存在，$f'$必须在包含$c$的某个开区间上存在。由于$f'(c) = 0$，

$$
f''(c) = \lim_{h\to0}\frac{f'(c+h) - f'(c)}{h} = \lim_{h\to0}\frac{f'(c+h)}{h}.
$$

在情形1中这个极限为正，所以存在$\delta > 0$，使得当$0<\abs h<\delta$时$f'(c+h)/h > 0$（极限的保号性）。因此当$-\delta<h<0$时$f'(c+h) < 0$，当$0<h<\delta$时$f'(c+h)>0$，由一阶导数判别法知这是局部极小值。（这里$f$在$c$处连续，因为它在那里可导。）把情形1应用于$-f$即得情形2。对于情形3，函数$x^4$、$-x^4$和$x^3$都满足$f'(0) = f''(0) = 0$，但它们在$0$处分别取得最小值、取得最大值和两者都不是。
:::

::: quiz
已知在点$c$处$f'(c) = 0$且$f''(c) = 0$。你能得出什么结论？

:::

## 渐近线与函数作图

极限描述了图像在定义域边缘附近的样子。竖直渐近线来自无穷的单侧极限（[[calculus-1/limits#def-infinite-limit]]），水平渐近线来自$\pm\infty$处的极限（[[calculus-1/limits#def-limit-infinity]]）。图像也可能趋近于一条倾斜的直线。

::: definition 斜渐近线 {#def-slant}
设$m \neq 0$。若直线$y = mx + b$满足

$$
\lim_{x\to\infty}\bigl(f(x) - (mx + b)\bigr) = 0,
$$

则称它是$f$当$x\to\infty$时的**斜渐近线**（也称倾斜渐近线）；$x\to-\infty$时的情形类似。
:::

若这样的渐近线存在，则$m = \lim_{x\to\infty} f(x)/x$，$b = \lim_{x\to\infty}\bigl(f(x) - mx\bigr)$。对于分子次数比分母次数高一次的有理函数，多项式除法给出$f(x) = mx + b + r(x)/q(x)$，其中$\deg r < \deg q$，而最后一项趋于$0$。

下面是一份把所有这些信息组织起来的检查清单。并非每一步对每个函数都适用，顺序也可以调整。

::: algorithm 描绘函数图像 {#alg-sketch}
1. **定义域**——$f$在哪里有定义？
2. **截距**——$f(0)$，以及$f(x) = 0$的解（如果能求出的话）。
3. **对称性**——$f$是偶函数、奇函数还是周期函数？
4. **渐近线**——定义域边缘处的竖直渐近线；$x\to\pm\infty$时的水平渐近线或斜渐近线。
5. **一阶导数**——临界点、递增区间与递减区间、局部极值。
6. **二阶导数**——凹凸区间与拐点。
7. **作图**——描出关键点，用虚线画出渐近线，再用单调性和凹凸性都正确的曲线把这些点连接起来。
:::

::: example 具有斜渐近线的有理函数 {#ex-sketch-rational}
描绘$f(x) = \dfrac{x^2}{x-1}$的图像。
::: solution
**定义域：**$x\neq1$。**截距：**$f(0) = 0$，且仅在$x = 0$处$f(x) = 0$。**对称性：**无。

**渐近线：**当$x\to1^+$时，分子趋于$1$，分母趋于$0^+$，所以$f\to\infty$；当$x\to1^-$时，$f\to-\infty$。所以$x = 1$是竖直渐近线。作除法得

$$
f(x) = x + 1 + \frac{1}{x-1},
$$

所以当$x\to\pm\infty$时$f(x) - (x+1)\to0$：直线$y = x+1$在两个方向上都是斜渐近线。由于$\frac{1}{x-1}$在$x>1$时为正，在$x<1$时为负，图像在右侧位于渐近线上方，在左侧位于渐近线下方。

**一阶导数：**$f'(x) = \dfrac{2x(x-1) - x^2}{(x-1)^2} = \dfrac{x(x-2)}{(x-1)^2}$。临界点：$0$和$2$。分母为正，所以在$(-\infty,0)$上$f'>0$，在$(0,1)$和$(1,2)$上$f'<0$，在$(2,\infty)$上$f'>0$。局部极大值为$f(0) = 0$，局部极小值为$f(2) = 4$。（局部极大值比局部极小值还小——它们位于不同的分支上。）

**二阶导数：**对$x + 1 + (x-1)^{-1}$求两次导数得$f''(x) = \dfrac{2}{(x-1)^3}$。所以$f$在$(-\infty, 1)$上是上凸的，在$(1,\infty)$上是下凸的；由于$1$不在定义域中，没有拐点。

图像有两个分支：左边是一段经过原点的拱形，从斜渐近线升到顶点$(0,0)$，再在竖直渐近线处降到$-\infty$；右边是一段杯形，最低点为$(2,4)$，从$+\infty$下降，再从上方趋近$y = x + 1$。
:::
:::

::: example 指数衰减乘以幂函数 {#ex-sketch-exp}
描绘$f(x) = xe^{-x}$的图像。
::: solution
**定义域：**$\R$。**截距：**只有$(0,0)$。**渐近线：**没有竖直渐近线。当$x\to\infty$时，由洛必达法则（[[calculus-1/mean-value-theorem#ex-lhopital]]），$f(x) = x/e^x\to0$，所以$y = 0$是右侧的水平渐近线；当$x\to-\infty$时，$x\to-\infty$且$e^{-x}\to\infty$，所以$f(x)\to-\infty$。

**一阶导数：**$f'(x) = e^{-x} - xe^{-x} = (1 - x)e^{-x}$。由于$e^{-x} > 0$，$f$在$(-\infty, 1]$上递增，在$[1,\infty)$上递减，全局最大值为$f(1) = 1/e\approx0.368$。

**二阶导数：**$f''(x) = -e^{-x} - (1-x)e^{-x} = (x - 2)e^{-x}$。所以$f$在$(-\infty, 2)$上是上凸的，在$(2,\infty)$上是下凸的，拐点为$(2, 2e^{-2})\approx(2, 0.271)$。

图像从$-\infty$陡峭地上升，经过原点，在$(1, 1/e)$处达到顶峰，在$x = 2$处由向下弯曲变为向上弯曲，然后向$x$轴衰减，但永远达不到$x$轴。例如，单次给药后血液中的药物浓度就可以用这种形状的函数来描述。
:::
:::

## 最优化

许多问题要求函数在某个区间上的最大值或最小值。在有界闭区间上，最值定理保证二者都存在，而费马定理告诉我们去哪里寻找。

::: algorithm 闭区间法 {#alg-closed-interval}
求连续函数$f$在有界闭区间$[a,b]$上的全局最大值和全局最小值：

1. 求出$f$在$(a,b)$内的临界点。
2. 计算$f$在这些临界点以及端点$a$和$b$处的值。
3. 这些值中最大的就是全局最大值，最小的就是全局最小值。
:::

这个方法之所以有效，是因为由[[calculus-1/continuity#thm-evt]]，最大值在$[a, b]$中的某处取得；若它在某个内点处取得，则该点是局部极大值点，从而由费马定理是临界点；否则它在端点处取得。最小值的情形也一样。这里不需要二阶导数判别法：只需比较函数值即可。

::: example 闭区间法 {#ex-closed-interval}
求$f(x) = x^3 - 3x^2 + 1$在$\bigl[-\frac12, 4\bigr]$上的全局最大值和全局最小值。
::: solution
$f'(x) = 3x^2 - 6x = 3x(x-2)$，所以$(-\frac12, 4)$内的临界点为$0$和$2$。函数值为

$$
f\bigl(-\tfrac12\bigr) = \tfrac18, \qquad f(0) = 1, \qquad f(2) = -3, \qquad f(4) = 17.
$$

全局最大值为$17$，在端点$x = 4$处取得；全局最小值为$-3$，在$x = 2$处取得。注意$0$处的局部极大值并不是全局最大值。
:::
:::

::: quiz
要求连续函数$f$在$[a, b]$上的全局最大值，必须检查哪些点？（选出所有正确选项。）
- [x] $f$在$(a,b)$内的临界点。
- [x] 端点$a$和$b$。
- [ ] $f$的拐点。
- [ ] 只需检查$f''<0$的点。
::: solution
由最值定理，最大值存在；若它位于内点处，则它是临界点（费马定理），否则它位于端点处。拐点本身并不是候选点；而只考虑$f''<0$的点，会漏掉位于端点处以及$f'$不存在之处的最大值。
:::
:::

应用问题在动用微积分之前，需要先经过一个翻译步骤：

1. 仔细读题，直到弄清要使什么取最大值或最小值，并画出示意图。
2. 给各个量命名，利用约束条件消去其他变量，把目标写成**一个**变量的函数。
3. 根据实际情况确定该变量的取值范围。
4. 求全局极值：若取值范围是有界闭区间，就用闭区间法；否则就用一阶导数判别法，具体做法见下文。
5. 回答题目所问的问题，并注明单位。

::: example 容积最大的盒子 {#ex-box}
用一块$30$ cm × $30$ cm的正方形卡纸制作一个无盖盒子：从四个角各剪去一个同样大小的正方形，再把四边折起来。剪去多大的正方形，才能使盒子的容积最大？
::: solution
设剪去的正方形边长为$x$ cm。于是盒子的底面是边长为$30 - 2x$的正方形，高为$x$，所以它的容积为

$$
V(x) = x(30 - 2x)^2, \qquad 0\le x\le 15.
$$

（在这个区间的两个端点处，盒子退化，$V = 0$。）用乘积法则求导，

$$
V'(x) = (30-2x)^2 - 4x(30 - 2x) = (30 - 2x)(30 - 6x) = 12(15 - x)(5 - x).
$$

$(0, 15)$内唯一的临界点是$x = 5$。比较$V(0) = 0$、$V(5) = 5\cdot20^2 = 2000$和$V(15) = 0$，可知最大容积为$2000$ cm³，此时剪去的是边长为$5$ cm的正方形。
:::
:::

::: widget plot
f: x*(30 - 2x)^2
x: 0, 15
y: 0, 2300
tangent: 2
points: 5, 2000
labels: V(x) = x(30-2x)^2
caption: 盒子的容积作为剪去尺寸$x$的函数。把切点拖到曲线的顶部，那里的切线是水平的：此时$x = 5$，$V'(5) = 0$，容积达到$2000$ cm³。在最大值附近图像很平坦，所以剪裁时的小误差只会损失很少的容积。
:::

在不是有界闭区间的区间上，全局极值未必存在，闭区间法也不再适用。一个有用的替代方法是**全局极值的一阶导数判别法**：若$f$在区间$I$上连续，$c\in I$，并且（在$I$中）当$x<c$时$f'<0$，当$x>c$时$f'>0$，则$f(c)$是$f$在$I$上的全局最小值，因为$f$在$c$之前递减、在$c$之后递增。对于最大值，把符号反过来，同样的结论成立。

::: example 最省料的罐头 {#ex-can}
一个圆柱形罐头的容积必须为$V$。什么形状能使所用金属的面积（顶面、底面和侧面）最小？
::: solution
设半径为$r$，高为$h$，则容积为$V = \pi r^2h$，表面积为$A = 2\pi r^2 + 2\pi rh$。消去$h = V/(\pi r^2)$，得

$$
A(r) = 2\pi r^2 + \frac{2V}{r}, \qquad r > 0.
$$

于是$A'(r) = 4\pi r - \dfrac{2V}{r^2}$，当$r^3 = \dfrac{V}{2\pi}$时它为零。把这个值记为$r_*$。当$r<r_*$时$4\pi r^3 < 2V$，所以$A'(r)<0$；当$r > r_*$时$A'(r)>0$。由全局极值的一阶导数判别法，$A$在$(0,\infty)$上于$r_*$处取得全局最小值。相应的高为

$$
h = \frac{V}{\pi r_*^2} = \frac{2\pi r_*^3}{\pi r_*^2} = 2r_*.
$$

所以最佳的罐头高度与宽度相同：高等于直径。对于容积为$330$ ml的饮料罐，这给出$r_*\approx3.74$ cm，$h\approx7.49$ cm。实际的饮料罐更高更细，这是因为顶面和底面所用的金属比侧面更厚，也与罐头的握持和堆放方式有关——这提醒我们，模型的好坏取决于它的假设。
:::
:::

::: application 费马原理与斯涅尔定律
光在空气中的速度为$v_1$，在水中的速度为$v_2$。一条光线从水面上方高$a$处的点$A$出发，到达水面下方深$b$处的点$B$，$B$与$A$的水平距离为$d$。若光线在与$A$水平距离为$x$的地方穿过水面，则所用的时间为

$$
T(x) = \frac{\sqrt{a^2 + x^2}}{v_1} + \frac{\sqrt{b^2 + (d - x)^2}}{v_2}, \qquad
T'(x) = \frac{x}{v_1\sqrt{a^2+x^2}} - \frac{d - x}{v_2\sqrt{b^2 + (d-x)^2}} = \frac{\sin\theta_1}{v_1} - \frac{\sin\theta_2}{v_2},
$$

其中$\theta_1$和$\theta_2$是光线的两段与竖直方向所成的角。可以验证$T''>0$，所以$T$是下凸的，它唯一的临界点就是全局最小值点。因此，费马原理——光沿用时最短的路径传播——预言了$\dfrac{\sin\theta_1}{v_1} = \dfrac{\sin\theta_2}{v_2}$，这就是斯涅尔（Snell）折射定律，每一块透镜和棱镜都证实了它。
:::

::: warning 检查端点和定义域
令$f'(x) = 0$只是最优化问题的一半。最大值可能出现在端点处（[[#ex-closed-interval]]），或者出现在$f'$不存在的点处；而你想要最大值时，找到的临界点可能是最小值点。在开区间或无界区间上，极值可能根本不存在：$1/x$在$(0,\infty)$上没有最小值。务必说明为什么你找到的临界点给出了全局极值。
:::

::: history
极值问题是数学中最古老的问题之一。公元1世纪，亚历山大的希罗（Heron of Alexandria）证明了：被镜面反射的光线在其两个端点之间走的是最短路径。皮埃尔·德·费马（Pierre de Fermat）求极大值与极小值的方法约于1636年以手稿形式流传，它第一次系统地使用了实质上就是条件$f'(c) = 0$的东西；1662年，费马从光沿用时最短的路径传播这一原理推导出了折射定律。莱布尼茨（Leibniz）关于微积分的第一篇论文（1684）在标题中就宣告了一种“求极大值与极小值以及切线的新方法”。对曲线形状的系统讨论充满了18世纪的教科书，例如玛丽亚·加埃塔纳·阿涅西（Maria Gaetana Agnesi）的《分析讲义》（*Instituzioni analitiche*，1748），它是最早的综合性微积分教材之一。
:::

## 后续内容

多元函数的最优化以及带约束的最优化是[[multivariable/extrema]]一章的主题：在那里，临界点由梯度求得，并用二阶导数构成的矩阵加以分类，而约束则用拉格朗日乘数来处理。凸函数——即本章中的下凸函数——是现代最优化的支柱，因为凸函数的每个局部极小值都是全局最小值。用牛顿法求根——它沿着切线逐步逼近零点——将在[[numerical-analysis/root-finding]]一章中研究；而图像的曲率，一种比$f''$的符号更精细的弯曲程度的度量，将出现在[[differential-geometry/curves]]一章中。

::: summary
- 临界点是满足$f' = 0$或$f'$不存在的内点；内部的局部极值只能出现在临界点处。
- 一阶导数判别法：$f'$的符号由$+$变为$-$给出局部极大值，由$-$变为$+$给出局部极小值，不变号则没有极值。
- 可导函数是下凸的，当且仅当$f'$递增；$f''\ge0$是一个充分条件。拐点是凹凸性发生改变的点。
- 二阶导数判别法：$f'(c) = 0$且$f''(c)>0$给出局部极小值，$f''(c)<0$给出局部极大值；$f''(c) = 0$时无法判断。
- 渐近线（竖直、水平、斜）描述图像在定义域边缘处的样子；它们与导数一起决定了图像的形状。
- 在有界闭区间上，通过比较临界点和端点处的函数值来求全局极值。
- 在应用问题中，要化为单变量函数，确定取值范围，并论证所求得的临界点给出全局极值。
:::

## 习题

::: exercise 临界点的分类 {level=1}
求$f(x) = x^3 - 12x + 1$的临界点，并判断每个临界点是局部极大值点、局部极小值点，还是两者都不是。
::: solution
$f'(x) = 3x^2 - 12 = 3(x-2)(x+2)$，所以临界点为$\pm2$。由于$f''(x) = 6x$，由[[#thm-second-derivative-test]]，$f''(-2) = -12<0$（局部极大值，$f(-2) = 17$），$f''(2) = 12>0$（局部极小值，$f(2) = -15$）。
:::
:::

::: exercise 全局最大值 {level=1 check="18"}
求$f(x) = x^3 - 3x$在$[0, 3]$上的全局最大值。
::: solution
$f'(x) = 3x^2 - 3$在$x = \pm1$处为零，其中只有$x = 1$位于$(0,3)$内。比较$f(0) = 0$、$f(1) = -2$和$f(3) = 27 - 9 = 18$，全局最大值为$18$，在$x = 3$处取得（全局最小值为$-2$，在$x = 1$处取得）。
:::
:::

::: exercise 凹凸性 {level=1}
求$f(x) = x^4 - 6x^2$为下凸或上凸的区间，以及它的拐点。
::: solution
$f''(x) = 12x^2 - 12 = 12(x-1)(x+1)$。它在$(-\infty,-1)$和$(1,\infty)$上为正，$f$在那里是下凸的；在$(-1,1)$上为负，$f$在那里是上凸的。凹凸性在$x = \pm1$处改变，所以拐点为$(\pm1, -5)$。
:::
:::

::: exercise 尖点 {level=2}
描绘$f(x) = 3x^{2/3} - 2x$的图像，指出它的临界点和局部极值。
::: solution
定义域为$\R$（负数的立方根没有问题）。当$x\neq0$时，

$$
f'(x) = 2x^{-1/3} - 2 = \frac{2\bigl(1 - x^{1/3}\bigr)}{x^{1/3}}.
$$

所以$f'(1) = 0$，而$f'(0)$不存在（差商$3h^{-1/3} - 2$无界）：临界点为$0$和$1$。当$x<0$时，分子为正，分母为负，所以$f'<0$；当$0<x<1$时，分子分母都为正，所以$f'>0$；当$x>1$时，分子为负，所以$f'<0$。因此$f$在一个尖点处取得局部极小值$f(0) = 0$（差商从左侧趋于$-\infty$，从右侧趋于$+\infty$），并取得局部极大值$f(1) = 1$。当$x\neq0$时，$f''(x) = -\frac23x^{-4/3}<0$，所以$f$在$(-\infty,0)$和$(0,\infty)$上都是上凸的。当$x\to\infty$时，$-2x$这一项起主导作用，$f\to-\infty$；当$x\to-\infty$时，$f\to\infty$。零点为$x = 0$和$x = 27/8$（由$3x^{2/3} = 2x$，即$x^{1/3} = 3/2$得到）。
:::
:::

::: exercise 抛物线上的最近点 {level=2 check="sqrt(7)/2"}
求点$(0, 2)$到抛物线$y = x^2$的最短距离。
::: hint
改为求距离平方的最小值：它的最小值点相同，而且没有平方根。
:::
::: solution
从$(x, x^2)$到$(0,2)$的距离的平方为$D(x) = x^2 + (x^2-2)^2 = x^4 - 3x^2 + 4$。于是$D'(x) = 4x^3 - 6x = 2x(2x^2 - 3)$，其零点为$0$和$\pm\sqrt{3/2}$。在由$-\sqrt{3/2}, 0, \sqrt{3/2}$分隔开的各区间上，$D'$的符号依次为$-,+,-,+$，所以$D$先递减到$-\sqrt{3/2}$，再递增到$0$，然后递减到$\sqrt{3/2}$，此后递增。它的全局最小值为$D(\pm\sqrt{3/2}) = \frac94 - \frac92 + 4 = \frac74$，最短距离为$\sqrt{7}/2\approx1.32$，在$\bigl(\pm\sqrt{3/2}, \frac32\bigr)$处取得。（临界点$x = 0$，即抛物线的顶点，是距离的局部**极大值**点。）
:::
:::

::: exercise 河边的田地 {level=2 check="180000"}
一位农民有$1200$ m长的篱笆，要沿一条笔直的河围出一块矩形田地；沿河的一边不需要篱笆。田地的面积最大可能是多少？
::: solution
设垂直于河的每条边长为$x$；平行于河的边长为$1200 - 2x$。面积为$A(x) = x(1200 - 2x)$，$0\le x\le600$。于是$A'(x) = 1200 - 4x$在$x = 300$处为零，而$A(0) = A(600) = 0$，$A(300) = 300\cdot600 = 180\,000$ m²。所以最大面积为$180\,000$ m²，此时沿河的一边是其他边的两倍长。
:::
:::

::: exercise 斜渐近线 {level=2}
求$f(x) = \dfrac{2x^2 + 3x - 1}{x + 2}$的斜渐近线，并判断当$x\to\infty$和$x\to-\infty$时图像分别位于它的哪一侧。
::: solution
多项式除法给出$2x^2 + 3x - 1 = (x+2)(2x - 1) + 1$，所以

$$
f(x) = 2x - 1 + \frac{1}{x+2}.
$$

由于当$x\to\pm\infty$时$\frac{1}{x+2}\to0$，直线$y = 2x - 1$在两个方向上都是斜渐近线。当$x > -2$时余项为正，所以当$x\to\infty$时图像位于渐近线上方；当$x<-2$时余项为负，所以当$x\to-\infty$时图像位于渐近线下方。
:::
:::

::: exercise 切线与弦 {#exr-chords level=3}
设$f$在开区间$I$上是[[#def-concave]]意义下的下凸函数。证明对所有$x, y\in I$和$t\in[0,1]$，有

$$
f\bigl((1-t)x + ty\bigr) \le (1-t)f(x) + tf(y).
$$

（从几何上看：图像位于它的每一条弦的下方。）
::: solution
令$z = (1-t)x + ty$，由于$I$是区间，$z$位于$I$中。在[[#eq-convex]]中取$a = z$，分别在$x$处和在$y$处应用它：

$$
f(x)\ge f(z) + f'(z)(x - z), \qquad f(y)\ge f(z) + f'(z)(y - z).
$$

把第一个不等式乘以$1 - t\ge0$，第二个乘以$t\ge0$，然后相加：

$$
(1-t)f(x) + tf(y) \ge f(z) + f'(z)\bigl((1-t)x + ty - z\bigr) = f(z),
$$

这是因为$(1-t)x + ty - z = 0$。这就是所要证的不等式。（弦不等式不需要导数就有意义，它是分析学和最优化中凸性的通常定义。）
:::
:::

::: exercise 算术-几何平均不等式 {level=3}
利用$\ln$的凹凸性，证明对所有$a, b>0$有$\sqrt{ab}\le\dfrac{a+b}{2}$。
::: solution
在$(0,\infty)$上，$\ln''(x) = -1/x^2<0$，所以由[[#thm-concavity]]，$\ln$是上凸的，而$-\ln$是下凸的。取$t = \frac12$，对$-\ln$应用[[#exr-chords]]，得$-\ln\frac{a+b}{2}\le-\frac12\ln a - \frac12\ln b$，即

$$
\ln\frac{a+b}{2}\ge\frac{\ln a + \ln b}{2} = \ln\sqrt{ab}.
$$

由于$\exp$是递增的，$\frac{a+b}{2}\ge\sqrt{ab}$。
:::
:::

::: exercise 严格凸函数至多有一个最小值点 {level=3}
设$f$在$\R$上二阶可导，且对所有$x$有$f''(x) > 0$。证明$f$至多有一个临界点，并且若$c$是临界点，则$f(c)$是$f$的全局最小值。
::: solution
由于$f''>0$，导数$f'$在$\R$上严格递增（[[calculus-1/mean-value-theorem#thm-monotonicity]]），所以它至多取值$0$一次：$f$至多有一个临界点。（由于$f$处处可导，$f$的临界点必须满足$f'(c) = 0$。）若$f'(c) = 0$，则当$x<c$时$f'(x) < f'(c) = 0$，当$x>c$时$f'(x) > 0$。所以$f$在$(-\infty, c]$上严格递减，在$[c,\infty)$上严格递增，并且对每个$x\neq c$有$f(x)>f(c)$：$f(c)$是全局最小值。（像$e^x$这样的函数表明，临界点未必存在。）
:::
