一杯$90\,^\circ$C的咖啡放在$20\,^\circ$C的房间里。十分钟后它的温度是多少？在食物充足时，一个细菌群落每小时数量翻一番。一天之后它有多大？食物短缺时又会怎样？一块骨头所含的碳-14是动物死亡时的$30\%$。这块骨头有多少年了？

这些问题都没有直接给出未知量的公式。每个问题给出的是**关于未知量变化率的规律**：咖啡冷却的速率与它高出室温的温差成正比；群落增长的速率与它的大小成正比；碳-14衰变的速率与现存的量成正比。联系未知函数与其导数的方程称为**微分方程**，而微分方程正是书写物理、化学、生物和经济规律的语言。

本章只是初步介绍。我们将认识基本术语，学会通过斜率场**看出**解的样子，用欧拉（Euler）法近似求解，精确求解最重要的一类方程——可分离变量方程，并把这些结果应用于指数增长与衰减、牛顿（Newton）冷却定律以及人口增长的逻辑斯谛模型。系统的理论将在[[ode]]课程中展开。

## 微分方程及其解

::: definition 微分方程 {#def-ode}
关于未知函数$y(x)$的**常微分方程**（ODE）是含有$x$、$y$以及导数$y', y'', \dots$的方程。方程中出现的最高阶导数的阶数称为方程的**阶**。区间$I$上的**解**是这样一个函数$y$：它具有方程所要求的各阶导数，并且在$I$的每一点处都满足该方程。一阶**初值问题**（IVP）是指方程$y' = f(x, y)$连同**初始条件**$y(x_0) = y_0$。
:::

先看几个例子，它们展示了解的行为的多样性。

- $y' = 2x$：解就是原函数$y = x^2 + C$。积分是最简单的一类微分方程。
- $y' = y$：解为$y = Ce^x$（下文将给出证明）。这里导数依赖于未知函数本身。
- $y'' = -y$：解包括$\sin x$、$\cos x$以及一切组合$A\cos x + B\sin x$（这是一个二阶方程，在[[ode/second-order-linear]]一章中研究）。

像$y = x^2 + C$这样含有任意常数、能描述所有解的公式，称为**通解**；由初始条件确定常数，就得到一个**特解**。

::: example 验证解 {#ex-verify}
证明对每个常数$C$，$y = Ce^{-x^2}$都是$y' = -2xy$的解，并求满足$y(0) = 3$的解。
::: solution
由链式法则，对所有$x$，$y' = Ce^{-x^2}\cdot(-2x) = -2x\cdot Ce^{-x^2} = -2xy$。由初始条件得$3 = Ce^0 = C$，所以$y = 3e^{-x^2}$，这是一条钟形曲线。（验证一个给定的解只需要求导；难的是**求出**它。）
:::
:::

::: warning 解存在于一个区间上
方程$y' = y^2$满足$y(0) = 1$的解为$y = \frac{1}{1 - x}$，这可以通过求导来验证。这个解只在$x < 1$时存在：当$x \to 1^-$时，它**在有限时间内**爆破到无穷大，尽管方程本身看起来完全无害。公式$\frac{1}{1-x}$在$x > 1$上描述的是**另一个**解（例如满足$y(2) = -1$的那个解）；$y = \frac{1}{1-x}$的图像并不是“一个中间有缺口的解”。一定要说明解在哪个区间上成立。
:::

## 斜率场

即使不解方程$y' = f(x, y)$，我们也能看出它的解是什么样子。在每一点$(x, y)$处，方程规定了经过该点的任一解曲线的斜率$f(x, y)$。在网格的每一点处画一条具有该斜率的短线段，就得到**斜率场**（或方向场）。解曲线就是在其每一点处都与这个场相切的曲线——就像一片树叶随水流漂动。

::: example 解读斜率场 {#ex-slope-field}
画出$y' = x - y$的斜率场的草图，求出一个直线解，并描述所有解的长期行为。
::: solution
斜率沿每条直线$x - y = c$（**等斜线**）保持不变：在$y = x$上斜率为$0$，在$y = x - 1$上斜率为$1$，在$y = x + 1$上斜率为$-1$，依此类推。在直线$y = x - 1$上规定的斜率是$1$，这恰好也是该直线本身的斜率，所以$y = x - 1$是一个解：确实，$y' = 1 = x - (x - 1)$。

在这条直线上方，$x - y < 1$，所以解曲线没有这条直线陡；在它下方，解曲线则比它陡；无论哪种情形，解曲线都趋近于它。事实上，对每个$C$，$y = x - 1 + Ce^{-x}$都是解（验证：$y' = 1 - Ce^{-x}$，$x - y = 1 - Ce^{-x}$），而当$x \to\infty$时$Ce^{-x} \to 0$：每个解最终都与直线$y = x - 1$非常接近。
:::
:::

::: widget slopefield
f: x - y
x: -3, 4
y: -3, 4
points: -2, 3; -2, -2; 0, 2; 0, -1
caption: $y' = x - y$的斜率场以及四条解曲线。点击任意位置，即可从那里出发画出一条新的解曲线。无论从哪里出发，每条曲线都会弯向直线解$y = x - 1$，然后沿着它延伸——斜率场无须求解就展示了这一点。
:::

形如$y' = f(y)$、其中不显含$x$的方程称为**自治**方程。它的斜率场沿每条水平直线都相同，而$f$的每个零点$y^*$都给出一个常数解$y = y^*$，称为**平衡点**。在相邻的平衡点之间，解在$f(y) > 0$处递增，在$f(y) < 0$处递减，所以$f$的符号表就说明了全部的定性性质。

一个自然的问题是：斜率场会不会误导我们？两条解曲线会不会相交？经过某一点的解会不会不存在？这门学科的基本定理回答了这些问题。

::: theorem 存在唯一性定理 {#thm-picard}
设$f(x, y)$和$\dfrac{\partial f}{\partial y}(x, y)$在一个内部包含$(x_0, y_0)$的矩形上连续。则存在包含$x_0$的区间$I$，使得初值问题$y' = f(x, y)$，$y(x_0) = y_0$在$I$上恰有一个解。
:::

::: proof {collapsed}
**证明概要。**积分后可知，解等同于满足$y(x) = y_0 + \int_{x_0}^x f\bigl(t, y(t)\bigr)\,dt$的连续函数。从$y_0(x) = y_0$出发，定义**皮卡（Picard）迭代**$y_{n+1}(x) = y_0 + \int_{x_0}^x f\bigl(t, y_n(t)\bigr)\,dt$。由$\partial f/\partial y$的连续性可得一个界$\abs{f(t, u) - f(t, v)} \le L\abs{u - v}$（由中值定理），据此可以证明：在足够短的区间上，迭代序列一致收敛于一个解，并且任意两个解都相同。完整的证明见[[ode/existence-uniqueness]]一章。
:::

唯一性有一个生动的几何意义：**这类方程的解曲线永远不会相交或相接触**，因为在公共点处，两者都是同一个初值问题的解。例如，$y' = x - y$的一个从直线$y = x - 1$上方出发的解，会永远停留在这条直线的上方。

关于$\partial f/\partial y$的假设不能去掉。对满足$y(0) = 0$的$y' = 3y^{2/3}$，$y = 0$和$y = x^3$都是解（验证：$(x^3)' = 3x^2 = 3(x^3)^{2/3}$），而这里$\partial f/\partial y = 2y^{-1/3}$在$y = 0$处没有定义。

### 欧拉法

斜率场提示了一种**计算**近似解的方法：从$(x_0, y_0)$出发，沿场在该点规定的方向走一小段距离$h$，在新的点处重新读出斜率，如此反复。

::: algorithm 欧拉法 {#alg-euler}
为了近似求解$y' = f(x, y)$，$y(x_0) = y_0$，选取步长$h > 0$，并对$n = 0, 1, 2, \dots$计算

$$
x_{n+1} = x_n + h, \qquad y_{n+1} = y_n + h\,f(x_n, y_n).
$$

则$y_n \approx y(x_n)$。
:::

每一步都用切线代替解曲线，所以每一步产生$h^2$阶的误差（泰勒定理，[[calculus-2/taylor-series#thm-taylor]]）；经过$1/h$步，这些误差累积起来，在固定的$x$处产生$h$阶的误差。对$y' = y$，$y(0) = 1$，该方法给出$y_{n+1} = (1 + h)y_n$，所以以步长$h = \frac1n$走$n$步后，在$x = 1$处得到$y_n = \left(1 + \frac1n\right)^n$——这正是[[calculus-2/sequences#ex-e]]中趋于$e$的数列：

| 步长$h$ | $0.5$ | $0.25$ | $0.1$ | $0.01$ |
|---|---|---|---|---|
| $x = 1$处的欧拉近似值 | $2.25$ | $2.441\,41$ | $2.593\,74$ | $2.704\,81$ |
| 误差$e - y$ | $0.468$ | $0.277$ | $0.125$ | $0.013\,5$ |

把$h$除以$10$，误差大约也除以$10$：误差与$h$成正比，这使得欧拉法简单但低效。好得多的方法将在[[numerical-analysis/numerical-odes]]一章中介绍。

::: widget odesolver
f: y
y0: 1
t: 0, 2
exact: exp(t)
h: 0.25
methods: euler
caption: 对$y' = y$，$y(0) = 1$应用欧拉法，并与精确解$e^t$作比较。每一步都沿着经过当前点的那个解的切线前进，所以折线越来越低于下凸的指数曲线。把步长减半：$t = 2$处的误差也大约减半——欧拉法具有一阶精度。
:::

## 可分离变量方程

大多数微分方程无法用公式求解。可以这样求解的一类重要方程是可分离变量方程，其中的变量可以分别移到等式的两边。

::: definition 可分离变量方程 {#def-separable}
如果一阶方程可以写成

$$
\frac{dy}{dx} = g(x)\,h(y)
$$

的形式，其中$g$是只含$x$的函数，$h$是只含$y$的函数，就称它是**可分离变量**的。
:::

例如，$y' = xy^2$、$y' = \frac{x}{y}$和$y' = ky$都是可分离变量的；$y' = x + y$则不是。非正式的做法是“分离变量，然后积分”：

$$
\frac{dy}{h(y)} = g(x)\,dx \quad\Longrightarrow\quad \int\frac{dy}{h(y)} = \int g(x)\,dx .
$$

把$dy$和$dx$当作数来运算需要理由，而链式法则提供了这个理由。

::: theorem 可分离变量方程的解法 {#thm-separable}
设$g$在区间$I$上连续，$h$在区间$J$上连续且不为零。设$G$是$g$的一个原函数，$H$是$\frac1h$的一个原函数。则可微函数$y\colon I \to J$是$y' = g(x)h(y)$的解，当且仅当存在常数$C$，使得

$$
H\bigl(y(x)\bigr) = G(x) + C \qquad\text{对所有 } x \in I
$$ {#eq-separable}

此外，$h$的每个零点$y^*$都给出一个常数解$y = y^*$。
:::

::: proof
由于$h(y(x)) \ne 0$，方程$y'(x) = g(x)h(y(x))$等价于$\dfrac{y'(x)}{h(y(x))} = g(x)$。由链式法则，左边等于$\dfrac{d}{dx}H\bigl(y(x)\bigr)$。所以$y$是解当且仅当在$I$上$\frac{d}{dx}\bigl[H(y(x)) - G(x)\bigr] = 0$，而由中值定理，这当且仅当$H(y(x)) - G(x)$为常数时成立。最后，若$h(y^*) = 0$，则常数函数$y = y^*$满足$y' = 0 = g(x)h(y^*)$。
:::

关系式[[#eq-separable]]**隐式地**确定了$y$；由于$H' = 1/h$在$J$上处处不为零，$H$严格单调，因而可以求逆（至少在原则上如此），从而显式地给出$y$。

::: example 解会爆破的可分离变量方程 {#ex-separable}
求解$y' = xy^2$，$y(0) = 1$，并求解存在的最大区间。
::: solution
这里$g(x) = x$，$h(y) = y^2$，当$y \ne 0$时它不为零。分离变量，得

$$
\int\frac{dy}{y^2} = \int x\,dx \quad\Longrightarrow\quad -\frac1y = \frac{x^2}{2} + C .
$$

在$x = 0$处$y = 1$：$-1 = C$。所以$\frac1y = 1 - \frac{x^2}{2} = \frac{2 - x^2}{2}$，从而

$$
y = \frac{2}{2 - x^2}.
$$

解必须在一个包含$0$的区间上可微，而该公式在$x = \pm\sqrt2$处爆破，所以解恰好在$(-\sqrt2, \sqrt2)$上存在。验证：$y' = \frac{4x}{(2 - x^2)^2} = x\left(\frac{2}{2-x^2}\right)^2 = xy^2$。（平衡点$y = 0$是满足$y(0) = 0$的解；由唯一性，其他解都不可能与它相接触。）
:::
:::

::: warning 不要丢掉常数解
只有在$h(y) \ne 0$处才能除以$h(y)$。满足$h(y^*) = 0$的常数解$y = y^*$很容易丢掉，而它们往往恰恰是最重要的解——模型的平衡点。另外，积分常数要**在积分的那一刻**加上：先写出$-\frac1y = \frac{x^2}{2}$，到最后才在最终公式上“加上$C$”（$y = \frac{-2}{x^2} + C$），会得到错误的答案。
:::

::: quiz
下列哪些方程是可分离变量的？（选出所有符合条件的选项。）
- [x] $y' = e^{x + y}$
- [ ] $y' = x + y$
- [x] $y' = \dfrac{\sin x}{y^2 + 1}$
- [x] $y' = y(1 - y)$
::: solution
$e^{x+y} = e^x\cdot e^y$可以分离。$\frac{\sin x}{y^2+1} = \sin x\cdot\frac{1}{y^2+1}$可以分离。$y(1 - y)$只依赖于$y$（取$g(x) = 1$），因此每个自治方程都是可分离变量的。但$x + y$不能写成乘积$g(x)h(y)$：这是一个**线性**方程，将在[[ode/first-order]]一章中用积分因子求解。
:::
:::

## 指数增长与衰减

最简单也最重要的微分方程是说：一个量的变化率与它的大小成正比：

$$
\frac{dy}{dt} = ky .
$$ {#eq-exp-growth}

当$k > 0$时，它描述不受限制的增长（资源无限时的种群、复利、链式反应）；当$k < 0$时，它描述衰减（放射性原子核、药物浓度、放电中的电容器）。按分离变量的做法可以得到$\ln\abs y = kt + C$，但当$y$可能为零时，除以$y$是靠不住的；直接论证更为简洁，并且能证明不存在其他解。

::: theorem 方程 y′ = ky 的解 {#thm-exp-growth}
设$k$为常数，则$y' = ky$在$\R$上的解恰好是函数$y(t) = Ce^{kt}$，$C \in \R$。满足$y(0) = y_0$的解是$y = y_0e^{kt}$。
:::

::: proof
每个$Ce^{kt}$都是解，因为$\frac{d}{dt}Ce^{kt} = kCe^{kt}$。反过来，设$y$是任意一个解，令$u(t) = y(t)e^{-kt}$。则

$$
u'(t) = y'(t)e^{-kt} - ky(t)e^{-kt} = \bigl(y'(t) - ky(t)\bigr)e^{-kt} = 0 ,
$$

所以由中值定理，$u$是常数$C$，从而$y = Ce^{kt}$。令$t = 0$得$C = y_0$。
:::

对于衰减（$k < 0$），**半衰期**$T_{1/2}$是该量减半所需的时间：由$e^{kT_{1/2}} = \frac12$得$T_{1/2} = \frac{\ln 2}{\abs k}$。对于增长，**倍增时间**为$\frac{\ln2}{k}$。两者都与初始量无关——这是指数行为的标志。

::: example 放射性碳定年 {#ex-carbon}
碳-14的半衰期为$5730$年。一块骨头所含的碳-14是活体组织的$30\%$。估计它的年龄。
::: solution
碳-14的量满足$N = N_0e^{kt}$，其中$k = -\frac{\ln2}{5730}$。我们需要$e^{kt} = 0.3$，所以

$$
t = \frac{\ln 0.3}{k} = \frac{5730\,\ln(1/0.3)}{\ln2} = \frac{5730\times1.2040}{0.6931} \approx 9950 \text{ 年}.
$$

（实际的放射性碳年代还要再经过校准，因为大气中碳-14的比例随时间并非严格不变。）
:::
:::

**牛顿冷却定律**是说：物体冷却的速率与它的温度$T$和环境温度$T_a$之差成正比：$T' = -k(T - T_a)$，其中$k > 0$。代换$u = T - T_a$把它化为$u' = -ku$，所以由[[#thm-exp-growth]]，

$$
T(t) = T_a + (T_0 - T_a)e^{-kt}.
$$ {#eq-cooling}

::: example 一杯逐渐冷却的咖啡 {#ex-coffee}
把$90\,^\circ$C的咖啡放在$20\,^\circ$C的房间里。$5$分钟后它的温度为$70\,^\circ$C。什么时候它会降到$50\,^\circ$C？
::: solution
由[[#eq-cooling]]，$T(t) = 20 + 70e^{-kt}$。由$T(5) = 70$得$70e^{-5k} = 50$，所以$k = \frac15\ln\frac75 \approx 0.0673$（每分钟）。于是$T(t) = 50$要求$70e^{-kt} = 30$，所以

$$
t = \frac{\ln(7/3)}{k} = \frac{5\ln(7/3)}{\ln(7/5)} \approx 12.6 \text{ 分钟}.
$$

注意，最初降温$20$度用了$5$分钟，而接下来的$20$度大约要用$7.6$分钟：咖啡的温度越接近室温，冷却得就越慢。
:::
:::

## 逻辑斯谛模型

指数增长不可能持续下去：没有哪个种群能永远增长。1838年，韦吕勒（Verhulst）提出：当种群数量$P$趋近于由可用资源决定的**环境容纳量**$K$时，人均增长率应当线性地减小：

$$
\frac{dP}{dt} = rP\left(1 - \frac PK\right), \qquad r > 0,\; K > 0 .
$$ {#eq-logistic}

当$P$比$K$小得多时，因子$1 - P/K$接近$1$，增长近似于增长率为$r$的指数增长。当$P$趋近于$K$时，增长放缓；而若$P > K$，种群数量就会减少。

**定性分析。**这是一个自治方程，$f(P) = rP(1 - P/K)$。它的平衡点为$P = 0$和$P = K$。当$0 < P < K$时，$f(P) > 0$，所以解递增；当$P > K$时，$f(P) < 0$，所以解递减。$K$附近的解向$K$靠拢——$K$是**稳定**的平衡点；而$0$附近（且$P > 0$）的解则远离$0$——$0$是**不稳定**的。此外，

$$
\frac{d^2P}{dt^2} = f'(P)\frac{dP}{dt} = r\left(1 - \frac{2P}{K}\right)f(P),
$$

所以当$0 < P < K$时，$P(t)$的图像在$P < \frac K2$时是下凸的，此后是上凸的：种群数量达到环境容纳量的一半时增长最快。这就是著名的S形（sigmoid）曲线。

::: widget slopefield
f: y*(1 - y)
x: 0, 10
y: -0.3, 1.6
points: 0, 0.05; 0, 0.3; 0, 1.5; 0, 0.7
caption: 逻辑斯谛方程$y' = y(1-y)$（$r = 1$，$K = 1$）。从$0$与$\frac12$之间出发的解沿S形曲线上升到稳定平衡点$y = 1$，在穿过$y = \frac12$处最陡；从$\frac12$与$1$之间出发的解始终是上凸的；位于$1$上方的解下降并趋于$1$。在$y = 0$下方点击，可以看到远离不稳定平衡点$y = 0$的那些（在生物学上没有意义的）解。
:::

::: theorem 逻辑斯谛方程的解 {#thm-logistic}
对$P(0) = P_0 > 0$，[[#eq-logistic]]的解为

$$
P(t) = \frac{K}{1 + A e^{-rt}}, \qquad A = \frac{K - P_0}{P_0},
$$ {#eq-logistic-solution}

它对所有$t \ge 0$都有定义，并且当$t \to \infty$时$P(t) \to K$。
:::

::: proof
若$P_0 = K$，则$A = 0$，$P \equiv K$，即平衡解。否则解永远不取值$0$或$K$（由唯一性，[[#thm-picard]]：它不能与平衡解相遇），所以由[[#thm-separable]]，它满足$\int\frac{dP}{P(1 - P/K)} = \int r\,dt$。由部分分式分解，$\frac{1}{P(1 - P/K)} = \frac{K}{P(K - P)} = \frac1P + \frac{1}{K - P}$，所以

$$
\ln\abs{P} - \ln\abs{K - P} = rt + C, \qquad\text{即}\qquad \abs{\frac{K - P}{P}} = e^{-C}e^{-rt}.
$$

量$\frac{K - P}{P}$连续且永不为零，所以它保持定号，其符号与$t = 0$时的符号相同。因此$\frac{K - P}{P} = Ae^{-rt}$，其中$A = \frac{K - P_0}{P_0}$，解出$P$即得[[#eq-logistic-solution]]。由于$P_0 > 0$，有$A > -1$，所以对所有$t \ge 0$都有$1 + Ae^{-rt} > 0$，公式在那里有定义；当$t \to\infty$时，$Ae^{-rt} \to 0$，$P(t) \to K$。
:::

::: example 一个逻辑斯谛种群 {#ex-logistic}
某种群的环境容纳量为$K = 1000$，增长率为每年$r = 0.5$，初始数量为$P_0 = 100$。它何时达到$500$？何时达到$900$？
::: solution
这里$A = \frac{1000 - 100}{100} = 9$，所以$P(t) = \dfrac{1000}{1 + 9e^{-0.5t}}$。$P = 500$要求$1 + 9e^{-0.5t} = 2$，即$e^{-0.5t} = \frac19$，所以$t = 2\ln9 \approx 4.39$年。这就是拐点，此时增长最快。$P = 900$要求$1 + 9e^{-0.5t} = \frac{10}{9}$，即$e^{-0.5t} = \frac1{81}$，所以$t = 2\ln 81 \approx 8.79$年——恰好是前者的两倍，这源于S形曲线关于其拐点的对称性。
:::
:::

::: quiz
对自治方程$y' = y(y - 2)$，下列哪个说法是正确的？
- [ ] 平衡点$y = 0$和$y = 2$都是稳定的。
- [x] $y = 0$是稳定的，$y = 2$是不稳定的。
- [ ] $y = 0$是不稳定的，$y = 2$是稳定的。
- [ ] 从$y(0) = 1$出发的解递增趋于$2$。
::: solution
$f(y) = y(y-2)$的符号表：当$y < 0$时为正，当$0 < y < 2$时为负，当$y > 2$时为正。所以略低于$0$的解递增趋于$0$，而介于$0$与$2$之间的解递减趋于$0$：$y = 0$从两侧吸引解（稳定）。在$2$附近，下方的解递减而远离$2$，上方的解递增而远离$2$：不稳定。满足$y(0) = 1$的解递减趋于$0$。
:::
:::

::: application 生物学之外的逻辑斯谛曲线
只要增长既与已经发生的量成正比、又与剩余的量成正比，就会出现逻辑斯谛方程。在最简单的流行病模型中，新感染的速率与感染者$I$和易感者$N - I$之间的接触次数成正比，由此得到$I' = \beta I(N - I)$，这是一个逻辑斯谛方程。同样的S形曲线也描述了谣言的传播和新技术的普及，而逻辑斯谛函数$\frac{1}{1 + e^{-z}}$是统计学中逻辑斯谛回归以及神经网络中激活函数的基础。1920年，雷蒙德·珀尔（Raymond Pearl）和洛厄尔·里德（Lowell Reed）用一条逻辑斯谛曲线拟合了美国的人口；这样的拟合在有限的时期内是有效的，但现实中的环境容纳量会随技术而变化。
:::

::: history
微分方程与微积分同时诞生：牛顿（Newton）在《流数法》（*Method of Fluxions*，1671年写成）中对一阶方程进行了分类，莱布尼茨（Leibniz）则在1691年发现了分离变量法。牛顿冷却定律于1701年以匿名方式发表在《哲学汇刊》（*Philosophical Transactions*）上。莱昂哈德·欧拉（Leonhard Euler）在《积分学原理》（*Institutiones calculi integralis*，1768年）中描述了以他的名字命名的数值方法。托马斯·马尔萨斯（Thomas Malthus）在1798年论证说，人口按几何级数增长，而食物供给则不然；皮埃尔-弗朗索瓦·韦吕勒（Pierre-François Verhulst）在1838年以逻辑斯谛方程作出了回应，但这个方程在很大程度上被人遗忘，直到1920年才被珀尔（Pearl）和里德（Reed）重新发现。放射性碳定年法由威拉德·利比（Willard Libby）在20世纪40年代末发展起来，他因此获得了1960年的诺贝尔化学奖。
:::

## 后续内容

[[ode]]课程将系统地展开这门学科：一阶线性方程与积分因子（[[ode/first-order]]），存在唯一性定理及其证明（[[ode/existence-uniqueness]]），描述振动的二阶线性方程（[[ode/second-order-linear]]），以及方程组——在那里，逻辑斯谛模型发展为捕食者-食饵模型和竞争模型（[[ode/nonlinear-systems]]）。欧拉法是[[numerical-analysis/numerical-odes]]一章中的第一个数值方法，在那里，龙格-库塔（Runge–Kutta）法把误差从$h$阶降低到$h^4$阶。未知函数依赖于多个变量的方程（例如热方程）是偏微分方程（[[pde/heat-equation]]）。

::: summary
- 微分方程把一个函数与它的导数联系起来；解必须在一个区间上满足方程，而初始条件从解族中挑出一个解。
- $y' = f(x, y)$的斜率场无须求解就能显示解曲线；在较弱的条件下，解存在且唯一，所以解曲线永不相交。
- 欧拉法$y_{n+1} = y_n + hf(x_n, y_n)$沿着斜率场一步步前进；它在固定点处的误差与$h$成正比。
- 可分离变量方程$y' = g(x)h(y)$由$\int\frac{dy}{h(y)} = \int g(x)\,dx$求解；不要丢掉$h(y) = 0$处的常数解。
- $y' = ky$的解恰好是$y = Ce^{kt}$；半衰期和倍增时间为$\ln 2/\abs k$。牛顿冷却定律可以化为这个方程。
- 逻辑斯谛方程$P' = rP(1 - P/K)$的解$\frac{K}{1 + Ae^{-rt}}$呈S形，趋于稳定平衡点$K$，并在$P = K/2$处增长最快。
:::

## 习题

::: exercise 验证解 {level=1}
证明对所有常数$A$、$B$，$y = A\cos 2x + B\sin 2x$都是$y'' + 4y = 0$的解，并求满足$y(0) = 1$，$y'(0) = 4$的解。
::: solution
$y' = -2A\sin 2x + 2B\cos2x$，$y'' = -4A\cos2x - 4B\sin2x = -4y$，所以$y'' + 4y = 0$。由$y(0) = A = 1$和$y'(0) = 2B = 4$得$B = 2$：$y = \cos 2x + 2\sin 2x$。
:::
:::

::: exercise 指数增长 {level=1 check="2*e^3"}
求解$y' = 3y$，$y(0) = 2$，并给出$y(1)$。
::: solution
由[[#thm-exp-growth]]，$y = 2e^{3t}$，所以$y(1) = 2e^3 \approx 40.17$。
:::

::: exercise 求半衰期 {level=1 check="ln(2)/ln(10/9)"}
某种物质每年损失其质量的$10\%$。求它的半衰期（以年为单位）。
::: solution
$t$年后质量为$m_0(0.9)^t = m_0e^{t\ln0.9}$，所以$k = \ln 0.9$，半衰期为$\frac{\ln2}{\abs k} = \frac{\ln 2}{\ln(10/9)} \approx 6.58$年。
:::
:::

::: exercise 正切函数解 {level=2}
求解$y' = 1 + y^2$，$y(0) = 0$，并求解存在的最大区间。
::: solution
这是可分离变量方程，$h(y) = 1 + y^2 \ne 0$：由$\int\frac{dy}{1+y^2} = \int dx$得$\arctan y = x + C$，由$y(0) = 0$得$C = 0$。所以$\arctan y = x$，这要求$-\frac\pi2 < x < \frac\pi2$，于是$y = \tan x$。解在$x = \pm\frac\pi2$处爆破，所以它存在的最大区间是$\left(-\frac\pi2, \frac\pi2\right)$——尽管$1 + y^2$处处有定义且光滑。
:::
:::

::: exercise 混合罐 {level=2 check="20*exp(-1/2)"}
一个罐中装有$100$升盐水，其中溶有$20$ kg盐。纯水以每分钟$5$升的速率流入，充分搅拌后的混合液以同样的速率流出。$10$分钟后罐中有多少盐？
::: solution
设$S(t)$为罐中盐的量（单位：kg）。浓度为每升$\frac{S}{100}$ kg，盐以每分钟$5\cdot\frac{S}{100} = \frac{S}{20}$ kg的速率流出，而没有盐流入。所以$S' = -\frac{1}{20}S$，$S(0) = 20$，从而$S(t) = 20e^{-t/20}$。$10$分钟后$S = 20e^{-1/2} \approx 12.13$ kg。
:::
:::

::: exercise 拟合逻辑斯谛模型 {level=2 check="2*ln(9)/ln(9/4)"}
某种群服从环境容纳量为$500$的逻辑斯谛方程。它的初始数量为$50$，$2$年后为$100$。它何时达到$250$？
::: solution
由$K = 500$，$P_0 = 50$得$A = \frac{450}{50} = 9$，$P(t) = \frac{500}{1 + 9e^{-rt}}$。由$P(2) = 100$得$1 + 9e^{-2r} = 5$，所以$e^{-2r} = \frac49$，$r = \frac12\ln\frac94 \approx 0.405$。于是当$9e^{-rt} = 1$，即$t = \frac{\ln 9}{r} = \frac{2\ln9}{\ln(9/4)} \approx 5.42$年时，$P = 250$。
:::
:::

::: exercise 手算欧拉法 {level=2}
对$y' = y$，$y(0) = 1$应用步长$h = 0.25$的欧拉法来估计$y(1)$。与$e$作比较，并解释为什么估计值偏小。
::: solution
每一步都乘以$1 + h = 1.25$：$y_1 = 1.25$，$y_2 = 1.5625$，$y_3 = 1.953\,125$，$y_4 = 2.441\,406$。真值为$e \approx 2.718\,28$，所以误差约为$0.277$。估计值偏小，是因为解$e^t$是下凸的：每条切线都位于曲线的**下方**，所以每一步都走得不够高，而这些不足会累积起来。
:::
:::

::: exercise 解不唯一 {level=3}
证明初值问题$y' = 2\sqrt{\abs y}$，$y(0) = 0$在$\R$上有无穷多个解。[[#thm-picard]]的哪个假设不成立？
::: hint
对每个$c \ge 0$，考虑在$x \le c$时等于$0$、在$x > c$时等于$(x - c)^2$的函数。
:::
::: solution
对$c \ge 0$，令当$x \le c$时$y_c(x) = 0$，当$x > c$时$y_c(x) = (x - c)^2$。当$x < c$时，$y_c' = 0 = 2\sqrt{0}$。当$x > c$时，由于$x - c > 0$，$y_c' = 2(x - c) = 2\sqrt{(x - c)^2} = 2\sqrt{\abs{y_c}}$。在$x = c$处，两个单侧差商都趋于$0$（右侧差商为$\frac{h^2}{h} = h \to 0$），所以$y_c'(c) = 0 = 2\sqrt{\abs{y_c(c)}}$。因此每个$y_c$都是满足$y_c(0) = 0$的解，而不同的$c$给出不同的函数。函数$f(x, y) = 2\sqrt{\abs y}$是连续的，但$\frac{\partial f}{\partial y} = \frac{\operatorname{sgn}(y)}{\sqrt{\abs y}}$在$y = 0$处无界（并且没有定义），所以唯一性的假设恰好沿着解$y = 0$不成立。
:::
:::

::: exercise 逻辑斯谛曲线的拐点 {level=3}
设$0 < P_0 < \frac K2$。只利用[[#eq-logistic]]（而不用解的公式），证明：解是递增的；当$P < \frac K2$时它是下凸的，一旦$P > \frac K2$它就是上凸的；并且它的最大增长率为$\frac{rK}{4}$。
::: solution
解永远不会到达平衡点$0$或$K$（由唯一性，解曲线不能相遇），所以对所有$t \ge 0$都有$0 < P(t) < K$，从而$P' = rP(1 - P/K) > 0$：$P$是递增的。用链式法则对方程求导，得

$$
P'' = r\left(1 - \frac{2P}{K}\right)P',
$$

由于$P' > 0$，$P''$的符号与$1 - \frac{2P}{K}$的符号相同：当$P < \frac K2$时为正（下凸），当$P > \frac K2$时为负（上凸）。增长率$P' = f(P) = rP - \frac{r}{K}P^2$是$P$的一条开口向下的抛物线，其最大值为$f\left(\frac K2\right) = r\cdot\frac K2\cdot\frac12 = \frac{rK}{4}$，所以总有$P' \le \frac{rK}{4}$。

还需证明解确实能达到$P = \frac K2$，从而上凸阶段确实会出现，最大增长率也确实能取到。由于$P$递增且以$K$为上界，当$t \to\infty$时它有极限$L \le K$（[[calculus-2/sequences#thm-mct]]同样适用于$t$的函数）。若$L < K$，则对所有$t \ge 0$，$P(t)$的值都在$[P_0, L]$中，而$f$在该区间上有正的最小值$m$；所以$P' \ge m$，$P(t) \ge P_0 + mt \to \infty$，矛盾。因此$L = K > \frac K2$，由介值定理，在某个时刻$t_*$有$P(t_*) = \frac K2$，此时$P'(t_*) = \frac{rK}{4}$：曲线在$t_*$之前是下凸的，在$t_*$之后是上凸的。
:::
:::

::: exercise 欧拉法对 y′ = y 收敛 {level=3}
对$y' = y$，$y(0) = 1$，设$E_n$是取$h = \frac1n$时欧拉法给出的$y(1)$的近似值。证明$E_n = \left(1 + \frac1n\right)^n$，并且$0 < e - E_n < \frac{e}{2n}$。
::: hint
利用当$u > 0$时$\ln(1 + u) > u - \frac{u^2}{2}$，以及当$v > 0$时$1 - e^{-v} < v$。
:::
::: solution
欧拉法的每一步给出$y_{k+1} = y_k + hy_k = (1 + h)y_k$，所以$n$步之后$E_n = (1 + \frac1n)^n$。由$\ln(1+u) < u$得$E_n = e^{n\ln(1 + 1/n)} < e^{1} = e$。对于另一个界，当$u > 0$时$\ln(1 + u) > u - \frac{u^2}{2}$（两者之差的导数为$\frac{1}{1+u} - 1 + u = \frac{u^2}{1+u} > 0$，且该差在$0$处为零），所以取$u = \frac1n$，得$n\ln\left(1 + \frac1n\right) > 1 - \frac{1}{2n}$。因此$E_n > e^{1 - 1/(2n)} = e\cdot e^{-1/(2n)}$，从而

$$
e - E_n < e\left(1 - e^{-1/(2n)}\right) < e\cdot\frac{1}{2n},
$$

这里用到了$1 - e^{-v} < v$。所以在这里，欧拉法的误差小于$\frac{e}{2n} = \frac{e}{2}h$：与步长成正比，正如正文中所说的那样。
:::
:::
