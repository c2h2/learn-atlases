在一个简单的天气模型中，每一天要么是晴天，要么是雨天。晴天之后的一天仍是晴天的概率为$0.9$，雨天之后的一天仍是雨天的概率为$0.5$。今天在下雨。三天后是晴天的概率有多大？从长期看，晴天所占的比例是多少？答案分别是$0.78$和$\tfrac56$，而且第二个答案与今天的天气完全无关：初始状态的影响以几何速度迅速消退。

这就是一条**马尔可夫链**：在这种随机过程中，未来只通过现在依赖于过去。马尔可夫链是随时间随机演化的最简单的模型，它们无处不在：排队、遗传学、洗牌、棋盘游戏、网页排序、语音识别，以及驱动现代贝叶斯统计的马尔可夫链蒙特卡罗算法。本章对具有有限个或可数个状态的链建立基本理论：转移矩阵及其幂、用首步分析求吸收概率、状态的分类、平稳分布，以及收敛定理——它解释了为什么长期行为会忘记起点。线性代数，特别是特征值（[[linear-algebra/eigenvalues]]），将始终伴随着我们。

## 马尔可夫性 {#markov-property}

::: definition 马尔可夫链 {#def-markov-chain}
设$S$是一个有限集或可数集，称为**状态空间**。称取值于$S$的随机变量序列$X_0, X_1, X_2,\ldots$是以$P = (p_{ij})_{i,j\in S}$为**转移矩阵**的（时齐）**马尔可夫链**，如果

$$
\Prob(X_{n+1} = j\mid X_n = i,\ X_{n-1} = i_{n-1},\ \ldots,\ X_0 = i_0) = p_{ij}
$$ {#eq-markov-property}

对所有$n\ge0$以及使条件事件的概率为正的所有状态$i_0,\ldots,i_{n-1},i,j$都成立。$X_0$的分布称为**初始分布**。
:::

这个定义式说了两件事。第一是**马尔可夫性**：给定现在的状态$X_n = i$，过去的状态$X_0,\ldots,X_{n-1}$不再提供关于下一个状态的任何信息。第二是**时齐性**：转移概率$p_{ij}$不依赖于$n$。$P$的每一行都是一个概率分布（从$i$出发时下一个状态的分布），所以

$$
p_{ij}\ge0,\qquad\sum_{j\in S}p_{ij} = 1\quad\text{对每个 } i .
$$

具有这些性质的矩阵称为**随机矩阵**。一条链可以方便地画成**转移图**：这是一个有向图，只要$p_{ij}>0$，就画一条从$i$指向$j$的箭头$i\to j$，并标上$p_{ij}$。

一些标准的例子：

- **天气。**$S = \{\text{晴},\text{雨}\}$，$P = \begin{pmatrix}0.9 & 0.1\\ 0.5 & 0.5\end{pmatrix}$。
- **赌徒破产。**一个持有$\pounds i$的赌徒每次下注$\pounds1$，以概率$p$赢、以概率$q = 1-p$输，直到资金变为$\pounds0$或达到目标$\pounds N$为止。于是$S = \{0,1,\ldots,N\}$，当$0<i<N$时$p_{i,i+1} = p$，$p_{i,i-1} = q$，且$p_{00} = p_{NN} = 1$：状态$0$和$N$是**吸收态**。
- **图上的随机游动。**从连通图的一个顶点出发，移动到均匀随机选取的一个相邻顶点：若$vw$是一条边，则$p_{vw} = 1/\deg(v)$（[[discrete/graphs]]）。
- **$\Z$上的简单随机游动。**对每个整数$i$，$p_{i,i+1} = p$，$p_{i,i-1} = q$：这是一个无限的状态空间。

转移矩阵和初始分布决定了链的一切。

::: proposition 路径概率 {#prop-paths}
若$(X_n)$是初始分布为$\lambda$、转移矩阵为$P$的马尔可夫链，则对所有状态$i_0,\ldots,i_n$，

$$
\Prob(X_0 = i_0, X_1 = i_1, \ldots, X_n = i_n) = \lambda_{i_0}\,p_{i_0i_1}\,p_{i_1i_2}\cdots p_{i_{n-1}i_n}.
$$
:::

::: proof
由乘法公式（[[probability/conditional-probability#thm-chain-rule]]），左边等于

$$
\Prob(X_0 = i_0)\,\Prob(X_1 = i_1\mid X_0 = i_0)\cdots\Prob(X_n = i_n\mid X_{n-1} = i_{n-1},\ldots,X_0 = i_0),
$$

而由马尔可夫性，第一个因子之后的每个因子都是一个转移概率$p_{i_{k-1}i_k}$。（若某个条件事件的概率为零，则两边都为零。）
:::

::: quiz
下列矩阵中，哪一个是两状态马尔可夫链的转移矩阵？
- [ ] $\begin{pmatrix}0.5 & 0.5\\ 0.5 & 0.6\end{pmatrix}$
- [x] $\begin{pmatrix}0 & 1\\ 1 & 0\end{pmatrix}$
- [ ] $\begin{pmatrix}0.3 & 0.7\\ 0.7 & 0.4\end{pmatrix}$
- [ ] $\begin{pmatrix}0.2 & 0.8\\ -0.1 & 1.1\end{pmatrix}$
::: solution
转移矩阵要求元素非负，且每行之和为$1$。只有第二个符合要求：它描述的是一条在两个状态之间确定性地来回交替的链。第一个和第三个都有一行之和为$1.1$，第四个有一个负元素（列和不必为$1$）。
:::
:::

::: warning 马尔可夫性不是独立性
马尔可夫链的相继状态通常是强相依的：明天的天气依赖于今天的天气。马尔可夫性说的是一件更弱也更有用的事——**给定现在**，未来与过去**条件**独立。如果你不知道今天的天气，那么得知前天下了雨，确实会改变明天下雨的概率；只有在今天的天气已知之后，更早的信息才变得无关紧要。一个实际过程是否具有这一性质，取决于状态中包含了什么：状态只是“晴”或“雨”的天气模型可能不满足它，而更丰富的状态（比如最近两天的天气）则可能使它重新成立。
:::

## 多步转移 {#n-step}

记$p_{ij}^{(n)} = \Prob(X_{m+n} = j\mid X_m = i)$为经$n$步从$i$到达$j$的概率。（由时齐性，它不依赖于$m$，下面的定理将说明这一点。）

::: theorem 查普曼-柯尔莫哥洛夫方程 {#thm-chapman-kolmogorov}
$n$步转移概率就是矩阵幂$P^n$的元素：

$$
p_{ij}^{(n)} = (P^n)_{ij},\qquad\text{从而}\qquad p_{ij}^{(m+n)} = \sum_{k\in S}p_{ik}^{(m)}p_{kj}^{(n)}.
$$

因此，若$\mu^{(n)}$表示$X_n$的分布（写成行向量），则$\mu^{(n)} = \mu^{(0)}P^n$。
:::

::: proof
对$n$用归纳法；$n = 1$的情形就是定义。假设对所有$m$、$i$、$k$都有$\Prob(X_{m+n} = k\mid X_m = i) = (P^n)_{ik}$。按时刻$m+n$的状态进行划分，并对条件概率测度$\Prob(\,\cdot\mid X_m = i)$应用全概率公式：

$$
\Prob(X_{m+n+1} = j\mid X_m = i) = \sum_k\Prob(X_{m+n} = k\mid X_m = i)\,\Prob(X_{m+n+1} = j\mid X_{m+n} = k, X_m = i).
$$

由马尔可夫性，最后一个因子为$p_{kj}$，所以这个和等于$\sum_k(P^n)_{ik}p_{kj} = (P^{n+1})_{ij}$。由恒等式$P^{m+n} = P^mP^n$即得第二个公式；而由全概率公式，$\mu^{(n)}_j = \sum_i\Prob(X_0 = i)p_{ij}^{(n)}$。
:::

因此，用马尔可夫链进行计算就是做矩阵乘法，而长期行为由幂$P^n$支配——这就引入了特征值。

::: example 两状态链 {#ex-two-state}
对$P = \begin{pmatrix}1-a & a\\ b & 1-b\end{pmatrix}$，其中$0<a+b<2$，求$P^n$及其极限，并把结果应用于天气链。
::: solution
各行之和为$1$，所以$P\mathbf{1} = \mathbf{1}$，$1$是一个特征值。迹为$2-a-b$，所以另一个特征值是$\lambda = 1-a-b$，且$\lvert\lambda\rvert<1$。把$P$对角化（[[linear-algebra/eigenvalues]]），或者用归纳法验证下面的公式，可得

$$
P^n = \frac{1}{a+b}\begin{pmatrix}b & a\\ b & a\end{pmatrix} + \frac{\lambda^n}{a+b}\begin{pmatrix}a & -a\\ -b & b\end{pmatrix}.
$$

当$n\to\infty$时$\lambda^n\to0$，所以$P^n$的两行都收敛于$\bigl(\frac{b}{a+b},\frac{a}{a+b}\bigr)$：无论从哪个状态出发，链最终处于状态$1$的概率都是$\frac{b}{a+b}$，而且收敛是几何式的，速率为$\lvert\lambda\rvert^n$。对于天气链，$a = 0.1$，$b = 0.5$，$\lambda = 0.4$，所以极限为$\bigl(\tfrac56,\tfrac16\bigr)$；从雨天出发，

$$
\Prob(\text{3天后晴}\mid\text{今天下雨}) = p_{21}^{(3)} = \frac56 - 0.4^3\cdot\frac{5}{6} = \frac56(1 - 0.064) = 0.78 .
$$
:::
:::

caption: 从雨天出发的天气链。柱形显示$X_n$的分布，它在几步之内就接近平稳分布$(\tfrac56,\tfrac16)$——差距每天按因子$0.4$缩小。下方模拟的游动显示的是一次实现：长时间的晴天被短暂的雨天打断。改变起点，可以看到极限是相同的。

## 吸收概率：赌徒破产问题 {#gamblers-ruin}

对于有吸收态的链，自然的问题是：链在哪里被吸收？需要多长时间？关键的技巧是已在[[probability/expectation]]一章中用过的**首步分析**：对第一步取条件，并利用马尔可夫性重新开始。

::: theorem 赌徒破产 {#thm-gamblers-ruin}
在$0<p<1$的赌徒破产链中，设$h_i$为从$i$出发、在到达$0$之前到达$N$的概率，并令$r = q/p$。则

$$
h_i = \begin{cases}\dfrac{1 - r^i}{1-r^N}, & p\ne\tfrac12,\\[2ex] \dfrac iN, & p = \tfrac12.\end{cases}
$$ {#eq-ruin}
:::

::: proof
显然$h_0 = 0$，$h_N = 1$。对$0<i<N$，对第一次下注取条件：链以概率$p$移到$i+1$，由马尔可夫性，此后在到达$0$之前到达$N$的概率为$h_{i+1}$；输的情形类似。由全概率公式，

$$
h_i = p\,h_{i+1} + q\,h_{i-1},\qquad 0<i<N .
$$

由于$p + q = 1$，上式可以改写为$p(h_{i+1} - h_i) = q(h_i - h_{i-1})$，所以差分$d_i = h_i - h_{i-1}$满足$d_{i+1} = r\,d_i$，从而$d_i = r^{i-1}d_1$，并且

$$
h_i = d_1 + d_2 + \dots + d_i = d_1(1 + r + \dots + r^{i-1}).
$$

条件$h_N = 1$确定了$d_1 = 1/(1 + r + \dots + r^{N-1})$。对几何级数求和，当$r\ne1$时得$h_i = (1 - r^i)/(1 - r^N)$，当$r = 1$即$p = \tfrac12$时得$h_i = i/N$。（这些方程唯一地确定了$h$，因为$h_0$和$d_1$确定了每一个$h_i$。）
:::

把$0$和$N$的角色互换，同样的论证表明破产的概率为$1 - h_i$——所以赌博以概率$1$结束；赌徒不可能永远玩下去。

::: example 玩轮盘赌 {#ex-roulette}
一个持有10英镑的赌徒在欧式轮盘赌上每次押1英镑于红色（赢的概率为$\tfrac{18}{37}$），直到资金翻倍或全部输光为止。求资金达到20英镑的概率，并与公平赌博作比较。
::: solution
这里$p = \tfrac{18}{37}$，$r = q/p = \tfrac{19}{18}$，$i = 10$，$N = 20$：

$$
h_{10} = \frac{1 - (19/18)^{10}}{1 - (19/18)^{20}} = \frac{1}{1 + (19/18)^{10}}\approx0.368 .
$$

（化简时用到了$1 - x^2 = (1-x)(1+x)$，其中$x = (19/18)^{10}$。）在公平赌博中，答案将是$\tfrac12$。每次下注的庄家优势不到$3\%$，但在所需的一长串下注中——平均约$98$次——它累积成了相当大的劣势。大胆策略，即在一次转盘中押上全部资金，成功的概率为$\tfrac{18}{37}\approx0.486$：面对不利的赌博，下注次数越少越好。
:::
:::

## 状态的分类 {#classification}

为了描述长期行为，我们首先需要知道哪些状态可以到达哪些状态。

::: definition 互通与不可约 {#def-communicate}
若对某个$n\ge0$有$p_{ij}^{(n)}>0$，则称状态$j$从$i$**可达**，记作$i\to j$。若$i\to j$且$j\to i$，则称状态$i$与$j$**互通**，记作$i\leftrightarrow j$。互通是一个等价关系（[[proofs/relations]]），它的等价类称为**互通类**。若链不能离开类$C$（即$i\in C$且$i\to j$蕴含$j\in C$），则称$C$是**闭**的。若只有一个类，即每个状态都可以到达其他每个状态，则称链是**不可约**的。
:::

在赌徒破产链中，$\{0\}$和$\{N\}$是闭类，而$\{1,\ldots,N-1\}$是一个不闭的类。天气链和连通图上的随机游动都是不可约的。

下一个区分是：链不断返回的状态与链最终会离弃的状态。设$T_i = \min\{n\ge1 : X_n = i\}$为首次返回$i$的时间（若不返回，则$T_i = \infty$）。

::: definition 常返与非常返 {#def-recurrent}
若$f_i = \Prob(T_i<\infty\mid X_0 = i) = 1$，则称状态$i$是**常返**的；若$f_i<1$，则称$i$是**非常返**（暂留）的。
:::

::: theorem 常返性判据 {#thm-recurrence}
状态$i$常返当且仅当$\displaystyle\sum_{n=1}^\infty p_{ii}^{(n)} = \infty$。
:::

::: proof
让链从$i$出发，设$V$为在时刻$n\ge1$访问$i$的次数。把$V$写成示性变量之和$V = \sum_{n\ge1}\mathbf{1}_{\{X_n = i\}}$，由期望的线性性（对非负项，无穷和也适用）得

$$
\E V = \sum_{n=1}^\infty p_{ii}^{(n)}.
$$

另一方面，由在（随机的）返回时刻应用的马尔可夫性——即**强马尔可夫性**，我们不加证明地使用它（见诺里斯（Norris）的《马尔可夫链》（Markov Chains）第1.4节）——链每次返回$i$时都重新开始。所以每次返回之后，以概率$f_i$还会再返回一次，且与过去独立，因而$\Prob(V\ge k) = f_i^k$。若$f_i<1$，则$\E V = \sum_{k\ge1}\Prob(V\ge k) = \frac{f_i}{1-f_i}<\infty$。若$f_i = 1$，则对每个$k$都有$\Prob(V\ge k) = 1$，所以以概率$1$有$V = \infty$，且$\E V = \infty$。
:::

常返性是一种**类性质**：若$i$常返且$i\leftrightarrow j$，则$j$也常返（取$a$、$b$使$p_{ji}^{(a)}>0$，$p_{ij}^{(b)}>0$；则$p_{jj}^{(a+n+b)}\ge p_{ji}^{(a)}p_{ii}^{(n)}p_{ij}^{(b)}$，所以$\sum_np_{jj}^{(n)} = \infty$也成立）。在**有限**链中，不可能所有状态都是非常返的——链总要在某处度过无穷长的时间，而非常返状态只被访问有限次——所以**有限不可约链的每个状态都是常返的**。

::: example 整数上的简单随机游动 {#ex-random-walk}
对$\Z$上的简单随机游动，证明：若$p = \tfrac12$，则状态$0$常返，否则非常返。
::: solution
只有经过偶数步、且向上与向下的步数相同时，才可能返回$0$：$p_{00}^{(2n)} = \binom{2n}{n}p^nq^n$。由斯特林公式，$\binom{2n}{n}\sim\frac{4^n}{\sqrt{\pi n}}$，所以

$$
p_{00}^{(2n)}\sim\frac{(4pq)^n}{\sqrt{\pi n}}.
$$

若$p = \tfrac12$，则$4pq = 1$，各项的性态如同$1/\sqrt{\pi n}$，其和发散（[[calculus-2/convergence-tests]]）：游动是常返的。若$p\ne\tfrac12$，则$4pq<1$，各项按几何速度衰减，和收敛，游动是非常返的——它漂向$\pm\infty$。乔治·波利亚（George Pólya）于1921年证明了：格点$\Z^d$上的对称随机游动当$d = 1, 2$时常返，当$d\ge3$时非常返：在平面网格上随机行走的人必定会回到家，而在三维空间中随机移动的人则可能永远游荡在外。
:::
:::

最后，有些链是循环运动的。状态$i$的**周期**为$d(i) = \gcd\{n\ge1 : p_{ii}^{(n)}>0\}$；若$d(i) = 1$，则称$i$是**非周期**的。周期也是类性质（见习题）。$P = \begin{pmatrix}0&1\\1&0\end{pmatrix}$的链周期为$2$，二部图上的任何随机游动也是如此；只要有一个状态满足$p_{ii}>0$，不可约链就是非周期的。

## 平稳分布 {#stationary}

如果$X_n$的分布趋于稳定，那么极限$\pi$在再走一步之后必定不变：$\pi = \pi P$。

::: definition 平稳分布 {#def-stationary}
称概率分布$\pi = (\pi_j)_{j\in S}$是$P$的**平稳分布**（或**不变分布**、**平衡分布**），如果

$$
\pi P = \pi,\qquad\text{即}\qquad\sum_{i\in S}\pi_ip_{ij} = \pi_j\ \text{ 对每个 } j .
$$ {#eq-stationary}
:::

若$X_0$的分布为$\pi$，则由于$\pi P^n = \pi$，每个$X_n$的分布也都是$\pi$。用线性代数的语言来说，$\pi$是$P$的属于特征值$1$的左特征向量，并经过归一化成为概率向量。方程[[#eq-stationary]]是一个**平衡方程**：在平衡状态下，一步之内流入$j$的概率等于处于$j$的概率。

::: warning 是左特征向量，不是右特征向量
由于分布写成**行**向量，平稳性条件$\pi P = \pi$说的是$\pi$是$P$的**左**特征向量，等价地，是转置矩阵$P\T$的普通特征向量。一个常见的失误是转而去解$P\mathbf v = \mathbf v$：由于每行之和为$1$，对每个随机矩阵，这个方程都有无用的解$\mathbf v = (1,\ldots,1)\T$。还要记住，$\pi$必须归一化，使其各分量之和为$1$；而采用列向量约定的软件，需要输入这里所写矩阵的转置。
:::

::: theorem 存在性与唯一性 {#thm-stationary-unique}
有限不可约马尔可夫链有唯一的平稳分布$\pi$。此外，对每个$j$都有$\pi_j>0$，且$\pi_j = 1/m_j$，其中$m_j = \E(T_j\mid X_0 = j)$是返回$j$的平均时间。
:::

::: proof
*证明概要。*存在性：从任一分布$\mu$出发，作平均$a_n = \frac1n\sum_{k=0}^{n-1}\mu P^k$。则$a_nP - a_n = \frac1n(\mu P^n - \mu)$，其各分量的绝对值至多为$\frac2n$。各$a_n$都属于概率向量的集合，而这个集合是$\R^{\lvert S\rvert}$中的有界闭集，所以有一个子列收敛于某个概率向量$\pi$（[[real-analysis/metric-spaces]]），取极限即得$\pi P = \pi$。正性：某个$\pi_i>0$；给定$j$，由不可约性，存在$n$使$p_{ij}^{(n)}>0$，于是$\pi_j = \sum_k\pi_kp_{kj}^{(n)}\ge\pi_ip_{ij}^{(n)}>0$。唯一性和公式$\pi_j = 1/m_j$可由下面的遍历定理得到（长期停留在$j$的时间比例既等于$\pi_j$，又等于$1/m_j$）；完整的证明见诺里斯的《马尔可夫链》定理1.7.7。另外，唯一性也是关于非负矩阵的佩龙-弗罗贝尼乌斯（Perron–Frobenius）定理的一部分。
:::

求解[[#eq-stationary]]是一个线性代数问题：共有$\lvert S\rvert$个方程，其中一个是多余的，再加上$\sum_j\pi_j = 1$。

::: example 更换网络 {#ex-networks}
每个月，手机用户按照下面的转移矩阵留在网络A、B、C中原来的那一个，或在它们之间更换：

$$
P = \begin{pmatrix}0.8 & 0.1 & 0.1\\ 0.2 & 0.7 & 0.1\\ 0.1 & 0.2 & 0.7\end{pmatrix}.
$$

求长期的市场份额。
::: solution
方程$\pi P = \pi$为

$$
\begin{aligned}
0.8\pi_A + 0.2\pi_B + 0.1\pi_C &= \pi_A,\\
0.1\pi_A + 0.7\pi_B + 0.2\pi_C &= \pi_B,\\
0.1\pi_A + 0.1\pi_B + 0.7\pi_C &= \pi_C .
\end{aligned}
$$

由第三个方程得$0.3\pi_C = 0.1(\pi_A + \pi_B)$，所以$\pi_A + \pi_B = 3\pi_C$；结合$\pi_A + \pi_B + \pi_C = 1$得$\pi_C = \tfrac14$。由第一个方程得$0.2\pi_A = 0.2\pi_B + 0.1\pi_C$，所以$\pi_A - \pi_B = \tfrac18$，再结合$\pi_A + \pi_B = \tfrac34$得$\pi_A = \tfrac{7}{16}$，$\pi_B = \tfrac{5}{16}$。所以从长期看，市场份额分别为$43.75\%$、$31.25\%$和$25\%$，而C的平均返回时间为$1/\pi_C = 4$个月：从C出发，链下一次回到C所需的期望月数为$4$（继续留在C的用户算作一个月后返回）。
:::
:::

::: widget markov
matrix: 0.8,0.1,0.1; 0.2,0.7,0.1; 0.1,0.2,0.7
states: A; B; C
start: 2
steps: 30
caption: 从一位使用C网络的用户出发的网络更换链。$X_n$的分布收敛于$(\tfrac{7}{16},\tfrac{5}{16},\tfrac14)$，比天气链慢，因为用户有“黏性”（对角元较大意味着特征值更接近$1$）。在模拟路径中数一数每个状态被访问的次数：其比例趋于同样的数值。
:::

借助一种更强的、局部形式的平衡，往往不必求解整个方程组就能找到平稳分布。

::: theorem 细致平衡 {#thm-detailed-balance}
若概率分布$\pi$对所有状态$i$、$j$都满足$\pi_ip_{ij} = \pi_jp_{ji}$，则$\pi$是平稳分布。（这时称链是**可逆**的。）
:::

::: proof
对每个$j$，$\sum_i\pi_ip_{ij} = \sum_i\pi_jp_{ji} = \pi_j\sum_ip_{ji} = \pi_j$，因为$P$的第$j$行之和为$1$。
:::

细致平衡是说，在平衡状态下，对每一对状态，从$i$到$j$的流量都等于从$j$到$i$的流量；这比[[#eq-stationary]]更强，后者只要求流入每个状态的总流量平衡。

::: example 图上的随机游动 {#ex-graph-walk}
对有$m$条边的连通图上的随机游动，证明$\pi_v = \deg(v)/(2m)$是平稳分布。
::: solution
各$\pi_v$都是正的，且和为$1$，因为各顶点的度之和为$2m$（每条边有两个端点）。若$vw$是一条边，则

$$
\pi_vp_{vw} = \frac{\deg(v)}{2m}\cdot\frac{1}{\deg(v)} = \frac{1}{2m} = \pi_wp_{wv},
$$

若$vw$不是边，则两边都为$0$。所以细致平衡成立，由[[#thm-detailed-balance]]，$\pi$是平稳分布。游动者在每个顶点停留的时间与该顶点的度成正比；返回$v$的平均时间为$2m/\deg(v)$。对于在国际象棋棋盘上随机移动的马，由此可知它返回一个角格的期望时间为$336/2 = 168$步（棋盘上共有$168$条马步边，而角格的度为$2$）。
:::
:::

::: quiz
对从状态$1$出发的链$P = \begin{pmatrix}0&1\\1&0\end{pmatrix}$，下列哪个说法是正确的？
- [ ] 不存在平稳分布。
- [ ] $\Prob(X_n = 1)\to\tfrac12$。
- [x] $(\tfrac12,\tfrac12)$是平稳分布，但$\Prob(X_n = 1)$在$1$和$0$之间交替。
- [ ] 平稳分布是$(1, 0)$，因为链从状态$1$出发。
::: solution
$(\tfrac12,\tfrac12)P = (\tfrac12,\tfrac12)$，所以它是平稳分布（而且由于链不可约，它是唯一的）。但链的周期为$2$：它在偶数时刻处于状态$1$，在奇数时刻处于状态$2$，所以$X_n$的分布不收敛。平稳分布仍然给出了长期停留在每个状态的**时间比例**。正如下一个定理所表明的，分布的收敛需要非周期性。
:::
:::

## 向平衡状态的收敛 {#convergence}

::: theorem 收敛定理 {#thm-convergence}
设$P$是一条有限、不可约且非周期的马尔可夫链的转移矩阵，其平稳分布为$\pi$。则对所有状态$i$、$j$，

$$
p_{ij}^{(n)}\to\pi_j\qquad(n\to\infty).
$$

因此，对每个初始分布，都有$\Prob(X_n = j)\to\pi_j$。
:::

::: proof
*证明概要（用耦合方法）。*我们要用到两个事实。(a) 由于链是有限、不可约且非周期的，存在$n_0$，使得对**所有**$i$、$j$以及所有$n\ge n_0$都有$p_{ij}^{(n)}>0$。（这是一个数论引理：使$p_{ii}^{(n)}>0$的$n$组成的集合对加法封闭，且其最大公因数为$1$，所以它包含所有充分大的整数；再由不可约性，任意$i$都可以连到任意$j$。）(b) 有限不可约链以概率$1$在有限时间内到达任一给定状态（由常返性）。

让链的两个独立副本同时运行：$(X_n)$从$i$出发，$(Y_n)$从$\pi$出发，从而对所有$n$都有$\Prob(Y_n = j) = \pi_j$。数对$(X_n, Y_n)$是$S\times S$上的马尔可夫链，转移概率为$p_{ik}p_{jl}$；由(a)，当$n\ge n_0$时，它的$n$步转移概率$p_{ik}^{(n)}p_{jl}^{(n)}$都是正的，所以它是不可约的。由(b)，这个数对在某个有限的随机时刻$T$到达对角线$\{(k,k)\}$。现在，当$n<T$时令$Z_n = X_n$，当$n\ge T$时令$Z_n = Y_n$：两个副本相遇之后，就跟随$Y$。由强马尔可夫性，$(Z_n)$仍是从$i$出发、转移矩阵为$P$的马尔可夫链，所以$\Prob(Z_n = j) = p_{ij}^{(n)}$。但只要$T\le n$，就有$Z_n = Y_n$，所以

$$
\bigl\lvert p_{ij}^{(n)} - \pi_j\bigr\rvert = \bigl\lvert\Prob(Z_n = j) - \Prob(Y_n = j)\bigr\rvert\le\Prob(Z_n\ne Y_n)\le\Prob(T>n)\to0.
$$
:::

三个假设都是必要的：来回翻转的链表明需要非周期性，而像赌徒破产链这样的可约链，其极限依赖于起始状态。对有限链，收敛是几何式的，其速率由$P$的第二大特征值模支配，就像[[#ex-two-state]]中那样。

即使没有非周期性，平稳概率也描述了长期的**平均**行为。这是大数定律（[[probability/limit-theorems]]）的马尔可夫链版本。

::: theorem 遍历定理 {#thm-ergodic}
对平稳分布为$\pi$的有限不可约马尔可夫链以及任意初始分布，在时刻$0,1,\ldots,n-1$中处于状态$j$的时间比例以概率$1$收敛于$\pi_j = 1/m_j$。
:::

::: proof
*证明概要。*由强马尔可夫性，离开$j$的相继各次游程的长度（相邻两次访问之间的时间）独立同分布，均值为$m_j$。由强大数定律，当$k$很大时，第$k$次访问的时刻约为$km_j$，所以在时间$n$内大约有$n/m_j$次访问。完整的证明（诺里斯，定理1.10.2）使这一论证严格化；再结合收敛定理或一个直接的论证，就可以把极限$1/m_j$与$\pi_j$等同起来。
:::

::: application PageRank
谷歌（Google）最初的网页排序方法建立了一个“随机冲浪者”模型：冲浪者在每一步以概率$d = 0.85$沿当前网页上的一个随机链接前进，否则就跳到一个均匀随机选取的网页。这种跳转使链不可约且非周期，因此收敛定理适用；一个网页的**PageRank**就是它的平稳概率，即冲浪者长期停留在该网页的时间比例。对于有链接$A\to B$、$A\to C$、$B\to C$、$C\to A$和$D\to C$的四个网页，平稳分布约为$(0.373, 0.196, 0.394, 0.0375)$：有三个网页链接到的网页C排名最高，而没有任何网页链接到的网页D只得到最小值$(1-d)/4 = 0.0375$。在实践中，对数十亿个网页计算$\pi$，用的是反复作乘法$\mu\mapsto\mu P$，即[[numerical-analysis/iterative-methods]]中的**幂法**，而幂法的收敛性恰好就是收敛定理。
:::

:::

::: application 马尔可夫链蒙特卡罗方法
收敛定理也可以反过来用。要从一个复杂的分布$\pi$中抽样——例如[[statistics/bayesian#thm-bayes-density]]中的后验分布——可以构造一条以$\pi$为平稳分布的链，让它运行很长时间，并记录它的状态。**梅特罗波利斯（Metropolis）算法**利用细致平衡做到这一点：从状态$i$出发，（按某种对称的规则）提议移动到$j$，并以概率$\min(1,\pi_j/\pi_i)$接受这一提议。由于只需要各$\pi_j$的**比值**，$\pi$的归一化常数——它往往无法计算——根本不会出现。
:::

::: history
安德烈·马尔可夫（Andrey Markov）于1906年在一篇把大数定律推广到相依随机变量的论文中，引入了以他的名字命名的链。他的动机之一是驳斥帕维尔·涅克拉索夫（Pavel Nekrasov）的一个论断，即大数定律成立必须以独立性为前提。1913年，马尔可夫把他的理论应用于语言：他把普希金（Pushkin）的诗体小说《叶甫盖尼·奥涅金》（Eugene Onegin）的前$20\,000$个字母分为元音和辅音两类，并估计了它们之间的转移概率。保罗·埃伦费斯特（Paul Ehrenfest）和塔季扬娜·埃伦费斯特（Tatiana Ehrenfest）于1907年提出了他们的扩散罐子模型，乔治·波利亚（George Pólya）于1921年证明了关于随机游动的常返性定理，安德烈·柯尔莫哥洛夫（Andrey Kolmogorov）在20世纪30年代发展了具有可数多个状态的链的理论。沃尔夫冈·德布林（Wolfgang Doeblin）于1938年为收敛定理引入了耦合论证。梅特罗波利斯算法由尼古拉斯·梅特罗波利斯（Nicholas Metropolis）及其同事于1953年发表，1970年由黑斯廷斯（W. K. Hastings）加以推广；谢尔盖·布林（Sergey Brin）和劳伦斯·佩奇（Lawrence Page）于1998年描述了PageRank。
:::

## 后续内容 {#where-next}

逗留时间服从指数分布的连续时间马尔可夫链，可以为排队、化学反应和流行病建模，并引出泊松过程和生灭过程（格里米特（Grimmett）与斯特扎克（Stirzaker）的书第6章）。马尔可夫链蒙特卡罗方法是[[statistics/bayesian]]的计算支柱。随机游动与调和函数以及[[pde/laplace-equation]]的离散版本相联系，而赌徒破产问题是鞅的最简单的例子，鞅是更高等课程的主题。随机矩阵的谱理论（[[linear-algebra/eigenvalues]]，对可逆链还有[[linear-algebra/spectral-theorem]]）决定了链混合得有多快，这对洗牌以及MCMC的效率都很重要。

::: summary
- 给定现在，马尔可夫链会忘记它的过去：转移由随机矩阵$P$支配，路径概率是转移概率的乘积。
- $n$步转移概率是$P^n$的元素，分布按$\mu^{(n)} = \mu^{(0)}P^n$演化。
- 首步分析把吸收概率和期望击中时间化为线性方程组；对赌徒破产问题，$h_i = (1-r^i)/(1-r^N)$，其中$r = q/p$。
- 状态分成若干互通类；若链以概率$1$返回某个状态，则该状态是常返的，等价地，$\sum_np_{ii}^{(n)} = \infty$；有限不可约链的所有状态都是常返的。
- 平稳分布是$\pi P = \pi$的解；有限不可约链恰有一个平稳分布，且$\pi_j = 1/m_j$。细致平衡$\pi_ip_{ij} = \pi_jp_{ji}$是一个便于检验的充分条件。
- 如果链还是非周期的，则$P^n$收敛于每一行都是$\pi$的矩阵：链忘记了它从哪里出发。没有非周期性时，$\pi$仍然给出长期的时间比例。
- 应用包括PageRank（随机冲浪者的平稳分布）和MCMC（设计一条具有指定平稳分布的链）。
:::

对于天气链，求晴天之后两天仍是晴天的概率。

::: exercise 一个平稳分布 {level=1 check="2/5"}
求$P = \begin{pmatrix}0.7 & 0.3\\ 0.2 & 0.8\end{pmatrix}$的平稳分布；请填写$\pi_1$。
::: solution
由[[#ex-two-state]]，取$a = 0.3$，$b = 0.2$：$\pi = \bigl(\frac{0.2}{0.5},\frac{0.3}{0.5}\bigr) = (0.4, 0.6)$。验证：$0.4\times0.7 + 0.6\times0.2 = 0.4$。
:::

::: exercise 状态分类 {level=1}
$\{1,2,3,4\}$上的一条链的转移矩阵各行依次为$(\tfrac12,\tfrac12,0,0)$、$(\tfrac12,\tfrac12,0,0)$、$(\tfrac14,\tfrac14,\tfrac14,\tfrac14)$和$(0,0,0,1)$。求各互通类，并指出哪些类是闭的、哪些状态是常返的。
::: solution
状态$1$与$2$互通，且不能到达$3$或$4$：$\{1,2\}$是一个闭类。状态$4$是吸收态：$\{4\}$是闭的。状态$3$可以到达每个状态，但其他状态都不能到达它，所以$\{3\}$是一个不闭的类。链在每一步以概率$\tfrac34$离开$3$，并且一去不返，所以$3$是非常返的（$f_3 = \tfrac14$）。状态$1$、$2$、$4$位于有限闭类中，是常返的。
:::
:::

::: exercise 公平赌博的持续时间 {level=2 check="21"}
在公平的赌徒破产问题（$p = \tfrac12$）中，初始资金为3英镑，目标为10英镑。求达到10英镑的概率以及下注次数的期望。
::: hint
对于持续时间$D_i$，首步分析给出$D_i = 1 + \tfrac12D_{i+1} + \tfrac12D_{i-1}$，且$D_0 = D_N = 0$；试试$D_i = i(N-i)$。
:::
::: solution
由[[#thm-gamblers-ruin]]，$h_3 = 3/10$。对于持续时间，$D_i = i(N-i)$满足边界条件，并且

$$
1 + \tfrac12(i+1)(N-i-1) + \tfrac12(i-1)(N-i+1) = 1 + i(N-i) - 1 = i(N-i),
$$

而且（与$h$的情形一样）这组方程只有一个解。所以下注次数的期望为$3\times7 = 21$。
:::

::: exercise 图上的平均返回时间 {level=2 check="8"}
一个随机游动在顶点为$A, B, C, D$、边为$AB$、$AC$、$AD$、$BC$的图上移动。求平稳分布以及返回$D$的平均时间。
::: solution
各顶点的度为$3, 2, 2, 1$，共有$m = 4$条边，所以由[[#ex-graph-walk]]，$\pi = (\tfrac38,\tfrac28,\tfrac28,\tfrac18)$。由[[#thm-stationary-unique]]，返回$D$的平均时间为$1/\pi_D = 8$步。（直接来看：从$D$出发，游动必定走到$A$，而每次位于$A$时，它以概率$\tfrac13$回到$D$；经过$B$和$C$的游程要花费时间。）
:::

::: exercise 奥兹国 {level=2 check="1/5"}
在奥兹国（凯梅尼（Kemeny）、斯内尔（Snell）和汤普森（Thompson）给出的一个例子）中，天气分为雨、晴好和雪三种，转移矩阵各行依次为$(\tfrac12,\tfrac14,\tfrac14)$、$(\tfrac12,0,\tfrac12)$、$(\tfrac14,\tfrac14,\tfrac12)$。求长期来看晴好天气所占的比例。
::: solution
对$\pi = (\pi_R,\pi_N,\pi_S)$解$\pi P = \pi$。由中间一列得$\pi_N = \tfrac14\pi_R + \tfrac14\pi_S = \tfrac14(1-\pi_N)$，所以$\pi_N = \tfrac15$。由第一列得$\pi_R = \tfrac12\pi_R + \tfrac12\pi_N + \tfrac14\pi_S$；代入$\pi_S = \tfrac45 - \pi_R$，得$\pi_R = \tfrac25$，进而$\pi_S = \tfrac25$。所以$\pi = (\tfrac25,\tfrac15,\tfrac25)$：五天中有一天是晴好天气。这条链是非周期的（$p_{RR}>0$），所以这也是晴好天气的极限概率。
:::

::: exercise 双随机矩阵 {level=3}
如果一个随机矩阵的各列之和也都为$1$，则称它是**双随机**的。证明：对$n$个状态上的双随机矩阵，均匀分布$(\tfrac1n,\ldots,\tfrac1n)$是平稳分布。由此推出：如果一种随机洗牌方法是$52!$种排列上的有限不可约非周期链，且每一步的转移矩阵都是双随机的，那么在极限情形下所有排列都是等可能的。
::: solution
取$\pi_i = \tfrac1n$，则$(\pi P)_j = \sum_i\tfrac1np_{ij} = \tfrac1n\sum_ip_{ij} = \tfrac1n$，因为第$j$列之和为$1$。所以均匀分布是平稳分布。对于洗牌链，由[[#thm-stationary-unique]]，平稳分布是唯一的，所以它就是$52!$种排列上的均匀分布；由[[#thm-convergence]]，牌叠的分布收敛于它。（形如“施加一个按固定分布选取的随机置换”的洗牌总是双随机的，因为在每个置换下，每种排列都恰好由一种排列得到。）
:::

::: exercise 周期是类性质 {level=3}
证明：若$i\leftrightarrow j$，则$d(i) = d(j)$。
::: solution
取$a$、$b$使$p_{ij}^{(a)}>0$，$p_{ji}^{(b)}>0$。则$p_{ii}^{(a+b)}\ge p_{ij}^{(a)}p_{ji}^{(b)}>0$，所以$d(i)$整除$a+b$。若$p_{jj}^{(n)}>0$，则$p_{ii}^{(a+n+b)}\ge p_{ij}^{(a)}p_{jj}^{(n)}p_{ji}^{(b)}>0$，所以$d(i)$整除$a+n+b$，从而整除$n$。因此$d(i)$是所有满足$p_{jj}^{(n)}>0$的$n$的公因数，所以$d(i)\le d(j)$（事实上$d(i)\mid d(j)$）。由对称性，$d(j)\le d(i)$，所以两者相等。
:::

::: exercise 不利的赌博 {level=3 check="(1-(11/9)^10)/(1-(11/9)^20)"}
一个赌徒每次下注1英镑，赢的概率为$0.45$。初始资金为10英镑，求他在输光之前达到20英镑的概率。
::: solution
这里$r = 0.55/0.45 = \tfrac{11}{9}$，所以由[[#eq-ruin]]，

$$
h_{10} = \frac{1 - (11/9)^{10}}{1 - (11/9)^{20}} = \frac{1}{1 + (11/9)^{10}}\approx0.118 .
$$

每次下注的劣势并不大（$45\%$对$50\%$），却使资金翻倍的机会从$\tfrac12$降到了不足$12\%$。
:::

::: exercise 有限链中的吸收 {level=3}
考虑一条状态为$0, 1, 2, 3$的链，其中$0$和$3$是吸收态；从$1$和$2$出发时，链以概率$\tfrac23$向上移动一步，以概率$\tfrac13$向下移动一步。对从$i = 1, 2$出发直到被吸收的期望时间$k_i$，列出并求解首步分析方程。
::: solution
首步分析给出$k_0 = k_3 = 0$以及

$$
k_1 = 1 + \tfrac23k_2 + \tfrac13k_0 = 1 + \tfrac23k_2,\qquad k_2 = 1 + \tfrac23k_3 + \tfrac13k_1 = 1 + \tfrac13k_1 .
$$

把第二个方程代入第一个：$k_1 = 1 + \tfrac23 + \tfrac29k_1$，所以$\tfrac79k_1 = \tfrac53$，$k_1 = \tfrac{15}{7}$；于是$k_2 = 1 + \tfrac57 = \tfrac{12}{7}$。从$1$出发，平均需要$\tfrac{15}{7}\approx2.14$步才被吸收。
:::
