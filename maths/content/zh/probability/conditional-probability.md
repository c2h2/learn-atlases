某种疾病在人群中的患病率为$1\%$。针对它的一种检测在两个方向上的准确率都是$95\%$：对$95\%$的患者，检测结果呈阳性；对$95\%$的非患者，检测结果呈阴性。你做了这项检测，结果呈阳性。你患这种病的可能性有多大？

大多数人会回答$95\%$。正确答案约为$16\%$。这项检测很好，但这种病很罕见；在所有检测呈阳性的人中，运气不好的健康人与真正的患者之比约为五比一。要得出正确答案，就需要一种在获得新信息时更新概率的精确方法，而这正是**条件概率**所提供的。

本章定义条件概率，并推导出它的三条主力法则：乘法公式、全概率公式和贝叶斯定理。接着转向**独立性**，即关于一个事件的信息丝毫不能告诉我们另一个事件的情况的情形。独立性是概率论中最重要的建模假设，也是最常被滥用的假设之一。

## 以事件为条件 {#conditioning}

掷一颗红骰子和一颗蓝骰子，假设别人只告诉你点数和为$8$。这时至少有一颗骰子掷出六点的概率是多少？

在得到这一信息之前，全部$36$个结果都是等可能的。一旦知道点数和为$8$，就只剩下五个可能的结果：

$$
B = \{(2,6), (3,5), (4,4), (5,3), (6,2)\},
$$

而且没有理由偏向其中任何一个，所以现在每个结果的概率都是$\tfrac15$。其中有两个含有六点，所以更新后的概率为$\tfrac25$，而此前是$\tfrac{11}{36} \approx 0.31$。得知$B$发生，就把样本空间缩小为$B$，并按比例调整了$B$内部的概率。用原来的概率表示，$\tfrac25 = \dfrac{2/36}{5/36} = \dfrac{\Prob(A\cap B)}{\Prob(B)}$，其中$A$是事件“至少有一个六点”。这就引出了一般的定义。

::: definition 条件概率 {#def-conditional}
设$B$是满足$\Prob(B) > 0$的事件。**给定$B$时$A$的条件概率**为

$$
\Prob(A \mid B) = \frac{\Prob(A \cap B)}{\Prob(B)}.
$$ {#eq-conditional}
:::

这个定义保留了$B$内部各结果概率的相对大小，舍弃了$B$之外的一切，并除以$\Prob(B)$，使总和重新等于$1$。

::: widget venn
sets: 2
expr: A & B
caption: 以$B$为条件，就使$B$成为新的样本空间。阴影区域$A \cap B$是$A$中仍然可能发生的部分，$\Prob(A \mid B)$是它在圆$B$中所占的份额，而不是在整个矩形中所占的份额。先输入`B`，再输入`A & B'`，比较$\Prob(A\mid B)$与$\Prob(A \mid B^c)$，后者是$A$在$B$之外所占的份额。
:::

条件概率本身就是一个概率：[[probability/probability-spaces]]一章中的所有法则都适用于它。

::: theorem 条件概率是概率测度 {#thm-cond-measure}
设$(\Omega, \mathcal{F}, \Prob)$是概率空间，$B \in \mathcal{F}$且$\Prob(B) > 0$。则$Q(A) = \Prob(A \mid B)$定义了$(\Omega, \mathcal{F})$上的一个概率测度$Q$，并且$Q(B) = 1$。
:::

::: proof
我们来验证柯尔莫哥洛夫公理。非负性：$Q(A) = \Prob(A\cap B)/\Prob(B) \ge 0$。规范性：$Q(\Omega) = \Prob(B)/\Prob(B) = 1$，同理$Q(B) = 1$。可数可加性：若$A_1, A_2, \ldots$两两不相交，则$A_1 \cap B, A_2 \cap B, \ldots$也两两不相交，并且$\bigl(\bigcup_n A_n\bigr) \cap B = \bigcup_n (A_n \cap B)$。因此

$$
Q\Bigl(\bigcup_n A_n\Bigr) = \frac{\Prob\bigl(\bigcup_n (A_n\cap B)\bigr)}{\Prob(B)} = \sum_n \frac{\Prob(A_n \cap B)}{\Prob(B)} = \sum_n Q(A_n).
$$
:::

因此$\Prob(A^c \mid B) = 1 - \Prob(A\mid B)$，$\Prob(A_1 \cup A_2 \mid B) = \Prob(A_1\mid B) + \Prob(A_2 \mid B) - \Prob(A_1\cap A_2 \mid B)$，等等：关于概率的每一条定理，对于给定某个固定事件$B$的条件概率都成立。

::: warning P(A | B) 不是 P(B | A)
这两个条件概率回答的是不同的问题，二者可能相差悬殊。几乎所有职业足球运动员都是男性，所以$\Prob(\text{男性} \mid \text{职业足球运动员})$接近$1$；但$\Prob(\text{职业足球运动员}\mid\text{男性})$非常小。混淆这两者（有时称为**逆向谬误**）正是本章开头诊断检测错误的根源：$\Prob(\text{阳性}\mid\text{患病}) = 0.95$，但$\Prob(\text{患病}\mid\text{阳性})$只有约$0.16$。下面的贝叶斯定理才是由一个求出另一个的正确方法。
:::

::: quiz
从一副洗匀的牌中抽出一张。设$A$为“这张牌是K”，$B$为“这张牌是花牌”（J、Q或K）。下列哪个说法正确？
- [ ] $\Prob(A \mid B) = \Prob(B \mid A) = \tfrac13$
- [x] $\Prob(A\mid B) = \tfrac13$且$\Prob(B\mid A) = 1$
- [ ] $\Prob(A\mid B) = \tfrac{1}{13}$且$\Prob(B \mid A) = \tfrac{3}{13}$
- [ ] $\Prob(A\mid B) = \tfrac{4}{52}$，因为条件化不会改变抽到K的概率
::: solution
这里$A \subseteq B$，所以$A \cap B = A$。于是$\Prob(A\mid B) = \dfrac{4/52}{12/52} = \dfrac13$：花牌中有三分之一是K。而$\Prob(B \mid A) = \dfrac{4/52}{4/52} = 1$：每张K都是花牌。这两个条件概率不相等，通常也都是如此。
:::
:::

## 乘法公式 {#multiplication}

把[[#eq-conditional]]变形，得$\Prob(A \cap B) = \Prob(B)\,\Prob(A\mid B)$。这往往是**计算**交事件概率的自然方法，因为在许多试验中，我们直接知道的正是条件概率：一张一张地发牌时，在已知第一张牌的条件下第二张牌的概率很容易写出来。重复这一论证，就得到适用于任意多个事件的法则。

::: theorem 乘法公式（链式法则） {#thm-chain-rule}
若事件$A_1, \ldots, A_n$满足$\Prob(A_1 \cap \dots \cap A_{n-1}) > 0$，则

$$
\Prob(A_1 \cap A_2 \cap \dots \cap A_n) = \Prob(A_1)\,\Prob(A_2 \mid A_1)\,\Prob(A_3 \mid A_1\cap A_2)\cdots\Prob(A_n \mid A_1 \cap\dots\cap A_{n-1}).
$$ {#eq-chain}
:::

::: proof
所有作为条件的事件的概率都是正的，因为$A_1 \supseteq A_1\cap A_2 \supseteq \dots \supseteq A_1\cap\dots\cap A_{n-1}$，而最后一个的概率为正，所以每个因子都有定义。对$n$用数学归纳法。$n = 1$时，命题就是$\Prob(A_1) = \Prob(A_1)$。设命题对$n - 1$个事件成立，记$C = A_1 \cap \dots \cap A_{n-1}$。由条件概率的定义，$\Prob(C \cap A_n) = \Prob(C)\,\Prob(A_n \mid C)$；由归纳假设，$\Prob(C)$等于[[#eq-chain]]中前$n - 1$个因子的乘积。再乘以$\Prob(A_n\mid C)$，就得到$n$个事件的公式。
:::

::: example 三张A {#ex-three-aces}
从一副洗匀的牌中发出三张牌。求三张都是A的概率。
::: solution
设$A_i$为“第$i$张牌是A”这一事件。第一张牌是A的概率为$\tfrac{4}{52}$。在第一张是A的条件下，第二张牌从$51$张牌中抽出，其中有$3$张A，所以$\Prob(A_2 \mid A_1) = \tfrac{3}{51}$；类似地，$\Prob(A_3\mid A_1\cap A_2) = \tfrac{2}{50}$。由乘法公式，

$$
\Prob(A_1\cap A_2\cap A_3) = \frac{4}{52}\cdot\frac{3}{51}\cdot\frac{2}{50} = \frac{1}{5525}.
$$

作为验算，直接计数也得到同样的答案：$\binom43\big/\binom{52}{3} = 4/22\,100 = 1/5525$。乘法公式往往是更快捷的途径，而当试验分阶段进行时，它也是最自然的方法。
:::
:::

组织这类计算的一种方便方法是**树形图**：试验的每个阶段按其可能的结果分出若干枝，每一枝上标出它在已走过的路径的条件下的条件概率，而一条完整路径的概率就是沿途各标注之积。

## 全概率公式与贝叶斯定理 {#bayes}

我们常常知道在几种情形中的每一种之下某个事件发生的可能性有多大，也知道每种情形本身发生的可能性有多大。全概率公式把这些信息综合起来。

::: definition 划分 {#def-partition}
若事件$B_1, B_2, \ldots$（有限个或可数个）两两不相交，且$\bigcup_i B_i = \Omega$，则称它们构成$\Omega$的一个**划分**：它们中恰有一个发生。
:::

::: theorem 全概率公式 {#thm-total-probability}
若$B_1, B_2, \ldots$是$\Omega$的一个划分，且对每个$i$都有$\Prob(B_i) > 0$，则对每个事件$A$，

$$
\Prob(A) = \sum_i \Prob(A \mid B_i)\,\Prob(B_i).
$$ {#eq-total-probability}
:::

::: proof
事件$A\cap B_i$两两不相交（因为各$B_i$两两不相交），并且它们的并为$A \cap \bigcup_i B_i = A\cap\Omega = A$。由可数（或有限）可加性和乘法公式，

$$
\Prob(A) = \sum_i \Prob(A\cap B_i) = \sum_i \Prob(A\mid B_i)\,\Prob(B_i).
$$
:::

最简单的划分是$\{B, B^c\}$，它给出$\Prob(A) = \Prob(A\mid B)\Prob(B) + \Prob(A\mid B^c)\Prob(B^c)$。用文字来说：$A$的总概率是它的各个条件概率的加权平均，权重就是各情形发生的可能性。

现在把问题反过来。观察到$A$之后，各情形的可能性分别有多大？这是由结果反推原因的问题，它的解答就是贝叶斯定理。

::: theorem 贝叶斯定理 {#thm-bayes}
设$B_1, B_2, \ldots$是$\Omega$的一个划分，且对所有$i$都有$\Prob(B_i) > 0$；又设$A$是满足$\Prob(A) > 0$的事件。则对每个$j$，

$$
\Prob(B_j \mid A) = \frac{\Prob(A\mid B_j)\,\Prob(B_j)}{\sum_i \Prob(A\mid B_i)\,\Prob(B_i)}.
$$ {#eq-bayes}
:::

::: proof
由条件概率的定义和乘法公式，$\Prob(B_j \mid A) = \dfrac{\Prob(B_j\cap A)}{\Prob(A)} = \dfrac{\Prob(A\mid B_j)\Prob(B_j)}{\Prob(A)}$，而由全概率公式，分母等于[[#eq-bayes]]中的和。
:::

在这种情境下，$\Prob(B_j)$称为情形$B_j$的**先验**概率（观察到$A$之前），$\Prob(B_j \mid A)$称为它的**后验**概率（观察到$A$之后），$\Prob(A\mid B_j)$称为在$B_j$之下该观察结果的**似然**。贝叶斯定理说的是：后验与似然乘以先验成正比；分母只是把这些数按比例调整，使它们的和为$1$。

::: example 次品是哪台机器生产的？ {#ex-machines}
某工厂有三台机器。机器1生产全部产品的$50\%$，次品率为$1\%$；机器2生产$30\%$，次品率为$2\%$；机器3生产$20\%$，次品率为$3\%$。随机抽取的一个零件是次品。求它是由机器3生产的概率。
::: solution
设$M_i$为“零件来自机器$i$”这一事件（它们构成一个划分），$D$为“零件是次品”这一事件。由全概率公式，

$$
\Prob(D) = 0.01 \times 0.5 + 0.02\times 0.3 + 0.03 \times 0.2 = 0.005 + 0.006 + 0.006 = 0.017.
$$

由贝叶斯定理，

$$
\Prob(M_3\mid D) = \frac{0.03\times 0.2}{0.017} = \frac{6}{17} \approx 0.353.
$$

类似地，$\Prob(M_1 \mid D) = \tfrac{5}{17}$，$\Prob(M_2\mid D) = \tfrac{6}{17}$。机器3只生产了五分之一的零件，却占了次品的三分之一以上；机器1生产了一半的零件，却只占次品的不到三分之一。
:::
:::

::: example 诊断检测 {#ex-diagnostic}
解答本章开头的问题：患病率为$1\%$，**灵敏度**$\Prob(+\mid D) = 0.95$，**特异度**$\Prob(-\mid D^c) = 0.95$。求$\Prob(D\mid +)$。
::: solution
这里$D$表示“患有该病”，$+$表示“检测呈阳性”。划分为$\{D, D^c\}$，其中$\Prob(D) = 0.01$；$\Prob(+\mid D^c) = 1 - 0.95 = 0.05$是假阳性率。由贝叶斯定理，

$$
\Prob(D\mid +) = \frac{0.95 \times 0.01}{0.95\times 0.01 + 0.05\times 0.99} = \frac{0.0095}{0.059} = \frac{19}{118} \approx 0.161.
$$

用**自然频数**来做同样的计算，结果更容易令人信服。设想有$10\,000$个人：其中$100$人患病，他们当中有$95$人检测呈阳性；$9900$人健康，他们当中的$5\%$，即$495$人，检测也呈阳性。在$95 + 495 = 590$个阳性者中，只有$95$人患病，而$95/590 \approx 0.161$。假阳性之所以占多数，是因为它们是一个非常大的群体中的一小部分。
:::
:::

用**几率**（odds）来表述，贝叶斯定理就格外清楚。事件$E$的几率是$\Prob(E)/\Prob(E^c)$；例如，概率$0.2$对应于几率$0.2/0.8 = 1/4$，即“4比1不利”（不发生与发生之比为4比1）。

::: proposition 几率形式的贝叶斯定理 {#prop-odds}
设$D$是满足$0 < \Prob(D) < 1$的事件，$A$是满足$\Prob(A\mid D^c) > 0$的事件。则

$$
\frac{\Prob(D\mid A)}{\Prob(D^c\mid A)} = \frac{\Prob(A\mid D)}{\Prob(A\mid D^c)}\cdot\frac{\Prob(D)}{\Prob(D^c)} .
$$

用文字来说：**后验几率 = 似然比 × 先验几率**。
:::

::: proof
左端的条件概率是有定义的，因为$\Prob(A) \ge \Prob(A\cap D^c) = \Prob(A\mid D^c)\Prob(D^c) > 0$。用划分$\{D, D^c\}$下的贝叶斯定理写出两个后验概率。它们有相同的分母$\Prob(A)$，在比值中约去：

$$
\frac{\Prob(D\mid A)}{\Prob(D^c\mid A)} = \frac{\Prob(A\mid D)\Prob(D)/\Prob(A)}{\Prob(A\mid D^c)\Prob(D^c)/\Prob(A)} = \frac{\Prob(A\mid D)}{\Prob(A\mid D^c)}\cdot\frac{\Prob(D)}{\Prob(D^c)}.
$$
:::

对于诊断检测，先验几率为$1/99$，阳性结果的**似然比**为$0.95/0.05 = 19$，所以后验几率为$19/99$，这又一次给出概率$19/118$。似然比衡量证据的强度，与先验无关。如果第二次独立的检测（其确切含义见下文）也呈阳性，几率就再乘以$19$：得$361/99$，对应的概率为$361/460 \approx 0.785$。

::: warning 基础比率谬误与检察官谬误
忽略先验$\Prob(D)$——即**基础比率**——是关于证据推理的最常见错误。它在法庭上的版本是**检察官谬误**：“如果被告是无辜的，出现这一证据的机会只有百万分之一，所以他无辜的机会只有百万分之一。”这混淆了$\Prob(\text{证据}\mid\text{无辜})$与$\Prob(\text{无辜}\mid\text{证据})$；在一个有一千万人口的城市里，大约会有十个无辜的人与这一证据相符。在英格兰的萨莉·克拉克（Sally Clark）案（1999年）中，一位专家证人把单个婴儿猝死的机会估计为$8543$分之$1$，再将其平方，从而估计一个家庭中发生两例婴儿猝死的机会约为$7300$万分之$1$。平方运算错误地假定了独立性，而且这个数字很容易被理解为被告无辜的概率。英国皇家统计学会于2001年公开批评了这一统计证据，该定罪于2003年被推翻。
:::

::: example 蒙提霍尔问题 {#ex-monty-hall}
在一档游戏节目中，三扇门中的一扇后面藏着一辆汽车（藏在每扇门后的可能性相同），另外两扇门后面各是一只山羊。你选了1号门。主持人知道汽车在哪里，他总会打开另外两扇门中的一扇，露出一只山羊；如果这两扇门后面都是山羊，他就随机选一扇。他打开了3号门。你应该改选2号门吗？
::: solution
设$C_i$为“汽车在$i$号门后”这一事件，于是$\Prob(C_i) = \tfrac13$；设$H_3$为“主持人打开3号门”这一事件。在上述规则下，

$$
\Prob(H_3 \mid C_1) = \tfrac12, \qquad \Prob(H_3\mid C_2) = 1, \qquad \Prob(H_3\mid C_3) = 0,
$$

这是因为：如果汽车在1号门后，主持人在2号门和3号门之间随机选择；如果汽车在2号门后，他只能打开3号门；而他从不让汽车露出来。由贝叶斯定理，

$$
\Prob(C_2\mid H_3) = \frac{1 \cdot \tfrac13}{\tfrac12\cdot\tfrac13 + 1\cdot\tfrac13 + 0\cdot\tfrac13} = \frac{1/3}{1/2} = \frac23 .
$$

所以改选获胜的概率为$\tfrac23$，坚持原选择获胜的概率为$\tfrac13$。直观的理解是：你最初的选择正确的概率为$\tfrac13$，主持人的任何举动都不能改变这一点，因为他总能打开一扇后面是山羊的门；剩下的$\tfrac23$就集中到他没有打开的那扇门上。答案取决于主持人的规则。如果他是**随机地**打开另外两扇门中的一扇，碰巧露出了山羊，那么改选获胜的概率就只有$\tfrac12$（见习题）。
:::
:::

::: remark 辛普森悖论
全概率公式把总体比率表示为各子群体比率的加权平均，而不同的权重可能使比较结果反转。一项经常被引用的1986年肾结石治疗研究报告称，疗法A的成功率为$78\%$（$273/350$），疗法B的成功率为$83\%$（$289/350$），所以总体上看B似乎更好。然而，对小结石A更好（$81/87 \approx 93\%$对$234/270 \approx 87\%$），对大结石A**也**更好（$192/263 \approx 73\%$对$55/80 \approx 69\%$）。原因在于A主要用于更难治的大结石。忽略这种**混杂**变量的比较可能会得出相反的结论；我们将在[[statistics/regression]]一章中再回到这个问题。
:::

::: quiz
某种罕见病每$1000$人中有$1$人患病。一种筛查检测的灵敏度为$99\%$，假阳性率为$2\%$。检测呈阳性的人中，大约有多大比例真正患病？
- [ ] 约$99\%$
- [ ] 约$50\%$
- [x] 约$5\%$
- [ ] 约$0.1\%$
::: solution
在$100\,000$人中，有$100$人患病，其中约$99$人检测呈阳性；而其余$99\,900$人中约有$2\%$，大约$1998$人，检测也呈阳性。所以$\Prob(\text{患病}\mid +) \approx 99/(99 + 1998) \approx 0.047$。答案$99\%$是灵敏度——这正是基础比率谬误的表现。
:::
:::

## 独立性 {#independence}

有时得知$B$发生完全不改变$A$的概率：$\Prob(A\mid B) = \Prob(A)$。两边乘以$\Prob(B)$，就把它变成一个对称的条件，而且这个条件在$\Prob(B) = 0$时也有意义。

::: definition 两个事件的独立性 {#def-independent}
称事件$A$与$B$**独立**，是指

$$
\Prob(A\cap B) = \Prob(A)\,\Prob(B).
$$

当$\Prob(B) > 0$时，这等价于$\Prob(A\mid B) = \Prob(A)$；当$\Prob(A) > 0$时，它等价于$\Prob(B \mid A) = \Prob(B)$。
:::

例如，对两颗均匀骰子，事件“红骰子掷出$6$”与“蓝骰子掷出偶数”是独立的：它们的交包含$36$个结果中的$3$个，而$\tfrac{3}{36} = \tfrac16\cdot\tfrac12$。不那么明显的是，“点数和为$7$”与“红骰子掷出$6$”也是独立的：$\Prob(\text{点数和为 } 7 \mid \text{红骰子为 } 6) = \tfrac16 = \Prob(\text{点数和为 } 7)$。（点数和为$8$的情形就不同了：见习题。）独立性是概率测度的一种数值性质，它不一定对应于任何物理上的分隔。

如果知道$B$发生对了解$A$毫无帮助，那么知道$B$**没有**发生也应当毫无帮助。

::: theorem 独立性与补事件 {#thm-indep-complements}
若$A$与$B$独立，则$A$与$B^c$、$A^c$与$B$、$A^c$与$B^c$也都独立。
:::

::: proof
$A$是$A\cap B$与$A\cap B^c$的不交并，所以

$$
\Prob(A\cap B^c) = \Prob(A) - \Prob(A\cap B) = \Prob(A) - \Prob(A)\Prob(B) = \Prob(A)\bigl(1 - \Prob(B)\bigr) = \Prob(A)\,\Prob(B^c).
$$

所以$A$与$B^c$独立。交换$A$与$B$的角色，可知$A^c$与$B$独立；再把第一个结论应用于独立的一对事件$A^c, B$，可知$A^c$与$B^c$独立。
:::

::: warning 独立不同于互斥
如果$A$与$B$互斥，且两者的概率都为正，那么它们是**不独立的**：$\Prob(A\cap B) = 0 \ne \Prob(A)\Prob(B)$。事实上，得知$B$发生就能确定$A$没有发生，这与“没有提供任何信息”恰恰相距最远。互斥事件不可能同时发生；独立事件同时发生的频繁程度恰好与单凭机会所预测的一样。
:::

对于两个以上的事件，必须对每个子族都要求独立性。

::: definition 相互独立 {#def-mutual}
称事件$A_1, A_2, \ldots, A_n$（**相互**）**独立**，是指对任意选取的不同指标$i_1 < i_2 < \dots < i_k$（$2 \le k \le n$）都有

$$
\Prob(A_{i_1}\cap A_{i_2}\cap\dots\cap A_{i_k}) = \Prob(A_{i_1})\,\Prob(A_{i_2})\cdots\Prob(A_{i_k}).
$$

如果一个无穷事件族的每个有限子族都独立，就称这个无穷事件族独立。如果上述条件对$k = 2$成立，即对每一对事件都成立，就称这些事件**两两独立**。
:::

对三个事件而言，这意味着四个等式：三对事件各一个，三个事件整体一个。下面的例子表明，两两之间的等式推不出最后一个等式。

::: example 两两独立但不相互独立 {#ex-pairwise}
抛两枚均匀硬币。设$A$为“第一枚硬币正面朝上”，$B$为“第二枚硬币正面朝上”，$C$为“两枚硬币朝上的面相同”。证明$A$、$B$、$C$两两独立，但不相互独立。
::: solution
四个结果$HH, HT, TH, TT$是等可能的，$A = \{HH, HT\}$，$B = \{HH, TH\}$，$C = \{HH, TT\}$的概率都是$\tfrac12$。每两个事件的交都是$\{HH\}$，其概率为$\tfrac14 = \tfrac12\cdot\tfrac12$，所以这三对事件都是独立的。但是

$$
\Prob(A\cap B\cap C) = \Prob(\{HH\}) = \tfrac14 \neq \tfrac18 = \Prob(A)\Prob(B)\Prob(C).
$$

其中任意两个事件都决定了第三个（若两枚硬币都正面朝上，则它们朝上的面相同），所以这三个事件远非相互独立。
:::
:::

独立事件最重要的来源是**重复试验**：多次抛掷硬币，检测生产线上的元件，有放回地抽样。我们对这类试验建模的方式是：规定取决于不同次试验的事件相互独立；于是一串结果的概率就是各个结果概率的乘积。如果每次试验“成功”的概率都是$p$，那么由补集法则和补事件的独立性，在$n$次独立试验中至少成功一次的概率为

$$
1 - (1-p)^n .
$$ {#eq-at-least-one}

这正是[[probability/probability-spaces]]一章中对德·梅雷骑士赌局的计算，现在它对任何由独立阶段构成的试验都有了依据。

::: example 系统的可靠性 {#ex-reliability}
一个系统有三个相互独立工作的元件，每个元件正常工作的概率都是$0.9$。元件1与由元件2和元件3组成的并联组串联：当元件1正常工作，**并且**元件2和元件3中至少有一个正常工作时，系统正常工作。求系统正常工作的概率。
::: solution
设$W_i$为“元件$i$正常工作”这一事件。并联组只有在两个元件都失效时才失效，由（补事件的，[[#thm-indep-complements]]）独立性，其概率为$0.1 \times 0.1 = 0.01$；所以并联组正常工作的概率为$0.99$。事件“并联组正常工作”只由$W_2$和$W_3$构成，它与$W_1$独立（由互不相交的几组独立事件分别决定的事件是相互独立的；一个特例见习题）。因此

$$
\Prob(\text{系统正常工作}) = \Prob(W_1)\,\Prob(W_2\cup W_3) = 0.9\times 0.99 = 0.891.
$$

为元件2配备一个备份，使这一级的可靠性从$0.9$提高到了$0.99$；现在系统受限于单个的元件1。
:::
:::

最后，独立性可能在给定某些信息的**条件下**成立，而在无条件时不成立；反之亦然。

::: definition 条件独立 {#def-cond-indep}
设$C$是满足$\Prob(C) > 0$的事件。若$\Prob(A\cap B\mid C) = \Prob(A\mid C)\,\Prob(B\mid C)$，则称事件$A$与$B$**在给定$C$的条件下条件独立**。
:::

对于[[#ex-diagnostic]]中的诊断检测，两次检测通常被建模为在给定患者真实状况的条件下条件独立：在你患病的条件下，每次检测各自独立地以概率$0.95$呈阳性；在你健康的条件下，每次检测以概率$0.05$呈阳性。正是这一点使几率两次乘以$19$的做法有了依据。但这两次结果在无条件时**并不**独立：由全概率公式，

$$
\Prob(\text{两次都 } +) = 0.01\times0.95^2 + 0.99\times 0.05^2 = 0.0115, \qquad \text{而} \qquad \Prob(+)^2 = 0.059^2 \approx 0.0035.
$$

第一次结果呈阳性使患病的可能性变大，这反过来又使第二次结果呈阳性的可能性变大。信息通过患者隐藏的真实状况在两次结果之间传递。

::: quiz
掷一颗均匀骰子一次。设$A = \{2, 4, 6\}$（“偶数”），$B = \{1, 2, 3, 4\}$。$A$与$B$是否独立？
- [x] 是
- [ ] 否，因为它们有重叠
- [ ] 否，因为$B$包含的结果比$A$多
- [ ] 不重复做试验就无法判断
::: solution
$\Prob(A) = \tfrac12$，$\Prob(B) = \tfrac23$，而$A\cap B = \{2,4\}$的概率为$\tfrac13 = \tfrac12\cdot\tfrac23$。所以它们是独立的，尽管两者涉及的是同一次投掷。等价地，$\Prob(A \mid B) = \tfrac{2}{4} = \tfrac12 = \Prob(A)$：$B$中的结果有一半是偶数，正如全部结果中有一半是偶数一样。
:::
:::

::: history
以托马斯·贝叶斯（Thomas Bayes）牧师命名的这一定理，出现在《机会学说中一个问题的求解》（An essay towards solving a problem in the doctrine of chances）一文中。这篇论文是在贝叶斯于1761年去世后从他的遗稿中发现的，由他的朋友理查德·普赖斯（Richard Price）于1763年发表在《皇家学会哲学汇刊》（*Philosophical Transactions of the Royal Society*）上。贝叶斯关心的是如何根据一个事件已经发生的次数来推断它未知的机会。皮埃尔-西蒙·拉普拉斯（Pierre-Simon Laplace）显然不知道贝叶斯的论文，他在1774年的一篇论文中提出了“由事件推断原因的概率”的原理，并把它发展成一种一般的推断方法，这种方法后来被称为**逆概率**。蒙提霍尔问题是统计学家史蒂夫·塞尔文（Steve Selvin）于1975年在致《美国统计学家》（*The American Statistician*）的信中提出的；1990年，玛丽莲·沃斯·莎凡特（Marilyn vos Savant）在她的杂志专栏“请问玛丽莲”（*Ask Marilyn*）中给出了正确答案，结果收到了成千上万封来信，其中许多出自拥有博士学位的读者之手，坚称她错了。
:::

## 后续内容 {#where-next}

条件化是概率论的主要工具。在[[probability/discrete-random-variables]]一章中，重复独立试验给出二项分布和几何分布；随机变量的独立性出现在[[probability/joint-distributions]]一章中；以随机变量为条件，引出[[probability/expectation]]一章中的条件期望；而[[probability/markov-chains]]一章中的马尔可夫性是关于条件概率的一个命题。把贝叶斯定理应用于未知参数而不是事件，就是[[statistics/bayesian]]的基础。

::: summary
- $\Prob(A\mid B) = \Prob(A\cap B)/\Prob(B)$把样本空间限制到$B$上并重新归一化；对固定的$B$，它是一个概率测度（[[#thm-cond-measure]]）。
- 乘法公式：$\Prob(A_1\cap\dots\cap A_n) = \Prob(A_1)\Prob(A_2\mid A_1)\cdots$，这是处理分阶段试验和树形图的自然工具。
- 全概率公式：对一个划分，$\Prob(A) = \sum_i \Prob(A\mid B_i)\Prob(B_i)$。
- 贝叶斯定理把$\Prob(A\mid B_j)$转化为$\Prob(B_j\mid A)$：后验$\propto$似然$\times$先验，或者说后验几率$=$似然比$\times$先验几率。
- 永远不要忽略基础比率：$\Prob(A\mid B)$与$\Prob(B\mid A)$可能相差很大。
- $A$与$B$独立是指$\Prob(A\cap B) = \Prob(A)\Prob(B)$；取补事件后独立性保持不变，而且它与互斥截然不同。
- 多个事件相互独立要求每个子族都满足乘积法则；两两独立是较弱的条件；条件独立既不蕴涵独立，也不能由独立推出。
:::

## 习题

::: exercise 一个条件概率 {level=1 check="1/2"}
事件$A$和$B$满足$\Prob(A) = 0.5$，$\Prob(B) = 0.4$，$\Prob(A\cap B) = 0.2$。求$\Prob(A\mid B)$，并判断$A$与$B$是否独立。
::: solution
$\Prob(A\mid B) = 0.2/0.4 = 0.5$。由于它等于$\Prob(A)$（等价地，$0.2 = 0.5\times0.4$），这两个事件独立。
:::

::: exercise 三张红桃 {level=1 check="11/850"}
从一副洗匀的牌中发出三张牌。求三张都是红桃的概率。
::: solution
由乘法公式，$\dfrac{13}{52}\cdot\dfrac{12}{51}\cdot\dfrac{11}{50} = \dfrac{1716}{132\,600} = \dfrac{11}{850} \approx 0.0129$。
:::

::: exercise 点数和为8与六点 {level=1}
掷两颗均匀骰子。事件“点数和为$8$”与“红骰子掷出$6$”是否独立？
::: solution
$\Prob(\text{点数和为 } 8) = \tfrac{5}{36}$，$\Prob(\text{红骰子为 } 6) = \tfrac16$，而交事件是$\{(6,2)\}$，概率为$\tfrac{1}{36}$。由于$\tfrac{5}{36}\cdot\tfrac{1}{6} = \tfrac{5}{216} \ne \tfrac{1}{36}$，它们不独立：$\Prob(\text{点数和为 } 8\mid\text{红骰子为 } 6) = \tfrac16 > \tfrac{5}{36}$。（与点数和为$7$的情形对比：无论红骰子掷出几点，点数和都有可能为$7$。）
:::
:::

::: exercise 两个罐子 {level=2 check="3/4"}
罐子I中有$3$个红球和$2$个蓝球；罐子II中有$1$个红球和$4$个蓝球。抛一枚均匀硬币来选择一个罐子，再从中取出一个球。取出的球是红球。它来自罐子I的概率是多少？
::: solution
对划分$\{\text{I}, \text{II}\}$应用贝叶斯定理，

$$
\Prob(\text{I}\mid\text{红球}) = \frac{\tfrac35\cdot\tfrac12}{\tfrac35\cdot\tfrac12 + \tfrac15\cdot\tfrac12} = \frac{3/10}{4/10} = \frac34 .
$$
:::
:::

::: exercise 垃圾邮件过滤器 {level=2 check="25/28"}
发送到某个地址的所有电子邮件中，$40\%$是垃圾邮件。单词“free”（免费）出现在$25\%$的垃圾邮件中，以及$2\%$的其他邮件中。求一封含有“free”的邮件是垃圾邮件的概率。
::: solution
记$S$为“是垃圾邮件”，$W$为“含有‘free’”，则

$$
\Prob(S\mid W) = \frac{0.25\times0.4}{0.25\times0.4 + 0.02\times0.6} = \frac{0.1}{0.112} = \frac{25}{28} \approx 0.893.
$$

用几率形式：先验几率为$0.4/0.6 = \tfrac23$，似然比为$0.25/0.02 = 12.5$，后验几率为$\tfrac{25}{3}$，对应概率为$\tfrac{25}{28}$。朴素贝叶斯垃圾邮件过滤器假定在给定类别的条件下各单词条件独立，从而把许多这样的似然比（每个单词一个）组合起来。
:::

::: exercise 需要几次阳性结果？ {level=2 check="4"}
对于[[#ex-diagnostic]]中的检测（患病率为$1\%$，灵敏度和特异度均为$95\%$），假设在给定患者状况的条件下，重复检测是条件独立的。至少要连续出现多少次阳性结果，患病的概率才会超过$0.99$？
::: hint
利用几率形式：每次阳性结果都使几率乘以$19$。
:::
::: solution
经过$k$次阳性结果后，几率为$19^k/99$。概率超过$0.99$意味着几率超过$99$，所以需要$19^k > 99^2 = 9801$，即$k > \ln 9801/\ln 19 \approx 3.12$。因此$k = 4$。（三次阳性给出概率$0.9858$；四次给出$0.9992$。）
:::
:::

::: exercise 独立性与并 {level=2}
设$A$与$B$独立，$A$与$C$独立，且$B \cap C = \varnothing$。证明$A$与$B\cup C$独立。
::: solution
由于$B$与$C$不相交，$A\cap B$与$A\cap C$也不相交，并且$A\cap(B\cup C) = (A\cap B)\cup(A\cap C)$。因此

$$
\Prob\bigl(A\cap(B\cup C)\bigr) = \Prob(A)\Prob(B) + \Prob(A)\Prob(C) = \Prob(A)\bigl(\Prob(B) + \Prob(C)\bigr) = \Prob(A)\,\Prob(B\cup C).
$$

（没有不相交的假设，结论可能不成立：在[[#ex-pairwise]]中，$C$与$A$独立，与$B$也独立，但$\Prob(C \cap (A\cup B)) = \tfrac14$，而$\Prob(C)\Prob(A\cup B) = \tfrac12\cdot\tfrac34 = \tfrac38$。）
:::
:::

::: exercise 漫不经心的主持人 {level=3 check="1/2"}
在蒙提霍尔游戏中，假设主持人不知道汽车在哪里：他从你没有选的两扇门中随机打开一扇，每扇的概率都是$\tfrac12$。你选了1号门，而他碰巧打开了3号门，露出一只山羊。改选2号门获胜的概率是多少？
::: solution
设$G$为事件“主持人打开3号门并露出一只山羊”。此时$\Prob(G\mid C_1) = \tfrac12$，$\Prob(G\mid C_2) = \tfrac12$（他以概率$\tfrac12$打开3号门，而门后是山羊），$\Prob(G\mid C_3) = 0$。由贝叶斯定理，

$$
\Prob(C_2\mid G) = \frac{\tfrac12\cdot\tfrac13}{\tfrac12\cdot\tfrac13+\tfrac12\cdot\tfrac13 + 0} = \frac12 .
$$

此时改选与坚持同样好。与[[#ex-monty-hall]]的区别在于：一个漫不经心的主持人露出山羊，同时也给了你关于1号门的信息——如果汽车在2号门或3号门后，他就有可能让汽车露出来。
:::
:::

::: exercise 正关联是对称的 {level=3}
设事件$A$和$B$满足$\Prob(A) > 0$，$\Prob(B) > 0$。证明$\Prob(A\mid B) > \Prob(A)$当且仅当$\Prob(B\mid A) > \Prob(B)$。并由此推出：若$\Prob(A \mid B) > \Prob(A)$且$\Prob(B) < 1$，则$\Prob(A\mid B^c) < \Prob(A)$。
::: hint
两个不等式都等价于$\Prob(A\cap B) > \Prob(A)\Prob(B)$。第二部分利用全概率公式。
:::
::: solution
两边乘以$\Prob(B) > 0$，不等式$\Prob(A\mid B) > \Prob(A)$等价于$\Prob(A\cap B) > \Prob(A)\Prob(B)$。两边乘以$\Prob(A) > 0$，可知$\Prob(B\mid A) > \Prob(B)$也与之等价。因此这两个不等式等价。

对于第二部分，由全概率公式得

$$
\Prob(A) = \Prob(A\mid B)\Prob(B) + \Prob(A\mid B^c)\bigl(1 - \Prob(B)\bigr),
$$

所以$\Prob(A)$是$\Prob(A\mid B)$与$\Prob(A\mid B^c)$的加权平均，权重$\Prob(B)$和$1 - \Prob(B)$都为正。两个不相等的数的这种平均严格位于两数之间；由于$\Prob(A\mid B) > \Prob(A)$，必有$\Prob(A\mid B^c) < \Prob(A)$。如果证据$B$会增强你对$A$的信念，那么没有这一证据就必然会削弱这一信念。
:::

::: exercise 独立事件的补事件 {level=3}
证明：若$A_1, \ldots, A_n$相互独立，则$A_1^c, A_2, \ldots, A_n$也相互独立。由此推出：把其中任意若干个事件换成它们的补事件，相互独立性保持不变；并且$\Prob(A_1\cup\dots\cup A_n) = 1 - \prod_{i=1}^n \bigl(1 - \Prob(A_i)\bigr)$。
::: solution
任取一个子族。如果它不含$A_1^c$，那么由假设，乘积法则成立。否则它是$A_1^c, A_{i_1}, \ldots, A_{i_k}$，其中$2 \le i_1 < \dots < i_k$；令$C = A_{i_1}\cap\dots\cap A_{i_k}$，则由独立性，$\Prob(C) = \prod_j \Prob(A_{i_j})$且$\Prob(A_1 \cap C) = \Prob(A_1)\Prob(C)$。于是

$$
\Prob(A_1^c\cap C) = \Prob(C) - \Prob(A_1\cap C) = \bigl(1 - \Prob(A_1)\bigr)\Prob(C) = \Prob(A_1^c)\prod_{j=1}^k\Prob(A_{i_j}).
$$

所以$A_1^c, A_2, \ldots, A_n$相互独立。由于定义对各事件是对称的，同样的论证可以把任意一个事件换成它的补，重复这一论证就可以把任意一组事件换成它们的补。特别地，$A_1^c, \ldots, A_n^c$相互独立，再由德摩根律，

$$
\Prob\Bigl(\bigcup_i A_i\Bigr) = 1 - \Prob\Bigl(\bigcap_i A_i^c\Bigr) = 1 - \prod_{i=1}^n\bigl(1 - \Prob(A_i)\bigr).
$$
:::
