筛查是预防医学中意图被审查得最严的一个分支，因为它的收益是延迟且统计的，而伤害是即刻且个体的：假阳性、过度诊断、间期癌、以及级联。**本章覆盖原则（威尔逊与荣格纳的谱系与其修订、以及四种偏倚）、国家规划（各自的试验与效果量与伤害与质量控制）、交付（接受率与公平与知情选择所需的那些数字）、以及边界（风险的分层与“自我要求的筛查”与新技术的证据标准与过度的那一条线）。**

## 原则

::: definition 为什么筛查需要试验：标准与偏倚 {#def-principles}
**经典的框架是威尔逊与荣格纳1968年的原则，此后被反复修订（最近一次世界卫生组织的重大更新仍保留“疾病—试验—治疗—规划”的四段结构）：疾病应当重要、其自然史应被理解、应存在可识别的早期阶段、早期治疗应优于晚期治疗、试验应可被接受、必须有可诊断与可治疗的患病率、必须有明确的两期自然史、以及成本必须与医疗总体相称；此外现代的两条：规划必须作为连续的项目而非一次行动，以及必须有筛与被筛者的知情同意。四种偏倚会制造出“筛查有效”的假象：先入时间偏倚（从更早的诊断点开始计算存活期而死亡时间不变，于是“存活率”改善而不救一命）、长度偏倚（筛查按定义更倾向于抓到生长慢的病变，而致死性最强的病变更常在两次筛查之间出现）、以及自愿筛查者健康偏倚（来参加的人本就更健康、更遵循医嘱、更少合并症），加上过度诊断（把终生不会引起症状的病变当真病）。因此唯一的公平终点是全因死亡（或至少是目标的疾病别死亡与发病率与“间期癌”的比率与伤害的计数），而随机试验的意义正是消除自选择的偏倚——而这也是为何筛查试验昂贵、缓慢、且常被视为“不道德”（对照组的被试者知道自己被拒于一种可能有益的检查之外，而研究者知道公众不会接受随机化的今天，所以只能靠集群与分阶段推开与中断时间序列来近似）。筛查还引入一种新的医学角色：对健康人施以干预，因此其伤害的门槛与对患者的治疗完全不同——一个为症状而来的病人可以从干预中获益，而一个被筛出的健康人被“转化”为病人，其收益与伤害都必须重新被论证——[[epidemiology-ebm/diagnostic-tests]]、[[epidemiology-ebm/critical-appraisal]]、[[pathology/cancer-diagnosis]]。**
:::

## 规划

::: definition 国家的筛查：试验、数字与伤害 {#def-programmes}
**宫颈癌筛查仍是成功的故事也是活的试验：细胞学时代的死亡率下降（“筛查救的英国女性比任何其他癌症规划都多”的算术）、以人类乳头状病毒为首要检测的转换（更高的灵敏度与更长的安全间隔与分诊的流程、以及在覆盖不足处自我取样的选项）、以及“治疗即预防”的闭环（对高级别病变的门诊处理与对年轻女性生育力的考量，以及疫苗接种普及之后筛查策略必须随之重设——当疾病在年轻队列中变罕见，继续在同一年龄筛查就会伤害多于收益）；伤害的一侧是阴性的假安全感与过度治疗（对一过性感染的处理与对生育的远期影响，尤其是宫颈的锥切与早产风险）——[[obstetrics-gynaecology/gynaecological-cancer]]、[[pathology/cancer-diagnosis]]。结直肠癌筛查的关键是“息肉被切掉即不再成为癌症”这一独特的事实：粪便免疫化学检测（其阈值决定了阳性预测值与肠镜的量与伤害）与乙状结肠与结肠的影像选项与“间期癌”与腺瘤的生物学，以及最重要的操作参数——肠镜的质量（腺瘤检出率作为质量指标，以及每提高一个百分点对间期癌风险的影响）与阳性者的等待时间与“未被处理的阳性”这一系统性的失败；同时要说清筛查不能替代有症状者的诊断路径（筛查抓到的是无症状者，而有便血者应走症状的快线而不是等一次粪便试验）——[[gastrointestinal/gi-bleeding-cancer]]、[[surgery/gastrointestinal-surgery]]。乳腺癌筛查的数字最被误用：死亡率相对下降与绝对下降与每千名被筛者的过度诊断与假阳性的累积（在一个十年的筛查史里假阳性比癌症常见得多，而它们引发的活检与焦虑有真实的代价）；而开始与结束的年龄与间隔是在收益与伤害之间的价值判断，不是技术的最优解——[[pathology/cancer-biology]]。前列腺特异性抗原是最有争议的一个（它更像器官而非肿瘤的标志，过度诊断的量与假阳性的后果与“共同决策优于规划”的证据，以及风险的分层与影像先行与靶向活检的新路径）；新生儿筛查是另一类（以疾病与治疗的同时可得为前提，串联质谱与“筛查—诊断—治疗”的闭环与对二次发现的存储政策）；以及主动脉与骨质疏松与房颤与眼底与妊娠的筛查，各自的界限由“治疗是否在无症状者中有效”决定——[[cardiovascular/vascular-disease]]、[[endocrine/bone-calcium]]、[[paediatrics/newborn]]、[[obstetrics-gynaecology/pregnancy-antenatal]]。**
:::

## 交付

::: definition 接受率、质量与知情选择所需的数字 {#def-delivery}
**接受率是规划的第一项产出，也是它的公平X光片：按剥夺与族裔与语言与移民状态与残障与学习困难的覆盖梯度意味着一个人群规划可以在总体上优秀而在某个邮编里失败（每个规划的数据里都有逆向照护法则的图案——宫颈癌与结直肠癌与乳腺的筛查在三至四个十分位的差距上反复出现，而且通常在被“改进”的年份扩大）。修复接受率的工具箱按有效性排：把默认的选项改变（预先纳入的邀约与把筛查与人们已在的场所结合与延长时段与移动的单位与自我取样与邮寄的粪便盒）、把障碍移除（语言与读写的适配与可及的交通与陪诊与不需要证件与不收费、以及把“多次邀约”变成流程而非例外）、以及用信任者（全科医师的一句话与社区的工作者与已筛查者的经验与在同种语言中的宣传，其效果优于任何海报）；而金钱与强制很少可取（把它们写进伦理的论证：筛查的正当性建立在自愿与知情之上）——[[public-health/determinants-inequalities]]。质量是一整套被测量的东西：试验的性能（灵敏度与特异度与阈值的选择与两者的权衡如何被显式做出）、读片与取材的双重或多重读取率与假阴性与间期癌的比例、被筛者被给予的数字与知情选择（每千名被筛者的死亡率下降与过度诊断与假阳性与后续的检查——“我需要知道什么才能决定”这个问题必须用绝对数回答，且用可比的框架）、以及规划层面的监测（覆盖、异常与假阳性、被筛人群的分期分布、以及伤害与赔付）；而“筛查项目”作为一个术语掩盖了它其实是一条包含邀约与采样与实验与读片与召回与治疗与终止的长流水线，其中的每一段都可以成为瓶颈或伤害的来源——[[clinical-skills/laboratory-tests]]、[[pathology/diagnostic-pathology]]。最后一个结构性问题：谁拥有筛查的边界。当检测变得可自费购买（全身的磁共振与基因的检测组合与冠脉的钙化与颈动脉的超声与“多癌种早筛”的液体活检），个体可以绕过规划的证据与保护，而临床医师则面对“我该如何回应”的追问；回答的原则是：不要用“没有证据”结束谈话，而要把未知的伤害讲成具体的东西（假阳性的下游与过度诊断与保险 与焦虑），并把患者的实际动机（家族史的恐惧与此前的丧失）当作值得回应的问题，并给出真正能降低风险的事——[[pharmacology/drug-development-prescribing]]、[[clinical-skills/communication]]。**
:::

::: example 引发活检的那次钼靶 {#ex-falsepositive}
一名52岁女性在筛查钼靶中被“召回”：一个可疑的影象，需要放大摄影与超声与空心针活检；她两周没有睡好并告诉同事“筛查只是带来恐慌”；病理结果良性。
::: solution
**把伤害诚实处理（[[#def-principles]]、[[#def-programmes]]、[[#def-delivery]]）：先纠正事实而不纠正情绪：召回不等于癌症（多数被召回者最终无癌，而这恰是筛查为了不漏掉癌症所付出的代价）；但对她而言这两周已经发生，所以要处理而不是最小化（并筛查急性应激与是否影响此后接受筛查的意愿——假阳性最大的长期后果是让人在下一次拒绝参加，这会把未来的真实风险升上去）——[[psychiatry/anxiety-disorders]]。技术的一层：为什么会被召回（致密的乳腺与重叠的假象与既往的稳定性缺失，所以“与旧片比较”是减少召回最有效的一步；而超声与放大摄影与活检的分工与各自的解释）；把她的结果讲清（良性的具体诊断与纤维囊性改变与“这与癌症无关”），给出明确的重返常规筛查的时间（含糊的“以后再说”是伤害）；并且不要在此之后追加不必要的影像（这是假阳性最常见的级联）——[[pathology/diagnostic-pathology]]、[[clinical-skills/medical-imaging]]。把她的判断纳入未来的决定：绝对数字的沟通（每千名筛查者在一个十年里避免的死亡数、以及每千名中的假阳性与活检与过度诊断数），并说明“因此你可以选择继续或不再参加”是一个合法的选择——知情选择包括退出的自由——[[epidemiology-ebm/diagnostic-tests]]、[[medical-ethics-law/consent-capacity]]。系统的一层：把这一事件放进质量的监测（召回率与召回后的癌症率与双重读取率、以及每千筛查的活检数）；若本单元的召回率高于同行，问题在读片的阈值与流程而不是这位患者“太焦虑”；同时改进沟通的做法（在邀约时就说明“你可能被召回，且多半不是癌症”——预先的知情能把伤害降低，这也是多数国家在新邀约信中已加入的内容）——[[public-health/screening]]、[[clinical-skills/patient-safety]]。**
:::
:::

::: example 粪便筛查与那次出血 {#ex-fitness}
一名61岁男性在粪便免疫化学筛查中阳性而被召回做肠镜；同周他因便血在门诊被开了“等筛查的结果”；他的肠镜被排在四个月后；他有缺血性心脏病的支架。
::: solution
**两条路径互相踩脚（[[#def-programmes]]、[[#def-delivery]]、[[gastrointestinal/gi-bleeding-cancer]]）：最危险的一件事是这两条路径在等待彼此。原则：有症状者走诊断路径，筛查路径不能成为延迟的理由——便血加年龄属于需要尽快诊断评估的组合（结直肠癌与炎症性肠病与贫血与痔的鉴别），应当立即为他开诊断性的肠镜并要求全血计数与铁与（在筛查系统中）标记“症状转诊”，同时通知筛查的协调单位取消筛查路径中的那一次预约（或保留时间但改变其性质：同一台肠镜可以既完成诊断又回应阳性筛查，前提是同意与准备与报告按诊断标准来）——[[pathology/cancer-diagnosis]]、[[clinical-skills/clinical-reasoning]]。四个月的等待是不可接受的：阳性粪便试验之后的肠镜有明确的时限（数周），延迟本身是可避免伤害的来源并有法律与质量的后果；所以要做的是：立刻升级预约（并记录临床的理由）、在等待期内检查是否有报警的症状需要更早、并确保“未被处理的阳性”不会滑出系统（筛查的协调单位需要一份未完成的阳性名单并有主动跟进的人；这是筛查最常见的系统性失败——阳性结果被报告给患者而患者没有回应）——[[clinical-skills/records-handover]]、[[public-health/screening]]。操作的一层：肠镜的准备与抗血小板治疗（支架后双联或单联的时长与出血与支架内血栓的风险，与心内科与内镜共同决定停药与桥接的取舍）与镇静与陪同与工作的请假；以及准备不佳时的复做与失败后影像的替代——[[cardiovascular/vascular-disease]]、[[surgery/gastrointestinal-surgery]]。结果的沟通：无论结果是什么，都要明确“筛查结束/继续”的状态与下一次的间隔，并把出血的其他原因（痔与肛裂与憩室的病）处理掉，不要让患者带着一个未解释的症状离开——[[blood/haemostasis-bleeding]]、[[clinical-skills/communication]]。**
:::

## 通向何处

试验性能与阈值的算术见[[epidemiology-ebm/diagnostic-tests]]；证据的分级与偏倚见[[epidemiology-ebm/critical-appraisal]]；各癌种的诊断见[[pathology/cancer-diagnosis]]与[[gastrointestinal/gi-bleeding-cancer]]与[[obstetrics-gynaecology/gynaecological-cancer]]；新生儿筛查见[[paediatrics/newborn]]；公平与覆盖见[[public-health/determinants-inequalities]]；卫生经济的评价见[[public-health/health-systems-economics]]。

::: history
**筛查的历史始于一个没有对照的干预：1928年格雷的宫颈涂片技术与其后四十年的“常规骨盆检查”文化，直到1970年代才有对筛查效果的分析；1968年的威尔逊与荣格纳报告给了这个世界一份宪法（一份关于疾病与试验与治疗与规划的条件清单），其结构至今未变。测量方法的进步才是真正的转折点：对先入时间与长度与自愿者健康的偏倚的命名与统计处理（1960至1970年代的流行病学），使“筛查有效”的断言必须用随机试验与死亡率而非存活率来回答——于是有了乳腺的多中心试验（哈比斯通与瑞典与加拿大的试验及其至今未息的争议）与结直肠癌的乙状结肠与粪便试验与前列腺特异性抗原的随机试验（其结果在十余年后才成熟，并被用来支持“共同决策优于全民规划”）。同时，规划化本身成为一种技术：邀约与召回与实验室的双重读取与读片者的一致性检验与间期癌的监测与赔付的数据；质量控制成为可审计的指标；而“筛查项目”从医生的行为变成有指标与责任人的系统。近年出现三场新的争论：过度诊断的量化（甲状腺与前列腺与乳腺的原位病变与“癌症”这一词对患者的影响）、以人类乳头状病毒检测取代细胞学并使间隔延长（把资源从实验室转向“治愈”的闭环，以及男性与自我取样的伦理与可及）、以及液体活检的多癌种早筛（用“灵敏地找到更多信号”重述了筛查，但没有带来先入时间与过度诊断问题的解决方案）——每一项都再次表明，筛查的问题与其说是技术，不如说是证据与公平与欲望——[[public-health/screening]]、[[epidemiology-ebm/randomised-trials]]。**
:::

::: summary
- 筛查对健康人施医，因此其伤害的门槛高于对患者的治疗；收益是统计且延迟的，而伤害是即刻且个体的。
- 四种偏倚（先入时间、长度、自愿者健康、过度诊断）会让无效的检查看起来救命；只有以死亡率或发病率做终点的对照设计能回答。
- 一个规划是一条长流水线：邀约、采样、实验、读片、召回、诊断、治疗、终止——每一段都可能成为瓶颈或伤害的来源。
- 接受率是规划的公平切片：平均优秀而尾部失败是常态，且若不专门外展，差距会在“改进”的年份扩大。
- 知情选择需要绝对数、可比的框架、以及说明不筛查也是一种可辩护的选择。
- 可购买的检测绕过了规划的证据与保护；临床医师的任务是把未知的伤害讲成具体的东西，并把恐惧转化为真正有效的风险降低。
:::

**逐条走标准（[[#def-principles]]、[[#def-programmes]]、[[cardiovascular/vascular-disease]]）：疾病重要（是的，破裂性动脉瘤死亡率高，且多数破裂前无症状）；自然史已知（生长速率与“越大越易破”的关系清楚，且有一个可识别的早期阶段）；早期治疗更好（对达到阈值直径的动脉瘤，择期修复的死亡率远低于破裂的死亡率——这是这个论证成立的核心）；试验可接受且安全（超声无创、便宜、可重复）；但接下来的几条才是决定性的：必须有可治疗的人群与合理的成本效果（在女性与不吸烟者与七十岁以下的人群中患病率极低，筛查的阳性预测值与每挽救一命所需筛查的人数急剧恶化；而在男性吸烟者的六十多岁人群中两者都变得可辩护），以及筛查必须在系统中兑现（发现小动脉瘤意味着终身的影像随访与手术的能力与患者的焦虑——如果“发现的更多”不等于“能治得更好”，筛查就是伤害）。决定性的一条是流行病学所决定的收益与伤害之比：因此结论是按风险分层而非全民——一次性的超声提供给六十多岁的男性吸烟者（或有家族史者），而女性与不吸烟者不筛；并且必须配套：明确的直径阈值与随访的间隔与修复的标准与手术量与结局的公开与“未被处理的发现”的名单管理——[[public-health/health-systems-economics]]、[[surgery/vascular-urological-surgery]]。要补的诚实一条：这条界限会随人群风险变化（吸烟率下降与人口老化会改变成本效果），所以政策的复审要有日期——[[public-health/screening]]。**

::: exercise 就前列腺特异性抗原给出建议 {level=2}
一名56岁、无症状、父亲死于前列腺癌的健康男性问：“能不能给我开个前列腺特异性抗原检查？”写出你的谈话结构。
::: solution
**共同决策的谈话（[[#def-principles]]、[[#def-programmes]]、[[medical-ethics-law/consent-capacity]]）：结构分五步。一，承认他的理由（家族史确实使风险升高，这不是焦虑，是流行病学；他的父亲之死是可理解的动机）。二，说明这个试验是什么（一个器官的标志而非癌的标志：升高见于增生与炎症与操作与年龄；正常也不排除癌）。三，给出双方的数字（在像他这样的男人中，多年的随访里每千名被筛者避免的癌症死亡数很小、而假阳性与活检的并发症（出血与感染与少见的脓毒症）与“发现后不治疗”的焦虑与最终被过度诊断的比例较高；而家族史者绝对风险更高，因此收益与伤害的比与他这个人的年龄与预期寿命与价值观有关）。四，给出可能的路径（不查、与他约定数年后复查、或先做影像与风险分层的现代路径——磁共振与靶向活检与主动监测的策略，这些正是把“发现即治疗”的旧困境拆开的地方）。五，把决定交还给他（“这不是有正确答案的问题；如果你更在意避免不必要的治疗，就不查；如果你更在意尽早知道，我们就查”）——[[pathology/cancer-diagnosis]]、[[pathology/cancer-biology]]。要避免的两件事：把它当作“患者的无知”而拒绝讨论（他会自己去查，且在没有任何解释的情况下拿到一个数字）；以及把它当作“反正人人都该查”（一个有家族史的男人在知情之后选择检查，是完全合理的选择）。最后，无论结论如何，都要写下你给了哪些数字与他的决定，并留下复谈的门——[[clinical-skills/communication]]、[[clinical-skills/records-handover]]。**

::: exercise 修好覆盖的缺口 {level=2}
某地的乳腺筛查在最高剥夺五分位的覆盖为46%、最低为78%；预算与人力不足以增加一次筛查的总量。请给出一年的行动计划。
::: solution
**在总量不变下提高覆盖（[[#def-delivery]]、[[public-health/determinants-inequalities]]）：先弄清为什么低（不要用“文化不关心”来代替调查）：常见的可修原因有——不知道或有邀约但没有（地址与身份与登记的缺失、移民与新迁入者不在系统内）、时间（不能请假与没有儿童照护与交通）、恐惧与误解（“疼与癌症与会被切”与被拒绝过的经历与对辐射与对乳头的压迫）、语言与读写与认知障碍、以及对机构的信任。行动的设计要匹配原因：一，把邀约改造（多语言的语音与短信与面对面的电话而非信件、并在信里预先说明“你可能被召回且多半没事”与“检查约二十分钟与会有不适但短暂”，以及由同社区的人拨打）；二，把服务搬走（移动的检查车开到人们已在的地方：社区中心与宗教场所与市场的停车场与傍晚与周末的时段，以及不设预约门槛与允许陪同与不设文件的核对）；三，把一次接触变成多次机会（把筛查与其他服务合并：在诊所与药房与学校的家长会上、在慢病的随访时、并在“错过者”的名册上做三轮的主动跟进与记录结果）；四，把信任建成常设的（付费给社区的组织而不是租用它们、并让她们参与设计与评估与“被漏掉者”的名册）。测量：按五分位与社区与语言的覆盖与“从未被筛过”的比例；以及公平影响的评估（在改进时不要让最高覆盖的组更快上升，那会扩大差距）；并监测伤害（假阳性率与召回后的等待时间，因为在覆盖不足的人群中一旦启动，级联的能力必须跟上）——[[public-health/screening]]、[[clinical-skills/patient-safety]]。**

::: exercise 评判一项新检测 {level=3}
一家公司宣称其血液的多癌种早筛检测“一次可查五十种癌、灵敏度79%、特异度99.5%”，已获某些地区的销售许可，并邀请你的卫生系统为其覆盖付费。请给出评估。
::: solution
**评估一个“信号很强”的新技术（[[#def-principles]]、[[#def-programmes]]、[[epidemiology-ebm/diagnostic-tests]]）：先把数字翻译：特异度99.5%听起来极高，但在患病率1%的人群中，每千人会有约五个假阳性（与十个真阳性），而在患病率0.1%处绝大多数阳性是假的——而“假阳性的下游”是一次以定位不明的信号为起点的全身搜索（重复的影像与内窥镜与焦虑与偶然发现的进一步检查），这正是此类检测的主要伤害。灵敏度79%是“总体”的加权值：对某些癌种的灵敏度很高、对早期与常见者很低——因此要按癌种与分期分别看，并问“被更早发现的是哪一种（是不是本来就预后好的那种，即长度偏倚）”。缺少的三类证据：一，随机或类随机设计中的死亡率或分期后移（以及最重要的全因死亡）；二，在真实筛查人群（含合并症与不同年龄与剥夺水平）而非富集的门诊人群中的性能；三，下游的能力与成本（谁做诊断检查、要多久、容量在哪里、以及在系统已满时新增的量会挤掉谁——这是被系统性地忽略的机会成本）——[[public-health/health-systems-economics]]、[[pathology/diagnostic-pathology]]。因此建议：不纳入公共规划（现阶段），允许其在明确的评估框架内运行（注册与预注册的终点与覆盖率的分层报告与对过度诊断的监测）；同时给出临床医师对“患者自费做了并拿到一个阳性”的应对路径（不要把孤立的液体活检阳性当作出生的第一个事实，要按检测的阳性预测值重估并优先做可定位的检查，并在阴性但症状存在时绝不因此推迟诊断路径）；并把“销售许可”与“规划采用”区分清楚——前者的标准是“不误导”，后者的标准是“人群净收益”，两者不同——[[clinical-skills/clinical-reasoning]]、[[medical-ethics-law/professionalism-regulation]]。**

::: example 降级的那个决定 {#ex-deesc}
新的指南把低级别与低病毒负荷的宫颈病变的处理从“锥切”改为“观察”；一名31岁、希望两年内怀孕、曾被建议锥切的女性带着两份不一致的意见来门诊问“到底要不要动刀”。
::: solution
**把“少即是多”解释到位（[[#def-programmes]]、[[#def-delivery]]、[[obstetrics-gynaecology/gynaecological-cancer]]）：先说明为什么改：多数低级别的病变与一过性的人类乳头状病毒感染会在数年清除；锥切切掉的常常是终生不会致病的病变，而它带来可测量的伤害（早产与胎膜早破与宫颈狭窄，以及对生育与妊娠的具体风险与“切得越多风险越高”的剂量反应）——这是筛查史上罕见的“减少治疗反而更好”的情形，也解释了为何新指南把观察设为默认——[[obstetrics-gynaecology/pregnancy-complications]]、[[pathology/cancer-biology]]。把她的具体情况说清：她的细胞学与分诊与活检的结果与病毒负荷与是否存在高级别的可疑、以及“观察方案”的实际内容（多久复查一次、做什么、什么条件下转为治疗）；以及“观察”不等于“不管”，它需要她能回来（这在她计划怀孕的两年里必须与产科的计划一起排）。她的顾虑要正面回答：对癌症的恐惧（把绝对风险与随访的保护力给出：在规律随访下进展为浸润癌的风险很低，且随访能捕捉到绝大多数）、对怀孕的顾虑（保留宫颈的益处正是此处）、以及“两份意见不一致”本身的不确定感（承认它并说明为什么改变、以及本中心的立场与依据，而不是把责任推给“文献”）——[[clinical-skills/communication]]、[[epidemiology-ebm/critical-appraisal]]。系统的一层：把这类降级变成可运行的实践（一致的报告语言与治疗与观察的界限与自动的随访提醒，因为在降级方案里失访是最主要的伤害——把一个“暂不治疗”变成“没人跟进”是不可接受的）；并把生育的结局纳入监测（锥切率的改变与妊娠结局的队列与患者的体验），以及教育患者：“筛查的目标是不得癌症，而不是发现尽可能多的病变”——这一句话能化解大部分对“为什么不做掉它”的疑问——[[public-health/screening]]、[[pathology/diagnostic-pathology]]。**
:::

::: example 没有治疗的新生儿筛查 {#ex-nbsx}
串联质谱的新生儿筛查发现一名婴儿有一种罕见代谢病的生化标志；没有已知的有效治疗；父母已经在网上查到“最坏的情况”并在等一个能承诺什么的医生。
::: solution
**筛查的边界在这里最尖锐（[[#def-principles]]、[[#def-programmes]]、[[genetics/genetic-testing]]）：先做能做的：确认（复查标本与定量的生化与代谢与分子的确认、以及急性的风险评估：是否有需要立即处理的代谢失代偿风险，有些“无治疗”的病仍需急性的喂养与监测方案）；然后才谈“这是什么意思”——[[paediatrics/newborn]]、[[cell-biochemistry/lipid-amino-acid-metabolism]]。信息的处理：不要在同一次里给出所有可能（表型的谱系宽到无法预测，同一个生化标志可以对应从无症状到严重）；给出当下能确定的与不能确定的，并承诺一个时间表与一个联系人（“每周五我打电话，无论有没有新消息”——可预期的沟通是不确定中最有效的镇定剂）；并把“没有治疗”翻译成“没有治愈性的药，但仍然有可以做的”（急性的预案与生长与发育与营养的监测与康复的早期介入与家庭的心理支持，以及登记与研究的机会，同时说清研究不等于治疗）——[[clinical-skills/communication]]、[[medical-ethics-law/consent-capacity]]。伦理的问题要摆到桌面上而不是藏在诊室里：筛查无有效治疗的疾病正当吗？支持方的论证（知情与准备与避免误诊的漫游与生育的咨询与登记与家族的风险）与反对方的论证（标签与焦虑与保险与歧视与“未知的孩子”与父母身份的负担）都有分量；而当代的答案是程序性的：纳入什么由独立的评估决定、必须配套遗传的咨询与治疗之外的支持、存储的二次使用与知情必须清晰、以及家庭应参与决策——[[genetics/genetic-testing]]、[[public-health/screening]]、[[medical-ethics-law/justice-resources]]。最后：把这一例放进质量与公平的复盘（确认与首诊告知的时长与父母体验的调查、以及是否只有会说英语与受过高等教育的家庭才获得了“理解发生了什么”的能力——这是筛查中最隐蔽的不公平）——[[public-health/determinants-inequalities]]。**

::: exercise 解释间期癌 {level=1}
一名58岁女性在两次正常的乳腺筛查之间被诊断出浸润性乳腺癌；她认为“筛查失败了”。请解释间期癌，并说明它是否等于过失。
::: solution
**间期癌的两类与它们的意义（[[#def-principles]]、[[#def-programmes]]、[[#def-delivery]]）：定义是“在一次阴性的筛查之后、下一次预定筛查之前出现的癌症”；它有两类完全不同的原因。生物学的一类：这类肿瘤生长快，从可被检出的阈值到症状之间的窗口很短——也正是长度偏倚的另一面：筛查最擅长发现的是生长慢的病变，而致死性最强的病变最常成为间期癌。技术与人的一类：病变本可被看见但被漏了（影像的密度与位置与读片的疲劳与未做双重读取与未比较旧片与取材与设备的因素）。区分二者对她是必要的（“你的癌症属于哪种”应当被回答，而不是用“筛查不是完美的”糊过去），对系统则是质量指标：间期癌率与按单位与读片者的分布及其回顾的盲法复检——[[pathology/diagnostic-pathology]]、[[clinical-skills/medical-imaging]]。是否等于过失：多数情况下不是；但要检查可避免的成分（那次筛查的影像是否合格与是否被双重读取与阳性结果是否被召回与她的致密乳腺是否被考虑与是否需要追加超声，以及她此前的症状是否被正确地当作“症状”而不是“筛查的阴性”）。对她的解释要包括：筛查的目的是降低死亡而不是保证没有癌症；她仍应继续按间隔参加（既往的假安全感与“反正查不出”的幻灭都会导致退缩）；以及在治疗之后与筛查的关系——[[clinical-skills/communication]]、[[pathology/cancer-biology]]。系统要做的收尾：把这一例纳入间期癌的审计（每一个都要被分类而不是被遗忘），并把发现的缺陷回馈到培训与流程与设备——因为这一环节是筛查质量的最终检验——[[clinical-skills/patient-safety]]。**

::: exercise 应对主动要求筛查的患者 {level=2}
一名67岁、无症状、无家族史的健康男性要求做一次全身磁共振的“癌症筛查”（他在广告上看到）；他说“反正不疼，查一下安心”。
::: solution
**回应“主动要求的筛查”（[[#def-principles]]、[[#def-delivery]]、[[clinical-skills/communication]]）：不要以“没有证据”结束谈话（这会让他觉得你在省钱），而是把他的动机当作问题来回答：他在怕什么（一次朋友的死亡与自己的年龄与某个未解的症状）；先做有效的（把这些年的健康行为与真正对他有效的筛查项目补齐：结直肠与（若他吸烟）肺与血压与血脂与免疫与骨与眼底与听力的实际可及，并把它们安排在同一天）；再讲清他要求的那一项的具体伤害（偶然发现的语义不确定率很高、多数会引向进一步影像与穿刺与并发症、并常常以“观察”结束，而“观察”本身就抵消了他想要的安心；以及一次阴性并不降低他未来患癌的风险，因此不能替代真正有效的项目）。把这些做成可比的量（每百人中有多少人因偶然发现而接受一次穿刺与其中多少最终无害），并把“我不想花冤枉钱买焦虑”作为他的目标加以肯定。若他仍要做：不阻止（他有自主权且风险主要是财务与心理），但要书面说明这是超出规划的证据之外、约定“除……之外不再追加”的边界、指定一个负责的临床医师来解释结果，并承诺在他拿到一个不确定的报告时仍然会解释——最糟糕的结果不是检查本身，而是有人拿着一份无人解释的报告独自焦虑——[[epidemiology-ebm/diagnostic-tests]]、[[clinical-skills/medical-imaging]]。系统层面：推动对直接面向消费者的检测广告的规管（要求以绝对数与人群与终点披露证据）、以及给临床医师一份“如何回应自费筛查”的标准应答（因为这类请求会持续增长，而每一次临场的即兴回答质量不一）——[[public-health/screening]]、[[medical-ethics-law/professionalism-regulation]]。**

你在主持一个结直肠癌筛查规划的季度委员会：覆盖率在下降、腺瘤检出率的分布很宽、有六例“阳性未处理”超过九个月、并且肠镜的等待在中位数十周。写出你的议程与决策。
::: solution
**委员会的议程（[[#def-programmes]]、[[#def-delivery]]、[[gastrointestinal/gi-bleeding-cancer]]）：按风险的量级排议程，而不是按谁提交得早。第一位是“六例超过九个月的阳性未处理”：这是可避免伤害与责任与公平的三重失败；决策：每一例当次即指定负责人与完成日期、给出系统的原因（是名单丢失还是患者不回应还是预约被取消）、并在三十天内向委员会回报；同时给“未被处理的阳性”设置硬性的护栏（自动升级至外展电话与上门与全科的三重联系与一个专门负责此名单的人，因为在筛查中最常丢的不是数据而是人）——[[clinical-skills/records-handover]]。第二位是肠镜的容量与十周的中位等待：这是覆盖与伤害的共同上游；决策：按阳性的定量结果分层（粪便血红素浓度越高越优先，这是已被证明能提高癌症检出效率的分诊办法）、把检查的时段在多个内镜单位之间共享、以及把检查与随访与“低风险的复查”从诊断能力中分离出来（否则筛查挤掉了有症状者，或反之）；并测量“从阳性到检查”与“从检查到结果”的分布而不是平均（尾部才是伤害所在）——[[pathology/diagnostic-pathology]]。第三位是腺瘤检出率分布很宽：这是质量的核心指标；决策：为每人（而非每单位）设定最低阈值、提供盲法回顾的复检与反馈与培训、并在持续低于阈值时改变执业的安排（这一步最困难，但筛查的正当性正建立在这里）——[[public-health/screening]]、[[clinical-skills/patient-safety]]。第四是覆盖率下降：按五分位与语言与年龄分解并交回给交付团队，附上明确的外展要求与三个月的复审。最后一条：把委员会的每一份决定与指标写成一页对公众透明的简报（筛查依赖信任，而信任依赖可见的问责）——[[public-health/determinants-inequalities]]。**

::: exercise 划定筛查的边界 {level=3}
政府要求你为一个“人人都在做但证据不足”的检查（甲状腺的超声筛查）给出建议：某地曾以超声普查儿童与年轻女性的甲状腺结节，随后手术量与终身甲状腺素替代的比率大幅上升。
::: solution
**划定边界（[[#def-principles]]、[[#def-programmes]]、[[endocrine/thyroid]]）：这一例是过度诊断的教科书（在流行学上已被清楚说明：普查发现的微小乳头状癌大量增加而死亡率几乎不变，即“癌症的发病率上升而死亡不变”是过度诊断最有力的证据）；被“治疗”的许多人其实终其一生不会有症状，而他们得到了甲状腺的切除与并发症的风险（喉返神经与甲状旁腺）与终身的服药与“我是癌症患者”的身份——伤害的量级说明：在做出推荐之前，收益必须与这些代价相比——[[pathology/cancer-biology]]、[[pathology/cancer-diagnosis]]。建议的四段：一，明确不做全民的甲状腺超声筛查（包括儿童与孕妇与无症状的成人），并说明理由（无死亡率获益的证据、显著的伤害、以及“没有安全阈值”的过度治疗倾向）；二，把有指征的评估界定清楚（可触及的肿块与压迫的症状与颈部照射史与家族性的综合征与超声发现大结节的处理路径），并推动“主动监测”作为一种正当的选择（对微小的低风险病灶，随访而非手术已有多年的证据，包括在普查高发地区）；三，把决策的规则制度化（报告的用语避免“癌”字对极低风险病灶的滥用、多学科强制讨论、患者材料中给出绝对的过度诊断率、以及对治疗量的监测与同行比较）；四，用这一案例教育（把甲状腺作为其他“越查越多”的筛查的原型：前列腺与乳腺的原位与肺的磨玻璃与皮肤的黑素，说明“发现更小的病变更早”是一个需要检验的假设而不是自动的好事）——[[epidemiology-ebm/critical-appraisal]]、[[medical-ethics-law/consent-capacity]]。最后要处理政治的现实：撤回一项“人人都在做”的检查会遭遇（患者与外科医师与既有的筛查机构）的抵制，所以要与“我们仍关心甲状腺健康”的正面主张一起提出（碘与放射暴露的管理与症状的快线与对结节的规范随访），并预先公开伤害的数字——诚实是这类政策唯一可持续的基础——[[public-health/health-systems-economics]]、[[clinical-skills/communication]]。**
