一位50岁的女性收到一封邀请她做乳腺X线摄影检查的信。她没有任何症状。如果她去检查，最可能的结果是正常。每一百名女性中有几人会被召回做进一步检查，而其中大多数在忐忑不安地度过几周之后被证实没有癌症。人数更少的一部分人会被早期发现癌症，其中一些人会因此免于死于乳腺癌。还有少数人被发现患有一种终生都不会伤害她们的癌症，她们将接受手术、放疗，也许还有内分泌治疗，而这些只会带来伤害。没有人，包括她的医生，能事先告诉她会属于哪一组。

筛查不同于普通的临床医学。当事人并不是带着问题前来；而是卫生服务机构主动接触一个健康的人并提供检测。这改变了伦理要求：项目必须确信它在整个受邀人群中利大于弊，而每个人都必须能够作出知情选择。本章解释筛查项目必须满足的标准、检测性能在筛查人群中的表现、使筛查看起来比实际更好的偏倚、过度诊断、截至2026年的英国筛查项目，以及项目如何运行和评价。本章以[[epidemiology-ebm/diagnostic-tests]]中关于检测准确性的内容为前提。

## 什么是筛查 {#definition}

::: definition 筛查 {#def-screening}
**筛查**是识别表面健康、但某种疾病或状况风险可能增加的人的过程，以便向他们提供信息、进一步检查和适当治疗，从而降低其风险或减少疾病的并发症。（此定义沿用英国国家筛查委员会所用的定义。）

筛查不是诊断。筛查结果阳性意味着需要进一步检查；诊断由后续检查作出。筛查**项目**包括整个路径：确定并邀请符合条件的人群、检测、告知结果、诊断性随访、治疗、质量保证和评价。
:::

筛查不同于**病例发现**（case-finding），后者是临床医生对因其他原因前来就诊的人进行检测（例如在就诊时测量血压，或通过触诊脉搏为老年人检查心房颤动）。筛查也不同于对已知高危者的**监测**，例如切除进展期腺瘤后的结肠镜监测，或对携带*BRCA1*变异的女性每年进行MRI检查，这些属于专科照护的一部分。

项目可以是**基于人群的**（某一年龄组的所有人，如肠癌筛查）、**有针对性的**（确定的较高风险群体，如为吸烟者进行的肺癌筛查），或**机会性的**（在人们因其他原因就诊时提供，没有系统的邀请）。拥有召集和再召集登记系统的人群项目，比机会性检测能达到更高、更公平的覆盖率。

## 筛查项目的标准 {#criteria}

::: definition 威尔逊与容纳原则 {#def-wilson-jungner}
1968年，威尔逊（James Wilson）和容纳（Gunnar Jungner）为世界卫生组织撰文，提出了筛查的十项原则：

1. 所筛查的疾病应是重要的健康问题。
2. 对已确诊的患者应有公认的治疗方法。
3. 应具备诊断和治疗的设施。
4. 疾病应有可识别的潜伏期或早期症状期。
5. 应有合适的检测或检查方法。
6. 检测应为人群所接受。
7. 应充分了解该病的自然史，包括从潜伏期发展到显性疾病的过程。
8. 对于把哪些人作为患者治疗，应有公认的政策。
9. 病例发现（包括诊断和治疗）的费用，与整个医疗照护可能的支出相比，在经济上应是平衡的。
10. 病例发现应是一个持续的过程，而不是“一劳永逸”的项目。
:::

现代标准增加了反映后来经验的要求。**英国国家筛查委员会**（UK NSC）为英国四个地区的部长提供建议，它按照疾病、检测、干预、项目及其实施等几组标准评估拟议的项目。最重要的新增要求是：

- 应有来自高质量**随机对照试验**的证据，证明该项目能降低死亡率或发病率。如果筛查的目的只是提供信息（如某些产前筛查），则必须有证据表明检测能准确衡量风险，且这些信息对受检者有价值。
- 获益应超过检测、诊断程序和治疗带来的身体和心理**危害**。
- 与这笔钱的其他用途相比，该项目应具有**成本效果**。
- 应有**质量保证**计划，以及管理和监测项目的计划。
- 人们应能在关于获益和危害的循证信息基础上作出**知情选择**。
- 应已考虑过管理该疾病的所有其他选择（如一级预防）。

大多数拟议的筛查项目不符合这些标准。UK NSC已建议不对许多疾病进行人群筛查，包括前列腺癌、卵巢癌以及一般人群中的2型糖尿病。

## 检测在筛查人群中的表现 {#performance}

在筛查人群中，疾病很少见，因此即使是好的检测，产生的也大多是假阳性。这是筛查中最重要的算术。

::: example 乳腺X线摄影的阳性预测值 {#ex-ppv}
在一个示例性的筛查轮次中，每1,000名受检女性中有8人患乳腺癌。在这一轮中，乳腺X线摄影的灵敏度为85%，特异度为96%。在10,000名受检女性中，有多少人被召回？其中多少人患癌？阳性预测值是多少？
::: solution
患癌女性：$10{,}000 \times 0.008 = 80$。真阳性：$80 \times 0.85 = 68$。假阴性：12。

未患癌女性：9,920。假阳性：$9{,}920 \times 0.04 = 396.8 \approx 397$。

被召回：$68 + 397 = 465$，召回率约为4.6%。

$PPV = 68/465 = 14.6\%$。每七名被召回的女性中约有六人没有癌症。

这就是为什么召回信必须说明大多数被召回的女性最终被证实没有癌症，也是为什么召回后应迅速进行评估。12个假阴性同样重要：其中一些人会在下次受邀之前因出现症状而就诊，成为**间期癌**。
:::
:::

:::

筛查项目使用特定的性能指标：

- **覆盖率**：在规定期间内接受筛查的符合条件人群的比例。**参与率**是某一轮受邀者中参加筛查的比例。
- **召回率**或**阳性率**：受检者中结果阳性的比例。
- **检出率**：每1,000名受检者中发现的病例数。
- **间期癌**：在一次阴性筛查之后、下一次筛查之前诊断的癌症。有些是检测漏掉的癌症（假阴性）；另一些是筛查之后才出现的快速生长的癌症。
- **项目灵敏度**：筛查发现的病例数除以筛查发现病例数与间期病例数之和。

### 选择阈值 {#threshold}

许多筛查检测给出连续的结果，由项目选择阈值。用于肠癌的粪便免疫化学检测（FIT）测量粪便样本中的血红蛋白浓度。较低的阈值能发现更多的癌症和进展期腺瘤，但会使更多人接受结肠镜检查，而结肠镜检查有费用、不适以及穿孔和出血的小风险。项目的容量是决策的一部分：结肠镜服务无法应付的阈值会延长每个人的等待时间。

在英格兰，肠癌筛查的阈值原为每克粪便120 µg血红蛋白。2026年1月，NHS英格兰宣布自2026年2月起将其降至80 µg/g，到2028年在全国逐步推行，使英格兰与苏格兰和威尔士保持一致。NHS英格兰估计，这一改变每年将多在早期发现约600例癌症（增加约11%），而转诊做进一步检查的参与者比例将从约每100人中2人升至约每100人中3人。

## 为什么筛查需要试验：偏倚 {#biases}

早期发现疾病必定是好事，这似乎显而易见。三种偏倚说明了为什么这并不显而易见，以及为什么筛查必须在随机试验中评价。

::: theorem 筛查以随机试验中的死亡率来评判 {#thm-endpoint}
从诊断时起计算的生存期不是衡量筛查获益的有效指标，因为即使筛查没有改变任何东西，它也会因领先时间和病程长度偏倚而被夸大。把接受筛查者与未接受筛查者相比较，会因选择偏倚而夸大效果。因此，筛查项目的获益必须在随机试验中衡量，比较*受邀*筛查组与未受邀组的疾病别（最好还有全因）死亡率，或晚期疾病的发生率。
:::

::: proof
**领先时间偏倚。** 筛查比症状更早地发现疾病。如果治疗不改变死亡时间，从诊断起计算的生存期在筛查发现的病例中仍然更长，仅仅因为计时开始得更早。诊断提前的时间间隔就是**领先时间**。

**病程长度偏倚。** 生长缓慢的肿瘤处于临床前可检出期的时间比生长迅速的肿瘤更长，因此任何时刻进行的筛查都更可能发现生长缓慢的肿瘤。生长迅速的肿瘤更常以间期癌的形式出现。因此，即使筛查没有任何作用，筛查发现的病例平均预后也更好。过度诊断是病程长度偏倚的极端情况：肿瘤生长如此缓慢，以至于永远不会引起症状。

**选择（健康志愿者）偏倚。** 接受筛查的人与拒绝筛查的人不同：他们平均更富裕、更注重健康、吸烟的可能性更低，更可能有其他健康行为。即使没有筛查，他们的死亡率也会更低。

随机化消除了选择偏倚，因为受邀组和未受邀组在平均水平上相似。比较两个完整组别的死亡率（按意向筛查分析，包括未参加者），消除了领先时间偏倚和病程长度偏倚，因为终点是在规定期间内规定人群中的死亡，而不是从诊断起计算的生存期。疾病别死亡率是常用的主要终点，因为全因死亡率需要大得不切实际的试验；但疾病别死亡率的下降可能被检查或治疗造成的死亡所抵消，也可能因死因归属错误而被扭曲。
:::

::: example 领先时间 {#ex-lead}
一名男性患肺癌，60岁时CT可以检出。如果不筛查，肿瘤会在63岁时引起症状并被诊断。他在67岁时死于该病，而且在本例中，无论在哪个阶段治疗都不改变死亡日期。计算有筛查和无筛查时他从诊断起的生存期，并说明在每种情况下他是否算作5年生存者。
::: solution
无筛查：63岁诊断，67岁死亡：生存期4年。他不是5年生存者。

有筛查：60岁诊断，67岁死亡：生存期7年。他是5年生存者。

领先时间为3年。筛查把他从“5年内死亡”变成了“5年生存者”，却没有让他多活一天。不过，他多了3年知道自己患有癌症的生活，并承受了治疗的影响。如果许多病例都是这样，一个项目就会显示5年生存率提高，而死亡率并未下降。
:::
:::

::: warning 生存统计数据的改善并不表明筛查有效
引入筛查项目后，从诊断起计算的5年生存率几乎总会上升，疾病的发病率通常也会上升，因为病例被更早发现，且有些属于过度诊断。即使筛查没有挽救任何生命，这两种变化也会发生。因此，“筛查使5年生存率从60%提高到85%”之类的说法并不是获益的证据。正确的证据是随机试验中疾病别死亡率的下降（或者对于成熟的项目，是考虑了这些偏倚的、关于死亡率的严谨观察性研究），以及晚期疾病发生率的下降。
:::

## 过度诊断 {#overdiagnosis}

::: definition 过度诊断与过度治疗 {#def-overdiagnosis}
**过度诊断**是对在当事人一生中永远不会引起症状或死亡的疾病作出诊断。它的发生是因为疾病进展非常缓慢或根本不进展，或者因为当事人先死于其他原因。被过度诊断的人无法被逐一识别：他们看起来与疾病被早期发现并成功治疗的人完全一样。

**过度治疗**是对被过度诊断的疾病进行治疗。它只会带来伤害。

过度诊断与假阳性结果不同。假阳性是未患病者的筛查检测呈阳性；过度诊断是经病理证实的、真实的诊断，只是这种疾病并不需要被发现。
:::

过度诊断在乳腺癌、前列腺癌、甲状腺癌和肺癌筛查中最为重要，在某些癌前病变的筛查中也很重要，例如年轻女性的宫颈上皮内瘤变，其中很大一部分会自行消退。过度诊断的估计方法是：在筛查停止后经过长期随访，比较筛查组和未筛查组的累积发病率；永远不会“追平”的超额发病就是过度诊断。

::: example 乳腺癌筛查的获益与危害 {#ex-overdiagnosis}
英国乳腺癌筛查独立专家组（Independent UK Panel on Breast Cancer Screening，2012年）估计，每10,000名受邀在此后20年接受筛查的50岁英国女性中，约可预防43例乳腺癌死亡，约有129例癌症被过度诊断。(a) 每预防一例死亡，有多少女性被过度诊断？(b) 必须邀请多少女性筛查20年才能预防一例乳腺癌死亡？(c) 应如何向一位正在决定是否参加筛查的女性呈现这些信息？
::: solution
(a) $129/43 = 3.0$：每预防一例乳腺癌死亡，约有三名女性被过度诊断。

(b) $10{,}000/43 = 233$；专家组引用的数字是“约235名”受邀女性预防一例死亡。

(c) 专家组估计，筛查使受邀女性的乳腺癌死亡率降低约20%，因此对大多数女性来说，这一决定确实是平衡的、个人的。信息应以规定时期内的绝对数字给出，获益和危害采用同样的格式，同时说明假阳性召回的可能性。NHS乳腺筛查宣传单呈现的就是这样的数字，因此拒绝筛查的女性不会被视为作出了非理性的选择。专家组指出，其数字存在不确定性，且基于几十年前的试验；此后治疗已有改进，这可能降低了早期发现的获益。
:::
:::

## 2026年的英国筛查项目 {#uk-programmes}

UK NSC推荐项目；各地区负责委托和运行。除另有说明外，以下细节指截至2026年的**英格兰**；苏格兰、威尔士和北爱尔兰有类似的项目，但在年龄、间隔和检测方面有一些差异。项目会变化，因此应以现行NHS和UK NSC指南为准。

### 癌症筛查 {#cancer-programmes}

| 项目 | 受邀对象 | 检测与间隔 |
|---|---|---|
| 宫颈癌 | 25～64岁的女性及有子宫颈的人 | 以高危型HPV检测为初筛；仅在发现HPV时做细胞学检查。HPV阴性者每5年一次（25～49岁人群自2025年7月1日起改为5年一次，此前为每3年一次；50～64岁人群原本就是每5年一次）。 |
| 乳腺癌 | 50岁至71岁生日前的女性 | 每3年一次乳腺X线摄影。71岁以上者可自行申请。家族性风险极高的女性从更年轻时起另行监测。 |
| 肠癌 | 50～74岁人群 | 每2年一次居家FIT检测。74岁以上者可申请检测盒。阈值自2026年起从120 µg Hb/g降至80 µg Hb/g。 |
| 肺癌 | 曾经吸烟、经评估为高风险的55～74岁人群 | 低剂量CT，符合条件者每2年复查一次。正在全国推广，计划于2029/30年度实现全面覆盖。 |

**宫颈癌筛查**非常有效，因为它主要是一个*预防*项目：它发现癌前病变（宫颈上皮内瘤变），并在癌症发生之前将其切除。英格兰于2019年改用HPV初筛。HPV检测阴性能在数年内提供非常可靠的保证，这就是为什么HPV阴性者采用较长的间隔是安全的；发现HPV者则提前复查。自2026年起，NHS英格兰开始向逾期未筛查的人提供HPV自采样检测盒，主要面向觉得窥器检查有困难的人。随着青少年期接种过HPV疫苗的出生队列进入筛查年龄，高危型HPV的流行率正在下降，这将降低检测的PPV，并可能使项目进一步调整。

**乳腺癌筛查**在福里斯特报告（Forrest Report，1986年）之后于1988年开始。AgeX试验是一项纳入数百万女性的整群随机试验，一直在检验在47～49岁或71～73岁多做一次筛查是否能降低死亡率；最终结果预计要到21世纪30年代才能得出。

**肠癌筛查**采用FIT，也通过发现腺瘤并在结肠镜检查中切除来预防癌症。对较早的愈创木脂粪便隐血试验的试验显示，受邀者的结直肠癌死亡率降低约15%；FIT更灵敏、更易被接受，而且是定量的，因而可以设定阈值。

**肺癌筛查**依据的是一些试验（美国国家肺筛查试验和荷兰-比利时NELSON试验），这些试验发现，在高危人群中使用低剂量CT可使肺癌死亡率降低约20%～25%。在英格兰，在全科医生处登记、曾经吸烟的55～74岁人群会被邀请进行风险评估，高风险者接受CT检查。该项目包括戒烟支持，因为戒烟仍是对这些参与者最有效的干预。

**前列腺癌。** PSA检测特异度低，会造成大量过度诊断，试验显示它最多只能小幅降低前列腺癌死亡率，代价是许多男性接受了不必要的治疗。2026年5月，UK NSC作出最终建议，反对人群筛查，也反对对黑人男性进行针对性筛查，但建议对携带*BRCA2*变异且有相关家族史的45～61岁男性每2年进行一次针对性筛查。截至2026年底，是否以及如何实施由英国各政府决定。无症状男性在与全科医生进行知情讨论后，仍可要求做PSA检测。

### 非癌症筛查 {#other-programmes}

- **腹主动脉瘤（AAA）。** 男性在年满65岁的那一年受邀进行一次性超声检查；年龄更大的男性可自行申请。英国多中心动脉瘤筛查研究（MASS，2002年）表明，受邀男性在四年内与动脉瘤相关的死亡率降低约40%。主动脉直径决定处理方式：

| 主动脉直径 | 分类 | 处理 |
|---|---|---|
| 小于3.0 cm | 正常 | 结束随访；不再筛查 |
| 3.0～4.4 cm | 小型AAA | 每12个月超声监测一次 |
| 4.5～5.4 cm | 中型AAA | 每3个月超声监测一次 |
| 5.5 cm及以上 | 大型AAA | 紧急转诊至血管外科医生（2周内就诊） |

  患有小型或中型动脉瘤的男性还会接受心血管风险评估和建议，因为他们发生心肌梗死和卒中的风险很高。快速增大的动脉瘤（一年内增大1 cm或以上）也要转诊。

- **糖尿病眼病筛查。** 12岁及以上的糖尿病患者接受视网膜摄影检查，每年一次；对于连续两次筛查均无视网膜病变的低风险者，每2年一次。

- **产前筛查。** 孕妇接受以下筛查：HIV、乙型肝炎和梅毒；镰状细胞病和地中海贫血；唐氏综合征（21三体）、爱德华兹综合征（18三体）和帕陶综合征（13三体），在孕早期采用联合检测，对较高几率的结果可进一步选择无创产前检测；以及在18+0至20+6周超声检查中筛查结构异常。产前筛查与其他项目不同，因为其目的常常是为生育选择提供信息；中立、非指导性的信息至关重要。

- **新生儿和婴儿筛查。** 出生时和6～8周时的体格检查（NIPE）检查眼、心脏、髋关节和睾丸异常。新生儿听力筛查发现永久性听力损失。第5天的新生儿足跟血斑检测筛查镰状细胞病、囊性纤维化、先天性甲状腺功能减退症和六种遗传代谢病（苯丙酮尿症、MCADD、枫糖尿症、异戊酸血症、1型戊二酸尿症和同型胱氨酸尿症）。自2021年起，重症联合免疫缺陷（SCID）筛查在英格兰部分地区作为服务内评估开展。

## 运行一个项目 {#delivery}

### 质量保证 {#qa}

筛查检测的好坏取决于围绕它的项目。每个项目都设定**标准**（例如最低参与率、从检测到出结果的最长时间，以及在一定范围内的召回率），并由筛查质量保证服务机构监测。筛查项目的失误会同时影响许多人，而且可能多年不被察觉：过去的事件包括邀请中的计算机错误、样本误读和随访丢失。从召集-再召集登记到治疗的每一步都需要监测和审核。

### 参与率与不平等 {#uptake}

在较贫困地区、某些少数族群、学习障碍者或严重精神疾病患者、跨性别者和非二元性别者（他们可能没有被正确邀请）以及宫颈癌筛查中的较年轻人群中，参与率较低。由于不参加的人往往风险更高，这些群体的低参与率扩大了癌症结局的不平等。有帮助的方法包括：全科医生为邀请背书、短信和电话提醒、消除实际障碍（自采样、非工作时间预约）、提供其他语言和易读格式的信息，以及社区卫生工作者。减少参与率的不平等是每个项目的标准目标。

::: example 参与率的不平等 {#ex-uptake}
在一轮肠癌筛查中，两个地区各邀请20,000人。在A区（富裕），75%的人寄回了检测盒；在B区（贫困），55%的人寄回。假设参与者中癌症患病率在A区为3‰，在B区为4‰，项目能发现参与者中80%的癌症。每个地区发现了多少癌症？每个地区的受邀人群中有多少癌症因当事人未参加而未被发现？
::: solution
**A区。** 参与者：$20{,}000 \times 0.75 = 15{,}000$。其中癌症：$15{,}000 \times 0.003 = 45$；发现：$45 \times 0.8 = 36$。未参加者：5,000；其中癌症：$5{,}000 \times 0.003 = 15$。

**B区。** 参与者：$20{,}000 \times 0.55 = 11{,}000$。癌症：$11{,}000 \times 0.004 = 44$；发现：$44 \times 0.8 = 35.2 \approx 35$。未参加者：9,000；其中癌症：$9{,}000 \times 0.004 = 36$。

B区的癌症更多，但项目发现的数量大致相同，而未参加者中有36例癌症，A区为15例。（实际上，未参加者的患病率可能比参加者更高，使情况更糟。）提高B区的参与率很可能比改进检测预防更多的死亡。
:::
:::

### 知情选择 {#informed-choice}

筛查是提供的，而不是开具的。人们必须获得关于可能的获益、危害和局限性（假阳性、虚假的安心、过度诊断、后续检查的风险）的平衡信息，以便决定是否参加。拒绝是正当的选择，应予以尊重并记录。项目使用个人邀请，但这并不使参加成为强制性的，临床医生不应施加压力或夸大获益。英国的癌症筛查宣传单现在给出获益和危害的绝对数字，这与20世纪90年代具有劝导性的宣传单形成对比。

### 新检测及其所需的证据 {#new-tests}

新的筛查技术不断被提出：全身MRI、多基因风险评分，以及在血液中寻找肿瘤DNA的多癌种早期检测血液检测。这些技术必须满足与任何其他筛查检测相同的标准。由于领先时间和过度诊断，发现更多的癌症或更早发现癌症还不够。英格兰的NHS-Galleri随机试验自2021年起纳入了14万多人，旨在检验增加一项多癌种血液检测是否能减少晚期诊断的癌症数量，这是死亡率的替代指标。直接面向公众销售的商业筛查检测常常绕过这种评价，其假阳性给NHS带来了工作负担和危害。

::: quiz
一家私人诊所推出了一种新的胰腺癌血液检测。经该检测发现癌症的患者5年生存率为40%，而因症状就诊后诊断的患者为10%。哪一个结论是合理的？
- [ ] 该检测能挽救生命，应向所有人提供。
- [ ] 该检测能挽救生命，但仅限于高危人群。
- [x] 由于领先时间偏倚、病程长度偏倚和选择偏倚，这一比较无法说明该检测是否能挽救生命。
- [ ] 如果两组按年龄匹配，生存比较就是有效的。
::: solution
即使死亡没有推迟，更早的诊断也会延长从诊断起计算的生存期（领先时间）；筛查发现的肿瘤偏向于生长缓慢的肿瘤（病程长度偏倚），其中包括一些被过度诊断的肿瘤；而自费做私人检测的人与一般人群不同（选择偏倚）。按年龄匹配不能解决其中任何一个问题。只有比较受邀组与未受邀组胰腺癌死亡率（或至少是晚期疾病发生率）的随机试验，才能证明获益。
:::
:::

::: history
1928年，帕帕尼科拉乌（George Papanicolaou）证明，在阴道涂片中可以识别癌细胞；1943年他与特劳特（Herbert Traut）作了更详细的报道。“巴氏涂片”成为第一个广泛使用的癌症筛查检测。1963年在纽约开始的健康保险计划（HIP）试验是第一个乳腺癌筛查随机试验，显示乳腺癌死亡率有所下降。1968年，威尔逊和容纳为世卫组织出版了《疾病筛查的原则与实践》（*Principles and Practice of Screening for Disease*）。在英国，福里斯特报告（1986年）促成了1988年的NHS乳腺癌筛查项目，宫颈癌项目也在同年实现了全国计算机化的召集和再召集。英国国家筛查委员会成立于1996年。英格兰的肠癌筛查始于2006年，腹主动脉瘤筛查始于2009年。过度诊断的概念在20世纪70年代通过尸检研究和肺癌筛查试验得到认识，在2012年英国独立专家组对乳腺癌筛查进行评估之后成为筛查政策的核心。
:::

## 后续内容

检测准确性的数学在[[epidemiology-ebm/diagnostic-tests]]中展开，偏倚在[[epidemiology-ebm/bias-confounding]]中讨论。筛查是预防的一种形式，预防的级别在[[public-health/prevention-promotion]]中描述；疫苗接种目前正在改变宫颈癌筛查项目，见[[public-health/vaccination-programmes]]。项目是否值得其成本，用[[public-health/health-systems-economics]]中的方法评估。

::: summary
- **筛查**为表面健康的人提供检测，以识别风险增加者；阳性结果需要诊断性确认。项目是整个路径，而不只是检测。
- 项目应满足源自**威尔逊与容纳（1968年）**、经UK NSC更新的标准：重要的疾病且有可检出的早期阶段、良好且可接受的检测、有效的早期治疗、来自**随机试验**的死亡率或发病率降低的证据、获益超过危害、成本效果、质量保证和知情选择。
- 在低患病率下，大多数阳性结果是假的；阈值要在检出与随访负担和容量之间取得平衡。
- **领先时间**、**病程长度**和**选择**偏倚使筛查发现的病例即使没有获益也显得更好；项目以受邀组与未受邀组试验中的死亡率来评判，而不是以从诊断起计算的生存期来评判。
- **过度诊断**是对永远不会造成伤害的疾病的诊断；对于乳腺癌筛查，英国专家组估计每预防一例死亡约有3例过度诊断。
- 2026年的英格兰：宫颈癌（25～64岁，HPV初筛，HPV阴性者每5年一次）、乳腺癌（50岁至71岁生日前，每3年一次）、肠癌（50～74岁，每2年一次FIT，阈值降至80 µg/g）、肺癌（曾经吸烟的55～74岁人群，正在推广）、AAA（65岁男性）、糖尿病眼病以及产前和新生儿项目。不推荐前列腺癌人群筛查。
- 不利群体的参与率较低，这会扩大不平等；减少这种差距是每个项目工作的一部分。
:::

## 习题

::: exercise 阳性预测值 {level=1 check="round(1000*68/464.8)/10"}
使用[[#ex-ppv]]中的数字（患病率0.8%，灵敏度85%，特异度96%），在不对假阳性人数取整的情况下计算PPV，以百分比表示，保留1位小数。
::: solution
每10,000人中：68个真阳性和396.8个假阳性。$PPV = 68/464.8 = 0.1463$，即14.6%。
:::

::: exercise 项目灵敏度 {level=1 check="75"}
在一轮筛查中，筛查发现了90例癌症，在下一轮之前，受检者中又诊断了30例间期癌。计算项目灵敏度，以百分比表示。
::: solution
项目灵敏度$= 90/(90 + 30) = 0.75$，即75%。并非所有间期癌都是检测失误：有些是在筛查之后才出现的。通过复查之前的影像，可将其分为漏诊、有轻微征象或真正新发。
:::

::: exercise AAA的处理 {level=1}
四名65岁男性的主动脉直径分别为(a) 2.6 cm，(b) 3.8 cm，(c) 5.0 cm和(d) 5.7 cm。说明在NHS AAA筛查项目中对每人的处理。
::: solution
(a) 正常：结束随访，不再筛查。(b) 小型AAA：每12个月做一次监测扫描，并进行心血管风险评估和戒烟支持。(c) 中型AAA：每3个月监测一次，并进行同样的危险因素管理。(d) 大型AAA：紧急转诊至血管外科服务，在2周内就诊，以考虑修复手术。
:::
:::

::: exercise 过度诊断比 {level=2 check="round(10*129/43)/10"}
使用英国独立专家组的估计（每10,000名受邀筛查20年的女性中，预防43例乳腺癌死亡，过度诊断129例癌症），每预防一例死亡，有多少例癌症被过度诊断？保留1位小数。
::: solution
$129/43 = 3.0$。每有三名女性被诊断并治疗了一种永远不会伤害她们的癌症，约可预防一名女性死于乳腺癌。
:::
:::

::: exercise 领先时间与5年生存率 {level=2 check="2"}
在某人群中，一种癌症总是在因症状诊断后4年导致死亡，治疗不能改变这一点。一项筛查检测使诊断提前2年，且每个病例都被筛查发现。(a) 从诊断起计算的平均生存期增加多少年？(b) 筛查使死亡年龄改变多少？
::: solution
(a) 从诊断起计算的生存期从4年增加到6年：增加2年，5年生存率从0%升至100%。

(b) 完全没有改变。每个人的死亡年龄都与以前相同。全部表面上的获益都是领先时间，这就是为什么不能用从诊断起计算的生存期来评判筛查。
:::
:::

::: exercise 选择FIT阈值 {level=2}
某肠癌筛查项目正在考虑降低其FIT阈值。列出对以下各项的预期影响：(a) 发现的癌症，(b) 结肠镜检查，(c) 癌症的PPV，(d) 间期癌，以及(e) 项目的实施能力。在作出决定之前，你需要哪些证据？
::: solution
(a) 发现更多的癌症和进展期腺瘤，尤其是较早期的。(b) 更多的结肠镜检查，伴随其不适、费用以及穿孔和出血的小风险。(c) PPV降低，因为额外的阳性者中有更多人没有显著疾病。(d) 间期癌减少。(e) 对结肠镜、内镜医师、病理和肠癌治疗的需求增加；如果容量不足，等待时间延长，这可能伤害按旧阈值检测阳性的人和有症状的患者。证据：关于各阈值下检出率和阳性率的建模和试点数据、结肠镜容量、成本效果，以及已采用较低阈值的项目的经验（苏格兰和威尔士使用80 µg/g）。
:::
:::

::: exercise 参与率与漏诊的癌症 {level=2 check="36"}
在[[#ex-uptake]]的B区，邀请了20,000人，55%参加。如果未参加者中癌症患病率为4‰，未参加者中有多少例癌症？
::: solution
未参加者：$20{,}000 \times 0.45 = 9{,}000$。癌症：$9{,}000 \times 0.004 = 36$。
:::

::: exercise 是否应该筛查？ {level=3}
一家公司提议用一种新的血液检测每年对所有50岁以上成年人进行胰腺癌筛查。在一项纳入200名已知胰腺癌患者和200名健康志愿者的病例对照研究中，该检测的灵敏度为90%，特异度为95%。在50岁以上人群中，胰腺癌的年发病率约为25/10万。对照筛查标准评估这一提议。
::: solution
**疾病。** 重要：胰腺癌预后极差。但其自然史（可检出、可治愈的临床前期持续多久）了解甚少。

**检测准确性。** 用已知的（常为晚期的）癌症与健康志愿者进行的病例对照设计会高估灵敏度和特异度（疾病谱偏倚）。即使按表面数字计算，患病率约为25/10万时：在10万人中，有22.5个真阳性和$0.05 \times 99{,}975 \approx 4{,}999$个假阳性；PPV约为0.45%。每发现一例真正的癌症，约有220人得到假阳性结果，每人都需要做CT或超声内镜检查，伴随费用、焦虑和并发症。

**治疗。** 获益的前提是更早的治疗能改善结局。对于筛查发现的胰腺癌，这是合理的推测，但尚未得到证实。

**证据。** 没有随机试验显示死亡率降低。领先时间和病程长度偏倚会使任何观察性生存数据产生误导。

**结论。** 该提议不符合标准。研究项目应首先在能代表待筛查人群的人群中研究准确性，然后开展以死亡率或分期迁移为终点的随机试验。在研究环境中对极高危群体（例如患有某些遗传综合征的人）进行监测，是更合理的第一步。
:::
:::

::: exercise 解读一项试验 {level=3}
在一项筛查检测的随机试验中，50,000人受邀，50,000人未受邀。15年后，受邀组目标癌症死亡200例，对照组250例；全因死亡分别为7,500例和7,520例。(a) 计算癌症死亡率的相对降低和需邀请人数。(b) 为什么全因死亡的差异如此之小？这是否意味着项目无效？
::: solution
(a) 癌症死亡率：$200/50{,}000 = 0.4\%$对$250/50{,}000 = 0.5\%$。相对降低$= 1 - 0.4/0.5 = 20\%$。绝对降低$= 0.1$个百分点；15年的需邀请人数$= 1/0.001 = 1{,}000$。

(b) 目标癌症死亡只占全部死亡的一小部分（7,520例中的250例），因此预防其中50例使全因死亡率变化不到1%，这一差异太小，在这种规模的试验中无法可靠地检测出来。全因死亡差异小与项目有效是一致的。然而，全因死亡率很重要，因为它能揭示检查或治疗造成的死亡，或在不同死因之间错误分类的死亡。试验和荟萃分析应报告它，并审视其置信区间，同时认识到大多数筛查试验对这一终点的检验效能不足。
:::
:::
