2007年7月，英格兰开始禁止在封闭的公共场所和工作场所吸烟。没有任何一个吸烟者因此得到建议、处方或随访预约，但一年之内，心肌梗死的急诊入院人数下降了，酒吧员工的肺部更健康了，而且在家中接触烟草烟雾的儿童人数并没有像批评者预言的那样增加，反而减少了。同一时期，戒烟服务通过一次次诊疗帮助成千上万的人戒了烟。两种方法都能预防疾病，但它们的作用方式截然不同，惠及的人群不同，引出的伦理问题也不同。

本章讨论预防：预防如何分类；为什么整个人群的小幅改变能比少数高危者的大幅改变预防更多疾病；健康促进如何发挥作用；什么促使人们改变行为；以及预防性干预如何评价和论证。本章以[[public-health/determinants-inequalities]]中描述的健康决定因素为基础。

## 预防的级别 {#levels}

::: definition 预防的级别 {#def-levels}
- **零级预防**（primordial prevention）通过塑造产生危险因素的社会、经济和环境条件，从源头上阻止危险因素出现。例如：便于步行和骑行的城市设计、限制向儿童推销不健康食品，以及防止儿童开始吸烟。
- **一级预防**通过消除或减少病因，或通过增强抵抗力，在未患病者中预防疾病。例如：疫苗接种、戒烟、在发生任何心血管事件之前治疗血压升高、孕前补充叶酸、系安全带。
- **二级预防**在疾病的早期（常为无症状期）发现并治疗疾病，使其不再进展。筛查是主要的例子；其他例子还有在初级保健中发现高血压或心房颤动病例。
- **三级预防**减轻已确立疾病的影响：限制并发症、残疾和复发。例如：心肌梗死后的心脏康复、糖尿病足部护理、卒中康复。
- **四级预防**保护人们免受不必要或有害的医疗干预：过度检查、过度诊断和过度治疗。
:::

这些界限并不清晰。在心脏病学中，“二级预防”通常指首次事件后为防止再次发生而进行的治疗，按照上面的一般框架这属于三级预防。治疗高血压是卒中的一级预防，但又是对一种本身即为疾病的状况（高血压）的治疗。这种分类是一种思考方式，而不是一组互斥的格子，具体含义应由上下文说明。

也可以按干预作用的“上游”程度来描述这些级别。**上游**干预改变产生风险的条件（税收、监管、住房）；**下游**干预在风险或疾病出现后作用于个人。大多数零级预防和许多一级预防属于上游；二级和三级预防属于下游。

## 人群策略与高危策略 {#strategies}

1985年，流行病学家罗斯（Geoffrey Rose）发表了一篇题为《患病的个体与患病的人群》（"Sick individuals and sick populations"）的论文。他指出，“这个人为什么得了这种病？”与“这个人群为什么有这么多这种病？”的答案不同。个体病例的病因解释的是人群中谁会患病；发病率的病因解释的是为什么一个人群的疾病远多于另一个人群。在一个人人吸烟的人群中，无法通过人群内部比较发现吸烟导致肺癌，因为没有未暴露组；只有在人群之间比较才能看出来。

::: definition 高危策略与人群策略 {#def-strategies}
**高危策略**识别风险最高的个人（例如通过筛查血压升高或计算心血管风险），并为他们提供干预。

**人群策略**旨在使整个人群中某一危险因素的分布发生移动，让每个人的风险都略有下降（例如降低加工食品的含盐量）。
:::

高危策略有明显的优点。干预与个人相匹配；当事人知道自己处于风险之中，因而有动力；医生对此驾轻就熟；资源集中在人均获益最大的地方。它的弱点是需要筛查，这要花钱，而且会遗漏不来参加的人；它是姑息性的，因为它不改变根本原因，新的高危者会不断出现；而且，正如罗斯所证明的，它只能应对疾病负担的一小部分。

::: theorem 预防悖论 {#thm-paradox}
大量暴露于小风险的人所产生的病例，可能远多于少数暴露于高风险的人。因此，一项给社区带来巨大益处的预防措施，对每个参与者个人的益处可能很小。
:::

::: proof
大多数危险因素，如血压、胆固醇、饮酒量和体重，都是连续变量，分布大致呈钟形，风险在整个范围内稳步上升，而不是从某个阈值开始。分布的高风险尾部人数很少；中间部分包含大多数人，每个人的风险都不大。人数乘以风险之后，中间部分往往贡献了大部分病例。

例如，假设一个10万人的人群中10%处于高风险（十年内20%），90%处于较低风险（5%）。高危组将产生$10{,}000 \times 0.2 = 2{,}000$例，较低风险组产生$90{,}000 \times 0.05 = 4{,}500$例。三分之二以上的病例发生在高危策略从不治疗的较低风险多数人中。移动整个分布能够触及这些人。但每个人的绝对获益很小，因此大多数改变行为的人永远不会经历一场他们原本会患的疾病；这就是悖论所在。
:::

罗斯还观察到，人群分布的均值可以预测极端尾部有多少人。平均血压高的人群有更多高血压患者；平均饮酒量高的人群有更多重度饮酒者。“患病的个体是患病人群的一部分。”因此，均值的适度下降会大大减少高危个体的人数。

::: example 移动血压的分布 {#ex-shift}
假设成年人收缩压呈正态分布，均值125 mmHg，标准差15 mmHg。(a) 收缩压高于140 mmHg的成年人比例是多少？(b) 一项全国减盐项目使均值降低5 mmHg而离散程度不变。现在高于140 mmHg的比例是多少？(c) 在100万成年人的人群中，高于该阈值的人减少了多少？
::: solution
(a) $z = (140 - 125)/15 = 1.00$。高于$z = 1$的比例为$1 - \Phi(1) = 0.1587$，即15.9%。

(b) 新均值为120 mmHg。$z = (140 - 120)/15 = 1.33$。高于该值的比例为$1 - \Phi(1.333) = 0.0912$，即9.1%。

(c) 在100万成年人中：高于140 mmHg的人减少$158{,}700 - 91{,}200 \approx 67{,}400$人。

5 mmHg的变化对任何一个人来说几乎察觉不到，却使高于高血压阈值的人数减少约43%。对心血管事件的影响还会比这个人数所显示的更大，因为低于阈值的人也会受益：风险随血压连续上升。
:::
:::

两种策略是互补的。合理的心血管预防政策把人群策略（减盐、控烟、主动出行、食品配方调整）与高危策略（对40～74岁成年人每五年进行一次NHS健康检查、用QRISK3评估风险，并按NICE指南治疗高危者）结合起来。

### 绝对风险与预防性治疗的获益 {#absolute-benefit}

预防性治疗通常在报告**相对危险降低**（RRR）的试验中检验。对个人的获益取决于其**绝对风险**。同样的相对效应，在基线风险高的人身上产生的绝对获益要大得多。

::: example 谁从他汀类药物中获益最多？ {#ex-nnt}
在这里使用的示例性试验中，一种他汀类药物使主要心血管事件的相对风险降低约25%。分别计算以下两人的绝对危险降低和十年需治人数（NNT）：(a) 一位10年心血管风险为20%的68岁男性；(b) 一位10年风险为5%的45岁女性。
::: solution
(a) ARR$= 0.20 \times 0.25 = 0.05$，即5个百分点。NNT$= 1/0.05 = 20$：像他这样的人中有20人服用他汀十年，才能预防一次事件。

(b) ARR$= 0.05 \times 0.25 = 0.0125$，即1.25个百分点。NNT$= 1/0.0125 = 80$。

相对获益相同，但治疗这位男性，每治疗一人所预防的事件是四倍。这就是为什么预防性治疗按绝对风险而不是按单一危险因素的水平提供。对个人的决定还要权衡不良反应、每天服药的负担和个人偏好，并遵循现行NICE血脂调整指南。风险计算器也有局限：即使终生风险很高，大多数年轻人的10年风险也很低，这就是为什么要同时使用终生风险估计等工具。
:::
:::

::: warning 相对危险降低夸大了低风险者的获益
“这种治疗使你的风险减半”听起来很有说服力，但如果风险原来是千分之二，就只降到千分之一：绝对降低0.1个百分点，NNT为1,000。患者、公众和临床医生在获益以相对风险表示时，都会认为获益更大。良好地传达预防获益应使用规定时间段内的绝对风险，最好用自然频数（“像你这样的100个人中，不治疗的话未来十年约有10人会发生心脏病发作或卒中，治疗后约为8人”），并以同样格式呈现危害。
:::

## 健康促进 {#promotion}

::: definition 健康促进 {#def-promotion}
**健康促进**是“使人们能够增强对自身健康的控制并改善健康的过程”（世卫组织，《渥太华宪章》，1986年）。它包括旨在增强个人技能和能力的行动，以及旨在改变社会、环境和经济条件的行动。

**健康教育**是较窄的任务，即传递信息、培养技能，使人们能够就自身健康作出知情决定。**健康保护**指保护人群免受危害的措施，如传染病控制、环境监管和食品安全，常通过法律实施。
:::

**《渥太华宪章》**提出的五个行动领域至今仍构成健康促进的框架：

1. **制定健康的公共政策**：把健康列入所有部门（税收、交通、住房、教育、农业）决策者的议程，而不只是卫生部门。这一理念现在称为“将健康融入所有政策”。
2. **创造支持性环境**：在家庭、学校、工作场所和城市中，使健康的选择成为容易的选择。
3. **加强社区行动**：社区自己确定优先事项，规划并实施策略。
4. **发展个人技能**：信息、教育和生活技能，包括**健康素养**，即获取、理解和使用健康信息的能力。
5. **调整卫生服务方向**：从治疗疾病转向促进健康，提供对文化和需要敏感的服务。

一个有用的区分是：依赖个人**能动性**的干预（人们必须注意、理解并行动）与改变**结构**的干预（环境为每个人而改变）。正如[[public-health/determinants-inequalities]]所解释的，能动性干预往往使有利群体受益更多，而结构性干预更为公平。

### 行为如何改变 {#behaviour}

有若干模型描述人们如何改变健康行为。它们相互重叠，没有一个是完整的。

- **健康信念模型**（20世纪50年代为结核病筛查而提出）认为，如果人们相信自己易患某病、该病严重、行动会有帮助，且障碍小于益处，就会采取行动；行动线索（症状、提醒、建议）会触发行为。
- 普罗查斯卡（Prochaska）和迪克莱门特（DiClemente）的**跨理论模型（行为改变阶段模型）**描述了前意向期、意向期、准备期、行动期和维持期，复发很常见。它在咨询中被广泛使用，但针对个人所处阶段“量身定制”的干预试验并未显示量身定制能改善结局，而且各阶段之间并不像模型所暗示的那样界限分明。
- **COM-B模型**是米基（Susan Michie）及其同事于2011年发表的行为改变轮（Behaviour Change Wheel）的一部分，它指出，当一个人具备执行某行为的**能力**（C：身体和心理）、**机会**（O：物质和社会）和**动机**（M：反思性和自动性）时，行为（B）就会发生。它把每一种缺陷与干预类型联系起来：能力不足用教育和培训，机会不足用环境重构和赋能，动机不足用说服和激励，其外围是监管和财政措施等政策选项。
- **助推**（nudge）由塞勒（Richard Thaler）和桑斯坦（Cass Sunstein）于2008年提出，它改变“选择架构”，但不禁止任何选项，也不显著改变经济激励：默认选项（选择退出式器官捐献、预先安排好的筛查预约）、把较健康的食物放在视线高度，以及较小的餐盘。默认选项是最有效的助推之一。不过，许多健康问题需要的不只是助推：证据表明，价格和监管措施的效果更大。

许多行为是习惯性的，由环境线索触发，而不是经过反思选择的。这就是为什么单靠信息很难改变行为，而环境改变的作用如此强大。

### 临床实践中的健康促进 {#mecc}

每一次临床接触都是一次机会。**让每次接触都有意义**（Making Every Contact Count，MECC）是英格兰NHS普遍采用的方法，鼓励工作人员利用常规接触简要地提出生活方式问题。对于吸烟，**极简建议**分三步，常概括为“询问、建议、行动”：询问吸烟情况并记录；建议戒烟的最佳方式是把药物或电子烟支持与专业的行为支持结合起来；根据对方的反应采取行动，转介到戒烟服务或开具处方。整个过程不到一分钟。对于饮酒，根据初级保健的系统评价，在用AUDIT-C或完整AUDIT问卷筛查之后进行**简短干预**，给予结构化的反馈和建议，可以减少饮酒风险增加或较高者的饮酒量。

NICE关于个人行为改变的指南（PH49，2014年）建议，干预应基于公认的行为改变技术，如设定目标、自我监测、为障碍作计划和安排社会支持，并应培训工作人员实施这些干预。

::: example 全科诊疗中的简短干预 {#ex-brief}
一位38岁的孟加拉裔男性因踝关节扭伤就诊。他的病历显示他每天吸烟20支，他的父亲52岁时发生过心脏病发作。三年来没有人询问过他的吸烟情况。描述临床医生如何在两分钟内利用这次接触进行预防，以及如果他有兴趣，COM-B模型如何帮助规划支持。
::: solution
**询问。** “你还吸烟吗？”记录回答和吸烟量。

**建议。** “你能为自己的健康做的最好的事就是戒烟，最有效的方法是在戒烟服务的支持下，配合药物或电子烟。使用这种支持的人成功的可能性约是自己尝试者的三倍。”避免说教，也不要把它与踝关节联系起来。

**行动。** 如果他有兴趣，转介到当地戒烟服务（如有帮助，可提供孟加拉语或锡尔赫特语支持），或开具戒烟药物。如果没有兴趣，接受他的回答，记录下来，并表示将来可以提供帮助。即使对方拒绝，极简建议仍然值得，因为它为将来的尝试埋下了线索。

**进一步预防。** 他的早发冠心病家族史和南亚族裔都会提高他的心血管风险，因此应邀请他进行风险评估（血压、血脂、HbA1c和BMI，使用针对族群的BMI阈值）。

**COM-B。** 能力：他可能不知道可以获得的支持，或不知道如何正确使用尼古丁替代疗法；向他解释。机会：轮班工作、家中有其他吸烟者、街角商店出售香烟；商定实际计划，例如无烟家庭以及在他能参加的时间提供支持。动机：他自己的理由（孩子、父亲的心脏病发作、省下的钱）比临床医生的理由更有力；自动性动机（习惯和渴求）通过药物和替换线索来应对。
:::
:::

## 人群干预的证据 {#evidence}

公共卫生中一些最大的收益来自人群措施。它们的证据很少来自随机试验，因为对国家法律进行随机试验往往是不可能的。证据来自**自然实验**，即政策在一个地方或时间发生变化，而在另一个地方或时间没有，用以下设计进行分析：**间断时间序列**（把变化后的趋势与根据变化前趋势外推的结果比较）、**双重差分**（把暴露人群的变化与未暴露人群的变化比较），以及**合成控制法**。英国医学研究理事会（MRC）关于开发和评价复杂干预的框架（2021年更新）描述了如何把这类评价与建模以及过程评价结合起来，过程评价探讨干预如何以及为何起作用。

证据充分的例子包括：

- **控烟。** 税收、无烟立法、广告禁令、标准化包装和购买年龄法律。英格兰2007年无烟法律实施后，一项间断时间序列分析发现心肌梗死急诊入院有小幅但显著的下降，约为2.4%（Sims等，2010年）。控烟在[[public-health/non-communicable-disease]]中全面讨论。
- **酒精定价。** 苏格兰2018年实行酒精最低单位定价后，完全归因于酒精的死亡估计下降了13.4%，降幅最大的是最贫困地区（《柳叶刀》，2023年）。
- **道路安全。** 英国强制前排乘员系安全带（1983年）、酒驾法律和呼气检测、限速和交通稳静化措施，以及分级驾照制度。英国道路死亡人数从20世纪60年代中期每年约8,000人降至21世纪10年代每年不到2,000人，尽管交通量大幅增加。
- **食品强化。** 在美国、加拿大和许多其他国家，面粉强制添加叶酸减少了神经管缺陷。英国于2024年立法规定在非全麦小麦粉中添加叶酸，该要求预定自2026年底起实施。
- **饮水加氟。** 调整饮用水中的氟浓度可以减少龋齿。在含氟牙膏普及的时代，获益的大小比早期研究所显示的要小，近期英国的评价发现效果有限，因此加氟仍有争议；英格兰约十分之一的人口饮用加氟水。

::: example 间断时间序列 {#ex-its}
某地区禁止在载有儿童的汽车内吸烟。禁令实施前，儿童哮喘每月急诊入院人数在稳步下降，按此趋势外推，禁令实施后第一年预计有950例入院。观察到的数字为920例。(a) 归因于禁令的估计降幅占预期数的百分比是多少？(b) 这一结论面临的主要威胁是什么？
::: solution
(a) 减少$= 950 - 920 = 30$例入院。占预期数的百分比：$30/950 = 3.2\%$。

(b) 这一估计假定原有趋势会保持不变。威胁包括：同期的其他事件（暖冬、新的哮喘指南、入院编码的变化，或严重程度不同的呼吸道病毒流行季），因此加入对照序列（例如成人哮喘入院，或未实施禁令的地区）能加强设计；如果禁令是在异常糟糕的一年之后实施的，会有向均数回归；在数字不大的情况下存在偶然性；如果行为在法律生效之前就已改变，会有预期效应。分析还应检查效应表现为水平的突变、斜率的变化，还是两者兼有，并报告置信区间。
:::
:::

### 预防比治疗便宜吗？ {#costs}

人们常以节省开支为由为预防辩护。有时确实如此：儿童疫苗接种和控烟节省的治疗费用远多于它们的成本。但科恩（Cohen）、诺伊曼（Neumann）和温斯坦（Weinstein）在2008年对已发表的成本效果研究进行分析后发现，大多数预防措施和大多数治疗一样，花的钱比省的钱多，尽管其中许多就所获得的健康而言物有所值。活得更久的人在多出的岁月里也会使用医疗服务。正确的问题不是“它省钱吗？”，而是“与其他选择相比，它是否以合理的成本换取了健康？”。回答这一问题的方法在[[public-health/health-systems-economics]]中介绍。

## 预防的伦理 {#ethics}

人群预防引出了个体临床照护所没有的伦理问题。预防是提供给健康的、并未提出要求的人的；大多数遵从者个人不会得到任何好处（预防悖论）；而且有些措施限制了自由。

**纳菲尔德生物伦理委员会**（Nuffield Council on Bioethics，2007年）描述了一个侵入性逐级增加的**干预阶梯**：从不采取行动、只监测情况，到提供信息、使选择成为可能、通过改变默认选项引导选择、通过激励或抑制措施引导选择，直到限制选择和取消选择。阶梯越高，所需的理由就越充分。该委员会描述了国家的“管家”角色：国家有义务保护弱势者（尤其是儿童）、减少健康不平等、使人们容易过上健康的生活，同时尽量减少强制并尊重自主。

支持更具侵入性措施的论据包括：对他人的伤害（二手烟、酒驾）、儿童的脆弱性、塑造环境的商业力量（营销本身就是对选择的侵扰），以及信息类方法会扩大不平等。反对的论据包括：家长主义、某些税收的累退效应（低收入者在烟草上花费的收入比例更大，尽管他们获得的健康收益也最多）、污名化，以及国家把受环境影响的状况归咎于个人的风险。

::: quiz
下列哪一项是零级预防的例子？
- [ ] 给一位血压165/100 mmHg的60岁患者开降压药。
- [ ] 邀请50～70岁女性进行乳腺X线摄影检查。
- [x] 限制向儿童投放高脂、高糖、高盐食品广告。
- [ ] 心肌梗死后的心脏康复。
::: solution
零级预防通过改变产生危险因素的条件来阻止危险因素的形成。限制向儿童推销不健康食品，目的是从一开始就防止不健康饮食和肥胖的形成。降压治疗是心血管疾病的一级预防，乳腺X线摄影是二级预防（筛查），心脏康复是三级预防。
:::
:::

::: history
预防级别的概念由利维尔（Hugh Leavell）和克拉克（E. Gurney Clark）在其教科书《社区医生的预防医学》（*Preventive Medicine for the Doctor in His Community*，1958年）中提出。1974年，加拿大卫生部长拉隆德（Marc Lalonde）发表了《加拿大人健康的新视角》（*A New Perspective on the Health of Canadians*），认为决定健康的不仅是医疗照护，还有生活方式和环境，这常被视为现代健康促进的开端。《阿拉木图宣言》（1978年）使初级卫生保健成为“人人享有卫生保健”的基础，《渥太华健康促进宪章》（1986年）提出了至今仍在使用的五个行动领域。1985年，罗斯发表了《患病的个体与患病的人群》，他的著作《预防医学的策略》（*The Strategy of Preventive Medicine*，1992年）阐述了预防悖论以及支持人群策略的理由。雅穆勒（Marc Jamoulle）于1986年提出了四级预防这一术语。
:::

## 后续内容

筛查是二级预防的主要形式，单独成章：[[public-health/screening]]。疫苗接种项目是针对感染最有效的一级预防，见[[public-health/vaccination-programmes]]。烟草、酒精、饮食和身体活动作为政策目标在[[public-health/non-communicable-disease]]中讨论。

::: summary
- 预防分为**零级**（预防危险因素）、**一级**（预防疾病）、**二级**（早期发现疾病）、**三级**（限制已确立疾病的影响）和**四级**（防止医疗干预造成的伤害）。各专科的用法有所不同。
- 罗斯的**人群策略**移动危险因素的整个分布；**高危策略**治疗分布尾部的个人。两者互补。
- **预防悖论**：大多数病例发生在大量中等风险的人中，因此使社区受益的措施对每个人的益处很小。
- 分布均值的小幅移动会大幅减少高危人数。
- 预防性治疗按**绝对风险**确定对象：同样的相对危险降低，在低风险者中带来的绝对获益较小、NNT较大。应以绝对风险呈现获益和危害。
- **健康促进**（《渥太华宪章》）通过健康的公共政策、支持性环境、社区行动、个人技能和调整服务方向来实现。
- 行为改变模型包括健康信念模型、行为改变阶段模型和**COM-B**；默认选项和环境改变比信息更有力。
- 人群干预作为**自然实验**来评价，采用间断时间序列和双重差分设计。
- 侵入性越强的措施需要越充分的理由（纳菲尔德**干预阶梯**）。
:::

## 习题

::: exercise 绝对危险降低 {level=1 check="40"}
一种预防性治疗使5年卒中风险从5%降到2.5%。计算为预防一例卒中需要治疗五年的人数。
::: solution
ARR$= 0.05 - 0.025 = 0.025$。NNT$= 1/0.025 = 40$。相对危险降低为50%。
:::
:::

::: exercise 预防的分类 {level=1}
把下列每一项归类为零级、一级、二级、三级或四级预防。(a) 12岁儿童接种HPV疫苗。(b) 用粪便免疫化学检测进行肠癌筛查。(c) 酒精最低单位定价。(d) 为一位已不再从他汀类药物获益的92岁衰弱老人停用他汀。(e) 糖尿病患者的视网膜筛查。(f) 髋部骨折后进行物理治疗以恢复活动能力。
::: solution
(a) 一级：预防感染，从而预防宫颈癌和其他癌症。(b) 二级：早期发现癌症和癌前息肉。(c) 零级或一级：它改变驱动有害饮酒的环境（零级），并减少饮酒者的饮酒量（一级）；这是界限模糊的一个好例子。(d) 四级：防止不必要的治疗造成伤害。(e) 视力丧失的二级预防：在视网膜病变威胁视力之前发现它（但就糖尿病本身而言属于三级）。(f) 三级：限制已发生损伤后的残疾。
:::
:::

::: exercise 病例从哪里来？ {level=1 check="round(1000*4500/6500)/10"}
在一个10万人的人群中，10%处于某病的高风险（十年内20%），90%处于较低风险（5%）。所有病例中有多大百分比发生在较低风险组？保留1位小数。
::: solution
高危组病例：$10{,}000 \times 0.2 = 2{,}000$。较低风险组病例：$90{,}000 \times 0.05 = 4{,}500$。合计6,500。来自较低风险组的百分比：$4{,}500/6{,}500 = 69.2\%$。
:::
:::

::: exercise 分布的尾部 {level=2 check="round(1000*0.0098153)/10"}
使用[[#ex-shift]]的分布（均值125 mmHg，标准差15 mmHg），收缩压高于160 mmHg的成年人百分比是多少？保留1位小数。（$1 - \Phi(2.333) = 0.0098$。）
::: solution
$z = (160 - 125)/15 = 2.333$。高于该值的比例$= 0.0098$，即1.0%。如果均值下降5 mmHg到120，$z = 2.667$，比例变为0.38%：均值下降4%，血压极高的人数下降60%以上。
:::
:::

::: exercise 同样的治疗，不同的获益 {level=2 check="25"}
一种治疗使某事件的相对风险降低20%。对于一个基线10年风险为20%的人，十年的NNT是多少？（给出整数。）
::: solution
ARR$= 0.20 \times 0.20 = 0.04$。NNT$= 1/0.04 = 25$。对于基线风险为5%的人，ARR$= 0.01$，NNT$= 100$。
:::
:::

::: exercise 水平突变 {level=2 check="round(1000*45/1500)/10"}
在一项新的限速政策实施之前，某城市每年的道路伤亡人数稳定在约1,500人。政策改变后的两年中平均为1,455人，而三个未改变政策的类似城市没有变化。估计归因于该政策的百分比降幅（保留1位小数），并说出研究设计的名称。
::: solution
减少$= 1{,}500 - 1{,}455 = 45$；$45/1{,}500 = 3.0\%$。把该城市的变化与对照城市的变化相比较，属于**双重差分**设计（这里对照组的变化为零）。它依赖于这样一个假设：如果没有该政策，各城市会遵循平行的趋势。
:::
:::

::: exercise 选择策略 {level=3}
某国成年人平均盐摄入量为每天8.5 g，而推荐的最大量为6 g。卫生部预算固定，正在以下两者之间选择：(A) 为已确诊高血压患者提供营养师咨询；(B) 为加工食品（提供了所吃的大部分盐）制定先自愿、后强制的减盐目标的项目。讨论二者各自对人群血压、不平等和个人选择可能产生的影响。
::: solution
**(A) 高危策略。** 咨询只能触及已确诊者，而他们只是将来会发生卒中者中的少数，并且依赖于他们的动机、读写能力以及购买和烹饪不同食物的能力。对饮食建议的依从性会随时间下降。对人群血压的影响很小，而且会有利于有利群体。它尊重选择，容易被接受。

**(B) 人群策略。** 大部分盐在购买时就已在食物中，因此调整配方能在消费者不采取任何行动的情况下降低所有人的摄入量，包括那些从不看医生的人。英国自2003年起的减盐项目之后，测得的盐摄入量和平均血压都有所下降，尽管很难精确归因。逐步调整配方不会被消费者察觉，因为口味会适应。它很可能减少不平等，因为低收入群体吃的加工食品更多。它改变的是选择架构，而不是限制选择。自愿目标只有在受到监测并以可能的监管为后盾时才有效。

最佳政策是两者结合，但按照罗斯的逻辑，人群策略每花一英镑所预防的卒中可能要多得多。
:::
:::

::: exercise 税收的伦理 {level=3}
某国政府提议对含糖饮料征税。反对者认为这是家长主义的，而且是累退的。利用干预阶梯评价这些反对意见。
::: solution
**所处位置。** 税收通过抑制措施引导选择：处于阶梯的中间一级。它不禁止任何产品。如果像英国软饮料行业税那样，其设计目的是鼓励厂商调整配方，那么主要影响落在产品上而不是消费者的选择上，在阶梯上的位置就更低。

**家长主义。** 支持这一级的理由很充分：含糖饮料的主要消费者包括儿童，国家对他们负有特殊的保护义务；大量营销已经在塑造选择；而且其后果（肥胖、2型糖尿病、龋齿）通过卫生服务给他人带来成本。

**累退性。** 低收入者在这类饮料上花费的收入比例更大，因此经济负担是累退的。但健康获益很可能是累进的，因为他们消费更多、对价格更敏感；配方调整在不涨价的情况下去除了糖；而且收入可以用于儿童健康（英国这项税收的收入曾与学校体育和早餐项目挂钩）。这一反对意见是真实的，但可以缓解。

一个相称的结论是：如果这项税收以证据为基础、透明、对其健康和不平等影响进行监测，并辅以使较健康的选择可获得、可负担的措施，它就是正当的。
:::
