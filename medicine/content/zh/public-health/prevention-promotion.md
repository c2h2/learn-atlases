预防是医学最古老的主张与最新的产业：从换得二十世纪大部分寿命增益的排污与净水革命，到显示“有组织的说服”能起作用的疫苗与控烟运动，再到今天的主张——最大的剩余收益藏在商品价格、早期童年与建成环境里，而不在诊室。**本章覆盖经典的分类（原始、第一、第二与第三级预防及其筛查与危险因素的遗产）、人群策略与高危策略的证据（罗斯定理：移动整个分布比处理尾部挽救更多生命，以及它的公平告诫）、改变人所为之事的 行为科学（COM-B 与阶段模型与默认选项与助推）、以及项目的设计、评估与伦理（从大规模宣传到处方式预防，以及其过度延伸与反弹与“谁来监督监督者”之问）。**

## 地图

::: definition 预防的层级及其服务对象 {#def-levels}
**按临床顺序的分类：原始预防（不让“因中之因”出现——食物环境与行业守则的设计）、第一级预防（疾病之前：免疫、安全立法、烟草与酒精与饮食的人群行动、以及职业与环境保护）、第二级预防（更早地发现无症状疾病——由筛查章节看管的那一翼）、以及第三级预防（诊断之后：他汀与降压药的二级预防药理、心脏与卒中与肺康复的项目、以及多因素糖尿病风险项目——其“单一大复方”试验显示有组织的处方能带来很大的效应量）；再加上第四级预防（保护患者免于过度预防），如今已自成一支文献——[[public-health/screening]]、[[cardiovascular/hypertension]]、[[geriatrics-palliative/polypharmacy]]。谁被哪一层服务，是本章的道德主线：人群措施（税收与立法与环境改造）不需要个体意愿即可作用于所有人，因而在最贫困群体中的绝对收益最大、且几乎不受依从性影响；临床预防（针对个体的处方与筛查的邀请）则按可及性与资源与谈判能力被取用，因而常常扩大差距——这就是“预防的公平悖论”，也是为何一份可信的预防战略必须同时包含上游的杠杆与下游的定向加重——[[public-health/determinants-inequalities]]。分类还带着历史的争论：罗斯关于人群与高危策略的两分既是最常被引用的洞见，也是最常被误读的——他说的是“两者需要”，且人群措施的正当性依赖于它不伤害少数高危者；而现代的风险阈值与治疗可及性的扩张已把这条界线部分抹去（血压与胆固醇与骨密度与人类免疫缺陷病毒的暴露前预防都同时是人群现象与个体处方）——[[epidemiology-ebm/diagnostic-tests]]。**
:::

## 杠杆

::: definition 行为、结构与政策工具 {#def-levers}
**行为的改变在个体层面有效、在人群层面常常不敷使用。可用的模型：COM-B（能力、机会、动机共同生成行为——这一框架的价值在于它迫使你去查“缺的是哪一种”）、跨理论阶段模型（对分阶段的短暂介入有效，尤其成瘾）、以及“计划行为”与社会认知理论关于自我效能的洞见；把行为改造成“默认选项”与改变的架构（自动加入与提醒与简化路径与“把健康变成容易的那条路”）在器官捐献与养老金与学校膳食与食物标签上都有实证；而“助推”的批评（它绕过审议、它可被反向使用、它把责任留给个体）是一个真实的伦理问题而非吹毛求疵——[[clinical-skills/communication]]。结构工具的有效性顺序在多数领域都相同：立法与税收最强，可及性次之，信息与劝导最弱——烟草是一个完整的教材（税与禁广告与包装与场所禁烟与戒烟服务的组合使 吸烟率在二十多年里腰斩，而每一步都有反对者的“不可行”与后来的“理所当然”）；酒精（价格与可获得性与促销，其中最有效的三样也是最被游说抵抗的三样）；道路安全（速度、安全带与头盔与酒驾执法的“安全系统”方法，它在十年里把死亡人数减半而不需要任何人改变生活方式）；职业与环境的规制（暴露限值与工程控制）；食品（配方调整与标签与促销限制与税收的混合，其证据仍在长）——[[public-health/non-communicable-disease]]、[[public-health/environmental-occupational]]。免疫是特殊的一章：它是唯一以“不打扰人”的方式起效的高效益干预（默认与校内接种与预约提醒与补种规则与覆盖率的监测），也是唯一需要公众信任才能运作的医学技术——因此它的成功与失败都在沟通与公平一侧——[[public-health/vaccination-programmes]]。**
:::

## 诚实

::: definition 过度延伸、反弹与前沿 {#def-honesty}
**预防有它自己的伤害清单，专业必须公开地管理它们。过度延伸：把生活方式建议当作道德评判（“你为什么不运动”）、把风险沟通变成罪责、以及“健康主义”（把一切社会问题都翻译成健康问题，从而免除了政治的答案）。医学化的前沿：把风险的分布变成个体的处方（过度诊断与过度治疗及其筛查与风险阈值的争论、以及被“病人身份”改变自我认知的健康人）；而生物标志与基因与可穿戴设备把“筛查”从有组织的规划变成持续自我测量，其证据与公平与数据治理都尚未跟上——[[public-health/screening]]、[[genetics/genetic-testing]]。反弹是真实的数据：强制措施的公众接受度依赖程序正义（被解释、被协商、被认为必要且成比例、并有退出路径），而“为你好”式立法会在下一次选举被撤销——肥胖与酒精的某些地方性措施就是教材；而产业会把自由与选择与就业作为武器来打这场仗，因此政策的设计必须预先写好对它的答案——[[public-health/determinants-inequalities]]。问责的不对称：预防的失败不可见（没有病历记录“从未发生的心梗”），而它的成功被归功于其他（新药与医院）；结果是预防在预算周期里总是输——除非指标被事先约定（死亡率与税率与超标天数与受伤率，并公开）。最后是权力的问题：谁定义“可预防”？吸烟与饮酒与饮食与体重与生育的选择，在个体层面是价值与乐趣与身份的问题——公共卫生的正当立场是改变默认与保护他人（第二手烟、道路上的他人、儿童），同时保留选择；而当它变成对成年人私德的监管，就既失去证据的支持也失去多数人的支持——[[medical-ethics-law/ethical-principles]]。**
:::

::: example 用了四十年的控烟 {#ex-tobacco}
你的卫生部要在两年内使吸烟率“显著下降”，考虑三项政策：包装与展示的图形警示、加税、以及“无烟一代”式的销售禁令；烟民集中在最贫困的社区与最脆弱的精神疾病人群。
::: solution
**四十年的课程（[[#def-levers]]、[[#def-honesty]]、[[public-health/non-communicable-disease]]）：先说排序：价格是最有力的单一杠杆（尤其在年轻人与低收入群体，其弹性最大；每一次实际税率的大幅上调都能观察到消费的下降与后来的死亡下降），因此若只有一年可用，加税；其次是让“开始”变难与“戒”变易的组合（禁广告与标准化包装与零售点的密度与展示的禁令，以及普遍可及且免费的戒烟支持与药物——这两者在弹性上都胜过单纯的劝告）；第三才是禁止销售这类激进措施（其证据是模型而非经验，而其执行与黑市与“代买”与刑事化的风险会把正当性输掉，且它对最贫困烟民最不利）。对公平的两点必须说清：一，税在名义上是累退的，但吸烟者对价格敏感且最重的吸烟者常是低收入者，因此其健康收益与净财务负担按收入分层计算后常为累进；二，若只加税而不提供戒烟支持，就是把负担留给最难戒的人——所以“税加支持”是同一个政策的两个部分，不可拆分——[[pharmacology/patient-variation]]。对精神疾病人群：吸烟率数倍于普通人群且戒断成功率更低（尼古丁的自我治疗理论与药物相互作用的现实：戒烟改变细胞色素P450 1A2 的抑制，会影响若干精神科药物的血药浓度），所以需要整合的干预（在精神科住院期间主动治疗尼古丁依赖并出院时继续处方）——[[psychiatry/substance-use]]、[[pharmacology/metabolism-excretion]]。沟通：不与烟民为敌、不承诺无法兑现的“无烟世界”时间表、并把产业替代生计与非法贸易的对策一并写出；以及把成果定义为“避免的死亡”而非“少吸的支数”——[[clinical-skills/communication]]。**
:::

::: example 糖税与配方调整 {#ex-sugartax}
政府引入按含糖量分档的饮料税；两年内市售饮料平均含糖量下降35%，购买量下降20%，而肥胖率的调查数据未见变化；行业声称“这证明税无效”，倡导团体要求扩大到其他食品。
::: solution
**读一份部分成功的政策（[[#def-levers]]、[[#def-honesty]]、[[public-health/non-communicable-disease]]）：先给结论：配方调整已经发生，这是糖税最被低估的机制（分档的设计让企业通过减糖来避税，于是“税”变成了“规管”），而它优于“仅减少购买”，因为它不依赖个体意志且对全体饮用者生效。肥胖率没变是意料之中而非反证：第一，肥胖的多因素性与滞后（数十年的能量平衡与体重调节的生理意味着两年的购买变化不会体现在体重调查里）；第二，调查的灵敏度（需要非常大的样本或多年趋势才能检出群体体重的微小移动）；第三，替代与补偿的可能（低糖饮料与高糖食品之间、以及家中制备的饮料与粉冲饮品）。有效的评估指标是中间与近端指标，且要预先注册：糖的购买量与含糖量的分布与替代效应（“无糖”的增长与低脂高糖的反弹）与牙齿的临床结局（在儿童中这是最敏感的，且已有可信的下降报告）与不同收入组的差别（受益最大者是否是最重饮用者）——[[gastrointestinal/clinical-nutrition]]、[[paediatrics/growth-development]]、[[epidemiology-ebm/critical-appraisal]]。反对扩大到其他食品时的诚实回答：食品的营养结构比饮料复杂（乳制品与脂肪与发酵与“总量还是成分”之争）且弹性不同，所以不是“糖税成功了就什么都该征税”，而是要看每类产品的暴露—反应证据与替代与配方可行性、以及税的收入是否投入配套（用于面向低收入群体的健康食品补贴与学校膳食）——[[public-health/health-systems-economics]]。政治的一层：公开说明“两年看不到肥胖变化是预期的”（否则对手会在第二年宣布政策失败），并把政策的使命说清楚：减少糖的摄入与龋齿，为体重曲线的转向争取时间——[[public-health/prevention-promotion]]。**

## 通向何处

筛查的伦理与技术见[[public-health/screening]]；疾病的具体杠杆见[[public-health/non-communicable-disease]]；不平等的证据与“按比例普遍主义”见[[public-health/determinants-inequalities]]；免疫规划见[[public-health/vaccination-programmes]]；环境与职业立法见[[public-health/environmental-occupational]]；成本效果见[[public-health/health-systems-economics]]。

::: history
**预防的历史比医学更长、后果也更大。第一个时代是基础设施：排污革命（霍乱调查与斯诺1854年的水泵之后伦敦的下水道与过滤工程、以及人口学者归功于它的大部分十九世纪死亡率下降的“卫生奇迹”）、随后是巴氏消毒与牛奶安全与住房与工厂法、以及在“磷颌坏死与镭表盘与石棉”的教训之后被法典化的职业保护。第二个时代是疫苗：詹纳1796年从人痘到牛痘的一步、巴斯德的细菌时代规划、白喉与破伤风的大规模接种、1980年认证的天花消灭（预防最大的单一成就，也是此后所有定向运动的模板）、以及索尔克与萨宾的脊髓灰质炎试验与其“一角钱行军”定义的群众接种政治。第三个时代是危险因素：1948年起的弗雷明汉发明了这一概念、基斯与饮食—心脏与七国研究把人群胆固醇锚定下来、以及多尔与希尔与温德与麦克马洪的吸烟因果证明（1950至1964年，在政治炮火中以卫生总监报告作结）。第四个时代是行为与说服：健康信念模型与大众宣传与社区干预、“知—信—行”幻灭的十年（知识几乎不改变行为）、以及向改变选择架构的转向（默认选项与助推）与其对个体责任的重新分配。第五个时代尚未命名：商品的定价与环境的立法与早期童年与“同一健康”与气候——以及以真实世界数据评估每项政策的尝试——使公共卫生第一次能按月回答“它起作用了吗”——[[public-health/global-health]]、[[epidemiology-ebm/measuring-disease]]。**
:::

::: summary
- 预防的层级不是荣誉等级：原始与第一级预防作用于环境，第二与第三级作用于个体，而它们的效果与公平属性完全不同。
- 把整条风险分布左移的人群措施通常比处理尾部避免更多病例，但只有与高危策略并用且不加剧可及性差距时才正当。
- 结构与法规强于信息与劝导：税收、立法、可获得性与默认选项的证据最强，而单靠教育最弱。
- 行为改变的科学是“能力、机会、动机”的诊断，不是道德劝导；把默认变健康比说服更有效。
- 预防有其伤害：过度诊断与过度预防与医学化与反弹；第四级预防与程序正义是它的护栏。
- 预防的成功不可见而失败被归给他因，因此必须在事先约定的公开指标上被问责。
:::

## 练习

::: exercise 给干预分级 {level=1}
把下列按“预期的人群健康收益/单位投入”与“公平影响”排序并说明理由：一套国家健康饮食 app、含糖饮料的分档税、工作场所禁烟立法、以及在他汀试验后的门诊他汀处方扩张。
::: solution
**分级的理由（[[#def-levers]]、[[#def-levels]]、[[#def-honesty]]）：收益与成本的第一名是工作场所禁烟立法：一次立法即对全体暴露者生效、不依赖个体意愿、第二手烟导致的心脏事件在数月至一年内可见地下降（多个城市的自然实验），且对最重暴露者（服务业与非技术工人）获益最大，是少见的“累进”健康立法。第二是分档糖税：它通过配方调整改变全体饮用者的暴露，成本几乎为零甚至为正收入，且在最重饮用群体中效果最大；缺点是健康结局滞后、且会遭遇替代与游说。第三是门诊他汀扩张：对高危个体效应很大、对人群贡献取决于“谁被算作高危”与开药之后是否继续（持有率按收入与教育分层，因此它常扩大差距）——[[cardiovascular/coronary-artery-disease]]、[[public-health/determinants-inequalities]]。最后是被高估的 app：几乎不改变行为（知识不是行为的瓶颈）、使用按数字素养与设备分层（因此反向不公平）、并带来数据隐私的问题；它在有推送与个性化与与真实服务连接时才有边际价值。诚实的注脚：这三类并非替代关系——立法与税收改变环境、临床预防保护高危个体、而数字工具只在能降低真实门槛时才值得——[[public-health/health-systems-economics]]。**
:::

**四分钟的结构（[[#def-levers]]、[[#def-honesty]]、[[psychiatry/substance-use]]）：用简短介入的结构（反馈、责任、建议、大量选择、简明、治疗关系）而不是说教：一，反馈可测的东西（把饮酒量换算成“每单位酒精与热量与体重的关系”与血压——很多人不知道酒精是高血压最可逆的原因之一，且在减到每日两杯以内时血压会掉几毫米汞柱）；二，把责任交还（“这是你的决定，我只是把它讲清楚”）并请求许可（“我可以说说我的担忧吗？”）；三，明确、具体、有限的建议（每周不超过若干单位、每周有几天不饮、以及家中戒酒的记录），并提供多个路径而不是唯一正解（自助的减量计画与追踪表与 应用程序 与门诊的药物治疗与相互支持）；四，把“下一步”落在最小可执行的一步（“我们先把血压记录两周；如果你想在四个月后复查血压前试试减量，那将是干净的实验”）；五，留下关系（预约一个具体的复查时间、以及“任何时候你可以直接问我要帮助”）——[[cardiovascular/hypertension]]、[[clinical-skills/communication]]。要避免的：把“障碍”的诊断当作给予建议的前提（简短介入对危险饮酒者有效，无需等到成瘾）、以及用恐惧（它触发回避与谎报）；也要筛查而不是假设（抑郁与失眠与创伤史常常是饮酒的功能，若只处理饮酒就会失败）——[[psychiatry/mood-disorders]]。文档：把介入记录在病历里（它是可计费与可审计的质量措施），并把后续（实验室与肝与血压与戒酒的努力）串成一次随访而非一次训话——[[clinical-skills/records-handover]]。**

::: exercise 给一项征税算成本 {level=2}
有人提议对超加工食品征税以改善饮食。请设计一份财政部的意见书：经济理由、分配影响、可行性、以及你会要求的评估。
::: solution
**征税意见书（[[#def-levers]]、[[#def-honesty]]、[[public-health/health-systems-economics]]）：经济理由的三条腿：外部性（与饮食相关的医疗与生产力成本不由购买者承担）、内部性与信息不对称（超加工食品的配方被工程化以驱动过量摄入，且标签不足以让人按营养选择）、以及儿童选择的不可逆；但要把“超加工”这一分类的测量问题写清（这套按加工程度的分类是按加工程度而非营养素，难以写入税则、也容易被轻微改配方规避）。分配影响：低收入家庭在此类食品上的支出占比更高，因此名义上累退；抵消机制必须写进政策（按收入分层的净效应计算、把税收明确用于面向低收入群体的健康食品补贴与学校膳食，使净转移为正）——否则这会被正当批评为向穷人征税。可行性是决定性的：税则必须可执行（按营养指标如糖与脂肪与盐的分档，而不是按“是否超加工”这种无法在海关执行的定义）、与既有的增值税与食品工业游说和贸易规则（世界贸易组织的框架与标签争端）相容、并且不与农业补贴与产业政策互相拆台。评估（要预先注册）：购买与价格传导（企业是否吸收税、以及“缩小包装”这种隐性提价）、替代（转向未征税的高热量食品？）、体重与龋齿与血压的中间结局与按收入分层的结果、以及就业与小店与舆论的反应；并附日落条款与“若无效则停止”的承诺——因为一个不能自证的税收会变成政府依赖的收入而非健康政策——[[public-health/non-communicable-disease]]、[[gastrointestinal/clinical-nutrition]]。**

::: exercise 设计一场运动 {level=3}
卫生部要在一个吸烟率31%（且青年电子烟使用上升）的地区设计为期一年的控烟传播与服务项目。给出设计、不做的事、以及评估。
::: solution
**运动的设计（[[#def-levers]]、[[#def-honesty]]、[[public-health/non-communicable-disease]]）：先说前提：传播只能作为组合的一部分，且必须与涨价与戒烟服务的可及同期推出，否则它把需求创造出来却无处满足（这是历史上“反烟广告”最常见的失败：增加戒断而不增加支持）。对成人：诉求放在具体损失与具体收益（性功能与气短与孙辈与费用——“一天一包等于每年一部车”这类换算比抽象的癌症危险更有效），渠道放在他们已在的地方（全科候诊与药房与足球与工地与社交媒体），并让戒烟服务成为每条信息的动词（一个号码与一个网页与“今天就接”）。对青年：不要“吓”（恐惧诉求在青少年中常被反向使用），而是把诉求放在当下与身份（电子烟的操控性与成瘾的速度与气味与“你在替谁做广告”），并用同伴与学校与运动与家庭的渠道；同时对电子烟的产品与营销与 香精口味 的监管与向未成年人销售执法要同期落地，因为传播对可及性无效——[[respiratory/asthma-copd]]、[[paediatrics/adolescent-health]]。不做的事：污名化吸烟者（它降低戒烟意图并把行为推入地下，且对最重吸烟者伤害最大）、以“个人责任”为框架（会削弱税收与立法的支持）、以及未经测试的“震撼”影像（在部分人群引起回避而非行动）。评估：以近端指标而非“暴露量”（拨打戒烟热线的呼入数与首次处方数与随访成功率与青年的尝试吸烟率与二手烟暴露的自报），并做中断时间序列与预注册的对照地区，把每一波投放的成本与每一次呼入与每一次成功戒烟的成本挂钩；同时监测 意外后果（电子烟作为戒断工具的自我使用、以及污名导致的产检隐瞒）——[[clinical-skills/patient-safety]]、[[pharmacology/patient-variation]]。**

::: example 使伤害减半的头盔法 {#ex-helmets}
一部自行车头盔法通过后，儿童头伤住院下降约一半；但骑自行车的人数下降了两成；反对者称头盔让骑行更不安全（颈部伤与虚假的安全感）并称这是“保姆国家”。
::: solution
**评估一项安全立法（[[#def-levers]]、[[#def-honesty]]、[[public-health/environmental-occupational]]）：先处理数字：一半的头伤下降在同期对照中不成立（多数国家的自然实验显示：法律通过前后头伤占比的改变大于头伤绝对数的改变，而部分下降来自风险补偿与骑行量减少），所以正确的效应量是“每千骑行小时的头伤”，而这是少数能测的（需要骑行量的观察数据，而非只有伤害登记）——[[emergency-critical-care/acute-assessment]]。风险的机制层：头盔对颞部与侧向冲击的力学保护是有实验支持的；“颈部伤增加”在人群数据中未见（这是被反复检查过的假说）；而风险补偿（戴盔者骑得更激进）在部分研究中可见但不足以抵消保护——[[nervous-system/stroke]]。真正的成本是出行：骑行量下降意味着身体活动减少（心血管与代谢与肥胖与心理健康与空气质量的损失）、以及道路安全的政治资本被转移到个体装备而非车速与基础设施（“安全系统”的方法——车速管理、分离的车道、路口设计——才是减少骑行者死亡的更大杠杆，且在荷兰与丹麦的经验中是可复制的）。所以政策上的回答：支持头盔作为伤害控制的一部分，但坚持把它与“让骑行安全”的结构措施一起立法；并诚实告知净效应的不确定性（对个体头伤的保护明确、对人群健康的净效应取决于是否抑制了骑行）。“保姆国家”之问的答案：法律的成本由所有人承担而收益集中于儿童与最脆弱者；在权衡时，程序正义（公开的论证与试验与逐步适用）比口号更能带来持久的服从——[[public-health/environmental-occupational]]、[[medical-ethics-law/justice-resources]]。**

::: example 校门口的反疫苗请愿 {#ex-hesitancy}
学生家长向学校递交请愿，要求取消入学所需的疫苗证明并禁止校医询问接种记录；他们在网上张贴了一份“疫苗伤害名单”；校长请你（当地公共卫生医师）来谈一次。
::: solution
**与怀疑对话而不是与帖子对辩（[[#def-levers]]、[[#def-honesty]]、[[public-health/vaccination-programmes]]）：先诊断再开口：把“反疫苗”拆成三类——对安全的具体担忧（可与证据对话）、对系统与制药的不信任（需要的是透明而非更多数据）、以及身份与群体归属（最强的预测因素，也是最不能被嘲笑的）；并问清他们真正想保护的是什么（多数人是“不想伤害孩子”，这为对话提供了共同的地基）。会议的规矩：不否认不良事件（接种后确实有罕见事件与偶合的时间关联，而“因此你们不可信”的感受是合理的）、承认历史错误（疫苗伤害救济制度与不当的实验与知情同意的问题）、把风险做成可比的具体量（每剂某疫苗的重症风险对每千剂的热性惊厥对 麻疹的肺炎与脑炎对未种的真实后果）；并把“我不知道”与“这我会去查并在周五前答复”当作合法的回答（承诺的时间必须兑现——这是唯一能重建信任的货币）——[[paediatrics/immunisation]]、[[clinical-skills/communication]]。政策层：取消入学要求通常是错误的（它会降低覆盖并伤害那些因医学原因不能接种的孩子），而“以学校为服务场所”（在校接种、便捷与免费与同意的清晰路径）通常是对的；同时把强制与可及与信任三种策略明确区分，不要用后者为前者辩护。要监测的：本地未接种儿童的名册与“零剂次”的搜寻（这才是暴发风险的所在），以及对骚扰与威胁的安全程序（校医与公共卫生人员被点名是真实的职业风险）；并把线上帖子的更正做在同一个平台与同一种语言里，而不是发一份新闻稿——[[public-health/communicable-disease-control]]、[[medical-ethics-law/professionalism-regulation]]。**

::: exercise 评估一个健康福利项目 {level=2}
一家雇主为你所在城市的员工健康项目付钱（可穿戴设备加健身房补贴加健康检查加“生物年龄”评分）；供应商报告“参与者满意度高、平均减重2公斤”。请评估并给出你会要求的合同条款。
::: solution
**评估企业健康项目（[[#def-levels]]、[[#def-honesty]]、[[public-health/health-systems-economics]]）：方法学的问题：自我选择的参与（最健康与最有资源的人先加入，所以“参与者的改善”不能外推）、缺乏对照（回归均值与霍桑效应足以解释两公斤）、结局是替代指标而非健康或费用（体重对心梗与缺勤的传导并不如宣传的直接）、以及发表偏倚（供应商的内部数据不公开）。文献的诚实结论是：多数可穿戴与健身补贴项目对体重与血压的长期效应小；回报最好的企业干预是结构性的（戒烟支持、血压与药物的可及、工时与夜班与心理社会风险的管理、以及把“因病缺勤”去罪化的政策），而非把健康变成个体的绩效指标。合同条款要包括：随机或分阶段的整群设计与外部分析权、按性别与职业类别与收入的分层报告（防止把不平等包装成成功）、对无法佩戴设备与不接受检查者的替代路径、不参与不受罚的明确保证、以及数据的用途限制（不得用于保费与考核与解雇，且保存期限与第三方共享须写清——“员工自愿同意”在权力不对称下是薄弱的基础）——[[medical-ethics-law/confidentiality]]、[[public-health/environmental-occupational]]。伦理与效果的一句话：如果这个项目使员工的“健康责任”增加而工时与夜班与不安全感不变，它可能同时降低满意度并升高风险——所以要连同工作组织一起谈，而不只是谈设备——[[public-health/determinants-inequalities]]。**

::: exercise 划定筛查的边界 {level=2}
一个患者团体游说将某种癌症的普遍筛查扩展到无症状的普通风险人群；试验显示死亡率下降20%而过度诊断增加30%，且参与率在最贫困五分位低四成。给出你的建议。
::: solution
**筛查的边界（[[#def-levels]]、[[#def-honesty]]、[[public-health/screening]]）：判断的框架仍是修订的福尔曼原则加上现代的权衡：疾病必须是重要的、自然史必须已知、必须有可被早期发现的阶段、必须有安全且可接受的确诊与治疗、费用必须与医疗总体机会成本相称、且筛查必须作为持续项目而非一次行动。三件事要同时给出：一，效果的正确度量：死亡率相对下降20%必须换算成绝对量（每千名筛查者与需要筛查的人数，以及“每避免一次死亡带来的过度诊断数”），并且要报告全因死亡（筛查试验常因死因归类的偏倚而高估获益）；二，伤害的量化与沟通（假阳性与过度诊断与治疗的并发症，以及“铅时间”造成的存活率错觉），并在知情同意中给出可比数字；三，公平的条件：如果参与率按剥夺分层低四成，则普遍筛查会把资源转向低风险人群并扩大差距——所以在扩展之前应先修复可及（非邀请式的路径与移动筛查与延长时段与语言与读写的适配与免费的交通）并以覆盖率为先决条件——[[public-health/determinants-inequalities]]、[[pathology/cancer-diagnosis]]。建议：不建议在普通风险人群无条件扩展；建议以风险分层的方案（用年龄与家族史与可测的风险标志确定起始年龄与间隔，从而在同样的资源下避免更多死亡并减少过度诊断），并附强制的评估条款（覆盖率按五分位、假阳性率、过度诊断的监测、以及每五年重审阈值）——[[epidemiology-ebm/diagnostic-tests]]、[[genetics/genetic-testing]]。**

::: exercise 构建肥胖战略 {level=3}
你要为本国写一份肥胖战略。请写出你愿意署名的组件、你会拒绝的组件、以及如何处理 GLP-1 类药物的现实。
::: solution
**肥胖战略（[[#def-levers]]、[[#def-levels]]、[[endocrine/diabetes]]）：愿意署名的组件（按证据与公平排序）：一，商品的环境（糖与高脂高盐食品的促销与价格与包装前端标签与针对儿童的营销限制，以及把学校与医院的食品标准纳入采购——这些改变默认而不惩罚个体）；二，城市与出行（步行与骑行的基础设施与运动场所的免费可及与学校体育的时间保障）；三，生命早期（育婴支持与母乳喂养的可及与母婴的随访与断奶期食品的政策，因为早期营养与出生体重与后来的脂肪量有关）；四，治疗的可及（把肥胖当作一种需要长期治疗的疾病：营养与运动与心理治疗的路径、以及减重手术在指征人群中的可及与随访）——[[paediatrics/growth-development]]、[[musculoskeletal/bones-joints]]、[[gastrointestinal/clinical-nutrition]]。会拒绝的组件：以体重指数为个体的“筛查”并把它写入儿童的通知信（它会加深刻痕与污名并导致回避照护，且体重正常者也可能代谢不良、体重高者也可能代谢健康）；以及任何把责任放回到“意志”的语言（肥胖的生理与环境的证据使其成为指责而非干预）——[[public-health/determinants-inequalities]]、[[psychiatry/eating-personality-disorders]]。GLP-1 的现实必须正面处理：药物有效且对若干结局有益，但（一）停约后体重反弹，故属长期治疗；（二）成本与供应使人人可用不可能，故需明确的优先分配规则（按合并症与风险与年龄，并预防“能付得起的人先拿”的两级体系及其对糖尿病药物的挤占）；（三）它会改变人群对政策的胃口（“药会解决它”是减糖与城市规划政策的天敌）——所以战略文本要明写：药物减少痛苦，环境减少病例；两者都要有，预算要分开——[[pharmacology/drug-development-prescribing]]、[[public-health/health-systems-economics]]。评估：以腰围与代谢结局与儿童肥胖的上升趋势线中断（按五分位分层）与生活质量为指标，而不是以处方量——[[epidemiology-ebm/measuring-disease]]。**

::: exercise 论证经济理由 {level=1}
一位财政官员说：“预防很好，但我不能用今天的钱去买二十年后的健康。”请给出三个回答，并承认她说对的一点。
::: solution
**三个回答（[[#def-levels]]、[[#def-honesty]]、[[public-health/health-systems-economics]]）：一，有些回报在同一个预算周期内：工作场所禁烟与道路安全与麻疹接种与职业暴露的控制，在数月至一两年内就能减少住院与创伤与失能；把这些与“二十年后的健康”分开列（一份“两年内可见”的预防清单比一句宏论更有用）——[[public-health/environmental-occupational]]。二，不预防的成本也在她的账上，只是记在别处：卒中的急性与长期照护、慢性呼吸病的反复住院、髋部骨折、以及因精神与成瘾疾病失去的劳动力——把它们与她考虑的干预放在同一张表上（跨部门的成本—收益，而不是卫生部门的“省钱”），并给出“若不做”的基线支出。三，折现率是价值判断而非技术常数：她的算术里隐含把未来的生命看得更轻的假设；用较低的折现率与包含无酬照护与生产力与不平等加权的完整成本，多数上游措施在十年内回本——[[medical-ethics-law/justice-resources]]。她说对的一点：预防常不比治疗便宜，也常常不能省钱（让更多人活到老年会增加长期照护与癌症与痴呆的费用），所以预防的正当地位来自健康与公平而非节约；把它包装成省钱的政策，一旦数字不支持就会失去支持——所以最诚实的一句话是：“这不是省钱，这是用可比较的成本买更多更健康的生命年——而这是卫生系统存在的理由”——[[geriatrics-palliative/palliative-care]]、[[public-health/determinants-inequalities]]。**
