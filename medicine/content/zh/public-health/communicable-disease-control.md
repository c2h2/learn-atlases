传染病控制是把流行病学作为公共卫生法律来执行：感染的链条（病原体、储存宿主、门户、途径、易感宿主）是临床对象，而切断它是一场有组织的活动——监测、病例发现、隔离、接触者工作、暴发科学与口岸和场所措施。**本章覆盖链条及其词汇（储存宿主、带菌者、基本再生数对有效再生数、消除的算术）、监测与通报（法定报告的机制、证候与基因组监测、指标与阈值的预警）、暴发调查（从假设到控制的序列、作为诊断工具的血清流行病学曲线、以及再生数的技艺）、控制规划（从麻疹到脊髓灰质炎与疟疾与结核与艾滋病的策略、以及它们各自的“最后百分之几”）、口岸与旅行与动物宿主与抗微生物耐药、以及人群措施伦理（隔离与通报与命名的正当性边界）。**

## 链条

::: definition 储存宿主、传播数字与消除的算术 {#def-chain}
**感染的链条同时是一份临床与公共卫生文件：病原体的栖居地（只感染人的疾病如麻疹与天花使“根除”可以设想，动物储存宿主如钩端螺旋体病与多数虫媒病毒使其不可能——储存宿主决定策略）、携带状态（带菌者——“伤寒玛丽”的食品从业限制至今仍在法典中——以及潜伏期与恢复期的排菌者，即临床医师背诵的传染病时间表的来源、以及慢性带菌者的从业规则）、以及门户与途径（接触、飞沫、空气、媒介物、节肢动物、垂直、性——每种途径是一套不同的控制算术：经呼吸道的传播在拥挤与通风不良处放大，粪—口途径在水与卫生处被切断，虫媒途径在孳生地与被叮咬的时刻处被削减）。数字决定策略：基本再生数在完全易感人群中的平均二代病例数，与有效再生数（在当前的免疫与控制下的值）——而流行学的基本不等式是流行在有效再生数小于一时熄灭，因此免疫的临界比例是（1−1/基本再生数）除以（1−疫苗效力）：麻疹需要约95%的两剂覆盖，这就是为何它是消除的第一候选也是最难的最后堡垒。消除的词汇必须精确：控制（把发病率降到本地阈值以下）、消除（在某一地理区域内阻断本地的传播链）、以及根除（全球永久零病例，只有天花做到、并有牛瘟作为动物界的例子）；以及“消除的陷阱”：一旦本地的发病消失，对风险与对疫苗的信任同时消失，于是输入病例找到一片易感的洼地——[[immunology/vaccines-immunotherapy]]、[[respiratory/respiratory-infections]]、[[public-health/vaccination-programmes]]。**
:::

## 系统

::: definition 监测、通报与暴发调查 {#def-surveillance}
**法定报告是把个体诊断转化为公共行动的技术：一张被定期审查并赋予资源的疾病清单、时限与定义清晰（疑似与临床诊断与实验室确认的病例定义、以及“何时按疑似即报告”）、一条把报告人（通常是医师）与公共卫生团队连起来的反馈路径、以及一套对不报告者的执行机制。通报的价值在于速度而不是完整性，因此现代系统同时接受“不完美但早”的信号：实验室的实时数据流（阳性结果的自动摄取）、死因登记、急诊的分诊文本与综合征的指标（“发热伴出血”的计数比确诊早十天）、以及废水与动物与食品的多路监测——它们共同构成预警的织网而非单一探针——[[clinical-skills/laboratory-tests]]。暴发调查的序列在任何一次食堂食物中毒与每一次医院感染聚集里都一样：确认暴发与病例定义（时间与地点与人群与临床与实验室的标准）、系统地找病例（主动的电话与名册与实验室筛查，因为被动报告只数到冰山）、描述性流行病学（流行曲线告诉你同源单次暴露还是持续传播或人传人；年龄与职业与地点的分布给你假设）、形成并检验假设（病例对照在少数患者时最省力，队列在暴露人群界清时更好）、以及环境或实验室的证据——同时立刻开始控制（等待统计学显著性才洗手是这个行业最贵的错误）。基因组测序已成为常规的工具：它把按种属鉴定推进到按传播链定位（区分相关的聚集与不相关的散发病例、并识别院内传播的方向），但它不能替代流行病学，而且它的时间戳并不总是可靠（同一宿主体内的进化与采样偏差与数据库的缺失）——[[microbiology/laboratory-diagnosis]]、[[infectious-diseases/stewardship-outbreaks]]。**
:::

## 工具箱

::: definition 控制规划、口岸与人群措施的伦理 {#def-toolkit}
**控制的工具箱按链条的环节组织：减少人类感染与排菌（早发现早治疗、有效的疗程、以及结核病与艾滋病毒中“治疗即预防”的证据——病毒载量测不到即不传播，是公共卫生史上少数几个既是科学又是希望的事实）；阻断传播（疫苗、通风与口罩与口罩与蚊帐与杀虫剂与安全注射与性传播的屏障、以及水与卫生的基础设施）；以及缩短感染到可被识别的时间（门槛降低的诊断与自助检测与主动筛查的规划）。规划的设计有其反复出现的难题：病例发现与被动报告的取舍（在结核与艾滋病毒与性传播感染中，主动与提供检测的方案能找到最多的病例，尤其在不常就诊的人群）、接触的追踪与随访（它是劳动密集、需要同意与保密、并且常常是唯一能发现儿童病例与新发感染的手段）、以及“最后一公里”（被遗漏的地区与人群：迁移的社区与边缘的定居点与拒绝接种的聚集，一个地区的疫苗接种率92%若聚集在若干学前机构，其局部易感性相当于60%）——[[infectious-diseases/tuberculosis]]、[[infectious-diseases/hiv]]。口岸与旅行的措施在历史上被高估：它们延缓而非阻止呼吸道的流行（除非伴随境内的大规模措施），其成本与对交通与贸易的干扰须被评估并透明说明；而《国际卫生条例》的核心能力与国内卫生检疫的授权，把“何时与由谁使用此类措施”变成需要论证的法律行为——[[public-health/global-health]]。伦理的边界：隔离与检疫与强制检测是对自由最严重的日常限制之一，其正当性依赖一系列条件（有效的科学依据、比例性、最后手段、期限、复核、以及被限制者的实际需求被满足——食物与工作保障与照护安排与沟通），而通报与命名（“某社区某族裔的病例”）造成的伤害既反流行学也不必要；“被信任才能被服务”的原则意味着保密、无费用门槛、以及无移民执法的联动，这三项都是有效性条件而非妥协——[[medical-ethics-law/justice-resources]]、[[emergency-critical-care/major-incidents]]。**
:::

::: example 周二的名单 {#ex-notification}
周二的监测系统返回一张实验室阳性名单：本周五例肺炎衣原体相关的聚集来自同一家养老院，一家实验室把某项检测的方法改了；你的团队三人，其中一人正在休假。
::: solution
**把名单当作调查的开始（[[#def-surveillance]]、[[#def-toolkit]]、[[infectious-diseases/healthcare-infections]]）：第一步不是发信而是核实：方法改变可以制造聚集（新的测定法与不同的参考区间与污染与批号的切换），所以先看检验的细节（哪一种检测与是否同一仪器与同一批试剂与 Ct 值），并与临床核对（这五例是真的肺炎吗——胸片与氧与发热，还是把定植与既往感染读成了现在时）——[[clinical-skills/laboratory-tests]]。同时按“可能是真的”行动（在排除之前按聚集处理，因为养老院的结构放大了后果：共用的活动与餐食与工作人员在两处工作）：感染控制的现场访问（隔离的房间可用性与是否被正确使用、个人装备的培训与依从、共同居住者与工作人员的筛查、以及环境清洁）与暴露者的分层（同室与同楼层与共享餐食与工作人员接触）；并考虑把聚集报告给卫生主管部门（这是法定职责，也是获得实验室与流行病学支援的唯一途径）——[[microbiology/infection-control]]。病例搜索要主动：按病例定义逐日回顾住院与就诊记录、以及联系全科医师找上周就诊的其他住户（被动报告只数到被送医的人，而养老院的可避免死亡常在“没人查”的那几天发生）——[[geriatrics-palliative/ageing-frailty]]。资源的一层：三人团队在暴发期间要“减少非必需活动”并且写下来（把谁被从什么工作中撤出的决定公开，避免因未处理的常规工作而产生新的风险）；休假的成员要在恢复时收到简报与名册；暴发后的复盘应改进触发条件（几家实验室的方法变更需要通知）与检测的路径——[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]。**
:::
:::

::: example 有接触者的传染病例 {#ex-hiv}
一名新确诊人类免疫缺陷病毒的男性拒绝告知其两名近期性伴；他说其中一人“会伤害他”；他的病毒载量很高；他在门诊问“你会不会把我的名字告诉他们”。
::: solution
**保密与风险的边界（[[#def-toolkit]]、[[#def-surveillance]]、[[infectious-diseases/sexually-transmitted-infections]]）：先答他所问（这是伦理也是有效性）：保密是有条件的义务，条件在极少数情形下被触发——当他人面临严重且即将发生的伤害、且没有其他办法避免时；而此刻的正确回答不是“永远不会”（不真实）也不是“我马上打电话”（摧毁照护），而是把规则与支持一起说清：我们会先与你一起做，你自己在几天内告知最好；若你做不到，性接触者追踪与专员联络可以以匿名方式联系对方（不透露你的名字）；若仍无法防止严重伤害，则存在依法通报的路径并会告诉你——这是“信任才能带来公共卫生”的教科书情形：保密、无费用门槛与无移民执法联动是有效性条件——[[medical-ethics-law/confidentiality]]。临床的一层即刻可做：治疗的启动与“测不到即不传播”的证据是既保护他也保护他人的最强干预；同时筛查并处理其他性传播感染与乙型肝炎与丙型肝炎与猴痘的风险、提供暴露前预防给其阴性伴侣（这是一项具体的、可立刻做的保护措施，并且把“保护伴侣”从道德义务变成医疗行为）、以及安全性行为与依从的支持——[[infectious-diseases/hiv]]、[[pharmacology/adverse-reactions]]。风险的另一侧：他提到有人可能伤害他（亲密伙伴暴力与恐吓是常见的，且是“为何不愿告知”的真实原因），所以需要安全评估与转介，并在他在场时避免让他成为暴力的对象；同时记录告知与协商的过程（这是未来的审计所需）——[[psychiatry/self-harm-suicide-prevention]]。系统的责任：如果每次这样的决定都靠单个医师当场权衡，就会做得不一致——需要书面路径（谁评估、如何匿名通知、何时升级）、法定报告的确认（病毒学的报告通常是强制且不点名的）、以及督导与同行讨论——[[clinical-skills/patient-safety]]、[[medical-ethics-law/professionalism-regulation]]。**

## 通向何处

病原体的生物学见[[microbiology/bacteria]]与[[microbiology/viruses]]；医院内的传播与措施包见[[infectious-diseases/healthcare-infections]]与[[microbiology/infection-control]]；抗菌药物的策略见[[infectious-diseases/stewardship-outbreaks]]；疫苗的规划学见[[public-health/vaccination-programmes]]；全球与法律的框架见[[public-health/global-health]]；暴发的临床调度见[[emergency-critical-care/major-incidents]]。

::: history
**传染病控制是最古老的有组织公共卫生，也是它自己的案例档案。卫生时代（瘴气与传染之争、斯诺1849至1854年的霍乱研究与移除宽街水泵把手旁边的那次流行病学、德国佩滕科弗的反理论、排污工程的建设、以及塞麦尔维斯与南丁格尔与医院自己的热病房）确立了以登记官为来源的监测（死亡通报单）、统计地理、以及“干预即试验”（斯诺对两家供水公司的比较是公共卫生第一个自然实验）。细菌学时代（1876至1898年的科赫—巴斯德—贝林一线）带来法定报告的想法与制度、以及实验室作为国家能力；20世纪的规划时代给出了垂直模式的成就与限度：结核的化疗与随后耐药的教训、疟疾的 滴滴涕扑灭计划与其生态与抗药性的反弹、以及天花的根除（1967年强化、1980年认证）以其监督加环形接种的策略成为所有消除运动的模板——[[public-health/global-health]]。疫苗时代从索尔克与萨宾的试验到“扩大免疫规划”与“麻疹/风疹/脊灰”的倡议，并把覆盖率的地理分布变成流行病学的主指标；而1980年代的新发病主义（艾滋病与莱姆病与埃博拉与 O139 霍乱与疯牛病）催生了“再流行”的概念与分子监测；21世纪的工具是基因组与废水与实时数据流与《国际卫生条例》（2005年修订）与“同一健康”，而2019冠状病毒大流行把检测速度与分享与不分享之间的代价变成了可计量的账——本领域现在把“从信号到行动的天数”当作首要指标——[[infectious-diseases/hiv]]、[[microbiology/laboratory-diagnosis]]。**
:::

::: summary
- 控制针对的是感染的链条：储存宿主的生物学决定策略（只感染人的病原可被根除，人畜共患只能被管理），途径决定措施，而传播的数字（基本再生数、有效再生数、代际间隔、二代发病率）决定发病是否增长——它们是临床医师的流行病学词汇。
- 监测是人群的诊断：对少数危险疾病“按疑似即报告”、实验室与哨点的骨架、证候与废水的早期预警、以及基因组的流程——近年的一系列大流行以响亮而昂贵的失败证明了这一点，因此发现的速度如今是本领域的首要指标。
- 暴发调查是把临床方法用于人群：核实、定义、找病例、按人地时描述、边控制边检验假设、沟通、并留下一份预防计划；流行曲线的形状是体征，而罹患率是实验室结果。
- 工具——隔离、带暴露后预防的接触追踪、除外与关闭、环形接种、大规模预防服药、媒介与环境措施——每一项都需要使依从成为可能的支持系统（有薪隔离与工作保障与物资），以及互惠的伦理。
- 垂直规划（结核、艾滋病、性传播感染、可免疫疾病、耐药）共享同样的教训：可及的公平是一个生物学变量、治疗就是预防、消除是一种需要维持的状态，而成功会悄悄侵蚀产生它的那份警惕。
- 人群措施遵守比例性、必要性、最小限制与限期并附正当程序——这是公共卫生伦理的宪法；违反它（强制的、无支持的、污名化的控制）可预期地摧毁措施所依赖的合作。
:::

一名护士在器官摘取手术中未戴双层手套，被一名随后查出人类免疫缺陷病毒与乙型肝炎阳性的供者的缝合针刺伤。写出第一个小时内的评估与处置。
::: solution
**暴露后的第一个小时（[[#def-toolkit]]、[[infectious-diseases/hiv]]、[[surgery/perioperative-care]]）：即刻：让伤口自行出血并用清水与肥皂冲洗（不要挤压到底、不要用腐蚀剂），记录伤口的性质与深度与是否可见血迹与器械的类型与在体内的时间与供者的风险；随后报告并启动基线的检测（人类免疫缺陷病毒与乙型与丙型肝炎的全套与妊娠与肾功能，以及心理的支持）——[[clinical-skills/patient-safety]]。人类免疫缺陷病毒：在数小时内（理想两小时内、七日之内仍可考虑）启动三药联合的暴露后预防（以替诺福韦/恩曲他滨加上多替拉韦一类方案并按本地耐药与相互作用与肾功能调整），连续二十八天，并在第零与四与十二与二十四周复查（若用人类免疫缺陷病毒的核酸早期诊断则可缩短随访）；同时告知急性逆转录病毒综合征的症状与安全性行为的建议——[[pharmacology/absorption-distribution]]。乙型肝炎：关键是她的疫苗史与抗体状态（既往完整接种且应答者一般无需处理；未接种者给疫苗，暴露者已知高传染时加免疫球蛋白，并在数周后测抗体）；丙型肝炎：没有暴露后预防，因此以丙氨酸氨基转移酶与核酸的系列随访早期发现（早期的干预可治愈）——[[gastrointestinal/liver-disease]]。系统性的一环：器械的锐伤是否可避免（传递区与禁手传器械与安全的缝合器与照明）与是否有人在旁记录与交接；以及供者的检测窗口与方法的确认（聚合酶链与抗原，“供者阴性”并不总等于无传染性的早期）；并把本次事件进入职业健康与质量改进的登记（同类事件若集中于某类操作，说明需要改变设备或流程，而不是“再多培训”）——[[microbiology/infection-control]]。**

::: exercise 给一次暴发定量 {level=2}
一场婚礼后一百八十人进食，五十六例在三十六小时内发病（呕吐为主）；你有一天的时间给出判断。计算你能算的，并说明它告诉你什么、不能告诉你什么。
::: solution
**算术与它的边界（[[#def-surveillance]]、[[#def-chain]]、[[gastrointestinal/digestion-absorption]]）：可算的：总罹患率56/180约31%；按菜品分层计算罹患率与相对危险（吃了某道菜者对未食者的比），以及最短与最长与中位的潜伏期（呕吐为主加十余小时的潜伏指向金黄色葡萄球菌肠毒素或蜡样芽孢杆菌，而超过二十小时更像诺如或产气荚膜梭菌），以及“是否有人吃了两道菜”的混杂——在暴露人群明确的闭合队列里，队列分析优于病例对照。它告诉你的：哪道菜最可能、暴发的类型（点源单次暴露，因为曲线尖锐且集中）、以及是否已经过了传播的窗口（同源暴发不会自己持续，除非有人传人阶段——诺如会）。它不能告诉你的：病因的确认（需要食物的留样与患者的标本与实验室的方法，以及“未检出不能排除取样过晚”）；以及被漏掉的病例（症状轻而未报告的人使罹患率被低估，并且分母中的“没来的人”是系统误差）；还有单一菜品相对危险在多人吃了多道菜时的伪影（要按所有菜品同时建模，并检查“吃得多”的暴露—反应梯度，这才是最有力的证据）——[[microbiology/laboratory-diagnosis]]。控制随之而来：留样与环境与人员的筛查（食品处理者的症状史与带菌状态）、以及给公众的说明（已发病者何时不再具传染性、以及诺如的洗手需要肥皂而非醇类凝胶——这是最常见的沟通失败）——[[infectious-diseases/stewardship-outbreaks]]。**

::: exercise 评判口岸措施 {level=2}
一种新型呼吸道病毒在境外流行，发病两周、无症状传播明确。政府拟对来自受影响国家的航班实施旅客入境禁令。请给出你的评估。
::: solution
**入境禁令的评估（[[#def-toolkit]]、[[#def-chain]]、[[public-health/global-health]]）：科学的一面：禁令延缓而非阻止传播（在其流行国家已有本地传播、且存在无症状与症状前传播时，任何单一措施只能推迟数天到数周，而流行曲线在境内继续）；有效性取决于覆盖率（禁令漏掉经第三国中转者与本国归国者）与执行；而它有三个被低估的成本：把旅行者推入更危险与更不透明的路线、削弱通报与分享的激励（这是《国际卫生条例》的核心顾虑：措施若惩罚报告者，下次就晚知道）、以及分散国内的注意力（边境的象征性行动常替代真正有效的境内措施）。可辩护的组合：把资源放在境内（检测与隔离的支持与通风与口罩的可及与高危场所的保护与快速的数据与沟通），并把口岸措施限定为可执行且有信息价值的那部分（旅客定位与健康申报与到港检测或自愿检测与针对归国者的隔离支持）。伦理与公平的一面：针对特定国籍与目的地的限制会助长歧视、并把疾病“外族化”（这是每个传染病教师都反复讲过的错误），而且对旅客造成不可偿还的负担——所以需要法律审查、定期复审、时限、以及非歧视的理由。要说给政治决定者的一句话：若目的是“减少国内的死亡”，则禁令的收益几乎全部在前几周且很快衰减；若目的是“为境内措施争取时间”，则必须与一项明确的、已筹资的、有时限的境内计划绑定，否则只是把时间花在原地——[[emergency-critical-care/major-incidents]]、[[medical-ethics-law/justice-resources]]、[[respiratory/respiratory-infections]]。**

::: exercise 设计消除的验证 {level=3}
一国已连续三十六个月无本地麻疹病例，要求申请消除的验证。请设计证据包，并指出会被拒的三个理由。
::: solution
**验证的证据包（[[#def-surveillance]]、[[#def-toolkit]]、[[public-health/vaccination-programmes]]）：验证的逻辑不是“没有病例”而是“监测系统足以证明没有病例”，因此文档要按证据等级组织：监测的灵敏度（急性发热皮疹的定期报告、每位住院的急性发热皮疹与所有不明原因发热者采集标本、以及非麻疹的证实性检测数——“每十万人口一份阴性标本”这类指标比病例数为零更能说明问题）；实验室的能力（外部质量评价、双重读取、以及病毒学与免疫学的试剂与冷链与周转时间）；病例的分类（每一例被调查并给出结论与依据，以及“与输入相关”与“地方传播链大于十二周”的区分规则）；暴发的响应（一次输入引发的局部传播的响应速度、以及病例与接触者搜索的时间线）；以及人群免疫（国家与地区的接种覆盖率及其分布与血清学的易感性调查、以及漏种人群的定位与补种）——[[immunology/vaccines-immunotherapy]]。三个会被拒的理由：一，覆盖率被高估（用行政分母与真实登记不符、或用国家平均掩盖了低覆盖的聚集——验证看的是最弱的那一处）；二，监测的质量不达标（报告延迟、标本的采集率与时间不合格、实验室无外部质量评价）；三，爆发响应的记录缺失（无法证明一次输入被发现并在其成为地方传播链之前被阻断）。此外：一次输入本身不构成失败，而隐瞒或迟报构成；因此申请过程最常被“我们不愿上报可疑病例”的文化杀死；以及验证之后需要“维持”的报告，因为消除是一种状态而不是勋章——[[clinical-skills/patient-safety]]、[[public-health/determinants-inequalities]]。**

::: example 有咳嗽登记表的诊所 {#ex-tb}
一家城市全科诊所的护士带来一份咳嗽登记表的复印件：四个月内六十三名咳嗽超过三周者，其中九人未去拍胸片；同一诊所在两年里接诊了两例涂片阳性的结核。
::: solution
**从登记表到控制（[[#def-surveillance]]、[[#def-toolkit]]、[[infectious-diseases/tuberculosis]]）：这张表既是病例发现的资产也是风险的清单：咳嗽三周以上是活动性结核的敏感但不特异的指标（在低流行国家其阳性预测值很低），所以问题不是“为什么没查”而是“查了之后会发生什么”——检查必须在数日内完成、结果要能被读到并有人行动，否则只是制造焦虑；九名未摄片者需要被主动联系并给出障碍的具体处理（工作与交通与费用与语言与对被发现的恐惧）——[[respiratory/respiratory-infections]]。两例涂片阳性发生在同一诊所的服务人群里，意味着需要正式的同源与传播链调查（把病例的时空与接触网络叠合，并考虑诊所等候室这一可能的传播场所——通风与口罩与咳嗽礼仪与把传染者分流到别的时段与房间），而不是各自的治疗与随访——[[microbiology/infection-control]]、[[respiratory/gas-exchange]]。控制包应当同时铺开：治疗（正确的四药方案与直接观察或视频观察与不良反应的监测与依从支持，以及耐药风险的评估：来自高耐药国家与既往治疗与接触者）、接触者的调查（家庭与密切与工作场所与无家者与庇护所与拘留所）与潜伏感染的发现与治疗（尤其五岁以下儿童与免疫抑制者）、以及对高风险人群的主动筛查（按本地流行病学而不是按族裔标签——族裔是贫困与迁移的代理，不是生物学原因）——[[infectious-diseases/immunocompromised-host]]、[[public-health/determinants-inequalities]]。伦理与支持的清单：有薪的隔离与工作保障与住房与营养与对歧视的救济；以及通报与身份保密与移民执法联动的避免——这些不是善意而是让病例愿意前来的条件；并把登记表改成闭环（每一个“咳嗽三周”都有条目、结果、负责人与关闭日期），并把闭环率作为质量指标在例会汇报——[[medical-ethics-law/justice-resources]]、[[clinical-skills/records-handover]]。**

::: example 诺如病毒的冬天 {#ex-norovirus}
一家八十床的社区医院在两周内出现八个病房的聚集性腹泻与呕吐；同时三所护理院报告类似情况；化验室只在少数病例做了检测；员工说“每年都这样”。
::: solution
**把“每年都这样”当作可解决的问题（[[#def-surveillance]]、[[#def-toolkit]]、[[gastrointestinal/digestion-absorption]]）：诊断上：冬季多发、多病房、以呕吐为主、短期自限、以及酒精擦手液效果不佳的表现，都指向诺如病毒；用一两份新鲜粪便的核酸检测确认即可（不需要每例都测，但要足够确认并排除艰难拟梭菌与细菌性原因，因为两者在同类症状里共存且措施不同）——[[clinical-skills/laboratory-tests]]、[[gastrointestinal/bowel-disease]]。措施的优先级按传播途径排：接触与环境（肥皂与水的洗手是最有效的一条，因为醇类对无包膜病毒效果有限，且要教到指尖与指甲与环境清洁的频次）、呕吐物的处置（气溶胶化的风险与即刻的清除与含氯消毒剂的浓度与作用的接触时间）、患者的安置（症状出现后四十八小时内留在单间或分区、停止共用的活动与餐厅与共享设备）、以及食品的环节（呕吐近旁的员工与备餐者的症状筛查与“从症状到复工”的严格时限，因为食品的二次传播会把一个病房变成六个）——[[microbiology/infection-control]]、[[infectious-diseases/healthcare-infections]]。被低估的两点：脱水与停药（老年人在腹泻与呕吐后的急性肾损伤与高钾与低血压，以及利尿剂与二甲双胍与血管紧张素转换酶抑制药的“病假日规则”要预先写在路径里）——[[renal/acute-kidney-injury]]、[[pharmacology/dosing-principles]]；以及关闭的代价（病房关闭保护他人但延误出院与压床与谵妄与跌倒——所以要与流转团队一起决定关闭的范围与时长，并同时启动同室的 cohorting 而不是简单地停一切）——[[geriatrics-palliative/delirium-dementia-care]]、[[clinical-skills/patient-safety]]。治理：把三所护理院与医院放进同一张图（同一社区与共享的员工与转运，说明这是区域性的暴发而不是八次独立事件），因此需要区域联合的指挥与共享的名册与统一的复工标准，并向上级通报（这是法定职责）；同时把“每年”的部分变成年度准备（在季前把消毒剂的库存与单间与检测的路径与员工的培训与“呕吐应急包”到位）——[[emergency-critical-care/major-incidents]]、[[public-health/communicable-disease-control]]。**

## 练习

::: exercise 写出风险沟通 {level=1}
某工厂发生工业性吸入暴露，十七人留观，暂无健康损害证据，媒体在门口；请写出你会说的那段话的要点。
::: solution
**沟通的要点（[[#def-surveillance]]、[[#def-toolkit]]、[[public-health/environmental-occupational]]）：五句话的结构：一，我们知道什么（时间、物质与暴露人数、以及目前的临床状态与已确认的无死亡）。二，我们不知道什么（暴露的剂量与某些延迟效应需要观察，明确说“尚未确定”比含糊更可信）。三，我们正在做什么（现场的处置与医学评估与环境的采样与何时会有下一次更新）。四，这对你意味着什么（需要就医的症状与去哪里、以及“如果你今天无症状则极不可能受严重影响”的诚实估计）。五，我们在为谁做（工厂与社区与员工代表参与的联合委员会、以及投诉与查询的渠道）——[[clinical-skills/communication]]。两条纪律：不用“没有危险”（无法证明，而一旦被推翻就永久失去可信度），而用“目前未发现损害，且我们仍在检查”；并给出下一次更新的确切时间并如期兑现（这比内容更能建立信任）。同时处理三个常见陷阱：把毒理的剂量—反应讲成可比的日常参照（并把不确定性与保守的假设说清）、对工人 补偿 与休假与随访承诺的具体说明（模糊会被读为回避）、以及对社交媒体上流传的具体传言逐条回应而不是发布一份通用新闻稿——[[public-health/determinants-inequalities]]、[[medical-ethics-law/professionalism-regulation]]。**

::: exercise 为耐药项目建模 {level=2}
你要为一个高耐药结核与医疗相关多重耐药菌并存的城市设计一个整合的抗微生物耐药项目。给出组件、以及你会监测的五个指标。
::: solution
**耐药的整合项目（[[#def-toolkit]]、[[infectious-diseases/stewardship-outbreaks]]、[[microbiology/antimicrobials]]）：组件按链条排：诊断的速度（分子药敏与血培养的路径与报告时间与“两小时降阶梯”的反馈回路，因为无诊断就没有管理）、处方的支持（本地的指南与结构化病历的强制理由与静脉到口服的切换与限制的抗生素的会商、以及把耐药监测图交给处方者而不是存档）、感染预防（手卫生与设备与环境与隔离的可执行性与医院与护理院与社区的贯通，因为耐药的传播主要发生在照护的连接处）、以及供应与质量的保障（假药与断供与农业与兽医用量的治理，即“同一健康”的部分）——[[gastrointestinal/clinical-nutrition]]、[[public-health/environmental-occupational]]。五个指标：一，耐药菌的血流感染每千床日的发生率（按机构与社区分层）；二，窄谱与短程与口服的比例（作为过程指标，比总用量更贴近质量）；三，从标本采集到药敏报告的中位时间；四，接触隔离与手卫生依从的可测执行率；五，社区获得性耐药与农业与环境监测的趋势（包括废水）。公平的一条：耐药的负担落在反复住院与护理院与免疫抑制与无家者与晚期疾病者身上，因此项目必须与照护的连续性与感染控制的基础设施一起筹资，而不是只针对处方行为——[[geriatrics-palliative/polypharmacy]]、[[infectious-diseases/immunocompromised-host]]。最后是结核的一翼：在结核中耐药意味着长程、昂贵与有毒的方案与住院与 stigma，所以直接观察或视频治疗与接触者调查与潜伏感染的治疗与药物可及的谈判，都是“耐药管理”的一部分而非并列的项目——[[infectious-diseases/tuberculosis]]。**

::: exercise 就隔离令进言 {level=2}
一名从埃博拉流行区归国的医务人员体温36.9度，坚持认为“我没有病”，正要登上长途客车参加家庭聚会；卫生官员要求你签署强制隔离的评估。
::: solution
**强制隔离的门槛（[[#def-toolkit]]、[[public-health/global-health]]、[[infectious-diseases/stewardship-outbreaks]]）：先把事实与规则分开：监测期内的每日两次体温 与症状的监测是自愿协议的第一层；强制的前提是（一）科学上此人有传播风险且疾病严重（埃博拉在症状前不传播，这是关键——也是为什么“发热才隔离”在此有效）；（二）比例性与最小限制（先提供自愿的方案与替代的去处与补偿，再谈强制）；（三）程序（由谁签、多久复核、被隔离者的申诉与法律帮助与基本的需要被满足）。所以今天的答案不是“关起来”，而是三件事同时做：把风险具体化并记录（这个温度的意义、以及为何此时乘长途客车与聚会不可接受——一辆密闭的长途车加一个家庭聚会，是本地最需要避免的暴露场景）；提供可接受的替代（单独的房间与交通与照护与与工作单位的沟通与对聚会的改期，以及一名被信任的人参与谈判）；以及若仍拒绝，启动法定的评估而不是自行争论（并明确告知强制的门槛与后果）。临床与照护的责任：一旦被隔离，评估的责任仍在（症状与检查与必要时的检测与转移的路径与感染控制的准备，以及若出现发热即送哪一家医院），并且要防止“公共卫生的处置”取代“医学的照护”（焦虑与孤立与基础病的治疗与解释性沟通都要有安排）——[[medical-ethics-law/consent-capacity]]、[[emergency-critical-care/major-incidents]]。事后的一步：把这一类决定做成书面的共同决策清单（阈值与替代方案与复核的时限与记录表格），因为强制权力的合法性取决于它是否一贯、可复核且有理由——[[clinical-skills/patient-safety]]、[[medical-ethics-law/justice-resources]]。**

::: exercise 构建早期预警的升级 {level=3}
某国监测系统在一次大流行中表现很差（发现晚、数据不互通、基层不敢报）。请给出一个五年的升级方案：能力、技术、治理与信任，并给出资金与优先级的论证。
::: solution
**五年升级（[[#def-surveillance]]、[[#def-toolkit]]、[[public-health/health-systems-economics]]）：先诊断为什么慢：多数薄弱系统的失败不是缺技术，而是缺（一）人（流行病学与信息学与实验室的人员、以及在地方层面能在一小时内开始调查的队伍）；（二）激励（报告者得不到反馈且被视为找麻烦、以及地方政府害怕措施的代价）；（三）互操作（各系统的定义与编码与身份不同、纸质的实验室记录与断网）。方案的第一年先做“能救命的最低集合”：法定疾病的清单与病例定义与二十小时内报告的时限、一条把实验室的阳性结果自动接入国家数据库的管道（用国际命名与字典）、一个可离线填报的手机端与热线、以及每周一次公开的数据与响应记录（因为透明是自我强化的：当公众看到数据被用，报告就会增加）——[[clinical-skills/laboratory-tests]]、[[clinical-skills/records-handover]]。第二年建实验室与基因组：国家参考实验室与区域的网络与外部质量评价与周转时间的公开指标与测序能力（以及分享的伦理与利益的谈判能力——在大流行中“分享序列换疫苗”的不对等需要制度性的解决）；第三年建人力：现场流行病学培训与在职的硕士与保留薪酬与晋升的通道（否则毕业的人会被世卫与国际组织与私营部门吸走）、以及“关键能力”的年度自评加上外部的验证——[[public-health/global-health]]。第四至五年做自动化与韧性：证候 与废水与动物与药店的信号、一条把异常检测与阈值预警做成可审计算法的规则（含误报的成本与响应的规程）、以及把系统接入急诊与重症的容量登记（发现的价值取决于响应是否有床位与防护与检验的能力）——[[emergency-critical-care/critical-care]]、[[microbiology/laboratory-diagnosis]]。资金与论证：把钱放在“平时就在工作”的能力上（监测同时服务常规项目的规划、以及疫苗安全与抗菌药物耐药与慢病的统计），因为“只为大流行而建的系统”会在和平年代被裁撤；并以成本对比说明（本领域最常被引用的一句话是：防范的成本比损失低一到两个数量级）；治理上写清三件事：谁在何时必须行动（避免“数据到部长桌上”才有人动）、如何保护个人数据与禁止将健康数据用于移民与治安目的、以及一份对迟报的独立审查——因为一个不敢报告的系统不是便宜的系统，而是把风险转移到最脆弱的社区——[[medical-ethics-law/confidentiality]]、[[public-health/determinants-inequalities]]。**
