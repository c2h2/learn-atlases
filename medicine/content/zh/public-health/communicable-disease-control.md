一个星期一的早上，一位全科医生接诊了三位呕吐并伴血性腹泻的患者。三人都是星期六同一场婚礼的宾客。每位患者都会得到个别治疗，但这位全科医生最重要的行动只需不到五分钟：给当地卫生防护团队打一个电话。这个电话启动了一连串的工作，可能找出致病的食物、阻止它再被供应给任何人、找到已经患病但尚未就医的宾客，并防止感染在他们的家庭和工作场所中传播。

传染病控制是公共卫生对感染的应对：监视感染（监测）、识别何时出现了异常情况、开展调查，并阻断传播。它的范围从单个脑膜炎球菌病病例直到全球大流行。本章介绍传播的术语、监测与报告、暴发调查、可用的控制措施，以及大流行防范，包括《国际卫生条例》。各种感染的微生物学和医院感染控制分别见[[infectious-diseases/stewardship-outbreaks]]和[[microbiology/infection-control]]。

## 传播的术语 {#transmission}

感染通过**感染链**传播：病原体从**储存宿主**（人、动物或环境）经**排出门户**离开，通过某种**传播方式**（接触、飞沫、空气、粪-口、媒介、血液，或从母亲到孩子的垂直传播）移动，经**侵入门户**进入**易感宿主**并造成感染。控制措施通过打断一个或多个环节起作用。

::: definition 时间段与罹患率 {#def-periods}
- **潜伏期**是从感染到出现症状的时间。
- **潜隐期**（latent period）是从感染到开始具有传染性的时间。它可能短于潜伏期，使人在出现症状之前就能传播（如流感和新冠），这使控制更加困难。
- **传染期**是感染者能够传播的时间段。
- **序列间隔**是一个病例出现症状到其所感染者出现症状之间的时间。**代际间隔**是相应的两次感染之间的时间。
- **罹患率**是暴发期间暴露人群中发病者的比例：病例数除以暴露人数。（它是一个比例，而不是率。）
- **二代罹患率**是原发病例的易感接触者中在一个潜伏期内被感染者的比例：衡量家庭等场所中传播能力的指标。
:::

[[public-health/vaccination-programmes]]中介绍的基本再生数$R_0$和有效再生数$R_e$衡量每个病例感染多少人。$R_e$取决于每次接触的传播概率、单位时间内的接触次数以及传染期的长短。每一项控制措施都降低这三者之一。

::: theorem 控制措施作用于R的各组成部分 {#thm-r-components}
有效再生数可写为

$$
R_e = \beta \times c \times D \times s,
$$ {#eq-r-components}

其中$\beta$是每次接触的传播概率，$c$是单位时间内的接触次数，$D$是传染期长度，$s$是接触者中易感者的比例。当$R_e < 1$时，流行减弱。各自按一定比例降低某一因素的独立干预，其效果相乘。
:::

::: proof
每个具有传染性的人在$D$天内每天有$c$次接触，共计$cD$次接触。其中比例为$s$的接触对象是易感者，每次这样的接触以概率$\beta$发生传播。因此，期望的新感染数为$\beta c D s$。手卫生、口罩和安全套降低$\beta$；隔离、保持社交距离和关闭场所降低$c$；早期诊断和治疗（例如结核病或性传播感染）缩短$D$；疫苗接种和预防用药降低$s$。如果一项措施使$c$降低50%，另一项使$\beta$降低30%，新的$R_e$就是原来的$0.5 \times 0.7 = 0.35$倍。这就是为什么多项不完美措施的组合能够控制任何单一措施都无法控制的流行。
:::

## 监测 {#surveillance}

::: definition 公共卫生监测 {#def-surveillance}
**监测**是持续、系统地收集、分析和解释与健康有关的数据，并将结果及时分发给需要采取行动的人。其目的是发现暴发和新的威胁、监测趋势、评价疫苗接种等干预措施，并指导政策。监测是“为了行动的信息”：收集了却不使用的数据不是监测。
:::

监测系统包括：

- **被动监测**：临床医生和实验室按要求报告病例（法定报告、实验室报告）。成本低但不完整。
- **主动监测**：公共卫生人员主动寻找病例，例如在暴发期间每天联系医院。
- **实验室监测**：报告鉴定出的病原体，现在包括全基因组测序，它能把看似无关的病例联系起来（例如把全国各地的*沙门菌*或*李斯特菌*病例追溯到同一个食品生产商），并发现抗微生物药物耐药性。
- **哨点监测**：由部分诊所或医院详细报告，例如报告流感样疾病并采集拭子的全科诊所网络。
- **症状监测**：监测NHS 111电话、全科就诊和急诊科就诊中腹泻或呼吸道疾病等症状的非特异性指标，在诊断得到确认之前提供早期预警。
- **环境监测**：对污水中病毒的检测（用于SARS-CoV-2，以及脊髓灰质炎病毒，2022年曾在伦敦污水中检出）和对病媒的监测。
- **基于事件的监测**：扫描媒体、报告和国际信息来源，寻找异常事件的信号。

对监测系统的评价考虑其灵敏度、预测值、及时性、代表性、简单性、灵活性和可接受性。

### 英格兰的传染病报告 {#notification}

根据**《2010年卫生防护（报告）条例》**（Health Protection (Notification) Regulations 2010），英格兰的注册医生必须向地方政府的“指定官员”（实际上是当地UKHSA卫生防护团队）报告他们怀疑患有**法定报告疾病**的患者。要点如下：

- 在**临床怀疑**时即须报告。医生不应等待实验室确认。
- 应在**3天**内报告；如属紧急病例（例如脑膜炎球菌病、麻疹、白喉，或怀疑食品从业人员发生食物中毒），应在**24小时**内电话报告。
- 诊断实验室另行报告其鉴定出的**病原体**。
- 对于对人类健康构成或可能构成重大危害的其他感染或污染（化学或放射性），即使不在名单上，医生也必须报告。

名单包括急性脑膜炎、急性脑炎、急性传染性肝炎、霍乱、白喉、肠热症（伤寒和副伤寒）、食物中毒、溶血性尿毒症综合征、感染性血性腹泻、侵袭性A群链球菌病、军团病、疟疾、麻疹、脑膜炎球菌败血症、流行性腮腺炎、鼠疫、狂犬病、风疹、猩红热、结核病、病毒性出血热和百日咳等。苏格兰、威尔士和北爱尔兰有各自的立法和名单。

在英格兰，**英国卫生安全局**（UKHSA，自2021年10月起运作）牵头负责传染病监测和应对，地方**卫生防护团队**由卫生防护顾问医师领导。地方政府的公共卫生主任、环境卫生官员（检查食品场所并调查食源性暴发）以及NHS感染预防与控制团队与他们协同工作。

::: warning 在怀疑时报告，而不是在确认时报告
一个常见的错误是等到实验室结果出来才报告。对于脑膜炎球菌病，接触者需要在诊断后24小时内进行抗生素预防；对于麻疹，暴露后接种在暴露后72小时内效果最好；对于食物中毒，受污染的产品可能仍在销售。一份后来被证明有误的报告几乎没有代价，而延误的报告可能导致死亡。法律义务适用于临床怀疑，卫生防护团队也宁愿尽早得到消息。
:::

## 暴发调查 {#outbreaks}

::: definition 暴发 {#def-outbreak}
**暴发**是指在时间和地点上相关联的两例或以上感染病例，或在特定时间和地点出现多于预期的病例，或单例特别严重的疾病（如白喉、病毒性出血热或一例脊髓灰质炎）。**流行**是人群中病例数高于预期水平的增加，通常范围更大；**大流行**是跨越几个国家或大洲的流行。当一种感染以基线水平持续存在于人群中时，称为**地方性流行**。
:::

暴发调查遵循一系列步骤，实际上这些步骤相互重叠，并与控制措施同时进行：

::: algorithm 暴发调查的步骤 {#alg-outbreak}
1. **准备并确认暴发。** 核实病例数确实超过预期（排除报告、检测或人群方面的变化），并与实验室一起确认诊断。
2. **如暴发较严重，召集暴发控制小组**，明确分工：卫生防护、微生物学、环境卫生、宣传沟通以及受影响的机构。
3. **确定病例定义。** 病例定义规定人群、地点、时间以及临床或实验室标准，常分层次（确诊、很可能、可能）。早期定义宽泛以便发现病例，后期收窄以便进行分析性研究。
4. **发现病例**，并用标准问卷收集病例信息。
5. **描述暴发**：按时间（流行曲线）、地点（地图）和人群（年龄、性别、暴露）描述。
6. **提出假设**：关于传染源和传播方式。
7. **检验假设**：采用分析性研究（队列研究或病例对照研究）、微生物分型和环境调查。
8. **一旦有理由就实施控制措施**；不要等到确定无疑。
9. 在全过程中与公众、专业人员和受影响者**沟通**。
10. **评价和报告**：宣布暴发结束（通常在两个潜伏期内无新病例之后），撰写包含经验教训的报告，并改进实践。
:::

### 流行曲线 {#epicurve}

**流行曲线**是按症状出现日期绘制的病例直方图。其形状提示暴发的类型：

- **点源**暴发来自某一时间的单次暴露（一场婚宴），在一个潜伏期范围内急剧上升又下降。从高峰向前推一个潜伏期中位数，可以估计可能的暴露时间。
- **持续同源**暴发（受污染的供水）形成一个平台，持续时间与暴露时间相当。
- **增殖性**暴发在人与人之间传播，产生相隔约一个序列间隔的连续波次，通常会不断扩大，直到控制措施或免疫使其减缓。

::: example 估计暴露时间 {#ex-exposure-time}
在一次办公室员工诺如病毒暴发中，第一例在星期三06:00开始呕吐，病例高峰在星期三18:00，最后一例在星期四08:00发病。诺如病毒的潜伏期通常为12～48小时，中位数约为33小时。可能的暴露时间是什么时候？曲线提示了什么？
::: solution
**从高峰向前推**一个潜伏期中位数：星期三18:00减去33小时，为星期二09:00。

**用范围核对。** 最早病例（星期三06:00）减去最短潜伏期（12小时），得到该病例最晚可能的暴露时间为星期二18:00。最后一例（星期四08:00）减去最长潜伏期（48小时），得到最早可能的暴露时间为星期二08:00。星期二约08:00至18:00之间的暴露与所有病例相符。

所有病例都落在约一个潜伏期之内，提示是**点源**，例如星期二午间会议上的食物或受污染的共用物体表面，而不是人传人。诺如病毒非常常见人传人，因此调查人员会留意一两天后在家庭接触者和同事中出现的第二波，并建议严格用肥皂和水洗手（含酒精的免洗手消毒液对诺如病毒效果较差）、用含氯产品清洁，并让病例在症状停止后48小时内不上班。
:::
:::

::: example 一场婚宴 {#ex-wedding}
一场婚礼的120名宾客中，47人在用餐后12～48小时内出现腹泻和呕吐。对全体宾客开展的队列研究结果如下：

| 食物 | 食用者：发病/总数 | 未食用者：发病/总数 |
|---|---|---|
| 鸡肉 | 42 / 70 | 5 / 50 |
| 米饭沙拉 | 30 / 80 | 17 / 40 |

计算每种食物的罹患率和相对危险度。哪种食物可能是传播媒介？接下来应做什么？
::: solution
**鸡肉。** 食用者罹患率$= 42/70 = 60\%$；未食用者$= 5/50 = 10\%$。相对危险度$= 0.60/0.10 = 6.0$。

**米饭沙拉。** 罹患率$= 30/80 = 37.5\%$，对比$17/40 = 42.5\%$。相对危险度$= 0.375/0.425 = 0.88$。

鸡肉与发病强烈相关，米饭沙拉则不相关。五名未吃鸡肉的发病宾客可能吃了却没有记住（回忆并不完美），或吃了被交叉污染的菜肴，或患的是另一种疾病。12～48小时的潜伏期符合*沙门菌*或*弯曲菌*等；对于大批量烹制并缓慢冷却的禽肉，*产气荚膜梭菌*（8～22小时）也有可能。

**下一步。** 采集病例粪便样本进行培养或PCR及分型；采集剩余食物样本；环境卫生官员检查餐饮承办方，重点检查烹饪、冷却和储存温度；核查食品从业人员是否患病（他们必须在症状停止后48小时内不得工作）；就卫生问题向病例提供建议，如果他们从事食品处理或卫生和社会照护工作，还应建议暂停工作；并核查该承办方是否还为其他活动供餐。还应报告相对危险度的统计检验和置信区间。
:::
:::

当无法界定暴露人群时（例如病例分散在全国各地），采用**病例对照研究**比较病例和对照的暴露情况，关联指标为比值比。全基因组测序现在常能把分散的病例联系起来并指向共同来源，然后通过沿食品供应链追溯来确认。

## 控制措施 {#control}

控制措施作用于传染源、传播途径和易感人群。

**传染源。** 治疗病例（缩短传染期）、将受污染的食品下架、关闭冷却塔并进行消毒（军团病）、扑杀受感染的动物，或处理水源。

**传播途径。** 手卫生、食品卫生、安全的水和卫生设施、通风、口罩和个人防护装备、安全性行为，以及病媒控制。

**易感人群。** 疫苗接种，用抗生素、抗病毒药、疫苗或免疫球蛋白进行暴露后预防，以及健康教育。

::: definition 隔离、检疫与排除 {#def-isolation}
- **隔离**（isolation）把*患病或已知被感染*的人与他人分开，以防止传播（例如把开放性肺结核患者安置在负压病房）。
- **检疫**（quarantine）在潜伏期内限制*健康但已暴露*者的活动，以防他们变得具有传染性。
- **排除**（exclusion）让病例或接触者在规定时期内不进入特定场所，如学校、托儿所或食品处理岗位。例如，腹泻或呕吐的儿童和成人通常在症状停止后48小时内不得上学、上托儿所或上班，某些感染（如产志贺毒素*大肠埃希菌*）在高风险人群中适用更严格的规定。

在英格兰，卫生防护立法允许治安法官在极少数情况下，当某人构成重大风险且不愿自愿配合时，下令采取拘留或隔离等措施。这类权力必须相称，并且是最后手段。
:::

### 接触者追踪 {#contact-tracing}

**接触者追踪**识别暴露于病例的人，对他们进行评估，并提供检测、预防用药、疫苗接种、建议或检疫。它是控制结核病、性传播感染（此时称为性伴通知）、脑膜炎球菌病、麻疹、病毒性出血热以及流行初期新发感染的核心手段。

当感染的潜伏期相对于追踪所需时间较长、大部分传播发生在症状出现之后、且接触者可以被识别时，接触者追踪效果最好。当大量传播发生在症状出现之前或无症状时，如新冠和流感，它就很难奏效，因为等到病例被识别时，其接触者可能已经具有传染性。**反向追踪**（询问病例是在哪里被感染的）能发现聚集性病例和超级传播事件，它们往往比逐个向前追踪每个人的接触者更有成效。

:::

::: example 家庭中的脑膜炎球菌病 {#ex-meningococcal}
一名17岁的女学生因脑膜炎球菌败血症入院。她与父母和弟弟同住，她的男友在她发病前两天曾在家中过夜。上周她去过学院上课。哪些接触者需要预防用药？还应做些什么？
::: solution
在临床怀疑时即用电话紧急**报告**卫生防护团队；不要等待确认。

**密切接触者**是在发病前7天内在家庭类型环境中与病例有长时间密切接触的人：这里是她的父母、弟弟和在家中过夜的男友。在随后几周里，他们的风险是一般人群的数百倍，主要是因为他们可能携带同一菌株。按照UKHSA指南，为他们提供**抗生素预防**（常用环丙沙星）以清除携带，最好在诊断后24小时内进行。如果菌株属于疫苗可预防的血清群（例如C、W或Y群，对于某些接触者还有B群），也可为密切接触者提供疫苗。

**学院接触者**在出现单个病例后通常不给予预防用药，因为他们的风险只是略有升高。而是向学院提供脑膜炎球菌病体征和症状的信息，以鼓励尽早就诊。同一场所出现两例或以上病例时，将重新评估是否扩大预防用药和疫苗接种。

**卫生工作者**只有在口鼻直接暴露于患者的呼吸道分泌物时（例如在未戴口罩的情况下进行气管插管）才需要预防用药。

如果病例本人的治疗中不包括能清除携带的抗生素，她本人也应接受一种这样的抗生素。
:::
:::

### 传播有多快？ {#growth}

在流行初期，病例大致呈指数增长。如果每一代感染使病例数乘以$R$，且两代之间相隔$T_g$天，则**倍增时间**约为

$$
T_d = T_g \times \frac{\ln 2}{\ln R}.
$$ {#eq-doubling}

::: example 组合干预 {#ex-combining}
一种新的呼吸道病毒$R_0 = 2.5$，代际间隔为5天。(a) 倍增时间是多少？(b) 采取了使接触减少一半的措施。$R_e$是多少？新的倍增时间是多少？(c) 此外，快速检测和隔离使剩余的传播减少30%。现在$R_e$是多少？
::: solution
(a) $T_d = 5 \times \ln 2/\ln 2.5 = 5 \times 0.693/0.916 = 3.8$天。病例几乎每周翻倍两次。

(b) $R_e = 2.5 \times 0.5 = 1.25$。$T_d = 5 \times 0.693/0.223 = 15.5$天。流行仍在扩大，但慢得多，为卫生服务和疫苗研发赢得了时间。

(c) $R_e = 1.25 \times 0.7 = 0.875$。低于1，流行开始减弱。正如[[#thm-r-components]]所预测的，任何单一措施都做不到这一点，而组合起来就能做到。必须权衡每项措施的成本和危害（经济、社会、教育方面），并以能使$R_e$保持可控的顺序和速度放宽措施。
:::
:::

## 医疗相关感染与抗微生物药物耐药性 {#hcai}

在医疗场所获得的感染，包括*艰难梭菌*感染、MRSA菌血症、革兰阴性菌血流感染、病房内的诺如病毒暴发和手术部位感染，在英格兰都属于强制监测对象。它们通过感染预防与控制（手卫生、隔离、清洁、器械护理）和抗微生物药物管理来控制。抗微生物药物耐药性是传染病控制面临的最严重的长期威胁之一：它使可治的感染变得无药可治，并危及外科手术、癌症治疗和重症监护。其全球层面见[[public-health/global-health]]，抗微生物药物管理见[[infectious-diseases/stewardship-outbreaks]]。

## 大流行防范与《国际卫生条例》 {#ihr}

::: definition 《国际卫生条例》 {#def-ihr}
**《国际卫生条例（2005）》**（IHR）是由世界卫生大会通过、具有法律约束力的国际法文书，它要求196个缔约国：

- 建立发现、评估、报告和应对公共卫生事件的核心能力；
- 在评估后24小时内向世卫组织通报任何可能构成**国际关注的突发公共卫生事件**（PHEIC）的事件；
- 避免采取对国际旅行和贸易造成不必要干扰的卫生措施。

**PHEIC**是指通过疾病的国际传播对其他国家构成公共卫生风险、可能需要采取协调一致的国际应对措施的不同寻常事件。它由世卫组织总干事根据突发事件委员会的建议宣布。每个国家都设有**《国际卫生条例》国家归口单位**；在英国，这一职能设在UKHSA内。
:::

已宣布的PHEIC包括：H1N1流感（2009年）、脊髓灰质炎（2014年，至今仍有效）、西非埃博拉（2014年）和刚果民主共和国埃博拉（2019年）、寨卡（2016年）、新冠（2020年），以及猴痘（2022年，以及2024年至2025年9月）。

新冠大流行暴露了条例的弱点：通报和信息共享延迟、疫苗和其他应对物资获取不公平，以及普遍不遵守条例。世界卫生大会于2024年通过的《国际卫生条例》修正案于2025年9月生效。修正案引入了一个新的、更高的警报级别，即**大流行紧急状态**，并加强了关于公平、国家《国际卫生条例》主管部门和筹资的条款。另外，世界卫生大会于2025年5月20日通过了**《世卫组织大流行协定》**。它涵盖预防（包括“同一健康”方法）、研究与开发、技术转让和公平获取；其关于病原体获取和惠益分享的附件仍在谈判之中，该协定需要60个国家批准才能生效。

国家层面的防范包括监测和实验室能力、应对物资储备、卫生服务扩容计划、法律权力、风险沟通，以及检验计划的演练。英国新冠调查（UK COVID-19 Inquiry）的第一份报告（2024年）得出结论：英国为错误的大流行即流感大流行作了准备，既没有为另一类病原体所需的检测、接触者追踪和隔离作出充分规划，也没有为措施对最脆弱群体的影响作出充分规划。

::: quiz
一位全科医生接诊了一名6岁儿童，有发热、斑丘疹、结膜炎和咳嗽。该儿童未接种疫苗。怀疑是麻疹，但尚未做任何检测。关于报告，全科医生应该怎么做？
- [ ] 等麻疹检测阳性后，在3天内报告。
- [ ] 只有在该地区还有其他病例时才报告。
- [x] 现在就根据临床怀疑紧急电话报告卫生防护团队。
- [ ] 不需要报告，因为孩子会在家中康复。
::: solution
麻疹在临床怀疑时即须报告，而且属于紧急报告，因为易感接触者（包括候诊室中的婴儿、孕妇和免疫抑制者）可能需要在72小时内进行暴露后接种或使用免疫球蛋白。卫生防护团队将安排检测（通常用口腔液采样盒）和接触者追踪。应让该儿童远离他人，包括在诊所内，并在出疹后4天内不上学。
:::
:::

::: history
1854年，斯诺（John Snow）绘制了伦敦苏活区宽街水泵周围霍乱死亡的地图，并说服当地委员会拆除了水泵把手；他对两家供水公司用户死亡情况的比较，为霍乱经水传播提供了更有力的证据。户籍总署的法尔（William Farr）建立了监测所依赖的人口动态统计系统。《1889年传染病（报告）法》在英格兰大部分地区规定了强制报告。20世纪初，在纽约当厨师的无症状携带者玛丽·马伦（Mary Mallon，“伤寒玛丽”）表明了携带者如何维持暴发，并提出了关于强制措施限度的长期问题。兰缪尔（Alexander Langmuir）于1951年在美国传染病中心创建了流行病情报服务（Epidemic Intelligence Service），并把现代监测定义为为了行动的信息。2003年的SARS暴发促成了2005年对《国际卫生条例》的修订，新冠大流行则促成了2024年的修正案和2025年的《世卫组织大流行协定》。
:::

## 后续内容

作为控制工具的疫苗接种见[[public-health/vaccination-programmes]]；国际卫生安全体系、“同一健康”和抗微生物药物耐药性见[[public-health/global-health]]；暴发的微生物学和抗微生物药物管理见[[infectious-diseases/stewardship-outbreaks]]；医院感染预防见[[microbiology/infection-control]]。暴发研究中使用的流行病学方法见[[epidemiology-ebm/observational-studies]]。

::: summary
- 传播沿着从储存宿主到易感宿主的链条进行；控制就是打断链条。关键时间段有潜伏期、潜隐期、传染期和序列间隔；罹患率和二代罹患率衡量传播程度。
- $R_e = \beta c D s$：控制措施降低每次接触的传播概率、接触次数、传染期长度或易感性，其效果相乘。
- **监测**是为了行动的信息：被动、主动、实验室和基因组、哨点、症状、环境以及基于事件的监测。
- 在英格兰，医生必须**在临床怀疑时**向卫生防护团队报告疑似法定报告疾病，紧急病例须电话紧急报告（《2010年卫生防护（报告）条例》）。
- 暴发调查：确认、组建小组、定义病例、发现并描述病例（流行曲线）、提出并检验假设（队列或病例对照研究、分型、环境调查）、控制、沟通和评价。在确定无疑之前就采取行动。
- **隔离**把感染者分开；**检疫**限制暴露者；**排除**使人们不进入特定场所。传播发生在症状出现之后时，接触者追踪效果最好。
- **《国际卫生条例（2005）》**要求各国建立核心能力并通报可能的**PHEIC**；2024年修正案自2025年9月生效，增加了**大流行紧急状态**级别；《世卫组织大流行协定》于2025年5月通过。
:::

## 习题

::: exercise 罹患率 {level=1 check="25"}
参加一次会议午餐的240人中，60人发生胃肠炎。罹患率是多少（以百分比表示）？
::: solution
$60/240 = 0.25$，即25%。
:::
:::

::: exercise 二代罹患率 {level=1 check="15"}
某感染的20个原发病例共有60名易感家庭接触者。在一个潜伏期内，其中9名接触者发病。计算二代罹患率（以百分比表示）。
::: solution
$9/60 = 0.15$，即15%。
:::
:::

::: exercise 隔离还是检疫？ {level=1}
把下列每一项归类为隔离、检疫或排除。(a) 一名从埃博拉暴发地区返回的旅行者曾照料过一名患者，但身体健康，被要求在家中停留21天并每天测两次体温。(b) 一名肺结核患者被收入负压病房。(c) 一名患诺如病毒感染的托儿所工作人员在最后一次呕吐后48小时内不上班。
::: solution
(a) 检疫（或在主动监测下的一种检疫形式）：当事人已暴露但健康。(b) 隔离：当事人已被感染并具有传染性。(c) 排除：病例在规定时期内不进入特定场所。
:::
:::

::: exercise 队列研究中的相对危险度 {level=2 check="round(100*(24/40)/(6/60))/100"}
在一次烧烤聚会中，吃了汉堡的40人中有24人发病，未吃的60人中有6人发病。计算相对危险度，保留2位小数。
::: solution
罹患率：$24/40 = 0.60$和$6/60 = 0.10$。RR$= 0.60/0.10 = 6.00$。
:::
:::

::: exercise 倍增时间 {level=2 check="round(10*4*log(2)/log(1.3))/10"}
某流行的$R_e = 1.3$，代际间隔为4天。计算倍增时间（天），保留1位小数。
::: solution
$T_d = 4 \times \ln 2/\ln 1.3 = 4 \times 0.693/0.262 = 10.6$天。
:::
:::

::: exercise 需要降低多少？ {level=2 check="60"}
某感染在完全易感人群中的$R_0 = 2.5$。在其他条件不变的情况下，接触必须减少百分之多少，才能使$R_e$恰好等于1？
::: solution
需要$2.5 \times (1 - r) = 1$，因此$1 - r = 0.4$，$r = 0.6$：接触必须减少60%。
:::
:::

::: exercise 解读流行曲线 {level=2}
描述你预期在以下情况下的流行曲线形状：(a) 一次聚会上由单一受污染甜点引起的*沙门菌*暴发；(b) 由受污染的公共供水引起、在被发现前持续两周的*隐孢子虫*暴发；(c) 一所学校中的麻疹暴发。对于(a)，你将如何估计暴露时间？
::: solution
(a) 点源：一个尖锐的单峰，病例分布在约一个潜伏期内（*沙门菌*大多为12～72小时）。从高峰向前推一个潜伏期中位数，或核对最早和最晚的病例是否符合最短和最长潜伏期，即可找到可能的暴露时间。(b) 持续同源：上升到一个平台，持续时间约与暴露时间相当，然后在供水恢复安全后的一个潜伏期内（*隐孢子虫*为数天）下降。(c) 增殖性：先出现第一个病例或聚集性病例，然后出现相隔约一个序列间隔（麻疹约为10～14天）的连续病例波次，不断扩大，直到控制措施或免疫使传播减缓。
:::
:::

::: exercise 分散的暴发 {level=3}
UKHSA的基因组监测在六周内于英格兰不同地区发现了35例基因组几乎相同的*沙门菌*病例。病例年龄从2岁到85岁不等。描述如何识别和控制传染源。
::: solution
**确认和组织。** 基因组联系确定了一个可能的暴发；由UKHSA、地方卫生防护团队、食品标准局和环境卫生部门组成事件处置小组。

**病例定义。** 在时间窗内发病、经实验室确认的暴发株*沙门菌*感染（在设定的SNP差异数之内）；可增加很可能病例。

**描述。** 绘制病例地图和流行曲线（持续时间长的曲线提示持续来源，如广泛分销的食品），并分析年龄和性别。

**假设。** 用详细的饮食史问卷（常为“拖网式”问卷）访谈病例，寻找共同的食物、商店或餐馆。在征得同意的情况下，超市会员卡数据可以识别具体产品。

**检验。** 比较病例与对照（例如患其他疾病的人，或来自市场调查样本库的对照）的病例对照研究，可以得出候选食物的比值比。检测食品样本并沿供应商追溯；对从食品或生产场所分离的菌株进行测序可以确认关联。如果产品是进口的，国际数据库可能显示其他国家也有匹配的病例。

**控制。** 一旦证据充分，立即下架并召回产品；发布公众建议；如果产品涉及贸易，通过国际网络通报其他国家；与生产商合作纠正问题。持续监测以确认不再出现病例。
:::
:::

::: exercise 接触者追踪值得吗？ {level=3}
对于以下哪种感染，你预期接触者追踪最有效？为什么？(a) 结核病，(b) 流感，(c) 一种新的感染，潜伏期10天，仅在症状出现后传播，且大多数病例病情严重。
::: solution
(c) 最有利。仅在症状出现后传播意味着病例一发病就可以隔离，而较长的潜伏期使人们有时间在接触者具有传染性之前找到他们并进行检疫。病情严重意味着病例能被识别。这些特点（与2003年的SARS类似）解释了为什么那次暴发在没有疫苗的情况下得到了控制。

(a) 结核病也适合接触者追踪，因为传播需要长时间接触，潜伏期长，而且潜伏感染的接触者可以通过检测发现并接受治疗以预防发病。这项工作耗费资源但很有效，是标准做法。

(b) 流感最不适合：其潜伏期约为2天，传播在症状出现前后就开始了，而且许多感染是轻症或无症状的。等追踪到接触者时，他们可能已经具有传染性。控制主要依靠疫苗接种、为高危者使用抗病毒药物以及一般性措施。
:::
:::
