免疫规划是仅次于排污最具成本效果的公共卫生干预，也是医学最容易被政治摧毁的成就：它把一个人群的流行病学压缩进一张日历，依赖每一代人信任那支针，并用两种其他服务不必面对的货币被衡量——被避免的死亡（看不见）与不良事件（看得见）。**本章覆盖规划的免疫学（记忆的生物学与群体效应的算术与日程的逻辑）、交付（记录系统与默认预约与补种与冷链与疫苗的可及与融资）、安全（不良事件的监测与因果的判断与沟通的困境）、犹豫的科学（把怀疑当作有结构的、情境依赖的、可用信任来回应的问题）、以及终局的策略（消除与根除与疫情期的教训）。**

## 免疫学

::: definition 免疫学、群体效应与日程的逻辑 {#def-immunology}
**疫苗的日程是应用免疫学：基础免疫建立记忆，其更快且更强的二次应答解释了间隔与加强剂的存在；整张日历在婴儿免疫系统的成熟、母体抗体的干扰、暴露的流行病学、以及保护能维持多久之间谈判。流感嗜血杆菌与肺炎链球菌与脑膜炎奈瑟菌的多糖荚膜不引起T细胞依赖的记忆，因此两岁以下的婴儿对纯多糖应答差——把多糖结合到蛋白载体上的技术是本领域最重要的单项发明，它使这些病原体变得可预防；而结合技术之外的路径（类毒素与亚单位与病毒样颗粒与载体蛋白平台与信使核糖核酸的设计）则展示了平台的可替换性——[[immunology/adaptive-responses]]。群体保护是一个覆盖率的地图：临界免疫比例取决于基本再生数（在麻疹的十二到十八这个范围里约需93%至95%的两剂覆盖），并且要求覆盖在空间上均匀——一个国家的平均95%若由三个接种率60%的聚集区拉平，其结果就是暴发；因此“谁没被接种”必须被逐个社区与逐个学前机构地找到，而不是按比例推断——[[public-health/communicable-disease-control]]。疫苗影响传播的程度决定群体效应：阻断感染的疫苗（麻疹）能保护不能接种者，而主要预防疾病而非感染的疫苗对传播的抑制较弱——这是群体效应与“间接保护”的算术所在，也是为何老年人接种（带状疱疹与肺炎链球菌与流感）在直接保护之外仍有可观的收益——[[respiratory/respiratory-infections]]、[[immunology/vaccines-immunotherapy]]。**
:::

## 规划

::: definition 交付、安全监测与犹豫 {#def-delivery}
**交付决定科学能兑现多少。架构各异（在全科病历与初级照护中的婴儿规划、负责青少年日程的学校接种队、在疫情期间被大规模合法化的药房交付、以及低收入国家由世界卫生组织与联合国儿童基金会与疫苗联盟支持的采购与冷链与“最后一公里”的机制），但设计的规则是普遍的：在自然的接触点设默认预约（出生时的首剂与出院前的、以及产后的、以及把每一次急诊与住院与门诊当作补种的机会）、双轨的记录系统（免疫的信息系统与病历互通，且能生成“谁漏种”的名单）、以及召回与主动搜寻（对未响应者用多通道与家庭与社区渠道、并把“拒种”与“未联系上”与“漏录”分开记录）——[[clinical-skills/records-handover]]、[[paediatrics/immunisation]]。安全监测是规划的免疫系统：被动报告（不良事件自发的通报，用于生成假设而不能算发生率）、主动监测（哨点的队列与住院的检索）、以及观察性与对照的序列设计（用风险间隔比较接种前后与用队列比对预期率）；信号的处理有既定的序列（时间关联与生物学合理性与剂量反应与去激发与再激发与病例的评审与独立委员会的复核）；而最关键的沟通原则是把绝对风险与背景率一起给出（每百万剂多少例），并说清我们不知道什么——[[clinical-skills/patient-safety]]、[[epidemiology-ebm/observational-studies]]。犹豫不是无知：它有结构——自满（对疾病风险的感知下降，恰恰因为疫苗成功了）、 Convenience（时间与交通与费用与请假）、以及信任（对系统与产业的信任、以及历史上被背叛的记忆），三者的相对权重因社区与疫苗与时间而异；干预的措施是“默认推定”（“我们今天要接种两剂”而非“你要不要”）、集成的机会（不要单独为此跑一趟）、面对面的信任者（医护人员的推荐是单一最强因素，与同为家长的社区工作者）、以及对具体担忧的回应（预先备好关于自闭症与汞与疫苗数量与硫柳汞与流产与生育力的问题并诚实回答：被反复检验并推翻的假说要说它被推翻了，而不是被忽略）——[[clinical-skills/communication]]、[[public-health/determinants-inequalities]]。**
:::

## 终局

::: definition 消除、根除与大流行的教训 {#def-endgame}
**词汇即策略：控制意味着传播与疾病的减少；消除意味着某一区域内无本地传播（麻疹与风疹与脊髓灰质炎的验证规划，永远受制于输入与覆盖的聚集）；根除意味着该物种已不存在（天花，以及脊髓灰质炎终局的最后几道山谷）；而根除的技术是在迫切需要下发明的：天花的“监测加环形接种”（发现病例、隔离、并接种其接触者与接触者的接触者，从而以少量疫苗形成免疫的包围圈）在大流行策略的失败之后被采用，成为本领域最重要的方法论贡献，并在此后被用于埃博拉——[[public-health/communicable-disease-control]]。终局的难题有其固定的清单：动物宿主（使根除不可能，如破伤风与黄热与多数虫媒病）、口服疫苗衍生病毒的循环（在覆盖率不足处，减毒的口服脊髓灰质炎疫苗病毒可以演化并传播——这是疫苗本身制造的罕见但真实的风险，并解释了从口服转向灭活疫苗的全球策略）、冲突与流动的人群与不敢前去的社区（最后一公里是政治问题不是物流问题）、以及资金曲线（一旦疾病从公众视野消失，国内投入就下降，而维持消除比达到消除更费组织）——[[paediatrics/immunisation]]、[[public-health/global-health]]。大流行的教训可以浓缩为五条：速度与公平不是权衡（因为病毒在覆盖率不均处演化，而“民族主义”最终延长所有人的疫情）；平台的准备（信使核糖核酸与病毒样颗粒与腺病毒的平台与既有的临床试验网络）决定了第一支疫苗多快可用；透明是有效性（数据与安全信号的处理必须外行可读，否则信任会在几周之内崩塌）；产能与技术许可是政策问题不是市场问题（把生产视为基础设施）；以及最后一段是最难的（当死亡不再下降而疲劳上升，措施便失去支持——这需要在设计时就写入分阶段的退出与地方决定权）——[[respiratory/respiratory-infections]]、[[medical-ethics-law/justice-resources]]。**
:::

::: example 未接种的聚集 {#ex-cluster}
一个城市的国家麻疹覆盖率为94%，但一所学校的一年级只有62%：多数家庭以哲学理由拒种；本周两名无旅行史的儿童出疹并被确认；卫生部门问你作为临床医师能做什么。
::: solution
**聚集如何被拆开（[[#def-immunology]]、[[#def-delivery]]、[[#def-endgame]]）：先做病例与接触者的工作：每一例都要调查（传染性期间的行踪与接触名单的逐个联系、易感接触者的暴露后疫苗（在两日内）或免疫球蛋白（对婴儿与孕妇与免疫抑制者在六日内）、以及被排除于学校的时间表与其依据——学校依法可要求暴露的未接种儿童暂时停课，这不是惩罚而是切断代际传播的唯一可用杠杆，但必须提前向家长解释规则而不是事发后突然执行）——[[paediatrics/acute-childhood-illness]]、[[public-health/communicable-disease-control]]。第二是覆盖：一场校园与社区的两剂核查与补种（把疫苗带到他们已在的地方：学校的当天与傍晚与周末与不设证明门槛与纸质凭证），并把漏种的名单与“零剂次儿童”作为每日指标；同时处理记录的假阳性（不少“未接种”其实是漏录——先查病历可以省下一半的外展）——[[clinical-skills/records-handover]]。第三是话语：不要羞辱（羞辱把技术性的怀疑变成身份的承诺，并把对话关闭）；先找可信的信使（本社区的儿科与家庭医师与已接种的家长与学校的管理者与宗教领袖）；并把风险换算成可比的具体量（麻疹在健康儿童中的并发症率与肺炎与脑炎与免疫失忆，与疫苗的重度不良事件率；以及对“群体免疫”的误解的正确说明：它不是把风险转给未接种者，而是麻疹根本没有“人人都有”的自然安全状态）——[[public-health/determinants-inequalities]]、[[clinical-skills/communication]]。第四是制度：把学校的入学审核与年度覆盖率报告变成有资源的流程（而非一次表格），对多个聚集区做联合演练（因为一个城市里若同时有三处低覆盖，一次输入就会变三次暴发）；并在控制之后留下机制（每校一名联络人与一个固定的补种窗口），否则覆盖会在下一学年滑回去——[[public-health/vaccination-programmes]]。**
:::

::: example 那个是真的安全信号 {#ex-signal}
一种新引入的疫苗在接种一百二十万剂后，监测发现每十万名年轻男性中有数例心肌炎，多在第二剂后一至四日；社交媒体已在传播；专家委员会本周开会。
::: solution
**信号变决策（[[#def-delivery]]、[[#def-immunology]]、[[clinical-skills/patient-safety]]）：先确认信号为真：病例定义与主动检索与背景率的比较与年龄与性别与剂次时间的模式与临床与实验室的一致性（肌钙蛋白与心电与心脏磁共振的证据与轻症的程度与康复的时间），并排除混杂（同一季流行的病毒性心肌炎是最大的混淆，所以需要同季的对照与病毒的检测分层）；这一步决定了沟通的可信度——承认一个真实但罕见的风险，永远比辩护更有说服力——[[nervous-system/neuroinflammation]]、[[clinical-skills/laboratory-tests]]。然后量化两侧的绝对风险：每十万剂的心肌炎对每十万名未接种者因该病住院与重症与死亡的风险（以及长期后遗症），并按年龄与性别分别给（青少年男性的疫苗相关心肌炎风险在原始流行下可能高于药物风险，而老年人则相反——这正是“按年龄而非按全民”的策略理由）——[[cardiovascular/valve-congenital-disease]]。可选的行动按伤害最小排序：继续并加强监测、缩短间隔或改为单剂（对低风险群体）、限制某些群体的第二剂、提供心肌炎的预警教育与休息的建议（避免剧烈运动数周）、以及明确的诊断与救济路径（对确诊者的支持与补偿会显著影响信任与报告的质量）——[[pharmacology/adverse-reactions]]、[[medical-ethics-law/justice-resources]]。沟通的四条：一，说“我们发现了这个、它罕见、它可以恢复、这是绝对数字、这是我们在做的事、下一次更新在周四”；二，不要说“安全”这个不含信息的词；三，把不确定性明确（我们尚不知道长期结果与恢复的中位时间）；四，公开决策的依据与异议（委员会的少数意见写进文件会提高而非降低公信）——[[public-health/communicable-disease-control]]、[[clinical-skills/communication]]。事后要修的：把接种后的随访与“心脏症状即刻就诊”的卡片纳入常规，把不良事件报告的质量与响应率作为服务指标，并预置对下一信号的机制（数据管道与委员会的会议节奏与预先约定的口径），因为在下一次大流行中真正的问题不是没有信号，而是处理信号的速度——[[emergency-critical-care/major-incidents]]。**

## 通向何处

免疫的生物学见[[immunology/adaptive-responses]]与[[immunology/vaccines-immunotherapy]]；具体疾病的规划见[[infectious-diseases/tuberculosis]]与[[infectious-diseases/hiv]]与[[respiratory/respiratory-infections]]；儿童的日程与操作见[[paediatrics/immunisation]]；覆盖率的公平见[[public-health/determinants-inequalities]]；监测与暴发的处置见[[public-health/communicable-disease-control]]；全球融资与毕业见[[public-health/global-health]]。

::: history
**免疫的历史开始于疫苗之前：几个世纪的中国与奥斯曼的皮肤接种、以及蒙塔古夫人1721年把“人痘”引入英国与新英格兰的实践（后者由被奴役的奥奈西穆斯向科顿·马瑟说明）；詹纳1796年从牛痘到疫苗的这一步与其后“以痘苗取代人痘”的运动（以及巴斯德以名字致敬詹纳的谦让）；十九世纪的冷链之前是疫苗的现场生产与动物的淋巴与“疫苗事故”（1901年的摩尔班与1930年的吕贝克事件——后者以数名儿童之死换来了国家检定与生产的法规）。二十世纪是规划的时代：巴氏的狂犬病与白喉抗毒素与类毒素、1930年代的百日咳与1950年代的索尔克与萨宾的脊髓灰质炎（其“一角钱行军”的群众融资与其后的丙肝污染丑闻、以及许可与生产的瓶颈）、1960年代的风疹与麻疹与腮腺炎、以及“扩大免疫规划”（1974年）把疫苗带进低收入国家；1967至1980年的天花根除与其“监测加环形接种”的转向至今仍是所有终局策略的原型；1980年代的艾滋病把“新疫苗极难”的教训写进现实，而以结合技术与反向疫苗学设计的肺炎链球菌与脑膜炎球菌与流感嗜血杆菌疫苗与人类乳头状病毒病毒样颗粒疫苗（其2006年后的引入与融资之争）则是工程的一翼；2020年代的核酸平台与大流行的剂量外交与“毕业”的争议把本领域最终的问题摆到桌面：技术不是瓶颈，公平与信任与融资才是——[[public-health/global-health]]、[[immunology/vaccines-immunotherapy]]。**
:::

::: summary
- 日程是应用免疫学：间隔与加强由记忆的生物学与母体抗体与成熟度与暴露的时间共同决定；结合技术让两岁以下的婴儿对多糖荚膜产生记忆。
- 群体保护是覆盖率的地图：临界覆盖由基本再生数决定，而失败几乎总发生在空间聚集的洼地，不是发生在国家的平均值里。
- 交付的规则是普遍的：默认的预约与自然的接触点与补种与召回与可查询的记录；每一次单独的往返都是一次失败的机会。
- 安全监测生成假设，对照研究检验它们；沟通的成功在于给出绝对的数字与背景率，并承认未知。
- 犹豫有结构（自满、便利、信任），因此对策也必须有三副面孔；羞辱会把技术问题变成身份问题。
- 消除是需要维持的状态：终局的最后一段由输入、覆盖的聚集、资金曲线与信任共同决定，而不是由技术决定。
:::

一名四岁儿童从国外迁来，只有一张手写的、部分无法辨认的接种卡：疑似两剂某疫苗与一剂“注射”；她未接种过麻腮风与水痘与肺炎链球菌的加强。请写出补种的计划与依据。
::: solution
**补种的原则（[[#def-delivery]]、[[#def-immunology]]、[[paediatrics/immunisation]]）：规则是“有疑即视为未种，但先找客观证据”：一是把可读的记录与本地的病历与学校的档案与前次的实验室结果查一遍（把已种的重复审录既浪费也削弱信任）；二是当记录确实无法确认时，按未种处理是安全且标准的（额外的剂次对这些疫苗是可接受的代价，而漏种的风险不可接受），除非某疫苗的重复剂次有特定的注意事项；三是“血清学的证据”可用于个别情形（如已免疫的证明）但不应成为常规，因为它增加一次抽血与一次往返并把重点从保护转向文件——[[clinical-skills/laboratory-tests]]。计划：按最小间隔重建一张日程（麻腮风两剂、间隔至少四周；水痘两剂；肺炎链球菌的加强按年龄与既往剂次决定是否需要；并按暴露的风险补种其他项目与外伤相关的破伤风），并把所有可同日接种的在同一次完成（不同部位与不限制同时接种的种类，因为每一次单独预约都是一次失败的机会）；四是把这张卡变成可持续的系统（免疫信息系统的记录、书面的凭证给家长、以及设置下一次预约与提醒与“若搬迁则转档”的说明）；五是抓住“每次接触”的机会：把她的急诊与牙科与住院的就诊都视为补种的窗口，并把筛查“谁漏种”作为该诊所的名单管理而非个人记忆——[[clinical-skills/records-handover]]。**

::: exercise 向学校进言 {level=2}
一所以住宿与体育闻名的中学发现约两成家庭未接种脑膜炎球菌与人类乳头状病毒疫苗；校方担心“强制”会引发退学，卫生部门担心开学后的聚集。请给出方案。
::: solution
**学校的方案（[[#def-delivery]]、[[#def-immunology]]、[[public-health/determinants-inequalities]]）：先诊断为什么低：这两类疫苗在青少年中的最大障碍不是反对而是便利的失败（青少年的日程与家长的工作与疫苗的年龄窗口短与校内 服务的可见度低与转介的断裂）；先做一次匿名快速的家长调查（把“忘记/没时间/不想要/不信任”分开——它们需要完全不同的对策）。对策的顺序：一，把服务送进校园并在同一周内提供两类疫苗（一个团队、一个同意流程、多次机会——错过当天的人还有两次），并允许学生的自我同意（在适龄且具备能力的情形下，依本地的法律与指南）与不设费用与文件门槛；二，把“默认”变成文书的写法（“请告诉我们他不接种的原因”优于“请回答他是否接种”——同一个表格的措辞可带来两位数的差别）；三，用同伴与家长的声音（高年级学生的宣传与家长委员会与体育队与宿舍长——这比卫生部门的海报有效）；四，用温和的激励而非惩罚（把接种与体育营与住宿的资格绑定会制造冲突与退学，且把健康变成一种条件，而把奖励与便利与“我们关心你们”绑定则不然）。沟通的底线：不隐瞒风险与不确定性；把人类乳头状病毒疫苗讲成癌症预防（这是它最容易被理解的语言，并且淡化性的暗示），并预先回答关于生育与安全性的传言（以诚实的“我们已反复检验并推翻”回应被推翻的假说）。监测：按年级与宿舍与家庭的覆盖与“拒种的原因”分布与接种后的反应；并把学校的覆盖纳入本地的消除监测（因为脑膜炎球菌的聚集恰恰在这些宿舍里发生）——[[public-health/determinants-inequalities]]、[[clinical-skills/communication]]。**

::: exercise 读试验并向部长建议 {level=2}
一种新的疫苗试验：对重症的保护82%（置信区间55%至93%）；对感染的保护32%且随时间下降；未报告对传播的影响；试验入组者平均48岁且极少合并症。部长想明天宣布全民加强。
::: solution
**读试验并泼冷水（[[#def-immunology]]、[[#def-delivery]]、[[epidemiology-ebm/critical-appraisal]]）：可以确认的：对重症的高保护是有意义的（区间宽是因为事件数少而非效应可疑），并且是决策最关心的终点。需要说清的三点：一，对感染与传播的效果未知或较弱且随时间衰减，所以“打了就不再传染”这一信息不可以讲（这决定了它不能替代其他措施，也影响对医护与住院患者接触者的建议）；二，人群的外推（试验人群偏年轻且健康，而收益最大的老年人、免疫抑制者、以及合并症者的效应量与持续时间还没有被充分估计——这是需要“桥接数据”的地方，而不是假设相同）；三，终点与时间（“重症”的定义与随访的长度与变异株的时期，都会改变结论对下一个季节的适用性）——[[immunology/vaccines-immunotherapy]]。给部长的建议不是“不”，而是一个更好的“是”：先做分层与可执行的第二步——（一）优先给风险最高与医院与养老与免疫抑制的人群并同步收集有效性数据（包括测试阴性设计与住院的检索）；（二）公开说清目的是“减少重症与保护系统”而非“阻断传播”，并给出与口罩与通风与假期措施的关系（否则公众会把疫苗当作其他措施的替代）；（三）为加强剂的间隔与“是否重复”预设数据驱动的复审节点（而不是每年默认一轮），并把剂量外交与产能与分配的规则与“为什么是他们先”的说明写进同一份声明；（四）建立安全与信任的看板：绝对风险与背景率的比较、信号的处理时限、以及每次更新的兑现——因为在大流行的后期，决策的可见过程比决策本身更能维持接种率——[[public-health/communicable-disease-control]]、[[clinical-skills/communication]]。**

::: exercise 写大流行的尸检 {level=3}
疫情多年后你被要求评估本国的免疫部署。请写出你的评估框架、五条最可能的结论、以及你会避免的一种叙述。
::: solution
**部署的评估（[[#def-delivery]]、[[#def-endgame]]、[[public-health/health-systems-economics]]）：框架按因果分五层：一，政策与优先顺序（谁先、依据什么、如何调整、以及优先组别的实际触达率与“高优先但难触达”群体的漏种）；二，供给与产能（剂次的可得与分配与废弃与冷链与到期与出口的双向承诺）；三，交付系统（默认的路径与把疫苗带到人身边与药房与社区与上门与流动诊所、以及“每次接触都补种”的执行）；四，信任与不平等（犹豫的原因的分布与语言与文化的可及与按剥夺与族裔与年龄与残障的覆盖差距，以及是否用强制与证明作为杠杆及其代价）；以及五，安全与适应（监测与响应与沟通与对变异株与间隔与剂次的决策过程）——[[public-health/determinants-inequalities]]。五条最可能的结论：疫苗极大地减少了死亡与住院而这段功劳被少算（因为在其他措施叠加下不易量化）；高收入国家的“第一剂优先”策略在总体效应上是成功的，但公众辩论把它当作道德丑闻；分配的不平等（剂次 被囤积而低收入国家数月得不到）是本世纪最大的卫生伦理失败，并且延长了自己的疫情；犹豫通常针对的是信任与不便，而不是错误信息本身；以及最强的干预是“默认与可及与熟人”，而不是宣传。要避免的叙述：把结果归为民族性格（“我们的文化使我们做得好”）或用一次危机给整个系统打分（短期的高效可能来自牺牲长期能力，例如把社区护士都调去接种台，导致常规儿童免疫与筛查的中断）。所以报告的最后一节应写“平时就需要的能力”与“下一次的具体时间表”，并列出因为这次部署而被关闭的服务与其后果——[[public-health/global-health]]、[[public-health/screening]]。**

::: example 冷链的断裂 {#ex-coldchain}
一夜之间，区级疫苗库的温度记录仪显示连续七小时高于8度；受影响的是两千剂需要冷藏的疫苗与一千剂可冻结的疫苗；后者旁边放着一瓶“震摇对照”；第二天有一场大型的接种活动。
::: solution
**冷链事件的处理（[[#def-delivery]]、[[#def-immunology]]、[[clinical-skills/patient-safety]]）：先分诊而非恐慌：温度敏感性的判断取决于产品、累积的热暴露与时间，而不是“断了一次电”；标准动作是（一）立即把这些疫苗标为“暂停使用”但先不丢弃（销毁的代价常常高于证明可用），（二）读取记录仪的完整曲线与最大值与超温的小时数并保留电池与标签与批次与效期，（三）向生产厂家与国家级部门查询该产品的热稳定性数据（许多疫苗有以平均动力学温度表达的暴露预算，部分制剂有短期室温的容忍度），（四）对可冻结的疫苗做震摇对照与目视与物理检查（吸附的疫苗一旦冻结会留下无法通过外观完全排除的絮集，因此对含吸附剂的制剂，“冻过”通常意味着弃用），（五）记录事件并做根本原因的分析与纠正（设备的故障与报警的路径与备用发电与库房的位置与夏季的策略与运输环节的断点）——[[microbiology/infection-control]]。第二天的活动怎么办：把受影响的批次移出、用未受影响的库存顶上、并事先准备好“如果不够”的说明与改期规则（活动的取消也是一种健康损害，因为被延误的第一剂会流失）；若没有替代库存，则推迟比给出效价不确定的疫苗更可辩护——除非已有稳定性数据支持其使用。信任的一层：对已接种者通常不需要复种（多数热暴露导致的是免疫原性的降低而非危害），所以要给临床医师一个明确的书面口径，避免家长被“你可能白打了”这种说法推向反疫苗；同时公开说明“发生了什么事、我们如何判定、结果是什么”——透明是维持冷链之外的第二条链——[[clinical-skills/communication]]、[[public-health/global-health]]。系统的要求：把温度记录仪与报警与断电的应急写入标准操作规程并纳入演练与督导（多数断裂是在“没人看曲线”的夜间发生）、把库存与批次与效期的可追溯数字化（使事件的影响面在几分钟内可被界定）、以及在预算里为冷链的冗余付钱（备用设备与车辆与发电，这是“看不见的支出”最需要在和平时期被保护的部分）——[[public-health/health-systems-economics]]。**

::: example 祖父的带状疱疹之问 {#ex-shingles}
一名78岁、既往有过一次带状疱疹、服用华法林与胺碘酮并有轻度认知损害的老人，问子女“我该不该去打带状疱疹的疫苗”；他在两年内做了两次髋部的手术；他的主要顾虑是“打针会不会诱发那次疼到睡不着的病”。
::: solution
**成人的接种决策（[[#def-immunology]]、[[#def-delivery]]、[[geriatrics-palliative/ageing-frailty]]）：先讲收益：老年人带状疱疹与其后遗神经痛的风险与痛苦都高，而疫苗（重组亚单位疫苗两剂）对带状疱疹与神经痛的保护明确、并在高龄处仍保持可观的绝对收益（免疫衰老使疾病负担加重，也正是需要接种的理由）；曾患过带状疱疹仍可接种，因为复发常见，且疫苗是预防而非“治疗那次”——这一点对他“是否会诱发”的顾虑要正面回答：疫苗不含活病毒、不会引发带状疱疹（接种后的局部与全身反应与短暂的肌痛常见且自限）；把时间线给他：两剂间隔二至六个月与常见反应的处理与何时需就医——[[immunology/vaccines-immunotherapy]]、[[pharmacology/adverse-reactions]]。共病的权衡要具体：抗凝（华法林）不是禁忌，用细针与按压而不揉搓并避开神经走行、并考虑在国际标准化比值在治疗范围时接种（避免肌肉注射的选择与延迟，因为延迟本身是有代价的，而血栓风险大于出血）；胺碘酮与光敏与心脏的情况不改变结论；轻度认知损害不是禁忌但意味着她需要一次“固定的地方、熟悉的人、书面的提醒、以及由家人陪同”的安排——而把两次剂次绑定到同一次预约与同一个地方是最有效的措施（成人的第二剂流失率远高于儿童）——[[cardiovascular/arrhythmias]]、[[clinical-skills/communication]]。更宽的一层：这次问诊是最好的时机把老年人应该接种的其他项目一次补齐（流感每年与肺炎链球菌与破伤风的加强与呼吸道合胞病毒在高风险者），并按共病的目标排序（他的髋部手术与跌倒与肺部并发症意味着流感与肺炎的接种有直接的实际价值）；同时做预先照护计划的邻接对话（疫苗是少数既便宜又符合“独立生活”目标的干预）；以及把决策交回给他（“如果你更怕那一次疼痛，我们打；如果你更怕打针的反应，我们可以谈清楚概率再定”）——[[geriatrics-palliative/palliative-care]]、[[medical-ethics-law/consent-capacity]]。**

::: exercise 处理拒绝 {level=1}
一位母亲在婴儿六周的预约时明确拒绝当日的疫苗，但愿意来下次门诊；她的理由是在网上看到的“疫苗太多太早”。写出你的应对与记录。
::: solution
**拒绝的应对（[[#def-delivery]]、[[#def-immunology]]、[[clinical-skills/communication]]）：三个目标同时达成：保留关系、给出真实的信息、并保留下一次的机会（她被记住为“合作但暂时拒绝”，而不是“反疫苗家庭”）。方法：先征得许可并倾听（“我可以问问你读到的是什么让你担心吗？”），把她的问题具体化（“太多”通常意味着两件事：同时多种抗原是否超载免疫系统、以及铝佐剂与硫柳汞的安全——两者都有可直接回答的诚实答案：婴儿每天接触的抗原远多于疫苗，且现代的抗原数量比数十年前更少而接种种类更多；铝的剂量低于母乳与配方与食物带来的暴露，而硫柳汞在儿童疫苗中已被移除且未被证实有害）；再给出她的孩子的具体风险（未接种的两月龄婴儿在百日咳与侵袭性肺炎链球菌疾病中的绝对风险与住院率与本国最近一年的病例数）；并把“分开打”的妥协诚实地谈：它不是无害的（它延长孩子处于无保护状态的时间、增加往返与注射次数、并常常因故中断），但比完全拒绝好；若能接受，可以把一部分同日、一部分延后，并写下明确的补种日期与不再“再加一次”的安排——不要为了今天的同意而牺牲长期保护。记录：把她的问题与你的回答与给出的材料与商定的下一步写进病历（这是未来审计所需，也是对她的尊重——她可以拿回自己那份），并预约一个具体的日期与提醒（无预约的“下次再来”多数会变成失访）；同时在免疫信息系统中把理由分类（便于服务的改进与外展），并把这名婴儿列入召回的名单——[[clinical-skills/records-handover]]、[[public-health/determinants-inequalities]]。**

::: exercise 设计青少年的补种 {level=2}
某地人类乳头状病毒疫苗在男孩中的覆盖为54%、女孩为71%（学校项目已存在）。请设计一个以提高覆盖为目标的改进，包含对家长与学校与系统的三条措施、以及你如何评估。
::: solution
**青少年的补种（[[#def-delivery]]、[[#def-immunology]]、[[public-health/screening]]）：三条针对不同的层。对家长：把信息改为“癌症预防”的语言并给出时间（“这是为了他成年时的癌症风险，越早两剂效果越好”），并回答关于性的顾虑（接种不增加性行为的频率，这是被反复研究的事实，应当明说而不是回避）；用儿科与家庭医师的主动推荐作为最强的杠杆（把“今天推荐”变成每次青少年就诊的默认动作，并在系统中设提醒）。对学校：把接种放在学年的开头并给多次机会（缺席者的第二机会要写进流程而不是靠临时补）、同意表用“默认参加、请退回表示拒绝”的设计（同一个表格的默认效应可带来两位数的提升）、并把疫苗与校内的其他健康服务合并（同一次流感与脑膜炎球菌的接种与视力的筛查，这样它不是“那个疫苗的日子”）。对系统：把覆盖的测量下沉到每一所学校与每一个年级（并公开），设置“谁没打”的名单与外展的负责人与时间；处理记录的失败（青少年的既往剂次常在他处，跨系统的对账能把“未接种”减少一大截）；以及给接种团队的时间与交通（放学后与周末与社区点，因为青少年在白天的课堂缺席有教学成本）——[[clinical-skills/records-handover]]、[[medical-ethics-law/consent-capacity]]。评估：以学校为单位的覆盖率（分性别）与中断率与错时率与“拒种原因”的分布为指标；用逐步推开的整群设计与同期未推开的对照；同时监测公平（最剥夺地区的学校是否赶上——因为差距常常在扩大的不是平均，而是尾部），并把结果在一年内回报给学校与家长——[[public-health/determinants-inequalities]]。**

::: exercise 审计一项疫苗决策 {level=2}
你的地区宣布为所有健康成人自费提供某呼吸道疫苗的年度接种。请做一份决策的审计。
::: solution
**决策的审计（[[#def-immunology]]、[[#def-delivery]]、[[public-health/health-systems-economics]]）：审计六个问题：一，目的（预防谁的重症、保护系统、还是维持经济活动？目的决定人群与终点，也决定“何时停止”）。二，证据（对目标人群的重症与感染与传播的效果与持续时间与对变异株的证据与真实世界的数据；并把试验的不确定性带过来而不是抹平）。三，替代与叠加（其他措施与药物与其他疫苗与 ventilator 的能力在别处是否有更多收益，尤其是当同一支人手被调走时——机会成本包括交付的人力）。四，成本效果（每质量调整生命年的成本与预算影响以及“健康成人”这一群体的绝对风险很低带来的高阈值；以及自费的公平问题：若价格排斥最需要的群体，则它扩大了不平等）。五，运营（冷链与两次剂次的间隔执行与不良事件的应对与“打了还被感染”的沟通，以及最重要的：第二剂与下一年的流失——成人接种的续完率长期不佳）。六，伦理与程序（优先顺序是否已用尽；“为所有人”听起来公平，但在供给不足时若先做低风险的年轻人，就会把死亡转给老年人，这是可预见的伤害；所以任何“普遍提供”之前先完成高风险人群的覆盖，并要求把这一条写进声明）。评估的方法：以覆盖的分层报告与住院与死亡的观察性评估（测试阴性设计与中断时间序列）以及信任与犹豫的指标；并预先约定复审的日期与退出的条件——一个没有退出条款的疫苗政策，会占用下一次疫情所需的注意力与人力——[[public-health/health-systems-economics]]、[[clinical-skills/patient-safety]]、[[medical-ethics-law/justice-resources]]。**

::: exercise 为暴发做模型 {level=3}
一座三百万人口的城市发生输入性麻疹：两日内确认九例（两例在急诊等待区停留数小时）。请给出你的响应模型：假设、干预、以及需要监测的指标与何时可宣布结束。
::: solution
**响应的模型（[[#def-endgame]]、[[#def-immunology]]、[[public-health/communicable-disease-control]]）：假设要写明：基本再生数12至18与代际间隔约十一至十四天与传染期（出疹前后四日）与无症状期不传播（这使病例发现有效）与免疫球蛋白与疫苗的暴露后效力（两日内疫苗、六日内免疫球蛋白对特定人群）。暴露的界定按场所与时间分层（同一候诊室与同一家住与同班与同一交通工具，并按通风与停留时长决定风险级别），并立即生成“需要行动的易感者名单”（这不是全部人口而是易感者与高风险者：婴儿与孕妇与免疫抑制者与医疗与教育机构）。干预的排序：一，病例与接触者（每一例的调查与隔离与接触者的逐人联系与随访到末次暴露后二十一日）；二，暴露后的接种与免疫球蛋白（并预设谁需要免球以避免临时讨论）；三，覆盖的动员（对覆盖低于阈值的所有学校与学前机构与医疗机构与社区，在两日内开展两剂核查与补种，并派出移动团队；把“没有免疫证据”默认按易感处理）；四，医院的防护（急诊与儿科与产科的筛查与口罩与空气传播的隔离与把候诊的等待时间降下来，因为医疗场所往往是把社区暴发放大成医院暴发的地方）；以及五，沟通（公众需要知道的是“哪里 exposures 了、我是否要动、去哪打、以及这不是秘密”）。监测的指标：每日新发（按传播代际看而不是按日历）、易感者的剩余（“谁还没被找到”是决定暴发长短的核心变量）、暴露者的随访完成率、补种的剂次数与其空间分布、以及医院获得性病例的零。结束的定义要按时间而不是按运气：自末例的传染性期起经过两个最长潜伏期（约二十一日两次）而无新发本地病例，同时保留对输入的警惕与恢复率的复审；并把这次事件变成常态的机制（每所学校的年度覆盖审查与对“零剂次儿童”的持续搜寻与对医疗场所的暴露筛查演练）——否则下一次的响应又会从零开始——[[paediatrics/immunisation]]、[[public-health/determinants-inequalities]]。**
