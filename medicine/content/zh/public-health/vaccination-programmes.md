2026年1月，世界卫生组织宣布英国失去了麻疹消除状态。这一决定基于2024年的数据：那一年英格兰报告了2,911例实验室确诊的麻疹病例，是2012年以来的最高年度数字。有儿童因此死亡。麻疹疫苗自1968年起就列入英国的免疫规划，MMR自1988年起列入，它是有史以来最有效的疫苗之一。问题不在疫苗，而在于接种两剂的儿童太少，而且未接种者集中在特定的社区和地区。

疫苗保护接种者本人。而疫苗接种*项目*保护的是人群，这就需要作出一系列决定：提供哪些疫苗、给谁、在什么年龄、以什么方式；接种足够多的人以阻断传播；建立监测覆盖率、疾病和安全性的系统；以及赢得公众的信任。本章讨论疫苗接种的人群层面：群体免疫和覆盖率阈值、项目如何设计、截至2026年的英国免疫规划、疫苗效果和安全性如何监测，以及信心如何建立和丧失。疫苗的免疫学在[[immunology/vaccines-immunotherapy]]中介绍，儿童免疫接种的临床实施在[[paediatrics/immunisation]]中介绍。

## 直接保护与间接保护 {#protection}

疫苗有几种类型：**减毒活疫苗**（MMRV、轮状病毒疫苗、卡介苗、鼻喷流感疫苗）、**灭活全病原体疫苗**（灭活脊髓灰质炎疫苗）、**类毒素疫苗**（白喉、破伤风）、**亚单位和重组蛋白疫苗**（乙型肝炎、无细胞百日咳、HPV、B群脑膜炎球菌、带状疱疹）、**多糖结合疫苗**（Hib、肺炎球菌、ACWY群脑膜炎球菌）、**mRNA疫苗**和**病毒载体疫苗**。疫苗类型决定了免疫应答、剂次数、保护持续时间和禁忌证。

疫苗对人群的作用有两部分。**直接效应**是对接种者个人的保护。**间接效应**是由于流行的感染减少，未接种者（以及疫苗未起作用的接种者）也得到保护。间接保护要求疫苗能减少感染或传播，而不只是减少疾病。破伤风疫苗不提供间接保护，因为破伤风不在人与人之间传播。针对Hib、肺炎球菌和脑膜炎球菌的结合疫苗能减少鼻咽部携带，从而减少传播；在婴儿和青少年中引入这些疫苗后，从未接种过的较大年龄组的疾病也减少了。

## 群体免疫 {#herd-immunity}

::: definition 再生数与群体免疫 {#def-herd}
**基本再生数**$R_0$是一个具有传染性的人进入完全易感人群后平均引起的继发病例数。

**有效再生数**$R_e$（或$R_t$）是在部分人群已有免疫或已采取控制措施的情况下，某一时刻平均引起的继发病例数。如果人群中易感者比例为$s$，且混合是随机的，则$R_e = R_0 s$。

**群体免疫**是当人群中有足够多的人具有免疫力、使感染无法广泛传播（因为$R_e < 1$）时，对易感者产生的间接保护。**群体免疫阈值**是要达到这一点所需的人群免疫比例。
:::

::: theorem 群体免疫阈值 {#thm-hit}
在随机混合的情况下，当免疫比例$p$超过

$$
p_c = 1 - \frac{1}{R_0}
$$ {#eq-hit}

时，感染无法维持传播。如果疫苗能在比例为$E$的接种者中预防感染（即其针对感染的效果），则**临界接种覆盖率**为

$$
V_c = \frac{1 - 1/R_0}{E}.
$$ {#eq-vc}

如果$V_c > 1$，仅靠该疫苗在任何覆盖率下都无法实现消除。
:::

::: proof
如果每个病例平均引起超过一个新病例，流行就会扩大。在易感者比例为$s$的人群中，每个具有传染性的人有$R_0$次有效接触，其中比例为$s$的接触对象是易感者，因此$R_e = R_0 s$。当$R_e < 1$，即$s < 1/R_0$时，传播减弱。免疫比例为$p = 1 - s$，因此条件为$p > 1 - 1/R_0$。

如果人群中比例为$V$的人接种了一种能在比例为$E$的接种者中预防感染的疫苗，则来自接种的免疫比例为$VE$。令$VE = 1 - 1/R_0$，得到$V_c = (1 - 1/R_0)/E$。
:::

这个阈值是一种简化。真实人群并不是随机混合的：人们主要与年龄相近的人在家庭、学校和社区中接触。如果未接种者聚集在一起，例如在一所学校或一个参与率低的宗教或社会群体中，即使全国覆盖率高于阈值，该群体内部的$R_e$也可能超过1，从而发生暴发。某些疫苗的免疫力也会减弱（百日咳、流行性腮腺炎），有些疫苗预防疾病的效果好于预防感染。因此，阈值是规划的下限，而不是保证。

| 感染 | 典型的$R_0$ | 群体免疫阈值 |
|---|---|---|
| 麻疹 | 12～18 | 92%～94% |
| 百日咳 | 12～17 | 92%～94% |
| 水痘 | 8～10 | 88%～90% |
| 流行性腮腺炎 | 4～7 | 75%～86% |
| 风疹 | 6～7 | 83%～86% |
| 脊髓灰质炎 | 5～7 | 80%～86% |
| 天花 | 5～7 | 80%～86% |

*$R_0$的数值因情境而异；这些是常引用的范围。*

::: example 麻疹与95%的目标 {#ex-measles-vc}
取麻疹的$R_0 = 15$，两剂MMR的效果为97%。(a) 群体免疫阈值是多少？(b) 需要多高的接种覆盖率？(c) 如果两剂覆盖率为85%且没有其他免疫来源，$R_e$是多少？
::: solution
(a) $p_c = 1 - 1/15 = 0.933$，即93.3%。

(b) $V_c = 0.933/0.97 = 0.962$，即约96%。这就是为什么世卫组织的目标是两剂覆盖率至少达到95%。

(c) 免疫比例$= 0.85 \times 0.97 = 0.8245$；易感比例$s = 0.1755$；$R_e = 15 \times 0.1755 = 2.6$。每个病例平均会引起两个以上的新病例，因此无论麻疹在哪里传入，暴发都会扩大。实际上，一些年长者因既往感染而具有免疫力，而且覆盖率因地区而异，因此局部的$R_e$与这一平均值不同。

2023—2024年，英格兰83.9%的儿童在五岁生日前接种了两剂MMR。这远低于阈值，而伦敦某些行政区和其他地区的覆盖率还要低得多。
:::
:::

## 设计疫苗接种项目 {#programme-design}

在英国，**疫苗接种和免疫联合委员会**（JCVI）就使用哪些疫苗以及为谁接种向四个地区的政府提供建议。它考虑疾病负担、疫苗的效力和安全性、对人群可能产生的影响（包括用传播模型模拟的间接效应）以及成本效果。英国卫生安全局（UKHSA）出版的**《绿皮书》**（*Immunisation against infectious disease*）是每种疫苗的临床参考，按章节更新。疫苗由中央统一采购，这带来了议价能力，并使全国供应得以统筹管理。

关键的设计选择包括：

- **策略。** **普遍性**项目向某一年龄组的所有人提供疫苗（向所有婴儿提供MMRV）。**选择性**项目针对风险较高的群体（为结核病高发地区的婴儿或父母来自高发国家的婴儿接种卡介苗；为乙肝母亲所生的婴儿接种乙肝疫苗；为患有某些临床疾病的人接种流感和肺炎球菌疫苗）。**职业性**接种保护工作者及其照护对象（为卫生工作者接种乙肝和流感疫苗）。**旅行**疫苗大多不在常规项目之内。
- **接种年龄。** 疫苗应在风险最大的年龄之前接种，但又要在免疫系统能够应答、母传抗体不再干扰的时候。这就是为什么大多数婴儿疫苗从8周开始，而含麻疹成分的疫苗在1岁时接种。
- **为间接保护而选择的目标群体。** 有时为一个群体接种能保护另一个群体。青少年ACWY群脑膜炎球菌疫苗接种针对携带率最高的年龄组，从而保护更年幼和更年长的人。孕期接种百日咳疫苗通过经胎盘抗体保护因年龄太小而无法接种的新生儿。
- **常规接种与补种。** 新项目常包括对较大出生队列的一次性补种。暴发时和消灭疾病时采用大规模接种运动。
- **剂次和程序。** 减少剂次可降低成本并提高完成率；在有证据表明在该年龄组一剂提供的保护与两剂相当之后，英格兰青少年HPV项目自2023年9月起改为**一剂**。

## 2026年的英国免疫规划 {#uk-schedule}

经过2025年7月和2026年1月的调整，英格兰的常规儿童免疫程序为：

| 年龄 | 疫苗 |
|---|---|
| 8周 | 六联疫苗（DTaP/IPV/Hib/HepB）第1剂；B群脑膜炎球菌疫苗第1剂；轮状病毒疫苗第1剂 |
| 12周 | 六联疫苗第2剂；B群脑膜炎球菌疫苗第2剂；轮状病毒疫苗第2剂 |
| 16周 | 六联疫苗第3剂；肺炎球菌结合疫苗（PCV）第1剂 |
| 1岁 | PCV加强剂；B群脑膜炎球菌疫苗加强剂；MMRV第1剂 |
| 18月龄 | 六联疫苗第4剂；MMRV第2剂 |
| 3岁4个月 | 学龄前四联加强剂（dTaP/IPV） |
| 12～13岁 | HPV（一剂） |
| 14岁 | 青少年三联加强剂（Td/IPV）；ACWY群脑膜炎球菌疫苗 |

儿童从2岁起直到整个学龄期，每年秋季还可接种流感疫苗。2026年1月的调整用**MMRV**取代MMR，把水痘纳入常规项目，取消了Hib/MenC加强剂，并设立了18月龄的接种。较大儿童的过渡安排，以及选择性的新生儿卡介苗和乙肝疫苗接种的细节，见[[paediatrics/immunisation]]。

成人项目包括：

- **孕期**：百日咳（16周起）、RSV（28周起）和季节性流感。
- **老年人**：65岁起每年接种流感疫苗；65岁时接种一剂肺炎球菌疫苗；65岁起接种带状疱疹疫苗（重组疫苗Shingrix），对较大年龄队列有过渡安排，严重免疫抑制者更早接种；以及**RSV**疫苗，2024年9月为75～79岁人群引入，自2026年4月1日起扩展到所有80岁及以上的人和老年人照护院的住户。
- **临床风险群体**：流感、肺炎球菌、新冠（为最高风险人群开展季节性接种）以及《绿皮书》规定的其他疫苗。
- **性健康服务**：为风险较高的男男性行为者（包括男同性恋者和双性恋男性）提供甲肝和乙肝、HPV和猴痘疫苗；并自2025年8月起为风险最高者接种4CMenB疫苗以减少淋病，这是世界上首个此类项目，依据的是约30%～40%保护作用的观察性证据。

### 监测覆盖率 {#coverage}

覆盖率根据全科医生记录和儿童健康记录测量。在英格兰，UKHSA的**COVER**项目按季度和年度报告各地区儿童在1岁、2岁和5岁时每种疫苗的覆盖率。覆盖率在较贫困地区、某些族群和宗教社区、吉卜赛人、罗姆人和旅行者家庭、受照护儿童和新近抵达的移民中，以及在伦敦市中心等人口流动性大的地区较低。全国平均数掩盖了这些“洼地”，而暴发正是从这些地方开始的。

漏种的原因多种多样：实际障碍（预约名额、搬家、记录丢失、工作、交通）、缺乏提醒、儿童因其他原因就诊时错失机会、对禁忌证的错误认识，以及犹豫。有效的措施包括召集和再召集系统、短信提醒、灵活的门诊和外展门诊、每次接触时核查接种状态，以及与社区领袖合作。在英国，大多数未接种儿童的父母并不反对接种；他们面临的是可及性障碍，或有未得到解答的疑问。

## 现场的疫苗效果 {#effectiveness}

上市前试验测量的是试验条件下的**效力**。**效果**是常规使用中实际达到的保护，可能因储存和处理、接种程序、接种人群、毒株变异和免疫衰减而不同。效果在疫苗引入后通过以下方法估计：队列研究、病例对照研究（包括用于流感和新冠的**检测阴性设计**，比较检测阳性者和阴性者的接种情况），以及**筛查法**。

::: warning “大多数病例都接种过”并不意味着疫苗失效
当覆盖率很高时，接种者占人群的大多数，因此即使是非常有效的疫苗，接种者中的病例也可能多于未接种者中的病例。在覆盖率97%、效果97%的情况下，约一半的病例发生在接种者中，因为在一个非常大的群体中有3%未得到保护，而未接种群体很小。病例中接种者的比例必须始终与人群中接种者的比例相比较。这种误解在新闻报道和反疫苗材料中很常见。
:::

::: example 筛查法 {#ex-screening-method}
**筛查法**根据病例中接种者比例（PCV）和人群中接种者比例（PPV）估计疫苗效果（VE）：

$$
VE = 1 - \frac{PCV}{1 - PCV} \times \frac{1 - PPV}{PPV}.
$$ {#eq-screening-method}

在某学校的一次麻疹暴发中，90%的学生接种过两剂MMR。病例中31.0%接种过疫苗。估计疫苗效果。
::: solution
$\dfrac{PCV}{1-PCV} = \dfrac{0.310}{0.690} = 0.449$。$\dfrac{1-PPV}{PPV} = \dfrac{0.10}{0.90} = 0.111$。

$VE = 1 - 0.449 \times 0.111 = 1 - 0.050 = 0.95$，即约95%。

近三分之一的病例接种过疫苗，但疫苗使风险降低了约95%。这种方法快速，适用于监测，但它对PPV的误差很敏感（PPV应在与病例相同的人群中测量，这里是该学校），并且假定接种者和未接种者的暴露相似。
:::
:::

## 疫苗安全性 {#safety}

疫苗以极大的数量接种给健康人，往往是儿童，因此安全标准必须非常高，罕见的不良事件也很重要。上市前试验通常纳入数千至数万名参与者，无法发现发生率低于约万分之一的不良事件。因此，**上市后监测**（药物警戒）必不可少。

在英国，药品和保健产品监管局（MHRA）运行的**黄卡**（Yellow Card）系统收集卫生专业人员和公众对可疑不良反应的自发报告。新疫苗带有黑色三角标志，要求报告所有可疑反应。自发报告可以产生**信号**，但不能确立因果关系，因为事件在接种后会偶然发生，而且报告不完整，并受到宣传的影响。

信号用分析方法检验：

- **观察数与期望数分析。** 把接种后风险窗内报告的事件数与根据背景发病率得出的期望数相比较。
- **自身对照病例系列**（SCCS）由法林顿（Paddy Farrington）及其同事于20世纪90年代提出，它把*同一*个体在接种后规定风险期内的事件发生率与其他时间的发生率相比较。由于每个人都是自己的对照，遗传和慢性病等固定的混杂因素被消除。该方法曾用于证明一种含Urabe株腮腺炎成分的MMR疫苗与无菌性脑膜炎有关，这导致该疫苗于1992年在英国停用；也曾用于证明MMR与孤独症之间没有关联。
- 在大型关联数据库中开展的**队列研究和病例对照研究**。

::: example 观察数与期望数 {#ex-observed-expected}
两百万成年人接种了一种新疫苗。吉兰-巴雷综合征（GBS）的背景发病率约为1.5/10万人年。接种后42天内报告了8例。偶然情况下期望有多少例？这是否构成信号？
::: solution
风险人时$= 2{,}000{,}000 \times 42/365 = 230{,}137$人年。

期望病例数$= 230{,}137 \times 1.5/100{,}000 = 3.45$。

观察到8例。如果病例服从均值为3.45的泊松分布，出现8例或更多的概率约为0.025。观察数是期望数的两倍多，不太可能单纯由偶然造成，因此这是一个需要调查的**信号**。它不是证据：接种人群的背景率可能高于假设值（例如年龄较大），接种后的报告可能更完整，有些病例可能不符合病例定义。接下来要用确诊病例开展自身对照病例系列研究或队列研究。如果得到证实，必须把这一风险（这里是每百万剂多出几例）与疫苗的获益相权衡。正是这类分析在2021年发现了腺病毒载体新冠疫苗接种后罕见的血栓伴血小板减少，并导致其使用按年龄作出调整。
:::
:::

因接种疫苗而严重残疾的人可以根据英国**疫苗损害赔偿**计划（依据《1979年疫苗损害赔偿法》设立）提出申请，该计划一次性支付赔偿，无需证明存在过失。这类计划通过承认罕见伤害确实会发生来维护公众信任。

## 疫苗信心与沟通 {#confidence}

::: definition 疫苗犹豫 {#def-hesitancy}
**疫苗犹豫**是指在可获得疫苗接种服务的情况下延迟接受或拒绝接种疫苗（世卫组织免疫战略咨询专家组，2015年）。它是介于完全接受和断然拒绝之间的连续谱，并因情境、时间、地点和疫苗而异。

其决定因素常概括为“3C”：**信心**（对疫苗、卫生服务和决策者的信任）、**自满**（认为疾病风险低）和**便利**（可获得性、可负担性、可及性）。后来的模型又增加了**计算**（信息搜寻）和**集体责任**。
:::

成功的疫苗接种会造成自满：当疾病变得罕见时，父母不再见到它们，注意力转向疫苗的副作用。信心可能很快受损。1998年，韦克菲尔德（Andrew Wakefield）及其同事在《柳叶刀》上发表了一个病例系列，暗示MMR与孤独症之间存在联系。这项研究后来被证明是欺诈性的；论文于2010年被撤回，韦克菲尔德被从英国医学注册中除名。大型研究未发现任何关联。但英格兰的MMR覆盖率在21世纪初降至80%左右，多年后才恢复，麻疹于2008年再次成为地方性流行病。

关于沟通的证据提示了几项原则：

- **明确推荐。** 卫生专业人员的推荐是接种的最强预测因素。**预设式**说法（“今天她该打1岁的疫苗了”）比参与式说法（“她的疫苗你想怎么办？”）带来更高的接种率，而且不会降低满意度。
- **倾听并回应顾虑。** 许多犹豫的父母有具体的问题。对于有持续顾虑的人，推荐使用**动机访谈**的技巧，探讨当事人自己的看法和理由。对顾虑不屑一顾会损害信任。
- **用平实的语言和人们使用的语言提供准确、平衡的信息**，包括常见的副作用。
- **谨慎应对错误信息。** 以事实而非谣言开头，解释错误说法为什么错，并利用社区中受信任的传播者。突出地重复谣言可能加深对它的记忆。
- **让接种变得容易。** 便利方面的障碍往往比信念更重要。

::: example 一位犹豫的父亲 {#ex-hesitant}
一位父亲带13月龄的女儿因小病到全科诊所就诊。她的记录显示她还没有接种1岁的疫苗。他说自己“并不反对疫苗”，但读到MMRV会“使免疫系统超负荷”，他宁愿再等等。诊所护士应如何回应？
::: solution
**利用这次接触。** 不发热的小病不是禁忌证，所以如果他同意，今天就可以接种。

**先推荐，再倾听。** “她该打1岁的疫苗了，我建议今天就打。你提到有些顾虑，能多说一点吗？”了解他读到了什么、他看重什么。

**回应具体的顾虑。** 婴儿的免疫系统每天都要应对来自食物、环境和定植细菌的大量抗原。免疫程序中的疫苗所含抗原只占免疫系统每天应对的抗原的极小一部分，而且现代疫苗所含的抗原比老式疫苗少得多。同时接种几种疫苗已经得到广泛研究；这是安全的，也不会降低对每种疫苗的应答。推迟接种会使她在麻疹以及肺炎球菌病和脑膜炎球菌病都很危险的年龄得不到保护，而且麻疹目前正在英格兰传播。

**如实说明副作用。** 发热和烦躁很常见；MMRV可能在约7～12天后引起发热和皮疹。热性惊厥不常见。严重反应非常罕见。

**尊重决定。** 如果他想考虑一下，提供书面信息，尽快安排一个方便的预约，并记录这次讨论。保持沟通的大门敞开：许多父母会回来，而一次尊重的交谈会增加这种可能。
:::
:::

## 消除与消灭 {#eradication}

**控制**是把疾病降至可接受的水平；**消除**是在确定的地区阻断地方性传播（例如，麻疹消除要求在高质量监测下至少12个月没有地方性传播）；**消灭**是使全球发病率永久降至零，从而不再需要干预措施。

天花于1980年被宣布消灭，是迄今唯一被消灭的人类疾病。使之成为可能的特点有：没有动物宿主；没有无症状携带，因此病例是可见的；有特征性的皮疹，无需实验室即可诊断；感染或接种后获得终生免疫；有耐热的冻干疫苗；以及**监测与围堵**策略（发现病例并对其接触者进行“环形”接种），即使在无法实现大规模覆盖的地方也行之有效。自1988年以来，野生脊髓灰质炎病毒的传播已减少99%以上，目前仅在阿富汗和巴基斯坦仍有地方性流行，但口服疫苗罕见地回复为循环疫苗衍生脊髓灰质炎病毒、冲突以及拒绝接种，使最后几步举步维艰。疫苗接种的全球问题在[[public-health/global-health]]中进一步讨论。

::: quiz
在一个两剂MMR覆盖率为97%的社区发生了麻疹暴发，一半的病例接种过两剂MMR。当地报纸的标题是“疫苗一半时间失效”。最好的解读是什么？
- [ ] 疫苗的效果约为50%。
- [ ] 由于病毒发生了变异，疫苗失去了效果。
- [x] 这一结果与疫苗高度有效是一致的，因为几乎每个人都接种了。
- [ ] 两剂的保护并不比不接种更好。
::: solution
在覆盖率97%、效果97%的情况下，接种者病例来自人群的$0.97 \times 0.03 = 2.9\%$，未接种者病例来自最多3%的人群。即使每个接种者的风险降低了97%，也会有约一半的病例接种过疫苗。同时使用病例中接种者比例和覆盖率的筛查法，会得出约97%的效果。
:::
:::

::: history
1796年，詹纳（Edward Jenner）用牛痘病灶的材料给菲普斯（James Phipps）接种，后来证明这个男孩对天花有了保护力；他于1798年发表了《探究》（*Inquiry*）。1853年，英格兰规定婴儿必须接种，这引发了反疫苗运动，并于1898年加入了“良心拒绝”条款。巴斯德（Louis Pasteur）的鸡霍乱、炭疽和狂犬病（1885年）减毒疫苗表明，这一原理可以推广。20世纪出现了白喉、破伤风、百日咳、脊髓灰质炎（索尔克疫苗1955年，萨宾疫苗20世纪60年代初）、麻疹（1963年）、流行性腮腺炎和风疹疫苗。世卫组织于1974年启动扩大免疫规划，世界卫生大会于1980年5月宣布天花被消灭。英国于1988年引入MMR，1992年引入Hib疫苗，并于1999年成为第一个引入C群脑膜炎球菌结合疫苗的国家。全球疫苗免疫联盟（Gavi）成立于2000年，为低收入国家的疫苗提供资金。2020年的新冠疫苗，包括首批获批的mRNA疫苗，其研发和部署速度超过以往任何疫苗。
:::

## 后续内容

疫苗背后的免疫学见[[immunology/vaccines-immunotherapy]]，儿童疫苗接种的临床实施（包括禁忌证和补种程序）见[[paediatrics/immunisation]]。暴发控制（疫苗接种是其中的一种工具）是[[public-health/communicable-disease-control]]的主题。

::: summary
- 疫苗为接种者提供**直接**保护；如果能减少传播，还为他人提供**间接**保护。
- **群体免疫阈值**$p_c = 1 - 1/R_0$；**临界覆盖率**$V_c = (1 - 1/R_0)/E$。麻疹（$R_0$为12～18）需要约95%的两剂覆盖率。未接种者的聚集使得即使在全国阈值之上也会发生暴发。
- 在英国，**JCVI**提供建议，**《绿皮书》**指导实践，UKHSA监测覆盖率（COVER）、疾病和效果。
- 2026年的免疫程序包括1岁和18月龄的MMRV、8周、12周和1岁的B群脑膜炎球菌疫苗、一剂HPV、孕期百日咳和RSV疫苗，以及为75岁及以上成人和照护院住户接种的RSV疫苗。
- 现场**效果**通过队列研究、病例对照（检测阴性）研究和筛查法估计。高覆盖率意味着即使疫苗极好，许多病例也是接种过的。
- 安全性依赖上市后监测：**黄卡**信号、观察数与期望数分析，以及**自身对照病例系列**。
- **疫苗犹豫**取决于信心、自满和便利。明确的推荐、倾听、如实的信息和便捷的可及性能提高接种率。
- 天花是唯一被消灭的人类疾病；野生脊髓灰质炎仅在阿富汗和巴基斯坦仍有地方性流行。
:::

## 习题

::: exercise 群体免疫阈值 {level=1 check="round(1000*(1-1/6))/10"}
在某人群中，流行性腮腺炎的$R_0 = 6$。群体免疫阈值是多少？以百分比表示，保留1位小数。
::: solution
$p_c = 1 - 1/6 = 0.8333$，即83.3%。
:::
:::

::: exercise 临界覆盖率 {level=1 check="round(1000*(1-1/6)/0.9)/10"}
如果疫苗中腮腺炎成分预防感染的效果为90%，需要多高的覆盖率才能达到上一题的阈值？以百分比表示，保留1位小数。
::: solution
$V_c = 0.8333/0.90 = 0.926$，即92.6%。在已接种的大学生中发生的腮腺炎暴发表明，预防感染的效果可能低于此值，而且免疫力会减弱，因此所需的覆盖率更高。
:::
:::

::: exercise 有效再生数 {level=1 check="2.4"}
某感染的$R_0 = 8$。人群中70%具有免疫力。假设随机混合，$R_e$是多少？
::: solution
$s = 0.3$；$R_e = 8 \times 0.3 = 2.4$。感染仍能传播。
:::
:::

::: exercise 病例中接种者的比例 {level=2 check="round(1000*0.97*0.03/(0.97*0.03+0.03))/10"}
覆盖率为97%，疫苗效果为97%。假设暴露相同，病例中接种者的百分比是多少？保留1位小数。
::: solution
相对于人群，接种者病例来自$0.97 \times 0.03 = 0.0291$，未接种者病例来自$0.03 \times 1 = 0.03$（以未接种者的罹患率为参照）。接种者比例$= 0.0291/(0.0291 + 0.03) = 0.492$，即49.2%。
:::
:::

::: exercise 筛查法 {level=2 check="round(100*(1 - (0.2/0.8)*(0.15/0.85)))"}
在一次儿童百日咳暴发中，社区内85%的儿童已全程接种，病例中20%已全程接种。用筛查法估计疫苗效果，以整数百分比表示。
::: solution
$\dfrac{PCV}{1-PCV} = 0.2/0.8 = 0.25$；$\dfrac{1-PPV}{PPV} = 0.15/0.85 = 0.176$。$VE = 1 - 0.25 \times 0.176 = 0.956$，即96%。
:::
:::

::: exercise 期望的背景事件数 {level=2 check="round(100*500000*30/365*10/100000)/100"}
五十万人接种了一种疫苗。贝尔麻痹的背景发病率约为10/10万人年。接种后30天内，偶然情况下期望有多少例？保留2位小数。
::: solution
人时$= 500{,}000 \times 30/365 = 41{,}096$人年。期望数$= 41{,}096 \times 10/100{,}000 = 4.11$。因此，仅凭巧合就预期接种后会出现若干例贝尔麻痹；报告少数几例本身并不表明存在问题。
:::
:::

::: exercise 规划暴发应对 {level=3}
在一个MMR覆盖率低的地区，一所小学报告了两例确诊麻疹。记录显示，420名学生中330人接种过两剂MMR或MMRV，30人接种过一剂，60人未接种。描述公共卫生应对措施，并解释为什么就整个英格兰计算的群体免疫阈值在这里不能令人放心。
::: solution
**即时行动。** 通知当地UKHSA卫生防护团队（麻疹在临床怀疑时即须报告）。确认病例（口腔液或血液检测），病例隔离至出疹后4天，并在学校和家庭中识别接触者。

**接种。** 为未接种和未全程接种的学生和教职员工提供MMR或MMRV，最好在暴露后72小时内作为暴露后预防，无论如何都可防止进一步暴露。开设学校或社区接种门诊以消除可及性障碍。

**脆弱的接触者。** 识别怀孕、免疫抑制或因年龄太小而无法接种的婴儿接触者，他们可能需要按UKHSA指南使用人正常免疫球蛋白。

**沟通。** 用家长使用的语言发出清晰的信函，并请社区中受信任的人士参与。

**为什么全国阈值没有帮助。** 学校内部的传播取决于学校自身的免疫水平。约有0.97 × 330 + 0.93 × 30 ≈ 348名学生有免疫力，约72人（17%）仍然易感，远高于麻疹所能容忍的6%～7%的易感比例。无论全国平均数如何，这所学校都是一个$R_e$大于1的聚集群体。
:::
:::

::: exercise 是否应增加一种新疫苗？ {level=3}
一种针对某细菌感染的新疫苗获批上市，该感染每年在英国婴儿中引起300例严重疾病和30例死亡。该疫苗预防疾病的效果为80%，可能减少携带，10%的接种者会发热，而且价格昂贵。概述JCVI在推荐它之前会考虑的问题。
::: solution
**负担。** 按年龄划分的发病率、严重程度、死亡和长期后遗症，以及随时间的趋势。

**疫苗。** 预防疾病和携带的效力、保护持续时间、为在风险高峰期保护婴儿所需的剂次和接种年龄、毒株覆盖范围、安全性（包括发热和任何罕见事件），以及能否与现有疫苗同时接种而不产生干扰或增加就诊次数。

**影响。** 用传播模型模拟直接和间接效应，包括如果携带减少，对年长者可能产生的保护，以及血清型或毒株替换的风险。

**成本效果。** 使用疫苗价格和项目成本计算每获得一个QALY的成本；为全国供应谈判达成的价格往往决定最终结果。

**项目。** 与免疫程序的衔接、工作量、父母的接受程度、额外注射或发热对信心的影响（例如像B群脑膜炎球菌疫苗那样需要预防性使用对乙酰氨基酚）、衡量影响的监测，以及可及性的公平。
:::
:::
