全球卫生是关于世界实况的流行病学与关于世界应然状态的伦理学：一个始于给殖民者的热带医学、变成给捐赠者的国际卫生、如今研究财富与权力与疾病如何跨越国界分配的领域。**本章覆盖疾病负担的记账与流行病学转型及其双重负担、制度架构（世界卫生组织与联合国系统、布雷顿森林机构、纵向基金、以及为多数被测量项目提供资金的双边捐赠者）、筹资与人力的流动（官方发展援助的卫生账本、疫苗联盟—全球基金—世界银行三角、以及人才流失）、安全的框架（大流行防范与《国际卫生条例》）、以及作为本领域统摄性问题的公平：1978年阿拉木图-阿塔的初级卫生保健承诺、它被纵向项目瓦解的过程、以及疫情后的重建论证。**

## 地图

::: definition 负担记账与转型 {#def-burden}
**全球卫生用可比指标说话。伤残调整生命年计算因早死或失能而损失的年数，带着方法学的争议（年龄加权与折现）与一个对公平“失明”的性质：除非刻意加入社会的加权，富国挽救的一年与穷国挽救的一年被记作相等。健康预期寿命提供标题数字：国与国之间十至十五年的差距、以及一个国家内部不同社区之间类似的差距——这使得凡是存在移民与不平等之处，全球卫生都是国内政策。全球疾病负担工程把危险因素归因变成单一可比的记账体系，围绕死因编码质量仍有争论，但作为本领域共享的地图其价值无可替代。流行病学转型（奥姆兰的表述，经“疾病压缩”的修订更新）描述了多数人群从感染性到慢性死因的转移，但真实的故事是叠加而非替代：同一人群、同一家庭、甚至同一个身体里同时携带感染与慢性两种负担（结核与糖尿病并存、风湿性心脏病与缺血性心脏病并存、以及被治好的儿童以高血压与肥胖的成人形式回来）——这就是双重负担，也是为什么“发展完了再做慢性病”的说法既错又贵。记账还有第三个用途：它显示负担最重处恰是卫生人力与数据最薄处——多数国家的关键数字来自抽样、模型与 外推；因此加强监测不是学术偏好而是主权的条件——[[public-health/determinants-inequalities]]、[[epidemiology-ebm/measuring-disease]]、[[endocrine/diabetes-complications]]。**
:::

## 机器

::: definition 制度、筹资与安全框架 {#def-machinery}
**世界卫生组织是本领域的宪制机构：规范的设定者（分类系统与治疗指南与多数国家处方目录照抄的基本药物清单）、认证者（消除与验证的规划）、以及紧急警报器（《国际卫生条例》下“国际关注的突发公共卫生事件”的宣布、2005年在严重急性呼吸综合征之后的修订、以及大流行协议谈判及其“一百天公平”目标与病原体获取体系——这些都要由下一次暴发评判）。围绕它的是联合国家族（联合国艾滋病规划署、联合国儿童基金会在采购上的主导地位、人口基金、以及粮农组织—世界卫生组织—世界动物卫生组织的“同一健康”秘书处）、作为最大外部卫生筹资者的世界银行（其在保险与社会保护之间的教义摆动）、以及区域开发银行。筹资的架构是一个三角：疫苗联盟作为疫苗市场的需求聚合者（及其中等收入国家的毕业规则与市场的长期重塑）、全球基金（其绩效基于拨款与三病聚焦）、以及世界银行（其软贷款与强化卫生系统的名义项目），再加上双边捐赠者与大流行应对基金——它们共同决定了哪些疾病被数、哪些被治。安全框架把卫生变成地缘政治：生物威胁的等级（有意与无意与自然）、实验室与监测的能力与《国际卫生条例》的核心能力要求、以及“通报即受罚”这一 抑制隐瞒的修复（技术援助与贸易与旅行限制克制使用的承诺）——[[public-health/communicable-disease-control]]、[[infectious-diseases/hiv]]、[[microbiology/infection-control]]。人力的流动是本领域最尖锐的道德账：高收入国家的卫生人力中出生与受训于低收入国家者的比例、招聘守则与自愿承诺的无力、以及“培训换回流”的论证——与卫生工作者薪酬与岗位的国内失败同时发生——[[medical-ethics-law/justice-resources]]。**
:::

## 问题

::: definition 公平、团结与重建论证 {#def-equity}
**公平是本领域的度量衡而非附属品。初级卫生保健的论证从阿拉木图开始（可及、社区、跨部门与适当技术），在结构调整的年代被削弱，又以“全民健康覆盖”的名字在2010年代回归——同一主张、更强的指标（覆盖范围三角：人群、服务、财务保护）与更硬的证据（东欧与东南亚与卢旺达的经验：卫生系统在十年里被建成、并带来可测的死亡下降）。团结的语言有硬内容：跨境传播使别国的卫生系统成为本国的基础设施（疫苗与检测与数据的共享、以及《国际卫生条例》的通报），大流行融资的集体行动问题（人人都有理由等别人付钱、而威慑不足与能力薄弱并存）、以及疫苗民族主义的代价—— 疫苗剂次与技术许可与技术转让与“公平”词汇之间的鸿沟，是本世纪最清晰的公共伦理案例。纵向项目的遗产需要诚实的评价：它们救活了生命（抗逆转录病毒治疗与蚊帐与疫苗与结核病的治疗）并把某些疾病推到了边缘，但也造出了平行的系统与外逃的薪酬与国内的优先级扭曲；解法不是取消而是嵌入（同样的药与同样的数据进入同一套初级卫生保健系统，并让本国预算逐步承担运行成本）——[[infectious-diseases/hiv]]、[[public-health/vaccination-programmes]]、[[public-health/health-systems-economics]]。重建论证的三条腿：把防范的成本与损失的规模比较（大流行的代价与常备投入相差数个数量级）、把卫生当作经济基础设施（学校关闭与长新冠与生产力与信任的损失）、以及把公平当作有效性（在下一个病原到来之前，最薄弱环节就是所有人的门槛）——[[public-health/global-health]]。**
:::

::: example 来了两次的转诊 {#ex-migration}
一名新到的萨摩亚裔患者带着两箱药与一份无法辨认的处方清单来门诊；她有癫痫、糖尿病与“肾脏问题”；她的姐姐说家里其他人也有同样的病；诊所无法联系原籍国。
::: solution
**移民作为全球卫生的门诊（[[#def-burden]]、[[#def-machinery]]、[[public-health/determinants-inequalities]]）：先解决眼前的安全问题：把两箱药做用药重整（重复、过期、以及剂量与原籍国不同）、把癫痫与糖尿病与肾病分别按本地指南重开、并把不能确认的既往结果当作未做（包括传染病筛查的按本地流行病学重做、而不是假定风险——这既是照护也是反歧视）——[[renal/chronic-kidney-disease]]、[[endocrine/diabetes]]、[[nervous-system/epilepsy]]。疾病为何“跟着人走”：同一人群的慢性病负担（肥胖、糖尿病、慢性感染如嗜酸性粒细胞增多与寄生虫、以及风心病与结核的隐性）、以及迁移本身的选择效应与宿主效应；“热带”疾病在温带出现需要按旅行与出生地思维（血嗜酸性粒细胞与特定的血清学与影像）——[[infectious-diseases/tropical-infections]]。家庭与群体的一层：家族史的采集要覆盖亲属与同乡（血友病与镰状细胞与地中海贫血与遗传性肿瘤风险的携带者网络），并把筛查与遗传咨询用能听懂的语言与文化上合适的方式提供（口译不是可选项——用家人做翻译会伤害保密与准确性）——[[genetics/genetic-testing]]、[[medical-ethics-law/confidentiality]]。系统的修复：跨境病历的可移植标准与互操作、以及把“移民健康门诊”建成一整套（预约与随访、伤口与疫苗与出生缺陷、以及社会处方与转介到社区组织）；并记住高收入国家的卫生人力常常正是这批患者的邻居——这也是为什么人才流失与移民健康是同一枚硬币的两面——[[clinical-skills/records-handover]]、[[public-health/screening]]。**
:::

::: example 想要指标的基金 {#ex-donor}
一个捐赠基金愿为某国的孕产妇健康出五千万美元，但要求以“每千活产的死亡率”作为唯一付款指标、并把项目建成独立的管理与数据系统；卫生部长希望接受。
::: solution
**把资金变成制度（[[#def-machinery]]、[[#def-equity]]、[[obstetrics-gynaecology/postnatal-period]]）：三个真问题：一是“哪个分母”——死亡率作为指标是好的终点，但把它变成唯一的付款条件会产生撇选（把最危重的转诊与边远地区排除在绩效之外）、以及“为指标而报数”的动力（漏报与活产登记的不完整会让分母说谎）；解法是“多重指标加验证”：结果、覆盖率、质量（如急产与产后出血的处置依从）、以及按地区的公平分层，并由独立的死亡评审与人口调查做交叉校验——[[clinical-skills/patient-safety]]、[[public-health/screening]]。二是“平行系统”——独立的管理与数据系统短期跑得快，长期却抽走人才（同一批熟练员工被项目工资抽走）并使国内预算失去运行责任；可谈判的中间立场是用现有系统并投资它（同意的数据标准与共享、把项目工资并入统一的绩效池、以及逐年下降的补贴曲线与明确的接管日期）——[[public-health/health-systems-economics]]。三是“接管的可行性”——若本国预算在未来承担运行成本，则今天的交易是可持续的；否则这是给下一任部长的账单；所以条款里应写进逐步提高的本国投入份额与成本的透明清单（人力、供应链、车辆燃料与维护，以及数据的运行成本）——[[medical-ethics-law/justice-resources]]。给部长的谈判立场：接受钱、拒绝单一指标与平行系统、并要求把资金用于最难被展示的两件东西（人力与信息系统），因为它们才是“减少死亡”的真实原因；同时把社区与患者的参与与问责写进合同，让指标不只向上汇报——[[obstetrics-gynaecology/pregnancy-complications]]、[[clinical-skills/communication]]。**
:::

::: example 午夜的疫情通报 {#ex-emergency}
你在国家级机关值夜班；东部一家医院报告两例不明原因发热伴出血，两名医护被感染；他们两周前参加过一场跨境葬礼；现在是晚上十一点，政治办公室要求你“先别声张，等确认”。
::: solution
**风险沟通与通报的伦理（[[#def-machinery]]、[[#def-equity]]、[[public-health/communicable-disease-control]]）：第一原则：不确定性不是沉默的理由——《国际卫生条例》要求对“可能构成国际关注的事件”在二十四小时内评估并通报，因为国际信任与技术援助都建立在早通报上；惩罚早通报的国家（以旅行与贸易限制相逼）会制造隐瞒的激励，所以“通报即受援”必须有配套的克制与援助承诺——[[emergency-critical-care/major-incidents]]。今夜的动作（并行而不是顺序）：感染控制（隔离与个人防护与“谁接触了谁”的清单、以及对两名医护所在病区的接触者追踪）与诊断（安全转运与最高等级实验室的病原检测、以及不要为了采样而制造暴露）、以及临床（支持治疗、避免非适应证的侵入操作、以及静脉补液的谨慎）——[[infectious-diseases/tropical-infections]]、[[microbiology/infection-control]]。同时启动沟通：向公众发布“我们知道什么、不知道什么、正在做什么、多久更新一次”（不说“别担心”；每次更新兑现上次承诺的时间）；对政治办公室的解释是：可控的早期披露保护政府，事后被揭穿的秘密摧毁政府。组织与后续：国家应急中心与地方团队与 世界卫生组织国别代表的连接与分工（谁管接触者名单、谁管实验室链、谁管社区）、跨境联络（同一葬礼的另一侧）、以及医院内的一线人员支持（设备、心理与家庭安排）——因为他们是最先且最重暴露的一群。复盘要写清两个数字：从“第一个人就诊”到“隔离”、以及到“第一次公开沟通”——这两条时间差决定了此后一切——[[clinical-skills/patient-safety]]、[[medical-ethics-law/professionalism-regulation]]。**

::: example 毕业的问题 {#ex-graduation}
一个中等收入国家被疫苗联盟通知将在三年内“毕业”（失去资格）；它的免疫规划覆盖率高但依赖外部资金与采购与技术岗位的外籍人员；财政部欢迎这笔节省，卫生部担心冷链与补充免疫活动。
::: solution
**毕业作为一种政策事件（[[#def-machinery]]、[[#def-equity]]、[[public-health/vaccination-programmes]]）：诚实的框架：毕业是资格规则的结果，不是“做好了”的评价——这个国家的疾病风险并未改变，而财政空间可能因债务而比受援时更窄。要谈的不是“是否毕业”而是“以什么条件毕业”：一张五年的成本表（疫苗本身、冷链与设备维护、人力、以及注射安全与废弃物处理与监测）；以及一个可预测的退出曲线（阶梯共付、按收入增长自动上调的自付份额、以及明确的截止年），因为它使财政部能在预算周期里排入这笔支出——而一次性切断几乎必然导致漏种与随后的暴发——[[public-health/health-systems-economics]]、[[paediatrics/immunisation]]。技术岗位的接班：把外籍技术支持的任务转移写进时间表并配套培训与薪酬（冷链工程师与数据员与督导），以及把新疫苗引入的决策留在本国技术顾问组（它有优先顺序的权力而不只是执行的角色）——[[medical-ethics-law/justice-resources]]。监测是防线：以乡级覆盖率的真实测量与“零剂次儿童”的主动搜寻与暴发准备（含补充免疫活动的自主资金）来证明自己配得上这些剂量；一次被及时发现的麻疹暴发比十年前的节省更贵——[[epidemiology-ebm/measuring-disease]]、[[infectious-diseases/stewardship-outbreaks]]。政治的沟通：把“节省”重新表述为“从援助转向本国预算的转移”，并向议会给出可比的成本（一次暴发的治疗与失学与死亡）；同时用政治经济学的眼光看毕业之后（其他纵向项目也退出时的系统空洞），把谈判目标定为“制度保留”而非“资金保留”——[[public-health/prevention-promotion]]。**

::: history
**全球卫生的制度史是战争、殖民与冷战的后话。1948年世界卫生组织的成立把“健康是基本人权而非慈善”写进宪章（同一年代还有《世界人权宣言》与1945年的联合国）；消灭天花（1967年强化、1980年宣布）留下了两种互相对立的教训——垂直动员可以做成不可能之事、也可以把系统掏空；1978年的阿拉木图宣言把初级卫生保健列为“2000年人人健康”的主路径，随后被结构调整的条件性削弱，却在1980年代以选择性策略的形式幸存；1987年的蒙特利尔与1990年代的治疗可及运动揭穿了“贫困国家不需要治疗只需预防”的说法，并把艾滋病从道德争论推入人权语言；2000年前后是基金的年代（全球基金与疫苗联盟与世界银行的三方）与千年发展目标把卫生压缩成可营销的数字；2002至2003年的严重急性呼吸综合征催生了2005年修订的《国际卫生条例》，把“通报”变成法律义务；2014至2016年的西非埃博拉暴露了“没有系统可强化”的处境并催生了应急响应机制；2015年的可持续发展目标与全民健康覆盖双指标、以及2019冠状病毒大流行的疫苗民族主义与《多哈宣言》之后的贸易知识产权之争，把“团结”变成一个可计量的缺口——本领域的伦理问题从未像现在这样同时也是一个财政与法律的技术问题——[[infectious-diseases/hiv]]、[[public-health/global-health]]。**
:::

::: summary
- 负担的数字是政治的选择：伤残调整生命年对公平“失明”，而健康预期寿命的差距使全球卫生成为任何不平等国家的国内议题。
- 转型不是替代而是叠加：双重负担在同一人群与同一个体中并存，“先发展后慢病”既错又贵。
- 制度与筹资三角决定什么被测量与被治疗；纵向项目救了命也造出平行系统，解法是嵌入而非取消。
- 通报是集体利益：惩罚早通报会制造隐瞒；因此《国际卫生条例》必须与援助和克制一起被遵守。
- 人力流动是本领域的道德核心：招聘守则要变成有约束的义务，而国内岗位与薪酬是同一问题的另一半。
- 疫情后的重建论证有三条腿：防范比损失便宜、卫生是经济基础设施、以及在下一个病原前最弱环节就是所有人的门槛。
:::

## 练习

::: exercise 读那张负担表 {level=1}
一张表显示某国“缺血性心脏病”死亡数二十年翻倍、而“下呼吸道感染”死亡数不变。请给出三种可能的解释、以及区分它们所需的三项数据。
::: solution
**读表的三个解释：一，人口增长与老龄化（死亡数上升可以是绝对数效应而年龄标化率下降）；二，诊断与登记质量的改善（院外与家庭死亡被更多地编码，尤其是传染病在低登记地区长期被低估）；三，真实的流行病学变化（高血压与糖尿病与吸烟与饮食的暴露移动，同时水的改善使感染死亡率停止下降）。区分所需的数据：年龄标化死亡率（与置信区间）、死因构成与“不明原因”与“症状性诊断”的比例随时间的变化、以及分病种的发病或住院与人群覆盖率的证据（如高血压控制率、糖尿病的患病率调查）；再补一条最诚实的：报告“用同一份登记、但按年龄别与地区别分层”的数字，因为标化率掩盖梯度——[[epidemiology-ebm/measuring-disease]]、[[public-health/determinants-inequalities]]。**
:::
:::

::: exercise 重新设计这门课 {level=2}
你要为本校医学生重设“全球卫生”课程，学员多数将在本国执业。给出目标、内容、教学法与你要拒绝的做法。
::: solution
**课程设计（[[#def-burden]]、[[#def-equity]]、[[medical-ethics-law/professionalism-regulation]]）：目标不是知识清单而是三种能力：读比较指标并知道其政治与局限；处理来自别处的患者（迁移健康、跨境病史、语言与文化、以及家族与社群的网络）；以及理解卫生系统如何塑造结局（筹资、人力、供应链、以及政策如何变成临床的每一天）。内容按连接而非按地理组织：从本地的健康不平等到世界的分配（同一条因果链）、从耐药与疫情与气候与疫苗到“为什么这与我明天的门诊有关”；伦理模块包括团结与捐助关系、以及研究伦理与利益申报（在高收入与低收入配对研究中的双重标准）——[[public-health/determinants-inequalities]]、[[microbiology/antimicrobials]]。教学法：本地数据作业（把本国各社区的差距与某国各区的差距并置）、以暴发与药品可及为案例的角色模拟、以及由患者与移民社区成员共同授课（不是作为故事而是作为教师）；短期海外实践只在有本地配对与长期伙伴关系与适当监督与反思时被纳入。你会拒绝的做法：把全球卫生变成慈善旅游与“手术队自我实现”的展示（它制造依赖与错误的技能）；以及把它当作只在“热带病周”出现的选修课（因此对未来的全科与内科与公共卫生从业者毫无影响）——[[public-health/global-health]]。**
:::

::: exercise 模拟一次通报 {level=2}
你所在国家发现一例经实验室确认的脊髓灰质炎疫苗衍生病毒；你的职责包括起草对外通报。写出通报中包含与不包含什么、以及为什么。
::: solution
**通报的起草（[[#def-machinery]]、[[#def-equity]]、[[public-health/communicable-disease-control]]）：包含：事件与证据（样本与测序与检出时间和地点、以及相关病例搜索的结果与已完成的接触者数量）；风险评估（覆盖率的真实数字、急性弛缓性瘫痪监测的灵敏度与废水监测的强度）；以及响应计划（补充免疫活动的范围与日期与目标人群与如何评估、以及国家应急日营与跨部门与跨境的协调）；还有承诺的更新节奏。不包含：对来源与责任的猜测（“某批次与某国传入”的推断会造成疫苗怀疑与对国家的惩罚性反应）、对旅行与贸易的限制性暗示（要明说《国际卫生条例》的建议是什么与克制原则）、以及“没有风险”的安慰（它不可信且在下一次检出时摧毁信任）。同时要在国内先讲：向临床医生与社区与媒体在同一天、以能理解的语言讲清“为什么在接种率高的国家会出现这个”（因为低覆盖的社群存在循环、以及口服疫苗衍生病毒的机制与停用口服疫苗的过渡逻辑）；并准备好被追问的数字（零剂次儿童数与免疫档案）——因为一次通报的真正考验是国内行动的速度，而不是文本的措辞——[[paediatrics/immunisation]]、[[clinical-skills/communication]]。**
:::
:::

::: exercise 审计一次器械引入 {level=2}
一个捐赠方为某国初级保健层免费配发一种新型电子诊断设备，三年后使用率低且维修停滞。请审计失败原因并提出条件。
::: solution
**技术引入的审计（[[#def-machinery]]、[[public-health/health-systems-economics]]、[[clinical-skills/medical-imaging]]）：典型的失败链：决策在别处做出（对本地最重的瓶颈没有对应）；缺乏耗材与试剂与电与网络的保障（以及无稳定的电力与温控）；缺乏培训与维护与备件（以及没有“修得起”的合同）；缺乏与转诊与治疗的连接（筛出病而无路径是伤害）；以及缺乏数据的所有权与用途（录入而无人读）。要审的证据：使用率的分布（哪些机构真的在用）以及停用时间与原因、停机时间的记录、维修的平均耗时与备件的成本、以及一次“总拥有成本”的核算（含人力与耗材与折旧与网络）。可写入合同的条件：与本国治疗指南与转诊绑定并纳入国家预算（把耗材成本列入基本药物与耗材清单）、以本地技术人员的培训与备件库为验收项、“零成本引入”的真实成本核算（以及政府是否能在捐赠结束后承担）、以及与本地数据系统与质量的挂钩——同时要有明确的退出与不采用的选择权（否则技术会占据注意力和台面而挤走人力与系统）。最后，问临床问题：在缺电缺人缺药的系统里，这台机器是不是当前边际收益最高的干预——多数情况下答案是否——[[public-health/prevention-promotion]]。**
:::

::: exercise 起草伙伴关系的条款 {level=3}
一所本国大学与三所高收入国家大学拟成立卫生研究伙伴。请起草条款：治理、资金、数据、署名、伦理与能力，并说明最常被违反的两条。
::: solution
**伙伴条款（[[#def-equity]]、[[medical-ethics-law/research-ethics]]、[[genetics/genomic-medicine]]）：治理：共同的项目负责人（而不是名义上的当地副手）、由双方共同决定的议程与提案筛选、以及以书面章程规定决策与投票与争议的解决；资金：明确的预算分配（包含本地人员的工资与间接费用与间接费用的真实分摊）、以及“不允许把全部经费留在富国机构”的比例下限与审计权；数据：材料转让协议与数据主权（样本与数据的所在地与访问权与再共享的规则、以及发表前对本地团队的强制先行阅读权）、以及利益分享（包括未来的专利与商业化）与社区回报的条款；署名与作者身份：按贡献的作者次序与对本地研究协调员的署名（他们常被写进致谢）、以及预印本与新闻稿的共同批准；伦理：双方伦理委员会与一个共同的社区咨询委员会、以及研究结束后干预的提供承诺（不要承诺无法维持的照护）；能力：培训与学位名额与设备的转移与维护、以及本地学者申请独立资助的“跳板”条款与共享的导师队伍。最常违反的两条是：数据与样本在伙伴未同意的情况下被再共享或用于二次分析（因为“合同上我们有权”）、以及发表策略由富国团队主导（时间、期刊、署名与媒体口径），使本地学者在晋升中拿不到第一作者——两者都源于同一点：治理与资金的不平等没有被条款纠正。要加的执行机制：年度公开的报告（按国别与性别的作者统计与经费流向）与一个“违反条款”的申诉路径——否则章程只是装饰品——[[public-health/global-health]]、[[clinical-skills/records-handover]]。**

::: exercise 回答病房 {level=2}
病房上两名住院患者被查出耐甲氧西林金黄色葡萄球菌与一种泛耐药的肠杆菌；一名来自国外的近期住院患者是携带者；护士问“我们是否该通知其他病房与其他医院”。请回答并给出依据。
::: solution
**跨境耐药的信息共享（[[#def-machinery]]、[[public-health/communicable-disease-control]]、[[infectious-diseases/healthcare-infections]]）：回答是：是。依据分三层：院内——多学科接触者筛查与环境清洁与接触隔离与专门的照护区域与手卫生依从的审计（以及共用设备的消毒与患者转运的记录）；院际——转诊网络的信息义务（接收携带者的下一家医院必须被告知，否则它无法在入院时就设防），以及本地卫生当局对“高优先级病原体”的法定或非法定通报，因为它驱动本地流行病学与经验性治疗政策；全球——耐药监测数据的通报是《国际卫生条例》核心能力与全球抗微生物耐药监测系统的一部分，因为新耐药机制会跨境传播且信息不对称使所有国家更脆弱——[[microbiology/antimicrobials]]、[[infectious-diseases/stewardship-outbreaks]]。方式：以事实与时间线通报，不以国籍与旅行史作为标签（“来自某国”在信息中几乎没有价值，却制造歧视并让人不再通报）；把风险沟通的对象与要点分开（员工需要操作改变、患者与家属需要个人风险与措施、社区需要“没有失控”的可信度）。同时把病房的问题当作系统的问题：筛查的触发规则（近期境外住院史是明确的入住筛查指征）、隔离房间的可用性与人员配置（这是隔离失败最常见的原因）、以及抗菌药物管理是否被纳入治疗决策（包括去殖民与是否清除定植的证据边界）——[[clinical-skills/patient-safety]]、[[medical-ethics-law/confidentiality]]。**
:::

::: exercise 给响应打分 {level=3}
疫情后，你被要求对某国的响应打分。写出你的评分框架、你需要区分“能力”与“表现”的三处、以及你会如何避免这份报告的副作用。
::: solution
**响应评分（[[#def-machinery]]、[[#def-equity]]、[[emergency-critical-care/major-incidents]]）：框架（按因果次序而不是按宣传顺序）：一，脆弱性基线（人口结构与合并症与老龄化和非正式住居与拥挤与多代同堂，因为它们决定了“同样的病毒”在不同国家的必然结局）；二，能力的证据（实验室与重症与人力与防护的常备、监测与测序、以及《国际卫生条例》评估的得分——注意自评的偏倚）；三，行动的速度与序列（从首例到社区传播之间的时间窗、非药物干预的时机、以及检测与追溯与隔离的可及性）；四，风险沟通的质量（一致、透明、有更新节奏、以及是否信任社区组织）；五，保护（经济与社会保护措施与对弱势群体的定向投入）；六，结果（每百万人口的超额死亡，它比确诊死亡率诚实得多）——这是唯一可用的终点。必须区分能力与表现的三处：高能力但低信任的国家（意大利北部与某些联邦制的对照，以及“最强的卫生系统”也可能失败）；低能力但组织良好的响应（若干低收入国家的经验与它们的年轻结构与早行动）；以及报告的滞后与死因定义（把没有检测到的死亡排除在外，会使最诚实的数字看起来最漂亮）。副作用及规避：一份排名的报告会被用于政治羞辱与对本国卫生部门的惩罚性削减、并把卫生工作者置于被指责的位置——所以只评“制度与决策”而不评“文化与国民性”；把不确定性写进方法（同一数据的不同建模者会得到不同排序）；公开数据与代码；以及把结论组织为可迁移的经验（早行动的价值、信任的价值、卫生人力与常备投入的价值）与对全球机制的改革建议（通报的激励、获取的公平、以及融资），而不是一张贴在各国身上的分数——[[public-health/global-health]]、[[public-health/determinants-inequalities]]。**

::: exercise 讲授转型 {level=1}
请给一群非医学背景的官员讲十五分钟的“双重负担”。用三个例子、一个数字、以及一条他们会反对的判断。
::: solution
**十五分钟（[[#def-burden]]、[[public-health/non-communicable-disease]]）：三个例子：同一家诊所里一位四十五岁女性因糖尿病足住院（她的糖尿病诊断来自一次结核随诊）；一座城市里五岁的喘息男孩与七十岁的慢阻肺老人同周入院；以及一个被“治好了”的镰状细胞病儿童在二十年后进入肾病门诊。一个数字：中低收入国家过早死亡中约八成来自慢性病，而其中多数发生在六十九岁以下——慢性病不是富人的病也不是老年人的病。一条他们会反对的判断：“我们的医院还没有准备好，所以我们先做感染控制、以后再做慢性病”是错的——不是因为慢性病更重要，而是因为它们共用同一套系统：缺人缺药缺记录的初级保健既不能完成儿童的免疫也不能管理血压；而当城市的成人开始死于卒中与心梗时，被削弱的正是那个曾经赢得感染的系统。政策含义：把投资放在同一批基础能力上（人、基本药物与耗材的连续供应、记录与实验室、以及社区的可及性），并拒绝“项目”与“系统”的二选一——这既是最便宜的路径，也是最难的政治决定，因为它要求预算在两个部门之间被同一批人共同负责——[[public-health/health-systems-economics]]、[[public-health/prevention-promotion]]。**
