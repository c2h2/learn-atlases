2024年，估计有490万名儿童在五岁生日之前死亡，其中近一半死于出生后第一个月。大多数死因在英国儿童中很少见：早产并发症、分娩过程中的问题、肺炎、腹泻和疟疾。2023年，约有26万名妇女死于妊娠和分娩并发症，其中约70%在撒哈拉以南非洲。凭借已经存在了几十年的知识和技术，这些死亡几乎都是可以预防的。全球卫生关注的正是它们为何仍在发生，以及能做些什么。

**全球卫生**是致力于改善全世界所有人的健康、实现健康公平的研究和实践，关注跨越国界的问题以及健康和疾病的全球性原因。它以健康的决定因素（[[public-health/determinants-inequalities]]）为基础，并把它们应用于国家之间。本章介绍全球疾病负担如何测量以及如何变化、孕产妇和儿童健康、主要传染病和抗微生物药物耐药性、“同一健康”、全球卫生的各类机构、全民健康覆盖以及可持续发展目标。

## 测量全球疾病负担 {#burden}

比较不同疾病的负担，需要一个把死亡和残疾结合起来的指标。5岁时死亡和85岁时死亡都是一例死亡，但前者损失的生命要多得多；而抑郁、腰痛和听力损失等疾病很少致死，却带来大量痛苦。

::: definition 伤残调整生命年 {#def-daly}
一个**伤残调整生命年**（DALY）是损失的一年健康生命。某一疾病造成的DALY是以下两项之和：

- 过早死亡造成的**寿命损失年**（YLL）：每例死亡按标准寿命表取其死亡年龄的剩余预期寿命；
- **伤残生存年**（YLD）：患病人数乘以介于0（完全健康）和1（相当于死亡）之间的**伤残权重**，再乘以病程。

$$
\text{DALY} = \text{YLL} + \text{YLD}.
$$ {#eq-daly}

DALY是**全球疾病负担**（GBD）研究的主要指标。该研究由健康指标与评估研究所协调，对200多个国家和地区的死亡、疾病和危险因素进行估计。
:::

DALY衡量的是损失的健康；[[public-health/health-systems-economics]]中讨论的、用于经济学评价的**质量调整生命年**（QALY）衡量的是获得的健康。两者都建立在价值判断之上：伤残权重来自对公众的调查，而使用统一的标准预期寿命意味着把每一年生命在任何地方都视为同样宝贵。批评者认为，伤残权重可能显得贬低了残疾人的生命，并且忽视了残疾的社会背景。

::: example 计算DALY {#ex-daly}
在某国，一种疾病每年导致100例死亡，死亡年龄都在40岁左右；40岁时的标准剩余预期寿命为45年。同一年，有1,000人患该病的非致死型，伤残权重为0.2，平均持续5年。计算该年新发病例的DALY。
::: solution
YLL$= 100 \times 45 = 4{,}500$。

YLD$= 1{,}000 \times 0.2 \times 5 = 1{,}000$。

DALY$= 4{,}500 + 1{,}000 = 5{,}500$。

这里的负担大部分来自过早死亡。对于偏头痛或抑郁症这样的疾病，情况会相反：死亡很少，但YLD很多。GBD的早期版本还对未来年份进行贴现，并按年龄对生命年加权；现行版本两者都不做。
:::
:::

### 流行病学转变 {#transition}

::: theorem 流行病学转变 {#thm-transition}
随着国家经济和社会的发展，疾病模式从以传染病、孕产妇和新生儿疾病以及营养不良为主（主要导致儿童和青年死亡），转向以非传染性疾病和伤害为主（主要导致老年人死亡）。预期寿命上升，主要死因发生变化。这一转变伴随着**人口转变**：死亡率下降之后，经过一段滞后，生育率也随之下降，因此人口先快速增长，然后老龄化。
:::

::: proof
奥姆兰（Abdel Omran）于1971年把这一转变描述为三个阶段：“瘟疫与饥荒时代”、“大流行消退时代”和“退行性疾病与人为疾病时代”。其机制已为人们充分了解。更好的营养、清洁的水和卫生设施、住房、教育（尤其是女性教育）、疫苗接种和医疗照护减少了感染导致的死亡，主要是儿童的死亡。更多的儿童存活到成年和老年，而心血管疾病、癌症和其他NCD的风险在老年最高。与此同时，城市化和经济变化改变了饮食、身体活动以及烟草和酒精的使用。儿童死亡率下降、教育改善以及获得避孕手段使家庭生育的孩子减少，因此人口老龄化。
:::

这一转变既不均匀，也不是必然的。许多低收入和中等收入国家现在面临**双重负担**：传染病以及孕产妇和儿童疾病仍然常见，而NCD迅速上升，发病年龄往往更小，获得治疗的机会也比高收入国家少。20世纪90年代，HIV使南部非洲预期寿命的提高出现逆转；2020—2021年，新冠使许多国家的预期寿命下降。在任何一个国家内部，较贫困群体在转变中所处的阶段都比富裕群体更早。

::: widget plot
f: 50 + 6*ln(x)
x: 1, 100
y: 40, 90
labels: \text{预期寿命（岁，示意）}
points: 2, 54.2; 50, 73.5
caption: 一条示意性的“普雷斯顿曲线”：在低收入水平，预期寿命随国民收入急剧上升，在高收入水平趋于平缓（这里用一个简单模型50 + 6 ln x，x为每人每年的收入，单位为千美元）。在低收入水平，资源的少量增加就能换来巨大的健康收益；在高收入水平，资源如何分配和使用比资源多少更重要。真实的国家在这样一条曲线周围分布得很分散，而且随着知识和技术的传播，整条曲线随时间向上移动。
:::

## 孕产妇、新生儿和儿童健康 {#mch}

::: definition 孕产妇和儿童死亡指标 {#def-mmr}
- **孕产妇死亡**是指妇女在妊娠期间或妊娠结束后42天内，由于任何与妊娠或其处理有关或因其加重的原因死亡，但不包括意外或偶然原因。
- **孕产妇死亡率**（MMR）是一个时期内每10万活产的孕产妇死亡数。
- **孕产妇死亡终生风险**把MMR与生育率结合起来：一名15岁女性最终死于孕产原因的概率。
- **5岁以下儿童死亡率**是5岁之前死亡的概率，以每1,000活产计。**新生儿死亡率**是出生后28天内死亡的概率，以每1,000活产计。
:::

据世卫组织数据，2023年约有26万例孕产妇死亡，全球MMR为每10万活产197例，约70%的死亡发生在撒哈拉以南非洲。主要原因是出血（尤其是产后出血）、妊娠期高血压疾病（子痫前期和子痫）、脓毒症、不安全流产的并发症和梗阻性分娩，以及疟疾、HIV和既往心脏病等间接原因。可持续发展目标3.1的目标是到2030年全球MMR低于每10万活产70例；世卫组织指出，这需要每年近15%的下降速度，远快于近年的进展。

2024年，490万名儿童在5岁之前死亡，其中230万（47%）为新生儿。主要原因包括早产并发症、产时并发症（出生窒息和产伤）、肺炎、腹泻和疟疾，营养不良是很大一部分死亡的潜在因素。可持续发展目标3.2旨在消除可预防的新生儿和5岁以下儿童死亡，到2030年，所有国家的新生儿死亡率降至每1,000活产12例或以下，5岁以下儿童死亡率降至每1,000活产25例或以下。

有效的干预措施众所周知且价格低廉：

- **妊娠前和妊娠期**：计划生育、产前检查、铁剂和叶酸、破伤风疫苗接种、预防妊娠期疟疾（长效驱虫蚊帐、间歇性预防治疗），以及预防HIV和梅毒的母婴传播。
- **分娩时**：熟练接生人员、清洁分娩、获得产科急救（包括剖宫产和输血）、第三产程积极处理和使用宫缩剂（如缩宫素）预防出血，以及用硫酸镁治疗子痫。
- **新生儿**：新生儿复苏、早期和纯母乳喂养、保暖护理（包括对小婴儿的“袋鼠式”皮肤接触护理）以及新生儿感染的治疗。
- **儿童**：疫苗接种、用口服补液盐和锌治疗腹泻、用抗生素治疗肺炎、长效驱虫蚊帐和及时治疗疟疾、安全的水和卫生设施，以及营养不良的预防和治疗。

::: example 三个延误 {#ex-three-delays}
一位住在农村地区的24岁女性在家中生下第三个孩子后发生产后出血。她的家人等了几个小时才决定求助；借来的摩托车花了四个小时才把她送到县医院；医院里没有血，唯一的医生正在手术室。她死了。用“三个延误”模型分析她的死亡，并提出每个层面的干预措施。
::: solution
**三个延误模型**（Thaddeus和Maine，1994年）指出了以下三方面的延误：(1) 决定寻求照护，(2) 到达医疗机构，以及(3) 到达后获得适当的照护。

**延误1：决定寻求照护。** 原因包括不了解危险征象、决定权掌握在家中其他人手里、费用以及以往不好的就医经历。干预措施：分娩准备计划、关于危险征象的社区教育、妇女小组、取消使用者付费，以及尊重的孕产照护，使妇女愿意使用服务。鼓励在有熟练接生人员的机构分娩，可以完全避免这种情况。

**延误2：到达照护机构。** 原因：距离、道路、缺乏交通工具和钱。干预措施：医院附近的待产之家、社区紧急转运计划、救护车服务，以及更多能够处理急症的医疗机构。

**延误3：获得适当照护。** 原因：缺乏人员、血液、药品（缩宫素、米索前列醇）、设备和技能。干预措施：县级产科急救、输血服务、基本药物供应链、培训，以及孕产妇死亡评审并根据评审结果采取行动。

此外，在分娩时进行预防（用宫缩剂积极处理第三产程）本可大大降低她发生出血的风险。她的死亡反映的是整个系统的失败，而不是某一个时刻的失败。
:::
:::

::: example 终生风险 {#ex-lifetime-risk}
在一个国家，MMR为每10万活产200例，妇女平均生育5次。在另一个国家，MMR为每10万活产10例，妇女平均生育1.6次。在不考虑其他原因死亡的情况下，估计两国孕产妇死亡的终生风险，并各以“N分之一”表示。
::: solution
每次分娩的风险：$0.002$和$0.0001$。

**第一个国家。** 终生风险$\approx 1 - (1 - 0.002)^5 = 0.00996$，约为100分之一。

**第二个国家。** 终生风险$\approx 1 - (1 - 0.0001)^{1.6} = 0.00016$，约为6,250分之一。

终生风险的差异（约60倍）大于MMR的差异（20倍），因为第一个国家的妇女面临这一风险的次数更多。因此，计划生育既通过减少妊娠次数，也通过避免高危和意外妊娠来降低孕产妇死亡率。
:::
:::

## 传染病与抗微生物药物耐药性 {#infections}

HIV、结核病和疟疾仍是全球主要死因，集中在撒哈拉以南非洲和南亚。21世纪初以来的大型全球项目，包括全球抗击艾滋病、结核病和疟疾基金（2002年）和美国总统防治艾滋病紧急救援计划（PEPFAR，2003年），扩大了抗逆转录病毒治疗、长效驱虫蚊帐和结核病治疗的覆盖，死亡人数大幅减少。随着新冠大流行的消退，结核病再次成为全球单一传染病中的首要死因。进展是脆弱的：2025年国际资金的削减，包括美国国际开发署（USAID）的解散，扰乱了许多国家的HIV、结核病、疟疾和营养项目。

**被忽视的热带病**（如血吸虫病、土源性蠕虫病、淋巴丝虫病、盘尾丝虫病、沙眼、利什曼病和毒蛇咬伤中毒）影响着世界上十多亿最贫困的人。其中许多通过群体药物治疗和改善水和卫生设施得到控制，若干国家已消除了其中一种或多种作为公共卫生问题的疾病。

**消灭。** 天花于1980年被消灭。自1988年全球根除脊髓灰质炎行动启动以来，野生脊髓灰质炎病毒病例已减少99%以上，野生脊髓灰质炎病毒目前仅在阿富汗和巴基斯坦仍有地方性流行，不过其他地方仍会发生循环疫苗衍生脊髓灰质炎病毒的暴发。麦地那龙线虫病（几内亚线虫病）在没有任何疫苗或药物的情况下，通过安全饮水和行为改变已接近消灭。相关原理见[[public-health/vaccination-programmes]]。

### 抗微生物药物耐药性 {#amr}

凡是使用抗微生物药物的地方都会产生抗微生物药物耐药性（AMR）：在人类医学中，在动物中（用于治疗，在某些国家还用于促生长），以及在农业中。耐药菌和耐药基因在人、动物和环境之间传播，并通过旅行、贸易和食品跨越国界。一项针对2019年的系统分析（GRAM研究，2022年发表于《柳叶刀》）估计，细菌AMR直接导致约127万人死亡，与约495万人死亡相关，撒哈拉以南非洲和南亚的死亡率最高。在较贫穷的国家，问题往往既有不当使用过多，也有有效抗生素可及性太低。

应对需要监测、感染预防（包括水、卫生设施和疫苗接种，它们减少了对抗生素的需求）、人类和动物卫生中的抗微生物药物管理、对无处方销售的监管，以及新的抗微生物药物；而新药需要新的经济模式，因为新的抗生素应当尽量少用。英国通过一种与销量无关的订阅模式为某些新抗生素付费。

::: definition 同一健康 {#def-one-health}
**同一健康**（One Health）是一种综合方法，它认识到人类、家养和野生动物、植物以及更广泛环境的健康紧密相连、相互依存，旨在同时平衡和优化所有这些方面的健康。它由**四方**组织推动：联合国粮食及农业组织（FAO）、联合国环境规划署（UNEP）、世卫组织和世界动物卫生组织（WOAH）。
:::

人类新发传染病中约四分之三是人畜共患病，包括HIV、埃博拉、禽流感、SARS、MERS，SARS-CoV-2也很可能是。其出现由森林砍伐、土地用途改变、集约化养殖、野生动物贸易和气候变化驱动。“同一健康”方法包括对动物和人类疾病的联合监测、对狂犬病和布鲁氏菌病等人畜共患病的协调控制、减少家畜的抗微生物药物使用，以及环境保护。

## 全球卫生的机构 {#institutions}

- **世界卫生组织**（成立于1948年）是联合国负责卫生的专门机构。其管理机构世界卫生大会每年5月召开；其职能包括制定规范和标准（如基本药物清单和治疗指南）、根据《国际卫生条例》协调突发卫生事件的应对、对药品和疫苗进行资格预审，以及支持各国。其预算大部分来自捐助方指定用于特定目的的自愿捐款，这限制了它的独立性。历史上最大的出资国美国退出了世卫组织，自2026年1月起生效。
- **其他联合国机构**：联合国儿童基金会（儿童健康、疫苗采购）、联合国艾滋病规划署、联合国人口基金（生殖健康）以及世界银行（融资和卫生系统贷款）。
- 针对特定问题的**全球卫生行动**：全球疫苗免疫联盟**Gavi**（2000年），为低收入国家的疫苗提供资金；以及**全球基金**（2002年）。
- **双边捐助方**，如英国外交、联邦和发展事务部；英国政府于2025年宣布，到2027年官方发展援助将从国民总收入的0.5%降至0.3%。
- **慈善基金会**，特别是盖茨基金会和惠康基金会，它们塑造着研究和政策的优先事项。
- **非政府组织**、学术机构，以及低收入和中等收入国家自身的政府和卫生系统，在大多数国家，后者提供了大部分卫生支出。

这一架构受到的批评包括：碎片化（行动众多，各有各的报告要求）；捐助方驱动的优先事项偏重单一疾病而非卫生系统；以及权力失衡，影响低收入和中等收入国家的决定却在高收入国家作出。“去殖民化”全球卫生的呼声要求把领导权、资金决策、研究署名和议程设置转移给受影响最大的国家和社区。

卫生安全由**《国际卫生条例（2005）》**（2024年修订，2025年9月起生效）和2025年5月通过的**《世卫组织大流行协定》**管理；两者在[[public-health/communicable-disease-control]]中介绍。

## 全民健康覆盖与可持续发展目标 {#uhc}

::: definition 全民健康覆盖 {#def-uhc}
**全民健康覆盖**（UHC）是指所有人都能在需要的时间和地点获得所需的全方位优质卫生服务，而不会陷入经济困难。它有三个维度，常画成一个立方体：覆盖**谁**（人口比例）、覆盖**哪些服务**，以及覆盖**多大比例的费用**。

**灾难性卫生支出**通常定义为家庭自付卫生支出超过家庭总消费或收入的10%（或按更严格的定义为25%）。**致贫性**卫生支出是使家庭跌至贫困线以下的支出。
:::

**《阿拉木图宣言》**（1978年）呼吁通过**初级卫生保健**实现“人人享有卫生保健”，《阿斯塔纳宣言》（2018年）重申了这一承诺。UHC是联合国会员国于2015年9月通过、以2030年为期限的**可持续发展目标**的具体目标3.8。可持续发展目标3（“确保健康的生活方式，促进各年龄段人群的福祉”）包括以下具体目标：孕产妇、新生儿和儿童死亡（3.1、3.2），艾滋病、结核病、疟疾和被忽视的热带病的流行（3.3），NCD和精神健康（3.4），物质使用（3.5），道路交通伤害（3.6），性和生殖健康（3.7），UHC（3.8），以及污染（3.9）。许多其他目标，如贫困、饥饿、教育、性别平等、水和卫生设施以及气候，都是健康的决定因素。

在就医时自掏腰包付费会阻碍人们寻求照护，每年都使数以百万计的家庭陷入贫困。在UHC方面取得进展的国家，一般都增加了公共筹资（来自税收或强制性保险）、在全人群中分担风险，并取消或减少了使用者付费，特别是针对贫困人口和孕产妇及儿童健康等优先服务。筹资模式的比较见[[public-health/health-systems-economics]]。

::: example 灾难性卫生支出 {#ex-catastrophic}
一个家庭每月消费200美元。一个孩子因肺炎住院，这个家庭当月支付了30美元的费用、药费和交通费。按10%的阈值，这是否属于灾难性支出？按25%的阈值呢？这个家庭可能不得不放弃什么？
::: solution
占消费的比例$= 30/200 = 15\%$。这超过了10%的阈值，但未超过25%的阈值。

一个把大部分收入花在食物和住房上的家庭，可能要通过变卖资产（牲畜、工具）、借高利贷、让孩子辍学或减少食物摄入来支付这类费用，而每一种做法都会损害健康和未来收入。基于支出的指标还漏掉了那些因付不起钱而放弃照护的家庭。这就是为什么UHC监测同时使用服务覆盖和经济保护两类指标。
:::
:::

::: warning 平均数掩盖了被落下的人
实现全球目标的国家进展可能掩盖巨大的差距。一个国家的全国平均5岁以下儿童死亡率可以低于每1,000活产25例，而农村、较贫困和少数群体的死亡率仍远高于此；全国疫苗接种覆盖率可以很高，而“零剂次”儿童集中在城市贫民窟、偏远地区和冲突地区。可持续发展目标“不让任何一个人掉队”的原则要求按收入、性别、年龄、地点、族群、残疾和移民身份分列数据。正如前面各章所示，同样的警示也适用于英国。
:::

## 移民、冲突与人道主义危机 {#humanitarian}

全世界有超过1亿人因冲突、迫害和灾害而被迫流离失所。冲突摧毁医疗设施，杀害卫生工作者，导致麻疹和霍乱暴发、营养不良以及慢性病得不到治疗。人道主义卫生的优先事项（载于“环球计划”标准）包括水、环境卫生和个人卫生，食物和营养，住所，疫苗接种（尤其是麻疹），传染病控制，性和生殖健康，精神健康和心理社会支持，以及慢性病照护的连续性。攻击医疗卫生设施和人员违反国际人道法。

抵达英国等高收入国家的移民，其卫生需求一般与当地人口相似，但也有一些特殊需求：疫苗接种不完整、在原籍国常见的感染（如结核病、乙型和丙型肝炎、HIV），以及难民和寻求庇护者遭受创伤的影响。获得照护的障碍包括语言、费用（对海外访客收取部分NHS服务费用）、对移民执法的恐惧以及不熟悉卫生体系。在英格兰，无论移民身份如何，每个人都可以在全科医生处登记。

::: quiz
关于全球疾病负担，下列哪一项是正确的？
- [ ] 非传染性疾病主要是高收入国家的问题。
- [ ] DALY只衡量死亡。
- [x] 非传染性疾病导致的过早死亡大部分发生在低收入和中等收入国家。
- [ ] 流行病学转变在每个国家都以相同的速度发生。
::: solution
世卫组织估计，82%的NCD过早死亡（70岁以前）发生在低收入和中等收入国家，那里的人往往在更年轻时患上NCD，获得治疗的机会也更少。DALY把死亡造成的寿命损失年与伤残生存年结合起来。转变在国家之间和国家内部差异很大，许多国家面临传染病和非传染性疾病的双重负担。
:::

::: history
1851年在巴黎开始的国际卫生会议试图就防范霍乱、鼠疫和黄热病的检疫规则达成一致，并促成了最早的国际卫生机构。世界卫生组织于1948年4月7日成立，这一天现在被定为世界卫生日。世卫组织的天花消灭规划于1967年加强，1977年索马里出现最后一例自然病例，1980年宣布消灭天花。《阿拉木图宣言》（1978年）把初级卫生保健作为实现“2000年人人享有卫生保健”的途径。口服补液疗法被《柳叶刀》在1978年称为可能是本世纪最重要的医学进展，它和联合国儿童基金会在20世纪80年代发起的“儿童生存革命”大大减少了腹泻导致的儿童死亡。千年发展目标（2000—2015年）为儿童和孕产妇死亡以及HIV、结核病和疟疾设定了目标，第一项全球疾病负担研究于20世纪90年代发表。可持续发展目标于2015年取而代之，全民健康覆盖处于其核心。
:::

::: summary
- **DALY**把寿命损失年与伤残生存年结合起来；全球疾病负担研究用它在各国之间比较疾病和危险因素。
- **流行病学转变**使负担从感染、孕产妇和儿童疾病以及营养不良转向NCD；许多国家面临**双重负担**。
- 2023年约有26万名妇女死于孕产原因（MMR为每10万活产197例，约70%在撒哈拉以南非洲）；2024年有490万名儿童在5岁前死亡，47%为新生儿。可持续发展目标的目标是到2030年MMR低于70，新生儿死亡率不超过每1,000活产12例，5岁以下儿童死亡率不超过25例。
- **三个延误**（决定、到达、获得照护）解释了孕产妇死亡；在妊娠、分娩和儿童期都有有效而廉价的干预措施。
- 野生脊髓灰质炎仅在阿富汗和巴基斯坦仍有地方性流行。2019年**AMR**直接导致约127万人死亡。**同一健康**把人类、动物和环境健康联系起来。
- 全球卫生机构包括世卫组织、联合国儿童基金会、世界银行、Gavi和全球基金；它们的资金和权力存在争议，并处于变动之中。
- **全民健康覆盖**（可持续发展目标3.8）：每个人都能获得所需的服务而不陷入经济困难；自付费用导致灾难性和致贫性支出。
:::

## 习题

::: exercise 孕产妇死亡率 {level=1 check="200"}
某国一年中记录了500例孕产妇死亡和25万例活产。计算每10万活产的孕产妇死亡率。
::: solution
$500/250{,}000 \times 100{,}000 = 200$/10万活产。
:::
:::

::: exercise 寿命损失年 {level=1 check="3000"}
一种疾病导致60名儿童死亡，每例死亡年龄的标准剩余预期寿命为50年。计算寿命损失年。
::: solution
YLL$= 60 \times 50 = 3{,}000$年。
:::
:::

::: exercise 伤残生存年 {level=1 check="1200"}
四千人患有一种伤残权重为0.1、平均持续3年的疾病。计算YLD。
::: solution
YLD$= 4{,}000 \times 0.1 \times 3 = 1{,}200$。
:::
:::

::: exercise 新生儿死亡所占比例 {level=2 check="round(1000*2.3/4.9)/10"}
2024年，490万名儿童在5岁前死亡，其中230万死于出生后28天内。5岁以下儿童死亡中新生儿死亡占百分之多少？保留1位小数。
::: solution
$2.3/4.9 = 0.469$，即46.9%（世卫组织报告为47%）。随着儿童死亡率下降，新生儿期死亡所占比例上升，因为针对较大儿童肺炎、腹泻和疟疾的干预比针对新生儿的干预更为成功，后者取决于分娩时的照护质量。
:::
:::

::: exercise 灾难性支出 {level=2 check="25"}
一个每月消费160美元的家庭，为一名患糖尿病的家庭成员花费40美元购买药品。这占消费的百分之多少？按25%的阈值是否属于灾难性支出？
::: solution
$40/160 = 25\%$。恰好达到25%的阈值（远高于10%的阈值）。需要终身服药的慢性病会造成反复支出，对家庭财务的损害尤其大。
:::
:::

::: exercise 终生风险 {level=2 check="round(1/(1-(1-0.004)^6))"}
在某国，MMR为每10万活产400例，妇女平均生育6次。以“N分之一”估计孕产妇死亡的终生风险，N取整数。
::: solution
每次分娩的风险$= 0.004$。终生风险$= 1 - (1 - 0.004)^6 = 0.0238$。$N = 1/0.0238 = 42$。约每42名妇女中有1人死于孕产原因。
:::
:::

::: exercise 实践中的“同一健康” {level=3}
某畜牧业正在扩张的农村地区报告了一种人畜共患病（如布鲁氏菌病或禽流感）的人间病例增加。描述一项“同一健康”应对措施。
::: solution
**联合监测。** 在人类和动物卫生服务及实验室之间共享数据；检测家畜，必要时也检测野生动物；利用基因组数据把人和动物的分离株联系起来。

**在动物源头控制。** 为家畜接种疫苗（布鲁氏菌病），在适当时进行扑杀和移动控制（禽流感），加强农场生物安全，并设立补偿计划，使农民愿意报告而不是隐瞒疫情。

**阻断向人的传播。** 牛奶巴氏消毒和安全的食品处理（布鲁氏菌病），为农场和屠宰场工人提供防护装备，以及公众宣传。

**人类健康。** 诊断和治疗、接触者随访，在推荐时为暴露工人提供抗病毒药物和季节性流感疫苗，如有国际传播风险，根据《国际卫生条例》进行通报。

**环境和驱动因素。** 应对土地用途改变、养殖集约化和与野生动物的接触；减少家畜的抗微生物药物使用。

**治理。** 在卫生、农业和环境部门之间建立协调机制，制订共同的计划和预算。
:::
:::

::: exercise 一个县的优先事项 {level=3}
一个农村县的5岁以下儿童死亡率为每1,000活产60例，MMR为每10万活产350例，有一小笔额外预算。提出并论证三项优先事项。
::: solution
只要以有效性、成本和公平性的证据为基础，许多答案都是合理的。例如：

1. **分娩时的熟练照护以及产科和新生儿急救。** 孕产妇和新生儿死亡中都有很大一部分发生在分娩前后。加强县医院的能力（人员、血液、宫缩剂、硫酸镁、剖宫产、新生儿复苏、袋鼠式护理），并提供交通和待产之家，可以解决第二和第三个延误，使母亲和婴儿同时受益。

2. **儿童疾病的社区病例管理。** 经过培训、配备物资的社区卫生工作者能够在离家近的地方治疗肺炎（抗生素）、腹泻（口服补液盐和锌）和疟疾（快速诊断检测和以青蒿素为基础的联合疗法），从而在远离医疗机构的地方应对新生儿期以后的主要死因。

3. **疫苗接种和预防。** 为“零剂次”儿童提供常规疫苗接种，发放长效驱虫蚊帐，支持母乳喂养、营养和计划生育。

取消孕产妇和儿童服务的使用者付费将对这三项都有支持作用。应使用按地区和财富分列的数据监测进展，并对孕产妇和围产期死亡进行评审，以指导改进。
:::
:::
