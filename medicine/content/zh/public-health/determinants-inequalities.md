两个婴儿在同一天出生于英格兰的同一座城市，相距只有几英里。一个出生在全国最贫困的十分之一社区，另一个出生在最不贫困的十分之一社区。按目前的数据，第二个婴儿的预期寿命要长好几年，而且在健康状态下度过的年数要多出将近二十年。这两个孩子都还没有见过医生。差别早已写进了他们将要成长的地方、家庭拥有的钱、将要就读的学校和将来从事的工作之中。

公共卫生正是从这一观察出发的。医疗照护固然重要，但人群之间健康差异的大部分来自人们出生、成长、生活、工作和老去的环境条件。本章解释这些条件是什么、它们如何“进入身体”、健康不平等如何测量，以及哪些行动能够减少不平等。所用的指标与[[epidemiology-ebm/measuring-disease]]中介绍的相同，只是用于社会群体之间的比较。

## 什么决定健康 {#determinants}

::: definition 健康及其决定因素 {#def-determinants}
世界卫生组织《组织法》（1948年）把**健康**定义为“身体、精神和社会适应上的完好状态，而不仅仅是没有疾病或虚弱”。这一定义常被批评为无法达到，但它强调了健康不只是没有诊断。

**健康决定因素**是影响个人和人群健康的因素，通常分为：

- 固定的个人因素：年龄、性别和基因；
- 个人行为：吸烟、饮食、身体活动、饮酒和药物使用、性行为；
- 社会和社区网络：家庭、朋友、社区支持、社会隔离；
- 生活和工作条件：收入、教育、就业和工作条件、住房、食物、水和卫生设施、交通，以及获得卫生和社会照护的机会；
- 总体的社会经济、文化和环境条件：经济、税收和福利、法律、文化和自然环境。

**健康的社会决定因素**是后三组中的非医学因素，以及塑造这些因素的权力、金钱和资源的分配。
:::

这些层次最著名的图示是达尔格伦（Göran Dahlgren）和怀特黑德（Margaret Whitehead）于1991年发表的“彩虹”模型。个人位于中心，带有年龄、性别等固定因素。其外依次是生活方式、社会网络、生活和工作条件，最外层是更宏观的社会经济、文化和环境条件。这个模型的用处在于说明：临床医生谈得最多的行为这一层，被外层包围并受其塑造。人们是在收入、社区、工作和文化的约束下吸烟、进食和饮酒的。

每一层对健康的贡献有多大？已有若干分析尝试分摊，常得出的结论是医疗照护只占健康结局变异的少部分，也许为10%～20%，其余大部分由行为以及社会经济因素决定。这些数字很粗略，取决于问题的提法，不应被当作精确值引用。可靠的是定性的结论：仅靠改善医疗照护，无法消除群体之间巨大的健康差异。

### 社会条件如何“进入身体” {#pathways}

说收入“导致”心脏病，需要有机制。通常描述四类途径，它们共同起作用。

- **物质途径。** 低收入限制了获得良好住房、健康食物、取暖、安全社区和交通的机会。寒冷潮湿的住房加重呼吸系统和心血管疾病。拥挤助长感染传播。危险的工作造成伤害和职业病。
- **心理社会途径。** 不稳定的工作、债务、对自身生活缺乏控制以及歧视会造成慢性应激。下丘脑-垂体-肾上腺轴和交感神经系统的反复激活会升高血压、加重胰岛素抵抗并促进炎症。慢性应激累积造成的“磨损”称为**稳态负荷**（allostatic load）。
- **行为途径。** 吸烟、不良饮食、缺乏身体活动和有害饮酒在贫困群体中更常见，部分原因是这些东西更便宜、在较贫困地区营销更密集，或被用来应对压力。因此，行为在一定程度上是社会地位的结果，而不单纯是自由选择。
- **生命历程途径。** 不利处境会累积。低出生体重、营养不良和童年不良经历的影响会持续到成年，一个时期的不利处境使下一个时期更可能处于不利。

获得医疗照护是第五条途径，但在使用时免费的体系中，它只能解释梯度的一部分。

## 社会梯度 {#gradient}

::: theorem 健康的社会梯度 {#thm-gradient}
健康在整个社会阶层中呈梯度分布，而不是分成健康差的少数和健康的多数。收入、教育、职业等级或社区贫困程度每上升一级，平均健康状况就更好，预期寿命就更长。这一梯度适用于大多数死因，几乎在所研究的每个国家都成立。
:::

::: proof
最清楚的证据来自对英国公务员的白厅研究（Whitehall studies）。所有参与者都有稳定的办公室工作，并能使用国民医疗服务体系（NHS），因此绝对贫困和缺乏医疗照护不能解释他们之间的差别。在1967年开始的第一次白厅研究中，最低职级的男性在随后十年的死亡率约为最高职级男性的三倍，而且每一级的死亡率都高于其上一级。经典危险因素（吸烟、血压、胆固醇）只能解释冠心病死亡差异的一部分。

1985年在马默特（Michael Marmot）主持下开始的白厅二期研究纳入了女性，并测量了工作中的心理社会环境。工作中控制感低可独立于职级和常规危险因素预测冠心病。这些研究共同表明，除物质匮乏之外，相对地位以及与之相伴的控制感和安全感也影响健康。
:::

梯度对政策有重要影响。如果只有最贫困群体健康较差，政策就可以只针对这一群体。由于梯度贯穿每个人，额外疾病负担的大部分落在分布中间的大量人群身上，政策必须作用于全体人群，并随着不利程度增加而加大力度。马默特2010年为英格兰所作的评估把这称为**比例普惠主义**（proportionate universalism）。

## 不平等、不公平及其测量 {#measuring}

::: definition 健康不平等与健康不公平 {#def-inequity}
**健康不平等**是群体之间任何可测量的健康差异：按年龄、性别、地区、收入、族群或其他特征划分。有些不平等不可避免：老年人比年轻人患病更多。

**健康不公平**是可避免的、不必要的且不公正的健康差异（怀特黑德于1990年给出的定义）。由社会和经济条件造成的差异属于不公平，因为它们可以改变。

在英国的用法中，“健康不平等”常被用来指不公平的差异，因此读者必须弄清所指的是哪种含义。
:::

健康不平等通常同时沿几个维度描述。在英格兰，NHS和公共卫生机构使用社会经济贫困程度（按地区测量）、受保护特征（如族群、性别、残疾和性取向）、地理位置（例如沿海城镇），以及**包容性健康**群体：无家可归者，吉卜赛人、罗姆人和旅行者社区，性工作者，与司法系统有接触的人，处境脆弱的移民，以及有药物或酒精依赖的人。包容性健康群体的死亡率往往是一般人群的许多倍，而常规数据很难反映他们的情况。

### 测量贫困程度 {#imd}

贫困程度通常按小区域而非个人测量，因为常规卫生数据很少记录收入。在英格兰，**多重贫困指数**（Index of Multiple Deprivation，IMD）综合了七个领域：收入、就业、教育和技能、健康和残疾、犯罪、获得住房和服务的障碍，以及居住环境。每个小区域（约1,500人的下层超级输出区，LSOA）从最贫困到最不贫困排序，再分为五等份（五分位组）或十等份（十分位组）。苏格兰、威尔士和北爱尔兰有各自的指数。

地区指标实用但不完善。贫困地区的人并非都贫困，许多贫困者住在混合地区。把一个地区的特征赋予个人，有犯**生态学谬误**的风险。

### 简单指标：差值与比值 {#gap-ratio}

最简单的比较使用两个群体，通常是最贫困组和最不贫困组。

- **率差**（绝对差距）是不利群体的率减去有利群体的率。
- **率比**（相对差距）是不利群体的率除以有利群体的率。

两个指标可以朝相反方向变化。如果两组死亡率按相同比例下降，比值不变而绝对差距缩小。如果两组下降相同的绝对量，差距不变而比值扩大。报告应同时给出二者。

::: example 绝对差距与相对差距 {#ex-gaps}
2010年，某地区最贫困五分位组的年龄标化心血管病死亡率为每年300/10万，最不贫困五分位组为150/10万。到2020年，两者分别为200/10万和90/10万。不平等是缩小了还是扩大了？
::: solution
2010年：率差$= 300 - 150 = 150$/10万；率比$= 300/150 = 2.0$。

2020年：率差$= 200 - 90 = 110$/10万；率比$= 200/90 = 2.22$。

绝对差距缩小了，每年减少40/10万。相对差距扩大了，因为最不贫困组按比例改善得更多（下降40%，而另一组下降33%）。两种说法都正确。绝对差距计算的是可以预防的超额死亡；相对差距表明进步的收益分配不均。只引用其中一个的报告会产生误导。
:::
:::

### 利用整个梯度的指标 {#sii}

只比较两个极端组，忽略了中间的每个人，并且结果取决于这两组的大小。基于整个梯度的指标可以避免这一问题。

::: definition 不平等斜率指数与相对不平等指数 {#def-sii}
把人群从最贫困到最不贫困排序，给每组赋予其累计人口份额的中点，使**相对秩次**从0（最贫困）到1（最不贫困）。对于大小相等的五分位组，中点为0.1、0.3、0.5、0.7和0.9。

将健康指标对相对秩次做直线回归（若各组人数不等，则按人口加权）。

- **不平等斜率指数**（SII）是量表两端即秩次0和秩次1处拟合值之差。它是绝对指标，单位与健康指标相同。
- **相对不平等指数**（RII）是相对指标。在英国的实践中，它常是两端拟合值之比；也有作者用SII除以人群均值。应始终说明所用方法。
:::

英国国家统计局（ONS）用SII报告英格兰预期寿命和健康预期寿命的不平等。在其涵盖2022—2024年的数据发布中，最贫困地区男性出生时健康预期寿命为49.8岁，最不贫困地区男性为69.2岁；女性分别为48.2岁和68.5岁。健康预期寿命的SII男性约为19年，女性约为20年。总预期寿命的差距较小，近年的估计约为8～10年。因此，最贫困地区的人寿命更短，而且一生中处于健康不良状态的比例更大。

::: example 计算斜率指数 {#ex-sii}
某城市五个贫困五分位组的年龄标化全死因死亡率，从最贫困到最不贫困依次为每年1,300、1,100、1,000、900和800/10万。各五分位组人口相等。计算SII和RII（取两端拟合值之比）。
::: solution
相对秩次：$x = 0.1, 0.3, 0.5, 0.7, 0.9$，均值$\bar x = 0.5$。平均率$\bar y = 5{,}100/5 = 1{,}020$。

离差：$x - \bar x = -0.4, -0.2, 0, 0.2, 0.4$；$y - \bar y = 280, 80, -20, -120, -220$。

$$
b = \frac{\sum (x-\bar x)(y - \bar y)}{\sum (x - \bar x)^2} = \frac{-112 - 16 + 0 - 24 - 88}{0.16+0.04+0+0.04+0.16} = \frac{-240}{0.4} = -600.
$$

截距为$a = \bar y - b\bar x = 1{,}020 + 300 = 1{,}320$。秩次0（最贫困）处的拟合率为1,320/10万，秩次1（最不贫困）处为$1{,}320 - 600 = 720$/10万。

SII$= 1{,}320 - 720 = 600$/10万/年。RII$= 1{,}320/720 = 1.83$。

SII大于两个极端五分位组之间的简单差距（$1{,}300 - 800 = 500$），因为它估计的是阶层最顶端与最底端之间的差异，而不是两个五分之一人群平均值之间的差异。
:::
:::

### 有多少死亡归因于不平等？ {#excess}

表达不平等的第三种方式是问：如果每个群体都具有最有利群体的健康水平，有多少死亡或病例不会发生。这是**人群归因分数**（PAF）的逻辑，只是用于社会地位而非单一危险因素。

::: example 超额死亡 {#ex-excess}
在[[#ex-sii]]的城市中，每个五分位组有20万人。如果每个五分位组都具有最不贫困组的死亡率（800/10万），每年可以避免多少死亡？占全部死亡的比例是多少？
::: solution
各五分位组死亡数$=$死亡率$\times 200{,}000/100{,}000 =$死亡率$\times 2$：分别为2,600、2,200、2,000、1,800和1,600，合计10,200。

如果每组死亡率都是800/10万，每组有1,600例死亡，合计8,000。

超额死亡$= 10{,}200 - 8{,}000 = 2{,}200$例/年，占全部死亡的$2{,}200/10{,}200 = 21.6\%$。

注意超额死亡落在哪里：最贫困五分位组1,000例，但中间三个五分位组合计1,200例。这就是梯度的作用，也是只针对最贫困五分之一人群的政策无法消除大部分超额死亡的原因。
:::
:::

::: warning 比较群体前必须对率进行年龄标化
英格兰的贫困地区人口往往较年轻，而富裕的农村地区人口往往较老。这时粗死亡率会*低估*贫困地区的超额死亡，因为年轻人群死亡较少。地区或群体之间死亡或疾病的比较应使用年龄标化率，或使用与年龄结构无关的预期寿命。按族群比较时同样需要注意，因为英国各族群的年龄结构差别很大。
:::

## 英国的不平等：主要模式 {#uk-patterns}

有几种模式在数据中反复出现。

- **贫困程度。** 如上所述，预期寿命和健康预期寿命按地区贫困程度呈陡峭梯度。婴儿死亡、吸烟、儿童肥胖、心血管和呼吸系统疾病死亡、肺癌、自杀和药物相关死亡在较贫困地区都更常见。自2010年以来，英格兰预期寿命的改善明显放缓，在最贫困地区，尤其是女性，有些年份停滞甚至下降。2020年马默特评估的后续报告把这称为失去进步的十年。
- **族群。** 模式因疾病而异，不能概括为“更差”或“更好”。在英格兰，南亚裔人群2型糖尿病和冠心病发病率较高，黑人高血压、卒中和某些癌症发病率较高，而一些少数族群的总死亡率低于英国白人群体。在历次MBRRACE-UK报告中，英国黑人女性的孕产妇死亡率显著高于白人女性。2020—2021年，几个少数族群的新冠死亡率较高，主要通过职业暴露、家庭拥挤和贫困。种族主义，无论是个人层面还是结构层面的，都通过上述每一条途径起作用。
- **地理位置。** 沿海城镇和英格兰北部的前工业地区结局最差之一，这与经济衰退、住房条件差以及健康年轻人的外迁有关。
- **严重精神疾病和学习障碍。** 严重精神疾病患者平均比一般人群早死15～20年，主要死于心血管和呼吸系统疾病等躯体疾病。学习障碍者也早死得多，全国死亡审查项目（LeDeR）多次发现可避免的死亡。

### 逆照护法则 {#inverse-care}

1971年，威尔士一个矿村的全科医生图德·哈特（Julian Tudor Hart）在《柳叶刀》（*The Lancet*）上写道：“良好医疗照护的可及性往往与所服务人群对它的需要成反比。”他称之为**逆照护法则**（inverse care law）。贫困地区的诊所有更多患多种长期疾病的患者，但历史上获得的经费和人员与额外的需要不相称，而且相对于问题的复杂程度，那里的诊疗时间往往更短。逆照护法则也通过利用率起作用：如后续各章所示，筛查、疫苗接种和NHS健康检查（NHS Health Check）在贫困地区和某些少数族群中的参与率较低。

::: example 受决定因素影响的一次诊疗 {#ex-case}
一位54岁的女性，是签订零工时合同的护理员，因气促到全科医生处就诊。她患有慢阻肺，每天吸烟15支，去年冬天因急性加重住院两次。她住在私人出租的公寓里，卧室有黑霉，她说付不起取暖费。她错过了两次肺康复预约，因为她无法请无薪假。这次诊疗如何才能顾及她健康的决定因素，而不只是她的肺？
::: solution
**首先是临床照护。** 复核慢阻肺诊断和吸入器使用技术，检查她的疫苗接种（流感、肺炎球菌，以及符合条件时的新冠疫苗），并按照现行NICE指南制订个体化管理计划。提供循证的戒烟支持，包括行为支持和药物或基于电子烟的方法。

**住房。** 寒冷潮湿的住房会直接加重慢阻肺。经她同意，诊所可以转介给地方政府的环境卫生服务部门，该部门可以要求私人房东处理潮湿和霉菌等严重隐患；也可以转介到帮助提高能效和取暖的项目。一封记录住房对健康影响的信函可以支持她的诉求。

**收入。** 询问她是否就可能有权获得的福利得到过咨询，并转介到福利权益或理财咨询服务。许多诊所现在都驻有这类顾问；收入最大化改善健康的证据有限，但经济上的收益可能相当可观。

**工作。** 病假证明（fit note）可以建议调整工作安排。把康复课程安排在她能参加的时间或地点，或提供居家康复方案，可以解决她缺席的原因。

**社会联系。** 社会处方（social prescribing）联络员可以协调这些转介和社区支持。

重点不在于全科医生必须解决她的住房和就业问题，而在于忽视它们会使临床照护效果变差，而卫生服务可以充当通往能提供帮助的机构的门户。询问金钱、住房和工作是良好病史采集的一部分。
:::
:::

## 什么能减少健康不平等？ {#action}

各种干预作用的“上游”程度不同。**下游**干预治疗疾病或改变个人行为；**中游**干预改变生活和工作条件；**上游**干预改变产生这些条件的经济和社会结构。

::: theorem 结构性干预比个体干预更可靠地减少不平等 {#thm-structural}
改变人们作出选择所处环境的干预，或重新分配资源的干预，往往能减少健康不平等，因为它们发挥作用不依赖于个人的时间、金钱、教育或动机。依赖个人注意、理解并根据信息行动的干预，往往更多地被有利群体利用，因此即使改善了平均健康水平，也可能扩大不平等。
:::

::: proof
考虑减少糖摄入的两种方式。关于糖的危害的传单宣传，只对那些阅读它、相信它、有钱有时间购买和准备替代品、且没有处于使改变更困难的压力之下的人有效。这些条件中的每一个都更常在有利群体中得到满足。而促使厂商调整饮料配方的税收，无需消费者任何努力就能减少所有人饮料中的糖；它甚至可能使低收入群体受益更多，因为他们消费受影响的产品更多。

关于“干预造成的不平等”的系统评价反复发现这一模式。媒体宣传和针对个人的建议往往有利于有利群体；价格措施（烟草税和酒税、酒精最低单位定价）、立法（无烟法律）、配方调整以及结构性的工作场所或住房措施往往是中性的，或有利于不利群体。同样的逻辑解释了为什么烟草税在低收入人群中减少吸烟最多，因为他们对价格最敏感。
:::

这并不意味着个体干预没有用。例如，戒烟服务帮助了贫困地区的许多人，而且可以设计成能够触及他们。这一原则关注的是干预对健康*分布*的预期影响，它意味着每个项目都应检查谁从中受益。

### 马默特的六项政策目标 {#marmot}

2010年的马默特评估《公平社会，健康生活》（*Fair Society, Healthy Lives*）为英格兰设定了六项政策目标，此后被许多地方政府采纳（“马默特地区”）：

1. 让每个孩子都有人生的最佳开端。
2. 使所有儿童、青少年和成年人充分发挥能力，并掌控自己的生活。
3. 为所有人创造公平的就业和体面的工作。
4. 确保所有人都有健康的生活水平。
5. 创建和发展健康、可持续的地方和社区。
6. 加强疾病预防的作用和效果。

2020年的后续报告又增加了两项：消除种族主义、歧视及其后果，以及同时追求环境可持续性与健康公平。只有第六项直接涉及卫生服务。幼儿期排在第一位，因为在那里的投入效果最大、最持久。

### 卫生服务的作用 {#nhs-role}

卫生服务无法单独弥合差距，但它可以避免扩大差距，并从几个方面作出贡献。

- **公平的可及性。** 按需要加权的经费分配公式；对参与率低的群体开展外展服务；口译；灵活的预约；易于获取的信息。
- **服务中的比例普惠主义。** 健康访视（health visiting）等普遍性服务，同时为需要更大的家庭提供额外支持。
- **有针对性的项目。** NHS英格兰的**Core20PLUS5**方法（2021年推出）聚焦于最贫困的20%人口、在地方层面确定的PLUS群体，以及成人的五个临床领域：孕产保健、严重精神疾病、慢性呼吸系统疾病、癌症早期诊断和高血压（及血脂管理）。儿童版本有自己的五个领域。
- **锚定机构。** NHS机构是大型雇主和采购方。在本地招聘、支付生活工资和向本地供应商采购，可以直接作用于决定因素。
- **数据。** 准确记录族群、贫困程度和残疾情况，可以使不平等显现出来。

### 英格兰的法律框架 {#law}

若干法律要求公共机构考虑不平等。**《2010年平等法》**（Equality Act 2010）要求公共机构适当考虑消除歧视，促进具有受保护特征者的机会平等（公共部门平等义务）。**《2012年卫生和社会照护法》**（Health and Social Care Act 2012）规定卫生大臣和NHS机构有义务考虑减少在可及性和结局方面的健康不平等的需要，**《2022年卫生和照护法》**（Health and Care Act 2022）把类似义务扩展到整合照护委员会。自2013年起，英格兰大部分公共卫生服务由地方政府负责，由其公共卫生主任领导。

### 国家之间的不平等 {#global-inequalities}

同样的模式也存在于国家之间。出生时预期寿命最高和最低的国家之间相差20多年。由马默特担任主席的世卫组织**健康问题社会决定因素委员会**于2008年发表报告，题为《用一代人时间弥合差距》（*Closing the Gap in a Generation*）。它的三项总体建议是：改善日常生活条件；解决权力、金钱和资源分配不公平的问题；测量和理解问题并评估行动的影响。国际层面的问题在[[public-health/global-health]]中讨论。

::: quiz
某地方政府开展了一项以传单、网站和免费手机应用为基础的体重管理宣传活动。两年后，成年人的平均体重指数略有下降，但最贫困和最不贫困选区之间的肥胖患病率差距扩大了。最可能的解释是什么？
- [ ] 该活动对贫困选区的人有害。
- [x] 较不贫困选区的人更多地参与了该活动并据此采取了行动。
- [ ] 肥胖主要由遗传决定，因此该活动无法影响差距。
- [ ] 由于平均水平改善了，差距扩大一定是偶然发现。
::: solution
这是干预造成的不平等的典型模式。依赖个人时间、金钱、数字设备可及性和动机的信息类宣传活动更多地被有利群体利用，因此在改善平均健康水平的同时扩大了差距。该活动并没有使任何人变得更糟；差距扩大是因为收益不均。可以预期，结构性措施（食物环境、定价、配方调整、主动出行）和按比例针对的支持在公平性上会做得更好。
:::
:::

::: history
1826年，法国医生维莱尔梅（Louis-René Villermé）证明，巴黎各区的死亡率随居民的富裕程度而变化，富裕程度以免税租金所占比例来衡量。1842年，查德威克（Edwin Chadwick）的《大不列颠劳动人口卫生状况报告》（*Report on the Sanitary Condition of the Labouring Population of Great Britain*）记录了利物浦劳工的平均死亡年龄远低于上流阶层，并促成了1848年的《公共卫生法》。同年，被派去调查上西里西亚斑疹伤寒流行的菲尔绍（Rudolf Virchow）得出结论：其原因是贫困和政治上的忽视，并认为“医学是一门社会科学”。

20世纪，英国户籍总署的社会阶层分类使人们能够按职业追踪死亡率。由道格拉斯·布莱克爵士（Sir Douglas Black）担任主席的工作组成立于1977年，于1980年报告：在NHS之下，阶层之间的死亡率差异并未缩小，物质条件是主要原因。当时的政府几乎没有宣传就发布了这份《布莱克报告》，但它成为现代不平等研究的基础。怀特黑德的《健康鸿沟》（*The Health Divide*，1987年）对其进行了更新。始于1967年的公务员白厅研究确立了梯度的存在，而艾奇逊调查（Acheson inquiry，1998年）、马默特评估（2010年）及其十年后续报告（2020年）为英格兰设定了政策议程。
:::

## 后续内容

预防策略以及如何在人群策略和高危策略之间作出选择，是[[public-health/prevention-promotion]]的主题。筛查和疫苗接种参与率的不平等在[[public-health/screening]]和[[public-health/vaccination-programmes]]中讨论，造成大部分梯度的危险因素在[[public-health/non-communicable-disease]]中讨论。卫生体系如何按需要分配资源在[[public-health/health-systems-economics]]中介绍。

::: summary
- 健康主要由人们出生、成长、生活、工作和老去的条件决定，即**健康的社会决定因素**。医疗照护只能解释群体之间差异的少部分。
- 社会条件通过物质、心理社会、行为和生命历程途径影响健康。
- 如白厅研究所示，健康在整个社会阶层中呈**社会梯度**；大部分超额死亡发生在分布的中间，而不只在最贫困者中。
- **不公平**是可避免的、不公正的健康差异。不平等用绝对差距、相对差距、**不平等斜率指数**和**相对不平等指数**以及超额死亡来测量。绝对指标和相对指标可能朝相反方向变化；应同时报告二者，并使用年龄标化率。
- 在英格兰，最贫困和最不贫困地区的健康预期寿命相差约19～20年（ONS，2022—2024年）。
- **逆照护法则**：最需要良好照护的地方，往往最难获得良好照护。
- 结构性干预（价格、监管、配方调整、住房、收入）往往减少不平等；基于信息的个体干预可能扩大不平等。**比例普惠主义**把普遍行动与按需要匹配的力度结合起来。
- 临床医生的贡献在于：询问金钱、住房和工作情况，转介到能提供帮助的服务，确保公平可及，并记录使不平等显现的数据。
:::

## 习题

::: exercise 率比 {level=1 check="1.6"}
某国最贫困五分位组的婴儿死亡率为4.8‰活产，最不贫困五分位组为3.0‰活产。计算率比。
::: solution
率比$= 4.8/3.0 = 1.6$。率差为$4.8 - 3.0 = 1.8$‰活产。
:::
:::

::: exercise 健康预期寿命差距 {level=1 check="19.4"}
据ONS数据，2022—2024年英格兰男性出生时健康预期寿命在最贫困地区为49.8岁，在最不贫困地区为69.2岁。两者相差多少年？
::: solution
$69.2 - 49.8 = 19.4$年。出生在最不贫困地区的男性，预期比出生在最贫困地区的男性多享有将近二十年的健康生活。（ONS使用全部十分位组计算的斜率指数略小，约为19.3年。）
:::
:::

::: exercise 不平等还是不公平？ {level=1}
把下列每一种差异归类为不属于不公平的不平等，或归类为不公平，并简要说明理由。(a) 80岁人群的痴呆发病率高于40岁人群。(b) 最贫困地区的儿童比最不贫困地区的儿童更容易患龋齿。(c) 男性甲型血友病的发病率高于女性。(d) 严重精神疾病患者比一般人群早死15～20年。
::: solution
(a) 不属于不公平：差异主要由年龄造成，其本身不可避免。(b) 属于不公平：龋齿是可以预防的（氟化物、饮食、获得牙科服务），其社会分布来自可避免的条件。(c) 不属于不公平：差异源于X连锁遗传。(d) 属于不公平：超额死亡大部分源于可预防的躯体疾病、吸烟、药物副作用以及较差的躯体健康照护可及性，这些都可以改变。
:::
:::

::: exercise 朝相反方向变化的差距 {level=2 check="round(100*(20/6 - 30/12))/100"}
某年最贫困五分位组的吸烟率为30%，最不贫困五分位组为12%。十年后分别为20%和6%。(a) 计算两个时间点的绝对差距（百分点）。(b) 计算两个时间点的相对差距（比值）。以比值的变化（后者减前者，保留2位小数）作答。
::: solution
(a) 绝对差距：之前为$30 - 12 = 18$个百分点；之后为$20 - 6 = 14$个百分点。绝对差距缩小了。

(b) 比值：之前为$30/12 = 2.50$；之后为$20/6 = 3.33$。变化为$3.33 - 2.50 = 0.83$：相对差距扩大了。

两组吸烟率都下降了，最贫困组下降的百分点更多，但下降的比例更小（33%对50%）。不平等是否“改善”取决于所用指标，因此应同时报告二者。
:::
:::

::: exercise 由三个组计算斜率指数 {level=2 check="30"}
某镇分为人数相等的三个贫困组（三分位组）。报告健康状况差的成年人比例在最贫困的三分之一为30%，中间三分之一为20%，最不贫困的三分之一为10%。使用相对秩次1/6、1/2和5/6，计算不平等斜率指数（百分点）。
::: hint
三个点恰好在一条直线上，因此可以用其中任意两点求斜率。
:::
::: solution
在秩次1/6和5/6之间（距离为2/3），比例下降$30 - 10 = 20$个百分点。斜率为每单位秩次$-20/(2/3) = -30$个百分点。秩次0处的拟合值为$30 + 30 \times 1/6 = 35\%$；秩次1处为$35 - 30 = 5\%$。

SII$= 35 - 5 = 30$个百分点，大于两个极端三分位组之间20个百分点的差距，因为SII外推到了阶层的最两端。
:::
:::

::: exercise 人群归因分数 {level=2 check="round(10000*0.4/1.4)/10000"}
某人群中20%的成年人吸烟，吸烟者患某种疾病的风险是非吸烟者的三倍。计算人群归因分数$PAF = \dfrac{p(RR-1)}{1 + p(RR-1)}$，保留4位小数。
::: solution
$p(RR - 1) = 0.2 \times 2 = 0.4$。$PAF = 0.4/1.4 = 0.2857$。该人群中约29%的该病病例归因于吸烟，如果没有人吸烟，这些病例就不会发生（假定该关系是因果性的且无混杂）。如果贫困群体的吸烟率更高，那里的PAF也更高，吸烟就解释了该病梯度的一部分。
:::
:::

::: exercise 年龄结构与粗率 {level=3}
A区（贫困）人口年轻；B区（富裕）人口老化。A区全死因粗死亡率为900/10万，B区为1,100/10万。一位地方议员认为B区的健康问题更大。解释为什么这一结论可能是错误的，你会改为计算什么指标，以及预期它会显示什么。
::: solution
死亡率随年龄急剧上升，因此即使年龄别死亡率较低，老年人口的死亡也更多。粗率把年龄结构的差异与风险的差异混在一起。直接年龄标化法把每个地区的年龄别死亡率应用于一个共同的标准人口（例如2013年欧洲标准人口），得到可以比较的率；预期寿命是另一个与年龄无关的指标。鉴于英格兰强烈的贫困梯度，A区在每个年龄的年龄别死亡率都可能更高，因此其年龄标化率很可能超过B区，预期寿命也会更低。这位议员混淆了死亡人数（这对服务规划很重要）和死亡风险（这才衡量健康）。
:::
:::

::: exercise 为公平而设计 {level=3}
某整合照护委员会希望提高NHS健康检查的参与率，目前最不贫困五分位组的参与率为55%，最贫困五分位组为35%。提出一个可能在总体上提高参与率而不扩大差距的计划，并说明你将如何评价它。
::: solution
**原则。** 比例普惠主义：保留普遍邀请，但把更多努力投向参与率低的群体。降低参加的成本（时间、交通、收入损失、数字设备可及性、语言），而不是只依靠信息。

**行动。** 利用诊所数据识别贫困地区和参与率低的群体中的未参加者。在工作时间以外和社区场所（工作场所、宗教场所、食物银行、社区中心、流动服务车）提供检查，由受信任的社区卫生工作者实施。使用人们所用语言的电话邀请和短信提醒，并预先安排好预约时间，而不是“请来电预约”。确保被发现风险高的人真正得到治疗和支持的随访，因为没有随访的检查毫无益处。与当地雇主合作，允许带薪请假。

**评价。** 在改变前后，按贫困五分位组、族群和性别测量参与率以及高风险者的随访情况，并用一个绝对指标和一个相对指标衡量差距（差值和比值，或SII和RII）。与未改变做法的类似地区比较，把计划的效果与长期趋势区分开来。核查成本，并在较长期内按五分位组观察血压控制和心血管事件的变化。
:::
:::

::: exercise 解读斜率 {level=2 check="round(10000*1100/600)/10000"}
在[[#ex-sii]]的城市中，后来的一次调查得到秩次0处的拟合死亡率为1,100/10万，秩次1处为600/10万。之前的数值是1,320和720。计算新的RII（两个拟合值之比），保留4位小数，并说明相对不平等是否发生了变化。
::: solution
新的RII$= 1{,}100/600 = 1.8333$；之前的RII为$1{,}320/720 = 1.8333$。相对不平等没有变化：两端按相同比例改善（约17%）。绝对的SII从600/10万降到500/10万，因此绝对不平等缩小了。
:::
