健康的决定因素是患者带着不同的身体来到门诊的原因；而不平等是“谁先到、谁病得更重、谁更没准备”这一可测量、不公正、可避免的差别。**本章覆盖社会决定因素的证据架构（梯度本身——不只是贫困而是等级——以怀特霍特研究为其标志、从“磨损”到财富的机制、以及根本原因框架）、生命过程与早期发展的证据（胎儿编程、不良童年经历、以及早期干预在学业与收入上的回报）、现代死亡率的具名危险因素（贫困、住房、教育、就业、收入、食物、烟草、酒精、毒品、肥胖与活动不足、以及社会联结，各自带着它的流行病学与政策杠杆）、以及不平等的测量与监测与“缩小差距”的政策工具箱与临床的那一份。**

## 梯度

::: definition 社会决定因素及其机制 {#def-determinants}
**医学地理学的核心经验事实是梯度：在任何社会内部，健康与寿命都随收入、教育、职业与等级逐级改善——所以中产比富人死得早、比穷人死得晚；梯度贯穿整个分布而不是停在贫困线附近。这是怀特霍特对伦敦文官的研究（原始队列与随访显示社会等级几乎预测所有死因的死亡率，而经典危险因素、体质乃至脑容量只能解释其中一部分）的发现，并在此后所有数据集中被复现，包括近年显示美国梯度在变陡、而其绝对水平落后于同类国家的研究。机制是累积的、部分已知的：物质的（收入、住房质量与寒冷、食物安全、能否取暖与进食与看病的余地）、等级的（控制感与承认与社会参与的缺乏，以及主观地位本身对结局的预测力）、以及生物的（下丘脑—垂体—肾上腺与自主神经与炎症的调节，即“磨损”：在高压力与低控制的生活里被反复调用而留下的血压与腰围与糖化血红蛋白与炎症标志的轨迹，最终表现为心梗、卒中、抑郁与关节疼痛）。发育的一翼同样重要：母体营养与胎儿编程、出生的体重与随后的血压与糖代谢、不良童年经历与剂量—反应的关联、以及早期干预在教育与收入与犯罪与健康上的回报（若干随机试验的长期随访使“学前教育值得投资”成为医学主张而非道德愿望）——[[paediatrics/safeguarding]]、[[endocrine/diabetes]]、[[cardiovascular/hypertension]]。“根本原因”框架给出统一的解释：收入与教育与权力之所以预测死因的清单，是因为它们决定了能否回避风险与获得保护——因此当新的干预出现时，优势群先采用，差距于是扩大而不是缩小；这条论断解释了为何新疗法可以在十年里同时改善结局并加深不平等——[[public-health/screening]]、[[pharmacology/drug-development-prescribing]]。**
:::

## 测量

::: definition 测量并监测不平等 {#def-measurement}
**不只有在可按群体分层测量时才可被管理，而多数卫生信息系统天生不记录分层：没有族群与收入与残疾与语言的字段，就没有不平等可见性——这是许多质量改进项目最大的单一盲点。可用的测量是简单的：把人群按剥夺指数（或收入或教育或族群或地域）分成五组或十分位，报告每个组的率，然后看两件事——绝对差距（率差）与相对差距（率比），它们的走向常常不同；以及梯度本身的形状（是全分布的斜坡还是只是最底端的断崖）——因为两种形状需要不同的政策。指标集要包括死亡（早死的年数）、可避免死亡、疾病的患病与控制（血压与糖化血红蛋白的控制率按分层的差距）、以及过程（筛查与免疫与牙科与门诊的可及、以及急诊与住院与可避免住院）。监测的纪律：一致的分组变量（同一份剥夺指数、族群分类标准随时间变化时的警告）、小群体的置信区间、避免生态谬误（社区的剥夺不等于个人的剥夺，二者都要有）、以及把不确定性显示出来以免“差距缩小”被读成“成功”——[[epidemiology-ebm/measuring-disease]]。“”逆向照护法则“”的教训：优质医疗的可及性往往与服务人群的需求呈反比；而“逆向照护激励”是其现代形式——按结果付费的激励使表现最差的机构最不愿接收最难的病例，所以任何基于激励的支付改革都必须内置公平的护栏（风险调整、按剥夺分层的目标、以及对“漏掉者”的报告）——[[public-health/health-systems-economics]]。最后：把不平等监测当作与感染率同级的法定监测项目——定期、公开、可比、以及有法定的响应要求，否则它会一直被排在优先级之外——[[public-health/prevention-promotion]]。**
:::

## 缩小差距

::: definition 缩小差距：政策、按比例普遍主义与临床的那一份 {#def-closure}
**有两件事已被证明：只针对最贫困群体的项目往往被污名化、覆盖不足、并漏掉最需要的人；而完全普遍的项目会按优势取用（新的服务先被最有余力者使用），于是差距扩大。“按比例普遍主义”是这两者之间的证据立场：面向全人口的普遍行动，并按需求比例配置更大强度的资源——它同时解释了为何“全民覆盖”本身不必然缩小差距，以及为何普遍服务加定向加重才有效。上游政策的记录最好：儿童贫困与收入、教育与学龄前的入学、住房与温暖的居所（把“居所的改良”当作呼吸与心理健康的干预来评估）、以及烟草（其税负与营销管制对低收入群体的降幅最大，因此在这些地方既减不平又最有效）与酒精与食物（价格、可及与促销）——[[public-health/non-communicable-disease]]、[[public-health/prevention-promotion]]。中游是卫生系统的份额：面向弱势群体的召回与外展、移动与社区门诊、可及的时间与地点与语言与读写的适配、以及数字服务之外的路径；还有把不平等写进质量指标（把“最剥夺五分位的控制率”作为目标，而不只是平均值）与把“被漏掉的人”作为例会的固定议题。下游是临床的那一份，真实而有限：确定性的问诊（把住房与寒冷与食物与债务与社交孤立作为问题列表的项目，并给出真实的下一步）、把处方开成对无家者与低收入者可行的药（每天一次、可负担、无需冷链）、把语言与读写与“回述”作为标准而不是例外、以及把福利与住房与法律的帮助接进门诊（一次就诊不能解决贫困，但一次错过可以加重它）——[[clinical-skills/communication]]、[[geriatrics-palliative/ageing-frailty]]。诚实的一句结尾：临床界可以缓冲不平等的后果，却无法治疗其成因；把两者混为一谈会让医生高估自己、也让政策逃脱责任——[[medical-ethics-law/justice-resources]]。**
:::

::: example 两名哮喘患者 {#ex-gradient}
两名十二岁男孩哮喘急性发作入住同一间病房。甲住在市中心之上的公寓，父母皆专业职业，家中养猫；乙住在潮湿的合租屋，母亲失业、家中吸烟、上一支吸入剂用完两周未续、上次出院后无人安排随诊。
::: solution
**同一种病，两套病因（[[#def-determinants]]、[[#def-closure]]、[[respiratory/asthma-copd]]）：出院计划的差别必须与病情同样仔细地被设计。对乙：把“为什么用完”当作病史的核心（费用、可及、理解、以及对“激素恐惧”的担忧——这些都要问且不指责），并把治疗改成一个他能完成的方案（单一吸入器、每日一次或两次、免费或低价路径、以及书面与图示的行动计划与一个“何时回来”的具体标准）；把随访安排到他自己会去的地方（学校与社区药房与门诊的同日打包），并在出院后四十八小时内打电话（不是四周后的信）——[[clinical-skills/records-handover]]、[[pharmacology/adverse-reactions]]。病房的病因层：室内霉菌与潮湿与尘与烟草暴露（对乙而言“转介到住房与除霉”与“吸食的二手烟”与“学校的出勤与活动受限”同等重要，并且可以按呼吸干预的方式评估——虽然医师开不出干燥的墙壁，但可以开出一个名字与一次转介并追踪是否发生）——[[public-health/environmental-occupational]]。家庭的负担：母亲的失业与睡眠与抑郁与社会支持（儿童慢性病的照护负担在贫困家庭更重且更缺少缓冲）；把成人的健康需求接上（戒烟与抗抑郁与福利咨询）——[[psychiatry/mood-disorders]]。系统的一层：把这类患儿列入“高频住院者”队列并做根因审查（可避免的哮喘住院本身就是一项不平等指标：它在最剥夺五分位高出数倍，因此一次一人的优化不如政策有效）；并把这次事件写进质量改进——出院与门诊衔接失败是一个可修的缺陷、不是一场不可避免的社会悲剧——[[clinical-skills/patient-safety]]、[[paediatrics/acute-childhood-illness]]。**
:::

::: example 两个邮编的预期寿命 {#ex-postcodes}
一份本地报告发现在同一条公交线两端的两组人群，健康预期寿命相差十九年；卫生与照护委员会要求“用卫生系统解释它”；公共卫生团队说不可能。
::: solution
**如何解释十九年（[[#def-determinants]]、[[#def-measurement]]、[[#def-closure]]）：先做分解而不是辩护：用按年龄标化的死亡率与病种别，把年数拆成可归因的组成部分（心血管与癌症与呼吸系统与外部原因与自杀与痴呆；以及“残障而无死亡”的年数对“早死”的年数），再用危险因素归因（吸烟、酒精、肥胖与活动不足、食物、贫困与住房）与卫生系统贡献（筛查参与、二级预防药物、急性事件救治、以及心理健康的可及）来分配。结果几乎总是这样：约一半到三分之二的差距落在卫生系统控制之外的原因上——所以委员会的问题问错了；该问的是“在卫生系统能够到的那一部分里，我们还差多少”。卫生系统能够到的部分仍然可观：戒烟支持与处方与血压与糖化控制与药物持有率（在许多体系里最贫困五分位的续方中断率最高——这是可以修的不平等）、筛查参与（非邀请式与移动与延长时段参与率提高最明显）与急性事件救治与心脏康复与肺康复与抑郁症治疗的到场率——[[cardiovascular/hypertension]]、[[public-health/screening]]、[[respiratory/asthma-copd]]。要拒绝的做法：把“生活方式选择”当作原因（它把环境的产物道德化）；以及把差距归因于“人群不珍惜服务”（正确的问题是服务被设计成谁容易用）。要交的东西：一份十九年的瀑布图、一张“我们能改的项”及其目标值与责任人与时限的清单、以及一份与住房与教育与就业部门的联署行动计划——因为没有一位卫生总监能独自减少十九年——[[public-health/health-systems-economics]]、[[medical-ethics-law/justice-resources]]。**
:::

## 通向何处

不平等的机制与卫生系统的角色见[[public-health/health-systems-economics]]；上游的政策工具见[[public-health/prevention-promotion]]与[[public-health/non-communicable-disease]]；筛查中的公平见[[public-health/screening]]；环境与职业暴露见[[public-health/environmental-occupational]]；生命过程的生理见[[physiology/homeostasis-body-fluids]]；全球尺度见[[public-health/global-health]]。

::: history
**“环境与疾病”的观念古老（空气的腐臭、瘴气说、以及四体液说里的环境），现代的形式始于十九世纪的统计与卫生调查：费里埃与斯诺与西蒙的死亡率地理、恩格尔的曲线、以及“贫穷与死亡”的表格；布斯1902年的《美国的贫穷与社会生活》把地图与死亡率叠在一起；1911年与1944年的贝弗里奇报告把健康写进社会保障的设计（“消除五大巨人”），并催生了战后普遍医疗服务的建立。流行病学的转折在1960至70年代：从“病因的单数”转向危险因素的统计，以及伦敦与波士顿等地对社区照护与住院的公平性研究。1978年的布莱克报告（英国）给出了一份对健康不平等的官方描述并建议从儿童与贫困着手；1980年代的怀特霍特研究把因果从“贫困造成疾病”改为“等级造成梯度”（并因此把不平等变成全社会的问题）；1990年代的“社会资本”热潮与其后的幻灭；以及2008年的《公平投资在健康上以缩小差距》（迈克尔·马莫特与威廉斯报告），它把“梯度”变成一个政策清单（在早期童年与收入与教育和住房与工作条件与社会保障与烟草上一并行动）与“按比例普遍主义”这一概念。与此同时，“死亡绝望”的二十年后研究（自杀与酒精与药物中毒的死亡与预期寿命的下降与自杀与成瘾）提醒富裕国家：不平等可以杀人而无需传染病参与。这段历史的方法论遗产是三条：以个体水平数据建立关联、以自然实验与历史对照检验因果、以及始终追问“这个差距是否在变大”——[[epidemiology-ebm/observational-studies]]、[[public-health/global-health]]。**
:::

::: summary
- 在每个社会内部，健康沿社会梯度下降：等级几乎预测所有死因的死亡率；经典危险因素、行为乃至生物学只能解释一部分，而梯度由收入、住房、工作、教育、早期生命、地方与压力的生理在数十年间共同制造。
- 生命过程的证据（胎儿编程、不良童年经历、教育与收入的回报、以及社区搬迁研究）显示时点与水平同等重要，而早期干预对成人疾病有可测的回报。
- 不平等以绝对差距、相对比、归因分数与梯度指数测量；剥夺指数与链接的人口数据是监测工具；生态谬误、率与比的选择、以及“看不见的人群”是陷阱。
- 逆向照护法则仍然成立：服务的可及与使用常与需求反向；按结果的支付激励若不设护栏会加深这一点。
- 缩小差距的立场是按比例的普遍主义：普遍的行动加上按需求加重的资源；只救最贫困者的项目被污名与低覆盖削弱，纯普遍的项目被优势者先取用。
- 临床的那一份真实而有限：可行的处方与可及的安排与确定性问诊能缓冲后果，但成因在诊室之外；把两者混淆会让医学高估自己。
:::

## 练习

::: exercise 取决定因素的病史 {level=1}
一名58岁男性因难以控制的高血压与抑郁前来。写出你会问的十个决定因素问题，以及你会据此改变的两件临床事。
::: solution
**十个问题（[[#def-determinants]]、[[#def-closure]]、[[cardiovascular/hypertension]]）：工作（现在做什么、以前接触过什么、是否零工与无保障）、收入（是否领福利、是否负债、是否“取暖还是吃饭”）、住房（是否潮湿与寒冷、是否独居、楼层与步行能力）、食物（能否负担并准备新鲜食物、有无冰箱与炉灶）、交通（能否到药房与门诊、往返距离）、家庭与照护（是否照顾他人、有无子女可协助）、教育与读写（能否读懂标签与说明书）、语言（需要口译吗）、社会联结（与谁联系、多久一次）、以及歧视与不安全感（是否曾被系统伤害过，因而回避就医）。两件要改的临床事：一，把方案改成他执行得动的（每日一次的单片复方与可负担的路径与不设“必须上午来”的随访、并把化验与门诊打包在同一天）；二，把抗抑郁的选择与副作用考虑他的劳动（镇静的与影响性功能与注意力的药在日班司机身上是职业问题），并给出非药物的、他能到达的路径（步行可达、免费的社区活动、以及把债务与福利咨询接进门诊）——[[psychiatry/mood-disorders]]、[[pharmacology/patient-variation]]、[[clinical-skills/communication]]。**

::: exercise 正确读梯度 {level=2}
一份报告称“我们的筛查参与率差距已从18%缩小到12%，说明干预有效”。请指出这一陈述中可能的四个统计与逻辑问题。
::: solution
**四个问题（[[#def-measurement]]、[[#def-closure]]、[[public-health/screening]]）：一，绝对与相对之混：如果两组的参与率都上升，差距可能缩小而弱势组的绝对改善很小（要同时报告每个十分位的率与率比与率差，以及“到目标还需多少年”）。二，分母的变化：筛查对象的登记质量、以及新迁入的人口构成改变了群体，使“同一群体变好”不成立（用固定出生队列与固定分组做敏感性分析）。三，回归到均值与时间趋势：从峰值回落不是干预的功劳（需要中断时间序列或对照地区）。四，辛普森与构成谬误：总差距缩小而每个亚组都变差、或“公平”来自把最难的社区移出统计（取消资格、改变分组变量、或把“不可联系”的比例上升算作排除——这是最常见的自欺）；所以要检查各分组的“未知与不可联系”比例是否也在变。补充要求：给出置信区间（小差距常不显著）、按年龄与性别标化、以及把最剥夺五分位的绝对参与率与达到临床收益所需的阈值一起报告——[[epidemiology-ebm/bias-confounding]]、[[clinical-skills/patient-safety]]。**
:::

::: exercise 向市长进言 {level=2}
市长愿意在任期内做“一件能缩小本地健康差距的事”，预算有限，且反对意见会是“这不是市政府的职责”。给出你的建议与论证。
::: solution
**一件最有把握被证明的事（[[#def-closure]]、[[#def-determinants]]、[[public-health/prevention-promotion]]）：建议：针对最剥夺社区的一项儿童早期的强化支持（学龄前入学与家庭访视与父母支持的组合，并在当地小学与儿童中心落地），因为它同时具备最好的长期健康证据、可见的地方资产、以及跨任期可衡量的中间结局（出勤与语言与肥胖与哮喘住院）。若政治周期太短，配一项“三年内可见”的措施作为可见的近期成果：住房保暖与除霉的定向改造（对呼吸与心理健康与燃料账单有直接的、当年可见的效果）——[[public-health/environmental-occupational]]、[[respiratory/asthma-copd]]。“不是职责”的回答：市长管着学校入学、住房与规划与道路与公园与治安与福利发放与采购与突发事件应对——每一项都是健康的决定因素；引“健康融入所有政策”与本地死亡与发病的地理图，把议题从“卫生项目”改述为“城市设计与责任”。论证的三块：本地的成本（可避免住院与急诊与儿童照护的公共支出）、公平（同一城市十九年的差距是不可辩护的）、以及合法性（市民对“看得见的事”的支持高于对全国数字的关心）——[[public-health/health-systems-economics]]。执行的要点：与社区共同设计并付费给社区组织、把剥夺十分位写进合同指标、以及承诺公开年度进展（包括失败）——[[medical-ethics-law/justice-resources]]。**

::: exercise 审计你所在服务的不平等 {level=3}
你要为本院的心衰服务做一次公平审计。写出数据来源、分组变量、指标、验证、以及你会如何避免审计变成一份无人执行的报告。
::: solution
**服务级的公平审计（[[#def-measurement]]、[[#def-closure]]、[[cardiovascular/heart-failure]]）：数据来源：住院与急诊的记录（可避免住院与再入院与住院日）、门诊与药物滴定与器械（起搏与除颤）的出席与拒绝与未出席、以及死亡；再链接社区的剥夺指数与族群与语言与残疾状态与居住安排（院外的照护与无家状态）——若链接不可得，就在病历里补录（这本身就是一项发现）。指标按“全程”选：从诊断（第一次利钠肽与超声心动的时间与途径，急诊诊断者通常更贫困）到指南驱动药物的开启与滴定与持有率、器械治疗的比例、康复的到场、以及预立照护计划的记录（在贫困与少数族群中常被系统性缺失，而其后果由家属承担）。验证：把分组变量的缺失率作为独立指标（族群与剥夺的“未记录”是主要盲点）、以及用人工抽样核对编码、并对小群体给出区间。分析：每组的率加置信区间与“达到目标所需年数”的图；并把平均表现与差距同时呈现——因为质量改进常把两者当成不同的事。行动设计（决定这份报告是否有人执行）：每一项被发现的差距都要有一个负责人、一个干预、一个时限、以及一个下一次的指标；把三件最可执行的先做（例如：把康复安排到傍晚与社区地点并把交通报销写进流程、把药物滴定的电话随访作为默认、以及为“未记录族群”设置强制字段与前台培训）；并在院务与质量委员会与公众（社区团体）面前汇报一次——公开的清单最不易被忘记——[[clinical-skills/patient-safety]]、[[clinical-skills/records-handover]]。**

::: example 疫苗接收率的地图 {#ex-uptake}
一区的麻疹一剂接收率为84%，但按细分社区看有三处低于65%；当地正在暴发；这三处分别是：一个宗教性社区、一处新迁入的难民安置区、以及一片以合租与高流动著称的公屋。
::: solution
**地图不是人群（[[#def-measurement]]、[[#def-closure]]、[[public-health/vaccination-programmes]]）：先纠正归因：三个低覆盖区的病因不同，因此不能用一份宣传材料。宗教社区——需求的是可信任的信使（本地宗教领袖与已接种的家庭）与回答具体问题（成分与酒精与细胞系与豁免）；不要以处罚开路，它会强化被迫害感并把技术问题变成身份政治——[[paediatrics/immunisation]]。难民安置区——问题通常是记录与流动与预约的门槛（没有国民保险号、语言、以及工作日白天的服务时间与交通与对强制的恐惧，包括担心“登记后被驱逐”）；解法是移动与现场接种（在学校与食品分发点与安置酒店、不设固定预约、允许同时补种多种疫苗并即时给纸质凭证，因为数字凭证排斥最需要的人）——[[public-health/global-health]]。公屋与高流动区——问题是被漏掉的名单与“零剂次儿童”（搬家与私下接种与私人诊所与“寄住在亲戚家”的孩子）：解法是主动搜寻（用入学名册与幼儿园与房东与社区组织、逐街敲门、并给每个被拒或不可联系的记录日期与结果），并把接种做在人们已在的地方（周末与傍晚与药房与社区中心与上门）——[[public-health/screening]]。风险沟通与信任：不隐瞒本次暴发的严重性与死亡个案（诚实比安慰更能建立信任）、公开本地的接收率与差距、以及承诺不用接种证明作为进入公共服务的惩罚性条件；同时把“为何这三处低”作为质量指标纳入监测，因为接收率是卫生系统表现而非人群美德的量度——[[clinical-skills/communication]]、[[medical-ethics-law/justice-resources]]。

::: example 产科选择门诊 {#ex-maternity}
一家教学医院推出“生育地点选择”政策（医院、生育中心或家中），并向所有孕妇发放手册；一年后审计发现：选择非医院分娩者几乎全部是大学学历的本地白人，而急诊剖宫产率在有配偶暴力史与无固定住所的妇女中上升。
::: solution
**选择作为一种分配品（[[#def-closure]]、[[#def-measurement]]、[[obstetrics-gynaecology/labour-birth]]）：这是“普遍服务扩大差距”的教科书案例：一项以信息为工具的选择政策，把决定权交给那些最有余力理解与谈判与安排交通与在紧急时有支持的人；对另一些人，“选择”只是把服务从身边移走的外包装。要做的修正有四：一，把咨询从“发手册”改为结构化对话（用可及的语言与图示与决策辅助、由同一名助产士或固定的关系提供者持续陪伴——连续性照护本身是对弱势孕妇最有效的干预、并被随机试验证实改善了满意度与早产）——[[obstetrics-gynaecology/pregnancy-antenatal]]。二，把风险沟通按人给：生育地点的安全性由产科风险与到最近产房的时间与住所条件与紧急时的支持者决定，所以“是否适合”的问题必须包括“你半夜怎么到医院”；对无家者与遭受暴力者，医院才是安全选项，而这一点必须写在评估里而不是靠她自己想到——[[obstetrics-gynaecology/pregnancy-complications]]、[[paediatrics/safeguarding]]。三，把不平等变成监测项：按剥夺与族群与语言与年龄与胎次报告生育地点与结局与转运率与不良事件（并把“未记录”作为指标）；对剖宫产率的差异要区分需求差异与获取与决策差异（在有暴力史与无住所者中，急诊剖宫产上升提示产时的连续性中断与缺乏支持，需要个案复盘）。四，把“选择”重新定义为包括支持：非医院分娩的资格要与“有人陪产与有电话与有交通与有可联系的团队”绑定，并把这些条件补齐（而不是取消选项）——[[clinical-skills/communication]]、[[public-health/health-systems-economics]]。

::: exercise 解释这个悖论 {level=1}
某国二十年间癌症死亡率下降40%，而最贫困五分位与最富裕五分位之间的癌症死亡差距扩大了。请用两个机制解释。
::: solution
**两个机制（[[#def-determinants]]、[[#def-measurement]]、[[pathology/cancer-diagnosis]]）：一，“根本原因”的机制：新的知识与技术（筛查、疫苗、手术与肿瘤内科的进步、以及治疗的可及）首先被资源更多的群体获取——所以总体曲线下移而斜率变陡；这在时间上可检验（比较两组曲线开始下降的年份，通常相差数年）。二，暴露与风险的迁移在两组之间不同步：烟草的下降在高教育群体中更早发生（且被筛查的参与放大），而肥胖与酒精与某些感染（幽门螺杆菌与人类乳头状病毒与肝炎）在贫困群体中的负担相对上升，同时筛查参与率与诊断延迟按剥夺分层——于是 发病率与分期 都在往不利方向移动。要区分二者需要：按癌种与年龄与分期与剥夺分层（分开死亡率与发病率与分期分布，以免把 先入时间 与编码变化误认为公平改善）；以及按组别与年份的筛查参与率与治疗启动时间作为中间指标（“两个组都在下降、只是速度不同”这一图形，比总差距的数字更有说服力）——[[public-health/screening]]、[[epidemiology-ebm/measuring-disease]]。**

::: exercise 写一次改变处方的两分钟谈话 {level=2}
一位靠福利生活的65岁女性有哮喘与骨关节炎与抑郁；她的吸入剂“没用完就断了”、非甾体抗炎药是她唯一相信的止痛药。写出你会说的内容与随后的处方改变。
::: solution
**两分钟（[[#def-closure]]、[[respiratory/asthma-copd]]、[[pharmacology/patient-variation]]）：先承认她的理论与她的账本：吸入剂“不像药片那样立刻有感觉”（这是控制与缓解的差别，需要用一句话与一个图示讲清），而“能拿到、不花钱、马上有效”的药片自然会赢——问题不是她不依从，而是方案与她的现实不匹配。然后重排方案：把控制药变成免费或最低成本的选项并一次开足三个月（并让药房在断药前提醒）；把装置换成她能用对的（与技师核对技术与吸气流速，并让她回述）、把需要每天多次与需要冷藏与需要“感觉有效”的方案删掉；给骨关节炎一条非药物与安全的止痛路径（局部非甾体或对乙酰氨基酚的定时使用、以及减重与运动治疗与助行与鞋与跌倒风险的评估），并说明与哮喘相关的风险（阿司匹林加重的呼吸道疾病在少数人中存在，问她以往是否有鼻炎与鼻息肉与发作加重）——[[musculoskeletal/osteoarthritis]]、[[pharmacology/adverse-reactions]]。抑郁的一层：把治疗与“精力与做事的能力”绑定并选择对体重与睡眠影响小的方案，并接上可负担的心理治疗路径（以及把债务与福利咨询作为“处方”的一部分）——[[psychiatry/mood-disorders]]、[[clinical-skills/communication]]。收尾要具体：“三个月后我来打电话问你两件事：吸入剂还剩几支、上个月有没有夜间被喘醒”——把随访设计成她能完成的形式，并把断药作为服务的质量指标而非她的失败——[[clinical-skills/patient-safety]]。**

::: exercise 做一次健康影响评估 {level=2}
拟议的一条环城货运铁路将穿过三个低收入社区（振动与夜间施工与拆迁、以及预期的空气改善因为卡车减少）。请做一份简明的健康影响评估。
::: solution
**健康影响评估（[[#def-closure]]、[[#def-determinants]]、[[public-health/environmental-occupational]]）：先给结论的形式：净效应取决于缓解措施是否被写入合同与预算——所以评估的目的不是预测一个数，而是让分配性后果可见并附加条件。路径分析：建设的短期（噪声与振动与粉尘对睡眠与心血管与儿童学习的影响；夜间施工需要上限与监测与独立申诉通道与“受影响家庭”的临时安置）；拆迁与补偿（最直接的健康决定因素：强迫迁移与社区网络与社会资本与学校中断的损失，以及“同一社区不同补偿率”的不公平）；运营期（空气改善与噪声与振动的新来源、以及铁路道口与绕行对步行的分割——一条线路可以毁掉一条步行网，这是城市建成环境里最常见的隐性伤害）；以及机会（站点周边的就业与可负担住房的承诺与沿线绿色空间与“谁先获得工作”的本地雇佣条款）。评估方法：按十分位与年龄与既有疾病分层的暴露—反应估算（颗粒物与噪声性心血管病与睡眠干扰的效应量），并明确写出无法量化的部分（社区解体、安全感、以及“承诺被反复违背”的历史）；把不平等影响单列而不是并入总量（一个总体为正的项目可以在净收益下伤害最贫困的一组）——[[public-health/environmental-occupational]]、[[public-health/health-systems-economics]]。治理要求：施工期与健康指标的实时公开与超限暂停的规则、缓解资金的独立管理、健康影响评估的约束力（其建议被拒绝须书面说明）、以及“承诺被追踪”的十年期随访——健康影响评估最常见的失败不是方法错，而是它被当作许可程序里的一章——[[public-health/prevention-promotion]]、[[clinical-skills/patient-safety]]。**

::: exercise 在听证会上作证 {level=3}
一场关于本国疫情应对的公开听证要求你就“健康不平等是否被忽视”作证。你会说哪三点、承认什么、以及拒绝支持什么主张。
::: solution
**作证（[[#def-measurement]]、[[#def-closure]]、[[public-health/global-health]]）：三点主张：一，不平等在数据可用之前就已经是可知的——多数国家在暴发最初几周就有按族群与地区的住院差异，而它们没有出现在风险沟通与资源配置里；这暴露了“监测有数据但没有响应机制”的制度缺陷（不平等监测必须是法定的、并要求书面响应）。二，被忽视的不平等首先是政策设计的产物而非解释的失败：需要自检与隔离与请假的政策预设了有薪假与独立的房间与可靠收入；没有这些，措施把风险转嫁给最无力遵守者，于是把死亡分配给了同一批社区；因此“公平影响评估”应与措施同时出台而非事后追补——[[public-health/communicable-disease-control]]、[[medical-ethics-law/justice-resources]]。三，非卫生服务的关闭是隐性致死的一部分：被中断的筛查与免疫与心理健康与成瘾服务与心血管疾病的治疗，其代价数年后才出现，且按剥夺分层——所以要提前把这些“被推迟的伤害”写进响应计划并公开测量。要承认的：不确定性是真实的（早期关于传播与无症状感染的知识确实不足），以及一线人员（许多本身来自被忽视的社区）做了超出能力的事——把系统失败说成个人失败会毁掉学习的机制。要拒绝的主张：把族群差异归因于文化或“不守规矩”或基因；把责任推给个人责任；以及用“我们没人知道”这一说法替决策免责——因为有数据却未行动，与没有数据，在道德与制度上不同。收尾一句：请本听证会评估的不是谁说了错话，而是为何我们的制度在没有新证据的八周里依然不做本可做的事——并把这条写入法定的公平响应要求——[[clinical-skills/patient-safety]]、[[public-health/determinants-inequalities]]。**
