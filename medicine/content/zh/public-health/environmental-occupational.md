2020年12月，伦敦的一位验尸官认定，空气污染对埃拉·阿杜-基西-德布拉（Ella Adoo-Kissi-Debrah）的死亡起了实质性作用。她是一个患有严重哮喘的九岁女孩，住在南环路附近。这是英国第一次把空气污染记录为一个人的死因。同一个月，在罗奇代尔，两岁的阿瓦布·伊沙克（Awaab Ishak）因长期暴露于其家庭所住社会住房公寓中的霉菌而死于呼吸系统疾病；随后出台的法律即“阿瓦布法”（Awaab's Law），要求英格兰的社会住房房东在规定时限内调查并修复严重的潮湿和霉菌隐患。两起死亡都源于已知、可测量且可预防的暴露。

环境卫生和职业卫生研究人们生活和工作所处的物理、化学和生物条件对健康的影响。本章介绍环境危害如何评估，英国和全球主要的环境暴露（空气污染、气候变化与高温、住房、化学品和辐射），以及职业病：其识别、法律框架和预防。临床医生的作用至关重要：除非有人询问，职业和环境病因常常被遗漏。

## 危害、暴露与风险 {#hazard-risk}

::: definition 危害、暴露与风险 {#def-hazard}
- **危害**是任何有可能造成伤害的东西：化学品、物理因素（噪声、辐射、高温）、生物因素或某种情境。
- **暴露**是人与危害之间的接触。用途径（吸入、摄入、皮肤接触）、浓度或强度、持续时间和频率来描述。**剂量**是进入人体或到达靶器官的量。
- **风险**是在特定暴露下发生伤害的概率及其严重程度。

没有暴露的危害不构成风险：密封在无人触动的天花板中的石棉是一种危害，但当有人在上面钻孔时就成了风险。
:::

**环境健康风险评估**包括四个步骤：**危害识别**（根据毒理学和流行病学，该因素能否造成伤害？）；**暴露-反应评估**（风险如何随剂量变化？）；**暴露评估**（谁暴露了、暴露多少、持续多久？）；以及**风险表征**（综合上述各项估计人群中的负担及其不确定性）。评估结果为**风险管理**提供依据：标准、限值和干预措施，同时还要权衡成本、可行性和公众的价值观。

两类暴露-反应关系对设定限值很重要。对于许多毒性效应，存在一个**阈值**，低于该阈值预期不会有伤害，可以在其下设定留有安全余量的限值。对于遗传毒性致癌物以及细颗粒物和铅等某些污染物，无法确定阈值：风险随暴露降低而下降，但永远不会降到零。这类物质的限值根据对何种风险可接受、可实现的判断来设定，暴露应保持在**合理可行的最低水平**。

## 空气污染 {#air-pollution}

与健康有关的主要室外污染物有：

- **颗粒物。** PM₁₀（直径小于10 µm的颗粒）和PM₂.₅（小于2.5 µm）。细颗粒物能深入肺部，有些可进入血液循环。来源包括道路交通（尾气以及刹车和轮胎磨损）、家庭燃烧木材和煤炭、工业、农业（氨形成二次颗粒物）以及从国外飘来的颗粒物。
- **二氧化氮**（NO₂），主要来自柴油车。
- **臭氧**（O₃），由其他污染物在阳光下生成，夏季以及城市下风向的农村地区最高。
- **二氧化硫**，随着燃煤减少，英国的浓度现在已很低。

长期暴露于PM₂.₅会增加心血管和呼吸系统疾病以及肺癌的死亡率，并与2型糖尿病、低出生体重和痴呆有关。短期峰值会增加哮喘、慢阻肺和心血管事件的住院。儿童、老年人、心肺疾病患者以及住在繁忙道路附近贫困地区的人受影响最大。

世卫组织2021年的**《空气质量指南》**将PM₂.₅年均指导值设定为**5 µg/m³**（从2005年的10 µg/m³减半），NO₂为10 µg/m³，这反映了在很低浓度下就有危害的证据。英国PM₂.₅年均浓度的法定限值为20 µg/m³，英格兰的目标是到2040年达到10 µg/m³。空气污染物医学效应委员会（COMEAP）估计，在英国，长期暴露于人为空气污染对死亡率的年度影响相当于28,000至36,000例死亡。

::: theorem 长期暴露于PM₂.₅的暴露-反应关系 {#thm-pm-response}
队列研究表明，长期死亡风险随PM₂.₅年均浓度大致呈对数线性上升，且没有阈值。如果系数表示为每10 µg/m³的相对危险度$RR_{10}$，则浓度变化$\Delta c$对应

$$
RR(\Delta c) = RR_{10}^{\,\Delta c/10}.
$$ {#eq-pm-rr}

COMEAP在英国的负担计算中对30岁及以上成年人的全因死亡率使用了$RR_{10} = 1.06$。在整个人群中，归因于超额暴露$\Delta c$的死亡比例为$1 - 1/RR(\Delta c)$。
:::

::: proof
如果浓度每增加一个增量都使风险乘以同一个因子，那么风险是浓度的指数函数，因此变化$\Delta c$对应的相对危险度就是$RR_{10}$的若干次幂，幂次为$\Delta c$中包含的10 µg/m³步长的个数。当整个人群都暴露于这一超额浓度时，归因分数为$(RR - 1)/RR = 1 - 1/RR$，即暴露流行率为1时的人群归因分数。由于这一关系没有阈值，即使浓度已远低于现行限值，每一次降低都预期会减少死亡。
:::

::: example 清洁空气的获益 {#ex-air}
某城市30岁及以上成年人每年死亡9,000人。清洁空气区以及禁止燃烧湿木材的措施预计将使人口加权的PM₂.₅年均浓度从12 µg/m³降至10 µg/m³。使用$RR_{10} = 1.06$，估计该政策从长期看每年可预防多少死亡。
::: solution
$\Delta c = 2$ µg/m³。$RR = 1.06^{0.2} = 1.0117$。

归因分数$= 1 - 1/1.0117 = 0.0116$，即1.16%。

预防的死亡$\approx 9{,}000 \times 0.0116 = 104$例/年。

对一座城市来说，这个数字似乎不大，但收益会在多年中累积，同时伴随住院减少和儿童肺部发育改善。获益是逐步到来的，因为长期暴露的影响需要数年才能逆转。这类估计也有不确定性：系数有置信区间，而且各地颗粒物的组成不同。
:::
:::

**室内空气。** 英国人大部分时间待在室内。室内危害包括潮湿和霉菌（哮喘、呼吸道感染，罕见情况下导致致命疾病，如阿瓦布·伊沙克之死）、故障燃具产生的一氧化碳（一个家庭的几名成员出现头痛、头晕和恶心，离开家后好转）、二手烟，以及燃烧木材和烹饪产生的颗粒物。在全球范围内，用固体燃料和煤油做饭造成的**家庭空气污染**是低收入国家妇女和幼儿的主要死因之一。

临床医生的贡献在于：询问家庭和工作暴露情况，就减少暴露提供建议（例如为肺病患者提供高污染日的建议），记录环境因素对疾病的影响，并支持患者向房东和地方政府提出的诉求。

## 气候变化与健康 {#climate}

气候变化直接通过热浪、洪水、风暴和野火影响健康，间接通过对粮食和水安全、空气质量、伊蚊和蜱等病媒的分布范围、流离失所和冲突以及精神健康的影响来影响健康。它加剧了现有的不平等，因为最贫困的人和国家暴露最多、适应能力最弱，而他们对排放的贡献最小。

**高温。** 当温度超过某一阈值时，死亡率急剧上升，尤其是75岁以上的人，患有心血管、呼吸系统或肾脏疾病、痴呆或严重精神疾病的人，服用某些药物（利尿剂、抗胆碱能药、某些抗精神病药）的人，独居者，以及顶层公寓和照护院的住户。在英格兰，UKHSA运行一套**高温健康警报**系统，根据预测的影响发布黄色、琥珀色和红色警报；它估计2022年夏季约有3,000例与高温有关的死亡，那一年英国首次录得40 °C以上的气温。简单的措施就能挽救生命：事先识别脆弱人群、探视他们、保持住所凉爽、在适当时调整用药并确保补充水分。长期适应措施包括建筑设计、城市绿地和照护院标准。

**减缓的协同效益。** 许多减少温室气体排放的措施也能直接改善健康：主动出行（更多身体活动、更少空气污染）、减少红肉和加工肉的饮食，以及更温暖、保温更好的住房。英格兰NHS已承诺，其直接控制的排放到2040年实现净零，其能够影响的排放（包括供应链）到2045年实现净零。卫生保健约占全国排放的4%～5%；含推进剂气体的吸入器、麻醉气体和药品是重要的排放源。

## 化学品、辐射和其他危害 {#chemicals}

- **铅**会对儿童造成神经发育损害，且没有已知的安全阈值。来源包括旧的含铅油漆、铅制水管、某些进口化妆品和偏方、受污染的土壤以及某些爱好和职业。在英格兰，儿童血铅的**公共卫生干预浓度**于2021年降至**0.24 µmol/L（5 µg/dL）**，达到或超过该浓度的病例须报告并调查来源。
- **氡**是一种来自岩石和土壤中铀的放射性气体，在某些地区（例如康沃尔、德文、德比郡和北安普敦郡的部分地区）会在建筑物内积聚。它是英国仅次于吸烟的第二大肺癌病因，在吸烟者中其风险成倍增加。英国住宅的行动水平为200 Bq/m³；整治措施（集气坑、通风）是有效的。
- **一氧化碳**与血红蛋白结合，导致头痛、恶心、意识模糊和死亡；当同一建筑中的几个人或宠物患病时应怀疑一氧化碳中毒，并通过测定碳氧血红蛋白予以确认。报警器和燃具维护可以预防。
- **水。** 安全的饮用水取决于水源保护、处理和输配。暴发仍有发生（例如公共供水中的*隐孢子虫*）。
- **化学事件**（火灾、泄漏、蓄意释放）由应急服务部门处置，UKHSA就暴露、洗消和健康影响提供建议；见[[emergency-critical-care/major-incidents]]。
- 来自道路、铁路和飞机的**环境噪声**干扰睡眠，并与高血压和心血管疾病有关。

::: example 一名血铅升高的儿童 {#ex-lead}
一名3岁女孩因缺铁性贫血和便秘接受检查。她的父母提到她经常把油漆碎片放进嘴里。这家人最近搬进了一栋正在翻修的维多利亚式联排住宅，窗框上的旧油漆正被打磨掉。她的血铅浓度为0.48 µmol/L。解读这一结果并概述公共卫生应对措施。
::: solution
**解读。** 0.48 µmol/L（约10 µg/dL）是英格兰公共卫生干预浓度0.24 µmol/L的两倍。缺铁会增加铅的吸收，而异食癖（吃非食物物质）是典型的暴露途径。20世纪60年代以前建造的房屋广泛使用含铅油漆，干法打磨旧油漆会产生细小的铅尘，落在地板、窗台和玩具上。

**报告和调查。** 该结果报告给当地UKHSA卫生防护团队。环境卫生官员上门识别来源（油漆、灰尘、水管、土壤、化妆品或传统偏方，以及父母可能通过衣服把铅带回家的职业或爱好），并就安全整治提供建议。

**减少暴露。** 停止干法打磨；处理旧油漆的工作应由经过培训的承包商采用湿法作业并加以围护，期间孩子不在家中；用湿布和湿拖把清洁；经常洗手和清洗玩具。家中的兄弟姐妹和其他儿童应接受检测，并为家中的孕妇提供建议，因为铅能通过胎盘。

**临床照护。** 治疗缺铁，这也能减少铅的吸收；复查血铅以确认其正在下降；转诊给儿科医生，由其在专科毒理学建议下决定是否需要螯合治疗（在这一水平很少需要）。适合进行发育随访，因为对于发育中的大脑，铅没有已知的安全水平。
:::
:::

## 职业卫生 {#occupational}

工作可能损害健康，健康也可能影响工作能力。好的工作也是良好健康最强的决定因素之一：失业与更差的身心健康和更高的死亡率相关。

::: definition 职业病与工作相关疾病 {#def-occupational}
**职业病**是主要或完全由工作中的暴露所致的疾病，例如石棉所致的间皮瘤、结晶二氧化硅所致的矽肺，或噪声性听力损失。**工作相关疾病**的范围更广：由工作引起或因工作而加重的疾病，包括肌肉骨骼疾病以及压力、抑郁或焦虑，在大不列颠，二者合计占自报工作相关疾病的大部分。

**控制层级**把保护工作者的措施从最有效到最无效排序：

1. **消除**：去除危害（停止使用石棉）。
2. **替代**：用危害较小的东西替代（用水性涂料代替溶剂型涂料）。
3. **工程控制**：把人与危害隔开（封闭、局部排风、防护装置、隔音屏障）。
4. **管理控制**：改变工作方式（岗位轮换、限制暴露时间、培训、标识）。
5. **个人防护装备**（PPE）：呼吸器、手套、听力保护器。

PPE是最后一道防线，因为它取决于每个工作者每一次的正确选择、适配、使用和维护，而且只保护佩戴者本人。
:::

### 大不列颠的法律框架 {#law}

**《1974年工作健康与安全法》**（Health and Safety at Work etc. Act 1974）规定雇主负有一般义务，在合理可行的范围内确保雇员和受其工作影响的其他人的健康、安全和福利。**健康与安全执行局**（HSE）和地方政府负责执法。具体法规包括：

- **《2002年有害健康物质控制条例》**（COSHH），要求评估和控制对有害物质的暴露，并在适当时进行健康监护。HSE公布了许多物质的**工作场所暴露限值**（EH40）；
- **《2012年石棉控制条例》**；
- **《2005年工作噪声控制条例》**，规定了80 dB(A)的较低暴露行动值（雇主必须提供信息并提供听力保护器）、85 dB(A)的较高暴露行动值（必须佩戴听力保护器，须开展噪声控制计划和健康监护），以及考虑听力保护后不得超过的87 dB(A)暴露限值；
- **《2005年工作振动控制条例》**（手臂振动综合征）；
- **《2013年伤害、疾病和危险事件报告条例》**（RIDDOR）。当雇主收到医生将疾病与工作联系起来的书面诊断时，必须报告某些已诊断的职业病（包括腕管综合征、手或前臂严重痉挛、职业性皮炎、手臂振动综合征、职业性哮喘、肌腱炎、职业性癌症以及生物因素所致疾病）。

患有某些由工作引起的**法定疾病**（prescribed diseases）的人，可以申请工伤残疾津贴，无需证明雇主有过失。

### 重要的职业病 {#diseases}

- **石棉相关疾病。** 吸入的石棉纤维在暴露数十年后（间皮瘤通常为30～40年或更长）导致间皮瘤、肺癌、石棉肺和胸膜斑。英国于1999年禁止使用石棉，但2000年以前建造的许多建筑中仍有石棉，扰动它的人（建筑工人、管道工、电工）仍会暴露。在大不列颠，间皮瘤每年导致2,000多人死亡，主要是数十年前在造船、建筑和工业中暴露的男性。几乎所有间皮瘤都由石棉引起，因此每个病例都应采集详细的职业史。
- **矽肺**，由采石、石匠作业、建筑以及近来切割人造石厨房台面时产生的可吸入结晶二氧化硅引起，后者已在年轻工人中引起严重、快速进展的矽肺；澳大利亚于2024年禁止使用人造石。
- **职业性哮喘**，由异氰酸酯（喷漆）、面粉和谷物粉尘（面包师）、木尘、乳胶、戊二醛和实验动物等致敏物，或由刺激物引起。早期诊断并脱离暴露能带来最好的恢复机会。
- **职业性皮炎**，刺激性或过敏性，常见于美发师、卫生保健工作者（湿作业和手套）、清洁工、厨师和建筑工人（水泥）。
- **噪声性听力损失**，听力图上在约4 kHz处有特征性切迹，伴耳鸣。
- **手臂振动综合征**，使用振动工具者出现血管（白指）、感觉和肌肉骨骼方面的表现。
- **职业性癌症**，包括芳香胺所致的膀胱癌（历史上见于染料和橡胶工人），以及波特（Percivall Pott）于1775年描述的扫烟囱工人阴囊癌。
- **肌肉骨骼疾病**以及**工作相关的压力、抑郁和焦虑**，是损失工作日的最常见原因。
- **感染**：卫生保健中的针刺伤（乙型和丙型肝炎、HIV）、农场工人和兽医中的人畜共患病（Q热、钩端螺旋体病），以及结核病。

::: example 一位患哮喘的面包师 {#ex-baker}
一名34岁男性在一家超市面包房工作了三年，因一年前开始出现喘息和气促就诊。他在工作时有鼻炎，休假时症状好转。最可能的诊断是什么？应如何确诊？有什么影响？
::: solution
**可能的诊断。** 由致敏物引起的职业性哮喘，可能是面粉粉尘或真菌α-淀粉酶（一种添加到面粉中的酶）。鼻炎常先于哮喘出现，离开工作后好转是关键线索。

**确诊。** 确认哮喘（含可逆性试验的肺量计检查、FeNO）。每天至少四次、持续数周的连续呼气峰流速记录（包括在岗和离岗期间），用经过验证的方法分析，可以为与工作相关的模式提供客观证据。针对面粉和淀粉酶的特异性IgE或皮肤点刺试验支持致敏的存在。应尽早转诊给职业性肺病专科医生，因为这一诊断对他的工作有重大影响，应客观地作出。

**处理。** 目标是尽早停止对致敏物的暴露：持续暴露会使预后变差，而且暴露结束后哮喘仍可能持续，尤其是在诊断延误的情况下。单靠呼吸防护通常是不够的。经他同意，应告知雇主，以便为他和他的同事减少暴露（除尘等工程控制，避免倾倒面粉等产尘作业），雇主必须根据RIDDOR报告这一诊断。他可能有资格领取工伤残疾津贴。对同事进行健康监护可能会发现其他病例。关于就业权利和再培训的建议很重要，因为职业性哮喘常常导致失业。
:::
:::

### 噪声暴露 {#noise}

声级用对数分贝标度测量，经A计权（dB(A)）以反映人耳的灵敏度。每增加3 dB，声能翻倍，因此88 dB(A)持续4小时与85 dB(A)持续8小时的噪声剂量相同。**个人日噪声暴露量**$L_{EP,d}$把暴露归一化为8小时工作日：

$$
L_{EP,d} = L_{A} + 10 \log_{10}\!\left(\frac{T}{8}\right),
$$ {#eq-lepd}

其中$L_A$是暴露期间的平均声级，$T$是以小时计的暴露时间。不同时段的暴露通过声能相加来合并，而不是分贝相加。

::: widget plot
f: L + 10*log10(x/8)
x: 0.25, 8
y: 70, 100
sliders: L=94:80:105:1
hlines: 80; 85; 87
labels: L_{EP,d}\ \text{（dB(A)）}
caption: 一名工作者暴露于L dB(A)噪声x小时、其余时间安静时的个人日噪声暴露量。水平线分别为较低和较高暴露行动值（80和85 dB(A)）以及暴露限值（87 dB(A)）。在94 dB(A)下，约一小时就足以达到较高行动值；声级每增加3 dB，允许时间减半。
:::

::: example 一名工作者的噪声暴露 {#ex-noise}
一名木工每天使用一台在其耳旁平均产生92 dB(A)的圆锯2小时，其余时间处于安静环境中。(a) 他的$L_{EP,d}$是多少？(b) 雇主有哪些义务？(c) 如果他每天还在嘈杂的车间里以85 dB(A)度过4小时，他的总$L_{EP,d}$是多少？
::: solution
(a) $L_{EP,d} = 92 + 10\log_{10}(2/8) = 92 - 6.0 = 86.0$ dB(A)。

(b) 这超过了较高暴露行动值（85 dB(A)），但未超过暴露限值（87 dB(A)，考虑听力保护）。雇主必须通过一系列技术和组织措施（更安静的设备、隔声罩、限制时间）在合理可行的范围内减少暴露，划定听力保护区并在其中强制佩戴听力保护器，并提供健康监护（定期听力测定）、信息和培训。

(c) 声能相加：$10\log_{10}\!\left[\dfrac{2 \times 10^{9.2} + 4 \times 10^{8.5}}{8}\right] = 10\log_{10}(3.96 \times 10^{8} + 1.58 \times 10^{8}) = 10\log_{10}(5.54 \times 10^{8}) = 87.4$ dB(A)。

他的每日总暴露约为87.4 dB(A)。如果不佩戴听力保护器，这将超过87 dB(A)的暴露限值，因此有效的噪声控制和正确适配的听力保护器必不可少。
:::
:::

### 临床医生的作用 {#clinician}

疾病的职业和环境病因常被遗漏。每位临床医生都应能够采集**职业史**：你做什么工作？你实际做些什么？你暴露于什么（粉尘、烟雾、化学品、噪声、振动、感染、压力）？工作中的其他人是否有类似症状？周末或休假时症状是否好转？你过去做过哪些工作，尤其是在工业、建筑或造船业？对于潜伏期长的疾病，如间皮瘤，相关暴露可能发生在40年前。

临床医生还开具**病假证明**（fit note），自2022年起，除医生外，注册护士、作业治疗师、药剂师和物理治疗师也可以开具；病假证明可以就分阶段复工、调整工作时间、调整职责或工作场所改造提出建议。职业卫生服务就工作能力、调整措施和健康监护为雇主提供建议。《2010年平等法》要求雇主为残疾雇员作出合理调整。

::: warning PPE不是首选答案
发现工作场所暴露时，本能的反应是建议戴口罩、手套或耳罩。这些是效果最差的控制措施。呼吸器只有在类型正确、针对个人脸型进行了适配测试、在整个暴露期间佩戴并得到维护时才能起保护作用；胡须会破坏密封；听力保护器常因不舒适或妨碍交流而被摘下。法律要求雇主沿控制层级逐级向下：首先是消除、替代和工程控制。只建议使用PPE的临床医生信函或报告，可能使该工作者及其同事继续暴露。
:::

::: quiz
一位68岁的退休管道工因气促和单侧胸腔积液就诊。胸膜活检显示间皮瘤。下列哪一项是正确的？
- [ ] 职业史无关紧要，因为他已退休数年。
- [x] 他的石棉暴露可能发生在30～40年或更久以前，他和他的家人可能有权获得赔偿。
- [ ] 间皮瘤主要由吸烟引起。
- [ ] 只有在他仍受雇时，他的前雇主才需根据RIDDOR报告这一诊断。
::: solution
几乎所有间皮瘤都由石棉引起，潜伏期通常为30～40年或更长，因此是否退休无关紧要。应采集详细的职业史（以及家庭暴露史，例如清洗亲属的工作服）。他可能有权获得工伤残疾津贴、法定计划下的一次性赔付以及民事赔偿；应尽早提供专业建议。间皮瘤死亡须提交验尸官，因为通常是由职业病导致的。吸烟不会引起间皮瘤，尽管它会使石棉所致的肺癌风险成倍增加。
:::
:::

::: history
1700年，拉马齐尼（Bernardino Ramazzini）出版了《论手工业者的疾病》（*De Morbis Artificum Diatriba*），描述了50多种职业的疾病，并敦促医生询问患者从事什么工作。1775年，波特描述了儿童时期就被派去爬烟囱的扫烟囱工人的阴囊癌，这是第一种职业性癌症。19世纪的《工厂法》开始规范英国的工作条件。在美国，汉密尔顿（Alice Hamilton）在20世纪初对铅和其他工业毒物的调查奠定了工业医学的基础。1952年12月，伦敦的一场烟雾在随后几周内造成约4,000例超额死亡，后来的估计还要高得多；它促成了《1956年清洁空气法》。1955年，多尔（Richard Doll）证明石棉工人患肺癌的风险大大增加；1960年，瓦格纳（Christopher Wagner）及其同事把间皮瘤与南非的青石棉开采联系起来。《1974年工作健康与安全法》建立了英国现代的工作场所监管体系。
:::

## 后续内容

空气污染和吸烟作为慢性病的危险因素在[[public-health/non-communicable-disease]]中讨论，环境疾病和气候变化的全球负担见[[public-health/global-health]]。环境损伤的病理学见[[pathology/environmental-pathology]]，职业性肺病见[[respiratory/interstitial-vascular-disease]]，化学事件见[[emergency-critical-care/major-incidents]]。

::: summary
- **危害**是造成伤害的可能性，**暴露**是接触，**风险**是伤害的概率和严重程度。风险评估包括危害识别、暴露-反应评估、暴露评估和风险表征。某些危害（细颗粒物、铅、遗传毒性致癌物）没有阈值。
- **空气污染**（PM₂.₅、NO₂、臭氧）增加心血管、呼吸系统和癌症死亡率。世卫组织2021年PM₂.₅年均指导值为5 µg/m³；英国限值为20 µg/m³。COMEAP估计其影响相当于英国每年28,000～36,000例死亡。室内潮湿和霉菌、一氧化碳和家用燃料烟雾也很重要。
- **气候变化**通过高温、洪水、粮食、病媒和流离失所损害健康；高温主要导致老年人和慢性病患者死亡。减缓措施带来健康协同效益。
- **铅**（英格兰儿童干预浓度0.24 µmol/L）、**氡**（行动水平200 Bq/m³）和**一氧化碳**是可预防的家庭危害。
- **控制层级**把消除和替代放在首位，PPE放在最后。主要法律：《1974年工作健康与安全法》、COSHH、《工作噪声控制条例》（80、85和87 dB(A)）、《石棉控制条例》、RIDDOR。
- 重要的职业病包括间皮瘤和其他石棉相关疾病、矽肺、职业性哮喘、皮炎、噪声性听力损失和手臂振动综合征；压力和肌肉骨骼疾病造成了大部分工作相关疾病。
- 始终采集职业史和环境暴露史；潜伏期长的疾病需要终生的工作史。
:::

## 习题

::: exercise 日噪声暴露 {level=1 check="round(10*(95+10*log10(1/8)))/10"}
一名工作者每天暴露于95 dB(A)噪声1小时，其余时间处于安静环境中。计算$L_{EP,d}$，保留1位小数。
::: solution
$L_{EP,d} = 95 + 10\log_{10}(1/8) = 95 - 9.03 = 86.0$ dB(A)，高于较高暴露行动值。
:::
:::

::: exercise 允许时间 {level=2 check="round(100*8*10^((85-94)/10))/100"}
一名工作者暴露于94 dB(A)噪声多少小时后，$L_{EP,d}$会达到85 dB(A)的较高暴露行动值？保留2位小数。
::: solution
解$94 + 10\log_{10}(T/8) = 85$：$\log_{10}(T/8) = -0.9$，因此$T = 8 \times 10^{-0.9} = 1.01$小时。声级每升高3 dB(A)，允许时间减半。
:::
:::

::: exercise 血铅的单位 {level=1 check="round(10*0.24/0.0483)/10"}
血铅浓度从µmol/L换算为µg/dL时除以0.0483。把英格兰0.24 µmol/L的公共卫生干预浓度换算为µg/dL，保留1位小数。
::: solution
$0.24/0.0483 = 4.97$，即5.0 µg/dL。
:::
:::

::: exercise 控制层级 {level=1}
一家家具作坊使用一种会引起头痛的溶剂型胶水，工人用手持砂光机打磨硬木，产生可见的粉尘。按照控制层级的顺序，为每种危害提出控制措施。
::: solution
**溶剂型胶水。** 消除：如可行，采用不需要胶水的工艺。替代：使用挥发性和毒性较低的水性胶粘剂。工程控制：在涂胶工作台设置局部排风，封闭式施胶。管理控制：限制使用量、盖好容器、培训、轮岗。PPE：合适的手套，只有在暴露无法以其他方式控制时才使用呼吸防护。

**硬木粉尘**（一种呼吸道致敏物，某些硬木还会导致鼻腔癌）。消除或替代：使用预涂装部件，或产尘较少的工艺。工程控制：带一体化工具端吸尘、连接合适除尘装置的砂光机，以及下吸式工作台；用吸尘器清洁，而不是扫地或用压缩空气吹。管理控制：维护和检测除尘设备、培训、健康监护（呼吸问卷）。PPE：针对残余暴露使用经适配测试的呼吸器。
:::
:::

::: exercise 归因于空气污染的死亡 {level=2 check="round(20000*(1-1/1.06^(0.5)))"}
某地区30岁及以上成年人每年死亡20,000人。政策预计将使人口加权的PM₂.₅降低5 µg/m³。使用$RR_{10} = 1.06$，估计从长期看每年可预防多少死亡。给出整数。
::: solution
$RR = 1.06^{0.5} = 1.0296$。归因分数$= 1 - 1/1.0296 = 0.0287$。预防的死亡$\approx 20{,}000 \times 0.0287 = 575$例/年。
:::
:::

::: exercise 合并噪声暴露 {level=2 check="round(10*10*log10((4*10^9 + 4*10^8.5)/8))/10"}
一名工作者在90 dB(A)下工作4小时，在85 dB(A)下工作4小时。计算$L_{EP,d}$，保留1位小数。
::: solution
$L_{EP,d} = 10\log_{10}\!\left[\dfrac{4 \times 10^{9.0} + 4 \times 10^{8.5}}{8}\right] = 10\log_{10}(5 \times 10^8 + 1.58 \times 10^8) = 10\log_{10}(6.58 \times 10^8) = 88.2$ dB(A)。85 dB(A)时段的贡献很小；较响的时段起主导作用。
:::
:::

::: exercise 全家头痛 {level=2}
一月份，一位女性带着两个孩子到全科医生处就诊，他们头痛、恶心和疲倦已有一周；她本人也有类似症状，他们在学校和工作单位时都感觉好些。他们家的狗也无精打采。应怀疑什么？应怎么做？
::: solution
应怀疑**一氧化碳中毒**：一个家庭的几名成员（和一只宠物）出现非特异性症状，离开家后好转，且发生在使用暖气的冬季。测定碳氧血红蛋白（静脉血或动脉血，或呼气CO；脉搏血氧仪无法区分），同时要考虑到离开污染源后其水平会下降。如果确诊或高度怀疑，紧急转诊进行评估并给予高流量氧气；重症病例（意识丧失、神经系统体征、妊娠、心肌缺血）需要住院治疗。在燃具得到检查之前，这家人不应回家：建议他们联系燃气应急服务，如果污染源可能仍然存在，应离开住宅。报告当地卫生防护团队，由其提供建议并安排调查；建议安装声响式一氧化碳报警器并定期维护燃具。同一栋楼里的其他住户也可能受到影响。
:::
:::

::: exercise 为热浪作规划 {level=3}
一家全科诊所服务的老年人很多，其中包括两家照护院。UKHSA为下一周发布了琥珀色高温健康警报。描述诊所及其合作伙伴应采取的行动，并解释为什么某些药物很重要。
::: solution
利用诊所登记册**识别高风险者**：75岁以上的人，独居者，患有心血管、呼吸系统或肾脏疾病、糖尿病、痴呆、严重精神疾病、帕金森病或活动能力下降的人，以及照护院住户。

**行动。** 联系最脆弱的人（或安排家人、照护者或社区服务每天探视）。就保持住所凉爽（拉上朝阳窗户的窗帘，室外较凉时开窗）、在正午避开高温、充足饮水以及识别热衰竭和中暑提供建议。与照护院合作监测室温、提供凉爽区域、鼓励饮水并留意病情恶化。

**药物。** 利尿剂和SGLT2抑制剂增加液体丢失；ACE抑制剂和血管紧张素受体阻滞剂在脱水时可能加重肾功能损害；抗胆碱能药和某些抗精神病药损害出汗和体温调节；脱水时锂浓度可能升高。审查高风险患者，告诉他们身体不适时该怎么办（相关时提供“病假日”指导），未经个体评估不要常规停药。

**事后。** 回顾所发生的情况，包括死亡和住院，并更新诊所的高温应对计划。长期措施包括建筑改造、绿地和照护院标准。
:::
:::
