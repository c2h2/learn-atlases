环境与健康职业是公共卫生最古老也最年轻的学科：工具最古老（排污、净水与工作场所立法构成了二十世纪寿命增益的大部分），问题最年轻（气候危机、未经同意就在人身上做的化学暴露实验、以及不稳定工作与平台劳动造成的职业困境）。**本章覆盖水与卫生及其尚未完成的二十亿人事务、环境空气与室内家庭空气污染、从铅到内分泌干扰物的化学暴露、建成环境、以及作为综合学科的气候与职业健康——在这里，医学的预防半壁与治愈半壁必须会合。**

## 水与空气

::: definition 水、卫生、清洁与颗粒物 {#def-water-air}
**水传播的世界仍在最贫困国家驱动着大量可预防疾病：粪—口途径感染，以及“卫生设施—管道水—氯化”这一序列的预防。霍乱、伤寒与儿童腹泻的算术使供水成为史上最大的医学技术，而它的维护在任何地方都没有完成：水源保护、处理、配水管网的完整、余氯、生物膜控制、以及铅管——弗林特危机正是用它给富裕国家上了一课：它们并没有学完。诊所与学校的水安全是感染控制的地基，并连着沙眼、血吸虫与蠕虫；以及灾后水安全手册——气候冲击不断把它重印。空气贡献两种政治取向相反的暴露。环境细颗粒物携带从1952年伦敦烟雾继承来的流行病学、以及现代的队列与时间序列研究：浓度—反应近似对数线性且未显示安全阈值，效应混合了心肺死亡、卒中、低出生体重与儿童呼吸道感染；而政策在曲线上设置的是“可行性目标”而非安全线——世界卫生组织的年均指导值与多数法规限值之间的差距本身就是论证。室内烟雾的政治相反：它是贫困的伤害——固体燃料炊事在数十亿人群中造成妇女与儿童的肺炎、慢阻肺与肺癌，解法是炉具与燃料可及性与烟囱排烟、以及被低估的“燃料梯”现象（家庭在不同燃料之间跳跃而非彻底转向清洁）——[[respiratory/respiratory-infections]]、[[public-health/global-health]]、[[paediatrics/acute-childhood-illness]]。**
:::

## 化学品与建筑

::: definition 污染物、毒物与剂量—时间—反应逻辑 {#def-chemicals}
**环境毒理学提供了本领域的语法。“剂量决定毒性”的原则带着现代的复杂化：内分泌干扰物的非单调用线、混合物问题、以及发育的关键窗口——而参考剂量却由成人推导。暴露重建是一门自己的科学：生物监测、暴露与效应生物标志、暴露组计划、以及从档案做事后重建（它把化学灾难变成队列研究）。潜伏期使这个领域在法律上令人畏惧：石棉与恶性间皮瘤（使禁令无效的潜伏期）、铅与儿童智力（被反复修订的“没有安全水平”）、苯与白血病、沙利度胺与己烯雌酚与发育窗口、水俣的汞与痛痛病的镉作为被法庭承认的环境疾病、以及弗林特作为信任流行学的现代案例。暴露清单仍有临床价值：职业与环境的病史应当被常规询问（作业与材料、工时与防护、家中暴露、以及同事是否有同样症状）——多数诊断的第一条线索来自工作史而不是检查。清单的常客包括：石棉（胸膜斑与潜伏期二十至四十年的间皮瘤）、结晶硅（肺癌与尘肺、以及伴随的结核与自身免疫）、有机溶剂（皮肤与中枢与少见的胆道）、农药（急性胆碱能危象与慢性争论）、铅与汞与镉、以及粉尘与哮喘和慢性阻塞性肺病——[[pathology/environmental-pathology]]、[[respiratory/interstitial-vascular-disease]]、[[musculoskeletal/connective-tissue-vasculitis]]。**
:::

## 气候与工作

::: definition 气候变化与职业健康作为综合领域 {#def-climate-work}
**气候通过四条通路把人群与患者连成闭环。直接：热及其与心肺肾疾病的交互、以及干扰体温调节的药物（β阻滞剂、利尿剂、抗胆碱药与抗精神病药的清单）、由住房质量与“降温权”中介的城市热岛、以及热—健康行动计划（其评估显示：发出预警容易，按预警行动难）。感染：媒介与人畜共患范围的上移出现在法定报告数据中——本地的登革热与“无旅行史”的病例——而归因科学对自己的限度诚实：把一次暴发“归因于”某次热浪是道德表述而非科学表述。营养：作物产量与微量营养素下降的预测喂给营养不良的危机。流离与精神健康：灾后的精神流行学（灾难—痛苦—流离的序列及其创伤后应激、抑郁与自杀的长尾）——[[nervous-system/dementia-neurodegeneration]]、[[public-health/global-health]]。职业健康是医学中预防与治愈必须会合的门诊：一个由暴露与工时塑造的患病人群，以及少数拥有立法权力的医师。它的三项永恒技能是：暴露史（比任何检查更早给出诊断）、对“群体聚集”的警觉（两名同事同样的病就是流行病学）、以及把工作放回病史（夜班与轮班的昼夜节律负担、以及长时间工作与卒中和缺血性心脏病死亡的关联）——[[pharmacology/adverse-reactions]]、[[cardiovascular/circulation-blood-pressure]]。当前的难题是工作的形态本身：非标准就业与平台工作使职业健康服务无从触达（没有雇主、没有暴露记录、没有工伤与疾病的定义通道），而全球供应链把危害转移到监管最弱处——[[public-health/determinants-inequalities]]。**
:::

::: example 不是流感的那台锅炉 {#ex-co}
一栋公寓楼里五名成员在一周内先后出现头痛、恶心与“乏力”，被当作流感；同一周内楼里三人呕吐、一名婴儿嗜睡；燃气热水器去年未检修。
::: solution
**把聚集当作暴露信号（[[#def-chemicals]]、[[#def-water-air]]、[[emergency-critical-care/poisoning]]）：识别——同一屋檐下的头痛与恶心加上“多名成员先后发病”是在排除一氧化碳之前的默认诊断：脉搏血氧无法区分碳氧血红蛋白（常规仪器给出假常值），所以确诊需要血气的共氧测定或血碳氧血红蛋白；吸烟者基线可升高，而婴儿与心脏病者更易损——[[clinical-skills/laboratory-tests]]。即刻处置——把所有人移到户外、高流量纯氧（非高压氧的适应证要按本地毒理咨询：意识丧失、神经体征、心肌受累、妊娠、以及碳氧血红蛋白的高值）与观察迟发的神经精神综合征——[[nervous-system/stroke]]。系统动作——同一小时通知燃气安全与住房部门紧急撤离与检修、并把楼里的其他住户一起评估（“谁还没来门诊”是这个病例最重要的问题）、以及一氧化碳报警器的强制安装与免费发放——[[public-health/health-systems-economics]]。后续——记录为环境—职业暴露事件并按法定报告；主动随访迟发的认知与情绪症状（数周内出现的痴呆样表现与帕金森样表现）；以及把“这不是流感”作为一次学习复盘：三人以上同宅症状的会诊触发规则——[[emergency-critical-care/major-incidents]]、[[clinical-skills/patient-safety]]。**
:::
:::

::: example 气短的建筑工人 {#ex-asbestos}
一名68岁退役建筑工主诉渐进气短与胸壁痛；胸片示胸膜斑块与肋膈角变钝；他拆过隔热材料与波纹板，从未戴过防尘面具；他不抽烟但担心“石棉疣”。
::: solution
**潜伏期的门诊（[[#def-chemicals]]、[[pathology/environmental-pathology]]、[[respiratory/interstitial-vascular-disease]]）：把影像读成暴露史——胸膜斑块是暴露的标记而非疾病（它们本身很少引起症状），所以症状必须有别的原因：石棉肺（下叶为主的间质纤维化，通常在极高暴露后二十年）、胸膜增厚或积液、以及间皮瘤（胸壁痛与积液伴体重下降是警示）；肺癌的风险与吸烟相乘而非相加，所以要如实谈戒烟——[[respiratory/lung-cancer-pleura]]。评估的次序：高分辨率CT与肺功能（包括弥散量）、区分胸膜与实质、以及在怀疑恶性时请胸科与胸腔镜活检（细胞学对间皮瘤敏感性低，需要组织与免疫组化；以及良恶性鉴别本身的困难）——[[pathology/cancer-diagnosis]]。归属与赔偿：这是职业病报告与赔偿的病例（职业暴露史的具体化：材料、年限、每小时暴露强度、以及同一工友的症状），并要解释“暴露—疾病”与“暴露—影像”的区别；同时筛查其他石棉相关暴露的并存（结晶硅与焊接烟尘）——[[public-health/environmental-occupational]]。监测与告知：向患者说明未来风险的时间表与需要立即返诊的红旗（新发胸痛、积液增长、体重下降）；把“没有安全阈值”讲清以支持家里的防尘与装修规范（旧材料的翻修与拆除是当代的暴露来源）——[[public-health/prevention-promotion]]、[[clinical-skills/communication]]。**
:::

## 通向何处

环境危害的病理在[[pathology/environmental-pathology]]；职业性肺病在[[respiratory/interstitial-vascular-disease]]与[[respiratory/asthma-copd]]；热的肾脏后果在[[renal/acute-kidney-injury]]与[[renal/water-sodium]]；不平等与环境正义在[[public-health/determinants-inequalities]]；气候的全球健康维度在[[public-health/global-health]]；而成本效果在[[public-health/health-systems-economics]]。

::: history
**环境与健康职业的历史是“把病归给环境”的漫长胜利与反复倒退。约翰·斯诺1854年宽街水泵的地图把一次流行变成一次暴露调查，并留下了本领域的方法论内核（病例的时间与地点、对照、以及可被干预的原因）；1842年的查德威克报告与随后的排污革命塑造了城市的寿命；19世纪的职业立法——从纺织厂儿童到煤矿通风——是在反对声中赢得的。二十世纪中叶属于化学与癌症：1930年代的苯与再生障碍、石棉肺的劳动病学文献与随后的赔偿诉讼、以及1962年《寂静的春天》把农药从田间问题变成公共问题；1970年代是美国环保署与国家职业安全健康机构的成立、以及“无安全阈值”之争的第一回合。风险的时代在1980年代到来：毒理的剂量外推、暴露评估与地表水标准、超级基金场地与“环境正义”运动（拉夫运河与有毒废物沿种族与收入的分布）；以及水的现代教训：1993年密尔沃基隐孢子虫与2014年弗林特铅——后者证明“合规”的报告不能替代监测、以及信任一旦被测量延迟摧毁就极难重建。气候流行病学则在本世纪成为主线：2003年欧洲热浪的两万余超额死亡、其后的热—健康行动计划与其评估、以及2010年代“归因”与“适应”的分野——[[epidemiology-ebm/observational-studies]]、[[public-health/prevention-promotion]]、[[public-health/global-health]]。**
:::

::: summary
- 水与卫生是史上效果最大的医学技术，而它的维护永未完成：管网、余氯、铅、以及灾后供水都属临床相关。
- 环境空气的浓度—反应无已证明的安全阈值；室内炊事烟雾则是贫困的伤害，解法是燃料与炉具的可及性。
- 职业与环境病史是最便宜的诊断工具；两名同事的同一症状就是一次小型流行病学。
- 潜伏期与关键窗口使本领域在法律上困难：石棉、铅与发育毒物的教训是“没有安全水平”与“事后无法补救”。
- 气候通过热、感染、营养与流离四条通路行医；预警容易、按预警行动难。
- 工作的形态（轮班、平台、非标准就业）正在成为新的暴露问题，而现有职业健康服务触达不到它。
:::

## 练习

::: exercise 取暴露史 {level=1}
一名42岁仓库包装工在两冬内反复咳嗽与晨起头痛；她的三个同事有相似症状；她有哮喘样发作并在下班后好转。写出你会问的八个问题与最可能的方向。
::: solution
**八个问题（[[#def-chemicals]]、[[#def-climate-work]]、[[respiratory/asthma-copd]]）：一，症状与工作的时间关系（周末与假期是否好转——这是“假日征”）；二，同一岗位其他人的症状（聚集是证据）；三，具体材料与工艺（新到的货物、清洁剂与消毒剂、胶与漆、叉车电池间、喷雾与粉尘）；四，通风与空调的维护（换风率、滤网、以及是否有人闻过异常）；五，防护装备与实际使用（型号、适配、以及是否有人被培训过）；六，暴露控制与职业服务是否知情；七，家与嗜好（吸烟与电子烟、养鸟与霉斑、地下室氡、以及装修）；八，工伤与工时与轮班（疲劳与夜班本身的风险）。方向——最值得先做的是排除致病因子并做客观证据：峰流速的工地内与工地外系列（工作相关哮喘的客观确认）、以及同时把“多名同事同症状”上报职业卫生与检查机构（这是公共卫生职责，不是可选步骤）；转诊职业医学与移除暴露是关键（“继续戴着面具做”不是控制层级里的办法）——[[public-health/determinants-inequalities]]、[[clinical-skills/patient-safety]]。**
:::

::: exercise 在热浪中给出建议 {level=2}
一次为期五天的热浪即将到达（夜间最低28度）。你负责一家有九十张床的老年科病房与一个社区的两百名居家 体弱患者名单。给出你的行动方案。
::: solution
**热浪方案（[[#def-climate-work]]、[[geriatrics-palliative/ageing-frailty]]、[[renal/water-sodium]]）：院内——识别高风险（认知障碍、行动受限、感染发热、心衰与肾病、以及体温调节被药物阻断者：抗胆碱药、利尿剂、β阻滞剂与抗精神病药，以及部分降压药在容量不足时的低血压）；调整药物（在热应激与食欲下降时预先商定的利尿剂与血管紧张素转换酶抑制药与二甲双胍的调整规则——这是“病假日规则”的季节版本）；监测（每班体温与意识、尿量与肌酐轨迹、以及电解质）；物理降温的容量（风扇与冷空气、冷敷、以及病房能否在夜间降温——建筑的自然遮阳与夜间的换气比白天的空调更关键）——[[renal/acute-kidney-injury]]、[[endocrine/diabetes]]。社区——名单不是干预：主动电话与上门、把“白天在何处凉快”与“如何安全补水与盐”写成易懂卡片、协调邻里与药房与社区组织；以及把热浪中的高危人群与独居者的检查与独居者的检查合并成一次（一次上门解决多个风险）——[[public-health/determinants-inequalities]]。治理与问责——明确谁在何时按温度阈值行动（阈值应基于本地死亡率数据、而非全国通用数字）；以及事件后的复盘：按“超额就诊与超额死亡的分层”来评估而非只数热射病住院（多数热相关死亡发生在家里且无中暑诊断，这是被系统性低估的账目）——[[emergency-critical-care/shock-fluids]]、[[public-health/communicable-disease-control]]。**
:::

一座城市因水源切换导致铅超标被曝光；你被请去设计健康与信任的响应。给出健康、暴露、以及信任三层的行动，并说明你会拒绝什么做法。
::: solution
**三层响应（[[#def-chemicals]]、[[#def-water-air]]、[[public-health/prevention-promotion]]）：健康层——儿童血铅的普查与随访（按年龄与暴露强度分层、以及重复检测以区分污染与真实暴露）、发育与学习的早期干预、以及孕产妇与婴幼儿的专项（配方奶用水的安全指导）；成人则关注血压与肾与心血管的长期风险；同时避免“筛出无症状的轻度升高却无法提供干预”的伤害——[[paediatrics/growth-development]]、[[renal/chronic-kidney-disease]]。暴露层——立即的替代供水与过滤（发放带认证滤芯的龙头装置并教育其使用与维护、以及“煮沸不能去铅、反而浓缩”这一必须反复讲清的一点）、临时切换水源与缓蚀剂的加注、以及管道与入户铅管的更换计划（含最易被忽略的私有段与_schools_与诊所）、以及把血铅与水质数据以同一张地图公开。信任层——与社区共同设计（不是事后解释）、由社区人员采样、以及公开“我们曾被告知指标合规而指标本身就是问题的一部分”；把监测的独立性与第三方复核写进委托——[[clinical-skills/communication]]、[[medical-ethics-law/professionalism-regulation]]。你会拒绝的做法：只用“风险很低”的沟通代替换管；用一次筛查取代长期随访；把瓶装水当作长期方案（既不可持续又暗示问题在居民）；以及让学校与儿科医生成为唯一的风险沟通渠道——[[public-health/global-health]]。**

::: exercise 给节能改造算成本 {level=2}
政府拟对十万户老住宅做保温与通风改造。请从健康角度给出论证结构、需要防范的两类风险、以及如何评估。
::: solution
**改造的健康论证（[[#def-water-air]]、[[#def-chemicals]]、[[public-health/health-systems-economics]]）：论证的四条收益流：冷住宅与冬季超额死亡与心血管与呼吸道疾病（以及哮喘儿童的住院）、潮湿与霉与儿童喘息、以及燃料贫困（改善后的能源账单对心理健康、债务与缺课的影响）、加上碳与空气质量的协同收益；把成本按“每质量调整生命年”与“每避免的冬季住院”分别给出，并同时给卫生部门与能源部门的账本——因为受益方与付费方不同是这类政策的常态。必须防范的两类风险：一，密闭化带来的室内污染（燃气燃烧与一氧化碳与二氧化氮与挥发性有机物与氡的累积，如果通风设计不到位——“先保证安全再谈能效”要成为强制的施工顺序与验收项，含机械通风与报警装置）——[[emergency-critical-care/poisoning]]；二，分配的错位（补贴流向有能力申请的业主，租户与最贫困家庭被留下；以及“改善后涨租”把受益者迁走）——所以要把改造与租户保护、以及由社区施工队实施的定向预算绑定。评估——按前后对照加匹配对照区，结局用能源账单与自报健康与处方数据与冬季入院、并把施工期间的干扰（搬迁、噪声、粉尘）作为副作用记录；同时准备一个“若健康收益小于预期，改造是否仍值得”的答复（碳与燃料账单与舒适仍然成立）——[[public-health/environmental-occupational]]、[[clinical-skills/records-handover]]。**

::: example 农场的夏天 {#ex-pesticide}
一个农场家庭在喷洒后有两名儿童恶心、流涎、瞳孔缩小；当地医生考虑“病毒性胃肠炎”；同周有几名雇工因“抽搐样发作”就诊；仓库里堆放着未标注容器。
::: solution
**胆碱能危象的现场（[[#def-chemicals]]、[[#def-climate-work]]、[[emergency-critical-care/poisoning]]）：识别——流涎、流泪、排尿与腹泻与瞳孔缩小与支气管分泌，加上接触史就是有机磷或氨基甲酸酯中毒；关键是“多名接触者同症状”这一聚集信号（把它当作职业—环境暴露而非各自独立就诊来处理），以及脉搏血氧与胸片可能低估支气管分泌的严重性；把“病毒”当作默认标签是本领域最常见的漏诊。处置——脱离与去污（衣物与皮肤；注意救治者自己的暴露——这是二次中毒的经典场景）、阿托品按分泌而非心率滴定、氯解磷定（对某些有机磷在“老化”前）、以及气道与通气；避免滥用琥珀胆碱与某些药物；测血浆与红细胞胆碱酯酶作为诊断与暴露的证据、并留基线以便日后——[[emergency-critical-care/airway-ventilation]]、[[clinical-skills/laboratory-tests]]。公共卫生行动——立即通知农业与劳动与毒物中心；追查容器来源与登记状态（非法或未标注产品）与作业规范（进入间隔期、防护、喷洒时间与风向、以及学校与住宅的距离）；以及农场的儿童暴露这个结构性问题（居住与劳动的重叠、以及季节性劳工的语言与培训与工作许可）——[[public-health/global-health]]、[[public-health/determinants-inequalities]]。随访与政策层——迟发的神经肌肉综合征与认知症状的随访、以及把“农场化学品”作为急性病房评估的常规一项（在农业区的分诊表里加上“最近有没有喷过药”）——[[nervous-system/neuromuscular]]。**

::: example 头痛的办公室 {#ex-sbs}
一个学期的冬天里，某学校幼儿部报告头痛与湿疹的聚集以及两例哮喘加重；教职工提到“变天时楼里有甜味”；那间活动教室是在2019年把霉斑刷掉之后装进来的。
::: solution
**“病楼”是一个诊断（[[#def-chemicals]]、[[#def-water-air]]、[[respiratory/asthma-copd]]）：方法——按房间与时间画症状地图（周末好转就是学校版的“假日征”）、通风审计（换风率与以二氧化碳为代理的实测数据，多数学校建筑不达标）、潮湿与渗水勘查（被刷掉的霉斑的历史、屋顶与天沟与地下水的缺陷在每个雨季复发）、以及顺着气味找来源（活动教室里的旧溶剂与密封胶、“挥发给与到场前先通风”的竣工调试失败、以及挥发性有机物与甲醛的问题）。临床层——呼吸与皮肤的表现（哮喘加重与湿疹与刺激症状）通常是非特异的，所以诊断依赖于“离开即好转”的时间结构与客观的室内测量，而不是过敏原筛查；把每名患儿按严重度处理（吸入器与哮喘行动计划）并同时处理环境（两者都做，不做后者就会反复）——[[respiratory/asthma-copd]]。沟通与治理——对家长与教职员工的透明沟通（不否认、不承诺无法保证的因果结论、给出时间表与实测数据）；一个跨部门的工作组（设施、校医、教育主管部门、以及家长代表）；以及“先修水源与通风、再谈心理”的顺序（把主诉归为焦虑是常见且代价高昂的早期错误）。评估——改善前后重复症状地图与峰流速与缺勤率；并在未来的采购与竣工调试中加入“通风验证与甲醛与挥发性有机物限值”，使问题不必再靠一次聚集才被看见——[[public-health/prevention-promotion]]、[[clinical-skills/patient-safety]]。**

::: exercise 写氡的运动 {level=1}
为一个高氡地区的住宅氡干预运动起草要点：证据、检测、行动阈值、公平与副作用。
::: solution
**氡运动（[[#def-chemicals]]、[[respiratory/lung-cancer-pleura]]、[[public-health/prevention-promotion]]）：证据——氡是肺癌的第二位病因与从不吸烟者的首位环境病因，剂量—反应来自矿工队列与住宅研究的合并，且与吸烟呈强相乘（所以戒烟与降氡必须一起讲）；效应比例适中但暴露普遍，因此人群归因分数不可忽视。检测——把“在最长使用的房间、按规程做三个月以上的被动测量”写进说明（短时测量受通风与季节影响大）、以及在出售房屋与学校与地下工作场所的强制检测；把免费或补贴的检测盒按高风险地质区发放。行动阈值——用国家行动水平并说明“低于阈值不等于零风险”；措施按成本排序（密封与地面裂缝与管道穿板的封堵、排水与地基通风、以及带热回收的机械送风与负压减少）；并且要“复测以确认有效”——降氡工程最常见的失败是完工后无人验证。公平——最重的暴露常在老房与地下室与低层住宅、以及无法自行投资的家庭，所以补贴与施工监管要一起给；沟通要避免把矛头指向住户（这是地质与建筑规范的责任）——[[public-health/determinants-inequalities]]。副作用与意外后果——“氡恐慌”与房产价值争议、以及对肺癌筛查的错误期待（降氡不能取代吸烟者的低剂量CT资格）；并把建筑规范的前瞻条款（新建筑的抗氡设计）与存量改造一起写进行动计划——[[clinical-skills/medical-imaging]]。**

::: exercise 论证热标准一案 {level=2}
职业安全机构拟规定“湿球黑球温度超过某值即必须停止露天作业并提供休息与饮水”；建筑业说无法执行。请以科学与可执行性两方面论证，并设计豁免与合规路径。
::: solution
**热标准一案（[[#def-climate-work]]、[[public-health/health-systems-economics]]、[[renal/acute-kidney-injury]]）：科学的一面——风险的度量是湿球黑球温度（它把湿度、辐射与气流一起纳入），而“阈值”应随工作强度、服装、以及个体因素（年龄、既往热病、心肺肾疾病、肥胖、药物如利尿剂与抗胆碱药与部分精神科用药、以及脱水与酒精）调整；证据支持分级停止工作与强制休息与遮阴与饮水与再水化、以及“同伴观察与冷浸准备”用于重度劳动者；热射病的死亡与急性肾损伤与横纹肌溶解在“再干一小时”的决定里发生——[[emergency-critical-care/shock-fluids]]、[[nervous-system/stroke]]。可执行性的一面——不要只写一条不可测的规则：用可观察的代理（一天中的时段与遮阳与休息周期的时长与水与“热应激班长”的存在）、把阈值表贴在现场、并用热指数分级配合工作—休息循环；用免费热线与举报渠道以及以事故报告反查合规。豁免与合规——对紧急与救援作业设“受控豁免”（须有医学监督与降温能力与轮换记录）；对小雇主给技术协助与设备补贴（遮阳与饮水与制冷）；以重复违规与造成伤害为处罚重点，而不是以初次纸面违规。评估——热相关急诊与工伤与肾损伤的月度指标与“停工天数”的经济指标一起报；并把标准写成随气候变化的活文件（阈值与季节适用期都要定期更新）——[[public-health/determinants-inequalities]]、[[clinical-skills/records-handover]]。**

::: exercise 评判空气质量的法律案件 {level=2}
一个民间组织以“违反空气质量法规”起诉政府；被告的抗辩是“超标主要因为越境的农业氨排放与沙尘”。请以流行病学与法律两方面评估专家证词。
::: solution
**评估专家证词（[[#def-water-air]]、[[epidemiology-ebm/bias-confounding]]、[[public-health/environmental-occupational]]）：科学的一侧有三个可辩护的主张。第一，法规的射程：法律通常管“本地可控源”（道路与工业与取暖），所以沙尘与越境氨可以缩小责任但很少能免除义务——因为法规要求的是达标而非“只承担自己那一份”。第二，归因的层次：人群层面的暴露—反应（对颗粒物与二氧化氮的因果结论已经确立）不同于个案归因，法律接受“增加的风险即是相关的风险”这一因果标准；混淆因素（吸烟、职业、收入）通过大样本个体级队列与暴露梯度与机制证据得到处理，而“微小效应不值得管”在普遍暴露下是统计谬误（小的相对风险乘以巨大的人群即大的归因分数）。第三，可用的证据组合：源解析（化学组分与同位素与风向模型）、自然实验与削减情景（道路收费、低排放区、封路期间的死亡率与就诊变化）、以及时间序列与队列；把这些排列成一个“因果阶梯”并说明各自能支持什么结论。法律一侧要提醒委托人：胜诉的关键常是“计划的充分性”（有没有可信、有时限、有资金来源的达标路线图）而非流行病学本身——所以要准备技术方案的评估而非只争论关联；同时注意禁令的可执行性、以及判决如何分配责任给其他部门（交通与农业），否则胜诉也可能只得到一份新的承诺书——[[public-health/health-systems-economics]]、[[public-health/prevention-promotion]]。**

::: exercise 建一间气候适应门诊 {level=3}
你要为一家地处洪水与热浪频发区的综合医院建一间“气候与健康”门诊。设计它服务的四类患者、 人员配置与流程、监测与问责、以及失败风险。
::: solution
**气候适应门诊（[[#def-climate-work]]、[[geriatrics-palliative/ageing-frailty]]、[[public-health/determinants-inequalities]]）：服务的四类人群：一，热与药物（心衰、肾病、精神科用药与体温调节受损者的季节性用药重整与“热浪护照”）；二，空气与花粉相关哮喘与慢阻肺的加重（按空气质量与花粉指数的预防性用药调整与吸入技术教学）；三，洪水之后（伤口感染与胃肠炎与霉菌暴露的呼吸道与皮肤、以及转移与中断的透析与胰岛素与精神科治疗的“补漏”门诊）——[[infectious-diseases/healthcare-infections]]、[[renal/chronic-kidney-disease]]；四，气候焦虑与灾后心理（生态哀伤、农民与救援人员的痛苦、以及把心理健康的长尾从灾难响应中拆出来）。人员与流程：一名全职的环境与职业医学顾问加护理与药师与社区外展员（而非“额外任务”）；一张“把环境暴露写进就诊”的触发规则（分诊表里加洪涝接触、化学品接触、热暴露与工时）；一处低门槛的吸入与雾化与补液单元、以及热射病的绿色路径（冷浸与快速通道）；以及与急救与社区与气象服务的热线连接；医院自身的韧性要一并负责（发电与供水与热浪中的温度、以及洪水屏障，因为失能的医院本身就是伤亡来源）——[[emergency-critical-care/critical-care]]、[[emergency-critical-care/major-incidents]]。监测与问责：按月报热相关急诊与住院与院内的热浪伤亡；报洪水后七与三十天的感染与透析与精神科的缺口；报门诊“外展名单”的触达率（居家患者被主动电话的完成比例）；公开一份年度适应报告并把院长的薪酬与其挂钩。失败的风险：被建成只谈碳足迹、不做患者照护的机构展示（“绿色营销”）、或只在灾难周存在、或把适应变成个人的责任清单而不去游说建筑与供水与社会保障——所以章程里要写明“政策与外展”作为门诊职责的一部分，并与公共卫生部门共同签署；同时预设资金：适应工作的价值在灾难之间的岁月里不可见，除非有人把避免的伤亡写成数字——[[public-health/health-systems-economics]]、[[public-health/prevention-promotion]]。**
