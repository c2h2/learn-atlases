慢性非传染性疾病造成高收入国家约四分之三的死亡，在世界范围内也占越来越大的多数；围绕它建立起来的公共卫生学科，必须在医学中最慢的时间尺度与最深的原因层次上工作。**本章覆盖四大疾病集群与它们共享的行为（烟草、酒精、饮食、身体活动不足，以及作为中介通路的肥胖、高血压、血脂异常与糖耐量受损）、因果框架（社会决定因素经由商业与环境暴露在整个生命过程中起作用、商业决定因素作为一门被研究的领域、以及“将健康融入所有政策”的机制）、预防策略（“最佳选择”、危险因素管理门诊、筛查的重叠、以及世界卫生组织的目标与其追踪），以及照护交付的半壁（慢性病管理模型的架构、作为人群问题的多病共存与多重用药、以及慢性病叙事常常遗忘的康复与姑息整合）。**

## 疾病负担

::: definition 四大集群、五种行为与代谢中介 {#def-burden}
**慢性非传染性疾病的框架把心血管病、癌症、慢性呼吸道疾病与糖尿病列为四大疾病；精神疾病以及肌肉骨骼与神经科疾病越来越被计入同一本账，因为它们共享危险结构与照护模型难题。行为决定因素数量少而体量大：烟草（仍是最大的单一可预防死因，带着成瘾经济学、促成工作场所禁烟的第二手烟证据、以及已被文件记录的产业剧本——后者如今是商业决定因素的案例研究）；酒精（剂量—反应与癌症及肝病、营销与可获得性与价格的弹性、以及与烟草汇流的产业策略催生了同样的批评）；饮食与身体活动不足（盐与血压的算术、产业配方可调计划、超加工食品的流行病学——其“配方对过量摄入”之争仍未定论、含糖饮料税及其评估文献、以及“能量平衡生理学归临床、致肥胖环境归规划”的肥胖环境）。代谢中介是血压、血脂、血糖与体重这四条斜线：它们在诊室里被测量，因此把人群预防与个体治疗连成一个连续体——也是药物预防最顺手的把手。疾病的算术值得记住：多数过早死亡发生在六十岁以前、且中低收入国家承担最重的份额；同一批危险因素也造成盲、肾病、截肢、失能与痴呆，所以“死因”这一指标低估了负担；而多病共存是常态而非例外——糖尿病合并高血压与抑郁，慢阻肺合并骨质疏松与焦虑——[[cardiovascular/hypertension]]、[[endocrine/diabetes]]、[[respiratory/asthma-copd]]、[[pathology/cancer-biology]]。**
:::

## 因中之因

::: definition 商业决定因素、环境与将健康融入所有政策 {#def-determinants}
**行为风险不会自我分配。近端原因是商业的：烟草业“死亡与否认”的剧本（内部文件的诉讼、以及世界卫生组织《烟草控制框架公约》的条约回应，此后的非法贸易与尼古丁产品之争）、酒精业向全球南方的转移及其赞助与游说模式（最受抵制恰恰是“最佳选择”里的价格与可获得性措施）、以及食品与超加工饮料业的政治经济学（配方调整对监管之争、智利与英国评估过的前端标签战、以及面向儿童营销的证据与软弱的自愿守则）。结构性原因是被建造出来的：可步行的城市对被汽车依赖的城市、以门店密度与价格比测量的食物环境、如今被承认为独立主要危险因素的空气污染（颗粒物与心肺死亡的算术把本章与环境章节连起来）、酒精与尼古丁的许可发放、以及作为“场所”的工作路与学校——[[public-health/environmental-occupational]]、[[public-health/determinants-inequalities]]。机制的框架是三重的：整个生命过程中的程序性原因（母体营养、胎儿编程、童年贫困与不良经历、以及教育对晚年健康的长链条）、物质与风险因素的暴露梯度、以及行为的意义与社会分层（为何“选择”一词在讲社会梯度时最不诚实）。治理的答案是“将健康融入所有政策”：健康影响评估、财政与农业与交通与规划的部际目标、以及健康城市与控烟公约把责任写进法律；其中最有力的教训是，把烟草当作对手、把食品业当作伙伴是一种政治选择，而不是证据的要求——[[public-health/prevention-promotion]]。**
:::

## 应对

::: definition 预防架构与慢性病照护交付 {#def-response}
**在上游，是经济学把论证做完的：《疾病控制优先项目》与世界卫生组织“最佳选择”的分析，把烟草与酒精税、减盐、以及身体活动大众运动列为全医学中每个伤残调整生命年最便宜的干预；而具有人群覆盖力的临床干预（治疗阈值处的血压控制、心肌梗死后的他汀与阿司匹林、以及“单一大复方与固定剂量组合”的依从性逻辑）实现了同时移动治疗阈值与覆盖率的“大赢”策略——[[public-health/health-systems-economics]]。服务交付是一门设计学科：慢性病管理模型（瓦格纳框架对互动的重新设计——自我管理支持、临床信息系统、交付系统设计、以及技能错配的修复）、开业护士与药师与社区卫生工作者的任务转移证据（在低收入地区由社区卫生工作者执行的高血压滴定方案达到了试验级的血压控制）、糖尿病与慢性肾病的登记与召回架构（其召回系统是筛查的近亲）、以及把分级诊疗、转诊双向性与随访清单写进系统的转诊设计——[[renal/chronic-kidney-disease]]、[[public-health/screening]]。多病共存与多重用药是人群问题：合并症加权的治疗负担可以压垮一位老人的一天（六种药、三种吸入器、糖尿病饮食与心衰限液的相互冲突的建议），所以指南需要被整合、治疗负担需要被测量、而“减药”是一门有自己证据与停止规则的正经临床技能——[[geriatrics-palliative/polypharmacy]]、[[pharmacology/dosing-principles]]。最后是被遗忘的半壁：康复与姑息。功能、参与与生活品质才是慢性非传染性疾病结局的实际货币；早期整合姑息照护在晚期心肺疾病与癌症中能减少症状负担、住院与侵略性终末照护；而康复应当与药物治疗同期开始、不是失败之后才请——[[geriatrics-palliative/palliative-care]]、[[musculoskeletal/bones-joints]]。**
:::

::: example 关于盐的谈话 {#ex-salt}
一名52岁新发现血压152/94的男性问他该“终身吃药”还是“只要少吃盐”；他祖母六十岁中风；他开重型货车。
::: solution
**两个答案都为真（[[#def-burden]]、[[#def-response]]、[[cardiovascular/hypertension]]）：他应得的算术——人群盐与血压的剂量—反应（每克盐对应几毫米汞柱的逻辑）、他自己的绝对心血管风险（把家族史与职业算进去的风险计算器）、以及在152/94这个水平下降压的“需治人数”要诚实说出：十年里药物能防掉一个确定比例的事件，而减盐会把他的血压挪动几点——这是真的，但在这个水平上通常单靠它不够。重型货车的层次——关于“治疗后血压与驾驶”的驾驶与职业规则（“先查许可与雇主的要求”这类建议属于职业生涯医学），而轮班与久坐驾驶构成他个人的风险环境。方案——用家庭或动态血压确认；把生活方式谈话重构为“你想改什么、我能帮你改哪一样”（他能掌握的盐、酒精、活动与体重四个把手），并在四到六周内复评；如果仍高于阈值，就把药物讲成一件便宜、安全、每天一次的事，而不是失败的承认；固定剂量组合与一两种药的低起点（以及在肥胖与夜间血压不降时考虑阻塞性睡眠呼吸暂停的筛查）、以及靶器官与血脂的评估——[[cardiovascular/hypertension]]、[[respiratory/asthma-copd]]。人群的一翼：同样的谈话在医院里对一千个类似的人做一遍，也不如把面包与加工食品的盐含量降一档有效——这就是为什么个体咨询与政策行动是一对而不是备选——[[public-health/prevention-promotion]]。**
:::

::: example 卖电子烟的工作场所 {#ex-workplace}
一家有四千名司机的物流公司提供包含电子烟在内的“戒烟福利”，并禁止在园区内吸烟；三分之二的戒烟司机改用了电子烟而不是彻底停止；工会向你的职业健康服务问：这是帮助还是陷阱。
::: solution
**工作场所的尼古丁政治（[[#def-determinants]]、[[#def-burden]]、[[respiratory/asthma-copd]]）：证据分层——电子烟对吸烟的危害比较（皇家医师学院与科克伦附近的位置：比继续吸烟明显少害、但无害谈不上，并说明双重使用与长期未知的特性）、作为戒烟工具的效力试验（英国戒烟服务数据中把尼古丁产品当工具的证据）、以及这项福利绝不该招募的“从不吸也从不电子烟者”。职业的框架——被认真评估的“无烟工作场所”政策（消除第二手烟是无争议的；“禁止是否把人赶到园区外和货车里吸”这一问题要用休息政策与支持来回答）；以及针对轮班者的设计（夜班时段可打的戒烟热线、尼古丁替代与电子烟的可及性、以及司机的健康服务）。公平的一条注：按职业与剥夺分层的吸烟率梯度，使这家公司的停车场成为全国最重要的慢性非传染性疾病现场之一。给工会的回答——支持转向作为减害、但坚持福利必须包含真正的戒烟路径与随访、且绝不以“合规”为名惩罚仍在吸烟的人；记录结果（吸者比例、双吸者比例、以及工伤与病假）并按年重评——[[medical-ethics-law/professionalism-regulation]]、[[public-health/communicable-disease-control]]。**

## 通向何处

这些疾病的临床半壁在[[cardiovascular/hypertension]]、[[cardiovascular/coronary-artery-disease]]、[[endocrine/diabetes]]、[[renal/chronic-kidney-disease]]、[[respiratory/asthma-copd]]与[[pathology/cancer-biology]]；危险因素的生理在[[physiology/homeostasis-body-fluids]]；筛查界面在[[public-health/screening]]；决定因素科学在[[public-health/determinants-inequalities]]；环境暴露在[[public-health/environmental-occupational]]；“最佳选择”的经济学在[[public-health/health-systems-economics]]。

::: history
**慢性非传染性疾病的时代始于一场意外。十九世纪的公共卫生是为感染建立的，而二十世纪初传染病死亡率的下降被读作文明的进步；到1930年代，保险与精算统计已经在显示“退行性”疾病的上升；战后的弗雷明汉心脏研究（始于1948年，“危险因素”一词在此被造出）发明了使血压、胆固醇与吸烟成为人群对象的队列逻辑。剂量—反应证据来得快且带有对抗性：英国医生研究、1950至1956年的多尔与希尔吸烟研究、以及1964年卫生总监报告关于因果的“异端”；饮食与冠心病的争论（基斯时代的脂肪对糖之争，今天仍在重演）；多项危险因素干预试验与其不大的效应量教会这个领域：单靠诊室改变不了分布；而罗斯定理（1981年“高危个体策略对人群策略”的表述）至今仍是本领域最爱的一句话、也是最难落实的一句。治疗证据平行到达：降压与降脂的试验浪潮、他汀、以及把急性事件死亡率大幅拉低的二级预防；随后是认识到“试验里的疗效”到“人群中的效果”之间隔着依从性、可及性与支付这道沟——于是有了单一大复方与固定剂量组合、社区药师的滴定、以及把治疗移到最近的试验。2011年与2018年的联合国慢性非传染性疾病高级别会议与可持续发展目标第3.4条把政治承诺与一套终止过早死亡的指标绑在一起；而“最佳选择”清单是一份刻意的反技术议程：最便宜的措施被排在了最炫的前面——[[epidemiology-ebm/observational-studies]]、[[clinical-skills/clinical-reasoning]]。**
:::

::: summary
- 四大疾病共享少数几种行为与一条代谢通路，所以预防的正确单位是危险因素的环境，而不是单个器官的专科。
- 风险不由“选择”分配：商业策略、建成环境、收入与教育决定了谁吸烟、谁吃高盐、谁有地方走路。
- 最便宜的干预是政策性的：税收、减盐、营销管制与禁烟立法；临床措施中最有覆盖力的是血压与继发事件的药物预防。
- 慢性病照护是一门设计学科：登记与召回、任务转移、自我管理支持、以及把技能匹配给任务。
- 多病共存需要整合的指南与被测量的治疗负担；减药是技能，不是放弃。
- 康复与姑息照护属于慢性病的核心，而不是终点的装饰：功能与参与才是结局的通货。
:::

## 练习

::: exercise 算一次人群的移动 {level=1}
某国成人平均收缩压为138毫米汞柱，把面包的盐含量降低使人群平均下降2毫米汞柱；已知卒中的风险每升高20毫米约翻倍。请估算影响并说明这种算法的弱点。
::: solution
**罗斯式的算术（[[#def-burden]]、[[#def-response]]）：把每次事件的相对风险近似为血压差的指数函数——下降2毫米相当于把整条分布左移，卒中与缺血性心脏病的年事件数下降的粗略量级为百分之几（每20毫米对应卒中最约翻倍，故2毫米约为7%的风险变化；乘以每年卒中数即得避免的事件数）；这个数字看着小，却是全国范围、无需个体依从、且对最上游人群获益最大的“零成本”干预。弱点：把人群均值当作可干预的常数（工业配方改变不均等地影响重度摄入者）、忽略了钠的其他通路（血压之外的心肌纤维化与胃疾病）与替代品效应、以及对个体水平的治疗阈值毫无意义——所以既要用它争取政策，也要避免用它替代对高危者的药物治疗——[[cardiovascular/hypertension]]、[[gastrointestinal/clinical-nutrition]]。**
:::

::: exercise 设计一座会走路的城市 {level=2}
市议会请你为新建住宅区（一万两千户）设计“促进体力活动与降低慢性病风险”的规划条款。给出干预、证据强度、治理与不平等风险。
::: solution
**规划条款（[[#def-determinants]]、[[#def-response]]）：干预按证据与可逆性排序：混合用途与步行半径内的日常目的地（超市、诊所、学校）、连接的人行路网与交通宁静化（机动车量的抑制比新建步道更能改变出行方式）、安全的自行车网络与停放、公园质量与可达（不是面积而是感知安全与维护）、以及禁止在 学校周边投放含糖饮料广告。证据：建成环境与活动的关联稳健而因果性有限，最强的随机证据来自“道路改造前后”的对照与出行方式干预；把“每减少一千次机动车行程”与血压、体重、抑郁症状的中介一起建模。治理：把健康影响评估写进规划许可的前置条件（“将健康融入所有政策”的实际形态）、以及把公交与住房部门的目标与本地健康指标绑定。不平等风险：绿化与步行化推高房价并置换原有低收入居民——健康改善却迁走受益者——因此每一条款都要与可负担住房、租金保护与本地就业承诺同写同批——[[public-health/determinants-inequalities]]、[[public-health/environmental-occupational]]。**

::: exercise 处理复合药的争论 {level=2}
一位公共卫生学者主张对50岁以上所有人开“复方药”（他汀加两种降压药的低剂量组合）而不做个体风险评估；临床界反对“过度治疗”。请提出你的立场与实施条件。
::: solution
**复合药的争论（[[#def-response]]、[[cardiovascular/hypertension]]、[[public-health/screening]]）：支持的理由是真实的：绝对风险高的中年人群里多数人在十年内会有事件；治疗便宜、安全、依从性是其最大障碍，而固定剂量组合把依从性提高约一半；并且风险评估在实践中很少被执行（算风险比开药更费时间）。反对的理由也是真实的：把药物从“治疗疾病”变成“人群暴露”，会带来副作用、误标“病人”身份、以及最脆弱者（30至70岁之间的女性）绝对获益低；以及它把资源从上游（减盐、烟草、城市设计）转向下游。可辩护的立场：以阈值覆盖而非全人群——按绝对风险或年龄加一个简单检查项（血压、血脂、糖尿病史）批量启动、允许在数周内用单片复方“试治”、并把停药规则与血压过低与跌倒风险写清；同时明确这不是筛查项目而是治疗覆盖率的补齐——需要有共同决策、明确的收益大小（每千人数年避免的事件）与不加重医疗化的承诺——[[geriatrics-palliative/polypharmacy]]、[[epidemiology-ebm/diagnostic-tests]]。**
:::

::: exercise 写2030年的问责报告 {level=3}
你被要求写出面向可持续发展目标第3.4条（过早死于慢性病减少三分之一）的国家进度报告。哪些指标、哪些陷阱、以及如果落后你如何写？
::: solution
**问责报告（[[#def-burden]]、[[#def-response]]、[[public-health/global-health]]）：指标集：30至70岁按病种与性别的死亡率、九项自愿目标（烟草与酒精税、有害饮酒、盐、身体活动、血压控制、糖尿病与高血压治疗、以及90-90-90式的治疗目标）、危险因素流行率、以及“灾难性卫生支出”这一交叉指标。三个陷阱：只用死亡率（它滞后且受急性照护改善影响，掩盖了发病率与失能上升）、用国家均值（梯度会掩盖停滞：最穷群体的曲线常常平了）、以及把“政策已宣布”当作“已实施”（税收是否跟上涨、销售点限制是否立法、是否有人执法）。落后的写法：诚实归因（烟草税多年未调、糖税被诉讼延迟、卫生预算被压）、把可问责性具体化（哪一项政策、由谁、在哪个部门、何时）、以及给出可执行的一年清单与预计的健康回报（“把盐平均降1克与把血压控制率提到50%，估计可避免多少例卒中”）。要写清卫生部门之外谁欠了什么——因为第3.4条在技术上是一条跨部门指标——[[public-health/health-systems-economics]]、[[public-health/determinants-inequalities]]。**

::: example 癌症延迟的审计 {#ex-backlog}
一次审计发现：过去两年“2周转诊”到确诊的中位数从14天升到26天，且最贫困地区的延迟最长；确诊时分期变晚；管理层指出癌症存活率仍“在全国平均水平”。
::: solution
**存活率作为掩盖物（[[#def-burden]]、[[#def-response]]、[[pathology/cancer-diagnosis]]）：统计的四重欺骗：先入时间偏倚（同样的死亡时间被“确诊更早”拉长了“存活”）、长度偏倚（筛查与快速通道抓到更多惰性肿瘤）、以及“全国平均”掩盖了按剥夺分层的差距与分母的分子化（只有能上门的人被诊断，所以看起来没变差）——因此必须看死亡率、看分期、看急诊通路诊断的比例。真正的成本被推迟在三个地方：治疗更晚与更侵袭（从局部切除变成根治术与化疗）、“等待期间的诊断延迟”对生存的绝对影响（每个癌种有其窗口）、以及患者报告的经济与心理后果——[[public-health/screening]]、[[geriatrics-palliative/symptom-control]]。审计要补的数字：按地区与性别的诊断路径分布、急诊期诊断的比例（这是对系统失败最诚实的指标）、以及从症状到治疗的完整间隔（不只是转诊到确诊）。修复的顺序通常是产能而非流程的：内镜与影像与病理的容量与人力、内窥镜的每日台次、“直接活检通道（皮肤、泌尿、子宫内膜）”、把最贫困地区设为“恢复目标”而不是“接受现实”、以及公共宣传“症状就医”的配套（否则只是把延迟从系统转移到患者）——[[clinical-skills/medical-imaging]]、[[clinical-skills/records-handover]]。**

::: example 糖尿病登记系统醒了 {#ex-registry}
新上线的糖尿病登记系统显示：两万两千名登记患者中只有六成长期接受过眼底筛查、四成测过足、不足一半的肾小球滤过率与白蛋白比达标；同时平均糖化血红蛋白在下降。
::: solution
**过程指标对结局指标（[[#def-response]]、[[#def-burden]]、[[endocrine/diabetes-complications]]）：如何读这组数字：平均糖化血红蛋白下降是好事但具有欺骗性（它可能由“轻症被更多地登记”造成、且对终点的作用远小于血压与吸烟的处理）；而并发症监测的覆盖率是真正可执行、可问责的质量缺口——它的分布几乎肯定按剥夺分层，所以要按地区、年龄、性别、种族与剥夺分层重报——[[public-health/determinants-inequalities]]。缺口的原因清单：把随访当作门诊的副产品（而不是主动召回）、认知筛查与足部与眼底检查需要培训与设备、验光与足病服务的容量与地理、以及“数据已录入而无人负责处理”的常见治理真空。修复的组合：以护士主导的年度综合评估门诊（一次完成眼、足、肾、烟、血与用药）、把筛查外包给社区光学与足病网络并签约完成率、把召回从信件改为多通道（短信与电话加社区渠道，并保留非数字路径）、以及在登记上建仪表盘与责任人（把“未随访超过15个月”作为一个需要清单的名单而非统计）——[[clinical-skills/records-handover]]、[[public-health/screening]]。治理：把完成率写入合同并与奖金脱钩（避免撇选重症患者）、把结果向全科与患者公开、以及监测“治疗负担”（每日被要求做的事是否已超出老人的执行能力）——[[geriatrics-palliative/polypharmacy]]、[[renal/chronic-kidney-disease]]。**

::: exercise 向财政部进言 {level=2}
财政部考虑提高酒精税以弥补赤字，但担心就业与健康影响。给出你的三条论证、一条你会承认的反论、以及你会要求的评估设计。
::: solution
**向财政部进言（[[#def-response]]、[[#def-determinants]]、[[public-health/health-systems-economics]]）：三条论证：一，需求有弹性且最弹性的是重度饮用的年轻人（价格上升10%会使总消费下降约一到两成、并使危险性饮酒下降更多），因此这是少数“收入与健康同向”的税；二，成本的外部性由他人支付（急诊与住院、暴力与生产力损失、以及儿童伤害），不含税的价格是错的；三，税收收入与医疗成本节约可以量化（对医院费用的净效应常常为正）。要承认的反论：累退性（穷人的绝对支出占比更高）与对酒店业就业的影响——回答是把净负担按收入分层计算（最穷人群的健康收益与医疗支出节省常常超过其税负），并把就业影响限定为可通过转型补贴处理的部分，同时坚决拒绝用“补贴替代”（那会把消费降回来）。评估设计：预先注册的中断时间序列，用未调整地区作对照、按品类与地点分层（免税与跨境购买、以及酒精强度与无醇产品的替代）、结局包括死亡率、急性胰腺炎、儿童入院与暴力事件；以及把“收入用于何种干预”写进同一份方案，否则税会被重新分配掉——[[public-health/prevention-promotion]]。**

::: exercise 设计多病共存的门诊 {level=2}
为一位78岁、患六种长期疾病、服十一味药、近月两次跌倒的女性设计门诊。说明结构、你会删掉什么、以及如何衡量这次门诊成功。
::: solution
**多病共存的门诊（[[#def-response]]、[[geriatrics-palliative/polypharmacy]]、[[geriatrics-palliative/ageing-frailty]]）：结构：预约双时段、护士或药师先做用药重整与治疗负担清单（一天要做的事与她真正想做的事）、一次完成所有必要检查（不要让她为一项化验来三次）、以及以目标而非疾病为主线的问题列表（“少跌倒、能在花园里待着、不去急诊”）。删掉什么：按专科叠加的血压与血糖下限（预期寿命与损伤风险改变了获益）、把低密度脂蛋白数字追到指南阈值的一级预防（此处更可能伤害而非获益）、以及会加重体位性低血压的组合（α阻滞加利尿加三种降压药、以及镇静与抗胆碱负荷）；每一步撤药都要写下理由、时间表、以及家属需要知道“可能有短暂波动”。也要加什么：骨与跌倒的运动处方、疫苗、营养与蛋白、以及照护者的支持——那些从不进指南却改变结局的项目。衡量：跌倒与急诊回访、症状与生活品质、非计划住院、以及她自己的目标是否被达成；再记录“她今天带着多少件事离开、其中几件是她要的”——[[geriatrics-palliative/falls]]、[[cardiovascular/hypertension]]、[[clinical-skills/communication]]。**

::: exercise 给一次被避免的卒中算成本 {level=2}
一项减盐加血压控制的组合每年使某人群减少320例卒中，其中约四成留下失能。请给出成本—效果论证的结构，并指出谁会在哪里不同意。
::: solution
**给被避免的卒中定价（[[#def-response]]、[[public-health/health-systems-economics]]、[[nervous-system/stroke]]）：论证的结构：一次卒中的终身成本（急性住院、康复、长期照护、丧失生产力、以及照护者的时间与抑郁）乘以严重度分布，减去避免这些事件所需的干预成本，再给出一个“每质量调整生命年成本”；由于失能者占四成，健康收益远大于“死亡数”这一指标所示——这正是使用伤残调整生命年与质量调整生命年的理由。会被质疑之处：折现率（对长寿命获益打折会让干预显得不如实际）、成本边界（是否计入照护者的无酬劳动与交通与住房改造）、以及单位成本来自哪里（高收入国家的长期照护价被直接搬到别处会失真）；还有“谁付钱谁受益”的部门错配（卫生支出换来的是社会照护与养老金的节省），这是政策上最难的一关——所以论证必须同时给卫生部门净成本与全政府净收益。反对意见的诚实质疑：避免的卒中有相当部分发生在高龄者，长期照护成本并未消失而是被转移；这不能否认健康收益，但要求把“结局”表述为健康与功能而不是储蓄——[[medical-ethics-law/justice-resources]]、[[geriatrics-palliative/end-of-life-care]]。**

::: exercise 写产业干扰政策 {level=3}
你的公共卫生机构要制定一份关于与食品、酒精与烟草业互动的政策。请起草条款：参与、资助、伙伴关系、命名、以及执行。
::: solution
**产业干扰政策（[[#def-determinants]]、[[#def-response]]、[[medical-ethics-law/professionalism-regulation]]）：参与：只有存在可证明的公共利益且目标、时点、指标事先公开时，才与非传染性疾病相关的商业实体互动；所有会议须有议程、记录、公开的利益申报，两名机构人员在场、且不允许单独会见。资助：拒绝用于机构运行、指南制定、继续教育、研究学生奖学与任何带有商标权的项目的资金；接受用于评估性研究时须是无条件研究基金、独立分析权、以及无论结果的发表承诺（预注册与数据可及条款）；并把“资金换政策温和”这一实际风险明说。伙伴关系：不使用联合品牌与共同署名、不担任其“责任与可持续”倡议的顾问委员会、不接受其提供的数据作为唯一依据（行业自有数据的“科学完整性”与独立测量比较）、以及不用其传播渠道开展健康宣传。命名与透明：公开全部互动的登记表、年报里单列“产业互动”一节、以及在本机构刊物上发布政策原文。执行：把政策变成采购与研究伦理的硬性核对项；违规的后果与处理路径写清；以及一个内部“警惕”角色，负责对新形式（企业社会责任奖项、学术讲座的赞助席位、以患者团体为中介的影响）作出判断。政治现实：草案会被告为“不合作”，所以要在文本中同时写下“与私部门合作解决其造成之问题的必要性”——这是既诚实又具防御性的框架——[[medical-ethics-law/consent-capacity]]、[[public-health/global-health]]。**

::: exercise 向新任卫生部长简报 {level=3}
新任部长上任第一周，请你用一页说明本国的慢性非传染性疾病问题与她真正能动的杠杆。写出这一页。
::: solution
**一页简报（[[#def-burden]]、[[#def-response]]、[[public-health/health-systems-economics]]）：第一段（问题）：本国的过早死亡中约三分之二来自慢性非传染性疾病、且高度集中在最贫困的五分之一人群；多病共存是常态；我们不是缺技术，而是缺覆盖与环境的改变。第二段（三件能立刻做的事）：把烟草与酒精税按超过通胀的幅度调整（同时立法把部分收入投入青少年服务）；启动食品工业的减盐第二阶段并把不达标产品的政府采购排除；以及在全国推行高血压的社区滴定方案（培训社区卫生工作者或药师、用固定剂量组合、以控制率为考核）。第三段（需要她的政治资本的那件事）：立法而非倡议——禁止面向儿童的促销、前端标签、以及公共场所禁烟的执行与资助；自愿守则的历史记录是失败，而部长唯一比卫生部门更大的杠杆是财政与农业与交通。第四段（她会听到的反对，以及回答）：“这是保姆国家”（回答是：环境让默认选项变健康，同时保留选择）；“会伤害穷人与小企业”（回答：配方调整的技术支援与分级时间表的缓冲、以及按收入分层的净效应计算）；“这会毁掉与产业的对话”（回答：对话继续，但不在监管权限内交换）。最后一段（如何知道自己成功了）：三年期的指标承诺——血压控制率、30至70岁的死亡率、按剥夺分层的诊断延迟、以及税收对价格的传导率——全部公开，并把它们放在她的预算陈述里——[[public-health/prevention-promotion]]、[[public-health/determinants-inequalities]]。**
