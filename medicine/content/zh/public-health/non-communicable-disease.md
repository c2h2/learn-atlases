1950年，多尔（Richard Doll）和布拉德福德·希尔（Austin Bradford Hill）报告说，在他们的伦敦医院研究中，几乎所有肺癌患者都吸烟。七十五年后，吸烟仍是英国最大的单一可预防死因，但成年吸烟者的比例已从男性的一半以上降至约十分之一的成年人。这一下降主要是靠政策实现的：税收、广告禁令、无烟法律，以及从2027年起逐年提高的购买年龄，这意味着2009年1月1日或之后出生的人永远不能合法购得烟草。控烟是预防非传染性疾病的范本，它既表明了什么有效，也表明了这需要多长时间。

非传染性疾病（NCD），主要是心血管疾病、癌症、慢性呼吸系统疾病和糖尿病，如今在几乎每个国家都造成了大部分死亡。本章描述其负担、预防它们的危险因素方法，以及针对每一种主要行为危险因素（烟草、酒精、饮食和身体活动）的政策杠杆。本章把[[public-health/prevention-promotion]]中的原则应用于具体问题。

## 非传染性疾病的负担 {#burden}

::: definition 非传染性疾病 {#def-ncd}
**非传染性疾病**（NCD）是不在人与人之间传播的疾病，通常病程长，由遗传、生理、环境和行为因素共同造成。世卫组织的NCD规划聚焦于四大类疾病：**心血管疾病**、**癌症**、**慢性呼吸系统疾病**和**糖尿病**，以及它们共有的四种行为危险因素：**烟草使用**、**有害饮酒**、**不健康饮食**和**缺乏身体活动**。在“5×5”框架中，空气污染被增列为第五种危险因素，精神健康被增列为第五类疾病。

在监测中，**过早**NCD死亡是指30～70岁之间的死亡。
:::

据世卫组织（2025年9月的概况介绍），2021年NCD至少导致4,300万人死亡，约占全球与大流行无关死亡的75%。其中1,800万例死亡发生在70岁之前，这些过早死亡中82%发生在低收入和中等收入国家。心血管疾病导致至少1,900万例死亡，癌症1,000万例，慢性呼吸系统疾病400万例，糖尿病200多万例（包括糖尿病导致的肾病死亡）。认为NCD是“富贵病”的观点是错误的：在国家内部和国家之间，NCD对较贫困者的打击最重。

可持续发展目标3.4旨在通过预防和治疗，在2015年至2030年间将NCD过早死亡率降低三分之一，并促进精神健康。很少有国家走在实现这一目标的轨道上。

在英国，心血管疾病和癌症约占全部死亡的一半，造成健康生命损失的主要危险因素是烟草、高血压、高体重指数、饮食风险、高血糖和酒精。每一项都有很强的社会分布特征，这就是为什么NCD在[[public-health/determinants-inequalities]]所述的预期寿命差距中占很大一部分。

## 危险因素方法 {#risk-factors}

大多数NCD有几十年间共同作用的多种病因。一种有用的思考方式是把它们看成一条链：**远端**决定因素（收入、教育、食品和烟草行业、城市设计）塑造**行为**危险因素（吸烟、饮食、缺乏活动、饮酒），后者导致**代谢**危险因素（血压升高、血糖升高、胆固醇升高、超重和肥胖），再导致**疾病**（心肌梗死、卒中、癌症、慢性肾脏病）。每一个环节都可以干预：政策作用于远端和行为因素，临床照护作用于代谢因素和疾病。

归因于某一危险因素的负担用**人群归因分数**（PAF）估计：如果暴露处于最低可行水平，将不会发生的病例所占的比例。对于单个二分类暴露，$PAF = p(RR - 1)/[1 + p(RR - 1)]$，其中$p$是暴露的流行率，$RR$是相对危险度。

::: warning 归因分数加起来并不等于100%
疾病有多种共同起作用的病因。一个既吸烟又有高胆固醇的人发生的心肌梗死可能同时归因于两者：消除其中任何一个都能预防它。因此，同一疾病的不同危险因素的PAF相互重叠，其总和可能超过100%。如果各危险因素独立起作用，合并PAF为$1 - (1 - PAF_1)(1 - PAF_2)\cdots$，而不是简单相加。这不是悖论；它反映了通常需要多种病因共同作用这一事实，这意味着预防每个病例都有几种途径。
:::

::: example 合并归因分数 {#ex-paf}
在某人群中，30%的冠心病死亡归因于血压升高，20%归因于吸烟。假设这两个危险因素独立起作用，冠心病死亡中有多大比例归因于其中一个或两个？
::: solution
*不*归因于血压的比例是$1 - 0.30 = 0.70$；其中不归因于吸烟的比例是$1 - 0.20 = 0.80$。两者都不归因的比例是$0.70 \times 0.80 = 0.56$。

合并PAF$= 1 - 0.56 = 0.44$，即44%，而不是$30\% + 20\% = 50\%$。有些死亡同时归因于两个因素，消除其中任何一个都能预防，因此把各自的PAF相加会重复计算这部分死亡。
:::
:::

### 为什么价格是最有力的杠杆 {#price}

导致大多数NCD的产品（烟草、酒精、高脂高盐高糖食品）由有利可图的行业生产和营销。它们通过营销、定价、产品设计和游说对健康产生的影响，称为**健康的商业决定因素**。由于这些产品是购买来的，其价格和可得性是减少消费最有效的杠杆之一。

::: theorem 需求的价格弹性 {#thm-elasticity}
**需求的价格弹性**$\varepsilon$是价格变化1%所引起的消费量变化的百分比。对于小幅变化，

$$
\%\Delta Q \approx \varepsilon \times \%\Delta P.
$$ {#eq-elasticity}

对于烟草和酒精，$\varepsilon$为负值（价格上涨使消费减少），其绝对值通常小于1（需求**缺乏弹性**）：在高收入国家，香烟的估计值通常约为$-0.4$，酒精则因饮料种类不同约在$-0.3$至$-0.8$之间。年轻人和低收入者的需求弹性更大。
:::

::: proof
缺乏弹性的需求有两个后果，二者共同使税收行之有效。第一，涨价仍会减少消费：在$\varepsilon = -0.4$时，价格上涨10%使消费减少约4%，在整个人群中这意味着吸烟者减少、每个吸烟者吸的烟减少、开始吸烟的年轻人减少。第二，由于消费下降的比例小于价格上涨的比例，该产品的总支出以及税收收入都会增加。政府获得可用于资助服务的收入，同时健康获益也在累积。

年轻人和低收入者的弹性更大，意味着税收对这些群体吸烟和饮酒的影响最大，因此价格措施往往会缩小健康不平等，尽管税收的经济负担是累退的。烟草税的效果也取决于执法：非法贸易和跨境贸易会削弱其效果，烟草公司还可以在廉价品牌上自行消化增税以保持低价，这就是为什么最低价格以及能提高最便宜产品价格的税收结构很重要。
:::

::: widget plot
f: 100*(1 + x/100)^k
x: 0, 100
y: 0, 110
sliders: k=-0.4:-1.5:0:0.05
labels: \text{消费量（基线的\%）}
hlines: 100
caption: 在价格弹性k恒定的情况下，消费量（占基线的百分比）随价格上涨百分比的变化。k = −0.4（香烟的典型值）时，价格翻倍（上涨100%）使消费减少约四分之一。把k向−1移动，观察年轻人等对价格更敏感群体的更强反应。
:::

::: example 一次增税 {#ex-tax}
增税后香烟价格上涨10%。使用$-0.4$的弹性，用(a)线性近似和(b)恒定弹性模型$Q = Q_0(1 + \Delta P)^{\varepsilon}$估计消费的下降幅度。如果原来的总支出为100亿英镑，它会怎样变化？
::: solution
(a) $\%\Delta Q \approx -0.4 \times 10\% = -4\%$。

(b) $Q/Q_0 = 1.10^{-0.4} = 0.9626$，下降3.7%。对于小幅变化，近似值很接近。

支出等于价格乘以数量：$1.10 \times 0.9626 = 1.059$，因此支出增加约5.9%，达到约106亿英镑。吸烟者作为一个群体支出更多，增加的部分主要以税收形式归政府。这就是烟草税的“双重红利”：吸烟减少，收入增加。这也是为什么增税应与戒烟帮助同时进行，使无力继续吸烟的人得到戒烟支持，而不是陷入困境。
:::
:::

## 烟草 {#tobacco}

吸烟可导致至少15个部位的癌症（肺、口腔、喉、食管、膀胱、胰腺、肾、宫颈等）、冠心病、卒中、外周动脉疾病、慢阻肺以及妊娠期损害。在英国医生研究的50年随访（2004年）中，成年后一直吸烟的男性平均比终生不吸烟者早死约10年，约一半的持续吸烟者死于吸烟。30岁戒烟几乎可以避免全部额外风险，50岁戒烟可使其减半。

据英国国家统计局数据，2024年英国成年人吸烟率为10.6%（约530万人），是自2011年有记录以来的最低水平。在较贫困地区、精神疾病患者（他们消费的香烟占全部香烟的很大一部分）和某些职业群体中，吸烟率仍然高得多。

**英国的政策措施**遵循世卫组织《烟草控制框架公约》（FCTC，2003年通过，2005年生效），世卫组织把其降低需求的措施概括为**MPOWER**：监测烟草使用（Monitor）；保护人们免受烟草烟雾危害（Protect）；提供戒烟帮助（Offer）；警示烟草危害（Warn）；执行广告、促销和赞助禁令（Enforce）；提高税收（Raise）。英国的里程碑包括：

- 禁止大多数烟草广告（2002—2003年）；
- 封闭公共场所和工作场所禁烟（苏格兰2006年，英格兰和威尔士2007年）；
- 购买年龄从16岁提高到18岁（2007年）；
- 商店撤除烟草陈列（2012—2015年）和标准化包装（2016—2017年）；
- 禁止在载有儿童的汽车内吸烟（2015年）；
- 禁止销售一次性电子烟（2025年6月）；
- **《2026年烟草与电子烟法》**（2026年4月29日获御准），规定向2009年1月1日或之后出生的任何人出售烟草均属违法，年龄限制自2027年1月1日起适用，并引入零售商许可制度以及管理电子烟口味、包装和陈列的权力。

**戒烟支持。** 最有效的方法是把戒烟服务的行为支持与药物（伐尼克兰、金雀花碱或联合尼古丁替代疗法）或尼古丁电子烟结合起来。Cochrane的系统评价发现了高确定性证据，表明与尼古丁替代疗法相比，尼古丁电子烟能提高戒烟率。电子烟并非没有风险，从未吸烟的儿童使用电子烟是一个严重问题，因此对年轻人的营销和销售受到限制；但对于吸烟的成年人来说，完全改用电子烟的危害远小于继续吸烟。

## 酒精 {#alcohol}

酒精导致肝病、多种癌症（口腔、咽喉、食管、肝、肠和乳腺）、高血压、心房颤动、心肌病、出血性卒中、胰腺炎、伤害、暴力和依赖，并与自杀有关。不存在没有癌症风险的饮酒水平。

::: definition 英国酒精单位与低风险指南 {#def-units}
一个英国**酒精单位**是10 mL（8 g）纯乙醇。一份饮品所含的单位数为

$$
\text{单位数} = \frac{\text{酒精度（\%）} \times \text{体积（mL）}}{1000}.
$$ {#eq-units}

英国首席医疗官的低风险饮酒指南（2016年）建议，为使健康风险保持在低水平，男性和女性经常饮酒时每周不应超过**14个单位**；每周饮酒多达14个单位的人应将其分散在三天或更多天；每周有几天不饮酒会有帮助；孕妇或计划怀孕的女性应完全不饮酒。
:::

::: example 计算酒精单位 {#ex-units}
一位52岁男性告诉全科医生，他“大多数晚上喝一瓶葡萄酒，大概每周五个晚上”。葡萄酒的酒精度为13.5%，每瓶750 mL。他每周喝多少个单位？接下来应怎么做？
::: solution
每瓶单位数$= 13.5 \times 750/1000 = 10.1$个单位。每周五瓶$= 50.6$个单位，是低风险指南的三倍多。

**下一步。** 用AUDIT-C进行结构化询问，若阳性再做完整的AUDIT，以评估风险和可能的依赖（例如晨起饮酒、戒断症状）。检查是否已有损害：血压、肝功能和全血细胞计数，并询问情绪、睡眠和受伤情况。进行简短干预：就他的饮酒量与指南相比给予个体化反馈，说明对他重要的风险，并制订切实可行的目标。如果他有依赖，就不应突然停酒，因为有戒断性癫痫发作和谵妄的风险；应通过专科服务转介进行辅助戒断和治疗。处理遵循NICE关于酒精使用障碍的指南。酒精相关危害和依赖在[[psychiatry/substance-use]]中进一步讨论。
:::
:::

**酒精政策。** 世卫组织针对酒精的“最合算措施”是通过税收或定价政策提高价格、限制实际可得性（营业时间、销售网点、购买年龄）以及限制广告。其他有效措施包括配合呼气检测的酒驾法律。

**最低单位定价**（MUP）为每单位酒精设定最低价格，低于该价格不得出售。它针对的是主要由重度饮酒者饮用的廉价烈性产品，对酒吧饮品的价格或适度饮酒者几乎没有影响。苏格兰于2018年5月以每单位50便士实行MUP，并于2024年9月提高到65便士。威尔士于2020年以50便士实行MUP，并于2026年10月提高到65便士。2023年发表于《柳叶刀》的一项评价估计，与预期相比，苏格兰的MUP与完全归因于酒精的死亡减少13.4%相关，降幅最大的是最贫困地区。英格兰和北爱尔兰尚未实行MUP。

## 饮食、肥胖与身体活动 {#diet}

不健康饮食（高盐、高糖、多加工肉类和高能量密度食品，水果、蔬菜、全谷物、豆类和坚果少）是全球主要的死亡危险因素之一。在英格兰，四分之一以上的成年人患有肥胖；根据全国儿童体格测量项目，六年级（10～11岁）儿童中超过五分之一患有肥胖，最贫困地区的患病率约为最不贫困地区的两倍。

肥胖源于能量失衡，而驱动这种失衡的主要是环境，而不是个人意志力。在肥胖上升的这段时期里，廉价高能量食品的供应、份量、营销以及以汽车为中心设计的建成环境都发生了变化，而人类的生物学并没有变。因此，政策旨在改变食物环境：

- **财政措施。** **软饮料行业税**（2018年）向添加糖的软饮料生产商征税，含糖量超过每100 mL 8 g的适用较高税率，超过5 g的适用较低税率。大多数生产商调整了配方以保持在阈值以下，所售饮料的含糖量大幅下降。自2028年1月1日起，较低的阈值降至每100 mL 4.5 g，添加糖的预包装奶基饮料也将被纳入征税范围。
- **配方调整项目**，为行业设定盐、糖和热量目标。2003年开始减盐之后，测得的盐摄入量有所下降。
- **营销限制。** 自2026年1月5日起，英国禁止在5:30至21:00之间在电视和点播服务上、以及在任何时间在付费网络媒体上投放可识别的“较不健康”食品和饮料产品的广告。英格兰自2022年起限制在商店显眼位置促销此类产品。
- **标签。** 包装正面的交通灯标签，以及自2022年起英格兰大型餐饮企业菜单上的热量标示。
- **场所。** 学校膳食标准、免费校餐和“健康起步”（Healthy Start）计划。

对于个人，NICE推荐多成分的体重管理项目；作用于GLP-1受体的药物（如司美格鲁肽和替尔泊肽）在试验中可使体重大幅下降，目前正在NHS中为符合NICE标准的人引入。这些治疗很有价值，但它们本身无法扭转由环境驱动的人群趋势，而且其成本和供应限制了可及性。

**身体活动。** 英国首席医疗官指南（2019年）建议成年人每周至少进行**150分钟**中等强度活动（或75分钟高强度活动，或两者结合），每周至少两天进行肌肉强化活动，并尽量减少久坐。儿童和青少年平均每天应进行至少60分钟中等至高强度活动。任何活动都比没有活动好，最大的收益来自让最不活跃的人开始做一些活动。人群措施包括安全的步行和骑行路线（“主动出行”）、城市设计、学校体育和工作场所政策；个人措施包括初级保健中的简短建议和运动转介。

## 预防心血管疾病和癌症 {#cvd-cancer}

心血管预防把人群策略（控烟、减盐、食品政策、主动出行）与高危策略结合起来。在英格兰，**NHS健康检查**每5年邀请一次40～74岁、无已知心血管疾病的成年人，检查血压、胆固醇、BMI、吸烟、饮酒和身体活动情况，并用**QRISK3**计算10年心血管风险。风险增加者可获得生活方式支持，并在适当时按照NICE指南使用他汀类药物和治疗高血压。发现并控制高血压是最有效的干预之一：许多高血压患者未被诊断或未治疗达标。

在癌症方面，英国癌症研究会估计，英国约十分之四的癌症病例是可以预防的，主要途径是不吸烟、保持健康体重、少饮酒、健康饮食、防晒以及避免某些感染（通过疫苗接种预防HPV和乙型肝炎）。癌症控制的另一支柱即筛查，见[[public-health/screening]]。

::: example 一次危险因素诊疗 {#ex-health-check}
一位47岁的加勒比黑人女性参加NHS健康检查。她不吸烟，每周饮酒约6个单位，很少步行，BMI为32 kg/m²。她的血压为152/96 mmHg，总胆固醇5.9 mmol/L，HbA1c 44 mmol/mol（6.2%）。概述接下来的步骤。
::: solution
**确认血压。** 检查中单次读数升高不能作为诊断。按照NICE高血压指南，提供动态（或家庭）血压监测予以确认，并寻找靶器官损害（尿白蛋白/肌酐比值、电解质和eGFR、眼底检查、心电图）。

**血糖。** HbA1c为42～47 mmol/mol提示2型糖尿病高风险（“非糖尿病性高血糖”）。应为她转介NHS糖尿病预防项目，并每年检查HbA1c。

**心血管风险。** 用完整数据计算她的QRISK3评分；族裔、血压、胆固醇和BMI都会影响评分。如果她的10年风险达到10%或以上，经讨论后按照NICE血脂指南提供他汀类药物。

**生活方式。** 讨论体重、饮食（包括盐）和身体活动，使用对她重要的目标；提供转介至体重管理服务。减重和减盐也会降低她的血压。

**如确诊，治疗高血压：** 对于无糖尿病的非洲黑人或非裔加勒比家族背景者，NICE流程推荐钙通道阻滞剂作为一线治疗，在这一群体中加用药物时优先选择血管紧张素II受体阻滞剂而不是ACE抑制剂。处理决定遵循现行NICE指南，并与患者共同作出。

这个病例说明了几个中等程度的危险因素如何叠加成可观的风险，以及一次检查如何打开多条预防途径。
:::
:::

## 全球应对 {#global}

世卫组织的“**最合算措施**”是针对NCD最具成本效果且可行的干预，包括烟草税、无烟法律、平装和广告禁令；酒税以及对可得性和营销的限制；通过配方调整和标签减盐；关于身体活动的公众教育；以及为心血管高危者提供药物治疗和咨询。芬兰北卡累利阿的成功范例（1972年起的社区项目与国家政策相结合，使冠心病死亡率大幅下降）鼓舞了世界各地采用人群方法。

障碍相当大。其产品导致NCD的行业游说反对监管、提起诉讼，并资助倡导个人责任而非政策的研究和组织。贸易协定可能限制国内监管。低收入和中等收入国家的卫生体系是为急性病和传染病建立的，往往难以应对长期疾病。这些问题在[[public-health/global-health]]中展开。

::: quiz
某国政府希望在预算固定的情况下尽可能减少酒精危害。哪种方法有最有力的人群获益证据支持？
- [ ] 开展关于饮酒风险的全国媒体宣传。
- [ ] 在中学开设酒精教育课。
- [x] 通过税收或最低单位定价提高最便宜酒类的价格。
- [ ] 在酒瓶上标注单位数。
::: solution
价格措施属于世卫组织针对酒精的“最合算措施”。价格上涨时需求下降，对饮用廉价酒的重度饮酒者和年轻人影响最大，而苏格兰的最低单位定价与集中在贫困地区的酒精特异性死亡减少相关。教育宣传、学校课程和标签很受欢迎，在提供信息方面有价值，但评价显示它们单独使用对饮酒影响甚微。
:::
:::

::: history
1950年，英国的多尔和布拉德福德·希尔，以及美国的温德（Ernst Wynder）和格雷厄姆（Evarts Graham）发表了将吸烟与肺癌联系起来的病例对照研究。多尔和希尔于1951年开始的英国医生研究随访了约34,000名男性医生达50年，量化了吸烟的终生风险。1948年在马萨诸塞州开始的弗雷明汉心脏研究引入了“危险因素”一词，并确定高血压、高胆固醇和吸烟是冠心病的病因。英国皇家内科医师学会的报告《吸烟与健康》（1962年）和美国卫生总监报告（1964年）把证据转化为政策。1972年，芬兰北卡累利阿项目开始了一项旨在降低心血管危险因素的全社区项目。2003年通过的世卫组织《烟草控制框架公约》成为联合国历史上获批准最广泛的条约之一。2011年，首次联合国NCD问题高级别会议把NCD列入全球发展议程。
:::

## 后续内容

本章背后的预防原则见[[public-health/prevention-promotion]]，NCD的社会梯度见[[public-health/determinants-inequalities]]。心血管疾病的临床预防见[[cardiovascular/hypertension]]，糖尿病见[[endocrine/diabetes]]，酒精和药物使用见[[psychiatry/substance-use]]。全球NCD议程在[[public-health/global-health]]中继续讨论。

::: summary
- NCD（心血管疾病、癌症、慢性呼吸系统疾病、糖尿病）在2021年至少导致4,300万人死亡，其中1,800万人死于70岁之前，大多在低收入和中等收入国家。可持续发展目标3.4旨在到2030年将NCD过早死亡率降低三分之一。
- 共同的行为危险因素（烟草、酒精、饮食、缺乏活动）通过代谢危险因素（血压、血糖、血脂、肥胖）起作用。归因分数相互重叠，加起来并不等于100%。
- **健康的商业决定因素**塑造暴露；价格是最有力的杠杆，因为需求**缺乏弹性**：税收减少消费、增加收入，并减少不平等。
- **烟草**：约一半的持续吸烟者死于吸烟。2024年英国成年人吸烟率为10.6%。MPOWER措施、无烟法律、标准化包装以及**《2026年烟草与电子烟法》**（自2027年起不得向2009年1月1日或之后出生的任何人出售烟草）。电子烟帮助成年人戒烟。
- **酒精**：单位数$=$酒精度×mL/1000；首席医疗官指南为每周14个单位。**最低单位定价**（苏格兰和威尔士为65便士）估计使苏格兰酒精死亡减少13.4%。
- **饮食和活动**：软饮料行业税、配方调整、对较不健康食品广告的限制（自2026年1月起）和主动出行；首席医疗官建议每周150分钟中等强度活动。
- **NHS健康检查**（40～74岁，每5年一次）在人群措施之外实施高危策略。
:::

## 习题

::: exercise 一份饮品的单位数 {level=1 check="round(10*5.2*568/1000)/10"}
一品脱（568 mL）酒精度为5.2%的啤酒含多少个单位？保留1位小数。
::: solution
$5.2 \times 568/1000 = 2.95$，保留1位小数为3.0个单位。四品脱约含12个单位，接近整整一周的低风险上限。
:::
:::

::: exercise 最低价格 {level=1 check="18.2"}
在每单位65便士的最低单位定价下，一瓶700 mL、酒精度40%的伏特加最低能以多少英镑出售？
::: solution
单位数$= 40 \times 700/1000 = 28$。最低价格$= 28 \times £0.65 = £18.20$。
:::
:::

::: exercise 一周的饮酒量 {level=1 check="round(10*12*175/1000*5)/10"}
一位女性每周五个晚上各喝一杯175 mL、酒精度12%的葡萄酒。她每周喝多少个单位？保留1位小数。
::: solution
每杯单位数$= 12 \times 175/1000 = 2.1$。每周$= 2.1 \times 5 = 10.5$个单位：在指南范围内，不过可以建议她每周有几天不饮酒，而她正是这样做的。
:::
:::

::: exercise 合并归因分数 {level=2 check="round(100*(1-(1-0.25)*(1-0.15)*(1-0.10)))/100"}
某疾病三个独立危险因素的人群归因分数分别为25%、15%和10%。至少归因于其中一个的病例占多大比例？以小数表示，保留2位小数。
::: solution
都不归因的比例$= 0.75 \times 0.85 \times 0.90 = 0.574$。合并PAF$= 1 - 0.574 = 0.426$，保留2位小数为0.43，而简单相加为0.50。
:::
:::

::: exercise 弹性 {level=2 check="-10"}
年轻成年人酒精需求的价格弹性估计为$-0.5$。用线性近似计算，价格上涨20%后他们的消费量会变化百分之多少？（给出带符号的数。）
::: solution
$\%\Delta Q \approx -0.5 \times 20\% = -10\%$。消费下降约10%。
:::
:::

::: exercise 吸烟的人群归因分数 {level=2 check="round(1000*0.11*19/(1+0.11*19))/10"}
假设11%的成年人吸烟，吸烟者相对于从不吸烟者患肺癌的相对危险度为20。用$PAF = p(RR-1)/[1 + p(RR-1)]$计算PAF，以百分比表示，保留1位小数。为什么今天肺癌真正归因于吸烟的比例高于这个数？
::: solution
$p(RR - 1) = 0.11 \times 19 = 2.09$。$PAF = 2.09/3.09 = 0.676$，即67.6%。

肺癌在暴露数十年后才发生，因此相关的流行率是20～40年前的吸烟率，那时远高于11%。既往吸烟者的风险也仍然升高，而这一简单公式把他们当作未暴露者。考虑既往吸烟的估计把英国70%以上的肺癌归因于吸烟。
:::
:::

::: exercise 设计无烟一代 {level=3}
《2026年烟草与电子烟法》禁止向2009年1月1日或之后出生的任何人出售烟草。讨论支持和反对这项政策的论点，以及如何评价其效果。
::: solution
**支持。** 几乎所有吸烟者都在21岁之前开始吸烟，因此防止年轻人开始吸烟，随着时间推移将几乎消除吸烟。烟草在按预期方式使用时具有独特的危害，尼古丁极易成瘾，因此吸烟的“选择”是由儿童作出的，之后又受到依赖的制约。逐年提高的购买年龄并没有从现有成年吸烟者那里拿走任何东西。它传递了明确的信号，并可以通过零售商许可制度来执行。

**反对。** 它对不同日期出生的成年人区别对待；随着受限出生队列年龄的增长，执法可能变得困难；它可能增加非法贸易；有人认为成年人应有承担风险的自由。直接证据很少，因为还没有哪个国家全面实施过这样的法律（新西兰在其版本生效之前就将其废除了）。

**评价。** 通过大型调查按出生队列监测开始吸烟的情况，比较出生在截止日期前后的队列（一项自然实验），并与其他国家比较；通过试购追踪零售商的遵守情况；监测非法烟草的市场份额和年轻人使用电子烟的情况；从长期看，测量受影响队列中与吸烟有关的疾病。
:::
:::

::: exercise 选择针对肥胖的干预 {level=3}
某地方政府有一笔减少儿童肥胖的预算。它正在考虑：(a) 为肥胖儿童提供体重管理项目；(b) 通过规划政策限制在学校附近新开热食外卖店；(c) 开展鼓励家长烹饪健康饭菜的宣传活动；(d) 以学校为基础的身体活动和更健康的学校膳食。从覆盖面、可能的效果和公平性方面评价每一项。
::: solution
(a) 针对性项目帮助个别家庭，也是必要的，但覆盖的儿童很少，效果有限且往往短暂，并依赖于家长的时间和资源。覆盖面小、效果有限，公平性取决于能否使其易于获得。

(b) 规划限制以低成本改变了学校周边所有儿童的环境，而且作用于外卖店集中的地区，这些地区往往较为贫困。关于其对肥胖影响的证据有限且多为观察性的，但这一措施是结构性的，很可能是公平的。覆盖面大，效果不确定。

(c) 信息宣传活动很受欢迎，但依赖于许多家庭缺乏的时间、金钱、技能和烹饪设施。效果小，且可能扩大不平等。

(d) 以学校为基础的措施每天都能覆盖几乎所有儿童，不论其家庭资源如何。关于学校膳食标准和活动项目的证据显示有一定获益。覆盖面大且公平。

以(b)和(d)为重点、并为需要的儿童提供(a)的组合，符合证据和比例普惠主义原则；地方政府还可以支持营销限制和软饮料行业税等全国性措施。
:::
