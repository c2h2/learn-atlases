卫生经济学是稀缺性的临床科学：每一个“不治”的决定都是别处“治”的决定，而这门学科研究体系如何做这种选择——靠排队、价格、配给或计划。**本章覆盖经济学家的工具箱（机会成本、边际分析、质量调整生命年及其批评者、成本效果阈值与评估机构）、筹资设计（税收对保险、自付、覆盖范围的三角）、供方支付与激励、以及交付经济学（人力、药品、数字健康与生产力）。**

## 工具箱

::: definition 稀缺、评估与质量调整生命年 {#def-toolkit}
**基础概念简单得具有欺骗性。机会成本是万物的真实价格：一项被资助项目的成本，就是它挤掉的那个次优项目——这句话让每一次处方目录决定都成为一次隐藏的配给决定。边际分析问“再多一单位值多少”：高峰时最后一张重症床的价值，等于在边际上被挤掉的照护价值。质量调整生命年把寿命与功能折成一个数（权重从1到0，加上测量与估值的方法学），它的强项是可比较，弱处是被误解：残障者估值之争、年龄与终末期的争议、以及“用人群偏好给重症打分”的哲学质问。成本效果阈值是一个治理装置而非科学常数（传统上常被引用的区间、以及“我们其实不知道它挤掉了什么”的坦白）；评估机构把算术变成程序——比较对象、证据的不确定性、附带条件的数据采集、罕见病与临终的例外、以及分布式的顾虑被写进权重还是被留在桌下。任何评估的四个问题始终不变：与谁比较、以何视角、成本与结局算到哪一层、以及折现——把提问顺序改一改，结论往往就翻面。**
:::

## 钱

::: definition 筹资体系与全民覆盖 {#def-financing}
**卫生体系回答四个问题，答案不同，绩效也可预测。筹款：一般税收（贝弗里奇谱系）、社会医疗保险（俾斯麦式的疾病基金与工资缴费）、私人保险（按风险定价因而易生逆选择、以及医疗储蓄账户的实验）、以及自付（累退、保障不足，且至今仍在数十亿人身上充当实际的主要筹资）。池化方式决定谁替谁承担风险：单一 payer、多方付款人竞争、或碎片化的多头。购买与供给是否分离改变激励：内部市场、合同化、以及按服务付费对按人头对诊断相关分组对按绩效付费对整群责任——每一种支付都是一次行为经济学的实验，而每一种都产生了文书：按服务付费诱导数量，按绩效付费诱发博弈，分组付费诱导编码强度（“抬高等级”的文献与稽核的应对）。覆盖范围的三角有三边：人群、服务包、以及财务保护——全民健康覆盖的定义是三者兼得，而自付造成的灾难性卫生支出是那只没人立法承认的累退税。支出水平本身也有学问：高收入国家普遍落在支出—健康曲线的平坦段，而支出结构（人力、药品、技术、行政）与生产力才是差异所在；把卫生当作投资而非消费，是财政叙事里最廉价也最难兑现的一次改写——[[public-health/global-health]]、[[public-health/prevention-promotion]]。**
:::

## 交付

::: definition 人力、药品与数字评估 {#def-delivery}
**人力经济学就是交付经济学：供给模型（培养管道的算术、使国内计划变成国际计划的迁移弹性、以及“医师诱导需求”与“诱导实施”的争论）、以及分布问题（农村与弱势地区的短缺，价格、指令与还贷方案只能部分修复）。药品经济学是最大的一笔杠杆：参照定价、招标、仿制药与生物类似药的引入、以及以量换价的谈判（中央药品招标节省的百分比，是最常被复制的政策结果之一）。数字健康的评估正在补课：远程医疗的随机对照证据比宣传少，而部署科学决定成败；以及“生产力”这个卫生系统最不情愿的词——床位流转、出院流程、择期手术台的利用、以及缺失的资本（老化的建筑与失败的病历系统）。安全经济学是回报最好的分支：可避免的伤害是体系最贵的产品（住院日延长、赔付、以及士气成本），所以预防跌倒、用药核对与产时安全的投入回报常常好于许多新技术——[[clinical-skills/patient-safety]]、[[pharmacology/drug-development-prescribing]]。**
:::

::: example 关节注射的评估 {#ex-appraisal}
一家公司为一种膝关节黏弹性补充注射寻求资助，每疗程900英镑；其试验显示相较安慰剂有轻微镇痛获益、而相较物理治疗的对照较弱；本地处方目录委员会每两周开一次会。
::: solution
**把评估落到实处（[[#def-toolkit]]、[[#def-delivery]]、[[musculoskeletal/osteoarthritis]]）：委员会真正的问题有三个。效果是真的吗——假手术对照试验的教训（器械试验里的安慰剂反应、疼痛评分的最小临床重要差异）？值得拥有吗——每质量调整生命年的增量成本对着惯例区间，“与谁比较”的选择决定答案；以及我们的支付能力意味着挤掉什么——同一笔钱若改投膝周肌力训练与体重管理课程，或投给等待名单上更痛的另一群人。流程素养也要写进答复：企业提交的证据包、外部小组、附加数据安排与患者报告结局；以及“以研究为条件的临时资助”这一路径（何时撤销、由谁撤销）。临床建议与决策建议要分开：拒绝入目录不等于禁止使用，也不等于伤害无罪——而是把它放在减重、运动、骨科转诊之后，并说清理由。沟通层最容易被忽略：给患者的通俗语言解释（“为什么这笔钱去了别处”）、以及医师的申诉与再评估通道——[[clinical-skills/clinical-reasoning]]、[[medical-ethics-law/justice-resources]]。**
:::
:::

::: example 击垮择期手术的冬天 {#ex-backlog}
你的机构财务总监预测将出现四千万英镑的赤字：呼吸季占据了需值守的床位、择期恢复低于计划、临时用工支出、以及一个“不再升级”的季度。董事会要方案；各科主任想知道经济学到底说了什么。
::: solution
**赤字即诊断（[[#def-financing]]、[[#def-toolkit]]、[[public-health/determinants-inequalities]]）：诚实的翻译——机构赤字通常是“服务量对支付标准”的算术加上波动成本：冬季停床是真实的钱（每台停开手术的机会成本、填排班用的临时用工溢价、以及延误本身带来的并发症成本）；支付标准未能覆盖成本上升；而需求侧的积压在复利。方案要按经济学排序而非按政治响亮程度排序：先恢复产能（床位流转、社区与出院流程、把“社会照护阻塞”当作可计价变量）；再买服务量（加班与临时用工的溢价对把手术台用到边际的净成本——同样的活动买两次，一次贵得多）；然后才是削减（那些伤害被推迟而非消失的项目、以及等待名单的健康债务如何回到急诊）。要给出被挤掉者的名单：把“我们少做四百台髋关节”翻译成质量调整生命年与赔付账单，并把推迟治疗的心血管与癌症外溢写清——[[emergency-critical-care/acute-assessment]]、[[cardiovascular/coronary-artery-disease]]。治理层：财务与临床共同的假设、以每周服务量与未去院率作领先指标、以及不隐瞒地公开削减的理由——因为配给不可回避，唯一的选择是让它明确、公平且有证据。**
:::

## 通向何处

体系比较见[[public-health/global-health]]；安全经济学见[[clinical-skills/patient-safety]]；药品定价见[[pharmacology/drug-development-prescribing]]；人力与迁移见[[medical-ethics-law/justice-resources]]；预防的筹资见[[public-health/prevention-promotion]]与[[public-health/screening]]。

::: history
**卫生经济学的奠基文本来自稀缺性的床边：阿罗1963年论不确定性与医疗福利经济学的论文（关于市场为何无法为能力定价的分析，把职业伦理与临床规范当作质量保障的替代品，至今仍解释着这个职业的结构）；1970年代的“费用爆炸”文献；以及测量医院成本及其决定因素的服务研究。评估转向随俄勒冈州医疗补助豁免实验而来（那份优先清单程序把显性配给变成公共辩论），也随199年在“邮编彩票”争议之后成立的评估机构而来；此后各国扩散的评估机构把质量调整生命年从学术争论变成行政工具，而“阈值对区间”的争论与罕见病、临终例外又把分配伦理写回算术。药品费用控制有其自身的政策史：专利契约、价格管制与参照定价、以及节省可复制的中央招标体制（可及性创新的反论永久地列在脚注里）。支付改革接踵而来：1983年按诊断相关分组的预付制革命与其行为副作用的全球法典化；按绩效付费的试验与其混杂结论；以及取消使用者付费的运动——“撤掉收费之后谁来供药”的后续研究——[[public-health/global-health]]、[[public-health/prevention-promotion]]。**
:::

::: summary
- 机会成本是本章的第一句话：资助任何事物都意味着放弃另一事物，所以配给不可避免，唯一的选择是它是否明确、公平且有证据指引。
- 评估是应用伦理：以质量调整生命年做的成本效用分析既有缺陷又不可或缺，而评估机构之所以是二十世纪最好的公共卫生发明之一，正因为它让配见变得可见且可争议。
- 筹资设计预测绩效：池化分散风险，购买与供给分离改变激励，而支付方付费是规模化的行为经济学（按服务付费诱导数量，按绩效付费诱发博弈，分组付费诱导编码）。
- 全民覆盖是一个三边三角（人群、服务、财务保护），而自付仍是各国政府从未立法的最累退税。
- 在低支出阈值之上，交付经济学主导结局：人力排班、出院流转、采购与数字化重构对健康的影响超过边际技术——而可避免的伤害是体系最贵的产品。
- 疫情证明了本章最难的几课：冗余产能是保险，积压会复利，而择期手术是一间质量调整生命年工厂，账本看不见它的缺席。
:::

## 练习

::: example 胰岛素的谈判 {#ex-insulin}
你所在区域的采购联盟面临胰岛素列表价格为去年三倍；四家投标者、一种新的生物类似药，而患者团体发起了价格运动。联盟负责人要求谈判策略。
::: solution
**买不能替代之物（[[#def-delivery]]、[[#def-financing]]）：先读市场——胰岛素是基本药物市场失灵的典型（需求缺乏弹性、接近寡头、转换成本与装置锁定、以及“返利墙”结构使列表价与净价分离）。有先例的杠杆工具：以量换价的可确定份额招标（若干国家体制由此取得两位数百分比的节省）、在招标之前写好的生物类似药资格与可互换规则、跨类似物与人胰岛素产品的组合招标、以及带透明节省记账的保密折扣。谈判桌的现实：“上市即涨价”的模式（把多年承诺按住，直到测量完目录转化）、供应安全条款（短缺年代之后写进合同的“多元制造与优先分配”）、以及制造地与冷链条件。公平审计：列表对净价的分离如何影响患者援助与最穷国的参照价格（运动所揭露的“分层定价与最惠国”问题）、以及联盟的披露政策——“公共卫生里没有秘密的节省”。要公布的结果指标：每限定日剂量的净价、转换完成率、断货天数、以及患者自付占比。战略一句话：在买方集中度高而需求刚性的市场，谈判设计比谈判者的人格重要。**
:::
:::

::: example 私立部门的问题 {#ex-private}
在你的国家贫困地区，一半的首诊照护由私立提供（药店、教会诊所、未注册提供者）；卫生部新的质量政策把它们排除在外，理由是“监管太难”。请向质量总监进言。
::: solution
**监管不可回避的供给（[[#def-financing]]、[[#def-delivery]]、[[clinical-skills/patient-safety]]）：先给事实：首诊份额、结局与转诊模式（未注册提供者的处置延迟、抗生素与注射的滥用、以及假药与过期药的流通）；把它们排除在质量政策之外不会让它们消失，只会让伤害不可见。可行的阶梯：先注册与基础标准（培训、处方权限、报告义务）；把公共质量指标与督导扩展到私立并给出激励（认证与医保支付资格绑定、转诊双向性）；把安全网功能正式化（药品可及、夜间与急诊的分诊协议、以及法定报告与传染病监测接入——不接入私立部门就永远查不清疾病暴发的缺口）——[[infectious-diseases/stewardship-outbreaks]]、[[microbiology/antimicrobials]]。财务现实：自付是穷人主要的首诊付费方式，所以任何质量政策若不同时处理价格与保障，就会把人们推向更便宜而更危险的选择（灾难性卫生支出的测量、以及服务与保费补贴的组合）——[[public-health/global-health]]。治理层：一个能真正执法的监管机构（投诉与检查的公开结果）、以及“把私立当伙伴而非污点”的政治经济学——包括其相反风险：监管俘获与以质量为名的排他。**
:::
:::

## 练习

::: exercise 解释机会成本 {level=1}
用两句话向一位非临床的市议员解释机会成本；然后指出这套说法在哪一种情形下会误导。
::: solution
**两句话版：预算是固定的，所以资助一项服务就意味着少做另一项；真正的成本不是账上的钱，而是被挤掉的那些患者失去的健康。误导之处：当产能闲置时（一间空手术台做一台手术的边际成本远低于其支付标准），以及当钱能从别处筹到且该项目的外部性大于其直接收益（疫苗接种、结核发现、儿童营养）——此时“挤掉”的假设与真实约束都不成立；诚实的说法是先分辨当前是硬约束还是软约束——[[#def-toolkit]]、[[public-health/prevention-promotion]]。**
:::
:::

::: exercise 算一个质量调整生命年 {level=1}
某干预使患者在生命剩余30年间从0.4的健康效用升到0.7，成本增量为一万二千美元；另一干预用八千美元把0.9提到0.95并延长2年。分别计算质量调整生命年增益与每质量调整生命年的增量成本，并说明这个算法漏掉了什么。
::: solution
**算术与它的盲区（[[#def-toolkit]]）：前者增益=（0.7−0.4）×30=9个质量调整生命年，每一年约一千三百美元；后者=生存年增加乘以效用（约2×0.9≈1.8，加上剩余年份0.05的效用差×30≈1.5），合计约3.3，每一年约两千四百美元——单看数字前者占优。漏掉的部分：效用权重的来源与测量（时间权衡与标准量化问卷对残障状态的估值分歧）、发病率的结局（疼痛、失能、工作能力的部分状态）、分配与严重度（谁得到、多病的得到多少）、以及“每质量调整生命年的成本”里那个“成本”是否包含照护与生产力（视角不同，答案不同）。诚实的用法是把它当作可比较的证据之一，而不是自动裁决——[[medical-ethics-law/justice-resources]]、[[clinical-skills/clinical-reasoning]]。**
:::
:::

::: exercise 诊断等待名单 {level=2}
一个地区的髋膝关节等待名单创纪录；有三种主张：加做手术、提高支付标准以吸引外科医师、或先做非手术管理。请以经济学论证你的排序，并说明你如何测量成功。
::: solution
**把三种主张分开算（[[#def-toolkit]]、[[#def-delivery]]、[[musculoskeletal/osteoarthritis]]）：加做手术（台次时段与人力溢价的价格、与“同样活动买两次”的边际成本对照）、提高支付标准（价格对供给的弹性在专科短缺中往往弱而滞后；且支付标准的收入若被用于加班与临时用工，则不会变成台次）、以及分流到非手术管理（减重、运动治疗、疼痛与注射的有限效果——需要按证据分级，别把营销当证据）与骨科前门诊的结构性方案。经济学的答案通常是：先修复产能与流转（麻醉与病房人力、出院流程、以及把“不能回家”当作可定价的瓶颈——社会照护），再谈价格；同时把需求管理当作长期投资而非削减伪装。测量——等待中位数与分布的尾部（等待超过一年的比例）、患者报告结局与疼痛改善、以及“等待期间的健康债务”（跌倒、抑郁、阿片使用、以及 最终的关节功能损失）。政治与沟通层：公开名单的规则要写清、并解释为何“最痛者优先”要优于“先来先得”——[[clinical-skills/communication]]、[[geriatrics-palliative/falls]]。**
:::

::: exercise 设计支付改革 {level=2}
为一家区域医院集团从按服务付费转向整合支付设计改革：目标、机制、博弈的防堵、以及公平保障。
::: solution
**支付改革设计（[[#def-financing]]、[[#def-delivery]]）：先说目标（避免住院与急诊回访、功能结局、人群健康、以及财务保护），因为支付形式是达成目标的手段而不是目的。机制：按人群按人头打包支付并附纵向责任、bundles用于择期手术路径、以及按绩效付费只挑真正可测且不诱发选择偏差的指标。防堵是设计的核心：编码强度膨胀（抬高等级）用年度一致的病例组合校正与外部稽核；撇选低风险患者用风险调整与“必须服务所有人”的合约束；服务转移（把门诊转成住院或把成本推给下级机构）用跨层数据监测；以及“以质量指标为名的门槛提高导致小型-提供者出局”的反身效应——[[clinical-skills/records-handover]]、[[public-health/determinants-inequalities]]。公平保障：按剥夺指数分层的结局与再入院、语言与残障的可及性、以及把“没人敢收的重症患者”比例作为硬指标。过渡治理：双向风险共担的年限、以基线服务量为对照的前后评估与预注册分析计划、公开结果看板、以及把节省优先用于服务而非用于行政的路径——[[public-health/health-systems-economics]]。**

::: exercise 给安全计划算成本 {level=2}
你要为一套患者安全干预（用药核对、分娩出血包、跌倒预防、以及不良事件报告与学习系统）争取预算。请说明成本、回报、以及这些回报为何总在账本上隐形。
::: solution
**安全经济学（[[#def-delivery]]、[[clinical-skills/patient-safety]]）：成本侧通常是人力与流程时间、培训、以及电子处方的配置；回报侧是住院日延长、额外检查与转科、赔付与保费、以及员工离职。为什么隐形：多数体系把并发症成本记在科室预算而把节省记在总账，所以没人赚到账本收益；而避免的伤害没有病历，因此无法被看见（“从未发生的手术延迟”）。方法学要求：以本地基线伤害率乘以避免比例与单位成本做模型、并给出敏感性区间；把不可定价的伤害（家属的痛苦、员工的道德创伤）明说而不是塞进货币值。治理收益：可信报告文化带来的早期预警本身就是保险（疫情前的 呼吸机演练、短缺预警）；而把安全预算当成“技术”而非“文化”的机构，会在下一次危机里付双倍。诚实的一句话：多数安全干预按每质量调整生命年算都很便宜，但“便宜”不会自动换来预算——需要一个愿意为看不见的东西负责的付款人——[[pharmacology/adverse-reactions]]、[[obstetrics-gynaecology/postnatal-period]]、[[geriatrics-palliative/falls]]。**

::: exercise 就税收向部长进言 {level=3}
部长考虑对含糖饮料加税。请给出支持的理由、预期会被引用来反对的理由、以及你会坚持要写进政策的三个补偿或评估条款。
::: solution
**税收咨询（[[#def-toolkit]]、[[#def-financing]]、[[public-health/prevention-promotion]]）：支持的理由是三重外部性与内部性：医疗成本的外部性、信息与自控的失败、以及儿童选择的不可逆；经济学预测价格弹性在低到中等收入群体最大（这正是“累退”的批评来源，也是健康收益最大的地方）。反对会被引用的理由：累退、替代消费、农民与制造业就业、以及“个人自由”。三条款：一是把税收明确用于面向低收入群体的健康干预（学校餐、运动、可及的健康食品补贴），把“累退的税负”变成“进步的净转移”；二是预先注册评估（购买、体重、牙科、以及跨品类替代的替代弹性）与日落条款；三是行业诉讼与“轻微改配方避税”的防御——按含糖量分档而非按品类、以及把代糖产品纳入规则时的证据谨慎——[[public-health/non-communicable-disease]]、[[gastrointestinal/clinical-nutrition]]、[[paediatrics/adolescent-health]]。治理与政治层：烟草与酒精税的收入曲线（弹性使收入低于线性预测）、走私与跨境购买的监测阈值、以及“税不是预算工具而是健康工具”这一公开承诺——[[public-health/determinants-inequalities]]。**

::: exercise 评估远程医疗扩张 {level=2}
一个慢性肾脏病门诊以视频替代了三分之二的复诊；管理层宣布“节省”了门诊空间并宣布满意度上升。请设计一个严肃的评估。
::: solution
**远程医疗的严肃评估（[[#def-delivery]]、[[public-health/screening]]、[[renal/chronic-kidney-disease]]）：先拆“节省”：门诊空间省下的是账面容量而非现金；真正的可变节省在交通与缺勤（对医院常不可见）、以及爽约率下降；被低估的成本在设备、平台许可、双向转诊与“隐形额外就诊”（视频之后仍需的化验与住院）。结局指标要按疾病选：肾功能的斜率、血压控制、高钾与酸中毒的急诊处理、药物调整时滞、以及是否漏掉了必须面诊的发现（体重、水肿、足部、注射部位）。不平等是核心变量而非附属：老年、听力障碍、低数字素养、语言与网络质量——远程医疗可以同时改善可及性与扩大差距，所以要按剥夺指数、年龄与语言分层报告（“数字排斥”的测量与替代路径：电话、社区场所协助、上门）。设计：前后对照加同期未转换队列、预注册的主要终点（住院与非计划就诊）、以及质性的“是否感觉被照顾”；再加治理条款：病历双向记录、跨辖区执业与处方规则、以及数据与平台退出的连续性——[[clinical-skills/medical-imaging]]、[[clinical-skills/records-handover]]、[[geriatrics-palliative/ageing-frailty]]。**

::: exercise 写出疫情的经济学判决 {level=3}
你被要求为新冠疫情写一份卫生经济学评估的结论章。请用六段说明哪些经济学判断被证实、哪些被推翻、以及留下什么改革清单。
::: solution
**疫情的经济学判决（[[#def-financing]]、[[#def-toolkit]]、[[public-health/global-health]]）：被证实——机会成本是真的（取消的筛查、推迟的诊断与被隔离的关系；以及超额死亡的分解：直接死于病毒者、死于延误者、以及死于恐惧与孤立者）；供应链脆弱性是一种隐性债务，最便宜的时候没人愿意为冗余付费；以及可避免伤害的成本高到使防护用品、通风与检验能力的投入成为划算的投资。被推翻——“以卫生支出衡量绩效”的幻觉：支出高而协调差的体系表现并不更好；以及模型内把生命当作可折现流量的做法在公共辩护中不可用——伦理约束不是参数的调整。被暴露——不平等的经济（封闭措施的不对称成本、死亡风险的的职业梯度、以及弱势社区中疫情后教育、就业与精神健康的疤痕效应）；以及卫生与其他部门的财政边界模糊（疫苗研发、企业担保、与“同一健康”的源头管理，都说明公共卫生支出不是孤立账目）——[[public-health/determinants-inequalities]]、[[public-health/communicable-disease-control]]、[[infectious-diseases/hiv]]。改革清单（按经济学排序）：把冗余写进采购（床位、防护用品、检验产能的常备与合同）；把突发事件筹资与常规卫生系统强化资金合流（避免“垂直项目”掏空基层）；给“看不见的伤害”设指标并每年报告（推迟治疗、疫苗漏种、心理健康）；数据与评估能力的常备（真实世界数据的治理与人员）；以及透明配给的社会契约（事先公布原则、并说明挤掉了什么）。最后一句留给政治家：疫情不是“没人能预见的意外”，而是“保险未被购买的已知风险”——下一次预算周期的任务，就是把保险买下来——[[public-health/environmental-occupational]]、[[medical-ethics-law/justice-resources]]。**
