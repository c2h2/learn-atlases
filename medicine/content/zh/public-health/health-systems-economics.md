每个卫生系统的资金、人员和时间都少于它所能使用的。一个疗程8万英镑的新抗癌药、增加一支社区护理团队、一项戒烟服务以及缩短髋关节置换的等候名单，都在争夺同一笔预算。当NHS为其中一项付费时，这笔钱就不能用于其他项目。卫生经济学研究这类选择是如何作出的，以及如何能作得更好；卫生系统研究则研究医疗服务如何筹资、组织和提供，以及效果如何。

本章介绍卫生经济学的基本概念（稀缺性、机会成本，以及为什么医疗市场不像其他市场那样运作）、经济学评价的方法（成本-效果分析、质量调整生命年和增量成本-效果比）、NICE如何使用这些方法，以及卫生系统如何筹资和组织，并以NHS作为主要例子。这些概念对临床医生很重要，因为花费医疗资源的大多数决定是由他们作出的。

## 稀缺性与机会成本 {#scarcity}

::: definition 机会成本与效率 {#def-opportunity}
- **稀缺性**：资源（资金、人员、床位、时间）相对于其所能满足的需要和需求是有限的，因此必须作出选择。
- 以某种方式使用一项资源的**机会成本**，是该资源在其最佳替代用途中本可获得的收益。在预算固定的卫生系统中，资助一项新治疗的机会成本，是那些为了给它腾出资金而被挤占照护的患者所损失的健康。
- **技术效率**是指用最少的资源产出给定的产出（例如，在结局相同时以日间手术代替住院手术）。
- **配置效率**是指在不同活动之间分配资源，以产生最大的总收益（例如，决定预防与治疗各花多少钱）。
- **公平**关注资源和健康分布的公正性。**横向公平**是指同等需要得到同等对待；**纵向公平**是指不同需要得到相应的不同对待。
:::

机会成本很容易被遗忘，因为受损失的人通常是看不见的：作出资助一种新药的决定时，他们不在场，他们也不知道一项他们本可能使用的服务从未提供过。新治疗的收益集中在可识别的患者身上；其成本则分散在许多无法识别的人身上。经济学评价试图让双方都变得可见。

### 为什么医疗卫生与众不同 {#market-failure}

1963年，经济学家阿罗（Kenneth Arrow）解释了为什么医疗市场的表现不同于普通商品的市场。有几个特征导致**市场失灵**，即不受监管的市场会产生低效或不公平的结果：

- **不确定性。** 疾病不可预测，而且可能非常昂贵，因此人们想要保险；但保险市场有其自身的问题。
- **信息不对称。** 医生比患者更清楚需要什么照护。患者依赖医生作为其代理人，当提供者按服务项目付费时，就产生了**供方诱导需求**的风险。
- **道德风险。** 有保险的人可能比在就医时自付全价的情况下使用更多的照护。
- **逆向选择。** 如果保险公司无法分辨谁是高风险者，购买保险的将是那些预计会用到保险的人，保费会上涨，低风险者会退出。保险公司的应对办法是**风险选择**（“撇脂”）：回避有既往疾病的人。
- **外部性。** 有些照护会使他人受益：给一个人接种疫苗能保护其周围的人；治疗结核病能防止传播。
- **公平。** 许多人认为，获得医疗服务应取决于需要，而不是支付能力。

这些失灵解释了为什么每个高收入国家都对医疗卫生进行大量干预：通过公共筹资、强制保险、对保险公司和专业人员的监管以及公共提供。

## 经济学评价 {#evaluation}

经济学评价从成本和结果两方面比较两个或多个备选方案。主要类型的区别在于如何测量结果：

| 类型 | 结果的测量方式 | 示例问题 |
|---|---|---|
| 最小成本分析 | 假定结果相同；只比较成本 | 在效果相同的情况下，仿制药是否比原研药便宜？ |
| 成本-效果分析 | 自然单位（检出病例数、获得的生命年） | 两种筛查策略每检出一例癌症的成本是多少？ |
| 成本-效用分析 | 质量调整生命年（QALY） | 与现有治疗相比，一种治疗多发性硬化的新药每获得一个QALY的成本是多少？ |
| 成本-效益分析 | 货币 | 一项道路安全计划的货币收益是否超过其成本？ |

NICE使用的是成本-效用分析，因为QALY可以在医疗卫生中差异极大的领域之间进行比较。

::: definition QALY与ICER {#def-qaly}
**质量调整生命年**（QALY）把生命的长度和质量结合起来。每段生命都用一个**效用值**（健康状态值）加权，效用值的标度中1代表完全健康，0代表死亡（也可能出现负值，代表被认为比死亡更差的状态）。一个QALY是完全健康地生活一年；以0.5的效用值生活两年也是一个QALY。

在英国，效用值通常通过让患者填写**EQ-5D**问卷（行动能力、自我照顾、日常活动、疼痛或不适、焦虑或抑郁）获得，并利用从普通公众中获取的偏好把他们的回答换算成一个数值。

一项新干预与其对照相比的**增量成本-效果比**（ICER）为

$$
\text{ICER} = \frac{C_{\text{new}} - C_{\text{old}}}{E_{\text{new}} - E_{\text{old}}} = \frac{\Delta C}{\Delta E},
$$ {#eq-icer}

即每多获得一个QALY所需的额外成本。对照应是当前最佳的替代方案，而不是什么都不做，除非什么都不做就是当前的做法。

在阈值$\lambda$（赋予一个QALY的价值）下的**净货币效益**为$\text{NMB} = \lambda\,\Delta E - \Delta C$。如果一项干预的NMB为正，它在该阈值下就是具有成本效果的；当$\Delta E > 0$时，这等同于ICER低于$\lambda$。
:::

::: example 一种新药的ICER {#ex-icer}
一种治疗慢性炎症性疾病的新药每年比现有治疗多花3,000英镑（已计入因住院减少而节省的费用）。无论是否用药，患者都能存活约10年，但该药能把他们的效用值从0.60提高到0.75。计算ICER：(a) 不贴现；(b) 成本和QALY都以每年3.5%贴现，第一年的成本和QALY不贴现。
::: solution
(a) 每年：$\Delta C = £3{,}000$，$\Delta E = 0.15$ QALY。10年中，$\Delta C = £30{,}000$，$\Delta E = 1.5$ QALY。ICER$= 30{,}000/1.5 = £20{,}000$/QALY。

(b) 第$t$年（第一年$t = 0$）的贴现因子为$1/1.035^{t}$。对$t = 0, \ldots, 9$求和得8.608。贴现后$\Delta C = 3{,}000 \times 8.608 = £25{,}823$；贴现后$\Delta E = 0.15 \times 8.608 = 1.291$ QALY。ICER$= 25{,}823/1.291 = £20{,}000$/QALY。

由于成本和收益在相同的年份中均匀发生，并以相同的贴现率贴现，所以这里贴现不改变ICER。当成本和收益发生在不同时间时，贴现会改变ICER。对于预防，成本发生在现在，收益在多年以后，因此贴现会使预防显得成本效果较差。
:::
:::

**贴现。** 人们和社会一般更偏好现在的收益而非以后的收益，而且现在花掉的钱本可用于投资。因此，经济学评价把未来的成本和结果换算为**现值**：在贴现率$r$下，$t$年后发生的成本或结果$X$相当于现在的$X/(1 + r)^{t}$。NICE在其参考案例中对成本和健康效果都使用每年3.5%的贴现率，在某些收益持久的情况下考虑使用1.5%。

::: widget plot
f: 100*(1 + r)^(-x)
x: 0, 50
y: 0, 100
sliders: r=0.035:0:0.1:0.005
labels: \text{100（QALY或英镑）的现值}
caption: 在贴现率r下，x年后发生的100个单位的成本或健康的现值。按NICE 3.5%的标准贴现率，20年后获得的100个QALY现在约值50个，50年后约值18个。拖动滑块，看看贴现率的选择对儿童疫苗接种或预防吸烟等干预（其收益在几十年后才出现）的影响有多大。
:::

### 成本-效果平面与优势 {#plane}

结果常显示在**成本-效果平面**上，横轴是效果的差异，纵轴是成本的差异。比对照更便宜且更有效的干预（右下象限）**占优**于对照，应予采用。成本更高且效果更差的干预（左上象限）是**劣势**的，应予拒绝。在另外两个象限（更有效但更贵，或效果更差但更便宜）需要借助ICER和阈值作出判断。

比较多个方案时，按效果排序，去掉劣势方案，然后计算每个方案与剩余方案中效果次低者相比的ICER。

::: example 在多种策略中选择 {#ex-dominance}
一个卫生委员会正在选择预防某种并发症的策略。与不实施项目（A）相比，每名患者的贴现成本和QALY如下：B花费4,000英镑，获得0.10 QALY；C花费8,000英镑，获得0.25 QALY；D花费20,000英镑，获得0.30 QALY；E花费10,000英镑，获得0.20 QALY。在每QALY 35,000英镑的阈值下应选择哪种策略？
::: solution
**严格劣势。** E比C花费更多而获得的QALY更少，因此E是劣势的，予以去除。

**扩展劣势。** 与A相比，B的ICER为$4{,}000/0.10 = £40{,}000$/QALY，而C的ICER为$8{,}000/0.25 = £32{,}000$。B的效果不如C，ICER却更高，因此A和C的组合能以更低的成本达到B的效果；B是**扩展劣势**的，予以去除。

**剩余方案。** A、C、D。C对A的ICER$= £32{,}000$/QALY。D对C的ICER$= (20{,}000 - 8{,}000)/(0.30 - 0.25) = £240{,}000$/QALY。

在每QALY 35,000英镑时，C与A相比具有成本效果，而D与C相比没有。选择**C**。直接把D与A比较（ICER为£66,667）会掩盖这样一个事实：与C相比，D的大部分额外成本只换来了很少的额外健康。
:::
:::

### NICE与阈值 {#nice}

**国家卫生与保健卓越研究院**（NICE）成立于1999年，为英格兰NHS评估新药和其他技术（威尔士和北爱尔兰一般遵循其技术评估；苏格兰有苏格兰药品联合会）。当NICE在技术评估中推荐一种药物时，英格兰的NHS购买方必须为其提供资金，通常在90天内。

NICE的参考案例使用以EQ-5D测量的QALY、从NHS和个人社会服务角度计算的成本，以及3.5%的贴现率。多年来，它认为ICER低于**每QALY 20,000英镑**的干预通常具有成本效果，20,000至30,000英镑之间的干预在有其他考虑因素时可以接受。根据政府2025年的决定，自2026年4月起的评估中，这一范围提高到**每QALY 25,000至35,000英镑**。还有特殊安排：针对极罕见疾病的高度专科化技术按高得多的阈值评估；自2022年起，**严重程度修正因子**对那些会使患者损失其预期剩余健康生命中很大比例的疾病的治疗给予额外权重（QALY收益乘以1.2或1.7）。许多药物只有在公司同意保密折扣（“患者可及计划”）后才获推荐，有些则通过**癌症药物基金**或管理式准入在收集更多证据期间提供。**品牌药品定价、可及和增长自愿计划**（VPAG）为NHS在品牌药品上的支出增长设定上限，超出上限的销售额由公司按一定比例返还。

::: theorem 阈值的机会成本论证 {#thm-threshold}
在预算固定的情况下，采用一项比现有照护花费更多的新干预，只有当它获得的健康大于为其腾出资金而被挤占的服务所损失的健康时，才能改善人群的总体健康。如果被挤占的服务在边际上以每QALY $k$英镑的成本产生健康，那么ICER高于$k$的新干预会减少总体健康，尽管它使其自身的患者受益。因此，成本-效果阈值应反映卫生系统的边际生产率。
:::

::: proof
假设新干预增加成本$\Delta C$，获得$\Delta E$个QALY。在固定预算下，$\Delta C$必须通过削减或不扩大其他服务来筹集，而这些服务在边际上每$k$英镑产生一个QALY；损失的健康为$\Delta C/k$。对人群健康的净效应为$\Delta E - \Delta C/k$，只有当$\Delta C/\Delta E < k$，即ICER $< k$时才为正。克拉克斯顿（Claxton）及其同事（2015年）估计，英格兰NHS支出的边际生产率约为每QALY 13,000英镑，低于NICE阈值；如果这一估计正确，以介于13,000英镑和阈值之间的ICER获批的干预所挤占的健康比它创造的更多。这一估计存在争议，而政策设定的阈值还反映了其他目标，例如支持生命科学产业。
:::

::: example 预算影响与被挤占的健康 {#ex-budget}
一种新治疗以每QALY 30,000英镑的ICER获得推荐。它每年将使NHS多花1,000万英镑，每年获得333个QALY。如果被挤占的NHS服务在边际上每13,000英镑产生一个QALY，对人群健康的净效应是什么？
::: solution
被挤占的服务损失的健康$= 10{,}000{,}000/13{,}000 \approx 769$ QALY/年。

净效应$= 333 - 769 = -436$ QALY/年。

按政策阈值，这种治疗“具有成本效果”，但在这些假设下它减少了人群的总体健康。受损失的是照护被推迟或未获提供的患者，他们往往处在政治关注度较低的服务中，如精神卫生或社区照护。这个例子说明了阈值为什么重要，以及为什么一些经济学家认为它应该更低；另一些人则认为边际生产率的估计太不确定，或者NHS的预算并非真正固定。与成本-效果分开的预算影响分析，则告诉购买方这项服务在短期内是否负担得起。
:::
:::

**对QALY的批评。** 无论谁获得QALY，其价值都相同，有些人认为这是公平的，另一些人则认为这忽视了人们关心的因素，如严重程度、罕见性、生命末期以及一个人是否有需要抚养的人。QALY可能低估了对残疾人或长期病患者的治疗价值，因为他们的生活质量无法升到1，还可能遗漏健康以外的收益，如对照护者的收益。EQ-5D在某些疾病中不够敏感，例如在精神卫生和听力损失中。已有人提出**ICECAP**能力量表和**幸福调整生命年**等指标作为替代或补充。

## 卫生系统与筹资 {#systems}

::: definition 卫生系统 {#def-health-system}
世卫组织把**卫生系统**定义为以促进、恢复或维护健康为主要目的的所有组织、人员和行动。其框架描述了六个**基本组成部分**：服务提供；卫生人力；卫生信息系统；基本药物、疫苗和技术的可及；筹资；以及领导和治理。卫生系统的目标是改善健康（水平和公平性）、**反应性**（有尊严地对待人们并满足其非健康方面的期望）、**经济风险保护**（筹资的公平性）以及效率。

**卫生筹资**有三项职能：**筹集收入**（筹钱）、**统筹**（在全人群中分担经济风险，使健康者补贴患病者）以及**购买**（向提供者支付服务费用）。
:::

各国主要以四种方式为医疗卫生筹资，大多数国家混合使用：

- **一般税收**（“贝弗里奇”模式）：英国的NHS，以及斯堪的纳维亚、西班牙和意大利的体系。覆盖是普遍的，以居住为基础；服务在使用时基本免费；政府控制总预算。
- **社会医疗保险**（“俾斯麦”模式）：德国、法国、荷兰和日本。雇主和雇员的强制性缴费进入保险基金（疾病基金），国家为无工作者缴费。提供者通常是公立、非营利和私立机构的混合。
- **私人医疗保险**：自愿缴纳保费，常通过雇主，美国的大部分劳动年龄人口即如此。没有监管时，它倾向于排斥高风险者；在大多数国家，它是对公共覆盖的补充。
- **自付费用**：患者直接向提供者付费。这是最不公平的筹资形式，阻碍人们使用必要的照护并造成灾难性支出；在许多低收入国家，它占卫生支出的很大一部分（[[public-health/global-health]]）。

**向提供者付费。** 向提供者付费的方式会影响他们的行为。**按服务项目付费**鼓励更多的活动（以及供方诱导需求）；**工资制**不奖励生产率；**按人头付费**（每个登记者一个固定金额，如英国的全科医疗）鼓励效率和预防，但有提供不足和回避复杂患者的风险；**按病例付费**（每个诊疗事件一个固定价格，如诊断相关分组以及NHS以前的“按结果付费”）奖励每个病例的效率，但可能鼓励提前出院和更多的入院。**按绩效付费**计划奖励被测量的质量：2004年为英国全科医疗引入的**质量与结果框架**（QOF）改善了记录和一些过程指标，但其对死亡率影响的证据很弱，而且未被测量的照护方面可能受损。

### NHS {#nhs}

NHS于1948年7月5日成立，其原则是：满足每个人的需要，在提供服务时免费，以临床需要而非支付能力为基础。卫生政策是下放的：NHS英格兰、NHS苏格兰、NHS威尔士和北爱尔兰卫生与社会照护的组织方式各不相同。北爱尔兰自1973年起就实行卫生与社会照护一体化；苏格兰和威尔士废除了内部市场，通过卫生委员会组织照护。

在英格兰，**《2022年卫生与照护法》**自2022年7月起建立了42个**整合照护系统**（ICS），每个系统设有一个**整合照护委员会**（ICB），负责为其人群规划和购买大部分NHS服务，并与地方政府组成整合照护伙伴关系。该法摆脱了《2012年卫生与社会照护法》以竞争为基础的做法。2025年3月，政府宣布将撤销NHS英格兰，把其职能并入卫生与社会照护部，并要求ICB大幅削减运行成本。2025年7月发布的英格兰**十年卫生计划**提出了三个“转变”：从医院转向社区，从模拟转向数字，从疾病转向预防。

成人**社会照护**由地方政府单独出资和组织，且须经经济状况审查；资产超过某一门槛的人要自付照护费用。免费的NHS照护与经济状况审查的社会照护之间的界限，以及社会照护人员和资金的短缺，是延迟出院和获得照护不平等的主要原因。

::: example 一个卫生系统的选择 {#ex-financing}
一个非正规就业部门规模很大的中等收入国家希望向全民健康覆盖迈进。一位顾问建议建立以工资缴费为资金来源的社会医疗保险计划；另一位建议扩大由税收资助的初级卫生保健。比较这两种方案。
::: solution
**以工资缴费为资金来源的社会医疗保险**在大多数人是正规就业的地方运作良好。在大部分劳动力是非正规就业（农民、商贩、家政工人）的地方，缴费难以征收，因此该计划起初主要覆盖较富裕的正规就业者和公务员。要覆盖其他人，就需要来自税收的政府补贴，因此这一体系最终无论如何都会部分依赖税收。多个基金会使风险池碎片化，除非将其合并或进行风险平衡。

**税收资助的服务**可以从一开始就以居住为基础覆盖所有人，并在全人群中统筹风险。其制约因素是国家的征税能力以及对卫生的政治重视程度。先扩大初级卫生保健能惠及最贫困的人，并高效地应对常见病。

**在实践中**，进展迅速的国家（例如2002年泰国的全民覆盖计划）利用一般财政收入覆盖非正规部门，取消或减少使用者付费，利用成本-效果证据确定福利包，并以按人头付费的方式为初级卫生保健付费。无论选择哪种模式，经济风险保护都需要限制自付费用，并应按收入组别监测覆盖情况。
:::
:::

::: warning 具有成本效果不等于便宜或负担得起
“具有成本效果”是指在给定阈值下，与备选方案相比，一项干预就其产生的健康而言物有所值。一项具有成本效果的干预仍可能增加支出（大多数都会），而一项便宜的干预如果作用不大，也可能并不划算。如果一项干预要提供给非常多的人，它也可能具有成本效果但在短期内负担不起：这就是为什么预算影响也很重要。反过来，“省钱”很少是检验预防措施的正确标准：大多数预防性干预是以可接受的成本改善健康，而不是省钱，也很少有治疗被期望收回其成本。
:::

::: quiz
与现有治疗相比，一种新药每名患者获得0.5个QALY，每名患者多花20,000英镑。下列哪一项是正确的？
- [ ] 该药占优于现有治疗。
- [x] ICER为每QALY 40,000英镑，高于NICE自2026年4月起的常规阈值范围。
- [ ] ICER为每QALY 10,000英镑。
- [ ] 该药应被拒绝，因为它增加了成本。
::: solution
ICER$= 20{,}000/0.5 = £40{,}000$/QALY，高于£25,000–£35,000。除非适用严重程度修正因子、特殊考虑或价格折扣，NICE不太可能以这一价格推荐它。它并不占优，因为它花费更多。仅仅增加成本并不是拒绝一项干预的理由：几乎所有新治疗都花费更多；问题在于额外的健康是否值得额外的成本。
:::
:::

::: history
贝弗里奇（William Beveridge）的报告《社会保险及相关服务》（1942年）把疾病列为五大“巨恶”之一，并以建立全面的卫生服务为前提。贝文（Aneurin Bevan）作为卫生大臣于1948年7月5日推出了NHS；更早的时候，俾斯麦（Otto von Bismarck）于1883年为德国工人引入了强制性疾病保险。阿罗1963年的论文《不确定性与医疗保健的福利经济学》奠定了卫生经济学作为一个领域的基础。1971年，图德·哈特（Julian Tudor Hart）描述了“逆向照护定律”：良好医疗照护的可得性往往与所服务人群对它的需要成反比。威廉斯（Alan Williams）1985年对冠状动脉旁路移植术每QALY成本的分析，帮助QALY在英国政策中确立了地位。NICE成立于1999年，其阈值范围在21世纪初首次被明确表述。《2012年卫生与社会照护法》加强了竞争的作用；《2022年卫生与照护法》在很大程度上扭转了这一点，转而支持整合。
:::

## 后续内容

筛查和预防项目的经济学评价使用本章的方法；见[[public-health/screening]]和[[public-health/prevention-promotion]]。全球筹资和全民健康覆盖在[[public-health/global-health]]中讨论。经济学评价所依赖的有效性证据，来自[[epidemiology-ebm/critical-appraisal]]中的方法。

::: summary
- **机会成本**：在固定预算中，资助一项服务意味着失去次优用途的健康收益。效率可以是技术效率或配置效率；公平可以是横向公平或纵向公平。
- 由于**不确定性、信息不对称、道德风险、逆向选择和外部性**，医疗市场会失灵，因此政府会进行干预。
- 经济学评价的类型：最小成本分析、成本-效果分析、**成本-效用分析**（QALY；NICE使用）和成本-效益分析。
- **QALY** = 年数 × 效用值；**ICER** = ΔC/ΔE；**NMB** = λΔE − ΔC。在计算ICER之前，先去除劣势和扩展劣势的方案。成本和QALY以每年3.5%**贴现**。
- 自2026年4月起，NICE的阈值范围为**每QALY 25,000～35,000英镑**（此前为20,000～30,000英镑），对极罕见疾病另有安排，并设有严重程度修正因子。阈值应反映在其他地方被挤占的健康；对NHS边际生产率的一项估计约为每QALY 13,000英镑。
- 筹资：一般税收（贝弗里奇）、社会保险（俾斯麦）、私人保险和自付费用；筹资职能为筹集收入、统筹和购买。向提供者付费的方式会产生激励。
- 在英格兰，2022年建立了42个**整合照护系统**；NHS英格兰正在并入卫生与社会照护部；十年卫生计划（2025年）寻求向社区、数字和预防的转变。
:::

## 习题

::: exercise 计算ICER {level=1 check="30000"}
一项新干预每名患者比现有照护多花12,000英镑，每名患者获得0.4个QALY。计算以英镑/QALY表示的ICER。
::: solution
ICER$= 12{,}000/0.4 = £30{,}000$/QALY，处于NICE自2026年4月起£25,000–£35,000的范围之内。
:::
:::

::: exercise 计算QALY {level=1 check="3.5"}
一名患者以0.7的效用值生活5年。这相当于多少个未贴现的QALY？
::: solution
$5 \times 0.7 = 3.5$个QALY。
:::
:::

::: exercise 现值 {level=1 check="round(1000/1.035^5)"}
在每年3.5%的贴现率下，5年后发生的1,000英镑成本的现值是多少？给出以英镑计的整数。
::: solution
$1{,}000/1.035^5 = 1{,}000/1.188 = £842$。
:::
:::

::: exercise 净货币效益 {level=2 check="-2500"}
一项干预获得0.5个QALY，比其对照多花15,000英镑。计算其在每QALY 25,000英镑阈值下的净货币效益。
::: solution
NMB$= 25{,}000 \times 0.5 - 15{,}000 = 12{,}500 - 15{,}000 = -£2{,}500$。在这一阈值下它不具有成本效果（其ICER为£30,000）。在£35,000时，NMB将为+£2,500。
:::
:::

::: exercise 贴现后的QALY {level=2 check="round(100*0.8*(1+1/1.035+1/1.035^2))/100"}
一种治疗每年带来0.8个QALY，持续3年。以每年3.5%贴现，第一年不贴现（第$t = 0, 1, 2$年）。贴现后是多少个QALY？保留2位小数。
::: solution
$0.8 \times (1 + 1/1.035 + 1/1.035^2) = 0.8 \times (1 + 0.9662 + 0.9335) = 0.8 \times 2.8997 = 2.32$个QALY。
:::
:::

::: exercise 被挤占的健康 {level=2 check="round(5000000/13000)"}
一个购买方从固定预算中资助一项每年花费500万英镑的新服务。如果被挤占的服务在边际上每13,000英镑产生一个QALY，其他地方每年会损失多少个QALY？给出整数。
::: solution
$5{,}000{,}000/13{,}000 = 385$ QALY/年。只有当新服务获得的QALY多于这一数字时，它才能改善总体健康。
:::
:::

::: exercise 向全科诊所付费 {level=2}
比较按人头付费、按服务项目付费和按绩效付费这几种向全科诊所付费的方式。每种方式产生什么激励？为什么许多体系采用混合方式？
::: solution
**按人头付费**（每个登记患者一笔固定金额，通常按年龄、性别和贫困程度加权）提供了可预测的预算，奖励保持患者健康和高效提供照护，但除非加权反映了需要，否则可能鼓励提供不足、把工作转给别处以及回避复杂患者。

**按服务项目付费**奖励活动，这对提供不足的服务很有用（如疫苗接种，英国诊所按剂次获得报酬），但鼓励过度提供有利可图的项目和供方诱导需求，而且管理成本高。

**按绩效付费**（如QOF）奖励被测量的质量，能提高被测量方面的标准，但会使人们以牺牲未被测量的照护为代价关注被测量的指标，可能奖励本已做得好的诊所，而且如果在贫困地区更难达到目标，还可能加剧不平等；例外报告为钻空子留下了空间。

**混合方式**结合了各自的优点：以按人头付费作为稳定的核心，对特定的提供不足的服务按项目付费，再加上适度的质量支付，同时监测意外影响。
:::
:::

::: exercise 评估一种用于罕见病的昂贵药物 {level=3}
一种用于一种罕见的致命儿童疾病的新基因疗法每名患者花费150万英镑，估计ICER为每QALY 120,000英镑。运用本章的概念，讨论在NHS中资助它的支持和反对理由。
::: solution
**支持。** 这种疾病很严重，患者是几乎没有替代治疗的儿童；严重程度修正因子和高度专科化技术评估程序承认，社会可能会更看重这样的健康收益。受影响的患者很少，因此预算影响很小。资助能鼓励对罕见病的研究，否则这些研究在商业上缺乏吸引力。可以通过有数据收集的管理式准入来减少不确定性，并通过保密折扣或基于结果的协议（只有在治疗有效时才付费）来降低价格。

**反对。** 在每QALY 120,000英镑的水平上，这笔钱如果用于现有服务，产生的健康会多出数倍（按每QALY约13,000英镑的边际生产率计算，约为九倍）。受损失的患者虽然不那么显眼，却同样真实。高价可能反映的是市场支配力而非研发成本，接受高价会开创先例。长期有效性往往不确定，因为试验规模小、时间短。

**权衡。** 合理的答案应认识到，这一决定是通过合法、透明的程序作出的价值判断（NICE的高度专科化技术项目使用高得多的阈值，并对非常大的收益给予QALY加权），应争取最低的价格和可靠的数据收集，并公开说明机会成本。
:::
:::
