神经肌肉系统是运动通路的最后一段：前角中的下运动神经元，其轴突穿过神经根、神经丛和周围神经，神经冲动传给肌肉的神经肌肉接头，以及肌肉本身。每个层面的疾病都会产生各自的无力模式、反射改变、感觉缺失和时间进程。识别这种模式是关键技能，因为它告诉你该做哪些检查、该考虑哪些疾病。

本章介绍周围神经病的诊断思路、神经传导检查和肌电图、吉兰–巴雷综合征和慢性炎性脱髓鞘性多发性神经病、重症肌无力和其他接头疾病、肌病，以及遗传性神经肌肉疾病。运动神经元病见[[nervous-system/dementia-neurodegeneration]]，上、下运动神经元查体见[[nervous-system/motor-systems]]。

## 在神经肌肉系统内定位

::: theorem 层面决定模式 {#thm-level}
下运动单位的每个层面都以可识别的方式出现故障。

- **前角细胞**（例如脊髓性肌萎缩症、MND的下运动神经元部分）：无力、肌萎缩和肌束颤动，无感觉缺失。
- **神经根**（神经根病）：沿皮节放射的疼痛，该皮节的感觉缺失，该肌节所支配肌肉的无力，以及该神经根所司反射消失。
- **周围神经**：单根神经（单神经病）引起该神经支配区的无力和感觉缺失；多根神经引起长度依赖性的“手套–袜套”样模式（多发性神经病）或斑片状模式（多发性单神经炎）。反射减弱或消失。
- **神经肌肉接头**：**易疲劳性**无力，活动后加重、休息后好转，常累及眼睑、眼外肌和延髓肌，感觉正常，反射通常正常。
- **肌肉**（肌病）：通常为**对称性近端**无力（从椅子上站起、上楼梯、举臂困难），感觉正常，反射在无力严重之前保留。
:::

时间进程也有帮助。数小时至数天内出现的无力提示吉兰–巴雷综合征、肉毒中毒、周期性瘫痪、肌无力危象或毒物；数周至数月提示炎性神经病或肌病；数年提示遗传性或退行性疾病。家族史、用药史和寻找全身性疾病使诊断更完整。

## 周围神经病

::: definition 周围神经病 {#def-neuropathy}
**周围神经病**是周围神经的疾病。用四个特征来描述：

1. **分布**：单根神经（**单神经病**）、数根分开的神经（**多发性单神经炎**），或对称性的多根神经（**多发性神经病**，通常为长度依赖性，从足部开始）。
2. **纤维类型**：运动、感觉（大纤维：振动觉、关节位置觉、反射；小纤维：痛觉和温度觉）或自主神经，或其组合。
3. **病理**：**轴索性**（轴突变性）或**脱髓鞘性**（髓鞘受损）。
4. **进程**：急性、亚急性或慢性。
:::

最常见的模式是**长度依赖性感觉或感觉运动性轴索性多发性神经病**。最长的神经最先受累，所以症状从足趾和足开始并向小腿上方扩展；当达到约膝部水平时，指尖开始受累（“手套–袜套”模式）。踝反射早期消失。小纤维受累引起烧灼痛和痛觉超敏；大纤维受累引起麻木、平衡障碍和Romberg征阳性。

在英国，最常见的病因是**糖尿病**。其他病因包括酒精、维生素B12缺乏、甲状腺功能减退、慢性肾病、药物（例如化疗中的长春新碱、铂类、紫杉烷类和硼替佐米；未加用吡哆醇的异烟肼；长期使用甲硝唑或呋喃妥因）、副蛋白血症和淀粉样变性、HIV，以及遗传性神经病。许多老年人找不到病因。

慢性多发性神经病的基本检查为HbA1c（或糖耐量）、全血细胞计数、维生素B12和叶酸、肾功能和肝功能、甲状腺功能，以及查副蛋白的**血清蛋白电泳**。当模式不典型（不对称、以运动为主、快速进展或非长度依赖性）或病因不明时，做神经传导检查。

提示可治疗或危险神经病的危险信号有：快速进展、不对称、突出的运动无力、近端和远端均无力，以及全身性表现。**多发性单神经炎**表现为单根神经相继出现的痛性病变（例如先足下垂，后腕下垂），提示**血管炎**，需要紧急检查（见[[musculoskeletal/connective-tissue-vasculitis]]）。

**腓骨肌萎缩症（Charcot–Marie–Tooth病）**是最常见的遗传性神经病（约1/2,500）。它引起缓慢进展的远端无力和肌萎缩、足部畸形（高弓足、锤状趾）、小腿细和反射减弱，常有不知道自己患病的受累亲属。最常见的类型CMT1A是一种脱髓鞘性神经病，由*PMP22*基因重复引起。

神经病理性疼痛用阿米替林、度洛西汀、加巴喷丁或普瑞巴林治疗（NICE CG173），局限性疼痛可用辣椒素乳膏。足部护理至关重要：糖尿病神经病患者至少每年用10 g单丝检查足部，因为未察觉的损伤会导致溃疡和截肢。

### 卡压性神经病

**腕管综合征**是腕部正中神经受压，是最常见的卡压。它引起拇指、示指、中指和半个环指的麻木和刺痛，典型地在夜间把人痛醒，甩手可缓解。后期出现鱼际肌萎缩和拇外展无力。相关因素包括妊娠、甲状腺功能减退、糖尿病、类风湿关节炎、肢端肥大症和腕部重复动作。治疗为夜间腕部支具、糖皮质激素注射，症状持续或严重时手术减压。**尺神经**常在肘部受压（小指麻木和手部小肌肉萎缩），**腓总神经**常在腓骨头处受压（足下垂；见[[nervous-system/motor-systems]]）。

### 神经传导检查和肌电图

**神经传导检查**用电刺激神经，从肌肉（运动）或神经本身（感觉）记录反应。它测量反应的**波幅**，反映传导轴突的数量；以及**传导速度**和**潜伏期**，反映髓鞘情况。

- **轴索性**神经病：波幅降低，速度正常或仅轻度减慢。
- **脱髓鞘性**神经病：速度明显减慢，远端潜伏期和F波延长，获得性者还有**传导阻滞**（两个刺激点之间反应急剧下降）和时间离散。

**肌电图（EMG）**通过针电极记录肌肉的电活动。在**神经源性**疾病中，失神经的肌纤维自发放电（纤颤电位和正锐波），存活的运动单位通过再支配失去神经的纤维而增大，产生宽大、时限长的运动单位电位。在**肌源性**疾病中，运动单位丢失纤维，产生小的、短时限的多相电位，并早期募集。**重复神经刺激**和**单纤维肌电图**检测神经肌肉接头。

::: example 建筑工人麻木的手 {#ex-carpal}
一位54岁建筑工人右手拇指、示指和中指麻木刺痛六个月。夜里会把他弄醒，他要甩手才能缓解。最近他总是拿不住螺丝。他患有2型糖尿病。鱼际肌轻度萎缩，拇外展无力；外侧三个半手指感觉减退，但鱼际表面的感觉正常。腕部Tinel征阳性。
::: solution
1. **定位。** 手指正中神经分布区的感觉缺失，伴正中神经支配的鱼际肌（拇短展肌）无力和萎缩，指向正中神经。鱼际表面感觉保留很重要：该处皮肤由掌皮支支配，它在腕部以上离开正中神经，不经过腕管。所以病变在**腕部**：腕管综合征。
2. **鉴别。** C6或C7神经根病（颈痛、反射改变、正中神经支配区以外的无力），或糖尿病多发性神经病（双侧，从足开始）。
3. **检查。** 神经传导检查可确诊并判断严重程度，在手术前以及糖尿病可能导致合并神经病时尤其有用。若近期未查，检查甲状腺功能。
4. **处理原则。** 因为已有肌萎缩和无力（轴索丢失），单用支具不太可能足够：应转诊手术减压。优化糖尿病控制。讨论工作上的调整，因为振动工具会加重症状。
:::
:::

## 吉兰–巴雷综合征

::: definition 吉兰–巴雷综合征 {#def-gbs}
**吉兰–巴雷综合征（GBS）**是一种急性免疫介导的多发性神经根神经病。它引起快速进展、通常**对称**的肢体无力，伴**反射减弱或消失**，在**四周**内（通常两周内）达到最重（最低点）。感觉症状（手足刺痛）常见，但感觉体征往往轻微。背痛或肢体痛常见，可能很严重。面部和延髓肌无力、**呼吸肌无力**和**自主神经功能障碍**（心律失常、血压波动、肠梗阻）是主要的生命威胁。
:::

GBS每年约每10万人中有1–2人发病。约三分之二的人在前几周有感染，最常见的是*空肠弯曲菌*胃肠炎、巨细胞病毒、EB病毒、*肺炎支原体*，或在暴发时的寨卡病毒。针对感染产生的抗体与神经上的神经节苷脂发生交叉反应（**分子模拟**）。

有几种亚型。**急性炎性脱髓鞘性多发性神经根神经病**在欧洲和北美最常见。**急性运动轴索性神经病**在东亚以及中美洲和南美洲更常见，与*弯曲菌*和抗GM1抗体相关。**Miller Fisher综合征**为眼肌麻痹、共济失调和反射消失三者并存，伴抗GQ1b抗体。

诊断是临床诊断，由显示**蛋白–细胞分离**（蛋白升高而细胞数正常；第一周蛋白可能正常）的**脑脊液**和神经传导检查支持。脑脊液白细胞超过50/µL时应重新考虑诊断（例如HIV、莱姆病、淋巴瘤、脊髓灰质炎样疾病）。当有感觉平面或早期括约肌障碍时，必须排除脊髓压迫或横贯性脊髓炎。

::: proof 为什么用数字而不是血氧饱和度来监测呼吸
在GBS和重症肌无力中，肺是健康的；问题在于泵无力。随着膈肌和肋间肌变弱，潮气量下降，患者呼吸变快变浅。血氧饱和度直到晚期才下降，因为肺泡仍能良好地交换气体，而吸氧会掩盖不足。二氧化碳只有在通气已经衰竭时才升高。等到血氧饱和度下降或血气显示高碳酸血症时，患者可能已接近呼吸骤停。**用力肺活量（FVC）**每天在床旁用肺量计测量数次，下降得更早、更平稳。实践中使用的参考点是“20–30–40规则”：当肺活量低于**20 mL/kg**、最大吸气压弱于**30 cmH₂O**或最大呼气压低于**40 cmH₂O**，或这些指标迅速下降时，考虑气管插管。不能一口气数到20、咳嗽无力、使用辅助呼吸肌、腹部矛盾运动以及吞咽分泌物困难都是警示征象。面肌无力会使肺量测定不可靠，因此要使用紧贴的面罩。
:::

治疗用**静脉免疫球蛋白**（IVIG，通常五天）或**血浆置换**，两者同样有效，对不能独立行走者在起病两周内（血浆置换可至四周）开始可加快恢复。糖皮质激素无效。支持治疗同样重要：血栓预防、镇痛、心律和血压监测、肠道和膀胱护理、压疮护理、物理治疗和心理支持。**Erasmus GBS呼吸功能不全评分（EGRIS）**根据起病速度、面部或延髓肌无力和肢体肌力，估计第一周内需要通气的风险。约五分之一到四分之一的人需要机械通气。大多数人在数月内恢复：约80%在六个月时能独立行走，但3%–7%死亡，部分人遗留持久的无力或疲劳。

::: example 先是脚麻，然后面部无力 {#ex-gbs}
一位32岁男性三周前腹泻。五天前双足开始刺痛，此后双腿变得无力；今天他上不了楼梯，闭眼也有困难。他有严重的下背痛。双下肢近端和远端肌力3/5，双上肢4/5；所有反射消失；跖反射屈性；无感觉平面。体重75 kg。他的FVC为1.8 L，昨天为2.6 L。脉搏110次/分，血压165/100 mmHg。
::: solution
1. **识别。** 腹泻（可能是*弯曲菌*）后出现快速进展的对称性无力、反射消失、双侧面肌无力和背痛：**吉兰–巴雷综合征**。
2. **呼吸风险。** 他的肺活量为$1.8 / 75 \times 1000 = 24$ mL/kg，接近20 mL/kg阈值且下降很快（昨天约35 mL/kg）。伴面肌无力且起病快，他的EGRIS评分很高。他需要**重症监护紧急会诊**，入住有监护的床位，每隔几小时测一次FVC。
3. **自主神经功能障碍。** 心动过速和高血压提示自主神经受累。他需要心电监护；血压波动要谨慎处理，因为治疗可能引起突然低血压。
4. **检查。** 神经传导检查；腰椎穿刺（蛋白可能仍正常）；包括电解质在内的血液检查；粪便培养查*弯曲菌*。表现不典型时做脊髓MRI。
5. **治疗。** 现在就开始**IVIG**（按当地方案根据体重给药），因为他不能独立行走且在起病两周内。血栓预防，针对神经病理性疼痛和背痛的镇痛，因闭眼不全而进行眼部护理，吞咽评估，并向他和家人解释病情。
:::
:::

**慢性炎性脱髓鞘性多发性神经根神经病（CIDP）**是GBS的慢性亲属。无力和感觉缺失在**超过八周**的时间里进展或复发，近端和远端均无力，反射广泛消失。神经传导检查显示脱髓鞘。它对IVIG、糖皮质激素或血浆置换有反应（EAN/PNS指南，2021年）。它很重要，因为它可以治疗，有时会被误标为糖尿病神经病。有一个亚组带有针对郎飞结蛋白（神经束蛋白-155、接触蛋白-1）的抗体，现称为**自身免疫性郎飞结病**，对IVIG反应差，但对利妥昔单抗反应好。

## 神经肌肉接头

::: definition 重症肌无力 {#def-mg}
**重症肌无力**是一种自身免疫病，针对突触后**乙酰胆碱受体（AChR）**的抗体，或较少见的针对**肌肉特异性激酶（MuSK）**或LRP4的抗体，减少了神经肌肉接头处有功能的受体数量。其标志是**易疲劳性无力**：反复或持续使用时加重、休息后好转的无力。局限于眼睑和眼外肌（上睑下垂和复视）时为**眼肌型**，累及延髓肌、肢体肌或呼吸肌时为**全身型**。
:::

重症肌无力有两个发病高峰：二三十岁的女性，以及60岁以上的男性和女性（现在是较大的群体）。全身型患者约85%有AChR抗体，但单纯眼肌型只有约一半。约10%–15%有**胸腺瘤**，许多较年轻的AChR阳性患者有胸腺增生。

正常接头有很大的**安全系数**：每次神经冲动释放的乙酰胆碱多于触发肌肉动作电位所需的量。反复放电时，每次冲动释放的量下降。正常情况下这无关紧要，但当受体丢失时，越来越多纤维的终板电位降到阈值以下，因此肌肉随使用而变弱。

诊断依靠临床表现和**抗体检测**。神经电生理显示3 Hz重复神经刺激时复合肌肉动作电位**递减**超过10%，单纤维肌电图（最灵敏的检查）显示**颤抖**增加。**冰袋试验**（在下垂的眼睑上敷冰两分钟可改善上睑下垂）是有用的床旁线索。胸部CT寻找胸腺瘤，并检查甲状腺功能，因为常合并自身免疫性甲状腺病。

治疗分几个层次。

- **对症**：**溴吡斯的明**，一种乙酰胆碱酯酶抑制剂，可增加接头处的乙酰胆碱。不良反应为毒蕈碱样：腹泻、腹痛、出汗和流涎。
- **免疫抑制**：**泼尼松龙**，从小剂量开始逐渐加量（大剂量起始可引起早期加重），然后加用硫唑嘌呤或吗替麦考酚酯等激素节制药物。利妥昔单抗对MuSK阳性者尤其有效。
- **胸腺切除术**：用于胸腺瘤，以及较年轻成人的AChR阳性全身型重症肌无力，一项随机试验（MGTX，2016年）显示其结局更好、激素需求更低。
- 针对难治性全身型疾病的**新型靶向治疗**：补体抑制剂（依库珠单抗、雷夫利珠单抗、齐鲁考普兰）以及阻断新生儿Fc受体从而降低IgG水平的药物（艾加莫德、罗泽利昔珠单抗）。它们在NHS中的可及性取决于NICE评估；NICE推荐罗泽利昔珠单抗（TA1155）用于标准治疗未能控制的抗体阳性全身型重症肌无力。
- **危象和快速加重**：IVIG或血浆置换。

**肌无力危象**是指无力严重到需要通气或威胁气道。常由感染、手术、妊娠或药物诱发。许多药物可加重重症肌无力：氨基糖苷类、氟喹诺酮类和大环内酯类、静脉镁剂、β受体阻滞剂、神经肌肉阻滞剂，以及免疫检查点抑制剂。重症肌无力患者应携带警示卡，新处方应进行核查。

::: example 傍晚的复视 {#ex-mg}
一位68岁女性六周来左眼睑下垂和复视，傍晚和阅读后加重。过去一周她吃饭时呛了两次，说话久了声音带鼻音。查体：左侧上睑下垂，持续向上注视60秒后加重，复视多变，屈颈无力且反复检查后加重。瞳孔和感觉正常；反射存在。
::: solution
1. **定位。** 易疲劳的上睑下垂、多变的复视、延髓症状和屈颈无力，瞳孔、感觉和反射正常：**神经肌肉接头**疾病，最可能是**全身型重症肌无力**。瞳孔正常使动眼神经麻痹不太可能。
2. **危险。** 延髓肌无力（呛咳、鼻音）使她面临误吸和呼吸衰竭的风险。测量FVC，评估吞咽；若FVC低或下降或吞咽不安全，收住院。
3. **检查。** AChR抗体（阴性则查MuSK）、重复神经刺激或单纤维肌电图、胸部CT查胸腺瘤，以及甲状腺功能。
4. **治疗原则。** 溴吡斯的明对症治疗；由神经科主导免疫治疗，泼尼松龙从小剂量开始逐渐加量，同时保护骨骼并监测血糖，然后加用激素节制药物。若延髓或呼吸肌无力加重，用IVIG或血浆置换。若发现胸腺瘤，行胸腺切除术。给她一份应避免使用的药物清单。
:::
:::

**Lambert–Eaton肌无力综合征（LEMS）**由针对突触前**P/Q型电压门控钙通道**的抗体引起，减少乙酰胆碱释放。约一半病例与**小细胞肺癌**相关。它引起下肢近端无力，反射减弱但在**最大收缩数秒后短暂增强**（运动后易化），以及口干和勃起功能障碍等自主神经症状；眼部体征比重症肌无力轻。重复神经刺激显示基线反应低，短暂运动后升高超过100%。治疗包括处理肿瘤、用阿米吡啶增加乙酰胆碱释放，必要时免疫抑制。

**肉毒中毒**由肉毒毒素阻断乙酰胆碱释放引起，产生从眼和延髓肌开始的**下行性**瘫痪，常伴瞳孔散大、对光反射消失；在英国主要见于注射吸毒者（伤口型肉毒中毒）。用抗毒素和支持治疗，属于法定报告疾病。

## 肌肉疾病

::: definition 肌病 {#def-myopathy}
**肌病**是骨骼肌的疾病。通常引起**对称性近端无力**，感觉正常。**肌酸激酶（CK）**是从受损肌纤维释放的酶，常升高。肌病分为**获得性**（炎性、内分泌性、药物性、中毒性）和**遗传性**（肌营养不良、强直性肌营养不良、代谢性和线粒体肌病、离子通道病）。
:::

**炎性肌病**（肌炎）在数周至数月内引起无力。

- **皮肌炎**：近端无力，伴上眼睑紫红色皮疹（向阳性皮疹）、指关节伸面鳞屑性丘疹（Gottron丘疹）和日光暴露部位皮疹。成人与癌症相关，因此诊断时要进行癌症筛查。
- **抗合成酶综合征**（例如抗Jo-1抗体）：肌炎伴间质性肺病、关节炎、发热和手指皮肤皲裂（“技工手”）；见[[respiratory/interstitial-vascular-disease]]。
- **免疫介导性坏死性肌病**：严重无力伴CK极高，与抗SRP抗体或抗HMGCR抗体相关，后者常在使用**他汀类**之后出现。停用他汀后仍会持续，需要免疫治疗。
- **包涵体肌炎**：50岁以上最常见的肌病，男性多见，引起缓慢进展、常不对称的**指屈肌**和**股四头肌**无力，伴跌倒，后期出现吞咽问题。对免疫抑制无反应。

肌炎用糖皮质激素和激素节制药物治疗，耐药者用IVIG或利妥昔单抗。

**其他获得性肌病**包括**甲状腺功能减退**（伴CK升高）、库欣综合征和长期使用**糖皮质激素**（近端无力而CK正常）、维生素D缺乏（伴骨痛）、酒精和药物。**他汀类**常引起肌肉酸痛而CK正常；很少引起明显的肌病或横纹肌溶解。

**横纹肌溶解**是肌肉迅速分解，释放肌红蛋白、钾和磷。病因包括挤压伤、跌倒后长时间不动、极度用力、癫痫发作、药物和毒物，以及遗传性代谢性肌病。它引起肌肉疼痛、深色尿（试纸检测隐血阳性而镜检无红细胞）、CK极高、高钾血症和急性肾损伤。治疗为大量静脉补液、纠正血钾并治疗病因（见[[renal/acute-kidney-injury]]）。

### 遗传性肌肉疾病

**Duchenne肌营养不良**是一种X连锁隐性遗传病，由*DMD*基因突变引起，导致**抗肌萎缩蛋白**缺失；这种蛋白把肌细胞的内部骨架与细胞膜连接起来。约每3,500–5,000名男婴中有1例。患儿学步晚、常跌倒，从地上站起时用手沿腿向上撑（**Gowers征**），伴小腿肥大（假性肥大）。CK大幅升高。不治疗时约12岁丧失行走能力。糖皮质激素可延长行走时间；呼吸支持、针对心肌病的心脏治疗、脊柱手术和多学科照护已使生存期延长到三十多岁甚至更长。一些基因疗法（外显子跳跃药物、基因治疗）在部分国家获批。**Becker肌营养不良**的抗肌萎缩蛋白减少或异常，病情较轻、起病较晚。女性携带者可发生心肌病。

**1型强直性肌营养不良**是最常见的成人肌营养不良。它为常染色体显性遗传，由*DMPK*基因的**CTG重复**扩增引起，并表现出**遗传早现**：重复序列往往代代扩增，使发病更早、更重；由患病母亲传递时可出现严重的先天型。特征包括**肌强直**（收缩后放松缓慢，例如握手后难以松开）、远端和面部无力伴上睑下垂和颞肌萎缩、前额秃发、**白内障**、**心脏传导疾病**（可导致猝死；需定期心电图）、胰岛素抵抗、日间嗜睡和吞咽问题。镇静药和麻醉有特殊风险。

**脊髓性肌萎缩症（SMA）**是一种常染色体隐性遗传的前角细胞变性，通常由*SMN1*基因缺失引起。最严重的类型在婴儿期引起严重无力，不治疗时两岁内死于呼吸衰竭。三种疾病修正治疗（诺西那生、利司扑兰和基因疗法onasemnogene abeparvovec）彻底改变了预后，而且在症状出现前给药效果最好，这是支持新生儿筛查的理由。

**周期性瘫痪**是由肌肉离子通道疾病或钾转移引起的弛缓性无力发作。**甲状腺毒性周期性瘫痪**发作时血钾低，主要见于年轻男性，尤其是东亚裔，由高碳水化合物餐或运动后休息诱发。要谨慎补钾，因为体内总钾并未耗竭，只是转移到细胞内，随后可能出现反跳性高钾血症；同时治疗甲状腺毒症（见[[endocrine/thyroid]]）。

::: example 从地上起身困难 {#ex-myositis}
一位57岁女性三个月来上楼梯、从浴缸里起身和梳头越来越困难。她上眼睑有皮疹，指关节伸面有红色鳞屑性斑块。她还出现了劳力性气促。无感觉症状；反射正常。CK为4,800 U/L（正常低于约200）。双肺底可闻及细湿啰音。
::: solution
1. **定位。** 对称性近端无力，感觉和反射正常，CK极高：**肌病**。
2. **诊断。** 向阳性皮疹和Gottron丘疹：**皮肌炎**。气促和湿啰音提示可能合并**间质性肺病**（尤其是伴抗合成酶抗体或抗MDA5抗体时）。
3. **检查。** 肌炎特异性抗体；大腿肌肉MRI（显示炎症并指导活检）；肌电图；肌肉（或皮肤）活检；胸部高分辨率CT和肺功能检查；吞咽评估；以及适合她年龄和性别的**癌症筛查**（例如胸、腹、盆腔CT，乳腺X线摄影和卵巢评估），因为成人皮肌炎与恶性肿瘤相关，尤其是在最初几年内。
4. **治疗原则。** 糖皮质激素加激素节制药物，因有肺部病变需与呼吸科共同选择；难治性疾病或严重吞咽困难用IVIG。长期使用激素时：保护骨骼，监测血糖和血压，联合免疫抑制时预防肺孢子菌。炎症控制后进行物理治疗。
:::
:::

::: quiz
一位61岁吸烟男性三个月来从椅子上站起困难，口干，勃起功能障碍。他静息时膝反射消失，但股四头肌最大收缩10秒后出现。眼球运动正常。哪项检查最可能揭示潜在病因？
- [ ] 乙酰胆碱受体抗体
- [ ] 肌酸激酶
- [x] 胸部CT
- [ ] 肌肉活检
::: solution
下肢近端无力、自主神经症状以及短暂运动后反射恢复（运动后易化）是**Lambert–Eaton肌无力综合征**的典型表现。在吸烟者中，约一半病例为副肿瘤性，通常来自**小细胞肺癌**，可能在神经综合征出现数月至数年后才被发现，因此胸部CT（阴性时做PET-CT，并重复筛查）是关键检查。诊断本身由电压门控钙通道抗体和显示运动后递增的重复神经刺激确认。
:::
:::

::: warning 无力患者的血氧饱和度正常
在神经肌肉性呼吸衰竭中，正常的血氧饱和度和正常的血气是晚期的、虚假的安慰。要测量肺活量，观察呼吸模式，检查咳嗽和吞咽，并尽早请重症监护参与。呼吸肌无力者避免使用镇静药，重症肌无力患者的每种新药都要对照加重肌无力的药物清单进行核查。
:::

::: history
1916年，乔治·吉兰（Georges Guillain）、让-亚历山大·巴雷（Jean-Alexandre Barré）和安德烈·施特罗尔（André Strohl）描述了两名急性瘫痪和反射消失的法国士兵，他们的脑脊液蛋白含量高而无细胞。纪尧姆-本杰明·迪谢纳（Guillaume-Benjamin Duchenne）在19世纪60年代描述了假肥大性肌麻痹，威廉·高尔斯（William Gowers）于1879年描述了沿腿向上攀爬的体征。1934年，伦敦圣阿尔菲奇医院的医生玛丽·沃克（Mary Walker）注意到重症肌无力与箭毒中毒相似，并证明抗胆碱酯酶药毒扁豆碱能改善病情。1973年，吉姆·帕特里克（Jim Patrick）和乔恩·林德斯特伦（Jon Lindstrom）用乙酰胆碱受体免疫家兔诱发了肌无力，确立了其自身免疫基础。让-马丁·沙可（Jean-Martin Charcot）、皮埃尔·玛丽（Pierre Marie）和霍华德·图思（Howard Tooth）于1886年描述了遗传性腓骨肌萎缩症。路易斯·孔克尔（Louis Kunkel）等人于1986年确定了Duchenne基因，埃里克·霍夫曼（Eric Hoffman）等人于1987年确定了抗肌萎缩蛋白。
:::

::: summary
- 无力的模式可以定位：前角（肌萎缩、肌束颤动、无感觉缺失）、神经根（皮节和肌节）、神经（支配区或手套–袜套）、接头（易疲劳、眼肌和延髓肌）、肌肉（对称性近端、感觉正常）。
- 多发性神经病用分布、纤维类型、轴索性或脱髓鞘性病理和进程来描述；在英国糖尿病是最常见的病因。多发性单神经炎提示血管炎。
- 神经传导检查：波幅降低意味着轴索丢失；速度减慢和传导阻滞意味着脱髓鞘。肌电图区分神经源性和肌源性疾病。
- GBS：感染后急性对称性无力伴反射消失；监测肺活量（20–30–40规则）和自主神经功能；用IVIG或血浆置换治疗；激素无效。CIDP是其可治疗的慢性亲属。
- 重症肌无力：易疲劳的上睑下垂、复视和延髓肌无力；AChR或MuSK抗体；溴吡斯的明、免疫抑制、胸腺切除；避免加重病情的药物。LEMS为突触前病变，常为副肿瘤性。
- 肌病引起近端无力伴CK升高；皮肌炎有皮肤体征并与癌症相关；包涵体肌炎累及指屈肌和股四头肌。
- Duchenne肌营养不良（X连锁、抗肌萎缩蛋白）、强直性肌营养不良（CTG重复、心脏传导疾病）和SMA（*SMN1*，现已可治疗）是重要的遗传病。
:::

## 习题

::: exercise 每千克肺活量 {level=1 check="20"}
一位吉兰–巴雷综合征女性体重70 kg，用力肺活量为1.4 L。她的肺活量是多少mL/kg？
::: solution
$1.4 \text{ L} = 1400$ mL；$1400 / 70 = 20$ mL/kg。这正处于通常考虑插管的阈值，因此应已请重症监护参与。
:::
:::

::: exercise 递减 {level=1 check="30"}
在3 Hz重复神经刺激中，第一个复合肌肉动作电位波幅为8.0 mV，第四个为5.6 mV。递减是多少？以整数百分比表示。
::: solution
$(8.0 - 5.6) / 8.0 \times 100 = 30\%$。递减超过10%支持重症肌无力等神经肌肉传递障碍。
:::
:::

::: exercise 病变在哪里？ {level=1}
为下列每种情况给出最可能的层面（前角、神经根、神经、接头或肌肉）：(a) 45岁，颈痛放射至拇指，屈肘无力，肱二头肌反射减弱；(b) 30岁，上睑下垂和复视在一天中逐渐加重；(c) 70岁，从椅子上站起困难，CK 2,000 U/L；(d) 60岁，双足麻木，踝反射消失；(e) 55岁，双手肌萎缩和肌束颤动，无感觉缺失。
::: solution
(a) 神经根（C6神经根病）。(b) 神经肌肉接头（重症肌无力）。(c) 肌肉（肌病）。(d) 周围神经（长度依赖性多发性神经病）。(e) 前角细胞（例如运动神经元病）；多灶性运动神经病是一种神经疾病，是重要的可治疗的类似疾病。
:::
:::

::: exercise 轴索性还是脱髓鞘性？ {level=2}
两位患者的神经传导检查：(a) 腓肠神经感觉波幅消失，腓总神经运动波幅0.8 mV（低），传导速度41 m/s（接近正常）；(b) 正中神经运动传导速度28 m/s（非常慢），远端潜伏期延长，腕部与肘部刺激之间运动反应下降60%。分别解读，并给出可能的病因。
::: solution
(a) 波幅降低而速度保留：**轴索性**神经病，例如长度依赖性糖尿病或酒精相关神经病。(b) 明显减慢、潜伏期延长和**传导阻滞**：**获得性脱髓鞘性**神经病，如GBS（急性）或CIDP（慢性）。若为均匀减慢而无传导阻滞，则提示CMT1A等遗传性脱髓鞘性神经病。
:::
:::

::: exercise 重症肌无力与胸部感染 {level=2}
一位全身型重症肌无力女性，服用溴吡斯的明和硫唑嘌呤病情稳定，现发生胸部感染。收治医生计划开克拉霉素，并因心律失常静脉给予镁剂。你担心什么？你会怎么做？
::: solution
感染是重症肌无力加重和危象的常见诱因。大环内酯类（克拉霉素）、氟喹诺酮类和氨基糖苷类都可能加重神经肌肉传递障碍，静脉镁剂减少乙酰胆碱释放，可诱发危象。按当地指南选择没有这种作用的抗生素（例如适当时用阿莫西林），尽可能为心律失常寻找其他治疗。密切监测FVC、吞咽和延髓功能，通知神经科团队，并准备在她病情恶化时给予IVIG或血浆置换。不要停用她平时的重症肌无力治疗。
:::

::: exercise 强直性肌营养不良家庭 {level=2}
一位38岁男性患轻度1型强直性肌营养不良（握手后难以松开，早发白内障），询问自己的健康风险和生育计划。你会讨论什么？
::: solution
他的健康：定期心电图（必要时动态心电图），因为心脏传导疾病可导致猝死，可能需要起搏器或除颤器；筛查糖尿病；评估日间嗜睡和呼吸；眼科复查白内障；以及麻醉警示，因为镇静药、阿片类和某些麻醉药可引起持久的呼吸抑制。他的孩子：该病为常染色体显性遗传，每个孩子有50%的机会遗传。由于遗传早现，孩子的病情可能比他更重；严重的先天型几乎只在从母亲遗传时出现，所以患病父亲的孩子发生先天型的可能性较小。转诊至临床遗传学进行咨询，讨论产前诊断或植入前遗传学检测等选择。亲属也可能希望接受检测。
:::

::: exercise 上升性无力，但不是GBS {level=3}
一位40岁女性四天内双下肢进行性无力，麻木上升到脐水平，并有尿潴留。下肢反射活跃。一位低年资同事说：“上升性无力，所以是吉兰–巴雷。”解释为什么这不太可能，给出鉴别诊断，并说明首先必须做什么。
::: solution
躯干上的**感觉平面**、早期**尿潴留**和**活跃**的反射指向**脊髓**，而不是周围神经。GBS引起反射消失，很少有感觉平面，括约肌问题只在晚期出现或很轻。（在急性脊髓压迫或脊髓炎的最初数小时，脊髓休克可使反射减弱，所以感觉平面和括约肌受累是更可靠的线索。）鉴别诊断是**压迫性脊髓病**（转移性脊髓压迫、硬膜外脓肿、椎间盘、血肿）和**横贯性脊髓炎**（MS、NMOSD、MOG抗体病、感染、结节病），以及脊髓梗死。第一步是**紧急全脊髓MRI**，因为压迫需要在数小时内治疗（见[[nervous-system/motor-systems]]和[[nervous-system/neuroinflammation]]）。尿潴留时留置导尿。
:::

::: exercise 手指无力、经常跌倒的男性 {level=3}
一位72岁退休教师三年来抓握缓慢进行性困难，左手尤甚，并因膝盖“发软”经常跌倒。他开始在进食时咳嗽。前臂屈肌和股四头肌萎缩，左侧更重；屈指无力；感觉正常；膝反射减弱。CK为600 U/L。有人建议他因“多发性肌炎”使用泼尼松龙。讨论可能的诊断及其处理。
::: solution
老年男性缓慢进展、不对称的**指屈肌**和**股四头肌**无力，伴跌倒、吞咽困难和CK中度升高，是**包涵体肌炎**的典型模式。它常被误诊为多发性肌炎。肌肉MRI、肌电图、抗cN1A抗体（约三分之一到一半阳性）和肌肉活检（炎症伴镶边空泡和蛋白聚集）支持诊断。与其他类型肌炎不同，它对糖皮质激素或其他免疫抑制**无反应**，而这些药物有实际危害，所以不应基于推测的多发性肌炎开始使用激素。处理是支持性的：物理治疗和运动，预防跌倒和辅具（例如膝支具和助行器），针对抓握的作业治疗，言语治疗师评估吞咽（严重吞咽困难时可选择环咽肌治疗等方法），以及支持。吞咽问题和误吸是重要的患病和死亡原因。
:::
