卒中是成人神经科的收住中最常见的单一病因、也是少数“分钟可以被测量地转化为被保有的功能”的疾病之一：**在大血管的闭塞期间大约每分钟死亡约一百万个脑细胞，溶栓与取栓都附带“硬性的、依赖时钟的”数字，而二级预防的军火库属于医学中证据最密集之列。**几乎每一位临床医师、而不只是神经科医师，都参与最初的那几个小时。

本章涵盖血管的解剖与卒中的综合征、短暂的脑缺血发作、包括再灌注在内急期的处理、出血性的卒中、以及二级预防与康复。

## 解剖与综合征

::: definition 血管的区域与临床的综合征 {#def-territories}
**前循环大脑中动脉与它的上下的分支及“豆纹的动脉”——对侧的“面与臂为主的偏瘫与偏身的感觉的丧失”伴同向的偏盲；在优势半球还有失语布洛卡的不流畅与韦尼克式流畅的综合征、以及“传导性的与全性的”变异——它们要被检查并分型，因为它们会改变康复与能力的评估；在非优势半球则是“伴疾病的不自知的偏侧的忽视与着装及空间的缺陷”——动脉的地图与“区域之间的分水岭”（其灌注不足造成近端的肢与肩的“桶中人”的综合征见[[anatomy/neuroanatomy]]；大脑前动脉——对侧的“以下肢为主的无力”伴“意志缺乏与尿的失禁及额叶的释放的征”、以及“双侧前动脉的变异”以截瘫模仿脊髓的病灶——误送的路见[[musculoskeletal/back-pain]]）。后循环椎基底系统与它的脑干与丘脑及枕叶及小脑的分支——“同侧脑神经的缺陷与对侧的长束的体征配成对”的交叉的综合征非神经科的人会把它们读成“转换性”；以及那块“保留意识与眼动的闭锁的”脑桥基底部状态在重症的决定中绝不可被误认为无反应——[[emergency-critical-care/critical-care]]；大脑后动脉——“伴黄斑的豁免”的同向的偏盲，若在优势半球则是“不伴书写困难的失读”；丘脑的梗死（“纯粹感觉的卒中”与“丘脑的疼痛”；以及小脑的卒中——三联“眩晕与呕吐及无法行走”伴随注视改变方向的眼震，它藏在“周围性的眩晕”后面，直到第四脑室的压迫与脑积水恶化——床旁试验的区分见[[nervous-system/sensory-systems]]）。小血管的综合征（腔隙的梗死与它们那经典的四联——纯运动、纯感觉、“共济失调的偏瘫”、以及“笨拙的手伴构音障碍”——及它们的“高血压与糖尿病”的底物；以及“累积白质的病变”所带来的“血管认知损害的与步态的失用”——[[cardiovascular/hypertension]]、[[nervous-system/dementia-neurodegeneration]]。）**
:::

## 几个小时

::: definition 疑似的卒中：从院前到再灌注 {#def-acute}
**识别与系统公众的“脸臂言语时间”的宣传与它们“把卒中的模仿者也叫来”的过度呼叫——一个被接受的成本；以及“最后一次看起来健康”的时钟；以及救护车向“超急卒中的单元”的分诊（带着直接送到CT的路径——是让溶栓得以交付的“系统工程的胜利”，其公平的告诫是“识别与呼叫的比率随语言、年龄、残疾与街区而不同”——[[public-health/prevention-promotion]]、[[public-health/determinants-inequalities]]）；第一分钟的评估（“气道呼吸循环”，在任何经口的东西之前先做吞咽的筛查；“只在缺氧时才给氧”这条来自试验的证据；血糖是被测量的、不是被假定的；血压在“溶栓适格的阈值”的背景下被记录；以及“美国国立卫生研究院卒中的评分”作为团队之间的共同的货币——[[emergency-critical-care/acute-assessment]]）；影像与决定（平扫的CT排除出血；“CT的血管成像加上灌注的不匹配”这一模型回答“闭塞与缺血半暗带”的问题；而“磁共振的弥散”在后颅窝与“醒来时的卒中”上更优越——试验的时代把治疗扩展到“起始不明的”与“经选择的闭塞最多24小时”——[[clinical-skills/medical-imaging]]）；再灌注的治疗静脉的溶栓——阿替普酶，以及“向替奈普酶实践的位移”，带着4.5小时的核心窗口与“经影像选择的延长”、以及绝对与相对的禁忌（近期的手术与创伤及卒中、“升高的国际标准化比值或在剂量内直接口服的抗凝药”的抗凝、活动的出血、以及那条“在病史没有要求时不要为血小板与国际标准化比值而延误”的规则、以及替奈普酶的便利、以及“进门到针头”的指标、以及“约6%的症状性出血的比率”这一知情同意的算术；以及机械的取栓——在6小时之内、“发病前状态良好前循环大血管的闭塞”，以及“经灌注选择的患者最多24小时”、“证明在院间转运是合理的需治数、麻醉策略的辩论、以及并发症——[[surgery/anaesthesia-pain]]、颈与弓的来源见[[cardiovascular/vascular-disease]]）；以及立即的后续（卒中单元这一病区本身就是一桩降低死亡率的干预，带着它那一整套“吞咽与体温及血糖及早期康复”的清单）。**
:::

::: definition 短暂的脑缺血发作：那笔“付得出账”的警报 {#def-tia}
**现代的把“没有梗死的”一过性神经的功能障碍定义为“组织的、而不是24小时的”——这就是为什么“伴弥散病灶的短暂发作”被重新归类为小的卒中。它是一桩急症，因为早期的卒中的风险在头48小时最高、并且可以用“评分以及经影像与病因 的改良”分层。紧急的路径：当日评估（“当日门诊与影像与治疗”的模型，在试验中把后续的卒中降低了“双位数的百分比”）；“带弥散的脑的影像与头颈的血管的影像”；以及为房颤做长时间的心的监测“贴片与可植入的记录器的时代”把“隐源性的”变成心源性的、并改变抗血栓的选择；超声心动以及在年轻人中“卵圆孔未闭与夹层及血管炎及易栓”的检查（按年龄与机制的比例——[[cardiovascular/arrhythmias]]、[[clinical-skills/medical-imaging]]、[[blood/haemostasis-bleeding]]）。按机制匹配预防：“显著症状性颈动脉的狭窄”的内膜的剥脱或支架，要早做以日计；一旦梗死的大小与临床的状态允许，理想在两周之内，带着麻醉与分流及再狭窄的细微差别——[[surgery/vascular-urological-surgery]]；抗血小板的治疗在未溶栓时急期负荷量的阿司匹林；以及为“高风险的短暂发作与小的卒中”的“短程双联的抗血小板”（带被说清的出血的取舍）；对比为房颤做的抗凝（直接口服的抗凝药在颅内出血上的优势、以及梗死之后的时机规则——套“一、三、六、十二天”的启发法、如今正被推得更早、以及为“真正不能耐受抗凝者”的“左心耳的封闭”一小块地——[[blood/thrombosis-anticoagulation]]、[[pharmacology/dosing-principles]]）；以及风险因子的包急性期之后的血压与血脂、吸烟配戒断药物提供的、糖尿病与体重及活动——它与下面那份“已完成的卒中”的清单完全相同。年轻人隐源性的卒中值得一份自己的清单（夹层与“隐匿心源性的”及易栓及血管炎及“药物的”）。**
:::

::: example 早餐时那个“找不出词”的问题 {#ex-aphasia}
一名72岁的退休教师在她丈夫发现她“说不出词”之后90分钟被送来；她能执行指令、认得他；右侧的面与臂无力；言语费力而断断续续；血糖5.8；血压158/92；评分7；未服抗凝药；“最后一次看起来健康”是02:00、被发现是08:30，但丈夫“很确定他在07:45起床时她还很好”。
::: solution
**很可能是左侧大脑中动脉分支的卒中、带一个被记录的“07:45的最后看起来健康”——处在每一个治疗窗口之内（[[#def-territories]]、[[#def-acute]]）：路径——超急的影像（CT排除出血、CT的血管成像找闭塞、按评分要求的灌注；以及溶栓的决定（从07:45算起的4.5小时的算术、本地“替奈普酶对阿替普酶”的方案、以及“唯一可以让针头等待的化验”——血压与血糖与国际标准化比值的核查——[[clinical-skills/laboratory-tests]]、[[emergency-critical-care/acute-assessment]]）；失语的那条告诫——一位不流畅的失语的患者通过“用是非题来核实的沟通”来表达同意、并把行话“去水分”；而“能力对沟通”这一区分必须被明确地说出来，因为“她说不太好”不等于“她不能决定”——无论是对溶栓还是对之后的同意——[[medical-ethics-law/consent-capacity]]、[[clinical-skills/communication]]）；如果发现M1的闭塞——取栓适格的讨论与“到神经介入中心的院间转运”、以及那份按现行证据的“在溶栓之后仍然值得”的桥接的逻辑告诉家属两种治疗各自在做什么；如果没发现——“允许性的高血压与24小时之后的抗血栓以及卒中单元的收住”的路径在早餐盘之前做吞咽的筛查；以及那一周就要开启的二级预防与康复——房颤的监测与血脂与血压的计划、言语治疗与职业治疗的转诊、以及驾照的告知对一位教师来说那是一场关于身份、而不是一张表格的谈话——[[public-health/prevention-promotion]]、[[clinical-skills/records-handover]]。**
:::

::: example 她一生中最严重的头痛 {#ex-sah}
一名49岁的女性在做家务时突发“最大强度的头痛”、颈的僵硬、呕吐一次；格拉斯哥15、无灶的体征；头的CT显示“基底池的高密度”；她服了800毫克的布洛芬并“感觉更糟”。
::: solution
**动脉瘤蛛网膜下腔的出血——一场“预防再出血的赛跑”与一段“血管痉挛的观察”（[[#def-territories]]）：最初的24小时——转诊给神经外科或神经介入、做“CT的血管成像的找动脉瘤”；用来预测与交流风险分级的量表；镇痛与止吐与“软化大便的”的处方；启动尼莫地平为了减少神经的并发症；“避免非甾的与抗血小板”的逻辑把布洛芬的病史记下来以便计划“逆转”；以及神经的观察配“脑积水与临床的引流”的道理和对低钠的监测（“抗利尿激素的不当分泌对脑的耗盐”这个陷阱——[[renal/water-sodium]]、[[endocrine/hypothalamus-pituitary]]）；确定动脉瘤的治疗——“栓塞对夹闭”，由动脉瘤的解剖与中心的专长决定，“把试验时代的结局说清楚”、而时机通常是早期；以及脑室的引流对腰穿引流的抉择、和在“第4到10天的血管痉挛带来迟发的缺血缺失”时“为恶性的梗死做去骨瓣的减压”的决定（用“诱导的高血压与等容量”的血流动力学取代了旧的“三重H”的教条，以及血管内的选项——[[emergency-critical-care/critical-care]]、[[cardiovascular/vascular-disease]]）；回头看——“未破裂的偶然发现与家族的筛查及遗传的背景”问题（罕见的结缔组织与多囊的疾病的关联、吸烟与高血压的修改、以及“对侧的焦虑性的扫描”的辩论、以及对“虽小但真实的被筛查发现动脉瘤的过度治疗”问题的披露——[[genetics/mendelian-inheritance]]、[[medical-ethics-law/justice-resources]]）；以及存活下来的那一段——甚至在“成功的栓塞或夹闭”之后仍会跟着患者的疲劳与认知及情绪及重返工作的现实——[[nervous-system/dementia-neurodegeneration]]、[[psychiatry/mood-disorders]]。**
:::

::: example 处“需要一个日期”的狭窄 {#ex-carotid}
一名67岁的男子昨天有15分钟的“左眼单眼的失明一过性的黑蒙”、现在已经缓解；CT的血管成像显示“同侧的颈内动脉85%的狭窄”；低密度的脂蛋白4.1；仍在吸烟；评分0。
::: solution
**症状性高级别颈动脉的狭窄——这台手术要像药一样定时（[[#def-tia]]、[[surgery/vascular-urological-surgery]]）：风险的分层——“症状性的狭窄之后的12周的复发风险”集中在最初的几天；评分的改良；以及“用影像确认元凶”（而那句“为什么不是另一侧”由“眼动脉栓塞的眼的而非半球的解剖”来回答——[[clinical-skills/medical-imaging]]）；紧急的路径——同一次收住或同一周的颈动脉的内膜的剥脱（或按解剖与年龄及外科的适格性做支架，带着“经股对经颈”的细微差别，因为获益在事件之后“每周衰减”、而“六周后的门诊”是这个综合征里最常见的系统的失败——[[cardiovascular/vascular-disease]]）；围手术期的内科学——“血压的波动与神经的损伤与过度的灌注”的咨询；抗血小板与他汀的负荷以及“现在就而不是出院时”开始戒烟的药物；以及对侧的闭塞与主动脉弓疾病的记录——[[pharmacology/dosing-principles]]、[[public-health/prevention-promotion]]、[[cardiovascular/hypertension]]；以及长期的博弈——“用高强度他汀、必要时加上额外的治疗”去达到低密度脂蛋白的目标；血运重建之后的血压的策略以及对“术后早期头痛的患者”的过度灌注的警告；以及“黑蒙复发的危险信号”的教育与“当日就回来”的指示——它能防住那一场“会完成的卒中”——[[#def-prevention]]、[[nervous-system/sensory-systems]]、[[clinical-skills/communication]]。**
:::

::: example 例“在阿哌沙班上出的血” {#ex-doac-ich}
一名81岁因房颤服用阿哌沙班的患者跌倒并撞到了头；两小时后她在呕吐、格拉斯哥11、CT上有一处“右侧壳核的大出血”；最后一次阿哌沙班是在6小时前；肌酐105。
::: solution
**“直接口服的抗凝药相关的脑内出血”——逆转、复苏、再评估（[[#def-ich]]）：逆转的决定——在被委托的地区用“特异的拮抗剂”带着“血栓的风险与抗Xa的活动反跳的监测”告诫，对“被广泛可及的四因子的凝血酶原复合物的浓缩液”；按“药物与剂量与距最后一次给药的时长”定剂量；在可及时测“抗抑制物的辅因子的活性”；以及那条“不要反射性地两样都给”的谨慎；以及“氨甲环酸时代的试验结果”（诚实地说出——[[blood/haemostasis-bleeding]]、[[blood/transfusion]]、[[pharmacology/dosing-principles]]）；第一小时的集束——“带着那个格拉斯哥的”气道保护的决定（麻醉与神经外科的共同呼叫；按试验得出的收缩压的目标用“可滴定的药物”控制血压；避免医源性的低血压与低容量；注意血糖与体温、以及“对恶化的患者的颅压的基本”——[[emergency-critical-care/airway-ventilation]]、[[emergency-critical-care/critical-care]]、[[cardiovascular/hypertension]]）；外科的问题——“年老患者深部的出血很少从清除中获益”（对恶化的浅表的小叶的病灶则不同，所以诚实的谈话是“舒适对继续升级”，与家属一起做，“用基线的功能与年龄及血肿的体积来透明地做预后的判断”、包括那一句“终身的抗血栓要不要撤”的含义——[[geriatrics-palliative/end-of-life-care]]、[[medical-ethics-law/consent-capacity]]）；以及后续——房颤与跌倒的对账为跌倒的人讨论“心耳的封闭”；“重新抗凝对永远不再”的决断，用“华法林脑出血较早的数据与更新的直接口服的抗凝药脑出血的自然史”预演一遍、以及那份用药的记录的更正与“跌倒的规划”（[[pharmacology/adverse-reactions]]、[[geriatrics-palliative/falls]]）。**

::: quiz
一名68岁因房颤服用华法林、国际标准化比值2.4，在“右半球的综合征”起病2小时到达、评分14、CT没有出血。关于溶栓的正确动作是：
- [ ] 给阿替普酶，因为她的国际标准化比值低于3
- [x] 因抗凝而不给静脉的溶栓，但立即评估取栓
- [ ] 先逆转华法林，再溶栓
- [ ] 给半剂量的阿替普酶
::: solution
**“治疗性的抗凝伴升高的国际标准化比值”是静脉溶栓的禁忌在大多数方案里是大于1.7的阈值、但它并不禁忌机械的取栓——这正是“为抗凝的患者走先做CT血管成像的路径”的意义：有闭塞就转运、没有闭塞就走“早期抗凝的逆转与允许性的血压”的卒中单元的路径（[[#def-acute]]、[[blood/thrombosis-anticoagulation]]）；半剂量的溶栓并不存在、而“先逆转再溶栓”会浪费时钟；而房颤意味着她的长期计划是“抗凝时机的决定”、不是抗血小板（[[#def-tia]]、[[cardiovascular/arrhythmias]]）。**
:::

## 预防、出血与恢复

::: definition 脑内出血的处理 {#def-ich}
**出血的患者：逆转为先华法林用“四因子的凝血酶原复合物的浓缩液加维生素K”、按国际标准化比值与体重定剂量，并承认血栓的风险；“直接口服的抗凝药”的逆转——达比加群用“特异单链的抗体片段”、Xa的抑制剂用“特异的拮抗剂或凝血酶原复合物的策略”带着它们的费用与可及性及促凝的告诫；“抗血小板相关的出血”——血小板输血的试验是阴性的、而“去氨加压素”仍是“逐中心的习惯”；以及“肝病的凝血病与血小板的减少”的版本（带着它们关于血制品的策略的辩论——[[blood/haemostasis-bleeding]]、[[blood/transfusion]]、[[gastrointestinal/liver-disease]]）；降压（“强化收缩压的目标”的试验显示“血肿稳定的获益”，带着“J的曲线”与肾及冠脉的告诫；在“被监测的床上用可滴定的静脉的药物”交付，以及“撤药对允许性”的那段时相的逻辑——[[cardiovascular/hypertension]]、[[emergency-critical-care/critical-care]]）；升级的决定格拉斯哥的轨迹与“血块的大小与位置”及年龄与病前的状态；“不再升级对去骨瓣的手术”在“伴恶化浅表小叶的出血”上的证据；以及“脑室内的积血与脑积水”的引流的问题——神经外科与姑息的两场谈话要并行，因为对不同的患者两者可能都是对的答案；以及在贴上“高血压的”这个标签之前要排除继发的原因（“小叶的与抗凝的与淀粉样的”组合、血管的畸形与肿瘤的出血、以及“拟交感的药物与血管炎及静脉的血栓”的鉴别——配上“CT或磁共振的血管成像与带磁敏感序列的磁共振（找海绵状血管瘤与淀粉样”）——[[nervous-system/neuroinflammation]]、[[pathology/cancer-biology]]）；以及“要不要重新抗凝”的咨询（房颤在脑出血之后：复发的恐惧对血栓的恐惧、以及“左心耳的封闭”一小块地、连同“时机与患者共同做的权衡”——[[blood/thrombosis-anticoagulation]]、[[clinical-skills/communication]]。）**
:::

::: definition 二级预防与康复 {#def-prevention}
**在“非心源性缺血的卒中”之后，抗血小板对抗凝的逻辑——阿司匹林75到325毫克无限期或氯吡格雷、或“双嘧达莫加阿司匹林”作为替代，它们之间的差别不大；短程双联治疗的适应证；以及“只在房颤与经选择的来源才抗凝”这一原则带着卵圆孔未闭与复发的事件的细微差别；降压以“噻嗪样的与转换酶的抑制剂”为中心的试验的证据、“急性期的允许性”这一告诫、以及那“远超过任何抗血栓之间的比较”的长期复发降低的幅度；脂类的策略高强度他汀并承认脑出血的取舍、对“未达目标者”的依折麦布与“前转化酶枯草溶菌素9的抗体”加用的药；以及出血性的卒中的患者——答案按机制而不同；以及生活方式与共存病的包配药物的戒烟、体重与活动、糖尿病（带“新药与卒中相关的试验证据”、减少酒精、在血管的类型中检出睡眠的呼吸暂停、以及“把试验的结果应用到一位85岁身上”时那条外推的告诫——[[cardiovascular/hypertension]]、[[endocrine/diabetes]]、[[cardiovascular/vascular-disease]]）；康复的核心——早期多学科的活动、配“物理治疗与职业治疗与言语治疗及心理与社会工作”的团队与目标的量化的工具；“从卒中单元到出院到社区”的连续性、以及“神经的康复对护理院”的决定它们塑造了患者在哪里恢复；以及那“更多的治疗的小时数买到更多的功能（到某个点为止”的剂量反应的证据——[[geriatrics-palliative/ageing-frailty]]、[[public-health/health-systems-economics]]）；以及后遗症的门诊的项目——痉挛的管理牵拉与体位及口服的巴氯芬与替扎尼定、以及“为灶的模式的肉毒毒素（包括那枚被藏起的拇指与腋部的卫生适应证”、以及鞘内的巴氯芬与“矫形外科肌腱的延长”——[[musculoskeletal/back-pain]]、[[pharmacology/adverse-reactions]]。）**
:::


::: exercise 读综合征 {level=1}
定位：（甲） 右侧的面与臂的无力、无感觉的丢失、言语流畅、“向左侧注视的偏好”；（乙） “伴疾病的不自知”的左侧偏侧的忽视；（丙） 双侧的腿的无力伴尿潴留与“脐部感觉的平面”；（丁） “构音障碍与笨拙的手”；（戊） 眩晕、同侧的面部发麻、对侧的躯体的痛温的丧失、霍纳与共济失调。
::: solution
**从综合征到动脉（[[#def-territories]]）：（甲）右侧的大脑中动脉的区域，其中“注视的偏好”指向那一侧的半球而在非优势半球，失语的检查无关——[[clinical-skills/physical-examination]]；（乙）非优势顶叶的大脑中动脉的下支，带着“着装与自知”的康复的后果；（丙）脊髓脐的平面大约是第十胸——在影像说了别的之前根本不是卒中：脊髓的压迫与横贯性的脊髓炎及梗死这份鉴别，配当天的磁共振——[[nervous-system/neuroinflammation]]、[[musculoskeletal/back-pain]]；（丁）腔隙的脑桥的基底部或内囊的膝小血管的综合征；以及（戊）延髓的外侧瓦伦贝格、小脑后下动脉或椎动脉——那个在最初24小时“最常被错标成周围性的眩晕”的后循环的卒中——[[nervous-system/sensory-systems]]、[[emergency-critical-care/acute-assessment]]。**

::: exercise 处理那次“误吸的热” {level=2}

一名60岁在小卒中后两年，承认他“把一半的药片停了，因为我感觉挺好”；他的降压药与他汀吃吃停停。
::: solution
**复发风险风险的数字、而不是训斥（[[#def-prevention]]、[[pharmacology/patient-variation]]）：量化——他大致的“每年的复发的风险”在索引事件之后5%到10%，早期更高，以及“降压（约减少四分之一的复发与他汀及抗血小板所增加的相对风险的降低”，然后换算成“每一百名患者年”的绝对的数字——是外行的头脑能握住的形式——[[epidemiology-ebm/measuring-disease]]）；说出那“沉默的治疗”的问题——血压与他汀没有“日常能被感觉到的获益”、而他确实感觉到的症状肌肉的酸痛与踝的水肿会被归给药物；所以要问他注意到了什么、并把每一种副作用重新框成“换药而不是停药”的谈话（配一份方案的菜单——[[pharmacology/adverse-reactions]]）；简化——每日一次合剂、与全科医师一起做“固定剂量的重写”的谈话、由药师主导的复查、以及“更少瓶子、同样的保护”这套“被复方的试验在依从上支持的”逻辑；以及尊重自主——目标是“知情的选择者”，所以说出他自己的优先独立与旅行、以及“不再变成一个患者”、约定那两种他永不停止的药与那一种他可以和重新商量的、并预约那“让计划成真”的随访——[[clinical-skills/communication]]、[[public-health/prevention-promotion]]。**
:::

## 通向何处

血管的底物在[[cardiovascular/vascular-disease]]与[[cardiovascular/hypertension]]；心律失常的来源在[[cardiovascular/arrhythmias]]；抗凝的药理学在[[blood/thrombosis-anticoagulation]]；神经解剖的地图在[[anatomy/neuroanatomy]]；康复与衰弱的接口在[[geriatrics-palliative/ageing-frailty]]与[[nervous-system/dementia-neurodegeneration]]。

::: history
**卒中的医学史，是神经病学失去“它保持了一个世纪治疗虚无的名声”的故事：十九世纪血管定位的经典——特鲁索的“失语与动脉”的描述、以及那个主导了“关于高血压的出血的思考达120年、后来才被修订到应有的规模”的“夏科与布夏尔的微动脉瘤”的理论——[[anatomy/neuroanatomy]]、[[pathology/haemodynamics]]；颈动脉内膜剥脱的谱系——始于1950年代“几乎出于偶然”的为“脑的缺血”做的那批手术，以及八十年代末与九十年代初的那两项试验“终于证明了外科医师们长期主张的东西”——是历史上最干净的外科与试验的合作之一——[[surgery/vascular-urological-surgery]]；溶栓的战役——欧洲的与澳洲的及美国的尝试、以及1995年那次国家研究所的结果、以及多年“窗口太窄、系统做不到”的反对——而反对不是被更好的药物、而是被“重新设计的救护车与CT的机房”所回答；这是“急症医学的创新常常是运作的研究、而不只是分子的生物学”这一伟大教训——[[emergency-critical-care/acute-assessment]]；2015年的取栓的复兴——五项试验、一个荟萃的信息、以及“支架取器的技术”为“在反对血管内的那十年荒野里做着无用的取栓”的神经放射科医师平了反——[[clinical-skills/medical-imaging]]；以及卒中单元的证据——那项“最便宜、最可靠地降低死亡率与残疾”的发现——以及“取栓与溶栓与当日的短暂发作的门诊”如何“一起把一门观察的疾病改写成了一门时间的医学”（[[public-health/health-systems-economics]]、[[clinical-skills/patient-safety]]）。**
:::
