卒中是由血液供应问题引起的脑功能突然丧失。它是主要死因之一，也是成人复杂残疾最常见的原因。它还是少数几种在最初数小时内给予治疗就能改变结局的神经科急症之一。当一条大动脉被堵塞时，它所供应的脑组织会逐步死亡；血流恢复得越早，挽救的就越多。这就是卒中诊疗路径围绕时钟来组织的原因。

本章介绍脑的血液供应及其衰竭后出现的综合征、短暂性脑缺血发作、缺血性卒中的急性治疗、脑出血和蛛网膜下腔出血，以及二级预防和康复。英国指南引自NICE NG128（《16岁以上人群的卒中和短暂性脑缺血发作》，2019年，及其后的更新）和2023年《英国和爱尔兰国家卒中临床指南》。处理始终遵循当地现行方案。

## 定义与类型

::: definition 卒中与短暂性脑缺血发作 {#def-stroke}
**卒中**是血管源性的突发局灶性（有时为全脑性）神经功能缺损。在英国，约85%的卒中为**缺血性**，由动脉阻塞引起；其余为**出血性**，包括**脑出血**（出血进入脑实质）和**蛛网膜下腔出血**（出血进入脑周围的腔隙）。

**短暂性脑缺血发作（TIA）**是由脑、脊髓或视网膜局灶性缺血引起的短暂神经功能障碍发作，且**没有**梗死。旧定义使用时间界限（症状在24小时内缓解）。现代定义以组织为基础：如果脑影像显示梗死，无论症状缓解得多快，该事件都是卒中。实际上，大多数TIA只持续数分钟。
:::

缺血性卒中按机制分类，因为机制决定预防：

- **大动脉粥样硬化**：颈动脉、椎动脉或颅内主要动脉的斑块脱落栓子或阻塞血管。
- **心源性栓塞**：来自心脏的血栓，最常见的是**心房颤动**时来自左心房，也可见于心肌梗死后或来自人工瓣膜。
- **小血管病**：脑深部小穿支动脉闭塞，典型地见于高血压或糖尿病患者，造成**腔隙性梗死**。
- **其他明确病因**：动脉夹层（青年人的重要病因）、血管炎、凝血障碍等。
- **原因不明（隐源性）**：经检查仍未找到病因。

## 动脉供血区与卒中综合征

脑由两条颈内动脉（**前循环**）和两条椎动脉供血，两条椎动脉汇合成基底动脉（**后循环**）。两个系统在脑底通过**Willis环**相连，但Willis环常不完整。相关解剖见[[anatomy/neuroanatomy]]。

::: definition 主要卒中综合征 {#def-syndromes}
- **大脑中动脉（MCA）**：对侧面部和上肢的无力和感觉缺失重于下肢，同向偏盲，以及**失语**（优势半球，通常为左侧）或对侧空间**忽视**（非优势半球）。主干（M1）闭塞造成完整的综合征，伴双眼向病灶侧凝视。
- **大脑前动脉（ACA）**：对侧下肢无力重于上肢；梗死较大时可有淡漠和尿失禁。
- **大脑后动脉（PCA）**：同向偏盲，常伴黄斑回避；累及内侧颞叶时有记忆丧失；优势半球病灶时有阅读困难。
- **腔隙综合征**：纯运动性卒中、纯感觉性卒中、感觉运动性卒中、共济失调性轻偏瘫和构音障碍–手笨拙综合征。没有皮质体征：无失语、忽视或视野缺损。
- **后循环（椎–基底动脉）**：眩晕、复视、构音障碍、吞咽困难、共济失调以及**交叉性体征**（一侧脑神经体征，另一侧肢体体征）的各种组合。**延髓背外侧综合征**（由椎动脉或小脑后下动脉闭塞所致）表现为眩晕、同侧Horner综合征、同侧面部和对侧躯体痛觉丧失、共济失调和吞咽困难。**基底动脉闭塞**可引起昏迷或**闭锁综合征**，此时意识保留，但仅剩垂直眼球运动和眨眼。
:::

后循环卒中比前循环卒中更常被漏诊，因为眩晕和呕吐被归因于内耳疾病，而CT显示后颅窝的能力又差。急性眩晕的HINTS检查见[[nervous-system/sensory-systems]]。

有几种情况会**模拟卒中**：低血糖、癫痫发作后的发作后（Todd）瘫痪、有先兆偏头痛、功能性神经障碍、既往卒中者合并脓毒症、脑肿瘤和硬膜下血肿。每一例疑似卒中都要测指尖血糖，因为低血糖常见、易于发现且容易治疗。

## 缺血性卒中的急性诊疗路径

::: theorem 时间就是大脑 {#thm-time}
在急性缺血性卒中中，不可逆损伤的组织区域（**核心**）周围是一圈灌注不足但仍存活的组织（**半暗带**）。若不再灌注，核心会在数分钟至数小时内向半暗带扩展，速度取决于侧支循环。因此，恢复血流的获益随时间稳步下降。一个被广泛引用的估计是：典型的大血管缺血性卒中每未治疗一分钟，就损失约190万个神经元。
:::

::: proof 为什么有些人在24小时仍能获益
核心扩展的速度因人而异。**侧支循环**良好的人，邻近动脉通过软脑膜吻合供应该区域，可以在许多小时内保留较大的半暗带（“慢进展者”）。侧支循环差的人在最初一两个小时内就失去了该区域的大部分（“快进展者”）。因此，发病后的时钟时间只是真正问题的替代指标，真正的问题是还剩多少可挽救的组织。CT灌注或MRI可以直接估计核心和半暗带。2018年发表的试验（DAWN和DEFUSE 3）利用这种影像，在最后正常时间后6至24小时之间筛选出核心小、错配大的患者，显示取栓的获益很大。同样的逻辑也是用MRI治疗部分醒后卒中（发病时间不明）的依据。
:::

### 识别与初步评估

公众宣传教授**FAST**（面部、手臂、言语、时间——拨打999）。急救人员使用结构化工具，救护车直接把疑似卒中患者送往超急性期卒中单元。到达后，团队确认缺损，测血糖，记录**最后正常时间**（而不是被发现的时间），核查是否使用抗凝药，并用**美国国立卫生研究院卒中量表（NIHSS）**评估严重程度，这是一个0–42分的量表，各团队把它作为共同的“通用货币”。只有血氧饱和度低时才给氧。经口给予任何东西之前先进行吞咽筛查。

第一项影像检查是头颅**平扫CT**，用于排除出血。从主动脉弓到颅顶的**CT血管成像**可以识别可能取出的大血管闭塞，在可能适合取栓时于同一次检查中完成。患者就诊晚或发病时间不明时，加做**CT灌注**或MRI。

### 溶栓

**静脉溶栓**使用重组组织型纤溶酶原激活剂溶解血栓。阿替普酶最先获批；NICE技术评估TA990（2024年7月）推荐**替奈普酶**作为阿替普酶的替代，用于症状发作4.5小时内。替奈普酶单次静脉推注给药，而不是推注后再输注一小时，这简化了治疗和转运。剂量按体重计算，来自现行处方集和当地方案。

核心规则是：

- 在影像排除出血后，于最后正常时间起**4.5小时**内治疗；
- 越早越好：3小时内的获益大约是3至4.5小时之间的两倍；
- 对部分超过4.5小时或醒后发现症状的人，高级影像（MRI或灌注成像）可识别可挽救的组织，专科医生可以给予治疗；
- 主要风险是**症状性颅内出血**，发生于百分之几的治疗患者；
- 重要的禁忌证包括影像上有出血、活动性出血、近期大手术或头部外伤、治疗性抗凝，以及治疗前血压无法降至约185/110 mmHg以下。

### 取栓

**机械取栓**是在影像引导下经股动脉或桡动脉送入支架取栓器或抽吸导管，取出血栓。2015年同时发表的五项试验表明，它能大大改善前循环大血管闭塞患者的结局。对这些试验的汇总分析（HERMES，2016年）发现，治疗组90天时功能独立的比例为46%，对照组为26.5%。

在英国指南（NICE NG128）中，对既往功能良好者，近端前循环闭塞在发病6小时内给予取栓，6至24小时之间影像显示有可挽救组织时也给予取栓；后循环（基底动脉）闭塞在24小时内可考虑取栓。若患者同时符合两种治疗条件，则溶栓与取栓一并进行；不应为了观察溶栓是否有效而推迟取栓。2022年以来发表的试验已把获益扩展到部分已有大面积梗死的患者和基底动脉闭塞患者，指南仍在演变。

::: example 早餐时被发现的男人 {#ex-acute}
一位74岁男性，最后被看到正常是在06:10，当时妻子听见他去卫生间。07:30妻子发现他瘫坐在厨房桌旁，不能说话，右侧口角下垂，右臂不能活动。急救人员于08:15把他送到超急性期卒中单元。血糖6.4 mmol/L。血压172/94 mmHg。NIHSS 19分。未服用抗凝药。CT未见出血。CT血管成像显示左侧M1段闭塞。
::: solution
1. **综合征。** 失语、右侧面部和上肢无力、NIHSS高：左侧MCA综合征。M1闭塞证实为大血管闭塞。
2. **时钟。** 最后正常时间是06:10，而不是07:30。4.5小时溶栓时间窗截止于$06{:}10 + 4{:}30 = 10{:}40$。他目前处于发病后2小时5分钟，完全在窗内。
3. **溶栓。** 无出血，血糖正常，血压低于185/110 mmHg，未用抗凝药：符合条件。应立即开始治疗。
4. **取栓。** 6小时内的近端前循环闭塞：他也应直接接受取栓，而不是等待观察溶栓是否有效。若本院不能开展取栓，立即安排转运到最近的中心。
5. **沟通。** 失语并不意味着他缺乏决策能力，但会使评估困难；若他无法参与决策，则按其最佳利益进行治疗，并告知其妻子。见[[medical-ethics-law/consent-capacity]]。

之后他在卒中单元接受管理：溶栓后24小时内血压维持在180/105 mmHg以下，吞咽筛查，神经系统观察，24小时复查CT后再开始抗血小板治疗。
:::
:::

### 最初几天：卒中单元

在**卒中单元**（配有专科多学科团队的专门病房）接受治疗，能降低所有类型卒中的死亡和依赖，是适用范围最广的单项治疗。其常规内容包括吞咽评估和营养、体位摆放和早期活动、预防吸入性肺炎、监测血糖、体温和血氧、对不能活动的患者使用间歇充气加压装置预防静脉血栓栓塞、排泄护理，以及物理治疗、作业治疗和言语治疗评估。

对未接受溶栓的缺血性卒中，一旦排除出血即开始**阿司匹林**，持续两周，之后开始长期抗栓治疗。60岁以下的大面积MCA梗死患者可能发生危险的水肿（恶性MCA梗死），应尽早转诊考虑**去骨瓣减压术**。

::: warning 急性缺血性卒中时不要激进降压
在急性缺血性卒中中，半暗带依赖灌注压，因为受损血管已无法自动调节。大幅降压会使梗死扩大。因此，只有在血压非常高、有其他指征（如主动脉夹层或心力衰竭），或在溶栓前后（溶栓前降至185/110 mmHg以下，溶栓后最初24小时维持在180/105 mmHg以下）时才降压。脑出血则不同，见下文；第一次CT决定适用哪条规则。
:::

## 短暂性脑缺血发作

TIA是一个警告：卒中风险在最初几天最高。英国现行指南（NICE NG128）要求，对过去7天内疑似TIA的任何人，除非有禁忌，立即给予**阿司匹林**，并在发病后**24小时**内安排专科评估。ABCD2等评分已不再推荐用于决定紧急程度，因为它们会漏掉心房颤动和颈动脉狭窄等重要病因。

评估包括脑影像（需要确定供血区或排除类似疾病时，行含弥散加权成像的MRI）、颈动脉影像、心电图，以及在病因不明时进行延长的心脏监测以寻找阵发性心房颤动。对小卒中或高危TIA患者，短期**双联抗血小板治疗**（阿司匹林加氯吡格雷，通常21天，在24小时内开始）可降低早期复发，代价是出血轻度增加；这基于CHANCE（2013年）和POINT（2018年）等试验。

::: example 一次失明和一条狭窄的动脉 {#ex-carotid}
一位67岁女性吸烟者，昨天左眼出现10分钟无痛性视力丧失，“像拉下了一块遮光帘”，之后完全恢复。今天查体正常。颈动脉超声显示左侧颈内动脉狭窄80%。
::: solution
1. **解读。** 短暂性单眼黑矇（**一过性黑矇**）是视网膜TIA，由栓子进入眼动脉或视网膜中央动脉（颈内动脉的分支）引起。同侧严重狭窄很可能是栓子来源。这是“症状性”狭窄。
2. **风险。** 症状性颈动脉狭窄后的卒中风险在最初数天和数周最高。
3. **治疗。** 现在开始抗血小板治疗和高强度他汀，并提供戒烟支持。在英国指南中，症状性狭窄50%–99%（按NASCET标准）的患者应在一周内评估是否行**颈动脉内膜剥脱术**，并在症状出现后两周内手术，因为手术获益随延误迅速下降。颈动脉支架置入术是部分患者的替代选择。
4. **类似疾病与其他事项。** 50岁以上视力丧失者都应考虑巨细胞动脉炎（询问头痛和下颌跛行，检查炎症指标）。评估血压、血脂和糖尿病，并根据DVLA规定建议她在评估前不要驾驶。
:::
:::

## 脑出血

**脑出血（ICH）**约占卒中的10%–15%，但在死亡中所占比例更大。常见病因包括长期**高血压**（深部出血，位于基底节、丘脑、脑桥或小脑）、**脑淀粉样血管病**（老年人的脑叶出血）、**抗凝治疗**，较少见的有血管畸形、肿瘤和可卡因等药物。没有影像就无法把它与缺血性卒中区分开。

::: definition 脑出血的急性处理 {#def-ich}
截至2026年，急性处理原则为：

1. 紧急**逆转抗凝**。华法林用凝血酶原复合物和静脉维生素K；达比加群用依达赛珠单抗；Xa因子抑制剂用凝血酶原复合物，或在当地政策支持时用特异性逆转剂（andexanet alfa）。
2. 对发病6小时内就诊、收缩压150–220 mmHg的患者**降低血压**。NICE NG128（2022年更新）建议把收缩压降至140 mmHg或以下，同时确保治疗开始后第一小时内下降幅度不超过60 mmHg。
3. 对有脑积水（常由小脑或脑室内出血引起）或大的小脑血肿压迫脑干的患者，**转诊神经外科**；对大多数幕上出血，手术尚未显示明确获益。
4. 与缺血性卒中一样的卒中单元治疗，用**间歇充气加压装置**预防静脉血栓栓塞。
5. 尽早与患者和家属坦诚讨论预后和治疗目标，但不过早限制治疗。
:::

这些要素共同构成一个“ABC”诊疗集束（逆转抗凝、降低血压、神经外科诊疗路径），在英国索尔福德引入后与死亡率降低相关。

## 蛛网膜下腔出血

大多数自发性**蛛网膜下腔出血（SAH）**来自Willis环或其附近囊状（“浆果样”）**动脉瘤**的破裂。典型表现是**霹雳样头痛**：约一分钟内达到最大强度的剧烈头痛，常被描述为一生中最严重的头痛，有时伴呕吐、颈强直、短暂意识丧失或癫痫发作。有些人在数天前有一次较小的“前哨”出血。

英国指南（NICE NG228，2022年）建议尽快行**头颅CT**。头痛发作6小时内完成的CT灵敏度很高；若6小时内CT正常，应考虑其他诊断。若CT在6小时后完成且正常，则考虑在发病至少12小时后行**腰椎穿刺**，寻找**黄变**（血红蛋白分解产生的黄色色素）。随后用CT血管成像寻找动脉瘤。

治疗旨在通过处理动脉瘤防止再出血，通常采用**血管内弹簧圈栓塞**（自2002年ISAT试验以来，在可行时首选）或手术**夹闭**。**尼莫地平**可降低**迟发性脑缺血**导致不良结局的风险，迟发性脑缺血通常发生在第4至14天。其他并发症包括脑积水、癫痫发作和低钠血症。突发头痛的总体处理思路见[[nervous-system/headache-pain]]。

::: example 健身房里的头痛 {#ex-sah}
一位46岁女性举重时突然出现爆炸样枕部头痛，数秒内达到高峰。她呕吐两次。3小时后到达医院时，GCS 15分，颈强直，无局灶体征。头颅CT显示基底池积血。
::: solution
1. **诊断。** 霹雳样头痛伴基底池积血：蛛网膜下腔出血，最可能为动脉瘤性。
2. **立即措施。** 转诊神经外科；CT血管成像寻找动脉瘤；镇痛和止吐；停用所有抗栓药物；开始尼莫地平；监测神经系统状况、血钠和液体平衡。
3. **确定性治疗。** 尽早处理动脉瘤，通常采用弹簧圈栓塞，以防再出血，再出血死亡率很高。
4. **警惕并发症。** 病情恶化可能由再出血、脑积水（需脑室引流）或第4至14天之间的迟发性脑缺血引起。低钠血症常见。
5. **远期。** 许多幸存者即使“恢复良好”，仍有疲劳、记忆和情绪问题，随访应包括这些问题，以及驾驶建议、戒烟和血压管理。
:::
:::

## 二级预防与康复

::: definition 缺血性卒中或TIA后的二级预防 {#def-prevention}
目标是通过针对机制和危险因素降低再发风险：

- **抗栓治疗。** 在英国，氯吡格雷是缺血性卒中后常用的长期抗血小板药。对**心房颤动**，用口服抗凝药（通常为直接口服抗凝药）替代抗血小板药。2023–2024年发表的试验（ELAN、TIMING和OPTIMAS）支持根据梗死大小，比以往惯例更早开始抗凝。
- **血压。** 2023年《国家卒中临床指南》建议大多数人的收缩压目标低于130 mmHg，严重双侧颈动脉狭窄者除外。
- **血脂。** 高强度他汀，如需达到目标，再加用其他降脂治疗。
- 对症状性狭窄行**颈动脉血运重建**，如[[#ex-carotid]]。
- **生活方式。** 戒烟、规律体力活动、健康饮食、适量饮酒和体重管理；控制糖尿病。
:::

恢复在最初数周和数月最快，由脑可塑性和康复推动。康复以目标为导向，由多学科完成：物理治疗改善运动和平衡，作业治疗改善日常活动，言语治疗改善交流和吞咽，心理支持应对卒中后常见的抑郁、焦虑、疲劳和认知问题。卒中和TIA后适用驾驶规定（英国由DVLA制定）。远期结局常用**改良Rankin量表**记录，从0（无症状）到6（死亡）。

::: example 卒中后的心房颤动 {#ex-af}
一位78岁女性，有高血压和2型糖尿病，从一次小的左侧MCA梗死中恢复良好。监测显示阵发性心房颤动。她的估算肾小球滤过率为52 mL/min/1.73 m²。她的CHA₂DS₂-VASc评分是多少？抗栓管理的原则是什么？
::: solution
CHA₂DS₂-VASc计分：充血性心力衰竭1分，高血压1分，年龄≥75岁2分，糖尿病1分，卒中/TIA/血栓栓塞2分，血管疾病1分，年龄65–74岁1分，女性1分。

她的评分：高血压1 + 年龄≥75岁2 + 糖尿病1 + 卒中2 + 女性1 = **7**。

她再发卒中的风险高，有抗凝指征（英国指南，NICE NG196）。通常选择直接口服抗凝药，剂量根据产品说明书和现行处方集按肾功能和年龄调整。除非有单独指征，不再同时使用抗血小板药。评估出血风险（例如用ORBIT评分）是为了发现未控制的血压等可改变的危险因素，而不是为了停用抗凝。
:::
:::

::: quiz
一位68岁男性在左侧无力发作2小时后到达。NIHSS 14分。CT未见出血。他因心房颤动服用华法林，INR 2.6。CT血管成像显示右侧M1闭塞。最合适的下一步是什么？
- [ ] 静脉溶栓，因为他在4.5小时内
- [ ] 用凝血酶原复合物逆转华法林，然后溶栓
- [x] 不溶栓，直接进行机械取栓
- [ ] 开始阿司匹林并收入卒中单元
::: solution
治疗性抗凝（多数方案中INR高于1.7）是溶栓的禁忌证，不推荐为溶栓而逆转华法林。抗凝不妨碍取栓，而他是6小时内的近端前循环闭塞，因此取栓是正确的治疗。单用阿司匹林会使他失去一种有效的治疗。
:::
:::

::: history
20世纪50年代，在波士顿工作的C·米勒·费希尔（C. Miller Fisher）描述了短暂性脑缺血发作、颈动脉疾病的作用和腔隙综合征，把卒中从模糊的“中风”变成了一组机制。1991年，北美症状性颈动脉内膜剥脱术试验（NASCET）和欧洲颈动脉外科试验确立了手术对严重症状性狭窄的获益。1995年，NINDS试验显示3小时内静脉注射阿替普酶可改善结局，2008年ECASS III把时间窗延长到4.5小时。国际蛛网膜下腔动脉瘤试验（2002年）确立了弹簧圈栓塞的地位。2015年，五项随机试验（MR CLEAN、ESCAPE、EXTEND-IA、SWIFT PRIME和REVASCAT）证明了取栓的获益，2018年DAWN和DEFUSE 3把它扩展到24小时。
:::

## 后续内容

这些综合征背后的血管解剖见[[anatomy/neuroanatomy]]，用于定位的运动和感觉体征见[[nervous-system/motor-systems]]和[[nervous-system/sensory-systems]]。血管性痴呆是小血管病的累积效应，见[[nervous-system/dementia-neurodegeneration]]。心房颤动见[[cardiovascular/arrhythmias]]，抗凝药见[[blood/thrombosis-anticoagulation]]。

::: summary
- 约85%的卒中为缺血性；其余为脑出血或蛛网膜下腔出血。只有影像能区分缺血性卒中和脑出血。
- TIA的定义取决于有无梗死，而不是持续时间。立即给予阿司匹林，并在24小时内安排专科评估。
- 供血区：MCA（面部和上肢，失语或忽视）、ACA（下肢）、PCA（视野缺损）、腔隙（纯运动或纯感觉，无皮质体征）、后循环（眩晕、复视、共济失调、交叉性体征）。
- 时间就是大脑：核心向半暗带扩展。在最后正常时间起4.5小时内给予溶栓（阿替普酶或替奈普酶）；近端前循环闭塞在6小时内取栓，经影像筛选可延至24小时。
- 卒中单元治疗降低所有类型卒中的死亡和依赖。
- 脑出血时：逆转抗凝，把收缩压降至140 mmHg或以下且第一小时下降不超过60 mmHg，把脑积水和大的小脑出血转诊神经外科。
- 霹雳样头痛需要CT；6小时内的CT灵敏度很高；否则在发病至少12小时后行腰椎穿刺。处理动脉瘤并给予尼莫地平。
- 二级预防以机制为基础：抗血小板或抗凝，多数人收缩压低于130 mmHg，高强度他汀，有指征时行颈动脉手术，以及改变生活方式。
:::

## 习题

::: exercise 溶栓截止时间 {level=1}
一位女性最后被看到正常是在21:40。23:10被发现右侧严重偏瘫。溶栓必须在几点之前开始才能在4.5小时内？
::: solution
时钟从最后正常时间21:40开始，而不是被发现的时间。$21{:}40 + 4{:}30 = 02{:}10$，即次日凌晨。实际上目标是尽快治疗，入院至溶栓时间应远少于一小时。
:::
:::

::: exercise 说出动脉 {level=1}
说出最可能闭塞的动脉：(a) 右下肢无力，上肢轻微无力；(b) 左侧同向偏盲伴黄斑回避，无无力；(c) 右侧面部和上肢无力伴表达性失语；(d) 左侧面部、上肢和下肢的纯运动性无力。
::: solution
(a) 左侧大脑前动脉。(b) 右侧大脑后动脉。(c) 左侧大脑中动脉（上干）。(d) 供应右侧内囊的小穿支动脉（腔隙性梗死）。
:::
:::

::: exercise CHA₂DS₂-VASc评分 {level=1 check="6"}
计算一位70岁男性的CHA₂DS₂-VASc评分，他有高血压、心力衰竭、糖尿病和既往TIA。
::: solution
心力衰竭1 + 高血压1 + 年龄65–74岁1 + 糖尿病1 + TIA 2 = 6。（男性计0分。）
:::
:::

::: exercise 取栓的需治人数 {level=2 check="5.1"}
在HERMES汇总分析中，取栓治疗组46.0%、对照组26.5%的患者在90天时功能独立（改良Rankin 0–2分）。多一个人功能独立的需治人数是多少？保留一位小数。
::: solution
绝对风险差 $= 0.460 - 0.265 = 0.195$。NNT $= 1/0.195 = 5.13$，保留一位小数为5.1。每治疗约五个人，就有一个人获得了原本不会有的功能独立，这是医学中最大的治疗效应之一。
:::
:::

::: exercise 出血后的血压 {level=2}
一位63岁男性在左侧无力发作2小时后就诊。CT显示右侧壳核出血。血压210/115 mmHg。未服抗凝药。描述血压目标，并解释为什么与缺血性卒中不同。
::: solution
他在6小时内就诊，收缩压在150至220 mmHg之间，因此建议快速降压。NICE的目标是收缩压140 mmHg或以下，且第一小时下降不超过60 mmHg；因此第一小时从210降到约150 mmHg就是限度，之后再进一步降低，目标维持至少7天。在出血中，高血压与血肿扩大相关，会使结局恶化，而周围组织并不像缺血性卒中那样依赖半暗带。相反，在缺血性卒中中，降压会减少半暗带的灌注并使梗死扩大，这就是规则相反的原因。
:::
:::

::: exercise 这是TIA吗？ {level=2}
一位58岁男性昨天左手麻木无力30分钟，现已完全缓解。含弥散加权成像的MRI显示右侧中央前回有一个小的急性梗死灶。这是TIA吗？答案如何影响处理？
::: solution
不是。按以组织为基础的定义，影像上有急性梗死，这就是一次小的缺血性卒中，无论症状多么短暂。最初几天的处理非常相似：紧急查明机制（颈动脉影像、心电图和心脏监测、血液检查）、抗血小板治疗（若早期开始，小卒中可短期使用双联抗血小板治疗）、他汀和危险因素控制。这一区分对驾驶规定和诊断记录很重要，也提醒临床医生：症状持续时间不能很好地反映组织损伤。
:::
:::

::: exercise 并非卒中的“卒中” {level=3}
一位34岁的1型糖尿病女性因突发右侧无力和意识模糊被送来。丈夫说她注射胰岛素后没吃午饭。NIHSS 9分。列出首先要做的三件事，并讨论鉴别诊断中哪些情况会改变处理。
::: solution
第一，立即测指尖血糖：低血糖可引起局灶性无力，几分钟内即可纠正。第二，评估气道、呼吸和循环，记录最后正常时间。第三，若血糖正常（或纠正后缺损仍持续），紧急按卒中路径进行：CT和CT血管成像，并作出溶栓决定。鉴别诊断包括低血糖（在作出任何溶栓决定之前纠正血糖并重新评估）、伴Todd瘫痪的癫痫发作（目击抽搐、咬舌，之后行脑电图）、有先兆偏头痛（既往类似发作史、逐渐扩展的阳性症状），以及青年人典型病因所致的卒中，如动脉夹层（颈痛、近期外伤）或心源性栓塞（包括经卵圆孔未闭的反常栓塞）。青年人卒中还应考虑药物使用、血管炎和易栓状态。
:::
:::

::: exercise 规划卒中服务 {level=3}
某农村地区有一家能开展溶栓的医院，取栓中心距离90分钟车程。运用[[#thm-time]]的思路，讨论把疑似大血管闭塞患者直接送往取栓中心（“母舰”模式）与先送最近的医院溶栓（“溶栓后转运”模式）之间的利弊权衡。
::: solution
溶栓有时间紧迫性，越早效果越好；把所有人都送往远处的中心，会延误没有大血管闭塞者的溶栓，而这些人占大多数，溶栓是他们唯一的再灌注治疗。对大血管闭塞而言，取栓比溶栓更有效，其获益同样随时间下降，因此先在当地医院停留再转运所带来的额外延误（包括安排转运的时间，常在一小时以上）可能会损失脑组织。答案取决于急救人员在到院前识别大血管闭塞的能力（院前量表的准确性有限）、转运时间、当地医院的“进门到出门”时间，以及影像和远程医疗的可及性。许多地区采用就近中心快速影像溶栓、确认闭塞后立即转运的模式，并审计“进门到出门”时间。公平性同样重要：农村患者和远离中心的人不应系统性地获得更差的服务。
:::
:::
