几乎每个人都头痛过，大多数头痛无害。仅偏头痛一项，一生中约每五名女性和每十五名男性中就有一人受其影响，世界卫生组织的全球疾病负担研究把它列为伤残生命年的主要原因之一。然而，有一小部分头痛是某种危险情况的最初征象：出血、感染、肿瘤或动脉炎症。临床医生的工作有两部分：识别并妥善治疗常见的原发性头痛，以及找出少数需要紧急处理的继发性头痛。

本章介绍疼痛的生物学、原发性头痛（偏头痛、紧张型头痛和丛集性头痛）、继发性头痛的警示征象、药物过度使用性头痛，以及慢性疼痛的处理原则。分类遵循《国际头痛疾病分类》第3版（ICHD-3，2018年）；英国的处理遵循NICE CG150（《12岁以上人群的头痛》）、NICE关于偏头痛新药的技术评估，以及NICE NG193（《慢性疼痛》，2021年）。

## 疼痛通路及其调控

::: definition 疼痛的种类 {#def-pain}
国际疼痛研究协会（IASP，2020年）将**疼痛**定义为一种与实际或潜在的组织损伤相关、或类似于此相关的不愉快的感觉和情绪体验。按机制分为三种类型：

- **伤害感受性疼痛**源于非神经组织的实际或潜在损伤及伤害性感受器的激活（例如骨折、关节炎或阑尾炎）。
- **神经病理性疼痛**由躯体感觉神经系统的病变或疾病引起（例如带状疱疹后神经痛、痛性糖尿病神经病变、三叉神经痛）。
- **伤害可塑性疼痛**源于伤害感受的改变，但没有明确的组织损伤证据，也没有躯体感觉系统病变的证据（例如纤维肌痛和许多形式的慢性原发性疼痛）。

**慢性疼痛**是指持续或反复超过3个月的疼痛。
:::

伤害性信号经Aδ和C纤维传至后角，再经脊髓丘脑束传至丘脑和皮质，见[[nervous-system/sensory-systems]]。脑并不只是被动接收这些信号，它还调控这些信号。

::: theorem 疼痛在每一层面都受到调制 {#thm-modulation}
疼痛的强度并不由损伤的大小决定。在后角，来自粗大触觉纤维的输入减少细纤维伤害性输入的传递（Melzack和Wall于1965年提出的**闸门控制**思想），这就是揉一揉撞到的肘部会有帮助的原因。来自中脑导水管周围灰质和延髓头端腹内侧区的下行通路，借助内源性阿片肽、5-羟色胺和去甲肾上腺素，可以抑制或易化后角的传递。注意、情绪、信念和预期作用于这些通路。持续的伤害性输入可使后角神经元兴奋性增高（**中枢敏化**），于是疼痛扩散，轻触变得疼痛，疼痛在病因消失后仍持续。
:::

这一原理解释了若干临床事实：同样的损伤，在恐惧或情绪低落的人身上更痛；升高去甲肾上腺素的抗抑郁药（阿米替林、度洛西汀）对某些慢性疼痛有效；安慰剂反应是真实且可测量的；而用越来越大剂量的阿片类药物治疗慢性疼痛往往失败。

## 原发性头痛

**原发性头痛**本身就是一种疾病。**继发性头痛**由另一种疾病引起，如出血或感染。

### 偏头痛

::: definition 偏头痛（ICHD-3） {#def-migraine}
**无先兆偏头痛**的诊断需要至少五次发作，每次持续4–72小时（未治疗或治疗无效），并且：

- 至少具备下列两项：单侧；搏动性；中度或重度；日常体力活动（如走路或上楼梯）使其加重或因此回避日常活动；
- 且至少具备下列一项：恶心和/或呕吐；同时畏光和畏声。

**有先兆偏头痛**的发作包括完全可逆的视觉、感觉、言语或其他神经系统症状，典型地在5分钟或更长时间内逐渐扩展，每种症状持续5–60分钟，通常随后出现头痛。最常见的先兆是视觉先兆：闪烁的锯齿状线条（城垛样光谱）或逐渐扩大的盲点（暗点）。

**慢性偏头痛**是指每月15天或以上有头痛，持续超过3个月，其中每月至少8天具有偏头痛特征。
:::

::: proof 偏头痛为什么痛，先兆如何扩展
现在认为偏头痛是脑兴奋性的疾病，而不仅仅是血管的疾病。**先兆**对应于**皮质扩散性去极化**：一种神经元和胶质细胞强烈去极化、随后活动受抑制的缓慢移动波，以约每分钟3–5 mm的速度跨越皮质。当它穿过视皮质时，闪烁的边缘在视野中移动，这就是先兆在数分钟内扩展的原因。**头痛**来自**三叉神经血管系统**的激活：三叉神经的感觉纤维支配脑膜及其血管。激活时它们释放神经肽，尤其是**降钙素基因相关肽（CGRP）**，使脑膜血管扩张，并使脑干和上颈髓的三叉神经通路敏化。这种敏化解释了为什么头痛呈搏动性、活动时加重，以及为什么头皮会变得触痛（皮肤痛觉超敏）。阻断CGRP或其受体的治疗可以减少发作，证实了这一通路的作用。
:::

偏头痛常有家族性，发作可由睡眠改变、漏餐、应激（及应激解除）、月经、酒精和脱水诱发，但人们常把发作过多地归咎于食物。许多发作在疼痛前数小时以**前驱期**开始，表现为打哈欠、渴望某些食物或情绪改变。

**急性期治疗**（NICE CG150）是曲坦类药物联合NSAID或对乙酰氨基酚，必要时加止吐药；在发作早期服用。**曲坦类**是5-羟色胺5-HT1B/1D受体激动剂；它们收缩脑膜血管并抑制CGRP释放。冠状动脉或脑血管疾病患者应避免使用。不推荐用阿片类药物治疗偏头痛。较新的急性期药物包括**吉泮类**（小分子CGRP受体拮抗剂，如瑞美吉泮）和**拉米地坦**（5-HT1F激动剂）；在英格兰，NICE推荐在至少两种曲坦类无效或不适用时，用瑞美吉泮进行急性期治疗。

当发作频繁或致残时，考虑**预防性治疗**。英国实践中的选择包括普萘洛尔、阿米替林、托吡酯和坎地沙坦（超说明书使用）。**托吡酯**有致畸性，自2024年起MHRA要求对可能怀孕的女性实施妊娠预防计划。对至少三种预防药物失败者，NICE推荐抗CGRP单克隆抗体（erenumab、fremanezumab、galcanezumab）和口服吉泮类瑞美吉泮和阿托吉泮，并推荐用**A型肉毒毒素**注射治疗慢性偏头痛。生活方式措施（规律睡眠和进餐、运动、限制咖啡因）和**头痛日记**是所有这些治疗的基础。剂量和适用条件遵循现行处方集和NICE技术评估。

有先兆偏头痛与缺血性卒中风险的适度增加相关，根据英国避孕方法医学适用标准，有先兆偏头痛的女性不使用复方激素避孕。

::: example 头痛前的锯齿线 {#ex-migraine}
一位23岁华裔女大学生描述她每月约发作两次。每次开始时，视野中心附近出现一个小的闪烁点，约20分钟内慢慢扩大成闪烁的锯齿状弧线，然后消退；有时麻刺感在10分钟内从手指向上扩展到面部。一小时内随之出现左侧或右侧的搏动性头痛，伴恶心，她不得不在暗室里躺上一整天。查体正常。她在服用复方口服避孕药，询问发作时可以吃什么药。
::: solution
1. **诊断。** 完全可逆的视觉和感觉症状，在5分钟或更长时间内逐渐扩展，每种持续5–60分钟，随后出现典型的偏头痛性头痛：**有先兆偏头痛**（ICHD-3）。逐渐扩展、阳性症状（闪烁、麻刺）以及麻刺感从手向面部的扩展，把先兆与TIA区分开来；TIA起病突然，通常引起阴性症状（视力或感觉丧失）。
2. **无危险信号。** 发作模式刻板且由来已久，查体正常，因此不需要影像检查。
3. **避孕。** 有先兆偏头痛的女性不使用复方激素避孕（英国避孕方法医学适用标准，第4类），因为会额外增加缺血性卒中风险。应为她提供单纯孕激素或非激素避孕方法。
4. **急性期治疗。** 头痛开始时服用曲坦类联合NSAID或对乙酰氨基酚（在先兆期间服用曲坦类无效），必要时加止吐药。她应把急性期治疗限制在每月少于10天。
5. **预防。** 每月两次发作，除非发作致残或急性期治疗失败，否则预防性治疗并非必需；头痛日记将指导决策。
:::
:::

### 紧张型头痛

**紧张型头痛**是最常见的头痛。它是双侧的，呈压迫或紧箍感（“头上像箍了一条带子”），轻至中度，日常活动不加重，无恶心（但可有畏光或畏声之一）。发作性紧张型头痛只需简单镇痛和安慰。频发或慢性紧张型头痛可能需要预防性治疗（NICE CG150建议考虑一个疗程的针灸），并关注药物过度使用、睡眠、情绪和姿势。

### 丛集性头痛与三叉自主神经性头痛

::: definition 丛集性头痛 {#def-cluster}
**丛集性头痛**表现为眼眶周围或眼后、颞部严格单侧的重度或极重度疼痛发作，未治疗时持续15–180分钟，发作频率从隔日一次到每日八次。每次发作伴有至少一项同侧自主神经症状（眼红或流泪、鼻塞或流涕、眼睑水肿、前额出汗、瞳孔缩小或眼睑下垂），和/或坐立不安或激越。发作常在一天中的同一时间出现，常使患者从睡眠中痛醒，并以持续数周至数月的**丛集期**出现，其间以数月或数年的缓解期相隔。
:::

丛集性头痛在男性和吸烟者中更常见。发作时患者踱步、摇晃，甚至用头撞物，与偏头痛患者静卧于暗室形成对比。急性期治疗（NICE CG150）是经非重复呼吸面罩给予**高流量100%氧气**，和/或皮下注射或鼻喷曲坦类药物。**维拉帕米**是主要的预防药物，需心电图监测，因为它可引起心脏传导阻滞。其他三叉自主神经性头痛，如阵发性偏侧头痛（对吲哚美辛完全有效），较为少见。

**三叉神经痛**不是头痛，而是面痛：在三叉神经一个或多个分支（通常为上颌支或下颌支）分布区内的短暂电击样疼痛，由触摸、咀嚼、说话或冷风诱发。卡马西平是一线药物。年轻患者、双侧疼痛或有感觉缺失者需要MRI，以寻找多发性硬化或肿瘤。

::: example 夜夜发作的眼痛 {#ex-cluster}
一位38岁男性，每天吸烟20支，三周来每晚约凌晨2点被右眼后方的剧痛痛醒。每次持续约45分钟。发作时他右眼流泪发红，右侧流涕，在屋里走来走去，无法安静。两年前他有过一次类似的六周发作期。
::: solution
1. **特征。** 严格单侧的眼眶部疼痛，极重，持续15–180分钟，每晚同一时间发作，伴同侧自主神经症状和坐立不安，以缓解期分隔成发作期：**发作性丛集性头痛**（ICHD-3）。
2. **排除。** 包括瞳孔、眼球运动和眼底在内的查体正常。由于首次发作偶尔可由垂体或其他结构性病变模拟，通常安排脑MRI。
3. **急性期治疗。** 通过当地供氧服务安排家庭氧疗，经非重复呼吸面罩给予高流量100%氧气，并进行消防安全评估（他吸烟，因此必须明确讨论在氧气附近吸烟的问题）；以及皮下注射或鼻喷曲坦类药物。口服曲坦类起效太慢，不适合这样短的发作。
4. **预防。** 维拉帕米，由专科医生开始或在其建议下使用，需做基线心电图，并在加量时监测心电图。可用短程糖皮质激素或枕大神经阻滞作为过渡。
5. **支持。** 戒烟帮助，以及关于该病的信息；丛集性头痛是已知最痛的疾病之一，应询问发作期间情绪低落的风险。
:::
:::

## 继发性头痛：找出少数危险病例

大多数头痛患者不需要影像检查。病史和查体的目的是找出那些会提高继发性病因可能性的特征。

| 危险信号 | 可能病因 |
|---|---|
| 约一分钟内达到高峰的突发剧烈头痛（“霹雳样”） | 蛛网膜下腔出血、可逆性脑血管收缩、动脉夹层、静脉窦血栓形成 |
| 50岁以上新发头痛，尤其伴下颌跛行、头皮触痛或视觉症状 | 巨细胞动脉炎 |
| 发热、颈强直、皮疹、意识模糊 | 脑膜炎、脑炎 |
| 进行性头痛，平卧或用力时加重，伴呕吐；视乳头水肿 | 颅内压增高：肿瘤、脑积水、特发性颅内高压、静脉窦血栓形成 |
| 新发神经功能缺损、癫痫发作、人格改变 | 肿瘤、脓肿、卒中 |
| 癌症或免疫抑制患者的头痛 | 转移瘤、机会性感染 |
| 头部外伤后的头痛，尤其在服用抗凝药时 | 硬膜下或硬膜外血肿 |
| 站立时加重、平卧时缓解的头痛 | 低颅压（腰椎穿刺后或自发性脑脊液漏） |
| 妊娠期或产褥期头痛，伴高血压 | 子痫前期、静脉窦血栓形成 |

**蛛网膜下腔出血**是霹雳样头痛中最主要的担忧。其检查（6小时内CT；若CT在6小时后完成且阴性，在发病至少12小时后行腰椎穿刺）见[[nervous-system/stroke]]。**渥太华SAH规则**帮助在意识清醒、新发剧烈头痛且一小时内达到高峰的成人中决定谁需要检查：只要存在以下任一项就需要检查：年龄40岁或以上、颈痛或颈强直、有目击的意识丧失、在用力时发作、霹雳样起病、查体颈部屈曲受限。在其验证研究中（Perry等，2017年），该规则在1,153名患者中识别出全部67例蛛网膜下腔出血，但特异度仅约14%。

**巨细胞动脉炎**见于50岁以上人群，引起新发颞部头痛、头皮触痛、下颌跛行、风湿性多肌痛症状，以及最重要的视力丧失。炎症指标通常升高。一旦怀疑就立即开始糖皮质激素，不必等待颞动脉超声或活检，因为数日内即可失明（见[[nervous-system/sensory-systems]]和[[musculoskeletal/connective-tissue-vasculitis]]）。

**特发性颅内高压（IIH）**主要见于肥胖的育龄女性，引起头痛、视乳头水肿、一过性视物模糊、搏动性耳鸣，有时有展神经麻痹。影像检查（MRI加静脉成像）除颅内压增高征象外正常，并可排除静脉窦血栓形成；腰椎穿刺显示成人初压25 cmH₂O或以上，脑脊液成分正常。主要威胁是永久性视力丧失。治疗包括减重（可以治愈）、乙酰唑胺，以及在视力受威胁时紧急手术。

::: example 头痛与视物模糊 {#ex-iih}
一位27岁女性，体重指数38 kg/m²，两个月来每天头痛，晨起和弯腰时加重。她耳中有“呼呼”声，站起时有几秒钟视物发灰。眼底检查显示双侧视盘肿胀。其余神经系统查体正常。她最近因痤疮开始口服四环素类药物。
::: solution
1. **识别颅内压增高。** 晨起和弯腰时加重的头痛、搏动性耳鸣、一过性视物模糊和双侧视乳头水肿。
2. **排除继发性病因。** 紧急行脑MRI加磁共振静脉成像，排除占位、脑积水和脑静脉窦血栓形成（后者可有完全相同的表现，需要抗凝）。
3. **腰椎穿刺。** 若影像正常，侧卧位腰椎穿刺测量初压（预期为25 cmH₂O或以上），并确认脑脊液成分正常。
4. **诊断与促成因素。** 若上述得到证实，诊断为特发性颅内高压；四环素类是公认的相关因素，应停用。
5. **处理原则。** 眼科正式评估视野和视力，并在治疗过程中复查；体重管理支持（适度减重即可诱导缓解）；许多病例使用乙酰唑胺；若视力恶化，紧急手术治疗（脑脊液分流、视神经鞘开窗术或静脉窦支架置入）。头痛本身常持续存在，可能有偏头痛成分或药物过度使用，需要单独治疗。
:::
:::

## 药物过度使用性头痛

::: definition 药物过度使用性头痛 {#def-moh}
**药物过度使用性头痛**是指原有头痛疾病的患者每月头痛15天或以上，并由规律过度使用急性期头痛药物超过3个月所致。过度使用是指每月15天或以上服用单纯镇痛药（对乙酰氨基酚、阿司匹林、NSAID），或每月10天或以上服用曲坦类、阿片类、麦角类或复方镇痛药（ICHD-3）。
:::

药物过度使用性头痛常见且常未被识别；它把发作性偏头痛或紧张型头痛转变为慢性每日头痛。阿片类和含可待因的复方制剂尤其容易引起该病。NICE CG150建议解释诊断，突然停用过度使用的药物至少一个月（必要时阿片类逐渐撤药），并告知头痛在好转之前可能会暂时加重，适当时对原发头痛疾病开始预防性治疗。

::: example 一份头痛日记 {#ex-diary}
一位44岁女教师有多年偏头痛史，说她的头痛现在“每天都有”。她过去30天的日记显示22天有头痛。她有12天服用对乙酰氨基酚，8天服用舒马普坦，9天服用可待因对乙酰氨基酚复方制剂；有些日子服用了不止一种。总计她在30天中有19天服用了某种急性期药物。
::: solution
1. **头痛频率。** 30天中22天头痛，超过每月15天：慢性每日头痛。若其中至少8天具有偏头痛特征，她也符合慢性偏头痛的标准。
2. **按类别计算用药天数。** 曲坦类天数（8天）加阿片类复方制剂天数（9天）：当这些类别合计使用达到每月10天或以上时，即使单独每类都低于10天，也作为“多类药物联合”合并计算。急性期用药总天数为30天中的19天。
3. **结论。** 她符合ICHD-3中偏头痛基础上合并药物过度使用性头痛的标准。
4. **处理原则。** 解释频繁使用急性期药物正在使头痛持续。停用过度使用的药物（若她一直大剂量服用可待因，则逐渐撤药），告知头痛可能在一到两周内加重，并开始适合她的预防药物（例如阿米替林或普萘洛尔，同时考虑她的其他疾病）。4–8周后带新的日记复诊，今后急性期治疗限制在每月少于10天。
:::
:::

::: warning 用可待因治疗头痛
可待因和其他阿片类药物是药物过度使用性头痛最常见的原因之一，英国指南不推荐用于偏头痛或紧张型头痛。人们可以在药店直接买到可待因复方制剂，因此在采集头痛病史时，一定要专门询问非处方药物。为原发性头痛开具阿片类药物，常常把一个发作性问题变成每天的问题。
:::

## 慢性疼痛

据估计，英国三分之一到一半的成人有慢性疼痛，约十分之一的人疼痛达到中度或重度致残。NICE NG193（2021年）把**慢性原发性疼痛**（疼痛本身就是疾病，例如纤维肌痛、慢性广泛性疼痛、许多原因不明的慢性腰痛）与**慢性继发性疼痛**区分开来，后者由骨关节炎、类风湿关节炎或子宫内膜异位症等另一种疾病引起，按该疾病的指南处理。

慢性原发性疼痛的处理原则是：

- 以人为中心评估疼痛如何影响生活、情绪、睡眠和工作，以及什么对患者最重要；
- **有指导的运动计划**和**心理治疗**（认知行为疗法或接纳承诺疗法），部分病例可用一个疗程的针灸；
- 在讨论获益与危害之后，可考虑一种抗抑郁药（如阿米替林、度洛西汀或选择性5-羟色胺再摄取抑制剂）；
- 对慢性原发性疼痛**不开始使用**阿片类、加巴喷丁类、NSAID、对乙酰氨基酚、苯二氮䓬类、局部麻醉药注射或氯胺酮，因为缺乏获益证据而危害已有充分记录。

**神经病理性疼痛**另行处理（NICE CG173）：阿米替林、度洛西汀、加巴喷丁或普瑞巴林为初始选择，一种无效时换用另一种；三叉神经痛用卡马西平；局限性疼痛用外用辣椒素。由于滥用以及与阿片类合用时有呼吸抑制风险，**加巴喷丁和普瑞巴林**自2019年起在英国列为管制药物。急性疼痛和术后疼痛见[[surgery/anaesthesia-pain]]。

::: quiz
一位32岁女性自青少年期起患无先兆偏头痛。过去一年头痛增加到每月约20天，她几乎每天服用一种非处方的可待因对乙酰氨基酚复方制剂。查体正常。最合适的第一步是什么？
- [ ] 脑MRI以排除肿瘤
- [ ] 在最严重的日子加用曲坦类
- [x] 解释药物过度使用性头痛，撤停可待因，并开始偏头痛预防
- [ ] 转诊进行肉毒毒素注射
::: solution
长期原发性头痛逐渐加重，伴频繁使用镇痛药且查体正常，是药物过度使用性头痛的典型表现，而不是肿瘤，因此不需要影像检查。加用曲坦类只会增加另一种被过度使用的药物。撤停过度使用的药物并配合预防性治疗是关键步骤。肉毒毒素留给在处理药物过度使用之后仍持续、且其他预防药物失败的慢性偏头痛。
:::
:::

::: history
1672年，托马斯·威利斯（Thomas Willis）提出偏头痛的疼痛源于血管扩张，这一观点在20世纪30至40年代由纽约的哈罗德·沃尔夫（Harold Wolff）通过实验加以发展。1944年，阿里斯蒂德斯·莱昂（Aristides Leão）在兔身上描述了皮质扩散性抑制；而卡尔·拉什利（Karl Lashley）早在1941年描绘自己的先兆时，就估计其扩展速度约为每分钟3 mm。迈克尔·莫斯科维茨（Michael Moskowitz）在约1979–1984年间提出了三叉神经血管学说。麦角胺由阿图尔·施托尔（Arthur Stoll）于1918年分离；第一种曲坦类药物舒马普坦于20世纪90年代初问世；第一种抗CGRP抗体erenumab于2018年获批。在疼痛科学中，罗纳德·梅尔扎克（Ronald Melzack）和帕特里克·沃尔（Patrick Wall）于1965年发表了闸门控制学说，约翰·博尼卡（John Bonica）创立了多学科疼痛门诊和IASP（1973年）。
:::

::: summary
- 疼痛是一种感觉和情绪体验；分为伤害感受性、神经病理性或伤害可塑性，并在后角和下行通路受到调制。慢性疼痛持续超过3个月。
- 偏头痛：反复发作，每次4–72小时，至少具备单侧、搏动性、中重度、活动加重中的两项，加上恶心或畏光与畏声。先兆是皮质扩散性去极化；疼痛涉及三叉神经血管系统和CGRP。
- 偏头痛急性期：曲坦类联合NSAID或对乙酰氨基酚，加止吐药；不用阿片类。预防：普萘洛尔、阿米替林、托吡酯（需妊娠预防）、坎地沙坦；三种失败后用抗CGRP抗体或吉泮类；慢性偏头痛用肉毒毒素。
- 紧张型头痛为双侧、压迫性、轻至中度。丛集性头痛为重度、单侧、眼眶部、15–180分钟，伴同侧自主神经症状和坐立不安；用高流量氧气和注射或鼻喷曲坦类治疗，用维拉帕米预防。
- 危险信号（霹雳样起病、50岁以上、发热和脑膜刺激征、颅内压增高征象、新发缺损、癌症或免疫抑制、妊娠）提示需检查继发性头痛。
- 药物过度使用性头痛：每月头痛15天或以上，单纯镇痛药15天或以上，或曲坦类、阿片类或复方制剂10天或以上。停用过度使用的药物并治疗原发疾病。
- 慢性原发性疼痛以运动、心理治疗、有时加抗抑郁药处理；不要为其开始阿片类或加巴喷丁类药物。
:::

## 习题

::: exercise 偏头痛还是紧张型头痛？ {level=1}
判断下列描述符合无先兆偏头痛还是紧张型头痛：(a) 双侧压迫性头痛，轻度，持续大半天，无恶心，能正常工作；(b) 单侧搏动性头痛持续12小时，伴恶心，想躺在暗而安静的房间里；(c) 双侧搏动性头痛，重度，上楼梯时加重，伴畏光和畏声。
::: solution
(a) 紧张型头痛。(b) 无先兆偏头痛（单侧、搏动性，伴恶心和畏光/畏声，活动加重）。(c) 偏头痛：单侧只是四项疼痛特征之一，双侧头痛只要具备另外两项（此处为搏动性、重度和活动加重），并伴畏光和畏声，就符合标准。
:::
:::

::: exercise 压力单位 {level=1 check="18.4"}
一位疑似特发性颅内高压的女性腰椎穿刺初压为25 cmH₂O。按1 cmH₂O = 0.7356 mmHg换算为mmHg，结果保留一位小数。
::: solution
$25 \times 0.7356 = 18.39$ mmHg，保留一位小数为18.4 mmHg。
:::
:::

::: exercise 计算用药天数 {level=1 check="12"}
在30天中，一名男性有9天服用布洛芬，6天服用曲坦类；其中3天两者都服用。他有多少天服用了某种急性期头痛药物？
::: solution
服用任一种的天数 $= 9 + 6 - 3 = 12$。两类单独都未达到阈值（单纯镇痛药少于15天，曲坦类少于10天），但ICHD-3还把每月合计10天或以上规律使用任何组合的急性期药物类别视为过度使用。因此，如果他每月头痛15天或以上，就符合多类药物所致药物过度使用性头痛的标准。
:::
:::

::: exercise 霹雳样头痛 {level=2}
一位52岁女性在做园艺时突然出现剧烈头痛，数秒内达到高峰。她意识清醒，无颈强直，神经系统查体正常。3小时时头颅CT正常。你如何解读？可能还需要哪些检查？
::: solution
渥太华规则阳性（年龄超过40岁、用力时发作、霹雳样起病），因此必须排除蛛网膜下腔出血。发病6小时内的现代CT经有经验的放射科医生判读，灵敏度很高，因此不常规需要腰椎穿刺（NICE NG228）。然而，CT正常并不能排除霹雳样头痛的其他病因：可逆性脑血管收缩综合征（常为反复霹雳样头痛，由用力或某些药物诱发）、颈部动脉夹层、脑静脉窦血栓形成、垂体卒中和脑出血。因此常根据临床特征行CT血管成像（必要时加MRI及静脉成像）。
:::
:::

::: exercise 预防药物的选择 {level=2}
一位29岁无先兆偏头痛女性每月发作8天，询问预防治疗。她有哮喘，计划一年内怀孕，情绪低落。讨论普萘洛尔、托吡酯和阿米替林对她是否合适。
::: solution
**普萘洛尔**是非选择性β受体阻滞剂，哮喘患者禁用，因为可引起支气管痉挛。**托吡酯**有致畸性（唇腭裂、低出生体重、可能的神经发育影响），较大剂量时还会降低激素避孕的效果；她计划怀孕，因此不合适，而且在英国，育龄女性只能在妊娠预防计划下使用。**阿米替林**常是合理的选择，尤其在伴睡眠障碍时；情绪低落应单独评估（小剂量阿米替林不能治疗抑郁，且过量时危险，因此应询问自杀风险）。坎地沙坦是另一选择，但妊娠期禁用。非药物措施和日记很重要，应建议她在受孕前复审预防治疗。
:::
:::

::: exercise 带状疱疹后的神经病理性疼痛 {level=2}
一位74岁男性在带状疱疹后四个月，右侧T6皮节区仍有烧灼痛，且对衣物接触极度敏感。对疼痛进行分类，说出你要寻找的体征，并概述药物选择及其在老年人中的主要注意事项。
::: solution
这是**带状疱疹后神经痛**，一种神经病理性疼痛（由水痘–带状疱疹病毒引起的躯体感觉系统病变）。寻找痛觉超敏（轻触引起疼痛）、痛觉过敏以及皮节内的感觉缺失区。选择（NICE CG173）：阿米替林（抗胆碱能作用如意识模糊、尿潴留和便秘；体位性低血压和跌倒；心脏传导影响）、度洛西汀（恶心、低钠血症）、加巴喷丁或普瑞巴林（镇静、头晕、跌倒，肾功能不全时减量，与阿片类合用时的呼吸抑制，滥用可能）；局限性疼痛可用外用辣椒素或利多卡因贴剂。从小剂量开始，缓慢加量，权衡获益与危害，无效的药物要停用。带状疱疹疫苗（英国为老年人提供）可降低带状疱疹和带状疱疹后神经痛的风险。
:::
:::

::: exercise 伴下颌痛的头痛 {level=3}
一位71岁女性三周来新发右侧颞部头痛，咀嚼时下颌疼痛，双肩酸痛。今晨她右眼视物模糊几分钟，现已恢复。CRP 68 mg/L。讨论诊断、紧急程度和处理原则，包括你会就治疗告诉她什么。
::: solution
可能的诊断是**巨细胞动脉炎**：50岁以上新发头痛、下颌跛行、风湿性多肌痛症状和CRP升高。一过性视力丧失（一过性黑矇）是眼部循环受威胁的不祥征象；数小时或数日内可发生永久性失明。处理（英国风湿病学会2020年指南）：立即、当天开始大剂量糖皮质激素，不等待确诊，因有视觉症状可考虑更大剂量或静脉方案；当天转诊至专科快速通道并请眼科会诊；尽快行颞动脉超声或活检（开始激素后数天内活检仍有诊断价值）。向她解释激素需要使用许多个月并缓慢减量，不能突然停药，并讨论其不良反应：骨保护（钙、维生素D，按指征使用双膦酸盐），监测血糖和血压，有指征时保护胃黏膜，以及情绪。复发或难治性病例可按NICE指南加用托珠单抗。若视觉症状再现，她应立即求助。
:::
:::

::: exercise 解读一条规则 {level=3 check="0.07"}
在某急诊科，意识清醒、急性剧烈头痛且一小时内达到高峰的成人中，6%有蛛网膜下腔出血。某决策规则的灵敏度为100%，特异度为15.2%。规则结果阳性者中真正有出血的比例是多少？结果保留两位小数，并解释这对使用该规则意味着什么。
::: solution
每1,000人中：60人有出血，60人全部阳性。940名无出血者中，$940 \times (1 - 0.152) = 797$人阳性。阳性预测值为$60/(60 + 797) = 0.070$，保留两位小数为0.07。阳性者中只有约7%有出血，但阴性者中没有一人有出血。该规则的设计目的是在少数人中（此处约14%）安全地排除出血，而不是确诊出血；阳性者仍需临床判断和检查。它的价值在于安全地让阴性者免于检查，并使诊疗规范化。
:::
:::
