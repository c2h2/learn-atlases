头痛是最常见的神经的主诉、也是这个专科最被低估的一项技能：**在几乎每一例中诊断只靠病史就能做出；危险信号是一份值得背下来的短清单；而治疗的失败更多来自“急性用药的过度使用与预防的不足”、而不是来自任何疑难的疾病。**面部疼痛又添上了三叉的综合征与牙科及鼻窦的那套产业。

本章涵盖原发头痛的疾病、继发的头痛与危险信号、三叉的与其他的面痛、以及“药物的过度使用”这个陷阱，并把镇痛的原理贯穿其中。

## 原发的头痛

::: definition 偏头痛 {#def-migraine}
**偏头痛是一种反复的、持续4到72小时的、单侧或双侧的搏动性的头痛，伴恶心与“畏光及畏声”及功能的受损、被活动加重；在“易感的基因的大脑”中由“三叉血管的与下丘脑脑干的”机制驱动（那“降钙素基因相关的肽”的故事孕育了“那类肽类的受体拮抗剂与抗体的方案”，是现代治疗学中最干净的“从实验台到病床”的弧线之一——[[pharmacology/drug-development-prescribing]]、[[genetics/common-disease-genetics]]）。患者很少主动交代的那几个时相——前驱（哈欠与情绪及“提前一天食物的改变”）、先兆10到60分钟扩散视觉的闪光与“隧道及锯齿”的现象、感觉的推进与失语，有时不伴头痛——那种让所有人（包括患者自己的全科医师都害怕的“晚年的不伴头痛的先兆”）、头痛、以及发作后（带着它的认知的宿醉与颈的僵硬——它会把检查者误导到“去找脑膜炎”——视觉皮层的力学见[[nervous-system/sensory-systems]]）。需要被命名、而不是被影像的变异——前庭的偏头痛（与眩晕的门诊的重叠——[[nervous-system/sensory-systems]]）、偏瘫的偏头痛（家族性通道病的形式，伴运动的先兆，以及那个“不要溶栓”的确定的陷阱、以及基因的三位点——[[genetics/mendelian-inheritance]]，模仿的一面见[[nervous-system/stroke]]）、“伴双侧脑干先兆的症状”的基底动脉型的偏头痛；作为“单眼视觉的丧失”的鉴别视网膜的偏头痛；儿童腹部的与周期性的呕吐以及后来的头痛的转化；以及“不伴先兆却持续的、但没有梗死的”先兆。带判断应用诊断的标准国际头痛疾病的分类“对发作的计数”本身；以及“大多数非典型的偏头痛其实是不被熟练的病史里的典型的偏头痛”这一认识；以及绝不可被归罪于偏头痛的危险信号——首次或最重或改变的头痛；40岁之后的或带卒中特征新发的先兆；体位的与用力的及咳嗽及“瓦氏动作”触发；雷击样的起病；伴发热或颈的僵硬或免疫抑制的头痛；伴视盘的水肿或进展的神经的缺损的头痛；妊娠与产后及恶性肿瘤及抗凝的背景；50岁以上伴颞部的压痛与颌的跛行（巨细胞的动脉炎——激素在活检之前；视觉的丧失只有靠速度才能预防——[[musculoskeletal/connective-tissue-vasculitis]]、[[nervous-system/neuroinflammation]]）。带分层阶梯的急性治疗——早期并以足够的剂量服用的简单的镇痛那次试验失败的教训是“大多数的患者是被治疗不足、而不是被治疗过度”；曲普坦与那两类较新的药物带它们禁忌的清单——曲普坦血管的告诫；以及“每月10天”的“药物过度使用的天花板”曲普坦与复方镇痛“、”每月15天“（简单的镇痛——冠脉的告诫见[[cardiovascular/vascular-disease]]、妊娠安全的选项见[[obstetrics-gynaecology/pregnancy-complications]]）；以及止吐药（带它的肌张力障碍与QT的告诫——[[pharmacology/adverse-reactions]]、[[gastrointestinal/oesophagus-stomach]]）。在“每月4天以上或有失能的发作”时提供的预防——β的阻滞剂与托吡酯及丙戊酸带着那如今主导这场谈话的生育的能力的限制、以及作为“便宜而有效”的经典阿米替林与坎地沙坦；“肽类的抗体与口服的拮抗剂”作为较新的靶向的一类带着它们诚实成本效果的辩论；以及“每一英镑的证据最强”的非药物那一层——睡眠的规律、运动、“把真实的模式与回忆的偏倚分开”的头痛日记、以及“为疼痛的灾难化的循环”的心理的治疗——[[psychiatry/mood-disorders]]、[[public-health/prevention-promotion]]、[[geriatrics-palliative/symptom-control]]。**
:::

## 继发的头痛与面部疼痛

::: definition 紧张型、簇集性与其他原发的 {#def-other}
**紧张型的头痛——双侧压迫的、非搏动的、轻中度的疼痛，不伴恶心允许畏光或畏声；发作的对慢性的形式在与“新发的每日持续的头痛”及“药物的过度使用”之间那条诊断的界线是模糊的；“是一个体征而不是一个原因”的颅周的肌的压痛；体位与工作负荷及压力的贡献者；以及那个治疗的悖论——简单的镇痛对发作的形式有帮助、却造成了慢性的那一种，于是留给我们诚实的工具是阿米替林的预防带着“剂量与睡眠及口干”的讨价还价与“运动与睡眠及心理”这一套，而把“肌的松弛剂与手法”的那套产业留给它的营销——颈与头痛的接口与”上颈牵涉的模式见[[musculoskeletal/back-pain]]。簇集的头痛作为神经病学中最疼痛也最被误诊的综合征——严格单侧的眶与颞的疼痛，持续15到180分钟，伴同侧自主的特征流泪与结膜的充血及上睑下垂与瞳孔的缩小及鼻涕及躁动——那个“无法躺下”的患者把它与偏头痛区分开；“带它下丘脑时钟的签名”的昼夜与年度的周期性，以及在发作期内酒精的触发；正在变窄男性的倾斜；以及“关于疼痛的严重度的自杀的风险”的诚实——风险的框架见[[psychiatry/self-harm-suicide-prevention]]、自主的解剖含霍纳见[[nervous-system/sensory-systems]]；它的急期的治疗——经“非重复吸入的面罩”以每分钟12到15升的高流量的氧气持续15到20分钟处方不足、安全、便宜、以及皮下或鼻内的舒马曲普坦带着“数小时之内两者不要一起给”的告诫与鼻的刺激这一取舍；它的预防——维拉帕米带着“心电图与便秘及抗心律失常的相互作用”这套监测的文化与激素及“枕大神经的阻滞”作为桥接、锂作为第三线带着它监测的那套编排；以及“迷走的刺激与翼腭的神经节的干预”及那具争议的下丘脑的靶点神经调控的前沿。共享簇集特征三叉自主的神经痛这一族——“阵发性偏侧的头痛”对吲哚美辛的绝对响应作为一个诊断的试验；“短时单侧的神经痛样头痛的发作”带着它们自主的泛滥与治疗的困难“；以及那”每日都对吲哚美辛有响应的“持续偏侧的头痛——脑干反射的解剖见[[nervous-system/motor-systems]]。以及公众会叫出名字原发的——用力的头痛与“伴咳嗽的头痛”要影像，因为少数藏着基亚里的畸形与后颅窝的病灶、“性行为相关的头痛”、以及“原发的咳嗽与用力及冰激凌头痛带它们血管的机制”。**
:::

::: definition 危险信号与“少数危险的” {#def-redflags}
**份“对得起它自己影像的开销”的危险信号的清单——把十项一类的教学变得可操作：全身的症状与发热、恶性肿瘤、免疫抑制、神经的缺损、视盘的水肿、突发、年长的起病、体位、“被咳嗽与用力及性诱发的”、模式的改变、“伴虹视的眼痛”、颌的跛行、头皮的触痛、颈的僵硬——每一项背后都有具名的疾病：蛛网膜下腔的出血（雷击样；“先CT然后腰穿或血管成像”的时代与“哨兵的头痛”的文献——[[nervous-system/stroke]]）、脑的静脉窦的血栓（产后与易栓及耳的感染的背景、“头痛伴视盘的水肿及发作及灶的缺损”这一组合、磁共振静脉成像的诊断、以及“即便有出血性的梗死也要抗凝”——[[nervous-system/stroke]]、[[blood/thrombosis-anticoagulation]]、[[obstetrics-gynaecology/pregnancy-complications]]）、巨细胞的动脉炎（“50岁以上紧急的颞与枕的头痛，伴头皮与颌及视觉的症状及血沉与C反应蛋白的升高”，在那儿“当天的激素能保住视力”，而超声与活检的路径跟随治疗而不是先行——[[musculoskeletal/connective-tissue-vasculitis]]）、急性的闭角与其他的眼科的病因（虹视与“疼痛的红眼”的分诊见[[nervous-system/sensory-systems]]）、自发的低颅压（“在硬膜的穿刺之后或自发的、带颈疼痛体位的头痛”、“增强磁共振上硬膜弥漫增厚的签名”、以及“血补丁”的路径——硬膜穿刺后头痛的预防与治疗见[[surgery/anaesthesia-pain]]）、脑膜炎与脑炎（“以小时计的阿昔洛韦与抗生素”的规则——[[nervous-system/neuroinflammation]]、[[infectious-diseases/fever-sepsis]]）、高血压的与子痫前期的及子痫的头痛带它们视觉的现象与“硫酸镁与抗高血压”的路径——[[obstetrics-gynaecology/pregnancy-complications]]、[[cardiovascular/hypertension]]；一氧化碳的核查清单“一个有炉道与锅炉的家庭里的多个人头痛及温暖的房间”；创伤后与脑震荡后的头痛带着它的“前庭与认知与睡眠”的集束、以及那份“回归活动而不是静养”的共识——[[emergency-critical-care/acute-assessment]]、[[musculoskeletal/back-pain]]；以及被纠正了神话的肿瘤性头痛——单独的头痛很少提示肿瘤，而危险信号就是上面；这正是“当互联网说了别的”时患者需要的安慰——[[pathology/cancer-biology]]。**
:::

::: definition 三叉神经痛与面部疼痛 {#def-facial}
**三叉神经痛——“在一支或多支三叉分支内的、由轻触与咀嚼及说话、刷牙、风吹诱发的、长达数秒电击样的疼痛”的阵发，在经典的形式中有无痛的间期与正常的检查；神经血管的压迫（通常是小脑上动脉压在“根的进入区”）伴脱髓鞘与“短路式的串扰”的病理生理学；“带方案序列的磁共振”的问题；以及在年轻与双侧的患者中的多发的硬化与病灶的继发的原因——[[nervous-system/neuroinflammation]]。治疗的阶梯——卡马西平与奥卡西平作为一线带低钠与酶的诱导及“人类白细胞抗原的定型”的告诫、以及“在无痛的间期之后缓慢地重新引入”的策略——[[pharmacology/metabolism-excretion]]，共享钠通道的逻辑见[[nervous-system/epilepsy]]；附加的药拉莫三嗪与巴氯芬，以及“被放弃的旧时代的偏方”；以及“带耐用性与麻木及复发的取舍”的操作——甘油的处理与球囊的压迫及射频的热凝及“分支的”的外周的操作及“伽玛刀的放射外科”；以及那“提供最长的无痛的间期、但带着它的开颅与被诚实地量化的稀少的严重的风险”的微血管的减压。被错标成神经痛的非典型与继发的面痛——持续特发的面痛（那“恒定的钝的、不按皮节的、对卡马西平无响应”的疼痛，需要“抗抑郁与心理”的管理与一份“放过牙医”的病史——[[geriatrics-palliative/symptom-control]]）；带状疱疹后三叉的神经痛带它带状的病史与“触发的疼痛”、以及“疫苗的适格”的谈话——[[microbiology/viruses]]、[[public-health/vaccination-programmes]]、[[immunology/vaccines-immunotherapy]]；舌咽的神经痛带它的“咽喉与耳”的触发的区与“晕倒的发作”，以及同样的手术与放射外科的考量；[[#def-other]]中“短时单侧神经痛样的”疾病；以及鼻窦与牙及“颞下颌的关节”的鉴别——上颌窦的炎带“面部为主的疼痛与窦口的病理”及“飞机诱发的压力伤”；在“三叉的地图”上被牵涉的牙与牙源的疼痛；以及颞下颌的关节的紊乱带它关节的弹响与清晨的咬紧，以及它在那个“每周都会被耳鼻喉与神经科看到鼻窦头痛的转诊中真实但被过度诊断的作用”——牵涉痛的解剖见[[nervous-system/sensory-systems]]、颈的牵涉见[[musculoskeletal/back-pain]]。**
:::

::: example 那个“伴新的找词困难”的头痛 {#ex-gca}
一名74岁的女性有3周的右侧颞部的头痛、“新发嚼吐司的困难”、梳头时头皮的发痒、以及今天早上“右眼的持续10分钟颜色视物的模糊”；血沉68，C反应蛋白42。
::: solution
**带“即将失去的眼”的巨细胞的动脉炎——在证明之前先治疗（[[#def-redflags]]、[[nervous-system/sensory-systems]]）：同一小时的动作——现在就把大剂量的激素给上去按血管炎的指导，“只被威胁的眼”用冲击静脉的甲泼尼龙，否则口服、在同一小时里给眼科与风湿科打电话；以及“激素先于活检”的记录，因为视力是在检查与检查之间失去的、从来不是因为活检做得晚——[[musculoskeletal/connective-tissue-vasculitis]]、激素的力学见[[pharmacology/dosing-principles]]；确认的路径——紧急的颞与腋的超声“光环与压闭的征象”的文献、以及那段“取很长的节段、而同时用激素并不会抹掉组织学”的活检的教导；以及“为大血管的表型”做主动脉与锁骨下的筛查——[[clinical-skills/medical-imaging]]、[[pathology/diagnostic-pathology]]；激素的战役——缓慢减量的方案带“在治疗中复发的识别”的规则、以及“风湿性多肌痛的共同处方”；以及“托珠单抗配甲氨蝶呤的背景”这一激素节约的策略带其对感染的警惕与疫苗的更新、以及在一位74岁身上的“骨与血糖及眼”的保护的包——[[endocrine/bone-calcium]]、[[endocrine/diabetes]]、[[infectious-diseases/immunocompromised-host]]；以及安全网的布置——“一旦出现视觉的症状立即回来”的指示、驾车的谈话、以及给全科医师的那封“知道动脉炎与风湿性多肌痛”的信共享减量的进度表；以及那句诚实的解释——随访的对象是另一只眼与主动脉，而不是那个头痛（[[clinical-skills/records-handover]]、[[geriatrics-palliative/symptom-control]]）。**

::: example 那个“在新药之后”的雷击样的头痛 {#ex-rcvs}
一名42岁的女性在36小时内有三次雷击样的头痛、其中一次在洗热水澡时，伴短暂视觉的扰乱；神经的检查与格拉斯哥正常；平扫的CT与腰穿正常；她开始了一种“减肥兴奋的补充剂”，并有偏头痛的病史。
::: solution
**可逆的脑血管的收缩的综合征在鉴别之列——而蛛网膜的下腔的出血与静脉窦的血栓已经被排除（[[#def-redflags]]、[[nervous-system/stroke]]）：模式——在1到3周之内反复的雷击样的头痛，最初的CT或腰穿正常；触发是洗澡与用力及情绪、以及那份“拟交感的与5-羟色胺的及大麻及选择性血清素的再摄取抑制剂”的药物清单；以及产后及“在动脉瘤的邻近”的背景；以及“节段的收缩在第二周造成卒中与凸面的蛛网膜的下腔的出血及发作”的并发症的风险——[[emergency-critical-care/poisoning]]、[[nervous-system/epilepsy]]、[[obstetrics-gynaecology/pregnancy-complications]]；检查——CT或磁共振的血管成像显示“多灶节段的狭窄”带着“最初的血管的影像可以正常——因为早期的远端的受累会藏起来，所以重复的影像很重要”这条告诫；以及“为血管炎与嗜铬细胞瘤及脑后的可逆的白质的病变”的完整继发排除的清扫——[[clinical-skills/medical-imaging]]、[[endocrine/adrenal]]；处理——钙通道的阻滞尼莫地平或维拉帕米、配“触发 avoidance？不——触发的回避”的处方不用收缩血管的药物、不用“血管活性的”补充剂、不做剧烈的屏气；带“阿片与曲普坦的告诫”的镇痛的选择；以及“在收缩的区域内避免低血压”这一血压的细微差别——[[pharmacology/adverse-reactions]]；以及后续——那条“3个月的影像显示可逆性”的规则把那张吓人的图变回解剖、并把这一综合征与“其治疗是免疫的抑制”的血管炎区分开；以及复发的咨询与“补充剂的停用”的记录（[[clinical-skills/communication]]、[[clinical-skills/records-handover]]）。**

::: example 那个“躺下时更重”的头痛 {#ex-iih}
一名31岁的女性，体质指数38，有3个月的每日的压迫的头痛清晨与弯腰时最重、看远时的复视、以及“右耳与脉搏同步的呼呼声”；检查显示双侧视盘的水肿与左侧的第六对神经的麻痹；视野显示盲点的扩大。
::: solution
**把视力悬在天平上特发颅内的高压（[[#def-other]]、[[nervous-system/sensory-systems]]）：紧急的顺序——同一周内的神经眼科，配正式的视野计与“相干断层扫描”的基线视力的丧失常常是外周的、并在“不再外周”之前不被注意到；带“排除静脉的血栓”的序列的磁共振静脉的成像，加上“横窦的狭窄”这一问与继发的原因；然后在“影像的安全”之后做“带起始压力的测量”的腰穿——[[clinical-skills/medical-imaging]]、与静脉窦的血栓的重叠见[[nervous-system/stroke]]、视野的追踪见[[nervous-system/sensory-systems]]；治疗——滴定到可耐受的乙酰唑胺带感觉异常与金属的味道及肾的结石及妊娠的告诫；以及托吡酯那份“头痛与体重的双重获益”带着它自己的认知的告诫；以及“作为改变疾病的治疗、而不是一句道德的旁白”被提供的体重管理的项目；以及那种“避免在药物过度使用的头痛之上再加一层”的镇痛药物的合理化——[[pharmacology/adverse-reactions]]、[[endocrine/reproductive-endocrinology]]；保住视力的升级——暴发式的病程快速视野的丧失要求收住并“系列的视野计”、乙酰唑胺与“作为桥接而并非肢体治疗的”激素；以及外科的选项——视神经的鞘的开窗与脑脊液的分流、以及“横窦的支架”的时代带着“按压力阶差选择患者”的细微差别与再狭窄的诚实，而适应证的选择要与神经外科及神经放射的团队共同做出；以及长期的现实——“药物的减量与体重的维持及视野的监测”的年、以及“怀孕与体重变化及症状的转变”事件时的复查（[[obstetrics-gynaecology/pregnancy-complications]]、[[public-health/screening]]）。**

::: example 那个“为每日的头痛的每日的药片” {#ex-moh}
一名44岁有15年的偏头痛，如今有“从醒来就有的钝的每日的头痛”，大多数日子服“对乙酰氨基酚与可待因的复方”、并“为了平衡”服布洛芬、每周两次为“真正的偏头痛”服“复方止痛的制剂”，并坚信自己“没有它们就无法运转”；为另一桩担心做的磁共振正常。
::: solution
**药物过度使用的头痛——诊断就是处方的计数（[[#def-migraine]]）：温和地说出的机制——“每月超过10天的曲普坦或麦角或阿片或复方的镇痛简单的制剂是15天”持续3个月，会驱动“受体与中段的致敏”的改变，让下一次的头痛更容易被生出；阿片与可待因的版本是最坏的元凶、也最难撤；配上“恶心与睡眠的扰乱及反跳的模式”的教育，好让她听到的是机制、不是责备——[[pharmacology/adverse-reactions]]、[[physiology/synapses]]；撤药的谈话——诚实地说出“2到10周的加重”的预后，以及预防的覆盖的计划在撤药之前或之中启动或优化预防，而不是要求她一无所有地硬扛；以及门诊对“白天的单元”对收住的撤药“哪一种适合她的工作与照护的职责；以及止吐药与在允许时的”非甾体的”，加一位具名的联系人，作为急救的脚手架——[[clinical-skills/communication]]；替代急期的计划——“一份被定义的每周的曲普坦的预算及书面的规则”、一个止吐的策略、以及行为的工具那“分级的回到运动与睡眠的规律”，做的正是可待因假装在做的工作；以及复发的框架——“这是一种像偏头痛本身一样会复发的疾病”，所以每年的复查与一个“尽早求助”的电话号码，胜过那句保证“偷偷地过度使用”的“再也不要吃一片药”的说教——[[geriatrics-palliative/symptom-control]]；以及共病的清扫——在慢性的每日的头痛中的抑郁与焦虑及创伤及睡眠的呼吸暂停的流行率；份“治疗这个人、而不只是药片”的处方；以及记录让下一位开药者在处方笺上看到这个数字（[[clinical-skills/records-handover]]、[[pharmacology/dosing-principles]]）。**
:::

::: exercise 在急诊处理那次“持续的发作” {level=1}
一名36岁有30小时重度的偏头痛伴呕吐、对她自己在第2小时服的曲普坦无响应；血压158/95；无危险信号；急期的处理接下来的一个小时是什么样的，有什么是你不该做的？
::: solution
**急救的治疗、而不是阿片（[[#def-migraine]]、[[emergency-critical-care/acute-assessment]]）：一线急诊的方案——静脉或肌注的多巴胺的拮抗剂（丙氯拉齐或甲氧氯普胺，带着“肌张力障碍与更年轻的女性的风险”以及“口腔黏膜的丙氯拉齐”这一替代、以及“抗胆碱的急救药”的知识）加一种非甾体的（酮咯酸或双氯芬酸，带肾与胃肠的告诫）加静脉的液体，以及一间“适合止吐的黑暗而安静的房间”——[[gastrointestinal/oesophagus-stomach]]、[[renal/filtration]]、[[pharmacology/adverse-reactions]]；二线——皮下的或鼻内的曲普坦（若尚未充分地尝试过——她的“在第2小时吃了一次曲普坦”是剂量不足、不是失败）；静脉的地塞米松用于24到72小时复发的减少，份温和但真实的证据；以及在“本地的实践与血管的安全允许时”的二氢麦角胺；以及那份“审计不断找出来的不要做的清单”——静脉的阿片（结局更差、就诊更多、是“药物过度使用的工厂”）、为一个稳定的已知的偏头痛且无危险信号而层层加码的影像、以及“只带着对乙酰氨基酚与乐观”的出院；离开的计划——一个具名预防的转诊、一份“带天数计数”的书面急期的方案、用平实语言写出危险信号的安全网、以及那通“让一次就诊与一段病程有所不同”的随访的电话（[[clinical-skills/patient-safety]]、[[clinical-skills/communication]]）。**

## 通向何处

神经眼科的急症在[[nervous-system/sensory-systems]]；血管的鉴别在[[nervous-system/stroke]]；血管炎性的头痛在[[musculoskeletal/connective-tissue-vasculitis]]；镇痛的阶梯与阿片的谨慎在[[geriatrics-palliative/symptom-control]]与[[emergency-critical-care/poisoning]]。

::: history
**头痛的史在很大程度上是一部“人被相信或不被相信”的史：古代“带愈合的边缘既证明了存活、也证明了洞能释放头痛的恶魔这一理论”的钻颅的头骨；盖伦头痛的分类、以及那几个世纪的“体液的胆汁与烟气”的疗法它把“偏头痛的词源”——半边的头痛与“黑痛”——留作了化石；1783年那部“第一次把伴病的头痛与单纯的分开”的专著；以及十九世纪的神经病学——利思与高尔斯——高尔斯自己偏头痛的日记，与他那本教科书里“直到今天仍被文献逐字引用”的先兆的描述；麦角的这条弧线——从助产士用来助产的麦角、与“因麦角中毒而得的头痛”（几十年“圣安东尼的火”的流行，经过1920到30年代“麦角胺的纯化”、到1960年代“由血清素与血管的收缩的工作所启发的”曲普坦的设计——可以说那是第一个“由一个关于头痛的机制的假说制造出来的”、而不是“通过观察发现的”药物——[[pharmacology/drug-development-prescribing]]）；簇集头痛名字的旅程“霍顿组胺的头痛”、患者民间的“自杀的头痛”、段被长期误诊为“鼻窦的”与“三叉的”的岁月、以及“在一次试验之后氧气被重新引入”——是一个“有效的疗法被遗忘了二十年”的典型案例；以及降钙素基因相关的肽的时代——“从神经源的炎症的假说到单克隆的抗体与小分子的药物”——是“现代的治疗学如何为一种曾经被当作性格缺陷的疾病做出一些东西”（[[pharmacology/drug-development-prescribing]]、[[immunology/vaccines-immunotherapy]]、[[public-health/prevention-promotion]]）。**
:::

::: summary
- 头痛靠病史诊断；危险信号的清单以任何好记的形式那十项决定了谁该被扫描、而“先兆未变的典型的偏头痛”不该被反复影像。
- 偏头痛要早治、足量、并按“每月的被计数预算”；药物的过度使用是“慢性的每日的头痛”最常见的医源性的原因。
- 50岁之后的新发的头痛“伴头皮与颌的症状”，在激素说话之前就是巨细胞的动脉炎；视力不等活检。
- 雷击样的起病意味着“同一小时蛛网膜下腔出血的方案”；而当那些都清楚时，就是“可逆的脑血管的收缩的综合征与静脉窦的血栓”的鉴别及它们的药物的触发的病史。
- 簇集的头痛值得氧气与“带心电图监测的”维拉帕米，而不是一辈子的偏头痛的药片；它的自杀的风险是一个真实的临床变量。
- 三叉神经痛是一个“要去找病因”的症状在年轻人中找多发的硬化与病灶，顶端是“从卡马西平的阶梯到微血管的减压”。
:::

::: exercise 管理那位妊娠的偏头痛患者 {level=2}
一名29岁在孕24周，每周4天的重度的偏头痛，此前在托吡酯按她自己的选择停了与普萘洛尔之下控制良好；如今失控；她在问什么是安全的。
::: solution
**妊娠头痛风险的平衡（[[#def-migraine]]、[[obstetrics-gynaecology/pregnancy-complications]]）：安慰与工作——大多数的偏头痛患者到第二季会改善，所以“没有改善”就挣得一次危险信号的复查、以及在后续的访视中“对子痫前期有警觉的血压与蛋白尿的检查”；托吡酯的停用是被肯定的致畸原、而“因为说明书所以把一切都停了”的决定要用数字重新审视——[[pharmacology/adverse-reactions]]；安全的清单——标准剂量的对乙酰氨基酚、恶心时用甲氧氯普胺与丙氯拉齐、镁与核黄素作为低风险的辅助；以及曲普坦的证据基础舒马曲普坦登记的数据最令人安心——“只留给重度的发作”、带血管的告诫与被记录的共同的决定——[[pharmacology/patient-variation]]；预防的谈话——普萘洛尔胎盘生长的考量，对比未经治疗的疾病的伤害脱水和摄入不足及“在疼痛中的跌倒”；阿米替林这个选项；以及“抗体——那里的数据真的还不存在，必须这样告诉她，而不是靠沉默把她纳入”——[[obstetrics-gynaecology/pregnancy-antenatal]]；以及物流——给分娩麻醉的信连同她自己曲普坦的计划；产后睡眠剥夺的策略最糟的一周是分娩的那一周；每一种被选择的药物的母乳喂养转运的数字；以及在出院之前就预约好的“静脉的血栓与先兆及含雌激素的避孕”的随访（[[obstetrics-gynaecology/postnatal-period]]、[[pharmacology/dosing-principles]]）。**

::: exercise 运行面痛的门诊 {level=2}
一名63岁的男性报告6周的“右颊电击样的疼痛”，由风与刷牙触发、“在发作之间有持续的钝痛”、而V2的轻触稍微减退。
::: solution
**经典对继发的三叉的神经痛，由细节决定（[[#def-facial]]）：两个信号——恒定的钝痛与感觉的缺失，就是“这一例要扫描”的特征：结构的病灶前庭的神经鞘瘤与脑膜瘤及转移、以及“侵犯海绵窦与圆孔所以偏好V2的鼻咽的癌”；以及在较年轻患者中的“多发硬化的部分脱髓鞘的斑块”的图景。带方案的磁共振，加上鼻与牙及鼻窦的检查伴危险信号——“单侧血性的耳炎与颈的肿块”意味着为鼻咽转耳鼻喉——[[clinical-skills/medical-imaging]]、[[nervous-system/neuroinflammation]]；治疗的开始——卡马西平或奥卡西平的滴定配“钠与人类白细胞抗原及血细胞与血小板的监测”这套文化；相互作用的复查华法林与他汀及移植的药物；以及驾驶的镇静的建议——[[pharmacology/dosing-principles]]、[[pharmacology/metabolism-excretion]]；升级的谈话——当疼痛跑赢药物时，份按“耐用性对麻木对复发”排序的麻醉与神经外科的菜单减压的那条长的无痛的曲线，对比“体弱与继发的原因”中的经皮的技术；配那份“治愈与控制是不同的”的期望的管理；以及“对处于疼痛的自杀的患者现在就转诊、而不是六个月之后”的规则——[[psychiatry/self-harm-suicide-prevention]]；以及要避开的陷阱——牙科的那条级联在疼痛被控制之前被拔的牙与“被牙源的解释所耽误”的病例：面痛的诊断一旦确立，就不要让“手术”成为唯一的沟通（[[clinical-skills/communication]]、[[musculoskeletal/back-pain]]）。**

::: exercise 审计头痛的服务 {level=3}
::: solution
**头痛的服务是“行为的改变的项目”（[[#def-migraine]]、[[public-health/health-systems-economics]]）：测量——“从基层的提取中数每位患者的曲普坦与复方镇痛用药的天数”的处方审计的定义；带适应证的编码及其“偶然发现的病灶与重复扫描的尾巴”的影像转诊的比率；以及预防的访视的记录的审计有三个必须出现的问题：发作的频率、急期的药的天数、失能的评分——[[epidemiology-ebm/measuring-disease]]、[[clinical-skills/laboratory-tests]]；干预的集合——一个“带分类的提示与危险信号的清单、以及在开药者的屏幕上触发的药物过度使用的警告”的模板的记录；由护士主导的“日记与滴定”的门诊；嵌入在申请单里的“影像的申请指南”带一个“为什么是现在？”的自由文本；以及那份“配预防的覆盖与随访的电话”的“把过度使用的药减停”的方案——[[clinical-skills/patient-safety]]、[[pharmacology/patient-variation]]；教育与文化的层——“关于危险信号与安慰的脚本”的全科医师午间的教学、神经科住院医的“影像的管家”的轮转、以及那份“解释为什么更少的扫描会让照护更好”的患者信息——[[public-health/prevention-promotion]]、[[clinical-skills/communication]]；以及“带护栏的”评估——每位患者的急期的天数与“每一百例新转诊影像的比率”及6个月的失能与头痛的影响的评分、以及那条“绝不能漏掉蛛网膜下腔的出血”的反向的监督（[[clinical-skills/records-handover]]、[[medical-ethics-law/professionalism-regulation]]）。**
