运动障碍是指运动过少、过多或类型异常，而没有无力的一类疾病。帕金森病患者肌力正常，却难以启动运动，也难以以正常的幅度和速度维持运动；舞蹈症患者的面部和肢体上则流动着并非其本意的动作。这些疾病大多来自基底节，即一组负责选择运动并调节其幅度的深部灰质核团。许多运动障碍仔细观察就能识别，其中有几种是可以治疗的。

本章介绍基底节环路、帕金森病及其治疗、非典型和继发性帕金森综合征，以及多动性运动障碍：震颤、肌张力障碍、舞蹈症、抽动和药物所致的运动障碍。英国帕金森病的处理遵循NICE NG71（《成人帕金森病》，2017年）；诊断遵循国际帕金森病和运动障碍学会（MDS）的临床标准（2015年）。

## 基底节环路

**基底节**包括**纹状体**（尾状核和壳核）、**苍白球**（外侧部和内侧部）、**丘脑底核**和**黑质**（致密部和网状部）。它们接收来自几乎整个皮质的输入，并经丘脑把输出送回额叶皮质。输出核团——苍白球内侧部和黑质网状部——是抑制性的（释放GABA），并持续活动：静息时它们抑制着丘脑，从而抑制运动。

::: theorem 直接通路与间接通路 {#thm-pathways}
在简化的经典模型中，纹状体通过两条途径影响输出核团。**直接通路**（纹状体到苍白球内侧部）**抑制**输出核团，解除对丘脑的抑制，易化被选中的运动。**间接通路**（纹状体到苍白球外侧部到丘脑底核到苍白球内侧部）**增加**输出核团的活动，抑制相互竞争的或不需要的运动。来自黑质致密部的**多巴胺**兴奋直接通路神经元（经D1受体），抑制间接通路神经元（经D2受体）；两种作用都有利于运动。因此，多巴胺缺失增加对丘脑的抑制，产生**运动减少**（帕金森综合征）；间接通路功能丧失（如亨廷顿病）减少抑制，产生**运动增多**（舞蹈症）。
:::

这个模型是一种简化：真实的环路以平行的回路运行（运动、眼动、认知和边缘），其神经元活动在时间模式上和放电频率上都有组织。但它能预测疾病的主要特征，并解释为什么刺激丘脑底核或苍白球内侧部的脑深部电刺激对帕金森病有效。

## 帕金森病

帕金森病是仅次于阿尔茨海默病的第二常见神经退行性疾病。其患病率随年龄急剧上升，男性略多见。它由黑质致密部多巴胺能神经元的进行性丢失引起；到出现运动症状时，这些神经元已大量丢失，纹状体多巴胺的丢失比例更大。残存神经元中含有**路易小体**，即聚集的**α-突触核蛋白**包涵体。α-突触核蛋白病理并不局限于黑质：它见于嗅觉系统、低位脑干、肠神经系统，后期见于皮质，这解释了众多的非运动特征。

::: definition 帕金森综合征与帕金森病 {#def-parkinsonism}
**帕金森综合征**定义为（MDS，2015年）**运动迟缓**合并**静止性震颤**、**强直**或两者兼有。

- **运动迟缓**是指运动缓慢，且随着动作重复，*速度或幅度进行性减小*（拇指和示指对指时所见的“递减”）。
- **静止性震颤**是肢体静止时4–6 Hz的震颤，常呈“搓丸样”，运动时减轻，保持某一姿势时再现。
- **强直**是在整个活动范围内对被动运动的阻力增高，与速度无关（与痉挛不同）。叠加震颤时出现“齿轮样”强直。

当存在帕金森综合征，且支持性特征（对多巴胺能治疗有明确而显著的反应、左旋多巴诱发的异动症、静止性震颤、嗅觉丧失等阳性辅助检查）多于危险信号，并且没有绝对排除标准（如小脑体征、垂直性核上性凝视麻痹，或起病时正在使用多巴胺阻断药物）时，诊断为**帕金森病**。
:::

运动特征在起病时通常是**不对称的**。其他特征包括声音低弱（发音过弱）、写字过小（小写征）、面部表情减少（面具脸）、眨眼减少、摆臂减少，以及弯腰、拖曳步态，伴**冻结**和**慌张步态**，后期出现平衡障碍和跌倒。

**非运动特征**往往比运动特征更致残。有些在运动体征出现前数年就已存在：**快速眼动睡眠行为障碍**（把梦境表演出来）、嗅觉丧失、便秘、抑郁和焦虑。后期特征包括自主神经功能衰竭（体位性低血压、尿急、勃起功能障碍）、疼痛、疲劳、淡漠、幻觉和精神病性症状，以及在病程多年后很大一部分人出现的痴呆。

::: example 声音变小、手臂僵硬 {#ex-pd}
一位64岁波兰裔退休电工发现，看电视时右手放在腿上会抖。妻子说他的声音变小了，走路时右臂不再摆动。他多年来便秘，嗅觉已丧失。十年来他在睡梦中拳打脚踢。查体：右手5 Hz静止性震颤，右腕强直伴齿轮样感，右手对指动作进行性减慢、幅度减小。眼球运动、反射和跖反射正常。他没有规律服用的药物。
::: solution
1. **是否存在帕金森综合征？** 是：运动迟缓伴递减，加上静止性震颤和强直。
2. **支持性特征。** 不对称起病、典型静止性震颤、嗅觉丧失，以及长期可能的快速眼动睡眠行为障碍和便秘，这些都是公认的路易体病前驱特征。
3. **危险信号与排除标准。** 无：眼球运动正常（无核上性凝视麻痹），无小脑体征，无早期跌倒或自主神经功能衰竭，未用多巴胺阻断药物。
4. **诊断。** 临床很可能的帕金森病。诊断是临床诊断；NICE NG71建议在开始治疗前转诊给专科医生（擅长运动障碍的神经科医生或老年科医生）。多巴胺转运体SPECT扫描（DaTscan）仅用于临床上无法区分特发性震颤和帕金森综合征的病例。
5. **下一步。** 讨论诊断及其病程；在症状影响生活质量时开始治疗；物理治疗和言语治疗；以及关于驾驶的建议（他必须通知DVLA）和快速眼动睡眠行为障碍可能伤及妻子的问题。
:::
:::

### 帕金森病的治疗

多巴胺本身不能通过血脑屏障。其前体**左旋多巴**可以通过，由大型中性氨基酸转运体携带，在残存的黑质末梢和其他细胞中转化为多巴胺。单用时，大部分左旋多巴会在肠道和血液中脱羧，引起恶心和体位性低血压，因此要与不进入脑的**外周多巴脱羧酶抑制剂**（卡比多巴或苄丝肼）合用。由于左旋多巴在吸收和转运上与膳食氨基酸竞争，高蛋白餐会削弱其作用。

主要药物类别有：

- **左旋多巴**（合用卡比多巴或苄丝肼）：治疗运动症状最有效的药物。
- **多巴胺受体激动剂**（普拉克索、罗匹尼罗、罗替高汀贴剂）：直接作用于多巴胺受体；效果不如左旋多巴，更易引起幻觉、嗜睡和**冲动控制障碍**（病理性赌博、性欲亢进、暴食、强迫性购物）。
- **MAO-B抑制剂**（雷沙吉兰、司来吉兰、沙芬酰胺）：减少脑内多巴胺的分解；效果中等。
- **COMT抑制剂**（恩他卡朋、奥匹卡朋）：减少左旋多巴的外周分解，延长每剂的作用时间。
- **金刚烷胺**：减轻左旋多巴诱发的异动症。

NICE NG71建议，对早期运动症状影响生活质量者给予左旋多巴；对症状尚未影响生活质量者，可考虑多巴胺受体激动剂、左旋多巴或MAO-B抑制剂。开始多巴胺受体激动剂前，必须告知患者（及其家属）冲动控制障碍的风险——它可能损害财务和人际关系——以及突然入睡的风险，这会影响驾驶。剂量按现行处方集缓慢滴定。

::: proof 为什么随病程进展出现运动波动
左旋多巴血浆半衰期短，约90分钟。在疾病早期这几乎没有影响：残存的黑质末梢摄取每剂生成的多巴胺，储存在囊泡中并平稳释放，因此一天几剂就能获得平稳的疗效。随着神经元丢失，储存能力下降，脑内多巴胺越来越随左旋多巴的血浆水平而波动。于是出现两个问题。在下一剂之前血药浓度下降时，症状再现（**剂末现象**）。在每剂的峰值时，对已敏化的突触后受体的高强度脉冲式刺激产生不自主的扭动样动作（**峰剂量异动症**）。“关期”与“异动”之间的浓度范围，即治疗窗，随着年头逐渐变窄。治疗运动波动的目的是使多巴胺能刺激更加持续：更小剂量、更频繁地给药；COMT或MAO-B抑制剂；长效激动剂；持续皮下输注福司左旋多巴–福司卡比多巴或阿扑吗啡；经空肠给予的左旋多巴凝胶；以及脑深部电刺激。
:::

::: example 八年后的剂末现象 {#ex-fluctuations}
一位69岁女性患帕金森病八年。她在07:00、11:00、15:00和19:00服用复方卡比多巴/左旋多巴。她说每剂约40分钟后“起效”，带来约两个半小时的良好活动，然后在下一剂之前的一小时里右手开始颤抖、走路变慢。每剂后约一小时，她颈部和双臂出现扭动样动作，家人看了很难受，但她说宁愿这样也不想处于“关期”。她常在进餐时服药。
::: solution
1. **描述问题。** 每剂起效约2.5小时，但给药间隔为4小时，因此她在每剂之前约有$4 - (0.67 + 2.5) \approx 0.8$小时，接近一小时，处于“关期”：**剂末现象**。她还在每剂后约一小时出现**峰剂量异动症**。
2. **机制。** 突触前储存能力的丧失意味着脑内多巴胺现在随左旋多巴短暂的血浆半衰期波动，治疗窗已经变窄（见上图）。
3. **简单措施。** 在餐前30–60分钟服药，或把蛋白质集中到晚餐，可改善吸收，使起效更可预测。
4. **平稳疗效。** 选择包括更小剂量、更频繁地给药（例如每天五次、每次剂量稍小，可同时降低峰值和谷值），加用COMT抑制剂（恩他卡朋或奥匹卡朋）或MAO-B抑制剂以延长每剂作用，或加用多巴胺受体激动剂。单独加用COMT抑制剂可使异动症加重，因此可能需要同时减少左旋多巴剂量。金刚烷胺可减轻异动症。
5. **若这些无效。** 转诊考虑器械辅助治疗：脑深部电刺激、阿扑吗啡或福司左旋多巴–福司卡比多巴皮下输注，或左旋多巴–卡比多巴肠凝胶。
:::
:::

**脑深部电刺激（DBS）**作用于丘脑底核或苍白球内侧部，可减少经过严格筛选者的运动波动、异动症和震颤，这些人对左旋多巴反应良好，且没有明显认知障碍或未控制的精神疾病。它对左旋多巴无效的症状没有帮助，如“开期”仍存在的冻结、平衡问题或痴呆。

多学科照护与药物同样重要：专科护士、物理治疗（包括针对冻结的提示策略）、作业治疗、针对嗓音和吞咽的言语治疗，关注情绪、睡眠、膀胱和肠道，后期还包括预立照护计划和姑息治疗。

::: warning 住院期间的帕金森病用药
左旋多巴不得突然停用或延迟。住院期间漏服，例如为手术禁食或卒中后不能吞咽时，会使强直和不能活动迅速加重，并可诱发误吸、跌倒，以及一种罕见但危及生命的、类似抗精神病药恶性综合征的反应（帕金森病–高热综合征）。帕金森病药物是“时间关键型”药物：按时给药；若口服途径丧失，在专科建议下使用替代方法，如罗替高汀贴剂或经鼻胃管给药。避免多巴胺阻断药：大多数抗精神病药（尤其是氟哌啶醇）、甲氧氯普胺和丙氯拉嗪都可严重加重帕金森症状。不通过血脑屏障的多潘立酮是首选的止吐药，但需注意其心脏风险。
:::

## 非典型和继发性帕金森综合征

并非所有帕金森综合征都是帕金森病。提示其他病因的特征有：对左旋多巴反应差、对称起病、早期跌倒、早期严重自主神经功能衰竭、早期痴呆或幻觉、眼球运动异常，以及小脑或锥体束体征。

| 疾病 | 主要特征 | 病理 |
|---|---|---|
| 路易体痴呆 | 痴呆先于帕金森综合征或在其一年内出现；认知波动；视幻觉；快速眼动睡眠行为障碍；对抗精神病药严重敏感 | α-突触核蛋白 |
| 多系统萎缩（MSA） | 帕金森综合征和/或小脑性共济失调，伴早期严重自主神经功能衰竭（体位性低血压、尿潴留或尿失禁、勃起功能障碍）；喘鸣；左旋多巴反应差 | 胶质细胞内α-突触核蛋白 |
| 进行性核上性麻痹（PSP） | 起病第一年内跌倒（常向后），垂直性核上性凝视麻痹（尤其向下凝视），轴性强直，构音障碍和吞咽困难，额叶认知改变 | tau蛋白 |
| 皮质基底节变性 | 显著不对称的强直和失用、皮质感觉缺失、“异己肢”、肌阵挛 | tau蛋白 |
| 药物性帕金森综合征 | 通常对称；有抗精神病药、甲氧氯普胺、丙氯拉嗪、丙戊酸钠用药史；停药后数周至数月内好转 | 无（受体阻断） |
| 血管性帕金森综合征 | 主要累及下肢和步态（“下半身帕金森综合征”）；有血管危险因素；MRI示白质病变 | 小血管病 |

在患有任何运动障碍的年轻人（约50岁以下）中，必须排除**肝豆状核变性（Wilson病）**，因为它可以治疗：查血清铜蓝蛋白、24小时尿铜，并做裂隙灯检查寻找Kayser–Fleischer环。

## 多动性运动障碍

### 震颤

**震颤**是身体某部位节律性的振荡运动。首先按其出现的时机分类。

- **静止性震颤**：肢体被支撑并放松时出现；是帕金森病的典型表现。
- **姿势性震颤**：保持某一姿势时出现，如双臂前伸。
- **动作性和意向性震颤**：运动过程中出现；**意向性震颤**在接近目标时加重，提示小脑病变。

::: definition 特发性震颤 {#def-et}
**特发性震颤**是一种孤立性震颤综合征，表现为双上肢动作性震颤（姿势性和动作性），病程至少3年，伴或不伴其他部位（如头部、声音或下肢）的震颤，且没有肌张力障碍、共济失调或帕金森综合征等其他神经系统体征（MDS共识声明，2018年）。它常有家族性，饮酒后常暂时改善。它是成人震颤最常见的原因。
:::

特发性震颤影响用杯子喝水、写字和使用餐具等活动。致残时，普萘洛尔或扑米酮是常用的首选药物；丘脑脑深部电刺激或聚焦超声丘脑毁损术是严重病例的选择。**增强的生理性震颤**是一种细小的姿势性震颤，焦虑、咖啡因、甲状腺毒症、低血糖、酒精戒断以及沙丁胺醇、锂盐、丙戊酸盐和选择性5-羟色胺再摄取抑制剂等药物可使其加重，因此对任何新发震颤者都应寻找这些因素。**功能性震颤**频率多变，可被注意力分散，并会随另一只手敲击的节律而同步。

::: example 写字发抖 {#ex-tremor}
一位58岁女教师双手震颤六年，在白板上写字困难，喝茶时会洒出来。紧张时加重，喝一杯葡萄酒后可改善一小时。她父亲有类似的震颤。查体：双手对称性7 Hz姿势性和动作性震颤，轻微的“摇头样”头部震颤。无静止性震颤、无运动迟缓、无强直、无肌张力障碍。甲状腺功能正常，每天喝两杯咖啡。
::: solution
1. **震颤类型。** 姿势性和动作性，双侧上肢，伴头部震颤；无静止性震颤。
2. **其他体征。** 无：无帕金森综合征、肌张力障碍或共济失调。
3. **病程与背景。** 六年；有家族史；饮酒有效。
4. **继发性病因。** 甲状腺正常，咖啡因摄入适度；无致震颤药物。
5. **诊断。** **特发性震颤**。由于没有帕金森综合征，不需要DaTscan。
6. **处理原则。** 解释并安慰她这不是帕金森病；实用辅具（加重餐具、带盖杯子）；由于影响工作，可按现行处方集试用普萘洛尔（须先排除哮喘和心脏传导阻滞）或扑米酮。应告诉她酒精不是治疗手段。
:::
:::

### 肌张力障碍

**肌张力障碍**是一种以持续或间歇性肌肉收缩为特征的运动障碍，引起异常的、常为重复性的动作、姿势或两者兼有。它常呈扭转样，由随意动作诱发或加重，并可因**感觉诡计**（拮抗姿势）而缓解，例如触摸下颌可缓解颈部肌张力障碍。肌张力障碍可以是**局灶性的**（颈部肌张力障碍、眼睑痉挛、书写痉挛、喉部肌张力障碍）、节段性的或全身性的。儿童期起病的全身性肌张力障碍常为遗传性。局灶性肌张力障碍用**肉毒毒素**注射到过度活动的肌肉中治疗；全身性肌张力障碍可对抗胆碱能药物或苍白球内侧部脑深部电刺激有反应。每一位患肌张力障碍的儿童或青年都要试用左旋多巴，因为**多巴反应性肌张力障碍**（由*GCH1*基因突变所致）反应显著。

**急性肌张力障碍反应**发生在开始使用多巴胺阻断药物后数小时或数天内，最常见于年轻人：动眼危象、斜颈、伸舌或牙关紧闭。它们令人恐惧，但对丙环定等抗胆碱能药物反应迅速。

### 舞蹈症与亨廷顿病

**舞蹈症**由不规则、不可预测、短暂的动作组成，从身体一处流向另一处，呈现坐立不安或舞蹈样的外观。病因包括亨廷顿病、药物（帕金森病中左旋多巴过量、口服避孕药、苯妥英）、自身免疫病（系统性红斑狼疮和抗磷脂综合征）、儿童链球菌感染后的**Sydenham舞蹈症**、妊娠（**妊娠舞蹈症**）、甲状腺功能亢进、非酮症性高血糖、红细胞增多症，以及基底节卒中（偏侧舞蹈症或偏侧投掷症，由丘脑底核病灶引起）。

::: definition 亨廷顿病 {#def-hd}
**亨廷顿病**是一种常染色体显性神经退行性疾病，由4号染色体上*HTT*基因的CAG三核苷酸重复扩增引起，编码亨廷顿蛋白中扩增的多聚谷氨酰胺链。重复长度的解读：

- 26次或以下：正常；
- 27–35次：中间型（本人不会发病，但重复可能在下一代扩增，尤其经父亲传递时）；
- 36–39次：外显不全（可能发病，也可能不发病）；
- 40次或以上：完全外显。

重复越长，起病越早；传递过程中（尤其是父系传递）的扩增导致**遗传早现**：后代起病越来越早。
:::

该病通常在30至50岁起病，表现为三联征：**舞蹈症**、**认知减退**（执行功能障碍、思维迟缓）和**精神症状**（抑郁、易激惹、淡漠、强迫行为、精神病性症状）。自杀风险增加。纹状体中型多棘神经元，尤其是间接通路的神经元，早期丢失，这解释了舞蹈症。截至2026年尚无改变病程的治疗；舞蹈症可用丁苯那嗪（VMAT2抑制剂）或抗精神病药减轻，照护需多学科协作。对有风险的成人进行**预测性检测**，须遵循检测前后认真咨询的方案（见[[genetics/mendelian-inheritance]]）。

### 抽动、肌阵挛与药物所致疾病

**抽动**是突然、快速、重复、无节律的动作（运动性抽动）或发声（发声性抽动），通常之前有一种冲动感，可暂时被抑制。当多种运动性抽动和至少一种发声性抽动存在超过一年、且在18岁前起病时，诊断为**Tourette综合征**。它常伴注意缺陷多动障碍和强迫障碍，抽动通常在成年后减轻。需要治疗时，行为治疗（抽动综合行为干预）为一线。

**肌阵挛**由突然、短暂、电击样的抽动组成。它可正常出现于入睡时（入睡抽动），也见于癫痫、代谢性脑病（尿毒症、肝衰竭；常伴**扑翼样震颤**，一种负性肌阵挛）、缺氧性脑损伤后，以及朊病毒病。

多巴胺阻断药物会引起一系列疾病：**急性肌张力障碍**（数小时至数天）、**静坐不能**（一种内心的不安，数天至数周）、**药物性帕金森综合征**（数周至数月），以及**迟发性运动障碍**（数月至数年后出现的口、舌和面部重复动作，停药后可能持续存在）。**抗精神病药恶性综合征**（强直、高热、自主神经不稳定、意识水平下降和肌酸激酶升高）是一种医学急症；必须与**5-羟色胺综合征**相区分，后者发展更快，引起阵挛和反射亢进，而不是铅管样强直。见[[psychiatry/psychotic-disorders]]和[[emergency-critical-care/poisoning]]。

::: example 新发震颤和行为古怪的年轻男性 {#ex-wilson}
一位22岁男大学生一年来变得易激惹，成绩下滑。双手前伸时发抖，呈粗大的“扑翼样”，言语含糊。去年全科医生发现他的肝功能轻度异常。无神经系统疾病家族史。
::: solution
1. **模式。** 年轻成人出现运动障碍（震颤、构音障碍）、精神改变和肝功能异常。
2. **不可漏诊。** **肝豆状核变性（Wilson病）**，一种常染色体隐性遗传的铜转运障碍（*ATP7B*），导致铜沉积于肝脏和脑（尤其是基底节）。它可以治疗，不治疗则致命。
3. **检查。** 血清铜蓝蛋白（通常降低）、24小时尿铜（升高）、裂隙灯检查Kayser–Fleischer环（几乎所有神经系统受累者都有）、肝功能和肝脏影像、脑MRI以及基因检测。可能需要肝活检定量测铜。
4. **治疗原则。** 由专科管理，使用铜螯合剂（青霉胺或曲恩汀）或锌剂，避免高铜食物；急性肝衰竭时行肝移植。螯合治疗早期神经症状可能加重，因此在专科监督下开始治疗。应筛查其兄弟姐妹。
:::
:::

::: history
1817年，詹姆斯·帕金森（James Parkinson）描述了六名患“震颤麻痹”的人，让-马丁·沙可（Jean-Martin Charcot）以他的名字命名该病，并认识到强直与无力不同。长岛的年轻医生乔治·亨廷顿（George Huntington）于1872年描述了遗传性舞蹈症。弗里德里希·路易（Friedrich Lewy）于1912年描述了以他命名的包涵体。1957–1960年，阿尔维德·卡尔松（Arvid Carlsson）证明多巴胺是一种神经递质，且左旋多巴可逆转利血平在动物中诱发的帕金森症状；1960年，赫伯特·埃林格（Herbert Ehringer）和奥列·霍尼凯维奇（Oleh Hornykiewicz）发现帕金森病患者纹状体多巴胺耗竭；1967年，乔治·科齐亚斯（George Cotzias）确立了有效的大剂量口服左旋多巴疗法。1993年，亨廷顿病协作研究组发现了CAG重复扩增；1997年，米哈埃尔·波利梅罗普洛斯（Mihael Polymeropoulos）等人在家族性帕金森病中发现了α-突触核蛋白突变。阿利姆-路易·贝纳比德（Alim-Louis Benabid）于1987年引入了治疗震颤的脑深部电刺激。
:::

::: summary
- 基底节选择运动并调节其幅度。多巴胺通过兴奋直接通路、抑制间接通路而有利于运动；多巴胺缺失引起帕金森综合征，间接通路丧失引起舞蹈症。
- 帕金森综合征是运动迟缓（伴递减）加静止性震颤和/或强直。帕金森病不对称起病、对左旋多巴有反应，并伴非运动特征（快速眼动睡眠行为障碍、嗅觉丧失、便秘、情绪改变、自主神经功能衰竭、后期痴呆）。
- 左旋多巴合用脱羧酶抑制剂是最有效的药物；多巴胺受体激动剂有冲动控制障碍和嗜睡的风险。运动波动和异动症随储存能力丧失而出现；持续刺激和脑深部电刺激有帮助。
- 住院期间帕金森病药物是时间关键型的；避免氟哌啶醇和甲氧氯普胺等多巴胺阻断药。
- 非典型帕金森综合征的危险信号：早期跌倒、凝视麻痹（PSP）、早期自主神经功能衰竭或共济失调（MSA）、早期痴呆和幻觉（DLB）、显著不对称伴失用（CBD）、左旋多巴反应差。考虑药物和Wilson病。
- 特发性震颤是双侧姿势性和动作性震颤，常有家族性且饮酒有效；用普萘洛尔或扑米酮治疗。
- 肌张力障碍：持续收缩伴异常姿势、感觉诡计；局灶性用肉毒毒素；年轻起病者试用左旋多巴。
- 亨廷顿病：*HTT*基因CAG扩增的常染色体显性遗传病（40次或以上完全外显，36–39次外显不全），表现为舞蹈症、认知减退和精神疾病。
- 多巴胺阻断药引起急性肌张力障碍、静坐不能、帕金森综合征、迟发性运动障碍和抗精神病药恶性综合征。
:::

::: exercise 说出震颤类型 {level=1}
说出最可能的震颤类型：(a) 看电视时左手4–6 Hz搓丸样震颤，伸手拿遥控器时消失；(b) 拿杯子时双手震颤，饮酒后改善；(c) 右手震颤，手指越接近检查者的手指越重；(d) 双手细小震颤，伴体重下降、怕热，静息脉搏每分钟112次。
::: solution
(a) 帕金森病的静止性震颤。(b) 特发性震颤（姿势性和动作性）。(c) 右侧小脑病灶引起的意向性震颤。(d) 甲状腺毒症引起的增强的生理性震颤。
:::

::: exercise 左旋多巴半衰期 {level=1 check="0.25"}
左旋多巴的血浆半衰期约1.5小时。假设为一级消除，峰值后3小时还剩峰值血浆浓度的多少？给出精确的小数。
::: solution
三小时是两个半衰期：$0.5^{2} = 0.25$，即峰值浓度的四分之一。这种快速下降是晚期疾病剂末现象的基础。
:::

::: exercise 亨廷顿重复次数 {level=1}
解读下列*HTT* CAG重复长度：(a) 18；(b) 31；(c) 38；(d) 44。
::: solution
(a) 正常。(b) 中间型：本人不会患亨廷顿病，但重复可能在其子女中扩增到致病范围，尤其是经父亲传递时。(c) 外显不全：本人可能发病，也可能不发病。(d) 完全外显：只要活得足够长，本人就会发病。
:::

::: exercise 住院 {level=2}
一位78岁帕金森病男性，每天服用五次复方卡比多巴/左旋多巴，因髋部骨折入院，等待手术期间禁食。之后他在病房中出现激越和幻觉。讨论应如何管理他的帕金森病药物，以及如何处理激越。
::: solution
他的左旋多巴是时间关键型药物。手术前后都应按时给药；若他不能口服，寻求专科建议（帕金森病专科护士或药师）使用替代方法，如罗替高汀贴剂或经鼻胃管给予左旋多巴，并计算等效剂量。漏服有严重强直、误吸、跌倒和帕金森病–高热综合征的风险。激越需要评估是否为谵妄：感染、疼痛、尿潴留、便秘、脱水、缺氧、漏服或过量用药，以及阿片类和抗胆碱能药等药物。首先采用非药物措施。必须避免氟哌啶醇和其他典型抗精神病药，因为它们可引起严重恶化和抗精神病药恶性综合征；若抗精神病药不可避免，按当地指南首选小剂量喹硫平（或在专科指导下用氯氮平）。
:::
:::

::: exercise 赌博损失 {level=2}
一位56岁女性的帕金森病用罗匹尼罗控制良好。她丈夫说，她三个月内在网上输掉了几千英镑，这完全不像她。可能的原因是什么？应该怎么办？
::: solution
多巴胺受体激动剂引起的**冲动控制障碍**。服用多巴胺受体激动剂的人中有相当一部分会出现，剂量越高、越年轻越常见，包括赌博、强迫性购物、暴食和性欲亢进。患者常因难以启齿而不报告，因此应事先告知家属并在复诊时询问。处理是逐渐减量或停用激动剂（突然停药可引起多巴胺受体激动剂撤药综合征，表现为焦虑、疼痛和情绪低落），同时调整左旋多巴以维持运动控制，并为财务和人际关系方面的后果提供支持。
:::
:::

::: exercise 判断非典型帕金森综合征 {level=2}
一位61岁男性两年来动作迟缓、僵硬，左旋多巴几乎无效。他站立时晕倒，因尿潴留需要导尿，打鼾响亮伴夜间喘鸣，步基宽、步态不稳。可能的诊断是什么？哪些特征能把它与帕金森病区分开？
::: solution
**多系统萎缩**（帕金森型和小脑型特征）。区分特征：早期严重的自主神经功能衰竭（直立性低血压、尿潴留或尿失禁、勃起功能障碍）、小脑性共济失调、喘鸣、进展快、对称起病，以及对左旋多巴反应差或短暂。在帕金森病中，自主神经功能衰竭出现较晚且较轻，左旋多巴产生明确而持续的获益。MRI可显示脑桥和小脑萎缩（“十字面包征”）或壳核萎缩。
:::
:::

::: exercise 一生未发病后的风险 {level=3 check="1/6"}
一位60岁男性的母亲患亨廷顿病，CAG重复43次；他未做检测，也没有症状。假设遗传了完全外显等位基因的人中有80%在60岁前出现症状（示意值）。运用贝叶斯定理，他携带该等位基因的概率是多少？以分数作答。
::: solution
携带该等位基因的先验概率：$1/2$。若为携带者，60岁时无症状的概率：$0.2$；若非携带者：$1$。后验概率：
$$P = \frac{0.5 \times 0.2}{0.5 \times 0.2 + 0.5 \times 1} = \frac{0.1}{0.6} = \frac{1}{6}.$$
他的风险从二分之一降到约六分之一，他的子女从他那里遗传该等位基因的风险是其一半，约十二分之一。这样的计算有助于人们决定是否在咨询后寻求能给出确定答案的预测性检测。
:::

::: exercise 用新药后的运动障碍 {level=3}
一位19岁女性来到急诊科，颈部向右扭转，双眼向上固定，这是她因胃肠炎开始使用一种止吐药几小时后出现的。(a) 诊断是什么，可能是什么药物？(b) 如何治疗？(c) 如果她是在开始使用抗精神病药三天后出现39.5 °C发热、全身强直、出汗、血压波动和意识模糊，你的评估会有何不同？(d) 哪些表现会指向5-羟色胺综合征？
::: solution
(a) 由多巴胺阻断类止吐药（最可能是甲氧氯普胺或丙氯拉嗪）引起的**急性肌张力障碍反应**（斜颈和动眼危象）。年轻女性尤其易感。(b) 停药，并按处方集给予抗胆碱能药物，如丙环定（静脉或肌内注射以快速起效）；症状在数分钟内缓解。应建议她今后避免使用该药，并记录为药物不良反应。(c) 这提示**抗精神病药恶性综合征**，一种医学急症：停用抗精神病药，测肌酸激酶（常非常高）、肾功能和电解质，给予降温和补液等支持治疗，通常在高依赖病房或重症监护室进行；可在专科建议下使用丹曲林或溴隐亭。警惕横纹肌溶解和急性肾损伤。(d) 5-羟色胺综合征通常发生在使用5-羟色胺能药物或药物组合后，数小时内发生，引起阵挛（尤其是可诱发的踝阵挛）、反射亢进、震颤、激越、腹泻和瞳孔散大，强直程度不如抗精神病药恶性综合征。
