运动障碍的神经病学是神经病学中最靠体格检查的一支：**诊断是先被看出来、然后才被听到的；体征是阳性的震颤与强直及动作迟缓及运动障碍及肌张力障碍及肌抽跃及共济失调及舞蹈症，而每一种都有一个如此独特的描述，以至于手机上的一段认真的录像胜过大多数的化验。**帕金森病在这一章里“在数量上与在治疗上都占支配”；其余的是一份“不想要的运动的词汇表”。

本章涵盖帕金森的综合征与它们的治疗的阶梯、震颤与肌张力障碍及抽动、以及“痉挛与强直对无力”的区分。

## 帕金森综合征

::: definition 帕金森病与它的模仿者 {#def-parkinson}
**核心的综合征——动作迟缓加上静止的震颤或强直、不对称并进展；支持性的病史有“小字的书写与扣纽扣的麻烦及卷起的袜子及音量降低及臂的摆动减少并冻结的越来越软的步态”；以及那支非运动的军队嗅觉的减退配它气味测试的诊断、作为最强的前驱的标志快速眼动的行为的异常——那种“突触核蛋白的病”的前兆；便秘；勃起与排尿及出汗的功能障碍；抑郁与焦虑及淡漠先于运动的疾病数年；睡眠的碎片化；以及较晚的认知与幻觉的并发症——病理上从“背的迷走的核与嗅球”到边缘再到新皮层的扩散它的分期，带着它对“多早算是太迟”的治疗的含义——嗅觉见[[nervous-system/sensory-systems]]、前驱的抑郁见[[psychiatry/mood-disorders]]、多巴胺的解剖见[[physiology/synapses]]。承载诊断与随访的检查的语言——统一帕金森的评分与分期、“眉间的叩击与钟摆及再激活的动作的细微差别”、“拉试验的时机”与“整块地转身”与起始的犹豫、以及“每一次访视都要索要的字迹的样本”。病理的模仿者以及如何分开它们——药物诱发的帕金森综合征（多巴胺阻断的抗精神病药与甲氧氯普胺，以及“在某些国家非处方的桂利嗪与氟桂利嗪的陷阱”：对称的、震颤常常缺失、而“多巴胺转运体的扫描”能解决问题——[[psychiatry/treatments-mental-health-law]]、[[pharmacology/adverse-reactions]]）；血管的帕金森综合征（下半身的、阶梯样的、影像可见的）；正压的脑积水（那“湿与晃与痴呆”的三联，配“诚实的以步态为先的分流的选择标准”——[[nervous-system/dementia-neurodegeneration]]）；以及“其危险信号就是检查日的信息”的非典型帕金森的综合征——多系统的萎缩（早期自主的衰竭，配“卧立血压的算术”与“共济失调与喉的喘鸣及对左旋多巴反应差”的组合、以及“臀的征与十字面包”的磁共振的时代；以及“体位的低血压”的重症般的管理）；进行性核上的麻痹早期的跌倒、垂直核上凝视的麻痹（配“方波的抽动与大摆地转身及鼓掌的征”与“对左旋多巴抵抗的轴性强直）；皮层基底节的综合征（不对称的失用与”异己肢“及皮层的感觉的缺失及肌抽跃）；以及路易体的痴呆（波动的认知与”成形视觉的幻觉“及”快速眼动的行为的异常“、以及那”让普通病房里为幻觉而给的氟哌啶醇成为一种从不应发生的事件“的严重的抗精神病药的敏感——[[nervous-system/dementia-neurodegeneration]]、[[psychiatry/psychotic-disorders]]）——每一种都要比在帕金森病中早得多的“照护者与预后及预见的照护”的谈话，因为它们走得更快、也更难治。**
:::

::: definition 左旋多巴与“运动的并发症的年” {#def-treatment}
**药理的阶梯与它的算术——左旋多巴作为最有效的药，配那句诚实的咨询：“尽早开始它既不会烧掉神经元、也不会加速并发症”延续十年的那两个问题；与“脱羧酶的抑制剂”一起给、按功能滴定，带着“蛋白的餐食与便秘的吸收及铁及甲氧氯普胺”相互作用；以及“儿茶酚的甲基转移酶与单胺的氧化酶的抑制剂”这两种延长它们之间的相互作用——与曲马多及抗组胺的止吐药及选择性血清素的再摄取抑制剂的“血清素的”告诫，每一次收住的用药清单都应当从第一原理重新推导一遍——[[pharmacology/metabolism-excretion]]、[[pharmacology/adverse-reactions]]、[[gastrointestinal/oesophagus-stomach]]。多巴胺的激动剂带着它们的“冲动控制障碍的军火库——赌博与色情及购物及”无目刻板的行为“，家属只有在”用被验证的问卷的坦率“被问及时才会交代；以及镇静与”突然睡眠的攻击“及体位的低血压及腿的水肿及”攻击的反跳“文献；以及”起病较年轻时使用“的道理与”年老的脑子要把它撤掉“的理由——[[psychiatry/substance-use]]。疾病的时间与”左旋多巴的脉冲性“所带来运动的并发症——剂末的现象可预测的剂末的恶化；用”把剂量分开与长效的制剂“及那两类延长酶抑制剂来回答与运动障碍峰值的与双相的模式；由患者做出的”令人痛苦的对比不致失能的“这一区分；金刚烷胺作为温和的药物，带着它的”网状青斑与踝的水肿及幻觉“的限度；以及”把早晨的一套例行变成一张电子表格“的波动。晚期的选项——阿扑吗啡（为冻结的急救的注射；以及持续的皮下的泵，带着它的”结节的与嗜睡的管理及起始的心脏的监测“）；经空肠的”左旋多巴的肠凝胶“那个管位的与意识混乱问题的时代；以及双侧的丘脑底核与苍白球的深部的脑的刺激——其选择的标准是”对左旋多巴有反应、没有早期的不稳或未治疗抑郁及没有认知的下降“，连同”电池与手术及说话音量及吞咽的取舍“作为一包来讨论；微损毁效应带来的欣快；术后程控的年；以及”被选择的标准认真地对待的自杀的风险的警惕”的文献（[[psychiatry/self-harm-suicide-prevention]]、[[emergency-critical-care/acute-assessment]]）。**
:::

::: definition 震颤、肌张力障碍、抽动与肌抽跃 {#def-others}
**震颤——只要你慢下来就会“自己报出名字”的现象学：帕金森静止的震颤（配“搓丸样的与再激活的）；行动的震颤分为”特发的震颤“——双侧上肢的”姿势的与动作的“模式、头与声音的受累、常常有家族史、进展缓慢、那种”患者在医师问起之前就先发现的“对酒精的反应、以及”与小脑相邻普肯耶的病理“的文献；在功能需要时治疗——普萘洛尔或扑米酮带着”从低剂量开始、缓慢地加“的镇静的问题、托吡酯；以及对”失能的难治的患者“的深部的脑的刺激与”聚焦超声丘脑的毁损“的选项包括毁损的”永久的构音障碍与步态“的取舍——小脑的那几行见[[nervous-system/motor-systems]]；加上那份”药物与代谢的“清单β的激动剂与锂及丙戊酸及”血清素的再摄取抑制剂“及甲状腺的毒症及戒断的状态、以及”睡眠的剥夺与咖啡因造成的增强的生理的震颤“——这让震颤首先是一桩药物病史的诊断、而不是神经病学的——[[pharmacology/adverse-reactions]]、[[endocrine/thyroid]]。肌张力障碍——“持续的或间歇的、有模式的肌的收缩”造成扭转与异常的姿势，按分布分灶的——“任务特异”的书写者的与音乐家的痉挛及“口下颌的”及颈部的配它的“感觉的把戏”与“反常的头斜；那个使它变得可治疗的”肉毒毒素的时代“，带着”剂量依赖的扩散与无力及吞咽困难“的”颈部的注射“的告诫与”抗体的问题“；节段的与泛化的（含基因的家系与”儿童期起病于腿然后泛化“的那种；以及”每一例年轻的患者都必须被排除的多巴的反应的肌张力障碍”——一小剂左旋多巴就能把它彻底改变——[[genetics/mendelian-inheritance]]）；病因的清单——孤立的或症状的——威尔逊病它的肝与“角膜的色素环”及精神的组合，配“铜蓝蛋白与铜的研究”，以及青霉胺与锌的治疗带着它自己那条“可能让神经更糟”的告诫——这是每一位年轻运动障碍的患者都要被筛查的代谢的疾病——[[genetics/mendelian-inheritance]]、[[gastrointestinal/liver-disease]]；药物诱发迟发的综合征——多巴胺阻断剂迟发的运动障碍，配它风险的算术；“一种囊泡的单胺的转运体的抑制剂”的治疗的时代；以及那条“不要为了掩盖动作而加量抗精神病药它会让病程更糟”的规则——[[psychiatry/treatments-mental-health-law]]；以及疼痛的与体位的变异、以及那“伴阵发的升级”的僵硬综合征。抽动——可被压制的、有前驱冲动的、重复的，配它们图雷特的综合征儿童期起病、时轻时重、常伴“注意的缺陷与强迫”它们对学业与自尊的决定作用远超动作；α的激动剂与抗精神病药及托吡酯治疗的层级；以及“家属很少知道它存在”的“习惯逆转的训练”；以及“作为最后的手段”的深部的脑的刺激；以及功能性的抽动的鉴别“成人突然起病时代的表现”——为分心的与牵引的现象做检查，治疗用的是“功能性的现象”的解释、而不是更多的抗精神病药——[[psychiatry/anxiety-disorders]]、牵引的测试见[[nervous-system/motor-systems]]。以及肌抽跃与舞蹈症与其他——肌抽跃皮层的（配“肌抽跃与脑电的锁定”的那套检查、皮层下的、以及脊髓的；以及“代谢的与药物的”的原因及“伴进展神经变性的”）；舞蹈症（亨廷顿的病及其遗传的咨询与“重复的序列”的检测及“家庭的与保险的与预见的照护”的问题——[[genetics/non-mendelian-inheritance]]、[[medical-ethics-law/ethical-principles]]；以及“良性遗传的”与其他的原因、以及“伴抗体的”的自身免疫的）。**

## 不想要的运动

::: example 那个“把梦演出来”的男人 {#ex-rbd}
一名62岁的教师的妻子发来视频：他在夜里拳打并喊叫“守住栅栏！”，每月好几次；他记得生动的防卫的梦；他有便秘与嗅觉的减退与轻度的动作的震颤；其余的检查正常；他不服任何药。
::: solution
**作为“前驱的突触核蛋白的病”的快速眼动的行为的异常——一个“有十年的后果”的诊断（[[#def-parkinson]]）：识别——“伴正常肌肉的张力消失丧失的梦的演出”；对同床的人与自己的伤害的风险；鉴别——“额叶的夜间发作与容易混淆的异态睡眠”；以及必须首先被移除的药物的原因血清素的再摄取抑制剂与“双重的再摄取抑制剂”，甚至戒断；“在诊断不确定或有模仿者时做视频的多导的睡眠的监测”——[[nervous-system/epilepsy]]、[[psychiatry/treatments-mental-health-law]]；风险的谈话——孤立快速眼动的行为的异常带着“很高的长期的转化率”转向帕金森路易体的痴呆与多系统的萎缩；气味的测试与“多巴胺转运体的扫描”及自主的检查研究的标志物“尚未准备好预测个体”；以及那句诚实的表述——“我们不能告诉你何时、也不能告诉你是哪一种，但这是我们将会观察的、以及你可以告诉我们的”——[[nervous-system/dementia-neurodegeneration]]、[[clinical-skills/communication]]；立即的管理——卧室安全的工程床放到地面；利器与家具及窗户及宠物的安排；褪黑素或氯硝西泮带跌倒与驾驶及认知的告诫；以及对同床的人的支持与睡眠的门诊的转诊的模式——[[geriatrics-palliative/falls]]、[[pharmacology/adverse-reactions]]；以及纵向的计划——每年的复查配运动的与认知及自主及幻觉的筛查；“在被加上镇静的药物或出现白天的嗜睡时”重新讨论驾车的建议；以及为一位“前面有十年精算的不确定性”的患者进行的“试验与研究的登记”的谈话（[[clinical-skills/records-handover]]、[[medical-ethics-law/ethical-principles]]）。**

::: example 那个服用普拉克索的赌徒 {#ex-icd}
一名54岁的早发的帕金森病，在普拉克索3毫克加左旋多巴之下控制良好；他输掉了积蓄，并开始了一段外遇，“自从吃了药片”；他的妻子说他“不像他自己”；运动的评分极好。
::: solution
**冲动控制的障碍——一种“尽管运动控制极好也必须停药”的药物副作用（[[#def-parkinson]]、[[#def-treatment]]）：披露——常规地问那一组问题赌博与色情及购物及进食及“刻板的活动”及性行为的过度、并用被验证的工具，因为羞愧会让患者闭嘴、而同床的人才是报告者；以及那个框定——“这是受体驱动的、不是性格”，这对“在减量期间把这个家庭维系在一起”至关重要——[[psychiatry/substance-use]]、[[clinical-skills/communication]]；减量——通常会解决行为的“激动剂剂量的下调”的计划；预先绘制出的“多巴胺激动剂戒断的综合征”（焦虑与疼痛及出汗及“对药物的渴求”及烦躁）；以及为在这段过程中维持运动的功能而做的“左旋多巴与那两类酶抑制剂及给药频次”的调整；以及为运动的代价而进行的“阿扑吗啡与肠凝胶与深部的脑的刺激”的适格的谈话；以及那条“不要为了修一个问题而同时停掉好几种药”的谨慎（[[pharmacology/dosing-principles]]、[[psychiatry/substance-use]]）。附带的伤害——“财务与关系及法律及就业”的后果需要现在就有实际的帮助博彩求助的服务与银行及律师、以及“修复关系”的谈话；减量期间的抑郁与自杀的筛查；以及“给全科与药房的警示”，好让未来的一位开药者不会随意地把激动剂重新开起来——[[psychiatry/mood-disorders]]、[[public-health/determinants-inequalities]]；以及同意的记忆——“激动剂之前的咨询的记录”在开始时是否解释过冲动控制的风险？、此后每一次复查时常规的重问；以及给团队的那个教学要点——“一个完美运动的评分并不是一个好的结局”（[[clinical-skills/clinical-reasoning]]、[[medical-ethics-law/consent-capacity]]）。**

::: example 只在消化科门诊“锁住”的舌头 {#ex-aps}
一名21岁的女性由急诊送来，她的舌头“咬紧并被向后拽”、颈扭向左侧、“双眼向上牵拉”并伴恐慌；症状在她为“胃肠炎”服下的第一剂甲氧氯普胺之后4小时开始；无发热，化验正常，别处无强直。
::: solution
**急性的肌张力障碍的反应——一位年轻患者身上的“多巴胺的阻断剂”的“眼球危象与痉挛的斜颈及伸出的舌头”的表现（[[#def-others]]、[[#def-treatment]]）：治疗——胃肠外抗胆碱的药（本托品或三己酚迪地尔）或“带抗胆碱活性抗组胺的药”（异丙嗪或苯海拉明），“数分钟之内戏剧性的响应”本身就是诊断的确认；对“严重的手与喉的受累”观察气道与唾液并明确“麻醉的后备”的阈值；口服的继续几天加“停掉元凶的药物”的处方；以及在病历上“把甲氧氯普胺这一条目写成不良反应、而不是真正的过敏”——[[pharmacology/adverse-reactions]]、[[emergency-critical-care/acute-assessment]]；不可错过的鉴别——破伤风（免疫接种的病史与“牙关紧闭的进展”及自主的不稳及伤口、低钙、发作、功能性的颈的模式；以及那个“她并不拥有的、因为她的体温与反射都正常”的“血清素与她没有那个”伴发热与强直的重叠的综合征“，因为她无热而反射正常）——[[infectious-diseases/tropical-infections]]、破伤风见[[microbiology/bacterial-pathogenesis]]、[[nervous-system/epilepsy]]；防止复发的教学——“年轻的女性与脱水及最近的剂量”这一风险的模式；社区处方审计的那一点——“为病毒性的胃肠炎常规给甲氧氯普胺”是个坏默认、而“昂丹司琼”是一个替代；以及那份“要避免哪些药物抗精神病药与抗胆碱的止吐药”的书面的信息（[[public-health/vaccination-programmes]]、[[clinical-skills/records-handover]]）。**

::: example 例“强直与发热与意识混乱” {#ex-nms}
一名46岁的“分裂的情感障碍”在服“氟哌啶醇癸酸酯的长效针加口服的利培酮”，由社区团队送来：体温39.4，肌酸激酶4200，血压大幅摆动，心率122，“大量的出汗”，显著的“铅管样的强直”，以及“伴波动意识的缄默”；无灶的体征；尿色深。
::: solution

## 通向何处

::: history
**运动障碍的医学始于伟大的临床的描述、终于那枚植入的电极：詹姆斯·帕金森在1817年关于震颤的麻痹的论文——那位“其论文以六个病例的精确性写成、而这个专科用了一个世纪才追上”的内科药剂师；而它的名字是由法国的学派加上去的夏科添上了“震颤的麻痹”这一说法、以及他自己的学生们以其名字命名的修正——[[nervous-system/motor-systems]]；十九世纪末的“去大脑的强直与黑质的病灶”的实验，以及那次“黑质多巴胺的神经元”的认识——它要等到瑞典的“荧光组织化学的时代”才成为神经化学；以及1960年代“把多巴胺的缺乏量化、从而使替代的治疗变得合理”的那项工作——[[physiology/synapses]]、[[pharmacology/drug-development-prescribing]]；左旋多巴的革命与“口服剂量的洞见”、以及那次诺贝尔奖；外科毁损的时代为震颤做苍白球的毁损与丘脑的毁损——“左旋多巴的时代曾把它短暂地掩埋”，而后来的重估与“高频的刺激”的发现把它复活成深部的脑的刺激——是罕见的“在它的对手的运动的并发症证明了这一点之后又回来的”疗法外科的语境见[[nervous-system/stroke]]；以及“运动障碍的社会学”——“把患者组织成团体、并迫使质量的测量与照护的路径进入神经病学”（[[public-health/health-systems-economics]]、[[medical-ethics-law/professionalism-regulation]]）。**
:::

::: summary
- 帕金森综合征是动作迟缓加上震颤或强直；诊断是临床的；不对称与良好的左旋多巴反应支持它，而早期的跌倒与凝视的麻痹及自主的衰竭及早期的幻觉反对它。
- 先用左旋多巴按这个人的功能来治疗、谨慎地用激动剂冲动控制的障碍；而运动的并发症用“分开给药与辅助药物”、以及对合适的患者尽早使用的器械。
- 非运动的疾病——睡眠与情绪及认知及自主的衰竭及疼痛及淡漠——通常决定了生活质量，需要被点名询问。
- 特发的震颤是“伴家族史动作的震颤”；普萘洛尔与扑米酮为先，“失能的难治的患者”用丘脑的刺激或超声。
- 年轻起病的运动障碍：先想威尔逊病与“多巴反应的肌张力障碍”及药物诱发的，再想特发的疾病。
- 快速眼动的行为的异常是“一个带预后的诊断”；把卧室做安全防护、并监测表型的转化，而不去预言它。
:::

::: exercise 在抗精神病药之前做筛查 {level=2}

一名79岁的帕金森病的患者在服左旋多巴与普拉克索及司来吉兰及索利那新；他每晚看见“门厅里的小动物”、感到害怕；他的女儿想要“一点治脑子的药”。

**帕金森谱系的精神病——先减、再加、而且绝不使用氟哌啶醇（[[#def-parkinson]]、[[#def-treatment]]）：谵妄的清扫——感染与便秘及尿的潴留那个索利那新！与疼痛及睡眠的剥夺；以及那“含三种多巴胺的药物与抗胆碱的负担”的药物堆栈套“贝尔斯标准与抗胆碱的量表”的文献正是为此而存在；以及“感觉缺陷的放大器”白内障与听力的损失及黑暗的门厅——[[geriatrics-palliative/delirium-dementia-care]]、把用药的对账当作干预——[[clinical-skills/patient-safety]]；阶梯——治疗触发并简化抗胆碱的药；然后减少或停掉激动剂与司来吉兰两种最可能造成视觉幻觉的药物、把左旋多巴留作“最后一个站着的药”；并向家属警告运动的代价并诚实地解释“看见的东西可能仍会留下来”——[[pharmacology/patient-variation]]；具体的药理——在可及时的“一种血清素的受体的药物”它的机制与QT及“年老痴呆的患者脑血管的告诫”，对氯氮平的那份显著的效力配它监测的编排与心肌炎的警惕；以及奎硫平作为“务实但证据较少”的选择；以及那一条“典型的抗精神病药与大多数的止吐药甲氧氯普胺与丙氯拉齐在路易体疾病的谱系中造成严重的抗精神病药的敏感”这一“从不应发生的事件”的记录——[[cardiovascular/arrhythmias]]、[[psychiatry/psychotic-disorders]]；以及那场与女儿一起的谈话——“你要的东西存在，但排第一位的是减法”（[[clinical-skills/communication]]、[[geriatrics-palliative/symptom-control]]）。**

::: exercise 设计深部脑刺激筛选的路径 {level=3}
为一个国家的卫生系统设计一条公平的、安全的“深部的脑的刺激”的筛选与随访的路径，涵盖证据、公平、能力与治理。
::: solution
**器械是一桩服务，不是一枚螺栓（[[#def-treatment]]）：适格的证据——“在最好的内科的治疗之下仍存在的”运动的波动与麻烦的运动障碍或震颤、而“左旋多巴的反应被保留”或对“以震颤为主的”豁免；疾病的时间与年龄及认知及精神及轴性的症状及姿势的不稳排除，配上试验的数据与“长期的随访”的诚实；以及“外科对内科的管理”的比较、以及“为单侧的震颤的聚焦超声的毁损”这一替代；以及这一切“在被监管与不可及之间”的地理——[[clinical-skills/clinical-reasoning]]；检查与同意——多学科的精神与神经放射的评估；靶点的选择丘脑底核对苍白球对“丘脑的中间腹侧核”；以及关于“电池的更换与程控及硬件及取出”的未来的能力与预见的谈话；以及刺激本身的“说话音量与吞咽”的取舍——被记录为那一整包的同意诉讼的模式就是这样教我们的——[[medical-ethics-law/consent-capacity]]；公平这一层——转诊模式的偏倚女性与少数族裔及农村的患者被转诊不足、以及那个“太老了”的启发法；程控的访视在“旅行与照护者及工作”上的影响；以及“按语言与健康的素养做了调整的”信息；以及“不要让器械的选择变成一场本地的委托的抽签”——把按邮编的变化公布出来（[[public-health/health-systems-economics]]、[[medical-ethics-law/justice-resources]]）。**
