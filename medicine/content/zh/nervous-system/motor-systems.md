无力是人们看神经科最常见的原因之一，也是最值得检查的症状之一，因为运动系统是分层构建的，各层以不同的方式失效。运动皮质、内囊、脊髓、神经根、周围神经、神经肌肉接头乃至肌肉本身受损，都可以使肢体无力。但每一种造成的无力**分布**不同，肌张力不同，反射不同，随时间的演变也不同。读懂这些线索，是神经系统查体的核心技能。

本章描述从皮质到肌肉的运动系统组织、上运动神经元与下运动神经元病灶的区别、基底节和小脑的作用、运动性脑神经，以及如何把查体组合起来定位病灶。

## 最后公路

::: definition 运动神经元与运动单位 {#def-motor-unit}
**下运动神经元**是指胞体位于脊髓前角（或脑干内运动性脑神经核）、轴突经周围神经或脑神经到达骨骼肌的神经元。**运动单位**是一个下运动神经元连同它所支配的全部肌纤维。运动单位小的只有几根纤维（眼外肌，提供精细控制），大的超过一千根（下肢大肌肉，提供力量）。神经元每次放电，该单位的所有纤维都一起收缩。
:::

谢灵顿（Charles Sherrington）把下运动神经元称为**最后公路**：对运动的一切影响，无论来自皮质、脑干、小脑还是脊髓反射，都必须通过它起作用。肌力通过两种方式分级：可以**募集**更多的运动单位，已经激活的单位也可以放电更快（**频率编码**）。募集遵循埃尔伍德·亨尼曼（Elwood Henneman）描述的**大小原则**：小运动单位（神经元小而易兴奋）先被募集，只有在需要更大力量时才加入大运动单位。这使得在低力量时控制精细，因为每增加一个单位只增加一点力量。

上运动神经元从上方控制这些下运动神经元。最重要的通路是**皮质脊髓束**。其纤维起自中央前回的初级运动皮质以及邻近的额叶和顶叶区域，下行经过**内囊后肢**、大脑脚、脑桥基底部和延髓锥体。在延髓下部，约85%–90%的纤维交叉（**锥体交叉**），在对侧脊髓的皮质脊髓侧束中下行；其余纤维不交叉，在皮质脊髓前束中下行。运动皮质按身体的拓扑排列，即**运动小人**：下肢在大脑半球内侧面，然后是躯干、上肢和手，面部在外侧面的最下方。

平行的**皮质延髓**纤维支配运动性脑神经核。这些核大多接受双侧半球的输入，因此一侧皮质病灶很少造成持久的吞咽困难或上面部无力。

## 上运动神经元与下运动神经元体征

::: definition 上运动神经元与下运动神经元病灶 {#def-umn-lmn}
**上运动神经元（UMN）病灶**损害前角细胞以上的下行通路。它造成**锥体束型**分布的无力（上肢伸肌弱于屈肌；下肢屈肌弱于伸肌）、**痉挛性**肌张力增高、腱反射活跃，有时有阵挛，以及**跖反射伸性**（Babinski征）。肌萎缩无或轻微，且出现较晚。

**下运动神经元（LMN）病灶**损害前角细胞、神经根或周围神经。它造成受损结构分布区的无力、**肌萎缩**、肌张力降低、反射减弱或消失，常有**肌束颤动**（单个运动单位可见的抽动）。跖反射为屈性或引不出。
:::

| 体征 | 上运动神经元 | 下运动神经元 | 神经肌肉接头 | 肌肉 |
|---|---|---|---|---|
| 分布 | 锥体束型；常为一侧或双下肢 | 神经根、神经或前角的支配区 | 易疲劳；眼、延髓、近端 | 通常近端、对称 |
| 肌萎缩 | 轻 | 明显 | 无 | 晚期出现，与无力程度相称 |
| 肌张力 | 增高（痉挛性） | 降低 | 正常 | 正常或降低 |
| 反射 | 活跃 | 减弱或消失 | 正常 | 正常，晚期消失 |
| 跖反射 | 伸性 | 屈性 | 屈性 | 屈性 |
| 肌束颤动 | 无 | 有（尤其前角病变） | 无 | 无 |
| 感觉缺失 | 取决于部位 | 神经根或神经病灶时存在 | 无 | 无 |

::: proof 为什么上运动神经元病灶引起痉挛
上运动神经元病灶之后，脊髓内的牵张反射环路失去下行控制。皮质脊髓束与网状脊髓束及其他脑干通路并行，后者正常时抑制牵张反射活动，而它们通常一同受损。在数天到数周内，脊髓环路发生重组：对牵张反射的抑制减弱，运动神经元的兴奋性增高。结果就是**痉挛**，即对被动牵拉的阻力呈速度依赖性增高：检查者移动肢体越快，阻力越大，有时会突然松开（“折刀样”）。这需要时间才能形成，因此急性UMN病灶，例如卒中后最初数小时或脊髓损伤后（脊髓休克），起初可表现为肌张力降低和反射消失。
:::

::: warning 早期UMN病灶可以像LMN病灶
在大面积卒中或急性脊髓损伤后的最初数小时或数天，受累肢体可以是弛缓性的，反射消失。双下肢弛缓性瘫痪伴感觉平面和尿潴留，是脊髓病灶而非神经病，无论反射表现如何。即使腱反射消失，跖反射也可能是伸性的；感觉平面和膀胱是更可靠的线索。把急性脊髓压迫误认为吉兰–巴雷综合征，会延误本可以挽救双腿的MRI检查。
:::

### 肌力分级

肌力用**英国医学研究理事会（MRC）分级**记录：0级，无收缩；1级，可见肌肉轻微收缩；2级，去除重力后可以活动；3级，能对抗重力但不能对抗阻力；4级，能对抗部分阻力；5级，肌力正常。4级涵盖范围很宽，常再分为4−、4和4+。分别记录每一肌群，可以使模式显现出来，并能衡量变化。

**腱反射**检查脊髓的单一节段及其神经根。每个反射都对应一个神经根：肱二头肌反射C5–C6，桡骨膜反射（肱桡肌）C5–C6，肱三头肌反射C7，膝反射L3–L4，踝反射S1。若某一水平的反射消失而上下水平的反射正常或活跃，提示该水平有病灶。**阵挛**是快速牵拉后持续的节律性收缩，通常在踝部检查；超过几次即为异常。

## 逐层定位无力

目标是回答一个问题：病灶在哪里？每一层面都有可辨认的模式。

**皮质。** 对侧面部和上肢无力（大脑中动脉供血区）或下肢无力（大脑前动脉供血区），常伴皮质体征：失语、忽视、视野缺损或皮质感觉缺失（不能通过触摸识别物体）。可出现癫痫发作。

**内囊。** 面部、上肢和下肢的纤维紧密排列在一起，因此一个小的腔隙性梗死就可以造成对侧面部、上肢和下肢同等程度的无力，而无皮质体征：即**纯运动性卒中**。

**脑干。** **交叉性体征**：病灶侧脑神经麻痹伴对侧肢体无力。例如，左侧脑桥腹侧病灶可造成左侧面神经（VII）或展神经（VI）麻痹伴右侧偏瘫。

**脊髓。** 双下肢无力（截瘫）或四肢无力（四肢瘫），病灶以下有UMN体征，伴感觉平面以及膀胱和直肠受累。在病灶水平，若前角细胞或神经根受损，可出现LMN体征。

**神经根（神经根病）。** 沿皮节放射的疼痛、该**肌节**的肌肉无力，以及相应反射消失。常见的例子是颈部的C6和C7，以及腰部的L5和S1。

**神经丛。** 一侧肢体内神经根和神经模式的斑片状混合，常伴疼痛（例如臂丛的神经痛性肌萎缩）。

**周围神经。** 无力和感觉缺失局限于一条神经的支配区（单神经病），或在多发性神经病中呈远端对称分布。

**神经肌肉接头。** 易疲劳的无力，典型地累及眼睑、眼球运动、面部、吞咽和近端肢体，反射和感觉正常。重症肌无力是主要的例子。

**肌肉。** 对称性近端无力（从椅子上站起、上楼梯、举臂过头困难），无感觉缺失，反射保留至晚期。

::: theorem 先定位，再命名疾病 {#thm-localise}
神经系统查体用来在回答“是什么？”之前先回答“在哪里？”。一旦知道了层面，**时间进程**就能缩小病因范围。数秒至数分钟提示血管事件或癫痫发作；数小时至数天提示炎症、感染或突然失代偿的压迫性病灶；数周至数月提示肿瘤或缓慢进展的炎症性疾病；数月至数年提示变性或遗传性疾病。把部位与时间进程（以及患者的年龄和背景）结合起来，通常只剩下一个简短的鉴别诊断清单。
:::

::: example 爬不上楼梯的男人 {#ex-cord}
一位68岁男性，前列腺癌已治疗，胸背中部疼痛六周，夜间和平卧时加重。三天来双下肢逐渐无力、僵硬，今晨不能排尿。双侧屈髋和踝背屈肌力MRC 3级，肌张力增高，膝反射和踝反射活跃，双侧跖反射伸性。针刺觉从乳头稍下方以下减退。双上肢正常。
::: solution
1. **层面。** 双下肢无力伴UMN体征，上肢不受累，有感觉平面和尿潴留：胸段脊髓病灶。
2. **高度。** 感觉平面刚好在T4以下。由于脊髓丘脑束的感觉平面可以比真实病灶低若干节段，病灶位于约T4–T6或其以上。
3. **时间进程与背景。** 数周的夜间疼痛，然后数天的进行性无力，发生在前列腺癌患者身上：在被证实不是之前，都应按**转移性脊髓压迫**处理。
4. **处理。** 紧急全脊柱MRI（不只是胸段，因为常有不止一个节段受累）。常开始使用糖皮质激素以减轻脊髓水肿，确定性治疗（手术减压或放疗）由脊柱和肿瘤团队按当地路径决定（NICE NG234，2023年）。随后是导尿、预防血栓、镇痛和压疮护理。治疗开始时能否行走是治疗后能否行走的最强预测因素，这就是延误代价如此之大的原因。
:::
:::

## 基底节与小脑

有两个大的系统塑造运动，但并不直接投射到脊髓。它们受损引起的是运动紊乱，而不是无力。

**基底节**（尾状核和壳核共同组成纹状体，以及苍白球、丘脑底核和黑质）经丘脑与皮质形成环路。简单地说，**直接通路**易化被选中的运动，**间接通路**抑制相互竞争的运动；来自黑质致密部的多巴胺易化直接通路、抑制间接通路。多巴胺缺失（如帕金森病）使平衡偏向抑制：动作变小变慢（**运动迟缓**），肌肉因**强直**而僵硬（与痉挛不同，强直是整个活动范围内一致、且不依赖速度的肌张力增高），并可出现静止性震颤。间接通路受损（如亨廷顿病）则效果相反，出现过多的不自主运动（**舞蹈症**）。这些疾病是[[nervous-system/movement-disorders]]的主题。

**小脑**把意图的运动与实际的运动相比较并纠正误差。它接收来自皮质的运动指令副本，以及来自脊髓和前庭系统的感觉反馈，再投射回运动皮质（经丘脑）和脑干。一条关键规则是：**一侧小脑半球的病灶影响身体的同侧**，因为其输出交叉一次，而皮质脊髓束又交叉一次。小脑体征包括：

- **共济失调**：动作笨拙、协调不良；步基宽、步态不稳；
- **辨距不良**：越过或达不到目标，见于指鼻试验和跟膝胫试验；
- **意向性震颤**：手指接近目标时震颤加重；
- **轮替运动障碍**：快速交替动作困难；
- **眼震**和**构音障碍**（言语含糊，“吟诗样”语言）。

小脑中线（蚓部）病灶通常由酒精引起，主要影响躯干和步态；半球病灶影响同侧肢体。

## 运动性脑神经

若干脑神经含有运动纤维，它们的无力有特征性模式。

**眼球运动。** **动眼神经（III）**支配大部分眼外肌、上睑提肌和瞳孔括约肌；完全麻痹时眼球处于“下外”位，伴上睑下垂和瞳孔散大。**滑车神经（IV）**支配上斜肌，在眼球内收时使其下转；麻痹引起垂直复视，向下看时（例如下楼梯）加重，并有向健侧的代偿性头倾斜。**展神经（VI）**支配外直肌；麻痹引起水平复视，向患侧看时加重。展神经麻痹可以是颅内压增高的“假性定位体征”，因为该神经颅内行程很长。

**面部。** **面神经（VII）**支配面部表情肌。面肌无力的模式可区分UMN与LMN病灶：

::: definition 上运动神经元与下运动神经元性面瘫 {#def-facial}
在**上运动神经元性面瘫**（例如卒中后）中，无力影响对侧下面部，而前额相对不受累，因为面神经核中支配上面部的部分接受双侧半球的输入。在**下运动神经元性面瘫**（面神经核或面神经病灶，例如Bell麻痹）中，一侧整个面部无力，包括前额：不能抬眉，眼睑不能完全闭合，试图闭眼时眼球上转（Bell现象）。
:::

**Bell麻痹**是一种急性、特发性LMN面瘫，在数小时到一两天内形成。只有在排除其他病因后才能诊断：耳部或腮腺疾病、带状疱疹（Ramsay Hunt综合征，耳部或腭部有疱疹）、莱姆病、卒中（前额不受累）以及双侧面瘫（提示结节病、吉兰–巴雷综合征或莱姆病）。英国指南（NICE临床知识摘要）建议，对发病72小时内就诊的成人，按现行处方集口服糖皮质激素，并保护可能无法闭合的眼睛：使用润滑剂，夜间用胶布贴合眼睑。大多数人在数月内完全恢复。

**延髓肌。** 舌咽神经（IX）、迷走神经（X）和舌下神经（XII）控制软腭、咽、喉和舌。无力有两种模式。在**延髓麻痹**（LMN模式，例如运动神经元病或重症肌无力）中，舌肌萎缩伴肌束颤动，言语带鼻音，下颌反射正常。在**假性延髓麻痹**（双侧UMN病灶，例如多次卒中或运动神经元病）中，舌小而僵硬，言语缓慢费力，下颌反射活跃，可有情绪不稳。二者都会引起危险的吞咽问题和误吸。

::: example 理发店里的歪嘴笑 {#ex-facial}
一位41岁南亚裔男性在理发店发现自己右侧口角下垂。到了晚上，他右眼无法闭合。其他部位无无力。他不能皱右侧额头。外耳道和鼓膜正常，无疱疹，腮腺不大。无皮疹，近期未在林地行走。
::: solution
1. **UMN还是LMN？** 前额受累、眼睑不能闭合：右侧**下运动神经元性**面瘫。卒中通常不累及前额，而且很少不伴其他体征。
2. **寻找病因。** 耳和鼓膜正常、无疱疹，使Ramsay Hunt综合征可能性降低；腮腺正常不支持肿瘤；无蜱接触史使莱姆病可能性降低；仅为单侧。无其他脑神经受累，无肢体无力。
3. **诊断。** Bell麻痹，一个排除性诊断。
4. **处理原则。** 因在72小时内就诊，口服糖皮质激素（按现行处方集和当地指南）；眼部护理以防角膜暴露：白天使用润滑滴眼液，夜间用眼膏并以胶布贴合眼睑；复诊。若眼睛变红或疼痛、三周内无改善或出现其他体征，应紧急转诊。可以告诉他，大多数人能完全或接近完全恢复。
:::
:::

## 作为工具的查体

运动系统查体按固定顺序进行，以免遗漏：**视诊**（姿势、肌萎缩、肌束颤动、异常运动）、**肌张力**、**肌力**、**反射**和**协调**，然后是**步态**。有两项筛查试验特别有用。在**旋前肌漂移试验**中，受检者双臂向前伸直，掌心向上，闭眼；轻微的UMN无力会使一侧手臂旋前并下落。观察一个人走路，往往在做任何其他检查之前就能得出诊断。

| 步态 | 表现 | 典型病因 |
|---|---|---|
| 偏瘫步态 | 上肢屈曲，下肢伸直并向外划半圈（画圈步态） | 卒中 |
| 痉挛性截瘫步态（“剪刀步态”） | 双腿僵硬，膝部交叉，足尖擦地 | 脊髓病灶、脑性瘫痪 |
| 帕金森步态 | 弯腰，小碎步拖行，摆臂减少，转身需要很多步 | 帕金森病 |
| 小脑性步态 | 步基宽，不稳，蹒跚 | 小脑疾病、酒精 |
| 感觉性共济失调步态 | 跺脚，眼看双足，暗处加重 | 后索或粗纤维神经病 |
| 跨阈步态（高抬腿） | 高抬足以使下垂的足离地 | 腓总神经麻痹、L5神经根病、神经病 |
| 鸭步 | 躯干左右摇摆 | 近端肌无力 |

意识水平也是运动系统查体的一部分。**格拉斯哥昏迷量表（GCS）**对睁眼（1–4分）、言语反应（1–5分）和最佳运动反应（1–6分）计分，总分3至15分。运动评分是对预后最有信息量的部分。完整量表及其在创伤中的应用见[[emergency-critical-care/acute-assessment]]。

::: example 计算GCS {#ex-gcs}
一位23岁女性从马上摔下后被送到急诊。她只在疼痛刺激时睁眼，发出无法理解的声音；按压斜方肌时，她的右手伸向刺激部位。她的左臂在肘部伸直。她的GCS是多少？不对称提示什么？
::: solution
1. **睁眼**：疼痛刺激时睁眼 = 2。
2. **言语**：发出无法理解的声音 = 2。
3. **运动**：按**最佳**反应计分。伸向刺激部位为**定位** = 5。（左臂伸直应得2分，但只计最佳反应。）

GCS = $2 + 2 + 5 = 9$，记为E2 V2 M5。GCS 8分或以下通常提示需要保护气道，因此她接近这一阈值，现在就需要上级医生评估气道。两侧的差异（右侧定位，左侧伸直）是一个偏侧体征，提示右半球病灶，如硬膜外或硬膜下血肿。她需要紧急行头颅和颈椎CT，并请神经外科会诊。
:::
:::

::: example 拍地的脚 {#ex-footdrop}
一位52岁尼日利亚裔女性，减重手术后体重大幅下降，常跷二郎腿坐着。两周来她发现右脚走路时拍地。右侧踝背屈和足外翻肌力MRC 2级；踝内翻和跖屈正常。踝反射存在。足背和小腿外侧下部感觉减退。无背痛。
::: solution
1. **模式。** 背屈（胫骨前肌）和外翻（腓骨肌）无力，**内翻正常**（胫骨后肌）。
2. **神经还是神经根？** 胫骨前肌和腓骨肌由**腓总神经**支配。胫骨后肌由胫神经支配，但它也是L5肌节的肌肉。L5神经根病时内翻也会无力；此处内翻正常，因此病灶在腓总神经，而非L5神经根。
3. **反射。** 踝反射（S1，胫神经）保留，与腓神经病灶一致。
4. **病因。** 腓骨头处受压，该处神经绕骨走行，位置表浅。体重快速下降使保护性的脂肪垫消失，跷腿则压迫神经。

处理：避免跷腿，使用踝足矫形器以安全行走，并复诊。若未见恢复，神经传导检查可确认部位和严重程度。大多数压迫性麻痹在数周至数月内恢复。神经传导检查的表现见[[nervous-system/neuromuscular]]。
:::
:::

::: quiz
下列哪一组表现指向左侧内囊病灶，而不是左侧运动皮质病灶？
- [ ] 右上肢无力伴表达性失语
- [x] 右侧面部、上肢和下肢同等程度无力，无失语、忽视或视野缺损
- [ ] 左侧面肌无力伴右侧上下肢无力
- [ ] 双下肢无力伴感觉平面
::: solution
在内囊中，支配面部、上肢和下肢的运动纤维紧密排列，因此一个小病灶就会造成三者同等程度的无力而无皮质体征（纯运动性卒中，是腔隙性梗死的典型表现）。皮质病灶通常面部和上肢受累重于下肢（或相反），且常伴失语、忽视或视野缺损。交叉性体征提示脑干；双下肢无力伴感觉平面提示脊髓。
:::

::: history
1870年，古斯塔夫·弗里奇（Gustav Fritsch）和爱德华·希齐希（Eduard Hitzig）证明电刺激狗的额叶皮质会引起对侧肢体运动；约翰·休林斯·杰克逊（John Hughlings Jackson）研究局灶性发作的扩散（“杰克逊扩展”），认为皮质含有运动的有序拓扑图。约瑟夫·巴宾斯基（Joseph Babinski）于1896年描述了作为锥体束病变体征的跖反射伸性反应。查尔斯·谢灵顿（Charles Sherrington）关于反射和运动神经元的工作总结在《神经系统的整合作用》（*The Integrative Action of the Nervous System*，1906年）中，他提出了“最后公路”一词，并于1932年分享了诺贝尔奖。1937年，怀尔德·彭菲尔德（Wilder Penfield）和埃德温·博尔德雷（Edwin Boldrey）在癫痫手术中绘制了人类运动和感觉皮质图，得到了“小人”。1957年，埃尔伍德·亨尼曼（Elwood Henneman）描述了运动单位按大小有序募集；1974年，格雷厄姆·蒂斯代尔（Graham Teasdale）和布赖恩·詹尼特（Bryan Jennett）发表了格拉斯哥昏迷量表。
:::

## 后续内容

基底节疾病见[[nervous-system/movement-disorders]]；合并运动和感觉缺失的卒中综合征见[[nervous-system/stroke]]；同时损害上、下运动神经元的运动神经元病见[[nervous-system/dementia-neurodegeneration]]；神经、接头和肌肉的疾病见[[nervous-system/neuromuscular]]。与运动传导束并行的感觉通路见[[nervous-system/sensory-systems]]。

::: summary
- 下运动神经元是最后公路；肌力通过募集（按大小原则先募集小单位）和放电频率分级。
- 皮质脊髓束经过内囊和脑干，在延髓下部交叉。
- 上运动神经元病灶：锥体束型无力、痉挛、反射活跃、跖反射伸性、肌萎缩轻。下运动神经元病灶：肌萎缩、肌束颤动、肌张力和反射降低。
- 在卒中或脊髓损伤后最初数小时，UMN病灶可以是弛缓性且无反射的；应依靠感觉平面、膀胱和跖反射。
- 逐层定位（皮质、内囊、脑干、脊髓、神经根、神经丛、神经、接头、肌肉），然后用时间进程命名疾病。
- 基底节调整和选择运动（多巴胺缺失引起运动迟缓和强直）；小脑纠正运动（病灶引起同侧共济失调、辨距不良和意向性震颤）。
- UMN面瘫不累及前额；LMN面瘫（Bell麻痹）累及前额。延髓麻痹为LMN性；假性延髓麻痹为双侧UMN性。
- 步态和旋前肌漂移是快速、敏感的筛查试验；GCS记录意识水平，其运动评分是最佳的单项预测指标。
:::

## 习题

::: exercise 计算GCS总分 {level=1 check="6"}
一名男性在疼痛刺激时睁眼，无言语反应，对疼痛刺激出现异常屈曲（去皮质姿势）。他的GCS是多少？
::: solution
疼痛刺激睁眼 = 2；无言语反应 = 1；异常屈曲 = 3。GCS $= 2 + 1 + 3 = 6$。

注意：如果屈曲是对疼痛的正常回撤，应得4分，总分为$2 + 1 + 4 = 7$。题目描述的是异常（去皮质）屈曲，所以答案是6。
:::
:::

::: exercise UMN还是LMN？ {level=1}
把下列体征分为上运动神经元或下运动神经元体征：(a) 肌束颤动；(b) 跖反射伸性；(c) 折刀样肌张力增高；(d) 第一骨间背侧肌明显萎缩；(e) 踝反射消失；(f) 持续性踝阵挛。
::: solution
(a) LMN；(b) UMN；(c) UMN（痉挛）；(d) LMN；(e) LMN（或反射弧的感觉部分病灶）；(f) UMN。

::: exercise 神经传导计算 {level=2 check="55.6"}
在神经传导检查中，分别在肘部和腕部刺激正中神经。肘部刺激后8.0 ms、腕部刺激后3.5 ms在拇短展肌记录到反应。两个刺激点之间的距离为250 mm。前臂传导速度是多少m/s？保留一位小数。
::: solution
两个潜伏期相减，消去了在神经肌肉接头和肌肉中耗费的时间：$8.0 - 3.5 = 4.5$ ms。速度 $= 250 \text{ mm} / 4.5 \text{ ms} = 55.6$ mm/ms $= 55.6$ m/s。这在前臂正中神经的正常范围内（大约在50 m/s以上）；明显减慢提示脱髓鞘。
:::
:::

::: exercise 交叉性体征 {level=2}
一位66岁男性突然出现向左看时复视、包括前额在内的左侧整个面部无力，以及右侧上下肢无力伴右侧跖反射伸性。病灶在哪里？解释每一项体征。
::: solution
病灶位于脑桥尾部左侧。左侧展神经（VI）核或其纤维受累，导致左外直肌无力和向左注视时复视。左侧面神经（VII）核或其纤维（绕展神经核走行）受累，导致伴前额无力的LMN面瘫。左侧脑桥基底部的皮质脊髓纤维尚未交叉（它们在延髓交叉），因此右侧上下肢无力伴UMN体征。同侧脑神经麻痹伴对侧偏瘫是脑干病灶的标志（此处为Millard–Gubler综合征的模式）；在他这个年龄，最可能的病因是小血管或基底动脉分支梗死。
:::
:::

::: exercise 近端无力 {level=2}
一位58岁女性三个月来从矮椅子上站起困难，举臂洗头困难。无感觉缺失，反射正常，无肌束颤动，眼睑和眼球运动正常。病灶可能在哪里？病史和查体中哪些特征有助于找到病因？
::: solution
对称性近端无力，无感觉缺失，反射保留，提示肌病。有帮助的特征：药物（他汀类、糖皮质激素、酒精）；眼睑或指节皮疹（皮肌炎）；肌痛；深色尿；吞咽困难；气短（部分炎症性肌病伴间质性肺病）；甲状腺或肾上腺疾病的症状；体重下降（癌症可与皮肌炎相关）；家族史；以及无力是否波动或易疲劳（重症肌无力可表现为近端无力，即使没有眼部体征）。初步检查包括肌酸激酶、甲状腺功能、炎症指标和电解质；根据需要再行肌炎抗体、肌电图、肌肉MRI和活检。见[[nervous-system/neuromuscular]]。
:::

::: exercise 急性软瘫的双腿 {level=3}
一位35岁女性先出现背痛，随后18小时内双下肢弛缓性无力，膝反射和踝反射消失。她下胸部有一圈麻刺感，已10小时未排尿。一位同事提出是吉兰–巴雷综合征。讨论鉴别诊断，说明哪一项表现最有力地反驳这一提议，以及下一步做什么。
::: solution
尿潴留和躯干某一水平的束带样感觉异常是关键表现：它们指向脊髓。吉兰–巴雷综合征可引起自主神经功能紊乱，但很少出现清楚的感觉平面伴早期、持续的尿潴留。反射消失可由急性脊髓病灶的脊髓休克解释。鉴别诊断包括急性脊髓压迫（硬膜外脓肿、血肿、椎间盘、肿瘤）、横贯性脊髓炎（特发性、多发性硬化、视神经脊髓炎谱系疾病、MOG抗体病、感染）和脊髓梗死（突然起病，常伴背痛，后索感觉保留）。下一步是紧急全脊柱MRI；若发现压迫，紧急转神经外科。若无压迫，行脑MRI、脑脊液检查和抗体检测（水通道蛋白4、MOG），并开始脊髓炎的急性治疗。现在就需要膀胱扫描和导尿。
:::

::: exercise 无力与时间 {level=3}
运用[[#thm-localise]]，对每一情景说出最可能的层面和最可能的病因：(a) 72岁男性突发右上肢和面部无力及找词困难，20分钟内缓解；(b) 25岁女性腹泻两周后出现三天的双下肢上升性麻刺感和无力，反射消失，无感觉平面；(c) 60岁男性一年来进行性双手无力和萎缩，上下肢肌束颤动，反射活跃；(d) 30岁女性复视和上睑下垂，傍晚加重。
::: solution
(a) 左半球皮质（面部和上肢无力伴失语）；突然且短暂：短暂性脑缺血发作，需当天专科评估。(b) 周围神经，对称且累及神经根：*空肠弯曲菌*感染后的吉兰–巴雷综合征；需要监测肺活量和吞咽。(c) 上、下运动神经元同时受累，无感觉缺失，一年内进行性加重：运动神经元病。伴神经根受压的颈椎脊髓病可以模拟此病，应予排除。(d) 神经肌肉接头，易疲劳：重症肌无力。
