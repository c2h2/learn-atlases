运动系统是神经病学中“仅凭一副诊查包与一张诊查床就能查到认证水平”的那部分：**无力有自己的模式，而模式会喊出层次的名字——肌、神经肌肉的接合处、周围神经、前角的细胞、神经根或神经丛、皮质脊髓束，或皮质。**上对下运动神经元的区分是临床医学的第一场伟大的分类练习、而“锥体系对锥体外系”的对比把你送进下一章。

本章涵盖解剖的层次与它们的体征、作为最常见病因的卒中单独处理、神经的损伤与麻痹、重症肌无力与接合处、以及运动神经元这一组。

## 运动系统的层次

::: definition 上下运动神经元的体征 {#def-umnlmn}
**下运动神经元的病灶（软的无力伴“肌的消瘦与肌束的颤动”及反射的减少或消失、没有巴宾斯基——是“前角的细胞、神经根、神经丛、神经或肌”的签名；配上“节段肌节的地图”与“周围神经的领地的地图”这两张你叠在病史上的网格；以及“神经传导的检查与肌电图”的电诊断的确证（带着它们的纤颤与正锐波及运动单位形态）——见[[clinical-skills/physical-examination]]与[[clinical-skills/laboratory-tests]]）；上运动神经元的病灶（痉挛的无力伴“随速度而变的折刀样的”张力增高、反射亢进、“伸肌的足底反应”、常常还有霍夫曼与踝阵挛——“除了失用之外肌容积得以保留”——是皮质脊髓束的签名；以及那“急期的脊髓或脑的休克”，它让急性的脊髓或半球的病灶起初是软的、无反射的，“直到张力回来”——这是急症医学里被读错最多的一个查体发现）；学员会被扣分的鉴别的细节——“臂的锥体系的分布伸肌比屈肌弱”与“腿的屈肌比伸肌弱”，对“肌病近端的无力”，对“因疼痛或不充分的用力的那种让路样的无力”；“垂腕对桡神经对骨间后的”解剖；以及“手的内在肌的消瘦”的模式它们把尺神经与第八颈第一胸及前角的细胞的疾病分开；还有那两个“坐在运动神经元之上并改变它的体征”的综合征——[[nervous-system/movement-disorders]]里的锥体外系的运动障碍（强直而不痉挛、反射正常、没有巴宾斯基）；以及那个“不协调而无力的丧失、张力低下、钟摆样的反射、意图的震颤、以及快速轮替动作的障碍”的小脑的世界——在“肌力的检查近乎正常”时家属把它叫做“没劲”。感觉的共同定位是必须的同伴：一个纯粹运动的缺失是一份不同的清单运动神经元病与“多灶的运动神经病”及肌无力及肌病、以及某些神经的病灶，与“混合感觉运动的”一份多发的神经病与神经丛及神经根及脊髓及脑完全不同；而“腱的反射与巴宾斯基这一对，加上袜套样的感觉平面”就是决定病灶在哪里的四个发现（[[nervous-system/sensory-systems]]、[[anatomy/neuroanatomy]]。）**
:::

## 按病程排列的无力

::: definition 按病程排列的无力 {#def-timecourse}
**超急性的无力以秒与分钟计的起病喊出了血管与创伤的机制——卒中与“短暂的脑缺血”的算术见[[nervous-system/stroke]]；创伤的脊髓与神经根及神经丛的损伤带着它们的外科的时间表——[[surgery/orthopaedics]]；以及“脊髓的出血与压迫的急症”：硬膜外的积脓与“在抗凝者身上的血肿”及转移的脊髓的压迫——在这里，“数小时之内的激素与影像及神经外科”决定的是行走的结局与膀胱（和腿一起——转移的那几页见[[pathology/cancer-biology]]、脓毒症的那几行见[[infectious-diseases/fever-sepsis]]、临床的图景见[[nervous-system/neuroinflammation]]）；急性到亚急性以日到周计——格林-巴利综合征与它的变异型伴“上升无反射的无力”及呼吸与自主的监测、以及“蛋白与细胞分离”的脑脊液、以及“免疫球蛋白对血浆置换”的等价、以及“感染后分子的模拟”这一机制；横贯性的脊髓炎；血管炎的神经病与“多发的单神经炎”；肌炎；肉毒中毒（伴它那“向下的、累及瞳孔的麻痹”；以及蜱与毒物清单——[[nervous-system/neuroinflammation]]、[[emergency-critical-care/poisoning]]、[[microbiology/bacterial-pathogenesis]]）；复发的模式（多发性硬化与它在时间与空间上的播散、伴视与感觉及脊髓的表现、以及“改变疾病治疗的时代”——[[nervous-system/neuroinflammation]]）；以及隐匿的模式以月到年计——肌的营养不良与代谢的肌病带着它们的肌酸的激酶与遗传及活检的路径——[[genetics/mendelian-inheritance]]、[[cell-biochemistry/proteins-enzymes]]；压迫性与变性的脊髓的脊髓病伴颈椎骨性增生的改变与“那种手的表现”；神经纤维瘤病周围神经的瘤——[[genetics/cancer-genetics]]；运动神经元病（把上下运动神经元的体征合在一起而不伴感觉的丢失；以及帕金森综合征——一种“假装成无力的缓慢”——[[nervous-system/movement-disorders]]）。对称性与梯度完成了大部分的工作：远端对称的（按长度依赖的神经病）；近端对称的（肌病与肌无力及“神经肌肉的接合处”）；不对称的多灶的（多发的单神经炎与神经丛的病及“运动神经病”）；以及“有平面的”（脊髓的）。把这张网格与病程叠在一起，多数病例“在你触摸到反射锤之前”就已经有了方向（[[clinical-skills/clinical-reasoning]]。）**
:::

## 周围神经、神经根与接合处

::: definition 神经的损伤、嵌压与神经根的病 {#def-peripheral}
**灶性神经的病灶正中神经在腕部的腕管：伴“夜间的感觉异常与鱼际的消瘦”、以及妊娠与甲状腺功能减退及糖尿病及透析的关联——[[endocrine/thyroid]]；尺神经在肘部：伴“第四第五指的发麻”与“腕屈肌保留”征及“手指分离”征、以及“肘管对更深的病灶”的逻辑；桡神经：经典的“骨折与拐杖与醉汉的夜晚”的麻痹；腓总神经在腓骨的小头：在体重下降与分娩及石膏之后；以及“股外侧的皮神经”的那种“感觉异常性股痛”（带着它肥胖与紧身裤的病史；以及那幅“嵌压叠加在全身性的之上”的图景——多发的神经病把嵌压揭示出来——[[clinical-skills/physical-examination]]）；神经根的病灶颈与腰骶的神经根病那“按皮区的疼痛与发麻及肌节及反射”的三联——“第五腰与第一骶与第四腰”的鉴别、直腿抬高与它的交叉的变异、以及马尾的危险信号：鞍区的麻木与尿潴留及双侧的坐骨神经痛——它们要求“同一小时的磁共振与减压（配一个被记录的膀胱的扫描”；以及那个悖论：“绝大多数急性的椎间盘与绝大多数的坐骨神经痛会不经手术而好转”，而影像的发现必须与临床的节段相匹配——[[musculoskeletal/back-pain]]、[[clinical-skills/medical-imaging]]、[[clinical-skills/patient-safety]]）；神经丛的综合征糖尿病性与感染后的“神经痛性的肌萎缩”：数日的“肩胛的剧痛”之后是“斑片样深度的无力”、免疫的机制；放射诱发的与“肿瘤浸润的”（伴霍纳与手的水肿及疼痛；产科臂丛的损伤（带着它漫长的外科的康复；以及“麻醉与重症监护体位的麻痹”——它们在同一间病房里绝不该发生第二次——[[surgery/perioperative-care]]、[[emergency-critical-care/critical-care]]）；以及作为“一份被写好的病史”的多发的神经病——“按长度依赖的袜套-手套样的”阳性与阴性的症状伴远端的无力及“踝的反射的早期丧失”，对“神经传导上的脱髓鞘与轴索的”模式；以及那份病因的短名单：糖尿病与酒精及“维生素B12与叶酸及硫胺（湿性的脚气病与再喂养）及肾衰竭与甲状腺功能减退及乳糜及淀粉样与”人类的免疫缺陷病毒“及”药物的（铂类与长春花及呋喃妥因及甲硝唑）“——[[clinical-skills/laboratory-tests]]、[[pharmacology/adverse-reactions]]、[[renal/chronic-kidney-disease]]、[[gastrointestinal/bowel-disease]]。）**
:::

::: definition 肌无力与接合处 {#def-nmj}
**重症肌无力是“可疲劳的无力”，落在眼、球、肢与呼吸的肌上——上睑的下垂与“在一天中游走并变化的复视”、随一句话的进行而“变成鼻音与构音障碍的言语”、会累的咀嚼、颈的屈肌的无力、肢带的易疲劳——而感觉正常、反射正常或活跃、张力正常，这就是它的诊断的指纹。免疫学就是要点：在大多数全身性的病例中是“突触后乙酰胆碱受体的自身抗体”；在“球与眼与呼吸为主的”一亚组是“肌肉特异的激酶”的抗体（它的机制由抗体介导、而“对新斯的明的反应更差”）；“低密度脂蛋白受体相关的蛋白5”罕见；以及那部分“需要单纤维的肌电图与专门的检测”的血清阴性的少数。胸腺是那个辅助——在“早发的疾病”中的胸腺的增生、以及少数人的胸腺瘤（它的发现会改变肿瘤的处理、而它的副肿瘤的关联——肌无力与红细胞再生障碍及“丙种球蛋白的减少”——值得一次自己的筛查）——[[immunology/tolerance-regulation]]、[[blood/anaemia]]、[[immunology/immunodeficiency]]。诊断——模式加受体的抗体、冰袋的试验、床旁那套“休息与疲劳”的检查、单纤维肌电图的“抖动”、以及“重复神经刺激的递减”——加上“对新斯的明的反应”这一药理的证明带着它诚实的局限。治疗：对症的新斯的明；为免疫的疾病用皮质激素与“省激素的药”；在“受体阳性全身的疾病中按试验的证据做胸腺的切除它要数年才见效”；为危象与术前的优化做“血浆置换与免疫球蛋白”；以及在难治的疾病中“新的”Fc的受体的抑制剂与补体的阻断带着它们的感染与疫苗的告诫——[[immunology/vaccines-immunotherapy]]、[[infectious-diseases/immunocompromised-host]]。肌无力的危象（球的衰竭与误吸的风险、以及在病房里被序列追踪的“不断下降的肺活量”——“考虑通气的二十对十五”的规则，以及“在一种波动的疾病里绝不信单次的用力肺活量”那条规则），对那一段历史如今已经在讲的“在治疗过度年代里的胆碱能的危象”；以及那些会把肌无力揭示出来或加重的药物（β的阻滞剂与氨基糖苷及大环内酯及镁及喹诺酮及“神经肌肉的阻滞剂”——[[pharmacology/adverse-reactions]]、[[surgery/anaesthesia-pain]]。）**
:::

**伴“节段的手的改变”的颈椎的脊髓病——这个组合喊出了脊髓的名字（[[#def-umnlmn]]、[[musculoskeletal/back-pain]]）：解读——在受压的那个平面上手的萎缩与无反射（前角与神经根的累及）、平面以下的痉挛与巴宾斯基皮质脊髓束，加上膀胱的尿急，这是那幅“骗着临床医师作出周围的诊断”的经典混合图景；而“莱米特与前手发麻的变异型”值得问同样的反射——[[nervous-system/sensory-systems]]、[[clinical-skills/physical-examination]]；检查——颈段的磁共振配“脊髓信号的改变”一问、鉴别是“维生素B12与叶酸及甲状腺及梅毒及脱髓鞘及运动神经元病”那个“纯运动的模仿者”，用化验；而当怀疑还在时，用神经生理——[[blood/anaemia]]、[[nervous-system/neuroinflammation]]、[[clinical-skills/laboratory-tests]]；外科的决定——“可手术的脊髓病”按功能与轨迹、而不是按片子的戏剧来分级；“中度的或严重的或在进展的”进入减压前路对后路及节段的数目、以及“第五颈的麻痹与再灌注的损伤”的咨询，而“轻度而稳定的”进入被记录了危险信号的监测；以及那份时机的诚实——“已经确立的膀胱与手的内在肌的丧失恢复得很差，而步态会先改善”——[[surgery/orthopaedics]]、[[clinical-skills/communication]]；以及非手术的那份照护——跌倒与手的治疗与驾驶、以及那封写给“整脊与物理治疗”的信里写明的“不要对脊髓病的颈动手法”的规则；加上那位在风湿科相邻患者身上的“相邻节段与韧带的骨化”的背景——[[musculoskeletal/bones-joints]]。**

## 通向何处

各种血管形式的卒中在[[nervous-system/stroke]]；脱髓鞘与炎症的神经病在[[nervous-system/neuroinflammation]]；脊髓与外科的压迫的急症在[[musculoskeletal/back-pain]]与[[surgery/orthopaedics]]；建立在基底节的环路之上的运动障碍在[[nervous-system/movement-disorders]]；神经肌肉的遗传学在[[genetics/mendelian-inheritance]]。

::: history
**运动的定位是生理学最盛大的侦探故事之一：贝尔与马让迪在1811到1822年“把前根运动与后根感觉分开”——这既是在动物身上做的、也是“在同代以为一根纤维两者都做的人面前”争来的——以及随之而来的“临床神经根的综合征”；布朗-塞卡尔在法国士兵身上的“半脊髓的生理学”、以及那个在诸多保留意见中幸存下来的名字；沙可的学派——杜兴的功能的神经病学与“用一把椅子诊断一个世纪的卒中与脊髓的病”、沙可本人“在诊查床边带着他的病人”讲授肌萎缩的侧索硬化、以及他也解剖过的“伟大的模仿者”癔症的角色；以及玛丽与富瓦的传导束的解剖——[[anatomy/neuroanatomy]]。周围神经的时代——第一次世界大战时期腕管的描述与它的手术松解的教训、以及那两个同名征、以及“让嵌压变得可测量的神经传导的工位”——[[clinical-skills/laboratory-tests]]。肌无力的旅程——从年轻女性身上那“致命的球麻痹”路易与黑布及约利的描述；战时创伤的外科中关于胸腺的切除的发现；辛普森在1960年代抗体的假说、以及帕特里克与林斯特罗姆受体免疫的模型，到今天那“由抗体定义、以补体为靶”的疾病——这是“从实验台到病床”的免疫学被记录得最好的胜利之一——[[immunology/autoimmunity]]、[[immunology/adaptive-responses]]。吉兰-巴雷-巴内与施特罗尔那个三角在1859到1860年代被描述、并在1976年的“猪流感监测的关注”之后被重画；而“空肠弯曲菌与分子的模拟”的工作把一个“感染后的谜”变成了一种“具体的抗神经节苷脂的机制”，带着诊断的血检与动物的模型。以及电诊断的革命——神经传导的检查与肌电图及单纤维的技术——它们让接合处与神经根“有了可以被测量的签名”（[[clinical-skills/laboratory-tests]]、[[physiology/muscle]]）。**
:::

::: summary
- 先按层次为无力分类上运动神经元对下运动神经元对接合处对肌对小脑与锥体外系、然后按病程、最后按对称性与梯度。
- 一条急性的“软的、无反射的”肢体，仍可能是“在脊髓或脑的休克中的急性的上运动神经元的病灶”；重新检查。
- “疼痛斑片样多灶的缺失”伴全身的特征，在被排除之前就是血管炎；神经的恢复是时间关键的。
- “可疲劳的眼与球的无力”伴反射正常，在抗体说话之前就是肌无力；查纵隔与肺活量。
- 上升的无反射“首先是一桩气道、自主与通气的问题、然后才是免疫学的问题”；尽早治疗。
- 危险信号的运动综合征是“按钟点的急症”：脊髓的压迫与马尾与肌无力的危象、“伴球或呼吸的体征的格林-巴利”、以及肉毒中毒。
:::
