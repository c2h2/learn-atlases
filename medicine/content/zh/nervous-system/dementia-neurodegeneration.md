神经退行性疾病是指特定神经元群通常在数年内进行性死亡的一类疾病。大多数与错误折叠蛋白的蓄积有关：阿尔茨海默病中的β-淀粉样蛋白和tau蛋白，帕金森病和路易体痴呆中的α-突触核蛋白，大多数运动神经元病和许多额颞叶痴呆中的TDP-43，以及克雅病中的朊蛋白。哪些神经元受累决定了临床表现：阿尔茨海默病为记忆，额颞叶痴呆为行为和语言，运动神经元病为运动神经元，共济失调为小脑。

本章介绍痴呆（评估、主要类型、可逆病因和治疗）、运动神经元病、小脑性共济失调和朊病毒病。英国痴呆的处理遵循NICE NG97（《痴呆》，2018年），运动神经元病的处理遵循NICE NG42（2016年，2019年更新）。对痴呆患者的照护，包括谵妄，在[[geriatrics-palliative/delirium-dementia-care]]中进一步展开。

## 痴呆

::: definition 痴呆与轻度认知障碍 {#def-dementia}
**痴呆**（重度神经认知障碍）是一个或多个认知领域（记忆、执行功能、语言、视空间功能、注意、社会认知）的获得性减退，其严重程度足以影响日常活动的独立性，且不能用谵妄或其他精神障碍解释。它是一种由多种病因引起的综合征，本身并不是一种疾病。

**轻度认知障碍**是指经检测证实、超出年龄和教育程度预期的认知减退，但日常独立性保留。轻度认知障碍者中有一部分人，尤其是有阿尔茨海默病理证据者，每年进展为痴呆；另一些人保持稳定或有所改善。
:::

据估计，英国有近一百万人患痴呆，并随人口老龄化而增加。年龄是最强的危险因素。2024年《柳叶刀》痴呆委员会确定了贯穿生命历程的14个潜在可改变的危险因素，包括受教育较少、听力下降、高LDL胆固醇、高血压、吸烟、肥胖、缺乏体力活动、糖尿病、过量饮酒、抑郁、社交孤立、空气污染、创伤性脑损伤和未治疗的视力丧失，并估计通过干预这些因素，原则上近一半的痴呆可以预防或推迟。听力下降和高LDL胆固醇的人群归因分值最大。

### 评估有记忆问题的人

评估有四个目的：确认是否存在认知障碍；描述其模式；找出任何可逆或促成的病因；以及了解什么对患者及其家人最重要。

- **病史**，来自本人和一位熟悉他的人：哪些能力发生了变化，变化的顺序和速度，对日常生活的影响，情绪、睡眠、幻觉、跌倒、驾驶、饮酒和用药。
- 用结构化工具进行**认知测试**，如Addenbrooke认知检查（ACE-III，100分）、蒙特利尔认知评估（MoCA，30分），在初级保健中可用6项认知障碍测试等较短的工具。分数必须结合年龄、教育程度、语言和文化来解读；以一种语言和文化设计的测试可能低估来自其他语言文化者的能力，应使用口译和经文化调适的工具。
- **体格和神经系统检查**：帕金森症状、步态、局灶体征、眼球运动、原始反射、血管疾病体征。
- **血液检查**以排除可逆的促成因素：全血细胞计数、尿素和电解质、钙、血糖或HbA1c、肝功能、甲状腺功能、维生素B12和叶酸；有指征时查梅毒和HIV血清学。
- **脑结构影像**（MRI，不适合时用CT），用于排除其他病因，并显示萎缩模式和血管病变。

可逆或可治疗的促成因素包括抑郁、甲状腺功能减退、B12缺乏、酒精、有抗胆碱能或镇静作用的药物、阻塞性睡眠呼吸暂停、**正常压力脑积水**（步态障碍、尿失禁和认知迟缓三联征，伴脑室扩大）、硬膜下血肿和脑肿瘤。真正“可逆的痴呆”并不常见，但促成因素很常见，值得治疗。

::: warning 谵妄不是痴呆
**谵妄**是一种急性、波动性的注意和意识障碍，通常由疾病、药物或代谢紊乱引起。痴呆患者发生谵妄的风险高得多，两者常同时存在。一个人的思维在数小时到数天内突然改变，在被证实不是之前都应视为谵妄，需要寻找病因（感染、药物、尿潴留、便秘、疼痛、缺氧、电解质）。不应在谵妄发作期间诊断痴呆；应在恢复后重新评估认知。
:::

### 主要类型

| 类型 | 典型早期特征 | 病理 | 影像 |
|---|---|---|---|
| 阿尔茨海默病 | 近事记忆（情景记忆）逐渐丧失，然后出现语言、视空间和执行问题；自知力常下降 | β-淀粉样蛋白斑块、tau神经原纤维缠结 | 内侧颞叶（海马）和顶叶萎缩 |
| 血管性痴呆 | 思维迟缓、执行功能障碍、步态问题、情绪改变；卒中后可呈阶梯式，或小血管病时逐渐进展 | 梗死、小血管病 | 梗死、广泛白质改变 |
| 路易体痴呆 | 注意力波动、反复出现的生动视幻觉、快速眼动睡眠行为障碍、帕金森症状；早期记忆相对保留 | α-突触核蛋白（路易小体） | 内侧颞叶相对保留；DaTscan显示多巴胺转运体摄取减少 |
| 行为变异型额颞叶痴呆 | 脱抑制、淡漠、共情丧失、强迫行为、饮食改变；通常在65岁以下 | tau蛋白或TDP-43 | 额叶和前颞叶萎缩 |
| 原发性进行性失语 | 进行性语言困难：费力的非流利言语、词义丧失（语义变异型），或找词停顿（少词变异型，通常为阿尔茨海默病理） | 多种 | 左侧额叶、前颞叶或颞顶叶萎缩 |

在老年人中，混合病理，尤其是阿尔茨海默病合并血管病变，是常态而非例外。

::: proof 淀粉样蛋白和tau蛋白被认为如何引起阿尔茨海默病
淀粉样前体蛋白是一种膜蛋白，正常情况下被分泌酶切割。先由β-分泌酶、再由γ-分泌酶切割，释放出**β-淀粉样蛋白**肽，尤其是β-淀粉样蛋白42，它们聚集成可溶性寡聚体，然后形成不溶性斑块。**淀粉样蛋白级联假说**认为，淀粉样蛋白蓄积是始发事件：它在症状出现前15–20年开始，并与小胶质细胞炎症一起，促进神经元内异常磷酸化的**tau蛋白**扩散，形成神经原纤维缠结。tau病理以可预测的顺序从内嗅皮质和海马扩散到联合皮质（Braak分期），与神经元丢失和症状相关性最好的是tau负荷而非淀粉样蛋白负荷。支持该假说的证据来自遗传学（*APP*、*PSEN1*和*PSEN2*突变导致早发性家族性阿尔茨海默病；有三份*APP*拷贝的唐氏综合征患者几乎都会出现阿尔茨海默病理），以及清除淀粉样蛋白的抗体所带来的有限临床获益。许多人有大量淀粉样蛋白却没有痴呆，说明了该假说的局限。**APOE ε4**等位基因是迟发性疾病的主要遗传危险因素：一个拷贝使风险增加数倍，两个拷贝增加更多。
:::

### 生物标志物

现在已能在生前通过测量病理来检测阿尔茨海默病。**淀粉样蛋白PET**和**tau PET**显示脑内的蛋白；**脑脊液**显示β-淀粉样蛋白42降低（或β-淀粉样蛋白42/40比值降低）和磷酸化tau升高；而**血液检测**磷酸化tau（尤其是p-tau217）在研究和专科环境中显示出很高的准确性。这些检测回答的问题是“是否存在阿尔茨海默病理？”，而不是“它是否导致了这些症状？”，其预测值取决于被检测的人群：相当一部分认知正常的老年人存在淀粉样蛋白。

### 治疗与照护

**乙酰胆碱酯酶抑制剂**（多奈哌齐、加兰他敏、卡巴拉汀）增加胆碱能突触处的乙酰胆碱，部分代偿基底前脑胆碱能神经元的丢失。NICE NG97推荐将其用于轻至中度阿尔茨海默病，以及路易体痴呆和帕金森病痴呆（后者获益常更大）。**美金刚**是一种NMDA受体拮抗剂，推荐用于不能耐受乙酰胆碱酯酶抑制剂的中度阿尔茨海默病，以及重度阿尔茨海默病，可单用或联用。获益有限且为对症性的：平均而言认知和功能略有改善或下降减缓。乙酰胆碱酯酶抑制剂可引起恶心、腹泻、梦境生动、心动过缓和晕厥，因此要检查脉搏（有指征时做心电图）。不推荐用于额颞叶痴呆，也不推荐用于不伴阿尔茨海默病的血管性痴呆。

**抗淀粉样蛋白单克隆抗体**（仑卡奈单抗和多奈单抗）清除淀粉样斑块，在有早期症状且淀粉样病理得到证实的阿尔茨海默病试验中，18个月内使临床量表上的下降减慢约四分之一到三分之一。它们需要静脉输注和MRI监测，因为存在**淀粉样蛋白相关影像学异常（ARIA）**，即脑水肿或微出血，通常无症状，但偶尔严重，在APOE ε4纯合子中更常见。在英国，MHRA于2024年批准了仑卡奈单抗和多奈单抗（不包括APOE ε4纯合子），但NICE在2025年的指南中出于成本效益原因不推荐在NHS中使用；经上诉后，该评估于2026年被退回NICE重新考虑，读者应查阅当前状况。

**非药物照护**是核心：坦诚并留出时间告知诊断；提供信息和一名指定的照护协调员；对轻至中度痴呆进行认知刺激治疗；支持照护者；预立照护计划，包括在患者仍有决策能力时设立持久授权书（见[[medical-ethics-law/consent-capacity]]）；驾驶评估；以及关注听力、视力、疼痛、情绪和睡眠。

**行为和精神症状**（激越、攻击、游走、精神病性症状）首先通过寻找原因（疼痛、感染、便秘、环境、未满足的需求）和以人为中心的非药物方法来处理。抗精神病药增加痴呆患者卒中和死亡的风险，只有在严重痛苦或有伤害风险时才使用，剂量最低、疗程最短，并定期复查。在路易体痴呆中，抗精神病药可引起严重、有时致命的反应。

::: example 一位总是重复自己的退休护士 {#ex-ad}
一位76岁退休护士由女儿陪同前来。女儿说，两年来母亲开始反复问同样的问题，忘记最近的谈话和约会，最近两次忘了关煤气。她能自理个人卫生，但不再自己管理财务。她说自己的记忆“以我这个年纪来说挺好”。她服用氨氯地平，以及治疗尿急的奥昔布宁。ACE-III为72/100，延迟回忆和言语流畅性明显受损。查体正常。血液检查正常。MRI显示双侧海马萎缩和轻度小血管病。
::: solution
1. **是否为痴呆？** 两年内进行性减退，认知测试异常，复杂活动（财务、厨房安全）独立性丧失：是。
2. **模式。** 早期突出的近事情景记忆丧失伴自知力下降，以及海马萎缩：典型的**阿尔茨海默病**，伴少量血管因素。
3. **促成因素。** 奥昔布宁是一种强抗胆碱能药物，可加重认知障碍；应重新评估，并尽可能换成米拉贝隆等替代药物。检查听力和视力。
4. **需要进一步检查吗？** 在这样典型的表现中，可以临床诊断。生物标志物检测（脑脊液或PET）用于诊断不确定，或检测结果会改变处理时，例如在可获得时判断是否适合抗淀粉样蛋白治疗。
5. **处理原则。** 向她解释诊断（经她同意，如她愿意可让女儿在场）；检查脉搏后提供乙酰胆碱酯酶抑制剂；转介诊断后支持服务；在她仍能作出决定时讨论持久授权书；评估家庭安全（煤气安全装置）；就驾驶和通知DVLA提供建议；并安排定期复查。
:::
:::

::: example 视幻觉与跌倒 {#ex-dlb}
一位71岁印度裔男性一年来“时好时坏”，有持续数小时的发呆和意识模糊。他看到花园里有并不存在的小孩，但并不害怕。妻子说多年来他在睡梦中大喊和挥拳。查体显示轻度双侧强直和动作缓慢。ACE-III显示突出的注意和视空间缺陷，回忆相对保留。在医院一次激越发作后，他被给予氟哌啶醇，随即变得僵硬、发热、不能活动。
::: solution
1. **模式。** 认知波动、反复出现的生动视幻觉、快速眼动睡眠行为障碍和帕金森症状，是**路易体痴呆**的四项核心临床特征（第四版共识报告，2017年）。具备两项或以上核心特征即为很可能的诊断。
2. **支持性检查。** DaTscan显示纹状体多巴胺转运体摄取减少，或多导睡眠图证实快速眼动睡眠期肌张力不消失，可加强诊断。
3. **氟哌啶醇反应。** 严重的**抗精神病药敏感性**是路易体痴呆的特征，可危及生命。应作为药物不良反应醒目记录，并避免使用氟哌啶醇及类似药物。
4. **处理原则。** 乙酰胆碱酯酶抑制剂（常对幻觉和波动有帮助）；对致残的帕金森症状谨慎使用左旋多巴，但可能加重幻觉；处理体位性低血压、便秘和睡眠问题；针对快速眼动睡眠行为障碍采取安全措施；支持他的妻子。若抗精神病药不可避免，需要专科建议，可考虑小剂量喹硫平或氯氮平。
:::
:::

## 运动神经元病

::: definition 运动神经元病 {#def-mnd}
**运动神经元病（MND）**，又称**肌萎缩侧索硬化（ALS）**，是一种累及上、下运动神经元的进行性神经退行性疾病。它在延髓、颈、胸和腰骶区域引起**上运动神经元体征**（痉挛、反射活跃、跖反射伸性）和**下运动神经元体征**（肌萎缩、无力、肌束颤动）的组合，随时间扩散，且无感觉缺失。诊断是临床诊断，由肌电图支持，并须排除类似疾病；Gold Coast标准（2020年）要求有进行性运动障碍，并在至少一个身体区域有上、下运动神经元表现，或在至少两个区域有下运动神经元表现。
:::

终生风险约为1/300。通常在50至70岁起病。约三分之二以肢体无力起病（常不对称，例如手无力或足下垂），约四分之一以**延髓**起病（言语含糊、吞咽困难），在老年女性中更常见。感觉、膀胱功能和眼球运动通常不受累。多达一半的人出现认知或行为改变，约10%–15%符合额颞叶痴呆标准；MND和FTD构成一个谱系，几乎所有MND病例中都有**TDP-43**病理将两者联系起来。约10%有家族史；最常见的遗传原因是**C9orf72**的六核苷酸重复扩增，其次是**SOD1**突变。从症状出现起的中位生存期约为两到三年，通常死于呼吸衰竭，但约10%的人存活超过十年。

需要排除的类似疾病包括伴神经根病的颈椎脊髓病、伴传导阻滞的多灶性运动神经病（可用免疫球蛋白治疗）、重症肌无力、包涵体肌炎、肯尼迪病，以及甲状腺和甲状旁腺疾病。

处理由专科多学科团队负责（NICE NG42）：

- **利鲁唑**是一种谷氨酸释放抑制剂，可适度延长生存期（平均几个月）。**托夫生**是一种降低SOD1蛋白的反义寡核苷酸，2023年在美国、2024年在欧盟获批用于*SOD1*突变者。
- 对呼吸功能不全使用**无创通气**，可改善生存和生活质量。定期监测呼吸功能（用力肺活量、鼻吸气压、夜间血氧，以及端坐呼吸和晨起头痛等症状）。
- **胃造口**以维持营养和水分，最好在呼吸功能下降过多之前放置。
- 言语治疗和**交流辅具**，包括在病程早期进行声音储存。
- 处理流涎、肌肉痉挛、痉挛状态、疼痛、情绪低落和情绪不稳；提供设备和居家改造。
- 尽早坦诚地进行**预立照护计划**，包括关于通气和临终照护的决定（见[[geriatrics-palliative/palliative-care]]）。

::: example 手无力和肌肉抽动 {#ex-mnd}
一位58岁建筑工人右手无力8个月，现在拧螺丝和扣纽扣都很困难。他注意到双臂和大腿肌肉抽动，体重下降了6 kg。查体：右侧第一骨间背侧肌和鱼际肌萎缩，双臂、双大腿和舌肌束颤动，四肢反射活跃，右侧跖反射伸性。感觉正常。他的用力肺活量为2.1 L，预计值为4.2 L。
::: solution
1. **模式。** 下运动神经元体征（肌萎缩、肌束颤动，包括舌）与上运动神经元体征（反射活跃、跖反射伸性）同时出现在多个区域（延髓、颈、腰骶），无感觉缺失，数月内进展：**运动神经元病**。
2. **类似疾病。** 伴神经根受压的颈椎病性脊髓病可引起手肌萎缩和下肢反射活跃，但不会引起舌肌束颤动或下肢广泛的肌束颤动；仍需做颈椎MRI。神经传导检查排除伴传导阻滞的多灶性运动神经病；肌电图显示广泛的失神经和神经再支配。检查甲状腺功能、钙和肌酸激酶。
3. **呼吸功能。** FVC为$2.1/4.2 = 0.50$，即预计值的50%，提示明显的呼吸肌无力。他需要及时进行呼吸评估（包括夜间血氧和夜间低通气症状），并讨论无创通气。
4. **下一步。** 由神经科医生确诊；转诊至MND专科多学科团队；利鲁唑；在适当时进行基因检测（对有家族史者提供，并越来越多地提供给所有人，因为结果可能影响治疗）；尽早讨论胃造口、交流辅具和预立照护计划；并在工作和经济方面支持他和他的家人。
:::
:::

## 小脑性共济失调

**共济失调**是运动的不协调。小脑性共济失调引起步基宽、步态不稳、肢体辨距不良和意向性震颤、构音障碍和眼震（见[[nervous-system/motor-systems]]）。其病因按时间进程和家族史分类。

- **急性**：后颅窝卒中或出血、药物中毒（酒精、苯妥英、锂盐）、Wernicke脑病（伴意识模糊和眼球运动障碍，由维生素B1缺乏引起）、儿童感染后小脑炎，以及Miller Fisher综合征。
- **亚急性**：肿瘤、副肿瘤性小脑变性（例如乳腺癌或卵巢癌伴抗Yo抗体）、免疫介导性共济失调（麸质共济失调、抗GAD），以及朊病毒病。
- **慢性获得性**：酒精相关小脑变性（主要累及蚓部，引起步态共济失调）、甲状腺功能减退、维生素E缺乏，以及小脑型多系统萎缩。
- **遗传性**：**Friedreich共济失调**（常染色体隐性遗传，*FXN*基因GAA重复扩增，儿童期或青春期起病，伴感觉神经病、反射消失、跖反射伸性、脊柱侧弯、心肌病和糖尿病），以及常染色体显性的**脊髓小脑性共济失调**，其中许多与亨廷顿病一样是CAG重复扩增。

::: example 酗酒后站不稳 {#ex-wernicke}
一位49岁大量饮酒的男性，数周来进食很少，被送来时意识模糊，没有支撑不能行走。他有水平眼震、双眼外展无力，步基宽、步态蹒跚。指尖血糖3.4 mmol/L。
::: solution
1. **识别。** 营养不良的大量饮酒者出现意识模糊、眼肌麻痹（或眼震）和共济失调：**Wernicke脑病**，由维生素B1（硫胺素）缺乏引起。只有少数人具备全部三项特征，因此凭怀疑即可诊断。
2. **立即治疗。** 大剂量**肠外维生素B1**（例如英国按处方集静脉给予Pabrinex），在给葡萄糖之前或同时给予，因为葡萄糖代谢会消耗硫胺素，可诱发或加重脑病。纠正低血糖、镁和其他电解质。
3. **寻找其他病因。** 头部外伤（因常有跌倒，行头颅CT）、肝性脑病、酒精戒断、感染，若共济失调不对称还要考虑后颅窝卒中。
4. **预后。** 眼部体征常在数天内改善；共济失调和意识模糊改善较慢。不治疗时可进展为昏迷或**Korsakoff综合征**，即伴虚构的持久性遗忘。对饮酒问题的长期支持是计划的一部分（见[[psychiatry/substance-use]]）。
:::
:::

## 朊病毒病

::: definition 朊病毒病 {#def-prion}
**朊病毒病**（传染性海绵状脑病）是由宿主自身**朊蛋白**（PrP）的错误折叠形式引起的致死性神经退行性疾病。错误折叠的形式作为模板，把正常蛋白转化为更多的错误折叠蛋白，这一自我扩增过程导致神经元丢失和海绵状改变。朊病毒病可以是**散发性的**（最常见）、**遗传性的**（*PRNP*基因突变）或**获得性的**（来自受污染的组织或器械，或在变异型克雅病中来自牛海绵状脑病）。
:::

**散发性克雅病（CJD）**是最常见的形式，每年每百万人中约有1–2人发病，典型年龄为55–75岁。它在数周至数月内引起**快速进展性痴呆**，伴肌阵挛、共济失调、视觉障碍和无动性缄默；大多数人在一年内死亡。检查显示MRI上皮质和基底节弥散受限，部分患者脑电图有周期性尖波复合波，脑脊液**实时振动诱导转化（RT-QuIC）**检测阳性，其特异性很高。**变异型CJD**与牛的牛海绵状脑病有关，累及较年轻的人，主要在英国，以精神和感觉症状起病。目前没有治疗方法。在英国，疑似病例转诊至国家CJD研究与监测中心，手术器械须采取特殊的感染控制措施。

::: quiz
一位63岁男性在18个月内变得脱抑制，对陌生人说不恰当的话，冲动花钱，大量吃甜食。他对这些变化毫不在意。他对近期事件的记忆相对较好。最可能的诊断是什么？
- [ ] 阿尔茨海默病
- [x] 行为变异型额颞叶痴呆
- [ ] 路易体痴呆
- [ ] 血管性痴呆
::: solution
在六十出头的人中出现早期脱抑制、冲动、饮食行为改变（常渴望甜食）和自知力丧失，而记忆相对保留，是行为变异型额颞叶痴呆的特征。MRI典型地显示额叶和前颞叶萎缩。乙酰胆碱酯酶抑制剂无帮助，还可能加重行为问题。应询问家族史，因为相当一部分FTD是遗传性的（*C9orf72*、*MAPT*、*GRN*）。
:::
:::

::: history
1906年，阿洛伊斯·阿尔茨海默（Alois Alzheimer）描述了奥古斯特·德特（Auguste Deter）脑中的斑块和缠结，她55岁时死于进行性记忆丧失和偏执；1910年，埃米尔·克雷佩林（Emil Kraepelin）以他的名字命名了该病。阿诺尔德·皮克（Arnold Pick）于1892年描述了局灶性额叶和颞叶萎缩。让-马丁·沙可（Jean-Martin Charcot）于1869年描述了肌萎缩侧索硬化。尼古劳斯·弗里德赖希（Nikolaus Friedreich）于1863年描述了以他命名的遗传性共济失调。汉斯·格哈德·克罗伊茨费尔特（Hans Gerhard Creutzfeldt，1920年）和阿方斯·雅各布（Alfons Jakob，1921年）描述了后来以他们命名的疾病；1982年，斯坦利·普鲁西纳（Stanley Prusiner）提出由一种传染性蛋白“朊病毒”致病，这项工作于1997年获得诺贝尔奖。1984年，乔治·格伦纳（George Glenner）和凯恩·黄（Caine Wong）分离出β-淀粉样蛋白；1993年，艾伦·罗斯（Allen Roses）等人确定APOE ε4是迟发性阿尔茨海默病的主要遗传危险因素。2006年，TDP-43被确定为MND和许多额颞叶痴呆包涵体中的主要蛋白。
:::

## 后续内容

痴呆和谵妄患者的照护（包括住院期间）见[[geriatrics-palliative/delirium-dementia-care]]；决策能力和预先决定见[[medical-ethics-law/consent-capacity]]；帕金森病和运动障碍见[[nervous-system/movement-disorders]]；认知减退的血管因素见[[nervous-system/stroke]]；MND诊断所依据的运动系统查体见[[nervous-system/motor-systems]]。

::: summary
- 痴呆是损害日常独立性的获得性认知减退；轻度认知障碍保留独立性。首先必须排除谵妄。
- 评估结合知情者提供的病史、结合语言和文化解读的认知测试、查体、寻找促成因素的血液检查和脑影像。
- 阿尔茨海默病（情景记忆丧失、海马萎缩、淀粉样蛋白和tau）、血管性痴呆（思维迟缓、执行和步态问题）、路易体痴呆（波动、视幻觉、快速眼动睡眠行为障碍、帕金森症状、抗精神病药敏感）和额颞叶痴呆（行为或语言、起病较早）是主要类型；混合病理常见。
- 乙酰胆碱酯酶抑制剂和美金刚带来有限的对症获益。抗淀粉样蛋白抗体适度减缓下降，有ARIA风险，其在NHS中的可及性取决于NICE当前的评估。
- 约14个可改变的危险因素，包括听力下降、高LDL胆固醇、高血压、吸烟和缺乏运动，占痴呆风险的很大部分。
- MND兼有上、下运动神经元体征而无感觉缺失；利鲁唑、无创通气、胃造口和多学科照护改善生存和生活质量；托夫生针对*SOD1*型MND。
- 小脑性共济失调按时间进程和遗传方式分类；Friedreich共济失调为隐性遗传（GAA重复）。
- 散发性CJD引起伴肌阵挛的快速进展性痴呆；脑脊液RT-QuIC特异性很高。
:::

一位MND男性的用力肺活量为2.1 L，预计值为4.2 L。他的FVC占预计值的百分比是多少？
::: solution
$2.1 / 4.2 \times 100 = 50\%$。

::: exercise 说出痴呆类型 {level=1}
说出最可能的痴呆类型：(a) 79岁，近事记忆逐渐变差，在熟悉的路上迷路；(b) 66岁，有动物的视幻觉，警觉性波动，步态拖曳；(c) 58岁，丧失了词义，不再能说出常见物品的名称，也认不出名人面孔；(d) 74岁，有糖尿病和两次卒中史，思维变慢，走路变成小碎步。
::: solution
(a) 阿尔茨海默病。(b) 路易体痴呆。(c) 语义变异型原发性进行性失语，一种额颞叶痴呆。(d) 血管性痴呆（皮质下小血管型，伴阶梯式加重）。
:::

::: exercise 可逆的促成因素 {level=1}
列出六种在记忆评估中应寻找的、可引起或加重认知障碍的可治疗情况或因素。
::: solution
以下任意六项：抑郁；甲状腺功能减退；维生素B12缺乏；有抗胆碱能或镇静作用的药物（例如奥昔布宁、阿米替林、苯二氮䓬类、强阿片类）；过量饮酒；听力或视力丧失；阻塞性睡眠呼吸暂停；正常压力脑积水；慢性硬膜下血肿；脑肿瘤；高钙血症或低钠血症；控制不佳的糖尿病伴低血糖；梅毒或HIV；并发疾病引起的谵妄。
:::
:::

::: exercise 初级保健中的生物标志物 {level=2 check="0.5"}
一种检测阿尔茨海默病理的血液检测灵敏度和特异度均为90%。在一组初级保健老年人中使用，其中10%有阿尔茨海默病理。阳性预测值是多少？给出精确的小数。
::: solution
每1,000人中：100人有该病理，其中90人阳性。900名无病理者中，90人阳性（10%假阳性）。PPV $= 90/(90 + 90) = 0.5$。一半的阳性结果是假的。在一半人有该病理的记忆门诊中，同一检测的PPV为0.9。这就是为什么这类检测应用于专科对有症状者的评估，而不是用于筛查。
:::
:::

::: exercise 护理院中的激越 {level=2}
一位84岁中度阿尔茨海默病女性住在护理院，过去一周变得激越，在个人护理时出手打人。工作人员要求开“一些让她平静的药”。你会如何处理？
::: solution
首先寻找原因：一周内的变化提示谵妄或未满足的需求。检查疼痛（例如关节炎、未被目击的跌倒后骨折、牙痛）、感染、便秘、尿潴留、新用药物、助听器或眼镜未使用，以及工作人员或环境的变化。用结构化方法描述行为及其诱因（例如ABC记录表）。非药物措施：护理前先解释、固定的照护者、调整个人护理的时间、音乐和有意义的活动。治疗发现的任何原因，包括疼痛（试用规律的对乙酰氨基酚可减少激越）。只有在采取这些措施后仍有严重痛苦或伤害风险时，才使用抗精神病药，剂量最低、短期使用、数周内复查，并在与她的家人或授权人讨论卒中和死亡风险增加之后使用。
:::
:::

::: exercise MND还是类似疾病？ {level=2}
一位47岁男性三年来左手和右足缓慢进行性无力，伴肌萎缩和一些肌肉痉挛，但无上运动神经元体征，无延髓症状。神经传导检查显示左尺神经和右腓神经运动纤维有传导阻滞，感觉神经正常。可能的诊断是什么？为什么重要？
::: solution
**伴传导阻滞的多灶性运动神经病**，一种免疫介导的运动神经病（常有抗GM1抗体），可模拟下运动神经元型MND。线索是进展缓慢、在单个神经分布区内的纯下运动神经元表现（常从上肢开始），以及神经传导检查显示传导阻滞。它很重要，因为它对静脉免疫球蛋白有反应而MND没有，而且预后完全不同。
:::
:::

::: exercise 快速衰退 {level=3}
一位64岁女性在10周内从生活自理变为需要帮助穿衣。她意识模糊，视物变形，四肢有抽动样动作，步态不稳。讨论快速进展性痴呆的鉴别诊断、检查，以及怀疑朊病毒病时的实际问题。
::: solution
快速进展性痴呆（数周至数月）鉴别诊断范围广，其中许多可以治疗：自身免疫性脑炎（包括抗LGI1及其他）、桥本脑病（伴甲状腺抗体的激素反应性脑病）、感染（HSV、HIV、梅毒、进行性多灶性白质脑病）、血管炎、代谢和中毒原因（低钠血症、Wernicke脑病、锂或铋中毒）、恶性肿瘤（原发性中枢神经系统淋巴瘤、转移瘤、副肿瘤综合征）、非惊厥性癫痫持续状态，以及快速进展的神经退行性疾病，包括她的肌阵挛、视觉症状和共济失调所提示的**散发性CJD**。检查：含弥散加权成像的MRI（CJD时皮质飘带征和基底节弥散受限）、脑电图（周期性尖波复合波；排除非惊厥性持续状态）、脑脊液（细胞计数、蛋白、葡萄糖、寡克隆带、神经元抗体、感染PCR、RT-QuIC、14-3-3蛋白）、血液检查（钠、钙、甲状腺功能和抗体、B12、HIV、梅毒、自身免疫筛查、副肿瘤抗体）以及寻找癌症。怀疑CJD时的实际问题：报告国家CJD研究与监测中心；对神经外科及其他有创操作和器械遵循感染控制指南；就预后与家属进行细致的沟通；姑息照护计划；以及支持。不能因为CJD看似可能就忽视可治疗的病因。
:::
:::

::: exercise 降低痴呆风险 {level=3}
一位52岁男性的母亲患阿尔茨海默病，他询问能做些什么来降低自己患痴呆的风险。他吸烟，每周饮酒30单位，有未治疗的高血压（152/96 mmHg），LDL胆固醇4.6 mmol/L，BMI 31 kg/m²，发现自己在嘈杂环境中听不清，工作时间长，很少运动。你会处理哪些可改变的风险？关于他的家族史你会告诉他什么？
::: solution
针对2024年《柳叶刀》委员会确定的因素：戒烟（提供支持）；把饮酒减少到每周14单位以内；治疗高血压（按委员会和国家指南，中年期收缩压目标为130 mmHg或以下）；治疗LDL胆固醇（按其心血管风险进行降脂治疗）；增加体力活动；体重管理；评估听力，必要时配助听器（听力下降是最大的可改变风险之一）；保持社交和认知活跃。这些措施也能降低卒中和心脏病风险。关于家族史：父母一方患迟发性阿尔茨海默病会使风险适度增加，部分是通过APOE ε4等共同基因；在研究之外不推荐用APOE基因检测进行预测，因为它不能决定他是否会患痴呆，也不改变建议。如果他母亲的发病异常早（例如60岁以前），或有多位亲属受累，应考虑转诊临床遗传学，评估是否为家族性阿尔茨海默病。
:::
:::
