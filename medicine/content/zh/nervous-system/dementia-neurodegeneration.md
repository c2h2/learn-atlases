痴呆与神经变性的疾病是神经病学与“一生的其余部分”相遇之处：**主诉是记忆，但诊断来自“认知与行为的变化、时间线与排除项”这一模式；而处理多半关乎驾驶与跌倒及药物与钱及照护者。**其神经科学是“以不合时宜的缓慢”在推进；而它的临床医学既要求很高又富有人情。

## 痴呆

::: definition 各类及其签名 {#def-types}
**引导一切综合征的分类学——以记忆为先的遗忘的表现，对“非遗忘的”：以语言为先的“原发进行性的失语”的变异；以视觉空间的为先的后部皮层的萎缩；以行为为先的额叶的变异综合征；以及“帕金森与认知的”组合——每一个都由其病理上惯常的元凶负责；而那个认识——“痴呆”是一个有病因的综合征，正如“昏迷”。阿尔茨海默的病隐匿的、渐进的、进展的“情景的记忆与视觉空间及语言”的连串，带着它“先淀粉样、然后tau、然后神经变性”的生物学的序列；那个如今可通过脑脊液与淀粉样的正电子发射断层、以及越来越多血浆检测使用的生物标志物的框架带着新的抗体类药物给基层的对话带来的预后的对诊断的告诫；“脑血管的与TDP及α突触核蛋白的”的共病理它解释了为什么大多数纯粹的病例并不纯；以及遗传学——那个风险等位基因的现实，与罕见的常染色体的显性的家族（对其检测是一场“遗传学与神经病学与保险”的谈话——[[genetics/mendelian-inheritance]]、[[genetics/genetic-testing]]、视觉变异的解剖见[[nervous-system/sensory-systems]]）。血管认知的损害阶梯样的或隐匿的、“以执行与步态为主的”这一图形——影像上的白质与梗死的负荷；以及与卒中相同的风险因子的内科学；“纯粹的形式很少、混合的是常态”这一现实；以及那条“不要把每一处白质的高信号都归给年龄、也不要都归给痴呆”的规则——[[nervous-system/stroke]]、[[cardiovascular/hypertension]]。路易体的疾病它的“全家都到齐”的临床的版本——波动的认知与反复的成形的视觉的幻觉及快速眼动的行为的异常及帕金森综合征伴严重的抗精神病药的敏感；以及“自主的与跌倒及对抗胆碱的敏感”这一 profile；那“看起来像谵妄、而且常常两者都被诊断”的“痴呆的波动”；以及“路易体的痴呆对帕金森病的痴呆”的时机的约定——[[nervous-system/movement-disorders]]、[[psychiatry/psychotic-disorders]]。额颞的叶的变性行为的变异——它的早期的“抑制的解除或淡漠及同情感的丧失及过度的进食与强迫的行为及执行受损而记忆相对保留”的表现——家属描述成“变了一个人”，而记忆门诊的简短量表对它并不公平；语言变异进行性的失语它的“不流畅与语义”及“错写样的”区分；额颞的与运动神经元疾病的重叠带那个基因的位点；以及“皮层基底节的与核上的麻痹”的Tau的疾病；以及“老年前期的、照护者的、法定监护的、以及早逝的”后果它们使这成为社会后果最惨烈的痴呆——[[nervous-system/motor-systems]]、[[genetics/mendelian-inheritance]]、[[medical-ethics-law/consent-capacity]]。其他不可错过的原因——份“值得自己的记忆术的纪律”的可治疗的清单：甲状腺功能减退与维生素B12及叶酸的缺乏；正压脑积水的“选择的诚实”；慢性硬膜下的血肿；神经的梅毒与人类免疫缺陷病毒；以精神的表现来发病自身免疫的脑炎；以及那“亚急性记忆的与发作的边缘系统的脑炎”（[[nervous-system/neuroinflammation]]、[[endocrine/thyroid]]、[[blood/anaemia]]、[[infectious-diseases/hiv]]）。**
:::

## 评估

::: definition 认知的评估 {#def-assessment}
**份高于一切检查的病史——知情者谁了解这个人的功能？最先改变了什么？工作与爱好及金钱与做饭及用药与驾驶及情绪与睡眠及行为；以月与年为单位的时间线；“把路易体的与谵妄从阿尔茨海默分开”的波动；以及那句“她一直就是这样”的人格的问题；覆盖“基本的与工具性的日常的活动”的功能的清单因为认知是一桩“以日常生活的后果”为标准的诊断，而驾驶与财务的决定先于正式的诊断而来；以及药物与物质的复查它的抗胆碱与苯二氮及阿片及酒精及大麻及镇静的负荷，以及“抗胆碱的量表”这一习惯——[[geriatrics-palliative/polypharmacy]]、[[psychiatry/substance-use]]、[[pharmacology/adverse-reactions]]。检查——认知筛查的测验（配它们应有的谦逊：简短的量表带着“教育与语言及地板与天花板”的告诫；而“床旁的筛查正常，从不排除轻度认知的损害或以额叶为主的疾病”这一事实）；“在会诊本身之中对额叶的行为的观察”；以及“时钟与流畅性及命名及抓握的反射”的发现；以及完整的神经的与全身的检查它能找到血管的与帕金森的及脑积水及硬膜下及威尔逊病及缺乏的体征——[[clinical-skills/physical-examination]]。检查的组合——血液血细胞与生化及钙及甲状腺功能及维生素B12与叶酸及血糖与糖化血红蛋白及血脂，以及“模拟维生素B12缺乏的情况”；在有指征时的人类免疫缺陷病毒与梅毒的血清学；以及在“图景需要时”的自身免疫的筛查——[[clinical-skills/laboratory-tests]]；影像——“带视觉评估的量表”的结构化的CT或磁共振（内侧颞叶的萎缩与白质及梗死，以及脑积水与硬膜下及肿瘤的阅片；以及“淀粉样的正电子发射断层与脑脊液的生物标志物使用的规则”、以及“生物标志物的阳性在哪里会改变处理、在哪里只会增加噪声”）；“当模式需要被正式地塑形时”的神经心理测量；以及“当某一桩具体的决定正在进行时”的能力的评估——[[clinical-skills/medical-imaging]]、[[medical-ethics-law/consent-capacity]]。与抑郁的鉴别“假性的痴呆对痴呆中的抑郁”这一问题——“我不知道”对“我尽力了”的陈词滥调，其可靠性低于教学所暗示的；以及“抑郁作为前驱对作为反应”的辩论；以及那“试用抗抑郁药并重新做认知评估”这一务实的答案；加上“淡漠对抑郁”那“会改变处方的”这一区分——[[psychiatry/mood-disorders]]。以及诊断的告知本身——“清楚地命名”这一义务、“诚实说出的诊断的不确定性”、以及“先向患者本人披露诊断”这条已不再是可选项的规则（[[clinical-skills/communication]]、[[medical-ethics-law/consent-capacity]]）。**
:::

::: definition 症状、药物与安全 {#def-management}
**那组“温和得有限”的药——胆碱酯酶的抑制剂多奈哌齐与卡巴拉汀及加兰他敏：在阿尔茨海默与路易体的疾病中温和的认知与全面的评分的获益；“胃肠的与心动过缓及晕倒及鲜明的梦”的副作用；缓慢的滴定与“停药的试验”的谈话；以及它们在说明书之外“对路易体的痴呆的幻觉与淡漠”的用处。美金刚在中重度的阿尔茨海默它自己的小效应量，以及“联合用药的实践”的现实。以及新的抗淀粉样的抗体的时代——一类药物：“淀粉样与血浆的tau的清除”、“在生物标志物阳性的早期疾病中的温和的减慢”；那“影像学水肿的监测与抗凝的告诫及磁共振的可及的公平的问题”；输注与输注反应的物流；以及那个真实的辩论——“量表上0.45分的减慢是不是患者会称之为进步的东西”——[[pharmacology/drug-development-prescribing]]、[[clinical-skills/medical-imaging]]、[[public-health/health-systems-economics]]。行为的与心理的症状的方案——才是每日真正的医学——未被满足的需求的解码疼痛与便秘及尿的潴留及感染及感觉的缺陷及药物的副作用及无聊，以及“任务与能力之间的不匹配”；环境与传统及沟通的干预带着它们的证据与它们的时间的成本；音乐与活动及“被占用的空间”的证据；以及“痴呆友好病区的设计”的教训；以及那份必须被赢得的抗精神病药的决定对严重的痛苦或风险的“小的绝对的获益”，对抗“在非典型的试验中年老痴呆的双倍死亡率的信号”；路易体的“灾难的敏感”这一禁忌；以及QT与跌倒及卒中及镇静的告诫；“最低的剂量、最短的时间、定期的复查”；以及监督它的那次药物的复查；以及对难治的病例电休克与其他选项的那份诚实——[[psychiatry/treatments-mental-health-law]]、[[nervous-system/stroke]]。风险的内科学——驾车告知的义务与道路的检测及“家属的担忧”的路径——[[medical-ethics-law/professionalism-regulation]]；跌倒与骨折的预防与“处方的做减法”；以及“体位的与视力及鞋”的审计——[[geriatrics-palliative/falls]]、[[endocrine/bone-calcium]]。保护的维度——痴呆所制造财务的与照护者的及机构的虐待与忽视；“能力与最佳利益及约束及自由的剥夺”这一法定的架构；以及“难缠的”痴呆的患者在医院里“被粗暴对待”的风险与“合理的调整”的义务成人的保护见[[medical-ethics-law/justice-resources]]、[[clinical-skills/patient-safety]]。**
:::

## 与痴呆共同生活

::: example 那个“继续为卖掉了的房子付钱”的男人 {#ex-fv}
一名61岁的退休的工程师在第三次“无理性的”置产之后被转诊；他变得多话而过分亲昵、“全天候地吃甜食”、不再洗澡、并把度假的基金花在了虚拟货币上；对事件的记忆还算不错；简短的筛查27/30。
::: solution
**行为变异的额颞的痴呆——那个“认知测验正常而生活正在坍塌”的综合征（[[#def-types]]、[[#def-assessment]]）：模式——早期的人格与行为的变化，伴“情景的记忆相对保留而执行功能失败”；淡漠与抑制的解除这两极；“过度的进食与强迫的刻板”；以及那种“看起来像自私同情感的丧失”；以及那个“把额颞的患者误导到精神科与财务的纠纷里好几年”的“筛查高分”的陷阱——躁狂的误诊见[[psychiatry/mood-disorders]]、临床的推理见[[clinical-skills/clinical-reasoning]]。检查——磁共振上以额叶为主的萎缩或正电子发射断层上的低代谢；神经心理测量的“以执行为主的模式”；以及“在早发或有家族史时遗传的咨询”带基因的讨论及其保险与家庭的含义——[[clinical-skills/medical-imaging]]、[[genetics/genetic-testing]]。“确实算治疗”的治疗——“选择性血清素的再摄取抑制剂”与其他对症的药物用于抑制的解除与强迫及过度的进食，它们的获益是部分的；行为与“有结构的传统”、以及“分阶段地移除财务的自主”这一做法；社会的处方与成人的支持的服务；以及“针对具体的决定的能力评估、而不是一个全面的判决”——[[medical-ethics-law/consent-capacity]]；以及作为患者的家属——“年轻照护者的抑郁与离婚及财务的破产及子女的学业”这一模式这是“工作年龄患者的痴呆”；持续的授权与“行为的资助”的规划；以及那“在还有选择余地的今天”就要开始的预见的照护的谈话（[[medical-ethics-law/end-of-life-ethics]]、[[clinical-skills/communication]]）。**

::: example 那位于内科病区上的“波动的女士” {#ex-dlb-hospital}
::: solution
**路易体的抗精神病药的敏感与那圈“医源病区的螺旋”（[[#def-types]]、[[#def-management]]）：综合征的解释——内生认知的波动家属与工作人员把它误读成“谵妄叠加谵妄”；以及那抗精神病药的敏感在路易体的痴呆中“2到3倍、且反应严重”的风险——伴强直与镇静及吞咽困难及自主的崩溃，以及它的死亡率，它使典型的抗精神病药与大多数的止吐药甲氧氯普胺与丙氯拉齐近乎禁忌——[[pharmacology/adverse-reactions]]、[[nervous-system/movement-disorders]]；现在就要做的限害的动作——停掉元凶的药物；并把这一反应显眼地记录为“严重的敏感”的警示，而不是“过敏”；补液并复查“那个写得很理想的吞咽与误吸性肺炎的计划”；并移走其他致谵妄的负荷（导尿管与身体的约束及阿片及抗胆碱的、以及“夜间血压的测量”）——[[geriatrics-palliative/delirium-dementia-care]]、[[renal/urinary-tract]]、[[clinical-skills/patient-safety]]；替代激越的方案——“未被满足的需求”的审计疼痛与便秘及尿及口渴及饥饿及恐惧及噪声，以及“缺失的眼镜与助听器”；重新定向与“在场”及“一对一或家属陪坐”的策略；以及音乐与点心的处方；只在“痛苦严重并有风险”时按指南用低剂量的奎硫平或氯氮平或优化胆碱酯酶的抑制剂来救援，并与家属做诚实的风险的讨论；以及在“难治的危险”时考虑电休克（[[psychiatry/treatments-mental-health-law]]、[[geriatrics-palliative/symptom-control]]）。**

::: example 那位“再也不能倒茶”的艺术家 {#ex-pca}
一名58岁的平面设计师有2年的“视觉空间的问题”——误判台阶、“在同一页上走丢”、面孔与颜色搭配的困难；她的眼睛被查过说是正常；记忆完好；筛查28分但“立方体的临摹与物体的组合”很差；磁共振显示以后部为主的萎缩。
::: solution
**后部皮层的萎缩——那个“在到神经科之前先看四个专科”的视觉的变异（[[#def-types]]、[[#def-assessment]]）：综合征——进行性的“视觉的知觉与视觉的空间及书写的”功能障碍（巴尔林的这几个特征——同时性的失认与视线的共济失调及眼动的失用；格斯特曼的元素；面目失认；以及颜色与深度的主诉；而早期的记忆与自知被保留，直到晚期）；“平均要好几年”的那条眼科与视光学的绕行；以及“大多数的病例带着阿尔茨海默的病理（偶尔是路易体的或朊蛋白的）”这一事实——所以那场生物标志物的谈话值得进行——皮层视觉的解剖见[[nervous-system/sensory-systems]]、[[clinical-skills/medical-imaging]]。鉴别——被妥善排除的眼的原因“皮层视觉的损害对视网膜对晶状体”这一区分；可逆的模仿者；以及“当病程快并伴肌抽跃时”的“朊蛋白的海登海因的谱系”；以及因为“空间的工作在诊断的标签到达之前就结束了”而要尽早处理的驾驶与工作的问题——[[medical-ethics-law/professionalism-regulation]]；处理——提供胆碱酯酶的抑制剂配现实的期望；职业治疗的“视觉的策略”的训练扫视的技巧与“对比与照明及组织”的适应；以及低视力的服务多数患者错误地以为那只属于眼病——[[public-health/health-systems-economics]]；以及那场轨迹的谈话——“在尚有判断力的现在”谈论驾驶与财务及预见的照护，并说明“变异型是一种痴呆、而不是只是眼睛的毛病”（[[clinical-skills/communication]]、[[medical-ethics-law/consent-capacity]]）。**

::: example 那位“腿变慢并有膀胱问题”的祖父 {#ex-nph}
一名74岁有2年的“磁石样短步的步态”最先受影响的是去椅子的路、跌倒过两次、新发的尿的急迫、以及轻度的思维变慢；CT显示脑室的扩大与“脑沟的突出不成比例”；他每周骑10公里的自行车，并在问“那个分流的手术”。
::: solution
**特发正压的脑积水——三联是一条选择的标准、不是一份承诺（[[#def-types]]、[[#def-management]]）：表型的权重——“以步态为先的、磁石样失用帕金森样的下半身”的图景，失禁与认知的损害更晚到来；影像（一项指数与“背侧脑室的不成比例扩大伴脑沟的紧贴”的征、以及那句“与脑沟的扩大不成比例”所守护萎缩的排除）；以及“穿刺的试验与腰穿的量与外部的腰穿的引流”的“侵入性对预测的价值”的取舍带着它诚实的敏感度数字——[[clinical-skills/medical-imaging]]、[[nervous-system/motor-systems]]。候选者的谈话——分流反应的预测因素“特发的、以步态为主、时间较短”这一 profile，他部分地符合，对不反应在大多数的尸体系列中占主导的是“萎缩与血管的负荷及阿尔茨海默的共病理”；以及“分流器的程控与引流过度及硬膜下及感染及再手术率”的现实；还有那句家属会记住的表述——“我们手术的对象是腿；膀胱有时跟着好转；而记忆最少”；并把“神经外科的第二意见”这一通道常态化——[[surgery/perioperative-care]]；替代与优化——血管风险的治疗与跌倒的项目；“不会把抗胆碱的加得过多”的泌尿的方案；骨的健康；以及那个复查的间隔它会等着看“最终会出现在许多做了分流的患者身上的阿尔茨海默或路易体的疾病”；以及诚实的试验的设计——随机对照的困难谁愿意被随机分配到不手术？使得“这一适应证至今依赖被精心选择的队列”（[[epidemiology-ebm/randomised-trials]]、[[clinical-skills/communication]]）。**

::: exercise 谈那个喂养管的问题 {level=2}
一位养老院住家的女儿“要求那根喂他母亲的管子”——她的母亲处于“晚期的重度”的痴呆不说话的、反复的误吸、体重下降5公斤；家属的会面已排定。
::: solution
**在晚期的痴呆中“手喂对经皮的胃造口”（[[#def-management]]、[[geriatrics-palliative/end-of-life-care]]）：被温和地交付的证据——在汇总的证据中，喂养的管道并不能预防误吸（唾液与反流是“管子管不了的），不能延长生存，不能愈合压疮，也不改善功能或舒适；反而加上约束与躁动及腹泻及管道事故负担；而”精心经口的喂养——手喂与体位及性状的修改及口腔的照护才是那个对照带着它自己诚实误吸的取舍“；而那句”把手头的一切做到底“的表述，会把”舒适的治疗“转化成为家属眼中的”积极的治疗“——[[gastrointestinal/clinical-nutrition]]、[[respiratory/respiratory-infections]]。目标的谈话——她的母亲本会想要什么在“她会为每一天而斗争”这个标签贴上去之前，先去考古她先前的价值；预后的框定反复的肺炎是这疾病的终局，而不是一桩“可修的意外”；以及提供姑息团队并行的投入；以及“在一个被规定的日期重新考虑这个决定”这个选项。若她仍不能决定，能力与法律的层——最佳利益、第二意见与倡导；以及“在相关时的保护法庭”这一通道；以及“不要把不治疗当成忽视、也不要把不喂养当成残忍”——这双重束缚要被公开地点名——[[medical-ethics-law/consent-capacity]]、[[clinical-skills/communication]]；以及那次会面的技术——“先复述他们的恐惧；然后说出数字；然后承诺一份书面的计划与一位具名负责的人”，而绝不逼出一个“当场的一致”（[[clinical-skills/patient-safety]]、[[geriatrics-palliative/palliative-care]]）。**

::: exercise 照护那位照护者 {level=2}
一名71岁的妻子——她的丈夫患路易体的痴呆已3年——“在她自己的全科医师那里”就诊，有失眠与体重下降及“警察再来时我撑不住了”；她拒绝了一切外部的帮助。
::: solution
**第二位患者（[[#def-assessment]]、[[#def-management]]）：引出——直接地问照护者的负荷（睡眠债的算术；以及警察与游走及公开的失禁事件；以及财务的挤压；以及“因他的淡漠而婚内守寡”）；像对任何患者那样筛查抑郁与自杀的意念，因为她的风险既升高又不可见；以及那场被她推迟了多年的身体的健康的复查——[[psychiatry/mood-disorders]]、[[geriatrics-palliative/ageing-frailty]]。能解锁帮助的那个重构——把“接受支持”框成保护他药物的监督与“暂时的喘息”是对他的精神病的预防复发、以及保护她（“如果你垮了，会同时来两个患者”）；以及那份“由一位具名的人来安排”的具体的菜单——照护者的评估那条法定的通道与日间的服务及喘息、联络的工作者、照护者支持的团体；以及“警务的备忘录与智能家居与痴呆的卡片”实务——而不是一张传单。卫生系统的触点——照护者自己的药物与酒精及驾驶的复查；邀请她参加他的预约信息的缺口在候诊室里最容易补上；以及“为警方的出警做复盘”的共同会诊它把这件事正常化。以及那条长的地平线——她现在能听进去的预见的照护规划的谈话因为她见过那条轨迹；“照护的地方与死亡的地方”及“她自己的优先”（[[geriatrics-palliative/end-of-life-care]]、[[clinical-skills/communication]]）。**

## 通向何处

::: history
**痴呆的历史是一个“谁被责怪、谁被相信”的故事：前现代的“第二次的童年”与收容所的昏睡的病区；以及关于“疯人与意志薄弱者”的法律的传统直到今天仍在塑造能力法——[[medical-ethics-law/consent-capacity]]；阿洛伊斯·阿尔茨海默在1906年的患者奥古斯特——那位有记忆丧失与幻觉的年轻的女性；“用银的染色”看到的斑块与缠结；以及那份病例记录在很久之后的重新发现它修正了几十年关于“她的名字是被一位未见过她的同事定下的”这段传说；中世纪治疗的虚无——“老年的痴呆，不可治”这句入院的话；以及“社区照护的时代”中“长期的病区被忽视”的丑闻它们既产出了反机构的运动、也产出了几十年投入不足的替代——[[public-health/health-systems-economics]]；社会的与神经心理的转向—— nurs养老院中的行为测绘；“行为与心理的症状”这一概念对“曾被用镇静来管理的症状”的正名；以及把诊断“从一个家庭的秘密变成一桩公共卫生的身份”的那场患者自我的倡导与“痴呆的友好社区”的运动。生物标志物的时代——“淀粉样级联的假说与遗传的尸检的证据”、脑脊液与正电子发射断层、以及如今的血浆的检测；以及“把生物学的定义与临床的综合征分开”的那个研究框架；以及那“针对淀粉样的人为抗体”最终跨过门槛、带来“一场关于进步意味着什么的正当的辩论”（[[genetics/genetic-testing]]、[[pharmacology/drug-development-prescribing]]、[[epidemiology-ebm/critical-appraisal]]）。**
:::

::: summary
- 痴呆是一个综合征；最初的症状的模式记忆与语言及行为及视觉及执行及帕金森综合征与速度就是诊断，先于任何扫描。
- 永远去搜寻可治疗的与可逆的贡献者——药物与抑郁及酒精及甲状腺及维生素B12及硬膜下及脑积水及人类免疫缺陷病毒及梅毒及免疫的与朊蛋白的疾病——并据此时机你的认知检查。
- 额颞的痴呆豁免了简短的量表、却摧毁了整个家庭；一位60岁的行为的表现值得头颅的影像与遗传的咨询、而不是抗精神病药。
- 路易体的疾病会惩罚典型的抗精神病药；波动就是疾病本身，而医院是那桩致谵妄的危险。
- 胆碱酯酶的抑制剂与美金刚做的是温和的工作；抗淀粉样的抗体“只用于早期的疾病、由生物标志物把关、需要大量扫描并在公平上受质疑”；它们都替代不了“行为与心理的症状”与驾驶及跌倒及照护者医学。
- 说出诊断，在能力仍存在时规划未来，并把“下一个决定由谁负责”写下来。
:::

## 练习

::: exercise 痴呆还是抑郁 {level=1}
一名74岁的丧偶的男性有4个月的“记忆差与我不知道式的回答”及体重下降及清晨的醒来及自我忽视；无神经的体征；CT正常。请给出计划。
::: solution
**治疗抑郁并重新检查（[[#def-assessment]]、[[psychiatry/mood-disorders]]）：晚年抑郁的评估——直接地问自杀的意图的问题；居丧的背景；以及“身体的健康与药物与酒精”的复查；以及关于“起病的速度与情绪为先对记忆为先”的知情者的病史；以及“模仿痴呆的我没什么意义”这种消极的回答；以及在情绪改善之后重新做认知评估才是真正的诊断试验；以及衰弱与营养及甲状腺与维生素B12的血液检查。以紧迫感治疗——抗抑郁药带抗胆碱与低钠及“体位的下降及出血的风险及血清素的告诫”；为居丧者的心理治疗的通道；以及“运动与团体及供餐的服务”处方它们比药片做得更多。安全网——针对“财务的忽视”这一项的能力的核查；以及保护与公用事业及跌倒的风险的视角；以及那个具名的随访的间隔——它要么证实了恢复，要么揭示出“藏在抑郁之下的神经变性的疾病”因为两者可以共存——[[geriatrics-palliative/polypharmacy]]、[[medical-ethics-law/consent-capacity]]。**

::: solution
**一个系统，而不是一项服务（[[#def-types]]、[[#def-management]]、[[public-health/health-systems-economics]]）：带着诚实的数字的一级的预防——“委员会式的”人群的“可归因的分数”的工作听力的损失与教育及高血压及肥胖及糖尿病及吸烟及抑郁及身体与认知的不活动及社会的孤立及空气的污染及酒精，被框成风险的降低而不是责备；助听器干预的文献；以及与心脏科及卒中共享血管风险的“共同的获益”——[[cardiovascular/hypertension]]、[[public-health/screening]]。诊断路径的设计——“带神经心理与影像的能力、以及生物标志物的可及计划”的“快速通道记忆的门诊”；痴呆专科的护士；以及诊断之后的“关键工作者”的职能随访的研究显示它比那个诊断的时段更重要；以及把公平的重点放在被诊断不足的人群少数族裔与学习的障碍及被监禁的及“老年早期的”及农村的——[[public-health/determinants-inequalities]]。社区与医院的安全——照护者的识别与支持及喘息及年轻照护者的策略份“无偿的经济”的资产负债表；“住房与痴呆友好的环境”及远程照护与痴呆的村落的构想；院内谵妄预防的集束；以及约束与“能力法及自由的剥夺的监督”的治理；以及照护者的临终（[[geriatrics-palliative/end-of-life-care]]、[[clinical-skills/patient-safety]]）；以及评估——“从诊断到生活的成本与结局”的配对的数据、按阶段痴呆人群的“谁被漏掉了”，以及那张“让下一轮的委托建立在证据而不是轶事上”的仪表盘（[[epidemiology-ebm/measuring-disease]]、[[medical-ethics-law/justice-resources]]）。**
