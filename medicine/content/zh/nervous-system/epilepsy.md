癫痫病学是“带着社会良知的应用的电化学”：**一次发作是“过度同步的神经元活动”造成短暂的功能障碍，而临床的工作是“把发作与许多模仿它的东西分开”、把癫痫分类以选择药物、然后管理一种“与驾驶与工作、妊娠、情绪及对死亡的焦虑同等地相互纠缠”的治疗。**诊断的大部分在病史；治疗的大部分是“选择某一位具体的患者能耐受哪一种副作用”。

本章涵盖定义与分类、“脑电时代的发作与符号学”、全面性强直阵挛发作持续状态、抗发作的药理学、以及“跟随每一张处方的”生活背景的章。

## 定义与分类

::: definition 发作、癫痫、以及它们的种类 {#def-classification}
**套“能终结争论”的词汇——一次发作是“由异常过度的或同步的神经元活动造成的症状与体征的短暂的出现”、通常是自限的；癫痫则被操作性地定义为“两次以上的间隔超过24小时非诱发的发作”，或“一次非诱发的发作伴高复发概率”影像上的病灶、典型的脑电、一个综合征，或“一个已经长过了它的活动的癫痫综合征”；而非癫痫的发作——晕厥根本就不是发作的事件——癫痫的门诊里最常见的误诊、以及功能性（心因性的非癫痫的发作——是“没有脑电发作的真实体验”、需要一种完全不同的治疗——[[psychiatry/anxiety-disorders]]，转换的体征见[[nervous-system/motor-systems]]）。真正会改变处方发作的分类学起始的发作——“意识保留对意识受损”、“运动的对非运动的”，其中“先兆作为小的发作”：上腹的上涌、似曾相识、恐惧、味觉、躯体感觉、以及“被错归成夜惊与异态睡眠运动过多额叶的夜间发作”——岛叶与颞的感觉的解剖见[[nervous-system/sensory-systems]]；全面起始的发作——运动的强直阵挛，配“舌的侧缘的咬伤与尿的失禁及发作后的意识混乱”这一模式与“非运动的失神”，配它们的每秒3赫兹的棘慢波、以及那份“排除了错误的药物”的药物清单——卡马西平会让失神与肌阵挛更糟；以及“未知起始”这一类（它迫使诚实的记录，直到更多的数据到达）。综合征与它们按年龄的拱廊——新生儿与热性的、以及那几种儿童与青少年期遗传全面的癫痫与“伴海马硬化颞叶的癫痫”与病灶的——带着它们的复发与预后及妊娠的含义、以及常常“比发作本身更重”的发育与行为的共病的负担——[[paediatrics/neurodevelopment]]、[[genetics/mendelian-inheritance]]；以及那份“值得写在每一张表单上的”病因的类别——结构的肿瘤与既往的卒中及创伤及“病灶皮质的发育不良”及海马的硬化及血管的畸形；遗传的；感染的全球实践中“神经的囊虫与结核及人类免疫缺陷病毒”的；代谢的；免疫的“以难治新发的发作与精神的危象来表现抗体的脑炎”；以及未知的——连同影像的决定规则“首次发作伴灶的特征或缺损或免疫抑制”要紧急做磁共振而不是CT；以及那个“CT阴性所以没事”却漏掉了发育不良的错误——[[clinical-skills/medical-imaging]]、[[pathology/cancer-biology]]、[[infectious-diseases/hiv]]、[[infectious-diseases/tropical-infections]]、[[nervous-system/neuroinflammation]]。**
:::

::: definition 首次的发作、模仿者与检查 {#def-mimics}
**各种形式的晕厥是那伟大的模仿者反射与血管迷走的，配它“发热感与恶心与视野变窄”的前驱、以及“被非专科的人称作抽搐性发作的短促肌阵挛的抽动”；直立性与“直立的心动过速”的背景；以及心脏的节律的晕厥——一种危险的——配“与用力时与仰卧与心悸与家族史”危险信号、以及“心电图与监测及癫痫对心律失常的转诊”带着“QT与布鲁加达与肥厚的心肌病及通道病”的读图——[[cardiovascular/arrhythmias]]、[[cardiovascular/valve-congenital-disease]]；功能性非癫痫的发作——它的诊断是“临床加上视频脑电”的一项工作、并要谨慎地交付，因为“这是心理的”这句话会被体验成“这是装的”；而它的治疗是“精神与心理治疗”的路径（配把发作的药撤掉——[[psychiatry/anxiety-disorders]]、[[clinical-skills/communication]]）；其他的模仿者——偏头痛的先兆在数分钟之内扩散、推进的、正性视觉的现象，对比“感觉的发作那种几秒之内快速的皮肤的推进”——尽管两者可以共存、而“偏头痛性的癫痫”比这个标签罕见得多；“一过性全面的遗忘”（那“反复提问的一小时而身份保留”——家属在凌晨三点去查资料、并错误地让自己安心——鉴别的遗忘见[[nervous-system/dementia-neurodegeneration]]）；睡眠的事件与异态睡眠与夜惊、以及“年长男性快速眼动的行为障碍”一种“突触核蛋白的病”的前兆——[[nervous-system/movement-disorders]]、[[geriatrics-palliative/delirium-dementia-care]]；以及“一过性的发作”的鉴别短暂发作的门诊与癫痫的门诊在此相遇：来自“颈动脉的狭窄”的“肢体抖动型的短暂发作（由运动诱发”、以及“表层含铁质的沉着”的“淀粉样的发作”——[[nervous-system/stroke]]）；以及各种检查与它们诚实的价值——脑电（“剥夺睡眠与闪光敏感及动态的与住院的视频”变体；一次常规记录的“发作间敏感度的天花板”，意味着“正常的脑电永远不能排除癫痫、而在不发作的人身上的癫痫样的异常也永远不能诊断它”——这就是检验前的概率的纪律）；“带癫痫的方案序列”的磁共振海马的硬化、以及“需要一双专门受训的眼睛才看得到的病灶的皮质的发育不良”、以及“病灶之后的那个病灶是不是原因、切掉它能否治愈的问题”；以及“为代谢与感染及免疫的背景”的血液检查（配上“抗体组合的审慎”——[[clinical-skills/laboratory-tests]]、[[clinical-skills/medical-imaging]]、[[nervous-system/neuroinflammation]]）；以及首次发作的咨询——它大半在讲复发的风险那个大约30%到50%的两年数字，会被病灶与脑电及“夜间的”事件推高、以及眼前的实务驾车的告知、以及“以风险的降低而非禁令的形式交付的”关于游泳与浴缸及高处及烹饪及抱婴儿的建议——[[medical-ethics-law/professionalism-regulation]]、[[public-health/prevention-promotion]]。**
:::

::: definition 抗发作的药物 {#def-drugs}
**高于任何一种药的原理在第二次非诱发的发作之后、或在“伴高复发概率的首次发作加患者的选择”之后才开始治疗；单一用药、从低剂量开始、缓慢地加、“滴定到效果或副作用”；按发作的类型与综合征、并按患者的因素做“按机制匹配的”选择——性别与生育的潜能及体重及肝与肾的功能及“精神与骨与心脏的共病”及那份相互作用的清单（因为酶的诱导剂——卡马西平与苯妥英及苯巴比妥及“高剂量的托吡酯”——会嚼碎避孕药与他汀及抗凝药及维生素D、以及肿瘤与移植的药物清单——[[pharmacology/metabolism-excretion]]、[[pharmacology/dosing-principles]]、[[obstetrics-gynaecology/contraception-fertility]]、[[endocrine/bone-calcium]]）。带着它们的“性格卡”的药物类别——钠通道的阻滞剂卡马西平与奥卡西平：低钠；以及在“南方汉族与其他人群”中的“人类白细胞抗原的筛查与史蒂文斯-约翰逊”；以及那“会杀人的伴嗜血细胞增多与发热与皮疹与淋巴结病及肝炎的药物反应综合征”；以及“卡马西平与苯妥英及叶酸及维生素B12”的告诫；拉莫三嗪：缓慢滴定以避免皮疹、以及“与丙戊酸的相互作用的减量”、还有它稳定情绪的额外好处；拉考沙胺：PR的间期与头晕、以及那个“从附加变成一线”的现代的故事；以及苯妥英——套“零级的动力学与白蛋白的结合与监测”的文化（如今应很少被重新开始）；以及广谱的药物丙戊酸——对全面的癫痫最有效的药、也是最成问题的致畸原其剂量相关的畸形与神经发育的风险“已被监管者限制为除非没有替代方案专科授权的用途”；酶抑制与高氨及胰腺炎、以及“体重与毛发及多囊的卵巢的相邻关系”；左乙拉西坦——每日一次的便利与“无相互作用”、以及它的行为的副作用那个“比任何血药浓度都更决定依从”的易怒与暴怒的问题；布瓦西坦那个表现更好的亲属；托吡酯与唑尼沙胺带“认知的减慢与体重下降及少汗及结石及青光眼及致畸”这一捆；以及“副作用更少但长期的数据有限”的新成员——“带精神黑框警告的”吡仑帕奈，以及“缓慢的”那种药物的滴定方案——[[pharmacology/adverse-reactions]]。监测与浓度的文化——哪些药需要测浓度苯妥英与丙戊酸及卡马西平（配它们的“浓度与效应及毒性”的窗口、以及“由妊娠与相互作用触发的”检查“）、哪些不需要；以及那场”因为不依从而浓度低“的谈话——它应当被当作信任的问题、而不是依从的失败——[[pharmacology/patient-variation]]。以及停药的问题——“两到五年的无发作”配上“允许的综合征”与脑电及病史、以及“复发的风险对恢复驾照与工作的自由的驱动”的权衡、连同那条“某些综合征（如青少年肌阵挛的癫痫）会终身复发”的诚实的说明（[[paediatrics/neurodevelopment]]、[[medical-ethics-law/professionalism-regulation]]）。**
:::

## 发作的处理

::: example 那次夜班时的发作 {#ex-status}
一位有已知的癫痫的成人，在“20分钟前开始全面强直阵挛的发作”之后被送来、仍未停止；又一次当着你面开始；静脉的通路已建立；血糖6；体温37.9。
::: solution
**确立的全面性强直阵挛发作持续状态——一套“依赖时钟的药物方案”、带着重症的视野（[[#def-classification]]、[[#def-drugs]]）：逐分钟的方案——用正确剂量的苯二氮依途径与场合“肌注的咪达唑仑或静脉的劳拉西泮或口腔黏膜的或肛门的地西泮”、按指南重复一次；失败时，紧急第二线静脉的抗发作药按本地的方案用左乙拉西坦或丙戊酸或磷苯妥英或苯巴比妥，带着它们的心脏与滴速的告诫，配持续发作的监测；以及第三线的麻醉的路径持续的脑电与“暴发抑制的目标”及其解读——以及那条“发作被控制了，但患者没有被控制”的原理；同时进行的“按顺序的可逆的病因”的清扫——与麻醉科一起做气道保护的决定；血糖、以及在有酒精与营养不良的风险时硫胺素；以及那套“发热与颈的僵硬及免疫抑制者的脑膜脑炎——阿昔洛韦不要延误”的逻辑；创伤与误吸的检查；以及钠与钙及肾及“药物的浓度及毒理”的筛查——[[emergency-critical-care/resuscitation]]、[[infectious-diseases/fever-sepsis]]、[[nervous-system/neuroinflammation]]、[[emergency-critical-care/poisoning]]；以及后续的动作——病房上进行的那场“找病因”不依从与药物的相互作用及酒精的戒断及新的病灶；以及那类“以难治的全面性强直阵挛发作持续状态伴正常的扫描”来表现自身免疫的脑炎；以及与家属的那场“预后与目标”的谈话谨慎地使用死亡率的量表、以及“重症的升级对不再升级”的决定要用同样的透明度做出——重新负荷与维持见[[#def-drugs]]、通气与升压药的背景见[[emergency-critical-care/critical-care]]。**
:::

::: example 那个“清晨的抽动”的学生 {#ex-jme}
一名19岁的大学学生“在大多数清晨掉落她的牙刷”、并“知道有些不对劲的事发生”但什么都不记得；在新生周饮酒之后有两次“大发作”；脑电显示每秒4到5赫兹的多棘慢波；磁共振正常；她在服避孕药。
::: solution
**青少年肌阵挛的癫痫——综合征的诊断把她从“错误的那十年治疗”中救出来（[[#def-classification]]、[[#def-drugs]]）：模式——清醒后1到2小时之内的肌阵挛的抽动（掉落的东西与尴尬的掩饰）、由睡眠的剥夺与酒精诱发的全面性强直阵挛的发作、光敏感的核查、多棘波的脑电与正常的影像；以及综合征之所以重要的理由：卡马西平与拉莫三嗪在某些时候及苯妥英会让肌阵挛加重，而丙戊酸是最有效的药——这与她的性别及致畸的规则迎面相撞；药物的协商——拉莫三嗪或左乙拉西坦作为合理的第一选择对抽动诚实地承认较低的效力；以及“只在专科妊娠预防方案的框架内”避孕、每月的风险确认、以及“以替代方案为先”的记录才进行丙戊酸的谈话；以及那张“最便宜的抗发作药”的处方的生活方式：睡眠的规律与酒精的节制、以及在相关时“关于游戏与光敏感”的建议——[[obstetrics-gynaecology/contraception-fertility]]、[[pharmacology/adverse-reactions]]；这个综合征的一生——停药后终身的复发率所以那句“我能不能上大学或上医学院时停药”要被诚实地回答为“可能永远无法完全停药”、而不是承诺一条终点线、驾车的规则配“无发作的期间”的算术、以及“向大学与保险及雇主的披露”这一问题用平等法的框架回答；以及共病的筛查——“比脑电更能决定她的结局”的焦虑与情绪及依从及酒精的模式；以及在说出诊断的同一口气里提供治疗的路径，好让癫痫的门诊不是她唯一一次听到“治疗”这个词的地方（[[psychiatry/anxiety-disorders]]、[[clinical-skills/communication]]）。**
:::

::: example “不是发作”的事件 {#ex-nes}
一名24岁在“三种抗发作药”之下仍每日有“发作”：事件持续8到15分钟、“以左右的摇头与眼睛的闭合”开始、时强时弱、并以哭泣结束；有一段“她从未向医师透露的”性虐待的病史。
::: solution
**功能性心因性的非癫痫的发作——一个阳性的诊断，并作为一个诊断来交付（[[#def-mimics]]、[[psychiatry/anxiety-disorders]]）：诊断的证据——符号学（眼睛的闭合与抵抗的睁眼、长的持续时间、时强时弱、“不同步的左右的运动”、骨盆的挺动与“发作时的哭泣”、保留瞳孔的反射；作为金标准的“在视频脑电上捕捉到一次典型的事件而没有脑电的发作”；以及泌乳素与“正常发作间的脑电”的诚实的限度——[[clinical-skills/laboratory-tests]]、[[clinical-skills/medical-imaging]]）；告知的谈话——把这句话写出来并预演：“这些是由心与身的成因造成的真实的事件、不是装出来的，而且它们不会响应癫痫的药物”；以及那句含混的“我们再试一种药”的转诊（常常已经跑了好几年所带来的伤害；以及“段受虐的病史只在有治疗的路径可以提供时去问，而不是作为诊断的弹药”——[[clinical-skills/communication]]、[[paediatrics/safeguarding]]）；治疗的架构——“渐进的、经同意抗发作药的减停”并诚实地重新计算驾车的建议、心理的治疗（“认知行为与聚焦创伤”的证据及其温和的效应量与可及的问题、“情绪与睡眠及疼痛”的共病的管理、以及“能预测结局的人格与创伤的复杂度”；以及那封能止住“急诊反复就诊的级联”的共同管理的信——[[pharmacology/patient-variation]]、[[clinical-skills/records-handover]]）；以及保护与预后的细微差别——受虐的病史对自伤与“再次受害”的风险的含义；以及“在近期起病非癫痫的发作中恢复的比率是好的”这条信息——这是本章中少数几句真正充满希望的话之一（[[psychiatry/mood-disorders]]、[[clinical-skills/patient-safety]]）。**
:::

::: example 那位不断“晕倒”的老先生 {#ex-convulsive-syncope}
一名79岁在三个月内有四次短暂的“抽搐”，每一次都在“快速地站起时或泡热水澡时”发生，伴10秒的抽动与立即的重新定向；一位目击者说“他在倒下之前脸变白了”；心电图显示一度的房室传导阻滞，而他在服“多沙唑嗪与呋塞米”。
::: solution
**伴肌阵挛的晕厥，不是癫痫——以及一份要编辑的药物清单（[[#def-mimics]]）：病史告诉你——“体位的与热的”触发、以及“先变白再倒下”的顺序、以及“以秒而不是以分钟计的抽动”、以及“没有意识混乱及舌的咬伤及尿的失禁的含糊”的立即的重新定向——把反射与体位的晕厥和发作分开；而“家属如今提供目击者的视频”应当由临床医师亲自看，而不是听人描述——[[clinical-skills/history-taking]]、[[clinical-skills/communication]]；检查——卧立位的血压（配药物的复查：α的阻滞剂加利尿剂作为“医源性的体位性”）；心电图（配“传导的疾病与停搏”这一问题；心律失常的监测与颈动脉窦及“为主动脉瓣的狭窄做超声心动”；以及那份“发作样的活动不等于癫痫”的记录——[[cardiovascular/arrhythmias]]、[[cardiovascular/valve-congenital-disease]]、[[clinical-skills/medical-imaging]]）；干预——药物的合理化、以及压力袜与“液体与盐”的建议并承认心衰的那一对立的观点、教会“反压的动作”；以及“只为被记录的心抑制的类型”考虑起搏（配诚实证据的评估——[[cardiovascular/heart-failure]]、[[renal/water-sodium]]、[[pharmacology/patient-variation]]）；以及被避免的伤害——那条“由一张写着发作的急诊的信开始的”抗发作药的级联，及其低钠在服利尿剂年长的患者身上用卡马西平及跌倒及驾照的后果；这就是为什么收住的文件应当说出机制、而不是动作——[[pharmacology/adverse-reactions]]、[[nervous-system/motor-systems]]。**

::: history
**癫痫是那种“治疗很古老而解释并不古老”的疾病：希波克拉底那句“圣病”是自然的记录、以及那中世纪的与“妖魔化”的逆流它塑造了几个世纪的污名，直到今天的世界卫生组织仍在点名；十九世纪的神经病学——杰克逊的灶的推进、以及他用电的类比（那“小小原生质的抽动”）、以及1924年的贝格的脑电（在发明与临床的采用之间那十二年的间隔，是一堂关于“技术的成熟度”的课——[[physiology/membrane-potentials]]、[[clinical-skills/laboratory-tests]]）；溴化物的时代维多利亚的“钾的溴化物镇静的鸡尾酒”以及苯巴比妥的续篇、然后是苯妥英的故事——1930年代“在寻找一种更好的催眠药的过程中意外发现的”活性、以及那位“其量效结构的工作是还算合理抗惊厥药物发现的早期范例”的发明者；以及卡马西平与扑米酮及丙戊酸的到来（它们让现代的多药成为可能——[[pharmacology/drug-development-prescribing]]）；国际抗癫痫联盟从1964年起的分类、以及1980年代那场“让临床医师按轨迹而不是按单次发作来思考”的综合征的转向；外科的复兴——较早颞叶的切除、它们那个时代的失败的试验、以及现代的证据基础那项“在经充分选择耐药颞叶的病例中显示显著的优越性”的外科对药物的随机对照；以及遗传的时代——“钠通道的基因”与德鲁埃、以及“葡萄糖转运体的缺陷与生酮的饮食”这一配对是“由机制到治疗”最清晰的范例之一、以及“从离子通道病到突触的病”的不断扩大的基因的队伍（[[genetics/mendelian-inheritance]]、[[genetics/genetic-testing]]、[[immunology/autoimmunity]]）。**
:::

## 通向何处

通道与受体的生理学在[[physiology/membrane-potentials]]与[[physiology/synapses]]；抽搐急期的处理在[[emergency-critical-care/acute-assessment]]；热性的发作与免疫接种在[[paediatrics/immunisation]]；妊娠与避孕的相撞在[[obstetrics-gynaecology/contraception-fertility]]与[[obstetrics-gynaecology/pregnancy-complications]]；以及免疫介导的脑炎在[[nervous-system/neuroinflammation]]。

::: summary
- 先诊断发作、再诊断癫痫；先诊断综合征、再选药；正常的脑电绝不能排除二者、而异常的也不能创造出它们。
- 灶的特征要求影像；而“晚年新发的灶的癫痫”在磁共振说出别的之前都是结构的病灶。
- 把机制对上综合征：钠通道的阻滞剂会让“全面的肌阵挛与失神”更糟；丙戊酸是“全面的癫痫”的金标准、但带着致畸的代价。
- 全面性强直阵挛发作持续状态是“按时间计算的方案”苯二氮、第二线的输注、麻醉的路径，与血糖及硫胺素及发热及“找病因”并行执行。
- 两种“经恰当选择”的药失败就是耐药的癫痫、就该转诊，而不是再试第三种的借口。
- 驾驶与避孕及妊娠及酒精及睡眠及污名，属于每一次的癫痫的会诊——因为缺了它们，治疗就会失败。
:::

::: exercise 处理酶的相互作用 {level=2}

::: solution
**以酶为中心的混乱（[[#def-drugs]]、[[pharmacology/metabolism-excretion]]）：药理学——卡马西平对细胞色素3A4与2C9的诱导及葡萄糖醛酸化的效应，会降低华法林的暴露国际标准化比值的下降与凝血的风险、降低“炔雌醇与孕激素”的暴露避孕的失败、以及它自身的自身诱导；以及“反向的”相互作用——唑类与大环内酯及葡萄柚会把卡马西平抬到中毒的水平——[[pharmacology/dosing-principles]]、[[blood/thrombosis-anticoagulation]]；修正——在发作的控制允许时，把抗癫痫的要换成“非诱导的”药物拉莫三嗪带着它自己与丙戊酸的相互作用的细微差别，或左乙拉西坦或拉考沙胺，配上交叉替换的方案与“在替换期间驾驶的安全”的规则；或者，如果瓣膜坚持要华法林而癫痫坚持要卡马西平，就加强国际标准化比值的监测、并把“预期要加量”写下来给“继承这位患者的人”；避孕的谈话——那个证据的层级适合的“左炔诺孕酮的宫内系统、含铜的宫内节育器、以及带告诫的注射的孕激素”；以及“复方口服药与单纯孕激素片”的不可靠，它必须是一场开药之前的谈话、不是一次妊娠访视的事后复盘——[[obstetrics-gynaecology/contraception-fertility]]；维生素D与骨那部分见[[endocrine/bone-calcium]]；以及记录——在癫痫与抗凝这两份病历上都更新相互作用的警示、并给全科医师写信列出“改变了什么以及由谁监测”（[[clinical-skills/records-handover]]、[[medical-ethics-law/professionalism-regulation]]）。**

::: exercise 运行妊娠的门诊 {level=2}

**发作的控制与致畸原的最小化放在一起（[[#def-drugs]]、[[obstetrics-gynaecology/pregnancy-complications]]）：证据与语气——她在这一方案下的绝对的风险拉莫三嗪与左乙拉西坦属于较低风险的药物；联合的治疗增加温和的风险，对比“全面强直阵挛的发作、缺氧与跌倒”对胎儿的已被证明的伤害；所以要积极地反驳“因为我看了说明书所以把一切都停了”，并且不做单方面的改变——[[pharmacology/adverse-reactions]]；计划——在这个人群中使用剂量的叶酸“较高剂量的实践”，并附带“其证据基础比处方惯例更弱”这条告诫；整个孕期“因拉莫三嗪的清除率增加”的浓度监测的进度表以及“产后回到原剂量”那个会造成中毒的错误；“暴露于酶的诱导剂的婴儿”的维生素K与新生儿的处理她没有被诱导，但计划里要说明为什么；以及与产科团队及那位具名的癫痫专科医师一起做的胎儿的监测与分娩的计划的谈话。分娩与生活的物流——“睡眠的剥夺对母乳喂养”的取舍用一个“夜间喂食的轮值”来管理（支持“配被保障的睡眠的母乳喂养”的文献）；产前发作的行动方案与“产程中不得拒给治疗”的规则；以及新生儿期“关于镇静与安全的”哺乳的建议——[[paediatrics/newborn]]、[[obstetrics-gynaecology/labour-birth]]、[[pharmacology/patient-variation]]。**

**人群的安全对个人的流动（[[#def-drugs]]、[[medical-ethics-law/professionalism-regulation]]、[[public-health/determinants-inequalities]]）：流行病学——按综合征与发作的类型及背景仅在夜间对“非诱发的白天”、结构的病灶、睡眠剥夺模式复发的概率；以及那“被驾驶的规则编码进”的碰撞风险的数据治疗前与发作之后的升高、以及“发作的风险”与“道路上的风险（会因报告与依从而改变）”之间那道诚实的差距；伦理的框架——自主与就业及农村的流动，对第三方的风险；交通政策的医学化；“按群体癫痫对按个人”的风险评估的辩论；以及“保密对告知”的义务（各个辖区的解法不同，而临床医师必须烂熟——[[clinical-skills/communication]]）；临床的实务——“无发作的期间与治疗的依从”条件、以及个人与有条件的驾照的机制、以及“营运车辆与出租”几层；以及“不认同自己的神经科医师的患者”的申诉与倡导的团体的角色；还有那个记录的习惯“已建议、已告知、日期”它能保护所有人；以及那份诚实的改革议程——“为了保住驾照而不报告发作”这种可预见的反向的激励；以及“比吊销更能廉价地降低风险”的“睡眠的呼吸暂停与失眠及轮班”诱发因素的管理；以及那条“服务应当被设计成让正确的决定成为容易的决定”的结论（[[public-health/screening]]、[[clinical-skills/patient-safety]]）。**
