大约每一百人中就有一人患癫痫，约十分之一的人一生中至少会有一次癫痫发作。一次发作可以是剧烈的抽搐、几秒钟的凝视、胃里一阵上升的感觉，或者突然跌倒。有些发作的人被错误地告知患有癫痫，也有些癫痫患者被错误地告知只是晕厥。诊断很重要，因为它会改变驾驶、工作、妊娠计划和用药，也因为有些人死于癫痫。

本章解释什么是癫痫发作，发作和癫痫如何分类，如何把发作与类似疾病区分开，抗癫痫发作药物如何起作用，以及如何处理癫痫持续状态。英国的实践遵循NICE NG217（《儿童、青少年和成人的癫痫》，2022年）；分类遵循国际抗癫痫联盟（ILAE）。

## 什么是癫痫发作

::: definition 癫痫发作与癫痫 {#def-epilepsy}
**癫痫发作**是由脑内神经元异常过度或同步化活动所引起的一过性症状或体征。

**癫痫**是一种脑部疾病，按ILAE实用性定义（2014年），满足下列任一条件即可诊断：

1. 至少两次间隔超过24小时的非诱发性（或反射性）发作；
2. 一次非诱发性（或反射性）发作，且未来10年内再发风险与两次非诱发性发作后的一般再发风险相当（至少60%）；
3. 诊断为某种癫痫综合征。

**诱发性（急性症状性）发作**发生在急性脑损伤或全身性紊乱之时，如低血糖、低钠血症、酒精戒断、脑炎，或卒中、头部外伤后的第一周内。诱发性发作本身不能构成癫痫的诊断。
:::

第二条标准意味着，如果再发风险高，一次非诱发性发作就足以诊断癫痫，例如脑电图有癫痫样放电，或存在陈旧性卒中等脑结构性病灶。

::: theorem 兴奋与抑制的平衡 {#thm-balance}
正常的脑活动依赖于兴奋与抑制之间的平衡：兴奋主要由谷氨酸作用于AMPA和NMDA受体介导，抑制主要由GABA作用于GABA-A受体介导。当这一平衡被打破，一群神经元过度且同步地放电，并经相互连接的网络扩散时，就发生了癫痫发作。任何增加兴奋（钠通道突变、皮质瘢痕、酒精或苯二氮䓬类药物戒断）或减少抑制（抑制性中间神经元丢失、GABA-A受体突变）的因素，都会降低发作阈值。
:::

::: proof 局灶性发作如何开始和扩散
在细胞水平，致痫组织的标志是**阵发性去极化漂移**：神经元出现一次大而持久的去极化，由突触谷氨酸和钙电流驱动，其上叠加一串动作电位。在正常组织中，每次爆发之后都有由GABA和钾电流介导的强烈超极化，使活动保持局限；在脑电图上，这种爆发表现为**发作间期棘波**。当周围的抑制失效时，发作就开始了：抑制性中间神经元耗竭，细胞外钾升高，氯离子梯度改变，使GABA的抑制作用减弱。随后邻近神经元被募集，放电沿解剖连接扩散。在一侧半球内扩散产生局灶性发作，其症状反映受累区域；经丘脑和胼胝体扩散到双侧半球，则产生局灶进展为双侧强直–阵挛发作。相反，全面性发作起源于双侧分布的网络，通常累及丘脑和皮质；在失神发作中，节律性的丘脑–皮质振荡依赖于丘脑神经元的T型钙通道，这就是乙琥胺有效的原因。
:::

## 发作与癫痫的分类

ILAE分类于2017年修订，并于2025年更新。2025年版保留了四大类发作：

- **局灶性发作**起源于局限于一侧半球的网络。按**意识**是否保留（根据患者的知晓和反应性判断）及其可观察到的特征来描述，例如运动活动、感觉或情感体验，或自动症（咂嘴、摸索）。局灶性发作可以进展为**局灶进展为双侧强直–阵挛发作**。旧术语（“单纯部分性”、“复杂部分性”、“继发全面化”）已不再使用。
- **全面性发作**起源于横跨双侧半球的网络。主要类型有**全面性强直–阵挛**发作、**失神**发作（突然短暂的活动停止伴凝视，典型持续5–15秒）、**肌阵挛**发作（短暂的抽动）、**失张力**发作（突然肌张力丧失而跌倒）和强直发作。
- **未知**起源是局灶性还是全面性，当未看到发作开始时。
- **不能分类**，当信息不足时。

随后确定**癫痫类型**（局灶性、全面性、全面性合并局灶性，或未知），并尽可能确定**癫痫综合征**以及**病因**：结构性、遗传性、感染性、代谢性、免疫性或未知。

| 综合征 | 典型年龄 | 特征 | 备注 |
|---|---|---|---|
| 儿童失神癫痫 | 4–10岁 | 每天多次失神；脑电图3 Hz棘慢波，过度换气可诱发 | 通常在青春期缓解 |
| 青少年肌阵挛癫痫 | 青少年期 | 晨起肌阵挛（早餐时掉东西）、全面性强直–阵挛发作，有时有失神 | 终身倾向；睡眠剥夺和酒精可诱发；某些药物使其加重 |
| 伴中央颞区棘波的自限性癫痫 | 4–10岁 | 夜间局灶性发作伴面部抽动和流涎 | 青春期缓解；常不需要治疗 |
| 婴儿癫痫性痉挛综合征 | 一岁以内 | 成串的屈曲性痉挛、发育倒退，脑电图高度失律 | 需专科紧急治疗 |
| Lennox–Gastaut综合征 | 幼儿期 | 多种发作类型，包括强直和失张力发作，伴认知障碍 | 通常为药物难治性 |
| 伴海马硬化的颞叶癫痫 | 青少年期或成年期 | 上腹部上升感、似曾相识感、自动症、意识受损 | 常为药物难治性；手术可治愈 |

::: example 爱发呆的小学生 {#ex-absence}
一位7岁女孩的老师反映，她每天多次“走神”，话说到一半停下来，凝视几秒钟，然后若无其事地继续。她的父母一直以为她在做白日梦。在门诊让她深而快地呼吸；约90秒后她停了下来，凝视，眼睑颤动8秒，然后从中断处接着数数。
::: solution
1. **发作类型。** 短暂的活动停止伴凝视并立即恢复，每天多次，过度换气可诱发：典型的**失神发作**，属于全面性发作。与白日梦不同，喊她的名字或触碰她都不能打断。
2. **综合征。** 在其他方面健康的儿童中4–10岁起病，提示**儿童失神癫痫**。
3. **确认。** 做含过度换气的脑电图，预期在发作期间显示全面性3 Hz棘慢波放电。
4. **治疗原则。** 乙琥胺为首选（NICE NG217），丙戊酸钠或拉莫三嗪在专科医生指导下作为替代；卡马西平和其他钠通道阻滞剂可使失神加重。剂量遵循儿童处方集。
5. **实际要点。** 每天数百次失神会影响学习，因此要告知学校；预后良好，大多数儿童到青春期会自然缓解；游泳或洗澡时应有人看护。
:::
:::

## 诊断：这是癫痫发作吗？

癫痫的诊断是临床诊断。它依赖于患者本人，尤其是**目击者**的详细描述；用手机录下的视频往往比任何检查都有用。主要的鉴别诊断是晕厥和功能性（分离性）发作。

| 特征 | 癫痫发作（强直–阵挛） | 晕厥 | 功能性/分离性发作 |
|---|---|---|---|
| 诱因 | 常无；部分人为睡眠剥夺、闪光 | 站立、炎热、疼痛、静脉穿刺、劳力（心源性） | 情绪应激，但常无明显诱因 |
| 起始 | 突然；可有先兆 | 有头晕、出汗、视物发灰等前驱症状 | 逐渐或波动 |
| 眼睛 | 睁开 | 通常睁开 | 常紧闭，抗拒被扒开 |
| 动作 | 节律性抽动1–2分钟 | 常有短暂的不规则抽动（少于约15秒） | 不同步、左右摆动、骨盆前冲、时强时弱；可持续许多分钟 |
| 面色 | 发绀 | 苍白 | 通常正常 |
| 咬舌 | 舌侧缘 | 少见；如有为舌尖 | 不常见 |
| 恢复 | 意识模糊数分钟至数小时，嗜睡，肌肉酸痛 | 迅速恢复清醒 | 不定；可流泪 |

**惊厥性晕厥**，即晕厥时出现几下抽动，是误诊为癫痫最常见的原因。尿失禁在两者中都可出现，没有鉴别价值。心源性晕厥，尤其是在运动中或平卧时发生，或有猝死家族史者，需要心电图和心内科评估（见[[cardiovascular/arrhythmias]]）。

**辅助检查**可以支持诊断，但很少能单独作出诊断：

- **血液检查**：血糖、钠、钙、镁，必要时做毒物筛查，以寻找诱发性发作。
- **心电图**：每一位疑似首次发作者都要做，以寻找长QT综合征等心源性晕倒的原因。
- **脑电图**：用于支持诊断和确定综合征，但不能用来排除癫痫：约一半癫痫患者发作间期常规脑电图正常，而轻微的非特异性异常在非癫痫者中也很常见。睡眠剥夺脑电图和长程视频脑电监测可提高阳性率。
- **脑MRI**：优于CT，用于寻找结构性病因，尤其是在局灶性发作或成人患者中。

::: example 公交车站的晕倒 {#ex-syncope}
一位19岁女大学生在一个炎热的早晨没吃早饭，在公交车站晕倒。一位朋友说，她脸色发白，说自己感觉“不对劲”，视物发灰，然后瘫倒在地。她的双臂抽动了几下，约10秒。她意识模糊不到一分钟，随后道歉并问发生了什么。她没有咬舌。她在抽血时有过两次类似发作。
::: solution
1. **发作前。** 在炎热中站立、空腹、有头晕和视物发灰的前驱症状，以及既往静脉穿刺时的发作：典型的血管迷走性晕厥。
2. **发作中。** 面色苍白和数秒钟的抽动。短暂的肌阵挛性抽动在晕厥中很常见（“惊厥性晕厥”），不是癫痫发作的证据。
3. **发作后。** 定向力在一分钟内迅速恢复。强直–阵挛发作后，意识模糊通常持续长得多。
4. **计划。** 诊断为血管迷走性晕厥。仍需记录心电图，以排除长QT或其他传导异常。不需要脑电图，脑电图还可能产生误导。指导她识别前驱症状并采取对抗动作。误诊为癫痫会对驾驶和工作产生严重后果；在不应诊断时避免诊断，与在应诊断时作出诊断同样重要。
:::
:::

## 抗癫痫发作药物

抗癫痫发作药物抑制发作，但不能治愈潜在的癫痫。约三分之二的人用药后无发作，通常是在尝试第一种或第二种药物时。**药物难治性癫痫**定义为：两种选择恰当、可耐受、剂量充分的药物均未能实现持续无发作；这些人应转诊至癫痫专科中心，可能可以接受手术或其他治疗。

::: definition 抗癫痫发作药物的主要机制 {#def-asm}
- **钠通道阻滞剂**稳定电压门控钠通道的失活状态，限制快速重复放电：卡马西平、奥卡西平、拉莫三嗪、苯妥英、拉考沙胺。
- **突触囊泡蛋白SV2A配体**减少递质释放：左乙拉西坦、布瓦西坦。
- **GABA增强剂**增加抑制：苯二氮䓬类和苯巴比妥（GABA-A受体调节剂）。
- 丘脑**T型钙通道阻滞剂**：乙琥胺（失神发作）。
- **广谱或多重机制**：丙戊酸钠、托吡酯、唑尼沙胺。
:::

选择药物取决于发作类型和综合征、年龄、性别和妊娠可能性、其他用药和其他疾病。在NICE NG217（2022年）中，一线选择包括：局灶性发作用**拉莫三嗪或左乙拉西坦**；全面性强直–阵挛发作和青少年肌阵挛癫痫，男性及不能生育的女性用**丙戊酸钠**，替代药为拉莫三嗪或左乙拉西坦；失神发作用**乙琥胺**。剂量缓慢递增，遵循现行处方集。

一些重要特性和风险：

- **丙戊酸盐**具有高度致畸性：约10%宫内暴露的婴儿有重大畸形，多达30%–40%有神经发育问题。自2024年1月起，英国药品和保健品管理局（MHRA）要求，除非两位专科医生独立认定没有合适的替代药物或生殖风险不适用，否则不得对55岁以下的任何人开始使用丙戊酸盐。对可能怀孕的女性，只能在**妊娠预防计划**下使用。
- **卡马西平、奥卡西平和苯妥英**可引起严重皮肤反应（Stevens–Johnson综合征和中毒性表皮坏死松解症）。卡马西平的风险与**HLA-B\*15:02**等位基因密切相关，该等位基因在汉族、泰国和马来人群中常见，这些人群在用药前要进行检测。它们是**酶诱导剂**，会降低激素避孕药、华法林和许多其他药物的效果。它们可使失神和肌阵挛发作加重。
- **拉莫三嗪**可引起皮疹，尤其是剂量增加过快或与丙戊酸盐（会升高其血药浓度）合用时。妊娠期和与复方口服避孕药合用时其血药浓度下降。
- **左乙拉西坦**可引起易激惹、情绪低落，少数可引起精神病性症状。
- **苯妥英**呈非线性（饱和）动力学，剂量小幅增加即可引起血药浓度大幅升高和中毒（共济失调、眼震）。

大多数抗癫痫发作药物遵循一级动力学：开始规律给药后，血药浓度向稳态上升，一个半衰期后达到约50%，两个半衰期后达到75%，五个半衰期后达到约97%。同一规则也说明药物相互作用需要多长时间才能完全显现。

::: example 避孕与癫痫发作 {#ex-contraception}
一位24岁局灶性癫痫女性服用卡马西平已两年无发作。她开始服用复方口服避孕药，询问这是否是好的选择。她计划约两年后怀孕。
::: solution
1. **相互作用。** 卡马西平诱导肝酶（CYP3A4），加快雌激素和孕激素的代谢，因此复方避孕药可能失效。根据英国性与生殖健康学院的指南，推荐不受酶诱导影响的避孕方法（含铜宫内节育器、左炔诺孕酮宫内缓释系统或醋酸甲羟孕酮注射剂）。
2. **妊娠计划。** 应转诊到她的癫痫团队进行孕前咨询。卡马西平的致畸风险较低但确实存在；可考虑换用已知风险最低的拉莫三嗪或左乙拉西坦，但换药要在受孕前很早进行，且只有在能维持发作控制时才换，因为未控制的强直–阵挛发作本身在妊娠期就很危险。
3. **叶酸。** NICE NG217建议可能怀孕的服用抗癫痫发作药物的女性每日服用叶酸5 mg，在受孕前开始。
4. **丙戊酸盐。** 除非两位专科医生认定没有替代药物，否则不是她的选择。
5. 随后将进行**妊娠登记**和更密切的监测（包括拉莫三嗪的血药浓度，其在妊娠期会下降）。
:::
:::

### 药片之外

药物治疗失败时，**癫痫外科手术**（例如针对海马硬化的前颞叶切除术）可使患者无发作；在2001年的一项随机试验中，接受手术的颞叶癫痫患者一年时58%无损害知晓的发作，而继续药物治疗者仅为8%。其他选择包括**迷走神经刺激**、**生酮饮食**（尤其在儿童中），以及较新的靶向药物，如用于Lennox–Gastaut综合征和Dravet综合征的大麻二酚。

## 与癫痫共处

**驾驶。** 在英国，规则由DVLA制定。对小汽车或摩托车驾照（第1组），首次非诱发性发作后，若评估显示风险未增加，通常需停驾6个月；诊断癫痫后，通常需无发作12个月。临床医生必须告知患者其通知DVLA的法律义务。第2组（公共汽车和货车）的规定严格得多。

**安全。** 淋浴而不是盆浴，注意高处、水和烹饪，游泳等活动应有适当看护。

**癫痫猝死（SUDEP）**在癫痫成人中每年约发生千分之一，在频繁全面性强直–阵挛发作、夜间发作和独自睡眠者中更常见。应与每一位癫痫患者讨论，因为控制发作和坚持服药可降低风险。

**心理健康。** 抑郁和焦虑在癫痫中常见，应当询问。在许多社区中，病耻感仍是真实的负担。

## 癫痫持续状态

::: definition 癫痫持续状态 {#def-status}
**癫痫持续状态**是指由于终止发作的机制失效，或由于启动了导致发作异常延长的机制而出现的状况。ILAE（2015年）为惊厥性（强直–阵挛）持续状态给出两个时间点：**t1 = 5分钟**，此后发作不太可能自行停止，应开始治疗；**t2 = 30分钟**，此后有出现包括神经元损伤在内的远期后果的风险。发作之间未恢复的反复发作按同样方法处理。
:::

惊厥性持续状态的治疗遵循分阶段方案，时机比具体药物的选择更重要。剂量遵循英国现行方案（例如英国复苏委员会和APLS流程）和处方集。

1. **0–5分钟**：气道、呼吸、循环，吸氧，测指尖血糖（处理低血糖），记录发作时间，防止受伤。
2. **5分钟时**：给予**苯二氮䓬类**，有静脉通路时用静脉劳拉西泮，否则用颊黏膜咪达唑仑（或直肠地西泮）。若发作持续，5–10分钟后可再给一次。院前给药也要计入。
3. **约20分钟，若发作持续**：静脉给予**二线药物**：左乙拉西坦、苯妥英（或磷苯妥英）或丙戊酸钠。ESETT试验（2019年）发现这三种药物疗效相似，各自约使一半患者的持续状态终止。
4. **难治性持续状态（约30–45分钟）**：快速顺序诱导麻醉并转入重症监护，进行脑电监测。

全程都要寻找并治疗病因：低血糖、低钠血症、酒精戒断（静脉给予维生素B1）、感染（脑膜炎或脑炎）、卒中、药物中毒，或停用抗癫痫发作药物。

::: warning 苯二氮䓬类给得太少、太晚
癫痫持续状态最常见的错误是治疗不足：第一剂苯二氮䓬类等待太久，剂量太小而无效，或随后苯二氮䓬类总共给了两次以上，导致呼吸抑制却未能终止发作。在5分钟时给予足量首剂，最多重复一次，然后迅速改用二线药物。还要记住，抽搐已停止但不醒的人可能处于**非惊厥性持续状态**；当意识未按预期恢复时，需要做脑电图。
:::

::: example 护理院里的一次长时间发作 {#ex-status}
一位58岁有学习障碍和癫痫的男性在护理院被发现正在强直–阵挛发作。工作人员在第8分钟给予了颊黏膜咪达唑仑。急救人员在第15分钟到达；他仍在发作，吸空气时血氧饱和度91%，血糖5.2 mmol/L。他在第30分钟到达急诊科，仍在发作。
::: solution
1. **识别持续状态。** 他持续发作超过5分钟：惊厥性癫痫持续状态。到第30分钟他已超过t2，神经元损伤成为风险。
2. **计算苯二氮䓬类剂次。** 已给一剂颊黏膜咪达唑仑。急救人员按其方案给第二剂苯二氮䓬类（例如建立静脉通路后用静脉劳拉西泮）。这就是两剂：不再给苯二氮䓬类。
3. **二线药物。** 到院后立即静脉给予二线药物：左乙拉西坦、苯妥英或丙戊酸盐。若已知他平时用药，选择时应考虑（例如若他已在服用苯妥英而血药浓度未知，避免苯妥英负荷）。
4. **为难治性持续状态做准备。** 现在就呼叫重症监护团队。若二线药物后发作仍持续，他将需要麻醉和机械通气。
5. **寻找病因。** 再次测血糖，查钠、钙、镁，必要时测血药浓度，查感染指标，询问漏服药物、近期疾病和饮酒情况。病情稳定后行头颅CT。
6. **恢复后。** 重新审视他的照护计划，确保急救用药计划清晰，并以易于理解的方式与他和照护者讨论发生了什么。
:::

::: quiz
一位16岁女孩大多数早晨双臂抽动，常把牙刷掉在地上，一次在朋友家过夜后出现全面性强直–阵挛发作。她的脑电图显示全面性多棘慢波放电。下列哪种药物是最不合适的选择？
- [ ] 左乙拉西坦
- [ ] 拉莫三嗪
- [x] 卡马西平
- [ ] 丙戊酸钠，仅在两位专科医生认定没有合适替代且已实施妊娠预防计划时
::: solution
这是青少年肌阵挛癫痫。卡马西平（以及苯妥英、奥卡西平等其他钠通道阻滞剂）可使全面性癫痫中的肌阵挛和失神发作加重，应避免使用。左乙拉西坦是年轻女性常用的首选。拉莫三嗪可以使用，但偶尔会使肌阵挛加重。丙戊酸盐对该综合征非常有效，但由于其致畸性，对女孩和女性只能在上述严格的英国规定下使用。
:::

::: history
约公元前400年，希波克拉底学派的作者在《论圣病》（*On the Sacred Disease*）中提出，癫痫是脑的疾病，而不是神灵降罚。19世纪70年代，约翰·休林斯·杰克逊（John Hughlings Jackson）把发作定义为“灰质偶发的、突然的、过度的、快速的局部放电”，并描述了局灶运动性发作的扩展。1857年查尔斯·洛科克（Charles Locock）引入的溴化物是第一种有效药物；苯巴比妥于1912年问世，苯妥英则由H·休斯顿·梅里特（H. Houston Merritt）和特雷西·帕特南（Tracy Putnam）于1938年利用猫的电休克模型发现。汉斯·伯格（Hans Berger）在20世纪20年代记录了人类脑电图；20世纪30年代，弗雷德里克·吉布斯（Frederic Gibbs）、埃尔娜·吉布斯（Erna Gibbs）和威廉·伦诺克斯（William Lennox）描述了失神发作的3 Hz棘慢波。怀尔德·彭菲尔德（Wilder Penfield）和赫伯特·贾斯珀（Herbert Jasper）从20世纪30年代到50年代在蒙特利尔发展了癫痫外科。
:::

## 后续内容

发作背后的离子通道和突触见[[physiology/membrane-potentials]]和[[physiology/synapses]]。卒中、感染和炎症所致的发作在[[nervous-system/stroke]]和[[nervous-system/neuroinflammation]]中讨论。儿童癫痫（包括热性惊厥）见[[paediatrics/neurodevelopment]]；妊娠与用药见[[obstetrics-gynaecology/pregnancy-complications]]。

::: summary
- 癫痫发作是神经元异常过度或同步化的活动；癫痫的定义是两次间隔超过24小时的非诱发性发作、一次再发风险高的非诱发性发作，或一种癫痫综合征。
- 诱发性发作（低血糖、酒精戒断、急性脑损伤）不是癫痫。
- 发作分为局灶性（意识保留或受损，可能进展为双侧强直–阵挛）、全面性、未知和不能分类（ILAE 2025年）。
- 诊断是临床诊断，依赖目击者描述；晕厥（包括惊厥性晕厥）和功能性发作是主要的类似疾病。每一位首次发作者都需要心电图；脑电图正常不能排除癫痫。
- 药物选择取决于发作类型和个体因素：局灶性发作用拉莫三嗪或左乙拉西坦；失神发作用乙琥胺；丙戊酸盐有效但高度致畸，在英国受到限制。
- 酶诱导剂与避孕药和其他药物相互作用；卡马西平可使全面性癫痫加重；相关血统人群在用卡马西平前检测HLA-B\*15:02。
- 药物难治性癫痫（两种合适药物失败）需转诊专科；手术可治愈。
- 癫痫持续状态：5分钟时给苯二氮䓬类，重复一次，然后二线药物（左乙拉西坦、苯妥英或丙戊酸盐），然后麻醉；全程寻找病因。
- 与每一位癫痫患者讨论驾驶、安全和SUDEP。
:::

## 习题

::: exercise 诱发性还是非诱发性？ {level=1}
把下列发作分为诱发性或非诱发性，并说明其本身能否确立癫痫的诊断：(a) 停止大量饮酒18小时后的发作；(b) 血钠112 mmol/L的男性的发作；(c) 大面积卒中两年后的单次发作，伴癫痫样脑电图；(d) 头部外伤当天的发作。
::: solution
(a) 诱发性（酒精戒断）：不是癫痫。(b) 诱发性（严重低钠血症）：不是癫痫。(c) 非诱发性，发生在卒中后很久，有结构性病灶和癫痫样脑电图：再发风险高（至少60%），因此一次发作后即可诊断癫痫。(d) 诱发性（急性症状性，外伤后立即发生）：本身不是癫痫。
:::
:::

::: exercise 稳态 {level=1 check="0.875"}
一种遵循一级动力学的药物开始规律给药。三个半衰期后达到稳态浓度的多少？给出精确的小数。
::: solution
比例为$1 - 0.5^{3} = 1 - 0.125 = 0.875$，即87.5%。

::: exercise 达到新稳态的时间 {level=2 check="100"}
某药消除半衰期为40小时。开始使用另一种诱导其代谢的药物，使其半衰期减半。按五个半衰期后实际达到新稳态的规则，在诱导剂充分起效后多少小时，第一种药物达到新的稳态？
::: solution
新的半衰期为$40/2 = 20$小时。五个半衰期 $= 5 \times 20 = 100$小时，略多于四天。（酶诱导本身需要数天至数周才能完全形成，因此实际上效应在更长时间内逐渐累积，可能需要监测血药浓度。）
:::

::: exercise 晕厥还是发作？ {level=2}
一位45岁男性在慢跑时无先兆地倒下。妻子看到他倒地、脸色发灰、抽动约10秒，一分钟内醒来。他的兄弟38岁时猝死。最重要的鉴别诊断是什么？下一步应该怎么做？
::: solution
运动中无先兆的晕倒、短暂抽动和迅速恢复，加上年轻时猝死的家族史，提示**心源性晕厥**（心律失常或肥厚型心肌病、离子通道病等结构性心脏病），而不是癫痫。抽动是惊厥性晕厥。他需要紧急心电图和心内科评估（超声心动图、动态心电监测、运动试验，可能还需基因检测），评估前不应驾驶或运动。给他贴上癫痫的标签并开始抗癫痫发作药物，会使一个可能致命的病因得不到治疗。
:::
:::

::: exercise 首次发作门诊 {level=2}
一位30岁女性有过一次在睡眠中发生、有人目击的全面性强直–阵挛发作。查体、血液检查和心电图均正常。概述她的检查，以及她在离开首次门诊前需要得到的建议。
::: solution
检查：脑电图（最好包含睡眠，若常规脑电图正常可做睡眠剥夺脑电图），寻找癫痫样放电和综合征；脑MRI寻找结构性病因。建议：她不得驾驶，必须通知DVLA（首次非诱发性发作后通常至少停驾6个月，若诊断癫痫则更长）；安全措施（淋浴而不是盆浴，注意高处和水）；若再次发作该怎么办（目击者描述、尽可能录视频、何时呼叫救护车）；避免睡眠剥夺和过量饮酒；以及与她情况相适应的SUDEP信息。是否开始治疗取决于她的再发风险（脑电图或MRI异常时更高）和她的意愿。
:::
:::

::: exercise 一例持续状态 {level=3}
一位有酒精依赖史的72岁女性因持续12分钟的发作入院。她已用过两剂劳拉西泮。血糖3.1 mmol/L。按顺序描述你的即刻处理，并解释每一步的理由。
::: solution
1. 气道、呼吸和循环；高流量吸氧；监护。2. 纠正低血糖，但要在给葡萄糖之前或同时**静脉给予维生素B1**，因为她有Wernicke脑病的风险，不补维生素B1而给葡萄糖可诱发该病。3. 不给第三剂苯二氮䓬类：已给两剂，再给主要会引起呼吸抑制。4. 现在静脉给予二线药物（按当地方案选择左乙拉西坦、苯妥英或丙戊酸盐；怀疑肝病时避免丙戊酸盐）。5. 呼叫重症监护，以防发展为难治性持续状态。6. 寻找病因：酒精戒断、低血糖、电解质（钠、镁、钙）、跌倒所致头部外伤（行头颅CT，因她可能有硬膜下血肿）、感染和药物中毒。7. 之后监测酒精戒断，评估营养，并安排随访。
:::
:::

::: exercise 贝叶斯与脑电图 {level=3 check="0.77"}
在首次发作门诊中，40%的转诊者经历的是癫痫发作。常规脑电图在50%的癫痫患者和10%的非癫痫者中显示癫痫样放电（示意值）。有癫痫样放电者患癫痫的概率是多少？保留两位小数，并评论脑电图正常意味着什么。
::: solution
取100人。40名癫痫患者中，$40 \times 0.5 = 20$人脑电图阳性。60名非癫痫者中，$60 \times 0.1 = 6$人脑电图阳性。阳性预测值为$20 / (20 + 6) = 0.769$，保留两位小数为0.77。

正常脑电图的信息量要小得多：74名脑电图正常者中仍有20人患癫痫（$20/74 \approx 0.27$），因此概率仅从0.40降到约0.27。这就是为什么发作间期脑电图正常永远不能排除癫痫，也是为什么对病史提示晕厥、验前概率低的人开具脑电图，产生的假阳性会多于真阳性。
:::
