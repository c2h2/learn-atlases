特殊感官是神经病学中“渗进其他每一专科”的那部分：看不清的孩子、复视的驾驶员、“因为前庭系统失效而跌倒的老人”、以及那位“功能性的无力”其实是没人描绘过视野缺损的患者。视觉占据了本章的大部分，因为大多数的感觉的主诉是视觉的，也因为视觉的通路是全身最长的传导束、并拥有最丰富的定位的价值。听觉与平衡“带着它们自己的几何”随后到来，而化学的感觉大多以耳鼻喉与全身的疾病的形式出现。

本章涵盖眼与它的急症、屈光与视网膜的疾病、视觉的通路与皮质的盲、听力的丢失与眩晕、以及味觉与嗅觉。

## 眼与“威胁视力的疾病”

::: definition 疼痛的红眼与“不痛的视力的丧失” {#def-eye}
**按三个问题接近——痛还是不痛、视力丢了还是保住了、有没有分泌物——因为红眼首先是一处“角膜与前房及结膜及附属器的解剖的分诊”、然后才是一个鉴别诊断。“威胁视力的病因”与它们的鉴别：急性闭角型的青光眼年长的、远视的、亚洲或女性的患者，剧烈单侧的痛与光晕及呕吐、“中等度散大的固定的瞳孔”、“冒雾的角膜”与“石头一样硬的眼球”——这是一桩靠“降眼压与激光的周边虹膜的切开”治疗的急症、而对侧的眼总要被安排预防，因为“解剖的易感是双侧的；角膜炎与角膜的溃疡戴接触镜的人、疼痛与体征不相称、荧光的染色、铜绿假单胞菌的风险、不要遮盖、”没有眼科的同意不要局部用激素“、当溃疡是中央的或化脓的要刮取培养；前段的葡萄膜炎怕光与”睫状的充血“及小的迟缓的瞳孔、”角膜后沉着物“、以及”让风湿科的病史成为检查的一部分的“与强直性脊柱炎相关的肠与背的关联；巩膜炎”把患者从睡眠中挖出来的钻痛“、”用去氧肾上腺素也不变白的红血管“、以及血管炎的搜寻；眼内的炎症操作后或创伤后或内源的、前房的积脓与玻璃体的炎、数小时之内的玻璃体内的抗生素；以及眼眶的蜂窝织炎（发热与突眼及“疼痛受限的活动度”、儿童那种“相邻筛窦的来源”、窦与眼眶的增强的影像、引流的决定、以及“作为被畏惧的延伸的海绵窦的血栓”——与良性的“眶前的版本”形成对照，后者不限制眼动也不推移眼球）。不痛的视力的丧失按速度与持续性来分：血管的事件视网膜中央动脉的阻塞——樱桃红斑点、一桩“以分钟与小时计”的眼科的急症、并且要做卒中的检查，因为“块抛出栓子的颈动脉也能抛出一块半球用的”；视网膜中央与分支的静脉的阻塞——“血与雷”、糖尿病与高血压的关联、以及“新血管的随访；玻璃体的积血（”红视的丧失“、眼底看不到、糖尿病与抗凝、以及”后玻璃体的脱离伴视网膜的创伤“）；视网膜的脱离（闪光与”飞蚊的骤增“、以及”伴进展视野丧失的帘幕“——一桩”只要当天手术就还能救下视力“的外科的急症）；以及缺血性的视神经的病变（年长者、”下颌跛行的那一问”、“肿胀而苍白的盘“、以及”巨细胞动脉炎绝不能被漏掉”——[[musculoskeletal/connective-tissue-vasculitis]]、[[nervous-system/stroke]]。）**
:::

## 屈光、处方与保护

::: definition 视网膜、视神经与视觉的通路 {#def-pathway}
**糖尿病的视网膜病变是一份“微血管的清点”：背景的改变微动脉瘤与出血及硬的渗出及“静脉的串珠”、增殖的疾病“盘上的与盘外的新血管”、玻璃体的风险、以及黄斑的病才是“致盲的机制里最常见的那个”、按“渗出与中心凹周围的水肿”分级；以及治疗的文法：“为增殖的风险做激光的光凝、为黄斑的水肿与新血管做玻璃体内抗内皮的生长因子”。筛查的项目之所以要计数，是因为病灶在成为灾难之前没有症状；妊娠与“胰岛素的需求”及高血压与肾的病会改变节奏、而“在快速血糖的纠正之后突然恶化”是真实的、值得警告患者（[[endocrine/diabetes-complications]]、[[renal/filtration]]、[[obstetrics-gynaecology/pregnancy-complications]]）。年龄相关黄斑的变性分为干性玻璃膜疣与萎缩、“那个配方研究的细微差别”、以及低视力的服务与湿性（在方格表上的“视物变形”、突发的扭曲、以及“保住而不是恢复”的抗内皮生长因子的方案）。青光眼——那种“杯囊与弓形的缺损”的视神经病、眼压是一个“可治疗的风险因子”而不是疾病本身——需要视野计与光学断层与多年的视野的比较；而它无症状的早期正是“在五十岁以上的人群与青光眼的亲属中见缝插针地测量”的论据。视神经炎年轻的女性、“眼球运动时痛”、数天的“饱和度与颜色的丧失”、“球后的病例里盘是正常的”，所以那是“一位眼底正常而看不见”的患者、多发性硬化的关联与磁共振的决定、“激素加速的是恢复而不是最终结局”这一点、以及模仿它的其他诊断——“血管性年长者的伴高度视野缺损而不痛的”缺血性视神经的病变、“双侧短暂的黑蒙”的视盘的水肿、“少年的男孩”的遗传的视神经病则连同它的“脱髓鞘的家族”一起放在[[nervous-system/neuroinflammation]]里。眼之外的通路“带着视交叉的交叉这一心思”来定位：单眼的丢失定位到视神经或视网膜；视交叉的病灶定位到双颞侧的偏盲鉴别是垂体与颅咽管瘤；视束与外侧膝状体定位到“对侧同向的偏盲”；视辐射定位到“不一致的缺损伴黄斑的豁免”（“颞叶的对上、顶叶的对下”）；而枕叶的皮质定位到“不一致性更高、黄斑的豁免更典型、并且”对侧偏盲而眼底正常“的缺损——外加皮质盲与”否认自己看不见的安东综合征“（[[anatomy/neuroanatomy]]、[[nervous-system/stroke]]、[[clinical-skills/medical-imaging]]。）**
:::

::: definition 屈光的错误与斜视 {#def-refraction}
**屈光的错误是光学，而它的临床内容是“谁会有它们”与“它们藏起了什么”：近视远距的模糊与轴的变长、以及“近距离的用眼与户外的光的剥夺”这一流行、以及“让儿童期的控制成为一个严肃的议题”的高度近视的并发症——视网膜的脱离与近视的黄斑的病及青光眼——阿托品的滴眼与角膜塑形镜及“离焦的眼镜”、带着它们“真实但不大”的效应量；远视在年轻人身上“由调节驱动的眼的疲劳与头痛”、“显著的未矫正的远视”导致弱视的风险、以及“老视把已代偿的患者推入模糊”；散光（角膜的形状与“重影”、以及“角膜门诊的瘢痕与圆锥角膜”与揉眼及特应性的关联——特应性的行军见[[musculoskeletal/skin]]）；以及老视（四十多岁那“人人都会的晶体的变硬”、每一位“不戴镜的专业人士”都把它体验为“看菜单与看手机的症状”）。接触镜带来它们自己的医学：过夜佩戴与水接触时的“微生物的角膜炎”的风险游泳者与自来水冲洗者的“棘阿米巴”——见[[microbiology/fungi-parasites]]的棘阿米巴的页面、以及“巨大乳头的结膜炎”与干眼、以及“任何住院医师都该按危险信号标出来的接触镜滥用的溃疡”。弱视是一桩“来自斜视或屈光参差或剥夺白内障、上睑下垂、血管瘤发育性皮质的现象”——这就是为什么新生儿的眼的检查要寻找红光反射、以及为什么遮盖“只在可塑性还剩下的时候有效”——筛查与治疗的方案的逻辑在[[paediatrics/growth-development]]与[[public-health/screening]]。斜视：可重复试验下的“共同性的偏斜”，对动眼与滑车及外展的麻痹的“麻痹性的斜视”——各自都有定位的含义（“痛而瞳孔受累动眼神经的麻痹，在证实之前就是动脉瘤”；“在颅内压增高时孤立的外展”是一处假定位的征；以及“豁免瞳孔糖尿病微血管的麻痹”）；以及眼球震颤的各族（先天性的、“以快相命名的方向”的前庭性的、“向下的与向上的”、以及“分离性与周期性的”；并别忘了“看见却说不清”的视觉的失认——[[anatomy/neuroanatomy]]、[[clinical-skills/physical-examination]]。）**
:::

::: example 那个带光晕的早晨 {#ex-angle}
一名68岁的女性醒来时“右眼带着彩虹的光晕”、眉弓的痛、呕吐两次并恶心；她一直只需要“看远的眼镜”；眼是“安静的红”、瞳孔中等度散大而固定、角膜冒雾；她因一片皮疹服用过一种抗组胺的药。
::: solution
**在被排除之前就是急性的闭角——而用药的病史就是那个触发（[[#def-eye]]、[[#def-refraction]]）：识别——光晕与疼痛及呕吐常常被错分成胃肠或偏头痛、“固定的中等散大的瞳孔”与冒雾的角膜及“远视小眼的类型”，其中“抗胆碱的药物抗组胺与抗抑郁及解痉及拟交感的”是经典的触发因子、而“电影院与黄昏时分暗下的瞳孔”是它的表亲——[[pharmacology/adverse-reactions]]、[[clinical-skills/history-taking]]；几分钟——同一小时的紧急眼科不要等病房、不要当成结膜炎治、按方案“降眼压局部的与全身的药物”β的阻滞剂的滴眼伴哮喘的告诫、α的激动剂、碳酸酐酶的抑制剂、有时用高渗的、止吐、“在眼压下降与疼痛允许之前避免缩瞳”、以及口服或静脉的乙酰唑胺带着它的磺胺与肾的告诫——[[pharmacology/dosing-principles]]、[[renal/filtration]]、磺胺与哮喘的病史在[[respiratory/asthma-copd]]；确定的动作——“在角膜变清之后做激光的周边虹膜的切开”、以及在今天就讨论“对侧的预防的激光”，因为“解剖的风险是双侧的”而“法医的文献毫不含糊”、并记录“关于黑暗的房间与新的药物的教育”——[[clinical-skills/patient-safety]]、[[clinical-skills/records-handover]]；以及模仿它的鉴别：来自“糖尿病的或缺血阻塞的视网膜”的新生血管的青光眼虹膜上的新血管、与“原发闭角的那张平坦的虹膜”正相反、“疼痛的高压-睫状危机的发作”、以及“伴虹膜后粘连的葡萄膜炎性继发性的关闭”——[[endocrine/diabetes-complications]]、[[musculoskeletal/connective-tissue-vasculitis]]、葡萄膜炎的肠的关联见[[gastrointestinal/bowel-disease]]。**
:::

::: example 傍晚天空里那块帘幕 {#ex-retinal-detachment}
一名55岁的高度近视的男子注意到“左侧周边在醒来时闪烁的光”两天、然后是“二十个新的飞蚊”的骤增、而现在“一块从下方爬上来灰色的帘幕、昨晚到现在没有移动”；中心的视力是6/6。
::: solution
**裂孔源性的脱离——下方的视野意味着上方的裂口、而“中心的视力还不错”意味着今天就手术（[[#def-pathway]]、[[#def-refraction]]）：机制——“后玻璃体的脱离在一处格子样变性的部位把周边的视网膜撕开”、近视与术后及创伤的易感、以及“闪光、然后飞蚊、然后帘幕”这个序列它是眼科里最可靠的病史；危险信号的清单见[[#def-eye]]；当日的路径——紧急的“玻璃体视网膜的评估”，散大的眼底检查与“压迫的检查”帘幕不会等一个常规的号、屈光介质混浊时用超声、“禁食的建议与体位的讨论”、以及一条明确的指示：“半个视野丢失之后不要开车”——[[clinical-skills/clinical-reasoning]]、[[clinical-skills/communication]]；手术与之后——填塞（气体或硅油）配体位的规则、“用了气体之后的飞行与海拔的禁忌”、以及随之而来的白内障的加速；对经选择的年轻的“自身晶状体的”患者则用巩膜的扣带；以及“一次一只眼”的咨询对侧的风险与要回来复诊的症状；以及后续的内科学——对侧眼的格子样变性的检查、创伤或手术后“罕见同时双眼的脱离”、以及“如果黄斑脱离得够久、成功的复位之后仍留下扭曲”时的低视力的转诊——低视力与职场的谈话属于[[clinical-skills/communication]]。**
:::

::: example 那个坐在前排的孩子 {#ex-amblyopia}
一名6岁被学校的视力筛查转诊，理由是“右眼斜而且视力差”；检查发现“显性的内斜”与“最佳矫正的视力右6/18、左6/5”；眼底正常。
::: solution
**斜视性的弱视、外加一个“仍然需要把病因分开的斜视”（[[#def-refraction]]、[[paediatrics/growth-development]]）：检查——“睫状肌麻痹下的验光”以揭出远视儿童用调节把它藏起来、而未矫正的远视同时驱动内斜与弱视、逐眼完整视力的记录、“眼位测量的检查”、以及排除少见器质的模仿者包括视网膜的母细胞瘤：白瞳症、在给“懒眼”贴标签之前永远先看红光反射——是法医上的经典、以及生长与神经学的背景（[[paediatrics/growth-development]]、[[anatomy/neuroanatomy]]）；治疗的阶梯——眼镜先来并全时戴一个显著远视的内斜“可能只靠矫正就变直”、然后是对好眼的“遮盖或惩罚”以每天的小时数计量、而依从与课业的协商才是真正的壁垒、然后在“视力被最大化之后”做斜视的手术在弱视的治疗之前手术是“用对位换掉一个被浪费的机会”——学校筛查为何存在的理由见[[public-health/screening]]、“与一个讨厌被遮盖的孩子的遮盖的契约”见[[clinical-skills/communication]]；监测的逻辑——“在大约七八岁之前动手”背后关键期的神经科学、那个“迫使成功治疗后继续复查”的复发的比率、以及那位“来得太晚”的成人患者（对他诚实的回答是“可塑性减少了，而不是没有了”）——视觉皮质关键期的生理见[[physiology/membrane-potentials]]、发育的那几行见[[anatomy/neuroanatomy]]；以及安全的那一层——“如果那只好的眼受伤，未来就只有一只眼”、所以在每一间弱视的门诊里，运动时的眼的防护是一场值得进行的谈话——[[public-health/environmental-occupational]]。**

## 听觉、平衡与化学的感觉

::: definition 耳：传导的、感音的与前庭的 {#def-ear}
**听力的丢失“在一切之前”先用音叉或听力图来分：传导的外耳与中耳：耵聍；中耳的积液“胶耳”——儿童听力丢失最常见的原因、以及腺样体与通气管的时代；耳硬化症（带着它的“常染色体的家族与妊娠时加重”的传说、以及那台出色的“镫骨的手术”；以及在糖尿病的年长者伴铜绿假单胞菌与脑神经的“恶性的外耳道炎”——[[endocrine/diabetes-complications]]、[[infectious-diseases/immunocompromised-host]]）；感音的老年性的听——双侧高频的、“群体门诊里隐藏的残疾”与助听器的接受度问题；噪声引起的带着它在4千赫的切迹与职业赔偿的现实——[[public-health/environmental-occupational]]；梅尼埃病“发作性的眩晕伴低频的丢失及胀满感及耳鸣”、内淋巴积水的模型、以及“倍他司汀与饮食、对鼓室内注射激素、对破坏性的操作”这一阶梯；突发特发感音神经的聋——“一桩在数日之内用激素、却被错归成耳堵塞”的急症；耳的毒性——氨基糖苷类在测血药浓度的时代里风险降低了但仍真实、顺铂带着它在儿童幸存者的负担与“耳蜗植入物的规划”、袢的利尿药、“奎宁时代的传说”、以及可逆的水杨酸的耳鸣——[[pharmacology/adverse-reactions]]、[[pathology/cancer-diagnosis]]；以及前庭的神经鞘瘤（单侧不对称的丢失伴“差的分辨力与耳鸣”、“内听道磁共振的方案”这一问、以及在“年轻双侧的病例”中的2型神经纤维瘤病——[[genetics/mendelian-inheritance]]、[[nervous-system/motor-systems]]）；以及混合性的；最后是中枢对周围性的眩晕——急性前庭综合征三联床旁的试验（“头冲击与眼球震颤的模式及偏斜的凝视”）“对后循环的卒中比早期的磁共振更敏感”；良性阵发性位置性的眩晕（带它“数秒的、扭转加上跳的”的位置性的眼震、以及作为床旁的治疗的“复位的手法”）；前庭神经炎对迷路炎按听力是否受累来分——[[nervous-system/stroke]]、[[clinical-skills/physical-examination]]。**
:::

::: example 阵“其实是卒中”的眩晕 {#ex-hints}
一名61岁的高血压的男子突发持续的眩晕伴呕吐、“没有支撑就无法站立”；眼球震颤“在向左右注视时改变方向”；“向右的头冲击试验正常”；他说话时有一点构音障碍。
::: solution
**在成像之前，它就是一桩“三联床旁试验脆弱的”后循环的卒中（[[#def-ear]]、[[nervous-system/stroke]]）：床旁的信号——在持续的眩晕中“随注视改变方向的眼震”与正常的头冲击，指向中枢、而不是周围；而“小的脑干的梗死在早期的弥散加权可以是阴性的”，意味着“第一张正常的磁共振”并不能推翻临床的体征——[[clinical-skills/physical-examination]]、[[clinical-skills/medical-imaging]]；卒中系统的响应——同一小时卒中的评估带评分的记录与“溶栓与取栓的时间窗的算术”、以及“头颈的CT的血管成像”去回答“以耳痛与眩晕为表现”的椎动脉的夹层与闭塞的问题——[[emergency-critical-care/acute-assessment]]、[[emergency-critical-care/resuscitation]]；收住的内科——“带着那份构音障碍”的误吸的筛查、以及静脉血栓与压疮及血糖的照护当“躺着感觉更安全”时、给浴室做防跌倒的改造、以及早期活动的争论“与卒中单元水平照护的逻辑”——[[clinical-skills/patient-safety]]；以及绝不可做的事——“用好几天止吐的镇静剂”会延迟代偿并镇静掉检查本身；在“那双眼睛始终对不上”时“以病毒的迷路炎出院”；以及“把倍他司汀当保险”——以及之后的门诊：“在急性期过去之后做前庭的康复”、以及“能让一位患者晕上一年”的偏头痛与焦虑的叠加、以及“在同一周写好驾照的那封信”的驾驶的建议——[[psychiatry/anxiety-disorders]]、[[clinical-skills/communication]]。**

::: example 耵聍、疼痛与穿孔 {#ex-ear}
一名34岁“自幼就有的、在冬天更差”的听力的丢失，因3天的剧烈的耳痛与发热及脓性的分泌物而来；鼓膜膨出；既往的听力图显示30分贝传导的丢失。
::: solution
**一只耳里的两种疾病——慢性鼓膜的病变“外加叠在其上的急性的中耳炎”（[[#def-ear]]）：急期的处理——镇痛为先按规律的给药、不是“按需”；“作为鼓膜的减压而出现的分泌物”；以及抗生素是否被指征（年龄与严重度及全身的特征及免疫的受损；以及“伴分泌物穿孔的路径”——在那里“外用喹诺酮的滴眼成为首选的药物”，并配一份“对听力安全的解释”（氨基糖苷的滴眼与耳蜗的风险）；以及关于“乳突的压痛与膨出及颈的僵硬”的安全网的教育——[[microbiology/antimicrobials]]、“肺炎链球菌与流感嗜血杆菌及卡他莫拉菌”的演员表见[[microbiology/bacteria]]）；听力的故事——份“自幼就有”的传导的丢失，要求“为穿孔做一次正式的检查”：胆脂瘤（“上皮的凹陷与恶臭的分泌物及CT上的骨的侵蚀”、以及那台“要在它能被安排时、而不是在它渗漏时做”的手术规则，“对听小骨的固定与胶耳”；以及“单侧听力的丢失”在职业与驾驶上的含义——[[public-health/environmental-occupational]]、[[microbiology/infection-control]]）；以及后续——在急性发作平息之后重复听力图持续存在传导的丢失需要耳鼻咽喉科的行动、“穿孔防水的措施”、以及那条“绝不要冲洗一具来路不明的鼓膜”的规则开业护士与急诊都一样——[[clinical-skills/patient-safety]]。**

::: exercise 搭起红眼的分诊 {level=1}
把它们分成“同一小时的眼科”与“治疗并复查”：（甲） 单侧黏稠的分泌物、视力正常、眼是软的；（乙） 戴接触镜的疼痛伴角膜上一个白点；（丙） 白内障手术后第3天的模糊伴飞蚊与疼痛；（丁） 突发不痛的飞蚊与帘幕；（戊） 金属加工之后“磨砂样的异物感”。
::: solution
**两份清单（[[#def-eye]]）：（甲）感染性的结膜炎——卫生的建议、不用激素、感染性的病例不遮盖配学校与工作的“缺席的时间”的安排，以及那条“绝不要以这个诊断放走术后患者”的规则——[[public-health/communicable-disease-control]]；（乙）接触镜的角膜炎——同一小时：如果有溃疡就刮取、“加强高频率局部的抗生素”、覆盖铜绿假单胞菌、永不遮盖、停戴、“把镜片与镜盒送去培养”——[[microbiology/antimicrobials]]；（丙）术后的眼内炎——同一小时、玻璃体的取样与玻璃体内的抗生素、这是一桩“以小时而不是以天计的”急症——[[infectious-diseases/healthcare-infections]]；（丁）视网膜的脱离——当日“玻璃体视网膜的服务”、“黄斑还在位”是一桩解剖与功能的急症——[[#def-pathway]]；（戊）角膜的异物——荧光染色、翻转上睑、“锈环与铁的沉积”、外用的抗生素与复查；若怀疑“眼内的穿透”则紧急用希德尔试验与“金属加工者的眼内异物的病史”、在移除任何可疑的东西之前先做CT、以及“为迟早要发生的只有一只眼的事故”做眼的防护的咨询——[[clinical-skills/physical-examination]]、[[emergency-critical-care/acute-assessment]]。**

::: exercise 为糖尿病的视网膜开处方 {level=1}
解释筛查发现的“背景的改变、没有黄斑的病”意味着什么、以及你的随访的处方该写什么。
::: solution
**把筛查的分级变成行动（[[#def-pathway]]、[[endocrine/diabetes-complications]]）：解释——背景性的病变意味着“微血管的渗漏已经存在、但还没有威胁视力的病灶”；份“好消息的框架”（目前视力是安全的）与“风险可修改的因子”——[[clinical-skills/communication]]；处方——“每年的视网膜的筛查的间隔、以及什么会让它更频繁”、以及“妊娠告知的义务”（因为视网膜的病变会在妊娠中进展、以及那句“突发不痛的飞蚊或帘幕意味着本周之内评估”的规则——[[obstetrics-gynaecology/pregnancy-complications]]、[[public-health/screening]]）；叠可修改的——个体化血糖的目标与那句“过快收紧”的警告、血压的控制视网膜与肾共享获益、血脂、吸烟、以及“抗凝与抗血小板的迷思”（它们不造成出血、而“停掉它们”极少是眼科的诉求——[[cardiovascular/hypertension]]、[[blood/thrombosis-anticoagulation]]、[[renal/filtration]]）；以及升级的触发——需要“全视网膜的光凝或抗内皮生长因子”的新血管、“为视力而不是为分级而治疗”的黄斑的水肿、“为超声与手术的规划”的玻璃体的积血、以及“患者被告知了什么”的记录——好让“我不知道它会导致失明”这个问题在病历里就有答案——[[clinical-skills/records-handover]]。**

::: exercise 查那个“跟脉搏同步的响声” {level=2}
一名45岁报告右侧的、“与脉搏同步的”耳鸣6周；耳的检查正常、也没有听力的丢失。
::: solution
**“客观性的耳鸣”的检查，因为它在被证实之前就是一根血管（[[#def-ear]]）：鉴别——“颈静脉球的瘤”在能看到时“鼓膜后那个红的血管的肿物”、以及副神经节的检查、硬脑膜动静脉的瘘“在同侧的颈动脉压迫时会停止的杂音”、迷走与扩张的血管、“高位颈静脉与缺损的球”颞骨的CT的问题、乙状窦的“室与狭窄”（以及“横窦的狭窄与颅内压”这一接口、甲状腺毒症与贫血的高流量的状态、以及“伴碱性磷酸酶升高的”佩吉特病血流的风声——[[endocrine/thyroid]]、[[blood/anaemia]]、[[musculoskeletal/bones-joints]]）；检查与听——用听诊器的听头“在耳与颈及眶及乳突上听诊”、以及“瓦氏动作与颈的旋转”修饰、以及眼底检查（那个有时藏在“只是耳朵里有响声”背后视盘的水肿——[[clinical-skills/physical-examination]]）；影像的阶梯——“骨缺损”用颞骨的CT、“肿物与骨髓”用增强的磁共振、瘘的问题用“CT或磁共振的血管成像及导管的血管造影”（配那次神经放射的谈话、以及“不该追的偶然发现”的伦理——[[clinical-skills/medical-imaging]]、[[medical-ethics-law/justice-resources]]）；路径的管理——“在影像做完而不是在那里被开出来”之后转诊给耳鼻喉与神经耳科及神经外科；如果一切都是阴性的，套“安心与声音”的方案配上被公开处理的睡眠与焦虑的环路；以及“新发听力的丢失或神经的症状”的那条被记录的危险信号的建议——[[psychiatry/anxiety-disorders]]、[[clinical-skills/records-handover]]。**

::: exercise 解释低视力的转诊 {level=2}
一名77岁的“终末期干性黄斑的变性”双眼只能数指问，她是不是该“干脆不出门了”；她独居、什么都不开、什么都不读。
::: solution
**盲的登记“是一桩服务的交易、不是一份判决”（[[#def-pathway]]、[[public-health/health-systems-economics]]）：登记与权利——“视觉残疾证明的路径”与它打开的东西（低视力的评估与辅具、税务与福利的准入、地方的感官的支持的服务，以及“法律的与功能的定义”的区别（因为数字会吓到患者——[[public-health/screening]]）；低视力服务的内容——放大与“偏心注视的训练”、对比与照明的工程、“如今胜过大多数光学辅具”的智能机的无障碍的工具、有声书与发声的设备的生态、以及那次“能预防下一次跌倒”的职业治疗的家访——[[geriatrics-palliative/falls]]）；眼本身的随访——“用每天的方格表的纪律监测向湿性的转化”、以及“即便在她的基线之下也做抗内皮生长因子的决定”、场“白内障手术将不会有帮助”的诚实的谈话、以及“眼压好而视野仍在丢失”能解释的“青光眼加黄斑的病变”的双重病理——[[#def-eye]]；心理社会的核心——“在法律与道德上有义务做的”抑郁的筛查低视力是一个风险因子、不只是一个不便、社区处方与“社区康复的团队”、关于驾驶与“和孙辈一起的活动”的谈话、以及那个“让只能数指的患者用耳朵重新阅读”的“什么对你要紧”的目标的设定——[[psychiatry/mood-disorders]]、[[geriatrics-palliative/ageing-frailty]]。**

::: exercise 设计眩晕的门诊 {level=3}
你们的服务每年看到600例“头晕”的转诊、其中一半持续超过6个月、大多数被贴上前庭的标签。请以评估、治疗与评估重新设计这条路径。
::: solution
**头晕是一个综合征、不是一个诊断（[[#def-ear]]、[[public-health/health-systems-economics]]）：分类先行的门诊——四个大类的分类（急性持续的、发作自发的、发作位置性的、以及“症状性的直立性/晕前的”驱动有针对性的检查，并强制问出“用药的清单与卧立位的血压”就能回答的问题——在任何“耳石复位”被预约之前；心血管与自主的贡献见[[cardiovascular/circulation-blood-pressure]]与[[physiology/autonomic-nervous-system]]与[[renal/water-sodium]]）；排除的规则——“基于那套床旁三联紧急卒中的标准”、“新发单侧听力的丢失”的路径、对每一例“慢性的头晕”的视盘水肿的检查、以及“跌倒发作与复视”的危险信号与它们的神经影像的触发——[[nervous-system/stroke]]、[[nervous-system/motor-systems]]；治疗的脊柱——把“良阵位置性眩晕复位的手法”作为员工的胜任力配上复发的咨询、由训练有素的物理治疗师交付前庭的康复配居家项目的依从的工程、梅尼埃分层的照护、以及前庭性的偏头痛的方案它的预防与睡眠及饮食的工作；以及那类“持续姿势感知的头晕”的类型——它的治疗是“认知行为加活动加把抑制剂撤下来”、而不是更多的检查，并与精神科在机制（而不是责备上诚实地合作——[[psychiatry/anxiety-disorders]]、[[nervous-system/headache-pain]]）；以及评估——到诊断的时间与“首次就诊就得到诊断的比例”、抑制剂处方的比率、康复的可及性与出席、跌倒与急诊的再来诊、“抽样的而不是人人做的”患者报告结局的工具头晕残障的指数、以及那个“揭示患者是被安心了还是只是被检查了”的再转诊的比率——[[epidemiology-ebm/measuring-disease]]、[[clinical-skills/patient-safety]]。**

## 通向何处

神经系统的检查与它的“定位的语法”在[[nervous-system/motor-systems]]与[[anatomy/neuroanatomy]]；脱髓鞘与视盘的水肿在[[nervous-system/neuroinflammation]]；卒中与视野在[[nervous-system/stroke]]；糖尿病的眼在[[endocrine/diabetes-complications]]；筛查的项目在[[public-health/screening]]；作为儿科与遗传学话题的听觉在[[paediatrics/growth-development]]与[[genetics/mendelian-inheritance]]。

::: history
**眼与耳的医学承载着医学里最古老的器械与最古老的不平等：从古代一直到十八世纪白内障的“打落法”与达维耶的手术的摘出、以及“一层一层地通向现代超声的乳化与晶状体的植入”的进步——它让失明在富裕的国家成了一个可解决的问题——[[surgery/perioperative-care]]；赫尔姆霍茨1851年的眼底镜，“在发明后的一年之内就把活着的视网膜变成了一本可读的书”、并开启了“用相机记录体征”的时代、以及一个世纪之后随之而来的“糖尿病视网膜筛查摄影的时代”；沙眼的控制运动作为第一次“大规模公共卫生的眼的项目”、以及“可避免的失明”道仍然敞开公平的伤口——[[public-health/global-health]]、被忽视的感染见[[infectious-diseases/tropical-infections]]；听力图在“炮舰与喷气机的时代之后的保听觉的听力学”中的军事的起源、以及它创造的赔偿的法律——[[public-health/environmental-occupational]]；梅尼埃1863年对内淋巴积水的描述、以及“在微器械与内淋巴囊及前庭神经的替代方案之前，它为手术的破坏开了一个世纪的许可”；以及良性阵发性位置性眩晕的故事——巴腊尼的“壶腹的物理学”、埃普利的海的复位手法被忽视了五十年，直到实验室的时代为它平反——这是“有效床旁的治疗被习惯所埋葬”的医学里最清楚的例子；以及现代的感官的神经科学的那条弧——从“埋着电极的猫的视觉皮层”到皮质的植入，以及耳蜗的植入的项目它把耳聋从一种感官的命运变成了一条外科的时间线；连接蛋白26的耳聋的基因与新生儿的筛查的辩论见[[genetics/mendelian-inheritance]]。**
:::

::: summary
- 按疼痛、视力与分泌物为红眼分诊，并对那“五个威胁视力的”动手：闭角、角膜炎、“紧急葡萄膜炎的病因”、眼内炎、眼眶的蜂窝织炎。
- 突发而不痛的视力的丧失，在被证实之前是血管的或视网膜的、而且是一桩当日的事；“伴闪光帘幕样视野的丢失”在视网膜说话之前就是脱离。
- 带着视交叉的交叉这一心思，沿通路为视力的丢失定位；视野的缺损就是病灶的肖像，而“不符合解剖的视野”是要被检查的、不是要与之争辩的。
- 遮住任一只眼就消失的复视是眼位的偏斜；一截“急性地痛而瞳孔散大”的动眼神经，在成像之前就是动脉瘤。
- 在治疗之前先用音叉或听力图为听力的丢失分类；“突发感音神经的丢失”是一桩“用激素的急症”，而“跟脉搏同步的耳鸣”在一根血管被否定之前就是血管。
- 急性持续的眩晕在安心之前需要先做那套床旁的三联试验；良阵位置性眩晕值得一记复位的手法，而前庭的抑制剂值得一张停药日期。
:::


## 练习

::: exercise 为急性的眼科事件分类 {level=1}
哪一个是急性的眼科的急症：增殖糖尿病的视网膜病变、新发玻璃体的积血、“数月来的不痛的逐渐的模糊”、还是“突发而固定的散大的瞳孔伴头痛”？
::: solution
**不同速度的急症（[[#def-eye]]、[[#def-pathway]]）：那个“伴固定瞳孔的头痛”是闭角或者是动眼神经的动脉瘤——小时很重要、而且它不是糖尿病特有的；玻璃体的积血是本周内配超声与“按视网膜是否在位决定手术的时机”；增殖的疾病是一桩“以月计的激光加抗内皮生长因子”的问题、而它的急症在于它是沉默的；那层慢的模糊是白内障或黄斑的病——预约它并解释它——[[endocrine/diabetes-complications]]、[[clinical-skills/communication]]。**
:::
:::

::: exercise 描绘视野的缺损 {level=1}
给出以下病灶的部位：双颞侧的偏盲；“伴黄斑的豁免”的右侧同向的偏盲；左上的象限盲；以及“一只眼弓形的缺损伴扩大的盲点”。
::: solution
**病灶的肖像（[[#def-pathway]]）：视交叉经典的是垂体与颅咽管瘤、配上[[endocrine/hypothalamus-pituitary]]的“内分泌与鞍区的影像”的路径；左侧枕叶的梗死大脑后动脉的区域、“豁免来自视觉皮层双重的血供”——[[nervous-system/stroke]]；右侧颞叶的“迈耶的袢”“天上的馅饼”、肿瘤与“海马的手术”的背景——[[nervous-system/epilepsy]]；以及一处“伴盘改变视神经的病变”——视盘的水肿与青光眼及盘的肿胀的鉴别、“配上测压与影像”的核查——[[#def-eye]]、[[nervous-system/neuroinflammation]]。**
:::
:::

::: exercise 处理化学的暴露 {level=2}
一名焊工在工作中把碱溅进了眼睛；就诊时“结膜是牛肉样的、角膜是混浊的”；他冲了“一两分钟”。
::: solution
**碱的烧伤是一桩“看酸碱度的急症”（[[#def-eye]]）：冲洗到中性——先表面麻醉、“用连冲的针或滴注持续冲洗、直到在停止冲洗后30分钟酸碱度仍然正常”、试纸的纪律、以及“翻转眼睑并清扫颗粒”——[[clinical-skills/physical-examination]]、[[emergency-critical-care/acute-assessment]]；分级与收住的决定——“角膜缘的缺血与角膜的透明度的分级”预示着结局；“整夜的收住加滴眼加睫状肌的麻痹加抗生素的保护”的方案、以及“抗坏血酸与柠檬酸盐与胶原”套说法、以及“早期关于羊膜的移植的前段的决定”——“组织修复的逻辑”保持在[[pathology/chronic-inflammation-repair]]；职业的那一半——“眼的防护的失效”与“事故的上报”及职场的评估、以及“另一只眼事故的历史”，它们让这一例比一只眼更大——[[public-health/environmental-occupational]]、[[clinical-skills/records-handover]]；以及随后几周——睑球粘连与睑及结膜的问题、以及那个“威胁着远期结果、并要求一场专科角膜缘重建的谈话”的干细胞缺乏的角膜病——[[musculoskeletal/skin]]。**
:::
:::

::: exercise 处理童年的“胶耳” {level=2}
一名4岁的“像是隔着棉花在听”、打鼾、“并在托儿所有言语方面的担忧”；鼓膜内陷但活动、并可见液平面。
::: solution
**带发育与气道的背景的中耳的积液（[[#def-ear]]、[[paediatrics/growth-development]]）：量化——按年龄适当听力的方法、声导抗的图形、以及那次“把听变成一个可测量的目标”的言语与语言的能力的评估——[[paediatrics/growth-development]]；观察与处理那条线——三个月的自然史（常会自行消退），对“持续伴听力的丢失与言语的影响”（它会把天平推向通气管；而当打鼾与呼吸暂停腺样体的成分存在时，推向“腺样的切除”这个联合的决定——带着“在一个小孩子身上的出血与麻醉”的咨询——[[surgery/anaesthesia-pain]]）；一次“共同流行的”核查——腭裂与唐氏综合征的“咽管的解剖”的背景、以及“托儿所的声音与背景的噪声的声学”，它们让助听器与调频的传声的系统及教室的座位“即便戴了通气管也仍然重要”——[[genetics/chromosomal-disorders]]；公平与后续——与学校的沟通与“听力学复查的节奏”、持续的积液伴凹陷、以及“绝不可被叫做只是胶”的上皮病变的追查、以及那场“助听器对通气管对什么也不做”并与家庭的目标一起被记录的谈话——[[clinical-skills/communication]]、听觉与交流的准入的相邻见[[paediatrics/safeguarding]]。**
:::
:::

::: exercise 决定驾驶的问题 {level=2}
对每一例说出你的处理：（甲） 一位52岁因微血管的病因出现外展的麻痹；（乙） 一位24岁新诊断的癫痫而扫描正常；（丙） 一位70岁卒中后同向的偏盲；（丁） 一位45岁每月两次的梅尼埃的发作。
::: solution
**驾驶适格是一种临床的职责（[[#def-eye]]、[[#def-ear]]、[[nervous-system/stroke]]、[[nervous-system/epilepsy]]、[[medical-ethics-law/professionalism-regulation]]）：（甲）在复视消失且“遮盖的试验正常”之前不得驾驶，并解释“遮盖一只眼开车的那种技巧不会被习惯重新获得”；以及为“货车与客车的驾照”它们的标准更严做职业健康的联络——[[clinical-skills/communication]]；（乙）无发作的期间由驾照的主管机关与辖区规定、“对发作的风险会影响职业”有即时告知的义务、以及“当患者不同意时把建议记录下来”——场必须留在病历里的谈话；（丙）偏盲之后的视野的标准——视野计的标准与“代偿的训练”的细微差别、以及为合适的病例“转诊做实际的驾驶评估”、由职业治疗与视光师分担角色；以及（丁）发作性的失能的规则：私人驾照需要的“无发作的间隔”、以及“在发作还在时就不得申领商业的驾照”、外加那句诚实的咨询：“罕见”与“不可预测”是两回事。四例都一样：职责是建议、记录、并在法律要求的地方告知——绝不用强力去执法——[[clinical-skills/patient-safety]]。**
