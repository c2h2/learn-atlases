一个人说“我的脚麻了”，他给医生的是一条线索，而不是一个诊断。一只脚麻木，可能是腓骨头处的神经受压，可能是椎间盘压迫神经根，可能是脊髓里的肿瘤，也可能是丘脑的一个小卒中。把这些可能性区分开的，是**模式**：身体的哪些部位受累，丢失的是哪几种感觉，以及还伴有什么。感觉通路沿着固定的路线走行，在固定的位置越过中线，因此每一个损伤部位都会留下可以辨认的特征。

本章从感受器到皮质，依次讲述主要的感觉系统：触觉与关节位置觉、痛觉与温度觉、视觉、听觉与平衡觉。对每一个系统都问同样两个问题：通路走在哪里？每一层面的病灶在床旁表现为什么？

## 感受器、纤维与信号的速度

每条感觉通路都始于一个**感受器**，即一种特化的末梢，它把刺激（压力、牵张、热、光、声）转换为膜电位的变化。变化足够大时，一级神经元发放动作电位，信息以一串锋电位的形式传入中枢神经系统。刺激越强，发放频率越高；不同的感受器对刺激的不同特征起反应。

躯体的**一级神经元**胞体位于背根神经节（面部则位于三叉神经节）。它们的纤维在直径和髓鞘化程度上各不相同，这决定了传导的快慢。

| 纤维类别 | 有无髓鞘 | 典型传导速度 | 传递的信息 |
|---|---|---|---|
| Aα（Ia、Ib） | 有，粗 | 70–120 m/s | 肌梭与腱器官的信号 |
| Aβ | 有 | 35–75 m/s | 触觉、振动觉、关节位置觉 |
| Aδ | 薄髓鞘 | 5–30 m/s | 尖锐、定位清楚的痛觉；冷觉 |
| C | 无 | 0.5–2 m/s | 烧灼样、定位不清的痛觉；温觉；痒 |

这些数字是标准生理学教材中的大致范围；重要的是数量级。足趾上的一次触碰在几十毫秒内到达脊髓，而同一足趾的C纤维信号大约需要一秒。这就是为什么踢到脚趾时，先是一阵尖锐的“第一痛”，随后是一阵更钝、范围更广的“第二痛”。

::: definition 感受野与两点辨别觉 {#def-receptive}
感觉神经元的**感受野**是指这样一片皮肤（或视网膜、耳蜗）区域：刺激该区域会改变这个神经元的发放。感受野小而密集，空间分辨率就高。**两点辨别觉**是指两个同时的触碰被感知为两点而不是一点时的最小距离。指尖约为2–5 mm，背部则为数厘米，这反映了感受器的密度及其在皮质中代表区的大小。
:::

在床旁检查中，每类纤维都有简便的检查方法。轻触觉（棉签）和振动觉（128 Hz音叉）检查粗纤维；**本体感觉**即关节位置觉，检查时让受检者闭眼，检查者将手指或足趾的末节向上或向下移动。针刺觉（一次性神经科检查针）和温度觉（凉的音叉）检查细纤维。两组都要查，因为疾病常常有所选择：维生素B12缺乏先累及粗纤维，而早期糖尿病神经病变常先累及细纤维。

::: example 信息要走多久？ {#ex-conduction}
一位高个子男性踩到一枚图钉。从足底到腰段脊髓的距离约1.2 m。传导速度为60 m/s的Aβ触觉信号需要多长时间到达？尖锐的Aδ痛觉（15 m/s）出现后，C纤维痛觉（1 m/s）要再过多久才到达？
::: solution
时间等于距离除以速度。

- Aβ：$t = 1.2 / 60 = 0.020$ s，即20 ms。
- Aδ：$t = 1.2 / 15 = 0.08$ s。
- C：$t = 1.2 / 1 = 1.2$ s。

C纤维信号比Aδ信号晚$1.2 - 0.08 = 1.12$ s到达。他先感到一下尖锐、定位清楚的刺痛，一秒多之后才出现烧灼样的酸痛。同样的算术也解释了为什么脱髓鞘性神经病（使粗纤维传导减慢）可以让振动觉先于针刺觉消失：粗纤维信号的减慢和离散破坏了感知振动所需要的时间精确性。
:::
:::

## 两条上行通路

感觉缺失的临床定位大多建立在一个解剖事实之上：两条主要的躯体感觉通路在不同的层面越过中线。

::: definition 后索–内侧丘系通路 {#def-dcml}
**后索–内侧丘系通路**传导精细触觉、振动觉和本体感觉。粗大的一级纤维进入脊髓后，在后索中**同侧**上行：**薄束**（来自下肢，位于内侧）和**楔束**（来自上肢，在T6以上加入外侧）。它们在延髓下部的薄束核和楔束核换元。二级纤维在此越过中线，作为**内侧丘系**上行至丘脑腹后外侧核（VPL）。三级神经元投射到中央后回的初级躯体感觉皮质。
:::

::: definition 脊髓丘脑通路 {#def-stt}
**脊髓丘脑束**传导痛觉、温度觉和粗触觉。细小的一级纤维进入脊髓后不久即在后角换元。二级纤维在一至两个节段内、于中央管前方的白质前连合交叉，在**对侧**前外侧索中上行至丘脑腹后外侧核，再到皮质。束内纤维呈分层排列：骶部纤维在最外侧，颈部纤维在最内侧。
:::

面部有自己的系统。面部触觉经三叉神经传至脑桥的三叉神经感觉主核；痛觉和温度觉纤维则在**三叉神经脊束**中下行，直到上颈髓才换元。二者随后交叉，加入通往丘脑（腹后内侧核，VPM）的通路。这条下行的脊束解释了为什么延髓外侧卒中可以造成一侧面部和另一侧躯体的痛觉丧失。

::: theorem 交叉点决定缺失的模式 {#thm-crossing}
病灶影响的是在该层面上走行于病灶一侧的通路。后索在延髓交叉，脊髓丘脑纤维在进入后一至两个节段内交叉，因此脊髓的一侧病灶造成病灶以下**同侧**的本体感觉和振动觉丧失，以及病灶以下**对侧**的痛觉和温度觉丧失。在延髓以上，两条通路都位于其所支配躯体的对侧，因此延髓以上的脑干、丘脑或皮质的一侧病灶，造成对侧全部感觉模式的丧失。
:::

::: proof 为什么脊髓病灶会把感觉模式分开
设想右侧T10水平的脊髓半切。来自右下肢的右侧后索纤维在T10正走在右侧后索中，被切断，于是右下肢丧失振动觉和位置觉。右下肢的脊髓丘脑纤维已在T10以下交叉到左侧，因而幸免；但左下肢的纤维在T10以下交叉到右侧前外侧索，此刻正穿过病灶，于是左下肢丧失痛觉和温度觉。皮质脊髓束已在延髓交叉，走在其所支配躯体同侧的侧索中，因此右下肢无力，伴上运动神经元体征。这一组合就是**Brown-Séquard综合征**（脊髓半切综合征）。由于脊髓丘脑纤维要经过一至两个节段才交叉，痛觉缺失的上界比病灶平面略低。
:::

### 感觉缺失的模式

识别模式比每次从基本原理推理更快。常见模式如下：

| 模式 | 典型病因 | 要点 |
|---|---|---|
| 手套–袜套样 | 长度依赖性多发性神经病（糖尿病、酒精、B12缺乏、药物） | 始于足趾；当下肢缺失达到膝部附近时累及指尖；踝反射早期消失 |
| 单一周围神经 | 卡压或损伤（腕部正中神经、肘部尺神经、腓骨头处腓总神经） | 缺失局限于该神经的支配区，伴其所支配肌肉无力 |
| 皮节 | 神经根受压（椎间盘、骨赘）或带状疱疹 | 与某一神经根相符的条带状缺失；疼痛沿其放射；该节段反射可消失 |
| 感觉平面 | 脊髓病灶 | 躯干某一水平面以下感觉缺失，常伴无力和膀胱症状 |
| 分离性、披肩样 | 脊髓中央病灶（脊髓空洞症） | 肩部和上肢痛温觉丧失；触觉和位置觉保留 |
| 仅累及后索 | B12缺乏、脊髓痨、铜缺乏 | 位置觉和振动觉丧失，感觉性共济失调，Romberg征阳性 |
| 偏身感觉缺失 | 丘脑、内囊或皮质 | 一侧全身，包括面部 |
| 面部与躯体交叉 | 延髓外侧 | 一侧面部和对侧躯体痛觉丧失 |

有几个皮节值得熟记，因为它们是其余皮节的锚点：C6拇指，C7中指，C8小指，T4乳头线，T10脐，L4小腿内侧，L5足背和踇趾，S1足外侧缘和足底。完整的皮节图见解剖学课程[[anatomy/neuroanatomy]]。

**Romberg试验**要求受检者双足并拢站立，先睁眼，再闭眼。关节位置觉丧失的人睁眼时依靠视觉保持平衡，闭眼后则摇晃或跌倒。阳性结果提示本体感觉性（感觉性）共济失调。小脑性共济失调的人睁眼时也不稳，因此不能在同样意义上称为“阳性”。

::: warning 出现感觉平面，在被证实不是之前都按急症处理
躯干上出现水平的感觉平面，意味着脊髓受累。若伴有下肢无力、尿潴留或新发背痛，可能是转移癌、硬膜外脓肿或椎间盘造成的脊髓压迫，预后取决于开始治疗时还保留多少功能。由于脊髓丘脑束的分层排列，查体发现的感觉平面常比真实病灶**低**若干节段，因此影像学必须覆盖全脊柱，而不仅是查体所提示的节段。英国指南（NICE NG234，2023年，针对转移性脊髓压迫）要求紧急行全脊柱MRI。伴有危险信号的背痛的总体处理思路见[[musculoskeletal/back-pain]]。
:::

::: example 一位牙医的烧伤双手 {#ex-syrinx}
一位34岁的女牙医发现自己双手被热盘烫伤却没有感觉。一年来，她双手的小肌肉逐渐萎缩。查体：双肩、上臂外侧和前臂外侧的针刺觉和温度觉丧失，呈披肩样分布。全身轻触觉、振动觉和关节位置觉正常。双下肢腱反射轻度活跃，跖反射为伸性。
::: solution
逐一分析各项特征。

1. **分离性感觉缺失。** 痛觉和温度觉丧失，触觉和位置觉保留。这把脊髓丘脑纤维与后索区分开来。
2. **分布。** 缺失覆盖双侧颈部皮节，但不向下延伸到躯干。支配这些皮节的纤维在颈段于中央管前方的白质前连合交叉。以中央管为中心的颈髓病灶恰好在双侧切断这些交叉纤维，同时保留了携带更低节段纤维的长束。
3. **手肌萎缩。** 病灶向C8–T1前角扩展，损害了手内在肌的下运动神经元。
4. **下肢反射活跃。** 对皮质脊髓束的压迫造成病灶以下的上运动神经元体征。

这一模式符合**脊髓空洞症**，即脊髓中央充满液体的空腔，常与Chiari畸形相关。需要做全脊柱和颅颈交界区MRI。无痛性烧伤是典型而危险的后果；在等待神经外科意见期间，应指导她保护双手。
:::
:::

## 作为一种感觉系统的疼痛

疼痛不只是伤害性感受器被激活。国际疼痛研究协会（IASP，2020年）将疼痛定义为一种与实际或潜在的组织损伤相关、或类似于此相关的不愉快的感觉和情绪体验。伤害性信号在每一层面都受到调制：在后角（即“闸门”，粗纤维输入减少细纤维输入的传递），通过来自中脑导水管周围灰质和延髓头端腹内侧区的下行通路，以及通过注意、情绪和预期。

感觉通路本身受损也可引起疼痛。**神经病理性疼痛**源于躯体感觉神经系统的病变或疾病：带状疱疹后神经痛、痛性糖尿病神经病变、三叉神经痛和卒中后中枢性疼痛都是例子。它常被描述为烧灼样、射击样或电击样，查体可发现**痛觉超敏**（通常不引起疼痛的刺激引起疼痛，如衣物接触皮肤）和**痛觉过敏**（疼痛刺激引起过度的疼痛）。慢性疼痛和头痛的治疗见[[nervous-system/headache-pain]]。

## 视觉：从视网膜到皮质

视觉通路是整个神经系统中解剖预测症状的最佳例子。由于纤维一直到枕叶皮质都保持着精确的视野拓扑，视野缺损的形状指向病灶的部位。

::: definition 视觉通路 {#def-visual}
落在**视网膜**上的光由视杆细胞和视锥细胞转换，信号经双极细胞传给**视网膜神经节细胞**，后者的轴突组成**视神经**。在**视交叉**处，来自每侧视网膜鼻侧半（看颞侧视野）的纤维交叉；来自颞侧半的纤维不交叉。因此在视交叉之后，每侧**视束**携带的是双眼对侧半视野的信息。视束到达丘脑的**外侧膝状体**，再由**视辐射**把信号传到距状沟周围的**初级视皮质**。视辐射的下部纤维向前绕经颞叶（**Meyer袢**），携带上方视野；上部纤维经顶叶走行，携带下方视野。
:::

视野缺损可直接推出：

| 部位 | 缺损 | 常见病因 |
|---|---|---|
| 视网膜或视神经 | 仅一眼缺损（视神经炎为中心暗点；缺血性视神经病为水平性缺损） | 视神经炎、缺血、青光眼、压迫 |
| 视交叉 | **双颞侧偏盲** | 垂体腺瘤、颅咽管瘤、脑膜瘤 |
| 视束 | 不一致的同向偏盲 | 肿瘤、脱髓鞘 |
| 颞叶视辐射（Meyer袢） | 对侧**上象限**盲 | 颞叶肿瘤、卒中、颞叶切除术 |
| 顶叶视辐射 | 对侧**下象限**盲 | 卒中、肿瘤 |
| 枕叶皮质 | 一致的同向偏盲，常伴**黄斑回避** | 大脑后动脉卒中 |

“同向”是指双眼丧失的是同一侧半视野。枕叶卒中的黄斑回避常被归因于枕极的双重血供（除大脑后动脉外还有大脑中动脉），但这一解释存在争议。对诊法检查视野快速但不敏感；当结果很重要时（例如涉及驾驶），需要正式的视野计检查。

### 瞳孔

瞳孔受两条相互拮抗的自主神经通路控制，每一条都可以以特征性的方式受损。

- **缩小（副交感）。** 光激活视网膜神经节细胞，其纤维离开视束进入顶盖前核。每侧顶盖前核投射到**双侧**Edinger–Westphal核，因此照射一眼会使双侧瞳孔缩小（直接反射和间接反射）。副交感纤维随**动眼神经（III）**到达睫状神经节和瞳孔括约肌。
- **散大（交感）。** 一条三级神经元链从下丘脑沿脑干下行至上胸髓（T1），出脊髓到颈上神经节，再沿颈动脉上行至瞳孔开大肌和上睑的Müller肌。

::: definition 相对性传入性瞳孔障碍 {#def-rapd}
当一侧视神经（少数情况下为视网膜）传导的光信号少于另一侧时，就存在**相对性传入性瞳孔障碍（RAPD）**。用**交替光照试验**显示：光线迅速在两眼之间来回移动。当光照到患眼时，双侧瞳孔都会轻度**散大**，因为该眼发出的信号比健眼弱。由于传出通路完好，静息时双侧瞳孔等大。RAPD是视神经疾病最客观的床旁体征。
:::

两种经典的传出障碍外观正好相反。**动眼神经麻痹**表现为上睑下垂、眼球静息时处于“下外”位，当位于神经外周的副交感纤维受压时，瞳孔散大且无反应。伴瞳孔受累的痛性动眼神经麻痹，在血管影像证实并非如此之前，都按正在扩大的后交通动脉瘤处理。**Horner综合征**由交感链中断所致，表现为瞳孔缩小、轻度上睑下垂，并视部位不同而有同侧面部无汗。新发的痛性Horner综合征提示颈动脉夹层。

::: example 一只眼前落下帘子 {#ex-visual-loss}
一位74岁的加勒比裔女性说，今天早上她右眼的视力“像百叶窗落下一样变黑了”，至今没有恢复。三周来她有新发头痛、咀嚼时下颌疼痛和双肩酸痛。右眼视力为指数，左眼6/9。右眼RAPD阳性。
::: solution
1. **定位。** 一眼视力丧失伴RAPD，意味着右侧视网膜或视神经的视交叉前病灶。
2. **时间进程。** 突然、无痛、持续的视力丧失提示血管性病因：视网膜中央动脉阻塞或前部缺血性视神经病。
3. **背景。** 在50岁以上的人中，新发头痛、下颌跛行和肩带酸痛强烈指向**巨细胞动脉炎**，这是一种累及中、大动脉的血管炎，可阻塞睫状后动脉或视网膜中央动脉。
4. **处理。** 这是急症，因为另一眼在数日内也有危险。处理遵循当地路径（英国为英国风湿病学会2020年指南）：一旦临床怀疑，立即开始大剂量糖皮质激素，不等待检查结果；检测炎症指标；紧急安排眼科会诊，以及包括颞动脉超声或活检在内的快速血管炎评估。当天开始治疗通常不能恢复已丧失的视力，但能保护另一只眼。

视网膜脱离是“帘子落下”的主要鉴别，通常先有闪光感和飞蚊症；它无痛，需当天眼科评估。瞳孔反应和眼底可以区分二者。
:::
:::

并非所有突发的视觉问题都来自神经。**急性闭角型青光眼**表现为痛性红眼、灯光周围有虹视、瞳孔固定于半散大位、恶心、眼球坚硬如石，需要紧急降眼压治疗。**视乳头水肿**是颅内压增高引起的双侧视盘肿胀，初期视力通常正常；它是需要去发现的体征，而不是症状，一旦发现应紧急行脑影像学检查。视神经炎是伴RAPD的痛性视力丧失，常是多发性硬化的首次事件，见[[nervous-system/neuroinflammation]]。

一位52岁男性头痛已数月。对诊法检查提示他双眼都看不到视野的外侧半。病灶最可能在哪里？
- [ ] 左侧视神经
- [x] 视交叉

## 听觉

声波使鼓膜和听小骨振动，听小骨把空气的阻抗与内耳液体的阻抗相匹配。在**耳蜗**中，基底膜沿其长度调谐：高频在底部，低频在顶部；内毛细胞把基底膜的运动转换为蜗神经中的信号。中枢听觉通路有多处交叉，因此耳蜗核以上的一侧病灶很少造成单侧耳聋。所以，单侧听力下降指向耳或蜗神经。

::: definition 传导性和感音神经性听力下降 {#def-hearing}
**传导性听力下降**是由于某种问题使声音无法到达耳蜗：耵聍、分泌性中耳炎、鼓膜穿孔或耳硬化症。**感音神经性听力下降**是由于耳蜗或蜗神经受损：年龄相关性听力下降（老年性聋）、噪声、耳毒性药物、梅尼埃病、感染或前庭神经鞘瘤。两种音叉试验可将二者区分开。**Rinne试验**中，把512 Hz音叉先置于乳突（骨导），再置于耳旁（气导）；正常时气导更响（“Rinne阳性”）。**Weber试验**中，把音叉置于前额，让受检者说出在哪一侧听到声音。
:::

| | 患耳Rinne试验 | Weber试验 |
|---|---|---|
| 正常 | 气导 > 骨导（阳性） | 居中 |
| 传导性听力下降 | 骨导 > 气导（阴性） | 偏向患耳 |
| 感音神经性听力下降 | 气导 > 骨导（阳性，二者均减弱） | 偏向听力较好的耳 |

有两种表现需要紧急处理。**突发性感音神经性听力下降**（在72小时或更短时间内发生）需要耳鼻喉科当天或次日评估，因为许多指南建议早期使用糖皮质激素治疗。**不对称的感音神经性听力下降或单侧耳鸣**需要做内听道MRI，以寻找前庭神经鞘瘤。

## 平衡与眩晕

前庭系统感知头部运动和位置。每侧内耳的三个**半规管**感知旋转；**椭圆囊和球囊**感知直线加速度和重力。它们的信号传到脑干的前庭神经核和小脑，再从那里传到眼肌。最著名的反射是**前庭眼反射（VOR）**：头转动时，眼球以同样的速度向相反方向转动，使图像在视网膜上保持静止。

**眩晕**是一种运动错觉，通常是旋转感。按时间特征分类很有用：

- **由头位诱发的短暂发作**，持续数秒：**良性阵发性位置性眩晕（BPPV）**，由半规管（通常为后半规管）内脱落的耳石所致。Dix–Hallpike手法可诱发，复位手法（Epley）常可治愈。
- **反复自发发作，持续数分钟至数小时**：前庭性偏头痛；梅尼埃病（伴波动性低频听力下降、耳鸣和耳闷胀感）；以及——这一点很重要——后循环短暂性脑缺血发作。
- **单次持续数天的发作**，即**急性前庭综合征**：持续性眩晕、恶心、眼震和不稳。多数为**前庭神经炎**，但少数是小脑或脑干的**后循环卒中**，二者乍看之下可以完全相同。

::: definition HINTS检查 {#def-hints}
**HINTS**是针对急性前庭综合征且检查时存在眼震者的三部分床旁检查。每一部分都有“周围性”和“中枢性”两种结果。

1. **甩头试验（Head Impulse）。** 检查者在受检者注视检查者鼻子时，迅速把其头部转动约15度。在前庭神经炎中，患侧VOR失效，眼球被带离目标，并出现一次追赶性扫视（试验**异常**，这反而令人放心）。在小脑卒中中VOR完好，因此甩头试验**正常**才是令人担忧的结果。
2. **眼震（Nystagmus）。** 周围性眼震无论向哪个方向注视都朝一个方向跳动。随注视方向改变方向的眼震，或纯垂直性、纯旋转性眼震，为中枢性。
3. **眼偏斜试验（Test of Skew）。** 交替遮盖双眼；出现垂直方向的矫正运动（**眼偏斜**）为中枢性。

任何中枢性体征，或新出现的听力下降（“HINTS plus”），都应按可能的卒中处理。HINTS不适用于没有眼震者、短暂的位置性眩晕，或已有其他明确神经系统体征者。
:::

HINTS的价值取决于由谁来做。在确立该检查的研究中，经验丰富的神经耳科医生和神经科医生对卒中的灵敏度远高于95%，优于早期MRI——后者在最初48小时内会漏掉一部分小的后循环梗死。2020年的一项系统评价发现，由未经专门培训的急诊科医生执行时，准确性要低得多。下图让你看到这些差异在实践中意味着什么。

::: example 健身后的眩晕 {#ex-hints}
一位61岁男性，有高血压和2型糖尿病，醒来时出现剧烈的旋转性眩晕、呕吐和不能行走。12小时后仍有持续性眩晕。向左看时有向左跳动的眼震，向右看时有向右跳动的眼震。双向甩头试验均正常。无眼偏斜。没有支撑时不能坐起。头颅CT正常。
::: solution
1. **综合征。** 持续数小时的眩晕伴眼震、恶心和不稳，属于急性前庭综合征，因此适用HINTS。
2. **甩头试验。** 正常。若为前庭神经炎，患侧应异常。这是一个中枢性体征。
3. **眼震。** 随注视方向改变方向：第二个中枢性体征。
4. **躯干共济失调。** 无支撑不能坐稳，对前庭神经炎而言过于严重，提示小脑病变。
5. **CT正常。** CT显示早期后颅窝梗死的能力很差，因此不能排除卒中。

结论是可能的小脑或脑干卒中。他需要紧急卒中评估，包括含弥散加权成像的MRI和椎–基底动脉系统的血管影像。小脑梗死在随后几天可能肿胀并压迫第四脑室和脑干，因此应在能获得神经外科支持的卒中单元中监护。血管危险因素提高了验前概率；查体则使之进一步大幅提高。见[[nervous-system/stroke]]。
:::
:::

## 嗅觉与味觉

嗅觉是唯一不先在丘脑中继就到达皮质的感觉。鼻腔顶部的嗅觉受体神经元发出轴突，穿过筛板到达嗅球。嗅觉丧失（**嗅觉缺失**）见于头部外伤（这些轴突被剪切）、上呼吸道感染（包括COVID-19）、鼻息肉和鼻窦疾病。它也是帕金森病和阿尔茨海默病的早期非运动特征，有时在诊断前数年就已出现。舌前三分之二的味觉经面神经的鼓索支传导，舌后三分之一经舌咽神经传导；人们所说的“味道”有很大一部分其实是嗅觉。

::: example 大腿上的一块麻木区 {#ex-meralgia}
一位45岁男性体重增加，并开始佩戴沉重的工具腰带。他描述右大腿前外侧有一块烧灼样麻木区，站立时加重。肌力、反射和其余查体正常。大腿前外侧一椭圆形区域内轻触觉和针刺觉减退，不越过膝部。
::: solution
1. **单纯感觉缺失，无无力或反射改变**，意味着是单纯感觉神经，或仅累及神经根的感觉部分而无运动受累。
2. **分布。** 大腿前外侧、不越过膝部的椭圆形区域，与**股外侧皮神经**的支配区相符，而不是一个皮节：L2或L3神经根病灶会向内侧延伸，L3或L4神经根病灶通常会使膝反射减弱。
3. **机制。** 该神经在髂前上棘附近从腹股沟韧带下方或穿过韧带走行，紧束的腰带、体重增加或妊娠都可在此压迫它。

诊断是**感觉异常性股痛**。它是良性的；处理是解释病情并去除压迫。只有在出现无力、反射改变、进展，或有理由怀疑盆腔肿块时才需要进一步检查。
:::
:::

::: history
查尔斯·贝尔（Charles Bell，1811年）和弗朗索瓦·马让迪（François Magendie，1822年）确立了脊神经后根为感觉性、前根为运动性，首次清楚地把感觉通路和运动通路分开。夏尔-爱德华·布朗-塞卡（Charles-Édouard Brown-Séquard）在19世纪40至50年代描述了在动物和病人中切断半侧脊髓的效应，解释了如今以他命名的交叉性感觉缺失。莫里茨·龙贝格（Moritz Romberg）在19世纪40年代的教科书中描述了脊髓痨患者闭眼站立的试验。1898年，查尔斯·谢灵顿（Charles Sherrington）在猴身上绘制了皮节图；亨利·黑德（Henry Head）与阿尔弗雷德·坎贝尔（Alfred Campbell）对带状疱疹的研究（1900年）帮助绘制了人类的皮节图。罗纳德·梅尔扎克（Ronald Melzack）和帕特里克·沃尔（Patrick Wall）的闸门控制学说（1965年）改变了人们对疼痛的理解；HINTS检查由豪尔赫·卡塔赫（Jorge Kattah）、戴维·纽曼-托克（David Newman-Toker）等人于2009年提出。
:::

与这些感觉传导束并行的运动通路，以及同时检查二者的查体，见[[nervous-system/motor-systems]]。合并感觉和视觉缺失的血管综合征见[[nervous-system/stroke]]，视神经炎见[[nervous-system/neuroinflammation]]。周围神经疾病，包括造成手套–袜套样缺失的多发性神经病，见[[nervous-system/neuromuscular]]。

::: summary
- 感觉纤维在粗细和速度上各不相同：有髓粗纤维快速传导触觉、振动觉和位置觉；细纤维和无髓纤维缓慢传导痛觉和温度觉。
- 后索在同侧上行并在延髓交叉；脊髓丘脑束在进入后一至两个节段内交叉。因此脊髓一侧病灶造成同侧位置觉丧失和对侧痛觉丧失（Brown-Séquard综合征）。
- 模式可以定位：手套–袜套样（多发性神经病）、神经支配区、皮节、感觉平面（脊髓）、披肩样分离性缺失（脊髓中央）、偏身感觉缺失（丘脑或皮质）、面部与躯体交叉（延髓外侧）。
- 感觉平面伴无力或膀胱症状是脊髓急症；应做全脊柱影像。
- 视野缺损沿通路定位：单眼（视神经）、双颞侧（视交叉）、同向（视交叉之后）、上象限（颞叶）、下象限（顶叶）、黄斑回避（枕叶）。
- RAPD是视神经疾病的关键体征。伴瞳孔受累的痛性动眼神经麻痹在被证实之前都按动脉瘤处理；痛性Horner综合征提示颈动脉夹层。
- Rinne和Weber试验区分传导性和感音神经性听力下降；突发或不对称的感音神经性听力下降需要紧急评估。
- 在急性前庭综合征中，甩头试验正常、方向改变的眼震或眼偏斜提示卒中；HINTS的好坏取决于检查者。
:::

::: exercise 音叉试验 {level=2}
一位30岁女性左耳听力逐渐下降。左侧Rinne试验阴性，右侧阳性。Weber试验偏向左侧。(a) 她是哪种类型的听力下降，在哪一侧？(b) 给出两个可能的病因。(c) 如果她患的是左侧前庭神经鞘瘤，结果会有何不同？
::: solution
(a) 左侧传导性听力下降：左侧骨导比气导响，Weber偏向患耳，因为传导阻滞减少了环境噪声的掩蔽。(b) 耵聍、分泌性中耳炎、鼓膜穿孔或耳硬化症（常在青年时出现，妊娠期可加重）。(c) 神经鞘瘤造成感音神经性听力下降：双侧Rinne均为阳性，Weber偏向右侧即听力较好的耳。单侧感音神经性听力下降应行内听道MRI。
:::
:::

::: exercise 脊髓刺伤 {level=2}
一位22岁男性背部被刺伤。他左下肢无力，伴腱反射活跃和跖反射向上，左下肢振动觉和位置觉丧失，右下肢针刺觉和温度觉丧失，上界刚好在脐下。病灶在哪一节段、哪一侧？解释每一项表现。
::: solution
病灶为约T9–T10水平的左侧脊髓半切（脐为T10，脊髓丘脑束的感觉平面比真实病灶低一至两个节段）。左下肢无力伴上运动神经元体征：左侧皮质脊髓侧束（已在延髓交叉）被切断。左侧振动觉和位置觉丧失：左侧后索不交叉地携带来自左下肢的纤维。右侧痛温觉丧失：来自右下肢的纤维在病灶以下交叉到左侧前外侧索，在那里被切断。这就是Brown-Séquard综合征。
:::
:::

::: exercise 周围性还是中枢性眩晕？ {level=2}
一位48岁女性感冒后出现持续性眩晕和呕吐一天。她在所有注视方向都有向右跳动的眼震，头快速向左转时出现追赶性扫视，无眼偏斜，听力正常，能行走但向左偏斜。解释每一项表现，并给出最可能的诊断。
::: solution
持续一天的眩晕伴眼震属于急性前庭综合征，因此适用HINTS。向左甩头试验异常，显示左侧前庭眼反射失效（周围性体征）。朝背离患侧方向跳动的单向眼震（向右跳动）为周围性。无眼偏斜，无新发听力下降。她能行走，向患侧偏斜。所有特征都指向左侧前庭神经炎。处理以支持治疗为主，必要时短期使用止吐药，并尽早进行前庭康复；长期使用前庭抑制剂会延缓中枢代偿。应告诉她如出现新的神经系统症状要及时返回，因为HINTS的表现取决于检查者，没有完美的检查。
:::

::: exercise HINTS的预测值 {level=3 check="83"}
在1,000名急性前庭综合征患者中，有100人为卒中。执行HINTS的检查者灵敏度为83%，特异度为44%。(a) 漏诊多少例卒中？(b) 多少无卒中者得到“中枢性”结果？(c) 100例卒中中被正确识别的百分比是多少？(c) 以整数作答。
::: solution
(a) 漏诊的卒中 = $100 \times (1 - 0.83) = 17$。(b) 假阳性 = $900 \times (1 - 0.44) = 504$。(c) 正确识别 = $100 \times 0.83 = 83$，即83%的卒中（也就是灵敏度本身）。阳性预测值为$83 / (83 + 504) \approx 14\%$：大多数“中枢性”结果是假警报，而仍有17例卒中被漏诊。本题的要点是：一项在专家手中表现良好的检查，在别处可能表现很差；培训以及对仍有疑虑者进行影像学检查都很重要。
:::

::: exercise 足部麻木和跌倒的患者 {level=3}
一位70岁女性服用二甲双胍12年、质子泵抑制剂8年，出现双足麻木、在暗处不稳和两次跌倒。振动觉消失至膝部，足趾关节位置觉丧失。Romberg征阳性。踝反射消失，但膝反射活跃，双侧跖反射为伸性。(a) 哪些病灶的组合可以解释这些体征？(b) 最可能的病因是什么，她为什么有此风险？(c) 概述检查和治疗原则，并解释为什么这是紧急的。
::: solution
(a) 踝反射消失伴感觉缺失提示周围神经病；膝反射活跃和跖反射伸性提示皮质脊髓束受累；振动觉和位置觉丧失伴Romberg征阳性表明后索功能障碍。后索、皮质脊髓束和周围神经同时受累，即**脊髓亚急性联合变性**。(b) 维生素B12缺乏。长期服用二甲双胍和抑酸药都会减少B12吸收；也应考虑恶性贫血。(c) 全血细胞计数（可无大细胞性改变）、血清B12，结果处于临界时测甲基丙二酸或同型半胱氨酸；内因子抗体；叶酸和铜（铜缺乏可造成完全相同的脊髓病）。脊髓MRI可显示后索信号改变。治疗是按现行处方集和当地指南及时肌内注射羟钴胺；若临床表现明确，不必等待所有结果；切忌先单独补充叶酸，因为这可能加重神经损害。神经功能的恢复取决于治疗开始的早晚，因此这是紧急的。预防跌倒和重新评估长期用药使计划完整（见[[geriatrics-palliative/falls]]）。
