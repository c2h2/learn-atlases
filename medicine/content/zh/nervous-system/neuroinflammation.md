神经的炎症是免疫学与大脑相遇的那个分支：**一位“头痛与意识混乱”的患者可能正死于一场用每个病区架子上都有的药就能治好的感染；而一次“精神病的崩溃”可能是用血浆置换就能治好的抗体的脑炎——在两者之中，从怀疑到治疗的那段间隔以小时计，并定义了结局。**本章涵盖脑膜炎与脑炎、多发的硬化与其他的脱髓鞘及自身免疫的综合征，外加“神经的结节病与血管炎”的边界。

## 通向何处

脱髓鞘背后免疫的机制在[[immunology/autoimmunity]]与[[immunology/adaptive-responses]]；视神经的炎与视盘的水肿在[[nervous-system/sensory-systems]]；脊髓的炎的鉴别在[[musculoskeletal/back-pain]]；接种的方案与不良的事件的科学在[[public-health/vaccination-programmes]]；与肿瘤学的接口在[[pathology/cancer-biology]]。

::: history
**炎症的神经病学史是“一系列疾病被从精神病学与从宿命论中拯救出来”的序列：多发硬化的识别——夏科在1868年那“伴眼震与意图的震颤的四联的斑块”与他的患者们的旅程；以及“多重的硬化”作为一个病理奇观的那几个十年，直到二十世纪的“复发缓解临床的身份”、以及“脑脊液的带”、以及随后的“诱发的电位”这一辅助检查的时代——[[nervous-system/sensory-systems]]；1916到1924年的嗜睡脑炎的流行冯·埃科诺米睡眠的疾病，带它的帕金森综合征的后遗症与仍被辩论的感染的触发、以及围绕这个实体是否存在的争执——是第一个现代群体的“先是感染、然后是自身免疫、然后是精神”的谜；感染后脱髓鞘的动物模型摩根与里弗斯的“实验变应性脑脊髓的炎”与弗罗因德的佐剂的年代——它把多发的硬化框成免疫介导的、并“由髓鞘碱性蛋白竞争的实验产出了那一种药”——在同一条弧线上从实验台到病床——[[immunology/adaptive-responses]]；视神经脊髓炎从多发性硬化中被分离出来的这条线——十九世纪末的描述在一个世纪之后“被2004年的水通道蛋白4的抗体平了反、以及2010年代糖蛋白抗体的工作”——那个把一百名被贴错标签多发硬化的患者变成一个可治疗的谱系的抗体时代，以及那条“绝不对视神经脊髓炎用纳他珠单抗”的处方规则；以及2000年代自身免疫脑炎的革命——卵巢的畸胎瘤与受体抗体的聚类把“精神病与癫痫的重症”变成了一个内科的疾病——以及“血浆置换与利妥昔单抗的进入神经科”（[[immunology/autoimmunity]]、[[psychiatry/psychotic-disorders]]、[[pathology/cancer-biology]]）。**
:::

::: summary
- 发热伴颈的僵硬以及任何意识的降低或灶的体征：先培养、给经验性的抗微生物在相关时覆盖李斯特菌、然后影像、然后穿刺——按这个顺序、以分钟计。
- 脑炎的特征意味着“在聚合酶链说话之前用阿昔洛韦”；头三天里阴性的早期单纯疱疹的检查并不能让患者脱嫌。
- 多发的硬化是一桩“临床与放射的、以在时间上与空间上的播散”的诊断；而视神经的炎与纵贯性的脊髓的炎“在贴下长期的标签之前”要求视神经脊髓炎与糖蛋白的抗体的检查。
- 伴运动障碍与自主的紊乱或发作的亚急性的精神的疾病，在被排除之前就是自身免疫的脑炎；治疗的延误要按恢复的月数来付出代价。
- 早期高效改变疾病的治疗、运动、以及对症与康复的医学决定了多发的硬化的患者的这十年，而不是那疗程的激素。
- 免疫检查点的抑制剂与抗胸腺细胞球蛋白及抗CD20的药物会把普通的患者变成“神经炎症的患者”——在第三剂之前就认识综合征。
:::

::: exercise 处理纳他珠单抗的两难 {level=2}
一名34岁因多发的硬化使用纳他珠单抗3年，JC的抗体阳性、指数2.6；她想知道她的“进行性多灶白质的病”的风险；她没有发作，并害怕换药。
::: solution
**风险的数字与个人的价值（[[#def-ms]]）：算术——“抗体的指数与用药的时长及既往的免疫的抑制”的风险的分层高指数超过两年的患者接近百分比的量级，对比低风险的层；“每年与每6个月磁共振的监测”的策略；以及“新的精神的与视觉的及运动的症状”的教育与“尽早来”的信息——“加强磁共振的试验”正是建立在这之上——[[clinical-skills/medical-imaging]]、这一章的进行性的多灶白质的病的符号学。排序的选项——继续并加强监测那“早发现带来更好的结局”的数据，对换药“鞘氨醇受体调节剂的撤除与纳他珠单抗的停用”的反跳的风险、洗脱的窗口；以及替代的药物的适配——富马酸酯或抗CD20或克拉屈滨或口服的选项（各有各的阶梯）；以及那“在观察性的队列中降低了风险、并把谈话从停对换重新框定”的“延长的给药间隔”的策略——[[pharmacology/dosing-principles]]；沟通——绝对的数字、而不是相对的风险；“你的风险现在有多大”的比较；邀请她在下一次访视时带一个人来；以及书面的摘要，因为恐惧会抹掉任何句子的中间三分之一；以及流程——共同的决定被记录、具名的复查、安全网的指示、以及那条“怀疑进行性多灶白质的病”的路径收住、聚合酶链、停药、并考虑血浆置换与免疫的重建（[[clinical-skills/communication]]、[[clinical-skills/patient-safety]]）。**

::: exercise 协调那次脑炎的收住 {level=2}
一名29岁的“很可能的自身免疫的脑炎”在重症中被通气、在用经验性的抗微生物、而抗体在等待中；精神科团队在问“这位患者归谁管”。
::: solution
**一张共用的床、一份病历（[[#def-other]]、[[emergency-critical-care/critical-care]]）：临床的脊柱——抗微生物一直用“到感染的排除真正完成”聚合酶链与培养的时机的逻辑，以及“人类免疫缺陷病毒与旅行及免疫的状态”的检查；同时免疫的治疗按临床的轨迹、而不是按“那张明信片的结果”开始；以及肿瘤的搜寻盆腔与睾丸的影像及“胸腹盆的CT”及重复搜寻的方案被完成——[[infectious-diseases/hiv]]、[[microbiology/laboratory-diagnosis]]；重症的医学——自主的不稳与发作及通气不足的管理；带行为效应的抗发作的选择；抗精神病药的最小化带激越的替代——苯二氮与β的阻滞及右美托咪定这套工具；以及横纹肌溶解与静脉的血栓及营养及眼及管道的常规——配那“只有系列地检查与脑电才能分清”的谵妄对疾病的困惑——[[nervous-system/epilepsy]]、[[pharmacology/adverse-reactions]]；与精神科的那道接口——被商定的表述“伴精神表现内科的疾病、共同的查房或具名的联络的安排；”强制对为内科的治疗做能力评估“的分析；以及第二意见与倡导的通道；以及向家属说出的那句诚实的话——”两个科室在治疗同一颗大脑“；以及之后的路径——降级的康复与”认知的与情绪的“的康复及”回到工作与学习”的那场长期战役（[[geriatrics-palliative/end-of-life-care]]、[[clinical-skills/records-handover]]）。**

::: exercise 设计脑膜炎的服务 {level=3}
为一个“儿童与免疫抑制的人群都很多”的区域设计“中枢的感染”的24小时的路径：抗微生物的政策、诊断、公共卫生、审计。
::: solution
**把小时与角色写下来（[[#def-meningitis]]、[[public-health/communicable-disease-control]]）：院前与分诊的层——“紫癜样的疾病”的救护车的方案（肌注的青霉素，带着那段“不褪色的皮疹”的公众信息的历史）；以及急诊的“进门到抗生素”的目标配那条被硬接线的“腰穿从来不会送药”的规则；以及脓毒性的集束的并行的启动——[[emergency-critical-care/acute-assessment]]、[[infectious-diseases/fever-sepsis]]；微生物的脊柱——同一天的组合、“带抗原的培养”、24小时革兰染色的可及；脑脊液的量的纪律；以及为风险的人群的“结核与隐球菌及李斯特”的加做的路径份“免疫抑制的宿主特有”的组合——弓形虫与巨细胞病毒及进行性的多灶的白质的病及隐球菌及结核的组合——[[microbiology/laboratory-diagnosis]]、[[infectious-diseases/immunocompromised-host]]；影像与操作的规则——明确地定义“谁在腰穿之前要CT”；“在考虑脑炎或脓肿或脓胸时做增强的磁共振”；穿刺的手法与起始的压力的测量的标准化；以及被写进政策的“放射待机反应的时间——[[clinical-skills/medical-imaging]]；以及公共卫生与审计的循环——“对脑膜炎球菌与b型流感的嗜血杆菌及肺炎链球菌的接触者”的立即的报告与化学的预防及疫苗的提供的路径配上那套“让它在凌晨三点也能实现”的“下班后同事的系统”；以及那套审计——“进门到抗生素的中位数、不该穿刺时穿刺了的比率、以及被漏掉的病例的复盘”（[[clinical-skills/patient-safety]]、[[epidemiology-ebm/measuring-disease]]）。**
