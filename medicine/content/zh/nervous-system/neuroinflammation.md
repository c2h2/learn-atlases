脑和脊髓受到血脑屏障的保护，人们曾经认为它们在很大程度上对免疫系统是隐藏的。实际上免疫细胞不断巡查中枢神经系统，当免疫反应出错或病原体突破屏障时，后果可能很严重。神经系统的炎症范围很广，从多发性硬化这种年轻人的终身疾病，到可在数小时内致命的细菌性脑膜炎。

本章介绍多发性硬化及其诊断和治疗、视神经炎和横贯性脊髓炎、视神经脊髓炎谱系疾病和MOG抗体病、自身免疫性脑炎，以及脑和脑膜的感染。英国多发性硬化的处理遵循NICE NG220（2022年），细菌性脑膜炎的处理遵循NICE NG240（2024年）。处理始终遵循当地现行指南。

## 多发性硬化

**多发性硬化（MS）**是一种中枢神经系统的慢性免疫介导性疾病，炎症在脑、视神经和脊髓中造成散在的**脱髓鞘**斑块，伴轴索丢失和胶质增生。它是年轻成人非创伤性神经残疾最常见的原因。英国有超过130,000人患MS。它通常在20至40岁起病，女性受累是男性的二至三倍。

风险反映了基因与环境的共同作用。最强的遗传因素是**HLA-DRB1\*15:01**等位基因；另有200多个变异各自增加少量风险。环境危险因素包括**EB病毒**感染（在2022年一项对美国军人的研究中，EB病毒感染后MS风险上升约32倍，而没有EB病毒感染几乎不发生MS）、维生素D水平低和日照少（离赤道越远MS越常见）、吸烟以及青春期肥胖。

::: proof 炎症如何产生症状，继而造成残疾
在复发期，自身反应性T和B淋巴细胞穿过血脑屏障，在小静脉周围引发炎症反应，招募巨噬细胞剥除轴突上的髓鞘。脱髓鞘的轴突传导减慢或完全不能传导，因为跳跃式传导所需的钠通道集中在郎飞结处，结间膜无法维持动作电位。这解释了复发时的症状。随着炎症消退、钠通道沿脱髓鞘节段重新分布以及部分髓鞘再生，功能得到恢复。部分脱髓鞘的轴突传导的安全系数降低，因此体温小幅升高（运动、热水澡、发热）就可阻断传导，使旧症状暂时重现（**Uhthoff现象**）；颈部脱髓鞘的后索受到牵拉时，可产生沿脊柱向下的电击感（**Lhermitte征**）。多年之后，被困在血脑屏障后的慢性炎症、失去髓鞘的营养支持以及线粒体衰竭会导致轴突变性。轴索丢失而非脱髓鞘，是永久性残疾和进展性病程的主要基础。
:::

### 临床病程与表现

大多数人（约85%）以**复发–缓解型MS**起病：新的或加重的症状发作（**复发**）在数天内形成，在无发热或感染的情况下持续至少24小时，然后在数周至数月内好转。许多人之后进入**继发进展型**阶段，残疾逐渐加重，伴或不伴复发。约10%–15%为**原发进展型MS**，从起病即残疾稳步加重，常在中年表现为痉挛性截瘫。首次脱髓鞘发作称为**临床孤立综合征**。

典型的首发表现有：

- **视神经炎**：一眼视力在数天内亚急性下降，伴眼球转动痛、色觉减退和相对性传入性瞳孔障碍（见下文）。
- **部分性脊髓炎**：从双足向上或在躯干呈束带样的麻木或麻刺感、Lhermitte征、下肢无力或尿急。
- **脑干综合征**：复视，尤其是**核间性眼肌麻痹**（侧视时内收眼不能内收，外展眼出现眼震，由内侧纵束病灶引起）；眩晕；面部麻木；年轻人的三叉神经痛。

疲劳、认知困难、抑郁、膀胱和肠道问题、性功能障碍、疼痛和痉挛在病程确立后很常见，对患者而言往往比可见的残疾更重要。

### 诊断

::: definition 空间多发性与时间多发性 {#def-dis-dit}
诊断MS需要证明疾病累及中枢神经系统不止一处（**空间多发性**），且病程持续而非单次事件（**时间多发性**），同时排除更好的解释。**McDonald标准**规定了MRI和脑脊液如何提供这些证据。

- **空间多发性**：在至少两个特征性区域出现典型病灶：脑室旁、皮质或近皮质、幕下、脊髓，以及自2024年修订版（2025年发表）起的**视神经**。
- **时间多发性**：新的临床发作、随访MRI出现新病灶，或同时存在强化（活动性）和非强化病灶。在2017年标准中，**脑脊液特异性寡克隆带**可替代时间多发性；2024年修订版还接受升高的**κ游离轻链指数**，并在某些情况下，若五个区域中至少四个有病灶，可在无时间多发性时作出诊断。

2024年修订版还使用能提高特异性的支持性MRI标志——**中央静脉征**（一条静脉穿过病灶中央）和**顺磁性边缘病灶**——并把同一框架应用于进展型病程。
:::

空间和时间多发性并不是全部要求：临床表现必须典型，“没有更好的解释”是必不可少的。许多疾病会在MRI上引起白质病灶，包括小血管病、偏头痛以及其他炎症性疾病（视神经脊髓炎谱系疾病、MOG抗体病、结节病、狼疮、血管炎）、感染和维生素B12缺乏。MS误诊是一个公认的问题，通常源于过度解读非特异性的MRI改变。

::: example 考试前一只眼睛模糊了 {#ex-on}
一位27岁英国白人女研究生，右眼视物模糊三天，转动眼球时疼痛。那只眼睛看颜色“发白”。视力右眼6/24，左眼6/6。右眼相对性传入性瞳孔障碍阳性。视盘外观正常。四年前她有过一个月双足麻刺感，向上一直到腰部，后来自行缓解；她当时没有看医生。
::: solution
1. **定位。** 痛性亚急性单眼视力下降，伴色觉减退、RAPD和视盘正常：**视神经炎**（球后型，所以视盘正常；“病人什么也看不见，医生也什么都看不见”）。
2. **典型还是不典型？** 年轻女性、眼球转动痛、单侧、中度视力下降：典型的脱髓鞘性视神经炎。提示NMOSD、MOG抗体病或其他病因的不典型特征包括：视力丧失非常严重、双侧同时受累、无疼痛、视盘明显水肿、三周内未开始好转，以及年龄超过50岁。
3. **既往发作。** 四年前上升至腰部的麻刺感提示曾有一次部分性脊髓炎：这是神经系统另一部位的第二次、更早的事件。
4. **检查。** 增强脑MRI（以及眼眶，通常还有脊髓）。典型部位的病灶可显示空间多发性，而在不同部位两次独立发作的病史已在临床上确立了时间多发性。血液检查排除类似疾病；如有任何不典型特征，检测水通道蛋白4和MOG抗体；若诊断仍不确定，查脑脊液寡克隆带。
5. **治疗原则。** 视神经炎治疗试验（1992年）表明，大剂量静脉甲泼尼龙可加快恢复，但不改变最终视力，因此对典型视神经炎，激素是可选的。大多数人在数周至数月内恢复良好视力。若确诊MS，转诊至MS团队讨论疾病修正治疗。她的考试仍可在作出调整后进行。

### MS的治疗

治疗有三部分。

**复发。** 并非每次复发都需要治疗。当复发致残时，短程大剂量糖皮质激素（按当地指南口服或静脉甲泼尼龙）可加快恢复，但不改变远期结局。必须先排除感染，尤其是尿路感染，因为感染可引起**假性复发**（发热使旧症状加重）。

**疾病修正治疗（DMT）**可减少复发型病程的复发频率和新的MRI病灶，并减缓残疾的累积。它们通过调节或清除免疫系统的某些部分起作用，按NHS英格兰的采购政策由MS专科服务开具。大致上：

- **中等疗效**药物：β干扰素、醋酸格拉替雷、特立氟胺、富马酸二甲酯；
- **高疗效**药物：那他珠单抗（阻止淋巴细胞进入脑内；有JC病毒所致**进行性多灶性白质脑病**的风险，按JC病毒抗体状态分层）、抗CD20抗体奥瑞珠单抗和奥法木单抗、克拉屈滨、阿仑单抗，以及芬戈莫德等1-磷酸鞘氨醇受体调节剂；
- 在部分中心，对高度活动性疾病行**自体造血干细胞移植**。

目前的趋势是更早使用高疗效治疗。在进展型病程中选择更有限：奥瑞珠单抗用于有活动性特征的早期原发进展型MS，西尼莫德用于活动性继发进展型MS。开始治疗前要讨论每种药物的致畸性以及在妊娠和哺乳期的安全性。

**症状管理和康复**在每个阶段都很重要：物理治疗和抗痉挛药物（巴氯芬、加巴喷丁、替扎尼定，局灶性痉挛用肉毒毒素）、膀胱管理（抗毒蕈碱药、间歇性自我导尿）、疲劳的治疗（能量管理、运动、认知行为疗法），以及对情绪、认知、就业和性健康的支持。NICE NG220建议有指导的运动，并仅在缺乏时补充维生素D，而不是把它作为MS的治疗。

::: example 解读一项试验结果 {#ex-arr}
在一项复发–缓解型MS新DMT的试验中，两年内对照组的**年化复发率**（总复发次数除以总随访人年）为0.50，治疗组为0.30。复发率的相对降低是多少？这对典型患者意味着什么？
::: solution
1. **相对降低**：$(0.50 - 0.30)/0.50 = 0.40$，即相对降低40%。
2. **绝对差值**：$0.50 - 0.30 = 0.20$次复发/人/年，即平均每治疗五个人年可预防一次复发。
3. **解读**：一个原本约每两年复发一次的人，治疗后约每三年零四个月复发一次。复发率只是一个结局指标；试验还测量新的MRI病灶和**确认的残疾进展**，后者对大多数人更重要。决策还取决于患者的疾病活动度、不良反应（包括感染和监测负担）、妊娠计划和个人意愿。见[[epidemiology-ebm/randomised-trials]]。
:::
:::

## 中枢神经系统的其他炎症性疾病

### 横贯性脊髓炎

**横贯性脊髓炎**是脊髓的炎症，在数小时至数天内出现无力、感觉平面和膀胱功能障碍。必须先用紧急MRI排除压迫。病因包括MS（通常为短节段、部分性病灶）、视神经脊髓炎谱系疾病（跨越三个或更多椎体节段的**长节段**病灶）、MOG抗体病、感染（水痘–带状疱疹病毒、HIV、梅毒）、结节病和系统性红斑狼疮。脊髓综合征的处理思路见[[nervous-system/motor-systems]]。

### 视神经脊髓炎谱系疾病与MOG抗体病

::: definition 视神经脊髓炎谱系疾病 {#def-nmosd}
**视神经脊髓炎谱系疾病（NMOSD）**是一种自身免疫性星形胶质细胞病，通常由针对**水通道蛋白4（AQP4）**——星形胶质细胞足突上的水通道——的抗体引起。其核心临床特征（2015年国际共识标准）为视神经炎（常为重度或双侧）、急性脊髓炎（典型为长节段）、**极后区综合征**（不明原因的呃逆或恶心呕吐），以及急性脑干、间脑或大脑综合征。女性远多于男性；与MS相比，它在东亚和非洲血统人群的脱髓鞘疾病中所占比例更大；并与其他自身免疫病相关。
:::

把它与MS区分开很重要，因为NMOSD的发作往往严重且恢复差，因此预防至关重要，而且某些MS药物（β干扰素、那他珠单抗、芬戈莫德）会使NMOSD加重。急性发作用大剂量激素和早期血浆置换治疗。预防选择包括利妥昔单抗和较新的靶向抗体（针对补体C5的依库珠单抗和雷夫利珠单抗、针对CD19的伊奈利珠单抗、针对白介素-6受体的萨特利珠单抗）。

**MOG抗体相关疾病（MOGAD）**由针对髓鞘少突胶质细胞糖蛋白的抗体引起。它是一种既不同于MS也不同于NMOSD的独立疾病，按2023年发表的标准诊断。它在儿童中常见，可表现为**急性播散性脑脊髓炎（ADEM）**，一种单相病程的炎症性疾病，伴脑病和广泛病灶，常在感染后发生。成人典型表现为视神经炎（常为双侧并伴视盘水肿）或脊髓炎。许多人只有一次发作。

### 自身免疫性脑炎

针对神经元表面蛋白的抗体可引起可治疗的脑炎。最著名的是**抗NMDA受体脑炎**，典型地见于年轻女性和儿童：先有精神症状前驱期（焦虑、精神病性症状、行为改变），然后出现癫痫发作、异常运动（尤其是口面部）、意识水平下降和自主神经不稳定。在年轻女性中它与**卵巢畸胎瘤**相关。**抗LGI1脑炎**见于老年人，尤其是男性，表现为记忆丧失、低钠血症和**面–臂肌张力障碍发作**（面部和手臂短暂、刻板的抽动）。诊断依赖于血清和脑脊液抗体检测、MRI、脑电图以及寻找肿瘤。治疗是免疫治疗（激素、静脉免疫球蛋白或血浆置换，必要时随后用利妥昔单抗或环磷酰胺）和切除肿瘤。凡新发精神病性症状伴神经系统特征者，以及HSV检测阴性的疑似病毒性脑炎，都应考虑自身免疫性脑炎。

::: example 并非精神科疾病的精神病性症状 {#ex-nmdar}
一位24岁非洲黑人血统女性，既往无精神疾病，因失眠、激越和偏执观念两周被收入精神科病房。三天后她出现一次全面性发作。随后反应性下降，出现重复的咀嚼和做鬼脸样动作，血压波动，并有心率减慢的发作。一位朋友提到她一个月前有过一次类流感样疾病。
::: solution
1. **提示器质性病因的危险信号。** 既往无病史的新发精神病性症状，随后出现癫痫发作、意识水平下降、口面部异常运动和自主神经不稳定。原发性精神疾病无法解释这些特征。
2. **鉴别诊断。** 病毒性脑炎（尤其是HSV）、**抗NMDA受体脑炎**、其他自身免疫性脑炎、若已用抗精神病药则需考虑抗精神病药恶性综合征、药物中毒或戒断，以及代谢性病因。
3. **立即措施。** 转入内科或神经科病房；在排除HSV之前开始静脉阿昔洛韦；脑MRI（抗NMDA受体脑炎时常正常或仅有轻微改变）；腰椎穿刺（常为轻度淋巴细胞增多，有时有寡克隆带）；脑电图（弥漫性慢波，有时有“极端δ刷”图形）；以及在**脑脊液**和血清中检测抗NMDA受体抗体，因为脑脊液检测更灵敏、更特异。
4. **寻找肿瘤。** 盆腔超声或MRI寻找卵巢畸胎瘤。
5. **治疗原则。** 一旦诊断可能，就开始一线免疫治疗（大剂量激素、静脉免疫球蛋白或血浆置换），不必等待数周的确认；切除畸胎瘤；若无改善，使用二线治疗（利妥昔单抗或环磷酰胺）。许多人需要数周的重症监护，但大多数恢复良好，常需数月至数年，早期治疗时尤其如此。抗精神病药要谨慎使用，因为这些患者似乎容易发生严重反应。
:::

## 脑和脑膜的感染

### 细菌性脑膜炎

**细菌性脑膜炎**是由细菌引起的脑膜炎症。在英国成人中，主要病原体是*肺炎链球菌*和*脑膜炎奈瑟菌*；*单核细胞增生李斯特菌*在60岁以上、妊娠期和免疫抑制者中很重要；新生儿则为B群链球菌和*大肠埃希菌*。疫苗接种（Hib、脑膜炎球菌和肺炎球菌疫苗；见[[public-health/vaccination-programmes]]）已彻底改变了其流行病学。

典型特征为发热、头痛、颈强直和精神状态改变，但不到一半的成人具备全部特征，幼儿和老年人常表现为非特异性症状。**脑膜炎球菌病**可引起败血症，伴不褪色的紫癜样皮疹和休克，伴或不伴脑膜炎。

::: theorem 先抗生素，后检查 {#thm-antibiotics}
在疑似细菌性脑膜炎或脑膜炎球菌病中，有效治疗每延误一小时，死亡率和神经损害都会上升。因此应立即给予抗生素，检查不得延误治疗。在英国实践中（NICE NG240，2024年），社区中疑似脑膜炎球菌病者，若不延误转运，在转运前肠外给予苄青霉素；在医院，到达一小时内静脉给予**头孢曲松**（有李斯特菌风险时加用阿莫西林），对疑似或确诊的成人和年长儿童细菌性脑膜炎同时给予**地塞米松**，它可减少听力丧失，在肺炎球菌脑膜炎中还可降低死亡率。若能及时、安全地进行，应行腰椎穿刺，最好在用抗生素之前，但绝不能以延误抗生素为代价；开始抗生素后，血培养和PCR仍有诊断价值。
:::

当有提示颅内压增高或占位性病变的征象时，应推迟腰椎穿刺（先行CT）：意识水平下降或波动（例如GCS低于9分或下降3分及以上）、局灶性神经体征、新发癫痫发作、视乳头水肿或严重免疫抑制。休克、凝血功能障碍或局部皮肤感染时也应推迟。

| 脑脊液表现 | 细菌性 | 病毒性 | 结核性 | 正常 |
|---|---|---|---|---|
| 外观 | 浑浊 | 清亮 | 清亮或微浑，可形成“蛛网样”凝块 | 清亮 |
| 白细胞（/µL） | 数百至数千，以中性粒细胞为主 | 数十至数百，以淋巴细胞为主 | 数十至数百，以淋巴细胞为主 | 少于5 |
| 蛋白 | 升高，常高于1 g/L | 正常或轻度升高 | 明显升高 | 低于约0.45 g/L |
| 脑脊液/血浆葡萄糖比值 | 低（低于约0.4） | 正常（约0.6或以上） | 极低 | 约0.6或以上 |

这些模式有重叠：早期细菌性脑膜炎可以淋巴细胞为主，部分治疗过的细菌性脑膜炎可像病毒性，*李斯特菌*常表现为混合性或淋巴细胞性。革兰染色、培养、PCR（脑膜炎球菌、肺炎球菌、肠道病毒、疱疹病毒）和血培养提供特异性诊断。

::: example 发热伴皮疹的大学生 {#ex-meningitis}
一位18岁大学生被朋友送到急诊科。从早上开始他发热、头痛、呕吐和双腿酸痛。他嗜睡，但对声音有反应（GCS 13分）。心率每分钟128次，血压92/54 mmHg，毛细血管再充盈时间4秒，手脚冰凉。双腿上有几个紫色斑点，用玻璃杯按压不褪色。轻度颈强直。
::: solution
1. **识别。** 年轻成人发热、不褪色皮疹和休克征象（心动过速、低血压、毛细血管再充盈延长、四肢冰冷）：**脑膜炎球菌败血症**，可能合并脑膜炎。下肢酸痛和四肢冰冷是败血症的早期征象。
2. **立即治疗。** 请上级医生；气道和吸氧；建立静脉或骨髓腔通路；采血做血培养和脑膜炎球菌PCR，但不延误抗生素；立即静脉给予**头孢曲松**；液体复苏；尽早请重症监护参与（见[[infectious-diseases/fever-sepsis]]）。
3. **腰椎穿刺？** 现在不做。他处于休克且意识水平下降，因此推迟腰椎穿刺。可通过血PCR和培养确诊。
4. 对不伴脑膜炎的脑膜炎球菌败血症，**地塞米松**不常规使用，但对疑似细菌性脑膜炎要使用；由上级医生判断并依据当地方案决定。
5. **公共卫生。** 脑膜炎球菌病是法定报告传染病。英国卫生安全局为密切接触者（家庭成员和有亲吻接触者）安排抗生素预防，并在适当时安排疫苗接种。
:::
:::

### 病毒性脑炎

**脑炎**是脑实质的炎症。发热和头痛伴行为或意识改变、癫痫发作或局灶体征。在英国，最重要的可治疗病因是**单纯疱疹病毒（HSV）脑炎**，典型地累及颞叶：意识模糊、人格改变、言语障碍、幻嗅或幻味，以及癫痫发作。不治疗时死亡率约70%。

原则是一旦怀疑病毒性脑炎，立即开始**静脉阿昔洛韦**，不等待结果。MRI显示颞叶信号改变；脑脊液典型表现为淋巴细胞增多伴蛋白升高，有时有红细胞；脑脊液**HSV PCR**可确诊。其他病因包括水痘–带状疱疹病毒、肠道病毒、HIV，以及旅行者中的虫媒病毒，如日本脑炎病毒和西尼罗病毒。HIV感染者和其他免疫抑制者易发生机会性感染，如隐球菌性脑膜炎、弓形虫病和PML（见[[infectious-diseases/immunocompromised-host]]）。

::: warning 不要等扫描或腰穿
中枢神经系统感染中最常见的严重错误，是在等待CT或腰椎穿刺时延误抗生素，以及因为表现看起来“像精神科问题”或“只是谵妄”而未给意识模糊的发热者开始阿昔洛韦。先治疗，在安全时尽快检查。开始抗生素或阿昔洛韦后数小时至数天内，培养和PCR仍有用；若发现了其他诊断，随时可以停药。
:::

::: history
1868年，巴黎萨尔佩特里耶医院的让-马丁·沙可（Jean-Martin Charcot）从临床和病理两方面描述了“斑块性硬化”，包括眼震、意向性震颤和吟诗样语言三联征。1916年，爱丁堡的詹姆斯·道森（James Dawson）描述了MS斑块的静脉周围炎症（“道森手指”）。德维克（Devic）和他的学生戈尔（Gault）于1894年描述了视神经脊髓炎；万达·伦农（Vanda Lennon）、布赖恩·温申克（Brian Weinshenker）等人于2004年发现了NMO抗体，并于2005年确定其靶点为水通道蛋白4。加斯帕尔·维厄瑟（Gaspard Vieusseux）于1805年在日内瓦描述了流行性脑膜炎球菌脑膜炎，安东·魏克塞尔鲍姆（Anton Weichselbaum）于1887年鉴定出脑膜炎球菌。β-1b干扰素于1993年成为第一种MS疾病修正治疗药物，约瑟普·达尔毛（Josep Dalmau）等人于2007年描述了抗NMDA受体脑炎。
:::

## 后续内容

周围神经的炎症，包括吉兰–巴雷综合征和慢性炎性脱髓鞘性多发性神经病，见[[nervous-system/neuromuscular]]。视神经炎所累及的视觉通路见[[nervous-system/sensory-systems]]。自身免疫的免疫学见[[immunology/autoimmunity]]，脓毒症见[[infectious-diseases/fever-sepsis]]，HIV相关神经系统疾病见[[infectious-diseases/hiv]]。

::: summary
- MS是一种年轻成人的免疫介导性脱髓鞘疾病，女性多见；危险因素包括HLA-DRB1\*15:01、EB病毒、维生素D水平低和吸烟。残疾主要源于轴索丢失。
- 大多数人以复发–缓解型起病；约10%–15%为原发进展型MS。典型表现：视神经炎、部分性脊髓炎、核间性眼肌麻痹等脑干综合征。
- 诊断需要空间和时间多发性且无更好的解释。2024年McDonald修订版把视神经列为第五个区域，并在寡克隆带之外接受κ游离轻链指数。
- 激素缩短复发而不改变远期结局；疾病修正治疗减少复发和新病灶；症状管理和康复必不可少。
- NMOSD（水通道蛋白4抗体）引起重度视神经炎、长节段脊髓炎和极后区综合征；某些MS药物会使其加重。MOGAD是一种独立疾病，儿童中常表现为ADEM。
- 自身免疫性脑炎（如抗NMDA受体脑炎）可以治疗；新发精神病性症状伴神经体征时要考虑。
- 细菌性脑膜炎：立即给予抗生素（头孢曲松，有李斯特菌风险时加阿莫西林）和地塞米松；不要为影像或腰椎穿刺延误治疗。
- 脑脊液模式：细菌性（中性粒细胞、葡萄糖比值低、蛋白高）、病毒性（淋巴细胞、葡萄糖正常）、结核性（淋巴细胞、葡萄糖极低、蛋白极高）。
- 疑似脑炎：立即开始静脉阿昔洛韦；脑脊液HSV PCR确诊。
:::

## 习题

::: exercise 脑脊液葡萄糖比值 {level=1 check="0.24"}
一位疑似脑膜炎的女性，同时测得脑脊液葡萄糖1.8 mmol/L，血浆葡萄糖7.5 mmol/L。脑脊液/血浆葡萄糖比值是多少？给出精确的小数。
::: solution
$1.8 / 7.5 = 0.24$。这远低于约0.6的正常比值，支持细菌性（或结核性、真菌性）脑膜炎，而非病毒性脑膜炎。
:::
:::

::: exercise 解读脑脊液 {level=1}
把下列脑脊液结果与最可能的诊断配对：(a) 白细胞2,400/µL（90%中性粒细胞），蛋白2.1 g/L，葡萄糖比值0.2；(b) 白细胞180/µL（95%淋巴细胞），蛋白0.6 g/L，葡萄糖比值0.65；(c) 白细胞250/µL（淋巴细胞），蛋白3.5 g/L，葡萄糖比值0.15，发热和体重下降两周；(d) 白细胞2/µL，蛋白0.35 g/L，葡萄糖比值0.65，脑脊液中有寡克隆带而血清中没有。
::: solution
(a) 细菌性脑膜炎。(b) 病毒性脑膜炎。(c) 结核性脑膜炎（亚急性病程、淋巴细胞、蛋白极高、葡萄糖极低）。(d) 细胞数、蛋白和葡萄糖正常，伴脑脊液特异性寡克隆带：鞘内抗体合成，如多发性硬化。
:::
:::

::: exercise 相对降低 {level=1 check="0.4"}
在一项试验中，安慰剂组年化复发率为0.50，疾病修正治疗组为0.30。复发率的相对降低是多少（以小数表示）？
::: solution
$(0.50 - 0.30)/0.50 = 0.4$，即相对降低40%。
:::
:::

::: exercise 核间性眼肌麻痹 {level=2}
一位31岁男性向右看时复视。向右注视时，他的左眼不能内收越过中线，右眼外展时出现眼震。集合功能保留。病灶在哪里？在他这个年龄最可能的病因是什么？
::: solution
这是左侧**核间性眼肌麻痹**，由左侧内侧纵束病灶引起，该束把右侧展神经核（向右注视）的信号传给左侧动眼神经核（使左眼内收）。集合功能保留说明左侧内直肌及其神经完好。在年轻成人中，尤其是双侧时，最可能的病因是MS的脱髓鞘；在老年人中，小的脑干梗死更可能。
:::
:::

::: exercise 是不是MS？ {level=2}
一位52岁女性有偏头痛和高血压，因头痛做MRI，发现深部和皮质下白质有十几个小的非特异性白质病灶。她没有神经系统症状，查体正常。她的朋友患MS，她担心自己也得了。你会怎么告诉她？
::: solution
MS的诊断是临床诊断，需要在特征性部位（脑室旁、近皮质或皮质、幕下、脊髓、视神经）有典型病灶，且临床表现相符、没有更好的解释。小的深部和皮质下白质病灶在偏头痛患者和有高血压等血管危险因素者中很常见，并随年龄增长而增多。它们本身不是MS的证据。没有症状、也没有典型病灶，她就没有MS。过度解读这类MRI表现是误诊的常见原因。应管理她的血压和血管危险因素。如果病灶的形态和部位具有MS典型特征，可考虑影像学孤立综合征这一术语，并请专科复查。
:::
:::

::: exercise 脑膜炎球菌病后的预防 {level=2}
一位大学生因脑膜炎球菌脑膜炎入院。哪些人需要抗生素预防？由谁安排？为什么要给？
::: solution
对发病前7天内的密切接触者提供预防：同住一户的人（包括宿舍中共用厨房的人），以及有亲密亲吻接触的人。医务人员只有在直接暴露于呼吸道分泌物时（例如未戴口罩进行气道管理）才需要。报告后由英国卫生安全局的卫生防护团队安排，同时向更广泛的接触者提供信息，若菌株可用疫苗预防则安排接种。给予预防是为了清除接触者中的带菌状态（他们患病风险增加），并阻止进一步传播。
:::
:::

::: exercise 意识模糊与发热 {level=3}
一位63岁男性被妻子送来，发热、头痛和行为怪异两天。他一直胡言乱语，并抱怨闻到一股别人闻不到的怪味。在急诊科他出现一次累及左侧面部的局灶性发作。GCS 13分，体温38.6 °C。概述你的即刻处理和检查，并给出理由。
::: solution
表现（发热、行为改变、幻嗅、局灶性发作）提示累及颞叶的脑炎，最可能是**HSV脑炎**。即刻处理：气道、呼吸和循环；控制发作；**立即开始静脉阿昔洛韦**（按处方集根据肾功能调整剂量），并在排除之前给予针对细菌性脑膜炎的经验性抗生素。检查：因有发作和意识水平下降，腰椎穿刺前先行CT（若能及时进行则做MRI）；然后腰椎穿刺查细胞计数、蛋白、葡萄糖、HSV和VZV PCR、肠道病毒PCR和细菌培养；意识仍受损时做脑电图；血培养和HIV检测。若HSV PCR阳性，阿昔洛韦至少使用14天（免疫抑制者更长），部分方案要求复查脑脊液PCR。若阴性而临床表现持续，考虑自身免疫性脑炎（送检抗体），以及少见的早期PCR假阴性，后者可能需要重复腰椎穿刺。
:::
:::

::: exercise 为年轻女性MS患者选择治疗 {level=3}
一位29岁女性一年前被诊断为复发–缓解型MS。这一年里她有两次致残性复发，最近的MRI显示四个新病灶，其中两个强化。她希望在未来两三年内怀孕。讨论影响疾病修正治疗选择的因素。
::: solution
她患有**高度活动性**复发型疾病（频繁的致残性复发和新的强化病灶），支持尽早开始高疗效治疗而不是缓慢升级，因为早期控制炎症与较少的远期残疾相关。妊娠计划是核心：有些药物致畸或需要长时间的洗脱期（特立氟胺需要加速清除；芬戈莫德和其他S1P调节剂应在受孕前很早停药，并有疾病反跳风险）；另一些则较为有利（β干扰素和醋酸格拉替雷必要时可在妊娠期继续使用；抗CD20抗体可在受孕前给药并间隔一段时间；在疾病非常活跃时，那他珠单抗有时会持续使用到妊娠期；阿仑单抗和克拉屈滨以疗程方式给药，在规定的间隔后可以怀孕）。其他因素：JC病毒抗体状态（那他珠单抗的PML风险）、感染风险和疫苗接种状态、监测负担、合并症、她对给药途径和频率的偏好，以及当地的采购规定。妊娠期复发风险下降，分娩后头三个月上升，这影响重新开始治疗的计划。决策由她与MS团队共同作出，并在她的计划改变时重新讨论。
:::
