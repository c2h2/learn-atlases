一切疾病都是细胞的紊乱。当一位患者发热、踝部水肿或肢体无力时，解释体征的事件都发生在单个细胞的内部或表面——而这种异常通常可以追溯到某一具体的区室：一道守不住离子的膜、一个折叠不成的受体、一个无法消化的溶酶体、一个合成不了ATP的线粒体。因此，学习细胞结构并不是需要死记硬背的描述性生物学，而是后续临床推理所依据的那张地图。

一个人体大约有$4 \times 10^{13}$个细胞，可区分为约两百种类型，全部来自同一个受精卵，全部携带同一套基因组。肝细胞之所以不同于神经元，在于它正在读取哪些基因、富含哪些细胞器。本课依次讲解典型动物细胞的各区室、维持它们的分子机器，以及其中一处失效时出现的疾病。

## 细胞作为一组区室

真核细胞与原核细胞最根本的区别只有一项：它被内部膜分隔为若干细胞器，每一处都有其独特的化学环境。线粒体在其内膜两侧维持质子梯度；溶酶体把其水解酶维持在pH 5；细胞核把基因组与胞质内的机械与酶学“交通”隔开。分隔正是调控得以可能的条件。

::: definition 真核细胞 {#def-eukaryote}
**真核细胞**是指细胞质被内部膜分隔为细胞器的细胞，其中包括由双层膜包被、内含线性染色体的细胞核。动物、植物、真菌以及原生生物的细胞均为真核细胞；细菌与古菌则不是。
:::

| 区室 | 主要职责 | 失效时的代表性疾病 |
|---|---|---|
| 细胞核 | 储存基因组、转录、核糖体亚基装配 | Hutchinson–Gilford 早衰症（核纤层蛋白） |
| 粗面内质网 | 分泌性与膜蛋白合成、折叠、N-连接糖基化 | α₁-抗胰蛋白酶缺乏（错误折叠与滞留） |
| 高尔基体 | 糖链加工与分选、甘露糖-6-磷酸标记 | I 细胞病（溶酶体酶标记错误） |
| 线粒体 | 氧化磷酸化、凋亡信号、血红素合成 | MELAS、Leigh 综合征 |
| 溶酶体 | 降解内吞与自噬来源物质 | Tay–Sachs、Gaucher 等贮积病 |

::: theorem 细胞器原理 {#thm-organelle}
单个蛋白的可遗传缺陷可以引起只累及特定组织的疾病，即使该蛋白在每一个细胞中都表达——只要某组织最依赖那项丧失的功能。
:::

::: proof
考虑呼吸链复合体Ⅰ的一个缺陷亚基。每个细胞都继承这一突变，但依赖持续ATP供应的细胞——神经元、骨骼肌与心肌、耳蜗毛细胞——最先失代偿，因为它们的工作负荷使ATP需求与已降低的产出之间的余量最小。能够转向糖酵解的细胞、或增殖缓慢的细胞则能耐受同一缺陷。同样的逻辑可以解释为何原纤维蛋白-1（fibrillin-1）的缺陷（Marfan综合征）主要累及主动脉、晶状体与骨骼：组织承受单位蛋白的机械负荷最大。所以表型取决于*该功能在哪里最为必需*，而非*该基因在哪里表达*。
:::

## 细胞核

细胞核把2米长的DNA收纳于直径约6 µm的球体中，并以染色质形式包装。核由两层脂双分子层包被：**外层核膜**（表面附着核糖体，与内质网相连续）与**内层核膜**，后者内衬由中间丝蛋白——核纤层蛋白（lamin）——构成的网。两者之间为核周隙。

核膜被**核孔**穿孔，核孔是巨大的蛋白复合体：小分子可自由扩散，而大约40–60 kDa以上的物质则需依赖信号导向的转运。 进入细胞核的蛋白质携带**核定位序列**（通常是一段碱性氨基酸），由importin识别；向外运输的货物携带核输出序列，与exportin同行，整个过程由Ran-GTP梯度驱动。

核内，DNA缠绕组蛋白八聚体形成核小体，折叠为染色质，并在分裂细胞中进一步形成染色体。转录活跃区（常染色质）结构松散、易于接近；沉默区（异染色质）高度浓缩，其极端例子是转录失活的第二条X染色体，它在女性间期细胞中表现为**巴尔小体**（Barr body）。**核仁**并不被膜包被：它是核糖体RNA转录与核糖体亚基装配的场所，在大量合成蛋白的细胞中十分显著。

::: warning 巴尔小体并不等于“只有一条X”
正常男性细胞没有巴尔小体；正常女性细胞有一个；Klinefelter综合征（47,XXY）患者有一个，Turner综合征（45,X）患者没有。巴尔小体的数目等于X染色体数目*减去保持活跃的那一条*——因此若不借助其他检测，计数巴尔小体永远无法区分46,XX与45,X/46,XX嵌合。
:::

::: example 核纤层蛋白与早熟衰老 {#ex-lamin}
一名四岁儿童表现为生长停滞、脱发、皮下脂肪消失、眼球突出与关节僵硬；影像显示广泛动脉粥样硬化。*LMNA*的一个点突变产生隐蔽剪接位点，生成截短且持续法尼基化的A型核纤层蛋白（“早衰素”progerin），滞留于核膜。请解释其显性作用机制，以及为何核膜结构的异常会损害整个细胞。
::: solution
早衰素并非单纯失去活性——它毒害核膜，因为突变蛋白仍能与野生型A型核纤层蛋白结合，而残留的法尼基使其锚定在内层膜上。核纤层失去韧性，基因组在机械上变得不稳定，DNA修复以及核周缘正常的基因沉默都随之退化，干细胞池亦被耗尽。各组织细胞均受累，故疾病是全身性的：动脉硬化、脂肪与骨丢失，并在十余岁死于心血管病。此例说明了解结构的价值——该蛋白的职责（支架）预示了支架变硬变黏时哪些组织会垮掉。
:::
:::

## 内质网与高尔基体：蛋白的制造与发运

粗面内质网因其胞质面附着的核糖体而得名。核糖体只合成一类蛋白：将要分泌出去的、将成为膜蛋白的、或送往内膜系统与分泌途径其他区室的蛋白。这一信息就写在蛋白自身之中——N端一段由疏水氨基酸构成的**信号序列**。当该序列自核糖体露出，便被信号识别颗粒（SRP）捕获，翻译暂停，整个复合体对接到内质网上的SRP受体；核糖体转移至转位子，翻译恢复，新生链边合成边穿越膜。此即**共翻译转运**，也是粗面内质网显得“粗糙”的原因。

在内质网腔内，新链被折叠，并借助分子伴侣（包括BiP与calnexin）完成；形成二硫键（这一环境为氧化性，与胞质相反）、在天冬酰胺残基上糖基化，许多蛋白还要装配成亚基。错误折叠的链被滞留；错误折叠负荷过大则触发**未折叠蛋白反应**，其扩大内质网容量、减缓新的翻译，若应激不能解除则启动凋亡。慢性内质网应激被认为参与2型糖尿病的β细胞衰竭及多种神经退行性疾病。

通过质控的蛋白以转运囊泡离开，进入**高尔基体**——一叠扁平池，具有明确顺面（入口）与反面（出口）。蛋白穿越池堆时依次经过按固定顺序排列的酶区室，其糖链被逐步修剪与重建，如同一份以糖为文字写下的到达时间记录。在反面，蛋白被分选：溶酶体水解酶被标记上**甘露糖-6-磷酸**，其余则被送往质膜，或持续送出，或如胰岛素与神经递质那样储存于调节性分泌颗粒中。

::: example 送错房间的标记 {#ex-icell}
一名婴儿有发育迟缓、面容粗陋、腹部膨隆伴肝脾大、角膜混浊与骨骼异常。体外培养成纤维细胞合成正常量的溶酶体酶，却几乎全部分泌至培养液中，而溶酶体内含有未消化物质的包涵体。哪一步出了问题？
::: solution
酶本身正常，转运至高尔基体也正常。缺失的是地址标签：甘露糖-6-磷酸标记的第一个酶——N-乙酰葡糖胺-1-磷酸转移酶缺乏，导致水解酶在反面高尔基不能被识别，遂依默认途径分泌出去。于是每个细胞都在自身未被消化的底物上缓慢“挨饿”，而释放入血的酶使血浆溶酶体酶活性升高——这是一条诊断线索。该病即I细胞病（包涵体贮积型黏脂贮积症Ⅱ型），它经典地证明：把蛋白送进溶酶体靠的是分选信号，而不是酶活性。
:::
:::

## 线粒体

线粒体是细胞的能量转换器，而且在真实意义上也是细胞器的祖先：它们起源于约二十亿年前被原始细胞吞噬的一个α变形杆菌，至今仍保有自己的环状DNA、自己的（类细菌的）核糖体和双层膜，其中折叠的**内膜**——嵴——承载着呼吸链。内共生起源有直接的药理学后果：线粒体核糖体与细菌核糖体相似，因此利奈唑胺与氯霉素可抑制线粒体蛋白合成，长期使用时导致乳酸酸中毒或神经病。

内膜对大多数离子不通透，生命的化学代价在此支付。NADH与FADH₂的氧化经复合体Ⅰ–Ⅳ把质子泵出基质；由此形成的**质子动力势**由复合体Ⅴ（ATP合酶）用于合成ATP，后者经腺苷酸转位子与磷酸根交换进入胞质。细节与数字见[[cell-biochemistry/energy-metabolism]]。此处有两点在结构上重要。其一，基质中含有自身37个基因的基因组，它们全部编码呼吸链组分或线粒体翻译机器；其余一千三百余种线粒体蛋白由核基因编码、自胞质输入，因此表现为普通的孟德尔遗传。其二，线粒体是**线粒体（内源性）凋亡**的不归点：生长因子撤除、DNA损伤或严重应激使Bcl-2家族蛋白使外膜通透性增加，细胞色素c漏入胞质，所形成的凋亡小体激活caspase-9。

由于线粒体几乎只经卵母细胞传递，线粒体DNA变异表现为**母系遗传**：患病母亲可把变异传给其所有子女，而患病父亲则一个都不传。第二个特点是**异质性**——一个细胞含数百个线粒体、数千份mtDNA拷贝，故突变基因组的比例在细胞间差异很大，只有超过某一阈值组织才失代偿。这就是线粒体病表达如此多变的原因，也是患儿的无症状母亲仍可携带低水平突变mtDNA的原因。

::: example 一种跳过父亲的综合征 {#ex-melas}
一名九岁儿童早期发育正常，出现卒中样发作伴偏盲和癫痫，血乳酸升高、身材矮小并有感音神经性耳聋；其母患糖尿病与耳聋，其姨母“患肌病”早逝，而其父完全健康、家族史无异常。问：该患儿的姐姐的子女预期按何种方式遗传？
::: solution
这是线粒体病的图像：多系统受累且集中于高耗能组织，乳酸升高，年龄不符的卒中样发作，并仅沿母系传递。最常见原因是*MT-TL1*中的m.3243A>G变异。姐姐的子女——以及她的儿子的子女，但不包括她的兄弟的子女——面临风险，因为线粒体DNA来自卵母细胞。任一孩子的严重程度取决于异质性水平，而卵子发生过程中该比例会漂移，故不能由母亲本人的轻微症状推断风险。检测血可能误导，因为突变速mtDNA会随年龄从分裂的白细胞中流失；尿沉渣或肌组织能给出更好的估计。
:::
:::

## 溶酶体、蛋白酶体与自噬：清除

大约四分之一的细胞蛋白在一小时内即被更换，清除机器与合成机器同等重要。清除有两条途径，处理的货物不同。

**泛素-蛋白酶体途径**处理短寿命、错误折叠或受调控的胞质与核内蛋白。靶蛋白经E1–E2–E3酶级联被接上一段泛素链，特异性由E3连接酶决定；蛋白酶体是依赖ATP的桶状复合体，把标记的链穿入核心并切成肽段。由于该途径调控周期蛋白、肿瘤抑制蛋白与IκB，蛋白酶体抑制剂在增殖细胞中尤为活跃——骨髓瘤使用硼替佐米正基于此。

**溶酶体**负责来自胞外的内吞物质，以及经自噬送来的胞内细胞器。溶酶体呈酸性（pH约5，由液泡型H⁺-ATPase维持），含约五十种酸性水解酶，并且是密封的；若膜受损，酶在中性胞质pH下活性并不完全，构成一层有限的安全余量。溶酶体功能失效有三种方式：缺少某种酶（五十余种**溶酶体贮积病**，多为常染色体隐性）、酶的标记或转运出错（I细胞病，[[#ex-icell]]）、或底物无法被接触，或生成速度超过降解能力。未消化物质的贮积使细胞膨胀并扰乱其正常功能；脑无法排出贮积的脂类，故最常受累。

**自噬**即溶酶体消化细胞自身成分。双层膜的隔离膜包绕胞质——常常是PINK1与parkin标记的线粒体——形成自噬体，再与溶酶体融合。自噬被饥饿与AMPK上调、被mTOR下调，因而是衰老、感染、肿瘤与神经退行性疾病研究的靶点；在疾病中，错误折叠蛋白聚集物经同一途径被清除（或清除失败）。

::: example 酶替代疗法为何有效 {#ex-gaucher}
一名六岁儿童有贫血、血小板减少、巨脾与壳三糖苷酶升高，白细胞葡萄糖脑苷脂酶活性为正常的8%。输注带磷酸化甘露糖-6-磷酸修饰的重组酶一年后，肝脾明显缩小。为什么注射的酶能到达巨噬细胞溶酶体，而脑却不受影响？
::: solution
重组酶被特意糖基化，使其甘露糖-6-磷酸（或在新制剂中为甘露糖）残基被巨噬细胞表面受体识别，经受体介导的内吞进入细胞并送达溶酶体——正确的地址写在分子上。于是网状内皮系统中贮积的底物被水解，血细胞减少与脏器肿大改善。中枢神经系统得不到帮助，因为注射的蛋白不能通过血脑屏障：这解释了神经病变型为何疗效差，也是研发底物减少疗法与基因治疗的原因。
:::
:::

## 细胞骨架与细胞表面

三大家族丝状结构决定细胞形状并在其内运输物质。

- **微丝（肌动蛋白）**，直径约7 nm，有极性且不断更新；与肌球蛋白马达结合后驱动肌肉收缩、胞质分裂、细胞迁移和上皮的终网。作用于它们的药物多属研究工具（鬼笔环肽结合F-肌动蛋白；细胞松弛素与latruncule破坏之）。
- **中间丝**，直径约10 nm，坚韧而无极性，命名源于其直径介于另两者之间：肌动蛋白与微管之间；不同组织含不同类型，此即上述免疫组化的依据。桥粒与半桥粒把它们锚定于细胞表面与基底膜；抗桥粒钙黏蛋白的自身抗体引起天疱疮这一类大疱病，抗半桥粒Ⅶ型胶原的抗体引起获得性大疱性表皮松解症。
- **微管**，直径约25 nm，是由α/β-微管蛋白组成的中空管，自中心体向外生长，高度动态，并被ATP驱动的马达——**驱动蛋白**（通常向正端，即向外）与**胞质动力蛋白**（向内，朝向中心）——用作轨道。微管构成有丝分裂纺锤体，其动态不稳定性被长春碱类与紫杉类用于肿瘤治疗，其组装则被秋水仙碱抑制（用于痛风）。

**纤毛**值得单独一提。以经典9+2微管二联体排列、并具内、外动力蛋白臂的运动纤毛做协调摆动：清除气道黏液、输送输卵管内的卵子、推动精子。几乎其余所有细胞都有一条不运动的**初级纤毛**，它是hedgehog、WNT与PDGFR信号以及肾小管感测渗透压的“天线”。纤毛结构或功能缺陷导致**纤毛病**：原发性纤毛运动障碍（湿性咳痰、新生儿期呼吸窘迫、约半数病例出现内脏转位等侧位异常——Kartagener综合征——以及生育力下降）、多囊肾病、视网膜营养不良、Bardet–Biedl与Joubert综合征。

细胞-细胞与细胞-基质连接把一群细胞变成组织。**紧密连接**封闭细胞旁通路，并把顶膜与基底侧膜的蛋白隔开，使上皮得以极化；**黏着连接**与**桥粒**提供力学连续（前者连肌动蛋白、依赖钙黏蛋白；后者连中间丝，是天疱疮的靶点）；**缝隙连接**是连接蛋白构成的通道，允许离子与小代谢物在相邻细胞间通过，使心肌与平滑肌合胞体作为一个整体收缩。连接蛋白突变引起某些遗传性耳聋与部分周围神经病。

## 细胞为何微小：表面、体积与扩散

膜是屏障，这一事实限制了细胞的设计。细胞对营养的需求与废物的产生与体积成比例，而供给与排出与表面积成比例。细胞长大时，体积随半径立方增加而表面积只随平方增加，故该比值按$3/r$下降。大细胞发展出各种对策：微绒毛倍增顶膜面积（单个肠绒毛刷状缘在整个小肠约达15 m²），膜内折形成折叠（嵴、肌浆网），骨骼肌中单个肌纤维是含数百核的合胞体，并有致密的横管系统。

::: definition 表面积与体积之比 {#def-sv}
半径为$r$的球形细胞，其表面积与体积之比为
$$
\frac{A}{V} = \frac{4\pi r^{2}}{\tfrac{4}{3}\pi r^{3}} = \frac{3}{r}
$$ {#eq-sv}
:::

距离也限制了扩散能在细胞内做什么。分子扩散距离$x$的平均时间约为

$$
t \approx \frac{x^{2}}{2D},
$$

其中$D$为扩散系数：胞质中小代谢物约为$10\ \mu\text{m}^{2}\,\text{s}^{-1}$，大分子蛋白则不足$1\ \mu\text{m}^{2}\,\text{s}^{-1}$。因此扩散在微米尺度上极其出色，在厘米尺度上毫无用处——这正是厚度超过几百微米的组织必须有循环的原因，也是工程支架与无血管肿瘤核心在中心部位失败的原因。

::: example 细胞能依靠扩散走多远？ {#ex-diffusion}
设$D \approx 10\ \mu\text{m}^{2}\,\text{s}^{-1}$，估算ATP在胞质中扩散5 µm（典型细胞半径）与5 mm（一层薄的组织片）所需时间。
::: solution
由$t = x^{2}/2D$：当$x = 5\ \mu\text{m}$，
$$
t = \frac{(5)^{2}}{2 \times 10} = \frac{25}{20} \approx 1.3\ \text{s}.
$$
当$x = 5\ \text{mm} = 5000\ \mu\text{m}$，
$$
t = \frac{(5000)^{2}}{20} = 1.25 \times 10^{6}\ \text{s} \approx 14\ \text{天}。
$$
距离增大两万倍，时间却增加一百万倍，因为时间与距离的**平方**成正比。限制细胞为微米级的算术，与必须存在毛细血管网的理由是同一个——它也解释了为何患者的肌细胞把线粒体紧贴在消耗其ATP的肌纤维旁。
:::
:::

::: widget plot

x: 0.5, 100

sliders: D=10:0.5:50
labels: t(x)
caption: 胞质内的平均扩散时间$t = x^2/(2D)$，以秒为单位对距离$x$（微米）作图。把滑块拖到大分子蛋白的扩散系数（$D < 1\ \mu\text{m}^2\,\text{s}^{-1}$）处，就会看到扩散超过几微米后如何变得不可用；按同一公式，5 mm 约需两周。
:::

::: warning “能量”并不是静息细胞中线粒体的主要供给物
线粒体确实合成人体约90%的ATP，但它同样重要地作为信号细胞器工作：经解偶联蛋白1在棕色脂肪产热，为血红素与固醇合成提供碳架，缓冲胞质钙，产生作为信号活性氧，并释放细胞色素c启动凋亡。因此“线粒体病”可以表现为卒中样发作、癫痫、心衰、乳酸酸中毒或糖尿病，而不仅仅是乏力——而且静息乳酸正常并不能排除它。
:::

## 细胞损伤可以先可逆，随后不可逆

由于各区室按可预期的顺序失效，细胞损伤的进程也是可预期的——这正是[[pathology/cell-injury]]的主题。短暂缺氧的细胞停止合成ATP，转为无氧糖酵解，乳酸聚积，钠泵减慢：钠与水进入细胞，细胞肿胀，内质网扩张。这是**可逆**性损伤（水变性）。若损伤持续，膜损害与钙内流激活酶，线粒体膜电位永久丧失，细胞便越过无法返回之点；随后发生坏死，内容物释放并引起炎症。膜完整性的丧失——而非ATP耗竭——才是不可逆的时刻。

细胞也有一条程序性死亡通路。**凋亡**时细胞皱缩，膜出泡但保持完整，DNA被切割成片段，磷脂酰丝氨酸翻转到质膜外层——这是一个“吃掉我”信号，被巨噬细胞识别，从而在不引起炎症的情况下清除遗体。这就是为什么凋亡不升高C反应蛋白而坏死会，也是二者在显微镜下截然不同的原因。

::: history
罗伯特·胡克1665年在软木中看到小室并称之为细胞；十年之后列文虎克看到了活细胞。1838–39年施莱登与施万提出所有动植物皆由细胞构成，1855年菲尔绍总结了其结论——*omnis cellula e cellula*，细胞来自细胞。化学追随形态的脚步很慢：酶在二十世纪初被纯化，离心技术使细胞器成为生物化学的真实对象（Christian de Duve于1955年分离出溶酶体），电子显微镜揭示了膜、核糖体与纤毛。Lynn Margulis在1960年代主张线粒体与叶绿体是被驯化的细菌，一度饱受讥笑；它们的DNA序列最终定谳。分子时代——把一种疾病追溯到单个分选错误的蛋白——始于1975年Günter Blobel与David Dobberstein提出的信号假说。
:::

## 通向何处

膜及其上的离子梯度在[[cell-biochemistry/membranes-transport]]中讨论；蛋白折叠、酶动力学与抑制在[[cell-biochemistry/proteins-enzymes]]；ATP的生成在[[cell-biochemistry/energy-metabolism]]。决定细胞读取哪些基因的机器见[[cell-biochemistry/gene-expression]]，决定细胞是否分裂的机器见[[cell-biochemistry/signalling-cell-cycle]]。当清除与容量控制在整个器官层面出错，你会在[[pathology/cell-injury]]中读到它。

::: summary
- 真核细胞以膜包被的区室为特征；每一区室维持自身的pH、离子或氧化还原环境，正是这种分隔使精确调控成为可能。
- 蛋白的目的地写在它自身之中：信号序列、核定位序列与甘露糖-6-磷酸都是被机器读取的地址，地址或读取者出错即致病。
- 内质网负责折叠与糖基化；慢性错误折叠引起内质网应激与未折叠蛋白反应，可保护亦可致死。
- 线粒体转换能量、调控凋亡、拥有自身基因组且母系遗传；异质性与阈值解释了线粒体病的多变。
- 两套清除系统：泛素-蛋白酶体处理被标记的短寿命蛋白，溶酶体（连同自噬）处理成批的胞内成分与经内吞进入的胞外物质；其失效导致贮积病。
- 细胞骨架分三大家；中间丝可判断肿瘤来源，微管驱动分裂与运输，肌动蛋白驱动形态与运动，纤毛是信号天线，其缺陷即纤毛病。
- 表面积限制体积：$A/V = 3/r$，且扩散时间随距离平方增长，故细胞微小而厚组织需要毛细血管。
:::

::: exercise 区室配对 {level=1}
指出下列过程各在何区室进行：(a) 氧化磷酸化；(b) 加上甘露糖-6-磷酸的溶酶体标记；(c) 泛素依赖性降解；(d) 核糖体亚基合成；(e) 极长链脂肪酸的β氧化。
::: solution
(a) 线粒体内膜（脱氢酶在基质）。(b) 反面高尔基网络。(c) 蛋白酶体，位于胞质与核。(d) 核仁。(e) 过氧化物酶体——注意*多数*脂肪酸的β氧化在线粒体，但极长链与支链脂肪酸必须由过氧化物酶体处理，这就是过氧化物酶体疾病时脂质蓄积的原因。
:::

::: exercise 哪条途径？ {level=1}
判断下列蛋白主要经蛋白酶体还是溶酶体降解：(a) 有丝分裂末期的周期蛋白；(b) 摄取后的胞外脂蛋白；(c) 滞留在内质网的错误折叠囊性纤维化跨膜电导调节子；(d) 受损后的整个线粒体。
::: solution
(a) 蛋白酶体——由后期促进复合体泛素化触发。(b) 溶酶体，经受体介导内吞后。(c) 经逆向转位回到胞质后由蛋白酶体处理（内质网相关降解）。(d) 溶酶体，经选择性自噬（线粒体自噬）。注意c)同时使用两个区室，两者之间的转位步骤正是其可调控之处。
:::

::: exercise 表面与供给 {level=1 check=“0.2”}
一半径$15\ \mu\text{m}$的球形细胞。用[[#eq-sv]]计算其表面积与体积之比，单位为$\mu\text{m}^{-1}$。
::: solution
$A/V = 3/r = 3/15 = 0.2\ \mu\text{m}^{-1}$。若半径增至$30\ \mu\text{m}$，该比值减半至$0.1\ \mu\text{m}^{-1}$，即单位体积只拥有原来一半的膜可供养自身。
:::

::: exercise Importin {level=2}
向细胞内显微注射化学纯的10 kDa蛋白，以及另注射一个含核定位序列的120 kDa融合蛋白。预测两者的分布并解释结果。
::: solution
10 kDa蛋白经核孔自由扩散，在胞质与核质之间达到平衡，故两者皆可测得。120 kDa融合蛋白不能有效扩散，但其核定位序列被importin结合，复合体借助Ran-GTP梯度主动转运，于是在核内浓度高于胞质。该实验同时说明两点：核孔是一个按大小选择的扩散屏障；此屏障可被信号导向的主动转运绕过——两者可以分开证明。
:::
:::

::: exercise 信号序列的逻辑 {level=2}
缺失一种分泌性水解酶N端20个疏水残基，其余序列完全正常。预测该截短蛋白在肝细胞内的去向，并与缺失己糖激酶（一种胞质酶）的信号肽的结果相比较。
::: solution
该水解酶失去进入内质网的门票：其核糖体不再被靶向转位子，因而由游离核糖体完成合成而留在胞质，既未被糖基化，也不被分泌，且很可能被降解。对照很重要：己糖激酶本无信号肽，也无需信号肽，因为它在胞质中发挥作用。这一对比证明信号肽携带的是关于*目的地*的信息，而非关于催化活性的信息——这正是信号假说的核心。
:::
:::

::: exercise 异质性 {level=2}
一名女性对某mtDNA变异为异质性，血液突变负荷30%。其四个子女中两人的负荷分别为5%与78%。解释这种分散，并说明为何在成人中血液可能是错误的检测组织。
::: solution
卵子发生过程中，卵母细胞所获得的线粒体是在线粒体数目先减少再扩增的阶段中取样形成的，故突变比例在细胞间大幅漂移（瓶颈效应）；每个孩子实际上抽取的是相互独立的样本，因此负荷范围及其疾病谱都很宽。血液对许多mtDNA变异并不可靠，因为高负荷的白细胞在生长中被负向选择，血中负荷随年龄下降，而终末分化组织（肌、脑）仍保留。疑诊疾病时以尿沉渣或肌肉为佳，血检阴性不能排除该变异。
:::

::: exercise 纤毛综合征 {level=3}
一名14岁患者有支气管扩张、自婴儿期起的慢性中耳炎与内脏转位，门诊测得鼻呼出气一氧化氮正常。其妹患视网膜营养不良与肾囊肿但无胸部疾病。请给出统一解释，并指出他本人应做的下一步检查。
::: solution
该少年的三联——婴儿期起病的湿咳伴支气管扩张、慢性耳部疾病与侧位异常——几乎可诊断原发性纤毛运动障碍；鼻呼出气一氧化氮降低是良好的筛查指标，但正常结果不能排除，因某些基因型仍保留一氧化氮，且操作技术影响结果。其姐的组合（视网膜营养不良加囊性肾病）指向*初级*纤毛信号缺陷，即Bardet–Biedl或肾单位肾病型纤毛病，故两人并非同一疾病，也不必然同一基因。对该少年应做高速视频显微观察纤毛摆动模式；由于多达三分之一的基因缺陷可表现为摆动频率正常，还应行透射电镜或基因panel检测动力蛋白臂相关基因；实际操作中可用鼻刷取材电镜或活检。
:::

::: exercise 贮积病的推理 {level=3}
一名儿童有进行性神经退行性变、视神经萎缩与眼底樱桃红斑；活检见神经元膨胀，内含膜包被物质，PAS染色阳性。纯化的溶酶体组分别对某合成底物无活性，但总蛋白正常。为何该组分蛋白正常却无活性？并预测葡萄糖神经酰胺合酶抑制剂是否可能获益。
::: solution
溶酶体数量正常、也被正确送达——故障在某一酶的催化活性，而非在靶向。无法水解的底物蓄积，水随之内流，神经元被逐渐“撑满”，此即贮积病的机制（上述描述符合神经节苷脂贮积症如Tay–Sachs）。由于障碍在降解，减少底物的*合成*即可重新平衡两个速率：以葡萄糖神经酰胺合酶抑制剂行底物减少疗法已在某些鞘脂病中确立，正是上述推论所指示的策略。它不能逆转已发生的神经元丢失，故治疗须早，而神经退行型主要以支持治疗为主。
:::
:::

::: exercise 一个定量的细胞器问题 {level=3 check=“84”}
肝细胞富含线粒体。设线粒体为直径1 µm、长3 µm的圆柱体，且嵴使内膜面积较圆柱体表面积为八倍。取$\pi = 3$，估算单个线粒体的内膜面积（µm²）。
::: solution
圆柱表面积（侧面加两端）为$2\pi r h + 2\pi r^{2} = 2(3)(0.5)(3) + 2(3)(0.5)^{2} = 9 + 1.5 = 10.5\ \mu\text{m}^{2}$。八倍放大得$84\ \mu\text{m}^{2}$内膜——足以容纳一个线粒体进行氧化磷酸化所需的数万个呼吸链复合体。以折叠膜的方式在不增加体积的前提下换取表面积，是细胞的通用手法；微绒毛、肺泡与肾小管用的是同一招。
:::
