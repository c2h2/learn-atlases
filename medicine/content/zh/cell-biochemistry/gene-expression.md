一个人体的细胞在任何时刻读取其两万余个蛋白编码基因中的约一万个，靠它所装配的染色质与所含的转录因子决定读哪些，其中许多转录本以不止一种方式被剪接，少数被编辑，按部分写在信使RNA序列中的速率被翻译，并按同样写在其序列中的日程被销毁。这条流水线的几乎每一步都有一种疾病，而其中越来越多步骤已有药物。

本课追随这条信息流：DNA到DNA（复制与修复）、DNA到RNA（转录及其调控）、RNA到蛋白（翻译），以及其间的各层——剪接、编辑、表观遗传标记与非编码RNA——当今最有临床意义的遗传学正发生在这里。

## DNA、染色质与“基因”是什么

DNA是双螺旋，A与T配对、G与C配对，两条链反向平行，序列按5′至3′读取。因两条链互补，每一条都是另一条的模板——此即遗传的物质基础，也是PCR的原理，以及突变只有在复制之后才成为永久改变的原因。

在核内DNA并非裸露。它缠绕于核小体（147 bp绕H2A、H2B、H3与H4组成的八聚体一圈），彼此由连接DNA相隔并结合H1，折叠为更高级结构，并经核纤层蛋白附着于核周。核小体的位置——启动子的一种可遗传性质——决定转录因子能否结合。“开放”染色质，即启动子区无核小体并带活性标记者，为**常染色质**；高度致密、甲基化而转录沉默的DNA为**异染色质**——可见的巴尔小体便是一整条处于该状态的染色体。

一个**基因**是其转录本具有功能的一个位点，而人类转录组的绝大多数都有功能：

- **蛋白编码基因**：被内含子隔断的外显子，含5′与3′非翻译区（远非无关紧要：其上携带调控基序、微小RNA靶位点，而血红蛋白者还有铁反应元件）、含核心元件（如TATA盒与CpG岛）的启动子，以及可位于数百千碱基之外、经染色质环化起作用的增强子。
- **非编码RNA基因**：转运RNA与核糖体RNA、小的核RNA与小核仁RNA、微小RNA、长非编码RNA（如**XIST**）以及环状RNA。
- **假基因**、重复序列，以及绝缘子（CTCF结合位点）等结构元件，其破坏可致病（例如α-珠蛋白基因座）。

::: definition 致病DNA改变的类型 {#def-mutation}
**点替换**：错义（氨基酸改变）、无义（产生终止密码子）、同义（无改变）、剪接位点（GT–AG共识二核苷酸及分支点），以及非翻译区改变。**小片段插入或缺失**：非3的倍数则为移码；整码子缺失为框内（如ΔF508）。**拷贝数与结构改变**：缺失、重复、倒位、易位，以及其形成的融合基因（BCR-ABL1、PML-RARA、EWSR1-FLI1）。**重复序列扩增**：三核苷酸与四核苷酸重复不稳定，并伴代际提前（anticipation）。**表观遗传改变**：甲基化或印记异常而序列正常。
:::

::: warning 一份基因报告不是诊断
实验室报告说明在所测区域发现了什么，而每个变异依人群频率、计算预测、功能数据与共分离而被分级——“意义未明变异”意味着实验室尚不能判断。临床问题是另一个：这一改变能否解释*这个*表型、在这一遗传方式、这一家族史之下？行动之前请核对：(i) 该基因及其机制是否与疾病相符；(ii) 隐性疾病中第二个等位基因是否已找到；(iii) 该发现是否见于未患病的亲属或对照人群；(iv) 是否需要临床遗传专科意见，以及必要时对其父母或组织进行检测。据未分级变异采取行动——例如据此做出生育决定或不可逆的手术——即为错误；而反向的错误，即因表型不典型而弃置一个发现，也会漏掉约五分之一在外显子组阴性病例经再分析后终获的诊断。
:::

## 复制，以及拷贝的代价

复制是半保留的，自多个起始点开始。解旋酶解开双链，单链结合蛋白予以保护，引发酶合成RNA引物，DNA聚合酶ε与δ延伸（只能5′→3′，故有前导链与不连续的滞后链及冈崎片段）， flap内切酶与连接酶收尾，拓扑异构酶解除前方的超螺旋。端粒酶是一种以自身RNA为模板的逆转录酶，维护每次分裂所损失的端粒末端；其在生殖系与干细胞中活跃，并在多数肿瘤中重新获得。

三个事实保证了忠实性：碱基选择、3′→5′外切酶的校正阅读，以及复制后的修复。尽管如此，每复制约$10^{8}$个碱基即出现一个新的核苷酸改变，故人人携带数十个新变异；突变、修复与克隆选择之间的平衡即肿瘤遗传学的内容（见[[genetics/cancer-genetics]]）。

| 修复系统 | 修复什么 | 失效时的疾病 | 治疗上的意义 |
|---|---|---|---|
| 直接逆转 | 烷基（MGMT），部分嘧啶二聚体 | MGMT表达者对烷化剂耐药 | 胶质瘤中MGMT启动子甲基化预测烷化剂疗效 |

针对酶的药物是现代医学中使用最多的一类：抗叶酸药（甲氨蝶呤）、氟嘧啶（5-氟尿嘧啶）与胞苷类似物扰乱胸苷酸合成；羟氯脲与阿糖胞苷阻断复制；依托泊苷与伊立替康捕获拓扑异构酶；铂类使DNA交联并依赖细胞的修复失败；博来霉素断裂链。其治疗窗是肿瘤与正常组织在修复能力与分裂速率上的差别——由此即有骨髓、肠道黏膜与毛囊的共同毒性，以及几乎所有此类药物的致畸性。

## 转录，以及“读哪些基因”的调控

RNA聚合酶Ⅱ在通用转录因子帮助下转录mRNA（含TBP的TFIID结合核心启动子，随后为TFIIA、B、E、F、H；最后者具解旋与激酶活性，磷酸化聚合酶C端七肽重复，使其进入延长阶段）。帽子几乎立即加上；3′端poly(A)尾在切割后加上，两者共同决定一条mRNA能存活多久、被翻译多有效。

**剪接**通过识别5′剪接位点（通常为GT）、分支点腺苷、嘧啶富集区与3′剪接位点（AG）移除内含子，由U1、U2、U4/U6与U5小核核糖核蛋白组装并重排成剪接体；内含子以套索形式释出。两个后果在临床上至为关键：

1. **约五分之一至四分之一的致病点突变作用于剪接**——制造新剪接位点、破坏原有位点，或破坏增强子序列（剪接因子本身如SRSF2与U2AF1亦在髓系肿瘤中突变）。β-地中海贫血展示了所有类别，包括常见的IVS-I-110与IVS-II-654内含子变异，以及产生部分正常mRNA的隐蔽位点突变。
2. **选择性剪接是一个调控层，也是一个可成药靶点。**同一基因在不同组织产生不同蛋白；*SMN1*有一个近乎相同的旁系同源基因*SMN2*，二者仅差一个核苷酸，致使*SMN2*约90%的转录本跳过7号外显子。结合*SMN2*前体mRNA并恢复7号外显子并入（inclusion）的反义寡核苷酸（nusinersen，以及口服的risdiplam属同类策略）把*SMN2*变成一只有功能的*SMN1*拷贝，并已改变脊髓性肌萎缩的结局——“剪接病”可以通过编辑剪接来治疗，这是最清楚的证明。

转录受**转录因子**（常见DNA结合模块：锌指、螺旋-环-螺旋与亮氨酸拉链二聚体、核受体结构域）经增强子与环化调控，也受**染色质状态**调控：组蛋白乙酰化通常开放染色质（组蛋白去乙酰化酶抑制剂用于T细胞淋巴瘤），而甲基化标记的意义取决于位置（活性启动子的H3K4me3、Polycomb抑制的H3K27me3、以及稳定沉默的H3K9me3与CpG甲基化）。启动子CpG岛的DNA甲基化是**印记**（见[[genetics/non-mendelian-inheritance]]）、X失活以及发育与肿瘤中稳定基因沉默背后的可遗传标记。

**小RNA**再加一层。微小RNA经Drosha与Dicer加工并载入Argonaute，与靶mRNA的3′非翻译区配对而降低蛋白产出；单一微小RNA可微调数百条mRNA，而一个微小RNA簇的丢失（如13q14上的miR-15/16，在许多慢性淋巴细胞白血病中缺失）或靶位的突变（poly(A)信号与3′非翻译区突变致病）都有真实的表型。合成的**小干扰RNA**利用同一机器：patisiran与vutrisiran分别在肝内沉默转甲状腺素蛋白，前者静脉、后者皮下给药，作用持续数月——这一药物类别直接源自Fire与Mello对RNA干扰的发现。

::: definition 表观遗传的传递 {#def-epigenetic}
**表观遗传**机制在不改变DNA序列的情况下经细胞分裂传递基因活性的模式：CpG甲基化、组蛋白修饰与染色质状态，以及维持它们的非编码RNA——而在生殖系，则有**印记**，即按亲本来源标记某一等位基因，使只有其中一份得以表达。模式在早期发育建立，由DNA甲基转移酶维持，在生殖系被部分擦除并重建，并可因印记中心的缺失、单亲二体、*cis*调控区突变，或机制本身（*DNMT3B*、*MECP2*、*ZBTB24*）的突变而被扰乱。
:::

## 翻译

遗传密码为三联体、不重叠、简并（61个编码密码子对20种氨基酸，多数第三位变异为同义），自AUG起始按5′→3′读取。第三位的摆动配对解释了为何所需的转运RNA少于61种，而密码子偏好与转运RNA丰度影响一条mRNA被翻译的快慢。线粒体密码略有不同，这在解释线粒体变异、以及判断某变异属核基因组抑或线粒体基因组时都很要紧。

起始是受调控的一步：真核起始因子组装43S复合体，40S亚基自5′帽向Kozak序列适宜的AUG扫描，随后60S亚基结合。感应双链RNA、氨基酸饥饿、血红素缺乏与内质网应激的几种激酶磷酸化eIF2α，全面降低起始而使特定mRNA（ATF4）反而被更好地翻译——即整合应激反应。许多病毒完全绕过该控制，或借助内部核糖体进入位点，或关闭宿主的依帽翻译（脊髓灰质炎病毒即通过切割eIF4G实现）。

延长使用eEF1A（携GTP递送氨酰基转运RNA）与eEF2（转位），终止则由释放因子eRF1与eRF2识别终止密码子。临床关联如下：

- **白喉毒素**与**铜绿假单胞菌外毒素A**以ADP-核糖基化使延长因子2失活。
- **氨基糖苷类**结合细菌16S rRNA，引起误读并阻断转位——此即其杀菌之由，也（经相关的线粒体核糖体）是其耳毒性与肾毒性的部分原因；**四环素类**、**大环内酯类**、**氯霉素**、**克林霉素**、**噁唑烷酮类**皆作用于细菌核糖体的特定部位，而细菌核糖体与线粒体核糖体的相似性，是其长期使用后若干不良作用（利奈唑胺与氯霉素所致乳酸酸中毒、神经病与骨髓抑制）的基础。
- **无义突变**在某些*DMD*、*CFTR*等基因型中可被某些氨基糖苷类与ataluren通读（后者对提前终止密码子显示一定选择性），获益温和且因基因型而异——这是一个活跃的研究领域，而非常规治疗。
- **核糖体病**如Diamond-Blackfan贫血显示，核糖体蛋白单倍体不足并不仅是生长问题：它稳定p53并删除特定谱系，这就是表型具组织选择性且有时随年龄改善的原因。

新合成的链在翻译过程中与伴侣蛋白共同折叠，并经信号识别颗粒途径定向（见[[cell-biochemistry/cell-structure]]）；随后由泛素-蛋白酶体与自噬系统决定其半衰期。翻译后修饰——糖基化、磷酸化、肉豆蔻酰化、异戊二烯化、γ-羧化、羟化——完成最终产物，而环节的失效构成一大组先天性糖基化障碍，以及维生素K或C缺乏所致的药物样综合征。

::: example 四位患者，一个基因，四种机制 {#ex-thal}
四位患者的β-珠蛋白生成均减少，均为小细胞贫血伴HbA₂升高。(i) 启动子TATA盒区域一个核苷酸改变；(ii) 内含子1的GT→AT改变；(iii) 第39位密码子G→A造成终止；(iv) 外显子1五个碱基缺失。请预测各例的β-珠蛋白mRNA与蛋白量，并指出哪一例最可能是“中间型”而非“重型”。
::: solution
(i) 启动子突变降低转录效率但不使之消失：仍有部分正常mRNA，故多为β⁺-地中海贫血，常表现为中间型，尤其在仅造成中等程度降低时。(ii) 剪接供位改变导致异常剪接或完全不剪接；未剪接的转录本多被滞留并降解，其表型取决于残存多少正确剪接——常为重型，若剪接“渗漏”则可为中间型。(iii) 无义密码子产生提前终止密码子，转录本被无义介导的降解破坏，故mRNA极少而蛋白无：β⁰（无效），重型。(iv) 移码同样触发无义介导的降解或产生不稳定的截短蛋白，亦为重型。总的原则——提前终止密码子位于最后一个外显子上游者经无义介导的降解被清除，故“无义”与“移码”表现为无效等位基因，而启动子与渗漏型剪接变异产生分级表型——正是β-地中海贫血的基因型比多数单基因病更能预测严重度的原因，也是共遗传的α-地中海贫血、*BCL11A*与*HBS1L-MYB*位点、以及提升胎儿血红蛋白的能力为何如此重要的原因。
:::

::: example 一个男孩、他的母亲，与一位步态不稳的外祖父 {#ex-fmr1}
一名7岁男孩有学习困难、耳廓突出、拍手动作为、巨睾丸与惊厥史。其母健康；其外祖父早年辍学，58岁时出现进行性的小脑性共济失调、帕金森综合征与记忆减退。检测显示男孩*FMR1* 5′非翻译区CGG重复132次，其母78次。请解释，并指出还应对谁进行遗传咨询。
::: solution
该男孩患脆性X综合征。*FMR1*三核苷酸重复特征性地经**母系**传递而扩增：55–200次的中间突变型等位在卵母细胞中不稳定，可达200次以上的全突变，此时启动子甲基化而基因沉默。故该综合征的机制是由DNA改变引起的表观遗传沉默所致的FMRP蛋白缺失，其遗传方式为带亲本偏倚的代际提前（anticipation）。外祖父晚发的共济失调、震颤与认知减退是**脆性X相关震颤/共济失调综合征**，由*中间突变型*通过RNA获得功能并伴核内包涵体所致：重复次数在两端决定相反的机制，55–200次产生过多的毒性转录本，200次以上则一个也不产生。咨询须涵盖该男孩的诊断与处理、其母再生育的风险（取决于其重复数且相当高）与其母自身的原发性卵巢功能不全风险，以及外祖父的诊断作为家族中间突变型的证据与其母同胞的风险。请注意检验学一点：重复引物PCR加甲基化检测可查出此病，而“阴性外显子组”会完全漏掉——这就是不明原因发育迟缓仍应以染色体微阵列与*FMR1*检测并与外显子组测序同查的原因。
:::

::: example 过度生长、核型正常，与肿瘤风险 {#ex-bws}
一名4月龄婴儿有巨舌、脐疝、出生体重高于第97百分位、耳垂皱褶与左侧身体过度生长。甲基化检测示11p15母源印记中心IC2（*KCNQ1OT1*差异甲基化区）甲基化丢失，无单亲二体。请诊断，并说明该分子结果改变了什么。
::: solution
这是Beckwith-Wiedemann综合征谱系，最常见的印记相关过度生长疾病。11p15区域含两个独立印记的亚区；正常情况下IC1在父源等位基因甲基化（调控*IGF2*与*H19*），IC2在母源等位基因甲基化（调控*KCNQ1OT1*与*CDKN1C*）。母源IC2甲基化丢失使母染色体表现得如父源，于是胎儿生长促进格局加倍。分子亚型预测肿瘤风险——IC2甲基化丢失的胚胎性肿瘤风险低于IC1甲基化获得或父源单亲二体，且各亚型需警惕的肿瘤不同——故该结果决定的是监测方案（腹部超声，较高风险组加甲胎蛋白以筛查肝母细胞瘤），而非诊断本身。两个临床细节需早察：胰岛细胞增生所致新生儿低血糖，须以喂养时点血糖监测发现，因为反复低血糖会损害脑；以及心脏与肾脏评估。Silver-Russell综合征是同一位点的镜像病变（IC1甲基化丢失使*IGF2*表达下降），这就是为何一处印记区域既可致生长不足亦可致过度生长，也是为何“印记疾病”是一种机制而非一种疾病。
:::
:::

::: example 编辑患者自己的细胞 {#ex-crispr}
一名16岁重度镰状细胞病患者，在规范服用羟基脲的情况下仍有十一次血管阻塞性疼痛危象与两次急性胸部综合征。她正在接受exagamglogene autotemcel的评估。请说明靶点选择的依据、治疗过程，以及治疗前必须讨论的内容。
::: solution
靶点取自一种人群中的保护性表型：同时遗传了胎儿血红蛋白持续存在症的镰状细胞病患者很少发作，因为胎儿血红蛋白抑制血红蛋白S的聚合。*BCL11A*是出生后关闭胎儿血红蛋白的抑制因子，而本疗法中CRISPR-Cas9切割的正是其红系特异性增强子。患者的自体造血干细胞被动员并采集，在实验室编辑使红系前体重新表达胎儿血红蛋白，随后在白消安清髓预处理后回输；这一校正并非修复基因，而是沉默一个抑制因子，故红细胞中出现一定比例的胎儿血红蛋白即已足够，也不需要筛选特定克隆。必须讨论的内容：清髓的风险（黏膜炎、感染、长期血细胞减少、生育力受损——故首先讨论生育力保存）、移植失败或编辑不充分、疗效持续时间的不确定、脱靶编辑与克隆造血未知的长期风险、等待治疗的时间，以及在此期间继续的标准治疗（羟基脲、输血方案、以及减少危象的较新药物）。值得命名的总体转变是：*体外*编辑把一种遗传病变成一次性的细胞治疗操作，其全部不可逆性亦随之而来，而伦理问题也从生殖系转向了可及性、费用与知情同意。
:::

::: theorem 阈值效应 {#thm-threshold}
就多数酶而言，只有当残余活性降至正常的一小部分以下时才出现临床异常，因为途径的通量被酶的过量所缓冲；这一曲线形状解释了为何隐性酶缺陷的杂合子健康，也为何某些X连锁疾病在女性之间差异如此之大。
:::

::: proof
设一条途径的产出大致与酶活性成正比，直至满足组织的通量需求后进入平台：则活性与表型的关系并非线性而是有阈的，观察到的表型在活性跌破某一临界值后陡升（该临界值取决于组织需求、有无替代途径与底物负荷）。就隐性病而言，一个正常等位基因给出约50%活性，而50%远在该阈值之上，故携带者不受累——但并非总是如此：某些疾病阈值很高，葡萄糖-6-磷酸脱氢酶或卟啉病的携带者在应激下可出现生化甚至临床表现。就女性的X连锁病而言，随机的X失天使组织成为嵌合，其表达细胞的比例决定严重度，而失活的偏倚造成从无症状携带者到患病者的连续谱。体细胞嵌合与突变发生的时点产生类似的分级图像。故同一基因型可以产生范围很广的表型，“该酶还有30%活性，够了吗？”这个问题问的是组织的需求曲线——这正是临床评估所能回答、而单一实验室数值不能回答的。
:::

::: quiz
一名囊性纤维化患者在第11外显子有一个把丝氨酸变为亮氨酸的*CFTR*变异。下列哪条信息最能帮助你判断其是否致病？
- [ ] 它改变了氨基酸，所以必然要紧。
- [x] 该残基在物种间是否保守、人群频率如何、蛋白是否被合成并转运、以及它是否在家系中与疾病共分离。
- [ ] 其父母是否近亲。
- [ ] 胸部病变是否严重，因为囊性纤维化的基因型总能预测表型。
::: solution
错义不等于致病：一个基因中新出现的错义变异多数是良性的。分级需看频率（在人群中常见的变异不可能导致罕见隐性病）、保守性与结构背景、计算预测（弱证据）、功能实验（如氯电导或CFTR的折叠与转运），以及在家系中与疾病的共分离，并按通行的五级体系报告。囊性纤维化的严重度依突变类别而异——两条染色体皆为无义或剪接等位基因者通常有胰酶不足，而R117H或poly(T)序列等残余功能变异常无——这正是变异解释必须基于机制的原因，也是同一基因型可以有轻度或晚发表现的原因。
:::

::: history
Archibald Garrod在1908年提出疾病可以是化学途径中的一个阻断；George Beadle与Edward Tatum在1941年把这一想法变成实验计划。基因的化学物质性质由Avery、MacLeod与McCarty（1944）以及Hershey与Chase（1952）确定；遗传密码在1961至1966年间由Marshall Nirenberg、Har Gobind Khorana、Severo Ochoa等破解，此前Sydney Brenner、François Jacob与Matthew Meselson已确立密码的三联体、不重叠性质并指出转运RNA的存在。令人意外的是分裂基因：1977年Richard Roberts与Phillip Sharp各自证明腺病毒转录本经过剪接，即内含子可以隔断编码序列——他们因此获得1993年诺贝尔奖的一半，另一半归Thomas Cech与Sidney Altman的催化性RNA。Frederick Sanger的1977年测序法使DNA可读，Kary Mullis的1985年聚合酶链反应使其可扩增，2001–03年的人类基因组使其可枚举。Andrew Fire与Craig Mello的RNA干扰（2006年诺贝尔奖）被证明正是小干扰RNA药物与反义寡核苷酸得以可能的机制；而Emmanuelle Charpentier与Jennifer Doudna的CRISPR-Cas9系统（2020年诺贝尔奖）在十年之内把靶向编辑从愿景变为实验台方法——第一种获批的基因编辑药物于2023年问世。
:::

## 通向何处

染色体、家系推理与变异分级见[[genetics/genome-chromosomes]]与[[genetics/genetic-testing]]；印记、重复扩增与线粒体遗传见[[genetics/non-mendelian-inheritance]]；肿瘤的体细胞遗传学见[[genetics/cancer-genetics]]；代谢在翻译层面的调控见[[cell-biochemistry/metabolic-integration]]。

::: summary
- 基因是具有功能转录本的一个位点：启动子、外显子与内含子、非翻译区，以及常常位于远处的增强子；基因组大部分被转录，只有一部分被翻译。
- 复制因碱基选择、校正阅读与修复而准确，而每种修复系统各有其疾病与各自的治疗开发（错配修复与检查点抑制剂，同源重组与PARP抑制剂）。
- 转录受染色质状态与经增强子起作用的转录因子控制；剪接是疾病的重要发生部位，也是现实的药物靶点，脊髓性肌萎缩即为范例。
- 表观遗传标记——CpG甲基化、组蛋白修饰、印记、X失活——不改变序列而改变表达，并可被疾病扰乱，也可因亲本来源而扰乱。
- 翻译在起始处受调控，是许多抗生素与少数毒素的靶点；提前终止密码子通常经无义介导的降解消除mRNA，而非产生截短蛋白。
- 变异分级是关于频率、机制、功能与共分离的判断：基因报告是证据，不是诊断。
- 多数酶的表型呈阈值行为，这解释了携带者的健康、多变的表现度，以及生化检测与基因检测并用的价值。
:::

## 练习

::: exercise 读密码表的逻辑 {level=1}
解释为何密码子第三位的G→A转换比第一位更可能是同义的，而CpG二核苷酸处的C→T转换作为疾病突变为何不成比例地常见。
::: solution
简并性集中于第三位，该位与反密码子的摆动位配对松弛，故第三位改变常编码同一氨基酸。相反，CpG处的甲基化胞嘧啶自发脱氨基为胸腺嘧啶，而修复系统对此的处理不如未甲基化胞嘧啶的脱氨基，故CpG是突变热点——这就是*FGFR2*、*MECP2*、视网膜母细胞瘤基因等中反复出现的“CpG”突变为何在无亲缘关系的家系中独立发生。
:::
:::

::: exercise 哪一种修复？ {level=1}
指出处理下列损伤的主要修复途径：(a) DNA中错配的尿嘧啶；(b) 紫外诱导的嘧啶二聚体；(c) 二核苷酸重复处形成的插入-缺失环；(d) G1期的双链断裂。
::: solution
(a) 碱基切除修复（尿嘧啶-DNA糖苷酶，随后AP内切酶）。(b) 核苷酸切除修复——其失效即着色性干皮病。(c) 错配修复——其失效造成微卫星不稳定，如Lynch综合征。(d) 非同源末端连接，易出错；同源重组仅在有姐妹染色单体可用时进行，即晚S期与G2期。
:::

::: exercise 无义介导的降解 {level=1}
两位患者的同一基因分别在第3外显子（共10个外显子）与最后一个外显子有无义突变。预测谁的残余蛋白较多，并说明理由。
::: solution
最后一个外显子的提前终止密码子可逃过无义介导的降解，因为该监视机制依赖沉积在正常终止密码子上游的外显子连接复合体；末外显子的终止密码子被读作正常终止。该转录本被翻译，产生的截短蛋白可能保留部分功能（或更糟地起显性负作用）。第3外显子的终止则触发降解，故mRNA少、蛋白极少或无——通常为无效等位基因，功能丧失更重。这就是“截短突变都等价”为什么不对的原因，也是某些基因型对read through或外显子跳过策略有反应而另一些没有的原因。
:::
:::

::: exercise 解释机制 {level=2}
一名29岁患结直肠癌的患者，其肿瘤为微卫星不稳定，其兄曾患子宫内膜癌。请解释为何免疫检查点抑制在这类肿瘤有效，而同一药物在微卫星稳定的结直肠癌通常无效。
::: solution
生殖系的错配修复等位基因缺失加体细胞第二个等位基因丢失（Lynch综合征）使肿瘤在重复序列处积累数千个插入与缺失突变，包括产生胸腺中不存在的新型肽段的移码。新抗原经HLA递呈并具免疫原性，故肿瘤只能靠抑制T细胞反应存活——通常通过程序性死亡配体1；解除该抑制的抗体（pembrolizumab、nivolumab，单用或联合ipilimumab）可产生持久缓解，其证据已使错配修复状态成为不依赖瘤种的治疗指征。微卫星稳定的肿瘤新抗原很少，解除抑制便无所作用；同一思路解释了为何如今把肿瘤突变负荷、POLE突变的超突变与错配修复状态一并报告，也解释了为何在确诊时检测改变的是治疗而非仅为预后。
:::

::: exercise 剪接 {level=2}
一名患者纯合存在外显子2供位上游5个核苷酸处产生新GT二核苷酸的内含子突变。请描述预期的转录本与蛋白，以及你将如何证实预测。
::: solution
若使用新的供位，则外显子延长五个核苷酸，造成移码并在下游产生提前终止密码子；或者新位点与正常位点同时使用，产生正常与异常转录本的混合，部分转录本可能整段跳过该外显子。故预测产物为含移码转录本所译的截短蛋白，加上若干逃脱的正常蛋白。证实需要展示RNA本身：反转录患者RNA（若该基因在血中表达则用血，否则用培养细胞或活检组织），跨外显子扩增并测序其产物；用片段分析或数字PCR定量可给出正确剪接信使的比例，而这正是决定表型轻重的关键。对影响剪接的变异，cDNA分析是标准的证据等级，也是为何在DNA结果含混时实验室的RNA报告可以具有决定性。
:::

::: exercise 再看印记 {level=2}
一名女孩有15q11-q13的父源缺失，一名男孩有同一区域的母源单亲二体。请预测两者的表型，并说明为何“相同的染色体异常”在此导致相同的疾病。
::: solution
两者都丧失了15q11-q13的父源表达贡献——*SNRPN*、SNORD116簇及其余父源转录本——而在神经元中表达的*UBE3A*来自母源等位基因，不受影响；故两者均为Prader-Willi综合征：新生儿期肌张力低下与喂养困难，随后多食、肥胖、性腺功能低下、学习困难与特征性行为。机制不同而表型相同，是因为该区域是印记的：只有父源拷贝活跃，故无论是缺失，还是继承两份母源拷贝（单亲二体，源于三体拯救）而失去它，在功能上等价。镜像病变——母源贡献丧失（缺失、父源单亲二体或*UBE3A*突变）——导致Angelman综合征。临床推论是：正常核型不能排除任一疾病，而甲基化特异性检测是能同时筛出两者的检查。
:::

::: exercise 设计实验 {level=3}
胎儿超声发现水肿；父母为第一代堂亲。常规与无创遗传检测未能定论。请拟定诊断策略及其解释，并说明为何外显子组阴性不等于问题结束。
::: solution
取诊断性胎儿样本（绒毛或羊水细胞），提供三人（胎儿加双亲）快速外显子组测序并联合水肿鉴别诊断的基因panel（淋巴管与心脏畸形基因、贮积病如LAMA2相关病与溶酶体疾病、Bart's胎儿水肿、高危人群的α-地中海贫血、包括拷贝数改变与单亲二体的染色体病，以及RAS病）。三人联合分析允许识别新发与复合杂合变异，也使近亲婚配可被解释，因为同一来源的纯合区段将显示隐性候选基因。阴性结果并非反对遗传病因的证据：外显子组可能遗漏深部内含子与调控变异、重复扩增（现需靶向检测或长读长测序）、被流程过滤区域的拷贝数与结构改变、低于检测限的嵌合，以及尚无疾病关联的基因；也可能是样本问题，如胎盘局限性嵌合。出生后再分析、对受累组织的靶向RNA研究、甲基化研究与基因组测序皆为合理的下一步；确有相当比例的“外显子组阴性”病例在数年后经再分析获得诊断。在此如在所有产前遗传工作中，解释最好与临床遗传学家一起完成，并就不确定性进行咨询。
:::

::: exercise 定量遗传学 {level=3}
某隐性疾病的杂合携带者酶活性为对照均值的52%。另一家系中同病的患病同胞对分别为8%与4%。该测定对DNA结果增加了什么？它何时会误导？
::: solution
酶测定提供了缺失的功能证据：52%的活性正是单一无效等位基因所致单倍体不足的预期，从而确认有一个等位基因无功能；4–8%则确认患病状态——这可以成为决定意义未明变异的关键，尤其当它与已知致病变异处于反式时。误导的情形包括：测定所用组织不表达相关同工型（或表达交叉反应的相关蛋白）、突变蛋白存在但无催化活性而免疫学正常（此时“正常”蛋白量误导而活性低，或相反）、疾病源于质的缺陷而非量的缺陷（显性负或获得功能等位基因）、疾病阈值低致症状患者仍有30–40%活性，以及炎症或溶血改变样本。总的规则：只有在组织、同工型与疾病机制都已知相符时，酶测定才是良好的功能试验。
:::
