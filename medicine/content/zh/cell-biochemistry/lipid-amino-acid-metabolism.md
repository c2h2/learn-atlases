脂肪既是身体的燃料储备，同时又是它的水分储备：一千克三酰甘油约携带38 MJ能量，而同样能量若以糖原储存，要拖带数千克结合水。氮则是相反的问题——身体可以贮存碳并从容处理，却必须持续排出氨基氮，而完成此事的机器一旦失效，其表现是数小时之内便触目惊心的。

本课谈这一不对称的两半：脂质代谢，从一餐脂肪到一个脂蛋白颗粒、从一个脂肪细胞到一个酮体；以及氨基酸代谢，从转氨基到尿素，并包括使其在临床上可见的遗传性酶病与获得性疾病。

## 脂肪的入与出

三酰甘油是三个脂肪酸接于甘油骨架。脂肪酸在链长与双键数目和位置上各异，而差异意义重大：人体不能在9号碳以外引入双键，故**亚油酸（n-6）与α-亚麻酸（n-3）为必需脂肪酸**，用于膜磷脂，并作为花生四烯酸、前列腺素、二十二碳六烯酸及分解介质的前体。缺乏时出现鳞屑性皮炎、伤口愈合不良，婴儿则生长停滞。

消化需要乳化。肝由胆固醇制成的胆盐贮存于胆囊并经肠肝循环返回，把脂肪分散为微滴；胰脂肪酶与辅脂酶释放2-单甘油酯与游离脂肪酸；胆盐、单甘油酯、脂肪酸、胆固醇与脂溶性维生素组装成**微胶粒**把后者送达肠细胞。在细胞内脂肪酸被重新酯化并包装为**乳糜微粒**，进入淋巴——而非门静脉——从而绕过肝脏。这一解剖事实解释了三件事：为何在中链甘油三酯（直接经门血入肝）被用于脂肪吸收障碍时；为何淋巴漏导致乳糜性腹水与淋巴细胞丢失；以及为何口服脂肪负荷使甘油三酯升高数小时，而肝自身产物（VLDL）的峰值较晚。

::: definition β氧化与肉碱穿梭 {#def-box}
**β氧化**在线粒体基质中每一步以乙酰CoA形式移去两个碳，循环包含脱氢（FAD）、水化、脱氢（NAD⁺）与硫解。**长链脂酰CoA不能穿越内膜**；它在外膜由**肉碱棕榈酰转移酶1（CPT1）**转移到肉碱上，跨膜交换后再由CPT2转化回脂酰CoA。**丙二酸单酰CoA**——脂肪酸合成的第一个产物——抑制CPT1，故胰岛素升高丙二酸单酰CoA即关闭脂肪氧化。
:::

::: example 十六个碳及其价值 {#ex-palmitate}
计算一分子软脂酸（棕榈酸）彻底氧化的净ATP产量：每NADH按2.5、每FADH₂按1.5计，并计入活化的代价。
::: solution
活化为软脂酰CoA相当于消耗2 ATP（ATP→AMP＋PPi）。七轮β氧化切下八个乙酰CoA，并产7 NADH与7 FADH₂：$7 \times 2.5 + 7 \times 1.5 = 28$ ATP。八个乙酰CoA经三羧酸循环产$8 \times 10 = 80$ ATP。净得$= 28 + 80 - 2 = 106$ ATP——约为葡萄糖的五倍半，这就是脂肪成为储存形式的原因，也是一名饥饿一周的患者其蛋白耗损程度不及饥饿两天者的原因。该算术还解释了“燃脂”开关的价值：静息时心与静息骨骼肌的大部分ATP来自脂肪酸，而游离脂肪酸与葡萄糖竞争（Randle效应），这也是肥胖时胰岛素抵抗部分是脂质现象的原因之一。
:::
:::

两个辅助系统具临床意义。**过氧化物酶体**缩短极长链与支链脂肪酸；其失败（Zellweger谱系疾病）或其底物进入线粒体的转运失败（X连锁肾上腺脑白质营养不良，极长链脂肪酸蓄积并损害白质与肾上腺皮质）会造成血浆中可测的蓄积。**奇数链**脂肪酸产生丙酰CoA，经依赖生物素的羧化酶变为甲基丙二酰CoA，再由依赖**维生素B₁₂**的变位酶转为琥珀酰CoA；这是唯一可转为葡萄糖的脂肪碳，也是B₁₂缺乏引起甲基丙二酸尿症的原因。

::: definition 酮体 {#def-ketone}
酮体——**乙酰乙酸**、**β-羟丁酸**以及自发分解的**丙酮**——在肝线粒体中由乙酰CoA生成，其条件是草酰乙酸稀缺而乙酰CoA充裕：长期饥饿、极低碳水化合物摄入、长时间运动、失控的1型糖尿病，以及（在反刍动物）泌乳期。HMG-CoA合酶是调控步骤。肝外组织把乙酰乙酸重新转为乙酰CoA；**肝本身不能利用酮体**，因其缺乏硫解酶（琥珀酰CoA:3-酮酸CoA转移酶）。
:::

酮症因此是一种适应性状态：为脑、心与肌提供水溶性燃料，从而节省葡萄糖与肌蛋白；饥饿数日后酮体可提供脑所需能量的很大一部分，这也是为何长期饥饿者神志清楚而低血糖者不能。**酮症酸中毒**则是失去控制的同一化学过程：胰岛素缺乏时脂解无刹车（激素敏感性脂酶失去抑制），糖异生又无草酰乙酸可省，于是酮体生成超过缓冲能力而pH下降。酒精性酮症酸中毒与妊娠饥饿性酮症酸中毒以同样方式发生，二者血糖均可接近正常。

::: warning 尿酮试纸可能在患者好转时显示加重
硝普钠试纸检测乙酰乙酸（与丙酮）而不检测β-羟丁酸。重度酮症酸中毒时升高的NADH/NAD比值使平衡偏向β-羟丁酸，故早期尿酮可看似轻微；治疗后随着氧化还原状态恢复，β-羟丁酸回转为乙酰乙酸，试纸反而读数更强。以尿酮、或以“升高”的酮体结果判断疗效会被误导。应随访血酮体浓度（β-羟丁酸）、pH或碳酸氢盐、阴离子间隙与临床状态。
:::

## 脂肪酸与胆固醇合成，以及脂蛋白

脂肪酸合成是其镜像过程，在胞质中由于多功能蛋白脂肪酸合酶（含酰基载体蛋白）完成，NADPH来自磷酸戊糖途径，乙酰单位由柠檬酸裂合酶自线粒体输出。其限速步骤**乙酰CoA羧化酶**是代谢逻辑的良好示例：被柠檬酸（线粒体燃料充裕）与通过去磷酸化起作用的胰岛素激活，被AMP活化的蛋白激酶磷酸化所抑制，因而受能量应激抑制。其产物丙二酸单酰CoA既推动合成又经CPT1阻断氧化，故细胞不会同时合成并燃烧脂肪。

胆固醇由乙酰CoA经甲羟戊酸合成，该途径的调控酶**HMG-CoA还原酶**是他汀的靶点，也是这条途径值得了解的原因：

- 几乎每个细胞都合成胆固醇；肝还合成以供VLDL输出，并分泌入胆汁；而只有肝（以及肠道细菌）能降解甾体环。
- 细胞内胆固醇经**SREBP**控制自身供给：当固醇下降，该转录因子被切割并诱导HMG-CoA还原酶与**LDL受体**。他汀降低细胞内胆固醇，进而上调LDL受体——这是其清除血浆LDL的方式；也解释了其效应依赖受体功能，故完全缺乏LDL受体者（纯合子家族性高胆固醇血症）应答很差。
- **PCSK9**结合LDL受体并将其导向溶酶体降解；抗PCSK9抗体与小干扰RNA通过保存受体显著降低LDL。

::: theorem 脂蛋白的逻辑 {#thm-lipoprotein}
脂蛋白由其所载及其去向定义。富含甘油三酯的颗粒（来自肠的乳糜微粒、来自肝的VLDL）经脂蛋白脂肪酶向脂肪组织与肌肉供脂，该酶需apoC-Ⅱ并由胰岛素激活；其残粒被肝摄取。富含胆固醇的颗粒反向运行：LDL经LDL受体把肝胆固醇送到外周，HDL经ABCA1自外周细胞收集胆固醇运回肝，并随胆汁排出。
:::

::: proof
每一流向取决于颗粒所携带或所遇到的酶，而非颗粒“想要”前往何处。乳糜微粒与VLDL在肌与脂肪的毛细血管内皮遇到脂蛋白脂肪酶；apoC-Ⅱ是其必需辅因子，故罕见的apoC-Ⅱ缺乏表现为乳糜微粒血症与胰腺炎。随着甘油三酯被移除，颗粒缩小，经CETP交出胆固醇酯，并以apoE介导的方式被肝清除。LDL是VLDL失去大部分甘油三酯后的残体，是血浆中主要的胆固醇载体，经受体介导的内吞清除——此过程的失效使LDL自出生即升高。HDL由贫脂的apoA-Ⅰ经ABCA1摄取胆固醇组装而成，经LCAT酯化以填充核心，再经SR-BI把胆固醇选择性交给肝。临床血脂谱由此自然得出：甘油三酯升高意味着富含甘油三酯颗粒清除障碍（最常见原因为失控的糖尿病与酒精，经典继发原因为甲状腺功能减退与肾脏疾病），而孤立LDL升高意味着受体介导清除受损或生成过多。动脉粥样硬化遵循动脉暴露于LDL颗粒的**累积时程**，这正是尽早治疗家族性高胆固醇血症的理由。
:::

::: example 肌腱结节与34岁的心梗 {#ex-fh}
一名29岁、体健而消瘦的男子胆固醇11.4 mmol/L，甘油三酯正常，HDL 1.2 mmol/L。其父44岁心梗、51岁去世；外祖母“年少丧子”二人。查体见双侧跟腱粗厚与指关节黄色小结。若不能直接测LDL，请计算之（甘油三酯1.1 mmol/L），并说明为何单用他汀可能不足。
::: solution
Friedewald公式给出LDL胆固醇＝总胆固醇−HDL−（甘油三酯÷2.2，均以mmol/L计），即$11.4 - 1.2 - 1.1/2.2 = 9.7$ mmol/L。如此高的LDL伴肌腱黄瘤、两代早发家族史且无继发原因，符合**杂合子家族性高胆固醇血症**的临床诊断标准，通常为*LDLR*失活等位基因，有时为*APOB*（配体）突变或*PCSK9*获得功能突变。处理为高强度他汀加依折麦布，未达目标时用LDL血浆置换或PCSK9靶向治疗；家系级联筛查是最有价值的一步，因为该病常见（约1/250）且在冠脉事件前多无症状。他汀部分经上调LDL受体起效，故残余受体活性少的患者应答较差；纯合子可能需要lomitapide或inclisiran，历史上也曾肝移植。
:::
:::

## 氮：转氨基、谷氨酸与尿素

氨基酸不被贮存。其碳架被利用或被燃烧；其氮被转移并最终排出。**磷酸吡哆醛**依赖的转氨酶把氨基转移到α-酮戊二酸生成谷氨酸；谷氨酸或在肝把氮交给尿素，或以**谷氨酰胺**形式输出——后者是无毒的运输形式，携带两个氮。

::: definition 尿素循环 {#def-urea}
在肝细胞中，一个游离氨（以氨甲酰磷酸形式）与一个来自天冬氨酸的氮缩合为**尿素**排出，并生成延胡索酸返回循环。五个酶为氨甲酰磷酸合成酶**Ⅰ**（线粒体，需**N-乙酰谷氨酸**作为必需的激活剂）、鸟氨酸氨甲酰转移酶、精氨酸代琥珀酸合成酶、精氨酸代琥珀酸裂合酶与精氨酸酶。每合成一分子尿素消耗四个高能磷酸键；整个循环在高蛋白摄入与分解代谢时上调。
:::

::: example 高蛋白餐后呕吐的男孩 {#ex-otc}
一名三岁男孩在一次多食蛋白质的家庭聚会后出现呕吐、共济失调与意识障碍。氨480 µmol/L，血气示呼吸性碱中毒，阴离子间隙正常，血糖正常，肝酶正常，血浆谷氨酰胺升高而瓜氨酸降低；尿乳清酸显著升高。其母系舅舅幼年死于不明“代谢病”。酶缺陷为何，乳清酸为何升高，呼吸性碱中毒为何是线索？
::: solution
这是**鸟氨酸氨甲酰转移酶（OTC）缺乏**，最常见的尿素循环障碍，也是唯一X连锁者，与一名患者及其母系舅舅幼年夭折相符。氨不能进入循环而蓄积；谷氨酰胺与丙氨酸升高，因身体试图储存氮，而星形细胞内的谷氨酰胺具渗透活性——这就是高氨血症脑水肿与肝性脑病的机制。线粒体生成的氨甲酰磷酸无处可用，漏至胞质并进入嘧啶合成，故尿**乳清酸**升高，可把OTC阻断与氨甲酰磷酸合成酶Ⅰ或N-乙酰谷氨酸合成酶缺乏（乳清酸低）区别开。氨直接刺激呼吸中枢，故患儿表现为呼吸性碱中毒，而非休克或代谢病应有的酸中毒：**阴离子间隙正常的高氨血症伴呼吸性碱中毒，在证伪之前即为尿素循环障碍**。处理为紧急降氨（重度者血液透析或持续肾替代治疗）、短暂停蛋白同时以葡萄糖与脂肪提供足够热量以制止分解代谢、静脉精氨酸（以补充瓜氨酸、维持循环其余部分并借滞留氮生成尿素）、以及苯甲酸钠与苯丁酸钠/苯乙酸钠等氮清除剂；长期处理为限蛋白、必需氨基酸补充、口服精氨酸或瓜氨酸，重型肝移植，以及家庭备用并在需要前就写好的急救方案。
:::
:::

慢性高氨血症（肝衰竭）导致波动的意识障碍、睡眠倒错、扑翼样震颤与肝臭，即肝性脑病；处理是找出诱因（便秘、感染、消化道出血、镇静剂、大量蛋白负荷、脱水），并用乳果糖酸化肠腔把氨以铵形式滞留，必要时加利福昔明。生物化学还解释了为何不再对肝硬化患者常规推荐低蛋白饮食：患者本已肌少，而肌肉恰是氮清除的重要场所。

## 值得记住其临床后果的个别氨基酸

- **苯丙氨酸 → 酪氨酸**经苯丙氨酸羟化酶与四氢生物蝶呤。酶缺乏导致**苯丙酮尿症**，现由新生儿筛查发现；未治者出现智力障碍、癫痫、湿疹、霉臭味以及毛发皮肤色浅（酪氨酸是黑色素前体）。治疗为限制饮食并补充酪氨酸，以血苯丙氨酸监测；孕期母体饮食尤为要紧，因母源性苯丙氨酸损害胎儿脑。辅因子缺乏型伴神经系统病变，单靠饮食不能纠正，故低苯丙氨酸而酶正常者须查辅因子。
- **酪氨酸**继续合成DOPA与儿茶酚胺、甲状腺素、黑色素（酪氨酸酶，缺乏即白化病）以及延胡索酸与乙酰乙酸。此末段途径的阻断引起Ⅰ型酪氨酸血症（肝衰竭、肾小管功能障碍、类似卟啉症的神经危象；用尼替西农治疗，其机制为阻断毒性代谢物上游）与黑尿病（尿黑酸氧化酶；尿液放置变黑，成年后赭黄病性关节病）。
- **同型半胱氨酸**经甲基钴胺素与5-甲基四氢叶酸再甲基化为甲硫氨酸，或经磷酸吡哆醛转硫化。胱硫醚β-合酶缺乏导致**同型半胱氨酸尿症**：高瘦体型、晶状体脱位通常向下向内（Marfan综合征向上）、骨质疏松、学习困难，以及危险的血栓栓塞；约半数对吡哆醇有效。无论病因，同型半胱氨酸升高亦见于叶酸或B₁₂缺乏，是B族维生素与神经管缺陷关联的机制之一，故围受孕期间补充叶酸。
- **甲基化**依赖叶酸-甲硫氨酸循环，这就是叶酸缺乏同时引起巨幼细胞贫血与神经管缺陷的原因，也是为何单给叶酸可纠正B₁₂缺乏者的血象却让脱髓鞘继续进展。
- **支链氨基酸**（亮氨酸、异亮氨酸、缬氨酸）在肌肉中转氨基并在肌肉与脑氧化，而非在肝；其α-酮酸由与丙酮酸脱氢酶相关的硫胺素依赖复合体降解。该复合体缺陷即**枫糖尿症**，第一周内即出现喂养困难、脑病与甜香尿，亮氨酸驱动神经损害；存在生物素与硫胺素反应型；处理为紧急透析、特殊配方与限制并密切监测——而其饮食仍须供应生长所需。
- **甘氨酸、谷氨酸、天冬氨酸、丙氨酸、脯氨酸、丝氨酸、酪氨酸、半胱氨酸、天冬酰胺、精氨酸以及（新生儿）谷氨酰胺**只是“条件性”非必需：当摄入或合成不足时该名单会变长，如苯丙酮尿症与早产儿的半胱氨酸。

::: example 深色尿、背痛与一张用药清单 {#ex-porphyria}
一名27岁女性有三天剧烈阵发性腹痛、呕吐、心动过速、血钠126 mmol/L，现双上肢无力；住院后尿液放置后转为葡萄酒色。六周前因三叉神经痛开始卡马西平，并一直在节食减肥。诊断为何，两项新因素有何相关，特异性治疗是什么？
::: solution
这是急性肝性卟啉病（急性间歇性卟啉病，卟胆原脱氨酶缺乏，常染色体显性而外显率低）。诱因是任何增加肝血红素合成需求者：卡马西平、巴比妥、磺胺及某些孕激素等细胞色素P450诱导药物；以及碳水化合物供给减少，如节食或感染，因为葡萄糖抑制ALA合酶。其临床三联为腹部、自主神经（心动过速、高血压、便秘、尿潴留）与神经（可致呼吸衰竭的运动神经病、癫痫，以及低钠血症，后者多由抗利尿激素不当分泌所致）；尿含卟胆原与δ-氨基酮戊酸，放置后变暗。重要的是腹部柔软、影像无帮助，故本病常被误作外科急症。以避光的随机尿卟胆原确诊，随后静脉给予**血红素精氨酸**（对ALA合酶形成反馈抑制）、补充葡萄糖并去除诱因；givosiran在肝内沉默ALAS1，可减少频繁复发者的发作。切勿在未核对卟啉病安全用药清单的情况下给患者使用孕激素为主或酶诱导的药物。
:::

由氨甲酰磷酸合成酶Ⅰ以HCO₃⁻与游离NH₄⁺在线粒体生成的氨甲酰磷酸提供一个氮；第二个氮在线粒体产物瓜氨酸与**天冬氨酸**由精氨酸代琥珀酸合成酶缩合时进入。天冬氨酸经延胡索酸与转氨基再生，故实际上氮经谷氨酸与转氨酶来自许多氨基酸，但直接供体是这两个。

::: history
Archibald Garrod在1908年《遗传性代谢缺陷》中提出，单个化学步骤的可遗传阻断即可产生疾病——本课每一种酶测定背后的思想。Knoop早在1905年以苯基标记的脂肪酸喂狗、观察尿中苯甲酸类而描绘出β氧化螺旋；Krebs与Kurt Henseleit于1932年解决了尿素循环。Asbjørn Fölling于1934年描述苯丙酮尿症，而Robert Guthrie 1961年的细菌抑制法使新生儿群体筛查成为一张滤纸与一次足跟采血的事。Konrad Bloch与Feodor Lynen阐明胆固醇合成与乙酸的活化（1964年诺贝尔奖）；Michael Brown与Joseph Goldstein随后解释了细胞如何通过LDL受体感知并摄取胆固醇（1985年诺贝尔奖），这正是他汀起效的原理。远藤章1976年从青霉菌中分离出compactin——当时他在筛选真菌代谢物中的HMG-CoA还原酶抑制剂，lovastatin随之而来：一类靠“筛发霉大米代谢物”而发现的药物。
:::

## 通向何处

途径在两餐之间如何整合，见[[cell-biochemistry/metabolic-integration]]；此处所列辅因子所需的维生素见[[cell-biochemistry/nutrition]]；脂蛋白与动脉粥样硬化生物学续于[[cardiovascular/vascular-disease]]；肝衰竭及其并发症见[[gastrointestinal/liver-disease]]；酶缺陷的遗传学见[[genetics/mendelian-inheritance]]。

::: summary
- 脂肪是浓缩的储备：吸收需胆盐与微胶粒，乳糜微粒携膳食脂肪经淋巴，而线粒体β氧化（长链经肉碱穿梭）每分子软脂酸约产106 ATP。
- 丙二酸单酰CoA是开关：它推动合成并经CPT1阻断氧化，故餐后与空腹状态各择一途。
- 酮体由肝为他者而造；禁食时是生理性的，只在失控时（如胰岛素缺乏）成为病态。
- 脂蛋白按载荷与方向分类：富甘油三酯者外出，富胆固醇者归乡；LDL靠受体清除，HDL靠逆转运；LDL受体解释了他汀、家族性高胆固醇血症与PCSK9。
- 氮以谷氨酰胺转运、以尿素排出，代价为四个磷酸键；高氨血症引起星形细胞肿胀与呼吸性碱中毒，尿乳清酸可区分尿素循环的阻断部位。
- 个别氨基酸途径解释苯丙酮尿症、同型半胱氨酸尿症、枫糖尿症、酪氨酸血症、黑尿病与急性卟啉病，其中多数已纳入若干地区的新生儿筛查。
:::

## 练习

::: exercise 必需与否 {level=1}
解释为何亚油酸是人类膳食的必需脂肪酸，而硬脂酸不是；并说出两种值得记住的亚油酸衍生物。
::: solution
人类的去饱和酶只能在Δ9或更靠近羧基端引入双键，故无法在9号碳与甲基端之间形成双键；n-6与n-3脂肪酸因此必须经口摄入。相反，硬脂酸由合酶生成并可经Δ9去饱和酶变为油酸。亚油酸生成花生四烯酸——前列腺素、血栓素、白三烯与脂氧素的前体，以及NSAID与脂氧合酶抑制剂所干预的类花生酸信号；它还是表皮屏障所必需，故必需脂肪酸缺乏引起皮炎。
:::
:::

::: exercise 肉碱 {level=1}
一名长期接受不含肉碱的肠外营养的患者，在并发感染时出现乏力、肌酸激酶升高与低酮性低血糖。为何肉碱耗竭可复现CPT2缺陷的图像？
::: solution
长链脂酰基必须搭载肉碱跨越线粒体内膜。若游离肉碱低——如多年透析后或肉碱转运缺陷——穿梭便不能把长链脂肪送进氧化场所，肌与肝便用不上其主要燃料：出现乏力与横纹肌溶解，因乙酰CoA供应不足而酮体生成下降，血糖下降则因肝既须输出葡萄糖又少有来自脂肪的ATP。短链与中链脂肪酸不需肉碱即可进入，故被“豁免”——这也是中链甘油三酯油对部分患者有益的原因，以及为何生化表现冠以“低酮性”低血糖这一独立标题。
:::

::: exercise Friedewald公式 {level=1 check=“6”}
总胆固醇8.0 mmol/L，HDL 1.0 mmol/L，甘油三酯2.2 mmol/L。计算LDL胆固醇。
::: solution
$\text{LDL} = 8.0 - 1.0 - 2.2/2.2 = 6.0$ mmol/L。当甘油三酯超过约4.5 mmol/L时该公式失效（乳糜微粒与很大的VLDL使估计失真），此时需直接测定LDL或采用制备法。
:::

::: exercise 碳的去向 {level=2}
判断以下底物在人体能否净生成葡萄糖，并简述理由：(a) 软脂酸；(b) 甘油；(c) 亮氨酸；(d) 奇数链脂肪酸；(e) 乙醇。
::: solution
(a) 不能：乙酰CoA不能净转为草酰乙酸，因循环两次脱羧不可逆；但它提供的ATP与还原力使肝得以从其他底物运行糖异生。(b) 能：甘油被甘油激酶（肝中丰富）磷酸化后进入磷酸二羟丙酮。(c) 不能：亮氨酸纯为生酮氨基酸。(d) 部分可以：末端三个碳产生的丙酰CoA生成琥珀酰CoA而可转糖，故奇数端为生糖，其余部分不然。(e) 净意义上不能：乙醇氧化为乙酸继而乙酰CoA，并升高NADH/NAD比值，使草酰乙酸转为苹果酸，反而促进酮生成与乳酸蓄积——这是酒精性酮症酸中毒发生的理由之一。
:::

::: exercise 尿素循环的算术 {level=2 check=“4”}
合成一分子尿素消耗多少个高能磷酸键？
::: solution
四个：氨甲酰磷酸合成酶Ⅰ用2个ATP（变为ADP＋Pi），精氨酸代琥珀酸合成酶把ATP转为AMP＋PPi，相当于2个。该能量代价解释了为何高蛋白摄入与分解代谢会上调循环，也解释了为何氨升高需要严重肝衰竭，而非仅仅摄入减少。
:::

::: exercise 解读血脂谱 {level=2}
三位患者：(A) 甘油三酯24 mmol/L，血浆呈乳白色，腹部钝痛，血糖22 mmol/L；(B) 自20岁起LDL 6.4 mmol/L，甘油三酯正常，跟腱增厚；(C) 甘油三酯4.0 mmol/L，HDL 0.7 mmol/L，腰围106 cm，血压148/92，血糖6.8 mmol/L。请判断各自类型与即刻风险。
::: solution
A：重度高甘油三酯血症伴乳糜微粒血症，最常见的诱因是失控的糖尿病——胰岛素缺乏使脂蛋白脂肪酶活性下降——即刻风险为急性胰腺炎，故目标是镇痛、胰岛素与停脂，而不是他汀。B：杂合子家族性高胆固醇血症的图像，风险为早发动脉粥样硬化，处理为强效降脂与家系筛查。C：代谢综合征的血脂异常（高甘油三酯、低HDL、小而密LDL），处理按绝对心血管风险决定，减重与活动是最有效的干预，他汀按计算风险而非LDL数值决定。请注意三位中只有一位最需要那个LDL数字。
:::

::: exercise 肝为何造自己不能用的酮体 {level=3}
就生物化学与进化两方面说明肝缺乏琥珀酰CoA:3-酮酸CoA转移酶的意义。
::: solution
生物化学上，酮体利用需要转移酶以琥珀酰CoA活化乙酰乙酸为乙酰乙酰CoA；肝胞质无此酶，故肝生成的乙酰乙酸只有一个去处——输出。相反，肝的HMG-CoA合酶在线粒体中高度活跃，且存在相应的磷酸酶以释放酮体。进化上，一个消耗自身出口的组织将使整条途径失去目的：酮体存在的意义是在葡萄糖短缺时把燃料从肝运往脑、心与肌，若肝自己高效利用它们，整条通路就成了燃烧动物正依赖之脂肪的无效循环。相反的酶分布是实现单向流动的常见设计——同一逻辑见于肝缺乏己糖激酶而有葡萄糖-6-磷酸酶，以及肝外组织有转移酶而肝无。
:::

::: exercise 新生儿筛查的实际 {level=3}
第五日的新生儿筛查显示苯丙氨酸320 µmol/L（正常< 120）。婴儿一般情况良好，纯母乳喂养。请陈述你的思路与即刻处理，并说明两个最常见的陷阱。
::: solution
在证伪之前按有意义处理，但要结合背景判读：标本必须在出生满24小时后采集（过早会漏掉正在上升的苯丙氨酸），早产或宫内生长受限、正在接受肠外营养或抗生素的婴儿既有假阳性也有假阴性。行动包括当日见家属、安排确认性血浆氨基酸定量与尿蝶呤分析以区分经典苯丙酮尿症与四氢生物蝶呤代谢缺陷、开始低苯丙氨酸配方同时继续母乳喂养，并转诊区域代谢病专业团队。两个造成损害的陷阱是：(i) 轻视结果、数周后复查，其间孩子不断蓄积苯丙氨酸，而其神经毒性取决于年龄；(ii) 只用饮食治疗辅因子缺陷，血值虽被纠正，单胺类神经递质合成仍持续不足，孩子在“正常”的苯丙氨酸下发生进行性神经病变。部分中心做四氢生物蝶呤反应性检测；无论是否如此，保护大脑的是目标范围而非排除诊断。
:::

::: exercise 饥饿：从第一小时到第三十天 {level=3}
描述从餐后一小时到完全饥饿三十天之间燃料与氮平衡的变化，并指出相关激素与途径。
::: solution
吸收后数小时依赖肝糖原分解，由下降的胰岛素/胰高血糖素比值驱动，同时为脑与红细胞节省葡萄糖，而肌肉摄取脂肪酸与开始出现的酮体。约一天后糖原几近耗尽，糖异生（来自氨基酸、甘油与乳酸）成为葡萄糖主要来源，而由于草酰乙酸被糖异生取用，酮体生成上升。数日之内脑适应氧化酮体的相当部分，从而降低葡萄糖需求与每日蛋白丢失：氮排泄由约10–12 g/日降至新的较低稳态，酮体可达5–7 mmol/L而无酸中毒（因胰岛素并非缺如，碳酸氢盐再生能与其并行），静息代谢率随瘦体重与甲状腺、交感张力下降而降低。至第三至五周，蛋白丢失再度成为限制，而脂肪储备将支撑旅程的末段；此时再喂养变得危险，因为胰岛素回归会把磷、钾与镁驱入细胞内——见[[cell-biochemistry/nutrition]]与[[gastrointestinal/clinical-nutrition]]。
:::
