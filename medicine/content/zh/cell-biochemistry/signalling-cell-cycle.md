细胞通过读取周围的分子来决定该做什么。肾上腺素使肝细胞在数秒内释放葡萄糖，胰岛素使脂肪细胞在数分钟内摄取葡萄糖，生长因子使祖细胞分裂，而皮质醇几乎使每个细胞改变其读取的基因。凡此种种都是一条链条：配体结合受体，受体改变构象，该变化由少数中介蛋白接力传递，接力被放大并被反馈塑形，其输出是酶活性、离子电导、基因转录或细胞命运的改变。

近三分之一的现代药物作用于这一受体大家族中的某个成员，而其余多数药物作用于同一链条上更下游的环节。细胞周期及其死亡程序是最终的输出：细胞是否分裂、停止或死亡。

## 任何信号系统的共同性质

在讲各部件之前，先讲一般原理，因为它们解释了临床药理学的多数现象：

- **特异性来自受体的组成，而非配体。**乙酰胆碱在神经肌肉接头的烟碱型受体上做一件事，在心脏的毒蕈碱型受体上做另一件事，因为受体不同。同一原理使单一激素在肝、肌肉与脂肪中各有作用。
- **放大是内建的。**一个被激活的受体可激活多个G蛋白；一个腺苷酸环化酶生成许多环磷酸腺苷；一个激酶磷酸化许多底物。于是皮摩尔浓度的激素可以移动毫摩尔浓度的代谢物池——而对称地，一小部分受体占据即可产生很大反应。
- **反应受占据率与内在活性调节。**对简单的可逆配体，分数占据率为$[L]/([L] + K_d)$；**激动剂**有内在活性（它们激活），**拮抗剂**有亲和力而无内在活性，**部分激动剂**无论占据多少受体，其最大效应仍低于完全激动剂。
- **系统会脱敏。**受体被G蛋白偶联受体激酶（GRK）磷酸化并与arrestin结合、内吞、降解与再致敏，过程决定信号持续多久，也解释了耐受以及骤停药物后的反跳。
- **反馈与模块化使其稳健而可成药。**负反馈（JAK-STAT上的SOCS蛋白、环核苷酸上的磷酸二酯酶、ERK磷酸化SOS）限制时程；正反馈（钙诱导的钙释放、caspase激活）使反应呈全或无。

::: example 同一种第二信使，不同的含义 {#ex-camp}
环磷酸腺苷升高时：在心肌细胞增强收缩力与心率；在脂肪细胞刺激脂解；在肾集合管引起水通道蛋白2的插入；在气道平滑肌引起舒张；在胃壁细胞刺激酸的分泌。差别从何而来，又为何对药物重要？
::: solution
信使是通用的，含义则来自每种细胞中环磷酸腺苷依赖性蛋白激酶（PKA）的锚定蛋白与底物的组合。AKAP支架蛋白把PKA停在特定靶标旁——心肌中的L型钙通道与受磷蛋白、脂肪细胞中的激素敏感性脂酶与包被蛋白、集合管中的水通道蛋白2囊泡，以及平滑肌中的肌球蛋白轻链激酶机制与钾通道。两个临床后果随之而来。第一，全身性升高环磷酸腺苷的药物（β₂受体激动剂、磷酸二酯酶抑制剂、感染中的霍乱毒素）会产生全身PKA靶器官的综合征——震颤、心动过速、低钾、高血糖、气道与肠道舒张——治疗作用只是这张清单上的一项。第二，组织选择性可以在受体下游获得：选择性β₂激动、PDE4与PDE5抑制的分工（罗氟司特与西地那非）、以及吸入而非全身给药，都是利用同工酶（而非该核苷酸）在组织间不同这一事实。
:::

## 穿越膜的四种方式

::: definition 细胞表面受体的类别 {#def-receptors}
**配体门控离子通道**（烟碱型乙酰胆碱、GABA_A、甘氨酸、谷氨酸、5-HT₃，以及嘌呤能P2X受体）：最快的信号，毫秒级，也是多数麻醉、镇静与抗惊厥药物的机制。
**G蛋白偶联受体**（视紫红质家族）：七个跨膜α螺旋，激活异三聚G蛋白——Gs、Gi/o、Gq/11、G12/13——并经GRK与arrestin脱敏。
**酶偶联受体**：受体酪氨酸激酶（胰岛素、IGF、EGF、FGF、PDGF、VEGF、RET、KIT）、经JAK信号转导的细胞因子受体，以及受体鸟苷酸环化酶（钠尿肽、鸟苷素）。
**黏附与连接受体**（整合素、钙黏蛋白、选择素、免疫球蛋白超家族）经细胞骨架信号转导，是抗整合素与抗选择素治疗的靶点。
胞内受体——**核受体**超家族（类固醇、甲状腺激素、维生素D、维甲酸与脂质配体）——补全此表，它们作为转录因子工作而非位于膜上。
:::

::: definition 第二信使 {#def-second}
**环磷酸腺苷**（腺苷酸环化酶；由磷酸二酯酶清除；效应物为PKA与环磷酸腺苷门控通道）。**环磷酸鸟苷**（一氧化氮作用于可溶性鸟苷酸环化酶，钠尿肽作用于颗粒型鸟苷酸环化酶；磷酸二酯酶5；效应物为PKG）。**二酰甘油与IP₃**（磷脂酶C；二酰甘油激活蛋白激酶C，IP₃释放内质网钙）。**钙**，由内质网/肌浆网的SERCA泵与线粒体缓冲，经钙调蛋白、钙调磷酸酶与PKA起作用。**PIP₃**（PI3K；由PTEN对抗；效应物为AKT与PDK1）。**肌醇多磷酸、花生四烯酸类类花生酸、一氧化氮与一氧化碳**作为短程信使。几乎每一种第二信使在治疗上都同样取决于终止它的酶——磷酸二酯酶、脂质磷酸酶、钙泵与激酶——而不止是生成它的酶。
:::

### G蛋白偶联受体

G蛋白循环是一只有内置计时器的分子开关。激动剂结合的受体作为Gα的鸟苷酸交换因子，使其释放GDP、结合GTP、与Gβγ解离，并调节效应物，直至其内在GTPase（由RGS的GTP酶激活蛋白加速）将其关闭。

效应物：**Gs**刺激腺苷酸环化酶；**Gi/o**抑制之并开放钾通道（GIRK），而Gβγ亚基可激活PI3Kβ；**Gq/11**激活磷脂酶Cβ，生成三磷酸肌醇（IP₃）与二酰甘油，从而释放内质网钙并激活蛋白激酶C；**G12/13**作用于Rho的鸟苷酸交换因子与细胞骨架。

两种细菌毒素是经典的一对：霍乱毒素ADP-核糖基化Gsα并将其锁定于开放状态，腺苷酸环化酶持续运转，CFTR向肠腔倾注氯；百日咳毒素ADP-核糖基化Gi并阻止其工作，于是抑制性信号失效，出现淋巴细胞增多（趋化因子信号需要Gi）、百日咳毒素自身的作用，以及心脏的失去拮抗的兴奋。

人类疾病沿同样的路径展开。加压素V2受体失活突变导致X连锁肾性尿崩症；TSH受体激活突变导致常染色体显性非自身免疫性甲亢，而Gsα激活的“gsp”突变见于生长激素分泌型垂体腺瘤；钙敏感受体失活突变导致家族性低尿钙性高钙血症，激活突变则导致低钙血症；视紫红质突变导致视网膜色素变性；而CCR5辅助受体的缺失（Δ32等位基因）赋予对HIV-1感染的抵抗，这也正是人们曾尝试CCR5编辑细胞治疗的原因。**假性甲状旁腺功能减退症1a型**，伴对甲状旁腺激素及其他经Gs起作用激素的抵抗，以及Albright遗传性骨营养不良表型，源于母源遗传的*GNAS*失活突变；该基因的印记解释了同一基因所致的亲本来源特异的表现（也见于合子后激活突变所致的McCune-Albright综合征）。

### 受体酪氨酸激酶与RAS–MAPK、PI3K轴

配体结合使受体二聚化，其激酶结构域互相磷酸化，磷酸酪氨酸随即招募含SH2或PTB结构域的蛋白——GRB2/SOS以激活RAS、胰岛素信号中的IRS蛋白、PI3K、PLCγ与SHP磷酸酶。RAS-GTP招募RAF，激活MEK1/2继而ERK1/2，后者入核诱导FOS、MYC与周期素D。PI3激酶在膜上生成PIP₃，招募PDK1与AKT；AKT磷酸化靶蛋白而抑制TSC2与GSK3、激活mTORC1并促进生长，同时抑制FOXO转录因子与凋亡机器。**PTEN**逆转这一脂质步骤，是最常被缺失的抑癌基因之一。

其临床清单之长足以自成课程：RAS病（RASopathies，包括NF1、Noonan、Costello与心-面-皮肤综合征）是同一通路过度激活所致的发展障碍；软骨发育不全为组成性激活的FGFR3；HER2扩增定义一种乳腺癌亚型，以曲妥珠单抗与抗体偶联药物治疗；肺癌的激活*EGFR*突变对奥希替尼应答，并经*T790M*与*C797S*、MET扩增或小细胞转化获得耐药；*KIT*与*PDGFRA*突变使胃肠道间质瘤对伊马替尼敏感；*BRAF* V600E黑色素瘤对BRAF加MEK抑制有效；而*PIK3CA*、*AKT*与*mTOR*抑制剂，以及以合成致死闻名的PARP抑制剂，都作用于分支。其毒性即通路毒性：EGFR抑制引起痤疮样皮疹、甲周炎与腹泻，因为正常皮肤与肠需要EGFR；VEGF通路抑制引起高血压、蛋白尿、伤口愈合不良与血栓形成。

### JAK–STAT，及其药理学上的成功

细胞因子受体本身无激酶活性；受体结合的**JAK**激酶互相磷酸化并磷酸化受体，招募**STAT**蛋白，后者二聚化后直接进入细胞核。生长激素经JAK2与STAT5b发挥作用（其缺失导致Laron型生长激素不敏感，以胰岛素样生长因子1治疗）；促红细胞生成素经JAK2（其V617F突变引起真性红细胞增多症）；干扰素经STAT1/2；IL-6经STAT3；IL-2经JAK3（其缺失导致重型联合免疫缺陷）。*STAT3*获得功能突变引起多器官自身免疫与淋巴增殖综合征，失去功能则导致高IgE（Job）综合征，伴葡萄球菌脓肿、肺大疱与特殊面容。由于该通路汇聚于多种细胞因子，JAK抑制剂（托法替布、巴瑞替尼、乌帕替尼）可用于类风湿关节炎、炎症性肠病、特应性皮炎、斑秃与移植物抗宿主病——并带有类别效应：带状疱疹再激活、静脉血栓、主要心血管事件与恶性肿瘤信号，因而需要修改说明书。这也提醒我们，关闭一条存活通路是有代价的。

### 核受体

它们是具有DNA结合锌指对、配体结合域的配体调节性转录因子，其开关是辅抑制物与辅激活物复合体的交换。甲状腺激素、维生素D、维甲酸、雌激素、雄激素、糖皮质激素、盐皮质激素与孕激素受体，以及“许可性”的PPAR、LXR、FXR等，各自调控一组基因。

临床例子多为内分泌受体综合征及其药物：完全性雄激素不敏感（*AR*）使46,XY个体呈现女性表型、乳房发育而子宫缺如；*AR*的CAG扩增以改变相互作用的方式导致脊髓与延髓肌萎缩；糖皮质激素受体突变引起皮质醇抵抗伴乏力与ACTH升高；皮质醇在肾内激活盐皮质激素受体本由11β-羟类固醇脱氢酶2型阻止，其缺乏即表面盐皮质激素过多综合征，而该受体本身是螺内酯与依普利酮的靶点；*VDR*突变引起伴脱发且治疗抵抗的Ⅱ型维生素D依赖性佝偻病；*PPARG*突变引起家族性部分性脂肪营养不良与胰岛素抵抗，而PPARγ激动（噻唑烷二酮）正是一类糖尿病药物的基础；急性早幼粒细胞白血病中PML-RARA融合把髓系分化阻断在早幼粒阶段，直到大剂量全反式维甲酸释放辅抑制物复合体、细胞开始分化——而分化综合征正是这一治疗作用转向危险的表现。耐药机制——受体突变、替代剪接、以及其他通路的旁路激活——正是内分泌相关肿瘤按序贯的受体靶向药物治疗的原因。

### 终生不退场的发育通路

**Notch**（配体诱导受体胞内段水解，后者作为转录辅因子）管理二元的细胞命运决定：*NOTCH3*突变引起伴皮层下梗死与痴呆的CADASIL，*JAG1*与*NOTCH2*突变引起伴胆管缺乏的Alagille综合征，而*NOTCH1*获得功能是一部分T细胞白血病的基础。**WNT**信号（由含APC的降解复合体降解β-连环蛋白）驱动隐窝增殖；生殖系*APC*突变导致家族性腺瘤性息肉病，体细胞*APC*突变则是多数结直肠癌的启动事件。**Hedgehog**（PTCH1解除对SMO的抑制，继而GLI转录因子）导致Gorlin综合征与一部分髓母细胞瘤，且可被药物阻断（vismodegib）。**TGF-β与SMAD**既抑制上皮生长又驱动纤维化；*TGFBR1/2*突变导致Loeys-Dietz主动脉病，*SMAD4*缺失导致幼年性息肉病并是胰腺癌的晚期事件，而*ACVR1*获得功能导致进行性骨化性纤维发育不良。

一名18岁患者因踝部手术以七氟烷与司可林诱导，过程顺利；20分钟后呼气末二氧化碳升高，心率140次/分，出现咬肌痉挛，钾由4.2升至6.4 mmol/L，体温急升。受体缺陷为何，丹曲林为何有效？
::: solution
这是恶性高热易感，通常为*RYR1*（肌浆网的钙释放通道）的获得功能突变，较少为感应横管电压的二氢吡啶受体*CACNA1S*。挥发性麻醉药与去极化肌松药触发过度的钙释放；钙泵与收缩装置的持续工作消耗ATP、产生热与二氧化碳，并漏出钾与肌酶，故最早的表现是无法解释的高碳酸与心动过速，随后是肌强直、高钾、横纹肌溶解、酸中毒与高热——若等到高热才诊断，它常是晚期甚至临终的征象。丹曲林结合RYR1并减少钙释放，故直接作用于该通道；处理为立即停用触发药物、以100%氧过度通气、给予丹曲林、治疗高钾与酸中毒、积极降温、警惕横纹肌溶解与弥散性血管内凝血，并至少监测一日以防复发。家系咨询、麻醉警示卡与避免触发因素（并须知对其他多数手术吸入麻醉并非绝对禁忌，而司可林必须避免）也是同一信号病变的处理内容。

## 细胞周期及其执行

::: definition 细胞周期的引擎 {#def-cycle}
进程由**周期蛋白依赖性激酶**（CDK）驱动，其浓度恒定，而活性取决于结合**周期蛋白**、磷酸化状态（由CAK的激活磷酸化、由Wee1的抑制性磷酸化、由CDC25磷酸酶去除），以及CDK抑制物：INK4族（p16^INK4a^、p15、p18、p19，结合CDK4/6）与CIP/KIP族（p21^CIP1^、p27^KIP1^，抑制CDK2复合体）。周期素D–CDK4/6继而周期素E–CDK2使**视网膜母细胞瘤蛋白**过度磷酸化，释放**E2F**转录因子并使细胞承诺进入S期；周期素A–CDK2驱动复制，周期素B–CDK1驱动有丝分裂；后期促进复合体/细胞周期体（APC/C）泛素化周期素B与securin以结束有丝分裂。
:::

两个检查点在临床上最为重要。**DNA损伤检查点**由感应器与转导器完成——应对双链断裂的ATM与CHK2、应对复制应激的ATR与CHK1——两者汇于p53并引起细胞周期阻滞，使损伤在复制或分离之前被修复。**p53**由激酶以及ARF诱导、并从MDM2释放，是抑癌基因的原型：它诱导p21（阻滞）、DNA修复基因、细胞衰老或凋亡；生殖系*TP53*突变导致Li-Fraumeni综合征，表现为早发的肉瘤、乳腺癌、脑肿瘤与肾上腺皮质癌。**纺锤体组装检查点**在每一个动粒完成附着之前阻止后期；被紫杉类、长春碱类及其他纺锤体毒物药理性破坏时，细胞停滞于分裂期并死亡，对快速分裂的细胞尤然。

控制的丧失是肿瘤的本质（见[[genetics/cancer-genetics]]与[[pathology/cancer-biology]]），但该通路也正是细胞毒治疗存在治疗窗的原因：骨髓、肠隐窝与毛囊在分裂，故受损——于是骨髓抑制、黏膜炎与脱发；而CDK4/6抑制剂帕博西利、瑞博西利与阿贝西利与内分泌治疗联用于雌激素受体阳性乳腺癌，是细胞周期生物学成为日常处方的例子。

## 死亡作为信号的结果

两条主要通路已在[[cell-biochemistry/cell-structure]]中对照；此处给出其分子控制。

- **线粒体（内源性）凋亡**：BH3-only感受器（PUMA、NOXA、BIM）抑制抗凋亡的守卫BCL-2、BCL-XL与MCL1，使BAX与BAK得以通透外膜；细胞色素c驱动APAF1凋亡小体与caspase-9。BCL-2抑制剂维奈克拉对已依赖BCL-2的细胞具致死性——慢性淋巴细胞白血病为范式——而同一机制解释了BCL-2上调为何造成化疗耐药。
- **死亡受体（外源性）凋亡**：FAS配体与TRAIL，连同FADD、caspase-8，并在部分细胞中经BID切割把两条通路连接起来。FAS缺失导致自身免疫性淋巴增殖综合征，伴双阴性T细胞、脾大与自身免疫。
- **程序性的替代通路**，各有其药理学：经RIPK1/RIPK3与MLKL的坏死性凋亡；经炎症caspase与gasdermin D成孔的细胞焦亡，位于炎症小体下游（IL-1β释放的机制，也是秋水仙碱与IL-1阻断在痛风与心包炎中获益的原理）；以及经脂质过氧化与谷胱甘肽过氧化物酶4的铁死亡。
- **衰老**：稳定的阻滞伴分泌表型（SASP），由持续的DNA损伤信号以及癌基因诱导的p16与p53驱动；衰老细胞随龄积累，正被清除衰老细胞的药物（senolytics）实验性清除。

::: example 身高很矮而生长激素很高的小儿 {#ex-laron}
一名8岁儿童，身高低于第0.4百分位，父母身高正常，胰岛素样生长因子1与其结合蛋白3均测不出，而葡萄糖负荷后生长激素为42 mU/L。通路缺陷在哪一环，如何证实，机制对治疗有何推论？
::: solution
生长激素经二聚体细胞因子受体与JAK2发挥作用，主要诱导肝以及生长板局部生成IGF1，而STAT5b介导其中相当部分的转录反应，包括酸不稳定亚基与IGF1本身的诱导。生后生长迟缓、IGF1极低且短程生长激素试验不升高，同时内源性生长激素升高，即为生长激素不敏感（Laron综合征），多因*GHR*缺陷，部分家系为*STAT5b*或受体后缺陷。以IGF1生成试验证实，在有条件时加做STAT5b依赖性转录降低或受体表面结合试验，并对*GHR*与*STAT5b*测序；鉴别诊断需注意IGF1受体缺陷（IGF1低而IGFBP3高，常有高血糖与小下颌）、*IGF1*本身，以及*ALS*（酸不稳定亚基）缺乏（此时IGF1与IGFBP3均低）。治疗绕开受体：重组IGF1（mecasermin）每日两次皮下注射，监测低血糖与扁桃体、腺样体淋巴组织，其现实限制是必须及早开始才能在生长板起效。机制还可解释家族日后出现的代谢表型——最初厄瓜多尔队列中报告的、对肿瘤与2型糖尿病的相对保护——这是信号通路决定两种常见病的最清楚的人类例证之一。
:::

::: example 手抖而高血压的移植患者 {#ex-calcineurin}
两名肾移植患者，分别服用环孢素与他克莫司，均出现震颤、头痛、高血压与肌酐升高25%，而血管超声正常。两人均在用质子泵抑制剂，其中一人还用了三唑类抗真菌药。请解释共同的机制、药物相互作用，以及为何西罗莫司不引起同样问题。
::: solution
环孢素（与亲环蛋白结合）与他克莫司（与FKBP12结合）都抑制**钙调磷酸酶**——一种钙-钙调蛋白依赖的磷酸酶，它使NFAT去磷酸化并进入核内转录IL-2等细胞因子基因；阻断T细胞激活的最后共同环节，正是它们如此有效免疫抑制的原因，也使其毒性成为类别效应。肾毒性来自入球小动脉收缩，慢性者则有间质纤维化与小动脉玻璃样变；高血压为肾性与血管性；神经毒性、震颤与头痛共有（他克莫司略多，且其另致糖尿病，因β细胞毒性）。两者皆为P-糖蛋白与CYP3A4的底物，故三唑类抗真菌药、大环内酯类、地尔硫与葡萄柚汁可急剧升高其浓度，而酶诱导剂（利福平、部分抗癫痫药）可致排斥反应；这就是此类药物须以谷浓度给药、以及一旦开始使用三唑类就应预期剂量调整的原因。西罗莫司同样结合FKBP12，但抑制mTOR而非钙调磷酸酶，阻断的是对IL-2的反应而非其生成，故不引起小动脉性肾毒性或高血压——其代价是口腔溃疡、水肿、脂代谢紊乱、蛋白尿、伤口愈合不良与肺炎。此例的道理可以推广：两种药物可结合同一胞内蛋白而抑制完全不同的东西，而不良反应谱会告诉你在通路的哪一个节点上动了手。
:::

::: quiz
一氧化氮通过作用于血管平滑肌而降低血压。下列机制哪项正确？
- [ ] 它结合内皮受体并激活磷脂酶C。
- [x] 它扩散入平滑肌细胞并激活可溶性鸟苷酸环化酶，升高cGMP并激活PKG。
- [ ] 它直接开放ATP敏感性钾通道。
- [ ] 它抑制磷酸二酯酶5，而该酶即其生理靶点。
::: solution
一氧化氮通过结合可溶性鸟苷酸环化酶的血红素铁而激活该酶，升高cGMP从而激活PKG，后者降低细胞内钙并使平滑肌舒张。磷酸二酯酶5是降解cGMP的酶——这就是为何西地那非类药物是**增强**而非模拟一氧化氮，也是为何与硝酸酯合用可致显著低血压。内皮一氧化氮的释放本身依赖钙，并在内皮功能障碍时受损，这部分是勃起功能障碍与冠心病共享危险因素的原因。
:::

::: warning “靶向”并不等于肿瘤特异
激酶抑制剂与单克隆抗体所阻断的通路，正是正常组织使用的通路：皮肤与肠需要EGFR，内皮与肾需要VEGF，皮肤与心肌需要BRAF/MEK，周细胞需要PDGFR，心肌需要HER2。故EGFR抑制剂引起皮疹、甲周炎与腹泻；VEGF或VEGFR抑制剂引起高血压、蛋白尿、出血、伤口愈合不良，偶有动脉血栓；MEK抑制剂引起视觉障碍与可逆的射血分数下降；曲妥珠单抗可致心肌病，尤其在曾用蒽环类之后。应预期反应，监测血压、超声心功能、尿蛋白与皮肤，围绕手术安排伤口愈合，并把它们当作药物不良反应而非过敏处理。耐药是另一半故事——药物浓度、靶点的继发突变、平行通路的激活，或谱系转变——这也是治疗通常需要序贯与联合的原因。
:::

::: history
神经信号的电化学传递由Otto Loewi论证：他1921年的蛙心实验——刺激迷走神经并把灌注液转给第二颗心脏使其减慢——证明有某种化学物质被释放；Henry Dale纯化了乙酰胆碱，两人共获1961年诺贝尔奖。Sutherland发现环磷酸腺苷是肾上腺素的胞内“第二信使”，获1971年诺贝尔奖；磷脂酰肌醇循环与二酰甘油由西冢泰美（Yasutomi Nishizuka）在1970至1980年代阐明，钙作为普遍胞内信使的中心地位也在同数十年确立。Alfred Gilman与Martin Rodbell发现了把受体与效应物偶联的G蛋白（1994年诺贝尔奖），Robert Lefkowitz与Brian Kobilka则阐明了受体本身，包括视紫红质的结构（2012年诺贝尔奖）。细胞周期的引擎来自遗传学：Paul Nurse与Leland Hartwell在酵母中的*cdc*突变，加上Tim Hunt发现的周期蛋白，获2001年诺贝尔奖；p53于1979年被鉴定，并在1980年代被理解为抑癌基因；死亡程序则由Robert Horvitz通过线虫中*ced*基因的发现打开，BCL-2与caspase随之而来，Horvitz与Sydney Brenner、John Sulston共获2002年诺贝尔奖。
:::

## 通向何处

信号所控制的离子通道与泵见[[cell-biochemistry/membranes-transport]]；清除系统与细胞骨架见[[cell-biochemistry/cell-structure]]；受体理论、剂量-反应与药物相互作用见[[pharmacology/drug-receptor]]；本系统的自主神经部分见[[physiology/autonomic-nervous-system]]与[[pharmacology/autonomic-drugs]]；生长控制失败见[[genetics/cancer-genetics]]与[[pathology/cancer-biology]]。

::: summary
- 信号链具有共同性质——由受体决定的特异性、放大、按占据率分级、脱敏、反馈——性质解释了效价、耐受，以及同一信使为何在不同组织含义不同。
- 四类表面受体（离子通道、G蛋白偶联、酶偶联、黏附）加上胞内核受体，几乎涵盖全部激素、神经递质与药物作用。
- G蛋白是GTPase计时器；霍乱与百日咳毒素、以及遗传性GPCR与G蛋白疾病把该循环一一标注；arrestin与GRK解释了脱敏与偏向性信号。
- RTK–RAS–MAPK与PI3K–AKT–mTOR、JAK–STAT，以及发育期的Notch、WNT、Hedgehog与TGF-β通路，既是疾病机制也是药物靶点，而其毒性是通路毒性。
- 细胞周期由周期蛋白–CDK复合物驱动，受INK4与CIP/KIP抑制物、Rb–E2F与p53约束，并由DNA损伤与纺锤体检查点执行；其药理抑制已是常规抗肿瘤治疗。
- 细胞死亡是信号的结果，具有多种程序——依赖caspase的内源性与外源性凋亡、坏死性凋亡、细胞焦亡、铁死亡、衰老——每一种都有正在发展的药物。
:::

## 练习

::: exercise 占据率 {level=1 check=“0.9”}
某药的解离常数$K_d$为2 nM。在游离浓度为18 nM时，受体的几分之几被占据？
::: solution
占据率$= \dfrac{[L]}{[L] + K_d} = \dfrac{18}{18 + 2} = 0.9$。请注意占据率取决于*游离*药物，而血浆浓度并非受体处浓度——组织结合、血浆蛋白结合与房室分布都会把两者分开，这就是组织中的效价与受体上的效价不同的原因。
:::
:::

::: exercise 激动剂的算术 {level=1}
定义效价与内在活性，并解释部分激动剂如何在同一组织中起拮抗剂作用。
::: solution
效价是产生某一效应所需的浓度或剂量（常以EC50表示），受亲和力、受体密度与偶联效率影响；内在活性是药物占据受体后所能产生的最大反应。部分激动剂的内在活性低于内源性递质，故在储备受体少的组织中只产生亚最大反应——而若该组织已被内源性激动剂完全激发，用较低内在活性的药物占据部分受体反而会降低总反应，即表现为功能性拮抗。丁丙诺啡在阿片受体、吲哚洛尔与阿立哌唑在各自系统中都说明了同一药理，其临床后果是呼吸抑制的“天花板效应”，以及给已充分使用激动剂的患者施用部分激动剂可诱发戒断。
:::
:::

::: exercise 通路配对 {level=1}
写出下列受体的主要信号通路：胰岛素、促红细胞生成素、烟碱型乙酰胆碱、甲状腺素、ADH的V2受体、心房钠尿肽。
::: solution
胰岛素：受体酪氨酸激酶，经IRS蛋白至PI3K–AKT与Ras–MAPK。促红细胞生成素：细胞因子受体配JAK2–STAT5。烟碱型乙酰胆碱：配体门控阳离子通道（Na⁺/K⁺，产生终板电位）。甲状腺素（以T3形式）：胞内核受体调控转录。ADH的V2受体：Gs–腺苷酸环化酶–PKA，插入水通道蛋白2。心房钠尿肽：受体鸟苷酸环化酶，在靶细胞升高cGMP（而在血管壁，关系密切的一氧化氮则作用于可溶性鸟苷酸环化酶）。
:::
:::

::: exercise 从第二信使到床边 {level=2}
用通路解释：(a) β₂受体激动剂为何引起震颤与低钾；(b) 西地那非与硝酸酯合用为何引起显著低血压；(c) 茶碱过量为何引起心动过速与惊厥。
::: solution
(a) β₂受体→Gs→环磷酸腺苷→PKA：在骨骼肌增强收缩与肌梭相关信号（震颤），在骨骼肌则提高Na⁺/K⁺-ATP酶活性而使钾转入胞内，故血钾下降；高血糖与脂解来自肝与脂肪中同一机制。(b) 硝酸酯提供一氧化氮，激活可溶性鸟苷酸环化酶而升高cGMP；西地那非抑制PDE5，即海绵体与血管平滑肌中水解cGMP的酶；两者作用于同一信使的生成与清除，反应因此成倍放大，已有晕厥与心肌缺血报告。(c) 茶碱抑制磷酸二酯酶（普遍升高环磷酸腺苷与环磷酸鸟苷）并阻断腺苷受体；环磷酸腺苷过多驱动心脏兴奋与心律失常，而腺苷受体阻断降低惊厥阈值，故可惊厥——这也是茶碱治疗窗窄、需要测血药浓度，及其相互作用（环丙沙星、大环内酯类、吸烟对CYP1A2的诱导）如此重要的原因。
:::
:::

::: exercise 受体储备与剂量 {level=2}
在组织A，5%受体被占据即达完全效应；在组织B，同一药物需要80%占据。请比较两者对i)给予50%受体阻断的非竞争性拮抗剂与ii)部分受体不可逆灭活的敏感性。
::: solution
组织A储备受体多，组织B几乎没有。在A，阻断或摧毁50%受体后仍余五倍于完全效应所需的占据，故剂量-反应曲线只轻度右移，且直到储备耗尽之前最大效应得以保持；在B，同样的阻断立即降低最大效应。不可逆拮抗之后，A先出现右移，随后在储备耗尽时失去最大效应，而B最大效应下降而表观亲和力改变不大——这正是当年用于证明储备受体的经典实验。临床上，这就是为何高储备受体的组织能耐受受体数量减少（如下调），以及为何同一药物在不同器官可以表现截然不同。
:::

::: exercise 检查点治疗 {level=3}
一名转移性乳腺癌患者开始接受CDK4/6抑制剂联合芳香化酶抑制剂。请解释这一联合的生物学、预期毒性，以及耐药如何发生。
::: solution
雌激素剥夺降低雌激素受体阳性细胞的周期素D1转录，故细胞通过限制点的驱动越来越依赖CDK4/6；加用CDK4/6抑制剂使视网膜母细胞瘤蛋白保持低磷酸化、E2F被束缚，细胞停滞于G1——这是细胞停滞性的协同，而非两种细胞毒药的叠加。主要毒性为中性粒细胞减少（CDK4与CDK6为髓系祖细胞增殖所需，该作用多可逆且发热性中性粒细胞减少少于化疗）、乏力、腹泻（阿贝西利较多），以及瑞博西利的QT延长，故需监测血常规、肝功能与心电图。耐药可通过RB1缺失或突变（不再有可被执行的制动）、CDK6或CCNE1扩增与CDK2激活、INK4A通路在另一方向的失活，以及替代激酶信号的激活而发生。对实践的启示是：一种强制执行检查点的药物，其好坏只取决于它所依赖的那个检查点；其获益由肿瘤对该轴的依赖预测，而不是因为它“是一种抗癌药”。

::: exercise 按通路的免疫治疗 {level=3}
请解释为何阻断PD-1或PD-L1可引起垂体炎、甲状腺炎、结肠炎、肺炎与1型糖尿病，以及这在病房处理上应带来什么改变。
::: solution
PD-1通路是一种生理性耐受机制：它在周围组织中约束T细胞，并被肿瘤借用来逃脱免疫。解除这一抑制因此增加了对自身抗原的T细胞活性，累及该通路本起耐受作用的器官，产生本质上是药物触发的自身免疫病的免疫相关不良事件。内分泌腺是显著的靶标，且各药的谱不同：垂体炎以CTLA-4阻断为特征，可遗留永久性腺垂体功能减退；而甲状腺功能异常在PD-1/PD-L1抑制剂中常见，常经甲状腺毒症期转为甲状腺功能减退；结肠炎与肝炎表现为腹泻与转氨酶升高；肺炎最令人担忧；而快速破坏性的β细胞衰竭可产生胰岛素依赖的糖尿病，有时以酮症酸中毒起病。处理是想到诊断（事件在开始后数周至数月出现，也可发生在停药之后）、排除感染与疾病进展、评定严重度，并多在暂停检查点抑制剂的同时以糖皮质激素治疗大多数器官受累——但孤立性腺垂体功能减退或甲状腺功能减退应以激素替代而非免疫抑制治疗；对激素难治的结肠炎则升级至英夫利昔单抗或维得利珠单抗。实践上的病房原则是：正在使用药物的患者出现无法解释的腹泻、咳嗽、气促，或新发的头痛与口渴，在证伪之前都是不良事件；患者应随身携带说明卡，并知道该报告哪些症状。

::: exercise 设计实验 {level=3}
一种新的小分子在模拟的心肌缺血-再灌注损伤中保护心肌细胞。你怀疑其经线粒体通透性转换孔信号，并推测某个新发现的激酶磷酸化该孔的组分。请描述能确立机制、靶标结合与特异性的实验。
::: solution
先定机制：直接测量终点——线粒体膜电位、钙黄绿素-钴淬灭或溶胀实验测定该通透孔的导度，并以已知方向的遗传与药理工具（亲环素D配体、*Ppif*敲除）作阳性与阴性对照，同时把活性氧、钙负荷与ATP作为公认调节因素一并处理。再证明该激酶在其上游：以激酶失活突变体、小干扰RNA或结构无关的抑制剂证实保护消失，以功能获得证实拟表；用质谱证明候选孔组分的磷酸化并以磷酸化特异性抗体验证，再检验磷酸化缺失型与模拟型突变能否复现表型。靶标结合需要细胞内该激酶自身底物磷酸化的药效学读数，如可能还须直接结合证据（表面等离子共振或热稳定位移），以及化合物与激酶的晶体或冷冻电镜结构。特异性要求跨激酶组的反向筛选、脱靶预测，并在删除假定靶点后证明保护消失；随后整个故事须在另一物种并在体（梗死面积测量、盲法分析）中重复。若药物确经该孔起效，而激酶联系无法被第二种方法复现，诚实的结论是：这是一个尚无机制的表型观察——这也是转化心脏病学在历史上常常到达的终点。

::: exercise 实践中的剂量-反应 {level=3}
同一肿瘤的两名患者接受同一靶向药与同一剂量。一人血药浓度远高于体外的IC90却无应答；另一人浓度恰在IC90而反应显著。请提出四条不是“肿瘤不同”的解释。
::: solution
第一，血药浓度高未必等于靶点结合：药物可能因灌注差或血-肿瘤屏障无效而被排除在肿瘤之外，或被外排转运体泵出，或因血浆结合而使游离浓度低于测得值。第二，检测体系要紧：在低血清条件下测得的细胞系IC90未必可外推，而体内该通路可能更活跃或由旁路驱动。第三，肿瘤可能依赖一条建系时所用细胞并不具备的平行通路；或活检未能取到在治疗初期频率尚低的耐药亚克隆（例如带门控突变者）。第四，宿主因素改变药理：诱导代谢的药物相互作用、生物制剂的抗药抗体、靶点表达的差异、依从性与合并症。总的习惯是把问题拆为递送（是否有足量活性药到达靶点）、结合（靶点是否被抑制，以药效学标志衡量）与依赖（肿瘤是否真的需要该靶点）——治疗失败可以出在这三者的任何一环，而补救办法每次都不相同。
:::
