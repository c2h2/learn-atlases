在高收入国家，综合内科普通病房入院的患者中约有两成到四成经筛查存在营养不良风险，而多数医院对饮食的处理要么延后，要么根本没有。在同一谱的另一端，超过十亿人生活在肥胖之中；而在全球范围内，微量营养素缺乏仍是最常见的营养障碍——因为它发生在并不消瘦的人身上。

因此营养学不是医学中软性的部分。它决定伤口能否愈合、通气患者能否撤机、腹泻的患儿能否存活于再喂养、纯素幼儿是否发生佝偻病，以及一位做过胃转流术的年轻女性是否会以意识模糊再来急诊。本课涵盖能量、宏量营养素、维生素与微量元素，以及使这一切同时重要的两种临床状态：营养不良与肥胖。

## 能量：需要什么，代价几何

能量需求可依体重与应激估算（多数住院患者约30 kcal/kg/日；发热、脓毒症、创伤、烧伤与大手术时更高；有条件者以间接测热法直接测定），其构成值得了解：静息代谢消耗在静坐成人约占总量的60–75%，食物热效应约10%，体力活动则是变异最大的部分。单位体重的静息消耗以婴儿最高，随年龄与瘦体重丢失而下降——这就是为何同样的处方对老年患者是喂养过快，而对年轻患者反而是不足。

储存的算术毫不宽容，也值得讲给患者听：1 kg体脂约相当于7700–8000 kcal，故每日持续超出100 kcal——两块饼干、一杯果汁——若无其他改变，预测每年增加约4–5 kg。实际上体重变化会因随体重上升而增加的能量消耗而减缓，而维持比减轻更困难，其原因在于食欲信号而非意志力。

## 蛋白质、脂肪、碳水化合物、膳食纤维与液体

**蛋白质**：健康成人约0.75 g/kg/日（英国参考营养素摄入量），而在危重病、严重创伤、烧伤、压疮愈合、妊娠与哺乳、以及患急性病的老年人中常需1.2–1.5 g/kg/日甚至更高——后者因合成抵抗，同样的摄入量产生的肌肉更少。氮平衡与简单的尿素趋势只是粗略监测；在水分与肾功能充足时尿素上升，通常意味着蛋白不足或分解代谢过强，而非相反。

**脂肪**不宜低于总能量的约20%，既因它携带脂溶性维生素与必需脂肪酸，也因极低脂饮食损害饱腹感与依从性。**碳水化合物**的质量比总量更重要：证据支持的是膳食模式（地中海式，多全谷、豆、坚果、蔬果，少精制碳水与含糖饮料），而非单一营养素指标。**膳食纤维**25–35 g/日可改善粪便重量与血脂，滋养其短链脂肪酸为结肠细胞提供燃料的结肠微生物群，并改善血糖控制。**液体**需要量正常成人约30–35 mL/kg/日，发热、腹泻、高流量肠造口或大量利尿（如梗阻解除后的多尿）时更多，心肾衰竭时更少。

## 维生素：功能、缺乏与毒性

| 维生素 | 主要作用 | 缺乏 | 要点与毒性 |
|---|---|---|---|
| A（视黄醇） | 视觉、上皮分化、免疫 | 夜盲、干燥症与角膜软化、Bitot斑、麻疹病死率 | 过量致畸与肝毒性；妊娠期与大剂量维A酸类须避免 |
| D（胆钙化醇） | 钙磷吸收、骨 | 儿童佝偻病、成人骨软化、近端肌病、跌倒风险升高 | 过量补充可致高钙血症；需肾1α-羟化，故普通维生素D不能纠正晚期肾脏病的代谢性骨病 |
| E（生育酚） | 膜抗氧化 | 脂肪吸收障碍与无β脂蛋白血症时的溶血及后索/小脑体征 | 脂溶性；缺乏缓慢，通常提示脂类代谢障碍 |
| K（植物甲萘醌/甲萘醌） | 凝血因子γ-羧化、骨钙素 | 出血伴INR升高，可被维生素K纠正 | 新生儿常规预防；肠道细菌参与；华法林拮抗该循环 |
| B₁（硫胺素） | 丙酮酸与α-酮戊二酸脱氢酶、转酮醇酶 | 脚气病（干性与湿性）、Wernicke–Korsakoff综合征 | 2–3周即耗竭；在依赖转酮醇酶的溶血综合征中可致溶血；高危者应先于葡萄糖给予 |
| B₂（核黄素） | FAD/FMN | 口角炎、唇炎、舌炎、脂溢性皮炎 | 常为多种缺乏并存 |
| B₃（烟酸） | NAD/NADP | 糙皮病：曝光部位皮炎、腹泻、痴呆 | 可由色氨酸合成，故玉米为主食与类癌综合征时耗竭；大剂量烟酰胺具治疗作用 |
| B₆（吡哆醇） | 转氨基、脱羧、ALA合成 | 铁粒幼细胞贫血、周围神经病、癫痫、舌炎 | 异烟肼与青霉胺致缺乏；过量吡哆醇本身即致神经病 |
| B₇（生物素） | 羧化酶 | 皮炎、脱发、乳酸酸中毒 | 生蛋清（抗生物素蛋白）与未补充微量元素的长期肠外营养 |
| B₉（叶酸） | 一碳转移、DNA合成 | 巨幼细胞贫血、舌炎、神经管缺陷、同型半胱氨酸升高 | 数周即耗竭；可纠正B₁₂缺乏的贫血而神经损害继续进展 |
| B₁₂（钴胺素） | 甲硫氨酸合酶、甲基丙二酰CoA变位酶 | 巨幼细胞贫血、亚急性联合变性、周围神经病、舌炎、视神经萎缩、精神症状 | 储备可数年；纯素、胃切除、回肠病变或切除、长期质子泵抑制、二甲双胍、氧化亚氮 |
| C（抗坏血酸） | 脯氨酸与赖氨酸羟化、抗氧化、促进铁吸收 | 坏血病：毛囊周围出血、螺旋状毛发、牙龈肿胀出血、伤口不愈、贫血 | 数周即耗竭；“茶与面包”式膳食、严重精神疾病、孤独症极端食物选择 |

两条原则统摄此表。脂溶性维生素（A、D、E、K）随脂肪吸收，并在胆汁淤积、小肠疾病、胰腺功能不全与奥利司他治疗时丢失，且可蓄积中毒。水溶性维生素鲜有毒性，可经透析丢失，并以周而非年计耗竭——B₁₂除外，其数年储备使其缺乏成为吸收障碍或严格回避所致，而非单纯摄入不足。

## 矿物质与微量元素

- **铁。**仍是全球最常见的营养缺乏。应寻找失血（月经、消化道）、需求增加（妊娠、红系增生）、吸收障碍（乳糜病、萎缩性胃炎、减肥手术、质子泵抑制剂）与炎症。铁蛋白是最好的单项检查，但它是一种急性期蛋白：CRP为120的患者铁蛋白40 µg/L并不能排除缺铁，转铁蛋白饱和度、试补后的网织红细胞反应以及寻找病因都很重要。部分患者因铁调素而口服铁无效；静脉铁纠正更快，在吸收不确定、失血持续或不能耐受时更为可取。
- **钙、磷、镁、维生素D与甲状旁腺激素**作为系统见于[[renal/potassium-calcium-phosphate]]；从营养角度请记住：磷结合剂须随餐服用，镁缺乏会导致难以纠正的低钾与低钙，而维生素D需要量随体重上升。
- **碘。**合成甲状腺素所需；缺乏引起甲状腺肿，严重胎儿与婴儿缺乏导致可预防的学习障碍。食盐加碘已在许多国家纠正此患，但随着碘强化水平下降已有再流行的记录——这是一项必须维持的公共卫生措施。
- **锌。**伤口愈合、味觉、免疫、皮肤。缺乏引起鳞屑性、糜烂性皮炎分布于肢端与口周（先天者即肠病性肢端皮炎）、脱发、腹泻、伤口愈合不良与性功能低下；高危情形为高流量肠造口、未补充微量元素的肠外营养与慢性腹泻。锌过量可致铜缺乏。
- **铜。**缺乏引起贫血伴中性粒细胞减少及类似B₁₂缺乏的骨髓神经病，见于胃手术后、锌过量或严重营养不良；Menkes病为铜吸收障碍，毛发扭曲伴神经退行性变；Wilson病为铜经胆排泄障碍，有肝、基底节与精神症状及K-F环。
- **硒。**缺乏引起心肌病（克山病）与肌痛；见于长期未补充微量元素的肠外营养。谷胱甘肽过氧化物酶为含硒酶。
- **铬与锰**为微量元素；锰在胆汁淤积与肠外营养中蓄积，可致帕金森综合征。

::: theorem 使用肠道 {#thm-enteral}
只要胃肠道可以安全使用，肠内营养即优于肠外营养：它维护黏膜与免疫功能，感染与代谢风险更低，且费用低数倍。
:::

::: proof
其机制彼此独立而各有临床证据。第一，肠黏膜主要靠肠腔内容物滋养——结肠细胞靠谷氨酰胺与短链脂肪酸，绒毛高度靠直接接触——故“饿着肠道”导致黏膜萎缩与屏障功能丧失，并出现细菌移位。第二，经肠喂养维护肠相关淋巴组织与分泌型IgA；在危重病与胰腺炎的试验中，肠内喂养的感染并发症少于肠外喂养。第三，肠外营养所需的中心静脉导管本身是血流感染的途径，而配方自身带来高血糖、高甘油三酯、肝脂肪变与胆汁淤积、电解质转移与再喂养风险，并需要监测微量元素与微量营养素。第四，费用：仅药剂成本即相差约一个数量级，还未计人力。例外界定了规则——肠梗阻、肠缺血、高流量瘘、活动性出血、严重肠麻痹或不耐受、以及短肠的早期阶段——而它们也是理由，只要还有任何一段肠道在工作，就应*补充*而非替代，这正是实践中远端喂养配合近端减压管、以及以10–20 mL/小时实施滋养量喂养的依据。
:::

## 营养不良：先识别，再不要把它弄得更糟

::: definition 蛋白质-能量营养不良 {#def-pem}
**消瘦（undernutrition）**指能量与蛋白摄入不足；**蛋白质-能量营养不良**描述其两个极端。**消耗型（marasmus）**为总体热量缺乏：消瘦、皮下脂肪与肌肉丧失、皮下储备低、心动过缓、低体温，而生化大致正常。**恶性营养不良型（kwashiorkor）**伴水肿、皮肤与毛发改变（斑驳样脱色、“漆皮样”皮炎）、肝大伴脂肪变、淡漠，常有低白蛋白血症；现代观点认为其水肿是毛细血管通透性与炎症的障碍，而非单纯白蛋白低，kwashiorkor即严重营养不良叠加感染与微量营养素缺乏时的面貌。儿童重度急性营养不良定义为身高别体重低于−3标准差、上臂围小于115 mm，或存在营养性水肿。
:::

入院时的营养筛查（例如营养通用筛查工具MUST，或经验证的本院工具）是真正改变结局的干预，因为医院里最常见的营养错误不是处方，而是遗漏：为从未做的手术长期禁食、“摄入差”连续记录三天而无营养科会诊。其后果并非抽象——伤口与吻合口愈合不良、压疮、呼吸肌无力与撤机失败、免疫麻痹与感染、住院日延长、再入院增多、药物耐受变差。

处理是这一序列：**识别、纠正病因、安全再喂养、补充、监测、支持**（再喂养讨论见[[cell-biochemistry/metabolic-integration]]）。顺序之所以重要，是因为在严重而长期的营养不良中，危险不在缺失本身，而在随喂养而来的胰岛素。微量营养素要同时纠正：硫胺素、叶酸、B₁₂、维生素D、铜、硒、锌与磷；重度急性营养不良儿童按世界卫生组织方案，刻意先给低能量、低钠而富含微量营养素的配方，之后再追求追赶生长。

::: example 牙龈出血与“茶加面包”的膳食 {#ex-scurvy}
一名71岁独居老人，腰痛而少做饭，因瘀斑、双腿肿痛（轻微活动即“剧痛”）与牙龈出血就诊。血红蛋白88 g/L，白细胞正常，血小板正常，INR正常，碱性磷酸酶升高，双腿见毛囊周围瘀点与卷曲毛发。请解释。
::: solution
这是坏血病。抗坏血酸是胶原中脯氨酸与赖氨酸残基羟化所必需，故缺乏造成结构缺陷的胶原：毛细血管脆弱（瘀点、瘀斑、牙龈出血、关节腔积血）、伤口愈合不良、毛干异常与骨痛（骨膜下出血与骨基质障碍，碱性磷酸酶升高）。贫血为多因素——失血、因抗坏血酸促进非血红素铁吸收减少而致的铁吸收下降，以及同一膳食中常见的叶酸缺乏。线索在于分布（毛囊周围、位于下肢）、出血却血小板与INR正常、以及膳食史。可测血浆抗坏血酸确认，但应立即治疗：维生素C、配合社会支持的正规膳食与牙科处理；疼痛数日内改善，淤斑数周内消退。鉴别诊断——血管炎、血小板减少、非意外伤害、淀粉样变紫癜——值得了解，因为坏血病恰恰漏诊在没人给他称体重的那类患者身上。
:::
:::

::: example 平均红细胞体积正常的贫血 {#ex-b12}
一名68岁素食十年、服二甲双胍2 g/日的患者乏力，血红蛋白96 g/L，MCV 89 fL，血小板100×10⁹/L，胆红素34 µmol/L，结合珠蛋白低，中性粒细胞分叶过多，双踝振动觉减退伴步态不稳。请解释MCV为何正常，以及为何单补叶酸是错的。
::: solution
图像是无效造血伴细胞内髓内破坏（胆红素与LDH升高、结合珠蛋白低），可貌似溶血，加上后索神经病——在证伪之前即为B₁₂缺乏。MCV正常是因为两个相反因素并存：DNA合成障碍所致的大细胞，与并存的铁缺乏所致的小细胞（饮食性，且此年龄段因月经或肠道失血而常见）；红细胞分布宽度增宽与血小板减少常是最早线索。二甲双胍（损害回肠吸收）与长期严格素食而不补充，都是危险因素，故这一“双重打击”合乎情理。单用叶酸会纠正贫血，却可能加重或揭出脊髓亚急性联合变性；正确的顺序是测B₁₂（临界时加甲基丙二酸与同型半胱氨酸）、查恶性贫血抗体与乳糜病，并以肌注羟钴胺治疗，首周监测血钾，因为网织红细胞迅速增高可致低钾。B₁₂低或临界伴神经体征者应治疗，而不是留待复查。
:::
:::

::: warning “她超重，所以不可能营养不良”
BMI衡量的是质量，不是营养。一名肥胖者可以有铁缺乏（常因月经量多）、维生素D被脂肪组织滞留而血浆25-羟维生素D低伴继发性甲状旁腺功能亢进、B₁₂缺乏、叶酸缺乏，以及在骤然限制摄入时的蛋白缺乏；而“肌少性肥胖”——体重很大而肌肉量少——很常见，并预示内外科结局更差。反之，“正常”BMI可以伴随严重的近期体重下降（如非典型神经性厌食）或隐匿的吸收不良。评估营养要看轨迹、摄入、功能、肌肉与微量营养素，而不是秤上的数字。
:::

## 肥胖

::: definition 肥胖 {#def-obesity}
**肥胖**指损害健康的脂肪过多。人体测量上的简化指标是BMI（kg/m²）：25–29.9为超重，30–39.9为肥胖，≥40为重度肥胖；在南亚等人群中因风险在较低BMI即出现而采用更低的切点。就个体而言，腰围与腰高比在捕捉中心性脂肪与心血管风险方面比BMI更有用，而身体构成（肌少性肥胖、液体潴留）解释了大多数看似矛盾之处。
:::

其原因压倒性地是能量失衡，由廉价、可口、能量密集的食物与活动减少的环境所维持，背景则是对体重增加及维护较高体重的多基因易感性；单基因肥胖（瘦素与瘦素受体、阿黑皮素原、黑素皮质素4受体）罕见但重要，因为其中部分类型可治。需要排除的继发原因包括Cushing综合征、甲状腺功能减退（对体重影响有限），以及药物——糖皮质激素、非典型抗精神病药（奥氮平与氯氮平最甚）、丙戊酸、米氮平、三环类、胰岛素与磺脲类、部分β受体阻滞剂，以及含较老整合酶抑制剂的抗病毒方案。体重影响每个系统：2型糖尿病、阻塞性睡眠呼吸暂停与肥胖低通气、骨关节与背痛、胃食管反流与脂肪性肝病、多囊卵巢综合征与生育力下降、抑郁与病耻感、静脉疾病、麻醉与手术难度，以及至少十三种癌症的风险升高，并与BMI呈剂量反应关系。

处理是分阶段的，而且必须在设计时就把“维持”考虑进去：适度的能量缺口加患者能长期坚持的饮食，加上行为支持与不依赖减重也获益的活动；药物治疗（奥利司他、GLP-1受体激动剂与GIP/GLP-1双激动剂，试验中减重约15–22%）作为辅助，并预期停药后复发；以及在合适患者中实施代谢与减重手术——依据伴并发症的BMI或单纯极高的BMI提出，经多学科评估后进行，并理解它是我们可用的治疗2型糖尿病最有效的手段，其风险（渗漏、内疝、边缘溃疡、胆石、倾倒、铁/B₁₂/叶酸/钙/维生素D与硫胺素缺乏，以及自杀风险升高）要求终身随访与补充。术后呕吐是一项关于硫胺素的急症：束带或转流术后的Wernicke脑病曾使青年患者失明或死亡，而其“只是呕吐”从未被进一步检查。

::: example 转流术后第八周开始呕吐 {#ex-bariatric}
一名33岁女性，腹腔镜袖状胃切除术后八周，呕吐三周，现出现眼球震颤、共济失调步态与意识模糊。血钠131 mmol/L，血糖4.2 mmol/L。头颅CT正常。你给什么，为何次序要紧？
::: solution
立即给予大剂量静脉硫胺素。这是减重手术后硫胺素耗竭所致的Wernicke脑病——在高收入国家它是本病最常见的场景之一，也是妊娠剧吐时应在葡萄糖前给硫胺素的理由。诊断为临床诊断，经典型三联征只见于少数患者，而她已具备其中两项并有符合的病史。CT正常不能排除；乳头体与导水管周围灰质的磁共振可支持诊断，但绝不能因其而延迟治疗。次序之所以要紧，是因为碳水化合物氧化需要硫胺素依赖的酶，故在耗竭患者中输入含糖液体可诱发或加重脑病；镁是硫胺素依赖酶的辅因子，其缺乏会使硫胺素失效，故两者同时补充，随后谨慎纠正血钠，并在患者稳定后查找呕吐原因（狭窄、袖套扭转、梗阻）。长期而言，减重手术患者需要明确的补充方案、对铁/B₁₂/叶酸/维生素D/钙/甲状旁腺激素的监测（反复呕吐时并测硫胺素），以及一旦不能保留任何口服物即可获得的肠外营养途径。
:::
:::

::: example 孕期呕吐，随后出现复视 {#ex-hyperemesis}
一名26岁孕妇，孕15周，呕吐七周，体重下降12 kg，现已有复视、眼球震颤、宽基步态与言语迟缓。外院过去一天输注5%葡萄糖盐水共3 L。诊断为何，发生了什么，如何处理？
::: solution
这是妊娠剧吐导致硫胺素耗竭的Wernicke脑病。硫胺素依赖的脱氢酶失效，乳酸升高，乳头体、丘脑内侧与导水管周围灰质受损；眼征与共济失调可在治疗后数分钟至数日改善，但Korsakoff综合征的记忆障碍——顺行性遗忘伴虚构——可能不能恢复。先给葡萄糖会加快残余硫胺素的消耗，故未经治疗者输注葡萄糖可促成全貌，本例即是。处理为立即大剂量静脉硫胺素（与镁同用，因呕吐后常低镁，而镁是硫胺素依赖酶所需），随后给予葡萄糖与电解质，控制呕吐，能耐受后改口服硫胺素，并监测其他缺乏（叶酸、B₁₂、钾、磷、维生素D）与妊娠剧吐的心理并发症。记录与随访亦属重要：部分治疗而遗留遗忘的病例后果终身，而其病因本可预防。
:::
:::

::: quiz
一名患者因肠麻痹已24日未进食，现开始喂养。哪种营养素的储备最可能已降至临床危险的水平？
- [ ] 维生素B₁₂。
- [ ] 维生素A。
- [x] 硫胺素。
- [ ] 体蛋白。
::: solution
在无摄入的情况下硫胺素储备约二至三周即耗尽，而在重新启用碳水化合物代谢时出现症状——这正是再喂养方案把喂养与硫胺素及电解质补充配对的原因。维生素B₁₂与维生素A的储备可维持数年；体蛋白虽被消耗，其本身并不构成急性生化危险，而且B₁₂缺乏所致贫血在24日内远不会发生。
:::

::: history
营养学作为科学始于对照比较：James Lind 1747年在海上的柑橘试验，以及在此后数十年、远在致病分子被发现之前，James Cook在长途航行中对坏血病的实际预防。Christiaan Eijkman在1897年证明以精米喂养的鸡之多发性神经炎可被米糠预防；Gowland Hopkins在1906–1912年证明动物除蛋白、脂肪、糖与盐之外尚需微量“辅助食物因子”，并因此分享1929年诺贝尔奖；Casimir Funk于1912年创制“vitamine”一词。Joseph Goldberger在1914–1915年证明糙皮病是膳食性疾病而非传染病，1937年Elvehjem鉴定烟酸为其抗糙皮病因子。Albert Szent-Györgyi于1928年分离出抗坏血酸（己糖醛酸），Walter Haworth与Edmund Hirst稍后确立其结构并合成。George Whipple、George Minot与William Murphy证明肝脏可治愈恶性贫血的贫血（1934年诺贝尔奖），1948年活性肝提取物被浓缩供临床使用，而钴胺素的结构由Dorothy Hodgkin的晶体学确立——这项工作为她赢得1964年诺贝尔化学奖，也是该方法最杰出的成就之一。二战中期，Ancel Keys的明尼苏达实验量化了人体对半饥饿的适应——心动过缓、低体温、淡漠、水肿与关于食物的心理；Elsie Widdowson与Robert McCance的食物成分表则使配给与治疗膳食成为可能。两者至今是我们能把膳食当作剂量开出的原因。
:::

## 通向何处

营养素所服务的代谢机器见[[cell-biochemistry/energy-metabolism]]与[[cell-biochemistry/lipid-amino-acid-metabolism]]；医院内的再喂养与饥饿状态见[[cell-biochemistry/metabolic-integration]]；肥胖的外科与临床管理见[[surgery/gastrointestinal-surgery]]；吸收不良与肝病见[[gastrointestinal/bowel-disease]]与[[gastrointestinal/liver-disease]]；婴儿喂养与全球图景见[[paediatrics/growth-development]]与[[public-health/global-health]]。

::: summary
- 能量需求取决于体重与应激，1 kg脂肪约7700 kcal：小幅而持续的失衡造成大幅而长期的变化。
- 脂溶性维生素依赖脂肪吸收并可蓄积中毒；水溶性维生素以周计耗竭，除B₁₂其储备可数年。
- 硫胺素、叶酸与维生素C耗竭之快足以在寻常医院实践中出事；任何有风险的病人，硫胺素先于葡萄糖。
- 铁缺乏在全球最常见；铁蛋白须结合炎症解读，而MCV正常不能排除B₁₂或叶酸缺乏。
- 营养不良应在入院时筛查，并按“找出病因—缓慢再喂养—补充电解质与微量营养素”的顺序治疗；再喂养之险在于胰岛素，不在于饥饿。
- 消耗型与kwashiorkor是同一缺失面对不同炎症的表现，而肥胖不排除营养不良；肥胖是脂肪组织的疾病，多基因、环境，偶为内分泌与药物所致。
- 减重手术有效而需终身补充与随访；对上腹部手术后呕吐者，应有很低的硫胺素给予阈值。
:::

## 练习

::: exercise 估算需求 {level=1 check=“1800”}
以30 kcal/kg/日估算一名无急性疾病的60 kg女性的每日能量需求。
::: solution
$60 \times 30 = 1800$ kcal/日。请注意其中的假设：无发热、无脓毒症、无手术、无妊娠或哺乳，也未对肥胖作校正（肥胖者常按调整或理想体重计算以免喂养过度）。危重病中间接测热法所得更为可靠。
:::
:::

::: exercise 是哪一种缺乏？ {level=1}
配对：(a) 酒瘾者的口角炎、舌炎与正细胞性贫血；(b) 曝光V形区皮炎、腹泻与意识障碍；(c) 瘀点与螺旋状毛发；(d) 胆汁淤积者的共济失调、反射消失与溶血性贫血；(e) 高流量肠造口者的皮疹、脱发与腹泻。
::: solution
(a) 核黄素（B₂），常与叶酸等其他B族并存；贫血可为混合性。(b) 烟酸（糙皮病），异烟肼或消耗色氨酸的类癌综合征均可引起。(c) 维生素C（坏血病）。(d) 维生素E，其吸收需胆盐与脂肪，缺乏引起脊髓小脑综合征伴溶血。(e) 锌，呈肢端与口周分布的类肠病性肢端皮炎皮疹；应查造口流量与肠外营养的微量元素含量。
:::
:::

::: exercise 铁指标 {level=1 check=“16”}
转铁蛋白饱和度＝血清铁÷总铁结合力×100%。血清铁8 µmol/L、TIBC 50 µmol/L，计算饱和度；并在铁蛋白28 µg/L、CRP 5 mg/L的情况下解释。
::: solution
$8/50 \times 100 = 16\%$。转铁蛋白饱和度降低伴铁蛋白低正常而CRP正常，是炎症缺如时的缺铁；此种情形铁蛋白低于30 µg/L通常即可诊断，低于15 µg/L几乎特异。下一步不是再做一项铁检查，而是寻找原因——月经史、膳食、乳糜病血清学，以及在男性与绝经后女性中进行消化道检查。
:::
:::

::: exercise 维生素D与肾脏病 {level=2}
一名5期慢性肾脏病患者25-羟维生素D 42 nmol/L，钙2.1 mmol/L，磷1.8 mmol/L，甲状旁腺激素1100 pg/mL。请解释为何单用普通维生素D难以控制其骨病，还需什么。
::: solution
维生素D在肝内羟化为25-羟维生素D（即所测指标），而调控步骤是肾的1α-羟化，随有功能肾单位减少与klotho依赖性成纤维细胞生长因子23信号改变而衰竭。故轻度降低的25-羟维生素D应予纠正，但该情境下的继发性甲状旁腺功能亢进由磷潴留、骨化三醇缺乏与骨骼对甲状旁腺激素抵抗驱动。处理为降磷（膳食磷、随餐服用结合剂）、钙与维生素D的平衡、选择性使用维生素D受体激动剂或拟钙剂、纠正代谢性酸中毒、保证透析充分；难治者可能需甲状旁腺切除。安全提示：不控磷而给活性维生素D有发生高钙血症与血管钙化之虞。
:::
:::

::: exercise 那条禁食医嘱 {level=2}
一名84岁衰弱女性因股骨骨折入院。她独居，以面包与茶水度日，两月内减轻6 kg，19:00起被医嘱禁食以备“次晨手术”，而手术推迟到下午，又因检查改期再次通宵禁食。请写出营养计划。
::: solution
按任何筛查工具她都已属高危（六个月内非意愿体重下降超过5%、摄入差、高龄），而最大的一项改进是停止不必要的禁食：现代术前禁食允许至麻醉前2小时摄入清液，加速康复外科方案并使用碳水负荷饮品；应核对检查的指征与是否真正需要禁食，并把“禁食”写成有起始时间、有终止日期、需再评估的临时医嘱。随后：第一日请营养科会诊；摄入不足时给口服营养补充；蛋白取较高区间（骨折愈合按1.2–1.5 g/kg/日）；补充维生素D与钙；按其膳食补充硫胺素、叶酸与B₁₂；再喂养期间监测磷与钾；早期活动与康复；并写下术后喂养计划——若因谵妄或意识水平下降而延迟经口摄入，需言语治疗科评估喂养安全性。把预计的总禁食时间写入交班，可防止医院营养不良最常见的原因：它不是任何人做出的决定。
:::

::: exercise 读一张喂养单 {level=2}
一名长期居家肠外营养的患者出现帕金森综合征与小细胞性贫血伴中性粒细胞减少。应考虑哪两种微量元素问题？如何证实？
::: solution
方向相反的锰蓄积与铜缺乏。锰经胆排泄，在胆汁淤积与某些肠外营养配方中蓄积，引起具基底节特征信号的帕金森综合征，可在全血测定；处理是从配方中减少或去除锰并治疗胆淤。铜缺乏引起贫血（常伴中性粒细胞减少，重者有类似B₁₂缺乏的骨髓神经病），以血清铜与铜蓝蛋白衡量，并须考虑铜蓝蛋白作为急性期反应蛋白的行为；同时查锌，因为锌过量是铜缺乏的常见原因。这两点正是居家肠外营养需要按项目安排微量元素与肝功能监测，而不能只看热量与电解质的原因。
:::

::: exercise 肥胖门诊的推理 {level=3}
一名41岁男性，BMI 43，2型糖尿病4年，阻塞性睡眠呼吸暂停正用持续气道正压，高血压，因一段视频而询问胃旁路手术。转诊前你需要明确什么？关于取舍你又该告诉他什么？
::: solution
先明确疾病负担与共病的可逆性：HbA1c与糖尿病病程（病程长、已用胰岛素者缓解率低）、睡眠呼吸暂停能否随减重改善、血压控制、有无肝病与脂肪性肝纤维化、关节与反流症状（旁路改善反流，袖状胃可能加重）、生育计划，以及——最重要——他本人的目标与心理社会背景，包括既往治疗经历、与食物的关系、心境、创伤史与自杀风险。并确认多学科团队评估、戒烟，以及对终身补充、随访与抽血的实际承诺。然后是坦诚的取舍：代谢手术是现有最有效的长期体重与糖尿病干预，降低死亡与微血管结局，但不能“治愈”——会复发，糖尿病可能复发，体重回升常见；并发症（内疝、边缘溃疡、狭窄、胆石、倾倒、铁/B₁₂/叶酸/钙/维生素D与硫胺素缺乏）与再次手术真实存在，自杀风险亦升高。若他尚未准备手术，替代选择如今已有分量：带维持支持的结构化生活方式干预，以及可使部分患者减重15%以上的药物（并具心血管代谢益处）；药物与手术可以组合并序贯。无论选择什么，方案都必须活过最初的决策阶段。
:::

一名14月龄的难民营幼儿，身高别体重−3.4 SD，双足水肿，“漆皮样”皮疹，稀疏发红头发，并有腹泻。请按世界卫生组织方案写出最初48小时的处理，并说明那个“想当然”的干预为何有害。
::: solution
那个想当然的干预——立即高能量喂养——是有害的，因为饥饿患儿的胰岛素反应会把磷、钾与镁驱入细胞，而过多的钠与蛋白负荷会加重心脏与肾脏负担；治疗最初几日经典的死因即再喂养，答案是分阶段的方案。最初48小时：防治低血糖，频繁喂养（起始配方F-75，低钠低蛋白，每2–3小时一次，包括夜间），以贴身接触与覆盖防治低体温，用低钠补液盐小量多次纠正脱水，用含维生素A、锌、铜与B族的治疗性补充剂纠正微量营养素缺乏，给予广谱抗生素（因临床感染常缺如而发热也可无），在相关地区处理疟疾与麻疹，并在稳定期内不给口服铁。每日测体重，警惕再喂养失败的征象（水肿加重、呼吸与脉搏增快、腹胀、萎靡），若不能进食或呕吐、或出现休克与严重并发症，则升级为住院方案。待食欲恢复、水肿消退后，过渡到F-100或即食治疗性食品以求追赶生长，再回到后续膳食与照护者教育。就项目层面而言的教训是：这一方案是现代医学中最具成本效益的干预之一，而其成效取决于能识别水肿型营养不良——最常被漏诊的表现——的工作人员。
