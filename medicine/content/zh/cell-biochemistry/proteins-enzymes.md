患者的疾病往往就是一种不能工作的蛋白：缺失、构象错误、送错位置、失去调控，或被一个专门设计来嵌合其活性位点的分子阻断。镰状细胞病是肽链上的一个氨基酸。坏血病是某种酶因缺乏辅因子而不能羟化胶原。骨髓瘤是一个克隆制造的蛋白，以淀粉样物质沉积于肾。甲氨蝶呤之所以有效，是因为它比底物更贴合二氢叶酸还原酶。

本课谈两件事：一条多肽链如何成为有功能的蛋白，以及酶一旦存在之后如何表现。两者都有方程，也都各自连着临床检查。

## 氨基酸：字母表

蛋白是20种氨基酸的聚合物，以肽键头尾相接；每个残基都有相同的骨架——氨基、α-碳、羧基——而侧链各异。正是侧链使蛋白在化学上意味深长，并同时决定折叠与疾病。

| 类别 | 侧链 | 需要记住的临床要点 |
|---|---|---|
| 非极性 | Gly、Ala、Val、Leu、Ile、Pro、Met、Phe、Trp | 埋于疏水核心；螺旋紧密堆积处需要甘氨酸（胶原中该位置的甘氨酸缺失致病严重） |
| 极性不带电 | Ser、Thr、Cys、Tyr、Asn、Gln | 糖基化、磷酸化与二硫键的部位 |
| 带正电 | Lys、Arg、His | 结合DNA；组氨酸参与缓冲并位于许多活性中心 |
| 带负电 | Asp、Glu | 结合钙；层粘连蛋白与原纤维蛋白缺陷中常被突变的残基 |
| 芳香族 | Phe、Tyr、Trp | 280 nm紫外吸收（蛋白定量之据）；儿茶酚胺、甲状腺素与黑色素的原料 |

有两个性质值得记住。其一，**脯氨酸**是亚氨基酸，强制形成转折；受体胞外环或胶原中连续的脯氨酸在结构上是决定性的。其二，只有**半胱氨酸**的巯基在蛋白环境中pKa低到在生理pH即具反应性：它形成二硫键、配位锌，并且是烷化剂类药物的作用靶点。

蛋白还携带翻译后加上的化学基团：已知的修饰超过200种，医学上重要的是糖基化（内质网中N-连接，高尔基体中丝氨酸/苏氨酸连接）、胶原中脯氨酸与赖氨酸的羟化（依赖维生素C）、凝血因子Ⅱ、Ⅶ、Ⅸ、Ⅹ及蛋白C与S中谷氨酸的γ-羧化（依赖维生素K）、信号转导中的磷酸化，以及降解中的泛素化。一个修饰就是一个开关、一个地址标签，或一枚质控印章——而其缺失即是一种疾病。

::: example 一个残基，及其后果 {#ex-hbs}
一名西非血统的婴儿九月龄时出现手足肿痛（指趾炎），此后反复疼痛危象；电泳显示血红蛋白S。请解释其分子病变，并说明为何其后果与氧结合关系甚少。
::: solution
突变是β-珠蛋白链第6位的Glu→Val：链表面一个带电荷的亲水残基被一个疏水残基取代。在脱氧血红蛋白中，新出现的缬氨酸嵌入相邻四聚体的疏水口袋，于是血红蛋白S聚合成纤维状多聚体，把红细胞扭成镰形。其对氧的亲和力接近正常；疾病来自一个本不该存在的*相互作用界面*——僵硬的细胞阻塞微循环、溶血、功能性无脾，以及随之而来的卒中、胸部综合征与肾髓质损害。请注意两点可以推广之处：疾病可以由新出现的表面性质而非活性中心丧失引起；且该异常只在蛋白的某一构象状态（脱氧）中表现，这正是缺氧、酸中毒、脱水与发热都能诱发危象的原因。
:::
:::

## 一条链如何成为蛋白

::: definition 蛋白质结构的层次 {#def-structure}
**一级结构**是氨基酸序列。**二级结构**是由骨架氢键稳定的局部重复构象：α螺旋与β折叠，其间为转角与环。**三级结构**是一条多肽完整的三维排布。**四级结构**是若干多肽链（亚基）在一个功能蛋白中的排布，如血红蛋白的α₂β₂。
:::

维持折叠蛋白的力，单个而言很弱，合起来却高度特异：疏水效应（主要驱动力，掩埋非极性表面）、氢键、盐桥、紧密堆积核心内的范德华接触，以及二硫键——二硫键贡献稳定而非信息，主要见于分泌蛋白与处于氧化环境的区室。

::: theorem Anfinsen法则 {#thm-anfinsen}
对于体外的小球状蛋白，氨基酸序列已包含指定天然构象所需的充分信息；天然态是该条件下自由能最低的构象。
:::

::: proof
Anfinsen还原了核糖核酸酶的二硫键并用尿素使其去折叠；除去变性剂并允许重新氧化后，酶复性并恢复活性，而若在链仍处于去折叠状态时重新氧化，则多数产物无活性，需经巯基-二硫键交换才逐渐重排到正确配对。因此序列决定折叠，而折叠由热力学挑选。两个限定正构成临床要点。第一，试管中的产率只是部分，因为聚集与折叠竞争；在细胞内，分子伴侣（新生链上的Hsp70、Hsp60/GroEL样的伴侣蛋白桶、内质网中的calnexin与BiP）并不提供信息，只是在折叠发生之际阻止错误的相遇。第二，“自由能最低”意味着该状态依赖于条件：改变pH、温度、氧化还原状态或浓度，原本可溶的蛋白可能不再可溶。
:::

并非所有蛋白都是规整的球体。**纤维蛋白**是结构蛋白，序列高度重复：胶原（Gly–X–Y重复形成三股螺旋，羟脯氨酸以氢键稳定，分泌后由赖氨酰氧化酶交联）、角蛋白、弹性蛋白（含desmosine交联）与纤维蛋白。仅胶原即占体蛋白的四分之一，也是相当一部分遗传性结缔组织病之所在。

::: example 脆骨与蓝色巩膜 {#ex-oi}
一名足月儿出生时即有六处骨折、颅骨可压缩、双侧巩膜呈蓝色、四肢短小；父母健康且非近亲。胶原研究显示结构正常的α1链含量减少，另一α2链变异体泳动较快并延缓螺旋形成。属哪一类突变，为何如此严重？
::: solution
这是成骨不全，多由*COL1A1*或*COL1A2*中Gly–X–Y重复内强制性甘氨酸的点突变所致。由于三条链盘绕时甘氨酸堆积于三股螺旋的轴心，该位置任何较大的残基都会局部阻碍折叠；而链装配为异源三聚体，故变异链毒害整个分子——一种**显性负**（“结构型”）效应，因此未患病父母所生的孩子可以病情严重。相反，*COL1A1*的失活等位基因只是把正常胶原的量减半，故病情轻微（Ⅰ型），因为造出来的胶原是正常的。该规则——失活等位基因多为隐性、结构型等位基因为显性——贯穿整个基质疾病，包括Marfan综合征与Ehlers–Danlos谱系。
:::
:::

## 折叠出错之时

细胞有质量控制：伴侣蛋白给蛋白数次尝试，错误折叠分子被滞留在内质网并经内质网相关降解清除，持续的错误折叠触发未折叠蛋白反应。疾病发生于该系统被压垮、某一突变使聚集不可避免，或蛋白不稳定而被降解（**功能丧失型构象病**：最常见的重型囊性纤维化等位基因ΔF508在很大程度上是折叠与转运失败，这正是“矫正剂”针对伴侣相互作用而非通道本身的原因）。

聚集病共有同一结构母题：富含β折叠的淀粉样纤维，其中以肽骨架而非侧链成键，因此不同的蛋白可以形成同一类纤维。

| 淀粉样蛋白 | 前体蛋白 | 临床类型 |
|---|---|---|
| AL | 免疫球蛋白轻链 | 骨髓瘤；肾病综合征、心肌病、巨舌 |
| ATTR | 转甲状腺素蛋白（野生型或变异型） | 家族性淀粉样多神经病；老年男性野生型心脏淀粉样变 |
| Aβ、tau | APP；tau | 阿尔茨海默病 |
| α-突触核蛋白 | α-突触核蛋白 | 帕金森病、多系统萎缩 |
| 胰岛淀粉样多肽 | IAPP | 2型糖尿病的胰岛淀粉样沉积 |
| PrP | 朊蛋白 | 克-雅病、变异型克-雅病、库鲁病 |

**朊蛋白**是极端情形：正常宿主蛋白（PrP^C^，以α螺旋为主）的一种错误折叠构象（转变为富β的PrP^Sc^），可以把同样的改变模板式地加于其他分子。由于不涉及核酸，这种“感染”传递的是构象株系；基因突变时可遗传，而含该蛋白的组织可使其传播——故有尸体来源硬脑膜与人生长激素注射造成的医源性聚集，也造成聚集体对高压灭菌、甲醛与蛋白酶的抵抗。

::: warning “电泳发现蛋白异常”并不是对机制的诊断
血红蛋白S、一条异常免疫球蛋白带、一个变异的转甲状腺素蛋白、一份PrP免疫组化阳性：只告诉你该蛋白存在，且电荷、分子大小或构象不同。它们都不告诉你疾病是由于正常功能丧失、毒性获得功能，抑或两者兼有——而这一区分决定治疗是替代（凝血因子Ⅷ）、稳定与矫正（CFTR）、沉默（ATTR的反义策略），还是清除前体（AL淀粉样变中的克隆）。在把一项检验结果当作治疗计划之前，先问自己在治哪种机制。
:::

## 酶：催化剂能与不能做什么

酶加速的是趋近平衡的速率。它不能改变平衡，因为它对**过渡态**的稳定在两个方向上是等同的，只降低活化能ΔG‡；反应的ΔG°′丝毫不变。速率可提高10⁶–10¹²倍，其手段包括邻近与定向效应、底物结合产生的张力、组氨酸等残基的酸碱催化、共价催化（磷酸吡哆醛、生物素、焦磷酸硫胺素、硫辛酸）以及排除水。

维生素在很大程度上就是辅因子的原料：硫胺素→TPP，核黄素→FAD/FMN，烟酸→NAD⁺/NADP⁺，泛酸→辅酶A，吡哆醇→磷酸吡哆醛，生物素、叶酸、硫辛酸，以及金属离子Zn²⁺、Mg²⁺、Fe²⁺/³⁺、Cu²⁺、Se（如谷胱甘肽过氧化物酶中的硒半胱氨酸）。这就是为何一种缺乏会同时表现出多条途径的综合征，也是为何“该酶用哪种辅因子”既是可预测的考题，也是好的临床问题。

::: definition 米氏动力学 {#def-mm}
对于 $E + S \rightleftharpoons ES \to E + P$，底物浓度为 $[S]$ 时的初速度为
$$
v_{0} = \frac{V_{\max}\,[S]}{K_{m} + [S]},
$$ {#eq-mm}
其中 $V_{\max} = k_{\text{cat}}[E]_{\text{T}}$，$K_m = (k_{-1} + k_{2})/k_{1}$，即达最大速度一半时的底物浓度。当 $k_2$ 很小时 $K_m$ 近似ES的解离常数；$k_{\text{cat}}/K_m$ 为专一性常数，其上限由扩散速率决定。
:::

::: proof
设短暂过渡之后ES的浓度稳定，即生成（$k_1[E][S]$）等于消失（$k_{-1}[ES] + k_2[ES]$）：
$$
k_{1}[E][S] = (k_{-1} + k_{2})[ES]
\quad\Longrightarrow\quad
[E] = \frac{(k_{-1}+k_{2})[ES]}{k_{1}[S]} = \frac{K_m[ES]}{[S]}.
$$
酶总量为 $[E]_{\mathrm T} = [E] + [ES]$，故 $[E]_{\mathrm T} = [ES]\left(1 + K_m/[S]\right)$，于是
$$
[ES] = \frac{[E]_{\mathrm T}[S]}{K_{m} + [S]}.
$$
产物生成速率为 $v_{0} = k_{2}[ES] = V_{\max}[S]/(K_{m}+[S])$。请注意推导所需的前提：$[S] \gg [E]_{\mathrm T}$；取初速度以使产物尚未积累；以及稳态假设。当 $[S] \ll K_m$ 时对 $[S]$ 呈一级；当 $[S] \gg K_m$ 时呈零级，酶已全力运转。
:::

f: x/(Km+x); x/(Km*(1+c)+x); x/((1+c)*(Km+x))
x: 0, 12
y: 0, 1.3
sliders: Km=1:0.2:4; c=0:0:4

:::

::: definition 可逆抑制的类型 {#def-inhibition}
**竞争性**抑制：抑制药结合活性中心；表观 $K_m$ 增大，$V_{\max}$ 不变，可被更多底物克服（他汀之于HMG-CoA还原酶；甲氨蝶呤之于二氢叶酸还原酶；乙醇之于乙醇脱氢酶）。同一套代数也描述可逆的受体拮抗，如纳洛酮与氟马西尼，这就是“竞争性”与“可克服”在两门课中同时出现的原因。
**非竞争性**抑制：抑制药结合别处，使有功能的酶分子数减少；$V_{\max}$ 下降，$K_m$ 不变。
**反竞争性**抑制：抑制药只结合ES复合体，故表观 $V_{\max}$ 与 $K_m$ 以同一系数下降。该型在简单单底物酶中少见，而于双底物机制中常见，凡结合酶-底物复合体的药物皆呈此型。
**不可逆**抑制：共价或永久性灭活；恢复需要新的蛋白合成，故效应存续时间长于血药浓度，剂量比血药水平更要紧（阿司匹林之于环氧合酶，氯吡格雷之于P2Y12，有机磷之于乙酰胆碱酯酶，奥美拉唑之于H⁺/K⁺-ATP酶）。
:::

::: example 两位患者，两类阻断 {#ex-inh}
患者A服辛伐他汀40 mg，LDL 2.6 mmol/L；剂量加倍至80 mg只再降低6%。患者B每日服小剂量阿司匹林，血小板血栓素抑制完全，且持续整个血小板寿命，而阿司匹林的血浆半衰期仅约20分钟。请从酶动力学解释两者。
::: solution
他汀与底物HMG-CoA竞争HMG-CoA还原酶。在底物不变时升高抑制药浓度只移动表观 $K_m$，无法把 $V_{\max}$ 压低，而肝内胆固醇的反馈又上调转运体与该酶；因此治疗剂量范围内的剂量-反应曲线平缓，近似对数线性——所谓“6%法则”，即他汀剂量加倍约多得6%的LDL降低。阿司匹林则把环氧合酶通道内的一个丝氨酸乙酰化而使之不可逆失活。血小板无核，不能合成新酶，故被累及的血小板在其8–10天寿命内一直处于沉默；恢复取决于新生血小板，这正是出血时间延长一周、每日一次给药即够的理由。二者的临床推论也不同：A的应答可以通过减少底物需求来改善（依折麦布、胆酸螯合剂、PCSK9抗体），而不是同一药物加量；而B的效应除输注血小板外无从撤销，且其他NSAID若先服、占据同一部位，便会妨碍阿司匹林的不可逆乙酰化。
:::
:::

## 调控：细胞如何设定酶活性

一条途径只有在通量可被改变时才有意义。机制按起效速度由快到慢排列：

- **底物可得性**：许多酶工作在 $K_m$ 以下，或其通量受某一步底物浓度限制（尿素循环的底物限制；肝与胰岛β细胞中葡萄糖对糖酵解的质量作用，其中葡萄糖激酶的高 $K_m$ 使之成为感受器）。
- **别构控制**：效应物结合活性中心以外的位点而改变构象。别构酶给出**S型**而非双曲线的动力学，以Hill系数 $n_{\mathrm H}$ 描述，且通常是限速的、受调控的一步——磷酸果糖激酶-1（受ATP、柠檬酸与果糖-2,6-二磷酸调节）、天冬氨酸转氨甲酰酶、血红蛋白（受氧、质子、CO₂与2,3-BPG调节）。
- **共价修饰**：激酶磷酸化与磷酸酶去磷酸化，受激素控制（环磷酸腺苷介导的胰高血糖素与肾上腺素；激酶级联介导的胰岛素），另有腺苷酰化、尿苷酰化与氧化还原变化。要点在于放大：一个激素分子改变许多酶分子。
- **数量控制**：转录的诱导与阻遏（固醇与甲状腺激素受体），以及经泛素连接酶的降解控制——周期蛋白、IκB与低氧诱导因子之所以具有陡峭的时间过程，机制即在此。
- **区室化与隔离**：糖酵解在胞质，β氧化在线粒体，脂肪酸合成在胞质，中间由穿梭系统与转运体作为受调控的闸门（乙酰辅酶A羧化酶产物丙二酸单酰CoA抑制CPT1，既是常考之点，也是肌肉“燃脂”开关的道理所在）。
- **酶原激活**：不可逆的蛋白水解切割，见于消化酶与凝血——其激活不可逆，并在局部被抑制（抗凝血酶、α₁-抗胰蛋白酶）。

::: example 缺在错地方的酶 {#ex-g6pd}
一名地中海血统的青年因疟疾预防服用伯氨喹，出现腰痛、酱油色尿，血红蛋白由145降至78 g/L，血涂片见咬痕细胞与赫恩小体；六周后血涂片正常。请解释其动力学与遗传方式，并说明为何发作会自行停止。
::: solution
葡萄糖-6-磷酸脱氢酶是磷酸戊糖途径的限速酶，也是红细胞内NADPH的唯一来源。NADPH使谷胱甘肽保持还原，还原型谷胱甘肽再经谷胱甘肽过氧化物酶（一种含硒酶）清除过氧化氢——这是细胞对抗氧化负荷的防御。缺乏它时血红蛋白被氧化并沉淀为赫恩小体，脾脏巨噬细胞将其咬出（咬痕细胞），膜损伤导致血管内与血管外溶血。该病为X连锁，故半合子男性发病，杂合子女性因X失活而表现不一。发作自限，因为该酶在幼嫩红细胞中活性最高：骨髓释放的网织红细胞相对保有较多活性，能在氧化应激中存活，故即使继续用药血红蛋白也会稳定——这恰说明酶的临床严重度取决于含该酶细胞群体的动力学。同样的逻辑解释了本病的新生儿黄疸、使用氨苯砜、拉布立酶、伯氨喹或呋喃妥因前须筛查的原因，以及蚕豆可致同样后果。
:::

::: quiz
某酶测定在无药时 $V_{\max}$ 为120 µmol/min、$K_m$ 为2 mmol/L。加药后 $V_{\max}$ 不变仍为120 µmol/min，表观 $K_m$ 为8 mmol/L。发生了什么？
- [ ] 该药为非竞争性抑制。
- [x] 该药为竞争性抑制，将底物提高约四倍即可克服。
- [ ] 该药为不可逆抑制。
- [ ] 该药提高了 $k_{\text{cat}}$。
::: solution
$V_{\max}$ 不变而表观 $K_m$ 增大，是竞争性抑制的标志：底物饱和时抑制药被置换，仍可达同一最大速率。表观 $K_m$ 升高4倍，故需约4倍底物才达半最大速度——这就是“可克服”一词的含义。不可逆或非竞争性抑制会使 $V_{\max}$ 下降；改变 $k_{\text{cat}}$ 影响的也是 $V_{\max}$ 而非 $K_m$。
:::
:::

## 临床中的酶测定

血浆酶之所以被测定，并非因为其血浆活性有意义，而是因为其出现在血浆意味着细胞渗漏。三条约定值得注意：**IU**（所述条件下每分钟转化1 µmol底物）；必须同时报告方法与参考区间（不同实验室差别很大）；以及酶活性降低可能意味着生成器官的衰竭（营养不良儿童的碱性磷酸酶降低，或肝衰竭、有机磷中毒时的胆碱酯酶降低）。

同工酶提供一定的组织特异性：心肌的肌酸激酶MB与肌钙蛋白；骨、肝与胎盘的碱性磷酸酶；前列腺的酸性磷酸酶；LDH同工酶谱（现多已被影像与特异性检测取代）。由于酶按其自身半衰期从血浆消失，其*时程*具有诊断价值：肌酸激酶在心肌梗死后数小时内升高，而肌钙蛋白可持续升高一至两周。

::: history
Wilhelm Kühne于1877年将酵母的这种活性命名为“enzyme”，Eduard Buchner在1897年证明无细胞的酵母汁仍能发酵糖类。Emil Fischer1894年的锁钥模型经Daniel Koshland于1958年的诱导契合说加以扩展。Leonor Michaelis与Maud Menten于1913年在柏林发表了转化酶的Kinetics；G. E. Briggs与J. B. S. Haldane在1925年把处理改为本课所用的稳态形式，Linus Pauling则在1946年以过渡态稳定解释催化。James Sumner于1926年结晶脲酶、John Northrop结晶胃蛋白酶，确立了酶即蛋白质。镰状细胞病成为第一种“分子病”——1949年Linus Pauling以生物化学证明患者血红蛋白泳动不同，1956年Ingram指出那一个氨基酸的改变——而Christian Anfinsen的核糖核酸酶折叠实验（1972年诺贝尔奖）使蛋白折叠成为实验科学。Stanley Prusiner的朊病毒概念获1993年诺贝尔奖，是同一思想最奇异的后代：一种只靠构象传递的表型。
:::

## 通向何处

膜与转运体如何服从同样的动力学见[[cell-biochemistry/membranes-transport]]；此处所述酶的激素调控见[[cell-biochemistry/metabolic-integration]]；胶原与原纤维蛋白突变如何损害主动脉与骨骼见[[pathology/cell-injury]]与[[musculoskeletal/connective-tissue-vasculitis]]；抑制剂如何成为药物见[[pharmacology/drug-receptor]]。

::: summary
- 二十种氨基酸，一种骨架；侧链决定电荷、溶解度、反应性（半胱氨酸）与能否紧密堆积（甘氨酸、脯氨酸）。
- 结构分四级；疏水效应驱动折叠，Anfinsen法则认为序列已足够——伴侣蛋白防止途中聚集，而条件可以解除折叠。
- 胶原是最丰富的蛋白，其甘氨酸重复解释了为何单个取代可呈显性负效应。
- 错误折叠致病有三种方式：功能丧失（ΔF508）、毒性聚集（淀粉样变）、可传播的构象（朊病毒）；机制决定治疗。
- 酶降低活化能而绝不改变ΔG°′；米氏动力学源于稳态假设，$K_m$、$V_{\max}$ 与 $k_{\text{cat}}/K_m$ 各有明确含义。
- 抑制类型按其作用于 $K_m$ 与 $V_{\max}$ 的方式区分；不可逆抑制使作用时长取决于蛋白更新而非血浆半衰期。
- 通量受底物、别构效应物、共价修饰、酶量、区室化与酶原激活调控。
- 血浆酶是细胞损伤的标志；同工酶与时程提供定位。
:::

## 练习

::: exercise 电荷与电泳 {level=1}
在pH 7.4时写出Asp、Lys、His与Tyr侧链的电荷，并解释为何Glu→Val取代使血红蛋白向阳极泳动变慢。
::: solution
Asp带负电（pKa约3.9），Lys带正电（约10.5），His在pH 7.4大部分未质子化而为中性，但其pKa（约6.0）使其在生理pH附近既是有效缓冲又能充当活性中心残基，Tyr基本不解离（pKa约10），尽管少数活性中心酪氨酸的酚盐形式很重要。Glu→Val以一个中性疏水侧链取代负电荷，使β链净负电荷减少；故在碱性电泳中血红蛋白S比血红蛋白A向阳极泳动更慢——经典分离方法正是据此。
:::
:::

::: exercise 四个层次 {level=1}
就结构层次（一级；二级/四级装配；翻译后修饰；降解/分选）各举一种相关疾病。
::: solution
一级：镰状细胞病（单个取代）或β-地中海贫血无义突变。装配：成骨不全或Marfan综合征（变异链毒害多聚体）；丙酮酸激酶缺乏的四级结构缺陷亦属此类。翻译后修饰：坏血病（羟化不足、交联障碍的胶原）、Ⅱ型成骨不全，或维生素K缺乏所致出血（羧化不足的凝血因子）。降解/分选：ΔF508囊性纤维化（滞留并降解）、I细胞病（缺乏甘露糖-6-磷酸地址），以及内质网贮积病。
:::

::: exercise 读图 {level=1}
某酶 $V_{\max}$ 为200 U，$K_m$ 为5 mM。在5 mM与15 mM时达 $V_{\max}$ 的几分之几？并说明为何在高底物时 $K_m$ 翻倍影响甚小。
::: solution
当 $[S] = K_m$，$v/V_{\max} = 0.5$（100 U）。在15 mM时，$v/V_{\max} = 15/20 = 0.75$（150 U）。底物远高于 $K_m$ 时酶已近饱和，故 $K_m$ 变化两倍只轻微改变结合比例（$15/(10+15) = 0.6$ 对 0.75——确实有影响，但远小于低底物时）。这就是竞争性抑制在底物浓度接近或低于 $K_m$ 时最为要紧的原因，也是此类酶上的药物作用取决于生理底物水平的原因（如蔗糖酶抑制与膳食碳水化合物）。
:::

::: exercise 酶单位 {level=2 check=“4000”}
3 mL反应体系中加血清30 µL。2分钟内产物增加0.24 µmol。以U/L报告该血清的活性（1 U = 1 µmol/min）。
::: solution
反应体系内的速率 $= 0.24/2 = 0.12\ \mu\text{mol} = 0.12$ U。这是30 µL血清所含活性，故每升为 $0.12 / (30 \times 10^{-6}\ \text{L}) = 4000$ U/L。请注意学生常丢分的两个稀释因素：样本体积与反应时间；而反应体系的总体积并不进入计算。
:::

::: exercise 协同性与Hill图 {level=2}
血红蛋白结合氧的 $n_{\mathrm H} \approx 2.8$，肌红蛋白为双曲线。请说明协同性的结构基础、生理意义，以及2,3-二磷酸甘油酸的作用。
::: solution
协同性源于氧结合使四聚体由紧张态（T）转为松弛态（R）：R态中血红素更契合，抵抗氧结合的盐桥被破坏；第一次结合使下一次更容易，故 $n_{\mathrm H} > 1$ 而曲线呈S形。其益处是装载-卸载的设计：在肺内 $p_{\mathrm O_2}$ 高时接近饱和，在组织中 $p_{\mathrm O_2}$ 小幅度下降即可释放大量的氧。肌红蛋白为单体，必须是双曲线并在组织 $p_{\mathrm O_2}$ 下紧紧持有氧——它是贮库而非运输者。2,3-BPG结合于T态的中央空腔，稳定T态并使曲线右移（亲和力下降），故其在慢性缺氧与库存血中升高；胎儿血红蛋白的γ亚基结合2,3-BPG较差，故胎儿血亲和力更高，得以在胎盘摄取氧。
:::
:::

::: exercise 伴侣疗法 {level=2}
解释为何“矫正剂加增强剂”可改善ΔF508囊性纤维化，而对G542X这类无义突变无效；并指出后者属于哪一类药物。
::: solution
ΔF508缺失核苷酸结合结构域1中的苯丙氨酸；该通道若能到达膜，其功能尚可，但折叠与装配失败并被内质网质量控制系统降解。矫正剂结合疏水斑块，帮助蛋白逃离降解到达表面；增强剂则提高已到达蛋白的开放概率。G542X使蛋白截短，没有全长分子可救：读通药物（氨基糖苷类样及新药）旨在让核糖体忽略终止密码子，反义或基因替代则绕开它；表型还取决于生成多少正常蛋白，这正是同一突变表现度可以多变的原因。一般原则是——治机制，不治基因——这也是“一种囊性纤维化药”被突变特异性治疗取代的理由。
:::

::: exercise 折不起来的折叠 {level=3}
一名肾病综合征合并心肌病的患者，其沉积物刚果红阳性、苹果绿双折射，抗λ轻链染色阳性。另一名78岁患者射血分数保留的心衰，既往双侧腕管综合征，同样刚果红阳性但分型为转甲状腺素蛋白。请比较两者的治疗逻辑。
::: solution
两者皆为淀粉样变，沉积物都是富含β折叠的错误折叠蛋白——但前体、生成部位与可逆性不同。AL淀粉样变来自浆细胞克隆，故治疗是血液学的：抑制或清除克隆（以硼替佐米、达雷妥尤单抗或自体移植为基础的方案），并接受既存沉积消退缓慢、器官功能可能无法恢复这一事实；疗效以游离轻链与影像监测。ATTR来自肝脏合成的转运蛋白，故选择是稳定四聚体（氯苯唑酸，减少其解离为致病单体）、以药物沉默肝内mRNA（patisiran、vutrisiran、inotersen）、基因编辑，或在选择性心脏病例中移植。野生型ATTR的“为何是现在”是年龄与男性优势，而腕管综合征早于心衰数年出现，是值得记住的诊断线索。两位患者都不是靠清除纤维治疗，也不是靠纠正折叠缺陷治疗——机制决定靶点。
:::

::: exercise 中毒中的酶动力学 {level=3}
疑诊甲醇中毒。过去曾用乙醇阻断其代谢。请用 $K_m$ 与竞争性抑制的概念解释为何有效，为何即使甲醇浓度下降缓慢仍须持续给药数小时，以及现在的替代方案。
::: solution
甲醇本身相当无害；毒性来自乙醇脱氢酶继而醛脱氢酶生成的甲醛与甲酸，后者导致视力损害与代谢性酸中毒。乙醇是同一种酶的竞争性底物，对酶的亲和力远高于甲醇，占据活性中心即阻断毒性代谢物的生成；母体甲醇随后经肾与肺缓慢清除，半衰期以小时计，故乙醇输注须持续到甲醇不能检出；水平高、酸中毒或有视力症状时应血液透析以移除甲醇（与甲酸）。目前常用4-甲基吡唑（fomepizole）：一种竞争性乙醇脱氢酶抑制剂，效价远高于乙醇，动力学可预测且无镇静作用，因此无需监测血醇浓度。请注意这是对前述测验的反转——此处你要挡在酶之外的“底物”正是毒物，而你给的抑制剂本身是竞争底物。
:::

::: exercise 显性负的算术 {level=3}
若某种结构型胶原突变产生的α2链变异体与正常α1链随机装配成组成为α1(I)₂α2(I)的三聚体，问至少含一条变异链的三聚体比例是多少？并预测为何该表型比50%的单倍体不足更重。
::: solution
设正常与变异的α2链等量，则一个三聚体的两条α2链皆正常的概率为 $(1/2)^{2} = 1/4$，故 $3/4$ 的三聚体至少含一条变异链而结构异常，而胶原总量可接近正常。这比只使总量减半、但每个分子都正常的失活等位基因更糟——由此形成从轻度脆骨病（量缺陷）到围产期致死型（同一基因的结构缺陷）的临床梯度。该算术适用于任何亚基混合的多聚体蛋白：血红蛋白、层粘连蛋白、连接蛋白与p53都呈显性负行为，受累比例取决于亚基的化学计量。
:::
