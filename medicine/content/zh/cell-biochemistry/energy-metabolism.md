人体在任何时刻大约含有50克ATP，而每天水解的量约以其体重计。仅此一点就组织了整个代谢：ATP不是贮库，而是通货，靠一个若非寻常则足以惊人的合成速率维持在较高浓度。静息者每天把全部ATP池重新合成约一千次，收入来自食物，支出则在肌肉收缩、离子泵送与生物合成。

本课追随从葡萄糖到二氧化碳的流向：胞质中的糖酵解、基质中的三羧酸循环、内膜上的氧化磷酸化——以及与之进出相连的两条路径，糖异生与糖原代谢。途径的临床疾病是医学中最优雅的，因为每一种病恰好揭出所缺失的那一步。

## 钱：ATP、磷酸肌酸与自由能

::: definition 能量通货 {#def-atp}
**ATP**是放能反应与耗能反应之间的中间物。其水解在标准条件下 $\Delta G^{\circ\prime} \approx -30.5\ \text{kJ}\,\text{mol}^{-1}$，而在细胞内约$-55\ \text{kJ}\,\text{mol}^{-1}$，因为细胞把ATP/ADP比值维持在远离平衡的状态——一个小而高电荷的分子被保持于待命状态。**磷酸肌酸**在肌与神经中经肌酸激酶为ATP浓度提供数秒的缓冲；**GTP**与之等价，由核苷二磷酸激酶互换。
:::

食物供能有三式：糖与脂肪彻底氧化为CO₂与水、无氧糖酵解生成乳酸、以及氨基酸的氧化。每克热值约为糖与蛋白17 kJ（4 kcal）、脂肪38 kJ（9 kcal）；**呼吸商**（CO₂产生量÷O₂消耗量）可指认所氧化的底物：糖为1.0，脂肪约0.7，蛋白约0.8，故静息混合膳食约0.82。由于无论有无氧ATP都要被消耗，随氧改变的是*产出*，而不是需要。

## 糖酵解：十步，两条规则

糖酵解在胞质中把葡萄糖转为丙酮酸，每分子葡萄糖净产2 ATP与2 NADH，且不需氧。值得记住的是其形状而非每个酶名：

- **投入阶段（第1–5步）**。葡萄糖被磷酸化（多数组织为己糖激酶，肝与β细胞为葡萄糖激酶）、异构化、再次磷酸化，并裂解为两个三碳糖。两次磷酸化消耗2 ATP，而更重要的是把糖困在细胞内——磷酸化的中间物不能跨越质膜。
- **回收阶段（第6–10步）**。每个三碳糖被氧化并捕获NADH，底物水平磷酸化产出4 ATP；净结果为2 ATP与2分子丙酮酸。

有三步实际上不可逆，因而也是调控点：己糖激酶/葡萄糖激酶、**磷酸果糖激酶-1（PFK-1）**与丙酮酸激酶。

PFK-1是限速酶，也是主要的控制点。它被ATP与柠檬酸抑制（表示细胞能量充足且循环底物充裕），被AMP激活，而最强的激活剂是**果糖-2,6-二磷酸**——它由一个双功能酶的激酶活性段生成，胰岛素使其磷酸化而胰高血糖素使其去磷酸化。肝因此不会自我竞争：一次磷酸化事件降低果糖-2,6-二磷酸，既减慢糖酵解又解除对果糖-1,6-二磷酸酶的抑制，于是葡萄糖生成增加。

己糖激酶与葡萄糖激酶是设计上的对照。己糖激酶$K_m$低、被葡萄糖-6-磷酸抑制，服务于普通细胞。**葡萄糖激酶**$K_m$高、不被产物抑制、且由胰岛素诱导——于是肝摄取葡萄糖随血糖升高而不会被自身产物关闭。它同时是β细胞的葡萄糖感受器，这解释了为何*GCK*失活突变导致轻度稳定的空腹高血糖（青少年发病的成人型糖尿病2型，MODY 2），完全失活导致永久性新生儿糖尿病，而获得功能突变导致先天性高胰岛素血症。

::: theorem 红细胞的困境 {#thm-rbc}
成熟红细胞既无线粒体也无核糖体：其全部ATP来自糖酵解，不能合成任何物质，并依赖磷酸戊糖途径提供NADPH。因此它的命运由不依赖氧的ATP生成，以及[[cell-biochemistry/proteins-enzymes]]中所述的抗氧化防御决定。
:::

::: proof
红细胞在成熟过程中排出细胞核并销毁细胞器，为血红蛋白腾出空间。没有线粒体，氧化磷酸化即不可能，故驱动阳离子泵、维持变形能力的ATP只能来自糖酵解——其中大部分耗于把钠排出陡梯度的Na⁺/K⁺-ATP酶。没有核糖体，受损蛋白便无法更换，这决定了约120天的寿命，也解释了为何在其他组织尚可耐受的酶缺陷在此引起溶血：丙酮酸激酶缺乏与葡萄糖-6-磷酸脱氢酶缺乏都是慢性溶血性贫血，而多数其他组织功能正常。红细胞还运行2,3-二磷酸甘油酸支路（绕过磷酸甘油酸激酶一步，故不获得ATP），由此制造出降低血红蛋白氧亲和力的分子：正是这个不能靠氧化供能的细胞，决定了氧被结合的紧密程度。
:::

**丙酮酸的去路**是全局的枢纽。当氧可供、线粒体在工作时，丙酮酸脱氢酶将其氧化脱羧为乙酰CoA。当呼吸链不能运转——缺氧、休克、氰化物、硫胺素缺乏——乳酸脱氢酶再生NAD⁺以使糖酵解继续，乳酸于是聚积。乳酸并非废物：心与静息肌肉偏好以它为燃料，运动肌肉将其输出，肝则经**Cori循环**将其回化为葡萄糖，代价由肝承担而收益归肌肉。

## 从乙酰CoA到NADH：三羧酸循环

在人体中乙酰CoA不能净转为葡萄糖，因为循环的两次脱羧不可逆，也不存在由乙酰单位净生成四碳中间物的途径。它能做的是被烧掉。

循环一转把一个乙酰基氧化为两分子CO₂，产出3 NADH、1 FADH₂与1 GTP，并再生草酰乙酸。除图示之外有三点值得强调：

- **循环在底物进入之处受调控。**丙酮酸脱氢酶被磷酸化关闭，其自身的激酶在乙酰CoA与NADH充裕、ATP富足时促进磷酸化；胰岛素、钙与持续运动激活使之复活的磷酸酶。异柠檬酸脱氢酶与α-酮戊二酸脱氢酶受ADP与Ca²⁺刺激。
- **它是生物合成的枢纽，而非仅是氧化之所。**柠檬酸外出用于脂肪酸与胆固醇合成；α-酮戊二酸用于氨基酸与谷胱甘肽；琥珀酰CoA用于血红素；草酰乙酸用于糖异生与天冬氨酸。为合成而移走的中间物必须由**回补**反应补充，主要是丙酮酸羧化酶（依赖生物素）。
- **脂肪要在碳水存在时燃烧。**乙酰CoA缩合需要草酰乙酸；若糖稀缺而草酰乙酸被糖异生取用，乙酰CoA便聚积并在肝中转为酮体。这一单纯的化学计量事实解释了饥饿时的酮症与糖尿病酮症酸中毒。

## 氧化磷酸化：质子的经济

还原型辅酶由呼吸链重新氧化，而其自由能只用于一件事：把质子泵出基质。复合体Ⅰ、Ⅲ、Ⅳ泵送；辅酶Q与细胞色素c在其间传递电子；复合体Ⅴ（ATP合酶）让质子回流并利用其转矩合成ATP。每分子NADH约泵出10个质子，而生成并输出一个ATP约需3–4个质子，故现代的P/O比约为**每NADH 2.5 ATP、每FADH₂ 1.5 ATP**——旧教材的3与2，以及学生由此记下的每分子葡萄糖36–38 ATP，都偏高。

::: example 把ATP算对 {#ex-atp}
以P/O比2.5与1.5计算一分子葡萄糖彻底氧化的ATP产量。
::: solution
底物水平磷酸化：糖酵解净2 ATP，循环产生2 GTP（每一乙酰CoA一个），合计4。
还原型辅酶：糖酵解产2个胞质NADH，主要经苹果酸-天冬氨酸穿梭入基质，故$2 \times 2.5 = 5$；丙酮酸脱氢酶产2 NADH = 5；循环产6 NADH = 15与2 FADH₂ = 3。
合计$= 4 + 5 + 5 + 15 + 3 = 32$ ATP。在骨骼肌，胞质NADH主要经3-磷酸甘油酸穿梭重新氧化，其电子直达辅酶Q，故两分子糖酵解NADH各得1.5，总数为30。两数都相当于葡萄糖燃烧自由能的约34%被捕获为磷酸键，其余以热散失——当目的正是保暖时，这热并不浪费。
:::
:::

::: warning 36还是38 ATP？
经典数字假定P/O比为3与2，至今仍印于旧版教材与某些考试答案中。它们还忽略了把胞质NADH运入线粒体的代价，而该代价在不同组织间不同；质子漏又使偶联部分“漏电”。请引用约30–32 ATP每分子葡萄糖，说明为何这是一个范围，并把穿梭视为肌与肝差异的原因；若考试或本地规范沿用旧数，则使用旧数并注明如此。
:::

膜电位还承载着细胞对同一梯度的第二大用途：产热。**解偶联蛋白1**（UCP1）在棕色脂肪中让质子不经ATP合成而回流，于是呼吸持续而产出热量——这是新生儿非战栗产热的机制，也是受寒成人PET上可见代谢活跃棕色脂肪的原因。人工解偶联剂则不加调控地做同一件事：2,4-二硝基苯酚曾被作为减肥药出售并致患者死于高热；水杨酸中毒部分经此途径引起发热、多汗以及呼吸性碱中毒合并代谢性酸中毒的混合型。

| 作用物 | 作用部位 | 后果 |
|---|---|---|
| 鱼藤酮、阿米妥 | 复合体Ⅰ | 阻断NADH氧化；实验上用于制作帕金森病模型 |
| 抗霉素A | 复合体Ⅲ | 阻断泛醌之后的全部电子流 |
| 氰化物、一氧化碳、叠氮 | 复合体Ⅳ | 电子不能到达O₂；细胞在含氧良好的血液中窒息 |
| 寡霉素 | 复合体Ⅴ | 质子不能回流；梯度无法释放，呼吸随之停止 |
| 解偶联剂（2,4-二硝基苯酚、FAM、UCP1） | 内膜 | 呼吸加快，ATP下降，产热 |

::: example 不肯交出氧的血液 {#ex-cn}
两人被从住宅火灾中救出，皆昏迷，乳酸14 mmol/L。一人碳氧血红蛋白28%；另一人碳氧血红蛋白正常，静脉血氧饱和度92%并有严重乳酸酸中毒。请分别解释。
::: solution
两人都是细胞内窒息，但机制与所需检验不同。碳氧血红蛋白降低血的携氧能力，并且更隐蔽地把氧解离曲线左移，使所携的氧更不易释放；脉搏血氧仪把它读作氧合血红蛋白，故读数正常不足为凭，必须用多波长血氧定量法。火灾烟气中的氰化物（塑料与毛料燃烧时皆有）结合细胞色素氧化酶的高铁铁，使氧化磷酸化完全停止：细胞不能摄取氧，于是静脉血异常富氧地离开组织（混合静脉血氧高、动静脉差窄），乳酸因无氧糖酵解增加、并因清除减少而升高。治疗对应机制：一氧化碳用100%氧（选择性病例用高压氧），氰化物用羟钴胺（结合氰形成氰钴胺），或用较老的亚硝酸盐/硫代硫酸盐方案——以后者生成高铁血红蛋白作为氰的“陷阱”，并提供硫供硫氰酸酶使用。火灾受害者若有不能解释的乳酸升高而碳氧血红蛋白正常，应按氰化物中毒处理。

## 糖异生：昂贵的制糖之道

脑每天消耗约120 g葡萄糖，红细胞与肾髓质还要更多；肝糖原大约只够一天之用。两餐之间与饥饿时，葡萄糖必须由三种底物制造：**乳酸**（Cori循环）、**甘油**（来自脂肪组织三酰甘油，也是脂肪中唯一能变成葡萄糖的部分）与**氨基酸**，尤其是肌蛋白来源的丙氨酸与谷氨酰胺，其氮由尿素循环处理。

四步反应绕过糖酵解的不可逆步骤，每一处都是临床考点：

| 绕行 | 酶 | 要点 |
|---|---|---|
| 丙酮酸 → 草酰乙酸 | 丙酮酸羧化酶 | 线粒体、依赖生物素、被乙酰CoA绝对激活 |
| 草酰乙酸 → 磷酸烯醇式丙酮酸 | 磷酸烯醇式丙酮酸羧激酶 | 以苹果酸或天冬氨酸形式离开线粒体 |
| 果糖-1,6-二磷酸 → 果糖-6-磷酸 | 果糖-1,6-二磷酸酶 | 被果糖-2,6-二磷酸抑制 |
| 葡萄糖-6-磷酸 → 葡萄糖 | 葡萄糖-6-磷酸酶 | 仅肝、肾与肠——这就是肌肉不能输出葡萄糖的原因 |

其成本为每分子葡萄糖4 ATP与2 GTP，因此糖酵解与糖异生同时进行的底物循环并非单纯浪费：小量的底物循环放大激素调控，并在棕色脂肪与肌肉中产热。

::: example 不能禁食的孩子 {#ex-gsd1}
一名九月龄、已改为三小时一次喂养的婴儿，在呕吐一夜后抽搐就诊。患儿消瘦、腹部膨隆、肝大质硬、呈“娃娃脸”。血糖1.4 mmol/L，乳酸7.8 mmol/L，pH 7.20，尿酸640 µmol/L，甘油三酯9 mmol/L；肝酶轻度升高；持续输注葡萄糖12小时后肝脏缩小。阻断在哪一步，乳酸为何升高？
::: solution
这是糖原贮积病Ⅰ型（von Gierke病），葡萄糖-6-磷酸酶缺乏，故糖原分解与糖异生都不能完成最后一步：葡萄糖-6-磷酸生成却无法释放。其后果皆由这一被围困的代谢物推得。G6P分流进入糖酵解，故丙酮酸与乳酸升高；乳酸又与尿酸竞争肾排泄，遂有高尿酸血症与日后痛风；多余乙酰CoA驱动脂肪生成，故高甘油三酯血症与黄瘤；糖原与脂肪使肝增大；一旦喂养间隔延长即出现低血糖与酮症。与糖原磷酸化酶或脱支酶缺陷的鉴别在于，后两者糖异生完好、禁食间期乳酸正常。处理是机械性的——频繁喂养与生玉米淀粉以提供缓慢的葡萄糖涓流——而且有效；未治儿童死亡，或发生腺瘤、肾病与肺动脉高压。
:::
:::

## 糖原：有分支的缓冲库

::: definition 糖原 {#def-glycogen}
**糖原**是动物的葡萄糖贮存形式：以α-1,4糖苷键相连的链，每8–12个残基左右有一个分支点，分支以α-1,6键连接，整个分子由蛋白引物糖原素（glycogenin）向外构建。它高度分支、高度水化并位于胞质，主要储存于肝（以维护血糖为调控目标）与肌肉（以维护自身ATP为调控目标）。
:::

糖原以α-1,4链与α-1,6分支点储存葡萄糖，使非还原端的数目倍增，从而倍增磷酸化酶可以作用的位点。合成以UDP-葡萄糖为底物，在糖原素的引物上由糖原合酶催化（去磷酸化时活跃，即胰岛素状态下），并需要分支酶制造α-1,6键。分解使用糖原磷酸化酶（磷酸化时活跃，受肾上腺素与胰高血糖素调节，在肌肉中还受钙调节——这正是收缩与燃料之间的联系）以及脱支酶的两种活性。

糖原贮积病可以按酶逐一读出来，而其表现按器官归类：

| 型 | 缺乏 | 特征 |
|---|---|---|
| 0 | 糖原合酶（肝） | 空腹酮症性低血糖，*无*肝大 |
| Ⅰ | 葡萄糖-6-磷酸酶 | 严重空腹低血糖、乳酸酸中毒、高尿酸血症、高脂血症、肾大 |
| Ⅱ（Pompe） | 溶酶体酸性α-葡萄糖苷酶 | 心肌病、肌张力低下、巨舌；可用酶替代治疗 |
| Ⅲ（Cori） | 脱支酶 | 肝大与低血糖但较轻；肌病与CK升高 |
| Ⅳ（Andersen） | 分支酶 | 肝硬化与生长停滞；异常多糖贮积 |
| Ⅴ（McArdle） | 肌糖原磷酸化酶 | 运动不耐受、肌痛、肌红蛋白尿、“第二次呼吸” |
| Ⅶ | 磷酸果糖激酶（肌） | 与Ⅴ相似，并有溶血与高尿酸血症 |

::: example 痛性痉挛与平坦的乳酸 {#ex-mcardle}
一名24岁举重训练者终生在冲刺后出现痉挛与深色尿，但短暂休息后已可行走而不症状发作。发作间期肌酸激酶900 U/L。前臂运动试验显示氨由45升至190 µg/dL，而乳酸仅由0.9升至1.0 mmol/L。请诊断并解释“第二次呼吸”。
::: solution
缺血性运动时乳酸不能升高、而氨反应正常，把阻断定位到肌肉的糖原分解或糖酵解：肌磷酸化酶缺乏（糖原贮积病Ⅴ型，McArdle病）。氨升高是因为嘌呤核苷酸循环反映肌肉的能量应激，故“氨正常升高而乳酸平坦”可把糖原分解缺陷与过度用力或表现不佳区别开。肌肉ATP在剧烈运动后数秒内耗竭，膜兴奋性丧失，患者出现类似挛缩的疼痛与横纹肌溶解、肌红蛋白尿，以及急性肾损伤风险。“第二次呼吸”发生于数分钟轻度运动之后，因心率与血管扩张使血中葡萄糖与游离脂肪酸得以供应——燃料不需要肌糖原磷酸化酶——这就是为何推荐的处方是短时热身后的中等强度有氧运动，而不是停止活动。等长与高强度运动、以及空腹运动才是危象的诱因；运动前摄入碳水化合物有帮助。
:::

::: quiz
肿瘤以高速率摄取葡萄糖，并在完全供氧时产生乳酸。为何这一特性对¹⁸F-氟脱氧葡萄糖成像有用？
- [x] 葡萄糖被摄取并磷酸化，而已结合的FDG-6-磷酸不能进一步代谢，故按摄取比例滞留。
- [ ] 肿瘤细胞无线粒体，糖酵解是其唯一ATP来源。
- [ ] FDG只经GLUT1转运，而只有肿瘤表达GLUT1。
- [ ] 信号取决于血流而非糖代谢。
::: solution
FDG是葡萄糖类似物，经GLUT转运体摄取并由己糖激酶磷酸化，但其2位氟使磷酸葡萄糖异构酶无法继续代谢，于是按糖流入细胞的通量滞留——此为肿瘤、感染与炎症PET成像的基础，也是三者重叠时须谨慎的原因。Warburg效应（有氧糖酵解）确实存在，但它是致癌信号与生物合成需求的结果，并不表示肿瘤细胞呼吸能力差：多数肿瘤线粒体功能正常。
:::

::: history
Otto Meyerhof与Otto Cori在1920年代阐明了肌肉如何把糖原转为乳酸、肝如何把乳酸回化为葡萄糖，与Carl Cori共获1947年诺贝尔生理学或医学奖（同获者还有Houssay）。Harden与Young在1906年前后于酵母中发现己糖磷酸酯，糖酵解中间物在此后数十年间自酵母与肌肉提取物中陆续析出。Karl Lohmann于1929年在肌肉中鉴定ATP，Fritz Lipmann于1945年描述辅酶A，使乙酰基的转移得以理解；Hans Krebs在1937年勾勒出以他命名的循环，其全部酶学步骤又花了十年方才补齐。Eduard Buchner 1897年的无细胞发酵在原理上使这一切成为可能。Otto Warburg早在1923年即注意到肿瘤即使在氧中也旺盛酵解，这一观察如今被用于成像。Peter Mitchell的1961年化学渗透假说历经十七年与一座诺贝尔奖方被接受；John Walker课题组1986年自牛线粒体解析出ATP合酶F1部分的晶体结构、并于1994年细化，揭示了Paul Boyer的结合变构机制所预言的旋转机器——Walker、Boyer与Jens Skou共获1997年诺贝尔奖。Skou 1957年发现的钠钾ATP酶则完成了ATP究竟花在何处的图景。
:::

## 通向何处

途径在餐后与空腹时如何被整合，见[[cell-biochemistry/metabolic-integration]]；脂肪与氨基酸如何进入途径，见[[cell-biochemistry/lipid-amino-acid-metabolism]]；低血糖与糖尿病急症的临床生理由[[endocrine/diabetes]]与[[endocrine/diabetes-complications]]承担；组织缺氧与休克见[[emergency-critical-care/shock-fluids]]。

::: summary
- ATP是通货而非贮库：池很小而每日周转约千次；磷酸肌酸缓冲数秒；细胞内水解$\Delta G$远偏离标准值。
- 糖酵解无氧净产2 ATP与2 NADH，受PFK-1按ATP、AMP与果糖-2,6-二磷酸调控，且是红细胞唯一的ATP来源。
- 丙酮酸是枢纽：呼吸链工作时进入乙酰CoA，不能工作时变成乳酸；乳酸既是燃料也是糖异生底物，而非仅仅是废物。
- 三羧酸循环既是氧化之所也是合成枢纽；人体中乙酰CoA不能净生成葡萄糖，而草酰乙酸的可得性决定脂肪是被完全氧化还是转为酮体。
- 氧化磷酸化把电子流与质子梯度偶联：每NADH约2.5、每FADH₂约1.5 ATP，每分子葡萄糖约30–32 ATP；抑制剂与解偶联剂各有其特征性临床图像。
- 糖异生以6个核苷三磷酸绕过三步不可逆反应，而只有肝、肾与肠能释放葡萄糖，因为只有它们有葡萄糖-6-磷酸酶。
- 糖原以分支倍增可用的葡萄糖端；其酶病分为肝型（低血糖、肝大）与肌型（痉挛、肌红蛋白尿），前臂运动试验可将其与相似疾病区分。
:::

## 练习

::: exercise 哪个穿梭？ {level=1}
写出胞质NADH还原当量进入线粒体的两种穿梭，指出各以何组织为主，并说明为何其中一种产出较低。
::: solution
苹果酸-天冬氨酸穿梭把电子交给基质NAD⁺，工作于肝、肾、心（以及大部分）脑，每分子胞质NADH得2.5 ATP。3-磷酸甘油酸穿梭还原内膜外表面的FAD，电子进入辅酶Q而绕过复合体Ⅰ，主导于骨骼肌与白色脂肪，得1.5 ATP。故葡萄糖氧化总产率在肝约32、在肌肉约30——这一差异既有生化趣味，在力竭性运动试验中也有若干生理后果。
:::

::: exercise 呼吸商 {level=1 check=“0.8”}
一名静息患者每分钟耗氧250 mL、产二氧化碳200 mL。计算呼吸商并解释。
::: solution
$RQ = 200/250 = 0.8$，为混合膳食、含相当比例脂肪氧化时的数值，接近吸收后状态。RQ接近1.0表示碳水化合物氧化（若大于1.0，则为净脂肪生成，或过度通气排出CO₂）；接近0.7几乎纯脂肪氧化，见于长期饥饿。RQ还可告诉营养师机械通气患者是否喂养过度，因为RQ上升伴$ p_{\mathrm{CO_2}} $上升意味着碳水化合物过多。
:::
:::

::: exercise 制糖的成本 {level=1 check=“6”}
由两分子丙酮酸合成一分子葡萄糖消耗多少个核苷三磷酸？
::: solution
六个：丙酮酸羧化酶每分子丙酮酸用1 ATP（共2），磷酸烯醇式丙酮酸羧激酶每分子丙酮酸用1 GTP（共2），磷酸甘油酸激酶每个1,3-二磷酸甘油酸用1 ATP（共2）。糖酵解两步产ATP反应就此被加倍偿还；该过程还消耗2 NADH用于还原1,3-二磷酸甘油酸。
:::

::: exercise 用语言说控制 {level=2}
用本课的酶与第二信使解释：为何胰高血糖素注射在空腹成人升高血糖，而在糖原与肝蛋白均已耗竭的长期饥饿患者几乎无效。
::: solution
胰高血糖素经Gs偶联受体起作用，升高环磷酸腺苷并激活蛋白激酶A：后者磷酸化磷酸化酶激酶进而激活糖原磷酸化酶（糖原分解），并磷酸化双功能的PFK-2/果糖-1,6-二磷酸酶使果糖-2,6-二磷酸下降。果糖-2,6-二磷酸降低既减慢糖酵解又释放果糖-1,6-二磷酸酶，于是糖异生得以进行。饥饿时糖原库已空，第一种机制无底物可用；糖异生继续进行，但受其底物限制——其中最大来源是肌蛋白的氨基酸，而甘油取决于脂肪动员。故胰高血糖素效应被削弱，因为失败的是*能力*而非信号；同一理由也说明为何肾上腺素在营养不良儿童引起的高血糖不如营养良好者明显。
:::
:::

::: exercise 硫胺素 {level=2}
一名酒精依赖患者入院时意识模糊、眼球震颤并有酸中毒；拟在补充维生素前输注葡萄糖。请说出硫胺素缺乏时受累的酶，并解释为何先输葡萄糖可诱发Wernicke脑病。
::: solution
以焦磷酸硫胺素形式存在的硫胺素是丙酮酸脱氢酶、α-酮戊二酸脱氢酶、支链α-酮酸脱氢酶与转酮醇酶的辅因子。缺乏时丙酮酸不能进入三羧酸循环而被还原为乳酸；依赖氧化代谢的脑即使在葡萄糖充裕时也处于饥饿。葡萄糖负荷提高对酶的需求并耗去残存的硫胺素，乳酸进一步升高；经典情形即诱发或加重Wernicke脑病的眼肌麻痹、共济失调与意识障碍，故高危患者应在葡萄糖之前或同时给予肠外硫胺素。同一逻辑解释了脚气病（“湿型”因外周血管扩张与肌代谢障碍而呈高输出量心衰），以及再喂养时的乳酸升高。
:::

::: exercise 解读生化学 {level=2}
两名患者均有空腹低血糖与肝大。A乳酸与尿酸升高，禁食后给胰高血糖素血糖不升而乳酸大幅升高。B乳酸正常、酮体高，短时空腹后胰高血糖素可正常升高血糖，而隔夜禁食后不能。请分别为其定位缺陷。
::: solution
A：葡萄糖-6-磷酸酶缺乏（Ⅰ型）。被围困的G6P代谢为乳酸，而肝既不能从糖原也不能从糖异生输出葡萄糖，故胰高血糖素不能升高血糖，反而使乳酸进一步升高。B：肝糖原分解缺陷而糖异生完好——磷酸化酶或脱支酶缺陷（0型无肝大）。短时空腹后糖原仍可动员，一旦贮库耗竭则依赖糖异生，并因脂肪氧化增高而出现酮症；乳酸正常，因为糖异生通量与丙酮酸处理完好。请注意一项激发试验加三项代谢物，在酶测定之前已能完成多少工作。
:::

::: exercise 二甲双胍与乳酸 {level=3}
一名2型糖尿病患者eGFR 26 mL/min/1.73 m²，因感染性休克入院，乳酸9 mmol/L，pH 7.05。二甲双胍一直在用。请解释二甲双胍升高乳酸的机制、肾功能不全为何要紧，以及休克合并二甲双胍为何危险。
::: solution
二甲双胍可逆地轻度抑制呼吸链复合体Ⅰ。其后果在治疗上是有效的——肝糖异生减少（该过程依赖ATP，并部分转向AMP活化的蛋白激酶信号）、胰岛素敏感性改善、不引起低血糖；而在高浓度时是有害的：复合体Ⅰ部分受阻使NADH升高，丙酮酸被推向乳酸，而肝对乳酸的摄取与糖异生清除也下降，因为把乳酸转化为葡萄糖需要乳酸来源的NADH被呼吸链再氧化，而这正是药物所阻碍的环节。通常这只造成轻微而无症状的乳酸升高。肾功能不全时药物蓄积，因其以原形经肾排泄；休克时组织低灌注的乳酸生成增加叠加肝清除减少，故二甲双胍相关乳酸酸中毒虽罕见而病死率高。这就是该药在eGFR低于约30时应停用、手术与碘造影前后应暂停、以及任何威胁灌注或氧合的急性病期间应暂停的理由。
:::

::: exercise 阴离子间隙的算术 {level=3}
用上题数值计算阴离子间隙（Na 138、Cl 102、HCO₃⁻ 12 mmol/L），并在乳酸为9 mmol/L的情况下判断间隙升高是否已被完全解释。若未解释，还该找什么？
::: solution
阴离子间隙$= 138 - 102 - 12 = 24$ mmol/L，参考值约12，超出12 mmol/L。乳酸9 mmol/L较正常值约1高出8 mmol/L，故约4 mmol/L不能被解释——这已足以要求寻找第二个原因：酮体（饥饿、酒精性酮症酸中毒）、肾衰时硫酸盐与磷酸盐滞留，或毒性醇（应查渗透压间隙；火灾或烟雾暴露者还应想到氰化物）。还应对比间隙升高幅度与碳酸氢盐的变化，以揭出并存的、由呕吐所致的代谢性碱中毒。此题的要点可以推广：休克中的酸中毒极少只有一个原因，而代谢的算术正是发现这一点的办法。
:::
