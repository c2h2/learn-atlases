健康人的血浆血糖在早餐、一上午忙碌、错过午餐与一整夜睡眠之间保持于约4至8 mmol/L。这一点毫不平凡：脑需要连续供应，红细胞没有替代燃料，肝必须输出并非自身所需的葡萄糖，而脂肪组织必须被说服在恰当的速率释放脂肪而不更快。完成此事的系统，是作用于[[cell-biochemistry/energy-metabolism]]所述各途径的一组激素开关，其中脂肪组织、肝、肌肉与脑处于持续的对话之中。

本课讲身体在其间转换的几种状态——餐后、吸收后、空腹、饥饿、创伤——以及该系统在实践中失效的两种方式：过度喂养造成的肥胖与代谢综合征，以及营养不良与再喂养造成的急性摄入不足。最后以遗传代谢病作为一种就诊模式收尾，因为它们在病房里正是这样出现的。

::: theorem 葡萄糖是优先项 {#thm-glucose}
身体在代谢取舍中首先维护血浆葡萄糖，先于其他一切：蛋白被分解以制造葡萄糖，酮体被生成以减少葡萄糖需求，其代价是无法回收的氮。
:::

::: proof
这一需求是算术问题。脑、红细胞、肾髓质与白质在成人约需160 g/日葡萄糖，而只有肝（长期饥饿时肾参与）能输出葡萄糖，因为只有它们把糖原分解与糖异生与葡萄糖-6-磷酸酶连接起来。糖原约可提供100 g，故一天之内缺口必须由前体物补足，而最充裕的前体物是肌蛋白。酮体生成是降低账单的适应：酮体能通过血脑屏障，数日后提供脑ATP的很大一部分，这就是单纯饥饿时蛋白丢失减慢、消瘦者能存活数周而非数日的原因。请注意代价与例外：丢失的氮无法在不进食的情况下补回；而葡萄糖的维护在新生儿、糖原耗竭的酒瘾者以及营养不良儿童中会失效——这正是禁食数小时即成急症的三类患者。
:::

## 四种代谢状态

::: definition 代谢状态 {#def-states}
**餐后（吸收）**：进食后0–4小时，胰岛素高、胰高血糖素低；葡萄糖、氨基酸与脂肪酸被储存。
**吸收后**：4–16小时；胰岛素下降、胰高血糖素升高，肝糖原分解维持血糖。
**空腹（早期饥饿）**：16小时至约2–3天；糖原耗尽，糖异生占主导，酮生成开始。
**长期饥饿**：数日至数周；脑相当程度依赖酮体，蛋白丢失降至新的低稳态，静息代谢下降。
**创伤或脓毒症**状态则有意不同：皮质醇、儿茶酚胺、胰高血糖素与细胞因子驱动糖异生、胰岛素抵抗、脂解与肌肉蛋白分解，即使在输注葡萄糖时也是如此，而且这一过程不能靠喂养关闭。
:::

::: widget plot

x: 0, 96

:::

**胰岛素**是合成代谢信号：经GLUT4转位促进肌肉与脂肪摄取葡萄糖，促进糖原合成、脂肪酸与三酰甘油合成、蛋白合成，以及钾与氨基酸进入细胞；它抑制激素敏感性脂酶、肝糖异生与酮生成。**胰高血糖素**是短期饥饿的对立调节者，经环磷酸腺苷作用于肝，释放糖原葡萄糖并制造新葡萄糖；对肌肉作用甚微，因肌肉几乎没有胰高血糖素受体。**皮质醇**允许糖异生、动员氨基酸并造成胰岛素抵抗；**儿茶酚胺**驱动糖原分解、脂解，并且重要的是驱动胰高血糖素反应；**生长激素**为对立调节且促脂解。对立调节反应的失效——尤其是反复低血糖后肾上腺素反应的丧失——正是部分1型糖尿病患者发生低血糖感知受损的原因。

::: example 倒下的患者：是低血糖吗，是谁的过错？ {#ex-hypo}
病房护士长发现一名糖尿病患者意识模糊、大汗；末梢血糖2.1 mmol/L，给予葡萄糖后症状缓解。另一次住院，值班医生发现一名一般情况良好的患者血糖2.0 mmol/L，而同时刻留取的血清显示胰岛素42 mIU/L（升高）、C肽3.4 nmol/L（升高）、胰岛素原比例高、磺脲类筛查阴性。请解释，并说明下一步。
::: solution
第一位患者满足**Whipple三联**——低血糖的症状与体征、实测血糖低、纠正后缓解——它确立诊断而不确立病因，而最常见的病因远是患者自身的胰岛素或磺脲类。第二位患者的标本是在低血糖*当时*留取的，这是此类标本唯一可解释的时机：血糖2.0 mmol/L时胰岛素本应被抑制到测不出。与低血糖不相称的胰岛素，伴C肽与胰岛素原升高，意味着内源性胰岛素分泌，其鉴别为胰岛素瘤、磺脲类或格列奈类摄入，以及较少见的原因——胃转流术后的非胰岛素瘤胰源性低血糖、胰岛素自身免疫综合征、或分泌胰岛素样生长因子2的非胰岛瘤。**促分泌剂筛查阴性**提示**胰岛素瘤**；伪造注射胰岛素应表现为胰岛素高而C肽*低*，伪造服用磺脲类则筛查阳性。下一步：在生化确诊之后才做定位影像，因为胰腺偶发瘤常见，而据其手术是错误的；此外请注意胰岛素介导的低血糖中β-羟丁酸本应偏低——胰岛素抑制酮生成——这有助于把它与酒精、饥饿或内分泌缺乏所致、酮体偏高的低血糖区别开。
:::
:::

## 脂肪组织是一个器官

脂肪在分泌。**瘦素**按三酰甘油储量成比例生成，作用于下丘脑受体以减少摄入、增加消耗；先天性瘦素缺乏与瘦素受体缺乏引起严重的早发肥胖，而重组瘦素已获批用于罕见类型及脂肪萎缩的代谢并发症。多数肥胖者瘦素高而表现为瘦素抵抗，故瘦素本身不是通用抗肥胖药。相反，**脂联素**随内脏脂肪增加而下降，可改善胰岛素敏感性与肌肉脂肪酸氧化。脂肪组织还释放游离脂肪酸（慢性升高对β细胞与肌肉产生脂毒性）、抵抗素、纤溶酶原激活物抑制物-1，以及来自扩张的内脏脂肪中巨噬细胞的TNF-α与IL-6等细胞因子，并表达11β-羟类固醇脱氢酶1型而在局部生成活性皮质醇。

这就是为何**腰围**与脂肪分布比BMI本身更能预测风险，也是为何**代谢综合征**是一个连贯实体而非一串清单：中心性肥胖、高甘油三酯、低HDL、高血压与空腹血糖升高，共享两条上游机制——胰岛素抵抗与游离脂肪酸流增加——而内脏脂肪是其可见标志。

::: definition 代谢综合征 {#def-mets}
国际上并无唯一定义，但各定义都要求**腹型肥胖、胰岛素抵抗（或空腹高血糖）、血脂异常（高甘油三酯、低HDL）与高血压**的聚集，并伴炎症与促凝标志物升高。临床上，该诊断的重要性不如这样一个事实：它识别出的个体其心血管风险远大于任何单一成分所提示者；其处理是体重、活动、血压与他汀，并关注很可能随之而来的糖尿病。
:::

::: warning “肝酶正常”不能排除脂肪肝，“只是脂肪肝”也不能排除肝硬化
代谢功能障碍相关脂肪性肝病（现取代“非酒精性脂肪性肝病”的称呼）在少量饮酒且具有其他代谢危险因素者中依影像或组织学诊断；丙氨酸氨基转移酶常正常，而正常值不能排除纤维化。少数患者经脂肪性肝炎进展为肝硬化与肝细胞癌，如今它已是高收入国家移植评估最常见的原因之一。有用的检查是用年龄、转氨酶与血小板构成的纤维化评分（如FIB-4），评分升高时加做弹性成像；有效的治疗是减重（减轻7–10%体重可改善脂肪性肝炎）、独立于体重的运动、在有指征时使用GLP-1受体激动剂或替尔泊肽，以及较新的甲状腺激素受体β激动剂（resmetirom），用于经活检证实伴纤维化的脂肪性肝炎。
:::

## 饥饿、恶病质，以及喂养的危险

单纯饥饿是一种有序适应。改变它的是炎症。**恶病质**——由TNF-α、IL-6、IL-1与干扰素-γ联合合成抵抗、摄入减少及肿瘤或器官因素所致的肌肉丢失（可伴脂肪丢失）——单靠喂养无效，这就是为何“高热量饮食”医嘱在晚期肿瘤、心脏或肾脏疾病中失败，也是为何评估必须包括原发病、食欲以及躯体与心理功能。

**再喂养综合征**是相反的危险，且完全是生物化学性的。一名饥饿或酒精依赖患者磷、钾、镁已耗竭（总体缺乏而血浆浓度正常），此时给予碳水化合物。胰岛素回归，随之而来的是磷（用于ATP与2,3-二磷酸甘油酸合成）、钾与镁的细胞内转移，以及碳水化合物代谢对硫胺素的消耗。2–4天内患者出现低磷血症、乏力、意识障碍、心律失常、无法撤离呼吸机、溶血，并有癫痫发作与死亡风险；钠潴留后出现水肿。预防即治疗：识别风险（10日以上无摄入、BMI<16、3–6个月内非意愿体重下降超过15%，或基线磷、钾、镁偏低），检查并补充上述电解质并**先于或同时**给予硫胺素，以需要量的一小部分起始喂养并在数日内递增，第一周内每日监测，并预期患者所需的钾与镁会多于看起来合理的量。

::: example 同一次住院中的两种危险 {#ex-refeed}
一名34岁、BMI 13的限制性进食患者入院。基线磷1.1 mmol/L，钾3.3 mmol/L，镁0.7 mmol/L。因她本人痛苦而病房希望“追赶进度”，遂以2000 kcal/日喂养。第三天她心动过速、水肿、双上肢抬不起来，磷0.3 mmol/L。发生了什么？本应怎么做？
::: solution
这是再喂养综合征。胰岛素激增把磷驱入细胞用于磷酸化反应与2,3-二磷酸甘油酸合成，由此产生的低磷血症损害膈肌与肢带肌力、心肌收缩力与氧输送；钠水潴留造成水肿；钾与镁的降低（两者均因再喂养转入细胞内而耗竭）参与了心动过速。本应的方案是：在病历中写明高风险分级、喂养前给硫胺素与B族复合维生素、补充钾磷镁、初始处方约10 kcal/kg/日（该患者约300–400 kcal），并在5–10天内逐步增加，同时第一周每日监测电解质，重度者给予心电监护。患者的痛苦是真实的，心理治疗也很重要，但过快给到的热量并不等同于给足热量——安全的方案正是继续喂养的前提。
:::
:::

::: example 意识模糊、体温低而醉酒 {#ex-alcohol}
一名45岁酒精依赖者连续两日大量饮酒且未进食，晨6时被送入院。血糖2.2 mmol/L，体温35.6 °C，pH 7.30，乳酸4.8 mmol/L，尿酮试纸阴性，氨轻度升高，AST高于ALT，磷0.6 mmol/L。请解释低血糖与酮体结果，并列出第一小时的治疗。
::: solution
乙醇的两步代谢造成了损害。乙醇脱氢酶与醛脱氢酶都把NAD⁺还原为NADH，而线粒体高NADH/NAD比值逆转了需要NAD⁺的反应：草酰乙酸转为苹果酸而不能用于糖异生，丙酮酸被还原为乳酸——这解释了无休克时的乳酸4.8。数日摄入不足使糖原耗竭，肝葡萄糖输出下降而发生低血糖；同一氧化还原状态与β氧化底物的缺乏又使酮体生成偏低，故“无酮”本身是图像的一部分而非反对饥饿的证据。随后陷阱相继出现：低体温、低磷与低镁、乳酸与（随酒精清除后才显现的）酒精性酮症酸中毒所致酸中毒，以及不能因输糖而被推迟的硫胺素缺乏。第一小时内：硫胺素（与镁同给，因镁是硫胺素依赖酶的辅因子，缺镁则硫胺素无效）先于或与葡萄糖同时给予，静脉右糖恢复血糖，补充钾、磷、镁，积极复温，监测血糖与电解质，并寻找该患者意识模糊的其他原因——颅内出血、脓毒症、戒断、肝性脑病，以及低血糖本身（纠正后仍可遗留意识缺陷）。
:::
:::

在一名长期呕吐、血糖3.1 mmol/L、酮体4 mmol/L、无糖尿病的患者中，胰岛素与C肽应当是：
- [ ] 升高，因为酮体刺激胰岛素分泌。
- [x] 被抑制至接近测不出，因为低血糖与饥饿本应关闭β细胞分泌。
- [ ] 正常，因为胰岛素总以基础速率分泌。

恰当的低血糖反应以被抑制的胰岛素、C肽与胰岛素原为特征，并伴对立调节激素升高、饥饿时β-羟丁酸上升，以及（相关时）皮质醇与生长激素反应正常。低血糖时仍可测到胰岛素即属病理——即胰岛素介导的低血糖——而酮生成未能随之升高是有力线索。血糖3.1 mmol/L时“基础正常”的胰岛素并不正常，恰恰是这种不能抑制使此类检测只在记录了低血糖时才可解释。

## 遗传代谢病：一种模式，而非一份清单

遗传性酶病以一组可辨认的方式就诊，知道模式比记住疾病更有用。

- **原本健康的新生儿在蛋白或禁食负荷后恶化**：高氨血症所致呕吐、过度通气与昏迷的脑病（尿素循环障碍、有机酸血症），或伴肝功能障碍的低酮性低血糖（脂肪酸氧化障碍），或阴离子间隙或渗透压间隙增高的乳酸酸中毒（有机酸血症、线粒体病）。诱因通常是疾病或禁食，而不单是饮食。
- **依赖该途径的器官出现进行性病变**：脑（发育倒退、癫痫、基底节改变）、肝（肝大、纤维化、衰竭）、肌肉（肌张力低下、心肌病、横纹肌溶解）、肾（小管综合征、结石）、骨与结缔组织（黏多糖贮积症）。
- **粗陋面容、角膜混浊、骨发育不良与樱桃红斑并贮积**：溶酶体贮积病；注意淋巴细胞空泡与黄斑颜色。
- **发作间期正常的间断发作**：卟啉病（见[[cell-biochemistry/lipid-amino-acid-metabolism]]）、晚发型尿素循环障碍、脂肪酸氧化障碍、同型半胱氨酸尿症。
- **筛查发现而无症状**：多数氨基酸与有机酸血症；这也是新生儿筛查作为拥有自身伦理的公共卫生项目的原因。

急性期处理的一般原则是一致的：停止毒性输入（蛋白停1–2天，同时给葡萄糖与脂肪防止分解代谢）、提供足以关闭分解代谢的热量——这是最有效的单项干预——促进替代途径排泄（苯甲酸盐与苯丁酸盐等氮清除剂、肉碱，以及在可能为反应型缺陷时的核黄素、生物素、羟钴胺与硫胺素）、清除毒素（氨与小的毒性分子用透析），并在缺陷局限于某一器官、损害又呈进行性时移植该器官（许多肝型遗传代谢病可肝移植）。

::: example 像脓毒症而非脓毒症的新生儿 {#ex-organic}
一名足月新生儿，生后四日内一切正常，现因喂养差、气促与嗜睡就诊。C反应蛋白轻度升高，血培养阴性，血糖2.8 mmol/L，pH 7.05，碱剩余−16，阴离子间隙26，乳酸4 mmol/L，酮体6 mmol/L，氨320 µmol/L，血气示酸中毒之上叠加代偿性呼吸性碱中毒。请说明生化模式与最初三项处理。
::: solution
原本健康而后因负荷恶化的新生儿出现**高阴离子间隙代谢性酸中毒伴显著酮症**、高氨血症与低血糖，提示**有机酸血症**——甲基丙二酸、丙酸、异戊酸或相关缺陷——而不是尿素循环障碍（后者无酸中毒与酮症，而以呼吸性碱中毒为主），也不是脂肪酸氧化障碍（其酮体不适当地低）。脓毒症仍须治疗，因为感染既可模仿亦可诱发此类危象。即刻处理为：完全停止蛋白24–48小时，同时给予高热量静脉葡萄糖（必要时加胰岛素）与脂肪，以逆转分解代谢（首要目标是不惜代价扭转负氮平衡）；在容量与葡萄糖之后谨慎纠酸（碳酸氢盐）；给予肉碱与辅因子维生素（核黄素、生物素、羟钴胺、硫胺素），同时等待尿有机酸、酰基肉碱谱与血浆氨基酸结果；若氨超过约500 µmol/L或意识受抑，及早安排血液滤过。
:::

::: history
饥饿状态的生理学主要由两对夫妻与一场战争确立。Carl与Gerty Cori在1906年至1947年间阐明了糖原分解以及把肌乳酸运回肝糖的乳酸-葡萄糖循环，与Bernardo Houssay共获1947年诺贝尔奖；Felig于1969年描述葡萄糖-丙氨酸循环，这解释了为何真正限制饥饿的是肌氮而非肌碳。激素研究紧随提取物而来：胰岛素于1921–22年在多伦多被纯化，胰高血糖素1923年由Kimball与Murlin作为“升高血糖因子”识别，1953年由Archibald Sutherland纯化。George Cahill在1966–70年对巴布亚新几内亚志愿者的长期饥饿研究界定了代谢适应与氮丢失的下降；而严重创伤与脓毒症的代谢后果，则由Sir David Cuthbertson 1942年提出的“衰减与波动”刻画至今仍是分解代谢反应最佳的一段描述。Jeffrey Friedman课题组1994年借助Jackson实验室的ob/ob与db小鼠突变体识别瘦素，把一个关于单基因肥胖的好奇，转变为对脂肪组织作为内分泌器官的现代理解。
:::

## 通向何处

途径本身见[[cell-biochemistry/energy-metabolism]]与[[cell-biochemistry/lipid-amino-acid-metabolism]]；使其危险的营养素见[[cell-biochemistry/nutrition]]；胰岛素与胰高血糖素的激素细节见[[endocrine/hypothalamus-pituitary]]与[[endocrine/diabetes]]；营养不良患者的临床评估与喂养策略见[[gastrointestinal/clinical-nutrition]]。

::: summary
- 身体在胰岛素/胰高血糖素比值下调控下于餐后、吸收后、空腹与饥饿状态间转换，皮质醇、儿茶酚胺与生长激素为对立调节者；糖原买来约一天，糖异生与酮生成买来其余。
- 胰岛素抑制酮生成；因此胰岛素介导的低血糖缺酮，而饥饿或酒精性低血糖富含酮体。
- 胰岛素、C肽与胰岛素原只能在记录了低血糖的标本上解释，且应同时测β-羟丁酸与促分泌剂筛查。
- 脂肪组织是内分泌器官；瘦素反映储量，脂联素反映敏感性，而内脏脂肪驱动代谢综合征的胰岛素抵抗与促凝状态。
- 饥饿是适应，恶病质是炎症性的且不能单靠热量逆转，而再喂养是危险的：先给硫胺素，补充电解质，从小量开始，缓慢加量。
- 遗传代谢病以一种模式就诊——原本健康的新生儿在蛋白或禁食负荷后恶化、器官不能满足能量或排出需求、或发作间期正常——而急性期处理是停止分解代谢。
:::

## 练习

::: exercise 排出燃料的顺序 {level=1}
就下列组织分别指出餐后与长期饥饿时的首选燃料：脑、红细胞、静息骨骼肌、心肌、肾皮质、脂肪细胞。
::: solution
脑：餐后为葡萄糖；适应后为葡萄糖加酮体（绝不用脂肪酸，因其不能以有意义量通过血脑屏障）。红细胞：永远为葡萄糖，因其无线粒体。静息骨骼肌：餐后与饥饿时皆为脂肪酸，饥饿时加上酮体；只有当胰岛素与运动把GLUT4带到膜上时才用葡萄糖。心肌：脂肪酸、乳酸、酮体与部分葡萄糖——心脏优先摄取乳酸，这就是缺血与运动肌肉的乳酸并不浪费的原因。肾皮质：脂肪酸、乳酸与谷氨酰胺，并参与糖异生。脂肪细胞：餐后为葡萄糖（供三酰甘油骨架与NADPH），饥饿时输出脂肪酸而非燃烧之。
:::
:::

::: exercise 激素与效应 {level=1}
哪一种单一激素缺乏会同时造成空腹低血糖伴酮症、高钾伴低钠、以及低血压？请说出诊断试验。
::: solution
皮质醇与醛固酮缺乏——原发性肾上腺皮质功能不全。皮质醇缺失使一种对立调节激素缺席，故低血糖为酮症性（因胰岛素被恰当抑制）；醛固酮缺失造成肾性钠丢失、高钾与体位性低血压；4型肾小管酸中毒的酸中毒完成全图。试验为晨间皮质醇与ACTH，加促皮质素（Synacthen）短期兴奋试验，并测肾素与醛固酮；经典病因为自身免疫性肾上腺炎与结核，而激素替代在任何疾病期间都不可中断。
:::
:::

::: exercise 酮体为何低 {level=1}
列出低酮性低血糖的三个原因及其共同机制。
::: solution
脂肪酸氧化障碍（中链酰基CoA脱氢酶缺乏、肉碱缺乏或CPT缺陷）、高胰岛素血症、以及严重肝衰竭。共同机制是：酮体来自脂肪酸来源的乙酰CoA，需要肝在其ATP与氧化还原状态允许时将其输出——若脂肪不能氧化（第一组）、若胰岛素抑制脂解与酮生成（第二组）、或肝细胞无法执行该途径（第三组），则血糖下降而酮体不适当地低。这就是“低酮性低血糖”自成一个诊断标题的原因。
:::
:::

::: exercise 读对立调节 {level=2}
一名病程18年的1型糖尿病患者自觉低血糖直到意识模糊才察觉；其低血糖阈值在钳夹试验中已低于既往。请用生理解释，并说明处理上随之而来的改变。
::: solution
反复低血糖会钝化对立调节反应：本应引起心悸、出汗与饥饿感的肾上腺素释放幅度下降，而1型糖尿病患者在发病数年后胰高血糖素对低血糖的分泌反应已经丧失。脑适应于在更低血糖下工作（低血糖相关的自主神经衰竭伴阈值的行为性适应），故症状只在认知已受损的水平才出现。处理不是更严格的控制而恰是相反：一段时间内（数周至数月）放宽目标，配合带报警的持续血糖监测、患者与家属教育、驾驶规定的复核，以使症状感知部分恢复。能自动停止输注的技术亦有帮助；减少夜间低血糖的方案也是选择之一。
:::
:::

::: exercise 床边的代谢综合征 {level=2}
一名52岁男性腰围108 cm、甘油三酯3.1 mmol/L、HDL 0.8 mmol/L、血压146/90、空腹血糖6.6 mmol/L、BMI 32，空腹胰岛素22 mIU/L。统一机制是什么？哪四项干预减少的是事件而非数字？
::: solution
胰岛素抵抗伴脂肪组织脂解与肝游离脂肪酸流增加：肝输出富甘油三酯的VLDL，胆固醇酯转移蛋白把甘油三酯换入HDL与LDL，随后肝脂酶清除富甘油三酯的HDL，遂形成特征性的高甘油三酯、低HDL；高胰岛素血症经钠潴留与交感活性升高血压。有终点证据的干预：饮食与体力活动结合的适度减重并附带维持支持；结构化生活方式改变与随访；按绝对心血管风险使用他汀；降压达标；以及在肥胖或糖尿病有指征时使用GLP-1受体激动剂（既有已证实的心血管益处，也减重）。二甲双胍可延缓糖尿病发生；贝特主要降低甘油三酯而对事件的减少并不一致。如此写出的理由是：五个成分随上游机制一同移动，故治机制比治四个数字更有效。
:::
:::

::: exercise 饥饿与糖尿病的对比 {level=2}
长期饥饿与失控的1型糖尿病都产生酮血症，但只有一者出现pH 7.05。请用三个机制说明差别。
::: solution
生成速率：饥饿时脂解受限，因胰岛素虽低却非缺如，下降的胰岛素/胰高血糖素比值对激素敏感性脂酶仍有抑制；绝对胰岛素缺乏则解除刹车，经HMG-CoA合酶的通量大得多。缓冲与丢失：饥饿性酮症轻微（通常低于5–7 mmol/L），碳酸氢盐再生可与之并行；糖尿病酮症酸中毒则生成超过缓冲，酮阴离子随尿丢失，容量不足与肾小球滤过下降又阻止肾排泄氢与酮阴离子。底物：高血糖造成渗透性利尿，故水、钠、钾与酮阴离子一并丢失，形成酸中毒叠加“看似正常或偏低”却总体缺钾的混合图像；饥饿则不然。故饥饿性酮症极少使pH低于7.3，而酒精或妊娠相关的酮症酸中毒可在血糖正常时很重——这也是为何诊断不能只看血糖。
:::

::: exercise BMI正常的神经性厌食 {level=3}
一名22岁非典型神经性厌食女性，在减轻14 kg后BMI为23，脉搏48次/分，钾3.2 mmol/L，磷1.0 mmol/L，肝肾功能正常。她正以1200 kcal/日再喂养并每日查电解质。两天后她头晕、脉搏54次/分、QTc 480 ms。请评述该方案。
::: solution
首先出错的是风险分级：六个月内体重下降超过15%、目前摄入不足已十余日、钾3.2与磷1.0，无论BMI如何都属高危；非典型神经性厌食的再喂养风险与低体重型相同。电解质与QTc显示正在演变的低磷血症合并低钾血症、很可能还有低镁血症；心动过缓伴QT延长与头晕是有理由给予心电监护并放慢（或至少在被补充覆盖的情况下）增加热量的信号。热量处方对高危患者过高：指南建议自约10 kcal/kg/日起，逐步递增并持续5–10天，第一周每日监测磷、钾、镁，喂养前给予硫胺素与含B族的多维生素。她还需要按躯体风险标准评估住院——心动过缓、低钾、QT延长与快速体重下降皆在其列；而心理治疗只有在代谢急症被安全处理后才可能持续。
:::

一名六月龄婴儿在添加辅食后出现肝大、生长停滞、乳酸酸中毒与高尿酸血症。列出三个鉴别诊断，以及最有效区分它们的单项检查。
::: solution
该模式提示糖原贮积病Ⅰ型（葡萄糖-6-磷酸酶）、遗传性果糖不耐受（醛糖B，与添加水果与蔗糖在时间上相关）、以及线粒体呼吸链疾病；也应排除果糖-1,6-二磷酸酶缺乏与Ⅰ型酪氨酸血症。最有效的单项检查是新制备去蛋白样本上的**乳酸/丙酮酸比值**，并结合糖代谢反应与代谢物模式：禁食后高比值伴酮症提示呼吸链缺陷；低或正常比值伴低血糖、高尿酸与高脂血症且输糖后改善，提示葡萄糖输出障碍（Ⅰ型或果糖-1,6-二磷酸酶缺乏）；果糖不耐受者在口服果糖后血糖与磷下降，但分子检测比负荷试验更安全。如今肝活检加酶测定只用于未明病例，因为其中多数可由血尿代谢物与DNA确诊。
