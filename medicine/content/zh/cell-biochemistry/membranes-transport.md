细胞是一场外界不断试图打赢的化学辩论。质膜是辩论得以继续的条件：一层不足5 nm厚的脂质薄膜，其结合力不过是不肯与水见面的烃链，然而它能维持钠离子30倍的浓度差、氢离子百万倍的差值，并自造出一个电位差。身体几乎每一道膜都以同样的方式工作，而各区室之间的差别几乎只在于其中插入了哪些蛋白。

本课讨论双分子层的物理、转运溶质穿膜的蛋白、移动一个带电粒子所导致的电学后果，以及移动水所导致的渗透后果。这四个观念解释了静息膜电位、血浆钠的浓度、利尿剂与地高辛的作用、纠正低钠过快之危险、囊性纤维化，以及水肿踝部积液的成分。

## 双分子层

磷脂是两亲分子：一个极性头基与两条非极性尾链。在水中它们自发形成双分子层，因为这种排列把尾链藏离水而让头基保持水化。不需要酶，也不需要能量输入——这一结构在热力学上是必然的，这就是膜被刺破后能自行封闭的原因。

::: definition 流动镶嵌膜 {#def-membrane}
**质膜**是一层二维的脂质溶液：4–5 nm厚的磷脂双分子层，其中胆固醇与膜蛋白侧向浮动。它对水与小非极性分子自由通透，对离子以及大约100 Da以上的极性分子几乎不通透，其性质由所含蛋白决定。
:::

脂相有两个特点具临床意义。其一，**流动性**取决于温度与脂质组成：不饱和尾链与短链增加流动性，胆固醇则起缓冲作用——在过热而过流动的膜中限制运动，在过冷的膜中防止紧密堆积。细菌与哺乳动物的膜都会被极端温度损伤，而某些生物能随温度改变其脂质组成，此即“膜流动性恒常适应”的分子基础。其二，两层脂层是**不对称的**：糖脂与磷脂酰胆碱主要分布在外侧，磷脂酰乙醇胺与磷脂酰丝氨酸在内侧，由翻转酶（flippase）与扰动酶（scramblase）维持。磷脂酰丝氨酸暴露于外叶并不只是一个奇趣事实：它是血小板的促凝表面，也是巨噬细胞识别衰老红细胞与凋亡小体的“吃掉我”信号。

蛋白约占膜重的一半，线粒体中更多。蛋白分两类：**整合蛋白**具有疏水的跨膜段（通常为20–25个残基的α螺旋）嵌入脂质中；**外周蛋白**以蛋白-蛋白结合附着于膜内表面——如红细胞内的spectrin与ankyrin，其缺陷见[[#ex-spherocytosis]]。

## 经膜的简单扩散

小非极性分子以简单扩散穿越脂质，其速率由菲克定律描述。设膜面积为$A$、厚度为$\delta$，两侧溶质浓度为$C_1$与$C_2$，则

$$
J = \frac{\dd}{\dd t}\text{（量）} = \frac{D\,K\,A}{\delta}\left(C_{1} - C_{2}\right) = P A\left(C_{1} - C_{2}\right),
$$ {#eq-fick}

其中$D$为膜内扩散系数，$K$为油-水分配系数，$P = DK/\delta$为**通透系数**。由于$K$随脂溶性陡升，脂溶性物质优先于同尺寸的水溶性物质通过。

| 物质 | 相对通透性 | 原因 |
|---|---|---|
| O₂、CO₂、N₂ | 极高 | 小且非极性 |
| 乙醇、尿素 | 中等 | 小、不带电、部分脂溶 |
| 水 | 尽管极性仍属中等 | 极小；也经水通道蛋白通过 |
| 葡萄糖、氨基酸 | 可忽略 | 大而极性——需要载体 |
| Na⁺、K⁺、Cl⁻、Ca²⁺ | 基本为零 | 水化离子不能进入脂质 |
| 蛋白、多糖 | 零 | 大分子 |

其临床后果是直接的。全身麻醉药、地西泮、酒精以及绝大多数口服药物因这一理由而具脂溶性；神经肌肉阻滞剂与氨基糖苷类等极性药物根本不穿越细胞膜，因而主要留在细胞外液，这决定了它们的分布容积与给药体重（见[[pharmacology/absorption-distribution]]）。

## 通道与载体：介导转运

凡不能溶于脂质者必须被运送。转运蛋白分为动力学完全不同的两族。

**通道**是水相孔道，由一圈亚基围成，允许离子顺其电化学梯度通过，速率高达每秒$10^{8}$个离子。它们具有选择性（K⁺通道对Na⁺的排除约达一万倍，其选择滤器以羰基氧精确替代钾的水化壳），并且**有门控**：由电压（心脏钠通道）、由配体（烟碱型乙酰胆碱受体）、由机械张力或由第二信使开放与关闭。门控并非全或无；每一扇门按其所能感受的信号以一定概率闪开闪闭，膜电导是众多此类门控的总和表现。

**载体**（转运体、泵）结合溶质、改变构象并在另一侧释放。它们较慢（每秒$10^{2}$–$10^{4}$个分子），高度特异，而且关键在于**会饱和**，故其速率服从米氏动力学：

$$
J = J_{\max}\,\frac{C}{K_{t} + C},
$$ {#eq-carrier}

其中$J_{\max}$反映转运体数目（旧文献写作$T_{\max}$），$K_t$为达最大速率一半时的浓度。

::: definition 介导转运 {#def-mediated}
**介导转运**是经特异蛋白的跨膜移动，其特征为i)选择性，(ii)**饱和性**（存在最大速率$J_{\max}$），(iii)相关底物之间的竞争性抑制。**易化扩散**是介导的被动转运；**主动转运**是介导的、消耗能量的转运，能量或直接来自水解（原发性主动转运，如Na⁺/K⁺-ATP酶），或借用既有梯度（继发性主动转运，如Na⁺-葡萄糖同向转运）。
:::

x: 0, 400

labels: J

饱和是一份诊断上的礼物。葡萄糖经Na⁺-葡萄糖同向转运体被肾小管重吸收，直至每一个转运体都被占用；血浆葡萄糖超过约11 mmol/L即出现在尿中。类似的$T_m$也限制近端小管对对氨基马尿酸的分泌、对肌酐的分泌（轻微）以及许多药物的分泌。

## 移动离子即产生电

在膜两侧分离电荷所费极少：一侧多出一个离子种类中的$10^{18}$分之一，就足以产生几十毫伏。这就是细胞可以成为电池而几乎不改变自身化学组成的原因，也是两种浓度完全相同的离子行为可以截然不同的原因。对单一可通透离子，其平衡电位——使电学与化学驱动力恰好抵消的电压——由能斯特方程给出。

::: theorem 能斯特方程 {#thm-nernst}
在温度$T$下，价数为$z$的离子的平衡电位为
$$
E_{\text{ion}} = \frac{RT}{zF}\ln\frac{[\text{ion}]_{\text{out}}}{[\text{ion}]_{\text{in}}},
$$
在37 °C时化为$E_{\text{ion}} = \dfrac{61.5}{z}\log_{10}\dfrac{[\text{ion}]_{\text{out}}}{[\text{ion}]_{\text{in}}}$（mV）。
:::

::: proof
将一摩尔离子向内移动的化学势差为$RT\ln([\text{in}]/[\text{out}])$。将一摩尔电荷$zF$移动过电位差$V_{\text{in}} - V_{\text{out}}$所需的电功为$zF V$。平衡时两者之和为零：
$$
RT\ln\frac{[\text{in}]}{[\text{out}]} + zFV = 0
\quad\Longrightarrow\quad
V = \frac{RT}{zF}\ln\frac{[\text{out}]}{[\text{in}]}. \qquad\blacksquare
$$
:::

在37 °C，$E_K \approx -97$ mV、$E_{Na} \approx +66$ mV、$E_{Cl} \approx -89$ mV（取细胞外K⁺ 4、Na⁺ 140、Cl⁻ 110，细胞内K⁺ 150、Na⁺ 12、Cl⁻ 4 mmol/L）。神经与肌纤维的**静息膜电位**约为−70至−90 mV，因此靠近$E_K$，因为静息时膜对K⁺的通透性远高于Na⁺。其定量表达即Goldman–Hodgkin–Katz方程，按通透性对各离子加权；它最有用的推论是：静息电位总是*移向*当时通透性最高的那个离子的平衡电位。

::: example 为何高钾使心脏停跳 {#ex-k}
一名急性肾损伤患者血钾8 mmol/L；心电图示QRS增宽，患者乏力并进展为弛缓性瘫痪。请解释。
::: solution
$E_K = 61.5\log_{10}(8/150) = 61.5 \times (-1.273) \approx -78$ mV，而在血钾4时约为$-97$ mV。于是静息电位*去极化*约19 mV。轻度过度去极化使电压门控钠通道更易开放，故高钾早期兴奋性升高；但持续去极化使大量Na⁺通道停留在失活状态，而它们只能靠复极化恢复。于是心肌与骨骼肌传导减慢——QRS增宽、正弦波、瘫痪——而依赖配体门控通道的膜相对较好。此结论可以推广：钾紊乱的临床相正是膜*兴奋性*的图像，重要的是$E_K$的变化，而非其绝对值。
:::
:::

::: warning 钠梯度不等于浓度差
钠在膜外浓度更高，故通道开放时它向内扩散——但内负的电位*也*把Na⁺拉向内侧，因此其电化学梯度远比单纯浓度梯度陡峭。钾正相反：浓度梯度把它推出去，电位梯度把它留住，两者几乎相消。假定电位项可以忽略，或弄错$z$的符号，都会把平衡电位算得方向相反；每一道能斯特计算都应用“该离子愿意往哪边走”的直觉校验。
:::

## 钠泵与继发性主动转运

Na⁺/K⁺-ATP酶每水解一个ATP送出三个钠、纳入两个钾。它是**产电性**的（净送出1个正电荷），维持着大多数其他转运体所依赖的梯度，并消耗人体静息ATP的约四分之一——在肾、脑与心脏则远多于此。它是强心苷的靶点：抑制心肌细胞膜上的该酶使胞内钠升高，减少Na⁺/Ca²⁺交换体排钙，从而增强收缩力。

::: theorem 钠梯度作为通货 {#thm-na}
继发性主动转运体使用钠梯度中储存的能量——由钠泵建立——把第二种溶质逆其自身梯度运送。钠的移动方向决定两者同向（同向转运）还是反向（反向转运）。
:::

::: proof
偶联是热力学性的，而非机械性的。同时结合Na⁺与底物S的转运体，其不同构象的相对稳定性取决于哪些位点被占据。若自由能变化之和$n\Delta\mu_{Na} + \Delta\mu_{S}$为负，偶联循环就朝“S uphill、Na⁺下坡”的方向进行；若为正，则倒转或不转。由于$\Delta\mu_{Na}$同时包含浓度项与膜电位项，同一转运体在电位改变时可能反转。两个推论随之而来：S可达到的最大梯度由钠梯度决定（生理条件下约13 kJ/mol，相当于不带电溶质约200倍的浓度梯度，故转运两个或三个钠离子可驱动$10^{4}$–$10^{6}$倍的蓄积），而抑制钠泵终久会使底物转运停摆，即使该底物的转运体完全正常。
:::

值得记住的例子：**SGLT2**与**SGLT1**逆梯度重吸收肾与肠的葡萄糖（SGLT2被列净类药物抑制而产生糖尿）；**Na⁺/H⁺交换体NHE3**重吸收钠并排氢；**Na⁺/K⁺/2Cl⁻同向转运体NKCC2**建立髓质梯度，被袢利尿剂阻断；红细胞的**Cl⁻/HCO₃⁻交换体**以碳酸氢盐形式运输二氧化碳；几乎每一个上皮基底侧的**Na⁺/K⁺-ATP酶**是跨上皮转运得以存在的前提。

::: example 两位患者，一道通道 {#ex-cftr}
患者A，6岁，生长停滞、脂肪泻与反复肺部感染，汗液氯95 mmol/L。患者B，30岁，旅行后大量水样腹泻，粪便钠90 mmol/L、氯100 mmol/L，禁食24小时腹泻仍不止。两者都涉及CFTR氯通道。请调和二者。
::: solution
CFTR是上皮顶膜上受cAMP调节的氯通道，同时也调控其他通道，是氯（从而碳酸氢钠）分泌的路径。在A，通道缺失或被摧毁——最常见为ΔF508突变，其产物错误折叠、被内质网滞留并降解——故上皮不能分泌氯，表面无法水化，黏液与分泌物变得浓稠：这是“导管”的疾病，累及胰腺、肺与汗腺（汗腺因不能重吸收氯而使汗液变咸）。在B，通道完好却被病理性过度激活：霍乱毒素把Gsα锁定于激活状态，腺苷酸环化酶持续运转，cAMP升高，CFTR向肠腔倾注氯，钠与水随之而去，而肠细胞正常的制动机制已被越过。同一道通道的功能丧失与过度激活分别导致阻塞性与分泌性疾病——这正是为何帮助折叠的“矫正剂”可治A，而通道抑制剂或可治B。
:::
:::

## 水、渗透压与张力

水经脂质缓慢、经水通道蛋白迅速通过，并且总是移向渗透活性颗粒浓度更高的一侧。描述溶液有两个量，且常被混淆。

::: definition 渗透浓度、渗透摩尔浓度与张力 {#def-tonicity}
**渗透摩尔浓度**（mOsm/kg水）计算溶解颗粒数，由实验室测定。**渗透浓度**（mOsm/L）是按每升溶液的同一概念；临床可用血浆渗透浓度≈$2[\text{Na}^+] + [\text{葡萄糖}] + [\text{尿素}]$（mmol/L）估算。**张力**（有效渗透浓度）只计算*不能穿过细胞膜*、因而真正驱动水移动的颗粒。尿素与乙醇有渗透活性，但随时间可平衡到细胞两侧，故尿素溶液是高渗的却不是高张的。
:::

血浆渗透摩尔浓度为285–295 mOsm/kg。实测值与计算值之差超过约10 mOsm/kg，意味着存在未测定的渗透分子——乙醇、甘露醇，或中毒时的毒性醇及其代谢产物——渗透压间隙即按此用途用于[[emergency-critical-care/poisoning]]。

因为水随钠走，血浆钠浓度衡量的是水的平衡而非钠的平衡：高钠血症几乎总意味着水缺乏，低钠血症则意味着相对于钠的水过多。其临床推论涉及输注液体。钠不易进入细胞，故0.9%氯化钠（每离子154 mmol/L，约308 mOsm/L）留在细胞外液并使其扩容；5%葡萄糖在袋内是等渗的，但葡萄糖被代谢后留下自由水，分布于总体水之中——因此一升葡萄糖既不显著扩容，也几乎不改变什么，而给低钠患者一升生理盐水，若其尿液不适当地浓缩，通常反而加重低钠。

::: example 读一个钠值 {#ex-na}
一名78岁服用氢氯噻嗪的老年女性，胸部感染后血钠118 mmol/L，葡萄糖6 mmol/L，尿素4 mmol/L，实测渗透摩尔浓度246 mOsm/kg，尿渗透压520 mOsm/kg，尿钠60 mmol/L。血压正常，无水肿。计算渗透压间隙并对该状态作出分类。
::: solution
计算渗透浓度$= 2(118) + 6 + 4 = 246$ mOsm/kg，故间隙为零：这是真正的低渗（低张）性低钠血症，不是脂类或蛋白造成的假性低钠，也不是高血糖导致的转移性低钠。患者容量状态正常，尿本应在血渗透浓度已低时变得稀释（< 100 mOsm/kg）却呈浓缩，且尿钠偏高，故为水排泄障碍：最可能的原因是噻嗪类利尿剂，因其阻断远端小管的尿液稀释而不损害浓缩所需的髓质梯度；胸部感染所致抗利尿激素不当分泌亦有参与。由膜生理学可引出两条规则：纠正要慢，因为脑细胞已排出渗透物质以挺过肿胀，其恢复不如水外移之快；以及停用致病药物。
:::
:::

::: quiz
向总体水42 L、细胞外液14 L的患者输注一升0.9%氯化钠，下列哪项近似正确？
- [ ] 分布于42 L之中，使血钠略升。
- [x] 留在细胞外间隙，使其扩容约1 L。
- [ ] 因其等渗而进入细胞。
- [ ] 数分钟内原样排出，什么都不改变。
::: solution
钠实际上不能透过膜，而钠泵又把它排出去，故等渗盐水是把1 L等渗液体加入细胞外间隙：只要钠平衡为正，这1 L就保留在这约14 L的间隙中，血钠不变。能排出钠负荷的患者最终会携水一并排出；而在心、肝或肾脏疾病中，它表现为水肿或腹水——Starling力的问题见[[physiology/homeostasis-body-fluids]]。
:::
:::

## 膜完成身体的工作

上皮是由极性化细胞构成的片层，其顶膜与基底侧膜携带*不同*的转运体，而基底侧的钠泵驱动一切。向量性转运——单向吸收、另一向分泌——只是该不对称的结果，紧密连接构成的细胞旁路可能完成回路。上皮“致密”处（集合管、结肠）反漏很少，能建立大梯度；“渗漏”处（近端小管、空肠）转运是等渗而大量的。

另有两种特化依赖膜转运机器。在**肌与神经**，表面膜以及（在肌）横管膜上的电压门控通道使动作电位在一毫秒内抵达收缩装置。在**腺泡与导管细胞**，受调节的氯或钾分泌渗透地带动水，形成唾液、胰液与胆汁——而这正是被霍乱毒素劫持、从而造成大量分泌性腹泻的机器。

::: example 膜骨架，而非代谢缺陷 {#ex-spherocytosis}
一名19岁患者有黄疸、脾大、血红蛋白92 g/L、网织红细胞12%、MCHC升高、Coombs试验阴性，血涂片见球形红细胞；其母24岁时因胆囊切除。请解释病理生理，并说明为何切脾有效。
::: solution
这是遗传性球形红细胞增多症，多为常染色体显性遗传，由膜骨架蛋白——ankyrin、spectrin、band 3或蛋白4.2——缺乏所致。脂双分子层与spectrin网络之间纵向连接的丢失使膜以小泡形式丢失：面积减少而体积不变，于是细胞成为表面积/体积比很低的球。球形红细胞无法变形通过脾索的狭窄裂隙，被困于低氧、低糖的脾内环境而过早死亡——血管外溶血，非结合胆红素升高并形成色素性结石。MCHC升高是诊断线索（相对细胞脱水），渗透脆性试验或eosin-5-马来酰亚胺结合流式细胞术可确认膜缺陷。切脾消除了破坏场所，而非缺陷本身：血涂片仍有球形红细胞，但它们能存活。故治疗是对症的，且须终身接种荚膜细菌疫苗。
:::
:::

::: history
活体组织的半透性由Lazzaro Spallanzani在1760年代以膀胱与肠的稀释液实验证明。1855年Adolf Fick在二十余岁时写下仍以他命名的扩散定律；Jacobus van t Hoff在1877年证明稀溶质按气体定律产生渗透压，这项工作为他赢得首届诺贝尔化学奖。Walther Nernst于1888年导出其方程，Julius Bernstein在1902年提出静息电位是由离子通透性决定的扩散电位。David Goldman于1943年给出恒场方程；Alan Hodgkin与Andrew Huxley在1952年用乌贼巨大轴突定量描述了动作电位，Erwin Neher与Bert Sakmann在1976年以膜片钳记录了单个通道。脂双分子层本身由Gorter与Grendel于1925年提出，被Davson与Danielli于1935年画成蛋白质-脂质-蛋白质三明治，1972年被Singer与Nicolson的流动镶嵌模型取代。Roderick MacKinnon于1998年发表钾通道晶体结构，最终以原子细节解释了为何选择滤器偏爱钾而非钠；编码CFTR的囊性纤维化基因则由John Riordan、Lap-Chee Tsui与Francis Collins于1989年克隆。
:::

## 通向何处

此处所述的膜电位是兴奋组织的基础，见[[physiology/membrane-potentials]]与心电图[[cardiovascular/electrophysiology-ecg]]。酶的饱和与载体动力学见[[cell-biochemistry/proteins-enzymes]]。体液间隙、Starling力与水肿见[[physiology/homeostasis-body-fluids]]与[[pathology/haemodynamics]]。通道与泵的药理学见[[pharmacology/autonomic-drugs]]。

::: summary
- 双分子层是能自封闭的脂质溶液：对气体与脂溶性分子通透，对离子与极性溶质不通透，后者需要通道或载体。
- 通道快速、有门控、有选择性；载体缓慢、特异且可饱和，其$J_{\max}$在肾形成阈值，并限制药物分泌。
- 原发性主动转运（Na⁺/K⁺-ATP酶、H⁺-ATP酶、Ca²⁺-ATP酶）消耗ATP建立梯度；继发性主动转运用梯度运送其他溶质。
- 离子受电化学梯度驱动：37 °C时$E_{\text{ion}} = 61.5/z \log_{10}([\text{外}]/[\text{内}])$；静息电位最接近$E_K$，钾紊乱通过改变它而发病。
- 决定水去向的是张力而非渗透浓度；尿素与乙醇有渗透活性但平衡后即失效，输注液体的分布取决于其所含不可通透的溶质。
- 上皮转运源自转运体的极性分布；CFTR丧失使分泌物阻塞，CFTR过度激活导致分泌性腹泻。
- 膜疾病包括通道病与膜骨架缺陷，如遗传性球形红细胞增多症。
:::

## 练习

::: exercise 通透性与结构 {level=1}
按穿越纯脂双分子层的能力排序：氧气、葡萄糖、钠、乙醇、菊糖（一种5 kDa多糖）。并说明排序依据的两三条原理。
::: solution
氧 > 乙醇 > 葡萄糖 > 钠 > 菊糖。原理是大小（小者更快）、电荷（离子无论多小基本被排除）与脂溶性（分配系数，使乙醇优于葡萄糖）。菊糖等大分子只能经孔道或囊泡转运，这就是它被用作细胞外间隙与肾小球滤过标志物的原因。
:::
:::

::: exercise 临床中的饱和 {level=1}
一名孕妇血糖7 mmol/L时尿中出现葡萄糖，但她并非糖尿病。请给出转运方面的解释。
::: solution
滤过葡萄糖负荷$=$ GFR $	imes$ 血糖。妊娠使GFR升高约50%，即使血糖正常，滤过负荷也可超过肾小管对葡萄糖的$T_m$：转运体饱和，肾阈值下降，于是出现糖尿。教训是阈值同时取决于$T_m$与滤过率，故糖尿本身并不等于糖尿病——而血糖升高伴糖尿则属预期。
:::
:::

::: exercise 能斯特 {level=1 check=“round(61.5*log10(8/150))”}
计算37 °C时细胞外K⁺为8 mmol/L、细胞内K⁺为150 mmol/L时的钾平衡电位，结果以mV表示并取整数。
::: solution
$E_K = 61.5\log_{10}(8/150) = 61.5 \times (-1.273) \approx -78$ mV。
:::

::: exercise 哪一步转运？ {level=2}
指出下列各过程的转运体或通道，并判断属原发性主动转运、继发性主动转运、易化扩散还是通道：(a) 近端小管顶膜的葡萄糖进入；(b) 同一细胞基底侧的葡萄糖出胞；(c) 醛固酮调控下集合管对滤过钠的重吸收；(d) 心肌细胞收缩后排钙；(e) 心肌动作电位的上升支。
::: solution
(a) SGLT2，继发性主动转运（Na⁺同向转运）。(b) GLUT2（某些种属/节段为GLUT1），易化扩散，顺a)所造成的浓度梯度。(c) ENaC，一种上皮钠通道；醛固酮增加其数量与开放概率，而基底侧Na⁺/K⁺-ATP酶属原发性主动转运。(d) 主要为Na⁺/Ca²⁺交换体（继发性主动转运，由钠驱动），另有少量肌膜Ca²⁺-ATP酶。(e) 电压门控钠通道。注意一个上皮包含多少环节，以及*基底侧*的泵出现缺陷会限制其中所有环节。
:::
:::

::: exercise 渗透压间隙 {level=2 check=“42”}
一名患者被发现昏迷。钠140 mmol/L，葡萄糖8 mmol/L，尿素5 mmol/L，血浆渗透摩尔浓度实测335 mOsm/kg。计算渗透压间隙，并说出如此大的间隙最常见的原因。
::: solution
计算值$= 2(140) + 8 + 5 = 293$ mOsm/kg，故间隙为$335 - 293 = 42$ mOsm/kg。如此量级的间隙意味着大量未测定的小分子渗透物质——典型为乙醇；而临床上危险的原因包括甲醇、乙二醇、异丙醇、丙二醇（来自输液）、甘露醇，或严重酮症酸中毒时的丙酮。应同时核对阴离子间隙与渗透压间隙，若病史不清则按中毒处理。
:::
:::

::: exercise 自由水 {level=2 check=“14”}
若总体水36 L、血钠140 mmol/L的患者潴留4 L电解质自由水，估算血钠下降的幅度（mmol/L）。（假定钠含量不变，且水在总体水中平衡。）
::: solution
新血钠$= 140 \times 36/40 = 126$ mmol/L，下降14 mmol/L——每潴留1 L水约降3.5 mmol/L，而实际上会更多，因为潴留的水还会引发利钠。这解释了为何给低钠患者大量低张液体可使血钠过快下降，以及为何急剧下降会引起头痛、癫痫（在未适应的脑中）脑疝。
:::
:::

::: exercise 病房中的张力问题 {level=3}
两位患者血钠均为128 mmol/L。A实测渗透摩尔浓度288 mOsm/kg、计算值267 mOsm/kg、甘油三酯55 mmol/L。B实测渗透摩尔浓度305 mOsm/kg，葡萄糖42 mmol/L，尿素5 mmol/L，pH正常。哪位是低渗性低钠血症？处理上有何含义？
::: solution
两位都不是——或者说只有A算，而A是伪象。A中升高的脂类置换了血浆中的水，故按每升*血浆*测得的钠假性偏低，而每升血浆水的钠（以及脑所体验的张力）正常：这是假性低钠血症，见于严重高脂血症与副蛋白血症，识别要点是实测渗透摩尔浓度正常而依钠计算的值偏低。用直接离子选择电极或血气分析仪可获得正确数值。B中葡萄糖是有效渗透分子，把水从细胞内吸出而稀释钠：血糖每高于正常5.6 mmol/L，校正钠上升约1.6–2.4 mmol/L，故真实性钠约为$128 + 16 \approx 144$ mmol/L，患者实为高渗且很可能失水。把两者当低钠血症给予高渗盐水均有害；正确的处理分别是安慰观察与胰岛素加补液。
:::
:::

::: exercise 一枚泵的两副面孔 {level=3}
一名因房颤服用地高辛的患者因呕吐入院，血钾3.0 mmol/L（此前服用噻嗪类）；心律现为缓慢室性心律并间断交界性心动过速。请用膜转运解释这一相互作用，并说明为何低钾会增强地高辛作用。
::: solution
地高辛抑制Na⁺/K⁺-ATP酶。在心肌，这使胞内钠升高、Na⁺/Ca²⁺交换体的驱动力下降、可供肌浆网利用的钙增多，从而增强收缩力——即治疗作用。毒性则主要为电学现象：胞内钙升高激活钠-钙交换体的内向电流（瞬时内向电流，去极化），产生延迟后除极与异位节律，同时迷走效应与直接效应使房室结传导减慢——故心房颤动变慢与交界区加速性节律并存，是经典的地高辛中毒心律。低钾之所以要紧，是因为钾与地高辛竞争该泵细胞外侧的同一部位：可供置换的钾减少，则在任一血药浓度下结合药物的比例增多。腹泻与呕吐还因失镁而使问题加重，而肾功能不全升高药浓度，因为地高辛经肾排泄。处理为停药、谨慎纠正钾与镁，危及生命的中毒则给予特异性抗体片段。
:::
:::

::: exercise 上皮的逻辑 {level=3}
请用转运体的分布解释：(a) 醛固酮为何引起钠潴留与钾丢失；(b) amiloride为何能纠正Liddle综合征的高血压而螺内酯不能。
::: solution
醛固酮作用于集合管主细胞，经基底侧膜进入细胞并作用于（核内）受体，增加SGK1与ENaC的转录。更多顶膜钠通道纳入更多钠，后者由基底侧钠泵排出；由此产生的管腔负电位驱动钾经ROMK通道分泌并促进氢离子分泌，于是钠被保留而钾被丢失。Liddle综合征中ENaC γ亚基突变使其不能被内吞降解，故过多通道*不依赖醛固酮*地坐在顶膜上；钠潴留与高血压随之发生，肾素与醛固酮被抑制。螺内酯作用的受体通路已被绕过，故无效；amiloride直接阻断通道，是特异性治疗。这一对比例证了转运体层面推理的价值：同一终末通路可由作用于受体、通道或泵的药物达到，而其中只有一种有效。
:::
