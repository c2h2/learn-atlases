自主神经药物就是“受体生理学的临床应用”。**自主神经系统以两种化学物质管理内脏：乙酰胆碱作用于烟碱型与毒蕈碱型受体，去甲肾上腺素作用于α与β肾上腺素能受体——本类几乎每一个药物，都是在模仿、阻断、增强或耗竭其中某一次突触传递。**因为同一批递质全身到处都在使用，这些药物谈不上细腻：它们同时作用于心、肠、膀胱、眼、气道、汗腺与血管，所谓治疗窗通常就是一门“选择打哪个受体亚型”的艺术。本章把药理接到[[physiology/autonomic-nervous-system]]已经讲过的生理上。

## 胆碱的一侧

::: definition 毒蕈碱类药物与阻滞 {#def-muscarinic}
**乙酰胆碱作用于毒蕈碱受体（M1主腺体、胃与中枢，M2主心，M3主平滑肌、内皮与腺体），产生“休息与消化”的整套程序：M2激活窦房结钾通道造成心动过缓；M3造成支气管痉挛与分泌物增多；肠收缩、膀胱通尿肌收缩；瞳孔缩小与视近调节；以及出汗——出汗是胆碱能的，因为到汗腺的交感节后纤维例外地也是胆碱能，这一点解释了有机磷中毒患者的湿冷皮肤（生理复述见[[physiology/autonomic-nervous-system]]）。**
直接拟毒蕈碱药大多是生理工具——贝坦胆碱用于检查膀胱与唾液腺，毛果芸香碱用于青光眼史与口干（放射治疗后与干燥综合征的促唾用途，代价是多汗与腹泻），毒蕈碱本身则是证明受体存在的毒素——但临床真正的流量在阻断药。**抗毒蕈碱药清单：阿托品（心动过缓用药、有机磷解毒药，以及证据早已过期仍在用的术前用药）、东莨菪碱（晕动病贴剂，在老年人以意识混乱换疗效）、异丙托溴铵与噻托溴铵（吸入制剂靠沉积部位与动力学滞留制造“选择性”，用于哮喘与慢阻肺）、奥昔布宁、索利那新、托特罗定、达非那新与曲司氯铵（膀胱过度活动症的武器库，账单是认知、便秘与尿潴留；M3选择性、难以入血的季铵类药物曲司氯铵与经皮凝胶绕过首过的办法都为此而生）、费索特罗定的活性代谢产物与肾清除逻辑、托吡卡胺与环喷托酯与阿托品眼用制剂用于验光及弱视争论。**
还有一份长长的“意外抗胆碱负荷”清单：三环类、抗组胺药、抗精神病药、膀胱用药——以及它们与认知衰退的关联、与老年患者减药级联的必要性。解毒的对偶诗：毒扁豆碱能过血脑屏障，用于中枢抗胆碱综合征；新斯的明是季铵盐，只能做外周救援（与重症肌无力危象的鉴别正在于此）；而胆碱酯酶抑制的不选择性意味着每个器官同时参与治疗与中毒（胆碱能中毒的SLUDGE口诀，对照抗胆碱能口诀“热如兔、盲如蝠、干如骨、红如甜菜、疯如帽匠”——急诊同时上演的两种中毒综合征）——[[geriatrics-palliative/polypharmacy]]、[[psychiatry/treatments-mental-health-law]]、[[emergency-critical-care/poisoning]]。**
:::

## 肾上腺素能的一侧

::: definition 肾上腺素能药物与阻滞 {#def-adrenergic}
**去甲肾上腺素作用于α1（血管与括约肌收缩、瞳孔散大）、α2（突触前抑制、中枢交感撤退、血小板、胰腺）、β1（心率、收缩力、肾素）、β2（支气管与子宫舒张、血管扩张、震颤、钾内移）；肾上腺素则是过敏性休克中不加选择的主角，肌肉注射入股外侧肌——那里吸收最快也最可靠。**
拟交感药按选择性与给药途径排列：吸入β2激动剂从沙丁胺醇的速效缓解，到沙美特罗与福莫特罗的动力学——福莫特罗起效快而作用久，因此既能维持又能缓解，布地奈德-福莫特罗作为单一吸入器的MART逻辑，以及SMART策略关于过度使用阈值的证据（ADRB1-ADRB2-Arg16的受体脱敏遗传学争论要诚实地保留）；慢阻肺的长效β2激动剂加抗毒蕈碱药组合——[[respiratory/asthma-copd]]。α类药物：去氧肾上腺素用于麻醉低血压与鼻腔减充血；米多君用于体位性低血压（含屈度昔巴的故事），以及滴鼻剂戒断的咨询；去甲肾上腺素作为感染性休克的首选升压药（动脉导管与短外周导管的务实做法、血管加压素作为第二药、间羟胺与去氧肾上腺素输注、外渗时用酚妥拉明解毒）。多巴胺的“剂量区间神话”只留在历史里；多巴酚丁胺的正性肌力伴快速性心律失常；左西孟旦作为钙增敏剂的生态位（休克时“低血压”与“低心排”的区分）——[[cardiovascular/hypertension]]、[[cardiovascular/heart-failure]]、[[renal/urinary-tract]]、[[psychiatry/lifespan-psychiatry]]。**
**β阻滞剂按选择性细分：比索洛尔、阿替洛尔、美托洛尔的β1偏好，及其在哮喘中随剂量崩塌的“选择性”；卡维地洛、拉贝洛尔与奈比洛尔的一氧化氮机制。具内在拟交感活性的部分激动剂如吲哚洛尔（运动心率的悖论）；脂溶性决定中枢副作用与能否被透析清除（普萘洛尔用于偏头痛与震颤，对阿替洛尔的肾脏命运）。α阻滞的亚型：哌唑嗪的首剂晕厥与创伤后应激噩梦用途；坦索罗辛与西多多辛的α1A泌尿选择性缓解前列腺梗阻，以及每位眼科医师都会问麻醉医师的术中虹膜松弛综合征；育亨宾作为历史上的α2探针。** 利血平与胍乙啶以耗竭和摄取1阻断的方式，靠破坏受体生理学教会了受体生理学；现代再摄取抑制药的自主神经副作用（可卡因与三环类的交感增强、单胺氧化酶抑制药与酪胺的高血压危机教训）——[[pharmacology/metabolism-excretion]]、[[psychiatry/substance-use]]。**
:::

## 神经节、接头与肾上腺
::: definition 神经节、神经肌肉接头与肾上腺的药物 {#def-ganglion-NMJ}
**烟碱型受体做两件完全不同的工作：神经元型（富含α4β2）位于神经节与中枢，持续去极化时会封锁传递；肌肉型位于神经肌肉接头，逐个终板打开阳离子通道。神经节阻断药（六甲溴铵、三甲噻芬用于主动脉夹层与高血压危机的历史用途）证明了站立张力的交感主导——它们的体位性虚脱教给的生理学比任何教科书都多；临床上的后继者是中枢α2激动剂：可乐定（停药后高血压反跳、口干与镇静、用于注意缺陷多动障碍及阿片与酒精戒断的症状控制）与右美托咪定（重症监护镇静，可被唤醒，伴心动过缓与低血压）。伐尼克兰作为α4β2部分激动剂用于戒烟，金雀花碱的旧分子重新出现；中枢对神经节的选择性解释了戒烟药为何不引起体位性低血压——这是受体亚型选择性的示范案例——[[public-health/prevention-promotion]]、[[psychiatry/substance-use]]。**
在接头处，药理几乎是外科性的：**琥珀胆碱去极化（肌束颤动，随后二相阻断，钾释放使烧伤、失神经与肌强直患者危险；在兰尼碱受体触发恶性高热，解毒是丹曲林；假性胆碱酯酶变异导致延长窒息）。罗库溴铵等为竞争阻断，可被新斯的明加格隆溴铵逆转，甾体类药物还可被舒更葡糖包裹——后者的过敏率与肾清除问题、以及再箭毒化的边缘病例仍需讨论。肉毒毒素切割SNARE蛋白，制造化学性失神经：局部对远隔扩散、抗体介导的治疗失败、以及医源性扩散的警示，各有各的解毒逻辑——[[surgery/anaesthesia-pain]]、[[nervous-system/neuromuscular]]。**
肾上腺髓质的程序（嗜铬细胞作为修饰的节后神经元，把肾上腺素、去甲肾上腺素与多巴胺分泌入血）是整个系统的药理学基准：**嗜铬细胞瘤就是一台自行输注拟交感药的肿瘤——先α阻滞再β阻滞的教义、只用普萘洛尔导致高血压危机与肺水肿的病例报告、变肾上腺素的生化与可乐定抑制试验的生理、以及偶发瘤的检查流程。副神经节瘤的遗传学与MEN、VHL、NF1的关联，把受体机器串成内分泌、肾、皮肤与眼科的一小时邻接之旅（未经对抗的α效应同样解释了可卡因胸痛——β阻滞时机仍有争议——以及麦角与曲普坦的血管警示）——[[endocrine/adrenal]]、[[genetics/cancer-genetics]]、[[endocrine/endocrine-emergencies]]。**
:::

::: example 抗胆碱负荷的核查 {#ex-anticholinergic}
一位82岁独居患者因失眠服阿米替林、因膀胱服索利那新、因瘙痒服氯苯那敏、因痉挛服丁溴东莨菪碱，另服帕罗西汀；她便秘、口干、夜间意识混乱，已跌倒两次。
::: solution
**减药即“拮抗作用求和”（[[#def-muscarinic]]、[[geriatrics-palliative/polypharmacy]]、[[nervous-system/dementia-neurodegeneration]]）：算术是关键——每一张处方的抗毒蕈碱分值都加在同一批受体上，因此患者体验到的是一次分散在五个处方里的过量。高负荷分值与认知衰退及跌倒的关联要诚实地连同混杂因素一起读；而住院时重复入院清单、从不问为什么的做法，本身就在制造谵妄——[[clinical-skills/patient-safety]]。撤药计划：帕罗西汀自带抗胆碱与撤除特征，应缓撤而非骤停；氯苯那敏换成非镇静替代，或以润肤与皮肤屏障处理解决瘙痒；失眠转向认知行为治疗与睡眠卫生，并重新评估抑郁问题（换用5-羟色胺药的争论、曲唑酮与米氮平各自有镇静、低钠与跌倒代价）；索利那新尝试停药并用排尿日记与盆底训练先行；丁溴东莨菪碱则改为便秘管理复查，而不是再加解痉药（肠易激指南里解痉药只是辅助，而这类清单常掩盖粪嵌塞与溢出性失禁的肛门检查）——[[psychiatry/mood-disorders]]、[[gastrointestinal/bowel-disease]]。**
教学部分：把两种中毒综合征与本人“干、糊、便秘、尿潴留、心率快”的画面作对照；重度中枢抗胆碱谵妄可用毒扁豆碱，现实则是支持治疗、苯二氮类、降温与导尿（鉴别感染、5-羟色胺综合征与神经阻滞剂恶性综合征）——[[emergency-critical-care/poisoning]]。系统习惯：抗胆碱负荷工具是对话起点，不是自动停药指令；药物复查要先把患者自己的目标写下来（控尿与清醒孰先孰后由她排序，而不是由表单排序），并安排照护者、社区药师与全科医师的信件、跌倒门诊与骨风险评估——髋部骨折的算术使“减停镇静性膀胱药”成为一项降低死亡率的干预——[[clinical-skills/communication]]、[[musculoskeletal/fractures]]。**

::: example 围手术期用药清单的复查 {#ex-periop-autonomic}
日间手术患者，患糖尿病、高血压、哮喘与前列腺增生，带来：雷米普利、氨氯地平、多沙唑嗪、按需沙丁胺醇、胰岛素与坦索罗辛。清单上少了三个问题与一个术中麻烦。
::: solution
**自主神经用药清单核查（[[#def-adrenergic]]、[[#def-muscarinic]]、[[surgery/anaesthesia-pain]]）：三个缺失的问题——鼻腔减充血剂史（羟甲唑啉与赛洛唑啉成瘾造成反跳性鼻塞，术中干扰拟交感药受体的α张力）；可乐定（围手术期停用会高血压反跳，继续则与其他药物叠加镇静与心动过缓）；降眼压眼药（噻吗洛尔滴眼产生全身β阻滞，在哮喘患者可致支气管痉挛与心动过缓；溴莫尼定的α2镇静与婴儿呼吸暂停，及其与单胺氧化酶抑制药和三环类的相互作用）——[[nervous-system/sensory-systems]]。术中麻烦：坦索罗辛等α1A阻滞剂引起术中虹膜松弛综合征，瞳孔扩张不良并有玻璃体与视网膜并发症，外科医师需要药名、疗程甚至数年前已停用的历史；麻醉含义是α阻滞叠加丙泊酚会造成深度低血压（需调整升压药选择与补液策略）——[[surgery/perioperative-care]]。**
当日流程：支气管扩张剂要带来；已长期服用的β阻滞剂围手术期继续（按滴定与低血压心动过缓警示，而非手术当天以高剂量新起，参考POISE的剂量递增教训）；血管紧张素转换酶抑制药在硬膜外与全身麻醉前停用或减量（术中难治性低血压，以及难治性血管麻痹用血管加压素与特利加压素的证据）；多沙唑嗪应停，因其体位性与跌倒风险、而它治疗增生的角色本身可疑（坦索罗辛对度他雄胺对经尿道切除的决策逻辑、5α还原酶抑制药对前列腺特异性抗原的解读与性功能副作用、排尿后训练、以及试拔尿管路径）——[[renal/urinary-tract]]。糖尿病层：胰岛素与禁食及激素和止吐药的变化（无碳水时的低血糖、禁食时磺脲类的停药、GLP-1激动剂延迟胃排空的误吸询问指导、以及SGLT2抑制剂在禁食麻醉下的正常血糖酮症酸中毒）——[[endocrine/diabetes]]、[[surgery/anaesthesia-pain]]。**

::: example 引起喘息的那瓶降眼压药水 {#ex-timolol-wheeze}
一位哮喘患者68岁，因青光眼开始用噻吗洛尔滴眼；六周后缓解吸入剂用量翻倍，并且乏力；全科医师只是让她更频繁使用沙丁胺醇，并考虑加长效β2激动剂。
::: solution
**眼科用药的全身效应（[[#def-adrenergic]]、[[respiratory/asthma-copd]]、[[nervous-system/sensory-systems]]）：机制——滴眼液流入鼻与泪道，被咽下后经结膜吸收，绕过首过代谢，因此一瓶眼药等于一剂剂量未知的非选择性口服β阻滞剂（心动过缓、乏力、支气管痉挛、掩盖低血糖的病例文献，以及脂溶性驱动的中枢与睡眠报告）；滴鼻剂的教训同理。处方错误——哮喘患者用β阻滞剂是禁忌症审查失败的经典案例；对策是换前列腺素类似物、或谨慎选β1选择性滴眼、或按眼科医师的目标眼压逻辑改用另一类（拉坦前列素的虹膜与睫毛改变及囊样黄斑水肿与单疱角膜炎警示、多佐胺与磺胺的邻缘、溴莫尼定的乏力与单胺氧化酶抑制药相互作用及对婴儿的呼吸暂停——绝不分瓶共用）。处理——与眼科医师沟通后停用或替换，注意停药期间眼压反跳的安全间隙；并且要明白：在未识别的β阻滞状态下加长效β2激动剂，是在治药而不是治病。若β阻滞剂无法避免，可教指压泪点与闭眼以减少吸收——数字上要诚实，只是部分帮助——[[clinical-skills/patient-safety]]、[[clinical-skills/communication]]。**

::: example 透析中低血压的患者 {#ex-dialysis-hypotension}
一位血液透析患者服多沙唑嗪、氨氯地平与雷米普利，每次治疗最后一小时反复血压塌陷；肾内科说“干体重设得太低”，患者说“药在病房冰箱，下午两点吃”。
::: solution
**当自主神经阻滞遇上超滤（[[#def-adrenergic]]、[[renal/chronic-kidney-disease]]、[[cardiovascular/hypertension]]）：塌陷的生理——超滤移除血浆容量，而代偿性交感反应（压力反射介导的血管收缩与心动过速）被α阻滞、血管扩张与血管紧张素转换酶抑制同时切除（对照自主神经衰竭的失衡综合征，以及应当寻找的糖尿病自主神经病变）——[[physiology/autonomic-nervous-system]]、[[endocrine/diabetes]]。按优先级的对策：治疗前与治疗中停抗高血压药（把给药时间从“晨服”改为“透析后”，并整体重新考虑多沙唑嗪在增生与低血压之间的取舍）；重新评估干体重与超滤速率，采用更慢更长的治疗、低温透析液、钠曲线，以及米多君治疗透析中低血压的证据——注意这类患者常同时有卧位高血压，氟氢可的松与米多君对舍曲林的读法要权衡。**
药物复查的机制：透析中心与全科共用一份清单，把每次治疗的给药时间写清楚；体重持续下降时重新评估抗高血压方案（“烧尽的高血压”现象——血管变硬与干体重变化后需要减药），以及透析中运动与压力袜等辅助手段（证据有限）。教学要点：这就是每小时350毫升的体位性低血压药理；同样的推理保护那位夜里起身、正在服α阻滞剂的衰弱患者——[[geriatrics-palliative/falls]]、[[musculoskeletal/fractures]]。**

## 通向何处

这些药物所利用的生理在[[physiology/autonomic-nervous-system]]展开；受体机器见[[pharmacology/drug-receptor]]；中毒综合征见[[emergency-critical-care/poisoning]]与[[nervous-system/neuromuscular]]；呼吸科应用见[[respiratory/asthma-copd]]。

::: history
**这一类药物正是受体科学的诞生地：1920年代奥托·洛伊的“迷走物质”实验——用另一只被刺激迷走神经的蛙心的灌注液去灌流第二颗心，使其减慢——证明了化学性神经传递（从梦到笔记本的故事，以及1936年与亨利·哈莱特的诺贝尔奖；后者的“肾上腺素样”与“乙酰胆碱样”命名框定了整个领域）——[[physiology/synapses]]。随后的结构计划——哈莱特与伯勒合成更简单的乙酰胆碱类似物，阿托品与毒蕈碱的分离造出了“毒蕈碱型”与“烟碱型”两个词，以及阿尔奎斯特1948年提出α与β肾上腺素能受代的论文：一位药理学家的猜测，比一切分子替代方案多活了三十年——[[pharmacology/drug-receptor]]。**
治疗收获：β阻滞剂的故事——詹姆斯·布莱克以异丙肾上腺素拮抗为起点的理性设计造出普萘洛尔，并身体力行：1988年诺贝尔奖；更早的麦角来源的二异丙肾上腺素同时揭示了受体与它的心律失常——[[cardiovascular/hypertension]]、[[cardiovascular/coronary-artery-disease]]。抗胆碱酯酶时代：阿托品的古老、19世纪的颠茄化学、1940至50年代的合成季铵（甲氯胺、普鲁本辛与“设计上更少中枢作用”的逻辑——在“基于结构开发药物”这个说法出现之前的范例），以及有机磷的双重历史（施拉德特的杀虫剂、德国战时项目的沙林与梭曼遗产，以及同源化学孕育的新斯的明、艾酚氯铵与氯解磷定解毒科学）——[[emergency-critical-care/poisoning]]、[[pathology/environmental-pathology]]。现代的精修：α1A泌尿选择性的克隆时代、噻托溴铵的动力学选择性及其慢阻肺死亡率声明之争、吸入三联治疗中长效抗毒蕈碱加长效β的组合、以及舒更葡糖的包裹式设计——以直接化学解毒重写神经肌肉监测——全部是把受体亚型选择性包装成便利性——[[respiratory/asthma-copd]]、[[surgery/anaesthesia-pain]]。**
:::

::: summary
- 自主神经药物在全身作用于同一批递质，因此疗效与副作用都是器官范围的；选择性只是受体亚型、给药途径与动力学的问题。
- 抗毒蕈碱负荷跨处方累积，可预测意识混乱、便秘、尿潴留、跌倒与功能衰退——按患者的目标减药，而不是按表单减药。
- 拟交感药按受体谱与途径选择；β2激动剂过度使用是哮喘控制不佳的标志，含福莫特罗的方案改变了缓解用药策略。
- β阻滞是相对且随剂量变化的选择性；“继续既有的β阻滞剂”对比“围手术期谨慎起始”，是药物管理学中重复验证最充分的发现之一。
- 神经节与神经肌肉接头各有专门药物：去极化对竞争阻断、新斯的明或舒更葡糖逆转、肉毒毒素作为化学失神经。
- 嗜铬细胞瘤、有机磷与抗胆碱中毒是本类的临床考试：两种中毒综合征，一张受体地图。
:::

::: exercise 评价一项新β阻滞剂的主张 {level=3}
一项试验报告：在标准心衰治疗上加奈比洛尔优于美托洛尔，且呼吸事件更少。请评价其机制主张、试验设计问题，以及是否应当更换患者用药。
::: solution
**β阻滞剂主张评估（[[#def-adrenergic]]、[[epidemiology-ebm/critical-appraisal]]）：机制可信度——奈比洛尔的β1选择性加一氧化氮介导的血管扩张，带来“较少心动过缓”的血流动力学与支气管叙事；β3与抗氧化主张可信但人体效应小；对脂代谢与胰岛素敏感性的优势向硬终点转化很弱。本类的关键证据来自不同试验人群：卡维地洛、美托洛尔、比索洛尔与老年奈比洛尔的证据库不可互换（“类效应”对“药效应”之争、以及非劣效设计的限度）。试验问题：对照药剂量是否等效、滴定是否成功；副作用谱不同使盲法可被质疑；呼吸终点的判定方式（“更少呼吸事件”是指更少β2事件，还是计入更多缓解吸入剂）；背景治疗是否达到盐皮质激素、SGLT2与血管紧张素脑啡肽酶抑制剂的当代标准；替代终点与硬终点的权重。**

## 练习

::: exercise 受体对应效应 {level=1}
写出以下受体与第二信使：窦房结的M2、支气管平滑肌的M3、心肌细胞的β1、小动脉平滑肌的α1、突触前的α2。
::: solution
**受体—信使演练（[[#def-muscarinic]]、[[#def-adrenergic]]）：M2走Gi，激活钾通道并减少钙电流，故心率减慢（迷走药理；移植心去神经后阿托品反应不同的现实）——[[cardiovascular/cardiac-cycle]]。M3走Gq-磷脂酶C-三磷酸肌醇-钙，作用于气道与肠平滑肌；内皮上的M3释放一氧化氮，因此全身性拟毒蕈碱药可在收缩气道的同时降低血压（β2与茶碱在平滑肌舒张上的汇聚）——[[respiratory/mechanics-breathing]]。β1走Gs-cAMP-蛋白激酶A，增强钙处理、心率与肾素释放（β2过量的心动过速、震颤与低钾；β阻滞剂的肾素效应）——[[renal/water-sodium]]。α1走Gq，造成血管收缩、瞳孔散大与括约肌张力（坦索罗辛与虹膜、以及反射性心动过缓的故事）。α2走Gi，减少中枢与外周去甲肾上腺素释放——可乐定的撤除性交感风暴与右美托咪定同类、莫索尼定的咪唑啉受体辅助、育亨宾的历史探针，以及变肾上腺素解读中的混杂（可乐定抑制试验的生理）——[[endocrine/adrenal]]、[[physiology/autonomic-nervous-system]]。**

::: exercise 选择吸入装置 {level=1}

反复口服激素的哮喘——升级控制药、核查依从性与技术、考虑加长效抗毒蕈碱，然后按嗜酸性粒细胞、免疫球蛋白E与呼出一氧化氮评估生物制剂资格；而“长效β2激动剂绝不单用”是哮喘死亡流行给本类上的最重要一课——[[respiratory/control-breathing-tests]]、[[clinical-skills/communication]]。**

::: exercise 处理两种中毒综合征 {level=2}
一位患者皮肤湿冷、心率慢、瞳孔小并有肌束颤动；另一位皮肤干、心率快、瞳孔大、意识混乱且体温高。请说出综合征、机制与解毒逻辑。
::: solution
**两种中毒综合征（[[#def-muscarinic]]、[[#def-ganglion-NMJ]]）：胆碱能危象——有机磷抑制胆碱酯酶（毒蕈碱过量：DUMBELS；烟碱：无力、肌束颤动、瘫痪；中枢：意识混乱、癫痫、呼吸暂停）。阿托品滴定至分泌物干燥（剂量大且需递增、纯抗毒蕈碱逻辑、先给氧与吸引），氯解磷定在酶“老化”之前使其复活（与作用剂与时间窗相关），苯二氮类控制癫痫，去污与职业性或神经性毒剂背景，阿托品输注时长与新合成酶的老化，以及中间综合征与迟发神经病变的随访——[[emergency-critical-care/poisoning]]、[[pathology/environmental-pathology]]。**
抗胆碱能谵妄——阻滞造成高热、心动过速、皮肤与黏膜干燥、尿潴留、瞳孔散大与躁动；需与5-羟色胺综合征（阵挛、出汗、腹泻）及神经阻滞剂恶性综合征（铅管样强直、高热、肌酸激酶升高、自主神经不稳与多巴胺阻断；用溴隐亭与金刚烷胺，高热用丹曲林）鉴别——[[psychiatry/psychotic-disorders]]、[[nervous-system/movement-disorders]]。毒扁豆碱之问：诊断确切时可用它逆转中枢抗胆碱谵妄，床旁须备阿托品，并警惕三环类引起的传导障碍；现实中的主力仍是支持治疗、苯二氮类、降温与导尿——[[nervous-system/dementia-neurodegeneration]]。**

::: exercise 评述β阻滞剂的争论 {level=3}
就下列主张分别评述正反两面：“β阻滞剂在房颤心率控制中被过度处方，在心衰中被不足使用，并在围手术期被错误地以新起高剂量处方。”
::: solution
**三段式评述（[[#def-adrenergic]]、[[epidemiology-ebm/critical-appraisal]]）：房颤过度使用——节律对心率的试验（RACE与AFFIRM时代显示节律策略不劣）、β阻滞剂与钙通道阻滞剂的心率控制效力研究、运动耐量与低血压等副作用，以及“治疗疾病对治疗危险因素”之争（体重、酒精、睡眠呼吸暂停与甲状腺）——[[cardiovascular/arrhythmias]]。心衰不足使用——实施缺口：出院时的起始与滴定方案、护士主导的门诊、以检查结果为触发的处方；不恰当搁置的理由（哮喘史的审计、“太累”的归因错误），以及卡维地洛、比索洛尔、琥珀酸美托洛尔缓释与奈比洛尔在射血分数降低人群中的证据——[[cardiovascular/heart-failure]]、[[respiratory/asthma-copd]]。**
围手术期的错误处方——POISE-1在急性期以大剂量新起始时再梗死减少而卒中与死亡增多；与之对照的是既有治疗继续使用的数据。教训是“变化方向”规则：长期服用者继续，手术当天不要新起，择期则以数周为尺度滴定；并以“低血压与心动过缓是伤害的中介”来解读结果、遵循国家卫生与卓越优化研究所的剂量递增停止规则、在术前评估门诊落实、并以共同决策表述。元论点：同一类药物可以既在有死亡率证据之处被不足使用，又在症状控制的惯性下被过度处方；两者都是处方质量问题，但解法不同——[[surgery/perioperative-care]]、[[clinical-skills/clinical-reasoning]]。**
