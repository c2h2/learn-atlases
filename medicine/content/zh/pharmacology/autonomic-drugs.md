自主神经系统控制心脏、血管、气道、胃肠道、膀胱、眼和腺体，大多在我们不知不觉中进行。它只使用少数几种化学递质和寥寥几类受体，而模拟或阻断这些递质的药物是医学中使用最广泛的药物之一：β受体阻滞药、沙丁胺醇、肾上腺素、阿托品、异丙托溴铵、坦索罗辛，以及麻醉中使肌肉松弛的药物和逆转它们的药物。

由于这个系统如此有序，其药理学可以从生理学推导出来。只要知道某组织使用哪种受体、该受体起什么作用，就能推断出作用于该处的任何药物的主要效应和不良反应。本章先列出这张图谱，然后依次讨论拟胆碱药、神经肌肉阻滞药和肾上腺素能药物。生理学部分在[[physiology/autonomic-nervous-system]]中有更深入的介绍，受体原理见[[pharmacology/drug-receptor]]。

## 自主神经图谱 {#sec-map}

自主神经系统的两个分支都以两级神经元链从中枢神经系统通向靶器官。**节前**神经元从脑干或脊髓走向神经节；**节后**神经元从神经节走向效应器。

::: definition 自主神经与躯体运动系统的递质和受体 {#def-ans}
- 在**所有自主神经节**中，无论交感还是副交感，节前神经元都释放**乙酰胆碱**（ACh），作用于**烟碱型（$\mathrm{N_N}$）受体**，即配体门控离子通道。
- **副交感**节后神经元向**毒蕈碱受体**（临床上重要的亚型为M₁–M₃）释放ACh，这些受体是G蛋白偶联受体。
- 大多数**交感**节后神经元向**肾上腺素受体**（α₁、α₂、β₁、β₂、β₃）释放**去甲肾上腺素**，这些受体同样是G蛋白偶联受体。例外是支配大多数汗腺的交感纤维，它们释放ACh，作用于毒蕈碱受体。
- **肾上腺髓质**是一个特化的交感神经节。其嗜铬细胞受节前纤维刺激后，主要向血液中释放**肾上腺素**（也有部分去甲肾上腺素）。
- **躯体运动神经元**在骨骼肌的神经肌肉接头处释放ACh，作用于**烟碱型（$\mathrm{N_M}$）受体**。

递质作用的终止方式各不相同。ACh在突触间隙内被**乙酰胆碱酯酶**在数毫秒内水解。去甲肾上腺素主要被**去甲肾上腺素转运体**（NET，“摄取1”）重新摄入神经末梢，然后重新装入囊泡或被**单胺氧化酶**（MAO）降解；循环中的儿茶酚胺还被**儿茶酚-O-甲基转移酶**（COMT）降解。
:::

对药物效应最重要的受体总结如下。药物的效应取决于它作用于哪些受体，以及在哪些组织中。

| 受体 | 主要分布 | 激动后的效应 |
|---|---|---|
| M₁ | 中枢神经系统、胃壁细胞（间接） | 认知；胃酸分泌 |
| M₂ | 心脏（窦房结和房室结） | 心率减慢，房室传导减慢 |
| M₃ | 气道、胃肠道和膀胱平滑肌；腺体；虹膜括约肌；血管内皮 | 支气管收缩、胃肠蠕动、膀胱收缩、分泌、瞳孔缩小、经一氧化氮的血管舒张 |
| α₁ | 血管平滑肌；虹膜开大肌；膀胱颈和前列腺 | 血管收缩、瞳孔散大、膀胱出口收缩 |
| α₂ | 突触前神经末梢；脑干 | 去甲肾上腺素释放减少；交感传出减少 |
| β₁ | 心脏；球旁细胞 | 心率加快、收缩力和传导增强；肾素释放 |
| β₂ | 气道平滑肌；骨骼肌小动脉；子宫；肝脏；骨骼肌 | 支气管扩张、血管舒张、子宫松弛、糖原分解、钾进入细胞、震颤 |
| β₃ | 膀胱逼尿肌；脂肪组织 | 逼尿肌松弛；脂肪分解 |

大多数器官同时接受两个分支的支配，二者通常相互拮抗。静息心率以迷走（副交感）张力为主，因此用阿托品阻断毒蕈碱受体会使心率加快。相比之下，血管几乎只受交感神经支配，因此血管张力是通过改变交感活动来调控的，而不是依靠副交感的“刹车”。

## 拟胆碱药与抗胆碱药 {#sec-cholinergic}

增强胆碱能活动的药物称为**拟胆碱药**或拟副交感药。阻断毒蕈碱受体的药物称为**抗毒蕈碱药**（常称抗胆碱药）。

::: definition 毒蕈碱激动药、抗胆碱酯酶药与抗毒蕈碱药 {#def-muscarinic}
**直接毒蕈碱激动药**作用于毒蕈碱受体。毛果芸香碱（pilocarpine）使瞳孔缩小并增加房水引流；用于某些类型的青光眼，口服用于放疗后的口干。

**抗胆碱酯酶药**抑制乙酰胆碱酯酶，使ACh蓄积并作用于*所有*胆碱能突触，包括毒蕈碱型和烟碱型。可逆性抑制剂包括新斯的明（neostigmine）和吡斯的明（pyridostigmine），它们不能通过血脑屏障，用于逆转神经肌肉阻滞和治疗重症肌无力；以及多奈哌齐（donepezil）、卡巴拉汀（rivastigmine）和加兰他敏（galantamine），它们能进入脑内，用于阿尔茨海默病（[[nervous-system/dementia-neurodegeneration]]）。用作杀虫剂和化学武器的**有机磷酸酯**实际上不可逆地抑制该酶。

**抗毒蕈碱药**是毒蕈碱受体的竞争性拮抗药。举例及用途：

- 阿托品（atropine）：症状性心动过缓、减少分泌、有机磷中毒；
- 格隆溴铵（glycopyrronium）：减少分泌，并与新斯的明合用以阻断后者的毒蕈碱效应；为季铵类，不进入脑内；
- 氢溴酸东莨菪碱（hyoscine hydrobromide，能进入脑内；晕动病、临终分泌物）和丁溴东莨菪碱（hyoscine butylbromide，不能进入；胃肠和膀胱痉挛）；
- 异丙托溴铵（ipratropium，短效）和噻托溴铵（tiotropium，长效），用于慢阻肺的吸入性支气管扩张药；
- 奥昔布宁（oxybutynin）、索利那新（solifenacin）等，用于膀胱过度活动症；
- 托吡卡胺（tropicamide）和环喷托酯（cyclopentolate）滴眼液，用于检查时散瞳。
:::

全身阻断毒蕈碱受体会产生一种可预测的模式：口干和皮肤干燥，调节麻痹引起的视物模糊，瞳孔散大，心动过速，便秘，尿潴留，面色潮红，出汗减少引起的体温升高，以及药物进入脑内时的意识模糊和激越。传统的英文口诀是“干如骨、红如甜菜、盲如蝙蝠、热如野兔、狂如帽匠”。有两种并发症值得了解：抗毒蕈碱药可在房角狭窄的眼中诱发急性闭角型青光眼，在前列腺增大的男性中诱发尿潴留。

许多不被视为抗胆碱药的药物也阻断毒蕈碱受体：三环类抗抑郁药、氯苯那敏（chlorphenamine）等第一代抗组胺药、某些抗精神病药，以及治疗膀胱不稳定的药物。在老年人中，总的**抗胆碱能负荷**与意识模糊、跌倒和认知下降相关。抗胆碱能认知负荷（ACB）量表等工具为每种药物评1至3分并求和；总分高提示需要审查用药（[[geriatrics-palliative/polypharmacy]]）。

::: example 膀胱充盈的意识模糊男子 {#ex-anticholinergic}
一名84岁男性因意识模糊加重三天被送到急诊科。他的膀胱可触及且有压痛，体温37.8 °C，脉搏104次/分，皮肤干燥，瞳孔散大。他的用药包括治疗尿频的奥昔布宁、治疗神经病理性疼痛的阿米替林（amitriptyline，近期加量）、止痒的氯苯那敏，以及呋塞米（furosemide）。请解释这一表现，并说明如何审查这些药物。
::: solution
他的表现构成抗毒蕈碱（抗胆碱能）综合征：意识模糊、尿潴留、心动过速、皮肤干燥、出汗减少引起的轻度体温升高，以及瞳孔散大。他的药物中有三种具有强抗毒蕈碱作用。在ACB量表中，奥昔布宁、阿米替林和氯苯那敏各计3分，呋塞米计1分，总分10分；一般认为3分或以上即有临床意义。老年人尤其易感，因为脑内的胆碱能储备随年龄下降，而近期阿米替林加量增加了他的暴露。尿潴留本身会加重意识模糊，而为治疗他膀胱问题所用的奥昔布宁又促成了尿潴留。

处理原则：导尿以解除潴留，寻找谵妄的其他原因（感染、脱水、便秘、电解质），并尽可能停用或减少抗毒蕈碱药物，针对每种适应证考虑替代方案。审查应与本人及其照护者一起进行，因为其中一些药物是针对真实存在的症状开始使用的。谵妄的照护见[[geriatrics-palliative/delirium-dementia-care]]。
:::
:::

### 有机磷中毒

有机磷农药中毒是全球自我中毒死亡的主要原因之一，在亚洲农村尤为突出，也可见于职业暴露。乙酰胆碱酯酶被抑制后，ACh在每一个胆碱能突触蓄积。**毒蕈碱样**效应包括大量分泌（流涎、出汗、流泪、支气管溢液）、支气管收缩、呕吐、腹泻、尿失禁、心动过缓和瞳孔缩小。神经肌肉接头处的**烟碱样**效应包括肌束颤动，继而无力和麻痹，包括呼吸肌。**中枢**效应包括意识模糊、癫痫发作和昏迷。死亡通常源于呼吸衰竭，由分泌物、支气管痉挛、肌无力和中枢抑制共同造成。

处理原则是复苏，重视气道和氧合；在保护医护人员的前提下去污；给予**阿托品**，剂量逐步递增，直至肺部分泌物清除、心率适当、血压得以维持。阿托品阻断毒蕈碱效应，但对烟碱样肌无力无效，后者可能需要通气支持。解磷定（pralidoxime）等肟类药物若在酶“老化”成永久失活形式之前给予，可使酶复活，但临床试验并未显示一致的获益，其使用遵循地方毒理学建议（[[emergency-critical-care/poisoning]]）。

## 作用于神经肌肉接头的药物 {#sec-nmj}

::: definition 神经肌肉阻滞药 {#def-neuromuscular}
**神经肌肉阻滞药**作用于烟碱型$\mathrm{N_M}$受体，使骨骼肌松弛，以便气管插管和手术。它们对意识和疼痛没有作用，因此只能在充分麻醉下使用。

- **非去极化型**阻滞药，如罗库溴铵（rocuronium）、阿曲库铵（atracurium）和维库溴铵（vecuronium），是烟碱受体的竞争性拮抗药。可用抗胆碱酯酶药（新斯的明）提高接头处的ACh来逆转阻滞，同时给予格隆溴铵或阿托品，以防止多出的ACh产生毒蕈碱效应，尤其是心动过缓。罗库溴铵和维库溴铵还可被**舒更葡糖**（sugammadex）逆转，它是一种环糊精，能包裹药物分子，使其离开受体。
- **去极化型**阻滞药**琥珀胆碱**（suxamethonium）是一种激动药，它打开通道并使终板去极化，引起短暂的肌束颤动，随后使终板保持去极化状态，使肌肉无法反应。它起效极快、作用短暂，因为它被血浆**丁酰胆碱酯酶**水解。
:::

琥珀胆碱有若干源于其作用机制的危险。肌肉去极化释放钾离子；在健康人中升高幅度很小，但在终板外受体增生的情况下可能危险，如烧伤、挤压伤或去神经支配后。它是易感者**恶性高热**的诱因。在遗传性丁酰胆碱酯酶缺乏者中，其作用可持续数小时而不是数分钟（“琥珀胆碱呼吸暂停”），需要持续通气和镇静直至作用消退（[[pharmacology/patient-variation]]）。

## 肾上腺素能药物 {#sec-adrenergic}

激动肾上腺素受体的药物称为**拟交感药**。它们直接作用于受体，或间接地通过释放去甲肾上腺素或阻断其再摄取而起作用。阻断肾上腺素受体的药物为α受体阻滞药和β受体阻滞药。

::: definition 肾上腺素受体激动药与拮抗药 {#def-adrenergic}
**直接激动药**及其主要临床用途：

- **肾上腺素**（adrenaline，α和β）：严重过敏反应、心脏骤停，以及与局部麻醉药合用以减慢其吸收；
- **去甲肾上腺素**（noradrenaline，主要为α₁，兼有部分β₁）：脓毒性及其他分布性休克时的血管升压药；
- **多巴酚丁胺**（dobutamine，主要为β₁）：心源性休克时的正性肌力药；
- **异丙肾上腺素**（isoprenaline，β₁和β₂，无α）：等待起搏时的心动过缓和心脏传导阻滞；
- **沙丁胺醇**（salbutamol）和**特布他林**（terbutaline）（β₂，短效），以及**沙美特罗**（salmeterol）和**福莫特罗**（formoterol）（β₂，长效）：哮喘和慢阻肺；
- **去氧肾上腺素**（phenylephrine）和**间羟胺**（metaraminol）（α₁）：麻醉期间低血压；去氧肾上腺素也用作散瞳药和鼻减充血药；
- **可乐定**（clonidine，α₂，中枢）：减少交感传出；用于某些疼痛和戒断状态；
- **米拉贝隆**（mirabegron，β₃）：膀胱过度活动症。

**间接拟交感药**从神经末梢释放去甲肾上腺素（苯丙胺类、麻黄碱、伪麻黄碱），或阻断其再摄取（可卡因，以及在较小程度上某些抗抑郁药）。

**α受体阻滞药**：选择性α₁拮抗药，如多沙唑嗪（doxazosin，高血压）和坦索罗辛（tamsulosin，良性前列腺增大）；酚苄明（phenoxybenzamine）是不可逆的非选择性α拮抗药，用于嗜铬细胞瘤术前。

**β受体阻滞药**：β₁选择性（“心脏选择性”）药物，如比索洛尔（bisoprolol）、阿替洛尔（atenolol）、美托洛尔（metoprolol）和奈必洛尔（nebivolol）；非选择性药物，如普萘洛尔（propranolol）和噻吗洛尔（timolol）；以及兼有α₁阻断作用的卡维地洛（carvedilol）和拉贝洛尔（labetalol）。
:::

### 严重过敏反应中的肾上腺素

肾上腺素是严重过敏反应的首选治疗，因为它通过不同受体逆转每一个危及生命的环节：α₁激动使血管收缩并减轻黏膜水肿；β₁激动增加心输出量；β₂激动使支气管平滑肌松弛，并减少肥大细胞进一步释放介质。根据英国复苏委员会（Resuscitation Council UK）2021年指南，成人剂量为500微克肌内注射（1 mg/mL肾上腺素0.5 mL），注射于大腿前外侧，若无改善5分钟后重复，儿童剂量较小。肌内注射优于皮下注射，因为肌肉吸收更快、更可靠。静脉注射肾上腺素仅限于有监护条件的专科使用，因为快速静脉给药可引起心律失常和严重高血压（[[emergency-critical-care/anaphylaxis]]）。

服用β受体阻滞药的人在严重过敏反应中对肾上腺素可能反应不佳，因为其β效应被竞争性阻断，而未被对抗的α效应可使血压升高，支气管痉挛却持续存在。在这种情况下，有时在专科建议下使用胰高血糖素（glucagon），它通过自身受体升高cAMP。

### β受体阻滞药的临床应用

β受体阻滞药降低心率、心肌收缩力和肾素释放。其用途包括心绞痛、心肌梗死后二级预防、射血分数降低的心力衰竭（比索洛尔、卡维地洛、奈必洛尔和缓释美托洛尔，从小剂量开始缓慢加量）、心房颤动的心率控制、高血压（在NICE指南中不是一线选择，但在有其他适应证时使用）、甲亢的对症治疗、特发性震颤、偏头痛预防、以躯体症状为主的焦虑、门静脉高压中预防静脉曲张出血，以及以滴眼液形式治疗青光眼。

其不良反应可从受体图谱推知：

- β₂阻断引起的**支气管痉挛**，这就是哮喘患者一般避免使用β受体阻滞药的原因；慢阻肺患者慎用心脏选择性药物，通常耐受良好；
- β₁阻断引起的**心动过缓和心脏传导阻滞**，与维拉帕米或地尔硫䓬合用时加重；静脉注射维拉帕米与β受体阻滞药合用可致心脏停搏；
- 失去β₂血管舒张作用引起的**肢端发冷**及雷诺现象加重；
- **乏力**，以及普萘洛尔等脂溶性药物引起的**睡眠障碍和噩梦**；
- **低血糖感知减弱**，因为震颤和心悸是β受体介导的，接受胰岛素治疗者从低血糖中恢复也较慢；
- 长期治疗突然停药时，由于受体上调而出现心绞痛或心律失常的**反跳**；
- 在失代偿性心力衰竭时以过高剂量开始使用β受体阻滞药，可使心力衰竭急性加重。

::: example 引起喘息的青光眼滴眼液 {#ex-timolol-wheeze}
一名70岁加勒比黑人裔女性患有轻度哮喘，多年来使用小剂量吸入性糖皮质激素控制良好。因开角型青光眼开始使用噻吗洛尔滴眼液。此后数周她出现气短和喘息，峰流速比平时低30%，静息脉搏52次/分。滴眼液怎么会引起这些？
::: solution
噻吗洛尔是非选择性β受体阻滞药。每一滴未被眼吸收的药液都经鼻泪管流入鼻腔，经鼻黏膜直接吸收进入体循环，避开了肝脏的首过代谢（[[pharmacology/absorption-distribution]]）。全身浓度可高到足以阻断气道的β₂受体，在哮喘患者中引起支气管收缩，并阻断心脏的β₁受体，引起心动过缓。

原则：应与眼科团队一起审查滴眼液并选择替代药物，例如不影响气道的前列腺素类似物。教患者压迫鼻泪管（滴药后按压内眼角一分钟）可减少任何滴眼液的全身吸收。哮喘或有支气管痉挛病史者一般避免使用局部β受体阻滞药，BNF也如此建议。在药效消退期间，应审查她的哮喘治疗，必要时升级。
:::
:::

::: example 先α后β {#ex-phaeo}
一名41岁男性在反复出现头痛、出汗、心悸伴严重高血压后，被发现患有嗜铬细胞瘤，这是一种分泌儿茶酚胺的肾上腺髓质肿瘤。术前他开始服用酚苄明，几天后加用普萘洛尔。请解释这一顺序，以及如果先给β受体阻滞药会发生什么。
::: solution
肿瘤释放大量去甲肾上腺素和肾上腺素。它们的α₁效应引起强烈的血管收缩和高血压；β₁效应引起心动过速；骨骼肌小动脉中的β₂效应引起一定的血管舒张，部分抵消了α收缩。

酚苄明不可逆地阻断α受体，因此肿瘤释放的儿茶酚胺激增也无法克服这一阻断，阻断一直持续到新的受体合成为止。随着血管收缩缓解，收缩的血浆容量重新扩张（鼓励摄入液体和盐）。α阻断建立之后，可加用β受体阻滞药，以控制α阻断和儿茶酚胺所引起的反射性心动过速。

如果先给β受体阻滞药，它会消除β₂介导的血管舒张，而α₁血管收缩则**无从对抗**。外周阻力进一步升高，可能发生高血压危象，有卒中、心肌梗死和急性心力衰竭的风险。“先α后β”的规则直接来自受体图谱。
:::
:::

### 竞争性β阻断的定量分析

β受体阻滞药是竞争性拮抗药，因此它们对激动药反应的影响遵循剂量比$DR = 1 + [B]/K_B$（[[pharmacology/drug-receptor]]）。下图显示有无β受体阻滞药时心率与β激动药异丙肾上腺素剂量的关系。

::: widget plot
f: 60+120*10^x/(10^x+1); 60+120*10^x/(10^x+1+P)
x: -2, 4
y: 50, 190
sliders: P=10:0:300:1
labels: \text{单用异丙肾上腺素}; \text{异丙肾上腺素 + 普萘洛尔}
caption: 示例性的心率（次/分）与异丙肾上腺素对数剂量的关系，剂量以产生一半最大增幅的剂量的倍数表示（$x = 0$）。$P$为普萘洛尔浓度，以其$K_B$的倍数表示。曲线右移$\log_{10}(1 + P)$而最大值不变，因此足够大剂量的激动药可以克服阻断。$P$很高时所需剂量可能不切实际，这就是β受体阻滞药过量时要使用其他药物的原因。
:::

::: example 需要多加多少激动药？ {#ex-iso-dose-ratio}
在一项志愿者示例实验中，普萘洛尔的游离血浆浓度为20 nmol/L，其在心脏β₁受体处的$K_B$取2 nmol/L。要使心率升高幅度与使用普萘洛尔之前相同，异丙肾上腺素剂量须增加多少倍？
::: solution
$DR = 1 + 20/2 = 11$。异丙肾上腺素剂量须增加11倍，即右移$\log_{10} 11 \approx 1.04$个对数单位。由于最大值不变，只要激动药剂量足够大，仍可获得完全反应；这就是[[pharmacology/drug-receptor]]中的可克服性阻断。
:::
:::

::: warning 选择性是相对的
“心脏选择性”β受体阻滞药在较高剂量和易感者中也阻断β₂受体。坦索罗辛对前列腺的α₁A受体具有“泌尿选择性”，但它会引起体位性低血压，并与白内障手术中的虹膜松弛综合征有关，因此外科医生需要知道患者在用此药。格隆溴铵不能通过血脑屏障，但仍会引起口干、尿潴留和心动过速。预测效应时，应假定药物可能作用于它所能到达的该类型的每一个受体，而且剂量越高选择性越窄。
:::

::: quiz
一名25岁女性哮喘患者喘息，反复雾化吸入沙丁胺醇。一小时后她出现震颤，脉搏120次/分，血钾从4.2降至3.1 mmol/L。哪种受体能解释全部三种效应？
- [ ] α₁
- [ ] 仅β₁
- [x] β₂（心动过速中有部分β₁的作用）
- [ ] M₃
::: solution
沙丁胺醇是β₂激动药。骨骼肌的β₂受体介导震颤；β₂激动通过Na⁺/K⁺-ATP酶驱使钾进入细胞，使血钾降低；心动过速则源于β₂介导的血管舒张及反射性交感激活、心脏β₂受体的直接激动，以及大剂量时选择性丧失而对β₁的部分激动。在强化支气管扩张治疗期间应监测血钾，尤其是合用糖皮质激素、利尿药或茶碱时。
:::
:::

::: history
神经传递的化学本质由勒维（Otto Loewi）于1921年证实。他刺激离体蛙心的迷走神经使心跳减慢，再把浸泡该心脏的液体转移到第二个心脏，后者同样减慢：一种“迷走物质”（Vagusstoff）被释放了出来，后来证明它就是乙酰胆碱。戴尔（Henry Dale）此前已阐明了乙酰胆碱的毒蕈碱样和烟碱样作用，戴尔和勒维共同获得1936年诺贝尔生理学或医学奖。冯·奥伊勒（Ulf von Euler）于1946年证实去甲肾上腺素是交感神经的递质，并分享了1970年诺贝尔奖。1948年，阿尔奎斯特（Raymond Ahlquist）根据六种儿茶酚胺在不同组织上效价顺序的差异，提出了α和β肾上腺素受体，这一观点在很大程度上被忽视，直到布莱克（James Black）用它设计出β受体阻滞药。布莱克的普萘洛尔于二十世纪六十年代中期进入临床，他因促成该药及H₂拮抗药西咪替丁（cimetidine）的药物设计原理，分享了1988年诺贝尔生理学或医学奖。
:::

::: summary
- 两个分支的节前神经元都向烟碱受体释放ACh；副交感节后神经元向毒蕈碱受体释放ACh；大多数交感节后神经元向肾上腺素受体释放去甲肾上腺素；肾上腺髓质向血液释放肾上腺素。
- 受体图谱（M₂心脏，M₃平滑肌和腺体，α₁血管，α₂突触前，β₁心脏，β₂气道和肌肉血管，β₃膀胱）可预测药物效应和不良反应。
- 抗胆碱酯酶药提高所有胆碱能突触的ACh；有机磷中毒产生毒蕈碱样、烟碱样和中枢效应，阿托品治疗其中的毒蕈碱样效应。
- 抗毒蕈碱效应会在不同药物之间累加；老年人的抗胆碱能负荷导致意识模糊、尿潴留和跌倒。
- 非去极化型神经肌肉阻滞药为竞争性，可用新斯的明（加格隆溴铵）逆转，罗库溴铵和维库溴铵还可用舒更葡糖逆转；琥珀胆碱使终板去极化，有其特有的危险。
- 肾上腺素通过α₁、β₁和β₂受体治疗严重过敏反应；英国指南中的成人肌内注射剂量为500微克。β受体阻滞药用途广泛，不良反应可预测；嗜铬细胞瘤应先α阻断后β阻断。
:::

::: exercise 受体与效应 {level=1}
说出主要负责下列每种效应的受体：(a) 沙丁胺醇引起的支气管扩张；(b) 迷走神经刺激引起的心率减慢；(c) 去氧肾上腺素引起的血管收缩；(d) 多巴酚丁胺引起的心率和收缩力增加；(e) 炎热天气中的出汗。
::: solution
(a) β₂。(b) M₂。(c) α₁。(d) β₁。(e) 汗腺上的毒蕈碱（主要为M₃）受体，由交感胆碱能纤维支配。
:::

::: exercise 预测阿托品的效应 {level=1}
一名健康成人静脉注射足以阻断全身毒蕈碱受体的阿托品。预测其对下列各项的影响：(a) 心率，(b) 瞳孔和近视力，(c) 唾液分泌，(d) 膀胱功能，(e) 温暖天气中的体温。
::: solution
(a) 心率加快，因为静息迷走张力（M₂）被消除。(b) 瞳孔散大（失去M₃介导的括约肌收缩），近视力模糊（睫状肌麻痹）。(c) 唾液分泌减少，口干。(d) 膀胱收缩减弱，可能发生尿潴留。(e) 体温可能升高，因为由毒蕈碱受体介导的出汗减少。
:::
:::

::: exercise 抗胆碱能负荷评分 {level=1 check="7"}
一名80岁女性服用索利那新（ACB评分3）、帕罗西汀（3），并在晚间服用一种老一代抗组胺药氯苯那敏（3）。她的全科医生停用了氯苯那敏，加用一种ACB评分为1的药物。她新的ACB总分是多少？
::: solution
原总分$= 3 + 3 + 3 = 9$。停用氯苯那敏减去3分，新药加1分：$9 - 3 + 1 = 7$。一般认为总分3分或以上即有临床意义，因此进一步审查索利那新和帕罗西汀是合理的。
:::
:::

::: exercise β阻断的剂量比 {level=2 check="16"}
某患者体内一种竞争性β₁拮抗药的游离浓度为30 nmol/L，该药的$K_B$为2 nmol/L。要获得与无拮抗药时相同的反应，β₁激动药的浓度须增加多少倍？
::: solution
$DR = 1 + [B]/K_B = 1 + 30/2 = 16$。激动药浓度须增加16倍。
:::

::: exercise 逆转神经肌肉阻滞 {level=2}
手术结束时，一名接受了罗库溴铵的患者仍有残余神经肌肉阻滞。请解释 (a) 新斯的明如何逆转阻滞，(b) 为什么要同时给予格隆溴铵，(c) 舒更葡糖的作用方式有何不同，并给出一个实际优点。
::: solution
(a) 罗库溴铵是烟碱型$\mathrm{N_M}$受体的竞争性拮抗药。新斯的明抑制乙酰胆碱酯酶，使ACh在突触间隙蓄积，在竞争受体时胜过罗库溴铵。

(b) 新斯的明也提高毒蕈碱突触处的ACh，引起心动过缓、支气管收缩、流涎和胃肠蠕动亢进。格隆溴铵阻断这些毒蕈碱效应；它不能通过血脑屏障，因此不会引起中枢效应。

(c) 舒更葡糖是一种修饰的环糊精，在血浆中包裹罗库溴铵（和维库溴铵）分子，降低其游离浓度；药物随即顺浓度梯度离开接头。它不作用于胆碱酯酶，因此无需抗毒蕈碱药；它甚至能逆转深度阻滞，而新斯的明做不到，因为酶抑制有上限。
:::
:::

::: exercise 为什么先α后β？ {level=2}
请从受体角度解释，为什么对嗜铬细胞瘤患者或可卡因中毒者单独给予非选择性β受体阻滞药可能使高血压加重。
::: solution
在这两种情况下，循环或突触中的儿茶酚胺都非常高。它们作用于α₁受体使小动脉收缩，作用于骨骼肌小动脉的β₂受体使其舒张，部分抵消了收缩。非选择性β受体阻滞药消除了β₂血管舒张，使α₁血管收缩无从对抗，外周阻力和血压可能进一步升高，有卒中、心肌缺血和心力衰竭的风险。因此在嗜铬细胞瘤中要先建立α阻断。在可卡因中毒时，急性期一般避免使用β受体阻滞药，按照毒理学建议使用苯二氮䓬类和血管扩张药。
:::
:::

::: exercise 瞳孔缩小的农场工人 {level=3}
一名34岁南亚农业工人在农药泄漏一小时后被送到医院。他瞳孔针尖样，大量出汗和流涎，双肺满布湿啰音，呕吐、腹泻，脉搏48次/分，广泛肌肉抽动，呼吸力量逐渐减弱。(a) 按受体类型对这些表现进行分组。(b) 解释为什么阿托品能改善部分表现而不能改善其他表现。(c) 你预期红细胞乙酰胆碱酯酶活性会如何？“老化”有什么意义？
::: hint
把毒蕈碱样、烟碱样和中枢效应分开。
:::
::: solution
(a) 毒蕈碱样：瞳孔缩小、出汗、流涎、支气管溢液（湿啰音）和支气管痉挛、呕吐、腹泻、心动过缓。烟碱样（神经肌肉接头）：肌束颤动，继而骨骼肌和呼吸肌无力。自主神经节的烟碱样效应在部分患者中也可引起心动过速和高血压，因此心率表现不一。中枢：任何意识模糊、癫痫发作或意识水平下降。

(b) 阿托品是毒蕈碱拮抗药。它使分泌物干燥、缓解支气管痉挛并恢复心率，这就是其剂量以肺部清晰、心率和血压适当为滴定目标的原因。它对烟碱受体没有作用，因此不能逆转肌束颤动或肌无力；肌无力所致的呼吸衰竭需要通气支持。

(c) 红细胞乙酰胆碱酯酶活性会明显降低，证实暴露。“老化”是被磷酰化的酶发生的一种化学变化，视化合物不同在数小时内发生，此后酶不能再被肟类复活。这是早期给予肟类的理论依据，但解磷定的临床试验并未显示一致的获益；处理遵循毒理学建议。
:::
:::

::: exercise 服用β受体阻滞药者的严重过敏反应 {level=3}
一名62岁男性因心力衰竭服用比索洛尔，在静脉注射造影剂后发生严重过敏反应。他接受了两次肌内注射肾上腺素，每次500微克，间隔五分钟，并静脉补液，但仍低血压和喘息，心率58次/分。请用受体药理学解释为什么他的反应可能不佳，以及通过非肾上腺素能受体起作用的药物如何能有所帮助。
::: solution
肾上腺素在严重过敏反应中的益处既依赖α₁（血管收缩），也依赖β₁受体（心率和收缩力）和β₂受体（支气管扩张、稳定肥大细胞）。比索洛尔是竞争性β₁拮抗药，在较高浓度下兼有一定的β₂阻断作用，因此肾上腺素在β受体处的剂量比增大：同样剂量产生的心脏和支气管效应减小。α₁效应未被阻断，因此可能出现血管收缩，却没有通常伴随的心输出量增加和支气管扩张。严重过敏反应本身也可引起相对性心动过缓。

胰高血糖素通过心肌细胞上自身的$G_s$偶联受体升高cAMP，增加心率和收缩力，而不需要β受体：这是一种绕过阻断的生理性拮抗。对于难治性严重过敏反应，按照英国复苏委员会指南，在专科监护下使用静脉肾上腺素输注及其他血管升压药，同时进行气道管理和补液。是否长期继续使用β受体阻滞药是另一个决策，需要权衡其对心力衰竭的益处与今后发生反应的风险。
:::
:::
