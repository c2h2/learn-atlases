使药物能从肠道吸收并到达靶点的性质，主要是脂溶性，恰恰也是使肾脏难以将其排出的性质。在肾小球被滤过的脂溶性分子会从肾小管直接扩散回血液。机体解决这一问题的办法是把这类分子在化学上转变为水溶性更强的分子（主要在肝脏中进行），使其能经尿液或胆汁排出。这就是**药物代谢**（又称生物转化）。本身已是水溶性的药物，如庆大霉素（gentamicin）、锂盐和许多青霉素类，主要以原形经肾脏排出。

本章介绍代谢的两个时相和细胞色素P450酶，这些酶的诱导和抑制（许多严重药物相互作用的基础），以及各种排泄途径。随后把消除归结为两个量——**清除率**和**半衰期**，并解释消除达到饱和时会发生什么。吸收和分布是[[pharmacology/absorption-distribution]]的主题；清除率如何决定给药方案在[[pharmacology/dosing-principles]]中展开。

## 代谢的目的与部位 {#sec-sites}

肝脏是药物代谢的主要部位，但不是唯一部位。小肠壁含有与肝脏中同样丰富的CYP3A4酶，参与首过代谢。血浆酯酶在数分钟内水解琥珀胆碱（suxamethonium）和瑞芬太尼（remifentanil），这就是二者作用如此短暂的原因。肺、肾和皮肤也代谢某些药物。

代谢通常（但并非总是）使药物失活。其产物分为四类。

- **无活性代谢物**：最常见的结局，例如对乙酰氨基酚（paracetamol）的葡萄糖醛酸结合物。
- **活性代谢物**，可增强或延长效应。地西泮（diazepam）转化为去甲地西泮，后者半衰期长得多。吗啡（morphine）部分转化为吗啡-6-葡萄糖醛酸苷，这是一种有活性的镇痛物质，经肾脏排泄，在肾功能损害时蓄积，引起嗜睡和呼吸抑制。
- **前药**，需经代谢才能起效。可待因（codeine）经CYP2D6转化为吗啡；氯吡格雷（clopidogrel）经CYP2C19及其他酶活化；依那普利（enalapril）和雷米普利（ramipril）水解为其活性形式依那普利拉和雷米普利拉；左旋多巴（levodopa）在脑内脱羧生成多巴胺。
- **毒性代谢物。**一小部分对乙酰氨基酚被氧化为一种活性中间体——N-乙酰对苯醌亚胺（NAPQI），后者通常立即与谷胱甘肽结合而解毒。过量服药后谷胱甘肽耗竭，NAPQI与肝脏蛋白结合，引起肝细胞坏死。乙酰半胱氨酸（acetylcysteine）通过补充谷胱甘肽起作用。对乙酰氨基酚过量的识别和处理遵循国家指南（[[emergency-critical-care/poisoning]]）。

## Ⅰ相与Ⅱ相反应 {#sec-phases}

代谢传统上分为两个时相。Ⅰ相反应引入或暴露一个活性基团；Ⅱ相反应在该基团上连接一个大的极性分子。许多药物依次经历两个时相，但有些直接进入Ⅱ相，有些只经Ⅰ相即被排出。

::: definition Ⅰ相反应与细胞色素P450系统 {#def-phase1}
**Ⅰ相**反应包括氧化、还原和水解。它们添加或暴露–OH、–NH₂或–COOH等官能团，通常使分子极性稍增，并为结合反应提供位点。

大多数Ⅰ相氧化反应由**细胞色素P450（CYP）酶**完成，这是一个含血红素的单加氧酶超家族，主要位于肝细胞和肠上皮细胞的滑面内质网中。它们按家族、亚家族和单个酶命名：CYP3A4即家族3、亚家族A、第4个酶。少数几种酶代谢了大多数药物：

| 酶 | 底物举例 | 说明 |
|---|---|---|
| CYP3A4 | 环孢素、他克莫司、辛伐他汀、阿托伐他汀、许多钙通道阻滞药、咪达唑仑、许多抗HIV药和抗肿瘤药 | 在肝脏和肠壁中含量最丰富；参与代谢的药物份额最大 |
| CYP2D6 | 可待因、曲马多、许多抗抑郁药和抗精神病药、美托洛尔、他莫昔芬 | 存在遗传多态性；不可诱导 |
| CYP2C9 | S-华法林、苯妥英、许多非甾体抗炎药、某些磺酰脲类 | 存在多态性；对华法林剂量很重要 |
| CYP2C19 | 氯吡格雷（活化）、质子泵抑制药、某些抗抑郁药 | 存在多态性 |
| CYP1A2 | 茶碱、氯氮平、奥氮平、咖啡因 | 被烟草烟雾诱导 |
| CYP2E1 | 乙醇、一小部分对乙酰氨基酚 | 被长期饮酒诱导 |

其他Ⅰ相酶也很重要：乙醇脱氢酶和乙醛脱氢酶（乙醇），单胺氧化酶（儿茶酚胺、5-羟色胺、酪胺），黄嘌呤氧化酶（巯嘌呤），以及许多酯酶和酰胺酶。
:::

::: definition Ⅱ相结合反应 {#def-phase2}
**Ⅱ相**反应把内源性极性基团连接到药物或其Ⅰ相代谢物上，生成通常无活性、易经尿液或胆汁排出的结合物。主要反应有：

- **葡萄糖醛酸化**，由UDP-葡萄糖醛酸基转移酶（UGT）催化：容量最大的途径，吗啡、对乙酰氨基酚、劳拉西泮（lorazepam）和胆红素均经此途径；
- **硫酸化**，由磺基转移酶催化：亲和力高但容量低，因此会饱和（大剂量对乙酰氨基酚时）；
- **乙酰化**，由N-乙酰转移酶2（NAT2）催化：异烟肼（isoniazid）、肼屈嗪（hydralazine）、某些磺胺类；
- **谷胱甘肽结合**：NAPQI等活性中间体的解毒；
- **甲基化**：例如硫嘌呤S-甲基转移酶（TPMT）对硫唑嘌呤（azathioprine）和巯嘌呤（mercaptopurine）的甲基化。
:::

其中若干酶存在个体差异，并产生临床后果。欧洲裔人群中约一半是**慢乙酰化者**，携带低活性的NAT2变异；他们更容易因异烟肼发生周围神经病，因肼屈嗪发生药物性狼疮。新生儿UGT活性低，这就是按成人剂量换算给予氯霉素（chloramphenicol）的新生儿发生致命性“灰婴综合征”的原因。吉尔伯特（Gilbert）综合征患者UGT1A1活性降低，使用伊立替康（irinotecan）时毒性风险更高，因为其活性代谢物经该酶清除。这些及其他遗传变异见[[pharmacology/patient-variation]]。

## 代谢的上调与下调 {#sec-induction}

代谢酶的数量和活性并非固定不变。有些药物和其他物质增加其合成，有些则阻断其作用。这两个过程解释了临床上相当大一部分重要的药物相互作用。

::: definition 酶诱导与酶抑制 {#def-induce-inhibit}
**酶诱导**是代谢酶数量的增加，通常是因为诱导物质激活了某种核受体（如孕烷X受体），从而增加该酶基因的转录。由于需要合成新的蛋白质，诱导在数天至约两周内逐渐形成，停用诱导剂后也在相近的时间内消退。其效应是降低经被诱导酶代谢的药物的浓度和效应，或增加活性或毒性代谢物的生成。

重要的诱导剂包括利福平（rifampicin，常用药物中作用最强者）、卡马西平（carbamazepine）、苯妥英（phenytoin）、苯巴比妥（phenobarbital）、圣约翰草，以及依非韦伦（efavirenz）等某些抗HIV药物。烟草烟雾通过芳香烃受体诱导CYP1A2；这一效应来自烟雾中的烃类，而不是尼古丁，因此尼古丁替代疗法不能维持这种诱导。

**酶抑制**是酶活性的降低，通常由抑制剂的竞争性或不可逆结合所致。一旦抑制剂达到足够浓度即开始起效，通常在一两天之内，并使依赖被抑制酶代谢的药物浓度升高。重要的抑制剂包括克拉霉素（clarithromycin）和红霉素（erythromycin），唑类抗真菌药（氟康唑、伊曲康唑、伏立康唑），HIV蛋白酶抑制剂及其增效剂利托那韦（ritonavir）和考比司他（cobicistat），葡萄柚汁（肠道CYP3A4），胺碘酮（amiodarone），地尔硫䓬（diltiazem）和维拉帕米（verapamil），以及对CYP2D6而言的氟西汀（fluoxetine）和帕罗西汀（paroxetine）。
:::

相互作用的后果更多取决于受影响的药物，而不是抑制剂或诱导剂。当受影响药物治疗指数窄、浓度–效应关系陡峭、且其代谢主要依赖一条途径时，后果严重。下表列出了典型的高风险组合；处方者应对照英国国家处方集（BNF）的相互作用资源或同类资源核查每一种新组合。

| 组合 | 机制 | 可能的后果 |
|---|---|---|
| 辛伐他汀 + 克拉霉素或伊曲康唑 | CYP3A4抑制 | 肌病和横纹肌溶解 |
| 他克莫司或环孢素 + 克拉霉素或唑类 | CYP3A4抑制 | 肾毒性、神经毒性 |
| 华法林 + 氟康唑、甲硝唑或胺碘酮 | CYP2C9抑制（及其他） | INR升高、出血 |
| 复方激素避孕药 + 利福平或卡马西平 | 诱导 | 避孕失败 |
| 氯氮平与戒烟 | CYP1A2诱导消失 | 氯氮平浓度上升、中毒 |
| 硫唑嘌呤或巯嘌呤 + 别嘌醇 | 黄嘌呤氧化酶抑制 | 严重骨髓抑制 |

::: example 开具抗生素的移植患者 {#ex-transplant}
一名52岁巴基斯坦裔男性三年前接受了肾移植，服用他克莫司（tacrolimus）、吗替麦考酚酯（mycophenolate）和泼尼松龙（prednisolone）。他的他克莫司谷浓度一直稳定在目标范围内。他的全科医生因胸部感染给他开了克拉霉素。五天后他感到发抖、头痛，肌酐从110升至180 µmol/L。请解释其机制，以及正确的做法应当是什么。
::: solution
他克莫司主要在肠壁和肝脏中经CYP3A4和CYP3A5代谢，也是P-gp的底物。克拉霉素是CYP3A4（以及P-gp）的强效抑制剂。开始服用后一两天内，他克莫司的清除率下降、生物利用度上升，浓度向一个高得多的新稳态攀升。他克莫司治疗指数窄：震颤和头痛是典型的神经毒性，肌酐上升符合钙调磷酸酶抑制剂肾毒性。

更安全的做法是避免这一相互作用：选择不抑制CYP3A4的抗生素（例如根据感染情况和地方指南选用阿莫西林或多西环素），或者，若确需大环内酯类，应让移植团队参与，以便减少他克莫司剂量并密切监测浓度。目前应紧急测定他克莫司浓度，停用或更换克拉霉素，并联系移植团队。停用克拉霉素后，抑制作用在数天内消退，剂量可能需要恢复到原先水平。
:::
:::

::: example 氯氮平与一次戒烟 {#ex-clozapine-smoking}
一名38岁女性精神分裂症患者服用氯氮平（clozapine）两年，病情稳定。她每天吸烟25支。因择期手术入院后她无法吸烟，给予尼古丁贴片。第五天她变得非常嗜睡，并出现一次全面性癫痫发作。请解释。
::: solution
氯氮平主要经CYP1A2代谢。烟草烟雾中的多环芳烃诱导CYP1A2，因此吸烟者要达到与不吸烟者相同的血浆浓度，需要显著更高的氯氮平剂量。她的剂量是在该酶被诱导时确定的。

她停止吸烟后，诱导在数天内消退，CYP1A2活性下降，氯氮平浓度上升，有时可升至原先水平的约两倍。镇静和癫痫发作是氯氮平的剂量相关不良反应。尼古丁替代不能防止这一点，因为尼古丁本身并不是诱导剂。

原则是预先考虑到这一点：服用氯氮平者的吸烟状况发生任何改变（包括改用不诱导CYP1A2的电子烟），都应促使监测血药浓度，并在精神卫生团队指导下有计划地减量。如果此人后来恢复吸烟，浓度会下降，复发便成为风险（[[psychiatry/psychotic-disorders]]）。
:::
:::

## 排泄 {#sec-excretion}

药物及其代谢物主要经尿液和胆汁离开机体。挥发性麻醉药经肺排出，许多药物也有少量出现在汗液、唾液和乳汁中。

**肾脏排泄**由沿肾单位的三个过程组成（[[renal/tubular-function]]）。

1. **肾小球滤过。**只有非结合药物被滤过，滤过速率等于肾小球滤过率（GFR）乘以非结合分数。肝素和大多数抗体等大分子不被滤过。
2. **近端小管的主动分泌。**有机阴离子转运体（OAT）分泌青霉素类、甲氨蝶呤（methotrexate）和许多利尿药等酸性药物；有机阳离子转运体（OCT）分泌二甲双胍（metformin）等碱性药物。分泌甚至能清除与蛋白结合的药物，其转运体也是相互作用的发生部位。丙磺舒（probenecid）抑制青霉素的分泌，曾被有意用来延长青霉素的血药浓度；非甾体抗炎药和质子泵抑制药可减少甲氨蝶呤的分泌，使其毒性增加。
3. **肾小管被动重吸收。**随着水被重吸收，小管内药物浓度上升。脂溶性的非解离型药物扩散回血液；极性或解离型药物留在尿中。尿液pH改变弱酸和弱碱的解离分数（[[pharmacology/absorption-distribution]]），这是水杨酸盐中毒时碱化尿液的依据。

**胆汁排泄**清除较大的极性分子，通常是分子量约500以上的结合物。某些经胆汁排出的葡萄糖醛酸结合物被肠道细菌水解，释放出的药物被重新吸收。这种**肠肝循环**延长了吗替麦考酚酯和某些雌激素等药物的作用。在中毒时，对少数药物重复给予活性炭可阻断肠肝循环。

## 清除率与半衰期 {#sec-clearance}

消除最好用清除率来描述。对于长期给药，它是最重要的单一药代动力学参数，因为它决定了一定给药速率所产生的稳态浓度。

::: theorem 清除率、消除速率常数与半衰期 {#thm-clearance}
**清除率**（CL）是单位时间内药物被完全清除的血浆容积：

$$
CL = \frac{\text{消除速率}}{\text{血浆浓度}}.
$$ {#eq-cl}

不同器官的清除率可以相加：$CL_{\text{总}} = CL_{\text{肾}} + CL_{\text{肝}} + \ldots$。当CL恒定时（一级消除），静脉推注后浓度呈指数下降，

$$
C(t) = C_0\,e^{-kt}, \qquad k = \frac{CL}{V_d},
$$ {#eq-decay}

**消除半衰期**即浓度减半所需的时间，为

$$
t_{1/2} = \frac{\ln 2}{k} = \frac{0.693\,V_d}{CL}.
$$ {#eq-thalf}
:::

::: proof
体内药量为$A = V_d\,C$。按清除率的定义，消除速率为$CL \cdot C$，因此$\dfrac{dA}{dt} = -CL \cdot C$。两边除以常数$V_d$，得$\dfrac{dC}{dt} = -\dfrac{CL}{V_d}\,C = -kC$。这一一阶微分方程的解为$C(t) = C_0 e^{-kt}$。令$C = C_0/2$，得$e^{-kt_{1/2}} = 1/2$，因此$t_{1/2} = \ln 2/k = 0.693\,V_d/CL$。
:::

最后这个方程值得仔细体会。半衰期是一个*导出*量：它同时取决于容积和清除率。药物半衰期长，可能是因为清除慢，也可能是因为它分布在非常大的容积中，而这两种情况的后果不同。胺碘酮长达数周至数月的半衰期主要来自其巨大的分布容积。在心力衰竭时，某些药物的分布容积下降而清除率也下降，半衰期可能保持不变，尽管稳态浓度升高了。

经过一个半衰期，剩余50%；两个，25%；三个，12.5%；四个，6.25%；五个，约3%。实际上，经过四至五个半衰期即认为药物已被消除。同一规律从另一方向理解，就给出了规律给药时达到稳态所需的时间（[[pharmacology/dosing-principles]]）。

**肾清除率**可直接测定为$CL_R = (U \times \dot{V})/P$，其中$U$为尿药浓度，$\dot V$为尿流率，$P$为血浆浓度。将其与滤过清除率（非结合分数×GFR）比较，可以看出肾小管在做什么：数值更高表示净分泌，更低表示净重吸收。

**肝清除率**取决于肝血流量$Q$（成人约1.5 L/min）和药物一次通过肝脏被清除的比例，即**摄取率**$E$：$CL_H = Q \times E$。

- **高摄取率药物**（$E$大于约0.7），如普萘洛尔（propranolol）、利多卡因（lidocaine）、吗啡和硝酸甘油，一次通过几乎被完全清除。其清除率受血流限制，因此在心力衰竭和休克时下降。它们的口服生物利用度低，并对肝病非常敏感。
- **低摄取率药物**（$E$小于约0.3），如华法林（warfarin）、苯妥英、茶碱（theophylline）和地西泮，清除缓慢。其清除率受酶容量和蛋白结合限制，因此会因酶诱导和酶抑制而改变，但受血流影响很小。

::: example 由容积和清除率求半衰期 {#ex-thalf}
某示例性药物的分布容积为42 L，清除率为6 L/h。(a) 其消除半衰期是多少？(b) 静脉给药后浓度为8 mg/L，降到1 mg/L需要多长时间？(c) 如果肾功能损害使清除率减半，半衰期会怎样？
::: solution
(a) $k = CL/V_d = 6/42 = 0.143$/小时，$t_{1/2} = 0.693 \times 42/6 \approx 4.9$小时。

(b) 从8降到1 mg/L是减半三次（8 → 4 → 2 → 1），因此需要$3 \times 4.9 \approx 14.6$小时。

(c) CL = 3 L/h时，$t_{1/2} = 0.693 \times 42/3 \approx 9.7$小时：半衰期加倍。一个剂量作用消退的时间和达到稳态的时间都加倍；在给药速率不变时，稳态浓度也加倍。
:::
:::

## 当消除达到饱和 {#sec-saturation}

只有当代谢酶或转运体远低于其最大能力工作时，清除率才是恒定的。酶遵循**米氏动力学**（Michaelis–Menten kinetics）：代谢速率随浓度上升，但最终趋于一个最大值。

::: definition 一级消除与零级消除 {#def-orders}
可饱和过程的消除速率为

$$
\text{速率} = \frac{V_{\max}\,C}{K_m + C},
$$ {#eq-mm}

其中$V_{\max}$为最大速率，$K_m$为速率达到最大值一半时的浓度。

- 当$C \ll K_m$时，速率约为$(V_{\max}/K_m)\,C$，与浓度成正比。这是**一级**消除，清除率恒定为$V_{\max}/K_m$，半衰期恒定。大多数药物在治疗剂量下如此。
- 当$C \gg K_m$时，速率趋近$V_{\max}$：无论浓度如何，单位时间内清除的药量恒定。这是**零级**（饱和）消除，药物不再有恒定的半衰期。
:::

乙醇是标准的例子：相当少量的酒精即可使乙醇脱氢酶饱和，因此血液酒精浓度每小时下降的量大致相同。苯妥英则是临床上关键的例子：其$K_m$落在治疗范围之内，因此剂量与稳态浓度之间的关系是向上弯曲的。过量的水杨酸盐和高浓度的茶碱也表现出饱和。

::: widget plot
f: V*x/(K+x); V*x/K; V+0*x
x: 0, 30
y: 0, 25
sliders: V=10:2:20:1; K=4:1:20:1
labels: \text{米氏动力学（可饱和）}; \text{一级外推}; V_{\max}
caption: 示例性的消除速率（mg/h）与血浆浓度（mg/L）的关系。低浓度时，可饱和曲线与一级直线重合，因此清除率$V_{\max}/K_m$恒定。当浓度接近并超过$K_m$时，速率趋于平稳，接近$V_{\max}$（水平线）。降低$K_m$，可见饱和在典型治疗范围内就开始出现，苯妥英正是如此。
:::

稳态时给药速率$R$等于消除速率，因此$R = V_{\max} C_{ss}/(K_m + C_{ss})$，整理得

$$
C_{ss} = \frac{K_m\,R}{V_{\max} - R}.
$$ {#eq-css-mm}

当$R$接近$V_{\max}$时，$C_{ss}$急剧上升；如果$R$超过$V_{\max}$，就不存在稳态，药物只会不断蓄积。

::: example 为什么苯妥英剂量要小步调整 {#ex-phenytoin}
某成人的示例性苯妥英参数为$V_{\max} = 500$ mg/天，$K_m = 4$ mg/L。应用[[#eq-mm]]，要使稳态浓度维持在10 mg/L和20 mg/L，各需每日多大剂量？
::: solution
稳态时每日剂量等于消除速率。

- 10 mg/L时：$R = 500 \times 10/(4 + 10) \approx 357$ mg/天。
- 20 mg/L时：$R = 500 \times 20/(4 + 20) \approx 417$ mg/天。

剂量仅增加约17%，血浆浓度就加倍。对于遵循一级动力学的药物，使浓度加倍需要剂量加倍。这就是为什么苯妥英剂量要小幅递增，为什么每次调整后都要复查浓度（并留出比通常更长的时间达到稳态，因为随着浓度上升，有效半衰期延长），以及为什么一个小的相互作用或剂量取整误差就可能导致中毒。个体的$V_{\max}$和$K_m$差异很大，因此实际给药依据血药浓度和专科建议。
:::
:::

::: warning 半衰期不是药物的固定属性
学生常给每种药物记一个固定的半衰期。实际上，只要清除率或容积改变，半衰期就会改变：肾或肝功能损害、心力衰竭、酶诱导或抑制、年龄，以及对于可饱和的药物，剂量本身。教科书上的半衰期是健康成人的典型值。安排采血测浓度的时间、过量后监测的持续时间或换药前药物洗脱所需的时间时，应依据患者可能的半衰期，而不是教科书上的数值。
:::

::: quiz
一名74岁女性服用华法林，病情稳定。她因骨感染开始为期两周的利福平治疗。最可能出现哪种INR变化模式？
- [ ] INR在24小时内升高，利福平一停用即恢复基线
- [x] INR在一到两周内逐渐下降；停用利福平后，INR在随后数周内再次上升，因此随着诱导消退需要减少华法林剂量
- [ ] 没有变化，因为利福平不影响CYP酶
- [ ] INR立即下降，因为利福平把华法林从白蛋白上置换下来
::: solution
利福平是CYP2C9、CYP3A4及其他代谢华法林的酶的强效诱导剂。诱导需要合成新的酶，因此华法林清除率在数天至两周内上升，INR下降，通常需要大幅增加剂量。停用利福平后，多出的酶在相近的时间内消失，华法林清除率下降，INR上升：如果继续使用增加后的剂量，就有出血风险。两个阶段都需要频繁监测INR。
:::
:::

::: history
药物代谢的现代研究始于威尔士生物化学家威廉斯（Richard Tecwyn Williams），他在《解毒机制》（*Detoxication Mechanisms*，1947）一书中对这些反应进行了分类，后来发展为Ⅰ相和Ⅱ相的概念。负责大多数氧化反应的酶在二十世纪五十年代末和六十年代初被鉴定出来：1958年，克林根贝格（Martin Klingenberg）和加芬克尔（David Garfinkel）各自在肝微粒体中发现了一种能结合一氧化碳的特殊色素；1962年，大村恒雄（Tsuneo Omura）和佐藤了（Ryo Sato）证明它是一种血红素蛋白，并根据其在450 nm处的吸收峰将其命名为细胞色素P450。康尼（Allan Conney）在二十世纪五六十年代的研究证实，药物和环境化学物质能够诱导这些酶。肠壁代谢的重要性因一次偶然发现而广为人知：1989年，加拿大的贝利（David Bailey）及其同事在一项关于钙通道阻滞药非洛地平（felodipine）的研究中用葡萄柚汁掩盖酒精的味道，结果发现药物浓度远高于预期；他们1991年的报告开启了经肠道CYP3A4的食物–药物相互作用研究。
:::

::: summary
- 代谢把脂溶性药物转化为可以排出的水溶性产物。代谢物可能无活性、有活性、有毒性，或（对前药而言）就是活性药物本身。
- Ⅰ相反应（氧化、还原、水解）以细胞色素P450酶为主，尤其是CYP3A4、2D6、2C9、2C19和1A2。Ⅱ相反应使药物与葡萄糖醛酸、硫酸、乙酰基、谷胱甘肽或甲基结合。
- 酶诱导（利福平、卡马西平、苯妥英、圣约翰草、烟草烟雾）在一到两周内形成和消退，使药物浓度降低。酶抑制（克拉霉素、唑类、利托那韦、葡萄柚、胺碘酮）起效迅速，使药物浓度升高。相互作用对治疗指数窄的药物最为重要。
- 肾脏通过滤过非结合药物、主动分泌和被动重吸收排泄药物；胆汁排泄大的结合物，其中一些经历肠肝循环。
- 清除率把消除速率与浓度联系起来。一级消除时，$t_{1/2} = 0.693\,V_d/CL$，约五个半衰期可清除一种药物。
- 高摄取率药物受血流限制；低摄取率药物受酶容量限制，对诱导、抑制和蛋白结合敏感。
- 可饱和（米氏）消除使浓度随剂量不成比例地上升，苯妥英和乙醇即是如此。
:::

::: exercise 由速率常数求半衰期 {level=1 check="3"}
某药按一级动力学消除，消除速率常数为每小时0.231。其半衰期是多少小时？取最接近的整数。

::: exercise 四个半衰期后还剩多少？ {level=1 check="6.25"}
假定一级消除，单次静脉给药后经过四个半衰期，体内还剩下多大百分比？给出准确值。
::: solution
$100 \times (1/2)^4 = 100/16 = 6.25\%$。

将下列每个反应归为Ⅰ相或Ⅱ相，并指出反应类型：(a) 可待因经CYP2D6转化为吗啡；(b) 吗啡转化为吗啡-3-葡萄糖醛酸苷；(c) 异烟肼转化为乙酰异烟肼；(d) 依那普利转化为依那普利拉；(e) 硫唑嘌呤的代谢物巯嘌呤经TPMT甲基化。

::: exercise 由容积和半衰期求清除率 {level=2 check="4.9"}
某药分布容积为70 L，半衰期为10小时。计算其清除率（L/h），保留一位小数。
::: hint
将[[#eq-thalf]]变形：$CL = 0.693\,V_d/t_{1/2}$。
:::
::: solution
$CL = 0.693 \times 70/10 \approx 4.85$ L/h，保留一位小数为**4.9** L/h（取$\ln 2 = 0.6931$，$CL = 4.852$ L/h）。

::: exercise 肾小管在做什么？ {level=2 check="50"}
某药不与血浆蛋白结合，血浆浓度为2 mg/L。一小时内收集的尿液体积为0.1 L，药物浓度为60 mg/L。患者GFR为100 mL/min。计算肾清除率（mL/min），并说明该药经历的是净肾小管分泌还是净重吸收。
::: hint
$CL_R = U\dot V/P$；把L/h换算为mL/min。
:::
::: solution
排泄速率$= 60 \times 0.1 = 6$ mg/h。$CL_R = 6/2 = 3$ L/h $= 3000/60 =$ **50** mL/min。非结合药物的滤过清除率等于GFR，即100 mL/min。肾清除率较低，因此存在净肾小管重吸收，这符合一种脂溶性较强的药物的预期。若清除率高于100 mL/min，则表明净分泌。
:::
:::

::: exercise 开始和停用诱导剂 {level=2}
一名29岁女性结核病患者将开始含利福平的治疗方案。她使用复方口服避孕药，不服用其他药物。请解释这一相互作用及其时程，以及由此得出的避孕原则。停用利福平后会发生什么？
::: solution
利福平是CYP3A4及其他代谢炔雌醇和孕激素的酶的强效诱导剂。在最初一到两周内，两种激素的清除率上升、浓度下降，因此避孕药可能无法抑制排卵。由于效应来自代谢增加，把药片剂量加倍并不能可靠地克服它。

依照性与生殖健康学院（Faculty of Sexual and Reproductive Healthcare）的指南，原则是在治疗期间使用不受酶诱导剂影响的避孕方法，如含铜宫内节育器、左炔诺孕酮宫内节育系统或单纯孕激素注射剂。停用利福平后，诱导会持续到多出的酶消失为止，因此在最后一剂后还要继续采取额外措施28天。还应考虑其他药物的致畸性，以及利福平与今后任何药物的相互作用。
:::
:::

::: exercise 苯妥英加量 {level=3 check="20"}
某女性的苯妥英代谢示例参数为$V_{\max} = 420$ mg/天，$K_m = 4$ mg/L。(a) 每日300 mg时她的稳态浓度是多少？(b) 每日350 mg时是多少？(b)的答案以mg/L表示。(c) 评论这一结果。
::: hint
应用[[#eq-css-mm]]：$C_{ss} = K_m R/(V_{\max} - R)$。
:::
::: solution
(a) $C_{ss} = 4 \times 300/(420 - 300) = 1200/120 = 10$ mg/L。

(b) $C_{ss} = 4 \times 350/(420 - 350) = 1400/70 =$ **20** mg/L。

(c) 剂量增加17%，稳态浓度就加倍了，因为给药速率正接近$V_{\max}$，消除接近饱和。若进一步增加到每日420 mg，就根本不存在稳态。实际上，在这一水平的加量应小步进行，并在可能已达到新稳态时复查浓度；浓度越高，达到稳态所需时间越长。
:::
:::

::: exercise 移植患者的痛风治疗 {level=3}
一名61岁男性接受了肝移植，服用硫唑嘌呤作为免疫抑制方案的一部分。他痛风反复发作，开始按标准剂量服用别嘌醇（allopurinol）。三周后他出现发热、口腔溃疡，中性粒细胞计数为0.3 × 10⁹/L。请用硫唑嘌呤的代谢途径解释这一相互作用的机制，并说明预防原则。
::: hint
想一想当巯嘌呤的某条失活途径被阻断时会发生什么。
:::
::: solution
硫唑嘌呤是一种前药，转化为巯嘌呤。巯嘌呤有三种相互竞争的去向：活化为有细胞毒性的硫鸟嘌呤核苷酸（既产生治疗性免疫抑制，也引起骨髓毒性），经TPMT甲基化失活，以及经黄嘌呤氧化酶氧化为硫尿酸而失活。

别嘌醇抑制黄嘌呤氧化酶。这条失活途径被阻断后，更多的巯嘌呤被分流到活性硫鸟嘌呤核苷酸途径。其效应相当于硫唑嘌呤剂量增加数倍，结果是严重的骨髓抑制。他的发热伴中性粒细胞减少是医疗急症（中性粒细胞减少性脓毒症）。

预防：应避免这一组合；若专科团队认为确有必要，则大幅减少硫唑嘌呤剂量（常减至约四分之一），并密切监测血细胞计数。应与移植团队一起考虑预防痛风的替代方案，例如没有这一相互作用的降尿酸药。本病例还说明了一条普遍规律：相互作用并不只经由细胞色素P450酶发生，任何加入窄治疗指数方案的药物都应加以核查。
:::
