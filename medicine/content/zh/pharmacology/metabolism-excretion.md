药物代谢就是身体的化学回收站：**它把脂溶性分子变得足够水溶以便排出；在此过程中它激活前药、制造毒性代谢物，并产生临床上一半的药物相互作用与特异质反应。**一相反应——主要是细胞色素P450的氧化——给分子装上功能基团；二相结合——葡萄糖醛酸化、乙酰化、硫酸化、甲基化与谷胱甘肽结合——为它贴上出口标签。哪一个酶负责某个药、这个酶在人与人之间差异多大、什么会诱导或抑制它，这三件事解释了临床药理一半的实际难题。

本章覆盖一相与二相代谢、代谢酶的药物遗传学、诱导与抑制，以及临床上重要的肝外与非肝途径。

## 两相

::: definition 一相反应 {#def-phase1}
**主角是细胞色素P450氧化：用文字描述血红素-硫醇盐循环——底物结合改变铁的自旋状态，两个电子由NADPH-P450还原酶送来，氧被活化，一个氧原子插入底物、另一个生成水。执掌临床医学的酶族：CYP3A4与3A5承担大约一半的药物代谢；CYP2D6是精神科与心内科那台多态性超载的主力；CYP2C9管华法林、苯妥英与非甾体抗炎药；CYP2C19管氯吡格雷与质子泵抑制药；CYP1A2管咖啡因、茶碱与氯氮平；而FMO3不是P450，却是负责氧化氮原子、处理气味与药物的酶——[[cell-biochemistry/proteins-enzymes]]。**
氧化之外的反应：酯酶与酰胺酶的水解（瑞芬太尼、吗啡葡萄糖醛酸物、有机磷的清除酶）；乙醇先经脱氢酶变成乙醛、再由乙醛脱氢酶收尾——其中的潮红多态性、双硫仑，以及甲硝唑的民间说法要诚实地读。毒性中间物是进步的代价：对乙酰氨基酚经CYP2E1生成NAPQI，由谷胱甘肽解毒；整个“扑热息痛危机”就装在这一个分子里——酒精诱导、禁食与谷胱甘肽耗竭都会使治疗窗缩小，而N-乙酰半胱氨酸作为谷胱甘肽前体救援，这条治疗线源自1970年代的先见研究——[[emergency-critical-care/poisoning]]、[[gastrointestinal/liver-disease]]。卤化麻醉药氧化为酰卤引起免疫性肝炎——氟烷的遗产、地氟烷与七氟烷的化合物F、化学稳定性的高低排序；至于生物活化生成反应性中间物、形成半抗原并驱动与人类白细胞抗原相关的特异质反应（新维宁、氟氯西林与阿巴卡韦的几场风波），见[[pharmacology/adverse-reactions]]与[[pharmacology/patient-variation]]。非P450的氧化：线粒体外膜的单胺氧化酶（膳食与神经递质的酪胺、“奶酪问题”以当代选择性数据作答），以及黄嘌呤氧化酶——[[renal/urinary-tract]]、[[blood/lymphoma-myeloma]]、[[infectious-diseases/stewardship-outbreaks]]。**
:::

## 结合及其政治

::: definition 二相结合 {#def-phase2}
**葡萄糖醛酸化是UGT的主场：以UDP-葡萄糖醛酸供体造出巨大而亲水的阴离子以供肾排泄。临床重要的UGT：UGT2B7管吗啡、非甾体抗炎药与丙戊酸；UGT1A1管胆红素与伊立替安的活性代谢物SN-38——其启动子TA重复多态性即Gilbert综合征与药物代谢的交汇：禁食与阿扎那韦时的黄疸，以及按基因型下调伊立替安剂量以避免中性粒细胞减少——[[gastrointestinal/liver-function]]、[[paediatrics/newborn]]。NAT2的乙酰化呈双峰多态：快慢乙酰化的人群遗传学；慢乙酰化者的异烟肼神经病与肝炎（因此常规合用吡哆醇），以及肼苯达嗪与普鲁卡因胺在慢乙酰化者中的狼疮——乙酰化代谢物的免疫学只回答了一半；慢乙酰化者对芳香胺的解毒失败，则与膀胱癌的职业流行病学相连接——[[infectious-diseases/tuberculosis]]、[[musculoskeletal/connective-tissue-vasculitis]]、[[pathology/environmental-pathology]]。**
硫酸化、甲基化与谷胱甘肽作为替代途径：硫酸转移酶在葡萄糖醛酸化饱和处接管；COMT抑制药恩他卡朋与奥匹卡朋提高左旋多巴的生物利用度而不过血脑屏障——[[nervous-system/movement-disorders]]。结合酶的未成熟与饱和门诊：新生儿葡萄糖醛酸化不成熟（氯霉素灰婴综合征、吗啡半衰期延长）；妊娠与雌激素在不同年龄以同一途径降低拉莫三嗪浓度；对乙酰氨基酚、乙醇与苯妥英的零级对一级饱和——苯妥英维持剂量的“悬崖”使血药浓度监测成为必需。前药要靠酯酶与细胞色素激活：氯吡格雷经CYP2C19两步激活、功能丧失等位基因使效差（血小板功能检测对基因型对替格瑞洛与普拉格雷无需激活的路线之争）；奥司他韦、缬更昔洛韦、左旋多巴，以及可待因与曲马多和羟考酮的“活性代谢物教训”——CYP2D6超快代谢者在扁桃体切除后死于可待因，因此禁忌被记住——[[blood/thrombosis-anticoagulation]]、[[pharmacology/patient-variation]]。**
:::

## 调高与调低系统

::: definition 诱导与抑制 {#def-induce-inhibit}
**酶抑制是“快”的那类相互作用：可逆竞争性抑制对机制依赖性灭活（后者需要合成新酶才能恢复），起病以日计、受酶更新速率而非药物半衰期限制。临床名单按酶排：CYP2C9、2D6、3A4与1A2——唑类抗真菌；大环内酯（红霉素与克拉霉素，阿奇霉素则另当别论：“我是读证据还是按类别外推”这个问题要按类别外推为不安全）；蛋白酶抑制药与考比司他的“药动学增强”其实是刻意的治疗（人类免疫缺陷病毒的药动学增强对药物相互作用的群体算术）；西柚的呋喃香豆素以时间依赖方式失活肠壁3A4，洗脱需72小时以上（而“另一只西柚”是神话）；西咪替丁对雷尼替丁的家族史；CYP1A2的二重奏：环丙沙星-茶碱、替扎尼定与阿戈美拉汀；氟伏沙明对咖啡因、氯氮平与雷美替明——起始时要全部重查；以及胺碘酮对华法林、地高辛与维拉帕米的三重奏（华法林需减量三至五成）——[[cardiovascular/arrhythmias]]、[[infectious-diseases/stewardship-outbreaks]]、[[psychiatry/treatments-mental-health-law]]。**
诱导则两头都慢：核受体感受器（PXR、CAR与AhR）以配体激活的转录起作，需要合成新蛋白——这解释了数日起效、数周消退。利福平是主角：降低避孕药、直接口服抗凝药、唑类、抗逆转录病毒药、美沙酮、丁丙诺啡与他克莫司的水平，并有移植排斥与肾上腺危象的报告（利福布汀减量作为折中，以及结核合并人类免疫缺陷病毒的联治算法）——[[infectious-diseases/tuberculosis]]、[[obstetrics-gynaecology/contraception-fertility]]。自身诱导与反跳：卡马西平在数周内自我缩短半衰期，停药后又缓慢回复；巴比妥的历史教训同样适用于结合酶——丙戊酸抑制拉莫三嗪的葡萄糖醛酸化并使清除率减半，因此拉莫三嗪的“极慢滴加”是为了皮疹风险；相互作用的两面要对照着教——[[nervous-system/epilepsy]]、[[psychiatry/mood-disorders]]。转运体相互作用在临床上与代谢纠缠在一起：P-糖蛋白、OATP、OCT、MATE与BCRP会抬高达比加群与他汀暴露（吉非罗辛的OATP1B1教训）；考比司他与多替拉韦抑制OCT2使肌酐“假性升高”而无实质损伤；以及肾与转运体多态性背景下的二甲双胍乳酸酸中毒——[[endocrine/diabetes]]、[[renal/chronic-kidney-disease]]。**
:::

::: example 移植门诊的相互作用 {#ex-transplant}
一位肾移植患者因念珠菌病开始氟康唑；三天后肌酐升高、手抖；再过一周，另一家门诊因潜伏结核重新开始利福平，却没有告诉任何人。
::: solution
**两次相互作用、一个移植肾（[[#def-induce-inhibit]]、[[immunology/transplant-tumour-immunology]]）：抑制阶段——氟康唑抑制CYP3A4并轻度抑制P-糖蛋白，使他克莫司浓度剧升。窄治疗指数意味着数日内就有结果，且谷值采血时间必须正确；“震颤-头痛-高钾-高血压-肌酐升高”五联是毒性而不是排斥；短疗程常以临时减量处理，此外唑类的效力不同，而伏立康唑自身还带CYP2C19的药物遗传学——[[renal/acute-kidney-injury]]。诱导阶段——利福平作为PXR激动剂，在数日至数周内把他克莫司压向零：诱导起效需要时间，而潜伏结核疗程长达数月；未申报的合并用药会失去移植肾。折中是改用加量的利福布汀并密切监测浓度，或与专科讨论非利福霉素方案；异烟肼的轻度抑制作为对照；而对神经病变风险组永远给吡哆醇——[[infectious-diseases/tuberculosis]]。**
系统修复——两个门诊都能看到的共享用药清单、以移植协调员为闸门、以及“在开药时触发而不是在事后阅读”的药师相互作用警示；红旗式沟通要有姓名、时间、地点与回述；免疫抑制人群的潜伏结核筛查与治疗算法应当事先决定，而不是事中——[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]。数字习惯：治疗药物监测的素养——哪种药该测哪个时点（谷值对随机）、浓度升高后做什么（他克莫司、环孢素与西罗莫司的谱不同；激素剂量影响浓度；排斥后的加强方案有其后果）——[[clinical-skills/laboratory-tests]]。**
:::

::: example 多药门诊 {#ex-polyclinic}
一位68岁的强迫症患者两周前开始氟伏沙明，如今心悸与震颤；用药清单里有茶碱与替扎尼定。
::: solution
**以CYP1A2为线索（[[#def-induce-inhibit]]、[[#def-phase1]]）：模式识别——氟伏沙明是强CYP1A2与2C19、兼部分3A4抑制剂；茶碱治疗指数窄，毒性表现为震颤、心悸、恶心、失眠与癫痫；替扎尼定若同服会低血压与过度镇静；若是氯氮平则浓度可升至三倍；阿戈美拉汀与雷美替明属禁配组合——查浓度、暂停或减量、系列解读——[[psychiatry/anxiety-disorders]]、[[respiratory/asthma-copd]]。**
吸烟这个变量：多环芳烃诱导CYP1A2，因此住院戒烟会在数周内抬高咖啡因、氯氮平与奥氮平的浓度——“入院前吸烟状态”应被当作一项生命体征；入院即减量的方案哪里都写、哪里都破；而电子烟与燃烧烟草的差别尚不清楚——[[psychiatry/treatments-mental-health-law]]、[[public-health/prevention-promotion]]。系统答案：按半衰期、治疗指数宽度与可监测性来梳理相互作用，而不是靠“相互作用”这个词吓人——可监测则保留、否则更换或停用；处方者与药师之间以回述确认沟通；并追问非处方药、草药与膳食（咖啡因与能量饮料、焦烤与熏制食品、十字花科的诱导，以及圣约翰草经3A4导致避孕失败的历史）——[[pharmacology/patient-variation]]、[[clinical-skills/history-taking]]。**
:::
:::

::: example 黄疸患者的用药 {#ex-liver-dose}
一位55岁酒精性肝硬化（Child-Pugh C）患者，为预防戒断服地西泮，另有加巴喷丁与奥美拉唑，逐渐嗜睡并出现扑翼样震颤；这是过度镇静、肝性脑病，还是两者兼有？
::: solution
**肝衰竭的镇静的两条路（[[#def-phase2]]、[[#def-induce-inhibit]]、[[gastrointestinal/liver-disease]]）：药动学一路——肝硬化的氧化清除几乎摧毁地西泮的代谢，其活性代谢物去甲地西泮逐日蓄积；因此改用只经葡萄糖醛酸化的劳拉西泮、奥沙西泮或替马西泮；加巴喷丁的肾清除干净但镇静相加；奥美拉唑暴露升高通常无关紧要；低白蛋白抬高游离分数，第三间隙则稀释亲水药物。药效学一路——肝硬化脑的苯二氮受体敏感性与γ-氨基丁酸张力增高，与氨协同；苯二氮会加重轻微与显性脑病；氟马西尼是个诊断陷阱，在依赖者可诱发癫痫——[[pathology/cell-injury]]。**
病房系统一路：肝病时的戒断用药应按症状触发而非固定剂量，指南的答案是奥沙西泮或劳拉西泮；先给硫胺素再输糖，并纠正镁、钾与磷——[[gastrointestinal/liver-disease]]、[[psychiatry/substance-use]]。同时治疗脑病：乳果糖、利福昔明，并追查诱因（出血、感染、便秘与脱水），同时暂停镇静药；把药物复查纳入处置包，并记录每一种药做了什么——[[clinical-skills/records-handover]]。**
:::
:::

::: example 草药的意外 {#ex-herbal}
一位肾移植患者“只是”开始服圣约翰草改善情绪，随后肌酐上升；她的朋友正在服舍曲林，吃同样的草药后感到烦躁与发热。
::: solution
**同一种草药，两种机制（[[#def-induce-inhibit]]、[[#def-phase1]]）：险些发生的排斥——圣约翰草是PXR与CAR激动剂，在肠、肝与肾诱导CYP3A4与P-糖蛋白，把他克莫司压垮；环孢素被诱导的病例系列是历史遗产；数日起效、数周消退，需减量并复查浓度。优先记住的清单：大蒜与银杏加抗血栓药；甘草造成假性醛固酮增多性高血压与低钾；以及移植、肿瘤与免疫调节的高风险复方草药——[[immunology/transplant-tumour-immunology]]、[[blood/haemostasis-bleeding]]。**
5-羟色胺负荷：圣约翰草自身有再摄取抑制、轻微的酶抑制与细胞色素作用，叠加舍曲林后产生躁动、震颤、出汗与腹泻；需与神经阻滞剂恶性综合征鉴别，判定毒性分级、停药、支持治疗，以及赛庚啶的证据级别——[[psychiatry/mood-disorders]]、[[emergency-critical-care/poisoning]]。咨询技术：不带评判地询问草药与补充剂、“把药架拍下来”的做法、“天然不等于惰性”这一有效解释，并把患者从网络恐慌导向可靠资源——[[clinical-skills/history-taking]]、[[clinical-skills/communication]]。**
:::

## 通向何处

这些酶的遗传变异在[[pharmacology/patient-variation]]展开；给药剂量的后果在[[pharmacology/dosing-principles]]；毒性机制在[[pharmacology/adverse-reactions]]；肝病的影响在[[gastrointestinal/liver-disease]]。

::: history
**药物代谢的研究从“如何处理毒物”长大：19世纪末20世纪初的马尿酸与葡萄糖醛酸结合工作，源自最早把苯甲酸盐加甘氨酸当作原型结合的生理化学学派——[[physiology/homeostasis-body-fluids]]。致癌物活化悖论：米勒夫妇1960年代“亲电-亲核”的致癌假说，与亚历山大·博伊德1930年代在尿中鉴定出2-萘胺代谢物——把苯胺染料流行病学与代谢物化学结为一体，后来NAT2的乙酰化状态被证明可修饰风险——[[pathology/environmental-pathology]]、[[epidemiology-ebm/observational-studies]]。P450的命名故事：克林伯格1958年发现的一氧化碳复合物吸收带给出了名字；1960至70年代大村与佐藤的增溶与纯化；威廉斯与根格里希的机制时代；基因组时代数出人类57个酶——[[cell-biochemistry/proteins-enzymes]]。**
乙酰化者的发现是药物遗传学的奠基：吃富组胺鱼类时有人发作有人不发作；异烟肼的神经病变分裂为快慢乙酰化两群；1959年弗里德里希·福格尔造出“药物遗传学”一词——[[genetics/common-disease-genetics]]、[[infectious-diseases/tuberculosis]]。现代的临床落地时代：药物基因组学实施联盟等指南机构（氯吡格雷-CYP2C19、可待因-CYP2D6、阿巴卡韦-HLA-B*5701、华法林-CYP2C9与VKORC1），先发制人的套餐检测之辩（测谁、据何行动），以及上市前药物相互作用研究的产业时代（鸡尾酒探针法与指示底物表，以及2020年代监管机构转向生理药动学建模的指导原则改革）——[[genetics/genomic-medicine]]、[[pharmacology/drug-development-prescribing]]。**
:::

::: summary
- 一相（细胞色素氧化、酯酶、黄素与胺氧化酶、黄嘌呤氧化酶）给分子装上功能基团；二相（葡萄糖醛酸化、乙酰化、硫酸化、甲基化、谷胱甘肽结合）把它结合后排出。
- 毒性中间物是“设计功能的失手”：NAPQI、酰卤与反应性醌由谷胱甘肽解毒，而其蛋白加合物可触发特异质反应。
- 抑制快、受酶更新限制；诱导两头都慢，因为它需要经PXR、CAR与AhR的转录——利福平与圣约翰草都比处方活得久。
- 遗传变异（CYP2D6、2C19、2C9、UGT1A1、NAT2、TPMT、DPYD）制造可预测的剂量亚群，从氯吡格雷无应答到氟尿嘧啶与硫嘌呤的灾难。
- 前药必须被代谢才起作用；而活性药也可依赖代谢物（可待因经CYP2D6生成吗啡-6-葡萄糖醛酸），因此遗传学既能造成失效也能造成致死过量。
- 相互作用的处置取决于治疗指数宽度、能否监测与效应方向，而不是“相互作用”这个吓人的词本身。
:::

::: exercise 相互作用的分拣处 {level=2}
把下列分为抑制、诱导或几乎无影响，并给出临床行动：红霉素、卡马西平、利托那韦、氟康唑、吸烟、奥美拉唑（对CYP1A2）、西柚汁、考来烯胺、丙戊酸。
::: solution
**分拣答案（[[#def-induce-inhibit]]）：抑制剂——红霉素抑制3A4（还有QT与胃动素的一面），克拉霉素与阿奇霉素要分开；与3A4及P-糖蛋白双重抑制在肾功能不全者合并秋水仙碱可致死，绝不可漏。利托那韦与考比司他是刻意的增强剂，涉及整个队列的剂量调整。氟康唑横跨2C9、2C19与3A4，会牵动华法林、苯妥英与他克莫司。丙戊酸抑制UGT与环氧化物水解酶，使拉莫三嗪清除减半；反方向的碳青霉烯-丙戊酸浓度崩塌也要记住。诱导剂——卡马西平经PXR与CAR，含自身诱导，既是加害者也是受害者；吸烟经CYP1A2影响茶碱、氯氮平、奥氮平与雷美替明，入院与出院都要调整。奥美拉唑是1A2的底物兼弱诱导，临床意义有限。考来烯胺不是酶作用而是结合——须与霉酚酸、甲状腺激素、华法林与左甲状腺素间隔四小时。每项的行动取决于治疗指数宽度：含3A4抑制剂时西酞普兰的QT剂量上限，以及直接口服抗凝药“避免-谨慎-无妨”的分层——[[cardiovascular/arrhythmias]]、[[pharmacology/patient-variation]]。**

::: exercise 用三种方式解释茶碱的故事 {level=2}
同一个茶碱剂量为何现在过量了：(a) 她在住院期间戒烟；(b) 加了环丙沙星；(c) 她出现了心衰与肝淤血。
::: solution
**三路解释（[[#def-induce-inhibit]]、[[#def-phase1]]、[[respiratory/asthma-copd]]）：戒烟——CYP1A2的去诱导在数日至数周内可使浓度升高近四成，因此需要“入院吸烟状态”算法与预先减量；浓度是电子烟不确定性的仲裁者——[[public-health/prevention-promotion]]。环丙沙星——数日内抑制CYP1A2使浓度上升，表现为恶心、震颤、心悸，重度则癫痫；48至72小时查浓度、暂停并减量，必要时按药敏换抗生素——[[microbiology/antimicrobials]]。心衰伴淤血——肝血流减少使“流量敏感”药物的清除下降，发热与急性病还会再减；失代偿期的剂量会来回摆动；同一机制使静脉氨茶碱危险；窄指数药物的剂型更换也要小心——[[cardiovascular/heart-failure]]、[[pharmacology/dosing-principles]]。**

::: exercise 按基因型给药 {level=2}
一位患者为CYP2C19功能丧失纯合、CYP2D6基因重复、UGT1A1*28杂合。请预测对氯吡格雷、艾司西酞普兰、可待因、伊立替康与地西泮的影响。
::: solution
**基因型到预测的演练（[[#def-phase2]]、[[#def-phase1]]）：氯吡格雷——慢代谢，活性代谢物减少，支架内血栓风险升高，故优选普拉格雷或替格瑞洛；并讨论中间表型、质子泵抑制药合用的细则与手术时机——[[cardiovascular/coronary-artery-disease]]。艾司西酞普兰——CYP2C19参与其清除，慢代谢者暴露升高，需考虑QT与低钠及剂量上限；实践中更多按副作用滴定，而“慢2C19加超快2D6”这类多酶表型会让简单预测失效——[[psychiatry/mood-disorders]]。可待因——CYP2D6重复意味着超快转化为吗啡，毒性风险因而禁忌；慢代谢者从可待因与曲马多获益很少，羟考酮较少依赖、氢可酮是其部分版本——[[surgery/anaesthesia-pain]]。伊立替康——UGT1A1*28杂合减慢SN-38的葡萄糖醛酸化，需按避免中性粒细胞减少的方案调整，而纯合频率随祖源不同。地西泮——CYP2C19参与氧化，规律给药时暴露适度升高、活性代谢物蓄积，老年人尤为脆弱——[[psychiatry/anxiety-disorders]]、[[geriatrics-palliative/polypharmacy]]。**

::: exercise 审计一份相互作用警示政策 {level=3}
你的电子处方系统每天弹出数百条相互作用警示，几乎全被忽略。请用临床药理学推理设计一次审计与再设计。
::: solution
**警示改造（[[#def-induce-inhibit]]、[[clinical-skills/patient-safety]]）：测量——按严重度与证据分级警示、收集忽略原因代码，并寻找“危险的漏报”而不仅是“嘈杂的命中”；警示负担与职业倦怠及“忽略疲劳”的文献——[[emergency-critical-care/acute-assessment]]。再设计原则——在开药时弹出，而不是埋在医嘱组里；让正确的角色看到正确的警示（药师在调配前、医师在开立时、护士在给药时）；把剂量与浓度核查打包而不是各弹一次；按相互作用方向警示（“给受害者加抑制剂”对“单独新开受害者”）；并给出替代方案而非只禁止；内置肾功能剂量计算器、可避开唑类的抗生素选择与抗凝分层——[[microbiology/antimicrobials]]。治理——由药师主导的委员会维护分级的本地清单（避免、谨慎加监测、影响极小），每季度复审并把严重事件教训回灌，包括他克莫司与化疗的未遂事件；追踪“避免的不良反应”对“延误治疗的伤害”；不把警示弹窗当作免责盾牌；营造一种让警示开启药师对话而非追责的文化；并在应用质量参差的现实下引导患者使用可靠查询工具——[[clinical-skills/laboratory-tests]]、[[medical-ethics-law/professionalism-regulation]]。**

## 练习

::: exercise 指派酶 {level=1}
为每种药指出主要的代谢酶或途径，以及一个临床相关的调节因素：华法林、氯吡格雷、可待因、茶碱、地西泮、吗啡、别嘌醇的靶点（而非其代谢）、硫唑嘌呤。
::: solution
**酶指派演练（[[#def-phase1]]、[[#def-phase2]]）：华法林——S-型经CYP2C9，*2与*3变异降低所需剂量，VKORC1启动子变异影响敏感性；按CYP2C9与VKORC1的指南给药在试验中获益有限；胺碘酮、甲硝唑与唑类需减量三至五成——[[blood/thrombosis-anticoagulation]]。氯吡格雷——CYP2C19功能丧失等位基因减少活性代谢物，东亚人群功能丧失频率较高，故以普拉格雷与替格瑞洛绕行；与质子泵抑制药的竞争问题已有“影响不大”的解答（泮托拉唑抑制较弱）——[[cardiovascular/coronary-artery-disease]]。可待因——经CYP2D6转为吗啡，两端极端（超快与慢代谢）；扁桃体切除后与哺乳期死亡的病例造就现行禁忌；曲马多陷阱类似；布托啡诺与丁丙诺啡较少依赖CYP2D6，因此更安全——[[psychiatry/substance-use]]、[[surgery/anaesthesia-pain]]。茶碱——CYP1A2：吸烟诱导，环丙沙星与氟伏沙明抑制，窄指数需测浓度。地西泮——CYP2C19与3A4氧化后再结合，活性代谢物在老年与肝病时蓄积，故“只用葡萄糖醛酸化”的劳拉西泮、奥沙西泮与替马西泮原则，以及新生儿慎用——[[psychiatry/anxiety-disorders]]、[[geriatrics-palliative/polypharmacy]]。吗啡——直接二相经UGT2B7葡萄糖醛酸化，无氧化负担，但要记住M6G经肾排泄的警示。硫唑嘌呤——经TPMT与NUDT15失活、经黄嘌呤氧化酶氧化，因此与别嘌醇同用需减量约三分之二或换药；用药前TPMT与NUDT15基因型已成标准；配药错误导致的骨髓抑制是血的教训——[[immunology/transplant-tumour-immunology]]、[[gastrointestinal/bowel-disease]]。别嘌醇本身——活性物氧嘌呤醇经肾清除；HLA-B*5801与中国南方及泰国人群的重性皮肤反应，及筛查政策与皮肤反应登记的教训——[[musculoskeletal/inflammatory-arthritis]]。**

::: exercise 用三个层次解释对乙酰氨基酚 {level=1}
向(a)一名少年、(b)一名药学学生、(c)一位肝病单元的顾问医师解释：为何一片“安全”的药会致死，以及N-乙酰半胱氨酸如何起作用。
::: solution
**三个深度（[[#def-phase1]]、[[#def-phase2]]）：少年版——肝有一条常规途径与一条应急途径；应急途径需要一种“身体库存”的解毒原料，而两天吃不好就能把它耗空；酒精占用同一批酶并制造更多坏中间物——[[emergency-critical-care/poisoning]]。学生版——九成以上经葡萄糖醛酸化与硫酸化；CYP2E1（啮齿类还有1A2与3A11）生成NAPQI，由谷胱甘肽解毒，直到越过关键阈值后发生腺泡3区坏死——该区脆弱性可由P450密度与氧张力解释；Rumack-Matthew治疗线是筛查工具而非神谕；四小时浓度依赖于服药剂量的诚实记录；分次超量难以解读；非典型表现要给出风险咨询；N-乙酰半胱氨酸既是半胱氨酸供体、又是直接的硫加合物，并在已发生的损伤中以改善微循环的抗炎方式起效；静脉对口服方案、类过敏的面红与处理、21小时疗程对暴发性病例的延长，以及国王学院标准的转诊移植条件。顾问版——最大速率与米氏常数的饱和数学，对低体重、长期饮酒与禁食重新评估安全系数；治疗剂量肝毒性病例系列的批判性解读；从氟烷与异烟肼时代量化的CYP2E1诱导；以及4-甲基吡唑与福美唑与乙醇竞争同一酶——[[gastrointestinal/liver-disease]]、[[renal/acute-kidney-injury]]。**
:::

::: exercise 给前药分类 {level=2}
对每种前药说明：什么把它激活、活性型做什么、哪个患者因素可能破坏激活：依那普利、氯吡格雷、卡培他滨、奥司他韦、左旋多巴、柳氮磺吡啶、可待因。
::: solution
**前药门诊（[[#def-phase2]]、[[#def-phase1]]）：依那普利——酯酶水解为依那普利拉；重度肝衰竭时转化下降；顺带把血管紧张素转换酶抑制药清单教对：赖诺普利不是前药，因此没有转化问题——[[cardiovascular/heart-failure]]。氯吡格雷——经CYP2C19两步氧化生成硫醇并与P2Y12不可逆结合；功能丧失等位基因抬高支架内血栓风险，还有冠状动脉旁路移植前的停药规则（基因型对血小板功能检测对临床判断之争）——[[cardiovascular/coronary-artery-disease]]、[[blood/thrombosis-anticoagulation]]。卡培他滨——三步酶促转化为氟尿嘧啶（羧酸酯酶与嘧啶磷酸化酶及胸苷激酶），分解代谢经DPYD：DPYD基因型是重度氟尿嘧啶毒性的原因，故有用药前检测与减量方案、尿嘧啶表型检测与亚叶酸救援；它的设计要点是肿瘤偏好性激活，而手足综合征对持续输注的黏膜骨髓模式——[[pathology/cancer-biology]]、[[pharmacology/drug-development-prescribing]]。奥司他韦——经肝酯酶稳健激活、经肾排泄，因此剂量由肾功能而非肝功能决定——[[respiratory/respiratory-infections]]、[[renal/chronic-kidney-disease]]。**
左旋多巴——外周芳香族氨基酸脱羧酶把它变成多巴而后者不能过血脑屏障，故合用卡比多巴与恩他卡朋（COMT阻断），并与大餐竞争氨基酸转运；胃排空延迟会推迟吸收，故有救援选项与十二指肠凝胶的肠道通透生理——[[nervous-system/movement-disorders]]。柳氮磺吡啶——结肠细菌的偶氮还原酶把它切成水杨酸与磺胺吡啶：前者在肠内局部起效，后者作为载体带来副作用（少精、葡萄糖六磷酸脱氢酶缺乏时溶血、与剂量相关的不耐受），而不耐受程度由乙酰化状态解释；美沙拉嗪、奥沙拉嗪与巴柳氮的设计史由此而来——[[gastrointestinal/bowel-disease]]、[[genetics/common-disease-genetics]]。可待因——经CYP2D6转为吗啡，基因型造成“失效”与“中毒”的两极；去甲替林与地昔帕明的CYP2D6治疗窗同理——[[psychiatry/mood-disorders]]。**

::: exercise 设计一份药物遗传学检测政策 {level=3}
你的医院可以对住院患者先发制人地做一个基因套餐。请为政策选择基因、药物、落地方式与证据评估。
::: solution
**套餐设计（[[#def-phase1]]、[[#def-phase2]]、[[genetics/genomic-medicine]]）：按证据与伤害挑选基因-药物对——A级：TPMT与NUDT15对硫嘌呤、DPYD对氟嘧啶、CYP2C19对氯吡格雷、CYP2C9对华法林与非甾体抗炎药、CYP2D6对可待因与他莫昔芬（经内昔芬）、HLA-B*5701对阿巴卡韦、HLA-B*5801对别嘌醇、HLA-A*3101对卡马西平（东南亚人群的重性皮肤反应）；UGT1A1对伊立替康与阿扎那韦黄疸则分级考虑——[[blood/lymphoma-myeloma]]、[[infectious-diseases/hiv]]、[[pharmacology/adverse-reactions]]。**
临床整合——结果要作为“可行动的提示”进入病历，而不是实验室的观光景点；当日即可解读的服务（药师与遗传咨询）；避免“意义未明变异”的洪水；人类白细胞抗原与TPMT有家族含义而一般药物遗传学结果没有；先发制人套餐意外提出的同意与数据保存问题——[[genetics/genetic-testing]]、[[medical-ethics-law/research-ethics]]。证据与公平的批评——先发制人与事后检测的随机试验（氯吡格雷、硫嘌呤与抗抑郁药），按“需要筛查的人数”对“避免的伤害”来读；注意等位基因频率与推荐强度随祖源不同；建模实施成本对避免住院；以及变异注释问题——以欧洲人群为主的套餐会漏掉非欧洲的功能丧失等位基因——[[epidemiology-ebm/randomised-trials]]、[[medical-ethics-law/justice-resources]]、[[public-health/global-health]]。**
