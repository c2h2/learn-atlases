给药方案要回答三个问题：给多少药、多久给一次、以多快的速度达到预期效应。对大多数药物而言，答案来自处方集中的批准剂量，再根据个体加以调整。但每个批准剂量背后，都是前两章所介绍的那些量：分布容积、清除率和半衰期。理解它们如何组合，就能解释为什么有些药物需要负荷剂量，为什么新剂量要数天后才显示出全部效应，为什么在错误时间采集的血药浓度比没有测还糟，以及肾功能衰竭时如何调整剂量。

本章从基本原理出发构建给药方案，内容包括靶浓度法、负荷剂量与维持剂量、蓄积与稳态、给药间隔的选择、治疗药物监测，以及肾病时的剂量调整。本章中的数字均为示例。实际剂量应依据现行处方集（如英国国家处方集BNF）和针对个体患者的地方指南。

## 靶浓度法 {#sec-target}

对大多数药物而言，效应与作用部位浓度的关系比与剂量的关系更密切。由于作用部位通常无法采样，便以血浆浓度作为替代。给药的目标于是成为达到并维持药物治疗范围内的**靶浓度**。

::: definition 治疗范围、负荷剂量与维持剂量 {#def-target-load}
**治疗范围**（或治疗窗）是指在大多数患者中获益概率高、不可接受毒性概率低的血浆浓度范围。其下限有时称为最低有效浓度，上限称为最低中毒浓度。它是群体层面的参考，而不是对个体的保证。

**负荷剂量**是为迅速达到靶浓度而给予的较大初始剂量，取决于分布容积：

$$
\text{负荷剂量} = \frac{V_d \times C_{\text{靶}}}{F}.
$$ {#eq-load}

**维持剂量**通过补充被消除的药物使浓度保持在靶值。稳态时输入速率等于消除速率，因此它取决于清除率：

$$
\text{维持给药速率} = \frac{CL \times C_{ss}}{F}.
$$ {#eq-maint}

其中$F$为生物利用度（静脉给药为1），$C_{ss}$为目标平均稳态浓度。
:::

这两个方程值得分开记住。容积决定负荷剂量；清除率决定维持剂量。水肿患者对于水溶性药物的容积较大，可能需要更大的负荷剂量，但如果清除率不变，维持剂量不变。肾衰竭患者对于经肾排泄的药物清除率较低，需要较小的维持剂量，但负荷剂量通常不变。

::: example 地高辛负荷剂量 {#ex-digoxin-load}
一名体重70 kg的76岁男性患心房颤动伴快心室率和心力衰竭，计划用地高辛（digoxin）迅速控制心率。采用示例值$V_d = 7$ L/kg、目标血浆浓度1 µg/L、口服生物利用度0.7，估算静脉和口服负荷剂量。为什么要用负荷剂量？
::: solution
$V_d = 7 \times 70 = 490$ L。

由[[#eq-load]]，静脉负荷剂量：$490 \times 1/1 = 490$ µg，约0.5 mg。

口服负荷剂量：$490/0.7 = 700$ µg。

这些数字与BNF中批准的负荷剂量处于同一数量级，后者通常分次给予，以降低药物分布期间中毒的风险。之所以使用负荷剂量，是因为肾功能正常者地高辛的半衰期约36小时，老年人和肾功能损害者更长。没有负荷剂量，就需要四至五个半衰期，即一周或更长时间，才能达到稳态。由于地高辛巨大的容积反映的是其在肌肉中的结合，肌肉量少的老年人容积较小，负荷剂量应相应减少。实际给药遵循BNF和地方指南。
:::
:::

## 蓄积与稳态 {#sec-ss}

重复给药时，每一剂都叠加在前几剂的残余量之上。体内药量不断上升，直到每个给药间隔内被消除的量等于给予的量。这种平衡就是**稳态**。

::: theorem 稳态与半衰期规则 {#def-ss}
对于一级消除（速率常数$k$，半衰期$t_{1/2}$）的药物，恒速静脉输注时浓度按下式上升：

$$
C(t) = C_{ss}\left(1 - e^{-kt}\right), \qquad C_{ss} = \frac{\text{输注速率}}{CL}.
$$ {#eq-infusion}

经过$n$个半衰期，浓度达到稳态的$1 - (1/2)^n$：一个半衰期后50%，两个后75%，三个后87.5%，四个后约94%，五个后约97%。**无论剂量多大，约经四至五个半衰期达到稳态。**

间歇给药时，每$\tau$小时给予剂量$D$，浓度围绕平均稳态值波动：

$$
C_{ss,\text{平均}} = \frac{F \times D}{CL \times \tau},
$$ {#eq-cssavg}

对于静脉推注，稳态峰浓度比首剂峰浓度高出一个**蓄积因子**$1/(1 - e^{-k\tau})$。
:::

::: proof
以速率$R_0$输注时，体内药量的变化为$V_d\,dC/dt = R_0 - CL \cdot C$。令$k = CL/V_d$，在$C(0) = 0$条件下求解，得$C(t) = (R_0/CL)(1 - e^{-kt})$。随着$t$增大，$C$趋近$R_0/CL = C_{ss}$。代入$t = n\,t_{1/2}$及$e^{-k t_{1/2}} = 1/2$，得比例$1 - (1/2)^n$。

对于推注，第$(n+1)$剂刚给完时的浓度是迄今所有剂量贡献之和：$C_0(1 + e^{-k\tau} + e^{-2k\tau} + \dots + e^{-nk\tau})$，其中$C_0 = D/V_d$。该几何级数趋于$C_0/(1 - e^{-k\tau})$。就一个间隔取平均：稳态时一个间隔内的曲线下面积等于单剂给药后的面积$F D/CL$，除以$\tau$即得[[#eq-cssavg]]。
:::

半衰期规则有几个重要推论。

- **达到稳态的时间与剂量无关。**剂量加倍使稳态浓度加倍，但并不更快达到稳态。只有负荷剂量能缩短等待时间。
- **任何剂量改变后，新的稳态都需要再经四至五个半衰期。**加量后过早测定的浓度会低估最终浓度。
- **当半衰期延长时**，例如肾衰竭时，达到稳态所需时间更长，且同一剂量下稳态浓度更高。毒性可能在开始用药数天后才出现。
- **同一规则也描述洗脱过程。**停药后，经过五个半衰期约97%的药物已被清除。

### 峰浓度、谷浓度与给药间隔

平均稳态浓度只取决于给药速率（$D/\tau$）和清除率。峰与谷之间的**波动**取决于给药间隔与半衰期的比较。如果间隔远短于半衰期，两剂之间浓度几乎不变；如果间隔更长，波动就很大。

给药间隔的选择要在方便与波动之间取得平衡。氨氯地平（amlodipine）或左甲状腺素（levothyroxine）等半衰期长的药物可每日一次给药而波动很小。半衰期短的药物则需要频繁给药、缓释制剂或静脉输注，除非其效应比其在血浆中存在的时间更长（如阿司匹林和奥美拉唑等不可逆抑制剂，[[pharmacology/drug-receptor]]）。

对抗微生物药物而言，暴露的模式与平均值同样重要。氨基糖苷类以浓度依赖方式杀菌并有抗生素后效应，因此每日一次的高峰浓度加低谷浓度可使杀菌最大化，并减少肾毒性和耳毒性。β-内酰胺类以时间依赖方式杀菌：关键在于给药间隔中浓度维持在病原体最低抑菌浓度之上的时间比例，因此适合频繁给药或延长输注（[[microbiology/antimicrobials]]）。

::: example 设计维持方案 {#ex-maintenance}
某示例性抗生素在某患者体内的清除率为5 L/h，分布容积为60 L。目标平均稳态浓度为10 mg/L。(a) 需要多大的给药速率？(b) 每12小时给药一次时剂量是多少？静脉推注后的稳态峰浓度和谷浓度大约是多少？(c) 改为每6小时给予一半剂量，这些值会如何变化？
::: solution
(a) 由[[#eq-maint]]，给药速率$= 5 \times 10 = 50$ mg/h。

(b) 每12小时：$50 \times 12 = 600$ mg。此处$k = 5/60 = 0.083$/小时（$t_{1/2} \approx 8.3$小时）。每剂使浓度升高$600/60 = 10$ mg/L。稳态峰浓度为$10/(1 - e^{-0.083 \times 12}) = 10/(1 - e^{-1}) \approx 15.8$ mg/L，谷浓度为$15.8 \times e^{-1} \approx 5.8$ mg/L。

(c) 每6小时300 mg，平均浓度相同（10 mg/L），但每剂增加5 mg/L：峰浓度$5/(1 - e^{-0.5}) \approx 12.7$ mg/L，谷浓度$\approx 7.7$ mg/L。缩短间隔可减少波动而不改变平均值。这样是否更好取决于药物：对于时间依赖性抗生素，较高的谷浓度可能有益；对于浓度依赖性抗生素，较低的峰浓度可能更差。
:::
:::

## 治疗药物监测 {#sec-tdm}

对大多数药物而言，效应本身可以测量：血压、心率、血糖、INR、疼痛评分、症状。剂量依据效应滴定，血药浓度不增加任何信息。只有一小类药物，测定血浆浓度才有用。

::: definition 治疗药物监测 {#def-tdm}
**治疗药物监测**（TDM）是测定血浆（或全血）中的药物浓度以指导给药。当以下条件全部满足时它才有用：

1. 浓度与效应或毒性之间存在明确关系；
2. 治疗范围窄；
3. 同一剂量产生的浓度在个体之间差异很大；
4. 效应难以直接测量，或毒性严重且可能无预兆地出现；
5. 有可靠的检测方法，且出结果的速度足以影响决策。

只有在已知末次给药时间和采样时间、药物已达稳态（评估毒性或负荷剂量时除外）、并结合临床情况解读时，血药浓度才能被解读。
:::

| 药物 | 采样时间（典型） | 监测原因 |
|---|---|---|
| 锂盐 | 末次给药后12小时；开始用药后和每次调整剂量后一周，之后定期 | 治疗范围窄；脱水、肾功能下降和相互作用药物可致中毒 |
| 地高辛 | 给药后至少6小时（分布完成后） | 毒性，尤其在低钾血症或肾功能损害时；依从性 |
| 苯妥英 | 通常在给药前；达稳态时 | 可饱和动力学；蛋白结合 |
| 庆大霉素、阿米卡星 | 按地方方案（例如每日一次给药后的定时浓度，或给药前谷浓度） | 肾毒性和耳毒性；肾功能变化 |
| 万古霉素 | 给药前谷浓度，或在采用时按AUC指导给药 | 疗效与肾毒性 |
| 环孢素、他克莫司 | 给药前谷浓度 | 治疗范围窄；相互作用多；排斥与毒性之间的权衡 |
| 某些抗癫痫药、茶碱 | 给药前谷浓度，达稳态时 | 毒性；依从性；妊娠期动力学变化 |

各治疗范围本身因实验室和适应证而异；例如，英国国家卫生与临床优化研究所（NICE）关于锂盐的指南一般在首次处方时以0.6–0.8 mmol/L为目标，对部分人可考虑更高水平。超出预期范围的结果，在改变剂量之前，应先核对采样时间、依从性、相互作用药物和器官功能。

::: warning 在错误时间采集的血药浓度可能严重误导
TDM中最常见的错误是采样时间。在早晨服药后2小时而不是晚间服药后12小时采集的锂浓度，捕捉到的是吸收峰，可能看起来已达中毒水平。给药后6小时内采集的地高辛浓度，测到的是尚未分布到组织中的药物，会高估其效应。对于半衰期36小时的药物，加量后三天检测的浓度尚未达到稳态，会低估最终浓度。每份申请单都应记录末次给药时间和采样时间。
:::

::: example 似乎过高的锂浓度 {#ex-lithium-ss}
一名47岁女性双相障碍患者多年来每晚服用碳酸锂，浓度维持在0.6–0.7 mmol/L。由于症状复发，她的剂量在周一增加。周三上午11点她抽血检查，此前照常在晚上10点服用了晚间剂量；结果为0.9 mmol/L。一位同事提议立即减量。改变剂量之前你会考虑什么？
::: solution
首先要考虑三个与时间有关的问题。

- **采样时间。**样本在服药后13小时采集，接近12小时的标准，因此可作为标准化浓度解读。
- **稳态。**成人锂的半衰期通常约为一天（老年人和肾功能损害者更长），因此新的稳态约需五天。加量后两天，浓度仍在上升。最终的稳态浓度很可能高于0.9 mmol/L，这加重而不是减轻了担忧。
- **其他原因。**脱水、并发疾病、肾功能下降或新加用的相互作用药物（噻嗪类利尿药、ACE抑制药、血管紧张素受体阻滞药和非甾体抗炎药都会降低锂的清除率）也会使浓度升高。

下一步是进行临床评估，寻找中毒体征（震颤、胃肠道症状、意识模糊、共济失调），检查肾功能、血钠和相互作用药物，并按照NICE指南和处方者的计划，在剂量调整一周后复查标准化的12小时浓度。目标浓度的决定（对复发过的患者可能高于通常水平）由专科团队负责（[[psychiatry/mood-disorders]]）。
:::
:::

### 结合改变时的浓度解读

大多数检测测定的是药物总浓度。对于高蛋白结合率的药物，低白蛋白使游离分数升高，因此在范围内的总浓度可能对应着高游离浓度（[[pharmacology/absorption-distribution]]）。对于苯妥英，有些实验室可直接测定游离浓度。在不能测定时，**希纳–托泽（Sheiner–Tozer）方程**给出一个粗略的校正总浓度：

$$
C_{\text{校正}} = \frac{C_{\text{实测}}}{0.2 \times \text{白蛋白（g/dL）} + 0.1}.
$$ {#eq-sheiner}

这只是一个近似值。它在肾衰竭和危重症中表现较差，临床体征仍是最终的依据。

::: example 每天服用的每周一次药物 {#ex-methotrexate-weekly}
一名69岁女性类风湿关节炎患者每周服用一次甲氨蝶呤（methotrexate）10 mg，并服用叶酸。一次住院后，她的出院处方写成了“甲氨蝶呤10 mg每日一次”。两周后她出现严重口腔溃疡、腹泻和瘀斑；中性粒细胞计数为0.4 × 10⁹/L，血小板为20 × 10⁹/L。请解释这一伤害的药理学原理及所涉及的安全原则。
::: solution
用于炎症性疾病的小剂量甲氨蝶呤每周给药一次。每天服用，她接受的剂量是预期的七倍。甲氨蝶呤抑制二氢叶酸还原酶；骨髓和肠黏膜等快速分裂的细胞首先受累，导致黏膜炎和全血细胞减少。甲氨蝶呤经肾脏排泄，因此住院期间任何肾功能下降都会进一步降低其清除率。她的表现属于医疗急症，需在专科紧急指导下处理，可能包括亚叶酸解救。

这是一种公认的、反复发生的差错，英国国家机构已多次就此发布安全建议。减少此类差错的原则包括：在处方上写明星期几，使用单一片剂规格，处方系统默认按周给药，在入院和出院时的用药重整中核对剂量，并向患者解释每周一次的方案，常配合患者自持的用药记录（[[pharmacology/drug-development-prescribing]]）。
:::
:::

## 按肾功能调整剂量 {#sec-renal}

许多药物或其活性代谢物经肾脏清除。肾功能下降时，清除率随之下降，如果不调整剂量，药物就会蓄积。对主要经肾排泄且治疗指数窄的药物，调整最为重要：氨基糖苷类、万古霉素、锂盐、地高辛、直接口服抗凝药、低分子量肝素、二甲双胍、加巴喷丁和普瑞巴林，以及某些抗病毒药。

肾功能主要有两种估算方法。

- **eGFR**由实验室根据肌酐、年龄和性别计算（在英国通常使用CKD-EPI方程），以每1.73 m²体表面积表示。它是为慢性肾脏病分期而设计的（[[renal/chronic-kidney-disease]]）。
- 用**科克罗夫特–高尔特（Cockcroft–Gault）方程**估算的**肌酐清除率**，以该患者实际的mL/min表示。许多药物说明书和剂量表是用它制定的。

$$
CrCl\ (\text{mL/min}) = \frac{(140 - \text{年龄}) \times \text{体重（kg）} \times K}{\text{血清肌酐 } (\mu\text{mol/L})},
$$ {#eq-cg}

其中男性$K = 1.23$，女性$K = 1.04$。BNF建议，对于直接口服抗凝药、主要经肾排泄且治疗指数窄的药物，以及体重极端者和老年人（这两种估算在他们身上可能相差很大），应使用估算的肌酐清除率而不是eGFR。肥胖者应使用何种体重，遵循地方指南。

清除率降低时，有两种策略可减少药物暴露。**减少剂量**而间隔不变，使峰浓度和谷浓度按比例降低。**延长间隔**而剂量不变，峰浓度保持而平均浓度降低，适用于氨基糖苷类等浓度依赖性药物。负荷剂量通常不减少，因为它取决于容积。当肾功能快速变化时，如急性肾损伤，肌酐滞后于真实的GFR，两种估算都不可靠（[[renal/acute-kidney-injury]]）。

::: example 估算肌酐清除率 {#ex-cockcroft}
一名82岁爱尔兰裔女性体重50 kg，血清肌酐110 µmol/L。实验室报告其eGFR为41 mL/min/1.73 m²。考虑为她的心房颤动使用直接口服抗凝药。估算她的肌酐清除率并加以评论。
::: solution
由[[#eq-cg]]：

$$
CrCl = \frac{(140 - 82) \times 50 \times 1.04}{110} = \frac{3016}{110} \approx 27 \text{ mL/min}.
$$

她的肌酐清除率（约27 mL/min）明显低于eGFR（41 mL/min/1.73 m²），因为她体型小、年龄大：eGFR按平均体型标准化，而她的肌肉量少，使“看似正常”的肌酐具有误导性。直接口服抗凝药说明书中的减量和禁忌是按肌酐清除率规定的，因此使用eGFR可能导致过量和出血。药物和剂量的选择遵循产品信息、BNF和地方抗凝指南。
:::
:::

::: example 不断升高的庆大霉素浓度 {#ex-gent}
一名71岁男性因肾盂肾炎伴菌血症，按地方方案开始每日一次静脉注射庆大霉素，同时使用其他抗生素。三天内他的肌酐从95升至160 µmol/L，第四剂前的给药前浓度高于方案阈值。请解释发生了什么，以及下一步的原则。
::: solution
庆大霉素几乎完全经肾小球滤过排泄。随着他的肾功能下降，其清除率降低、半衰期延长，每一剂在下一剂之前被消除的量减少。谷浓度上升；持续偏高的谷浓度与肾毒性和耳毒性相关，而肾毒性又会进一步降低清除率。脓毒症、低血压和其他肾毒性药物可能也促成了肾损伤。

下一步的原则：暂停给药，直到浓度降到阈值以下，然后延长给药间隔（而不是单纯减少剂量，以保留浓度依赖性杀菌所需的高峰浓度），或在培养结果允许时换用肾毒性较小的药物。评估是否还需要庆大霉素，因为许多方案将疗程限制在数天之内。密切复查血药浓度和肾功能，寻找并停用其他肾毒性药物。具体阈值和列线图以地方方案为准（[[infectious-diseases/stewardship-outbreaks]]）。
:::
:::

::: history
药物应按浓度而不是单纯按体重给药的观念，形成于二十世纪六七十年代灵敏检测方法问世之时。气相色谱法和随后的免疫测定法使常规实验室能够测定苯妥英、地高辛和氨基糖苷类等药物，临床药理学家开始把浓度与效应和毒性联系起来。希纳（Lewis Sheiner）及其同事在二十世纪七十年代发展了群体药代动力学方法，利用许多患者的稀疏样本来估计典型的清除率和容积及其变异；如今使用的给药软件和列线图都以他们的方法为基础。科克罗夫特（Donald Cockcroft）和高尔特（Henry Gault）于1976年根据249名男性的数据发表了他们的肌酐清除率方程，对女性的校正则是作为一个假设加入的；近半个世纪后，它仍是药物审批和给药的一部分。二十世纪九十年代，临床研究表明氨基糖苷类延长间隔（每日一次）给药与分次给药疗效相近而毒性更小，此后这种给药方式被广泛采用。
:::

::: summary
- 给药的目标是使浓度达到治疗范围内的靶值。负荷剂量$= V_d \times C_{\text{靶}}/F$；维持给药速率$= CL \times C_{ss}/F$。
- 无论剂量多大，经四至五个半衰期达到稳态；只有负荷剂量能缩短等待。任何剂量改变都会重新开始计时。
- 平均稳态浓度$= F D/(CL\,\tau)$。给药间隔与半衰期的关系决定峰谷之间的波动。
- 治疗药物监测适用于治疗范围窄、动力学多变且效应难以测量的药物：锂盐、地高辛、苯妥英、氨基糖苷类、万古霉素、环孢素和他克莫司等。
- 解读血药浓度要结合采样时间、是否达稳态、蛋白结合和临床情况。
- 肾功能损害时，经肾清除的药物应减少维持剂量或延长间隔；在药品说明书和BNF要求时，估算肌酐清除率（科克罗夫特–高尔特方程）。
:::

## 习题

::: exercise 离稳态有多近？ {level=1 check="87.5"}
某药恒速静脉输注。经过三个半衰期，达到最终稳态浓度的百分之多少？给出准确值。
::: solution
$100 \times (1 - 0.5^3) = 100 \times 0.875 = 87.5\%$。
:::
:::

::: exercise 负荷剂量 {level=1 check="200"}
某药分布容积为50 L，静脉给药。要使血浆浓度达到4 mg/L，需要多大的负荷剂量（mg）？
::: solution
由[[#eq-load]]，负荷剂量$= 50 \times 4/1 = 200$ mg。
:::
:::

::: exercise 维持剂量 {level=1 check="360"}
某药清除率为3 L/h，静脉给药。目标平均稳态浓度为15 mg/L。每8小时应给予多大剂量（mg）？
::: hint
先求每小时给药速率。
:::
::: solution
给药速率$= CL \times C_{ss} = 3 \times 15 = 45$ mg/h。每8小时：$45 \times 8 = 360$ mg。
:::
:::

::: exercise 频繁给药时的蓄积 {level=2 check="3.4"}
半衰期为12小时的药物每6小时静脉推注一次。稳态峰浓度是首剂峰浓度的多少倍？答案保留一位小数。
::: hint
蓄积因子为$1/(1 - e^{-k\tau})$，且$e^{-k\tau} = (1/2)^{\tau/t_{1/2}}$。
:::
::: solution
$e^{-k\tau} = 0.5^{6/12} = 0.5^{0.5} \approx 0.707$。蓄积因子$= 1/(1 - 0.707) \approx 3.41$，保留一位小数为**3.4**。当间隔短于半衰期时，药物在达到稳态之前会显著蓄积。
:::
:::

::: exercise 科克罗夫特–高尔特方程 {level=2 check="43"}
用科克罗夫特–高尔特方程估算一名75岁、体重80 kg、血清肌酐150 µmol/L的男性的肌酐清除率。答案取最接近的整数，单位为mL/min。
::: solution
$CrCl = (140 - 75) \times 80 \times 1.23/150 = 6396/150 \approx 42.6$，即**43** mL/min。
:::
:::

::: exercise 何时检测浓度 {level=2}
一名58岁男性癫痫患者服用一种半衰期约60小时的抗癫痫药。由于突破性发作，他的剂量于3月1日增加。(a) 大约何时达到新的稳态？(b) 何时检测浓度最有意义？应在一天中的什么时间？(c) 如果他在3月3日出现共济失调，你会等到稳态再检测浓度吗？
::: solution
(a) 四至五个半衰期：约240–300小时，即10–12天。约在3月11日至13日达到稳态。

(b) 约两周后采集给药前（谷）样本，能最可重复地反映新的稳态，并记录末次给药时间。

(c) 不会。稳态对于判断剂量从长期看是否合适很重要。怀疑中毒则是立即检测浓度并进行临床评估的理由；解读结果时要知道浓度可能仍在上升。
:::
:::

::: exercise 输注时接近稳态所需时间 {level=3 check="13.3"}
半衰期为4小时的药物开始恒速静脉输注，不给负荷剂量。达到稳态浓度的90%需要多少小时？答案保留一位小数。然后解释负荷剂量会如何改变这一点，以及为什么不能靠提高输注速率来加快这一过程。
::: hint
解方程$1 - e^{-kt} = 0.9$，其中$k = \ln 2/4$。
:::
::: solution
$e^{-kt} = 0.1$，因此$t = \ln 10/k = \ln 10 \times 4/\ln 2 \approx 13.29$小时，即**13.3**小时（约3.3个半衰期）。

开始时给予$V_d \times C_{ss}$的负荷剂量可立即充满分布容积，使浓度立即达到靶值，随后由输注维持。若改为提高输注速率，最终稳态浓度会按比例升高，但时间进程不变（达到新的更高平台的90%仍需3.3个半衰期），因此患者会超过靶值。先以高速率输注一段时间再降为低速率，实际上就是一段时间内给予的负荷剂量。
:::
:::

::: exercise 低白蛋白时校正苯妥英浓度 {level=3 check="10"}
一名66岁女性患有癫痫和肾病综合征，实测苯妥英总浓度为6 mg/L，血清白蛋白为25 g/L（2.5 g/dL）。用希纳–托泽方程[[#eq-sheiner]]计算校正后的总浓度（mg/L），给出准确值。解释这一结果对她的给药意味着什么，并说明该计算的两点局限。
::: solution
$C_{\text{校正}} = 6/(0.2 \times 2.5 + 0.1) = 6/0.6 = 10$ mg/L。

实测的6 mg/L看起来偏低，但由于她的白蛋白低，药物中游离的比例更大。校正值10 mg/L估计的是白蛋白正常时的总浓度，提示她的游离（活性）浓度处于通常范围的下端，而不是低于治疗水平。依据未校正的总浓度加量可能导致中毒，尤其是因为苯妥英的消除是可饱和的。

局限：该方程是在特定人群中推导的，在肾衰竭（尿毒症毒素也会置换苯妥英）和危重症中准确性较差；它假定结合只取决于白蛋白浓度。有条件时，实测的游离苯妥英浓度更可靠，决策应基于癫痫控制情况和中毒的临床体征。
:::
:::
