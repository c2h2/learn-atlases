剂量是关于浓度的决定。**每一次剂量、途径与间隔都是一次隐含的下注：药物在作用部位的浓度将落进一个窗口——足够高而有效、足够低而安全、持续足够久、在此人今日。临床药动学把这注变成算术：目标浓度、分布容积、清除率、半衰期、稳态、负荷剂量、维持速率。**治疗药物监测核对这注，个体化则修正它。本章建立这些数字，也同样重要地，建立围着它们的谦逊。

## 核心算术

::: definition 目标浓度、分布容积与负荷 {#def-target-load}
**浓度是通用货币：多数药物的效应跟随血浆（或作用部位）浓度而非剂量，所以我们瞄准一个目标区间而不是查毫克表；同一药片在一个人是治疗量、在另一个人是中毒量。负荷剂量来自恒等式“剂量=目标浓度×分布容积”——若要立刻达到20 mg/L而分布容积为40 L，体内就需要800 mg，再按生物利用度折算（负荷剂量=目标×分布容积/F）。分布容积是一个记账比值，不是解剖间隙，所以水肿、肥胖、腹水与第三间隙都会改变它，负荷剂量也必须随之改变。**
需要负荷的情形是“等不起”：心律失常、抽搐、重度感染、新血栓的抗凝——以及药物半衰期长或蓄积慢时。它也是医源性伤害最有效的生产环节：忘记的一次、重复的一次推注、每公斤体重的算错，都会全额落地，因为负荷绕过了身体缓慢的缓冲。缓解手段乏味而有效：按浓度或按体重分段的负荷表、肝素与胰岛素与细胞毒药的双人独立核查、预充注射器与智能泵限值，以及知道哪些药永不负荷——其治疗指数或受体行为会惩罚峰值（华法林起效慢的逻辑：维生素K依赖因子的半衰期；以及β阻滞剂“滴定而非负荷”的教义）——[[cardiovascular/arrhythmias]]、[[blood/thrombosis-anticoagulation]]、[[nervous-system/epilepsy]]、[[clinical-skills/patient-safety]]。**
:::

## 稳态及其麻烦

::: definition 清除率、半衰期与稳态 {#def-ss}
**清除率是单位时间被清出药物的血浆体积；决定平均稳态浓度的是它而非半衰期：维持速率=目标浓度×清除率/F。半衰期是推导量（t½=0.693×分布容积/清除率），它回答另一个问题：到稳态要多久（约四至五个半衰期，与剂量和给药频率无关）、以及洗脱要多久。临床推论说容易做难：改变维持剂量不改变到达新稳态的时间，因此隔三天就调锂盐、胺碘酮或抗抑郁药，是把不耐烦装扮成照护；给负荷剂量是唯一提早到达的方法；而肾功能不稳时昨天算出的清除率今天可能是虚构——所以第3天复查要重算而不是回忆。**
一级动力学（单位时间消除固定比例）在治疗剂量下对乙醇与苯妥英失效，对水杨酸也在临床程度上失效：**恒量消除意味着剂量小幅增加会带来不成比例的浓度上升与漫长的平台——苯妥英的“维持剂量悬崖”（300 mg加到400 mg就变成毒性），以及可饱和动力学为何使表观半衰期随剂量拉长。零级思维还支撑着“酒精单位”的诚实、苯妥英换厂牌与换剂型时的换算、以及慢性水杨酸过量中“看浓度而非列线图”的陷阱——[[nervous-system/epilepsy]]、[[emergency-critical-care/poisoning]]、[[psychiatry/mood-disorders]]。**
:::

## 测量这注赌注

::: definition 治疗药物监测 {#def-tdm}
**治疗药物监测在四个条件同时成立时才正当：浓度比剂量更能预测效应；治疗窗窄或效应难以直接观察；检测存在且快到足以改变决定；团队知道拿到数字后该做什么。经典清单——氨基糖苷、糖肽（如今万古霉素按曲线下面积而非追谷值）、锂、苯妥英、丙戊酸、卡马西平、免疫抑制药、部分抗真菌与抗肿瘤药——各自带着采样礼节，而礼节其实是伪装起来的药理：环孢素与他克莫司的谷值与时点诚实（“12小时的真相”）；庆大霉素用随机但偏晚的浓度、肾不稳时以两点估半衰期；低白蛋白与尿毒症时要测苯妥英游离浓度，因为蛋白结合会说谎；锂的12小时标准化浓度不可在给药后4小时抽，并要结合采血时间史解读；卡马西平的晨间浓度与其活性代谢物之争（不依从违反稳态假设——一个浓度可以是行为的证据而非生物学的证据，这把双刃剑要靠事先商定的检测谈话来处理）——[[renal/potassium-calcium-phosphate]]、[[psychiatry/mood-disorders]]、[[immunology/transplant-tumour-immunology]]、[[medical-ethics-law/confidentiality]]。**
现代的扩展是以药动学信息指导的给药：**贝叶斯一样本与两样本的庆大霉素与万古霉素软件、甲氨蝶呤与他克莫司的人群模型、按曲线下面积目标的抗逆转录病毒与抗真菌药（伏立康唑自身的CYP2C19基因型乱局）；以及检测受限的前沿——多数肿瘤与精神科仍在猜。整项实践按“这个数字会不会改变下一次剂量”来分级：没有行动规程的监测就是抽血表演——[[clinical-skills/laboratory-tests]]、[[pharmacology/metabolism-excretion]]。**
:::

::: example 庆大霉素的两星期 {#ex-gent}
一位70公斤的铜绿假单胞菌菌血症患者被开庆大霉素每日一次5 mg/kg；第5天肌酐从80爬到120，病房问是停药还是延长间隔。
::: solution
**运行中的每日一次给药算术（[[#def-ss]]、[[#def-tdm]]、[[renal/acute-kidney-injury]]）：为何每日一次——浓度依赖杀菌加抗生素后效应加适应性耐药，因此目标是高峰值加长而低于毒性的谷；用延长间隔列线图或两次浓度估出这位患者自己的消除。其窄指数由毛细胞与肾小管的累积暴露决定，所以曲线下面积重要；出人意料的是“高峰值加深谷”比“中等峰值加抬高的谷”毒性更低——[[microbiology/antimicrobials]]、[[nervous-system/sensory-systems]]。第5天的问题——肌酐上升意味着清除下降，同一剂量带来更高暴露；按药动学素养排序的选项：减量、延长间隔、或（因需要覆盖铜绿）换药；决定应由实测浓度与新的半衰期作出，而不是只看肌酐数字（查尿量与容量状态；移除或论证其他肾毒药——万古霉素、非甾体抗炎药、对比剂；并把计划写清以便听诊——[[clinical-skills/records-handover]]）。**
监测节奏——每日或隔日测浓度与肾功能直至稳定；疗程拉长时每周查听力与前庭（基线听力与平衡的记录、以前庭优势为主的咨询——暗室中的视物跳动；以及当手术可能需要数周时的“累积总暴露”对话）。元教训——正是这个半衰期最短的药教会我们最多关于测量的事：两个样本、一条斜率、一次剂量、个体化；胜过记住那些把不可平均者平均掉的列线图（[[#def-target-load]]）。**
:::
:::

::: example 锂的稳态之争 {#ex-lithium-ss}
一位双相患者夜间服锂1200 mg，12小时浓度1.1，有口干与细震颤；住院医想加到1600，“因为他还抑郁”；一位代班医师在4小时复测并报出1.6，称为“中毒”。
::: solution
**稳态与采样时间的素养（[[#def-ss]]、[[#def-tdm]]、[[psychiatry/mood-disorders]]）：采样错误——速释锂给药后4小时的浓度是吸收与分布相的数字，不能与12小时标准化的列线图比较；把它按12小时的区间报告就制造了一场假急诊（标准化时点的纪律：核对采血时间、实验室拒收未标注标本；与环孢素“12小时真相”和他克莫司谷值同理）——[[clinical-skills/laboratory-tests]]。临床问题——双相的抑郁不是把锂长期推到1.2以上来解决的（维持浓度约0.6至0.8的证据与复发严重度的取舍；附加策略：在心境稳定剂覆盖下合用抗抑郁药之争、鲁拉西酮与喹硫平的证据、睡眠与心理治疗的优化；以及长期锂必需的甲状腺、钙与肾监测——[[endocrine/thyroid]]、[[renal/chronic-kidney-disease]]、[[endocrine/bone-calcium]]）。细震颤与口干是常见副作用，可给调整给药时间、换缓释与安抚；而粗震颤、共济失调、呕吐与意识混乱是毒性，需停药并查浓度、肾与神经（毒性的诱因：脱水、非甾体抗炎药、噻嗪、血管紧张素转换酶抑制药——它们通过减少肾清除抬高浓度；病假日规则要写在卡片上，相互作用清单则是每位处方者加药前的背诵）——[[cardiovascular/hypertension]]、[[renal/water-sodium]]。**
治理——同一药物不同时点的这场风波，应按“学习而非追责”复盘，并制定重复采样的共同规程；锂的窄指数文件包括心电图、肾与甲状腺基线，以及作为致畸药的妊娠咨询（埃布斯坦畸形的风险要诚实地量化）——[[medical-ethics-law/consent-capacity]]、[[obstetrics-gynaecology/early-pregnancy]]。**
:::
:::

::: example 每周一次的误会 {#ex-methotrexate-weekly}
一位61岁类风湿关节炎患者把她“每周一次”的甲氨蝶呤15 mg按每日吃了11天；因口腔溃疡、呕吐、腹泻与血小板下降来诊；发药标签写着“每周一次服用”，另有一瓶每日的叶酸。
::: solution
**错误间隔的伤害及其修复（[[#def-ss]]、[[#def-target-load]]、[[pharmacology/adverse-reactions]]）：错误的药理——每日给药取消了每周方案内建的恢复窗口，于是快速分裂的黏膜与骨髓承受打击（抗叶酸的机制；效应腔积液时清除下降与蓄积；以及相互作用的放大器——甲氧苄啶、非甾体抗炎药、部分患者的质子泵抑制药——在本就错了的剂量之上更狠）——[[musculoskeletal/inflammatory-arthritis]]、[[renal/chronic-kidney-disease]]。救援——用亚叶酸钙按规程紧急给（不是叶酸），追踪血象、肾功能与乳酸，考虑粒细胞集落刺激因子与输血支持；有条件时测甲氨蝶呤浓度，肾衰且浓度高时考虑葡萄糖酸酶——[[emergency-critical-care/poisoning]]、[[blood/anaemia]]。系统修复——只允许每周包装与给药日历、剂量辅助工具与患者随身记录、药师以回述确认并让家人参与“每周仪式”、电子处方对“每日甲氨蝶呤”的硬性拦截；以及各国把它列为“永不发生事件”的报告：通俗语言标签、在药名行突出“每周”——[[clinical-skills/patient-safety]]、[[clinical-skills/communication]]。告知义务——诚实解释、道歉、记录与事件报告；就是否以及重新开始做共同决定；并核查同一家庭中其他每周或间歇用药（阿仑膦酸、异维A酸与秋水仙碱的“误为每日”事件族）——[[medical-ethics-law/professionalism-regulation]]、[[musculoskeletal/osteoarthritis]]。**
:::

::: example 透析日的抗生素 {#ex-dialysis-timing}
血液透析患者的抗生素总按“病房时刻表”给：头孢曲松每日09:00（包括透析日）、左氧氟沙星每日不减肾剂量、庆大霉素只在透析中心于透析后给而病房在其他日照常给且不查浓度。
::: solution
**体外循环药动学分诊（[[#def-ss]]、[[#def-tdm]]、[[renal/chronic-kidney-disease]]）：什么会被透析清除——分布容积小、蛋白结合低、分子小、亲水：因此庆大霉素与左氧氟沙星被大量清除，而头孢曲松（结合高、按肾的标准分布容积大）几乎不被清除；所以只有“可清除”的药需要透析后补充（高通量膜与血流速度使教科书表只是近似；连续肾替代治疗算法中透析清除可超过残余肾清除）——[[emergency-critical-care/critical-care]]。时机规则——可清除的药在透析后给或在治疗后补充，由浓度来讲道理；因为在清除药物的治疗之前给药等于只给半剂（经肾处理药物在三次每周透析间的蓄积、透析内低血压影响输送、以及导管感染时的管腔封管与生物膜问题）——[[infectious-diseases/healthcare-infections]]。审计要修的条目——左氧氟沙星减量并定时；庆大霉素只在有浓度、且中心与病房共享书面“透析后方案”时使用；头孢曲松按非透析逻辑保留并注意胆道；万古霉素按规程给、治疗前浓度与曲线下面积思维；并把“透析日”当作药动学事件纳入抗菌药物管理查房。治理——肾科药师参与透析规程、电子处方的“知晓透析”警示、以及教育患者“住院会改变你的给药时刻表”（这与居家透析的自主设计形成对照：患者按监测目标自行管理肝素与促红素剂量）——[[renal/filtration]]、[[clinical-skills/records-handover]]。**

## 通向何处

肾与肝的调整机制见[[pharmacology/metabolism-excretion]]与[[renal/chronic-kidney-disease]]；人群变异与药物遗传学见[[pharmacology/patient-variation]]；处方安全文化见[[clinical-skills/patient-safety]]。

::: history
**把剂量变成科学始于化学让药物可测：19世纪特鲁索的洋地黄单位与当时的标准阿片制剂；未标准化的植物提取物使剂量沦为民间传说（纯溶液与加仑制剂之争，以及后来的标准化法律）——[[pharmacology/drug-development-prescribing]]。窄指数的现代时代由图上的两条线奠定：1960至70年代莱维的工作——为苯妥英的可饱和动力学建模并解释其怪癖；以及里琴斯与邓洛普1973年的苯妥英“剂量-毒性”研究与血药浓度指导给药的同年诞生——这一行的教训来自那些苯妥英共济失调家庭：剂量正常而浓度上升时“癫痫加重”——[[nervous-system/epilepsy]]、[[clinical-skills/laboratory-tests]]。半衰期与消除速率的框架由1950至60年代学派形式化：麻醉药再分布动力学的时代，随后是罗兰-托泽与吉巴尔迪-皮尔手册时代的房室建模（1960至70年代），把临床药理变成在半对数纸上画直线教的算术（一房室的教科书与两房室的门诊）——[[pharmacology/absorption-distribution]]。**
治疗药物监测的繁荣：1969至1973年苯妥英常规检测出现、1970年代氨基糖苷的峰谷规程、以及锂浓度成为精神科第一次用实验室给治疗拴上缰绳（维持治疗的锂试验与英国锂监测门诊及其护士主导的抽血轮值）——[[psychiatry/mood-disorders]]。现代个体化时代：夏伊纳-比尔1970至80年代的非线性混合效应方法与群体药动学、2010至2020年代“以模型指导的精确给药”及床旁软件、以曲线下面积为目标的万古霉素共识（改写了一个有四十年历史的追谷值习惯）、以及智能泵与电子处方护栏时代——那些从未消失的负荷剂量错误、以及它们变成的“永不发生事件”——[[clinical-skills/patient-safety]]、[[microbiology/antimicrobials]]。**
:::

::: summary
- 给药就是浓度管理：负荷针对分布容积，维持针对清除率，而半衰期只告诉你时间。
- 无论你怎么改剂量，稳态都要四至五个半衰期；负荷是唯一提早到达的办法，也是最快中毒的办法。
- 可饱和动力学（苯妥英、乙醇、水杨酸）打破比例给药：接近饱和时小剂量变化造成大浓度变化。
- 治疗药物监测只有在时点正确、解读正确（游离对总浓度、依从对生物学）并有预先商定的行动时才有用。
- 肾与肝的调整改变维持剂量而通常不改变首剂；患病中的患者需要今天重算，而不是回忆上周。
- 窄指数药物值得一份规程：体重分段、双人核查、浓度时间表与书面的停止规则。
:::

::: exercise 为何首剂要给足 {level=1}
解释为什么在急性肾损伤时“为肾减量”对亲水抗生素的首剂是错的；以及哪些情况下你仍会改首剂。
::: solution
**首剂逻辑（[[#def-target-load]]、[[#def-ss]]）：首剂取决于分布容积而非清除率；脓毒症与毛细血管渗漏使亲水药物的分布容积变大，因此足量（常更高）的负荷剂量才能把浓度送进范围，而减低的维持剂量只负责让它留在那里——脓毒性休克中“延迟的足够治疗”与死亡率信号、以及“因谨慎而剂量不足”的审计发现——[[emergency-critical-care/shock-fluids]]。首剂确实要改的情形：分布容积被扰乱的药物（肥胖与水肿的表）；毒性主导的负荷（地高辛与茶碱“很少立即负荷”的教义，按体重与瘦体重计算）；以及活性代谢物在肾衰时蓄积、以致第一次暴露也要紧的情形（M6G与吗啡的对照；以及头孢吡肟神经毒性的教训——当清除接近零时浓度可在一天内升高）——[[renal/acute-kidney-injury]]、[[microbiology/antimicrobials]]。**
:::
:::

::: exercise 安排负荷的顺序 {level=2}
为深静脉血栓用华法林快速抗凝时要肝素覆盖；房颤控制心率要缓慢负荷地高辛；癫痫负荷则要在左乙拉西坦与苯妥英之间选——数学不同。请按动力学或受体理由解释每种设计。
::: solution
**负荷设计的比较（[[#def-target-load]]、[[#def-ss]]）：华法林与肝素的桥——华法林的效果需要消耗维生素K依赖因子（因子VII与蛋白C先降，凝血酶需数日），所以国际标准化比值是一份迟到的报告，抗凝必须立刻由胃肠外覆盖；另有早期蛋白C下降的高凝警示，以及肝素自身的监测（体重与肾功能的极端情形下低分子肝素的抗Xa问题）——[[blood/thrombosis-anticoagulation]]、[[blood/haemostasis-bleeding]]。地高辛——巨大的分布容积（结合于肌肉钠钾泵）意味着一日内可口服负荷，但当目标只是心率时并无必要；其陡峭的浓度-毒性曲线（房室结与自律性的平衡；低钾与低镁在任何浓度下都增加毒性；维持依赖肾）使我们宁可缓慢接受或换药——[[cardiovascular/heart-failure]]、[[renal/potassium-calcium-phosphate]]。抗癫痫负荷——左乙拉西坦线性动力学、低结合与宽松指数允许按体重快速输注；苯妥英的可饱和代谢、非线性输注动力学、丙二醇的心脏毒性与“紫袋综合征”则迫使更慢的速率、心电监护与按浓度补量；丙戊酸、拉考沙胺与布瓦西坦各带自己的负荷取舍空间——[[nervous-system/epilepsy]]。**
:::

::: exercise 写出病假日计划 {level=2}
为下列药物起草书面病假日规则（停、减或继续加复查）：锂、二甲双胍、SGLT2抑制药、血管紧张素转换酶抑制药与利尿剂、泼尼松、阿哌沙班、吸入胰岛素、左甲状腺素（其吸收被食物、咖啡、钙、铁与质子泵抑制药扣为人质，所以浓度复查应跟着胃的变化而不只是剂量的变化——[[endocrine/thyroid]]）。
::: solution
**病假日规则草案（[[#def-ss]]、[[#def-tdm]]、[[emergency-critical-care/shock-fluids]]）：锂——呕吐、腹泻、发热伴进食差时停，补液，恢复正常进食后重启；病程数日者查浓度；并把非甾体抗炎药、噻嗪与血管紧张素转换酶抑制药列入同一张警惕清单——[[psychiatry/mood-disorders]]。二甲双胍——容量不足与对比剂时的病假日规则以预防乳酸酸中毒；急性病伴低氧或脓毒症时停用；SGLT2抑制药在围手术期与饥饿状态要停，因为正常血糖酮症酸中毒并不需要多高的血糖（酮体试纸的咨询与“胰岛素不能归零”的教学）——[[endocrine/diabetes]]、[[renal/acute-kidney-injury]]。血管紧张素转换酶抑制药与利尿剂——容量不足的急性病中停以保护灌注与钾，能饮水后重启；心衰者的利尿剂剂量问题要与高血压患者区分（同一批药在“补液”与“脱水”两种逻辑下冲突）——[[cardiovascular/heart-failure]]、[[renal/water-sodium]]。泼尼松——在肾上腺抑制后绝不可简单停：按指南应激加量、随身激素卡与急救注射；以及掩盖感染的取舍——[[endocrine/adrenal]]。阿哌沙班——不设常规停药，但在出血、脱水伴肾损伤或出现相互作用药物时复查；由于肾清除比例与P-糖蛋白，呕吐腹泻日的暴露难以预测，要点名直接口服抗凝药的逆转途径——[[blood/thrombosis-anticoagulation]]。卡片本身：每药一面、通俗语言、写明何时停、何时查、何时打电话；在门诊与患者共同书写，每年与每次住院后复查——[[clinical-skills/communication]]。**

::: exercise 批评一张负荷剂量表 {level=3}
你的医院把一张重症监护的负荷剂量表（按体重、与器官功能无关的首剂）搬到普通病房。请评价收益、失败模式，以及使其在监护室外安全或危险的那些防护。
::: solution
**方案移植的批评（[[#def-target-load]]、[[clinical-skills/patient-safety]]）：支持的理由——剂量不足在脓毒症、疼痛与抗凝中常见且有害；按体重的负荷配双人核查，正是重症、麻醉与肿瘤科已在安全地做的事；它把药动学素养变成交给默认动作而非个人英雄主义。失败模式——病房没有重症的监测密度，因此对“毒性即时且无声”的药（地高辛与苯妥英输注的警示）负荷需要与抗生素不同的护栏；没有智能泵限值与独立双人核查的每公斤算术正是伤害的栖身处；以及照搬重症剂量却不带重症的前提（容量状态、白蛋白、肾轨迹、输注设备）——那是药动学旅游（肝素与胰岛素方案的依从性文献；不断制造伤害的“浓度搞错的储瓶”——用药安全研究所的永不发生事件与高矮字传统）——[[emergency-critical-care/critical-care]]、[[endocrine/diabetes]]。防护——浓度标准化并移除重复的规格、强制功能的双人核查并在超过体重上限时硬停、窄指数清单的药师复查、泵的剂量范围显示与本地库；以及把未遂事件作为方案反馈而非过失来报告的学习系统。评估——“到足够治疗的时间”与不良事件的前后审计；体重记录缺失时估重的公平性（记录体重的文献）；以及方案的日落审查——被复印的表格总比它的证据活得久——[[pharmacology/adverse-reactions]]、[[clinical-skills/records-handover]]。**

## 练习

::: exercise 做这道算术 {level=1}
目标浓度20 mg/L、分布容积35 L、口服生物利用度0.7：负荷剂量是多少？若清除率为0.5 L/h，维持速率应为多少？半衰期是多少？
::: solution
**把数字念出来（[[#def-target-load]]、[[#def-ss]]）：负荷剂量=目标×分布容积/F=20×35/0.7=1000 mg；维持速率=目标×清除率/F=20×0.5/0.7≈14.3 mg/h；半衰期=0.693×分布容积/清除率=0.693×35/0.5≈48.5小时——因此不负荷的话约需十天到稳态，这正是负荷剂量体现价值的时刻；然后是合理性检查：先看单位，再看体重分段，最后看规程；若答案看着不对，先查F与容积的假设，再怪药房（[[#def-tdm]]）。**
:::
:::

::: exercise 负荷还是等？ {level=1}
逐项说明“负荷加维持”还是“缓慢滴定”并给理由：今日需要控制心率的房颤（β阻滞剂）；疑似脑膜炎（万古霉素加头孢曲松）；新发单纯高血压（氨氯地平）；重度抗凝过度的逆转（维生素K）；重症肌无力的维持（硫唑嘌呤）。
::: solution
**负荷对滴定的分诊（[[#def-target-load]]、[[#def-ss]]）：心率控制——急则用短效药滴定，而不是盲目负荷长效药；因为β阻滞可按心率与血压滴定，受体逻辑偏好分级占据（静脉对口服、以及失代偿心衰的谨慎）——[[cardiovascular/arrhythmias]]、[[cardiovascular/heart-failure]]。脑膜炎——立刻给足首剂，此处整个剂量就是负荷；按药效与药动学匹配的β内酰胺剂量与中枢穿透现实决定选药（地塞米松时机的邻接、脑室炎时的鞘内问题）——[[nervous-system/neuroinflammation]]、[[microbiology/antimicrobials]]。高血压——以数周为尺度缓慢滴定，因为获益是慢性的、副作用谱被耐心磨平，而受体与容量系统会适应（白大衣对实测控制；依从支持先于剂量升级）——[[cardiovascular/hypertension]]。维生素K逆转——按出血严重度给一个深思熟虑的剂量（1对5对10 mg的算术；严重出血加凝血酶原复合物；重启华法林的计划；以及大剂量维生素K后长达一个月的抵抗问题）——[[blood/thrombosis-anticoagulation]]。重症肌无力用硫唑嘌呤——起效需数月、不负荷；在抗体分布与生成应答期间用静脉免疫球蛋白或血浆交换桥接（先查TPMT与NUDT15；以及缓慢结局测量的纪律）——[[nervous-system/neuromuscular]]、[[pharmacology/patient-variation]]。**
:::

::: exercise 修正方案 {level=2}
带理由重新设计：(a) 铜绿假单胞菌菌血症按常规剂量每日三次给庆大霉素；(b) 胺碘酮一日内负荷、第10天因“浓度已达治疗范围”而停；(c) 苯妥英两周内从300加到400再加到500 mg，共济失调加重；(d) 静脉万古霉素间断推注而患者浓度“总不达标”。
::: solution
**方案重设计（[[#def-ss]]、[[#def-tdm]]）：庆大霉素——改为每日一次（延长间隔）并按实测半衰期调整；浓度依赖杀菌要峰值，而肾与耳毒性要谷值——这个悖论使常规每日三次既不够有效也不更安全（按调整体重的肥胖剂量问题与透析日时机）——[[microbiology/antimicrobials]]、[[renal/acute-kidney-injury]]。胺碘酮——数周的半衰期意味着第10天的“治疗浓度”反映的是负荷后再分布而非平衡；问题在于数月尺度上的心律与耐受；停不停取决于适应证与毒性的平衡，而不是一个浓度——组织蓄积的动力学解释了角膜沉着、光敏、甲状腺与肺毒性（计算机断层密度的线索）与监测方案——[[cardiovascular/arrhythmias]]、[[respiratory/interstitial-vascular-disease]]。苯妥英——可饱和代谢使300到400到500 mg成为浓度的指数式爬升；解法是小步调整并测浓度、在低白蛋白时解读游离浓度；同时查相互作用（蛋白结合与酶诱导的审计、剂型与厂牌换算），以及长期美容、小脑、骨与神经病变的账单——并问是否换药更明智——[[nervous-system/epilepsy]]、[[pharmacology/metabolism-excretion]]。万古霉素——改为曲线下面积指导（两个浓度或贝叶斯软件）或按规程持续输注；把谷值追到15至20 mg/L以上买来的是肾毒性而非疗效；检查最低抑菌浓度的漂移、源头控制，以及这个药本身是否选错（D试验与可诱导耐药、导管交换；而“口服万古霉素治结肠炎是另一种药”的规则）——[[renal/acute-kidney-injury]]、[[infectious-diseases/stewardship-outbreaks]]。**

::: exercise 设计居家监测服务 {level=3}
为社区的锂与他克莫司服务设计治疗药物监测：采样物流、解读、行动规程、公平与治理。
::: solution
**社区监测设计（[[#def-tdm]]、[[public-health/health-systems-economics]]）：采样物流——把标准化时点做得在院外可执行（锂的12小时与他克莫司的谷值，靠拍照记录给药时间与程序提醒支撑）；社区采样网络、经验证的容积血卡邮寄、居家采集与实验室标准的准确性比较、免疫分析标本的运输与稳定性规则。解读层——“语境中的浓度”决策支持，随药物浓度一并送检肾、甲状腺、钙与白蛋白；零浓度只能在事先同意的检测谈话下作为依从性证据来读，绝不做伏击式检测；并与治疗同盟及配药数据三角验证——[[medical-ethics-law/confidentiality]]、[[psychiatry/treatments-mental-health-law]]。行动规程——预先商定的剂量调整列线图并明确药师权限与处方者回呼；锂超出区间或他克莫司骤升伴肌酐变化的当日紧急路径；两药的病假日规则（胃肠炎期间的锂卡片、移植门诊呕吐日的静脉桥接方案）——[[renal/chronic-kidney-disease]]。公平层——把门诊时间、交通、读写能力与口译接入纳入采用率建模，因为“漏掉的血检”会在同一批家庭变成毒性住院；数字门户的设计不得假定人人有智能手机。治理——检测标准化与室间质量评价、“从结果到剂量”的时间审计、与浓度区间并列的患者报告结局与体验、以及住院与毒性终点（锂门诊人群的结局公平看板；他克莫司浓度变异指数作为移植肾存活的危险因素被主动管理；药师主导门诊的证据）——[[immunology/transplant-tumour-immunology]]、[[public-health/determinants-inequalities]]、[[clinical-skills/records-handover]]。**
