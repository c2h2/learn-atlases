每一种有效的药物都可能造成伤害。药物造成的伤害大多可从药物的药理作用预测，并发生在常规剂量下：抗凝药引起出血，降压药引起低血压，几种影响肾血流的药物合用时引起肾损伤。较少的一部分不可预测，例如对某种抗生素的严重过敏反应，或对某种抗癫痫药的严重皮肤反应。这些反应合起来是疾病的重要原因。2004年发表的一项对英格兰两家医院18,820例入院的前瞻性研究显示，约6.5%的入院与药物不良反应有关；同一研究组用2019年数据重复研究，发现这一比例高得多，为16.5%，但作者告诫不宜直接比较。在两项研究中，最常涉及的都是常用药物，其中包括小剂量阿司匹林、利尿药、抗凝药和非甾体抗炎药。

本章定义药物不良反应并对其分类，介绍免疫性反应和严重综合征，解释药物相互作用如何造成伤害，并说明如何识别、评估和报告不良反应。预防贯穿始终。前面在[[pharmacology/drug-receptor]]和[[pharmacology/metabolism-excretion]]中介绍的机制，是下文大部分内容的基础。

## 定义与分类 {#sec-classification}

::: definition 药物不良反应及相关术语 {#def-adr}
**药物不良反应**（ADR）是对药品产生的有害且非预期的反应。较早的世界卫生组织定义将其限定于人体常规使用剂量；现行英国和欧盟药物警戒法规还包括由差错、误用、滥用、过量以及超出许可条件使用所引起的反应。

相关术语的用法不同：

- **不良事件**是治疗期间发生的任何有害情况，无论是否由药物引起；临床试验记录不良事件，事后再评估因果关系；
- **副作用**是除预期效应之外的任何效应，无论有害与否（例如抗组胺药引起的嗜睡，夜间甚至可能正是想要的）；
- **用药差错**是治疗过程中的失误，如处方、调配或给药环节的失误，导致或可能导致伤害。
:::

::: definition 药物不良反应的分类 {#def-adr-classes}
罗林斯（Michael Rawlins）和汤普森（John Thompson）于1977年提出的方案将反应分为两型，后来扩展为六型：

| 类型 | 名称 | 特点 | 举例 |
|---|---|---|---|
| A | 增强型 | 可从药物已知药理作用预测；与剂量相关；常见；通常较轻，但造成大部分疾病负担 | 华法林引起出血；胰岛素引起低血糖；β受体阻滞药引起心动过缓 |
| B | 异常型 | 不能从药理作用预测；常规剂量下与剂量无明显关系；少见；常为免疫性或遗传性；死亡率较高 | 青霉素引起严重过敏反应；卡马西平引起史–约综合征；恶性高热 |
| C | 慢性型 | 与累积剂量和长期使用相关 | 糖皮质激素引起骨质疏松；抗精神病药引起迟发性运动障碍 |
| D | 迟发型 | 暴露后很久才出现 | 化疗后继发肿瘤；致畸作用 |
| E | 停药型 | 停药时出现戒断或反跳 | β受体阻滞药停药后反跳性心绞痛；长期糖皮质激素停药后肾上腺危象；阿片类戒断 |
| F | 失效型 | 治疗意外失败，常由相互作用引起 | 酶诱导剂导致避孕失败 |

另一种方案**DoTS**（Aronson和Ferner，2003）以剂量关系（**Do**se）、时间进程（**T**ime course）和易感因素（**S**usceptibility）描述每种反应。它更精确，有助于找出预防某一具体反应的方法，但A至F分类仍是通用的临床术语。
:::

A型反应是预防最有成效的领域，因为它们遵循事先已知的规律。常见的易感因素是那些升高药物浓度或敏感性的因素：肾或肝功能减退、高龄、低体重、相互作用药物，以及代谢方面的遗传变异（[[pharmacology/patient-variation]]）。许多A型反应是主要效应的延伸，如服用抗凝药时出血。另一些则来自同一药物作用于其他部位，如β受体阻滞药引起的支气管痉挛或三环类抗抑郁药的抗胆碱能作用。

## 免疫性反应与特异质反应 {#sec-hypersensitivity}

大多数B型反应是免疫介导的**药物过敏**。小分子药物本身通常太小，不能单独引起免疫反应，但有些能与体内蛋白质共价结合，作为**半抗原**形成新的抗原；另一些则直接与HLA分子或T细胞受体等免疫受体结合。盖尔–库姆斯（Gell–Coombs）分类描述了四种机制（[[immunology/hypersensitivity]]）：

| 类型 | 机制 | 时间 | 药物举例 |
|---|---|---|---|
| Ⅰ | 肥大细胞上的IgE；组胺及其他介质 | 数分钟至一小时 | 青霉素类、神经肌肉阻滞药、氯己定引起的严重过敏反应、荨麻疹和血管性水肿 |
| Ⅱ | 针对药物包被细胞的IgG或IgM | 数天 | 某些头孢菌素引起溶血性贫血；肝素（HIT）或奎宁引起血小板减少 |
| Ⅲ | 免疫复合物沉积于组织 | 一至三周 | 血清病样反应；药物性血管炎 |
| Ⅳ | T细胞介导 | 数天至数周 | 接触性皮炎；斑丘疹型药疹；史–约综合征和DRESS |

并非所有看似过敏的反应都是过敏。**非免疫性（假性过敏）反应**通过直接释放介质或其他途径模拟过敏。快速输注万古霉素可直接释放组胺，引起上半身潮红（“万古霉素潮红反应”），减慢输注即可预防。吗啡等阿片类药物可释放组胺而引起瘙痒。非甾体抗炎药可使花生四烯酸代谢转向白三烯，从而在非甾体抗炎药加重性呼吸系统疾病患者中诱发支气管痉挛。ACE抑制药通过减少缓激肽的降解引起血管性水肿，这种反应可能在治疗多年后才首次出现。

::: definition 严重皮肤不良反应 {#def-scs}
少数累及皮肤的药物反应可危及生命，必须及早识别。

- **史–约综合征（SJS）和中毒性表皮坏死松解症（TEN）**是同一种疾病的不同程度：广泛的角质形成细胞死亡，伴表皮起疱和剥脱，以及黏膜（口腔、眼、生殖器）糜烂。剥脱面积小于体表面积10%为SJS，大于30%为TEN，介于二者之间为重叠型。典型起病时间为开始用药后4至28天。常见的致病药物包括别嘌醇、卡马西平、拉莫三嗪、苯妥英、包括复方磺胺甲噁唑在内的磺胺类，以及奈韦拉平。
- **药物反应伴嗜酸性粒细胞增多和系统症状（DRESS）**在开始用药后二至八周出现，表现为发热、广泛皮疹、面部肿胀、淋巴结肿大、嗜酸性粒细胞增多、异型淋巴细胞以及器官受累，最常累及肝脏。抗癫痫药、别嘌醇和某些抗生素是常见原因。
- **急性泛发性发疹性脓疱病（AGEP）**在数天内于红斑基础上出现大量小的无菌性脓疱，常发生于使用β-内酰胺类之后。

每种情况的第一步也是最重要的一步，都是停用可疑药物。治疗以支持为主，常在烧伤或皮肤科病房进行，并把该药物明确记录为永不再用的药物。
:::

其中一些反应与特定HLA等位基因密切相关。HLA-B*15:02在汉族、泰国及其他东南亚血统人群中常见，携带者发生卡马西平所致SJS/TEN的风险大大增加；HLA-B*58:01与别嘌醇反应相关，HLA-B*57:01与阿巴卡韦（abacavir）超敏反应相关。处方前筛查这些等位基因的内容见[[pharmacology/patient-variation]]。

::: warning 青霉素过敏标签常常是错的，而且代价高昂
在英国，约十分之一的人病历中记录有“青霉素过敏”，但经过正式检测，其中绝大多数（约十分之九）可以安全使用青霉素。许多标签来自儿童期病毒感染时出现的皮疹，或恶心之类的不耐受。未经核实的标签促使处方者选择更广谱的抗生素，而后者与更多的艰难梭菌（*Clostridioides difficile*）感染、更多耐药菌和更差的结局相关。仔细询问发生了什么、何时发生、如何处理，准确记录反应，并在有地方路径时转诊去除标签，都是良好处方的一部分。同样，确有严重过敏反应或严重皮肤反应病史的，必须记录并予以尊重。
:::

::: example 服用阿莫西林后出现皮疹 {#ex-rash-review}
一名19岁加纳裔学生咽痛、发热、颈部淋巴结触痛、脾大。两天前因疑似扁桃体炎开具了阿莫西林（amoxicillin）。她现在出现广泛瘙痒性斑丘疹，无黏膜受累，血压正常，无呼吸困难。嗜异性抗体试验阳性。她应被标记为青霉素过敏吗？
::: solution
这些特征提示EB病毒引起的传染性单核细胞增多症。急性EB病毒感染者使用阿莫西林或氨苄西林时，常出现非荨麻疹样的斑丘疹。这反映的是病毒感染期间短暂的免疫相互作用，而不是持久的IgE介导过敏，大多数此类患者以后能耐受青霉素类。

单凭皮疹外观难以确定，因此原则是：停用阿莫西林（病毒性疾病本不需要抗生素），对症治疗，并检查严重反应的警示特征（黏膜糜烂、水疱、皮肤疼痛、发热伴器官受累），本例均无。病历应准确描述所发生的情况（“急性EB病毒感染期间服用阿莫西林第2天出现斑丘疹，无黏膜或全身表现”），而不是简单写“青霉素过敏”，以便日后的临床医生判断风险并考虑正式评估。深色皮肤上的红斑较难辨认；皮疹可能呈紫色或深棕色而非红色，质地和瘙痒是有用的线索（[[musculoskeletal/skin]]）。
:::
:::

## 药物相互作用 {#sec-interactions}

当一种药物的效应被另一种药物、食物、草药产品或疾病状态改变时，就发生了**药物相互作用**。由于许多患者同时服用多种药物，相互作用很常见；当受影响药物治疗指数窄，或联合效应使某一生理系统越过阈值时，相互作用就具有临床意义。

**药代动力学相互作用**改变药物在作用部位的浓度：

- *吸收*：钙、铁和抗酸药与四环素类、喹诺酮类和左甲状腺素螯合；
- *分布*：从血浆蛋白上置换，单独存在时很少有意义（[[pharmacology/absorption-distribution]]）；
- *代谢*：酶诱导和酶抑制，这是最重要的一类（[[pharmacology/metabolism-excretion]]）；
- *排泄*：噻嗪类、ACE抑制药和非甾体抗炎药降低锂的肾清除率；非甾体抗炎药和质子泵抑制药减少甲氨蝶呤的分泌。

**药效学相互作用**发生在两种药物作用于同一系统而不改变彼此浓度时：

- *出血*：抗凝药与抗血小板药、非甾体抗炎药或选择性5-羟色胺再摄取抑制药（SSRI）合用；
- *QT间期延长和尖端扭转型室速*：大环内酯类、某些抗精神病药、西酞普兰、美沙酮和某些止吐药等的组合，尤其伴低钾血症或低镁血症时；
- *5-羟色胺综合征*：5-羟色胺能药物（SSRI、SNRI、MAO抑制剂、曲马多、利奈唑胺、高暴露的曲坦类、锂盐）的组合，引起精神状态改变、自主神经不稳定和神经肌肉亢进（阵挛、反射亢进、震颤）；
- *高钾血症*：ACE抑制药或血管紧张素受体阻滞药与保钾利尿药、钾补充剂或甲氧苄啶合用；
- *中枢神经系统抑制*：阿片类与苯二氮䓬类、加巴喷丁类或酒精合用；
- *急性肾损伤*：ACE抑制药或血管紧张素受体阻滞药、利尿药与非甾体抗炎药三者合用，常称为“三重打击”。

::: example 三重打击 {#ex-triple-whammy}
一名78岁女性患高血压和心力衰竭，服用雷米普利（ramipril）、呋塞米（furosemide）和螺内酯（spironolactone）。在炎热的一周里她又腹泻，并因膝痛自购了布洛芬（ibuprofen）。五天后她嗜睡，肌酐从90升至260 µmol/L，血钾6.6 mmol/L。请解释她的药物如何促成了这一情况。
::: solution
肾小球滤过取决于肾小球内的压力；肾灌注下降时，有两种机制保护这一压力：前列腺素介导的入球小动脉舒张，以及血管紧张素II介导的出球小动脉收缩（[[renal/filtration]]）。

- **利尿药**加上腹泻和高温，使她的循环容量和肾灌注减少。
- **布洛芬**阻断了前列腺素合成，入球小动脉无法舒张。
- **雷米普利**减少了血管紧张素II，出球小动脉无法收缩。

在低血容量时两种保护机制都被去除，肾小球压力和GFR急剧下降：急性肾损伤。钾排泄减少随之引起高钾血症，而螺内酯和雷米普利都减弱醛固酮的作用，使其进一步加重。

原则是紧急处理高钾血症，停用非甾体抗炎药，并在她容量不足期间暂停ACE抑制药、利尿药和螺内酯（常以“病假日规则”的形式固定下来），同时恢复容量。预防措施包括建议避免自购非甾体抗炎药，以及由药师审查新购入的药品（[[renal/acute-kidney-injury]]）。
:::
:::

::: example 他汀与新加的降压药 {#ex-statin-myo}
一名71岁印度裔男性多年来每晚服用辛伐他汀（simvastatin）40 mg。因高血压加用氨氯地平（amlodipine）。两个月后，他在一次长距离步行后诉大腿和肩部肌肉酸痛，尿色加深。肌酸激酶（CK）为正常上限的12倍。多年来首次检测的TSH升高。请解释可能的促成因素及处理原则。
::: solution
他汀相关肌肉症状的范围从CK正常的酸痛到肌炎，罕见情况下为横纹肌溶解。他的CK升高伴尿色加深，提示有明显的肌肉损伤。风险随他汀暴露增加而升高，而本例存在若干因素：

- **相互作用**：辛伐他汀经CYP3A4代谢，氨氯地平对其有弱抑制作用。自2012年起，英国的建议将与氨氯地平合用时的辛伐他汀剂量限制为每日20 mg，因此他的暴露增加了；
- **未治疗的甲状腺功能减退症**，这是他汀肌病的公认危险因素；
- 年龄，可能还有剧烈运动。肝脏摄取转运体（SLCO1B1）的遗传变异也会增加辛伐他汀的风险。

处理原则：停用他汀，评估水化状态和肾功能，复查CK；治疗甲减。恢复后，鉴于他的心血管风险，重新考虑他汀治疗，通常采用较低剂量或较少依赖CYP3A4的他汀（如适当剂量的阿托伐他汀，或瑞舒伐他汀、普伐他汀），并先治疗甲状腺疾病。在临床试验中，大多数报告服用他汀后有肌肉症状的人，在安慰剂组中报告的比例相近，因此应把他这样的真正肌病与非特异性酸痛区分开来；后者在未经仔细评估之前，并不足以成为放弃一种有益药物的理由。
:::
:::

## 识别、评估与报告 {#sec-causality}

判断一种药物是否引起了某一事件往往并不确定。临床医生所寻找的特征，与正式评估所用的特征相同。

::: definition 因果关系评估与药物警戒 {#def-adr-causality}
**因果关系评估**权衡药物引起某一事件的证据：

- **时间**：事件是否在用药后合理的时间间隔内出现？
- **去激发**：停药或减量后是否好转？
- **再激发**：再次暴露时是否复发？（很少有意进行再激发，因为可能有危险。）
- **其他原因**：疾病本身或其他药物能否解释？
- **合理性与已有知识**：该反应对此药或此类药物是否已知，是否有血药浓度等支持证据？

结构化工具把这些转化为类别。**纳兰霍（Naranjo）算法**对十个问题评分；总分9分或以上为“肯定”，5至8分为“很可能”，1至4分为“可能”，0分或以下为“可疑”。世界卫生组织–乌普萨拉监测中心系统使用从“肯定”到“不太可能”的描述性类别。

**药物警戒**是上市后发现、评估、理解和预防药品不良作用的科学与活动。其主要工具是**自发报告**，即医务人员和患者向监管机构报告可疑反应：在英国即药品和保健产品监管局（MHRA）的**黄卡计划**（Yellow Card scheme）。报告被汇总分析，以发现**信号**：可能的新关联或已知关联的新方面，值得进一步调查。
:::

之所以需要自发报告，是因为临床试验规模太小、时间太短，不能发现罕见反应。一个有用的近似方法——**三的法则**——指出：如果$n$人中未发生任何事件，事件发生率95%置信区间的上限约为$3/n$。因此，一个3,000名患者中未出现某种反应的试验项目，可以排除发生率高于约千分之一的情况，但不能排除万分之一的反应，而对一种广泛使用的药物来说，后者仍然很重要。

在英国，新药以及具有新适应证或新剂型的老药，在额外监测期间，其产品信息和BNF中标有倒置的**黑三角**（▼）。对这些药物的所有可疑反应都应报告。对于已确立的药物，应报告严重反应、儿童中的反应以及对草药产品的反应。报告并不要求确定是该药物所致。

为在大型数据库中发现信号，监管机构比较某一反应在某药物报告中出现的频率与在所有其他药物报告中出现的频率。一个简单的指标是**比例报告比**（PRR）：

$$
PRR = \frac{a/(a+b)}{c/(c+d)},
$$ {#eq-prr}

其中$a$为该药物所关注反应的报告数，$b$为该药物其他反应的报告数，$c$和$d$为所有其他药物的相应数字。在报告数足够的情况下，PRR明显大于1即为信号，而不是证明：报告受到媒体宣传、药物上市时间长短以及使用人群的影响。

::: example 计算比例报告比 {#ex-prr}
某监管数据库中有一种新降糖药的报告1,000份，其中20份描述急性胰腺炎。所有其他药物合计有100,000份报告，其中200份描述急性胰腺炎。计算PRR并加以解读。
::: solution
由[[#eq-prr]]：$a = 20$，$a + b = 1000$，$c = 200$，$c + d = 100{,}000$。

$$
PRR = \frac{20/1000}{200/100{,}000} = \frac{0.02}{0.002} = 10.
$$

胰腺炎在该药物报告中所占的比例是其他药物的十倍。这是一个值得调查的信号。它既不能确立因果关系，也不能给出真实的发生率。其他解释包括适应证混杂（2型糖尿病患者因肥胖、高甘油三酯血症和胆石症，胰腺炎的基线风险较高），以及宣传后报告增多。调查将包括病例审查、试验数据分析和药物流行病学研究，如在电子健康记录中开展的队列研究（[[epidemiology-ebm/observational-studies]]）。
:::
:::

::: example 监测一种已知的严重反应 {#ex-clozapine-adr}
一名27岁男性精神分裂症患者对两种其他抗精神病药无效，将开始使用氯氮平（clozapine）。请解释决定其监测方案的严重不良反应，并对其进行分类。
::: solution
氯氮平是治疗难治性精神分裂症最有效的药物，但有三种严重不良反应决定了它的使用方式。

- **中性粒细胞减少和粒细胞缺乏**（B型；怀疑为免疫介导机制）。粒细胞缺乏的发生率低于1%，大多发生在最初18周内。在英国，只有在监测服务登记后才能调配氯氮平：前18周每周查血细胞计数，此后至一年每两周一次，之后每月一次，并设定中断治疗的阈值。应告知他一旦出现咽痛或发热立即报告。
- **心肌炎和心肌病**。心肌炎在最初两个月最常见；许多机构建议在最初几周监测症状、生命体征以及肌钙蛋白和C反应蛋白等指标。
- **便秘和胃肠动力减退**（A型，源于抗毒蕈碱作用），可进展为肠梗阻，并已导致死亡。MHRA已就此发布安全警告。每次复诊都询问排便情况，并及早使用泻药。

其他剂量相关的效应包括镇静、流涎过多、体重增加、高浓度时的癫痫发作，以及与CYP1A2有关的吸烟相互作用（[[pharmacology/metabolism-excretion]]）。本例说明，当获益很大时，已知反应是通过结构化监测来管理的，而不是一味回避（[[psychiatry/psychotic-disorders]]）。
:::
:::

::: quiz
一名66岁男性因风湿性多肌痛长期每日服用泼尼松龙（prednisolone）20 mg，度假时丢失药片而突然停药。三天后他出现低血压、呕吐和意识模糊，血钠128 mmol/L。按扩展的罗林斯–汤普森分类，这一反应最恰当的分类是：
- [ ] A型（增强型）
- [ ] B型（异常型）
- [ ] D型（迟发型）
- [x] E型（停药型）
::: solution
长期使用糖皮质激素抑制下丘脑–垂体–肾上腺轴，因此突然停药时肾上腺无法作出反应。由此引起的肾上腺危象是一种戒断（停药型）反应，即E型。可通过逐渐减量、类固醇急救卡和病假日规则预防，治疗需紧急给予胃肠外氢化可的松（[[endocrine/adrenal]]）。
:::
:::

::: history
现代药品监管源于一次次灾难。1937年，美国有一百多人在服用以有毒溶剂二甘醇溶解的磺胺“酏剂”后死亡；次年，《联邦食品、药品和化妆品法》要求药品上市前提供安全性证据。沙利度胺（thalidomide）自1957年起作为镇静药和妊娠呕吐药上市，导致数千名婴儿出现严重的肢体畸形（海豹肢症）；1961年，澳大利亚的麦克布赖德（William McBride）和德国的伦茨（Widukind Lenz）报告了这一关联，该药随后撤市。在英国，这促成了由邓洛普爵士（Sir Derrick Dunlop）担任主席的药品安全委员会，该委员会于1964年启动了黄卡计划，并促成了1968年的《药品法》。世界卫生组织国际药物监测规划始于1968年，其数据库现由乌普萨拉监测中心保管。在美国，食品药品监督管理局的凯尔西（Frances Kelsey）曾拒绝批准沙利度胺，1962年的基福弗–哈里斯修正案在安全性之外又增加了证明有效性的要求。不良反应的A型和B型分类由罗林斯和汤普森于1977年发表。
:::

::: summary
- 药物不良反应是对药品的有害、非预期反应；在医院入院中，相当一部分与药物不良反应有关，涉及的大多是常用药物。
- A型反应可预测、与剂量相关且常见；B型反应不可预测，常为免疫性；C至F型分别为慢性、迟发、停药和失效反应。DoTS描述剂量、时间和易感性。
- 药物过敏遵循盖尔–库姆斯分型。SJS/TEN、DRESS和AGEP是严重皮肤反应，须立即停用药物。其中一些与HLA等位基因相关。
- 许多青霉素过敏标签不准确；准确记录和去除标签可改善诊疗。
- 药代动力学相互作用改变药物浓度；药效学相互作用叠加对出血、QT间期、5-羟色胺、血钾、镇静和肾灌注的效应。
- 因果关系依据时间、去激发、再激发、其他原因和已有知识判断。自发报告（黄卡）和信号检测能发现试验遗漏的罕见反应；三的法则说明了原因。
:::

用扩展的罗林斯–汤普森方案分类：(a) 服用格列齐特（gliclazide）者漏餐后发生低血糖；(b) 首剂阿莫西林克拉维酸引起严重过敏反应；(c) 多年使用抗精神病药后出现迟发性运动障碍；(d) 突然停用苯二氮䓬类后癫痫发作；(e) 服用复方避孕药并合用卡马西平的女性意外妊娠。
::: solution
(a) A型：药物降糖作用的延伸。(b) B型：免疫介导（Ⅰ型超敏反应），不能从药理作用预测。(c) C型：与长期累积暴露相关。(d) E型：停药（戒断）反应。(e) F型：酶诱导导致治疗失败。

::: exercise 匹配超敏反应类型 {level=1}
为下列每种情况指定盖尔–库姆斯类型：(a) 静脉注射头孢呋辛10分钟内出现荨麻疹和喘息；(b) 开始使用肝素7天后血小板计数下降并出现新的血栓；(c) 一个抗生素疗程两周后出现发热、关节痛和皮疹，补体降低；(d) 外用抗生素处出现瘙痒性湿疹样皮疹。

(a) Ⅰ型（IgE介导）。(b) Ⅱ型（针对肝素–血小板第4因子复合物的抗体引起血小板活化：肝素诱导的血小板减少症）。(c) Ⅲ型（免疫复合物；血清病样反应）。(d) Ⅳ型（T细胞介导的接触性皮炎）。

::: exercise 三的法则 {level=1 check="0.2"}
在一种新药的试验中，1,500名患者接受了治疗，无一人发生某种严重肝脏反应。按三的法则，发生率95%置信区间的上限约为多少？以百分数表示，给出准确值。
::: solution
$3/1500 = 0.002 = 0.2\%$。数据与高达约五百分之一的发生率相容，因此试验中未出现病例只能提供有限的保证。
:::

::: exercise 不成比例信号 {level=2 check="10"}
某自发报告数据库中有药物X的报告1,000份，其中20份描述某种反应。所有其他药物有100,000份报告，其中200份描述该反应。计算比例报告比，给出准确值。
::: hint
应用[[#eq-prr]]：比较药物X报告中的比例与所有其他药物报告中的比例。
:::
::: solution
$PRR = (20/1000)/(200/100{,}000) = 0.02/0.002 = 10$。这是需要进一步调查的信号，而不是因果关系的证据。
:::

::: exercise 因果关系评分 {level=2 check="7"}
一名女性在开始服用某药3周后发生肝炎。使用以下纳兰霍条目评分：该反应既往有确切报告（+1）；事件在用药后出现（+2）；停药后好转（+1）；未再激发（0）；经检查未发现其他原因（+2）；未给安慰剂（0）；未测血药浓度（0）；未改变剂量（0）；既往未暴露（0）；有客观证据证实（肝活检）（+1）。总分是多少？属于哪一类别？
::: solution
$1 + 2 + 1 + 0 + 2 + 0 + 0 + 0 + 0 + 1 = 7$。5至8分为“很可能”。

::: exercise 需治疗多少人才导致一例伤害 {level=2 check="100"}
在一项随机试验中，新药组2%、安慰剂组1%的患者在一年内发生严重不良事件。一年的需伤害人数（NNH）是多少？
::: solution
绝对风险增加$= 0.02 - 0.01 = 0.01$。需伤害人数$= 1/0.01 = 100$：每治疗100人一年，就多一人发生该事件。这要与获益的需治疗人数相权衡（[[epidemiology-ebm/randomised-trials]]）。
:::

::: exercise 换用新止痛药后烦躁的患者 {level=3}
一名45岁女性因抑郁症服用舍曲林（sertraline），因背痛被开具曲马多（tramadol）。两天后她烦躁、出汗，体温38.6 °C，脉搏118次/分，瞳孔散大，震颤，可诱发踝阵挛，反射活跃且以下肢为著。(a) 可能的诊断和机制是什么？(b) 哪些特征可将其与神经阻滞剂恶性综合征和抗胆碱能中毒相鉴别？(c) 概述处理和预防的原则。
::: hint
注意神经肌肉体征和皮肤。
:::
::: solution
(a) 5-羟色胺综合征，一种药效学相互作用。舍曲林抑制5-羟色胺再摄取；曲马多除作用于阿片受体外，也抑制5-羟色胺（和去甲肾上腺素）再摄取。二者合用增加5-羟色胺能活动，尤其是在脑干和脊髓的5-HT₂A受体。（舍曲林不是强效CYP2D6抑制剂，但氟西汀或帕罗西汀等强效抑制剂还会升高曲马多浓度。）

(b) 5-羟色胺综合征在用药改变后数小时至一两天内出现，伴神经肌肉亢进（阵挛、反射亢进、震颤），以下肢为著，并有出汗、腹泻和瞳孔散大。神经阻滞剂恶性综合征在开始使用或加量多巴胺拮抗药后数天内形成，表现为“铅管样”强直、运动迟缓、高热和极高的CK，无阵挛。抗胆碱能中毒也引起烦躁、发热和瞳孔散大，但皮肤干燥、肠鸣音减弱、反射正常。

(c) 停用5-羟色胺能药物，给予支持治疗（补液、降温、用苯二氮䓬类控制烦躁），重症时寻求专科建议，可能使用5-HT₂A拮抗药，高热时可能需要重症监护。预防：处方前核查相互作用；对服用SSRI者优先选用无5-羟色胺能作用的镇痛药，并提醒患者注意具有5-羟色胺能作用的非处方药和草药产品，如圣约翰草。
:::

::: exercise 衰弱男性的高钾血症 {level=3}
一名83岁男性心力衰竭患者每日服用雷米普利10 mg和螺内酯25 mg，血钾一直在5.0–5.3 mmol/L。因尿路感染给予一个疗程的甲氧苄啶（trimethoprim）。四天后他的血钾为6.8 mmol/L，肌酐从130升至165 µmol/L。心电图显示T波高尖。(a) 解释每种药物如何促成高钾血症。(b) 为什么即使GFR并未真正下降，他的肌酐也可能升高？(c) 哪些系统层面的改变可以预防这种情况？
::: solution
(a) 雷米普利减少血管紧张素II，进而减少醛固酮分泌，使集合管的钾分泌减少。螺内酯阻断盐皮质激素受体，作用相同。甲氧苄啶像阿米洛利一样阻断集合管的上皮钠通道（ENaC），消除了驱动钾分泌的电化学梯度。三种药物依次作用于同一通路：这是一种发生在储备很少的人身上的药效学相互作用，又叠加了与年龄相关的肾功能下降。

(b) 甲氧苄啶还抑制肌酐的肾小管分泌，因此血清肌酐会适度升高而GFR并未下降。升高中可能有一部分是这种假象；也可能有一部分是感染和脱水引起的真正肾损伤。两者都需要评估。

(c) 伴心电图改变的高钾血症应按地方方案作为急症处理。预防：对使用肾素–血管紧张素–醛固酮系统阻滞药和保钾利尿药的人，在地方指南允许时选择其他抗生素，若必须使用甲氧苄啶，则在数天内复查血钾；对高风险组合使用电子处方提醒；让药师参与审查多药合用者的新处方；并为ACE抑制药和螺内酯提供病假日指导。每一项预防措施针对的都是可从药理作用预测的A型反应。
:::
