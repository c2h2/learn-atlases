药物不良反应是“必要的药理作用造成的伤害”，可随剂量也可不随剂量。**流行病学令人谦卑：不良反应占了入院原因的相当比例，伤害集中在老人、极重患者与多重用药者，而多数严重反应其实可以从药物机制、患者的遗传学、器官功能或相互作用清单中预知。**不良反应分为增强的药理效应（A型，常见，可预防）、特异质反应（B型，少见，在免疫学或遗传学解释之前显得神秘），以及长潜伏期类别——致癌与致畸——由各自章节覆盖。本章的职责是把混乱整理出秩序：分类、机制、具体综合征、监测系统，以及把时间巧合变成诊断的因果关系推理。

## 分类与机制

::: definition A型、B型与字母表的扩展 {#def-adr-classes}
**A型（增强）：把药理作用开得太高——β阻滞剂的心动过缓、胰岛素低血糖、抗凝药出血、抗毒蕈碱药意识混乱——常见、随剂量、可逆，几乎是所有“可预防伤害”项目的靶点（剂量错误、相互作用与器官功能衰竭三条路径见前几章，窄治疗指数清单就是病房的危险登记册）——[[pharmacology/dosing-principles]]、[[pharmacology/patient-variation]]。B型（怪异）：与剂量无关的宿主反应——免疫性（药物超敏综合征、血清病样反应、药物性狼疮及其抗组蛋白药物与生物制剂自身的自身免疫悖论），以及越来越能被“毒性代谢物处理”、线粒体与酶多态性解释的非免疫性特异质：氟烷肝炎是第一个在分子层面被理解的特异质反应——氧化代谢生成三氟乙酰化蛋白加合物——以及1990年代毒理学学派的框架：“获得性药物代谢”假说与“次要代谢途径生成反应性中间物”的想法，使生物活化成为药物开发的常规问题——[[pharmacology/metabolism-excretion]]、[[immunology/hypersensitivity]]。**
公告中使用的扩展字母表：C型（慢性：吸入糖皮质激素的生长与骨效应、迟发性运动障碍、镇痛药肾病）、D型（延迟：致畸，带孕期特异性窗口与沙利度胺遗产，见胚胎学与产科；以及潜伏期极长的致癌）、F型（家族：药物遗传学——琥珀胆碱窒息、恶性高热易感、葡萄糖六磷酸脱氢酶缺乏与溶血清单、以及与人白细胞抗原关联的重性皮肤反应——本质是穿了免疫学外衣的药物遗传学）；以及已被撤下的E型（撤除：阿片、苯二氮类、β阻滞剂反跳、激素危机）——其现象临床重要到以别的名字存活下来（停药综合征常被不良反应报告系统漏掉，因为“没有用药”看起来不像有病因）——[[obstetrics-gynaecology/pregnancy-complications]]、[[genetics/common-disease-genetics]]、[[psychiatry/substance-use]]。**
最后是登记册与说明书使用的“伤害词汇”：副作用（预期内、常轻微）、不良效应（有害）、不良反应（没有合理理由把病因归给别的因素）、不良事件（任何与药物在时间上相关的事件）、严重（死亡、住院、残废、先天畸形、需要干预）、哨点事件与“永不发生事件”——这套语言决定了一个信号是否会被看见，因为一个只统计“够得上打官司”的伤害的系统学到的最少——[[clinical-skills/patient-safety]]。**
:::

## 主要综合征

::: definition 重性皮肤与全身性超敏 {#def-scs}
**重性皮肤不良反应是一个共享免疫学、面貌不同的临床病理家族：斑丘疹疹常见、良性、自限（儿童病毒疹对药疹的鉴别，以及传染性单核细胞增多症用阿莫西林的经典）；荨麻疹与血管性水肿是肥大细胞疾病，其中血管紧张素转换酶抑制药的缓激肽型不痒、抗组胺药无效，且可在治疗数月后才出现。重性四联：Stevens-Johnson综合征与中毒性表皮坏死松解（角质细胞凋亡伴表皮剥脱、黏膜炎与SCORTEN评分，绝大多数由药物引起，肇事药多在一至三个月内新起）；DRESS伴嗜酸性粒细胞增多、器官累及、疱疹病毒再激活生物学以及延迟而波动的病程；以及急性泛发性发疹性脓疱病，在抗生素后以“发热-脓疱-中性粒细胞增多”迅速起病——[[musculoskeletal/skin]]。**
把人白细胞抗原药物遗传学把这些病从抽奖变成预测：HLA-B*5701与阿巴卡韦（强制检测政策消除了临床相关超敏）、HLA-B*1502与卡马西平及拉莫三嗪在东南亚与汉族人群的风险、HLA-B*5801与别嘌醇在高危人群的筛查建议、HLA-A*3101与卡马西平皮肤反应在更广泛祖源中的关联、以及氟氯西林黄疸信号与21个月潜伏期的病例对照怪论；再加半抗原、p-i（药物与免疫受体的直接药理相互作用）与“改变受体库”模型，解释一个小分子如何重新教育T细胞——[[pharmacology/patient-variation]]、[[immunology/adaptive-responses]]、[[genetics/genetic-testing]]。其他全身综合征：药物性狼疮（肼苯达嗪、硝呋太尔、米诺环素、普鲁卡因胺的抗组蛋白格局，以及抗坏死因子α性狼疮的不同抗体谱与“关节痛-浆膜炎”表现、停药后数周至数月缓解）；血清病与血清病样反应（头孢克洛与嵌合单克隆抗体的模式、补体消耗与III型机制）；伴嗜酸性粒细胞增多与器官受累的药物反应（肝、肾、肺、甲状腺的累及，以及激素减停反跳的处理之争）；血管炎（丙硫氧嘧啶与左旋咪唑掺假可卡因的抗中性粒细胞胞质抗体模式，模拟寡免疫性血管炎）；以及“药物热”这一排除诊断——相对缓脉的老话、周末退药即退热的模式、以及再次激发确认的伦理——[[musculoskeletal/connective-tissue-vasculitis]]、[[immunology/autoimmunity]]、[[infectious-diseases/healthcare-infections]]。**
共有的处理主轴：尽早停肇事药（Stevens-Johnson与中毒性表皮坏死松解的早期停药生存数据，以及按时间轴排列的常见嫌疑清单）、烧伤病房与重症级别的支持治疗、鉴别不清时做活检与免疫荧光、全身治疗（证据仍有争议）、把反应连同严重度与日期写入病历以保证将来处方安全、患者随身记录与过敏标签的纪律——青霉素标签审计发现多数标签并不正确却很少再做激发，而艰难梭菌、手术与头孢交叉反应率的百分比倒常常引用得正确；过敏门诊的“去标签”服务本身就是一项抗菌药物管理——[[clinical-skills/records-handover]]、[[infectious-diseases/stewardship-outbreaks]]。**
:::

## 看见、证明与预防

::: definition 监测与因果 {#def-adr-causality}
**药物警戒建立在不完美的数据上：自发报告（黄卡及各国对应制度）对怪异反应灵敏度极好而对发生率特异度极差，因为报告由“新奇”驱动（韦伯效应——报告在上市后可达峰）、媒体与诉讼；分母是处方数而不是患者数，分子则是某一位医师的惊讶（报告比值比与“报告差异”统计、比例报告分析的陷阱，以及最终变成机制文献的病例系列）。群体水平的确认来自处方事件监测、队列与自身对照设计，使用基层与医院链接数据（以病例为中心的设计适合短暂暴露与突发结局）——[[epidemiology-ebm/observational-studies]]、[[epidemiology-ebm/measuring-disease]]。**
个体层面的因果判断使用结构化推理：时间合理性（按反应类型的潜伏期：过敏性休克为数分钟，药疹为数日至数周，Stevens-Johnson与DRESS为一至三个月，迟发性综合征为数月至数年）、去激发（停药后好转）、再激发（重启后重复——有时是证据，通常是不道德的选项）、排除疾病本身（“其实是淋巴瘤的皮疹”、感染热对药物热的算术）、以及经验证的量表（Naranjo与世界卫生组织乌普萨拉中心分级）——诚实地当作沟通工具而不是神谕；量表已知的弱点（多药同时停用时的归因不足、适应证混杂）都写在方法学文献里——[[clinical-skills/clinical-reasoning]]。**预防栈是医学早已知道答案却常常不用的部分**：带相互作用与剂量带警示的电子处方，以及抗凝药、胰岛素与细胞毒药“三兄弟”的强制双人核查；交接时药师主导的药物复查（调剂缺口被记录为伤害载体）；高警示标签体系（听似看似药名、高矮字、浓溶液与稀释液清点）；带结构化严重度细节的过敏与反应记录；以及减药项目——其效益以便免的跌倒、谵妄与入院来衡量（抗胆碱负荷、质子泵抑制药、苯二氮类与减药证据族）——[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]、[[geriatrics-palliative/polypharmacy]]。**
义务层：即使不确定也要报告严重可疑反应（信号检测的算术需要不完美的分子）、伤害后的坦诚、补偿制度（疫苗损害给付的类比）、以及利益冲突管理——它使上市后证据可信；从己烯雌酚到罗格列酮的“因伤害而撤市”史，要当作警戒制度的正反案例来读——[[medical-ethics-law/professionalism-regulation]]、[[immunology/vaccines-immunotherapy]]。**
:::

::: example 皮疹与抗生素的复查 {#ex-rash-review}
因葡萄球菌菌血症使用氟氯西林的第八天：患者瘙痒，躯干出现麻疹样皮疹，嗜酸性粒细胞1.4，肌酐由70爬至105；团队想换成替考拉宁，“因为青霉素已经禁用了”。
::: solution
**β内酰胺药疹的推理（[[#def-scs]]、[[#def-adr-causality]]、[[microbiology/antimicrobials]]）：先看表型——良性斑丘疹疹、早期DRESS，还是荨麻疹性进展；明确检查黏膜、水疱与全身征象这些红旗，并核对时间轴（第八天是T细胞介导药疹的典型时点，也是肝炎与肾炎的窗口；氟氯西林自身的胆汁淤积性黄疸可在数月后出现，是另一个值得记录的信号）——[[musculoskeletal/skin]]。器官问题：嗜酸性粒细胞增多加肌酐上升更提示早期间质性肾炎（尿检、皮肤与全身征象，“停药观察、重症用激素”的文献），而不是并发的脓毒症肾损伤——这需要把用药决定与临床轨迹放在一起读——[[renal/acute-kidney-injury]]。**
换药之争：确认为严重反应时停肇事药是对的，但“青霉素禁用”是从一个非重性药疹得出的错误结论——头孢与碳青霉烯的交叉反应率低，且由侧链而非β内酰胺环决定（R1侧链相似性规则；IgE介导病史下的分级激发与试验剂量方案，以及皮刺与皮内试验加口服激发的路径可为大多数人去标签）；而替考拉宁自带皮疹与嗜酸性粒细胞增多的风险，并失去治愈菌血症所依赖的抗葡萄球菌确定性——[[infectious-diseases/stewardship-outbreaks]]。记录：把实际发生的事（描述、严重度、治疗、日期）写清，让下一团队能理性地再激发或回避；为想要回青霉素的患者转诊过敏门诊；并把可疑DRESS报告给药物警戒系统——[[clinical-skills/records-handover]]、[[pharmacology/patient-variation]]。**
:::

::: example 他汀肌痛的迷宫 {#ex-statin-myo}
一位服阿托伐他汀80 mg的女性在两种他汀上都出现致残性肌痛而肌酸激酶正常；低密度脂蛋白很高且家族史强烈；她要求“永远不再用他汀”；遗传门诊提到了SLCO1B1。
::: solution
**A型肌病对疾病分类（[[#def-adr-classes]]、[[#def-adr-causality]]、[[cardiovascular/vascular-disease]]）：机制图——他汀肌肉症状是一个谱，从劳累性肌痛到抗HMGCR抗体的免疫介导坏死性肌病（罕见、进展、由他汀触发的自身免疫型，停药后仍继续，需要免疫抑制，是最不能漏的一型）——[[nervous-system/neuromuscular]]。**
药动学贡献：SLCO1B1变异损害肝OATP1B1摄取，最显著提高辛伐他汀酸暴露（SEARCH试验信号、阿托伐他汀与普伐他汀的排序差异）；再加非诺贝特类肌溶解的警示、CYP3A4抑制药堆叠，以及在怪罪他汀之前必须排除的甲状腺功能减退、维生素D不足、运动与炎症性疾病——[[pharmacology/metabolism-excretion]]、[[endocrine/thyroid]]。能把“永不用他汀”变成数据的再激发策略：自身n-of-1与开放的计划性重启证据（StatinWISE与盲法再激发研究显示多数他汀肌肉症状在安慰剂上同样复现——反安慰剂效应既是真实生理也是咨询工具），配合间歇或低剂量方案（按半衰期选隔日给药的瑞舒伐他汀或普伐他汀，并监测下递增），辅酶Q10的弱证据要诚实引用；以及遗传与血脂团队存在的理由——非他汀升级：依折麦布的肌病中性、前蛋白转化酶枯草溶菌素9抑制药的降脂威力（依从性、成本与注射的考量）与英克利司兰的一年两针逻辑、贝派地酸“前药设计避开肌肉”的卖点及其肌腱与痛风警示——[[genetics/common-disease-genetics]]。因果记账：时间关系、去激发与再激发模式、n-of-1记录、共同决策并记录偏好（风险感知、被框架化的低密度脂蛋白数字、以及她作为先证者触发的家系筛查级联）——[[clinical-skills/communication]]、[[genetics/genetic-testing]]。**

::: example 氯氮平验血之辩 {#ex-clozapine-adr}
一位服氯氮平的男性问他为什么“要永远每周扎针”；他的朋友因为“这些药把心吃坏了”而停掉了抗精神病药；门诊的争论在于监测究竟是过度还是不足。
::: solution
**监测即伤害预防的经济学（[[#def-adr-classes]]、[[#def-adr-causality]]、[[psychiatry/treatments-mental-health-law]]）：粒细胞缺乏的故事——小比例的特发性中性粒细胞破坏，多在最初数月，这就是登记制度、推迟阈值与血液科联络的理由；以及良性族裔中性粒细胞减少问题：绝对的细胞计数规则多年把合格患者挡在门外，直到按族别调整的参考范围与BENEFIT数据改变政策（一个不良反应管理制度制造了准入不公——这是公正性的读法）——[[blood/anaemia]]、[[medical-ethics-law/justice-resources]]。心肌炎问题——早期短暂的嗜酸性粒细胞与C反应蛋白及肌钙蛋白升高，多在第一个月，通常自限；这个综合征造就了“黑框警告时代”，而未治疗的精神病造成的死亡多于心肌炎（风险比较要诚实，采用症状加生化标志物的方案）；加上较晚出现的代谢综合征、便秘与肠梗阻（背后是有死亡病例的肠道抗胆碱负荷）、镇静、流涎与剂量相关的癫痫——[[psychiatry/psychotic-disorders]]、[[gastrointestinal/bowel-disease]]。**
依从性逻辑：登记制度成为医患关系中的第三方；追“漏验的血”是安全与自由之间的张力（停药级联与社区处方）；而“能否延长间隔”应由发生率曲线与信任建设回答，不是由官僚程序回答。患者应得的比较：把未治疗疾病的伤害（自杀、代谢漂移、功能衰退）与药物伤害并列量化，并按指南真正规定的间隔（而非门诊忘记的间隔）为所有抗精神病药做代谢监测——[[clinical-skills/communication]]、[[psychiatry/mood-disorders]]。**

::: example 草药性肝炎 {#ex-herbal-hep}
一位45岁自身免疫性肝炎患者正在服硫唑嘌呤，又在网购买回“护肝”与“提高免疫”的复方；六周后丙氨酸氨基转移酶升至基线的15倍；鉴别包括疾病活动、药物、病毒与保健品。
::: solution
**肝细胞损伤的侦查工作（[[#def-adr-causality]]、[[#def-adr-classes]]、[[gastrointestinal/liver-disease]]）：因果框架——RUCAM式推理：潜伏期（草药性肝炎常为一至三个月，硫唑嘌呤特异质则不定）、模式（按R值区分肝细胞型与胆汁淤积型，而保健品偏爱混合模式）、去激发（先停保健品，看是否好转，再怪处方药）、以及排除（病毒血清学，含她在免疫抑制下携带的再激活风险；自身免疫活动指标，疾病活动对药物有时需活检区分；影像查血管与胆道原因；以及肌病与乳糜泻这些安静的排除）——[[immunology/autoimmunity]]、[[infectious-diseases/tropical-infections]]。**
保健品取证：网络成分的不确定性（标签不足、掺杂物；绿茶提取物、藤黄与乌药酸、类叶升麻与美洲石蚕的文献；吡咯里西啶生物碱的肝窦阻塞综合征模式；健身产品里的隐藏激素及其胆汁淤积），加上报告与中毒信息中心的渠道，以及保留批号的建议——保健品的不良反应是警戒系统的盲点，而同一批产品还在药动学上相互作用（圣约翰草的酶诱导降低硫唑嘌呤与许多其他药）——[[pharmacology/metabolism-excretion]]、[[clinical-skills/patient-safety]]。处理的平衡：停可疑药并监测严重度（Hy定律启发式及其诚实的限度、国际标准化比值与胆红素上升时的转院标准、以及与移植中心对话的阈值）；若仍可能是自身免疫活动，与肝病科共同决定激素；硫唑嘌呤能否重启由损伤模式回答。信任的修复：不嘲笑自行用药，解释为何“天然”产品绕过了她的处方药所经历的检测，约定一份需与药师核对的购买清单，并报告可疑产品——让下一个读信号的人有数据可用——[[clinical-skills/communication]]、[[public-health/prevention-promotion]]。**
:::

## 通向何处

免疫机制见[[immunology/hypersensitivity]]与[[immunology/autoimmunity]]；代谢特异质见[[pharmacology/metabolism-excretion]]；遗传预测见[[pharmacology/patient-variation]]与[[genetics/genetic-testing]]；致畸见[[obstetrics-gynaecology/pregnancy-complications]]；致癌见[[pathology/cancer-biology]]。

::: history
**现代药物警戒是用两场灾难换来的：1937年的磺胺事件，以二甘醇作溶剂杀死百余人且多为儿童，催生1938年美国《食品、药品与化妆品法》以及“上市前先证明安全”的最初义务；以及1957至1961年的沙利度胺胚胎病，其识别归功于伦茨与麦克布赖德的病例系列警示，其监管遗产是1962年的凯弗-哈里斯修正案（要求疗效与报告）、欧洲的许可改革、致畸物警戒的诞生，以及异维A酸与丙戊酸至今仍运行的妊娠预防程序——[[obstetrics-gynaecology/pregnancy-complications]]、[[pharmacology/drug-development-prescribing]]。随后是系统监测时代：1960至70年代的波士顿协作药物监测项目把流行病学方法用于住院反应；1970年苯丙酸诺龙教训之后在卡迪夫开始的处方事件监测；以及1990至2000年代的基层病历数据库、链接数据与自身对照设计，使罕见事件信号的确认成为常规——[[epidemiology-ebm/observational-studies]]。**
然后是“医源性伤害”的清算：1970年代关于“白大衣医学”的论文、2000年美国医学研究所的《人非圣贤》，以及越来越多的归因审计发现住院不良事件中相当比例为药物相关、且半数可预防——这就是抗凝药、胰岛素与细胞毒药物成为“高警示三合一”的原因——[[clinical-skills/patient-safety]]。最后是机制与遗传的转向：1970至80年代的氟烷肝炎研究（糖蛋白加合物的免疫学）、“获得性药物代谢”假说的争论、1990年代末至2000年代的HLA-B*5701与阿巴卡韦（十年之内从病例系列走到强制验血）、重性皮肤反应登记（EuroSCAR的病例对照研究定义了药物特异的比值比与潜伏期），以及卡马西平、别嘌醇与硫嘌呤的药物遗传学筛查落地及其“祖源公平”之争——[[pharmacology/patient-variation]]、[[immunology/adaptive-responses]]、[[medical-ethics-law/justice-resources]]。**
:::

::: summary
- 多数严重不良反应是A型——可预期、随剂量、可用那些乏味却有效的防线预防：用药核对、警示、双人核查、监测，以及每次照护交接后的复查。
- B型反应日益可解释：生物活化为反应性中间物、人白细胞抗原限制的T细胞刺激、以及代谢与免疫基因的变异。
- 潜伏期具有诊断价值：免疫球蛋白E为分钟，药疹与DRESS为数日至数周，Stevens-Johnson与中毒性表皮坏死松解为一至三个月，迟发与自身免疫综合征为数月至数年。
- 重性皮肤反应要求尽早停肇事药、烧伤病房级别的照护、精确的记录与报告；过敏去标签就是一种抗菌药物管理。
- 因果是一个结构化论证（时间、去激发、再激发、排除替代解释），不是一种感觉；量表帮助沟通，但不能制造证据。
- 警戒系统需要不完美的报告：报告严重可疑反应的义务，正是下一代得以计算分母的原因。
:::

::: exercise 从清单中识别综合征 {level=1}
说出下列经典药源性疾病：肼苯达嗪与普鲁卡因胺；未合用维生素B6的异烟肼；用氯丙嗪数月后；夜间咳嗽、服药数周后来诊的血管紧张素转换酶抑制药；胺碘酮伴颈部包块与消瘦；呋塞米伴抽筋与QT延长。
::: solution
**综合征识别（[[#def-adr-classes]]）：肼苯达嗪与普鲁卡因胺的药物性狼疮（慢乙酰化与女性居多、抗组蛋白抗体、关节痛-浆膜炎-皮疹而不累及肾与中枢、数周至数月缓解）——[[musculoskeletal/connective-tissue-vasculitis]]；未补吡哆醇的异烟肼周围神经病（慢乙酰化、随剂量、手套袜套样感觉异常，以及可预防它的咨询）——[[infectious-diseases/tuberculosis]]、[[nervous-system/neuromuscular]]；数月数年的多巴胺阻断后迟发性运动障碍（口-舌-颊运动、与帕金森综合征的鉴别在于“抗胆碱药会加重”、囊泡单胺转运体2抑制药的选择、长期抗精神病药之前的风险沟通）——[[psychiatry/psychotic-disorders]]、[[nervous-system/movement-disorders]]；血管紧张素转换酶抑制药咳嗽（缓激肽与P物质机制、数周潜伏、干咳发痒、“停药并等待痊愈”的诊断学；以及可以很晚发作、由缓激肽而非组胺介导、需要气道处理的血管性水肿，以及伊卡替班与C1抑制剂超说明书证据的诚实读法）——[[pharmacology/autonomic-drugs]]；胺碘酮引起的甲状腺毒症（I型底物型对II型破坏型的区分决定硫脲对激素，而甲状腺功能减退更常见也更简单）——[[endocrine/thyroid]]；以及袢利尿剂的低钾低镁延长QT并有尖端扭转型风险、用药清单审计（大环内酯、抗精神病药、止吐药与唑类及美沙酮的QT清单），再加上低钾本身的贡献——[[cardiovascular/arrhythmias]]、[[renal/water-sodium]]。**

::: exercise 运用因果量表 {level=2}
用文字给出分级（明确、很可能、可能、不可能）并说明理由：(a) 新抗癫痫药第9天出疹，停药10天缓解，未再激发；(b) 脑转移患者抗生素第2天抽搐；(c) 服某草药4周后肝衰竭，病毒与自身免疫检查阴性，停药后好转；(d) 首次已知暴露于肌松药后过敏性休克死亡。
::: solution
**因果论证（[[#def-adr-causality]]）：抗癫痫药皮疹——按时间与去激发为“很可能到明确”，再激发是有意不做的（芳香族抗癫痫药之间的交叉反应图谱、拉莫三嗪的剂量规则教训，以及写清的安全替代清单）——[[nervous-system/epilepsy]]。抗生素抽搐——至多“可能”：头孢吡肟、碳青霉烯与喹诺酮的神经毒性确实存在，但转移灶提供了主导病因；诚实的回答是没有药物浓度与暴露细节就无法评估——这正是适应证混杂问题与因果量表存在的原因（“排除替代病因”这一步在承担全部工作量）——[[clinical-skills/clinical-reasoning]]。草药性肝炎——很可能：潜伏期合适、替代病因阴性、去激发明确，而成分的不确定性限制了确定程度（RUCAM逻辑、无论如何都要报告的义务、以及绝不提议再激发的规则）——[[gastrointestinal/liver-disease]]。“首次”暴露的肌松药过敏休克——虽称首次，却接近“明确”，因为环境中的季铵与取代基交叉致敏可解释阴性病史（过敏休克的流行病学、类胰蛋白酶与肥大细胞检查、分级激发与避免肇事药的记录、以及患者警示卡）——[[immunology/hypersensitivity]]、[[surgery/anaesthesia-pain]]。**

::: exercise 在多药门诊清单上做分诊 {level=2}
一位80岁患者在两次入院后服14种药，站立时头晕、跌倒过一次、时常出现新的意识混乱。清单：氨氯地平、多沙唑嗪、呋塞米、阿米替林、索利那新、佐匹克隆、非处方氯苯那敏、奥美拉唑、辛伐他汀、舍曲林、钙与维生素D、按需对乙酰氨基酚、硫酸亚铁、左甲状腺素。请做一次“不良反应优先”的复查。
::: solution
**不良反应优先的复查（[[#def-adr-classes]]、[[geriatrics-palliative/polypharmacy]]、[[nervous-system/dementia-neurodegeneration]]）：头晕与跌倒的解剖——体位性因素层层堆叠（多沙唑嗪、氨氯地平与呋塞米三件套：α阻滞加容量不足的算术；夜间的佐匹克隆与次日跌倒；阿米替林的α阻滞、抗胆碱与镇静；再加上一种抗组胺药），以卧立位血压作为客观检查（跌倒门诊与骨风险的算术使这成为一次关于死亡率而非舒适的对话）——[[geriatrics-palliative/falls]]、[[musculoskeletal/fractures]]。意识混乱的解剖——抗胆碱负荷（阿米替林加索利那新加氯苯那敏）、舍曲林的低钠、长期质子泵抑制导致的低镁与维生素B12缺乏、甲状腺功能、以及佐匹克隆耐受造成的“睡眠剥夺-谵妄”循环（认知测试要等谵妄清除后再做，以及痴呆与可逆成分的区分）——[[renal/potassium-calcium-phosphate]]、[[endocrine/hypothalamus-pituitary]]。**
减药顺序：先停非处方抗组胺药（毫无损失、负荷立即可减），再多沙唑嗪（增生与低血压的取舍：改评坦索罗辛或谈手术），佐匹克隆以认知行为治疗与睡眠措施配合缓慢减停，阿米替林减量或停用并重新解决“疼痛-睡眠-抑郁”的原始适应证，索利那新则在完成便秘-潴留-溢出检查与膀胱训练后重评。每种药设计一次“试用性停药”，并把患者的目标排序写清（跌倒与控尿孰重由她决定）；复查计划要重测卧立位血压与认知，并预先安排撤药症状的应对，而不是把它误当作疾病复发——[[clinical-skills/communication]]、[[psychiatry/anxiety-disorders]]。**

::: exercise 撰写“报告义务”政策 {level=3}
为科室起草一份可疑不良反应报告政策，涵盖法律义务、临床伦理、报告不足的问题、伤害后的患者沟通，以及记录反应时的数据保护问题。
::: solution
**报告政策草案（[[#def-adr-causality]]、[[medical-ethics-law/professionalism-regulation]]）：义务——报告严重可疑反应是一项职业义务，即使诊断仍不确定；要把它解释为群体层面的伤害预防（信号检测的算术需要不完美的分子，韦伯效应使上市初期窗口格外紧迫），在入职培训中讲授黄卡及对应渠道，并针对严重反应设立简单的科室内目标，而绝不为轻微报告设指标。**
伤害之后的伦理——发生即坦诚（道歉、解释、记录，以及“无过错补偿”制度；疫苗损害给付的类比正好说明信任如何被建立或被摧毁），记录患者自己的叙述并共同商定“以后再遇到怎么办”的计划：反应要写进病历与过敏栏，含严重度、日期与结局，而不是“青霉素-皮疹”了事——[[clinical-skills/patient-safety]]。数据层——反应记录属于个人数据，用于照护无需重新同意；质量问题（自由文本的“过敏”栏塞满非过敏，导致可避免的二线用药）要靠结构化条目与去标签服务解决；而病历用于研究与信号分析时，受研究伦理与保密规则约束，同一套规则也保护医务人员在学习型系统中的自白。再加上公平与全球诚实——多数报告系统位于高收入国家，因此热带病与传统医学的反应长期描述不足，而其使用者承受伤害；科室应当以对待自身审计同样的认真程度，为药物警戒能力建设出力——[[medical-ethics-law/confidentiality]]、[[public-health/global-health]]、[[immunology/vaccines-immunotherapy]]。**

## 练习

::: exercise 为反应分类 {level=1}
属于A、B、C、D型还是撤除：华法林在国际标准化比值6时出血；阿巴卡韦发热伴皮疹；吸入激素使皮肤变薄；沙利度胺的四肢畸形；苯二氮类停药后抽搐；甲氨蝶呤多年后肝硬化；氯霉素的再生障碍性贫血。
::: solution
**分类演练与理由（[[#def-adr-classes]]）：华法林高国际标准化比值出血——A型，位于陡峭的浓度-效应曲线上，需审计相互作用与给药（老年人出血危险因素的叠加：贫血、高血压、既往卒中）——[[blood/thrombosis-anticoagulation]]；阿巴卡韦发热伴皮疹——B型免疫性、HLA-B*5701限制，再激发的危险教育与强制用药前检测（“第一周发热加皮疹”的规则使预筛除消除了该反应）——[[infectious-diseases/hiv]]；吸入激素皮肤变薄——C型慢性、局部加全身吸收，取决于剂量、装置与储雾罐（高剂量哮喘的生长监测与骨及白内障方案）——[[respiratory/asthma-copd]]、[[paediatrics/growth-development]]；沙利度胺——D型，机制（数十年后才发现的小脑蛋白介导的血管生成与肢芽通路）与现代在麻风与骨髓瘤中的严格管控再启用；苯二氮类抽搐——撤除（E型以自身名字存活），缓慢减停的教义与γ-氨基丁酸A受体的适应生理——[[psychiatry/anxiety-disorders]]、[[physiology/synapses]]；甲氨蝶呤肝硬化——C型，累积剂量与酒精、肥胖、糖尿病的纤维化风险及监测方案的历史演变（III型前胶原氨基末端肽对肝活检对瞬时弹性成像）——[[gastrointestinal/liver-disease]]、[[musculoskeletal/inflammatory-arthritis]]；氯霉素再生障碍性贫血——经典特异质反应，与剂量无关，两机制的教训（可逆的、随剂量的线粒体抑制对罕见致死的再生障碍；血液监测与限制使用政策的理由）——[[blood/anaemia]]。**

某药上市六个月后，急性肾损伤的报告增加三倍。列出各种解释、可以区分它们的研究，以及从信号到行动的决定阶梯。
::: solution
**信号评估（[[#def-adr-causality]]）：解释——真实毒性（被更大范围使用揭露）、分诊与适应证效应（最重的患者最先用上新药）、韦伯效应与媒体放大、以及“前因倒置”偏倚（早期疾病表现被归给因它而起的药——袢利尿剂与膀胱癌的经典、激素替代与子宫内膜的偏倚案例）、还有诊断活动效应（新药使用者查了更多肌酐）——[[epidemiology-ebm/bias-confounding]]、[[renal/acute-kidney-injury]]。研究阶梯——先描述（谁、何时、剂量、合并用药、按Stevens-Johnson规则的潜伏期核查），再用对照正确的人群设计（新使用者、活性对照；短暂暴露用自身对照病例系列；突发结局用交叉设计；适应证混杂用限制、匹配与工具变量的巧思），最后是机制佐证（质量合格的病例系列、任何再激发数据、生物标志物或活检证据）——[[epidemiology-ebm/observational-studies]]。决定阶梯——信号到标签（警示、监测要求）、信号到限制（风险最小化：肾功能剂量与血药浓度规则）、信号到暂停（获益-风险重评，并记录医师与患者的声音）；以及在沟通中对不确定性诚实（报告不足对过度反应的平衡，不要因一个偏倚人工产物制造新的“药物恐惧”）——[[public-health/health-systems-economics]]、[[clinical-skills/communication]]。**

::: exercise 经营一间过敏门诊 {level=2}
三个转诊：“6岁时出过青霉素皮疹，之后再未接触”；“第二次接触对比剂后发生反应”；“牙科用药后出现非甾体抗炎药的荨麻疹与血管性水肿”。各做什么检查？能对患者说什么？
::: solution
**过敏门诊的决策（[[#def-scs]]、[[#def-adr-causality]]）：儿童期的青霉素标签——多数此类标签要么错误要么早已过期（病毒疹与“单核细胞增多症用阿莫西林”的经典），按病史分层风险（荨麻疹与过敏性休克的给药-时间-严重度关系对模糊皮疹），再做皮试与有监督的口服激发：可为绝大多数人去标签、恢复一线抗生素；同时教授头孢的交叉反应（侧链规则取代旧的比例恐慌），并说明她将来可能需要的手术、结核与心内膜炎方案获益——[[microbiology/antimicrobials]]、[[infectious-diseases/stewardship-outbreaks]]。对比剂的“过敏”——多数反应是肥大细胞直接激活与渗透压效应而非免疫球蛋白E；复发风险真实但可管理（换制剂、预处理方案、观察条件）；要拆掉贝类与碘的神话（“碘是一种元素”的论证），讲清在服β阻滞剂时过敏性休克会被加重，以及对比剂肾病与过敏的区分——[[clinical-skills/medical-imaging]]。非甾体抗炎药反应——区分由环氧合酶1抑制驱动的交叉反应性疾病（阿司匹林加重性呼吸系统与皮肤疾病，伴鼻息肉与慢性荨麻疹：所有强环氧合酶1抑制药都可疑，但分级剂量的对乙酰氨基酚与环氧合酶2选择性药通常可耐受，需激发试验确证）与单一药物的选择性反应（该类药物其余部分可用）；置入支架后需要抗血小板治疗时的环氧合酶2选择性再激发与脱敏路径——[[cardiovascular/coronary-artery-disease]]、[[immunology/hypersensitivity]]。**

::: exercise 设计“可预防伤害”运动 {level=3}
医院希望把可预防的不良用药事件减半。请用“什么有效、什么会适得其反、如何诚实地测量”的证据设计干预包。
::: solution
**伤害削减设计（[[#def-adr-causality]]、[[clinical-skills/patient-safety]]）：干预包——高警示药物标准化浓度、带硬性限值的智能泵及其“绕行”审计、真正仍能增加安全性的独立双人核查（儿童按体重给药与化疗）与已经沦为表演的场合；入院、出院与交接时的药师复查（把用药核对缺口计入）；抗凝、锂与甲氨蝶呤服务；减药门诊与STOPP-START式复查，以跌倒、骨折与谵妄为结局框架——[[geriatrics-palliative/polypharmacy]]、[[blood/thrombosis-anticoagulation]]。会适得其反的部分——警示疲劳（弹窗与实际处理率的巨大差距、需分层警示）、一刀切的禁令把治疗推向次优（克林霉素与艰难梭菌的取舍）、表演性的勾选核查、以及只停留在记录上的药物复查。测量——用“监测中的伤害”而不是病历回顾（触发工具与“全球触发并发症研究”的谱系）、可预防性的裁定小组、以处方文化指标作为过程指标；配一套学习型复盘系统，把事件主题回灌进规程、落实坦诚与道歉路径，并收集患者与照护者报告的伤害，因为系统会漏掉多数院外伤害。治理——董事会层面的伤害指标与“永不发生事件”登记、公平性的读数（伤害集中在衰弱、非英语与多病共存者），以及一句诚实的话：下降会先出现在未遂事件与过程指标上，入院数的改善会滞后——[[medical-ethics-law/professionalism-regulation]]、[[public-health/health-systems-economics]]、[[clinical-skills/records-handover]]。**
