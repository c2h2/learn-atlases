早餐时吞下的一片药，在其中一部分药物到达[[pharmacology/drug-receptor]]所述的受体之前，是毫无用处的。在途中，它必须溶解，穿过肠壁，经受肝脏的首过作用，进入血液循环，再离开血液到达其作用的组织。每一步都可能损失药物或延迟药物，而且每一步在不同药物之间、同一药物的不同制剂之间以及不同患者之间都不相同。

本章跟随一种药物从给药部位走到作用部位，内容包括药物如何跨膜、给药途径、生物利用度的含义与测定，以及药物在体内如何分布，包括表观分布容积和血浆蛋白结合。将药物再清除出体外的代谢与排泄是[[pharmacology/metabolism-excretion]]的主题。这些过程常合称为**ADME**：吸收（absorption）、分布（distribution）、代谢（metabolism）和排泄（excretion）。

## 跨膜转运 {#sec-membranes}

药物旅程中几乎每一步都涉及跨越细胞膜：胃肠上皮、毛细血管壁（在某些组织中）、血脑屏障、胎盘、肾小管。药物跨膜主要有三种方式。

- **经脂质双层的被动扩散。**这是大多数小分子药物的途径。其速率遵循菲克（Fick）定律：与浓度梯度、可利用的面积和药物的脂溶性成正比。小的、不带电荷的脂溶性分子容易通过；大分子或带电荷的分子几乎不能通过。
- **载体介导的转运。**溶质载体（SLC）转运体把药物转入细胞，ATP结合盒（ABC）转运体则把药物泵出细胞。药理学中最重要的外排泵是**P-糖蛋白**（P-gp），存在于肠壁、血脑屏障、肝脏和肾脏。P-gp把地高辛（digoxin）和洛哌丁胺（loperamide）等药物泵回细胞外，减少其吸收，并把它们挡在脑外。
- **经细胞间隙。**大多数毛细血管有间隙，小分子无论脂溶性如何都能自由通过。脑毛细血管没有这样的间隙，这就是血脑屏障能阻挡极性药物的原因。

大多数药物是**弱酸或弱碱**。在溶液中，它们部分以非解离型存在，这种形式脂溶、能够跨膜；部分以解离型存在，这种形式水溶、基本不能跨膜。两种形式之间的平衡取决于药物的pKa和所处液体的pH。

::: theorem 解离与亨德森–哈塞尔巴尔赫方程 {#thm-ionisation}
对于弱酸HA ⇌ H⁺ + A⁻和弱碱B + H⁺ ⇌ BH⁺，

$$
\text{酸：} \frac{[\text{解离型}]}{[\text{非解离型}]} = 10^{\,\mathrm{pH} - \mathrm{p}K_a}, \qquad \text{碱：} \frac{[\text{解离型}]}{[\text{非解离型}]} = 10^{\,\mathrm{p}K_a - \mathrm{pH}}.
$$ {#eq-hh}

当pH等于pKa时，药物一半解离。pH每偏离pKa一个单位，比值变化十倍。酸在酸性液体中主要为非解离型；碱在碱性液体中主要为非解离型。
:::

::: proof
对于酸，解离常数为$K_a = [\text{H}^+][\text{A}^-]/[\text{HA}]$。取负对数，$\mathrm{p}K_a = \mathrm{pH} - \log_{10}([\text{A}^-]/[\text{HA}])$，因此$[\text{A}^-]/[\text{HA}] = 10^{\mathrm{pH}-\mathrm{p}K_a}$；$\text{A}^-$为解离型。对于碱，$K_a$指质子化（解离）型：$K_a = [\text{H}^+][\text{B}]/[\text{BH}^+]$，整理得$[\text{BH}^+]/[\text{B}] = 10^{\mathrm{p}K_a - \mathrm{pH}}$。
:::

### 离子障

当两个pH不同的液体间隔被一层只有非解离型能通过的膜隔开时，平衡时两侧的非解离型浓度相等。此时，药物解离程度较高的一侧*总*浓度较高。这就是**离子障**（离子捕获）。弱酸在碱性一侧蓄积，弱碱在酸性一侧蓄积。

离子障有一些临床用途。在严重水杨酸盐中毒时，碱化尿液（静脉给予碳酸氢钠）可增加肾小管液中水杨酸盐的解离比例，使其重吸收减少、排泄增加。乳汁的酸性略强于血浆，因此弱碱在乳汁中往往比弱酸达到更高的浓度。胃内酸性很强，因此血液中的弱碱会被捕获在胃液中。

::: example 阿司匹林在哪里是非解离型？ {#ex-aspirin-ph}
阿司匹林（乙酰水杨酸）是弱酸，pKa约3.5。计算在pH 2的胃液和pH 7.4的血浆中解离型与非解离型药物之比，并评论其吸收部位。
::: solution
对酸应用[[#eq-hh]]：

- 胃，pH 2：比值$= 10^{2 - 3.5} = 10^{-1.5} \approx 0.03$。约97%为非解离型。
- 血浆，pH 7.4：比值$= 10^{7.4 - 3.5} = 10^{3.9} \approx 7900$。几乎全部解离。

在胃内，阿司匹林主要以脂溶型存在，因此部分在胃内吸收并进入胃黏膜细胞，在那里接近中性的pH使其解离并被捕获。这种局部捕获促成了阿司匹林对胃的刺激。即便如此，大部分阿司匹林是在小肠吸收的。尽管那里pH较高、任一时刻非解离型较少，但其表面积大数百倍，血流也更丰富，而且对少量非解离型的吸收不断推动平衡移动。仅凭pH分配并不能预测主要的吸收部位，起决定作用的是表面积。
:::
:::

## 给药途径 {#sec-routes}

给药途径决定药物起效多快、有多少进入循环，以及哪些组织接触到最高的浓度。

| 途径 | 主要优点 | 主要局限 | 举例 |
|---|---|---|---|
| 口服 | 方便、便宜、易接受 | 吸收不稳定；首过代谢；需要胃肠功能正常且能吞咽 | 大多数片剂和液体制剂 |
| 舌下或颊黏膜 | 起效快；避开首过代谢 | 仅适用于小分子、强效、脂溶性药物 | 硝酸甘油、丁丙诺啡 |
| 直肠 | 呕吐或不能吞咽时有用；部分避开首过 | 吸收不稳定；可接受性 | 地西泮、对乙酰氨基酚栓剂 |
| 静脉 | 完全而即时；可滴定剂量 | 需要血管通路；剂量无法收回；感染和输注差错 | 脓毒症时的抗生素、麻醉诱导 |
| 肌内 | 较快；可制成长效制剂 | 疼痛；吸收取决于肌肉血流 | 严重过敏反应时的肾上腺素、疫苗、长效抗精神病药 |
| 皮下 | 可自行注射；吸收缓慢平稳 | 容量小；外周灌注差时吸收差 | 胰岛素、低分子量肝素、许多生物制剂 |
| 吸入 | 肺内局部浓度高而全身剂量低 | 取决于装置使用技术 | 支气管扩张药、吸入性糖皮质激素、麻醉气体 |
| 经皮 | 数天内平稳释放 | 起效和消退慢；皮肤刺激 | 芬太尼、尼古丁、雌二醇、东莨菪碱贴剂 |
| 局部 | 局部作用，全身暴露少 | 仍可能全身吸收 | 皮肤、眼部和鼻腔制剂 |
| 鞘内或硬膜外 | 直接到达脊髓和神经根 | 需专科技术；用错药物危害严重 | 脊髓麻醉、某些化疗 |

其中两项值得说明。局部用药并不意味着没有全身作用：β受体阻滞药滴眼液可引起支气管痉挛和心动过缓，因为药物经鼻泪管流出，从鼻黏膜吸收而不经首过代谢（[[pharmacology/autonomic-drugs]]）。鞘内给药则是一次差错就可能造成灾难的途径；某些药物，如长春新碱（vincristine），鞘内注射是致命的，因此国家规定要求将其给药过程严格分开。

### 生物利用度

::: definition 生物利用度与首过代谢 {#def-absorption}
**生物利用度**（$F$）是给药剂量中以原形到达体循环的比例。按定义，静脉给药的$F = 1$。对于其他途径，通过比较该途径给药后与静脉给药后的血浆浓度–时间曲线下面积（AUC）来估计：

$$
F = \frac{AUC_{\text{口服}} \times \text{剂量}_{\text{静脉}}}{AUC_{\text{静脉}} \times \text{剂量}_{\text{口服}}}.
$$ {#eq-f}

**首过（系统前）代谢**是药物在到达体循环之前在肠壁和肝脏中的损失。从胃和小肠吸收的一切都先经门静脉通过肝脏。因此，肝摄取率高的药物即使被完全吸收，其口服生物利用度也可能很低。
:::

之所以使用AUC，是因为对于线性动力学的药物，无论曲线形状如何，AUC都与进入循环的药量成正比。首过代谢显著的药物包括硝酸甘油（glyceryl trinitrate），因此它采用舌下或经皮给药；还有吗啡和普萘洛尔（propranolol），它们的口服剂量大于静脉剂量。出于同样的原因，利多卡因（lidocaine）不口服用于全身作用。

首过代谢因人而异，也随肝病而改变。在肝硬化时，门静脉血经门体分流绕过肝脏，肝细胞功能下降，因此高摄取率药物的生物利用度可升高数倍。严重肝病患者口服此类药物时需格外谨慎（[[pharmacology/patient-variation]]）。

::: example 计算生物利用度 {#ex-bioavailability}
在一项药代动力学研究中，健康志愿者一次静脉给予某药10 mg，另一次口服40 mg。静脉给药后的AUC为400 µg·h/L，口服后为480 µg·h/L。口服生物利用度是多少？对于目前静脉给药5 mg且病情稳定的患者，等效的口服剂量是多少？
::: solution
由[[#eq-f]]：

$$
F = \frac{480 \times 10}{400 \times 40} = \frac{4800}{16000} = 0.30.
$$

口服剂量只有30%到达体循环。要输送与静脉5 mg相同的药量，口服剂量应为$5/0.30 \approx 17$ mg（示例值）。实际换算应采用处方集中该产品已获批的口服和静脉剂量，因为生物利用度在个体之间和制剂之间各不相同。
:::
:::

### 影响口服吸收的因素

有若干因素会改变药物吸收的量和速度。

- **剂型。**片剂必须崩解、药物必须溶解后才能被吸收。**缓释**制剂设计为缓慢释放药物，使浓度曲线平缓并减少给药次数。缓释制剂不应压碎；某些缓释产品的不同品牌之间不能互换，因此对于硝苯地平（nifedipine）缓释片和某些抗癫痫药等药物，处方者会指定品牌。
- **胃排空与胃肠动力。**吸收主要发生在小肠，因此胃排空减慢（使用阿片类药物后、糖尿病胃轻瘫、偏头痛发作时）会延迟起效。快速通过或腹泻可减少缓慢吸收药物的吸收量。
- **食物。**食物可延迟、减少或增加吸收。因此有些药物需空腹服用，有些则需随餐服用。
- **螯合与结合。**四环素类和喹诺酮类与钙、铁、镁和铝形成不溶性复合物。钙剂和铁剂会减少左甲状腺素（levothyroxine）的吸收。将服药时间错开数小时可避免这种相互作用。
- **外排与肠壁代谢。**肠上皮细胞中的P-gp和CYP3A4酶降低许多药物的生物利用度。葡萄柚汁（抑制CYP3A4）等抑制剂可使其升高。

**生物等效性**比较同一药物的两种产品，例如仿制药与原研药。英国、欧盟和美国的监管机构通常在两种产品的AUC之比及峰浓度之比的90%置信区间均落在80%至125%之间时，认可其生物等效。对大多数药物而言，这使仿制药可以互换。对于治疗指数窄的药物，可能需要更严格的界限或持续供应同一产品。

吸收的速度与程度同样重要。吸收较慢时，即使吸收总量（AUC）相同，峰浓度也较低、出现较晚。下图展示了这一点。

## 分布 {#sec-distribution}

药物一旦进入血液，就向各组织分布。分布有多快，取决于各组织的血流量以及药物穿过毛细血管和细胞膜的难易程度。分布有多广，取决于药物与血浆蛋白结合相对于与组织成分结合的强度，以及药物的脂溶性。

脑、心、肝、肾等灌注良好的器官在数分钟内达到平衡。肌肉需要更长时间，而血供差的脂肪最慢。这一顺序解释了**再分布**现象。单次静脉注射丙泊酚（propofol）或硫喷妥钠（thiopental）等脂溶性麻醉药后，药物在一个循环时间内到达脑，患者失去意识。在随后的几分钟内，药物继续进入肌肉、再进入脂肪，脑内浓度下降，患者苏醒，尽管大部分药物尚未被消除。

::: definition 表观分布容积 {#def-distribution}
**表观分布容积**（$V_d$）是在与血浆相同浓度下容纳体内全部药量所需的液体容积：

$$
V_d = \frac{\text{体内药量}}{\text{血浆浓度}}.
$$ {#eq-vd}

静脉推注后，$V_d$按剂量除以初始血浆浓度$C_0$（外推至零时刻）估算。$V_d$并不是真实的解剖腔隙。停留在血浆中的药物，其$V_d$接近血浆容量；浓集于组织中的药物，其$V_d$可远大于总体液量。
:::

对于70 kg的成人，血浆容量约3 L，细胞外液约14 L，总体液约42 L。这些参照点有助于解读药物的$V_d$：

| 大致$V_d$ | 解读 | 举例 |
|---|---|---|
| 约3–10 L | 基本局限于血浆；大分子、极性强或高度蛋白结合 | 肝素、华法林 |
| 约15–20 L | 细胞外液；能穿过毛细血管但不能穿过细胞膜的极性药物 | 庆大霉素及其他氨基糖苷类 |
| 约40 L | 总体液；小分子水溶性物质 | 乙醇、锂（大致） |
| 数百至数千升 | 广泛的组织结合或脂肪储存 | 地高辛、胺碘酮、三环类抗抑郁药 |

分布容积有三个实际用途。第一，它决定了快速达到目标浓度所需的**负荷剂量**，这一计算在[[pharmacology/dosing-principles]]中展开。第二，它与清除率一起决定半衰期（[[pharmacology/metabolism-excretion]]）：分布于大容积中的药物从血浆中清除得慢，因为在任一时刻其大部分都不在肝和肾所能触及的范围内。第三，它预测体外清除能否有助于中毒的治疗。血液透析只能清除血液中的药物。它对锂很有效，因为锂的$V_d$中等且不与蛋白结合；但对地高辛或三环类抗抑郁药几乎无用，因为体内几乎全部药物都在组织中。

::: example 脓毒症时增大的分布容积 {#ex-icu-vd}
一名体重70 kg的67岁女性因腹腔脓毒症入住重症监护病房。她已输注6 L静脉液体，全身广泛水肿。开始使用一种氨基糖苷类药物，示例剂量为7 mg/kg。在典型成人中，该药的$V_d$约为0.25 L/kg；在有毛细血管渗漏的危重患者中可能约为0.4 L/kg。估算两种情况下的峰浓度，并说明其意义。
::: solution
剂量为$7 \times 70 = 490$ mg。

- 典型$V_d$：$0.25 \times 70 = 17.5$ L，因此$C_{\text{峰}} \approx 490/17.5 = 28$ mg/L。
- 增大的$V_d$：$0.4 \times 70 = 28$ L，因此$C_{\text{峰}} \approx 490/28 = 17.5$ mg/L。

氨基糖苷类的杀菌作用呈浓度依赖性，因此峰浓度相对于病原体最低抑菌浓度的高低很重要。由于该药为极性药物、分布于细胞外液，组织间隙中多出的液体会稀释它，同样的mg/kg剂量所得峰浓度低了近40%。这就是为什么在危重症中，即使肾功能差，亲水性抗生素的负荷剂量通常也不减少：负荷剂量取决于容积，而肾功能决定此后的维持剂量。实际剂量与监测遵循地方抗菌药物指南和血药浓度。
:::
:::

### 血浆蛋白结合

许多药物与血浆蛋白可逆结合。**白蛋白**主要结合酸性和中性药物，如华法林、苯妥英和许多非甾体抗炎药。**α₁-酸性糖蛋白**是一种急性期蛋白，结合许多碱性药物，如利多卡因和某些抗抑郁药。结合型药物不能穿过毛细血管壁，不能作用于受体，不能被肾小球滤过，（对大多数药物而言）也不能被代谢。只有**非结合（游离）部分**具有活性。

::: warning 置换性相互作用通常被高估
常有人说，把华法林从白蛋白上置换下来的药物会引起出血。对大多数药物而言，这在实践中并不成立。加用置换药时，游离分数上升，但多出的游离药物也会分布到组织中，并被肝或肾清除。在几个半衰期之内，决定效应的*游离*浓度回到大致原先的水平；只有*总*浓度最终变低。归咎于置换的相互作用几乎总是同时涉及代谢抑制（例如华法林与某些抑制CYP2C9的抗真菌药）。置换主要在以下情况下才重要：加用置换药后的短暂时期内，置换药大剂量静脉给予时，或药物摄取率很高且治疗指数很窄时。
:::

蛋白结合更重要的后果在于**解读血药浓度**。大多数实验室检测测定的是总（结合加游离）浓度。如果白蛋白低，如营养不良、肾病综合征、肝病、妊娠晚期或危重症时，高结合率药物的游离分数上升。一个看起来偏低或“在范围内”的苯妥英总浓度，可能对应着足够甚至中毒的游离浓度。此时为使总浓度上升而加量就会导致中毒。条件允许时应测定游离浓度；否则使用校正方法，并结合临床体征加以解读（[[pharmacology/dosing-principles]]）。

### 屏障：脑、胎盘与乳汁

**血脑屏障**由以紧密连接相连的脑毛细血管内皮细胞构成，其膜上有P-gp和其他外排泵。全身麻醉药、苯二氮䓬类和许多阿片类等脂溶性药物容易进入脑内。极性药物和P-gp底物则被挡在外面。洛哌丁胺是一种作用于肠道的阿片类药物，常规剂量下几乎没有中枢作用，因为P-gp把它泵出脑外。有些药物被特意设计为不进入脑：西替利嗪（cetirizine）等第二代抗组胺药比老一代药物镇静作用轻，部分原因就是它们进入脑内很少。炎症会使屏障松弛，因此通常难以穿透的青霉素类，在细菌性脑膜炎时大剂量给药可在脑脊液中达到有效浓度。

**胎盘**允许大多数脂溶性药物通过，因此最稳妥的假设是：母体循环中的药物都会到达胎儿，除非它分子很大或极性很强。华法林能通过胎盘并可能损害胎儿；肝素类是大分子极性物质，不能通过。分娩前不久给予的药物，如阿片类，可影响新生儿。妊娠期用药见[[pharmacology/patient-variation]]。

大多数药物以少量进入**乳汁**。婴儿所接受的剂量取决于乳汁中的浓度、乳汁量以及婴儿自身清除药物的能力，而早产儿和新生儿的这种能力有限。英国哺乳期用药咨询服务（UK Drugs in Lactation Advisory Service）等专业资源提供针对具体药物的建议。

::: example 乳汁中的弱碱 {#ex-milk}
某弱碱pKa为8.4，不与蛋白结合。血浆pH为7.4，乳汁pH为7.0。假定只有非解离型能通过且已达平衡，乳汁与血浆中药物总浓度之比是多少？
::: solution
平衡时两侧非解离型浓度$U$相同。每一侧的总浓度为$U(1 + \text{解离型}/\text{非解离型})$，比值由[[#eq-hh]]中碱的公式求得。

- 血浆：$10^{8.4 - 7.4} = 10$，因此总浓度$= 11U$。
- 乳汁：$10^{8.4 - 7.0} = 10^{1.4} \approx 25.1$，因此总浓度$\approx 26.1U$。

乳汁/血浆比$\approx 26.1/11 \approx 2.4$。由于离子障，弱碱在酸性较强的乳汁中浓集。弱酸的情况相反，比值小于1。实际的乳汁/血浆比还取决于蛋白结合、脂溶性和主动转运，因此在有实测值时应使用实测值。
:::
:::

::: quiz
一名30岁男性过量服用了一种药物，该药在70 kg成人中的分布容积约为500 L，蛋白结合率为95%。一位同事建议用血液透析清除它。哪种说法正确？
- [ ] 透析会有效，因为该药分子足够小，能通过透析膜
- [x] 透析只能清除体内总负荷的很少一部分，因为几乎全部药物在组织中，而血浆中的药物大部分与蛋白结合
- [ ] 透析会有效，因为分布容积大意味着药物主要在血浆中
- [ ] 蛋白结合不影响透析，因为只有游离药物有毒性
::: solution
透析只能清除流经透析器的血液中的非结合药物。500 L的分布容积远大于总体液量，意味着血浆中只含总量的极小部分；而在95%的蛋白结合率下，其中只有二十分之一是可被透析的游离药物。能被透析很好清除的药物，如锂，分布容积小且蛋白结合率低。
:::
:::

::: example 不再起效的甲状腺素剂量 {#ex-levothyroxine}
一名72岁南亚裔女性因甲状腺功能减退症服用左甲状腺素多年，甲状腺功能一直稳定。一次脆性骨折后，她开始服用碳酸钙加维生素D，并因缺铁服用硫酸亚铁，所有药物都与左甲状腺素一起在早餐时服用。三个月后她的TSH为14 mU/L（此前为2）。最可能的解释是什么？应依据哪些原则处理？
::: solution
最可能的原因是左甲状腺素吸收减少。钙盐和铁盐在肠道内与左甲状腺素结合，形成不能被吸收的复合物，生物利用度下降，她出现生化性甲减。

第一步是错开服药时间，而不是增加左甲状腺素剂量。左甲状腺素最好空腹服用，通常建议与钙剂和铁剂间隔至少四小时。在达到新的稳态所需的时间后复查甲状腺功能（左甲状腺素的半衰期约一周，因此约需六周）。如果改为加量，那么每当其他药片的服用时间改变时，她都会出现治疗过度。TSH升高的其他原因，如依从性、更换品牌或乳糜泻，也需要考虑（[[endocrine/thyroid]]）。
:::
:::

::: history
药物吸收与分布的测定源于二十世纪的分析化学。1937年，瑞典生理学家特奥雷尔（Torsten Teorell）发表了药物在房室之间分布的数学模型，这被视为药代动力学的开端，尽管这一领域的名称是后来才有的。德国的多斯特（Friedrich Hartmut Dost）于1953年提出了*Pharmakokinetik*（药代动力学）一词。pH分配假说，即非解离型药物跨膜、因而pH支配吸收与捕获，是二十世纪五十年代由美国国立卫生研究院的布罗迪（Bernard Brodie）、尚克（Lewis Schanker）及其同事提出的，他们在动物中测定了酸和碱在胃和肠道的吸收。生物利用度的重要性在二十世纪六十年代末和七十年代初变得显而易见：当时苯妥英和地高辛片剂中非活性成分的改变使吸收发生了足以引起中毒或疗效丧失的变化，监管机构由此开始要求仿制药提供生物等效性证据。
:::

::: summary
- 大多数药物以其非解离的脂溶性形式经被动扩散跨膜；P-糖蛋白等载体增加了摄取与外排。
- 解离遵循亨德森–哈塞尔巴尔赫关系；膜两侧的pH差造成离子障，这一原理用于水杨酸盐中毒，并解释了药物在乳汁和胃液中的蓄积。
- 给药途径决定起效速度、生物利用度以及哪些组织接触最多的药物。局部用药仍可能产生全身作用。
- 生物利用度$F$是到达体循环的比例，用剂量校正后的AUC测定。肠壁和肝脏的首过代谢降低口服$F$。
- 表观分布容积把体内药量与血浆浓度联系起来。它决定负荷剂量，影响半衰期，并能预测透析能否清除药物。
- 只有非结合药物具有活性。置换性相互作用很少有临床意义，但低白蛋白会改变总药物浓度的含义。
- 血脑屏障阻挡极性药物和P-gp底物；大多数脂溶性药物能通过胎盘并进入乳汁。
:::

::: exercise 由推注求分布容积 {level=1 check="25"}
静脉推注某药500 mg，外推得到的初始血浆浓度为20 mg/L。表观分布容积是多少升？
::: solution
由[[#eq-vd]]，$V_d = 500/20 = 25$ L。对成人而言，这大于细胞外液而小于总体液。
:::

::: exercise 弱碱的非解离比例 {level=1 check="1"}
某弱碱的pKa为9.4。在pH 7.4的血浆中，非解离型药物占多大百分比？答案取最接近的整数。
::: hint
对于碱，解离型/非解离型$= 10^{\mathrm{p}K_a - \mathrm{pH}}$。非解离型百分比为$100/(1 + \text{比值})$。
:::
::: solution
比值$= 10^{9.4 - 7.4} = 100$。非解离型百分比$= 100/101 \approx 0.99\%$，取整为**1%**。许多碱性药物，如三环类抗抑郁药和局部麻醉药，在血浆中大部分是解离的；少量的非解离部分足以使它们跨膜，因为它会不断得到补充。
:::
:::

::: exercise 选择给药途径 {level=1}
针对下列每种情况，建议一种合适的给药途径并给出一个理由：(a) 严重呕吐、需要止吐药的人；(b) 在家中癫痫持续发作、没有静脉通路的儿童；(c) 哮喘的长期治疗，希望尽量减少糖皮质激素的全身暴露；(d) 脓毒性休克、需要立即使用抗生素的人。
::: solution
(a) 非口服途径，如肌内、静脉、皮下或（对某些药物而言）颊黏膜或直肠给药，因为口服的药物会在吸收前被吐出。(b) 颊黏膜（或鼻内）咪达唑仑（midazolam），或直肠地西泮（diazepam），因为照护者无需静脉通路即可给药，且数分钟内起效；选择依据该儿童的照护计划。(c) 吸入，因为药物直接送达气道，全身剂量远低于口服治疗。(d) 静脉，因为吸收完全而即时，不依赖于休克时可能很差的胃肠或肌肉灌注。
:::
:::

::: exercise 由两项研究求生物利用度 {level=2 check="0.4"}
某药口服100 mg后AUC为30 mg·h/L，静脉给予20 mg后AUC为15 mg·h/L。以小数形式计算口服生物利用度。
::: hint
比较两种途径每毫克剂量对应的AUC。
:::
::: solution
应用[[#eq-f]]，$F = (30 \times 20)/(15 \times 100) = 600/1500 = 0.4$。口服剂量只有40%以原形到达体循环，原因是吸收不完全、首过代谢或二者兼有。
:::
:::

::: exercise 乳汁与血浆 {level=2 check="2.4"}
用[[#ex-milk]]的方法，计算pKa为8.4的弱碱在乳汁与血浆中总浓度之比，假定血浆pH 7.4、乳汁pH 7.0、无蛋白结合且只有非解离型能通过。答案保留一位小数。然后不经计算说明，pKa为4.4的弱酸的这一比值是大于1还是小于1。
::: solution
血浆总浓度$= U(1 + 10^{1.0}) = 11U$；乳汁总浓度$= U(1 + 10^{1.4}) \approx 26.12U$。比值$\approx 2.37$，保留一位小数为**2.4**。

对于弱酸，在碱性较强的血浆中解离程度更高，因此被捕获在血浆中，乳汁/血浆比小于1。
:::
:::

::: exercise 透析与否？ {level=2}
参照分布容积和蛋白结合，解释为什么严重锂中毒时使用血液透析，而地高辛中毒时不用。对于严重地高辛中毒还有什么其他治疗？它为什么有效？
::: solution
锂是一种不与蛋白结合的小离子，大致分布于总体液中（分布容积小于1 L/kg）。在任一时刻，体内负荷有相当大一部分位于血液和细胞外液中，因此透析能清除可观的量；而且锂不被代谢，除此之外肾脏是它唯一的排出途径。

地高辛的分布容积很大，达每千克数升，因为它与肌肉和其他组织中的Na⁺/K⁺-ATP酶广泛结合。血浆只含总量的一小部分，因此透析清除的量极少。

对于严重地高辛中毒，使用地高辛特异性抗体片段（Fab）。它们以极高的亲和力结合血浆中的游离地高辛，降低游离浓度；地高辛随后顺浓度梯度从组织结合位点转移到血浆中，又被依次结合。复合物经肾脏排出。适应证和剂量遵循毒理学建议（[[emergency-critical-care/poisoning]]）。
:::
:::

::: exercise 水肿与首剂 {level=3 check="17.5"}
接[[#ex-icu-vd]]，一名70 kg的患者接受490 mg氨基糖苷类药物。若其分布容积已升至0.4 L/kg，假定瞬时分布，预期峰浓度（mg/L）是多少？给出准确值。然后解释为什么亲水性抗生素的负荷剂量通常依据体重和容积而不是肾功能确定，以及随后要进行哪些监测。
::: solution
$V_d = 0.4 \times 70 = 28$ L，因此$C_{\text{峰}} = 490/28 = 17.5$ mg/L。

首剂所达到的浓度只取决于剂量和药物分布的容积（见[[#eq-vd]]）。肾功能决定随后药物被清除的速度，从而决定给药间隔和以后的剂量。如果因为肌酐升高而减少首剂，就会在最需要有效杀菌的时候得到偏低的峰浓度。首剂之后，依据血药浓度（按地方方案，常为结合列线图使用的定时浓度或谷浓度）和肾功能来调整给药间隔，并决定是否继续治疗。
:::
:::

::: exercise 误导性的苯妥英浓度 {level=3}
一名79岁非洲黑人裔男性患有癫痫和慢性肝病，白蛋白为22 g/L（参考范围约35–50 g/L），因步态不稳和眼球震颤入院。其血浆苯妥英总浓度报告为9 mg/L，略低于常引用的总浓度范围10–20 mg/L。一位低年资医生建议加量。请用游离分数的概念解释为什么这样做不明智，并概述应如何解读该浓度。
::: hint
苯妥英通常约90%与白蛋白结合。
:::
::: solution
苯妥英通常约90%与白蛋白结合，因此10–20 mg/L的总浓度对应约1–2 mg/L的游离（活性）浓度。白蛋白为22 g/L，且肝病时结合可能进一步减少，游离分数可能是正常的两倍或更高。此时9 mg/L的总浓度可能对应约2 mg/L或更高的游离浓度，处于或高于通常游离浓度范围的上限。

他的步态不稳和眼球震颤是苯妥英中毒的典型体征，与总浓度看似偏低而游离浓度很高的情况相符。加量会使他病情加重，而且苯妥英的代谢可饱和，意味着浓度的上升可能不成比例（[[pharmacology/metabolism-excretion]]）。

应结合临床表现解读该浓度。有条件时，实测的游离苯妥英浓度是最好的依据；否则谨慎使用白蛋白校正后的估计值，见[[pharmacology/dosing-principles]]。还需考虑引起他症状的其他原因，如饮酒、其他镇静药物、后循环卒中或肝性脑病。
:::
:::
