药动学是一个分子在体内的旅程：**吸收决定有多少、多快进入循环；分布决定哪些组织被浸润、哪些被挡住；两者都由理化性质支配——脂溶性、解离、蛋白结合、分子量——再加上身体自身的地理：血流、膜与转运体。**把分布容积与清除率装进脑子，半衰期、负荷剂量、途径选择，以及肥胖、水肿、妊娠、肾病与肝病中的药物行为就不再是需要死记的规则。

## 进入体内

::: definition 吸收与生物利用度 {#def-absorption}
**途径及其物理：口服涉及溶出、胃pH、溶解度与通透性，以及首过效应——即生物药剂学分类的逻辑：快速溶出且通透的药物，对照溶解度受限者（食物与脂肪会影响后者），以及两头皆差的一类；pH分配说要保持比例——离子截留确实存在，但表面积、脂溶性与转运体才是主角。胃排空与动力决定一切：腹泻、短肠与梗阻时缓释制剂失败；GLP-1激动剂延缓通过而影响所有人的吸收；经胃管碾碎缓释片是一份灾难清单——[[gastrointestinal/digestion-absorption]]、[[gastrointestinal/clinical-nutrition]]。**
两处肝前损失：肠壁代谢与外排（小肠细胞顶膜的CYP3A4与P-糖蛋白；西柚呋喃香豆素的教训是“酶失活比果汁更久”；环孢素与他索洛尔、环孢素与地高素的相互作用遗产；以及利福平的酶诱导要数日才消退）——[[pharmacology/metabolism-excretion]]；以及肝首过（摄取比值的算术：硝酸酯、普萘洛尔、利多卡因与吗啡这类受血流限制的高摄取药，对照受能力与结合限制的低摄取药；F=1−摄取比值的教学；以及肝硬化分流时生物利用度暴增——口服对静脉的效价比值在肝血流下降时会变得危险）——[[gastrointestinal/liver-disease]]、[[cardiovascular/vascular-disease]]。**

**舌下与颊黏膜为硝酸酯与部分类固醇绕过首过；直肠部分绕过但可靠性参差；透皮的通量由通透性、面积与浓度决定，并附有加热与移除后储库的告诫；肌内与皮下储库由血流与溶解度支配，需注射部位轮换，而抗体剂型改皮下提高了生物利用度；吸入给药面积大且无首过，其全身类固醇效应正是吸收的证明；静脉为一百百分之，并有推注对输注的算术——[[respiratory/asthma-copd]]、[[surgery/anaesthesia-pain]]、[[endocrine/diabetes]]。**
:::

## 药物去向

::: definition 分布与房室 {#def-distribution}
**分布容积是记账而非解剖：Vd=体内药量/血浆浓度，所以巨大的Vd意味着组织扣留——脂储存、两性亲阳离子的溶酶体截留（胺碘酮、选择性血清素再摄取抑制药、氯喹）、或转运体摄取（地高辛按肌肉钠钾泵结合而显出庞大的表观Vd）；华法林的极小Vd把它留在血浆。两房室的形状：先分布支再消除支；硫喷妥醒靠再分布而非代谢；芬太尼与咪达唑仑长时间输注后有语境敏感半时累积，而瑞芬太尼的酯水解不依赖器官——[[surgery/anaesthesia-pain]]。**

**游离药物才有活性，但有“限制性清除”的例外；“置换相互作用”的恐慌要诚实地读：非甾体抗炎药与华法林的出血更多是代谢与抗血小板机制而非置换；真正对结合敏感的情形是脓毒症、妊娠或肝硬化时白蛋白下降中的苯妥英游离浓度。蛋白结合是储库而非优势——[[pharmacology/dosing-principles]]、[[renal/chronic-kidney-disease]]。**
**血脑屏障：紧密连接、P-糖蛋白与BCRP外排、载体摄取，以及炎症脑膜中通透性增加；旧的“脂溶性且非解离”规则之上叠加了转运体的改写（脂溶性β阻滞剂的中枢效应；洛哌丁胺在治疗剂量被挡于脑外，只有滥用剂量压垮P-糖蛋白才进入）——[[nervous-system/neuroinflammation]]、[[psychiatry/substance-use]]。胎盘不是屏障：按浓度平价的交换，加上转运体、胎儿代谢与各孕期特定的致畸窗口；乳汁转运由脂质、pH与解离决定（乳汁略酸而截留碱基如苯丙胺），婴儿剂量按母体血浆浓度的分数估计——[[obstetrics-gynaecology/pregnancy-complications]]、[[obstetrics-gynaecology/labour-birth]]。体成分的重塑：脂肪是脂溶性药物的储库（肥胖中琥珀胆碱呼吸暂停延长），以及给药体重的争论（按药物类别用实际、理想或调整体重；抗生素、麻醉与抗凝的体重表；以及减重手术重新布线了吸收）；第三间隙——毛细血管渗漏、烧伤、脓毒症——抬高亲水药物的Vd及其负荷剂量——[[geriatrics-palliative/ageing-frailty]]、[[emergency-critical-care/shock-fluids]]、[[gastrointestinal/liver-disease]]。**
:::

::: definition 排泄界面与患者重塑 {#def-excretion}
**开处方者需要的肾消除解剖：肾小球滤过由分子大小、形状与电荷的自由分数驱动；肾小管有主动分泌（OAT、OCT与P-糖蛋白）与脂溶性非解离药物的重吸收（依赖尿流——强制利尿的遗产与水杨酸碱化技巧）；肾小管分泌在治疗范围内即可饱和（丙磺舒与青霉素的历史；考比司他与多替拉韦抑制OCT2造成肌酐上升而无肾小球滤过率损伤，这一解读要点到）——[[renal/filtration]]、[[renal/tubular-function]]。清除率分层下降：按肾小球滤过率的分档对实测肌酐清除率对胱抑素C组合；肌肉量与肌酐生成是混杂（少肌、截肢、瘫痪、素食），以及肥胖的肌酐悖论；可透析性的经验法则（分子量、蛋白结合、Vd、水溶性）与透析后补充给药（多西环素不被清除；左氧氟沙星与头孢吡肟不减量会神经毒性；透析日与非透析日的抗生素时机）——[[renal/chronic-kidney-disease]]、[[emergency-critical-care/critical-care]]。**
肝消除即血流与能力：处方者要会读“良好搅拌模型”——内在清除率、摄取与蛋白结合共同决定肝清除；肝硬化、胆汁淤积与炎症攻击方程的不同部分；酶诱导、抑制与分流各有临床签名（利平霉素降低激素避孕、直接口服抗凝药与免疫抑制药浓度，以及按药物不可逆的胆汁淤积性黄疸；胆汁淤积对肝细胞的预测价值决定哪些药要避；胆道排泄药物与肠肝循环——炔雌醇再循环的哺乳与避孕教训）——[[gastrointestinal/liver-disease]]、[[pharmacology/metabolism-excretion]]。**

**妊娠逐渐提高肾清除、分布容积与肝活性，同时白蛋白下降：拉莫三嗪因雌激素诱导的葡萄糖醛酸化而在孕晚期浓度降一半，剂量要升、产后两三周又跌回——一个“治疗中被拖着走再崩塌”的故事，值得完整讲一次。老年：肾、肝、脑改变而血肌酐正常，掩蔽了肾损失，且效应受体敏感性增加（苯二氮、阿片、抗胆碱药“低起点、慢加量”的信条；少肌掩蔽了清除率下降）——[[geriatrics-palliative/polypharmacy]]。儿科：成熟曲线与异速缩放；葡萄糖醛酸化不成熟与氯霉素灰婴教训；新生儿对年长儿对青少年的剂量逻辑；以及把治疗药物监测当作生长期的医学——[[paediatrics/newborn]]、[[paediatrics/growth-development]]、[[obstetrics-gynaecology/pregnancy-complications]]。**
:::

::: example 重症监护的负荷剂量问题 {#ex-icu-vd}
一名80公斤脓毒症患者有毛细血管渗漏、用升压药，需要一种负荷要求大且经肾消除的抗生素；病房的方案剂量正被“因为肾”而减。
::: solution
**休克中的分布容积（[[#def-distribution]]、[[emergency-critical-care/shock-fluids]]、[[pharmacology/dosing-principles]]）：正确的物理——负荷剂量取决于分布容积而非清除率（负荷=目标浓度×Vd，而维持跟着清除率）；脓毒症在提高亲水药物Vd（β内酰胺、糖肽、氨基糖苷、左乙拉西坦）的同时因低灌注降低清除率，把两个调整相互抵消是经典错误——[[renal/acute-kidney-injury]]。方案审计——首剂要给足，因为剂量不足会致命；只有维持剂量按肾功能调整；以及β内酰胺的延长间隔对持续输注的药效学（高于最低抑菌浓度的时间、曲线下面积对比最低抑菌浓度、峰值对比最低抑菌浓度这几类，使调整方式与药物匹配；糖肽与氨基糖苷的监测文化，以及转向按曲线下面积指导的万古霉素）——[[microbiology/antimicrobials]]、[[clinical-skills/laboratory-tests]]。持续输注的背景——丙泊酚、芬太尼与咪达唑仑一夜累积（每日中断的唤醒试验遗产；为何瑞芬太尼与顺式阿曲库铵是不依赖器官的英雄，以及各自的组胺与成本问题）；以及吗啡的M6G在肾衰时累积、丁丙诺啡不适合做输注——[[surgery/anaesthesia-pain]]、[[renal/chronic-kidney-disease]]。系统答案——在有条件处设治疗药物监测与药动学咨询服务、药师查房、把体重与液体平衡记为剂量变量、以及随患者恢复而降阶梯（毛细血管渗漏关闭时水肿回移、Vd下降而肾小管损伤仍在——这就是第4天的剂量必须重算而非回忆的理由）——[[clinical-skills/patient-safety]]、[[pharmacology/patient-variation]]。**
:::

::: example 华法林与唑类的相互作用 {#ex-fluconazole}
一名74岁服用稳定华法林的女性（国际标准化比值2.4）因阴道念珠菌病服氟康唑；九天后国际标准化比值为8并流鼻血；她同时一周内每日服对乙酰氨基酚3克。
::: solution
**三种机制、一个比值（[[#def-absorption]]、[[pharmacology/metabolism-excretion]]、[[pharmacology/adverse-reactions]]）：唑类与华法林的接口——CYP2C9抑制减少S-华法林清除（立体化学课：S-华法林是强效的CYP2C9底物）；氟康唑半衰期长，效应比疗程更久；其CYP3A4抑制在同一次就诊中也会抬高苯妥英与卡马西平——[[pharmacology/patient-variation]]。对乙酰氨基酚的贡献——大剂量时占用CYP通路并生成一种维生素K拮抗代谢物；每日3至4克造成比值漂移的证据要诚实地读——它并非抗凝患者被宣传的那份安心；以及酒精、禁食、营养、维生素K摄入、肠炎、抗生素灭菌后的肠道菌群与治疗性维生素K伙伴对同一比值的效应（甘蓝与绿叶菜的饮食教育；门诊要问便秘对腹泻）——[[gastrointestinal/bowel-disease]]、[[gastrointestinal/clinical-nutrition]]。处置演练——按情形定维生素K的剂量与途径，严重出血用凝血酶原复合物并记录重启策略；加上“绝不因一次感染单停华法林”的规则、出院时的相互作用核查、以及合适时改用直接口服抗凝药（先排除瓣膜、肾与抗磷脂情形）——[[blood/thrombosis-anticoagulation]]、[[renal/chronic-kidney-disease]]。预防系统——与抗凝门诊的抗菌药物沟通（当日电话而不是一张说明书）；起始相互作用药物后48至72小时复查比值；警示卡与程序；以及每次交接时的用药核对——[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]。**
:::

::: example 头孢吡肟的困惑 {#ex-cefepime}
一名78岁肺炎患者用头孢吡肟，肌酐180；第4天出现肌阵挛与意识水平下降；家属问这抗生素是否安全；脑电图示广泛周期性放电。
::: solution
**作为暴露药动学的神经毒性（[[#def-excretion]]、[[#def-distribution]]、[[renal/chronic-kidney-disease]]）：机制——高脑脊液浓度时β内酰胺拮抗GABA-A；头孢吡肟有此偏好，青霉素癫痫是历史遗产；炎症脑膜提高通透，肾小管处理增添变数；而“按肾小球滤过率分档给药”的失效——78岁、肌酐180可能意味着滤过率近25，并有脓毒症的急性加重，而肌酐上升时从未重算剂量。诊断与处置——停药或大幅减量并在有条件时测浓度；鉴别包括影像阴性的代谢性原因与非惊厥性癫痫持续状态；特征性脑电图图形、可用的头孢吡肟浓度、难治者用肾替代治疗；48至96小时内缓解即是诊断确认——[[nervous-system/epilepsy]]、[[clinical-skills/clinical-reasoning]]。给药纪律的修复——电子处方带当前体重与计算的滤过率做肾剂量警示，肌酐不稳时每日重算；药师方案在第3天而不只是第1天复查剂量；抗菌药物管理查房识别神经毒性签名；以及记住抗生素的药效学分类——高于最低抑菌浓度时间类药物需要思考给药频次而非只看日总量（延长输注与肾调整在“日总量才是关键”时如何互动）——[[microbiology/antimicrobials]]、[[clinical-skills/patient-safety]]。沟通——向家属解释“这是蓄积不是过敏”；标签管理让未来的头孢决策安全而不是一律禁用；如果重算剂量的延误本可避免，则须道歉——[[clinical-skills/communication]]、[[pharmacology/adverse-reactions]]。**
:::

::: example 拉莫三嗪的妊娠计划 {#ex-lamotrigine}
一名29岁癫痫患者用拉莫三嗪225毫克控制良好，计划怀孕；她读到抗癫痫药会伤害胎儿，并以为自己的剂量“必须降下来”。
::: solution
**把妊娠药动学做对（[[#def-excretion]]、[[obstetrics-gynaecology/pregnancy-antenatal]]）：生理弧线——雌激素诱导的UGT1A4葡萄糖醛酸化加上肾清除与分布容积增加，使拉莫三嗪浓度到孕晚期可降近一半；剂量通常需在整个孕期随每月浓度上调；剂量不足导致发作的风险超过对拉莫三嗪的致畸焦虑；产后两到三周回到孕前剂量，哺乳时监测婴儿镇静与皮疹；以及叶酸与神经管的时间窗、与丙戊酸的诚实比较（剂量依赖的风险层级、预防 计划 规则与登记数据）——[[nervous-system/epilepsy]]。避孕回路——含炔雌醇的避孕药诱导葡萄糖醛酸化使拉莫三嗪降30%至50%；酶诱导的抗癫痫药降低避孕效果；以及含铜宫内节育器与左炔诺孕酮的分级选项——[[obstetrics-gynaecology/contraception-fertility]]。监测与边界——妊娠期治疗药物监测作为常规，并理解孕期白蛋白变化下游离对总浓度的解读；睡眠剥夺与依从支持与药动学相邻；孕前由神经科与产科多学科讨论，并预先谈分娩与喂养——[[clinical-skills/records-handover]]。风险沟通——发作控制对药物暴露的绝对风险数字（引用英国与澳大利亚登记数据时用区间而非点值）；解释“因恐惧而停药”的危险；并记录共同决定；以及未计划妊娠使孕前窗口捕获率偏低的问题——[[clinical-skills/communication]]、[[paediatrics/congenital-genetic]]。**

**药动学研究的其实是药物真正去了哪里：皮奥利1854年的胃吸收研究与19世纪“催吐与泻下”剂量的经验主义；以及斯塔林1894年对吸收与分泌的对照（同一个人推动了医学两门整合科学——[[physiology/homeostasis-body-fluids]]）。现代时代始于测量手段的竞争：1960年代灵敏血浆检测到来，开启单房室与两房室时代；1968至1971年成立的临床药理单元在患者身上测半衰期——[[clinical-skills/laboratory-tests]]。1950年代硫喷妥的再分布发现教会麻醉界：苏醒是药动学而非代谢（普莱斯1937年“全麻即物理化学”的论文超前于时代，后来被受体时代修正）——[[surgery/anaesthesia-pain]]。**
转换的数字：罗兰与托泽的教科书一代把清除率与分布容积变成可教的算术（1970至80年代病房查房的药动学文化，以及苯妥英、庆大霉素与锂的治疗药物监测热潮）——[[pharmacology/dosing-principles]]。转运体与屏障时代：肿瘤中多药耐药转运体的发现解释了正常组织的屏障（血脑屏障与胎盘的外排范式）；1990年代的Caco-2与溶解度-通透性分类时代（生物药剂学分类系统成为监管科学）；生物制剂时代的药动学——FcRn再循环解释抗体半衰期与抗药物抗体；以及GLP-1时代重新排列了日常药物的吸收——[[immunology/adaptive-responses]]、[[endocrine/diabetes]]。**
:::

::: summary
- 生物利用度等于溶出、通透、肠壁代谢与外排，再加肝首过；高摄取药依赖肝血流，低摄取药依赖内在能力与结合。
- 缓释设计换来便利与副作用平滑，但在转运改变、管饲与减重解剖中可能彻底失效——要按药物而非按类别核查。
- 分布容积是记账不是解剖：脓毒症、水肿、肥胖、妊娠与烧伤都会改变它；负荷剂量跟着Vd，维持剂量跟着清除率。
- 只有未结合的药物有作用，但置换性相互作用很少具有临床意义，除了限制性清除、高摄取或窄指数的药物（如苯妥英与在特定情境中的华法林）。
- 血脑屏障、胎盘与哺乳是由转运体管理的界面而非墙壁；胎儿与婴儿暴露取决于分子大小、脂溶性、解离与泵。
- 途径选择是应用生理学——肠、肺、皮肤、肌肉、泵；每一次途径切换都是一次需要重新思考的剂量改变，而不是查表。
:::

::: exercise 为何此药不可透析 {level=1}
预测并论证下列药物的透析清除：地高辛、华法林、左乙拉西坦、锂、苯妥英、头孢吡肟。
::: solution
**把可透析性法则用出来（[[#def-excretion]]）：核查清单——分布容积（一般大于1 L/kg即无法明显透析清除）、蛋白结合（结合高则不被清除）、分子量、水溶性，以及与分布容积相当的表面积与通量。地高辛：Vd与结合巨大，不被清除，给药时机无关紧要（毒性用地高辛特异性片段抗体；以及透析后浓度反跳的测量窗口）——[[cardiovascular/arrhythmias]]。华法林：高度结合、不被清除，出血由维生素K与凝血因子决定。左乙拉西坦：小分子、水溶、低结合，可被显著清除并需透析后补充。锂：小分子水溶，连续肾替代可清除，而间歇透析可造成反跳性神经毒性（锂的失衡综合征告诫；连续测浓度并持续清除直至趋势安全）——[[psychiatry/mood-disorders]]、[[emergency-critical-care/poisoning]]。苯妥英：蛋白结合且经肝，不可透析；尿毒症时的游离分数解读已在别处处理。头孢吡肟：经肾清除且可被清除，因此肾替代治疗可作为神经毒性的救援，并使给药时机围绕透析日——[[renal/acute-kidney-injury]]、[[emergency-critical-care/critical-care]]。**
:::

::: exercise 分类首过问题 {level=2}
解释机制与临床规则：普萘洛尔在患者间剂量相差四倍；舌下硝酸甘油；吗啡口服对静脉的比值为三分之一；左旋多巴与卡比多巴合用；两周前停用的利福平疗程之后他克莫司浓度崩塌。
::: solution
**首过与生物利用度问答（[[#def-absorption]]）：普萘洛尔是高摄取药，门静脉血流、CYP2D6基因型与蛋白结合共同造成口服浓度四倍变异（高摄取药“低起点、按效应滴定”；以及为何静脉剂量极小、以及在休克与肝病中血流很重要）。舌下硝酸甘油绕过门静脉循环，而吞下会把生物利用度降到可忽略（口干与给药技术的教育；以及含无硝酸酯间期的贴剂设计）——[[cardiovascular/coronary-artery-disease]]。口服吗啡在肠与肝被葡萄糖醛酸化，活性代谢物M6G的命运在肾（三分之一的比值在肝肾疾病时会移动，以及何时换途径）——[[renal/chronic-kidney-disease]]。左旋多巴加周围脱羧酶抑制剂减少周围降解而让药物入脑；加上蛋白竞争的进餐时间、用多潘立酮治胃瘫、以及高蛋白饮食与症状波动的争论；肠道凝胶泵与皮下激动剂的救援装置——[[nervous-system/movement-disorders]]。利福平持续诱导CYP3A4与P-糖蛋白，停药两周后他克莫司、避孕药与直接口服抗凝药浓度仍低，酶更新的半衰期解释了滞后（移植、人类免疫缺陷病毒与结核共治疗的剂量重建与浓度监测方案；以及改用利福布的逻辑）——[[infectious-diseases/tuberculosis]]、[[immunology/transplant-tumour-immunology]]。**
:::

::: exercise 为两种肝开药 {level=2}
比较吗啡、多西环素、呋塞米、华法林、双氯芬酸与头孢曲松在（a）肝硬化伴腹水与（b）胆汁淤积性黄疸中的处方逻辑。
::: solution
**按肝状态处方（[[#def-excretion]]、[[gastrointestinal/liver-disease]]）：肝硬化伴腹水——门体分流提高口服吗啡的生物利用度（高摄取药），带来镇静与肝性脑病风险（选择阿片替代时把脑病风险放在心里、最低剂量、最短疗程）；低白蛋白影响限制性清除药物；肾灌注脆弱——呋塞米仍有效但要注意钠与肝肾综合征风险；腹水的生理以螺内酯为先；非甾体抗炎药直接拒绝；自发性腹膜炎预防用的环丙沙星要带肌腱、心电图间期与耐药性的告诫——[[geriatrics-palliative/polypharmacy]]、[[renal/acute-kidney-injury]]。胆汁淤积性黄疸——胆道排泄药物蓄积与梗阻模式的警示（头孢曲松的胆泥与钙沉淀；多西环素是肝毒性而非胆道蓄积）；胆汁淤积风险药物清单要按具体产品读；以及华法林悖论——两种状态都延长国际标准化比值（胆汁淤积的维生素K吸收不良对肝硬化合成功能衰竭），纠正手段不同（维生素K对凝血因子）；经肝代谢药物按摄取与内在清除率而非胆红素给药；基于Child-Pugh与终末期肝病模型的说明书建议很少经过验证——[[blood/haemostasis-bleeding]]。元规则——先问“这个药用到肝处理机的哪一部分”，再问“这个病弄坏了什么”，然后定剂量并监测，窄指数者测浓度——[[pharmacology/patient-variation]]。**

::: exercise 设计门诊静脉抗生素服务 {level=3}
为骨与复杂感染设计门诊静脉抗生素治疗：按药动学选药、通路与导管、监测、安全治理、公平与环境考量。
::: solution
**门诊静脉治疗设计（[[#def-excretion]]、[[public-health/health-systems-economics]]、[[microbiology/antimicrobials]]）：按药动学选药——能否每日一次或持续输注（头孢曲松附胆道与血小板告诫；达托霉素需肌酸激酶监测；奥雷巴万古霉素与替考拉宁的负荷方案及其失败告诫；按药敏安排的厄他培南；以及泵的类型要与居家护理可及性匹配）；口服降阶梯的资格取决于高生物利用度药物（氟喹诺酮、利奈唑胺、甲氧苄啶、多西环素、甲硝唑与克林霉素，对比口服暴露低的β内酰胺）——口服试验与降阶梯时代的规则要读指南——[[infectious-diseases/healthcare-infections]]、[[surgery/orthopaedics]]。通路与安全——按疗程在经外周中心静脉导管、中型导管、隧道式导管与输液港间选择，并配套血栓、堵塞与导管感染措施包（见[[microbiology/infection-control]]的逻辑）；患者与照护者能力培训配可视辅助、二十四小时电话线；以及相容性、冲管与居家药房标准。监测与治理——方案驱动的血液检查（肾、肝、全血细胞与药物特异项），糖肽另测浓度；社区采血通路与结果处理的安全网；全科、医院、社区护士的三方共同照护沟通与不良事件报告路径；每日复查与明确的停药日期。公平与绿色层——谁能安全地做门诊治疗（社会与数字排斥的核查、冷链与无菌配制可及性、口译与适应读写能力的教育材料）；按药敏图谱制定政策以对抗“广谱的便利”；药物、导管与出行的环境足迹要按比重与住院收益一起读；以及以床日与患者报告结局衡量成本效果——[[public-health/determinants-inequalities]]、[[clinical-skills/records-handover]]。**

## 练习

::: exercise 向学生解释生物利用度 {level=1}
为何口服吗啡的效价约为注射的三分之一？为何西柚汁对某些药是数小时、对另一些是数天？为何食物帮助某些药片而毁掉另一些？
::: solution
**用平实的话讲生物利用度（[[#def-absorption]]）：吗啡的首过——肠壁葡萄糖醛酸化加肝摄取（M6G的肾蓄积告诫；以及肝肾疾病如何移动口服对注射的效价比值）——[[renal/chronic-kidney-disease]]、[[gastrointestinal/liver-disease]]。西柚的时间——肠内可逆抑制以小时计，而对酶的时间依赖性失活需数天等新酶合成（呋喃香豆素的机制依赖性失活；优先关注的CYP3A4底物清单：非洛地平、辛伐他汀、环孢素、他克莫司；以及果汁、水果与果酱之间的剂量依赖差异）——[[pharmacology/metabolism-excretion]]。食物的两个方向——高脂餐拯救脂溶性且难溶的药物，而另一些相互作用降低吸收（奶、铁与四环素的螯合；双膦酸盐、左甲状腺素与咖啡和钙片的服用规则）；以及酒精导致的缓释剂量突释这一经典失效，加上减重术后首选速释而非缓释——[[gastrointestinal/digestion-absorption]]、[[endocrine/thyroid]]。**
:::
:::

::: exercise 选择途径并为之辩护 {level=1}
为下列情形选择途径并以吸收生理学论证：无静脉通路的癫痫持续状态；首过95%的肝硬化患者用某药；严重腹泻伴肠麻痹时的抗生素；肝衰竭中需要可靠消退的输注；过敏性休克的肾上腺素。
::: solution
**途径选择的门诊（[[#def-absorption]]、[[#def-distribution]]）：无静脉通路的癫痫持续状态——颊黏膜咪达唑仑或鼻内给药，对照直肠地西泮（鼻黏膜面积与脂溶性动力学；急救人员实践的证据；以及“能建立静脉就用静脉”的规则）——[[nervous-system/epilepsy]]、[[emergency-critical-care/resuscitation]]。首过95%的肝硬化——用注射或舌下绕过，但要小心门体分流会把高摄取药的口服生物利用度推向静脉的领域（口服对静脉的比值在肝病中不可靠）；例外是需要肝激活的前体药（奥司他韦、氯吡格雷）——[[gastrointestinal/liver-disease]]。肠麻痹时口服不可靠——改静脉并列出弃用缓释的清单（“粪便里的空药片”解释对“永不碾碎”规则；以及直肠给药在肠麻痹时仍有效，因为结肠吸收不需要转运）——[[gastrointestinal/bowel-disease]]。肝衰竭中要可靠消退——选不依赖器官消除的药（瑞芬太尼的酯水解、顺式阿曲库铵的霍夫曼消除；语境敏感半时表，以及各自的组胺特征）——[[surgery/anaesthesia-pain]]。过敏性休克——大腿中段外侧肌内注射是最快最可靠的吸收，而皮下在休克时不可靠（三角肌对大腿的吸收比较、自动注射笔的技术教学、五分钟重复规则；以及静脉肾上腺素只能稀释、滴定并由有经验者给）——[[emergency-critical-care/anaphylaxis]]、[[immunology/hypersensitivity]]。**
:::
:::

::: exercise 在极端体型中开处方 {level=2}
为下列情形做剂量计划：需预防抗凝与β内酰胺的150公斤患者；肾功能正常、需脂溶性精神科维持治疗的38公斤成人；第3天肌酐清除率已高的烧伤患者；需要地高辛这类亲水药物的水肿型心衰。
::: solution
**按体型处方（[[#def-distribution]]、[[pharmacology/patient-variation]]）：肥胖——按药物使用体重分段或调整体重的表格（依诺肝素的体重分段与极端体重时的抗Xa监测；肥胖中β内酰胺强化给药的证据；脂溶性药物的诱导剂量按瘦体重而非总体重；以及超过120公斤或体质指数40以上时直接口服抗凝药的争论）——[[blood/thrombosis-anticoagulation]]、[[respiratory/respiratory-infections]]。低体重成人——与儿科的每公斤体重连续性，并核查吸收与白蛋白；恶病质中脂溶性药物分布改变，脂肪与蛋白耗竭的毒性教训；有条件时使用治疗药物监测——[[psychiatry/mood-disorders]]、[[pharmacology/dosing-principles]]。早期高代谢烧伤——肾与肝清除增加、分布容积扩大、α1酸性糖蛋白升高，因此需要更高的输注速率；要读烧伤药动学指南，并记住约第2天起琥珀胆碱因高钾而禁忌——[[surgery/trauma]]、[[pharmacology/metabolism-excretion]]。水肿中的亲水药——分布容积变大需要更大或分次的负荷剂量，之后按浓度给常规维持（地高辛按瘦体重给药、由肾功能决定维持；“脂肪不储存地高辛”这一说法要破除；浓度解读要看采样时机）——[[cardiovascular/heart-failure]]。**

::: exercise 设计生物类似药转换方案 {level=3}
你的机构计划把使用原研阿达木单抗与英夫利昔稳定的患者转为已批准的生物类似药。请设计药动学、免疫原性、沟通与治理方案。
::: solution
**生物类似药转换设计（[[#def-distribution]]、[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]）：科学简报——生物制剂药动学的家规（FcRn再循环延长半衰期；经网状内皮系统分解而非肝代谢或肾排泄；皮下吸收的变异；以及为何生物类似药不是仿制药——活细胞制造以可比性研究与外推适应证来回答，并向患者解释）——[[immunology/adaptive-responses]]、[[cell-biochemistry/proteins-enzymes]]。免疫原性监测——抗药物抗体与中和抗体会降低疗效并增加输注反应；合并甲氨蝶呤的免疫原性证据；以及疗效丧失时同时测药物浓度与抗体——[[musculoskeletal/inflammatory-arthritis]]、[[gastrointestinal/bowel-disease]]。转换流程——把无安慰剂效应的反效应计划好而不是寄望消失（处方者、药师、护士与说明书的一致信息；共同决定并允许无污名的退出；按症状评分在6至12周随访而不是开放式出院；先培训医师的信心再回答患者问题；在下一次开笔时转换而不中断当前疗程；以及装置改变与注射部位轮换的培训）——[[clinical-skills/communication]]。治理——药物警戒与登记参与；处方记录须载明商品名与批号（可追溯性要靠设计而不是靠希望）；转换组与未转换组的对照监测看板（把发作归属对照疾病负担基线）；省下的钱要留在药品预算而不是被吸收；以及患者与照护者参与方案设计的发言权——[[public-health/health-systems-economics]]、[[medical-ethics-law/justice-resources]]。**
