一种新药到达患者手中，是一个漫长过程的终点。从最初确定靶点到获得批准的产品，通常相隔十年以上，而进入人体试验的候选药物大多数永远不会上市。在此过程中，药物的获益与伤害在实验室系统、动物、健康志愿者和患者身上被逐一测定；监管机构决定它能否销售；卫生技术评估机构决定它是否值得付费；最后，由处方者决定它是否适合某一位具体的人。

本章沿着这条路径展开。它介绍药物发现和临床前试验、临床试验的各个分期、上市许可和上市后监测，以及成本效果评估。随后转向处方者的职责：合理选药、开具安全的处方、识别常见差错，以及抗微生物药物和阿片类药物的管理。前几章描述了药物如何起作用、如何造成伤害；本章描述关于药物的证据如何收集和使用。

## 从靶点到候选药物 {#sec-discovery}

::: definition 药物发现与临床前开发 {#def-discovery}
**药物发现**是找出一种可能安全地改变疾病过程的分子。通常经历以下步骤：

1. **靶点确定与验证**：选择一个受体、酶、转运体或其他分子，对其进行调节应当有益，并有来自生物学、遗传学或已有药物的证据；
2. **苗头化合物发现**：筛选大型化合物库，依据靶点结构设计分子，或对于单克隆抗体等**生物药**，制备能结合靶点的蛋白质；
3. **先导化合物优化**：修饰化学结构以提高效价强度、选择性和药代动力学性质，并去除毒性。

**临床前开发**在药物用于人体之前对候选药物进行测试：细胞和动物药理学、药代动力学、安全药理学（对心律、呼吸和神经系统的影响）、至少两个物种的重复给药一般毒理学、遗传毒性，以及在适当阶段的生殖毒性和致癌性研究。这些研究确定毒性靶器官和无不良反应剂量，用于选择安全的人体起始剂量。
:::

动物研究能预测许多人体毒性，但不是全部，因为物种之间在受体、代谢和免疫功能上存在差异。2006年，这一局限以极端的方式显现出来：伦敦的六名健康志愿者首次在人体接受了TGN1412，这是一种旨在刺激部分T细胞的单克隆抗体。数小时内，六人全部发生严重的细胞因子释放综合征和多器官衰竭。起始剂量是按常规方法根据动物毒理学计算的，但该抗体对人体细胞的作用要强得多。随后的审查建议：对于高风险药物，首次人体剂量应基于**最低预期生物效应水平**（MABEL）；志愿者应逐一给药，彼此之间留有间隔；此类试验应在有重症监护条件的地方进行。

## 临床试验 {#sec-trials}

::: definition 临床开发的分期 {#def-phases}
- **Ⅰ期**：首次用于人体，通常为少量（数十名）健康志愿者；抗肿瘤药等毒性药物则用于患者。目的：安全性、耐受性、药代动力学及合适的剂量范围，先单次递增剂量，再多次递增剂量。
- **Ⅱ期**：数十至数百名目标疾病患者。目的：获得活性证据、剂量–反应关系和更多安全性数据，以决定是否值得开展大型试验。
- **Ⅲ期**：数百至数千名患者参加的随机对照试验，在有临床意义的结局上将药物与安慰剂或标准治疗比较。Ⅲ期结果通常构成上市许可的主要证据。
- **Ⅳ期**：上市后的研究，包括监测罕见和长期不良反应、在试验排除的人群中开展的研究，以及与其他治疗的比较。

有些研发项目还包括探索性的**0期**（微剂量）研究，给予极小的非治疗剂量，以便及早研究药代动力学。
:::

使试验可信的设计特征见[[epidemiology-ebm/randomised-trials]]。简言之：**随机化**使已知和未知的预后因素在各组间均衡分布；**分配隐藏**和**盲法**防止参与者和研究者的预期影响结果；预先设定的**主要结局**限制选择性报告；**意向性治疗**分析保留随机化的益处。试验可以检验药物是否优于对照（**优效性**），或是否不比对照差超过预先设定的界值（**非劣效性**）；后者用于新药具有副作用更少或给药更简便等其他优势的情况。

涉及人的研究伦理，包括知情同意、独立伦理审查和《赫尔辛基宣言》，见[[medical-ethics-law/research-ethics]]。试验必须在开始前注册，无论结果阳性或阴性都必须报告；未发表的阴性试验会使处方者所依赖的证据产生偏倚。

试验规模决定了它能检测出什么。一个太小、不足以检测出有临床意义差异的试验不太可能提供有用的信息，而且试验根本无法排除罕见的不良反应。下图说明检验功效。

::: widget hypothesis

caption: 原假设（无差异）和备择假设（真实标准化效应为0.3）下的抽样分布。增大$n$，观察功效（即检测到该效应的概率）上升。把效应量减半，看看要获得同样的功效需要多出多少参与者。因此，在心血管事件等硬终点上效应较小的药物，其试验需要数千名参与者。
:::

### 解读试验结果

试验结果常以相对效应报告，听起来比绝对效应更大。二者都重要，而处方者和患者作决定时需要的是绝对差异。

::: example 相对获益与绝对获益 {#ex-formulary-read}
一项为期三年的试验在心血管高危人群中比较一种新的降脂药与安慰剂，两组均在他汀基础上加用。主要结局（心血管死亡、心肌梗死或卒中）在安慰剂组发生率为10%，新药组为8%。计算相对危险度降低、绝对危险度降低和需治疗人数，并说明在将该药纳入地方处方集之前还需要什么。
::: solution
- 相对危险度$= 0.08/0.10 = 0.8$，因此**相对危险度降低**为20%。
- **绝对危险度降低**$= 10\% - 8\% = 2\%$（三年）。
- **需治疗人数**$= 1/0.02 = 50$：五十人服药三年才能预防一次事件。

处方集委员会还会问：试验实施得好吗（随机化、盲法、随访、意向性治疗分析）？结局有临床意义吗？患者与本地患者相似吗？发生了哪些不良反应？需伤害人数是多少？有哪些替代方案，该药与它们相比如何？费用是多少？NICE是否已作评估？“它有效吗？”只是这些问题中的第一个（[[epidemiology-ebm/critical-appraisal]]）。
:::
:::

## 上市许可、监管与监测 {#sec-licensing}

::: definition 上市许可、评估与药物警戒 {#def-licensing}
**上市许可**允许企业按规定的适应证、剂量、途径和人群销售某药品，这些内容载于**产品特性概要**（SmPC）。上市许可由监管机构在评估质量、安全性和有效性后授予：在英国为**药品和保健产品监管局**（MHRA）；在欧盟为欧洲药品管理局与欧盟委员会；在美国为食品药品监督管理局。对于存在未满足需求的严重疾病，监管机构可根据不够完整的证据授予**附条件**许可，并要求企业提供进一步的数据。

上市许可意味着药品可以销售，而不是国家医疗服务体系（NHS）应当为其付费。在英格兰，**NICE技术评估**评价临床效果和成本效果。NHS机构必须为技术评估推荐的药品提供资金，通常在三个月内。

**上市后监测**贯穿药品的整个生命周期：自发报告（黄卡计划）、对新药进行重点监测的黑三角（▼）、生产企业的定期安全性报告，以及药物流行病学研究。监管机构可以修改SmPC、增加警示、限制使用或撤销许可（[[pharmacology/adverse-reactions]]）。
:::

成本效果以**质量调整生命年**（QALY）衡量，它把生命的长度和质量结合起来（一个QALY即完全健康地生活一年）。**增量成本效果比**（ICER）是新治疗相对于现行治疗的额外成本除以其额外产生的QALY：

$$
\text{ICER} = \frac{\text{成本}_{\text{新}} - \text{成本}_{\text{现行}}}{\text{QALY}_{\text{新}} - \text{QALY}_{\text{现行}}}.
$$ {#eq-icer}

NICE把ICER与一个阈值范围进行比较。多年来这一范围是每QALY 20,000至30,000英镑。根据政府2025年12月宣布的决定，自2026年4月起，技术评估的标准范围变为每QALY 25,000至35,000英镑；高度专科化技术适用不同的安排，严重度调整因子可对最严重疾病的QALY赋予更大权重。这些数字是政策选择，可能再次改变，因此应查阅现行的NICE方法。其基本逻辑是：花在一种治疗上的钱就不能用于其他治疗，阈值代表了对这些钱原本可以产生多少健康的估计（[[public-health/health-systems-economics]]）。

::: example 它具有成本效果吗？ {#ex-icer}
一种治疗慢性肺病的新疗法，每位患者终生比现行治疗多花费30,000英镑，平均获得1.2个QALY。计算ICER，并对照自2026年4月起使用的NICE阈值范围加以评论。
::: solution
由[[#eq-icer]]：$\text{ICER} = 30{,}000/1.2 = 25{,}000$英镑/QALY。

这处于25,000至35,000英镑范围的低端，因此只要委员会接受证据和经济模型的假设（例如获益在试验结束后能持续多久），很可能被认为是对NHS资源具有成本效果的使用。在原先20,000至30,000英镑的范围下，它也落在范围之内，但更接近委员会需要更有力理由的那一点。模型的不确定性、疾病的严重程度以及QALY未能体现的创新也会被权衡。
:::
:::

### 按说明书用药、超说明书用药与无许可药品

药品可以通过三种方式处方：

- **按说明书用药**：在上市许可的条件之内；
- **超说明书用药**：已获许可的药品在许可条件之外使用，如用于其他适应证、年龄组、剂量或途径。这很常见，尤其是在儿科、姑息治疗和精神科：例如阿米替林用于神经病理性疼痛，或许多药物用于低于许可年龄的儿童；
- **无许可药品**：在英国没有上市许可的产品，如进口产品或特别配制的制剂。

在许可之外处方是合法的，而且常常是良好的实践，但它把更多的责任转移给处方者。英国的专业指南（来自英国医学总会等）要求处方者确信有足够的安全性和有效性证据，对处方和监测负责，记录理由，并在与患者（或父母、照护者）的决策相关时，向其解释该用法超出了许可范围。

::: example 首次人体剂量 {#ex-phase1-vol}
一家公司计划开展一种激活免疫受体的单克隆抗体的首次人体研究。在猴子中，50 mg/kg剂量未见不良反应。人体细胞实验显示，约10%的受体占领率即可产生可测得的细胞因子释放。请解释为什么主要依据动物无不良反应剂量确定的起始剂量可能不安全，并概述设计首次人体研究的原则。
::: solution
动物无不良反应剂量反映的是药物对动物受体和免疫系统的作用。如果抗体与人体受体结合的亲和力更高，或人体细胞反应更强，那么在猴子中安全的剂量可能在人体中产生巨大而迅速的效应。对于免疫受体激动药，主要风险来自被放大的预期药理作用本身，而不是脱靶毒性。

源自TGN1412审查的原则：

- 起始剂量基于**最低预期生物效应水平**（MABEL），利用人体体外结合、占领率和反应数据，并取基于MABEL和基于毒理学的估计值中较低者；
- 首剂只给一名参与者，观察一段时间后再给下一名，并谨慎地递增剂量；
- 采用缓慢静脉输注，以便随时停止；
- 在可立即获得重症监护的单位开展研究，并制定处理细胞因子释放的预案。

参与者的知情同意必须如实说明不确定性，并由独立的伦理和监管审查评估试验设计（[[medical-ethics-law/research-ethics]]）。
:::
:::

## 合理与安全的处方 {#sec-prescribing}

处方是医生最常做、后果最重大的事情之一。世界卫生组织的《合理处方指南》（*Guide to Good Prescribing*，1994）提出了一个至今仍然有用的流程：

1. 明确患者的问题；
2. 确定治疗目标；
3. 选择治疗，考虑非药物方案，在药物之间考虑有效性、安全性、对该患者的适宜性和费用（该指南把处方者充分了解的首选药物称为“P药”）；
4. 开具处方；
5. 提供信息、用法说明和警示；
6. 监测，必要时停止治疗。

::: definition 处方集、指南与共同决策 {#def-formulary}
**处方集**是某一机构或地区批准使用的药品清单，附有首选用药的指导。它基于证据、安全性和费用，使处方更加一致。**英国国家处方集**（BNF）和**英国国家儿童处方集**（BNFC）是关于适应证、剂量、注意事项、相互作用和监测的国家参考资料，而**临床指南**（NICE、专科学会、地方抗菌药物指南）则针对特定疾病推荐治疗。

指南描述的是对群体通常最有效的方案。**共同决策**把这些证据应用于个体：讨论各种选择（包括不治疗），以绝对数字说明其获益与伤害，以及对本人最重要的是什么。只要理由经过斟酌并有记录，不遵循指南的决定也可能是正确的。
:::

### 开具安全的处方

处方无论是手写还是电子形式，都必须使预期的治疗毫无歧义。其基本要素包括：患者身份（姓名、出生日期、医院或NHS号码），在医院中还包括体重和过敏状态及反应性质；**通用名**，除非品牌很重要（如某些缓释制剂、环孢素、锂盐和某些抗癫痫药）；剂量，所用单位不带不必要的小数点；途径；频次和时间；必要时的疗程或复查日期；适应证；以及处方者的签名和联系方式。

严重差错的常见原因包括：

- **“units”（单位）缩写**为“U”或“IU”，可能被误读为零；胰岛素和肝素的剂量应始终写全“units”；
- **微克与毫克**混淆；“micrograms”（微克）应写全，避免末尾的零（写5 mg而不是5.0 mg），并使用前导零（写0.5 mg而不是.5 mg）；
- **形似或音似的药名**；
- **每周一次的药物按每日给药**，如甲氨蝶呤（[[pharmacology/dosing-principles]]）；
- **阿片类差错**：混淆吗啡或羟考酮的速释与缓释制剂，阿片类之间换算错误，或给未用过阿片类的人使用高剂量制剂；
- 入院时**遗漏关键药物**，如帕金森病药物、胰岛素和抗凝药；
- **未核查过敏史**，以及未识别相互作用。

**用药重整**把患者入院前服用的药物清单与医院所开药物进行比较，并解决其中的差异；NICE建议在入院后24小时内及照护转接时进行。**管制药品**在处方、储存和记录方面须遵守《滥用药物条例》的额外法律要求；对于附表2和附表3中的药品，处方必须以文字和数字两种形式写明总量。

::: warning 开始用药很容易；停药也是处方的一部分
许多有害的处方在最初开具时并没有错，而是随着时间推移变成了错误：培养结果阴性后仍继续使用的抗生素，原计划短期使用却连用多年的质子泵抑制药，反复续开的苯二氮䓬类，疼痛缓解后仍继续使用的阿片类。每张处方都需要复查日期或停药日期、可以核查的适应证以及监测计划。**减停药物**，即有计划、有监督地减少或停用那些伤害已超过获益的药物，本身就是一项技能（[[geriatrics-palliative/polypharmacy]]）。
:::

::: example 找出差错 {#ex-prescription-review}
一名住院医师为一位因跌倒入院的76岁女性（体重52 kg，eGFR 28 mL/min/1.73 m²）开具了以下医院处方：

- “Insulin glargine 10U at night”（甘精胰岛素10U，睡前）
- “Morphine MR 30mg bd”（吗啡缓释片30 mg，每日两次；她此前未用过阿片类）
- “Methotrexate 7.5mg daily”（甲氨蝶呤7.5 mg，每日一次；她因类风湿关节炎服用）
- “Enoxaparin 40mg sc od”（依诺肝素40 mg皮下注射，每日一次；用于预防血栓）
- “Gentamicin”（庆大霉素；无剂量或适应证）。

指出问题以及每一项应如何纠正。
::: solution
- **胰岛素**：“U”可能被误读为0，把10单位变成100单位。应写全“10 units”。
- **吗啡缓释片30 mg每日两次**，对于一位年老、衰弱、未用过阿片类且肾功能减退的女性是危险的高起始剂量；吗啡的活性代谢物在肾功能损害时蓄积。如需使用阿片类，应以小剂量速释制剂滴定至起效，根据肾功能调整阿片类药物的选择，并及时复查。
- **甲氨蝶呤每日一次**是一种典型的、可能致命的差错。应为“每周一次”，写明星期几，并在用药重整时与她平时的方案核对。
- **依诺肝素**：在肾功能明显减退和低体重的情况下，用于预防血栓的剂量可能需要按照BNF和地方指南、依据肌酐清除率调整；还应评估她的出血风险。
- **庆大霉素**：没有剂量、途径、适应证或计划。肾功能减退者使用氨基糖苷类，需要明确的适应证、按地方方案计算的剂量和血药浓度监测，或改用其他药物。

还应记录过敏状态、每种药物的适应证和复查日期。电子处方系统能防止其中一些差错，但不是全部，药师审核是一道宝贵的第二重核查（[[clinical-skills/patient-safety]]）。
:::
:::

### 抗微生物药物与阿片类药物的管理

有些类别的药物需要专门管理，因为过度使用不仅伤害个人，也伤害他人。

**抗微生物药物管理**旨在保持抗微生物药物的有效性：只在需要时使用，选择最窄谱的有效药物，并及时停药。英国的“*明智开始，然后聚焦*”（*Start Smart then Focus*）方法要求医院处方者尽可能在开始使用抗生素前采集培养标本，脓毒症时立即开始治疗，记录适应证、药物、剂量、途径和复查日期，然后在48至72小时作出明确决定：停药、由静脉改为口服、根据结果换用较窄谱的药物、继续，或转为门诊胃肠外治疗（[[infectious-diseases/stewardship-outbreaks]]、[[microbiology/antimicrobials]]）。

**阿片类药物管理**是对以下证据的回应：对大多数慢性非癌性疼痛，长期使用阿片类的获益有限，并带来依赖、过量和其他伤害的风险。其原则是与本人一起设定切合实际的目标；急性疼痛使用最低有效剂量和最短疗程；定期复查；避免与其他镇静药合用；对高剂量格外谨慎（按照英国专业指南，相当于口服吗啡每日120 mg以上时，伤害风险显著上升）；在伤害超过获益时支持逐步减量。癌痛患者或临终者不受同样的限制；充分镇痛仍然至关重要（[[geriatrics-palliative/symptom-control]]）。

::: quiz
一种治疗罕见病的新药获得了MHRA的附条件上市许可。下列哪种说法正确？
- [ ] 英格兰NHS现在必须立即为其提供资金
- [ ] 由于已获许可，它不再需要上市后监测
- [x] 它可按批准的适应证销售，负有提供进一步证据的义务，并以黑三角标示接受重点监测
- [ ] 它只能超说明书处方
::: solution
附条件许可允许在存在未满足需求时依据不够完整的证据上市，并附有完成研究的义务。作为新药，它带有表示额外监测的黑三角，因此所有可疑反应都应报告。许可与资金是两回事：英格兰NHS的资金取决于NICE评估或其他采购决策。
:::
:::

::: history
现代药物研发框架是由悲剧和科学进步共同塑造的。1937年磺胺酏剂致死事件之后，美国要求药品上市前提供安全性证据；沙利度胺事件之后，基福弗–哈里斯修正案（1962）又要求提供来自充分且有良好对照研究的有效性证据。在英国，药品安全委员会于1964年开始工作，1968年的《药品法》建立了许可制度；MHRA成立于2003年。1948年英国医学研究理事会与统计学家希尔（Austin Bradford Hill）共同设计的链霉素治疗结核病试验之后，随机对照试验成为证据的标准。1964年，世界医学会通过了关于研究伦理的《赫尔辛基宣言》。NICE于1999年成立，负责为NHS评估治疗的临床效果和成本效果。2006年的TGN1412试验改变了首次人体研究的设计；在有证据表明阴性结果常常未被发表之后，国际上对试验注册的要求自二十一世纪头十年中期起不断加强。
:::

::: summary
- 药物发现从靶点到先导化合物再到候选药物；临床前研究描述药理和毒性特征，以确定安全的起始剂量。对于高风险药物，首次人体剂量基于MABEL。
- Ⅰ期确定安全性和动力学，Ⅱ期确定活性和剂量，Ⅲ期确定相对于安慰剂或标准治疗的有效性，Ⅳ期研究长期和罕见效应。
- 绝对危险度降低和需治疗人数以与决策相关的方式表达获益；当基线风险低时，相对降低会夸大获益。
- 监管机构批准药品上市；NICE用ICER评估成本效果，自2026年4月起的标准阈值范围为每QALY 25,000至35,000英镑。
- 超说明书处方合法且常见，但需要证据、承担责任并作出解释。
- 安全处方需要无歧义的处方、用药重整、对高风险药物和情形的关注，以及有计划的复查和停药。抗微生物药物和阿片类药物的管理既保护个人，也保护更广泛的人群。
:::

::: exercise 研发的分期 {level=1}
将每项研究与其分期对应：(a) 24名健康志愿者接受一种新化合物的单次递增剂量；(b) 一项在电子病历中针对20万名某药使用者开展的队列研究，寻找其与胰腺炎的关联；(c) 3,500名心力衰竭患者被随机分配到新药或安慰剂组，主要结局为心血管死亡或住院；(d) 180名银屑病患者被随机分配到三种剂量之一或安慰剂组，观察皮损是否改善。
::: solution
(a) Ⅰ期。(b) Ⅳ期（上市后监测）。(c) Ⅲ期。(d) Ⅱ期（剂量探索和活性证据）。
:::

::: exercise 需治疗人数 {level=1 check="100"}
五年内，安慰剂组4%、活性药物组3%的人发生卒中。需要治疗多少人五年才能预防一次卒中？
::: solution
ARR $= 0.04 - 0.03 = 0.01$，因此NNT $= 1/0.01 = 100$。
:::

::: exercise 这张处方有什么问题？ {level=1}
指出每项的问题：(a) “Levothyroxine 100 mcg od”；(b) “Heparin 5000 IU sc bd”；(c) “Digoxin .125 mg od”；(d) “Lorazepam 1.0 mg prn”。
::: solution
(a) “mcg”可能被误读为“mg”；应写全“micrograms”（微克）。(b) “IU”可能被误读（例如读成“10”）；应写全“units”（单位）。(c) 缺少前导零的“.125”可能被误读为125；应写“125 micrograms”（或0.125 mg）。(d) “1.0”中末尾的零可能被误读为10；应写“1 mg”，而且“按需”处方还需要写明适应证、最短间隔和每日最大剂量。
:::
:::

::: exercise 增量成本效果比 {level=2 check="30000"}
一种新药每位患者比标准治疗多花费18,000英镑，额外产生0.6个QALY。计算ICER（英镑/QALY）。
::: solution
ICER $= 18{,}000/0.6 = 30{,}000$英镑/QALY。这处于NICE自2026年4月起采用的25,000至35,000英镑范围之内；决策还取决于不确定性和委员会考虑的其他因素。
:::
:::

::: exercise 安全性研究需要多大规模？ {level=2 check="2995"}
某不良反应在服药者中的发生率为千分之一。至少需要随访多少名患者（取最小整数），才能有至少95%的概率观察到至少一例？然后结合典型Ⅲ期研究项目的规模评论这一结果。
::: hint
$n$人中无一例发生的概率为$0.999^n$。令其不超过0.05。
:::
::: solution
需要$1 - 0.999^n \ge 0.95$，即$0.999^n \le 0.05$，$n \ge \ln 0.05/\ln 0.999 \approx 2994.2$。最小整数为**2995**，与三的法则（$3/n$）一致。

观察到一例并不能确立与药物的关联；要显示与本底发生率之间的显著差异需要多得多的参与者。因此，数千人规模的Ⅲ期研究项目可以检测出约千分之一的反应，但检测不出万分之一或更罕见的反应，这就是上市后监测必不可少的原因。
:::
:::

::: exercise 超说明书还是无许可？ {level=2}
把下列每项归类为按说明书、超说明书或无许可用药，并对每个超说明书或无许可的情况说明处方者的一项责任：(a) 小剂量阿米替林用于神经病理性疼痛；(b) 由于没有获批的口服液，为儿童特别配制的口服液体制剂；(c) 某药按其批准的适应证用于2岁儿童，但它只获批用于6岁以上；(d) 阿托伐他汀用于成人心血管疾病一级预防。
::: solution
(a) 超说明书（在英国阿米替林获批用于抑郁症而非神经病理性疼痛，尽管后者已被广泛推荐）。(b) 无许可（没有上市许可的“特配制剂”）。(c) 超说明书（超出许可年龄范围）。(d) 按说明书。

对于(a)至(c)，处方者应确信有证据支持该用法，对处方和监测负责，记录理由，并在与决策相关时向患者或家长说明超说明书或无许可的情况，遵循专业指南和BNF或BNFC。
:::

::: exercise 72小时抗生素复查 {level=3}
一名68岁男性因疑似社区获得性肺炎入院，开始静脉使用阿莫西林克拉维酸和克拉霉素。72小时时他已退热，能进食进水，CRP从210降至60 mg/L。血培养阴性；痰培养生长出对阿莫西林敏感的肺炎链球菌（*Streptococcus pneumoniae*）。尿军团菌抗原阴性。按照“明智开始，然后聚焦”框架，概述应作出的决定及其理由。
::: solution
在48至72小时复查时，有五种选择：停药、由静脉改为口服、换药、继续，或门诊胃肠外治疗。

- 他临床好转且能口服药物，因此**由静脉改为口服**是合适的。
- 病原体已明确且对阿莫西林敏感，因此方案应**降阶梯**为口服阿莫西林，停用阿莫西林克拉维酸（谱更广，与艰难梭菌关系更密切），并停用克拉霉素（军团菌抗原阴性，不再需要覆盖非典型病原体；还可降低相互作用和QT风险）。
- 总**疗程**应遵循地方指南，对大多数社区获得性肺炎而言疗程较短（如病情好转，总疗程常为五天）。

记录决定、理由和停药日期。这种做法在不影响其诊疗的前提下，减少了不良反应和费用，并减缓了耐药菌的选择。
:::
:::

::: exercise 非劣效性试验 {level=3}
一项试验比较一种新的口服抗生素与标准静脉治疗用于骨感染。预先设定的非劣效界值为10个百分点。新药治愈率为88%，标准治疗为90%；差值为−2个百分点（95%置信区间−6至+2）。(a) 新药是否非劣效？(b) 若界值为5个百分点，结论会改变吗？(c) 给出临床医生仍可能偏爱新药的两个理由，以及一个需要核查的方法学问题。
::: solution
(a) 是。若整个置信区间都高于−10个百分点即证明非劣效；下限为−6，高于−10。

(b) 若界值为−5，下限（−6）越过了界值，因此不能证明非劣效：结果不确定，与新药最多差6个百分点的情况相容。

(c) 口服治疗避免了静脉导管及其感染，可以更早出院，而且通常更便宜、更易为患者接受。方法学问题：界值是否有临床依据并预先设定；符合方案分析与意向性治疗分析是否一致（在非劣效性试验中，意向性治疗分析可能偏向于得出无差异的结论）；以及标准治疗是否实施得当，因为实施不佳的对照会使非劣效更容易被证明（[[epidemiology-ebm/critical-appraisal]]）。
:::
