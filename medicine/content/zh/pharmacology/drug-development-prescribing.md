在一种药进入处方之前，它要先与证据进行一场长达十年的辩论。**开发从靶点发现开始，经1期的安全性、2期的剂量探索、3期的确证试验、监管审评与上市后监测；而处方是这一过程的公开端——在这里，药品目录制度、指南、成本效果与人类行为共同决定“好证据”能否变成“好治疗”。**理解这条流水线，才能解释药物为何带着这样的标签、为何某些看似安全的药会消失、以及“证据”为何是分阶段的论证而不是终局判决。

## 从分子到许可

::: definition 发现与早期开发 {#def-discovery}
**从靶点到先导：疾病机制研究提出靶点，筛选（如今以高通量与计算筛选为主）找到起始化学，药物化学随后优化效价、选择性、溶解度与代谢稳定性，同时毒理学早期标出器官风险（用于QT风险的hERG钾通道试验、遗传毒性电池、安全药理核心组合，以及杀掉落选者多于“无效”的信号——肝毒性）。淘汰率的数量级是一万个化合物换一个获批药物；而抗真菌与化疗药物的选择性例外恰好证明了规则：“有些靶点可成药，有些不可”——[[pathology/cancer-biology]]、[[pharmacology/drug-receptor]]。**
首次人体：1期在少数健康志愿者中进行（肿瘤研究用患者，因为毒性），确立安全性、耐受性、药动学与最初步的药效信号——细胞毒药物的“最大耐受剂量”文化对现代药物的剂量-暴露-反应；哨兵给药与队列递增设计及伦理防护；以及生物标志物终点（PET上的受体占据、血中的靶点抑制）让小研究也能说明问题。随后2a期在患者中做概念验证、2b期做剂量范围（如今要求“以模型指导剂量选择”；安慰剂反应膨胀会让后续所有读数难堪；而无望性设计让有前景的药提早放弃）——[[pharmacology/dosing-principles]]、[[epidemiology-ebm/randomised-trials]]。**
为未满足需求而弯曲时间线的特殊路径：**加速或条件性批准（基于替代终点——人类免疫缺陷病毒蛋白酶抑制药的革命发明了加速批准；肿瘤缓解率与免疫治疗时代及确证试验失败带来的撤市机制；罕见病的孤儿药框架及其“小人群、以许可换学习”的取舍）；以及“老药新用”路径（沙利度胺与西地那非的职业转折、阿司匹林的长尾、以及秋水仙碱在现代心脏科的回归）——[[infectious-diseases/hiv]]、[[pathology/cancer-diagnosis]]、[[cardiovascular/coronary-artery-disease]]。最后是所有后续都被其塑造的上市前经济学：专利悬崖与“常青化”、按预计独占期终止点倒推的试验规模与时长选择、“以安慰剂作对照”的选择（用活性对照会更难但更科学）、以及使试验更干净却使实践更混乱的人群选择（排除标准）——[[public-health/health-systems-economics]]。**
:::

## 批准之后

::: definition 试验、监管与监测 {#def-licensing}
**3期是决定许可的试验：随机、对照、常为国际多中心，按监管者在乎的终点（死亡、梗死、进展）而非生理学家在乎的替代终点设把握度；有预注册的分析计划与“重复试验”传统及其现代例外。读数技巧属于批判性评价一章：绝对效应、随时间事件的曲线及其风险比例假设、由单一组分驱动的复合终点、礼貌地放宽的非劣效界值、以及有充分理由被禁止的跨试验比较——[[epidemiology-ebm/randomised-trials]]、[[epidemiology-ebm/statistics-for-clinicians]]、[[epidemiology-ebm/critical-appraisal]]。**
监管：各国机构（美国食品药品监督管理局、欧洲药品管理局与英国药品监管局等）审评档案、检查临床现场与生产、核定标签，并在需要时附风险最小化措施（妊娠预防程序、监测登记、教育义务——沙利度胺、异维A酸与丙戊酸是这套架构用代价换来的祖先）；条件性批准与滚动审评（疫情时代的机制，及其“证据速度对证据深度”之争）；国际协调（ICH指南）使数据可共享，但市场仍是政治的——[[obstetrics-gynaecology/pregnancy-complications]]、[[pharmacology/adverse-reactions]]。**上市后：4期承诺、自发报告的信号机器、大型实用主义安全性试验，以及登记与链接研究——它们测量被试验排除掉的东西（罗非昔布的撤市、激素替代的重新解读、在3期嫌“太合并症”的人群中发现的相互作用）。诚实的说法是：许可是证据曲线的起点而不是终点——[[epidemiology-ebm/observational-studies]]、[[clinical-skills/patient-safety]]。黑框警告作为一种文类：要当作“附带出处的发生率与严重度陈述”来读（病例系列、试验信号、类别效应）；有些警告在更好的数据后被撤回（抗精神病药与老年痴呆死亡率的细化、以及25岁以下人群使用选择性5-羟色胺再摄取抑制药与自杀的争论——后者永远改变了同意的方式）——[[psychiatry/psychotic-disorders]]、[[psychiatry/mood-disorders]]。**
:::

## 作为系统的处方

::: definition 药品目录、指南与成本效果 {#def-formulary}
**可及性就是带经济学的药理：国家与医院药品目录决定哪些有效的药在哪个阶段可得（世界卫生组织基本药物示范清单与“基本药物”概念作为全球政策；医院集团的合同；抗菌药物管理的分级——限制、保留、预先审批）；评估机构则为增量定价——国家健康与卓越优化研究所的技术评估与其质量调整生命年阈值（效益乘效用再积分的算术、生命末期与超罕见病的调整及其一致性争论、“增量成本效果比对上公平性”的辩论），以及各国的对应机构（加拿大、德国与澳大利亚的评估机构）都在问同一句话：“每多花一元换来多少额外效益、谁有权规定可接受的比率”——[[public-health/health-systems-economics]]、[[infectious-diseases/stewardship-outbreaks]]。**
指南把试验翻译为实践并给证据分级（GRADE的确定性与强度语言；学会与机构之间的不一致要由处方者导航；以及在证据浪潮中持续更新的“活综述”制度）；而实施缺口属于行为科学——审计与反馈、医嘱组的默认选项、药师与护士的规程、药品目录的助推，以及仍然比多数证据更能改变处方的意见领袖效应——[[epidemiology-ebm/systematic-reviews]]、[[clinical-skills/records-handover]]。可及性的两个案例研究：新抗生素面临失灵的经济学（销量少、因耐药管理而被刻意压制——“推-拉”与包干付费试点如CARB-X与英国的模式），因此尽管需求巨大管线仍稀薄；而肿瘤的“有条件批准与保密折扣”使评估格外有争议（生存获益对成本的透明度之辩）——[[microbiology/antimicrobials]]、[[pathology/cancer-biology]]。**
处方本身是一门有失败模式的临床技能：先就适应证与目标达成一致；按上一章个体化药物与剂量；写下复查日期与停止规则；在“处方义务”旁边并列“减药义务”；以及仿制与生物类似药替换的治理（可互换规则、以厂牌与批号追踪生物制剂、以及决定“省下的是钱还是信任”的反安慰剂管理）——[[clinical-skills/communication]]、[[immunology/vaccines-immunotherapy]]。**
:::

::: example 为药品目录会议读一篇试验 {#ex-formulary-read}
一种新型口服抗凝药提交3期：与国际标准化比值控制良好的华法林相比卒中相对减少25%；胃肠出血更多；并有一行“全因死亡中性”。医院已在达比加群上有采购经验，而成本不同。
::: solution
**评估素养的实战（[[#def-formulary]]、[[epidemiology-ebm/critical-appraisal]]、[[blood/thrombosis-anticoagulation]]）：分解效应——25%的相对风险是相对哪个基线（试验年数内的绝对风险差、需治人数对需害人数；复合终点是否掩盖了真正移动的组分——出血性卒中下降驱动获益而缺血性持平，那就与标题是另一种药）；以及华法林组的治疗范围内时间（若平庸，对照是稻草人；若优秀如标签所示，增量主张就缩小为便利与有限的余地）。出血的算术——胃肠出血的超额要按本院人群的年龄与幽门螺杆菌及质子泵抑制药实践来读；可逆性药物问题在早期标签后已更新；依从性与监测的取舍（不必查国际标准化比值对必须监测肾功能、以及各药相互作用表的差别；而抗磷脂综合征是唯一仍必须用华法林的情形）——[[renal/chronic-kidney-disease]]、[[gastrointestinal/oesophagus-stomach]]。**
比较效果学上的诚实——与本院现有药物的跨试验比较只是假说，因此决定要倾向价格、合同、监测基础设施与患者偏好证据（共同决策研究显示人们高度重视“免于抽血与注射”）；以及大规模替换时的切换与交叉安全性（反安慰剂与理解不足的风险需要主动管理）。治理答案——按本院人群的绝对效益评估；在类别内谈最优价格而不是禁用某药；公布监测路径；并在下一波试验落地时安排复查——[[public-health/health-systems-economics]]、[[clinical-skills/patient-safety]]。**
:::
:::

::: example 被撤出的药，在用的患者 {#ex-withdrawal}
2025年重读罗非昔布的教训：你院的快速通道门诊曾大量使用一种现已受限的药；患者问自己是否“被当成实验品”，而同时一款新药的试验因从本院招募而受批评。
::: solution
**上市后伤害与研究信任（[[#def-licensing]]、[[medical-ethics-law/research-ethics]]）：证据生命周期的解释——上市前试验（数千患者、数月、经过选择）找不到需要在数万人中经年才显现的心血管信号；这正是上市后监测系统存在的原因，也是“许可上的安全证据”是地板而非天花板的原因（沙利度胺、己烯雌酚、罗非昔布与甲羟孕酮的教训要当作警戒史来读；有些信号由观察性研究推进到试验确证，有些没有）——[[pharmacology/adverse-reactions]]、[[epidemiology-ebm/observational-studies]]。回应患者——诚实的时间陈述（风险在可测量时被识别，当时的处方遵循了当时的证据与监管）、“我们现在知道什么、将改变什么”的计划（复查受影响患者的当前治疗、提供心血管危险因素管理、更正记录并写下反应）、坦诚程序及其自身的法律架构、以及在存在时的补偿渠道——[[clinical-skills/communication]]、[[medical-ethics-law/professionalism-regulation]]。**
研究诚信的对应面——从本院招募为何正当（团队不可知性的要求、伦理委员会与受试者信息标准、以及“患者可能把试验与治疗混为一谈”这一现实要靠同意程序与“可以拒绝常规处方”的表述来对抗）；当本院医师是研究者、当申办方资助门诊、当招募压力可能腐蚀入组标准时的利益管理（审计与监查系统，以及在第一个受试者入组前就签署的发表政策）——[[epidemiology-ebm/randomised-trials]]、[[medical-ethics-law/research-ethics]]。**
:::
:::

::: example 1期志愿者之问 {#ex-phase1-vol}
一名22岁健康志愿者被提供2000英镑参加首次人体研究；你的医学生想知道是什么在保护他、以及“高风险医学模式”的国家为何受到批评。
::: solution
**早期试验的伦理与设计（[[#def-discovery]]、[[medical-ethics-law/research-ethics]]）：架构中的保护——诚实说明未知的知情同意（首次人体意味着人体的剂量-反应确实是未定义的）；伦理委员会对临床前档案与起始剂量计算的把关（未观察到不良效应剂量除以安全系数、异速生长与药动学交叉验证）；哨兵给药与缓慢的队列递增及停止规则；独立的数据安全监督与全天候医疗覆盖——[[epidemiology-ebm/randomised-trials]]。报酬之问——合理补偿对不当诱导（设上限的辩论；某些国家以低收入与负债者构成“职业志愿者”人群；英国与欧洲偏好的小额补偿，并诚实承认任何报酬都会按收入筛选受试者）；同意访谈中的胁迫筛查与冷静期。2006年北伦敦的细胞因子风暴试验（TGN-1412）展示了当首次人体剂量选择与临床前信号都出错时会发生什么：其病理、后续分析的透明度，以及由此产生的欧洲规则——1期最小间隔、药理学起始剂量指导、以及提高临床前“人体相关性”的要求——[[immunology/hypersensitivity]]。给学生的答案——这是真正造福人类的正当科学（现代医学多数剂量安全数据来自这些研究）；防护措施正是对脆弱性的回答；考试版的答案是“不当诱导、团队不可知性、以及同意对话的诚实”——[[clinical-skills/communication]]。**
:::

::: example 指南与说明书的冲突 {#ex-label-vs-guideline}
你的哮喘指南如今推荐按需的激素-福莫特罗优于每日沙丁胺醇；患者的说明书却写着相反的话；支付方质疑医院为何资助一个“超说明书”方案。
::: solution
**许可、指南与实践（[[#def-formulary]]、[[respiratory/asthma-copd]]）：三份文件可以正当地不一致——说明书描述的是厂商为注册适应证而资助的试验；指南对证据分级，包括厂商从未做过的试验（无专利的对照与方案没人有义务研究）；而实践落在“患者获益与法律相遇之处”（超说明书处方是处方者的责任，须有同意与理由；当证据优于说明书时，这样的使用是常规且合理的——儿科、皮肤科与姑息照护的绝大多数处方住在这里）——[[paediatrics/acute-childhood-illness]]、[[clinical-skills/communication]]。具体到这个案例：维持兼缓解治疗的证据基础（SMART与SYGMA时代的试验及其急性发作与死亡率信号文献；沙丁胺醇过度使用既是风险标志也是机制）；说明书为何滞后（改标签需要申请与经济学）；对支付方的回答（该方案有指南支持、医院目录记录了理由、同意书载明了超说明书的讨论、审计追踪的是处方与结局而不是纸面）——[[epidemiology-ebm/systematic-reviews]]、[[clinical-skills/patient-safety]]。反向的错误——以为“未注册”就是坏、“已注册”就是最好（沙利度胺时代的反讽：老的注册药可能正是危险，而再评估的义务永远运行）；实务规则是：遵循指南、记录推理、复查结局，并把说明书放在它该在的位置——证据的地板，不是天花板——[[pharmacology/adverse-reactions]]。**
:::

## 通向何处

试验设计在[[epidemiology-ebm/randomised-trials]]展开；评价在[[epidemiology-ebm/critical-appraisal]]与[[epidemiology-ebm/statistics-for-clinicians]]；安全监测在[[pharmacology/adverse-reactions]]；个体化给药在[[pharmacology/patient-variation]]；全球可及性在[[public-health/global-health]]。

::: history
**现代药物监管是一连串灾难加上一个好主意：1937年的磺胺剂与1961年的沙利度胺胚胎病，催生了1938与1962年的安全测试与报告义务（凯弗-哈里斯修正案要求证明疗效也证明安全、知情同意与不良事件报告的建筑、以及欧洲平行的许可法），把药房变成了证据法——[[obstetrics-gynaecology/pregnancy-complications]]、[[pharmacology/adverse-reactions]]。那个好主意是随机对照试验本身：其现代形式随1948年英国医学研究委员会的链霉素试验到来——常被引为第一个现代随机临床试验——用随机数字分配、以抽签决定对照、并由集体怀疑的署名人共同完成；布拉德福德·希尔在前后提供了方法学领导（“你怎么知道？”从病房查房走进了统计学）——[[infectious-diseases/tuberculosis]]、[[epidemiology-ebm/randomised-trials]]。**
随后试验工业化：1960至70年代的合作组与退伍军人事务部试验；1966年FDA的效力再评价（把数百个已上市产品撤下，让“证明有效”开始有意义）；CONSORT与伦理一面（见研究伦理章节）；以及1990年代互联网时代的试验注册库与发表偏倚纠正（ClinicalTrials.gov时代与“报告全部结果”的规范）——[[epidemiology-ebm/systematic-reviews]]、[[medical-ethics-law/research-ethics]]。卫生技术评估带着“把稀缺说出口”到来：俄勒冈医疗补助的抽签设计、加拿大与澳大利亚及新西兰的药品清单、以及1999年成立的NICE及其质量调整生命年阈值之争、癌症基金与“价格与证据一同到达”的准入管理协议（保密折扣时代）——[[public-health/health-systems-economics]]。最新一章是速度对深度：2020至2021年的疫情压缩了每个环节（平台疫苗在完整安全装置下获批，真实世界效果研究在数月内完成确证工作，并采用滚动审评）；抗菌药物包干付费试点试图修复失灵的市场；老药新用与孤儿药加速器；以及人工智能辅助药物发现的竞赛——其第一批经临床验证的赢家仍在观察之中——[[immunology/vaccines-immunotherapy]]、[[public-health/global-health]]、[[genetics/genomic-medicine]]。**
:::

::: summary
- 开发是一个淘汰漏斗：效价与选择性让分子起步；溶解度、代谢、毒性与临床获益杀死多数候选物，通常死在2期。
- 上市前证据回答的是“在数千人、数月内是否有效且安全”；罕见、迟发与人群特异的效应在设计上属于上市后的知识。
- 监管者带条件与风险最小化措施发放许可；评估机构评估价值；药品目录决定可及性——三个不同的问题，公共辩论却不断混为一谈。
- 读关键试验要看绝对效应、复合终点的组分、对照的质量与预注册终点，而不是新闻稿里的相对风险。
- 处方是实施端：适应证一致、药物个体化、复查有日期、停止规则写清、减药可用、替换兼顾含义与成本。
- 每种可及性制度都明示或默示地权衡创新、成本与公平；把这笔交易摆在桌面上就是诚实的版本。
:::

::: exercise 把问题配给阶段 {level=1}
下列开发阶段哪个最能回答：“它结合靶点吗？”“剂量多少？”“它能预防结局吗？”“它值这些钱吗？”“它会伤害少数患者吗？”“我们能换成便宜的版本吗？”
::: solution
**阶段配对（[[#def-discovery]]、[[#def-licensing]]、[[#def-formulary]]）：靶点结合——1期的生物标志物与占据研究（“占据到效应”的假设留待后面检验）与2a期概念验证。剂量——2b期的暴露-反应与以模型指导的选择（以及窄指数药物在获批后由治疗药物监测细化）。结局——3期的事件试验（替代终点对临床终点的区分、加速批准的附注）——[[epidemiology-ebm/randomised-trials]]。价值——卫生技术评估（每一质量调整生命年的成本与预算影响，试验无法回答）。罕见伤害——上市后监测、登记与实用主义安全试验（三法则的算术）——[[pharmacology/adverse-reactions]]。替换——仿制药的生物等效性与可互换框架、生物类似药的可比性研究制度；对窄指数产品（左甲状腺素、华法林、他克莫司、抗癫痫药）替换需配监测方案；对生物制剂需以药物警戒追踪免疫原性——[[immunology/vaccines-immunotherapy]]、[[endocrine/thyroid]]。**

::: exercise 把两篇摘要对着读 {level=2}
药A：对照安慰剂，卒中相对减少30%，五年需治人数90，严重出血0.4%对0.2%。药B：对照活性药，主要复合终点非劣效，输血更少，未报告死亡数据。你给谁用哪个药？还需要什么？
::: solution
**跨摘要推理（[[#def-licensing]]、[[#def-formulary]]、[[epidemiology-ebm/critical-appraisal]]）：药A——安慰剂对照的问题（效应真实，但“优于什么都不用”不是临床问题，如果药B才是标准）；绝对数字（需治人数90对需害人数500的严重出血；人群基线一变两者都变——风险计算器、年龄、既往出血史）；以及需要去查的复合终点与随访细节。药B——非劣效界值（多宽、如何选定；在背景治疗已更好的今天，活性对照自身的效应是否完好——即“检验敏感性”之辩）；缺失的死亡率（为何不报：事件数、时间跨度，还是出血终点更方便）；以及输血终点的临床分量——[[blood/transfusion]]、[[cardiovascular/arrhythmias]]。处方逻辑——没有头对头证据时，按患者因素选择（出血风险、肾功能、依从能力、可逆性、相互作用、成本，以及患者本人在决策辅助中对“卒中对出血”的权衡）；支付层则适用本系统公布的评估规则；并为将来那场真正把两者对照的试验预留复查日期——[[clinical-skills/communication]]、[[public-health/health-systems-economics]]。**

::: exercise 设计抗菌药物管线的激励 {level=2}
向政策研讨会解释为何无人研发新抗生素，并勾画两种激励机制及其失败模式。
::: solution
**抗生素经济学（[[#def-formulary]]、[[microbiology/antimicrobials]]、[[infectious-diseases/stewardship-outbreaks]]）：市场失灵——有效的管理刻意压低用量（成功扼杀收入）；新药被留作储备（作为政策的保险而分文不进）；耐药对分子价值的侵蚀快于任何其他治疗领域；为耐药人群设计的“小试验终点”路径（2018年美国的替代终点途径与欧洲的灵活设计）降低了获批成本却没有降低收入的不确定性——大型药企在2010年代的退出就是自然均衡。机制一（推）：公共与慈善资金资助临床前到2期的工作（CARB-X与创新制药倡议模式、学术通道的优势）；失败模式是管线相关性（追随性分子）与转化断层。机制二（拉）：包干付费或市场进入奖励，使回报与销量脱钩（英国与美国的β内酰胺酶抑制剂复方制剂的包干试点、“像公用事业一样为待命状态而购买”的观念）；失败模式是定价政治、资格标准的博弈、以及可及延迟（付了钱的药医院却不备货）与全球公平的黑洞（耐药负担最重处恰是最贫困的采购系统）——[[public-health/global-health]]。不应忘记的补充杠杆：快速诊断以减少经验性广谱使用、疫苗与饮用水及卫生改善以减少选择压力、以及感染控制——那是史上最便宜的“新抗生素”——[[public-health/communicable-disease-control]]。**

::: exercise 为平行进口的替换辩护或重新设计 {level=3}
你的药房进口了一种已注册但包装不同的版本以省钱；医师注意到名称与外观改变，混淆事件开始出现；涉及服华法林与左甲状腺素的患者。
::: solution
**平行替换的治理（[[#def-formulary]]、[[clinical-skills/patient-safety]]）：合法性与安全性的分裂——进口已注册产品可能合法却仍不安全，如果包装、强度标注与装置人机学发生改动，而缺少国家监管机构预期的替换治理（听似看似与外观相似的事件数据；窄指数药物的患者混淆伤害路径——同一毫克在不同厂牌下是不同风险）——[[medical-ethics-law/professionalism-regulation]]。本案的具体风险——华法林（片剂强度的颜色、剂量记录册被打断、以及厂牌更换后国际标准化比值漂移的报告：混杂要读清，但仍须行动）；左甲状腺素（2017年法国的改版危机是“未管理的替换”的定性研究：群体性焦虑、被归因于反安慰剂的症状复燃、Prescrire的警告、部长去职的政治；而由乳糖改甘露醇的辅料变化才是需要与谣言分离的真正药动学问题）——[[endocrine/thyroid]]、[[blood/thrombosis-anticoagulation]]。重新设计——窄指数产品免于不打招呼的替换，配同意与监测方案；强度对应的颜色与装置全国统一；记录实际发出的厂牌（社区药房的数据轨迹在安全调查中派上用场）；更换前数周发出沟通包（患者材料与被告知清单，含辅料变化的信息：罕见的糖不耐受与过敏生态位按许可变更沟通处理）。审计——事件报告率、以及更换前后的国际标准化比值与促甲状腺激素漂移作为决策数据；把节省额扣除被避免的伤害成本后诚实地报出——[[public-health/health-systems-economics]]、[[clinical-skills/records-handover]]。**

## 练习

::: exercise 给流水线排序 {level=1}
按顺序排列并各加一条成功标准：患者中的剂量范围探索、受体占据生物标志物、hERG与遗传毒性筛查、确证性结局试验、自发报告的信号检出、药品目录列入决定。
::: solution
**流水线顺序（[[#def-discovery]]、[[#def-licensing]]、[[#def-formulary]]）：靶点与筛选→hERG与遗传毒性（在进入患者之前先清掉特定器官风险的安全药理筛查）→首次人体1期并带占据或靶点抑制标志物（证明药物确实结合它被设计来打的东西）→2b期剂量范围（建立暴露-反应模型并向监管者论证所选剂量）→确证性3期（结局、对照、预注册分析）→带监测的许可（信号检出启动改标签的循环）→评估与目录（你所在医院生活在其中的每一质量调整生命年成本与预算影响决定）。每一阶段的失败模式就是下一阶段的滤网；而特殊路径的捷径要与其补偿义务一起标出（条件性批准附带的确证试验与登记义务）——[[epidemiology-ebm/randomised-trials]]、[[public-health/health-systems-economics]]。**
:::

::: exercise 评价一条标题 {level=2}
“一种新的阿尔茨海默病药物在认知量表上把衰退减慢35%”——列出决定你是否支持采购的问题，以及哪些证据能回答每个问题。
::: solution
**标题评价（[[#def-formulary]]、[[epidemiology-ebm/critical-appraisal]]）：效应——35%是相对哪个基线、哪个量表；该量表的最小临床重要差是否发表；替代终点（淀粉样蛋白下降）对临床终点；试验自身的复合与敏感性分析（计量表之争的文献、功能与照护者负担的次要终点）——[[nervous-system/dementia-neurodegeneration]]。伤害——淀粉样蛋白相关影像异常的发生率、载脂蛋白E基因型的风险分层及其监测需求（磁共振基础设施与抗凝出血的谨慎）、退出率与失访处理——[[genetics/genetic-testing]]、[[clinical-skills/medical-imaging]]。人群——试验的早期病例选择对记忆门诊的现实（排除标准使痴呆试验队列异常健康、合并症与预期寿命的背景）；可及性的公平（谁能早到足以合格、跨中心是否都有生物标志物确证路径）——[[geriatrics-palliative/ageing-frailty]]、[[public-health/determinants-inequalities]]。系统——加速批准之后的确证试验状态；不同效用假设下的每质量调整生命年成本模型；采购决定的机会成本要与其它痴呆服务对照（多数家庭真正使用的是人手与照护），以及向家庭诚实地说明：略微减慢衰退并不等于逆转——[[public-health/health-systems-economics]]、[[clinical-skills/communication]]。**

::: exercise 修订替换规程 {level=2}
你的医院把若干生物制剂与复杂仿制药换成生物类似药或授权仿制以释放预算，涉及阿达木单抗、左甲状腺素、华法林与他克莫司的患者。请设计切换方案。
::: solution
**替换设计（[[#def-formulary]]、[[pharmacology/absorption-distribution]]、[[clinical-skills/patient-safety]]）：按风险归类——窄指数或窄治疗裕度的产品最需谨慎（华法林的国际标准化比值与左甲状腺素的促甲状腺激素在任何产品改变后复查；他克莫司由移植门诊在约定间隔监测浓度，尤其在“封闭系统”的移植专科内切换；生物制剂由负责的专科以疾病活动评分处理，而不是药房一刀切）——[[blood/thrombosis-anticoagulation]]、[[endocrine/thyroid]]、[[immunology/transplant-tumour-immunology]]。沟通包——在切换前由处方者、药师、护士与说明书发出同一信息（反安慰剂的证据强度足以让我们为它设计，而不是对它设计）、一致的命名（厂牌加生物类似药的说明）、无污名的退出选项、按疾病特点安排随访并配量表（皮肤科、风湿科与消化科的切换研究教训：复发更多源于糟糕的沟通而非糟糕的分子）——[[clinical-skills/communication]]、[[musculoskeletal/inflammatory-arthritis]]。可追溯与治理——生物制剂按厂牌处方并记录批号、疗效丧失与注射反应的药物警戒渠道、必要时监测免疫原性（促红素抗体致纯红细胞再生障碍的历史，是“改配方而未警惕”的警示故事）——[[blood/anaemia]]、[[immunology/adaptive-responses]]。评估——省下的钱是否真的流向一线、切换对未切换的结局看板、患者体验指标；以及让下一次切换比这一次更容易的复盘——[[public-health/health-systems-economics]]。**

::: exercise 为可及性的等式辩护 {level=3}
一项卫生技术按每质量调整生命年3万英镑评估后被拒绝；而一座体育场的补贴照办。请就分配问题的两面立论，并提出一份你愿意公开辩护的决策程序。
::: solution
**分配之争（[[#def-formulary]]、[[medical-ethics-law/justice-resources]]、[[public-health/health-systems-economics]]）：一致性之辩——如果卫生系统宣称每质量调整生命年3万英镑是“公款换健康”的汇率，那么拒绝此药却资助健康回报率更差（或毫无健康回报）的活动，不是不公平，就是暴露了阈值只是谈判姿态；透明度的要求（公布汇率、并一致适用于所有与健康相关的支出，包括预防、基础设施与更宽的经济效应）确实有力——[[epidemiology-ebm/measuring-disease]]。多元主义之辩——健康价值不是单维的（若干系统对“严重度与未满足需求”的折价；因患者是残障者就折减其质量调整生命年权重，违反机会平等；今日的贵药是明日的仿制药，而拒绝资助管线有代际成本；罕见病的溢价由谁承担的分配问题——小人群的风险池经济学）；再加一个观察：真实决策永远包含紧迫性、可见性与倡导力量的不对称，质量调整生命年抓不住这些，假装它能抓住只会悄悄腐蚀程序。决策程序——明示并公布（成本效果平面，按规则而非按舆论施加严重度修正）；困难情形保留审议成分（市民小组与患者之声解释“一个质量调整生命年的权重意味着什么”；评估委员的利益规则）；申诉只针对证据而不针对声量；对不确定的评估附加研究条件（“有条件给付并承诺复查”机制）；以及诚实的公共叙事——稀缺是真实的，权衡要么在会议室里做、要么在阳光下做，只有后者能保住信任，而信任本身就是一种健康结局——[[clinical-skills/communication]]、[[public-health/determinants-inequalities]]。**
