几乎所有药物都是通过与体内某种蛋白质结合、改变该蛋白质的功能而起作用的。沙丁胺醇（salbutamol）与气道平滑肌上的受体结合，使平滑肌舒张。奥美拉唑（omeprazole）与胃的质子泵结合，使其停止分泌胃酸。纳洛酮（naloxone）与阿片受体结合后什么作用也不产生，而这恰恰是它能逆转阿片类药物过量的原因：它占据受体，把阿片类药物挡在外面。

药理学的这一部分称为**药效学**（pharmacodynamics），研究药物对机体做了什么。它的核心问题很简单：药物与什么结合？结合得有多牢？结合之后，它是开启靶点、关闭靶点，还是只是停在那里？随着剂量增加，反应如何增长？这些问题的答案解释了为什么有些药物的效应存在上限，为什么一种拮抗药可以被更多的激动药克服而另一种不能，为什么会产生耐受，以及为什么一种药物在某一剂量下安全、在三倍剂量下却可能危险。从[[pharmacology/absorption-distribution]]开始的后续各章讨论本学科的另一半——**药代动力学**（pharmacokinetics），即机体对药物做了什么。

## 药物靶点 {#sec-targets}

大多数药物作用于四类蛋白质之一：受体、离子通道、酶和转运体。少数药物则通过单纯的物理或化学方式起作用：渗透性泻药把水分保留在肠腔内，抗酸药中和胃酸。这些属于例外。

::: definition 受体与四个受体超家族 {#def-families}
**受体**（receptor）是一种能识别特定化学信号（如激素或神经递质）并把结合转化为细胞功能变化的蛋白质。受体分为四个超家族，它们在结构和速度上各不相同。

1. **配体门控离子通道**（离子型受体）。受体本身就是通道，结合后在数毫秒内开放。例如神经肌肉接头处的烟碱型乙酰胆碱受体和脑内的GABA-A受体。
2. **G蛋白偶联受体**（GPCR）。一条多肽链七次跨越细胞膜。结合后在数秒内激活细胞内的G蛋白。$G_s$激活腺苷酸环化酶，升高环磷酸腺苷（cAMP）；$G_i$抑制该酶；$G_q$激活磷脂酶C，升高细胞内钙浓度。肾上腺素受体、毒蕈碱受体、阿片受体和多巴胺受体都是G蛋白偶联受体，约三分之一的上市药物作用于这一家族。
3. **激酶偶联受体**。结合后激活膜内侧的一种酶，通常是酪氨酸激酶。效应在数分钟至数小时内出现，常改变基因表达。胰岛素受体和许多生长因子受体属于此类。
4. **核受体**。位于细胞内。类固醇激素、甲状腺激素和维生素D等脂溶性配体穿过细胞膜与之结合，受体–配体复合物改变靶基因的转录。效应需要数小时至数天。
:::

另外三类靶点在临床上同样重要。不属于受体的**离子通道**，例如电压门控钠通道，可被局部麻醉药以及某些抗癫痫药和抗心律失常药阻滞。**酶**可被血管紧张素转换酶（ACE）抑制药、他汀类、阿司匹林和胆碱酯酶抑制药等药物抑制。**转运体**负责将离子或分子转运过膜：选择性5-羟色胺再摄取抑制药阻断5-羟色胺转运体，袢利尿药阻断髓袢的Na⁺/K⁺/2Cl⁻同向转运体，地高辛（digoxin）抑制Na⁺/K⁺-ATP酶。这些信号通路的生理学见[[cell-biochemistry/signalling-cell-cycle]]和[[physiology/hormones]]。

经G蛋白偶联受体或激酶传递的信号会被**放大**。一个被激活的受体可以激活许多G蛋白，每个G蛋白又驱动一种酶生成大量第二信使分子。正是这种放大，使组织在只有一小部分受体被占据时就能产生最大反应；这一概念将在下文以“受体储备”的形式再次出现。

## 结合：亲和力与占领率 {#sec-binding}

药物的结合通常是可逆的。药物分子不断地与受体结合又解离，达到平衡时结合速率等于解离速率。将质量作用定律应用于这一平衡，可以得到药理学中最有用的方程之一。

::: theorem 占领率与质量作用定律 {#thm-occupancy}
对于可逆地结合于单一类别受体的药物A，平衡时被占据受体的比例为

$$
p = \frac{[A]}{[A] + K_D}
$$ {#eq-occupancy}

其中$[A]$为游离药物浓度，$K_D$为**平衡解离常数**。当$[A] = K_D$时，一半受体被占据。$K_D$越小，**亲和力**越高：占据相同比例的受体所需的药物越少。
:::

::: proof
设受体总浓度为$R_T$，游离受体为$R$，被占据受体为$AR$。正向反应$A + R \to AR$的速率为$k_{+1}[A][R]$，逆向反应的速率为$k_{-1}[AR]$。平衡时二者相等，因此$[A][R]/[AR] = k_{-1}/k_{+1}$，这一比值定义为$K_D$。代入$[R] = R_T - [AR]$，得$[A](R_T - [AR]) = K_D [AR]$。整理得$[AR](K_D + [A]) = [A] R_T$，因此被占据的比例为$[AR]/R_T = [A]/([A] + K_D)$。该曲线是关于$[A]$的直角双曲线；以$\log[A]$为横轴作图时，它变成熟悉的S形曲线，占领率从10%升至90%需要浓度跨越81倍的范围（大约两个对数单位）。
:::

这在临床上有两点重要推论。第一，占领率取决于受体处的*游离*浓度，而不是血浆中的总量，这就是血浆蛋白结合重要的原因（见[[pharmacology/absorption-distribution]]）。第二，这一关系在顶部趋于平坦。浓度从$K_D$升到$3K_D$，占领率从50%升到75%；但从$9K_D$升到$27K_D$，占领率只从90%升到约96%。超过某一点之后，增加药量几乎换不来额外的占领率，只换来额外的脱靶效应。

::: example 剂量加倍能多占据多少受体？ {#ex-occupancy}
某示例性拮抗药对其受体的$K_D = 2$ nmol/L。常规剂量下受体处的游离浓度为6 nmol/L。处方者考虑将剂量加倍，这（假定为线性动力学）使游离浓度加倍至12 nmol/L。加倍前后被占据受体的比例各为多少？
::: solution
应用[[#eq-occupancy]]。

加倍前：$p = 6/(6 + 2) = 0.75$，即75%的受体被占据。

加倍后：$p = 12/(12 + 2) = 0.857$，约86%。

剂量加倍只使占领率增加了11个百分点。如果副作用来自另一个亲和力较低的靶点，浓度加倍可能使*那个*靶点的占领率按比例增加得多得多。这就是临床上常见现象背后的算术：在剂量范围的顶端加量，增加的不良反应多于获益。
:::
:::

## 激动药、拮抗药与内在活性 {#sec-ligands}

结合只是故事的一半。药物结合后，可能激活受体，也可能不激活。药理学把这两种性质区分开来。

::: definition 亲和力、内在活性与配体的类型 {#def-ligands}
**亲和力**（affinity）是药物与受体结合的强度（以$K_D$衡量）。**内在活性**（efficacy，又称效能）是已结合药物激活受体并产生反应的能力。二者彼此独立：一种药物可以有很高的亲和力而完全没有内在活性。

- **完全激动药**结合并激活受体，足以产生该组织所能给出的最大反应。例如：吗啡（morphine）作用于μ阿片受体，沙丁胺醇作用于气道平滑肌的β₂肾上腺素受体。
- **部分激动药**结合并激活受体，但即使完全占据，产生的反应也小于最大反应。例如：丁丙诺啡（buprenorphine）作用于μ阿片受体，伐尼克兰（varenicline）作用于烟碱受体。
- **拮抗药**结合但不激活受体。它本身不产生反应，但阻断激动药的反应。例如：纳洛酮、阿替洛尔（atenolol）、氯沙坦（losartan）。
- **反向激动药**结合后降低受体在无激动药时也存在的活性（**组成性活性**）。许多曾被称为拮抗药的药物，包括若干H₁抗组胺药，在实验系统中表现为反向激动药。
:::

部分激动药具有一种有用的双重性。单独使用时，它适度地刺激受体。在完全激动药存在时，它与之竞争同一受体，反而把反应*降低*到它自身较小的最大值。丁丙诺啡体现了这两个方面。它对呼吸抑制的上限效应使其在阿片类替代治疗中比完全阿片激动药更安全。但若给予体内已有高水平完全激动药的人，它的高亲和力会把该激动药置换下来，反应骤然下降，此人可能出现**催促戒断**。因此，丁丙诺啡只在戒断体征已经出现后才开始使用（[[psychiatry/substance-use]]）。

受体也可以被间接地“阻断”。在**生理性（功能性）拮抗**中，两种药物作用于不同受体，对同一组织产生相反效应。严重过敏反应中的肾上腺素就是经典例子：它并不阻断组胺受体，而是通过刺激α₁和β₂受体使血管收缩、支气管扩张，从而对抗组胺及其他介质的作用（[[emergency-critical-care/anaphylaxis]]）。**化学性拮抗**更简单：拮抗药直接与药物本身结合，例如鱼精蛋白（protamine）结合肝素（heparin）。

::: warning 效价强度不等于效能
一种药物如果以更小的剂量产生某一效应，它的**效价强度**（potency）就更高；如果它的最大效应更大，它的**效能**（efficacy）就更高。芬太尼（fentanyl）的效价强度远高于吗啡，但二者都是完全激动药，最大效应相同，因此“效价更强”在任何有临床意义的层面上都不等于“作用更强”。姑息治疗中使用的等效镇痛剂量表之所以能在不同药物之间换算剂量，正是因为它们的效价强度不同而效能相同。临床上更好的药物通常是效能更高、选择性更好或药代动力学更好的药物，而不仅仅是效价强度更高的药物。
:::

## 剂量–反应曲线 {#sec-curves}

如果在单一组织或单个人身上测量一系列激动药浓度下的反应，得到的是**量反应**型剂量–反应曲线。如果在一个群体中记录某个固定的全或无效应（如“癫痫发作停止”或“死亡”），得到的是**质反应**曲线。二者各有用途。

::: definition 量反应与质反应的剂量–反应关系 {#def-curves}
**量反应**曲线描述在一个系统中浓度与反应大小之间的关系，通常用**希尔方程**（Hill equation）表示：

$$
E = \frac{E_{\max}\,[A]^{n}}{EC_{50}^{\,n} + [A]^{n}}
$$ {#eq-hill}

其中$E_{\max}$为最大反应（衡量效能），$EC_{50}$为产生一半最大反应的浓度（衡量效价强度），$n$为**希尔系数**，决定曲线的陡度。$n = 1$时，曲线形状与[[#eq-occupancy]]相同。

**质反应**曲线以群体中出现某一规定效应的百分比对剂量作图。其中点为**ED₅₀**（对50%受试者有效的剂量）；对毒性效应而言为**TD₅₀**，在动物研究中为**LD₅₀**。**治疗指数**为

$$
TI = \frac{TD_{50}}{ED_{50}}.
$$ {#eq-ti}

治疗指数低的药物，如地高辛、锂盐、华法林（warfarin）、庆大霉素（gentamicin）或苯妥英（phenytoin），有益剂量与有害剂量之间的距离很小，通常需要监测。
:::

剂量–反应曲线几乎总是以剂量或浓度的对数作横轴。在对数坐标上，双曲线变成对称的S形曲线，中段近乎直线，效价强度的变化表现为曲线横向平移而形状不变。下图展示了几种主要模式。

::: widget plot
f: 100/(1+10^(-x)); 40/(1+10^(-x)); 100/(1+(1+B)*10^(-x)); 100*p/(1+10^(-x))

y: 0, 105

caption: 简化的对数浓度–反应曲线，浓度以激动药$EC_{50}$的倍数表示（因此$x = 0$即$EC_{50}$）。移动$B$（竞争性拮抗药浓度，以其$K_B$的倍数表示）：曲线右移$\log_{10}(1+B)$，但达到相同的最大值。移动$p$（不可逆拮抗药作用后剩余受体的比例）：最大值下降。这一示例模型忽略了受体储备；在真实组织中，受体储备会推迟最大值的下降。
:::

希尔系数的意义比它抽象的外表所暗示的更大。陡峭的曲线（$n > 1$）意味着浓度的微小变化就能从几乎无效跨到接近最大效应。神经肌肉阻滞药和许多麻醉药的曲线都很陡，这是它们需要如此谨慎地滴定和监测的原因之一。

::: example 解读治疗指数 {#ex-ti}
在一项关于某新型抗惊厥药的示例性动物研究中，消除癫痫发作的ED₅₀为8 mg/kg，引起严重镇静的TD₅₀为120 mg/kg。第二种药物的ED₅₀为5 mg/kg，TD₅₀为20 mg/kg。计算两者的治疗指数并加以评论。
::: solution
由[[#eq-ti]]：药物1的$TI = 120/8 = 15$；药物2的$TI = 20/5 = 4$。

药物2的效价强度更高（ED₅₀更低），但安全范围更小。不过，治疗指数只比较了两条曲线的中点。如果毒性曲线较平缓，有些个体在远低于TD₅₀的剂量下就会受到伤害。更谨慎的比较采用TD₁/ED₉₉之类的比值，即对1%受试者有害的剂量除以对99%受试者有效的剂量。在人体中，实际对应的概念是**治疗窗**：与获益相关而无不可接受毒性的血浆浓度范围，这是[[pharmacology/dosing-principles]]中药物监测的基础。
:::
:::

### 受体储备

在许多组织中，激动药只占据一部分受体时就能产生最大反应。未被占据的受体称为**储备受体**，这一现象称为**受体储备**。它源于信号放大：一旦足够多的受体被激活、使下游某一步骤达到饱和，再多的激活也不会增加反应。

受体储备有三点实际后果。第一，完全激动药的EC₅₀低于其$K_D$；药物在组织中显得比单凭结合所提示的更强效。第二，不可逆拮抗药起初使激动药曲线右移，只有在储备耗尽后才压低最大值。第三，一种药物表现为完全激动药还是部分激动药，部分取决于组织。内在活性中等的药物，在受体储备大的组织中可产生完全反应，在受体很少的组织中则只产生部分反应。这是同一种β激动药对气道肌和心肌效应不同的原因之一。

## 拮抗作用 {#sec-antagonism}

拮抗药是使用最广泛的药物之一：β受体阻滞药、血管紧张素受体阻滞药、抗组胺药、抗精神病药（主要是多巴胺D₂拮抗药）和阿片受体拮抗药。它们如何阻断很重要，因为这决定了阻断能否被克服。

::: theorem 竞争性拮抗与剂量比 {#thm-schild}
**竞争性（可克服的）拮抗药**与激动药可逆地结合于同一位点。在其存在下，激动药的浓度–反应曲线平行右移，最大值不变。右移的幅度称为**剂量比**（DR）：为获得相同反应，激动药浓度必须增加的倍数。对于浓度为$[B]$、解离常数为$K_B$的单纯竞争性拮抗药，加德姆–席尔德（Gaddum–Schild）方程给出

$$
DR = 1 + \frac{[B]}{K_B}.
$$ {#eq-schild}

在对数轴上，曲线右移$\log_{10}(DR)$。拮抗药的**pA₂**是使剂量比等于2的浓度的负对数；对于单纯竞争性拮抗药，它等于$-\log_{10} K_B$。
:::

::: proof
激动药A与拮抗药B竞争同一受体，对二者都应用质量作用定律，可得A的占领率为

$$
p_A = \frac{[A]}{[A] + K_D\left(1 + [B]/K_B\right)}.
$$

这就是把[[#eq-occupancy]]中的$K_D$乘以$1 + [B]/K_B$。如果反应只取决于$p_A$，那么无拮抗药时在激动药浓度$[A]$下得到的任何反应，在有拮抗药时需在$[A]\,(1 + [B]/K_B)$下才能得到。这个倍数就是剂量比。由于当$[A]$很大时$p_A$的最大值仍为1，最大反应不变。
:::

**不可逆拮抗药**以共价键结合，或解离极慢，实际上相当于永久结合。增加激动药无法将其置换，因此一旦受体储备耗尽，最大反应就会下降。恢复需要新的受体或酶蛋白。酚苄明（phenoxybenzamine）用于嗜铬细胞瘤术前准备，不可逆地阻断α肾上腺素受体。阿司匹林使血小板中的环氧合酶-1乙酰化；由于血小板没有细胞核、不能合成新的酶，这一效应持续到血小板寿命终结，约7至10天。奥美拉唑及其他质子泵抑制药与质子泵共价结合，这就是为什么一个血浆半衰期约一小时的药物能抑制胃酸长得多的时间。

**非竞争性拮抗药**作用于与激动药不同的位点，或阻断受体之后的某个步骤，因此也压低最大值。其中许多作用于**变构**位点（见下文）。

::: example 克服β受体阻滞药 {#ex-beta-block}
一名64岁加勒比裔女性因心绞痛服用比索洛尔（bisoprolol），因一次快速、耐受不良的快速性心律失常入院，后来发现她服用的β受体阻滞药远多于处方量。她血压低，心率38次/分。请用[[#thm-schild]]解释为什么可能需要大剂量的β激动药，以及为什么要同时使用其他治疗。
::: solution
比索洛尔是竞争性β₁拮抗药。在高浓度下，$[B]/K_B$很大，因此剂量比很大：任何β激动药（内源性去甲肾上腺素和肾上腺素，或静脉给予的药物）的曲线都被大幅右移。原则上这种阻断是可克服的，足够高的激动药浓度可以恢复反应；但实际所需的剂量可能非常大，并引起其他效应。

因此，临床处理还使用完全绕过β受体的药物，这体现了生理性拮抗。胰高血糖素（glucagon）通过其自身的$G_s$偶联受体升高心肌中的cAMP；大剂量胰岛素联合葡萄糖可改善心肌的能量利用。疑似过量的处理遵循现行毒理学建议（在英国为TOXBASE和国家毒物信息服务），细节见[[emergency-critical-care/poisoning]]。
:::
:::

::: example 计算剂量比 {#ex-dose-ratio}
在一项离体组织实验中，加入浓度为45 nmol/L、$K_B = 5$ nmol/L的竞争性拮抗药。(a) 为恢复原来的反应，激动药浓度须增加多少倍？(b) 曲线右移多少个对数单位？(c) 多大的拮抗药浓度会使剂量比为2？
::: solution
(a) 由[[#eq-schild]]，$DR = 1 + 45/5 = 10$。激动药浓度须增加10倍。

(b) 右移$\log_{10} 10 = 1$个对数单位。

(c) $DR = 2$要求$[B]/K_B = 1$，因此$[B] = K_B = 5$ nmol/L。pA₂为$-\log_{10}(5\times10^{-9}) \approx 8.3$。
:::
:::

### 变构调节药

**变构调节药**结合于受体上不同于激动药结合位点（正构位点）的部位，改变受体对其天然配体的反应。**正性变构调节药**增强激动药的效应，负性变构调节药则减弱之。苯二氮䓬类是临床上最著名的例子。它们结合于GABA-A受体α与γ亚基的交界处，增强GABA的作用，增加通道开放的频率。在没有GABA时它们几乎不起作用，这是苯二氮䓬类单用时比巴比妥类更少引起致命性呼吸抑制的原因之一，但与酒精、阿片类或其他中枢抑制药合用时风险会急剧上升。氟马西尼（flumazenil）是苯二氮䓬结合位点的竞争性拮抗药。用于甲状旁腺功能亢进症的西那卡塞（cinacalcet）是钙敏感受体的正性变构调节药，使甲状旁腺细胞的反应如同血钙更高一样（[[endocrine/bone-calcium]]）。

::: quiz
在离体组织上先单独测试一种新的激动药，再在某种未知拮抗药的固定浓度存在下测试。有拮抗药时曲线右移，与原曲线平行，并达到相同的最大值。无论拮抗药暴露5分钟还是60分钟后洗脱，右移幅度都相同。哪种拮抗药最能解释这一结果？
- [x] 作用于激动药结合位点的可逆性竞争性拮抗药
- [ ] 在无受体储备组织中的不可逆拮抗药
- [ ] 降低内在活性的负性变构调节药
- [ ] 作用于不同受体的生理性拮抗药
::: solution
平行右移且最大值不变是竞争性、可克服拮抗的特征（[[#thm-schild]]）。在无受体储备组织中的不可逆拮抗药会压低最大值。降低内在活性的负性变构调节药同样压低最大值。生理性拮抗药通过另一条通路对抗反应，通常改变曲线的形状和最大值，而不是产生干净的平行移动。
:::
:::

## 反应随时间的变化 {#sec-regulation}

对药物的反应不是固定不变的。受体不断地被合成、转移和降解，细胞会对持续的刺激或阻断作出调整。

::: definition 脱敏、耐受与受体调节 {#def-tolerance}
**脱敏**（desensitisation，又称**快速耐受**，tachyphylaxis）是在持续或反复接触激动药数分钟内出现的反应丧失。**耐受**（tolerance）是在数天至数周内逐渐出现的反应降低，需要更大的剂量才能获得同样的效应。其机制包括：

- **受体脱偶联与内化**：被激活的G蛋白偶联受体被G蛋白偶联受体激酶磷酸化后，β-抑制蛋白（β-arrestin）得以结合，阻断G蛋白偶联，并导致受体从膜上移除；
- **下调**：在持续刺激下合成的受体减少或降解的受体增多；**上调**则是对持续阻断的相反反应；
- **介质耗竭**，例如间接作用的拟交感药所释放的储存去甲肾上腺素被耗尽；
- **药代动力学耐受**，即药物诱导自身代谢（卡马西平（carbamazepine）即为一例）；
- **生理性适应**，即稳态机制对抗药物的效应。
:::

这些机制解释了若干实用规则。持续服用有机硝酸酯的患者在数天内丧失抗心绞痛效应，因此长效硝酸酯的处方安排为每天有一段低硝酸酯间期。规律大量使用短效β₂激动药会下调气道β₂受体，并提示哮喘控制不佳（[[respiratory/asthma-copd]]）。长期使用β受体阻滞药后β受体数量增加；突然停药时，更多的受体暴露于正常水平的儿茶酚胺之下，可出现反跳性心动过速、高血压或心绞痛。因此，长期治疗通常应逐渐停药。阿片类药物对镇痛和呼吸抑制产生耐受，但对便秘和瞳孔缩小的耐受要弱得多，这就是长期服用阿片类药物的人便秘持续存在的原因。

**依赖**是一个相关但不同的概念：对药物的适应变成正常功能所必需，因此停药会产生戒断综合征，其表现通常与药物的急性作用相反。

::: example 失效的纳洛酮 {#ex-naloxone}
一名31岁男性被发现时嗜睡，呼吸频率6次/分，瞳孔针尖样。静脉注射纳洛酮后两分钟内他有反应并清醒过来。45分钟后，他再次嗜睡、呼吸缓慢。在他身边发现的包装提示他服用了一种长效阿片类药物。请用受体和时程原理解释所发生的情况。
::: solution
纳洛酮是μ阿片受体的竞争性拮抗药，亲和力高、无内在活性。静脉给药后它迅速置换阿片类药物，激动药的占领率下降，呼吸和意识恢复。由于拮抗是竞争性的，结局取决于两种药物在受体处的相对浓度（[[#thm-schild]]）。

纳洛酮作用时间短（静脉给药后其效应通常持续约20至90分钟），而美沙酮（methadone）或缓释制剂等长效阿片类药物在体内停留许多小时。随着纳洛酮浓度下降，$[B]/K_B$下降，剂量比缩小，残留的阿片类药物再次占据足够多的受体，抑制呼吸。这种**再麻醉化**正是接受纳洛酮治疗的人需要留观、可能需要重复给药或持续输注、以及所涉阿片类药物种类很重要的原因。处理遵循现行地方和国家指南（[[emergency-critical-care/poisoning]]）。

快速逆转本身也有风险：对阿片类药物依赖的人，大剂量纳洛酮可诱发急性戒断。通常的原则是小剂量滴定至呼吸充分，而不是滴定至完全清醒。
:::
:::

## 选择性与临床效应的格局 {#sec-selectivity}

没有任何药物是完全特异的。**选择性**描述的是一种偏好，通常以药物对目标靶点的亲和力与对其他靶点亲和力之比表示。选择性总是相对的，且依赖剂量：比索洛尔这样的“β₁选择性”阻滞药在较高浓度下也会阻断β₂受体，这就是哮喘患者使用β受体阻滞药需谨慎的原因。

一旦知道了某药物全部靶点的清单，许多不良反应都是可以预测的。三环类抗抑郁药除了作用于单胺转运体外，还阻断毒蕈碱受体、组胺H₁受体和α₁肾上腺素受体，这解释了它们引起的口干、镇静和体位性低血压；高浓度时它们阻断心肌钠通道，这就是它们过量时危险的原因。许多抗精神病药既阻断中脑边缘通路的D₂受体，也阻断纹状体的D₂受体，从而引起运动障碍。识别这些模式是[[pharmacology/adverse-reactions]]中不良反应分类的基础。

::: history
受体的概念在二十世纪初从两个方向产生。在剑桥研究烟碱和箭毒对骨骼肌作用的兰利（John Newport Langley）于1905年提出，肌细胞上存在一种能与这些药物结合的“接受物质”。研究染料和抗微生物化学物质的埃尔利希（Paul Ehrlich）发展了他的侧链学说，并以一句话概括之：*corpora non agunt nisi fixata*，即物质不结合就不起作用。克拉克（Alfred Joseph Clark）在二十世纪二三十年代把质量作用定律应用于药物–受体结合，得出了本章所用的占领率方程。1948年，阿尔奎斯特（Raymond Ahlquist）根据一系列激动药的效价顺序将肾上腺素受体分为α和β两型；二十世纪五十年代，阿里恩斯（Everhardus Ariëns）和斯蒂芬森（Robert Stephenson）把亲和力与内在活性区分开来，提出了内在活性和储备受体的概念。席尔德（Heinz Otto Schild）在二十世纪四十年代末发展了竞争性拮抗的定量分析。在受体被分离和克隆之前，它们在很大程度上停留在理论层面；莱夫科维茨（Robert Lefkowitz）和科比尔卡（Brian Kobilka）因对G蛋白偶联受体的研究（包括β₂肾上腺素受体与其G蛋白结合的晶体结构）共同获得2012年诺贝尔化学奖。
:::

::: summary
- 大多数药物作用于受体、离子通道、酶或转运体。受体分为四个超家族：配体门控离子通道、G蛋白偶联受体、激酶偶联受体和核受体。
- 占领率遵循质量作用定律：$p = [A]/([A]+K_D)$。亲和力（$K_D$）与内在活性是两种独立的性质。
- 完全激动药产生最大反应，部分激动药的上限较低，拮抗药不产生反应，反向激动药降低组成性活性。部分激动药在完全激动药存在时可起拮抗作用。
- 效价强度（EC₅₀）不等于效能（Eₘₐₓ）。治疗指数TD₅₀/ED₅₀衡量获益与伤害之间的距离；治疗指数低的药物需谨慎使用，常需监测。
- 竞争性拮抗药使曲线平行右移，剂量比为$1 + [B]/K_B$；不可逆拮抗药和非竞争性拮抗药压低最大值。受体储备会改变这两种情况。
- 脱敏、耐受、下调和上调解释了硝酸酯耐受、β受体阻滞药停药后的反跳，以及许多药物需要逐渐停用的原因。
:::

## 习题

::: exercise 给定浓度下的占领率 {level=1 check="80"}
某药物与其受体可逆结合，$K_D = 10$ nmol/L。当游离药物浓度为40 nmol/L时，被占据受体的百分比是多少？结果取整数。
::: hint
应用$p = [A]/([A] + K_D)$，再换算为百分比。
:::
::: solution
$p = 40/(40 + 10) = 0.8$，因此80%的受体被占据。
:::
:::

::: exercise 判断配体类型 {level=1}
根据下列描述说出配体的类型：(a) 结合于β₂肾上腺素受体，产生该组织所能给出的最大支气管扩张；(b) 结合于μ阿片受体，单独使用时产生一定镇痛作用，与吗啡同时存在时则减弱吗啡的效应；(c) 结合于H₁受体，使其活性降低到低于完全没有配体时的水平；(d) 结合于血管紧张素AT₁受体，不产生反应，但阻断血管紧张素II的效应。
::: solution
(a) 完全激动药。(b) 部分激动药：它本身有内在活性，但小于吗啡，因此与完全激动药竞争时会降低反应。(c) 反向激动药：它降低受体的组成性（不依赖激动药的）活性。(d) 拮抗药（实际上是竞争性拮抗药；氯沙坦即为一例）。
:::
:::

::: exercise 效价强度还是效能？ {level=1}
药物X使血压最大下降20 mmHg，ED₅₀为2 mg。药物Y使血压最大下降35 mmHg，ED₅₀为50 mg。哪种药物效价强度更高？哪种效能更高？对于血压高出目标值40 mmHg的人，在二者之间选择时哪种性质更重要？
::: solution
X的效价强度更高（ED₅₀更低）。Y的效能更高（最大效应更大）。对于需要大幅降压的人，效能更重要：X无论用多大剂量都不能使血压下降超过20 mmHg，而Y可以。毫克剂量较大本身并不是缺点。
:::
:::

::: exercise 曲线的移动 {level=2 check="2"}
某竞争性拮抗药的$K_B = 1$ nmol/L。某患者受体处的游离浓度为99 nmol/L。激动药浓度–反应曲线右移多少个对数单位？给出准确的整数。
::: hint
先求剂量比，再取其以10为底的对数。
:::
::: solution
$DR = 1 + 99/1 = 100$。右移$\log_{10} 100 = 2$个对数单位：为获得相同反应，激动药浓度须增加100倍。
:::
:::

::: exercise 部分激动药的实际应用 {level=2}
一名45岁女性每天使用非法海洛因，准备开始丁丙诺啡阿片类替代治疗。请用受体理论解释为什么首剂通常要推迟到她出现客观戒断体征之后，以及为什么单独服用时丁丙诺啡引起致命性呼吸抑制的风险低于美沙酮。
::: solution
丁丙诺啡是μ阿片受体的高亲和力部分激动药。如果在海洛因（及其活性代谢物，主要是吗啡）仍占据许多受体时给药，它会因高亲和力而置换完全激动药，但产生的受体激活较少。净效应骤然下降，引起催促戒断。等到戒断已经开始，被完全激动药占据的受体很少，此时丁丙诺啡会增加而不是减少净效应。

由于其内在活性有限，它引起的呼吸抑制随剂量增加而趋于平台（上限效应）。美沙酮是完全激动药，没有上限。这种保护是相对的：与苯二氮䓬类、加巴喷丁类或酒精等其他抑制药合用时，丁丙诺啡仍可促成致命性呼吸抑制。
:::
:::

::: exercise 为什么阿司匹林的作用比其半衰期长 {level=2}
阿司匹林的血浆半衰期约15至20分钟，但单次剂量即可使血小板聚集减弱数天，外科医生也常要求在某些手术前一周评估抗血小板药物。请用所涉及的拮抗类型解释这一点，并预测对于布洛芬（ibuprofen）这类可逆性环氧合酶抑制药，恢复所需的时间会怎样变化。
::: solution
阿司匹林使血小板环氧合酶-1活性位点上的一个丝氨酸残基乙酰化，这是不可逆的共价修饰。血小板没有细胞核，不能合成新的酶，因此每个受影响的血小板在其余生中都处于被抑制状态。功能只有在骨髓释放新的血小板后才能恢复；血小板寿命约7至10天，每天约有十分之一的血小板被更新。效应持续时间由靶点更新决定，而不是由药物半衰期决定。

布洛芬可逆、竞争性地抑制环氧合酶，因此其抗血小板作用随血浆浓度下降而减弱，在一天之内基本消失。（在阿司匹林之前不久服用布洛芬，还可阻止阿司匹林接近该酶，这一相互作用值得了解。）术前是否停用抗血小板药物，取决于地方围手术期指南以及当初使用该药的原因。
:::
:::

::: exercise 陡度与安全性 {level=3 check="round(100*0.5^4/(0.5^4+1))"}
两种药物产生毒性效应的EC₅₀相同，但希尔系数不同，分别为$n = 1$和$n = 4$。应用[[#eq-hill]]，以最大值的百分比表示毒性反应，计算$n = 4$的药物在EC₅₀一半浓度时的毒性反应（取最接近的整数百分比），并与$n = 1$的药物比较。这对在毒性范围附近给药意味着什么？
::: hint
把$[A] = 0.5\,EC_{50}$代入希尔方程：$E/E_{\max} = 0.5^n/(0.5^n + 1)$。
:::
::: solution
对于$n = 4$：$E/E_{\max} = 0.0625/(0.0625 + 1) = 0.0588$，约**6%**。

对于$n = 1$：$E/E_{\max} = 0.5/1.5 = 0.333$，约33%。

在毒性EC₅₀的一半浓度处，陡峭曲线几乎不显示毒性，而平缓曲线已显示出最大毒性效应的三分之一。但陡峭曲线上升得很快：在$2\,EC_{50}$时，$n = 4$的药物产生最大毒性反应的$16/17 \approx 94\%$，而$n = 1$的药物为67%。因此，陡峭的毒性曲线意味着从表面安全到严重中毒的过渡很窄。浓度的小幅上升，例如由于相互作用或肾功能下降，可能在几乎没有预兆的情况下引起突然中毒，这就是此类药物需要小步滴定并加以监测的原因。
:::

::: exercise 解释耐受与反跳 {level=3}
一名58岁男性因特发性震颤和高血压服用普萘洛尔（propranolol）十年。他在国外时药物用完，两天后出现心悸和劳力性胸闷。一个月前，他开始每天上午8点和晚上8点各服用一次单硝酸异山梨酯（isosorbide mononitrate），并说第一周之后心绞痛缓解的效果似乎减退了。请用受体调节解释这两种现象，并概述预防每个问题的原则。
::: solution
**停用β受体阻滞药后的反跳。**长期阻断β肾上腺素受体导致上调：细胞因刺激减少而增加受体数量。突然停用普萘洛尔后，其浓度在一天左右下降，正常循环中的儿茶酚胺此时作用于比治疗前更多的受体。心率、心肌收缩力和心肌耗氧量上升，在冠心病患者中可诱发心绞痛或心律失常。原则是在可能时逐渐停用长期使用的β受体阻滞药，并保证药物供应的连续性（例如出行前的建议）。

**硝酸酯耐受。**持续接触有机硝酸酯会在数天内产生耐受。已提出的机制包括硝酸酯生物转化为一氧化氮的过程受损、氧化应激以及反调节性神经体液变化。间隔十二小时的每日两次给药造成持续暴露。原则是采用不对称给药方案（例如普通制剂在上午和下午早些时候给药，或每日一次的缓释制剂），使每天有一段低硝酸酯期，通常在夜间。处方细节遵循英国国家处方集（BNF）和地方指南。他的新症状需要临床评估，而不是简单地加量。

::: exercise 设计一个受体实验 {level=3}
某研究小组有一种新化合物，他们认为它是组胺H₂受体的竞争性拮抗药。他们可以测定离体胃腺对组胺的胃酸分泌反应。请描述一个实验及你预期的结果，用以 (a) 判断拮抗是否为竞争性，(b) 估计$K_B$。什么结果会提示它是不可逆拮抗药？
::: solution
(a) 分别在单独组胺以及在该化合物几个固定浓度（例如跨越十倍或更大范围的三个浓度）存在下，构建完整的组胺浓度–反应曲线，每个浓度都留出达到平衡的时间。竞争性拮抗预测曲线平行右移、最大值不降低，且拮抗药浓度越高右移越大。洗脱后效应应可逆转。

(b) 对每个拮抗药浓度，在相同反应水平（例如最大值的50%）测定剂量比。以$\log(DR - 1)$对$\log[B]$作图，即席尔德图。对于单纯竞争性拮抗，得到斜率为1的直线，其在$\log[B]$轴上的截距为$\log K_B$（等价地，由[[#eq-schild]]，在任一单一浓度下$K_B = [B]/(DR - 1)$）。斜率明显偏离1提示拮抗并非单一位点上的单纯竞争。

不可逆拮抗药在低浓度时会使曲线右移（在受体储备尚存时），在较高浓度时则使最大值下降，且洗脱后不能恢复。恢复需要合成新的受体。
:::
