药物与受体的相互作用是每一张处方底下的物理学：**一个分子遇见一个蛋白，按亲和力可逆结合，占据一部分受体；临床效应取决于占据率、内在活性、储备受体，以及结合与反应之间的下游放大——直到耐受、脱敏与遗传变异在某个具体患者身上改写规则。**药效学（药物做什么）是效价、选择性、拮抗、激动与剂量-反应陡峭度变成“选药选量”实用工具的地方。

本章覆盖受体家族与信号、从激动剂到偏向性激动剂的配体、剂量-反应的数学、选择性与脱靶效应的决定因素，以及包括耐受在内的反应调节。

## 受体家族

::: definition 靶点及其机器 {#def-families}
**四个以上的家族及其临床化身。配体门控离子通道以毫秒计：烟碱型乙酰胆碱受体、γ-氨基丁酸A、NMDA、甘氨酸与5-羟色胺3，以及神经肌肉接头的烟碱受体；亚基组成决定敏感性（α1对α2/3，即镇静对抗焦虑的设计规划）——[[physiology/membrane-potentials]]、[[physiology/synapses]]、[[surgery/anaesthesia-pain]]。G蛋白偶联受体以秒计：七次跨膜超家族，配Gs、Gi、Gq与G12/13模块；晶体学时代的“活性结构基础”与纳米抗体复合物，β肾上腺素受体、阿片、毒蕈碱与多巴胺受体及其药物帝国——[[pharmacology/autonomic-drugs]]、多巴胺受体见[[nervous-system/movement-disorders]]。**
激酶与核受体以分钟到小时计：受体酪氨酸激酶（胰岛素、胰岛素样生长因子、表皮生长因子受体、HER2、Trk，以及细胞因子相关的JAK-STAT，构成小分子抑制药的帝国）与核受体超家族（类固醇、甲状腺、类固醇样的维生素D与维甲酸、PPAR、LXR与FXR，配体诱导的转录复合物及辅激活-辅抑制因子的交换）——[[cell-biochemistry/signalling-cell-cycle]]、[[endocrine/reproductive-endocrinology]]。转运体、同工酶与酶作为靶点：SLC与ABC转运体（5-羟色胺、去甲肾上腺素与多巴胺转运体及其药物——选择性5-羟色胺再摄取抑制药、三环类、可卡因与苯丙胺；SGLT2抑制药；以及OCT、P-糖蛋白与血脑屏障载体）——[[cell-biochemistry/membranes-transport]]。酶类靶点：血管紧张素转换酶、环氧合酶、激酶、胆碱酯酶、碳酸酐酶、黄嘌呤氧化酶、二氢叶酸还原酶、胸苷酸合成酶与细菌转肽酶；酶抑制药常为不可逆或紧密结合，而靶标的更新速率决定作用时长（阿司匹林与血小板寿命、单胺氧化酶抑制药数周的恢复）——[[pharmacology/drug-development-prescribing]]。**
再加上非受体的生态位：抗凝药经抗凝血酶起作用（肝素的五糖诱导构象改变，是一首变构的炫技曲）；锂与肌醇及GSK3的奇事；以及渗透性与物理性制剂的提醒——并非每个药物都需要一个蛋白靶点——[[blood/haemostasis-bleeding]]。**
:::

## 配体与反应

::: definition 亲和力、内在活性与拮抗 {#def-ligands}
**把词汇画成图：占据率对效应；亲和力Kd与效价EC50之别；拮抗剂的pA2；为何EC50同时随亲和力与体系因素移动；以及治疗指数、治疗窗与治疗裕度的定义——[[pharmacology/dosing-principles]]。内在活性连续谱：完全激动剂常无需100%占据即达最大效应——储备受体的概念解释了部分激动剂为何能给反应设上限；内在活性可量化。临床推论是吲哚洛尔、丁丙诺啡与阿立哌唑：上限效应、在内源性张力高时“翻转”为拮抗——丁丙诺啡的促发戒断机制，与阿立哌唑“多巴胺稳定剂”的表述——[[psychiatry/substance-use]]。**
**拮抗的类型（临床版）：竞争性、可超越——曲线平行右移，加大激动剂即可克服（普萘洛尔对肾上腺素的右移；氟马西尼与纳洛酮的竞争性救援，在长期使用者身上自带毒性风险）；非竞争性、不可超越——最大效应被压低（酚苄明的不可逆α阻断与阿司匹林的共价环氧合酶1抑制是原型，恢复速度由受体或血小板更新决定）；药理性拮抗——不同受体作用于同一生理（过敏性休克中组胺对肾上腺素；血管紧张素II对容量）；功能性拮抗——下游对抗（皮质醇、胰高血糖素与肾上腺素对胰岛素的反调节）——[[immunology/hypersensitivity]]、[[endocrine/diabetes-complications]]。变构革命：正变构调节剂与负变构调节剂，带探针依赖性与可饱和的协同性（唑吡坦类对苯二氮位点α1亚基的选择性、AMPA调节剂规划、代谢型谷氨酸2/3辅助治疗的试验记录）；配体导向的偏向性激动（β-arrestin招募的信号对G蛋白通路；G蛋白偏向性μ阿片激动剂的希望及其3期结果的参差，是“不要过度解读信号偏向”的一课）；以及避开内源性配体峰值竞争的变构途径（CCR5进入抑制药马拉维若；作为钙敏感受体正变构调节剂的西那卡塞）——[[cardiovascular/circulation-blood-pressure]]、[[endocrine/bone-calcium]]。**
反向激动剂与组成型活性：**受体在没有配体时也在发放信号，反向激动剂可压制基础张力——这是“拮抗剂阻断配体结合”与“反向激动剂移动平衡”的区分；β-咔啉类的部分反向激动，氟马西尼的弱反向行为；只有在组成型活性的检测系统中才能测到反向激动。组成型活性突变的疾病：黄体生成素受体激活导致的性早熟、Gsα的McCune-Albright综合征、以及促甲状腺激素受体引起的非促甲状腺激素依赖性甲状腺功能亢进——[[genetics/non-mendelian-inheritance]]、[[endocrine/thyroid]]、[[endocrine/reproductive-endocrinology]]。**
:::

## 曲线及其临床解读

::: definition 剂量-反应的数学 {#def-curves}
**每一次剂量决定都活在两条曲线之间。量效曲线：浓度-反应呈双曲，有最大效应、EC50与Hill斜率（协同性的陡度）；对数坐标下呈S形，而“阈值不过是图形约定”；竞争性拮抗的Schild分析与pA2；受体克隆时代的亲和力光谱。量反应（群体）曲线：ED50、TD50、治疗指数的比值，以及“治疗窗”与“毒性斜率陡峭时的安全裕度”——地高辛、锂与华法林这些窄指数药物的实践推论——[[pharmacology/dosing-principles]]、[[pharmacology/patient-variation]]。**
效价与内在活性的临床区别：**为何存在“吗啡10 mg对哌替啶100 mg”的等效表；为何部分激动剂无论加多少都有上限（镇痛与精神拟似的上限教训）；为何具内在拟交感活性的β阻滞剂在心梗后被回避；以及“等效表是给药方案学，不是优劣排序”——[[surgery/anaesthesia-pain]]。信号放大解释了储备受体：G蛋白级联以秒计、第二信使扩散、激酶级联可放大千倍，故10%的占据即可给出最大反应（异丙肾上腺素的环磷酸腺苷累积使曲线左移；“储备受体”的耐受逻辑）——[[cell-biochemistry/signalling-cell-cycle]]、[[physiology/membrane-potentials]]。激动剂节省与致敏的两个对立面：慢性阻断后的上调（β阻滞剂反跳的高血压与心绞痛机制要诚实地读）对腺苷受体上调与咖啡因头痛的遗产（镇痛药过度使用所致反跳头痛作为系统药理）——[[nervous-system/headache-pain]]、[[cardiovascular/hypertension]]。**
超敏状态：瞳孔试验的遗产、左旋多巴致敏的间断刺激概念、抗精神病药撤药后的超敏性精神病，以及迟发性运动障碍背后的多巴胺受体适应——[[nervous-system/movement-disorders]]、[[psychiatry/treatments-mental-health-law]]。耐受机制按部位分类：**药动学耐受（代谢诱导：卡马西平的自我诱导；酒精耐受中的代谢适应成分）；药效学耐受（受体减少：激动剂诱导的内吞——规律使用β2激动剂的下调、苯二氮受体脱耦联、阿片受体的脱敏与再循环，与纳洛酮的急性逆转不同）；学习与行为补偿；反向耐受与致敏（点燃现象与兴奋剂致敏；酒精与苯二氮的交叉耐受及双向的戒断危险）；以及快速耐受（酪胺与麻黄碱因去甲肾上腺素贮备耗竭而快速耐受）——[[psychiatry/substance-use]]、[[pharmacology/metabolism-excretion]]、[[respiratory/asthma-copd]]。**
:::

::: example 不平等的等效 {#ex-opioid-equivalence}
一位日服口服吗啡60 mg的患者因恶心被换成“等效”芬太尼贴；两天后意识混乱、镇静，空气下血氧89%。所用的换算表取1比2.5，且未做安全减量。
::: solution
**等效表的“平等”幻觉（[[#def-curves]]、[[pharmacology/dosing-principles]]、[[surgery/anaesthesia-pain]]）：表为何误导——交叉耐受不完全，因此阿片轮换在设计上就需减量25%至50%；而效价比来自轻度疼痛、短效、阿片未耐受人群的推算，却被外推到重度慢性疼痛。口服吗啡对经皮芬太尼的比值随体重、出汗与脂肪而变；加热垫与发热会加速释放，这段历史有它自己的黑框警告——[[pharmacology/patient-variation]]、[[emergency-critical-care/poisoning]]。芬太尼贴的物理——皮肤储库与缓慢消退（移除后半衰期12至24小时，这解释了为何救援纳洛酮需要输注或重复给药、而不是安瓿一支）；贴剂不适合不稳定的疼痛、阿片未耐受者与发热者；黏膜、经皮与鼻用的滥用流行病学要在临床上说清楚。代谢物的方向——吗啡-6-葡萄糖醛酸在肾功能不全时蓄积；芬太尼无活性代谢物；美沙酮的QT间期延长与15至60小时的累积半衰期；丁丙诺啡的部分激动上限与促发戒断风险及其独特的轮换规则——[[renal/chronic-kidney-disease]]、[[pharmacology/metabolism-excretion]]。**
急性处理——在阿片依赖患者身上，纳洛酮应滴定到“通气”而不是“清醒”；促发戒断会带来疼痛危机、躁动与肺水肿的危险；把低剂量稀释方案与标准安瓿对照着读，并监测到芬太尼消退之后。阿片恶心的策略：先换阿片，再用多巴胺拮抗剂或5-羟色胺3拮抗剂并了解其边界——[[emergency-critical-care/resuscitation]]。系统修复——在医嘱组里把“必须减量”写成等效表的一步；贴剂处方核查表要记录“阿片耐受”的定义与“绝不因恶心而贴”（恶心常常源于疼痛或另一种药，需审计）；药师主导的轮换方案并安排48小时复查——[[clinical-skills/patient-safety]]、[[pharmacology/adverse-reactions]]、[[geriatrics-palliative/symptom-control]]。**

::: example β阻滞剂难题 {#ex-beta-block}
一位哮喘患者在高剂量沙丁胺醇与吸入激素之上，因射血分数降低的心衰被开始卡维地洛；喘息加重；同时静息心率52、震颤消失。心内科信上写：“卡维地洛有证据；看不出哮喘有什么相关。”
::: solution
**一个患者身上的受体选择性（[[#def-ligands]]、[[pharmacology/autonomic-drugs]]、[[cardiovascular/heart-failure]]）：受体的地理——β1在心，β2在支气管、血管、子宫与代谢；选择性比值随剂量下降（“心脏选择性是一条谱，不是一种属性”）。卡维地洛是非选择性加α1阻断；比索洛尔与阿替洛尔偏β1；普萘洛尔脂溶而入中枢。具内在拟交感活性的部分激动剂在心梗后被回避。反向的问题是：哮喘是否禁止β阻滞？观察性研究在哮喘、慢阻肺与心衰中显示选择性β阻滞剂常常不是问题；慢阻肺的观察性生存获益时代；有方案与监护的小心心脏选择性试验；以及诚实的绝对禁忌清单——高剂量治疗下的重度支气管痉挛，对“轻度哮喘且肺功能正常”。**
治疗的多效性——震颤阻滞（普萘洛尔治特发性震颤，以及考试焦虑的伦理邻接）、偏头痛预防、甲状腺危象中普萘洛尔抑制外周四碘甲腺原氨酸转换、门脉高压的静脉曲张预防（非选择性β阻滞与卡维地洛在腹水时要“滴到心率但避免低血压”的细微）与心率控制（房颤级联）——[[nervous-system/headache-pain]]、[[endocrine/thyroid]]、[[gastrointestinal/liver-disease]]、[[cardiovascular/arrhythmias]]。实务解法——决定应有结构：哮喘是否活动？血嗜酸性粒细胞怎么说？能否在保留救命的卡维地洛的同时以升级的激素-福莫特罗控制表型？是否改用心脏选择性的替代（比索洛尔或奈比洛尔）、其证据各如何？并制定联合计划：喘息日记、峰值流量与两周复查，而不是两位专科各猜——[[respiratory/asthma-copd]]、[[clinical-skills/communication]]。底下的剂量-反应课：治疗剂量时阻滞心脏β1，而浓度上升会侵入支气管β2；无症状的心率52代表心脏阻滞充分、仍有滴定空间，而不是停药的理由；骤停的反跳危险要教给患者——[[pharmacology/adverse-reactions]]。**

::: example 麻醉医师的受体之旅 {#ex-theatre}
一例在全身麻醉下的剖宫产：丙泊酚诱导、琥珀胆碱先肌束颤动后瘫痪、七氟烷维持、瑞芬太尼输注，关腹时给新斯的明加格隆溴铵，术后还问了一个关于腰麻后头痛的问题。
::: solution
**一间手术室的受体之旅（[[#def-families]]、[[#def-ligands]]、[[surgery/anaesthesia-pain]]）：诱导——丙泊酚是γ-氨基丁酸A的正变构调节剂，作用在它自己的位点，β亚基影响敏感性，并伴有体温调节的怪事（依托咪酯抑制11β羟化酶的教训作为对照）——[[endocrine/adrenal]]。神经肌肉接头——琥珀胆碱的去极化阻断（肌束颤动后脱敏），丁酰胆碱酯酶遗传变异导致窒息，二相阻断受温度与酸中毒影响；恶性高热的兰尼碱受体与CACNA1S遗传学，丹曲林作为兰尼碱受体阻断药；非去极化的罗库溴铵被舒更葡糖包裹——以直接化学解毒取代新斯的明的算术——[[nervous-system/neuromuscular]]。挥发性麻醉药——钾离子TREK与双孔道通道、甘氨酸与谷氨酸调制等多靶点，解释了“找不到单一受体”；最低肺泡有效浓度是效价的比较，血气溶解度决定动力学，语境敏感半衰期与第二气体效应，以及胎儿与新生儿暴露的问题——[[respiratory/gas-exchange]]、[[obstetrics-gynaecology/labour-birth]]。**
瑞芬太尼——酯水解的药动使其语境敏感半衰期不随输注时长改变（这是它独有的设计）；阿片诱导的痛觉过敏与μ受体适应，包括预防性纳洛酮输注为何适得其反，以及诱导时“胸壁僵硬对过敏对癫痫”的鉴别。逆转的数学——新斯的明在所有胆碱能受体上放大内源性乙酰胆碱，因此必须合用毒蕈碱药；格隆溴铵是季铵，绕开胎儿与脑；按阻断深度给药，并用定量的加速度监测防止残余肌松。至于腰麻后头痛：它不是受体问题，而是脑脊液漏——硬膜血补片与咖啡因苯甲酸钠的历史（腺苷拮抗）见[[emergency-critical-care/acute-assessment]]与[[nervous-system/headache-pain]]——[[pharmacology/absorption-distribution]]。**

::: example 门诊的药理问题袋 {#ex-clinic-bag}
一上午门诊里的五个问题：硝酸酯贴为什么夜里要撕掉；为什么戒咖啡因会头痛而戒“交感”不会；为什么硝酸酯有耐受而肼苯达嗪没有；为什么选择性5-羟色胺再摄取抑制药的剂量固定而β阻滞剂要滴定；为什么左旋多巴的剂量多年后不是简单加大而是变复杂。
::: solution
**五个机制答案（[[#def-curves]]、[[#def-ligands]]）：硝酸酯窗口——可溶性鸟苷酸环化酶脱敏、硫醇耗竭与反调节，用非对称给药（每日留出无药间期）解决；肼苯达嗪不依赖一氧化氮，故无耐受；硝酸酯头痛来自脑膜血管扩张——[[cardiovascular/coronary-artery-disease]]。咖啡因头痛——腺苷受体上调与戒断时的血管扩张；对照直立不耐受中的交感适应——[[nervous-system/headache-pain]]、[[cardiovascular/circulation-blood-pressure]]。选择性5-羟色胺再摄取抑制药固定对β阻滞剂滴定——受体占据与临床效应曲线的形状不同：转运体占据很快进入平台、疗效曲线平坦而副作用斜率陡；β阻滞剂则是占据的等级反应，心率就是药效学生物标志——[[psychiatry/mood-disorders]]、[[cardiovascular/hypertension]]。**
左旋多巴的复杂——变性持续进展使治疗窗变窄、间断刺激造成可塑性、外周脱羧酶适应；异动症来自超敏与峰浓度——这就是持续给药方案与“COMT抑制药对MAO-B抑制药”选择的理由——[[nervous-system/movement-disorders]]。给患者的元教训：**药物是在调一个会反击的系统；耐受、疾病进展与致敏之间的区分是诊断，不是哲学——[[clinical-skills/communication]]。**
:::

## 通向何处

自主神经受体的临床细节见[[pharmacology/autonomic-drugs]]；从吸收到排泄见[[pharmacology/absorption-distribution]]与[[pharmacology/metabolism-excretion]]；剂量设计见[[pharmacology/dosing-principles]]；个体变异与药物遗传学见[[pharmacology/patient-variation]]；毒性模式见[[pharmacology/adverse-reactions]]。

::: history
**受体观念从毒物与测量中长出来：19世纪的箭毒与咖啡因生理学先驱，以及兰雷1878年用烟碱与毛果芸香碱在无神经组织上做的“接受物质”实验——在没有看见受体的情况下发明了受体，实验药理先于分子而生——[[physiology/autonomic-nervous-system]]。竞争被量化：克拉克的占据理论、加德姆的竞争工作、席尔德1947年的pA2分析给了药理学严格的算术，阿尔奎斯特1948年仅凭观察就作出α与β的分类，早于纯化许多年——[[pharmacology/autonomic-drugs]]。受体纯化时代：放射性配体结合与β受体的亲和层析，到莱夫科维茨1980年代克隆β肾上腺素受体——“靠基因来纯化”；2012年他与科比卡分享化学诺贝尔奖，后者经稳定性工程改造的晶体结构开启了基于结构的设计——[[cell-biochemistry/proteins-enzymes]]。**
信号转导的黄金时代：萨瑟兰1957年起的环磷酸腺苷第二信使时代，吉尔曼与罗德贝尔的G蛋白工作（1971与1980年的两次诺贝尔），以霍乱与百日咳毒素作分子手术刀——[[microbiology/bacterial-pathogenesis]]、[[cell-biochemistry/signalling-cell-cycle]]。偏向性激动的时代：定量激动性争论——布莱克与莱夫1983年的操作性模型、两态模型、1990至2000年代arrestin招募的偏向配体规划，以及奥列司定的教训：信号偏向本身不能预测临床安全，其审评成为转化研究的一面警示牌——[[pharmacology/drug-development-prescribing]]。耐受的脱敏机器：莱夫科维茨的受体激酶与arrestin项目，证明激动剂诱导的内吞、再循环对降解使受体有了“生命周期”；以及哮喘中的β2激动剂之争——从2006年长效β2的安全信号到改变实践的激素-福莫特罗试验时代——[[respiratory/asthma-copd]]。**
:::

::: summary
- 药物作用始于结合：亲和力决定某一浓度下有多少受体被占据，内在活性决定占据产生什么；两者彼此独立。
- 受体家族决定时钟：离子通道毫秒、G蛋白偶联受体秒、激酶分钟、核受体小时——这个节奏塑造起效、时长与耐受。
- 储备受体与放大意味着最大效应发生在完全占据之前：这就是部分激动剂能封顶反应的原因，也是“占据-效应对照表”误导人的原因。
- 竞争性拮抗可被加大激动剂超越；不可超越与不可逆的阻断取决于受体更新——这是逆转药的逻辑，也是反跳现象的逻辑。
- 变构与偏向配体扩大了设计空间，但临床优势必须前瞻性证明；仅有信号偏向预示不了多少。
- 耐受是一族机制——代谢诱导、受体脱敏与减少、行为补偿——各有其临床签名，各有其对轮换与撤药策略的含义。
:::

::: exercise 画出曲线的移动 {level=1}
描述并画出下列情况的浓度-反应曲线变化：加竞争性拮抗剂；加非竞争性拮抗剂；单用部分激动剂；部分激动剂加完全激动剂；受体下调；存在储备受体。
::: solution
**曲线移动的几何（[[#def-curves]]、[[#def-ligands]]）：竞争性拮抗——平行右移、最大效应不变，真正的竞争性拮抗呈Schild线性；“加大激动剂可克服”的推论对应纳洛酮与氟马西尼的临床给药逻辑。非竞争性或不可超越——最大效应下降、可能伴右移；恢复速度由受体或血小板更新决定（阿司匹林的血小板寿命与酚苄明的“等新生”遗产）。单用部分激动剂——曲线升到低于最大的平台（“再加药也没用”的上限教学：丁丙诺啡的呼吸、阿立哌唑的多巴胺）。部分加完全激动——在高张力下部分激动剂充当拮抗（吲哚洛尔的运动心率悖论；丁丙诺啡用于完全激动剂者时的促发戒断）。下调——受体数目减少，故右移且最大下降（慢性激动剂下的β2、阿片与苯二氮模式）。储备受体——以小部分占据即达最大，曲线陡升到顶（为何许多低占据的临床药已达平台，以及疗效曲线与毒性曲线的分离）——[[pharmacology/dosing-principles]]。**
:::

::: exercise 解释“上限” {level=1}
丁丙诺啡与阿立哌唑为何有临床上限？这个上限如何帮助一种风险、又让另一种镇痛或抗精神病的情形变复杂。
::: solution
**上限效应解释（[[#def-ligands]]、[[#def-curves]]）：机制——部分内在活性把反应封在自己的最大效应，与剂量无关；而高亲和力与慢动力学（丁丙诺啡）增加了占据的稳定性——要区分“药动学的受体饱和”与“药效学的上限”两种读法。镇痛——呼吸抑制的上限使丁丙诺啡在过量流行病学中更安全（转移注射与舌下给药的比较研究）；高亲和力置换造成的促发戒断，使“微剂量起始”成为现行标准；而重度疼痛的疗效上限与合用完全激动剂的策略要按指南读；贴、膜与植入剂的剂型差别。**
精神病——阿立哌唑的D2稳定化（在低多巴胺状态呈激动、在高多巴胺状态呈拮抗）：阳性与阴性症状的现象学、静坐不能与失眠的代价、冲动控制障碍这一“多巴胺能”副作用、长效注射剂与“部分激动反而改善依从”的悖论——[[psychiatry/psychotic-disorders]]、[[psychiatry/substance-use]]、[[surgery/anaesthesia-pain]]。**
:::

::: exercise 推断相互作用的后果 {level=2}
一位心衰患者：比索洛尔滴定被药师叫停，理由是“1988年有过支气管痉挛”；两位医师分别开了螺内酯加血管紧张素转换酶抑制药加甲氧苄啶；华法林加复方磺胺；地高辛加克拉霉素。请为每个风险定级并处理。
::: solution
**以受体语言做相互作用分诊（[[#def-ligands]]、[[#def-curves]]、[[pharmacology/patient-variation]]）：β阻滞剂与陈旧哮喘史——把心衰的死亡率级证据与35年前一次支气管痉挛（如今肺功能正常）放在天平两端：在监护下以心脏选择性药物重新试用并记喘息日记、写下表型以保护将来的处方——[[cardiovascular/heart-failure]]、[[respiratory/asthma-copd]]。三重钾负荷——血管紧张素转换酶抑制药减少醛固酮、受体拮抗剂阻断其作用、甲氧苄啶像阿米洛利那样阻断上皮钠通道（受体层面的相加）：停或减、膳食与病假日咨询、48小时复查——[[renal/potassium-calcium-phosphate]]。华法林加复方磺胺——CYP2C9抑制加上菌群维生素K流失（国际标准化比值陡升与出血的审计；预先减量并在48至72小时复查，或换抗生素）——[[blood/thrombosis-anticoagulation]]、[[pharmacology/metabolism-excretion]]。地高辛加克拉霉素——P-糖蛋白抑制抬高这个窄指数靶点药物的浓度；地高辛半衰期长，故浓度在数日内爬升：监测并教育（心动过缓、恶心、视觉症状），并记住P-糖蛋白在肠、肾与血脑屏障都有——[[cardiovascular/arrhythmias]]、[[cell-biochemistry/membranes-transport]]。**

::: exercise 评价一类新的变构药物 {level=3}
一种毒蕈碱M4正变构调节剂进入精神分裂症认知损害的试验。请评价机制的前景、探针依赖问题、种属转化、生物标志物策略与终点设计。
::: solution
**变构药物评价（[[#def-ligands]]、[[epidemiology-ebm/critical-appraisal]]、[[psychiatry/psychotic-disorders]]）：机制前景——M4正变构调节剂压制中脑边缘多巴胺溢出，其假设是“不阻断D2也能抗精神病”；桑诺美兰-曲司氯铵时代以外周拮抗剂来控制外周毒蕈碱副作用，是概念验证的故事；而“亚型选择性就是全部赌注”——M1、M2、M3重叠带来的毒性地理：心动过缓、流涎、胃肠，以及认知的双向效应——[[cardiovascular/arrhythmias]]、[[gastrointestinal/digestion-absorption]]。变构特有的问题——探针依赖会让两个实验室对同一化合物得出不同结论；协同性有可饱和的上限；种属受体差异需用突变面板绘制；认知终点缺少“内源性张力”这一问题；以及PK-PD与占据工具较弱（变构药比正构的PET配体更难追踪靶点结合）——[[pharmacology/dosing-principles]]。**
终点——认知试验的历史是一片墓地：练习效应、评估者负担、认知与阳性及阴性症状的分离、以出院时点与替代者评定的功能为终点、以及当副作用提示“分到了活性组”时观察者盲法被破坏——[[epidemiology-ebm/randomised-trials]]、[[epidemiology-ebm/measuring-disease]]。临床医师的立场——换药对加用的情境、与现有选项比较代谢负担、目标难治人群、以功能来裁决认知主张；以及诚实的读试验：效应量小、可重复性与发表偏倚检查、并对早期阶段的乐观打折——[[public-health/health-systems-economics]]、[[clinical-skills/clinical-reasoning]]。**

## 练习

::: exercise 为配体分类 {level=1}
吲哚洛尔、丁丙诺啡、纳洛酮、氟马西尼、阿立哌唑、沙美特罗、地高辛。逐一说明：激动剂、部分激动剂、拮抗剂或酶抑制药，以及在什么靶点上。
::: solution
**配体分类演练（[[#def-ligands]]）：吲哚洛尔——具内在拟交感活性的部分激动型β阻滞剂（心梗后回避的理由，以及较少低血压与心动过缓的怪癖）——[[cardiovascular/hypertension]]。丁丙诺啡——μ部分激动剂，结合紧密并有δ与κ作用，故有呼吸上限与促发戒断的潜力（轮换进与出的规则）——[[surgery/anaesthesia-pain]]、[[psychiatry/substance-use]]。纳洛酮——竞争性μ拮抗剂，消退快于美沙酮与芬太尼（“再麻醉”的观察窗）——[[emergency-critical-care/poisoning]]。氟马西尼——γ-氨基丁酸A上苯二氮位点的竞争性拮抗剂，在依赖者与合并三环类摄入时有癫痫风险（混合过量中不常规使用）——[[emergency-critical-care/poisoning]]。阿立哌唑——D2部分激动，兼5-羟色胺1A部分激动与5-羟色胺2A拮抗（“多巴胺稳定剂”的表述、静坐不能的代价与长效注射剂型）——[[psychiatry/psychotic-disorders]]。沙美特罗——长效β2激动剂，靠外部位点长锚定再结合（药动学与受体结合的备忘录，解释慢洗脱，以及“长效β2不配激素”的哮喘死亡教训）——[[respiratory/asthma-copd]]。地高辛——是酶抑制药而非受体激动剂（抑制钠钾泵使细胞内钙升高，兼有迷走性心率效应，治疗指数窄）——[[cardiovascular/heart-failure]]、[[cardiovascular/arrhythmias]]。**

::: exercise 向患者解释耐受 {level=1}
用三分钟并给出机制解释：苯二氮助眠剂量的逐月爬升；硝酸酯贴的夜间撕除窗口；沙丁胺醇“越常用越没效”；一个学期里咖啡越喝越多；选择性5-羟色胺再摄取抑制药的情感钝化与耐受的不同。
::: solution
**耐受的咨询（[[#def-curves]]、[[psychiatry/substance-use]]、[[pharmacology/adverse-reactions]]）：苯二氮的爬坡——γ-氨基丁酸A受体脱耦联与亚基移位，加上学习性补偿；等效剂量漂移、“减药而非加药”的教义、以及反跳性失眠被误当作“病回来了”——先做认知行为治疗——[[psychiatry/anxiety-disorders]]、[[geriatrics-palliative/polypharmacy]]。硝酸酯窗口——硫醇耗竭与神经激素反调节，以每日10至14小时无药间期解决；这是应用化的受体药理——[[cardiovascular/coronary-artery-disease]]。β2过度使用——受体脱敏与下调并有炎症参与；转向激素-福莫特罗的缓解策略；以及“掩盖炎症”的危险（长效β2的安全教训用平实的话重述）——[[respiratory/asthma-copd]]。一个学期的咖啡——腺苷受体上调，需要更多阻断才有同样效果；戒断时的血管扩张性头痛是咖啡因研究中的混杂——[[nervous-system/headache-pain]]。选择性5-羟色胺再摄取抑制药的情感钝化不是耐受——相当比例的服用者报告，与剂量及5-羟色胺1A机制相关；有停药症状但没有渴求（是依赖，不是成瘾）——[[psychiatry/mood-disorders]]、[[psychiatry/treatments-mental-health-law]]。**

::: exercise 判断相互作用的机制 {level=2}
为下列情形区分受体层面与药动学机制：单胺氧化酶抑制药患者用鼻腔减充血剂后的高血压危机；非甾体抗炎药削弱呋塞米的效果；茶碱加环丙沙星后抽搐；曲马多加选择性5-羟色胺再摄取抑制药的5-羟色胺毒性；螺内酯加血管紧张素转换酶抑制药的钾问题。
::: solution
**相互作用机制分诊（[[#def-ligands]]、[[#def-curves]]、[[pharmacology/metabolism-excretion]]）：单胺氧化酶抑制药加酪胺或拟交感药——自由儿茶酚胺遇上上调的肾上腺素受体（高血压危象貌似嗜铬细胞瘤；以酚妥拉明为主处理；利奈唑胺的弱酶抑制教学；洗脱期由单胺氧化酶的更新速率决定）——[[emergency-critical-care/poisoning]]、[[cardiovascular/vascular-disease]]。非甾体抗炎药对利尿剂——前列腺素依赖的肾血流与钠处理被对消（肾单位层面的功能性拮抗；“转换酶抑制药加利尿剂加非甾体抗炎药”的三联打击与入球小动脉生理）——[[renal/water-sodium]]、[[renal/acute-kidney-injury]]。茶碱加环丙沙星——纯药动学：CYP1A2抑制抬高这个本身就是受体药的窄指数支气管扩张剂（腺苷拮抗与非选择性磷酸二酯酶抑制造成抽搐与心律失常；测浓度；吸烟与氟伏沙明朝相反方向拉）——[[respiratory/asthma-copd]]、[[pharmacology/patient-variation]]。选择性5-羟色胺再摄取抑制药加曲马多等——靶点层面的过度刺激（转运体阻断加合成增加），按Hunter标准诊断、与神经阻滞剂恶性综合征鉴别，处理是停用5-羟色胺能药、赛庚啶、降温与苯二氮——[[emergency-critical-care/poisoning]]、[[pharmacology/adverse-reactions]]。螺内酯加血管紧张素转换酶抑制药——在钾处理上“受体阻断加配体撤除”的相加：肾功能、膳食、代盐与病假日规则；依普利酮的选择性理由；以及钾结合剂辅助的时代——[[renal/potassium-calcium-phosphate]]、[[cardiovascular/hypertension]]。**

::: exercise 设计一项偏向性激动剂的首次人体研究 {level=3}
一家公司向你所在的临床药理单元提供一种G蛋白偏向性μ阿片激动剂，临床前证据显示“镇痛而不抑制呼吸”。请设计1期方案与停止逻辑，并诚实地评述偏向假说。
::: solution
**偏向性激动剂1期设计（[[#def-ligands]]、[[epidemiology-ebm/randomised-trials]]、[[pharmacology/drug-development-prescribing]]）：临床前评述——对偏向量化指标保持怀疑：tau与对数tau之比、哪种检测读到什么；-arrestin、GIRK电流与通气反应之间的不一致；奥列司定的历程——疗效差别不大而真实的安全信号：**偏向不等于安全**，而治疗窗要定量表述（镇痛与呼吸抑制ED50之间的分离指数——在哪一个种属、用哪一个终点）——[[epidemiology-ebm/critical-appraisal]]。1期架构——哨兵给药配持续二氧化碳与血氧描记及呼吸激发终点（高碳酸与低氧通气反应测定，以μ激动剂作阳性对照）、瞳孔测量作为药效生物标志、结肠传输测定（因为便秘才是真实世界的限制）；对PK-PD占据假设严格审查；停止规则预先设定（呼吸暂停与血氧阈值；安全监督委员会有一票否决）——[[clinical-skills/patient-safety]]、[[respiratory/control-breathing-tests]]。**
受试者伦理与现实——为刻画安全性而区分未用过药与有经验的队列、报酬与胁迫的防护、诚实地设定依赖潜力终点；解救性拮抗药的可及性与匹配消退药理的规程——长效激动剂要“输注而非安瓿”，并制定研究专用的过量预案——[[emergency-critical-care/poisoning]]、[[medical-ethics-law/research-ethics]]。诚实的结论——信号偏向是有用的设计启发式，不是保证（“多通路的药物总有意外”的教训）；以及本单元的决定框架：预注册的分析计划与开放数据的承诺、以及在偏向未能带来分离时愿意宣布失败——[[epidemiology-ebm/systematic-reviews]]、[[pharmacology/adverse-reactions]]。**
