患者不是70公斤的健康志愿者。**年龄、体重、妊娠、器官功能、遗传、疾病与其他药物，会沿着说明书平均值抹平的曲线改变暴露与敏感性。个体化给药的做法，就是对“此时此人”回答三个问题：他需要哪个目标浓度、他的分布容积与清除率是多少、以及将通过什么检查来核实。**本章汇集这些修饰因素——尤其是药物遗传学的那些——以及把知识变成一张被修改的处方的系统。

## 身体本身

::: definition 年龄、体重与器官功能 {#def-body}
**新生儿不是小大人：肾功能在第一年成熟，肾小球滤过与肾小管分泌约在6至24个月达成人速率；肝氧化不成熟，某些葡萄糖醛酸化途径成熟很晚（氯霉素灰婴与磺胺把胆红素从蛋白上置换的教训）；细胞外液比例更大，因此水溶性药物即使“肾不成熟”也需接近成人的每公斤剂量；而异速生长与成熟度建模已支撑儿童用药许可——同时大多数儿科处方仍是外推的现实、蔗糖与苄甲醇辅料毒性的历史，以及发育期神经毒性的动物数据之争（这正是三岁以下麻醉需要与家长讨论的原因）——[[paediatrics/newborn]]、[[paediatrics/growth-development]]、[[surgery/anaesthesia-pain]]。**
老年身体把数字朝反方向改变：肾储备下降而肌少症使肌酐“正常”、肝质量与血流减少、脂肪增多而总体水减少从而改变脂溶与水溶药物的分布；而占主导的效应是脑对镇静药、阿片与抗胆碱药的敏感性升高——所以“起始低、加量慢”主要是一条药效学规则。跌倒、谵妄、低钠、便秘与尿潴留这些综合征，本质是穿了内科外衣的老年药理；药物复查本身就是一种可治疗的老年综合征（抗胆碱、苯二氮、非甾体抗炎药与质子泵抑制药的对话，以及“用一种药治另一种药的副作用”的处方级联）——[[geriatrics-palliative/polypharmacy]]、[[geriatrics-palliative/ageing-frailty]]、[[geriatrics-palliative/falls]]。肥胖按药物逐个改变给药，没有单一规则：**脂溶性药物分布入脂肪但脂肪灌注差，因此诱导剂量按瘦体重而某些输注会蓄积；亲水性抗生素需要加大剂量而极端体重的证据仍然稀薄（极高体重的抗Xa监测、体重超过120公斤时直接口服抗凝药的数据缺口、麻醉的体重分段表，以及减重手术后吸收被重接——胃旁路后的缓释剂型）——[[pharmacology/absorption-distribution]]。**
肝病与肾病攻击的参数不同：**肾衰竭降低清除率、有时升高分布容积，透析则等于外加一个器官；肝病通过分流减少高摄取药物的清除、改变蛋白结合，并使氧化能力不规则地受损。所以剂量问题是“这个药走哪条途径、那条途径坏掉多少”，而不是“哪项化验最难看”（慢加急性肝衰竭逐日重算的习惯、脆弱肾的围手术期给药）——[[renal/chronic-kidney-disease]]、[[gastrointestinal/liver-disease]]。**
:::

## 基因及其门诊

::: definition 药物遗传学 {#def-pgx}
**可在临床行动的药物遗传学按后果成簇。因“无法激活”而失去药效：氯吡格雷的CYP2C19功能丧失等位基因使活性代谢物减少、部分试验中支架内血栓增多，有按基因型降级治疗的证据与人群频率的注意事项；因“过快灭活”而毒性（人类白细胞抗原不属于这里——那是免疫呈递）。因蓄积而毒性：TPMT与NUDT15变异与硫嘌呤骨髓抑制（如今在用硫唑嘌呤与巯嘌呤前筛查）；DPYD变异与氟尿嘧啶或卡培他滨的灾难（用药前检测方案与减量或回避）；NUDT15在亚洲人群中作用更强，再次提醒祖源与套餐设计——[[infectious-diseases/hiv]]、[[musculoskeletal/inflammatory-arthritis]]、[[pathology/cancer-biology]]。**
映射到人类白细胞抗原的免疫特异质：阿巴卡韦-B\*5701（强制检测后该反应近乎消失）、卡马西平-B\*1502（东南亚与汉族患者）、别嘌醇-B\*5801（高危人群筛查政策及其与肾功能剂量的交互）、以及氟氯西林-B\*35:01信号——但因归因风险极低而不建议筛查（这是处方场景里“绝对风险对相对风险”的一课）。**药效学的例子：**恶性高热的兰尼碱受体与CACNA1C邻近易感（用咖啡因-氟烷收缩试验检测）、琥珀胆碱窒息的丁酰胆碱酯酶变异、华法林的CYP2C9加VKORC1剂量算法（试验获益有限而指南态度暧昧）、以及他汀肌病与转运体的关联。框架问题：外显率与效应量决定“先检、事后检、还是不检”；等位基因频率与单倍型定义随祖源不同，因此在欧洲人身上验证的套餐会漏掉别处的变异，而参考标准正在被纠正（祖源代表性问题是患者安全问题）；先发制人的套餐检测在卫生系统尺度上已可讨论经济学，但它要求结果解读服务、带“证据变化时重新联系”规则的安全存储、对附带药物遗传信息的同意（通常为空，这本身令人安心，也值得告诉患者），以及能对结果采取行动的处方系统——**因为一个未被行动过的基因型是法律责任，不是创新**——[[genetics/genetic-testing]]、[[genetics/genomic-medicine]]、[[medical-ethics-law/research-ethics]]。**
:::

## 其他一切会改变剂量的因素

::: definition 相互作用、妊娠与情境 {#def-context}
**相互作用的机制在上一章已述；此处把它当作群体现象来看：平均一位多病共存的老人，其相互作用负荷随处方者人数与交接频率而增长——所以收益最高的干预不是一本新教科书，而是每次交接时由药师主导的用药核对，并且要认真询问非处方药、草药与“借来的药”（只有不带审判的问法，才会问出“共用一包药”与“吃配偶的药”）——[[clinical-skills/records-handover]]、[[pharmacology/metabolism-excretion]]、[[pharmacology/adverse-reactions]]。妊娠可预期地改变药动学，却因本能反射而开药不足：分布容积与肾清除增加、葡萄糖醛酸化被诱导（拉莫三嗪剂量必须在孕期上调、产后下调）、蛋白结合改变；而致畸焦虑造成癫痫、抑郁、哮喘与血栓倾向的危险性治疗不足——风险比较几乎永远是“药对未治疗的疾病”，而不是“药对健康”；诚实的咨询包是叶酸、疫苗与按剂量调整的单药，而证据基础正缓慢建成的妊娠登记。哺乳大多把药转移给婴儿的效率很低但不是零：相对婴儿剂量的算术、分泌入乳的药物类别清单，以及“维持母亲治疗才能保住母乳喂养”的框架（母亲失代偿会伤害婴儿这笔账要公开说）——[[obstetrics-gynaecology/pregnancy-complications]]、[[obstetrics-gynaecology/early-pregnancy]]、[[nervous-system/epilepsy]]。**
值得点名的疾病修饰因素，因为它们反复出现：**无脾与补体抑制药带来的脑膜炎球菌疫苗义务；肾剂量与透析日给药时机的规律作为日常；心衰与非甾体抗炎药、噻嗪与痛风、锂的这些相互作用家族；以及那批同时也是代谢病的罕见药物遗传病（恶性高热易感、葡萄糖六磷酸脱氢酶缺乏的用药清单——伯氨喹、氨苯砜与硝呋太尔，定量酶测定使消除时代的疗法成为可能；由专科登记处维护的卟啉原性药物清单；以及琥珀胆碱敏感）——[[renal/chronic-kidney-disease]]、[[infectious-diseases/immunocompromised-host]]。行为层：依从性就是一种剂量。**半数慢性病药物并未按处方服用，因此个体化算法的第一个输入是实际暴露——每日一次、复方制剂与长效注射剂的设计解法、较粗但有效的干预（简化、贴合日常作息、成本与配药核查、时效有限的提醒、以及在其适用处有效的动机访谈）；而“不依从对耐药对吸收不良”的鉴别由治疗药物监测裁定；依从性证据本身也要像读任何药物试验一样批判性地读——[[psychiatry/treatments-mental-health-law]]、[[clinical-skills/communication]]、[[public-health/prevention-promotion]]。**
:::

::: example 拉莫三嗪的围产期计划 {#ex-lamotrigine-pp}
一位局灶性癫痫女性，服拉莫三嗪每次200 mg每日两次，在停用复方避孕药后怀孕；到第10周先兆增多；她的产褥期计划写着“恢复孕前剂量”。
::: solution
**一个药，两个方向（[[#def-body]]、[[#def-context]]、[[obstetrics-gynaecology/pregnancy-complications]]）：先看雌激素相互作用——炔雌醇诱导UGT1A4的葡萄糖醛酸化，可使拉莫三嗪浓度约减半；因此停避孕药后的意外妊娠既移除了诱导，妊娠药动学又把浓度继续压低：同方向的两次扰动。先兆增多是浓度问题，还挂着安全问题（驾驶、沐浴与监护的咨询）——[[nervous-system/epilepsy]]、[[obstetrics-gynaecology/contraception-fertility]]。孕期计划——每月或每孕期测浓度，把剂量上调以维持她个人的孕前目标（绝大多数患者可达到无发作的证据；对拉莫三嗪相对令人安心的致畸数字要诚实，同时强调剂量-暴露的关系）；按指南在受孕前补叶酸；并进入专科主导的联合门诊，而不是让两个科室各自猜测——[[paediatrics/congenital-genetic]]。**
产后陷阱——葡萄糖醛酸化在一至三周内恢复正常，于是孕期剂量变成中毒剂量（镇静、复视与共济失调的报告看起来“像产后本来就该有的样子”；因此要在分娩前写好阶梯式回到孕前剂量的计划并用浓度确认）；多数抗癫痫药可哺乳，同时监测婴儿镇静与吸吮差（拉莫三嗪入乳相对较多的读法是“监测而非回避”）；再加上睡眠剥夺与恢复避孕的咨询，以及按当地法律的驾驶对话——[[obstetrics-gynaecology/postnatal-period]]、[[clinical-skills/communication]]。**
:::
:::

::: example 120公斤患者的用药 {#ex-obesity-dose}
一位体重120公斤、身高168公分的58岁患者因蜂窝织炎、需要抗凝的房颤与慢性疼痛入院；药房标出三项剂量决定。
::: solution
**体重分段的药理学（[[#def-body]]、[[pharmacology/absorption-distribution]]）：抗生素——β内酰胺的分布容积随脂肪与水肿增大而清除并不下降，故常规剂量暴露不足；选择是在许可上限内的加量固定剂量，或体重分段方案，并结合感染部位与肾功能；决定必须记录，因为“块头大就多给”不是方案（亲水药物分布的细节与每种药的毒性裕度）——[[microbiology/antimicrobials]]、[[musculoskeletal/skin]]。抗凝——体重超过120公斤或体质指数超过40时，直接口服抗凝药处于数据缺口，替代方案证据较低：华法林配国际标准化比值，或按抗Xa浓度指导使用直接口服抗凝药，或按体重分段的低分子肝素并以抗Xa监测；选择要说清依据，而预防剂量与治疗剂量不得混用——[[blood/thrombosis-anticoagulation]]。**
镇痛——神经阻滞与区域麻醉的解剖因体表标志与针长而改变（超声时代的实践）；脂溶性诱导药按瘦体重给以避免延长镇静，而输注需随分布变化重新滴定；按体重给阿片则应放在监护资源最充足的一端，并询问睡眠呼吸暂停（阿片所致呼吸抑制的危险因素清单由肥胖领衔）——[[surgery/anaesthesia-pain]]、[[endocrine/diabetes]]。公平的注记：“因为体型大而回避给药”正是患者被低估治疗的方式；解法是方案、药动学素养与体重记录，而不是“以不治疗来表示谨慎”；而曾做减重手术的患者带着另一种吸收问题（胃旁路后的缓释剂型与避孕警示）——[[gastrointestinal/clinical-nutrition]]、[[public-health/prevention-promotion]]。**
:::

::: example 硫嘌呤的两难 {#ex-thiopurine-pgx}
一位24岁新诊断克罗恩病、菲律宾祖源的患者被提供硫唑嘌呤；TPMT酶活性正常，但化验单注明NUDT15检测“本院不作为常规”。
::: solution
**考虑祖源的药物遗传学（[[#def-pgx]]、[[gastrointestinal/bowel-disease]]）：科学——TPMT缺乏导致硫嘌呤骨髓抑制，筛查可使早期毒性减半；但在东亚与东南亚人群中，NUDT15变异才是常规剂量下重度骨髓抑制更常见的原因，因此一个正常的TPMT结果既真的令人安心、也真的不完整（人群特异的变异频率是患者安全事实，不是脚注）——[[blood/anaemia]]。可行的选择按优先级：加做NUDT15（越来越可得，与一次再生障碍事件相比费用极低）；或以减量起始并密集监测血细胞；或选择其他诱导方案（生物制剂优先的对话，它有自身的免疫原性与监测逻辑）——只要把机制向患者解释清楚，三者都站得住。更宽的模式：华法林算法的表现随祖源不同；卡马西平与别嘌醇的人类白细胞抗原筛查建议之所以锚定祖源，是因为等位基因本身锚定祖源；而选择性5-羟色胺再摄取抑制药与氯吡格雷的指南带人群附注——所以“指南说”若不含等位基因频率这一层，套餐就会让少数族裔患者落空——[[pharmacology/adverse-reactions]]、[[medical-ethics-law/justice-resources]]。咨询——骨髓抑制出现早，只要追血象就可逆；TPMT与NUDT15的结果不许可放松监测；顺带提醒别嘌醇与血管紧张素转换酶抑制药的粒细胞减少及华法林相互作用；以及生育计划的问题（硫嘌呤是受孕与妊娠中研究较充分的免疫抑制药之一，应与炎症性肠病和产科团队共同决定，而不是由说明书决定）——[[obstetrics-gynaecology/early-pregnancy]]、[[clinical-skills/communication]]。**

::: example 有家族史的麻醉同意 {#ex-mh-family}
一位健康19岁患者的兄弟在阑尾切除时死亡，“和肌松药与发热有关”；麻醉医师被问到该怎么办。
::: solution
**疑似恶性高热路径（[[#def-pgx]]、[[surgery/anaesthesia-pain]]）：病史——“高热死亡与肌松药的关联”在证明不是之前就是恶性高热（RYR1与CACNA1S变异、外显率多变的常染色体显性易感、机制是琥珀胆碱与挥发性麻醉药揭发）——[[genetics/mendelian-inheritance]]。计划——用“干净机器”技术避开触发药（全凭静脉麻醉、按规程拆去蒸发罐并换新鲜回路、不用琥珀胆碱）；丹曲林触手可及且房间内每个人都知道冲配演练；全程体温监测与常温维持；急诊手术不必为“先做检测”而推迟。家族路径——转诊恶性高热研究单位；咖啡因-氟烷收缩试验与基因套餐，并解释其灵敏度与特异度的取舍；通过先证者提供级联检测；随身警示卡与登记入册会保护他未来十年的手术（真正的触发时刻是拔牙与智齿）——[[genetics/genetic-testing]]、[[medical-ethics-law/confidentiality]]。诚实的咨询——易感不是麻醉的禁忌；多数今后麻醉在防范下平顺；家属会问的焦虑、保险与运动问题都有平静的答案；而那次事件本身要报告并从中学习——[[clinical-skills/patient-safety]]。**

## 通向何处

每个修饰因素的机制细节见[[pharmacology/absorption-distribution]]、[[pharmacology/metabolism-excretion]]与[[pharmacology/dosing-principles]]；单基因的酶与受体疾病见[[genetics/common-disease-genetics]]；基因组学在临床的落地见[[genetics/genomic-medicine]]。

::: history
**药物遗传学始于两个被认真阅读的临床奇事：1956年首次报告的琥珀胆碱窒息家族（那个“酶变异”的故事为本领域提供了词汇），以及1950至60年代埃文斯与普赖斯-埃文斯及罗森克兰茨对异烟肼与肼苯达嗪乙酰化表型的工作；同时有人发现某些人对富酪胺鱼类的升压反应过强，于是把NAT2与膳食和药物处理连接起来（那句“周末偏头痛”的观察变成酶多态性）——[[infectious-diseases/tuberculosis]]、[[pharmacology/metabolism-excretion]]。随后是人类白细胞抗原的联系：1960年代把免疫标志与药物反应相关联的观察，接着1970年代发现人类白细胞抗原系统（当时称W6/HL-A）可预测粒细胞缺乏与其他特异质——于是B型反应被框定为免疫遗传学——[[immunology/adaptive-responses]]。硫嘌呤门诊把它制度化：雷林与埃文斯在1990至2000年代的TPMT基因型项目与减量方案，除去了白血病维持治疗的大部分早期死亡；DPYD与氟嘧啶的文献二十年后才到，落地仍不均衡；而阿巴卡韦-B\*5701从病例系列到强制检测政策不足十年——这是现代药物警戒最好的成果——[[blood/lymphoma-myeloma]]、[[infectious-diseases/hiv]]。**
氯吡格雷与CYP2C19的时代展示了限度：药理坚实、遗传学可重复，但在多种祖源的试验证据成熟之前指南态度暧昧——本行业由此学到，决定临床价值的是效应量与可行动的替代方案，不是P值。2010至2020年代的实施科学：国际药物基因组学实施联盟与药物基因组学工作组的指南、eMERGE与PGx-CARRY与U-PGx的前瞻队列、先发制人套餐对事后检测的经济学；而当套餐从研究走向处方，“祖源代表性”的纠正就成了安全议题——[[genetics/genomic-medicine]]、[[public-health/global-health]]。**
:::

::: summary
- 真实患者的暴露是每一个修饰因素的乘积再乘以依从比例；说明书只给你分子。
- 年龄、体重、妊娠、器官衰竭与透析各自动特定的参数——剂量问题就是“对这个药而言哪个参数主导”。
- 在效应量大且检测会改变行动之处，药物遗传学真有临床价值：硫嘌呤与TPMT/NUDT15、氟嘧啶与DPYD、阿巴卡韦与B\*5701、卡马西平与B\*1502、别嘌醇与B\*5801。
- 基因套餐的好坏取决于训练它的祖源；代表性公平是一个用药安全问题。
- 妊娠会抬高某些药的剂量需求随后又撤回（拉莫三嗪是教学案例）；母亲疾病的低估治疗本身就是一种暴露。
- 不依从是“药物失效”最常见的原因；在升级治疗之前先测量或直接询问。
:::

::: exercise 为旅行者开药 {level=2}
为一位70公斤、器官功能正常的成人计划用药：在葡萄糖六磷酸脱氢酶检测后为根治间日疟用伯氨喹、用多西环素预防、以及为痤疮用异维A酸。哪些相互作用、进食影响与依从性设计重要？
::: solution
**旅行者与痤疮的药理（[[#def-context]]、[[pharmacology/absorption-distribution]]）：伯氨喹——8-氨基喹啉在葡萄糖六磷酸脱氢酶缺乏时造成溶血，用定量酶测定在“每周一次、八周”与“每日方案”之间作选择；它需要CYP2D6才能激活（慢代谢者根治失败——这是“复发”的一个基因型原因）；须与食物同服、高铁血红蛋白的边缘、与联合用药的时机、以及按目的地的耐药图谱——[[pharmacology/metabolism-excretion]]。多西环素——螯合规则（奶、铁、钙与抗酸剂，间隔四至六小时）；与热带行程相冲突的光敏咨询（防晒霜与衣物的话术）；以大量水与保持直立预防食管炎；以及在“每日100 mg的简便”里诚实区分有效性与依从性。异维A酸——须每日随脂肪餐吸收；致畸管理的架构（两种避孕方式、妊娠试验、处方时限规则与“立即报告妊娠”的义务）；避免同时补维生素A；与多西环素禁配（颅内压风险）——一张三药清单，在一次门诊里同时教了进食、遗传与监管——[[musculoskeletal/skin]]、[[obstetrics-gynaecology/early-pregnancy]]、[[pharmacology/drug-development-prescribing]]。**
:::

::: exercise 向三种听众解释药物遗传学 {level=1}
把一份CYP2C19慢代谢结果解释给：(a) 植入支架后的患者；(b) 一名医学生；(c) 正在决定是否检测的医院药事委员会。
::: solution
**三种语域（[[#def-pgx]]、[[clinical-skills/communication]]）：患者版——“你的肝有一种酶的慢版本，所以氯吡格雷在你身上不能被完全打开；另外还有不需要这个开关的药”：具体机制、点名的替代药、不带责怪的说法、以及“把结果做成卡片供将来处方使用”的用处（顺带说明对家人的意义）。学生版——前药与酶的课：CYP2C19功能丧失等位基因减少活性硫醇代谢物、血小板抑制下降、在观察性研究与部分随机数据中支架内血栓上升；按基因型降级到普拉格雷或替格瑞洛在试验中减少事件，代价是出血，而等位基因频率随祖源而变——[[cardiovascular/coronary-artery-disease]]。委员会版——成本效果取决于本人群的事件率、替代药在合同价上的成本、结果能否实时在处方系统中被行动、以及“你真的会据此行动的那几个基因-药物对”的证据强度（而不是你顺手收集的那个套餐）；给出分阶段计划（先做支架人群、评估、再扩展范围），而不是一份宣传册——[[public-health/health-systems-economics]]、[[genetics/genomic-medicine]]。**

::: exercise 肾内科门诊的药物复查 {level=2}
一位滤过率22的患者：二甲双胍每日两次各1 g、雷米普利10 mg、呋塞米80 mg、螺内酯25 mg、按需萘普生、舍曲林、西酞普兰30 mg、索利那新、按需复方对乙酰氨基酚与可待因、以及按需硝呋太尔预防尿路感染。请带着理由削减这张清单。
::: solution
**重写肾科清单（[[#def-body]]、[[renal/chronic-kidney-disease]]）：停药清单及机制——滤过率22时二甲双胍已进入禁忌地带（乳酸酸中毒风险；按阈值规则重构降糖方案，转向胰岛素或肾科适宜的替代并做低血糖咨询）——[[endocrine/diabetes]]；硝呋太尔预防在此滤过率下无效（尿中浓度不足），只带来毒性而得不到获益——[[renal/urinary-tract]]、[[microbiology/antimicrobials]]；萘普生停（前列腺素对脆弱肾的灌注打击、钠钾效应、出血风险，并在不用非甾体抗炎药的前提下重建镇痛阶梯）——[[renal/acute-kidney-injury]]；西酞普兰30 mg超过肾与肝调整的上限，叠加QT与低钠——应只留一种抗抑郁药并重查QT清单——[[cardiovascular/arrhythmias]]、[[psychiatry/mood-disorders]]；复方对乙酰氨基酚与可待因中的吗啡代谢物会蓄积（肾衰时M6G造成镇静与呼吸抑制；把所有产品中的对乙酰氨基酚合计记账；并制定非阿片方案）——[[surgery/anaesthesia-pain]]。**
保留并监测的清单——雷米普利与螺内酯因肾与心的保护而保留，但配上钾与肌酐的时间表与病假日规则；呋塞米按效果重新滴定；索利那新减量并做抗胆碱负荷与认知核查；整张清单在每一级滤过率下降时重审——肾剂量分段是一份“活的文件”，不是一次性的事——[[geriatrics-palliative/polypharmacy]]、[[clinical-skills/records-handover]]。**

::: exercise 评述“祖源对遗传学”的开药之争 {level=3}
一些指南用祖源决定药物遗传学检测（卡马西平、别嘌醇），另一些则完全回避种族类别。请评述证据、伦理与一份站得住的政策。
::: solution
**祖源与处方（[[#def-pgx]]、[[medical-ethics-law/justice-resources]]）：科学——人类白细胞抗原等位基因频率因人群史与病原驱动的选择而强烈随祖源变化，所以B\*1502筛查在东南亚与汉族人群具成本效果，而在该等位基因稀少的人群几乎无用；别嘌醇-B\*5801在高危人群、NUDT15在东亚、南亚与西班牙裔队列同理（等位基因频率表就是指南，而自我报告的祖源是一个已知不吻合的替代指标）——[[genetics/common-disease-genetics]]。伦理——普遍筛查避免带污名的分类且不漏人，但更贵并需要实验室能力；按祖源触发的询问高效，但要求医师认真对待祖源而不做本质化，且询问本身必须有尊严并可选择（“临床祖源”对“社会种族”的区分要写进话术）——[[clinical-skills/history-taking]]。**
失败模式——懒惰地套用替代指标（凡“看起来像本地人”就不测，或在多元门诊里条件反射地全测）；只在一种祖源上训练的套餐在其他祖源表现不佳（这场争论真正藏着的安全风险）；以及记录的缺口——被拒绝的检测从病历上消失。站得住的政策——在相关变异存在之处提供以基因型为基础的检测（把祖源提示做成处方系统里的建议而非闸门）；在经济可行处转向先发制人的套餐，使检测不再取决于患者的外观；每条建议都附等位基因频率证据；并按祖源分层审计检测与结局，以捕捉政策自己造成的公平缺口——[[genetics/genomic-medicine]]、[[public-health/determinants-inequalities]]、[[clinical-skills/patient-safety]]。**

## 练习

::: exercise 哪个参数在动？ {level=1}
写出主要的药动学或药效学改变及其剂量后果：早产儿与氯霉素；82岁与地西泮；妊娠中期与拉莫三嗪；血液透析日与左乙拉西坦；肝硬化分流与普萘洛尔。
::: solution
**参数移动（[[#def-body]]、[[#def-context]]）：新生儿与氯霉素——葡萄糖醛酸化不成熟致药物蓄积与线粒体毒性（灰婴综合征、改用替代药的规则、以及按受孕后周龄给每公斤剂量的成熟度图表）——[[paediatrics/newborn]]；老年与地西泮——活性代谢物清除下降加脑敏感性升高，因此改用“只经葡萄糖醛酸化”的劳拉西泮或奥沙西泮或替马西泮、起始剂量减半，并做跌倒与骨折咨询——[[geriatrics-palliative/polypharmacy]]；妊娠与拉莫三嗪——被诱导的葡萄糖醛酸化与肾清除使浓度减半，故上调剂量并每月监测，产后数周内按书面计划下调——[[obstetrics-gynaecology/pregnancy-complications]]；透析与左乙拉西坦——分子小、不与蛋白结合、经肾清除，故在两次透析之间被大量移除，需要透析后补充剂与“间期下降曲线”（同一套规则可预判哪些药无需补充）——[[renal/chronic-kidney-disease]]；分流与普萘洛尔——高摄取药的口服生物利用度在门静脉血绕过肝细胞时逼近注射途径，因此肝硬化前有效的口服剂量现在可能过高——[[gastrointestinal/liver-disease]]。**
:::

::: exercise 检还是不检 {level=2}
就下列情形分别论证“用药前检测”“需要时检测”或“都不检测”，用效应量、可行动性、潜伏期与漏检的代价：新诊断炎症性肠病用硫嘌呤；汉族患者用卡马西平；21岁患者用氟氯西林；哺乳期女性在扁桃体切除后用可待因；辅助治疗结肠癌前用氟尿嘧啶。
::: solution
**检测策略的论证（[[#def-pgx]]）：硫嘌呤——用前测TPMT与NUDT15：效应大、漏检后果惨重、有可行动的替代与减量方案，且与一次骨髓抑制住院相比检测很便宜（NUDT15在亚洲队列提出的“跨祖源等位基因”论据）——[[gastrointestinal/bowel-disease]]。汉族患者用卡马西平——B\*1502检测是为了预防Stevens-Johnson与中毒性表皮坏死松解，比值比很大且有替代药，故对高危祖源是标准（人群等位基因频率对个人风险这一框架，以及标签里记录的拉莫三嗪交叉风险警示）——[[nervous-system/epilepsy]]、[[musculoskeletal/skin]]。氟氯西林——不测：B\*35:01的相对风险高但特异质黄疸的绝对风险低，且反应晚发不可预测；答案是患者教育加“注意黄疸”的建议与报告义务，而不是用药前人类白细胞抗原分型——[[gastrointestinal/liver-disease]]。哺乳期与扁桃体切除后的可待因——无论基因型如何均禁忌，因为超快代谢者会把常规剂量转为吗啡并已有婴儿死亡；政策的回答是“不要用”，这是把药物遗传学用在群体层面而不必检测任何人——[[paediatrics/acute-childhood-illness]]、[[surgery/anaesthesia-pain]]。氟尿嘧啶——用药前测DPYD是当前的方向（部分缺乏者的减量方案有早期避免毒性的数据；四个常见变异对罕见变异的表型对基因型之争，以及以尿嘧啶测定作为替代）——[[pathology/cancer-biology]]、[[pharmacology/adverse-reactions]]。**
:::

::: exercise 重写出院带药 {level=2}
一位86岁患者因心衰失代偿出院，带药：呋塞米加倍、加用螺内酯、雷米普利上调、“关节炎”继续萘普生、非处方西替利嗪止痒、锂盐不变。找出五个用药安全问题并重写方案。
::: solution
**出院复查重写（[[#def-body]]、[[#def-context]]、[[geriatrics-palliative/polypharmacy]]）：三重钾打击——螺内酯加雷米普利，加上一位86岁患者未言明的膳食与疾病变量；因此计划里要写明48至72小时与一周的钾与肌酐复查、病假日规则，并首先移除萘普生（非甾体抗炎药造成出血、急性肾损伤、高钾、低钠与治疗抵抗；以外用与对乙酰氨基酚替代，并把“关节炎”重新评估为手部锻炼、支具与体重的对话）——[[musculoskeletal/osteoarthritis]]、[[renal/potassium-calcium-phosphate]]。锂与利尿剂——袢利尿剂、噻嗪、血管紧张素转换酶抑制药与非甾体抗炎药都影响锂清除（脱水到毒性的级联；在病情与剂量变化时查浓度；长期治疗需监测肾、甲状腺与钙）——[[psychiatry/mood-disorders]]、[[endocrine/thyroid]]、[[endocrine/bone-calcium]]。呋塞米的逻辑——因淤血加倍是对的，但上调血管紧张素转换酶抑制药与加盐皮质激素受体拮抗剂会减少排钾，所以利尿剂剂量与钾计划必须一起移动，配每日体重与门诊电话；并核查“低钾加重地高辛毒性”的病史。**
西替利嗪——第二代抗组胺药通常无妨，但在这具身体里要考虑镇静-跌倒与抗胆碱叠加及肾剂量下调；更要问清瘙痒究竟是皮肤干燥、淤积还是药物（答案是减药并修复皮肤屏障）——[[immunology/hypersensitivity]]。系统层——出院对话要用实际药盒做回述；为这一新组合给全科与社区药师发出警示，并把一周后的血检落实到具体负责人；记录再入院风险，使下一次复查时这份记录找得到——[[clinical-skills/records-handover]]、[[cardiovascular/heart-failure]]。**

::: exercise 为药物遗传学服务写一份立项书 {level=3}
为成人群体在初级保健建档时进行先发制人的药物遗传学检测立项。纳入临床、经济、公平、伦理与实施论证，以及最有力的反对意见。

**立项书的构造（[[#def-pgx]]、[[public-health/health-systems-economics]]）：临床论证——一次检测可在一生的处方中反复使用（硫嘌呤、氟嘧啶、阿巴卡韦、氯吡格雷，以及已有的阿片与抗抑郁药代谢指导），既避免毒性也避免精神药理的多年试错；同时要诚实地说多数结果是“代谢正常”，而成本效果正来自那少数可行动者——[[genetics/genomic-medicine]]。经济模型——检测加解读服务的成本对避免的住院（TPMT、DPYD与人类白细胞抗原的严重反应、重症级别的毒性与诉讼）；节省随复用与数十年的药价变化累积，因此要以卫生系统而非单一科室为框架；并对处方系统整合与解读人力保持现实。公平的双向论证——跨祖源的等位基因覆盖需要多样化的参考数据（否则就是漏检问题），而按建档人群检测可在决定“谁能获得精准医疗”的贫困梯度上拉平机会；风险是它变成又一项数字排斥的服务，除非渠道是多样的。伦理与反对——关于重新联系与数据保存的同意、保险与歧视的担忧（多数已由法律回答，但仍需平实的答复）、“依据弱效应证据行动会把处方医疗化”的反对；最有力的反对是治理失败：未被行动过的基因型制造法律责任，“意义未明变异”的洪水制造混乱。以设计作答：结果只在配有解读时才回传、处方警示、行动率审计、以及证据变化时的重新联系政策；配上以硬终点与公平监测为核心的试点与评估计划——[[medical-ethics-law/research-ethics]]、[[medical-ethics-law/justice-resources]]、[[clinical-skills/patient-safety]]。**
