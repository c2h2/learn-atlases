药品的批准剂量是为临床试验中的典型成人选定的。真实的患者很少是典型的。新生儿还不能结合许多药物；一位88岁的女性，其肾功能只剩下她30岁时的一小部分；妊娠晚期的女性对某些药物的清除速度是孕前的两倍；携带某种酶遗传变异的人，可能把标准剂量的可待因转化为危险剂量的吗啡。因此，同一剂量可以产生截然不同的浓度和效应。

本章对这些差异进行梳理。差异来自**药代动力学**，即同一剂量产生不同的浓度；也来自**药效学**，即同一浓度产生不同的效应。差异还来自药物究竟有没有被服用。本章涵盖体型、年龄与器官功能，遗传变异，妊娠与哺乳，以及依从性，并说明每一项如何应用于处方。本章以[[pharmacology/dosing-principles]]、[[pharmacology/metabolism-excretion]]和[[pharmacology/absorption-distribution]]为基础。

## 体型、年龄与器官功能 {#sec-body}

::: definition 药物反应差异的来源 {#def-body}
患者之间对同一剂量反应的差异来自：

- **吸收**：胃肠功能、食物、相互作用药物、首过代谢；
- **分布**：体型和身体组成（水、脂肪、肌肉）、血浆蛋白；
- **消除**：肝肾功能、酶活性（遗传的以及被诱导或抑制的）；
- **敏感性**：受体数量和功能、稳态储备、靶器官疾病；
- **依从性**：是否服药、何时服药以及如何服药。

对于任何个体，处方者都要问：其中哪些很可能与确定该剂量时的人群不同，偏向哪个方向。
:::

### 儿童

儿童不是缩小的成人。在**新生儿**，尤其是早产儿中，总体液占体重的比例更大，因此水溶性药物每千克体重的分布容积更大。血浆白蛋白较低，结合位点可能被胆红素占据。葡萄糖醛酸化尚未成熟，这就是按成人剂量缩减给药的氯霉素（chloramphenicol）曾引起“灰婴综合征”的原因；肾小球滤过率也低，因此庆大霉素等经肾排泄的药物需要更长的给药间隔。在最初几个月里，这些功能迅速成熟。此后幼儿按每千克体重计算对许多药物的代谢反而*快于*成人，因为其肝脏相对于体重更大。

因此，儿童剂量通常按**体重**（mg/kg）计算，对于细胞毒药物等某些药物则按**体表面积**计算，并与成人最大剂量核对。在英国，《英国国家儿童处方集》（BNFC）按年龄段和体重给出剂量。许多药物从未获批用于儿童，因此超说明书用药很常见，只要有证据和指南依据即可接受。有些药物受到专门限制：自2013年起，MHRA禁止12岁以下儿童使用可待因（codeine）止痛，并禁止18岁以下因阻塞性睡眠呼吸暂停而行扁桃体或腺样体切除术的儿童使用，原因是曾有属于CYP2D6超快代谢者的儿童死于呼吸抑制（[[paediatrics/acute-childhood-illness]]）。

::: example 按体重计算剂量 {#ex-paed-dose}
一名体重18 kg的4岁男孩发热且烦躁不安。家长询问应给多少对乙酰氨基酚（paracetamol）口服混悬液。以示例单剂量15 mg/kg计算剂量，并说明适用的核对步骤。
::: solution
剂量$= 15 \times 18 = 270$ mg。随后的核对步骤与计算同样重要。

- **与年龄段剂量和最大剂量比较。**产品说明书和BNFC按年龄段给出剂量；按体重计算的剂量不应超过成人最大单剂量，并须遵守每日总剂量和给药间隔。
- **仔细换算为体积。**若使用120 mg/5 mL的混悬液，270 mg为11.25 mL；若使用250 mg/5 mL的混悬液，则为5.4 mL。混淆规格是儿童用药过量的公认原因。
- **使用正确的体重。**使用近期实测体重；对于肥胖儿童，某些药物可能适合使用校正体重或理想体重。
- **核查同一药物的其他来源**，如复方感冒药。

以上均遵循现行BNFC和产品信息。原则是：计算出的剂量是起点，而不是最终答案。
:::
:::

### 老年人

衰老几乎改变药代动力学的每一个环节，也改变敏感性。

- **肾功能**随年龄下降，即使血清肌酐正常也是如此，因为肌肉量和肌酐生成减少。地高辛、锂盐、加巴喷丁和直接口服抗凝药等经肾排泄的药物，若不调整剂量就会蓄积（[[pharmacology/dosing-principles]]）。
- **身体组成**改变：脂肪增加，总体液减少。地西泮（diazepam）等脂溶性药物分布容积更大，半衰期长得多；水溶性药物浓度更高。
- **肝血流量和肝脏体积**下降，使高摄取率药物的清除率降低、生物利用度增加。
- 对作用于脑的药物（苯二氮䓬类、阿片类、抗毒蕈碱药）**敏感性**增加，稳态储备下降，因此降压药更容易引起体位性低血压和跌倒。

老年人服用的药物也最多。多重用药使相互作用和不良反应成倍增加；STOPP/START标准（第3版于2023年发表）等工具列出了可能不适当的药物和可能遗漏的有益药物。结构化用药审查、在获益不再超过伤害时减停药物，以及关注本人的优先事项，见[[geriatrics-palliative/polypharmacy]]。

### 体重与肥胖

使用哪种体重取决于药物分布在哪里以及如何被清除。常用三种指标：

- **总体重**（TBW），即实测体重；
- **理想体重**（IBW），根据身高估算；一个常用公式（Devine公式）为：男性50 kg、女性45.5 kg，身高超过5英尺的部分每英寸加2.3 kg；
- **校正体重**，常按IBW + 0.4 × (TBW − IBW)计算，用于部分分布于多余组织的某些药物。

氨基糖苷类等亲水性药物主要分布于瘦组织和细胞外液，因此在肥胖者中按总体重给药会导致过量；常用校正体重。某些脂溶性药物的分布容积随总体重增加，这会影响负荷剂量。低分子量肝素按总体重给药，在体重极端时有时设定上限或监测抗Xa活性。这些规则因药而异，遵循产品信息和地方指南。

### 肝、肾和心脏疾病

**肾功能损害**已在[[pharmacology/dosing-principles]]中讨论：它降低经肾排泄的药物和活性代谢物（例如吗啡-6-葡萄糖醛酸苷）的清除率，并增加对某些药物的敏感性，如使用保钾药物时高钾血症的风险。

**肝病**更难量化，因为没有一项血液检查能衡量药物代谢能力。Child–Pugh评分被用作粗略的参考。多种效应叠加：低摄取率药物代谢减少，高摄取率药物因门体分流而生物利用度增加，白蛋白降低，以及敏感性增加。镇静药和阿片类可诱发肝性脑病；在伴腹水的肝硬化中，非甾体抗炎药可引起肾损伤、胃肠道出血和液体潴留；损害凝血的药物则加重肝衰竭的凝血障碍。

**心力衰竭**使肝血流量减少，减慢利多卡因（lidocaine）等高摄取率药物的清除，并引起肠壁水肿，可能减少利尿药的口服吸收。因此，在失代偿性心力衰竭中，静脉给予利尿药有时更有效。

## 遗传变异 {#sec-pgx}

::: definition 药物遗传学与代谢型 {#def-pgx}
**药物遗传学**研究单个基因的遗传变异如何影响药物反应；**药物基因组学**将其扩展到整个基因组。变异主要通过三种方式起作用：

- 作用于**药物代谢酶或转运体**，改变浓度（例如CYP2D6、CYP2C19、CYP2C9、TPMT、NUDT15、DPYD、SLCO1B1）；
- 作用于**药物靶点**，改变敏感性（例如华法林的VKORC1）；
- 作用于**免疫系统**（HLA等位基因）或细胞易损性（G6PD、RYR1、线粒体DNA），引起特异质反应。

对于酶，按**代谢型**对人群分组：**慢代谢者**（几乎没有酶活性）、**中间代谢者**、**正常代谢者**和**超快代谢者**（酶活性增加，例如由于*CYP2D6*基因拷贝数增加）。其后果取决于药物是被该酶灭活还是活化。慢代谢者体内活性药物蓄积，但从前药获得的效应很小；超快代谢者则相反。
:::

下表列出临床后果最明确的基因–药物组合。其中若干项目前在英国已常规检测。

| 基因 | 药物 | 变异的效应 | 实践 |
|---|---|---|---|
| *CYP2D6* | 可待因、曲马多（前药） | 超快代谢：吗啡过多，呼吸抑制。慢代谢：镇痛作用很小 | 儿童和哺乳期限制使用可待因 |
| *CYP2C19* | 氯吡格雷（前药） | 功能缺失等位基因：活性代谢物减少，复发事件增多 | NICE（2024）建议在缺血性卒中或TIA后进行检测以指导氯吡格雷的使用 |
| *TPMT*、*NUDT15* | 硫唑嘌呤、巯嘌呤 | 活性低：标准剂量下严重骨髓抑制 | 开始用药前检测TPMT活性或基因型 |
| *DPYD* | 氟尿嘧啶、卡培他滨 | DPD缺乏：严重或致命毒性 | 自2020年起英国在开始用药前常规检测 |
| *HLA-B\*57:01* | 阿巴卡韦 | 超敏反应 | 处方前检测；阳性则不处方 |
| *HLA-B\*15:02* | 卡马西平、苯妥英 | SJS/TEN | 汉族、泰国及部分其他东南亚血统者在使用卡马西平前检测 |
| *HLA-B\*58:01* | 别嘌醇 | SJS/TEN、DRESS | 在某些亚洲人群中频率较高；部分地区检测 |
| *G6PD* | 伯氨喹、氨苯砜、拉布立酶、呋喃妥因 | 溶血 | 使用伯氨喹和拉布立酶前检测 |
| *MT-RNR1*（m.1555A>G） | 氨基糖苷类 | 即使单剂也可致严重听力丧失 | NICE（2023）有条件地建议在新生儿病房进行快速检测 |
| *RYR1*、*CACNA1S* | 挥发性麻醉药、琥珀胆碱 | 恶性高热 | 家族史；专科检测 |
| *BCHE* | 琥珀胆碱、米库氯铵 | 呼吸暂停延长 | 家族史；酶活性检测 |
| *CYP2C9*、*VKORC1* | 华法林 | 敏感性更高，所需剂量更低 | 依据INR给药；已有基因型指导的算法 |

各种变异的频率在不同人群中不同，这是处方指南中出现血统因素的原因之一。但这并不意味着血统可以替代检测：每个人群内部都存在个体差异，自报的血统也只是基因型的不完善指标。

::: example 可待因与母乳喂养的婴儿 {#ex-codeine-um}
一名31岁女性剖宫产后因疼痛被开具可待因加对乙酰氨基酚，并在母乳喂养。第7天，她的婴儿非常嗜睡、吃奶差。请解释她的基因型可能怎样导致这一情况，以及相应的安全规则是什么。
::: solution
可待因是前药：约5%至10%的剂量经CYP2D6 O-去甲基化生成吗啡，后者提供了其大部分镇痛作用。有些人携带额外的有功能的*CYP2D6*拷贝，属于**超快代谢者**；他们把更多的可待因更快地转化为吗啡。对于哺乳期母亲，这可使乳汁中的吗啡浓度高到足以使婴儿镇静和呼吸抑制，而婴儿自身清除吗啡的能力尚未成熟。2006年一例广为报道的新生儿死亡正是这种情况。

婴儿需要紧急医学评估。MHRA建议哺乳期母亲不应使用可待因，12岁以下儿童禁用可待因止痛。母亲的替代药物包括对乙酰氨基酚、布洛芬，以及在需要阿片类时，短疗程使用不依赖CYP2D6活化的药物，用最低有效剂量并监测婴儿。由于超快代谢者在某些人群中频率较高（例如北非和中东的部分地区），“正常”剂量对某些群体的风险高于其他群体。
:::
:::

::: example 硫嘌呤类药物的两难 {#ex-thiopurine-pgx}
一名35岁男性克罗恩病患者将开始使用硫唑嘌呤（azathioprine）。其TPMT活性报告为缺失（纯合缺陷）。按标准剂量会发生什么？有哪些选择？如果人群中无功能TPMT等位基因的频率为5%，预计纯合缺陷者和杂合子各占多大比例？
::: solution
硫唑嘌呤转化为巯嘌呤，后者或被灭活（经TPMT甲基化和黄嘌呤氧化酶），或转化为活性硫鸟嘌呤核苷酸（[[pharmacology/metabolism-excretion]]）。没有TPMT活性时，标准剂量会产生极高的硫鸟嘌呤核苷酸水平，在数周内引起严重甚至致命的骨髓抑制。选择是避免使用硫嘌呤类而改用其他药物，或在专科监督下使用大幅减少的剂量并密切监测。中间活性者通常从减少的剂量开始。即使TPMT活性正常，也要继续定期监测血象，因为其他因素（包括在东亚血统人群中更常见的*NUDT15*变异）也会引起毒性。

在哈迪–温伯格平衡下，等位基因频率$q = 0.05$，$p = 0.95$：纯合缺陷$= q^2 = 0.0025$（约1/400）；杂合子$= 2pq = 0.095$（约1/10）。欧洲人群的实际观察值约为1/300活性极低、约1/10活性中等，与此接近。
:::
:::

::: example 麻醉前的家族史 {#ex-mh-family}
一名23岁女性被安排行腹腔镜阑尾切除术。术前评估时她提到，她的舅舅“曾在麻醉中高热，差点死掉”，她的表亲后来做过检测。可能是什么疾病？如何遗传？她的麻醉应遵循哪些原则？
::: solution
病史提示**恶性高热**（MH），这是一种骨骼肌钙调节的药物遗传学疾病，通常由*RYR1*（肌质网兰尼碱受体）变异引起，较少由*CACNA1S*变异引起。它以常染色体显性方式遗传，外显率不一，因此即使她的父母从未发生过反应，她也可能是携带者。在易感者中，挥发性麻醉药和琥珀胆碱触发肌肉中不受控制的钙释放，引起呼气末CO₂上升、心动过速、肌强直、高热、高钾血症、酸中毒和横纹肌溶解。不治疗可能致命；丹曲林（dantrolene）减少肌质网钙释放，是特异性治疗。

原则：在被证明不是之前，应将她视为MH易感者。麻醉应避免所有触发药物（使用全凭静脉麻醉和非去极化型神经肌肉阻滞药），使用无挥发性麻醉药残留的麻醉机，监测体温和呼气末CO₂，并备好丹曲林。她及其亲属应转诊到英国恶性高热检测机构接受检测和咨询，并清楚记录结果。如果手术紧急，不应为检测而推迟；不使用触发药物即可安全实施麻醉（[[surgery/anaesthesia-pain]]）。
:::
:::

## 妊娠与哺乳 {#sec-pregnancy}

::: definition 妊娠期与哺乳期用药 {#def-context}
妊娠以可预测的方向改变药代动力学：

- 血浆容量和总体液增加，白蛋白降低；
- 肾小球滤过率升高约50%，增加锂盐和许多抗生素等经肾排泄药物的清除；
- 某些酶的活性升高（CYP3A4、CYP2D6，以及对拉莫三嗪进行葡萄糖醛酸化的UGT1A4），另一些则降低（CYP1A2、CYP2C19）。

药物对**胎儿**的影响取决于时间：

- 受精后最初两周内，暴露的效应往往是“全或无”：妊娠丢失或正常发育；
- 在**胚胎期**（受精后约第3至8周）器官形成，这是结构畸形的主要风险期；
- 在**胎儿期**，药物可影响生长和功能，例如ACE抑制药和血管紧张素受体阻滞药损害胎儿肾功能，妊娠晚期使用非甾体抗炎药导致动脉导管提前闭合。

在**哺乳期**，大多数药物以少量进入乳汁。婴儿的暴露取决于乳汁中的浓度和婴儿自身的清除能力，而早产儿和新生儿的这种能力有限。
:::

**致畸物**是能引起胚胎或胎儿结构或功能异常的物质。公认的例子包括**丙戊酸钠**（sodium valproate），它使约10%的暴露妊娠发生重大畸形，宫内暴露的儿童中高达30%至40%出现神经发育障碍；异维A酸；华法林（妊娠早期）；甲氨蝶呤和吗替麦考酚酯；以及程度较轻的某些抗癫痫药。鉴于丙戊酸钠危害之大，MHRA要求对所有可能怀孕的人实施**妊娠预防计划**；自2024年起，除非两名专科医生独立认为没有其他有效或可耐受的治疗，55岁以下的任何人都不应开始使用丙戊酸钠。异维A酸和某些其他药物也适用同等的预防措施。

许多疾病在妊娠期仍须治疗，未经治疗的癫痫、抑郁症、哮喘或高血压可能同时伤害母亲和婴儿。原则是尽可能计划妊娠，以最低有效剂量使用安全用药经验最多的药物，除非必要避免在妊娠早期开始新药，并利用英国致畸信息服务（UK Teratology Information Service）和BNF等专业资源（[[obstetrics-gynaecology/pregnancy-antenatal]]）。

::: example 妊娠晚期的一次发作 {#ex-lamotrigine-pp}
一名29岁女性癫痫患者服用拉莫三嗪（lamotrigine）每日200 mg，已三年无发作，孕前血药浓度为6 mg/L。妊娠32周时，她出现了多年来的首次发作。她的拉莫三嗪浓度为2.4 mg/L，且每剂都按时服用。请解释这一变化，估算恢复原先浓度所需的剂量（假定线性动力学），并解释分娩后的主要风险。
::: solution
拉莫三嗪主要经葡萄糖醛酸化（UGT1A4）清除，妊娠期高雌激素水平使其活性增加。GFR升高也有少许贡献。到妊娠晚期，清除率通常升高两到三倍，因此在固定剂量下浓度下降。

稳态时，浓度与剂量除以清除率成正比（[[pharmacology/dosing-principles]]）。她的浓度下降到原来的$1/2.5$（$6/2.4 = 2.5$），因此清除率约升高了2.5倍。要恢复到6 mg/L：剂量$\approx 200 \times 6/2.4 = 500$ mg/天。实际上，剂量在专科照护下分步增加，并在整个妊娠期监测血药浓度。

分娩后，雌激素水平在数天内下降，拉莫三嗪清除率在数周内恢复正常。如果继续使用提高后的剂量，她的浓度可能升至目标值的约2.5倍，出现头晕、复视和共济失调，而此时她正在照顾新生儿。因此，产后有计划地减量并检测浓度是方案的一部分。产后睡眠剥夺也会增加发作风险，还应给予洗澡和抱婴儿时的安全建议（[[nervous-system/epilepsy]]）。
:::
:::

::: warning 按体重计算的剂量可能超量
只有将结果与成人最大剂量比较时，按mg/kg计算儿童剂量才是安全的。一名体重80 kg的青少年按体重计算的剂量会超过许多药物的成人剂量。肥胖成人也是如此：总体重会高估亲水性药物的合适剂量。按体重计算的剂量一律以推荐最大剂量为上限，并为该药物选择正确的体重指标。
:::

## 依从性及其他因素 {#sec-adherence}

反应差异的最大来源往往是药物有没有被服用。对于长期治疗，世界卫生组织估计，在高收入国家约有一半的人未按处方服药。**不依从**可能是有意的（由于副作用、对药物的看法或怀疑是否需要），也可能是无意的（遗忘、方案复杂、打不开包装或不会使用吸入器、费用）。疗效不佳时，在加量或加用其他药物之前，应以不加评判的方式交谈，了解药物实际上是如何服用的。简化方案、使用药与本人的优先事项相一致，以及让药师参与，都有帮助（[[clinical-skills/communication]]）。

其他因素同样重要。饮食和吸烟改变酶活性（烟草与CYP1A2）。靶器官疾病改变敏感性：甲减患者对阿片类更敏感，低钾血症患者对地高辛更敏感。不同人群之间的平均反应可能不同，例如英国高血压指南建议，对非洲黑人或非洲–加勒比黑人家族背景的人，首选钙通道阻滞药而不是ACE抑制药，部分原因是平均反应的差异以及ACE抑制药所致血管性水肿的风险较高。这类建议描述的是群体平均值，而不是个体。

::: quiz
一名86岁女性多年来每晚服用地西泮5 mg。她跌倒并发生髋部骨折。年龄带来的哪种变化组合最能解释她因该药增加的风险？
- [ ] 代谢加快，脑敏感性降低
- [x] 这种脂溶性药物的分布容积增大且清除减慢，使半衰期大大延长，同时衰老的脑敏感性增加
- [ ] 分布容积减小，肾排泄加快
- [ ] 血浆白蛋白升高，使游离分数增加
::: solution
随着年龄增长，体脂增加，使地西泮等脂溶性药物的分布容积增大，肝脏氧化代谢减慢。二者都延长半衰期（$t_{1/2} = 0.693\,V_d/CL$），其活性代谢物去甲地西泮进一步蓄积。与此同时，老年人的脑对苯二氮䓬类更敏感，镇静、意识模糊和跌倒增加。STOPP标准建议老年人避免长期使用苯二氮䓬类。
:::
:::

::: history
遗传差异可以解释异常药物反应的观念可追溯到二十世纪五十年代。1956年，一些士兵对伯氨喹敏感而发生溶血，被追溯到葡萄糖-6-磷酸脱氢酶缺乏；同一年代，琥珀胆碱后呼吸暂停延长被追溯到血浆胆碱酯酶的遗传变异。埃文斯（Wendell Price Evans）于1960年证明，人群可分为异烟肼的慢乙酰化者和快乙酰化者。莫图尔斯基（Arno Motulsky）于1957年提出，这类遗传变异可以解释许多意外反应；福格尔（Friedrich Vogel）于1959年创造了“药物遗传学”一词。二十世纪七十年代，伦敦的史密斯（Robert Smith）在一项由他本人设计的研究中服用异喹胍（debrisoquine）后病倒，德国的艾歇尔鲍姆（Michel Eichelbaum）则在研究司巴丁（sparteine）时，各自独立发现了后来被确认为*CYP2D6*的多态性。[[pharmacology/adverse-reactions]]中讨论的沙利度胺灾难，使致畸性检测成为新药的一项要求。
:::

::: summary
- 药物反应的差异来自药代动力学（同一剂量产生不同浓度）、药效学（同一浓度产生不同效应）和依从性。
- 新生儿葡萄糖醛酸化和肾功能尚未成熟；幼儿代谢许多药物很快；剂量按体重或体表面积计算，并以成人最大剂量为上限。
- 在老年人中，肾功能减退、体脂增加、肝清除减慢和敏感性增加使标准剂量风险更大；用药审查和减停药物是核心。
- 代谢酶、靶点和HLA等位基因的药物遗传学变异改变疗效和安全性；英国的关键检测包括TPMT/NUDT15、DPYD、HLA-B*57:01、卒中后用于氯吡格雷的CYP2C19，以及新生儿的MT-RNR1。
- 妊娠增加许多药物（拉莫三嗪、锂盐）的清除，并使胎儿暴露；致畸风险取决于时间。丙戊酸钠受到严格管控。
- 肥胖、肝病和心脏病改变分布和清除；不依从很常见，应在升级治疗之前加以了解。
:::

## 习题

::: exercise 按体重计算剂量 {level=1 check="270"}
以示例剂量15 mg/kg计算，体重18 kg的儿童单次剂量（mg）是多少？
::: solution
$15 \times 18 = 270$ mg，需与BNFC中的年龄段剂量和最大剂量核对。
:::

::: exercise 慢代谢者的频率 {level=1 check="4"}
在某人群中，某药物代谢酶基因无功能等位基因的频率为0.2。假定哈迪–温伯格平衡，且只有携带两个无功能等位基因的人是慢代谢者，慢代谢者占人群的百分之多少？
::: solution
$q^2 = 0.2^2 = 0.04$，即**4%**。
:::
:::

::: exercise 动力学还是效应学？ {level=1}
说明下列每项主要是药代动力学还是药效学的差异来源：(a) 老年人在相同苯二氮䓬浓度下镇静更明显；(b) 肾功能损害时庆大霉素谷浓度升高；(c) 妊娠期拉莫三嗪浓度下降；(d) 携带*VKORC1*变异者对华法林更敏感；(e) 戒烟后氯氮平浓度升高。
::: solution
(a) 药效学（脑敏感性增加）。(b) 药代动力学（肾清除减少）。(c) 药代动力学（葡萄糖醛酸化增加）。(d) 药效学（药物靶点维生素K环氧化物还原酶的差异）。(e) 药代动力学（CYP1A2诱导消失）。
:::
:::

::: exercise 校正体重 {level=2 check="94.6"}
某男性身高6英尺（72英寸），体重120 kg。用IBW = 50 + 2.3 ×（超过60英寸的英寸数）和校正体重 = IBW + 0.4 × (TBW − IBW)，计算他的校正体重（kg），保留一位小数。
::: solution
IBW $= 50 + 2.3 \times 12 = 77.6$ kg。校正体重$= 77.6 + 0.4 \times (120 - 77.6) = 77.6 + 16.96 = 94.56$ kg，保留一位小数为**94.6** kg。
:::
:::

::: exercise 妊娠期暴露的时间 {level=2}
一名女性发现自己怀孕；按日期推算，受精发生在5周前。在过去5周内，她服用了一种被怀疑会引起结构畸形的药物。请解释这一时间意味着什么，以及进一步处理的原则。
::: solution
受精后最初两周属于“全或无”期；随后三周落在胚胎期（受精后第3至8周）之内，此时器官正在形成，可能发生结构畸形。对此类药物而言，这一窗口内的暴露承担着主要风险。

原则：只有在权衡了疾病不治疗的风险之后才停药或换药（有些疾病，如癫痫，不能不治疗）；就具体药物、剂量和时间向致畸信息资源（在英国为UKTIS）寻求专科建议；提供咨询和适当的产前筛查，包括详细的畸形筛查超声；不要先入为主地认定有害，因为即使是已知的致畸物，大多数暴露的妊娠结局也是正常的。
:::
:::

::: exercise 阿片类前药 {level=2}
参照CYP2D6代谢型，解释为什么可待因对某些人几乎没有镇痛作用，而对另一些人却是危险的。为什么氟西汀等强效CYP2D6抑制剂会减弱可待因的作用？
::: solution
可待因是经CYP2D6活化为吗啡的前药。慢代谢者没有功能性的酶，生成的吗啡很少，镇痛作用很小。超快代谢者常携带额外的基因拷贝，更快地生成更多吗啡，有阿片类中毒的风险，尤其是儿童和母乳喂养的婴儿。氟西汀和帕罗西汀是强效CYP2D6抑制剂；它们把正常代谢者变成功能上的慢代谢者（**表型转化**），减少吗啡生成和镇痛作用。因此，表型既取决于基因，也取决于药物。
:::
:::

::: exercise 妊娠期的拉莫三嗪 {level=3 check="500"}
某女性孕前服用拉莫三嗪每日200 mg，血药浓度为6 mg/L。妊娠32周时，在同样剂量且完全依从的情况下浓度为2.4 mg/L。假定线性动力学，预计每日多大剂量（mg）可恢复到6 mg/L？给出准确值。分娩后最初几周必须计划什么？为什么？
::: hint
稳态时，浓度与剂量成正比，与清除率成反比。
:::
::: solution
清除率增加了$6/2.4 = 2.5$倍。要恢复到6 mg/L：$200 \times 2.5 =$ **500** mg/天。

分娩后，雌激素驱动的UGT1A4诱导在数天至数周内消退，清除率回落到基线水平。此时500 mg的剂量会使浓度比预期高约2.5倍，导致中毒。因此应事先与癫痫团队计划在产后最初几周内依据浓度和症状逐步减量，如[[#ex-lamotrigine-pp]]所述。
:::
:::

::: exercise 为汉族男性选择抗癫痫药 {level=3}
一名36岁、出生于香港的汉族男性新诊断为三叉神经痛。卡马西平是常规一线治疗。(a) 开始用药前建议进行什么检测？为什么？(b) 如果结果阳性，应如何处理？(c) 如果他已经服用卡马西平六个月且无问题，检测还有用吗？请解释。
::: solution
(a) HLA-B*15:02基因分型。该等位基因在汉族、泰国及部分其他东南亚人群中常见，携带者发生卡马西平所致史–约综合征和中毒性表皮坏死松解症的风险大大增加，而这些疾病有相当高的死亡率。产品信息和BNF建议这些血统的人在开始使用卡马西平前进行检测。

(b) 如果阳性，除非没有其他选择且获益明显超过风险，否则不应开始使用卡马西平。相关药物（奥卡西平，以及有部分相同风险的苯妥英）也应谨慎使用；可考虑加巴喷丁等替代药物或专科方案。

(c) 用处不大。卡马西平所致SJS/TEN通常发生在最初两到三个月内。服药六个月而无反应的人以后发生的风险很低，因此检测通常不会改变处理。这说明基因检测在首次暴露之前最有用。
:::
