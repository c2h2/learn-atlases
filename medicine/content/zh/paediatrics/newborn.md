出生是一个人一生中经历的最大生理变化。在几分钟之内，婴儿必须开始呼吸空气，把循环改道经过肺，并在没有胎盘的情况下保持体温和获得营养。大多数婴儿无需帮助就能完成这一过程。临床医生的工作是支持这一过渡，仔细检查婴儿，并及早识别那一小部分正在病情加重的婴儿，因为新生儿以安静、非特异的方式表现疾病。

本章涵盖出生时的过渡、新生儿体格检查和筛查、喂养与黄疸、感染，以及早产儿的照护。英国的实践遵循NICE和国家筛查项目；指南会变化，因此标注日期的陈述应对照现行版本核实。

## 过渡与新生儿体格检查

::: definition 出生时的过渡 {#def-transition}
**过渡**是使胎儿适应宫外生活的一系列变化。最重要的三项是：

- **肺充气。**气道中的液体被吸收，最初几次呼吸使肺泡充满空气。
- **循环改变。**肺血管阻力下降，肺血流增加，胎儿分流通道（卵圆孔和动脉导管）关闭。
- **代谢独立。**婴儿必须在没有胎盘持续供应的情况下维持自身体温和血糖。
:::

::: theorem 氧和压力使胎儿分流通道关闭 {#thm-shunts}
出生后，胎儿分流通道之所以关闭，是因为维持其开放的压力关系发生了逆转，并且动脉导管会因氧而收缩。任何使肺血管阻力保持在高水平的情况，或任何使循环依赖动脉导管的情况，都可能使婴儿在最初几天发病。
:::

::: proof
胎儿的肺充满液体，肺血管阻力高，因此右心室的大部分血液经动脉导管进入主动脉。来自胎盘的含氧血进入右心房，经卵圆孔到达左侧。出生时，肺扩张和氧分压升高使肺血管扩张，肺阻力下降。夹闭脐带去除了低阻力的胎盘，因此体循环阻力升高。左心房压力此时超过右心房压力，将卵圆孔的瓣片推向关闭。随着氧分压升高和胎盘来源的前列腺素减少，动脉导管收缩，通常在几天内功能性关闭。如果肺不能充气，或婴儿缺氧或寒冷，肺阻力可能持续升高，血液持续右向左分流：这就是新生儿持续性肺动脉高压。而如果婴儿患有某种心脏缺陷，其流向全身或流向肺的血液依赖动脉导管，那么婴儿出生时可能看起来正常，而在动脉导管关闭时（常在第2或第3天）突然衰竭。
:::

### Apgar评分

**Apgar评分**是对婴儿出生后1分钟、5分钟以及必要时10分钟状况的快速概括。它对五项特征分别评0至2分：心率、呼吸努力、肌张力、反射反应和肤色。7–10分令人放心。该评分描述婴儿的状况；它不决定复苏，复苏从最初几秒钟起就由心率、呼吸和肌张力指导。

大多数婴儿只需擦干、保暖并检查呼吸和心率。不呼吸的婴儿给予**膨肺通气**使肺充气。打开肺是新生儿复苏中最重要的步骤，因为大多数新生儿心动过缓是由肺未充气引起的，而不是由心脏疾病引起的。对于不需要复苏的婴儿，脐带至少延迟一分钟再夹闭，这能改善足月儿的铁储备，并降低早产儿的死亡率。

::: example 在1分钟时评分 {#ex-apgar}
阴道分娩后1分钟，一名婴儿心率90次/分，哭声微弱且不规则，四肢有一些屈曲，吸引鼻腔时皱眉，躯干红润而手足青紫。计算Apgar评分。
::: solution
逐项评分：

- 心率低于100次/分：**1**分（无心率为0分；100次/分或以上为2分）。
- 呼吸弱而不规则：**1**分（无呼吸0分；哭声响亮2分）。
- 有一些屈曲：**1**分（松软0分；活动自如2分）。
- 刺激时皱眉：**1**分（无反应0分；咳嗽、打喷嚏或啼哭2分）。
- 躯干红润、四肢末端青紫：**1**分（全身青紫或苍白0分；全身红润2分）。

评分为**5**分（满分10分）。心率低于100次/分是关键发现：它意味着婴儿需要帮助使肺充气，应擦干、刺激，必要时给予膨肺通气，而不必等待评分。手足周围性青紫（肢端青紫）在出生第一天很常见，属于正常。
:::
:::

### 新生儿和婴儿体格检查

在英格兰，每个婴儿都会在出生后72小时内接受**新生儿和婴儿体格检查（NIPE）**，并在6–8周时由全科医生重复。这是一次全面检查，但有四项筛查内容在全国登记：

- **眼**：红光反射，用于发现先天性白内障，罕见情况下发现视网膜母细胞瘤。
- **心脏**：杂音、心音、股动脉搏动和肤色，用于发现先天性心脏病。
- **髋**：Barlow和Ortolani手法，用于发现发育性髋关节发育不良。有危险因素（臀位、家族史）的婴儿接受髋关节超声检查。
- **睾丸**：用于发现男孩的隐睾。

每个婴儿还接受另外两项筛查。**新生儿听力筛查**使用自动耳声发射测试，必要时加做自动听性脑干反应测试。**新生儿血斑**（足跟采血）检测最好在第5天进行。在英格兰，它筛查九种疾病：镰状细胞病、囊性纤维化、先天性甲状腺功能减退症，以及六种遗传代谢病（苯丙酮尿症、MCADD、枫糖尿症、异戊酸血症、1型戊二酸尿症和同型胱氨酸尿症）。自2021年起，英格兰部分地区对严重联合免疫缺陷的筛查进行了评估。所有婴儿出生时还会接受**维生素K**以预防维生素K缺乏性出血。

::: warning 24小时检查正常并不能排除心脏病
患有动脉导管依赖性心脏病变（如主动脉缩窄或左心发育不良）的婴儿，在动脉导管开放时检查可以完全正常。几天后婴儿出现喂养差、呼吸急促、苍白和股动脉搏动减弱或消失。应告诉家长需要注意什么，每次都要触摸股动脉搏动，任何在检查正常后病情恶化的婴儿都应从头重新评估，而不能因先前的正常检查而放心。出于这个原因，许多医疗单位增加了脉搏血氧饱和度筛查，尽管它并不属于英格兰国家筛查项目。
:::

## 喂养与黄疸

::: definition 出生后最初几周的正常喂养和体重 {#def-feeding}
大多数婴儿出生后体重下降，因为他们排尿、排出胎粪，而母乳供应尚未建立。出生第一周体重下降至多约**出生体重的10%**很常见。大多数婴儿在**2周**时恢复到出生体重。体重下降超过10%，或3周时仍未恢复出生体重的婴儿，需要进行喂养评估。

建议在最初约6个月**纯母乳喂养**。配方奶喂养和管饲的婴儿，奶量在最初几天逐步增加，按当地指南，通常到第一周末达到约150 mL/kg/d。
:::

::: example 体重下降过多的母乳喂养婴儿 {#ex-weightloss}
普丽娅（Priya）足月出生，出生体重3.40 kg，纯母乳喂养。第4天体重3.02 kg。她嗜睡，过去24小时只有两片湿尿布，黄疸蔓延到腹部。她丢失了出生体重的百分之几？接下来应该怎么做？
::: solution
**计算。**下降量为$3.40 - 3.02 = 0.38$ kg。占出生体重的百分比为$0.38/3.40 \times 100 = 11.2\%$。

**解释。**下降超过10%超出正常范围。加上湿尿布少（到第4天应约有六片）和嗜睡，提示她没有得到足够的奶。母乳喂养婴儿脱水会导致**高钠血症**，这可能很危险；摄入不足还会加重黄疸，因为经粪便排出的胆红素减少。

**下一步。**检查血清钠和胆红素。观察一次母乳喂养，注意体位和含接，评估母亲的泌乳量。喂养计划可包括更频繁地喂奶、挤奶，以及用挤出的母乳或配方奶补充。24–48小时内再次称重。支持母亲继续母乳喂养是治疗的一部分，而不是可有可无的附加措施。
:::
:::

### 新生儿黄疸

约60%的足月儿和80%的早产儿在出生第一周出现肉眼可见的黄疸。其中大部分是**生理性黄疸**：新生儿红细胞量多、红细胞寿命短，而肝脏的结合酶（UGT1A1）尚未成熟。胆红素从第2天开始升高，约在第3–5天达峰，两周内消退。母乳喂养的婴儿更常出现黄疸，且持续时间更长。

未结合胆红素可以通过血脑屏障。在极高水平时，它会引起**急性胆红素脑病**和称为**核黄疸**的永久性损害：手足徐动型脑性瘫痪、听力损失和凝视麻痹。治疗的目的是预防这些后果。

NICE指南NG98的关键规则是：

- **出生后24小时内出现的黄疸总是病理性的。**必须紧急测定胆红素，在2小时内完成。最常见的原因是血型不合引起的溶血（Rh或ABO）、G6PD缺乏症和感染。
- **不要依赖肉眼观察**来估计胆红素水平，尤其是肤色较深的婴儿，他们的黄疸更难看出。应观察巩膜、牙龈和按压后的皮肤，并用经皮胆红素测定仪（胎龄35周或以上、出生超过24小时的婴儿）或血清标本测定胆红素。
- 将结果描绘在与婴儿胎龄对应的NICE**治疗阈值图**上。该图给出**光疗**的胆红素水平，以及更高水平时**换血**的胆红素水平，两者都随婴儿的小时龄增加而升高。
- **迁延性黄疸**是指足月儿超过14天、早产儿超过21天的黄疸。这些婴儿需要测定**结合胆红素**。结合胆红素高于25 µmol/L提示肝脏疾病，需要紧急转诊。

英国的胆红素以µmol/L报告。换算为mg/dL时除以17.1。

**光疗**之所以有效，是因为蓝绿光把皮肤中的胆红素转化为水溶性异构体，这些异构体无需结合即可排出。换血是用供者血液替换婴儿的血液，仅用于极高水平或出现脑病征象时。

::: example 浅色大便 {#ex-palestools}
托马什（Tomasz）4周龄，仍有黄疸。他母乳喂养，体重增长良好。母亲说他的大便变成了浅奶油色，尿色深黄。总胆红素190 µmol/L，其中结合胆红素110 µmol/L。
::: solution
**第1步。**这是迁延性黄疸，所以首先要问它是结合型还是未结合型。此处结合胆红素为110 µmol/L，远高于25 µmol/L。这是**结合胆红素血症**，它绝不是生理性的，也绝不是母乳引起的。

**第2步。**大便颜色浅、尿色深，说明胆红素没有到达肠道，而是经尿液排出。这是胆汁淤积。

**第3步。**最重要的原因是**胆道闭锁**，一种胆管进行性闭塞的疾病。其他原因包括α1-抗胰蛋白酶缺乏症、感染、Alagille综合征和代谢性疾病。

**第4步。**紧急转诊至肝病专科中心进行超声和进一步检查。胆道闭锁通过手术（Kasai肝门肠吻合术）治疗，越早手术效果越好，最好在出生后6–8周内完成。给予维生素K，因为胆汁淤积影响其吸收，这些婴儿可能出血。大便比色卡可帮助家长识别浅色大便。
:::
:::

## 感染及其他早期问题

### 早发型新生儿感染

新生儿感染可在数小时内进展为脓毒症。早发型感染发生在出生后72小时内，通常来自母亲生殖道；**B族链球菌（GBS）**是英国最常见的病原体，其次是*大肠埃希菌*。晚发型感染更多来自环境。

征象是非特异性的：行为或肌张力改变、喂养差、体温不稳定、呼吸困难或呼吸暂停、出生24小时内出现黄疸，或惊厥。NICE指南NG195（2021）列出了**危险因素**（例如母亲GBS定植、早产胎膜早破、母亲产时发热，以及双胎之一疑似感染）和**临床指征**，其中一些被标为**红旗征**，例如出生4小时以后才开始的呼吸窘迫、惊厥、休克征象，或母亲确诊侵袭性感染。

处理原则是：

- 有红旗征，或有两项或以上危险因素或临床指征的婴儿，应做血培养并在1小时内开始抗生素治疗。NG195推荐的一线组合是静脉**苄青霉素加庆大霉素**；剂量依据现行处方集。
- 风险较低的婴儿接受密切观察。对于胎龄34周或以上的婴儿，NG195也允许在结构化项目中使用经过验证的**脓毒症风险计算器**。
- 在开始时以及18–24小时后测定C反应蛋白。如果36小时时血培养阴性、婴儿状况良好且CRP结果令人放心，通常可以停用抗生素。停用不必要的抗生素很重要，因为它们会扰乱婴儿的肠道菌群并促进耐药。

::: example 第2天嗜睡的婴儿 {#ex-sepsis}
阿德（Ade）胎龄39周出生，出生前母亲胎膜已破裂20小时。母亲产时体温38.4 °C。第2天助产士注意到他不愿吃奶，体温35.9 °C，呼吸70次/分，伴呻吟。
::: solution
**危险因素：**母亲产时发热，以及胎膜破裂时间延长（超过18小时）。

**临床指征：**喂养差、体温低，以及在出生很久之后才开始的呼吸窘迫。出生4小时以后开始的呼吸窘迫是红旗征。

**解释。**阿德有红旗征，因此在被证明不是之前，必须按早发型脓毒症处理。最可能的病原体是GBS。

**行动。**上报新生儿团队。做血培养，然后在1小时内静脉给予苄青霉素和庆大霉素，不必等待结果。测定CRP和血糖，并按需给予呼吸支持。如果血培养阳性、婴儿病情很重或有神经系统体征，考虑腰椎穿刺。36小时时根据血培养和CRP结果复核计划。

对新生儿而言，体温过低与体温升高同样重要。
:::
:::

### 低血糖

健康足月儿在出生后最初几天的血糖低于年长儿童，并利用酮体作为替代燃料。有显著低血糖风险的是**代谢适应受损**的婴儿：母亲患糖尿病或服用β受体阻滞剂的婴儿、生长受限的婴儿、早产儿，以及寒冷或患病的婴儿。这些婴儿在第二次喂奶前检测血糖。英国的实践遵循英国围产医学协会（BAPM）的框架（2017），对有风险的足月儿在出生后最初48小时使用2.0 mmol/L的操作阈值，对有异常体征的婴儿容忍度更低。治疗首先是喂养，然后根据血糖水平和婴儿状况使用颊黏膜葡萄糖凝胶或静脉葡萄糖。

::: example 抖动的大婴儿 {#ex-idm}
格雷丝（Grace）的母亲患1型糖尿病，妊娠晚期控制不佳。格雷丝胎龄38周出生，体重4.6 kg。3小时时她出现抖动，血糖1.4 mmol/L。
::: solution
**机制。**母亲的高血糖通过胎盘，使胎儿分泌更多胰岛素。胰岛素在胎儿期是一种生长激素，这就是格雷丝体型大（巨大儿）的原因。脐带剪断后，葡萄糖供应停止，但她的胰岛素水平仍然很高，因此血糖迅速下降。

**评估。**抖动是一种可能反映低血糖的临床体征，她的血糖1.4 mmol/L远低于操作阈值。糖尿病母亲的婴儿还有发生低钙血症、红细胞增多症、黄疸、呼吸窘迫和先天性心脏病的风险。

**处理。**由于她有症状且血糖很低，收入新生儿病房静脉补充葡萄糖。继续喂养。监测血糖直至稳定，并检查血钙。最初几天之后仍持续或反复的低血糖需要查找其他原因。
:::
:::

## 早产儿

::: definition 早产与出生体重 {#def-preterm}
**早产**是指在满37周之前出生。**极早产**是指32周之前出生，**超早产**是指28周之前出生。

**低出生体重**是指低于2,500 g，**极低出生体重**低于1,500 g，**超低出生体重**低于1,000 g。婴儿可因早产、胎儿生长受限或两者兼有而低出生体重。
:::

在英格兰和威尔士，约7–8%的分娩为早产。死亡和远期残疾的风险随胎龄降低而急剧升高。在英国，24周出生并接受重症监护的婴儿现在有一半以上存活，但相当一部分存活者有残疾。

出生前和出生时的若干干预措施可改善结局。给母亲使用**产前糖皮质激素**可促进肺成熟，减少呼吸窘迫、脑出血和死亡。在极早产分娩前给予**硫酸镁**可降低脑性瘫痪的风险。**延迟脐带夹闭**、**为婴儿保暖**（极早产儿使用塑料袋或包裹膜）以及在设有新生儿重症监护病房的中心分娩都有帮助。

早产的主要问题源于各器官的不成熟：

| 系统 | 问题 | 要点 |
|---|---|---|
| 肺 | 呼吸窘迫综合征 | 表面活性物质缺乏；用CPAP和表面活性物质治疗 |
| 肺 | 支气管肺发育不良 | 校正胎龄36周时仍需吸氧 |
| 呼吸控制 | 早产儿呼吸暂停 | 用咖啡因治疗 |
| 脑 | 脑室内出血、白质损伤 | 头颅超声发现；有脑性瘫痪风险 |
| 肠道 | 坏死性小肠结肠炎 | 腹胀、血便；母乳具有保护作用 |
| 眼 | 早产儿视网膜病 | 对31周前出生或体重低于1,501 g的婴儿进行筛查 |
| 心脏 | 动脉导管未闭 | 可引起心力衰竭或加重肺部疾病 |
| 免疫 | 晚发型脓毒症 | 常与中心静脉导管有关 |
| 体温 | 低体温 | 皮肤薄、脂肪少、体表面积大 |

**早产儿视网膜病**是视网膜血管的异常生长。它由不成熟引起，并因过量用氧而加重。由眼科医生进行筛查，可以在视网膜脱离之前进行激光或抗VEGF治疗。这就是为什么早产儿的血氧饱和度目标要谨慎设定，既避免用氧过多，也避免用氧过少。

早产儿出院后需要随访。他们的生长和发育按校正年龄评估（见[[paediatrics/growth-development]]），他们发生脑性瘫痪、学习困难、注意缺陷多动障碍和孤独症的风险更高。他们按通常的实际年龄而不是校正年龄接受常规疫苗接种。

::: example 超早产分娩前该说什么 {#ex-extreme}
一名妇女在妊娠23周4天时早产临产。新生儿科顾问医师在分娩前与父母见面。顾问医师需要讨论什么？
::: solution
这次谈话遵循英国围产医学协会关于超早产分娩的框架（2019），该框架建议决策应基于对婴儿总体风险的评估，而不仅仅是胎龄，并与父母共同作出。

**信息。**顾问医师解释这一胎龄婴儿可能的存活机会和严重残疾的机会，并根据改变风险的因素加以调整：估计体重、是否已使用糖皮质激素、性别、单胎或多胎，以及分娩地点。数字尽可能清楚地给出，并如实说明不确定性。

**选择。**在22–23周，积极稳定治疗和以舒适为主的照护都可以是合理的。父母的价值观是核心。如果选择积极治疗，则给予糖皮质激素和硫酸镁，并应在设有新生儿重症监护病房的中心分娩。

**计划。**讨论内容包括出生时将发生什么、随着婴儿状况变得明朗可以重新考虑决策，以及如果需要，姑息治疗是什么样子。记录这次谈话，并为父母提供时间、书面信息和进一步讨论的机会。
:::

::: quiz
一名足月儿在出生12小时时出现肉眼可见的黄疸。正确的第一步是什么？
- [ ] 告诉父母这是生理性黄疸，第3天复查。
- [ ] 鼓励更频繁地母乳喂养，明天再观察肤色。
- [x] 紧急测定血清胆红素，在2小时内完成。
- [ ] 因为黄疸迁延，测定结合胆红素。
::: solution
出生24小时内出现的黄疸总是病理性的，提示溶血或感染。必须紧急测定胆红素，并描绘在治疗阈值图上。生理性黄疸在第2天或之后出现，迁延性黄疸指超过14天。
:::

::: history
早产儿的照护始于保暖。1880年，巴黎产科医生斯特凡·塔尼耶（Stéphane Tarnier）引入了一种由孵化小鸡用的孵化器改造而来的暖箱，他的同事皮埃尔·布丹（Pierre Budin）证明保暖、细致的喂养和卫生可提高存活率。1952年，美国麻醉医师弗吉尼亚·阿普加（Virginia Apgar）提出了评估新生儿的评分，次年发表。1959年，玛丽·埃伦·埃弗里（Mary Ellen Avery）和杰尔·米德（Jere Mead）证明，死于呼吸窘迫综合征的婴儿肺中缺乏表面活性物质。1972年，格雷厄姆·利金斯（Graham Liggins）和罗斯·豪伊（Ross Howie）报告产前糖皮质激素可减少早产儿的呼吸窘迫；1980年，藤原哲郎（Tetsuro Fujiwara）及其同事报告用人工表面活性物质治疗成功。黄疸的光疗也有一个简单的起源：20世纪50年代，埃塞克斯郡罗奇福德医院的护士注意到，放在阳光下的婴儿黄疸减轻，理查德·克里默（Richard Cremer）及其同事于1958年发表了光疗试验。
:::

::: summary
- 出生时肺充气、肺阻力下降、胎儿分流通道关闭；患动脉导管依赖性心脏病的婴儿可在动脉导管关闭时衰竭。
- 使肺充气是新生儿复苏中最重要的步骤。Apgar评分描述婴儿状况，但不指导复苏。
- NIPE在72小时内和6–8周时筛查眼、心脏、髋和睾丸；在英格兰，第5天的血斑检测筛查九种疾病。
- 第一周体重下降至多10%很常见；通常2周时恢复出生体重。
- 出生24小时内的黄疸是病理性的；迁延性黄疸需要测定结合胆红素，浅色大便提示胆道闭锁，需要紧急转诊。
- 早发型感染表现隐匿；有红旗征或多项危险因素时，应做血培养并在1小时内给予苄青霉素加庆大霉素，36小时时复核。
- 早产影响每一个器官。产前糖皮质激素、硫酸镁、延迟脐带夹闭和保暖可改善结局，存活者需要发育随访。
:::

::: exercise 计算体重下降 {level=1 check="round(1000*(3.65-3.32)/3.65)/10"}
一名出生体重3.65 kg的婴儿第3天体重3.32 kg。丢失了出生体重的百分之几？保留一位小数。
::: solution
下降量为$3.65 - 3.32 = 0.33$ kg，$0.33/3.65 \times 100 = 9.04\%$，四舍五入为**9.0%**。这在通常范围内，但接近上限，因此应复核喂养并再次称重。
:::

报告胆红素为300 µmol/L。换算为mg/dL，保留一位小数。
::: solution
$300/17.1 = 17.54$，即**17.5** mg/dL。
:::

说出新生儿和婴儿体格检查的四项筛查内容，以及每项旨在发现的一种疾病。

眼：先天性白内障（红光反射）。心脏：先天性心脏病。髋：发育性髋关节发育不良。睾丸：隐睾。

::: exercise 每日喂养量 {level=2 check="3.2*150/8"}
一名配方奶喂养的婴儿体重3.2 kg，按150 mL/kg/d分8次等量喂养。每次应喂多少毫升？
::: solution
每日总量为$3.2 \times 150 = 480$ mL。分为8次，每次为$480/8 = $ **60 mL**。实际中奶量会根据婴儿的饥饿程度和体重增长调整。

::: exercise 停用抗生素 {level=2}
一名足月儿因母亲产时发热，在2小时龄时开始使用苄青霉素和庆大霉素。36小时时婴儿吃奶良好、生命体征正常，血培养无生长，CRP开始时为4 mg/L，20小时时为6 mg/L。应该怎么做？为什么这很重要？
::: solution
婴儿状况良好，36小时血培养阴性，两次CRP都低，因此应按照NG195**停用**抗生素，婴儿通常可以出院，并向父母交代预警征象。停药之所以重要，是因为不必要的抗生素会扰乱发育中的肠道微生物群、促进抗生素耐药、使母婴滞留医院，并使婴儿承受留置套管和庆大霉素的风险。
:::
:::

::: exercise 光为什么能治疗黄疸 {level=2}
解释为什么光疗不需要肝脏结合就能降低新生儿的胆红素，以及为什么它用于未结合型黄疸而不用于结合型黄疸。
::: solution
未结合胆红素是脂溶性的，在肝脏结合之前不能经胆汁或尿液排出。皮肤中的胆红素吸收蓝绿光后，转化为水溶性更强的异构体（构型异构体和光红素），无需结合即可经胆汁和尿液排出。光疗针对的是核黄疸的风险，后者来自未结合胆红素穿过血脑屏障。在结合型黄疸中，问题是胆汁淤积：胆红素已经结合，不具有同样的神经毒性，任务是找出并治疗肝脏或胆管疾病。
:::

::: exercise 第3天衰竭的婴儿 {level=3}
一名足月女婴在18小时时NIPE正常并出院。第3天她被送到急诊科，面色灰白、呼吸急促、吃奶差。她的肝脏肿大，摸不到股动脉搏动。讨论最可能的诊断、紧急处理，以及如何解释先前正常的检查。
::: hint
想一想出生后最初几天循环中发生了什么变化。
:::
::: solution
**可能的诊断。**第3天出现股动脉搏动减弱伴休克和心力衰竭，强烈提示**动脉导管依赖性体循环**，最常见的是**主动脉缩窄**，或重度主动脉瓣狭窄或左心发育不良。鉴别诊断包括脓毒症和遗传代谢病，须同时处理。

**为什么检查正常。**动脉导管开放时，来自肺动脉的血液经导管到达降主动脉，因此股动脉搏动存在。随着导管关闭，下半身血流减少。

**紧急处理。**复苏（气道、呼吸、循环），并在专科指导下开始输注**前列腺素E**（前列地尔或地诺前列酮）以重新开放导管；呼吸暂停是其副作用，因此要做好呼吸支持的准备。血培养后给予抗生素，检查血糖和血气，并安排紧急超声心动图和转运至心脏中心。

**经验。**每次检查都必须触摸股动脉搏动，家长应了解预警征象，早期检查正常不能排除动脉导管依赖性疾病。
:::
:::

::: exercise 26周早产儿的照护计划 {level=3}
一名胎龄26周出生、体重850 g的婴儿现在4周龄。列出团队在接下来几周要关注的早产问题，以及婴儿出院前后需要的筛查。
::: solution
**住院期间。**呼吸窘迫综合征和支气管肺发育不良的风险（校正胎龄36周时的用氧需求）；早产儿呼吸暂停（用咖啡因治疗）；动脉导管未闭；增加喂养时的坏死性小肠结肠炎（母乳具有保护作用）；晚发型脓毒症，尤其是有中心静脉导管时；脑室内出血和白质损伤（头颅超声）；贫血和早产儿代谢性骨病；营养与生长；以及体温控制。

**筛查。****早产儿视网膜病**筛查，因为婴儿在31周前出生且体重低于1,501 g。听力筛查（在重症监护病房的早产儿听力损失风险更高）。常规血斑检测（早产儿按要求重复采样）。按正常实际年龄从8周开始接种疫苗，即使仍在住院。

**出院后。**在校正年龄下随访生长和发育至2岁，并进行正式的发育评估，因为脑性瘫痪、学习困难、孤独症和注意缺陷多动障碍的风险增加。对经历了漫长而紧张住院过程的父母给予支持，也是照护的一部分。
:::
