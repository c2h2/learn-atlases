疫苗是人类历史上最成功的医学干预、也是最被误解的。免疫接种把基础的免疫学（安全地呈递抗原并产生记忆）与群体的科学结合起来：时间表与冷链及覆盖率的阈值及不良的事件的监测，以及“场所决定来之不易的群体的免疫能否挺过一条谣言的沟通”。临床的工作很小、而社会的判断很大。

## 科学与时间表

::: definition 疫苗的免疫学与方案 {#def-science}
**疫苗如何起效，以及时间表为何在那里。平台的分类：“减毒的活的疫苗在复制，驱动很强的细胞的与体液的记忆，一到两剂即可——带着排出与妊娠及免疫受损的禁忌；灭活的与亚单位的与结合的技术——那”把多糖结合到蛋白上的技巧，它使B型流感的嗜血杆菌与肺炎的球菌及脑膜炎的球菌能在婴儿中被预防——因为T细胞非依赖的抗原在婴儿中不起作用这就是“为什么2岁之下需要结合疫苗的解释；白喉与破伤风的类毒素的科学；人乳头状的病毒与轮状的病毒的类病毒颗粒的工艺；以及更新的信使的核酸与病毒的载体的平台带着它们脂的纳米的颗粒的递送，与那件历史性的2020年的事：快，因为序列就够了；以及那份让冈比亚与卢旺达能快速地部署抗疟疾信使疫苗的精确；以及佐剂的科学——铝的盐与那两种新的佐剂，以及为什么佐剂的意思是“每一剂更具免疫原性、代价是一条酸痛的胳膊”，而不是“化学的兴奋”。时间表的逻辑：“母体抗体的干扰这就是为什么麻疹在多数方案中放在12个月、而不是4个月，而在流行时更早；”为什么那多种联合的疫苗放在8与12与16周这一基础的系列，配上“加速的时间表与补种的最小的间隔的规则；”乙肝出生的一剂是为了围产的风险；以及卡介苗与脊髓灰质的“谁住在哪里”的方案；”青少年的加强人乳头状的病毒与脑膜炎的球菌及白喉破伤风——为什么放在11到14岁：免疫原性在11到14岁比在16岁更好这是真的，而覆盖率的问题是一回事；“终身被保有的标题在可行时——麻疹与水痘的自然的加强，以及百日咳的减弱与母亲的那一剂；以及以及群体的免疫的阈值”每一种病原的那个数不同；而把学校的入学当作一个控制的点——这就是为什么一份接种的记录是一份旅行的文件。而解释“为什么接种过的人还会生病”的话：“疫苗不是100%的，而它们是对比这种病会造成什么来被测量的、不是对比完美；两剂接种者的突破的麻疹罕见而通常轻微，而他们仍然传染得更少这一续发的攻击率的教育；“变异免疫的逃逸对感染在减弱、对重症并不如此——这就是为什么按型的更新关注于住院”这一真正有帮助的语言；以及那个收尾的论证：”而有些人因为真实的医学的原因不能接种——而保护他们，正是为什么覆盖率是一个道德的数字、不是一个官僚的数字——这一章讲的其实正是这件事“[[immunology/vaccines-immunotherapy]]、[[immunology/adaptive-responses]]、[[public-health/vaccination-programmes]]、[[infectious-diseases/stewardship-outbreaks]]。**

## 实务与安全

::: definition 临床的免疫接种的实务 {#def-practice}
**“方案的成败就在这次门诊里”。筛查与技术：“真实的对神话的禁忌的那份清单——聚乙二醇的脂与乳胶及酵母的成分的成分图因为是哪一种成分会影响转诊的决定；”打在对的肌肉、对的角度的针，针的长度要够穿过脂肪垫，而永远不要回抽；以及那套注射的技术的科学：“三角肌对大腿——而臀部对免疫的反应是错的，出于法律的理由也是错的”；以及”晕倒正是我们把人接种时让坐着并观察15分钟的理由——那个最常发生的反应是晕厥、不是过敏；而把晕厥当晕厥来治，能同时预防伤害与检查与那个神话。急性的反应：“在接种的门诊里的过敏性休克平躺、肌注肾上腺素、叫急救、5分钟后第二剂并观察；以及那条细微：”正在用支气管扩张剂的哮喘者要有更低的用肾上腺素的阈值；以及免疫接种相关的压力的体验——过度换气并发抖的九年级的成簇者，靠冷静的分开来处理、而不是靠救护车的调度；那条规则：“重新评估、绝不可轻慢；以及肩的损伤来自力学、不是来自阴谋这一鉴别；以及那份量化的诚实：”信使的疫苗之后的年轻男性的肌炎罕见而通常轻微，而这种病造成的肌炎更常见也更重——这两个事实放在同一句话里“。特殊的人群：”脾的切除与补体的缺陷及那种补体的抑制的药及艾滋病与原发的免疫的缺陷——活疫苗的规则及免疫受损者的家庭接触者及轮状的病毒的排出及避免卡介苗这一免疫受损的矩阵；“在妊娠中的安全灭活的与流感及疫苗；活的不行；以及”早产儿的按出生体重的规则与家庭接触者的接种“。信任的基础设施：”学校的护士与全科的团队需要对那七个反复出现的问题准备好被写好的回答，以及按证据分级的传单配12种语言；以及那份政策的诚实：“疫苗的犹豫要靠获取与连续及信任来解决、不靠羞辱、也不靠在公众面前强制的论证——尽管学校人乳头状病毒的方案与医护人员的接种展示了默认的机制能做到什么“。以及那句”方案是医学、不是行政”：“冷链与携带及锐器的容器及为过敏性休克做好准备这一运作的纪律；以及”谁拥有数据与未接种者的追踪及获取的公平的监测这一基础设施——因为一支在冰箱里的疫苗不是被接种了的疫苗，而一剂被接种了也不等于一个人被保护了，直到第二剂也被接种“[[immunology/immunodeficiency]]、[[obstetrics-gynaecology/pregnancy-antenatal]]、[[public-health/vaccination-programmes]]。**

::: definition 常规的时间表之外的疫苗 {#def-situations}
**“第二套适应证的课程”。旅行与特殊的暴露：套“按行程与季节及海拔及停留的时长”的框架——”对大多数的热带的行程用伤寒与甲型的肝炎；对亚洲的乡村的夏天的旅行用日式的脑的炎；以及狂犬病的暴露前与暴露后带着那句紧迫：“在果阿被狗咬了是一次医学的预约、不是一段假期的回忆；以及那最便宜的一条救命的招：”先冲洗手部15分钟“；黄热的疫苗配发证的中心与国际的证书及”在过境的10天之前接种的物流；口服的霍乱用于危机的地区；疟疾的预防是一味药、不是一枚疫苗；以及那个被错失了大多数旅行者风险的提问——“住在家乡院子里的朋友与亲人们比打包的观光客风险更高，你问过他们吗？”；以及那道算术：“旅行的门诊要在4到6周之前、不是在机场”。流行与职业的工具：“环状的接种带着天花的遗产与猴痘，以及”有限的剂量先给谁这一分配的伦理；在营地与洪水中的口服的霍乱；低覆盖率的地区的大规模麻疹运动的方案对常规的服务的加强——基层的照护对垂直的运动的这场永恒的辩论；医护人员的乙肝与水痘及麻疹及百日咳及流感；以及“从来没有记录学生职业健康的现实；以及”在职业的健康护士到来之前先处理——一次针刺伤的急诊医学“。还有”谁该得到什么“：”脾的切除与镰状的细胞及补体的缺陷：肺炎的球菌与脑膜炎的球菌及乙型的流感的嗜血杆菌的疫苗，加上青霉素预防的方案——那张“为什么这个幼儿在吃抗生素？”的处方，它是预防、不是治疗；“被切除了脾的孩子的这份记录的协议的要点疫苗与预防的药及一份书面的计划及一只被携带的蜂鸣器；”疟疾化学的预防按行程的方案，包括按体重的儿童给药及依从性与耐药性的地形图；以及“治疗性的疫苗正在到来也在退去——癌症治疗性疫苗的失望对人乳头状病毒预防的胜利这一对比的教训”恶性黑色素的这几十年对宫颈的癌的这几十年“；以及”新的那一类：呼吸合胞病毒母体的疫苗与婴儿的单克隆的抗体——“疫苗相邻的被动的免疫”，人人都要学；以及那个必然的下一个问题：“谁在哪里为它付钱”。而这一切都汇聚到一处：“一枚疫苗在获批之后的生命——谁被提供它、谁能拿到它、谁相信它、以及谁付钱——属于公共卫生；而儿科医师是它的一线临床医师、也是它最有说服力的翻译者”[[public-health/vaccination-programmes]]、[[public-health/global-health]]、[[microbiology/infection-control]]、[[medical-ethics-law/justice-resources]]。**

::: example 例“托幼机构的麻疹” {#ex-measles}
一名20个月的未接种的孩子出现发热与咳嗽及流涕及结膜炎，随后出疹；全科怀疑麻疹；这家人住在一个跨代的家庭里，有一个6周大的婴儿与一位正在服霉酚的祖母；而这个孩子在一所“未接种者成群的托幼机构”里。
::: solution
**“在一个真实家庭里的麻疹”（[[#def-science]]、[[#def-practice]]、[[paediatrics/acute-childhood-illness]]）：临床与公共卫生的这份双份工作——“用咽的拭子与尿做聚合酶的链式的反应及免疫球蛋白M来确认；在这家人走进候诊室之前就告诉急诊与门诊的员工；麻疹经空气传播，所以这间房间与那条走廊及别的患者才是那起公共卫生的事件——现在就做感染的控制、不是明天；在急性期按指导用维生素A与水化；并为肺炎与脑炎做安全网——因为这个病毒是通过它的并发症来杀人的；而儿科的资深的医师持有临床的半。家庭——“年长的兄姐今天就要补种、不是等下一次检查；学校与托儿所需要被给出的隔离的期限与接触者的名单，以及”在门外搭一顶帐篷来接种“这一交付；以及那公平的医学：这个家庭需要的是交通与被匹配到其语言的信息、不是一张英文的传单”。一群——“句有点难说的诚实：”一所未接种者成群的托幼机构是一些父母主动承担的一种被计算过的风险，而流行就是这笔账单到来的方式说的时候不要带幸灾乐祸；”对暴露者在72小时之内的环状的接种能提供某些保护；把易感的接触者从第5天隔离到第21天；主动的病例与接触者的管理的监测；以及一次战时式的“我们要把缺失的那30个孩子的家门一扇扇敲开”的方案——这就是高覆盖率的国家已经忘了怎么做的事；以及那条通知：“这是本季度这一区的第7例麻疹”[[infectious-diseases/stewardship-outbreaks]]、[[public-health/vaccination-programmes]]、[[paediatrics/safeguarding]]。**

::: example 那个“该吃轮状的病毒的疫苗”的免疫缺陷的婴儿 {#ex-bcg}

## 通向何处

机制的免疫学在[[immunology/vaccines-immunotherapy]]与[[immunology/adaptive-responses]]，方案的设计与犹豫在[[public-health/vaccination-programmes]]，流行期间感染的控制在[[infectious-diseases/stewardship-outbreaks]]与[[microbiology/infection-control]]，而新生儿的出生的一剂在[[paediatrics/newborn]]。

::: history
**免疫接种是“医学最古老的经验的胜利、也是最年轻的一门社会学”：从人痘的接种到疫苗的这条谱系——几个世纪以来的中国与奥斯曼的皮肤的接种的传统，经由1721年蒙塔古夫人的引入到达乔治时代的英国；以及在新英格兰的那位被奴役的奥奈西穆斯 与其主人的讲述。然后是牛痘的接种：詹纳的那位挤奶的女工与1798年那份薄薄的册子；巴斯德减毒的鸡的霍乱与炭疽及狂犬病；以及柯霍与白喉的类毒素与抗毒素。二十世纪带来了卡介苗与病毒性脑炎疫苗的脊髓灰质、以及那两种口服对注射的竞赛；然后是泰勒与麻疹及那种种联合的疫苗；而世界卫生组织天花的根除1980)“——一次被人类主动干掉的疾病。然后是现代的这层：”乙型肝炎的疫苗与人乳头状的病毒及结合的技术；以及那段那例肠道的研究与韦克菲尔德的那份被撤稿的论文（它制造了三十年的伤害）。以及2020年代的层：“信使核酸的平台在一场流行中被部署；欧洲的覆盖率在下滑；而”反疫苗“成为一种被组织化的政治的运动；以及那个去影响的年代——卫生的部门学会了诚实地说”我们还不知道“正是打败下一条谣言的方式”。方案成熟了，并同时保住这两课——科学与共同体——因为每一枚疫苗归根到底是一种关于被共同认可的风险的社会的技术”[[public-health/vaccination-programmes]]、[[public-health/global-health]]、[[immunology/vaccines-immunotherapy]]。**
:::

::: summary
- “平台决定了规则：减毒的活疫苗在妊娠与深度的免疫抑制中被限制；而结合疫苗之所以存在，是因为婴儿无法对纯的多糖作出回答。
- 时间表编码着免疫学——母体抗体的干扰与最小的间隔及青少年的加强，以及把孕期接种当作经胎盘新的生的预防。
- 大多数急性的“反应是晕厥或压力的反应”；把它们当作它们本身来处理；并为那个真正的罕见备好肾上腺素。
- 方案的成功是基础设施：冷链与登记册及召回及被按公平绘图的覆盖率及流行的演练，以及诚实的药物警戒。
- 用精确比较的风险来回答父母；为要再等等的人留着一扇门；并不带羞辱地记录提供与拒绝。
- ”免疫缺陷的孩子们证明了覆盖率为何是一种集体的责任：他们只被别的人的每一剂保护着。
:::

**“不靠谎言的谣言的控制”（[[#def-practice]]、[[public-health/vaccination-programmes]]、[[clinical-skills/communication]]）：先判定、再开口——“去查收住的登记与急诊及学校及不良的事件的登记册，以及”到底谁收住了孩子“——按名字；因为”我们否认一文不值，除非你能补上因为我们查过了；而如果答案是一个孩子有过一次热性的惊厥、一次晕厥、一次无关的胃肠炎，就在获得家庭的许可之后一字不差地这么说、而不是把它们匿名成一个幽灵；具体，才是打败一个含糊故事的方式；以及那个不带对抗的重构：“我们理解你们被告知的是三个孩子，而这是实际发生的”；绝不要把“这与疫苗没有关联”作为第一条发出去；先发“这是实际发生了什么”。然后——”48小时之内一次面对面的会学校的体育馆，配一位资深的儿科医师与那位打过第一通电话的护士；把每一剂与每一批号都核查一遍；“把撤回的家庭按名字一个一个地回访不是群发的信；三周内每周对齐覆盖率；”对媒体的那句话要与对家长的那句话一字不差；“发布（在同意后）具体的孩子后来怎么样了——因为下一条谣言还会再用到他们；”以及那次对员工的复盘——“因为为一件做好的工作而被憎恨会让人受伤，而没有人提起这件事”这一文化“。那个方案保住的教训是：疫苗的安全是一门带着一间门诊沟通的服务，而它需要一笔预算——因为流行在第一孩子到达医院之前的48小时，就已经在群聊里被决定了”[[clinical-skills/communication]]、[[public-health/determinants-inequalities]]、[[clinical-skills/patient-safety]]。**

学校里人乳头状病毒疫苗的覆盖率整体是87%，而在一个有高的缺课率、新来移民的家庭与一个发声网络共同体的行政区里是58%。请设计这个评估与干预，并把强制的问答得明明白白。

**“人乳头状病毒公平的评估”（[[#def-science]]、[[public-health/vaccination-programmes]]、[[medical-ethics-law/justice-resources]]）：先诊断、再运动——“把接种的记录与出勤及特殊的教育的需要及癫痫及”被照管的身份“及搬家的次数链接起来；”这是一个拒绝的问题、还是一个在场的问题？——因为在一个缺课率达60%的人群里的58%，几乎总是在场的问题；那个重构：“那个”难以触达“的标签是对服务的一份起诉书、不是对家庭的”；按选区与语言及学校做分层；并把“有信息的拒绝”的计数与“从未被恰当地提供”的计数分开测量——因为那是两种不同的疾病；与青少年一起做定性的工作他们实际上听到了什么——因为性的癌的流言会在学校与家长的群组里流传。干预——“在校内、也在校外为那些不上学的孩子提供；傍晚与周末的诊所及流动的团队；同意的工作与一个私人的空间；一个不被旁观的选项对跨性别与有信仰的孩子；以及为无证父母孩子的一剂与别的东西（这绝不成为一次执法的相遇）。强制的那个问题——”同意属于这个年轻人或那位有亲权的人；我们可以提供并极力推荐、并把拒绝当作一个合法的答案；而我们不通过默认把接种与出勤或入学绑在一起“。问责——”按学校每季度的公布覆盖率，以及“谁最接近那个58%、是怎么做到的”这一友好的竞争；一个青少年的小组每年审查材料，并对措辞有否决权；把信任的调查（“你会为了第二剂再来吗？”）作为一级的结局来测量——因为这一方案正是那个能证明现代的公共卫生能否赢得同意、而不只是收集同意的方案；而这里的公平的失败要付出一代本可预防的癌——而孩子恰恰是最承受不起的那一批“[[public-health/screening]]、[[paediatrics/adolescent-health]]。**

## 继续深入

有三件事，超出了时间表本身，完成了免疫接种的课程。第一，去学例外的表格、而不只是常规的：被严重抑制的孩子活疫苗被按住、而家庭的接触者被接种；被切除了脾的与有补体的缺陷的患者脑膜炎的与肺炎的加剂配加强；暴露于乙型肝炎的婴儿；以及那个“按实际的年龄与完全的剂量接种”的早产的孩子；还有旅行与流行的场景，带着它们的环状的剂次的算术。这一领域的大多数的临床的错误是例外的失败、不是时间表的失败。第二，把犹豫的那场谈话排练到流利：先问这个家庭听到了什么、从谁那里听到的，认可这个问题保护孩子是我们共同的动机，把你的推荐当作一项推荐来陈述、不是一份菜单，讲一个你真见过的受到伤害孩子的故事，以及预约下一次门诊，而不是让这个家庭输在一场二对一的争论里。来自动机式面谈试验的证据是：有指引的共情会推动接种率，而对峙不会；而任何一家诊所覆盖率的审计，通常追踪的是它的临床医师如何应对那场十五分钟的谈话、胜过了他们如何应对冷链。第三，“把每一次的接种的接触当作实时的监测”：接种之后的发热正是一次询问那些没有人安排过里程碑的机会；一处与疫苗的反应不匹配的皮疹是一次给健康保护小组的电话；而那个错过了四次访视的孩子是一个值得摸一摸的保护的信号。”免疫接种是一门罕见的专科：出色的实践是以那些不再出现在你病房里的疾病来被测量的——这让它的纪律很容易丢失；而能守住它的临床医师，是在一个清闲的周二，仍然会问自己：如果那个带着发热的未接种的幼儿现在走进来，我会怎么做的人“。
