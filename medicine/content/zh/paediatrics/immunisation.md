除清洁饮水外，疫苗比任何其他医学干预措施预防了更多的儿童死亡。几代人以前挤满儿童病房的疾病，如白喉、脊髓灰质炎和b型*流感嗜血杆菌*脑膜炎，如今在英国已很罕见。这一成功也带来了它自己的难题：今天的家长很少见到这些疾病，却常常听说疫苗的副作用，有真实的，也有想象的。

临床工作有三个部分。第一是理解疫苗在婴儿体内如何起作用，因为这解释了免疫程序。第二是在正确的时间安全地接种正确的疫苗，并了解少数真正的禁忌证。第三是以诚实回答家长问题的方式与家庭沟通。本章涵盖这三方面，以截至2026年的英国免疫规划为例。免疫程序会变化，因此现行的UKHSA《绿皮书》（*Immunisation against infectious disease*）始终是参考依据。

## 疫苗如何保护儿童

::: definition 疫苗类型与免疫应答 {#def-science}
**主动免疫**刺激儿童自身的免疫系统产生抗体和记忆细胞。**被动免疫**提供现成的抗体，如免疫球蛋白或单克隆抗体制剂，或抗体经胎盘从母亲传给胎儿。被动保护立即生效，但会在数周至数月内消退。

**减毒活疫苗**含有在体内短暂复制的减弱病原体，如MMRV、轮状病毒疫苗和卡介苗。它通常在一至两剂后产生强而持久的免疫，但必须避免用于免疫功能严重低下者和孕妇。

**灭活疫苗**含有被杀死的病原体、其纯化成分或灭活毒素（**类毒素**，如白喉和破伤风类毒素）。它不会引起感染，但通常需要多剂和加强接种。

**结合疫苗**将细菌多糖与载体蛋白连接，如Hib、肺炎球菌和脑膜炎球菌疫苗。
:::

### 婴儿为什么需要结合疫苗

引起婴儿最危险感染的细菌（Hib、肺炎球菌和脑膜炎球菌）被多糖荚膜包裹。针对荚膜的抗体具有保护作用，但约2岁以下的婴儿对单纯多糖抗原反应很差。

::: theorem 结合使多糖变成T细胞依赖性抗原 {#thm-conjugate}
婴儿对多糖疫苗反应很差，但对结合疫苗反应良好，因为把多糖与蛋白质连接可募集T细胞辅助，从而产生类别转换的抗体和免疫记忆。
:::

::: proof
单纯多糖通过交联B细胞受体直接激活B细胞。这种**T细胞非依赖性**应答依赖于脾边缘区的一群B细胞，而这群细胞在婴儿期尚未成熟，因此婴儿产生的抗体很少。产生的抗体主要是IgM，且不形成记忆。在结合疫苗中，受体识别多糖的B细胞摄取整个结合物，加工其中的蛋白载体，并通过MHC II类分子把载体肽段呈递给辅助性T细胞。T细胞随后帮助该B细胞转换为IgG、实现亲和力成熟并形成记忆B细胞。婴儿从2月龄起就能产生这种应答。结合疫苗还能减少细菌在鼻咽部的携带，因此也能保护未接种的人。
:::

### 母传抗体与免疫程序的时间安排

IgG抗体主要在妊娠晚期通过胎盘。它们在最初几个月保护婴儿，但也会中和活疫苗。这是含麻疹成分疫苗在1岁而不是婴儿早期接种的主要原因。早产儿获得的母传抗体较少，这也是他们按正常实际年龄接种、不校正早产的原因之一。

为孕妇接种疫苗是在有意利用同样的转运。孕期接种百日咳疫苗可在婴儿能自己接种之前保护他们免受百日咳，孕期接种RSV疫苗可保护他们免受毛细支气管炎。

### 人群保护

疫苗保护个体儿童，也减少传播。如果人群中有足够多的人具有免疫力，平均每个病例引起的新病例少于一个，疫情就会消退。

::: theorem 群体免疫阈值 {#thm-herd}
如果在完全易感的人群中每个病例引起$R_0$个新病例，那么当免疫比例$p$超过

$$
p_c = 1 - \frac{1}{R_0}
$$ {#eq-hit}

时，传播降至更替水平以下。如果疫苗能使接种者中比例为$E$的人免于感染，所需的疫苗接种率为$p_c / E$。
:::

::: proof
当人群中比例为$p$的人具有免疫力时，一个感染者的接触者中只有比例$1-p$的人能被感染，因此平均每个病例引起$R = R_0(1-p)$个新病例。当$R < 1$，即$1 - p < 1/R_0$时感染减少，整理后得$p > 1 - 1/R_0$。如果接种使一个人以概率$E$获得免疫，那么接种率$c$产生的免疫比例为$cE$，因此需要$cE > p_c$。这个简单模型假设随机混合。真实人群中存在未接种儿童的聚集，例如在一所学校或一个社区中，即使全国接种率看起来很高，这些地方也可能发生疫情。
:::

::: widget plot
f: 1 - 1/x
x: 1, 20
y: 0, 1
hlines: 0.95
labels: p_c = 1 - 1/R_0
caption: 群体免疫阈值随$R_0$急剧上升。麻疹（$R_0$约12–18）需要约92–94%的人具有免疫力，这就是为什么WHO的目标是两剂含麻疹成分疫苗接种率达到95%。$R_0 = 2$的感染只需50%。
:::

::: example 麻疹疫苗接种率多少才够？ {#ex-herd}
取麻疹$R_0 = 15$。两剂含麻疹成分疫苗可保护约97%的接种儿童。要防止持续传播，两剂接种率需要达到多少？
::: solution
**阈值。**$p_c = 1 - 1/15 = 14/15 = 0.933$，因此约93.3%的人群必须具有免疫力。

**接种率。**由于只有97%的接种儿童获得免疫，所需接种率为$0.933/0.97 = 0.962$，约**96%**。

**解释。**麻疹需要几乎普遍的接种。在英格兰，5岁儿童的两剂接种率多年来一直远低于95%，这就是麻疹疫情卷土重来的原因，尤其在接种率较低的社区和地区。一剂可保护约93%，因此第二剂对个体儿童和人群都很重要。
:::
:::

## 英国常规免疫程序

下表显示截至2026年、经过2025年7月和2026年1月调整后的英格兰常规免疫程序。英国其他地区的程序非常相似。

| 年龄 | 疫苗 |
|---|---|
| 8周 | 六联疫苗（DTaP/IPV/Hib/HepB）第1剂；MenB第1剂；轮状病毒疫苗第1剂 |
| 12周 | 六联疫苗第2剂；MenB第2剂；轮状病毒疫苗第2剂 |
| 16周 | 六联疫苗第3剂；肺炎球菌结合疫苗（PCV）第1剂 |
| 1岁（满一周岁当天或之后） | PCV加强；MenB加强；MMRV第1剂 |
| 18个月 | 六联疫苗第4剂；MMRV第2剂 |
| 2岁至11年级结束 | 流感疫苗（减毒活疫苗鼻喷剂），每年秋季 |
| 3岁4个月 | 学龄前四联加强疫苗（dTaP/IPV） |
| 12–13岁 | HPV（一剂） |
| 14岁 | Td/IPV青少年加强；MenACWY |

六联疫苗预防白喉、破伤风、百日咳、脊髓灰质炎、Hib和乙型肝炎。MMRV预防麻疹、流行性腮腺炎、风疹和水痘。

### 2025年和2026年的变化

- **2025年7月。**婴儿MenB第2剂从16周提前到12周，因为MenB疾病在出生后最初几个月达到高峰。婴儿期唯一一剂PCV从12周移到16周。
- **2026年1月。****MMRV**取代MMR，将水痘纳入常规规划。1岁时的**Hib/MenC**加强接种被取消：青少年MenACWY规划已使婴儿MenC疾病变得罕见，Hib加强改由第4剂六联疫苗完成。为2024年7月1日或之后出生的儿童新设了**18个月**接种，以接种第4剂六联疫苗和第2剂MMRV。

在这些日期之前出生的儿童遵循过渡规则。例如，2022年9月1日至2024年12月31日出生的儿童在3岁4个月接种时接种MMRV；2026年11月至2028年3月，为2020年1月1日至2022年8月31日出生、未患过水痘也未接种过水痘疫苗的儿童提供一剂MMRV补种。对任何具体儿童，以现行《绿皮书》和儿童的接种记录决定应接种什么。

### 各剂次为什么安排在这些时间

- **8、12和16周。**三剂灭活疫苗间隔一个月，在百日咳、Hib和MenB疾病的高峰年龄之前、母传抗体逐渐减少之时，尽早建立初次免疫。
- **轮状病毒疫苗**有严格的年龄限制。15周或以上不能接种第1剂，全程必须在24周前完成。设定这些限制是因为罕见的副作用肠套叠在小婴儿中风险较低。因此，错过的轮状病毒疫苗剂次以后不再补种。
- **1岁。**母传抗体已经消失，因此MMRV活疫苗能起作用。PCV和MenB加强接种建立持久的记忆。
- **青春期。**HPV疫苗在大多数青少年开始性活动之前接种。自2023年9月起使用一剂，因为研究表明在年轻人中一剂提供的保护与两剂相似。14岁时接种MenACWY保护处于脑膜炎球菌病第二个高峰的青少年，并减少携带，从而保护他人。

### 选择性接种规划

有些疫苗只提供给风险较高的儿童：

- **母亲患乙型肝炎的婴儿接种乙肝疫苗。**出生24小时内和4周时接种单价乙肝疫苗，然后接种常规六联疫苗，并按《绿皮书》在1岁时追加剂次和进行血液检测。母亲传染性高的婴儿和极低出生体重儿出生时还要接种乙型肝炎免疫球蛋白。
- **卡介苗（BCG）**用于结核病风险较高的婴儿，例如居住在高发地区，或父母或祖父母出生于结核病高发国家的婴儿。自2021年起，卡介苗在约28日龄、新生儿严重联合免疫缺陷筛查结果出来之后接种，因为卡介苗是活疫苗。
- 为无脾、镰状细胞病、补体缺陷、慢性心、肺、肾或肝病以及其他危险状况的儿童额外接种肺炎球菌、脑膜炎球菌和流感疫苗。

孕期，孕妇可接种**百日咳**疫苗（从16周起，最好在20周左右）、**RSV**疫苗（从28周起），以及在流感季节接种**流感**疫苗。

## 安全接种

::: definition 禁忌证与慎用情况 {#def-practice}
**禁忌证**是指不应接种某种疫苗的情况。真正的禁忌证很少：

- 对既往一剂该疫苗或其某一成分发生确证的**严重过敏反应**；
- 对于**活疫苗**，严重免疫抑制（例如癌症治疗、大剂量糖皮质激素或原发性免疫缺陷所致）和妊娠；
- 专门针对轮状病毒疫苗：严重联合免疫缺陷和既往肠套叠。

**慎用情况**是推迟接种或需要注意的理由，例如伴发热的急性疾病，此时推迟到儿童康复后再接种。

**错误的禁忌证**是有时被用作不接种理由、但并不成立的理由。
:::

错误的禁忌证是漏种的常见原因。以下情况都不是暂缓接种的理由：不伴发热的轻微疾病，如感冒；正在服用抗生素；早产；母乳喂养；疫苗反应或惊厥的家族史；稳定的神经系统疾病；湿疹或哮喘；鸡蛋过敏（包括对MMRV和儿童流感疫苗，但曾因严重过敏反应需要重症监护的鸡蛋过敏儿童应在医院接种流感疫苗）；以及既往轻微的局部反应。

幼儿的**同意**由具有父母责任的人作出。有能力作出决定的青少年可以自己同意（见[[paediatrics/adolescent-health]]）。除口服轮状病毒疫苗和鼻喷流感疫苗外，疫苗采用肌内注射，婴儿注射于大腿前外侧，年长儿童注射于三角肌。同一次就诊可在不同部位安全地接种多种疫苗。

### 预期反应

轻微反应很常见：注射部位疼痛和肿胀、发热、烦躁和睡眠不佳，持续一两天。**MenB疫苗**使许多婴儿发热，因此在英国，建议在8周和12周MenB接种后按现行方案根据年龄给予**对乙酰氨基酚（paracetamol）**。MMRV中的麻疹成分可在接种后7–12天减毒病毒复制时引起发热和皮疹；这不具传染性。

疑似不良反应通过药品和保健品管理局（MHRA）运行的**黄卡（Yellow Card）**系统报告。被动报告能发现罕见的信号，但它本身不能证明因果关系；这需要比较接种组和未接种组的发生率。

::: warning 晕厥不是严重过敏反应
青少年在接种时或接种后不久常发生晕厥，尤其是站立时。晕厥是一种反射：在数秒至数分钟内开始，伴苍白、出汗和脉搏缓慢，平躺后迅速恢复。**严重过敏反应**很罕见（大多数疫苗约百万剂次一例），通常在数分钟内开始，引起气道肿胀、喘鸣、伴脉搏增快的低血压，常伴荨麻疹样皮疹。混淆两者会造成双向伤害：把晕厥标为过敏会使人错失以后的疫苗，而把严重过敏反应当作晕厥处理则会延误基本治疗**肌内注射肾上腺素**。为青少年接种时让其坐着，接种后再坐几分钟。
:::

::: example 学校接种现场的晕倒 {#ex-anaphylaxis}
一名14岁女孩在学校接种现场接种了Td/IPV和MenACWY。站起来时她说头晕，随即瘫倒在地。她面色苍白、出汗，脉搏48次/分。平卧并抬高双腿后一分钟内，她能说话，肤色恢复，脉搏76次/分。没有皮疹、喘鸣或肿胀。
::: solution
**时间与特征。**站立时立即发生，苍白、出汗、脉搏**缓慢**，平卧后迅速恢复，这些是**血管迷走性晕厥**的典型表现。

**不支持严重过敏反应。**没有气道、呼吸或皮肤受累，脉搏缓慢而不是增快。她未经治疗即恢复。

**处理。**让她保持平卧直至完全恢复，然后坐一会儿，观察，并将事件记录为晕厥。检查跌倒是否造成损伤。她今后可以继续接种疫苗，最好躺着或坐着接种。

**如果特征不同。**唇或舌肿胀、喉喘鸣、喘鸣音、伴脉搏增快的低血压或广泛荨麻疹意味着严重过敏反应。应对措施是呼救、让她平卧并立即肌内注射肾上腺素，遵循英国复苏委员会的流程，如无改善，5分钟后重复一剂。
:::
:::

## 与家庭沟通

大多数犹豫的家长是有疑问，而不是持有固定立场。最有效的方式是诚实、具体和尊重：

- 以儿童将会接种为前提，询问家长有什么问题。
- 了解家长听说了什么，最担心什么。
- 给出清楚的数字，比较疾病的风险和疫苗的风险。
- 承认真实的副作用。家长信任对发热和腿疼如实相告的临床医生。
- 如果家长拒绝，保持沟通的大门敞开，并提供另一次预约。

英国最具破坏性的疫苗恐慌始于1998年安德鲁·韦克菲尔德（Andrew Wakefield）及其同事发表的一篇论文，该文提出MMR与孤独症之间存在联系。对数百万儿童的大型研究未发现任何联系，该论文于2010年被撤回，韦克菲尔德被从医师注册名录中除名。MMR接种率下降了多年，麻疹卷土重来。

::: definition 暴露后免疫与特殊情况下的免疫 {#def-situations}
**暴露后预防**是在暴露于某种感染后给予疫苗或免疫球蛋白以预防发病。例如：6月龄或以上的易感者在暴露于麻疹后72小时内接种MMR（或MMRV）；6月龄以下暴露婴儿、严重免疫抑制者和易感孕妇使用人正常免疫球蛋白；易感染破伤风的伤口使用破伤风疫苗和免疫球蛋白；以及血液暴露后使用乙肝疫苗，必要时加用免疫球蛋白。

**补种**使漏种的儿童赶上进度。原则是继续接种程序，绝不重新开始。
:::

::: example 家中出现麻疹 {#ex-measles}
一名未接种疫苗的3岁女孩出现高热、咳嗽、流涕和结膜充血，随后出现从耳后开始的斑片状皮疹。麻疹得到确诊。她和父母、4月龄的弟弟，以及一位肾移植后正在服用吗替麦考酚酯（mycophenolate）的祖母住在一起。她7岁的表兄昨天来访过，他接种过两剂MMR。
::: solution
**传染性。**麻疹从出疹前约4天至出疹后4天具有传染性，经空气传播。应将诊断报告给当地健康保护团队，由他们协调应对。

**4月龄的弟弟**太小，不能接种MMR，且有患重症的风险。应给予**人正常免疫球蛋白**，可在暴露后6天内使用。

**祖母**处于免疫抑制状态。应紧急检查她的麻疹免疫状态；如无免疫力，应给予免疫球蛋白。她不能接种MMR，因为它是活疫苗。

**父母**应核查自己的疫苗接种史；如无免疫力，可在72小时内接种MMR。

**表兄**接种过两剂，很可能已受保护。

**患儿**应在出疹后4天内不去托儿所、远离他人，并观察并发症：肺炎、中耳炎、腹泻，罕见情况下为脑炎。麻疹还会在数月至数年内抑制免疫记忆。她康复后，应补齐其他疫苗，包括第二剂含麻疹成分疫苗，该疫苗还能预防腮腺炎、风疹和水痘。
:::
:::

::: example 母亲患乙型肝炎的婴儿 {#ex-hepb}
梅（Mei）足月出生，母亲患慢性乙型肝炎，HBeAg阴性、病毒载量低。由于产后病房当晚很忙，出生剂次被漏掉了。梅现在36小时龄。应该怎么做？
::: solution
**风险。**如不接种，出生时感染的婴儿中多达90%会发展为慢性感染，可导致肝硬化和肝癌。及时接种可预防大多数此类感染。

**今天的行动。****现在**就接种单价乙肝疫苗。目标是在出生24小时内接种，但延迟接种仍有保护作用，绝不能跳过。由于母亲传染性低且梅是足月儿，通常不需要免疫球蛋白，但这要依据《绿皮书》标准和当地意见。

**之后。**4周时接种第二剂单价疫苗，从8周起接种常规六联疫苗，并按《绿皮书》规定在1岁时追加剂次并做血液检测，确认梅未被感染。母乳喂养是安全的。

**系统。**将延误作为不良事件记录，并审查出生剂次的提示方式，因为漏种出生剂次是该流程中已知的薄弱环节。
:::
:::

::: example 有免疫缺陷家族史的婴儿 {#ex-bcg}
拉维（Ravi）8周龄，到了接种第一批疫苗的时间。他的哥哥7个月时死于严重联合免疫缺陷（SCID）。由于他家所在地区不提供SCID新生儿筛查，拉维没有做这项筛查。因为父母出生于结核病高发国家，他也应接种卡介苗。
::: solution
**危险。**对于患SCID的婴儿，活疫苗可引起严重的持续性感染。卡介苗可引起播散性卡介苗病，轮状病毒疫苗可引起慢性腹泻。

**行动。**在明确拉维的免疫状态之前，不要接种卡介苗或轮状病毒疫苗。安排紧急免疫学评估，包括淋巴细胞计数和淋巴细胞亚群。无论筛查结果如何，兄姐患SCID的家族史本身就是紧急评估的指征。

**灭活疫苗。**六联疫苗和MenB疫苗不是活疫苗，不会引起感染。可以接种，尽管患SCID的婴儿可能对其无应答。

**时间很重要。**轮状病毒疫苗有严格的年龄上限，因此需要尽快作出决定。如果拉维免疫系统正常，可在15周前接种第一剂。卡介苗可以稍后接种。
:::
:::

::: quiz
一位母亲问，她的8周龄婴儿有流涕但不发热，是否应推迟接种。他是34周出生的。最佳建议是什么？
- [ ] 推迟接种，待感冒好了再从那天开始按程序接种。
- [ ] 因为他是早产儿，推迟到校正年龄8周。
- [x] 今天按实际年龄接种。
- [ ] 今天接种灭活疫苗，但推迟轮状病毒疫苗。
::: solution
不伴发热的轻微疾病不是推迟接种的理由，早产也不是：早产儿按实际年龄接种，因为他们的母传抗体丧失得早，感染风险更高。感冒时可以接种轮状病毒疫苗，推迟反而有错过其严格年龄窗口的风险。
:::
:::

::: history
1796年，爱德华·詹纳（Edward Jenner）用牛痘病灶的物质为詹姆斯·菲普斯（James Phipps）接种，并证明这个男孩随后对天花具有了保护。路易·巴斯德（Louis Pasteur）在19世纪80年代把这一思想推广到鸡霍乱、炭疽和狂犬病的减毒疫苗。白喉和破伤风类毒素在20世纪20年代问世，乔纳斯·索尔克（Jonas Salk）的灭活脊髓灰质炎疫苗于1955年获得许可，阿尔伯特·萨宾（Albert Sabin）的口服活疫苗在20世纪60年代初随之而来。英国在20世纪40年代开始常规接种白喉疫苗，国民医疗服务体系使每个儿童都能接种疫苗。结合疫苗改变了对婴儿的保护：英国于1992年引入Hib疫苗，1999年引入C群脑膜炎球菌结合疫苗，是第一个在全国使用该疫苗的国家。2015年，英国成为第一个向所有婴儿提供MenB疫苗的国家。1980年，世界卫生大会宣布天花已被根除。
:::

## 后续内容

免疫记忆、佐剂和疫苗平台的免疫学见[[immunology/vaccines-immunotherapy]]，如何在人群层面规划、监测和评价免疫规划见[[public-health/vaccination-programmes]]。这些疫苗所预防的感染见[[paediatrics/acute-childhood-illness]]和[[microbiology/viruses]]。免疫缺陷儿童的免疫接种见[[immunology/immunodeficiency]]。

::: summary
- 活疫苗产生强免疫，但避免用于严重免疫抑制者和孕妇；灭活疫苗需要多剂。
- 结合疫苗募集T细胞辅助，使婴儿产生针对荚膜多糖的IgG和记忆。
- 群体免疫阈值为$1 - 1/R_0$；麻疹需要两剂接种率达到约95%。
- 截至2026年，英国免疫程序为：8周六联、MenB、轮状病毒；12周六联、MenB、轮状病毒；16周六联、PCV；1岁PCV、MenB、MMRV；18个月六联、MMRV；3岁4个月四联；12–13岁HPV；14岁Td/IPV和MenACWY；2岁起每年流感疫苗。
- 轮状病毒疫苗有严格的年龄限制（第1剂在15周前，全程在24周前完成），过后绝不补种。
- 真正的禁忌证很少；轻微疾病、早产、鸡蛋过敏和家族史都不是禁忌证。绝不重新开始接种程序。
- 晕厥和严重过敏反应在时间、脉搏和特征上不同；严重过敏反应用肌内注射肾上腺素治疗。
- 家长应得到诚实的数字和尊重；大多数犹豫是一系列疑问，而不是拒绝。
:::

## 习题

::: exercise 写出今天的接种计划 {level=1}
英格兰一名健康女孩今天满一周岁，此前的疫苗都已按时接种。列出她已经接种了什么、今天应接种什么，以及接下来是什么。
::: solution
**已接种：**8周时六联、MenB和轮状病毒疫苗；12周时六联、MenB和轮状病毒疫苗；16周时六联和PCV。

**今天应接种（满一周岁当天或之后）：**PCV加强、MenB加强和MMRV第1剂。不再接种Hib/MenC疫苗。

**接下来：**18个月时六联第4剂和MMRV第2剂；从2岁起每年秋季接种流感疫苗；3岁4个月时学龄前四联加强。应始终核对现行《绿皮书》，因为免疫程序会变化。
:::
:::

::: exercise 群体免疫阈值 {level=1 check="round(100*(1-1/4))"}
一种感染的$R_0 = 4$。人群中百分之多少必须具有免疫力才能防止持续传播？给出整数。
::: solution
$p_c = 1 - 1/4 = 0.75$，即**75%**。
:::
:::

::: exercise 真禁忌证还是假禁忌证？ {level=1}
对以下每种情况，判断它是否是1岁疫苗接种的禁忌证：(a) 不伴发热的感冒；(b) 对既往一剂MenB疫苗发生严重过敏反应；(c) 伴荨麻疹的鸡蛋过敏；(d) 正在接受白血病化疗。
::: solution
(a) 不是禁忌证。(b) 是继续接种MenB疫苗的禁忌证；其他疫苗应征求专科意见。(c) 不是禁忌证；MMRV可以在基层医疗机构接种。(d) 是MMRV活疫苗的禁忌证；可以接种灭活疫苗，但可能无效，接种时间应与肿瘤科团队共同计划。
:::
:::

::: exercise 疫苗效力 {level=2 check="round(100*(1-0.03/0.30))"}
在一次学校暴发中，30%的未接种儿童和3%的接种儿童发病。计算疫苗效力，以百分比表示，取整数。
::: hint
疫苗效力等于1减去接种者相对于未接种者的相对危险度。
:::
::: solution
相对危险度$= 0.03/0.30 = 0.1$。效力$= 1 - 0.1 = 0.9$，即**90%**。
:::
:::

::: exercise 不完美疫苗所需的接种率 {level=2 check="round(1000*(1-1/6)/0.85)/10"}
一种感染的$R_0 = 6$，疫苗可保护85%的接种者。要达到群体免疫阈值，接种率需要达到百分之多少？保留一位小数。
::: solution
$p_c = 1 - 1/6 = 0.8333$。所需接种率$= 0.8333/0.85 = 0.9804$，即**98.0%**。当阈值接近100%而疫苗又不完美时，仅靠接种可能无法达到群体免疫，对最脆弱人群的保护取决于高接种率和为他们周围的人接种。
:::
:::

::: exercise 犹豫的家长 {level=2}
一位父亲说，他读到同时接种多种疫苗会使婴儿的免疫系统“超负荷”，问能否把疫苗分开接种。你会如何回应？
::: solution
承认他的担忧，并询问他读到了什么。解释婴儿的免疫系统每天都会遇到来自食物以及在肠道和皮肤定植的细菌的数千种新抗原，现代疫苗中的抗原总数与之相比很少。研究表明，同时接种不会降低对每种疫苗的应答，也不会增加严重副作用。分开接种意味着更多次就诊、更多针，并让婴儿在百日咳、MenB和肺炎球菌疾病最危险的年龄更长时间得不到保护。如实说明发热和疼痛很常见，并解释MenB接种后使用对乙酰氨基酚的建议。如果他仍想等待，就商定一个尽快接种的计划，而不是结束谈话。
:::
:::

::: exercise 错过16周接种后的补种 {level=3}
英格兰一名2025年3月出生的女孩来进行1岁接种。她接种了8周和12周的疫苗，但错过了16周的接种。今天她应接种什么？哪些不应接种？
::: hint
记住关于重新开始程序的原则、轮状病毒疫苗的年龄限制，以及1岁以上儿童只需一剂PCV。
:::
::: solution
**绝不重新开始。**她已接种两剂六联疫苗，需要第三剂。距上一剂已超过4周的最短间隔，因此今天可以接种。

**今天：**第3剂六联疫苗，同时接种1岁时的疫苗：PCV、MenB加强和MMRV第1剂，在不同部位注射。一次就诊接种多种疫苗是安全的，并可避免再错过一次接触。

**PCV：**1岁或以上儿童只需满一周岁后的那一剂PCV，因此不单独补种错过的婴儿期PCV。

**轮状病毒疫苗：**她的两剂已完成，但即使错过了，24周后也绝不接种轮状病毒疫苗。

**接下来：**18个月时接种第4剂六联疫苗和MMRV第2剂。记录所接种的疫苗，并询问为什么错过了16周接种。搬家、记录丢失和预约困难是常见原因，解决这些问题可防止再出现空缺。
:::
:::

::: exercise 学校中的麻疹暴发 {level=3}
一所小学有400名学生。记录显示，340人接种过两剂MMR或MMRV，20人接种过一剂，40人未接种。出现了两例麻疹。按两剂效力97%、一剂效力93%，估计仍有多少学生易感，并概述公共卫生应对措施。
::: solution
**易感学生。**两剂：$340 \times 0.03 = 10.2$。一剂：$20 \times 0.07 = 1.4$。未接种：40（除非患过麻疹）。合计约**52**名易感学生，其中40名未接种。

免疫比例约为$348/400 = 87\%$，低于麻疹所需的约93%阈值，因此很可能进一步传播。

**应对。**报告健康保护团队。识别接触者。为未接种和未完成接种的学生和教职员工接种MMR或MMRV，最好在暴露后72小时内。病例在出疹后4天内不得到校，并建议免疫抑制的易感接触者、怀孕的接触者和婴儿弟妹就免疫球蛋白寻求医疗意见。以家长使用的语言与家长进行清晰、迅速的沟通。暴发之后，查明为什么10%的学生未接种，并与社区合作改善可及性和信任。
:::
:::
