先天的疾病是儿科学与家庭在他们最脆弱的时刻相遇的地方——而那往往正是曾被承诺会带来喜悦的那个时刻。这一章涵盖如何识别并诊断一个有畸形的孩子；常见外科的与结构的情况如何被处理；以及遗传学如何被当作一门家庭的医学来实践。

## 识别与诊断

::: definition 畸形的新生儿 {#def-recognise}
**识别是一门被训练的工艺。主要的与微小的畸形因不同的理由而重要：一项主要结构的畸形一处腭裂、一足的马蹄内翻、一个隔的缺损，各带着第二项的畸形或一个染色体的或单基因的诊断的机会的增加数倍；而微小的畸形——一个掌侧的横纹、一只位置低或向后旋转的耳、一节短的指骨、一个皮肤的垂赘——单个意义不大，但成簇时有意义。人群的基线是：约3%到5%的新生儿有一项可被识别的畸形，而另外10%到15%有一项微小的特点——这就是为什么畸形学专家数的是模式、而不是特点。第一遍的方法是被系统的：测量头围与身长及体重，用定制的曲线；成长的那三道关口小头与大头各打开自己的那份鉴别；然后是皮肤；眼睛红光的反射、眼底；耳朵形状、位置、凹沟——一个耳前的凹沟加上耳形状的异常加上听力的风险，是一个肾脏影像的提问；口与腭一个黏膜下的腭裂藏在悬雍垂分叉的后面；手纹路、手指、拇指——缺失的或三节的拇指是一份血液的警报；脊柱与骶一个带毛丛的凹窝、一条偏移的臀沟、一个脂肪瘤；外生殖器模糊的外生殖器在第一周是内分泌的急症，因为有失盐的可能；以及每一个有综合征孩子的那眼底与心脏及髋。诊断的那架梯子十五年来重新排过序：对非整倍体的怀疑做核型；染色体的微阵列如今是未解释的多发畸形与发育的迟缓的一线，诊断的产出约15%到20%；靶点的基因的组；以及在被挑选的人群里产出30%到50%的外显子的或基因组的测序——它可用，而它也会带来意义未明的变异，其中的一些会永远无法被解决。三代的关系史包括流产与死产及近亲的婚配、要不回避地问；以及那一次对年长的同胞的检查——它在几秒钟之内回答关于遗传方式的提问。识别的那一刻也是一次沟通的事件：父母记得最初的十句话，所以“我能看到一些不一样的东西，我还不知道它意味着什么，而这是我正在呼叫的人”胜过虚假的安心或过早的命名“[[genetics/genetic-testing]]、[[genetics/chromosomal-disorders]]、[[clinical-skills/history-taking]]。**
:::

::: definition 常见先天的情况与它们的处理的弧线 {#def-conditions}
**每一个常见的情况都有一道可预测的弧线，而家庭应当很早就被告知。先心的病：脉搏血氧筛查的方案在出院之前抓到严重左侧的与依赖导管的病变；前列腺素E1在超声心动与转运期间为依赖导管的病变把导管保持开放；而那条大的教训是：一个身体粉红而外周灰白休克的新生儿，在一天的记录里某个地方曾“吃奶很差”。先天的膈的疝：产前的诊断；带着儿科的外科与新生儿科在场分娩的计划；温和的通气并允许二氧化碳的潴留；可能时延迟结扎脐带；避免用面罩把胃吹胀；以及对难治的病例的体外膜式的氧合。咨询的数字——在有经验的中心，孤立病例如今的存活率是80%到90%；而伴肝的疝出与小的肺时更差——必须对“被引用的是哪个分子”保持诚实。食管的闭锁伴或不伴瘘：导管在盲囊里盘绕就是诊断；第一次的喂奶绝不被允许；而手术的修补是一个关于反流与吞咽的治疗及胃的折叠决定故事的开端。腹裂（脐旁的、没有囊的缺损，肠管裸露，通常是一个正常的婴儿）对脐膨出中线的、被囊覆盖的缺损，它要求一次染色体的与心脏的搜寻：”先放先放置那层袋、然后关闭的路径；体温与液体的丢失是即刻的生理的敌人；以及那条长期的肠内的喂养的道路。小的脐膨出可以直接关闭；大的要用一层袋缓慢地压缩。神经的管的缺陷：开放性脊柱的裂在最初的几天之内手术或在被挑选的中心做胎儿的手术；神经源性的肠与膀胱及肾的方案——它比那个囊的关闭更决定着成年生活；乳胶暴露的回避；脑积水的那条分流或内镜的处理；以及那个让二十岁的人们不落到肾的衰竭的那间转诊的门诊。唇的裂与腭的裂：8周的唇，9到12个月的腭；语言的治疗师与正畸的医师及耳鼻喉的科医师，以及一辈子的听力学；在第一次手术的日期之前对父母的喂养的教学。马蹄内翻足：一套系列石膏的矫形——在一位被训练的技师手里，它比任何一间手术室都更可靠。发育性髋发育的不良：出生时与6周时的检查；超声的那场争议；那条帕夫利克的吊带；以及那例任何筛查的方案都不能完全预防的晚的就诊。尿道下裂与模糊的外生殖器：在修补之前不做环切；一次从上到下的查看，它会找到近位的尿道口；以及那个多学科性别的提问——由一个团队与一个家庭来处理、不由一个周末的决定来处理。每一个情况如今都有一位具名护士的协调者，而一位年资轻的医师能做出的最高价值的动作之一，是学会该给哪一位打电话[[paediatrics/newborn]]、[[surgery/gastrointestinal-surgery]]、[[renal/urinary-tract]]。**
:::

## 家庭、风险与那条长尾

::: definition 遗传的咨询与不确定及伦理 {#def-counsel}
**一个诊断是一件家庭的事件，而咨询就是它的药。复发的风险要被推导、不是被猜测：一个常染色体隐性的情况带着那个四分之一的数字——而父母通常在休克被给过时间之后才听得进去；新发显性的情况带着低复发的风险，但来自父母的嵌合与生殖层的效应的非零的风险——这就是为什么“它只是碰巧发生”需要那条能让同胞安全的限定。咨询以家庭的语言进行，常常跨两次门诊，常常配一封被总结的信，好让父母能在凌晨两点重读数字、而不必再次听错它。它必须经受住现代的并发症：“一个无法被说成”大概不是病因“的意义未明的变异——因为一旦这么说，在家庭耳里就成了”他们不知道“；一个偶发的发现它的披露的规则因实验室与司法辖区而异，而它必须在测序之前被预先谈好；一个会重塑一位父母自己健康的成果那个“有核病变的孩子与那位现在需要一位心脏科医师的父亲”的模式；以及那个为了做捐献者而怀上的同胞身上的次级的发现。产前的诊断带来它自己的实务：在增高颈层的透明带或一个软性的标志之后，场地发现结果的谈话应当是一场遗传学的讨论、不是一份传单；”那个与生命不相容的用语被随意地使用过，并且毁掉过被期待的妊娠；而在畸形的筛查之后继续或终止妊娠的决定，需要与其他任何严重的诊断一样的非指令咨询的技巧、以及一样的对儿科的安宁细则的可及性——生育的自主意味着父母来决定，而临床医师的工作是准确的信息，是在那个具体的家庭的那个变异的可能范围内对预后的诚实，以及在任何一方都不放弃。新生的儿的筛查位于这一章的逻辑之下：在被早期治疗能改变结局的情况上筛查；同意是被默认退出、但带着真实的信息；而假阳性的那条路径是一次家庭危机——服务做得很差，而仅凭一通电话的设计就能把它做好。整章伦理的脊柱是：生育的决定属于父母，而预后的决定属于实时中的家庭——“生活的质量要被问向这个家庭的孩子、而不是问向教科书上的那个轮廓；不给或撤除治疗是逐情况被决定的，通常与一位在房间里给这个婴儿洗过澡的护士一起决定会更好；而安宁的儿科学不是放弃，而是一门把那3%到5%的有限制生命情况的孩子们症状的负担做小、并把在家的时间做大的专科。最后是那与保护的重叠：多发的骨折与硬膜下的积液及视网膜的出血——一个婴儿身上的每一次无法解释的恶化，在被回答之前同时是一个代谢的、一个遗传的与一个保护学的提问；而儿科的遗传的学家与放射的科医师及儿童的保护的团队应当在同一场讨论里，通常是在几小时之内”[[genetics/genetic-testing]]、[[medical-ethics-law/beginning-of-life]]、[[paediatrics/safeguarding]]、[[genetics/chromosomal-disorders]]。**
:::

::: example 那个“心脏的缺损与腭裂，哭声不像别的孩子”的新生儿 {#ex-diGeorge}
一名新生儿有一个心室流出道畸形心脏的缺损、喂养的困难；而在第2天，钙1.6，并有一次惊厥。
::: solution
**“以低钙的惊厥来表现的22q11.2的缺失”（[[#def-recognise]]、[[#def-conditions]]）：急症的层——先治钙与惊厥；在一个伴流出道畸形低钙的新生儿身上查镁与磷及旁甲状腺的激素——因为低的旁甲状腺的激素就是诊断、不是一句事后想起的话；葡萄糖酸钙的输注配心脏的监护；喂养与钙分开；并预期在诊断追上来之前需要更多。诊断——“流出道心脏缺损加腭的机能的不全加低钙这三联，在被证明之前就是那个缺失；而快速的荧光的原位杂交或微阵列来确认它，不用等外显子；去找那处隐蔽的腭——一处咽的腭的机能的不全，它会解释明天鼻腔的反流；以及那个胸腺的影子与T细胞的数字——因为一例罕见完全的迪乔治需要现在、而不是将来的免疫的重建；而语言的与听力的与肾脏的影像的及发育的随访从诊断开始、不从手术开始。与这个家庭的谈话——”准确而合比例地命名它：大多有22q11.2缺失的孩子过得不错，配心脏的修补及语言的与治疗及追赶；而少数有学习的困难及心理的疾病的风险那个后来的精神分裂症的风险；因为它是新发的或是被遗传的，所以要检查双亲，通常也要给你们两位做检测；而一位携带的父母值得拥有他们自己的被解释的诊断——那位一直有“鼻音”与“一次奇怪耳感染的成簇”的家长，可能就是这份家系里缺失的那一条；以及这个孩子会遇到许多专科——他们都应当在那个问题的清单里看到这个缺失；而学校需要那份免疫的与学习的概况被写在一封信里、不是五封“[[genetics/chromosomal-disorders]]、[[immunology/immunodeficiency]]、[[cardiovascular/valve-congenital-disease]]。**
:::

::: example 那次“20周的畸形的筛查” {#ex-ntd}
一次20周的筛查显示一个开放性腰骶神经的管的缺陷，伴后脑的疝与脑室的扩大；父母问：“你们能修好它吗？、我们的生活会是什么样？”
::: solution
**场神经管缺陷的谈话（[[#def-conditions]]、[[#def-counsel]]）：在回答之前——“把他们在48小时之内请回来；不要在筛查的那间房间里回答一个最初休克时的提问”这条政策；那位具名的助产士与遗传的咨询师及胎儿的医学的团队；房间里两位临床医师，以及一个不是网站清单支持组织的提供；以及这个具体的病变的真实数字——位置很重要：腰骶伴后脑的改变对胸段的是另一种生活，以范围引用，并说明不确定的理由。准确地给出医学的计划——“开放性胎儿的手术在少数中心为被定义的指征被提供，带着真实的母体的风险与中度的行走的能力的获益”这个选项；产后48小时之内关闭的标准；分流的那个决定在出生后做、不在之前；以及那个泌尿的方案——”在婴儿室里就教清洁的间歇的导尿、而不是在第一次尿路感染之后——因为决定三十岁的那个器官是肾、不是足。生活的提问要被说好——“大多数的孩子会走或借助辅具移动；轮椅的那个决定由功能来做、不由那张磁共振来做；控制排尿是那个长期的挑战，而我们会早期开始膀胱的保护；我们会支持你们朝任何一个方向；而如果你们继续，你们不会在分娩时被塞一个文件夹就被留下——正是这个团队的用途；以及那句没有父母预期、却需要的话：“今晚我们不能把一切告诉你们；我们可以告诉你们我们是谁，以及今晚没有任何东西是在这一周被决定的”。咨询的标准是：父母离开时能够说出那个计划、数字和名字——这三样能把一个糟糕的处境变得可以导航[[obstetrics-gynaecology/pregnancy-complications]]、[[public-health/screening]]、[[medical-ethics-law/beginning-of-life]]。**

::: example 那个“第3天有模糊外生殖器的男孩” {#ex-genitalia}
一名“女孩”在第3天有男性化的外生殖器，一侧可触及的性腺；钠128、钾6.4，并在呕吐。这家人来自一个没有新生儿筛查的地区。

::: example 例外显子测序发现了母亲的动脉瘤的风险 {#ex-incidental}

**次级的发现与连锁的家庭医学（[[#def-counsel]]、[[genetics/genetic-testing]]、[[medical-ethics-law/confidentiality]]）：孩子优先——“为她现在就做心脏的监护与活动的指导及血压的管理——这个遗传的结果只有在医学的计划跟上它时才有用；而这位少年会想要她自己的一份档案，而这份档案应当为她未来的那个自己而写——封信是为二十年后的那位患者写的原则。父亲——”连锁的检测靠邀请、不靠报告——他没有被检测，因为没有人解释过他的扫描对他的其他的孩子与他的表亲们有多重要；带着那句确切的话重新邀请：“你的女儿的结果意味着你可能需要一片降压药和一次磁共振，而它可能救你的命或你兄弟的命”；他可以拒绝，是他的权利；我们记录下我们提供过；我们不会绕过他去打给他的雇主或他的全科医师。披露的伦理——“本地的实务：由与这个家庭有关系的临床医师去咨询亲属，而先要这个索引病例同意共享；遗传医学的服务有一份具名危机沟通的方案，用于同意无法获得的时候；而至少要在未获同意时先尝试取得同意、并记录下这次尝试，然后才把任何一个变异披露给亲属——是把DNA寄进一封信与守住一条会杀人的沉默之间的那条中路。系统——”测序之前就定好的实验室的次级发现的政策；份真的列出了会返回什么的同意书；那个记得谁被提供了什么的家族的链接的数据库；以及那间会去审计多少连锁的亲属被联系了、对比多少人真的被扫描了的门诊——因为那个差距就是可预防的死亡藏身的地方“[[cardiovascular/vascular-disease]]、[[genetics/genomic-medicine]]、[[clinical-skills/records-handover]]。**

::: example 那个“没有人检查过年长的同胞” {#ex-sibling}
一名3岁在行为的退步之后被诊断为X-连锁肾上腺白质的营养不良；他5岁的妹妹与18个月的弟弟被算作“好”；而父母问这个男孩什么时候能被正规地查一查。
::: solution

## 通向何处

检测的技术在[[genetics/genetic-testing]]与[[genetics/chromosomal-disorders]]，遗传的算术在[[genetics/mendelian-inheritance]]，新生儿的其他的急症在[[paediatrics/newborn]]，保护的这条界线在[[paediatrics/safeguarding]]，而筛查的政策在[[public-health/screening]]。

::: history
**先天的疾病经由四次转变，从宿命走到了家庭的医学。第一，畸形学的那堂硬课：1958到1961年的海豹肢的畸形——当反应停穿过胎盘，成千的婴儿出生时没有肢体——它把零散的怪胎的病例报告，变成了一门关于胚胎的发育的关键窗口的科学、关于药物的致畸的管制的科学；并诞生了国家的先天性的畸形的登记与现代的致畸的信息服务。这是那个证明：“一种化学物质会在被定义的那一周里穿过胎盘”，而处方的实务是一个公共卫生的变量。第二，外科的拯救：1940到1950年代经典的手术——腭裂的修补与食管的闭锁及脐膨出，以及后来的脑积水的分流——它们在最小的与最重的孩子身上起初几乎总是失败；直到那个模式——”能活下来的少数在变好，而最重的仍然在死亡——把那个伦理的提问公开地逼了出来；而婴儿的外科的奠基者们公布存活的曲线，在1980年代初的关于婴儿的治疗的判决中被用于法庭——正是今天每一场“安宁的照护对手术”的谈话直接的前身。第三，染色体的时代：1956年那个正确的人类的染色体的数目，1959年的21三体，费城的染色体那一条与细胞的遗传学；然后是带带的核型与原位杂交的探针及微阵列与测序——它们让一半未解释的发育的迟缓有了名字。第四，门政治：产前的诊断与筛查把选择带给了父母，也带来了一个残疾权利的批评——它迫使从“被影响者”与“正常”语言，走向“一个带着某个情况的孩子”；它迫使预后保持诚实，而不是在鼓舞与绝望之间二选一；而它把关于终止妊娠的提问从隐私的领域搬进了公共的辩论。这一专科的教训是：诊断只有与支持配对时才是力量——一个没有计划的名字，只是一个拼写更好的预后“[[genetics/genomic-medicine]]、[[public-health/screening]]、[[medical-ethics-law/beginning-of-life]]。**
:::

::: summary
- 主要的畸形会成簇；微小的畸形单个意义不大——数模式；测量成长；系统地把眼睛与耳朵及腭及脊柱及髋及心脏查一遍。
- 诊断的那架梯子如今是先微阵列、再外显子或基因组；但表型驱动着检测，而一个阴性的结果永远删不掉一个可被识别的综合征。
- 每一个先天的情况都有一道可预测的弧线与一位具名的协调者——在值班之前把那道弧线与那个电话号码学会。
- 复发的风险由遗传的方式与父母的检查及嵌合的限定来推导——从不猜测；永远写下来，并让它在家里被重读。
- 产前的与新生儿的筛查会把决定成倍地增加：对这个家庭的那个变异的准确的预后；非指令的咨询；任何一方都不被放弃。
- 意义未明的变异是一个终生信息管理的问题——要在测序仪跑起来之前，先把那份披露的政策定下来。
:::
