约2–3%的婴儿出生时有重大结构异常，还有更多婴儿患有在儿童期后期才显现的遗传性疾病。先天性和遗传性疾病如今是英国婴儿期死亡的主要原因之一，在医院门诊所见的儿童中也占很大比例。这些儿童中许多人会带着同样的疾病长大成人，因此儿科工作包括为他们的未来做规划。

本章采取实用的视角。它先解释如何处理有异常特征的儿童，然后介绍每个医生都会遇到的三类疾病：先天性心脏病、囊性纤维化和常见染色体综合征。最后介绍遗传代谢病、新生儿筛查和遗传咨询。遗传和染色体疾病的基本机制见遗传学课程。

## 识别先天性疾病

::: definition 畸形、综合征与序列征 {#def-recognise}
**重大畸形**是具有医学、外科或美容意义的结构差异，例如唇裂或心脏缺陷。**微小畸形**本身没有严重后果，例如通贯掌或耳前小皮赘。三个或以上微小畸形同时存在，会增加潜在重大畸形或综合征的可能性。

**畸形特征**是指与通常所见不同的身体特征，尤其是面部、手和足。

**综合征**是由单一潜在病因引起的一组可识别的畸形模式，例如唐氏综合征。**序列征**是由单一初始问题引起的一连串畸形：在**Pierre Robin序列征**中，下颌过小把舌推向后方，从而阻止腭的闭合。**联合征**是一组比偶然情况下更常同时出现、但没有已知单一病因的畸形，例如VACTERL（椎骨、肛门、心脏、气管食管、肾脏和肢体畸形）。
:::

评估可能存在畸形特征的儿童遵循常规程序。采集**三代家族史**，询问流产、早亡、学习困难和近亲婚配。采集**妊娠史**，包括超声检查、感染、饮酒和用药。测量身高、体重和头围并描绘。从头到脚系统检查，并与父母比较特征，因为许多特征只是家族性的。经同意拍摄的照片有助于同行会诊，日后也有用。

基因检测变化迅速。在英格兰，检测通过NHS基因组医学服务按照《国家基因组检测目录》开具。能检测小片段缺失和重复的**染色体微阵列分析**，已取代核型分析成为大多数发育迟缓或多发畸形儿童的首选检查。微阵列正常时使用**外显子组**或**全基因组测序**，对病情危急的婴儿和重症监护中的儿童可进行快速全基因组测序，数天内出结果。

## 先天性心脏病

每1,000名婴儿中约有8名患先天性心脏病。它是最常见的重大先天性畸形。有些病变在产前畸形筛查超声中被发现，有些在新生儿体格检查时被发现，有些只有在婴儿发病时才被发现。

::: definition 先天性心脏病的分类 {#def-conditions}
**左向右分流**使含氧血流回肺：室间隔缺损（VSD）、房间隔缺损（ASD）、动脉导管未闭（PDA）和房室间隔缺损（AVSD）。婴儿肤色红润，但肺接受的血流过多。

**梗阻性病变**使某一心室的流出道狭窄：主动脉缩窄、主动脉瓣狭窄和肺动脉瓣狭窄。

**青紫型病变**使脱氧血到达体循环：法洛四联症、大动脉转位以及其他复杂病变，包括功能性单心室病变。

**动脉导管依赖性病变**是指流向肺或流向全身的血液依赖动脉导管的病变。这些婴儿在出生后最初几天动脉导管关闭时会病情危重。
:::

::: theorem 左向右分流随肺阻力下降而增大 {#thm-shunt}
经室间隔缺损或动脉导管未闭的血流取决于肺循环与体循环之间的阻力差。由于肺血管阻力在出生后最初几周下降，大量分流常在出生时没有症状，而在约4–6周时以心力衰竭起病。
:::

::: proof
出生时肺血管阻力仍相对较高。在随后几周，肺小动脉的肌层变薄，阻力降向成人水平。血液经缺损流向阻力较低的一侧，因此随着肺阻力下降，更多血液从左心室经缺损进入肺循环。肺循环与体循环血流之比$Q_p/Q_s$上升。当它较大（约大于2）时，左心必须泵出远多于身体所需的血液，肺部充血，婴儿发生**心力衰竭**：呼吸急促、喂奶时出汗和疲劳、体重增长差以及肝脏肿大。随着血流增加，杂音也可能变响。如果大分流不予修补，肺动脉会因高血流和高压力而受损，阻力最终升至高于体循环。分流随之逆转，儿童出现青紫，这种情况称为**艾森门格综合征**，已无法矫治。
:::

分流的大小可以用心导管检查时测得的血氧饱和度，按Fick原理估计：

$$
\frac{Q_p}{Q_s} = \frac{S_{\text{主动脉}} - S_{\text{混合静脉}}}{S_{\text{肺静脉}} - S_{\text{肺动脉}}}
$$ {#eq-qpqs}

其中每个$S$是一个血氧饱和度。实际上超声心动图和MRI远比心导管检查常用，但这个公式解释了“大分流”的含义。

::: example 喂奶时出汗的婴儿 {#ex-vsd}
阿米娜（Amina）6周龄。她吃奶耗时长，喂奶时出汗、呼吸急促，出生以来体重只增加了300 g。她在胸骨左缘下部有响亮的全收缩期杂音，肝缘在肋缘下3 cm。心导管检查的血氧饱和度为：主动脉97%，上腔静脉（混合静脉）67%，肺静脉97%，肺动脉87%。计算$Q_p/Q_s$并解释她的症状。
::: solution
**计算。**$Q_p/Q_s = (97 - 67)/(97 - 87) = 30/10 = 3.0$。她的肺接受的血流是体循环的三倍。

**解释。**这是大型**VSD**。出生时肺阻力高，所以分流小。到6周时阻力下降，分流增大。额外的血流引起肺充血（呼吸急促），心脏的额外做功加上喂养不佳导致生长迟滞。出汗反映交感神经活动增强。

**处理。**用利尿剂减轻充血，用高能量喂养支持生长，必要时经鼻胃管喂养。伴心力衰竭的大型VSD通常需要在出生后最初几个月、肺血管病变形成之前进行外科关闭。相反，小的肌部VSD常可自行闭合。
:::
:::

### 青紫与动脉导管

青紫的新生儿可能有心脏问题，也可能有肺部问题。心脏病引起的青紫不能被吸氧纠正。**大动脉转位**的婴儿在动脉导管关闭时于数小时内出现青紫，需要前列腺素维持动脉导管开放，并紧急行球囊房间隔造口术以在心房水平混合血液，随后行大动脉调转术。**法洛四联症**（VSD、主动脉骑跨、肺动脉狭窄和右心室肥厚）引起的青紫程度随肺动脉狭窄的程度而不同；较大的婴儿哭闹时可出现青紫加重的“缺氧发作”。

### 无害性杂音

许多健康儿童有由正常血流引起的**无害性杂音**。它柔和、位于收缩期、听诊范围小、随体位变化，出现在没有症状且心血管检查其余部分正常的儿童中。舒张期杂音、响亮（伴震颤）杂音、全收缩期杂音，或伴有症状、青紫或脉搏异常的杂音，需要转诊做超声心动图。

## 囊性纤维化

**囊性纤维化**（CF）是北欧血统人群中最常见的危及生命的常染色体隐性遗传病。白种欧洲血统人群中约每25人中有1人是携带者，英国约每2,500名婴儿中有1名患病。它见于所有种族群体，但在其他群体中较少见，而在被认为罕见的群体中更容易被漏诊。

CF由*CFTR*基因变异引起，该基因编码上皮细胞中的一种氯离子通道。氯离子分泌减少使分泌物黏稠、脱水。在肺部，黏液清除不良，导致慢性感染（*金黄色葡萄球菌*、*流感嗜血杆菌*，后期为*铜绿假单胞菌*）和支气管扩张。在胰腺，导管阻塞引起**胰腺外分泌功能不全**，导致脂肪泻和生长不良，后期出现CF相关糖尿病。约10–20%的婴儿以**胎粪性肠梗阻**起病。大多数男性CF患者因输精管缺如而不育。

CF在新生儿血斑检测中被发现：**免疫反应性胰蛋白酶原**（IRT）升高后再检测常见的*CFTR*变异。诊断通过**汗液试验**确认：汗液氯化物60 mmol/L或以上即可诊断。

治疗是终身的、多学科的：每日气道清除理疗、吸入黏液溶解剂、抗生素、随餐补充胰酶、脂溶性维生素和高能量饮食。近年来最大的变化是**CFTR调节剂**。这些药物纠正或增强缺陷通道的功能。依来卡托、替扎卡托和依伐卡托（elexacaftor、tezacaftor和ivacaftor）三联组合可显著改善至少有一个*F508del*变异者的肺功能和体重，自2020年起在NHS可获得，现已包括幼儿。英国CF患者的中位预期生存期在调节剂问世前已达约50岁，预计还将进一步提高。

::: example 新生儿筛查阳性 {#ex-cfscreen}
奥利弗（Oliver）的血斑检测显示IRT升高并有两个*CFTR*变异，其中包括*F508del*。他3周龄，母乳喂养良好，体重增长正常。他的父母没有CF家族史，深感震惊。接下来会发生什么？
::: solution
**确认。**在CF中心做汗液试验。汗液氯化物60 mmol/L或以上可确诊CF。

**向父母解释。**CF是常染色体隐性遗传，因此父母双方都必定是携带者。携带者没有症状，这就是为什么没有家族史。今后每次妊娠，孩子患CF的机会为1/4，为携带者的机会为1/2，两者都不是的机会为1/4。

**早期照护。**转诊至CF专科团队。检测粪便弹性蛋白酶以评估胰腺功能，如果偏低则补充胰酶。定期采集呼吸道标本并进行理疗。讨论CFTR调节剂治疗，这取决于他的变异和年龄。

**更广泛的家庭。**父母各自的兄弟姐妹有1/2的机会是携带者，可以提供级联检测。为今后的妊娠提供遗传咨询，包括产前诊断的选择。

**经验。**新生儿筛查使治疗可以在损害发生之前开始。看起来状况良好的筛查阳性婴儿仍需要及时确诊。
:::
:::

## 染色体综合征与微缺失综合征

### 唐氏综合征

**唐氏综合征**（21三体）在英国约每1,000名活产儿中有1例。婴儿表现为肌张力低下、面部扁平、睑裂上斜、内眦赘皮、小耳、通贯掌，以及第一、二趾间的“草鞋脚”间隙。通常有学习障碍，但程度差异很大，早期支持会带来很大不同。

唐氏综合征儿童的照护主要是对相关疾病进行**监测**，遵循唐氏综合征医学兴趣小组的指南：

- **心脏**：约一半患有先天性心脏病，最常见的是房室间隔缺损。每个婴儿在出生后最初几周都要做超声心动图，即使检查正常。
- **消化道**：十二指肠闭锁和先天性巨结肠更常见。
- **甲状腺**：甲状腺功能减退症很常见；终身定期检查甲状腺功能。
- **听力和视力**：分泌性中耳炎、白内障和屈光不正很常见，因此定期检查听力和眼睛。
- **血液**：新生儿期短暂性异常髓系造血，以及白血病风险较高。
- **睡眠**：阻塞性睡眠呼吸暂停很常见，影响行为和学习。
- **生长**：描绘在唐氏综合征专用生长曲线图上。
- 乳糜泻和寰枢椎不稳也更常见。

唐氏综合征成人现在通常可活到六十多岁。阿尔茨海默病的发病比一般人群早，部分原因是*APP*基因位于21号染色体上。

### 22q11.2缺失综合征

::: example 有心脏缺陷和低钙的新生儿 {#ex-diGeorge}
科菲（Kofi）足月出生。第2天他出现惊厥。他的血钙低，甲状旁腺激素不适当地降低。超声心动图显示主动脉弓离断。他的脸稍长，耳小而低位。
::: solution
**模式。**圆锥动脉干心脏缺陷（主动脉弓离断、永存动脉干或法洛四联症）伴甲状旁腺功能减退所致低钙血症，是**22q11.2缺失综合征**（DiGeorge综合征）的典型表现。

**检查。**染色体微阵列分析，可检出该缺失。标准核型分析通常检不出。

**需要寻找的其他特征。**胸腺发育不良伴T细胞减少和感染风险；腭裂或腭功能不良导致喂养问题和鼻音；肾脏畸形；学习困难；以及日后焦虑、注意缺陷多动障碍、孤独症和精神病的风险较高。

**紧急预防措施。**接种活疫苗前检查T细胞数量。在免疫功能明确之前，只输注**经辐照的**血液制品，因为未经辐照的制品可在T细胞功能缺失的儿童中引起输血相关移植物抗宿主病。治疗低钙血症。

**家庭。**大多数缺失是新发的，但约1/10遗传自可能只有轻微特征的父亲或母亲。如果父母一方携带该缺失，每个孩子有50%的机会遗传，因此提供父母检测。
:::
:::

### 特纳综合征、爱德华兹综合征和帕陶综合征

**特纳综合征**（45,X及其变异型）约每2,500名女孩中有1例。它引起身材矮小和卵巢功能不全，并与主动脉缩窄、主动脉瓣二叶畸形、马蹄肾、甲状腺功能减退症和听力损失相关。它可在出生时表现为手足淋巴水肿，或在日后表现为身材矮小或青春期缺如（见[[paediatrics/growth-development]]）。生长激素和雌激素替代是主要治疗。

**爱德华兹综合征**（18三体）和**帕陶综合征**（13三体）罕见得多，引起多种严重畸形。大多数患儿在出生后最初几周或几个月内死亡，但有些存活更久。照护与父母共同计划，通常以舒适为重点。

## 遗传代谢病与遗传咨询

**遗传代谢病**是酶或转运体的遗传性缺陷，大多为常染色体隐性遗传。单个病种罕见，但合起来是新生儿疾病的重要原因。典型表现是出生时状况良好（妊娠期间胎盘清除了有毒代谢物），开始喂养后发病：喂养差、呕吐、嗜睡、惊厥和昏迷。

对脑病婴儿，床旁关键检查是血糖、血气、乳酸、酮体和**血氨**。高氨血症提示尿素循环障碍或有机酸血症，血氨极高是可能需要透析的急症。紧急治疗原则是停止蛋白质摄入、静脉给予葡萄糖以阻止分解代谢，并紧急寻求代谢专科团队的意见。

**苯丙酮尿症**（PKU）是筛查成功的典范。不治疗会引起严重学习障碍；在出生后最初几周开始低苯丙氨酸饮食，儿童可以正常发育。**中链酰基辅酶A脱氢酶缺乏症**（MCADD）在禁食或患病时引起无酮症性低血糖，并可导致猝死；一旦确诊，通过避免禁食并在患病时给予紧急葡萄糖方案来处理。

::: definition 遗传咨询 {#def-counsel}
**遗传咨询**是一个沟通过程，帮助人们理解一种遗传病、它如何遗传、它在家族中发生或再发的机会，以及可选择的方案。它是非指导性的：咨询者支持家庭自己作出决定。

**再发风险**是同一对父母的下一个孩子患病的机会。它取决于遗传方式：父母双方均为常染色体隐性遗传病携带者时每次妊娠为25%，父母一方患常染色体显性遗传病时为50%，大多数新发染色体异常和新发显性变异则较低（常约1%）。

**级联检测**是为已确诊遗传病患者的亲属提供检测。
:::

::: example 携带者风险的计算 {#ex-carrier}
汉娜（Hannah）的哥哥患囊性纤维化，汉娜本人未患病。她的伴侣萨姆（Sam）无家族史，为白种英国人血统。在未做任何检测之前，他们的第一个孩子患CF的机会是多少？
::: solution
**汉娜的携带者风险。**她的父母都是携带者。他们的孩子中，$1/4$患病，$1/2$为携带者，$1/4$非携带者。汉娜未患病，因此她属于其余三种可能之一，其中两种是携带者。她的携带者风险是$2/3$。

**萨姆的携带者风险。**他所属血统的人群携带者频率，约$1/25$。

**孩子的风险。**如果双方都是携带者，每个孩子患CF的机会为$1/4$。因此风险为
$$
\frac{2}{3} \times \frac{1}{25} \times \frac{1}{4} = \frac{2}{300} = \frac{1}{150}.
$$

**下一步。**携带者检测。检测汉娜是否携带其家族的变异，准确性很高。如果萨姆的常见变异检测组合结果为阴性，他的残余风险会远低于1/25，但不会降到零，因为检测组合不能检出所有变异。
:::
:::

::: warning 核型正常并不能排除遗传诊断
核型分析只能检出数百万碱基对大小的大片段染色体改变。22q11.2等微缺失、单基因病和许多印记疾病都检不出来。仅做核型分析后就告诉家庭“基因检测正常”是误导性的。正确的检测取决于要回答的问题，遗传学结果应与临床遗传学团队共同解读。
:::

::: quiz
一名男婴出生时有腭裂和下颌极小。出生第一天，他仰卧时出现气道梗阻发作。对这一模式最恰当的描述是什么？
- [ ] 综合征，因为有不止一种畸形
- [x] 序列征，因为一个原发畸形导致了其他畸形
- [ ] 联合征，因为这些畸形偶然同时出现
- [ ] 无意义的微小畸形
::: solution
这是**Pierre Robin序列征**。下颌过小（小颌畸形）使舌向后移位，从而阻止腭的闭合并阻塞气道。这类婴儿采用俯卧或侧卧护理，可能需要气道支持。它可单独出现，也可作为Stickler综合征或22q11.2缺失等综合征的一部分出现，因此仍需要遗传学评估。
:::
:::

::: history
1934年，挪威医生阿斯比约恩·弗林（Asbjørn Følling）在两名学习障碍儿童的尿液中发现了苯丙酮酸，描述了苯丙酮尿症。1953年，霍斯特·比克尔（Horst Bickel）及其同事在伯明翰证明低苯丙氨酸饮食能改善患儿状况；1963年，罗伯特·格思里（Robert Guthrie）发表了一种在干血斑上检测苯丙氨酸的简单细菌学方法，使对每个新生儿进行筛查成为可能。1938年，多萝西·安德森（Dorothy Andersen）描述了胰腺囊性纤维化；1989年，徐立之（Lap-Chee Tsui）、约翰·赖尔登（John Riordan）、弗朗西斯·柯林斯（Francis Collins）及其同事鉴定出*CFTR*基因。1944年，阿尔弗雷德·布莱洛克（Alfred Blalock）和海伦·陶西格（Helen Taussig）在技术员维维安·托马斯（Vivien Thomas）的协助下，施行了第一例缓解法洛四联症青紫的手术，这是儿童心脏外科的开端。
:::

遗传方式和染色体疾病的深入内容见[[genetics/mendelian-inheritance]]和[[genetics/chromosomal-disorders]]，基因检测见[[genetics/genetic-testing]]。新生儿筛查的介绍见[[paediatrics/newborn]]，人群筛查原则见[[public-health/screening]]。心脏病变的更多细节见[[cardiovascular/valve-congenital-disease]]。遗传病儿童的发育需求见[[paediatrics/neurodevelopment]]。

::: summary
- 评估可能存在畸形特征的儿童时，采集三代家族史和妊娠史，进行测量和系统检查；与父母作比较。
- 微阵列是大多数发育迟缓或多发畸形儿童的首选基因检测；其后是外显子组和基因组测序。
- 先天性心脏病约占每1,000名婴儿中的8名。大量左向右分流随肺阻力下降在4–6周时以心力衰竭起病；动脉导管依赖性病变在最初几天以衰竭或青紫起病。
- 囊性纤维化是常染色体隐性遗传病（白种欧洲人中携带者频率约1/25），通过新生儿筛查发现，汗液氯化物60 mmol/L或以上可确诊；CFTR调节剂改变了治疗。
- 唐氏综合征的照护是监测：心脏、甲状腺、听力、视力、睡眠、血液和生长。
- 22q11.2缺失：圆锥动脉干心脏缺陷、低钙血症和免疫缺陷；使用辐照血液，接种活疫苗前检查T细胞。
- 遗传代谢病表现为喂养后发病的婴儿；检查血糖、血气和血氨，停止蛋白质并给予葡萄糖。
- 再发风险取决于机制，咨询是非指导性的。
:::

## 习题

::: exercise 再发风险 {level=1}
给出下列每种情况下一次妊娠的再发风险：(a) 父母双方均为某常染色体隐性遗传病的携带者；(b) 父亲患某常染色体显性遗传病；(c) 孩子有新发22q11.2缺失，父母检测均为阴性。
::: solution
(a) 1/4（25%）。(b) 1/2（50%）。(c) 低，约1%，这考虑到父母一方的部分卵子或精子细胞携带该缺失（生殖腺嵌合）的小概率。
:::

::: exercise 分流大小 {level=1 check="(98-70)/(98-91)"}
心导管检查时，一名动脉导管未闭的儿童血氧饱和度为：主动脉98%，混合静脉70%，肺静脉98%，肺动脉91%。计算$Q_p/Q_s$。
::: solution
$Q_p/Q_s = (98 - 70)/(98 - 91) = 28/7 = $ **4**。这是一个大分流。
:::

::: exercise 唐氏综合征的监测 {level=1}
一名唐氏综合征婴儿在NIPE时心脏检查正常。他需要做超声心动图吗？说出儿童期要筛查的另外四种疾病。
::: solution
需要。约一半的唐氏综合征婴儿患先天性心脏病，房室间隔缺损在最初几天可能没有杂音，因此每个婴儿都要做超声心动图。其他：甲状腺功能减退症、听力损失、视力问题（白内障、屈光不正）、阻塞性睡眠呼吸暂停、乳糜泻，以及在唐氏综合征专用曲线图上的生长情况。
:::
:::

::: exercise 携带者风险 {level=2 check="2/3*1/25*1/4"}
一名女性的姐姐患CF（她本人未患病），她的伴侣无家族史，人群携带者频率为1/25。他们的第一个孩子患CF的概率是多少？以分数或小数作答。
::: solution
$\frac{2}{3} \times \frac{1}{25} \times \frac{1}{4} = \frac{1}{150} \approx 0.0067$。
:::

::: exercise 青紫的婴儿 {level=2}
一名足月儿在6小时龄时出现青紫，血氧饱和度70%，吸氧后不上升。他呼吸平稳，没有杂音。最可能的诊断和紧急处理是什么？
::: solution
吸氧无效的严重青紫而无呼吸窘迫，提示青紫型先天性心脏病，最可能是**大动脉转位**，此时体循环和肺循环平行运行，混合依赖动脉导管和卵圆孔。杂音常常没有。开始输注**前列腺素E**以维持动脉导管开放，如出现呼吸暂停则给予呼吸支持，并安排紧急超声心动图和转运至心脏中心，行球囊房间隔造口术，之后行大动脉调转术。
:::
:::

::: exercise 喂奶后变得嗜睡的婴儿 {level=2}
一名3日龄女婴出生时状况良好，现在变得嗜睡、吃奶差。她呼吸急促。血糖4.5 mmol/L，pH 7.48，血氨450 µmol/L。解释这些发现并概述紧急处理。
::: hint
呼吸性碱中毒伴极高血氨指向某一类特定疾病。
:::
::: solution
血氨极高伴呼吸性碱中毒（氨刺激呼吸）而无酸中毒，提示**尿素循环障碍**。有机酸血症通常引起代谢性酸中毒。必须同时考虑脓毒症。处理：停止一切蛋白质，静脉给予葡萄糖（常同时给予胰岛素）以阻止分解代谢，培养后开始抗生素，紧急联系代谢专科团队使用氨清除药物（苯甲酸钠、苯丁酸钠），如果血氨持续升高则准备血液滤过或透析。采集标本做专科检查。时间至关重要，因为高血氨会损害大脑。
:::
:::

::: exercise 为什么分两阶段筛查？ {level=3 check="round(1000*0.0004*0.95/(0.0004*0.95+0.9996*0.005))/10"}
某疾病患病率为1/2,500，一项筛查检测的灵敏度为95%，特异度为99.5%。计算其阳性预测值（百分比，保留一位小数），并解释为什么要使用第二阶段检测。
::: solution
在1,000,000名婴儿中，400名患病，999,600名未患病。真阳性：$400 \times 0.95 = 380$。假阳性：$999{,}600 \times 0.005 = 4{,}998$。$\text{PPV} = 380/(380 + 4{,}998) = 0.0707$，即**7.1%**。

超过90%的阳性结果会是假阳性。告诉数千个家庭他们的婴儿可能患有严重疾病，会造成真实的焦虑和代价。只对第一阶段阳性者进行第二阶段检测，例如IRT升高后检测*CFTR*变异，可使该检测的先验概率升至约7%，因此其阳性预测值要高得多。代价是，不携带所检测变异的部分患病婴儿会被漏诊。
:::
:::

::: exercise 新的诊断与家庭 {level=3}
一名7岁男孩有轻度学习困难，法洛四联症已修补，微阵列分析发现他有22q11.2缺失。他母亲儿时做过腭裂修补，从十几岁起就有“焦虑”。讨论这一诊断对男孩及其家庭的意义。
::: solution
**对男孩。**这一诊断解释了他的心脏缺陷和学习困难，并增加了监测内容：血钙和甲状旁腺功能，在再接种任何活疫苗前检查免疫功能（T细胞亚群），如需输血使用辐照血液，听力和腭功能评估，肾脏超声，甲状腺功能，以及因焦虑、注意缺陷多动障碍和精神病风险较高而在青春期和成年期监测心理健康。应考虑额外的教育支持，常通过教育、健康和照护计划提供。

**对母亲。**她的腭裂和焦虑提示她可能携带同样的缺失。经她同意，应为她提供检测和遗传咨询。如果她携带该缺失，她可能需要自己的检查（血钙、甲状腺、心脏、心理健康），她的每个孩子都有50%的机会遗传。

**对更大的家族。**可以讨论为她的亲属进行级联检测。咨询必须审慎处理：孩子的诊断可能带来父母意想不到的诊断，父母可能感到内疚。非指导性的咨询和支持至关重要。
:::
