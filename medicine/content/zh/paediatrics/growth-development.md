生长是儿科的生命体征。儿童健康的保健是“被应用的发育的生物学”：随时间被描绘的身高与体重及头围，“在任何实验室之前”讲述着营养与内分泌的功能及慢性的疾病及遗传的故事；发育的里程碑通过游戏为神经系统绘图；而入学与新生儿的筛查的方案把测量变成了一次又一次的行动。

## 测量生长

::: definition 生长的评估与成长停滞 {#def-growth}
“生长学是一门带着纵向的灵魂的测量的科学。技术：”身长卧位与身高立位在2岁之下及重复的测量要用同样的规则——正确的器械与身高计及不穿鞋及三次读数，因为变异是操作者的错误、不是生物学；在英国的或世界卫生组织的或本地的参考的集合上描绘“选择一个参考并坚持它”这一规则；根据父母的身高计算靶目标的范围；上臂中点的周径作为“当体重让人困惑时的那个工具”；头围作为脑的生长的探针带着它的小头与大头的鉴别；以及那条法则——“单个的数值意义不大、斜率意义一切；以及那句教学：沿百分位向下跨越那条线才是旗子、而不是那个绝对的数字；以及每一位受训者都需要一字不差地记住的那句——“一个在第0.4百分位上、却沿着自己的线生长的、父母高大的孩子是健康的；一个在第50百分位上减速的孩子是病的”。正在衰减的孩子：“体重的失败先于身高对身高在先对两者都的机制——因为急性的营养不足的保脑作用会保住身长、而慢性的损害会让两者都付代价；以及”头部被保住与被保不住的宫内生长受限多普勒的延续性；以及”被组织为摄入的不足对吸收的不足对利用的不足的成长停滞的原因带着那个分诊：最常见的是喂养的技术或供给或抗拒，而最罕见的是那种罕见的疾病；以及那份实际的检查——出生的病史与是否被抱着及奶瓶及谁喂及多久一次及吃饭时发生了什么的病史；以及危险信号的清扫——心力衰竭伴出汗的喂养及呼吸的急促及反流伴误吸及乳糜泻与囊性的纤维化及燃料的激素生长激素与胰岛素的样生长因子的结合蛋白3及甲状腺及肾及激素。矮小的检查：胰岛素样的生长因子1与结合蛋白3及甲状腺及乳糜泻及肾及激素及“先谈照护与热量”的筛查；以及骨龄的片子作为那项伴随的检查；以及那条教学——“特纳的综合征：每一位矮小的女孩都要做核型或有针对性的遗传学的检查，因为45倍体可以只表现为矮小，而颈蹼是晚的征象、不是早的“；以及那条格言——”一个停止长高却在增重的孩子，在内分泌的或外源的激素的或皮质醇的原因被排除之前就是它们；一个体重下降伴生长失败的孩子是营养的或胃肠的“；以及”生长激素治疗适应证的证据对行业的炒作谁符合条件、获益多大量、要治多少年、费用与监测；以及那句诚实的总结——“对特发的矮小使用生长激素是一种价值观的决定、不是对一种疾病的治疗”[[endocrine/hypothalamus-pituitary]]、[[gastrointestinal/digestion-absorption]]、[[paediatrics/safeguarding]]。**

## 发育

::: definition 发育的监测与延迟 {#def-development}
**发育是“在行动中被观察的、不是在格子里被观察的”。领域与它们的时间表：大运动的（坐与扶走及走；带着那条阈值——“独立行走平均12个月、18个月则是令人担忧的）；精细运动的（”16周之内的伸手与9到12月的捏取“；以及那条规则——”18个月之前的不对称的用手是一个偏瘫的危险信号、不是一种偏好）；视觉与听觉作为前提（那个筛查的当务之急：“一个不理你的孩子可能是聋的、而不是叛逆的）；以及言语与语言的关注的线（”2岁两个词、3岁两到三个词的句子）。社会认知的那一串：“共同的注意与指物及共同的参照，在12到18个月——正是组织了自闭症的识别的存在或不存在”。格言：“游戏就是儿科的神经的检查——一个不去探索的孩子不只是有运动的问题”；“发育协调的障碍与动作的笨拙藏在笨拙学校回避的门诊里”；以及那条绝对的话：“在任何年龄的退行都是一次急症转诊、不是一种变异”；”不对称的进步，以及在获得之后失去词语或社交的技能，在被排除之前是神经的退化的疾病带着代谢的与线粒体的及影像的及遗传的紧迫性；以及那条规则：“全面的延迟加退行加脏器的增大加樱桃红的斑点加惊厥加族裔加近亲的婚配，就是一段储存疾病的病史与检查及一份紧急的标本”；以及那条路径的改变：“一个全面延迟的孩子需要染色体的微阵列，而如今常常是一线的外显子组、而不是二线的一线代谢的大撒网”；以及“在床边，安氏与毛-维氏的认得出的人比检查更好”。而必须“带着日期与一个具名的负责人和一份计划”才能被说出的话——“观察等待与再等等看与六个月后复查，若不带，就是带着友好的措辞的过失”；“发育的延迟与残障之间的分别是学校和家庭接下来能做什么”；“监测属于所有的孩子；评估属于某些孩子；而干预属于现在”；“每一次的监测的访视都应测量生长并描绘它，并询问发育与这个家庭——四分钟内的那四个P，由练过的护士与医师来做”；以及“一个在一个上午做不全这四项的门诊是一个排班的问题、不是临床的局限”[[paediatrics/neurodevelopment]]、[[paediatrics/newborn]]、[[public-health/screening]]、[[endocrine/thyroid]]。**

## 青春期与骨

::: definition 青春期与正在生长的骨骼 {#def-puberty}
**青春期是一座被重新激活的时钟带着外科的并发症。正常的：“下丘脑的促性腺激素释放激素脉冲的发生器被重新唤醒，而肾上腺的雄激素的成熟与那根轴是分开的——所以那条规则是：阴毛的发育是肾上腺的，而阴毛先于乳房发育常常是良性的——但若在进展，就要检查先天肾上腺的增生与肿瘤及提前的骨龄；以及顺序：”乳蕾与睾丸的容积4毫升标志着中枢的青春期；而在女孩中，月经初潮是晚的、而生长的突增在初潮之前达到峰值；在男孩中，它在睾丸的生长之后“；以及”坦纳的分期是观察、不是审视，而分级的自我照片能减少痛苦为了分期而不需要侵入性的检查——这是一种懂得创伤的实践“；”11岁矮小而15岁正常是体质的延迟；11岁高而15岁正常是家族的模式——而每一句他跟我的小时候一样的病史都是一种预测“；以及那位”8岁就有乳蕾的女孩如今通常是正常的——对初潮的年龄的长期趋势与早期的乳房的发育及族裔及肥胖及内分泌的干扰物的流行病学，诚实的咨询是：大多数早期乳房的发育不需要一次磁共振“。过早的：”女孩在8岁之前、男孩在9岁之前；中枢的对外周的（配睾酮与雌二醇及黄体生成素及激发试验）；中枢的是激素依赖的，在女孩中通常是特发的；而在男孩与很年轻的女孩中及在进展者中要考虑下丘脑的病灶——所以要成像并治疗这一逻辑；以及性早熟的病因的流行病学已转向外源的雌激素，而三级转诊中心看到的是那混合、不是那80%的特发的女孩这一现实；以及那家族性的中枢的性早熟遗传的那个小众的领域；以及外周的是促性腺激素非依赖的，而超声与肾上腺与性腺的影像及特殊的检验会定位它“。延迟的：”13岁无乳房或14岁无睾丸的增大需要检查体质一时性的延迟与那类下丘脑的及高促性腺激素的原因：特纳的与那类和克氏与免疫的及治疗的原因；以及“没有青春期、没有生长突增”的少年需要骨龄与激素的组合及嗅觉与中线及肾脏的问题的筛查（卡尔曼的综合征是一个整体的诊断）。正在生长的骨：“成骨与骨骺的板及那套”年龄与成角的重塑的规则“——”一个2岁的股骨能重塑2厘米，而一位青少年几乎什么都不重塑“；”通过病理病灶的骨折在打钉之前要活检这一纪律；“股骨的头与掌骨及舟骨及月骨的无血供的坏死是骨骺的供血的疾病——而那间以名字命名的门诊是一间血管的门诊”；以及那个连接：“股骨头骺的滑脱再一次是儿科的髋部的急症”；以及“软骨的发育不全的枕骨大孔的狭窄与颈髓的压迫及肌张力低与呼吸的暂停睡眠的检查是麻醉的与神经外科要警惕的疾病；以及那一种肽类的类似物的治疗的时代“；以及”代谢的骨的疾病骨的软化与低磷酸酶的酶及那一种x连锁低磷的及双膦酸盐类及酶的替代是儿科与医学与外科的联合”[[endocrine/reproductive-endocrinology]]、[[endocrine/hypothalamus-pituitary]]、[[musculoskeletal/fractures]]、[[paediatrics/neurodevelopment]]。**

## 通向何处

“新生儿时期的方案”在[[paediatrics/newborn]]，神经发育的状况在[[paediatrics/neurodevelopment]]，保护的语境在[[paediatrics/safeguarding]]，内分泌的轴在[[endocrine/hypothalamus-pituitary]]与[[endocrine/thyroid]]，而营养在[[gastrointestinal/clinical-nutrition]]。

::: history
**生长与发育先变得可被测量、之后才变成医学的：套儿童期测量的装备——1830到1840年代的关于身体的统计学，1870年代学校测量的摊位，以及1900年代的那场关于生物测定的学会对期刊的辩论；而“生长的曲线始于一位比目鱼的研究者想要知道正常的孩子是什么样”。然后是百分位本身：“两条线替代了那套医生的直觉；而”一条孩子的矮小第一次成了一件可被追踪的事“。青春期的分期在1950与60年代被坦纳标准化（”套分级的照片让分期成为一项可以教并可以复现的观察）。中枢性早熟的抑制与生长激素的提取以及那段从尸体的垂体到一次医源性传播疾病黑暗的历史，随后是重组的时代；以及那一段肽类的类似物终于成为一种治疗的现在。而最近的一段历史是“人群的那一层：新生儿的筛查与入学的项目及学校的免疫接种的方案——以及那份被承认的：方案的曲线上空缺正是社会的不平等被过度转诊的与从未被转诊的群体——而一套训练的数据本身就带着公平的问题“。而它仍然结束于同一句诊室里的话：”孩子们按自己的时间表生长；我们的工作是在一个时间表改变时注意到并找出为什么，并在做这件事的同时保护这个孩子不因在学校里不一样而承受后果”[[endocrine/hypothalamus-pituitary]]、[[public-health/screening]]、[[medical-ethics-law/justice-resources]]。**
:::

::: summary
- “信号是生长的速度、不是单个的百分位”：描绘、用正确的手法重测、并把“向下跨越百分位”当作一个症状。
- 成长停滞按摄入对吸收对利用来分诊——多数是喂养的实践；而危险信号的清扫包括心与肾及内分泌与保护的原因。
- 发育监测读的是共同的注意与游戏及退行：任何年龄的退行都是一次紧急的转诊；而延迟需要一份带一个具名复查日期的计划。
- 性早熟按病史与激素及骨龄分为中枢对外周；而外源的激素的暴露是“一个值得直接问的常见的现代的元凶”。
- 一个12岁的女孩矮小而无青春期，即使没有畸形，也要求做特纳的检查；而单独的体质的延迟是一次有理性排除的诊断。
- “生长与发育的数据是公共卫生的基础设施”：筛查的方案需要有资助下游的路径与获取的公平，否则它们在伦理上会崩塌。
:::

## 练习

::: exercise 先把它描绘出来 {level=1}
一名4岁的孩子因“体重的担忧”就诊：出生3.2公斤；1岁时在第25百分位；如今0.2；身高在第25百分位、头围在50；吃饭“像只小鸟；非常活跃、很开心；父母又高又瘦。那张曲线说了什么？最初的三个动作是什么？
::: solution
**读出那条正在衰减的曲线（[[#def-growth]]、[[gastrointestinal/clinical-nutrition]]）：曲线说的是——”体重在三年里从第25百分位向下跨越到0.2、而身高与头围被保住，这是慢性的能量的不足或高消耗、不是基因的瘦——因为高而瘦的父母能解释比例、解释不了减速；以及那条推论：一个开心的孩子并不是没有疾病的证据，而一个不饿的孩子也不是食欲的证据“。动作：（甲）一份真正的饮食与吃饭时段的病史谁喂及多久一次及喂养时发生了什么，配3天的记录与一次称重观察的喂养或至少一次门诊的称量；以及那份贫困的筛问——学校的膳食与食物的保障及谁先吃。（乙）危险信号内科的清扫：尿肾小管的酸中毒与糖尿病与乳糜泻与甲状腺及血细胞计数与铁蛋白及急性的与慢性的反应蛋白及电解质与肝及白蛋白及钙磷及肌酸的激酶；以及大便的弹性蛋白酶与大便的培养及寄生虫及结核的试验。（丙）把它描绘下来并设一个有具名负责人复查的日期——“一次被安排好的复查就是一项检查”[[gastrointestinal/digestion-absorption]]、[[public-health/determinants-inequalities]]。**

::: exercise 用正确的年龄来判断 {level=2}
一名26周的早产现在的孩子，实际月龄20个月、矫正的月龄14个月；不会走；3个词；在矫正11个月时能独立地坐；新生儿髋部的超声正常；眼与耳正常。家人想要“物理的治疗”。请带着生长与发育的推理做咨询，并说出“什么会改变你对预后的想法”。
::: solution
**“按矫正的年龄做咨询”（[[#def-development]]、[[paediatrics/neurodevelopment]]）：先做算术——”矫正的14个月、不是实际的20个月；而矫正14个月还不能独立地在行走是令人担忧的、但不是异常的——我们判断的是自上次评估以来的轨迹；而早产儿的大运动的档案会落后然后追上来，但在矫正18个月之后仍存在则值得治疗与诊断；以及那句诚实的话：“全面大运动的延迟加3个词加矫正11个月才会坐加极度的早产，会提出脑的瘫痪与动作的协调的障碍及认知的风险问题；而足月的孩子在15到20个月独立行走的那条阈值正是让矫正14个月成为早、而不是令人安心的“；以及那句承认：”早产儿发育性髋部的发育不良是要检查的一件事；而视觉与听觉已经正常，这有帮助“。然后计划——”是的，物理的治疗，越早越好；以目标为导向、不是被动的手法，配对父母的教练、不是数小时数；以及对语言的评估与视与听的正式的重查；以及在矫正18个月时的那次具名的复查；以及”如果到矫正18个月还不会走，我们要开始为脑的瘫痪做正式的评估与配置——这句话说出来不是为了吓他们，而是为了让他们有一个日期可以指望“[[paediatrics/newborn]]、[[paediatrics/neurodevelopment]]。**

::: exercise 不慌张地估计 {level=1}

::: solution
