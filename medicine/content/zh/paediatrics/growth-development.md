生长是儿科学中最有用的单一体征。一个生长正常的儿童极不可能患有严重的慢性疾病，而一个生长减慢或停滞的儿童几乎总有值得查明的原因。发育是第二个体征。儿童按可预测的顺序获得技能，一个落后、发展不均衡或丧失技能的儿童，正在告诉我们有关大脑、感官或环境的某些信息。

本章讲解如何测量儿童、如何描绘和解读生长曲线图、如何评估发育，以及青春期如何进行。重点在于方法：测量本身很简单，但结论取决于是否正确地测量，以及是否着眼于随时间变化的模式，而不是单个数据点。

## 测量生长

单次测量说明儿童处于什么位置。重复测量则说明儿童正朝哪里发展，而这通常是更重要的问题。

常规测量项目是体重、身长或身高，以及头围。婴儿裸体在电子秤上称重。2岁以前用量板卧位测量身长，此后用身高计测量站立身高，测量时双足跟并拢，头部保持在法兰克福平面。头围取经过前额和枕部的三次测量中的最大值，使用无弹性软尺。每项测量都有几毫米或几克的误差，当两次测量时间间隔很近时，这一点很重要。

::: definition 百分位与生长曲线图 {#def-growth}
**百分位**是某一测量值在同年龄、同性别儿童参照人群中的位置。身高位于第25百分位的儿童比参照人群中25%的儿童高，比75%的儿童矮。

**生长曲线图**将百分位线按年龄绘出。英国的曲线图有九条线：第0.4、2、9、25、50、75、91、98和99.6百分位。相邻两条线相距三分之二个标准差，因此两条线之间的距离称为一个**百分位间距**。

**生长迟滞**（以前称“发育停滞”）是指婴儿期或儿童期体重增长速度慢于该年龄和性别的预期。它是一种描述，而不是一个诊断。
:::

在英国，出生至4岁的儿童使用2009年引入的**UK-WHO曲线图**。它将世界卫生组织儿童生长标准（描述健康母乳喂养儿童*应当*如何生长）与英国早产儿数据结合起来。从2岁起，身高、体重和体重指数（BMI）使用**UK90**参照曲线图。两套系统在2至4岁之间重叠。

::: theorem 百分位线在标准差尺度上等距分布 {#thm-centiles}
对于在每个年龄大致呈正态分布的测量值，英国曲线图上的百分位线对应的z评分为−2.67、−2、−1.33、−0.67、0、+0.67、+1.33、+2和+2.67。z评分随时间保持不变的儿童是沿着一条百分位线生长的；z评分下降0.67即下降一个百分位间距。
:::

::: proof
z评分是某一测量值高于或低于同年龄、同性别均值的标准差个数。如果测量值服从正态分布，每个z评分对应一个固定的百分位：z = 0是第50百分位，z = −0.67约为第25百分位，z = −1.33约为第9百分位，z = −2约为第2百分位，z = −2.67约为第0.4百分位。曲线图的设计者选择这些线，使它们在z尺度上间距相等。体重呈偏态而非正态分布，因此参照数据先经过变换（LMS法），使其在每个年龄都呈正态。这就是为什么体重百分位线以千克计看起来间距不均，但以标准差计仍然等距。其实际意义是：“跨越两条百分位线”在曲线图的任何位置都代表相同程度（以标准差计）的变化。
:::

下图显示标准正态曲线。将−2.67与+2.67之间的区域加阴影，可以看到只有约0.8%的健康儿童位于最外侧两条线之外。因此，低于第0.4百分位的测量值总是需要解释。

### 生长速度与正常生长的形态

生长在胎儿期和婴儿期最快。典型的足月儿约5个月时体重翻倍，1岁时约为出生体重的3倍，第一年身长约增加一半。整个儿童期身高每年增加约5–6 cm。青春期出现生长突增，女孩身高增长速度峰值约为每年8–9 cm，男孩约为每年9–10 cm。女孩的突增比男孩早约两年，这是成年男性平均比女性高约13 cm的主要原因。

**身高增长速度**是两次测量之间身高的变化除以间隔时间，以每年厘米数表示。由于测量误差为几毫米，生长速度应在至少6个月、最好一年的间隔上计算。

### 遗传潜能：父母中位身高

儿童的成年身高在很大程度上取决于父母的身高。**父母中位身高**用于估计儿童的遗传目标身高：

$$
\text{MPH（男孩）} = \frac{\text{父亲} + \text{母亲} + 13}{2}, \qquad \text{MPH（女孩）} = \frac{\text{父亲} + \text{母亲} - 13}{2}
$$ {#eq-mph}

身高以厘米计。13 cm用于校正男女之间的平均差异。目标范围大约是MPH ± 8.5 cm。如果儿童的身高百分位明显低于根据父母推算的百分位，即使高于第2百分位，也值得仔细评估。

::: example 父母中位身高的计算 {#ex-mph}
阿米尔（Amir）9岁，身高位于第9百分位。他父亲身高183 cm，母亲170 cm。计算他的父母中位身高，并判断他的身高是否与之相符。
::: solution
对于男孩，$\text{MPH} = (183 + 170 + 13)/2 = 366/2 = 183$ cm。目标范围约为174.5–191.5 cm。

在英国男性曲线图上，183 cm的成年身高位于第75与第91百分位之间。阿米尔位于第9百分位，比他的遗传预期低约两个百分位间距。

这一差距并不能作出诊断，但意味着“他矮是因为父母矮”这一解释不成立。下一步是找出既往测量数据，看他是一直位于这条百分位线上，还是下降到这里；在接下来6个月测量他的身高增长速度；检查他的青春期状态，并询问父母的青春期发动时间；并询问慢性疾病病史（例如乳糜泻或炎症性肠病）。
:::
:::

### 校正早产

早产的婴儿并没有“损失”生长，只是起步更早。对于37周前出生的婴儿，测量值按**校正年龄**描绘：实际年龄减去提前出生的周数。在UK-WHO曲线图上，32–36周出生的婴儿校正到1岁，32周前出生的婴儿校正到2岁。

::: example 描绘前校正年龄 {#ex-corrected}
埃拉（Ella）在胎龄28周出生，现在26周龄。她的测量值应按什么年龄描绘？
::: solution
足月按40周计。埃拉提前了$40 - 28 = 12$周出生。她的校正年龄是$26 - 12 = 14$周。

如果按26周描绘，她的体重可能低于第2百分位，提示生长迟滞。按14周描绘，体重可能位于第25百分位，完全合适。由于她在32周前出生，校正要持续到2岁。同样的校正也适用于发育里程碑：预计她在*校正*年龄约6周时出现应答性微笑，也就是出生后约18周。
:::
:::

### 生长迟滞

NICE指南NG75（2017）按跨越的百分位间距数来界定对婴儿和儿童体重的担忧。如果出生体重低于第9百分位，下降一个或以上百分位间距即值得关注；出生体重在第9至第91百分位之间者，下降两个或以上；出生体重高于第91百分位者，下降三个或以上。无论出生体重如何，当前体重低于第2百分位也值得关注。

对大体重婴儿的较大容许范围反映了**均值回归**。出生体重部分反映宫内环境，许多大婴儿在最初几个月会落到较低的百分位上。父母身材矮小的瘦小婴儿也可能向上跨越百分位。两者都是正常的。

大多数生长迟滞有简单的原因：摄入的奶或食物不够，或保留下来的不够。第一步是仔细询问喂养史、观察一次喂养，并询问呕吐、大便和疾病情况。器质性原因较少见但很重要：乳糜泻、牛奶蛋白过敏、囊性纤维化、先天性心脏病、肾脏疾病、甲状腺功能减退症和慢性感染。忽视也是原因之一，住院后生长恢复是一个重要的观察结果。

### 身材矮小与身材高大

**身材矮小**通常定义为身高低于第2百分位，转诊时则以低于第0.4百分位为标准。大多数矮小儿童是健康的，属于以下两种模式之一：

- **家族性矮小**：父母身材矮小，儿童以正常速度平行于百分位线生长，骨龄与实际年龄相符。
- **体质性生长和青春期延迟**：儿童期身材矮小，青春期发动晚，生长持续时间更长。骨龄延迟。常有“晚熟”家族史。最终身高通常在家族目标范围内。

提示病理性矮小的情况包括：身高百分位下降、身高增长速度低、四肢与躯干比例失调、畸形特征，或身高远低于家族目标。病因包括甲状腺功能减退症、生长激素缺乏、女孩的特纳综合征、乳糜泻、炎症性肠病、慢性肾脏病、长期使用糖皮质激素以及心理社会剥夺。

**身材高大**通常是家族性的。病理性原因包括性早熟（现在高，但由于生长板过早闭合，成年后矮）、克兰费尔特综合征和马方综合征，罕见情况下为生长激素过多。

::: warning 一次测量不等于生长模式
单独一次位于第2百分位的身高或体重本身几乎说明不了什么。生长评估中最常见的错误是：按错误的年龄描绘（忘记校正早产，或按最近的生日描绘）、使用错误的曲线图，以及根据相隔几周、差值小于测量误差的两次测量下结论。务必找出既往测量值，核查描绘，并与父母作比较。
:::

## 发育

发育是指技能的获得。它分为四个领域描述：**粗大运动**、**精细运动与视觉**、**言语、语言与听力**，以及**社交、情感与行为**。在每个领域中，技能出现的顺序在儿童之间非常一致，但每项技能出现的年龄差异很大。因此，知道**界限年龄**（几乎所有儿童都已具备某项技能的年龄）比知道平均年龄更有用。

::: definition 发育迟缓与发育倒退 {#def-development}
**发育迟缓**是指在预期的界限年龄仍未达到里程碑。它可以只影响一个领域（例如单纯言语迟缓），也可以影响多个领域。

**全面发育迟缓**是指5岁以下儿童在两个或以上领域存在显著迟缓。对年龄较大的儿童，一旦可以进行正式评估，就使用**智力障碍**（英国服务中称为学习障碍）这一术语。

**发育倒退**是指丧失儿童已经获得的技能。它总是异常的，总是需要紧急评估。
:::

### 需要掌握的里程碑

下表列出几个关键里程碑的典型年龄和界限年龄。数据依据英国常用的教学资料；不同来源相差几周。

| 领域 | 技能 | 典型年龄 | 若未达到则在此年龄转诊 |
|---|---|---|---|
| 社交 | 应答性微笑 | 6周 | 8周 |
| 粗大运动 | 无支撑独坐 | 6–8个月 | 9个月 |
| 粗大运动 | 独立行走 | 12个月 | 18个月 |
| 精细运动 | 全掌抓握方块 | 6个月 | — |
| 精细运动 | 钳形抓握 | 10个月 | 12个月 |
| 精细运动 | 伸手够物 | 4个月 | 6个月 |
| 言语 | 发出辅音咿呀声（“baba”） | 7个月 | — |
| 言语 | 说出有意义的单词 | 12个月 | 18个月 |
| 言语 | 把两个词连起来 | 20–24个月 | 30个月 |
| 社交 | 用手指指向以分享兴趣 | 12个月 | 18个月 |

有两种模式在任何年龄都是异常的：**12个月前出现利手**（提示另一侧无力，例如偏瘫），以及**技能丧失**。家长对听力或视力的担忧总是应当认真对待，因为他们往往是对的。

### 如何评估发育

在英格兰，**健康儿童计划**为每个家庭提供与健康访视员的接触，包括约9–12个月和2–2½岁时的评估，届时会检查发育，常使用年龄与发育进程问卷（Ages and Stages Questionnaire）。医生通常通过病史和观察儿童游戏来评估发育。一个有用的顺序是：先观察，然后询问家长儿童在家里会做什么，再用简单的玩具测试特定技能。

发现迟缓时，首先要问：

1. **它是真实的吗？**年龄是否已经按早产校正？儿童当时是否生病、疲倦或害羞？
2. **哪些领域受累？**单纯言语迟缓首先提示听力损失或语言障碍。单纯运动迟缓提示神经肌肉疾病或脑性瘫痪。全面发育迟缓提示遗传、代谢、结构或环境原因。
3. **是否有倒退？**
4. **头围和生长是否正常？**小头畸形和巨头畸形都是重要线索。

每个言语迟缓的儿童都需要正式的听力测试。每个全面发育迟缓的儿童都需要仔细检查畸形特征、皮肤标记（例如咖啡牛奶斑）和神经系统体征。一线检查通常包括染色体微阵列分析和脆性X检测、运动迟缓男孩的肌酸激酶测定，以及甲状腺功能。神经发育障碍见[[paediatrics/neurodevelopment]]。

::: example 20个月仍走不好的幼儿 {#ex-regress}
夸梅（Kwame）20个月。他18个月时会走，但经常摔倒，不会跑。他的言语有点落后：会说六个词。检查发现他小腿粗大。让他从坐在地上站起来时，他先翻身俯卧，然后用双手撑着大腿推起身体。
::: solution
**第1步：哪个领域？**主要是粗大运动迟缓，伴较轻的言语迟缓。

**第2步：检查补充了什么？**双手攀扶大腿站起是**高尔斯征**（Gowers' sign）。它显示髋部和大腿肌肉无力。近端无力的男孩出现小腿粗大，提示假性肥大。

**第3步：可能的诊断。**这种模式是**迪谢内肌营养不良**（Duchenne muscular dystrophy）的典型表现，这是一种由抗肌萎缩蛋白缺失引起的X连锁疾病。迪谢内肌营养不良常伴言语和学习困难，这解释了言语迟缓。

**第4步：检查。**首选检查是血清**肌酸激酶**，它显著升高（常为正常值的10至100倍）。*DMD*基因检测可确诊。转诊至儿童神经肌肉专科。

**经验。**任何18个月仍不会走的男孩都应测定肌酸激酶。诊断延迟意味着家庭的遗传咨询和糖皮质激素等治疗的开始都被延迟。
:::
:::

### 头围

婴儿期头部生长反映脑的生长。**小头畸形**（头围低于第0.4百分位）可能是家族性的，但也可能反映先天性感染、遗传综合征、胎儿酒精暴露或脑损伤。**巨头畸形**（高于第99.6百分位）常为家族性（测量父母头围），但也可能反映脑积水。最重要的体征是**向上跨越百分位**的头围，尤其伴有前囟膨隆、颅缝分离、呕吐或“落日”眼时。

::: example 头长得太快的6周婴儿 {#ex-headcirc}
在6周检查时，索菲娅（Sofia）的头围位于第91百分位。出生时位于第50百分位。她的体重和身长位于第50百分位。她吃奶很好。前囟饱满但不紧张，父母的头围都属于一般大小。
::: solution
索菲娅的头围在六周内跨越了两个百分位间距，而体重和身长保持在同一百分位。这是不成比例的头部生长，父母的头围不能解释它。

需要担心的是**脑积水**，即脑脊液过多导致脑室扩大。婴儿的颅缝未闭，因此在出现典型的颅内压增高体征之前头部就会增大。其他原因包括良性蛛网膜下腔增宽，以及罕见的占位性病变或硬膜下积液。

下一步是经开放的前囟进行**头颅超声**，快速且无需镇静，若异常则行MRI。应仔细重新测量，因为单次测量误差很常见，但前囟饱满时，重复测量不应延误影像学检查。如果发现硬膜下积液，鉴别诊断包括虐待性头部创伤（见[[paediatrics/safeguarding]]）。
:::
:::

## 青春期与生长中的骨骼

青春期是产生性成熟和成年身高的一系列身体变化。它由下丘脑–垂体–性腺轴的重新激活驱动：促性腺激素释放激素（GnRH）的脉冲式分泌刺激垂体释放黄体生成素（LH）和卵泡刺激素（FSH），进而刺激性腺。

::: definition 青春期及其分期 {#def-puberty}
**Tanner分期**将青春期发育分为五期，从青春期前（1期）到成人（5期），女孩的乳房、男孩的生殖器以及两性的阴毛分别分期。

女孩青春期的第一个征象是**乳房初发育**（乳芽），平均约在11岁。男孩的第一个征象是**睾丸增大**至4 mL或以上（用睾丸测量器测量），平均约在11.5–12岁。

**性早熟**是指女孩8岁前、男孩9岁前出现青春期发动。**青春期延迟**是指女孩13岁仍无乳房发育，或男孩14岁仍无睾丸增大。
:::

两性的事件顺序不同。女孩的生长突增出现得早，在乳房2–3期；**月经初潮**出现得晚，约在乳房初发育后2–2½年，此时生长突增大部分已经结束。男孩的生长突增出现得晚，在生殖器4期。这解释了为什么12岁的女孩常比同龄男孩高。

### 骨龄

在两性中，生长板都在雌激素的作用下闭合。骨骼的成熟程度可以通过左手和腕部X线片与标准图像对比来估计。这就是**骨龄**。骨龄延迟意味着还有更多的生长空间，是体质性延迟、甲状腺功能减退症和生长激素缺乏的典型表现。骨龄提前是性早熟和肥胖的典型表现。

### 性早熟

在女孩中，大多数性早熟是**中枢性**的（依赖促性腺激素）：正常过程只是开始得太早，大多数病例找不到病因。在男孩中，找到病因的情况多得多，因此男孩性早熟总是需要检查大脑（MRI）以及睾丸和肾上腺。外周性（不依赖促性腺激素）原因包括先天性肾上腺皮质增生症、肾上腺或性腺肿瘤以及McCune–Albright综合征。

应当认识两种良性变异。**单纯乳房早发育**是孤立的乳房发育，通常见于2岁以下女孩，不伴生长突增。**单纯肾上腺功能早现**是由肾上腺雄激素引起的阴毛或腋毛早现和体味，不伴乳房或睾丸发育，在南亚裔和非洲–加勒比裔儿童以及肥胖儿童中更常见。

::: example 矮小的13岁女孩 {#ex-shortgirl}
莱拉（Leila）13岁6个月，因为是班上最矮的而被转诊。她的身高位于第2百分位；8岁时也位于第2百分位。她没有乳房发育。过去一年的身高增长速度为5 cm。她母亲身高160 cm，15岁月经初潮；父亲172 cm。骨龄11岁。
::: solution
**第1步：遗传目标。**对于女孩，$\text{MPH} = (172 + 160 - 13)/2 = 319/2 = 159.5$ cm。这接近女性第25百分位。莱拉低于家族预期。

**第2步：模式。**她的身高五年来一直沿第2百分位，每年5 cm的速度对青春期前儿童是正常的。她并没有偏离自己的百分位。

**第3步：青春期。**13.5岁仍无乳房发育，符合青春期延迟的定义。她的骨龄延迟两年半，因此她比同学剩余的生长空间更多。

**第4步：解释。**青春期前稳定生长、骨龄延迟、母亲月经初潮晚，这些组合符合**体质性生长和青春期延迟**。但对于青春期延迟的矮小女孩，必须排除两个诊断。**特纳综合征**（45,X及其变异型）引起身材矮小和卵巢功能衰竭；每个原因不明的矮小女孩都需要做核型分析。**甲状腺功能减退症**以及乳糜泻等慢性疾病也必须排除。

**第5步：计划。**核型分析、甲状腺功能、乳糜泻血清学、全血细胞计数和炎症指标，以及LH、FSH和雌二醇。FSH升高提示卵巢功能衰竭。如果均正常，可以给予安慰并随访。部分体质性延迟的青少年可从短疗程低剂量性激素中获益以启动青春期，这是专科决定。
:::
:::

::: quiz
一名4岁男孩的身高自婴儿期以来一直位于第9百分位。他的父母中位身高位于第9百分位。他的身高增长速度正常。最可能的解释是什么？
- [x] 家族性矮小：他正沿着自己的遗传百分位正常生长。
- [ ] 体质性延迟：他的骨龄会延迟。
- [ ] 生长激素缺乏：他的身高低于第25百分位。
- [ ] 生长迟滞：他需要喂养评估。
::: solution
他一直位于同一百分位，生长速度正常，位置与父母相符。这对这个家庭来说是正常的生长。第9百分位不属于身材矮小，生长激素缺乏会导致百分位下降和生长速度降低。生长迟滞指的是体重，而不是身高。
:::
:::

::: history
通过测量儿童来判断其健康状况有着悠久的历史。1759年至1777年间，菲利贝尔·盖诺·德蒙贝亚尔（Philibert Guéneau de Montbeillard）从儿子出生到18岁每六个月为他测量一次；这些数据后来被绘成图，显示了人类生长曲线的形态，包括青春期突增。20世纪，詹姆斯·坦纳（James Tanner）及其在伦敦儿童健康研究所的同事在哈彭登生长研究（Harpenden Growth Study）中研究儿童的生长。1966年，他与R. H. 怀特豪斯（R. H. Whitehouse）和Michio Takaishi发表了英国身高、体重和生长速度标准，坦纳对青春期各期的描述也成为青春期分期的标准方法。2006年，世界卫生组织发布了基于六个国家健康母乳喂养儿童的标准，英国于2009年将其用于4岁以下儿童。
:::

## 后续内容

生长与发育是本课程其他各章的背景。新生儿期，包括校正年龄和早期体重下降，见[[paediatrics/newborn]]。常以身材矮小或发育迟缓起病的遗传综合征见[[paediatrics/congenital-genetic]]，孤独症、注意缺陷多动障碍、脑性瘫痪和学习障碍的评估见[[paediatrics/neurodevelopment]]。从青少年角度看的青春期，包括可能以体重下降或青春期延迟起病的进食障碍，见[[paediatrics/adolescent-health]]。生长的内分泌基础见[[endocrine/hypothalamus-pituitary]]。

::: summary
- 准确测量，按正确的年龄在正确的曲线图上描绘，并依据随时间变化的模式而不是单个数据点来判断生长。
- 英国曲线图的百分位线相距三分之二个标准差；约0.8%的健康儿童位于最外侧两条线之外。
- 父母中位身高给出遗传目标；远低于家族目标的儿童即使高于第2百分位也需要评估。
- 早产校正到1岁（32–36周出生）或2岁（32周前出生）。
- 大多数矮小儿童是家族性矮小或体质性延迟；百分位下降、生长速度低和比例失调提示疾病。每个原因不明的矮小女孩都需要做核型分析。
- 里程碑使用界限年龄。倒退、过早出现利手以及家长对听力或视力的担忧总是需要评估。
- 女孩8岁前、男孩9岁前青春期发动为性早熟；女孩13岁、男孩14岁仍未发动为青春期延迟。男孩性早熟通常有病因。
:::

## 习题

::: exercise 计算父母中位身高 {level=1 check="166"}
一个女孩的父亲身高180 cm，母亲165 cm。以厘米计算她的父母中位身高。
::: hint
对于女孩，先减去13 cm再除以2。
:::
::: solution
$\text{MPH} = (180 + 165 - 13)/2 = 332/2 = 166$ cm。目标范围约为157.5–174.5 cm。
:::
:::

::: exercise 按正确的年龄描绘 {level=1 check="7"}
一个31周出生的婴儿现在16周龄。该婴儿的校正年龄是多少周？
::: solution
提前了$40 - 31 = 9$周出生，因此校正年龄为$16 - 9 = 7$周。由于该婴儿在32周前出生，校正要持续到2岁。
:::
:::

::: exercise 身高增长速度 {level=1 check="round(10*(131.2-128.0)/(9/12))/10"}
一个男孩3月时身高128.0 cm，九个月后为131.2 cm。计算他的身高增长速度（cm/年），保留一位小数。
::: solution
增长3.2 cm，历时0.75年，因此速度为$3.2/0.75 = 4.27$ cm/年，四舍五入为**4.3** cm/年。这对青春期前儿童属于正常偏低。由于测量误差为几毫米，九个月间隔的速度相当可靠，但再测一次会更可靠。
:::
:::

::: exercise 体重指数 {level=2 check="round(10*30/1.3^2)/10"}
一个8岁女孩体重30 kg，身高1.30 m。计算她的BMI（kg/m²），保留一位小数，并说明在儿童中如何解读。
::: solution
$\text{BMI} = 30/1.30^2 = 30/1.69 = 17.75$，四舍五入为**17.8** kg/m²。

儿童的BMI随年龄变化，因此不能与成人切点比较。应将其描绘在UK90 BMI百分位曲线图上。在英国临床实践中，BMI达到或高于第91百分位提示超重，达到或高于第98百分位提示肥胖。
:::
:::

::: exercise 哪些婴儿存在生长迟滞？ {level=2}
评估三名4月龄婴儿。婴儿A：出生体重第98百分位，现在第50百分位。婴儿B：出生体重第50百分位，现在第9百分位。婴儿C：出生体重第6百分位，现在略低于第2百分位。按NICE阈值，哪些值得关注？
::: hint
数一数跨越的百分位间距，并记住阈值取决于出生时的百分位。
:::
::: solution
婴儿A出生时高于第91百分位，已跨越三个间距（第98→第91→第75→第50）。这达到了大体重婴儿三个间距的阈值，因此值得关注，尽管均值回归是可能的解释，可能只需了解喂养史即可。

婴儿B出生时位于第9至第91百分位之间，已跨越三个间距（第50→第25→第9），超过两个间距的阈值，因此值得关注。

婴儿C出生时低于第9百分位，已跨越一个间距，降到略低于第2百分位。一个间距是小婴儿的阈值，而且任何低于第2百分位的体重本身就值得关注，因此这也值得关注。

三名婴儿都需要喂养评估和复查。这些阈值用于识别需要关注的情况，而不是疾病。
:::
:::

::: exercise 性早熟的男孩 {level=2}
一个7岁男孩出现阴毛、成人体味和生长突增。他的双侧睾丸各为2 mL。睾丸体积说明了什么？最需要排除的原因是什么？
::: solution
睾丸仍为青春期前大小（小于4 mL）而有雄激素过多的表现，意味着雄激素并非来自促性腺激素驱动下的睾丸。这是**外周性（不依赖促性腺激素）**性早熟。来源很可能是肾上腺。最重要的原因是**先天性肾上腺皮质增生症**（非经典型可以这样起病）和**肾上腺肿瘤**。检查包括17-羟孕酮、肾上腺雄激素、骨龄和肾上腺影像学。单纯肾上腺功能早现引起的变化较轻，不伴明显的生长突增或骨龄快速提前。
:::
:::

::: exercise 言语迟缓的儿童 {level=3}
一个2½岁女孩会说约十个词，不会把词连起来。她能听从简单指令，会和娃娃玩假想游戏，会用手指指东西给妈妈看。她的运动发育正常。去年冬天她反复患耳部感染。讨论鉴别诊断和首选检查。
::: solution
这是单纯的表达性语言迟缓（她在30个月时应能把词连起来），理解力良好，运动发育正常，社交沟通良好（用手指指向以分享兴趣、假想游戏）。

**鉴别诊断。**(1) 分泌性中耳炎引起的**传导性听力损失**，反复耳部感染提示这一点。(2) **发育性语言障碍**，常见且常有家族性。(3) 家庭中语言接触不足。(4) 由于她的社交沟通良好，孤独症可能性较小，但应记在心里。(5) 由于其他领域正常，全面发育迟缓不太可能。

**首选检查。**包括鼓室导抗测试在内的正式**听力学评估**，因为听力损失是可治疗的，而每个言语迟缓的儿童都必须检查听力。可同时转诊言语和语言治疗。应继续发育监测，因为语言障碍日后可能影响学习和行为。
:::
:::

::: exercise 解读一组生长数据 {level=3}
杰米（Jamie）是一个6岁男孩，身高如下：3岁，第50百分位；4岁，第50百分位；5岁，第25百分位；6岁，第9百分位。他的体重一直保持在第50百分位，因此BMI百分位在上升。他看起来状态良好，但母亲说他容易疲倦，学业成绩下降。可能属于哪一类疾病？首先做哪些检查？
::: hint
比较身高和体重的变化。哪些疾病使身高增长减慢而体重得以维持？
:::
::: solution
杰米的身高跨越百分位下降（两年下降两个间距，身高增长速度低），而体重得以维持，因此他相对变得超重。这种模式指向**内分泌原因**。营养性和慢性炎症性疾病通常先影响体重、后影响身高，因此儿童会变瘦。

主要的内分泌原因是**获得性甲状腺功能减退症**（疲倦和学业成绩下降与之相符）、**生长激素缺乏**（包括颅咽管瘤等肿瘤所致，后者还可能引起头痛和视野缺损）以及**库欣综合征**，包括类固醇治疗所致。

首选检查：甲状腺功能（TSH和游离T4）、骨龄X线片，并仔细询问头痛、视力和类固醇使用史，检查视野和眼底。如果甲状腺功能正常，他需要转诊至儿科内分泌专科进行生长激素检测，很可能还需行垂体区MRI。
:::
:::
