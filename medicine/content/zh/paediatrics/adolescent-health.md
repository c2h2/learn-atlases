世界卫生组织把10至19岁定义为青少年期，这是身体、大脑和社会生活迅速变化的时期。大多数青少年身体健康，但许多心理健康问题在这个年龄开始，吸烟、饮酒和使用药物等习惯在这个年龄形成，患慢性病的青少年也在这个年龄开始接管自己的照护。在英国，青少年死亡的首要原因是伤害和自杀，而不是疾病。

青少年也是临床医生最常觉得难以交谈的患者。他们可能尴尬、戒备，或担心哪些信息会被转告给父母。因此，本章的技能既关乎疾病，也关乎问诊：如何单独见青少年，保密和同意如何运作，以及如何询问最重要的事情。

## 问诊与保密

青少年的大脑仍在发育。驱动寻求奖赏和情绪的边缘系统在青春期早期就已成熟，而支持计划和自我控制的前额叶皮质则持续成熟到二十多岁中期。这有助于解释为什么青少年会冒更多风险，尤其是在同伴面前，以及为什么他们对被当作伙伴的反应比对说教的反应更好。

::: definition 年轻人的同意与保密 {#def-consult}
**保密**是指年轻人分享的信息未经其同意不会被转告他人。它适用于年轻人，就像适用于成人一样。只有在年轻人本人或他人面临严重伤害风险，或法律要求时，才能打破保密，并且通常应先告知年轻人。

根据《1969年家庭法改革法》第8条，**16或17岁**的年轻人只要具有决策能力，就被推定能够同意自己的医疗。

**16岁以下**的年轻人如果有足够的理解力和智力完全理解所提议的内容，就可以同意治疗。这称为**Gillick能力**，源自1985年英国上议院的判决。能力针对的是具体决定；儿童可能有能力同意一项简单治疗，却没有能力同意一项复杂治疗。

**Fraser准则**专门适用于为16岁以下青少年提供避孕和性健康方面的建议与治疗。临床医生必须确认：年轻人理解这些建议；无法被说服告诉父母或允许临床医生告诉父母；无论是否避孕都可能发生性行为；若不提供，其健康可能受损；并且提供符合其最佳利益。
:::

18岁以下年轻人拒绝治疗与同意治疗的处理方式不同。如果符合年轻人的最佳利益，法院可以推翻其对挽救生命治疗的拒绝。这种情况很少见，需要上级和法律意见。

有一些固定的界限。根据《2003年性犯罪法》，**13岁以下**儿童在法律上不能同意性活动，因此13岁以下儿童的性活动总是需要进行儿童保护转介。对13–15岁的年轻人，性活动同样违法，但法律的本意不是起诉年龄相仿的年轻人之间自愿的性活动；临床医生要评估是否存在剥削和虐待，例如伴侣年龄大很多、胁迫、送礼物或使用毒品或酒精。

### 单独见年轻人

良好的做法是问诊的一部分有父母在场，一部分单独见年轻人。把这解释为常规（“我对所有年轻人都会单独谈一段时间”），可以避免暗示任何人受到怀疑。单独交谈开始时，清楚地解释保密及其界限。

结构化的心理社会病史有助于覆盖重要话题而不作假定。**HEEADSSS**框架询问：

- **H**家庭：谁住在家里、关系、安全。
- **E**教育和就业：出勤、成绩、欺凌、计划。
- **E**进食：体重和体像、节食、暴食或呕吐。
- **A**活动：朋友、爱好、运动、屏幕和社交媒体使用。
- **D**药物：烟草、电子烟、酒精和其他毒品。
- **S**性：恋爱关系、性活动、避孕、知情同意、性取向和性别认同。
- **S**自杀与情绪：情绪低落、焦虑、自伤、自杀念头。
- **S**安全：伤害、网络安全、暴力、剥削。

从不太敏感的话题（家庭、学校、活动）开始，再转到更敏感的话题。直接询问自伤和自杀念头不会增加风险，许多年轻人会因为被问到而感到释然。

::: example 腹痛并藏着秘密的15岁女孩 {#ex-teenpain}
克洛伊（Chloe）15岁，因下腹痛2天由母亲陪同来急诊科就诊。在解释保密后单独交谈时，她说她和男朋友发生过性关系，上次月经是7周前。她的男朋友16岁。她请医生不要告诉她母亲。
::: solution
**临床优先事项。**有性生活的年轻人出现下腹痛伴月经推迟，需要做**妊娠试验**以排除可能危及生命的**异位妊娠**。为她做检查并测量生命体征。还应考虑盆腔炎、尿路感染、卵巢囊肿意外和阑尾炎。

**同意与保密。**克洛伊15岁。如果她理解这些检查及其意义，她就具有Gillick能力，可以同意检查。应尊重她的保密要求；没有自动告诉她母亲的义务。

**儿童保护。**15岁的性活动低于法定同意年龄，因此要评估这段关系。伴侣年龄相仿、没有胁迫、礼物、酒精或毒品、也没有其他担忧，并不自动需要转介。年龄差距大、有控制或剥削的迹象，或克洛伊本人有担忧，就会改变这一判断。记录评估过程。

**进一步照护。**提供性传播感染检测，包括衣原体和淋病，并讨论避孕。鼓励她让母亲或另一位信任的成年人参与，并主动提供帮助，同时尊重她的决定。

**如果检测阳性，**她需要紧急评估以排除异位妊娠，然后就所有选择获得保密、不带评判的支持。
:::
:::

## 常见表现

::: definition 进食障碍、抑郁与自伤 {#def-presentations}
**神经性厌食**是限制食物摄入导致体重显著降低，伴对体重增加的强烈恐惧以及对体形或体重的体验紊乱。

**神经性贪食**是反复暴食并伴呕吐、使用泻药或过度运动等代偿行为，自我评价过度受体形和体重影响；体重通常在正常范围内。

**回避/限制性摄食障碍（ARFID）**是由感觉敏感、对食物缺乏兴趣或害怕噎食等后果所驱动的限制性进食，不伴对体形的担忧。

年轻人的**抑郁症**是持续的情绪低落或易激惹，或兴趣和愉快感丧失，伴睡眠、食欲、精力和注意力改变，无价值感和死亡念头等其他症状，持续至少两周并影响功能。

**自伤**是有意的自我中毒或自我伤害，无论其表面目的为何。
:::

### 进食障碍

进食障碍通常始于青春期，神经性厌食是所有精神疾病中死亡率最高的之一。它们影响男孩和各种背景的年轻人，而不仅仅是白人女孩，在这些群体中常被漏诊。

在儿童和年轻人中，体重用**BMI中位数百分比（%mBMI）**评估：年轻人的BMI除以同年龄、同性别的BMI中位数，再乘以100。成人BMI切点不适用，因为BMI随年龄变化。

神经性厌食的医学风险用英国皇家精神科医学院2022年发布的指南**《进食障碍中的医学急症》（MEED）**评估，它取代了之前的MARSIPAN和Junior MARSIPAN指南。它考虑体重和体重下降速度、心率、血压（包括体位变化）、体温、血液检查（尤其是电解质、血糖和磷酸盐）、心电图以及从蹲位站起的能力。%mBMI低于70%是高风险的标志之一。

饥饿使心率减慢、血压和体温降低，并耗竭磷酸盐、钾和镁。重新开始进食时，胰岛素把这些物质驱入细胞，血液中的水平可能危险地下降；这就是**再喂养综合征**。高风险的年轻人需要住院进行医学稳定，在再喂养期间仔细监测电解质。

NICE NG69推荐的年轻人神经性厌食的主要治疗是**以进食障碍为重点的家庭治疗**，在年轻人康复期间，支持父母负责孩子的进食。

::: example 评估体重下降的年轻人 {#ex-ed}
普丽娅（Priya）16岁。4个月来她通过限制饮食和每天跑步减重9 kg。她体重41.0 kg，身高1.65 m。卧位心率44次/分，立位72次/分，血压88/52 mmHg，体温35.6 °C。本例中，取她同年龄、同性别的BMI中位数为20.5 kg/m²。
::: solution
**BMI。**$41.0/1.65^2 = 41.0/2.7225 = 15.06$ kg/m²。

**%mBMI。**$15.06/20.5 \times 100 = 73.5\%$。

**解释。**她的%mBMI刚高于70%，但体重下降很快（约每月2 kg），静息心率很低且体位变化时明显上升，血压低，体温偏低。在MEED中，即使%mBMI不是最低，体重快速下降和心血管不稳定也是高医学风险的标志。运动训练可以降低静息心率，但不能同时解释这些发现。

**行动。**紧急评估，进行血液检查（电解质、磷酸盐、镁、血糖、全血细胞计数、肝功能）和心电图，并与儿科团队讨论收住院进行医学稳定和监督下再喂养，同时紧急转诊至社区进食障碍服务。坦诚而温和地向普丽娅解释原因，并让她的父母参与。评估她的情绪和自伤风险。
:::
:::

简短的筛查问卷，如五个问题的SCOFF，有助于识别需要更全面评估的年轻人。与任何筛查检测一样，其有用程度取决于该疾病在受检群体中的常见程度。

### 抑郁、焦虑与自伤

情绪低落和焦虑在青春期很常见，并在过去十年中变得更加常见。年轻人的抑郁可能表现为易激惹、退缩、学业成绩下降、躯体症状或物质使用，而不是明显的悲伤。

NICE NG134（2019）建议分级处理。轻度抑郁最初可采用积极监测，如持续存在，则采用数字化认知行为治疗、团体治疗或指导下的自助。中重度抑郁需要转诊至儿童和青少年心理健康服务（CAMHS）接受特定的心理治疗。抗抑郁药（通常是氟西汀，fluoxetine）只在专科评估后并与心理治疗联合使用，并密切监测激越或自杀念头增加，尤其在最初几周。

自伤在青少年中很常见，是日后自杀的强危险因素。NICE NG225（2022）强调，每个自伤的年轻人都应得到同情和尊重，都应接受探讨其需要和处境的**心理社会评估**，并都应有一份照护计划。NICE建议不要使用风险评估工具或量表来预测未来自杀或决定谁接受照护，因为它们的预测能力很差。

如果你受到本节所涉问题的影响，在英国可以从Childline（0800 1111）、Samaritans（116 123）以及面向35岁以下年轻人的Papyrus HOPELINE247（0800 068 4141）获得支持。

::: example 不再去上学的14岁男孩 {#ex-sr}
马库斯（Marcus）14岁，过去一个月大部分时间没去上学。他父亲说他待在房间里，易激惹，不再踢足球。单独交谈时，他说他觉得“没意义”，睡不着，一直在割自己的手臂。他因性取向在网上遭到欺凌。
::: solution
**评估。**持续一个多月的情绪低落、兴趣丧失、睡眠障碍和退缩提示**抑郁症**。他有自伤行为。网络欺凌和他对自己性取向的感受是重要的应激因素。

**直接询问自杀念头。**询问他是否想过结束生命、是否有任何计划，以及是什么帮助他坚持下去。询问不会增加风险。

**即时照护。**查看并处理伤口。与马库斯讨论还需要让谁知道。他的安全是首要的，他父亲需要参与保护他的安全，但马库斯可以参与决定分享哪些信息以及如何分享。

**转诊。**紧急转诊至CAMHS进行评估和治疗，紧急程度取决于他关于自杀念头和计划所说的内容。与他一起制订**安全计划**：预警信号、他自己可以做的事、可以联系的人以及危机热线。与学校合作处理欺凌问题并安排逐步复学。

**尊重。**用他自己的话来称呼他的身份，避免假定，并明确表示他的性取向不是问题；欺凌才是问题。
:::
:::

### 物质使用与性健康

在青春期尝试酒精、烟草和大麻很常见，电子烟也已广泛流行。询问时应不带评判。风险包括事故、无保护的性行为、被剥削，对一些人来说还包括依赖和心理健康问题；规律使用大麻与易感年轻人的精神病有关。简短建议、减少伤害和转诊至青少年物质滥用服务是主要手段，提示被剥削的使用模式，如替他人携带毒品，属于儿童保护问题。

年轻人的性健康照护包括避孕、性传播感染检测，以及关于知情同意和健康关系的建议。**长效可逆避孕**（皮下埋植剂和宫内避孕方法）最有效，适合年轻人。**紧急避孕**的选择有：含铜宫内节育器（最有效，无保护性行为后5天内）、醋酸乌利司他（ulipristal acetate，120小时内）和左炔诺孕酮（levonorgestrel，72小时内）。衣原体是年轻人中最常见的细菌性性传播感染，常无症状。

### 一个骨科陷阱

::: example 膝痛的13岁男孩 {#ex-suFE}
丹尼尔（Daniel）13岁，左膝疼痛3周，开始跛行。他超重。膝关节检查正常。髋关节检查显示，屈曲左髋时髋关节外旋，内旋受限且疼痛。
::: solution
**关键原则。**髋部疼痛常在膝部感觉到，因为闭孔神经同时支配两者。**膝痛的儿童一定要检查髋关节。**

**诊断。**超重的青春期早期少年内旋受限、屈曲时强制性外旋，提示**股骨头骨骺滑脱（SCFE）**：在生长突增期间，股骨头在生长板处向后滑移。

**检查。**双髋X线片，包括蛙式侧位片，因为滑脱可能只在侧位片上可见，而且双侧都可能受累。

**处理。**停止负重，紧急转诊至骨科进行手术固定。延误有进一步滑脱和股骨头缺血性坏死的风险。
:::
:::

## 慢性疾病与过渡

::: definition 过渡与青少年服务 {#def-systems}
**过渡**是患有长期疾病的年轻人从以儿童为中心的医疗有计划地转向以成人为导向的医疗。NICE NG43（2016）建议在13–14岁开始计划，由一名指定工作人员协调，让年轻人参与决策，并安排成人服务在转移前与年轻人见面。

**依从性**是指一个人的行为（如服药）与商定建议相符的程度。它在青春期普遍下降。
:::

许多慢性疾病在青春期变得更难管理。生长、青春发育和作息变化改变了疾病及其治疗：例如，青春期胰岛素需要量上升。年轻人想和同龄人一样，可能怨恨自己的疾病，并正在学习自我管理。依从性差很常见，与其责备，不如理解。

转到成人服务是年轻人常常脱离照护的时期，结局可能恶化。良好的过渡包括分阶段培养自我管理技能、单独见年轻人、让他们负责预约和处方，以及与成人团队联合门诊。“Ready Steady Go”等结构化项目有助于追踪这一过程。

::: warning 不要把年轻人排除在他们自己的照护之外
把问题都指向父母、越过年轻人讨论他们的情况，是很容易犯的错误。这样做会削弱他们正在发展的自主性，使他们不太可能透露重要信息。先对年轻人说话，从青春期早期起每次问诊都单独见他们一段时间，并解释保密。父母仍是重要的伙伴，目标是把双方结合起来，而不是以一方取代另一方。
:::

- [ ] 拒绝，因为她未到法定同意年龄。
- [ ] 先告知她的父母再开处方。
- [x] 按Fraser准则评估她，如果符合，就保密地提供避孕。
- [ ] 因为16岁以下的性活动违法，转介至儿童社会照护部门。
::: solution
Fraser准则允许在16岁以下有能力的年轻人无法被说服让父母参与、无论如何都可能发生性行为、且不提供则健康会受损时，不经父母参与而为其提供避孕。儿童保护评估是问诊的一部分，但年龄相仿的年轻人之间自愿的性活动，在没有被剥削迹象时，本身不需要转介。
:::

::: history
1985年，英国上议院对*Gillick诉西诺福克和威斯贝奇地区卫生局*案作出裁决。十个孩子的母亲维多利亚·吉利克（Victoria Gillick）对允许医生在未经父母同意的情况下向16岁以下女孩提供避孕建议的政府指南提出了质疑。斯卡曼勋爵（Lord Scarman）提出了现以吉利克命名的能力检验标准，弗雷泽勋爵（Lord Fraser）提出了关于避孕的具体准则。《1969年家庭法改革法》此前已赋予16和17岁青少年同意医疗的权利。青少年需要专门服务的观念在二十世纪下半叶逐步发展，1989年通过的《联合国儿童权利公约》确立了儿童就影响他们的事项表达意见的权利。
:::

## 后续内容

青春期与生长见[[paediatrics/growth-development]]，保护年轻人免受虐待和剥削见[[paediatrics/safeguarding]]。进食障碍、心境障碍和自伤的深入内容见[[psychiatry/eating-personality-disorders]]、[[psychiatry/mood-disorders]]和[[psychiatry/self-harm-suicide-prevention]]。全生命周期的同意与保密见[[medical-ethics-law/consent-capacity]]和[[medical-ethics-law/confidentiality]]，避孕见[[obstetrics-gynaecology/contraception-fertility]]。

::: summary
- 青少年期是大脑发育、冒险行为和精神疾病起病的时期；伤害和自杀是首要死因。
- 问诊的一部分单独见年轻人，解释保密及其界限，并用HEEADSSS组织心理社会病史。
- 16–17岁青少年被推定能够同意；16岁以下如具有Gillick能力可以同意；避孕适用Fraser准则。
- 13岁以下的性活动总是需要儿童保护转介；对13–15岁青少年，评估是否存在剥削。
- 进食障碍用%mBMI和MEED指南评估；家庭治疗是年轻人神经性厌食的一线治疗；警惕再喂养综合征。
- 抑郁分级处理（NG134）；抗抑郁药只与心理治疗联合并在专科监督下使用。
- 每个自伤的年轻人都需要富有同情的照护和心理社会评估，而不是风险评分（NG225）。
- 膝痛的儿童一定要检查髋关节。
- 过渡应在13–14岁开始，由指定工作人员负责，并逐步培养自我管理能力。
:::

## 习题

::: exercise 谁可以同意？ {level=1}
对下列每名患者，说明在英格兰同意治疗的法律依据：(a) 一名需要阑尾切除术的17岁少年；(b) 一名想治疗痤疮并理解其风险的14岁少年；(c) 一名要求避孕且不愿让父母参与的15岁女孩。
::: solution
(a) 被推定具有决策能力，可依据《1969年家庭法改革法》第8条同意。(b) Gillick能力。(c) Fraser准则，同时评估能力和儿童保护问题。
:::

::: exercise HEEADSSS {level=1}
列出HEEADSSS每个字母代表什么，并解释为什么顺序很重要。
::: solution
家庭；教育和就业；进食；活动；药物；性；自杀与情绪；安全。这一顺序从不太敏感的话题过渡到更敏感的话题，在询问药物、性和自伤之前留出建立融洽关系的时间。
:::
:::

::: exercise 计算%mBMI {level=1 check="round(1000*(38/1.58^2)/19.8)/10"}
一名15岁女孩体重38 kg，身高1.58 m。取她同年龄、同性别的BMI中位数为19.8 kg/m²。计算她的%mBMI，保留一位小数。
::: solution
$\text{BMI} = 38/1.58^2 = 38/2.4964 = 15.22$ kg/m²。$\%\text{mBMI} = 15.22/19.8 \times 100 = $ **76.9%**。
:::

::: exercise 再喂养综合征 {level=2}
解释为什么饥饿的年轻人开始进食时磷酸盐会下降，以及可能的后果。
::: solution
饥饿期间身体利用脂肪和蛋白质，胰岛素水平低，细胞内的磷酸盐、钾和镁被耗竭，尽管血液水平可能正常。摄入碳水化合物后胰岛素升高，把葡萄糖、磷酸盐、钾和镁驱入细胞，细胞需要磷酸盐来合成ATP和其他磷酸化中间产物。血液水平随之下降。严重低磷血症可引起肌无力、呼吸衰竭、心力衰竭、心律失常、惊厥和死亡。预防方法是谨慎地再喂养，监测电解质并在需要时补充。
:::
:::

::: exercise 紧急避孕 {level=2}
一名17岁女孩4天（96小时）前发生了无保护的性行为。还有哪些紧急避孕选择？哪一种最有效？
::: solution
左炔诺孕酮只获准在72小时内使用，因此已不再适用。醋酸乌利司他（120小时内）和**含铜宫内节育器**（无保护性行为后5天内，或最早预计排卵日后5天内）仍可选择。含铜宫内节育器最有效，还能提供持续避孕。提供性传播感染检测，并讨论持续避孕，如相关，还要讨论知情同意和安全。
:::
:::

::: exercise 是情绪低落还是别的？ {level=2}
一名16岁少年3个月来疲乏、情绪低落、退缩，体重下降4 kg。在诊断抑郁症之前，应考虑哪些躯体原因和其他问题？
::: solution
躯体原因：甲状腺功能减退症、贫血（包括月经过多所致缺铁）、乳糜泻、炎症性肠病、1型糖尿病、传染性单核细胞增多症和其他病毒感染后疲劳，罕见情况下为恶性肿瘤。体重下降还提示进食障碍的可能。其他问题：物质使用、睡眠问题（包括入睡时间推迟和大量使用屏幕）、欺凌、虐待或剥削，以及妊娠。HEEADSSS病史、体格检查和简单的血液检查会有帮助。
:::
:::

::: exercise 设计过渡门诊 {level=3}
一家医院请你改进1型糖尿病年轻人的过渡，其中许多人在转诊后不再复诊。设计一个方案。
::: solution
**尽早开始。**按照NICE NG43，在12–13岁开始准备，由一名指定工作人员负责，并用结构化项目（例如Ready Steady Go）追踪技能：理解疾病、调整胰岛素、申请处方、预约就诊、应对酒精、驾驶、性和避孕。

**改变问诊方式。**每次就诊都单独见年轻人一段时间，使用HEEADSSS，并筛查进食紊乱（包括为减重而漏打胰岛素）和情绪低落。

**衔接服务。**儿科和成人团队联合开设青年门诊，时间灵活（晚上、放学或下课后），短信或应用程序提醒，并在成人服务中指定一名联系人。

**随访。**追踪未复诊的年轻人并主动联系，而不是让他们出院。监测出勤率、HbA1c、因糖尿病酮症酸中毒住院以及患者体验等结局，并让年轻人参与服务设计。
:::
:::

::: exercise 性健康中的儿童保护问题 {level=3}
一名14岁女孩到性健康门诊要求紧急避孕。她说她的男朋友22岁，给她买礼物，带她去聚会，在聚会上她被给酒喝。她要求不要告诉任何人。讨论临床应对和儿童保护应对。
::: solution
**临床照护。**提供紧急避孕，进行性传播感染和妊娠检测，并讨论持续避孕。她可能有能力同意这些措施。

**儿童保护。**伴侣年龄大很多、礼物、酒精和聚会都是**儿童性剥削**的指征。成年人与14岁儿童之间的性活动是刑事犯罪。她的安全高于她的保密要求，因此即使没有她的同意，也必须与儿童社会照护部门（并通过当地商定的流程与警方）分享信息。

**如何做。**如实向她解释为什么必须分享信息以及接下来会发生什么，尽可能让她参与，不要作出无法兑现的保密承诺。做好仔细、客观的记录。遵循门诊的儿童保护程序，并征求指定儿童保护负责人的意见。保持今后照护的大门敞开：被剥削的年轻人往往不认为自己是受害者，与服务机构的信任关系本身就具有保护作用。
:::
