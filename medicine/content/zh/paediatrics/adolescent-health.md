青春期是一段被误诊为一个行为的问题的发育的阶段，而青少年的医学把它当作生理学来治疗。青少年的脑——边缘系统奖赏的敏感走在前额的控制之前，以及被移位的昼夜的节律和作为人群的常态的睡眠的债——这解释了许多被成年人称为懒惰与鲁莽的东西。这一章讲的是保密与能力，以及那些就诊；常见的情况疼痛与皮肤及体重及情绪及性的健康及药物；以及青少年所需要的那过渡与学校及人口的工具。

## 门诊与保密

::: definition 同意、保密与青少年的门诊 {#def-consult}
**青少年医学的两种货币是信任与时间，而两者都要花在那场保密的谈话上。一个16岁之下的年轻人，如果对这一个决定有充分的理解与智力，就可以为治疗同意（一项能力的标准）；而具体的指南专门管理着不为父母所知避孕的建议。实务的检验是理解、保持、权衡与传达；加上临床医师的判断：这个年轻人很可能会使用这一治疗；如果没有它，他的健康很可能会受损；而他们的最佳利益要求这么做——而父母的参与是被鼓励的、不是被要求的。保密在头两分钟里被许诺、然后被守住：我们谈的东西留在我们之间，有三个例外，而我现在就告诉你们——如果有人在受到伤害；如果你正处于严重的伤害的危险；以及那一条有边界的、我们与你一起做而不是绕过你做的传染病的接触的追踪。例外是罕见的，而它们在使用之前被解释、不是在使用之后。法律的地面在记录里很重要：一个有能力的15岁的性传播感染的被瞒着父母的治疗是合法的；而一个14岁的在自我伤害之后要止痛药的要求不是一次保密的危机、也不该变成一次；而当它与这个年轻人一起被排练过——你希望谁知道、谁绝对不能知道——信息共享就比让它成为一次惊吓时更有效。门诊的结构：每一次就诊都有一部分是与临床医师独处的电话的翻译在场，而兄弟姐妹与母亲在敏感的那一半被请出房间；总是提供一位陪同的人；在双手移动之前把检查解释清楚；以及那份三分钟的、能找出大多数疾病心理的社会的筛查：学校的出勤与成绩；家庭的关系；进食与体的像；睡眠入睡的时间与醒来的时间及屏幕——晚睡一小时可以表现为抑郁；活动；药物与酒精及电子烟；自我伤害；心境与焦虑；行为与法律；由他们自己描述的、而不是由一个勾选项来假定的性；以及网上的安全，包括霸凌、以及装扮成与一个年长二十岁的人的一段恋爱到来的剥削。最后那条规则是：青少年是识别“你是否见过十几岁的孩子”的专家：“你这个年龄的大多数人……”打开病史的能力超过任何问卷；而以“我该怎么写给你的全科，以及我能告诉你妈妈什么”结束的那次门诊，正是会产出下一次就诊的那一次“[[paediatrics/safeguarding]]、[[psychiatry/psychiatric-assessment]]、[[clinical-skills/communication]]。**
:::

## 常见的就诊

::: definition 就诊、治疗与青少年的特有的陷阱 {#def-presentations}
**青少年的名单在重复：避孕与性的健康——”那位在吃避孕药的、或带着那个埋植的或那个宫内节育器的孩子，正带着那个会决定是否继续的副作用的提问；妊娠选择的咨询与产前的照护（见[[obstetrics-gynaecology/pregnancy-antenatal]]）；性传播感染的筛查，以及那句“我忘了我的那一针”的依从的挽救；暴食-清除与限制的模式（见[[psychiatry/eating-personality-disorders]]）；自我伤害，配自杀风险的评估与安全的计划（见[[psychiatry/self-harm-suicide-prevention]]）；电子烟正是那个曾经的吸烟的形状的那个洞，而要以事实的方式问起大麻与一氧化二氮；以及那场不制造出一个进食障碍肥胖的门诊——在私下称重或干脆不称；讨论行为而不是数字；治疗这个家庭的食物环境、而不是这个孩子的羞耻。然后是慢性的疾病：那个随着发育正常地主张控制权而依从崩溃的孩子——那个把打针“忘了”的1型的糖尿病的少年，是在做身份的功课；处理方式是把它大声地命名出来、而不是靠监视。三个会逮住通科医师的、青少年特有的陷阱：第一，急性的髋——“那个被贴为”生长的疼痛“的跛行的、体重大的13岁的股骨头骨骺的滑脱；这里的那张X线是一项决定、不是一种礼貌；而答案是今晚不负重并叫骨科——在一次可以被固定的滑脱变成一只被毁掉的髋之前。第二，睾丸的扭转——那个呕吐着、却羞于指向自己腹股沟的14岁；而那条规则是在每一个不适的少年的男孩身上检查生殖器；那6小时的窗口使得迅速的问诊本身就是一项临床的干预。第三，月经的紊乱——那个“月经量多”被称作正常而铁蛋白被耗空的缺铁的女孩；处以缺课来表现子宫内膜的异位症；以及那个必须谨慎诊断多囊卵巢的综合征（因为正常的青春期的特点会模仿它）。月经的病史（疼痛与时长及量及规律）是青少年女孩一项生命的体征，属于每一份记录。再加上定义这一章的时代的情况：性别的痛苦——好的实务意味着彻底地探索、治疗共病的孤独症与神经的发育的及心理的健康的情况、一次真实生育的对话、以及在时间的界限之内做出的决定，而那最被需要的孩子往往是最晚被转诊的：靠伪装挺过来的、有神经发育障碍的女孩。加那个多症状的少年（头痛与腹痛及头晕、体格检查正常）——他需要的是这份构思：“真实的症状、可理解的心与身的放大、分级的恢复、一位统筹的临床医师”，而不是又一次的检查的级联，因为那份转诊的跑步机本身，就是那次治疗的失败”[[paediatrics/acute-childhood-illness]]、[[endocrine/reproductive-endocrinology]]、[[musculoskeletal/fractures]]。**
:::

## 青少年的医学所需要的系统

::: definition 过渡、学校与人口的工具 {#def-systems}
**有三件事，比任何药物都更决定青少年的结局：学校、交班，以及人口的这种基础设施。学校几乎是所有事情交付的渠道：接种的方案；作为早期的预警的系统的缺课与被劝离的数据（它们预警着保护的问题、以及未被诊断的学习的与心理的健康的问题）；以及那份教育、健康与照护的计划要么撑住、要么失败特殊教育的界面（见[[paediatrics/neurodevelopment]]）。一个从不与年级的主管说话的儿科医师，是在真空里执业；而那位学校的护士是这个国家最被闲置的临床医师。从未年的服务到成人服务的过渡是一个过程、不是一封信：一位具名统筹的工作者；过渡的护照；一场14到16岁的、由年轻人主导规划的会议；为成人的临床医师写医学的摘要；以及诚实的谈话——16岁的避孕由谁来开处方，以及那位上了学院之后血糖的控制崩塌的少年由哪间门诊接手。过渡质量审计的线索就是收住的数据——它们在交班的那几年里会翘起来；而好的服务靠全科的名册与具名的工作者把它们压下去、不靠漂亮的出院的摘要。在人口的层面，青春期正是预防要么落地、要么死掉的地方：接种的补种；吸烟与酒精的指导；以及关于头盔与安全带及刀具及溺水的、讲起来很无聊而确实救命的谈话——它们救的恰恰是那些不系安全带的人群。以及那套可及性的建筑：年轻人不会使用必须排在父母身边的服务；所以保密的、随到随看的性的健康与青少年的咨询的中心及先打电话心理健康的分诊，以及诚实的网上的引导——它们是那个界面的那一层，缺了它，上面每一项政策都会变成一份文件。最后是测量的纪律：青少年的服务应当追踪：由年轻人自己报告的可及性“你能不能在父母不在场的情况下约到一次门诊”)；连续性“你知道你那位具名的工作者吗”)；按剥夺与族裔的出勤的公平；以及年轻人自己报告的那个结局——这个系统认不认识他们。因为一个处在麻烦中的17岁的人会在19岁寻求帮助与否的最好的预测者，是有没有一位临床医师曾经帮助过他们一次、并且没有让他们受辱“[[public-health/prevention-promotion]]、[[public-health/determinants-inequalities]]、[[clinical-skills/records-handover]]。**
:::

::: example 那个“腹痛与一个秘密的15岁” {#ex-teenpain}
一名15岁的女孩，两个月内因脐周的疼痛四次到急诊；血液正常；今天她流泪、安静，并要求在“没有我妈妈”的情况下谈话。
::: solution
**句“没有我妈妈”（[[#def-consult]]、[[#def-presentations]]）：头五分钟决定一切——把母亲温和地分离出去的那套做法的脚本（“她就在这里等；之后我们一起见她”）；陪同的人在场；以及那句青少年真正能回答的提问：“有没有发生过什么你还没有告诉医生的事？”。之后的病史要覆盖那腹部反复的疼痛所藏起来的那三联：虐待或性的暴力常常以一位年长一些的“男朋友”来呈现，或以一段她认为是自己的错的“僵住”的叙述；焦虑与拒绝上学伴躯体的放大；以及妇科的原因——卵巢的囊肿与周期中期的及月经的病理，以及无论病史怎么说都要考虑的妊娠。行动——先相信，并按指征检查；接入性暴力的那条路径、而不是临场编造法医学的提问；与她而不是与她的父母商定一份安全的计划；用她的原话记录；并确切地解释什么会被共享、与谁、以及为什么。因为一个不得不把母亲带进一次披露的女孩，是一个永远不会披露的女孩；而那四次到急诊，是这个系统没能与她独处的失败。当那个秘密既安全又被相信之后，躯体的疼痛通常就消退——“我相信你；这能解释你的肚子；而这是接下来的安排”这三句话能打断一场躯体化的旋涡[[paediatrics/safeguarding]]、[[clinical-skills/communication]]。**
:::
:::

::: example 那个“髋部疼痛的16岁的板球的运动员” {#ex-suFE}
一名16岁，体质量指数34，3周的“生长的疼痛”的大腿与膝的不适；走路时外旋的跛行；急症的X线被报告为正常；而他的母亲说“他只是长得太快了”。
::: solution
**在被证明之前就是股骨头的骨骺的滑脱（[[#def-presentations]]、[[musculoskeletal/fractures]]）：识别——”被转诊的膝的疼痛，在被证明之前就是髋的疼痛；被迫的外旋与外八字的步态就是那个征；而在一个少年身上，髋要带着站立的前后位与蛙腿位的X线来检查；一张在急症的紧迫程度下被读的“正常”的片子要被一位资深的人重读——因为早发的滑脱是一处微妙骨骺的增宽，漏掉它会毁掉一个职业生涯与一只髋。今晚的行动——“从现在开始不负重；不再打板球；不许”试试止痛药再看看“；当晚或次日早晨儿科骨科的复查；在被固定的手术室里，在一处轻度的滑脱变成一处重度的之前把它钉住——因为这整场病是一个有小小窗口机械的问题，带着终身的后果：软骨的溶解与无血供的坏死，是决定他的三十岁的并发症。内分泌的那条注脚——”在一个不寻常的年龄或体型的滑脱会引出甲状腺与生长激素的查看；而那场关于体重的谈话要在之后、在私下、与他一起进行，围绕这只髋与他的运动来框定、而不是在他母亲面前围绕一个数字。落实——“另一只髋会得到监护与教育，因为相当一部分的少数会发生在对侧；学校体育的豁免今天就被写下来；以及理疗与回到运动的方案由一个具名的团队拥有——因为男孩要么太早回到运动、要么彻底放弃，而两者都是服务的失败”[[paediatrics/acute-childhood-illness]]、[[endocrine/hypothalamus-pituitary]]。**
:::
:::

::: example 那个“电子烟之后胸痛的17岁” {#ex-vape}
一名17岁的男孩，3个月的每天的含四氢大麻酚的电子烟；因胸膜的疼痛与气短就诊；血氧93%，胸部的X线清晰；而一位每次都先开口的父亲在诊室里。
::: solution
**电子烟相关的肺损伤这一形状的病与那半个门诊（[[#def-consult]]、[[#def-presentations]]）：医学——维持氧；检查那张X线会漏掉的纵隔的气体的积聚与小的积液；按发现做计算机断层或超声心动；鉴别包括心肌的炎；那个既吸电子烟又在一次长途的飞行之后吸过烟人的肺的栓塞；以及与那一种维生素E的乙酸酯相邻黑市的弹头化学性的肺炎；只有当随访归你负责时才让他回家，并把电子烟的戒断作为处方的一部分来治疗。门诊的形状——“在两分钟之内把父亲分离出去，作为标准的做法；因为儿子对每一个提问的”我不知道“是一个翻译的问题：临床医师必须问儿子无法在父亲面前说出的事——电子烟里是什么、谁在买、他是被卖给他还是被逼着买；然后再把父亲请回来讨论那个计划，因为把儿子妖魔化会过早地结束这份病史。场戒断的谈话：吸含四氢大麻酚的电子烟不是“什么也没有”；而在17岁起效动机的风格是事实的与面向未来的（运动与钱及这次胸痛的惊吓及那个不明的添加剂）、不是父母的；份被记录的伤害的减量（“现在就停掉所有这类弹头，尤其是非正规的来源；这是今晚会让我担心的表现”）加上一款戒断的应用，再加两周的复查，胜过那一场一次性的说教。如果血氧或疼痛变差：收住，并带着中毒的或肺的损伤的方案重新问那份暴露的历史——因为这是一种暴露与排除的诊断，而那份暴露要在独处时被取得[[respiratory/asthma-copd]]、[[psychiatry/substance-use]]。**
:::

::: example 那个“不去上学的14岁” {#ex-sr}
一名14岁的女孩，缺课11周；每天早晨躯体的头痛与腹痛，而在被允许留在家里时“到午饭就好了”；没有精神病的病史；而父母已经耗尽，并“只希望医生说这是器质性的，这样学校就不再打电话”。
::: solution
**把拒绝上学当作一个系统的诊断（[[#def-consult]]、[[#def-systems]]）：构思——”症状是真实的；机制是带着躯体的放大的焦虑；而维持的那条回路是早晨的逃脱：症状、缺课、短期的缓解、然后在学校自我效能与朋友的接触上的更长久的坍塌，以及六个月后同一份焦虑的一个更暗的版本。来自父母的那个请求——给他们那个诚实的器质性的回答：没有任何危险的东西在发生；除了这次检查之外不需要检查；而这就是为什么“器质性的”与“焦虑的”是有关于她的身体的同一句话。计划有四个负责人与一张时间表、不是一个希望：分级的回归（第一天：两节课与图书馆；由学校写这份计划并配一位具名的导师；第一周不做集会与走廊的暴露的治疗）；父母的那份早晨的脚本症状在校门口被处理、不是在家的床上；关于睡眠与周末的反转的家庭的工作；以及那带着学校的调整的认知行为的治疗，加上一份每周被追的转诊——因为14周的等待按算术就是一次治疗的失败。绝不能被跳过的筛查：霸凌，包括网上的；一种被功课的难度揭开的学习上的困难；一种以拒绝上学来表现的少数情况，即孤独症；妊娠；自我伤害；以及常常在这个年龄一同到达的那个进食的问题。一个月后的再来就诊就是那个结局的指标；学校的出勤率就是那块计分板；而父母在第一天就需要的那句话是：“你没有辜负她，而让她留在家里正是那件让这一切更糟的事——我们会把她一小块一小块地接回去，从周四开始。[[psychiatry/anxiety-disorders]]、[[clinical-skills/communication]]。**

## 通向何处

急性的陷阱接上[[paediatrics/acute-childhood-illness]]，精神的共病接上[[psychiatry/lifespan-psychiatry]]与[[psychiatry/self-harm-suicide-prevention]]，性的健康接上[[infectious-diseases/sexually-transmitted-infections]]与[[obstetrics-gynaecology/contraception-fertility]]，而保护的那层叠加接上[[paediatrics/safeguarding]]。

::: history
**青少年的医学是最年轻的儿科的亚专科，而它的历史是一部医学终于注意到十几岁的人的史。那个19世纪的观点——童年结束于工厂或账房所需要的任何年龄——缓慢地让位：1870到1900年代的同意年龄与义务教育的斗争，把“青少年”创造为一个法律的身份、随后是一个科学的类别；1904年那部关于青春期的大型著作，为这个新的阶段给出了它那份如今让人难为情的“风暴与压力”的理论；而1920到1930年代儿童指导的门诊，产出了第一批“的问题的少年”的文献——它为三代人把正常病理化了。那次医学的转向来自两个方向：那些不能再把囊性的纤维化与白血病的幸存者在没有中间服务送进成年期的儿科医师；以及1960到1970年代那些可见的流行——妊娠与药物及自杀——它们在对着医院的文化建立了住院的青少年单元；而先驱的病房为过夜的床位与同性的探视，以及住院期间的教育而战斗。关于保密的判例——1985到1986年的那一起著名的案件——从避孕的可及性开始、以儿童的能力的法律告终，是这个语系的专科的建国的文件；而它的指南至今每周都在门诊里被使用。流行病学的贡献是让人谦逊的：大多数心理的疾病在14岁之前就开始；自杀与自我伤害在某些人群里从1980年代稳定地上升；脊柱侧凸的筛查在用对曲线的阈值时成功了、而作为一次通用健康的名目则失败了；而在16岁最大的杀手根本不是疾病，而是碰撞与溺水及过量及自我伤害——这就是为什么这一领域的治疗里包括一条安全带的立法与一个分级驾车的方案及无烟的车内的法律，以及一条上学的时间，胜过任何一张处方。最新的一章——互联网作为发育的环境——还没有被写下：2010年代关于社交媒体与青少年的心境的证据到达时带着争论；管理者转向了设计守则与适龄的设计、而不是临床的共识；而临床医师如今把“你看什么、你和谁说话、手机在什么时候被交出去”当作与饮食的病史同等严肃的事来问——因为没有它，2020年代的门诊已经无法辨认”[[psychiatry/lifespan-psychiatry]]、[[public-health/prevention-promotion]]、[[clinical-skills/communication]]。**
:::

::: summary
- 保密就是干预：早点许诺它；显眼地守住它；与这个年轻人共享信息、而不是绕过他。
- 能力的那一项标准与那几项指南管理着16岁之下的同意；能力是就具体决定而言的、并被记录的，不是一个生日。
- 经典青少年的陷阱——股骨头骨骺的滑脱与睾丸的扭转及卵巢的病理及妊娠及缺铁的月经量多——都会在被父母挡在前面而匆忙完成的病史里被漏掉。
- 肥胖与性别的痛苦及多症状的就诊是门诊的形状的问题：用隐私与构思及一位统筹的临床医师来治疗，绝不要用那台转诊的跑步机。
- 过渡是一个有资金的、有具名负责人的过程；学校要么是一位共同的治疗者、要么是一位共同的应激源，而缺课的数据会告诉你是哪个。
- 按青少年实际体验的方式测量可及性：不需要父母、不需要排队、不需要羞耻。
:::

## 练习

::: exercise 把第一次的青少年的门诊组织好 {level=1}
一名13岁的哮喘的孩子第一次独自来门诊。请列出头三分钟要做的事，以及在这个年龄，最可能改变处理的那四个心理的社会的提问。
::: solution
**那个独处的13岁（[[#def-consult]]）：头三分钟——作为标准，至少有一部分的时间单独见他；用一口气说明保密与它的三个例外；用他自己的话问家里还有谁、以及今天为什么来；以及把吸入器的技术的检查作为那件建立信任的身体的任务交给他。四个提问：吸烟与电子烟（对哮喘而言那个与复发相关的）；大麻（隐蔽的、被污名化的，而这个年龄最常见的非法的暴露）；霸凌与网上的生活（那个会改变出勤与睡眠的）；以及酒精（以事实的方式问：你试过什么、和谁、多久一次）——因为在13岁，这四样比任何吸入器的品牌决定更多的患病率；而一位问过一次的临床医师，之后会被问及所有别的东西[[respiratory/asthma-copd]]、[[psychiatry/substance-use]]。**
:::
:::

::: exercise 处理那个“漏服的药与那次侵犯的提问” {level=2}
一名17岁披露了3个夜晚之前的一次性的侵犯；她在吃复合的避孕药并吐了两次；她“其实还好”，并要求紧急的避孕和不要有戏剧。请处理她的请求与接下来的步骤。
::: solution
**带着自主权的侵犯后的照护（[[#def-consult]]、[[#def-presentations]]）：精确地尊重这两个请求——她是节奏的作者，而你是完整性的主人。尽快提供紧急的避孕：“左炔诺孕酮的窗口是72小时；另一种是120小时、并且在晚的时候更好；而铜的宫内节育器是最有效的，同时也就是那场关于性的健康的安全与未来的避孕的对话；解释与她的常规的那片药的相互作用；并给出清楚妊娠试验的时间。提供、但不要求：”性传播感染的筛查（包括那两种感染的核酸检测）；人类免疫缺陷病毒与肝炎的血液，带着窗口期的解释；以及那暴露后的预防的讨论要在72小时之内诚实地谈，因为它可能仍然相关；无论她说的确定性如何，都提供妊娠选择的咨询。一位自动儿童保护转诊的问题——17岁而被一位“给她买东西”的年长的男性侵犯是一次剥削的模式，保护团队应当在她的知情之下听说它。尊重一个请求与放弃一份职责之间的分别是那句被大声说出的话：“今晚我会完全按你想要的做；而有两件我不会停止做的事：让你远离他，以及在两周之后还在这里。[[obstetrics-gynaecology/contraception-fertility]]、[[paediatrics/safeguarding]]。**
:::
:::

::: exercise 主持那场过渡的规划的会议 {level=2}
一名16岁，有脊柱的裂与神经源性的膀胱及两次的分流，并已订好了学院的名额；而他“完全不知道”明年的转诊由谁来做。请主持这场会议：谁在房间里？结束时他必须能回答的那五个提问？以及必须存在的文件？
::: solution
**场过渡的会议（[[#def-systems]]）：在房间里——他（先说话）；在他的邀请之下的父母；那位统筹的或护士主导过渡的协调者；学校或学院的那位特殊的教育需要的协调者；以及那位全科的护士或具名的全科医师（如果不能到场就用视频）；而泌尿与神外的书面的状态。五个提问：谁给我的导尿管开处方，以及如果在凌晨2点用完了会怎样；谁组织我每年的肾脏的超声与我的分流的检查，以及当我在两小时外的学院时由谁做；成年之后我如何保密地拿到那片药或一间门诊或一张处方；我的那两种危险的情况（泌尿的脓毒症与分流失能）的征象是什么、该去哪一家医院；以及五年之后当我想要避孕或生育的建议或一份妊娠的计划时会发生什么——因为提问就是那份他必须带走病情的摘要。如果任何一位负责人在5点之后不接电话，那么他需要知道——被服务的名字与一个具名的人、不是被转诊，因为那位带着一次感染、没有登记的16岁的就诊，是一场他无法独自导航的门诊。文件：一份由他控制一页纸的健康护照；每家成人的服务的具名工作者的细节；一份带上与麻醉的相关的详情全科的摘要；一份能力的与同意的记录的副本；以及那份学院的支援的计划——以及一个服务拥有那份完整性的检查，可以按名字被审计，因为一场没有人审计的过渡，就是每一次都被预测到的那次收住[[public-health/health-systems-economics]]、[[clinical-skills/records-handover]]。**
:::

::: exercise 设计一个学校心理健康分诊的服务 {level=3}
::: solution
**基于学校的心理的健康的服务（[[#def-systems]]）：设计——在中学与学院里嵌入的临床医师，配先打电话的可及；对被转诊的危机的病例的48小时评估的承诺；为孤独症与创伤的调整而受过训练的、低强度的认知行为的治疗师；一条绕过那条漫长的等候队伍的、直达的升级到危机团队的通路；以及一份急诊联络的方案：每一次自我伤害的就诊在出院之前都得到一位具名的工作者。治理：关于一位学校的咨询师可以做什么、不可以做什么的能力的框架；当风险越过被定义的阈值时的强制转诊的规则；在模型里被提供资金临床的监督；以及用朴素的语言告诉学生们他们的咨询师能保守什么、不能保守什么数据共享的协议——因为一次保密的承诺如果不被解释，就是一次等待被背叛的背叛。两项公平的检验：一个因“行为”而被转诊的孩子得到的评估，与一个为心境自我转诊的那个是一样的；记录住在临床的档案里、与被劝离的程序之间隔着一道防火墙；而转诊的标准向学生与父母公布——因为一个被学校学会用来执行纪律心理健康的服务，将永远不会再被一个14岁的人信任；而能揭穿这一失败的结局的指标，是那个再次就诊的比率[[psychiatry/self-harm-suicide-prevention]]、[[public-health/determinants-inequalities]]。**
:::

::: exercise 做一次青少年的体格检查 {level=1}
::: solution
**青少年的检查（[[#def-presentations]]）：五个不同——生长与青春期的分期要在一位陪同的人在场、并带着解释与一次退出的选择来做；脊柱与姿势（脊柱的侧凸与那只滑脱的髋）；皮肤痤疮的严重度；被袖子遮住自我伤害的疤痕；以及催吐的那种指节的茧；当头痛或某些药物要求时的眼底；以及在每一个不适的男孩、每一个阴囊或腹部的疼痛上的生殖器与睾丸的检查。两个最常改变诊断的：睾丸——扭转与肿瘤，以及那段“它转过又转回来了”的发作的病史，它只有一次检查能确认；以及在大腿与腹部上的皮肤（带着同意与情景来读）——因为自我伤害与催吐的痕迹，是穿着皮肤科的衣服到达的精神病的诊断。而这一切由那三条规则统辖：在触碰之前解释；总是提供一位陪同的人；以及把“你随时可以叫停”大声说出来——这就是青少年能够忍受体格检查的全部原因[[clinical-skills/physical-examination]]、[[paediatrics/safeguarding]]。**

::: exercise 开出第一支吸入器……或者第一支疫苗 {level=1}
一名15岁的吸电子烟哮喘的孩子到了常规的青少年的加强和那一种人乳头状病毒的补种的时候；他问：“这些会影响生育或吸电子烟或我的吸入器吗？”请回答他。
::: solution
**青少年的疫苗与药学的一课（[[#def-consult]]、[[paediatrics/immunisation]]）：按顺序的回答——”疫苗不影响生育；关于这一类疫苗与生育的证据庞大而令人安心，而它们所预防的那个疾病会伤害生育；你的吸入器里没有任何东西会与它们相互作用；电子烟是这个房间里唯一会改变你的哮喘的控制的东西；而这是那一段关于戒烟的论证，它关乎你的运动与你的房租、不关乎你祖父的品德。然后实务：青少年的加强（两种细菌的与那一种脑膜炎的联合的补种及这一年龄的人乳头状的病毒的补种的剂次）；针对针与晕倒的处理（卧位；对那位从未晕过、而现在会知道自己会不会晕的15岁做15分钟的观察）；门诊的那保密的一部分被守住保密（他曾独自问过那一针是否打在手臂上，以及他的母亲会不会拿到记录——在注射之前回答这两个）；以及被记录的共同的决定——因为那位的问题被当作成人一样回答的15岁，正是那个在25岁给自己的未来的孩子接种疫苗、而不用在午夜上网搜索的人[[paediatrics/immunisation]]、[[clinical-skills/communication]]。**

::: exercise 处理那位在凌晨2点“越界”的16岁 {level=2}
一名1型的糖尿病的16岁在凌晨2点带着醉酒到达；酮体6、血糖19；“忘了”两天的胰岛素；而他的父母愤怒，并要求团队“为了他自己好而禁足他”。请写出收住与出院的计划。
::: solution
**糖尿病与伏特加的那次收住（[[#def-consult]]、[[#def-presentations]]）：先医学——“用方案治疗那酮症，不要把它道德化；查那在酒精之后第8到12小时来袭低血糖的延迟，并为了观察而收住——因为酒精加上1型的糖尿病是一个真实延迟低血糖的风险，而“他现在好了”不是那个终点。补液之后的谈话——与他独处：发生了什么；那个模式是什么（这不是遗忘，而是青少年的依从的崩溃经典的形式；而温和地把它命名出来——“今年这糖尿病是谁的？”——本身就是那个干预）；把吸电子烟与胰岛素的相互影响以事实的方式陈述；问那驾驶的与大学的计划；以及那个“什么会让打胰岛素变得容易一点？的清单”。出院的计划：一个当天面对面的糖尿病团队的约；那个护士的电话在一周之内；一份书面生病的日子与酒精的计划；重新配急救的胰高血糖素；在同意之下被通知的学院或学校的护士；因为两次这样的一次发作就是一个模式而提供的心理的转诊；以及一位具名的成年临床医师，拥有接下来的六个月——因为这次收住的审计，是他会不会去赴下一次的门诊；而青少年会去那些没有让他们受辱的服务[[endocrine/diabetes]]、[[psychiatry/lifespan-psychiatry]]。**

::: exercise 设计一套网上安全门诊的方案 {level=3}
::: solution
**图像滥用的方案（[[#def-consult]]、[[#def-systems]]）：即刻的步骤——先单独见这个年轻人；确定谁对谁做了什么、带着什么意图——因为那位“加害者”常常是一位14岁的同学，而那位受害者同时是某个人的那段故事的嫌疑人；在不要求看到那张图像的情况下记录；把你所在地的警方的立场朴素地解释清楚（在当地，制作一个未成年人的不雅的图像在技术上是一项罪，但有一份公布起诉背景的政策与明确的转移的实务——临床医师必须知道本地的现实、而不是那个标题的法律）；把它转诊给真的能移除内容举报的平台（那个网络观察的基金与主要的平台的举报的通路是有效的）。而那句被说给那位已经在哭的青少年听的话是：“这不是你的错；我们有办法把它移除；而我不会给任何一位成年的人除了真的需要它的人出示你的图像。” 一周之后：关于数码的足迹与同意与举报的一次的教育，被放进下一次门诊里，不带说教：”在发送下一张图像之前，要知道三件事：你发送的图像可能活得比那段恋爱更长；你的同意随它同行，你举报它偷窃的权利也是；而如果它有一天泄漏了，我宁愿在第一个小时从你这里听说，而不是在第一个月。“——这是一句能把一场未来的危机变成一次门诊临床的语言[[paediatrics/safeguarding]]、[[clinical-skills/records-handover]]。**
