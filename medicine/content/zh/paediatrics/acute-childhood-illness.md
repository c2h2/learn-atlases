孩子恶化得快、恢复得更快；而“病情往往对父母比对第一位临床医师更明显”。儿童的急性疾病是“对着一小串会杀人的疾病的模式识别”：脓毒症与脑膜炎的球菌的疾病与毛细支气管炎及哮喘及胃肠的炎造成的脱水，以及惊厥与发热及不褪色的皮疹。

## 识别生病的孩子

::: definition 评估与那些会杀人的综合征 {#def-assess}
**急性不适的孩子在最初的那一分钟里要被“从头读到脚”。“看这个孩子的顺序：被作为儿科的高级生命支持教授的”从A到E加葡萄糖儿科评估的方法；那条纪律：“在任何数字之前，先看清醒的程度与灌注及呼吸的工作量”；“发热孩子红绿灯的那套系统与那条元规则：你越担心，就越要往上报”；“一个坐着、身体前倾呈三脚架、或一个词一个词地说话的孩子，按定义就是严重的；而不发热且血氧正常时呼吸的急促仍是一个临床的问题”；“那个令人安心的睡着的孩子会为奶而醒、并能处理空气“呼吸、睡眠、喂养”对“那个能安抚却叫不醒的孩子——这一分别是整个儿科学在一双眼睛里的全部；”父母带着那条连续的监测线：他们不是安全网的一部分，而是观察的团队的一部分；而“如果有什么不一样，你最知道”这一句既是善意、也是医学”；“退烧是因为它让人难受、不是因为它危险；不要用凉的湿布去追那个数字；也不要把本来就要出来的皮疹怪到退烧药身上“。脓毒症与脑膜炎的球菌这一块：”新生儿与3个月之下的规则占主导；句格言：“小的发热婴儿需要的是一位临床医师、不是一款应用；”转诊的阈值，以及鲜红的、压之不褪色的、伴皮肤坏死的皮疹，在血液的培养证明别的之前就是脑膜炎的球菌；而那句”它在玻璃杯下褪色了，所以我就回家了——是一起会得到一份报告的死亡；玻璃杯试验的民间说法带着真实的限度因为早期的皮疹会褪色；“灰白的、花斑的、肢端发绀伴毛细血管再充盈的时间延长在寒冷的房间里超过5秒——不是一个可选的指标；”脑膜炎的病的不典型的征象颈部僵硬在后期的孩子里、怕光与拒绝被抱起及一种不安的、被安抚不了的哭声；“休克的数字：血压是一个晚的指标；”立即的治疗：氧与液体的一次的推注及抗生素与转运——不要为了等培养而等抗生素、也不要为了等影像而等抗生素；“流行性脑炎与脑膜炎的差别靠临床与脑脊液及有时靠聚合酶。呼吸系统这一块：”“胸壁的凹陷与呻吟及鼻翼的扇动与呼吸的急促按年龄的阈值；”毛细支气管炎的季与早产的与先心的人群及单克隆的抗体的预防；“喘息孩子哮喘的张面孔病毒诱发的与运动诱发的及夜间症状与家族史；”哮喘持续与镁及肾上腺素能的持续给药及激素在第一次就诊时给。那些不典型的杀手：“葡萄球菌烫伤样的综合征与川崎的病那些不完整的病例；”噬血细胞的疾病；“菌血症在疫苗的时代更罕见，而支原体的与流感及新冠及合胞的病毒及腺的及肠的病毒各有各年份的流行病学；”一个反复以病毒的喘息就诊的孩子，需要一次认真的哮喘与囊性的纤维化及原发的纤毛的运动的功能的障碍及免疫与吞咽及反流及气道与结构的提问——而不是第六张支气管扩张剂的记录表；“一个不断地回来的孩子就是多回来的那一个孩子——把就诊本身当作一个症状；以及”一对自身正处于危机中的父母带来的孩子，到达时是一个病人这一心理的社会的急性的医学——因为当父母应付不了时，同一个发热在同一个孩子身上就是另一个诊断；而当孩子不能独自被留在家里时，同样的呕吐就是另一种疾病“[[emergency-critical-care/acute-assessment]]、[[paediatrics/safeguarding]]、[[respiratory/asthma-copd]]、[[paediatrics/newborn]]。**

## 发热、惊厥与皮疹

::: definition 幼儿发热与热性的惊厥及皮疹 {#def-fever}
**三个最常见的“我为什么在这里”的就诊。3个月之下的发热：“91天之下对91到364天对3到5岁的规则；以及那几层：”完整脓毒症的筛查并收住对谨慎的观察对带着随访的门诊”；“婴儿会脱水、会恶化、会把病情藏起来这三重；“在只是有点烦躁的小婴儿身上查脐部与关节及眼睛及尿”；“单纯疱疹的脑炎以嗜睡来表现，所以要早用阿昔洛韦——因为先做计算机断层、再做聚合酶、一天就来不及了”这一经验性抗病毒的规则；以及”例以对治疗的脓毒症加喂奶后哭闹来表现先天性代谢的缺陷，伴高阴离子的间隙与酮体——当那个婴儿本来是完好的时候，就要想到代谢的缺陷这条旗子；以及“未行环切的男婴的尿路感染被过度诊断，而真正的尿路感染需要导尿或中段尿——集尿袋的尿只能用来排除”这一细菌学的工艺。热性的惊厥：“6个月到5岁，全面性的强直阵挛、15分钟之下、发作后嗜睡并恢复就是单纯的；而影像与脑电不属于单纯的热性的惊厥这一过度的检查的改革；复杂的特点超过15分钟的时长或局灶的或发作后的缺陷或在24小时内的复发要求收住，并考虑中枢的感染与癫痫的预测；“在家抽搐的救援：米达唑仑颊部的对直肠的对鼻内的，并教父母看时钟与何时叫急救——而不是一遍遍地加地西泮；”复发的风险约30%，而癫痫的风险从1%起、在复杂的特点下升到几个百分点——但父母需要一个被反复重复简单的版本“。以及那个被过度治疗的鉴别：”发热的感染加局灶的惊厥加神经的症状——要考虑脑炎与脓毒症。那个“不断地回来的孩子”的透镜：“一个冬天里四次到急诊就是一个诊断；而当这个孩子在病房里好起来时，那个”为什么“会自己问出来；社会性的收住不是一种羞耻——它是关于剥夺与住房及父母的健康的一条线索；”成长停滞加不就诊加反复损伤的重叠，因为急性的医学与儿童的保护共享一条边界；以及那个在最便宜的沙发上、暖气关着的孩子更可能有被呼吸的暂停弄复杂的毛细支气管炎、而更不可能回来做那次复查——这一公平的医学。这就是为什么出院的记录必须清晰可读、必须有翻译的版本，而随访必须是一次被预约的门诊、不是一个希望”[[paediatrics/safeguarding]]、[[infectious-diseases/tropical-infections]]、[[paediatrics/newborn]]。**

## 系统与综合征

::: definition 儿科急性医学的综合征 {#def-syndromes}
**在发热之外，病房是按综合征收住的：软的、肿的、苍白的、浮肿的、疼痛的孩子。“肌张力低与无力的鉴别：那个只是软软的婴儿——脊性的肌的萎缩与肉毒的中毒及重症的肌无力及脓毒症；而对一个3个月还抬不起头的孩子，不要等一间遗传的门诊；而“脊性的肌的萎缩如今有基因的疗法，而症状前的新生儿的筛查让”等等看“成为一种过失”这一时代医学。”伴发热的肿而痛的关节，在被抽出液体之前就是脓毒性的关节炎；而暂时性的滑膜炎与莱姆的及白血病及结核的名称及那枚不肯弯曲的髋；以及“完全不肯走的孩子不同于走得疼痛的孩子这一分级。”浮肿的面部与深的尿——肾炎的综合征与那一种紫癜的方案；称体重并监测血压，而不是“只是一次的尿路感染”。“花斑的、苍白、心跳快的孩子伴吃土的历史——铅。”突然的苍白与瘀点——在遗传性球形的红细胞情况下再生的障碍，以及小病毒的 B19 与遗传性的大红细胞的情况及白血病都以此表现这一血液的急症的分诊。“发红耳朵伴面的麻痹是莱姆的；而”伴头痛与呕吐的红眼要看眼底、不能记成病毒的结膜炎——因为视盘的积水以偏头痛来表现；而“一个会被头痛叫醒并在空腹时呕吐且越来越频繁的孩子是今天就做磁共振这一脑的肿瘤的危险信号——因为”孩子不会得脑的肿瘤正是那句延误它们的话，而不是每一个头痛都是肿瘤正是让磁共振保持诚实的那句话。腹部的与肾的模仿者：“继发性的夜间排尿多尿与体重的下降，在血糖说别的之前就是糖尿病；”脑膜刺激征伴不正常的玻璃杯的试验“；”一个不会说话的孩子的肠的梗阻以阵发的哭闹加蜷腿来表现；以及“尿路感染伴高热的幼儿要想到肾的盂的肾炎。那些不会被说出口的人群：”一个残疾婴儿的恶化伴损伤的模式不相符，或反复的胃肠的，或“那位父母比孩子还平静”——这是放射学与保护，不是运气；而“有神经发育障碍的孩子也会得阑尾的炎，而以”就是不太对“来表现；”有残疾孩子的父母是最好的病史的讲述者，他们值得被问一句“什么会让你带她来？”这一诊断的谦逊。以及那句对来得太勤的父母与那位说“我觉得自己来很傻”的家长都要给的话——“你来是对的——因为这句话能防止一场凌晨四点的死亡，而且是免费的实践；以及”这个孩子是一整个系统：儿童的健康与教育及保护；而只看发热的儿科医师有一半的时候会漏掉诊断这一系统的医学“[[emergency-critical-care/acute-assessment]]、[[renal/urinary-tract]]、[[gastrointestinal/bowel-disease]]、[[paediatrics/safeguarding]]。**

::: example 那个“能安抚而嗜睡的6周的孩子” {#ex-youngfever}
一名6周的孩子，昨天吃奶还好，今天“安安静静、嗜睡”；体温36.2，心率190，花斑，毛细血管的再充盈5秒，呼吸的频率70；而母亲说“他就是感觉不一样”。
::: solution
**“在一个花斑婴儿身上的新生儿脓毒的生理”（[[#def-assess]]、[[paediatrics/newborn]]、[[emergency-critical-care/shock-fluids]]）：识别——“低体温可以是脓毒症；而在一个6周的孩子身上，”能安抚而嗜睡“是失代偿的语言；那位说”不一样“的母亲是这栋楼里最灵敏的仪器；这个孩子处于休克，无论有没有皮疹；以及”盏灯是红的，因为它是这么规定的、不是因为温度计同意“。第一个小时——气道与呼吸：给氧；如果对液体在失败，不要用”看看输完液之后“来延误插管；按体重两次的10毫升平衡晶体的推注，每一次之后重新评估；”对液体耐受不了的休克要早期用肾上腺素、而不是第四次的推注这一接近儿科重症的做法；”需要在60秒之内建立静脉或骨髓的通路、而不是六次的尝试这一通路的现实；血培养与血细胞计数及急性的反应蛋白及乳酸及血气及葡萄糖；在休克期间不做腰穿，在抗生素之前也不做；“按本地的方案给经验性的青霉素或头孢，并在这个年龄考虑加上阿昔洛韦；以及”一克的退烧药不是这个病的治疗。然后那个家庭——你有激素或用的心脏的病吗？他被筛查过什么吗？家里有什么我们要知道的吗？被问家长的问题；每小时的葡萄糖，并考虑肾上腺的与代谢的若要给激素，先留皮质醇的标本；在“对治疗的脓毒症”之后，以及那个出生筛查的复核——因为这是那个代谢病来的时刻；以及婴儿是婴儿、是一个家庭：喂养与联结及母亲自身的疾病及保护不是指控；以及那一句“我很抱歉，你的病得很重”，配一位具名的医师、一位具名的护士、和一个能在旁边睡觉的地方这一以家庭为中心的重症；以及那次“他为什么昨天没有被看到？”的复盘：它不是指责，但它就是今天的内容——因为他曾以“只是有点烦躁”就诊过；用她的原话记录下那个“不一样”意味着什么——因为那一句话同时是证据、是历史、也是医学[[clinical-skills/patient-safety]]、[[endocrine/endocrine-emergencies]]。**

::: example 场“从来不是哮喘的喘息” {#ex-wheeze}
一名3岁，“今年四次病毒的喘息，用沙丁胺醇、有时用激素，没有预防的药”;今晚：安静、口周的发绀、呼吸的频率58、空气中血氧88、不发热；记录上生长正常、没有湿疹；而父母整小时都在用雾化器。
::: solution
**“在最糟糕的那一刻重新思考学龄前的喘息”（[[#def-syndromes]]、[[respiratory/asthma-copd]]）：先治今晚——“急性哮喘支气管的痉挛，而不是病毒的标签——这些都不如氧重要：连续沙丁胺醇的雾化与异丙托溴铵及泼尼松龙；而”不能说话、安静的胸部、发绀，就是重症；现在是问重症监护的问题、不是下一次发作之后这一升级；“威胁生命时用静脉的硫酸镁；以及”当雾化的输送在失败时用肌注的肾上腺素——因为一个哭闹的孩子什么都吸不进去这一实际的治法；以及那条规则：“不要把一个正在每小时用雾化的孩子留给一个只看过两次的资深者以外的人”。然后是明天的重新思考——“一年四次的喘息需要一份计划；而”除了他来的时候，我一直在管理得很好“是一次服务的失败、不是父母的失败；学龄前哮喘预测的特点——湿疹与血的嗜酸性的细胞及父母的过敏及不伴感冒的喘息；而那个”其实是被误贴标签哮喘病毒诱发的喘息，要靠一次规律吸入激素的试验、然后停药来验证而被找到；“这周需要每小时的沙丁胺醇的3岁，走的是升级并复查的那条路径、不是”只是一次感冒“，无论它被贴了哪个标签；以及”那个完全没有响应的孩子不是哮喘——是异物的与结构的及心脏的；以及“伴成长停滞的喘息意味着囊性的纤维化与原发的纤毛的运动的功能的障碍及免疫的缺陷。然后那份计划——”环境的历史烟草与霉菌及宠物；一次对预防的用药的依从的谈话——见过四次“最后的办法”的父母不会信任那只黄色的吸入器；以及那句真正能减少收住的问题：“家里有吸烟的人吗？；以及学校与托幼需要一份，这样”他开始时他们没能给他“就到此为止；以及48小时一次电话的随访能防住一半再来的就诊这一证据；以及那位说我觉得很自责的父母会听到这句话——你一直在独自做急性的医学，而今晚它结束了——因为这是真的，而它能打开那场接下来八个月所依赖的依从的谈话[[public-health/determinants-inequalities]]、[[respiratory/asthma-copd]]。**

::: example 那个“只是焦虑的14岁” {#ex-teen}
一名14岁的女孩，六周内四次因恐慌的发作到急诊——心悸与麻刺感及发晕；今天她苍白、坐位的心率130、血压正常、血氧正常、葡萄糖4.6；而学校说她体重下降了，并在课上睡觉。

**“那个被告知这是焦虑的少年”（[[#def-assess]]、[[paediatrics/adolescent-health]]）：生理的搜寻——”青少年的心跳快与疲劳及体重的下降，在被排除之前不是一项排除的诊断；那类的体位的过度综合征与铁的贫血及乳糜泻及甲状腺及肾上腺的功能不全各有各的线索；“一个以焦虑来表现少年里的糖尿病——而没有人问过尿多这回事；带真正计时表体位的观察；而”晕厥伴心悸要今天做一张心电图——因为长的Q-T与预激的不会以“只是恐慌”来表现；若是发作性的则做霍尔特的与事件的记录器；超声心动与肾上腺的功能及乳糜泻的血清学；以及月经的与节食的病史要在只有她一个人在场时被问这一必要的保密的问诊。同时存在的两个诊断——“恐慌的疾病是真实的、常见的，并被身体的过度换气所触发，而症状不是装出来的；而这个诊断是两个都有、不是二选一；那个安心的说法是恐慌是可以被治疗的、而不是什么也没发生“这一框定；”呼吸的再训练与认知行为的治疗的转诊及学校的联系，以及分级的回到活动这一康复、而不是回避活动这一有证据的做法；以及那个对麻刺感过度换气碱中毒医学的解释——它能止住“我是不是要死了”的那个问题。以及那条界线：“如果体重在下降，就不是单纯的焦虑；而被诊断为焦虑的、而从未被独自问诊过的孩子，是后来带着糖尿病酮症回来的孩子”[[paediatrics/adolescent-health]]、[[cardiovascular/arrhythmias]]、[[psychiatry/anxiety-disorders]]。**

## 通向何处

幼龄发热的路径从出生就开始在[[paediatrics/newborn]]，保护的叠加在[[paediatrics/safeguarding]]，那些可被预防的疾病的接种在[[paediatrics/immunisation]]，呼吸慢性的照护在[[respiratory/asthma-copd]]，而严重的感染的神经发育的后果在[[paediatrics/neurodevelopment]]。

::: history
**急性的儿科学是一部“认真对待孩子的发热”的史：18与19世纪生病的儿童医院——1756年的为贫困的孩子的学校，以及1852年与1861年的伦敦与爱丁堡及都柏林的儿童医院；以及孩子不是缩小的成人这场反对儿童的普通的病区长期的斗争。然后是那会杀人的疾病的时代被逐个关掉：白喉与百日咳及麻疹的这两剂的方案，以及那三种联合的疫苗；然后是新的那批：”脑膜炎球菌的C与那一种B及肺炎的球菌的结合的与那一型的；每一次的引入都先改写了那张鉴别表。重症的那一层：儿科的高级生命支持的课程与儿童早期预警的评分把成人的数字硬套到孩子身上的时代关掉了；儿科转运的服务与被受训的重症的队伍——它们把死亡率的那次下降搬到了从病房到这段路上。模仿者的章节仍在被重写：“那种曾经靠一张贴纸诊断脓毒的关节炎；以及那次新冠时代多系统炎症的综合征——它的名字有误导性，而这个多系统炎症的综合征重新把心脏病学与风湿病学聚到了一起；以及那个”看起来挺好发热的谨慎这一2020年代的教训。因为每一代人都会重新学会：同一个发热既可能是这十年的那个疾病、也可能只是糟糕的一周；而唯一的防守是被结构化的谦逊“[[paediatrics/immunisation]]、[[public-health/determinants-inequalities]]、[[clinical-skills/patient-safety]]。**
:::

::: summary
- 在数字之前先看这个孩子：呼吸的工作量与灌注及清醒的程度，以及父母那句“不一样”，在任何实验室的数值之前决定了升级。
- 3个月之下的发热遵循严格的规则；低体温就是脓毒症；而“能安抚而嗜睡是恶化的语言”。
- 褪色的皮疹或低的急性的反应蛋白永远不排除早发脑膜炎球菌的疾病；轨迹加上重新检查加上一张写下来的安全网才是标准。
- 单纯热性的惊厥不需要影像、也不需要抗惊厥的药；而复杂的特点或脑膜的刺激征会完全改变那条路径。
- 反复的”病毒的喘息要求一次认真鉴别的复查；而对支气管的扩张剂没有响应的孩子得的不是哮喘。
- 反复的就诊本身就是一个症状——关于疾病、关于剥夺、或关于危险；而每一次出院都需要清晰可读的、有翻译的、被预约的随访。
:::

**一个未分化的发热的第1小时（[[#def-fever]]、[[clinical-skills/clinical-reasoning]]）：给她的回答——在24小时的时候没有人能说出它的名字；我会告诉你那个诚实的、最可能的病毒的答案；我们今天排除了什么；接下来我们要看什么；以及“今晚你为我做的那一件事”（看呼吸与液体；而那个皮疹的试验要被解释为一道筛查、不是一张通行证）——这一被结构化的诚实，是父母真正会记住的；而那个麻疹的问题被用接种的病史与暴露来回答：如果我怀疑它，我们会检测、会隔离、会告诉你——而不是希望你们没有注意到这一透明。计划——系列的检查胜过系列的抽血；把皮疹用手电筒与日期拍下来这一由患者持有的记录；尿在排出的或导尿的标本中筛查、不是用集尿袋来确诊这一工艺；急性的反应蛋白在第12小时或随着重新评估来查、不是把第1小时当作神谕；以及一条被写下来的安全网（什么时候回来，以及回来看谁）；以及被预约的24小时的电话或门诊——因为一句“如果再看一下会不一样”是这条路径上最便宜的安全[[clinical-skills/clinical-reasoning]]、[[emergency-critical-care/acute-assessment]]、[[clinical-skills/communication]]。**

::: exercise 审计“冬天的收住” {level=3}
::: solution
**冬天的流的审计（[[#def-assess]]、[[public-health/health-systems-economics]]、[[clinical-skills/records-handover]]）：数据——先看病例的组合：有多少是真正的严重、有多少是社会的收住；谁在几点来、来自哪个剥夺的分位；被给了支气管的扩张剂或激素或抗生素的毛细支气管炎的孩子们这一过度的治疗的审计；到第一次喂养评估的时间，以及“鼻腔的吸引是否真的被教给了父母”这一照护的一束对仪式；以及把再次就诊的记录逐行读一遍，找“什么本可以防住这一件”——这是唯一严肃审计的方法。干预——日间收住的单元与治疗并转给社区的护理；把吸引与喂养的基本教给父母并用“回教一遍”来确认；以及出院的标准写成“三次好的喂奶并呼吸舒适”、而不是“离开了氧气多少小时”这一目标的设定；以及在高峰的季节的先打电话的分诊，配合明确的谁可以在家的标准；以及那个儿科的床位的管理者与一所为那些不需要病房孩子准备的、医院之外的单元——因为冬天的危机一半是病例的组合的问题、而不只是容量的问题。一项文化的工作：让“我不确定”成为一个合法的句子——因为一个不敢说不确定的服务，会把它的不确定变成一次出院[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]。**

## 继续深入

有两件收尾的习惯，把出色的急性的照护的儿科医师与够用的那位区分开。第一是被刻意的不确定性的管理：当一个发热小婴儿的轨迹不清楚时，把那份不确定大声地说出来；说明如果它朝每一个方向解决，你会怎么做；设定复查的时间；并把这份怀疑作为一条信息交班出去——而不是把它抹平。恶化这一文献的一致的发现是：延误跟随的是那些没有人被允许怀疑的决定，而不是错了的决定。第二是发育的情景的意识：每一次收住都是对成长的一次打断，所以急性的儿科医师会在静脉的通路还在的时候问起学校与喂养及活动的能力及家里的那个同胞——因为把一个孩子放回一个停滞环境的出院，只是在下一次收住的预约。这两件习惯除了谈话之外什么都不花费，而它们在每一项实验室的结果上都是看不见的。
