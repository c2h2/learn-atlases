大多数急性患病的儿童患的是自限性病毒感染。少数患有严重细菌感染、外科问题或代谢急症，而这些儿童在早期可能看起来出奇地好。急性儿科的技能在于快速而安全地区分这两类儿童，在诊断明确之前就治疗病重的儿童，并让状况良好的儿童回家，同时清楚交代需要注意什么。

本章讲授患病儿童的结构化评估、发热的处理思路、常见的呼吸系统和胃肠道疾病，以及液体量的计算。内容遵循英国实践：NICE关于5岁以下儿童发热（NG143）、16岁以下疑似脓毒症（NG254）、毛细支气管炎（NG9）、腹泻和呕吐（CG84）以及静脉补液（NG29）的指南。文中提到的剂量仅为示意；实际处方依据《英国儿童国家处方集》（BNF for Children）和当地指南。

## 识别患病儿童

儿童不是缩小的成人，这些差异在急症中至关重要。他们的气道狭窄，因此轻微肿胀就会使阻力大幅上升。他们代谢率高、糖原储备少，因此很快发生低血糖。他们的正常心率和呼吸频率更快，正常范围随年龄变化。

| 年龄 | 呼吸频率（次/分） | 心率（次/分） |
|---|---|---|
| 1岁以下 | 30–40 | 110–160 |
| 1–2岁 | 25–35 | 100–150 |
| 2–5岁 | 25–30 | 95–140 |
| 5–12岁 | 20–25 | 80–120 |
| 12岁以上 | 15–20 | 60–100 |

这些范围依据高级儿科生命支持（APLS）课程所教授的数值。睡眠中的儿童数值较低，哭闹、受惊或发热的儿童数值较高，因此应在儿童安静时重复测量生命体征。

::: definition 结构化评估与早期预警评分 {#def-assess}
**ABCDE评估**按对生命威胁的先后顺序检查和处理问题：**A**气道、**B**呼吸、**C**循环、**D**神经功能障碍（意识水平、瞳孔、姿势和血糖）以及**E**暴露（皮疹、体温、损伤）。在每一步发现的问题都要先处理再进入下一步。

**儿科早期预警评分（PEWS）**把常规生命体征转化为一个分数，分数上升时触发评估。英格兰已引入全国性的PEWS（全系统儿科观察追踪，即SPOT项目），配有按年龄区分的观察记录表，并可记录家长和护士的担忧。

**AVPU量表**用于快速评估意识水平：**A**清醒、**V**对声音有反应、**P**对疼痛有反应、**U**无反应。只对疼痛有反应或更差的儿童，格拉斯哥昏迷评分约为8分或以下，可能无法保护自己的气道。
:::

::: theorem 儿童在休克中直到晚期才出现血压下降 {#thm-compensation}
在休克的儿童中，心动过速、毛细血管再充盈时间延长、肢端发凉和尿量减少出现得早，而血压直到晚期都保持正常。儿童出现低血压是失代偿性休克的征象，是濒死前的表现。
:::

::: proof
血压等于心输出量乘以体循环血管阻力，心输出量等于心率乘以每搏输出量。循环血量下降时，交感神经系统使心率加快、外周血管收缩。儿童血管健康，交感反应强，因此即使丢失大量血容量，血管收缩也能维持血压稳定。代价表现在其他方面：皮肤发凉、出现花斑，毛细血管再充盈缓慢，肾脏产生的尿液减少，脑灌注也可能下降，使儿童烦躁或嗜睡。只有当这些机制耗竭时血压才会下降，而此时儿童已接近心搏骤停。儿童增加每搏输出量的能力也有限，因此依赖心率；患病儿童心率下降（心动过缓）是一个不祥的征象，常由缺氧引起。
:::

### 估计体重

药物剂量和液体量取决于体重。只要可能就应给儿童称重。在急症中无法称重时，可以用APLS课程所教授的公式按年龄估计体重：

- 0–12个月：体重（kg）$= 0.5 \times \text{月龄} + 4$
- 1–5岁：体重（kg）$= 2 \times \text{年龄（岁）} + 8$
- 6–12岁：体重（kg）$= 3 \times \text{年龄（岁）} + 7$

这些只是估计值。按身长估算的软尺或家长对近期体重的了解往往更好，应尽快为儿童称重。

## 发热

::: definition 发热与NICE交通信号灯系统 {#def-fever}
儿童**发热**是指体温38 °C或以上。4周以下婴儿用电子体温计测腋温；4周至5岁儿童可用电子或化学点式体温计测腋温，或用红外鼓膜体温计。

NICE指南NG143把临床特征分为**交通信号灯系统**，用于估计5岁以下发热儿童患严重疾病的风险：

- **红色（高风险）**特征包括：面色苍白、花斑、灰白或青紫；对社交提示无反应，在医务人员看来病容明显，叫不醒或醒后不能保持清醒，哭声微弱、尖调或持续不止；呻吟，呼吸频率超过60次/分，或中重度胸壁凹陷；皮肤弹性下降；**3个月以下**婴儿体温38 °C或以上；不褪色皮疹；前囟膨隆、颈项强直、癫痫持续状态或局灶性神经体征。
- **琥珀色（中等风险）**特征包括：家长诉面色苍白；反应不正常或活动减少；鼻翼扇动、呼吸急促或空气中血氧饱和度95%或以下；心动过速、黏膜干燥、婴儿喂养差、毛细血管再充盈时间3秒或以上、尿量减少；**3–6个月**体温39 °C或以上；发热**5天或以上**；寒战；肢体或关节肿胀。
- **绿色（低风险）**指没有任何琥珀色或红色特征。

**热性惊厥**是指6个月至5岁儿童伴发热的惊厥，无中枢神经系统感染，且既往无无热惊厥。**单纯型**热性惊厥为全面性发作，持续不到15分钟，24小时内不复发。**复杂型**热性惊厥为局灶性、持续时间长或反复发作。
:::

交通信号灯指导行动。有任何红色特征的儿童需要由儿科专科医生紧急面诊。有琥珀色特征的儿童需要评估或明确的安全保障措施。只有绿色特征的儿童通常可以在家处理并给予建议。

发热本身并不危险，降低体温也不能预防热性惊厥。退热药（对乙酰氨基酚或布洛芬）是为了缓解不适，而不是为了使体温恢复正常。应告诉家长哪些特征意味着应再次就医：不褪色皮疹、孩子难以唤醒、呼吸困难、脱水征象、发热持续5天或以上，或仅仅是他们比之前更担心了。

需要特别牢记的病因：

- **脑膜炎球菌病**可在数小时内致死。发热儿童出现不褪色皮疹，在被证明不是之前，应视为脑膜炎球菌败血症。在社区，只要不延误转运，应在转运前肌内或静脉注射一剂苄青霉素。
- **尿路感染**是婴儿最常见的严重细菌感染，常无定位体征。任何不明原因发热的婴儿都应检测尿液标本。
- 发热持续5天或以上时应考虑**川崎病**。其特征是发热伴结膜充血、口唇和口腔改变、皮疹、手足改变以及颈部淋巴结肿大。早期静脉注射免疫球蛋白可降低冠状动脉瘤的风险。

::: example 体温升高的6周婴儿 {#ex-youngfever}
扎伊纳布（Zainab）6周龄。母亲带她来急诊科，因为她摸起来发烫，今天吃奶减少。她的体温38.3 °C，心率175次/分，呼吸50次/分。她清醒，哭声正常，肤色正常，无皮疹。
::: solution
**第1步：交通信号灯。**3个月以下婴儿体温38 °C或以上是**红色**特征，无论婴儿看起来多好。小婴儿在严重感染早期很少表现出征象，而且免疫系统不成熟。

**第2步：可能是什么？**尿路感染、菌血症（B族链球菌、*大肠埃希菌*）、脑膜炎，以及包括肠道病毒和流感在内的病毒感染。出生后最初几周还要考虑单纯疱疹病毒。

**第3步：检查。**NG143建议3个月以下发热婴儿做全血细胞计数、血培养、C反应蛋白和尿液检查。1个月以下的婴儿，以及1–3个月看起来病重或白细胞计数低于$5$或高于$15 \times 10^9$/L的婴儿，还应做**腰椎穿刺**。英国许多医疗单位对有任何令人担忧发现的3个月以下发热婴儿都遵循这一规则。

**第4步：治疗。**如果扎伊纳布病重，或检查提示细菌感染，她需要立即静脉使用抗生素。NG143推荐第三代头孢菌素，3个月以下婴儿加用对*李斯特菌*有效的抗生素（如阿莫西林）。剂量依据《英国儿童国家处方集》。

**第5步：观察。**即使最初的检查结果令人放心，这个年龄的发热婴儿通常也要在医院观察，直到培养结果出来。
:::
:::

## 呼吸问题

呼吸道感染是儿童冬季住院最常见的原因。

### 毛细支气管炎

**毛细支气管炎**是婴儿小气道的病毒感染，最常由呼吸道合胞病毒（RSV）引起。起病时流涕、咳嗽，数天内发展为呼吸急促，伴湿啰音，有时伴哮鸣音。症状通常在第3–5天最重，咳嗽可持续长达3周。

处理以支持治疗为主。NICE NG9建议：

- 6周龄及以上儿童血氧饱和度持续低于90%，或6周以下婴儿及有基础疾病的儿童持续低于92%时，给予吸氧。
- 婴儿经口摄入不足时经鼻胃管补充液体。
- **不要**使用沙丁胺醇、肾上腺素、糖皮质激素、抗生素或高渗盐水。试验未显示这些治疗有益。
- 出现呼吸暂停、严重呼吸窘迫（呻吟、明显凹陷或呼吸频率超过70次/分）、中心性青紫或血氧饱和度持续偏低时紧急转诊。

3个月以下婴儿、早产儿以及患先天性心脏病、慢性肺病或免疫缺陷的儿童发生重症的风险更高。孕期接种RSV疫苗（见[[paediatrics/immunisation]]）可保护小婴儿。

::: example 是毛细支气管炎还是别的？ {#ex-wheeze}
汤姆（Tom）4个月。他感冒咳嗽三天，今天呼吸急促，吃奶量只有平时的一半。体温37.9 °C，呼吸58次/分，心率160次/分，空气中血氧饱和度91%。他有肋下凹陷，双肺弥漫细湿啰音。
::: solution
**诊断。**冬季婴儿在卡他症状后出现呼吸急促、凹陷和弥漫细湿啰音，是**毛细支气管炎**的典型表现。

**严重程度。**他的血氧饱和度91%高于其年龄的吸氧阈值90%，因此暂不需要吸氧。但他只吃了一半的奶，这是收住院的理由：NG9建议当摄入量低于平时的50–75%时考虑收住院。他的呼吸频率高，但低于70次/分。

**计划。**收住院观察并支持喂养，如不能吃够则经鼻胃管喂养。血氧饱和度持续低于90%时给予吸氧。不用支气管扩张剂、糖皮质激素或抗生素。注意呼吸暂停和疲劳。向父母解释他很可能在好转之前还会加重一两天。

**会改变判断的红旗征。**高热（超过39 °C）或局灶性胸部体征提示肺炎。心脏杂音、肝脏肿大或心率极快提示先天性心脏病所致心力衰竭，后者可能被误认为毛细支气管炎。
:::
:::

### 哮吼

**哮吼**（喉气管支气管炎）是一种病毒感染，通常由副流感病毒引起，导致声门下肿胀。典型患者为6个月至3岁儿童。其特征是犬吠样咳嗽、声音嘶哑和**喉喘鸣**，即吸气时粗糙的声音，常在夜间加重。

大多数哮吼是轻度的。口服一剂**地塞米松**可减轻症状、减少住院需要，适用于任何严重程度的哮吼儿童。重度哮吼表现为静息时喉喘鸣、明显凹陷、烦躁或嗜睡，雾化吸入**肾上腺素**可在糖皮质激素起效前暂时缓解，并需要上级医生的帮助。

有喉喘鸣的儿童不应用压舌板检查咽喉，应让其安静地坐在家长腿上。**会厌炎**和**细菌性气管炎**少见但更危险：一个中毒貌、流涎、不能吞咽并前倾坐位的儿童需要麻醉医师和耳鼻喉外科医生，而不是口腔检查。自Hib疫苗接种以来，会厌炎已很罕见。吸入**异物**是幼儿突发喉喘鸣的一个重要的替代原因。

### 哮喘和肺炎

急性哮喘根据儿童的说话能力、呼吸频率、辅助呼吸肌的使用、血氧饱和度以及年长儿童的峰流速进行评估。治疗遵循英国胸科学会、SIGN和NICE的指南，使用经储雾罐吸入的沙丁胺醇、口服糖皮质激素，严重发作时在医院给予氧疗及进一步治疗。发热、呼吸急促和局灶性体征提示**肺炎**；幼儿最常见的细菌病原体是*肺炎链球菌*，阿莫西林是常用的一线口服抗生素。

## 呕吐、腹泻与补液

::: definition 脱水、休克与维持液 {#def-syndromes}
**临床脱水**是体内水分丢失，表现为反应改变、眼窝凹陷、黏膜干燥、心动过速、呼吸急促和皮肤弹性下降等特征。**临床休克**在此基础上还有灌注不良的征象：皮肤苍白或花斑、四肢冰冷、毛细血管再充盈时间延长、外周脉搏微弱、意识水平下降，晚期出现低血压。

**维持液**是儿童每天补充正常丢失所需的液量。用**Holliday–Segar公式**计算：体重的前10 kg每千克100 mL/d，接下来的10 kg每千克50 mL/d，超过20 kg的部分每千克20 mL/d。
:::

::: widget plot
f: if(x <= 10, 100x, if(x <= 20, 1000 + 50(x - 10), 1500 + 20(x - 20)))
x: 0, 60
y: 0, 2500
points: 10, 1000; 20, 1500
labels: \text{维持液量（mL/d）}
caption: 每日维持液的Holliday–Segar公式。斜率在10 kg和20 kg处下降，因为随着儿童长大，每千克代谢率下降。医院常把体型接近成人的儿童的液量上限定为每天2–2.5升，并在抗利尿激素分泌可能增加时限制液量。
:::

**胃肠炎**是呕吐和腹泻最常见的原因，通常由诺如病毒等病毒引起（自疫苗接种以来轮状病毒已少见得多）。呕吐通常在3天内停止，腹泻在7天内停止。

大多数胃肠炎儿童可以在家处理，少量多次饮水并继续母乳喂养。有临床脱水的儿童用**口服补液盐（ORS）**补液：NICE CG84建议在4小时内给予50 mL/kg，再加上维持液，少量多次给予，必要时经鼻胃管给予。休克、不能耐受ORS以及病情恶化的儿童需要静脉补液。

对于休克，NICE NG29建议在不到10分钟内给予**10 mL/kg**不含葡萄糖的等渗晶体液（如0.9%氯化钠）推注，每次推注后重新评估。静脉维持液也应为等渗液，钠浓度131–154 mmol/L，因为低渗液可在患病儿童中引起危险的低钠血症，这些儿童常有抗利尿激素分泌过多。

并非每个呕吐的儿童都是胃肠炎。提示其他诊断的特征有：

- **胆汁性（绿色）呕吐**，提示肠梗阻，例如肠旋转不良伴肠扭转，属于外科急症；
- 2–8周饥饿婴儿的**喷射性呕吐**，提示**幽门狭窄**，伴低氯、低钾性代谢性碱中毒；
- 约3个月至2岁儿童间歇性绞痛、发作时面色苍白和“果酱样”大便，提示**肠套叠**；
- 头痛、前囟膨隆或意识水平下降，提示颅内压增高或脑膜炎；
- 腹痛、深快呼吸和体重下降，提示**糖尿病酮症酸中毒**。

::: example 为脱水儿童计算液量 {#ex-ors}
玛雅（Maya）3岁，体重14 kg。她腹泻和呕吐两天。她清醒，但黏膜干燥、眼窝凹陷，心率135次/分，毛细血管再充盈时间2秒。她没有休克征象。计算她最初4小时的口服补液方案。
::: solution
**评估。**她有临床脱水但无休克，因此适合口服补液。

**补充累积损失。**$50 \text{ mL/kg} \times 14 \text{ kg} = 700$ mL，在4小时内给予。

**维持液。**按Holliday–Segar公式：前10 kg为$10 \times 100 = 1000$ mL，接下来4 kg为$4 \times 50 = 200$ mL，合计每天1,200 mL，即$1200/24 = 50$ mL/h。4小时为200 mL。

**总量。**$700 + 200 = 900$ mL ORS，在4小时内给予，约**225 mL/h**，少量多次给予，例如每隔几分钟用注射器或杯子喂5–10 mL。

**监测。**定期重新评估。如果她持续呕吐，可以使用鼻胃管。如果出现休克征象，她需要静脉液体复苏。补液完成后，恢复正常饮食和液体，每次大量水样便后补充ORS。
:::
:::

::: example 腹痛伴呼吸急促的14岁少年 {#ex-teen}
丹尼尔（Daniel）14岁。一周来他饮水多、尿频，体重下降。今天他腹痛并呕吐三次。他嗜睡，深呼吸，频率32次/分，心率125次/分。毛细血管血糖28 mmol/L。
::: solution
**识别。**口渴、多尿和体重下降是新发**1型糖尿病**的典型症状。腹痛、呕吐、嗜睡和深长叹息样呼吸（库斯莫尔呼吸）提示**糖尿病酮症酸中毒（DKA）**。DKA是儿童1型糖尿病常见的起病方式，很容易被误认为胃肠炎或急腹症。

**确认。**静脉血气和血酮。英国儿科内分泌与糖尿病学会（BSPED）指南将儿童DKA定义为酸中毒（静脉pH低于7.3或碳酸氢盐低于15 mmol/L）伴酮血症（血酮高于3 mmol/L），见于高血糖或已知糖尿病的儿童。

**处理原则。**按照BSPED的DKA指南和计算器处理：在48小时内谨慎地进行液体复苏和补充，在开始补液后1–2小时开始胰岛素输注，并频繁监测血糖、酮体、电解质（尤其是钾）和神经系统状态。

**危险。****脑水肿**是儿童最令人担忧的并发症。头痛、心率减慢、血压升高、意识水平下降或新出现的意识混乱需要上级医生立即评估和治疗。
:::
:::

::: warning 不要轻视胆汁性呕吐
婴儿或儿童呕吐绿色物，在被证明不是之前，应视为外科急症。肠旋转不良伴肠扭转可在数小时内阻断整个中肠的血供，而婴儿起初可能看起来一切正常。任何胆汁性呕吐都需要紧急外科评估，通常需要上消化道造影检查。不要把它归为反流或胃肠炎。
:::

::: quiz
一名2岁女孩发热6天。她烦躁，双眼发红但无分泌物，口唇干裂发红，躯干有皮疹，双手肿胀。必须考虑并紧急治疗的是哪个诊断？
- [ ] 麻疹
- [x] 川崎病
- [ ] 猩红热
- [ ] 病毒疹；用退热药治疗
::: solution
发热5天或以上，伴结膜充血、口唇和口腔改变、皮疹和手部改变，符合**川崎病**的标准。静脉注射免疫球蛋白（以及在专科指导下使用阿司匹林）可降低冠状动脉瘤的风险，并需要超声心动图检查。NG143把发热持续时间长列为琥珀色特征，正是为了不漏诊这一疾病。
:::
:::

::: history
Holliday–Segar公式源自马尔科姆·霍利迪（Malcolm Holliday）和威廉·西格（William Segar）1957年发表于*Pediatrics*的论文，他们把需水量与热量消耗联系起来：每消耗100 kcal约需100 mL水。他们的方法沿用了几十年，但当时用作维持液的低渗液后来被发现会在住院儿童中引起低钠血症和死亡，2015年NICE建议使用等渗液。口服补液盐是在20世纪60年代开发的，在孟加拉国以及1971年战争期间印度难民营中的试验表明，它可以在没有静脉补液的情况下治疗霍乱、挽救生命；它常被称为二十世纪最重要的医学进展之一。川崎富作（Tomisaku Kawasaki）于1967年在日本描述了以他命名的疾病。
:::

## 后续内容

出生后最初几天的感染见[[paediatrics/newborn]]，预防其中许多疾病的疫苗见[[paediatrics/immunisation]]。成人和儿童的呼吸道感染见[[respiratory/respiratory-infections]]，糖尿病见[[endocrine/diabetes]]，复苏和脓毒症见急诊与重症医学课程，例如[[emergency-critical-care/anaphylaxis]]。热性惊厥和癫痫见[[nervous-system/epilepsy]]。当损伤或疾病与病史不符时，见[[paediatrics/safeguarding]]。

::: summary
- 儿童代偿能力强：心动过速、毛细血管再充盈缓慢和尿量减少出现得早，低血压是晚期的濒死征象。
- 使用ABCDE、按年龄区分的正常值和早期预警评分；给儿童称重，急症时估计体重。
- 3个月以下体温38 °C或以上是红色特征；发热5天或以上为琥珀色特征，应考虑川崎病。
- 发热伴不褪色皮疹，在被证明不是之前，应视为脑膜炎球菌病。
- 毛细支气管炎以支持治疗为主：血氧饱和度低于90%（6周以下或有危险因素者低于92%）时吸氧，支持喂养，不用支气管扩张剂、糖皮质激素或抗生素。
- 哮吼用一剂口服地塞米松治疗；不要检查可能患会厌炎的儿童的咽喉。
- Holliday–Segar给出维持液量：100、50和20 mL/kg/d。口服补液是一线治疗；休克用10 mL/kg等渗液推注治疗，维持液用等渗液。
- 胆汁性呕吐是外科急症，DKA可能伪装成胃肠炎。
:::

::: exercise 估计体重 {level=1 check="2*3+8"}
用APLS公式估计一名3岁儿童的体重（kg）。
::: solution
1–5岁时，体重$= 2 \times 3 + 8 = $ **14 kg**。

::: exercise 维持液速度 {level=1 check="(1000+500+20*3)/24"}
用Holliday–Segar公式计算一名23 kg儿童每小时的维持液速度（mL/h）。
::: solution
$10 \times 100 + 10 \times 50 + 3 \times 20 = 1000 + 500 + 60 = 1560$ mL/d。除以24小时：**65 mL/h**。

::: exercise 交通信号灯 {level=1}
用NICE交通信号灯系统对一名18个月发热儿童的下列每项发现进行分类：(a) 体温39.5 °C；(b) 不褪色皮疹；(c) 空气中血氧饱和度94%；(d) 肤色正常、反应正常、会笑。
::: solution
(a) 体温本身只在6个月以下婴儿中才是红色或琥珀色特征；在18个月时，它本身不改变分类。(b) **红色**。(c) **琥珀色**。(d) **绿色**。
:::

::: exercise 液体推注 {level=2 check="10*18"}
一名18 kg儿童有休克征象。NICE NG29推荐的首次液体推注量是多少毫升？
::: solution
$10 \text{ mL/kg} \times 18 \text{ kg} = $ **180 mL**不含葡萄糖的等渗晶体液，在不到10分钟内给予，随后重新评估。
:::

::: exercise 犬吠样咳嗽的儿童 {level=2}
一名2岁男孩犬吠样咳嗽、声音嘶哑一天。今晚他哭闹时有喉喘鸣，安静时没有，有轻度凹陷。血氧饱和度97%。概述处理和你会给出的建议。
::: solution
这是轻至中度**哮吼**。口服一剂地塞米松（剂量依据《英国儿童国家处方集》）。让他保持安静，避免用压舌板检查咽喉，并进行观察；大多数儿童在数小时内好转，可以回家。告诉父母，如果安静时出现喉喘鸣、孩子变得苍白、嗜睡或青紫、流涎或不能吞咽，或他们感到担心，应立即返回。不推荐蒸汽吸入。
:::
:::

::: exercise 首次热性惊厥 {level=2}
一名20个月女孩在家发热时发生全面性惊厥，持续3分钟。到院时她清醒、在玩耍，体温38.8 °C，咽部发红。这是哪种类型的惊厥？应排除什么？应告诉家长什么？
::: solution
这是**单纯型热性惊厥**：6个月至5岁儿童的全面性发作，持续不到15分钟。首要任务是找出发热的原因并排除中枢神经系统感染：寻找脑膜刺激征、前囟膨隆、不褪色皮疹和发作后期延长，对已使用抗生素或病重的儿童降低腰椎穿刺的门槛。本例很可能是病毒性咽部感染。应告诉家长：热性惊厥很常见（约每30名儿童中有1名），不会造成脑损伤，约三分之一的儿童会再次发作，退热药不能预防发作，以及发作时该怎么做：让孩子侧卧，计时，如果超过5分钟则呼叫救护车。
:::
:::

::: exercise 呕吐的婴儿 {level=3}
一名5周男婴4天来喂奶后剧烈呕吐。呕吐后他很饿，体重下降。血气显示pH 7.52，碳酸氢盐34 mmol/L，氯88 mmol/L，钾3.0 mmol/L。解释血液结果、可能的诊断和处理顺序。
::: hint
想一想胃内容物呕吐丢失了什么，以及肾脏如何反应。
:::
::: solution
**诊断。**这个年龄饥饿婴儿的非胆汁性喷射性呕吐提示**幽门狭窄**，即幽门肌肥厚。试喂时可触及橄榄样肿块，超声可以确诊。

**血液结果。**呕吐胃内容物丢失盐酸，引起**低氯性代谢性碱中毒**。脱水激活肾素–血管紧张素–醛固酮系统；醛固酮使肾脏保钠排钾、排氢，导致低钾血症并加重碱中毒（反常性酸性尿）。

**处理顺序。**这不是急诊手术。首先用含氯化钠和钾的静脉液体纠正脱水和电解质紊乱，直到碳酸氢盐和氯恢复正常，因为代谢性碱中毒的婴儿在麻醉后有呼吸暂停的风险。然后由外科医生施行**幽门肌切开术**。
:::
:::

::: exercise 安排冬季查房 {level=3}
一个冬天的早晨，儿科住院医师有五名新患者：(1) 7周毛细支气管炎婴儿，空气中血氧饱和度89%，吃奶量为平时的40%；(2) 4岁儿童，发热39 °C两天，咳嗽，血氧饱和度97%，除流涕外检查正常；(3) 9个月婴儿，发热伴双腿不褪色皮疹；(4) 2岁哮吼儿童，安静时有喉喘鸣；(5) 6岁儿童，从夜里开始呕吐，呕吐物呈绿色。按紧急程度排序，并说明每名患者的紧急处理。
::: solution
1. **发热伴不褪色皮疹的9个月婴儿（3）：**推定为脑膜炎球菌脓毒症。ABCDE，血培养，立即静脉使用抗生素，如有休克给予液体推注，请上级医生和重症监护团队参与。
2. **安静时有喉喘鸣的2岁儿童（4）：**重度哮吼。让孩子与家长在一起保持安静，雾化吸入肾上腺素并给予地塞米松，如无好转呼叫上级医生和麻醉医师。
3. **胆汁性呕吐的6岁儿童（5）：**可能为肠扭转或粘连等梗阻。禁食，建立静脉通路并补液，紧急外科评估和影像学检查。
4. **7周毛细支气管炎婴儿（1）：**血氧饱和度低于90%且喂养差。开始吸氧和鼻胃管喂养，注意呼吸暂停。
5. **发热伴流涕的4岁儿童（2）：**绿色特征。可能为病毒感染；用退热药缓解不适，给予安全保障建议，如果持续状况良好则出院。

排序取决于重新评估，任何儿童病情恶化时顺序都会立即改变。
:::
