神经的发育是关于时间的儿科学：那些不是由一项异常的检查来定义、而是由一个孩子跨越多年的、在多个领域里的轨迹来定义的情况，并且很早就开始。这一章讲的是神经的发育的情况如何被识别与诊断——孤独症与发育的协调的障碍及言语与语言及注意的缺陷及脑的瘫，以及它们如何被管理：在多学科的团队里、与学校一起、并带着家庭在中心。

## 识别与诊断

::: definition 原则与常见的情况 {#def-conditions}
**诊断是描述的、维度的与功能的。发育是一个领域一个领域的：大的与细的运动；言语与语言接受的对表达的，在实务中是不同的疾病；认知；社会的沟通；适应的行为；学习；注意与行为。而孩子很少全面地落后，所以5岁之下的全面的发育的迟缓与其后的智力发育的障碍（智商大致低于70，伴适应的功能的局限）是摘要、不是诊断。脑的瘫是慢性的运动的残疾的最常见的原因（学龄的孩子约每1000人中2人），是发育中的脑的一次不进展的损伤或的障碍，按分布来分类痉挛性的双瘫、偏瘫、四肢瘫，按张力与运动的类型痉挛的、不自主运动的、共济失调的——以及被错贴为“笨拙”或在缺氧的损伤与严重的黄疸之后被错贴为“手足徐动的脑的瘫”的肌张力障碍与指划的徐动，并按功能用那五级粗大运动的分类系统。那条必要的限定是：运动系统从来不会独自存在：癫痫，来自髋与脊柱侧凸的疼痛，便秘，反流，沟通与智力的障碍会与它同行；而多学科的团队之所以存在，是因为没有任何一个专科拥有这个孩子。孤独症是社会的沟通与局限的或重复的行为上的一种神经的发育的差异：从早期的发育就存在；在支持的需求与在表现上都存在于一条谱带上；靠观察加病史来发展性地诊断两个研究支持辅助的工具，不是魔法；而在社会的伪装延误了诊断的女孩身上正被越来越多地识别；伴高共病的焦虑、喂养的差异、少数一部分智力发育的障碍，以及另一部分有天赋的少数——那个“双重例外”的孩子（既是孤独症又是聪明的），他之所以被漏掉，是因为没有人把痛苦与那份概况联系起来。注意缺陷的障碍是一种注意的与或活动过度-冲动的、造成跨场景损害神经发育的疾病，带着可遗传的神经的生物学；而关于它是否存在的争论已经对着怀疑者结案了。这个诊断靠跨场景的病史与功能来做出、不靠一张问卷的分数；而要排除的鉴别是睡眠呼吸的障碍、失神的发作、焦虑与创伤、被伪装成不注意的学习的困难，以及那间会辜负任何一个孩子的教室。特异性语言的障碍、发育协调的障碍、包括图雷特抽动的障碍（句“他紧张的时候眨眼睛”，其实是一种约6到8岁起病的、起伏不定的神经的情况，而随行的注意的缺陷与强迫的那份行李比抽动本身更致残），以及诵读的困难与计算的困难学习的困难，补全了那一组常见的情况。两条结构的规则：孩子身上每一个新的神经的发育的诊断都会引出这个提问：这个孩子需要评估听力与视力吗？这个模式需要一个遗传的或代谢的或影像的原因吗？——神经发育的情况是一份表型，而“原因不明”是被允许的，但必须被挣得；以及每一个诊断都要让学校在环内做出，因为一半的损害住在那里[[paediatrics/growth-development]]、[[psychiatry/lifespan-psychiatry]]、[[genetics/common-disease-genetics]]。**
:::

## 管理、系统与药物

::: definition 干预与围绕它们的系统 {#def-manage}
**治疗在三个层面起效：孩子的技能、家庭的负荷与环境的要求。对孤独症，证据支持那些能改善沟通并减少学龄前痛苦的、以父母为媒介的方法；以功能为目标的言语与职业的治疗（而不是按小时的机械的训练）；以及为孤独症的来访者调整过的认知行为的治疗，用来对付那个常常占据整个图景的焦虑。而应用的行为的分析的那一类的方案，要在睁着眼睛的情况下被采纳与审计——关于它们的证据的基础，以及它们把正常的孤独症的动作病理化的可能；并且每一个治疗的小时都需要这个提问：在什么上更好？怎么测量？。对学龄的孩子的注意缺陷的障碍：兴奋剂的药物（大多数的指导里一线的是哌甲酯，然后按顺序是赖氨酸的安非他命与其他；以及右安非他命与托莫西汀及关法辛作为进一步的选项）是整个精神病学里对症状的水平最有效的治疗之一；监测身高与体重及脉搏及血压及睡眠；对那部分有结构心脏的病的人做心脏的复核；以及那句诚实的咨询：“药物加上行为的学校的措施加上睡眠的保护，胜过任何单独的一样。少年需要那场依从的谈话谁拿着那个药盒，以及那场驾驶的与滥用的谈话要早谈、不要在被停学之后。对脑的瘫，张力的管理是一架梯子：先是理疗与矫形的器具及教育；对局限的痉挛用肉毒的毒素；对全身性的张力与睡眠用口服的巴氯芬与地西泮；对被挑选的重症的病例用鞘内的巴氯芬与选择性的背根切断；配上髋监护的方案，以及其实是披着白大褂的生活的质量谈话的胃的造口与胃的折叠的讨论。对言语、语言与协调，关键的干预是可及性：由言语的与语言的治疗师来训练教师；那些不花钱的教室的调整（额外处理的时间、书面的指示、座位、活动的休息）——它们正是活动的结局会有差异的全部理由。而在这一切周围站着那座法律的建筑：特殊教育需要的这套系统——学校支持计划的遗留；以及那份地方当局必须在法律固定的时限内评估的教育、健康与照护的计划；以及这份承诺的全国性的慢性的失败——法庭与因未被满足的需求而受到伤害孩子的验尸官已经把它记录下来。儿科医师的信常常是一份计划与一场法庭之间的分别，所以它必须用朴素而具体的句子描述功能与证据及需求、不只是诊断。最后是健康的不平等的层：创伤后的行为与依恋的困难会与真正的神经的生物学并存早期的逆境、依恋的中断与真正的神经的生物学同时存在；贫困中的孩子被过度诊断为行为的、而被不足诊断为需要帮助的；以及这个系统的默认——那个会威胁上诉中产阶级的、口齿伶俐的父母会得到言语的治疗——是医学里最安静的一次可及性的失败”[[psychiatry/lifespan-psychiatry]]、[[nervous-system/motor-systems]]、[[public-health/determinants-inequalities]]。**
:::

## 与这个诊断共同生活

::: definition 青少年、共病与长远的目光 {#def-long}
**神经的发育不在青春期结束；而门诊的交班正是服务失败的地方。孤独症少年的抑郁常常被治疗不足，因为“孤独症的人就是那样”变成了不去询问的借口。注意缺陷障碍的青少年风险的那份档案——无照的驾驶、物质的滥用、被学校开除、自我伤害——是这个情况在16岁时真正的患病率，它属于每一次的药物复查。那个她的孤独症被伪装到14岁、直到一次拒绝上学或一次进食障碍的就诊才被看见的女孩，需要这个诊断作为一种能重建她的自我叙事的解释；而临床医师应当准备好不带歉意地给出它——即使“你是孤独症的”这句话，是在多年“你懒惰、无礼、夸张”之后才到达。进食的障碍与孤独症的共聚集的比率之高，应当改变住院的实务（感觉的食物清单、可预期性、更少的在荧光灯下混乱的进餐时间）；而在一个僵化的、有局限特殊的兴趣少年身上的“看起来不像教科书非典型的厌食”，是一条线索。神经发育孩子慢性的疼痛与疲劳被评估不足，因为沟通的差异被误当作没有痛苦：疼痛的量表必须被调整；而那个不会说话的孩子的痛苦的行为要被读作数据；而在那最高两级的脑的瘫里的髋的扫描与理疗的时间表的存在，正是因为疼痛表现为“痉挛加重与睡眠变差”、而不是表现为一次主诉。然后是过渡：到成人的神经科或学习的障碍的服务——在那里，“没有发作的间期”与“不需要主动的治疗”被人用来让需要一个懂他的癫痫与便秘的全科医师的人出院；到学院或工作，带着那份由诊断信解锁学习的支援；以及到性的健康与能力的谈话——儿科医师应当在14岁、在父母的祝福之下开始它们；因为同意与被剥削的保护“一个给他们买薯片的陌生人是学习的障碍的服务里最常见的加害者的故事以及网上的易受伤害，既是神经的发育的问题、也是社会的问题。而对家庭，长远的目光意味着那个被家长化的同胞，那位停止工作的父母，以及父母自己的变老——“我们不在了以后会怎样”这个问题在每一间门诊的候诊室里在凌晨被问出，而被沉默或一份通用的传单糟糕地回答。答案是一份在童年就开始、每年复查的个人的人生计划，具备法律的知识信托、直接的支付，以及在律师可以规划时的持久授权，并且对公共服务实际能交付什么保持诚实。一间只管理诊断神经发育的门诊是一间填表的服务；有价值管理的是轨迹与期待及界面——学校、社会照护、成人的服务——而一个孩子的生活实际上是在那里被决定的[[paediatrics/safeguarding]]、[[psychiatry/lifespan-psychiatry]]、[[medical-ethics-law/consent-capacity]]。**
:::

::: example 那个“没有在努力的7岁” {#ex-adhd}
一名3年级的男孩：坐立不安、捣乱；作业“有能力但不稳定”；这一学期两次被劝离；阅读明显低于他的班级；睡不好并大声打鼾；而他的父母（两位都“在那个年龄也是这样的”）要“那种专注的药片”。
::: solution
**开药之前先看全貌（[[#def-conditions]]、[[#def-manage]]）：评估——”注意缺陷的障碍是由临床医师主导的、跨场景的诊断，带着学校与家庭的数据简短注意病史的工具是辅助、不是判决；而打鼾必须被认真对待——因为腺样体与扁桃体的肥大是“活动过度”加白天的不注意的那个经典的可逆的原因；而阅读的差距必须被测量，因为一个跟不上班的孩子按构造就是一个行为的问题——所以先治鼻子、先教阅读，然后看还剩下什么注意。体格与发展的那次清扫——“生长；只在有指征时为铁与维生素D及铅抽血；视力与听力；言语与协调的发展的时间线；创伤与依恋的历史；以及与孤独症重叠的提问——因为没有共病的“纯粹的”注意的缺陷，比传单所暗示的更罕见。药物的谈话——”兴奋剂有效、在监测之下安全，而且它们不是镇静剂、也不是道德的工具；而规范级的实务是药物加上行为与学校的措施，在专科起始与剂量调整之后由全科共同开处方；而那张学校的支持的计划要被写下来、不是被许诺：座位、把指示切成小块、活动的休息、份阅读支持的转诊，以及那份奖励你想要的行为的方案；而如果学校只给劝离、不给计划，那条法定评估的道路要被早期点名——因为一个因神经的发育的症状而被劝离的7岁，是一次法律上的失败，而儿科医师可以帮助纠正它。药片是在这一切的末尾被开的，常常是合适的，但绝不能用它来替代这一切[[psychiatry/lifespan-psychiatry]]、[[nervous-system/epilepsy]]。**
:::

::: example 那个“拒绝上学并被当作焦虑的14岁” {#ex-autism-girl}
一名14岁的女孩，以前成绩很好，已5个月没有上学；在走廊里恐慌的发作；6周前开始不吃正常的食物；而她的母亲说“她一向对标签与声音很怪”；儿童精神卫生的分诊说是“广泛性的焦虑”。
::: solution
**那个被伪装的孤独症的少年（[[#def-conditions]]、[[#def-long]]）：没有人问过的那份历史——“一段靠伪装而严丝合缝的童年：婴儿期的羞怯；一两位亲密的朋友，而关系的规则是被明确地学会的；强烈而自我和谐的特殊的兴趣；份感觉的清单衣服的标签、午餐厅的噪音、荧光灯的灯；只在家里的崩溃；以及十年的印象的管理之后的那种耗尽“。不引导地问，并用观察与家庭自己的叙述来确认。加上”她的进食是局限的-感觉的与焦虑驱动的；带着孤独症的那副镜片去做那个厌食的工作——因为在一个混乱的病房里被再喂养，正是女孩崩溃并被贴上治疗耐药的途径。诊断与解释——“孤独症的评估本身就是干预、和那个标签一样：被以不带贬义的、准确的框定给出这个词的少年”你的大脑从一个房间里接收到的比多数人更多，而它靠分析来学会社交的规则；而14岁的学校全是房间、全是规则，常常在几周之内就减少了自我指责与上学的焦虑；而这个诊断还解锁了考试的安排与教育的、健康与照护的计划的支援——笼统的焦虑永远触发不了它们；治疗要具体、明确、由兴趣引导——而不是那门假定神经典型社交的学习小组焦虑的课程；以及由一个会大声说出“孤独症”这个词的人主持的家庭与学校的会议——在父母因解脱或愤怒而哭泣之前，而两者都是有治疗作用的。句长远目光的话：“这个诊断不是一块天花板；它是一份终于有了正确的维度的描述——因为另一个选择是再多五年被当作另一种病来治疗”[[psychiatry/eating-personality-disorders]]、[[psychiatry/anxiety-disorders]]。**

::: example 那个“抽动更重、脾气也更坏的9岁” {#ex-tics}
一名9岁的孩子，新发颈部的抽动与清嗓子，在家更重、在学校更好；之后一个月暴怒的发作；而父母找到了一页提到链球菌感染后的网页，并要抗生素。
::: solution
**抽动与那份情绪的级联（[[#def-conditions]]、[[#def-manage]]）：被解释的自然的病程——“抽动会起伏；在疲劳时与在家的安全感之下更重，而在被监督的学校里更好——这与”他能控制住它”正好相反——这是抽动的医学里最具治疗作用的一句话；而那个在学校抑制、然后在家里爆炸傍晚抽动的风暴，是迎合的代价；而那个放学后的狂怒是耗尽、不是行为的障碍；以及大多数的抽动在青春期之前会消退——这是真的，并且不等同于等着什么也不做。共病才是靶点——“注意缺陷的障碍与强迫及焦虑及学习的问题，通常比抽动本身更决定功能；而这个孩子需要完整的筛查——因为那个”抽动不是问题、而它底下的那个强迫才是“的情况会发生；以及抽动对强迫的的分别；以及对”其他的“运动的检查：舞蹈病的与肌阵挛的及被父母称为”走神的抽动“的失神的凝视，以及那一种在”新发的抽动与成绩变差的少年“身上没有人愿意错过铜代谢的病。场关于链球菌后的类的谈话——”那个关联被真实地发现、被过度地引申；而抗生素与免疫球蛋白及血浆的置换没有被证明对经过严格定义的大多数有效；我们不会在没有指征的情况下使用它；而那个不会让你儿子被听不见的框架是：“孩子里的一部分确实有一次感染的触发；而我们对感染的治疗是对感染的治疗、不是对抽动的治疗”。方案——“心理的教育是治疗；抽动专门的行为的治疗在可用的地方；只有严重时用α2的激动剂或抗精神病药（并做代谢的监测）这一架梯子；把睡眠当作一种抽动的治疗这一被认真的处方；以及学校会拿到一份一页纸的说明（休息与一条安静地离开的方案，以及不因抽动的声音而惩罚）——正是抽动的孩子们学会隐藏并爆炸的方式。这一咨询的一半是这件事，而另一半是：“他不会回到从前；他会成为噪声更小的他自己”这一预后的诚实[[nervous-system/movement-disorders]]、[[psychiatry/anxiety-disorders]]。**

## 通向何处

正常变异的基线在[[paediatrics/growth-development]]，运动的综合征在[[nervous-system/motor-systems]]，发作在[[nervous-system/epilepsy]]，精神的共病在[[psychiatry/lifespan-psychiatry]]与[[psychiatry/anxiety-disorders]]，而教育的法律的那个界面在[[public-health/determinants-inequalities]]。

::: history
**神经发育的专科从三个各自的不义中生长出来。第一是机构：19世纪的为愚人的收容所与20世纪大规模的机构，而它们被曝光的境况——医院的调查与1968年那部《秘密的孩子们》及那个正常化的原则——推动了1970年代的去机构化，并教会了医学一条永久的教训：没有人格的“照护”就是伤害；而以家庭为基础、由社区支持的服务，无论多么不完美，都更好。机构的关闭是儿科的与残疾的历史上最伟大的改革，也是它最没有被完成的改革。第二是分类的战争：1940到1960年代的最小的脑的损伤与脑损伤的孩子，让位于1943年与1944年那两篇关于早发的孤独症的论文（以及那位作者在纳粹统治之下的那份让人难以处理生平——至今仍在被辩论）；1970年代的标准让孤独症成为一个可被观察的行为的综合征、而不是一种精神病；把描述与研究的标准结合在一起的那一次第三版的婚姻；1990年代那场其实是被拓宽的识别的“康复率的流行”；以及2013年并成一条孤独症的谱带——那个疾病分类学吸收了阿斯伯格的那个共同体，而那个共同体关于“被诊断到不存在”的争辩，直到今天仍然决定着服务如何与人们说话。第三是教室：残疾的权利与“没有我们的参与就不要谈关于我们”的运动；从1978年那份报告到2014年那部关于儿童与家庭的法律的立法；网上神经多样性的一个运动（改变了语言的孤独症的自我主张者——身份优先的“一个孤独症的人”在这个领域的许多地方成了标准，因为共同体选择了它）；以及注意的缺陷的障碍这场从“父母缺失的”行为主义，经由1930到1950年代兴奋剂的试验，走到那批让怀疑在专业上无法立足的基因的与影像的文献的斗争。而那份诚实的子章节是：兴奋剂的供应与被施加压力的诊断，一次又一次地跑在了服务能够恰当地评估的能力之前，制造出批评者们所引用的那幅漫画。技术的那段历史更小但是真实的：改变了谁在18岁能够走路的髋的监护的方案；把一整条聋孩子们的语言轨迹挪动的那套新生儿听力的筛查；以及在1997年给临床医师与家庭一份共享的功能的语言、并同时改变了研究与学校的规划的那套分类系统。以及近期的项认识——仍在缓慢地渗入政策：在女孩身上与在每一个被边缘化的群体身上的诊断的延误是一项结局的变量，而如果不把它数出来，如今已是一种过失。那条贯穿的线索：每一代人对那个难缠的孩子的那份自信的描述，最后都被证明是一处与环境的错配加上一个神经的系统；而这一专科的进步，是以它多早停止指责孩子、并开始描述那处错配来测量的”[[paediatrics/growth-development]]、[[public-health/determinants-inequalities]]、[[psychiatry/psychiatric-assessment]]。**
:::

::: summary
- 神经发育的诊断是描述的、跨场景的与功能的；而那份表型仍然在问：听力与视力及遗传学或一个保护的问题是否藏在里面。
- 脑的瘫与孤独症及注意的缺陷及言语及协调及抽动各有一条有证据的道路；而它们的共病（癫痫与疼痛及焦虑及进食及睡眠）通常是真正的负担。
- 兴奋剂在恰当的评估之后是注意的缺陷的障碍的一线；孤独症的干预关乎沟通与家庭的负荷及学校的现实，而不是消除自我刺激的动作。
- 环境是一种治疗：考试的安排、法定的计划与受训练的教师，改变轨迹的程度不亚于门诊。
- 少年需要长远的目光：女孩身上的伪装与延误；心境与进食的共病；驾驶与被剥削的风险；以及一份点出真实服务名过渡的计划。
- 测量你自己的公平：谁在4岁被诊断、谁在14岁被诊断，是一项与任何结局同样有效服务质量的统计。
:::

一封能得到一份计划的信（[[#def-manage]]、[[public-health/determinants-inequalities]]）：功能的段落——“具体而可观察的句子：”无法用笔清晰地书写超过两分钟；不能用剪刀；在体育的游戏中困难；在楼梯上摔倒“；并带上那句”认知正常、而挫折是继发的、不是原发的“——这一句能保护她不被叫作违抗。需求的段落——”笔记本电脑或文字处理的权限；用打字代替手写；额外的时间或考试的代写；体育的调整而不是豁免（因为体能的要紧）；多次短的书写、而不是长的；把任务拆成步骤；言语的治疗与职业的治疗每年两次进校——每一条需求一句话，而每一句话都可被检验。供给的段落——”如果这份供给没有到位，那么可以预期：不断升级的拒绝上学与焦虑及体育的回避，并带有已知的长期的出勤与心理的健康代价——把支持供给临床的理由写成一条被预期的病程，因为法庭与合议庭会对被引用的、以医学散文写出的伤害作出回应；以及那种“需要多少百分比的协助”的量化——它不留关于“多少”的争辩；以及被命名的复查的日期——因为没有复查日期的一份计划是一部小说[[clinical-skills/communication]]、[[public-health/health-systems-economics]]。**

::: exercise 封“没有人读门诊的信” {level=3}
读一读这份真实的风格的门诊的出院：发育的迟缓，很可能是环境的；言语的治疗被提供；按需要来门诊。一位母亲拿着它无法得到学校的支持。请重写它，并指出它所演示三个结构的失败。
::: solution
**重写那封不成信的信（[[#def-manage]]、[[clinical-skills/records-handover]]）：重写——“带日期与负责人的具体的功能的句子：”表达的语言在按年龄的第25百分位、接受性的在第10百分位；听力按3月14日的听力学的检查正常；由学校提供视觉的时间表与处理的时间；在8周之内由分诊复查，附上言语的转诊；目前没有全面的迟缓；父母关于社会的沟通的担忧已被记录，而孤独症的评估已预约在9月“——因为每一个子句都在回答：谁在什么时候做什么，以及我们会从什么发现它变差了。三个结构的失败——”那个没有证据的“很可能是环境的”，而它其实是“因为是环境的所以被忽视”——是那句古老的指责母亲的话穿着现代的衣服；那个没有附上转诊单的“言语的治疗被提供”——它把整个可及性的问题委托给了一位压力下的父母；以及那个“按需要来门诊”——它假装这个家庭知道“需要”会长成什么样子；而那句“如果有怀疑就回来是一条被当作建议服务的失败”。服务的修法——“每一封信都有模板：功能、供给、负责人、复查的日期，以及”什么会改变这一条”字段；信会被学校读，所以要为那位有特殊教育需要的协调者而写这一读者的意识；全科拿到的是结构化的摘要、不是那份叙述——因为全科正是法庭首先问的那个人；以及以两种语言镜像到父母的门户这一交付——因为一封以无人打开附件到达的信，是一枚有图章的流言。重写只比原文多花九十秒，却改变了哪些机构能够行动——而这正是一封出院信全部的目的[[public-health/determinants-inequalities]]、[[clinical-skills/communication]]。**
