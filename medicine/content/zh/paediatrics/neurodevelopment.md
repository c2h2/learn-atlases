神经发育障碍始于儿童期，影响大脑的发育方式：儿童如何运动、沟通、学习、集中注意力或与他人相处。它们包括孤独症、注意缺陷多动障碍（ADHD）、脑性瘫痪、智力障碍、抽动障碍以及特定学习障碍和语言障碍。它们合起来影响超过十分之一的儿童。

这些疾病是终身的，但其影响并不是固定的。家庭和学校正确的理解、恰当的调整，有时再加上恰当的药物，可以大大改变儿童的经历。许多孤独症人士和ADHD人士把自己的状况视为自身的一部分，而不是一种疾病，许多人更喜欢以身份为先的表述（“孤独症儿童”）。本章两种表述都使用。目标是识别需要帮助的儿童，正确地评估他们，并支持他们及其家庭，而不假定每一种差异都是缺陷。

## 识别与诊断

::: definition 主要的神经发育障碍 {#def-conditions}
**孤独症**（孤独症谱系障碍）的定义是社交沟通和社会互动方面的持续差异，加上局限、重复的行为、兴趣或活动模式，包括对感觉输入的异常反应。这些特征从儿童早期就存在，尽管可能要到社交需求增加时才被识别，并给日常生活造成显著困难。

**注意缺陷多动障碍（ADHD）**是一种与儿童发育水平不相称的持续性注意缺陷和/或多动冲动模式，始于12岁之前，出现在两个或以上场合（例如家庭和学校），并损害功能。

**脑性瘫痪**是一组由发育中的胎儿或婴儿大脑的非进行性损害引起的永久性运动和姿势障碍。它常伴有感觉、沟通、学习、行为方面的困难和癫痫。

**智力障碍**（英国服务中称为**学习障碍**）是智力功能的显著受限，通常智商低于约70，同时伴有沟通、自理和社交技能等适应性技能的受限，起始于发育期。分为轻度、中度、重度和极重度。

**特定学习障碍**影响某一个领域，而总体能力正常：**阅读障碍**（阅读和拼写）、**计算障碍**（数字），以及**发育性协调障碍**（运动协调，有时称为运动障碍）。**发育性语言障碍**是在没有听力损失等已知原因的情况下，理解或使用语言的持续困难。
:::

这些疾病很常见。在英国，至少每100名儿童中有1名被诊断为孤独症，近期研究提示数字更高。ADHD影响全世界约5%的儿童。脑性瘫痪约见于每1,000名活产儿中的2名。发育性语言障碍影响约7%的入学儿童。

::: theorem 特质是维度性的；诊断需要功能损害 {#thm-impairment}
孤独症和ADHD的特征在人群中呈连续分布，许多儿童都表现出其中一些特征。只有当这些特征普遍、持续并在日常生活中造成显著损害时，才能作出诊断。
:::

::: proof
注意力、活动水平、社交互惠和思维灵活性在所有儿童之间都有差异，孤独症和ADHD的遗传贡献大部分来自许多常见遗传变异，每个变异的效应很小，这正是身高等连续分布性状所见的模式。因此，“有”与“没有”这些疾病之间没有天然的分界。诊断手册（DSM-5-TR和ICD-11）用功能损害来划线：这些特征必须在社交、教育或其他功能方面造成真正的困难，并跨越不同场合、持续一段时间。这就是为什么来自多个场合的病史很重要，为什么一次门诊观察是不够的，以及为什么同样的特质在一种环境中是困难而在另一种环境中不是。它也解释了为什么在某个年龄达到诊断阈值而在另一个年龄没有，例如中学的社交需求暴露出在小学时尚可应付的困难。
:::

这些疾病相互重叠。三分之一到一半的孤独症儿童也有ADHD的特征，许多脑性瘫痪儿童有智力障碍或癫痫，有一种学习障碍的儿童常常还有另一种。因一种疾病被转诊的儿童应同时评估其他疾病。

### 儿童如何被转诊和评估

担忧可能来自家长、托儿所工作人员、教师、健康访视员或儿童本人。NICE指南规定了评估应如何进行：19岁以下孤独症见CG128，ADHD见NG87，25岁以下脑性瘫痪见NG62。

**孤独症评估**由多学科团队进行，常包括儿科医生、言语和语言治疗师以及心理学家。它包括从父母处采集详细的发育史、来自学校或托儿所的信息、直接观察（常使用ADOS-2等结构化工具），以及体格检查以寻找遗传综合征的特征和神经皮肤疾病的皮肤征象。NICE建议在转诊后3个月内开始评估，但等待时间常常长得多。

**ADHD**由儿科或精神科专科医生诊断。通过家长和教师收集信息，常使用评定量表，并考虑其他解释：听力或视力问题、学习困难、睡眠问题、焦虑、情绪低落、创伤以及儿童环境的影响。

运动里程碑延迟、肌张力异常、过早出现利手、不对称、原始反射持续存在或喂养困难，提示**脑性瘫痪**。危险因素包括早产、低出生体重、新生儿脑病、感染和卒中。脑MRI有助于确定损伤的原因和时间。NICE NG62建议，高风险婴儿应纳入强化发育随访项目，至少随访至2岁。

脑性瘫痪按类型和功能分类。主要类型是**痉挛型**（约80–90%，分为单侧或双侧）、**运动障碍型**和**共济失调型**。**粗大运动功能分级系统（GMFCS）**将移动能力分为五级：

| 级别 | 移动能力 |
|---|---|
| I | 行走不受限制 |
| II | 行走有限制，例如在不平的地面或长距离行走时 |
| III | 使用手持移动辅助器具行走 |
| IV | 自主移动受限；可使用电动移动工具 |
| V | 用手动轮椅转运 |

::: example “不肯努力”的七岁孩子 {#ex-adhd}
杰克（Jack）7岁。他的老师说他做不完作业，在课堂上大声插话，离开座位，丢东西。在家里他吃饭坐不住，不停地打断别人，不看路就冲到马路上。他的父母被告知他“懒”和“调皮”。这种行为从他上学开始就存在，导致他被排除在课间游戏之外并失去朋友。
::: solution
**第1步：这一模式是否符合ADHD？**注意缺陷（做不完作业、丢东西）以及多动冲动（插话、离座、打断别人、不能等待），在家庭和学校都存在，持续两年以上并造成损害（被排斥、失去友谊、马路上的危险）。这符合定义。

**第2步：还有什么可以解释它？**听力或视力问题、特定学习障碍（不会阅读的孩子完不成书面作业）、发育性语言障碍、阻塞性睡眠呼吸暂停等睡眠问题、焦虑、家庭中的不良经历，以及常常共存的孤独症。

**第3步：评估。**转诊至专科。父母和学校填写评定量表，采集发育史和家族史，进行包括生长、心率、血压在内的体格检查和心血管病史询问，如近期未做听力测试则进行测试。

**第4步：如果确诊ADHD的处理**（见下一节）：为家庭和学校提供信息和支持，在课堂上进行环境调整，并且由于他的困难持续而显著，讨论药物治疗。

**经验。**“懒”和“调皮”这样的词是描述，不是解释。问孩子为什么这样做，是评估的开始。
:::
:::

## 处理以及围绕儿童的体系

::: definition 支持、调整与治疗 {#def-manage}
**合理调整**是对环境或服务提供方式的改变，使残障人士不处于不利地位。在英国，这是《2010年平等法》规定的法律义务。

**特殊教育需要支持（SEN support）**是学校内为有特殊教育需要的儿童提供的额外帮助，与学校的特殊教育需要协调员（SENCO）共同计划。

**教育、健康和照护计划（EHC计划）**是英格兰针对0–25岁儿童和青年的一份法律文件，在地方当局完成需求评估后，列明其需要以及必须提供的支持。它遵循《特殊教育需要和残障实施守则》（SEND Code of Practice，2015）。
:::

**孤独症。**没有针对孤独症核心特征的药物。支持的目标是帮助沟通和社会理解、减少痛苦，并使环境更可预测、不那么令人难以承受。NICE推荐帮助家长和教师调整沟通方式并支持以游戏为基础的社会学习的干预措施。共存的困难要分别治疗：睡眠问题（行为方法，必要时使用褪黑素）、焦虑、癫痫、胃肠道问题和喂养困难。抗精神病药有时用于严重易激惹或攻击行为，需在专科监督下使用，但不作为第一步。

**ADHD。**NICE NG87建议为所有儿童提供家庭信息和支持以及学校中的调整。5岁以下儿童首先采用家长培训项目，只有在专科建议下才使用药物。对于5岁及以上、尽管采取了这些措施仍有持续显著损害的儿童，可以提供药物治疗：

- **哌甲酯（methylphenidate）**是一线药物。它阻断多巴胺和去甲肾上腺素的再摄取。
- **赖右苯丙胺（lisdexamfetamine）**是二线兴奋剂。
- 当兴奋剂不能耐受或无效时，非兴奋剂如**托莫西汀（atomoxetine）**和**胍法辛（guanfacine）**是替代选择。

兴奋剂常降低食欲，并可影响睡眠、生长、心率和血压。治疗前记录身高、体重、心率和血压，并采集心血管病史。治疗期间定期监测这些指标并描绘在百分位曲线图上。剂量依据《英国儿童国家处方集》，由专科医生滴定。兴奋剂属于管制药品，年轻人的意见在治疗决策中很重要。

**脑性瘫痪。**照护是多学科的：针对运动和姿势的物理治疗、作业治疗、针对沟通和吞咽的言语和语言治疗、矫形器和辅助设备。痉挛可用巴氯芬等口服药物、向特定肌肉注射肉毒毒素治疗，部分儿童可进行手术，包括选择性脊神经后根切断术。脑性瘫痪儿童需要定期X线片进行**髋关节监测**，因为不能行走者髋关节移位很常见，还需关注营养、流涎、便秘、疼痛、睡眠和癫痫。

**智力障碍。**用基因检测（染色体微阵列分析、脆性X检测，如均正常则进行外显子组或基因组测序）寻找病因，支持的重点是教育、沟通、独立能力和家庭。学习障碍者比一般人群死亡更早，常死于可治疗的原因，NHS“从生命与死亡中学习”项目（LeDeR）审查这些死亡以改进照护。

::: warning 诊断遮蔽
**诊断遮蔽**是指把新出现的症状归因于已知疾病而不去检查的错误。一个不会说话的孤独症儿童开始撞头，可能是牙痛、中耳炎或便秘。一个脑性瘫痪儿童在被搬动时变得痛苦，可能是髋关节脱位或骨折。一个学习障碍儿童不再进食，可能有反流或食管问题。行为就是沟通。行为改变时，务必寻找躯体原因。
:::

::: example 不再去上学的14岁女孩 {#ex-autism-girl}
阿伊莎（Ayesha）14岁，已经六周没去上学了。在家里她长时间待在房间里画画，能非常详细地谈论某个系列的小说。小学时她安静、守规矩，从未被认为有困难。升入一所大型中学后，她每天头痛、肚子痛，在拥挤的走廊里惊恐发作，并说她“假装正常已经精疲力竭”。她母亲说她蹒跚学步时会把玩具排成一排，日常安排一改变就非常不安。
::: solution
**模式。**随着社交需求增加而显现的社交困难、强烈而集中的兴趣、早期的重复行为和对变化的痛苦、在人群中的感觉超载，以及**伪装**（有意模仿他人以融入）带来的精疲力竭。这种模式是女孩孤独症的典型表现，女孩常因能伪装自己的困难而比男孩更晚被诊断。

**鉴别诊断和共存疾病。**焦虑障碍和抑郁在孤独症青少年中很常见，可能是主要的就诊问题。应考虑欺凌、不良经历以及头痛和腹痛的躯体原因。应询问有无进食障碍。

**计划。**转诊做孤独症评估。审慎地筛查情绪低落和自伤。与学校合作逐步复学并作出调整：一个安静的空间、允许提前离开课堂以避开拥挤的走廊、一位指定的联系人，以及清晰的日常安排。用为孤独症青少年调整过的方法治疗焦虑。

**经验。**青少年缺课是一个需要理解的症状。对有些年轻人来说，原因是未被识别的孤独症。
:::
:::

## 抽动及其他疾病

**抽动**是突然、快速、重复的动作或声音。简单抽动，如眨眼或吸鼻子，在儿童期非常常见，常时有时无。当出现多种运动抽动和至少一种发声抽动超过一年、且起病于18岁之前时，诊断为**抽动秽语综合征（Tourette综合征）**。抽动通常在5–7岁开始，在青春期早期达到高峰，成年后常有改善。抽动之前常有一种冲动，抽动后冲动缓解；抽动可以被暂时抑制，但要付出努力。ADHD、强迫障碍和焦虑常常共存，而且往往比抽动本身更致残。

::: example 抽动加重、脾气变坏的九岁男孩 {#ex-tics}
奥利（Ollie）9岁。他眨眼、做鬼脸、耸肩已有三年，18个月来还发出清嗓子和吸鼻子的声音。他累了或兴奋时抽动加重。最近老师反映他发脾气，注意力不集中，而且他一天洗手很多次。
::: solution
**诊断。**多种运动抽动和至少一种发声抽动超过一年，起病于儿童期，符合**抽动秽语综合征**的标准。

**共存疾病。**注意力不集中提示ADHD，反复洗手提示强迫障碍。发脾气很常见，常与这些疾病、抑制抽动所付出的努力或被嘲笑有关。这些共存疾病对日常生活的影响常常大于抽动。

**处理。**为奥利、他的家庭和学校提供解释（心理教育）是第一步，也常常是最有帮助的一步。教师不应把注意力引向抽动。如果抽动造成痛苦或功能损害，**行为治疗**（习惯逆转训练或抽动综合行为干预）是一线治疗。当行为治疗不够时，专科医生会使用阿立哌唑（aripiprazole）或可乐定（clonidine）等药物。ADHD和强迫症状需要各自的评估和治疗。
:::
:::

::: example “只是笨手笨脚”的早产三岁孩子 {#ex-premzy}
利奥（Leo）29周出生，现在3岁。他24个月（校正21个月）时会走。他用脚尖走路，经常绊倒，不会跳。他的双手功能良好。检查发现双腿肌张力增高、反射亢进，小腿肌肉紧张，巴宾斯基征阳性。他的言语和理解与年龄相符。
::: solution
**诊断。**一个极早产出生的儿童，双腿肌张力增高、反射亢进，且下肢受累远重于上肢，提示**双侧痉挛型脑性瘫痪**（痉挛性双瘫）。它常由脑室周围白质损伤（脑室周围白质软化）引起，因为支配下肢的纤维最靠近脑室走行。

**分级。**他不用辅助器具即可行走，但有限制，因此属于**GMFCS I级或II级**。

**评估。**脑MRI以确定病因。检查视力和听力，早产儿常有这方面的问题。监测髋关节，并注意其他问题：学习困难、癫痫，以及日后的ADHD，这些在早产后更常见。

**处理。**物理治疗以维持肌肉长度、改善力量和功能，踝足矫形器，并考虑在小腿注射肉毒毒素。为托儿所和学校计划支持。

**经验。**“只是笨手笨脚”可能掩盖一个诊断。伴反射亢进的足尖行走不是特发性足尖行走。
:::
:::

## 带着诊断生活

::: definition 长期需求与过渡 {#def-long}
**过渡**是年轻人从儿童服务转向成人服务的有计划、有目的的转移。NICE指南NG43建议在13–14岁开始计划，由一名指定工作人员主导，并让年轻人参与决策。

**共存疾病**是与主要诊断同时存在的疾病，如癫痫、焦虑、睡眠障碍和胃肠道问题，它们在神经发育障碍中更常见，往往需要各自的治疗。
:::

残障儿童的家庭面临实际和情感上的负担：就诊、设备、睡眠不足、为争取学校支持而奔波，以及经济忧虑。他们有权接受照护者评估，短期喘息服务和家长互助小组会有帮助。兄弟姐妹也需要关注。

青春期带来新的挑战：青春发育、性、网络和恋爱关系中的安全、被剥削的风险，以及关于独立和决策能力的决定。在英格兰和威尔士，16岁起适用《2005年心智能力法》，对于有决策能力的年轻人，父母不会自动替其作出决定。成人服务往往不够完善，尤其是针对ADHD和孤独症的服务，因此过渡计划很重要。

::: quiz
一名4岁男孩被诊断为ADHD。他的父母询问药物治疗。按照NICE NG87，这个年龄的一线治疗是什么？
- [ ] 哌甲酯
- [ ] 托莫西汀
- [x] 家长培训项目
- [ ] 褪黑素
::: solution
对于5岁以下的ADHD儿童，NICE建议首先采用以ADHD为重点的团体家长培训项目。没有第二位专科医生的意见，不为5岁以下儿童提供药物。对于5岁及以上、环境和教育措施不足以改善的儿童，哌甲酯是一线药物。
:::
:::

::: history
1861年，英国骨科医生威廉·利特尔（William Little）描述了在难产或早产后出现下肢僵硬的儿童，这种疾病长期被称为利特尔病；西格蒙德·弗洛伊德（Sigmund Freud）后来指出，许多病例不能仅用产伤来解释。1943年，巴尔的摩的利奥·坎纳（Leo Kanner）描述了11名有“情感接触的孤独性障碍”的儿童；1944年，维也纳的汉斯·阿斯佩格（Hans Asperger）描述了一组有社交困难和强烈兴趣的男孩。1979年，伦敦的洛娜·温（Lorna Wing）和朱迪丝·古尔德（Judith Gould）描述了“三联损害”和孤独症谱系的概念。1902年，儿科医生乔治·斯蒂尔（George Still）在皇家内科医师学会的讲座中描述了在“道德控制”和注意力方面有问题的儿童，这是对今天所称ADHD的早期描述。乔治·吉勒·德拉图雷特（Georges Gilles de la Tourette）于1885年描述了以他命名的抽动障碍。
:::

发育里程碑和评估发育迟缓的最初步骤见[[paediatrics/growth-development]]。智力障碍的遗传原因见[[paediatrics/congenital-genetic]]和[[genetics/genetic-testing]]。支配运动的脑系统见[[nervous-system/motor-systems]]，癫痫见[[nervous-system/epilepsy]]。青春期的心理健康，包括焦虑和抑郁，见[[paediatrics/adolescent-health]]和[[psychiatry/lifespan-psychiatry]]。

::: summary
- 神经发育障碍常见、终身存在且常常共存；对每个儿童都要评估相关疾病。
- 孤独症和ADHD的特质是维度性的；诊断需要跨场合的持续特征并伴显著损害。
- 孤独症评估是多学科的（NICE CG128）；女孩常因伪装而诊断较晚。
- ADHD（NG87）：5岁以下首先家长培训；5岁起哌甲酯是一线药物，需监测生长、心率和血压。
- 脑性瘫痪是一种非进行性脑损伤，导致永久性运动和姿势障碍；按类型和GMFCS分级，并记住髋关节监测。
- 智商低于70识别出约2%的人，但智力障碍还需要适应功能受限。
- 学校提供特殊教育需要支持，在英格兰EHC计划赋予获得支持的法定权利。
- 行为就是沟通：避免诊断遮蔽，寻找行为改变背后的疼痛或疾病。
- 过渡计划应在13–14岁开始。
:::

## 习题

::: exercise 说出疾病名称 {level=1}
对下列每种描述，说出最可能的疾病：(a) 一名6岁儿童智力正常、接受了良好的教学，仍持续难以学会阅读；(b) 一名5岁儿童眨眼和吸鼻子3个月；(c) 一名因脑性瘫痪而使用手持助行架行走的儿童。
::: solution
(a) 阅读障碍（一种特定学习障碍）。(b) 暂时性抽动障碍；抽动秽语综合征需要运动和发声抽动超过一年。(c) GMFCS III级的脑性瘫痪。
:::
:::

::: exercise 智商低于70 {level=1 check="round(1000*0.02275)/10"}
智商分数的均值为100，标准差为15。按正态分布，人群中百分之多少的人得分低于70？保留一位小数。
::: hint
70比均值低两个标准差。
:::
::: solution
$z = (70 - 100)/15 = -2$。$z = -2$以下的比例为0.02275，即约**2.3%**。由于适应功能也必须受限，智力障碍的患病率低于此数，约为1–2%。
:::
:::

::: exercise 开始使用兴奋剂之前 {level=1}
列出儿童开始使用哌甲酯之前所需的测量和病史。
::: solution
身高和体重并描绘在百分位曲线图上；心率和血压并描绘在百分位曲线图上；心血管病史（晕厥、心悸、运动时胸痛、气促）和心源性猝死或心脏病家族史，如有任何一项则做心电图并征求心脏科意见；抽动、惊厥、睡眠问题、食欲和物质使用史；以及讨论年轻人自己的意见。
:::
:::

::: exercise 治疗中的体重 {level=2 check="round(1000*(32.0-30.4)/32.0)/10"}
一名9岁儿童服用哌甲酯，治疗前体重32.0 kg，六个月后为30.4 kg。他丢失了体重的百分之几？保留一位小数。应该怎么做？
::: solution
$(32.0 - 30.4)/32.0 = 0.05$，即**5.0%**。生长中的儿童体重下降是有意义的，尤其是跨越百分位时。询问食欲和进餐情况；随早餐或餐后服药；在药效消退的晚上安排一顿丰盛的饭；如果生长持续受影响，考虑减量、有计划地停药或换药。还应监测身高增长速度。
:::
:::

::: exercise 撞头的孩子 {level=2}
一名6岁不会说话的孤独症男孩在过去一周开始拍打头的一侧，夜里哭闹。他的父母问是不是他的孤独症加重了。你会如何处理？
::: solution
孤独症不是进行性的，新出现的行为是一种需要解释的变化。避免诊断遮蔽，寻找躯体原因：中耳炎、牙痛、头痛、便秘、反流、外伤或癫痫发作。检查他的耳朵、口腔和腹部，询问排便习惯、睡眠以及家庭或学校中的任何变化。利用父母对他如何表达疼痛的了解。日常安排的变化，如换了新老师或新班级，也会引起痛苦，但在考虑躯体原因之前不应先作此假定。
:::
:::

::: exercise 哪些学生需要什么？ {level=2}
一所小学请你提供建议。解释特殊教育需要支持与EHC计划之间的区别，并各举一个可能需要它的儿童的例子。
::: solution
**特殊教育需要支持**由学校利用自身资源提供，由SENCO协调，采用评估、计划、实施和复核的循环。例子：一名阅读障碍儿童需要小组阅读辅导和额外时间。**EHC计划**是在仅靠特殊教育需要支持无法满足儿童需要时，经地方当局法定评估后制定的。它具有法律约束力，涵盖教育、健康和社会照护。例子：一名GMFCS IV级、有沟通困难的脑性瘫痪儿童，需要特殊学校学位、治疗和设备。
:::
:::

::: exercise 计划过渡 {level=3}
一名15岁痉挛性四肢瘫型脑性瘫痪（GMFCS V级）少年患有癫痫并有胃造口，由一名儿科医生、一名神经科医生、一名消化科医生、一名骨科医生和社区服务共同照护。概述向成人服务过渡的计划。
::: solution
**时间和主导。**计划应已在13–14岁开始，由一名指定工作人员主导，遵循NICE NG43。

**年轻人本人。**用他的沟通方式尽可能让他参与。评估他对具体决定的决策能力；16岁起适用《心智能力法》，他无法作出的决定按他的最佳利益作出，并征求父母意见。

**服务。**为每一项需求确定成人服务：成人神经科医生负责癫痫，消化科或营养支持团队负责胃造口，骨科和物理治疗负责髋关节、脊柱和挛缩，呼吸照护，以及由全科医生协调。安排联合门诊或交接会议，以及一份书面健康护照。

**社会照护和教育。**EHC计划可持续到25岁。在服务结束前安排成人社会照护评估、持续医疗照护资助、设备和住房。

**家庭。**照护者评估和支持；紧急情况预案；以及对未来照护的讨论，适当时包括预立照护计划。
:::
:::

::: exercise 等候名单问题 {level=3}
一个社区儿科服务每年接到600份孤独症评估转诊，每年能完成350例评估。家庭等待已超过2年。讨论其后果和可能的应对措施。
::: solution
**算术。**每年600份转诊、350例评估，等候名单每年增加250人，因此除非能力或需求发生变化，等待时间会持续延长。

**后果。**儿童错过早期支持，家庭承受压力，学校可能等到诊断后才提供帮助，可能出现心理健康问题，而且不平等扩大，因为有条件的家庭可以自费就诊。

**应对。**根据需要而不是诊断提供支持：无论是否已作出诊断，学校都应通过特殊教育需要支持满足需要，这也是《特殊教育需要和残障实施守则》的要求。对转诊进行分诊，优先处理年幼儿童和高风险儿童。通过增加经过培训的人员、多技能组合团队以及利用学校信息的高效流程来提高能力。在等待期间为家庭提供支持，包括家长项目以及关于睡眠和焦虑的建议。监测谁在等待，以及某些群体（例如女孩，或少数族裔家庭）是否转诊不足。
:::
