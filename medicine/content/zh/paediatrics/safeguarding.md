儿童保护是指保护儿童免受伤害并促进其福祉。每个接诊儿童的临床医生，以及每个接诊身为父母的成年人的临床医生，都在其中承担一份责任。大多数虐待和忽视发生在家中，由儿童认识的人实施，大多数从未被专业人员看到。即使被看到，征象往往也很细微：婴儿身上的一处瘀伤、一处与陈述不符的损伤、一个总是错过预约的孩子、一个结交了新的年长朋友的青少年。

本章解释虐待和忽视的形式、如何识别、如何检查和记录，以及英格兰法律的要求。内容遵循NICE指南CG89（儿童受虐待：何时应怀疑）和法定指南《共同努力保护儿童2023》（*Working Together to Safeguard Children 2023*）。苏格兰、威尔士和北爱尔兰的细节有所不同，但原则相同。临床医生的职责是识别、记录和转介。调查以及对发生了什么作出判断属于多机构体系的职责。

## 识别

::: definition 虐待与忽视的类别 {#def-recognise}
**躯体虐待**是打、摇晃、扔、投毒、烧伤、烫伤、溺、使窒息或以其他方式对儿童造成躯体伤害，包括捏造或诱发疾病。

**情感虐待**是对儿童持续的情感上的不当对待，损害其情感发育，例如让儿童感到自己毫无价值或不被爱、恐吓儿童，或让儿童目睹他人遭受的虐待，包括家庭暴力。

**性虐待**是强迫或引诱儿童参与性活动，无论儿童是否意识到正在发生什么，包括接触性和非接触性活动，例如让儿童参与制作性图像。

**忽视**是持续未能满足儿童基本的生理或心理需要，可能损害儿童的健康或发育：例如未能提供足够的食物、衣物或住所，未能保护其免受危险，未能确保充分的看护，或未能确保其获得医疗照护。
:::

这四个类别来自《共同努力》。有几种重要的伤害形式横跨这些类别：

- **儿童性剥削**和**儿童犯罪剥削**，即儿童被胁迫或操纵参与性活动或犯罪活动，以换取儿童想要或需要的东西，或为施虐者谋利。“县界线”（county lines）毒品贩运是犯罪剥削的一种形式。
- **女性生殖器切割（FGM）**，在英国是违法的。
- **捏造或诱发的疾病**，即照护者报告、夸大或造成儿童的症状，导致不必要的医疗。
- **家庭暴力**，它伤害目睹、听到或经历家庭暴力的儿童。根据《2021年家庭暴力法》，儿童被承认为独立的受害者。

在英格兰，忽视是儿童被列入儿童保护计划最常见的原因。任何时候，英格兰约有50,000名儿童处于这样的计划中。

### 应引起关注的损伤

关于任何损伤的关键问题是：它是否与所给的解释和儿童的发育阶段相符。

::: theorem 损伤必须能由儿童的发育水平来解释 {#thm-mobility}
意外损伤发生在儿童自身活动的过程中，因此其模式与儿童能做的事相符。如果儿童不可能自己造成某一损伤，或损伤模式无法用儿童的活动解释，就需要另一种解释。
:::

::: proof
尚不会移动的婴儿不会摔倒、攀爬或撞到家具，因此这一群体的意外瘀伤很少见。一项针对常规就诊婴儿的研究发现，尚不会扶走的婴儿中只有约2%有瘀伤，更小的婴儿中更少，由此得出教学口诀“不会扶走，很少瘀伤”（those who don't cruise rarely bruise）。随着儿童开始爬、扶走和行走，瘀伤变得常见，但它们出现在身体前部的骨性突起处：胫前、膝部、前额、肘部。它们很少出现在面颊、耳、颈、腹部、臀部和背部等柔软、受保护的部位，而这些正是蓄意伤害的典型部位。同样的推理也适用于骨折：不会行走的婴儿发生长骨骨折，需要婴儿自己无法产生的外力。这就是为什么NICE CG89建议，任何尚不能独立移动的儿童出现瘀伤，以及此类儿童出现无医学解释的任何骨折，都应使临床医生怀疑受虐待。
:::

应引起关注的特征包括：

- **瘀伤**：见于尚不能独立移动的婴儿；位于耳、颈、面颊、躯干、臀部或生殖器；成簇出现、有图案（指尖、手掌、皮带或绳圈）或呈可辨认的形状；以及眼周或颈部的瘀点。
- **咬痕**，可能是人咬的且为成人大小。
- **烧伤和烫伤**：边缘锐利，呈手套或袜套样分布（浸烫），位于背部、臀部或足底，或呈烟头、熨斗等物体的形状。
- **骨折**：见于不会行走的儿童；肋骨骨折（尤其是后肋）、长骨干骺端骨折（“角状”骨折）、肩胛骨、胸骨或脊柱骨折；以及多处不同时期的骨折。
- **虐待性头部创伤**：婴儿硬膜下出血，常伴视网膜出血和脑病。可表现为呕吐、烦躁、惊厥、呼吸暂停或虚脱，有时没有外部损伤。
- **哨兵损伤**：小婴儿身上的轻微损伤，如一小处瘀伤或口腔损伤，出现在更严重的虐待之前。识别它们提供了预防进一步伤害的机会。

行为和环境也很重要：就医延迟、解释前后变化或与损伤不符、照护者出乎意料的反应、反复就诊、儿童退缩或恐惧、与年龄不相称的性化行为，以及错过健康预约。

### 看似虐待的情况

许多疾病可能被误认为虐待，临床医生必须考虑到它们。**先天性真皮黑素细胞增多症**（以前称为蒙古斑）在肤色较深的婴儿中很常见，出生时或出生后不久即存在；它在数天内不会变化，而瘀伤会变化。出血性疾病会引起容易瘀伤。**成骨不全症**、佝偻病和其他骨病会在受力很小时发生骨折。一些感染如脓疱疮可能看起来像烟头烫伤。拔罐或刮痧等文化习俗会留下痕迹。考虑这些情况并不意味着打消疑虑，而是意味着做正确的检查。

::: example 大腿肿胀的10周婴儿 {#ex-fracture}
杰登（Jayden）10周龄，因右大腿肿胀、换尿布时哭闹被带到急诊科。他母亲说他可能两天前把腿卡在了婴儿床的栏杆里。X线片显示股骨螺旋形骨折。他的左耳有一小处瘀伤。
::: solution
**为什么引起关注。**杰登不会移动，不可能靠自己的动作产生造成股骨骨折的力量。解释不相符：对这个年龄来说，腿卡在床栏里不是股骨螺旋形骨折的可信原因。就医有延迟。他还有一处耳部瘀伤，这是一个不会移动的婴儿身上受保护部位的瘀伤。

**即时照护。**镇痛和骨折的骨科处理。将他收住在安全的地方。

**转介。**与值班的上级儿科医生讨论，并按当地程序当天转介至儿童社会照护部门。随后的策略讨论可能会让警方参与。

**检查**，遵循英国皇家儿科与儿童健康学院和英国皇家放射科医师学院的建议：**骨骼检查**（11–14天后部分复查，届时愈合会使细微骨折可见）、**头颅CT**（因为1岁以下受虐婴儿隐匿性头部损伤很常见）、**眼科**检查视网膜出血，以及寻找其他解释的血液检查：全血细胞计数、凝血功能、骨代谢指标、维生素D和甲状旁腺激素。还需要考虑兄弟姐妹和家中的其他儿童。

**记录。**按母亲的原话记录病史、由谁提供以及时间，附人体示意图并对瘀伤进行测量描述。

**沟通。**以不带指责的方式如实向母亲解释正在发生什么以及原因。目的是确保杰登安全并弄清发生了什么，而不是提出指控。
:::
:::

::: warning 不要轻视婴儿身上的瘀伤
不能独立移动的婴儿身上的一小处瘀伤很容易被解释过去，尤其是当家庭态度友善、门诊又很忙的时候。不会移动的婴儿出现瘀伤并不常见，可能是严重虐待之前的哨兵损伤。NICE CG89建议，这种瘀伤应引起怀疑，大多数地区都有针对不会移动婴儿瘀伤的专门规程，要求进行儿科评估并与儿童社会照护部门讨论。漏诊的后果可能是婴儿的死亡。
:::

## 法定框架

::: definition 英格兰的法律与多机构实践 {#def-law}
**《1989年儿童法》**是主要法律。**第17条**规定地方当局有义务为**有需要的儿童**提供服务，即没有这些服务其健康或发育可能受损的儿童，或残障儿童。**第47条**要求地方当局在有合理理由怀疑某儿童正在遭受或可能遭受**重大伤害**时进行调查。

**《2004年儿童法》**规定各机构有合作的义务。**保护伙伴**（地方当局、整合照护委员会和警方）主导地方安排，具体见《共同努力保护儿童2023》。

**儿童保护计划**是在儿童保护会议上，当判断儿童持续面临重大伤害风险时商定的计划。
:::

临床医生有担忧时，通常的顺序是：

1. 与上级同事或指定的儿童保护专业人员**讨论**。不要等到确定无疑。
2. **转介**至儿童社会照护部门。如果儿童处于直接危险中，报警。电话转介后再提交书面转介，通常在48小时内。
3. 社会照护部门决定如何应对。这可能是需求评估、与警方和卫生部门的**策略讨论**，以及**第47条调查**。
4. 如果风险持续，**初次儿童保护会议**决定儿童是否需要儿童保护计划。
5. 在紧急情况下，法院可以发出**紧急保护令**，警方可以对儿童实施最长72小时的**警察保护**。

**信息共享。**临床医生常常担心保密问题。数据保护法并不阻止为保护儿童而共享信息。在可能的情况下，向家庭说明你正在共享信息及其原因，除非这样做会使儿童面临更大风险或妨碍调查。记录共享了什么、与谁共享以及原因。

**FGM。**自2015年起，英格兰和威尔士受监管的卫生和社会照护专业人员及教师负有**强制义务**，凡在工作中发现18岁以下女孩遭受FGM（无论是女孩告知还是看到身体征象），都须向警方报告。这项义务是个人义务，不能委托他人。

### 记录

良好的记录既保护儿童，也保护临床医生。当时书写，注明日期并签名，记录：

- 由谁提供病史，用其原话，以及还有谁在场；
- 儿童本人的陈述，如有则用其原话，不提诱导性问题；
- 检查发现，包括测量值、人体示意图，必要时经同意进行医学摄影；
- 你的判断及理由，以及你做了什么，包括你和谁交谈过。

不要就疑似虐待详细询问儿童。如果儿童披露，要倾听、安抚，不承诺保密，记录所说内容，然后转介。正式询问由经过培训的警察和社会工作者进行。

::: example 反复尿路感染的15岁女孩 {#ex-exploit}
沙妮丝（Shanice）15岁，两个月内因泌尿系统症状三次到全科医生处就诊。今天她拿着一部新的昂贵手机，最近缺课，问诊期间不断收到信息并焦虑地查看。被问到时，她说有个24岁的男朋友“照顾她”，她有时住在他朋友的公寓里。
::: solution
**识别。**反复的泌尿生殖系统症状、年长的男朋友、礼物、缺课、不在家过夜以及通过手机被控制，都是**儿童性剥削**的指征。24岁的人与15岁的人之间的性活动是刑事犯罪。

**临床照护。**进行性传播感染和妊娠检测，治疗感染，并讨论避孕。沙妮丝可能有能力同意这些照护。

**与沙妮丝交谈。**单独与她交谈。被剥削的年轻人常把施虐者视为男朋友，并不认为自己是受害者，因此要避免指责。说明你担心她的安全，需要分享你的担忧。

**转介。**当天转介至儿童社会照护部门，并与诊所的儿童保护负责人讨论。可能需要通过当地程序通知警方。清楚地记录各项指征。

**之后。**保持大门敞开。与临床医生的信任关系可以起到保护作用，如果她受到尊重，她更可能再回来。
:::
:::

## 忽视、捏造的疾病及其后果

::: example 反复胸部感染的3岁孩子 {#ex-neglect}
凯（Kai）3岁，一年内因胸部感染和喘息急诊就诊六次。他的预防用吸入器很少被领取。他的体重从第25百分位降到第2百分位。他有未治疗的龋齿，言语发育迟缓。他母亲正在与抑郁症抗争，家里的公寓潮湿。错过了儿科门诊和牙科的两次预约。
::: solution
**识别。**这一模式是**忽视**：医疗需要未得到满足（处方未领取、错过预约、龋齿未治疗）、生长迟滞、发育迟缓以及恶劣的生活条件。忽视是持续性和累积性的，要通过随时间变化的模式而不是单一事件来识别。

**背景。**他母亲的抑郁症和住房问题很可能是促成因素。忽视并不总是故意的，但重要的是对儿童的影响。理解原因有助于找到正确的支持。

**行动。**治疗他的哮喘，安排牙科治疗。描绘他的生长曲线并评估发育。坦诚地与他母亲讨论这些担忧以及她自己的健康。转介至儿童社会照护部门，可以是依据第17条进行需求评估，如果伤害重大且持续，则进行第47条调查。与全科医生和健康访视员共享信息。不要简单地让错过预约的儿童出院：对儿童来说，正确的描述是“没有被带来”（was not brought），这是一个儿童保护信号。
:::
:::

**捏造或诱发的疾病（FII）**是指照护者通过虚假报告症状、夸大、伪造检查结果，或罕见情况下诱发疾病（例如投毒或使窒息），使儿童被认为比实际病得更重。英国皇家儿科与儿童健康学院的指南（2021）强调**令人困惑的表现**这一概念：症状不符合任何已知疾病，并对儿童造成明显有害的后果。应对措施是协调照护、确定儿童的实际健康状况、停止不必要的检查和治疗，并在伤害正在发生时进行儿童保护转介。

::: definition 虐待的影响与创伤知情照护 {#def-impact}
**童年不良经历（ACEs）**是童年时期的应激性或创伤性事件，如虐待、忽视、家庭暴力、父母精神疾病或物质滥用。它们与成年后较差的躯体和心理健康相关。

**创伤知情实践**是一种认识到创伤对人们的行为及其对服务的反应之影响的方法，旨在避免再次造成创伤，例如提供选择、说明将要发生什么以及建立信任。

**受照管儿童**是由地方当局照管的儿童。受照管儿童的躯体、发育和心理健康需要比例更高，在进入照管时和此后定期进行法定健康评估。
:::

虐待和忽视对儿童的影响在伤害停止后仍长期存在。慢性应激会改变发育中的大脑和应激反应系统。儿童可能表现为焦虑、攻击性、注意力和人际关系困难、发育迟缓或学业失败。与一位关爱他们的成年人建立支持性关系是最有力的保护因素，协调良好的服务可以带来很大改变。

::: example 幼儿双足的烧伤 {#ex-burns}
一名学校护士转介了2岁的阿米拉（Amira），她的保姆注意到她双足皮肤发红、脱皮。她父亲说她踩进了热洗澡水里。检查发现双足烧伤，上缘锐利，在双踝同一水平，而接触浴缸的足底未受累。
::: solution
**模式。**双足对称烧伤，上缘呈锐利的“袜套”样且在同一水平，并且压在浴缸上的皮肤未受累，这是**强迫浸烫**的典型表现。意外踩进热水的儿童会迅速缩回，造成边缘不规则、伴飞溅痕迹的烧伤，通常只在一只脚上。

**鉴别诊断。**应考虑感染（例如葡萄球菌烫伤样皮肤综合征）或皮肤病，但其形状和对称性强烈提示蓄意伤害。

**行动。**评估和治疗烧伤，并转诊至烧伤专科。与上级儿科医生讨论，当天转介至儿童社会照护部门。记录描述、测量值和照片。对有可疑烧伤的2岁以下儿童考虑进行骨骼检查，并考虑家中的其他儿童。
:::
:::

caption: 仅为示意数值。假设一组受伤婴儿中有5%受到虐待，某一发现见于一半的受虐婴儿，但只见于2%的其他婴儿。那么这一发现是引起关注的有力理由，但不是证据。降低特异度，可以看到一项在意外损伤中常见的发现所增加的信息要少得多。这就是为什么临床医生要权衡全局，并在怀疑时而不是确定时转介。
:::

::: quiz
一名4月龄婴儿因咳嗽被带到全科医生处。医生注意到婴儿面颊上有一处1 cm的瘀伤。母亲说可能是婴儿的哥哥姐姐弄的。最恰当的应对是什么？
- [ ] 接受这一解释，因为兄弟姐妹常会弄伤婴儿，并记录下来。
- [ ] 请母亲在出现更多瘀伤时再来。
- [x] 遵循当地针对不会移动婴儿瘀伤的规程：安排当天儿科评估，并与儿童社会照护部门讨论。
- [ ] 做凝血功能检查，待结果出来后再决定是否转介。
::: solution
根据NICE CG89，尚不能独立移动的婴儿在面颊等受保护部位出现瘀伤，应引起怀疑。这一解释可能是真的，但应由儿科医生评估，考虑相关检查，并按当地规程与社会照护部门讨论。等待出现更多瘀伤有造成严重伤害的风险。
:::
:::

::: history
1946年，美国放射科医生约翰·卡菲（John Caffey）描述了患有硬膜下血肿和不明原因长骨骨折的婴儿。1962年，C. 亨利·肯普（C. Henry Kempe）及其同事在JAMA上发表了《受虐儿童综合征》，促使美国各地制定了要求报告疑似虐待的法律。在英国，1973年玛丽亚·科尔韦尔（Maria Colwell）之死引发了一次公开调查，并促成了地区儿童保护委员会的设立。《1989年儿童法》建立了英格兰至今仍在使用的框架，包括重大伤害的概念。2000年，维多利亚·克林比（Victoria Climbié）在与多个机构有过接触的情况下死亡，由此产生了莱明勋爵（Lord Laming）2003年的调查报告、“每个孩子都重要”（Every Child Matters）计划和《2004年儿童法》。2007年彼得·康奈利（Peter Connelly）之死促成了进一步改革，《共同努力保护儿童》指南也经过多次修订，最近一次是在2023年。
:::

::: summary
- 儿童保护是每个临床医生的责任：识别、记录、转介。
- 四个类别是躯体虐待、情感虐待、性虐待和忽视；剥削、FGM、捏造或诱发的疾病以及家庭暴力横跨这些类别。
- 损伤必须与解释和儿童的发育相符：“不会扶走，很少瘀伤”。不会移动的婴儿出现瘀伤或骨折需要评估。
- 令人担忧的模式包括受保护部位的瘀伤、有图案的瘀伤、浸烫、后肋骨折和干骺端骨折，以及伴视网膜出血的硬膜下出血。
- 对幼儿疑似躯体虐待的检查包括骨骼检查、头颅CT（1岁以下）、眼科检查以及寻找其他原因的血液检查。
- 在英格兰，《1989年儿童法》第47条要求在怀疑重大伤害时进行调查；《共同努力2023》规定了多机构安排。
- 18岁以下的FGM必须由发现它的专业人员向警方报告。
- 准确记录，不要详细询问儿童，为保护儿童而共享信息。
- 忽视要通过随时间变化的模式来识别；“没有被带来”是一个儿童保护信号。
:::

## 习题

::: exercise 四个类别 {level=1}
说出《共同努力》中虐待和忽视的四个类别，并各举一例。
::: solution
躯体虐待（例如摇晃婴儿）；情感虐待（例如持续贬低，或让儿童目睹家庭暴力）；性虐待（例如让儿童参与制作性图像）；忽视（例如未能获得医疗照护或提供足够的食物）。
:::
:::

::: exercise 令人担忧的瘀伤 {level=1}
列出儿童瘀伤中应引起对虐待关注的四个特征。
::: solution
尚不能独立移动的儿童出现任何瘀伤；位于受保护部位（耳、颈、面颊、躯干、臀部、生殖器）的瘀伤；成簇或有图案的瘀伤（指尖、手掌、器具）；以及与解释或儿童发育不符的瘀伤。眼周或颈部的瘀点也令人担忧。
:::
:::

::: exercise 报告FGM的义务 {level=1}
一名16岁女孩告诉护士，她8岁时接受了FGM。护士必须做什么？
::: solution
根据英格兰和威尔士的强制报告义务，由于女孩未满18岁并披露了FGM，护士必须亲自向警方报告，通常拨打101，最好在下一个工作日结束前报告。护士还应遵循当地儿童保护程序，考虑女孩的妹妹们，提供医疗照护和支持，并向女孩说明接下来会发生什么。
:::
:::

::: exercise 错过的预约 {level=2}
一名5岁1型糖尿病儿童已错过三次门诊预约。门诊的常规政策是错过两次预约后让患者出院。应该怎么做？
::: solution
儿童不会自己来就诊，因此正确的描述是“没有被带来”。对于患有严重疾病的儿童，错过预约可能意味着医疗需要未得到满足，这可能是忽视的征象。团队应联系家庭了解原因，与全科医生和学校核实，查看近期的HbA1c和住院情况，并提供灵活的预约时间。如果担忧持续，与儿童保护负责人讨论，并考虑转介至儿童社会照护部门。不应简单地让该儿童出院。
:::
:::

::: exercise 瘀伤还是胎记？ {level=2}
一名孟加拉裔6月龄女婴的下背部和臀部有一片蓝灰色区域。健康访视员担心是瘀伤。你如何区分先天性真皮黑素细胞增多症和瘀伤？
::: solution
先天性真皮黑素细胞增多症在出生时或出生后最初几周即存在，在肤色较深的婴儿中常见，通常为蓝灰色、边界不清，位于下背部和臀部，无压痛，数天内颜色不变。瘀伤常有压痛，可能肿胀，愈合过程中数天内颜色会变化。查看新生儿和健康访视员的记录，并在几天后再次检查该区域会有帮助。在新生儿检查时记录胎记可以避免日后混淆。
:::
:::

::: exercise 骨骼检查的时间 {level=2 check="11"}
建议在首次骨骼检查后11–14天进行复查。复查最早应在首次检查后第几天进行？
::: solution
**11天。**到那时，愈合（骨膜反应和骨痂）会使首次检查时看不到的骨折，如肋骨骨折和干骺端骨折，更可能被看到。
:::
:::

::: exercise 门诊中的披露 {level=3}
在一次哮喘复诊中，一名11岁男孩说他母亲的伴侣用皮带打他，并说他不能告诉任何人。他请你承诺不告诉别人。逐步说明你会如何回应。
::: solution
**倾听。**保持冷静，让他说，不提诱导性问题，不追问细节。

**安抚。**告诉他告诉你是对的，这不是他的错。

**诚实。**不要承诺保密。说明你需要告诉那些负责保护他安全的人，并尽可能说明接下来会发生什么。

**评估即时安全。**询问他今天回家是否安全。如果他处于直接危险中，联系警方。

**检查**有无损伤，须经他同意并有陪护人员在场，并在人体示意图上记录。

**记录**他用自己的话所说的内容，注明日期和时间。

**转介**：当天转介至儿童社会照护部门，并与儿童保护负责人讨论。不要与母亲的伴侣讨论这一指控，在与母亲讨论之前先征求意见，以免使他面临风险或妨碍调查。
:::
:::

::: exercise 令人困惑的表现 {level=3}
一名7岁女孩两年内因报告的惊厥、食物不耐受和疲乏看过六位专科医生。没有任何检查找到病因。她母亲要求轮椅和胃造口。孩子很少上学。讨论团队应如何处理。
::: solution
**识别模式。**症状不符合已知疾病、大量检查无发现、对干预措施的要求不断升级，以及对儿童的伤害（失学、活动受限、有创操作的风险），符合英国皇家儿科与儿童健康学院所描述的**令人困惑的表现**，其中可能包括捏造或诱发的疾病。

**协调照护。**指定一名主管顾问医师。把所有专科医生的记录汇集成一份时间线。与全科医生和学校召开专业人员会议。

**确定儿童的实际健康状况。**使用客观证据：例如针对所报告的惊厥进行视频脑电图监测，在医院或学校观察进食，以及学校关于她活动情况的报告。避免进一步进行没有临床指征的检查和操作。

**沟通。**与父母坦诚讨论发现了什么、没有发现什么，并制订让孩子康复的计划（复学、恢复正常活动）。

**儿童保护。**如果儿童正在受到伤害，或有捏造或诱发疾病的迹象，与指定医生讨论并转介至儿童社会照护部门。自始至终的重点是儿童的健康和福祉，而不是证明照护者的动机。
:::
