儿童的保护是儿科学的那一部分：在它的鉴别诊断里包括房间里的成年人。保护学的实务意味着识别身体的、性的与情感的虐待及忽视；像对待任何疾病那样透彻地理解它们发展的后果；知道那法律的与多机构的骨架；并知道那对家庭的长期的伤害——以及对那些没能被保护的孩子的那种诚实。

## 识别

::: definition 虐待与忽视的模式 {#def-recognise}
**身体的虐待靠不相符来识别：与所给出的机制不相符的损伤；那些没有出现在把这名孩子带来就诊的病史里的损伤；发育的不可能（一个3个月的孩子不会翻滚动到火里）；分布（在一个还不会移动的婴儿身上的瘀伤是一项危险信号的伤害，需要同一天内资深的评估与调查；而在一个会动的孩子身上，躯干与耳及颈部及生殖器区域的瘀伤，仅凭位置就可疑）；以及模式（抓痕、圈的痕迹、某一件具体物品的印记）。骨骼的普查与头部的影像，以及为视网膜的出血而做的那次眼科的检查，属于转诊的那条路径、不属于鉴别诊断的那场辩论——检查是为了保护、为了给损伤定年代而做。而那一组模仿者（成骨的不全，包括看起来不像非意外的类型；一种酸的尿的异常；出血的疾病；以及刮的与拔的罐的文化的做法——它们留下特征性的对称的痕迹，应当引出一场谈话、而不是自动的一次转诊），是儿科的保护的团队的工作、不是一位忧虑资浅者的工作。忽视是被证实的最常见的类别，也是在床边最难定义的：它是一个模式、不是一张快照——反复的成长停滞（份成长的曲线就是它的文件）；慢性未治疗的疾病；因照护不足而造成的反复的损伤；毒性家庭的指标（药物的滥用；被孩子们目击家内的暴力；以及父母的心理的疾病与学习的障碍）；以及学校与健康的服务在多年里支撑着一个家庭，却没有人把证据加起来。性虐待在绝大多数的案例里让一次医学的检查是正常的——正常的检查不是什么都没有发生的证据；而它的识别是行为的与叙事的：与年龄不符的性化的行为与语言；一个孩子身上新发性传播的感染（一个青春期前孩子的感染，在被证明之前就是虐待）；段在几个月里以碎片的方式展开、并由时间来检验的披露；以及青少年被剥削的那个模式——在其中，一个14岁的人对一个27岁的人表面的同意，按法律与发育的现实就是剥削。情感的虐待是那恒常的共存的项——其他的每一个类别都包含着它；而它是由孩子的需求与照护者的能力之间的差距来诊断的，通过发育的监护与学校的观察来记录、不通过任何单一体征。致命与非致命的窒息（呼吸暂停的就诊与“我抱着他时他变软了”的故事及一个之前受伤过的同胞）补全了那份目录。统一临床的习惯：总是在一位陪同的人在场时检查整个孩子；当说法分歧时，总是对每一位照护者分别取一份病史；总是把成长的曲线与就诊的时间表当作文件来查看；以及在一个班结束之前，总是问：“为什么是现在？为什么是这个？这个家里还有什么？”[[paediatrics/acute-childhood-illness]]、[[paediatrics/newborn]]、[[psychiatry/psychiatric-assessment]]。**
:::

## 法律的骨架

::: definition 法律、阈值与多机构的实务 {#def-law}
**框架是：保护儿童的份跨部门的指南：需求的三个层次（健康的、正在升级的、以及有严重的伤害的风险的）；四项法定的评估（早期的帮助、有需要的儿童、处于保护之下的儿童的调查、以及照护的程序）；以及那通过多机构保护的中枢来运行跨部门的安排——转诊的决定在那里被分诊；还有儿童保护的会议，而其类别与计划常由儿科医师主持或起草。临床医师的职责是具体的：任何有担忧的专业人员都要转诊——这份职责不要求个人的、能证明伤害的证据；一次法定评估需要在被定义的时间之内有医学的输入；在保护计划上的儿童有复查的间隔；而严重的病例的复盘（如今是儿童的死亡的复盘与从死亡案例中学习的实务）三十年来在重复同样的发现：跨部门沟通的失败；“乐观的规则”；以及那份从未把这个孩子包含进去的、以成人为中心的历史。实务的机制：一份转诊是一份书面的记述：观察到什么、说了什么（用引号），以及为什么它让你担忧，并记录这个家庭的观点；除非会造成对孩子的伤害，你会把一次转诊通知父母（而当不通知时，记录下为什么）；警方与儿童的社会的照护联合的访谈使用那套为证据而设计的访谈的框架，而不是重复的、被医学化的讯问；而关于违背父母宗教的反对为孩子治疗、为一位拒绝输血的少年决定、或是一位16岁之下的人要求的与那一种切割相关检查的能力与同意的问题，由法庭与最佳利益的分析来决定、不是由最后喊得最大声的人来决定。保密对共享是每日的谈判：当一个孩子处于危险中时，信息就被共享——数据保护的法律包含着明确的通路，而儿童的设计的守则的那个年代已经把这个问题定下来了：数据保护不是不做保护的理由；所以转诊不等同意，而对于一份职责也不请求同意。跨界的情形——家庭会前往让某种切割或儿童的婚姻或别的同意年龄成为常态的国家的孩子——要求同一套本地的法律带着文化的素养被应用：对这一做法零容忍，而这个孩子与这个家庭的信任要最大程度地呵护，以及具体的法定的工具（一种伤害的预防的令状与那份奴隶制转向的通知——它被用来辅助、而不是取代专业的判断）。阈值的一句话说：如果你在问一位同事“这该转诊吗？”，那么它就是——份不确定本身就是那个发现；而那个分诊的存在，正是为了吸收那份不确定、而不是为了惩罚它[[medical-ethics-law/confidentiality]]、[[public-health/determinants-inequalities]]、[[paediatrics/growth-development]]。**
:::

## 后果与修复

::: definition 发育的影响、带着创伤的知识的实务与那条长尾 {#def-impact}
**不良的童年的经历被像危险因素那样测量，因为它们的行为就像危险因素：与缺血的心脏的病与慢性的阻塞的肺的病及抑郁及药物的依赖及过早的死亡的剂量相关的关联；其媒介是毒性的应激的生理与稳态的负荷，以及被中断的学业与家庭的不稳定的社会的通路。但人群水平效应的量并不描述这一个孩子：复原力是真实的；被保护的关系是恢复的最强的预测者；而临床的任务是让这个孩子的下一些经历是可预期的、身体上是安全的、并在叙述上是连贯的。所以带着创伤的知识的实务不是一种咨询的技术、而是一种服务的设计：在属于虐待的领域的每一次检查之前征求同意；由一位儿科医师配一名专门的受训者来给青春期的前的孩子做检查，而不在每一个机构重复检查；对更小的孩子的披露使用游戏与绘画、而不是讯问；避免那台会造成再次创伤医学的跑步机；以及用确切的词向一位15岁的人解释一次法医学的检查包含什么——因为含糊比细节更糟。门诊实际在管理发育的后遗症：依恋的障碍，以及在曾被机构照护孩子身上的不加选择的类型；混乱带来的学习与注意的后果——它们常被错贴为注意缺陷的障碍这个诊断是两者都有、不是二选一，而把它当作一种来治就会输；解离与自我伤害，以及在被虐待的人群里被过度代表进食的障碍（见[[psychiatry/eating-personality-disorders]]）；青少年那种性化的行为——它是一个症状、不是一个行为的问题；以及那条生长曲线的下降——在它被反驳之前，它是忽视的那个身体的征象。长期的健康系统会为童年的逆境付三种货币：成人心理健康的使用、慢性疾病的负担、以及那代际的传递——早期干预抚育的方案与那对父亲与母亲的家内的暴力的工作，正在第三代之前对它下手。修复的那一面更慢、但是被记录的：在安全时的重新团聚；亲属的照护的那份“有爱而缺资源”的混合的成绩单；以及被照管的孩子的健康计划——在大多数的地区它们是空壳：一次“被照管的孩子在最近6个月里得到过一次完整的评估”的审计，通常是一个令人难堪的数字；而儿科医师应当把它公布出来——因为统计里的孩子，正是第一次没能及时被发现被虐待的“[[paediatrics/neurodevelopment]]、[[public-health/determinants-inequalities]]、[[psychiatry/lifespan-psychiatry]]。**
:::

::: example 那个“股骨骨折的10周的孩子” {#ex-fracture}
一名10周的孩子，第一胎；“从换尿台掉到了地上”；X线上股骨干无移位的骨折；而父母平静而说法一致，并说“祖父母明天就来帮忙”。
::: solution
**一项危险信号的伤害，配一条可以安排的道路（[[#def-recognise]]、[[#def-law]]）：一个10周的孩子股骨的骨折，无论那份说法多么一致，都是一起保护的急症——所给出的机制在这个年龄不会产生这一损伤；而计划作为一个过程推进、而不是作为一个判决：即刻收住在正确的保护之下（这个孩子留在医院里，直到评估完成——这是照护、不是指控，而要对父母这么说）；完整骨骼的普查并在2周时用后续的影像来为其他的损伤定年代；在各自专科的窗口之内完成头部的影像与眼科；通过血液排除出血的与骨代谢的模仿者；以及当天的转诊，并与社会的照护及警方讨论那份策略。这个过程需要的证据：在第一年就分别访谈每一位照护者，问那次跌落——“当时谁在看这个孩子？换尿台是什么位置？落在什么面上？”——因为被第一份说法排练过的细节很少能对上，而那份改过两次的病史就是数据；用一字不差的引语加上身体的地图与每一处痕迹的身体示意图来记录；把成长的曲线以及产前的与出生的记录好好地读一遍；并带着那张家系图评估这个家庭的支持与应激源。父母会对你保持礼貌——因为他们认识孩子在上周被来访的帮工弄伤了的家庭——这正是为什么这次评估是一个有日期与任务的过程、而不是屋子里的一种感觉。出院只能出到一份由团队写好安全的计划上；而儿科的报告将决定这个婴儿是回家、还是进入亲属的照护或寄养——这就是为什么那份报告要像证据一样被写，因为它就是证据[[paediatrics/acute-childhood-illness]]、[[musculoskeletal/fractures]]。**
:::

::: example 那个“反复尿路感染的15岁” {#ex-exploit}
一名15岁，一年内四次因“尿路感染”与脱水收住；一位每次收住都来、并替她回答的“男朋友”；三次被学校劝离；而那份成长的曲线显示8个月里体重下降了4公斤。
::: solution
**穿着医学的衣服的剥削（[[#def-recognise]]、[[#def-law]]）：这个模式就是诊断——一个青少年反复的、医学上未解释的或反复复发的就诊；一位总在场的、控制性年长的伴侣；体重的下降；学校的坍塌；以及没有人把它们联系起来的劝离，就是那幅经典的犯罪的剥削或胁迫的关系的图景（药物的网络与性的剥削的团伙都靠关注来招募，并恰好产出这种“难缠的就诊者”的表型）。而这次收住就是干预：在第一小时之内单独见她（“这是对所有青少年的常规，是我们评估的一部分”——而不是“医师想和你私下谈谈）”；以事实的方式问剥削筛查的提问：他知道你花了多少钱吗；你去哪里；谁在付手机的话费；他有没有拿走你的手机；你是不是欠着谁的钱；这个月你有没有为他去过另一座城镇；有没有人给你拍过照片或录过像；当你说不的时候会发生什么。把披露一字不差地记录；筛查身体的与性的健康的需求（妊娠与性传播的感染及损伤及药物的使用）；并转诊到剥削的那条路径——当地的线的方案与儿童的社会的照护，以及那套转诊的机制（份国家转诊的名录，因为它会启动一个法定受害者的身份）。不要要求她指控任何人——把那份关于她的生活的陈述（部手机里的账单与缺失的时间及被记录的体重）当作证据来呈现，把它们作为保护学的事实来记录。最后，统筹：一位具名的临床医师；学校被告知那最低的必要；警方在剥削的框架之下、带着她的理解被通知；以及一份关于生活的提供——外展的工作者，以及那句“你有麻烦”的反面：“你没有麻烦，你是被利用了——因为这是这一章最古老的那份职责的现代的面孔：看见那个系统几乎一直看见、却始终没有看见的孩子”[[paediatrics/adolescent-health]]、[[paediatrics/safeguarding]]。**
:::

::: example 那个“反复胸部感染的3岁” {#ex-ftrace}
一名3岁，18个月里四次因“吸入的肺炎”收住，从未被调查过；母亲是医院的一位志愿者，叫得出各位顾问医师的名字，并且每次收住都留下来过夜；而这个孩子在第一年的第50百分位之后，沿着第25百分位在生长；而血氧“下降”只在被观察的时候。
::: solution
**以完美的就诊者的面貌来表现的被捏造的或被诱发的疾病（[[#def-recognise]]）：这个模式——”三联：（甲）只在照护者在场时出现的症状；（乙）一位异常地被医学化、又异常地配合的照护者；以及（丙）一个病历悄悄地下滑的孩子——就是这个综合征的签名；而四次收住之后仍然没有一个诊断，本身就是一项值得被加起来的发现。方法——“不对峙，也不制造新的一串侵入的检查；一位统筹的顾问医师；一次完整纵向记录的回看从没有其他医院被请求过的”报告“)；而如果怀疑仍然存在、伤害是可信的——在儿科与警方的共同的保护的治理之下，做一次被结构化的住院的观察或摄像的研究；因为分离之后的恢复与只在独处时的症状，是任何争辩都打不赢的数据。伦理的那条线：这是由那个通常也正是孩子的主要的照护者、并且常常自己也很痛苦的人实施的虐待——处理是对这个孩子的保护，加上对这个家长的精神的与心理的帮助，按这个顺序；绝不用那句会终结职业生涯与家庭的那个诊断的笑话。即刻的规则——”不再为一份没有诊断的诊断去做带风险的操作；把学校与托幼的健康的记录调出来，因为哮喘的发作在别处从不发生；而被照管的兄弟姐妹的记录也要被查看，以及在策略的会议上会被提出的那个提问；以及一份会随这个家庭一起迁移的模式记录，因为这一综合征会在搬迁之后复发。给那位忧虑的住院医师的那句话：“你并不是一个糟糕的医师，因为你治疗过这一次肺炎；如果你第五次收住她而不问为什么只有你看得见它，你就会成为那样一个医师。”[[respiratory/respiratory-infections]]、[[clinical-skills/clinical-reasoning]]。**
:::

::: example 那位学校护士的“只是皮肤很差的转诊” {#ex-burns}
一名5岁因持续的“湿疹”被转诊：它是双侧的、对称的、边界清楚的，并避开了臀部那些会被沐浴液冲到的区域；学校说“她从不在外面玩”；而母亲说“皮肤是我们家的肥皂弄的”。
::: solution
**伪装成皮炎的那处烫伤（[[#def-recognise]]、[[#def-law]]）：形态——“一处边界清楚、对称的臀部的烫伤，带着一条清晰的被避开的边界——是孩子被从热水里提起或被按在热的表面上时的位置——就是经典的浸泡的或接触的烫伤的模式；而一处形状固定的、对治疗从不响应的“湿疹”，在皮肤科与儿科一致同意之前就是一处烫伤；边界本身，就是病史。回应——”当天内资深者儿科的复查，并按本地的政策拍照；关于洗澡与取暖的提问以事实的方式、并在几天里反复地问（洗澡水的温度与热水器以及她睡在哪里）；完整皮肤的普查与损伤的普查；以及单凭这个形状就足以成立的那份转诊——这一模式与肥皂不相容。情景——“那个从不在外面玩的孩子，与学校那份安静的、对小问题的积累，就是复盘的报告总会提到的”加起来“；而转诊正是让学校的观察与全科的出勤的数据以及这片皮肤变成一份文件的地方。语气——”被虐待的孩子的父母大约会与无罪的家长同样频繁地平静而连贯地、带着可信的解释来呈现；而说法的一致不是无罪的证据。处烫伤才是证据：检查这个孩子、而不是检查这场访谈“[[paediatrics/acute-childhood-illness]]、[[musculoskeletal/skin]]。**
:::

**小腿与耳朵（[[#def-recognise]]）：”一个正在扶走的11个月孩子小腿的瘀伤，是童年里最正常的那种损伤；而耳与面的瘀伤不是：2岁之下的孩子的耳与颈部及面颊的瘀伤，是一项处于令人担忧位置的发现，需要当天内资深儿科的评估。而正确的电话的建议是：“你今天就要看到他——如果你无法完成检查，或者那份说法一直缺席，我来查；因为一处可信的瘀伤加上一处不可信的瘀伤的组合是经典的混合的图景，而那一处可信的瘀伤常常正是被主动提供的那一处。要记录什么：确切的描述；身体的地图；每一位照护者为每一处瘀伤给出的日期；以及发育的病史。不要做什么：“不要在电话里把那个”也许是“接过来当作你自己的结论；也不要在没有检查的情况下给予安心——因为下一次就诊，可能正是需要这份记录才能被理解的那一次”[[paediatrics/acute-childhood-illness]]、[[clinical-skills/communication]]。**

::: exercise 为那一种女性生殖器切割做筛查 {level=1}
一名在英国出生、家庭来自一个高流行国家的9岁的女孩，在入学前的接种的门诊就诊；年长的同胞在5年前被医院记录了那一种切割；而父母提到了6周之后的家庭的“回乡的假期”。三个强制的或最佳实务的步骤？以及那份报告的职责？
::: solution
**那个预防的窗口（[[#def-recognise]]、[[#def-law]]）：份职责是即刻的、并且是被命名的：一项强制报告的要求规定，一位了解到一名18岁之下的女孩已经被实施了切割（被记录的程序或一次披露）的注册的专业人员，必须在一个月之内通过那条官方的通路亲自向警方报告。在这里，那位年长的同胞的被记录的切割与这个家庭的计划把风险挑明了；而那份职责适用于被确诊的病例，而风险的例要通过保护的转诊来处理——这两条路径并行：（甲）把这个家庭的切割的病史与那个假期的计划记在儿童健康的记录里，并给两家全科都设上标记；（乙）现在就做一份保护的转诊；（丙）安排一次儿科的或专门的门诊的谈话，向这个家庭解释那法律与危害，并把那个假期与那项承诺直接地问出来。份健康记录的那一项旗子与那一次对姐姐的复核；以及给那位女孩的一次未来的产科与性的健康的通路。句要被说出来的话：“如果我不说出来，我就是辜负了这个女孩；而我会温和而清楚地说出来。绝不要：”把一个来自高流行国家的家庭记录成一份已经完成的风险的评估；也绝不让那个假期的提问因为难为情而不被问——一段执行的历史，大多是专业人员在正是这个时刻保持礼貌的声音”[[paediatrics/immunisation]]、[[public-health/global-health]]。**
:::

::: exercise 教练那位“没有转诊”的资浅医师 {level=2}
你们病房上的一位基础科的医师在交班时告诉你：“上个月那个瘀伤的病例我有一种担忧，而我没有转诊，因为父母太讲道理了，而我觉得自己在过度反应——我一直在想这件事。”请作为教育者与保护学的负责人及一个人来回应。
::: solution
**一次可以教学的未转诊（[[#def-law]]）：先是那份职责——既然这个病例被认出来了，那么它今天就要被复查：重新读这个孩子的档案；把那一份缺失的转诊追溯性地补上，并记录下这次延误；并通过保护学的团队对这个孩子目前的处境做一次安全的检查。对一位同事迟疑的隐瞒本身就是一项风险。然后是那件能防止下一次发生的教练：把那个机制命名出来——“乐观的规则”与“讲道理家长的启发法”，正是每一份严重病例复盘所列的偏差；教那条阈值的规则：“如果你在问要不要转诊，就转诊——那个分诊的存在就是为了给你们的分诊你们的犹豫，而它宁愿听到它、也不愿等到那间复盘的会议室”；那个记录的习惯：“把那份担忧在同一个班内写下来，即使你最后不转诊”；以及关于那位担忧的医师的保护学负责人的话：“谢谢你告诉我；我们会一起把这一例修好；没有人会因为迟疑而被惩罚——只会因为沉默，而你刚刚选择了相反的那一样”。最后是系统：这个部门的审计应当问：有多少个“我犹豫过”的时刻没有被记录下来；而这个问题只有被反复地询问才能找到答案——这正是一种公正的文化的保护学系统存在的目的[[clinical-skills/patient-safety]]。**

::: exercise 建造这家医院的“不到访的孩子的方案” {level=3}
::: solution
**不到访的安全的方案（[[#def-law]]、[[public-health/health-systems-economics]]）：重构——“一个已经被服务认识孩子一次错过的门诊不是一个行政的问题；它要么是一个小小保护的信号，要么是一个大大信号的开端；而每一份严重病例的复盘都把“这家人没有来”当作一个句子来用、不是一个发现来用。数据的那条脊柱：一份自动把出勤与保护的计划及被照管的身份链接起来的名册（面旗必须在看病的系统里、不是在某个人的脑子里）；按风险层次的不到访的阈值——对于一个在计划上的孩子，一次错过核心的门诊会触发同一周电话的确认，以及由健康的访问员或统筹者的两次登门的家访；而这次确认要被记录为照护、不是记录为行政。交通的手段：同一个具名的人来打电话；在第一次尝试时就用短信与信件和电话并行，并记录尝试而不仅仅是尝试过。成功的指标：那个趋向于零的指标——每一个被标记的孩子在最近若干个月里都有一次被确认的人类的接触——因为那份提示里的那例可被复盘的死亡，并不是被一次错过门诊造成的；它是由三年里没有任何一位专业人员能够说出“我最后一次见到这个孩子是在这一天”造成的[[paediatrics/growth-development]]、[[clinical-skills/records-handover]]。**

## 通向何处

急症的识别接上[[paediatrics/acute-childhood-illness]]与[[paediatrics/newborn]]，发育的后果接上[[paediatrics/neurodevelopment]]与[[paediatrics/adolescent-health]]，信息共享的伦理接上[[medical-ethics-law/confidentiality]]，而人口的那一层接上[[public-health/determinants-inequalities]]。

::: history
**现代的保护学是被孩子们的死亡写下的：1945年那一份第一次告诉医师们要留意虐待的通函；以及1962年那篇创造了“被殴打的孩子”、把一簇放射学的发现转化成一个被命名的综合征与一场必须谈话的论文。1973年那个女孩的死亡，它的复盘产出了第一份要求专业人员彼此交谈的指导；1980年代的那几个病例的复盘重复了同一个发现——社会的工作者与医师们未能把孩子们当作一个个个体来看。2000年那名女孩的死亡，它的那份报告建立了现代的建筑：具名的孩子与每一个机构都要负责，以及那份每个儿童都重要的立法；2007年那个“宝宝P”与那个严重的保护的复盘的时代，带着它那份60次专业的接触却从未被加起来的目录；以及2012年那个男孩，他的复盘里令人定罪的细节——一个偷偷地在垃圾桶边找吃的孩子；一份每周只有12节课的课程表而没有人质疑；以及在七个互不相通的系统里记录下担忧的七位专业人员——把“要在心里把这个家庭的说法过两遍”变成了培训。法律的里程碑并行着：1989年与2004年那两部关于儿童的法律；份跨部门指南的一版又一版的版本；2010年代跨部门的中枢；以及法定的调查的时代的一项认识：从2014年那份报告往后，人们承认在某些城镇里，对女孩的性的剥削被忽视了十五年——因为专业人员不相信在收容的住处与外卖店里的女孩是受害者；也因为对会被指控为种族主义的恐惧，加上机构的自我维护，与阶级的轻蔑结合在一起，把报告压了下去。份调查的教训如今是培训的教条：这个孩子的故事会传播；种族不能把虐待解释掉；而在共同体问题上政治的怯懦，和其他任何一项一样，是一次保护学的失败。关于切割的政策的历史是它自己的一章：从被礼貌地绕开的传统、到那项强制的报告与预防的门诊以及那份跨境的罪行的立法[[public-health/global-health]]、[[medical-ethics-law/confidentiality]]、[[public-health/determinants-inequalities]]。**
:::

::: summary
- 损伤的不相符——机制与分布及发育的可信性——以及在一个还不会移动的婴儿身上的任何损伤，是危险信号的发现；而那份成长的曲线是忽视的那位证人。
- 一次正常的检查永远不排除性虐待；而剥削常常以“常来的就诊者”或“难缠的少年”来就诊，并且要靠模式来读、不是靠发现来读。
- 转诊是一份关于观察与引语的书面文件；必要时可以在没有家庭的同意之下做出；它是一份职责——份不确定属于那个分诊的中枢、不属于个人的良知。
- 不良的童年的经历是下一章所覆盖一切剂量依赖的危险因素；而复原力跟随一段稳定的关系——所以服务保护的是关系。
- 带着创伤的知识的设计是对被医疗造成伤害的保护：可能时只做一次检查；用确切的词；在每一次敏感的处置之前先问这个孩子。
- 三十年严重病例的复盘在重复三个失败：没有看见这个孩子、没有把证据加起来、以及各机构之间没有说话——而每一个本地的系统都应当能够展示它如何击败每一项。
:::

## 练习

::: exercise 读出那处损伤 {level=1}
::: solution
**三处损伤，三个回答（[[#def-recognise]]）：（甲）可疑到高度可疑——“一个4个月孩子的瘀伤，在任何位置都是一项危险信号的伤害；那位兄弟所给出的机制对一处线状的瘀伤是不可信的，而它要按”所提供的说法”被记录下来；而当天内的这条路是适用的：资深儿科的复查、骨骼的普查，以及保护学的讨论，无论这个家庭表现得多好。（乙）低担忧但带情景——“一个会走的幼儿的前额的瘀伤是最常见的意外的童年的损伤；记录下这次检查与发育的阶段及那份说法的一致性，并把它加进记录里，这样以后的就诊能加到某个东西上。（丙）带着文化的素养的高度担忧——”对称的椭圆的痕迹符合那一种拔罐或刮痕的模式；问出那个具体的提问，并检查别处模式的痕迹与其他损伤；如果这一做法被确认而没有别的担忧，那么回应是教育、记录与监测、不是自动的分离——但如果那分布或那说法或那份成长的曲线说着相反的话，那么转诊继续，而那不是一层油能解释的。统一的一课：位置、分布与可信性是物理学；而文化是情景，它会改变谈话的用词，永远不会改变孩子的安全[[paediatrics/acute-childhood-illness]]、[[clinical-skills/physical-examination]]。**

::: exercise 写下那份转诊 {level=2}
::: solution
**同一个病例的两份转诊（[[#def-law]]）：份分诊的转诊用可以被分开的句子陈述事实与担忧：“10周的男婴，于某日因股骨干的无移位的骨折收住，据报从换尿垫上掉到地毯上——以我专业的意见，这一机制在这个年龄与这一损伤不相容；既往无就诊；生长在第50到91百分位；父母分别的说法在某一个具体的细节上有分歧；祖母从某地来访；担忧：可能被造成的损伤；这个婴儿的安全的计划需要一次完整的评估。观察到什么；一字不差地说了什么；什么不相符；请求什么——带上日期、签名；不要用形容词来辩论。警方那份策略的文件补上他们那个访谈真正需要临床的细节；但绝不要写下那位医师关于有罪的确信——“这对父母做了这件事”或“这对父母显然无罪”——因为这两种说法从一次骨折里都无法被证明；两者都会使之后的每一位专业人员产生偏向；而当答案最后被证明是那位同住的叔叔时，两者都会在法庭上或复盘会上被回敬给你。写下这个孩子的脆弱，而不是你的判决[[paediatrics/acute-childhood-illness]]、[[clinical-skills/records-handover]]。**

::: exercise 处理那贴近披露的压力 {level=2}
一名在你儿童的保护计划上的16岁向那位实习的护士披露：她的父亲“翻看她的手机，并且不让她去学院”；并恳求她“不要告诉任何人，因为他会不让我见你”。她并没有在描述身体的伤害。请给那位实习的护士与那份记录以建议。
::: solution
**一份在保护的计划之内的保密的请求（[[#def-law]]、[[#def-impact]]）：那位实习的护士的处境是诚实而有边界的——她在同一天告诉她的督导与那位具名的临床医师（一份保护的计划是一份常设信息共享的协议；“一份你无法守住的担忧，不属于你可以守住的东西）”)；而这个年轻人要在任何事情被做之前被清楚地告知这一点，并解释接下来会发生什么：这是控制的行为，按定义就是情感的虐待，与那份被建立来正好留意这种逐渐的控制的模式的计划相关——不是一场“家庭的争吵”。回应是分级的，不是自动的升级：与社会的工作者及这个年轻人的讨论；复查这份计划现在覆盖什么；一条学校与学院的安全的路径；以及与这位16岁的人关于她想要什么的那场谈话（年轻人常常希望那种控制停止、而不希望这个家庭被毁掉——这份计划必须同时容纳这两样）。份记录：一字不差的披露；日期；谁在场；段确切的关于保密的讨论；以及与她一起商定的行动——写得让她明年能够读，并认出她自己的话被尊重了。给那位学生的那个教学的点：一份你无法守住的承诺，是唯一一份你能确定的伤害；而在第一分钟就带着尊重告诉她那个限度，既是那件符合伦理的事、也是那件能让她继续说话的事[[medical-ethics-law/confidentiality]]、[[psychiatry/psychiatric-assessment]]。**
:::

::: exercise 审计你们病房保护学的系统 {level=3}
::: solution
**保护学的审计（[[#def-law]]、[[clinical-skills/patient-safety]]）：五个指标——（甲）因瘀伤或危险信号的伤害而收住的1岁之下与5岁之下的孩子里，在24小时之内有过一次被记录的评估的比率（分母：所有这一类的收住）；（乙）被收住到你们病房上的、在保护计划上的孩子里，其统筹者在24小时之内被联系到的百分比（那个“有没有人打电话”的指标，历史上最令人难堪的一个）；（丙）被照管的孩子们：有一份个人的教育与健康的计划、并有一份在有效期内健康评估的百分比（一项法定要求的数字）；（丁）及时性：从由你们部门发起法定评估的转诊到策略讨论中位的天数；以及（戊）反馈的环路：你们转诊的结果在30天之内被反馈给转诊者的百分比。预期的失败：第乙与第戊——病房会把一个在计划上的孩子收住而没有人按名字给那位社会的工作者打电话；而转诊进一个黑洞的临床医师会停止转诊，这在文献里被称为转诊的疲劳，而它是一次系统的失败、不是个人的失败。再加上那副审计无法藏起来公平的透镜：在你们的前台，谁被转诊、谁被贴上“难缠的家庭”的标签；以及按族裔与剥夺来比较的比率——因为那同一种转诊不足的模式，曾存在于已经不再相信某些孩子正在被伤害的服务里[[public-health/health-systems-economics]]、[[public-health/determinants-inequalities]]。**
