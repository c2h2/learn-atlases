乳腺外科和内分泌外科有着相同的工作方式。大多数患者是因为一个肿块或一项异常检查结果而来，而不是因为急症；首要任务是以尽可能少的干预判断问题是良性还是恶性。决策由多学科团队作出，成员包括外科医生、放射科医生、病理科医生、肿瘤科医生、内分泌科医生和专科护士。而手术虽然很少是大手术，却紧邻那些一旦损伤就会永久改变患者生活的结构：喉部的神经、甲状旁腺、腋窝的神经。

本章介绍乳腺症状的评估、乳腺癌及其外科处理、遗传风险与筛查、甲状腺结节和甲状腺手术、甲状旁腺功能亢进症以及肾上腺。指南以英国为主（NICE 关于早期和局部晚期乳腺癌的 NG101、关于家族性乳腺癌的 CG164、关于甲状腺疾病的 NG145、关于甲状旁腺功能亢进症的 NG132，以及英国甲状腺协会），内容截至2026年。个体患者的处理遵循当地多学科方案。

## 乳腺症状与三联评估

大多数乳腺症状由良性疾病引起，但乳腺癌是英国女性最常见的癌症，因此每一个新出现的乳腺症状都应得到明确的答复。在英国，有可疑乳腺症状的人在**一站式乳腺门诊**就诊，在一次就诊中即可完成体格检查、影像检查和活检。

::: definition 三联评估 {#def-breast}
**三联评估**是对乳腺肿块或其他可疑乳腺症状的标准评估，包括三个部分：

1. **临床评估：**病史（持续时间、是否随月经周期变化、乳头溢液、皮肤改变、家族史、激素使用）以及对双侧乳腺、腋窝和锁骨上窝的检查。
2. **影像检查：**约40岁以下女性用**超声**，因为其致密的乳腺组织使乳腺 X 线摄影的作用降低；年龄较大的女性用**乳腺 X 线摄影**加超声。
3. **组织取样：****空芯针活检**，通常在超声或立体定向乳腺 X 线摄影引导下进行，可得到组织学诊断并进行受体检测；细针穿刺主要用于囊肿和腋窝淋巴结。

每一部分都按五分制评分（例如1为正常，2为良性，3为不确定，4为可疑，5为恶性）。结果必须一致。只要有任何一部分可疑，即使其他部分令人放心，病变在被证明不是之前都应按可能恶性处理。
:::

常见的良性疾病包括：

- **纤维腺瘤：**年轻女性中光滑、活动、有弹性的肿块（"乳腺鼠"），由过度生长的小叶组织构成。一旦确诊，通常不必处理，除非较大或在增大。
- **囊肿：**充满液体，常见于40多岁和绝经前后的女性；可突然出现并有压痛。超声可确诊；有症状时行穿刺抽吸。
- **纤维囊性改变**（乳腺良性改变）：周期性的结节感和疼痛。
- **乳腺炎和乳腺脓肿：**通常见于哺乳期女性；治疗为抗生素、继续哺乳或挤出乳汁，以及对任何脓肿行超声引导下穿刺抽吸。在非哺乳期女性中，导管周围乳腺炎与吸烟相关，且必须排除炎性乳腺癌。
- **乳头溢液：**如果来自多个导管且不带血，通常为良性；单个导管的血性溢液可能来自导管内乳头状瘤，较少见的是癌。
- **男性乳腺发育：**男性乳腺组织的良性增大，原因包括生理变化（青春期、老年）、药物（螺内酯、抗雄激素药、某些抗精神病药、合成代谢类固醇、大麻）、肝病、性腺功能减退，以及少见的分泌激素的肿瘤。男性也会患乳腺癌，因此硬的、偏心的肿块要按与女性相同的方式评估。

::: example 乳腺致密的年轻女性的肿块 {#ex-dense}
一位34岁女性发现左乳有一个肿块。检查发现外上象限有一个2 cm 质硬、不规则的肿块。超声报告为"可能良性"病变（3分，不确定）。由于体格检查可疑，她做了乳腺 X 线摄影，显示乳腺组织致密，没有明确异常。下一步应该做什么？
::: solution
**原则：**三联评估的三个部分必须一致。这里体格检查可疑（质硬且不规则），影像为不确定。乳腺致密的女性乳腺 X 线摄影正常并不能排除癌症，因为致密的腺体组织和肿瘤在乳腺 X 线片上看起来可能相似。

**下一步：****超声引导下空芯针活检**；只要评估中有任何部分不是明确良性的，就需要活检。如果活检为良性而临床表现仍然可疑，就在多学科会议上讨论该病例，并考虑再次活检、MRI 或切除。

**背景：**年轻女性的乳腺癌较少见，但常常更具侵袭性，诊断延误是公认的伤害来源。年轻不应让团队放松警惕。
:::
:::

## 乳腺癌

大多数乳腺癌是**浸润性导管癌**（也称非特殊类型浸润性癌），其次是**浸润性小叶癌**，后者倾向于弥漫性扩散，在影像上可能难以发现。**导管原位癌（DCIS）**是局限于导管内的恶性细胞增生，常在筛查中以微钙化的形式被发现；它不会转移，但可进展为浸润性癌。

治疗取决于三方面的信息：

- **分期：**肿瘤的大小、腋窝淋巴结受累情况和远处扩散（骨、肝、肺、脑），采用 TNM 系统。
- **分级：**细胞看起来的异常程度（1至3级）。
- **受体状态：****雌激素受体（ER）**和孕激素受体，预测能否从**内分泌治疗**（他莫昔芬、芳香化酶抑制剂）中获益；**HER2**，预测能否从曲妥珠单抗等 HER2 靶向药物中获益。三者均缺乏的癌症称为**三阴性**乳腺癌；它在年轻女性和 *BRCA1* 变异携带者中更常见，用化疗以及越来越多地用免疫治疗来治疗。

### 乳腺的手术

主要有两种选择：

- **保乳手术**（广泛局部切除，也称肿块切除术）切除肿瘤及其周围一圈正常组织，随后对剩余乳腺进行**放疗**。20世纪70年代和80年代的长期试验表明，对于合适的肿瘤，保乳手术加放疗后的生存率与乳房切除术相同。不可触及的病变在术前于影像引导下放置导丝或标记物定位。
- **乳房切除术**切除整个乳腺。用于相对于乳房体积较大的肿瘤、位于不同象限的多发肿瘤、无法进行放疗的情况，以及患者更愿意选择时。为合适的女性提供即刻或延期**乳房重建**，使用假体或患者自身的组织（如取自腹部的皮瓣）。

较大的肿瘤可先接受**新辅助**（术前）化疗或内分泌治疗以缩小肿瘤，从而得以保乳。新辅助化疗也是许多 HER2 阳性和三阴性乳腺癌的标准治疗，因为疗效可预测结局并指导后续治疗。

### 腋窝的手术

::: theorem 前哨淋巴结原理 {#thm-sentinel}
来自肿瘤的淋巴液首先引流到一个或几个淋巴结，即**前哨淋巴结**。如果前哨淋巴结没有癌转移，该引流区域内的其余淋巴结受累的可能性就非常小。因此，只切除并检查前哨淋巴结就能准确地对腋窝进行分期，同时避免切除所有淋巴结带来的并发症。
:::

::: proof
肿瘤的淋巴扩散遵循淋巴引流的解剖路径，即有序地从原发部位到达引流区域的第一站淋巴结，然后才到达更远的淋巴结。在肿瘤附近或乳晕下注射放射性示踪剂（锝-99m）和/或蓝色染料，可以标记出淋巴路径；外科医生用γ探头并根据颜色找到前哨淋巴结。在大型验证研究中，前哨淋巴结活检之后再进行完整的腋窝清扫，结果显示在绝大多数女性中，前哨淋巴结正确地预测了腋窝的状态，同时使用两种示踪剂时假阴性率很低。由于完整的**腋窝淋巴结清扫**会使相当一部分女性出现上肢淋巴水肿、肩关节僵硬和麻木，而前哨淋巴结活检很少引起这些问题，这一原理使大多数临床淋巴结阴性的女性完全避免了清扫。
:::

术前用**超声**评估腋窝，对任何异常淋巴结进行活检。如果超声正常，就在乳腺手术时行**前哨淋巴结活检**。如果证实淋巴结有癌转移，则对腋窝行清扫或放疗。试验表明，一些前哨淋巴结受累有限（如一个或两个淋巴结）、接受保乳手术和放疗的女性，可以安全地避免进一步的腋窝手术；这一决定由多学科团队作出。

### 辅助治疗与预后

术后，**辅助**治疗可降低复发风险：放疗、ER 阳性癌的内分泌治疗（通常至少5年）、高风险癌的化疗，以及 HER2 阳性癌的 HER2 靶向治疗。**NHS Predict** 等在线工具可估计每种治疗对个体的获益。**诺丁汉预后指数（NPI）**是一个简单而历史悠久的预后评分：

$$
\text{NPI} = 0.2 \times \text{肿瘤大小 (cm)} + \text{淋巴结评分} + \text{分级}
$$ {#eq-npi}

其中无淋巴结受累时淋巴结评分为1，1–3个淋巴结受累为2，4个或以上为3；分级为1、2或3。分数越低预后越好：常用的分组是良好（不超过3.4）、中等（3.41–5.4）和较差（高于5.4）。

::: example 计算 NPI {#ex-npi}
一位58岁女性因一个2.5 cm、2级、ER 阳性、HER2 阴性的浸润性导管癌接受了广泛局部切除和前哨淋巴结活检。她的两个前哨淋巴结中有一个有转移。计算她的 NPI 并加以解读。
::: solution
**大小项：**$0.2 \times 2.5 = 0.5$。

**淋巴结评分：**1–3个淋巴结受累，因此为2。

**分级：**2。

**NPI：**$0.5 + 2 + 2 = 4.5$。

**解读：**NPI 为4.5，属于中等预后组。实际上，她的治疗计划将基于更全面的评估：多学科团队会考虑对乳腺（可能还有腋窝）放疗、因肿瘤 ER 阳性而进行内分泌治疗，以及化疗是否有额外获益，常借助 NHS Predict，有时还会对肿瘤进行基因组检测。NPI 出现在受体检测和靶向治疗之前，因此它是一个起点，而不是最终结论。
:::
:::

## 风险、筛查与遗传性乳腺癌

::: definition 乳腺癌筛查与家族性风险 {#def-risk}
**筛查。**NHS 乳腺筛查项目邀请50岁至71岁生日前的女性**每3年做一次乳腺 X 线摄影**；71岁以上的女性可以自行申请。筛查能更早发现癌症并降低乳腺癌死亡率，但也会造成**过度诊断**：发现那些永远不会造成伤害的癌症（和 DCIS），而这些癌症随后被治疗。2012年英国乳腺癌筛查独立专家组估计，每预防一例乳腺癌死亡，约有三名女性被过度诊断。

**家族性风险。**约5–10%的乳腺癌由遗传性高风险变异引起，最常见于 **BRCA1** 和 **BRCA2**，较少见于 *PALB2*、*TP53* 等基因。提示遗传风险的特征包括多位近亲患乳腺癌或卵巢癌、诊断时年龄小、双侧乳腺癌、男性乳腺癌、年轻时患三阴性乳腺癌，以及德系犹太人血统。NICE CG164 规定了哪些人应转诊至遗传学服务，以及对风险增加者的强化监测（包括对高风险年轻女性每年做 MRI）。
:::

携带高风险变异的女性可以选择**降低风险的手术**：双侧乳房切除术，可使乳腺癌风险降低约90%或更多；对于 *BRCA* 携带者，在完成生育后行**降低风险的输卵管卵巢切除术**，可降低卵巢癌风险，在部分女性中还可降低乳腺癌风险。这些是在遗传咨询之后作出的个人决定（[[genetics/cancer-genetics]]）。

## 甲状腺

::: definition 甲状腺结节与甲状腺手术 {#def-endocrine-neck}
**甲状腺结节**非常常见，大多数是良性的。评估的目的是找出少数癌症，而不对大量良性结节进行手术：

1. **病史和体格检查：**生长迅速、结节质硬或固定、声音嘶哑（喉返神经受累）、喘鸣、颈部淋巴结肿大、既往颈部放疗史以及甲状腺癌或 MEN2 家族史提示恶性。
2. **甲状腺功能检查：**TSH 低提示高功能（"热"）结节，这种结节很少是恶性的，用放射性核素扫描评估。
3. **超声**，按英国甲状腺协会的 **U1–U5** 系统分级（U1 正常，U2 良性，U3 不确定，U4 可疑，U5 恶性）。令人担忧的特征包括实性低回声结节、边缘不规则、微钙化和异常淋巴结。
4. 对 U3–U5 结节行**超声引导下细针穿刺细胞学检查（FNAC）**，按 **Thy1–Thy5** 分类报告（Thy1 不能诊断，Thy2 非肿瘤性，Thy3 不确定，其中 Thy3a 为非典型性，Thy3f 为可能的滤泡性肿瘤，Thy4 可疑恶性，Thy5 恶性）。

**手术**分为**甲状腺腺叶切除术**（半侧切除），用于不确定结节的诊断和小的低风险癌症的治疗；以及**全甲状腺切除术**，用于较大或较高风险的癌症、Graves 病和引起压迫的巨大多结节性甲状腺肿。
:::

### 甲状腺癌

- **乳头状癌**是最常见的类型（约占五分之四）。它向颈部淋巴结扩散，大多数患者预后极好。
- **滤泡状癌**经血行扩散至骨和肺。在细胞学上无法将其与良性滤泡性腺瘤区分，因为诊断需要在组织学上看到包膜或血管侵犯。这就是为什么 Thy3f 结果通常导致诊断性腺叶切除术。
- **髓样癌**起源于分泌降钙素的滤泡旁 C 细胞。约四分之一是遗传性的，由 *RET* 突变引起（MEN2）。降钙素用作肿瘤标志物。
- **未分化癌**见于老年人，生长迅速，预后极差。
- 甲状腺**淋巴瘤**与桥本甲状腺炎相关。

分化型（乳头状和滤泡状）癌的治疗是手术，部分较高风险的患者随后接受**放射性碘**清除治疗和左甲状腺素 TSH 抑制治疗。全甲状腺切除术后的随访以甲状腺球蛋白作为标志物。

### 甲状腺手术的并发症

甲状腺紧邻以下结构：**喉返神经**，走行于气管食管沟内，支配除环甲肌以外的所有喉内肌；**喉上神经外支**，支配环甲肌并控制音调；以及**甲状旁腺**，通常有四个，位于甲状腺背面。

- **喉返神经损伤**如为单侧，引起声音嘶哑、无力；如为双侧，引起喘鸣和气道梗阻。在有经验的医生手中，暂时性麻痹的发生率为百分之几，永久性麻痹约为1%或更低。术前和术后检查声带；许多外科医生使用术中神经监测。
- **低钙血症**发生在全甲状腺切除术后甲状旁腺受到挫伤或被切除时。它很常见，通常是暂时的，但有时是永久性的。症状有口周麻刺感、手指感觉异常、肌肉痉挛，严重时有手足搐搦、抽搐和心律失常。全甲状腺切除术后测量血钙（或甲状旁腺激素），并按需补充。
- 甲状腺手术后的**颈部血肿**可在数分钟内压迫气道，主要通过静脉和淋巴回流受阻以及喉头水肿。这是一种急症，病房工作人员必须接受识别和处理它的培训。
- **甲状腺危象**（甲状腺毒症的严重加重）的预防方法是使甲状腺功能亢进患者在术前恢复甲状腺功能正常。

::: example 甲状腺切除术后的喘鸣 {#ex-haematoma}
一位56岁女性因巨大甲状腺肿接受全甲状腺切除术，术后4小时她变得烦躁不安，说颈部发紧，呼吸有杂音。她的颈部肿胀，敷料绷紧。氧饱和度93%。发生了什么？应该怎么做？
::: solution
**诊断：**压迫气道的**颈部血肿**。甲状腺手术后不久出现颈部肿胀、发紧感、喘鸣和氧饱和度下降，在被证明不是之前即可作出诊断。

**立即行动：**呼救（紧急呼叫外科医生和麻醉医生），让她坐起，给予高流量氧气；如果气道受到威胁，不要等待手术室，**在床旁打开伤口**。英国的指南（"SCOOP"方法，得到困难气道学会和英国内分泌与甲状腺外科医师协会的认可）概括了这些步骤：暴露皮肤（**S**kin exposure）、剪开缝线（**C**ut sutures）、打开皮肤（**O**pen skin）、打开肌层（**O**pen muscles）、填塞伤口（**P**ack the wound）。清除血凝块可解除对气道的压迫。然后她被送往手术室控制出血点，麻醉医生要为困难气道做好准备。

**预防伤害：**每位颈部手术后患者的床旁都备有拆线剪或拆线包，护理人员接受识别早期征象并采取行动的培训。
:::
:::

## 甲状旁腺

**原发性甲状旁腺功能亢进症**是甲状旁腺过度分泌甲状旁腺激素（PTH），导致高钙血症。约80–85%的患者由**单个腺瘤**引起，其余为多腺体增生（见于 MEN1 和 MEN2A），罕见为癌。大多数病例是在常规血液检查中发现的。有症状时，症状包括疲乏、口渴、多尿、便秘、情绪低落、肾结石，以及骨质疏松引起的骨痛或骨折（"骨痛、结石、腹部呻吟和精神抱怨"）。

诊断依据是**白蛋白校正钙**升高，同时 PTH 升高或不适当地正常（在恶性肿瘤等其他高钙血症病因中，PTH 被抑制）。家族性低尿钙性高钙血症是一种良性遗传病，可通过测量尿钙排泄来排除。由于约40%的血清钙与白蛋白结合，总钙要按白蛋白浓度进行校正：

$$
\text{校正钙 (mmol/L)} = \text{总钙} + 0.02 \times (40 - \text{白蛋白 (g/L)})
$$ {#eq-calcium}

各地实验室使用的公式可能略有不同。钙的生物化学见[[endocrine/bone-calcium]]。

NICE NG132（2019年）建议，对有症状、有靶器官损害（肾结石、脆性骨折或骨质疏松）或白蛋白校正血钙**达到或超过2.85 mmol/L** 的原发性甲状旁腺功能亢进症患者，转诊进行手术。术前用颈部超声和 sestamibi 扫描或其他影像检查对异常腺体进行**定位**。然后可经小切口切除单个腺瘤（**聚焦性甲状旁腺切除术**），一些单位在术中测量 PTH 以确认其下降。如果影像为阴性或怀疑多腺体病变，则行**双侧颈部探查**，检查全部四个腺体。手术成功后，血钙可能急剧下降（有明显骨病的患者出现"骨饥饿综合征"），需要监测。

::: example 血钙与扫描报告 {#ex-ca}
一位61岁女性的常规血液检查显示总钙2.72 mmol/L，白蛋白32 g/L。PTH 9.8 pmol/L（参考范围约1.6–6.9）。她曾患肾结石。计算她的校正钙，并决定是否应转诊手术。
::: solution
**校正钙：**$2.72 + 0.02 \times (40 - 32) = 2.72 + 0.16 = 2.88$ mmol/L。

**诊断：**校正钙升高伴 PTH 升高，符合**原发性甲状旁腺功能亢进症**。应测量尿钙排泄以排除家族性低尿钙性高钙血症，并检查维生素 D。

**手术：**她在两个方面符合 NICE 标准：校正钙高于2.85 mmol/L，且有靶器官损害（肾结石）。应转诊给内分泌外科医生。影像检查（超声和 sestamibi）用于术前定位腺瘤，而不是用于诊断，诊断是生化性的。还应评估骨密度。
:::
:::

## 肾上腺

因偶然发现的肿瘤而接受肾上腺手术的情况越来越多。**肾上腺偶发瘤**是在因其他原因进行的影像检查中发现的肿块。每一个偶发瘤都要回答两个问题：

- **它是否分泌激素？**检查包括用于皮质醇过多的过夜地塞米松抑制试验、用于嗜铬细胞瘤的血浆或尿**甲氧基肾上腺素类物质**，以及在有高血压或低钾血症的患者中用于原发性醛固酮增多症的醛固酮/肾素比值。
- **它可能是恶性的吗？**体积大（尤其是超过约4 cm）、平扫 CT 密度高以及随访中增大，提示肾上腺皮质癌或转移瘤的可能。大多数平扫 CT 密度低（富含脂质）的小病变是良性腺瘤。

**嗜铬细胞瘤**是肾上腺髓质分泌儿茶酚胺的肿瘤，引起发作性头痛、出汗、心悸和高血压。术前，患者接受数周的**α受体阻滞**（如酚苄明或多沙唑嗪），同时补充液体和盐，**只有在充分α受体阻滞之后才使用β受体阻滞剂**。先给β受体阻滞剂会使α受体介导的血管收缩失去对抗，可引起危险的血压升高。手术本身通常为腹腔镜肾上腺切除术，在处理肿瘤时以及结扎其静脉之后，需要麻醉医生仔细处理血压的剧烈波动。内分泌背景知识见[[endocrine/adrenal]]。

**多发性内分泌腺瘤病（MEN）**综合征把这些器官联系在一起。**MEN1**（甲状旁腺、垂体和胰腺神经内分泌肿瘤）由 *MEN1* 突变引起；**MEN2A**（甲状腺髓样癌、嗜铬细胞瘤和甲状旁腺功能亢进症）和 **MEN2B**（甲状腺髓样癌、嗜铬细胞瘤、黏膜神经瘤和类马方体型）由 *RET* 突变引起。携带 *RET* 突变的儿童在取决于具体突变的年龄接受预防性甲状腺切除术。甲状腺髓样癌患者在甲状腺手术前必须排除嗜铬细胞瘤。

::: quiz
一位42岁男性有发作性头痛、出汗和高血压，血浆甲氧基肾上腺素类物质升高，肾上腺有一个3 cm 的肿块。在他接受肾上腺切除术之前，哪种方案是正确的？
- [ ] 先用β受体阻滞剂控制心率，然后加用α受体阻滞剂
- [x] 开始使用α受体阻滞剂，同时补充液体和盐；如果心动过速持续，只在充分α受体阻滞之后加用β受体阻滞剂
- [ ] 不做准备立即手术，以去除儿茶酚胺的来源
- [ ] 用利尿剂控制他的血压
::: solution
先进行α受体阻滞，以控制血管收缩并使血浆容量扩张。先给β受体阻滞剂会使α受体介导的血管收缩失去对抗，可诱发高血压危象。不做准备就手术有血压剧烈波动的风险。利尿剂会加重这些患者已有的容量不足。
:::
:::

::: example 30岁男性的颈部肿块 {#ex-necklump}
一位30岁男性甲状腺右叶有一个2.5 cm 的无痛性肿块，是他的伴侣发现的。甲状腺功能正常。超声分级为 U4（实性、低回声、有微钙化），并显示右侧颈部有一个轻度增大的淋巴结。结节的 FNAC 报告为 Thy5。可能的诊断是什么？如何处理？
::: solution
**可能的诊断：****甲状腺乳头状癌**，可能有淋巴结扩散。乳头状癌是最常见的类型，典型地见于年轻成人，超声上的微钙化反映了砂粒体。

**进一步评估：**对异常淋巴结行 FNAC（在穿刺针冲洗液中测量甲状腺球蛋白），术前检查声带，并查血钙。如担心有广泛的局部扩散，则进行断层影像检查。

**治疗：**在甲状腺癌多学科会议上讨论。如果证实淋巴结有癌转移，通常的方案是**全甲状腺切除术加受累淋巴结区域的颈淋巴结清扫**，然后考虑**放射性碘**和 TSH 抑制治疗。无淋巴结扩散的较小癌症可仅行腺叶切除术。

**咨询：**年轻成人乳头状癌的预后极好。要讨论手术的风险（声音改变、低钙、全甲状腺切除术后需终身服用左甲状腺素）。
:::
:::

::: history
特奥多尔·科赫尔（Theodor Kocher）自1872年起担任伯尔尼的外科教授，他通过精细的技术和对解剖的细致关注，把甲状腺切除术的死亡率从曾使一些人称之为屠宰的水平降至远低于1%。他还注意到，切除整个甲状腺的患者会出现一种他称为"甲状腺切除后恶病质"（cachexia strumipriva）的状况，后来证实这就是甲状腺功能减退；这一观察有助于揭示甲状腺的功能。他于1909年获得诺贝尔生理学或医学奖。在乳腺外科方面，威廉·霍尔斯特德（William Halsted）的乳腺癌根治术（1894年）切除乳腺、两块胸肌和腋窝内容物，这一术式作为标准治疗沿用了80年，直到美国的伯纳德·费希尔（Bernard Fisher）和米兰的翁贝托·韦罗内西（Umberto Veronesi）领导的试验表明，规模小得多的手术加放疗可获得同样的生存率。
:::

## 后续内容

甲状腺、甲状旁腺和肾上腺的生理和内科疾病见[[endocrine/thyroid]]、[[endocrine/bone-calcium]]和[[endocrine/adrenal]]。遗传性癌症的遗传学见[[genetics/cancer-genetics]]，癌症生物学和分期见[[pathology/cancer-biology]]和[[pathology/cancer-diagnosis]]，筛查的原则见[[public-health/screening]]。

::: summary
- 乳腺症状通过**三联评估**进行评估：临床检查、影像（约40岁以下用超声，以上用乳腺 X 线摄影加超声）和空芯针活检。只要有任何部分可疑，病变就按可能恶性处理。
- 乳腺癌的治疗取决于**分期、分级和受体（ER、PR、HER2）**。对于合适的肿瘤，保乳手术加放疗与乳房切除术的生存率相同。
- **前哨淋巴结活检**对临床淋巴结阴性的腋窝进行分期，使大多数女性免于腋窝清扫和淋巴水肿。
- NPI = 0.2 × 大小（cm）+ 淋巴结评分 + 分级。
- NHS 对50–71岁女性每3年筛查一次；筛查挽救生命，但会造成过度诊断。*BRCA1/2* 携带者可以选择强化监测或降低风险的手术。
- 甲状腺结节通过甲状腺功能检查、超声（**U1–U5**）和 FNAC（**Thy1–Thy5**）评估。乳头状癌最常见；滤泡状癌需要组织学诊断；髓样癌与 *RET* 和 MEN2 相关。
- 甲状腺切除术的风险：喉返神经损伤、低钙血症和**威胁气道的血肿**（在床旁执行 SCOOP）。
- 原发性甲状旁腺功能亢进症：校正钙升高而 PTH 未被抑制；有症状、靶器官损害或血钙 ≥ 2.85 mmol/L 时手术；聚焦性甲状旁腺切除术前先定位。
- 肾上腺偶发瘤要检查激素过多和恶性可能；嗜铬细胞瘤需要**先α受体阻滞，再β受体阻滞**。
:::

## 习题

::: exercise 三联评估的实践 {level=1}
一位45岁女性的乳腺肿块在体格检查中评为2分（良性），影像评为2分，空芯针活检评为4分（可疑）。结论是什么？如果评分是4、2和2呢？
::: solution
在两种情况下评估都是**不一致的**，因此都不能把病变称为良性。在第一种情况下，活检可疑，因此她需要进一步组织取样或切除。在第二种情况下，尽管影像和活检为良性，临床检查却可疑；要在多学科会议上讨论该病例，通常导致再次活检或切除，因为可能存在取样误差。规则是三个部分必须一致才能给予安慰。
:::
:::

::: exercise 计算 NPI {level=1 check="0.2*1.5+1+1"}
计算一个1.5 cm、1级、无淋巴结受累的肿瘤的 NPI。给出精确值。
::: solution
$0.2 \times 1.5 + 1 + 1 = 0.3 + 2 = 2.3$。属于良好预后组（不超过3.4）。
:::
:::

::: exercise 校正钙 {level=1 check="2.52+0.02*(40-28)"}
一位患者总钙2.52 mmol/L，白蛋白28 g/L。用本章的公式计算白蛋白校正钙（mmol/L）。给出精确值。
::: solution
$2.52 + 0.02 \times (40 - 28) = 2.52 + 0.24 = 2.76$ mmol/L。虽然总钙接近正常上限，但校正值已升高。在白蛋白低的患者中，未校正的血钙可能掩盖高钙血症。
:::
:::

::: exercise 解读细胞学结果 {level=2}
解释为什么甲状腺结节 FNAC 结果为 Thy3f（可能的滤泡性肿瘤）时通常要行诊断性腺叶切除术，而 Thy2 结果通常只需安慰或随访。
::: solution
滤泡状癌和滤泡性腺瘤在细胞学上表现相同：两者都由滤泡细胞构成。区别在于肿瘤是否侵犯其包膜或血管，而这只有对整个结节进行组织学检查才能看到。因此 Thy3f 结果有相当大的恶性可能，不切除腺叶就无法确定。Thy2 结果是非肿瘤性的（如胶质结节或甲状腺炎）；结合良性的超声表现，除非结节引起压迫症状、增大或有令人担忧的特征，否则不需要手术，一些单位会重复 FNAC 以确认。
:::
:::

::: exercise 谁需要转诊遗传学？ {level=2}
对下列每位女性，判断是否适合因可能的遗传性乳腺癌转诊至遗传学服务，并说明理由：(a) 一位62岁女性，其母亲75岁时患乳腺癌；(b) 一位35岁三阴性乳腺癌女性；(c) 一位50岁德系犹太人血统的女性，其姐妹患卵巢癌；(d) 一位患乳腺癌的男性。
::: solution
(a) 可能不需要：一位亲属在较大年龄确诊只会适度增加风险，通常不提示高风险变异。按当地标准执行。(b) 需要：年轻时患三阴性乳腺癌与 *BRCA1* 相关，检测结果会影响治疗和家庭成员。(c) 需要：近亲患卵巢癌以及德系犹太人血统（其中 *BRCA* 奠基者变异相对常见）都增加了遗传变异的可能性。(d) 需要：男性乳腺癌与 *BRCA2* 相关。基因检测标准由国家制定，并随着检测的普及而变化。
:::
:::

::: exercise 术后声音嘶哑 {level=2}
一位47岁教师在右侧甲状腺腺叶切除术后第二天声音嘶哑，说话容易疲劳。可能的原因是什么？如何评估？预后如何？为什么双侧损伤更危险？
::: solution
**可能的原因：****右侧喉返神经**损伤（常为牵拉或挫伤引起的神经失用），导致右侧声带麻痹。**评估：**由耳鼻喉科医生行喉镜检查观察声带运动。**预后：**大多数术中看到神经完好的损伤在数周至数月内恢复；永久性麻痹不常见。言语和语言治疗有帮助；如果不能恢复，可以通过手术把麻痹的声带移向中线。她作为教师，声音尤为重要，这本应是知情同意讨论的一部分。**双侧损伤**可使两侧声带都停留在中线附近，拔管后引起喘鸣和气道梗阻，可能需要再次插管或气管切开。
:::
:::

::: exercise 并非甲状旁腺引起的高钙血症 {level=3}
一位70岁男性校正钙3.15 mmol/L，PTH 0.6 pmol/L（被抑制），体重下降，背痛。他嗜睡且脱水。解释为什么甲状旁腺功能亢进症手术不是答案，列出可能的病因，并概述紧急治疗。
::: solution
**为什么不是甲状旁腺功能亢进症：**在原发性甲状旁腺功能亢进症中，PTH 升高或不适当地正常。**PTH 被抑制**说明甲状旁腺对高血钙的反应正常，因此病因在别处。**可能的病因：****恶性肿瘤**，通过骨转移（如来自肺癌、乳腺癌、前列腺癌或肾癌）或**多发性骨髓瘤**，或肿瘤分泌 PTH 相关肽（如肺鳞状细胞癌）；较少见的有维生素 D 过量、结节病、噻嗪类药物和制动。体重下降和背痛指向恶性肿瘤，可能是骨髓瘤。**紧急治疗：**静脉输注0.9%氯化钠纠正脱水并促进肾脏排钙，同时监测液体平衡；停用升高血钙的药物（噻嗪类、钙剂和维生素 D 补充剂）；补液后按当地指南静脉给予**双膦酸盐**（某些情况下用地舒单抗）。检查：骨髓瘤筛查（血清和尿蛋白电泳、游离轻链）、PTH 相关肽、胸部 X 线片或 CT，并寻找原发肿瘤。见[[endocrine/endocrine-emergencies]]。
:::

**问题：**这一信息只给出了获益，并暗示参加筛查理所当然。知情选择需要同时了解获益和危害。**平衡的内容：**筛查降低死于乳腺癌的风险；它可能发现那些永远不会造成伤害的癌症（**过度诊断**），因此一些女性接受了她们并不需要的手术、放疗和药物治疗（英国独立专家组估计，每预防一例死亡约有三名女性被过度诊断）；一些女性被召回做进一步检查和活检，结果并没有癌症（假阳性），这会引起焦虑；乳腺 X 线摄影会漏掉一些癌症，因此两次筛查之间出现的新症状应及时就诊；以及是否参加由女性自己选择。NHS 乳腺筛查宣传册已经按照这些思路进行了修订。筛查的伦理和评价见[[public-health/screening]]。
