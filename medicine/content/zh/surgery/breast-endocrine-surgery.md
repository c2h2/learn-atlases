乳腺与内分泌外科把两条路径放在一起：一条是乳腺的病变（从肿块到癌与植入物），另一条是颈部的小器官（甲状腺、甲状旁腺与肾上腺）[[pathology/cancer-diagnosis]]、[[endocrine/thyroid]]。

本章涵盖乳腺的路径与风险评估和筛查，以及甲状腺、甲状旁腺与肾上腺的外科。

## 乳腺的路径

::: definition 乳腺的疾病与它的外科 {#def-breast}
**诊断靠三联：临床检查、影像（乳腺X线与超声，选定时用MRI）与组织学（粗针活检）；读片的标准化分类（1到5级）决定下一步[[clinical-skills/physical-examination]]、[[clinical-skills/medical-imaging]]、[[pathology/diagnostic-pathology]]。良性的病变包括囊肿、纤维腺瘤、纤维囊性改变与乳头溢液[[endocrine/reproductive-endocrinology]]、[[obstetrics-gynaecology/menstrual-pelvic-disorders]]。恶性病变分原位与浸润（导管型与小叶型）；分期与受体状态（雌激素与孕激素受体、HER2与增殖指标）决定治疗[[pathology/cancer-biology]]、[[pathology/cancer-diagnosis]]、[[immunology/tolerance-regulation]]。手术的选择：保乳手术加放疗，或全乳切除；腋窝从前哨淋巴结活检到清扫；重建可以用植入物或自身组织同期或延期[[surgery/perioperative-care]]、[[clinical-skills/medical-imaging]]。全身治疗包括内分泌治疗、化疗、抗HER2的靶向治疗，以及在早期三阴性中的免疫治疗[[pharmacology/drug-development-prescribing]]、[[immunology/vaccines-immunotherapy]]、[[geriatrics-palliative/symptom-control]]。**
:::

::: definition 风险、筛查与特殊的人群 {#def-risk}
**风险因素包括月经与生育史、乳腺密度、家族史与基因的变异（BRCA1与2及其他中等外显的基因）[[genetics/mendelian-inheritance]]、[[genetics/common-disease-genetics]]、[[genetics/cancer-genetics]]、[[obstetrics-gynaecology/menstrual-pelvic-disorders]]。风险的评估把家族史、计算的模型与致病的变异结合，用来把人分层；高风险者可用MRI监测、药物的预防与减少风险的手术[[public-health/screening]]、[[clinical-skills/medical-imaging]]、[[pharmacology/drug-development-prescribing]]、[[genetics/genetic-testing]]。筛查：在适龄人群中的乳腺X线摄影能降低死亡，但必须同时谈假阳性与过度诊断[[public-health/screening]]、[[public-health/health-systems-economics]]。特殊人群包括年轻的、妊娠期的、男性乳腺癌，以及植入物相关的大细胞间变性淋巴瘤（表现为反复的积液与肿胀）[[obstetrics-gynaecology/pregnancy-antenatal]]、[[blood/lymphoma-myeloma]]、[[pathology/cancer-diagnosis]]。**
:::

## 颈部的小器官

::: definition 甲状腺、甲状旁腺与肾上腺的外科 {#def-endocrine-neck}
**甲状腺：结节很常见；评估靠甲状腺功能、超声的形态特征与细针细胞学；手术用于癌、大的或造成压迫的甲状腺肿与中毒的结节[[endocrine/thyroid]]、[[clinical-skills/medical-imaging]]、[[pathology/diagnostic-pathology]]。这类手术的特定风险是喉返神经损伤（声音改变）、甲状旁腺损伤（低钙）与出血压迫气道；因此术后查钙、听声音并警惕颈部肿胀是照护的核心[[surgery/perioperative-care]]、[[emergency-critical-care/airway-ventilation]]、[[renal/potassium-calcium-phosphate]]。甲状腺癌分乳头状、滤泡状、髓样（查RET与多发性内分泌肿瘤家族）与间变；随访用甲状腺球蛋白与影像[[endocrine/thyroid]]、[[genetics/non-mendelian-inheritance]]、[[pathology/cancer-biology]]。甲状旁腺：原发性甲旁亢（高钙伴相应的症状与肾与骨的损害）在有症状、年轻或有靶器官损害时手术；定位靠超声与核素的扫描；术后要警惕骨饥饿综合征造成的低钙[[endocrine/bone-calcium]]、[[renal/chronic-kidney-disease]]、[[clinical-skills/laboratory-tests]]。肾上腺：无功能的腺瘤最常见，但要筛查激素的分泌——醛固酮（高血压伴低钾）、皮质醇（库欣）与儿茶酚胺（嗜铬细胞瘤）；后者在手术前必须先α受体阻断[[endocrine/adrenal]]、[[cardiovascular/hypertension]]、[[pharmacology/autonomic-drugs]]。**
:::

::: example 乳腺X线正常的肿块 {#ex-dense}
一位44岁乳腺致密的女性摸到一个2厘米的孤立肿块；诊断性乳腺X线报告无异常，她被交代自己观察并尽量别担心。
::: solution
**三联中的任何一环都不能单独排除癌：致密乳腺会降低X线的敏感性，所以可触及的肿块必须做超声并取组织[[clinical-skills/medical-imaging]]、[[pathology/diagnostic-pathology]]、[[#def-breast]]。让她自己观察不可接受：当影像与触诊不一致时，要完成三联评估、安排复查，必要时做MRI[[public-health/screening]]、[[clinical-skills/patient-safety]]。记录要写明发现、已做的检查、复评的时间与负责的医生[[clinical-skills/records-handover]]、[[clinical-skills/communication]]。教学：在肿块面前，正常的X线只是一个假阴性，而不是保证；这也是这类纠纷的常见起点[[clinical-skills/clinical-reasoning]]、[[medical-ethics-law/professionalism-regulation]]。**
:::
:::

::: example 钙与扫描的报告 {#ex-ca}
一位67岁的血检显示校正钙2.78，而甲状旁腺激素不适当正常；她感觉良好；两年前因肾绞痛做的腹部CT提到现在已无结石；她的全科医生开了噻嗪类利尿剂。
::: solution
**高钙伴不被抑制的甲状旁腺激素就是原发性甲状旁腺功能亢进，直到被证明别的；无症状很常见，而靶器官的损害（结石、骨丢失与肾功能下降）可能早已存在[[endocrine/bone-calcium]]、[[renal/chronic-kidney-disease]]、[[renal/urinary-tract]]。噻嗪类会减少尿钙排出并把血钙升高，所以应停药换药[[renal/water-sodium]]、[[cardiovascular/hypertension]]、[[geriatrics-palliative/polypharmacy]]。评估：复查钙与白蛋白、维生素D与磷酸盐、24小时尿钙、骨密度与甲状旁腺的定位影像[[clinical-skills/laboratory-tests]]、[[clinical-skills/medical-imaging]]。治疗：在有靶器官损害、年龄较轻或肾功能下降时，切除腺瘤可以治愈；不适合手术者用药物与监测[[surgery/perioperative-care]]、[[endocrine/bone-calcium]]、[[public-health/health-systems-economics]]。**
:::
:::

::: example 过早外露的植入物 {#ex-explant}
在即刻植入物重建并计划放疗后的第七周，乳腺切除的皮瓣在上极裂开，露出扩张器的端口；她不发热，伤口周围皮肤看起来还可以。
::: solution
**外露的装置是一个需要决定而不是换药的问题：皮瓣坏死与装置表面污染会让感染定居下来，而放疗会进一步削弱愈合[[#def-breast]]、[[surgery/wounds-surgical-infection]]、[[pathology/cancer-biology]]。选项要与重建团队一起定：早期的小面积暴露可以尝试伤口处理、组织覆盖与抗生素；若污染明显或处理失败，则移除装置并延期重建[[surgery/perioperative-care]]、[[microbiology/antimicrobials]]。优先次序：不要为了保住装置而推迟放疗，因为肿瘤结局最重要[[clinical-skills/communication]]、[[medical-ethics-law/consent-capacity]]。同时处理影响皮瓣的因素：营养、血糖与吸烟[[gastrointestinal/clinical-nutrition]]、[[endocrine/diabetes]]、[[public-health/prevention-promotion]]。把讨论与选择写进记录[[clinical-skills/records-handover]]。**
:::
:::

::: example 30岁的颈部肿块 {#ex-necklump}
一位30岁不吸烟的人左侧颈部IV区有3厘米硬肿块已两个月，可动且不痛；一家私人诊所的细针报告为非典型淋巴样细胞，不能排除淋巴瘤；有人建议直接把肿块切掉。
::: solution
**年轻人侧颈的无痛肿块要在淋巴瘤、头颈原发、甲状腺的转移与感染（分枝杆菌与猫抓病）之间鉴别[[clinical-skills/physical-examination]]、[[pathology/diagnostic-pathology]]、[[infectious-diseases/tuberculosis]]、[[endocrine/thyroid]]、[[microbiology/fungi-parasites]]。实践规则：在诊断未明时不要做局部切除活检，因为它会破坏淋巴瘤的分级与分期；需要核心的或整颗淋巴结的切除活检，配合免疫组化与流式[[blood/lymphoma-myeloma]]、[[immunology/adaptive-responses]]。评估：血常规与乳酸脱氢酶、影像、甲状腺超声与口咽的检查[[clinical-skills/laboratory-tests]]、[[clinical-skills/medical-imaging]]。沟通：解释检查需要的时间与下一步，避免重复的私人检查[[clinical-skills/communication]]、[[clinical-skills/records-handover]]。**
:::
:::

::: quiz
一个2厘米的不定结节在粗针活检被报告为放射状瘢痕/复杂硬化性病变（B3级）。通常的下一步是：
- [x] 切除活检，因为多达10-30%会在粗针错过的位置藏着邻近的恶性
- [ ] 12个月后重复粗针
- [ ] 安心；B3意味着良性
- [ ] 直接的放疗
::: solution
**B3的类别是不确定的：既不是良性，也不能用观察代替，所以要把病变完整切除以排除邻近的恶性[[#def-breast]]、[[pathology/diagnostic-pathology]]、[[clinical-skills/medical-imaging]]。**
:::

## 通向何处

影像与读片的分类在[[clinical-skills/medical-imaging]]与[[pathology/diagnostic-pathology]]；肿瘤的生物学与诊断在[[pathology/cancer-biology]]与[[pathology/cancer-diagnosis]]；遗传的评估在[[genetics/cancer-genetics]]与[[genetics/genetic-testing]]；内分泌在[[endocrine/thyroid]]与[[endocrine/bone-calcium]]与[[endocrine/adrenal]]；筛查在[[public-health/screening]]；而症状与目标在[[geriatrics-palliative/symptom-control]]与[[medical-ethics-law/consent-capacity]]。

::: history
乳腺外科从根治的大切除与腋窝清扫，走向等效而更小的手术，因为试验证明保乳加放疗与全乳切除的生存相同[[pathology/cancer-biology]]、[[public-health/health-systems-economics]]；前哨淋巴结活检减少了腋窝清扫的并发症[[pathology/cancer-diagnosis]]；受体检测与靶向治疗将治疗变得个体化[[immunology/tolerance-regulation]]、[[pharmacology/drug-development-prescribing]]；筛查项目与双读片降低了死亡，也带来了过度诊断的辩论[[public-health/screening]]；而甲状腺与内分泌外科从极高的死亡率走到常规，靠的是对解剖与生理（钙与声音与气道）的理解[[endocrine/thyroid]]、[[renal/potassium-calcium-phosphate]]、[[surgery/perioperative-care]]。
:::

::: summary
- 乳腺的评估是三联：临床、影像与组织学；任何一环正常都不能单独排除癌[[#ex-dense]]。
- B3的类别是不确定的，需要切除活检而不是观察[[#def-breast]]。
- 治疗按分期与受体：手术（保乳或切除、腋窝与重建）、放疗与全身治疗[[#def-breast]]。
- 甲状腺与甲状旁腺手术要按特定的并发症照护：声音、钙与颈部肿胀[[#def-endocrine-neck]]。
- 肾上腺的意外发现必须先筛查激素分泌；嗜铬细胞瘤在手术前必须先阻断[[endocrine/adrenal]]。
:::

## 练习

::: exercise 安排结节门诊 {level=1}
为一位55岁、有3厘米可触及肿块、影像为4C级的患者安排门诊：今天做什么、由谁做、时间线如何。
::: solution
**4C意味着高度可疑，应在同一次就诊中完成粗针活检，并同时评估腋窝（超声加针吸）[[clinical-skills/medical-imaging]]、[[pathology/diagnostic-pathology]]。同意谈话要说明活检的目的与术前的标记（在可能保乳时放置定位标记）[[medical-ethics-law/consent-capacity]]、[[surgery/perioperative-care]]。时间线：数日内出结果、提交多学科肿瘤板、并预约手术日期，全程在症状路径的时限内[[public-health/screening]]、[[public-health/health-systems-economics]]、[[clinical-skills/records-handover]]。同时提供乳腺护士与重建的信息并讨论家属的安排[[clinical-skills/communication]]、[[geriatrics-palliative/symptom-control]]。**
:::
:::

::: exercise 为发现BRCA的人提供咨询 {level=2}
一位39岁的女性在乳腺癌治疗后被告知她携带BRCA1致病性变异。写出咨询内容与可选的方案。
::: solution
**先把结果讲清：终身的风险、遗传的方式与代际的传递，以及卵巢与输卵管的风险[[genetics/genetic-testing]]、[[genetics/cancer-genetics]]、[[obstetrics-gynaecology/gynaecological-cancer]]。可选方案：加强监测（MRI与X线交替）、药物的预防、减少风险的手术（乳腺切除与输卵管卵巢切除），以及生育的考虑[[public-health/screening]]、[[pharmacology/drug-development-prescribing]]、[[obstetrics-gynaecology/contraception-fertility]]、[[obstetrics-gynaecology/early-pregnancy]]。家庭层面：级联检测与沟通的困难与对孩子的忧虑[[genetics/genomic-medicine]]、[[clinical-skills/communication]]、[[medical-ethics-law/confidentiality]]、[[psychiatry/anxiety-disorders]]。重大的决定不应在一次门诊中完成：安排第二次谈话与第二意见[[clinical-skills/records-handover]]、[[public-health/health-systems-economics]]。**
:::
:::

::: exercise 处理甲状腺切除后的危机电话 {level=2}
全甲状腺切除后第1天护士来电：喘鸣、口周麻刺感、校正钙1.9、声音不对、颈部发紧但引流在工作。你在电话里说什么？
::: solution
**先给指令：让护士留在床边、呼叫帮助、备好气道抢救车，并给静脉钙（有症状且钙1.9需要静脉治疗而不是口服）[[endocrine/bone-calcium]]、[[renal/potassium-calcium-phosphate]]、[[emergency-critical-care/airway-ventilation]]。喘鸣加颈部发紧要警惕血肿压迫气道：立即外科评估，必要时在床边拆开缝线减压，然后回手术室[[surgery/perioperative-care]]、[[emergency-critical-care/critical-care]]、[[surgery/wounds-surgical-infection]]。声音异常要记录，并在事后做喉部评估以明确喉返神经[[clinical-skills/records-handover]]、[[nervous-system/sensory-systems]]。同时查镁与磷酸盐与心电图的QT间期，把静脉钙滴定，并用口服钙与活性维生素D过渡[[endocrine/thyroid]]、[[cardiovascular/arrhythmias]]。**
:::
:::

::: exercise 读腋窝 {level=1}
新诊断的3厘米ER阳性、HER2阴性左侧乳腺癌；腋窝超声正常；手术的前哨淋巴结含三个宏转移；计划全乳切除。澄清决定。
::: solution
**前哨阳性把治疗推向腋窝的处理与区域淋巴结的放疗；试验提示放疗可以替代清扫而获得相当的局部控制，因此决定要按负荷与全身治疗一起定[[pathology/cancer-diagnosis]]、[[clinical-skills/medical-imaging]]、[[surgery/perioperative-care]]。要说清利弊：区域放疗提高局部控制并减少腋窝复发，而腋窝清扫增加淋巴水肿与肩部的活动问题[[geriatrics-palliative/symptom-control]]、[[respiratory/mechanics-breathing]]。全身治疗：内分泌治疗是基础，再按分级与Ki67和淋巴结数目考虑化疗[[immunology/tolerance-regulation]]、[[pharmacology/drug-development-prescribing]]、[[pathology/cancer-biology]]。重建的时机与放疗的顺序、以及植入物在放疗下的表现，也应在同一次谈话中讨论[[clinical-skills/communication]]、[[clinical-skills/records-handover]]。**
:::
:::

::: exercise 设计一站式乳腺门诊 {level=3}
为一个60万人口的地区配置并评估一个症状导向的一站式乳腺门诊：人员、影像、病理、遗传、护理、审计与公平设计。
::: solution
**核心是当日完成三联：评估医师、技师、超声与乳腺X线在同一地点，粗针活检与定位标记在同一次访问中完成，病理在数日内出报告[[clinical-skills/medical-imaging]]、[[pathology/diagnostic-pathology]]、[[public-health/screening]]。人员：乳腺外科、放射、病理、乳腺护士、顾问护士、心理支持与重建的通道[[public-health/health-systems-economics]]、[[psychiatry/anxiety-disorders]]、[[clinical-skills/communication]]。遗传：把BRCA与其他基因的检测及级联检测与门诊流程相连[[genetics/genetic-testing]]、[[genetics/cancer-genetics]]。公平设计：翻译服务、交通与停车、可预约的时间段、多种语言的提醒，因为不来诊集中在被剥夺的群体[[public-health/determinants-inequalities]]、[[public-health/prevention-promotion]]。审计：从转诊到诊断的时间、不来诊的比率、分期分布与患者报告的结局[[clinical-skills/patient-safety]]、[[clinical-skills/records-handover]]。**
:::
:::

::: exercise 处理不确定的细胞学 {level=2}
一个1.9厘米实性结节的Bethesda III（意义不明的异型）；患者问这是不是癌，以及是否需要切除甲状腺。诚实使用数字并给出路径。
::: solution
**诚实的数字：Bethesda III在重复取材或手术标本中约有10到30%最终为恶性，因此既不是癌也不是良性；观察、重复取材、分子检测或诊断性的腺叶切除都是选项[[pathology/diagnostic-pathology]]、[[endocrine/thyroid]]、[[clinical-skills/medical-imaging]]。路径：结合超声的形态分级、结节大小、淋巴结与家族史来分层[[clinical-skills/physical-examination]]、[[genetics/cancer-genetics]]。手术：在高度可疑的形态、症状或患者意愿下做一侧腺叶切除，以术后的病理作最终决定[[surgery/perioperative-care]]、[[endocrine/thyroid]]。沟通：不要说结节不摄取显像所以安全，也不要说细针已经定性；说明不确定性与下一步的时限[[clinical-skills/communication]]、[[medical-ethics-law/consent-capacity]]、[[clinical-skills/records-handover]]。**

::: exercise 治疗恶性的高钙 {level=2}
一位74岁已知的乳腺癌患者，钙3.4，意识混乱、脱水、急性肾损伤，正在用噻嗪类的利尿剂与钙-维生素D的药片。给出最初的48小时与之后一个月，包括陷阱。
::: solution
**最初的48小时：停用噻嗪与钙和维生素D；用等张盐水扩容以恢复尿量并纠正肾损伤；然后给双膦酸盐（在肾功能允许时）或地舒单抗，并监测钾、镁与液体平衡[[renal/potassium-calcium-phosphate]]、[[endocrine/bone-calcium]]、[[renal/acute-kidney-injury]]、[[renal/water-sodium]]。陷阱：把袢利尿剂当成主要治疗（只在容量充足后作为辅助）、把意识改变归因于年龄或药物、以及忘记数天后的反跳性低钙[[geriatrics-palliative/polypharmacy]]、[[nervous-system/dementia-neurodegeneration]]、[[cardiovascular/arrhythmias]]。机制：在乳腺癌中骨的溶解与体液因素常并存，因此治疗肿瘤本身才能减少复发[[pathology/cancer-biology]]、[[pharmacology/drug-development-prescribing]]。之后一个月：监测钙、做口腔评估（下颌骨坏死的风险）、继续骨的保护与跌倒的预防，并就反复高钙时的姑息优先与目标展开讨论[[geriatrics-palliative/palliative-care]]、[[geriatrics-palliative/falls]]、[[medical-ethics-law/end-of-life-ethics]]。**

::: exercise 评估你们的筛查邀请信 {level=3}
评估你们地区的乳腺筛查的邀请信：把它当作公平的干预与知情同意的文件来读，并提出改变。
::: solution
**作为公平干预来读：语言难度、语言的版本与可及性（字号与屏幕阅读）决定参与，而不平等地区的参与最低[[public-health/determinants-inequalities]]、[[public-health/screening]]、[[public-health/prevention-promotion]]。作为知情同意来读：信要说清获益（相对的死亡下降）与伤害（假阳性、过度诊断与不适），因为具体数字支撑自主的决定[[public-health/screening]]、[[medical-ethics-law/consent-capacity]]、[[clinical-skills/communication]]。改变：用平衡的语言、每千人的图示与多语版本和简短视频，并测试理解[[public-health/health-systems-economics]]、[[clinical-skills/patient-safety]]。评估：把信的版本做随机的对比，按人群分层参与率，并追踪被邀请者的诊断分期[[epidemiology-ebm/randomised-trials]]、[[public-health/screening]]、[[clinical-skills/records-handover]]。**
