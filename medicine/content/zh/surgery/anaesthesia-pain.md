1846年以前，手术是在患者清醒的状态下进行的，由助手按住患者，动作最快的外科医生就是最好的外科医生。麻醉改变了这一切：它使长时间、精细的手术成为可能，并把手术从最后的手段变成了常规治疗。如今，全身麻醉是医院里最安全的事情之一，但这种安全来自细致的评估、持续的监测，以及对罕见急症反复演练过的应对。

本章解释全身麻醉和区域麻醉的作用及其实施方式、气道的管理、手术室里每位医生都应识别的急症，以及术后急性疼痛的治疗。指南以英国为主（麻醉医师协会、皇家麻醉医师学院、困难气道学会和 NICE），内容截至2026年。药物细节用于解释原则；个体患者的剂量以现行处方集和当地方案为准。

## 全身麻醉

::: definition 全身麻醉 {#def-general}
**全身麻醉**是一种由药物引起的可逆状态，患者处于无意识状态，对手术刺激没有反应。它通常被描述为三个组成部分的平衡，即**麻醉三要素**：

- **催眠**（意识消失和遗忘），由静脉或吸入麻醉药产生；
- **镇痛**（减弱对疼痛刺激的反应），由阿片类药物、局麻药阻滞和其他镇痛药产生；
- **肌肉松弛**，在手术或气道需要时由神经肌肉阻滞药产生。

一次麻醉分为三个阶段：**诱导**（入睡）、**维持**（手术期间保持睡眠）和**苏醒**（醒来）。
:::

### 药物

**静脉诱导药**在一个臂-脑循环时间（约30秒）内起效。**丙泊酚**（propofol）是使用最广的诱导药。它增强抑制性 GABA-A 受体的作用，引起血管扩张和血压下降，并抑制气道反射，因此适合置入声门上气道装置。**氯胺酮**（ketamine）阻断 NMDA 受体；它比丙泊酚更能维持血压和气道反射，适用于休克患者，但可引起不愉快的苏醒反应。**硫喷妥钠**（thiopental）现在主要在一些医院用于快速顺序诱导。

单次注射丙泊酚后患者醒来，并不是因为药物被代谢，而是因为它从脑重新分布到肌肉和脂肪中。对于较长时间的麻醉，丙泊酚可以持续输注（**全凭静脉麻醉，TIVA**），通常使用计算机控制的泵，以计算出的血浆或脑内浓度为目标。

**挥发性麻醉药**（七氟烷、地氟烷和异氟烷）是吸入的蒸气，主要用于维持。它们的效能用**最低肺泡有效浓度（MAC）**来描述。

::: definition 最低肺泡有效浓度 {#def-mac}
吸入麻醉药的**最低肺泡有效浓度（MAC）**是指在一个大气压下，使50%的患者对标准的手术切皮刺激不发生体动的肺泡浓度。MAC 越低，药物效能越强。健康中年成人的近似值为：七氟烷约2%，地氟烷约6%，异氟烷约1.2%。MAC 随年龄增长、低体温、妊娠以及使用阿片类药物或其他镇静药而降低，在幼儿中升高。
:::

由于 MAC 是群体平均值，手术期间通常使用约1.0–1.3 MAC，使大多数患者不发生反应。呼气末浓度被持续测量，近似于肺泡浓度。挥发性麻醉药是强效的温室气体，地氟烷尤甚，许多英国医院已出于环境原因停用地氟烷。

**阿片类药物**（芬太尼、瑞芬太尼、吗啡）提供镇痛，并减弱插管和手术引起的心血管反应。瑞芬太尼被血浆酯酶分解，因此无论输注多久，停止输注后几分钟内作用即消失。

**神经肌肉阻滞药**作用于神经肌肉接头的烟碱型乙酰胆碱受体，使骨骼肌麻痹。它们不会引起意识消失，因此被肌松的患者必须始终处于充分的麻醉之下。

- **琥珀胆碱**（suxamethonium）是*去极化*肌松药：它打开受体并使膜保持去极化。它在一分钟内起效，约5–10分钟后作用消失，因为血浆胆碱酯酶将其分解。遗传性或获得性缺乏这种酶的人可能会麻痹数小时。其副作用包括肌肉疼痛、血钾升高（在烧伤、挤压伤或失神经支配后有危险）以及诱发恶性高热。
- **罗库溴铵、维库溴铵和阿曲库铵**是*非去极化*肌松药：它们在受体上与乙酰胆碱竞争。其作用可用**新斯的明**（一种抗胆碱酯酶药，与格隆溴铵合用以阻断其毒蕈碱样作用）拮抗；对于罗库溴铵和维库溴铵，也可用**舒更葡糖钠**（sugammadex）拮抗，它直接与药物分子结合。

阻滞深度用神经刺激器监测，采用**四个成串刺激（TOF）**：以2 Hz 给予四个刺激。随着阻滞加深，肌颤搐逐渐衰减并消失。定量监测仪测量 **TOF 比值**（第四个颤搐除以第一个）；拔管前比值至少要达到0.9，因为低于此值的残余肌无力会损害吞咽和呼吸。

### 监测

麻醉医师协会的标准（2021年）要求麻醉医生全程在场，并为每一次全身麻醉规定了最低监测：脉搏血氧饱和度、无创血压、心电图、**持续波形二氧化碳描记**、吸入氧和麻醉蒸气浓度，以及气道压力。只要使用神经肌肉阻滞药就必须进行神经肌肉监测；当 TIVA 与神经肌肉阻滞合用时，建议使用处理过的脑电图（"麻醉深度"）监测，因为这种组合的术中知晓风险最高。任何超过30分钟的操作都要测量体温。

二氧化碳描记值得强调。误插入食管的导管看起来可能位置正确，甚至能引起胸廓起伏，但不会产生持续的二氧化碳波形。困难气道学会将其概括为**"无波形 = 位置错"**：插管后没有二氧化碳描记波形，就应认为导管不在气管内，直到证明并非如此——即使在心脏骤停时也是如此，因为胸外按压仍会产生小的波形。

## 气道

全身麻醉下，患者的舌和咽部肌张力消失，保护性反射也消失。气道必须保持通畅并受到保护，主要有三种方法：

- **面罩**配合口咽或鼻咽通气道，用于短小操作或插管前；
- **声门上气道装置**（如喉罩），罩在喉的上方，用于许多已禁食患者的择期手术；
- **气管导管**，穿过声带，带有封闭气管的套囊。它能防止误吸，用于腹部和胸部手术、有误吸风险的患者以及需要长时间确保气道的情况。

麻醉前的**气道评估**寻找困难气道的预测因素：既往困难插管、张口受限、下颌小或后缩、颈部活动受限、肥胖、阻塞性睡眠呼吸暂停、胡须，以及头颈部病变。没有任何单一测试能很好地预测困难气道，因此麻醉医生综合考虑这些因素，并始终准备好应对失败的计划。

::: definition 快速顺序诱导 {#def-rsi}
**快速顺序诱导（RSI）**是在胃可能未排空时使用的技术，如肠梗阻、急诊手术、近期创伤或妊娠晚期。先给患者预充氧，使肺内充满氧气，然后给予固定剂量的诱导药，紧接着给予快速起效的神经肌肉阻滞药（大剂量罗库溴铵或琥珀胆碱）。在带套囊的气管导管就位之前，避免或只轻柔地进行球囊面罩通气，以免胃充气。可施加**环状软骨压迫**以压闭食管，但其益处存在争议，如果它使插管困难就应松开。
:::

当插管意外困难时，**困难气道学会（DAS）**的指南（2025年更新）提供了一系列计划。整个过程的首要任务是**氧合**，而不是插管：

- **计划 A：**插管，通常使用可视喉镜，并限制尝试次数。
- **计划 B：**如果插管失败，置入声门上气道装置进行氧合。
- **计划 C：**如果仍失败，进行面罩通气，并在可能时唤醒患者。
- **计划 D：**如果患者既无法插管又无法氧合（**CICO**），实施紧急**颈前气道**：经环甲膜做手术刀切口，置入探条和小号带套囊导管。

每一步都必须大声宣布，让团队知道处于流程中的哪个位置。反复尝试喉镜检查会造成肿胀和出血，使之后的每一次尝试更加困难。

## 区域麻醉

::: definition 区域麻醉和局部麻醉 {#def-regional}
**局麻药**阻断神经膜上的电压门控钠通道，使动作电位无法传导。**区域麻醉**利用局麻药阻断身体某一部位的感觉：

- 伤口的**局部浸润**；
- 对某一神经或神经丛的**外周神经阻滞**，通常在超声引导下进行（如髋部骨折时的股神经或髂筋膜阻滞，或上肢手术时的臂丛阻滞）；
- **椎管内阻滞**：**脊髓麻醉**（在脊髓末端以下向脑脊液中单次注射，数分钟内产生持续1–3小时的完善麻醉）或**硬膜外麻醉**（在硬膜外腔置入导管，可连续输注数天）。

细小的无髓鞘自主神经纤维最先被阻滞，然后是感觉纤维，最后是运动纤维。这就是为什么脊髓麻醉在患者丧失下肢活动能力之前就会引起**低血压**（交感神经阻滞导致血管扩张）。
:::

区域麻醉技术可避免全身麻醉的某些风险，提供延续到术后的良好镇痛，并减少阿片类药物的需要。它们可以在患者清醒或镇静时单独使用，也可以与全身麻醉联合使用。

椎管内阻滞有很小的**脊髓或硬膜外血肿**风险，血肿可压迫脊髓。服用抗凝药的患者风险最大，因此指南（麻醉医师协会和专科学会）规定了最后一次抗凝药与穿刺针或导管置入或拔除之间的最短间隔。例如，预防剂量的低分子量肝素通常应在椎管内阻滞前至少12小时给予，治疗剂量至少24小时。椎管内阻滞后出现严重背痛、新发下肢无力或麻木是急症，需要紧急 MRI 和神经外科会诊。

### 局麻药剂量

每种局麻药都有最大安全剂量，通常以 mg/kg 表示，因为血液中的药量过多会引起中毒。加入肾上腺素可减慢吸收并提高最大剂量。溶液以百分比标示，换算对每种药物都相同：**1% = 1 g/100 mL = 10 mg/mL**。

::: example 局麻药剂量核查 {#ex-la-dose}
一位50 kg 的女性需要在局麻下切除一个较大的皮肤病灶。科室采用的示意性最大剂量为单纯利多卡因3 mg/kg。按此规则，她最多可接受多少体积的1%单纯利多卡因？
::: solution
**最大剂量：**$3\ \text{mg/kg} \times 50\ \text{kg} = 150$ mg。

**浓度：**1%利多卡因含10 mg/mL。

**最大体积：**$150\ \text{mg} \div 10\ \text{mg/mL} = 15$ mL。

还有两点。如果使用2%利多卡因，同样的150 mg 只有7.5 mL；混淆浓度是常见的过量途径。而且按体重计算的规则要与处方集中规定的绝对最大剂量结合使用，取两者中较低者，在衰弱、高龄或血供非常丰富的部位还要进一步减量。这个计算是一种安全核查，而不是目标剂量。
:::
:::

## 麻醉急症

麻醉下的严重急症很少见，这正是要反复演练的原因。每种急症都有可识别的模式和具体的首要行动。

::: definition 麻醉急症 {#def-emergencies}
- **严重过敏反应：**突发低血压、支气管痉挛或气道压力升高、心动过速，有时有皮疹或肿胀（皮肤体征可能缺如或被手术单遮盖）。在英国第六次国家审计项目（NAP6，2018年）中，最常见的诱因是抗生素（尤其是替考拉宁和阿莫西林克拉维酸）、神经肌肉阻滞药、氯己定和专利蓝染料。治疗是肌内注射或静脉滴定**肾上腺素**、补液并去除诱因，之后采集肥大细胞类胰蛋白酶样本并转诊至过敏专科门诊（[[emergency-critical-care/anaphylaxis]]）。
- **局麻药全身毒性（LAST）：**口周麻刺感、耳鸣和激动，进展为抽搐、心律失常和心脏骤停。停止注射、呼救、处理气道和抽搐，并给予**静脉脂肪乳剂**。复苏可能需要持续很长时间。
- **恶性高热：**一种骨骼肌兰尼碱受体的遗传性疾病（通常为 *RYR1* 变异）。挥发性麻醉药或琥珀胆碱触发肌肉中不受控制的钙释放，导致增加通气后呼气末 CO₂ 仍持续上升、心动过速、肌肉强直（包括咬肌痉挛）、高钾血症，以及较晚出现的高热。停用触发药物，用100%氧气过度通气，给予**丹曲林**（dantrolene），降温并治疗高钾血症。患者及其亲属要转诊进行检测。
- **喉痉挛：**声带的反射性关闭，通常发生在诱导或苏醒期麻醉较浅时。用100%氧气、托下颌和持续正压处理，如持续存在则加深麻醉或给予小剂量琥珀胆碱。
- **高位或全脊髓麻醉：**局麻药扩散过高，引起低血压、心动过缓、呼吸困难和意识丧失。对气道、呼吸和循环进行支持治疗。
- 全身麻醉下的**意外术中知晓**：患者在麻醉的部分时间内是清醒的。第五次国家审计项目（NAP5，2014年）发现，自发报告的发生率约为每19,000例全身麻醉中1例，在使用神经肌肉阻滞、剖宫产和 TIVA 时更常见。
:::

::: example 抗生素后的气道高压 {#ex-anaphylaxis}
一位45岁女性在麻醉下接受腹腔镜胆囊切除术。静脉给予阿莫西林克拉维酸5分钟后，她的血压从120/70降至60/30 mmHg，心率升至135次/分，气道压力升高并有哮鸣音。看不到皮疹。可能的诊断是什么？紧急处理是什么？
::: solution
**诊断。**静脉给药后数分钟内出现严重低血压和支气管痉挛，在被证明不是之前应视为严重过敏反应。没有皮疹并不能排除它；在 NAP6 中，皮肤体征起初常常缺如，而低血压是最常见的首发表现。

**紧急处理。**

1. 呼救并宣布严重过敏反应。停用任何可能的诱因（抗生素已经给予；还要考虑氯己定和其他药物）。
2. 给予100%氧气，维持气道和通气。
3. 给予**肾上腺素**；在麻醉下由麻醉医生以小剂量静脉推注滴定，如果没有静脉通路则肌内注射。
4. 抬高双腿，快速静脉输注晶体液。
5. 如无反应，开始肾上腺素输注，并按严重过敏反应流程处理，包括难治性支气管痉挛的治疗。
6. 在复苏开始后尽快抽血检测**肥大细胞类胰蛋白酶**，并在1–2小时及之后再次检测。

**事后：**手术通常推迟；她在重症监护病房接受监测；记录并上报这一反应；并转诊至专科过敏门诊，对她所接受的所有药物进行检测。要告诉她发生了什么，并提供书面信息。
:::
:::

::: example 上升的二氧化碳 {#ex-mh}
一位19岁男性在七氟烷全身麻醉下接受急诊阑尾切除术。20分钟时，尽管分钟通气量已加倍，他的呼气末 CO₂ 仍从4.8 kPa 升至9.5 kPa。心率140次/分，下颌僵硬，钠石灰罐发热。体温37.9 °C。发生了什么？
::: solution
**判断。**增加通气后呼气末 CO₂ 仍上升，说明 CO₂ 产生大大增加。合并心动过速和肌肉强直，在被证明不是之前应视为**恶性高热**。高热常常是*晚期*体征，因此体温正常或稍高并不能排除它。也要考虑 CO₂ 升高的其他原因（吸收剂耗竭、重复吸入、脓毒症、甲状腺危象），但不能因此延误治疗。

**处理。**呼救并取来恶性高热急救箱。停用挥发性麻醉药，改为静脉麻醉，用高流量新鲜气体和100%氧气过度通气。给予**丹曲林**，它减少肌浆网的钙释放，重复给药直至体征缓解。积极降温；治疗高钾血症和心律失常；监测尿量以发现肌红蛋白尿，并测量肌酸激酶。请外科医生尽快结束手术。之后他需要进入重症监护，并与家人一起转诊至国家恶性高热中心进行基因和肌肉检测。
:::
:::

## 术后恶心呕吐

术后恶心呕吐（PONV）是最常见的麻醉并发症之一，也是患者最害怕的事情之一。成人的简化 **Apfel 评分**对以下每项各计1分：女性、不吸烟、既往 PONV 或晕动病史、预计术后使用阿片类药物。有0、1、2、3或4个危险因素时，风险分别约为10%、20%、40%、60%和80%。

止吐药作用于不同的受体：**昂丹司琼**（5-HT₃ 拮抗剂）、**地塞米松**（糖皮质激素）、**赛克利嗪**（H₁ 拮抗剂）、**氟哌利多**和**丙氯拉嗪**（D₂ 拮抗剂）。在一项大型析因试验（IMPACT，2004年发表）中，昂丹司琼、地塞米松和氟哌利多各自使 PONV 的相对风险降低约四分之一，联合使用时效应大致相乘。实际意义在于：风险较高的患者接受来自不同类别的更多药物，同时减少病因（如减少阿片类药物用量，或用 TIVA 代替挥发性麻醉药）也有帮助。

## 术后急性疼痛

术后疼痛不仅仅是令人不适。它使患者无法深呼吸和咳嗽，导致肺部感染；推迟下床活动，增加静脉血栓栓塞的风险；升高心率和血压；扰乱睡眠并促发谵妄；而控制不佳的急性疼痛还会增加术后慢性疼痛的风险。

::: theorem 多模式镇痛 {#thm-multimodal}
术后疼痛最好通过联合使用作用于疼痛通路不同部位（外周伤害感受器、外周神经、脊髓和脑）的镇痛药来控制。联合用药能以更低的单药剂量获得更好的镇痛效果，从而减少副作用，尤其是阿片类药物的副作用。在实践中，这意味着规律使用**对乙酰氨基酚**、无禁忌时使用 **NSAID**、尽可能采用**局部或区域麻醉**，而**阿片类药物**仅用于其他药物无法控制的疼痛。
:::

::: proof
伤害感受有几个阶段：伤害感受器对损伤的换能（被前列腺素和炎症介质致敏）、沿外周神经的传导、在脊髓背角的调制，以及在脑内的感知（[[nervous-system/headache-pain]]）。NSAID 减少损伤部位前列腺素的生成；局麻药阻断神经传导；阿片类药物作用于背角和脑内的受体；对乙酰氨基酚通过尚未完全阐明的机制在中枢起作用。由于每种药物阻断不同的阶段，它们的效应可以叠加，而决定副作用的单药剂量就可以保持较低。阿片类药物的副作用（镇静、呼吸抑制、恶心、便秘、尿潴留和肠麻痹）是康复的主要障碍，因此减少阿片类药物的使用是加速康复的直接目标（[[surgery/perioperative-care#def-eras]]）。
:::

镇痛药有重要的注意事项。NSAID 可引起肾损伤（尤其是在脱水、合用 ACE 抑制剂或利尿剂时）、胃肠道出血，并可能使少数患者的哮喘加重。体重低于50 kg 或有肝毒性危险因素的人，对乙酰氨基酚要减量。阿片类药物在肾功能衰竭（尤其是吗啡）和老年人中会蓄积，阿片类药物与其他镇静药（如苯二氮䓬类和加巴喷丁类药物）合用会增加呼吸抑制的风险。

**患者自控镇痛（PCA）**让患者按下按钮获得小剂量静脉阿片类药物，并设有**锁定时间**，在前一剂起效之前不能再给药。它的安全性依赖于这样一个事实：过于嗜睡的患者会停止按按钮。如果由他人按按钮、加入背景输注或同时给予其他镇静药，它就变得危险。使用 PCA 或硬膜外输注的患者需要定期观察镇静评分和呼吸频率，并且必须开具**纳洛酮**处方以处理阿片类药物引起的呼吸抑制。

::: warning
**呼吸频率是阿片类药物中毒的晚期体征，镇静是早期体征。**呼吸频率仍然正常但难以唤醒的患者已经处于危险之中。镇静评分应与呼吸频率一起记录，嗜睡加重时应停用阿片类药物并在呼吸频率下降之前评估患者。吸氧可以在二氧化碳升高时仍使氧饱和度保持正常，因此 SpO₂ 正常不能排除通气不足。
:::

::: example 术后第1天嗜睡的患者 {#ex-opioid}
一位82岁女性全膝关节置换术后第1天。她使用吗啡 PCA，规律服用对乙酰氨基酚，夜间曾服用加巴喷丁。她的肌酐从90升至160 µmol/L。她难以唤醒，呼吸频率9次/分，瞳孔缩小。吸氧2 L/min 时氧饱和度95%。发生了什么？应该怎么做？
::: solution
**判断。**这是阿片类药物中毒。三个因素叠加：肾功能下降时吗啡及其活性代谢物吗啡-6-葡萄糖醛酸苷蓄积；加巴喷丁增加镇静和呼吸抑制，且同样经肾清除；高龄使她对两者都更敏感。她的氧饱和度正常只是因为在吸氧；她的 CO₂ 很可能已升高。

**处理。**停用 PCA 和加巴喷丁。评估气道和呼吸；静脉小剂量滴定给予纳洛酮，直到她能被唤醒且呼吸充分，避免完全逆转，因为完全逆转会引起剧烈疼痛和躁动。由于在肾功能受损时纳洛酮的作用时间短于吗啡，她可能需要重复给药或持续输注并密切监测。查动脉血气。检查并治疗急性肾损伤：如果容量不足则补液，停用肾毒性药物（包括任何 NSAID）。

**随后：**重新制订镇痛计划。恢复规律使用对乙酰氨基酚，考虑区域镇痛技术，如果需要阿片类药物，则按疼痛团队的建议使用较低剂量、较少依赖肾脏排泄的药物。将此事件作为学习事件上报。
:::
:::

传统的**世界卫生组织镇痛阶梯**（非阿片类、弱阿片类、强阿片类）是为癌痛设计的。术后的逻辑恰恰相反：疼痛在开始时最重，并在数天内减轻，因此镇痛从强效开始并逐步*降级*，阿片类药物应尽早停用。患者出院时只带少量药物，并有逐渐减量的明确说明，因为长期使用阿片类药物常常始于手术之后。

::: quiz
一位使用吗啡 PCA 的患者非常嗜睡，但呼吸频率12次/分，吸氧4 L/min 时氧饱和度97%。哪种说法是正确的？
- [ ] 她是安全的，因为呼吸频率和氧饱和度都正常
- [x] 她可能存在通气不足；吸氧可在 CO₂ 上升时使氧饱和度保持正常
- [ ] 应继续使用 PCA，但增加吸氧量
- [ ] 她嗜睡时应由亲属替她按按钮
::: solution
镇静是阿片类药物中毒的早期警示体征。吸氧可在通气不足时仍维持正常的氧饱和度，因此 CO₂ 可能正在上升。应停用 PCA 并紧急评估她。除患者本人外，任何人都不应按 PCA 按钮。
:::
:::

::: history
1846年10月16日，牙医威廉·莫顿（William Morton）在波士顿马萨诸塞州总医院为爱德华·吉尔伯特·阿博特（Edward Gilbert Abbott）施用乙醚，外科医生约翰·柯林斯·沃伦（John Collins Warren）为他切除了颈部肿物。佐治亚州的克劳福德·朗（Crawford Long）在1842年曾使用乙醚但没有发表，霍勒斯·韦尔斯（Horace Wells）1845年的笑气公开演示被认为失败。莫顿演示的消息迅速传开；1847年，爱丁堡的詹姆斯·扬·辛普森（James Young Simpson）引入了氯仿，伦敦的约翰·斯诺（John Snow）研究了这两种药物的生理作用和剂量，并于1853年在维多利亚女王分娩时为她施用氯仿。局部麻醉始于1884年卡尔·科勒（Carl Koller）将可卡因用于眼部，1898年奥古斯特·比尔（August Bier）实施了首例有计划的脊髓麻醉。1942年，蒙特利尔的哈罗德·格里菲斯（Harold Griffith）和伊妮德·约翰逊（Enid Johnson）引入箭毒作为肌松药，使浅麻醉下也能获得良好的手术条件，从而使现代腹部手术成为可能。
:::

## 后续内容

麻醉前患者的准备见[[surgery/perioperative-care]]。受体药理学、药物相互作用和患者间差异见[[pharmacology/drug-receptor]]和[[pharmacology/patient-variation]]。急诊和重症监护中的气道管理见[[emergency-critical-care/airway-ventilation]]，慢性疼痛和癌痛的治疗见[[geriatrics-palliative/symptom-control]]。

::: summary
- 全身麻醉结合**催眠、镇痛以及需要时的肌肉松弛**，经历诱导、维持和苏醒三个阶段。
- 丙泊酚、氯胺酮和挥发性麻醉药产生意识消失；挥发性麻醉药的效能以 **MAC** 表示，MAC 随年龄增长和使用阿片类药物而降低。
- 神经肌肉阻滞药引起麻痹而不引起意识消失；用 **TOF 比值 ≥ 0.9** 排除残余阻滞；舒更葡糖钠可拮抗罗库溴铵和维库溴铵。
- 最低监测包括**持续波形二氧化碳描记**：无波形意味着位置错。
- RSI 保护可能未禁食患者的气道。DAS 的计划 A–D 以**氧合**为首要任务，在 CICO 时以颈前气道告终。
- 局麻药阻断钠通道。最大剂量以 mg/kg 计算；**1% = 10 mg/mL**。LAST 用脂肪乳剂治疗。
- 需要演练的急症：**严重过敏反应**（肾上腺素）、**恶性高热**（丹曲林）、喉痉挛、高位脊髓麻醉和 LAST。
- PONV 风险遵循 **Apfel 评分**；不同类别的止吐药可以联合使用。
- 术后疼痛用尽量减少阿片类药物的**多模式镇痛**治疗；镇静是比呼吸频率更早的阿片类药物中毒警示。
:::

## 习题

::: exercise 三个组成部分 {level=1}
对每种药物，说明它主要提供麻醉三要素中的哪一个：(a) 丙泊酚；(b) 芬太尼；(c) 罗库溴铵；(d) 七氟烷；(e) 股神经阻滞。
::: solution
(a) 催眠。(b) 镇痛（较大剂量时也有助于催眠）。(c) 仅肌肉松弛；它不提供催眠或镇痛，这就是为什么被肌松的患者如果麻醉不充分就有术中知晓的风险。(d) 催眠，通过脊髓作用也有一定的肌松和抑制体动作用。(e) 股神经支配区域的镇痛（感觉阻滞）和运动阻滞。
:::
:::

::: exercise 百分比换算 {level=1 check="7.5"}
按单纯利多卡因3 mg/kg 的示意性最大剂量，50 kg 的患者最多可接受多少毫升 **2%** 单纯利多卡因？给出精确值。
::: hint
先求出以 mg 计的最大剂量，再求出2%溶液每毫升含多少毫克。
:::
::: solution
最大剂量：$3 \times 50 = 150$ mg。2%溶液含 $20$ mg/mL。体积：$150 \div 20 = 7.5$ mL。与[[#ex-la-dose]]中1%溶液的15 mL 相比：相同体积的高浓度溶液剂量加倍。
:::
:::

::: exercise 解读四个成串刺激 {level=1}
手术结束时，定量神经肌肉监测仪显示 TOF 比值为0.6。外科医生问能否拔管。你如何回答？为什么？
::: solution
不能。TOF 比值低于0.9意味着存在明显的残余神经肌肉阻滞。尽管患者可能能够呼吸甚至抬头，但咽部和上气道的肌肉无力，拔管后有气道梗阻、误吸和低氧的风险。应给予拮抗药（如使用了罗库溴铵则用舒更葡糖钠，或在有一定自主恢复后用新斯的明加格隆溴铵），只有在比值达到至少0.9时才拔管。
:::
:::

::: exercise 谁需要快速顺序诱导？ {level=2}
对每位患者，说明是否需要 RSI 及其原因：(a) 一位已禁食、接受择期膝关节镜检查的30岁患者；(b) 一位小肠梗阻、一直在呕吐的70岁患者；(c) 一位妊娠38周、需要在全身麻醉下急诊剖宫产的女性；(d) 一位25岁男性，在腕部骨折前一小时刚吃过饭，现在需要紧急骨折固定。
::: solution
(a) 不需要：胃已排空且没有反流风险；声门上气道装置可能就合适。(b) 需要：无论禁食多久，肠梗阻都会使胃内充满液体，通常在诱导前先经鼻胃管抽吸。(c) 需要：妊娠晚期食管下括约肌张力降低、腹内压升高（正因为如此，尽可能首选区域麻醉）。(d) 如果需要尽快进行全身麻醉，则需要：创伤、疼痛和阿片类药物会减慢胃排空，因此胃内可能仍有食物。区域阻滞可能完全避免全身麻醉。
:::
:::

::: exercise 椎管内阻滞与抗凝药 {level=2}
一位74岁男性计划在脊髓麻醉下接受髋关节置换术，他在前一天晚上20:00注射了预防剂量的低分子量肝素。手术定于08:00。按预防剂量后至少12小时的示意性间隔，脊髓麻醉能否按时进行？术后出现哪些症状属于急症？
::: solution
从20:00到08:00恰好12小时，因此按此规则脊髓麻醉可以在08:00进行，但不能更早，前提是他没有使用会改变时间的其他抗凝药或抗血小板药（必须核对当地指南和其他用药）。术后出现新发或加重的背痛、超出预期阻滞时间仍持续的下肢麻木或无力，或膀胱、直肠失控，可能提示椎管内硬膜外血肿。这需要紧急 MRI 和神经外科会诊，因为结局取决于能否在数小时内减压。
:::
:::

::: exercise 选择镇痛方案 {level=2}
为一位肾功能正常、接受开放右半结肠切除术的58岁男性写一份镇痛方案，并解释每一项。然后说明如果他的 eGFR 为25 mL/min/1.73 m²，方案将如何改变。
::: solution
**方案：**在手术时放置区域镇痛（如胸段硬膜外或腹直肌鞘导管）；规律使用对乙酰氨基酚；无禁忌时规律使用 NSAID；静脉阿片类药物 PCA 或口服阿片类药物用于爆发痛，同时开具纳洛酮和止吐药。监测镇静、呼吸频率和疼痛评分，2–3天后停用区域镇痛并有计划地过渡到口服镇痛。使用阿片类药物时开具缓泻剂。

**理由：**每一项作用于疼痛通路的不同部位，因此联合使用可减少阿片类药物的需要量及其副作用（肠麻痹、恶心和镇静），有利于早期活动和进食。

**eGFR 为25时：**避免使用 NSAID（有进一步肾损伤的风险）；尽可能避免使用吗啡，因为其活性代谢物会蓄积；如需阿片类药物，按疼痛团队或药师的建议，使用较少依赖肾脏的药物并减量；密切监测镇静。区域镇痛技术就更有价值了。
:::
:::

::: exercise PONV 的预防 {level=3 check="round(1/(0.6*0.26))"}
一位35岁女性从不吸烟，既往没有 PONV 或晕动病史，将接受腹腔镜手术，预计术后需要阿片类药物。(a) 她的简化 Apfel 评分是多少？PONV 的大致风险是多少？(b) 假设一种止吐药使这一风险的相对值降低26%。像她这样的患者需要有多少人接受这种止吐药，才能预防一例 PONV？四舍五入到最接近的整数。
::: hint
绝对风险降低等于基线风险乘以相对风险降低。
:::
::: solution
(a) 女性（1）、不吸烟（1）和术后使用阿片类药物（1），评分为 **3**，风险约60%。

(b) 绝对风险降低为 $0.6 \times 0.26 = 0.156$，需治疗人数为 $1/0.156 \approx 6.4$，四舍五入为 **6**。如果她还有晕动病史（评分4，风险约80%），同一种药的绝对风险降低为0.208，需治疗人数约为5。基线风险越高，每种药物使越多的患者获益，这就是为什么高风险患者会接受多个类别的止吐药。
:::
:::

::: exercise 手术室里的虚脱 {level=3}
一位60岁男性在接受大容量局麻药的肌间沟臂丛阻滞10分钟后、全身麻醉诱导之前，变得烦躁，诉口中有金属味，随后发生全身性抽搐。他的心率降至40次/分，QRS 波增宽。给出诊断、鉴别诊断、紧急处理，以及两项降低此事发生概率的措施。
::: solution
**诊断：**局麻药全身毒性（LAST），由血管内注射或快速吸收引起。先出现中枢神经系统症状（口周麻刺感、金属味、烦躁、抽搐），继而出现心脏毒性（心动过缓、传导阻滞、心律失常，可能心脏骤停），这一顺序是典型的。

**鉴别诊断：**血管迷走反应（无抽搐或 QRS 增宽）、严重过敏反应（低血压和支气管痉挛）、原发性癫痫或低血糖（查血糖），以及因注射位置靠近椎管而引起的高位或全脊髓麻醉，肌间沟阻滞时可能发生。

**处理：**停止注射；呼救；给予100%氧气并确保气道，避免低氧和酸中毒，因为它们会加重毒性；用苯二氮䓬类药物或小剂量丙泊酚治疗抽搐；按麻醉医师协会的指南给予**静脉脂肪乳剂**；处理心律失常，要认识到复苏可能需要很长时间，而且常规抗心律失常药的选择有所不同（不使用利多卡因）。如果发生心脏骤停，开始心肺复苏并继续给予脂肪乳剂；可考虑体外循环或 ECMO。

**预防：**事先计算并记录最大剂量；采用超声引导和最低有效容量；注射前回抽，并在观察患者的同时小剂量分次缓慢注射；在所有进行区域阻滞的地方都要随时备有脂肪乳剂。
