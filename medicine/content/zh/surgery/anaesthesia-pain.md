麻醉让手术成为可能，而它的安全取决于监测与处理危机的分钟。本章涵盖全身与区域麻醉的药物与技术、气道与监测，以及术后疼痛与急症的处理[[pharmacology/drug-receptor]]、[[emergency-critical-care/airway-ventilation]]。

本章涵盖麻醉药物与技术、气道与监测、麻醉的急症，以及疼痛的治疗。

## 药物与技术

::: definition 全身麻醉与监测 {#def-general}
**全身麻醉是可逆的意识消失、运动抑制与伤害感受阻断的组合：镇静药（作用于GABA受体的丙泊酚与吸入麻醉药）[[pharmacology/drug-receptor]]、阿片类（钝化应激反应）[[pharmacology/autonomic-drugs]]、以及神经肌肉阻滞剂（为气道与手术条件）[[physiology/muscle]]、[[physiology/synapses]]。气道是核心技能：术前预测困难的插管，并准备逐级上升的计划（面罩、喉镜、视频喉镜、声门上装置，最后是外科气道）[[emergency-critical-care/airway-ventilation]]。监测包括心电、血压、脉搏血氧、呼气末二氧化碳与神经肌肉功能的监控[[clinical-skills/laboratory-tests]]、[[respiratory/control-breathing-tests]]。生理目标是氧合、通气与血压，避免长时间的术中低血压[[cardiovascular/circulation-blood-pressure]]、[[renal/acute-kidney-injury]]。苏醒期要处理恶心、疼痛与寒战，并按目标给氧与观察[[emergency-critical-care/acute-assessment]]。**
:::

::: definition 区域麻醉与急性疼痛 {#def-regional}
**区域技术把局麻药打到神经附近，阻断传导（其顺序是自主、感觉、然后运动）[[pharmacology/autonomic-drugs]]、[[physiology/muscle]]。中枢（椎管内的）：蛛网膜下腔与硬膜外的阻滞，用于下腹与下肢的手术和分娩的镇痛[[obstetrics-gynaecology/labour-birth]]；外周的：神经的阻滞（在超声的引导下）与局部的浸润[[surgery/orthopaedics]]。局麻药的全身毒性：口周的感觉异常与耳鸣，然后是惊厥与心律失常；处理是停止注射、给氧与控制惊厥，并用脂肪乳作为脂溶性的药的解毒[[pharmacology/dosing-principles]]、[[emergency-critical-care/resuscitation]]。并发症：硬膜后的头痛与血肿和感染（在抗凝的时代尤其重要）[[blood/thrombosis-anticoagulation]]、[[surgery/wounds-surgical-infection]]。疼痛的治疗是多模式：对乙酰氨基酚与非甾体的和阿片类，加上区域的技术与非药物的支持，并把副作用（恶心与肠的麻痹和镇静）一起治疗[[gastrointestinal/bowel-disease]]、[[pharmacology/adverse-reactions]]、[[geriatrics-palliative/symptom-control]]。**
:::

::: definition 麻醉的急症 {#def-emergencies}
**气道：不能插管不能通气的路径要求明确的算法与团队的训练和外科的选择[[emergency-critical-care/airway-ventilation]]。误吸：在饱胃与梗阻中风险高，需要快速诱导的保护与胃管[[gastrointestinal/oesophagus-stomach]]、[[respiratory/respiratory-infections]]。过敏：从皮疹到支气管痉挛与休克；处理是肾上腺素与液体并停止触发（神经肌肉的药与抗生素与乳胶最常见）[[emergency-critical-care/anaphylaxis]]、[[immunology/hypersensitivity]]。恶性高热：挥发剂与琥珀胆碱在易感者中触发肌肉的代谢失控（二氧化碳急剧上升、心率快、体温升高与僵直）；处理是丹曲洛林与停止药与降温[[physiology/muscle]]、[[endocrine/endocrine-emergencies]]。低血压与心律失常按原因处理；在清醒阻滞中局麻药的毒性需要即刻的识别[[cardiovascular/arrhythmias]]、[[pharmacology/dosing-principles]]。所有的都需要：早期的呼救、算法、以及事后记录与审计[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]。**
:::

## 危机的分钟

::: example 被抗凝的背 {#ex-epidural-clot}
一根硬膜外的导管原定6点拔除；病房的护士在名单到达前的8点给了依诺肝素的剂量；拔除晚了几小时；到下午患者两腿不能动并诉带状的背痛。
::: solution
**这是椎管内的血肿直到被证明别的：在抗凝的窗口中拔管会造成硬膜外的出血与脊髓的压迫；带状的背痛与进展的瘫痪是标志[[blood/thrombosis-anticoagulation]]、[[#def-regional]]。处理：即刻的紧急评估（MRI）与外科或介入的减压，因为功能的结果按分钟而不是按小时[[clinical-skills/medical-imaging]]、[[nervous-system/motor-systems]]。系统的教训：拔管与剂量的时间规则（在最后一次治疗剂量之后经过足够的时间才拔，而在拔除之后经过足够的时间才给下一剂）必须由开药的与拔管的共同遵守，而护士的给药需要被核对[[surgery/perioperative-care]]、[[clinical-skills/patient-safety]]。预防：把时间与剂量写在患者的记录上，并使用清单[[clinical-skills/records-handover]]。**
:::
:::

::: example 你预测到的困难气道 {#ex-anticipated}
一位56岁强直性脊柱炎的患者需要开腹手术：切迹2厘米、Mallampati 4级、既往放疗、体重指数38；CT显示在胸廓入口压迫气管的纵隔肿块。
::: solution
**多个预测的指标（牙的切迹与颈部活动度与放疗后的组织）加上腔内的压迫意味着一个可能既不能插管也不能通气的气道[[#def-emergencies]]、[[emergency-critical-care/airway-ventilation]]。计划：在有经验的医师与设备的条件下清醒的纤维支气管插管并保留自主的呼吸，并同时准备好救援（声门上的装置与外科的气道）以及肿块的位置的处理[[respiratory/mechanics-breathing]]、[[surgery/perioperative-care]]。陷阱：在麻醉的诱导后失去呼吸的驱动会造成腔内的塌陷与无法通气的局面；镇静会保留呼吸但会失去肌肉的张力[[emergency-critical-care/critical-care]]、[[pharmacology/autonomic-drugs]]。讨论：风险与计划与替代和记录，包括在清醒状态下的同意[[medical-ethics-law/consent-capacity]]、[[clinical-skills/communication]]、[[clinical-skills/records-handover]]。**
:::
:::

::: example 不是低氧的去饱和 {#ex-quiet-desat}
髋关节置换后第二夜在用吗啡的自控镇痛：护士记录空气下饱和84%，嗜睡但可唤醒，呼吸率8，没有二氧化碳的监测，虽然呼吸率被记录为8但她看起来舒适；家属说患者一直在说不要给药片。
::: solution
**阿片类的呼吸抑制会表现为安静的嗜睡与低的呼吸率；饱和正常或轻度下降不能排除高的二氧化碳，而没有二氧化碳的监测时数字会给出虚假的安心[[#def-general]]、[[respiratory/control-breathing-tests]]、[[pharmacology/autonomic-drugs]]。处理：停止阿片类、给被滴定的氧气并监测二氧化碳（在二氧化碳潴留时氧气不能过量）、监测意识与呼吸，并在严重时用拮抗剂并呼叫帮助[[emergency-critical-care/airway-ventilation]]、[[respiratory/respiratory-failure]]。系统的问题：自控镇痛的安全需要教育（患者与护士）与监护和剂量的限制，以及家属作为观察者的角色被鼓励[[clinical-skills/patient-safety]]、[[surgery/perioperative-care]]。家属的报告（不要给药片）值得被记录与调查，因为这是一个伤害的预警[[clinical-skills/records-handover]]、[[geriatrics-palliative/symptom-control]]。**
:::
:::

::: example 消退得不对的阻滞 {#ex-block-wrong}
膝关节置换后第一天在收肌管阻滞之后：膝不痛但足下垂，患者不能外翻；外科医生认为是阻滞的影响；疼痛团队在下午茶时间被叫来，因为感觉有点奇怪。
::: solution
**收肌管的阻滞影响隐神经（内侧的感觉与膝的疼痛），它不会造成足下垂（腓总神经的支配）；一个不能解释的运动缺损必须被当作一个神经的损伤来评估[[surgery/orthopaedics]]、[[nervous-system/motor-systems]]、[[#def-regional]]。要做：记录运动与感觉的分布与反射与时间；与疼痛和外科和神经的评估共同回顾；并考虑压迫（绷带与体位与止血带）与血肿[[clinical-skills/physical-examination]]、[[pathology/environmental-pathology]]。早的记录很重要：这既是为了患者的治疗（支具与理疗和预后）也是为了坦诚的沟通与学习[[clinical-skills/communication]]、[[clinical-skills/patient-safety]]、[[clinical-skills/patient-safety]]。教训：运动的检查要在阻滞前后被常规记录，而且当症状不符合解剖时，不要把先前的解释当作答案[[nervous-system/sensory-systems]]。**
:::
:::

对一位在接受治疗剂量低分子肝素的外科患者，硬膜外导管拔除的时间规则主要是为了预防：

:::

## 通向何处

受体的机制与剂量在[[pharmacology/drug-receptor]]与[[pharmacology/dosing-principles]]；神经肌肉的生理在[[physiology/muscle]]与[[physiology/synapses]]；气道的路径在[[emergency-critical-care/airway-ventilation]]；过敏与危重时的处理在[[emergency-critical-care/anaphylaxis]]与[[emergency-critical-care/critical-care]]；抗凝与间隔的规则在[[blood/thrombosis-anticoagulation]]；围手术期的系统与转归在[[surgery/perioperative-care]]与[[surgery/wounds-surgical-infection]]；疼痛的控制与症状在[[geriatrics-palliative/symptom-control]]；而同意与坦诚在[[medical-ethics-law/consent-capacity]]与[[clinical-skills/patient-safety]]。

::: history
麻醉始于一次公开演示，从气体到静脉的诱导与维持技术与监测（脉搏血氧与二氧化碳）把死亡从罕见事件降到统计的尾[[clinical-skills/laboratory-tests]]、[[clinical-skills/patient-safety]]；神经阻滞从表面的解剖到超声与刺激器[[nervous-system/motor-systems]]；硬膜外的镇痛改变了外科的疼痛与分娩[[obstetrics-gynaecology/labour-birth]]；危机的算法（气道与过敏与局麻药的毒性）来自审计与登记，包括困难气道的报告与训练的模拟[[emergency-critical-care/airway-ventilation]]、[[emergency-critical-care/anaphylaxis]]；而多模式的镇痛与增强恢复把阿片类从治疗的核心移到边缘，以肠功能与活动作为回报[[surgery/perioperative-care]]、[[gastrointestinal/bowel-disease]]。
:::

::: summary
- 全身麻醉是三类药物的组合（镇静、阿片、阻滞），其安全取决于气道的计划与监测和生理的目标。
- 区域技术减少阿片类并改善镇痛，但有时间规则（抗凝）与毒性（局麻药的全身）与并发症（血肿与感染）。
- 麻醉的急症是分钟的工作：气道的算法、误吸的预防、过敏的肾上腺素，以及恶性高热的丹曲洛林。
- 术后疼痛用多模式治疗：按时间的非阿片类加上区域的技术，并主动处理副作用。
- 安静的嗜睡与低的呼吸率是阿片类过量，而不是平静的恢复；没有二氧化碳的监测时饱和的数字会骗人[[#ex-quiet-desat]]。
:::

::: exercise 选择气道的计划 {level=1}
一位体重指数42、有睡眠呼吸暂停与颈部放疗史的患者需要急诊的手术。为全身麻醉写出气道的计划。
::: solution
**假设困难并同时计划失败：预吸氧与被测量的给氧的时间；由有经验者诱导并保留自主呼吸在必要时；工具包括视频喉镜与声门上装置与吸引与外科的气道[[emergency-critical-care/airway-ventilation]]、[[#def-emergencies]]。在急诊与饱胃时按误吸的风险处理（抗酸与快速序列与环状软骨的压力）[[gastrointestinal/oesophagus-stomach]]、[[surgery/acute-abdomen]]。睡眠呼吸暂停者：术后的监护与被滴定的氧，因为对阿片类的呼吸抑制敏感[[respiratory/asthma-copd]]、[[pharmacology/autonomic-drugs]]。设备与人员与位置在切开之前被明确说明，并写在记录中[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]。**
:::
:::

::: exercise 解读四个成串的收缩 {level=2}
在神经肌肉的阻滞之后，四个成串的比值为0.4；患者看起来在动并可以抬头。解释这个数字与风险，并给出行动。
::: solution
**四个成串的比值低于0.9意味着残留的阻滞：肌力可以在大的动作上看起来被保存，而气道与呼吸的肌肉以及保护的反射尚未恢复[[physiology/muscle]]、[[respiratory/control-breathing-tests]]。风险：上气道的塌陷与误吸和低的通气与缺氧的事件[[emergency-critical-care/airway-ventilation]]、[[respiratory/respiratory-failure]]。行动：不拔管或延迟转出；继续支持并给逆转（在氨基药物上胆碱酯酶的抑制与毒蕈碱的副作用，或在甾体的阻滞剂后的特异的结合剂）[[pharmacology/dosing-principles]]、[[physiology/synapses]]。监测到比值达到0.9以上并加上临床的标准[[clinical-skills/laboratory-tests]]、[[surgery/perioperative-care]]。**
:::
:::

::: exercise 打断治疗不足的疼痛的循环 {level=2}
一位髋骨折的老年人在第三天仍然疼痛并拒绝活动，用按需的对乙酰氨基酚与阿片类；她说疼得厉害但护士说数字是4/10。写出这个循环与打断它的处方。
::: solution
**治疗不足有它自己的进展：疼痛→不敢呼吸和活动→肺不张与谵妄和跌倒→更长的住院与更多的疼痛[[geriatrics-palliative/falls]]、[[geriatrics-palliative/delirium-dementia-care]]、[[respiratory/respiratory-infections]]。数字评分在认知受损或文化的人中不可靠，因此要用行为的与功能的测量并按时给治疗[[geriatrics-palliative/ageing-frailty]]、[[clinical-skills/physical-examination]]。处方：按时的对乙酰氨基酚（检查肝）[[gastrointestinal/liver-disease]]、谨慎非甾体的（肾与心）[[renal/chronic-kidney-disease]]、低剂量阿片类与防便秘与恶心[[pharmacology/adverse-reactions]]、以及区域的技术来减少阿片类的需求[[#def-regional]]、[[surgery/orthopaedics]]。加上非药物的（位置与冰与早期的理疗）与记录的目标（睡一夜与走到门口）[[gastrointestinal/clinical-nutrition]]、[[clinical-skills/records-handover]]。**
:::
:::

::: exercise 建立麻醉的同意对话 {level=3}
为一位需要急诊的手术但可能有气道风险的肥胖者设计同意的对话：说什么、怎么说、以及如何在急诊的时间压力下保存同意。
::: solution
**内容：手术的理由与替代、气道的风险与可能的计划（包括清醒的技术与恢复的延迟）、以及术后的问题（监护的床位与疼痛与恶心的可能）[[medical-ethics-law/consent-capacity]]、[[clinical-skills/communication]]。方式：具体的词与数字（一个会改变决定的风险必须说），留出提问的时间，并使用回述来确认理解[[clinical-skills/communication]]。时间的压力：在急诊中同意可以是简短的对话与被记录的关键；若这些能力受损或有紧迫的危险，则按最佳利益与紧急的框架[[medical-ethics-law/consent-capacity]]→[[medical-ethics-law/consent-capacity]]。记录：被讨论的风险与计划与患者提出的问题；同时给后续（麻醉的访视与电话）[[clinical-skills/records-handover]]、[[surgery/perioperative-care]]。**
:::

## 练习

::: exercise 给虚脱分类 {level=2}
在脊椎麻醉后十分钟，患者出现恶心、心率50与血压70/40且意识丧失。给出机制与处理的顺序，并命名两个必须排除的其他原因。
::: solution
**最常见的是交感被阻断后的血管扩张与静脉的回流下降：心输出量与血压下降，而脑的灌注减少造成意识丧失与恶心[[#def-regional]]、[[cardiovascular/circulation-blood-pressure]]。顺序：呼救与把气道与呼吸保持住、把腿抬高与液体（晶体或胶体）与血管收缩药以及在心率很低时用提前的药物[[emergency-critical-care/shock-fluids]]、[[cardiovascular/arrhythmias]]、[[emergency-critical-care/acute-assessment]]。必须排除：局麻药的全身毒性（惊厥与心律失常和耳鸣的前驱）与过敏（皮疹与气道和休克）[[#def-emergencies]]、[[emergency-critical-care/anaphylaxis]]；也考虑心源性的原因（心肌缺血与心律失常）[[cardiovascular/coronary-artery-disease]]。记录与审计包括时间与剂量[[clinical-skills/records-handover]]。**
:::
:::

::: exercise 写镇痛的处方 {level=1}
为一位在肾功能不全与心力衰竭的老年人在腹部的手术之后写一个24小时的多模式镇痛计划。
::: solution
**基础：按时的对乙酰氨基酚（在肝病与低体重时减量）[[gastrointestinal/liver-disease]]、避免非甾体的（肾与心）[[renal/chronic-kidney-disease]]、[[cardiovascular/heart-failure]]。阿片类：低剂量的滴定与严格的监测（呼吸与意识与二氧化碳如果可用），加上预防（泻药与止吐）[[pharmacology/autonomic-drugs]]、[[gastrointestinal/bowel-disease]]。区域的技术优先考虑：硬膜外或腹横肌的平面与伤口的浸润，用以减少阿片类[[#def-regional]]、[[surgery/acute-abdomen]]。目标被写下（睡眠与咳嗽与活动）与测量的工具（在认知受损时行为的评分）[[geriatrics-palliative/ageing-frailty]]、[[clinical-skills/physical-examination]]。每天的药物回顾与副作用的主动处理[[geriatrics-palliative/polypharmacy]]、[[pharmacology/adverse-reactions]]。**

::: exercise 解释恶性高热 {level=2}
一名30岁在用挥发剂与琥珀胆碱诱导的人在分钟内的二氧化碳急剧上升、心率快并且肌肉变得僵硬。解释机制、处理，以及事后的步骤。
::: solution
**机制：骨骼肌钙通道的缺陷（常为受体的基因变异）导致钙的失控释放与肌肉的代谢的失控：二氧化碳急剧上升与氧的消耗和热的产生与钾和肌酸的释放[[physiology/muscle]]、[[genetics/mendelian-inheritance]]、[[endocrine/endocrine-emergencies]]。处理：停止触发（挥发剂与琥珀胆碱）、呼救与使用恶性高热的包（记录的时间与剂量）、给丹曲洛林并用标准的方案、积极降温并处理心律失常与高钾，以二氧化碳的下降作为指引[[emergency-critical-care/critical-care]]、[[renal/acute-kidney-injury]]、[[renal/potassium-calcium-phosphate]]。事后的：转入重症监护与肌酸和钾和尿的检查、把设备去污染与标记，以及家属的咨询和遗传的评估与警示的卡[[genetics/genetic-testing]]、[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]。**
:::

::: exercise 设计自控镇痛的安全系统 {level=3}
为一个外科病房设计静脉自控镇痛的安全系统：患者与护士的教育、处方的控制、监测，以及失效的防线。
::: solution
**患者与护士的教育：谁能使用按钮（患者本人）、剂量限制与风险的信号（嗜睡与呼吸慢），以及家属不得替患者按下按钮[[#ex-quiet-desat]]、[[clinical-skills/patient-safety]]。处方的控制：双人核对与浓度的限制与背景剂量在未用过阿片类者中的避免，以及特殊人群的规则（睡眠呼吸暂停与老年者需要更低的设置）[[respiratory/asthma-copd]]、[[geriatrics-palliative/falls]]、[[pharmacology/dosing-principles]]。监测：规律的呼吸与意识（评分）和二氧化碳在风险的患者，以及升级的标准与团队的呼叫[[emergency-critical-care/acute-assessment]]、[[respiratory/respiratory-failure]]。失效的防线：记录不良事件并做并发症的审计，以及自动的把泵停止在一定的时间或失败的剂量[[clinical-skills/records-handover]]、[[public-health/health-systems-economics]]。指标：疼痛的评分与呼吸的事件和转入重症的次数[[surgery/perioperative-care]]。**
