急腹症是外科最常见的急诊：腹痛、体征与全身反应合在一起，要求在数小时内分辨出需要手术的疾病，同时不漏掉腹腔外的模仿者[[clinical-skills/history-taking]]、[[emergency-critical-care/acute-assessment]]。

本章涵盖急腹症的评估、外科的疾病（梗阻、穿孔、缺血与炎症），以及决策路径与围手术期的医学。

## 识别

::: definition 急腹症的评估 {#def-assessment}
**病史要问起病的速度、部位与转移、性质与伴随症状（呕吐、排便改变、停止排气），以及既往手术与用药[[clinical-skills/history-taking]]、[[gastrointestinal/bowel-disease]]、[[geriatrics-palliative/polypharmacy]]。老年人、免疫抑制者与糖尿病患者的表现会被削弱，所以体征轻微而病情可能很重[[geriatrics-palliative/ageing-frailty]]、[[infectious-diseases/immunocompromised-host]]、[[endocrine/diabetes]]。体检包括生命体征与恶化评分、腹部压痛与肌紧张和反跳痛，以及疝的检查[[clinical-skills/physical-examination]]、[[surgery/gastrointestinal-surgery]]。化验有血常规与生化与炎症标志和乳酸，尿与妊娠试验，以及在提示时的淀粉酶[[clinical-skills/laboratory-tests]]、[[obstetrics-gynaecology/early-pregnancy]]、[[gastrointestinal/pancreas-biliary]]。影像包括立位腹平片、超声与增强CT（怀疑缺血时加动脉相）[[clinical-skills/medical-imaging]]。要想到腹外的模仿：心肌梗死、肺炎、酮酸中毒、肾绞痛与血管炎的腹痛[[cardiovascular/coronary-artery-disease]]、[[endocrine/endocrine-emergencies]]、[[renal/urinary-tract]]、[[musculoskeletal/connective-tissue-vasculitis]]。**
:::

## 外科的疾病

::: definition 梗阻、穿孔、缺血与炎症 {#def-conditions}
**梗阻可以是机械性的（粘连、疝、肿瘤与肠扭转）或动力性的（术后、药物与代谢紊乱），表现为腹痛、呕吐、腹胀与停止排气；CT能显示移行带、梗阻点与肠壁是否缺血[[gastrointestinal/bowel-disease]]、[[surgery/gastrointestinal-surgery]]、[[clinical-skills/medical-imaging]]。处理包括胃肠减压、液体与电解质的纠正，以及在绞窄、闭袢或嵌顿疝时的急诊手术[[renal/water-sodium]]、[[emergency-critical-care/shock-fluids]]、[[surgery/perioperative-care]]。穿孔产生游离气体，先是化学性后是细菌性的腹膜炎；常见来源是溃疡、乙状结肠憩室与肿瘤穿孔，需要复苏、抗生素与急诊手术[[gastrointestinal/oesophagus-stomach]]、[[pathology/acute-inflammation]]、[[infectious-diseases/fever-sepsis]]。缺血来自动脉血栓或栓塞、静脉血栓与非阻塞性的低灌注，典型表现是疼痛与体征不成比例加乳酸升高；治疗是尽早恢复血流并切除坏死的肠[[surgery/vascular-urological-surgery]]、[[cardiovascular/arrhythmias]]。炎症包括阑尾炎、胆囊炎、憩室炎与炎症性肠病，各有其定位的体征与影像[[gastrointestinal/pancreas-biliary]]、[[gastrointestinal/bowel-disease]]。**
:::

## 腹周围的系统

::: definition 决策的路径与围手术期的医学 {#def-pathways}
**决策的核心是三问：是否需要手术、需要多快、以及在哪里做。可用的工具包括评分与影像标准、恶化的升级（恶化评分与快速反应团队）与外科的当班评估[[emergency-critical-care/acute-assessment]]、[[clinical-skills/clinical-reasoning]]、[[clinical-skills/patient-safety]]。判断要综合发现与趋势：一次不确定的评估不等于可以出院，重复的检查与写明的复评时间就是安全网[[clinical-skills/records-handover]]、[[clinical-skills/medical-imaging]]。围手术期的医学包括复苏、适时的抗生素、液体的滴定与保温，以及共病的管理（抗凝、心脏、血糖与肾上腺的覆盖）[[surgery/perioperative-care]]、[[blood/thrombosis-anticoagulation]]、[[endocrine/diabetes]]、[[endocrine/adrenal]]。在老年与衰弱者中，要把目标、并行的姑息照护与重症的上限放在一起谈[[geriatrics-palliative/ageing-frailty]]、[[geriatrics-palliative/palliative-care]]、[[medical-ethics-law/end-of-life-ethics]]。最后，把死亡与并发症的病例回顾做成常规审计，用来改进路径[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]。**
:::

::: example 心房颤动与柔软的腹 {#ex-ami}
一位76岁房颤而未抗凝的患者：脐周痛9/10已6小时，腹软且无压痛，白细胞14，乳酸2.4且在上升，CRP 6；腹盆CT被报告为无急性外科病变，仅小肠轻度扩张。
::: solution
**疼痛与体征不成比例，加上房颤与上升的乳酸，就是肠系膜缺血，直到被证明别的；早期缺血在CT上可以非常隐匿，特别是扫描没有取动脉相时[[#def-conditions]]、[[surgery/vascular-urological-surgery]]、[[clinical-skills/medical-imaging]]。行动：与外科一起重看影像（动脉的阻塞、肠壁强化的减弱与门静脉气体），并请介入或血管外科会诊[[cardiovascular/arrhythmias]]、[[emergency-critical-care/acute-assessment]]。治疗是复苏、抗凝、恢复血流（介入或手术）与切除坏死的肠，并在重症监护中观察[[renal/water-sodium]]、[[blood/thrombosis-anticoagulation]]、[[emergency-critical-care/critical-care]]。教学：一份不放心人的CT不能推翻临床的趋势；高年资的复评与重复的检查就是安全网[[clinical-skills/records-handover]]、[[clinical-skills/clinical-reasoning]]。**
:::
:::

::: example 只是便秘的84岁 {#ex-elderly}
一位84岁的养老院的居民，三天没有大便，意识混乱且不吃东西，淡漠，心率96，体温36.1，白细胞11；腹平片显示粪便充盈；院里要求开泻药；她的基线是独立生活。
::: solution
**老年人的严重腹内病变常表现为功能丧失而不是疼痛：淡漠、不吃与轻度低体温可能就是脓毒症[[geriatrics-palliative/ageing-frailty]]、[[infectious-diseases/fever-sepsis]]、[[emergency-critical-care/acute-assessment]]。粪便充盈不是诊断，只是影像所见；必须排除的是结肠梗阻、乙状结肠扭转、腹膜炎与肠缺血[[#def-conditions]]、[[gastrointestinal/bowel-disease]]、[[clinical-skills/medical-imaging]]。做法：完整体检（包括疝口）与恶化评分、液体复苏与尿量的监测，并做增强CT而不是反复的平片[[renal/water-sodium]]、[[clinical-skills/physical-examination]]。若确诊扭转或梗阻或穿孔，治疗要在手术的选择与目标之间决定，并把患者一贯的意愿与家属纳入[[surgery/gastrointestinal-surgery]]、[[medical-ethics-law/end-of-life-ethics]]、[[clinical-skills/communication]]。记录复评的时间与升级的阈值[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]。**
:::
:::

::: example 妊娠的右侧 {#ex-pregnancy}
妊娠28周：从右侧腰部到右下腹的痛已36小时，呕吐，体温38.4，白细胞15（在妊娠中可以是正常的），尿的试纸显示微量血与1+蛋白，在疼痛的间歇中舒适地躺着，宫底无压痛。
::: solution
**妊娠会把阑尾向上向外推移，而体征会被子宫与妊娠的改变掩盖，因此常见的几个诊断（肾绞痛、先兆产痛、胎盘早剥与阑尾炎）必须同时考虑[[obstetrics-gynaecology/pregnancy-antenatal]]、[[renal/urinary-tract]]、[[gastrointestinal/bowel-disease]]。评估：先做超声（肾与附件与右下腹），需要时用MRI以减少辐射，同时做胎心的监测与产科的评估[[clinical-skills/medical-imaging]]、[[obstetrics-gynaecology/pregnancy-complications]]。要点：微量血尿支持结石但不能排除阑尾炎；白细胞在妊娠中本可升高，所以趋势与体征更有价值[[clinical-skills/laboratory-tests]]。治疗：外科的阈值要放低（穿孔会造成早产与胎儿丢失），而手术在妊娠中是可行的，需要与产科和新生儿团队一起计划[[surgery/gastrointestinal-surgery]]、[[paediatrics/newborn]]、[[surgery/anaesthesia-pain]]。**
:::
:::

::: example 变暗的造口 {#ex-stoma}
乙状结肠切除与端式结肠造口后第6天：造口的尖端变成暗紫色，患者有脓毒症，排出停止，心率118，CRP 260。
::: solution
**暗色或发黑的造口提示缺血甚至坏死，常发生在通过筋膜的那一点；这是外科急症[[#def-pathways]]、[[surgery/gastrointestinal-surgery]]、[[infectious-diseases/fever-sepsis]]。评估：查看黏膜的颜色与光泽、用手电透照造口内部并做指检，同时CT寻找回缩与腹腔积聚[[clinical-skills/physical-examination]]、[[clinical-skills/medical-imaging]]。处理：复苏与抗生素，并回到手术重建或转流，在坏死时切除失活的肠[[surgery/perioperative-care]]、[[emergency-critical-care/shock-fluids]]、[[surgery/wounds-surgical-infection]]。教训：造口的早期缺血会被表面的湿润所掩盖，所以造口的记录与团队的教育 会减少延误[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]。**
:::
:::

## 通向何处

病史与体检在[[clinical-skills/history-taking]]与[[clinical-skills/physical-examination]]；影像的选择在[[clinical-skills/medical-imaging]]；液体与电解质在[[renal/water-sodium]]与[[emergency-critical-care/shock-fluids]]；炎症与腹膜炎的病理在[[pathology/acute-inflammation]]；肠与胆道在专科中在[[gastrointestinal/bowel-disease]]与[[gastrointestinal/pancreas-biliary]]；手术的路径在[[surgery/gastrointestinal-surgery]]与[[surgery/vascular-urological-surgery]]；脓毒症在[[infectious-diseases/fever-sepsis]]；而老年与上限的讨论在[[geriatrics-palliative/ageing-frailty]]与[[medical-ethics-law/end-of-life-ethics]]。

::: history
急腹症的历史是把犹豫变成决策：腹部外科从战场的肠缝合与致死率极高的腹膜炎开始，随着麻醉、无菌与液体治疗而改变[[surgery/anaesthesia-pain]]、[[surgery/wounds-surgical-infection]]、[[emergency-critical-care/shock-fluids]]；阑尾炎在疼痛被定位成一个外科的疾病之后才被理解[[gastrointestinal/bowel-disease]]；影像从立位平片上的游离气体走到超声与增强CT，把诊断从天缩短到小时[[clinical-skills/medical-imaging]]；复苏、抗生素与重症监护降低了手术的死亡[[infectious-diseases/fever-sepsis]]、[[emergency-critical-care/critical-care]]。近年，路径、审计与老年外科把重点从手术技术移到时间的决策与治疗的目标[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]、[[geriatrics-palliative/ageing-frailty]]。
:::

::: summary
- 急腹症的评估是把病史的模式与生理的趋势结合；老年人和免疫抑制者会表现轻微而病情很重[[#def-assessment]]。
- 四种机制覆盖多数病例：梗阻、穿孔、缺血与炎症，每一种都有自己的时间与影像的征象[[#def-conditions]]。
- 疼痛与体征不成比例加乳酸上升是肠系膜缺血，直到被证明别的[[#ex-ami]]。
- 一次不确定的评估不等于出院：写明的复评时间与升级的阈值是安全网[[#def-pathways]]。
- 手术的时机与目标要一起决定，尤其在老年与衰弱者中[[medical-ethics-law/end-of-life-ethics]]。
:::

## 练习

::: exercise 给疼痛定位 {level=1}
给出疼痛模式对应的最可能的诊断：(a) 脐周绞痛伴停止排气；(b) 从上腹到背的穿透性；(c) 转移右下腹的；(d) 弥漫的伴板状腹。
::: solution
**(a) 小肠梗阻（粘连或疝）：绞痛伴呕吐、腹胀与停止排气[[#def-conditions]]、[[gastrointestinal/bowel-disease]]。(b) 胰腺炎，或穿透性的主动脉瘤：疼痛从上腹穿到背部[[gastrointestinal/pancreas-biliary]]、[[surgery/vascular-urological-surgery]]。(c) 阑尾炎：疼痛转移是最典型的模式[[gastrointestinal/bowel-disease]]。(d) 弥漫性腹膜炎（穿孔或缺血）：板状腹与全身反应[[pathology/acute-inflammation]]、[[emergency-critical-care/acute-assessment]]。定位只是第一层，还要与生理的趋势和影像结合[[clinical-skills/clinical-reasoning]]、[[clinical-skills/medical-imaging]]。**
:::
:::

::: exercise 度过梗阻的夜 {level=2}
一位有既往开腹的人被诊断为粘连性小肠梗阻：腹胀、呕吐、CT显示一个移行带但没有壁的改变。写出这一夜与明天的计划。
::: solution
**最初的数小时：胃管减压、用盐水复苏并纠正电解质，记录胃肠引流量、尿量与腹围[[renal/water-sodium]]、[[emergency-critical-care/shock-fluids]]、[[surgery/gastrointestinal-surgery]]。观察的重点是疼痛性质的改变：新出现的持续性疼痛提示绞窄；同时按恶化评分、炎症标志与乳酸追踪[[#def-assessment]]、[[emergency-critical-care/acute-assessment]]。在选定的路径中，水溶性造影剂的通过试验既能预测缓解也可能有帮助[[clinical-skills/medical-imaging]]、[[gastrointestinal/bowel-disease]]。手术的触发：腹膜炎、绞窄、闭袢，或规范的非手术处理在约定的时间后仍未缓解[[surgery/perioperative-care]]。记录复评的时间与外科当班的联系方式[[clinical-skills/records-handover]]。**
:::
:::

::: exercise 应用CT阴性的规则 {level=2}
一位持续腹痛的人的CT被报告为正常；疼痛评分4，白细胞13，心率102。出院还是留下？写出规则与理由。
::: solution
**规则：CT阴性不排除疾病，决定要依靠生理的趋势与临床的能力，而不是单凭一份报告[[#def-assessment]]、[[clinical-skills/clinical-reasoning]]。仍需要阿片类的疼痛与持续的心动过速说明还没有被排除，应留观、由高年资复评并重复检查[[emergency-critical-care/acute-assessment]]、[[clinical-skills/records-handover]]。可以离院的：疼痛减轻、生理正常、能进食，并且有书面的警告与明确的复评地点[[clinical-skills/communication]]、[[clinical-skills/patient-safety]]。陷阱：早期的肠缺血、早期阑尾炎与微小的穿孔可以在早期正常；在女性要想到妇科的原因与妊娠[[obstetrics-gynaecology/early-pregnancy]]、[[gastrointestinal/bowel-disease]]。**
:::
:::

::: exercise 设计急诊普通外科的服务 {level=3}
为一家地区医院设计24小时的急诊普通外科服务：人员、决策、影像与手术、重症与结局。
::: solution
**人员：被覆盖的顾问外科与受训的外科医师，配合随时可用的麻醉与手术室通道，并明确升级的联系方式[[surgery/perioperative-care]]、[[surgery/anaesthesia-pain]]、[[public-health/health-systems-economics]]。决策：一条写明的急腹症路径，含恶化的升级与从入院到手术的时间目标，以及强制的高年资复评[[emergency-critical-care/acute-assessment]]、[[clinical-skills/patient-safety]]。影像与手术：全天候的CT与介入放射，和为急诊保留的手术室时段[[clinical-skills/medical-imaging]]、[[surgery/gastrointestinal-surgery]]。重症与结局：足够神志清醒的床位、并行的姑息照护，以及把时间与并发症公开审计[[emergency-critical-care/critical-care]]、[[geriatrics-palliative/palliative-care]]。公平：按人群与到达方式分层延迟与死亡，以找到被延误的群体[[public-health/determinants-inequalities]]、[[clinical-skills/records-handover]]。**
:::
:::

::: exercise 分辨上腹痛 {level=1}
一位54岁：持续5小时的上腹痛穿到背部并呕吐，有饮酒史，体温37.9，脉搏108，胸片无游离气体，淀粉酶1400。给出接下来三个决定与一个绝不能漏的诊断。
::: solution
**最可能是急性胰腺炎：查超声找结石、查血脂与钙找病因，并用严重度评分和器官功能来分层[[gastrointestinal/pancreas-biliary]]、[[emergency-critical-care/critical-care]]。三个决定：目标导向的液体与充分镇痛，以及在能耐受时尽早经口进食[[emergency-critical-care/shock-fluids]]、[[surgery/anaesthesia-pain]]、[[gastrointestinal/clinical-nutrition]]；确定病因并安排胆源性者的胆囊切除时机[[gastrointestinal/pancreas-biliary]]、[[surgery/gastrointestinal-surgery]]；监测并处理局部并发症（坏死与感染）与器官功能不全[[infectious-diseases/fever-sepsis]]。绝不能漏：穿孔的溃疡与肠系膜缺血，后者尤其表现为疼痛与体征不成比例[[gastrointestinal/oesophagus-stomach]]、[[#ex-ami]]。**
:::
:::

::: exercise 写出憩室炎的医嘱集 {level=2}
一位68岁首次发作，CT为Hinchey Ib的结肠周的3.5厘米脓；在用硫唑嘌呤治疗克罗恩而免疫抑制；其他稳定。门诊抗生素？住院？引流？现在手术？用理由说明。
::: solution
**门诊不合适：免疫抑制会掩盖体征与炎症反应，而带脓的发作需要住院观察[[infectious-diseases/immunocompromised-host]]、[[#def-pathways]]。住院后用静脉抗生素、液体与生理监测，并请外科与介入放射共同评估[[emergency-critical-care/shock-fluids]]、[[microbiology/antimicrobials]]、[[clinical-skills/medical-imaging]]。3.5厘米的结肠周脓在路径可行时应经皮引流，因为它常常可以避免急诊手术[[surgery/gastrointestinal-surgery]]、[[pathology/acute-inflammation]]。即刻手术不作为常规：仅在弥漫性腹膜炎或源头控制失败时；但在免疫抑制者中门槛要更低，因为体征不可靠[[surgery/perioperative-care]]、[[geriatrics-palliative/ageing-frailty]]。炎症消退后安排结肠镜以排除肿瘤，并与炎症性肠病团队讨论长期的用药[[gastrointestinal/gi-bleeding-cancer]]、[[gastrointestinal/bowel-disease]]、[[clinical-skills/records-handover]]。**

::: exercise 处理胆囊切除后的疼痛 {level=2}
在所谓的顺利腹腔镜胆囊切除后第3天：上腹痛加重，胆红素45、ALT 300、淀粉酶900，超声显示胆总管9毫米伴少量游离液体。说出三个机制与处理。
::: solution
**三个机制：残留的胆总管结石（最常见的疼痛与酶升高）；胆道的损伤或被夹闭造成的胆汁漏；以及胆囊管残端或Oddi括约肌相关的漏[[gastrointestinal/pancreas-biliary]]、[[surgery/gastrointestinal-surgery]]。区分依靠酶的与胆红素的模式、MR胰胆管造影与CT上的积液[[clinical-skills/laboratory-tests]]、[[clinical-skills/medical-imaging]]。处理：按胆管炎复苏与用抗生素，行内镜逆行胰胆管造影取石并置支架；若有明显的胆汁漏或损伤，则需引流与在专门中心的重建[[infectious-diseases/fever-sepsis]]、[[gastrointestinal/pancreas-biliary]]、[[surgery/perioperative-care]]。同时如实向患者说明、记录并按损伤上报审计，因为早期识别会改善结局[[clinical-skills/communication]]、[[clinical-skills/patient-safety]]、[[clinical-skills/records-handover]]。**

::: exercise 为你能看到的延迟定价 {level=3}
你们单位从进门到手术的中位数：嵌顿疝11小时、穿孔溃疡9小时；都不达标。为一个会说时间只是行政指标的委员会建立改进的论证。
::: solution
**先给证据：在这两类损伤中，从进门到手术的时间与并发症和死亡相关，所以小时是临床变量而不是行政数字[[#def-pathways]]、[[clinical-skills/patient-safety]]。再拆构成：把时间分成诊断、决策、手术室的可用、麻醉的覆盖与床位，因为改进必须针对具体的环节[[emergency-critical-care/acute-assessment]]、[[surgery/perioperative-care]]。测量：定义从进门到切开的分子与分母，公开看板，并记录每一例延误的原因[[clinical-skills/records-handover]]、[[public-health/health-systems-economics]]。改变：保留急诊的手术时段、建立直接进入手术室的路径、高年资随叫与夜间的能力[[surgery/gastrointestinal-surgery]]、[[surgery/anaesthesia-pain]]。成本：把并发症例数与重症床日的费用换算成钱，改进通常是省钱的[[public-health/health-systems-economics]]。**
