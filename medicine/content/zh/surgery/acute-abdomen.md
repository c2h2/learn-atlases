**急腹症**是指近期起病（通常少于一周）、可能需要紧急治疗（常常是手术）的腹痛。它是急诊入院最常见的原因之一。大多数患者的病情经简单处理即可缓解，但其中有肠穿孔、绞窄性疝、肠缺血或腹主动脉瘤渗漏的患者，对他们来说每一小时都很重要。关键在于及早识别这些患者，对他们进行复苏，并迅速让他们得到正确的治疗。

本章解释腹痛如何产生以及在何处被感知、如何评估患者、四种基本的外科病理过程（炎症、梗阻、穿孔和缺血）、常见疾病、非外科的类似疾病，以及急诊剖腹手术的照护标准。指南以英国为主（NICE、国家急诊剖腹手术审计和各专科学会），内容截至2026年。药物选择以原则形式给出；个体处方遵循当地指南。

## 腹痛为何在那里被感知

腹部的疼痛由两类神经传导，它们的表现不同。

**内脏痛**来自肠壁和脏层腹膜。它由自主神经传入纤维传导，这些纤维在双侧多个节段进入脊髓，因此疼痛**定位不清**，在中线感知，被描述为钝痛、痉挛性痛或绞痛。它由牵拉、扩张和缺血引起，而不是由切割引起。疼痛在哪里被感知取决于器官的胚胎起源：

- **前肠**（食管至十二指肠第二段、肝、胆囊、胰腺）：**上腹部**；
- **中肠**（十二指肠至横结肠近端三分之二，包括阑尾）：**脐周**；
- **后肠**（横结肠远端至肛管上部）：**耻骨上区**。

**躯体痛（壁层痛）**来自壁层腹膜，后者与其上方的腹壁由相同的节段性脊神经支配。它**锐利且定位明确**，活动和咳嗽时加重，并引起局部压痛和肌紧张。

::: theorem 炎症累及壁层腹膜时疼痛发生转移 {#thm-migration}
发炎的器官最初引起疼痛时，疼痛属于内脏痛，按器官的胚胎起源在中线被感知。当炎症扩散到其上方的壁层腹膜时，疼痛变为躯体痛，并转移到器官的实际位置，在那里疼痛锐利并伴有压痛。
:::

::: proof
来自阑尾的内脏传入纤维随交感神经纤维到达脊髓 T10 节段，该节段也接收来自脐周皮肤的传入；因此大脑把这一信号解读为来自脐周。随着阑尾炎症加重，炎症到达右髂窝的壁层腹膜，后者由局部腹壁节段的躯体神经支配，因此此时疼痛被精确地感知在阑尾上方，按压或牵动该处腹膜都会引起疼痛。同样的逻辑解释了为什么胆囊炎始于上腹痛并转移到右上腹，也解释了**牵涉痛**的产生：膈肌受到刺激（被血液或脓液）时，疼痛在肩尖被感知，因为膈神经（C3–C5）与肩部皮肤共享节段。相关解剖见[[anatomy/abdomen]]。
:::

## 评估

::: definition 急腹症的评估 {#def-assessment}
对急性腹痛患者的评估包括四个部分，同时进行：

1. **生理状态优先：**检查气道、呼吸和循环，寻找脓毒症或休克的征象（心率、血压、呼吸频率、体温、尿量、乳酸）。在进一步检查之前先复苏。
2. **病史：**疼痛的部位、起病方式（突发、渐起）、性质（持续性或绞痛性）、放射、严重程度和时间；呕吐、排便习惯和排气；泌尿系统和妇科症状；既往手术；用药（尤其是抗凝药、NSAID、激素和免疫抑制剂）；以及合并症。
3. **体格检查：**一般外观（静卧不动提示腹膜炎；辗转不安提示绞痛）、休克征象、黄疸、腹胀、瘢痕、疝环口（一定要检查腹股沟）、压痛、肌紧张、板状腹和肠鸣音；必要时进行直肠指检。
4. **检查**的选择要回答具体的问题（见下文），包括**对任何可能妊娠者进行妊娠试验**。
:::

**腹膜炎**是腹膜的炎症。**局限性腹膜炎**引起某一区域的压痛和肌紧张。**弥漫性腹膜炎**由广泛的污染（如溃疡穿孔）引起，表现为板状腹、患者静卧不动、任何活动都引起疼痛，并常伴休克。弥漫性腹膜炎通常需要紧急手术。

### 检查

- **血液检查：**全血细胞计数、尿素和电解质、肝功能、**淀粉酶或脂肪酶**、C反应蛋白、静脉或动脉血气及**乳酸**、凝血、血型鉴定与抗体筛查，脓毒症时做血培养。注意，白细胞计数或 CRP 正常并不能排除严重疾病，尤其是在早期或老年和免疫抑制患者中。
- **尿液：**尿液试纸检测和**妊娠试验**（尿或血清 hCG）。
- **立位胸部 X 线片：**膈下游离气体提示空腔脏器穿孔。它快速，但不如 CT 敏感。
- **超声：**怀疑胆囊疾病时的首选检查，也是儿童和孕妇怀疑阑尾炎时的首选检查；也用于妇科病因。
- **腹部和盆腔增强 CT：**对诊断不明的成人来说是最有用的单项检查。它可显示游离气体和液体、梗阻及其原因、炎症、积液以及许多血管急症。怀疑肠系膜缺血或动脉瘤破裂时使用 **CT 血管造影**。

## 四种外科病理过程

::: definition 炎症、梗阻、穿孔和缺血 {#def-conditions}
急性腹痛的大多数外科病因可归入四类，它们可能相互重叠：

- 器官的**炎症**：阑尾炎、胆囊炎、憩室炎、胰腺炎。疼痛持续、逐渐加重，壁层腹膜受累时定位；常有发热和炎症指标升高。
- 管道的**梗阻**：小肠或大肠梗阻、胆绞痛、输尿管绞痛。疼痛呈**绞痛性**（平滑肌对抗阻塞收缩时一阵一阵发作），肠梗阻时伴呕吐和腹胀。
- 空腔脏器的**穿孔**：消化性溃疡穿孔、憩室穿孔、阑尾穿孔。疼痛突然而剧烈，随后出现弥漫性腹膜炎。
- 器官的**缺血**：急性肠系膜缺血、绞窄性疝、肠扭转。疼痛剧烈而持续，早期常与体格检查发现**不相称**，乳酸上升。

患者可以从一类转变为另一类：梗阻的肠袢可能发生缺血，继而穿孔。
:::

## 常见疾病

### 阑尾炎

阑尾炎是最常见的外科急症，在十几岁和二十几岁的人群中最常见。阑尾腔被粪石或淋巴组织增生阻塞，导致扩张、细菌过度生长和炎症，如不治疗可发生坏疽和穿孔。

典型病史是**脐周痛转移至右髂窝**，伴食欲减退、恶心和低热。体格检查时，**McBurney 点**（脐与髂前上棘连线的外三分之一处）有压痛和肌紧张，按压左髂窝时右髂窝疼痛（Rovsing 征），有时伸展右髋时疼痛（腰大肌征，提示盲肠后位阑尾）。许多患者并没有典型表现：盆位阑尾可引起腹泻、泌尿系统症状而腹部压痛很轻，幼儿、老年人和孕妇的表现也常不典型。

临床评分有助于估计可能性。**Alvarado 评分**对以下各项计分：疼痛转移（1）、食欲减退（1）、恶心或呕吐（1）、右髂窝压痛（2）、反跳痛（1）、体温37.3 °C 或以上（1）、白细胞增多（2）和中性粒细胞增多（"核左移"，1），满分10分。低分提示阑尾炎可能性小；高分提示可能性大。阑尾炎炎症反应（AIR）评分和成人阑尾炎评分的表现相近或更好。评分指导是进行影像检查、观察还是手术；它们不能取代判断。

治疗通常是**腹腔镜阑尾切除术**加抗生素。对 CT 显示为单纯性阑尾炎的部分患者，**单用抗生素**也是一种选择：在美国的 CODA 试验（2020年）中，抗生素在30天总体健康状况方面不劣于阑尾切除术，但约十分之三接受抗生素治疗的患者在90天内接受了阑尾切除术，存在**阑尾粪石**时比例更高。这一选择要与患者讨论。

::: example 计算 Alvarado 评分 {#ex-alvarado}
一位19岁男性腹痛18小时，起于脐周，现在位于右髂窝。他没有食欲，呕吐过一次。右髂窝有压痛和反跳痛。体温37.8 °C，白细胞计数 $13.5 \times 10^9$/L，伴中性粒细胞增多。计算他的 Alvarado 评分并概述下一步。
::: solution
**评分：**转移（1）+ 食欲减退（1）+ 呕吐（1）+ 右髂窝压痛（2）+ 反跳痛（1）+ 体温 ≥ 37.3 °C（1）+ 白细胞增多（2）+ 核左移（1）= **10**。

**解读：**9–10分意味着阑尾炎的可能性非常大。对于表现如此的年轻男性，许多外科医生不做 CT 直接行腹腔镜检查；另一些人则先做 CT 确认诊断并寻找并发症，尤其是在考虑抗生素治疗时。

**下一步：**镇痛（缓解疼痛不会掩盖体征）、静脉补液、一旦作出决定按当地指南使用抗生素、禁食、知情同意，并安排腹腔镜阑尾切除术。讨论抗生素治疗的选择、其成功率和复发风险。
:::
:::

### 肠梗阻

**小肠梗阻**最常见的原因是既往手术造成的**粘连**，其次是**疝**（一定要检查腹股沟和瘢痕），较少见的原因有肿瘤、克罗恩病狭窄和胆石性肠梗阻。它引起中腹部绞痛、早期频繁呕吐（胆汁样，以后为粪样）、腹胀和完全性便秘（无排便、无排气），在高位梗阻中后者可能出现较晚。

**大肠梗阻**最常见的原因是**结直肠癌**，其次是**肠扭转**（乙状结肠或盲肠绕其系膜扭转）和憩室性狭窄。它引起逐渐加重的腹胀、便秘，呕吐出现较晚。如果回盲瓣功能完好，结肠就在回盲瓣与梗阻部位之间形成**闭袢**，盲肠可能扩张直至穿孔。

肠梗阻中最重要的问题是肠管是否**绞窄**：即其血供被切断，如在狭窄的疝、闭袢或肠扭转中。提示绞窄的征象有持续性（而非绞痛性）疼痛、压痛、发热、心动过速、腹膜刺激征、乳酸升高和 CT 上的缺血表现。绞窄需要紧急手术。

无绞窄的粘连性小肠梗阻最初通常采用非手术治疗（"**输液加减压**"）：静脉补液并补充电解质、置入鼻胃管为胃减压、镇痛和监测。经管注入**水溶性造影剂**（如泛影葡胺）兼具诊断和可能的治疗作用：如果在约24小时内 X 线片显示造影剂到达结肠，梗阻很可能无需手术即可缓解。如果梗阻不缓解或出现绞窄，则需要手术。

乙状结肠扭转通常用软式乙状结肠镜和肛管排气减压，之后因其易复发而考虑择期切除。盲肠扭转通常需要手术。梗阻性结直肠癌可通过切除、转流性造口，或有时用结肠支架作为手术前的过渡来治疗。

### 穿孔

**消化性溃疡穿孔**引起突然剧烈的上腹痛，随后变为全腹痛，伴板状腹。NSAID、*幽门螺杆菌*（*Helicobacter pylori*）、吸烟和激素是危险因素。立位胸部 X 线片或 CT 显示游离气体。治疗为复苏、抗生素、质子泵抑制剂，通常行腹腔镜或开腹大网膜补片修补。一些不适合手术的患者，若穿孔已封闭，可采用非手术治疗。

### 急性肠系膜缺血

急性肠系膜缺血的原因有肠系膜上动脉**栓塞**（常来自心房颤动）、动脉粥样硬化动脉的**血栓形成**、**静脉血栓形成**，或低血流状态下的**非闭塞性**缺血。典型特征是剧烈疼痛而腹部体征出奇地少。早期乳酸可能正常。诊断依靠 **CT 血管造影**，延误是致命的，因为梗死的肠管会穿孔并引起压倒性的脓毒症。治疗包括抗凝、血运重建（血管腔内或开放手术）和切除坏死肠管，常需计划性的二次探查手术。

::: example 老年女性与体征不相称的疼痛 {#ex-ami}
一位78岁女性患心房颤动，一个月前因鼻出血停用了抗凝药，现因4小时剧烈的持续性中腹痛就诊。她非常痛苦，呕吐过。腹部柔软，仅有轻度压痛。心率110次/分，不规则；血压140/80 mmHg。乳酸3.8 mmol/L。团队应怀疑什么？应该怎么做？
::: solution
**怀疑：**肠系膜上动脉**栓塞**引起的急性肠系膜缺血。关键特征是疼痛剧烈而体征很少（疼痛与体征不相称）、未经抗凝的心房颤动，以及乳酸升高。

**行动：**用氧气、静脉补液和镇痛进行复苏；除非有禁忌，开始肝素抗凝；给予广谱抗生素；申请紧急腹部 **CT 血管造影**；立即请外科、血管外科和介入放射团队参与。如果 CT 证实闭塞，她需要血运重建（取栓或血管腔内治疗），并行剖腹手术评估和切除任何坏死的肠管。

**陷阱：**柔软的腹部会让人产生错误的安心感。等待腹膜炎出现就意味着等待肠管坏死。早期乳酸正常也不能排除这一诊断。
:::
:::

### 胆道急症

胆结石引起一系列疾病（[[gastrointestinal/pancreas-biliary]]）：

- **胆绞痛：**结石暂时阻塞胆囊管，引起右上腹或上腹痛，典型地在餐后发生，持续数分钟至数小时后缓解。无发热，炎症指标正常。
- **急性胆囊炎：**持续的梗阻引起胆囊炎症。疼痛持续时间更长，伴发热、炎症指标升高和 **Murphy 征**（触诊右上腹时疼痛并使吸气中止）。超声显示胆囊壁增厚、有结石，周围有积液。治疗为抗生素，并按 NICE 的建议尽可能**在诊断后1周内行腹腔镜胆囊切除术**。
- **急性胆管炎：**梗阻的胆总管发生感染。**Charcot 三联征**：发热（常伴寒战）、黄疸和右上腹痛。再加上意识模糊和低血压即为 **Reynolds 五联征**，提示严重脓毒症。治疗为复苏、抗生素和紧急胆管引流，通常经 **ERCP**。东京指南（2018年）规定了严重程度分级。
- **胆源性胰腺炎**，见下文。

### 急性胰腺炎

::: definition 急性胰腺炎（修订版亚特兰大分类） {#def-pancreatitis}
满足以下三项标准中的两项即可诊断**急性胰腺炎**：（1）典型腹痛（急性、剧烈、上腹部，常放射至背部）；（2）血清脂肪酶或淀粉酶至少为正常上限的**三倍**；（3）影像学上的特征性表现。严重程度按修订版亚特兰大分类（2012年）分级：

- **轻症：**无器官衰竭，无局部或全身并发症；
- **中重症：**一过性器官衰竭（48小时内缓解）或有局部并发症；
- **重症：****持续性器官衰竭**超过48小时。
:::

在英国最常见的病因是**胆结石**和**酒精**。其他病因包括高甘油三酯血症、高钙血症、药物、ERCP 和创伤。改良 Glasgow（Imrie）评分等评分系统可识别可能发展为重症的患者：在最初48小时内，PaO₂ 低于8 kPa、年龄超过55岁、白细胞计数高于15、血钙低于2 mmol/L、尿素高于16 mmol/L、LDH 或 AST 升高、白蛋白低于32 g/L 和血糖高于10 mmol/L 各计1分；3分或以上预示重症胰腺炎。治疗以支持为主：谨慎的液体复苏（避免补液过多）、镇痛、在耐受时尽早肠内营养，以及器官支持。不常规使用抗生素，仅用于已证实或高度怀疑的感染。胆源性胰腺炎之后要行胆囊切除术，轻症者最好在同一次住院期间进行，以防复发；紧急 ERCP 仅用于合并胆管炎或持续性胆管梗阻时。并发症包括液体积聚、坏死（可能继发感染）和假性囊肿。

### 憩室炎

**憩室病**在西方国家的老年人中很常见，大多位于乙状结肠。**憩室炎**（憩室的炎症）引起左髂窝疼痛、发热和炎症指标升高。复杂性憩室炎包括脓肿、穿孔、瘘（通向膀胱或阴道）和狭窄。**Hinchey 分类**对穿孔性病变分级：I 级，结肠周围脓肿；II 级，盆腔或远处脓肿；III 级，化脓性腹膜炎；IV 级，粪性腹膜炎。

NICE 指南 NG147（2019年）建议对怀疑复杂性憩室炎者行 CT，并提出全身情况良好的单纯性憩室炎患者可以不用抗生素，给予简单镇痛并复查。脓肿足够大时行影像引导引流。化脓性或粪性腹膜炎需要手术，常行 **Hartmann 手术**（切除乙状结肠并做末端结肠造口），部分患者可行切除加吻合。

## 类似疾病：内科、妇科和血管疾病

许多肠道以外的疾病也会引起腹痛，其中一些本身就是急症。仔细的病史和几项检查就能发现它们。

- **腹主动脉瘤破裂：**老年患者（常为吸烟男性）出现腹痛、背痛或腰痛并虚脱。可能被误认为肾绞痛。见[[surgery/vascular-urological-surgery]]。
- **妇科：****异位妊娠**（一定要做妊娠试验）、卵巢扭转、卵巢囊肿破裂、盆腔炎（[[obstetrics-gynaecology/early-pregnancy]]）。
- **泌尿系统：**肾绞痛、肾盂肾炎、尿潴留、睾丸扭转（男孩可表现为下腹痛）。
- **内科：**心肌梗死（上腹痛）、下叶肺炎、糖尿病酮症酸中毒、高钙血症、镰状细胞危象、艾迪生危象、出疹前的带状疱疹，以及急性卟啉病。

::: example 年轻女性的右髂窝疼痛 {#ex-pregnancy}
一位24岁女性右髂窝疼痛12小时。她的末次月经在7周前，并有少量阴道点滴出血。心率104次/分，血压108/70 mmHg。右髂窝有压痛。必须首先做什么检查？为什么？
::: solution
**首先检查：****妊娠试验**（尿 hCG，随后血清 hCG）。对于有腹痛、月经推迟和阴道点滴出血的女性，阳性结果意味着在被证明不是之前应视为**异位妊娠**。她的轻度心动过速可能是异位妊娠破裂早期出血的表现。

**如果阳性：**紧急请妇科团队参与，建立静脉通路，送血型鉴定与抗体筛查或交叉配血，并安排经阴道超声。异位妊娠破裂是外科急症。

**如果阴性：**鉴别诊断包括阑尾炎、卵巢囊肿意外或扭转、盆腔炎和尿路感染。对年轻女性，盆腔和阑尾超声是合理的首选影像检查。

**一般规则：**任何可能妊娠、因腹痛就诊的人，在进行涉及辐射的影像检查和手术之前，都必须做妊娠试验。
:::
:::

::: warning
**不要在外科医生检查患者之前扣留镇痛药。**随机试验和系统综述表明，给急性腹痛患者使用阿片类镇痛药不会降低诊断的准确性，也不会延误治疗。缓解疼痛是人道的，并且使检查更容易。同样，不要因为老年、免疫抑制或使用激素的患者腹部柔软，或因为病程早期白细胞计数或 CRP 正常，而产生错误的安心感。
:::

## 急诊剖腹手术

急诊剖腹手术的风险远高于大多数择期手术：在英国，**国家急诊剖腹手术审计（NELA）**近年的报告显示死亡率约为9%，在老年和更衰弱的患者中则高得多。NELA 推动形成了一系列标准：

- 术前使用经过验证的工具（如 NELA 风险计算器）评估并记录**死亡风险**；
- 对脓毒症患者**1小时内给予抗生素**；
- 在患者足够稳定时术前完成 **CT 并出具报告**，尽可能由顾问医师审阅影像；
- 在与紧急程度相适应的时间内进入手术室；
- 对高危患者，**顾问外科医生和顾问麻醉医生在手术室中在场**；
- 对高危患者提供**术后重症监护**；
- 对老年患者，尤其是衰弱者，由老年医学科医生进行评估。

::: example "只是便秘"的老年患者 {#ex-elderly}
一位84岁、患痴呆的女性因便秘和呕吐3天从养老院被送来。她腹胀，有轻度压痛。心率112次/分，血压102/60 mmHg，体温37.9 °C。乳酸3.1 mmol/L，肌酐168 µmol/L（基线85）。右侧腹股沟耻骨结节外下方有一个小的、有压痛、不能回纳的肿块。可能的诊断和处理计划是什么？
::: solution
**可能的诊断：**嵌顿的**股疝**引起的小肠梗阻，很可能已经绞窄。股疝在老年女性中常见，位于耻骨结节的外下方，疝颈狭窄而坚硬，因此容易绞窄。心动过速、发热、压痛和乳酸升高提示肠管缺血。这里的"便秘"是梗阻引起的完全性便秘。

**计划：**复苏（静脉补液、导尿管、鼻胃管、镇痛、抗生素）；治疗她的急性肾损伤；用 NELA 等工具计算她的风险；请上级外科医生、麻醉医生和老年医学科医生参与；与她的家人或受托人讨论手术的风险和获益。在这个病例中手术很可能是最佳选择，因为不手术的话绞窄性疝会致命，而修补常可经腹股沟切口完成。如有疑问 CT 有帮助，但对于明确的绞窄性疝，不得因此延误手术。

**教训：**一定要检查疝环口，尤其是在有梗阻的老年女性中；股疝很小，容易漏诊。
:::
:::

::: quiz
哪位患者最需要紧急手术，而不是先采用非手术治疗？
- [ ] 一位45岁粘连性小肠梗阻患者，绞痛，腹部柔软，乳酸正常
- [x] 一位60岁小肠梗阻患者，持续性疼痛，局部压痛，发热，乳酸4.2 mmol/L
- [ ] 一位35岁单纯性憩室炎患者，全身情况良好
- [ ] 一位50岁轻症胆源性胰腺炎患者

肠梗阻患者出现持续性疼痛、局部压痛、发热和乳酸升高，提示**绞窄**，需要紧急手术。其他患者通常先采用非手术治疗：粘连性梗阻用输液加减压和水溶性造影剂，单纯性憩室炎用镇痛和复查，轻症胰腺炎用支持治疗，之后行胆囊切除术。
:::

::: history
长期以来，人们把阑尾的病变归咎于盲肠：右髂窝的炎症被称为"盲肠周围炎"。1886年，波士顿病理学家雷金纳德·菲茨（Reginald Fitz）分析了数百个病例，证明病变通常源于阑尾，创造了"阑尾炎"一词，并主张早期切除。1889年，查尔斯·麦克伯尼（Charles McBurney）描述了以他命名的最大压痛点，并于1894年描述了一种分离肌肉的切口。1902年，弗雷德里克·特里维斯（Frederick Treves）在爱德华七世国王原定加冕礼的两天前为他引流了阑尾脓肿，此后阑尾切除术广为人知。1980年，德国妇科医生库尔特·泽姆（Kurt Semm）完成了首例腹腔镜阑尾切除术。
:::

## 后续内容

具体器官的外科学在[[surgery/gastrointestinal-surgery]]中继续讨论。内科背景知识见[[gastrointestinal/bowel-disease]]和[[gastrointestinal/pancreas-biliary]]。脓毒症见[[infectious-diseases/fever-sepsis]]，影像学见[[clinical-skills/medical-imaging]]。

::: summary
- 内脏痛定位不清，按胚胎起源在中线被感知（前肠在上腹部，中肠在脐周，后肠在耻骨上）；躯体痛锐利且定位明确。炎症累及壁层腹膜时疼痛**转移**。
- 先评估生理状态并复苏；采集完整病史；检查疝环口；对任何可能妊娠者做妊娠试验。
- 四种病理过程是**炎症、梗阻、穿孔和缺血**；它们可能相互重叠。
- 阑尾炎：转移性疼痛、右髂窝压痛；Alvarado 等评分指导影像检查；腹腔镜阑尾切除术，或在部分病例中使用抗生素。
- 肠梗阻：小肠多为粘连和疝，大肠多为癌和肠扭转；注意寻找**绞窄**。
- 肠系膜缺血：疼痛与体征不相称、心房颤动、乳酸升高；立即行 CT 血管造影。
- 胆道：胆绞痛、胆囊炎（一周内行胆囊切除术）、胆管炎（Charcot 三联征，紧急引流）。
- 胰腺炎：三项标准满足两项；严重程度取决于持续性器官衰竭；以支持治疗为主。
- 镇痛不影响诊断。NELA 标准（风险评估、早期抗生素、CT、顾问医师在场、重症监护）可改善结局。
:::

## 习题

::: exercise 疼痛在哪里被感知？ {level=1}
说明下列疾病的早期内脏痛通常在何处被感知：(a) 急性胆囊炎；(b) 阑尾炎；(c) 乙状结肠憩室炎；(d) 小肠梗阻。解释其原理。
::: solution
(a) 上腹部（前肠）。(b) 脐周（中肠）。(c) 耻骨上或下腹部（后肠），不过一旦壁层腹膜受累，憩室炎常表现为左髂窝疼痛。(d) 脐周，呈绞痛（中肠）。内脏传入纤维进入脊髓的节段由器官的胚胎起源决定，大脑把疼痛牵涉到同一节段的皮肤，且位于中线，因为肠道是作为中线结构发育的。
:::
:::

::: exercise 计算评分 {level=1 check="6"}
一位30岁女性右髂窝压痛、恶心，体温37.5 °C，白细胞计数 $12 \times 10^9$/L，无中性粒细胞增多。她的疼痛没有转移，食欲正常，没有反跳痛。计算她的 Alvarado 评分。
::: solution
右髂窝压痛（2）+ 恶心（1）+ 体温 ≥ 37.3 °C（1）+ 白细胞增多（2）= **6**。转移、食欲减退、反跳痛和核左移计0分。5–6分为中间值：阑尾炎有可能，需要影像检查（年轻女性首选超声，因为也可能是妇科病因）和妊娠试验。
:::
:::

::: exercise 是不是 Charcot？ {level=1}
一位70岁男性右上腹痛，体温39 °C 伴寒战，巩膜黄染。血压85/50 mmHg，意识模糊。说出诊断、以人名命名的体征和确定性治疗。
::: solution
**急性胆管炎**伴严重脓毒症：发热、黄疸和右上腹痛构成 **Charcot 三联征**；再加上低血压和意识模糊即为 **Reynolds 五联征**。处理为复苏、血培养和静脉抗生素，随后**紧急胆道引流**，通常经 ERCP 取石或放置支架；如果无法行 ERCP，则经皮引流。
:::
:::

::: exercise 扫描结果的预测值 {level=2 check="round(100*0.3*0.85/(0.3*0.85+0.7*0.1))"}
在一组怀疑阑尾炎的儿童中，验前概率为30%。超声的敏感度为85%，特异度为90%。扫描阳性的儿童患阑尾炎的概率是多少（以百分比表示，四舍五入到最接近的整数）？
::: hint
设想有1000名儿童：有多少人患阑尾炎且检查阳性，有多少人未患阑尾炎但检查阳性？
:::
::: solution
1000名儿童中，300人患阑尾炎，其中 $0.85 \times 300 = 255$ 人检查阳性。在700名未患阑尾炎的儿童中，$0.10 \times 700 = 70$ 人检查阳性。阳性预测值：$255/(255 + 70) = 255/325 \approx 0.785$，四舍五入为 **78%**（取最接近的整数为78）。扫描阴性时概率仍为 $45/(45 + 630) \approx 6.7\%$，因此症状持续的儿童仍需复查。
:::
:::

::: exercise 胰腺炎的严重程度 {level=2 check="4"}
一位64岁胆源性胰腺炎女性在48小时时的结果为：PaO₂ 7.6 kPa，白细胞计数 $17 \times 10^9$/L，血钙2.15 mmol/L，尿素12 mmol/L，AST 150 U/L，LDH 450 U/L，白蛋白30 g/L，血糖8 mmol/L。她的改良 Glasgow 评分是多少？是否预示重症胰腺炎？
::: solution
PaO₂ < 8 kPa（1）；年龄 > 55（1）；白细胞计数 > 15（1）；血钙 < 2（0）；尿素 > 16（0）；LDH > 600 或 AST > 200（0）；白蛋白 < 32（1）；血糖 > 10（0）。总分 **4**。3分或以上预示重症胰腺炎，因此她应在高依赖病房接受治疗，并密切监测器官衰竭。她的疾病实际上是否为重症，由修订版亚特兰大标准决定：器官衰竭持续超过48小时。
:::
:::

::: exercise 病房里的肠梗阻 {level=2}
一位58岁男性10年前做过剖腹手术，现因24小时的腹部绞痛、呕吐、腹胀和停止排气就诊。他的腹股沟正常。没有压痛，乳酸1.4 mmol/L。CT 显示小肠梗阻，有移行点，无缺血征象。概述处理。
::: solution
这很可能是无绞窄的**粘连性小肠梗阻**。处理：静脉补液并补充电解质（呕吐引起低钾血症和代谢性碱中毒）；置入鼻胃管自由引流；镇痛和止吐；监测液体平衡，必要时留置导尿管；预防 VTE；经鼻胃管注入**水溶性造影剂**，数小时后拍腹部 X 线片，看造影剂是否到达结肠（预示梗阻将缓解）。定期复查：出现持续性疼痛、压痛、发热、心动过速或乳酸上升提示绞窄，需要手术。几天后仍不缓解（各地做法不同，常为约72小时）也是手术指征。
:::
:::

::: exercise 伴虚脱的"肾绞痛" {level=3}
一位吸烟的71岁男性突发左侧腰痛，放射至腹股沟。他在家时感到头晕欲倒。心率105次/分，血压98/60 mmHg。尿液试纸显示微量血尿。接诊医生计划给予镇痛并按肾绞痛做 CT KUB。还必须考虑什么？评估应如何改变？
::: solution
必须首先考虑**腹主动脉瘤破裂**。60岁以上男性、尤其是吸烟者，首次出现"肾绞痛"并伴头晕、心动过速和相对低血压，在被证明不是之前应视为腹主动脉瘤破裂。镜下血尿不能区分两者。**处理方法的改变：**检查腹部有无搏动性、膨胀性肿块；建立大口径通路，送交叉配血；如有经过培训的操作者，进行床旁主动脉超声；立即呼叫血管外科团队。采用**允许性低血压**（避免用大量液体把血压推高）。如果他足够稳定，CT 血管造影可确认诊断并显示是否适合血管腔内修复。肾绞痛的疼痛通常不伴低血压；腰痛合并休克时一定要想到这一点。
:::
:::

::: exercise 一次关于风险的谈话 {level=3}
一位81岁男性患心力衰竭和慢性肾脏病，乙状结肠憩室穿孔伴粪性腹膜炎。他的 NELA 预测死亡率为32%。他有决策能力。根据 NELA 标准，概述他的照护应如何组织，以及应如何与他讨论这一决定。
::: solution
**组织：**复苏并在一小时内给予抗生素；完成 CT（已完成）并由顾问医师审阅；计算并记录风险；由于风险高，**顾问外科医生和顾问麻醉医生**应在手术室中在场，并安排**重症监护床位**；请老年医学科医生参与围手术期照护；尽快进入手术室，因为粪性腹膜炎有很强的时间紧迫性。

**讨论：**清楚地解释正在发生什么：不手术的话，粪性腹膜炎很可能致命；而手术本身约有三分之一的死亡风险，并很可能出现并发症、造口（可能行 Hartmann 手术）、入住重症监护和漫长的康复，并可能丧失独立生活能力。询问对他最重要的是什么。讨论其他选择，包括以舒适为重点的治疗。无论他选择哪一种，都要尊重他的决定，并记录讨论内容、他的理解和他的决定。如果他拒绝手术，要确保良好的姑息治疗，而不是撤除照护。
:::
:::
