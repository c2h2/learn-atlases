血管外科和泌尿外科是两个独立的专科，但在许多医院里它们共用一个查房，也有若干共同特点。两者都治疗老年人的常见疾病，患者常是患有心脏病和糖尿病的吸烟者。两者都有以分钟或小时决定器官能否存活的急症：没有血流的下肢、扭转的睾丸、破裂的主动脉、梗阻并感染的肾脏。而且两者都越来越多地通过导管和导丝而不是开放切口来治疗疾病。

本章介绍外周动脉疾病和肢体缺血、主动脉瘤、颈动脉疾病、静脉疾病和糖尿病足，然后介绍主要的泌尿外科疾病：结石和梗阻的肾脏、尿潴留和良性前列腺增大、血尿和泌尿系统肿瘤，以及阴囊和阴茎急症。指南以英国为主（NICE、NHS 腹主动脉瘤筛查项目、欧洲血管外科学会和英国国家筛查委员会），内容截至2026年。个体患者的处理遵循当地方案。

## 外周动脉疾病

::: definition 外周动脉疾病 {#def-vascular}
**外周动脉疾病（PAD）**是供应四肢的动脉狭窄或闭塞，几乎都由**动脉粥样硬化**引起。主要危险因素是吸烟、糖尿病、高血压、血脂异常、慢性肾脏病和年龄。它按阶段表现：

- **无症状**，因脉搏消失或踝部血压低而被发现；
- **间歇性跛行**：走一段可预测的距离后小腿、大腿或臀部出现痉挛性疼痛，休息数分钟后缓解；
- **慢性威胁肢体缺血（CLTI）**：静息痛（典型地在夜间出现于前足，把腿垂到床边可缓解）或组织缺损（溃疡或坏疽），持续超过两周。

PAD 是广泛动脉粥样硬化的标志：跛行患者发生心肌梗死和卒中的风险远大于失去下肢的风险。
:::

关键的床旁检查是**踝肱压力指数（ABPI）**：踝部最高收缩压（用手持多普勒测量足背动脉或胫后动脉）除以最高的肱动脉收缩压。

$$
\text{ABPI} = \frac{\text{踝部收缩压}}{\text{最高肱动脉收缩压}}
$$ {#eq-abpi}

正常 ABPI 约为1.0–1.4。低于0.9提示 PAD；低于约0.5提示病变严重。在糖尿病或慢性肾脏病患者中，钙化的动脉无法被压瘪，因此 ABPI 可能假性正常或高于1.4；此时改用趾压和动脉波形。

NICE 指南 CG147 规定了处理方法。每一位 PAD 患者都要接受**心血管风险降低**治疗：戒烟（最重要的单项措施）、抗血小板药、高强度他汀类药物，以及控制血压和糖尿病（[[cardiovascular/vascular-disease]]）。对于跛行，**有监督的运动计划**是首选治疗，能显著提高步行距离。当运动效果不够且症状限制生活时，考虑血运重建（血管成形术、支架置入或旁路手术）；CLTI 则需要血运重建以挽救肢体。先用双功超声，再用 CT 或 MR 血管造影来规划手术。

::: example 测量 ABPI {#ex-abpi}
一位吸烟的68岁男性步行约200米后右小腿疼痛，休息2分钟后缓解。多普勒测压：右臂146 mmHg，左臂138 mmHg；右踝88 mmHg（胫后动脉，两条踝部动脉中较高者）；左踝140 mmHg。计算他的 ABPI 并加以解读。
::: solution
**分母：**较高的肱动脉压，146 mmHg。

**右侧 ABPI：**$88 / 146 \approx 0.60$。

**左侧 ABPI：**$140 / 146 \approx 0.96$。

**解读：**右侧 ABPI 0.60证实右侧有中度 PAD，与他的小腿跛行相符（可能为股浅动脉病变）。左侧正常。

**处理：**这是跛行，而不是威胁肢体的缺血。他需要戒烟支持、抗血小板药、高强度他汀类药物、血压和血糖评估，并转诊参加有监督的运动计划。如果尽管运动后症状仍使他严重受限，以后再考虑血运重建。应告诉他，他最大的风险是心脏病发作或卒中，这就是为什么药物治疗最为重要。
:::
:::

## 急性肢体缺血

**急性肢体缺血**是肢体灌注突然减少，威胁肢体的存活。原因有**栓塞**（常来自心房颤动或心肌梗死后的心脏）、已因动脉粥样硬化而狭窄的动脉或旁路移植物的**血栓形成**、创伤或夹层。

典型特征是 **6P**：**疼痛**（pain）、**苍白**（pallor）、**无脉**（pulselessness）、**冰冷**（perishingly cold）、**感觉异常**（paraesthesia）和**麻痹**（paralysis）。感觉丧失和肌力减弱是肢体**受到威胁**的征象：神经和肌肉是对缺血最敏感的组织，约6小时内就可能开始发生不可逆的损伤。不褪色的固定性花斑、小腿坚硬有压痛和完全麻痹提示肢体已发生不可逆损伤。

栓塞性和血栓性闭塞可通过病史区分：栓塞在有栓子来源（心房颤动）、既往无跛行的患者中突然起病，另一侧下肢的脉搏常正常；血栓形成发生在已知有 PAD 的患者中，由于已有侧支血管形成，起病常不那么突然。

处理遵循**欧洲血管外科学会**的指南（2020年）：立即给予**肝素**以阻止血栓蔓延、镇痛、紧急血管外科评估，并根据病因和严重程度，通过**取栓术**（用球囊导管）、**旁路手术**或**导管接触性溶栓**和血管腔内治疗进行血运重建。受威胁的肢体需要在数小时内血运重建，常常没有时间做详细的影像检查。恢复血流后，肢体会肿胀（再灌注损伤），可能需要筋膜切开术处理**骨筋膜室综合征**（[[surgery/orthopaedics]]）。再灌注还可释放钾、酸和肌红蛋白，引起高钾血症、心律失常和急性肾损伤。

::: example 冰冷苍白的下肢 {#ex-ali}
一位79岁女性患心房颤动，未接受抗凝治疗，左下肢突然剧痛3小时。膝以下的下肢苍白冰冷，股动脉以下无脉搏。她的足部不能感知轻触，足趾活动无力。右下肢脉搏正常。诊断是什么？优先事项是什么？
::: solution
**诊断：**急性肢体缺血，很可能由**栓子**引起（突然起病、心房颤动、对侧脉搏正常、无跛行史）。闭塞可能位于腘动脉或股动脉分叉处。

**严重程度：**感觉丧失和肌力减弱意味着肢体**立即受到威胁**。如果不在数小时内血运重建，她将丧失肌肉和神经功能，可能需要截肢。

**优先事项：**静脉给予**肝素**和镇痛，立即呼叫血管外科团队，抽血（包括血型鉴定与抗体筛查、肾功能和肌酸激酶）并做心电图，禁食。她很可能需要紧急**取栓术**，可能需要术中血管造影，团队必须为筋膜切开术和再灌注效应做好准备。需要对她的心房颤动进行长期抗凝以防止再次栓塞。
:::
:::

## 主动脉瘤

**腹主动脉瘤（AAA）**是腹主动脉永久性扩张至直径**3.0 cm 或以上**。大多数位于肾动脉以下。危险因素有年龄、男性、吸烟（最强的可改变因素）、家族史、高血压和动脉粥样硬化。大多数 AAA 在破裂之前没有症状，而破裂常常在患者到达医院之前就已致命。

::: theorem 拉普拉斯定律与动脉瘤增大 {#thm-laplace}
对于圆柱形血管，管壁张力与腔内压力和半径的乘积成正比：$T \propto P \times r$。因此，在相同血压下，较宽的主动脉承受更大的管壁张力，这使它进一步扩张；直径增大和血压升高都会增加破裂风险。
:::

::: proof
设想沿轴线剖开一段血管。作用于内表面的压力 $P$ 以与 $P$ 乘以投影面积成正比的力把两半推开，而投影面积与直径成正比。与之抗衡的是沿两条切缘作用的管壁张力。力的平衡使管壁张力与 $P \times r$ 成正比；管壁材料内的应力等于这一张力除以管壁厚度，因此管壁越薄情况越糟。在动脉瘤中，弹性蛋白和胶原的降解削弱了管壁，管壁在被拉伸时变薄，因此应力的上升快于直径的增加。这是一个正反馈循环：扩张增加应力，应力又引起进一步扩张。它解释了为什么小动脉瘤增长缓慢而大动脉瘤增长较快，为什么破裂风险随直径急剧上升，以及为什么控制血压和戒烟（可减缓增长）是监测的一部分。
:::

**筛查。****NHS AAA 筛查项目**邀请男性在65岁那一年做一次腹部超声检查；年龄更大的男性可以自行申请。结果决定后续随访：

| 主动脉直径 | 分类 | 措施 |
|---|---|---|
| < 3.0 cm | 正常 | 结束筛查 |
| 3.0–4.4 cm | 小 AAA | 每年超声监测 |
| 4.5–5.4 cm | 中 AAA | 每3个月超声检查 |
| ≥ 5.5 cm | 大 AAA | 转诊给血管外科医生，2周内就诊 |

女性不常规筛查，因为 AAA 在女性中少见得多，但女性的动脉瘤在较小直径时就会破裂。

**修复。**对**5.5 cm 或以上**的动脉瘤、每年增长超过约1 cm 的动脉瘤（直径超过4.0 cm 后），以及**有症状**的动脉瘤（有压痛，或引起背痛或腹痛）考虑修复。低于这一大小时，破裂风险低于手术风险。修复方法有两种：**开放修复**，经剖腹用人工血管替换病变段；以及**血管腔内动脉瘤修复（EVAR）**，经股动脉放置覆膜支架。EVAR 早期死亡率较低，但需要终身影像监测以发现**内漏**（血液持续流入瘤囊），再干预也更多；开放修复更持久。按照 NICE 指南 NG156（2020年），选择取决于解剖、患者的身体状况和其本人的偏好。

**破裂**表现为腹痛或背痛、虚脱和搏动性肿块，但肿块可能难以触及。它可能被误认为肾绞痛、憩室炎或心肌梗死。处理为**允许性低血压**（血压足以使患者保持清醒即可；积极补液会增加出血）、输注血液制品，并立即送往手术室修复；如果解剖允许且能安全地完成 CT，则行 EVAR，否则行开放修复。

::: example 有压痛的搏动性肿块 {#ex-rupture}
一位74岁男性在家中突发剧烈背痛后虚脱。在急诊科，他心率118次/分，血压82/50 mmHg，面色苍白、出汗，但能说话。脐上方有一个有压痛的搏动性肿块。如何处理？
::: solution
**诊断：**在被证明不是之前应视为 AAA 破裂。

**处理：**

1. 立即呼叫血管外科医生、麻醉医生和手术室团队；启动**大出血预案**。
2. 建立两条大口径静脉通路；抽血做交叉配血、全血细胞计数、凝血和肾功能。
3. **允许性低血压：**由于他意识清醒、收缩压82 mmHg，避免大剂量液体推注；如果病情恶化则输注血液制品。把血压推向正常可能增加破口的出血。
4. 如果他足够稳定，**CT 血管造影**可显示解剖结构以及是否可行 EVAR。如果不稳定，直接送往手术室。
5. 与他（和他的家人）讨论正在发生的事情、极高的风险以及他的意愿，因为一些患者，尤其是有严重合并症者，会选择舒适照护。

即使及时手术，AAA 破裂的死亡率仍然很高，这就是为什么筛查和对大动脉瘤进行择期修复很重要。
:::
:::

### 颈动脉疾病

颈动脉分叉处的动脉粥样硬化通过栓塞引起卒中和短暂性脑缺血发作（TIA）。对于发生 TIA 或非致残性卒中、且有50–99%**症状性颈动脉狭窄**（按 NASCET 方法测量）的患者，**颈动脉内膜切除术**可降低再次卒中的风险，且手术越早获益越大：NICE（NG128）建议在症状出现后一周内评估和转诊，最迟在两周内手术。无症状狭窄通常采用最佳药物治疗。卒中医学见[[nervous-system/stroke]]。

## 静脉疾病

**静脉曲张**是由静脉瓣功能不全引起的浅静脉扩张、迂曲，通常位于大隐静脉或小隐静脉系统。许多人有静脉曲张而无症状。NICE 指南 CG168 建议，对有症状的静脉曲张、皮肤改变（色素沉着、湿疹、脂性硬皮病）、伴有反流的浅静脉血栓形成、静脉性腿部溃疡或已愈合的溃疡者，转诊至血管外科服务。在双功超声检查之后，治疗通常是对功能不全的主干进行**腔内热消融**（射频或激光），泡沫硬化治疗或手术作为替代。

**静脉性腿部溃疡**发生在慢性静脉高压的下肢内踝周围（"绑腿区"）。溃疡浅，边缘倾斜，周围有皮肤改变。治疗的主要手段是**加压**，只有在用 ABPI 排除动脉疾病之后加压才是安全的。及早治疗潜在的浅静脉反流可加快愈合并减少复发。

**深静脉血栓形成**用 Wells 评分、D-二聚体和加压超声诊断，用抗凝治疗（[[blood/thrombosis-anticoagulation]]）。大范围髂股静脉 DVT 可引起肿胀、青紫、疼痛的下肢（**股青肿**），威胁肢体存活，可能需要导管接触性溶栓。

### 糖尿病足

糖尿病足病是**神经病变**、**缺血**和**感染**的结合。神经病变使痛觉消失并造成畸形，因此溃疡在受压点毫无预兆地形成；缺血妨碍愈合；感染在足部的组织间隙中迅速扩散。NICE 指南 NG19 建议设立多学科足部服务，对每位糖尿病患者定期检查足部，并对威胁肢体的问题立即转诊。这些服务运作良好时，截肢率会下降（[[endocrine/diabetes-complications]]、[[surgery/wounds-surgical-infection]]）。

## 泌尿外科

::: definition 主要的泌尿外科急症 {#def-urology}
- **梗阻合并感染的肾脏：**结石（或其他原因）阻塞输尿管，其上方的尿液发生感染。这是一种外科急症，除抗生素外，还需要通过肾造瘘或输尿管支架进行**紧急引流**。
- **急性尿潴留：**疼痛性的无法排尿；治疗为导尿。
- **睾丸扭转：**睾丸绕其精索扭转，切断其血供；治疗为**立即手术探查**。
- **Fournier 坏疽：**会阴和生殖器的坏死性感染；治疗为复苏、抗生素和紧急清创。
- **缺血性阴茎异常勃起：**持续超过4小时的疼痛性勃起，无动脉血流入；治疗为从海绵体抽血并注射血管收缩剂。
- **嵌顿包茎：**上翻的包皮无法复位至龟头上方，龟头肿胀；治疗为手法复位。
:::

### 肾结石与输尿管结石

**肾绞痛**是剧烈的、阵发性的腰部疼痛，放射至腹股沟（随着结石下降放射至睾丸或阴唇），常伴恶心和镜下血尿。患者无法保持静止。结石由草酸钙、磷酸钙、尿酸、鸟粪石（伴产脲酶细菌感染）或胱氨酸形成；危险因素包括脱水、饮食、高钙尿症、痛风、既往结石史和家族史。

NICE 指南 NG118（2019年）建议以 **NSAID** 作为一线镇痛药（除非有禁忌），并在就诊后24小时内做肾、输尿管和膀胱的**低剂量平扫 CT**；儿童和孕妇使用超声。许多小结石可自行排出；对于小于10 mm 的输尿管远端结石，可以给予 **α受体阻滞剂**。不能排出、引起无法控制的疼痛或较大的结石，采用**体外冲击波碎石术**、**输尿管镜**治疗，对于较大的肾结石则采用**经皮肾镜取石术**。

::: example 发热与结石 {#ex-pyo}
一位44岁女性已知有右侧肾绞痛，2天后因寒战被送回急诊科，体温39.4 °C，心率124次/分，血压90/56 mmHg。右侧腰部有压痛。CT 显示右侧输尿管中段有一个7 mm 结石伴肾积水。诊断和治疗是什么？
::: solution
**诊断：****梗阻合并感染的肾脏**伴脓毒症。脓液在压力下被困在梗阻上方，细菌进入血流。

**治疗：**遵循脓毒症指南（血培养和尿培养、乳酸、静脉补液，按当地指南使用广谱抗生素），并安排对肾脏进行**紧急减压**，由介入放射科医生放置经皮**肾造瘘管**，或由泌尿外科医生逆行放置**输尿管支架**。单用抗生素无法清除梗阻系统内的感染。

**不要：**在感染的肾脏中尝试确定性的结石治疗（如输尿管镜）；结石在感染清除后再处理。有结石的脓毒症患者绝不能只给镇痛药就让其出院。
:::
:::

### 尿潴留与前列腺

**急性尿潴留**表现为膀胱疼痛、可触及，且无法排尿。在男性中最常见的原因是**良性前列腺增大**，常由便秘、抗胆碱能药或阿片类药物、饮酒、感染或手术诱发。其他原因包括尿道狭窄、血块潴留、神经系统疾病（包括马尾综合征），以及女性的盆腔肿块。处理是**导尿**，记录残余尿量，并治疗诱因。检查肾功能；解除慢性尿潴留后可能出现**梗阻后利尿**。男性通常在**拔除导尿管试排尿**之前开始使用 **α受体阻滞剂**（如坦索罗辛）。

**慢性尿潴留**无痛性地发展，残余尿量大。高压性慢性尿潴留可引起肾积水和肾衰竭。

**良性前列腺增大**引起下尿路症状：尿线细弱、排尿踌躇、尿频、尿急和夜尿。治疗从生活方式建议到α受体阻滞剂（松弛前列腺平滑肌）、5α还原酶抑制剂（在数月内缩小前列腺）以及手术，如**经尿道前列腺切除术（TURP）**或激光手术。

### 血尿与泌尿系统肿瘤

无感染的**肉眼血尿**是膀胱癌或肾癌的警示信号。根据 NICE NG12，45岁及以上、有不明原因肉眼血尿而无尿路感染（或感染治疗后血尿持续）的成人，按疑似癌症路径转诊；60岁及以上、有不明原因镜下血尿并伴排尿困难或白细胞计数升高者，也应转诊。检查通常为**软性膀胱镜检查**和上尿路影像检查（CT 尿路造影或超声）。

- **膀胱癌**（大多为尿路上皮癌）与**吸烟**和职业性接触芳香胺相关。非肌层浸润性肿瘤经内镜切除，并以膀胱镜监测随访；肌层浸润性肿瘤采用根治性膀胱切除术或放疗。
- **肾癌**（肾细胞癌）常在影像检查中偶然发现。局限性病变的治疗为肾部分切除术或根治性肾切除术。
- **前列腺癌**是英国男性最常见的癌症。诊断始于 **PSA** 升高或直肠指检异常，然后按 NICE NG131 的建议做前列腺**多参数 MRI** 和靶向活检。处理从低风险病变的**主动监测**到根治性前列腺切除术或放疗，晚期病变采用激素治疗。PSA 对癌症并不特异：它在良性增大、感染和器械操作后都会升高。2026年5月，英国国家筛查委员会建议不进行人群 PSA 筛查，并建议对确认携带 *BRCA2* 变异且有相关家族史的45至61岁男性每2年进行一次靶向筛查；在撰写本文时，英国各政府尚未公布其决定。要求做 PSA 检测的男性在讨论其利弊之后可以接受检测。
- **睾丸癌**是年轻男性中最常见的实体癌。它表现为睾丸内无痛的硬肿块。超声可确诊；测量肿瘤标志物（**AFP、β-hCG、LDH**）；治疗始于**经腹股沟根治性睾丸切除术**（不经阴囊，以免改变淋巴引流）。即使有转移，治愈率也非常高。

### 急性阴囊疼痛

::: warning
**睾丸扭转是临床诊断，影像检查绝不能延误手术。**男孩或年轻男性突发剧烈睾丸疼痛，常伴恶心呕吐，有时表现为下腹痛，在被证明不是之前都应视为扭转。睾丸可能位置偏高、呈横位，提睾反射常消失。如果在约6小时内复位，挽救率很高，此后急剧下降。多普勒超声可能给出错误的安心结论。正确的做法是紧急阴囊探查，复位并固定双侧睾丸（因为解剖上的易患因素通常是双侧的）。对腹痛的男孩一定要检查睾丸。
:::

急性阴囊疼痛的其他原因包括**睾丸附件扭转**（疼痛局限于上极，有时有"蓝点征"）、**附睾睾丸炎**（起病较缓，有发热和泌尿系统症状；年轻男性中由性传播病原体引起，老年男性中由泌尿道病原体引起）、创伤、嵌顿性腹股沟疝，以及少见的在轻微损伤后才被发现的肿瘤。

::: example 阴囊疼痛的男孩 {#ex-testis}
一个14岁男孩在05:00因左侧睾丸剧痛醒来，已呕吐两次。他于07:30到达医院。左侧睾丸压痛明显，位置比右侧高，左侧提睾反射消失。他的母亲问能否先做超声检查。应该怎么做？
::: solution
**诊断：**在被证明不是之前应视为睾丸扭转：青少年突发剧痛、呕吐、睾丸位置高和提睾反射消失。

**行动：**在全身麻醉下紧急**阴囊探查**，不要等待超声检查。他已有2.5小时的症状；如果及时进入手术室，挽救睾丸的机会很大。禁食，镇痛，取得他母亲的同意（并征得他本人的同意），解释如果睾丸已无活力将予以切除（睾丸切除术），并会固定另一侧睾丸以防将来扭转。

**如果探查发现的是睾丸附件扭转**，就将其切除，也不会造成伤害。探查一个结果并没有扭转的睾丸，被视为不漏诊扭转所付出的可接受的代价。
:::
:::

**Fournier 坏疽**是会阴、阴囊和阴茎的坏死性筋膜炎（[[surgery/wounds-surgical-infection]]）。它在患糖尿病、肥胖或酗酒的男性中更常见。疼痛和全身症状超过可见的皮肤改变；可触及捻发感。治疗为复苏、广谱抗生素和立即根治性清创，常需反复进行。

::: quiz
一位70岁男性因12小时无法排尿伴耻骨上疼痛被送来。他3天前因背痛开始服用可待因，并有便秘。哪种说法是正确的？
- [ ] 在导尿之前必须先做肾脏超声
- [x] 应该给他导尿，记录残余尿量，并处理可待因和便秘问题
- [ ] 应该开始使用α受体阻滞剂，不留置导尿管让他回家
- [ ] 背痛伴尿潴留总是由前列腺增大引起
::: solution
急性尿潴留首先通过导尿来解除，并记录残余尿量。阿片类药物和便秘是常见的诱因，应予以处理；通常在之后拔管试排尿之前开始使用α受体阻滞剂。背痛伴尿潴留还应促使医生检查有无**马尾综合征**（鞍区麻木、下肢无力、肠道症状），后者需要紧急 MRI。
:::
:::

::: history
1912年，法国外科医生亚历克西·卡雷尔（Alexis Carrel）因与查尔斯·格思里（Charles Guthrie）共同发展的血管缝合技术获得诺贝尔生理学或医学奖，这些技术使血管重建和器官移植成为可能。1951年，巴黎的夏尔·迪博斯特（Charles Dubost）完成了首例腹主动脉瘤切除并用同种异体血管替换的手术。1964年，查尔斯·多特（Charles Dotter）描述了经腔血管成形术，即用导管扩张狭窄的动脉；1990年，布宜诺斯艾利斯的胡安·帕罗迪（Juan Parodi）报告了首例腹主动脉瘤血管腔内修复。在泌尿外科方面，马克西米利安·尼采（Maximilian Nitze）于1879年研制的膀胱镜使人们能够从内部观察膀胱；1980年，慕尼黑的克里斯蒂安·肖西（Christian Chaussy）及其同事报告了首例用体外冲击波碎石术治疗肾结石。
:::

::: summary
- PAD 表现为跛行或**慢性威胁肢体缺血**；ABPI < 0.9可确诊。每位患者都要治疗心血管风险；跛行采用有监督的运动；严重影响生活的症状或 CLTI 需要血运重建。
- **急性肢体缺血**（6P）：感觉丧失和肌力减弱意味着肢体受到威胁；肝素并在数小时内血运重建；警惕再灌注损伤和骨筋膜室综合征。
- AAA ≥ 3.0 cm；男性65岁时筛查；按大小监测；**≥ 5.5 cm**、快速增大或有症状时修复（开放或 EVAR）。拉普拉斯定律把直径、压力和破裂联系起来。
- AAA 破裂：允许性低血压并立即修复；老年男性出现"肾绞痛"时要考虑到它。
- 50–99%的症状性颈动脉狭窄：2周内行内膜切除术。
- 静脉曲张：腔内热消融；静脉性溃疡：测 ABPI 后加压治疗。
- 肾绞痛：NSAID，CT KUB；**梗阻合并感染的肾脏需要引流**。
- 急性尿潴留：导尿并治疗诱因；拔管试排尿前使用α受体阻滞剂。
- 45岁以上的肉眼血尿需要紧急检查；PSA 特异性有限，英国的筛查仅限于靶向人群。
- **睾丸扭转**：立即探查；腹痛的男孩要检查睾丸。
:::

## 习题

::: exercise 区分下肢疼痛 {level=1}
把每一项描述与最可能的病因相匹配：(a) 步行100米后小腿痉挛，休息2分钟后缓解；(b) 夜间前足烧灼痛，把腿伸出床外可缓解；(c) 心房颤动患者一侧下肢突然疼痛、苍白、冰冷；(d) 傍晚下肢沉重酸痛，伴扩张迂曲的静脉。
::: solution
(a) 间歇性跛行（PAD）。(b) 缺血性静息痛，是慢性威胁肢体缺血的征象（腿下垂时重力改善灌注）。(c) 栓子引起的急性肢体缺血。(d) 有症状的静脉曲张（静脉功能不全）。
:::
:::

::: exercise ABPI {level=1 check="round(100*72/140)/100"}
一位女性的最高肱动脉压为140 mmHg，右踝压为72 mmHg。计算她的右侧 ABPI，四舍五入保留两位小数，并加以解读。
::: solution
$72 / 140 \approx 0.514$，四舍五入为 **0.51**。这提示明显的 PAD，接近严重范围。如果她有静息痛或组织缺损，就属于慢性威胁肢体缺血，需要紧急血管外科评估。
:::
:::

::: exercise 监测间隔 {level=1}
按照 NHS AAA 筛查项目，一位65岁男性的主动脉直径为 (a) 2.4 cm、(b) 3.8 cm、(c) 5.0 cm、(d) 6.1 cm 时，分别如何处理？
::: solution
(a) 正常；结束筛查。(b) 小 AAA；每年超声监测，同时戒烟并管理心血管风险。(c) 中 AAA；每3个月超声检查。(d) 大 AAA；转诊给血管外科医生，2周内就诊，评估是否修复。只要有动脉瘤，都要建议他戒烟，并治疗他的血压和血脂。
:::
:::

::: exercise 拉普拉斯定律的数字 {level=2 check="(6/2)*(150/120)"}
用简化关系 $T \propto P \times r$，收缩压150 mmHg 时6 cm 动脉瘤的管壁张力是收缩压120 mmHg 时正常2 cm 主动脉的多少倍？给出精确值。
::: hint
比值等于直径比与压力比的乘积。
:::
::: solution
直径比：$6/2 = 3$。压力比：$150/120 = 1.25$。张力比：$3 \times 1.25 = 3.75$。动脉瘤的管壁还会变薄，因此管壁内的实际应力升高得更多。这就是为什么直径和血压控制都很重要。
:::
:::

::: exercise 妊娠期结石 {level=2}
一位妊娠24周的女性右侧腰痛放射至腹股沟，有镜下血尿。她的检查和处理与非妊娠女性有何不同？
::: solution
**影像：**超声是一线检查，以避免电离辐射；妊娠期生理性肾积水（右侧更常见）可能使解读困难，因此在专科讨论后可使用不加造影剂的 MRI，或少数情况下使用低剂量 CT。**镇痛：**妊娠期避免使用 NSAID，尤其是在妊娠晚期（对胎儿动脉导管和肾脏有风险），一般不使用；按产科指南使用对乙酰氨基酚和阿片类药物。**鉴别诊断：**阑尾炎（妊娠期位置上移）、肾盂肾炎、胎盘早剥和早产。**治疗：**大多数结石可自行排出；如果有梗阻合并感染或无法控制的疼痛，用支架或肾造瘘引流肾脏，确定性治疗通常推迟到分娩之后。请产科团队参与。
:::
:::

::: exercise 无痛性肿块 {level=2}
一位29岁男性发现右侧睾丸有一个无痛的硬肿块。概述检查和首选治疗，并解释为什么要经腹股沟切除睾丸。
::: solution
**检查：**阴囊**超声**（证实睾丸内实性肿块）；睾丸切除术前测定**肿瘤标志物** AFP、β-hCG 和 LDH；胸部、腹部和盆腔 CT 进行分期。治疗前提供**精子冷冻保存**。**首选治疗：****经腹股沟根治性睾丸切除术**，经腹股沟切口切除睾丸和精索，通过组织学区分精原细胞瘤和非精原细胞性生殖细胞肿瘤；后续治疗（监测、化疗或放疗）取决于组织学、标志物和分期。**为什么经腹股沟：**睾丸的淋巴管随精索走行至主动脉旁淋巴结。阴囊切口可能使肿瘤种植于阴囊皮肤，并开辟一条通往腹股沟淋巴结的新淋巴途径，使分期和治疗复杂化。
:::
:::

::: exercise 血尿的分诊 {level=3}
对下列每位患者，判断按 NICE NG12 是否需要疑似癌症转诊，以及还应做什么：(a) 一位吸烟的52岁男性，有一次无痛性肉眼血尿，尿培养阴性；(b) 一位30岁女性有排尿困难、尿频、肉眼血尿，尿培养阳性，抗生素治疗后症状消失；(c) 一位65岁女性两次尿试纸检测有镜下血尿，白细胞计数升高，未发现感染。
::: solution
(a) 需要：45岁或以上，有不明原因的肉眼血尿且无感染。一次发作就足够。他需要膀胱镜检查和上尿路影像检查，并接受戒烟建议。(b) 不需要：血尿可由已痊愈的尿路感染解释。治疗后复查尿液是合理的；血尿持续则需要进一步评估。(c) 需要：60岁或以上，有不明原因的镜下血尿和白细胞计数升高。她需要膀胱镜检查和上尿路影像检查，还应检查肾功能和蛋白尿，因为镜下血尿也可能来自肾脏疾病。
:::
:::

::: exercise 取栓术后的下肢 {level=3}
一位72岁男性因急性缺血下肢接受了成功的股动脉取栓术（缺血时间约8小时），术后6小时，他的小腿变得紧张，被动牵拉足趾时剧痛。血钾6.4 mmol/L，尿色深，肌酸激酶48,000 U/L。解释发生了什么，并概述处理。
::: solution
**发生了什么：****再灌注损伤**。恢复缺血肌肉的血流会产生自由基并增加毛细血管通透性，因此肌肉在筋膜室内肿胀，引起**骨筋膜室综合征**（被动牵拉痛是早期征象；脉搏可能仍然存在）。受损的肌肉释放**钾**、酸和**肌红蛋白**（横纹肌溶解），引起高钾血症和深色尿，肌红蛋白还可引起**急性肾损伤**。

**处理：**紧急行小腿**四间室筋膜切开术**以解除筋膜室压力；立即治疗**高钾血症**（心电监护、静脉给予钙剂保护心脏、胰岛素加葡萄糖，并按高钾血症指南采取进一步措施）；给予充足的静脉补液以维持高尿量，保护肾脏免受肌红蛋白损害；密切监测肾功能、血钾、CK 和液体平衡，需要时进行肾脏替代治疗；适当时继续抗凝。缺血时间长时可以预见再灌注综合征，因此对这类患者常在血运重建的同时进行筋膜切开术。
:::
:::
