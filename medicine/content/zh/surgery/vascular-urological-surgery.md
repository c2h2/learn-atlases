血管与泌尿外科共享同样的主题：管道、压力与终身的监测。血管外科处理动脉的瘤与闭塞性病变和静脉的疾病；泌尿外科处理尿路的梗阻与结石和肿瘤[[cardiovascular/vascular-disease]]、[[renal/urinary-tract]]。

本章涵盖血管外科、泌尿外科，以及监测的医学。

## 动脉、静脉与通道

::: definition 血管外科 {#def-vascular}
**动脉瘤是动脉的局部扩张，破裂的风险随直径上升；腹主动脉瘤通常在5.5厘米以上时被干预，方式是开放修复或腔内的支架，按解剖与生理选择[[cardiovascular/vascular-disease]]、[[surgery/perioperative-care]]、[[clinical-skills/medical-imaging]]。破裂是外科急症：低血压、腰背痛与搏动性肿块；处理是即刻的复苏、大量输血与立即的手术或腔内隔绝[[emergency-critical-care/shock-fluids]]、[[blood/transfusion]]、[[emergency-critical-care/resuscitation]]。闭塞性疾病表现为间歇性跛行、静息痛与组织丢失（慢性），以及疼痛、苍白、无脉、感觉异常、麻痹与皮温低的急性缺血；治疗是抗血小板与他汀和运动康复，加上腔内或旁路的重建[[cardiovascular/vascular-disease]]、[[pharmacology/drug-development-prescribing]]、[[public-health/prevention-promotion]]。静脉：静脉曲张与静脉性溃疡与血栓后综合征；而透析的动静脉通路（自体的瘘与人工的移植）需要成熟与血栓的监测[[renal/chronic-kidney-disease]]、[[blood/thrombosis-anticoagulation]]、[[gastrointestinal/clinical-nutrition]]。**
:::

## 尿路及其他

::: definition 泌尿外科 {#def-urology}
**下尿路：前列腺的梗阻造成尿线细、排尿困难与尿潴留；男性的肾后性急性肾损伤常源于膀胱出口梗阻。治疗是先导尿减压，然后用α受体阻滞剂与五型还原酶抑制剂，失败时手术切除[[renal/acute-kidney-injury]]、[[renal/water-sodium]]、[[pharmacology/autonomic-drugs]]、[[surgery/perioperative-care]]。结石：典型是肾绞痛与血尿；急症是梗阻合并感染（脓肾），需要立即减压（支架或肾造瘘）、抗生素与复苏[[renal/urinary-tract]]、[[infectious-diseases/fever-sepsis]]、[[emergency-critical-care/shock-fluids]]。肿瘤：膀胱癌表现为无痛血尿，靠内镜切除与膀胱内的卡介苗治疗原位病变；肾癌表现为血尿、腰痛与肿块三联的只有少数；前列腺癌用PSA与影像和活检分层[[pathology/cancer-diagnosis]]、[[clinical-skills/medical-imaging]]、[[renal/urinary-tract]]。**
:::

::: definition 监测的医学 {#def-surveillance}
**血管与泌尿的很多照护是长期的监测：腹主动脉瘤按直径决定超声的间隔（小的每数年，中间的每年），直到达到干预的阈值[[cardiovascular/vascular-disease]]、[[clinical-skills/medical-imaging]]、[[public-health/screening]]。旁路与动静脉的瘘需要流量的检查与体格检查，因为血栓形成前有可以被发现的信号[[renal/chronic-kidney-disease]]、[[surgery/perioperative-care]]。膀胱肿瘤需要定时的膀胱镜与细胞学，以及在高风险者中的影像[[pathology/cancer-diagnosis]]、[[renal/urinary-tract]]。慢性肾病与高血压与糖尿病的控制、骨与代谢的并发症与贫血，属于同一套监测[[renal/chronic-kidney-disease]]、[[endocrine/diabetes]]、[[cardiovascular/hypertension]]、[[blood/anaemia]]、[[public-health/non-communicable-disease]]。共同的原则：把监测的项目与间隔和负责的医生写在患者的记录里，让患者与全科医生都知道下一步的时间[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]。**
:::

::: example 疼痛的搏动性肿块 {#ex-rupture}
一位71岁男性在家中倒下；急救测收缩压70；在急诊有左侧腰部与背部疼痛、腹部搏动性肿块、血红蛋白96、肌酐150；他的医院护照写着不做心肺复苏但其他治疗都可以。
::: solution
**这是腹主动脉瘤破裂，直到被证明别的：不要等待常规检查。已知的动脉瘤加上表现可以直接送手术室；若血压对复苏有反应，快速CT可以帮助制定方案[[#def-vascular]]、[[clinical-skills/medical-imaging]]、[[emergency-critical-care/resuscitation]]。处理：允许性低压、启动大量输血方案、立即腔内或开放修复，并在重症监护中继续[[emergency-critical-care/shock-fluids]]、[[blood/transfusion]]、[[emergency-critical-care/critical-care]]。意愿：护照中的不心肺复苏不等于不做手术；要立即与家属和既有照护团队澄清目标并记录[[medical-ethics-law/end-of-life-ethics]]、[[clinical-skills/records-handover]]、[[clinical-skills/communication]]。生存者还要监测肾功能与心脏，并安排动脉瘤后的随访影像[[renal/acute-kidney-injury]]、[[cardiovascular/coronary-artery-disease]]。**
:::
:::

::: example 发热与结石 {#ex-pyo}
一位46岁上周扫描已知8毫米近端输尿管结石、正等待排出的患者，现在寒战、体温39.2、心率122、白细胞21、肌酐190，而疼痛反而缓解，她觉得这是好转。
::: solution
**疼痛缓解不是好转，而是集合系统被完全梗阻的信号；在发热与寒战时这就是感染的梗阻肾，需要在数小时内减压（输尿管支架或肾造瘘），同时给抗生素与复苏[[#def-urology]]、[[infectious-diseases/fever-sepsis]]、[[emergency-critical-care/shock-fluids]]、[[clinical-skills/medical-imaging]]。急性期不做碎石或取石，因为操作会增加肾内压并把感染播散；结石在感染被控制后处理[[renal/urinary-tract]]、[[surgery/perioperative-care]]。监测尿量、乳酸、培养与肾功能，并按脓毒症路径升级[[renal/acute-kidney-injury]]、[[emergency-critical-care/critical-care]]、[[clinical-skills/laboratory-tests]]。教学：大于5到6毫米的近端结石不应在门诊无限期等待；复评的时间与干预的阈值必须写下[[clinical-skills/patient-safety]]、[[clinical-skills/records-handover]]。**
:::
:::

::: example 只是静脉曲张的腿 {#ex-phlegmasia}
一位38岁产后正在用复方口服避孕药的女性：左腿明显肿胀、青紫而疼痛，该侧踝臂指数0.7，筋膜室张力高，超声报告广泛的髂股静脉血栓。
::: solution
**这是青肿性深静脉血栓（髂股静脉的完全阻塞），一个可能失去肢体的急症：严重肿胀把组织压升高到损害动脉灌注，所以踝臂指数会下降[[#def-vascular]]、[[blood/thrombosis-anticoagulation]]、[[surgery/vascular-urological-surgery]]。立即处理：治疗剂量的肝素、液体复苏、抬高肢体并密切监测筋膜室与尿量和肌酸激酶[[emergency-critical-care/shock-fluids]]、[[renal/acute-kidney-injury]]、[[surgery/orthopaedics]]。升级：在有条件的中心做导管溶栓或取栓，或在骨筋膜室压力高时减压[[clinical-skills/medical-imaging]]、[[emergency-critical-care/critical-care]]。病因处理：停用含雌激素的避孕药，并规划产后抗凝的疗程与避孕的替代[[obstetrics-gynaecology/postnatal-period]]、[[obstetrics-gynaecology/contraception-fertility]]。**
:::
:::

::: example 无痛肿块的男性 {#ex-testis}
一位27岁感到右侧睾丸硬而不痛的肿块3周；超声为睾丸内实性病灶2.4厘米；AFP 42、β-hCG 30；CT显示腹膜后淋巴结2.6厘米；他问能否先观察。
::: solution
**年轻男性的睾丸内实性病灶，在证明别的之前都是生殖细胞肿瘤；升高的肿瘤标记物（AFP与hCG）提示非精原的成分类，所以观察不是选项[[#def-urology]]、[[pathology/cancer-diagnosis]]、[[clinical-skills/medical-imaging]]。路径：经腹股沟的精索与睾丸切除（不要经阴囊活检，因为会改变淋巴引流与局部复发），并检测标记物与分期[[surgery/perioperative-care]]、[[renal/urinary-tract]]。分期决定后续：腹膜后淋巴结的清扫或化疗，按类型与标记物的下降[[pathology/cancer-biology]]、[[pharmacology/drug-development-prescribing]]、[[immunology/tolerance-regulation]]。在手术前讨论精子保存，因为治疗会损害生育[[obstetrics-gynaecology/contraception-fertility]]、[[clinical-skills/communication]]、[[medical-ethics-law/consent-capacity]]。把标记物的时间与复评的间隔写进记录[[clinical-skills/records-handover]]。**
:::
:::

## 通向何处

动脉的瘤与闭塞性疾病在[[cardiovascular/vascular-disease]]；血栓与抗凝在[[blood/thrombosis-anticoagulation]]；尿路感染与结石在[[renal/urinary-tract]]；急性与慢性肾损伤在[[renal/acute-kidney-injury]]与[[renal/chronic-kidney-disease]]；脓毒症在[[infectious-diseases/fever-sepsis]]；休克与液体在[[emergency-critical-care/shock-fluids]]；肿瘤的诊断在[[pathology/cancer-diagnosis]]；生育与妊娠在[[obstetrics-gynaecology/contraception-fertility]]。

::: history
血管外科的世纪是把动脉变成可以修的管道：从血栓的剥除与旁路的建立，到腔内的支架与隔绝术，把开放的大手术变成穿刺的干预[[cardiovascular/vascular-disease]]、[[surgery/perioperative-care]]；腹主动脉瘤的筛查项目使死亡下降，也带来过度诊断的辩论[[public-health/screening]]、[[public-health/health-systems-economics]]；泌尿外科从开放的手术走到内镜、腔内与体外碎石[[renal/urinary-tract]]；而抗凝与围手术期的血栓预防改变了围手术期的危险[[blood/thrombosis-anticoagulation]]、[[surgery/perioperative-care]]。
:::

::: summary
- 动脉瘤按直径决定干预；破裂是分钟到小时的病，允许性低压与即刻隔绝是核心[[#ex-rupture]]。
- 急性肢体缺血是小时级的急症；青肿性血栓可能丢失肢体，需要肝素与升级[[#ex-phlegmasia]]。
- 感染的梗阻肾必须减压，抗生素不能替代引流[[#ex-pyo]]。
- 睾丸的实性病灶要经腹股沟切除并查标记物，治疗前讨论生育[[#ex-testis]]。
- 这一章的多数照护是终身的监测：把间隔与责任人写清楚[[#def-surveillance]]。
:::

## 练习

::: exercise 给腿痛分类 {level=1}
给出疼痛模式对应的血管或泌尿诊断：(a) 走固定距离的小腿痛，坐下休息一分钟内缓解；(b) 足趾夜间痛，把腿垂下缓解；(c) 突然的疼痛、苍白、无脉；(d) 一天站立后加重的沉重胀痛，晚间踝部肿胀。
::: solution
**(a) 间歇性跛行（动脉闭塞）：疼痛在运动中发生，休息后迅速缓解[[#def-vascular]]、[[cardiovascular/vascular-disease]]。(b) 静息痛（严重的慢性缺血）：夜间痛、下垂缓解，是需要血管评估的信号[[surgery/vascular-urological-surgery]]。(c) 急性肢体缺血：栓塞或原位血栓，需要肝素与急性的再通[[emergency-critical-care/acute-assessment]]、[[blood/thrombosis-anticoagulation]]。(d) 静脉功能不全：日间加重的胀痛与踝部肿胀和皮肤的改变[[surgery/vascular-urological-surgery]]、[[surgery/wounds-surgical-infection]]。工具是踝臂指数、多普勒与超声或CT的血管成像[[clinical-skills/physical-examination]]、[[clinical-skills/medical-imaging]]。**
:::
:::

::: exercise 写出PSA的对话 {level=2}
一位64岁健康男性带着PSA 4.8前来，问是否得了前列腺癌。写出这段对话与可选的方案。
::: solution
**先说诚实的边界：PSA不能区分致命与不致命的前列腺癌，而升高的数值也可来自前列腺增大与炎症[[#def-urology]]、[[pathology/cancer-diagnosis]]、[[clinical-skills/laboratory-tests]]。下一步：复查并结合风险，做多参数的前列腺MRI，只在可疑病灶上取材（融合的靶向活检）；低风险者用主动监测替代即刻治疗[[public-health/screening]]、[[clinical-skills/medical-imaging]]、[[surgery/perioperative-care]]。也要说伤害：假阳性、取材的并发症与治疗造成的尿失禁与勃起功能的问题[[clinical-skills/communication]]、[[obstetrics-gynaecology/contraception-fertility]]。共同决定：按年龄、期望寿命与偏好，用每千人的数字解释获益与伤害并记录[[medical-ethics-law/consent-capacity]]、[[geriatrics-palliative/ageing-frailty]]、[[clinical-skills/records-handover]]。**
:::
:::

::: exercise 处理带导尿管的急性肾损伤 {level=2}
一位78岁男性跌倒后入病房，没有排尿，有前列腺病史；膀胱膨胀，肌酐从90升到240，钾5.9；导尿后一小时排出1.2升尿。给接下来的数小时。
::: solution
**这是肾后性急性肾损伤，导尿后进入梗阻后利尿：先解除梗阻（导尿；若不能放入则请泌尿做耻骨上膀胱穿刺或内镜下置管）[[renal/acute-kidney-injury]]、[[renal/urinary-tract]]、[[surgery/perioperative-care]]。之后逐小时记录尿量与容量平衡，并监测钠、钾、镁与磷酸盐，因为大量的尿液会把离子带走[[renal/water-sodium]]、[[renal/potassium-calcium-phosphate]]、[[emergency-critical-care/shock-fluids]]。高钾按急症处理（稳定心肌、转移入细胞、促进排出）并按心电图调整[[cardiovascular/arrhythmias]]、[[endocrine/adrenal]]。回顾病因：前列腺的梗阻与药物的作用（抗胆碱能与阿片类）[[geriatrics-palliative/polypharmacy]]、[[pharmacology/adverse-reactions]]。后续：泌尿的评估、α受体阻滞剂、导尿管的移除计划与肾功能的随访[[renal/chronic-kidney-disease]]、[[clinical-skills/records-handover]]。**
:::
:::

::: exercise 建立血管中心与网络的论证 {level=3}
为把血管外科集中到高容量中心、同时在地方保留急救入口建立论证：证据、入口、人力与财务。
::: solution
**证据：在动脉瘤破裂与肢体缺血的救治中，手术量与结局相关，因此把复杂的手术集中会改善死亡[[#def-surveillance]]、[[public-health/health-systems-economics]]、[[clinical-skills/patient-safety]]。入口：必须保留地方的急救能力（复苏、超声的诊断与转诊的路径和转运的协议），因为破裂的动脉瘤与缺血的肢体不会等待[[emergency-critical-care/major-incidents]]、[[cardiovascular/vascular-disease]]、[[surgery/vascular-urological-surgery]]。人力与财务：中心需要团队与重症与介入的容量，而地方需要维持诊断与稳定病情的技能，避免这些能力流失[[public-health/global-health]]。审计：把时间与结局公开，并按人群与地理分层，以便看到被延误的群体[[public-health/determinants-inequalities]]、[[clinical-skills/records-handover]]。**
:::
:::

::: exercise 最初的四条医嘱 {level=1}
62岁：三天的劳力性小腿痛现在变成持续的静息痛，足苍白而凉，无脉，毛细血管再充盈6秒，运动与感觉正常。写出最初的四条医嘱与理由。
::: solution
**一、静脉肝素抗凝，在等待影像与评估时防止血栓扩展[[blood/thrombosis-anticoagulation]]、[[#def-vascular]]。二、保护肢体：避免受压与抬高过度，保暖而不加热，做足部的减压与保护[[surgery/vascular-urological-surgery]]、[[emergency-critical-care/acute-assessment]]。三、急性的血管影像（超声、CT或血管造影）并由血管外科决定再通的方式[[clinical-skills/medical-imaging]]、[[surgery/perioperative-care]]。四、二级预防：抗血小板与他汀与戒烟和血糖血压的控制[[pharmacology/drug-development-prescribing]]、[[public-health/prevention-promotion]]。运动与感觉正常说明肢体还可挽救，因此这几个小时应用于重建，而不是观察[[emergency-critical-care/critical-care]]、[[clinical-skills/records-handover]]。**
:::
:::

::: exercise 解读踝臂指数 {level=2}
一位糖尿病透析患者的踝臂指数双侧1.28，趾压32，足跟有一个小溃疡伴角化。动脉正常吗？如何管理？
::: solution
**不正常：踝臂指数被中层的钙化人为抬高，所以1.28不能排除疾病；要看趾压、波形与皮肤灌注压[[#def-vascular]]、[[clinical-skills/physical-examination]]、[[renal/chronic-kidney-disease]]。趾压32合并溃疡提示严重的缺血，需要血管的评估与可能的重建[[surgery/vascular-urological-surgery]]、[[cardiovascular/vascular-disease]]。管理：溃疡的清除、减压与湿性敷料，感染的评估与抗生素，以及血糖、营养与足病团队[[endocrine/diabetes-complications]]、[[surgery/wounds-surgical-infection]]、[[gastrointestinal/clinical-nutrition]]。注意：在透析患者中使用造影剂与检查时要权衡容量与残余肾功能[[renal/acute-kidney-injury]]、[[clinical-skills/medical-imaging]]。**
:::

::: exercise 给阴囊分类 {level=2}
晚上9点的两位男性：(a) 16岁，5小时的突然睾丸痛伴恶心，睾丸位置偏高，提睾反射消失，既往有类似发作自行缓解；(b) 28岁，逐渐的疼痛伴排尿困难与阴囊发红。
::: solution
**(a) 睾丸扭转，直到被证明别的：位置偏高、提睾反射消失、恶心与既往的自限发作都支持；需要立即的外科评估与探查，因为超声不应延误手术，而在时间过去后睾丸会丧失[[#def-urology]]、[[emergency-critical-care/acute-assessment]]、[[surgery/perioperative-care]]。(b) 附睾睾丸炎：常有排尿症状与阴囊红肿，用抗生素与支持治疗[[renal/urinary-tract]]、[[infectious-diseases/sexually-transmitted-infections]]、[[microbiology/antimicrobials]]。教学：在a)中即使超声正常也不能排除扭转，临床判断优先；探查阴性也胜过失去睾丸[[clinical-skills/clinical-reasoning]]、[[clinical-skills/records-handover]]。**

::: exercise 审计截肢 {level=3}
你们地区糖尿病的主要下肢截肢率是表现最好地区的两倍。用可以避免的截肢的框架建立改进的项目。
::: solution
**先分解路径：足病的筛查（感觉与足部检查）、血管的评估、多学科足病团队的可及性与伤口照护[[endocrine/diabetes-complications]]、[[surgery/vascular-urological-surgery]]、[[public-health/screening]]。再测量：从新发足溃疡到血管评估的时间、截肢前的血管再通率，并按社会经济地位与地理分层[[public-health/determinants-inequalities]]、[[clinical-skills/records-handover]]。改变：筛查项目、足病团队与血管中心，加上患者教育与减压鞋具[[public-health/prevention-promotion]]、[[public-health/health-systems-economics]]、[[gastrointestinal/clinical-nutrition]]。治理：把可避免的截肢作为质量指标，并向专业团队与公众报告[[clinical-skills/patient-safety]]、[[medical-ethics-law/professionalism-regulation]]。**
