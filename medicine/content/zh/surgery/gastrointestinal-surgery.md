胃肠外科把上消化道、肝胆胰与结直肠的解剖和生理变成可以修的问题：反流与梗阻、出血与穿孔、肿瘤与炎症，每一条都有路径、手术与非手术的替代[[gastrointestinal/oesophagus-stomach]]、[[gastrointestinal/bowel-disease]]。

本章涵盖上消化道、结直肠与肛门，以及贯穿其中的原则（吻合口、造口与围手术期的照护）。

## 上消化道

::: definition 食管、胃与十二指肠 {#def-upper}
**胃食管反流病源于下食管括约肌功能不全与食管裂孔疝；治疗是质子泵抑制与生活方式的改变，而在药物依赖或出现并发症时做抗反流手术（把疝复位并重建瓣膜），需知道其并发症（吞咽困难、气腹与复发）[[gastrointestinal/oesophagus-stomach]]、[[public-health/prevention-promotion]]、[[surgery/perioperative-care]]。消化性溃疡的病因是幽门螺杆菌与非甾体抗炎药，因此根除与停药就是治疗；手术留给出血、穿孔与梗阻并发症[[gastrointestinal/oesophagus-stomach]]、[[pharmacology/adverse-reactions]]、[[microbiology/bacteria]]。上消化道出血：复苏、内镜止血，以及在止血失败时的介入或手术[[emergency-critical-care/shock-fluids]]、[[gastrointestinal/gi-bleeding-cancer]]。食管与胃的肿瘤：先分期，然后在新辅助治疗后由有容量的中心切除；无法根治时用支架与营养支持做姑息[[pathology/cancer-diagnosis]]、[[clinical-skills/medical-imaging]]、[[gastrointestinal/clinical-nutrition]]。胆道与胰腺：胆绞痛与胆囊炎、总管结石与胆管炎、以及胰腺炎，按内镜、手术与介入的次序处理[[gastrointestinal/pancreas-biliary]]、[[infectious-diseases/fever-sepsis]]。**
:::

## 下消化道

::: definition 结直肠与肛门的外科 {#def-lower}
**结直肠癌：从筛查到诊断（结肠镜与病理）与CT分期；治疗是带淋巴结取样的切除，在直肠癌中加入新辅助放化疗，而在错配修复缺陷的局部进展病例中免疫治疗正在改变路径；转移者要评估肝与肺的切除可能[[gastrointestinal/gi-bleeding-cancer]]、[[pathology/cancer-diagnosis]]、[[clinical-skills/medical-imaging]]、[[public-health/screening]]、[[immunology/tolerance-regulation]]。炎症性肠病：溃疡性结肠炎从药物到全结肠切除与储袋重建；克罗恩病处理狭窄与瘘并保存肠管[[gastrointestinal/bowel-disease]]、[[immunology/autoimmunity]]。憩室病与肠易激和慢性的便秘属于常见的门诊[[gastrointestinal/bowel-disease]]、[[public-health/non-communicable-disease]]。疝：腹股沟与切口疝用补片修补，嵌顿时需急诊手术[[surgery/acute-abdomen]]、[[surgery/wounds-surgical-infection]]。肛门：痔、脓肿的引流、瘘的挂线，以及肛管的癌[[gastrointestinal/bowel-disease]]、[[pathology/cancer-diagnosis]]。肝与胰的肿瘤在选定的病例中做切除与分期的多学科治疗[[gastrointestinal/liver-disease]]、[[gastrointestinal/pancreas-biliary]]、[[pathology/cancer-biology]]。**
:::

## 把连起来的原则

::: definition 吻合口、造口与围手术的照护 {#def-anastomosis}
**吻合口愈合需要血供、无张力、健康的组织与没有污染；营养不良、血糖失控、药物（激素与免疫抑制）、急诊手术与术中的低灌注都会提高漏的风险[[gastrointestinal/clinical-nutrition]]、[[endocrine/diabetes]]、[[pharmacology/adverse-reactions]]、[[surgery/perioperative-care]]。漏的表现是术后几天的发热、疼痛加重与生理恶化，或引流液的性质改变；处理是CT定位、经皮引流、抗生素，以及在需要时的再次手术[[clinical-skills/medical-imaging]]、[[infectious-diseases/fever-sepsis]]、[[surgery/acute-abdomen]]。造口：教育要与造口治疗师一起尽早开始，并发症包括缺血、回缩、狭窄、高输出与周围皮肤糜烂，长期要关注生活质量与支持[[surgery/wounds-surgical-infection]]、[[gastrointestinal/clinical-nutrition]]、[[geriatrics-palliative/symptom-control]]。围手术的照护包括增强恢复的路径（术前口服、镇痛的多模式、早期活动）、老年患者的目标讨论，以及把时间与并发症做成审计[[surgery/perioperative-care]]、[[surgery/anaesthesia-pain]]、[[geriatrics-palliative/ageing-frailty]]、[[public-health/health-systems-economics]]。**
:::

::: example 发现太晚的贫血 {#ex-iron}
一位66岁女性在常规血检中发现血红蛋白82伴缺铁；她只有轻微的肠道症状，并拒绝做结肠镜，直到女儿坚持；CT显示右半结肠癌而没有远处转移。
::: solution
**绝经后女性与男性的缺铁性贫血，在证明别的之前都算胃肠道肿瘤，需要同时查胃与结肠；轻微的症状不能降低怀疑[[blood/anaemia]]、[[gastrointestinal/gi-bleeding-cancer]]、[[clinical-skills/laboratory-tests]]。治疗是根治性的右半结肠切除与淋巴结取样；术前用贫血程序纠正铁与营养会减少输血[[surgery/gastrointestinal-surgery]]、[[gastrointestinal/clinical-nutrition]]、[[blood/transfusion]]。分期决定辅助化疗[[pathology/cancer-diagnosis]]、[[pharmacology/drug-development-prescribing]]。系统层面：拒绝检查要被记录并再次邀请，因为筛查之外的延迟最常见于依从性的断裂[[public-health/screening]]、[[clinical-skills/communication]]、[[clinical-skills/records-handover]]、[[medical-ethics-law/consent-capacity]]。**
:::
:::

::: example 失败的储袋 {#ex-pouch}
一位34岁在八年前因溃疡性结肠炎做了回肠储袋的人，现在每天12次血便，有储袋-阴道瘘，MRI提示储袋的克罗恩病；她的结直肠外科医生即将退休，而全科医生说不再有选择。
::: solution
**储袋失败有几个可以处理的原因：克罗恩病的新诊断、瘘、慢性储袋炎，以及机械的问题（扭转与狭窄）[[gastrointestinal/bowel-disease]]、[[immunology/autoimmunity]]、[[clinical-skills/medical-imaging]]。评估靠内镜与活检、断层影像与炎症指标，并与专门的中心讨论[[pathology/diagnostic-pathology]]、[[public-health/health-systems-economics]]。选择包括强化药物（生物制剂与局部治疗）、瘘的手术，以及储袋切除改为永久回肠造口[[immunology/autoimmunity]]、[[surgery/gastrointestinal-surgery]]、[[surgery/wounds-surgical-infection]]。不再有选择几乎从来不是事实：转诊与第二意见是标准，尤其在年轻人中[[clinical-skills/communication]]、[[medical-ethics-law/consent-capacity]]、[[public-health/determinants-inequalities]]。**
:::
:::

::: example 困难的胆囊 {#ex-cvs}
结石性胆囊炎第4天，肥胖，白细胞19，CRP 280；腹腔镜下Calot三角被炎症与粘连冻成一整块；麻醉师注意到整个手术中气腹压力都偏高。
::: solution
**当结构无法安全辨认时，首要目标是避免胆道损伤：从胆囊床或底部进入并减压、做术中胆道造影，必要时行次全切除或引流，而不是冒险分离[[gastrointestinal/pancreas-biliary]]、[[surgery/gastrointestinal-surgery]]、[[clinical-skills/medical-imaging]]。获得关键的视野（漏斗与胆囊管的交界）比坚持完成一期切除更安全[[surgery/perioperative-care]]、[[clinical-skills/patient-safety]]。持续偏高的气腹压力在肥胖与长时间手术中会减少静脉回流与肾灌注并影响通气，需要调整压力、通气与液体[[surgery/anaesthesia-pain]]、[[renal/acute-kidney-injury]]、[[respiratory/mechanics-breathing]]。若术后发现损伤，尽早转诊到专门中心能显著改善结局[[clinical-skills/communication]]、[[public-health/health-systems-economics]]。**
:::
:::

::: example 不能减慢的造口 {#ex-high-output}
右半结肠切除与末端回肠造口后5天，排出1900毫升清亮液体；第12天已因脱水与急性肾损伤再次入院。她为了跟上而每天喝4升水，并在用洛哌丁胺。
::: solution
**高输出造口会同时丢失水和钠并损害肾脏；大量喝低渗的纯水会加重钠的丢失并进一步增加输出，所以第一步是用口服补液盐替代纯水并限制白水[[gastrointestinal/clinical-nutrition]]、[[renal/water-sodium]]、[[renal/acute-kidney-injury]]。药物是定时给用的止泻药与减少分泌的药，并加质子泵抑制；同时寻找原因：部分梗阻的缓解期、感染（艰难梭菌与小肠的细菌过度生长）与促动力的药物[[pharmacology/autonomic-drugs]]、[[microbiology/microbiota]]、[[surgery/wounds-surgical-infection]]。监测体重、尿量、血钠与肾功能，并由造口治疗师教育患者，写出明确的出院标准与复评的时间[[clinical-skills/records-handover]]、[[public-health/health-systems-economics]]。**
:::

## 通向何处

解剖与生理在[[gastrointestinal/digestion-absorption]]与[[gastrointestinal/oesophagus-stomach]]；肝胆胰在[[gastrointestinal/pancreas-biliary]]与[[gastrointestinal/liver-disease]]；肿瘤在[[gastrointestinal/gi-bleeding-cancer]]与[[pathology/cancer-diagnosis]]；急症在[[surgery/acute-abdomen]]；营养在[[gastrointestinal/clinical-nutrition]]；围手术的照护在[[surgery/perioperative-care]]与[[surgery/anaesthesia-pain]]；感染与伤口在[[surgery/wounds-surgical-infection]]；而筛查与服务的路径在[[public-health/screening]]。

::: history
胃肠外科的可行性来自几道门槛：胃的切除随着麻醉、液体与无菌的进步从极高的死亡率变成常规[[surgery/anaesthesia-pain]]、[[emergency-critical-care/shock-fluids]]、[[surgery/wounds-surgical-infection]]；结直肠手术从一期切除加造口走到一期吻合与储袋，因为理解了血供与细菌[[gastrointestinal/bowel-disease]]、[[pathology/acute-inflammation]]；内镜把诊断与治疗合为一体（止血与切除）[[gastrointestinal/gi-bleeding-cancer]]、[[clinical-skills/medical-imaging]]；腹腔镜把大切口变成几个孔，并把胆囊切除变成日间手术[[surgery/gastrointestinal-surgery]]、[[public-health/health-systems-economics]]；而多学科团队、审计与筛查把结局变成被测量的责任[[public-health/screening]]、[[clinical-skills/patient-safety]]。
:::

::: summary
- 上消化道以酸与机械的问题为主：反流、溃疡与出血，而手术留给并发症与肿瘤[[#def-upper]]。
- 下消化道以肿瘤、炎症与机械的问题为主，治疗常在药物、内镜与手术之间切换[[#def-lower]]。
- 吻合口漏由血供与张力决定，在术后几天以生理恶化出现，需要影像、引流与再手术的决定[[#def-anastomosis]]。
- 造口是需要教育的疗法：高输出与皮肤与缺血类并发症是可以预防的再入院原因[[#ex-high-output]]。
- 在困难中改变术式（次全切除或引流）比冒险分离更安全；损伤后尽早转诊会改善结局[[#ex-cvs]]。
:::

## 练习

::: exercise 给出血分级 {level=1}
凌晨两点的两位急诊：(a) 45岁，已知十二指肠溃疡，黑便，血红蛋白70，内镜显示15毫米后壁十二指肠溃疡伴显露血管；(b) 72岁在用阿哌沙班，无痛的大量便血后自行停止。
::: solution
**(a) 这是高危的内镜所见：需要联合的内镜止血（肾上腺素加上机械或热凝），而后壁的位置提示胃十二指肠动脉，止血失败时要尽早请介入或外科[[gastrointestinal/oesophagus-stomach]]、[[gastrointestinal/gi-bleeding-cancer]]、[[emergency-critical-care/shock-fluids]]。之后给大剂量质子泵抑制并根除幽门螺杆菌[[pharmacology/dosing-principles]]。再出血时手术阈值要低，因为第二次出血的死亡最高[[clinical-skills/patient-safety]]。(b) 自止的大量下消化道出血在抗凝者中常见于憩室病与血管发育不良：复苏、监测血常规、管理抗凝，并在肠道准备后做结肠镜；若持续出血则做CT血管造影[[blood/thrombosis-anticoagulation]]、[[clinical-skills/medical-imaging]]、[[renal/acute-kidney-injury]]。**
:::
:::

::: exercise 为梗阻选择手术 {level=2}
78岁，急性大肠梗阻；CT为乙状结肠扭转，经直肠减压后排出1.5升，腹软；但五年中已是第二次复发，独居，在用洛哌丁胺。
::: solution
**减压成功只是买回时间：乙状结肠扭转的复发率超过一半，而每次发作都有肠坏死与死亡的风险，所以择期乙状结肠切除才是治疗[[gastrointestinal/bowel-disease]]、[[surgery/gastrointestinal-surgery]]。决定时要考虑合并症、衰弱程度与对造口的接受，因为急诊手术的风险远高于择期[[geriatrics-palliative/ageing-frailty]]、[[surgery/perioperative-care]]。同时处理基础：慢性便秘与促动力的药物，停用洛哌丁胺并建立规律的肠道方案[[geriatrics-palliative/polypharmacy]]、[[gastrointestinal/bowel-disease]]。若不适合手术，则讨论内镜减压或造口作为姑息，并把治疗目标写进记录[[medical-ethics-law/end-of-life-ethics]]、[[clinical-skills/records-handover]]。**
:::
:::

::: exercise 主持多学科团队 {level=2}
62岁，中位直肠癌距肛缘6厘米；MRI为cT4a、直肠系筋膜受累、环周切缘可疑阳性、侧方淋巴结9毫米可疑、无远处转移。她希望保留肛门。列出团队的决定。
::: solution
**先把风险说清：环周切缘受累意味着切缘阳性与局部复发，而可疑的侧方淋巴结会改变治疗的靶区[[gastrointestinal/gi-bleeding-cancer]]、[[pathology/cancer-diagnosis]]、[[clinical-skills/medical-imaging]]。第二，用新辅助治疗让肿瘤退缩：全程新辅助（放化疗加化疗）在局部进展病例中提高完全缓解率，也提高保留括约肌的机会[[immunology/tolerance-regulation]]、[[pharmacology/drug-development-prescribing]]。第三，评估反应后决定手术：全直肠系膜切除，必要时括约肌间路径；在反应极好者中可以与患者讨论观察等待[[surgery/gastrointestinal-surgery]]、[[pathology/diagnostic-pathology]]。第四，功能目标：与造口治疗师和康复团队讨论保护性回肠造口与长期的功能与长期的生活质量[[gastrointestinal/bowel-disease]]、[[geriatrics-palliative/symptom-control]]。最后把决定与证据和替代写进多学科记录[[clinical-skills/communication]]、[[clinical-skills/records-handover]]、[[medical-ethics-law/consent-capacity]]。**
:::

::: exercise 设计漏的应对 {level=3}
你们单位直肠癌手术的吻合口漏率为14%，而结局差异极大。建立预防组合、监测路径、应对路径与治理。
::: solution
**预防组合：术前优化（铁与营养与戒烟与血糖）、技术标准化（评估灌注、保证无张力、必要时做充气试验）、在高风险吻合中使用保护性造口，并纳入增强恢复路径[[#def-anastomosis]]、[[surgery/perioperative-care]]、[[gastrointestinal/clinical-nutrition]]。监测：术后的规律观察与早期预警（心率与呼吸率与引流液的改变）、明确的CT指征，与怀疑时的盆腔评估[[emergency-critical-care/acute-assessment]]、[[clinical-skills/medical-imaging]]。应对：一条写明路径（抗生素、经皮引流、再手术的指征与重症支持），以及规定的高年资呼救时间[[infectious-diseases/fever-sepsis]]、[[surgery/acute-abdomen]]、[[emergency-critical-care/critical-care]]。治理：用统一定义统计漏、公开报告、逐例回顾并与团队一起学习[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]、[[clinical-skills/records-handover]]。**
:::

::: exercise 分辨胃术后的访客 {level=1}
Billroth II术后两年的患者：餐后45分钟出现心悸与出汗；另一位食管切除后6个月的患者夜间平卧时加重。分别说出机制与处理。
::: solution
**第一位是倾倒综合征：高渗的糖快速进入小肠，引起液体转移与胰岛素反应，早期是心悸出汗，晚期可以低糖[[gastrointestinal/oesophagus-stomach]]、[[endocrine/diabetes]]、[[gastrointestinal/clinical-nutrition]]。处理是饮食结构（少量多餐、复杂碳水、餐时与进餐分离液体），持续者用减少动力的药[[pharmacology/autonomic-drugs]]。第二位是反流与误吸：食管切除后胃被拉到胸腔且括约肌被破坏，因此夜间平卧加重[[gastrointestinal/oesophagus-stomach]]、[[respiratory/respiratory-infections]]。处理是抬高床头、抑酸与少量多餐，顽固者需要影像与内镜评估[[surgery/gastrointestinal-surgery]]。两者都要把机制向患者解释，因为他们常被告知这只是焦虑[[clinical-skills/communication]]、[[clinical-skills/records-handover]]。**
:::
:::

::: exercise 决定只用抗生素 {level=2}
24岁与61岁的CT确认的单纯性阑尾炎都问：能否只用抗生素？按这两个人回答。
::: solution
**证据：在影像确认的单纯性阑尾炎中，先用抗生素对多数成人可在中期内避免手术，但相当比例最终仍需手术（复发或持续疼痛），而存在粪石者失败率更高[[gastrointestinal/bowel-disease]]、[[microbiology/antimicrobials]]、[[pathology/acute-inflammation]]。24岁：若他能接受不确定性与复发的可能，并且影像已排除其他病变，选择抗生素是合理的；粪石会把天平推向手术[[clinical-skills/medical-imaging]]、[[clinical-skills/clinical-reasoning]]。61岁：要考虑不同，因为同样的影像必须先排除盲肠与结肠的肿瘤，所以结肠镜与更严格的随访常成为决定的一部分[[gastrointestinal/gi-bleeding-cancer]]、[[public-health/screening]]。共同点：把选择、恶化的信号（疼痛加重与发热）与复评的时间写清楚[[clinical-skills/communication]]、[[emergency-critical-care/acute-assessment]]、[[clinical-skills/records-handover]]。**
:::
:::

::: exercise 审计90天的死亡 {level=2}
你们的结直肠单位的30天死亡率看起来很好；而一份国家的报告说你们急诊右半结肠切除的90天死亡率是异常值。解释这怎么可能，并设计审查。
::: solution
**一种解释：术后的死亡可以发生在30天之后，尤其在急诊与肿瘤手术之后；如果患者在周中死于并发症的后续或基础病的进展，就不计在30天窗口内，于是单位看起来很好而90天很差[[#def-anastomosis]]、[[surgery/acute-abdomen]]、[[pathology/cancer-diagnosis]]。另一种解释：病例组合与风险调整（急诊比例、肿瘤分期与衰弱）会扭曲比较[[public-health/health-systems-economics]]、[[epidemiology-ebm/bias-confounding]]。审查设计：把90天内的每一例死亡逐例回顾（死因与地点与是否讨论过目标），核对记录，并在同意下访谈家属[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]、[[medical-ethics-law/end-of-life-ethics]]。改变的方向：急诊的路径、早期目标讨论与并行的姑息照护、以及术后病房的升级标准，都要纳入审计[[geriatrics-palliative/palliative-care]]。**
:::
:::

::: exercise 为减重的服务建立论证 {level=3}
你们地区提议把被资助的肥胖的手术限制在体重指数50以上并且在生活方式的项目失败之后。批评这个提议并设计一个证据的服务规范。
::: solution
**批评：这样的限制把治疗推迟到最严重、获益反而下降的阶段；而手术在较低体重指数合并代谢病时已经证明有效，尤其是第二型糖尿病的缓解[[endocrine/diabetes]]、[[gastrointestinal/clinical-nutrition]]、[[public-health/prevention-promotion]]。先要求生活方式项目失败会增加年数而不增加获益，因为重度肥胖的生理会抵抗行为干预[[endocrine/diabetes-complications]]。公平：限制会不成比例地影响本来难以获得照护的群体[[public-health/determinants-inequalities]]、[[public-health/global-health]]。服务规范：一条多学科路径（外科与营养与心理与长期的随访）与明确的标准（体重指数、合并症与决策的能力）和公开的数据[[psychiatry/mood-disorders]]、[[clinical-skills/communication]]、[[public-health/health-systems-economics]]。结局指标：体重的变化、合并症的缓解、生活质量与成本[[public-health/health-systems-economics]]、[[clinical-skills/patient-safety]]。**
:::

## 继续深入

给外科受训者的提醒：本章的每一个决定都会在你凌晨两点独自面对的患者身上重现，因此值得记住的算法是决定何时不手术的——被局限的穿孔可以保守处理，梗阻先给胃管与CT再考虑刀，术后心动过速与少尿在被影像推翻之前就是漏。并发症率会奖励早期把患者叫回来的外科医生，而惩罚维护自己计划的人。当有疑问时，两个人人可以救活患者的问题总能回答：有没有积聚，有没有缺血。
