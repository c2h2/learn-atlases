普通外科在很大程度上是消化道和腹壁的外科。它的日常工作范围很广：从修补疝和切除胆囊（这是任何医院中最常见的手术之一），到需要一整天、由专科团队共同完成的大型肿瘤切除术。本章介绍外科病房中低年资医生最常遇到的疾病以及把它们联系起来的原则：疝如何形成以及何时需要修补、胆结石的外科治疗、上消化道和下消化道癌症的诊疗路径、炎症性肠病、肛门直肠疾病、造口和吻合口，以及肥胖的外科治疗。

同样这些器官的急诊表现（阑尾炎、梗阻、穿孔、胆囊炎）见[[surgery/acute-abdomen]]，这些疾病的内科方面见[[gastrointestinal/oesophagus-stomach]]、[[gastrointestinal/bowel-disease]]和[[gastrointestinal/gi-bleeding-cancer]]。指南以英国为主（NICE），内容截至2026年；个体患者的治疗遵循当地多学科方案。

## 疝

::: definition 疝 {#def-hernia}
**疝**是指内脏或内脏的一部分经过其所在体腔壁的缺损向外突出。腹壁疝有**疝囊**（腹膜）、**疝颈**（缺损处）和**疝内容物**（常为大网膜或小肠）。疝可以是：

- **可复性**的：内容物可以推回腹腔；
- **难复性**的（嵌顿性）：内容物不能推回；
- **梗阻性**的：疝内的肠管发生梗阻；
- **绞窄性**的：内容物的血供被切断，导致缺血、坏死和穿孔。
:::

绞窄的风险主要取决于疝颈的宽度：**狭窄而坚硬的疝颈**更容易卡住内容物。这就是为什么疝环狭窄的股疝比疝颈宽大的直疝更容易发生绞窄。

**腹股沟疝**是最常见的类型，男性远多于女性。**斜疝**经腹壁下血管外侧的内环，沿未闭的鞘突穿出，可下降至阴囊。**直疝**由于后天的薄弱，从腹壁下血管内侧经腹股沟管后壁（Hesselbach 三角）向外突出。临床上两者都出现在耻骨结节的内上方；往往只有在手术中才能区分。相关解剖见[[anatomy/abdomen]]。

**股疝**经腹股沟韧带下方的股管穿出，出现在**耻骨结节的外下方**。股疝在女性中更常见（尽管在女性中总体上腹股沟疝仍然更常见），常以伴梗阻的急症就诊。每一个股疝都应及时修补。

其他疝包括**脐疝和脐旁疝**、白线上的**上腹疝**、经手术瘢痕的**切口疝**（[[surgery/wounds-surgical-infection]]），以及胃经膈肌的**食管裂孔疝**。

**处理。**有症状的腹股沟疝通常要修补。对症状轻微的男性，**观察等待**是合理的选择，因为绞窄的风险低，不过许多人随着症状加重最终选择手术。修补时用**补片**无张力地加强腹股沟管后壁，可采用开放手术（**Lichtenstein** 修补术），也可在腹腔镜下从后方修补（**TAPP**，经腹腹膜前修补；或 **TEP**，完全腹膜外修补）。双侧疝和复发疝常首选腹腔镜修补。修补后神经受刺激引起的慢性腹股沟疼痛是知情同意时需要讨论的最重要的远期并发症。

## 胆石症

胆结石很常见：大多数是**胆固醇结石**，在胆汁中胆固醇过饱和时形成，常合并胆囊淤滞。**胆色素结石**见于溶血性疾病和感染。大多数胆结石患者没有症状，不需要治疗。

有症状的胆结石表现为胆绞痛、急性胆囊炎、胆管炎、胆总管结石引起的梗阻性黄疸，或胰腺炎（[[surgery/acute-abdomen]]）。首选检查是**腹部超声**。如果胆管扩张或肝功能呈梗阻性改变，用 **MRCP**（磁共振胰胆管成像）寻找胆管结石，并在手术前或手术时经 **ERCP** 取出，或在手术中行胆管探查取出。

NICE 指南 CG188 建议为有症状的胆结石患者提供腹腔镜胆囊切除术；对急性胆囊炎，在诊断后一周内进行。

::: theorem 关键安全视野 {#thm-cvs}
**胆管损伤**是胆囊切除术最严重的并发症。它主要发生在把胆总管误认为胆囊管而将其切断时。为预防这种情况，在获得**关键安全视野**之前，外科医生不应夹闭或切断任何结构：（1）肝胆囊三角内的脂肪和纤维组织已被清除；（2）胆囊下三分之一已从肝床上分离；（3）只看到**两个且仅有两个**结构进入胆囊：胆囊管和胆囊动脉。
:::

::: proof
胆管损伤源于辨认错误，而不是技术不足：在发炎的胆囊中，胆总管可能被牵拉到一个看起来像胆囊管的位置；而一旦外科医生认定了错误的结构是胆囊管，之后看到的一切往往都会被解读得符合这一认定。斯蒂文·斯特拉斯伯格（Steven Strasberg）于1995年描述的关键安全视野，用一个只有正确解剖才能通过的正面检验，取代了对单一管状结构的辨认：如果恰好有两个结构进入胆囊，并且胆囊已从其床上分离，那么其中任何一个都不可能是胆总管。当炎症过重而无法获得这一视野时，安全的选择是中转开腹、行**胆囊次全切除术**，或停止手术并引流，而不是在危险区域继续解剖。
:::

::: example 困难的胆囊 {#ex-cvs}
在症状出现10天后因急性胆囊炎行腹腔镜胆囊切除术时，外科医生发现肝胆囊三角周围有致密的炎症。45分钟后仍无法获得关键安全视野。有哪些选择？哪种做法不应采取？
::: solution
**选择：**（1）请另一位上级医生提供意见；（2）行**胆囊次全切除术**，切除胆囊的大部分，保留或缝闭靠近胆囊管的部分，从而避免在危险区域解剖；（3）如果有帮助则中转开腹，同时要认识到开腹时同样的炎症依然存在；（4）放置引流管或行**胆囊造瘘**，计划在炎症消退后再手术。

**不应做的：**在没有关键安全视野的情况下，夹闭并切断被认为是胆囊管的结构。这是导致胆管损伤的典型途径，胆管损伤可能需要大型重建手术，并永久影响患者的生活。

**之后：**手术记录要写明所见和所作的决定；告知患者做的是次全切除术以及其可能的后果（通常会自行缓解的胆漏，以及以后残余胆囊内再生结石的小风险）。
:::
:::

## 上消化道外科

::: definition 上消化道癌症诊疗路径 {#def-upper}
**食管癌**分为**腺癌**和**鳞状细胞癌**。腺癌目前在英国更常见，与反流和 Barrett 食管相关，通常位于下三分之一；鳞状细胞癌与吸烟和饮酒相关，通常位于上、中三分之一。**胃癌**大多为腺癌，与*幽门螺杆菌*、吸烟和饮食相关。两者都就诊较晚，常表现为**吞咽困难**（进行性，先是固体食物），或体重下降、贫血和消化不良。

诊疗路径是：紧急内镜检查加活检（NICE 指南 NG12 建议，对有吞咽困难者，以及55岁及以上有体重下降并伴上腹痛、反流或消化不良者，进行紧急直接预约上消化道内镜检查）；用胸部、腹部和盆腔 CT 进行**分期**，食管癌加做 PET-CT，有时还需超声内镜和分期腹腔镜检查；并在**多学科团队（MDT）会议**上讨论。对身体状况良好、病变局限的患者，根治性治疗通常将化疗或放化疗与**食管切除术**或**胃切除术**结合。许多患者就诊时已是晚期，接受姑息治疗，如放置支架缓解吞咽困难。
:::

食管切除术和胃切除术是有重大风险的大手术，风险包括吻合口漏、肺炎和长期营养问题。在英格兰，这些手术集中在专科中心进行，因为手术量大的单位结局更好。

**消化性溃疡病**现在主要采用药物治疗（根除*幽门螺杆菌*、停用 NSAID、质子泵抑制剂），但其并发症仍需外科医生参与：**穿孔**（修补，见[[surgery/acute-abdomen]]）、内镜和介入放射无法控制的**出血**，以及少见的胃出口梗阻。

## 结直肠外科

::: definition 结直肠癌 {#def-lower}
**结直肠癌**是英国最常见的癌症之一。大多数在数年间由**腺瘤性息肉**发展而来（腺瘤-癌序列），这就是为什么切除息肉的筛查能够预防癌症。危险因素包括年龄、家族史和遗传综合征（林奇综合征、家族性腺瘤性息肉病）、炎症性肠病、红肉和加工肉类、肥胖、吸烟和饮酒。

表现取决于部位。**右侧**癌常表现为缺铁性贫血、体重下降或肿块。**左侧**癌和直肠癌表现为排便习惯改变、直肠出血、里急后重或梗阻。

分期采用 **TNM** 系统：穿透肠壁的深度（T）、淋巴结受累（N）和远处转移（M），最常转移至肝和肺。
:::

**筛查和转诊。**在英格兰，NHS 肠癌筛查项目每两年向50至74岁的人寄送一份居家**粪便免疫化学检测（FIT）**；结果高于项目阈值者接受结肠镜检查。对于有症状的人，NICE 建议在初级保健中用 FIT 指导转诊：FIT 结果至少为**每克粪便10 µg 血红蛋白**的成人，以及有直肠或腹部肿块或其他强烈临床怀疑者，应作疑似癌症紧急转诊。

**检查。**结肠镜检查加活检是关键的诊断检查；不适合结肠镜检查时使用 CT 结肠成像。分期采用胸部、腹部和盆腔 CT，直肠癌加做**盆腔 MRI**，它可显示肿瘤与**直肠系膜筋膜**（计划切除的边界）的关系。每一例结直肠癌都要检测错配修复缺陷以发现林奇综合征（[[genetics/cancer-genetics]]）。

**手术。**手术切除受累肠段及其血供和淋巴结：

- 盲肠和升结肠：**右半结肠切除术**；
- 降结肠：**左半结肠切除术**；
- 乙状结肠：**乙状结肠切除术**；
- 直肠上段和中段：**前切除术**加**全直肠系膜切除（TME）**，即将直肠连同其完整的脂肪和淋巴结包膜一并切除；
- 累及括约肌的低位直肠：**腹会阴联合切除术**，做永久性结肠造口。

直肠癌常先接受**放疗或放化疗**，以缩小肿瘤并减少局部复发。一些患者达到临床完全缓解，可在专科单位接受密切监测（"观察等待"）。肝和肺转移灶有时可以根治性切除。

::: example 老年男性的贫血 {#ex-iron}
一位72岁男性被发现血红蛋白92 g/L，铁蛋白低，小细胞性。他没有肠道症状，体重下降了3 kg，感到疲乏。全科医生为他做的 FIT 结果为64 µg/g。这提示什么？下一步是什么？
::: solution
**解读：**男性（或绝经后女性）的缺铁性贫血，在被证明不是之前应视为胃肠道失血所致。右半结肠癌常常缓慢出血而不改变排便习惯，因此没有症状并不能令人安心。他的 FIT 为64 µg/g，远高于10 µg/g 的转诊阈值。

**下一步：**作疑似癌症紧急转诊，进行下消化道检查，通常为**结肠镜检查**；由于上消化道和下消化道都可能引起缺铁，还要做**上消化道内镜检查**（取十二指肠活检以排除乳糜泻）。在等待检查期间开始补铁。

**如果发现盲肠癌：**CT 分期、MDT 讨论，如为局限性病变则行腹腔镜右半结肠切除术。术前静脉补铁纠正贫血可减少输血需要（[[surgery/perioperative-care]]）。
:::

### 憩室病与炎症性肠病

**憩室病**的择期手术适用于反复发作的复杂性憩室炎、瘘（如通向膀胱，引起气尿和反复尿路感染）和狭窄，而不是仅仅因为发作过若干次单纯性憩室炎。

在**溃疡性结肠炎**中，需要手术的情况有：药物治疗无效的**急性重症结肠炎**、异型增生或癌变，以及药物无法控制的慢性病变。急性重症结肠炎患者在静脉使用激素后约第3天重新评估；如果没有反应，可选择挽救性药物治疗或**结肠切除术**。对无反应的患者推迟手术会增加穿孔和死亡的风险。由于溃疡性结肠炎只累及结肠和直肠，**全结直肠切除术**可以治愈它；许多患者之后接受**回肠储袋肛管吻合术**，从而避免永久性造口。

**克罗恩病**可累及消化道的任何部位，手术不能治愈它；吻合口处复发很常见。手术用于处理狭窄、瘘和脓肿等并发症，并尽可能保留肠管（有限切除，或不切除肠管而拓宽狭窄的**狭窄成形术**）。肛周克罗恩病由外科医生和消化科医生共同处理。

### 肛门直肠疾病

- **痔**是肛管血管垫的增大。它引起无痛性鲜红色出血（见于手纸上或便池中）和脱垂。治疗从增加纤维和液体摄入开始；症状持续者用**胶圈套扎**，痔大或反复发作者行手术（痔切除术）。血栓性外痔引起急性疼痛。
- **肛裂**是肛管皮肤的撕裂，通常位于后正中线，引起排便时剧痛和鲜红色出血。内括约肌痉挛减少血流，妨碍愈合。治疗为大便软化剂、外用**地尔硫䓬**或**硝酸甘油**松弛括约肌，无效时用肉毒毒素或侧方内括约肌切开术。不在中线的肛裂提示可能为克罗恩病、感染或恶性肿瘤。
- **肛周脓肿**由肛腺感染引起，治疗为**切开引流**。约三分之一或更多的肛周脓肿伴有或之后发展为**肛瘘**，即肛管与肛周皮肤之间的通道。累及括约肌少的肛瘘行敞开术（瘘管切开术）；瘘管跨越大量括约肌时，用**挂线**和保留括约肌的手术，以保护控便功能。
- **藏毛窦病**是臀沟内含毛发窦道的慢性感染，常见于年轻男性。脓肿要引流；慢性病变行切除，常采用偏离中线的缝合。

绝不能在未考虑癌症的情况下把直肠出血归因于痔，尤其是在50岁以上、排便习惯改变或暗红色血与粪便混合的人中。

## 吻合口与造口

::: definition 吻合口与造口 {#def-anastomosis}
**吻合口**是两个空腔结构之间的手术连接，例如切除后肠管两端的连接。可以手工缝合或用吻合器吻合。愈合取决于良好的**血供**、**无张力**、健康的组织以及营养良好的患者。

**造口**是空腔器官在皮肤表面的开口。在肠道手术中：

- **回肠造口**通常位于右髂窝，呈**乳头状**（突出2–3 cm），因为小肠排出物呈液态，会刺激皮肤；
- **结肠造口**通常位于左髂窝，与皮肤**平齐**，因为其排出物已成形；
- **末端**造口只有一个开口（远端肠管已切除或封闭）；
- **袢式**造口把一段肠袢提到体表，有两个开口，通常用于**转流**（使粪便绕开）下游的吻合口，以后再还纳。
:::

**吻合口漏**是肠道手术最令人担心的并发症。低位直肠吻合的漏发生率高于结肠吻合，在男性、吸烟者、营养不良者和放疗后也更高。吻合口漏通常在第3至7天之间表现出来：心动过速、发热、腹痛、肠麻痹、炎症指标上升或新出现的器官功能障碍（[[surgery/perioperative-care]]）。CT 可以确诊。小的局限性漏可在影像引导下引流；较大的伴腹膜炎的漏需要返回手术室，常需拆除吻合口并做造口。这就是为什么常做袢式回肠造口来保护低位直肠吻合：它不能预防吻合口漏，但能减轻其后果。

**造口并发症**包括皮肤刺激、回缩、狭窄、脱垂、**造口旁疝**和缺血（术后早期造口呈暗紫色或黑色）。**高排量造口**（回肠造口每天排出量常定义为超过1.5–2升）引起脱水、钠和镁丢失以及急性肾损伤。处理包括测量排出量、治疗病因（感染、腹腔内脓毒症、药物、部分梗阻）、限制口服**低张**液体（会增加钠丢失）、给予高钠的**口服补液溶液**，以及使用减慢转运（洛哌丁胺、可待因）和减少分泌（质子泵抑制剂）的药物。要教会患者识别脱水，造口护士在其照护中起核心作用。

::: example 排出量降不下来的造口 {#ex-high-output}
一位45岁男性因急性重症溃疡性结肠炎行结肠次全切除加末端回肠造口术后第6天。他的造口排出量已连续3天为每天2.8升。他口渴，大量饮用水和果汁饮料。血钠131 mmol/L，血镁0.55 mmol/L，肌酐145 µmol/L（基线70）。发生了什么？应如何处理？
::: solution
**解读：**他有**高排量回肠造口**，伴脱水、低钠血症、低镁血症和急性肾损伤。大量饮用水和果汁饮料使情况更糟：低张液体把钠吸入肠腔，增加排出量。

**处理：**

1. 用**静脉**氯化钠和镁纠正缺失，每天监测肾功能和电解质。
2. 寻找病因：腹腔内脓毒症、*艰难梭菌*或其他感染、部分梗阻，以及药物（如突然停用激素或使用促动力药）。
3. 限制口服低张液体（如每天约1升），其余部分给予钠浓度约90 mmol/L 或以上的**葡萄糖-盐口服补液溶液**。
4. 给予**洛哌丁胺**（餐前服用，有时在专科建议下使用高于常规的剂量；如果转运快，可打开胶囊服用），可能还需要可待因；**质子泵抑制剂**可减少胃液分泌。
5. 请造口护士和营养师参与；教他测量排出量并识别脱水；随着排出量下降调整方案。
:::
:::

## 减重手术

肥胖增加2型糖尿病、高血压、阻塞性睡眠呼吸暂停、脂肪肝病、骨关节炎和多种癌症的风险。**减重（代谢）手术**带来的体重下降比任何其他治疗都更大、更持久，并常使2型糖尿病缓解。

NICE 关于超重和肥胖管理的指南（NG246，2025年）建议，**BMI 40 kg/m² 或以上**，或 **35–39.9 kg/m²** 且有可通过减重改善的重要健康问题的成人，在同意长期随访的前提下，转诊接受减重手术评估。对于南亚、华人、其他亚洲、中东、非洲黑人或非洲加勒比家庭背景的人，由于他们在较低的 BMI 时就会出现肥胖相关疾病，可考虑采用较低的阈值（降低2.5 kg/m²）。对新近发生2型糖尿病且 BMI 35或以上的人提供加速评估，对 BMI 30–34.9者考虑加速评估。

最常见的两种手术是：

- **袖状胃切除术**，沿胃大弯切除约四分之三的胃，留下一个狭窄的管状胃；
- **Roux-en-Y 胃旁路术**，建立一个小胃囊并与一段空肠相连，绕过胃的大部分和十二指肠。

两者部分通过限制摄入起作用，但主要通过改变肠道激素（如 GLP-1 和胃饥饿素）来降低食欲并改善胰岛素敏感性。并发症包括漏、出血、狭窄、反流（尤其是在袖状胃切除术后）、旁路术后的**内疝**（可在数年后引起肠缺血，表现为间歇性腹痛）、胆结石、倾倒综合征和**营养缺乏**（铁、维生素 B12、叶酸、钙、维生素 D）。患者需要终身补充营养素并每年监测。治疗肥胖的药物（GLP-1 受体激动剂及相关药物）作为替代或补充正变得越来越重要。

::: example 应用 BMI 阈值 {#ex-bmi}
一位47岁、巴基斯坦家庭背景的男性体重101 kg，身高1.70 m。他患阻塞性睡眠呼吸暂停（使用 CPAP 治疗）和高血压。他是否符合 NICE 转诊接受减重评估的标准？
::: solution
**BMI：**$101 / 1.70^2 = 101 / 2.89 \approx 34.9$ kg/m²。

**标准阈值：**40或以上，或35–39.9且有重要健康问题。34.9刚好低于有合并症时的标准阈值35。

**调整后的阈值：**对于南亚家庭背景的人，NICE 建议考虑把阈值降低2.5 kg/m²：37.5，或有重要健康问题时32.5。他的 BMI 为34.9，合并睡眠呼吸暂停和高血压，高于32.5，因此应考虑转诊接受专科评估。

**要点：**在某些族群中 BMI 会低估代谢风险，这些族群在较低的 BMI 时就会发生2型糖尿病和心血管疾病，调整后的阈值旨在纠正这种不公平。最终决定取决于专科评估和他本人的意愿。
:::
:::

::: quiz
一位52岁女性的 BMI 为37 kg/m²。两年前她患上了2型糖尿病。按照 NICE 指南（2025年），哪一种说法最恰当？
- [ ] 她的 BMI 低于40，因此不符合减重评估的条件
- [x] 由于她新近发生2型糖尿病且 BMI 为35或以上，应为她提供减重手术的加速评估
- [ ] 她必须先完成两年的药物体重管理
- [ ] 2型糖尿病是减重手术的禁忌证
::: solution
NICE 建议为新近发生2型糖尿病且 BMI 为35或以上的人提供减重手术的加速评估。手术常使糖尿病缓解，尤其是在病程早期。是否手术在专科评估之后决定，并取决于她本人的意愿和身体状况。
:::
:::

::: warning
**胃旁路术后的腹痛，在被证明不是之前应视为内疝。**Roux-en-Y 旁路术后，小肠可经系膜缺损疝出，常发生在体重大幅下降之后。疼痛可能是间歇性的，腹部可能柔软，血液检查可能正常，CT 也可能看起来几乎正常。延误会导致一长段小肠绞窄。旁路术后有持续或反复疼痛的患者应尽早与减重外科医生讨论，即使影像不明确，也可能需要诊断性腹腔镜检查。
:::

::: history
1881年，维也纳的特奥多尔·比尔罗特（Theodor Billroth）为胃癌患者完成了首例成功的远端胃切除术，把残胃与十二指肠相连（Billroth I 式手术）。1908年，威廉·欧内斯特·迈尔斯（William Ernest Miles）根据他对直肠癌如何向淋巴结扩散的研究，描述了直肠腹会阴联合切除术。1982年，英国外科医生比尔·希尔德（Bill Heald）描述了**全直肠系膜切除术**，即将直肠连同其完整的脂肪包膜一并切除；它大幅降低了直肠癌的局部复发，现在已成为标准治疗。腹腔镜胆囊切除术由德国的埃里希·米厄（Erich Mühe）于1985年首次完成，并从1987年起由里昂的菲利普·穆雷（Philippe Mouret）和巴黎的弗朗索瓦·迪布瓦（François Dubois）推广，开启了普通外科的微创时代。
:::

## 后续内容

这些疾病的急诊表现见[[surgery/acute-abdomen]]，围手术期照护（包括肠道手术的加速康复）见[[surgery/perioperative-care]]。炎症性肠病的内科治疗见[[gastrointestinal/bowel-disease]]，营养见[[gastrointestinal/clinical-nutrition]]，筛查项目见[[public-health/screening]]。

::: summary
- 疝可以是可复性、难复性、梗阻性或**绞窄性**的；疝颈狭窄者（股疝）容易绞窄。腹股沟疝用补片修补，开放或腹腔镜均可；观察等待适合部分症状轻微的男性。
- 有症状的胆结石：腹腔镜胆囊切除术，急性胆囊炎在一周内手术。**关键安全视野**可预防胆管损伤；胆囊次全切除术是安全的退路。
- 食管癌和胃癌就诊较晚；吞咽困难者行紧急内镜检查；分期和 MDT；大型切除术在专科中心进行。
- 结直肠癌由腺瘤发展而来；英格兰对50至74岁人群每两年用 FIT 筛查；有症状者 FIT ≥ 10 µg/g 应紧急转诊。手术切除肠段及其淋巴引流区；直肠癌采用 **TME**，常在（放化疗）放疗之后。
- 溃疡性结肠炎可通过全结直肠切除术治愈；克罗恩病的手术较为保守，主要处理并发症。
- 肛门直肠疾病：痔用套扎，肛裂松弛括约肌，脓肿引流，复杂肛瘘采用保留括约肌的治疗。
- 吻合口需要血供且无张力。吻合口漏在第3–7天表现出来。回肠造口呈乳头状，结肠造口与皮肤平齐；高排量造口需要富含钠的液体并限制低张液体。
- 减重手术（袖状胃切除、旁路术）适用于 BMI ≥ 40，或 ≥ 35且有合并症者（某些族群阈值降低2.5）；旁路术后内疝是危险的晚期并发症。
:::

::: exercise 哪种疝？ {level=1}
对每一项描述，说出最可能的疝：(a) 一位70岁女性耻骨结节外下方的肿块；(b) 一位30岁男性下降至阴囊、按压内环可控制的肿块；(c) 脐上方中线处的膨出；(d) 剖腹手术瘢痕处的膨出。

::: exercise 选择手术 {level=1}
说出下列部位癌症的标准切除术：(a) 盲肠；(b) 乙状结肠；(c) 距肛缘8 cm 的直肠中段；(d) 侵犯肛门括约肌的低位直肠。
::: solution
(a) 右半结肠切除术。(b) 乙状结肠切除术（有时称为高位前切除术）。(c) 前切除术加全直肠系膜切除，常根据分期先行新辅助治疗，通常做临时转流性袢式回肠造口。(d) 腹会阴联合切除术，做永久性末端结肠造口。

::: exercise 体重指数 {level=1 check="round(10*118/1.68^2)/10"}
一位女性体重118 kg，身高1.68 m。计算她的 BMI，四舍五入保留一位小数。在没有任何合并症的情况下，她是否符合 NICE 减重评估的标准阈值？
::: solution
$\text{BMI} = 118 / 1.68^2 = 118 / 2.8224 \approx 41.8$ kg/m²。这高于40，因此即使没有合并症，只要她同意长期随访，就符合转诊评估的阈值。是否适合手术则取决于专科评估。
:::

::: exercise 可以等待吗？ {level=2}
一位66岁男性有一个小的、容易回纳的右侧腹股沟疝已2年。只有在长时间步行后才有轻微不适。他问是否必须做手术。你怎么回答他？
::: solution
对于腹股沟疝症状轻微的男性，**观察等待**是合理的选择：疝发生绞窄的风险低。不过，许多腹股沟疝男性最终会出现更多症状并选择修补。决定取决于他的偏好、身体状况以及疝对他生活的影响。应教会他嵌顿和绞窄的警示征象：肿块变得疼痛、紧张且不能回纳，尤其是伴有呕吐或腹胀时，需要紧急评估。如果他选择手术，要讨论可选的术式（开放补片修补或腹腔镜修补）以及慢性腹股沟疼痛和复发的风险。
:::
:::

::: exercise 治疗失败的结肠炎 {level=2}
一位28岁女性患急性重症溃疡性结肠炎，已静脉使用糖皮质激素3天。她每天仍有9次血便，CRP 65 mg/L，心率104次/分。有哪些选择？应该请谁参与？等待有什么危险？
::: solution
到第3天她对静脉激素仍无反应（频繁血便和 CRP 升高预示治疗失败）。可选择**挽救性药物治疗**（英夫利西单抗或环孢素）或**结肠切除术**（通常为结肠次全切除加末端回肠造口，保留直肠，以便她以后如有意愿可行储袋手术）。由消化科医生和结直肠外科医生与她共同作出决定，并应尽早让她见造口护士。继续每天复查，拍腹部 X 线片观察有无结肠扩张。**等待的危险：**长时间无效的药物治疗会增加中毒性巨结肠、穿孔和死亡的风险，并使她成为较差的手术候选者。如果挽救治疗在几天内失败，不应再推迟手术。
:::
:::

::: exercise 肛周问题 {level=2}
一位34岁男性肛门旁搏动性疼痛3天，坐下时加重，体温38.1 °C。距肛缘3 cm 处有一个有压痛、发红、有波动感的肿胀。诊断和治疗是什么？关于以后应告诉他什么？
::: solution
**诊断：**肛周脓肿。**治疗：**切开引流，通常在急诊手术排程中于全身麻醉下进行，同时检查肛管；抗生素不能替代引流，但在有蜂窝织炎、糖尿病或免疫抑制时可以加用。**以后：**相当一部分患者（约三分之一或更多）之后会发展为或被发现有**肛瘘**，表现为引流部位持续流液或脓肿反复发作。应告诉他出现这种情况时要复诊。反复发作或复杂的病变需要考虑克罗恩病，并做 MRI 检查。
:::
:::

::: exercise 造口丢失 {level=3 check="2700"}
一位60 kg、新做了回肠造口的女性在过去24小时内造口排出量为2.2升，目前还不能喝足够的水。她的团队按25 mL/kg/天开具维持水量，另外补充超过每天1升的造口排出量（维持量已包括典型的回肠造口排出量）。如果她的排出量保持不变，接下来24小时内她需要多少毫升静脉液体？给出精确值。补充部分应使用哪种液体？还应做些什么？
::: hint
先根据体重算出维持量，再加上超过1升的额外丢失。
:::
::: solution
维持量：$25 \times 60 = 1500$ mL。造口额外丢失：$2200 - 1000 = 1200$ mL。总量：$1500 + 1200 = 2700$ mL。

回肠造口液富含钠（约90–100 mmol/L 或更高），因此补充部分应使用**含钠**晶体液，如0.9%氯化钠并根据需要加钾，依据她的电解质调整，而不是使用葡萄糖。检查并补充镁。同时团队要寻找高排量的原因，开始使用洛哌丁胺，在她能饮水后限制口服低张饮料而改用口服补液溶液，并请造口护士和营养师参与。每天称体重、记录液体平衡和检查肾功能以指导方案。
:::
:::

::: exercise 旁路术后的腹痛 {level=3}
一位38岁女性2年前接受了腹腔镜 Roux-en-Y 胃旁路术，体重已下降45 kg。她一个月内第三次出现餐后剧烈的中腹痛，持续数小时。今天疼痛是持续性的。她的腹部柔软，中腹部有轻度压痛，白细胞计数和乳酸正常，CT 显示肠系膜血管"漩涡征"。给出鉴别诊断、最可能的诊断和处理。
::: solution
**鉴别诊断：**内疝；粘连性肠梗阻；胆石症（快速减重后胆结石很常见）；胃空肠吻合口处的边缘溃疡（尤其是吸烟者和使用 NSAID 者）；肠套叠；以及胰腺炎等非外科病因。

**最可能：**经系膜缺损的**内疝**。大幅减重后反复餐后腹痛以及 CT 上的肠系膜漩涡征是典型表现。血液检查正常和腹部柔软不能排除它，而持续性疼痛提示肠管此时可能已受损。

**处理：**禁食，补液和镇痛，紧急与减重外科团队讨论。她需要**紧急腹腔镜手术**，复位疝并关闭系膜缺损，切除任何失活的肠管。等待腹膜炎或乳酸上升有失去一长段小肠的风险。如果她被送到了没有减重外科的医院，在她病情恶化时普通外科医生应当手术，而不是为了转院而拖延。
:::
