每一次手术都会造成伤口，而每一个伤口都必须愈合。大多数手术伤口在一两周内悄然愈合，但当愈合失败或感染发生时，后果从多换几次敷料到腹部切口裂开或危及生命的软组织感染不等。手术部位感染是最常见的医疗相关感染之一，其中很大一部分是可以预防的。

本章介绍伤口如何愈合以及什么因素会减慢愈合、伤口如何缝合、手术部位感染如何预防、识别和治疗，以及脓肿、坏死性软组织感染、伤口裂开、切口疝、压力性损伤和咬伤等具体问题。指南以英国为主（NICE 关于手术部位感染的 NG125、关于咬伤的 NG184，以及英国卫生安全局关于破伤风的《绿皮书》（*Green Book*）），内容截至2026年。抗生素的选择以原则形式描述；个体处方遵循当地微生物学指南。

## 伤口如何愈合

::: definition 伤口愈合的阶段 {#def-healing}
伤口愈合经历四个相互重叠的阶段：

1. **止血**（数分钟）：血管收缩，血小板聚集，形成纤维蛋白凝块。血小板释放血小板衍生生长因子（PDGF）和转化生长因子β（TGF-β）等生长因子，启动下一阶段。
2. **炎症**（约第0–4天）：中性粒细胞最先到达，清除细菌和碎屑；随后巨噬细胞到来，成为修复的主要协调者，释放生长因子。
3. **增殖**（约第3–21天）：成纤维细胞沉积新的胶原（起初为 III 型），新生毛细血管长入（血管生成），形成红色颗粒状的**肉芽组织**，上皮细胞向表面迁移覆盖，肌成纤维细胞使伤口收缩。
4. **重塑**（约3周至1–2年）：胶原重新排列，III 型被更坚韧的 I 型取代；瘢痕变平、变白。抗张强度在3周时约为正常的20%，最终不超过未受伤皮肤的约80%。
:::

炎症与修复的组织生物学在[[pathology/chronic-inflammation-repair]]中有更详细的介绍。对外科医生来说，有两点最重要。第一，伤口在第一周最薄弱，此时胶原的分解和重塑快于沉积；缝合的伤口和肠吻合口最容易在这时裂开。第二，每个阶段都依赖良好的血供，由它输送氧、营养物质和免疫细胞。

### 一期愈合与二期愈合

::: definition 一期愈合、二期愈合和延迟一期缝合 {#def-intention}
- **一期愈合：**受伤后不久即将伤口边缘对合（用缝线、钉皮器、组织胶或胶带）。所需肉芽组织很少，愈合快，瘢痕细。用于清洁的手术伤口。
- **二期愈合：**伤口保持开放，由基底长出肉芽组织填充，然后收缩并上皮化。愈合需要数周，瘢痕较宽，但感染可以引流。用于脓腔、严重污染的伤口和某些藏毛窦伤口。
- **延迟一期缝合（三期愈合）：**对污染的伤口进行清创后保持开放数天，待其清洁后再缝合。用于某些创伤性伤口和污染的手术伤口。
:::

### 什么会妨碍愈合

减慢愈合的因素可以方便地分为伤口的**局部**因素和患者的**全身**因素。

| 局部因素 | 全身因素 |
|---|---|
| 血供差（动脉疾病、缝合张力过大、敷料过紧） | 糖尿病（中性粒细胞功能受损、小血管病变） |
| 感染 | 营养不良，尤其是蛋白质、维生素 C 和锌缺乏 |
| 异物、坏死组织和血肿 | 吸烟（血管收缩、一氧化碳） |
| 该部位既往接受过放疗 | 糖皮质激素、化疗和其他免疫抑制剂 |
| 活动和机械应力 | 高龄、肥胖、黄疸、尿毒症 |
| 水肿和静脉高压 | 术中低体温和低血容量 |

糖皮质激素是全身因素的一个好例子。它抑制炎症期，使巨噬细胞释放的生长因子减少，成纤维细胞沉积的胶原减少。维生素 A 可以部分抵消其对愈合的影响，但并不常规使用。

::: example 不愈合的伤口 {#ex-foot}
一位67岁的2型糖尿病男性，右脚前掌有一处无痛性溃疡已6周。他以为是老茧。溃疡直径2 cm，探针可触及骨，周围皮肤发红发热范围达3 cm，足部动脉搏动减弱。主要问题有哪些？下一步应该怎么做？
::: solution
**问题。**他患有糖尿病足溃疡，存在三种相互独立的妨碍愈合的威胁：

1. **神经病变**，这就是溃疡无痛并发生在受压点的原因。
2. **感染**：扩散的红肿发热提示软组织感染，探针触及骨强烈提示**骨髓炎**。
3. **缺血**：搏动减弱提示外周动脉疾病，这会妨碍愈合，可能需要血运重建。

**下一步。**这很紧急。NICE 关于糖尿病足问题的指南（NG19）建议，有威胁肢体或正在扩散的感染的患者应立即转诊至急诊服务和多学科足部护理服务。他需要包括炎症指标和 HbA1c 在内的血液检查、深部组织或骨标本培养（而不是浅表拭子）、足部 X 线片，很可能还需要 MRI，并按当地指南使用抗生素。用踝肱压力指数（在糖尿病患者中可因动脉钙化而假性升高）或趾压以及双功超声进行动脉评估，可显示是否需要血运重建（[[surgery/vascular-urological-surgery]]）。必须解除溃疡处的压力（减压）、清除坏死组织并控制血糖。延误会增加截肢的可能。
:::
:::

## 缝合伤口

大多数手术伤口用缝线、钉皮器或组织胶闭合。选择取决于部位、张力和对外观的要求。

- **可吸收缝线**（如聚乳酸羟基乙酸或聚二氧环己酮）在数周至数月内被分解；用于深层、肠吻合和许多采用皮内缝合的皮肤闭合。
- **不可吸收缝线**（如尼龙或聚丙烯）保持强度，用于需要拆除的皮肤缝线，以及需要永久支撑的结构，如某些疝修补和血管吻合。
- **单股**缝线穿行顺滑，藏匿的细菌较少；**编织**缝线更容易操作，但细菌可沿其纤维渗入。

皮肤缝线的拆除时间取决于血供：通常面部约5天，头皮和躯干7–10天，四肢和关节表面10–14天。

腹部正中切口是一个特殊情况。在瘢痕仍薄弱时，它必须承受咳嗽和用力。2015年发表的一项大型随机试验（STITCH）发现，用**小针距**（缝针距边缘约5 mm、针距约5 mm，使用缓慢吸收的单股缝线）而不是传统的大针距缝合正中筋膜，可使1年时的切口疝从21%降至13%。其基本原则是缝线长度至少应为切口长度的四倍，从而使张力由许多小针分担。

## 手术部位感染

::: definition 手术部位感染 {#def-ssi}
**手术部位感染（SSI）**是指在术后30天内（按照美国 CDC 等监测定义，某些涉及植入物的手术可长达90天）发生的伤口或术中处理过的组织的感染。按深度分类：

- **浅表切口感染：**皮肤和皮下组织（发红、有脓、伤口裂开）；
- **深部切口感染：**筋膜和肌肉；
- **器官/腔隙感染：**术中打开或操作过的身体任何部位，如腹腔内脓肿、脓胸或感染的关节假体。
:::

SSI 的风险取决于进入伤口的细菌数量、细菌的毒力，以及患者和伤口抵抗细菌的能力。污染程度用**伤口分类**来描述。

::: definition 伤口污染分类 {#def-wound-class}
- **清洁：**无炎症，且未进入呼吸道、消化道、生殖道和泌尿道（如疝修补术、甲状腺切除术）。历史 SSI 率约1–2%。
- **清洁-污染：**在受控条件下进入上述某一腔道而无异常污染（如择期胆囊切除术或肠切除术）。历史发生率低于10%。
- **污染：**新鲜的创伤伤口、无菌技术的重大破坏，或肠内容物大量溢出。历史发生率约15–20%。
- **污秽（感染）：**已有感染或空腔脏器穿孔（如有脓液的阑尾穿孔、含坏死组织的陈旧创伤伤口）。历史发生率高达40%。

这些数字来自没有现代预防措施的较早研究；目前的发生率较低，但排序不变。
:::

### 预防 SSI

NICE 指南 NG125 规定了手术前、手术中和手术后的措施。最重要的有：

- **术前：**尽可能治疗远处感染；术前用肥皂淋浴或沐浴；**不要**常规备皮，如果必须去除毛发，应在手术当天使用带一次性刀头的电动剪毛器，而不是剃刀（剃刀造成的微小擦伤会有细菌定植）；在某些手术中，按当地政策筛查并去除*金黄色葡萄球菌*（*Staphylococcus aureus*）定植。
- **抗生素预防：**用于涉及植入物或假体的清洁手术、清洁-污染手术和污染手术。在麻醉开始时静脉单次给药，使切皮时组织浓度处于高水平；手术时间长时追加。术后不常规继续使用。已经感染的污秽伤口需要的是**治疗**，而不是预防。
- **术中：**在切皮前即刻消毒皮肤，首选**含醇氯己定**，除非有禁忌或靠近黏膜（使用电刀前要让其完全干燥，以免起火）；保持患者温暖、氧合良好和灌注良好；维持正常血糖；轻柔处理组织；使用无菌手术衣、手套和手术单。
- **术后：**在手术结束时用合适的交互式敷料覆盖伤口；换药时采用无菌非接触技术；对一期愈合的伤口不使用局部抗生素。

::: example 解读一项 SSI 审计 {#ex-ssi-audit}
一个结直肠外科单元一年中完成了400例择期肠切除术。监测发现36例 SSI：24例浅表、8例深部、4例器官/腔隙。随后该单元引入了一套集束措施（用剪毛代替剃毛、含醇氯己定皮肤消毒、保温、血糖控制和切口保护器）。第二年，410例切除术中有23例 SSI。SSI 发生率分别是多少？相对降低多少？
::: solution
**之前：**$36/400 = 0.09 = 9.0\%$。

**之后：**$23/410 \approx 0.0561 = 5.6\%$。

**相对降低：**$(0.09 - 0.0561)/0.09 \approx 0.377$，下降约38%。绝对降低约3.4个百分点，即大约每30例切除术预防1例 SSI。

**解读。**这一改善与集束措施有效相符，但前后比较无法证明这一点。其他解释包括病例构成的变化（急诊更少、造口更少）、第二年监测不够完整（尤其是出院后，许多浅表 SSI 在此时出现）以及机遇（例数不多）。良好的监测使用固定的定义、出院后的主动随访和风险校正，并在改变之后持续进行，以观察效果能否维持。
:::
:::

### 识别和治疗 SSI

浅表 SSI 通常在**术后5–7天**出现，常常在出院之后，表现为疼痛加重、发红、肿胀、发热和流脓，有时伴有发热。大多数浅表感染的治疗方法是**敞开伤口**（拆除几根缝线或皮钉）让脓液流出，然后换药并让其二期愈合。如果有扩散的蜂窝织炎或全身症状，则加用抗生素。取拭子做培养，但没有感染临床表现时拭子阳性通常反映的是定植而不是感染。

深部和器官/腔隙感染需要影像检查（超声或 CT）来寻找积液。积液需要引流，通常由介入放射科医生在影像引导下置管，有时需要手术。感染的植入物（如补片或人工关节）可能需要取出。

::: warning
**抗生素不能治疗脓液积聚。**脓肿是一个有包裹的腔，血供差；抗生素很难渗透进去，而其中的脓液含有抗生素无法清除的死亡中性粒细胞和细菌。一位正在使用抗生素、但仍有弛张热、炎症指标上升、伤口或腹部压痛的患者，需要寻找未引流的脓液，而不是更换抗生素。*Ubi pus, ibi evacua*：哪里有脓，就把它放出来。
:::

### 脓肿

**脓肿**是被炎症组织包绕的局限性脓液积聚。皮肤脓肿通常由*金黄色葡萄球菌*引起，包括产生杀白细胞素（Panton–Valentine leucocidin）的菌株，它会引起反复发作的坏死性疖肿。肛周脓肿来自感染的肛腺，并与肛瘘相关。藏毛窦脓肿在臀沟内围绕毛发形成。

脓肿的治疗是**切开引流**：打开脓腔，分离任何分隔，冲洗干净，让其从底部愈合。存在周围蜂窝织炎、全身症状或免疫功能低下时加用抗生素。反复发作的脓肿提示需寻找潜在原因，如糖尿病、肛瘘、化脓性汗腺炎或克罗恩病。

## 坏死性软组织感染

::: definition 坏死性软组织感染 {#def-nsti}
**坏死性软组织感染**（包括**坏死性筋膜炎**）是一种迅速扩散的筋膜和皮下组织感染，引起小血管血栓形成和组织坏死。按病原体分类：

- **I 型（多种微生物）：**需氧菌和厌氧菌混合感染，常见于糖尿病患者、腹部或会阴手术后，或发生在会阴部（**Fournier 坏疽**，[[surgery/vascular-urological-surgery]]）。
- **II 型（单一微生物）：**通常为*化脓性链球菌*（*Streptococcus pyogenes*，A 组链球菌），有时合并*金黄色葡萄球菌*；可在轻微损伤后发生于健康的年轻人。

其他形式包括梭菌性气性坏疽，以及接触海水后由*弧菌*属引起的感染。
:::

早期表现具有迷惑性。皮肤可能只是轻度发红，但疼痛与可见体征**不相称**，因为感染在外观正常的皮肤下沿筋膜扩散。较晚的体征包括超出发红范围的张力性水肿、暗紫色皮肤、水疱、气体引起的捻发感、神经坏死导致的感觉丧失，以及脓毒性休克。

LRINEC 评分（基于 CRP、白细胞计数、血红蛋白、钠、肌酐和血糖）等评分系统曾被提出用于辅助诊断，但后来的研究发现它们会漏诊许多病例，因此不能用低分来排除诊断。CT 可显示气体或筋膜水肿，但当临床高度怀疑时，影像检查绝不能延误手术。

治疗是**紧急根治性外科清创**，切除所有坏死组织直至见到出血的健康组织，并每24–48小时返回手术室，直至不再发现坏死。同时：对脓毒性休克进行复苏，静脉使用包括克林霉素在内的广谱抗生素，克林霉素可减少链球菌和葡萄球菌的毒素产生。死亡率仍然很高，手术延迟是使死亡率升高的主要因素之一。

::: example 与体征不相称的疼痛 {#ex-nsti}
一位52岁的2型糖尿病女性在大腿轻微擦伤2天后就诊。她大腿剧痛，体温38.9 °C，心率125次/分，血压92/55 mmHg。有一块6 cm 的轻度发红区，但整个大腿肿胀紧绷，红肿范围以外也有明显压痛。CRP 310 mg/L，血钠129 mmol/L，血糖22 mmol/L。应如何处理？
::: solution
**识别。**超出可见发红范围的剧痛和压痛、张力性水肿、伴低血压的脓毒症、低钠血症以及糖尿病患者的高血糖，都指向**坏死性软组织感染**。单纯蜂窝织炎在皮肤改变如此轻微时不会引起这种程度的疼痛和全身症状。

**紧急处理。**

1. 按脓毒症指南复苏：给氧、建立静脉通路、血培养、乳酸、液体推注，并尽早请重症监护参与。
2. 按当地指南开始包括克林霉素在内的静脉广谱抗生素。
3. 立即请上级外科医生。诊断在手术室中确认并同时治疗：筋膜呈灰色、暗淡，容易与组织分离，可能有稀薄的"洗碗水样"液体。切除所有坏死组织。
4. 如果临床表现明确，不要为了做 CT 而推迟进手术室。

**之后。**她需要再次清创、重症监护、血糖控制，以后还需要皮肤移植进行修复。A 组链球菌感染是法定报告的疾病，密切接触者可能需要接受建议。
:::
:::

## 伤口裂开与切口疝

**伤口裂开**是指已缝合伤口的各层分开。其最严重的形式是**腹部筋膜裂开**（"腹部切口裂开"），筋膜缝合失败，肠管可能出现在伤口中。它通常发生在术后**第5–10天**。典型的警示信号是伤口突然流出**粉红色浆液性液体**，这是腹腔液经失败的筋膜渗出。

危险因素包括妨碍愈合的因素（高龄、营养不良、激素、糖尿病、黄疸）、使腹内压升高的因素（咳嗽、肠麻痹、肥胖、呕吐）以及技术因素（张力下缝合、大针距技术、感染）。

腹部切口裂开的处理：安抚患者，用无菌生理盐水浸湿的纱布覆盖暴露的肠管，给予镇痛，禁食，并安排再次手术。有些患者在腹部无法安全关闭时采用临时关腹或负压伤口治疗。

**切口疝**是其晚期的慢性对应形式：筋膜逐渐分开而皮肤不破，腹腔内容物经此膨出。相当一部分腹部正中切口术后会发生切口疝，尤其是发生过伤口感染之后。小针距缝合、对高危患者预防性使用补片以及避免感染可以减少切口疝。有症状或疝颈狭窄、有嵌顿风险时考虑修补（[[surgery/gastrointestinal-surgery]]）。

::: example 第7天的粉红色液体 {#ex-pop}
一位74岁男性因乙状结肠穿孔接受急诊剖腹手术后第7天。他因肺部感染一直剧烈咳嗽，白蛋白22 g/L。在坐便椅上用力时，他发现敷料被粉红色水样液体浸透。可能发生了什么？应该怎么做？
::: solution
**诊断。**剖腹手术伤口在第5–10天左右突然流出粉红色浆液，提示**筋膜裂开**：即使皮肤仍完整，深层缝合已经失败。他的危险因素包括急诊污染手术、可能的伤口感染、营养差（低白蛋白更多反映的是疾病和炎症，而不仅仅是营养）、咳嗽和用力。

**紧急措施。**让他平卧并安抚他。检查伤口：必要时拆除几根皮肤缝线以检查筋膜。如果看到肠管，用温的生理盐水浸湿的无菌纱布覆盖。给予镇痛，禁食，查血，并通知上级外科医生和麻醉医生。

**确定性处理。**大多数患者返回手术室关腹，常采用减张技术；如果腹腔污染，则临时关腹。治疗他的肺部感染、营养问题和咳嗽。他以后发生切口疝的风险很高。
:::
:::

## 压力性损伤

**压力性损伤**（压疮）是皮肤及其下组织的局部损伤，通常位于骨突处，如骶部、足跟或髋部，由单纯压力或压力合并剪切力引起。持续的压力超过毛细血管闭合压会导致缺血，而深部肌肉比皮肤更易受损，因此在完整或仅轻度变色的表面之下，损伤可能已经很广泛。

压力性损伤分为 **1类**（完整皮肤上不褪色的发红）、**2类**（部分皮层缺损）、**3类**（全层皮肤缺损，可见脂肪）和 **4类**（全层组织缺损，暴露骨、肌腱或肌肉），另有被腐肉或焦痂覆盖的**不可分期**损伤和**可疑深部组织损伤**两类。外科患者在长时间手术中、术后制动期间以及髋部骨折后都有风险。预防依赖于风险评估、定期翻身、压力再分布床垫、足跟减压、皮肤护理和营养。

## 咬伤与破伤风

人、狗和猫的**咬伤**是污染伤口。猫咬伤尤其会造成深的穿刺伤，把细菌（包括*多杀巴斯德菌*，*Pasteurella multocida*）带入腱鞘和关节。指关节上的人咬伤常由拳击对方口部引起（"打架咬伤"），可进入掌指关节并引起化脓性关节炎。处理原则是：清洗并冲洗，清除坏死组织，考虑保持伤口开放而不缝合（面部除外），并评估是否累及肌腱或关节。NICE 指南 NG184（2020年）建议在某些情况下对破皮的咬伤进行抗生素预防，如猫咬伤、见血的人咬伤，以及高危部位（手、足、面部、生殖器、关节附近）或高危人群的咬伤；通常首选阿莫西林克拉维酸。人咬伤后要评估血源性病毒风险，国外动物咬伤或蝙蝠咬伤后要评估狂犬病风险。

**破伤风**由*破伤风梭菌*（*Clostridium tetani*）的毒素引起，其芽孢存在于土壤和粪肥中。**易感染破伤风的伤口**包括穿刺伤、含异物或泥土的伤口、开放性骨折、有失活组织的伤口、烧伤和咬伤，尤其是处理延迟时。处理取决于伤口和患者的免疫接种史，遵循英国《绿皮书》：所有伤口都要彻底清洗；未完成全程破伤风疫苗接种或接种情况不明的人，给予一剂疫苗；对于不能假定有免疫力的高危破伤风易感伤口，给予**人破伤风免疫球蛋白**。

::: quiz
一位30岁女性被自家的猫咬伤手背。穿刺伤口很小，手看起来正常。最合适的处理是什么？
- [ ] 缝合伤口并安抚她
- [ ] 伤口很小，不需要治疗
- [x] 清洗并冲洗，保持伤口开放，给予抗生素预防并安排复查
- [ ] 只有在伤口拭子培养出细菌时才使用抗生素
::: solution
猫咬伤造成的深穿刺伤会把细菌带入腱鞘和关节；表面的小伤口可能隐藏着深部感染。NICE 建议对破皮的猫咬伤预防性使用抗生素，伤口应清洗并通常保持开放。等待拭子结果会延误对快速进展感染的治疗。
:::
:::

::: history
1847年，伊格纳兹·塞麦尔维斯（Ignaz Semmelweis）在维也纳总医院的产科病房工作时发现，由从尸检室过来的医生和学生负责的病房中产褥热远比助产士负责的病房常见，而用含氯石灰溶液洗手可使死亡率大幅下降。他的工作在其生前基本上遭到拒绝。二十年后，格拉斯哥的约瑟夫·李斯特（Joseph Lister）在读到路易·巴斯德（Louis Pasteur）关于微生物的工作后，开始用石炭酸处理开放性骨折和伤口，并于1867年在《柳叶刀》（*The Lancet*）上发表了结果；感染和截肢随之减少。抗菌法（在伤口中杀灭细菌）逐渐被无菌法（不让细菌进入）取代，这得益于器械的蒸汽灭菌，以及约从1890年起由威廉·霍尔斯特德（William Halsted）在约翰斯·霍普金斯医院引入的橡胶手套。
:::

## 后续内容

炎症与修复的一般生物学见[[pathology/acute-inflammation]]和[[pathology/chronic-inflammation-repair]]。感染控制和抗菌药物管理见[[microbiology/infection-control]]和[[infectious-diseases/stewardship-outbreaks]]，脓毒症见[[infectious-diseases/fever-sepsis]]。预防 SSI 的围手术期措施（保温、血糖控制、抗生素时机）见[[surgery/perioperative-care]]。

::: summary
- 愈合经历**止血、炎症、增殖和重塑**。伤口在第一周最薄弱；瘢痕强度在3周时约为20%，最多达到正常的约80%。
- 愈合方式有**一期愈合**（边缘对合）、**二期愈合**（保持开放，肉芽生长）或**延迟一期缝合**。
- 局部因素（血供、感染、异物、放疗）和全身因素（糖尿病、营养不良、吸烟、激素）妨碍愈合。
- **SSI** 分为浅表、深部或器官/腔隙；风险随**伤口分类**（清洁、清洁-污染、污染、污秽）升高。
- NICE NG125：不常规备皮（需要时用剪毛器），**含醇氯己定**皮肤消毒，有指征时在诱导时单次预防给药，保温和良好灌注。
- 浅表 SSI 的治疗是敞开伤口；**脓液需要引流**，而不仅仅是抗生素。
- 坏死性软组织感染表现为**与体征不相称的疼痛**，需要紧急清创；评分不能排除诊断。
- 第5–10天左右出现粉红色浆液预示**筋膜裂开**；小针距缝合可减少切口疝。
- 咬伤是污染伤口；猫和人咬伤常需预防性使用抗生素。破伤风的处理取决于伤口类型和免疫接种状态。
:::

## 习题

::: exercise 伤口分类 {level=1}
给出下列手术的污染分类：(a) 使用补片的开放腹股沟疝修补术；(b) 择期腹腔镜胆囊切除术；(c) 有游离脓液的十二指肠溃疡穿孔剖腹手术；(d) 术中肠内容物溢出的急诊右半结肠切除术。
::: solution
(a) 清洁（未进入腔道），但因有植入物可考虑预防用药。(b) 清洁-污染（在受控条件下进入胆道）。(c) 污秽（已有化脓感染）。(d) 污染（肠内容物大量溢出）。(c) 和 (d) 在大多数情况下需要治疗疗程的抗生素而不仅仅是预防，皮肤可保持开放或疏松缝合。
:::
:::

::: exercise 一期还是二期？ {level=1}
下列伤口最适合哪种愈合方式？(a) 3小时前前臂的清洁裂伤；(b) 已引流的肛周脓腔；(c) 18小时前小腿的狗咬伤，周围有污染；(d) 粪性腹膜炎术后腹腔严重污染的剖腹手术伤口。
::: solution
(a) 一期愈合：清洁、新鲜、血供良好。(b) 二期愈合：让脓腔从底部愈合，以免脓液再次积聚。(c) 清洗后通常保持开放，采用延迟一期缝合或二期愈合，因为伤口陈旧且有污染；面部咬伤是主要例外，常予缝合。(d) 关闭筋膜；皮肤常保持开放或疏松缝合，采用延迟缝合或负压治疗，以减少浅表 SSI。
:::
:::

::: exercise SSI 发生率 {level=1 check="4.5"}
一家医院记录了400例剖宫产后发生18例手术部位感染。以百分比表示的 SSI 发生率是多少？给出精确值。
::: solution
$18/400 = 0.045 = 4.5\%$。许多剖宫产 SSI 在出院后才出现，因此只统计住院期间感染的监测会低估真实发生率。
:::
:::

::: exercise 愈合轨迹 {level=2 check="40"}
一处糖尿病足溃疡首次评估时面积为12.0 cm²，四周后为7.2 cm²。面积减少了百分之多少？给出精确值。4周内缩小不到约一半的溃疡在现有方案下不太可能在12周内愈合；应该怎么做？
::: hint
减少百分比 =（初始 − 当前）/ 初始 × 100。
:::
::: solution
$(12.0 - 7.2)/12.0 \times 100 = 4.8/12 \times 100 = 40\%$。40%的缩小低于预测愈合的约50%，因此多学科足部团队应重新审查方案：检查感染（包括骨髓炎），重新评估血供并考虑血运重建，检查减压是否有效且被坚持使用，清创，优化血糖控制和营养，并戒烟。
:::
:::

::: exercise 第6天红肿 {level=2}
一位41岁女性因阑尾穿孔接受开放阑尾切除术后第6天，伤口红肿、压痛，有波动区，体温38.2 °C，其他方面情况良好。她已口服抗生素3天。诊断和治疗是什么？哪些特征会让你寻找更深部的问题？
::: solution
**诊断：**浅表切口 SSI 伴皮下积液。**治疗：**拆除部分缝线或皮钉敞开伤口，引流脓液，送培养，冲洗并填塞或敷料覆盖，让其二期愈合。单用抗生素已经失败，因为有脓液存在；如有扩散的蜂窝织炎可继续使用。**寻找更深部问题的情况：**她有腹痛、肠麻痹、腹泻或直肠不适（盆腔脓肿），引流后仍有弛张热或炎症指标上升，或出现脓毒症征象。腹部和盆腔 CT 可寻找腹腔内积液，这在阑尾穿孔后很常见。
:::
:::

::: exercise 正确的抗生素方案 {level=2}
对每种情况，说明应进行抗生素预防、治疗疗程还是不用抗生素，并说明理由：(a) 一位健康男性的择期腹腔镜腹股沟疝修补术，不用补片；(b) 择期全髋关节置换术；(c) 择期前切除术；(d) 粪性腹膜炎的剖腹手术。
::: solution
(a) 按 NICE NG125，对低风险患者的无植入物清洁手术一般不进行预防（腹腔镜疝修补通常确实使用补片，这会改变决定）。(b) 预防：带假体的清洁手术，一旦感染后果是灾难性的。(c) 覆盖肠道菌群（需氧菌和厌氧菌）的预防，诱导时单次给药，手术时间长时追加。(d) 治疗疗程：腹腔已经感染，因此术后要继续使用抗生素一段确定的时间，根据临床进展和感染源控制情况调整。
:::
:::

::: exercise 注射吸毒者的腿部肿胀 {level=3}
一位34岁的注射吸毒男性出现腹股沟和大腿上部疼痛肿胀，体温39.5 °C，心率130次/分，血压88/50 mmHg。腹股沟注射部位附近有一个波动性肿块，大腿皮肤紧绷、暗紫，并有一个水疱。给出鉴别诊断、检查和紧急处理。在腹股沟做任何切口之前必须考虑什么特殊危险？
::: solution
**鉴别诊断：**注射部位的腹股沟脓肿；坏死性软组织感染（紧绷、暗紫、起疱的皮肤合并休克提示此病）；注射入动脉引起的感染性**股动脉假性动脉瘤**；化脓性血栓性静脉炎或深静脉血栓形成；髋关节化脓性关节炎；梭菌感染（包括来自污染的毒品）。

**检查：**血培养、乳酸、全血细胞计数、CRP、肾功能、血糖，经同意后检测血源性病毒；紧急腹股沟双功超声或 CT 血管造影。

**紧急处理：**脓毒症复苏，按当地指南使用包括克林霉素在内的广谱抗生素；紧急上级外科医生评估；如确诊坏死性感染则进手术室清创；提供不带评判的照护，关注疼痛、阿片类替代治疗和戒断。

**危险：**腹股沟搏动性肿块可能是**假性动脉瘤**。把它当作脓肿切开可能导致灾难性出血。对注射吸毒者，在股血管附近做任何切口之前，都要先进行影像检查并请血管外科参与。
:::
:::

::: exercise 制订腹部切口裂开的预防方案 {level=3}
你所在单元在六个月内急诊剖腹手术后发生了三例筋膜裂开。利用愈合的生物学和本章中的证据，设计一个涵盖患者、缝合技术和术后阶段的预防方案。
::: solution
**患者因素：**在手术时识别高危患者（65岁以上、急诊手术、污染、营养不良、使用激素、肥胖、慢性肺病、黄疸）。迅速优化能够改变的因素：从第1天开始营养支持、控制血糖、在安全的前提下减少激素剂量。

**缝合：**使用连续缓慢吸收单股缝线，采用**小针距技术**缝合筋膜，缝线长度与切口长度之比至少为4:1；根据当地证据考虑对极高危患者预防性使用补片；避免在过大张力下关腹，如果腹部肿胀或严重污染则临时关腹；采取 SSI 预防措施（切口保护器、保温、氧合、灌注）。

**术后：**治疗咳嗽和肺部感染，预防和治疗肠麻痹和呕吐，避免便秘和用力，咳嗽时扶住伤口，并把粉红色浆液渗出视为紧急警示信号。

**审计：**记录每次关腹的技术以及缝线长度与切口长度之比，追踪1年时的裂开、SSI 和切口疝，并在并发症与死亡病例讨论会上回顾每一个病例。
:::
