伤口与外科的感染是同一枚硬币的两面：微生物的污染与宿主的修复之间的平衡决定了愈合还是化脓。本章涵盖手术部位的感染与预防性抗生素、伤口的愈合与其失败，以及咬伤、蜇伤、烧伤与污染伤[[microbiology/infection-control]]、[[pathology/chronic-inflammation-repair]]。

本章涵盖手术部位的感染、愈合的生理与失败、特殊的伤，以及预防的项目。

## 感染的一面

::: definition 手术部位的感染与抗生素的策略 {#def-ssi}
**手术部位的感染来自微生物的剂量与毒力和宿主的防御与组织的状态：皮肤的菌群与肠道的菌与环境的来源[[microbiology/bacteria]]、[[microbiology/microbiota]]。危险的因素包括糖尿病与营养和吸烟和免疫抑制，以及手术的技术与血肿与异物[[endocrine/diabetes]]、[[gastrointestinal/clinical-nutrition]]、[[public-health/prevention-promotion]]、[[immunology/innate-immunity]]、[[pathology/chronic-inflammation-repair]]。预防的束：被剪的毛发与含醇的皮肤准备和适时的抗生素（在切皮前的分钟内，按药物的半衰期与失血再剂）与体温与糖和伤口的保护[[microbiology/antimicrobials]]、[[surgery/perioperative-care]]、[[clinical-skills/patient-safety]]。分类：表浅的与深部的与器官的腔隙[[pathology/acute-inflammation]]；表现是天的发热与伤口的改变和疼痛的加重，而在肠的手术后要想到漏[[surgery/acute-abdomen]]。处理：开口引流与培养与针对原因的抗生素，并把严重的软组织感染作为外科的急症[[microbiology/laboratory-diagnosis]]、[[infectious-diseases/fever-sepsis]]、[[surgery/trauma]]。**
:::

## 愈合的一面

::: definition 伤口的愈合与它的失败 {#def-healing}
**愈合是重叠的阶段：止血（血小板与纤维）与炎症（中性粒与巨噬细胞的细胞因子）与增殖（成纤维细胞与新生血管和角化细胞的迁移）与重塑（胶原的交叉连接与强度的逐渐恢复）[[pathology/acute-inflammation]]、[[pathology/chronic-inflammation-repair]]、[[physiology/homeostasis-body-fluids]]。一期愈合是被对合的边缘；二期是边缘被留下并靠肉芽来填充；植皮与瓣用于大的缺损[[surgery/wounds-surgical-infection]]。失败的原因可以按层面来记：局部的（感染与血肿和异物与张力与灌注）与全身的（年龄与糖尿病和营养与缺氧和药物如激素与化疗）[[endocrine/diabetes]]、[[gastrointestinal/clinical-nutrition]]、[[pharmacology/adverse-reactions]]、[[geriatrics-palliative/ageing-frailty]]。慢性的伤口（静脉的与动脉的和压力性溃疡与糖尿病足）需要按原因的治疗与湿性愈合环境和渗出的管理[[cardiovascular/vascular-disease]]、[[surgery/vascular-urological-surgery]]、[[endocrine/diabetes-complications]]、[[geriatrics-palliative/falls]]。裂开与疝是严重的失败[[surgery/gastrointestinal-surgery]]。**
:::

::: definition 咬、蜇、烧与污染 {#def-zoonotic}
**动物咬伤会把口咽菌群带到深部；手的咬伤尤其危险，因为关节与腱鞘就在表面。处理是充分的冲洗、评估深部结构、覆盖厌氧菌的抗生素，以及破伤风与狂犬病风险的评估[[microbiology/bacteria]]、[[immunology/vaccines-immunotherapy]]、[[infectious-diseases/tropical-infections]]、[[surgery/orthopaedics]]。刺伤（如鞋钉）会把感染带到骨与腱[[microbiology/laboratory-diagnosis]]、[[surgery/orthopaedics]]。烧伤按深度（部分层与全层）与面积（体表的百分比）评估；治疗包括按面积的液体复苏、警惕吸入性损伤的气道、以及痂的处理与适时的覆盖[[emergency-critical-care/airway-ventilation]]、[[emergency-critical-care/shock-fluids]]、[[microbiology/infection-control]]。破伤风：按伤口的类型与免疫史决定疫苗与免疫球蛋白[[immunology/vaccines-immunotherapy]]、[[public-health/vaccination-programmes]]、[[pathology/environmental-pathology]]。所有污染的伤口都要记录时间与冲洗和剂量[[clinical-skills/records-handover]]。**
:::

::: example 第6天的渗出 {#ex-pop}
因穿孔的乙状结肠炎做急诊开腹后第6天，伤口被一期缝合：粉棕色的液体湿透敷料，患者只是觉得累，体温37.8，钠131，白细胞16，C反应蛋白仍为240。
::: solution
**肠手术之后出现粉棕色的渗出，意味着肠的内容物，直到被证明别的：可能是深部感染伴筋膜裂开，也可能是肠与皮肤之间的通道[[#def-ssi]]、[[#def-healing]]、[[surgery/acute-abdomen]]。这不是一个换药能解决的问题：需要外科评估、CT寻找积聚与漏、培养、液体复苏与抗生素[[clinical-skills/medical-imaging]]、[[emergency-critical-care/shock-fluids]]、[[microbiology/laboratory-diagnosis]]。若筋膜已裂开而肠在膨出，这是需要紧急处理的急症[[surgery/gastrointestinal-surgery]]、[[surgery/perioperative-care]]。同时纠正影响愈合的因素：营养、血糖与缺氧，并向患者说明伤口可能需要较长时间的换药[[gastrointestinal/clinical-nutrition]]、[[endocrine/diabetes]]、[[clinical-skills/communication]]。**
:::
:::

::: example 只是一个胼胝的糖尿病足 {#ex-foot}
一位58岁的第二型糖尿病患者主诉在第一跖骨头下的一个鸡眼，恶臭，可探到骨，发热，血糖19，C反应蛋白180；他走了六周因为不痛。
::: solution
**可探到骨的溃疡伴发热与炎症指标升高，高度提示骨髓炎；感觉神经病变解释了为什么六周的行走并不痛[[endocrine/diabetes-complications]]、[[nervous-system/sensory-systems]]、[[pathology/acute-inflammation]]。评估要用深部组织的培养而不是表面的拭子；影像包括X线、MRI与血管的评估；同时查血糖与肾功能[[microbiology/laboratory-diagnosis]]、[[clinical-skills/medical-imaging]]、[[cardiovascular/vascular-disease]]、[[renal/acute-kidney-injury]]。治疗是外科清除与引流、按骨感染的长期抗生素、减压与必要时的血管重建，以及血糖的控制[[microbiology/antimicrobials]]、[[surgery/orthopaedics]]、[[surgery/vascular-urological-surgery]]、[[endocrine/diabetes]]。预防的教训：足病的团队与鞋具和定期检查能预防反复的溃疡与截肢[[public-health/prevention-promotion]]、[[clinical-skills/communication]]、[[geriatrics-palliative/falls]]。**
:::
:::

::: example 破了两次的手套 {#ex-glove}
在为一处猫咬伤的腱鞘冲洗后十二小时，同一位外科医生用同一双手套（外面再加一层）做了拇指尖的切割伤手术；到第3天患者的指尖搏动性疼痛，而外科医生记不起那次手套的破损。
::: solution
**猫咬伤会把口腔菌群带到深部，腱鞘感染本身并发症率高；如果手套被污染且破损未被发现，第二次手术会把微生物接种到新的伤口[[#def-zoonotic]]、[[microbiology/bacteria]]、[[surgery/orthopaedics]]。对患者：尽早再评估、切开引流与冲洗，并用覆盖口腔菌的抗生素[[microbiology/laboratory-diagnosis]]、[[microbiology/antimicrobials]]、[[infectious-diseases/healthcare-infections]]。对系统：如实告知并记录，同时按事件报告的程序上报手套破损与疑似的感染聚集[[clinical-skills/patient-safety]]、[[medical-ethics-law/professionalism-regulation]]、[[clinical-skills/records-handover]]。教训：污染操作之后必须换手套，双层手套不能替代更换，而破损要当时记录[[microbiology/infection-control]]、[[surgery/perioperative-care]]。**
:::
:::

::: example 补片的门诊信箱 {#ex-mesh}
在开放的腹股沟补片修补五年后，一位男性来信：烧灼样腹股沟的痛在骑车时加重，疤痕旁新发的膨出，以及一个团体的说法，说补片在毒害他。
::: solution
**三种可能需要分开：神经性（髂腹股沟或生殖股神经的损伤或被补片包裹，表现为烧灼痛并沿分布区）；结构性（复发或膨出或补片收缩）；以及无关的原因（腰椎与髋关节的病变）[[surgery/gastrointestinal-surgery]]、[[musculoskeletal/back-pain]]、[[nervous-system/sensory-systems]]。评估靠体检定位、动态超声观察咳嗽时的膨出，必要时用诊断性的局部封闭来确认神经的来源[[clinical-skills/physical-examination]]、[[clinical-skills/medical-imaging]]。沟通：承认疼痛真实存在，说明补片已知的并发症与其概率，既不过度归咎也不否认[[clinical-skills/communication]]、[[medical-ethics-law/consent-capacity]]。治疗按机制：神经性疼痛的药物与注射和物理治疗；在精心选择者中手术切除补片或松解神经[[pharmacology/adverse-reactions]]、[[geriatrics-palliative/symptom-control]]、[[public-health/health-systems-economics]]。**
:::
:::

## 通向何处

微生物与耐药在[[microbiology/bacteria]]与[[microbiology/antimicrobials]]；感染的控制在[[microbiology/infection-control]]与[[infectious-diseases/healthcare-infections]]；炎症与修复的病理在[[pathology/acute-inflammation]]与[[pathology/chronic-inflammation-repair]]；围手术期的束在[[surgery/perioperative-care]]；休克的软组织在[[infectious-diseases/fever-sepsis]]；血管与淋巴的足在[[surgery/vascular-urological-surgery]]；糖尿病的足在[[endocrine/diabetes-complications]]；而伤口的护理与资源在[[geriatrics-palliative/symptom-control]]与[[public-health/health-systems-economics]]。

::: history
外科感染的历史是从病房到微生物：产褥热的病因与洗手使感染变成可预防的[[microbiology/infection-control]]、[[public-health/communicable-disease-control]]；抗菌与无菌技术与手套把手术变成这些可能[[surgery/perioperative-care]]；抗生素带来了预防的用法，也带来了耐药与艰难梭菌的感染，促使被管理的项目[[microbiology/antimicrobials]]、[[infectious-diseases/stewardship-outbreaks]]；伤口的治疗从干燥的敷料到湿性愈合与负压的装置[[pathology/chronic-inflammation-repair]]；而质量的指标（手术部位感染率与并发症的审计）把结果变成可比较的数据[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]。
:::

::: summary
- 手术部位的感染由微生物的剂量、组织的状态与宿主的防御共同决定；预防是一个束（皮肤、适时的抗生素、体温与糖与技术）。
- 愈合有四期；失败要按局部与全身的原因来查，而慢性的伤口要治疗其背后的血管、压力或代谢的原因。
- 按天读伤口：第2天的发热多为生理，第5-7天的疼痛与渗出是感染，两周以上的渗出与肠的内容提示筋膜与肠的通道[[#ex-pop]]。
- 坏死性的软组织感染需要立即的探查；影像不得延误这把刀[[#def-ssi]]。
- 咬伤、刺伤与烧伤各有一套规则：冲洗与覆盖、破伤风与狂犬病的评估，以及面积的液体与气道的观察。
:::

## 练习

::: exercise 开出预防的抗生素 {level=1}
在MRSA流行的病房中做择期的开放腹股沟疝补片修补：预防用还是不用、药物、时机、再剂与疗程，并说明理由。
::: solution
**要用：补片是异物，一旦感染会造成深部的与长期的后果[[#def-ssi]]、[[surgery/gastrointestinal-surgery]]。药物按本地指南：以第一二代头孢菌素为主，在MRSA流行的病房中加万古霉素并配合监测[[microbiology/antimicrobials]]、[[infectious-diseases/stewardship-outbreaks]]。时机是关键：在切皮前给药，使组织浓度在细菌被接种时已达峰值；诱导时给药最实用[[surgery/perioperative-care]]。再剂：手术超过药物的半衰期或失血大时重复[[emergency-critical-care/shock-fluids]]。疗程：单剂或至多24小时；延长不减少感染，反而增加耐药与艰难梭菌[[microbiology/microbiota]]、[[clinical-skills/patient-safety]]。**
:::
:::

::: exercise 给发热的伤口分类 {level=2}
阑尾切除后第4天：伤口边缘的压痛与3厘米明显的红，体温38.1，C反应蛋白140但在下降，患者一般情况好。然后是第5天的变化：(a) 2厘米有波动感的肿胀；(b) 蔓延的红伴水泡。
::: solution
**第4天是表浅手术部位感染的早期：伤口边缘的压痛与局限的红。患者状况良好而CRP在下降，处理是观察与伤口的局部照护，并在有渗出时打开缝线[[#def-ssi]]、[[microbiology/laboratory-diagnosis]]。(a) 波动感的肿胀说明有积聚：打开伤口、引流并按需填塞，脓液送培养；源头被引流后常不需要抗生素[[pathology/acute-inflammation]]、[[surgery/perioperative-care]]。(b) 蔓延的红、水泡、疼痛与体征不成比例和全身毒性提示坏死性软组织感染：立即外科探查，同时给广谱抗生素与循环支持[[infectious-diseases/fever-sepsis]]、[[surgery/trauma]]、[[microbiology/antimicrobials]]。**
:::
:::

::: exercise 为咬伤开药 {level=2}
一处4小时前横跨手腕的狗咬伤，健康成人，狗已接种且可查，破伤风史不确定。覆盖：伤口处理、抗生素的选择与疗程、破伤风、狂犬病的决定，以及是否缝合。
::: solution
**伤口处理是核心：大量冲洗、探查手腕的关节与腱与神经、去除失活组织，并在怀疑深部损伤时影像[[#def-zoonotic]]、[[surgery/orthopaedics]]、[[clinical-skills/medical-imaging]]。抗生素：手与关节附近的咬伤需要预防性覆盖，选择能覆盖口腔菌与厌氧菌的药物（阿莫西林克拉维酸，青霉素过敏时用替代）[[microbiology/antimicrobials]]、[[microbiology/bacteria]]。破伤风：史不确定时接种疫苗，污染伤口再加免疫球蛋白[[immunology/vaccines-immunotherapy]]、[[public-health/vaccination-programmes]]。狂犬病：可观察的健康家犬通常不需要暴露后免疫，但要按本地的流行与公共卫生的评估决定[[infectious-diseases/tropical-infections]]、[[public-health/communicable-disease-control]]。缝合：面部伤口可在冲洗后一期缝合，其余部位常延迟关闭以保证引流[[surgery/wounds-surgical-infection]]、[[clinical-skills/records-handover]]。**
:::
:::

::: exercise 构建压力性溃疡的预防项目 {level=3}
你们单位的院内与社区的压力性溃疡率是国家的异常值。设计这个项目：风险的评估、支持的表面、营养、组织活力的人力、数据的诚实与这些不可事件。
::: solution
**风险评估：用经验证的量表在入院与转科时评分，并把每个分值绑定到具体的行动，而不只是贴标签[[geriatrics-palliative/ageing-frailty]]、[[clinical-skills/patient-safety]]。支撑与体位：减压的床垫、定时的翻身、足跟的保护，并警惕器械造成的压力（面罩与导管）[[emergency-critical-care/critical-care]]、[[surgery/perioperative-care]]。营养：筛查风险、设定蛋白目标并补充，同时纠正贫血与微量营养素[[gastrointestinal/clinical-nutrition]]、[[blood/anaemia]]。人力：组织活力团队与分级培训，并建立医院与社区之间的连续路径[[public-health/health-systems-economics]]。数据的诚实：统一分期定义与归因规则，因为异常值常常来自记录方式的差异[[clinical-skills/records-handover]]、[[public-health/screening]]。事件处理：把院内发生的溃疡作为质量指标复盘，并向患者与家属如实说明[[clinical-skills/patient-safety]]、[[medical-ethics-law/professionalism-regulation]]。**
:::
:::

::: exercise 给积聚分级并引流 {level=2}
开腹后第8天：CT显示4厘米的膈下积聚与2厘米的盆腔积聚；患者有脓毒症但血压对液体有反应。计划接下来的六小时：谁做、在哪做、用什么，以及源头控制何时才算完成。
::: solution
**六小时之内：留取培养后给抗生素、按脓毒症的路径复苏液体并监测，同时请介入放射经皮引流4厘米的膈下积聚；若介入不可行或患者恶化，则由外科处理[[#def-ssi]]、[[emergency-critical-care/shock-fluids]]、[[clinical-skills/medical-imaging]]、[[infectious-diseases/fever-sepsis]]。2厘米的盆腔积常在主要病灶被引流后自行消退，因此是否引流取决于通道的可行性与风险的权衡[[surgery/perioperative-care]]。源头控制完成的定义：引流量减少、炎症指标下降、临床趋势改善，以及复查影像的证据；若引流失败要再次介入或手术，并寻找漏的来源[[microbiology/laboratory-diagnosis]]、[[gastrointestinal/bowel-disease]]。记录时间、决定与计划的复评，并向患者与家属说明[[clinical-skills/records-handover]]、[[clinical-skills/communication]]。**
:::
:::

::: exercise 第2天的发热 {level=1}
开放结肠切除后第2天38.3度，无其他症状，NEWS 3分，伤口清洁，肺清，尿清，管道都好。教科书说肺，我们要检查吗？用生理来回答。
::: solution
**术后的细胞因子会在早期造成发热与心动过速，这是炎症的生理而不是感染[[#def-healing]]、[[pathology/acute-inflammation]]。检查按线索而不是套餐：在有风险者中查血气与培养，而在无症状时常规胸片与痰和尿的检查不增加价值[[clinical-skills/laboratory-tests]]、[[microbiology/laboratory-diagnosis]]。更重要的是再次查体：管道的位置、伤口的外观与腿的体征[[surgery/wounds-surgical-infection]]、[[blood/thrombosis-anticoagulation]]，并按恶化的评分决定升级[[emergency-critical-care/acute-assessment]]。把发热放在时钟上理解：第2天多为生理，第5天之后要主动找原因[[#def-ssi]]、[[clinical-skills/clinical-reasoning]]。**
:::

::: exercise 为腹的爆裂提供咨询 {level=2}
一位80岁衰弱的人在第5天在床边发生肠的脱出：大量血清血性的渗出，然后是一段肠在伤口处。走过分钟、手术的决定，以及与家属的对话。
::: solution
**分钟：不要把肠推回，用温的生理盐水浸湿的敷料覆盖并托住腹部，让患者平卧，呼叫外科与麻醉与手术室，同时给液体与镇痛并留取血标本[[#def-healing]]、[[surgery/acute-abdomen]]、[[emergency-critical-care/acute-assessment]]。手术的决定：急诊的筋膜关闭（减张的缝合），或在污染与肠水肿时计划的开放腹部管理（负压装置与定时的复评），并按需要重症的床位[[surgery/gastrointestinal-surgery]]、[[emergency-critical-care/critical-care]]。与家属：说明发生了什么与为什么（愈合的失败）、下一步与其风险、长期的结果（疝与再次手术），并在衰弱者中讨论目标[[clinical-skills/communication]]、[[medical-ethics-law/end-of-life-ethics]]、[[clinical-skills/records-handover]]。**
:::

::: exercise 设计肛周的脓毒症规则 {level=3}
你们单位的坐骨直肠窝脓肿复发与挂线门诊的不来诊是异常值。建立路径：引流的标准、关于瘘的预防性谈话、挂线门诊的设计，以及克罗恩的路径。
::: solution
**引流标准：深部的坐骨直肠窝积聚需要在麻醉下引流并记录位置与引流量，由有经验者处理复杂的情况；表浅的脓在局部麻醉下切开即可[[#def-ssi]]、[[surgery/gastrointestinal-surgery]]、[[pathology/acute-inflammation]]。瘘的预防性谈话：在引流时说明日后形成瘘与反复的可能，以及失禁的风险与随访的安排[[clinical-skills/communication]]、[[gastrointestinal/bowel-disease]]。门诊设计：明确的入口、提醒与可及的时间段，考虑到照护与交通的负担，并为不来的患者建立再联系的路径[[public-health/health-systems-economics]]、[[public-health/determinants-inequalities]]。克罗恩路径：早期的评估（肠镜与影像）与多学科团队，用生物制剂与保括约肌的手术策略[[gastrointestinal/bowel-disease]]、[[immunology/autoimmunity]]、[[pharmacology/drug-development-prescribing]]。**
