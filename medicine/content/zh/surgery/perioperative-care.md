手术是一种有意造成的损伤。外科医生切开、牵拉并切除组织，目的是让患者最终获益；但机体对这种损伤的反应与对意外创伤的反应相同：应激激素激增、炎症、体液转移，以及一段储备能力下降的时期。**围手术期管理**是指从考虑手术那一刻起直至完全康复期间对外科患者的医疗照护。它的目标说起来很简单：让患者以尽可能好的状态进入手术室，在手术中不受可避免的伤害，并在术后迅速而安全地康复。

术后的大多数死亡和并发症并不是由手术技术失误引起的。它们来自患者的心、肺、肾和脑在手术应激下的不堪重负，以及感染、血栓和谵妄等常常可以预测、有时可以预防的并发症。正因为如此，每一位照护外科患者的医生都需要掌握本章的内容。

本章介绍手术应激反应、术前评估与优化、药物与禁食、液体治疗、手术本身、按出现顺序排列的术后并发症，以及把这一切联系起来的安全体系和加速康复路径。全章以英国指南为主（NICE 和围手术期照护中心 CPOC），内容截至2026年；对具体患者而言，当地方案始终优先。

## 机体对手术的反应

组织受伤时，下丘脑、交感神经系统和免疫系统都会作出反应。这种反应在进化中形成，帮助受伤的动物在愈合之前存活下来：维持血压、潴留盐和水、向血液释放能量物质并对抗感染。对一位已经在接受补液、营养支持和抗生素的患者来说，这种反应的大部分已不再有用，其中一部分甚至有害。

::: definition 手术应激反应 {#def-stress-response}
**手术应激反应**是组织损伤之后发生的一系列激素、代谢和炎症变化。其主要特征是：

- **激素：**皮质醇、儿茶酚胺、胰高血糖素、抗利尿激素（ADH）和醛固酮升高，并出现相对的胰岛素抵抗。
- **代谢：**血糖升高，肌肉蛋白和脂肪分解以提供能量，出现负氮平衡。
- **盐和水：**肾脏潴留钠和水，因此即使液体平衡充足，术后第一天左右尿量也会减少。
- **炎症：**细胞因子（尤其是白细胞介素-6）释放，引起发热、白细胞计数升高和C反应蛋白（CRP）升高，CRP 约在第二或第三天达到峰值。

反应的强度大致与损伤的大小成正比：开放手术大于腹腔镜手术，长时间手术大于短时间手术。
:::

由此得出两点推论。术后第一天尿量偏少和轻度发热常常是正常反应的一部分，因此要结合整体情况来判断。许多现代措施，如微创手术、区域麻醉、缩短禁食时间和早期进食，其作用部分正是来自减轻这一反应。激素变化背后的生理学见[[physiology/hormones]]和[[physiology/integrative-physiology]]。

## 术前风险评估

手术的风险取决于三件事：患者、手术和紧急程度。一位健康的30岁患者接受疝修补术，风险非常低。一位85岁、患心力衰竭的患者因肠穿孔接受急诊剖腹手术，风险非常高。大多数患者介于两者之间，术前评估的任务就是准确地确定他们的位置。

::: theorem 手术风险由三部分构成 {#thm-risk}
术后死亡或严重并发症的风险随以下因素而升高：（1）**患者的生理储备**（年龄、衰弱、心肺疾病、肾功能、营养状况）；（2）**手术的规模**（时间、失血量、打开的体腔、切除的器官）；（3）**紧急程度**（对一位未经准备、常伴脓毒症或脱水的患者施行急诊手术，其风险是同一手术择期施行时的数倍）。三者是相乘而不是相加的关系：衰弱的患者可以很好地耐受一次小的择期操作，却可能无法耐受一次大的急诊手术。
:::

::: proof
手术会带来一段氧需求增加的时期：应激反应提高代谢率，组织还必须愈合。心肺储备良好的患者通过增加心输出量和通气量来满足这一需求。储备差的患者做不到，于是组织相对缺氧，原本勉强代偿的器官（衰竭的心脏、功能下降的肾脏、易发生谵妄的大脑）失代偿。更大的手术增加需求；急诊手术还叠加了脓毒症、脱水和电解质紊乱，并且没有时间去纠正它们。因此，风险由需求与储备之间的差距决定，差距两侧的因素都很重要。
:::

### 术前评估

::: definition 术前评估与优化 {#def-preassessment}
**术前评估**是一次结构化的审查，通常在择期手术前数周于护士或麻醉医生主导的门诊进行，有四个目的：

1. **识别风险：**通过病史、体格检查和有针对性的检查发现增加风险的情况。
2. **优化：**在可用的时间内治疗能够改善的问题，如贫血、糖尿病控制不佳、吸烟、营养不良或未控制的高血压。
3. **计划：**确定麻醉方式、术后照护的级别（普通病房、强化照护单元或重症监护）、药物调整和出院需求。
4. **告知：**为患者提供共同决策所需的信息，并让他们为将要发生的事情做好准备。
:::

**病史**是最有用的工具。关键问题包括心肺疾病、既往麻醉史及其中出现的问题、麻醉问题的家族史（如恶性高热或使用琥珀胆碱后长时间瘫痪）、出血倾向、药物和过敏、饮酒和吸烟，以及**功能储备**。功能储备常通过询问患者能否不停歇地爬两层楼梯或快步上坡来估计，这大约相当于4个代谢当量（METs）。医生的非正式印象并不精确；杜克活动状态指数（Duke Activity Status Index）等结构化问卷表现更好，对于大手术，一些中心使用**心肺运动试验（CPET）**，无氧阈偏低提示储备有限。

评分系统可以概括风险。ASA 分级描述总体健康状况；修订心脏风险指数（Lee 指数）统计六项心脏并发症的预测因素（高危手术、缺血性心脏病、心力衰竭、脑血管疾病、使用胰岛素的糖尿病，以及肌酐高于177 µmol/L，即2.0 mg/dL）；临床衰弱量表对衰弱分级；NELA 计算器等工具估计急诊剖腹手术后的死亡率。

::: definition ASA 身体状况分级 {#def-asa}
**美国麻醉医师协会（ASA）身体状况分级**对患者的总体健康状况进行分级：

- **ASA 1** — 正常健康的患者。
- **ASA 2** — 轻度系统性疾病（如控制良好的高血压、目前吸烟、妊娠）。
- **ASA 3** — 严重系统性疾病（如控制不佳的糖尿病、慢阻肺、病态肥胖、病情稳定的透析患者）。
- **ASA 4** — 持续威胁生命的严重系统性疾病（如近期心肌梗死、严重心力衰竭）。
- **ASA 5** — 不手术就预计无法存活的濒死患者。
- **ASA 6** — 已宣布脑死亡、正在摘取器官用于捐献的患者。

后缀 **E** 表示急诊手术（如 ASA 3E）。
:::

**检查**的选择取决于其结果能否改变处理。NICE 指南 NG45（择期手术的常规术前检查）把检查与 ASA 分级和手术规模联系起来：接受小手术的健康年轻人通常不需要任何检查，而患心血管疾病、接受大手术的患者需要全血细胞计数、肾功能和心电图。糖尿病患者要查 HbA1c，可能妊娠的女性应进行妊娠试验。不必要的检查会推迟手术并产生假阳性。

### 优化

择期手术前的几周是一个机会。**预康复**是指通过运动、营养和心理准备在术前改善身体状况。具体目标包括：

- **贫血**，通常由缺铁引起，会增加输血和并发症；用铁剂治疗，如果数周内就要手术，常静脉补铁。
- **糖尿病。**英国指南（CPOC）建议，在可以安全等待的情况下，HbA1c 高于69 mmol/mol（8.5%）的患者在择期手术前转诊进行优化。
- **吸烟和饮酒。**戒烟在任何时候都能减少伤口和肺部并发症，越早戒效果越好；要识别大量饮酒，以便预见戒断。
- **营养和衰弱。**营养不良的患者（用 MUST 等工具识别）可从营养支持中获益，衰弱的老年患者可从老年综合评估中获益。

### 知情同意

手术知情同意是一个讨论的过程，而不是一个签名。在英国，最高法院2015年对 *Montgomery v Lanarkshire Health Board* 一案的判决确立了这样的原则：医生必须尽合理的注意，确保患者知晓任何**重大风险**——即处于患者位置的理性人会认为重要的风险，或医生知道或应当知道这位患者本人会认为重要的风险。讨论内容包括诊断、手术、其获益和风险、包括不治疗在内的其他选择，以及康复过程。决策能力、知情同意和法律框架见[[medical-ethics-law/consent-capacity]]。

::: example 应当推迟手术的患者 {#ex-defer-optimise}
一位62岁女性因反复胆绞痛预约择期腹腔镜胆囊切除术。术前评估时，她的 BMI 为42，每天吸烟25支，患2型糖尿病，HbA1c 为74 mmol/mol，并提到最近上坡时出现胸闷。手术应当在下周进行吗？
::: solution
**第一步：权衡紧急程度。**反复胆绞痛令人痛苦、影响生活，但短期内通常并不危险。只要她知道出现哪些症状（发热、黄疸、持续疼痛）需要紧急返院，就有时间为她做准备。

**第二步：找出最危险的问题。**新出现的劳力性胸闷可能是心绞痛。这对她生命的威胁大于胆结石，在任何择期手术之前都需要由全科医生或心脏科医生评估。如果她需要放置冠状动脉支架，随后的抗血小板治疗本身就会影响手术时机。

**第三步：优化可以改善的方面。**她的 HbA1c 高于69 mmol/mol，应转诊以改善糖尿病控制。应为她提供戒烟支持。体重增加了麻醉和伤口风险；适度减重有帮助，但通常不会仅为减重而推迟手术。

**第四步：与她商定计划。**解释推迟手术是治疗的一部分，设定一个复查日期和具体目标（完成心脏评估、HbA1c 下降、减少或停止吸烟），并书面告知何时应紧急就医。如果她在此期间发生急性胆囊炎，将按急诊路径处理，并利用已收集的信息。
:::
:::

## 药物与禁食

大多数常规用药在围手术期继续使用。少数需要停用、调整或替换，少数停用反而危险。决定取决于药物、手术和患者，应在术前评估时清楚地写下来。

| 药物类别 | 常规做法（遵循当地指南） | 原因 |
|---|---|---|
| 华法林 | 术前约5天停用；检查 INR；仅对血栓风险高者（如某些机械心脏瓣膜）用肝素桥接 | 出血风险 |
| 直接口服抗凝药 | 术前1–3天或更早停用，取决于药物、肾功能和手术的出血风险 | 出血风险；半衰期短，无需桥接 |
| 抗血小板药 | 阿司匹林常继续使用；氯吡格雷等通常术前约7天停用，但近期放置冠状动脉支架者例外，此时必须请心脏科医生参与 | 权衡出血与支架内血栓 |
| ACE 抑制剂和血管紧张素受体阻滞剂 | 常在手术当天早晨停用 | 可在麻醉下引起低血压 |
| β受体阻滞剂和他汀类 | 继续使用 | 停药会引起反跳性心动过速和心脏事件 |
| SGLT2 抑制剂（如达格列净） | 手术前一天和手术当天停用（英国多学会指南，2025年） | 正常血糖性糖尿病酮症酸中毒的风险 |
| GLP-1 受体激动剂 | 通常继续使用，同时进行评估并采取降低误吸风险的技术（英国多学会指南，2025年） | 胃排空减慢 |
| 二甲双胍 | 除非会错过不止一餐，或预计使用造影剂或发生肾损伤，否则通常继续使用 | 少量乳酸酸中毒风险 |
| 胰岛素 | 调整剂量而不停用；预计禁食时间长时使用可变速率胰岛素输注 | 低血糖和酮症酸中毒 |
| 长期糖皮质激素 | 继续使用，术中额外补充激素 | 肾上腺危象的风险 |
| 复方口服避孕药和激素替代治疗 | 考虑在大手术前4周停用，或给予 VTE 预防 | 静脉血栓栓塞 |

麻醉前**禁食**可以降低**肺误吸**的风险，即在气道保护性反射消失时胃内容物进入肺部。传统的"午夜后禁食禁水"让患者口渴、脱水并出现胰岛素抵抗，却并没有让他们更安全。目前英国和欧洲对成人择期手术的指南是：

- **固体食物**（包括牛奶和食物）可进食至麻醉前**6小时**；
- **清饮料**（水、清澈的果汁饮料、不加奶的茶或咖啡）可饮用至麻醉前**2小时**，许多医院现在鼓励患者在被送往手术室之前小口饮水；
- 许多加速康复路径会在术前数小时给予**碳水化合物饮料**（糖尿病患者需谨慎）。

儿童一般可饮用清饮料至麻醉前1小时。胃排空延迟的患者（肠梗阻、糖尿病胃轻瘫、妊娠晚期、近期使用阿片类药物、近期创伤）无论禁食多久都仍有风险，麻醉医生会采用快速顺序诱导来应对（[[surgery/anaesthesia-pain]]）。

::: quiz
一位没有胃排空延迟的成人预定于14:00接受择期手术。哪一项指示符合目前的禁食指南？
- [ ] 午夜后不吃不喝
- [x] 08:00 前吃清淡的早餐，然后可喝清饮料至12:00
- [ ] 可喝清饮料至08:00，此后什么都不吃不喝
- [ ] 在被叫去手术室之前任何时候都可以吃喝
::: solution
固体食物可进食至麻醉前6小时（08:00），清饮料可饮用至麻醉前2小时（12:00）。从午夜开始禁食会增加脱水、口渴和胰岛素抵抗，却不能降低误吸风险。一直进食到手术前则会使胃内残留固体食物。
:::
:::

## 液体治疗

在手术期间和术后，许多患者不能正常饮水，静脉补液的处方就成了医生的工作。补液太少会导致低血容量、低血压和肾损伤。补液太多则导致组织和肠道水肿、胃肠功能恢复减慢、伤口愈合受损和呼吸问题。NICE 指南 CG174（住院成人的静脉液体治疗）把每一份处方都围绕 **5R** 来组织：复苏（resuscitation）、常规维持（routine maintenance）、补充丢失（replacement）、再分布（redistribution）和再评估（reassessment）。

::: definition 常规维持液体需要量 {#def-fluids}
对于仅需静脉补液作常规维持的成人，NICE 建议每24小时的初始处方为：

- **水：**25–30 mL/kg/天；
- **钾、钠和氯：**每种约1 mmol/kg/天；
- **葡萄糖：**50–100 g/天，以限制饥饿性酮症（这并不能满足营养需要）。

对于年老或衰弱、有肾功能衰竭或心力衰竭、或营养不良的患者，考虑较少的液体量（如20–25 mL/kg/天）。持续丢失（呕吐、鼻胃管引流、造口排出、引流管丢失、发热）的**补充**要单独开具处方，并按丢失液体的量和成分匹配。
:::

::: example 维持补液处方 {#ex-fluid-calc}
一位体重70 kg 的男性在开放肠切除术后第一天禁食。他没有其他途径的液体丢失，肾功能和心功能正常。他在24小时内的常规维持需要量是多少？
::: solution
**水：**$25$ 至 $30\ \text{mL/kg/天} \times 70\ \text{kg} = 1750$ 至 $2100$ mL。

**钾：**$1\ \text{mmol/kg/天} \times 70\ \text{kg} \approx 70$ mmol；钠和氯也各约70 mmol。

**葡萄糖：**50–100 g。

一种满足方式是给予约2升0.18%氯化钠加4%葡萄糖溶液，并根据测得的血钾加入钾。这大约含有60 mmol 钠和80 g 葡萄糖。具体使用哪种制剂取决于当地处方集。

**每天再评估：**体重、液体平衡、临床检查和血清电解质。低张液体可引起**低钠血症**，尤其是因为术后 ADH 分泌增多（见[[#def-stress-response]]）。如果他开始呕吐或鼻胃管引流量大，就要额外补充这些丢失，通常使用含钠液体，如哈特曼液（Hartmann's solution）或加钾的0.9%氯化钠。
:::
:::

低血容量患者的复苏补液则不同：在15分钟内输注500 mL 平衡晶体液，然后再评估，见[[emergency-critical-care/shock-fluids]]。尿量是一个参考指标；常用的目标是至少 **0.5 mL/kg/h**，尿量低于此值持续6小时即符合 KDIGO 1期急性肾损伤的尿量标准（[[renal/acute-kidney-injury]]）。

## 手术室内

麻醉本身是[[surgery/anaesthesia-pain]]的主题。这里重点讨论术中照护中能够预防术后并发症的部分。

::: definition 安全术中照护的核心要素 {#def-intraop}
- **抗生素预防**（有指征时），在切皮前静脉给予（通常在切皮前60分钟内；有些指南允许至120分钟），使细菌进入伤口时组织浓度处于高水平；手术时间长或失血量大时追加剂量（[[surgery/wounds-surgical-infection]]）。
- **维持正常体温：**使核心体温保持在36.0 °C 或以上。NICE（CG65）把**意外围手术期低体温**定义为核心体温低于36.0 °C，并建议对手术时间超过30分钟或高危的患者进行主动保温。
- **仔细摆放体位并加衬垫**，以预防神经损伤、压力性损伤和眼部损伤。
- **目标适宜的液体和血液管理**，既避免容量不足也避免过多，并在合适时采用限制性输血阈值（[[blood/transfusion]]）。
- **预防静脉血栓栓塞**，包括术中使用机械方法。
- **世界卫生组织手术安全核查表**，在三个时间点执行：麻醉诱导前（签到）、切皮前（暂停核查）和患者离开手术室前（签出）。
:::

低体温值得特别重视，因为它常见、预防成本低而且有害。麻醉消除了寒战并引起血管扩张，热量从核心转移到外周，核心体温在第一小时内下降1–1.5 °C。轻度低体温会损害凝血（出血增多）、减少伤口的氧供（感染增多）、减慢药物代谢，并在苏醒时引起寒战，而寒战会增加耗氧量。

::: example 复苏室里体温过低的患者 {#ex-warmth}
一位71岁男性在接受了2小时的开放手术后被送到复苏室，他在寒战并且意识混乱。核心体温35.1 °C，伤口在渗血。预防性头孢唑林在130分钟前诱导时给予，此后没有追加。手术室的交接说"无特殊"。哪里出了问题？应该怎么做？
::: solution
**判断。**他发生了意外围手术期低体温（低于36.0 °C）。低体温很可能是其他三个表现的共同原因之一：渗血（寒冷损害凝血）、意识混乱（药物代谢减慢，加上高龄）和寒战（增加氧需求）。

**紧急处理。**用压力空气加温毯和加温液体主动复温，寒战期间给氧，并监测心律和血压（复温时血管扩张可使血压下降）。处理疼痛。检查伤口，区分随复温应会停止的弥漫性渗血与需要处理的手术出血点。检查血糖和电解质。复温后再评估意识混乱；谵妄在老年患者中常见，但不应想当然地认定。

**抗生素。**头孢唑林通常在约4小时后或大量失血后追加；应对照当地政策核实时间并记录。

**系统层面的教训。**保温应在诱导前就开始并贯穿全程。体温应成为标准交接内容的一部分，因为"无特殊"掩盖了一个可测量的问题。这正是围手术期正常体温审计应当捕捉的事件。
:::
:::

## 术后：按时间出现的并发症

术后并发症往往在特定的时间出现。了解通常的时间有助于医生在患者病情变化时想到可能的原因，但绝不能因此不去考虑危险的原因。

::: theorem 术后并发症遵循一个时钟 {#thm-clock}
每种常见并发症都有其典型的时间窗：

- **数小时内（第0天）：**出血、气道梗阻、阿片类药物引起的呼吸抑制、低血压、恶心呕吐、尿潴留。
- **第1–3天：**肺不张、早期肺炎、液体和电解质问题、急性肾损伤、谵妄，以及应激反应引起的正常炎症性发热。
- **第3–7天：**肺炎、尿路感染、静脉导管感染、**吻合口漏**和腹腔内积液、手术部位感染、术后肠麻痹。
- **第5天起并持续数周：**深静脉血栓形成和肺栓塞、艰难梭菌（*Clostridioides difficile*）感染、深部伤口感染。
- **数月至数年：**切口疝、粘连性肠梗阻、慢性疼痛。
:::

::: proof
这个时钟反映了背后的生物学。出血和麻醉药物的作用发生在这些药物和新鲜伤口仍然活跃的时候。肺不张在数小时内出现，因为全身麻醉、平卧、疼痛和阿片类药物都会减少肺容积。感染需要时间让细菌繁殖、让宿主反应变得可以察觉，因此大约在3天后才表现出来。肠吻合口在第3–5天左右最薄弱，此时伤口中胶原的分解快于新胶原的沉积（[[surgery/wounds-surgical-infection]]），所以吻合口漏通常在这时出现。静脉血栓在数天的制动和应激反应造成的高凝状态中逐渐形成，其风险在出院后仍持续数周。
:::

### 术后发热

**发热**（体温达到或超过38.0 °C）在术后很常见。术后48小时内，发热通常由组织损伤引起的炎症反应所致。此后出现的发热，或患者看起来病情不佳时，需要仔细寻找原因：检查胸部、伤口、置管部位、小腿和腹部；根据指征查尿液、血培养、炎症指标和胸部 X 线片；并考虑吻合口或积液是否为感染源。药物反应和输血反应是较少见的原因。

::: warning
**"只是肺不张"不是一个可以就此止步的诊断。**术后早期发热意味着肺不张这一旧说法缺乏证据支持，固守这一判断会延误严重问题的诊断。肠道手术后第4天出现发热、心率上升、尿量减少和腹痛加重的患者，在被证明不是之前应视为吻合口漏。生命体征的趋势，尤其是持续的心动过速，比术后第几天更重要。应尽早上报并考虑 CT 检查。
:::

### 其他常见问题

- **术后恶心呕吐**在未预防的患者中约占三分之一；危险因素和治疗见[[surgery/anaesthesia-pain]]。
- **尿潴留**常见于脊髓麻醉、盆腔和腹股沟手术后以及使用阿片类药物时；表现为下腹不适和尿量减少，用膀胱扫描确认。
- **术后肠麻痹**是协调的肠运动暂时丧失，引起腹胀、呕吐和不排气；阿片类药物、液体过多以及低钾或低镁会使其延长。
- 术后**急性肾损伤**通常由低血容量、低血压、脓毒症或肾毒性药物（NSAIDs、ACE 抑制剂、造影剂）引起。停用肾毒性药物和恢复灌注是首要措施（[[renal/acute-kidney-injury]]）。
- **谵妄**是注意力和认知的急性紊乱。它在大手术或急诊手术后的老年患者中很常见，并与较高的死亡率相关；预防措施见下文的髋部骨折例题（[[geriatrics-palliative/delirium-dementia-care]]）。

### 静脉血栓栓塞的预防

外科患者具备菲尔绍三联征（Virchow's triad）的全部三个要素：制动引起的血流淤滞、手术引起的内皮损伤，以及应激反应引起的高凝状态（[[blood/thrombosis-anticoagulation]]）。NICE 指南 NG89 建议在入院时评估每位患者的 VTE 风险和出血风险，并随病情变化重新评估。预防措施包括早期活动、机械方法（无禁忌时使用抗血栓弹力袜或间歇充气加压）和药物方法（通常为低分子量肝素）。腹部或盆腔恶性肿瘤大手术后，药物预防延长至约28天；髋、膝关节置换术后，根据所选方案延长数周。

::: example 老年女性的髋部骨折 {#ex-hip-prehab}
一位78岁女性在家中跌倒，发生股骨颈骨折。她服用呋塞米、雷米普利、阿司匹林和舍曲林，独自住在没有电梯的四楼，入院时认知筛查得分低于正常范围。她的围手术期照护应如何组织？
::: solution
**时机。**NICE 指南 CG124 建议在入院当天或次日手术。延迟会增加疼痛、谵妄、压力性损伤、肺炎和死亡率。内科问题由骨科老年医学、麻醉和外科团队同时进行优化，而不是一个接一个地进行。

**药物。**雷米普利通常在手术当天早晨停用。呋塞米根据她的容量状态决定暂停或继续。阿司匹林通常不会推迟髋部骨折手术。舍曲林继续使用，但应检查血钠，因为 SSRI 可引起低钠血症。

**预防谵妄。**她的认知得分低，提示风险高。措施包括定向、佩戴眼镜和助听器、充分镇痛（髂筋膜阻滞或股神经阻滞可减少阿片类药物需要量）、补充水分、肠道护理和早期活动。

**术后。**她应在术后次日之前在物理治疗师帮助下下床活动，接受 VTE 预防，并评估骨骼健康和跌倒风险。

**出院。**她住的楼没有电梯是一个大问题，因此作业治疗和社会照护的计划应从入院时就开始。
:::
:::

## 加速康复与安全体系

**加速康复外科（ERAS）**是一组循证措施，在整个路径中共同实施，以减轻应激反应、加快康复。这一理念由丹麦外科医生亨里克·克勒特（Henrik Kehlet）在20世纪90年代提出，他认为许多术后并发症来自不必要的常规做法，而不是手术本身。

::: definition 加速康复路径 {#def-eras}
**加速康复路径**包括：

- **术前：**提供信息并设定预期、预康复、避免长时间禁食、在合适时进行碳水化合物负荷、许多手术不常规进行肠道准备；
- **术中：**尽可能采用微创技术、使用短效麻醉药、区域麻醉、平衡的液体治疗、维持正常体温、避免常规放置引流管和鼻胃管；
- **术后：**节省阿片类药物的多模式镇痛、预防恶心呕吐、早期经口进食、早期活动、尽早拔除导尿管和各类管路，以及明确的出院标准。

获益并不来自某一个单独的要素，而来自各要素的组合，以及对执行情况的审计。
:::

::: definition 手术安全体系 {#def-safety-systems}
**手术安全体系**是让差错更不容易伤及患者的一系列常规做法。它们包括**世界卫生组织手术安全核查表**；英格兰的**有创操作国家安全标准（NatSSIPs）**，其中规定了核查表、手术部位标记、纱布和器械清点以及团队简报应如何进行；结构化的**交接**（如 SBAR：情况、背景、评估、建议）；**并发症与死亡病例讨论会**；国家审计项目，如国家急诊剖腹手术审计和国家髋部骨折数据库；以及职业和法律上的**坦诚义务**，即出现问题时必须对患者坦诚相告。
:::

核查表之所以有效，是因为它创造了让整个团队停下来开口说话的时刻：确认患者、手术和手术侧别、过敏、抗生素、预计失血量和气道方面的担忧。它还让团队中资历最浅的成员也有权提出疑虑。如果在大家继续干活的同时机械地念一遍，它几乎没有作用。

::: history
现代围手术期照护源于三次变革。19世纪40年代，麻醉使长时间的手术成为可能；19世纪60年代，约瑟夫·李斯特（Joseph Lister）基于路易·巴斯德（Louis Pasteur）的细菌学说创立的抗菌法，使患者能够在手术后存活。第三次变革来得晚得多：医生开始测量患者术后的结局。1997年，亨里克·克勒特（Henrik Kehlet）提出了术后康复的"多模式"方法，由此发展为加速康复运动。2008年，世界卫生组织推出手术安全核查表；2009年，亚历克斯·海恩斯（Alex Haynes）、阿图·葛文德（Atul Gawande）及其同事在《新英格兰医学杂志》（*New England Journal of Medicine*）上报告：在八个国家的八家医院引入核查表之后，住院死亡率从1.5%降至0.8%，严重并发症从11.0%降至7.0%。现在大多数国家都常规使用它。
:::

## 后续内容

麻醉与镇痛见[[surgery/anaesthesia-pain]]，伤口愈合与手术部位感染见[[surgery/wounds-surgical-infection]]，急诊外科患者见[[surgery/trauma]]和[[surgery/acute-abdomen]]。内科背景知识见[[emergency-critical-care/shock-fluids]]、[[blood/transfusion]]、[[geriatrics-palliative/ageing-frailty]]和[[clinical-skills/patient-safety]]。

::: summary
- 手术引发**应激反应**：皮质醇、儿茶酚胺和 ADH 升高，胰岛素抵抗，盐和水潴留以及炎症。术后早期的一些变化（尿量少、轻度发热、CRP 高）是其中的一部分。
- 手术风险取决于**患者的储备**、**手术的规模**和**紧急程度**，三者相乘。
- 术前评估识别风险、**优化**可以改善的方面（贫血、糖尿病、吸烟、营养、衰弱）、计划照护，并支持以**重大风险**为基础的知情同意讨论。
- 大多数药物继续使用；抗凝药、抗血小板药、SGLT2 抑制剂、ACE 抑制剂和糖尿病治疗需要具体的计划。糖皮质激素不能简单地停用。
- 禁食：成人择期麻醉前，**固体食物至6小时，清饮料至2小时**。
- 成人维持液体：约 **25–30 mL/kg/天的水，钠、钾和氯各1 mmol/kg/天，葡萄糖50–100 g/天**，丢失量另行补充，并经常再评估。
- 切皮前预防性抗生素、**维持正常体温（≥ 36.0 °C）**、体位摆放和**世界卫生组织核查表**可在手术室内预防可避免的伤害。
- 并发症遵循一个**时钟**：数小时内出血和气道问题，第1–3天肺部问题，第3–7天吻合口漏和感染，VTE 持续数周。生命体征的趋势比术后第几天更重要。
- 加速康复在整个路径中结合多项措施；安全体系通过团队合作和敢于发声来发挥作用。
:::

## 习题

::: exercise 健康状况分级 {level=1}
为下列每位患者确定 ASA 分级：(a) 一位接受膝关节镜检查的健康25岁患者；(b) 一位高血压控制良好的50岁患者；(c) 一位患慢阻肺、爬一层楼梯就气喘的68岁患者；(d) 一位患严重心力衰竭、静息时即气喘、接受急诊剖腹手术的75岁患者。
::: solution
(a) ASA 1：正常健康的患者。(b) ASA 2：轻度、控制良好的系统性疾病。(c) ASA 3：限制活动但并不持续威胁生命的严重系统性疾病。(d) ASA 4E：严重心力衰竭持续威胁生命，且手术为急诊。ASA 分级描述的是患者的健康状况，而不是某一具体手术的风险，因此在估计风险时总要与手术的规模和紧急程度结合起来。
:::
:::

::: exercise 维持水量 {level=1 check="1500"}
一位60 kg 的女性术后禁食，只需要常规维持补液。按25 mL/kg/天计算，她在24小时内需要多少毫升水？
::: hint
用每千克的量乘以她的体重。
:::
::: solution
$25\ \text{mL/kg/天} \times 60\ \text{kg} = 1500$ mL/24小时。若按 NICE 范围的上限（30 mL/kg/天）计算，则为1800 mL。她还需要钠、钾和氯各约60 mmol，以及50–100 g 葡萄糖。应每天再评估她的液体平衡和电解质。
:::
:::

::: exercise 尿量 {level=1 check="160"}
一位80 kg 的男性离开手术室已4小时。要在这4小时内达到0.5 mL/kg/h 的目标，最少需要多少毫升尿量？
::: solution
$0.5\ \text{mL/kg/h} \times 80\ \text{kg} = 40$ mL/h，$40 \times 4 = 160$ mL。尿量更少时应进行评估：检查导尿管是否堵塞（如果没有导尿管则做膀胱扫描），评估他的容量状态和血压，并审查用药。尿量持续6小时低于0.5 mL/kg/h 即符合 KDIGO 1期急性肾损伤的尿量标准，不过术后最初几小时尿量有所减少是应激反应的一部分。
:::
:::

::: exercise 手术当天早晨 {level=2}
一位66岁男性将接受择期髋关节置换术。他的用药有二甲双胍、达格列净、雷米普利、比索洛尔、阿托伐他汀、用于心房颤动的阿哌沙班，以及因风湿性多肌痛每天服用的泼尼松龙5 mg。对每种药物，说明通常的围手术期计划及其理由。（假设当地指南与本章原则一致。）
::: hint
想一想哪些药物继续使用会造成伤害（出血、低血压、酮症酸中毒），哪些药物停用会造成伤害（反跳效应、肾上腺危象）。
:::
::: solution
- **二甲双胍：**如果他不会错过一餐以上，通常继续使用；如果预计禁食时间更长、使用造影剂或发生肾损伤，则停用。
- **达格列净：**手术前一天和手术当天停用，因为 SGLT2 抑制剂在禁食和手术应激时可引起正常血糖性酮症酸中毒。待他恢复正常饮食后重新开始。
- **雷米普利：**常在手术当天早晨停用，以避免麻醉下低血压。
- **比索洛尔和阿托伐他汀：**继续使用；突然停用β受体阻滞剂可引起反跳性心动过速和心肌缺血。
- **阿哌沙班：**术前停用，对于肾功能正常、接受大手术的患者通常停用2天或更久，按当地方案执行。不需要肝素桥接。在出血风险允许时重新开始，期间给予 VTE 预防。
- **泼尼松龙：**继续使用，并在围手术期额外补充激素，因为长期使用激素会抑制肾上腺，停药有发生肾上腺危象的风险。
:::

::: exercise 第5天发热 {level=2}
一位59岁女性因直肠癌接受前切除术后第5天。她体温38.4 °C，心率118次/分，血压104/62 mmHg，过去4小时尿量20 mL/h。她体重70 kg。腹部压痛比昨天加重，CRP 从140升至290 mg/L。按优先顺序列出鉴别诊断，并概述紧急处理。
::: solution
**最可能且最危险的：吻合口漏**伴腹腔内脓毒症。时间（第5天）、心动过速加重、腹部压痛加重、CRP 上升和少尿（按她的体重，0.5 mL/kg/h = 35 mL/h，20 mL/h 低于此值）都符合。

**其他原因：**不伴吻合口漏的腹腔内积液、肺炎、尿路感染、导管感染、手术部位感染、艰难梭菌感染（如有腹泻）以及肺栓塞（可引起发热和心动过速）。

**紧急处理：**按 A 到 E 进行评估；需要时给氧；建立静脉通路，抽血（全血细胞计数、尿素和电解质、乳酸、培养），给予液体推注并再评估；按当地脓毒症指南开始广谱抗生素；留置导尿管并监测每小时尿量；立即通知上级外科医生；安排紧急腹部和盆腔 CT。确诊的吻合口漏可能需要介入放射引流或再次手术。关键的教训是：趋势（心动过速和疼痛加重）已足以采取行动；等待"典型"表现会耽误时间。
:::
:::

::: exercise 更安全的出院 {level=2}
一位84岁男性在结肠切除术后第6天被宣布"在医学上适合出院"。他扶助行架能走20米，进食少量，社会照护评估尚未完成，也没有写给全科医生的信。还缺少什么？
::: solution
仅仅在医学上适合并不能使出院安全。他需要商定的出院标准（经口进食、口服镇痛药可控制疼痛、排便恢复、活动能力足以应付家中环境）、关于他将如何生活的治疗和社会照护评估、经过核对的用药（包括需继续使用的 VTE 预防）、为他和家人提供的书面警示症状和联系电话，以及在出院当天发给全科医生的出院小结。
:::
:::

::: exercise 解读核查表研究 {level=3 check="round(1/(0.015-0.008))"}
在2009年世界卫生组织手术安全核查表研究中，住院死亡率从1.5%降至0.8%。假设这一差异完全归因于核查表，需要多少位患者在使用核查表的情况下接受手术才能预防一例死亡（需治疗人数）？四舍五入到最接近的整数。然后给出两个理由说明真实效应为何可能不同。
::: hint
需治疗人数为 $1/\text{绝对风险降低}$，风险以比例表示。
:::
::: solution
绝对风险降低为 $0.015 - 0.008 = 0.007$。需治疗人数为 $1/0.007 \approx 142.9$，四舍五入为 **143**。

需要谨慎的理由：(1) 该研究比较的是引入核查表前后的结局，没有随机化，因此同期的其他变化，包括工作人员知道自己被研究（霍桑效应），可能解释了部分效应；(2) 各医院的基线死亡率差异很大，因此在死亡率本已较低的医院，效应可能更小。绝对风险和相对风险的计算见[[epidemiology-ebm/randomised-trials]]。
:::
:::

::: exercise 为衰弱患者决定是否急诊手术 {level=3}
一位88岁女性患中度痴呆，住在养老院，洗漱和穿衣需要帮助，因乙状结肠憩室穿孔伴弥漫性腹膜炎入院。她接受急诊剖腹手术的估计死亡率非常高。她的女儿持有健康与福利方面的持久授权书。讨论应如何作出是否手术的决定。
::: solution
**如实评估风险。**NELA 风险计算器等经过验证的工具结合她的衰弱评分，可以估计死亡率以及她存活后可能的功能状态；存活可能意味着长时间住 ICU、造口和丧失独立生活能力。

**了解对她最重要的是什么。**评估她对这一决定的决策能力；中度痴呆患者可能缺乏这种能力，但必须经过评估，而且仍应尽可能让她参与。如果她缺乏决策能力，她的女儿作为健康与福利方面的受托人，可以按她的最佳利益作出决定。任何预先决定或她以前表达过的意愿都很重要。

**讨论所有选择。**这些选择包括：急诊剖腹手术（通常为哈特曼手术并造口）、在特定情况下采用创伤较小的方法，或以舒适为重点的治疗。决定不手术并不等于决定不照护：它意味着良好的症状控制和支持，并请姑息治疗团队参与（[[geriatrics-palliative/end-of-life-care]]）。

**迅速行动。**无论作何决定，腹膜炎都需要及时使用抗生素、补液和镇痛；如果选择手术，延迟会使结局变差。讨论应有上级外科医生和麻醉医生参与，并清楚记录，包括作出决定的理由。
:::
