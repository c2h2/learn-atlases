外科照护是一个时间的学问：手术前的日子用来降低风险，手术中的小时用来避免伤害，而术后的天决定并发症是否发生。本章涵盖术前的评估与优化、生理的反应与术后的照护，以及围绕患者安全的系统[[clinical-skills/patient-safety]]、[[physiology/homeostasis-body-fluids]]。

本章涵盖术前的评估与优化、术中的生理与术后的照护、安全的系统，以及增强恢复的路径。

## 手术之前

::: definition 术前的评估与优化 {#def-preassessment}
**目的：识别风险、改善储备，并计划照护，使手术不会在一个可避免的低谷上进行。评估包括心血管的风险与功能状态（代谢当量与病史的线索）[[cardiovascular/coronary-artery-disease]]、呼吸的风险（吸烟与慢阻肺）[[respiratory/asthma-copd]]、肾与肝[[renal/chronic-kidney-disease]]、[[gastrointestinal/liver-disease]]、营养与容量[[gastrointestinal/clinical-nutrition]]、认知与衰弱[[geriatrics-palliative/ageing-frailty]]、以及用药与共病[[geriatrics-palliative/polypharmacy]]、[[endocrine/diabetes]]。检查按指征而不是按常规[[clinical-skills/laboratory-tests]]。优化：戒烟与疫苗[[public-health/prevention-promotion]]、纠正贫血（铁的途径）[[blood/anaemia]]、血糖（在急性病规则中暂停某些药物）[[endocrine/diabetes]]、抗凝的管理与桥接[[blood/thrombosis-anticoagulation]]、类固醇的覆盖[[endocrine/adrenal]]、营养与运动准备[[public-health/prevention-promotion]]。决定要记录风险与替代，并使用清单与交接[[clinical-skills/records-handover]]、[[#def-safety-systems]]。**
:::

## 术中与术后

::: definition 术中的生理与术后的照护 {#def-intraop}
**手术激活神经内分泌的反应：激素与细胞因子造成钠水潴留、钾的丢失与糖异生，其强度随切口与机制而变（微创会减轻这一反应）[[physiology/hormones]]、[[pathology/acute-inflammation]]、[[pharmacology/drug-receptor]]。液体：术中与术后的维持按丢失来滴定；过多会造成肠的水肿与肺的并发症，过少会损害肾[[renal/water-sodium]]、[[emergency-critical-care/shock-fluids]]、[[gastrointestinal/clinical-nutrition]]。体温：低体温会引起凝血障碍、感染与心脏事件，因此需要加温设备与加温的液体[[blood/haemostasis-bleeding]]、[[surgery/wounds-surgical-infection]]。并发症按时钟排列：早期的（出血、气道与心脏）[[cardiovascular/coronary-artery-disease]]、[[emergency-critical-care/resuscitation]]；这几天的（肺不张、感染与静脉血栓）[[respiratory/respiratory-infections]]、[[blood/thrombosis-anticoagulation]]；以及较晚的（吻合口漏、粘连与疝）[[surgery/gastrointestinal-surgery]]。预防的组合：抗血栓、适时的抗生素、保温与早期的活动[[surgery/wounds-surgical-infection]]、[[clinical-skills/patient-safety]]。**
:::

## 患者周围的系统

::: definition 外科的安全系统 {#def-safety-systems}
**多数不良事件来自系统的失效而非个人的疏忽，因此改善也来自系统：清单与时机的暂停，在切开前核对身份、部位与计划[[clinical-skills/patient-safety]]；结构化的交接，把术中的事件与风险写在纸上并当面移交[[clinical-skills/records-handover]]；团队的简报与明确的角色[[clinical-skills/communication]]；增强恢复的路径——提前的口服、阿片类节约的镇痛、早期活动与管道早移除[[surgery/anaesthesia-pain]]、[[public-health/prevention-promotion]]；生理的监测与恶化的评分及快速反应团队[[emergency-critical-care/acute-assessment]]；以及把结局与并发症公开审计，用来改变路径[[public-health/health-systems-economics]]、[[clinical-skills/patient-safety]]。原则：把正确的步骤变成默认的路径，并在偏离时要求一个理由。**
:::

::: example 78岁的髋 {#ex-hip-prehab}
一位78岁在用呋塞米与ACE抑制剂和阿司匹林及舍曲林的人跌倒并骨折了股骨颈；她独住在三楼；认知的筛查是有点快；手术是如果有床明天。
::: solution
**髋的骨折需要在小时内手术，延迟会增加死亡与并发症，所以优化的工作要在小时内做而不是天[[surgery/orthopaedics]]、[[geriatrics-palliative/falls]]。需要：液体与电解质的纠正（利尿剂与摄入减少会造成低钾与容量不足）[[renal/potassium-calcium-phosphate]]、[[renal/water-sodium]]；阿司匹林通常不必等待而抗血小板的桥接不做[[blood/thrombosis-anticoagulation]]、[[surgery/wounds-surgical-infection]]；心电图与心脏的评估按线索[[cardiovascular/coronary-artery-disease]]；以及把认知与谵妄的风险当作一个老年医学的问题[[geriatrics-palliative/delirium-dementia-care]]。出院从入院开始：理疗与 作业的评估及家庭的安排（三楼与独住意味着康复机构或家庭的支持）[[public-health/health-systems-economics]]、[[geriatrics-palliative/ageing-frailty]]。抗凝与脊柱的麻醉的时机也要与麻醉科讨论[[surgery/anaesthesia-pain]]。**
:::
:::

::: example 应该等待的择期 {#ex-defer-optimise}
一位62岁体重指数42、糖化74、每天25支烟并有新发的劳力性胸痛的人被安排腹腔镜胆囊切除，因为她常因胆道的痛去急诊。
::: solution
**新的劳力性胸痛在这样一个风险的人中必须先被调查，因为它可能是冠脉的疾病，而在未识别的缺血下做手术会造成事件[[cardiovascular/coronary-artery-disease]]、[[#def-preassessment]]。反复的急诊就诊可以用保守的措施（饮食与药物）以及在等待中的疼痛的管理[[surgery/gastrointestinal-surgery]]、[[gastrointestinal/pancreas-biliary]]。优化的菜单：戒烟（即使数周也有益）与疫苗[[public-health/prevention-promotion]]、血糖（目标与急性病规则）[[endocrine/diabetes]]、体重与营养[[gastrointestinal/clinical-nutrition]]、以及心脏的评估与治疗[[cardiovascular/hypertension]]。共同决策：说明延迟的风险（另一次发作）与手术的风险，并把决定与理由记录[[clinical-skills/communication]]、[[medical-ethics-law/consent-capacity]]、[[clinical-skills/records-handover]]。**
:::
:::

::: example 被认为没问题的低体温 {#ex-warmth}
一位90分钟的开放手术结束时患者寒战且意识混乱：核心温度35.1摄氏度，伤口渗血，出血时间延长，抗生素在诱导时给（100分钟前），交接中没有记录关注。
::: solution
**低体温会损害血小板与凝血酶的功能（所以渗血与出血时间的延长），增加手术部位的感染与心脏事件，并延迟药物的代谢（因此寒战与意识混乱）[[surgery/anaesthesia-pain]]、[[surgery/wounds-surgical-infection]]、[[pharmacology/metabolism-excretion]]。处理：主动的加温（气流的毯与加温的液体）与把房间加温，并把血液制品在输注前加温[[emergency-critical-care/shock-fluids]]、[[blood/transfusion]]。抗生素：在一例长的开放手术中需要术中再剂（按药物的半衰期与丢失），所以这个细节应该写在路径中[[microbiology/antimicrobials]]、[[clinical-skills/patient-safety]]。交接的失败：被错过的项目正是清单的目的（体温与丢失和剂量）[[clinical-skills/records-handover]]、[[#def-safety-systems]]。**
:::
:::

::: example 日间手术的人 {#ex-daycase}
一位44岁的腹股沟疝，体重指数38，睡眠呼吸暂停在用持续正压但只是有时，每周15单位酒精，家里没有人支持，做零工排班；名单要把他作为常规的日间。
::: solution
**日间手术需要特定的条件：合并症被稳定、气道风险可接受、明确的疼痛与恶心的计划、以及一个在晚上支持的人[[surgery/gastrointestinal-surgery]]、[[surgery/anaesthesia-pain]]。这里的红旗：未经优化的睡眠呼吸暂停（气道的风险与阿片类）[[respiratory/asthma-copd]]、家里的没有支持、以及零工的收入（复工与随访）[[public-health/determinants-inequalities]]；酒精的单位要问戒断的风险与肝脏[[gastrointestinal/liver-disease]]、[[psychiatry/substance-use]]。合适的做法：把风险与麻醉科讨论、给出明确的指导（陪同的人与夜间电话）或改为过夜[[clinical-skills/communication]]、[[clinical-skills/records-handover]]。原则：日间的路径是为被选择的患者，而不是为了名单的流量[[public-health/health-systems-economics]]、[[clinical-skills/patient-safety]]。**
:::

## 通向何处

风险的沟通与共同的决策在[[medical-ethics-law/consent-capacity]]与[[clinical-skills/communication]]；生理的监测与恶化的识别在[[emergency-critical-care/acute-assessment]]；液体与电解质在[[renal/water-sodium]]与[[emergency-critical-care/shock-fluids]]；麻醉与镇痛的技术在[[surgery/anaesthesia-pain]]；伤口与感染在[[surgery/wounds-surgical-infection]]；抗凝与桥接在[[blood/thrombosis-anticoagulation]]；糖尿病的规则在[[endocrine/diabetes]]；而出院与交接在[[clinical-skills/records-handover]]与[[public-health/health-systems-economics]]。

::: history
现代的外科安全是三件事的交汇：麻醉与无菌使大的手术可行[[surgery/anaesthesia-pain]]、[[surgery/wounds-surgical-infection]]；生理与液体（战时的休克研究与术后代谢的研究）使术后的照护有了科学[[emergency-critical-care/shock-fluids]]、[[physiology/homeostasis-body-fluids]]；而质量的运动（把事故称为可预防的、清单与并发症的审计）把个体英雄的工作变成了一个可靠的系统[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]。增强恢复的路径把原则整合：更少的管道与更早的活动与被标准化的路径[[public-health/prevention-promotion]]、[[geriatrics-palliative/ageing-frailty]]。
:::

::: summary
- 术前：按指征评估风险，用可以数周的时间做能做的优化，用小时做必须做的（髋的骨折就是小时）。
- 术中：保温、适时的抗生素与被滴定的液体是三项便宜而有效的干预。
- 术后：把并发症按时钟想（小时、天、周），并把观察与阈值写在时间上。
- 系统：清单与时机的暂停、结构化的交接、增强恢复的路径与快速反应，比任何个人的细心更重要。
- 决策：风险的沟通、上限的讨论与出院的准备都属于同一个外科照护的连续体。
:::

::: exercise 写出液体的计划 {level=1}
开放右半结肠切除后第一天，胃管在低负压吸引，尿0.3毫升每千克每小时，钠132、钾3.4、肌酐从78升到110：为接下来的24小时开出并说明理由。
::: solution
**这是容量不足（少尿与肌酐升高和第三间隙的液体转移到血管内）：先给等张的晶体（平衡的盐溶液）作为被评估的输注，并按反应再给，同时记录出入量[[emergency-critical-care/shock-fluids]]、[[renal/water-sodium]]。用含钾的溶液纠正低钾（在确认尿之后）[[renal/potassium-calcium-phosphate]]；用等张而不是低张的液体避免加重低钠，并避免葡萄糖的负荷（会造成低钠与水过多）[[renal/water-sodium]]、[[endocrine/diabetes]]。检查胃管的丢失并按丢失补充（氢与氯和钾的丢失会造成低氯的碱中毒）[[gastrointestinal/oesophagus-stomach]]、[[renal/acid-base-disorders]]。再评估：尿与肌酐和体重及临床，并在肠功能恢复后转向口服[[gastrointestinal/clinical-nutrition]]、[[#def-intraop]]。**
:::
:::

::: exercise 解释风险 {level=1}
用一个给出你的结肠切除患者30天4%严重发病风险的计算器，用一段话完成同意的对话：你会说什么，不会说什么，按判例的标准。
::: solution
**要说：这是什么手术与为什么做，预期的获益（肿瘤的切除与症状的缓解），以及具体的风险：大约每一百人中会有四人在一个月内遇到一个严重的问题，包括出血与感染和吻合口的渗漏及血栓，另有一个造口的可能[[#def-preassessment]]、[[surgery/gastrointestinal-surgery]]、[[clinical-skills/communication]]。还要说替代（包括保守的路径与这些不手术的选择）与这些不确定，并留出提问的时间[[medical-ethics-law/consent-capacity]]。不要说：孤立的数字而不解释它们对生活意味着什么；也不要把少见但会改变决定的风险略过，因为同意的标准是从这位患者的角度什么必须被披露[[medical-ethics-law/consent-capacity]]、[[clinical-skills/records-handover]]。记录：讨论了什么与问了什么与被提出的顾虑[[clinical-skills/records-handover]]。**
:::
:::

::: exercise 追查钾 {level=1}
一位肠切除后的患者在输4%葡萄糖四小时后钾从4.1降到3.0，心电图出现新的U波；她因房颤在用地高辛。处理并解释机制两次——稀释性的与全身的。
::: solution
**葡萄糖会刺激胰岛素的分泌，把钾驱动入细胞内，所以这是重新分布的低钾而不是全身的缺乏；同时不含钾的液体会把浓度稀释[[renal/potassium-calcium-phosphate]]、[[endocrine/diabetes]]。在地高辛存在时低钾会增加心律失常的风险（结合增加），所以要停止低钾的驱动并纠正[[cardiovascular/arrhythmias]]、[[pharmacology/dosing-principles]]。处理：换到含钾的等张液体并静脉补钾（按浓度与通路的规则），同时检查镁（低镁会使钾难以纠正）[[renal/potassium-calcium-phosphate]]、[[emergency-critical-care/shock-fluids]]；监测心电与尿及系列的钾；并回顾利尿剂与丢失（胃管）[[geriatrics-palliative/polypharmacy]]、[[gastrointestinal/oesophagus-stomach]]。教训：术后不要常规用葡萄糖的维持液体作为唯一的液体[[gastrointestinal/clinical-nutrition]]、[[#def-intraop]]。**
:::
:::

::: exercise 增强恢复的项目审计 {level=3}
你们的结直肠增强恢复路径报告18%的再入院与良好的依从性。设计一个审计来检验这两个数字是否真实。
::: solution
**先质疑这两个数字的定义与分母。哪些再入院被计入：所有急诊的就诊还是只有非计划的重住？在30天内还是住院期间？谁被排除（死亡与转院）？把数字与病历的复核双重编码，因为常规收集常低估[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]。依从性：按患者而不是按项目勾选来测，明确哪些条目被核查（术前的口服、管道的时间、活动的目标与镇痛 dose）[[#def-safety-systems]]。再测结果：住院的时间与并发症与康复的进度和患者的报告[[public-health/prevention-promotion]]。调整混杂：病例的组合与肿瘤的分期会解释差异[[epidemiology-ebm/bias-confounding]]。最后：与团队一起解释并把改变写进路径，然后重新测量[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]。**
:::

## 练习

::: exercise 计划用药的清单 {level=1}
手术当天的决定与理由：二甲双胍、SGLT2抑制剂、雷米普利、比索洛尔、机械瓣的华法林、二级预防的阿司匹林、舍曲林、口服避孕药、泼尼松龙5毫克。
::: solution
**二甲双胍：在大手术或有急性肾损伤风险时当天暂停，术后确认能进食且肾功能稳定再重启[[endocrine/diabetes]]、[[renal/acute-kidney-injury]]。SGLT2抑制剂：术前暂停，因其会增加酮症与脱水风险[[endocrine/diabetes]]、[[renal/water-sodium]]。雷米普利：手术当天常暂停以避免麻醉中的低血压，术后按血压与肾功能重启[[cardiovascular/hypertension]]、[[renal/potassium-calcium-phosphate]]。比索洛尔：继续服用，突然停用会诱发心肌缺血与心率反跳[[cardiovascular/coronary-artery-disease]]、[[pharmacology/adverse-reactions]]。机械瓣的华法林：停用并按血栓风险桥接，术后按计划重启[[blood/thrombosis-anticoagulation]]。二级预防的阿司匹林：通常继续[[cardiovascular/coronary-artery-disease]]。舍曲林：继续[[psychiatry/anxiety-disorders]]。口服避孕药：在大手术与制动前暂停并提供替代[[obstetrics-gynaecology/contraception-fertility]]、[[blood/thrombosis-anticoagulation]]。泼尼松龙5毫克：在较大手术中考虑应激剂量[[endocrine/adrenal]]。**
:::
:::

::: exercise 读发热的时钟 {level=2}
开腹手术后第二天发热38.9、心率112、少尿，C反应蛋白从80升到240：五个W之中在统计上最可能是哪一个，而实际的生理要求什么？把助记词与医学分开。
::: solution
**助记词（肺与尿路和伤口与导管与血栓）会在第二天指向肺；但术后早期的发热常是细胞因子的生理反应，不该自动触发套餐[[#def-intraop]]、[[pathology/acute-inflammation]]。真正的信号是生理：少尿与心动过速及炎症标志的上升意味着不稳定，需要按急性的路径评估[[emergency-critical-care/acute-assessment]]、[[clinical-skills/patient-safety]]。要主动找可治的原因：吻合口的漏与腹内的脓（在天是典型）[[surgery/gastrointestinal-surgery]]、伤口的感染（包括坏死的软组织感染）[[surgery/wounds-surgical-infection]]、肺炎[[respiratory/respiratory-infections]]、尿路[[renal/urinary-tract]]、以及血栓[[blood/thrombosis-anticoagulation]]。做法：床旁的评估与培养和影像（按指征的CT），同时给液体与抗感染，并把复评的时间写下[[clinical-skills/laboratory-tests]]、[[microbiology/laboratory-diagnosis]]、[[clinical-skills/medical-imaging]]。**

::: exercise 修正出院 {level=2}
一位84岁衰弱的人在结肠切除后第6天被判定医学上适合出院：用助行架走20米、进食尚可、社会服务评估待定、社区护士已分配、给全科医生的信未发出。这个出院有什么不对，请设计更好的。
::: solution
**出院是一次多系统的转换，而不是单个医生的判断[[#def-safety-systems]]、[[clinical-skills/records-handover]]。此处缺失：功能、营养与认知的具体目标（走20米与进食尚可不足以支撑回家）[[geriatrics-palliative/ageing-frailty]]；社会服务评估未完成，意味着居家风险未被处理；用药复核与伤口及门诊随访未安排[[surgery/wounds-surgical-infection]]；而给全科医生的信未发出，等于把责任悬空[[clinical-skills/records-handover]]。更好的出院：一份书面的出院计划，含目标、日期与联系人；与家属及社区团队的当面交接；一份用药清单与明确的警告（发热、伤口渗液、不能进食）；以及被预约的复查、康复与营养支持[[public-health/health-systems-economics]]、[[medical-ethics-law/consent-capacity]]、[[gastrointestinal/clinical-nutrition]]。**
:::
:::

::: exercise 论证集中化 {level=3}
你们地区提议把食管切除与腹主动脉瘤破裂的修补集中到一个高容量的中心，并在其他地方保留急救的入口。提出并批判这个论证：证据、入口、公平、人力与财务。
::: solution
**证据：在这两类手术中，容量与结局的关系反复被观察到——高容量的中心与医师的死亡更低，而破裂的动脉瘤的救治在具备即刻手术与血管的团队的地方更好[[surgery/vascular-urological-surgery]]、[[pathology/cancer-diagnosis]]、[[public-health/health-systems-economics]]。集中的好处还包括团队的熟练、重症的床位与审计的规模[[clinical-skills/patient-safety]]。反对：转运会延迟时间并可能增加死亡（尤其是 路远的与资源少的群体）[[emergency-critical-care/major-incidents]]、[[public-health/determinants-inequalities]]；入口的成本（家属的住宿与误工）会把这些不平等放大[[public-health/health-systems-economics]]；还有人力（集中的中心需要训练有素的人员）与本地的技能的流失[[public-health/global-health]]。折中：明确的入口标准与转运的协议、在卫星中心的急救稳定与团队培训、以及被测量的结局与时间的审计[[emergency-critical-care/acute-assessment]]、[[clinical-skills/records-handover]]。**
:::
