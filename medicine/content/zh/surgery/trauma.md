创伤是年轻人的首要死因，也是各年龄残疾的重要来源；它的救治是一条连续的时间线：现场、转运、初评、手术、重症与重建[[emergency-critical-care/major-incidents]]、[[public-health/environmental-occupational]]。

本章涵盖现场的评估与分类、初级调查与休克的分类、损伤控制与确定性治疗，以及长期的后果与重建。

## 最初的小时

::: definition 现场与初级调查 {#def-survey}
**现场：安全优先，然后是即刻的止血（止血带、加压敷料与创伤包），因为肢体出血可以在数分钟内致命；转运的决定与现场的通讯要清楚[[emergency-critical-care/major-incidents]]、[[emergency-critical-care/airway-ventilation]]。初级调查按顺序：气道（含颈椎保护）、呼吸、循环（含出血控制）、失能与暴露，同时保温[[emergency-critical-care/acute-assessment]]。复苏按休克的类型（低血容量与心源性与分布性和梗阻性）进行：限制性的液体、平衡的血液制品比例与抗纤溶药物[[emergency-critical-care/shock-fluids]]、[[blood/transfusion]]、[[blood/haemostasis-bleeding]]、[[cardiovascular/circulation-blood-pressure]]。辅助检查包括床旁超声（心包液体、气胸与腹腔液体）与放射，而CT用于被稳定者的定义性诊断[[clinical-skills/medical-imaging]]、[[emergency-critical-care/acute-assessment]]。随后按机制检查头颅与脊柱与胸腹与骨盆与肢体[[nervous-system/motor-systems]]、[[surgery/orthopaedics]]。**
:::

::: definition 损伤控制与确定性治疗 {#def-damage-control}
**当低体温、酸中毒与凝血障碍同时存在（致死三联）时，继续做一期的确定性手术会耗尽剩余的生理储备。损伤控制的原则是用最小的手术控制出血与污染，转入重症监护复苏，待生理恢复后再回到手术室[[emergency-critical-care/shock-fluids]]、[[pathology/acute-inflammation]]、[[surgery/acute-abdomen]]。手段包括腹腔填塞、血管的结扎或分流、临时的腹壁关闭，以及长骨的外固定支架[[surgery/vascular-urological-surgery]]、[[surgery/orthopaedics]]、[[surgery/gastrointestinal-surgery]]。复苏的核心是复温、按比例的血液制品、在大量输血时补钙，并按目标监测凝血[[blood/transfusion]]、[[renal/potassium-calcium-phosphate]]、[[pharmacology/dosing-principles]]。确定性治疗在之后的数小时到数天内按优先级完成；在选定的损伤中，介入放射的栓塞可以替代手术[[clinical-skills/medical-imaging]]。系统层面：把正确的患者送到正确的地方并在正确的时间内，是创伤网络的核心[[emergency-critical-care/major-incidents]]、[[public-health/health-systems-economics]]。**
:::

## 长长的尾巴

::: definition 创伤后的全身与重建的照护 {#def-long-tail}
**最初的数小时之后，并发症按时间聚集：感染（肺炎、伤口与导管）与静脉血栓与肠麻痹和应激性溃疡[[infectious-diseases/healthcare-infections]]、[[blood/thrombosis-anticoagulation]]、[[gastrointestinal/bowel-disease]]、[[emergency-critical-care/critical-care]]；随后是晚期的脓毒症与持续的炎症反应和多器官功能不全[[pathology/acute-inflammation]]、[[renal/acute-kidney-injury]]。骨与软组织的损伤需要分期的处理、骨的重建与软组织的覆盖（植皮与皮瓣）[[surgery/orthopaedics]]、[[surgery/wounds-surgical-infection]]、[[musculoskeletal/fractures]]。长期的后果包括慢性疼痛与关节功能丧失与瘢痕，以及心理创伤（创伤后应激）[[nervous-system/headache-pain]]、[[psychiatry/anxiety-disorders]]、[[geriatrics-palliative/symptom-control]]。康复从重症室开始：早期活动、营养支持、多学科的团队与家属的参与[[public-health/prevention-promotion]]、[[gastrointestinal/clinical-nutrition]]、[[clinical-skills/communication]]。伤害的预防（道路与家庭与工作场所）属于公共卫生的范畴[[public-health/environmental-occupational]]、[[public-health/non-communicable-disease]]。**
:::

::: example 高速路上的多发伤 {#ex-motorway}
一位24岁高速正面碰撞的患者：GCS 12且言语不清，呼吸28，心率118，血压92/60，腹软，平片示骨盆不稳，股骨短缩，尽管给氧饱和仍在下降。
::: solution
**这是一位正在失血的患者，同时气道与呼吸也在恶化。按顺序处理：先考虑气道保护（GCS下降与言语不清），并立即恢复氧合——先排除气胸与血胸，因为正压通气会让它们恶化[[emergency-critical-care/airway-ventilation]]、[[emergency-critical-care/acute-assessment]]、[[respiratory/respiratory-failure]]。不稳定的骨盆与股骨骨折会藏住大量血液：用骨盆带或床单环扎并把患者放在平板上，做床旁超声或诊断性穿刺，并启动大量输血方案[[#def-survey]]、[[blood/transfusion]]、[[surgery/orthopaedics]]、[[surgery/vascular-urological-surgery]]。路径决定：若生理不允许，直接去介入栓塞或手术填塞，而不是先做CT；同时联系创伤中心[[#def-damage-control]]、[[emergency-critical-care/major-incidents]]。头颅在稳定后再扫描[[nervous-system/motor-systems]]、[[clinical-skills/medical-imaging]]。**
:::
:::

::: example 从高处坠落 {#ex-fall}
一位31岁从4米落到脚上：双侧跟骨骨折，L1爆裂骨折伴30%的高度丢失与轻度的后突，双腿肌力正常而知觉正常，膀胱在排尿，背痛9/10。
::: solution
**足跟着地的坠落会把力量沿腿、骨盆与脊柱向上传导，因此双侧跟骨骨折与腰椎爆裂骨折要一起考虑，并同时排查其他部位（胸腹与肾）[[surgery/orthopaedics]]、[[nervous-system/motor-systems]]、[[renal/urinary-tract]]。神经功能正常不等于脊柱稳定：30%的高度丢失与骨块后突提示可能不稳，需要用CT与MRI评估柱与后方复合体[[clinical-skills/medical-imaging]]、[[musculoskeletal/fractures]]。在神经完整者中，可以在支具与手术之间选择；而不稳定或有进展者需要外科的固定与减压[[surgery/orthopaedics]]、[[musculoskeletal/back-pain]]。同时警惕更高位损伤造成的神经源性休克（低血压伴心动过缓与皮肤温暖）[[emergency-critical-care/shock-fluids]]。长期要处理疼痛与骨质量与康复和复工[[geriatrics-palliative/symptom-control]]、[[public-health/prevention-promotion]]。**
:::
:::

::: example 不再复张的胸 {#ex-chest}
因肋骨骨折的血胸放入28号胸管后第1天：引出400毫升后停止，胸片仍示全白，皮下气肿在扩大，说话时有持续的气漏。
::: solution
**引流停止而胸片仍是白的，加上持续的气漏与扩大的皮下气肿，说明胸管位置不佳或已堵塞，更重要的是可能存在持续漏气（肺的撕裂或支气管的损伤）[[#def-survey]]、[[respiratory/mechanics-breathing]]、[[clinical-skills/medical-imaging]]。步骤：检查管道（扭曲、吸引与波动），做CT并请支气管镜寻找气道损伤，并重新放置一根位置正确的管[[emergency-critical-care/airway-ventilation]]。持续气漏与肺不复张需要外科评估（胸腔镜或开胸修补与血胸清除）；若延误数月则机化的血胸需要剥离[[surgery/wounds-surgical-infection]]、[[respiratory/lung-cancer-pleura]]。同时预防脓胸，并用良好的镇痛让他能咳嗽[[respiratory/respiratory-infections]]、[[surgery/anaesthesia-pain]]。**
:::
:::

::: example 父母很安静的孩子 {#ex-child}
一位2岁的患者被说成从楼梯上摔下：螺旋型的胫骨骨折，多处不同颜色的瘀斑，父母的说法前后不一，孩子张力低且回避目光，祖母说他只是笨拙。
::: solution
**不合理的解释、不同颜色的瘀斑与前后不一致的说法，加上孩子的低张力与回避目光，构成需要按保护路径处理的组合[[paediatrics/safeguarding]]、[[clinical-skills/clinical-reasoning]]。医学优先：筛查严重的隐匿损伤（头颅、腹腔与骨骼），因为还不会走的孩子会有这些不成比例的损伤[[paediatrics/acute-childhood-illness]]、[[musculoskeletal/fractures]]、[[nervous-system/motor-systems]]。程序：联系保护团队与警方、分别访谈、详细的客观记录（身体图与照片），并避免在孩子面前与父母对抗[[paediatrics/safeguarding]]、[[clinical-skills/communication]]、[[clinical-skills/records-handover]]、[[medical-ethics-law/confidentiality]]。后续：住院观察与家庭的评估与其他孩子的检查，并把这次事件完整记录在案[[paediatrics/growth-development]]、[[public-health/health-systems-economics]]。**
:::
:::

## 通向何处

初评的原则与评分在[[emergency-critical-care/acute-assessment]]；大事件的组织在[[emergency-critical-care/major-incidents]]；液体与输血在[[emergency-critical-care/shock-fluids]]与[[blood/transfusion]]；凝血在[[blood/haemostasis-bleeding]]；脑与脊髓在[[nervous-system/motor-systems]]；胸在[[respiratory/mechanics-breathing]]与[[respiratory/respiratory-failure]]；腹在[[surgery/acute-abdomen]]与[[surgery/gastrointestinal-surgery]]；血管在[[surgery/vascular-urological-surgery]]；骨与软组织在[[surgery/orthopaedics]]；儿童的保护在[[paediatrics/safeguarding]]。

::: history
创伤系统的建立来自一份国家的报告：它把创伤称为现代社会被忽视的疾病，并指出许多早期死亡可以通过组织来避免[[emergency-critical-care/major-incidents]]、[[public-health/health-systems-economics]]。随后出现分级的创伤中心、区域化的转运与审计的评分[[surgery/perioperative-care]]；损伤控制外科从战场走进城市的急诊[[#def-damage-control]]、[[surgery/acute-abdomen]]；按比例的大量输血、抗纤溶药物与黏弹性的凝血检测改变了复苏[[blood/transfusion]]、[[blood/haemostasis-bleeding]]；而预防（安全带与头盔与酒精的政策）在系统层面把死亡曲线压低[[public-health/environmental-occupational]]、[[public-health/prevention-promotion]]、[[psychiatry/substance-use]]。
:::

::: summary
- 创伤救治按时间分层：现场止血与气道、第一小时的初级调查与复苏、之后的损伤控制与重症照护。
- 初级调查是按顺序找出即刻致命的问题并反复重估；超声、放射与CT按稳定程度使用[[#def-survey]]。
- 致死三联（低体温、酸中毒、凝血障碍）要求损伤控制：最短的手术、复苏、然后确定性修复[[#def-damage-control]]。
- 骨盆与股骨会藏住大量血液；环扎与外固定是救命的措施[[#ex-motorway]]。
- 后期死亡来自脓毒症与多器官功能不全，而康复与心理照护决定长期的结局；预防属于公共卫生[[#def-long-tail]]。
:::

## 练习

::: exercise 现场的分类 {level=1}
多车相撞：四位患者——A无反应而呼吸有声；B腹痛、血压96伴股骨变形；C腕部受伤在大叫；D能走能说话但苍白而休克。分类并说明理由。
::: solution
**A最优先：呼吸有声意味着气道梗阻，需要体位、吸引与通气支持，这会在数分钟内致命[[emergency-critical-care/airway-ventilation]]、[[emergency-critical-care/acute-assessment]]。B其次：腹痛加股骨变形提示失血性休克，需要输血与手术或介入[[#def-survey]]、[[blood/transfusion]]、[[surgery/acute-abdomen]]。D是陷阱：能说话不代表安全，苍白的休克要重新评估并提高优先级[[emergency-critical-care/shock-fluids]]。C最后：镇痛、夹板固定与伤口处理[[surgery/orthopaedics]]、[[surgery/wounds-surgical-infection]]。分类结果要用统一的语言记录并交接[[emergency-critical-care/major-incidents]]、[[clinical-skills/records-handover]]。**
:::
:::

::: exercise 读骨盆 {level=2}
一位APC型的骨盆环损伤伴低血压：绑带已上，FAST阴性，胸片清晰，股骨完整，增强CT在耻骨上支附近显示造影剂渗出。谁在出血，什么能止住，原则是什么？
::: solution
**骨盆出血可来自静脉丛与骨面（多数，靠环的闭合与填塞控制），也来自动脉支；CT上的造影剂渗出说明动脉在出血[[#def-survey]]、[[surgery/vascular-urological-surgery]]、[[surgery/orthopaedics]]。绑带与骨盆闭合缩小容积、帮助静脉止血；而动脉渗出需要介入栓塞，或在极不稳定时做腹膜外填塞[[#def-damage-control]]、[[blood/transfusion]]、[[clinical-skills/medical-imaging]]。原则：FAST阴性已排除腹腔，所以出血源在骨盆本身；并且不要在低血压的骨盆上反复重复应力检查[[emergency-critical-care/acute-assessment]]、[[musculoskeletal/fractures]]。**
:::
:::

::: exercise 处理开放的胫骨 {level=2}
农场工人，开放性节段性胫骨骨折，3小时，明显污染，足底感觉完好，血管检查正常。给出抗生素、破伤风、清除的时机、固定、关闭与并发症的预案。
::: solution
**抗生素与破伤风在到达时立即给；农业污染要覆盖土壤来源的菌并核实免疫状态[[surgery/wounds-surgical-infection]]、[[microbiology/antimicrobials]]、[[immunology/vaccines-immunotherapy]]。清除：早期彻底冲洗并切除失活组织，通常需要计划中的二次探查[[surgery/orthopaedics]]、[[surgery/wounds-surgical-infection]]。固定：节段骨缺损与软组织损伤决定外固定或髓内钉的选择，按损伤分级[[musculoskeletal/fractures]]。关闭：伤口多不做一期缝合；晚期覆盖需要植皮或皮瓣，骨外露时要请重建团队[[surgery/wounds-surgical-infection]]。并发症预案：感染、骨不连与关节僵硬，同时处理吸烟与营养影响愈合的因素[[gastrointestinal/clinical-nutrition]]、[[public-health/prevention-promotion]]。**
:::
:::

::: exercise 论证网络 {level=3}
为你们地区设计颅脑损伤的路径：从社区到CT的阈值、分支与中心的影像规则、神经外科的取回，以及一位在抗凝中的血肿患者转诊前的逆转。并提出批评。
::: solution
**社区阈值：用公开的头伤CT规则（抗凝与神经系统体征与持续呕吐等）决定谁需要扫描，避免低风险者的放射暴露[[emergency-critical-care/acute-assessment]]、[[clinical-skills/medical-imaging]]、[[clinical-skills/clinical-reasoning]]。分支与中心：在分支完成扫描与稳定，用远程读片决定是否转诊；取回策略与手术的时间要被测量[[nervous-system/motor-systems]]、[[emergency-critical-care/major-incidents]]。抗凝的逆转：颅内出血时立即停药并逆转（特异性拮抗剂或因子复合物加维生素K），因为血肿会进展[[blood/thrombosis-anticoagulation]]、[[nervous-system/stroke]]。批评：集中会延长转运时间并加重弱势群体的负担，所以要按人群分层审计时间与结局[[public-health/determinants-inequalities]]、[[public-health/health-systems-economics]]。**
:::
:::

::: exercise 选择开腹 {level=1}
钝性腹外伤，FAST阳性，输2单位后血压84/50、心率128，胸与骨盆不能解释，头部正常。下一步及其理由；什么会改变它？
::: solution
**这是腹腔出血导致的、对复苏反应不佳的休克：直接开腹止血，而不是再做CT，因为持续的出血在低体温与酸中毒形成后不会自行停止[[#def-damage-control]]、[[surgery/acute-abdomen]]、[[emergency-critical-care/shock-fluids]]。同时启动大量输血、补钙、保温并用凝血监测引导[[blood/transfusion]]、[[renal/potassium-calcium-phosphate]]。会改变决定的：若血流动力学反应良好，CT加介入栓塞可以处理实质的脏器损伤；若出血源在胸或骨盆，则治疗那里[[#ex-motorway]]；若超声显示心包液体，则考虑心脏的原因[[cardiovascular/valve-congenital-disease]]。记录复苏的时间、输血量与决定的理由[[clinical-skills/records-handover]]。**
:::
:::

::: exercise 逆转抗凝的头出血 {level=2}
一位82岁在用阿哌沙班的人跌倒；GCS从12降到9；CT显示14毫米的急性硬膜下伴移位。安排这60分钟，包括逆转的辩论。
::: solution
**60分钟内：保护气道与氧合并按指征控制通气（抬高头部、必要时用高渗盐）、立即逆转（特异性拮抗剂，或在没有它时用因子复合物加维生素K）、停用抗凝，同时呼叫神经外科与麻醉[[nervous-system/motor-systems]]、[[blood/thrombosis-anticoagulation]]、[[emergency-critical-care/airway-ventilation]]。逆转的辩论：直接口服抑制剂的作用会因年龄与肾功能而延长，而血肿正在扩大，因此倾向逆转；血栓风险要按其指征与停药的时长评估并记录[[cardiovascular/arrhythmias]]、[[renal/chronic-kidney-disease]]。手术：血肿清除与必要的减压，按移位与瞳孔的体征[[nervous-system/motor-systems]]、[[surgery/perioperative-care]]。共同决策：把年龄、合并症与预后说清，包括不做大手术的路径[[medical-ethics-law/end-of-life-ethics]]、[[clinical-skills/communication]]。**

::: exercise 处理挤压 {level=2}
房屋倒塌：被埋8小时，现在被救出，钾6.3、pH 7.2、肌酸激酶9000、少尿、大腿张力高。给液体、钾、间室的问题与透析的阈值。
::: solution
**被压时就开始补液（解救前）可以减轻再灌注后的钾与肌红蛋白的冲击[[emergency-critical-care/shock-fluids]]、[[renal/water-sodium]]。救出后：用盐水维持尿量，监测钾（心电图、静脉钙、转移与排出的措施）与酸中毒；高钾的紧急处理是钙剂稳定心肌、转移入细胞与促进清除[[renal/potassium-calcium-phosphate]]、[[cardiovascular/arrhythmias]]、[[renal/acute-kidney-injury]]。间室：张力高的大腿、被动伸展时的疼痛与感觉异常提示骨筋膜间室综合征，需要紧急切开减压，而不是等待压力数值[[surgery/orthopaedics]]、[[musculoskeletal/fractures]]。透析的阈值：难以控制的高钾与酸中毒、容量过负荷与尿毒症[[emergency-critical-care/critical-care]]。随访：清除肌红蛋白、监测肾的恢复与肢体的康复[[public-health/prevention-promotion]]、[[gastrointestinal/clinical-nutrition]]。**

::: exercise 设计重伤的康复转诊 {level=3}
为重伤后的早期专业康复写出转诊与资金的论证，反对康复可以在稳定并出院后再开始的观点。
::: solution
**生理的论证：重症与固定会造成肌肉减少、关节挛缩与认知疲劳的后遗，而康复的窗口在早期——在病床上多躺一天，独立的概率就下降[[geriatrics-palliative/ageing-frailty]]、[[emergency-critical-care/critical-care]]、[[public-health/prevention-promotion]]。经济的论证：早期专业康复缩短总住院、减少再入院与长期的机构照护，因此在重伤人群中成本效益更好[[public-health/health-systems-economics]]。设计：在创伤中心内设置康复团队（治疗师与护士与医师与心理），制定明确的转诊标准与床位，并纳入家属的支持与住房安排[[public-health/determinants-inequalities]]、[[geriatrics-palliative/falls]]、[[psychiatry/mood-disorders]]。指标：功能评分、就业恢复、再入院与患者报告的结局[[clinical-skills/patient-safety]]、[[clinical-skills/records-handover]]。**
