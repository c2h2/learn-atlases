在全世界，损伤是儿童和年轻成人的主要死因之一，也是生命年损失的主要原因之一。许多创伤死亡发生在受伤后数分钟内，源于任何人都无法存活的损伤。还有许多死亡发生在最初几小时内，源于出血、气道梗阻或脑受压，而这些正是组织良好的创伤救治体系能够预防的死亡。

本章介绍如何评估和复苏受伤患者、如何控制大出血，以及如何识别头部、胸部、腹部、骨盆和脊柱常见的危及生命的损伤。最后介绍烧伤，以及儿童、老年人和妊娠期损伤的特点。指南以英国为主（NICE 关于严重创伤的 NG39、关于严重创伤服务的 NG40、关于脊柱损伤的 NG41 和关于颅脑损伤的 NG232），并结合美国外科医师学会的高级创伤生命支持（ATLS）课程（现为第11版，2025年），内容截至2026年。剂量仅作为原则给出；处理遵循当地创伤方案。

## 创伤救治体系

当重伤患者被送往能够同时处理其所有损伤的医院时，结局更好。自2012年起，英格兰的区域**创伤网络**把**严重创伤中心**（拥有24小时由顾问医师领导的创伤团队、介入放射、神经外科和其他专科）与其他医院的**创伤单元**连接起来。救护人员使用分诊工具，把伤势最重的患者直接送往严重创伤中心，即使距离更远。创伤审计与研究网络（TARN）的全国审计显示，网络建立后存活率持续提高。

在医院内，由一位指定组长领导的**创伤团队**接收患者。团队在患者到达前通过救护人员的结构化预警得到通知，例如 **ATMIST** 格式：年龄（Age）、受伤时间（Time）、受伤机制（Mechanism）、发现的损伤（Injuries）、体征（生命体征，Signs）和已给予的治疗（Treatment）。事先分配好角色，使评估和治疗同时进行，而不是一个接一个地进行。

## 初级评估

::: definition 初级评估 {#def-survey}
**初级评估**是一种快速、结构化的评估，按照致死的先后顺序发现并处理立即危及生命的问题。在目前的英国和 ATLS 实践中，它写作 **<C>ABCDE** 或 **xABCDE**：

- **<C> 或 x — 灾难性（致命性）外出血：**立即用直接压迫、止血敷料或止血带止血。
- **A — 气道及颈椎保护：**寻找梗阻；开放并确保气道；对有脊柱损伤风险的患者限制颈椎活动。
- **B — 呼吸：**寻找张力性气胸、开放性气胸、大量血胸和连枷胸；给氧。
- **C — 循环及出血控制：**寻找休克及其来源；建立血管通路；抽血；开始以血液制品为基础的复苏。
- **D — 神经功能障碍：**意识水平（格拉斯哥昏迷评分）、瞳孔、血糖、肢体活动。
- **E — 暴露与环境：**脱去衣物检查全身（包括背部，采用轴线翻身或尽量减少活动的评估），然后预防低体温。

每发现一个问题就立即处理，然后再继续。患者病情一有变化就重新评估。
:::

初级评估和初始复苏之后是**二级评估**：从头到脚的检查和完整病史，常概括为 **AMPLE**（过敏 Allergies、用药 Medicines、既往史和妊娠 Past history、最后进食 Last meal、事件和环境 Events）。它寻找所有其余的损伤，可在救命手术之后再进行。**三级评估**在24小时内重复进行，以发现注意力集中在别处时漏掉的损伤，如手足的小骨折。

影像检查是评估的一部分。NICE NG39 建议对钝性严重创伤并怀疑多发伤的成人进行**全身 CT**（从头顶到大腿中部）。在复苏室可拍胸部 X 线片和骨盆 X 线片。**FAST**（创伤重点超声评估）寻找心包和腹腔内的游离液体；对于不稳定的患者，它有助于确定出血来源，但阴性结果不能排除损伤。

## 出血与休克

出血是受伤后可预防死亡的首要原因。**休克**是组织灌注不足；创伤后在被证明不是之前都应假定为**失血性**休克，尽管张力性气胸、心脏压塞和脊髓损伤（神经源性休克）也可引起休克（[[emergency-critical-care/shock-fluids]]）。

成人正常血容量约为 **70 mL/kg**（儿童约80 mL/kg）。机体通过血管收缩和心动过速代偿失血，因此在丢失大量血液之前血压可以维持。ATLS 长期以来把失血分为四级：

| 分级 | 失血量 | 心率 | 血压 | 其他特征 |
|---|---|---|---|---|
| I | 不超过15% | 正常 | 正常 | 轻微 |
| II | 15–30% | 轻度增快 | 正常 | 脉压缩小，焦虑 |
| III | 30–40% | 增快（常 > 120次/分） | 下降 | 意识模糊，尿量减少 |
| IV | > 40% | 明显增快 | 低 | 嗜睡，尿量极少 |

这个表格是一种教学上的近似。真实的患者并不完全符合：年轻人和运动员代偿良好，然后突然恶化；老年人和服用β受体阻滞剂的患者可能不出现心动过速；疼痛或恐惧本身也会使心率加快。创伤患者血压下降是一个晚期体征。血气中的**碱缺失**或**乳酸**升高常能更早地揭示灌注不足。

::: example 估计失血量 {#ex-blood-loss}
一位80 kg 的男性腹部被刺伤。他的心率128次/分，血压92/60 mmHg，呼吸频率28次/分，焦虑且意识模糊。按 ATLS 分级，他大约失血多少？
::: solution
**血容量：**$70\ \text{mL/kg} \times 80\ \text{kg} = 5600$ mL。

**分级：**心动过速超过120次/分、血压下降和意识模糊符合 **III 级**，即失血约30–40%。

**失血量：**$0.30 \times 5600 = 1680$ mL 至 $0.40 \times 5600 = 2240$ mL，即约1.7–2.2升。

**后续。**估计值本身不如结论重要：他已大量失血且仍在出血，需要血液制品和紧急手术控制出血来源，而不是大量晶体液。创伤团队启动大出血预案，他被送往手术室。
:::
:::

### 损伤控制性复苏

::: definition 损伤控制性复苏与损伤控制性手术 {#def-damage-control}
**损伤控制性复苏**是针对创伤性大出血患者的策略。其要素是：

- 通过手术或介入放射（栓塞）**迅速控制出血**；
- 在出血得到控制之前采用**允许性低血压**：接受低于正常的血压（如可触及桡动脉搏动或收缩压约80–90 mmHg），以免冲掉血凝块；但创伤性脑损伤除外，此时需要足够的血压来维持脑灌注；
- **以血液制品为基础的复苏**：通过**大出血预案**及早按平衡比例输注红细胞、血浆和血小板，尽量少用晶体液；
- 尽早使用**氨甲环酸**，且在受伤后3小时内；
- 预防和纠正**低体温、酸中毒和凝血功能障碍**，以及低离子钙。

**损伤控制性手术**是为生理紊乱严重、无法耐受长时间确定性手术的患者实施的简化手术：止血，控制污染（如用吻合器封闭受损的肠管），填塞并临时关腹，然后在重症监护中纠正生理紊乱，24–48小时后返回手术室进行确定性修复。
:::

::: theorem 致死三联征 {#thm-triad}
在出血的创伤患者中，**低体温、酸中毒和凝血功能障碍**相互强化，每一个都会使另外两个加重。一旦形成，这一循环可使出血无法控制，即使手术出血源已经处理。从一开始就预防这三者，而不是在它们出现后再纠正，是损伤控制的基础。
:::

::: proof
失血减少了氧输送，组织转为无氧代谢并产生乳酸。暴露、冷的液体和打开的体腔导致低体温；休克减少产热。凝血因子是酶，低体温和酸中毒都会减慢其活性并损害血小板功能。严重损伤还会引起**急性创伤性凝血病**，它由组织损伤和休克驱动，在给予任何液体之前就已出现；用晶体液稀释血液会使之加重。凝血功能差导致更多出血，进而加深休克、酸中毒和降温。损伤控制在每一个环节打破这一循环：用血液制品代替晶体液，使用加温液体并主动保温，尽早使用氨甲环酸，缩短手术。
:::

证据基础包括两项大型试验。**CRASH-2**（2010年）纳入了2万多名出血的创伤患者，发现氨甲环酸降低了全因死亡率（14.5%对16.0%）和出血死亡。后续分析显示获益取决于早期治疗：受伤后3小时内给药有益，3小时后给药似乎有害。**PROPPR**（2015年）在680名患者中比较了血浆、血小板和红细胞1:1:1与1:1:2的比例。它发现24小时和30天的死亡率没有显著差异，但1:1:1组中更多患者实现了止血，最初24小时内死于失血的人更少。这些发现支持早期、平衡的血液制品复苏（[[blood/transfusion]]）。

::: warning
**两升生理盐水不是出血的复苏策略。**大量晶体液会稀释凝血因子和血小板、使患者降温、加重酸中毒（0.9%生理盐水增加氯负荷），并使血压升高到足以冲掉脆弱的血凝块。对出血的创伤患者，首要任务是止血和输注血液制品。在获取血液的同时，晶体液仅限于小剂量推注。
:::

## 胸部损伤

胸部损伤占创伤死亡的四分之一或更多，但大多数无需开胸即可处理：胸腔引流和良好的镇痛足以处理大多数病例。有几种是立即危及生命的，必须在初级评估中发现。

- **张力性气胸：**空气通过单向活瓣进入胸膜腔而无法排出。压力升高，肺萎陷，纵隔被推向对侧，回心血量减少。体征有呼吸窘迫、低氧、心动过速、低血压、患侧呼吸音减弱和叩诊过清音、气管偏向对侧（晚期体征）以及颈静脉怒张（低血容量时可缺如）。这是一个**临床诊断**，应立即减压（针刺或手指胸腔造口，成人通常在第4或第5肋间、腋中线稍前方），然后放置胸腔引流管。
- **开放性气胸：**空气经胸壁伤口被吸入。用带排气阀的敷料覆盖，并放置胸腔引流管。
- **大量血胸：**胸膜腔内大量积血（如放置引流时超过1500 mL，或持续丢失约200 mL/h）。它同时引起低血容量和呼吸功能受损，常需开胸。
- **连枷胸：**相邻两根或以上肋骨各有两处或以上骨折，形成反常运动的胸壁节段。导致低氧的是其下方的肺挫伤。治疗为镇痛（常用区域镇痛）、给氧和通气支持；对部分患者采用手术肋骨固定。
- **心脏压塞：**心包内积血限制心脏充盈，通常发生在穿透伤后。体征有低血压、颈静脉怒张和心音遥远（Beck 三联征），但常常缺如。超声可显示积液。治疗是手术：对穿透性胸部损伤后心脏骤停或濒临骤停的患者施行**复苏性开胸术**。

老年人的肋骨骨折值得特别提及。几根肋骨骨折年轻人可以耐受，却可能使80岁的老人发生肺炎、呼吸衰竭和死亡。这些患者需要尽早有效的镇痛、物理治疗和密切监测。

## 腹部与骨盆损伤

腹部损伤由**钝性**创伤（交通事故、跌落、殴打）或**穿透性**创伤（刺伤和枪伤）引起。在钝性创伤中，最常受伤和出血的是实质性器官，即**脾和肝**。空腔脏器（肠、膀胱）受伤较少，但可能引起在数小时内逐渐发展的腹膜炎。

评估取决于血流动力学是否稳定：

- **不稳定**且有腹腔出血征象（FAST 阳性或明显腹膜炎）的患者：直接送往手术室**剖腹探查**，部分病例行介入放射治疗。
- **稳定**的患者：**静脉增强 CT** 明确损伤。稳定患者的许多实质器官损伤现在采用**非手术治疗**，包括观察、反复检查，以及在有活动性造影剂外溢时进行栓塞。

**骨盆环骨折**可引起大出血，主要来自骨盆内的静脉和骨折断面。不应通过用手"挤压"骨盆来检查其稳定性，因为这会扰动血凝块。对怀疑骨盆骨折并有休克的患者，应在股骨大转子水平放置**骨盆带**，以闭合并稳定骨盆环。然后通过血管栓塞、腹膜外填塞或外固定控制出血。尿道口有血时应怀疑尿道损伤；不要强行插导尿管，应征求泌尿外科意见。

::: example 高处坠落 {#ex-fall}
一位28岁男性从6米高的脚手架上侧身坠落。到达时，他的气道通畅，呼吸频率26次/分，吸氧下 SpO₂ 94%，心率132次/分，血压84/50 mmHg，GCS 14。左下肋部有压痛，骨盆疼痛。急救人员已为他放置了骨盆带。描述初级评估的优先事项和可能的出血来源。
::: solution
**<C>：**没有灾难性外出血。

**A：**通畅；鉴于受伤机制，限制颈椎活动。

**B：**呼吸急促伴下肋部压痛；寻找气胸和血胸（胸部检查、超声或胸部 X 线片），需要时减压或引流。

**C：**他处于休克状态（心动过速、低血压）。可能的来源：**脾**（左下肋损伤）、**骨盆**（高处坠落后骨盆疼痛）、胸部和长骨。启动大出血预案；经大口径通路输注血液制品；给予氨甲环酸；检查骨盆带是否正确地放在大转子处。FAST 可能显示腹腔游离液体。

**D：**GCS 14 可能反映休克或颅脑损伤；检查瞳孔和血糖。

**E：**暴露，在尽量减少活动的情况下检查背部，并保暖。

**决策。**如果他对输血只有短暂反应，就需要立即控制出血：FAST 阳性时剖腹处理脾出血，如果骨盆是出血来源则行骨盆血管栓塞或填塞。复合手术室可同时进行两者。如果他稳定下来，全身 CT 将明确损伤并指导治疗，可能包括脾栓塞。
:::
:::

## 颅脑损伤

创伤性脑损伤是年轻人严重创伤后最常见的死因。**原发性损伤**发生在撞击的瞬间。**继发性损伤**在随后数小时至数天内发生，源于低氧、低血压、颅内压升高、抽搐以及低血糖或高血糖。急救无法逆转原发性损伤；其目的是预防继发性损伤。

**格拉斯哥昏迷评分（GCS）**通过三个方面的最佳反应来衡量意识：

| 睁眼（E） | 言语反应（V） | 运动反应（M） |
|---|---|---|
| 4 自发睁眼 | 5 定向正常 | 6 遵嘱活动 |
| 3 声音刺激睁眼 | 4 言语错乱 | 5 疼痛定位 |
| 2 压力刺激睁眼 | 3 只能说词语 | 4 正常屈曲（回缩） |
| 1 不睁眼 | 2 只能发声 | 3 异常屈曲 |
| | 1 无言语 | 2 伸展 |
| | | 1 无反应 |

总分范围为3到15，报告时应始终注明各项分值（如 E2 V3 M5 = 10）。GCS 为8分或以下通常意味着患者无法保护气道，需要插管。颅脑损伤分为**轻度**（GCS 13–15）、**中度**（9–12）和**重度**（3–8）。

NICE 指南 NG232（2023年）规定了哪些患者需要头颅 CT。成人**1小时内**行 CT 的指征包括：在急诊科初次评估时 GCS 低于13，受伤后2小时 GCS 低于15，怀疑开放性或凹陷性颅骨骨折，颅底骨折征象（鼓室积血、"熊猫眼"、耳或鼻脑脊液漏、Battle 征），外伤后抽搐，局灶性神经功能缺损，以及呕吐超过一次。服用抗凝药的头部受伤者，即使没有上述特征，也应在8小时内行 CT。

**硬膜外血肿**通常由颞骨骨折下方的脑膜中动脉撕裂引起，典型表现为短暂意识丧失后出现**中间清醒期**，随后迅速恶化。**急性硬膜下血肿**由桥静脉撕裂引起，更为常见，尤其是在老年人和服用抗凝药者中，常伴有其下方的脑损伤。两者都可能需要紧急神经外科清除。颅内压升高和脑疝的征象包括 GCS 下降、单侧瞳孔散大以及库欣反应（高血压伴心动过缓）。

## 脊柱损伤

任何具有危险受伤机制、颈部或背部疼痛或神经症状的患者，都必须怀疑脊柱损伤。在排除损伤之前要限制脊柱活动，但不再对每位患者常规使用硬质颈托：目前的做法强调**手法轴线固定**、小心搬运以及尽量缩短在硬质担架板上的时间，因为后者会造成压力性损伤。NICE NG41 和加拿大颈椎规则等临床决策规则指导哪些人需要影像检查；成人颈椎首选 CT，有神经功能缺损时行 MRI。

**神经源性休克**发生于约 T6 以上的脊髓损伤：交感神经输出丧失导致低血压伴**心动过缓**和外周温暖。必须将其与失血性休克区分，因为它可能掩盖后者。

## 烧伤

烧伤按其**范围**（占全身体表面积的百分比，%TBSA）和**深度**评估。浅表（表皮）烧伤发红、疼痛但无水疱，如晒伤，**不**计入 %TBSA。**九分法**可快速估计成人面积：头部9%，每侧上肢9%，躯干前面18%，躯干后面18%，每侧下肢18%，会阴1%。**Lund-Browder 图表**更为准确，并考虑到儿童头部较大、下肢较小的特点。患者手掌连同手指约占其体表面积的1%。

深度决定愈合。浅表部分皮层烧伤呈粉红色、有水疱且疼痛，两周内愈合。深部分皮层和全层烧伤颜色较苍白或呈白色、皮革样、疼痛较轻（神经末梢被破坏），通常需要切痂植皮。

大面积烧伤因毛细血管渗漏而大量丢失液体。在英国，成人烧伤面积超过约15% TBSA、儿童超过10%时，通常开始正规的液体复苏。传统的 **Parkland 公式**给出受伤后最初24小时的晶体液（通常为哈特曼液）量：

$$
V = 4\ \text{mL} \times \text{体重 (kg)} \times \%\text{TBSA}
$$ {#eq-parkland}

一半在**受伤后**（而不是到达后）最初8小时内输入，其余在随后16小时内输入。这个公式只是一个起点。包括 ATLS 在内的许多方案现在对成人从2 mL/kg/%TBSA 开始，以减少过度复苏（"液体蔓延"），后者会导致水肿、骨筋膜室综合征和呼吸衰竭。补液速度根据尿量每小时调整，成人目标通常约为0.5 mL/kg/h，儿童为1 mL/kg/h。

::: widget plot

x: 0, 24
y: 0, 30
sliders: r=4:2:4:2; w=70:10:120:5; b=30:15:80:5

:::

烧伤的其他优先事项包括：尽早识别**气道烧伤**（密闭空间内烧伤、面部烧伤、鼻毛烧焦、口中有烟灰、声音嘶哑或喘鸣），可能需要在肿胀使插管变得不可能之前尽早插管；吸入烟雾后的**一氧化碳**和**氰化物**中毒；胸部或肢体环形全层烧伤限制呼吸或血流时的**焦痂切开术**；镇痛；以及转诊至专科烧伤中心。

::: example 烧伤补液计算 {#ex-parkland}
一位70 kg 的女性于10:00在房屋火灾中发生30% TBSA 的深部分皮层和全层烧伤。她于12:00到达急诊科。按传统 Parkland 公式，她在最初24小时内应接受多少液体？12:00至18:00之间的输注速度是多少？
::: solution
**总量：**烧伤后最初24小时 $4 \times 70 \times 30 = 8400$ mL。

**最初8小时（10:00至18:00）：**总量的一半，4200 mL。

**已输入量：**假设急救人员在到达前已输入500 mL。那么12:00至18:00之间还需输入 $4200 - 500 = 3700$ mL。

**速度：**$3700\ \text{mL} \div 6\ \text{h} \approx 617$ mL/h。

**之后：**其余4200 mL 在随后16小时内输入（约263 mL/h）。

根据她的尿量每小时**调整**速度（目标约 $0.5 \times 70 = 35$ mL/h）。若采用较低的起始值2 mL/kg/%TBSA，24小时总量为4200 mL；无论使用哪个公式，关键在于患者的反应。鉴于是房屋火灾，她还需要评估气道烧伤和一氧化碳中毒。
:::
:::

## 特殊人群

**儿童**的头部相对身体较大，气道位置更靠前且较软，生理储备更大：他们能维持血压直至晚期，然后突然恶化。剂量、液体量和器械型号都按体重确定。损伤与病史不符或就诊延迟时，应引起对**非意外伤害**的警惕，并遵循儿童保护程序（[[paediatrics/safeguarding]]）。

**老年人**常因低能量机制（如站立高度跌倒）而受重伤。他们可能不出现心动过速（β受体阻滞剂、储备下降），其"正常"血压可能已是相对低血压，抗凝药增加出血，尤其是颅内出血。对老年患者分诊不足是一个公认的问题；NICE 和创伤网络现在已把年龄和抗凝药使用纳入分诊。

**妊娠期**生理发生变化：血容量增加，因此休克体征出现较晚，胎儿可能在母亲出现体征之前就已受到损害。约20周以后，女性平卧时子宫压迫下腔静脉，因此要将子宫**手法向左推移**或采取左侧倾斜体位。对胎儿最好的治疗是对母亲进行有效的复苏。Rh 阴性女性在腹部创伤后接受抗 D 免疫球蛋白。约20周以后发生孕产妇心脏骤停时，在骤停后约5分钟内施行**复苏性子宫切开术**（濒死剖宫产）可改善孕产妇复苏。

::: quiz
一位75岁男性服用β受体阻滞剂和阿哌沙班，从楼梯上摔下。他的心率72次/分，血压118/70 mmHg（平时为160/90）。他嗜睡。哪种说法是正确的？
- [ ] 他的心率正常，可以排除明显出血
- [x] 他可能处于休克状态，抗凝治疗增加了颅内出血的风险
- [ ] 由于受伤机制是低能量的，可以按轻伤处理
- [ ] 如果他的 GCS 恢复到15，就不需要头颅 CT
::: solution
β受体阻滞剂会钝化心动过速反应，而118的血压远低于他平时的160，因此对他而言可能已经是低血压。老年人跌倒可造成严重损伤，抗凝治疗增加颅内出血的风险。他需要全面的创伤评估，并按 NICE NG232 行头颅 CT，如发现出血则逆转抗凝。
:::
:::

::: example 股骨骨折的幼儿 {#ex-child}
一个2岁男孩因大腿肿胀被带来就诊。父母说他昨天从沙发上摔下来。X 线片显示股骨螺旋形骨折。他的背部和耳部还有不同时期的瘀伤。应如何处理？
::: solution
**首先是临床处理：**镇痛、夹板固定和骨折的骨科处理。

**担忧：**尚不能独立行走的儿童发生股骨骨折、就诊延迟、耳部和背部（跌倒时通常不会受伤的部位）的瘀伤，以及不同时期的瘀伤，都是引起**非意外伤害**担忧的特征。从沙发上摔下通常不会使幼儿发生这种骨折。

**行动：**仔细、客观地记录病史和检查结果；通知上级医生；遵循当地儿童保护程序，包括与儿科保护团队和儿童社会照护部门讨论；并安排进一步检查，通常包括全身骨骼检查，根据年龄和发现还可能包括脑部影像和眼科检查。目的是在公正评估解释的同时保护儿童；要如实告诉父母这些担忧和处理过程。
:::
:::

::: history
1966年，美国国家科学院国家研究委员会发表了《意外死亡与残疾：现代社会被忽视的疾病》（*Accidental Death and Disability: The Neglected Disease of Modern Society*），指出受伤者常在设备简陋的医院中由未经培训的人员救治。这份报告促成了急救医疗服务和创伤救治体系的建立。1976年，骨科医生詹姆斯·斯泰纳（James Styner）驾驶的轻型飞机在内布拉斯加州农村坠毁；他的妻子遇难，孩子们重伤，而他们在当地一家小医院接受的救治混乱无序。他说："如果我在现场用有限的资源都能比我和孩子们在基层医疗机构得到的救治做得更好，那么这个体系就出了问题。"他与同事于1978年开发了首期高级创伤生命支持课程，美国外科医师学会于1980年采纳了该课程，如今它已在全世界讲授。
:::

## 后续内容

休克与液体治疗见[[emergency-critical-care/shock-fluids]]，复苏见[[emergency-critical-care/resuscitation]]，大规模伤亡事件见[[emergency-critical-care/major-incidents]]。骨折的处理在[[surgery/orthopaedics]]中继续讨论，输血见[[blood/transfusion]]。

::: summary
- 创伤救治体系把伤势最重的患者送往**严重创伤中心**；团队借助结构化预警同时开展工作。
- **初级评估（<C>ABCDE 或 xABCDE）**按顺序发现并处理生命威胁：灾难性出血、气道及脊柱保护、呼吸、循环、神经功能障碍、暴露。
- 成人血容量约 **70 mL/kg**。失血分级只是近似；低血压是晚期体征，乳酸或碱缺失可更早揭示休克。
- **损伤控制性复苏**：止血、允许性低血压（脑损伤除外）、平衡的血液制品、**3小时内**使用氨甲环酸，并预防低体温、酸中毒和凝血功能障碍组成的**致死三联征**。
- 立即危及生命的胸部损伤包括张力性气胸（临床诊断）、大量血胸、开放性气胸、连枷胸和心脏压塞。
- 稳定的腹部损伤用 CT 评估，常采用非手术治疗；不稳定者送往手术室。**骨盆带**可控制骨盆环出血。
- 颅脑损伤的救治旨在预防**继发性损伤**；GCS 按各项分值报告；NICE NG232 规定了 CT 指征。
- 烧伤：评估 %TBSA（不计浅表烧伤）和深度；Parkland 公式 **4 mL/kg/%TBSA**，一半在烧伤后最初8小时内输入，按尿量滴定；注意气道。
- 儿童、老年人和孕妇的休克表现不同；对儿童要考虑非意外伤害。
:::

## 习题

::: exercise 安排初级评估的顺序 {level=1}
一位摩托车手大腿畸形，有搏动性出血浸透敷料，呼吸有杂音且口中有血，呼吸频率30次/分，GCS 11。这些问题按什么顺序处理？每一项做什么？
::: solution
1. **<C> 灾难性出血：**首先用直接压迫控制大腿的搏动性出血，必要时使用止血带。2. **气道：**吸除血液，使用气道手法和辅助装置，同时限制颈椎活动；可能需要确定性气道，尤其是 GCS 11 且气道内有血时。3. **呼吸：**评估呼吸急促的原因（气胸、血胸、挫伤），给氧。4. **循环：**评估休克，建立通路，输注血液制品，用夹板固定股骨以减少出血。5. **神经功能障碍：**GCS 各项分值、瞳孔、血糖。6. **暴露：**全面检查并保暖。在团队中，其中几项同时进行，但组长要掌握优先顺序。
:::
:::

::: exercise 血容量 {level=1 check="1680"}
以血容量70 mL/kg 计算，估计一位80 kg 成人进入 III 级失血（血容量的30%）时的失血量（毫升）。
::: solution
血容量：$70 \times 80 = 5600$ mL。其30%为 $0.3 \times 5600 = 1680$ mL。
:::

::: exercise GCS 评分 {level=1 check="10"}
一位男性头部受伤后，只有在挤压斜方肌时才睁眼，说出不恰当的词语，并能把手移向疼痛刺激处以推开它。他的 GCS 总分是多少？
::: solution
压力刺激睁眼：E2。不恰当的词语：V3。疼痛定位：M5。总分 $2 + 3 + 5 = 10$，报告为 E2 V3 M5 = 10，属于中度颅脑损伤。按 NICE NG232（初次评估时 GCS 低于13），他需要在1小时内行 CT，并密切观察气道。
:::
:::

::: exercise 烧伤补液速度 {level=2 check="700"}
一位70 kg 的男性烧伤面积30% TBSA。按4 mL/kg/%TBSA 计算，总量的一半要在烧伤后最初8小时内输入。他在烧伤后2小时到达，尚未输液。为了按计划进行，接下来6小时的输注速度应为多少 mL/h？给出精确值。
::: hint
最初8小时的液体量现在必须在剩余的6小时内输入。
:::
::: solution
总量：$4 \times 70 \times 30 = 8400$ mL；最初8小时的量：4200 mL。最初8小时中剩余的时间：6小时。速度：$4200 \div 6 = 700$ mL/h。然后根据尿量调整速度（70 kg 时目标约35 mL/h）。
:::
:::

::: exercise 休克而胸部安静 {level=2}
一位40岁女性左胸胸骨外侧第5肋间被刺伤。她心率130次/分，血压75/50 mmHg，颈静脉怒张，双侧呼吸音对称。最可能的诊断是什么？如何确认？治疗是什么？
::: solution
**最可能：**心脏压塞。心前区刺伤伴低血压和颈静脉怒张，且呼吸音对称（使张力性气胸的可能性较小），符合这一诊断。**确认：**床旁超声（FAST 心包切面）显示心包积液；如果她在恶化，不要为了正式影像检查而延误治疗。**治疗：**立即手术减压并修补心脏伤口；如果她足够稳定可以到达手术室，则在手术室行胸骨切开术；如果她发生心脏骤停或濒临骤停，则在急诊科行**复苏性开胸术**。在无法立即手术时，心包穿刺只是一种临时措施。在准备的同时输血。
:::
:::

::: exercise 抗凝患者的头部损伤 {level=2}
一位82岁女性因心房颤动服用阿哌沙班，跌倒时撞到头部。她没有意识丧失，没有呕吐，GCS 15，没有局灶体征。她需要头颅 CT 吗？什么时候做？如果 CT 显示急性硬膜下血肿会怎样？
::: solution
按 NICE NG232，服用抗凝药的头部受伤者，即使没有其他指征，也应在受伤后8小时内行头颅 CT。如果显示急性硬膜下血肿，应紧急逆转她的抗凝作用（对于阿哌沙班，按当地方案使用特异性逆转剂如 andexanet alfa，或使用凝血酶原复合物浓缩物），并与神经外科团队讨论。治疗取决于血肿大小、中线移位和她的神经状态；她的整体衰弱程度和意愿也是决策的一部分。她还需要定期的神经系统观察。
:::
:::

::: exercise 解读骨盆 X 线片 {level=3}
一位35岁的司机在正面碰撞后，输注2单位红细胞后心率140次/分，血压70/40 mmHg。胸部 X 线片正常，FAST 未见游离液体，骨盆 X 线片显示耻骨联合明显分离和右侧骶髂关节增宽（"开书样"骨折）。尿道口有血。解释休克的来源和处理，包括两件不应做的事。
::: solution
**来源：**骨盆环骨折。开书样损伤使骨盆容积增大，撕裂静脉丛和骨折断面，有时也撕裂动脉。胸部 X 线片正常和 FAST 阴性使胸腔和腹膜腔成为出血来源的可能性较小（尽管 FAST 不能排除腹膜后出血）。**处理：**检查骨盆带是否正确地放在大转子上；继续大出血预案，输注平衡的血液制品和氨甲环酸；为患者保暖；并根据当地资源，紧急通过**血管栓塞**、**腹膜外填塞**或**外固定**控制出血。**不要：**反复挤压骨盆检查稳定性，这会扰动血凝块；也不要盲目插入导尿管，因为尿道口有血提示尿道损伤——需要泌尿外科意见以及逆行尿道造影或耻骨上膀胱造瘘。
:::
:::

::: exercise 一个失败的体系 {level=3}
一位19岁行人夜间被汽车撞伤，被送往最近的一家小医院，该医院没有 CT，下班后也没有在院的外科医生。他的 GCS 为9，有不稳定的骨盆骨折。安排转往严重创伤中心花了3小时，他在转运途中死于出血。分析问题出在哪里，以及创伤网络应如何预防此类事件。
::: solution
**问题所在：**现场分诊决定把他送到了一家无法处理其损伤的医院，因此在两个地方耽误了时间：在第一家医院停留的时间和安排转运的时间。在出血时，获得确定性止血的时间至关重要。可能的促成因素包括未应用分诊工具、没有预警、缺乏明确的转运方案，以及没有及早开始输注血液制品和氨甲环酸的机制。

**预防：**建立区域网络，制订明确的**院前分诊工具**，把有严重损伤征象（GCS 低、骨盆不稳定、生理指标异常）的患者直接送往严重创伤中心，即使路程更长也在所不惜；提供能够输注血液制品和氨甲环酸的院前重症救治团队；严重创伤中心实行**"不拒收"政策**，紧急转运只需一个电话；创伤单元配备足够的人员和设备，以便在患者确实到达时迅速稳定并转运。通过 TARN 式数据和并发症与死亡病例讨论审计每一例死亡，以发现失误，并应公开上报和审查这一病例。
:::
