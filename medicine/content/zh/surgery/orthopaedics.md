骨科学是关于骨、关节、韧带、肌腱和脊柱的外科。它处理各种损伤，从腕部骨折到严重毁损的下肢，也处理关节炎、畸形和背痛等慢性疾病。每个急诊科的工作中有很大一部分涉及肌肉骨骼系统，而英国最常见的严重骨折，即老年人的髋部骨折，既是外科急症，也同样是内科和社会急症。

本章介绍骨折愈合和骨折处理原则、骨科急症（开放性骨折、骨筋膜室综合征、关节脱位、马尾综合征和化脓性关节炎）、髋部骨折路径、常见骨折和损伤、骨与关节感染、儿童骨科、骨肿瘤以及关节置换。指南以英国为主（NICE，包括关于髋部骨折的 CG124，以及英国骨科协会创伤标准 BOAST），内容截至2026年。个体患者的处理遵循当地方案。骨折生物学和骨病的内科方面在[[musculoskeletal/fractures]]和[[musculoskeletal/bones-joints]]中有进一步介绍。

## 骨折如何愈合

::: definition 骨折愈合 {#def-fracture}
**骨折**是骨的连续性中断。愈合恢复的是骨而不是瘢痕组织，并经历相互重叠的几个阶段：

1. **血肿与炎症**（数天）：骨折端出血形成血肿；炎症细胞和生长因子到达。
2. **软骨痂**（约第1–3周）：成纤维细胞和成软骨细胞形成跨越骨折间隙的纤维组织和软骨，新生血管长入。
3. **硬骨痂**（数周至数月）：软骨经软骨内成骨被编织骨取代。此时骨折达到临床愈合：无压痛，无活动。
4. **重塑**（数月至数年）：编织骨被板层骨取代，并按其承受的负荷塑形（Wolff 定律）。在儿童中，重塑可以纠正相当大的成角。

这种经过骨痂的途径称为**二期（间接）骨愈合**，发生在骨折被固定后仍有一定活动度时（**相对稳定**），如石膏、髓内钉或桥接钢板固定。当骨折块被加压在一起而没有活动时（**绝对稳定**），如加压钢板或拉力螺钉固定，骨以**一期（直接）骨愈合**的方式愈合，骨单位直接跨越骨折线，看不到骨痂。
:::

儿童、松质骨（干骺端）和血供良好的骨愈合较快。妨碍愈合的因素有吸烟、糖尿病、营养不良、长期大剂量使用 NSAID（证据不一）、感染、骨折处活动过多、固定过于坚强而留有间隙，以及血供差。一些部位因血供从一端进入而易发生**缺血性坏死**：**舟骨**（近极）、**股骨头**（囊内股骨颈骨折后）和**距骨**。

骨折在不良位置愈合称为**畸形愈合**。未能在预期时间内愈合称为**延迟愈合**，完全不愈合称为**骨不连**，后者可能由于生物学条件差（萎缩性骨不连），也可能由于活动过多（肥厚性骨不连，骨痂丰富但未桥接）。

## 处理原则

骨折的处理常概括为**复苏、复位、固定、康复**。

- **复苏：**先治疗患者，再治疗骨折。长骨或骨盆骨折可引起大量失血，其他部位危及生命的损伤优先处理（[[surgery/trauma]]）。
- **复位：**如果移位不可接受，通过闭合手法或切开手术恢复骨折块的对线。并非所有骨折都需要复位：根据骨的部位、患者的年龄和功能，一定程度的移位是可以接受的。
- **固定：**在愈合期间维持骨折块的位置：吊带、夹板或石膏、牵引，或用钢板螺钉、髓内钉、克氏针或外固定架进行手术固定。
- **康复：**从早期开始通过物理治疗恢复活动、力量和功能；长期制动会导致关节僵硬、肌肉萎缩和血栓形成。

每一处骨折都要系统地**描述**，以便能在电话中交流：患者、骨、侧别、部位（骨干、干骺端、骨骺、关节内）、骨折形态（横形、斜形、螺旋形、粉碎性、多段性、撕脱性）、**移位**（平移、成角、旋转、短缩，以远端骨折块的位置描述）以及是**开放性还是闭合性**。在任何手法操作前后都要检查并记录肢体的神经血管状态。

**手术固定的指征**包括：不手术无法维持在可接受位置的骨折、有移位的关节内骨折（以恢复光滑的关节面并减少以后的关节炎）、开放性骨折、伴血管损伤的骨折、多发伤（以便早期活动）、病理性骨折，以及早期活动至关重要的骨折，如老年人的髋部骨折。

### 骨折的并发症

| 早期（数小时至数天） | 晚期（数周至数年） |
|---|---|
| 出血和休克 | 延迟愈合、骨不连、畸形愈合 |
| 骨筋膜室综合征 | 缺血性坏死 |
| 神经和血管损伤 | 创伤后骨关节炎 |
| 感染（尤其是开放性骨折） | 关节僵硬 |
| 脂肪栓塞综合征 | 复杂区域疼痛综合征 |
| 静脉血栓栓塞 | 生长障碍（儿童骺板损伤） |

**脂肪栓塞综合征**典型地发生在长骨（尤其是股骨）骨折后24–72小时，引起呼吸窘迫、意识模糊以及上半身和结膜的瘀点皮疹。股骨骨折的早期固定可以减少其发生。

## 骨科急症

### 开放性骨折

**开放性骨折**通过伤口与外界相通，因此骨折及其血肿受到污染。**Gustilo–Anderson 分类**在清创时最终确定，对损伤进行分级：I 型（伤口小于1 cm，清洁）、II 型（1–10 cm，无广泛软组织损伤）、IIIA 型（广泛软组织损伤，但骨可以被覆盖）、IIIB 型（骨膜剥离，需要皮瓣覆盖）和 IIIC 型（需要修复的动脉损伤）。

BOA 开放性骨折标准规定了时间要求：

- **尽快静脉使用抗生素，最好在受伤后1小时内**，并按指征预防破伤风；
- 拍摄伤口照片，清除明显的污染物，用生理盐水浸湿的敷料覆盖，并用夹板固定肢体；记录神经血管状态；
- 由顾问骨科医生和整形外科医生共同在**手术室清创**：对严重污染的伤口（农业、水生或污水污染）或血管受损者**立即**进行；其他高能量损伤在**12小时**内；其他开放性骨折在**24小时**内；
- 在受伤后**72小时内完成确定性软组织覆盖**，最好与确定性固定同时进行。

复杂的下肢开放性骨折在有骨科-整形联合团队的专科中心治疗。

::: example 胫骨开放性骨折 {#ex-open}
一位31岁骑自行车者被汽车撞倒。他的右小腿畸形，胫前有一个6 cm 的伤口，可见骨外露，伤口内有泥土。足部温暖，脉搏可触及，感觉正常。紧急步骤和时间要求是什么？
::: solution
**评估：**完成初级评估后，这是一例高能量的**胫骨开放性骨折**，伤口较大（至少为 Gustilo II 型，很可能为 III 型；最终分级在清创时确定）。

**紧急步骤：**

1. 受伤后1小时内按当地指南**静脉使用抗生素**（通常为阿莫西林克拉维酸或头孢菌素等广谱药物），并根据他的免疫接种情况预防破伤风。
2. 镇痛；**拍摄**伤口照片留档；清除明显的污染物；用生理盐水浸湿的敷料和不透水薄膜覆盖；不要反复查看伤口。
3. 恢复对线并用**夹板**固定肢体；复查并记录脉搏、毛细血管再充盈和感觉（包括腓深神经和胫神经）。
4. 监测**骨筋膜室综合征**，即使是开放性骨折也可能发生。

**时间：**泥土污染使这成为一个严重污染的伤口，因此应**立即**清创；否则高能量损伤应在12小时内由骨科和整形外科医生共同清创。可以使用临时固定（常为外固定架），在72小时内完成确定性固定和软组织覆盖（可能需要皮瓣）。
:::
:::

### 骨筋膜室综合征

::: theorem 骨筋膜室综合征降低灌注压 {#thm-compartment}
四肢的肌肉位于由无弹性筋膜包围的间室内。如果间室内压力升高，例如骨折或再灌注后出血或肿胀，就会压迫静脉和毛细血管。组织灌注取决于动脉压与间室压之差。当这一**灌注压**降得过低时，肌肉和神经发生缺血，进而引起更多肿胀，形成恶性循环，除非切开间室，否则数小时内就会导致肌肉坏死。
:::

::: proof
只有当驱动血液的压力超过周围组织的压力时，血液才能流过毛细血管。随着间室压升高，低压的静脉首先塌陷，因此流出受阻而动脉流入仍在继续；毛细血管压升高，更多液体渗入组织，间室压进一步升高。由于筋膜不能伸展，容积的少量增加就会引起压力的大幅升高。远端脉搏通常仍可触及，因为大动脉的压力远高于间室压；这就是为什么可触及脉搏不能排除骨筋膜室综合征。临床上有用的指标是 **Δ压（delta pressure）**：舒张压减去间室压。Δ压**低于30 mmHg** 提示灌注不足，是筋膜切开术的指征。
:::

主要症状是**与损伤不相称的疼痛**，尤其是**被动牵拉**间室内肌肉时的疼痛（例如被动伸展足趾会牵拉小腿后深间室）。随后出现感觉异常、张力性肿胀，较晚出现肌力减弱。苍白和无脉是**晚期**征象；等待它们出现就是在等待肌肉坏死。常见的情况有胫骨骨折、前臂骨折、挤压伤、血管修复后再灌注、石膏过紧，以及长时间不能活动者的肢体长时间受压。

处理方法是去除所有**环形敷料并将石膏剖开**直至皮肤，使肢体保持在心脏水平（抬高会减少动脉流入），如患者低血压则恢复血压；如果症状不能迅速缓解，紧急行**筋膜切开术**，打开所有间室（小腿有四个）。当临床评估不可靠时，例如在昏迷或镇静的患者中，可以测量间室压。

::: example 挤压后的前臂 {#ex-compartment}
一位40岁男性的前臂被机器压住2小时。他前臂剧痛，被动伸展手指时加重。血压110/60 mmHg，测得的屈肌间室压为42 mmHg。是否需要筋膜切开术？
::: solution
**Δ压：**$60 - 42 = 18$ mmHg，远低于30 mmHg。

**临床表现：**挤压伤后疼痛与损伤不相称和被动牵拉痛是骨筋膜室综合征的典型表现；可触及桡动脉搏动也不会改变这一判断。

**决定：**需要，紧急行前臂间室**筋膜切开术**。注意，他的舒张压相对较低，使灌注衰竭的阈值降低；恢复血压是治疗的一部分，但不得因此延误手术。挤压伤后还要检查肌酸激酶、血钾和肾功能，以发现横纹肌溶解。
:::
:::

### 关节脱位与神经损伤

**脱位**是关节面之间完全失去接触。在拍摄 X 线片并记录神经血管状态之后，需要及时复位：

- **肩关节：**大多数为**前脱位**，发生在跌倒时手臂外展、外旋并伸直撑地之后。**腋神经**（支配"肩章区"感觉和三角肌功能）有受损风险。后脱位发生在癫痫发作和电击之后，容易漏诊。
- **髋关节：**后脱位，通常由车祸中的仪表盘损伤引起，下肢短缩、屈曲、内收和内旋；**坐骨神经**有受损风险，由于有股骨头缺血性坏死的风险，复位很紧急。在日常实践中，髋关节置换后脱位更为常见。
- **膝关节：**胫股关节（而非髌骨）脱位是威胁肢体的损伤，因为**腘动脉**常常受损；即使复位后也需要进行血管评估（ABPI、影像检查）。

### 马尾综合征

**马尾综合征**是脊髓末端以下的腰骶神经根受压，最常由巨大的中央型腰椎间盘突出引起。症状包括背痛和坐骨神经痛（常为双侧）、**鞍区麻木**、**膀胱功能障碍**（感觉减退、排尿起始困难、尿潴留）以及肠道或性功能障碍。一旦发展为无痛性尿潴留伴充溢性尿失禁，膀胱功能恢复的预后就较差。任何怀疑马尾综合征的患者都需要**急诊 MRI**，并转诊至脊柱外科团队进行减压。对背痛患者的安全警示建议应包括这些症状（[[musculoskeletal/back-pain]]）。

## 髋部骨折路径

英国每年约有7万人发生髋部骨折，大多是衰弱的老年人在站立高度跌倒后发生。约四分之一或更多的人在一年内死亡，许多人无法恢复到以前的独立水平。因此，髋部骨折按照一条协调的路径进行处理。

::: definition 髋部骨折的类型及其手术 {#def-joint}
髋部骨折按其与髋关节囊的关系分类：

- **囊内**（股骨颈）骨折可破坏股骨头的血供，后者主要来自沿股骨颈上行的支持带血管。**Garden 分类**对其进行描述：I 型不完全骨折，II 型完全骨折但无移位，III 型完全骨折伴部分移位，IV 型完全移位。无移位骨折（Garden I–II 型）通常用螺钉或滑动髋螺钉固定。**有移位**骨折（Garden III–IV 型）发生缺血性坏死和骨不连的风险高，因此要置换股骨头：**半髋关节置换术**；对于能独立在户外行走、最多使用一根手杖、无认知障碍且身体状况适合的人，行**全髋关节置换术**（NICE CG124）。
- **囊外**骨折（转子间和转子下骨折）不威胁股骨头的血供，因此予以固定：大多数转子部骨折用**滑动髋螺钉**，转子下骨折用**髓内钉**。
:::

患者典型地在跌倒后就诊，不能负重，**下肢短缩并外旋**。X 线片（骨盆正位和髋关节侧位）通常可显示骨折；如果 X 线片正常而病史和体格检查提示骨折，则用 **MRI**（不能做 MRI 时用 CT）寻找隐匿性骨折。

NICE CG124 建议：

- **在入院当天或次日手术**；
- 到达后立即镇痛，包括**神经阻滞**（髂筋膜或股神经阻滞）和规律服用对乙酰氨基酚，慎用阿片类药物；
- 从入院开始提供**骨科老年医学**照护，在准备手术的同时迅速进行内科优化，而不是一连串的拖延；
- 手术应使患者术后能够立即**完全负重**；
- 术后次日由物理治疗师帮助**下床活动**；
- 评估**骨骼健康**和**跌倒风险**，以预防下一次骨折。

**国家髋部骨折数据库**对英格兰、威尔士和北爱尔兰的每家医院审计这些标准。病例的内科方面见[[surgery/perioperative-care]]。

::: example 服用抗凝药者的髋部骨折 {#ex-warfarinhip}
一位86岁女性患心房颤动，服用华法林，在养老院跌倒，发生左股骨颈有移位的囊内骨折（Garden IV 型）。她的 INR 为3.1。跌倒前她在养老院内借助助行架行走，有中度痴呆。适合什么手术？应如何处理她的抗凝？
::: solution
**手术：**有移位的囊内骨折要置换股骨头。她不符合全髋关节置换术的标准（不能独立在户外行走，且有认知障碍），因此适合行**骨水泥型半髋关节置换术**，术后可立即完全负重。

**抗凝：**华法林不应使手术延误超过必要的时间。她的 INR 为3.1，对于手术和脊髓麻醉来说过高；用**静脉维生素 K** 逆转，通常在6–12小时内可使 INR 降到足够低的水平，因此她仍可以在入院当天或次日手术。凝血酶原复合物浓缩物仅用于紧急逆转，如出血时。术后给予 VTE 预防，在出血风险允许时重新开始华法林，并讨论她的卒中风险。

**路径：**到达时行髂筋膜阻滞，骨科老年医学评估，预防谵妄（她的痴呆增加了风险），早期活动，评估骨骼健康和跌倒风险。应让她的养老院参与计划她的返回。
:::
:::

## 常见骨折与损伤

- **桡骨远端骨折**在两端年龄段都很常见。**Colles 骨折**（跌倒时手伸直撑地）的远端骨折块向背侧移位和成角（"餐叉样"畸形）；**Smith 骨折**向掌侧移位。许多采用手法复位和石膏固定；不稳定或关节内骨折用掌侧钢板固定。必须注意有无正中神经症状。老年人的桡骨远端骨折是一种**脆性骨折**，应促使对骨质疏松进行评估。
- **舟骨骨折**发生在年轻人跌倒时手伸直撑地之后，引起**解剖学鼻烟窝**压痛，沿拇指轴向挤压时疼痛。最初的 X 线片可能正常。怀疑骨折者要制动，并尽早做 MRI。舟骨近极的血供从远端流向近端，因此近端骨折有**缺血性坏死**和骨不连的风险。
- **踝关节损伤：****渥太华踝关节规则**把 X 线检查限于以下患者：任一踝的后缘或尖端有骨压痛，或者在受伤后即刻和在急诊科都不能负重行走四步（中足也有类似规则：舟骨和第五跖骨基底部）。稳定骨折用靴具治疗；不稳定骨折（累及关节两侧或有距骨移位）通常需要固定。
- **膝关节软组织损伤：****前交叉韧带**断裂（扭转损伤时有"砰"的一声，关节积血导致迅速肿胀，以后出现不稳）、**半月板撕裂**（交锁、关节线压痛）和侧副韧带损伤；MRI 可以确诊。
- **跟腱断裂**发生在突然蹬地之后；挤压小腿时足不发生跖屈（**Simmonds 试验**）。治疗采用功能性支具或修复。

一位22岁男性跌倒时手伸直撑地。他的解剖学鼻烟窝有压痛，但舟骨 X 线片正常。最合适的处理是什么？
- [ ] 安慰他没有骨折，让他出院且不安排随访
- [x] 固定腕关节，安排尽早 MRI 或复查，因为舟骨骨折在最初的 X 线片上可能看不到
- [ ] 安排立即手术固定
- [ ] 向腕关节内注射激素
::: solution
舟骨骨折在最初的 X 线片上常常看不到。漏诊有导致骨不连和近极缺血性坏死的风险，造成长期残疾。临床怀疑的骨折要制动并进一步检查，通常按当地路径做 MRI。
:::

## 骨与关节感染

**化脓性关节炎**是关节的细菌感染。它在数天内破坏软骨，因此是一种急症。*金黄色葡萄球菌*是最常见的病原体；也可见链球菌、*淋病奈瑟菌*（*Neisseria gonorrhoeae*，见于性活跃的年轻成人）、革兰阴性菌（老年和免疫抑制患者）和*金氏金氏杆菌*（*Kingella kingae*，幼儿）。表现为关节红热、肿胀、疼痛，活动范围减小；患者可能发热。危险因素包括原有关节疾病（类风湿关节炎）、人工关节、糖尿病、免疫抑制和注射吸毒。

关键的检查是**在使用抗生素之前进行关节穿刺**（除非患者有脓毒症而抗生素不能等待）：革兰染色、培养、白细胞计数和晶体检查。发现晶体不能排除感染，因为痛风和感染可以并存。要做血培养。治疗为按当地指南静脉使用抗生素，随后长疗程用药，大多数自体关节感染还要进行关节**冲洗**（关节镜或开放手术）。

在儿童中，区分髋关节化脓性关节炎和**一过性滑膜炎**（病毒感染后常见的自限性炎症）很困难。**Kocher 标准**对以下各项各计1分：不能负重、体温高于38.5 °C、ESR 高于40 mm/h 和白细胞计数高于 $12 \times 10^9$/L。在原始研究中，化脓性关节炎的概率随满足标准的数目急剧上升，从一项都不满足时非常低，到四项都满足时非常高；许多中心还使用 CRP 高于20 mg/L。怀疑化脓性关节炎的儿童需要超声检查、穿刺和紧急骨科会诊。

**骨髓炎**是骨的感染。在儿童中通常为**血源性**，累及长骨的干骺端。在成人中更多发生在开放性骨折、手术或糖尿病足溃疡之后，椎体骨髓炎则发生在菌血症之后。MRI 是最敏感的影像检查；骨活检可以确定病原体。治疗结合长疗程抗生素，存在死骨时手术清除死骨。

**假体周围关节感染**发生在一小部分关节置换中。早期感染（术后数周内）可通过清创、抗生素并保留假体来治疗；慢性感染通常需要取出假体，并分一期或二期翻修。疼痛、发热的人工关节、持续渗液的伤口或窦道，应由关节置换团队评估；在穿刺之前不应"盲目"开始使用抗生素，因为这会使病原体更难确定。

::: example 跛行的儿童 {#ex-kocher}
一个6岁女孩从昨天起拒绝用右腿行走。她上周感冒了。体温38.9 °C；她保持髋关节屈曲，抗拒活动。白细胞计数 $16.1 \times 10^9$/L，ESR 52 mm/h，CRP 64 mg/L。超声显示髋关节积液。Kocher 标准提示什么？应该怎么做？
::: solution
**Kocher 标准：**不能负重（1）、体温高于38.5 °C（1）、ESR 高于40 mm/h（1）、白细胞计数高于 $12 \times 10^9$/L（1）：**4项中满足4项**。她的 CRP 也高于20 mg/L。

**解读：**四项标准全部满足，尽管近期有病毒感染，髋关节化脓性关节炎的可能性仍非常大，远大于一过性滑膜炎。

**行动：**紧急骨科会诊；髋关节**穿刺**（在超声引导下或在手术室）做显微镜检查和培养；血培养；然后按当地儿科指南静脉使用抗生素并行**手术冲洗**。延误有破坏股骨头和骺板的风险。

**注意：**这类标准只是辅助临床判断；满足标准较少但临床表现令人担忧的儿童，仍需要穿刺。
:::
:::

## 儿童骨科

儿童的骨骼与成人不同：骨膜厚，骨在断裂之前先弯曲（**青枝骨折**和**隆突骨折**），损伤可累及**生长板（骺板）**，按 **Salter–Harris** 系统分类（I 至 V 型；较高的类型累及关节面或压碎骺板，生长障碍的风险更大）。在关节活动平面上靠近生长板的成角，重塑可以纠正很大一部分，但旋转不能纠正。

跛行的常见原因随年龄而不同：

- **发育性髋关节发育不良（DDH）：**在新生儿和6–8周检查时用 Barlow 和 Ortolani 手法筛查，对检查异常或有危险因素（臀位、家族史）的婴儿做超声检查。早期治疗用 Pavlik 吊带。
- **一过性滑膜炎**（约3–10岁）：急性跛行最常见的原因，发生在病毒感染之后，患儿一般情况良好；是在排除化脓性关节炎之后的排除性诊断。
- **Perthes 病**（约4–8岁，男孩更常见）：股骨头缺血性坏死，表现为跛行和髋部或膝部疼痛。
- **股骨头骨骺滑脱（SUFE）**（青春期早期，常超重）：股骨头经生长板从股骨颈上滑脱。可表现为**膝部疼痛**（经闭孔神经的牵涉痛）、跛行和髋关节内旋受限。治疗为手术穿钉固定；漏诊会导致缺血性坏死和早发关节炎。

骨折与病史不符的幼儿，必须考虑非意外伤害（[[paediatrics/safeguarding]]）。

## 骨肿瘤与骨转移

原发性骨肿瘤很少见；年轻人中最常见的恶性骨肿瘤是**骨肉瘤**（青少年膝关节周围）和**尤文肉瘤**。年轻人出现持续性骨痛（尤其是夜间）、肿块或病理性骨折，需要紧急检查并转诊至骨肿瘤中心，活检应在那里进行。

在成人中，迄今最常见的骨肿瘤是**转移瘤**，来自**乳腺癌、肺癌、前列腺癌、肾癌和甲状腺癌**，以及骨髓瘤。转移瘤削弱骨骼，引起**病理性骨折**、高钙血症和脊髓压迫。在骨折发生之前进行预防性固定可获得更好的功能。**Mirels 评分**估计长骨溶骨性转移灶发生骨折的风险，对四项特征各计1至3分：部位（上肢1，下肢2，转子周围3）、疼痛（轻度1，中度2，功能性即使用时疼痛3）、病变类型（成骨性1，混合性2，溶骨性3）以及大小占骨直径的比例（小于三分之一1，三分之一至三分之二2，大于三分之二3）。总分**9分或以上**提示预防性固定；8分为临界。

## 关节置换

对于终末期骨关节炎，**全髋和全膝关节置换术**是医学中最成功的手术之一，可使大多数患者在15–20年或更长时间内缓解疼痛、恢复功能。当尽管进行了非手术治疗（运动、减重、镇痛），症状仍严重影响生活质量时，才提供关节置换，而不是仅仅根据 X 线表现或年龄（[[musculoskeletal/osteoarthritis]]）。并发症包括感染、脱位（髋）、VTE（预防遵循 NICE NG89）、双下肢不等长、神经损伤、假体周围骨折、持续疼痛（膝关节置换后比髋关节置换后更常见），以及远期需要翻修的松动和磨损。国家关节登记系统记录英国的每一例关节置换，并识别过早失效的假体。

::: warning
**可触及脉搏不能排除骨筋膜室综合征，镇痛需求增加是一个警示信号。**对于胫骨或前臂骨折患者，疼痛不断加重且对强效镇痛无反应，或者患者需要越来越多的阿片类药物，应立即评估是否有骨筋膜室综合征，而不是再给一剂。区域神经阻滞和患者自控镇痛可能掩盖疼痛；高危损伤后接受这些镇痛的患者需要定期评估并记录，在无法评估疼痛时监测间室压。
:::

::: history
1895年威廉·伦琴（Wilhelm Röntgen）发现 X 射线，几周之内它就被用于骨折成像。休·欧文·托马斯（Hugh Owen Thomas）是一位接骨匠的儿子，在利物浦行医，他为股骨骨折设计了托马斯夹板；第一次世界大战期间，他的外甥罗伯特·琼斯（Robert Jones）在西线推广使用这种夹板，据报道它使开放性股骨骨折的死亡率大幅下降。1958年，瑞士 AO 小组（Arbeitsgemeinschaft für Osteosynthesefragen，骨折内固定研究协会）开始发展内固定的原则和器械，这些至今仍在讲授。20世纪60年代初，约翰·查恩利（John Charnley）在兰开夏郡的赖廷顿医院研制了低摩擦全髋关节置换，用小金属球头与高密度聚乙烯相关节，并以丙烯酸骨水泥固定，还引入了洁净空气手术间以减少感染。
:::

::: summary
- 骨折通过骨痂愈合（**二期愈合**，相对稳定）或直接愈合（**一期愈合**，绝对稳定）。舟骨、股骨头和距骨易发生缺血性坏死。
- 处理：**复苏、复位、固定、康复**；系统地描述骨折；记录神经血管状态。
- 开放性骨折：1小时内使用抗生素；严重污染时立即清创，高能量损伤在12小时内，其他在24小时内；72小时内完成软组织覆盖。
- 骨筋膜室综合征：疼痛与损伤不相称，被动牵拉痛；脉搏仍存在；**Δ压 < 30 mmHg**；剖开石膏并行筋膜切开术。
- 马尾综合征需要急诊 MRI 和减压。
- 髋部骨折：入院当天或次日手术；有移位的囊内骨折行置换（半髋或全髋关节置换），囊外骨折行固定；骨科老年医学照护和早期活动。
- 化脓性关节炎：尽可能在使用抗生素之前穿刺，然后用抗生素并冲洗；Kocher 标准有助于儿童的诊断。
- 儿童跛行：按年龄考虑 DDH、一过性滑膜炎、Perthes 病、SUFE（膝部疼痛！）和感染。
- 转移瘤是成人最常见的骨肿瘤；Mirels 评分 ≥ 9提示预防性固定。
- 尽管经保守治疗仍有症状时提供关节置换；感染、脱位和 VTE 是主要风险。
:::

:::

::: exercise Δ压 {level=1 check="78-55"}
一位胫骨骨折患者血压130/78 mmHg，测得前间室压为55 mmHg。计算Δ压（mmHg）。它是否提示骨筋膜室综合征？
::: solution
Δ压 = 舒张压 − 间室压 = $78 - 55 = 23$ mmHg。这低于30 mmHg，提示灌注不足；结合临床情况，需要紧急筋膜切开术。
:::
:::

::: exercise Mirels 评分 {level=1 check="3+3+3+2"}
一位66岁转移性乳腺癌女性，股骨转子间区有一个溶骨性病变，约占骨宽度的一半。她行走时疼痛。计算她的 Mirels 评分。
::: solution
部位，转子周围：3。使用时疼痛（功能性）：3。溶骨性：3。大小，在三分之一至三分之二之间：2。总分 $3 + 3 + 3 + 2 = 11$。9分或以上提示骨折风险高，因此在与她的肿瘤团队讨论后，应考虑预防性固定（如用长髓内钉），通常随后进行放疗。
:::
:::

::: exercise 哪种髋关节手术？ {level=2}
为下列每位患者选择通常的手术并说明理由：(a) 一位78岁的无移位囊内骨折（Garden I 型）患者；(b) 一位打高尔夫球、能独立行走的72岁患者，有移位的囊内骨折；(c) 一位患痴呆、借助助行架行走的88岁患者，有移位的囊内骨折；(d) 一位81岁的转子间骨折患者。
::: solution
(a) 内固定（螺钉或滑动髋螺钉）：无移位骨折时股骨头的血供很可能得以保留（不过有些外科医生会对老年患者考虑关节置换）。(b) **全髋关节置换术**：她能独立在户外行走，无认知障碍，身体状况很可能适合，对这类患者全髋置换的功能优于半髋置换。(c) **半髋关节置换术**（骨水泥型）：由于移位威胁股骨头血供，必须置换股骨头，但鉴于她的活动能力和认知状况，不适合全髋置换。(d) **滑动髋螺钉**：囊外骨折，股骨头血供良好；转子下骨折或反斜形骨折用髓内钉。
:::
:::

::: exercise 肿胀的膝关节 {level=2}
一位58岁类风湿关节炎男性正在服用甲氨蝶呤，左膝红热、肿胀、疼痛2天，体温38.2 °C。他有痛风病史。概述你的处理。如果穿刺液中发现尿酸钠晶体，诊断是否就能确定？
::: solution
**处理：**在被证明不是之前按**化脓性关节炎**处理：免疫抑制和原有关节疾病都是危险因素。在使用抗生素之前进行关节穿刺（除非他有脓毒症而抗生素不能等待），送检革兰染色、培养、白细胞计数和晶体；做血培养、全血细胞计数、CRP 和肾功能；然后按当地指南开始静脉抗生素，如果感染可能性大或已证实，转诊骨科进行冲洗。与风湿科讨论他的甲氨蝶呤。**晶体：**发现尿酸盐晶体**不能**排除感染，因为痛风和化脓性关节炎可以并存。抗生素要继续使用，直到培养结果和临床过程能够排除感染。
:::
:::

::: exercise 青少年的膝部疼痛 {level=2}
一个超重的12岁男孩左膝疼痛4周，并开始跛行。膝关节检查正常。什么诊断绝不能漏掉？如何检查？治疗是什么？
::: solution
**股骨头骨骺滑脱（SUFE）。**由于共同的神经支配（闭孔神经），髋部病变常表现为膝部疼痛，因此对任何膝部疼痛的儿童都**必须检查髋关节**；在 SUFE 中，内旋受限，髋关节屈曲时可能出现外旋。**检查：**双髋正位和**蛙式侧位** X 线片（滑脱可能是双侧的，在侧位片上更容易看到）。**治疗：**紧急骨科转诊，不负重，用一枚螺钉跨越生长板进行手术固定（原位穿钉）；考虑对另一侧髋关节预防性穿钉。延误诊断会增加严重滑脱、缺血性坏死和早发骨关节炎的风险。
:::

::: exercise 复位后减弱的脉搏 {level=3}
一位25岁男性在摩托车事故中发生膝关节脱位，在急诊科复位。复位后，他的足部温暖，足背动脉搏动微弱可及。低年资医生计划收他住院、抬高患肢，第二天早上复查。解释为什么这样做不安全，以及应该怎么做。
::: solution
膝关节脱位常合并**腘动脉损伤**（内膜撕裂和血栓形成），因为该动脉在关节上下两端都被固定。可触及脉搏并不能排除损伤：内膜瓣可在数小时内形成血栓，而侧支血流起初可以维持微弱的脉搏。漏诊的腘动脉损伤会导致缺血、骨筋膜室综合征和截肢。**应该做的：**测量 **ABPI**（低于0.9提示动脉损伤）；如果异常或有任何疑问，安排紧急 **CT 血管造影**或血管外科评估；频繁复查神经血管状态（腓总神经也常受损）；尽早请血管外科医生参与；并监测骨筋膜室综合征。如需血运重建，应在数小时内完成，常同时行筋膜切开术。韧带重建以后再计划。
:::
:::

::: exercise 过紧的石膏 {level=3}
一个9岁女孩前臂骨折手法复位并石膏固定12小时后，尽管服用了对乙酰氨基酚和布洛芬，仍疼得哭泣。她的手指肿胀，被动伸展手指时哭叫。桡动脉搏动可触及。概述你的紧急措施、可能的诊断，以及为什么脉搏并不能令人安心。
::: solution
**紧急措施：**把手臂抬高到心脏水平（不要更高）；沿石膏全长**剖开石膏和所有衬垫直至皮肤**，并将其撑开；几分钟内重新评估。如果疼痛和被动牵拉痛不能迅速缓解，呼叫骨科住院总医师紧急评估**前臂骨筋膜室综合征**并考虑筋膜切开术。**可能的诊断：**肢体肿胀时石膏造成的压迫，或已形成的骨筋膜室综合征；可能性较小的有骨折移位或神经损伤。镇痛需求增加和被动伸指痛是关键的警示信号；在儿童中，"三个 A"（焦虑 anxiety、躁动 agitation 和镇痛需求增加 increasing analgesia requirement）可能是最初的线索。**为什么脉搏不能令人安心：**足以阻断肌肉毛细血管灌注的间室压，远低于阻断桡动脉搏动所需的动脉压，因此脉搏会一直存在到很晚，而那时肌肉可能已经坏死。
:::
