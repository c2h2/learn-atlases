骨科把力学与生物学合在一起：骨折需要复位与固定，而愈合需要血供与合适的负荷；关节置换、骨与软组织的感染与肿瘤，以及脊柱与儿童的病变共同构成这门学科[[musculoskeletal/fractures]]、[[musculoskeletal/bones-joints]]。

本章涵盖骨折科学与固定、关节置换与骨肌肉感染和肿瘤，以及脊柱、儿童与神经肌肉的骨科。

## 骨折与它们的处理

::: definition 骨折科学与固定 {#def-fracture}
**骨折按部位与形态、皮肤是否破（开放或闭合）与是否移位来描述；记录致伤的机制、邻近的关节与神经血管会决定治疗[[musculoskeletal/fractures]]、[[clinical-skills/medical-imaging]]、[[clinical-skills/physical-examination]]。愈合需要血供、稳定与适度负荷：保守治疗（石膏、支具与受保护的负重）与手术固定（髓内钉、钢板螺钉与外固定）各有适应证[[musculoskeletal/fractures]]、[[pathology/chronic-inflammation-repair]]、[[surgery/perioperative-care]]。急症包括开放性骨折（抗生素与清创）、伴血管或神经损伤的骨折与脱位、骨筋膜室综合征与关节内的积血[[surgery/trauma]]、[[musculoskeletal/fractures]]、[[microbiology/antimicrobials]]。并发症：感染与血栓和脂肪栓塞，以及骨不连、畸形愈合与关节僵硬[[surgery/wounds-surgical-infection]]、[[blood/thrombosis-anticoagulation]]、[[nervous-system/motor-systems]]。老年人的髋部骨折应在数小时内手术，并同时处理谵妄与跌倒的预防[[geriatrics-palliative/falls]]、[[geriatrics-palliative/ageing-frailty]]、[[geriatrics-palliative/delirium-dementia-care]]。**
:::

## 关节、感染与肿瘤

::: definition 关节置换、骨肌肉的感染与肿瘤 {#def-joint}
**关节置换用于终末期关节炎的疼痛与功能丧失；假体周围的感染、脱位与无菌性松动是主要的晚期失败[[musculoskeletal/osteoarthritis]]、[[musculoskeletal/inflammatory-arthritis]]、[[surgery/wounds-surgical-infection]]。预防包括适时的抗生素、无菌的流程、保温与血栓预防[[surgery/perioperative-care]]、[[microbiology/infection-control]]、[[blood/thrombosis-anticoagulation]]。急性关节的疼痛需要抽液，以区分结晶性、感染性与炎症性[[microbiology/laboratory-diagnosis]]、[[musculoskeletal/inflammatory-arthritis]]、[[infectious-diseases/fever-sepsis]]。假体周围的感染靠培养、炎症指标与影像，处理可以是保留假体的清创或分期翻修[[microbiology/antimicrobials]]、[[surgery/orthopaedics]]。骨肿瘤要区分原发（骨肉瘤与尤文）与转移（来自乳腺、肺、肾、甲状腺与前列腺）；在可疑病灶上不要贸然内固定，因为不恰当的切口会毁掉保肢的机会，应先由骨肿瘤团队规划活检[[pathology/cancer-diagnosis]]、[[pathology/cancer-biology]]、[[respiratory/lung-cancer-pleura]]。重建、放疗与全身治疗需要在专门的中心进行[[surgery/orthopaedics]]、[[immunology/transplant-tumour-immunology]]。**
:::

## 脊柱、儿童与神经

::: definition 脊柱、儿童与神经肌肉的骨科 {#def-spine}
**下背痛常见而需要手术者少；关键是识别红旗：创伤、发热、癌症史、进行性的神经缺失与马尾的征象[[musculoskeletal/back-pain]]、[[pathology/cancer-diagnosis]]、[[surgery/wounds-surgical-infection]]、[[nervous-system/motor-systems]]。神经根的疼痛（坐骨神经痛）多用镇痛与保持活动治疗，而会阴麻木、尿潴留与双侧缺失构成马尾综合征，需要急症减压与导尿[[musculoskeletal/back-pain]]、[[surgery/perioperative-care]]、[[renal/urinary-tract]]。儿童的骨折要保护生长板，损伤会扰乱骨的发育；儿童的髋与膝的疼痛可能来自股骨头骨骺的病变[[paediatrics/congenital-genetic]]、[[musculoskeletal/fractures]]、[[paediatrics/growth-development]]。神经肌肉的骨科处理脑瘫与痉挛和脊柱的畸形，需要康复团队共同参与[[nervous-system/motor-systems]]、[[paediatrics/neurodevelopment]]、[[public-health/prevention-promotion]]。**
:::

::: example 伴房颤与华法林的髋骨折 {#ex-warfarinhip}
一位83岁在用华法林（房颤与既往卒中）的人跌倒；移位性的囊内骨折；INR 3.4；家属说她基线时有些意识混乱；除了这一点在医学上是稳定的。
::: solution
**髋部骨折的死亡与手术延迟相关，目标是在数小时内手术；INR 3.4需要纠正（维生素K，需要时用因子复合物或新鲜血浆），而不是等它自然下降[[surgery/orthopaedics]]、[[blood/thrombosis-anticoagulation]]、[[surgery/perioperative-care]]、[[blood/transfusion]]。术式：移位性囊内骨折在高龄与活动量少者用置换，在年轻者用固定，按骨的质量与平时的活动能力决定[[musculoskeletal/fractures]]、[[geriatrics-palliative/ageing-frailty]]。认知：基线的混乱要做谵妄的评估与预防，并把镇痛、早期活动与定向的照护放在一起[[geriatrics-palliative/delirium-dementia-care]]、[[geriatrics-palliative/falls]]。出院要从入院规划：康复与骨健康管理（维生素D与钙、双膦酸盐）与跌倒的排查与抗凝的重启[[endocrine/bone-calcium]]、[[clinical-skills/communication]]、[[clinical-skills/records-handover]]。**
:::
:::

::: example 六周后疼痛的全髋 {#ex-hotprosthetic}
在水泥型全髋置换后六周：腹股沟痛加重，伤口渗出清亮液体，不发热，C反应蛋白仍为120；她在三周的电话随访时说不想麻烦别人。
::: solution
**假体周围感染，直到被证明别的：持续升高的炎症指标、伤口渗出与疼痛加重都指向它，而不发热并不能排除[[#def-joint]]、[[surgery/wounds-surgical-infection]]、[[microbiology/laboratory-diagnosis]]。评估：关节抽液的细胞计数与培养（必要时加炎症标志物）、血培养与影像；在取材之前不要给经验性抗生素[[microbiology/laboratory-diagnosis]]、[[microbiology/antimicrobials]]、[[pathology/diagnostic-pathology]]。治疗：早期且假体稳定者可以考虑清创保留假体加长期抗生素，而慢性或松动者需要分期翻修[[surgery/orthopaedics]]、[[surgery/perioperative-care]]、[[immunology/tolerance-regulation]]。系统层面：伤口渗出需要被查看而不是被安慰；把症状的阈值与呼叫的电话写在路径里，鼓励早期联系[[clinical-skills/patient-safety]]、[[clinical-skills/communication]]、[[clinical-skills/records-handover]]。**
:::
:::

::: example 膝痛的少年 {#ex-scfe}
一位13岁、体重指数38的少年，左膝被当作生长痛四周；今天跛行并把髋外旋，髋的屈曲受限而内旋时膝痛；骨盆X线被开出。
::: solution
**少年的髋部病变常表现为膝痛，因为闭孔神经的共同支配；外旋姿态、内旋时膝痛与屈曲受限提示股骨头骨骺滑脱，而肥胖与青春期是危险因素[[paediatrics/congenital-genetic]]、[[musculoskeletal/osteoarthritis]]、[[nervous-system/sensory-systems]]。评估：骨盆与髋的正位与侧位X线（看骨骺的线），不要只查膝，也不要把正常的髋X线当作排除[[clinical-skills/medical-imaging]]、[[clinical-skills/physical-examination]]。治疗是紧急的原位螺钉固定，因为延迟会造成股骨头坏死与关节的变形[[surgery/orthopaedics]]、[[surgery/perioperative-care]]、[[musculoskeletal/fractures]]。教学：肥胖青少年的髋或膝痛必须检查髋；生长痛不是可以解释体征的诊断，把这条推理与转诊写进记录[[paediatrics/growth-development]]、[[clinical-skills/clinical-reasoning]]、[[clinical-skills/communication]]、[[clinical-skills/records-handover]]。**
:::
:::

::: example 午夜的开放骨折 {#ex-open}
农场事故：Gustilo IIIB的开放性胫骨骨折，4小时，明显污染，血管完整，无其他损伤；值班的团队在讨论是凌晨3点清创还是等到早晨的名单。
::: solution
**在明显污染的农场伤中，早而彻底的清创加上抗生素与破伤风的评估是关键；把重度污染的伤口等到早晨会增加感染，因此凌晨手术有理由[[#def-fracture]]、[[microbiology/antimicrobials]]、[[immunology/vaccines-immunotherapy]]、[[surgery/trauma]]。次序：到达时即给抗生素（覆盖土壤来源的菌）、去除异物与失活组织、大量冲洗，并计划第二次的探查[[surgery/orthopaedics]]、[[surgery/wounds-surgical-infection]]。固定：软组织受损时优先外固定，待软组织条件改善后再考虑髓内钉[[musculoskeletal/fractures]]、[[surgery/perioperative-care]]。覆盖：大面积的软组织缺损需要皮瓣或植皮的重建团队[[surgery/wounds-surgical-infection]]。记录与沟通：时间、清创的范围、计划的复评与对长期功能的坦诚说明[[clinical-skills/records-handover]]、[[clinical-skills/communication]]、[[clinical-skills/patient-safety]]。**
:::
:::

一位4岁发热、拒绝负重、髋关节发热肿胀：下一步是

## 通向何处

骨与关节的病理在[[musculoskeletal/bones-joints]]与[[musculoskeletal/osteoarthritis]]；骨折与炎症性关节病在[[musculoskeletal/fractures]]与[[musculoskeletal/inflammatory-arthritis]]；背痛与马尾综合征在[[musculoskeletal/back-pain]]；创伤的评估在[[surgery/trauma]]与[[emergency-critical-care/acute-assessment]]；感染与伤口在[[surgery/wounds-surgical-infection]]与[[microbiology/antimicrobials]]；骨的代谢在[[endocrine/bone-calcium]]；儿童的病变在[[paediatrics/growth-development]]；而老年髋的照护与跌倒与康复在[[geriatrics-palliative/falls]]与[[geriatrics-palliative/ageing-frailty]]。

::: history
骨科的现代来自几项交叉：麻醉与无菌使关节手术成为可能[[surgery/anaesthesia-pain]]、[[surgery/wounds-surgical-infection]]；内固定从骨板走到髓内钉与微创置入，因为理解了血供与负荷[[musculoskeletal/fractures]]；髋与膝的置换让毁损的关节重获功能，靠的是材料与设计[[musculoskeletal/osteoarthritis]]、[[surgery/perioperative-care]]；断层影像与活检路径改变了骨肿瘤的处理[[clinical-skills/medical-imaging]]、[[pathology/cancer-diagnosis]]；而髋骨折的路径、骨健康的合作服务与跌倒的预防把结局变成系统的责任[[geriatrics-palliative/falls]]、[[endocrine/bone-calcium]]、[[public-health/health-systems-economics]]。
:::

::: summary
- 骨折的处理是把生物学（血供与愈合）与力学（稳定与负荷）平衡；描述、机制与神经血管的检查决定路径[[#def-fracture]]。
- 急症是清晰的：开放骨折需要抗生素与清创，室综合征需要切开减压，髋骨折需要在数小时内手术[[#ex-open]]。
- 疼痛的假体在证明别的之前是感染；抽液的细胞计数与培养优先于经验性的抗生素[[#ex-hotprosthetic]]。
- 脊柱的红旗（马尾与感染与肿瘤与骨折）必须被识别；多数下背痛不需手术[[#def-spine]]。
- 儿童的髋与膝的疼痛要检查髋，因为生长痛不能解释体征与跛行[[#ex-scfe]]。
:::

::: exercise 回答腕部的问题 {level=1}
一位28岁在手撑地跌倒后出现鼻烟窝压痛；腕部X线正常。给出处理与理由。
::: solution
**舟骨骨折常在早期的X线上看不见，而鼻烟窝压痛会显著提高其可能；处理是拇指腕掌的石膏固定并安排复查影像（X线、CT或MRI），或在疼痛不能控制时直接请骨科评估[[musculoskeletal/fractures]]、[[clinical-skills/medical-imaging]]、[[surgery/orthopaedics]]。不能仅凭X线正常而安心的理由：舟骨近端的血供较差，漏诊会造成骨不连与塌陷[[musculoskeletal/fractures]]、[[pathology/chronic-inflammation-repair]]。记录与安全网：固定的时间、复查的日期与需要复诊的信号[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]。**
:::
:::

::: exercise 处理发热的关节 {level=2}
一位74岁有痛风史的人在膝置换后三年出现一天的膝关节剧痛、发热与不能负重。给出最初的数小时与鉴别。
::: solution
**第一步是抽液：细胞计数、结晶与培养，因为化脓性关节炎与痛风或假性痛风会表现相同，而关节液决定治疗[[microbiology/laboratory-diagnosis]]、[[musculoskeletal/inflammatory-arthritis]]、[[surgery/wounds-surgical-infection]]。线索：既往的痛风发作史更支持结晶性，而人工关节与全身症状要优先按感染处理；两者可以并存，所以培养不可省[[clinical-skills/physical-examination]]、[[clinical-skills/laboratory-tests]]。治疗：在感染时是引流或冲洗加静脉抗生素（必要时翻修），在结晶时用镇痛药、秋水仙碱或激素[[infectious-diseases/fever-sepsis]]、[[microbiology/antimicrobials]]、[[surgery/orthopaedics]]、[[endocrine/adrenal]]。**
:::
:::

::: exercise 给伴足趾麻木的背痛分类 {level=2}
两位患者：(a) 45岁，腰背痛伴单侧放射到足背、足趾背屈肌力4/5，反射存在，排尿正常；(b) 60岁，腰背痛伴会阴麻木与排尿困难。
::: solution
**(a) 神经根病（椎间盘突出）：在没有进行性缺失或马尾征象时，影像并非必需，因为多数会改善；治疗是镇痛、保持活动，持续不缓解时转诊[[musculoskeletal/back-pain]]、[[clinical-skills/medical-imaging]]、[[nervous-system/motor-systems]]。要追踪肌力的进展与感觉的分布[[emergency-critical-care/acute-assessment]]。(b) 马尾综合征：会阴麻木加排尿困难是急症，需要紧急的MRI与减压手术和导尿[[surgery/perioperative-care]]、[[renal/urinary-tract]]。记录症状出现的时间与呼叫的时间，因为这决定手术的窗口与之后的功能[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]。**
:::
:::

::: exercise 建立骨折联络服务 {level=3}
为一个地区建立骨折联络服务（骨质疏松的路径）：服务对象、评估、治疗与审计。
::: solution
**对象：从髋部与椎体的骨折开始，扩展到50岁以上的所有脆性骨折，因为再骨折的风险在骨后的最初一两年最高[[endocrine/bone-calcium]]、[[musculoskeletal/fractures]]、[[geriatrics-palliative/falls]]。评估：跌倒史与用药史与继发病因的化验（甲状腺、肾、钙磷与激素），加上骨密度测量与骨折风险的工具[[clinical-skills/laboratory-tests]]、[[clinical-skills/medical-imaging]]、[[endocrine/thyroid]]、[[renal/chronic-kidney-disease]]。治疗：双膦酸盐或单克隆的抗体加钙与维生素D，并结合跌倒的预防与运动处方[[endocrine/bone-calcium]]、[[public-health/prevention-promotion]]、[[geriatrics-palliative/falls]]。治理：把评估与治疗的比率作为质量指标，并与骨科和全科医生一起报告[[public-health/health-systems-economics]]、[[clinical-skills/patient-safety]]、[[clinical-skills/records-handover]]。**
:::

## 练习

::: exercise 解读跛行的儿童 {level=1}
按线索把这些可能的诊断排序：(a) 2岁，昨夜突然拒绝行走，不发热，髋保持屈曲；(b) 5岁，烦躁的髋伴发热39与任何活动都痛；(c) 8岁，无痛跛行、足外旋、肢体短缩；(d) 12岁肥胖，膝痛而内旋受限。
::: solution
**(a) 暂时性滑膜炎（常在病毒感染后）：不发热且全身状况好，但需复查确认[[paediatrics/acute-childhood-illness]]、[[musculoskeletal/inflammatory-arthritis]]。(b) 化脓性关节炎直到被证明别的：发热、拒绝任何活动与炎症指标升高要求急查、超声与引流[[infectious-diseases/fever-sepsis]]、[[microbiology/laboratory-diagnosis]]、[[surgery/orthopaedics]]。(c) Perthes病（股骨头骨骺的缺血坏死）：无痛跛行、足外旋与肢体短缩[[paediatrics/congenital-genetic]]、[[musculoskeletal/fractures]]。(d) 股骨头骨骺滑脱：肥胖青少年、膝痛与内旋受限，需要紧急固定[[musculoskeletal/osteoarthritis]]、[[surgery/perioperative-care]]。共同的规则：儿童的髋部病变会伪装成膝痛[[clinical-skills/physical-examination]]、[[clinical-skills/clinical-reasoning]]。**
:::
:::

::: exercise 给疼痛的假体分类 {level=2}
一位71岁在全髋置换后4年，从坐到站时酸痛并有起步痛；不发热，CRP 4；X线显示股骨柄尖端的小的内膜透光带，两年不变。给鉴别与处理。
::: solution
**线索支持机械性的松动：体位改变时的痛、X线上稳定的透亮线与正常的炎症指标[[#def-joint]]、[[musculoskeletal/osteoarthritis]]、[[clinical-skills/medical-imaging]]。但仍要排除低毒力感染（CRP，必要时关节抽液与培养），因为它也可以表现为轻痛[[microbiology/laboratory-diagnosis]]、[[surgery/wounds-surgical-infection]]。鉴别还包括外展肌腱的病变、腰椎的牵涉痛与髋的其他结构[[musculoskeletal/back-pain]]、[[nervous-system/sensory-systems]]。处理：症状轻而影像稳定时观察与康复；疼痛加重或透亮线进展时考虑翻修，且在翻修之前必须先排除感染[[surgery/orthopaedics]]、[[surgery/perioperative-care]]、[[clinical-skills/records-handover]]。**
:::

::: exercise 设定抗凝的路径 {level=2}
一位择期全髋置换的患者在用利伐沙班20毫克治疗房颤（CHA2DS2-VASc 5分），eGFR 45。计划最后一次给药、手术时机、术后第一剂与血栓预防的衔接，并说出你不会做什么。
::: solution
**原则：按药物的半衰期与肾功能停药，eGFR 45时需要更长的间隔（通常至少两天），并在术前确认没有其他出血因素[[blood/thrombosis-anticoagulation]]、[[renal/chronic-kidney-disease]]、[[surgery/perioperative-care]]。不做常规桥接：直接口服抑制剂的患者用肝素桥接会增加出血而不减少事件[[cardiovascular/arrhythmias]]、[[blood/thrombosis-anticoagulation]]。区域麻醉：遵守拔管与给药之间的间隔规则[[surgery/anaesthesia-pain]]。术后：止血后按方案给预防剂量的抗凝，并按出血风险决定治疗剂量的重启时间[[surgery/orthopaedics]]、[[geriatrics-palliative/polypharmacy]]。把时间与责任写进记录并在交接时重复[[clinical-skills/records-handover]]。**
:::

::: exercise 处理脊柱内固定后的手术部位感染 {level=3}
后路腰椎内固定融合后第12天：伤口裂开并有脓性渗出，不发热，CRP 160在下降后再次上升，神经功能完好，患者说只是清洁问题。
::: solution
**这是需要被查看而不是被安慰的伤口：脊柱器械周围的感染会变成慢性并累及椎间隙，所以深部培养与早期评估是第一步[[#def-joint]]、[[surgery/wounds-surgical-infection]]、[[microbiology/laboratory-diagnosis]]。处理：取深部培养（不是表面拭子）、手术冲洗与清创并重建软组织的覆盖，再按结果给静脉抗生素[[surgery/orthopaedics]]、[[microbiology/antimicrobials]]、[[surgery/perioperative-care]]。器械的去留：早期且融合尚未完成时通常保留内固定并控制感染；慢性或不愈合时可能需要取出，由脊柱团队决定[[pathology/chronic-inflammation-repair]]。神经方面：记录运动与感觉的变化并警惕硬膜外的积聚[[nervous-system/motor-systems]]、[[emergency-critical-care/acute-assessment]]。沟通：如实说明严重性、疗程与再次手术的可能，并把这例纳入伤口的审计[[clinical-skills/communication]]、[[clinical-skills/patient-safety]]、[[clinical-skills/records-handover]]。**
