心律失常是[[cardiovascular/electrophysiology-ecg]]的电生理病理化：普通环路被误用（折返）、普通细胞不正常放电（增强自动节律与触发活动）、或普通通道突变（通道病）。临床架构按三个问题依次——**心律现在危险吗（不稳定患者用电）、为什么会发生（底物、扳机、调节剂：缺血、瓣膜病、甲状腺、药物、基因）、我们如何阻止复发（_rate与节律控制、消融、器械、及长期看比心律本身更要紧的卒中与猝死预防）**。

本章讲述机制、心房与心室心动过速、心动过缓与阻滞（其起搏逻辑已在心电图章建立）、晕厥、及心脏性猝死。

## 机制：三种误火方式

::: definition 折返、自动节律、触发活动 {#def-mechanisms}
**折返**——冲动在闭合（或功能闭合）路径内环转——需要**两条不应性与传导速度不同的路径、其中一条单向阻滞、及足够慢的传导使另一条在波前到达时已恢复**（[[physiology/membrane-potentials]]兴奋性周期与[[cardiovascular/electrophysiology-ecg]]可激动间隙逻辑的不应期梯度算术）。经典示范：**房室结折返性心动过速（AVNRT——双重房室结生理、90%病例“慢-快”环路、心房额外刺激曲线上练习器的不连续）、经旁路的房室折返性心动过速（[[cardiovascular/electrophysiology-ecg]]的WPW环路）、心房扑动（腔静脉-三尖瓣峡部大折返——心电图章的例子）、心梗周室速（[[cardiovascular/coronary-artery-disease]]重塑定理的瘢痕通道）、及房颤（多子波与转子由心房牵张、纤维化与短不应期维持——“房颤生房颤”的自我底物）**。**增强的正常或异常自动节律**——去极化或病变细胞自放4期（交界性逸搏及其加速、心房与心室异位灶、**地高辛中毒的自动节律增高加传导抑制双重奏**、及运动诱发室性早搏的儿茶酚胺驱动触发自律）。**触发活动**——达到阈值的后除极：**早后除极（EAD）在长动作电位与慢心率（先天性与药物长QT的停顿依赖、短联联间期的尖端扭转——使索他洛尔与多非利特在低心率时致心律失常的反向使用依赖性、及为何起搏与镁与异丙肾上腺素拯救它们）、及肌浆网钙超载的晚后除极（DAD）（洋地黄与儿茶酚胺及流出道与特发性室速综合征——右室流出道cAMP介导、消融可治愈的灶性自动节律）**。**心律失常三角——底物（瘢痕、牵张、肥厚、突变）、扳机（早搏、停顿、儿茶酚胺、频率）、及调节剂（缺血、电解质、自主张力、药物）**——是以下每个病例及心电图章急症的推理模板（[[physiology/autonomic-nervous-system]]与[[renal/potassium-calcium-phosphate]]供给调节剂）。
:::

## 心房颤动：最常见的持续性心律失常

::: definition 房颤：机制、卒中、三条管理轴 {#def-af}
**心房颤动**——组织性心房率>约350/分产生混乱的机械静止与绝对不齐的心室反应——来自**扳机（肺静脉袖套的早搏——胚胎静脉-心房套袖组织及肺静脉隔离是消融手术的原因）作用于心房牵张、纤维化、炎症与不应期缩短的底物（高血压、[[cardiovascular/heart-failure]]的瓣膜与衰竭心房、肥胖与睡眠呼吸暂停、酒精、甲状腺毒症——[[endocrine/thyroid]]、年龄与心外膜脂肪及自主神经节）**、其阵发→持续→长期持续→永久的自然史由心房自身重塑驱动（[[cardiovascular/circulation-blood-pressure]]的肾素-血管紧张素与[[cardiovascular/heart-failure]]的纤维化作为底物放大器）。管理走三条轴：**(1) 率对节律：率控制（β阻滞剂、地高辛对静息与衰竭患者的结增强——邻近地高辛中毒（[[cardiovascular/heart-failure]]）、结构正常心脏的非二氢吡啶钙阻滞剂、及难治者的消融加起搏配再同步化或希氏束起搏背板——[[cardiovascular/electrophysiology-ecg]]阻滞章）对节律控制（电复律及其抗凝窗口规则——经食道超声引导或三周治疗量、偶发阵发的口袋药策略、按底物选择的抗心律失常药——无结构病：氟卡尼或普罗帕酮加房室结阻断药防止1:1扑动灾难；结构与冠脉及衰竭病：胺碘酮与多非利特——Vaughan-Williams分类药理之家在药物章）、及导管消融、早期节律控制试验更新的心律与心衰结局证据（EAST-AFNET 4在诊断一年内治疗的心血管获益发现）与房颤-心衰消融试验的信号（CASTLE-AF线）；(2) 卒中预防——左心耳血栓的栓塞性卒中（自发性回声contrast与心耳的梳状肌架构）风险评分（CHA₂DS₂-VA式评分及其随指南离开评分性别人工物而被直接风险因子清单取代）、及用**直接口服抗凝药（[[blood/thrombosis-anticoagulation]]药理的Xa因子与凝血酶抑制剂——按肾功能、年龄与体重给药、带试验设定的抗血小板组合上限）或真正抗凝不耐受者的左心耳封堵器械、及机械瓣与中重度风湿性二尖瓣狭窄例外（[[cardiovascular/valve-congenital-disease]]的华法林专属人群）；(3) 风险因子与上游管理——体重、酒精、血压、睡眠呼吸暂停与运动证据（REVERSE-RAFT与LEGACY时代的风险因子试验与肥胖表型消融：最软的轴、最硬的复发效果）。** 临床陷阱：**预激性房颤（心电图章的禁忌）、多年不受控心室反应率的率相关心肌病（可逆的衰竭原因——[[cardiovascular/heart-failure]]的介导性心动过速清单）、房颤中的规则心室律（地高辛中毒或完全阻滞的露馅）、及年轻人的“孤立性”房颤（甲状腺与酒精假日及迷走与肾上腺素模式——及越查越多的心房遗传学之问、[[genetics/common-disease-genetics]]）。**
:::

::: example 音乐会时的心悸 {#ex-svt}
26岁研究生今年四次静息时突发突止的规则搏动、静坐20分钟消退；一次发作时急救员记录了规则窄QRS心动过速190；发作间期无恙、心电图与血液正常。
::: solution
**阵发性室上性心动过速、几乎肯定是AVNRT**（年轻女性 predominance、突发突止、规则窄QRS、环路中心房对关闭的房室瓣收缩的颈部撞击——[[cardiovascular/cardiac-cycle]]大炮波的症状化）。检查阶梯：**捕捉（智能手表或环路记录仪的发作描记——动态监测时代已把经验性药片降级）、然后按频率与偏好的选择：(1) 自限——教迷走动作（改良Valsalva的提升成功率与重新用力的技巧）并记录安全网；(2) 门诊或急诊处理急性发作用腺苷（心电图章的诊断兼治疗工具——[[cardiovascular/electrophysiology-ecg]]）或必要时直流电；(3) 预防——按需口袋药（排除预激与缺血后的β阻滞剂或Ic类加结阻断剂）、长期β或钙阻滞剂、或多数年轻患者选择的无药选项：慢径导管消融（>95%成功、小的结阻滞与复发谈话、及患者年龄支持的确切答案）**。发作间期心电图的工作：**排除delta波（改变每个用药决定的WPW——[[cardiovascular/electrophysiology-ecg]]的例子）、长QT与Brugada及早期复极签名、及使腺苷用于未分化心动过速成为监护下决定的预激。**

::: example 刮胡子时晕倒的老人 {#ex-carpark}
78岁、浴缸里跌倒两次、在洗车场刮脖子时倒地一次，动态心电图有4.2秒长间歇、其间他感到眼前发黑；日间血压有30/15的卧立位下降、他服多沙唑嗪与氨氯地平。
::: solution
**混合性晕厥：颈动脉窦超敏加药物促成体位性低血压、伴记录到的有症状长间歇。**生理：**反应过度的颈动脉窦压力感受器弧（[[physiology/autonomic-nervous-system]]与[[cardiovascular/circulation-blood-pressure]]）——Hering神经沿舌咽的窦传入到孤束核、迷走（心抑制——长间歇）与交感撤退（血管抑制——血压下降）的传出肢、随年龄与动脉粥样硬化与颈部刺激放大；多沙唑嗪的α阻断移除了仅存的血管代偿（[[geriatrics-palliative/polypharmacy]]与[[cardiovascular/circulation-blood-pressure]]的体位练习）。**顺序：**停多沙唑嗪并复测（血管抑制成分可能完全是药物造的）、症状与长间歇的心电图与监测相关性（4秒有症状长间歇的心抑制表型）、在监护、可复苏场合做颈动脉窦按摩求可重复反应（经典3秒停搏加50 mmHg定义、只在诊断会改变管理时做）、及起搏决定——有症状心抑制亚型的 chamber dual（闭环刺激）起搏、附诚实警诫：起搏修长间歇而不修血压下降（血管抑制部分照样发昏、这就是为何药物与物理对抗压与压迫措施先行）。**本例教的晕厥一般定律：**治可治的机制、移除模仿疾病的药、在多沙唑嗪审计关闭之前永不给反射起搏（[[cardiovascular/arrhythmias]]自己的指征文件与[[geriatrics-palliative/falls]]）。**

::: example 八十岁患者的快而不齐心律 {#ex-af-old}
81岁养老院男性因一周咳嗽入院；快房颤148、血压104/70、血氧94%、发热伴右下肺实变；NT-proBNP与肌钙蛋白轻度升高；无胸痛；超声EF 55%、左房大小正常。
::: solution
**脓毒症驱动的快心室反应房颤——2型肌钙蛋白与肽的升高是乘客、不是司机。**推理：**感染（发热、儿茶酚胺、缺氧、炎症）是老化传导系统上的扳机（[[#def-mechanisms]]调节剂臂）；这不是“需要节律控制的新发原发房颤”——而是率与病因的管理、抗凝决定冷静地做。**管理：**治肺炎（抗生素、氧、谨慎补液——[[infectious-diseases/fever-sepsis]]组套）；温和率控制（静脉β阻滞剂或地高辛负荷、附血压与脓毒症心肌的警诫——联合的低血压算术；目标是症状与率控制、不是窦性转复）、补镁补钾（[[renal/potassium-calcium-phosphate]]）、避免对血管扩张者经验性胺碘酮冲击、并期待退热后自发转复或可接受心率。**肌钙蛋白与BNP：系列、而非惊慌——[[cardiovascular/coronary-artery-disease]]的需求性损伤与[[cardiovascular/heart-failure]]肽混淆因素的模式。**抗凝：评卒中风险（仅年龄即够格）、权衡出血风险与跌倒与能力与目标背景（[[geriatrics-palliative/polypharmacy]]、[[medical-ethics-law/consent-capacity]]）、急性病与肾功能宣示后启动直接口服抗凝、并记录复发模式供门诊随访（脓毒症诱发房颤的大量长期复发与卒中统计——“转复了、停药片”的错误）**。转复若失败而率仍难治、是[[#def-af]]复律安全规则后的以天而非分钟计的择期决定。

::: definition 室速、室颤与不稳定患者 {#def-vf}
**室性心动过速**（三次或以上>100/分的室搏、宽而规则）在证明不是之前是**瘢痕相关折返（心梗周通道——已知心梗的单形室速就是瘢痕）、通道病性（儿茶酚胺敏感的双向与运动耦合心动过速——[[genetics/non-mendelian-inheritance]]的儿茶酚胺性多形室速与长QT亚型）、或流出道与特发性（腺苷敏感、射频可治愈的灶）**、而**不稳定患者的首选治疗是有时间就镇静的同步直流电复律**（无脉或多形用除颤器的非同步电击——[[emergency-critical-care/resuscitation]]算法的两个开关）、稳定患者用**普鲁卡因胺、索他洛尔或胺碘酮（胺碘酮对普鲁卡因胺试验的判决倾向普鲁卡因胺在稳定宽QRS的急性疗效）、然后是底物检查与二级预防器械。** **QT正常的多形室速在证明不是之前是缺血（急性闭塞性心律失常——导管室）；QT延长则是尖端扭转（停顿与心动过缓依赖：一线镁、即便血镁正常、超速起搏与异丙肾上腺素与血钾正常高值及撤肇事药——心电图章清单）；QT短而有家族史则是罕见的短QT综合征。** **心室颤动**——骤停心律（与无脉室速的可电击对）——其流行病学、生存链与ICD二级预防规则在复苏章；电生理医师的工作是**可逆原因（缺血、电解质、药物、获得性长QT及[[cardiovascular/coronary-artery-disease]]与[[emergency-critical-care/critical-care]]的骤停后目标温度与再灌注算术）、及风暴（交感放大器——β阻滞（左星状神经节阻滞与胸段硬膜外与外科交感切除的古-现代阶梯）、深镇静、及紧急消融扳机与底物灶、电击众多时用机械支持）。** 抗心律失常药理学器官账——**胺碘酮的甲状腺（含碘分子的低与高——[[endocrine/thyroid]]）、肺（慢性肺炎与机化性肺炎模式——[[respiratory/interstitial-vascular-disease]]）、肝、角膜、皮肤与神经、及其CYP与P-糖蛋白相互作用（其强迫的华法林与地高辛减量——[[pharmacology/metabolism-excretion]]）**——属于药物章及关于它的每次处方谈话。
:::

::: example 运动员的被中止的死亡 {#ex-arvc}
22岁篮球运动员训练中倒地；目击的可电击骤停被救回；复苏后心电图V1–V3 T波倒置伴epsilon波、MRI示右室壁纤维脂肪伴节段无动、其叔叔“年轻时死于睡梦中”。
::: solution
**伴复苏后猝死的心脏停搏致心律失常性右室心肌病（ARVC）**——遗传性桥粒病（plakoglobin与desmoplakin及plakophilin与连接联线——外显率多变的常染色体显性：[[genetics/mendelian-inheritance]]的家系、[[genetics/non-mendelian-inheritance]]的表达可变课），其中**机械应激下的细胞-耦联失败造成心肌细胞死亡、纤维脂肪替代、及运动触发室速的折返底物——“运动员年轻猝死”统计背后的机制（年轻运动员猝死鉴别：肥厚型心肌病（肌小节的、[[cardiovascular/valve-congenital-disease]]讨论的非对称室间隔与其心肌纤维紊乱）、[[anatomy/thorax]]的冠脉开口异常、心肌炎、通道病与震荡冲击）。**管理：**二级预防ICD（I类、无疑问的）、运动限制咨询及有争议的共同决定时代竞技体育的活指南之争——自主权的伦理（[[medical-ethics-law/consent-capacity]]）、反复电击用β阻滞与导管消融（心内-心外膜底物入路；疾病进展故消融是辅助）、家系级联（心电图与MRI与基因筛查——先证者的变异是锚、[[genetics/genetic-testing]]）、及运动员筛查与除颤器可及性的公共卫生辩论（[[public-health/prevention-promotion]]）。** 本章的考试钩：**epsilon波（右室延迟激动的激后切迹）与成人运动员V1以外的T波倒置——两者在V1都近乎正常、越过V1都不正常——与[[cardiovascular/electrophysiology-ecg]]的Brugada与早期复极图形同样的判读纪律。**

机制的世纪：**Mayer与Wenckebach与Lewis**的环行运动与临床标测实验（1920年代扑动环路——心电图章的历史）、**Schmitt与Erlanger**的折返示意图与不应期几何、房颤的**Rosenblueth**及然后**Moe与Abildskov**多子波数学、**Wit与Bigger**及**Surawicz与Rosen**的触发活动与洋地黄性心律失常电生理、及**El-Sherif与Spear和Moore**的再灌注性心律失常时代；**触发性心律失常的儿茶酚胺与环核苷酸理解及1990年代尖端扭转-临床试验时代（d-索他洛尔的失败与自动除颤器黎明期的DIAMOND与EMITAT与CASH试验——Moss与Schwartz与Vincent与Keating的分子长QT谱系——[[genetics/non-mendelian-inheritance]]）；Cox迷宫手术的房颤外科与Haïssaguerre 1998年的肺静脉扳机（测验的机制到手术管线）及消融工具时代（冷冻球囊、脉冲电场）**；**器械时代（Mirowski的电容器与Sudden Death及MADIT与SCD-HeFT一级预防规划及皮下除颤器世代）**及**Holter与环路记录仪与经电话传输监测谱系（晕厥诊断的技术革命）**完成本章的工具包历史。
:::

## 通向何处

心电图图形与急症在[[cardiovascular/electrophysiology-ecg]]；不应期与动作电位生物物理在[[physiology/membrane-potentials]]；自主神经调制在[[physiology/autonomic-nervous-system]]；抗凝药理在[[blood/thrombosis-anticoagulation]]；心衰界面在[[cardiovascular/heart-failure]]；缺血底物在[[cardiovascular/coronary-artery-disease]]；通道病与心肌病遗传学在[[genetics/non-mendelian-inheritance]]；复苏与除颤在[[emergency-critical-care/resuscitation]]；晕厥的跌倒重叠在[[geriatrics-palliative/falls]]。

::: summary
- 三种机制——折返、自动节律、触发活动——加底物-扳机-调节剂三角，是所有心律的诊断语法，并决定药物、消融与器械各治哪个环节。
- 房颤管理走三轴：率或节律（肺静脉隔离的消融是最强杠杆）、按风险评分的卒中预防（比心律本身更要紧）、及决定复发的风险因子与上游管理。
- 不稳定心律用电；宽QRS遵循“不稳定即同同步电”的规则；多形室速按QT分类——正常（缺血）、延长（尖端扭转：镁与超速）或短（罕见综合征）。
- 晕厥是机制的分诊：反射、直立性、心源性——治可治者、先停模仿疾病的药、长间歇起搏是有症状且归因后的决定。
- 猝死 survivors 有病因（缺血、心肌病、通道病）、有家系（级联筛查）、及器械二级预防——以及要求把机制与预防一起教的运动与公共卫生谈话。
:::

## 练习

::: exercise 辨认机制 {level=1}
把机制（折返/触发/自动）分配给：AVNRT、地高辛中毒性室性早搏、尖端扭转、流出道室速、心房扑动、停顿依赖性早后除极早搏。
::: solution
**折返：AVNRT与房扑**（固定环路——不连续曲线底物与峡部依赖大折返——两者都可导管治愈，因为环路解剖明确）。**触发、晚后除极：地高辛中毒性早搏心衰章地高辛例的钙超载后除极（[[cardiovascular/heart-failure]]）及儿茶酚胺性多形室速的运动耦合双向室速（[[genetics/non-mendelian-inheritance]]的ryanodine受体病）。** **触发、早后除极：尖端扭转与长QT的停顿依赖早搏（[[#def-mechanisms]]的反向使用依赖逻辑）。** **灶性自动节律或触发微环路：流出道室速（腺苷敏感cAMP机制、可消融）。** 练习要旨：**机制预测治疗——折返用电、触发用镁与率与撤药、自动与儿茶酚胺用β阻滞与消融。**
:::
:::

::: exercise 评分并处方 {level=1}
计算72岁女性伴高血压、糖尿病、无卒中史的卒中风险判定（CHA₂DS₂-VA式项）、陈述抗凝推荐及直接口服抗凝药是错药的两个场景。
::: solution
**风险因子：女性（1——及评分自身对该项的贬低——现代风险因子清单问性别调整之问）、高血压（1）、年龄65–74（1）、糖尿病（1）=≥3：明确抗凝指征（历史阈值男性≥2、女性≥3、而单女性从不是指征）。**推荐：**直接口服抗凝药（阿哌沙班、利伐沙班、达比加群或艾多沙班——按肾功能、体重与年龄调整剂量——[[blood/thrombosis-anticoagulation]]药理）优于华法林，除非禁忌。**两个直接口服抗凝药错误场景：**机械瓣（及中重度风湿性二尖瓣狭窄）——华法林专属人群——及严重肾衰竭的剂量下限问题加抗磷脂综合征（血栓表型的试验失败——邻近[[immunology/hypersensitivity]]及[[cardiovascular/valve-congenital-disease]]的瓣膜与妊娠抗凝讨论）**；其余近排除是费用与依从现实及相互作用药（强P-糖蛋白与CYP3A4诱导与抑制剂——[[pharmacology/metabolism-excretion]]）。
:::

::: exercise 率还是节律、何时 {level=2}
55岁初检房颤4个月、EF 45%、致残性心悸的患者倾向节律控制。按底物给药物选择、复律安全规则、及消融论证。
::: solution
**按底物的药：**除轻度率相关EF下降外无结构病（介导性心动过速成分使恢复 plausible——[[cardiovascular/heart-failure]]）：**氟卡尼或普罗帕酮（必配结阻断剂——_without_它能产生的1:1传导房扑是考纲陷阱）或决奈达隆（非碘胺碘酮表亲、其心衰与永久房颤排除）、或索他洛尔与多非利特（QT与住院起始警诫——心电图章反向使用依赖）、或胺碘酮（有效、而其器官账——[[#def-vf]]——支持年轻患者消融优先）。** **复律安全：**之前三周治疗量抗凝（或经食道超声排除心耳血栓）及之后四周（心房机械功能的顿抑与复律后血栓栓塞窗口——围操作规则独立于CHA₂DS₂-VA评分、之后按评分继续）、及电击前的甲状腺毒症与地高辛与钾检查（[[renal/potassium-calcium-phosphate]]毒性带电的谨慎）。**消融论证：**早期节律控制试验数据、该病程与该心房大小的阵发房颤单次手术高成功率、逆转轻度衰竭表型的可能、及患者年龄与偏好——附诚实的复发统计、并发症率（填塞、罕见的房-食管瘘、膈神经与狭窄）、及无论表面节律成功仍需按风险评分继续抗凝（[[#def-af]]）。
:::

::: exercise 胺碘酮监测 {level=2}
列出胺碘酮的基线与年度监测、并解释其甲状腺毒性的机制（两个相反表型）及其华法林与地高辛相互作用。
::: solution
**监测：甲状腺、肝、肾与电解质与葡萄糖基线与6个月至年度；胸片与肺功能（含弥散容量）与眼科（角膜微沉着近乎普遍而无害；视神经病变罕见而须停药）；心电图与血压与皮肤检查及年度症状复查查隐匿的气促与共济失调与光敏；有药物浓度检测时用于依从之问。** **甲状腺：分子约37%重为碘且结构似甲状腺素——1型（自主或潜在Graves腺的碘诱导激素合成——抗甲状腺药治疗、放射性碘摄取受限的问题）与2型（释放预制激素的破坏性甲状腺炎——激素应答型）、而碘充足地区甲低期（Wolf-Chaikoff失败）更常见——[[endocrine/thyroid]]与[[immunology/autoimmunity]]的联合病例。** **相互作用：CYP2C9、CYP3A4与P-糖蛋白抑制升高华法林暴露（经验性减半——INR监测的谈判）与地高辛浓度（减半；与低钾无关机制的中毒增强双重奏）、并叠加他药的QT而悖论地极少引起尖端扭转（均一的动作电位延长——[[#def-mechanisms]]的离散度概念——[[pharmacology/metabolism-excretion]]、[[pharmacology/drug-receptor]]）。**
:::

::: exercise 爱电击的装置 {level=2}
ICD患者一个月内六次适当与两次不适当电击。分拣原因并按类别给管理。
::: solution
**适当电击（真室速/室颤——装置在工作）：**原因是底物进展（缺血、衰竭、风暴）、药物失败或不依从、及可逆调节剂（电解质、QT药、脱水）——管理：**interrogate每次事件并复习存储心电图、缺血与衰竭复审、抗心律失常强化（胺碘酮加β阻滞、美西律加入）及瘢痕室速的紧急消融（VANISH与事后试验逻辑）、配[[#def-vf]]风暴路径（镇静、插管、临时机械支持、极端时的经皮与外科交感切除）。** **不适当电击：****快传导的房颤或房扑（判别算法在快而不齐区的失败——结消融加起搏或房颤消融是答案）、运动不足进入频率区的窦速（运动重程与频率起始判别设置）、T波与肌电位与导线过度感知（骨折——电击导线翻修与皮下装置谈话）及噪声**——按类别管理：**先重程、骨折翻修导线、及磁铁与无电击软垫文胸的姑息与安全时代（[[geriatrics-palliative/end-of-life-care]]装置停用伦理属于此处与医学伦理章——[[medical-ethics-law/consent-capacity]]）。** 共享规则：**绝不让装置查询与患者叙述各行其是；每次电击都有一个电图与一个理由（[[clinical-skills/records-handover]]）。**
:::

::: exercise 晕厥分诊 {level=2}
给出三个机制类别及各有两个判别、及应收治而非安慰的危险信号。
::: solution
**反射（神经介导）：**前驱（发热感、恶心、管视、长时间站立与疼痛与情绪扳机）与面色苍白出汗的恢复；亚型血管抑制、心抑制（[[#ex-carpark]]的长间歇）与混合、伴颈动脉窦与吞咽与咳嗽的情境变异。**直立性：**体位时机与药物、脱水、自主神经衰竭（神经源性的[[cardiovascular/circulation-blood-pressure]]-练习综合征）背景及保护性心动过速的缺席。**心源性：**劳力或卧位或无扳机的突然发作、先前的心悸、结构与家族及通道病史、异常心电图与杂音、及无前驱的受伤（“栽倒”）。**危险信号（收治或当日评估）：劳力中或卧位晕厥、先前胸痛或呼吸困难、家族猝死史、异常心电图或EF降低、严重贫血或缺氧或酸中毒、受伤、65岁以上伴共病、及反复不明事件**——ESC晕厥规则架构；工作检查的动态监测层（贴片、植入式环路记录仪）用于罕见事件、及直立倾斜试验在反射性晕厥标记的选定角色（[[emergency-critical-care/acute-assessment]]、[[epidemiology-ebm/diagnostic-tests]]）。

::: exercise 妊娠心律失常 {level=2}
29岁、14周反复室上速；概述急性与预防管理及胎儿考量、及两个应避开的药物类别与理由。
::: solution
**急性：先迷走、然后腺苷（安全——半衰期极短、无子宫效应；与非孕同方案——[[cardiovascular/electrophysiology-ecg]]）、不稳定者毫不犹豫同步直流电复律（胎儿耐受电击胜过母亲低血压—— aside aside监护与左侧倾斜及可存活期后保胎的细节）。** **预防：低剂量β阻滞剂（首选药物、配胎儿生长与心动过缓与低血糖监测及胎盘转运药理）或维拉帕米替代；仅药物抵抗风暴才消融、需要时腹部遮蔽或零透视电解剖技术（[[clinical-skills/medical-imaging]]剂量逻辑）。** **避开：胺碘酮（碘负荷的新生儿甲状腺与神经发育效应——[[endocrine/thyroid]]与[[endocrine/hypothalamus-pituitary]]——留给危及生命的难治例）及ACE/ARB/脑啡肽酶类别与直接口服抗凝药（致畸与胎盘转运问题——需抗凝孕妇的华法林对低分子肝素谈判——[[blood/thrombosis-anticoagulation]]、[[obstetrics-gynaecology/pregnancy-complications]]）。** 产后层：β阻滞剂选择的哺乳安全表、尖端扭转用镁与腺苷的连续性、及心衰章的围产心肌病-房颤重叠（[[cardiovascular/heart-failure]]）。
:::

::: exercise 设计猝死检查 {level=3}
19岁在足球赛中死亡；尸检近乎正常。设计死后检查规划、家系路径、及俱乐部医师的职责。
::: solution
**死后：专科心脏病理医师的检查（取材块与传导系统及细微的ARVC与心肌炎与早期HCM取样——“近乎正常的心脏”是取材与组织学与遗传学之问、不是终局）、毒化与生化（兴奋剂与补剂筛查及类胰蛋白酶与代谢贮积物检测）、及**保留材料作分子检测（通道病与心肌病基因的panel与靶向入路——阴性尸检猝死人群的死后基因分析在相当比例的少数中找到可操作变异——[[genetics/genetic-testing]]法医邻近领域）。** **家系路径：级联——一级亲属心电图与超声、发现变异时配遗传咨询的预测检测（临界表型伦理：运动员资格、保险与生育之问——[[medical-ethics-law/consent-capacity]]自主权讨论与未成年人预测检测限制）；家系自身共享底物的筛查（ARVC与HCM表型可晚宣示）、及带心律失常特异性消罪内容居丧支持。** **俱乐部与社区职责：应急预案审计（AED位置、使这可能成为可生存事件的分钟-到-电击链——[[emergency-critical-care/resuscitation]]与[[public-health/prevention-promotion]]的公共除颤器证据）、共享原因时队友的复出政策（震荡冲击与病毒性心肌炎的筛查周）、及文书与注意义务的沟通。** 生理框架：**结构正常年轻心脏的猝死通常是在最大运动的儿茶酚胺与pH及复极储备下暴露的通道或耦联突变——同一个[[#def-mechanisms]]三角、跑在一棵家系树上。**
