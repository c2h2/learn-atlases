心律失常是指正常窦性心律以外的任何心律。有些无害，例如几乎每个人都有的偶发早搏。有些引起令人不适的心悸，但危险很小。有些因心跳过慢而引起晕厥。少数几种，尤其是心室颤动，如不治疗，会在数分钟内致命。还有一种——心房颤动——其危险与其说来自心律本身，不如说来自颤动的心房中形成并流向脑部的血栓。

本章介绍心律失常的三种机制、处理缓慢和快速心律的实用方法、心动过缓和心脏传导阻滞、室上性心动过速、心房颤动及其卒中风险、室性心律失常和心源性猝死，以及用于治疗的药物和器械。本章以[[cardiovascular/electrophysiology-ecg]]为基础。本章遵循英国指南（心房颤动依据 NICE NG196，并采用英国复苏委员会〔Resuscitation Council UK〕的流程），并注明欧洲心脏病学会（ESC）的指南；实际处理遵循现行的当地指南。

## 机制：三种出错方式

::: definition 心律失常的机制 {#def-mechanisms}
- **异常自律性**：窦房结以外的细胞自发去极化并发放冲动，或窦房结本身发放过快或过慢。例如：窦性心动过速、部分房性心动过速、再灌注后的加速性室性自主心律。
- **触发活动**：后除极，即动作电位之后膜电位的小幅振荡，达到阈值并触发额外的搏动。**早期后除极**发生在动作电位延长时（长 QT），可触发尖端扭转型室性心动过速。**延迟后除极**发生在复极之后、细胞钙超载时，如地高辛中毒和儿茶酚胺敏感性多形性室性心动过速。
- **折返**：冲动沿环路传导，再次激动它已激动过的组织。这是大多数持续性心动过速的机制，包括房室结折返性心动过速、心房扑动、利用旁路的心动过速以及围绕瘢痕的室性心动过速。
:::

::: theorem 折返的条件 {#thm-reentry}
折返需要：
1. 两条传导或不应期特性不同的通路，两端相连形成环路；
2. 其中一条通路发生**单向阻滞**；
3. 环路内**传导足够缓慢**，使冲动回到起点时，那里的组织已经恢复。

如果环路长度大于**波长**——传导速度与不应期的乘积——环路就能自我维持。
:::

::: proof
设想一个冲动到达一个分叉处，分为通路 A 和 B。通路 B 仍处于上一次搏动的不应期，因此冲动只沿 A 下传（单向阻滞）。在远端，它从下方进入 B 并逆行向上。如果传导足够缓慢，此时 B 已经恢复，冲动便传回起点，发现 A 也已恢复，于是再次绕行。早搏是通常的触发因素，因为它到达时其中一条通路仍处于不应期。

波长规则由此得出：环行波的波头不能追上它自己的不应期波尾。传导缓慢（由缺血或瘢痕引起）或不应期缩短（由心房牵张或迷走张力引起）都会缩短波长，使折返更容易发生。治疗正是作用于这些因素：**抗心律失常药物**进一步减慢传导直至发生阻滞，或延长不应期以增加波长；**导管消融**破坏环路的关键部分；**电复律**使所有组织同时去极化，不留下可供波进入的可激动间隙。
:::

## 实用方法

对任何心律失常，第一个问题是患者是否**稳定**。英国复苏委员会的流程列出四项**不良特征**：**休克**（低血压、苍白、出汗、四肢冰冷、意识模糊）、**晕厥**、**心肌缺血**（胸痛、缺血性心电图改变）和**严重心力衰竭**。快速性心律失常伴不良特征者需要**同步电复律**（在镇静或麻醉下）；缓慢性心律失常伴不良特征者需要**阿托品**，无效时需要**起搏**。无脉搏的患者处于心脏骤停。

对稳定的患者，12 导联心电图回答三个问题：
- **频率**：慢（低于 60）还是快（高于 100）？
- **QRS 宽度**：窄（小于 0.12 s），意味着心室经正常传导系统激动，心律起源于心室以上；还是宽，意味着起源于心室或传导异常？
- **规则性**：规则还是不规则？

## 心动过缓与心脏传导阻滞

**窦性心动过缓**在身体健康者和睡眠中是正常的。它也可由药物（β 受体阻滞剂、减慢心率的钙通道阻滞剂、地高辛、胺碘酮）、甲状腺功能减退、低体温、颅内压升高和下壁心肌梗死引起。**窦房结功能障碍**（病态窦房结综合征）通常由老年人的退行性纤维化引起，导致不适当的心动过缓、窦性停搏，并常有心动过缓与房性快速性心律失常交替出现（快-慢综合征）。

::: definition 房室传导阻滞 {#def-block}
- **一度房室传导阻滞**：PR 间期长于 0.20 s；每个 P 波都能下传。通常为良性。
- **二度Ⅰ型房室传导阻滞（莫氏Ⅰ型，文氏阻滞）**：PR 间期逐渐延长，直至一个 P 波不能下传；然后周而复始。阻滞通常位于房室结。常见于睡眠中和运动员，通常为良性。
- **二度Ⅱ型房室传导阻滞（莫氏Ⅱ型）**：PR 间期恒定，P 波无预兆地间歇性不能下传。阻滞通常位于房室结以下的希氏-浦肯野系统，可突然进展为完全性传导阻滞。
- **2:1 房室传导阻滞**：每隔一个 P 波下传一次；可以是Ⅰ型或Ⅱ型，根据 QRS 宽度和临床情况判断。
- **三度（完全性）房室传导阻滞**：所有 P 波都不能下传。心房和心室各自独立搏动；心室由逸搏心律驱动，为交界性（QRS 窄，40–60 次/分）或室性（QRS 宽，20–40 次/分）。
:::

房室传导阻滞的病因包括传导系统退行性纤维化（老年人最常见的病因）、缺血性心脏病、药物、高钾血症、浸润性疾病（结节病、淀粉样变性）、感染（莱姆病、伴主动脉根部脓肿的心内膜炎），以及心脏手术或经导管主动脉瓣植入术中的损伤。

在排除药物或高钾血症等可逆病因后，莫氏Ⅱ型、完全性传导阻滞和高度阻滞（连续两个或以上 P 波不能下传）即使无症状，一般也有植入**永久起搏器**的指征；有症状的窦房结功能障碍同样如此。

::: example 刮胡子时晕倒 {#ex-carpark}
一位 79 岁男性有三次无预兆的突然意识丧失，其中一次发生在刮胡子时，每次持续不到一分钟，完全恢复。他未服用减慢心率的药物。心电图示窦性心律 72 次/分，PR 0.22 s，右束支传导阻滞伴电轴左偏。动态心电监测记录到一次头晕发作：期间 P 波以 80 次/分持续出现，但 6 秒内没有 QRS 波，随后出现 30 次/分的宽 QRS 逸搏心律。诊断和治疗是什么？

::: solution
监测显示**阵发性完全性心脏传导阻滞**：P 波不能下传，心室停搏，然后缓慢的室性逸搏接管。由一段停搏或极度心动过缓引起的无预兆、迅速恢复的突然意识丧失，称为**阿-斯综合征（Stokes–Adams 发作）**。

他的基线心电图已经预示了这一点。右束支传导阻滞伴电轴左偏（左前分支阻滞）为**双分支阻滞**；加上 PR 间期延长，传导依赖于剩下的一支分支，而它可能间歇性失效。

治疗是植入**永久起搏器**。刮胡子时晕厥可能提示**颈动脉窦高敏**（压迫颈部引发心动过缓或血管扩张），但本例症状发作时记录到的传导阻滞已回答了这个问题。应按现行驾照规定，建议他在治疗前不要驾车。
:::
:::

## 窄 QRS 波心动过速

常见的规则窄 QRS 波心动过速有：

- **窦性心动过速**：对发热、疼痛、焦虑、低血容量、贫血、低氧、甲状腺毒症或肺栓塞的正常反应。治疗病因，而非治疗心率。
- **房室结折返性心动过速（AVNRT）**：利用一条快径路和一条慢径路在房室结内折返。是最常见的阵发性室上性心动过速（SVT），女性尤多。频率一般为 140–250 次/分；P 波通常隐藏在 QRS 波中或紧随其后。
- **房室折返性心动过速（AVRT）**：利用旁路折返，如预激综合征（Wolff–Parkinson–White 综合征）。
- **房性心动过速**：心房内的一个病灶快速发放冲动。
- **心房扑动**：一个大的折返环路，通常绕右心房的三尖瓣环。心房以约 300 次/分搏动，"锯齿状"扑动波在 Ⅱ、Ⅲ 和 aVF 导联最清楚；经房室结 2:1 下传时，心室率约为 **150 次/分**。任何频率为 150 的规则窄 QRS 波心动过速都应寻找扑动波。

**心房颤动**是常见的**不规则**窄 QRS 波心动过速。

对稳定的规则窄 QRS 波心动过速，步骤如下：

1. **迷走神经刺激。** 在 REVERT 试验（2015）中，**改良 Valsalva 动作**（半卧位向注射器吹气 15 秒，然后平卧并抬高双腿）终止 SVT 的比例远高于标准 Valsalva 动作。老年人避免颈动脉窦按摩，因为有卒中风险。
2. **腺苷**，在心电图记录下快速静脉推注。它使房室结阻滞数秒，从而终止依赖房室结的折返（AVNRT、AVRT），或在心房扑动或房性心动过速中短暂减慢心室率以显露心房活动。它会引起短暂而难受的濒死感、潮红和胸闷，哮喘患者慎用。
3. 如腺苷无效或有禁忌，使用 **β 受体阻滞剂**或**维拉帕米**（verapamil；不用于预激性心动过速，也不与 β 受体阻滞剂合用），或**同步电复律**。

AVNRT 的慢径路**导管消融**或旁路消融可治愈大多数患者，适用于反复发作者。

::: example 音乐会上的心悸 {#ex-svt}
一位 26 岁女性在音乐会上突发快速、规则的心悸。急诊科测心率 186 次/分，血压 118/76 mmHg，神志清楚，无胸痛。心电图示规则的窄 QRS 波心动过速，未见 P 波。她既往有类似但较短的发作，都突然终止。概述诊断和处理。

::: solution
年轻女性突发突止的**规则窄 QRS 波心动过速**、未见 P 波，最可能是 **AVNRT**。她**无不良特征**，因此适合药物或迷走神经刺激治疗。

1. 在心电监护下行**改良 Valsalva 动作**。
2. 如无效，将**腺苷**快速静脉推注入大静脉，随后用生理盐水冲管，同时持续记录心电图；必要时按方案追加剂量。应提前告知她会有短暂而强烈的不适感。
3. 终止后，记录窦性心律下的 12 导联心电图，寻找**预激**（PR 短、delta 波）。
4. 检查电解质和甲状腺功能。

今后，可教她自行做改良 Valsalva 动作。如反复发作，应转诊行**电生理检查和导管消融**，通常可治愈；长期药物治疗是另一种选择。
:::
:::

## 心房颤动

::: definition 心房颤动 {#def-af}
**心房颤动（房颤，AF）**是心房电活动紊乱、没有协调的心房收缩。心电图**无 P 波**，基线不规则，心室节律**绝对不规则**。房颤按病程分类：
- **阵发性**：7 天内自行终止或经干预终止；
- **持续性**：持续超过 7 天；
- **长期持续性**：在仍追求节律控制的情况下持续超过 12 个月；
- **永久性**：患者和医生已接受这一心律，不再计划尝试节律控制。
:::

房颤是最常见的持续性心律失常。其患病率随年龄急剧上升，在 80 岁以上人群中占相当比例。大多数房颤起源于**肺静脉**肌袖的快速发放，并由因牵张、纤维化和炎症而重构的心房维持。危险因素包括年龄、高血压、心力衰竭、瓣膜病（尤其是二尖瓣）、冠心病、肥胖、糖尿病、阻塞性睡眠呼吸暂停、饮酒、甲状腺毒症和耐力运动。急性诱因包括感染、手术、肺栓塞和酗酒。

房颤通过三种方式造成危害：**卒中和体循环栓塞**（血液在左心耳淤滞并形成血栓）；**症状**（心悸、气短、乏力、运动能力下降）；以及**心力衰竭**，既因失去心房收缩，也因心室率过快。因此处理分为三部分：预防卒中、控制心率或节律、治疗基础疾病和危险因素。

### 卒中预防

房颤的卒中风险用 **CHA₂DS₂-VASc** 评分估算：

| 因素 | 分值 |
|---|---|
| **C** 充血性心力衰竭（或左心室功能障碍） | 1 |
| **H** 高血压 | 1 |
| **A** 年龄 75 岁或以上 | 2 |
| **D** 糖尿病 | 1 |
| **S** 既往卒中、短暂性脑缺血发作或血栓栓塞 | 2 |
| **V** 血管疾病（既往心肌梗死、外周动脉疾病、主动脉斑块） | 1 |
| **A** 年龄 65–74 岁 | 1 |
| **Sc** 性别类别为女性 | 1 |

根据 **NICE NG196**（2021），对 CHA₂DS₂-VASc 评分 **2 分或以上**者**给予**抗凝治疗，对评分 1 分的男性**考虑**抗凝，同时考虑出血风险。**ESC 2024** 指南采用 **CHA₂DS₂-VA**，去掉了女性这一项，因为女性主要在存在其他因素时才增加风险；它建议评分 2 分或以上时抗凝，1 分时考虑抗凝。

对大多数人，首选**直接口服抗凝药（DOAC）**，如阿哌沙班（apixaban）、依度沙班（edoxaban）、利伐沙班（rivaroxaban）或达比加群（dabigatran），而非华法林。**华法林**仍是**机械心脏瓣膜**或**中重度二尖瓣狭窄**患者的抗凝药，这些人不使用 DOAC。评估出血风险（NICE 推荐 ORBIT 评分）主要是为了识别和纠正可改变的因素，如未控制的高血压、过量饮酒、不必要的抗血小板药或非甾体抗炎药以及贫血，而不是作为不予抗凝的理由。**阿司匹林不用于房颤的卒中预防**：其效果远不如抗凝，却同样引起出血。对不能使用抗凝药的部分患者，**左心耳封堵**是一种选择。

::: example 80 多岁的不规则脉搏 {#ex-af-old}
一位患高血压和 2 型糖尿病的 82 岁女性在例行复查时被发现脉搏绝对不规则，112 次/分。她有轻度劳力性气短。心电图证实为心房颤动。血压 146/84 mmHg，eGFR 58，血红蛋白正常。她服用氨氯地平（amlodipine）、二甲双胍（metformin），以及因膝痛自购的布洛芬（ibuprofen）。计算她的 CHA₂DS₂-VASc 评分并概述处理。

::: solution
**CHA₂DS₂-VASc**：高血压 1，年龄 75 岁或以上 2，糖尿病 1，女性 1，合计 **5**。她的卒中风险高，在讨论获益和风险后**应给予抗凝**。通常使用 **DOAC**，剂量根据药品说明书标准（年龄、体重、肾功能）和当地处方集确定。

**出血风险**：处理可改变的因素，而不是以此拒绝治疗：**停用布洛芬**（非甾体抗炎药与抗凝药合用增加出血，并加重高血压和肾功能损害），控制血压，了解饮酒情况。

**心率控制**：对大多数房颤患者，NICE 建议首先控制心率，使用 **β 受体阻滞剂**或减慢心率的钙通道阻滞剂（地尔硫䓬〔diltiazem〕或维拉帕米）。她已在服用氨氯地平，这是一种不减慢心率的二氢吡啶类药物；换用 β 受体阻滞剂既能控制心率，又能治疗高血压。对活动少的人，地高辛是一种选择。

**进一步措施**：超声心动图（结构、瓣膜病、左心室功能）、甲状腺功能，并评估心率控制后症状是否持续。如症状仍持续，考虑**节律控制**（复律、抗心律失常药物或导管消融）。控制危险因素（血压、体重、饮酒、睡眠呼吸暂停）可减少房颤负荷。
:::
:::

### 控制心率还是控制节律？

对许多症状轻微的老年人，单纯控制心率是合理的。**节律控制**旨在恢复并维持窦性心律，在房颤有可逆病因、引起心力衰竭或心率控制后症状仍持续时首选。EAST-AFNET 4 试验（2020）发现，在诊断后一年内尽早开始节律控制，与常规治疗相比减少了心血管死亡、卒中和住院，这促使人们更早地考虑节律控制。

- **复律**（电复律，或在无结构性心脏病者中用氟卡尼〔flecainide〕、或用胺碘酮进行药物复律）恢复窦性心律。由于房颤开始后约 48 小时内左心房即可形成血栓，而新恢复的心房收缩可使其脱落，因此只有在房颤确定持续不足 48 小时，或治疗性抗凝至少 3 周后，或经食管超声心动图显示无血栓后，才进行复律。复律后继续抗凝至少 4 周；如 CHA₂DS₂-VASc 评分有指征，则长期抗凝。
- **抗心律失常药物**维持窦性心律：β 受体阻滞剂、氟卡尼（与房室结阻断药合用，且仅用于无结构性或缺血性心脏病者）、决奈达隆（dronedarone）、索他洛尔（sotalol）和胺碘酮（最有效，但长期毒性显著）。
- **肺静脉隔离**的**导管消融**在维持窦性心律方面比药物更有效，在药物无效或不能耐受时采用，而且越来越早地采用。

对卒中风险高的人，恢复窦性心律并不能免除抗凝的需要，因为房颤常常无症状地复发。

## 室性心律失常与猝死

**室性早搏**常见，通常为良性；极为频繁的早搏在少数情况下可引起心肌病。

**室性心动过速（室速，VT）**是起源于心室的宽 QRS 波心动过速，通常由心肌梗死后或心肌病中围绕瘢痕的折返引起。**单形性**室速的 QRS 波形态一致；**多形性**室速则形态多变。**尖端扭转型室速**是一种 QRS 电轴围绕基线扭转的多形性室速，与 QT 间期延长相关；治疗为静脉注射**镁剂**、纠正血钾和停用延长 QT 的药物。**心室颤动（室颤，VF）**是心室活动紊乱，没有心输出量。

::: definition 宽 QRS 波心动过速 {#def-vf}
**规则的宽 QRS 波心动过速**除非有明确的相反证据，应按**室性心动过速**处理。其他可能是 SVT 伴束支传导阻滞（差异性传导）和预激性心动过速。支持室速的特征包括结构性心脏病（尤其是既往梗死）、**房室分离**（P 波独立地规则出现）、融合波和夺获波、QRS 极宽、电轴极度偏移，以及胸导联同向性（全部正向或全部负向）。
- **无脉性**室速或室颤：心脏骤停；除颤和高级生命支持。
- 室速**伴不良特征**：同步电复律。
- **稳定的**室速：寻求专科意见；常用静脉胺碘酮；无效时复律。
:::

对室颤或无脉性室速（可电击心律）引起的**心脏骤停**，英国复苏委员会流程（2021 年，2025 年更新中予以重申）要求尽快电击，随后进行 2 分钟心肺复苏再评估心律，**第三次电击后给予肾上腺素和胺碘酮**，此后每 3–5 分钟给予肾上腺素。全程寻找可逆病因（低氧、低血容量、低钾或高钾血症及其他代谢紊乱、低体温、血栓形成、张力性气胸、心脏压塞、毒物）（[[emergency-critical-care/resuscitation]]）。

老年人的**心源性猝死**大多是冠心病引起的室颤。在 35 岁以下人群中，以遗传性疾病为主：肥厚型心肌病、致心律失常性心肌病、长 QT 综合征和 Brugada 综合征，以及儿茶酚胺敏感性多形性室速。**植入式心律转复除颤器（ICD）**用于无可逆病因的室颤或持续性室速幸存者（二级预防），以及部分高风险者（一级预防），如射血分数重度降低者（[[cardiovascular/heart-failure]]）。

::: example 倒下的足球运动员 {#ex-arvc}
一位 19 岁足球运动员在比赛中倒下，被发现为室颤；旁观者心肺复苏和公共除颤器恢复了窦性心律。之后他的心电图示 V1–V3 导联 T 波倒置，偶发呈左束支传导阻滞形态的室性早搏。超声心动图和心脏 MRI 显示右心室扩大、收缩差，伴脂肪和纤维替代。可能的诊断是什么？接下来怎么做？

::: solution
可能的诊断是**致心律失常性心肌病**（致心律失常性右心室心肌病）：一种遗传性疾病，通常累及桥粒蛋白，心肌（主要是右心室）被脂肪和纤维组织替代，形成折返性室速的基质。青春期后 V1–V3 导联 T 波倒置、来自右心室的早搏（左束支传导阻滞形态）以及影像学表现支持诊断；诊断依据正式的工作组标准。

接下来：
- 因他曾在室颤中幸存，植入 **ICD** 作为二级预防；
- **避免竞技性和高强度耐力运动**，因为运动会加速疾病进展并诱发心律失常；
- β 受体阻滞剂，对反复室速有时行导管消融；
- 与其他遗传性心脏病一样，进行**基因检测**，并对一级亲属用心电图和影像进行**级联筛查**（[[genetics/mendelian-inheritance]]）。

他之所以能存活，靠的是旁观者立即实施心肺复苏和早期除颤，这是生存链中最有力的环节。
:::
:::

::: warning 不要对宽 QRS 波心动过速使用维拉帕米
如果心律实际上是室速，维拉帕米（及其他房室结阻断药）会抑制收缩力、扩张血管，使已在衰竭的心脏发生严重低血压和心脏骤停。在预激性房颤中，它可加快经旁路的传导。除非确定是 SVT 伴差异性传导，否则应把宽 QRS 波心动过速当作室速处理。
:::

## 抗心律失常药物

**Vaughan Williams 分类**按主要作用对抗心律失常药物分组，尽管许多药物有多种作用：

| 类别 | 作用 | 举例 |
|---|---|---|
| Ⅰ | 阻断钠通道（减慢 0 相和传导） | Ⅰa 丙吡胺；Ⅰb 利多卡因；Ⅰc 氟卡尼 |
| Ⅱ | 阻断 β 肾上腺素受体 | 比索洛尔、美托洛尔 |
| Ⅲ | 阻断钾通道（延长复极和不应期） | 胺碘酮、索他洛尔 |
| Ⅳ | 阻断 L 型钙通道（减慢房室结传导） | 维拉帕米、地尔硫䓬 |
| 其他 | | 腺苷、地高辛、镁剂、伊伐布雷定 |

所有抗心律失常药物也都可能**引起**心律失常（致心律失常作用）。**CAST 试验**（1989）对此给出了决定性证明：氟卡尼和恩卡尼抑制了心肌梗死后的室性早搏，却增加了死亡率，因为在瘢痕心肌中减慢传导促进了折返。这就是为什么结构性和缺血性心脏病避免使用氟卡尼，也是为什么抑制早搏本身不是目标。胺碘酮有效，在心力衰竭中使用安全，但不良反应很多：甲状腺功能异常（亢进和减退均可）、肺纤维化、肝损伤、光敏感和皮肤变色、角膜沉积、视神经病变，以及升高华法林作用和地高辛浓度的相互作用。

::: quiz
一位 70 岁男性的心电图示规则窄 QRS 波心动过速，150 次/分。由于这一频率，应特别考虑哪一诊断？
- [ ] 疼痛引起的窦性心动过速
- [x] 心房扑动伴 2:1 阻滞
- [ ] 室性心动过速
- [ ] 心房颤动
::: solution
**心房扑动**的心房率通常约为 300 次/分；房室 2:1 下传时心室率约为 **150**。扑动波可能隐藏在 T 波中，因此应查看下壁导联，或用迷走神经刺激或腺苷短暂减慢心室率以显露扑动波。房颤是不规则的，室速是宽 QRS 波。
:::
:::

::: history
约 1900 年，麦肯齐（James Mackenzie）用他的多导描记仪同时记录动脉和静脉搏动，描述了一种持续不规则的脉搏，其静脉波形中的心房波消失了；1909 年，刘易斯（Thomas Lewis）在心电图上确认这种心律为心房颤动。1952 年，佐尔（Paul Zoll）经胸壁对人类心脏进行了起搏。1958 年，斯德哥尔摩的森宁（Åke Senning）和埃尔姆奎斯特（Rune Elmqvist）为拉松（Arne Larsson）植入了第一台完全植入式起搏器，拉松一直活到 2001 年。20 世纪 60 年代初，洛恩（Bernard Lown）发展了与 QRS 波同步的直流电复律；米罗夫斯基（Michel Mirowski）的植入式除颤器于 1980 年首次用于患者。1998 年，波尔多的海斯盖尔（Michel Haïssaguerre）及其同事证明，大多数阵发性房颤由肺静脉触发，这是肺静脉隔离消融的基础。
:::

## 后续内容

心电图判读见[[cardiovascular/electrophysiology-ecg]]，心律失常的基质见[[cardiovascular/coronary-artery-disease]]、[[cardiovascular/heart-failure]]和[[cardiovascular/valve-congenital-disease]]。抗凝药理学见[[blood/thrombosis-anticoagulation]]，卒中见[[nervous-system/stroke]]，心脏骤停见[[emergency-critical-care/resuscitation]]。

::: summary
- 心律失常源于异常自律性、触发活动或折返；折返需要两条通路、单向阻滞和缓慢传导。
- 检查不良特征（休克、晕厥、心肌缺血、严重心力衰竭）：有不良特征时，快速性心律失常需同步电复律，缓慢性心律失常需阿托品和起搏。
- 莫氏Ⅱ型、完全性和高度房室传导阻滞通常需要永久起搏器；一度和莫氏Ⅰ型阻滞通常为良性。
- 规则窄 QRS 波心动过速：迷走神经刺激（改良 Valsalva 动作）、腺苷，然后其他药物或复律；消融可治愈大多数 AVNRT 和 AVRT。频率为 150 时提示心房扑动。
- 房颤：按 CHA₂DS₂-VASc 抗凝（NICE：2 分或以上给予，男性 1 分考虑；ESC 采用 CHA₂DS₂-VA）；除机械瓣或中重度二尖瓣狭窄外首选 DOAC；不用阿司匹林。处理出血风险，而不是因此不予抗凝。
- 用 β 受体阻滞剂或减慢心率的钙通道阻滞剂控制心率；节律控制采用复律（房颤不足 48 小时、抗凝 3 周或经食管超声心动图后）、药物或消融。
- 把宽 QRS 波心动过速当作室速处理；尖端扭转型室速对镁剂有效；心脏骤停时尽早电击，第三次电击后给予肾上腺素和胺碘酮。
- 所有抗心律失常药物都可能致心律失常（CAST）；ICD 可预防部分患者的猝死。
:::

::: exercise 卒中风险评分 {level=1 check="4"}
计算一位患高血压、射血分数降低的心力衰竭和既往心肌梗死的 70 岁男性的 CHA₂DS₂-VASc 评分。
::: solution
年龄 65–74 岁：1；高血压：1；充血性心力衰竭：1；血管疾病（既往心肌梗死）：1。合计 **4**。应给予抗凝。
:::
:::

::: exercise 说出阻滞类型 {level=1}
说出各心律的名称：(a) PR 0.24 s，每个 P 波后都有 QRS 波；(b) PR 依次延长为 0.20、0.28 和 0.34 s，随后一个 P 波后无 QRS 波，然后周而复始；(c) PR 恒定为 0.16 s，偶有 P 波不能下传；(d) P 波 80 次/分，宽 QRS 波 34 次/分，两者之间没有关系。
::: solution
(a) **一度房室传导阻滞**。(b) **莫氏Ⅰ型（文氏阻滞）**。(c) **莫氏Ⅱ型**。(d) **完全性（三度）心脏传导阻滞**伴室性逸搏心律。
:::
:::

::: exercise 累积风险 {level=1 check="round(100*(1-0.96^5))"}
一位房颤患者的年卒中风险为 4%。假设年风险保持恒定且各年相互独立，计算 5 年内至少发生一次卒中的概率，以百分数表示并四舍五入到整数。
::: solution
5 年内不发生卒中的概率为$0.96^5 = 0.815$。至少发生一次卒中的概率为$1 - 0.815 = 0.185$，四舍五入为 **18%**。（直接相乘$5 \times 4\% = 20\%$会略微高估。）
:::
:::

::: exercise 心率控制的选择 {level=2}
为下列永久性房颤患者选择控制心率的药物并说明理由：(a) 68 岁，HFrEF（LVEF 30%）；(b) 74 岁，重度 COPD，无心力衰竭；(c) 91 岁，居家不出，活动很少。
::: solution
(a) 获准用于心力衰竭的 **β 受体阻滞剂**，它还能改善 HFrEF 的生存；可加用地高辛。避免使用地尔硫䓬和维拉帕米，因为它们抑制收缩力。

(b) 如不能耐受 β 受体阻滞剂，**地尔硫䓬或维拉帕米**（减慢心率的钙通道阻滞剂）是合理的；不过，心脏选择性 β 受体阻滞剂在 COPD 中一般可以耐受（主要禁用于哮喘），因此仍常使用 β 受体阻滞剂。

(c) **地高辛**可控制静息心率，适合活动少的人；它对运动时心率的控制较差。剂量根据肾功能调整，怀疑中毒时监测血药浓度。
:::
:::

::: exercise 胺碘酮的监测 {level=2}
一位患者开始长期服用胺碘酮。列出需要监测的器官和检查，以及两种重要的药物相互作用。
::: solution
- **甲状腺**：用药前及每 6 个月检查甲状腺功能（由于其含碘及直接作用，可致甲减和甲亢）。
- **肝脏**：用药前和用药期间检查肝功能。
- **肺**：基线胸片；如出现症状，评估肺纤维化或肺炎。
- **眼**：角膜微沉积常见；视神经病变罕见但严重；出现视力变化应报告。
- **皮肤**：光敏感（防晒）和石板灰色变色。
- **心脏**：心电图（QT 延长、心动过缓）；血钾和血镁。

**相互作用**：胺碘酮增强**华法林**作用（INR 升高）并升高**地高辛**浓度，因此通常需减量；它还与某些他汀（辛伐他汀剂量限制）及其他延长 QT 的药物相互作用。其半衰期很长，停药后作用可持续数月。
:::
:::

::: exercise 复律与时间 {level=2}
一位无结构性心脏病的 58 岁男性因 3 天前开始的房颤而心悸。他病情稳定。今天能为他复律吗？说明可选方案。
::: solution
由于房颤已持续**超过 48 小时**，左心耳内可能已形成血栓，复律可能导致卒中。可选方案为：
- **抗凝至少 3 周**，期间控制心率，然后择期复律；或
- 行**经食管超声心动图**排除左心房血栓，然后在抗凝下复律。

无论哪种方案，复律后都继续抗凝至少 4 周，并根据他的 CHA₂DS₂-VASc 评分决定是否长期抗凝。如他变得不稳定，尽管有风险，也应紧急复律。
:::
:::

::: exercise 晕厥门诊 {level=2}
将下列短暂意识丧失按心源性风险高或低分类，并说明理由：(a) 22 岁，在炎热的教堂里站了一小时后晕倒，之前有出汗和恶心；(b) 64 岁，运动时倒下，有收缩期杂音；(c) 34 岁，其兄弟 30 岁时猝死，听到闹钟响时倒下；(d) 75 岁，无预兆倒下，有双分支阻滞。
::: solution
(a) **低风险**：**血管迷走性晕厥**的典型情境和前驱症状。

(b) **高风险**：运动时晕厥伴杂音提示**主动脉瓣狭窄**或**肥厚型心肌病**；需紧急超声心动图。

(c) **高风险**：突然的声音刺激和猝死家族史提示**长 QT 综合征**（2 型典型地由突然的噪声诱发）；需心电图、测量 QTc 和专科评估。

(d) **高风险**：伴传导系统疾病的无预兆晕厥提示**间歇性完全性心脏传导阻滞**。

增加心源性风险的特征包括运动时或卧位晕厥、无前驱症状、倒下前心悸、结构性心脏病、心电图异常以及猝死家族史。
:::
:::

::: exercise 宽 QRS 波心动过速 {level=3}
一位 67 岁男性 4 年前患前壁心肌梗死，现因心悸和头晕就诊。他神志清楚；血压 104/68 mmHg。心电图示规则的宽 QRS 波心动过速，172 次/分，QRS 0.16 s，偶见与 QRS 波无关的 P 波，还有一个比预期提前出现的较窄 QRS 波。一位低年资医生建议用维拉帕米治疗"SVT 伴束支传导阻滞"。解读心电图，讨论鉴别诊断，并概述处理。
::: hint
独立的 P 波和一个提前出现的较窄搏动，说明了心律起源于哪里？
:::
::: solution
**解读**：规则的宽 QRS 波心动过速，伴**房室分离**（P 波与 QRS 无关）和一个**夺获或融合波**（窦性冲动短暂地正常激动心室时出现的提前、较窄的 QRS 波）。这些特征可诊断**室性心动过速**。即使没有这些特征，**心肌梗死**病史也使瘢痕相关折返性室速成为首要诊断。

**鉴别诊断**：SVT 伴原有的或频率相关的束支传导阻滞；预激性心动过速（经旁路前传的 AVRT）；起搏心律；高钾血症或钠通道阻断药中毒导致的宽 QRS 波。

**处理**：
- **不要给维拉帕米**：如果是室速，它可能导致循环衰竭。
- 他目前无不良特征（神志清楚、血压 104/68、无胸痛或心力衰竭），但必须在备有除颤器的条件下密切监测；如出现不良特征，在镇静下行**同步电复律**。
- 稳定的室速需寻求专科意见；常用**静脉胺碘酮**；纠正血钾和血镁。
- 寻找缺血证据（肌钙蛋白、终止后的心电图），并评估左心室功能。
- 康复后，鉴于既往梗死伴持续性室速，很可能会植入 **ICD**，并可考虑导管消融。
