心电图是本书生理章节中动作电位的细胞外投影：数百万心肌细胞电位的向量和、九个电极记录、按一系列时钟与方向来读。临床技艺有两半——决定患者生命几分钟的模式识别（闭塞性心肌梗死、高钾、预激房颤、长QT）与映射到上一章力学的慢性签名（肥厚、阻滞、心腔增大）——两半都建立在知道每个偏转是哪个细胞事件之上。

本章讲述心脏电生理、心电图的生物物理、及带急症的系统读法。

## 从离子通道到心电图偏转

::: definition 动作电位家族 {#def-aps}
工作心肌（心房与心室肌细胞、浦肯野纤维）跑**快反应动作电位**：**全或无钠电流（I_Na）**造上升支——0期、心电图的QRS；**平台（2期）**来自L型钙电流对抗延迟整流钾电流——ST段；复极（3–4期）——T波、其正常由心内膜向心外膜的序列（心外膜细胞先复极、动作电位短）给出多数导联直立的T。**结区组织**（窦房与房室结）跑**慢反应**：无稳定静息电位、**舒张期去极化**来自**funny电流I_f（HCN通道——起搏电流、去甲肾上腺素经cAMP右移电压依赖加速、乙酰胆碱与伊伐布雷定刹住）**、经T型然后L型钙通道达阈——故钙通道阻滞剂心动过缓；及房室结（而非希氏-浦肯野系统）是**生理性延迟**的属性（递减、速率适应、迷走控制——保护心室免受房性心律失常的门、使一度时PR延长良性、阻滞位置更低时危险）。**不应性**——有效（无传导反应）与相对（需更强或更晚刺激）期由钠通道恢复设定——是强度-时值曲线、抗心律失常药靶、及折返需可激动间隙才能维持背后的组织属性：多数临床心动过速的机制（下文房室结与旁路折返环、心房扑动的宏大折返、[[cardiovascular/coronary-artery-disease]]的瘢痕相关室速）。
:::

::: definition 向量、导联与正常值 {#def-leads}
Einthoven三角与加压及胸导从固定方向采样心脏电向量：**平均QRS电轴**（成人约+60°——由哪些肢体导联为正决定：电轴左偏是左前分支与主动脉瓣狭窄左室肥厚领地、电轴右偏是儿童、右位心的镜像与右室肥厚）、及**胸导序列**（V1–V6采样右室间隔到侧壁——下文梗死定位表的解剖基础）。正常算术：**率60–100**（300/大格捷径及其在不齐心律的局限）、**PR 120–200 ms、QRS<120 ms、QTc**（Bazett与Fridericia校正对心率——450/460 ms阈值与500 ms尖端扭转悬崖）、**Q波**（≥40 ms或>同导R的25%、两个相邻导联时病理——完成性梗死的窗）、**ST段**（以毫米计的J点偏移、决定再灌注）、及**P波**（二尖瓣病与高血压舒张衰竭的左房终末力）。读图纪律是固定序列——**率、律、轴、间期、肥厚、然后对照临床故事的缺血**——因为漏诊聚集在被跳过的步骤（被读成“快速房颤”的STEMI、被记为“正常窦性”的晕厥图里的长QT）。
:::

::: example 150次的锯齿波 {#ex-flutter}
70岁高血压气促患者心室率规则150；心电图无窦性P波、下壁导联300次/分锯齿基线；缓慢静脉β阻滞后心室率降至75、描记下方的图形清晰一倍。
::: solution
**心房扑动2:1传导、被减慢至4:1后揭穿**——机制是**右房宏大折返环（三尖瓣峡部依赖、典型逆时针环）**以约300/次/分激动心房；房室结的递减生理（[[#def-aps]]）隔搏阻一次、心室坐在150——经典的“老人规则窄QRS心动过速150次即扑动，直到下壁导联另有说法为止”。减慢传导提高阻滞比并揭示锯齿（扑动波以下壁与V1最清）、腺苷也做这一诊断动作（短暂、警诫是它是诊断工具而非治疗工具）。管理：**率控制（β或非二氢吡啶钙阻滞剂——警惕两药合用加重阻滞）、扑动比颤动更难率控、抗凝按与房颤相同的卒中风险规则、及也是本章最成功消融的最终答案：三尖瓣峡部线性阻滞（>90%治愈）、附注这部分患者日后宣示房颤、需[[cardiovascular/arrhythmias]]的长期规划**（药理由[[cardiovascular/arrhythmias]]接管；此处生理要点是有固定频率与被保护峡部的宏大折返是理想的导管靶点——环路解剖即处方）。
:::
:::

::: example 终结争论的那张图 {#ex-stemi}
58岁男性、压榨性中央胸痛40分钟、出汗：心电图II、III、aVF抬高4 mm伴I、aVL镜像压低、V2–V3高R伴ST抬高至S-T交界水平。
::: solution
**下壁ST段抬高心肌梗死伴后壁延伸——启动导管室、而不是“20分钟后复查心电图”的谈话。**定位是解剖算术：**II/aVF与III=下壁、右冠领地（优势型）——闭塞在右缘支近端、伴后壁V2–V3压低高R（后壁导联V7–V9确证）、依优势型为右或左回旋的后降支；镜像改变（高侧壁压低）是真闭塞对心包炎与早期复极模仿的最强单一线索**。该心电图携带的伴随陷阱：**右室受累**（下壁心梗：加做V4R——抬高的右室ST预言不能给硝酸酯、需要液体的前负荷依赖低血压——冠脉病房里的[[cardiovascular/cardiac-cycle]]Guyton论证）、**缓慢性心律失常与房室阻滞**（多数心脏的房室结由右冠供血——结缺血加Bezold-Jarisch迷走浪：阿托品、临时起搏备用——[[cardiovascular/arrhythmias]]）、及**机械并发症时钟**（乳头肌断裂、游离壁破裂、间隔破裂——第2–5天、各是新杂音与休克、[[cardiovascular/coronary-artery-disease]]）。管理：**网络分钟预算内的直接经皮冠脉介入（门-球时间）、阿司匹林加P2Y12抑制剂与抗凝负荷、导管室超出转运窗口时的溶栓替代（[[cardiovascular/coronary-artery-disease]]的症状起始与心电图演变算术）**——及读图课：**闭塞图形胜时间窗；令人信服的图形伴持续疼痛即闭塞、直到造影另有说法**，含各种等价型（后壁、右室、新发左束支阻滞与超急性T波闭塞综合征）。

## 阻滞、捷径与暗通道

::: definition 房室阻滞与起搏逻辑 {#def-block}
**一度**（PR>200 ms而每个P下传）是传导延迟标志、结性（迷走、运动员、β阻滞剂）时良性、希氏下（预告更高阻滞的宽QRS一度）时值得随访。**二度I型（Wenckebach）**——PR进行性延长后QRS脱落——多为**结性**、迷走或药物或下壁缺血、阿托品应答、暂时。**II度II型与2:1及宽QRS的高度阻滞**——阻滞在**希氏下**（His-Purkinje、纤维化或前壁心梗）、突发、阿托品不可靠、**永久起搏指征**、其生理是逸搏等级：交界性40–60或室性20–40、阻滞以下脆弱。**三度（完全）**——房室分离（[[cardiovascular/cardiac-cycle]]练习的大炮a波、规则心动过缓、停搏长间歇与宽QRS逸搏的风险）：**阿托品只对结性阻滞、希氏下临时然后永久起搏、及现代生理性起搏改良（左束支区与希氏束起搏）避开慢性右室心尖起搏的不同步**——同一同步障碍使心脏再同步化治疗成为阻滞患者与心衰患者的共同答案。指征文件（ACC/AHA与NICE起搏指南）是难治生理的律法：**归因于阻滞的症状、伴长间期的阻滞、宽QRS的希氏下阻滞、及传导病跑得比肌病快的神经肌肉病。**
:::

::: example 健康24岁者的心悸 {#ex-wpw}
健康24岁者突发突止规则心悸190；终止后窦性心律心电图示短PR（90 ms）、钝波上升支（delta波）伴继发T倒置；发作时QRS窄而规则。
::: solution
**Wolff-Parkinson-White图形伴顺向型房室折入性心动过速**——旁路（存活于环状纤维化的胚胎心肌桥——[[anatomy/embryology]]的绝缘失败）**前向经结下传（窄QRS、典型顺向环）、逆向经旁路上行**、[[#def-aps]]的折返由旁路的单向阻滞完成。管理按环的方向与心房的行为分流：**先迷走动作、腺苷（终止结依赖环的房室结阻滞剂——早给；宽QRS心动过速时仅在诊断有信心且监护下给，因为可能被它揭穿的预激房颤是另一个危险故事——绝对不齐宽QRS律、房室结阻滞禁忌（腺苷、β阻滞剂、地高辛与维拉帕米都会经旁路加速心室）；那里用普鲁卡因胺或伊布利特或电复律）**。根治：**电生理检查与旁路导管消融（有症状旁路的年轻患者、及偶然发现的旁路不应期谱或高危职业的讨论）**、以**猝死统计**作咨询的配重（预激房颤中罕见以首发表现的室颤——风险分层规划的目的）。
:::
:::

::: example 透析患者的宽QRS {#ex-hyperk}
61岁无尿透析患者缺席两次治疗；心电图示心动过缓40、P波消失、宽而畸形的QRS、尖窄尾T波；钾8.1。
::: solution
**高钾血症——膜电位章节写在心电图上**：部分去极化（细胞外钾升高移动E_K——[[physiology/membrane-potentials]]的Nernst算术）**使钠通道失活（QRS变宽——“正弦波”是终末融合）、抑制心房与结的电活动（消失的P、交界性或室性自搏）并提前加速复极（帐篷T）**——进展至停搏是连续而非阶梯的、**心电图与数字相关并不完美：治图形、图形走到这么远时下重手**。顺序即生理：**钙（葡萄糖酸或氯化——膜稳定剂数分钟内抬高阈值兴奋性、通道上的直接对抗者、不是降钾药）、然后胰岛素-葡萄糖（及沙丁胺醇雾化；两者经Na/K-ATP酶及其胰岛素驱动的插入实现胞内转移——[[physiology/homeostasis-body-fluids]]的钾机器）、然后终须发生的移除（透析——无尿患者唯一真正的出口；胃肠道结合剂作慢辅助；纠酸并停驱动——ACE、钾、缺席的治疗），起搏谨慎（高钾抬高捕获阈值——早先练习器曲线变成临床）、阿托品常无效，因为结以下的阻滞是心肌细胞去极化而非迷走**。病例隐藏的鉴别——终末期钠通道阻滞剂中毒（三环、氟卡尼）的宽QRS心动过缓改用高渗钠——完成课程：宽QRS加慢率是膜电流问题、问题是哪个电流。
:::

::: history
**Augustus Waller**1887年在自己身上做的胸部电流计描记（心电图之前的心电图）、**Willem Einthoven**的弦线电流计与命名法（P-Q-R-S-T字母承自Lippmann毛细管电流计）与1906年诺奖；**Lewis**的机制时代工作（1920年代扑动与颤动环路、发作性心动过速、传导系统的“X因子”）、**Aschoff与Tawara**的结发现（起搏器与房室束、以及His的His束）、**Rosenblueth与Cannon**的自主神经编码；**Goldberger**的加压肢体导联（1940年代——12导联标准）、**Wilson**的胸导与单极系统及使定位成为可能的向量革命、**Master**的二阶梯运动试验与Master-Person正常值表；**Sodi-Pallares与世纪中叶心梗定位图谱（1940–60年代；“de Winter”与Wellens图形后来从旧文献找回）、Moe、Kaufman与Otani及Scherf**的房室结生理、**1910–30年代的旁路时代（Wolf-Parkinson-White 1930年论文的“短PR”）与Durrer和Wellens的标测时代**、然后**Scheinman与Josephson**1980年代消融规划把本章环路变成导管治愈；及**Moss、Vincent与Keating的分子QT时代**（LQTS基因与通道亚型药理——[[genetics/non-mendelian-inheritance]]以晕厥就诊的遗传学）使T波成为基因型之问。
:::

## 通向何处

膜生物物理在[[physiology/membrane-potentials]]与[[physiology/synapses]]；自主神经调制在[[physiology/autonomic-nervous-system]]；此处每个心律的力学后果在[[cardiovascular/cardiac-cycle]]；心律失常管理在[[cardiovascular/arrhythmias]]；缺血综合征在[[cardiovascular/coronary-artery-disease]]；电解质生理在[[renal/potassium-calcium-phosphate]]；通道病的遗传学在[[genetics/non-mendelian-inheritance]]。

::: summary
- 两个动作电位家族——快钠（工作心肌、浦肯野）与慢钙/起搏（结）——生成心电图的波与两种临床不同的传导病；不应性与折返解释多数心动过速。
- 心电图是从固定角度采样的向量：电轴定位、胸导分区、间期量化传导；固定读图序列防住被漏的急症。
- 闭塞图形（ST抬高、镜像改变、后壁与右室延伸）是启动决定，房室阻滞图形是解剖决定（结性对希氏下）而急迫性相反。
- 预激、高钾与长QT是把通道、旁路与泵的药理写进毫秒的三种“电学急症”，其治疗各自直取膜机制。
:::

## 练习

::: exercise 率与轴速读 {level=1}
一张心电图R-R间期4.5大格；I导联正、aVF负、II导联正。给出率与轴类别。
::: solution
率=300/4.5≈**67/分**。I正而aVF负=电轴偏左方向；II正使其停在正常-左边界内（轴约0到−30°为正常偏左；真正的左偏是I正、II负）。故：**正常偏左轴**——临床含义：病理左偏（−45°以下）提示左前分支阻滞或下壁梗死丢失、下一步是QRS宽度与II、III、aVF形态（梗死的小q浅R对分支阻滞的rS）。
:::
:::

::: exercise 测量QT {level=1}
率100时QT 520 ms。按Bazett计算QTc并判断；列出造成此象的四类药与两种电解质病变。
::: solution
Bazett：QTc=520/√0.60≈**671 ms**（率100时RR=0.60 s）——显著延长、>500 ms尖端扭转风险带（Bazett在高速率过度校正——Fridericia或配速确认是细心医师的第二次算术）。原因：**Ia与III类抗心律失常药（奎尼丁、索他洛尔、多非利特、胺碘酮——尽管其尖端扭转率低）、大环内酯类、唑类、氟喹诺酮类、抗精神病药（氟哌啶醇、齐拉西酮、喹硫平）与美沙酮、昂丹司琼及其他止吐药、及三环类**；电解质：**低钾与低镁（也低钙——[[renal/potassium-calcium-phosphate]]的U波与神经肌肉签名）**。处理：停药、钾补到正常高值并补镁、监护、及先天之问（[[genetics/non-mendelian-inheritance]]长QT故事的β阻滞剂治疗与家系筛查）。
:::
:::

::: exercise 读绝对不齐的宽QRS {level=2}
预激房颤与室速都可“不齐而宽”。给三个判别（临床或心电图）及能在不确定中存活的处理规则。
::: solution
**预激房颤**：年轻、心悸史、之后窦性时的短PR delta、心电图**极快（常>250/分）、绝对不齐、形态多变的宽QRS**（“似多形”、融合波与最短预激RR<250 ms是危险标志）；**伴不齐的室速**（差传的房颤或变夺获的室速）偏向年龄、结构病、旧梗死与规律图形（融合、夺获、房室分离、同向一致）。**处理规则：不稳定的不齐宽QRS心动过速无论机制一律直流电复律；稳定者用普鲁卡因胺或伊布利特（疑预激）或专家会诊后的室速方案——而绝不在未分化的不齐宽QRS律用腺苷、维拉帕米、地尔硫䓬或地高辛，因为若是预激房颤、每一个都会把心室加速向室颤（[[#ex-wpw]]的禁忌）**（[[cardiovascular/arrhythmias]]与[[emergency-critical-care/acute-assessment]]）。
:::

::: exercise 起搏图形 {level=2}
双腔起搏器心电图示P波跟随伴长AV间期、偶发未下传的房性早搏伴心室起搏于上限频率、图形交替。用电生理解释装置行为，及患者的那一个主诉。
::: solution
装置在**跟随心房（心房感知→程控AV间期心室起搏——程控师设定的PR、房性早搏或窦速超过上限跟踪频率时的Wenckebach或2:1行为——逆行室房传导完成环时的起搏介导性心动过速环、以每一QRS后带P的上限频率心室起搏律识别）**。管理是同一生理：**延长AV间期（交替传导图形是上限频率行为、长AV间期也减少不必要的右室心尖起搏——[[#def-block]]的不同步论证）、启用室早/上限频率行为模式、以磁铁应用或程控终止起搏介导性心动过速（阻逆行臂的不应期动作）**。患者的主诉是**AV定时错误时心房对关闭三尖瓣收缩的颈部撞击（[[cardiovascular/cardiac-cycle]]大炮波装置的形态）或模式悄悄把患者切进纯心室起搏生活、失去心房助推的气促——“起搏器综合征”、电序列不良的血流动力学代价、整章浓缩于一个主诉。**

::: exercise 心包炎对闭塞 {level=2}
给25岁体位性胸痛患者区分急性心包炎与早期复极及STEMI的四个心电图判别（加一个临床与一个实验室）。
::: solution
心电图：(1)**分布**——心包炎：广泛凹面向上ST抬高伴PR压低（心房损伤电流）、下侧壁导联、**aVR的PR抬高**；闭塞：冠脉领地伴镜像压低（[[#ex-stemi]]规则）；早期复极：前壁凹面向上抬高无PR改变、伴显著切迹。(2)**凹度**——心包炎向上凹的“鞍形”对闭塞的凸面/墓碑样。(3)**演变**——心包炎的弥散分期序列（数日）对领地特异的分钟到小时QRS/T改变。(4)**Spodick征（TP段下斜）与Q波缺席**支持心包炎；PR压低是其近乎特异的标志。临床：**体位性、胸膜性、前倾减轻的疼痛、心包摩擦音、病毒前驱与发热**；实验室：**肌钙蛋白（心肌心包炎有轻升——分辨靠数字的模式而非有无）、CRP、超声心包积液与心脏磁共振的炎症**——同一生理的影像章版本、伴由开头那张图决定的管理岔路（NSAID加秋水仙碱对导管室）；胸痛路径本身在[[emergency-critical-care/acute-assessment]]。
:::

::: exercise Brugada与发热 {level=2}
30岁东南亚男性从夜间心脏骤停中被复苏；骤停后心电图示V1–V2穹窿形ST抬高伴右束支样图形；前夜有发热。解释通道病、发热链接的钠电位机制与管理。
::: solution
**Brugada综合征**——亚洲部分地区年轻男性最常见的遗传性心律失常综合征（地方民俗的“不明原因夜间猝死”——其通道病基础是现代心电图学的发现）。病理生理：**钠电流缺失（SCN5A及亲属；及钙电流与转运伙伴）不成比例地累及右室心外膜、其瞬体外向钾电流（I_to）最密——由此产生的电压梯度给出V1–V2的ST抬高与2相折返的室颤**。**发热与钠阻滞药（氟卡尼；阿吉马林或氟卡尼激发试验；及三环与可卡因的钠阻断）能揭穿它，因为温度进一步使突变通道失活并加快门控——[[physiology/membrane-potentials]]温度与阈值的同一生物物理**：故积极退热规则、避药清单（brugadadrugs.org纪律）及心电图的动态、诊断加可激发性质（自发1型图形是危险标志）。管理：**生存者的ICD（二级预防——本例）与选定有症状家属；奎尼丁（I_to阻滞剂——通道逻辑的解毒剂）与消融（心外膜底物）用于电风暴；心电图与基因的家系筛查（外显率降低的常染色体显性家系——[[genetics/non-mendelian-inheritance]]的课），及发热与药物会转化的偶发2/3型图形的安心路径**——本章收尾演示：一张心电图图形是用毫米写成的膜电流（[[cardiovascular/arrhythmias]]）。
:::

::: exercise 给束支定位 {level=2}
QRS 140 ms、V5–V6宽单相R伴小q、V1的rS伴宽S。命名阻滞、其在年轻与年长者的常见原因、及伴胸痛新发时的意义。
::: solution
**左束支阻滞**（心室自间隔向左到右、再经延迟的左壁逐细胞激动——QRS≥120伴I/V6正常间隔q消失、V1宽S；右束支阻滞是其镜像：V1的rSR′、I/V6钝S）。年轻人孤立性右束支阻滞可能是正常变异或房间隔缺损领地（卵圆孔型的术后再迹——[[cardiovascular/valve-congenital-disease]]）；老年人的左束支阻滞意味着传导系统纤维化（Lenegre/Lev病）、高血压性或缺血性或瓣膜性心脏病——从非“正常”。**伴胸痛新发左束支阻滞即闭塞直到证明不是**（历史上“STEMI等价型”——今天Sgarbossa与改良Sgarbossa标准加与旧图系列对比做分拣、因直接闭塞试验显示许多此类图形陈旧而非缺血）；其存在摧毁缺血的判读（继发ST-T改变）、运动心电图选项（→改影像负荷、[[cardiovascular/coronary-artery-disease]]）与电轴算术，而其医源孪生——起搏诱导的左束支图形——带[[#def-block]]右室心尖起搏的不同步代价。
:::

::: exercise 设计异常心电图的分诊 {level=3}
地区医院引入AI辅助心电图判读。设计临床治理：必须绕过一切延迟的三个发现、最常被过度报告的三个、及人的因素保障——各以本章生理论证。
::: solution
**绕过一切的发现（以分钟计、不进队列）**：(1)**ST抬高与闭塞等价图形**（[[#ex-stemi]]的解剖：领地抬高、后壁与右室延伸、de Winter与超急性T、Sgarbossa阳性左束支）——因为病变是一条正在关闭的动脉、图形胜肌钙蛋白；(2)**恶性急症律与间期**——伴晕厥的完全与希氏下阻滞（[[#def-block]]）、预激房颤与规则宽QRS心动过速（[[#ex-wpw]]）、有肇事药时尖端扭转带的QTc（[[#ex-hyperk]]的邻居）、及骤停生存者的Brugada与早期复极及ARVC签名（epsilon波、终末激动延迟）；(3)**电解质与中毒图形**（正弦波钾、钠阻滞剂QRS、地高辛的双向性与勺形伴阻滞图像）——膜电流急症。**过度报告的发现**（假阳性税）：年轻人和运动员的早期复极被读成STEMI（凹鞍与切迹）、体型与心律的正常变异——梗死与肥厚的电轴左偏和低电压模仿者、窦性心律不齐与游走起搏点被读成心脏阻滞、及**长QT算法在高速率随率的过度校正**（Bazett人工物——校正值需人工复核）。**人的因素保障**：每条警报到达具名临床医师并有电话升级（决策支持的中断-覆盖问题）、**图与故事必须能调和**（心包炎对闭塞靠病史与[[#ex-stemi]]镜像逻辑；正常变异鸡胸的算法“前壁梗死”）、系列对比作为一级功能（旧心电图是最强的人工智能）、以生理加权复核启动时间与假阴性伤害的审计（漏掉的闭塞、而非漏掉的正常，才是指标）、**及教学模式**——解释其报警的系统，保住了本章急症在夜班仍需要的人类判断（[[clinical-skills/patient-safety]]）。
:::
