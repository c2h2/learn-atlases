每一次心跳都始于一个电事件。右心房内一小群细胞自发放电，冲动扩散到整个心房，在房室结内被延迟，然后沿特化的传导纤维迅速传播，几乎同时激动整个心室。心电图（ECG）从体表记录这些活动的总和。它便宜、快速、安全，而且常常是最快改变处理方案的检查：在救护车上记录的一份心电图，就可以把冠状动脉闭塞的患者直接送进导管室。

本章解释心脏动作电位及其背后的离子流、传导系统、心电图如何记录以及每个导联为什么看到它所看到的东西，并给出系统阅读 12 导联心电图的方法和常见的异常图形。心律失常在[[cardiovascular/arrhythmias]]中进一步展开。

## 心脏动作电位

静息细胞膜带电，膜内为负，因为钾经开放的通道外流比其他离子内流更容易。静息电位和动作电位的一般原理见[[physiology/membrane-potentials]]。心脏有两种截然不同的动作电位。

::: definition 心室肌（快反应）动作电位 {#def-aps}
心房和心室的工作心肌细胞以及浦肯野纤维的静息电位稳定在约 −90 mV，上升支快速。其动作电位分为五期：

- **0 期，快速去极化。** 电压门控钠通道开放，钠迅速内流，在一两毫秒内使膜电位达到约 +20 mV。
- **1 期，快速复极初期。** 钠通道失活，瞬时外向钾电流形成一个小切迹。
- **2 期，平台期。** 钙经 L 型钙通道内流，与外向钾电流平衡，使膜保持去极化 200 ms 或更长。内流的钙触发肌质网释放钙，从而引起收缩。
- **3 期，复极化。** 钙通道关闭，延迟整流钾电流（快速成分$I_{Kr}$和缓慢成分$I_{Ks}$）使膜恢复静息。
- **4 期，静息期。** 内向整流钾电流$I_{K1}$使膜电位维持在约 −90 mV。
:::

漫长的平台期使心肌具有很长的**不应期**。钠通道失活期间，细胞不能再次兴奋，因此在收缩接近结束之前第二个冲动无法到达。这防止了强直收缩——对一个必须舒张才能充盈的泵来说，强直收缩是致命的。许多药物作用于这些电流。Ⅰ类抗心律失常药阻滞钠通道、减慢 0 期；胺碘酮（amiodarone）和索他洛尔（sotalol）等Ⅲ类药物阻滞钾通道、延长 3 期。许多非心脏药物也阻滞$I_{Kr}$（由 *hERG*，即 *KCNH2* 编码的通道）并延长 QT 间期，这就是药物性长 QT 常见的原因。

::: definition 起搏细胞（慢反应）动作电位 {#def-pacemaker}
**窦房结**和**房室结**细胞没有稳定的静息电位。在 4 期，它们从约 −60 mV 缓慢去极化，驱动力来自**起搏电流（funny current）**$I_f$（一种经 HCN 通道、由超极化激活的内向钠-钾电流）和 T 型钙通道。达到约 −40 mV 的阈电位后，L 型钙通道产生缓慢的上升支。由于没有快钠电流，结区组织传导缓慢。细胞随后经钾通道复极，周期重复。
:::

窦房结的频率由 4 期的斜率决定。交感神经经 β1 肾上腺素受体和环磷酸腺苷增大$I_f$和钙电流，使斜率变陡、心率加快。迷走神经释放乙酰胆碱，打开乙酰胆碱激活的钾通道，使细胞超极化、斜率变平，心率减慢。没有任何自主神经输入时，窦房结约以 100 次/分发放冲动；静息心率 60–80 次/分反映了迷走张力占优势。伊伐布雷定（ivabradine）通过阻滞$I_f$减慢心率而不影响收缩力。由于房室结传导依赖钙通道，钙通道阻滞剂（维拉帕米〔verapamil〕、地尔硫䓬〔diltiazem〕）、β 受体阻滞剂、地高辛（digoxin）和腺苷（adenosine）均可减慢房室结传导。这些药物用于控制心房颤动时的心室率，或终止涉及房室结的折返。

## 传导系统

冲动沿固定路径传导：

1. 位于上腔静脉与右心房交界处的**窦房结**首先发放冲动。
2. 冲动扩散到两侧心房，形成 P 波。
3. 冲动到达房间隔下部的**房室结**。这里传导缓慢，使心室激动延迟约 0.1 s，让心房收缩完成对心室的充盈。房室结也保护心室免受极快的心房节律影响，因为它不能传导每一个冲动。
4. **希氏束**携带冲动穿过把心房与心室彼此绝缘的纤维骨架。
5. **左、右束支**（左束支又分为前分支和后分支）沿室间隔两侧下行。
6. **浦肯野纤维**把冲动迅速传遍心内膜，使心室在约 0.08–0.1 s 内被激动。室间隔最先激动，方向从左向右。

如果上一级失效，传导系统的每一级都可以作为起搏点，但频率依次降低：房室交界性心律约 40–60 次/分，室性逸搏心律约 20–40 次/分。这一层级解释了为什么伴室性逸搏的完全性心脏传导阻滞会导致脉搏缓慢并可引起晕厥。

## 记录心电图

心电图记录体表电极之间的电位差。去极化波朝向正电极传播时，波形向上；背离时向下；与之垂直时偏转很小，或正负相等（**等电位**或**双相**）。复极化的方向相反，正常情况下 T 波与 QRS 方向相同，因为在心室中，最后去极化的区域（心外膜）最先复极。

::: definition 导联及其视角 {#def-leads}
标准 12 导联心电图使用十个电极，产生十二个视角。

- **肢体导联**在额面观察心脏。**标准导联**Ⅰ、Ⅱ、Ⅲ（Einthoven）测量两肢体之间的电位差；**加压导联** aVR、aVL 和 aVF 将一个肢体与另两个肢体的平均电位相比较。
- **胸（心前区）导联** V1–V6 在水平面观察心脏，从室间隔右侧（V1）一直到左侧壁（V6）。

导联按其面对的区域分组：

| 区域 | 导联 | 常见对应冠状动脉 |
|---|---|---|
| 下壁 | Ⅱ、Ⅲ、aVF | 右冠状动脉（或回旋支） |
| 间隔 | V1、V2 | 左前降支 |
| 前壁 | V3、V4 | 左前降支 |
| 侧壁 | Ⅰ、aVL、V5、V6 | 回旋支或对角支 |

aVR 导联从右肩向心腔内观察，因此窦性心律时其 P 波、QRS 波和 T 波通常均为负向。
:::

英国的标准走纸速度为 25 mm/s，定标为 10 mm/mV。在标准心电图纸上，**一个小方格为 1 mm，即 0.04 s**；**一个大方格为 5 mm，即 0.2 s**。五个大方格为一秒。

## 波形与间期

::: definition 正常心电图 {#def-normal}
- **P 波**：心房去极化。正常时在Ⅱ导联直立，宽度小于 0.12 s，高度小于 2.5 mm。
- **PR 间期**：从 P 波起点到 QRS 波起点；冲动经心房、房室结和希氏-浦肯野系统传导的时间。正常 0.12–0.20 s（3–5 个小方格）。
- **QRS 波群**：心室去极化。正常小于 0.12 s（3 个小方格）。Q 波是任何起始的负向波，R 波是第一个正向波，S 波是 R 波之后的负向波。
- **ST 段**：从 QRS 终点（**J 点**）到 T 波起点；正常位于基线，此时整个心室均已去极化。
- **T 波**：心室复极化。除 aVR（常常还有 V1）外，在大多数导联正常直立。
- **QT 间期**：从 QRS 起点到 T 波终点，即心室去极化和复极化的总时间。心率加快时 QT 缩短，因此需按心率校正（QTc）。
:::

::: theorem 心率与 QT 校正 {#thm-rate}
对于规则心律，在标准心电图纸上：
$$
\text{心率（次/分）} = \frac{300}{\text{R-R 之间的大方格数}} = \frac{1500}{\text{R-R 之间的小方格数}}.
$$
对于不规则心律，数出 10 秒节律条上的 QRS 波群数，再乘以 6。

**Bazett 公式**按心率校正 QT 间期：
$$
QT_c = \frac{QT}{\sqrt{RR}}
$$ {#eq-bazett}
其中 QT 以 ms（或 s）计，RR 间期以秒计。男性 QTc 超过约 450 ms、女性超过约 470 ms 为延长；超过 500 ms 时尖端扭转型室速的风险显著增加。
:::

Bazett 公式在心率快时校正过度，在心率慢时校正不足。其他公式（使用 RR 立方根的 Fridericia 公式，以及 Framingham 公式）在极端心率时表现更好；许多心电图机会同时报告多种结果。图中显示了一个固定的实测 QT 如何随 RR 间期的变化转换为校正值。

::: example 心率、心律与 QTc {#ex-qtc}
一位正在服用几种新药的 70 岁女性的心电图显示规则的窄 QRS 波群。R 波间隔 4 个大方格。QT 间期为 11 个小方格。计算心率、RR 间期、QT 间期和按 Bazett 公式计算的 QTc。

::: solution
心率 $= 300/4 = 75$ 次/分。

RR 间期 $= 4 \times 0.2 = 0.8$ s。

QT $= 11 \times 0.04 = 0.44$ s $= 440$ ms。

$QT_c = 440/\sqrt{0.8} = 440/0.894 \approx 492$ ms。

对女性而言这是延长的（超过 470 ms），并且接近 500 ms。下一步是审查她的药物中是否有延长 QT 的药物（例如某些大环内酯类和氟喹诺酮类抗生素、抗精神病药、美沙酮〔methadone〕、昂丹司琼〔ondansetron〕、西酞普兰〔citalopram〕以及Ⅰa 类和Ⅲ类抗心律失常药），检查血钾、血镁和血钙，并复查心电图。低钾和低镁都会延长复极，增加风险。
:::
:::

## 心电轴

**平均 QRS 电轴**是额面上心室去极化的平均方向，以度表示，Ⅰ导联为 0°，aVF 为 +90°。正常范围约为 −30° 至 +90°。

用Ⅰ、Ⅱ导联的快速判断法：

- **Ⅰ和Ⅱ导联 QRS 均以正向为主**：电轴正常。
- **Ⅰ导联正向，Ⅱ导联负向**：电轴左偏（比 −30° 更负）。原因包括左前分支阻滞、下壁心肌梗死和部分左心室肥厚。
- **Ⅰ导联负向，Ⅱ（或 aVF）导联正向**：电轴右偏（超过 +90°）。原因包括右心室肥厚、肺栓塞、左后分支阻滞；在瘦高的年轻人中也可为正常。

若要更精确的估计，找出 QRS 最接近等电位的肢体导联，电轴与该导联垂直。

::: example 计算心电轴 {#ex-axis}
一位 32 岁男性的心电图中，Ⅰ导联 QRS 以负向为主（小 r 波、深 S 波），Ⅱ导联以正向为主，aVF 明显正向。aVR 导联接近等电位。估计心电轴并提出可能的原因。

::: solution
Ⅰ导联负向而 aVF 正向，电轴位于 +90° 与 +180° 之间：**电轴右偏**。等电位导联为 aVR，位于 −150°。与之垂直的方向为 +120° 和 −60°；由于 aVF 正向，电轴约为 **+120°**。

可能的原因包括右心室肥厚（例如由肺动脉高压或肺动脉瓣狭窄引起）、急性或慢性肺栓塞、左后分支阻滞、右位心或肢体导联接反（检查Ⅰ导联 P 波是否直立：左右手电极接反时 P 波倒置）。在无症状的瘦高年轻人中，轻度电轴右偏可以是正常的。这一发现需结合临床情况和心电图其余部分解读。
:::
:::

## 系统阅读

每份心电图都按同样的顺序阅读，以免遗漏。

1. **基本信息**：患者姓名、日期和时间、记录时有无症状，以及定标和走纸速度。
2. **心率**。
3. **心律**：是否规则？每个 QRS 之前是否都有 P 波，每个 P 波之后是否都有 QRS？Ⅱ导联 P 波是否直立（提示来自窦房结）？
4. **心电轴**。
5. **P 波**：形态和大小。
6. **PR 间期**：缩短、正常还是延长；恒定还是变化。
7. **QRS**：宽度、振幅、Q 波、束支传导阻滞图形。
8. **ST 段**：抬高或压低，以及其形态。
9. **T 波**：倒置、高尖、低平。
10. **QT 间期**以及有无 U 波。
11. **与既往心电图比较**。变化比任何单一的异常更重要。

## 常见异常图形

### 心室肥厚与束支传导阻滞

**左心室肥厚**在左心室上方的导联产生高 QRS 电压，在右侧导联产生深 S 波。一个广泛使用的标准（Sokolow-Lyon）是 V1 的 S 波加上 V5 或 V6 中较大的 R 波超过 35 mm。心电图电压标准特异性高但敏感性低，且在瘦的年轻人中电压常偏高；超声心动图是评估左心室质量更好的检查。侧壁导联 ST 段压低和 T 波倒置的"劳损"图形提示肥厚较重。

**束支传导阻滞**使 QRS 增宽到 0.12 s 或以上，因为一侧心室是经心肌而非经传导系统缓慢激动的。

- **右束支传导阻滞（RBBB）**：V1 呈 RSR′ 图形（第二个 R 波），Ⅰ和 V6 导联出现宽而粗钝的 S 波。可见于健康人，也可见于房间隔缺损、肺栓塞和缺血性心脏病。
- **左束支传导阻滞（LBBB）**：Ⅰ、aVL、V5 和 V6 导联出现宽大、常有切迹的 R 波，V1 出现深而宽的 S 波。LBBB 几乎总是提示存在基础心脏病（缺血性、高血压性、心肌病或瓣膜病）。它使 ST 段变形，使缺血难以判读。

一个有用的记忆方法是：RBBB 时 V1 的波群以正向为主，LBBB 时以负向为主。

### 缺血与梗死

缺血首先影响复极。**ST 段压低**和 **T 波倒置**提示心内膜下缺血。**ST 段抬高**提示透壁损伤，通常由心外膜冠状动脉完全闭塞引起。

::: definition 急性心肌梗死的 ST 段抬高 {#def-stemi}
在没有左心室肥厚或左束支传导阻滞的情况下，《第四版心肌梗死全球定义》（2018）将缺血性 ST 段抬高定义为至少两个相邻导联 J 点处新出现的 ST 段抬高：

- V2–V3 以外的所有导联 **≥ 1 mm**；
- **V2–V3**：40 岁及以上男性 ≥ 2 mm，40 岁以下男性 ≥ 2.5 mm，任何年龄女性 ≥ 1.5 mm。

对侧壁导联出现**对应性 ST 段压低**支持诊断。新发 LBBB、起搏心律、后壁心肌梗死（V1–V3 ST 段压低伴高 R 波）和某些其他图形也可提示急性冠状动脉闭塞，需按专科标准判断。
:::

全层心肌梗死的演变遵循典型顺序：数分钟内出现超急性期高大 T 波；数小时内 ST 段抬高；随着梗死心肌失去电活动、电极"透过"它看到对侧心壁，出现病理性 Q 波（数小时至数天）；数天内 T 波倒置。及时再灌注可以中断这一顺序。Q 波是陈旧性梗死的电学瘢痕。

::: example 胸痛伴异常心电图 {#ex-stemi}
一位 61 岁男性出现 40 分钟的胸骨后压榨性疼痛伴出汗。心电图显示Ⅱ、Ⅲ、aVF 导联 ST 段抬高 3 mm，Ⅰ和 aVL 导联 ST 段压低 2 mm，窦性心律 52 次/分。解读心电图并说明其直接意义。

::: solution
**急性下壁 ST 段抬高型心肌梗死（STEMI）。** Ⅱ、Ⅲ、aVF（相邻的下壁导联）ST 段抬高远超 1 mm 阈值，Ⅰ和 aVL 的 ST 段压低是对应性改变，加强了诊断。罪犯血管最常为右冠状动脉。

心率慢与之相符：右冠状动脉通常供应窦房结和房室结，下壁梗死还会增加迷走张力。应加做右胸导联（V4R），因为右心室受累会使患者对硝酸酯类敏感，并依赖充足的充盈。

直接意义是**紧急再灌注**。根据英国（NICE）和欧洲指南，对症状出现 12 小时内就诊者，如果能在可给予溶栓的时间点之后 120 分钟内完成直接经皮冠状动脉介入治疗，则首选直接 PCI；否则进行溶栓。细节见[[cardiovascular/coronary-artery-disease]]。
:::
:::

**心包炎**也引起 ST 段抬高，但它分布广泛（不局限于一个冠状动脉供血区），呈凹面向上（"马鞍形"），没有对应性压低（aVR 和 V1 除外），常伴 PR 段压低。**良性早期复极**常见于年轻男性，引起轻度凹面向上的 ST 段抬高，J 点有切迹，主要见于胸导联，且随时间稳定。

### 电解质与药物

钾的影响最为显著：

- **高钾血症**：T 波高尖；继而 P 波低平、消失，PR 延长；再后 QRS 增宽；最终出现正弦波图形、心室颤动或心搏停止。心电图改变与血钾水平的相关性不强，因此心电图正常并不能排除危险的高钾血症。
- **低钾血症**：T 波低平、ST 段压低和明显的 U 波（T 波之后的小波），QT 看似延长。
- **高钙血症**使 QT 缩短；**低钙血症**使 QT 延长。
- **地高辛**在治疗浓度时引起下垂型（"反勾形"）ST 段压低；中毒时几乎可引起任何心律失常，典型的是房性心动过速伴房室传导阻滞。

::: example 透析患者的宽 QRS 波 {#ex-hyperk}
一位 58 岁的血液透析女性错过了两次透析，感到乏力。心电图显示 P 波消失，QRS 时限 0.16 s，T 波高尖；心率 48 次/分。解读心电图并概述紧急处理原则。

::: solution
T 波高尖、P 波消失和宽 QRS 伴心动过缓的图形提示**重度高钾血症**，有即将发生心搏骤停的高风险。错过透析是可能的原因。

处理遵循当地指南和英国复苏委员会（Resuscitation Council UK）指南，有三个目标：

1. **保护心脏**：静脉注射钙剂（葡萄糖酸钙或氯化钙）可在数分钟内稳定心肌细胞膜。它不降低血钾。
2. **使钾转入细胞内**：静脉注射胰岛素加葡萄糖，常同时雾化吸入沙丁胺醇（salbutamol）；两者均在约 15–30 分钟内起效，需监测血糖。
3. **将钾排出体外**：对透析患者，紧急透析是根本治疗；钾结合剂起较慢的辅助作用。

持续心电监护必不可少。给予钙剂后复查心电图；如改变持续存在，可能需要重复给药。
:::
:::

### 预激与遗传性离子通道病

在 **Wolff-Parkinson-White（WPW）综合征**中，一条额外的传导通路（旁路）连接心房和心室，绕过房室结。部分心室被提前激动，产生**短 PR 间期**（小于 0.12 s）和 QRS 起始部粗钝的上升支，即 **delta 波**，使 QRS 增宽。旁路使折返性心动过速成为可能。如果发生心房颤动，旁路可极快地向心室传导，引起心室颤动，这就是为什么预激伴心房颤动时应避免使用房室结阻滞药物。旁路导管消融通常可以根治。

几种遗传病直接影响离子通道本身。**先天性长 QT 综合征**（最常见的是 *KCNQ1*、*KCNH2* 或 *SCN5A* 变异）延长复极，易发生尖端扭转型室速；典型诱因因类型而异（运动和游泳、突然的噪音或情绪、睡眠）。**Brugada 综合征**常由钠电流减少引起，V1–V2 出现穹窿形 ST 段抬高，有发生心室颤动的风险，通常在静息时或发热时。正因为有这两种疾病，年轻人不明原因的晕厥或猝死会促使对其亲属进行心电图筛查（[[genetics/mendelian-inheritance]]）。

::: warning 既要读图，也要看患者
有两种常见错误。第一是相信机器打印的诊断。自动报告有用，但会遗漏细微的 ST 段抬高、把伪差误读为心律失常，并过度报告轻微异常；每份心电图都需要人结合临床情况来阅读。第二是认为心电图正常就排除了急性冠脉综合征。在后来证实为心肌梗死的患者中，相当一部分人的首份心电图正常或无诊断意义，回旋支闭塞尤其如此，因为标准导联对其供血区域观察不佳。需要复查心电图、检测肌钙蛋白并重视病史。
:::

::: quiz
在以 25 mm/s 记录的标准心电图上，规则心律的 R 波间隔 15 个小方格。心率是多少？
- [ ] 60 次/分
- [ ] 75 次/分
- [x] 100 次/分
- [ ] 150 次/分
::: solution
心率 $= 1500/15 = 100$ 次/分。也可以这样算：15 个小方格是 3 个大方格，$300/3 = 100$。每个小方格为 0.04 s，所以 RR 间期为 0.6 s，$60/0.6 = 100$。
:::
:::

::: history
1887 年，沃勒（Augustus Waller）在伦敦用毛细管静电计记录了第一份人体心电图，但波形很小，难以解读。莱顿的爱因托芬（Willem Einthoven）制造了灵敏得多的弦线电流计，到 1903 年已能记录清晰的心电图；他命名了 P、Q、R、S 和 T 波，定义了三个标准肢体导联，并描述了以他名字命名的三者之间的关系。他于 1924 年获得诺贝尔生理学或医学奖。威尔逊（Frank Wilson）在 20 世纪 30 年代引入单极胸导联，戈德伯格（Emanuel Goldberger）于 1942 年引入加压肢体导联，形成了今天使用的 12 导联心电图。20 世纪初，伦敦的刘易斯（Thomas Lewis）使用爱因托芬的仪器，以心电图解释了心房颤动和其他心律失常。
:::

## 后续内容

心律失常的机制、缓慢性和快速性心律失常及其治疗见[[cardiovascular/arrhythmias]]。缺血和梗死的心电图改变在[[cardiovascular/coronary-artery-disease]]中结合急性冠脉综合征进一步阐述。离子通道和静息电位的一般内容见[[physiology/membrane-potentials]]，钾平衡见[[renal/potassium-calcium-phosphate]]。

::: summary
- 心室肌细胞有钠驱动的快速上升支和长的钙平台期，因而不应期长；结区细胞有缓慢的钙上升支，并通过$I_f$自发进行 4 期去极化。
- 冲动传导路径：窦房结 → 心房 → 房室结（延迟）→ 希氏束 → 束支 → 浦肯野纤维。较低位的起搏点频率较慢。
- 走纸速度 25 mm/s 时，一个小方格为 0.04 s，一个大方格为 0.2 s。心率等于 300 除以 R-R 间的大方格数。
- 正常 PR 0.12–0.20 s，QRS < 0.12 s；QTc（Bazett，QT/√RR）男性超过约 450 ms、女性超过约 470 ms 为延长，超过 500 ms 为高风险。
- 正常电轴为 −30° 至 +90°；Ⅰ、Ⅱ导联可快速估计。
- 缺血性 ST 段抬高为两个相邻导联 ≥ 1 mm（V2–V3 阈值更高）并伴对应性改变；导联可定位受累区域。
- 高钾血症表现为 T 波高尖、P 波消失和 QRS 增宽；WPW 表现为短 PR 和 delta 波；长 QT 和 Brugada 是遗传性离子通道病。
:::

## 习题

::: exercise 由心电图计算心率 {level=1 check="round(300/3.5)"}
规则心律在走纸速度 25 mm/s 的心电图上 R 波间隔 3.5 个大方格。计算心率，四舍五入到整数（次/分）。
::: solution
心率 $= 300/3.5 = 85.7$，四舍五入为 **86 次/分**。
:::
:::

::: exercise 校正 QT {level=1 check="500"}
实测 QT 间期为 400 ms，RR 间期为 0.64 s。按 Bazett 公式计算 QTc（ms，精确值）。
::: solution
$\sqrt{0.64} = 0.8$，所以$QT_c = 400/0.8 =$ **500 ms**。这明显延长，应审查药物和电解质。
:::
:::

::: exercise 哪个区域？ {level=1}
说出下列 ST 段抬高对应的区域和最可能的罪犯血管：(a) V1–V4；(b) Ⅱ、Ⅲ和 aVF；(c) Ⅰ、aVL、V5 和 V6。
::: solution
(a) **前间壁**，左前降支。

(b) **下壁**，通常为右冠状动脉（有时为优势型回旋支）。

(c) **侧壁**，回旋支或左前降支的对角支。
:::
:::

::: exercise 左束支还是右束支 {level=2}
两份心电图的 QRS 时限均为 0.14 s。第一份 V1 呈 rSR′ 波，Ⅰ导联有宽 S 波。第二份 V1 呈深而宽的 QS 波，V6 呈宽大有切迹的 R 波且无 Q 波。识别每种图形并说明其意义。
::: solution
第一份是**右束支传导阻滞**。右心室激动延迟，在 V1 产生第二个正向波（R′），在左侧导联产生晚而宽的 S 波。它可以是正常发现，但也可伴发于房间隔缺损、肺栓塞或缺血性心脏病。

第二份是**左束支传导阻滞**。室间隔从右向左激动（因此 V6 无间隔性 q 波），左心室激动缓慢。LBBB 几乎总提示结构性心脏病，应行超声心动图检查；它也使 ST 段难以用于判断缺血。
:::
:::

::: exercise 心包炎还是闭塞？ {level=2}
一位 23 岁男性在一次病毒感染后出现锐痛性胸痛，平卧加重、前倾坐位缓解。心电图显示Ⅰ、Ⅱ、aVL、aVF 和 V2–V6 导联凹面向上的 ST 段抬高 1.5 mm，Ⅱ导联 PR 段压低，仅 aVR 导联 ST 段压低。列出支持心包炎而非急性冠状动脉闭塞的特征。
::: solution
- ST 段抬高**分布广泛**，跨越多个冠状动脉供血区，而非局限于一个区域。
- ST 段呈**凹面向上**（"马鞍形"）。
- 除 aVR（有时 V1）外**没有对应性 ST 段压低**，而 aVR 的压低在心包炎中是预期的。
- **PR 段压低**反映炎症心包对心房的损伤。
- **疼痛**与体位有关、呈胸膜炎性，发生于病毒感染后的年轻男性。

没有 Q 波，也没有梗死的演变过程。如果伴有心肌炎，肌钙蛋白仍可能轻度升高，超声心动图可寻找积液。如仍有疑问，需复查心电图并请专科会诊，因为漏诊闭塞的危害更大。
:::
:::

::: exercise 血钾升高的顺序 {level=2}
将下列心电图改变按血钾升高时通常出现的顺序排列：QRS 增宽；T 波高尖；正弦波图形；P 波消失和 PR 延长。解释为什么治疗时首先给予钙剂。
::: solution
**T 波高尖 → P 波消失和 PR 延长 → QRS 增宽 → 正弦波图形**（继而心室颤动或心搏停止）。这是典型的进展顺序，但改变与实测血钾的相关性不强，也可能跳过某些步骤。

首先给予钙剂，是因为它在数分钟内起效，稳定心肌细胞膜，提高兴奋阈值、降低心律失常风险，同时等待较慢的使钾转入细胞或排出体外的治疗起效。钙剂并不降低血钾。
:::
:::

::: exercise 短 PR 与粗钝的上升支 {level=2}
一位 19 岁学生有快速而规则的心悸发作。发作间期心电图显示 PR 间期 0.10 s，QRS 0.13 s，上升支粗钝。解释这些发现，并说明如果她发生心房颤动，为什么地高辛或维拉帕米是危险的。
::: solution
这些是 **Wolff-Parkinson-White 图形**的特征。旁路不经房室结延迟就从心房传到心室，部分心室被提前激动：PR 缩短，经普通心肌的早期缓慢激动产生 delta 波和宽 QRS。她的心悸最可能是利用旁路的房室折返性心动过速。

在心房颤动时，房室结通常会限制极快的心房冲动传到心室的数量，而旁路没有这种限制。阻滞房室结的药物（地高辛、维拉帕米、地尔硫䓬，以及腺苷）消除了房室结的竞争，可能增加经旁路的传导，导致极快的心室率，并可蜕变为心室颤动。她应转诊进行电生理检查和导管消融。
:::
:::

::: exercise 解读一份心电图 {level=3}
一位 81 岁男性因一次短暂意识丧失的跌倒入院。心电图显示窦性心律 66 次/分，PR 间期 0.28 s，QRS 0.14 s，V1 呈 rSR′，Ⅰ导联有宽 S 波；Ⅰ导联 QRS 以正向为主，Ⅱ导联以负向为主。全面解读心电图，并讨论它对其跌倒原因的提示。
::: hint
依次分析心率、心律、电轴、PR、QRS。有几个传导分支显示出病变证据？
:::
::: solution
- **心率和心律**：窦性心律，66 次/分。
- **PR 间期** 0.28 s：**一度房室传导阻滞**（超过 0.20 s）。
- **QRS** 0.14 s，V1 呈 rSR′，Ⅰ导联宽 S 波：**右束支传导阻滞**。
- **电轴**：Ⅰ导联正向、Ⅱ导联负向：**电轴左偏**，在此情况下提示**左前分支阻滞**。

右束支传导阻滞加左前分支阻滞为**双分支阻滞**：只有左后分支传导正常。再加上 PR 间期延长，提示存在广泛的传导系统病变（有时被笼统地称为"三分支"病变，尽管 PR 延迟可能位于房室结）。

因此，他伴意识丧失的跌倒可能由**间歇性完全性心脏传导阻滞**（阿-斯综合征发作，Stokes-Adams attack）引起，这可以解释无预兆的突然晕倒和迅速恢复。鉴别诊断包括直立性低血压、颈动脉窦过敏、室性心动过速（如有结构性心脏病）以及非心源性原因，如癫痫发作或机械性跌倒。他需要心电监护、审查减慢传导的药物、超声心动图和专科评估；有记录或高度怀疑的间歇性高度房室传导阻滞是植入永久起搏器的指征（[[cardiovascular/arrhythmias]]）。
:::
:::
