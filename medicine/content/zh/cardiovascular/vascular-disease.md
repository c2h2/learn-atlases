血管树是循环系统的分配工程：弹性导管、肌性节流、交换晶格与容量床、每段以各自的临床习语失效——动脉闭塞、主动脉扩张并撕裂、静脉血栓并反流、毛细血管失调。物理处处相同——Laplace张力-半径关系、顺应性的脉搏波与反射算术、狭窄处Poiseuille与湍流——本章四门临床科学（粥样硬化-梗阻性、动脉瘤-夹层性、炎症性、静脉-淋巴性）是逐段读出的那套物理。

本章讲述动脉壁生物学与僵硬度、外周动脉病、动脉瘤与夹层、血管炎与Raynaud现象、及慢性静脉病。

## 壁与其负荷

::: definition 动脉壁、脉搏波与僵硬化 {#def-wall}
**弹性动脉（主动脉及其大分支）**是复合压力容器——带糖萼与机械感知的内膜内皮（[[cardiovascular/circulation-blood-pressure]]的剪切介导一氧化氮生物学）、弹性板层与平滑肌的中膜（滋养血管喂养其外壁——[[pathology/haemodynamics]]动脉粥样硬化发生场的附膜与炎症贡献）、及胶原外膜壳——其功能随**年龄、压力、血糖与吸烟**退化：弹性蛋白疲劳与断裂、胶原交联（[[endocrine/diabetes]]的晚期糖基化化学）、中膜钙化（[[renal/potassium-calcium-phosphate]]的钙磷乘积与糖尿病及肾小管的Mönckeberg中膜钙化硬化）、及平滑肌表型转换（[[cell-biochemistry/signalling-cell-cycle]]收缩到合成的转换）。血流动力学后果是**动脉僵硬化**：**脉搏波速度上升（Moens-Korteweg平方根律——壁越硬波越快）、收缩压波与其反射的早期_return_在主动脉而非外周叠加（增强指数上升——[[cardiovascular/circulation-blood-pressure]]运动的老年单纯收缩期高血压、宽脉压、及作为研究级动脉年龄测量的颈-股脉搏波速度）、左室后负荷与冠脉舒张灌注压双双恶化（中心对上臂压力的锯齿）、及脑与肾的微循环失去其搏动流缓冲（僵硬动脉的白质与肾小球损伤——[[nervous-system/stroke]]与[[renal/chronic-kidney-disease]]共享的土壤）。** **内皮功能障碍——糖萼脱落与NO对内皮素-1及活性氧的转换、黏附分子上调与促凝表面（[[blood/thrombosis-anticoagulation]]的组织因子与血栓调节蛋白生物学）**是最早、全身、部分可逆的病灶：吸烟、脂质、糖与压力的通用货币、及本章疾病共存并互相预测的原因（[[cardiovascular/coronary-artery-disease]]的风险因子算术无处不在）。
:::

## 梗阻：外周动脉

::: definition 外周动脉病：从跛行到组织缺失 {#def-pad}
动脉粥样硬化的下肢分布遵循同一[[cardiovascular/coronary-artery-disease]]过程、带腿特异解剖（**收肌管的隐股段与腘及胫腓run-off——[[anatomy/lower-limb]]的外科走廊、带糖尿病的中型变与胫及足血管优势**）。临床阶梯（Fontaine与Rutherford分类）是**间歇性跛行——固定工作量诱发、休息数分钟内缓解的肌肉痛（[[cardiovascular/coronary-artery-disease]]练习器的血流储备算术、按病变水平在小腿或大腿或臀部、及[[musculoskeletal/back-pain]]与椎管狭窄及静脉与神经源的性的性事与勃起及Leriche主髂综合征与假性跛行鉴别）**→**静息痛（临界灌注底线：夜间、下垂位、足与趾的痛、悬腿缓解——灌注压与小动脉最大程度舒张的生理）**→**组织缺失（溃疡、坏疽：慢性肢体威胁性缺血、付不起自身修复伤的伤口——赤字的[[surgery/wounds-surgical-infection]]愈合生理、糖尿病足的神经病变与畸形与感染叠加——[[endocrine/diabetes ]]）**。诊断是床旁加简单物理：**脉搏检查与动脉杂音及下垂发红与毛甲营养改变、然后踝肱指数（多普勒收缩压比：≤0.9诊断、0.4–0.9跛行带、<0.4典型肢体威胁——及糖尿病与肾病钙化血管的假阴性、由趾压的不可压缩免疫与TcPO₂经皮氧及双工波形与CT与MR及导管造影层级救回——[[clinical-skills/medical-imaging]]分辨率对风险的阶梯）**；及**急性肢体威胁栓塞或血栓的六个P表现——痛、白、无脉、感觉异常、瘫、冷——血管急症、其存活分诊（感觉运动丧失与多普勒信号）决定即刻肝素加栓子切除或溶栓或primary截肢、再灌注损伤（骨筋膜室综合征与肌红蛋白尿性[[renal/acute-kidney-injury]]及钾负荷）及栓子来源搜寻（房颤与动脉瘤与反常路径——[[cardiovascular/arrhythmias]]、[[#def-aneurysm]]）在小内跟随（[[emergency-critical-care/acute-assessment ]]）**。管理走三条腿：**使心血管死亡减半的风险因子与抗栓药物（他汀与戒烟与抗血小板、选定患者的低剂量利伐沙班加阿司匹林血管剂量策略——COMPASS算术与出血平衡、[[blood/thrombosis-anticoagulation]]）、运动处方（监督规划——侧支与肌肉代谢及内皮机制及指南在血运重建前的一线地位）、及生活方式限制性跛行保守失败与所有肢体威胁的血运重建（血管成形加支架对外科旁路决定——病变长度与run-off与移植物 与耐久性的腔内对外科试验家族权衡、及混合与日归时代的患者特异答案；不适用者的交感阻断与前列环素及脊髓刺激救援层级、及截肢平面哲学——保膝、规划假肢、及[[surgery/orthopaedics]]邻近康复服务的残端护理与幻痛随访）。**
:::

::: example 橱窗购物者的小腿 {#ex-claudication}
63岁吸烟者走100米右小腿抽筋、橱窗购物20分钟被迫停下、3分钟缓解；足脉搏消失、小腿肌萎缩、右踝肱指数0.62、左0.95。
::: solution
**典型单侧隐股/腘区跛行（Rutherford 2–3级、Fontaine IIb）。**定位是临床的：**小腿=股腘或胫动脉病变、大腿与臀=主髂、勃起功能障碍加臀的Leriche模式；0.62的踝肱指数确认中度梗阻、不对称给病变定位侧（[[#def-pad]]的压力比逻辑与[[anatomy/lower-limb]]收肌管的偏爱——动脉在管出口的拴系是其首先闭塞的原因）。**管理按获益排序：**戒烟（对进展与截肢的最大单项效应——管理复吸的规划、不止劝告）、监督运动（走到痛并休息的方案及其侧支与代谢机制——指南一线、及使其成真的依从结构）、全面二级预防药物（高强度他汀与抗血小板及血压与糖尿病优化——共存并杀死患者的冠脉与颈动脉及肾动脉病——[[cardiovascular/coronary-artery-disease]]与[[cardiovascular/hypertension]]共享粥样硬化政策）、神经受累时的足护理与糖尿病足界面（[[endocrine/diabetes]]）；及仅上述失败且生活方式受限时的造影加干预（血管成形加支架对股腘旁路的病变与患者选择——选外科时静脉移植物优先的耐久性规则）。**随访脚本含患者自身的洞见：**小腿在宣告全身病——五年冠脉与卒中事件率与腿相当。**
:::

## 动脉瘤、夹层、与Laplace的算术

::: definition 扩张与撕裂的主动脉 {#def-aneurysm}
**动脉瘤**是持续动脉扩张（主动脉：≥1.5倍正常直径——肾下腹部的3 cm基线与梭形粥样硬化模式对胸部的结缔组织领地——Marfan与Loeys与血管性Ehlers-Danlos主动脉病及[[cardiovascular/valve-congenital-disease]]的二叶瓣与缩窄关联及[[genetics/mendelian-inheritance]]原纤维胶原、及霉菌性与炎症性及IgG4相关变异）。自然史是**Laplace生长：壁张力随半径上升（练习器的线性项）、板层与弹性蛋白中膜变薄并炎症（[[pathology/chronic-inflammation-repair]]的MMP与巨噬细胞蛋白溶解）、破裂风险在约5.5 cm之上陡升——证成对65岁男性人群超声筛查（死亡率削减试验）与择期修复-然后-监测规划（开放与腔内（EVAR）手术的动脉瘤囊隔绝、其I–III型内漏与囊再生及移植物感染及肾与脊髓缺血监测影像时间表）的尺寸阈值逻辑（带形态、增长率、囊状形态与家族修正的精化）**。破裂表现经典三联（痛、低血压、搏动性包块——少数携带全部三样）、活在分钟-到-手术室或破裂套间决定上。**夹层**是不同的力学课：**内膜撕裂（升主动脉与弓的更大剪切、或原发壁内血肿变异的滋养血管出血）把血驱入劈开的中膜平面（高血压与年轻结缔组织及二叶瓣及妊娠及可卡因及医源组的囊性中膜坏死底物）、造出带自己血流政治的假腔——并发症是分支血管的（冠脉开口与颈动脉及脊髓及肾及肠系膜——卒中与截瘫及肠与肢体缺血）及主动脉瓣与心包的（[[cardiovascular/circulation-blood-pressure]]分类的急性主动脉瓣反流与填塞）。** **Stanford A对B的划分（任何升主动脉累及=A）是治疗算法唯一要紧的解剖：A夹层进手术室（死亡率逐时攀升、根与弓及冠脉开口重建是手术）、而单纯B用抗冲击治疗（β阻滞剂优先规则——降dP/dt与剪切、不只是压力、然后扩血管药加用；复杂B——缺血、破裂、快速扩张——进入胸主动脉腔内支架世代）、两者长期影像、及年轻与家族性的基因与家系筛查（TGF-β与原纤维蛋白及胶原组套——[[genetics/genomic-medicine]]）。**主动脉综合征的鉴别（撕裂样疼痛游走与脉搏血压差异及纵隔增宽及D-二聚体的年龄调整排除及CT血管造影仲裁——[[emergency-critical-care/acute-assessment]]胸痛路径伴[[cardiovascular/electrophysiology-ecg]]与[[cardiovascular/coronary-artery-disease]]的对手）是本章时间关键的鉴别。
:::

::: example 撕裂的背 {#ex-dissection}
66岁高血压男性突然倒地、肩胛间撕裂痛即刻达最高；右臂血压188/102、左臂128/80；心电图左室劳损；胸片纵隔增宽；嗜睡但四肢能动。
::: solution
**CT说话之前就是急性主动脉夹层——双臂压差、即刻达峰的痛与高血压三联。**即刻生理导向治疗：**降主动脉壁剪切——先静脉β阻滞（艾司洛尔或拉贝洛尔可滴定的心率底线<60及收缩压100–120的抗冲击压力目标）、β阻滞后才加扩血管药（硝普钠或尼卡地平）、因为未阻滞后扩血管药的反射性正性肌力升高dP/dt并推进撕裂（与[[physiology/autonomic-nervous-system]]嗜铬细胞瘤规则同一无对抗正性肌力逻辑、及[[cardiovascular/circulation-blood-pressure]]后负荷对收缩力区分的致命化）。**然后解剖决定：**全主动脉CT血管造影（撕裂、真假腔与分支血管累及）——升主动脉（Stanford A）一小时内进手术室（升主动脉血肿与心包积液与主动脉瓣反流与冠脉开口及颈动脉缺血发现各自抬高紧急度；此处嗜睡要求弓血管评估及卒中对深镇静对选择性灌流的算术）；降主动脉（单纯B）进抗冲击单元配系列影像及β阻滞剂终身续用、复杂B（缺血、破裂、顽固痛与高血压、快速扩张）进胸主动脉支架。**并发症清单读起来像解剖研讨会（脊髓Adamkiewicz动脉截瘫及肾与肠系膜及肢体缺血及要求终身影像的晚期动脉瘤样假腔扩张）、及病因脚注：**题干的未控高血压是人群主驱动——[[cardiovascular/hypertension]]预防论证以主动脉壁的毫米陈述。**
:::

## 血管的炎症与痉挛

::: definition 血管炎与Raynaud {#def-vasculitis}
**血管炎**是按口径与表型分类的血管壁炎症（Chapel Hill命名——大：**巨细胞动脉炎与大动脉炎**；中：**结节性多动脉炎及伴多动脉炎及嗜酸性及显微镜下多血管炎的ANCA相关肉芽肿**；小：免疫复合物与ANCA小血管病及IgA与冷球蛋白及抗GBM与[[renal/chronic-kidney-disease]]邻近章肾小球肾炎重叠）——此处按**超过其风湿表现的血管表现**组织：**巨细胞动脉炎（50岁以上颞颌下颌关节跛行与头皮触痛及CRP与ESR升高、永久视力丧失威胁要求在活检前即刻大剂量激素——颞动脉活检与超声晕征及FDG主动脉炎影像、风湿性多肌痛重叠及激素节省的托珠单抗时代——[[musculoskeletal/connective-tissue-vasculitis]]持有完整分类）；大动脉炎（年轻女性无脉主动脉弓——肢体跛行与颈动脉及[[cardiovascular/hypertension]]的高血压章肾动脉狭窄继发高血压、血管壁MRI与造影分期及激素加节省免疫抑制及静止期手术与血管成形时机）；ANCA相关与结节性多动脉炎（单神经炎多发与指端及肠系膜及肾微动脉瘤及中血管动脉瘤及乙肝关联——邻近[[microbiology/viruses]]）；及血管邻近的模仿者（胆固醇结晶与华法林及暴发性及感染性及放射性及药物血管炎清单）。** **Raynaud现象**是发作性指小动脉痉挛（苍白-发绀-潮红三相颜色故事、寒冷与情绪扳机）按病因划分：**原发性（对称、年轻、甲褶毛细血管正常且自身抗体阴性、钙阻滞剂与保暖及剂量滴定的管理及安心路径）对结缔组织病继发性（硬皮病谱系与混合及重叠——异常甲褶毛细血管镜与特异自身抗体——[[musculoskeletal/connective-tissue-vasculitis]]与[[immunology/autoimmunity]]、指端凹陷与溃疡、及使血压监测成为救器官检查的硬皮病肾危象ACE抑制剂强制——[[renal/acute-kidney-injury]]肾素驱动病灶）；药物与职业清单（β阻滞剂与麦角及化疗药及可卡因及手-臂振动白指）；及紧急缺血型冷球蛋白与冷凝集素及冷纤维蛋白原蛋白现象、抗磷脂血栓性指端与血管炎指、指缺血规程——复温、扩血管药（硝苯地平与PDE5及前列环素及交感阻断层级）、抗血小板与病因治疗、及肉毒毒素与颈交感切除救援阶梯——适用（[[blood/thrombosis-anticoagulation]]血栓性指端鉴别）。** Buerger病（血栓闭塞性脉管炎——年轻重度吸烟者、远端血管与浅表血栓性静脉炎及弓血管节段炎症血栓、螺旋状侧支及只有截肢与戒断的进展故事）结束清单：**唯一治疗全是吸烟的血管病**（免疫复合物血管炎的[[immunology/hypersensitivity]]III型邻近领地）。
:::

::: example 白指 {#ex-raynaud}
29岁办公室职员在超市与洗碗后手指痛性蓝白；今年指尖成愈合缓慢的裂口；查体指垫皮肤紧绷发亮、甲褶毛细血管脱失；ANA 1:1280阳性、着丝点型。
::: solution
**伴早期系统性硬化谱系病（局限/着丝点表型）及初发指溃疡的继发性Raynaud。**病理生理从痉挛升级为结构：**多年寒冷触发的α₂肾上腺素能及5-羟色胺及内皮素-1血管收缩伴NO与前列环素舒张不足（[[cardiovascular/circulation-blood-pressure]]内皮在最小尺度）加硬皮病血管闭塞性内膜与外膜纤维化——甲褶毛细血管脱失是那重塑的显微镜、指溃疡是终点。**管理走两半：**血管痉挛臂（保暖与手套与习惯架构、滴定的二氢吡啶钙阻滞剂（头痛与踝水肿代价——[[cardiovascular/circulation-blood-pressure]]毛细血管前扩张剂Starling水肿）、溃疡的PDE5抑制剂与前列环素及内皮素受体药物层级、交感阻断与肉毒救援）、血栓-炎症臂（抗血小板与避免溃疡的外伤感染规划——[[surgery/wounds-surgical-infection]]愈合生物学）、及救器官的全身监护：血压与肌酐（硬皮病肾危象——[[cardiovascular/hypertension]]肾素-恶性高血压生理及ACE抑制剂作为救命治疗的规则及危象前激素警诫）、肺高压与间质肺年度复查（[[respiratory/interstitial-vascular-disease]]）、心脏与胃肠（[[gastrointestinal/oesophagus-stomach]]食管动力障碍）、及自身抗体特异轨迹咨询。**教学：**Raynaud是症状、不是诊断——毛细血管镜与抗体与皮肤决定它是烦恼还是病**（[[clinical-skills/physical-examination]]）。
:::

## 容量系统：静脉与淋巴

::: definition 慢性静脉病与小腿泵 {#def-venous}
腿静脉是循环的**容量室与直立挑战**：深系统及其双瓣、小腿肌泵（[[physiology/integrative-physiology]]运动静脉生理及交通支与浅系统的交界——[[anatomy/lower-limb]]大、小隐静脉领地——及站立无肌肉动作使其升至约90 mmHg、对照卧位约15 mmHg的行走静脉压）。**静脉高压**——来自瓣膜衰竭（原发性静脉曲张反流病）或梗阻（[[blood/thrombosis-anticoagulation]]深静脉血栓伴其瓣膜破坏的血栓后遗）或泵衰竭（不动、瘫痪、久站职业）——是CEAP分类的阶梯、从**蜘蛛与静脉曲张及水肿与皮炎与色素沉着（外渗红细胞的含铁血黄素——[[blood/haemoglobin-disorders]]踝部的色素化学）与脂性硬化到静脉溃疡（内踝的纤维蛋白套与细胞因子及机械牵张伤口生物学——[[surgery/wounds-surgical-infection]]慢性伤口章原型）**。管理跟随柱物理：**加压（梯度绷带与弹力袜——替代压力梯度、其依从与动脉禁忌核查（加压前的踝肱指数——[[#def-pad]]数字的双重职务）定义实践）、症状性浅反流血管内消融与泡沫硬化及外科结扎剥除时代、溃疡的四部规划（加压加清创加感染控制加植皮代用品、及四层与间歇气压及五层试验证据）、血栓后与髂加压（May-Thurner）及下腔静脉滤器邻近的介入时代、及淋巴水肿连续体（[[cardiovascular/circulation-blood-pressure]]Starling水肿鉴别：富蛋白间质的非凹陷与Stemmer征及反复蜂窝织炎淋巴损伤螺旋、以加压与运动与皮肤护理淋巴规划治疗、微丝与手术及放疗原因、及新生的生理性淋巴手术与抽脂技术）。**
:::

::: history
**Mönckeberg**的中膜钙化（1903）与**Marchand**的粥样斑块命名（1904）命名了底物；**Virchow**三联（内皮、血流与血液——1856）框定了血栓与栓塞（[[blood/thrombosis-anticoagulation]]谱系）；**John Hunter**的结扎时代动脉瘤外科及**Astley Cooper**与**Travers**的动脉讲座、**Laennec**的临床动脉瘤诊断、及**Halsted学派**的血管教学；**Rendu、Osler与Weber**的毛细血管扩张及**Hutchinson**与**Raynaud**（1860-1880年代）的痉挛与血管分类学章；**Buerger**1924年在战争吸烟者队列的血栓闭塞性脉管炎；**Eales与Takayasu（1908年“无脉病”文献）及Horton的巨细胞动脉炎命名（1930-40年代）**；**Gross与Hufnagel**的缩窄手术（1945-48）、**Crawford与DeBakey与Cooley的主动脉外科时代及Stanford学派的弓低温停跳技术**、**Linton与Babcock与Trendelenburg**的静脉外科隐静脉时代、及**Kunlin与Dubost与Wertheimer**的动脉重建世代（股腘旁路与血栓内膜切除）及**Dotter**与**Grüntzig**腔内线经**Juan Parin首例腔内支架 graft（1990年代）**抵达主动脉、及使开放对腔内修复随机化并定义现代动脉瘤实践的**EVAR-1、DREAM与OVER试验时代**；[[public-health/screening]]主动脉应用的**Fazekas与筛查试验（MASS与英国AMSTAT及Euroscreen随机超声规划）**；及使[[#def-vasculitis]]成为可读分类而非命名大游行的**Chapel Hill命名会议（1990年代-2012及2022修订）**。
:::

## 通向何处

压力与流量物理在[[cardiovascular/circulation-blood-pressure]]；动脉粥样硬化的冠脉版在[[cardiovascular/coronary-artery-disease]]；动脉瘤与夹层的高血压底物在[[cardiovascular/hypertension]]；血栓与抗凝在[[blood/thrombosis-anticoagulation]]；血管炎的完整分类在[[musculoskeletal/connective-tissue-vasculitis]]；下肢外科解剖在[[anatomy/lower-limb]]；伤口愈合在[[surgery/wounds-surgical-infection]]；筛查试验证据在[[public-health/screening]]；主动脉病遗传学在[[genetics/mendelian-inheritance]]。

::: summary
- 动脉僵硬化（弹性蛋白疲劳、交联、钙化）抬高脉搏波速度与中心收缩负荷、剥除微循环的搏动缓冲——卒中、痴呆、肾损伤与老年单纯收缩期高血压的共享底物。
- 外周病从跛行（血流储备）经静息痛（灌注底线）到组织缺失分级；踝肱指数配趾压救援、然后运动加药物优先、有指征时血管成形与旁路——而心血管死亡是主要结局。
- 动脉瘤遵循Laplace（张力∝半径）伴非线性破裂风险——筛查与择期修复的算术；夹层分为A（手术室）与B（先抗冲击、复杂则支架）。
- 血管炎与Raynaud是带肢体与器官威胁终点的血管壁炎症与血管张力失调——三相颜色手指需要甲褶毛细血管镜与抗体、绝不一律安心。
- 慢性静脉病是静柱压衰竭——加压、浅反流消融、及溃疡四部规划；淋巴水肿是Starling水肿鉴别的第五机制、自有照护阶梯。
:::

## 练习

::: exercise 解读踝肱指数 {level=1}
糖尿病患者在典型跛行病史与足脉搏消失下双侧踝肱指数1.28。解释并给下两个检查。
::: solution
**不可压缩、钙化胫动脉的假性高踝肱指数（Mönckeberg与糖尿病及肾性中膜钙化——袖带压不扁硬管、所以测得“收缩压”高估；>1.30不可压缩极限与1.0–1.3临界带）**——恰是[[#def-pad]]预测的假阴性。下一步：**趾压（指动脉抗中膜钙化——绝对趾压及其运动后下降与趾肱指数恢复生理）、及经皮氧测量（预测愈合的组织灌注代理）加双工波形及规划干预时的CT或MR血管造影。**课程可推广到每个假设被疾病违反的检查（[[epidemiology-ebm/diagnostic-tests]]）。
:::
:::

::: exercise 六个P然后呢 {level=1}
按决定权重顺序列出急性肢体缺血的存活评估及对应干预。
::: solution
**感觉丧失（轻触——最早）→运动缺失及其程度→动脉与静脉多普勒信号→皮肤肌肉不可压缩（不可逆肢体的僵硬）。**映射：**可存活（无缺失、信号可闻）→肝素、收住院、紧急影像与病因检查、择期或半急血运重建；边缘威胁（极微感觉改变）→即刻肝素加同日导管定向溶栓或取栓/腔内或外科栓子切除（按病因与时长）；即刻威胁（感觉加轻度运动缺失）→紧急血运重建（开放取栓与旁路通常快于溶栓）配筋膜切开与骨筋膜室及再灌注代谢（钾、肌红蛋白与[[renal/acute-kidney-injury]]）预防；不可逆（瘫痪、感觉丧失、固定染色、静脉多普勒不可闻）→一期截肢（给死肌肉血运重建会杀人——肌红蛋白与钾雪崩）（[[emergency-critical-care/acute-assessment]]、[[emergency-critical-care/shock-fluids]]）。**病因搜寻（房颤与动脉瘤与血栓化移植物与反常栓塞与肿瘤）及抗凝决定并行（[[blood/thrombosis-anticoagulation]]）。
:::

::: exercise 筛查还是不筛 {level=2}
总结对65岁男性腹主动脉瘤一次性超声筛查的论证（试验证据与偏倚类型）、及女性与永不吸烟者公平辩论提出的两个批评。
::: solution
**支持：流行率与Laplace自然史逻辑（[[#def-aneurysm]]与练习器）、三个随机试验及其荟萃分析显示显著腹主动脉瘤死亡率削减（英国MASS与丹麦及西澳大利亚规划）及吸烟转移时代下降的需筛人数、检查的良性（超声——无辐射无对比剂）、及择期修复对破裂死亡率差距（只有筛查能利用的数个百分点择期对数十个百分点破裂的算术）。**批评：(1)性别——女性主动脉更小、动脉瘤在更小直径破裂、试验证据（多为男性）不外推、所以男性专属规划既是敏感度缺口又是指南缺口、按尺寸指数化阈值辩论持续；(2)风险因子公平与流行率下降——队列的吸烟梯度意味着贫困集中疾病、而普筛年龄策略在永不吸烟者中低产出（过度诊断与焦虑及随访成本——[[public-health/screening]]Wilson-Jungner清单与[[epidemiology-ebm/diagnostic-tests]]流行率与似然比算术）、引出风险因子定向规划与吸烟女性之问。**
:::

::: exercise 抗冲击算术 {level=2}
定义急性夹层的血压与心率目标及为何dP/dt比绝对压力更要紧；给β阻滞剂优先顺序及透析患者的褶皱。
::: solution
**目标：数分钟内收缩压100–120 mmHg与心率<60。**物理：**主动脉壁应力的损伤成分是压力上升率与脉搏压幅值（内膜片上的dP/dt与射血冲击）、不只是稳态压力——低率、低冲动的循环较少推进夹层（[[#def-wall]]的Moens-Korteweg与剪切推理）、这就是纯扩血管药（单用硝普钠或二氢吡啶）可能有害——其反射性心动过速与正性肌力抬高冲击；先β阻滞（可滴定艾司洛尔或静脉拉贝洛尔、然后口服续用）后扩血管药是顺序（[[physiology/autonomic-nervous-system]]受体逻辑与[[cardiovascular/circulation-blood-pressure]]后负荷-收缩力对）。**透析或无尿患者的褶皱：**容量与压力状态解读改变（干体重对高血压算术——[[renal/chronic-kidney-disease]]透析中高血压及β阻滞对液体转移耐受下降）、由能超滤的团队规划降压、同样的抗冲击优先适用于随访影像与结缔组织筛查。**
:::

::: solution

::: exercise 溃疡门诊 {level=2}
78岁患者6周、4 cm、浅表、渗液、内踝溃疡伴静脉曲张、含铁血黄素与水肿；踝肱指数0.85。写出管理规划及每行的生理。
::: solution
**先诊断（混合图像的两扇门）：静脉性（部位、浅表、肉芽、脂性硬化与静脉曲张——[[#def-venous]]）带轻度动脉成分（踝肱指数0.85——[[#def-pad]]降低而不临界灌注）、所以：改良压力加压（理想40 mmHg完整压、踝肱指数0.5–0.8时23–30/改良绷带方案并监护——加压前查踝肱指数规则的临床含义：临界缺血肢体的加压致坏死）、伤口规划（温和清创与渗液管理敷料及仅临床感染才治的规则——[[surgery/wounds-surgical-infection]]慢性伤口生物学及生物膜与细胞因子环境）、水肿与小腿泵措施（抬高与运动与活动及加压袜维持相）、皮肤允许时的静脉曲张反流转诊（血管内消融的溃疡复发削减证据）、营养与蛋白与贫血纠正（愈合底物——[[blood/anaemia]]、[[gastrointestinal/clinical-nutrition]]）、及四周复评然后升级（皮代用品与植皮及负压层级、及非典型或不愈合就活检排除Marjolin溃疡与血管炎及脓皮病模仿者的规则——[[musculoskeletal/skin]]）。**

::: exercise Buerger对一切 {level=2}
33岁重度雪茄吸烟者右足静息痛、浅表血栓性静脉炎史、弓造影螺旋状、上肢累及；踝肱指数低、抗核与抗中性粒细胞胞浆抗体阴性。诊断、以阴性发现论证、并给唯一疾病修饰治疗及其证据强度。
::: solution
**血栓闭塞性脉管炎（Buerger病）**——年轻烟草使用者的节段性炎症-血栓远端血管病（雪茄与自卷烟尼古丁及添加物暴露、远端上下肢累及、游走性浅血栓性静脉炎与弓侧支图形）。阴性承载诊断：**[[#def-vasculitis]]硬皮病与ANCA及[[blood/thrombosis-anticoagulation]]血栓性指端鉴别的自身抗体血清学阴性；年龄与吸烟模式反对过早粥样硬化（仍需血脂与糖尿病及腘及以上模式——[[cardiovascular/coronary-artery-disease]]领地）；及栓塞与弓动脉瘤来源已排除（[[#def-aneurysm]]的超声与主动脉）。**疾病修饰治疗：**完全停烟草与尼古丁——唯一证明可阻止进展的干预（复吸与截肢相关；证据观察性队列强而试验少、这恰是临床紧迫性的传达方式）、成瘾规划支持（[[psychiatry/substance-use]]）**；辅助（危重缺血的前列环素与交感阻断与硬膜外及伊洛前列素及肉毒与干细胞试验层级、伤口与截肢平面照护）治缺血、从不治病因（[[surgery/vascular-urological-surgery]]的手术极限）。

**预防（粥样硬化-僵硬度轴）：**[[cardiovascular/hypertension]]与脂质及吸烟人群规划及高危门诊足检查的PAD病例发现（踝肱指数作生命体征之辩与[[#ex-claudication]]全身风险信息——他汀与抗血小板与运动包）、及僵硬度上游靶标（盐与年龄脉压——[[cardiovascular/circulation-blood-pressure]]）（[[public-health/non-communicable-disease]]）。**急症：**肢体威胁路径（六P分诊专线、即刻肝素/即刻影像规则、随叫栓子切除与溶栓及再灌注监护能力、及截肢时机伦理——[[emergency-critical-care/acute-assessment]]）；主动脉路径（[[#ex-dissection]]的胸背痛CT排除、抗冲击规程、及破裂动脉瘤即刻EVAR或开放及社区死亡复审）；两者都带卒中与心梗网络首创的转运与网络分钟预算（[[epidemiology-ebm/observational-studies]]）。**监测人群：**AAA筛查退出与生长规划（练习器阈值）、夹层与主动脉病遗传门诊（年轻与家族性配[[genetics/genomic-medicine]]）、成人先心与动脉旁路术后及移植物与支架队列（[[cardiovascular/valve-congenital-disease]]）、血管炎与硬皮病及淋巴水肿纵向服务（[[#ex-raynaud]]毛细血管镜与器官筛查配[[musculoskeletal/connective-tissue-vasculitis]]）、及静脉溃疡预防（DVT后加压与转化及手术与创伤VTE预防界面——[[blood/thrombosis-anticoagulation]]）。**人力与证据：**血管外科-内科联合会诊与腔内培训及护士主导门诊模式（糖尿病足与截肢预防数据）、及本章标记的开放缺口（女性动脉瘤阈值、抗血小板对双通路出血平衡及保肢对一期截肢试验的 Equipoise、运动规划依从及远程监测试验家族）——服务按本章生理设计、试验议程写进其审计日历（[[epidemiology-ebm/randomised-trials]]）。
