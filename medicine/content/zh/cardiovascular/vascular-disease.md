动脉和静脉出问题的方式不多。动脉会狭窄和闭塞（动脉粥样硬化、血栓形成、栓塞）、扩张和破裂（动脉瘤）、撕裂（夹层）或发生炎症（血管炎）。静脉会形成血栓（静脉血栓栓塞）或瓣膜失效（慢性静脉疾病）。每一种都产生可识别的临床表现，其中几种是急症，几分钟或几小时就决定能否保住肢体或生命：腹主动脉瘤破裂、急性主动脉夹层、急性缺血的下肢、大面积肺栓塞。

本章介绍动脉壁的力学、外周动脉疾病和急性肢体缺血、腹主动脉瘤及其筛查、主动脉夹层、血管炎和雷诺现象、静脉血栓栓塞以及慢性静脉疾病。本章遵循英国 NICE 指南和 NHS 筛查项目，并注明欧洲指南；实际处理遵循现行的当地指南。

## 血管壁及其负荷

动脉壁有三层：**内膜**（位于一薄层结缔组织上的内皮）、**中膜**（平滑肌，大动脉中还有弹性膜）和**外膜**（含有血管自身血供和神经的结缔组织）。弹性主动脉在收缩期储存能量，在舒张期释放；肌性动脉和小动脉控制血流（[[cardiovascular/circulation-blood-pressure]]）。

::: theorem 血管的 Laplace 定律 {#thm-laplace}
对于薄壁圆柱，环向壁张力 $T$（单位长度管壁上的力）与腔内压力和半径成正比：
$$
T = P \times r,
$$ {#eq-laplace}
壁应力（张力除以壁厚 $h$）为 $\sigma = Pr/h$。
:::

::: proof
沿轴线剖开一小段圆柱。作用于内面的压力以等于压力乘投影面积的力把两半推开，即 $P \times 2r \times L$。抵抗这一力的是管壁两个切缘中的张力，$2 \times T \times L$。两者相等，得 $T = Pr$。除以壁厚即得管壁材料中的应力。

这对动脉瘤有两个推论。第一，在相同压力下，较宽的动脉壁张力较大：直径 6 cm 的动脉瘤壁张力是正常 2 cm 主动脉的三倍。第二，动脉瘤扩大时管壁通常变薄，因此应力上升得更快。应力增高导致进一步扩张，扩张又使应力再次升高：这种正反馈解释了为什么大动脉瘤比小动脉瘤生长更快、更易破裂，也解释了为什么控制血压和避免血压骤升很重要。
:::

## 外周动脉疾病

::: definition 外周动脉疾病 {#def-pad}
**外周动脉疾病（PAD）**是供应下肢（较少为上肢）的动脉发生动脉粥样硬化性狭窄或闭塞。其临床阶段为：
- **无症状期**，通过踝肱压力指数降低发现；
- **间歇性跛行**：小腿、大腿或臀部的痉挛性疼痛，在行走一段可重复的距离后出现，休息数分钟内缓解；
- **慢性威胁肢体的缺血**：由灌注严重减少引起的静息痛（典型为夜间足部疼痛，下垂肢体可缓解）、溃疡或坏疽。截肢风险高。

**踝肱压力指数（ABPI）**是踝部（足背动脉或胫后动脉）最高收缩压除以肱动脉最高收缩压。数值**低于 0.9** 提示 PAD。数值高于约 1.3 提示动脉钙化、不可压缩（常见于糖尿病和慢性肾脏病），此时该指数不可靠，应改用趾压或其他检查。
:::

PAD 与冠心病有相同的危险因素，尤其是**吸烟**和**糖尿病**。它是广泛动脉粥样硬化的标志：PAD 患者发生心肌梗死和卒中的风险很高，这些事件造成的死亡多于下肢疾病本身。体征包括脉搏消失或减弱、股动脉杂音、皮肤苍白发凉、毛发脱落，重症时有 **Buerger 征**：抬高时苍白，下垂时暗红。

跛行的处理（NICE CG147）分三部分：
- **降低心血管风险**：戒烟、他汀、抗血小板药（NICE 指南首选氯吡格雷〔clopidogrel〕），控制血压和糖尿病。对部分患者，在阿司匹林基础上加用小剂量利伐沙班（rivaroxaban）可减少主要心血管和肢体事件，代价是出血增多。
- **有监督的运动计划**，通常每周 2 小时，持续 3 个月，鼓励患者走到最大疼痛点。它增加行走距离的效果不亚于许多介入治疗。
- 在运动和危险因素治疗后症状仍致残，或有慢性威胁肢体的缺血时，进行**血运重建**（血管成形术、支架或旁路手术）。如运动帮助不够，且不愿或不适合血运重建，萘呋胺（naftidrofuryl）是一种选择。

糖尿病足病合并了 PAD、神经病变和感染，需要多学科足病服务（[[endocrine/diabetes-complications]]）。

::: example 让他无法逛街的小腿 {#ex-claudication}
一位每天吸 20 支烟的 66 岁男性 9 个月来步行约 200 米后右小腿出现痉挛性疼痛，站立 2 分钟后缓解。他的右足脉搏消失。肱动脉收缩压右侧 146 mmHg，左侧 152 mmHg。右足背动脉压 88 mmHg，胫后动脉压 95 mmHg。计算右侧 ABPI 并概述处理。

::: solution
ABPI 使用该侧**最高**的踝部压力和**最高**的肱动脉压力：
$$
ABPI = \frac{95}{152} = 0.625.
$$
数值 0.63 证实为中度的**外周动脉疾病**，符合股浅动脉或腘动脉病变引起的**间歇性跛行**（小腿疼痛提示病变位于小腿以上）。

处理：
- **戒烟**，辅以支持和药物：这对他的腿和生命都是最重要的一步。
- **他汀**、**抗血小板药**（氯吡格雷），评估血压、血糖和血脂，并询问有无冠状动脉和颈动脉疾病症状。
- **有监督的运动计划**。
- 复查：如经上述处理症状仍限制生活，行双功超声或血管造影以计划**血运重建**。出现静息痛、溃疡或坏疽需紧急转诊。
:::
:::

## 急性肢体缺血

**急性肢体缺血**是肢体灌注突然减少，威胁肢体存活。其原因有**栓塞**（最常来自房颤时的左心房，或梗死后的左心室血栓）、已有动脉粥样硬化狭窄的动脉或旁路移植物的**血栓形成**、腘动脉瘤血栓形成、创伤或夹层。

典型特征为 **"6P"**：**疼痛**（pain）、**苍白**（pallor）、**无脉**（pulselessness）、**冰冷**（perishingly cold）、**感觉异常**（paraesthesia）和**瘫痪**（paralysis）。感觉丧失和肌肉无力表明肢体受到威胁，需要在数小时内血运重建；固定的花斑和坚硬、压痛的小腿提示缺血已不可逆。栓塞典型地见于房颤患者，症状突然而严重，对侧下肢脉搏正常；原位血栓形成常见于有跛行史者，由于已形成侧支，起病没那么突然。

处理十分紧急：镇痛、**静脉肝素**防止血栓蔓延，并立即请血管外科评估行取栓、溶栓、血管成形术或旁路手术。血运重建后，**再灌注损伤**可引起小腿筋膜间室内的肿胀（**骨筋膜室综合征**，需切开减压），以及高钾血症、酸中毒、肌红蛋白尿和急性肾损伤。基础病因（常为房颤）用长期抗凝治疗。

## 腹主动脉瘤

::: definition 主动脉瘤 {#def-aneurysm}
**动脉瘤**是动脉永久性局限扩张，超过正常直径的 1.5 倍。**腹主动脉瘤（AAA）**通常定义为肾下腹主动脉直径**3.0 cm 或以上**。**真性动脉瘤**累及管壁全部三层；**假性动脉瘤**是被周围组织包裹的局限性渗漏，例如动脉穿刺后。
:::

AAA 源于炎症和蛋白水解酶对中膜弹性蛋白和胶原的降解。主要危险因素为**年龄**、**男性**、**吸烟**（最强的可改变因素）、家族史、高血压和其他动脉粥样硬化性疾病。大多数在破裂前没有症状。它们可能在影像检查中偶然发现、查体时触及搏动性腹部包块，或经筛查发现。

破裂风险随直径急剧上升。由于破裂通常是灾难性的，大多数人在到达医院前或到达后不久死亡，英国开展了筛查项目。**NHS 腹主动脉瘤筛查项目**为男性在其满 65 岁的那一年提供一次超声检查（年龄更大的男性可自行申请）。英国 MASS 试验（2002）表明，对这一年龄的男性进行筛查可减少 AAA 导致的死亡。结果的处理为：
- **小于 3.0 cm**：正常，结束随访；
- **3.0–4.4 cm**（小）：每年超声监测；
- **4.5–5.4 cm**（中）：每 3 个月监测；
- **5.5 cm 或以上**（大）：转诊血管外科医生，2 周内就诊。

英国不对女性进行常规筛查，因为女性 AAA 少见得多，不过患动脉瘤的女性在同样直径下破裂风险更高。

NICE（NG156）建议，未破裂的动脉瘤在**有症状**、**5.5 cm 或以上**，或 **4.0 cm 或以上且一年内增长超过 1 cm** 时，考虑修复。修复方式有**开放手术**（用人工血管替换动脉瘤段）或**腔内动脉瘤修复术（EVAR）**（经股动脉放置覆膜支架）。EVAR 早期死亡率较低，但试验发现长期生存相似，EVAR 后晚期并发症和再干预更多，需要终身影像监测。NICE 2020 年的建议对适合开放手术者倾向于开放修复，这一立场仍有争议；欧洲指南对 EVAR 更为宽松。与此同时，要处理心血管风险：戒烟、他汀、抗血小板药和控制血压。

::: example 偶然发现的动脉瘤 {#ex-aaa}
一位 71 岁男性因肾结石行 CT 检查，发现肾下腹主动脉瘤 5.8 cm。他没有症状。他患高血压和伴中度气短的 COPD，仍在吸烟。接下来怎么办？

::: solution
5.8 cm 的动脉瘤超过了考虑修复的 5.5 cm 阈值，因此应**紧急转诊血管外科**，约 2 周内就诊。

关于修复的决定需要权衡：
- 这一大小的**破裂风险**，每增加一厘米风险都会上升（Laplace：在相同压力下，5.8 cm 时的壁张力接近正常主动脉的三倍）；
- 他**对手术的耐受性**：COPD 和吸烟增加开放修复的风险，因此需要肺功能检查、心脏评估，以及 CT 血管造影评估解剖是否适合 EVAR；
- 在解释修复（开放或腔内）和不修复的风险后，他本人的**意愿**。

与此同时：**戒烟**（吸烟加速动脉瘤生长并增加破裂风险），控制血压，使用他汀和抗血小板药。他应了解破裂的症状（突发剧烈腹痛或背痛、晕倒），并知道应立即呼叫急救。由于 AAA 有家族聚集性，应告知他的兄弟和儿子，他们可能受益于检查。
:::
:::

**AAA 破裂**表现为突发剧烈的腹部、背部或腰部疼痛，晕倒和低血压，有时可触及搏动性包块；可能被误诊为肾绞痛。处理为立即转运至血管中心，采用**允许性低血压**（限制补液，以维持患者清醒为度，因为恢复正常血压会加重出血），并行急诊修复，解剖条件允许时采用 EVAR。

## 主动脉夹层

**主动脉夹层**是内膜撕裂，血液进入中膜并使管壁分离，形成可沿主动脉及其分支延伸的**假腔**。危险因素为**高血压**（最常见）、结缔组织病（马方综合征、血管型 Ehlers–Danlos 综合征、Loeys–Dietz 综合征）、二叶式主动脉瓣、主动脉缩窄、既往心脏或主动脉手术、使用可卡因、妊娠和炎症性主动脉炎。

**Stanford 分型**按处理方式划分夹层：
- **A 型**累及**升主动脉**（无论起源于何处）。它可破入心包（心脏压塞）、破坏主动脉瓣（急性主动脉瓣反流）或阻塞冠状动脉。需要**急诊手术**。
- **B 型**只累及左锁骨下动脉以远的主动脉。通常**内科**治疗，控制心率和血压；出现破裂、器官或肢体灌注不良或疼痛无法控制等并发症时，行**胸主动脉腔内修复术（TEVAR）**。

典型表现为**突发、剧烈、撕裂样或刀割样胸痛，向背部放射**，起病时即达高峰。可能出现双臂脉搏或血压差异、新的舒张早期杂音、神经功能缺损（卒中、脊髓缺血导致的截瘫）、肢体缺血、肠系膜缺血引起的腹痛，或心脏压塞体征。有些人，尤其是老年人，表现不典型或无痛。诊断依靠 **CT 血管造影**，病情不稳定者用经食管超声心动图。

在紧急转诊外科的同时，初始治疗为镇痛和降低射血力量：按当地方案静脉使用 **β 受体阻滞剂**降低心率（通常降至约 60 次/分），然后必要时用血管扩张剂降低收缩压（通常降至 100–120 mmHg）。因疑似冠脉综合征而误用抗栓药物，可能造成灾难性后果（[[cardiovascular/coronary-artery-disease]]）。

::: example 撕裂样疼痛 {#ex-dissection}
一位身高 1.96 m、手指细长、有晶状体脱位史的 34 岁男性突发撕裂样胸痛，向两肩胛之间放射。脉搏 112 次/分，右臂血压 164/58 mmHg，左臂 128/52 mmHg。胸骨左缘可闻及舒张早期杂音。诊断是什么？即时计划是什么？

::: solution
这些特征提示**马方综合征**（身材高大、蜘蛛指、晶状体脱位）伴**急性 A 型主动脉夹层**：突发撕裂样疼痛向背部放射，双臂收缩压相差 **36 mmHg**，以及主动脉根部受累引起的**主动脉瓣反流**所致的新发**舒张早期杂音**。脉压增大符合急性主动脉瓣反流。

即时计划：
- **紧急主动脉 CT 血管造影**（不稳定时行经食管超声心动图），并做心电图（寻找冠状动脉受累），但不得延误诊断。
- **紧急转诊心胸外科**：A 型夹层需要**急诊手术**；如不治疗，最初几天内死亡率每小时都在上升。
- **镇痛**，并用静脉 β 受体阻滞剂有控制地降低心率和血压，同时避免低血压，低血压可能提示心脏压塞或破裂。
- **不用抗血小板药、抗凝药或纤溶药**。

康复后，他需要终身主动脉监测、控制血压，并进行 *FBN1* **基因检测**及**亲属筛查**（[[genetics/mendelian-inheritance]]）。
:::
:::

## 血管炎与雷诺现象

**血管炎**是血管壁的炎症，按受累血管的大小分类（[[musculoskeletal/connective-tissue-vasculitis]]）。这里有两种形式很重要：
- **巨细胞动脉炎**：老年人最常见的血管炎（几乎都在 50 岁以上）。特征：新发头痛、头皮压痛、**下颌跛行**、视觉障碍、ESR 和 CRP 升高，常伴风湿性多肌痛。它可因缺血性视神经病变导致突然、永久的**视力丧失**，因此怀疑本病时应**立即开始**大剂量**糖皮质激素**，并紧急请专科评估，经颞动脉超声或活检确诊。
- **大动脉炎（Takayasu 动脉炎）**：年轻女性的大血管血管炎，累及主动脉及其分支，表现为上肢跛行、脉搏消失和血管杂音。

**川崎病**是幼儿的中等血管血管炎，可引起冠状动脉瘤（[[paediatrics/acute-childhood-illness]]）。**血栓闭塞性脉管炎**（Buerger 病）是吸烟的年轻人肢体中小动脉的炎症性闭塞性疾病；必须完全戒除一切烟草。

**雷诺现象**是指动脉的发作性痉挛，由寒冷或情绪诱发：手指先变白，再变青紫，血液回流时变红。**原发性雷诺现象**常见，始于年轻女性，呈对称性，不损伤组织。**继发性雷诺现象**见于结缔组织病（尤其是系统性硬化症）、振动损伤、某些药物（如 β 受体阻滞剂）及其他疾病；线索为 30 岁以后发病、不对称、指端溃疡、甲襞毛细血管异常和自身抗体阳性。

## 静脉血栓栓塞

::: theorem Virchow 三联征 {#thm-virchow}
血栓形成由三种因素共同导致：
1. 血流**淤滞**；
2. 血液**高凝状态**；
3. 血管壁**内皮损伤**。
:::

::: proof
每一种因素都去除了一道抗血栓防线。正常血流使血小板保持在血流中央，并冲走活化的凝血因子；**淤滞**（制动、长途旅行、心力衰竭、静脉阻塞）使它们积聚，尤其是在下肢深静脉瓣尖后方，静脉血栓通常从这里开始。**高凝状态**增加凝血倾向：癌症、妊娠和产后、含雌激素的避孕药和激素替代治疗、炎症、肾病综合征、抗磷脂综合征，以及因子 V Leiden 等遗传性易栓症。**内皮损伤**暴露组织因子和胶原：手术、创伤、中心静脉导管和既往血栓。大多数静脉血栓栓塞事件涉及不止一种因素；例如髋关节置换就三者兼具。血栓形成的一般病理学见[[pathology/haemodynamics]]。
:::

**深静脉血栓形成（DVT）**典型地引起下肢肿胀、疼痛、发热和小腿压痛；也可无症状。**肺栓塞（PE）**引起呼吸困难、胸膜炎性胸痛、咯血、心动过速和低氧；大面积 PE 引起晕厥、右心衰竭和休克。

诊断遵循结构化路径（NICE NG158）：
- 用**两级 Wells 评分**（DVT 或 PE）估计临床概率。
- 如 DVT"可能"，安排**近端下肢静脉超声**；如 PE"可能"，安排 **CT 肺动脉造影（CTPA）**。如不能及时进行影像检查，给予临时抗凝。
- 如评分为"不太可能"，测定 **D-二聚体**。D-二聚体阴性时 VTE 可能性很小；阳性则需影像检查。D-二聚体敏感但不特异：感染、癌症、妊娠、手术和年龄都会使其升高。
- 对临床概率低的疑似 PE，可用 **PERC 规则**决定不再进一步检查。

治疗为**抗凝**，通常用 DOAC（阿哌沙班〔apixaban〕或利伐沙班），至少 **3 个月**。是否延长取决于事件是由短暂的主要危险因素（如手术）**诱发**的还是**无诱因**的，以及出血风险；无诱因 VTE 患者常接受更长期的治疗。癌症相关 VTE 用 DOAC 或低分子肝素治疗。伴休克的**大面积 PE** 如无禁忌，采用**溶栓**治疗。按 NICE NG89，住院患者需评估 VTE 风险，并给予机械或药物预防（[[blood/thrombosis-anticoagulation]]）。

::: example 肿胀的腿 {#ex-dvt}
一位 54 岁女性在长途飞行 10 天后出现左小腿肿胀、压痛。她未使用激素，无癌症史。左小腿比右侧粗 4 cm，有凹陷性水肿，沿深静脉走行有压痛。她的两级 Wells DVT 评分为 3。概述检查和处理。

::: solution
Wells 评分 2 分或以上，DVT 为**"可能"**。下一步是在 4 小时内行**近端下肢静脉超声**；如不能做到，则查 D-二聚体并开始临时抗凝，24 小时内完成超声。

如超声显示 DVT，用**抗凝药**治疗，通常为 DOAC，**至少 3 个月**。DVT 是否算作由飞行诱发需要临床判断；长途飞行是一个相对较弱的短暂危险因素，因此她可能被视为无诱因 DVT，3 个月后是否继续需要重新评估，权衡复发风险与出血风险。仔细询问病史和查体以寻找癌症症状是评估的一部分。

如超声阴性但 D-二聚体阳性，约一周后复查超声，因为小腿血栓可能会延伸。
:::
:::

::: warning 概率高时，D-二聚体阴性意义不大
只有在临床概率低时，D-二聚体检测才有用。对于 Wells 评分为"可能"的人，D-二聚体阴性不能安全地排除 VTE，仍需影像检查。反过来，住院患者、老年人或孕妇的 D-二聚体阳性很常见，并不是血栓形成的证据。应结合验前概率解读检测结果（[[epidemiology-ebm/diagnostic-tests]]）。
:::

## 慢性静脉疾病

小腿肌肉泵推动血液从下肢流向心脏：收缩挤压深静脉，单向瓣膜防止血液倒流。当瓣膜因原发性薄弱或在 DVT 后（**血栓后综合征**）失效时，行走时下肢静脉压仍然很高（**静脉高压**）。结果是**静脉曲张**、踝部水肿、皮肤改变（含铁血黄素沉着、静脉性湿疹和**脂性硬皮病**——踝上方坚硬、紧绷的皮肤），最终发生**静脉性腿部溃疡**，典型位于内踝上方。静脉性溃疡是腿部溃疡最常见的原因。

在使用**加压治疗**前要测量 **ABPI**，因为对有明显动脉病变的腿加压可能导致组织坏死。加压包扎或弹力袜是静脉性溃疡的主要治疗。根据 NICE CG168，有症状的静脉曲张或静脉性皮肤改变者应转诊血管科；**腔内热消融**（射频或激光）是一线治疗，不适合时依次采用泡沫硬化治疗和手术。治疗浅静脉反流可加快溃疡愈合并减少复发。

::: quiz
NHS 腹主动脉瘤筛查项目在下列哪个阈值将男性转诊血管外科医生？
- [ ] 3.0 cm
- [ ] 4.5 cm
- [x] 5.5 cm
- [ ] 6.5 cm
::: solution
**5.5 cm 或以上**的动脉瘤需转诊血管外科医生，2 周内就诊。3.0–4.4 cm 的动脉瘤每年复查，4.5–5.4 cm 每 3 个月复查。NICE 还建议，如动脉瘤有症状，或 4.0 cm 或以上且每年增长超过 1 cm，即使小于 5.5 cm 也考虑修复。
:::
:::

::: history
19 世纪 50 年代，在维尔茨堡和柏林工作的魏尔啸（Rudolf Virchow）证明肺栓子来自静脉中的血栓，并描述了导致血栓形成的因素，后人将其概括为他的三联征。1951 年，巴黎的迪博斯特（Charles Dubost）切除了一个腹主动脉瘤并用同种异体血管替换，这是此类手术的首次成功。1964 年，多特（Charles Dotter）用导管扩张狭窄的股动脉，引入了经腔血管成形术，这是血管腔内治疗的开端。1990 年，布宜诺斯艾利斯的帕罗迪（Juan Parodi）用覆膜支架完成了腹主动脉瘤的腔内修复。2002 年发表的英国多中心动脉瘤筛查研究（MASS）表明，对老年男性进行超声筛查可减少动脉瘤导致的死亡，促成了英格兰自 2009 年起的全国筛查项目。
:::

## 后续内容

动脉粥样硬化及其危险因素见[[cardiovascular/coronary-artery-disease]]，夹层的主要危险因素——高血压——见[[cardiovascular/hypertension]]。抗凝见[[blood/thrombosis-anticoagulation]]，颈动脉疾病引起的卒中见[[nervous-system/stroke]]，血管炎见[[musculoskeletal/connective-tissue-vasculitis]]，血管外科见[[surgery/vascular-urological-surgery]]。

::: summary
- Laplace：壁张力 $T = Pr$；动脉瘤越大，壁应力越高，生长越快，越易破裂。
- PAD：跛行或慢性威胁肢体的缺血；ABPI 低于 0.9 可确诊；处理心血管风险（戒烟、他汀、抗血小板药），有监督的运动，对致残或威胁肢体的病变行血运重建。
- 急性肢体缺血（6P）由栓塞（常为房颤）或血栓形成引起，需肝素和紧急血运重建；警惕骨筋膜室综合征。
- AAA：主动脉 3.0 cm 或以上；NHS 对 65 岁男性筛查；3.0–4.4 cm 每年监测，4.5–5.4 cm 每 3 个月监测；5.5 cm 或以上转诊；有症状或 4.0 cm 以上且每年增长超过 1 cm 时考虑修复。
- 夹层：向背部放射的撕裂样疼痛，双臂血压差；A 型需急诊手术，B 型通常内科治疗；排除夹层前绝不使用抗栓药物。
- 巨细胞动脉炎威胁视力：立即开始激素。继发性雷诺现象提示结缔组织病。
- VTE 遵循 Virchow 三联征；使用 Wells 评分、D-二聚体（仅在不太可能时）、超声或 CTPA；抗凝至少 3 个月，许多无诱因事件需更长时间。
- 慢性静脉疾病：瓣膜失效导致静脉高压、皮肤改变和溃疡；加压前检查 ABPI；腔内热消融是静脉曲张的一线治疗。
:::

## 习题

::: exercise 计算 ABPI {level=1 check="0.6"}
一位女性的肱动脉最高收缩压为 140 mmHg，左侧踝部最高压力为 84 mmHg。计算她的左侧 ABPI（精确值）并加以解读。
::: solution
$ABPI = 84/140 =$ **0.6**。低于 0.9，提示中度的**外周动脉疾病**。
:::
:::

::: exercise Laplace 与动脉瘤 {level=1 check="3"}
在相同血压下，根据 Laplace 定律，6.0 cm 动脉瘤的壁张力是正常 2.0 cm 主动脉的多少倍？
::: solution
张力与半径成正比，因此比值为 $3.0/1.0 =$ **3**。如果动脉瘤壁还变薄了，壁应力的增加会更大。
:::
:::

::: exercise 6P 之后怎么办？ {level=1}
一位两周前停用抗凝药的 79 岁房颤女性右腿突发疼痛。腹股沟以下的腿苍白、冰冷、无脉，足部感觉减退。列出即时措施。
::: solution
这是**急性肢体缺血**，可能是来自左心房的**栓子**。感觉减退意味着肢体受到威胁。即时措施：镇痛；**静脉普通肝素**；**紧急血管外科评估**，在数小时内行取栓或其他血运重建；基线血液检查，包括肾功能、血钾、肌酸激酶和凝血功能；心电图。血运重建后，监测骨筋膜室综合征和再灌注效应（高钾血症、酸中毒、肌红蛋白尿）。重新开始针对房颤的长期抗凝，并处理当初停药的原因。
:::
:::

::: exercise 筛查结果 {level=2}
说明 NHS 腹主动脉瘤筛查中，主动脉直径为下列数值的男性的处理结果：(a) 2.6 cm；(b) 3.8 cm；(c) 4.9 cm；(d) 5.6 cm。为什么监测间隔随直径增加而缩短？
::: solution
(a) 正常：**结束随访**，不再复查。
(b) 小动脉瘤：**每年**超声监测。
(c) 中动脉瘤：**每 3 个月**监测。
(d) 大动脉瘤：**转诊血管外科医生**，2 周内就诊。

间隔缩短是因为**生长速度和破裂风险随直径增加**：壁张力随半径升高（Laplace），管壁变薄，较大的动脉瘤生长更快。所有患动脉瘤的男性还会得到戒烟建议，并接受心血管风险评估。
:::
:::

::: exercise 心率与夹层 {level=2}
解释为什么急性主动脉夹层时先给 β 受体阻滞剂，再给血管扩张剂。
::: solution
目的是减小血液射入受损主动脉的力量，特别是**压力上升速率**（$dP/dt$）和心率，以及压力本身，以限制夹层的扩展。单独使用血管扩张剂会通过压力感受器反射引起**反射性心动过速**和收缩力增强，从而增加 $dP/dt$ 和对主动脉壁的剪切力。先用 β 受体阻滞剂可以削弱这一反射；如压力仍高于目标，再加用血管扩张剂。
:::
:::

::: exercise 头痛与下颌 {level=2}
一位 74 岁女性新发颞部头痛 3 周，咀嚼时下颌疼痛，双肩酸痛。ESR 78 mm/h。今天早上她一只眼出现了 10 分钟的视物模糊。可能的诊断是什么？为什么紧急？
::: solution
**巨细胞动脉炎**：50 岁以上新发头痛、下颌跛行、风湿性多肌痛症状和 ESR 很高。一过性视力丧失（**一过性黑蒙**）提示视神经或视网膜缺血，预示即将发生的**永久性失明**，且可累及双眼。应**立即开始**大剂量**糖皮质激素**，不必等待确诊，并在当天请专科（眼科和风湿科）评估；诊断经颞动脉超声或活检确认，开始激素后数天内这些检查仍有诊断价值。她还需要骨保护，并监测激素不良反应。
:::
:::

::: exercise 腿部溃疡门诊 {level=2}
一位 72 岁女性内踝上方有一浅表溃疡，周围有棕色色素沉着和坚硬的皮肤。她的 ABPI 为 0.95。可能的病因是什么？主要治疗是什么？为什么要测量 ABPI？
::: solution
部位（内踝上方）、色素沉着（含铁血黄素）和坚硬皮肤（脂性硬皮病）提示由慢性静脉高压引起的**静脉性腿部溃疡**。

主要治疗是**加压治疗**（多层包扎或弹力袜），同时抬高下肢、锻炼小腿肌肉泵并护理伤口；转诊血管科评估**浅静脉反流**，对其进行治疗（例如腔内热消融）可加快愈合并减少复发。

测量 **ABPI** 是因为对有明显动脉病变的腿加压可减少动脉血流并导致皮肤坏死。ABPI 0.95 表明没有明显的动脉病变，因此可以安全地充分加压。
:::
:::

::: exercise 术后气短 {level=3}
一位 61 岁男性在右侧全膝关节置换术后第 8 天出现气短和胸膜炎性胸痛。脉搏 118 次/分，血压 104/66 mmHg，未吸氧时 SpO₂ 90%，呼吸频率 26 次/分。他没有癌症。构建鉴别诊断，解释你将如何选择检查，并概述如果他出现低血压，处理会有何改变。
::: hint
用 Virchow 三联征判断验前概率。D-二聚体何时有用，何时没用？
:::
::: solution
**鉴别诊断**：**肺栓塞**（最可能：近期大型骨科手术兼具淤滞、高凝和内皮损伤）；肺炎，包括吸入性肺炎；肺不张；急性冠脉综合征；心力衰竭或液体过负荷；气胸；脂肪栓塞（通常更早，在 72 小时内）。

**检查**：他的两级 Wells PE 评分较高（心率超过 100、4 周内手术、PE 是最可能的诊断），因此 PE 为**"可能"**。**D-二聚体没有用**：术后它必然升高，而在这一概率下阴性结果也不能排除 PE。他需要 **CT 肺动脉造影**，如影像检查延迟则给予临时抗凝（与骨科团队共同考虑手术出血风险）。心电图、胸片、血气、肌钙蛋白和 BNP 有助于鉴别诊断和风险分层；超声心动图评估右心室劳损。

**如果他出现低血压**（收缩压持续低于 90 mmHg 或大幅下降），即为**高危（大面积）PE**。处理将转为立即复苏并考虑**全身溶栓**。由于他刚做完大手术 8 天，出血风险高，因此应按当地方案紧急与专科讨论**经导管治疗或外科取栓**等替代方案。CT 无法安全进行时，床旁超声心动图显示右心室扩大可支持诊断。
:::
:::
