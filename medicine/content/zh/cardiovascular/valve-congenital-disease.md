瓣膜与先天性心脏病是前几章曲线遇上固定解剖之处：狭窄瓣膜强加流量平方的梯度与压力负荷心室、反流瓣膜造出带两个出口的容量负荷心室、分流造出带自己压力-电阻政治的并联环路（[[cardiovascular/circulation-blood-pressure]]与[[cardiovascular/cardiac-cycle]]的方程、如今带外科指征）。临床算术是时机——**无症状病变伴代偿心室对有症状病变伴衰减曲线**——而手术（修复、置换、经导管世代、小儿分期重建）已从最后手段变为规划的生理。

本章讲述瓣膜病变及其心室、心内膜炎、分流与发绀型先心病、肥厚型心肌病、及成人先心实践。

## 狭窄与反流：两种负荷、两个心室

::: definition 病变血流动力学与作为固定口的瓣膜 {#def-lesions}
狭窄瓣膜是**流量依赖的压力汇**：按口与连续性原理、平均梯度随流量平方除以有效面积缩放（练习器的两条曲线）、所以**同一个0.7 cm²主动脉瓣在运动中抗议、而在衰竭低输出心室静息时“低梯度”——低流量低梯度的重度狭窄带其多巴酚丁胺收缩储备算术及其计算瓣面积陷阱（小环与反常高血压变异）**——而心室以**同心性肥厚（[[physiology/muscle]]后负荷生长程序）**应压力负荷：氧需求更高、冠脉正常的心内膜下缺血（[[#ex-as]]的心绞痛）、顺应性下降（[[cardiovascular/heart-failure]]的HFpEF生理与房颤苗床）、及最终的后负荷失配衰竭。反流是**两出口容量负荷**：总射血分数分给前向与反流、心室扩张（离心性生长）带**看似超正常的射血分数已经低估肌肉质量——重度主动脉或二尖瓣反流的“EF 55%”是病态而非安慰的原因（两个瓣的指南工作点都远高于正常范围）**；接收腔的顺应性决定症状（[[cardiovascular/coronary-artery-disease]]乳头肌断裂与心内膜炎及夹层的急性反流以闪性水肿或休克表现，因为正常心房接受不了体循环压力的射流——[[cardiovascular/circulation-blood-pressure]]同一生理的例子）。逐病变：**主动脉瓣狭窄**（老年退行性钙化与二叶瓣的提早十年、伴二尖瓣伙伴的风湿性；经典症状三联——心绞痛、劳力性晕厥、心衰——各标记一条生存曲线悬崖、杂音的晚期递增型与细迟脉及消失的S2读严重程度、及干预时机的症状与EF及极重度标准、外科置换对经导管主动脉瓣植入（TAVI）按年龄、解剖与手术风险决定、主动脉根与传导系统及患者-假体失配与抗凝与心内膜炎谈话跟随假体选择（[[#ex-as]]与练习））；**二尖瓣狭窄**（几乎总是风湿性——[[infectious-diseases/fever-sepsis]]的链球菌史如今 arriving 移民与原住民队列；二尖瓣面积与梯度的流量依赖、左房扩大→房颤→栓塞及咯血与声音与吞咽后遗症、舒张期杂音与开放拍击音与响亮叩击心尖、[[#ex-ms-pregnancy]]的妊娠与心动过速与感染诱发、及融合柔软交界处的手术修复对比钙化的置换）；**主动脉瓣反流**（慢性——二叶瓣与主动脉病与心内膜炎与夹层与结缔组织病——按指南尺寸与EF管理、降后负荷桥与心室不可回头点之前手术的极佳时机余地、及急性——[[cardiovascular/circulation-blood-pressure]]的例子——急症）；**二尖瓣反流**（原发/退行性——连枷与Barlow与黏液样瓣叶及乳头肌梗死断裂—对—继发/功能性来自扩张或缺血心室的牵拉（[[cardiovascular/heart-failure]]环扩张环）、退行性病变中修复优于置换、不可手术的功能性病变的边缘对边缘与成形环器械世代、及尊重容量负荷心室负荷条件谎言的指南EF阈值）；**三尖瓣与肺动脉病变**（类癌与起搏导线及分流术后右心的反流、孤立风湿性肺动脉狭窄的球囊治愈、及法洛术后右室对肺动脉反流后负荷的敏感）。
:::

::: example 差点摔倒的教师 {#ex-as}
79岁教师监督体育活动时两次差点晕倒、上楼胸闷6个月；脉58而慢升、血压118/78、颈动脉搏动慢升、粗糙喷射性杂音传至颈动脉伴柔和单一S2、超声：钙化三叶主动脉瓣面积0.7 cm²、平均梯度52 mmHg、EF 58%、CT冠脉正常。
::: solution
**有症状的重度主动脉瓣狭窄——心绞痛、近晕厥、数字一致、这是容易而紧急的病例。**生理是完整的[[#def-lesions]]：**固定后负荷的同心性肥厚造成心内膜下缺血（冠脉干净的心绞痛）、血管扩张肌肉对抗固定输出的劳力性晕厥前（及心律失常与血管反射成分）、及症状一旦宣示中位生存降到2–5年的生存曲线（使“观察等待”成为关于周而非十年的决定的历史自然史）。**管理：**加速瓣膜置换——外科置换对TAVI由心脏团队按年龄与风险与解剖选择（二叶瓣与冠脉高度与主动脉尺寸与经股通路的细微；组织对机械的抗凝与耐久权衡谈话——[[blood/thrombosis-anticoagulation]]）、球囊扩张留作桥接或姑息、及本例早已冲过的无症状患者指南干预标准（EF漂移、极重度速度、运动试验反应）**。 meanwhile的药物层：**扩血管药的谨慎、固定每搏量下强力β阻滞的心动过缓（她脉58）、硝酸酯治巧合心绞痛的陷阱、及心内膜炎与牙科规划；操作后预期肥厚与舒张功能数月消退、及TAVI传导损伤的心电图与起搏器统计（[[cardiovascular/electrophysiology-ecg]]阻滞章）。**
:::

::: example 气促的新娘 {#ex-ms-pregnancy}
26岁、第二次妊娠28周（儿童期未治的风湿病史）、突发气促伴咯血；脉126绝对不齐、双肺湿啰音、超声示二尖瓣狭窄面积1.0 cm²、左房扩张无血栓。
::: solution
**妊娠使二尖瓣狭窄失代偿——按点到 hemodynamic 完美风暴。**生理：**血浆容量扩张与心输出量到第三孕季升约40%穿过固定1.0 cm²口（梯度随流量平方缩放——练习器上线）、加心动过速偷走舒张充盈时间（梯度是舒张期现象——每次舒张缩短的搏动都是更多左房压）、加新发房颤取消心房排空并抬率（最后一击：[[cardiovascular/cardiac-cycle]]心房贡献的丧失与舒张时间税同时）——水肿与咯血来自[[cardiovascular/circulation-blood-pressure]]方程的支气管静脉曲张与毛细血管压力机制。**管理：**收住院；率控制（β阻滞剂双份工作——更慢的率、更长的舒张、及产科生长监护）、不稳定则电复律（妊娠中安全配[[cardiovascular/arrhythmias]]的胎儿监护）、谨慎利尿（前负荷依赖——肺与输出之间的平衡）、抗凝因为房颤加风湿性二尖瓣狭窄是[[#def-lesions]]与[[blood/thrombosis-anticoagulation]]的华法林专属领地（妊娠的肝素桥接与胎儿华法林时机规则——[[obstetrics-gynaecology/pregnancy-complications]]）、及产科-心脏联合团队的分娩规划（第二产程Valsalva与子宫收缩的自体输血是麻醉规划必须预判的血流动力学诱发——[[surgery/anaesthesia-pain]]）。**根治：**经皮二尖瓣球囊交界分离术（柔软交界病变的治愈、药物治疗失败时带腹部遮蔽进行、含妊娠期）或产后手术——全球风湿性心脏病消除战略为其而预防的病例[[public-health/communicable-disease-control]]。**

## 内皮上的感染、与本应关上的门

::: definition 感染性心内膜炎 {#def-endocarditis}
心内膜炎是**固定于湍流内皮的感染**：瓣膜损害（狭窄、反流射流的冲击病灶、高速分流下游壁——[[#def-lesions]]的病变与室间隔缺损的室间隔“喷射病灶”）提供**血小板-纤维蛋白非细菌性血栓性心内膜炎、菌血症（牙与黏膜与皮肤与导管入口）在其上播种、赘生物在血流自身的保护下生长（纤维蛋白的抗生素渗透极限与假体的生物膜）**——按场景分微生物：**葡萄球菌（急性的、注射毒品与装置与医疗相关）、草绿色链球菌（亚急性牙科故事——[[microbiology/bacteria]]葡聚糖与黏附章）、肠球菌（泌尿生殖道）、HACEK与巴尔通体及培养阴性联军（延长培养与血清学与16S及18S分子时代）**。临床综合征是**发热加栓塞加免疫现象**、按**改良Duke标准**读（血培养与超声心动主要标准——含现代心脏CT与PET/CT对假体瓣与装置的角色——对次要临床标准——[[epidemiology-ebm/diagnostic-tests]]复合标准例子）：杂音的新反流、裂片状出血与Osler与Janeway病灶及Roth斑（栓塞对免疫的分裂）、脾与肾梗死、**霉菌性动脉瘤与卒中（感染性栓子的抗凝是对抗出血转化与霉菌性动脉瘤破裂风险的决定、其神经Timing决定手术室Timing）**、瓣膜破坏（[[cardiovascular/circulation-blood-pressure]]例子的急性主动脉或二尖瓣反流）与根脓肿（监护上新发心脏阻滞——主动脉环毗邻希氏束的解剖、[[anatomy/thorax]]）、使进手术室的心衰与破裂。管理：**延长病原定向静脉治疗及外科指征——药物治疗失败、血流动力学灾难、困难微生物与持续菌血症及大活动性栓塞赘生物——由专职心内膜炎团队决定（早期外科试验的死亡率算术）；复发对再感染的随访；预防只留给最高风险的假体与先天及既往心内膜炎队列的牙科操作（NICE对AHA指南分歧是关于数字不是细菌的政策争论——[[medical-ethics-law/justice-resources]]预防公平脚注、[[microbiology/antimicrobials]]管理依据）。** 装置时代的添加：**起搏器与除颤器导线感染（拔除中心决定）及TAVI与经导管瓣膜心内膜炎、及注射毒品的右心疾病、其感染性肺栓塞（[[respiratory/respiratory-infections]]的结节与空洞影）与三尖瓣破坏以咳嗽与胸膜炎而非外周体征游行表现（[[#ex-ie-right]]）。**
:::

::: example 咳嗽的注射者 {#ex-ie-right}
31岁每日注射海洛因者发热10天、胸膜性胸痛与咯血；湿啰音及胸片散在结节影伴两个空洞、新发柔和三尖瓣杂音、葡萄球菌血培养阳性、超声1.5 cm活动性三尖瓣赘生物。
::: solution
**伴感染性肺栓塞的右心自体瓣膜葡萄球菌心内膜炎**——经重复使用的针头浸泡在皮肤菌群系统中的三尖瓣低压装置病变。表现的生理：**右心栓子去肺（楔形与空洞结节——“多发双肺不同期的肺炎”）、所以左侧疾病的外周体征与全身栓塞并发症缺席、杂音柔和（右心梯度小）；反常栓塞例外是卵圆孔未闭之路（[[cardiovascular/cardiac-cycle]]与[[cardiovascular/circulation-blood-pressure]]分流生理）。管理：延长抗葡萄球菌静脉治疗、只在失败时源头外科——大赘生物与持续菌血症与右心衰指征（支持 uncomplicated 右侧疾病药物治疗的手术对结局数据）、成瘾医学与会开抗生素一样认真的处方（减害与阿片激动与心理健康规划——没有它复发与再感染统计占上风——[[psychiatry/substance-use]]）、转移感染搜寻（脊柱、关节、脑与眼——念珠菌与葡萄球菌眼内膜炎扩瞳）、及HIV与病毒性肝炎与疫苗议程（[[infectious-diseases/fever-sepsis]]、[[immunology/immunodeficiency]]）、及抗生素选择与导管护理及门诊胃肠外（OPAT）安全规划。**
:::

::: definition 分流、Eisenmenger、与长大的孩子 {#def-congenital}
左向右分流（**室间隔与房间隔缺损及动脉导管——[[anatomy/embryology]]的分隔与弓衍生物**）按缺损大小与两个循环阻力比（Qp:Qs）把含氧血送回肺：心室容量负荷（[[#def-lesions]]的离心性生长）、肺血流抬压力、而多年高流量高压重塑肺床（[[cardiovascular/circulation-blood-pressure]]剪切-张力与[[respiratory/interstitial-vascular-disease]]的丛样动脉病）直到**Eisenmenger生理**逆转或均衡分流（发绀、杵状指、劳力性呼吸困难的成人、其缺损如今是泄压阀、而关闭它将诱发急性右心衰——关不掉的病变与移植-姑息疾病、带母体死亡率数字的妊娠禁忌（[[obstetrics-gynaecology/pregnancy-complications]]））。**临床签名：**小的室间隔缺损响亮而大的无声伴婴儿期衰竭；房间隔缺损固定而宽分裂的S2（心房不再调制的右室射血延迟——[[cardiovascular/cardiac-cycle]]分裂生理）及其继发孔病变从未发现时四十余岁以反常栓塞与晚期房颤及运动不耐受就诊；导管的连续机器样杂音及其宽脉脉压及其动脉炎及其器械关闭；及21三体家系的房室/通道缺损（[[genetics/chromosomal-disorders]]）。**发绀型病变（法洛的分隔失败与主动脉骑跨与右室流出道梗阻及其高危发绀发作——膝胸位、氧、去氧肾上腺素的升压后负荷生理、β阻滞、手术、及新生儿的前列腺素E1保导管急症（[[paediatrics/newborn]]）——及在大动脉转换手术前需要导管与间隔的大动脉转位、及左心发育不良的分期重建）如今是**成人先天性心脏病**：一个增长中的术后儿童人群、其后遗症（法洛术后的肺动脉反流与右室扩张与房性心律失常及Fontan衰竭单心室及其血栓与蛋白丢失性肠病与肝病、及 baffles与 conduits 狭窄）要求终身影像监护——本章的流行病学要点：[[cardiovascular/heart-failure]]与[[cardiovascular/arrhythmias]]表型日益包括先天变异——带心内膜炎预防与妊娠及运动及抗凝全被特异解剖重写、这就是成人先心心脏病学是专科而非门诊日的原因。**
:::

::: example 未固定的分裂 {#ex-asd}
43岁秘书体检发现“柔和杂音”；超声示24 mm卵圆孔型房间隔缺损伴右室扩张、Qp:Qs 2.2、肺压正常、她提到两次伴先兆的偏头痛与其父亲“年轻时中风”。
::: solution
**血流动力学显著继发孔房缺伴家族血栓栓塞史**——经典成人偶发发现而并非偶发：**固定分裂与右室容量负荷（[[#def-congenital]]的查体线索）、及Qp:Qs 2.2（指南关闭阈约1.5伴腔室扩大）说明这个房间隔四十年来一直在再循环第二个循环。**管理：**边缘足够的继发孔病变经导管器械关闭（边缘 deficient 与其他分隔类型外科补片）——关闭前导管或影像评估肺血管阻力（Eisenmenger谨慎：关闭一个已变泄压阀的缺损就是[[#def-congenital]]的伤害）、预期重塑（数月右室逆扩张、及中年前关闭的运动能力与生活质量获益及房性心律失常风险削减）、及带器械-瓣叶与残余分流随访的关闭后抗血小板与内皮化时间表。**伴先兆偏头痛与父亲的早卒中使**反常栓塞（[[cardiovascular/circulation-blood-pressure]]的练习与[[blood/thrombosis-anticoagulation]]隐源卒中-PFO文献）**成为咨询核心：**应诚实讨论关闭的卒中与偏头痛证据（卵圆孔未闭试验的混合判决与选择表型论证）——她为右室而关闭、栓塞获益是合理希望、不是承诺。**

::: definition 肥厚型心肌病 {#def-hcm}
HCM是**肌小节蛋白疾病（MYH7与MYBPC3及伙伴基因——随年龄可变表达的常染色体显性外显：[[genetics/mendelian-inheritance]]与[[genetics/non-mendelian-inheritance]]外显率课）产生不对称肥厚（室间隔占优）、心肌纤维紊乱与间质纤维化**、带三个临床后果：**(1) 动态左室流出道梗阻（基底间隔加二尖瓣叶收缩期前移——狭窄流出道的Venturi与拖曳几何——一个与主动脉瓣狭窄相反行为的杂音：心室容量越小越响——站位、Valsalva；蹲踞与握力的后负荷升高越轻——[[#def-lesions]]对[[#def-hcm]]的听诊表存在，因为梯度是可塌陷的不是固定的（[[cardiovascular/circulation-blood-pressure]]小动脉对固定口的对照））；(2) 心律失常底物（紊乱与纤维化的折返——猝死风险按早死家族史、晕厥、壁厚、非持续性室速与异常血压反应评分、带除颤器谈话与级联基因筛查）；及3) 舒张与瓣膜后遗症（[[cardiovascular/heart-failure]]HFpEF图像与瓣叶前拖的二尖瓣反流、及僵硬心室靠心房助推存活的房颤不成比例症状——[[cardiovascular/arrhythmias]]房颤脚注）。**管理：**β阻滞剂或非二氢吡啶钙阻滞剂或丙吡胺（负性肌力与减率延长充盈并减小可塌陷梯度——避免清单：扩血管药、二氢吡啶、地高辛与正性肌力药、它们缩小或高收缩腔室并加重梗阻——生理处方）、室间隔减容（第一隔支酒精消融及其诱生梗死与阻滞算术对外科肌切除术、都用于药物抵抗的梗阻性病变）、肌球蛋白抑制剂时代（mavacamten与终于被瞄准的肌小节装配药理——[[pharmacology/drug-receptor]]的现代例子）、风险分层的器械与家系规划、及妊娠与运动咨询（血流动力学规则——维持前负荷与后负荷、[[obstetrics-gynaecology/pregnancy-complications]]的维持前负荷后负荷与产科麻醉谨慎及[[cardiovascular/arrhythmias]]的运动员资格谈话）。**
:::

::: quiz
Valsalva用力相时、肥厚型心肌病杂音变响而主动脉瓣狭窄杂音变轻，因为：
- [ ] 静脉回流增加、提升两病变的每搏量
- [x] 更小的腔室容量加重可塌陷的流出道梗阻、却减少穿过固定口的流量
- [ ] 后负荷升高抵消肥厚型心肌病的梗阻
- [ ] 副交感浪潮减慢穿过狭窄瓣的传导
::: solution
用力相降低前负荷并缩小腔室：**HCM梯度是动态的（间隔-瓣叶几何收紧——[[#def-hcm]]）、故梗阻与杂音增加；主动脉瓣狭窄梯度是流量的固定口函数（练习器曲线）、故流量少则梯度少声音少。**蹲踞逆转两者、而握力的后负荷升高增强反流性杂音——因一个梗阻塌陷而另一个不塌陷而存在的床旁鉴别（[[clinical-skills/physical-examination]]）。

## 通向何处

瓣膜负荷生理在[[cardiovascular/cardiac-cycle]]与[[cardiovascular/circulation-blood-pressure]]；反流的急性形态在[[cardiovascular/coronary-artery-disease]]与[[cardiovascular/circulation-blood-pressure]]；衰竭后遗症在[[cardiovascular/heart-failure]]；分流的胚胎学在[[anatomy/embryology]]；肺高压终点在[[respiratory/interstitial-vascular-disease]]；假体的抗凝在[[blood/thrombosis-anticoagulation]]；遗传性心肌病在[[genetics/mendelian-inheritance]]；导管依赖新生儿在[[paediatrics/newborn]]。

::: summary
- 狭窄强加流量平方依赖的梯度与压力负荷（同心性肥厚、缺血、舒张病）；反流强加两出口的容量负荷（离心性扩张与看似良好的射血分数）；在心室而非症状日历上定时机是技艺。
- 有症状重度主动脉瓣狭窄是生存悬崖诊断；经导管与外科置换按解剖、年龄与风险选择、低梯度状态需要流量感知的解读。
- 心内膜炎是湍流上的感染：Duke标准、延长病原定向治疗、及为失败与血流动力学灾难与栓塞风险的手术；预防是狭窄的、而成瘾医学是右侧治愈的一部分。
- 分流病变是电阻政治——在Eisenmenger生理使关闭致命之前关闭它们、并随访如今带着自己后遗症清单的术后儿童。
- HCM是肌小节梗阻性、心律失常性与舒张性疾病、其药与主动脉瓣狭窄相反、其风险被评分并被器械处理、其家系用基因与心电图筛查。
:::

## 练习

::: exercise 计算面积 {level=1}
LVOT直径2.0 cm（圆形）、LVOT速度-时间积分20 cm、主动脉瓣速度-时间积分60 cm。计算主动脉瓣面积并分级；陈述连续性方程的假设。
::: solution
LVOT横截面积=π×(1.0)²=3.14 cm²；穿过它的每搏量=3.14×20=62.8 mL；**AVA=62.8/60≈1.05 cm²——重度领域是≤1.0、所以这是重度-中度临界（小体型者按体表面积指数——0.6 cm²/m²切点与极重度≤0.6 cm²）**。假设：**圆形LVOT（低估椭圆）、与血流对齐的单一LVOT VTI取样（余弦误差）、层流且无瓣下梗阻、及前向容积等于无反流每搏量的正常主动脉瓣（混合病变警诫）**——考试要点即[[#def-lesions]]的：面积是基于物理假设的算术、临床图像与钙化评分仲裁分歧（[[clinical-skills/medical-imaging]]）。
:::
:::

::: exercise 杂音动作 {level=1}
用负荷生理为什么Valsalva用力相对主动脉瓣狭窄与HCM杂音影响不同、为什么蹲踞使HCM变轻却可能使AS杂音变响、及握力对反流性杂音做什么。
::: solution
**Valsalva用力相（前负荷降低、腔室变小）：AS杂音下降（固定口流量减少——练习器流量项）而HCM杂音上升（更小流出道增加可塌陷梗阻与二尖瓣叶拖曳——[[#def-hcm]]）；蹲踞（前负荷与后负荷升高、腔室变大）：HCM杂音下降（扩张的流出道）而AS杂音随每搏量增加上升（固定口把流量转化为梯度与声音）；握力（后负荷升高）：反流性杂音——二尖瓣与主动脉瓣反流与室缺——变响（后负荷把两出口分配推向反流分数）、而喷射杂音几乎不变。**床旁表是[[#def-lesions]]病变算术的声音执行——更深的要点：杂音不单是瓣膜而是瓣膜×流量×负荷、这就是为何贫血、妊娠与甲状腺毒症造出听起来无害的流量杂音、及β阻滞一小时内改变HCM的声音（[[clinical-skills/physical-examination]]）。
:::
:::

::: exercise 无症状的重度瓣膜 {level=2}
给出重度AS、MR与AR在症状之前或之外干预的四个指南扳机、及各自保护的生理。
::: solution
**重度AS：**症状（或运动试验揭开的症状）、**EF<50%（后负荷失配开始）、极重度解剖（速度≥5 m/s或面积≤0.6——练习器的梯度-面积曲线）、及伴BNP上升或血压反应异常的快速进展——各自防不可逆纤维化与术后生存差距。**重度MR（原发性）：**EF≤60%或收缩末内径≥40 mm（两出口算术的假性良好EF与后负荷敏感的内径——在心室不可回头点之前手术、优选修复）、或新发房颤或肺高压（心房与静脉床作为泄漏表）。**重度AR：****EF<55%或收缩末内径>40 mm（或指数化——容量负荷内径是病变的真实进度表）、及主动脉根本径阈值（按病因45–55 mm规则与二叶瓣与主动脉病与妊娠规划——[[cardiovascular/vascular-disease]]与[[obstetrics-gynaecology/pregnancy-complications]]）。** 统一生理：**每个扳机是心室或血管的代偿曲线越过其拐点——影像是曲线的监护、不是瓣膜的（[[cardiovascular/cardiac-cycle]]的EDPVR与ESPVR语言、[[clinical-skills/medical-imaging]]的系列对比纪律）。**
:::

::: exercise 瓣膜与抗凝 {level=2}
58岁机械主动脉瓣、房颤与既往消化道出血患者要求“现代血液稀释药”。给出正确药物方案与支配它的数字、及为何直接口服抗凝药在此是错的。
::: solution
**华法林是强制的（机械假体的致血栓表面——双叶热解碳的剪应力激活血小板与淤滞及纤维蛋白铺层——机械瓣的直接口服抗凝药试验（RE-ALIGN与另一达比加群组因血栓与出血伤害的早期终止）是假体瓣凝血酶生成不是房颤淤滞的现代证明）。**方案：**华法林达正确INR带（现代双叶主动脉瓣目标约2.5（2.0–3.0）、旧星形阀与二尖瓣假体及血栓栓塞风险加入者更高或加阿司匹林——她的房颤把目标保持在带的治疗中心；鉴于消化道出血史按缺血与血管风险选择性加阿司匹林——[[blood/thrombosis-anticoagulation]]）、治疗窗内时间质量指标及桥接与围操作期及药物相互作用及妊娠（华法林胚胎病与胎儿窗口）规则、及长期监护瓣膜自身血栓——透视下开放与梯度及跨瓣反流的鉴别（[[#def-lesions]]瓣周对跨瓣问题）、及溶血的深色尿与破碎红细胞签名（[[blood/haemoglobin-disorders]]机械碎裂）。**
:::

::: exercise Eisenmenger咨询 {level=2}
24岁未手术大室缺伴发绀、杵状指、肺压与体压相等；询问关闭、妊娠与飞行。各从生理回答。
::: solution
**关闭：不——缺损如今是泄压阀：固定、超体循环的肺血管阻力（[[respiratory/interstitial-vascular-disease]]的病）、关闭它把右室的喘息变成急性衰竭与死亡（[[#def-congenital]]生理）；管理是Eisenmenger医学：先进肺扩血管治疗（内皮素与PDE5及前列环素通路——[[cardiovascular/circulation-blood-pressure]]扩血管药理应用于肺床）、仅用于高黏滞症状且注意补铁的放血、及移植谈话。**妊娠：强烈不推荐——产褥的体循环血管扩张与失血与制动加深右向左分流与母体死亡率（历史30–50%数字——[[obstetrics-gynaecology/pregnancy-complications]]母体生理章）、可靠避孕、若她仍坚持则专科管理。**飞行与高原：低压舱内使本已减饱和的循环进一步减饱和（[[respiratory/mechanics-breathing]]的Dalton分压算术）——短途商业飞行补水通常可耐受、避免高原与运动与脱水的组合、并记录个体评估**——一个病变、三个答案、一套生理。
:::

::: exercise 变蓝的新生儿 {level=2}
4日龄婴儿吃奶时变蓝软绵；产前超声“正常”；脉搏有力伴柔和单一第二心音；前列腺素E1输注改善血氧饱和。解释这是哪些病变及药物为何有效。
::: solution
**导管关闭时宣示的导管依赖性发绀或左/右心梗阻性病变：鉴别包括大动脉转位复合征、重度肺动脉或主动脉狭窄与闭锁、伴重度梗阻的法洛（“粉红法洛”关闭到发蓝）、及左心梗阻性（以导管依赖体循环的休克而非发绀就诊的缩窄与左心发育不良——[[paediatrics/newborn]]与[[anatomy/embryology]]弓）。**药理：**PGE1（alprostadil）重开并维持动脉导管（[[cardiovascular/cardiac-cycle]]胎儿循环章：导管平滑肌随产后氧与前列腺素撤除升高而收缩）、恢复病变依赖的混合或体-肺血流（呼吸暂停与发热与低血压副作用监护——起始前告知气道团队、因为婴儿可能因导管与舌与癫痫阈的原因梗阻）**——通向超声诊断的稳定桥、前列腺素、导管支架或分流及[[#def-congenital]]的分期手术；“产前超声正常”的课：**胎儿循环隐藏右心与弓病变因为胎盘就是肺——提醒筛查试验设计（[[public-health/screening]]、[[epidemiology-ebm/diagnostic-tests]]）必须知道什么生理在掩盖。**
