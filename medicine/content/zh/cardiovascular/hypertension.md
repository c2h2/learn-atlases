高血压很少引起症状，却是全世界卒中、心肌梗死、心力衰竭和慢性肾脏病最大的单一可改变病因。世界卫生组织估计，远超十亿成人患有高血压，而其中得到控制的不到五分之一。因此，临床任务颇为特殊：发现一种无症状的疾病，用一种不精确的测量来确认它，评估它已造成的损害，并说服一个自我感觉良好的人接受长达数十年的治疗。

本章介绍高血压如何定义和测量、原发性高血压的机制、靶器官损害、值得寻找的继发性病因，以及指南选择治疗的原则。本章遵循英国国家卫生与临床优化研究所（NICE）的指南（NICE 指南 NG136《成人高血压》，2019 年首次发布，2023 年最后更新），并注明欧洲和美国指南的不同之处。指南会变化；实际处理应遵循现行的当地指南。

## 风险是连续的，阈值是选择的

血压与心血管风险之间的关系没有阈值。前瞻性研究协作组（Prospective Studies Collaboration，2002）汇总了约一百万成人的数据，发现从 115/75 mmHg 的通常血压起，在 40 至 69 岁人群中，收缩压每升高 20 mmHg（或舒张压每升高 10 mmHg），卒中死亡和缺血性心脏病死亡大约增加一倍。不存在血压从"安全"突然变为"危险"的点。

因此，高血压的诊断是一个划线的决定：在这条线以上，检查和治疗的获益被认为超过贴标签和药物治疗的代价与危害。不同的指南小组把线划在不同的位置，这就是为什么同一个人在一个国家被诊断为"高血压"，在另一个国家却是"正常高值"。

::: definition 高血压及其分期（NICE NG136） {#def-definition}
在英国，高血压由诊室读数诊断，并用诊室外测量确认，方法为**动态血压监测（ABPM）**，若不适合则用**家庭血压监测（HBPM）**：

| 分期 | 诊室血压 | 日间 ABPM 或 HBPM 平均值 |
|---|---|---|
| 1 期高血压 | 140/90 至 159/99 mmHg | 135/85 至 149/94 mmHg |
| 2 期高血压 | 160/100 mmHg 或更高 | 150/95 mmHg 或更高 |
| 重度高血压 | 收缩压 180 或更高，或舒张压 120 或更高 | — |

靶器官损害**不是**一个分期。它是对 1 期高血压患者给予药物治疗的理由之一。
:::

其他指南的分类不同。**欧洲心脏病学会（ESC）2024** 年指南仍以 140/90 mmHg 及以上为高血压，但增加了**血压升高**（120–139/70–89 mmHg）这一类别，对其中心血管风险高者考虑药物治疗。**美国心脏病学会和美国心脏协会**的指南（2017 年及 2025 年更新）将 **1 期高血压定义为 130–139/80–89 mmHg**，2 期为 140/90 mmHg 及以上。这些是政策上的差异，而非生物学上的差异：它们反映了对同一批试验的不同解读，以及对成本和过度诊断的不同判断。

## 测量一个变动的数字

血压随体位、活动、说话、膀胱充盈、咖啡因、疼痛和焦虑时时变化。单次诊室读数难以反映一个人的通常血压；而且由于首次读数偏高者重复测量时往往较低（**回归均值**），诊断总是需要重复测量。

NICE 规定了细致的诊室测量技术：

- 使用经验证的仪器和与上臂相配的袖带；
- 受测者坐位、放松，手臂支撑于心脏水平；
- 首次评估时测量双臂；如差值超过 15 mmHg，重复测量，若仍存在，此后使用读数较高的一侧手臂；
- 如首次读数为 140/90 mmHg 或更高，测第二次，若与第一次差异明显，再测第三次；记录**后两次中较低的读数**；
- 对糖尿病患者、有体位性头晕或跌倒症状者以及 80 岁及以上者，检查有无体位性低血压（测量站立血压）。

随后用诊室外测量确认诊断。**ABPM** 在受测者通常的清醒时间内每小时至少记录两次，取至少 14 次清醒时读数的平均值。**HBPM** 每次连续测两次坐位血压，间隔至少一分钟，每天两次（最好早晚各一次），至少连续 4 天，最好 7 天；舍弃第一天的读数，其余取平均。

比较两种环境下的测量可发现两种重要模式：

- **白大衣高血压**：诊室血压升高而诊室外血压正常。如果没有诊室外监测，这些人会接受可能并不需要的药物。他们的长期风险比两种环境下血压都正常的人略高，需要随访。
- **隐匿性高血压**：诊室血压正常而诊室外血压升高。除非刻意寻找，否则会漏诊，其风险接近持续性高血压。当存在靶器官损害（如左心室肥厚）而诊室读数看似正常时，应怀疑此病。

ABPM 还记录夜间血压。睡眠时血压通常下降 10–20%；不下降（"非杓型"）常见于慢性肾脏病、糖尿病和阻塞性睡眠呼吸暂停，并与较高的风险相关。

::: example 白大衣 {#ex-confirm}
一位 44 岁的办公室经理两次就诊的诊室读数分别为 146/92 和 150/94 mmHg。她用经验证的仪器在家测量血压，早晚各两次，连续七天；舍弃第一天后，平均值为 131/83 mmHg。她的尿白蛋白-肌酐比值、eGFR、心电图和眼底均正常，10 年心血管风险为 3%。她有高血压吗？

::: solution
她的诊室读数处于 1 期范围（140–159/90–99），但**家庭平均值 131/83 mmHg 低于 135/85 的诊室外阈值**。根据 NICE NG136，**不诊断**高血压：这是**白大衣高血压**。

下一步：
- 确保家庭测量数据可靠：技术正确、仪器经验证、读数足够；如有疑问，用动态血压监测确认；
- 完成常规评估（本例已完成且正常）。如有靶器官损害而无诊室外高血压，则应寻找隐匿性夜间高血压或其他病因；
- 给予生活方式建议；
- 至少每 5 年复测一次诊室血压，如接近 140/90 mmHg 则更频繁，因为白大衣高血压进展为持续性高血压的比例高于血压正常者。

按照诊室外阈值为 130/80 mmHg 的 ACC/AHA 框架，同样的家庭平均值会被称为 1 期高血压，并根据她的 10 年风险决定是否治疗。标签取决于线划在哪里。
:::
:::

## 原发性高血压

约 90% 的成人高血压为**原发性（特发性）高血压**，找不到单一病因。它源于许多各自作用微小的遗传变异与环境因素的相互作用。

::: definition 原发性高血压 {#def-primary}
**原发性高血压**是没有可识别继发性病因的持续性血压升高。其主要促成因素有：

- **年龄**：动脉僵硬在整个成年期使收缩压升高，因此单纯收缩期高血压（收缩压升高，舒张压正常或偏低）是老年人最常见的形式；
- **膳食盐**，尤其在盐敏感者中，以及钾摄入不足；
- **超重**，通过交感激活、胰岛素抵抗、钠潴留以及内脏脂肪对肾脏的压迫；
- **饮酒**、缺乏体力活动和阻塞性睡眠呼吸暂停；
- **家族史和祖源**：在英国，非洲黑人和非裔加勒比裔人群中高血压更常见、发病更早，导致更多的卒中和肾脏病。
:::

无论诱因是什么，持续性高血压都意味着肾脏的压力-利钠关系已经移位，使其需要更高的压力才能排出每日的盐负荷（[[cardiovascular/circulation-blood-pressure#thm-natriuresis]]）。随着时间推移，升高的血压本身又损害肾脏和其他部位的小动脉，使血压升高自我维持。

## 靶器官损害

血压升高损害心脏、脑、肾脏、眼和动脉。

- **心脏。** 左心室肥厚以使室壁应力正常化（Laplace 定律）。肥厚会变得有害：僵硬的心室充盈不良（射血分数保留的心力衰竭），增厚的心肌超出其血液供应，心房颤动更容易发生。高血压也是冠心病和射血分数降低的心力衰竭的主要原因（[[cardiovascular/heart-failure]]）。
- **脑。** 高血压是缺血性卒中和脑出血最强的可改变危险因素，并促成血管性认知障碍和痴呆（[[nervous-system/stroke]]）。
- **肾脏。** 高血压性肾硬化使肾内小动脉狭窄；白蛋白尿是早期标志，慢性肾脏病是晚期后果。肾脏病反过来又使血压升高（[[renal/chronic-kidney-disease]]）。
- **眼。** 高血压视网膜病变从小动脉狭窄和动静脉交叉压迹，到火焰状出血、棉絮斑，在急进型高血压中可出现视盘水肿。
- **动脉。** 高血压加速动脉粥样硬化，是主动脉夹层的主要危险因素，并促成主动脉瘤和外周动脉疾病（[[cardiovascular/vascular-disease]]）。

NICE 建议所有新诊断的高血压患者都接受靶器官损害和心血管风险评估：

- 尿**白蛋白-肌酐比值**和尿试纸检查血尿；
- 血液检查 **HbA1c**、电解质、肌酐和 **eGFR**，以及总胆固醇和高密度脂蛋白胆固醇；
- **眼底检查**评估视网膜病变；
- **12 导联心电图**（左心室肥厚、陈旧性梗死或心律失常）；
- 用 QRISK3 估算 **10 年心血管风险**（对已知高风险者不适用，如已有心血管疾病或慢性肾脏病者）。

## 继发性高血压

约十分之一的高血压患者有可识别的病因。其中一些可以治愈，另一些需要特定治疗。NICE 建议，40 岁以下的高血压患者应考虑转专科评估继发性病因，并更详细地评估治疗的长期获益和风险。其他线索包括重度或顽固性高血压、原本稳定的血压突然升高、低钾以及特定病因的症状或体征。

::: definition 主要的继发性病因 {#def-secondary}
- **肾实质疾病**：最常见的继发性病因。线索：肌酐升高、蛋白尿或血尿。
- **肾血管疾病**：老年血管病患者的动脉粥样硬化性肾动脉狭窄；年轻人，尤其女性的纤维肌发育不良。线索：腹部血管杂音、开始使用 ACE 抑制剂或 ARB 后肌酐上升超过约 30%、反复"闪电性"肺水肿、双肾大小不等。
- **原发性醛固酮增多症**：肾上腺腺瘤或双侧增生自主分泌醛固酮。它是最常见的内分泌性病因，估计见于 5–10% 的高血压患者，在顽固性高血压中更多。只有少数患者血钾降低。筛查试验：**醛固酮/肾素比值**（[[endocrine/adrenal]]）。
- **嗜铬细胞瘤和副神经节瘤**：分泌儿茶酚胺的肿瘤。线索：阵发性头痛、出汗和心悸，血压波动。检查：血浆或尿**甲氧基肾上腺素类物质**。
- **库欣综合征**、甲状腺疾病、原发性甲状旁腺功能亢进和肢端肥大症。
- **主动脉缩窄**：上肢高血压伴股动脉搏动减弱、延迟（桡-股动脉延迟）（[[cardiovascular/valve-congenital-disease]]）。
- **阻塞性睡眠呼吸暂停**：在顽固性高血压中常见，尤其伴肥胖者。
- **药物和物质**：非甾体抗炎药、复方口服避孕药、糖皮质激素、环孢素和他克莫司、促红细胞生成素、某些抗抑郁药（文拉法辛〔venlafaxine〕）、减充血剂、甘草、过量饮酒、可卡因和苯丙胺类。
- **妊娠**：妊娠期高血压和子痫前期（[[obstetrics-gynaecology/pregnancy-complications]]）。
:::

::: example 两种药物下的低钾 {#ex-conn}
一位 52 岁男性尽管服用氨氯地平（amlodipine）和吲达帕胺（indapamide），诊室血压仍为 158/96 mmHg，家庭平均值 152/94 mmHg。血钾 3.1 mmol/L。他的兄弟 49 岁时发生卒中。最可能的继发性病因是什么？如何检查？

::: solution
两种药物未能控制的高血压伴**低钾**，提示**原发性醛固酮增多症**。噻嗪样利尿剂可降低血钾，但 3.1 mmol/L 的水平不应未经检查就归因于利尿剂，早发卒中的家族史也增加了怀疑。

检查（通常由内分泌或高血压专科主导）：
1. **纠正血钾**，因为低钾抑制醛固酮，可导致假性正常结果。
2. **测定醛固酮/肾素比值。** 原发性醛固酮增多症中肾素被抑制，而醛固酮不适当地正常或升高。多种药物会改变该比值（利尿剂、ACE 抑制剂、ARB、β 受体阻滞剂、盐皮质激素受体拮抗剂），因此专科医生可能会根据当地方案，在检查前把他的治疗换成干扰较小的药物（例如钙通道阻滞剂或 α 受体阻滞剂）。
3. 筛查阳性时行**确证试验**（例如盐水抑制试验）。
4. **分型**：肾上腺 CT；如考虑手术，行**肾上腺静脉取血**，以明确过多的醛固酮来自一侧肾上腺（常为腺瘤，可切除）还是双侧（用盐皮质激素受体拮抗剂治疗）。

原发性醛固酮增多症的意义不止于血压：在同样的血压下，它比原发性高血压带来更多的心房颤动、卒中、心力衰竭和肾损害，因为醛固酮本身促进纤维化。
:::
:::

::: example 闪电性肺水肿 {#ex-ras}
一位 74 岁女性有外周动脉疾病和 50 包年吸烟史，一年内第二次因突发肺水肿入院。血压 196/104 mmHg。射血分数 55%。三个月前开始使用雷米普利（ramipril）后，她的肌酐从 110 升至 165 µmol/L。超声显示右肾 8.5 cm，左肾 11 cm。解释最可能的诊断。

::: solution
这些表现的组合提示**动脉粥样硬化性肾动脉狭窄**，可能为双侧或累及优势侧肾脏：

- 她有广泛的动脉粥样硬化（外周动脉疾病、重度吸烟）；
- 使用 ACE 抑制剂后**肌酐上升了 50%**。肾灌注压低时，肾小球滤过依赖血管紧张素 Ⅱ 收缩出球小动脉；去除它会使滤过压降低（[[cardiovascular/circulation-blood-pressure]]）；
- **双肾大小相差**超过 1.5 cm，提示较小的一侧缺血；
- 射血分数保留的**反复闪电性肺水肿**是公认的表现：肾素和血管紧张素激活伴钠排泄受损，导致突然的容量超负荷和高血压。

肾动脉影像（CT 或 MR 血管造影，或多普勒超声）可确诊。大多数动脉粥样硬化性肾动脉狭窄采用内科治疗（控制血压、他汀、抗血小板治疗、戒烟），因为在未经选择的患者中进行的支架随机试验未显示获益。对部分选择性患者考虑血运重建，反复闪电性肺水肿是公认的适应证之一。
:::
:::

## 治疗：生活方式与药物的依据

**生活方式措施**适用于所有高血压患者以及正常高值者。每一项可使血压降低几个 mmHg，合在一起可达到一种药物的效果：

- 减少盐摄入（英国对成人的建议是每天不超过 6 g 盐；WHO 建议少于 5 g）；
- 富含水果和蔬菜的健康饮食（如 DASH 饮食），同时增加钾摄入；
- 超重者减轻体重；
- 规律的有氧运动；
- 饮酒不超过推荐限量；
- 戒烟（它不降低血压，但大大降低总体心血管风险）；
- 减少过量的咖啡因。

药物的依据来自随机试验。Ettehad 及其同事（2016 年，《柳叶刀》）对 123 项试验的大型荟萃分析发现，收缩压每降低 10 mmHg，主要心血管事件的相对风险降低约 20%（相对风险 0.80），卒中降低约 27%，心力衰竭降低约 28%，冠心病降低约 17%，全因死亡降低约 13%。在很宽的起始血压范围内，比例获益相似。

::: theorem 相对获益与绝对获益 {#thm-benefit}
降压带来的比例性（相对）风险降低大致恒定，因此**绝对**获益与个人的基线风险成正比：
$$
\text{绝对风险降低} = \text{基线风险} \times (1 - RR), \qquad NNT = \frac{1}{\text{绝对风险降低}}.
$$
总体心血管风险高的人从同样的降压中获益最多。这就是为什么指南在决定治疗对象时把血压与绝对风险结合起来。
:::

::: example 治疗能换来什么？ {#ex-nnt}
两个人的持续收缩压都是 152 mmHg。A 是一位 45 岁女性，10 年心血管风险 4%。B 是一位 70 岁男性，患糖尿病，10 年风险 25%。假设治疗使收缩压降低 10 mmHg，相对风险为 0.80，分别计算两人的绝对风险降低和 10 年需治疗人数。

::: solution
**A**：风险从 4% 降至$4 \times 0.80 = 3.2\%$。绝对风险降低 0.8 个百分点，$NNT = 1/0.008 = 125$：像她这样的人治疗 10 年，需治疗 125 人才能预防一次主要心血管事件。

**B**：风险从 25% 降至$25 \times 0.80 = 20\%$。绝对风险降低 5 个百分点，$NNT = 1/0.05 = 20$。

同样的血压、同样的药物效果，获益相差六倍。这一算术就是为什么 NICE 在 1 期高血压伴靶器官损害、心血管疾病、肾脏病、糖尿病或 10 年风险 10% 及以上时给予药物治疗，也是为什么对低风险的年轻人，治疗决定是一个共同决策，她自己的价值观占有重要分量。
:::
:::

## 治疗对象与目标

根据 NICE NG136，截至 2026 年：

- **2 期高血压**：任何年龄，在生活方式建议之外给予药物治疗。
- **80 岁以下的 1 期高血压**：对有以下一项或多项者讨论药物治疗：靶器官损害、已确诊心血管疾病、肾脏病、糖尿病，或估计 10 年心血管风险 10% 及以上。
- **60 岁以下、10 年风险低于 10% 的 1 期高血压**：考虑药物治疗。
- **80 岁以上**：如诊室血压高于 150/90 mmHg，考虑对 1 期高血压进行药物治疗，并考虑衰弱和多病共存。

诊室目标为：**80 岁以下低于 140/90 mmHg**，**80 岁及以上低于 150/90 mmHg**；相应的家庭或动态目标低 5 mmHg（低于 135/85 和低于 145/85）。对衰弱或有多种长期疾病的人，目标由临床判断确定。其他指南设定的目标更低：ESC 2024 指南建议大多数成人在可耐受时收缩压目标为 120–129 mmHg，ACC/AHA 指南为低于 130/80 mmHg。这些更低的目标在很大程度上依据 SPRINT 试验（2015）：在无糖尿病的高风险成人中，与收缩压目标低于 140 mmHg 相比，目标低于 120 mmHg 减少了心血管事件和死亡，但低血压、晕厥、电解质紊乱和急性肾损伤更多。SPRINT 用自动仪器在受试者独处时测量血压，其读数低于常规诊室测量，因此其数字不能直接搬到普通诊室。

## 药物选择

主要的一线药物类别为：

- **A**：ACE 抑制剂（如雷米普利）或血管紧张素 Ⅱ 受体阻滞剂（ARB，如氯沙坦〔losartan〕或坎地沙坦〔candesartan〕）。它们减弱血管紧张素 Ⅱ 的作用，可引起高钾血症和肌酐升高；ACE 抑制剂可引起咳嗽，少数引起血管性水肿。两者均有**致畸性**，妊娠期避免使用，对可能怀孕的人慎用。
- **C**：钙通道阻滞剂，通常为二氢吡啶类，如氨氯地平。它们扩张小动脉。踝部水肿、潮红和头痛常见。
- **D**：噻嗪样利尿剂（新处方首选吲达帕胺或氯噻酮〔chlortalidone〕，而非苄氟噻嗪〔bendroflumethiazide〕等较老的噻嗪类）。它们可引起低钠血症、低钾血症、尿酸升高（痛风）和血糖升高。

在英国指南中，β 受体阻滞剂不是单纯高血压的一线药物，因为在试验中它们预防卒中的效果不如其他类别。它们用于有其他适应证时，如心绞痛、陈旧性心肌梗死、心力衰竭或心房颤动。

::: algorithm NICE NG136 治疗步骤 {#alg-steps}
**第 1 步**
- 2 型糖尿病（任何年龄或祖源）：**A**（对非洲黑人或非裔加勒比裔人群，优先选用 ARB 而非 ACE 抑制剂）。
- 无 2 型糖尿病、55 岁以下且非非洲黑人或非裔加勒比裔：**A**。
- 无 2 型糖尿病、55 岁及以上，或任何年龄的非洲黑人或非裔加勒比裔：**C**（如钙通道阻滞剂不适用，例如因水肿或心力衰竭，则用噻嗪样利尿剂）。

**第 2 步**：如血压未控制，加用第二类药物：A + C 或 A + D，或 C + A 或 C + D（对非洲黑人或非裔加勒比裔人群用 ARB 而非 ACE 抑制剂）。

**第 3 步**：在检查依从性后，**A + C + D**。

**第 4 步（顽固性高血压）**：在 A + C + D 最佳耐受剂量下高血压仍未控制。首先用 ABPM 或 HBPM 确认，检查有无体位性低血压，并讨论依从性。然后：
- 如血钾**不超过 4.5 mmol/L**，考虑加用小剂量**螺内酯**（spironolactone）；
- 如血钾**高于 4.5 mmol/L**，考虑加用 **α 受体阻滞剂**或 **β 受体阻滞剂**。

如在四种药物最佳耐受剂量下血压仍未控制，寻求专科意见。
:::

年龄和种族规则反映了肾素-血管紧张素系统的平均差异：老年人以及非洲黑人或非裔加勒比裔人群更常为低肾素、盐敏感性高血压，对钙通道阻滞剂和利尿剂的反应好于对血管紧张素阻断的反应。这些只是平均情况。第 4 步螺内酯的推荐依据 PATHWAY-2 试验（2015）：在顽固性高血压中，螺内酯的降压效果优于比索洛尔（bisoprolol）或多沙唑嗪（doxazosin），与醛固酮过多的作用相符。血钾限值反映了高钾血症的风险，这一风险也随肾功能下降而增加；开始使用后需监测血钾和肾功能。

::: warning 顽固性高血压常常是别的问题
在宣布高血压"顽固"并加用第四种药物之前，先寻找**假性顽固**：测量技术不当（袖带对手臂而言过小）、白大衣效应，以及最常见的——没有服用所开的药物；采用药物浓度检测的研究发现，在因顽固性高血压转诊的人中有相当比例存在这种情况。然后寻找**驱动因素**：高盐或过量饮酒、非甾体抗炎药及其他干扰药物、阻塞性睡眠呼吸暂停，以及继发性病因，尤其是原发性醛固酮增多症。不做这些检查就加药，会使患者承受不良反应而问题仍未解决。
:::

## 重度高血压与高血压急症

血压很高时，处理取决于是否存在急性器官损害。

根据 NICE NG136，诊室血压 **180/120 mmHg 或更高**者，如有视网膜出血或视盘水肿（急进型或"恶性"高血压）、危及生命的症状（如新发意识模糊、胸痛、心力衰竭体征或急性肾损伤），或怀疑嗜铬细胞瘤，应转诊**当天专科评估**。否则，应尽快检查靶器官损害；如发现损害，可不等诊室外监测即开始治疗；如未发现，在 7 天内复测诊室血压。

**高血压急症**是重度高血压伴脑（高血压脑病、卒中）、心脏（急性冠脉综合征、急性肺水肿）、主动脉（夹层）、肾脏或视网膜的急性损害，或发生于妊娠（重度子痫前期或子痫）。它需要住院，通常进入高依赖病房，用静脉药物有控制地降压。由于脑和肾的自身调节已适应高压，血压骤降可引起卒中或肾损伤；通常在数小时内逐步降压，但在某些特定情况下，如主动脉夹层，目标是快速降压。

::: example 头痛和视物模糊 {#ex-accelerated}
一位 38 岁非裔加勒比裔男性头痛、视物模糊两周。血压 232/138 mmHg。眼底检查见双侧火焰状出血、棉絮斑和视盘水肿。肌酐 210 µmol/L，尿试纸蛋白和潜血阳性，血涂片见红细胞碎片。解读这些发现。

::: solution
这是**急进型（恶性）高血压**：重度高血压伴**视盘水肿和视网膜出血**，同时有急性肾损伤和微血管病性溶血（红细胞碎片）。极高的血压引起小动脉纤维素样坏死；红细胞通过这些血管时受损，肾脏小血管受伤，激活肾素，使血压进一步升高。

这是一种**高血压急症**，需要当天专科处理、住院、密切监测和有控制地降压，并仔细关注肾功能。病情稳定后，鉴于他的年龄和病情严重程度，需要寻找继发性病因，尽管原发性高血压是恶性高血压最常见的基础病因。
:::
:::

::: history
1827 年，布赖特（Richard Bright）描述了肾脏病变伴心脏增大的患者，后来的观察者怀疑动脉压升高把两者联系在一起。19 世纪 70 年代，伦敦的马霍迈德（Frederick Mahomed）用脉搏描记器证明，没有肾脏病的人血压也可以很高。里瓦-罗奇（Scipione Riva-Rocci）的充气袖带（1896）和科罗特科夫（Nikolai Korotkoff）对声音的描述（1905）使血压测量成为常规。数十年来，血压升高常被看作一种不应干扰的代偿。始于 1948 年的弗雷明汉心脏研究（Framingham Heart Study）表明，较高的血压可预测心血管疾病；1967 年，由弗赖斯（Edward Freis）领导的退伍军人管理局协作研究证明，治疗重度舒张期高血压的男性可显著减少并发症。后来的试验把获益扩展到较轻的高血压、老年人的单纯收缩期高血压（SHEP，1991）以及 80 岁及以上人群（HYVET，2008）。
:::

血压调控的生理学见[[cardiovascular/circulation-blood-pressure]]。高血压的后果在[[cardiovascular/coronary-artery-disease]]、[[cardiovascular/heart-failure]]、[[cardiovascular/vascular-disease]]和[[nervous-system/stroke]]中再次出现。妊娠期高血压见[[obstetrics-gynaecology/pregnancy-complications]]，肾上腺病因见[[endocrine/adrenal]]，人群层面的血压防控见[[public-health/non-communicable-disease]]。试验和需治疗人数的解读在[[epidemiology-ebm/randomised-trials]]中展开。

::: summary
- 心血管风险随血压连续升高；诊断阈值是政策选择，NICE、ESC 和 ACC/AHA 各不相同。
- NICE NG136：1 期为诊室 140/90 或更高，并经 ABPM 或 HBPM 平均 135/85 或更高确认；2 期为诊室 160/100 或更高，诊室外平均 150/95 或更高；重度高血压为诊室收缩压 180 或更高，或舒张压 120 或更高。
- 诊室外监测可发现白大衣高血压和隐匿性高血压；测量技术很重要。
- 约 90% 为原发性高血压；继发性病因包括肾脏病、肾动脉狭窄、原发性醛固酮增多症、嗜铬细胞瘤、主动脉缩窄、睡眠呼吸暂停和药物。40 岁以下者应考虑专科评估。
- 对所有人评估靶器官损害和心血管风险：尿白蛋白-肌酐比值、HbA1c、肾功能、血脂、眼底、心电图和 QRISK3。
- 收缩压每降低 10 mmHg，主要心血管事件减少约 20%；绝对获益取决于基线风险。
- NICE 步骤：第 1 步根据年龄、种族和糖尿病选 A 或 C；第 2 步 A + C 或 D；第 3 步 A + C + D；第 4 步血钾不超过 4.5 mmol/L 用螺内酯，否则用 α 或 β 受体阻滞剂。目标：80 岁以下低于 140/90，80 岁及以上低于 150/90。
- 重度高血压伴视网膜出血、视盘水肿或危及生命的表现需当天专科评估；应有控制地降压。
:::

## 习题

::: exercise 为患者分期 {level=1}
按 NICE NG136 对每个人分类：(a) 诊室 164/102 mmHg，ABPM 日间平均 154/97 mmHg；(b) 诊室 148/88 mmHg，HBPM 平均 139/86 mmHg；(c) 单次就诊诊室 186/112 mmHg，无症状，眼底正常。
::: solution
(a) **2 期高血压**：诊室 160/100 或更高，ABPM 150/95 或更高。

(b) **1 期高血压**：诊室收缩压 140 或更高，诊室外平均 135/85 或更高（本例两个分量都超过阈值）。

(c) **重度高血压**（收缩压 180 或更高）。无症状且眼底正常，无需当天转诊；应尽快检查靶器官损害，如未发现，在 7 天内复测诊室血压。如发现损害，可不等诊室外监测即开始治疗。
:::
:::

::: exercise 家庭平均值 {level=1 check="round(10*824/6)/10"}
一位男性记录了七天的家庭血压。他每天收缩压的平均值为：第 1 天 152，第 2 天 140，第 3 天 138，第 4 天 136，第 5 天 139，第 6 天 137，第 7 天 134 mmHg。按 NICE 方法（舍弃第一天）计算他的平均收缩压，四舍五入到一位小数，并说明是否达到 1 期阈值。
::: solution
舍弃第 1 天。其余六个数之和为$140 + 138 + 136 + 139 + 137 + 134 = 824$。平均值 $= 824/6 = 137.33$，即 **137.3 mmHg**。高于 135，因此若诊室读数为 140/90 或更高，即确认为 **1 期高血压**（舒张压平均值也应一并考虑）。
:::
:::

::: exercise 选择第一种药物 {level=1}
按 NICE NG136 流程，给出下列各人第 1 步的药物类别：(a) 34 岁无糖尿病的白人女性；(b) 48 岁无糖尿病的非洲黑人男性；(c) 61 岁患 2 型糖尿病的南亚男性；(d) 72 岁无糖尿病的白人女性，既往试用氨氯地平出现踝部水肿。
::: solution
(a) **ACE 抑制剂或 ARB**（55 岁以下、无糖尿病）。由于她可能怀孕，应讨论致畸风险，以及避孕和计划怀孕时应如何处理。

(b) **钙通道阻滞剂**（非洲黑人、无糖尿病、任何年龄）。

(c) **ACE 抑制剂或 ARB**（2 型糖尿病，不论年龄或祖源）。

(d) 通常首选钙通道阻滞剂（55 岁及以上），但它引起了水肿，因此替代选择是**噻嗪样利尿剂**。
:::
:::

::: exercise 需治疗人数 {level=2 check="ceil(1/(0.15-0.15*0.8^2))"}
某人 10 年心血管风险为 15%。治疗使收缩压降低 20 mmHg。假设每降低 10 mmHg 相对风险为 0.80，并按乘法叠加，计算预防一次事件需治疗 10 年的人数，向上取整。
::: hint
连续两次 10 mmHg 的降低使相对风险为$0.80 \times 0.80$。
:::
::: solution
降低 20 mmHg 的相对风险为$0.80^2 = 0.64$。治疗后风险为$0.15 \times 0.64 = 0.096$。绝对风险降低为$0.15 - 0.096 = 0.054$。$NNT = 1/0.054 = 18.5$，向上取整为 **19**。（需治疗人数按惯例向上取整。）
:::
:::

::: exercise 第 4 步 {level=2}
一位 63 岁女性在雷米普利、氨氯地平和吲达帕胺最佳耐受剂量下，家庭血压平均值仍为 151/92 mmHg。血钾 4.1 mmol/L，eGFR 72 mL/min/1.73 m²。列出加用第四种药物前应检查的内容，并说明 NICE 建议的药物及其所需监测。
::: solution
**加药之前**：用诊室外读数确认血压升高（本例已完成，但需检查技术和仪器）；检查有无体位性低血压；坦诚讨论**依从性**；审查干扰药物（非甾体抗炎药、减充血剂、甘草）以及盐和酒精摄入；考虑阻塞性睡眠呼吸暂停和继发性病因，尤其是在顽固性高血压中常见的**原发性醛固酮增多症**。

**药物**：血钾**不超过 4.5 mmol/L**，NICE 建议考虑小剂量**螺内酯**。

**监测**：开始使用后不久及此后定期检查血钾和肾功能，因为有高钾血症风险，尤其当 eGFR 下降或加用其他升高血钾的药物时。男性可出现乳房发育。如四种药物下血压仍未控制，寻求专科意见。
:::
:::

::: exercise 发作 {level=2}
一位 41 岁女性有阵发性搏动性头痛、出汗和心悸，每次持续 20 分钟，发作时记录的血压为 210/120 mmHg。发作间期血压 150/95 mmHg。必须排除什么诊断？如何排除？为什么不应单独开始使用 β 受体阻滞剂？
::: solution
必须排除**嗜铬细胞瘤或副神经节瘤**。首选检查是**血浆游离甲氧基肾上腺素类物质**或 24 小时尿甲氧基肾上腺素类物质；随后用 CT 或 MRI 及功能影像对肿瘤定位。惊恐发作、甲亢和低血糖可以模仿它，但漏诊嗜铬细胞瘤有发生高血压危象的风险。

单独使用 β 受体阻滞剂是危险的，因为阻断 β2 介导的血管扩张后，循环儿茶酚胺引起的 α 肾上腺素受体血管收缩就失去了对抗，可诱发高血压危象。应先开始 α 受体阻断（例如酚苄明〔phenoxybenzamine〕或多沙唑嗪），如因心动过速需要，之后再加用 β 受体阻滞剂，然后手术切除（[[endocrine/adrenal]]）。
:::
:::

::: exercise 老年患者 {level=2}
一位独立生活的 84 岁女性诊室血压 166/78 mmHg，家庭平均值 158/74 mmHg。卧位血压 164/80 mmHg；站立 3 分钟后为 136/68 mmHg，并感到头晕。讨论决定治疗时需考虑的问题。
::: solution
她有**单纯收缩期高血压**，家庭平均值高于 NICE 阈值；在 80 岁及以上身体状况良好者中进行的试验（HYVET）表明，治疗可减少卒中、心力衰竭和死亡。她的诊室血压高于 150/90 mmHg，因此可以考虑治疗。

她还有**直立性低血压**（收缩压下降 28 mmHg 并有症状）。进一步降压可能导致跌倒，而在她这个年龄，跌倒可导致骨折、头部损伤和丧失独立生活能力（[[geriatrics-palliative/falls]]）。

合理的原则：审查并停用加重体位性低血压的药物；建议充分饮水和缓慢起身；如开始治疗，从低剂量开始缓慢加量；以**站立**和坐位读数共同确定目标；采用与她年龄相应的 NICE 目标（诊室低于 150/90，家庭低于 145/85），并就衰弱程度作临床判断。决定与她共同作出，权衡在数年内逐渐显现的获益与可能立即发生的危害。
:::

::: exercise 年轻成人的高血压 {level=3}
一位 24 岁男性诊室血压 172/104 mmHg，经动态血压监测确认（平均 165/100 mmHg）。血钾 3.4 mmol/L。查体发现股动脉搏动比桡动脉弱且延迟，背部可闻及收缩期杂音。构建年轻成人高血压的鉴别诊断，指出本例最可能的病因，并解释各项发现。
::: hint
比较上肢和下肢的脉搏。什么会导致两者之间的压力差？
:::
::: solution
40 岁以下高血压的**鉴别诊断**：肾实质疾病（肾小球肾炎、多囊肾、反流性肾病）；肾血管疾病（纤维肌发育不良）；原发性醛固酮增多症和其他盐皮质激素过多（包括 Liddle 综合征等罕见遗传类型）；嗜铬细胞瘤；库欣综合征；甲状腺疾病；**主动脉缩窄**；阻塞性睡眠呼吸暂停；药物（合成代谢类固醇、兴奋剂、可卡因、减充血剂、甘草）；以及原发性高血压，尤其在有肥胖和家族史时仍有可能。

**最可能：主动脉缩窄。** 主动脉狭窄，通常恰在左锁骨下动脉起点远端，导致：
- **上肢高血压**，因为左心室要对抗梗阻射血，而在梗阻远端以低压灌注的肾脏激活肾素；
- **股动脉搏动减弱、延迟**（桡-股动脉延迟），下肢血压较低；
- **背部杂音**，来自通过狭窄处和**侧支动脉**（肋间动脉）的血流，侧支动脉可侵蚀肋骨下缘（胸片上的肋骨切迹）。

血钾轻度降低与肾脏肾素激活引起的继发性醛固酮增多相符。主动脉缩窄与二叶式主动脉瓣相关，在女性中与 Turner 综合征相关。超声心动图和 CT 或 MR 血管造影可确诊，治疗为支架或手术。即使修复后，高血压也常持续存在，需要长期随访（[[cardiovascular/valve-congenital-disease]]）。
:::
