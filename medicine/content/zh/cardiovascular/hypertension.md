高血压是最常见的慢性病、也是全球早死最大的单一贡献者——是上一章生理最清晰的应用：肾性压力-排钠设定点的持续上移、以诊室数字表达、以卒中、心肌梗死、心衰、肾病、视网膜病变与痴呆偿付。其临床逻辑建立在三个事实上：**风险从远低于当前阈值处连续上升**（通常压力与血管事件的对数线性关系、无安全下限也无阈值获益）、**治疗按绝对降压幅度成比例预防事件**（试验的削减在实现的毫米数层面可获得、且大体与药类别无关）、及**少数病例有可除去的病因**——这就是管理算法头几行花在确认与排除、然后才处方数年的原因。

本章讲述定义与测量、原发性高血压的病理生理、继发原因、靶器官损害、及作为应用生理的治疗算法。

## 定义、确认并测量一个移动的数字

::: definition 阈值与测量问题 {#def-definition}
高血压是**需要治疗水平的血压、不是一个疾病实体**：诊室阈值（NICE式两步算法中、140/90的阶段1由诊室外平均≥135/85确认、阶段2为诊室≥160/100或阶段1伴靶器官损害；较低的ACC/AHA 130/80反映连续风险数据与SPRIFT结局试验的解读）位于**真正风险连续体的上方**——指南语言是“confirmed”、“诊室治到140/90以下、家中135/85以下”的原因。**数字的质量是一个测量问题**：袖带气囊大小（臂围误差）、休息与靠背与臂高（±5–10 mmHg的体位与静水压项）、五遍取首五条平均规则、谈话与膀胱与近期咖啡因、及**使单次就诊不可信的回归均值**（诊断需要第二个场合、而家庭或动态监测——带其夜间杓型与变异性与隐匿模式数据——是确认工具）。两个命名的测量综合征是流行病学家与处方者的共同问题：**白大衣高血压**（诊室高、诊室外正常——近乎良性、但是值得随访的风险标志、及把十年药片塞给无辜者的陷阱）与**隐匿性高血压**（诊室正常、诊室外或夜间高——轮班者、动脉硬化的糖尿病者、原因不明左室肥厚的“血压正常者”）——而**动态监测的夜间非杓型**本身就是最强的诊室外预测因子（[[epidemiology-ebm/diagnostic-tests]]此论证的版本：阈值以敏感度换成本、确认性检查的目的是把患者从筛查状态移入已知数字的治疗状态）。
:::

::: definition 原发性高血压：设定点疾病 {#def-primary}
九成成人高血压是**原发性（essential）**——不是一个机制而是数个汇聚于[[cardiovascular/circulation-blood-pressure]]的肾钠处理与小动脉张力：**肾单位数目与肾小管重吸收**（发育与遗传的“肾单位剂量”——低出生体重的少而大的肾小球；[[renal/potassium-calcium-phosphate]]的单基因课程——Liddle的功能获得ENaC以肾素抑制模拟醛固酮过多、Gordon的噻嗪敏感共转运体过度活动、及功能丧失的Gitelman与Bartter表式证明转运体设定群体血压）；**压力性排钠增益降低**（肾只在更高血压排出钠负荷——[[#def-primary]]标题的Guyton综合、这就是限钠降压及设定点一旦确立便自我防御的原因）；**肾素-血管紧张素-醛固酮系统作为个人的“肾素谱”**（年长、黑人与慢性肾病患者的低肾素盐-容量表型解释 Differential 药物反应而非种族生物学本身、及年轻白人女性的高肾素血管痉挛表型）；**交感张力及其重设**（压力反射、肥胖相关的肾神经传入与传出激活——肥胖-高血压流行与去神经试验的机制原理）；及**血管重塑**（小动脉中膜增厚与内径减小——因还是果、Bayliss肥厚的前馈——僵硬的大动脉加上老年单纯收缩期高血压与宽脉压：血管树章疾病的最常见形态、[[cardiovascular/vascular-disease]]）。胰岛素抵抗、尿酸、微生物群与炎症起调制作用；孟德尔随机化与全基因组关联架构（数百个小效应血压位点、单基因离群值）证实多基因加环境模型（[[genetics/common-disease-genetics]]）。
:::

::: example 白大衣与夜间 {#ex-confirm}
44岁办公室经理两次就诊三次读得148/94；家庭监测平均124/79；动态白天平均127/81、夜间杓型4%。
::: solution
**伴夜间非杓型的白大衣高血压——病例的两半要分开。**诊室升高、诊室外正常与接近真血压正常者的低心血管事件率说明：这个数字不用药、生活方式建议、年度复查（一部分转化为持续性高血压）、及认识到诊室的交感浪潮是代谢与升压高反应性的真实特质标志、值得随访而非治疗（[[epidemiology-ebm/diagnostic-tests]]的确认逻辑、[[clinical-skills/physical-examination]]）。**4%的杓型（正常≥10%）是值得谈话的发现**：非杓型与靶器官损害并行并预测事件、其原因是不知不觉打鼾的她患的睡眠呼吸暂停、酒精与晚间咖啡因、糖尿病自主神经病变、慢性肾病与原发性醛固酮（[[endocrine/adrenal]]）、抑郁与轮班。管理于是是**靶器官普查（眼底、心电图与超声心肌质量、尿白蛋白-肌酐比与肌酐与eGFR、血脂与HbA1c）、带血压特异数字的生活方式（体重约1 mmHg/kg、盐靶标、全周运动的5–8 mmHg、酒精上限、DASH式饮食与补钾的肾警诫）、及6–12个月再监测**——加上病史早已挣得的睡眠研究。教训可推广：**动态研究不是判决而是回答了另一个问题——平均值做主、图形供情报。**
:::

## 继发原因与受损的靶器官

::: definition 继发性高血压：值得寻找的短名单 {#def-secondary}
生理呼喊或数字不端时就找病因：**肾实质病变**（总体上最常见继发原因——[[renal/chronic-kidney-disease]]容量-肾素图像伴贫血与钙磷同伴）、**肾动脉狭窄**（年长者动脉瘤、年轻女性的纤维肌性发育不良伴杂音与串珠样造影——[[cardiovascular/circulation-blood-pressure]]历史段的金页-单夹两肾生理表达为反复闪性肺水肿、ACE抑制剂后eGFR下降>30%、及Pickering综合征的血运重建论证）、**原发性醛固酮增多症**（[[#ex-confirm]]与[[endocrine/adrenal]]）、**嗜铬细胞瘤**（持续或阵发的儿茶酚胺升压浪潮：头痛、心悸、出汗与苍白、波动或体位性图像、变肾上腺素类的生化首着、及[[physiology/autonomic-nervous-system]]与[[cardiovascular/circulation-blood-pressure]]的先α后β诫命）、**Cushing综合征及甲状腺、甲状旁腺与肢端肥大的内分泌病**（[[endocrine/thyroid]]、[[endocrine/bone-calcium]]、[[endocrine/hypothalamus-pituitary]]——皮质醇的盐皮质激素允许与血管效应、甲状腺毒症收缩期与甲减舒张期高血压、肢端肥大的睡眠呼吸暂停）、**主动脉缩窄**（无线电-股动脉延迟与臂腿压差的年轻高血压者、[[cardiovascular/valve-congenital-disease]]的二叶瓣与Turner关联）、**药物诱导**（口服避孕药与雌激素的血管紧张素原效应、NSAID的前列腺素撤除钠潴留、激素及carbenoxolone与甘草的盐皮质激素效价——11β-羟类固醇脱氢酶的表观盐皮质激素过多、环孢素与他克莫司、促红素、可卡因与苯丙胺、减充血剂、文拉法辛与MAOI的奶酪相互作用、及医学史上的甘草茶表型）、及**阻塞性睡眠呼吸暂停**（经交感与醛固酮激活及胸内压摆动的非杓型、抵抗、鼾声-肥胖表型）。查体与基础血检尿检心电图与眼底能找到大多数；警示特征（<30或>55岁起病、抵抗、低钾、肾功能恶化、发作、肾脏不对称）打开特异路径（[[clinical-skills/physical-examination]]）。
:::

::: example 低钾的高血压者 {#ex-conn}
52岁服氨氯地平与苄氟噻嗪，血压158/96、随机钾3.0、eGFR 78、45岁卒中家族史。
::: solution
**现在筛原发性醛固酮增多症**——近抵抗性高血压加近自发性低钾加早卒中家族史是[[#def-secondary]]病例发现三联、而钾到3.0时噻嗪是同谋而非解释（被揭穿后仍这么低的正常人不缺的噻嗪泄漏仍值得比值）。实用顺序：**把降压药换离干扰肾素的组合（停苄氟噻嗪与ACE/ARB及若在的螺内酯类；氨氯地平、多沙唑嗪与维拉帕米相对不扰比值）、纠正钾、送醛固酮-肾素比（被抑制的肾素伴不当正常-高的醛固酮是信号）、确认、然后成像——并接受CT会在这个年龄组一半显示偶发微结节、所以定位决定属于肾上腺静脉取血、不属于放射医师。**疾病超出数字的要紧之处：**醛固酮的心肌与肾纤维化、相等血压下房颤与卒中与心衰的超额**（[[renal/potassium-calcium-phosphate]]的钾与[[cardiovascular/heart-failure]]醛固酮臂的论证）、所以切掉的腺瘤或用上的依普利酮买到的多于毫米数。比值分拣的鉴别：**Liddle综合征**（[[renal/potassium-calcium-phosphate]]年轻、低肾素低醛固酮、阿米洛利应答的家系）、表观盐皮质激素过多与甘草、Cushing、先天性肾上腺增生的去氧皮质酮过多、及比值读作继发性醛固酮增多 Renovascular 高肾素/高醛固酮图像（两激素皆升、肾素未被抑制——让患者免去不必要肾上腺切除的区分）。
:::

::: example 闪性水肿与上升的肌酐 {#ex-ras}
71岁吸烟者伴弥漫血管病、两次夜间突发气促伴粉红泡沫痰、血压210/110、被当“哮喘”治；因蛋白尿起始的ACE抑制剂十天内把肌酐从96抬到148 µmol/L；超声肾脏9与7 cm。
::: solution
**双侧（或孤立肾）肾动脉狭窄伴Pickering闪性肺水肿及后负荷依赖的肾小球滤过。**生理如故事：两肾（或唯一有功能的那个）经固定狭窄灌注并依赖**血管紧张素II的出球小动脉收缩维持滤过压**（[[renal/filtration]]的单肾单位算术）；移除该张力使GFR下降而压力不怎么变——**ACE抑制剂后的肌酐上升不是过敏而是生理、其双侧病变时>30%的上升是停药-普查信号**（伙伴健康的单侧狭窄耐受同药甚至肾脏保护获益——考官偏爱的不对称）。闪性水肿是同一状态对僵硬心室的负荷压力袭击（[[cardiovascular/heart-failure]]射血分数保留生理与[[cardiovascular/circulation-blood-pressure]]钠与后负荷故事）、而不对称的小型缺血肾完成解剖证据。管理：**强化的药物治疗（他汀、抗血小板、及解剖明了后在肌酐监护下谨慎重启肾素-血管紧张素阻断——动脉粥样硬化性肾血管试验的教训：血运重建只在闪性水肿与难治性心衰表型优于药物治疗、恰是这个表现、血运重建——球囊加支架——收益最高）、纤维肌性发育不良的对照（年轻女性、球囊不带支架、常治愈）、及在血管中心做的主动脉造影或CT或MR或双工的解剖决定**（[[cardiovascular/vascular-disease]]、[[renal/chronic-kidney-disease]]）。
:::

::: example 抵抗的打鼾者 {#ex-osa}
49岁男性（BMI 38、颈围44 cm）服氨氯地平10、雷米普利10与苄氟噻嗪2.5、家测血压156/98、白天嗜睡、目击呼吸暂停、钾4.1、eGFR 88。
::: solution
**伴阻塞性睡眠呼吸暂停表型的抵抗性高血压**——加第四种药之前、[[#def-secondary]]清单：依从性（配药史与越来越多的尿或血药检测）、NSAID与甘草与减充血剂审计、盐与酒精、袖带与技术、**及本例Epworth评分的睡眠呼吸暂停**——间歇缺氧的交感浪潮、醛固酮激活、夜间非杓型与夜间口呼吸生理使颈围成为带血压后果的查体发现、且该表型里[[#ex-conn]]的醛固酮筛查也比例失衡地常阳性。检查与管理：**家庭睡眠研究或多导睡眠图、按严重度的CPAP或减重或下颌装置（CPAP的血压效应温和——几个毫米汞柱——但依从介导与清醒获益及依从者可能的心血管事件效应驱动指南支持）、GLP-1时代的减重论证（替尔泊肽与司美格鲁肽的呼吸暂停严重度与血压试验结果——[[endocrine/diabetes]]的肥胖药理）、夜间习惯咨询、然后驱动治疗后压力仍高时抵抗练习的螺内酯加药阶梯。**教学：抵抗更常是有未治原因的综合征、而非四药之病——而病因清单是生理（[[cardiovascular/circulation-blood-pressure]]的时间尺度、[[endocrine/adrenal]]的醛固酮、[[renal/water-sodium]]的钠）。

::: history
高血压的历史是对**治疗虚无主义的击败**：Riva-Rocci的带袖带血压计（1896）与Korotkoff的听诊音使数字可见；von Recklinghausen然后**Allbutt与Mahomed与Parkes Weber**描述了伴肾与心结局的“高血压”病；Keith、Wagener与Barker的**眼底分级（1939）**与恶性高血压的生存曲线（治疗前的中位年数——20世纪医学最吓人的图）定义了自然史。干预时代：**1950-60年代的退伍军人管理局试验（证明重度高血压获益的限钠与降压药试验）、Framingham队列的风险因子流行病学（把数字重构为风险的连续关系、[[epidemiology-ebm/observational-studies]]）、MRC医学研究理事会轻度高血压试验及澳洲与IPPPSH与HDFP试验把治疗扩展到轻度范围、SHEP与Syst-Eur试验证明老年单纯收缩期高血压的获益（HYVET的健旺80+续篇）、及现代类别与策略试验——ALLHAT的噻嗪比较之争、HOPE与ONTARGET的ACE/ARB领域逻辑、钠的血压算术的盐替代试验、PATHWAY-2对抵抗的螺内酯答案、及带无人值守示波测量读数星号的SPRINT强化目标之争**；期间、病因被发现——Conn的醛固酮分泌腺瘤（1955）、嗜铬细胞瘤的外科时代、Liddle的阿米洛利应答家系、肾动脉与Goldblatt线、及遗传学时代的单基因家系收获（[[renal/potassium-calcium-phosphate]]）。
:::

## 通向何处

血压生理——本章利用的——在[[cardiovascular/circulation-blood-pressure]]；肾转运与单基因型在[[renal/water-sodium]]与[[renal/potassium-calcium-phosphate]]；继发内分泌病因在[[endocrine/adrenal]]与[[endocrine/thyroid]]；血管与心脏靶损害在[[cardiovascular/vascular-disease]]、[[cardiovascular/heart-failure]]与[[cardiovascular/coronary-artery-disease]]；证据机器在[[epidemiology-ebm/randomised-trials]]与[[epidemiology-ebm/diagnostic-tests]]；妊娠的高血压在[[obstetrics-gynaecology/pregnancy-complications]]。

::: summary
- 高血压是连续风险曲线上的治疗阈值；诊室外测量确认（白大衣与隐匿模式、夜间非杓型）是诊断的一部分、不是形式。
- 原发性高血压是肾性压力-排钠设定点加小动脉重塑、钠处理、肾素谱、交感张力与血管僵硬度是其可调项。
- 继发清单短而值得知道——肾实质与肾血管病变、醛固酮过多、嗜铬细胞瘤、内分泌与药物病因、缩窄与睡眠呼吸暂停——按临床模式追捕、而非散弹检查。
- 靶损害（左室、视网膜、脑、肾、血管）既给疾病分级又重构风险；找到它把临界患者推过治疗线。
- 治疗是毫米数：生活方式数字、匹配肾素/盐表型的AB/CD类别算法、抵抗加螺内酯、及受控下降的急症规则（[[cardiovascular/circulation-blood-pressure]]自身调节的谨慎）。
:::

## 练习

::: exercise 分类并确认 {level=1}
两次就诊诊室读数146/92与150/94；七天家庭平均131/83。给患者分期并说明下一步。
::: solution
诊室阶段1（140–159）——但家庭平均**131/83、低于135/85的诊室外阈值**：所以按NICE式算法这是**白大衣或至少临界性高血压域——还别贴阶段1标签**；行动是**动态监测（或延长家庭记录）确认、靶器官普查（超声心肌质量、尿白蛋白、eGFR、眼底）——临界状态下它决定治疗线、及生活方式治疗数月复查**——附注ACC/AHA框架会把同一人叫“阶段1高血压”并按十年风险治疗、这是阈值政策（[[epidemiology-ebm/diagnostic-tests]]）而非生物学的诚实例子、而家庭读数技术（验证设备、早晚各两遍×7天、丢弃第1天）必须先正确、算术才有意义。
:::

::: exercise 选第一个药 {level=1}
给出NICE式起始类别（及理由）：(a) 28岁白人女性；(b) 64岁黑人男性；(c) 57岁伴2型糖尿病与白蛋白尿；(d) 71岁伴单纯收缩期168/72。
::: solution
**(a) A（ACE抑制剂/ARB）**——年轻、高肾素生理类别效应试验规则：55岁以下与育龄女性——配避孕与妊娠致畸咨询、把（a)变成家系规划谈话、[[obstetrics-gynaecology/contraception-fertility]]）。**(b) C（钙通道阻滞剂）**——年长/黑人人群低肾素盐处理表型（“按年龄与族裔A或C”算法；此生理中C在卒中终点胜B）。**(c) A**——白蛋白尿糖尿病肾病的出球臂肾脏保护（[[renal/chronic-kidney-disease]]指南强制的ACE/ARB、现已加[[endocrine/diabetes]]的SGLT2抑制剂与非奈酮臂）。**(d) C或噻嗪样利尿剂**——老年僵硬动脉的单纯收缩期高血压（[[#def-primary]]的宽脉压生理；此确切表型的二氢吡啶与氯噻酮/吲达帕胺证据、HYVET的健旺八旬延伸、及伴冠脉病史时舒张压过度降至约60以下的谨慎——J曲线之争、[[cardiovascular/coronary-artery-disease]]）。β阻滞剂：本框架不是单纯高血压的一线类别（卒中与新发糖尿病比较）、但有强适应证时一线——心绞痛、心梗后、率控制、主动脉病。
:::

::: exercise 解读肾素谱 {level=2}
分配可能的诊断：(a) 高肾素、高醛固酮、高血压、低钾、肾脏不对称其一8 cm；(b) 低肾素、低醛固酮、高血压、低钾、每天喝甘草茶；(c) 低肾素、高醛固酮；(d) 高肾素、高醛固酮、无高血压、钾正常低值。
::: solution
**(a) 肾血管性高血压/缺血性肾病**——被夹肾的高肾素驱动伴继发性醛固酮增多[[#ex-ras]]生理的单侧小肾；与（c)的区分正是比值肾素一半的工作）。**(b) 表观盐皮质激素过多（甘草/生胃酮）**——甘草次酸的11β-HSD2阻断让皮质醇在盐皮质激素受体起作用：容量扩张、肾素与醛固酮俱受抑、低钾——Liddle的可读似原型（也俱低；阿米洛利应答与家系分开它们——[[renal/potassium-calcium-phosphate]]）。**(c) 原发性醛固酮增多症**——[[#ex-conn]]。**(d) 无高血压的低钾组：Gitelman与Bartter及偷偷服利尿剂的肾素与醛固酮高、血压正常状态（尿利尿剂筛查与尿钙尿氯做分拣——[[renal/tubular-function]]基于氯的算法）**——谱的课：肾素与醛固酮是一双坐标、高血压与钾填第三第四维。
:::
:::

::: exercise 抵抗性高血压 {level=2}
正确定义抵抗（先给假性清单）、然后给生理加药阶梯、含证据最好的四线药及其监测。
::: solution
**真抵抗需要对照测量的确认升高（[[#ex-confirm]]动态核查）、依从性（药物浓度检测令人不适的诚实——“抵抗”队列的三分之一）、及驱动清单：NSAID、减充血剂、甘草、酒精与盐、阻塞性呼吸暂停、[[#ex-conn]]的醛固酮、肾动脉狭窄、失效的透析通路容量负荷、及长期糖尿病钙化动脉被袖带测错的假性抵抗。**阶梯：**A（或C）+ C（或A）+ 足量噻嗪样利尿剂（吲达帕胺/氯噻酮——苄氟噻嗪剂量上限问题）——然后PATHWAY-2的螺内酯（轻度自主醛固酮生理想象的人群；1–2周监测钾与肌酐及男性乳腺发育谈话；依普利酮或阿米洛利作耐受替代、eGFR<45时高钾风险陡升——[[renal/potassium-calcium-phosphate]]）；四线以上选项：β或α阻滞剂（前列腺获益）、米诺地尔的直接小动脉扩张配反射-β阻滞剂加利尿剂（多毛与心包积液的老药现代救场）、肼屈嗪的同逻辑配对、中枢作用药的旧权衡、及肾去神经装置的转诊试验地位。**底层算术：抵抗通常是**容量/钠与醛固酮生理加未识别的驱动**——阶梯是带药名的那个洞见（[[cardiovascular/circulation-blood-pressure]]、[[renal/water-sodium]]）。
:::

::: exercise 嗜铬细胞瘤检查 {level=2}
列出临床模式、带准备陷阱的生化首检、定位顺序、及决定生存的围术期生理。
::: solution
**模式：**发作性头痛-心悸-出汗-苍白的阵发伴波动或持续抵抗性高血压及体位性低血压（背后的血浆容量收缩）、带囊性与高血管成像行为的肾上腺偶发病灶、家族综合征（RET/MEN2、VHL与SDH及NF1线——[[genetics/cancer-genetics]]肿瘤综合征章、及10%双侧、肺外、恶性、家族性、儿童口诀的现代百分比）。**生化：****血浆游离变肾上腺素类或24小时尿分馏变肾上腺素类**（代谢物泄漏逻辑——循环儿茶酚胺的持续肿瘤O-甲基化胜过空腹点测儿茶酚胺）、带假阳性药物（三环、拉贝洛尔与索他洛尔的检测干扰、某些检测里的对乙酰氨基酚）及α阻滞剂邻近停药陷阱；急性病与应激采样的假阳性（[[epidemiology-ebm/diagnostic-tests]]似然比逻辑）。**定位：**先CT或MRI肾上腺、功能影像（MIBG/DOTATATE时代）搜肺外与转移。**围术期生理——考题：****α阻滞（酚苄明的非竞争性共价阻断或多沙唑嗪的竞争性）10–14天并放开盐与液体重新扩容、α确立后才β阻滞（无对抗α的高血压危象逻辑——[[physiology/autonomic-nervous-system]]与[[cardiovascular/circulation-blood-pressure]]的嗜铬细胞瘤提及）、术中肿瘤处理的升压浪潮与夹闭后及切除后的循环虚脱用液体与输注管理、及切除后的低血糖与低血压监护（关掉的驱动与β阻滞、容量脆弱循环）**——加上使手术成为照护开端而非终点的基因检测与终身随访（[[endocrine/adrenal]]）。
:::

82岁（健旺、独立）诊室164/78、家测158/74、伴头晕的体位下降28/14；肌酐118、钠136。规划下降并为它辩护。

::: solution
**个体线（级联）：**WHO HEARTS与NICE式诊室算法——确认、普查靶器官、按表型以固定剂量组合治疗（依从与成本逻辑；单片复方试验——POLYLISH与TIPS与SECURE及2022-24固定剂量组合一级预防试验——“单片复方策略”证据家族）、护士与药师主导的滴定与家庭读数文化；以衡量的**治疗级联（知晓→治疗→控制）**作问责指标、附社区健康工作者与远程监测分权试验的支持数字。**人群线（Rose）：**因为风险连续、人人小移胜过少数人大移——故**食品政策减钠与钾替代盐（盐替代与SSaTT中国试验的人群规模卒中与死亡削减、带肾病安全警诫及食品环境的标签与再配制杠杆——[[public-health/prevention-promotion]]与[[public-health/non-communicable-disease]]）、酒精与体重与运动政策、及使血管风险门诊成为单一服务的烟草与饮食交互（[[public-health/determinants-inequalities]]的不公梯度：高血压的患病、检出与控制都追踪贫困）。** **证据脊柱：**轻度高血压与老年收缩期试验家族证明治疗获益（[[epidemiology-ebm/randomised-trials]]）、练习器的毫米-风险荟萃曲线、及SPRINT读数警诫作为测量要紧的可教例子（[[epidemiology-ebm/critical-appraisal]]）。** **诚实线：**阈值下移的过度诊断与标签成本（白大衣部分——诊断试验算术）、依从衰减作为约束性限制（直接观察与每日一片组合及门诊整合配药与移动提醒试验家族、药物浓度监测的令人不适的发现）、及原发性醛固酮的筛查不足作为抵抗队列可解决的比例。委员会的规划因此是：盐上政策、诊室上级联、处方上组合、患者一侧家庭监测、及控制率目标——一条曲线、四个杠杆。
