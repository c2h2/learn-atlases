冠心病是动脉粥样硬化应用于心脏自身的循环：一生暴露于动脉壁内滞留、变异的脂蛋白，以心绞痛、梗死与猝死兑付，而其中自然史的每个阶段如今都可治——这恰是它仍是头号死因的原因，因为治疗要求识别一个沉默数十年的病。生理是供需资产负债表（[[#def-ischemia]]）、病理是[[pathology/haemodynamics]]的血流场故事、而药理与外科是一串关于斑块稳定、血栓与血运重建阈值的决定。

本章讲述动脉粥样硬化发生与风险、慢性冠脉综合征及其检查、急性冠脉综合征及其分钟、及决定下一个十年的二级预防规划。

## 资产负债表：供应、需求与要紧的狭窄

::: definition 动脉粥样硬化与其风险算术 {#def-athero}
动脉粥样硬化发生是**对滞留脂蛋白的反应**过程：**进入内膜基质并被困住的LDL与残粒（apoB的必要而充分角色——遗传学证明——家族性高胆固醇血症的常染色体显性LDL受体课程，[[genetics/mendelian-inheritance]]）被滞留、被修饰（氧化、髓过氧化物酶化）、驱动单核募集、泡沫细胞形成与脂纹**，纤维帽斑块（脂质-坏死核上的平滑肌胶原）在**低剪切、摆动血流区**（分叉——LAD近端与冠脉开口的偏爱、[[pathology/haemodynamics]]的内皮力学生物学与[[anatomy/thorax]]的冠脉解剖与优势型）用数十年成熟。**临床危险因素是这一过程的剂量变量**——LDL与Lp(a)（遗传固定、因果、现已可测、治疗在望的脂蛋白）、apoB对LDL的不一致、血糖与血压与吸烟的暴露-反应曲线（后者急性血栓与血管痉挛效应叠加于其慢性效应）、年龄、男性、及使个人与多基因史成为算术一部分的家族史加遗传风险架构（[[genetics/common-disease-genetics]]）；**风险计算器（QRISK与SCORE家族）**把它们合成为驱动一级预防阈值的十年概率——粗糙但正是试验证据与个体相遇的界面、**冠脉钙化评分再分类**（解决临界计算器的解剖真相）之家。现代生物学精炼靶标：**暴露的终身量比末次值更要紧（曲线下面积LDL——孟德尔随机化与他汀及PCSK9随访逻辑）、而炎症是可治的轴（CANTOS的canakinumab与秋水仙碱试验证明白介素-1通路阻断不碰脂质而减事件——[[immunology/innate-immunity]]炎小体的临床着装）。**
:::

::: definition 缺血与慢性冠脉综合征 {#def-ischemia}
心肌氧供应是**舒张期冠脉流受限**（心内膜下、最后灌注而最先受压——内三分之一的脆弱及其ST压低的缺血心电图签名），**冠脉床靠舒张来满足需求（[[cardiovascular/circulation-blood-pressure]]的腺苷介导代谢性充血）**——正常的**血流储备3–4倍**、狭窄在静息血流下降之前把它耗尽：**充血血流在约85–90%直径狭窄时崩塌（练习器四次方算术），而血流储备分数（跨病变压力导丝比、≤0.80为缺血线）与血流储备概念把“显著狭窄”从外观改为功能定义**，化解造影的灰区与解剖对症状的不一致（有非阻塞性冠脉病与微血管功能障碍的心绞痛女性——[[cardiovascular/vascular-disease]]内皮故事的雌激素、高血压与糖尿病底物、一个真实、高负担、少被命名的综合征；及血管痉挛性Prinzmetal变异的短暂ST抬高与激发试验）。需求的决定因素——率、收缩力、**壁张力（Laplace：压力×半径——肥厚与扩张心室额外的氧账单、[[cardiovascular/cardiac-cycle]]心室功能论证应用于供需）**——生成**慢性稳定心绞痛**的表现：中央劳力性或情绪性胸部压榨感、休息或硝酸酯数分钟内缓解、加拿大心血管学会分级给阈值定量（I极度劳力→IV静息）、**糖尿病去神经、年龄与女性表现的不对称型与“以呼吸困难为主”与无痛性缺血**——这些都是预试验概率（现按临床评分、旧的年龄-性别-症状表已让位于解剖优先路径）驱动所选检查的原因：**冠脉CT血管造影（当代路径的解剖一线、带钙化与狭窄报告及其FFR衍生研究臂）或功能检查（腺苷或多巴酚丁胺灌注与室壁运动研究——腺苷试验即[[cardiovascular/circulation-blood-pressure]]冠脉扩张储备原则对狭窄的反用、及敏感度平平的运动心电图如今留给特定预试验窗口）**，侵入造影与血运重建决定跟随症状与缺血负担对照**稳定患者必须先最大化的药物治疗（ISCHEMIA与COURAGE试验的发现：稳定病变中立即血运重建不优于最优药物对死亡与梗死——而改善心绞痛与生活质量、其本身即指征）**。
:::

::: example 登山时的下颌痛 {#ex-stable}
58岁吸烟伴高胆固醇男性，三个月来爬坡时下颌发紧、休息2分钟消失、静息无；查体、心电图与肌钙蛋白正常；LDL 4.4 mmol/L；父亲52岁心梗。
::: solution
**按预试验概率的典型（阻塞性）心绞痛、高危脂谱与家族史**——仅下颌分布是经典的牵涉性心源性痛（T1–T4皮节与迷走传入通路——[[nervous-system/sensory-systems]]），不是不典型故事。路径：**CT血管造影或功能检查记录领地与负担（按本地路径与计算器选择——[[epidemiology-ebm/diagnostic-tests]]的临床概率逻辑应用于胸痛）**，加**不论解剖如何即刻、无条件的二级预防式治疗：高强度他汀与LDL靶值、未达标加依折麦布/PCSK9抑制剂或inclisiran阶梯（LDL与家系提示家族性高胆固醇血症时的级联家系脂筛查[[genetics/mendelian-inheritance]]——LDL受体、apoB或PCSK9功能获得家系）、阿司匹林、风险因子规划（戒烟的可测量事件削减、[[endocrine/diabetes]]与[[cardiovascular/hypertension]]靶标、心脏康复式运动处方）、及β阻滞剂或钙阻滞剂或长效硝酸酯的症状控制与GTN喷剂教育（坐下、5分钟、重复一次、不缓解叫救护车——患者自己的急性冠脉综合征分诊）**。若缺血广泛或症状持续：**造影并按病变与解剖逻辑血运重建（左主干与三支、尤其糖尿病的复杂病变中搭桥的生存数据（SYNTAX与FREEDOM试验家族）胜过介入、单一领地病变则支架加双联抗血小板的介入程序是工具）**。教学点在明处：**正常酶从不排除稳定心绞痛、下颌是心脏症状区、而决定他下一个十年的是那个血脂数字——不是造影。**
:::

## 急性冠脉综合征：分钟、血栓与时间

::: definition 斑块事件与综合征谱 {#def-acs}
急性冠脉综合征是**高危斑块的血栓并发症**——薄帽、大脂核、巨噬与肥大细胞激活、点状钙化与正性重塑（脆弱斑块特征、只有少数最终发生梗死、且多位于非阻塞角度：解释为什么人群他汀-风险策略胜过追捕高危病变的流行病学）——**破裂或侵蚀暴露组织因子与胶原、血小板黏附（von Willebrand与GPIb、GPVI）与凝血酶爆发产生以动脉为主的“白血栓”**：完全闭塞成**STEMI**（透壁损伤：ST抬高、[[cardiovascular/electrophysiology-ecg]]的Q波演变、闭塞动脉与领地）、不完全或间歇闭塞伴远端栓塞成**NSTEMI/不稳定心绞痛**（心内膜下：ST压低与T倒置、肌钙蛋白阳或阴——第四统一定义的99百分位加变化规则与高敏检测的快速规则入/出流程、[[epidemiology-ebm/diagnostic-tests]]与[[clinical-skills/laboratory-tests]]的分析故事）。**2型缺血**（供需失配——脓毒症、出血、快速性心律失常与贫血患者的肌钙蛋白升高）与**MINOCA**（非阻塞冠脉心肌梗死——痉挛、栓塞、自发性冠脉撕裂的年轻女性、[[physiology/autonomic-nervous-system]]的儿茶酚胺心肌顿抑Takotsubo）是导管室守住的鉴别、而**正在上升的肌钙蛋白是心肌损伤、不自动等于冠脉血栓**——这条区分把脓毒患者从无谓肝素下、把冠层撕裂患者从错误支架下救出。STEMI的治疗是**动脉：网络分钟预算内的直接PCI（症状起始与诊断至导丝目标、转运试验逻辑）、或PCI不可及时的溶栓（纤维特异药加抗凝及年龄血压调整剂量）配药物有创转运；NSTEMI的是风险评分定时机（GRACE评分的极高/高/中危层决定2小时至72小时至择期造影、抗血小板加抗凝负荷相同、及脆弱、低危与非冠脉损伤患者保守路径的位置）**（[[emergency-critical-care/acute-assessment]]、[[emergency-critical-care/resuscitation]]）。
:::

::: theorem 时间就是心肌、而心肌是重塑 {#thm-remodel}
梗死面积随缺血时间与侧支供应缩放（[[respiratory/gas-exchange]]扩散类比的Krogh毛细血管张力与分水岭心内膜下逻辑：坏死波前约6小时内心内膜向心外膜推进）；被救回的心肌可收缩（顿抑）、长期灌注不足则冬眠——血运重建后功能恢复。幸存残存心肌随后经历神经激素重塑。
::: proof
**波前现象**（Reimer与Jennings的缺血级联实验：20分钟可逆损伤边界、[[cell-biochemistry/membranes-transport]]相邻章节的ATP与膜泵衰竭、及ATP耗竭到坏死的梯度）加**侧支竞争**（腺苷试验反用的供体动脉窃取生理）给出梗死面积算术——而再灌注添上自己的生物学（再灌注氧悖论的钙与活性氧损伤、微血管栓塞与水肿的无复流、及回收却顿抑的收缩状态、其钙处理恢复需数日至数周——[[physiology/muscle]]兴奋-收缩机器重启）。**重塑一半是[[cardiovascular/circulation-blood-pressure]]与[[cardiovascular/heart-failure]]的RAAS-交感故事**：梗死扩展与扩张、Laplace壁张力螺旋、离心性肥厚与功能性二尖瓣反流（[[cardiovascular/valve-congenital-disease]]）、室壁瘤及其壁栓与体循环栓塞（[[blood/thrombosis-anticoagulation]]）、及作为晚期猝死最常见底物的梗死周折返环——每一步是一类药的指征：**ACE/ARB、β阻滞剂、醛固酮拮抗剂、SGLT2抑制剂与他汀的心梗后处方是重塑的二级预防、不是装饰、而6–12周的射血分数复查决定一级预防除颤器（等重塑宣示自己的40天与90天试验规则——[[cardiovascular/arrhythmias]]）。**
:::
:::

::: example 不典型的七天 {#ex-nstemi}
81岁因房颤服阿哌沙班的女性，乏力纳差三天就诊；肌钙蛋白3→140 ng/L、心电图侧壁ST压低、血红蛋白82、病房中出现黑便。
::: solution
**NSTEMI（1型对2型——本例活在这个岔口）在高出血风险、抗凝、贫血的患者。**推理序列：(1)**肌钙蛋白升高是缺血性损伤还是需求？**贫血与任何脓毒症或心律失常驱动2型——把2型当1型治（肝素、双联抗血小板）在一个出血的81岁患者身上正是医源伤害的发生方式（[[clinical-skills/patient-safety]]药物伤害查房）；然而ST压低加症状提示冠脉成分、走GRACE评分路径。(2)**先停伤害：黑便是优先——复苏、输到心脏症状窗口（[[blood/transfusion]]限制对宽松的试验算术及其MINT心梗子试验的细微）、停阿哌沙班、仅危及生命的出血才逆转、急诊内镜配心内-消化联合规划（[[gastrointestinal/gi-bleeding-cancer]]）。**(3)**冠脉决定按合并的风险评分（GRACE缺血对CRUSADE/出血风险）、只在止血允许后早侵入、造影可能显示需求病变（旧的中等狭窄无血栓——生理而非斑块破裂）或闭塞的回旋支（侧壁ST压低领地 惯常嫌疑、真正需要抗栓策略的1型）。**(4)**长期答案：房颤卒中风险对再出血风险、左心耳封堵器是否入计划；贫血的铁与肿瘤检查；及老年衰弱目标谈话（[[geriatrics-palliative/polypharmacy]]）**。NSTEMI管理于是是本章伦理与生理的病例：**同一张心电图与一个不同的出血胃指向相反的下一个小时。**
:::
:::

::: example 第三夜的杂音 {#ex-mechanical}
下壁心梗溶栓（晚就诊者）后第3天，66岁患者突然气促低血压；心尖新发全收缩期杂音传至腋部、胸片肺水肿、颈静脉升高伴大v波。
::: solution
**后内侧乳头肌断裂伴急性重度二尖瓣反流**——机械并发症时钟的经典条目（第1–5天、[[pathology/cell-injury]]修复时间表的凝固性坏死软化峰、下壁心梗乳头肌的单动脉供血——[[anatomy/thorax]]冠脉、延迟再灌注与首诊与女性与高龄危险因素）。生理解释体征：**大小正常而不顺应、在体循环压力下接收反流射流左房（[[cardiovascular/cardiac-cycle]]颈静脉/楔压讨论的大v波——此处读在楔压曲线上）、无心脏扩大的巨大房压性肺水肿、冒充“心源性休克”的低前向输出、及房室压均衡时可能错觉性地柔和的杂音**。诊断与管理并行：**超声（连枷瓣叶与偏心射流、经胸然后经食道）、作为外科地图的急诊CT与造影、机械支持（主动脉内球囊的舒张期冠脉加降后负荷逻辑与现代经皮器械）及正性肌力与升压平衡下的降后负荷、急诊手术（修复对置换——指南的心源性休克与机械并发症急诊、使转运谈话诚实的死亡率数字）、团队与不适用者的姑息替代（机械并发症的未幸存者占很大比例、这也必须说）**。同一时钟携带的同胞清单：**室间隔破裂（伴阶梯与休克的全收缩期杂音）、游离壁破裂（填塞与无脉电活动死亡）、真室壁瘤较晚的壁栓与心律失常与衰竭**——考试的“第3天、新杂音、休克”在影像说话前是这三个之一（[[cardiovascular/heart-failure]]）。
:::

::: example 产后撕裂 {#ex-scad}
33岁、顺利分娩后六周，凌晨压榨性胸痛醒来；心电图前壁ST抬高、肌钙蛋白上升、无血管危险因素、BMI正常。
::: solution
**启动直接血管成形——并在导管室预期自发性冠脉动脉夹层（SCAD）直到造影另有说法**：年轻产后STEMI原型（围产期激素与血流动力学动脉壁改变、肌纤维发育不良与结缔组织关联、多产与子痫前期史——[[obstetrics-gynaecology/postnatal-period]]与[[cardiovascular/vascular-disease]]）。区分为何改变管理：**SCAD中导丝与球囊是对脆弱内膜的武器——默认保守（多数夹层动脉自愈）、PCI或搭桥留给持续缺血、左主延伸或不稳定；在导管室前给的溶栓是危害不是治愈；双联抗血小板、β阻滞（复发削减信号）与监测造影构成药物治疗程序、随之的妊娠与激素避孕咨询及肌纤维发育不良与动脉筛查（头盆CT血管造影搜寻并存动脉瘤）。**[[#def-acs]]的MINOCA清单鉴别分支走在同一冠脉上：**Takotsubo（心尖球囊、情绪扳机、干净冠脉）、冠脉栓塞（围产期心肌病[[cardiovascular/heart-failure]]的血栓、瓣膜与[[cardiovascular/valve-congenital-disease]]分流的反常路径）、及罕见高Lp(a)年轻患者的真斑块破裂STEMI（[[#def-athero]]）**——一张心电图、四种疾病、导管室仲裁。
:::

他汀（降脂一般如此——PCSK9抑制剂与依折麦布结局试验追踪毫摩尔数、但影像生物学共享）**减少斑块巨噬与脂质内容并改善内皮功能、造出更厚更稳定的帽——加上急性期“多效”内皮与抗炎效应、而CANTOS式炎症轴现已单独证明可药（[[#def-athero]]）**。它们既不设定心跳也不放支架；这一点临床要紧是因为斑块稳定数周内开始（不稳定患者他汀负荷试验）、解释事件在脂检回应完成前就下降、并与秋水仙碱及抗炎试验结果并列为本领域第二治疗轴。
:::
:::

::: history
这一疾病的概念随**Heberden与Parr**18世纪的胸痛分类学、**Parry**的尸体解剖冠脉、及**Herrick**1910年使心梗成为医学诊断的冠脉血栓论文而出现；世纪中叶的三重奏——**Master**的运动试验与**Framingham心脏研究**（风险因子概念本身）及Keys的饮食-胆固醇之旅与七国研究的流行病学革命——把听天由命的“冠脉闭塞”变成可改的病。**DeBakey**的内膜剥脱时代、**Sones与Judkins**的造影导管技术、**Dotter**的首例血管成形、**Grüntzig**1977年的球囊与支架时代（Palmaz、Sigwart）及药物洗脱改良、和**Furchgott**的内皮一氧化氮（1980年的发现把动脉重构为一个器官及本章的硝酸酯-腺苷生理）造出工具；**溶栓时代（ISIS与GISSI试验、链激酶与组织型纤溶酶原激活剂网络、继而直接PCI试验综合）、Braunwald的不稳定心绞痛与NSTEMI框架、及再灌注生物学实验室（Jennings与Reimer的波前及Yellon与Hausenloy的再灌注标志时代）**把本章变成时间关键的系统；而**胆固醇假说的终局（1990年代起的他汀试验、法国家系的PCSK9发现与[[genetics/mendelian-inheritance]]的LDL受体遗传学及evolocumab与FOURIER试验）及CANTOS/秋水仙碱的炎症证明**完成了本章教的三轴治疗——脂质、血栓、炎症。
:::

## 通向何处

上游的力学生物学在[[pathology/haemodynamics]]与[[physiology/membrane-potentials]]，细胞生物学在[[pathology/cell-injury]]与[[pathology/cancer-biology]]；脂蛋白遗传学与风险架构在[[genetics/mendelian-inheritance]]与[[genetics/common-disease-genetics]]；炎症轴在[[immunology/innate-immunity]]；心电图判读在[[cardiovascular/electrophysiology-ecg]]；力与音在[[cardiovascular/cardiac-cycle]]；再灌注损伤与侧支循环与所有器官的缺血再灌注及移植的[[surgery/perioperative-care]]故事共享。二级预防药物在[[pharmacology/drug-receptor]]的[[pharmacology/dosing-principles]]；急症的处置室算术在[[emergency-critical-care/acute-assessment]]；心衰结局在[[cardiovascular/heart-failure]]；介入的冠脉解剖在[[anatomy/thorax]]与[[clinical-skills/medical-imaging]]。

::: summary
- 冠心病是滞留脂蛋白的数十年回应，剂量变量是LDL、Lp(a)、血糖、血压与吸烟；风险计算器把暴露转为概率、而钙化评分以解剖真相重新分类。
- 缺血是供需资产负债表：充血时血流在约85–90%狭窄崩塌、FFR给生理而非外观的定义、慢性综合征靠最大药物治疗、症状与缺血负担决定是否加血运重建。
- 急性冠脉综合征是斑块的血栓并发症：STEMI以分钟救动脉（PCI对溶栓），NSTEMI以GRACE定时机、而2型缺血与MINOCA是必须用升高的肌钙蛋白做的鉴别。
- 梗死面积是时间的函数、而幸存心肌重塑——心梗后处方（ACE、β、醛固酮、SGLT2、他汀）是对重塑的二级预防、机械并发症时钟在第1–5天有致命签名。
:::

## 练习

::: exercise 解释血流储备 {level=1}
70%狭窄只在上坡跑步时心绞痛、走路不。用本章双曲线生理、并命名两个不改狭窄而降低心绞痛阈值的条件。
::: solution
静息时微循环只部分舒张而储备尚存；充血（上坡跑）要求3–4倍血流、狭窄的固定阻力加已征用的血管舒张在其崩塌点以下无法给出——缺血恰好出现在[[#def-ischemia]]/练习器曲线的陡区、而**狭窄只在总阻力（病变加最大程度舒张的床）超过供应能力时才限流**。降阈值条件：**贫血与缺氧（含量少——Fick供应项、[[physiology/integrative-physiology]]）、快速性心律失常与高血压（需求高、舒张灌注时间/压力低）、血管收缩（寒冷、吸烟、可卡因——痉挛加需求的组合）、及左室肥厚或主动脉瓣狭窄（[[cardiovascular/valve-congenital-disease]]的Laplace与挤压罚——冠脉正常心绞痛最常见解释）。**临床上是为什么“比平时更重的心绞痛”促使复查整个患者、而不只动脉（[[cardiovascular/electrophysiology-ecg]]的需求性缺血肌钙蛋白升高属同一算术）。
:::
:::

::: exercise 解读FFR {level=1}
LAD病变造影看似70%；腺苷充血时远端血流储备分数读0.74；支架后读0.96。解释两个数字、及为什么目测不可信。
::: solution
FFR=**最大充血时（远端压−充盈偏移）/主动脉压≈病变允许的最大血流分数**——0.74低于≤0.80缺血线、故病变功能显著、值得支架（腺苷输注是与灌注影像负荷药相同的冠脉扩张储备药理——[[#def-ischemia]]）；支架后0.96记录生理成功。目测失败是因为**造影是腔影——随投照体位、对动脉粥样硬化重塑盲目（[[pathology/haemodynamics]]的Glagov外向扩张使管腔在斑块成为负担前正常）、对弥漫病变盲目（无正常参考段）、且不生理（画面里没有血流也没有需求）**——故生理优先实践与钙化评分及CT-FFR影像章的类比论证（[[clinical-skills/medical-imaging]]）。
:::
:::

::: exercise 肌钙蛋白岔路 {level=2}
给出无急性冠脉血栓的肌钙蛋白升高四个机制、及在真实病房患者把各自与1型NSTEMI分开的两个心电图加病史线索。
::: solution
**2型需求性缺血**（脓毒症、肺栓塞、快速性心律失常、高血压危象、贫血）——发热与感染源与缺氧及无领地的ST图形；**心肌炎与Takotsubo**——青中年的病毒前驱或情绪扳机、弥散ST-T改变与心尖球囊、[[#def-acs]]MINOCA清单的干净冠脉；**心衰与心肌应变**——伴临床淤血的慢性升高与平坦的系列变化；**肾衰竭**——基线稳定的高敏值慢性升高（变化规则全部目的——99百分位加升降、[[clinical-skills/laboratory-tests]]）；加上消融/电复律、挫伤、横纹肌溶解邻近的检测问题与危重病。凌晨3点要紧的判别：**冠脉领地的动态ST-T改变（1型）对随疾病进程上升的需求背景、及系列变化形态（事件的升降对平台）**；管理跟随岔路——2型治基础病并降级抗栓、1型评分并启动（[[emergency-critical-care/acute-assessment]]、[[infectious-diseases/fever-sepsis]]）。
:::
:::

::: exercise 抗血小板算术 {level=2}
服阿司匹林与氯吡格雷的药物洗脱支架患者，支架后第21天因出血性憩室炎需急诊手术。陈述你在平衡的风险与指南形状折中。
::: solution
**支架血栓（一个致血栓的聚合物与支架丝表面——其内皮化成需数月；头数周最高、骤停后最糟——灾难性、常致命的闭塞）对双联抗血小板下的外科与麻醉出血**（P2Y12的不可逆血小板阻断——[[blood/haemostasis-bleeding]]血小板药理）。折中：**尽可能全程续用阿司匹林、把择期手术推迟到最短双联窗口（现代代次支架指南可缩短的窗口——高出血风险患者短至1–3个月、旧指南6–12；第21天在危险区内）、急诊手术在单用阿司匹林下进行并输血小板与强化局部及外科止血（P2Y12晚在则血小板用处下降——时机警诫）、止血一允许即重启P2Y12（以天、而非周为志向）、并在决定之前（而非之后）请介入心内会诊**——[[blood/thrombosis-anticoagulation]]的肝素桥接逻辑只适用于抗凝药、绝不当抗血小板替用品（经典考试陷阱）。
:::

::: exercise Prinzmetal的课 {level=2}
38岁吸烟者反复凌晨4点胸痛伴一过性ST抬高、造影正常、肌钙蛋白两次阴性；除戒烟外，命名机制、诊断激发选项、治疗及需谨慎的一个药物类别。
::: solution
**冠脉血管痉挛（Prinzmetal/变异性心绞痛；吸烟的Rho激酶与NO降解生物学的内皮功能障碍加平滑肌高反应性、昼夜及寒冷及曲普坦及麦角及可卡因及5-FU/卡培他滨化疗扳机）**——同时是一个MINOCA与一个冠脉正常缺血的原因（[[#def-acs]]）。诊断：**疼痛时捕捉ST、及诊断有后果时导管室内冠脉内乙酰胆碱或麦角新碱激发**。治疗：**大剂量二氢吡啶钙通道阻滞剂（氨氯地平/地尔硫䓬骨架——平滑肌松弛药理）加长效硝酸酯与谨慎的尼古丁替代；痉挛受控后结局通常好**。谨慎类别：**非选择性β阻滞剂（普萘洛尔的α无对抗血管收缩与β₂介导冠脉扩张的丧失）可加重痉挛——与嗜铬细胞瘤药物规则同一无对抗α生理（[[physiology/autonomic-nervous-system]]）；而麦角与曲普坦与可卡因回避不言自明**。教学：正常造影不结束胸痛鉴别、而[[cardiovascular/circulation-blood-pressure]]内皮是靶器官药（[[cardiovascular/vascular-disease]]）。
:::

::: exercise 猝死预防 {level=2}
命名心梗后心脏猝死风险的三个决定点及各自导向（射血分数、时机规则、及QRS/束支之问）。
::: solution
**(1) 心梗后40天/3个月及血运重建后的射血分数（40天与90天试验窗——重塑必须先宣示自己、埋藏式心律转复除颤器的一级预防获益才受评：优化治疗下EF≤35%伴NYHA II–III——MADIT-II与SCD-HeFT家族）；(2) 晕厥与心律失常发现（不在急性心梗窗内的自发室速或室颤=二级预防、即刻器械之问——[[cardiovascular/arrhythmias]]）；(3) 电底物标志——非持续性室速加程序刺激可诱发性（MUSTT逻辑）及[[cardiovascular/electrophysiology-ecg]]的QRS负担与早期复极及Brugada图形。**完整答案加**β阻滞剂与醛固酮与盐皮质激素及可穿戴器械的过渡桥、宽QRS不同步共存时的再同步化之问（[[cardiovascular/heart-failure]]）、及家系谈话（缺血底物不需基因检查、但年轻的不明病例重启通道病之问——[[genetics/non-mendelian-inheritance ]]）**。
:::

::: exercise 冠脉干净却心绞痛的女性 {level=2}
61岁糖尿病女性典型劳力性心绞痛、缺血负荷试验、冠脉造影正常。命名综合征、机制、两个诊断工具、及当前循证治疗靶点。
::: solution
**非阻塞冠脉缺血（INOCA）、微血管心绞痛表型（“冠脉正常心绞痛”人群中约一半是微血管功能障碍——冠脉血流储备受损、充血阻力与血管痉挛成分；[[#def-athero]]与[[cardiovascular/vascular-disease]]的糖尿病、高血压、雌激素丧失与内皮风险底物）。**机制：**微血管收缩与稀少及代谢性舒张受损（腺苷通路的终末器官臂——[[cardiovascular/circulation-blood-pressure]]）产生真缺血、真事件（患者射血分数保留心衰与梗死风险升高）与被轻视的症状**。工具：**冠脉血流储备与微循环阻力指数导丝研究、及心脏磁共振心肌血流标测（从研究到临床的定量灌注）、PET血流储备是经典参考标准**。治疗：**强力风险改造（他汀、血压、血糖——内皮NO规划、[[endocrine/diabetes]]的SGLT2与GLP1类别新出现心肾证据）、抗心绞痛药（β阻滞剂、钙阻滞剂——注意痉挛重叠的谨慎、曲美他嗪与尼可地尔及丙咪嗪的神经调制角色、雷诺嗪数据）、及认真对待症状轨迹的随访**。教学：**造影回答“哪条动脉”、从不回答“哪块组织在挨饿”——本章供需生理才是疾病、狭窄只是其最常见原因（[[clinical-skills/clinical-reasoning]]双过程谨慎）。**
:::

::: exercise 设计二级预防包 {level=3}
55岁药物洗脱支架的非复杂STEMI后出院规划。为每个成分带生理论证构建完整预防包、随访时机、及包省略而应含的两个谈话。
::: solution
**抗血小板：双联（阿司匹林加P2Y12——替格瑞洛/普拉格雷对氯吡格雷按缺血与出血风险选择——指南窗口及降阶与出血调整策略、随后终身单阿司匹林）——支架的[[#ex-nstemi]]对血栓算术。脂质：即刻高强度他汀（[[#def-acs]]测验的不稳定斑块稳定）配LDL靶值与依折麦布/PCSK9/inclisiran升级、及LDL与家系吻合时的家族性高胆固醇血症与家系筛查决定（[[genetics/mendelian-inheritance]]）。神经激素：ACE/ARB（重塑预防——[[#thm-remodel]]、配[[cardiovascular/hypertension]]靶值）、β阻滞剂（需求削减、抗重塑、抗心律失常三重直到EF之问解决）、EF与糖尿病指征的醛固酮拮抗剂（EPHESUS/RALES逻辑）。糖与心：糖尿病或其边界处的SGLT2抑制剂与二甲双胍架构（[[endocrine/diabetes]]）。生活方式与康复：运动心脏康复规划（事件削减与生活质量数据——[[public-health/prevention-promotion]]）、药物辅助戒烟、饮食与酒精与疫苗与驾驶与工作证明（属会诊而非药典的驾照与职业规则）。随访：6–12周EF复查（上一练习的器械决定）、支架与抗血小板门诊及药物核对与依从复查。两个省略的谈话：**伴侣与家系风险算术（共享行为与共享遗传的风险——筛查并治疗的家会）及意义谈话——患者对下一次疼痛的恐惧、性生活与焦虑抑郁筛查（心梗后抑郁的双重事件风险）、及“如果下一次很大怎么办”的问题记录在何处（[[clinical-skills/communication]]）。**
