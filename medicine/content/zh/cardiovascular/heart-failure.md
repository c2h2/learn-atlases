心衰是心脏辜负其两项工作的综合征——产生输出、并在不过度充盈压下接受回流——及其两张临床面孔：**淤血与低灌注**。现代概念（第四统一定义及ESC与ACC/AHA指南的架构）分三层：**分期**（A–D、从风险到难治、基本不可逆地向前的）、**按射血分数的表型**（降低、轻度降低、保留——部分是测量约定、大部分是真正的病理生理想象线）、及**病因**（缺血、高血压、瓣膜、毒物、遗传、浸润、炎症、围产——最改变管理而最常无人回答的问题）。表型四周是**神经激素-机械螺旋**——[[cardiovascular/circulation-blood-pressure]]的机体自身代偿变成疾病引擎——及打断它的四支柱药理、成人医学把生理转化为死亡率获益最成功的一次翻译。

本章讲述衰竭泵病理生理、临床综合征及其诊断、四支柱与减容技艺、及弧线的先进与姑息两端。

## 螺旋：从分子到综合征

::: definition 衰竭心室及其适应 {#def-spiral}
任何杀死心肌细胞的病因（梗死——[[cardiovascular/coronary-artery-disease]]）、压负荷（主动脉瓣狭窄、高血压）、量负荷（反流、分流、贫血与肥胖的高输出需求）、毒害收缩（酒精、[[pharmacology/adverse-reactions]]相邻肿瘤学的蒽环与曲妥珠、可卡因）、浸润（淀粉样——[[blood/lymphoma-myeloma]]的AL与老年人及被低估的ATTR、铁、结节病）、炎症（病毒与巨细胞心肌炎）或突变肌小节（扩张与肥厚型心肌病的遗传学——[[genetics/mendelian-inheritance]]与[[cardiovascular/valve-congenital-disease]]的HCM讨论）都终结于同一细胞生理：**兴奋-收缩偶联破坏（[[physiology/muscle]]钙处理失效——SERCA下调、渗漏的ryanodine受体、缓慢的钠钙交换）、能量学受损（衰竭心的底物转换与ATP转运衰竭——[[cell-biochemistry/energy-metabolism]]赤字的记账）、细胞骨架与细胞外基质重塑（胶原与僵硬）、及心肌细胞死亡与胚胎基因重编程（[[cell-biochemistry/signalling-cell-cycle]]与[[genetics/genomic-medicine]]应激肥厚程序）**。全器官反应是螺旋：**射血下降与容量上升→壁应力（又是Laplace——半径生半径）→压力感受器卸负荷的交感浪潮、肾素-血管紧张素-醛固酮激活及血管加压素与利钠肽的反调节→钠水潴留与小动脉收缩在牺牲充盈压（淤血）与后负荷（更多衰竭）的代价下恢复压力、而醛固酮与儿茶酚胺重塑心肌、肾与血管（纤维化、低钾与心律失常环境）→Frank-Starling曲线被压平并下降（练习器）、EDPVR变陡（正常容量即淤血）、心室变球形与二尖瓣环扩张（功能性反流——自生之环、[[cardiovascular/cardiac-cycle]]的PV环疾病）**。**利钠肽（BNP与NT-proBNP——心肌壁应力激素、诊断生物标志物、及脑啡肽酶及其抑制剂沙库巴曲保护的肽）**是此螺旋的生化影子：有用的数字带自己的混淆因素（降低它的肥胖、升高它的年龄、肾功能损害、房颤与肺高压——锻炼成的推理）。
:::

::: definition 四个表型、四个同名疾病 {#def-phenotypes}
**HFrEF**（射血分数降低、≤40%）：低输出、扩张、神经激素炽热的表型、带[[#def-treatment]]死亡率证实的四联治疗。**HFpEF**（≥50%）：**僵硬、增厚、年龄与高血压与肥胖与房颤与女性的表型**——腔室（与全身）顺应性疾病：[[cardiovascular/cardiac-cycle]]陡的EDPVR意味着小容量转移造大压力摆动（闪性水肿生理、射血分数“看似正常”时运动充盈压飙升的劳力性呼吸困难）、底物是冠脉微血管炎症（全身共病范式）、titin与胶原僵硬、房室依赖与变时功能不全——**其试验（ARB、醛固酮与脑啡肽酶阻断对死亡证明中性）出名地失败、而首批获益信号来自代谢药：SGLT2抑制剂与GLP-1激动剂及减重试验（STEP-HFpEF规划——独立于体重的肥胖表型改善）**（[[endocrine/diabetes]]）。**HFmrEF**（41–49%）行为足够像降低侧而应得多数其药；**恢复中与已恢复的射血分数**（心肌炎性、takotsubo、围产与心动过速介导心肌病）要求反向推理——限时的治疗撤除决定而非终身升级（[[cardiovascular/coronary-artery-disease]]顿抑心肌、[[obstetrics-gynaecology/postnatal-period]]围产心肌病）。最后是**分期轴（ACC/AHA A–D）**：A（风险、无病——治高血压与糖尿病）、B（结构或肽、无症状——化疗前心脏肿瘤学与心梗后重塑门诊）、C（有症状——医院的人群）、D（难治——[[#def-advanced]]的先进治疗与姑息谈话）、这是**指南把心脏病学变成预防规划的方式**、及心衰是从未被诊断者最常见出院诊断的原因。
:::

::: example 湿的与冷的 {#ex-acute}
72岁患者被送来时喘憋、粉红泡沫痰、血压186/100、空气下氧饱和78%、湿啰音遍布至肺底、S3、颈静脉压到下颌角；心电图窦速与陈旧下壁Q波。
::: solution
**急性肺水肿、“暖而湿”（灌注好、淤血）高血压闪性水肿——治疗是把[[cardiovascular/circulation-blood-pressure]]与[[cardiovascular/cardiac-cycle]]讲座压缩进一小时急性失代偿。**生理：僵硬或衰竭的心室面对后负荷浪潮（交感血管收缩、常伴肾钠潴留与漏服或NSAID或缺血或心律失常扳机）→楔压飙升→Starling毛细血管衰竭（[[cardiovascular/circulation-blood-pressure]]方程倒转、血浆入肺泡）→缺氧与呼吸功→更多交感浪潮——要尽可能多点快速打断这个环：**氧与无创通气（CPAP/BiPAP——肺泡开放、及优雅地经胸内压升高减轻前与后负荷——[[respiratory/mechanics-breathing]]压力做血流动力学功）、硝酸酯舌下然后静脉（静脉容量库填充——Guyton的应激容量移出循环中枢腔、较高剂量加小动脉降后负荷）、静脉袢利尿剂（呋塞米双重效应——利钠前的早期静脉扩张即[[renal/tubular-function]]袢利尿剂药理——及剂量逻辑：家用剂量×2.5规则、2小时尿量作滴定指标、及噻嗪增强到美托拉宗及终极超滤的抵抗性淤血升级）、治病因清单（心电图与肌钙蛋白查缺血、心律失常、脓毒症、主动脉与二尖瓣病变、药物史）、及回避清单：吗啡（伤害信号）、无通气支持的常规氧、易休克液体转移中起始或续用的β阻滞剂、及给186血压的液体冲击**。体位、监护、为无反应者的导管与超声规划、及永不重复入院的出院处方：[[#def-treatment]]四支柱、每日体重与盐与液体的架构、心脏团队随访——**再入院曲线是每个急性心衰小时的真实终点。**
:::

## 识别并标记综合征

::: definition 诊断：症状、体征、肽、腔室 {#def-diagnosis}
没有单一检查能确诊：**预试验推理（修订心衰临床评分及其在基层医疗的差判别力、那里症状——劳力性呼吸困难、乏力、踝肿——是肥胖、去适应、贫血与肺病者最常见主诉）**驱动现代算法：**利钠肽看门人（高敏感度、有用排除；[[#def-spiral]]的混淆因素与开单前先读实验室参考阈值——[[clinical-skills/laboratory-tests]]、[[epidemiology-ebm/diagnostic-tests]]）、继而超声心动作为仲裁（射血分数、舒张参数与E/e′充盈压估计、瓣膜与室壁与心包评估——追病因的研究）、配胸片（心脏扩大、头向分布、Kerley线与积液是Starling方程的X线版）、心电图（兼作治疗靶点的心律失常与梗死与左束支信号）、及病因组套（缺血影像、铁与淀粉样与甲状腺与酒精与药物史、睡眠研究、及扩张或肥厚或致心律失常表型要求时的遗传谈话——[[genetics/genomic-medicine]]级联筛查）**。**床旁仍是分期工具**：升高的颈静脉压（伴肝颈回流与腹颈反射——[[cardiovascular/cardiac-cycle]]右侧检查及其Kussmaul与填塞变异）、第三心音（扩张心室快速充盈的晃动——特异而不敏感）、移位而高动力或安静的心尖、搏动性肝、下垂与骶部水肿、中枢性睡眠呼吸暂停的潮式呼吸（[[respiratory/control-breathing-tests]]）、及低输出状态的窄脉压冷外周；**右心导管**为不确定的充盈压、心源性对休克之问、移植与左室辅助装置检查及肺高压表型分类（[[respiratory/interstitial-vascular-disease]]的毛细血管后对前的算术）保留其角色。心脏磁共振完成组织诊断（心肌炎、梗死与浸润的水肿与延迟钆增强图形——[[clinical-skills/medical-imaging]]）。
:::

::: example 射血分数“正常”的气促祖母 {#ex-hfpef}
80岁（BMI 36、高血压、永久性房颤、两次因“胸部感染”入院）NT-proBNP 1,400、射血分数62%、左房显著扩大、E/e′ 17；腿与骶部肿胀、爬不了一层楼。
::: solution
**伴淤血的HFpEF——只靠射血分数会一直漏掉的诊断。**生理读出本例：**高血压、高龄、肥胖、房颤心室伴陡EDPVR（普通容量即淤血——[[#def-phenotypes]]段）、房颤的心房助推丧失与率相关的舒张期缩短（充盈时间与[[cardiovascular/cardiac-cycle]]心房贡献算术——每次心动过速都失代偿）、及原是肺静脉高压与积液的“胸部感染”**。诊断纪律：**排除模仿者与贡献者（贫血、甲状腺、肾钠潴留、肺高压的毛细血管前份额、主动脉瓣狭窄、OSA、去适应与肥胖力学）、确证舒张生理（E/e′与左房容量与TR流速、静息检查模棱时的运动或负荷超声或导管血流动力学——HFpEF文献的全部抱怨）**、然后治可治的：**SGLT2抑制剂（使其成为该表型类别首选的症状、首次住院与心血管死亡获益、及肥胖表型的GLP-1与体重规划、配滴定到体重与骶部检查——而非踝部——的利尿剂）、率控制与节律策略考量（房颤消融在HF试验的信号：窦性心律在该表型可能比β阻滞的控率教条更重要——[[cardiovascular/arrhythmias]]）、血压与心率架构、及运动/康复转诊（呼吸困难的骨骼肌与外周氧摄取成分——运动生理文献“伴骨骼肌肌病的心衰”脚注——[[physiology/integrative-physiology]]）。**教学句：**射血分数是关于收缩率的数字；这位女士的病关于舒张、容量与共病、而其管理必须关于这三样。**
:::

::: definition 四支柱与减容阶梯 {#def-treatment}
慢性HFrEF治疗如今是**四类降死亡降住院的类别在诊断后数周内起始、而非数年依次滴定到耐受**：**(1) 肾素-血管紧张素系统阻断、最好以血管紧张素受体-脑啡肽酶抑制剂沙库巴曲/缬沙坦（[[#def-spiral]]的利钠肽增强概念成药——PARADIGM试验对雷米普利至上及36小时ACE抑制剂洗脱规则）、不耐受或负担不起时ACE/ARB；(2) 循证β阻滞（比索洛尔、卡维地洛、缓释美托洛尔、旧高血压变通用尼比洛尔——交感毒性逆转、其早期负性肌力意味着低起始、减容后且脱离正性肌力药、每周翻倍；机制的优雅：率、需求、抗心律失常及[[cardiovascular/coronary-artery-disease]]定理式的逆重塑）；(3) 盐皮质激素受体拮抗剂（醛固酮-纤维化轴、监测钾与肌酐——[[renal/potassium-calcium-phosphate]]）；及4) SGLT2抑制剂（渗透性利尿利钠、心肾代谢药、其跨表型跨病因的获益仍超出已被彻底研究的机制——[[renal/filtration]]管球反馈与钠处理及能量学假说、及其生殖泌尿感染与罕见正常血糖酮症警诫、[[endocrine/diabetes]]）。** 骨架上挂着**症状与淤血的袢利尿剂（发病与舒适、非死亡——24小时尿与体重的剂量指标）、按表型的加入（黑人人群及ACE不相容及妊娠安全格位的肼苯达嗪-硝酸异山梨酯——[[obstetrics-gynaecology/pregnancy-complications]]；率特征患者的伊伐布雷定；症状与住院削减的地高辛、其窄治疗窗与其[[physiology/muscle]]收缩力机制及肾与钾敏感性；维立西呱与铁输注用于缺铁与近期失代偿者）、器械（[[cardiovascular/coronary-artery-disease]]猝死规则的EF≤35与更差预后算术的ICD、左束支与宽QRS不同步、其机制是[[cardiovascular/electrophysiology-ecg]]间隔到侧壁收缩延迟的治疗化、传导系统起搏时代的改良、及住在其试验格位的房分流与压力感受器装置与三尖瓣夹）、及病因特异治愈（血运重建的缺血心室、夹或换的瓣膜、停掉的酒精、放血或螯合的血色沉着症、分型而治的淀粉样、消融的介导性房颤、心肌炎的免疫抑制、家族性心肌病的遗传门诊）。**
:::

::: example 心脏扩大的年轻人 {#ex-dcm}
34岁患者6周乏力与端坐呼吸就诊；超声示6.5 cm扩张左室伴射血分数15%、功能性二尖瓣反流、冠脉造影正常；他“几乎每天几品脱”喝酒、不吃药；父亲44岁猝死。
::: solution
**新发扩张型心肌病（DCM）——本例是检查与家系、不只是处方。**即刻处理是减容加谨慎引入四支柱（若血压限制滴定、低输出患者可能需要[[#def-advanced]]的正性肌力与先进治疗评估）、加**能改变一切的病因搜寻：诚实量化的饮酒史（少数中的毒-可逆病因、戒断后常跟显著逆重塑——[[#def-phenotypes]]的恢复中射血分数类别）、病毒与免疫史及心脏磁共振组织图形、血色沉着症铁检查及甲状腺与HIV与恰加斯与围产及检查点抑制剂之问、兴奋剂与可卡因与合成类固醇及化疗暴露清单、睡眠与家系图、及基因组合**titin截断与lamin与桥粒与lamin A/C及其他DCM/LVNC基因、其识别意味着：**心律失常风险可超过EF的表面安稳（lamin与桥粒的心律失常先发型心肌病早早进入除颤器谈话——[[cardiovascular/arrhythmias]]）、而级联家系筛查是预防医学（[[genetics/genomic-medicine]]与[[genetics/mendelian-inheritance]]的家系工具）。**父亲44岁猝死也使基因结果成为医学伦理教学病例（成人风险者的预测检测讨论、伴侣的筛查选择、及驾驶与运动咨询）、而心衰团队的先进治疗与移植上名（[[#def-advanced]]的机械支持桥接与终点逻辑）在支柱与戒断未在3-6个月重塑时钟内逆转他时变为现实（移植免疫学见[[immunology/transplant-tumour-immunology]]）。
:::

::: definition 难治性衰竭：器械、移植与诚实的地平线 {#def-advanced}
D期是最后一图底线曲线的生理：**利尿剂抵抗（[[renal/tubular-function]]远端肾单位肥大、肠水肿与心肾血管收缩）、正性肌力依赖、反复入院、及靶器官代价（淤血肾、心源性肝硬变、肿瘤坏死因子-食欲轴的恶病质）**。选项是**机械循环支持（持续流左室辅助装置——桥接移植、桥接恢复与终点治疗指征、及其代价：驱动线感染、需要抗凝的泵血栓与卒中（[[blood/thrombosis-anticoagulation]]最苛刻的患者）、获得性von Willebrand综合征——剪应力蛋白展开致胃肠道出血与主动脉瓣反流及动静脉畸形三联、及装置修不了的右室衰竭——[[cardiovascular/cardiac-cycle]]间隔与依赖生理以外科并发症回归）；心脏移植（精选者的金标准：检查的年龄与共病与依从与社会心理算术、供体配型与分配的免疫学及终身三联免疫抑制的感染、皮肤癌、移植后淋巴增殖病、糖尿病、及作为[[immunology/transplant-tumour-immunology]]慢性排斥血管病的移植心脏血管病），及——对到不了前两者的多数——姑息医学整合（预后标志与惊奇问题、预先照护计划与首选离世地点、利尿剂与小剂量阿片为呼吸困难共享的症状管理伙伴、及诚实的再入院对质量谈话——[[geriatrics-palliative/palliative-care]]与[[geriatrics-palliative/end-of-life-care]]）。** 三段背后的英国登记真相：新发心衰携带与常见癌匹敌的多年死亡率、半数患者诊断后五年内死亡、而只有四分之一到过专科衰竭门诊——所以内科医师、老年科医师与全科医师首诊时的四支柱处方、流行病学上是本书心血管章最重要的一页。
:::

::: solution
**教科书场景的地高辛中毒——窄治疗指数遇上其三个相互作用者。**药理：**肾功能不变而甲氧苄啶阻断肾小管分泌、脱水与肾动脉及年龄生理使肾小球滤过下降、袢利尿剂低钾增强心脏苷在[[physiology/muscle]]钠钾-ATP酶的结合（钾-地高辛受体竞争使严重程度读出是血清钾、不只是药物浓度）、及低肌肉量与低白蛋白缩小分布容积（[[pharmacology/absorption-distribution]]、[[pharmacology/metabolism-excretion]]肾清除章的活形态）。**表现如生理：**胃肠（纳差、恶心、呕吐——化学感受器触发带与肠水肿）、眼（黄视与模糊光晕）、自动节律增高加传导抑制的心律失常——题干“规则化的房颤”是病理生理的赠礼（房速伴阻滞、儿茶酚胺加苷环境的双向室速、高度阻滞与慢交界性逸搏——[[cardiovascular/electrophysiology-ecg]]自动节律对触发活动的课）、及大量急性中毒的高钾（泵出的梯度）、与慢性患者的低钾增强相反的预后征****。处理：**停药的相互作用者、症状性心动过缓用阿托品或起搏、镁与钾纠正（高钾过量时的谨慎补钾——结合片段赢得那场争论）、危及生命的心律失常或急性中毒钾超约5.5–6或恶性剂量加肾图像用地高辛特异性抗体片段**——配慢性剂量课：**试验时代的地高辛角色是窄窗的症状与住院削减（肾损害的低剂量血清靶策略、老肾的隔日与62.5–125 µg现实——[[renal/potassium-calcium-phosphate]]的钾与[[geriatrics-palliative/polypharmacy]]的停药清单）、而整个病例属于上述失代偿审计的药物史之问。**

::: history
**Withering**的洋地黄（1785年毛地黄的试验记录用于“水肿”、剂量-毒性纪律及机制的[[physiology/muscle]]钠泵抑制至今仍由历史学家从同一页文献争论）、**Hope与Laennec**及然后**James Mackenzie**的静脉压与临床衰竭综合（左心时代前先淤血为的心脏病学）、**Christison与Bright**的心肾交织及**Sir Thomas Lewis**学派的力学；**限盐与汞剂及黄嘌呤利尿剂时代（1940年代Kempner的米食实验——钠作用的首个现代证明——及1950年代创造现代淤血治疗的氯噻嗪革命）**；**扩血管药革命（1970-80年代的Cohn与Chatterjee及Parmley的硝普钠与降后负荷生理及V-HeFT试验）**把“惰性心衰”变成血流动力学疾病；**神经激素时代的临床试验（CONSENSUS与SOLVD及把该类别从禁忌翻为核心石的β阻滞剂试验——CIBIS与MERIT-HF与COPERNICUS规划、RALES与EPHESUS与EMPHASIS醛固酮线、CHARM与PARADIGM-HF脑啡肽酶及DAPA-HF与EMPEROR及DELIVER的SGLT2浪潮——每一个都基于生理、每一个都是经过验证的死亡率主张）**；器械线（**Barnard**的移植、全心、然后**DeBakey与Devries时代的持续流心室辅助装置及BerlinHeart时代**、诞生于同一降后负荷概念的**MIRACLE与CARE-HF再同步化试验**），及现代HFpEF与肥胖-代谢试验时代终于以SGLT2抑制剂与GLP1激动剂及体重表型医学把“什么都无效”的表型带回桌面。
:::
 history
**Hyden与Mach与Laennec的充盈静脉与心杂音时代、Colles与Henderson与Houghton的1916-18年脉压与心脏指数及Thomas Lewis的呼吸循环研究**使衰竭泵成为可测量的对象；**Cournand与Richards**的右心导管（1940年代、诺奖）、**Cope与Frone**的静脉压生理，然后**Courmand与Cope与Brock**的瓣膜与分流定位，使淤血有了数字。药理的纪元始于**洋地黄（Witherring的1785年紫花地强心草论文）、然后Sutherland与Cragg与Selye及**1940-50年代**的汞利尿剂与**利尿剂（1957年的氯噻嗪与1964年的呋塞米）**；**Brunner与Laragh与Genest及Gavras与Ferguson的1970年代ACE抑制剂翻译、以及Cushman与Ondetti的化学**把RAAS从学术（[[renal/water-sodium]]的鱼肾）变成药物；**1970年代Chatterjee与Ganz的床边血流动力学与Swan-Ganz导管、及Weber与Aickin的运动生理与Packer对“利尿剂悖论”的警告**定义了阶梯；然后**Cohn与Archibald与SOLVERA与CONSENSUS及1980-90年代**的β阻滞剂试验（Waagstein与His、PARR-2与MERIT-HF与CIBIS-II与SENATIS）及**AIRE与RALES与EMES及醛固酮逃逸及螺内酯的意外**建立四分之三支柱；**McMurray与Paradigm及de la Motte与SGLT2抑制剂**（[[endocrine/diabetes]]的降糖药、成为心衰药）与**STEP-HFpEF**及**维立西呱**完成本章治疗图；而**DeBakey与Cooley与Shumway**及**心脏移植与心脏辅助装置（1960年代、Jarvik与DeBakey的装置与1980年代的Novacor与HeartMate与ROVAT与REMATCH及后来的持续流革命）**给D期一个出口，**姑息心脏病学（Hill与Sacke与Byock及姑息-心衰联合门诊**）给它诚实。
:::

## 通向何处

泵血力学在[[cardiovascular/cardiac-cycle]]；代偿生理在[[cardiovascular/circulation-blood-pressure]]；利尿剂与神经激素药理及其肾靶点在[[renal/tubular-function]]与[[renal/water-sodium]]；心肾综合征在[[renal/chronic-kidney-disease]]；缺血底物在[[cardiovascular/coronary-artery-disease]]；心律失常与器械界面在[[cardiovascular/arrhythmias]]与[[cardiovascular/electrophysiology-ecg]]；移植免疫学在[[immunology/transplant-tumour-immunology]]；姑息弧线在[[geriatrics-palliative/palliative-care]]。

::: summary
- 心衰是分期（A–D）、表型（射血分数降低/保留及中间与恢复带）与病因——三个标签都改变管理；找到病因就是治疗。
- 螺旋——损伤、神经激素代偿、重塑、淤血与低灌注——是[[cardiovascular/circulation-blood-pressure]]生理的病理读法、这就是打断它的四类药在HFrEF降低死亡率的原因。
- 淤血靠把液体移出循环来治（通气支持、硝酸酯、利尿剂）、心中输出曲线要在心里；低灌注是不同、更稀缺、更危险的轴、自有其阶梯。
- HFpEF是顺应性与共病性疾病、其管理是减容、代谢与节律策略、及新的SGLT2与体重证据——不是照抄HFrEF四联。
- 难治疾病是机械支持、移植与诚实姑息之间的选择、而人群层面的杠杆是每个最先见到患者的临床医师早期开出四支柱。
:::

::: exercise 设计心衰服务 {level=3}
50万人的地区（65岁以上发病率约每年10/1,000）请求心衰规划。构建它：预防、快速通道诊断、出院药理、再入院削减、先进路径与人力、各元素带生理/证据理由。
::: solution
**预防（A/B期）**：高血压与糖尿病控制（[[cardiovascular/hypertension]]与[[endocrine/diabetes]]架构——肾素-血管紧张素与SGLT2臂被试验字面标注“心衰预防”）、心脏肿瘤学监测（蒽环与曲妥珠方案——[[pharmacology/adverse-reactions]]）、及心梗后重塑处方（[[cardiovascular/coronary-artery-disease]]）；**快速通道**：肽看门的气促门诊配开放准入利尿滴定与当周超声（诊断延迟证据与基层试验家族）、及作为服务脊柱的心衰专科护士（多学科-再入院试验文献——每个指南I类推荐背后的同一证据基础）；**出院药理**：住院内起始四支柱配出院后2周滴定（STRONG-HF协作照护与快速上调试验及其安全架构课——出院是会诊、不是床位）、心衰药物对NSAID与二甲双胍与利尿剂剂量的核对（[[geriatrics-palliative/polypharmacy]]）；**表型特异轨道**：HFpEF与肥胖-代谢及房颤-节律路径、淀粉样与铁及缺血病因服务配遗传门诊（[[genetics/genomic-medicine]]）；**先进**：单一地区LVAD/移植中心、转诊标准教给地区医院（第四个ICU周前的D期识别）、及姑息医学整合与首选照护地点记录（[[geriatrics-palliative/end-of-life-care]]）；**问责**：临床医师层面的再入院与死亡率及四支柱处方率、患者报告功能、及公平审计（发病率、晚诊断与器械获取的贫困梯度——[[public-health/determinants-inequalities]]）。生理贯穿线：每个元素在[[#def-spiral]]螺旋的不同节点、在系统能达到的最早节点发起攻击。
