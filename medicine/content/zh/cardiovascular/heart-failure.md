心力衰竭是许多心血管疾病的终点。心肌梗死、长期高血压、瓣膜病、心肌病和心律失常都可能留下一颗在正常充盈压下无法泵出足够血液的心脏。在高收入国家，每一百名成人中约有一到两人患有心力衰竭，70 岁以上人群中升至十分之一，它也是老年人急诊入院最常见的原因之一。它的预后曾被拿来与许多癌症相比。由于一个观点，预后已大为改善：机体对衰竭心脏的反应在短期内有益，长期却有害，阻断这些反应可以延长生命。

本章介绍心力衰竭的定义和分类、病因、解释其进展的神经激素模型、诊断、改变病程的治疗、急性心力衰竭以及晚期患者的照护。本章遵循英国指南（NICE 指南 NG106《成人慢性心力衰竭》，2025 年更新）以及欧洲心脏病学会（ESC）2021 年指南及其 2023 年重点更新；实际处理遵循现行的当地指南。

## 什么是心力衰竭

::: definition 心力衰竭 {#def-hf}
**心力衰竭**是一种临床综合征，有症状（如呼吸困难、乏力和踝部肿胀）和体征（如颈静脉压升高、肺部湿啰音和外周水肿），由心脏的结构或功能异常引起，导致静息或运动时心腔内压力升高或心输出量不足。

按**左心室射血分数（LVEF）**分类：
- **射血分数降低的心力衰竭（HFrEF）**：LVEF 40% 或以下；
- **射血分数轻度降低的心力衰竭（HFmrEF）**：LVEF 41–49%；
- **射血分数保留的心力衰竭（HFpEF）**：LVEF 50% 或以上，并有结构或功能异常以及充盈压升高的证据（例如利钠肽升高）。

LVEF 曾为 40% 或以下、之后改善至 40% 以上者，有时称为**射血分数改善的心力衰竭**。
:::

心力衰竭也按病程和严重程度描述。**急性心力衰竭**是症状迅速出现或加重、需要紧急治疗，既可以是新发的，也可以是慢性心力衰竭的失代偿。症状严重程度按**纽约心脏协会（NYHA）心功能分级**：

| NYHA 分级 | 症状 |
|---|---|
| Ⅰ | 日常体力活动不受限 |
| Ⅱ | 轻度受限：静息时舒适，日常活动引起症状 |
| Ⅲ | 明显受限：低于日常的活动即引起症状 |
| Ⅳ | 静息时有症状，任何活动均加重 |

"左"心衰和"右"心衰描述的是哪一侧的淤血占主导。左心衰使肺静脉压升高，引起呼吸困难、端坐呼吸和肺水肿。右心衰使体循环静脉压升高，引起 JVP 升高、外周水肿、肝淤血和腹水。右心衰最常见的原因是左心衰；孤立性右心衰提示肺部疾病（肺源性心脏病）、肺栓塞、肺动脉高压或右心室梗死。

## 病因

- **缺血性心脏病**：在英国是 HFrEF 最常见的病因，通过梗死和慢性缺血起作用（[[cardiovascular/coronary-artery-disease]]）。
- **高血压**：引起左心室肥厚和僵硬（HFpEF 的主要病因），晚期引起心室扩大（[[cardiovascular/hypertension]]）。
- **瓣膜病**：主动脉瓣狭窄、二尖瓣和主动脉瓣反流（[[cardiovascular/valve-congenital-disease]]）。
- **心肌病**：扩张型（遗传性、心肌炎后、酒精、蒽环类和曲妥珠单抗等化疗、围生期）、肥厚型、限制型（包括淀粉样变性，老年人 HFpEF 中一个认识不足的病因）和致心律失常型。
- **心律失常**：持续快速的心律，如控制不佳的心房颤动，可引起**心动过速性心肌病**，心率控制后可恢复。
- **高输出状态**：重度贫血、甲状腺毒症、大的动静脉瘘、Paget 骨病和脚气病（硫胺素缺乏），此时心脏无法满足异常高的需求。
- **心包疾病**：缩窄性心包炎限制充盈。

已知心力衰竭患者突然加重时，通常有一个**诱因**：心肌缺血或梗死、心律失常（尤其是新发心房颤动）、感染、未控制的高血压、未服药、盐或液体过多、肾损伤、贫血、甲状腺疾病，或引起液体潴留或抑制心脏的药物（非甾体抗炎药、某些钙通道阻滞剂、噻唑烷二酮类、某些化疗药）。

## 神经激素模型

::: theorem 心力衰竭的神经激素模型 {#thm-neurohormonal}
当心输出量下降时，机体的反应如同失血：激活**交感神经系统**、**肾素-血管紧张素-醛固酮系统**和**抗利尿激素**。这些反应在短期内支持血压和心输出量，但持续激活会损害心脏和循环，推动心力衰竭进展。阻断这些系统的药物可以延缓进展、延长生命。
:::

::: proof
考虑一次大面积前壁心肌梗死后的过程。

1. **每搏输出量下降。** 压力感受器感受到动脉压降低，肾脏感受到灌注减少。
2. **交感激活**使心率加快、收缩力增强，并使小动脉和静脉收缩。动脉压得到支持，静脉回流增加。
3. **肾素-血管紧张素-醛固酮激活**使小动脉收缩，使肾脏潴留钠和水。血容量增加使舒张末期容积增大，Frank-Starling 机制使每搏输出量增加（[[cardiovascular/cardiac-cycle#thm-starling]]）。
4. **抗利尿激素**潴留水分并收缩血管。

每一种反应在短期内都有益。持续下去则变得有害：
- 血管收缩增加**后负荷**，衰竭的心室无法克服，每搏输出量进一步下降；
- 钠水潴留使**充盈压**升高，超过衰竭心脏 Starling 曲线的平坦顶部，产生淤血（肺水肿和外周水肿），而输出几乎没有增加；
- 去甲肾上腺素和血管紧张素 Ⅱ 对心肌有直接毒性，引起**肥厚、凋亡和纤维化**；醛固酮促进心脏和血管的纤维化；
- 心室扩大并变得更接近球形（**重构**），增加室壁张力和需氧量（Laplace 定律），并牵拉二尖瓣环，引起**功能性二尖瓣反流**；
- 心动过速和儿茶酚胺易诱发**心律失常**和猝死。

结果是一个恶性循环，代偿本身加重了衰竭。由受牵拉心肌释放的**利钠肽**通过促进钠排泄和血管扩张对抗这些系统，但在心力衰竭中它们被压倒了。

这一模型解释了试验中的一个显著规律。直接增强收缩力的药物（如长期口服正性肌力药）改善了血流动力学，却增加了死亡率。阻断神经激素的药物（ACE 抑制剂、β 受体阻滞剂、盐皮质激素受体拮抗剂，以及血管紧张素受体阻滞剂与脑啡肽酶抑制剂的复方）则改善了生存，尽管 β 受体阻滞剂在短期内会降低收缩力。
:::

图中显示了正常心室和衰竭心室的 Frank-Starling 曲线。在衰竭曲线上，充盈（因而淤血）大幅增加只换来很少的每搏输出量增加。不同的治疗使患者向不同方向移动：利尿剂沿同一曲线左移（淤血减轻，输出变化不大），而血管扩张剂和逆转重构的药物则使患者向更高的曲线移动。

## 症状、体征和诊断

典型**症状**是劳力性呼吸困难、**端坐呼吸**（平卧时呼吸困难，因血液从下肢重新分布到胸部）、**夜间阵发性呼吸困难**（入睡一两小时后憋醒）、乏力、运动耐量下降和踝部肿胀。老年人可表现为意识模糊、跌倒、体重下降或夜间咳嗽。

**体征**包括心动过速、JVP 升高、心尖搏动移位（心室扩大时）、第三心音、杂音（病因性杂音或功能性二尖瓣反流）、肺底湿啰音、胸腔积液、肝大以及腿部或骶部凹陷性水肿。单独看，这些体征都不敏感：许多心力衰竭患者体征很少，而踝部水肿还有很多其他原因。

::: definition 诊断心力衰竭（NICE NG106） {#def-diagnosis}
对疑似心力衰竭者，测定 **N 末端 B 型利钠肽原（NT-proBNP）**：
- **高于 2000 ng/L**：紧急转诊，在 **2 周**内进行专科评估和经胸超声心动图；
- **400–2000 ng/L**：转诊，在 **6 周**内进行专科评估和超声心动图；
- 未经治疗者**低于 400 ng/L**：心力衰竭可能性较小，但不能排除。

70 岁以上、心房颤动、肾脏病、肺栓塞、脓毒症和其他心脏应激原因会使利钠肽水平**升高**；肥胖以及利尿剂、ACE 抑制剂、血管紧张素受体阻滞剂、β 受体阻滞剂和盐皮质激素受体拮抗剂治疗会使其**降低**。**超声心动图**用于确诊、测量射血分数并明确病因（室壁运动异常、瓣膜病、肥厚）。
:::

其他基线检查包括心电图（心电图完全正常时 HFrEF 可能性不大）、胸片（心脏扩大、肺静脉淤血、胸腔积液；并排除肺部疾病）、全血细胞计数（贫血）、铁代谢（铁缺乏常见且可治疗）、肾功能和电解质、肝功能和甲状腺功能、HbA1c 和血脂。寻找病因的进一步检查包括冠状动脉影像、心脏 MRI（用于心肌病、心肌炎、浸润性病变和瘢痕），以及在怀疑时进行淀粉样变性检查。

::: example 射血分数正常的呼吸困难 {#ex-hfpef}
一位 79 岁女性有长期高血压、2 型糖尿病和肥胖（BMI 36），一年来劳力性呼吸困难和踝部肿胀逐渐加重。她有阵发性心房颤动。NT-proBNP 为 1150 ng/L。超声心动图示左心室射血分数 62%，向心性左心室肥厚，左心房扩大，估测充盈压升高。这是心力衰竭吗？如何处理？

::: solution
她有心力衰竭的症状和体征、NT-proBNP 升高（她的肥胖会降低利钠肽水平，所以真实信号只会更强），以及充盈压升高的结构证据（肥厚、左心房扩大），射血分数 62%。这是**射血分数保留的心力衰竭（HFpEF）**。NT-proBNP 在 400–2000 ng/L，她本应在 6 周内转诊专科评估。

机制是**左心室僵硬**：肥厚、纤维化和年龄相关的变化降低了舒张和顺应性，因此心室需要高充盈压才能达到正常容积。这一压力传至左心房和肺，在运动时尤甚，因为舒张期缩短，充盈时间更少。心房颤动去除了心房的贡献并缩短部分心动周期，使充盈更差。

处理：
- 用**利尿剂**减轻淤血。
- **SGLT2 抑制剂**（达格列净〔dapagliflozin〕或恩格列净〔empagliflozin〕），在 EMPEROR-Preserved 和 DELIVER 试验中减少了 HFpEF 和 HFmrEF 的心衰住院；盐皮质激素受体拮抗剂非奈利酮（finerenone）在 FINEARTS-HF 试验（2024）中减少了心衰恶化事件。
- **治疗合并症**：血压、**心房颤动**（心率或节律控制以及抗凝）、糖尿病、**肥胖**（减重可改善症状），并筛查心脏淀粉样变性等病因，它在老年 HFpEF 患者中常见且有特定治疗。
- **运动康复**。

与 HFrEF 不同，没有证据表明 ACE 抑制剂或 β 受体阻滞剂可改善 HFpEF 的生存，但其他疾病可能需要它们。
:::
:::

## 射血分数降低的心力衰竭的治疗

治疗的目的是缓解症状、预防住院和延长生命。证据来自一系列里程碑式的试验，每一项都在既往标准治疗之上增加一类药物。

::: definition HFrEF 的核心药物 {#def-treatment}
- **ACE 抑制剂**（或**沙库巴曲缬沙坦**〔sacubitril–valsartan〕，一种血管紧张素受体-脑啡肽酶抑制剂，ARNI）。ACE 抑制剂在 CONSENSUS 试验（1987）及后续试验中降低了重度心力衰竭的死亡率。沙库巴曲缬沙坦在血管紧张素受体阻断之外加上对脑啡肽酶（降解利钠肽的酶）的抑制，在 PARADIGM-HF（2014）中与依那普利（enalapril）相比减少了心血管死亡和心衰住院。如不能耐受 ACE 抑制剂，使用 ARB。
- 获准用于心力衰竭的 **β 受体阻滞剂**（比索洛尔〔bisoprolol〕、卡维地洛〔carvedilol〕，老年人可用奈必洛尔〔nebivolol〕）。尽管起初会降低收缩力，它们仍能降低死亡率，包括猝死。应在患者稳定时从小剂量开始，缓慢加量。
- **盐皮质激素受体拮抗剂（MRA）**：螺内酯（spironolactone）或依普利酮（eplerenone）。螺内酯在 RALES 试验（1999）中降低了重度 HFrEF 的死亡率。
- **SGLT2 抑制剂**：达格列净或恩格列净。在 DAPA-HF（2019）和 EMPEROR-Reduced（2020）中，无论有无糖尿病，它们都减少了心血管死亡或心衰恶化。

根据 2025 年更新的 NICE NG106，HFrEF 患者应接受**全部四类**药物（ACE 抑制剂、β 受体阻滞剂、MRA 和 SGLT2 抑制剂），除非有禁忌或不耐受，并滴定至最大耐受剂量。不能耐受 ACE 抑制剂（血管性水肿除外）时用沙库巴曲缬沙坦替代 ACE 抑制剂；症状持续时考虑换用沙库巴曲缬沙坦；ESC 指南将沙库巴曲缬沙坦列为与 ACE 抑制剂并列的首选。
:::

每种药物都有指导监测的特征性问题：

- ACE 抑制剂、ARB、ARNI 和 MRA 可引起**高钾血症**和**肌酐升高**；开始用药前及每次调整剂量后都应检查肾功能和血钾。开始沙库巴曲缬沙坦前必须停用 ACE 抑制剂至少 36 小时，因为两者合用会大大增加血管性水肿的风险。
- β 受体阻滞剂可引起心动过缓、乏力，以及滴定期间淤血的暂时加重。
- SGLT2 抑制剂引起 eGFR 早期轻度下降、生殖器真菌感染，罕见情况下引起**血糖正常或仅轻度升高的酮症酸中毒**，尤其在急性疾病或禁食时。

**袢利尿剂**（呋塞米〔furosemide〕、布美他尼〔bumetanide〕）减轻淤血，是缓解症状所必需的，但尚未证明能延长生命。剂量以保持无淤血的最低剂量为准；每日称体重有助于早期发现液体潴留。

其他选择通常由专科开始使用，包括：
- **伊伐布雷定**（ivabradine），用于使用 β 受体阻滞剂后窦性心律、心率仍为 75 次/分或以上者；
- **肼屈嗪联合硝酸异山梨酯**，尤其用于中重度 HFrEF 的非洲或加勒比裔患者；
- **地高辛**，用于缓解症状或心房颤动的心率控制；
- **静脉补铁**用于铁缺乏，可改善症状和运动能力并减少住院。

::: example 恶心和黄视 {#ex-digoxin}
一位 84 岁女性患 HFrEF 和心房颤动，服用地高辛、比索洛尔、雷米普利（ramipril）、螺内酯、达格列净和呋塞米。腹泻一周后，她出现恶心、食欲不振、意识模糊，并说灯光看起来发黄。脉搏 44 次/分，规则。肌酐从 105 升至 190 µmol/L，血钾 5.9 mmol/L。解释发生了什么。

::: solution
这一表现提示由**急性肾损伤**诱发的**地高辛中毒**。

- 地高辛主要经肾脏清除。腹泻引起的脱水，加上利尿剂和降低肾小球滤过的药物（雷米普利、螺内酯、达格列净的早期效应），使其清除减少，浓度升高。
- 中毒的典型表现有胃肠道症状（恶心、食欲不振）、神经系统症状（意识模糊）和视觉症状（黄绿色视、视物模糊），以及心律失常。**心房颤动患者脉搏缓慢而规则**，提示完全性心脏传导阻滞伴交界性逸搏心律，这是地高辛的典型效应。
- **高钾血症**源于肾损伤和保钾药物。在急性地高辛中毒中，钠-钾泵受抑制也会导致高钾血症；反之，低钾会增加地高辛的毒性。

处理遵循当地方案：停用地高辛，测定地高辛浓度（末次给药后至少 6 小时采血），心电监护，补液，纠正电解质，并暂停损害肾功能或升高血钾的药物。对危及生命的心律失常、重度高钾血症或血流动力学受损，使用**地高辛特异性抗体片段**。本例说明了"病假规则"和仔细审查多重用药对老年心力衰竭患者的重要性（[[geriatrics-palliative/polypharmacy]]）。
:::
:::

**器械**治疗电学问题。**植入式心律转复除颤器（ICD）**可预防部分 LVEF 35% 或以下患者的心律失常性猝死。**心脏再同步治疗（CRT）**同步起搏两个心室，可改善宽 QRS 波（尤其是 QRS 150 ms 或以上的左束支传导阻滞）且 LVEF 35% 或以下患者的症状和生存。

::: warning 肌酐一升高就停用延长生命的药物是错误的
开始或增加 ACE 抑制剂、ARB、ARNI 或 SGLT2 抑制剂后，肌酐小幅升高（最多约 30%）是预料之中的，反映的是肾小球内压的变化而非肾损伤。因这种升高而停药，会剥夺患者的生存获益。更大幅度的升高、高钾血症或合并其他疾病时的恶化需要复查，在脱水性疾病期间常建议暂时停药（"病假规则"）。同样，病情稳定的患者轻度失代偿时，不要突然停用 β 受体阻滞剂；仅在休克或重度心动过缓时减量。
:::

::: example 心脏扩大的年轻男性 {#ex-dcm}
一位 38 岁男性三个月来呼吸困难和端坐呼吸逐渐加重。他每周饮酒约 70 单位。超声心动图示左心室扩大、弥漫性运动减弱，射血分数 25%；冠状动脉造影正常。血压 108/70 mmHg，脉搏 96 次/分，窦性心律，血钾 4.4 mmol/L，eGFR 85。概述处理原则。

::: solution
他患有**扩张型心肌病所致的 HFrEF**，可能与酒精有关，但也应考虑遗传性病因、心肌炎和其他原因（心脏 MRI 有帮助，如怀疑遗传性病因，可提供家族筛查）。

原则：
- **完全戒酒**，并给予安全戒酒的支持（评估酒精戒断）。酒精性心肌病在戒酒后可显著改善。
- 用**利尿剂**减轻淤血。
- **四种核心药物**：ACE 抑制剂（或 ARNI）、β 受体阻滞剂、MRA 和 SGLT2 抑制剂，从小剂量开始，按耐受情况加量，监测血压、心率、血钾和肾功能。他的血压偏低，因此滴定的顺序和速度需个体化。
- **优化治疗约 3 个月后复查 LVEF。** 如仍为 35% 或以下，考虑 ICD（如 QRS 宽，考虑 CRT）。
- 接种流感和肺炎球菌疫苗，运动康复，并进行关于症状、每日称重和限盐的教育。

他的射血分数可能会恢复。即便如此，通常仍继续指南推荐的治疗，因为停药可能导致复发。
:::
:::

## 急性心力衰竭

急性心力衰竭是医疗急症。初步评估寻找**病因或诱因**（急性冠脉综合征、高血压急症、心律失常、急性瓣膜问题、肺栓塞、感染、心脏压塞）以及患者的**血流动力学分型**，在床旁判断：

- **"湿"或"干"**：有无淤血体征（JVP 升高、湿啰音、水肿、端坐呼吸）。
- **"暖"或"冷"**：外周灌注是否充足，或有无低输出体征（四肢冰凉、意识模糊、尿量少、脉压窄、乳酸升高）。

大多数患者为**暖而湿**：灌注良好但有淤血。治疗以**静脉袢利尿剂**为中心，低氧时给氧，呼吸窘迫或给氧无效的低氧时使用无创通气（CPAP），血压高时静脉使用硝酸酯类。不再常规使用阿片类药物。较少的一部分为**冷而湿**，即**心源性休克**：他们需要重症监护和病因治疗（如紧急冠状动脉血运重建），可能需要正性肌力药、血管加压药或机械循环支持。

::: example 又湿又冷 {#ex-acute}
一位已知缺血性 HFrEF（射血分数 25%）的 72 岁男性因严重呼吸困难入院。他意识模糊。血压 82/58 mmHg，脉搏 118 次/分，四肢冰凉有花斑，JVP 升至耳垂，湿啰音达中肺野，未吸氧时 SpO₂ 88%。乳酸 4.6 mmol/L，尿量 10 mL/h。描述他的血流动力学分型，并解释为什么治疗不同于暖而湿的患者。

::: solution
他是**冷而湿**：有淤血（JVP 升高、肺水肿、低氧）且灌注不良（低血压、皮肤湿冷有花斑、意识模糊、乳酸高、少尿）。这是**心源性休克**。

对暖而湿的患者，大剂量利尿剂和硝酸酯类可在维持灌注的同时减轻淤血。而本例中心输出量太低，不足以灌注器官。硝酸酯类会使血压进一步下降；由于肾灌注差，单用利尿剂可能无效。处理包括：
- **重症监护**和有创监测；
- 给氧和通气支持以纠正低氧；
- **治疗诱因**：心电图和肌钙蛋白寻找需要紧急血运重建的急性冠脉综合征，并寻找心律失常、感染或机械并发症；
- **正性肌力支持**（例如多巴酚丁胺〔dobutamine〕）以提高心输出量，有时加用血管加压药（去甲肾上腺素）以维持灌注压；
- 灌注改善后使用利尿剂；
- 对部分患者考虑**机械循环支持**，并因死亡率高而尽早讨论治疗目标。

休克时可能需要暂时减量或停用 β 受体阻滞剂。
:::
:::

## 晚期心力衰竭与生命末期

当症状在最佳治疗下仍持续时，可选择：对部分（通常较年轻的）患者进行**心脏移植**；**左心室辅助装置（LVAD）**，一种机械泵，作为移植的过渡或长期治疗；以及**姑息治疗**。心力衰竭的病程常难以预测，反复住院且有猝死风险，因此关于目标和意愿的谈话应尽早开始并不断回顾。姑息治疗关注呼吸困难、乏力、水肿、疼痛、焦虑和情绪低落，并规划患者希望在何处接受照护。生命末期停用 ICD 的电击功能，应事先与患者和家属讨论（[[geriatrics-palliative/palliative-care]]）。

::: quiz
下列哪一类药物能缓解 HFrEF 的淤血症状，但**未**被证明能降低死亡率？
- [ ] β 受体阻滞剂
- [ ] 盐皮质激素受体拮抗剂
- [x] 袢利尿剂
- [ ] SGLT2 抑制剂
::: solution
**袢利尿剂**减轻淤血，是缓解症状所必需的，但试验未显示它们能延长生命。β 受体阻滞剂、MRA 和 SGLT2 抑制剂，加上 ACE 抑制剂或沙库巴曲缬沙坦，可降低 HFrEF 的死亡率和住院率。
:::
:::

::: history
1785 年，伯明翰的医生威瑟林（William Withering）出版了《毛地黄概述》（*An Account of the Foxglove*），描述了一种含毛地黄的家传方剂如何缓解"水肿病"；此后近两个世纪，洋地黄一直是治疗心力衰竭的主要药物。20 世纪 50 至 60 年代先后问世的汞利尿剂以及噻嗪类和袢利尿剂，彻底改变了淤血的缓解。CONSENSUS 试验（1987）证明 ACE 抑制剂依那普利可降低重度心力衰竭的死亡率，这是药物能延长心力衰竭患者生命的第一个明确证据，开创了神经激素治疗时代。曾被认为是禁忌的 β 受体阻滞剂在 20 世纪 90 年代末被证明可降低死亡率，随后是螺内酯（RALES，1999）、沙库巴曲缬沙坦（PARADIGM-HF，2014）和 SGLT2 抑制剂（DAPA-HF，2019）。1967 年，巴纳德（Christiaan Barnard）在开普敦完成了第一例人类心脏移植。
:::

## 后续内容

本章的生理学基础见[[cardiovascular/cardiac-cycle]]和[[cardiovascular/circulation-blood-pressure]]。病因在[[cardiovascular/coronary-artery-disease]]、[[cardiovascular/hypertension]]、[[cardiovascular/valve-congenital-disease]]和[[cardiovascular/arrhythmias]]中展开。休克及其处理见[[emergency-critical-care/shock-fluids]]，血钾和肾功能的管理见[[renal/chronic-kidney-disease]]。生命末期的照护见[[geriatrics-palliative/palliative-care]]。

::: summary
- 心力衰竭是由心脏结构或功能异常引起的临床综合征；按 LVEF 分为降低（40% 或以下）、轻度降低（41–49%）或保留（50% 或以上），并按 NYHA 分级。
- 主要病因：缺血性心脏病、高血压、瓣膜病、心肌病和心律失常；失代偿通常有诱因。
- 神经激素激活（交感、肾素-血管紧张素-醛固酮、ADH）短暂支持循环，但驱动重构和进展；阻断它可延长生命。
- NICE：NT-proBNP 高于 2000 ng/L，2 周内转诊并行超声心动图；400–2000 ng/L，6 周内；未经治疗者低于 400 ng/L 时心力衰竭可能性较小。肥胖和治疗会降低其水平。
- HFrEF：给予 ACE 抑制剂（或沙库巴曲缬沙坦）、β 受体阻滞剂、MRA 和 SGLT2 抑制剂；袢利尿剂用于淤血；部分患者用 ICD 和 CRT。
- HFpEF：利尿剂、SGLT2 抑制剂、治疗合并症（高血压、房颤、肥胖），并筛查淀粉样变性等特定病因。
- 急性心力衰竭按暖或冷、湿或干评估；心源性休克需病因治疗和循环支持。
- 姑息治疗和预立医疗照护计划是心力衰竭照护的一部分。
:::

## 习题

::: exercise 心力衰竭分类 {level=1}
按射血分数类别分类：(a) LVEF 30%；(b) LVEF 45%；(c) LVEF 58%，伴呼吸困难、NT-proBNP 900 ng/L 和左心房扩大；(d) LVEF 原为 30%，治疗后为 48%。
::: solution
(a) **HFrEF**（40% 或以下）。(b) **HFmrEF**（41–49%）。(c) **HFpEF**（50% 或以上，有充盈压升高证据）。(d) **射血分数改善的心力衰竭**；通常继续治疗。
:::
:::

::: exercise 解读利钠肽 {level=1}
对基层医疗中下列疑似心力衰竭的患者，说明 NICE 的转诊时限：(a) NT-proBNP 2600 ng/L；(b) BMI 38 的女性，NT-proBNP 650 ng/L；(c) 未经治疗的 50 岁患者，NT-proBNP 210 ng/L。
::: solution
(a) 高于 2000 ng/L：**紧急转诊，2 周内进行专科评估和超声心动图**。

(b) 400–2000 ng/L：**6 周内**。肥胖会降低利钠肽水平，因此这一数值比表面上更有意义。

(c) 未经治疗者低于 400 ng/L：**心力衰竭可能性较小**；考虑症状的其他原因，但如怀疑仍高，应重新考虑。
:::
:::

::: exercise DAPA-HF 的需治疗人数 {level=2 check="ceil(1/(0.212-0.163))"}
在 DAPA-HF 试验中，在中位约 18 个月的随访期内，主要终点（心衰恶化或心血管死亡）在安慰剂组发生率为 21.2%，在达格列净组为 16.3%。计算在此期间预防一次主要终点事件的需治疗人数，向上取整。
::: solution
绝对风险降低 $= 21.2\% - 16.3\% = 4.9\% = 0.049$。$NNT = 1/0.049 = 20.4$，向上取整为 **21**。
:::
:::

::: exercise RALES {level=2 check="ceil(1/(0.46-0.35))"}
在 RALES 试验中，重度 HFrEF 患者在平均 24 个月的随访期内，安慰剂组约 46% 死亡，螺内酯组约 35% 死亡。计算在此期间预防一例死亡的需治疗人数，向上取整，并指出实际使用螺内酯时的主要安全问题。
::: solution
绝对风险降低 $= 0.46 - 0.35 = 0.11$。$NNT = 1/0.11 = 9.1$，向上取整为 **10**。

主要安全问题是**高钾血症**（以及肾功能恶化），尤其在与 ACE 抑制剂或 ARB 合用、老年人和慢性肾脏病患者中。RALES 发表后，处方量急剧增加，在一些监测不足的人群中，因高钾血症住院的人数增加了，这是把试验结果转化为常规医疗时的一个教训。
:::
:::

::: exercise 寻找诱因 {level=2}
一位稳定 HFrEF 两年的 76 岁女性因呼吸困难加重和 10 天内体重增加 4 kg 入院。列出你要寻找的诱因，以及针对每一项的检查或询问。
::: solution
- **不依从**药物或限盐限水建议：询问，核对处方。
- **新药**：非甾体抗炎药（用于关节炎）、糖皮质激素、非二氢吡啶类钙通道阻滞剂、吡格列酮：药物审查。
- **心律失常**，尤其是心房颤动：心电图。
- **心肌缺血或梗死**：症状、心电图、肌钙蛋白。
- **感染**，常为呼吸道或泌尿道：体温、胸片、尿检、炎症指标。
- **未控制的高血压**：血压。
- **肾损伤或电解质紊乱**：肾功能、血钾、血钠。
- **贫血**：全血细胞计数、铁代谢。
- **甲状腺功能异常**：甲状腺功能（包括服用胺碘酮者）。
- **瓣膜病加重**：超声心动图。
:::
:::

::: exercise 缩窄还是衰竭？ {level=2}
一位 61 岁男性二十多岁时曾因淋巴瘤接受放疗，现有 JVP 升高且吸气时上升、腹水、腿部水肿，双肺清晰。超声心动图示心室大小和射血分数正常。应考虑什么诊断？为什么不能漏诊？
::: solution
**缩窄性心包炎**。增厚、僵硬的心包（本例可能源于纵隔放疗；其他原因包括结核、既往心脏手术和病毒性心包炎）使心室无法充盈超过一个固定容积。静脉压升高，JVP 吸气时上升（**Kussmaul 征**）并有陡峭的 y 降支，右心淤血占主导，而心室本身收缩正常。它可能被误认为肝病（腹水）或限制型心肌病。

它之所以重要，是因为它**可通过心包切除术治愈**，而心力衰竭药物帮助甚微。诊断采用观察血流呼吸变异的超声心动图、心脏 MRI 或 CT（心包增厚），必要时进行左右心同步导管检查。
:::
:::

::: exercise 哪种器械？ {level=2}
对下列在最佳药物治疗 3 个月后的 HFrEF 患者，说明可能考虑 ICD、CRT、两者都用还是都不用：(a) LVEF 30%，窦性心律，QRS 90 ms，NYHA Ⅱ级，缺血性病因；(b) LVEF 28%，窦性心律，左束支传导阻滞，QRS 168 ms，NYHA Ⅲ级；(c) LVEF 33%，晚期癌症，预计生存期数周。
::: solution
(a) 可考虑 **ICD** 预防心律失常性猝死；QRS 窄，CRT 无益。

(b) 由于宽 QRS 的左束支传导阻滞，有 **CRT** 指征；通常为联合的 **CRT-除颤器**，需个体化评估。

(c) **都不用**：预防猝死的预期获益被有限的预后所抵消。不会植入器械，已有器械的电击功能可在讨论后停用。
:::
:::

::: exercise 妊娠相关的心力衰竭 {level=3}
一位 31 岁女性在第二个孩子出生三周后出现逐渐加重的呼吸困难、端坐呼吸和腿部肿胀。NT-proBNP 3400 ng/L，超声心动图示 LVEF 30%，左心室扩大。讨论鉴别诊断、最可能的诊断，以及常规心力衰竭治疗必须如何调整。
::: hint
想一想哪些药物有致畸性或会进入乳汁，以及扩大的心室在围生期有哪种特别相关的并发症。
:::
::: solution
**鉴别诊断**：围生期心肌病；妊娠血流动力学负荷暴露出的原有扩张型心肌病（包括遗传类型）；心肌炎；心肌梗死（包括自发性冠状动脉夹层）；肺栓塞（产后呼吸困难的常见原因）；伴肺水肿的子痫前期，可在分娩后发生；以及羊水栓塞或其他罕见原因。

最可能的诊断是**围生期心肌病**：在妊娠末期或分娩后数月内出现的心力衰竭，LVEF 低于 45%，且无其他病因。

调整：
- **分娩后**可使用标准 HFrEF 治疗，但需注意**哺乳**：某些 ACE 抑制剂（如依那普利）和 β 受体阻滞剂一般被认为与哺乳相容，而 ARNI、MRA 和 SGLT2 抑制剂在哺乳期通常避免使用，具体遵循专科和药学建议。**妊娠期间**，ACE 抑制剂、ARB、ARNI 和 MRA 因对胎儿有害而禁用。
- 由于左心室血栓风险高且围生期处于高凝状态，考虑**抗凝**。
- 一些中心使用**溴隐亭**（bromocriptine），其依据是催乳素的一种裂解片段对心脏有毒性的假说；需联合抗凝并在专科指导下使用。
- 由心内科和产科团队共同管理。约一半女性的心室功能可恢复，但再次妊娠有复发风险，因此关于**避孕和未来妊娠**的咨询必不可少（[[obstetrics-gynaecology/postnatal-period]]）。
:::
:::
