心脏产生压力；血管决定血流去向。健康成人静息时每分钟泵出约 5 升血液，而运动时仅肌肉一项每分钟就可以获得超过 20 升，同时肾脏、肠道和皮肤得到的血液减少。这种再分配靠小动脉直径的微小变化实现，而且在此过程中动脉压保持得相当稳定。理解压力、血流和阻力之间的关系，以及机体如何维持血压，是理解高血压、休克、晕厥和水肿的基础。

本章介绍血管中血流的物理学、动脉压及其测量、血流的局部调节、毛细血管中的液体交换，以及在数秒、数小时和数天内调节血压的反射和激素系统。

## 压力、血流与阻力

血液从高压处流向低压处。对于一条血管或整个循环，这一关系就是血流动力学版本的欧姆定律。

::: theorem 血流、压力与阻力 {#thm-flow}
通过一个血管床的血流量（$Q$）等于其两端的压力差除以其阻力：
$$
Q = \frac{\Delta P}{R}.
$$ {#eq-ohm}
应用于整个体循环，以心输出量为血流量：
$$
MAP - RAP = CO \times TPR,
$$ {#eq-map}
其中$MAP$为平均动脉压，$RAP$为右心房压，$TPR$为总外周（体循环血管）阻力。由于 RAP 很小，常简化为$MAP \approx CO \times TPR$。

对于在刚性管中稳定的层流，**泊肃叶定律（Poiseuille 定律）**给出阻力：
$$
R = \frac{8 \eta L}{\pi r^4},
$$ {#eq-poiseuille}
其中$\eta$为黏度，$L$为长度，$r$为半径。
:::

方程中最重要的一项是半径的四次方。血管半径减半，阻力增加十六倍。因此，血管平滑肌张力的微小变化会对血流产生极大的影响。在体内长度几乎不变，黏度只随血细胞比容变化（真性红细胞增多症时升高，贫血时降低）。血液不是简单的流体，血管也不是刚性管，所以泊肃叶定律只是近似，但它对半径的依赖关系足以解释临床观察。

::: widget plot

vlines: 1
labels: \text{血流量 (基线的 \%)}
caption: 由泊肃叶定律（血流量 ∝ $r^4$）得出：在恒定压力下，血管的相对血流量对其半径（以基线的分数表示）。半径减少 20%（0.8）只剩下约 41% 的血流量；半径增加 20%（1.2）血流量约增加一倍。这是简化模型：真实血管有弹性，血液是非牛顿流体。
:::

阻力串联时相加，并联时按倒数相加。体循环各器官主要以并联方式排列，因此每个器官都以大致相同的压力接受动脉血，并通过调节自身阻力来控制它在心输出量中所占的份额。**小动脉**是阻力的主要所在：压力在小动脉中下降最陡，从平均约 85 mmHg 降至毛细血管起始处的约 30 mmHg。它们是循环的节流阀。

**静脉**的表现不同。静脉壁薄、顺应性很大，压力稍有升高就能容纳大量额外的血液。任一时刻约三分之二的血容量位于体循环的静脉和小静脉中；它们是**容量血管**。交感神经引起的静脉收缩把部分血液推向心脏，从而增加充盈和心输出量。

正常血管中的血流是**层流**：各层血液彼此滑过，中心最快，血流无声。当流速升高、血管突然狭窄或黏度降低时，血流变为**湍流**。湍流是可以听到的。狭窄的颈动脉或肾动脉上方的**杂音（血管杂音）**和异常瓣膜处的心脏**杂音**都是湍流的声音。湍流的倾向用雷诺数概括，雷诺数随流速、直径和密度增大而增大，随黏度增大而减小；这就是为什么贫血时黏度低、心输出量高，可产生柔和的"血流杂音"。

::: example 计算外周阻力 {#ex-tpr}
一位 56 岁男性在重症监护病房，血压 120/80 mmHg，右心房压 5 mmHg，用热稀释法测得心输出量 4.4 L/min。估算他的平均动脉压和总外周阻力，并用换算系数 80 将阻力换算为许多监护仪所用的单位（dyn·s·cm⁻⁵）。

::: solution
在正常心率下，平均动脉压可估算为舒张压加三分之一脉压：
$$
MAP \approx 80 + \tfrac{1}{3}(120 - 80) = 80 + 13.3 = 93.3 \text{ mmHg}.
$$

总外周阻力：
$$
TPR = \frac{MAP - RAP}{CO} = \frac{93.3 - 5}{4.4} = 20.1 \text{ mmHg·min/L}.
$$

乘以 80 约为 **1600 dyn·s·cm⁻⁵**，高于成人静息时约 800–1200 的通常范围。阻力高而心输出量偏低，提示血管收缩在代偿血流的减少。计算结果的可靠性取决于测量：三分之一法则只是近似，如有动脉导管，可直接获得实测平均压。
:::
:::

## 动脉血压

::: definition 收缩压、舒张压、脉压和平均动脉压 {#def-bp}
- **收缩压**：射血期动脉压的峰值。
- **舒张压**：最低压力，在下一次射血之前、血液从动脉流入小动脉时达到。
- **脉压**：收缩压减舒张压。它随每搏输出量和大动脉僵硬度的增加而增大。
- **平均动脉压（MAP）**：整个心动周期的平均压力，即推动血液流入各器官的压力。在静息心率下，它近似等于舒张压加三分之一脉压。脓毒性休克时常以约 65 mmHg 的 MAP 作为最低目标。
:::

主动脉和大动脉有弹性。收缩期它们被扩张，储存部分每搏输出量；舒张期它们回缩，使血液继续流向组织。这一**弹性贮器（Windkessel）**功能把心脏间歇性的输出转化为连续的血流。随着年龄增长，弹性纤维断裂，胶原增加，动脉变僵硬，压力波传播加快。从外周反射回来的波在收缩期而非舒张期回到主动脉。收缩压和脉压升高，而舒张压下降。老年人的**单纯收缩期高血压**就是这样形成的（[[cardiovascular/hypertension]]）。

临床上用袖带无创测量血压。听诊法是将袖带充气至高于收缩压后缓慢放气；首次出现的叩击样 **Korotkoff 音**标志收缩压，声音消失标志舒张压。现在大多数诊所使用经验证的自动示波法血压计，它检测袖带中的压力振荡并计算出数值。袖带气囊必须与上臂相配：袖带过小会高估血压。测量时患者应坐位、背部有支撑、手臂支撑于心脏水平，并先休息几分钟。诊断性测量的细节见[[cardiovascular/hypertension]]。

## 血流的局部调节

每个器官都调节自身的阻力，使血流与需求相匹配，这在很大程度上不依赖中枢控制。

- **自身调节**使血流在一定灌注压范围内大致保持恒定（健康人的脑和肾，平均动脉压约 60–150 mmHg）。**肌源性反应**是其中的一部分：压力升高牵拉小动脉平滑肌，使其收缩。慢性高血压时自身调节范围上移，因此降压过快可引起脑或肾缺血。
- **代谢性调节。** 活动的组织产生腺苷、二氧化碳、氢离子、钾和乳酸并消耗氧，这些都会使小动脉扩张。这种**主动充血**使运动的肌肉和工作的心肌得到更多血流。一段时间的阻断后，血流会出现过冲（**反应性充血**）。
- **内皮**释放**一氧化氮**（受切应力以及乙酰胆碱、缓激肽等物质刺激）和**前列环素**，两者都是血管扩张剂；还释放**内皮素**，一种血管收缩剂。内皮功能障碍伴一氧化氮减少，是动脉粥样硬化、糖尿病和高血压的早期特征。有机硝酸酯通过提供一氧化氮缓解心绞痛。

一些循环有特殊的表现。**冠状动脉**血流主要发生在舒张期，几乎完全由代谢控制。**脑**血流对二氧化碳高度敏感：过度通气使$P_aCO_2$降低、脑血管收缩。**肺**循环是低压、低阻力系统，缺氧引起血管收缩（与体循环血管相反），使血液避开通气不良的肺泡（[[respiratory/gas-exchange]]）。**皮肤**血流主要由交感神经控制，用于体温调节。**骨骼肌**静息时阻力高，扩张潜力大。

## 毛细血管交换与水肿

毛细血管是循环完成其工作的地方：氧、营养物质和代谢废物通过弥散跨过管壁，水则按管壁两侧压力的平衡移动。

::: theorem Starling 液体交换原理 {#thm-starling-filtration}
液体跨毛细血管壁的净滤过量为
$$
J_v = K_f\big[(P_c - P_i) - \sigma(\pi_c - \pi_i)\big],
$$ {#eq-starling}
其中$P_c$和$P_i$分别为毛细血管内和组织间隙的静水压，$\pi_c$和$\pi_i$为相应的胶体渗透压，$\sigma$为血浆蛋白的反射系数（在大多数毛细血管中接近 1），$K_f$为滤过系数，反映管壁的通透性和表面积。
:::

::: proof
毛细血管内的静水压把液体推出；血浆蛋白不易穿过管壁，其胶体渗透压把水吸回。在大多数组织中，这一平衡使整条毛细血管都有少量净外向滤过。基于内皮表面糖萼的现代观点认为，起作用的胶体渗透压是糖萼层下方的那一个，因此大多数毛细血管的静脉端很少或没有液体重吸收。滤出的液体经**淋巴管**回到循环，淋巴管每天把数升液体送回静脉系统。当滤过超过淋巴引流时就形成水肿。
:::

该方程直接列出了水肿的原因：

- **毛细血管静水压升高**：心力衰竭、静脉阻塞（深静脉血栓形成）、静脉功能不全、液体过负荷，以及扩张小动脉多于小静脉的药物，如二氢吡啶类钙通道阻滞剂（氨氯地平〔amlodipine〕），它们使腿部毛细血管压升高。
- **血浆胶体渗透压降低**：肾病综合征、肝病或营养不良引起的低白蛋白。
- **通透性增加**（$K_f$升高、$\sigma$降低）：炎症、脓毒症、烧伤、过敏反应。
- **淋巴阻塞**：淋巴结手术或放疗后、恶性肿瘤或丝虫病。纤维化形成后，淋巴水肿为非凹陷性。

肺水肿是发生在肺内的同一过程。当左心房压升高超过约 20–25 mmHg 时，滤过超过淋巴引流，液体进入间质，继而进入肺泡。水肿的一般病理学见[[pathology/haemodynamics]]。

::: example 踝部肿胀 {#ex-oedema}
一位 72 岁女性双侧踝部肿胀六周。JVP 不高，双肺清晰，尿试纸蛋白阴性，血清白蛋白 41 g/L。两个月前她的降压药改为氨氯地平。用 Starling 原理分析最可能的原因。

::: solution
逐项分析方程：

- **胶体渗透压**：白蛋白正常且无蛋白尿，因此血浆胶体渗透压降低（肾病综合征、肝病）不太可能。
- **体循环静脉压**：JVP 不高、双肺清晰，因此右心衰竭或液体过负荷可能性较小，但在她这个年龄做一次超声心动图仍是合理的。
- **药物引起的毛细血管静水压升高**：二氢吡啶类钙通道阻滞剂扩张小动脉多于小静脉，更多的压力传入下垂部位组织的毛细血管，使$P_c$和滤过增加。时间上相符。
- **通透性或淋巴因素**：没有提示炎症或淋巴疾病的表现，且肿胀为双侧。

**氨氯地平引起的踝部水肿**是最可能的原因。它与剂量有关，对利尿剂反应不佳，因为问题在于毛细血管压而非钠水潴留；可选方案包括减量或换药，由处方者与患者共同决定。如果是单侧肿胀或有小腿压痛，则需首先排除深静脉血栓形成（[[cardiovascular/vascular-disease]]）。
:::
:::

## 血压的调节：数秒、数小时和数天

动脉压是心输出量与外周阻力的乘积，两者都受到调控。三个系统在不同的时间尺度上起作用。

::: definition 压力感受器反射 {#def-baroreflex}
**动脉压力感受器**是位于**颈动脉窦**（传入纤维走行于舌咽神经）和**主动脉弓**（传入纤维走行于迷走神经）管壁中的牵张感受器。压力升高时其放电增加。信号到达延髓的**孤束核**，孤束核：

- 增加至心脏的**迷走**（副交感）传出，使心率减慢；
- 减少至心脏（降低心率和收缩力）、至小动脉（降低阻力）和至静脉（增加静脉容量）的**交感**传出。

压力下降时作用相反。该反射在数秒内起作用，缓冲瞬间的变化，例如站立时的变化。在数天内它会**重调**到一个持续的新压力水平，因此它并不决定血压的长期水平。
:::

站立时，约 500–800 mL 血液积聚在腿部和腹部。静脉回流、每搏输出量和动脉压下降；压力感受器放电减少；心率加快，小动脉和静脉收缩，这一切在几次心跳之内完成。当这一过程失效时就发生**直立性（体位性）低血压**：站立 3 分钟内收缩压下降至少 20 mmHg，或舒张压下降至少 10 mmHg。常见原因有血容量不足、药物（降压药、利尿剂、α 受体阻滞剂、硝酸酯类、抗精神病药、左旋多巴）以及自主神经功能衰竭，例如糖尿病或帕金森病。**血管迷走性晕厥**是相反的一种失调：一种反常反射，常由久站、疼痛或情绪诱发，撤除交感张力并增加迷走张力，使血压和心率同时下降。

其他反射也参与其中。心房和大静脉中的**心肺感受器**感受充盈程度。颈动脉体和主动脉体中的**外周化学感受器**受缺氧刺激时增加交感活动。**库欣反射（Cushing 反射）**是对颅内压升高的反应：脑缺血触发强烈的交感性血管收缩，由此产生的高血压又触发压力感受器反射性心动过缓。头部外伤患者出现高血压伴心动过缓和呼吸不规则，是晚期的危险征象。

::: definition 肾素-血管紧张素-醛固酮系统 {#def-raas}
**肾素**由肾脏入球小动脉的球旁细胞释放，受三种信号刺激：肾灌注压降低、到达**致密斑**的氯化钠减少，以及经 β1 肾上腺素受体的交感刺激。肾素把（来自肝脏的）血管紧张素原裂解为血管紧张素 Ⅰ，后者主要在肺内皮由**血管紧张素转换酶（ACE）**转化为**血管紧张素 Ⅱ**。血管紧张素 Ⅱ 作用于 AT1 受体：

- 收缩小动脉；
- 刺激肾上腺皮质释放**醛固酮**，醛固酮增加集合管对钠的重吸收（和钾的排泄）；
- 增加近端小管对钠的重吸收；
- 收缩出球小动脉，在肾灌注下降时维持肾小球滤过；
- 刺激口渴和抗利尿激素（血管升压素）的释放；
- 长期促进心脏和血管的重构与纤维化。

ACE 还降解缓激肽，这就是为什么 ACE 抑制剂会引起干咳，并在少数情况下引起血管性水肿。
:::

其他激素使这一图景更完整。**抗利尿激素**在血浆渗透压升高和血容量大幅下降时释放，保留水分，高浓度时还收缩血管。**利钠肽**（心房利钠肽和 B 型利钠肽）在心房和心室受牵拉时释放，促进钠排泄和血管扩张；B 型利钠肽被用作心力衰竭的血液检查（[[cardiovascular/heart-failure]]）。

::: theorem 压力性利钠与血压的长期水平 {#thm-natriuresis}
在数天到数周的时间尺度上，动脉压由肾脏对钠和水的处理决定。肾灌注压升高使钠和水的排泄增加（**压力性利钠**），减少细胞外液量和心输出量，直到压力回到摄入等于排出的水平。因此，持续性高血压必然意味着这一关系发生了移位，使肾脏需要更高的压力才能排出每日的钠负荷。
:::

::: proof
假设压力升高而盐摄入不变。肾脏排出的钠多于摄入的钠，细胞外液和血浆容量缩小，静脉回流和心输出量下降，压力回落。这一过程会持续，直到排出再次等于摄入，而这只有在原来的压力下才会发生。由于该系统会一直起作用直到误差为零，用工程学的术语说，它具有"无限增益"。相反，压力感受器反射会重调，留下残余误差。

这就是为什么许多高血压的病因作用于肾脏：醛固酮过多、肾动脉狭窄、慢性肾脏病，以及肾小管钠重吸收增加的遗传综合征。这也是为什么利尿剂——帮助肾脏在较低压力下排钠——是有效的降压药（[[cardiovascular/hypertension]]）。
:::

::: example 站立时头晕 {#ex-ortho}
一位 68 岁男性患 2 型糖尿病 20 年，伴周围神经病变，每天早上起床时感到头晕。卧位血压 148/84 mmHg，脉搏 76 次/分；站立 3 分钟后血压 112/70 mmHg，脉搏 78 次/分。解读这些读数并解释其机制。

::: solution
站立 3 分钟内他的收缩压下降 36 mmHg，舒张压下降 14 mmHg，符合**直立性低血压**的定义。

关键特征是他的心率几乎不变（76 至 78）。在血容量不足或药物引起的血管扩张中，压力感受器反射完好，因此血压下降时心率会明显加快。血压下降**而无代偿性心动过速**，提示反射弧本身失效：在本例为**糖尿病自主神经病变**，它损害了至血管和心脏的交感传出纤维（常常迷走神经纤维也受累）。

他的卧位高血压说明了自主神经功能衰竭处理的难处：降低卧位血压的治疗会加重站立时的症状。处理方案由他和医生共同决定，首先是审查降低血压或导致容量不足的药物，缓慢起身，足够的液体摄入，以及加压袜等物理措施；升高站立血压的药物属于专科选择。
:::
:::

::: quiz
健康人突然站起。数秒内压力感受器活动和自主神经传出会发生什么变化？
- [ ] 压力感受器放电增加；迷走传出增加
- [x] 压力感受器放电减少；交感传出增加，迷走传出减少
- [ ] 压力感受器放电减少；数秒内的主要反应是肾素释放
- [ ] 压力感受器放电不变，因为脑血流自身调节起了代偿作用
::: solution
站立使血液积聚在腿部，静脉回流和每搏输出量下降，动脉压短暂下降。颈动脉和主动脉压力感受器放电**减少**，因此延髓**增加交感**传出（心率、收缩力、小动脉和静脉收缩）并**减少迷走**传出。肾素释放确实会增加，但它在数分钟到数小时内起作用，而不是数秒。脑血流自身调节保护脑血流，但并不能阻止体循环压力下降。
:::
:::

## 循环性休克

**休克**是循环不能向组织输送足够的氧以满足其需要。低血压常见但并非必需：代偿可以在灌注已经不足时维持血压。灌注不良的体征包括四肢冰凉、毛细血管再充盈缓慢、意识模糊、尿量减少和乳酸升高。休克按机制分类，每种机制在[[#eq-map]]的各变量上都有特征性的模式。

| 类型 | 常见原因 | 心输出量 | 外周阻力 | 静脉压 |
|---|---|---|---|---|
| 低血容量性 | 出血、呕吐和腹泻、烧伤 | 低 | 高 | 低 |
| 心源性 | 心肌梗死、心律失常、瓣膜衰竭 | 低 | 高 | 高 |
| 梗阻性 | 心脏压塞、大面积肺栓塞、张力性气胸 | 低 | 高 | 高 |
| 分布性 | 脓毒症、严重过敏反应、脊髓损伤 | 正常或高（补液后） | 低 | 低或正常 |

低血容量性、心源性和梗阻性休克都表现为低输出伴代偿性血管收缩，因此皮肤冰冷苍白。分布性休克是阻力的衰竭：血管扩张，因此至少在早期皮肤可能是温暖的。在胸段中部以上的脊髓损伤中，交感传出丧失，因此低血压伴有心动过缓。各类休克的处理原则见[[emergency-critical-care/shock-fluids]]。

::: example 两位低血压患者 {#ex-shock}
两位患者血压均为 80/45 mmHg。患者 A，34 岁，皮肤温暖潮红，脉搏洪大，124 次/分，体温 39.4 °C，JVP 低；她患有尿路感染。患者 B，70 岁，皮肤湿冷，脉搏细弱，118 次/分，JVP 升高，双肺底湿啰音；他已胸痛四小时。对每种休克进行分类，并用$MAP = CO \times TPR$解释各项发现。

::: solution
**患者 A：分布性（脓毒性）休克。** 炎症介质和一氧化氮使小动脉扩张，因此 **TPR 低**。心输出量正常或偏高（脉搏洪大、心动过速、皮肤温暖），但不足以维持 MAP。静脉扩张和毛细血管渗漏也减少静脉回流，因此 JVP 低，她通常需要补液，并需要血管加压药恢复阻力。

**患者 B：心源性休克**，可能由大面积心肌梗死引起。由于左心室衰竭，**心输出量低**。交感反应使 **TPR** 升高（皮肤湿冷、脉搏细弱），但不能完全恢复血压，还增加衰竭心脏的负担。逆向压力使 JVP 升高并引起肺水肿（湿啰音）。大量补液会加重水肿；治疗针对病因（紧急冠状动脉再灌注）并支持泵功能。

同样的血压，相反的血流动力学模式：这就是为什么检查皮肤、脉搏和静脉压与袖带读数同样重要。
:::
:::

::: warning 血压正常并不能排除休克
代偿可以在器官血流不足时维持动脉压正常。年轻人失血可达血容量的约 30% 而收缩压仍不下降，因为心率加快和血管收缩起了代偿作用。老年人和服用 β 受体阻滞剂的人可能根本不出现心动过速。要寻找灌注不良的体征（毛细血管再充盈、精神状态、尿量、乳酸），不要被一次正常读数所安慰。
:::

::: history
1733 年，黑尔斯（Stephen Hales）描述了将一根黄铜管插入马的动脉、并接上一根高玻璃管的实验：血液上升约八英尺，并随每次心跳起落，这是第一次测量动脉压。19 世纪 30 至 40 年代，在巴黎行医的泊肃叶（Jean Poiseuille）为理解血流研究了细玻璃管中的流动，推导出流量与半径四次方的关系。1896 年，斯塔林（Ernest Starling）描述了毛细血管壁两侧静水压与蛋白渗透压的平衡。1898 年，蒂格斯泰特（Robert Tigerstedt）和贝里曼（Per Bergman）报告兔肾提取物可升高血压，并将其活性物质命名为肾素。里瓦-罗奇（Scipione Riva-Rocci）的臂袖带（1896）和科罗特科夫（Nikolai Korotkoff）对其下方声音的描述（1905）使常规血压测量成为可能。20 世纪下半叶，盖顿（Arthur Guyton）及其同事建立了循环调控的定量模型，把肾脏置于长期调节的中心。
:::

## 后续内容

这些原理贯穿整个课程。高血压（[[cardiovascular/hypertension]]）是本章所述长期调节的紊乱。心力衰竭的低输出和淤血状态（[[cardiovascular/heart-failure]]）可以用同样的方程解释，休克的循环管理也是如此，见[[emergency-critical-care/shock-fluids]]。自主神经系统见[[physiology/autonomic-nervous-system]]，体液分区见[[physiology/homeostasis-body-fluids]]，肾脏对钠的处理见[[renal/water-sodium]]。

::: summary
- 血流量等于压力差除以阻力；对体循环，$MAP - RAP = CO \times TPR$。
- 阻力与半径的四次方成反比（泊肃叶定律），因此小动脉张力控制血流和血压；静脉是容量血管，容纳约三分之二的血液。
- 平均动脉压约等于舒张压加三分之一脉压；随年龄增长的动脉僵硬使收缩压和脉压升高。
- 自身调节、代谢性血管扩张和内皮一氧化氮使局部血流与需求相匹配。
- Starling 原理解释水肿：毛细血管压升高、胶体渗透压降低、通透性增加或淋巴阻塞。
- 压力感受器反射在数秒内缓冲血压但会重调；肾素-血管紧张素-醛固酮系统和 ADH 在数分钟到数小时内起作用；肾脏的压力性利钠决定长期水平。
- 直立性低血压指站立 3 分钟内收缩压下降至少 20 mmHg 或舒张压下降至少 10 mmHg；心率不增加提示自主神经功能衰竭。
- 休克是组织氧输送不足：低血容量性、心源性、梗阻性或分布性，各有典型的血流动力学模式。
:::

## 习题

::: exercise 平均动脉压 {level=1 check="110"}
用舒张压加三分之一脉压，估算血压 150/90 mmHg 时的平均动脉压（mmHg，精确值）。
::: solution
脉压为$150 - 90 = 60$ mmHg。$MAP \approx 90 + 60/3 =$ **110 mmHg**。
:::
:::

::: exercise 半径减半 {level=1 check="6.25"}
根据泊肃叶定律，如果小动脉半径减半而其两端压力不变，剩余血流量为原来的百分之几（精确值）？
::: solution
阻力与$1/r^4$成正比，因此半径减半使阻力乘以$2^4 = 16$。血流量变为原来的$1/16$，即 **6.25%**。
:::
:::

::: exercise 反射的哪一环？ {level=1}
对下列每种情况，说明压力感受器反射弧是否完好，以及受影响的是哪一部分：(a) 出血患者，脉搏 130 次/分；(b) 自主神经病变患者，站立时血压下降而脉搏不变；(c) 服用 β 受体阻滞剂者，站立时血压下降，脉搏略有加快。
::: solution
(a) **完好**：血压下降被感知，交感反应产生心动过速和血管收缩。

(b) **传出支受损**：至心脏和血管的自主神经不能作出反应，因此既无心动过速，也无足够的血管收缩。

(c) **反射完好，但效应器被阻断**：交感信号已发出，但心脏的 β1 肾上腺素受体被部分阻断，因此心率反应减弱。
:::
:::

::: exercise 外周阻力 {level=2 check="16"}
某患者平均动脉压 100 mmHg，右心房压 4 mmHg，心输出量 6 L/min。计算总外周阻力（mmHg·min/L，精确值）。
::: solution
$TPR = (100 - 4)/6 =$ **16 mmHg·min/L**，相当于 1280 dyn·s·cm⁻⁵。
:::
:::

::: exercise 半径的小变化 {level=2 check="round(100*(1.1^4-1))"}
一种血管扩张剂使某血管床小动脉的半径增加 10%。根据泊肃叶定律，在灌注压不变时，血流量增加百分之几？四舍五入到整数百分比。
::: solution
血流量与$r^4$成正比，因此乘以$1.1^4 = 1.4641$。血流量增加 **46%**。直径的适度变化产生血流量的大幅变化，这就是小动脉张力调控如此有力的原因。
:::
:::

::: exercise 三种肿胀 {level=2}
用 Starling 原理解释下列各项为何引起水肿，以及你预期在检查或化验中发现什么：(a) 肾病综合征；(b) 右心衰竭；(c) 蜂蜇。
::: solution
(a) **肾病综合征**：大量蛋白尿使血浆白蛋白降低，从而使血浆胶体渗透压（$\pi_c$）降低，削弱了把液体保留在毛细血管内的力量；肾脏钠潴留也起作用。预期见到全身水肿，常在早晨表现为眼睑水肿，尿试纸大量蛋白尿，血清白蛋白低；除非有液体过负荷，JVP 不高。

(b) **右心衰竭**：体循环静脉压升高逆传至毛细血管，使$P_c$升高。预期见到 JVP 升高、下垂部位凹陷性水肿、肝大，可能有腹水。

(c) **蜂蜇**：组胺等介质增加毛细血管通透性（$K_f$升高、$\sigma$降低），使蛋白和液体渗出；小动脉扩张也使$P_c$升高。预期见到局部红、热和肿胀；如出现全身反应伴低血压或气道肿胀，则为严重过敏反应（[[emergency-critical-care/anaphylaxis]]）。
:::
:::

::: exercise ACE 抑制剂与肾脏 {level=2}
解释为什么 ACE 抑制剂 (a) 能降低血压，(b) 可引起干咳，(c) 在双侧肾动脉狭窄患者中可引起肾小球滤过的急性下降。
::: solution
(a) 它们减少血管紧张素 Ⅱ，因此小动脉扩张（TPR 降低）、醛固酮减少（钠潴留减少、容量降低），并减轻血管紧张素 Ⅱ 的长期重构作用。

(b) ACE 还降解**缓激肽**。抑制 ACE 使缓激肽在气道中积聚，部分人因此出现干咳；血管紧张素受体阻滞剂不影响缓激肽，是通常的替代药物。

(c) 当狭窄使肾灌注压降低时，肾小球滤过依赖血管紧张素 Ⅱ 收缩**出球小动脉**，以维持肾小球毛细血管压。去除血管紧张素 Ⅱ 使出球小动脉扩张，肾小球内压下降，滤过减少。这就是为什么在开始使用这类药物前后都要检查肌酐和血钾。
:::
:::

::: exercise 降不下来的血压 {level=3}
一位 49 岁女性尽管服用三种药物，血压仍为 168/104 mmHg。一位住院医师认为她的压力感受器"一定是设定得太高了"，这是病因。用本章的原理解释为什么长期问题更可能在肾脏，并列出通过肾脏钠处理起作用的高血压病因。
::: hint
想一想血压升高数天后压力感受器反射会怎样，以及哪个控制系统会一直起作用直到误差为零。
:::
::: solution
压力感受器反射在数天内重调到持续的压力水平，因此它缓冲短期波动，但不决定数周内血压围绕其调节的水平。如果压力感受器反射是唯一的异常，肾脏会通过**压力性利钠**纠正血压：任何高于钠排出等于摄入时的压力，都会导致钠的净丢失、容量和心输出量下降，直到压力回落。因此，血压的持续升高意味着肾脏的压力-利钠关系已经移位，使其需要更高的压力才能排出每日的钠负荷。（压力感受器反射可能有一定作用，压力感受器激活装置也已有研究，但它们是通过改变交感传出——包括至肾脏的传出——起作用的。）

通过肾脏钠处理起作用的病因包括：
- **原发性醛固酮增多症**（醛固酮过多增加集合管钠重吸收；常伴低钾）；
- **肾动脉狭窄**（激活肾素-血管紧张素系统）；
- **慢性肾脏病**（肾单位减少、排泄受损）；
- 盐敏感者的**高盐摄入**，以及引起钠潴留的药物（非甾体抗炎药、糖皮质激素、甘草）；
- 罕见的遗传综合征，如 Liddle 综合征（上皮钠通道过度活跃）。

一位 49 岁女性的顽固性高血压还需要检查依从性、测量技术、白大衣效应、饮酒、睡眠呼吸暂停和继发性病因（[[cardiovascular/hypertension]]）。利尿剂，包括在适当情况下使用的小剂量螺内酯，正是针对这一机制。
:::
