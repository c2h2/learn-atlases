动脉压是脑干几乎凌驾一切变量之上守卫的产品——**压力=心输出量×体循环阻力**，输出是前两章的业务、阻力是细动脉半径四次方的算术。围绕这个乘积，身体堆叠三个时间尺度：秒的减压反射、分钟到天的肾素-血管紧张素-醛固酮与血管加压素系统、天到周的肾压力-钠利尿——最后是长期设定点、也是原发性高血压终归是肾压力重设病的原因。休克是供应的失败，其四种机制（泵、管、容量与分布）就是把同一生理倒过来读。

本章讲述阻力及其调控、压力控制的三个时间尺度、水肿与毛细血管Starling力、作为生理分类的休克。

## 阻力：作为油门的细动脉

::: definition 体循环总阻力与其局部调控 {#def-tpr}
体循环每个毛细血管床约20 mmHg的压降主要在**细动脉**谈判——这种阻力血管的张力同时设定血压与器官灌注压、带Poiseuille的四次方半径依赖（半径变16%即流量翻倍或减半：[[physiology/homeostasis-body-fluids]]与[[anatomy/thorax]]的x⁴主题）与串联布置、大规模并联的网络（体循环总阻力=80×(MAP−右房压）/心输出量、即导管室仍在沿用约定的约900–1200 dyn·s/cm⁵。功能所需处局部调控当家：**代谢性与活动性充血**（工作中组织的腺苷、K⁺、CO₂、H⁺、乳酸、前列腺素与剪切产生的一氧化氮——冠脉、骨骼肌与餐后肠血流；腺苷的冠脉角色即[[cardiovascular/coronary-artery-disease]]腺苷/双嘧达莫负荷试验的基础）、**肌源性张力**（对牵张的Bayliss收缩——自身调节的肌肉臂、肾与脑尤其）、**剪切介导的内皮一氧化氮**（流量介导的舒张——内皮作为流量感受器、其障碍是血管病的最早病变）、及**交感性**（α1收缩；肌肉的β2与胆碱能舒张；[[physiology/integrative-physiology]]运动预算的肌泵与静脉张力）。脑与冠脉床缴最高的自身调节税——平均压约60–150 mmHg上压力稳定的流、慢性高血压时右移（高血压患者容忍更少低血压、也要求更少的降压原因）——而皮肤跑相反的程序，献给体温调节（[[physiology/integrative-physiology]]的热预算）与休克时的α收缩。
:::

## 三个时间尺度，一个变量

::: definition 秒到天：减压反射、激素、肾 {#def-timescales}
**秒——减压反射**（[[physiology/autonomic-nervous-system]]是第一文本）：颈动脉与主动脉牵张→孤束核→尾腹外侧延髓、交感缩血管与心脏驱动及迷走释放、工作点附近高增益、数日内重设（高血压者被捍卫的海拔）。**分钟到天——内分泌升压系统**：**肾素-血管紧张素-醛固酮系统**（近球细胞肾素因灌注压下降释放——肾的减压感受器——对β1交感驱动与致密斑远端小管低钠；血管紧张素II作缩血管剂、醛固酮刺激剂、中枢渴感与交感促进剂、及心肾重塑者；ACE作为同时降解缓激肽的激肽酶——ACE抑制剂药理的咳嗽与血管性水肿）加**血管加压素**（[[renal/water-sodium]]的高剂量V1升压臂），加**毛细血管再充盈与应激容量动员**（静脉储备）。**天到周——压力-钠利尿**：肾灌注压陡驱动排钠（肾自身的工作曲线、原发性高血压时增益降低、设定点抬高——Guyton的综合、及肾单位丢失、肥胖相关钠潴留与单基因小管综合征——Liddle过度吸收的ENaC、[[renal/potassium-calcium-phosphate]]的Gordon与Gitelman与Bartter反例——重设全身压力）；这条长环反馈的慢性阻断（ACE抑制剂、ARB、利尿剂、醛固酮拮抗剂）即[[cardiovascular/hypertension]]的药理、而其肾动脉去神经的重设尝试是本器械时代曲线可塑性的教训。时间尺度在临床上嵌套：**高血压急症是减压反射与脑自身调节在右移曲线之上失败（[[nervous-system/stroke]]邻域的视盘水肿与脑病）；透析患者的滤过中低血压是超滤速率跑赢再充盈与反射；移植后、去肾神经的高血压与四肢瘫者失去的交感张力各是一个时间尺度被减去。**
:::

::: example 踝部肿胀之问 {#ex-oedema}
68岁患者凹陷性踝水肿；从一个方程出发，考虑它能产生的五种机制，各配一种疾病。
::: solution
**毛细血管Starling方程**——滤过=K_f×[(P_c−P_i)−σ(π_c−π_i)]——组织起整个鉴别：**毛细血管压升高**（心衰抬高的右房与静脉压后传；下垂与静脉功能不全、妊娠子宫的机械阻断；[[cardiovascular/cardiac-cycle]]高输出练习的动静脉瘘下游高压）、**血浆胶体渗透压降低**（肾病、肝硬化、营养不良的低白蛋白——π_c下降、重吸收失败）、**毛细血管通透性升高**（脓毒症、烧伤、炎症、血管性水肿——σ项塌陷、蛋白外漏拖水；炎症的水肿、局部而疼痛）、**间质压升高/淋巴 大范围阻塞**（淋巴水肿——术后、丝虫、恶性；凹陷不能压出的非凹陷、富蛋白间质及其喜爱的感染——蜂窝组织炎环），及**淋巴溢流**（任何剧烈滤过负荷超过泵力、高输出衰竭与妊娠晚期水肿失代偿的原因）。床旁分类器——凹陷对非凹陷、对称对单侧、疼痛对无痛、伴颈静脉升高与肺部体征与否——读出哪一项移动，治疗跟随那一项：**压力用利尿剂与盐、胶体用病因导向的白蛋白经济学（肾病与肝硬化患者的白蛋白输注加利尿剂协同——及试验的谨慎）、管道用压迫与淋巴科、毛细血管漏用炎症自身的治疗。**本章主题的缩影：一个教科书方程读对了，就是一张鉴别诊断表。
:::

::: example 头痛与水肿的视盘 {#ex-hturg}
47岁未治疗高血压患者一天搏动性头痛、视物模糊与呕吐；门诊血压232/138、眼底视盘水肿伴火焰状出血、肌酐180（基线110）、尿蛋白+++。
::: solution
**高血压急症（恶性/急进性高血压）**——脑与肾的自身调节天花板被突破：细动脉被顶过肌源性极限进入**突破血管舒张与纤维素样坏死**（病理教科书的增生性细动脉炎与“蚤咬肾”、[[#def-timescales]]右移曲线的脑水肿与视盘水肿、视网膜出血与蛋白尿性肾损伤——使它区别于“数字很大”的另一种病的靶器官损害）。治疗生理很精细：**头数小时内平均压降幅不超过约四分之一（右移的脑肾自身调节会在“正常化”的压力下灌注不足——分水岭梗死与依赖透析的肾是仓促的代价），用可滴定的静脉药（拉贝洛尔的α/β双阻、纯后负荷药、尼卡地平类、硝普钠的老旧可靠及其氰化物警诫与颅内压警诫）**入监护床，随后数日内口服降阶梯、依从性与继发原因检查（[[cardiovascular/hypertension]]与[[endocrine/adrenal]]的肾动脉、醛固酮与嗜铬细胞瘤之问）。改变药物的两个变异：**子痫（镁、拉贝洛尔/肼屈嗪、分娩——[[obstetrics-gynaecology/pregnancy-antenatal]]）与嗜铬细胞瘤（[[physiology/autonomic-nervous-system]]的先α后β诫命）**——而给慢性定级的眼底（多年的细动脉狭窄与动静脉交叉压迹、数周视盘与出血）是眼底镜在读本章的时间尺度史。

::: example 两个脉、一个病变 {#ex-pulse-pressure}
30岁注射毒品使用者三天发热气促；脉110、血压118/72——脉压正常；62岁已知二叶瓣患者同一病变慢性存在、168/44伴颈动脉陷落脉。
::: solution
两人都是**主动脉瓣反流**；分别是**顺应性、不是严重度**。急性重度AR（感染性心内膜炎穿孔的瓣叶）卸载进**大小正常而不顺应的心室**：左室舒张末压冲向心房与肺毛细血管压（爆发性水肿、[[#def-shock]]的梗阻与泵交界的心源性休克）、舒张期杂音可能短或无（主动脉与左室舒张压快速均衡——题干所示偏窄脉压的临床陷阱），治疗是**急诊手术、在血培养与超声病变评估之后（[[cardiovascular/valve-congenital-disease]]的心内膜炎与急性AR节）**。慢性AR（扩张、顺应、离心性肥厚的心室——[[physiology/muscle]]的腔级适应）耐受反流量多年、经**宽脉压与周围体征**揭晓：动脉树的大每搏量（水冲脉、Quincke与Musset与Traube与de Musset征的冠名巡游、全是同一脉压算术加高动力循环），直到心室代偿耗尽、射血分数与运动耐量宣布手术时机——**指南阈值（射血分数与收缩末内径）是顺应心室的出口标志、读自[[cardiovascular/cardiac-cycle]]的压力-容积环**。一个病变、两个血流动力学故事、及上一练习的脉压商作为判别器。

## 休克：四机制分类

::: definition 供应、需求与四种休克 {#def-shock}
休克是**组织氧输送不足**（DO₂=心输出量×动脉含量——Fick方程（[[physiology/integrative-physiology]]）变成急诊），靠摄取失败与交感溢出的标志识别（乳酸、毛细血管再充盈、尿量、神志、碱缺失与中心静脉氧饱和度）、远早于血压下降——**低血压除神经源性与部分梗阻型外是晚征。**分类是机械的、而[[#def-timescales]]的动静脉曲线语言与[[cardiovascular/cardiac-cycle]]的Guyton交叉图完成区分：**低血容量性**（失血、烧伤、胃肠炎、胰腺炎、利尿剂与肾上腺危象的钠丢失——应激容量没了：心动过速、血管收缩、少尿、窄脉压、液体有反应者，其抬高的充盈压需要[[blood/transfusion]]与[[emergency-critical-care/acute-assessment]]的输血与止血）；**心源性**（泵衰竭——梗死、心肌炎，及梗阻表亲：填塞与张力性气胸与大栓塞、各有自己的生理与体征：[[cardiovascular/cardiac-cycle]]示例的填塞、[[respiratory/respiratory-failure]]胸部的颈静脉与气管、[[respiratory/interstitial-vascular-disease]]的右心应变超声）；**分布性**（血管麻痹——脓毒症的细胞因子与一氧化氮与微循环关闭（暖休克肢）、过敏性休克的肥大细胞组胺与静脉池聚（[[blood/transfusion]]的过敏孪生）、及神经源性/延髓交感崩溃伴把其与床旁失血分开的悖论性**心动过缓**与暖肢）——早期高动力高输出状态、其治疗是对血管容量丢失的儿茶酚胺与容量恢复（去甲肾上腺素的α填满非应激容量水库；[[infectious-diseases/fever-sepsis]]），及**梗阻性**（填塞、张力性气胸、血栓栓塞——腔与胸之间被捏住的路径、中心静脉压抬高而输出被饿死的生理）。代偿跟随时间尺度（减压反射分钟、肾素-血管紧张素与加压素小时、肾盐天——而应激容量丢失的毛细血管液体转移即跨毛细血管再充盈在一小时内运行、是失血患者早期血红蛋白两次说谎的原因：稀释现形、再充盈在路上）。监测工具是同一曲线：**液体反应性问题即Starling斜率（动态指标——脉压变异、被动抬腿）、液体耐受性问题即EDPVR（莫要填充僵硬或衰竭的心室）——[[cardiovascular/cardiac-cycle]]的练习推广到每张复苏床位**（[[emergency-critical-care/acute-assessment]]与重症章节接管方案；生理考点是**清除的乳酸、温暖的肢端与尿量证明复苏、而正常化的血压什么也不证明**）。
:::

::: example 糖尿病患者的体位性下降 {#ex-ortho}
59岁长期糖尿病伴早期视网膜病变患者，在车站站立时近晕；卧位血压138/82、脉78；站立三分钟96/60、脉82。
::: solution
**神经源性直立性低血压**——减压反射弧（[[physiology/autonomic-nervous-system]]）被长度依赖的自主神经病摧毁：站立使约700 mL池积于腿与内脏床（[[physiology/integrative-physiology]]运动算术的倒放）、静脉回流与输出下降、而正常代偿（交感缩血管与迷走释放）**两臂皆失败——压力降≥20/10而脉搏不成比例上升（40 mmHg的下降配∆<15次/分是神经源性指纹）**。糖尿病背景补齐其余：并存的卧位高血压（去神经超敏与减压反射缓冲丢失——同章练习的治疗陷阱）、需排除的肾上腺与甲状腺贡献、容量与药物审计（前列腺症状用的α阻滞剂、利尿剂、SGLT2抑制剂的容量效应、神经病疼痛与情绪清单里的三环与抗精神病药——[[pharmacology/adverse-reactions]]）。管理是生理复原：**患者教育（缓慢起立、对抗动作、交叉双腿、夹紧臀肌）、卧位压允许时放宽盐与水（1–1.5 L快速容量技巧及其邻近去氨加压素的升压窗口）、压迫（长筒30–40 mmHg与腹带——静脉容量杠杆）、抬高床头睡眠（卧位高血压与夜间钠利尿的纠正）、及按机制用药：米多君（α1激动剂——直立时数前给药）、屈昔多巴（去甲肾上腺素前药）、吡斯的明（神经节增强——温和而位选的药）、氟氢可的松（其扩容药伴卧位高血压、低钾与踝水肿的代价——[[#ex-oedema]]Starling方程的贷方）**。该病例存在的规则：**在自主神经衰竭中，同一条肾与同一颗心在床的两端都表现糟糕——治站立的问题而别砸坏躺着的。**
:::

::: history
**Stephen Hales**用马肠线与铜管给母马颈动脉插管（1733——第一次动脉压、第一次循环的数学）、**Poiseuille**的毛细管流量定律与四次方半径、**Marey与Chauveau与Ludwig**19世纪的测压与记纹描记、及**Tigerstedt与Bergman**1898年发现肾提取物升血压——升压素/肾素线、其1930–40年代的纯化遇上**Goldblatt**的夹动脉高血压模型（两肾一夹实验使肾成为慢性压力的仲裁者、Guyton压力-钠利尿综合随后）、**Cannon**的急诊生理与**Selye**的应激三联（内分泌升压系统的整合框架）、**Wiggers**的失血性休克生理与**Blalock与Rich**的外科时代及其容量丢失分类。毛细血管一侧运行**Starling**1896年方程与**Drinker与Field**的淋巴证明、而现代休克文献——**Weil与Shubin**早期目标导向时代的血流动力学、1970年代重症先驱的多器官功能障碍综合征、2016年Sepsis-3围绕乳酸与灌注的重新定义——使本章老的四格分类成为每间复苏室的操作系统。
:::

## 通向何处

完整反射弧在[[physiology/autonomic-nervous-system]]；肾素-血管紧张素系统的肾半部在[[renal/water-sodium]]、其药物类别在抗高血压药理章节；高血压的临床管理在[[cardiovascular/hypertension]]；血管病的硬管后果在[[cardiovascular/vascular-disease]]；过敏性休克的生理在[[emergency-critical-care/anaphylaxis]]与[[immunology/hypersensitivity]]；脓毒症在[[infectious-diseases/fever-sepsis]]；填塞力学在[[cardiovascular/cardiac-cycle]]。

::: summary
- 动脉压等于输出乘阻力，而阻力四次方地住在细动脉——局部代谢物、肌源性、内皮与交感调控分配心输出量并捍卫压力。
- 控制在嵌套的时间尺度上运行——减压反射（秒）、肾素-血管紧张素-醛固酮与加压素（分钟到天）、肾压力-钠利尿（天）——而慢性高血压是肾设定点疾病、其反射与内分泌适应定义了治疗极限。
- 毛细血管壁的Starling力给出水肿的五项鉴别、把每个机制映射到一个治疗。
- 休克按泵、容量、分布与梗阻分类；灌注标志先于血压报警，而液体反应（Starling斜率）与液体耐受（EDPVR）是两个必须分开回答的问题。
- 自主神经衰竭与三个时间尺度的任何一环断裂，都把同一循环变成位置依赖、昼夜依赖与药物依赖的临床问题。
:::

## 练习

::: exercise 计算阻力 {level=1}
MAP 100、右房压5、心输出量5 L/min。用Wood单位与mmHg·min/L给出TPR，并预测交感风暴使阻力翻倍而输出不变时的新TPR（及新MAP）。
::: solution
TPR=(100−5)/5=**19 Wood单位≈19 mmHg·min/L**（×80=1520 dyn·s/cm⁵；注意全循环正常约15–20 Wood、含CVP减法）。输出不变而阻力翻倍则梯度翻倍：**MAP≈5+5×38=195**——这道算术显示纯缩血管药要在输出维持时升压、及升压药的剂量-压力曲线用于滴定而非正常化的原因；身体自己的版本（[[physiology/autonomic-nervous-system]]示例的嗜铬细胞瘤、高血压危象）是同一方程、肾上腺充当输液泵。
:::
:::

::: exercise 哪个反射臂 {level=1}
颈动脉窦按摩减慢心率；失血的减压反射部分经迷走退出恢复压力。用自主神经章节的链式语言指派传出臂（心与血管）及各突触的神经递质。
::: solution
传出：**心**——迷走（乙酰胆碱→窦房房室结的毒蕈碱M₂、其撤除升率的副交感刹车）与**交感**（去甲肾上腺素→β1率与力；肾上腺肾上腺素入血）；**血管**——交感肾上腺素能（去甲肾上腺素→α1细动脉收缩；[[physiology/autonomic-nervous-system]]的汗腺胆碱能例外与肌肉血管舒张臂）。失血时的卸载反应**两心肌臂同开加缩血管张力退出**，肾素-血管紧张素与加压素作[[#def-timescales]]的激素放大器——临床明珠：**颈动脉窦综合征（反射弧过度活跃——剃须与转头时的停搏与跌倒）、β阻滞剂对心臂的钝化、及前文练习中α阻滞剂少一臂的直立性低血压。**
:::
:::

::: exercise 窄脉压 {level=2}
用数学与生理解释为什么低血容量休克早期窄化脉压、而主动脉瓣反流与甲状腺毒症却使其增宽；各一个方程。
::: solution
脉压≈**每搏量/动脉顺应性**（加波反射时相）：失血缩小每搏量（Frank-Starling降支——MAP=CO×TPR的输出项下降、而代偿性α收缩**靠抬高舒张压**维持MAP：收缩压降、舒张压升、压窄），而**主动脉瓣反流与甲状腺毒症**增大每搏量（反流量加正常量、及高动力低阻力高输出状态）及/或降低阻力（β2与血管舒张代谢——收缩压保留而舒张压塌陷——[[cardiovascular/valve-congenital-disease]]的水冲脉（速搏脉）签名）。两者是同一商而分子相反、床旁脉压读数于是是超声前的血流动力学筛查：窄-缩血管-冷对宽-高动力-暖是休克分类的第一个分叉。
:::
:::

::: exercise 踝水肿、每项一行 {level=2}
为[[#ex-oedema]]的五种机制各给一个定位它的临床或实验室线索。
::: solution
**静脉压升高**——颈静脉升高与肝颈回流（衰竭）或深静脉阻塞的单侧饱满小腿（[[blood/thrombosis-anticoagulation]]）；**低胶体**——血清白蛋白（及肾病丢失的尿蛋白比值）；**毛细血管漏**——局部体征（红、热、痛——炎症）或脓毒症的分布性图像伴白蛋白下降与血细胞比容升高（血浆退入间质浓缩了细胞）；**淋巴阻塞**——非凹陷、足背Stemmer征、影像与病史（乳房切除与淋巴结野、丝虫）；**溢流状态**——妊娠、瘘流量与高输出数字。管理含义随定位而异（利尿剂响应的压力性水肿对利尿剂抵抗的富蛋白淋巴水肿——后者治疗是压迫与淋巴科、其感染预防是[[blood/haematopoiesis]]切脾邻近课程的青霉素与皮肤护理规则）。
:::
:::

::: exercise ACE抑制剂的三份工作 {level=2}
说出ACE抑制剂阻断或揭穿的血管紧张素II作用的三个臂，并从每个导出一个治疗用途与一个副作用。
::: solution
**缩血管（细动脉肌的AT₁）**——用途：高血压、心衰的后负荷减低；副作用：容量与肾素依赖者的首剂低血压（肾动脉狭窄、利尿剂与心衰的谨慎——出球小动脉张力下降，第二臂也阻它）。**醛固酮与钠处理**——用途：心梗后与心衰的重塑及降蛋白尿获益；副作用：**高钾血症**（[[renal/potassium-calcium-phosphate]]的醛固酮撤除、被保钾利尿剂、甲氧苄啶、NSAID与代盐叠加）。**缓激肽降解（ACE=激肽酶II）**——不是治疗臂而是副作用臂：**干咳与罕见血管性水肿**（ARB被设计的原因——受体阻断而不激肽蓄积——及脑啡肽酶抑制剂组合沙库巴曲沿同一通路ACE自带血管性水肿警诫的原因：[[cardiovascular/heart-failure]]的换药须清洗规则、药典重复的36小时窗口）。
:::
:::

::: exercise 读休克数字 {level=2}
三位ICU患者都乳酸4.5、去甲肾上腺素运行中。从下列指派可能的休克类别与下一检查：(a) CVP 4、脉压变异18%、肢端暖；(b) CVP 18、床旁超声左室小而高动力伴右室扩张隔弓左移；(c) CVP 16、全域运动减低EF 20%、肢端冷。
::: solution
**(a)分布性（脓毒症）休克**——低充盈压加**液体反应性（机械通气周期脉压变异>13%——[[#def-shock]]动态指数）**与暖的血管麻痹肢端：**液体（平衡晶体弹丸并重估）加一小时内血培养与抗菌药（[[infectious-diseases/fever-sepsis]]）**、去甲肾上腺素继续作容量血管的α填充。**(b)梗阻性——大面积肺栓塞**（CVP升高、右室扩张隔弓向左——[[cardiovascular/cardiac-cycle]]填塞逻辑的相互依赖、小而未充盈的左室）：**CT肺动脉造影或床旁血栓在途超声、按风险的溶栓/取栓，及积极补液加重隔弓的警诫**（[[respiratory/interstitial-vascular-disease]]的右室容量陷阱）。**(c)心源性**——高充盈压、低输出、缩血管冷肢：**正性肌力/升压平衡与病因的机械探查（缺血？心肌炎？瓣膜？）、超声心指数、及[[cardiovascular/heart-failure]]的升级阶梯（主动脉内球囊与经皮支持到移植与姑息）**——三个答案都读自同两条曲线（Guyton与Starling）的交点、本章不断向[[cardiovascular/cardiac-cycle]]借的那对。
:::
:::

::: exercise 透析患者的抽筋 {level=2}
血液透析患者在移除4升的最后一小时抽筋、头晕；机器血压曲线示进行性下降伴脉搏上升。解释超滤对再充盈失配的生理及能纠正的处方改动。
::: solution
**再充盈天花板**：超滤中血浆容量靠**跨毛细血管再充盈**维持、主要由**血浆胶体渗透压（[[#ex-oedema]]方程的π_c−π_i梯度、被低白蛋白饿着）**驱动、受毛细血管静水压下降对抗、上限约5–10 mL/kg/分；机器的血浆水移除跑赢再充盈时，血黏度上升、静脉回流与输出下降、减压反射（若糖尿病与尿毒症自主神经病还剩它）心动过速并缩血管——抽筋（肌肉与神经的低灌注）、哈欠、血压滑落。按机制的处方修正：**更长或分次治疗（更低mL/h）、透析液降温（血管运动增益）、钠与电导曲线描绘与米多君及降压药时机审查（透析前停服）、生物阻抗或超声的干体重重估（过干的“干体重”——真实体重被水肿时代设定的无尿患者）、胶体受限处的白蛋白、及超滤速率上限作为算术答案——再充盈方程读成处方、及最初把间质灌满的同一Starling逻辑的反向。**
:::

::: exercise 设计降压方案 {level=3}
64岁2型糖尿病、CKD 3期（eGFR 40、蛋白尿）、诊室血压162/86、除早期细动脉狭窄外眼底正常。用本章的时间尺度与曲线构建药物方案、附监测规则与每行理由。
::: solution
**确认与分期**：动态或家庭监测（[[epidemiology-ebm/diagnostic-tests]]的白大衣与隐匿性高血压算术——诊室数字是筛查样本、靶标是诊室外均值）、眼底与心电图与尿与肌酐电解质钙血脂HbA1c基线、及只在生理提示处做继发性高血压筛查（顽固、早发、无缘低钾——醛固酮/肾素比值与爆发性肺水肿表型的肾动脉多普勒——[[renal/chronic-kidney-disease]]、[[endocrine/adrenal]]）。**按机制的骨架**：**ACE抑制剂或ARB滴定至最大、强化降蛋白尿的出球臂效应（两肾、一个肾小球：画出球内压降低的出球小动脉舒张——起始可接受的≤30%肌酐上升、监测钾——[[renal/water-sodium]]与[[renal/potassium-calcium-phosphate]]规则）**，加**二氢吡啶类钙通道阻滞剂（[[#def-tpr]]的细动脉油门、对低肾素、盐处理、老年与黑人表型强效；其踝水肿是毛细血管前扩张剂的Starling后果而非过敏、加ACE/ARB缓解而非停药）**，及**噻嗪样药（吲达帕胺、氯噻酮——容量乘阻力的杠杆、有结局试验、及bendroflumethiazide较弱的证据基础与eGFR约30的噻嗪抵抗阈值、以下由袢利尿剂或美托拉宗增强策略接班）**。**四线**：**螺内酯（顽固高血压的PATHWAY-2赢家——醛固酮组分逻辑、带钾与男性乳腺发育警诫及eGFR谨慎）**、器械与肾去神经谈话只在试验与顽固中心。**监测与靶值**：家庭读数文化（数字属于患者）、每年钾/肌酐与容量不足时停四联的病假日规则（SADMANS教学——脱水时停ACE抑制剂、利尿剂、二甲双胍、ARB、SGLT2抑制剂与NSAID，而用激素者加倍而非停——[[renal/acute-kidney-injury]]与[[endocrine/diabetes]]共享该卡）、控制后的减药谈话、及生活方式行（盐的肾设定点效应、富钾饮食及其肾谨慎、体重的钠利尿、酒精、运动的自主增益）作为药物以药理执行生理（[[cardiovascular/hypertension]]的指南表、恰建在这种机制-人群匹配上）。
:::
