心脏是并排相连的两个泵。右心接受来自全身的血液，以较低压力将其送经肺；左心接受来自肺的血液，以较高压力将其送往全身。每一次心跳都遵循同样的顺序：电激动、收缩、瓣膜活动和舒张。这一顺序就是**心动周期**。一旦在脑中建立起它的图像，床旁体格检查的大部分内容便顺理成章：心音是瓣膜关闭的声音，颈静脉搏动是从颈部看到的右心房，动脉搏动则是在腕部触到的左心室射血。

本章介绍心脏作为泵的结构、心动周期的各个时相、心音与静脉搏动、心输出量及控制它的四个因素，以及压力-容积环——一张能够显示心室工作状况的图。

## 心脏作为泵

心脏有四个腔。两个**心房**壁薄，是接受血液的腔；两个**心室**是泵。四个瓣膜保证血液单向流动：

- 右心房与右心室之间的**三尖瓣**，以及左心房与左心室之间的**二尖瓣**。它们是**房室瓣**。瓣叶由**腱索**系于心室壁上的**乳头肌**，在心室收缩时防止瓣叶翻向心房；
- 右心室出口的**肺动脉瓣**和左心室出口的**主动脉瓣**。它们是**半月瓣**，各有三个瓣尖，没有腱索。

瓣膜是被动的。当瓣膜后方的压力高于前方时它开放，压力梯度反转时它关闭。因此，心动周期中的每一个瓣膜事件都可以由瓣膜两侧的压力推知。

左心室壁的厚度约为右心室的三倍，因为它产生的压力约为右心室的五倍。在任何持续的时间段内，两个心室每分钟泵出的血量相同；否则，几分钟之内血液就会在肺或体循环中积聚。心肌本身由冠状动脉供血，冠状动脉主要在舒张期充盈，此时收缩的心肌不再挤压它们。这一细节稍后很重要：心率加快会缩短舒张期，从而缩短冠状动脉血流可用的时间（[[cardiovascular/coronary-artery-disease]]）。大体解剖见[[anatomy/thorax]]，收缩的细胞学基础见[[physiology/muscle]]。

健康成人静息时的典型压力（mmHg）值得记住，因为异常值要与之对照才能识别：

| 部位 | 收缩压/舒张压（平均压） |
|---|---|
| 右心房 | 平均 0–6 |
| 右心室 | 15–30 / 0–6 |
| 肺动脉 | 15–30 / 6–15（平均 10–20） |
| 肺毛细血管楔压（≈左心房压） | 平均 6–12 |
| 左心室 | 100–140 / 3–12 |
| 主动脉 | 100–140 / 60–90（平均 70–105） |

## 心动周期的时相 {#sec-phases}

::: definition 心动周期 {#def-phases}
**心动周期**是一次心跳中各事件的顺序。**收缩期**是心室收缩的时期；**舒张期**是心室舒张和充盈的时期。左心室的心动周期分为四个时相：

1. **等容收缩期。** 心室开始收缩，其压力升至高于心房压，二尖瓣关闭；但此时压力仍低于主动脉压，主动脉瓣保持关闭。两个瓣膜都关闭，容积不变。
2. **射血期。** 当心室压超过主动脉压（约 80 mmHg）时，主动脉瓣开放，血液射出，先快后慢。
3. **等容舒张期。** 心室舒张，其压力降至低于主动脉压，主动脉瓣关闭。两个瓣膜再次都关闭，容积恒定。
4. **充盈期。** 当心室压降至低于心房压时，二尖瓣开放。充盈起初很快（**快速充盈期**），舒张中期减慢（**减慢充盈期**），最后由**心房收缩**再增加一部分充盈。

充盈结束时心室内的容积为**舒张末期容积（EDV）**；射血后剩余的容积为**收缩末期容积（ESV）**。**每搏输出量**为$SV = EDV - ESV$，**射血分数**为$EF = SV/EDV$。
:::

健康成人静息时，EDV 约 120 mL，ESV 约 50 mL，因此每搏输出量约 70 mL，射血分数约 58%。超声心动图上，正常左心室射血分数通常定为 50% 或以上；40% 或以下则界定为射血分数降低的心力衰竭（[[cardiovascular/heart-failure]]）。

右心以较低的压力经历同样的四个时相，与左心略有先后。在年轻人中，静息时心房收缩约贡献心室充盈的五分之一；在老年人中贡献更大，因为他们的心室舒张缓慢，舒张早期充盈较少。这就是为什么心房颤动——它消除了协调的心房收缩——的发生可以使一位心室僵硬的老年人出现呼吸困难。

时相长短随心率而变。心率 75 次/分时，一个心动周期持续 0.8 s，其中收缩期约 0.3 s，舒张期约 0.5 s。心率加快时，舒张期的缩短远多于收缩期。心率 150 次/分时，心动周期为 0.4 s，舒张期可能只有约 0.15 s。依赖缓慢充盈的心室，或存在固定狭窄的冠状动脉，首先受到影响。

::: example 每搏输出量与射血分数 {#ex-ef}
一位 62 岁女性的超声心动图测得左心室舒张末期容积 150 mL，收缩末期容积 90 mL。她的心率为 80 次/分。计算她的每搏输出量、射血分数和心输出量，并作评论。

::: solution
每搏输出量为$SV = 150 - 90 = 60$ mL。

射血分数为$EF = 60/150 = 0.40$，即 40%。

心输出量为$CO = HR \times SV = 80 \times 60 = 4800$ mL/min，即 4.8 L/min。

她的心输出量在静息正常范围内，但它是由一个扩大的心室维持的：EDV 比通常大，射血分数降低。40% 的射血分数属于心力衰竭所用的降低范围。这说明了一个普遍规律：扩大、收缩无力的心室可以通过在更大容积下工作，在静息时输出正常的每搏量，因此心输出量正常并不意味着心脏正常。
:::
:::

## 心音、静脉搏动和动脉搏动

同样的事件在床旁可以听到、看到。把心动周期学扎实，才能使听诊从猜测变为推理。

::: definition 心音 {#def-sounds}
- **第一心音（S1）**由心室收缩开始时二尖瓣和三尖瓣关闭产生，与颈动脉搏动的上升支同时出现。
- **第二心音（S2）**由射血结束时主动脉瓣（A2）和肺动脉瓣（P2）关闭产生。正常时 A2 先于 P2。
- **S2 的生理性分裂。** 吸气时胸腔内压下降，回到右心的静脉血增加，右心室射血时间延长，因此 P2 推迟，分裂增宽。呼气时两个成分靠近。
- **第三心音（S3）**是舒张早期快速充盈时出现的低调声音。它在儿童、青年和妊娠时正常；40 岁左右以后出现通常提示心室扩大、充盈压升高，如心力衰竭。
- **第四心音（S4）**紧接在 S1 之前出现，是心房收缩将血液挤入僵硬心室（如左心室肥厚）时产生的。心房颤动时不可能出现 S4，因为没有心房收缩。
- **杂音**由湍流产生。其时相（收缩期或舒张期）、部位、传导方向以及对各种动作的反应可提示病变所在（[[cardiovascular/valve-congenital-disease]]）。
:::

S2 的异常分裂是用心动周期进行推理的经典练习。右心室排空延迟时（如右束支传导阻滞），出现仍随呼吸变化的**宽分裂**。**固定分裂**不随呼吸变化，是房间隔缺损的典型表现，因为分流抵消了右心充盈的呼吸性变化。**反常（逆分裂）**在吸气时变窄，见于主动脉瓣关闭延迟、使 A2 落在 P2 之后的情况：常见原因是左束支传导阻滞和重度主动脉瓣狭窄。

**颈静脉压（JVP）**是颈内静脉搏动的高度，患者取 45° 体位，从胸骨角垂直测量。右心房位于胸骨角下方约 5 cm，因此 JVP 为 3 cm 时相当于右心房压约 8 cmH₂O。颈内静脉与右心房之间没有瓣膜，因此它直接反映右心房压力的变化。其波形各部分有专门名称：

- **a 波**：右心房收缩，恰在 S1 之前；
- **c 波**：心室收缩开始时三尖瓣向心房膨出形成的小隆起（床旁很少能看到）；
- **x 降支**：心房舒张以及心室射血时三尖瓣环向下牵拉；
- **v 波**：三尖瓣关闭时心房充盈，在收缩末期达到顶峰；
- **y 降支**：三尖瓣开放、心房排空进入心室时压力下降。

每一部分都有经典的异常。心房颤动时 a 波消失。心房在三尖瓣关闭时收缩会出现**大炮 a 波**：完全性心脏传导阻滞时不规则出现，某些交界性和室性心律时规则出现。**巨大 v 波**融合成一个收缩期波，是三尖瓣反流的体征。**陡峭的 y 降支**提示缩窄性心包炎，而心脏压塞时 y 降支消失。吸气时 JVP 不降反升（**Kussmaul 征**）提示缩窄，或右心室无法接受额外容量。

**动脉搏动**反映左心室射血和动脉的僵硬程度。**缓升、低容量的脉搏**提示主动脉瓣狭窄。脉压增宽的**陷落脉（水冲脉）**提示主动脉瓣反流或其他高输出状态。**交替脉**（强弱交替的搏动）是重度左心室功能不全的体征。**奇脉**是指吸气时收缩压正常的下降幅度扩大到超过 10 mmHg，典型见于心脏压塞和重度急性哮喘。

::: example 低血压伴静脉压升高 {#ex-tamponade}
一位 54 岁男性心脏手术后六小时被送回病房。血压 82/60 mmHg，心率 128 次/分，JVP 升至下颌角，心音遥远。吸气时收缩压从 82 降至 64 mmHg。用心动周期解释每一项发现，并说出最可能的诊断。

::: solution
**最可能的诊断是心脏压塞**，由术后心包内积血所致。

- **JVP 升高。** 心包腔内的液体使心脏周围压力升高。只有当静脉压高于这一外部压力时，右心房和右心室才能充盈，因此静脉压上升。
- **低血压和心动过速。** 由于心室不能充盈，舒张末期容积和每搏输出量下降。压力感受器反射使心率加快以维持心输出量，但充盈才是限制因素。
- **奇脉（下降 18 mmHg）。** 心包使心脏的总容积固定。吸气时回到右心室的静脉血增加；室间隔向左心室移位，左心室充盈减少，因此左心室每搏输出量和收缩压的下降比平常更多。
- **心音遥远。** 液体削弱了心音的传导。

低血压、静脉压升高和心音遥远的组合称为 **Beck 三联征**。超声心动图可确认积液及其对充盈的影响；治疗是引流，心脏手术后通常意味着返回手术室。本例说明，"血压低"可以是充盈问题，而不是泵或容量问题，而 JVP 可以将它们区分开。
:::
:::

## 心输出量及其四个决定因素

::: definition 心输出量及其决定因素 {#def-output}
**心输出量**是一侧心室每分钟泵出的血量：
$$
CO = HR \times SV
$$ {#eq-co}
成人静息时约为 5 L/min。由于体型不同，常将其除以体表面积，得到**心指数**（正常约 2.5–4.0 L/min/m²）。每搏输出量取决于三个因素，心输出量取决于四个因素：

- **前负荷**：收缩前心室肌被牵拉的程度，最好用舒张末期容积表示。
- **后负荷**：心室射血必须克服的负荷，主要由动脉压和阻力、主动脉的僵硬度以及心室的大小决定。
- **心肌收缩力（变力性）**：在给定前、后负荷下收缩的内在强度。
- **心率（变时性）**。
:::

这些因素并不独立。心率加快会缩短舒张期，可能降低前负荷。收缩力增强使心室排空更多，收缩末期容积降低。后负荷升高使每搏输出量减少，留在心室中的血液增多，下一次舒张末期容积升高，因此健康心室能部分自我纠正。这种自我纠正就是 Frank-Starling 机制。

::: theorem Frank-Starling 原理 {#thm-starling}
在生理范围内，心室舒张末期容积越大，射出的每搏输出量越大。因此，健康心脏会把回流给它的血液全部泵出，两个心室逐搏保持匹配。
:::

::: proof
其机制在肌节。心肌纤维在收缩前被牵拉，会增加其产生的力量，原因有二。

第一，**肌丝重叠**。在正常工作范围内，心肌肌节长度低于约 2.2 µm 的最适长度。牵拉使其接近肌动蛋白与肌球蛋白重叠最佳的长度。

第二，在心肌中更重要的是**长度依赖性激活**。牵拉增加肌钙蛋白 C 对钙的敏感性，并使肌球蛋白头部更靠近肌动蛋白，因此同样的钙瞬变产生更大的力。肌联蛋白（titin）——贯穿肌节的巨大弹性蛋白——参与这一效应，并决定纤维的被动僵硬度。

在整个心脏的层面上，舒张末期容积更大意味着纤维更长、力量更大、每搏输出量更大。如果右心室短暂地比左心室多泵出一些血，左心室在随后几次心跳中的充盈增加，输出随之增加，直到两侧再次相等。在充盈压很高时曲线变平：心包和心肌的僵硬度限制了进一步牵拉；而在衰竭的心脏中，整条曲线更低、更平。
:::

收缩力使整条 Frank-Starling 曲线移位。交感神经通过 β1 肾上腺素受体升高细胞内钙并加快舒张，曲线向上、向左移动，同样的充盈产生更大的每搏输出量。心肌梗死、心肌病以及维拉帕米等负性肌力药物使曲线下移。在图中改变收缩力系数，可以看到较弱的心脏需要高得多的充盈容积才能产生同样的每搏输出量。

::: theorem Fick 原理 {#thm-fick}
机体每分钟摄取的氧量，等于流经肺的血流量乘以动脉血与混合静脉血的氧含量之差。整理后得：
$$
CO = \frac{\dot V_{O_2}}{C_aO_2 - C_{\bar v}O_2}
$$ {#eq-fick}
其中$\dot V_{O_2}$为耗氧量（mL/min），$C_aO_2$和$C_{\bar v}O_2$分别为动脉血和混合静脉血（肺动脉血）的氧含量（每升血液所含氧的毫升数）。
:::

菲克（Adolf Fick）于 1870 年以守恒原理提出这一关系：在肺内进入血液的氧，必等于离开肺的血液所携带的氧减去到达肺的血液所携带的氧。它至今仍是测量心输出量的参考方法，其变形还解释了一个常见的临床现象：如果心输出量下降而耗氧量不变，组织会摄取更多的氧，混合静脉血氧含量下降。因此，混合静脉（或中心静脉）血氧饱和度降低是休克时心输出量不足的标志（[[emergency-critical-care/shock-fluids]]）。

::: example 用 Fick 法计算心输出量 {#ex-fick}
一位 45 岁男性在心导管检查中测得耗氧量 250 mL/min，动脉血氧含量 200 mL/L，肺动脉（混合静脉）血氧含量 150 mL/L。心率 70 次/分，体表面积 2.0 m²。计算他的心输出量、每搏输出量和心指数。

::: solution
动静脉氧含量差为$200 - 150 = 50$ mL O₂/L 血。

由 Fick 原理，
$$
CO = \frac{250 \text{ mL/min}}{50 \text{ mL/L}} = 5.0 \text{ L/min}.
$$

每搏输出量为$5000/70 \approx 71$ mL。

心指数为$5.0/2.0 = 2.5$ L/min/m²，处于正常低限。

注意单位：氧含量以每升血液中氧的毫升数表示，耗氧量以每分钟毫升数表示，因此结果为每分钟升数。如果氧含量以 mL/100 mL（mL/dL）给出，需先乘以 10。
:::
:::

## 静脉回流与耦合的循环

心脏泵出的血量不可能多于回流给它的血量。静脉回流的驱动力是**平均体循环充盈压**（若心脏停搏、全身压力平衡后循环中各处的压力，约 7 mmHg）与右心房压之差，再除以静脉回流阻力：
$$
\text{静脉回流} = \frac{P_{msf} - P_{RA}}{R_{VR}}.
$$
盖顿（Arthur Guyton）在 20 世纪 50 年代证明，把这条静脉回流曲线与心功能曲线画在同一坐标上，就得到循环的工作点：回流量等于泵出量时的右心房压。扩容或静脉收缩使平均体循环充盈压升高，工作点上移；失血使其下移。更强的心脏在同样血流下使右心房压降低；衰竭的心脏使其升高。

这一耦合的观点解释了为什么单凭右心房压（中心静脉压）难以判断患者是否需要补液。高值可能意味着容量过多，也可能意味着心脏无法泵出所接受的血液；低值在健康心脏中也可能是足够的。

::: warning 射血分数不等于收缩力，静脉压不等于容量
有两种走捷径的做法会导致错误。第一，射血分数既取决于收缩力，也取决于前负荷和后负荷。在重度二尖瓣反流中，心室把部分容积向后射入低压的心房，因此即使心肌已开始衰竭，射血分数也可能看起来正常；而在后负荷极高的患者中，健康的心室也可能表现为射血分数降低，压力控制后即恢复。第二，中心静脉压告诉你的是右心房内的压力，而不是体内的血容量，也不能说明补液后心输出量是否会增加。这两个数字都应结合患者的整体情况解读。
:::

## 压力-容积环 {#sec-pvloop}

把一次心跳中左心室压力对容积作图，会得到一个逆时针方向的闭合环。四个角就是四个瓣膜事件：右下角为二尖瓣关闭（舒张末期），右上角为主动脉瓣开放，左上角为主动脉瓣关闭（收缩末期），左下角为二尖瓣开放。

::: theorem 压力-容积环所显示的内容 {#thm-pvloop}
- 环的**宽度**是每搏输出量；垂直的右边为等容收缩期，左边为等容舒张期。
- 环内的**面积**是心室每搏所做的外功（每搏功）。
- 下边界沿着**舒张末期压力-容积关系（EDPVR）**，这条曲线描述舒张的心室的被动僵硬度。心室越僵硬，曲线越陡，充盈使其压力升高越多。
- 在不同负荷下记录的环，其左上角近似落在一条直线上，即**收缩末期压力-容积关系（ESPVR）**。其斜率**收缩末期弹性**是不依赖负荷的收缩力指标。
:::

每搏输出量的各决定因素都以可预测的方式移动这个环：

- **前负荷增加**（快速补液）：环向右增宽；舒张末期容积增加，每搏输出量增加，收缩末期容积几乎不变。
- **后负荷增加**（动脉压骤升）：环变高、变窄；收缩末期容积增加，每搏输出量减少。
- **收缩力增强**（正性肌力药或交感驱动）：ESPVR 变陡；心室排空更多，每搏输出量增加。
- **舒张功能不全**（僵硬的心室，如长期高血压）：EDPVR 变陡；只有在高充盈压下才能达到正常容积，而这一压力会传回肺。

::: example 读懂环的变化 {#ex-pvloop}
一位长期高血压的 70 岁女性记录了两个压力-容积环。在第二个环中，舒张末期容积不变，收缩末期容积从 50 mL 增加到 70 mL，收缩期峰压从 140 mmHg 升至 190 mmHg。是哪一个决定因素发生了变化？每搏输出量怎样了？

::: solution
舒张末期容积不变，因此前负荷相同。峰压升高而心室排空减少，这是**后负荷增加**的模式。如果是收缩力下降，心室也会排空减少，但峰压会降低而不是升高。

如果舒张末期容积为 120 mL，每搏输出量从$120 - 50 = 70$ mL 降至$120 - 70 = 50$ mL。在健康心脏中，增多的收缩末期容积会使下一次舒张末期容积升高，通过 Frank-Starling 机制部分恢复每搏输出量。在衰竭的心脏中，Starling 曲线平坦，因此每搏输出量的下降持续存在。这就是为什么用血管扩张剂降低后负荷可以增加心力衰竭患者的心输出量。
:::
:::

::: quiz
第一心音由哪一事件产生？
- [ ] 主动脉瓣和肺动脉瓣开放
- [x] 二尖瓣和三尖瓣关闭
- [ ] 舒张早期心室快速充盈
- [ ] 心房收缩挤入僵硬的心室
::: solution
S1 由心室收缩开始、心室压升至高于心房压时房室瓣（二尖瓣和三尖瓣）关闭产生。正常心脏中半月瓣开放是无声的。快速充盈产生 S3，心房收缩挤入僵硬心室产生 S4。
:::
:::

## 心肌需氧量

即使在静息时，心脏也从冠状动脉血中摄取约 70% 的氧，远多于大多数器官。因此它几乎没有增加摄氧的储备，工作加重时必须增加冠状动脉血流。心肌需氧量的主要决定因素是心率、室壁张力和收缩力。室壁张力遵循**拉普拉斯定律（Laplace 定律）**：对球体而言，张力与压力乘以半径再除以室壁厚度成正比。扩大的心室要产生同样的压力需要更大的张力，因此每搏耗氧更多；肥厚的室壁则把负荷分摊到更多心肌上。心率的代价尤其高，因为它既增加需氧，又缩短冠状动脉血流发生的舒张期。这些概念会在心绞痛中再次出现——β 受体阻滞剂缓解症状主要靠减慢心率（[[cardiovascular/coronary-artery-disease]]）；也会在心力衰竭中出现——扩大的心室在机械上效率低下（[[cardiovascular/heart-failure]]）。

::: example 脉搏缓慢的健康年轻人 {#ex-athlete}
一位 24 岁赛艇运动员静息心率 44 次/分，测得心输出量 5.3 L/min。最大运动时心率达 190 次/分，每搏输出量 160 mL。计算他的静息每搏输出量和最大心输出量，并解释耐力训练如何产生这种模式。

::: solution
静息每搏输出量为$5300/44 \approx 120$ mL（保留一位小数为 120.5 mL）。

最大心输出量为$190 \times 160 = 30\,400$ mL/min，约 30 L/min。

耐力训练增加血容量，使左心室增大、顺应性好、舒张末期容积大（生理性离心性重构）。更大的每搏输出量使同样的静息心输出量可在更低的心率下实现，迷走张力增强也起作用。运动时，即使在高心率下也能维持较大的每搏输出量，因此最大心输出量可比未受训练者高出数倍。无症状的健康人静息脉搏缓慢是意料之中的；同样的心率出现在有头晕的老年人身上，则需要检查是否存在传导系统疾病（[[cardiovascular/arrhythmias]]）。
:::
:::

::: history
哈维（William Harvey）在《心血运动论》（*De Motu Cordis*，1628）中，从瓣膜和简单的算术论证血液是循环的：把每搏的容量乘以心跳次数，一小时内的血量远多于身体能由食物生成的量。菲克（Adolf Fick）于 1870 年提出了测定心输出量的原理，但直到心导管术问世后才在人体中应用。奥托·弗兰克（Otto Frank）在 19 世纪 90 年代用蛙心，斯塔林（Ernest Starling）在 20 世纪 10 年代用犬心-肺标本，证明心脏的输出随充盈增加；斯塔林将其概括为"心脏定律"。1929 年，福斯曼（Werner Forssmann）把导管插入自己的右心房；后来，库尔南（André Cournand）和理查兹（Dickinson Richards）将心导管术发展为测量患者压力和心输出量的方法，三人于 1956 年共同获得诺贝尔奖。
:::

## 后续内容

触发每个心动周期的电活动见[[cardiovascular/electrophysiology-ecg]]。心脏所供应的循环的调控，以及左心室所对抗的动脉压，见[[cardiovascular/circulation-blood-pressure]]。心力衰竭（[[cardiovascular/heart-failure]]）在很多方面就是本章的反向演绎：变平的 Frank-Starling 曲线、移位的压力-容积环以及由此引发的代偿。扰乱心动周期的瓣膜病变见[[cardiovascular/valve-congenital-disease]]。

::: summary
- 左心室的心动周期有四个时相：等容收缩期、射血期、等容舒张期和充盈期。瓣膜按压力梯度被动开闭。
- 每搏输出量为 EDV − ESV；射血分数为 SV/EDV（正常约 50% 或以上）；心输出量为心率 × 每搏输出量，静息约 5 L/min。
- S1 为房室瓣关闭，S2 为半月瓣关闭（吸气时分裂）；40 岁左右以上成人出现 S3 提示扩大的心室快速充盈；S4 提示心房收缩挤入僵硬的心室。
- JVP 显示右心房事件：a 波（心房收缩）、x 降支、v 波（心房充盈）、y 降支（三尖瓣开放）。大炮 a 波、巨大 v 波和 Kussmaul 征各有特定原因。
- 每搏输出量取决于前负荷、后负荷和收缩力；Frank-Starling 原理通过肌节的长度依赖性激活使输出与充盈相匹配。
- Fick 原理给出$CO = \dot V_{O_2}/(C_aO_2 - C_{\bar v}O_2)$；混合静脉血氧饱和度降低提示心输出量低。
- 压力-容积环显示每搏输出量（宽度）、每搏功（面积）、收缩力（ESPVR 斜率）和僵硬度（EDPVR）。
:::

## 习题

::: exercise 射血分数 {level=1 check="57"}
某左心室舒张末期容积 140 mL，收缩末期容积 60 mL。计算射血分数（百分数，四舍五入到整数）。
::: hint
先求每搏输出量，再除以舒张末期容积。
:::
::: solution
每搏输出量为$140 - 60 = 80$ mL。射血分数为$80/140 = 0.5714$，四舍五入为 **57%**，在正常范围内。
:::
:::

::: exercise 心输出量 {level=1 check="5.04"}
某人心率 72 次/分，每搏输出量 70 mL。计算心输出量（L/min，精确值）。
::: solution
$CO = 72 \times 70 = 5040$ mL/min $=$ **5.04 L/min**。
:::
:::

::: exercise 说出心音 {level=1}
对下列每种情况，说出心音名称及产生它的事件：(a) 收缩期开始时的声音，与颈动脉搏动上升支同步；(b) 一位 68 岁、有呼吸困难和左心室扩大的男性的舒张早期低调声音；(c) 一位窦性心律、高血压性左心室肥厚的女性的舒张晚期声音。
::: solution
(a) **S1**，二尖瓣和三尖瓣关闭。

(b) **S3**，在充盈压升高的扩大心室快速早期充盈时产生；在这个年龄提示心力衰竭。

(c) **S4**，由心房收缩将血液挤入僵硬、肥厚的心室产生。如果她发生心房颤动，S4 就会消失。
:::
:::

::: exercise 用 Fick 法计算心输出量 {level=2 check="5"}
某患者耗氧量 300 mL/min，动脉血氧含量 190 mL/L，混合静脉血氧含量 130 mL/L。计算心输出量（L/min）。
::: hint
心输出量等于耗氧量除以动静脉氧含量差。
:::
::: solution
动静脉氧含量差为$190 - 130 = 60$ mL/L。$CO = 300/60 =$ **5 L/min**。
:::
:::

::: exercise 第二心音的分裂 {level=2}
预测下列情况下 S2 随呼吸的表现，并用哪个瓣膜何时关闭来解释：(a) 右束支传导阻滞；(b) 房间隔缺损；(c) 左束支传导阻滞。
::: solution
(a) **宽分裂，吸气时仍增宽。** 右心室激动延迟，因此肺动脉瓣关闭较晚；正常的吸气性 P2 延迟叠加在其上。

(b) **宽而固定的分裂。** 右心室在整个心动周期中承担大量容量，因此 P2 延迟；心房间交通使右心在吸气和呼气时的充盈趋于相等，因此分裂不随呼吸变化。

(c) **反常（逆）分裂。** 左心室激动延迟，A2 落在 P2 之后。吸气时 P2 后移、靠近 A2，分裂变窄；呼气时分裂增宽。
:::
:::

::: exercise 大炮波 {level=2}
一位 79 岁女性脉搏 36 次/分。在她颈部可见偶尔出现的、与动脉搏动没有固定关系的巨大静脉搏动。解释这些波，并说出最可能的心律。
::: solution
这是**大炮 a 波**。当右心房在三尖瓣关闭时收缩——因为心室恰在同一时刻收缩——心房血液被推回颈静脉，就会出现大炮 a 波。其出现时间不规则，说明心房和心室活动彼此独立。伴随缓慢而规则的脉搏，这是**完全性（三度）房室传导阻滞**：心房按窦性频率跳动，心室按缓慢的逸搏频率跳动，因此心房收缩偶尔与心室收缩重合。心电图可确诊（[[cardiovascular/arrhythmias]]）。
:::
:::

::: exercise 心指数 {level=2 check="2.2"}
心肌梗死后，一位男性心率 110 次/分，每搏输出量 40 mL，体表面积 2.0 m²。计算他的心指数（L/min/m²，精确值）并评论其意义。
::: solution
$CO = 110 \times 40 = 4400$ mL/min $= 4.4$ L/min。心指数 $= 4.4/2.0 =$ **2.2 L/min/m²**。

尽管心率很快，这一数值仍低于约 2.5–4.0 L/min/m² 的正常范围。每搏输出量小表明左心室正在衰竭；心动过速是一种代偿，但它也缩短了舒张期、增加了心肌需氧量。心指数低于约 2.2 L/min/m² 并伴有灌注不良体征，是心源性休克的血流动力学标准之一。
:::
:::

::: exercise 休克伴静脉压升高 {level=3}
一位 66 岁女性出现低血压（78/50 mmHg），JVP 升高，听诊双肺清晰。列出四种低血压伴静脉压升高而双肺清晰的原因，并对每一种说明心动周期或循环的哪一部分出了问题，以及哪一项床旁或简单检查的发现可将其区分。
::: hint
想一想充盈受阻、右心室流出道受阻以及右心室本身衰竭。
:::
::: solution
1. **心脏压塞。** 两个心室的充盈受心包压力限制。线索：奇脉、心音遥远、y 降支消失、心电图低电压或电交替；超声心动图显示积液及右心舒张期塌陷。
2. **大面积肺栓塞。** 右心室流出道受阻，右心室扩大、衰竭，左心室充盈不足。线索：血栓形成的危险因素、与胸部体征不相称的低氧血症、心动过速、心电图右心室劳损征象；CT 肺动脉造影或超声心动图（右心室扩大）可确诊（[[cardiovascular/vascular-disease]]）。
3. **右心室梗死。** 通常伴下壁心肌梗死。右心室不能泵血，右心房压升高而左心室充盈下降。线索：下壁导联 ST 段抬高、右胸导联 V4R ST 段抬高、Kussmaul 征；使用硝酸酯类后低血压加重。
4. **张力性气胸。** 胸腔内压升高阻碍静脉回流并压迫心脏。线索：一侧呼吸音消失、叩诊过清音、气管偏向对侧、呼吸窘迫；应立即减压治疗，不必等待影像学检查。

其他原因包括缩窄性心包炎（y 降支陡峭、Kussmaul 征、起病较缓）。共同点是：左心室充盈不足而静脉侧淤血，因此补液可能短暂有帮助，但不能解决病因。
:::
:::
