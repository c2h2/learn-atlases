心动周期是泵的四幕压力-容积剧：充盈、等容收缩、射血、等容舒张——每一幕由哪组瓣膜敞开、哪个心腔压力领先、心室纤维几何能达成什么来定义。在Wiggers图与压力-容积环上读，它成为一切杂音、一切心衰生理、一切休克状态与一切麻醉相互作用写在上面的框架；同一个环为主动脉瓣狭窄、填塞或扩张型心肌病重画，就是诊断本身。

本章讲述周期力学与心音、压力-容积分析、Starling与Guyton——心与血管作为一个耦合系统——及胎儿循环与其过渡。

## 周期

::: definition 四个时相 {#def-phases}
**充盈（心室舒张）：**第三心音时代的早期快速充盈之后（张力下降、心室在吸——房室压力阶差与弹性回缩被动驱动约70%的充盈），**心房收缩**贡献最后15–30%（“心房助推”——静息时不大、在僵硬心室与快心率时决定性，这就是新发房颤让主动脉瓣狭窄、肥厚型心肌病与任何舒张性心衰失代偿的原因）。**等容收缩：**房室瓣关闭（**S1**）、四瓣俱闭而压力攀升——此相的最大dP/dt是经典的等容收缩力指数。**射血：**一旦超过主动脉（或肺动脉）压，半月瓣开放；快速射血随后减慢射血，心室以**椭球形、螺旋纤维几何**经纵向缩短、扭转与径向增厚把血拧出——射血分数与应变测量背后的力学（[[cardiovascular/electrophysiology-ecg]]的影像表亲）。**等容舒张：**主动脉瓣关闭（**S2**——主动脉成分先于肺动脉成分、肺动脉成分在吸气时生理性分裂、同样的物理使房间隔缺损的宽固定分裂成为诊断），张力塌到房压以下、房室瓣开放、周期重启——舒张本身是**ATP驱动、Lusitropic（SERCA介导）的过程**，在缺血与肥厚中早期受损（[[physiology/muscle]]舒张练习的僵硬心室、S4心音、高血压老人的舒张性衰竭）。
:::

::: definition 心音、杂音与颈静脉波 {#def-sounds}
**S1**（二尖瓣与三尖瓣关闭）、**S2**（先主动脉后肺动脉；吸气时因肺动脉瓣延迟关闭而生理性分裂——固定分裂是房间隔缺损的容量均衡化、逆分裂是左束支阻滞或重度主动脉瓣狭窄的延迟）、**S3**（扩张顺应心室的快速充盈减速音——年轻人与妊娠正常，老人在是收缩衰竭与高充盈压的标志）、**S4**（心房对僵硬心室收缩——高血压、肥厚、缺血；永不正常）。**杂音**是流体声学的液体版：层流无声、湍流有声（Reynolds的速度、直径与黏度——与[[respiratory/mechanics-breathing]]的气道及贫血流量性杂音同一阈值逻辑）；**收缩期杂音**在射血期穿过半月瓣（主动脉瓣狭窄的射血递增型、二尖瓣反流的平台），**舒张期杂音永远病理**（主动脉瓣反流的早期递减伴塌陷脉、二尖瓣狭窄的低音调隆隆伴开瓣音——这个病变使本章的节奏问题致命）。**颈静脉搏动**是右心房在颈部的测压：**a波**（心房收缩——完全性心脏阻滞与室速中心房对关闭的三尖瓣收缩时的巨大“炮”音a波、房颤时缺席）、**c**（膨出、三尖瓣关闭）、**v**（对关闭瓣膜的充盈——三尖瓣反流的巨大cv）及**x与y降支**（收缩降支、舒张塌陷——y降支消失见于填塞、显著见于缩窄性心包炎）。
:::

## 压力-容积分析：会诊断的环

::: theorem 环及其操作 {#thm-pvloop}
左室的一次搏动在压力-容积坐标上画成一个环：**舒张末容积点在被动充盈曲线（EDPVR——顺应性）上**、垂直上升（等容收缩至**收缩末压力-容积关系，ESPVR——其斜率Emax是不依赖负荷的收缩力指数**）、沿顶边射血、再沿ESPVR回到充盈曲线。由此：**每搏量=EDV−ESV**（面积是**每搏功=压力×容积**、其下矩形是**势能**、两者之和——**压力-容积面积——与心肌耗氧量相关**：这是麻醉医师降低壁张力的理由——Laplace张力=压力×半径/2×壁厚——作为心绞痛的治疗、及扩张变薄的心室为何单位输出耗氧更多）。**升高前负荷**（液体）→环沿Starling曲线向右变宽；**升高后负荷**（去氧肾上腺素、主动脉瓣狭窄）→环变窄变高、ESV增大；**升高收缩力**（运动、多巴酚丁胺、交感驱动）→ESPVR变陡、ESV下降、环在充盈不变时变宽——射血分数上升是因为**收缩末容积沿ESPVR移动**，这正是射血分数作为被负荷污染的收缩力读数的确切含义；**顺应性下降**（肥厚、水肿、填塞的外部约束）→EDPVR向左上移位、小容积高压（舒张性心衰——环在陡充盈曲线上又窄又高）。填塞的环与缩窄性心包炎的环——心室相互依赖、室间隔的来回运动（超声的室间隔弹跳）——是同一张图把心包的约束写进EDPVR，即下文矛盾脉的物理基础。
:::

::: definition Starling、Guyton与耦合的循环 {#def-guyton}
**Frank-Starling**——心泵出返回的血，经长度依赖激活（[[physiology/muscle]]的长度-张力机制加钙敏感性增强）——是握手的心室半边；**Guyton的静脉回流曲线**是血管半边：血流沿**平均系统充盈压**（受应容积的弹性回缩，约+7 mmHg）到右房压的梯度返回，故**静脉回流随右房压升高而下降、随受应容积与交感性静脉收缩（升高充盈压）而上升**。稳态是**两条曲线的交点**——心输出量与右房压一起落定——而每个临床操作移动其中一条曲线：**液体、头低位、抬腿与静脉收缩升高充盈压、沿静脉回流曲线移动；强心在交点处降低右房压；出血压垮受应容积（低血容量休克平坦而低的曲线、心对空管狂跳）；衰竭的心是无法随充盈上升而升高的平坦Starling线——这就是它的治疗卸载（利尿剂、血管扩张剂、[[cardiovascular/heart-failure]]的肾素-血管紧张素与脑啡肽酶阻断）而不强心的原因。**骨骼肌泵与呼吸泵（[[physiology/integrative-physiology]]）是两条辅助曲线：静脉瓣与收缩向上挤回血液，及吸气的负压胸腔既降右房压又挤肺静脉——脊髓麻醉低血压时主动腿部动作与[[physiology/autonomic-nervous-system]]的Valsalva四相背后的生理。
:::

::: example 床旁的三联 {#ex-tamponade}
化疗中的淋巴瘤患者出现气促心动过速；颈静脉充盈、动脉压在吸气时下降18 mmHg、心音低钝、脉细速。
::: solution
**Beck三联与矛盾脉：心脏填塞**——心包液抬高心外压力直到四个心腔都跑在共同的舒张末高压上（导管显示的均衡化、颈静脉显示的y降支消失：心不能充盈，因为其外部约束而非张力设定了[[#thm-pvloop]]的EDPVR）。每个征的生理：**心动过速**（每搏量被封死时维持输出的唯一剩路——填塞患者遇β阻滞与诱导的血管扩张会垮）；**颈静脉升高伴y降支消失**（充盈只在早期舒张、在心包压力重新抓住它之前——对照缩窄性心包炎的显著y与平台）；**矛盾脉**（夸大的>10 mmHg吸气下降：吸气增加的静脉回流在充液心包的固定总容积内把室间隔向左推压——心室相互依赖——恰在左室充盈因血池淤在肺循环而下降时压低左室每搏量），及**遥远的心音**（液体的声学绝缘）。处理是环的物理反转：**边准备引流边扩容抬升充盈压（临时桥梁——[[#def-guyton]]交点论证的实时版），急诊心包穿刺或开窗——超声或透视引导、留管引流、病因（恶性、尿毒症、结核、心梗后、医源）事后追查**；穿前危险清单——不要正压通气（升胸腔内压进一步压垮充盈）、不要β阻滞、不要等待那心律为空心腔PEA的心脏骤停（[[cardiovascular/arrhythmias]]的可逆病因箱、H与T里填塞占一个T）。
:::

::: example 气促的舞者 {#ex-mitral}
34岁难民、爬一层楼即气促、新发心悸，心尖叩击感、S1亢进、开瓣音与心尖舒张期低调隆隆；心电图示P波消失、律绝对不齐。
::: solution
**风湿性二尖瓣狭窄刚刚把心房助推输给了房颤**——一次入院演完周期生理。狭窄瓣使充盈成为**舒张期压力阶差问题**（[[#def-sounds]]：S1来自仍活动的篷状瓣叶、开瓣音来自其骤然止步、隆隆来自湍流射流——又是Reynolds）；跨瓣心输出量需要**舒张时间与心房压力头**，房颤两样都攻击：有序收缩丢失（此处助推值20%的充盈、超过正常的15–30%，因为心室长期充盈不足而依赖）及更糟的**率**——心动过速缩短舒张、阶差暴涨、左房压冲入肺毛细血管（狭窄患者合头发热、贫血或妊娠的爆发性肺水肿），而扩大淤滞的左房孕育血栓，其栓塞使二尖瓣狭窄成为卒中病（[[nervous-system/stroke]]的年轻患者章节）。处理是同一物理：**先率控制（β阻滞剂——延长舒张），然后是本章一路描述的机械解——合适的（柔韧、无钙化、无反流、无血栓）瓣膜行经皮球囊瓣膜成形、否则外科——及由节律与心房大小驱动的抗凝，风湿病用华法林至今未被DOAC试验打败（[[blood/thrombosis-anticoagulation]]的被排除生态位）**。公共卫生脚注：世界最年轻的心脏病仍是风湿性，其首发往往正是这个——没人听见的杂音直到心律失常使其有症状（[[cardiovascular/valve-congenital-disease]]）。

## 胎儿循环及其过渡

::: definition 并联的两条回路，然后串联成一条 {#def-fetal}
胎儿循环为一个不工作的肺而建：**胎盘气体交换（低阻力胎盘取走约40%的联合心输出量）、右室主导（65%的输出）、经三个分流混合的并联体循环**——**静脉导管**（含氧的脐静脉血流穿过卵圆孔到左心与脑——**右冠与脑血管的氧饱和度高于下半身**——护住胎儿脑与心的上身优先血流）、**卵圆孔**（右向左的心房分流）与**动脉导管**（右室输出对抗约35 mmHg胎肺血管阻力的肺动脉-主动脉泄压阀）。出生时序列先机械后分子：**肺膨胀随第一口气把肺血管阻力降低几个数量级（而氧是导管的收缩剂与肺血管的舒张剂——与成人缺氧性肺血管收缩相反，[[respiratory/gas-exchange]]的血管反着走因为它在按胎儿方式走）**、肺血流暴涨、左房压超过右房并在功能上关闭卵圆孔（四分之一成人残留卵圆孔未闭）、**导管随PaO₂升高与循环前列腺素E₂下降而收缩（来源——胎盘与导管本身——随脐带一起移除）**、分流变成韧带（动脉韧带、静脉韧带、脐动脉的内侧韧带——[[anatomy/embryology]]的成人遗迹）。过渡失败是有成人后果的儿科急症：**动脉导管未闭**（机器样杂音；早产导管的**前列腺素敏感——吲哚美辛/布洛芬关闭；母亲用吲哚美辛会关闭胎儿导管——妊娠晚期NSAID规则**）、**房间隔缺损的固定分裂S2与成人肺动脉高压问题（Eisenmenger反转——动脉导管未闭的差异性发绀：下肢发绀而双手粉红，分流解剖写着饱和度图案）**、**主动脉缩窄**（新生儿下肢依赖导管的循环——前列腺素E₁重开导管、及年长修复型患儿的肋骨切迹侧支）、及**大动脉转位与并联循环病变、其分流是唯生命线**（前列腺素维持的导管与球囊心房隔造口作为生理的救援手术）——属[[cardiovascular/valve-congenital-disease]]与[[paediatrics/newborn]]。
:::

::: example 入学体检发现的杂音 {#ex-murmur}
7岁儿童因杂音转诊：3/6级、短、收缩早期、乐性、胸骨左下缘最响、平卧与站立时减轻、无症状、第二心音正常。
::: solution
描述即**Still无害性振动杂音**——学龄期经典（右室流出道层流湍动的乐性、拨弦样、胸骨下段、姿势敏感、短的收缩早期峰值杂音，S2分裂正常而其余全无：无咔嗒音、无传导、无震颤、无症状）。教学是家长等着听到的**病理阳性清单**：舒张期杂音（必然结构性）、全收缩与晚收缩杂音、粗糙或传导的性质、二叶瓣的咔嗒音与其喷射音、宽或固定的分裂S2、胸骨旁抬举、发绀或气促的孩子、发育停滞、及猝死家族史（肥厚型心肌病——那个**随站立与Valsalva增强**的杂音、动态流出道梗阻的负荷依赖正是[[#thm-pvloop]]后负荷一课的镜像）。无害对病理的辨别是本章查体的浓缩：**杂音的时相、性质、位置、姿势反应与其同伴——关于流量、口径与心腔的一句完整话，读自与导管室数字同一的压力-容积与Reynolds逻辑**；现代时代的确认是超声、其多普勒流速经修正Bernoulli关系（**压力阶差≈4×流速²**——正是[[cardiovascular/vascular-disease]]狭窄物理的同一方程）把杂音的音符变成狭窄的毫米汞柱。
:::

::: example 把心喂得太好的瘘 {#ex-fistula}
透析通路手术六个月后，58岁患者出现踝水肿、劳力性气促与脉压增大的循环；瘘的震颤搏动强劲、静息心输出量9 L/min、射血分数68%。
::: solution
**动静脉瘘的高输出生理**——移动的是Guyton曲线、不是Starling线：低阻力分流**降低体循环阻力、把动脉压泄入静脉、抬高平均系统充盈压与静脉回流**（[[#def-guyton]]：水龙头开着所以血流回来了），于是心输出量随之上升——宽脉压（舒张期跑水）、高动力心室（EF 68%是一颗正常心在加班）、而分流流量超过代偿耐受时（大瘘、小心的心、贫血或瓣膜病垫底）、**失代偿高输出衰竭的淤血**（水肿、仍在猛挤的心室上抬高的充盈压）。高输出状态的鉴别清单是同一曲线位移穿不同的衣服：**贫血、甲状腺毒症、妊娠、脚气病（湿型的动脉小肌瘫痪——[[cell-biochemistry/nutrition]]的硫胺素）、Paget病、及[[blood/lymphoma-myeloma]]的多发性骨髓瘤动静脉分流**。管理问流量：**把通路流量与心输出量一起测；若瘘就是病变——环缩、重建或（最后）结扎、预期此后心脏重塑；若不是、治驱动（甲状腺、血红蛋白）**——及该病例要教诊断习惯：**一颗射血分数良好的心衰是一个负荷问题，直到曲线证明不是**——正是把[[#thm-pvloop]]的读环术带到透析门诊。
:::

周期的年表是方法的年表：**Ludwig**与**Marey**记纹鼓的颈动脉与颈静脉描记（1860–70年代——作为数据的动脉脉与静脉脉）、**Chauveau与Marey**在马身上的直接心脏测压（1863——终于看见收缩舒张的压力曲线）、**Einthoven**的弦线电流计与心音图（心音的时间线、其1906年诺奖先于临床把心电图变成日常）、及**Wiggers**1928年的图给周期以本教科书使用的形状。**Frank**1895年与**Starling**1914年的心肺制备确立长度-张力定律及其“心的定律”（Starling自己的储备能与衰竭实验）、**Cournand与Richards**的心导管术（1956年诺奖）把心腔压力与Fick心输出量带上病房、**Sarnoff**的收缩力组分分析与**Suga与Sagawa**的收缩末弹性（1970年代日本学派）使压力-容积环成为今日的精密仪器、**Guyton**的交叉作图生理（1960–70年代静脉回流与平均充盈压规划）提供了现代休克与重症文献仍在引用的全循环耦合。胎儿一半属于**Barcroft与Hamilton**的宫内生理与**Dawes**的胎羊工作（1950–60年代——过渡循环的关键发现：导管的氧与前列腺素药理造就新生儿科的第一批药物治疗、及**Keith、Rowe与Vladimir**1950年代的导管自然史）。
:::

## 通向何处

肌肉力学在[[physiology/muscle]]；电-机械耦合在[[cardiovascular/electrophysiology-ecg]]；作为Starling线坍缩的衰竭在[[cardiovascular/heart-failure]]；瓣膜病变的负荷效应在[[cardiovascular/valve-congenital-disease]]；两条曲线的麻醉操作在[[cardiovascular/circulation-blood-pressure]]与围术章节；胎儿分流解剖在[[anatomy/embryology]]。

::: summary
- 周期由四个等容与射血时相组成，其瓣膜、心音与颈静脉波是心腔压力的直接征象；分裂与额外心音给时相病变定位。
- 压力-容积环统一前负荷、后负荷与收缩力（EDPVR、ESPVR、每搏功与近似耗氧的面积），每个药、每个瓣膜病变、每种休克都是其一边框的重画。
- 稳态是Guyton的交点：心输出量与右房压由Starling与静脉回流两条曲线共同设定——液体治疗、正性肌力药、升压药与心衰平坦曲线生理的基础。
- 心房助推在僵硬与狭窄的循环里最贵，这就是新发房颤使二尖瓣狭窄、肥厚与舒张衰竭患者骤然失代偿的原因。
- 胎儿循环是并联回路加三个分流，其过渡由氧与前列腺素药理指挥；分流的持续、关闭或依赖定义从早产儿瘘到成人Eisenmenger先心的疾病谱。
:::

## 练习

::: exercise 命名时相 {level=1}
心室压上升、所有瓣膜关闭、容积恒定：哪个时相？其后发生什么？期间动脉压如何变化？
::: solution
**等容收缩**——它跟着二尖瓣关闭（S1）、终于超过主动脉压、瓣开而射血开始；期间**主动脉压缓缓跌向其舒张最低**（向外周跑水而无入流）、潮波缺口属于开始下一次等容舒张的射血末瓣关闭。该时相的临床用途：**其dP/dt最大值是收缩力指数（β阻滞与衰竭降低、儿茶酚胺升高）及“射血前期”，随收缩力衰竭而延长——旧力学的收缩时间间期、现已被超声组织多普勒取代。**
:::
:::

::: exercise 射血分数的算术 {level=1}
EDV 180 mL、ESV 60 mL、心率75。计算SV、EF、CO；然后同一心室在去氧肾上腺素下（后负荷升高）ESV 85 mL、EDV 190：EF与每搏量发生什么？为什么“EF降了、心更差了”是不完整的读数？
::: solution
基线：**SV 120 mL、EF 67%、CO 9 L/min**。去氧肾上腺素后：SV=190−85=**105 mL**、EF=105/190≈**55%**。EF降了、每搏量也降了——但**是后负荷独自干的**：同一块肌肉对着更高的主动脉压射、射得少而剩更大ESV（环变窄变高）、而升高的EDV（Frank-Starling）部分代偿SV。EF依赖负荷（[[#thm-pvloop]]）；不依赖负荷的问题是ESPVR斜率，而临床上是：患者每次超声自身的后负荷（与容量）是否不同？——高血压入院时EF 35、随访时55的那位从来不是新的心肌病。
:::
:::

::: exercise 大炮a波 {level=2}
解释心房与心室收缩不同步时出现的颈静脉波，并列出三种产生间断巨大a波的心律及其心电图签名。
::: solution
**a波是心房对开放的三尖瓣收缩**；当心房改为对**关闭的**三尖瓣收缩（与心室收缩重合），压力直冲颈部成为**大炮a波**——房室关系逐搏变化时不规则、固定时规则。三种心律：**完全性心脏阻滞**（房室分离伴心房率更快、随机重合与心率缓慢）、**室性心动过速**（心房在快心室下独立行军——a波是宽QRS心动过速心室起源的床旁判别）、及**交界性心律/房室结折入性心动过速**（逆行心房激动在心室收缩中或对抗之——规则的“蛙征”、该心律的颈部有节奏撞击）。考试链：大炮a波=房室分离或心房对闭瓣的时相；心电图定其何者——[[cardiovascular/electrophysiology-ecg]]与[[cardiovascular/arrhythmias]]。
:::
:::

::: exercise 填塞之外的矛盾脉 {level=2}
定义之，给出其在填塞的机制（相互依赖），及另外三个原因及其机制。
::: solution
**矛盾脉**：收缩压吸气下降>10 mmHg（以脉动仅在呼气出现的压力与全周期出现的压力之差测量）。**填塞**：[[#ex-tamponade]]的室间隔移位——全心容积固定，故右心充盈的吸气增加直接窃取左心几何。其他：**缩窄性心包炎**（同一相互依赖、稍不完全；约三分之一病例）；**大面积肺栓塞**（扩张的右室在完整心包内把室间隔压向左侧——同一物理、[[respiratory/respiratory-failure]]的急性肺心病）；及**伴巨大吸气压的重度哮喘/COPD**（此处机制不同：显著负压胸腔升高左室透壁后负荷并使肺血池积——巨大的收缩压吸气下降可在无任何心包病时可触及——床旁征是生理问题而非诊断的原因）。
:::
:::

::: exercise 僵硬的心室 {level=2}
78岁高血压患者EF 62%、S4、左房增大、卧位呼吸困难。用环的语言解释：EDPVR移位、房颤 发作时的充盈压反应，及为什么硝酸酯与利尿剂有用而地高辛无用。
::: solution
慢性高血压平行添加肌节（[[physiology/muscle]]的肥厚生物学）与胶原——**EDPVR向左上移位：正常容积、高压**用力心房助推造的S4、肺淤血压造的劳力性呼吸困难、左房对着抬高的下游压扩张、**房颤**的左房扩大底物——并记住浸润性模仿者（淀粉样变、同一僵硬心室故事、在[[cardiovascular/heart-failure]]）。新发房颤抽走心房贡献（[[#def-phases]]）——它本在承担充盈的大头；心率上升缩短舒张——充盈压继续爬升、肺水肿。治疗跟随曲线：**利尿剂与硝酸酯降低陡EDPVR上的工作点（减前负荷缓解淤血——环的充盈角就是病变）；β阻滞剂与率控制延长舒张、在能维持窦性处恢复心房贡献；盐皮质激素阻断与血压控制缓慢重塑僵硬度。****地高辛在此毫无用处**——收缩力（ESPVR）从来不是问题（EF 62%）：把泵衰竭的药给一个储器衰竭的患者，就是本章“环决定治疗”的道德（[[cardiovascular/heart-failure]]）。
:::
:::

::: exercise 从胎儿到成人 {level=2}
追踪三个分流的关闭、其成人遗迹、导管的两个调控、及每个方向的失败后果（未闭、及宫内过早关闭）。
::: solution
**卵圆孔**——出生后数分钟被左房压反超功能关闭、数月内解剖（原发隔与继发隔边缘融合）——约25%保留卵圆孔未闭，**反常栓塞**（[[blood/thrombosis-anticoagulation]]的练习）与房间隔器械世界的底物。**动脉导管**——被升高的PaO₂与下降的前列腺素E₂收缩、成为动脉韧带（及其临床亲戚：**主动脉缩窄的峡部位置与喉返神经在弓下的袢**——[[anatomy/thorax]]的神经几何）。**静脉导管**——随夹脐带关闭、成静脉韧带、其再通即[[gastrointestinal/liver-disease]]放射学的经颈肝内分流。**未闭**（早产——机器样杂音、肺过度循环、及早产儿导管窃取舒张期流的衰竭；吲哚美辛/对乙酰氨基酚关闭、年长儿器械关闭）与**宫内过早收缩**（母亲NSAID暴露、尤其妊娠晚期——胎儿右室对着关闭的出口、新生儿肺动脉高压；同一前列腺素轴解释**PGE₁输注保持导管开放**——当新生儿病变（转位、缩窄、右心梗阻）在手术前依赖它，[[paediatrics/newborn]]与[[cardiovascular/valve-congenital-disease]]）。
:::
:::

::: exercise 读一条Wiggers描记 {level=2}
在主动脉与左室同步压力描记上，描述重度主动脉瓣狭窄时两条曲线、S2与射血时相发生什么，及为什么脉是细迟脉。
::: solution
瓣膜的固定口径把射血变成长而受阻的攀登：**室收缩压超过主动脉压达狭窄阶差（40–100+ mmHg）、射血时间延长、主动脉上升支与峰值变慢变平、主动脉潮波缺口迟到而弱——瓣叶固定时S2的A2成分低或消失**。**细迟脉**（颈动脉上升支弱而迟）是同一主动脉搏波物理在周边的读数：小口径流量减少而延迟、钝化并推迟压力波（[[cardiovascular/vascular-disease]]的脉搏波章）。负荷后果直落回环：**慢性后负荷压力超负荷的向心性肥厚（Laplace壁应力的正常化——张力=Pr/2h、故厚度上升）、EDPVR升高S4、心绞痛的氧供需挤压：肥厚肌、高壁张力、受压的心膜下穿孔支与缩短的舒张——心绞痛-晕厥-衰竭自然史背后的三联、重度狭窄患者遇房颤、血管扩张剂与麻醉容量转移而失代偿的原因**，及为什么瓣膜置换的环、症状清单与风险评分（及低流量低压差重度狭窄需多巴酚丁胺试验的悖论）归[[cardiovascular/valve-congenital-disease]]。
:::

::: exercise 设计液体试验 {level=3}
心外科后患者心脏指数1.8 L/min/m²、中心静脉压6、心率110、用去甲肾上腺素与多巴酚丁胺。设计生理引导的液体策略：测量序列、在场的两个曲线框架、要紧的终点、及停药规则。
::: solution
**框架**：Starling曲线（这个心室在升支上吗？）与Guyton静脉回流曲线（受限的是受应容积还是其压力？），在工作点相接。**袋之前先测**：**机械通气周期的脉压与每搏量变异（通气患者——动脉脉压与流量计的每搏量呼吸变异作为动态容量反应指标、优于静态CVP、其“6”什么也不说）；超声（充盈——低血容量的小而高动力心室对衰竭的扩张平坦曲线心室；下腔静脉变异作为粗测静脉压的窗），及被动抬腿试验作为自体的、可逆的300 mL弹丸、逐搏读每搏量。**终点**：每搏量与心输出量（流量）——不是血压或CVP；乳酸与中心静脉氧饱和度（灌注）作次级。**规则**：**只在试验使每搏量上升≥10%处给液体、试验不再推动时即停（平坦的Starling肢——继续扩容只升充盈压与淤血、不升流量：心外正平衡文献的伤害、及第三天湿透的伤口与肺水肿成本）。然后治曲线、不治患者的口渴**：纵隔出血后低充盈压伴心动过速是容量与血优先（[[blood/transfusion]]配比的失血生理）；高充盈压低输出是正性肌力与降后负荷、最终[[cardiovascular/heart-failure]]的机械支持阶梯；高输出、低充盈压是体外循环炎症反应的血管麻痹、去甲肾上腺素与亚甲蓝时代的救援是曲线的另一杠杆。答案是一套带具名停药规则的探查计划——本章与上一章的临床考试。
