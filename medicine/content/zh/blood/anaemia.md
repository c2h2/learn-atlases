贫血——红细胞质量降到氧输送所需水平以下，操作上即血红蛋白低于健康人群范围（男性13–17 g/dL、女性12–15，儿童与妊娠更低）——不是诊断而是有机制的发现，而机制通常在三张数字里可见：**平均红细胞体积（MCV）**、**网织红细胞计数**与**血涂片**。再加上铁代谢检查、B₁₂与叶酸、溶血筛查，世界最常见血液问题的鉴别就自行组织成一张流程图，从采血椅开始，很少需要更多。

本章讲述红细胞生成及其测量、贫血的分类、铁生理、叶酸与B₁₂、溶血性贫血，与疾病相关贫血。

## 分类与最初的检查

::: definition 分类的生理轴 {#def-class}
贫血生于生成减少、破坏或丢失增加，或两者兼有；实验室轴心：**MCV**（正常细胞性80–100 fL；小细胞性——血红蛋白化问题：缺铁、地中海贫血、炎症性贫血、罕见的铁粒幼与缺铜状态；大细胞性——巨幼的DNA合成问题，B₁₂与叶酸缺乏，及一大列非巨幼原因：酒精、肝病、网织红增多本身、羟基脲、骨髓增生异常）、**网织红细胞计数**生成的审计——按血细胞比容与成熟时间校正为**网织红细胞生成指数**：<2不适当地低（生成问题），>3高增殖（溶血或出血），与**涂片**（把分子缺陷定位的红细胞形态：缺铁的低色素与铅笔形细胞、巨幼变的大卵圆细胞与核分叶过多中性粒、球形细胞、破碎细胞、镰形细胞、咬痕细胞——每个都是自报家门的诊断）。**血红蛋白**本身对急慢性指导很差：生理主题的连串马拉松——血浆容量扩张会稀释（妊娠11 g/dL的“生理性贫血”不是病）、急性出血24小时内不可见、而慢性患者能带着6 g/dL走路——这个数字在急诊会触发复苏。
:::

## 铁：一种稀缺金属的生理

::: definition 铁的平衡、吸收与铁调素 {#def-iron}
成人体含铁3–5克，**三分之二在血红蛋白**、三分之一为贮铁蛋白与含铁血黄素、极小的转运池（转铁蛋白结合，约3 mg）每小时周转一遍——且**无生理排泄途径**：男性每日丢失约1 mg（肠道、皮肤）、女性1.5–2 mg随月经而定，故铁平衡完全由**吸收**在十二指肠肠细胞层面执掌。Fe³⁺在刷状缘由**十二指肠细胞色素b（DcyTB）**还原、以Fe²⁺经**DMT1**摄入、贮为铁蛋白或经基底外侧**膜铁转运蛋白**输出——细胞唯一的铁出口——而全系统由**铁调素**号令：这种肝细胞肽激素的信息只有一行：**铁调素结合并降解膜铁转运蛋白**，高铁调素（铁充足、炎症——IL-6驱动）把铁锁在肠细胞与巨噬内，低铁调素（铁耗竭、缺氧、红系驱动——经BMP6/SMAD与hemojuvelin信号）打开出口。这一个环路解释本时代的中心临床事实：**炎症时的缺铁**（慢性病贫血——高铁调素、铁扣留于巨噬、血清铁低而铁蛋白高、促红素部分耐药，因为红系前体的铁门被关）；**血色病**（HFE突变把体铁误读为高、铁调素不适当地低、吸收无上限——北欧裔最常见遗传病，[[genetics/common-disease-genetics]]的外显率课）；口服铁剂的**肠细胞阻断**（在前一剂铁蛋白未清前再给即部分浪费——铁调素时代隔日给药更佳）；及巨噬细胞的双重身份——衰老红细胞铁的回收者与铁调素的囚徒——这就是输注铁（每单位约200 mg、无排泄逃逸）在长期输血的地贫患者先积于网状内皮巨噬、后实质器官——螯合的地形（[[blood/haemoglobin-disorders]]）。
:::

::: example 疲惫的献血者 {#ex-irondef}
46岁女性每年献血两次，爬楼气短；Hb 104、MCV 74、铁蛋白8、转铁蛋白饱和度9%、血小板480。
::: solution
**缺铁性贫血，经期献血者的摄入-需求失衡**——一个没有出口体系的算术：反复放血（每次约200 mg铁，她无法快得足以重吸收）耗空了贮池（铁蛋白8——最早的异常；<15 μg/L即诊断贮池枯竭，而炎症里“看起来正常”的铁蛋白可以是抬高的假阴性，急性时相陷阱），转运池低（饱和度9%——骨髓的补给线），贫血呈**小细胞、低色素（铅笔形细胞）伴反应性血小板增多**（实践中最常见的血小板升高——巨核与缺铁串话），MCV是四个数字里最后降的。病因仍须点名——她是月经丢失加献血；在70岁男性或任何绝经后女性，缺铁**即是胃肠道失血直至内镜否定**（以乏力和MCV 70起病的右半结肠癌是医学最常被漏诊的诊断之一，而乳糜泻、幽门螺杆菌、减重手术与PPI吸收不良清单填在同一张单上）。治疗：口服铁（一剂、配维生素C、空腹或依铁调素生理隔日晨服、每日或隔日40–65 mg元素铁）、一周网织红升高、两月血红蛋白纠正，**随后三个月贮池回填**（终点是铁蛋白不是血红蛋白），不耐受、吸收不良或IBD发炎肠道用静脉铁（现代碳水外壳制剂、过敏现罕见）——加上纠正病因，因为还给一个正在出血病灶的铁只是更慢的诊断。
:::
:::

::: example 关节炎患者的血红蛋白 {#ex-acd}
60岁长期类风湿、服甲氨蝶呤，Hb 100、MCV 92、铁蛋白220、血清铁8、TIBC低正常、饱和度14%、网织红低、无出血。
::: solution
这是**炎症性贫血**（“慢性病贫血”）：IL-6升高肝细胞**铁调素**、肠细胞与巨噬的膜铁转运蛋白一同被降解、铁被锁走（血清铁低而**铁蛋白高**——与缺铁相反的配对，鉴别靠不升的TIBC）、红细胞生成受铁限制、骨髓对EPO轻度耐药，贫血正常或小细胞性、轻中度、网织红减少。两个混杂因子已实名在场：**甲氨蝶呤**（叶酸拮抗剂——查超出预期的MCV增大与B₁₂/叶酸状态；服甲氨蝶呤者的MCV 92可能是药，不是“正常”）及NSAID并存胃肠道失血的可能（粪隐血与练习表里铁对炎症的算术）。处理按机制排序：**控制炎症**（贫血随疾病好转——生物制剂奏效的红系效应）、确存缺铁则纠正（高铁调素常需**静脉**铁绕过肠细胞阻断——功能性缺铁正是炎症性贫血开发静脉铁与HIF脯氨酰羟化酶抑制剂的原因）、ESAs只给有症状、CKD重叠或化疗者，而输血阈值不因同情而改变。该课推广到后几章列出的每个慢性炎症、感染与恶性状态：**炎症性贫血不是骨髓衰竭而是铁隔离——铁调素有意的、防御性的、有时被过度治疗的生理。**
:::
:::

## 叶酸与B₁₂：甲基化维生素

::: definition 巨幼红细胞生成 {#def-megaloblastic}
B₁₂（钴胺素）与叶酸都为**胸苷酸合成**所需：无甲基B₁₂（作为甲硫氨酸合酶辅因子），叶酸即被困为N5-甲基四氢叶酸——“甲基叶酸陷阱”——DNA前体池崩塌而**胞质蛋白合成继续**，得到病理性的不同步：**巨幼成熟**——骨髓巨大晚幼粒、血中大卵圆细胞与**核分叶过多中性粒**（六叶——最早的涂片征）、无效造血（髓内凋亡：LDH升高与轻度间接胆红素血症可貌似溶血），及每个高周转上皮的同一阻断（舌炎、口角炎、肠道吸收不良）。**B₁₂的处理更复杂也更常考**：食物结合钴胺素被胃蛋白酶释放、转给**R结合蛋白（触珠蛋白类haptocorrin）**、后者在十二指肠被胰蛋白酶消化、释出B₁₂交给**内因子（IF，胃壁细胞）**；IF–B₁₂复合物在**末端回肠**吸收（切除与克罗恩的规则）、结合**转运钴胺素II**运输（递送者——其先天缺失致婴儿巨幼变而血清B₁₂正常，检测陷阱）、体贮池（肝2–5 mg、够数年）解释素食与胃切除缺乏的**潜伏期**（数年）对**叶酸**（体贮数月、数周即膳食缺乏——酒徒、骨髓以十倍正常消耗叶酸的溶血患者、不服叶酸的孕妇）。B₁₂的**神经综合征——亚急性联合变性**（后索侧索脱髓鞘：感觉异常、共济失调、痉挛，加视神经萎缩与认知改变）反映独立的甲基丙二酰辅酶A与甲基化两支（B₁₂缺乏时血甲基丙二酸与同型半胱氨酸均升、叶酸缺乏只升后者），由此而来的治疗铁律：**给B₁₂缺乏者单用叶酸会纠正贫血、却让脊髓病无声进展**。诊断顺序（血B₁₂、然后甲基丙二酸/同型半胱氨酸、然后IF与壁细胞抗体、然后——罕见地——试验性治疗）与恶性贫血机制（自身免疫性萎缩性胃炎伴无酸、IF抗体敏感约50–60%、伴发甲状腺自身免疫与胃癌监测问题）属临床章节；生理是图都画在其上的地图。
:::

::: example 两种大细胞增多 {#ex-macrocytic}
(a) 78岁养老院住户，素食数十年：Hb 84、MCV 118、中性粒八叶、轻度黄疸、LDH 1200、双足对称麻木、Romberg征阳性。(b) 34岁乳糜泻：Hb 90、MCV 112、涂片相仿、无神经体征、甲基丙二酸正常。
::: solution
两例都是**巨幼**（核分叶过多、无效造血的LDH-胆红素“假溶血”像——有核红的髓内死亡），分叉靠甲基丙二酸与病史。**(a) B₁₂缺乏**（数十年素食、后索体征——亚急性联合变性）：低B₁₂确证（水平临界时用功能标志——MMA与同型半胱氨酸升高），然后**终身肌注羟钴胺**（1 mg负荷后每三月一次；现代口服大剂量1–2 mg的证据适用于依从的无神经受累者），**首周治疗监测血钾**（重建骨髓摄钾可很急——经典住院风险），并搜寻恶性贫血（IF抗体、胃炎），因为该诊断带出胃癌与自身免疫并存含义。**(b) 叶酸缺乏**（近端小肠乳糜泻吸收不良、MMA正常）：**口服叶酸5 mg**治疗（先排除B₁₂缺乏——上述铁律——或经验性同时覆盖B₁₂）、纠正乳糜（无麸质饮食恢复近端吸收），记着需求增加清单（溶血——每个溶血患者都需要叶酸；甲氨蝶呤的抗叶酸；妊娠神经管预防400 µg、5 mg只归专科名单）。两种贫血、一副骨髓像、两个分子，而神经查体加一种代谢物把它们完全分开。
:::
:::

## 溶血：问题在破坏时

::: definition 溶血签名及其分区 {#def-haemolysis}
加速的红细胞破坏说一种固定的实验室方言：**网织红增多**（除非骨髓无法响应——溶血患者的再障**危象**是细小病毒B19对红系祖细胞的阻滞，与[[infectious-diseases]]相邻、在任何突发贫血的慢性溶血患者身上都值得想起）、**间接（非结合）胆红素血症**（血红蛋白负荷超过肝结合——较重组的黄疸与终身溶血的色素结石）、**LDH升高**、**触珠蛋白低或不测出**（游离血红蛋白被结合清除——最敏感的标志，但它是急性时相反应物，感染期“正常”不能排除），及损伤为**血管内**时的**血红蛋白尿/含铁血黄素尿**（机械瓣、行军血红蛋白尿、补体攻击、PNH），而非平常的**血管外**路径（脾巨噬清除——球形增多症、免疫性与滞留综合征）。病因按红细胞内外分拣：**胞性**（膜——遗传性球形与椭圆形增多症、[[blood/haematopoiesis]]膜段落的谱蛋白与锚蛋白缺陷；酶——G6PD与丙酮酸激酶；血红蛋白——下一章的血红蛋白病）与**胞外**免疫——温抗体AIHA（IgG、血管外、球形细胞、DAT阳性）、冷抗体（IgM、补体、偏血管内、肢端发绀及支原体与EBV关联）、药诱导（半抗原、自身抗体、免疫复合物机制）、溶血尿毒综合征与TTP、DIC与机械损伤（**破碎细胞**、头盔细胞——微血管病家族）、脾功能亢进、感染（疟疾——世界头号原因），及作为特例的**阵发性睡眠性血红蛋白尿**——获得性**PIG-A**克隆性GPI锚缺失，CD55与CD59无法安放膜上、**补体**在血管内溶细胞（经典的夜间血红蛋白尿——实则多为持续；现代图像：Coombs阴性溶血**加血栓**（腹腔与脑静脉——补体驱动的血小板激活）加骨髓衰竭——流式测FLAER结合蛋白缺失已是检测，依库珠单抗（抗C5）扭转了血栓死亡率）。
:::

::: example 深色尿的患者 {#ex-pnh}
32岁，三周背痛、乏力、晨起可乐色尿；Hb 78、网织红12%、LDH 2400、触珠蛋白不测出、DAT阴性；血小板70；下肢超声示股静脉血栓。
::: solution
**血管内溶血伴血小板减少与罕见部位血栓的青年=PNH，直到流式否定。**机制是[[#def-haemolysis]]的克隆：GPI锚丢失从每条造血系剥去**CD59（MAC抑制物）**与CD55，自发性补体激活无人阻止——慢性血管内溶解（滤过铁重吸收致含铁血黄素尿，故缺铁与溶血并存；被清除的一氧化氮致平滑肌张力障碍——背痛、腹绞痛、吞咽困难与勃起功能）加**异常模式的易栓**（肝、门、脑与皮肤静脉；年轻“肝硬化”里的经典Budd-Chiari），背景是把PNH与[[blood/haematopoiesis]]免疫性骨髓衰竭相连的再生障碍。诊断： 粒细胞流式查CD55/CD59与FLAER（荧光气泡素直接结合GPI锚），按克隆大小报告——再生障碍里的小克隆无需补体阻断，大的临床克隆需要。按严重度治疗：**依库珠单抗/雷夫利珠单抗（抗C5）**废除血管内溶血、血栓风险减半、改写生存（但**首剂前脑膜炎球菌疫苗为强制**——药的补体阻断与细菌的荚膜在同一蛋白上相遇）；**allo-HSCT**仍是唯一治愈，留给骨髓衰竭主导或控制不良者；抗凝个体化、C5阻断覆盖血栓风险；且**避免蓄铁的输血策略**（同所有慢性溶血）。夜间尿色——一个神话的真理内核（睡眠的轻度呼吸性酸中毒增强C9组装）——与本章主题同归：病史的怪处通常编码真实生理。
:::

细胞时代始于**Leeuwenhoek**第一幅红细胞图（1695）与贫血的临床分类学——**Warrington的White**1749年“绿色病”病例（行经少女的氯毒症——最古老被描述的疾病之一）、Addison与**Biermer**1858年的巨幼细胞恶性贫血、**Thomas Hodgkin**与**Murchison**的脾性贫血描述，及**Paul Ehrlich**的美蓝涂片（1878——分类计数，1900年代超活体网织红染色随后使骨髓产量可见）。治疗世纪围着肝转动：**George Whipple、William Murphy与George Richards**在去头犬身上证明生肝治愈恶性贫血（1934年诺贝尔奖授予Murphy与Whipple）、**William Castle**1929年证明不耐热的食物因子与耐热的胃因子共同生成抗恶性贫血原则，给出内/外因子学说与内因子命名，而**Minot与Murphy**1926年的诺贝尔奖已奖励肝疗法的临床发现。铁生物学的分子时代自1960–70年代转铁蛋白与铁蛋白工作开启，1993–94年转铁蛋白、铁蛋白与HFE基因克隆，及**2000–2001年铁调素的发现**——小鼠与人遗传学（Hamp、HJV、BMP6与HFE）数年间熔成铁领域最具后果的生理。溶血一侧属于脾外科医生、**Coombs**1939年的抗人球蛋白试验（抗体包被的红细胞变得可见）、及1940年代柠檬酸盐输血科——它们把这一切从生理变成常规。
:::

## 通向何处

铁与维生素生化在[[cell-biochemistry/nutrition]]；血红蛋白病在[[blood/haemoglobin-disorders]]；骨髓衰竭在[[blood/haematopoiesis]]；输血阈值在[[blood/transfusion]]；肾病贫血在[[renal/chronic-kidney-disease]]、妊娠贫血在[[obstetrics-gynaecology/pregnancy-antenatal]]；疟疾在[[infectious-diseases]]。

::: summary
- 贫血是机制性发现：MCV、网织红计数（校正为生成指数）与涂片在任何昂贵检查前把它分成生成失败对破坏/丢失。
- 铁平衡无排泄臂；铁调素对膜铁转运蛋白的掌控统一了缺铁、炎症性贫血（高铁调素扣留）与血色病（低铁调素负荷），并决定现代口服与静脉铁的给药。
- B₁₂与叶酸缺乏停滞胸苷酸合成、产生巨幼无效造血；B₁₂的吸收级联（R结合蛋白、内因子、末端回肠、转运钴胺素II）预言其缺乏的病因，其神经综合征是叶酸绝不可盲目的原因。
- 溶血是网织红增多、非结合胆红素、LDH与低触珠蛋白，分血管内与血管外、胞性与胞外病因；PNH，GPI锚克隆，是溶血、血栓与骨髓衰竭三合一的综合征。
- 炎症与肾病贫血共享同一终末通路——铁调素与EPO——治疗即逆转或替代它们，铁管理是限速辅因子。
:::

## 练习

::: exercise 网织红的裁决 {level=1}
Hb 65、网织红8%、血细胞比容22%。计算校正网织红计数与生成指数（此比容下成熟时间约2天），并分类该贫血。
::: solution
校正=8×(22/45)≈**3.9%**；RPI=3.9/2≈**1.9**。解读：外行看8%就算 brisk；按贫血与成熟时间校正后**临界/偏低**：对急性Hb 65的预期反应应是RPI>3。所以要么**进行性溶血/出血而骨髓响应不足**（查叶酸、铁、肾功能），要么**伴网织红渗漏的低增殖过程**——下一步是涂片、溶血筛查与铁/B₁₂/叶酸组合，而算术的信息是：**网织红计数只有校正后才有意义**——RPI是[[#def-class]]一个数说完的生成审计。
:::
:::

::: exercise 铁检查三写法 {level=1}
为缺铁、炎症性贫血与血色病列表血清铁、TIBC/转铁蛋白饱和度与铁蛋白；并说出各一个有诊断意义的数字。
::: solution
| | 铁 | TIBC | 饱和度 | 铁蛋白 |
|---|---|---|---|---|
| 缺铁 | ↓ | ↑ | ↓↓ | **↓（<15即诊断）** |
| 炎症 | ↓ | **↓/正常（“TIBC不升”）** | ↓ | **正常/↑（急性时相——陷阱）** |
| 血色病 | ↑ | ↓/正常 | **↑↑（>45–50，最早）** | ↑ |
可溶性转铁蛋白受体（组织缺铁时升高、不受炎症影响）与转铁蛋白受体-铁蛋白指数分开混合状态；炎症里缺铁的诊断仍奖励“TIBC低正常加低饱和度加病史”模式，无创数字打平时靠**可溶性转铁蛋白受体、骨髓铁染色（旧金标准）或治疗试验**。
:::
:::

::: exercise 性状还是缺乏 {level=2}
Hb 112、MCV 68、RBC 5.9×10¹²/L、铁蛋白40、HbA₂ 4.8%。说出疾病、点破它的规则，以及你不会做的事。
::: solution
**β地中海贫血性状**（小细胞程度超出贫血、**红细胞计数升高**——Mentzer指数MCV/RBC=68/5.9≈11.5，<13偏向性状而非缺铁——**铁蛋白正常**、血红蛋白HPLC/电泳诊断性**HbA₂升高（>3.5%）**，代偿性α₂δ₂）。不会做的事：**开铁剂**（被错贴“难治性缺铁”标签、喂铁多年者——贮池负荷风险）；会做的事：咨询（配偶筛查与生育风险算术由[[blood/haemoglobin-disorders]]与[[obstetrics-gynaecology/pregnancy-antenatal]]展开，两个β性状父母每次妊娠面对25%β地贫重型）、并寻找可**使假性偏低HbA₂正常化**的并存缺铁（同一HbA₂读数需铁充足后才能排除β性状）。
:::
:::

::: exercise DAT阳性的患者 {level=2}
29岁新发SLE：Hb 68、网织红15%、见球形细胞、DAT IgG阳性、C3d阴性。解释机制、脾的角色与治疗阶梯。
::: solution
**温抗体自身免疫性溶血性贫血**：IgG自身抗体（狼疮常为Rh家族特异性）在体温下包裹红细胞；**脾巨噬啃食膜**（Fc受体部分吞噬）造出球形细胞、严重时完整红细胞吞噬——**血管外溶血而DAT报告IgG**（直接Coombs：患者细胞+抗人球蛋白试剂→凝集；洗脱液鉴定抗体）。脾是舞台，故阶梯：**大剂量糖皮质激素**首发（数日应答；网织红与胆红素跟踪）、**利妥昔单抗**为公认二线（现代转向）、**切脾**三线（有效，须带[[blood/haematopoiesis]]无脾规则的终身荚膜菌疫苗与青霉素预防纪律），随后激素助减与挽救药（硫唑嘌呤、麦考酚、环磷酰胺、IVIG角色有限），**输血“按需并预先告知血库”**（泛反应性自身抗体使交叉配合困难——需要时“最不不相合”的单位可安全输注；在缺氧患者中不敢输比溶血更危险），并同时治疗狼疮本身。
:::
:::

::: exercise 咬痕细胞 {level=2}
一位马耳他-塞浦路斯医学生服普拉喹预防疟疾，两天后排深色尿；Hb下降30 g/L，涂片见咬痕细胞与水疱形细胞，第三周自行正常。解释之，包括涂片形态与自限病程。
::: solution
**G6PD缺乏、II/III型变异、氧化应激**：**X连锁**酶（[[genetics/mendelian-inheritance]]的交叉遗传）供应细胞全部NADPH、故保还原谷胱甘肽；普拉喹的氧化代谢物把血红蛋白变性成**海因茨小体**（沉淀、膜结合），脾通过时**咬掉**之（咬痕细胞、水疱形细胞），酶最少者发生血管内与血管外溶血。**自限病程即生理自救**：老细胞（酶少）死去、随后的网织红**富酶而耐受**，故继续用药溶血仍消退——诊断必须在恢复**后**寻求（危象期正常检测反映年轻细胞的假阴性），也是蚕豆病与感染触发危象在成人比新生儿期黄疸轻、而缺乏却无法过渡的最初几周的新生儿黄疸危险（严重的地中海型变异核黄疸风险最高）的原因。管理清单：**用现代安全/不安全表教避药**（普拉喹/他非诺喹按定量给药、氨苯砜、呋喃妥因、亚甲蓝、大剂量维生素C；蚕豆；令人安心的是绝大多数日常药安全）、新生儿筛查、**X连锁的人群地理**（地中海、非洲与亚洲流行率及其疟疾选择解释——[[genetics/common-disease-genetics]]），仅重度下降时输血。
:::
:::

::: exercise 溶血对失血对骨髓衰竭 {level=2}
给出网织红计数、胆红素、LDH与预期骨髓像：(a) 急性出血后三天，(b) 就诊时的自身免疫性溶血，(c) 早期再生障碍性贫血——并解释每一项。
::: solution
**(a)** 网织红上升（第5–7天达峰；EPO驱动红系增生——骨髓转运时间缩短）、胆红素轻升（外渗血液重吸收的血红素——大血肿的吸收黄疸同一负荷）、LDH近正常（除丢失细胞外无胞内释放）、骨髓**红系增生而可染铁下降**（贮池在资助恢复）。**(b)** 网织红高（除非骨髓衰竭-溶血重叠——PNH，或慢性溶血者的细小病毒再障危象）、**胆红素与LDH高**（破坏加上近巨幼状态的无效造血模仿者）、血管内型触珠蛋白不测出、骨髓**红系增生伴铁与含铁血黄素**（回收过载）。**(c)** 网织红**低（关键异常——贫血而无响应）**、胆红素与LDH正常、骨髓**低细胞、脂肪化、伴造血岛而无含铁血黄素**（诊断性环钻）。三件套——响应（网织红）、破坏标志（胆红素/LDH/触珠蛋白）、细胞性（骨髓）——是同一流程图在三个断点的读法，网织红计数仍是每条路的第一个分叉。
:::

::: exercise 老年人的贫血 {level=2}
82岁，CKD 4期、中度衰弱、无症状，Hb 102、MCV 88、铁蛋白180、转铁蛋白饱和度22%、网织红低正常、B₁₂与叶酸正常、未发现出血。梳理机制层级与治疗阈值之争。
::: solution
图像是**老年 增龄多因贫血**：**肾EPO响应钝化**（周小管质量与HIF信号下降——[[blood/haematopoiesis]]控制器增益变低）、**炎症型铁限制**（铁蛋白180而饱和度22%——炎性衰老背景上铁调素介导的功能缺乏）、可能有**摄入与吸收铁不足**（萎缩性胃炎、PPI——[[cell-biochemistry/nutrition]]吸收不良清单）与骨髓响应力下降；若指数或病史指向，隐匿胃肠道失血仍须排除（铁蛋白180能藏住并存失血——双升状态）。治疗论证跟随生理：**真缺铁或功能性受限时先补铁（炎症模式下先试静脉铁再承诺红细胞生成刺激剂是合理的）**、B₁₂/叶酸低正常而神经或精神含糊时补充、**ESAs只按方案规则**（CKD指南：有症状者、靶值约100–115 g/L、绝不正常化——正常化试验的血栓与卒中信号、与运动员滥用同一教训，及非CKD肿瘤患者的癌症死亡警戒），输血留给症状——把衰弱的老年人贫血“治到一个数字”就是逆证据而治，正确的干预可能是减药（ACE抑制剂？效应轻微；PPI的铁与B₁₂吸收不良）、营养与被看重的结局是运动能力。
:::

::: exercise 设计筛查规划 {level=3}
缺铁是世界最常见的营养缺乏。为一低收入环境的学龄前儿童设计人群策略：写出基于生理的理由、附试验证据的干预选项、须避免的伤害，及某些环境放弃普遍补铁的原因。
::: solution
**先讲生理**：婴儿需求巨大（第一年3–5克体铁与血红蛋白质量翻倍、约4–6个月贮池耗尽后全靠膳食——[[cell-biochemistry/nutrition]]的需求曲线），铁调素逻辑要紧两次：缺铁儿童**吸收更多**（低铁调素打开十二指肠膜铁转运），故补铁有效，但铁充足儿童不然（未吸收的铁喂养肠道致病菌并扰动菌群）。**按机制与证据排序的干预**：食品**强化**（面粉、双强化盐/酱油——触达所有人包括充足者、人均便宜、有血红蛋白增益记录的经典公共卫生杠杆）、**间断补充**（WHO每周铁叶酸微量营养素粉、贫血人群3个月疗程——铁调素友好的每周剂量）、**贫血儿童的靶向治疗**（治疗剂量、在有土传寄生虫致失血算术处驱虫），及病因层（疟疾控制、钩虫、膳食多样、及不用一粒铁就改变人群贫血率的血红蛋白病婚育咨询）。**伤害**：疟疾信号——**奔巴岛试验**（在筛查缺失、疟疾传播的沿海环境，口服铁与叶酸加重重度贫血/死亡），促使WHO转向**传播强烈处先筛后治加疟疾控制**，及菌群与（负荷风险）遗传学论证（HFE血色病地区——[[genetics/common-disease-genetics]]对北欧裔人群普遍补铁的劝退）。**放弃论补全**：在疟疾与感染覆盖充分处，补铁减少贫血；在无覆盖处，干预重新分配风险；故规划是**肠道感染控制、然后强化、然后靶向治疗**——生理、然后流行病学、然后伦理，按此顺序。
