白血病是被逮住过度生产现场的造血组织癌：一个体细胞突变的干细胞或祖细胞，其后代因**分化受损**（急性白血病的原始细胞期分化停滞、骨髓被挤满）或**保留成熟的不受约束生产**（慢性骨髓增殖性疾病）而积累——表现为骨髓衰竭、器官浸润，或本时代最常见路径：一张意外的血细胞计数。本章的智识脊梁与病理课程讲实体瘤是同一条——突变、克隆演化、选择——应用于一个生来就液态的癌；而其临床脊梁是让白血病成为分子靶向肿瘤学模范的治疗革命：伊马替尼、ATRA、FLT3与IDH抑制剂、维奈克拉与CAR-T。

本章讲述急性白血病的分类与生物学、骨髓增生异常、骨髓增殖性肿瘤与淋系白血病。

## 定义与生物学

::: definition 白血病是什么 {#def-def}
**急性白血病**：骨髓或血中≥20%原始细胞（WHO阈值；Auer小体或特异基因病变在任何计数下即可诊断），髓系或淋系前体成熟失败——数日至数周内以骨髓拥挤的后果起病（贫血、中性粒缺乏感染、血小板减少出血），淋系疾病加牙龈浸润、骨痛与淋巴结病；**慢性白血病**：偏成熟细胞积累伴脾大与高计数、隐匿或意外起病，终有**急变**风险（髓系疾病向急性白血病终末加速）。生物学是克隆性与演化性的：驱动病变或**促存活/增殖**（FLT3-ITD、RAS、BCR::ABL1的激酶）或**阻滞分化并改变自我更新**（核心结合因子易位、KMT2A重排、NPM1突变），叠加于**白血病干细胞组分**之上——它再生疾病、自周期依赖性化疗中豁免自己，是移植与免疫治疗的真靶；对其测量（**微小残留病**，多色流式或融合基因/Ig基因重排定量PCR）如今是本领域最强的预后数字。年龄仍是主宰变量：急性髓系白血病发病率在七八十岁仍在上升，因为积累的干细胞克隆（[[blood/haematopoiesis]]收尾练习的CHIP）与治疗（烷化剂与放射相关MDS/AML、[[pharmacology/adverse-reactions]]的潜伏期与风险表）都在施肥。
:::

## 急性髓系白血病

::: definition 分类、风险与可治病变 {#def-aml}
诊断：血涂片与骨髓抽吸（原粒——MPO阳性、病变允许时Auer小体）、**免疫分型**（CD34、CD117、CD33、CD13、单核系CD14/64）及——决定性的**细胞遗传学与分子检查**（ELN框架）：**预后良好**核心结合因子白血病t(8;21)与inv(16)、**NPM1突变/FLT3-ITD阴性**病与**CEBPA双等位**；**预后不良**复杂与单体型核型、−5/−7、RUNX1、ASXL1、TP53（治疗相关与MDS来源生物学、抗拒一切的克隆），**FLT3-ITD**（增殖驱动；ITD等位负荷有治疗意义）与**KMT2A重排**属中危到不良组、其靶向伙伴（FLT3与menin抑制剂）现已加入方案。起病急症数得过来：**APL（M3——t(15;17)、PML::RARA）**及其灾难性凝血病（见下）；**高白细胞与白细胞滞留**（原始细胞>100×10⁹/L、髓系细胞更大更黏、堵塞微循环——低氧、卒中、阴茎异常勃起：羟基脲与白细胞单采的细胞减灭急症、肿瘤溶解预防）；**DIC**（带组织因子的早幼粒与单核）；及**肿瘤溶解**（首剂后高转换负荷：钾、磷、尿酸、钙——水化加别嘌醇或**拉布立酶**、G6PD缺乏患者绝不能用——[[blood/haemoglobin-disorders]]的溶血陷阱）。治疗仍是阿糖胞苷加蒽环诱导（“7+3”），**FLT3突变者加midostaurin或quizartinib**、治疗相关与骨髓增生异常相关病用脂质体阿糖胞苷-柔红霉素（CPX-351），而“7+3会杀死”的老弱组用**维奈克拉加去甲基化剂**——改变七十岁以上一线AML的BCL-2抑制剂组合；按风险巩固（良好风险大剂量阿糖胞苷、中/不良首次完全缓解与所有首次复发用**异基因移植**）；及**MRD指导的强化**——框架的定量核心。
:::

::: example 不能等待的出血 {#ex-apl}
34岁女性因牙龈出血、瘀斑与弥散性血管内凝血图像就诊：血小板20、纤维蛋白原0.7 g/L、INR 1.6、D-二聚体极高；涂片见高颗粒原始细胞成束Auer小体（“柴捆细胞”）。
::: solution
**急性早幼粒细胞白血病直到基因确证——而ATRA（全反式维甲酸）在临床怀疑时即开始、先于结果。**病变：**t(15;17) PML::RARA**——视黄酸受体α与PML融合把髓系细胞锁在早幼粒阶段（一个药理可逆的分化阻滞：**药理剂量维甲酸松开阻滞**——那个把早期死亡皆为失血性休克病治愈的分化治疗），而恶性早幼粒的颗粒内容（组织因子、膜联蛋白II、蛋白酶）驱动头几天致死的**纤溶亢进与DIC凝血病**——故积极成分支持（冷沉淀或浓缩物把纤维蛋白原维持>1.5 g/L、血小板>50、避免肌内注射的护理规则）。方案：标危（WBC≤10）**ATRA加三氧化二砷**——无化疗、绝大多数可治愈、配QT监测与砷剂警诫，高危用ATRA/砷加吉妥珠单抗奥唑米星或伊达比星；**分化综合征**（发热、水肿、呼吸困难、浸润、低血压——分化中细胞的细胞因子风暴与毛细渗漏）用地塞米松治疗、重症暂停ATRA，绝不可只当感染；维持与鞘内决定按风险；及作为现代治愈证明的**PML::RARA PCR** MRD。该病例一句话的道德、每个血液病房都教：**出血患者见柴捆细胞，先开ATRA，让实验室事后同意你。**
:::

::: example 白细胞三十万的呼吸困难患者 {#ex-leukostasis}
72岁患者被送来时意识模糊、低氧；计数仪提示WBC 310×10⁹/L、涂片满布原始细胞、胸片无浸润、眼底见视网膜静脉淤张与出血。
::: solution
**高白细胞伴白细胞滞留**——髓系原始细胞（比淋系更大、更硬、颗粒更多）升高血液黏滞、塞住微循环：**肺**（放射线清晰的低氧——灌注阻断而非肺炎）、**脑**（意识模糊、视觉改变、阴茎异常勃起、眼底淤积）、及肾，外加危险：细胞减灭将释放前文练习的溶解化学。即刻的定向于生理的处理：**细胞减灭剂量羟基脲（有症状者白细胞单采——机械移除买来几天、试验证据一般而神经与呼吸滞留的角色稳固）、小心水化避免淤塞肺床过度灌注、TLS预防在计数下降前运行、暂缓输血（旧教义：未确诊时红细胞升高黏滞——只在危重贫血补充）**，同时当场回答并排除APL之问（[[#ex-apl]]的凝血病会要求立即ATRA，而白细胞滞留加DIC指向早幼粒或单核变异型）。激素——淋系的答案（ALL原始细胞的皮质醇敏感）——在系别未知前不给，因为未声明的淋系白血病中它们部分治疗并掩盖诊断；插管与镇静要带着低氧与酸中毒恶化变形与毛细堵塞的知识进行。该病例是全身流变学：与[[physiology/homeostasis-body-fluids]]黏滞讨论同一Poiseuille式思维，白细胞计数是变量。
:::

## 淋系白血病与慢性髓系疾病

::: definition 急性淋巴细胞白血病 {#def-all}
ALL是儿童的病（2–5岁峰、儿童急性白血病约80%），也发生于生物学更差的高龄成人：阻滞在淋系祖细胞——约85%为**B前体CD10/CD19/TdT阳性**，细胞遗传学风险图即[[genetics/cancer-genetics]]易位一课：**ETV6::RUNX1 t(12;21)**（预后好的隐蔽融合、旧命名的“TEL-AML1”）、**婴儿KMT2A（MLL）重排**（最差）、**BCR::ABL1样与费城阳性**病（现以TKI加入化疗或blinatumomab方案治疗）、**Ph样ALL**（激酶融合组、其靶向伙伴靠测序找到）——及**T-ALL**（青少年男性纵隔肿块与气道、积液风险）。诊断：涂片与骨髓、免疫分型、细胞遗传学、及**腰穿**——中枢神经是**庇护所**（血脑与血睾屏障挡住全身治疗，故现代方案把中枢定向治疗——鞘内甲氨蝶呤±阿糖胞苷±氢化可的松、风险适配的放疗现已放过多数儿童——与MRD监测立为双柱，使儿童ALL五年生存从约10%走到90%以上：可治愈癌症的模范）。成人ALL添上blinatumomab与inotuzumab（CD3双特异与CD22免疫偶联物）时代及第二次缓解期移植，青少年与青年方案移植到成人单位完成其余。
:::

::: definition 骨髓增殖性肿瘤 {#def-mpn}
**JAK2/CALR/MPL**驱动三重奏定义了经典**费城（BCR::ABL1）阴性骨髓增殖性肿瘤**——一个或多个髓系的增殖伴分化保留、髓外造血致脾大、共享的血栓、出血（极高血小板的获得性血管性血友病）与**进展为髓纤维化或AML**风险：**真性红细胞增多症**（>95% JAK2 V617F——红细胞增多伴EPO低；水致瘙痒、面色红褐、高血压、痛风、脾大；血栓是杀手也是治疗目标——放血至血细胞比容<45%、低剂量阿司匹林、高危用羟基脲或干扰素细胞减灭）、**原发性血小板增多症**（JAK2/CALR/MPL；其血小板计数要求先排除反应性原因——缺铁、切脾、炎症、恶性疾病——再命名肿瘤，并排除隐匿性真红与纤维化前期髓纤维化，MPN-1/MIPSSU评分的血栓与出血风险驱动阿司匹林/羟基脲/干扰素决定）、**原发性髓纤维化**（巨核TPO信号克隆经倾倒PDGF/TGF-β纤维化骨髓——[[blood/haematopoiesis]]的幼红幼粒涂片、泪滴细胞与巨脾、体质症状与**ruxolitinib**对细胞因子机器的JAK1/2抑制——脾与症状获益、无治愈——及异基因移植唯一治愈选项），及**慢性髓性白血病**、为整个类别命名的例外：**BCR::ABL1 t(9;22)、费城染色体**——一个组成性激活的酪氨酸激酶，其发现（Nowell与Hungerford 1960年急性白血病染色体；Rowley 1973年易位证明；Van Etten-Daley-Baltimore对融合激酶转化活性的重构）四十年内从描述走到**伊马替尼**（ATP口袋抑制剂——Druker的规划、I期传奇的持久缓解）：CML现以高粒细胞计数与核左移、嗜碱增多、脾大与**PCR可测BCR::ABL1**起病，按原始细胞百分比分期（慢性/加速/急变——后者呈AML或ALL样转化），并以TKI治疗（伊马替尼，或第二代尼洛替尼/达沙替尼/博舒替尼及其副作用签名——QT、胸腔积液、腹泻），目标是**停药后维持的深层分子缓解——临床实践最接近“以血检定义治愈”之处**。
:::

::: example 瘙痒的退休者 {#ex-pv}
66岁男性因“红细胞多、淋浴后背痒”转诊；Hb 198、Hct 60%、WBC 15、血小板480、脾可及、EPO低、JAK2 V617F阳性、血氧饱和正常。
::: solution
**真性红细胞增多症**——JAK2驱动、不依赖促红细胞生成素的增殖并把EPO压下去（把继发红细胞增多——EPO高或正常、缺氧性与罕见EPO分泌瘤、及[[blood/haemoglobin-disorders]]的高亲和血红蛋白——与EPO低的肿瘤分开的反馈判别）。检查以**JAK2突变与骨髓形态**（三系增生——同时抬高WBC与血小板的全髓增生）收尾，EPO或病史古怪时加红细胞质量与动脉血氧、睡眠监测与碳氧血红蛋白（吸烟者的假性红细胞增多是经典模仿者）。症状是高黏滞与嗜碱/肥大细胞及细胞因子生物学：**水致瘙痒**（淋浴触发、无皮疹、机制不明的肥大细胞/神经纤维性瘙痒、最难治的症状——抗组胺多失败；SSRI与细胞减灭本身最有效）、面部红紫、高血压、红斑肢痛（阿司匹林敏感的指端烧灼——微血管血小板聚集）、痛风（转换）与两个组织管理的临床风险：**血栓**（动静脉皆然、主要死因——含JAK2筛查已成规则的罕见部位Budd-Chiari与门静脉血栓）及晚年的**纤维化或白血病转化**（数十年后小百分比）。管理是风险分层的三联：**放血至血细胞比容<0.45（CYTO-PV试验明确的生存信号）、低剂量阿司匹林除非计数相关血管性血友病或出血介入、高危病（年龄>60或既往血栓——本例合格）细胞减灭（羟基脲首选；年轻与孕妇用干扰素、ropeginterferon是现代长周期选项）**，ruxolitinib用于不耐受/耐药；脾、瘙痒与微血管症状是治疗反应读数，而整个患者就是本章一课：驱动突变的临床综合征由它组成性开启哪条细胞因子通路写成。
:::

::: example 跛行的四岁孩子 {#ex-all}
母亲带来四岁孩子：两周不肯走路、低热、瘀斑；Hb 78、血小板22、WBC 34见“原始细胞”、骨与小腿痛、无肿块、凝血正常。
::: solution
**急性淋巴细胞白血病**——年龄高峰期的贫血、血小板减少与循环原始细胞三联，伴常被先诊为“生长痛”、或早期涂片正常时被诊为**暂时性红细胞生成障碍、甚至类似脑瘫的拒绝行走**的骨痛（骨髓扩张）；孩子的疼痛、发热与瘀斑模式本身就是一条转诊规则。检查分期：涂片与骨髓（多数CD10/CD19/TdT+ B前体；淋巴母细胞形态不再是预后因素）、**细胞遗传学/分子风险归类**（ETV6::RUNX1好；KMT2A与低二倍体差；ABL类现已可操作）、**腰穿与脑脊液细胞学定中枢状态**、及纵隔与睾丸基线影像。治疗是治愈儿童癌症的架构：**风险适配的多药化疗**（激素、长春新碱、蒽环、门冬酰胺酶、鞘内甲氨蝶呤、环磷酰胺/依托泊苷与放疗留给正在降级的历史高危组）、**第29天与诱导末骨髓MRD**决定升级（最强预后变量——低于10⁻⁴即好结局平台）、每个方案的中枢预防、及**TKI与免疫治疗加入（blinatumomab、inotuzumab、复发用CAR-T）**使多次复发的儿童ALL成为可能治愈而非终末的病。病例藏着的实用儿科点：**可安全避免时，诊断骨髓前绝不输血或给激素**（掩盖诊断是经典转诊灾难）、**从第一份标本起TLS预防**、门冬酰胺酶的胰腺炎、血栓与抗体形成警惕、及生存者议程——蒽环心肌病监测、远期效应筛查、及一个生存者已多于新发者的疾病的教育与生育工作。

本领域的里程碑都是治疗的里程碑：**Donné**1844年细胞计数、**Hughes Bennett**1845年血液图谱与**Virchow**1847年为“白血”疾病命名；随后**Ehrlich**的差分染色（1878–81）与**Pappenheim**的形态学使急性与慢性、髓系与淋系范畴可见；**Farber**的氨基蝶呤缓解儿童ALL（1948——开创肿瘤化疗的一页）、**Skipper与Schabel**的对数杀灭小鼠白血病学说、及**Emil Freireich**同事们的NCI联合化疗规划（儿童ALL与霍奇金淋巴瘤作为概念验证），连同定义方案的巩固与维持研究；**Janet Rowley**证明费城染色体是易位（1973、**BCR::ABL1**基因1983–87年鉴定）与**Druker**的伊马替尼规划（2001年I期）——定义分子医学的从靶到药弧线；**王振义与陈竺**的上海ATRA故事（分化发现成长为砷剂联合治疗）与现代CAR-T时代（2012年起）完成从1845年显微镜到工程细胞的弧线。
:::

## 通向何处

转化遗传学在[[genetics/cancer-genetics]]；CHIP与干细胞衰老在[[blood/haematopoiesis]]；淋系肿瘤在[[blood/lymphoma-myeloma]]；上述各方案的输血支持在[[blood/transfusion]]；中性粒缺乏急症在[[infectious-diseases/fever-sepsis]]；姑息整合在[[geriatrics-palliative]]。

::: summary
- 白血病按分化停滞（急性：原始细胞、骨髓衰竭）与保留成熟的积累（慢性：高计数、脾大、急变风险）分类，其治疗随分类与克隆的基因走。
- AML是年龄与病变之病：ELN风险分层决定强化、靶向（FLT3、IDH、menin）与移植，而APL以临床怀疑即启动的分化与砷治疗，是治愈最快、早期死因是凝血病的例外。
- ALL以儿童为模范：风险适配化疗加中枢预防加MRD，把绝大多数患儿带向治愈；成人依从同一逻辑并添免疫治疗。
- 髓增殖肿瘤是JAK2/CALR/MPL（CML为BCR::ABL1）驱动、分化保留之病，血栓是其共同临床货币，而TKI的深度分子缓解与“停药治愈”使CML成为靶向医学的旗舰。
- 白血病干细胞与MRD是现代疾病观的两极：测量残留并攻击其干细胞库，正是移植、免疫治疗与分化策略存在的理由。
:::

## 练习

::: exercise 识别原始细胞 {level=1}
一群原始细胞中的Auer小体确立哪一系？哪些染色确证？哪个实体需要当小时治疗？
::: solution
**Auer小体（融合的初级颗粒——过氧化物酶与MPO阳性、结晶化的嗜天青颗粒）意味着髓系**——先于免疫分型的形态学答案（流式CD33/CD117/MPO；苏丹黑与MPO细胞化学现为确证）；淋巴母细胞MPO阴性、带TdT与CD19/CD10或CD3/CD7。当小时实体：**高颗粒早幼粒图像伴Auer成束——APL**——其柴捆细胞、DIC化验与“怀疑即ATRA”规则见[[#ex-apl]]（t(15;17)结果随后到、FISH间期检测缩短等待）。
:::
:::

::: exercise 按标志分类 {level=1}
归类：CD10⁺CD19⁺TdT⁺；CD33⁺MPO⁺；CD3⁺CD7⁺伴纵隔肿块；CD5⁺CD19⁺CD23⁺伴成熟小淋巴细胞增多。
::: solution
**B前体ALL；AML；T-ALL（青少年纵隔肿块——镇静前先查气道与积液）；及CLL**——最后者是慢性淋系白血病、其成熟表型把它标为[[blood/lymphoma-myeloma]]交界的病（小淋巴细胞增多伴CD5/CD23共表达与涂抹细胞——老年人体检意外发现多于其症状的诊断）。
:::

::: exercise 管理第一天 {level=2}
55岁新诊断AML，WBC 180、肌酐130、尿酸640、钾5.4、LDH 2900。给出预防方案与监测间隔，并说出你在预防的机制。
::: solution
**肿瘤溶解综合征预防**——自发性与化疗后胞内钾、磷与核酸（嘌呤级联的尿酸）释放伴发次性钙磷沉积：**收治入院、持续心电监护、积极静脉补液（细胞减灭前即开始2–3 L/m²/日等效水化）、别嘌醇（高危或已存在的高尿酸用拉布立酶——G6PD缺乏者绝不用）、停钾停磷、钙只给症状性低钙（钙磷乘积）、每4–6小时电解质/尿酸/肌酐共48–72小时、预先安排好ICU与透析通路**。机制：尿酸与磷酸钙在肾小管结晶沉积驱动AKI、继而放大每个电解质紊乱；细胞减灭（羟基脲、WBC 180有症状滞留者白细胞单采——[[#def-aml]]的呼吸神经微闭塞）必须在保护运行时开始、从不在后。
:::
:::

::: exercise 为什么腰穿 {level=2}
用庇护所与复发模式解释为什么ALL方案经腰穿给药治疗、而AML方案多不给预防性颅脑放疗。
::: solution
淋系白血病在免疫与药理特权间隔——**中枢与睾丸**——藏身并复发，因为全身药物跨血脑屏障差、脑膜与睾丸壁龛选择储库克隆；不治疗时脑膜白血病是儿童ALL复发的普遍路径，而**鞘内甲氨蝶呤/阿糖胞苷±氢化可的松加中枢渗透的系统药（大剂量甲氨蝶呤、地塞米松）加风险调制的颅脑放疗（因内分泌、认知与第二肿瘤远期效应现被回避或减量）**把中枢复发从多数压到少数。AML的中枢侵犯更少（单核型与高白细胞型率较高——此时给诊断腰穿与鞘内覆盖），故全脑照射从来不在其治愈交易里。总教义——**庇护所必须预防性治疗，否则全身治愈在它那里失败**——在睾丸癌与中枢淋巴瘤预防中重现，也解释了睾丸与中枢在每个ALL方案中的位置。
:::
:::

::: exercise TKI耐药 {level=2}
CML患者第二年失去分子应答；激酶域检测示T315I突变。解释耐药机制、选药逻辑、及必须先于两者的依从性谈话。
::: solution
BCR::ABL1激酶域突变在药物选择下产生（克隆在口袋里演化）；**T315I——关口苏氨酸异亮替换——废除伊马替尼、尼洛替尼、达沙替尼与博舒替尼的结合**（第一二代药的位阻与氢键丢失），而留下**泊那替尼（围绕关口的炔键延长设计抑制剂）、asciminib（豆蔻酰口袋变构抑制剂——完全不同的结合位点）与移植**作为选项。先于药理的那场谈话：**不依从是失去应答最常见的原因**（每日两次、受食物与酸相互作用影响的方案——[[pharmacology/absorption-distribution]]的PPI与抗酸吸收陷阱），顺序是复核依从与相互作用、复测突变（耐药克隆与多克隆反弹不同）、再按突变与共病换药（达沙替尼的积液、尼洛替尼的QT与血管、泊那替尼的动脉闭塞风险管理）——也要求**PCR监测时刻表（使CML成为以血检管理的病的里程碑）的精准医学算法**。
:::
:::

::: exercise 分化综合征对脓毒症 {level=2}
APL的ATRA/砷第4天：发热38.6、体重增4公斤、低氧、间质浸润、肌酐上升。两个鉴别诊断、判别特征、及各自的处理。
::: solution
**分化综合征**（分化中早幼粒的细胞因子释放、毛细渗漏与器官浸润——发热、增重、水肿、低氧、浸润、低血压、肾损；高白细胞病以皮质醇预防）对**中性粒缺乏脓毒症**（APL患者仍中性粒缺乏——[[infectious-diseases/fever-sepsis]]的导管、中心静脉与肠道易位规则原样适用）。判别权重：综合征的**无感染源、随计数上升而非下降的快速增重与水肿（分化中的细胞）**、及其部分激素应答——但处理是**两手都做、问题后置**：**立即地塞米松10 mg每日两次（首次低氧即经验性按综合征治）、完整脓毒症检查与广谱抗生素、液体平衡与利尿或透析支持、重症暂停ATRA/砷**、及早死APL真正发生处的监护床升压与通气。教学：APL里治疗相关与感染相关的表现共享整个体征签名、且不治疗数小时内皆致死——故方案并行治两者、从不做鉴别后再治。
:::
:::

::: exercise 移植指征 {level=2}
给出本章各疾病异基因造血干细胞移植的现行指征，及它比二十年前既更多又更少被用的两个原因。
::: solution
**更多用（或用在更明确的生态位）**：首次缓解的不良风险AML（TP53与复杂核型组、化疗几乎无人治愈）、复发/难治AML与ALL（现常作为**blinatumomab或CAR-T缓解的桥梁**）、高危MDS/继发AML，及**非亲缘相合与单倍体供者的到来**（移植后环磷酰胺平台使家属成为供源）加**脐血与不合平台**把可及性扩展到HLA同胞之外。**更少用**：TKI时代的标危CML（移植几近废除）、良好风险AML与MRD阴性ALL（化疗/免疫治愈率使移植死亡率不可辩护）、及老年武器库大量转向**减低强度预处理**（非清髓的移植物抗白血病时代策略、以更快复发换耐受性——移植物抗白血病效应作为治疗的活性成分、慢性移植物抗宿主作为其税负）。组织原则即[[#def-aml]]教过的同一算术：移植替换骨髓并买来免疫抗白血病效应；在复发风险超过移植相关死亡率处提供——而现代靶向药不断为这个比较重新定价。
:::

::: exercise 设计临床试验 {level=3}
你在为60–75岁未治疗AML设计一线试验。指明对照骨架、一个基于本章生理的合理试验臂、分层变量、及定义现代AML试验的两个终点。
::: solution
**对照**：该年龄段现行标准——**维奈克拉加阿扎胞苷**（取代去甲基化剂单药的VIALE-A骨架；适合者仍以7+3为对照）——配方案的MRD适配巩固与移植规则。**试验臂（生物学驱动）**：如**FLT3突变层用维奈克拉/阿扎胞苷加FLT3抑制剂、或KMT2A/menin依赖层加magrolimab/CD47轴或menin抑制剂**——按靶点原理（克隆的依赖）与不重叠毒性（骨髓抑制与QT/器官签名的绘制）选择。**分层**：年龄档与体能（ECOG、心肾功能）、ELN遗传风险组、FLT3-ITD负荷、治疗对新生、基线MRD检测类型、及（日益）CHIP/克隆共突变（TP53、PPM1D）与MRD方法（NGS对流式的统一问题）。**终点**：**复合完全缓解（CR/CRi）伴MRD阴性作为关键次级、如今多设计里已是试验级主要终点，及总生存——加上旧试验缺如的患者报告与输血独立指标**。伦理框架：60–75人群“适合什么”即入组标准、安慰剂问题以叠加设计解决（每位患者都得活性骨架），而试验成功标准不是缓解率而是**两年时存活、脱离输血并离开医院的患者比例**——正是这个结局使维奈克拉-阿扎胞苷尽管生存曲线交叉仍成标准：本章历史恰是一连串这样的终点革命。
:::
