输血医学是把免疫学以最高节奏施行于 床旁施行的学问：两个抗原（ABO与Rh）加一列其他（Kell、Duffy、Kidd、MNS、Lewis）按Landsteiner定律排列、一个数分钟内揭穿不合的血管床、及1901–1940年代的发现序列（血型、抗原-抗体反应、柠檬酸盐保存、战时血库）——它们支撑每台手术、每次产科出血与每程白血病诱导。现代实践为这门技术添上后半：**血是稀缺、有风险、捐献来的资源，本学科之关乎不输血正如关乎安全输血**——患者血液管理即本章循证的第二主题。

本章讲述血型与抗体力学、成分治疗与相容性试验、输血反应、胎儿新生儿溶血病，及安全与管理系统。

## 血型与抗体

::: definition ABO与Rh系统 {#def-abo}
**ABO**是临床主宰系统，因为其抗体**天然存在**：**Landsteiner规则**——个体对其**缺乏**的A与B碳水抗原（H抗原前体经A/B糖基转移酶修饰、Bombay表型的抗H是教规则那个罕见例外）产生IgM（及IgG），无需可见感染、推测由交叉反应微生物与食物抗原刺激：O组有**抗A与抗B**、A组有抗B、B组抗A、AB组两者皆无——这就是**主侧交叉配血**（供者红细胞对受者血浆）是性命攸关的方向、**O组红细胞是急救万能供者**而**AB血浆（无两种抗体）是血浆万能供者**的镜像规则、及为什么一单位O型全血不适合AB受者。**Rh(D)**与其余系统（Kell、Duffy、Kidd、MNS、Lewis、Lutheran）一般需要来自暴露的**免疫性（IgG）抗体**（输血或妊娠——Kidd抗-Jkᵃ的回忆性、延迟、血管外溶血模式、及输血实践要求潜在暴露患者**每≤3天标本复查抗体筛查**的原因）。随之的临床架构：**血型与抗体筛查**（筛查细胞panel）、**鉴定**（panel与酶与硫醇研究）、**交叉配血或电子发放**（筛查阴性且计算机核对身份与病史时）、**直接抗人球蛋白试验**（读出已在细胞上的抗体或补体的Coombs——[[blood/haemostasis-bleeding]]与[[blood/lymphoma-myeloma]]的共用工具）、及急救方案（**实验室工作时用O阴性红细胞与AB血浆、定型安全即切分组特异血**）——整个体系由一个事实支撑：**ABO不合的红细胞引起即刻血管内溶血**，而IgG包被细胞**数小时到数日后成为脾巨噬的牺牲品**（血管外——延迟溶血反应及其无法解释的计数下降与轻度黄疸）。
:::

## 成分与保存生理

::: definition 究竟输什么 {#def-components}
全血分成各具保存生物学的治疗：**红细胞**添加液、4 °C保存42天；**保存损伤**——ATP与2,3-BPG下降（解离曲线左移、输后数小时恢复）、膜出泡与钾漏（快速大量新生儿输注用新鲜细胞、高钾心脏外科患者红细胞要洗涤的原因）；**血小板**（单采单位——一个治疗剂量血——**室温连续振荡保存5–7天**：细菌生长风险使血小板成为最常见的输血感染、推动病原体灭活技术与保存对脓毒症之权衡）；**血浆**（≤72小时速冻保留不稳定因子V与VIII的FFP、37 °C融化——[[blood/thrombosis-anticoagulation]]逆转之问的容量与柠檬酸盐负荷；及**冷沉淀**——纤维蛋白原、血管性血友病、因子VIII与XIII组分、[[blood/haemostasis-bleeding]]产科DIC的补纤维蛋白原主力）；**粒细胞**（罕见、角落、带其淋巴细胞内容的肺反应）；及作为“生理即处方”的**特殊处理**：**去白细胞**（发达血库普遍——HLA同种免疫、发热反应与白细胞亲和病毒（CMV）传播降到“CMV安全”）、**照射**（防**输血相关移植物抗宿主病**——供者淋巴细胞在免疫受损或HLA纯合亲属输血中植入、几乎必死、25 Gy预防：指征清单——宫内与新生儿、嘌呤类似物与干细胞患者、亲属定向捐献、HLA相合制品）、**洗涤**（去血浆蛋白——易过敏IgA缺乏患者的路径）、及IgA缺乏与重度过敏史的容量减少/洗涤——每种处理都是[[#def-reactions]]某个反应的直接答案。
:::

## 反应及其机制

::: definition 输血反应鉴别 {#def-reactions}
按小时与机制排序：**急性溶血性输血反应**（数分钟——通常是**抄写/床旁错误所致ABO不合**：发热、腰痛、低血压、血红蛋白尿、DIC与罕见早期死亡——处理算法以**停输、生理盐水保通路、核对标签与标本、直接抗人球蛋白试验、支持循环与尿量**开始、“医院内科最常见的严重错误”、每条条码核对政策存在的理由）；**非溶血性发热反应**（保存制品细胞因子积累与受者抗供者白细胞抗体——去白使其更罕见的排除诊断；扑热息痛、而检查仍须排除溶血与细菌）；**过敏与过敏性**（血浆蛋白的荨麻疹；**伴抗IgA的IgA缺乏患者过敏性休克**——洗涤细胞与最小血浆制品、肾上腺素与气道处理）；**TRALI**（供者抗HLA/HNA抗体——常经多次生育供者、故仅男性血浆政策——受者肺中性粒启动与**6小时内低血压发热的非心源性肺水肿**：支持治疗、利尿无益、必须与其模仿者分开的诊断）；**TACO**（静水压对应版——容量与速度、高血压、利钠肽、放射淤血：**利尿与更慢速度**、两个诊断的伤害相反、算法要求BNP/超声评估；老年心肾患者与ICU推注实践是其流行病学）；**细菌污染/脓毒症**（血小板为首——寒战、休克、血袋革兰染色与患者及血袋急查培养）；**延迟溶血与血清学反应**（数日——回忆性IgG、无法解释的输后贫血黄疸、Kidd与Duffy系统的专长、血红蛋白病患者的同种加自身抗体雷区）；**输血相关移植物抗宿主病**（数日至数周、皮疹、腹泻、全细胞减少、>90%致死——[[#def-components]]的照射指征）；及**长尾危害**——慢性输注的铁负荷（[[blood/haemoglobin-disorders]]的螯合）、输血传播感染（HIV、HBV、HCV与梅毒靠供者选择加血清学及**核酸检测**、疟疾与巴贝虫旅行回避、理论上的vCJD——每一层都是一桩1980年代丑闻的历史）、及**免疫调节**文献（旧的“去白/自体血感染更少”观察现多由下文限制性输血生理解释）。统一的床旁规则：**任何血制品输注中或刚后的任何新征象——发热、低氧、低血压、深色尿、皮疹——在排除反应前就是输血。**
:::

::: example 手术台上的深色尿 {#ex-ahtr}
剖腹手术输第二单位红细胞二十分钟，麻醉师注意到切口渗血、导尿呈可乐色、患者低血压、监护显示气道峰压上升；外科医生问怎么办。
::: solution
**急性溶血性输血反应直到证明不是**——全麻下经典三联被隐藏、这些是其替代征：**无法解释的低血压、支气管痉挛/气道压上升、弥散出血（凝血活酶样颗粒释放的消耗性凝血病）与深色尿（血红蛋白尿）**。算法背诵：**立即停输**（剩余血与输器送回实验室——血袋与患者标本是法证与临床证据）；**维持静脉通路、给盐水/容量支持循环与尿量（液体负荷，随后手术允许范围内的低剂量儿茶酚胺支持）**；**核对抄写链（标签、腕带、标本）并送反应后标本复查血型、抗体筛查、直接抗人球蛋白、游离血红蛋白、触珠蛋白、纤维蛋白原、血小板、肌酐与钾**；**通报**——血库冻结该患者其他成分并启动回溯；及**处理两个效应器**：DIC（按[[blood/haemostasis-bleeding]]靶值的制品）与血红蛋白尿肾（容量、避免肾毒性一击——麻醉推论：术中维持血压高于接受较低血压）。最常见原因不在实验室而在床旁：**把错的血输进患者**——条码与双识别核对政策、及“绝不输与腕带不符的单位、绝无视停输血为小事”就是输血安全版的外科核查表（[[clinical-skills/patient-safety]]）。
:::

::: example 一周后下降的计数 {#ex-delayed}
产后贫血一次顺利输血后十天，女性黄疸气促复诊；Hb已低于输血后峰值、网织红上升、LDH 900、触珠蛋白不测出、DAT现阳性并鉴定出抗-Jkᵇ；首次输血检查抗体筛查阴性。
::: solution
**延迟溶血性输血反应**——[[#def-abo]]回忆应答的教科书形：既往妊娠（或输血）使她免疫于Kidd（Jkᵇ）；滴度衰减**到筛查检测限以下**、输血再暴露在数日内驱动IgG上升、抗体包被的供者细胞被脾巨噬清除（Kidd世界里她自身细胞Jkᵇ阴性——仅供者细胞破坏）——故第5–14天黄疸、LDH与计数下坠。Kidd系统两个臭名昭著的属性即本例：**会衰减到测不出的滴度（阴性筛查是诚实的、不是无用的）与补体在红细胞上的固定（可剧烈——甚至血管内——溶血及罕见急性肾图像）**。管理：**停止一切择期输注、识别仍在循环的不合单位效应、支持、需要时输Jkᵇ阴性、记录并咨询**——该抗体今为终身、鉴定进入档案与卡片、每个未来实验室必须提前发现它、及下次妊娠的**产前含义**（[[#def-hdfn]]监测现把Kidd列为真正的HDFN病因、比D轻但真实）。 发病率会议上引用流行病学：多数严重延迟反应跟随**有临床指征但勉强**的输血——[[#def-pbm]]的管家论证写在一个人的黄疸里。

::: example 第一次就封喉的剂量 {#ex-anaphylaxis}
血浆头几毫升输入数秒后患者出现喘鸣、哮鸣、腹泻与循环虚脱、发热轻微；她既往两次输血均平稳、且有反复胸部感染史。
::: solution
**伴抗IgA抗体的IgA缺乏患者过敏性休克**——[[#def-reactions]]的经典机制：选择性IgA缺乏（最常见的免疫缺陷、除鼻窦支气管感染与自身免疫外常无症状、[[immunology/immunodeficiency]]的流行病学）使**抗IgA IgG/IgE**遭遇普通制品的血浆蛋白；既往输血使她致敏、再暴露触发肥大与嗜碱脱颗粒——**荨麻疹可以缺席、虚脱随头几毫升到来、反应针对血浆蛋白而非红细胞**（故它在血浆与血小板制品和红细胞同样出现）。即刻处理是过敏性休克而非“暂停输血”：**停制品、肌注肾上腺素、气道与氧、液体与平卧、抗组胺与激素为辅**，配实验室检查（血清类胰蛋白酶时机、**抗IgA测定与IgA水平**）——及稳定后防复发的输血计划：**洗涤红细胞与血小板（洗涤去血浆蛋白——[[#def-components]]的处理指征）、血浆及含血浆制品只用IgA缺乏供者来源或不用（FFP之问即为何预先指定冷冻/去甘油洗涤细胞策略）、过敏与免疫转诊、记录的卡片与血库标记、无替代时预用药加慢速方案。**团队仍须在同样几分钟排除的鉴别：细菌污染（血小板单位的寒战休克）、TRALI（低氧为主、较慢）、及结合珠蛋白缺乏患者血浆的过敏样补体激活制品反应——但IgA故事是改变每一张未来处方的那个。

## 胎儿与新生儿溶血病

::: definition 同种免疫妊娠 {#def-hdfn}
机制一行：**母体IgG同种抗体（针对来自父亲的胎儿红细胞抗原形成——RhD最著名、但抗-c、Kell、Duffy及其余在D预防时代日益增多）跨过胎盘溶化胎儿红细胞**，产生**贫血伴髓外红系造血、高胆红素血症、重型则胎儿水肿**（[[blood/haemoglobin-disorders]]水肿物理在高输出心衰、腹水与胎盘增大中的免疫而非珠蛋白版）；新生儿脸是**头24小时上升的、非结合的、威胁白蛋白的黄疸**（不同于生理性黄疸的第2–3天起病）伴**脐血直接抗人球蛋白阳性**、及可能在出生后数小时或数周出现的贫血（Kell阳性“晚发贫血”、其网织红应答被抑制——Kell的靶抗原在红系前体、是溶血加生成不足的双伤）。预防是本章最伟大的公共卫生胜利：**给D阴性母亲28周（或按国家方案30/34周）及致敏事件后72小时内的抗D免疫球蛋白**、其效力（共识试验与人群级HDFN下降）建立在母体免疫化前清除胎儿细胞；**剂量随母胎失血量放大——Kleihauer（酸洗脱）或流式定量**（算术——见下文示例）⇒追加抗D。已同种免疫者的监测：**抗体滴度（临界滴度阈值）、大脑中动脉峰值收缩期流速多普勒（贫血的黏度物理——流速升高预言胎贫）、**宫内输血**（超声引导脐静脉穿刺、输压缩O阴性、CMV阴性、照射、去白、血细胞比容配比的血液——把水肿从判决变成管理方案的治疗）、分娩时机与早产权衡，然后新生儿光疗、IVIG（Fc阻断原理）与高胆红素急症的换血——核黄疸阈值归[[paediatrics/newborn]]。
:::

::: example 抗D的算术 {#ex-anti-d}
D阴性女性38周娩出D阳性婴儿；90分钟后筛查试验报告母体循环中4%胎儿细胞，其总红细胞量估计为2.5升血、母细胞4.5×10¹²/升。
::: solution
母胎失血量：约（2.5升×4.5×10¹²细胞/升⇒胎儿细胞≈0.04×该数）的4%。计数转体积不精确——实验室报告**胎儿细胞百分比乘母体红细胞体积**：0.04×约2500 mL≈**100 mL胎儿全血**（约50–60 mL胎儿红细胞）。标准剂量覆盖**4 mL胎儿红细胞按国家惯例对应125–1500 IU（英国：每2 mL胎儿红细胞125 IU（25 µg）；大出血用1500 IU（300 µg）加量模式）**⇒约60 mL胎儿红细胞：约**3750–4000 IU、以1500 IU重复或按方案加权给药**（确切数字由实验室与指南驱动——要点是**比例性**：失血更大需更多、而每个D阴性分娩都必须做该检测）。周边规则：**常规28周预防**（常规产前抗D方案）覆盖孕晚期隐匿失血；**分娩或致敏事件72小时内**（方案宽限到7–10天会减弱但不取消获益）；**婴儿D阴性或母亲已同种免疫则不用抗D**（抗体筛查决定——而近期预防的假阳性“抗D”必须对照已给剂量记录）；**无细胞胎儿RhD检测使本不存在的“D阳性胎儿之D阴性母亲”无需常规产前预防**、若干国家规划以靶向预防取代的普查方案；及**D阴性母亲自身急救时的D阳性输血政策**（给她D阳性血而非耗尽O阴性库存、接受免疫化——若足够早给予预防仍可能钝化：产科出血指南的细微）。该病例是Landsteiner 1901年发现完成其弧线：从血型系统到阻止第二次妊娠之病的剂量计算，恰好一个世纪。

## 血液管家：何时（不）输血

::: definition 患者血液管理 {#def-pbm}
证据时代（TRICC的限制对宽松ICU阈值、心脏与骨科手术的FOCUS与Villar试验、SAQRI与TRISS产科与创伤系列）定了核心问题：**稳定患者70–80 g/L的血红蛋白并不比90–100 g/L更可靠地触发输血——触发是生理（心肌缺血、低容量休克、活动性出血、症状性贫血），不是数字**——限制策略减少同种血暴露而无伤害（少数试验“宽松安全”的结论建立在血确实输了、而非更高的设定点有益）。其上建构的规划：**术前**（识别并治疗缺铁——[[cell-biochemistry/nutrition]]与[[blood/anaemia]]路径、口服对静脉决定；按[[blood/thrombosis-anticoagulation]]桥接逻辑停抗凝；选定患者用EPO）、**术中**（常温与酸碱与钙控制——致死三角生理、预计失血的自体血回输、氨甲环酸——CRASH-2与WOMAN证据见[[blood/haemostasis-bleeding]]复审、外科技术与止血设备、及**贴合生理的限制性麻醉计划**）、**术后与内科**（采血最小化——每张住院黄疸病历的医源性失血审计、口服铁与CKD-EPO策略、使“写明指征”成为临床标准指标的输血照护记录、及稳定病房患者的**输一单位再评估规则**）。血液保全的终点是双向安全：未输的出血者死于休克、过度输注者死于TACO、TRALI、反应与成本——带**宗教信仰者规划**（无血外科路径、白蛋白与因子替代、自体回输与EPO接受度谈话）作为本章伦理门诊附录。系统层：**输血警戒**报告（严重输血危害与警戒局方案——推动床旁条码核对的事件率看板）、**供者选择与检测**（问卷与病原体算法、NAT混池检测、血小板病原体灭活、回避政策之争）、**库存**（过期、紧急发放与重大事件panel）、及使回溯与不良事件调查成为可能的**从静脉到静脉的可追溯性**：本章最简单临床句子背后的全部基础设施——**为患者输血、不为数字；每个反应在证明前都当输血。**
:::

::: history
**Karl Landsteiner**1901年发现人类血型（1930年诺贝尔奖、Decastello与Sturli 1902年补上AB）、**Ottenberg**1907年首次输血、**Hustin与Brinkman**血型时代的实践、**Robert Robertson**1918年柠檬酸盐与冷藏保存血、**Norman Bethune**1932–36年移动血库车与战时血浆全血体系（Chatelain的冻干血浆、北非登陆）、**Landsteiner与Wiener**1940年猴免疫血清定义Rh因子（Levine与Rosenfeld溶血病机制的诺奖级工作）、及**Clarke、Finn、Mourant、Race与Taylor**1940–60年代的利物浦-布里斯托-伦敦规划——把抗D预防从志愿者试验带进国家政策、结束了Rh病作为婴儿常见死因。反应分类学随后：**Mollison**的红细胞保存与相容性教科书（“Blood Transfusion in Clinical Medicine”数代）、1970年代TRALI的认识（Popovsky与Sachs的抗体研究继Britton、Engelfriet与Korst系列）、**Slichter与Aster**的血小板研究与单采时代、及现代限制性输血试验与输血警戒体系，完成从Landsteiner试管到安全看板的弧线。
:::

## 通向何处

免疫机制在[[immunology/antigen-recognition]]与[[immunology/hypersensitivity]]；血红蛋白病的输血医学在[[blood/haemoglobin-disorders]]；产科出血管理在[[obstetrics-gynaecology/pregnancy-antenatal]]与[[emergency-critical-care/acute-assessment]]；围术规划在麻醉与外科章节；铁与EPO治疗在[[blood/anaemia]]与[[renal/chronic-kidney-disease]]。

::: summary
- ABO之所以要紧，因其抗体是针对微生物模板碳水、天然存在的IgM——Landsteiner规则固定供受者相容矩阵（O红细胞与AB血浆万能、急救发放的镜像逻辑）；其余系统经免疫IgG致病（延迟、血管外、妊娠驱动）。
- 成分是保存生理的制品——4 °C带保存损伤的红细胞、室温带细菌风险的血小板、补因子与纤维蛋白原的FFP与冷沉淀——而特殊处理（去白、照射、洗涤）各防一个具名反应。
- 急性反应是机械抄写型（错血）、免疫型（溶血、TRALI、过敏/休克）、循环型（TACO）、感染型或免疫晚期型（TA-GvHD、铁、同种免疫）；床旁算法是停、核、支持、报告。
- 胎儿新生儿溶血病是母体IgG抗胎儿抗原——用按量失血给药的抗D可预防、在同种免疫者用多普勒监测与宫内输血可管理。
- 限制性、生理触发的输血是证据默认，患者血液管理——术前三相——如今是半个学科，由输血警戒与供者检测体系保证另半安全。
:::

## 练习

::: exercise 定型逻辑 {level=1}
细胞与抗A、抗B都凝集；血清凝集A与B细胞但不凝集O细胞。解决这个表面矛盾，并说出要检测的现象。
::: solution
正定型=**AB**组；血清本应**无抗A或抗B**——两种试剂细胞皆凝集提示**额外抗体（抗H、冷自身凝集素、缗钱状或阳性对照问题）**，或经典地——**获得性B表型**（脓毒症与结直肠病中肠菌酶使A组去乙酰化、模仿B），或反方向**缺失/弱反应提示Bombay（抗H）或无丙种球蛋白状态**。解决：洗涤细胞复查、看盐水对照、查唾液ABH物质并测抗H；考试版：**正/反不符必须先解释再发血、绝不按“可能”血型输血。**
:::

::: exercise 为什么是三天 {level=1}
为什么潜在妊娠或多次输血患者的血型与筛查标本不得超过72小时？及创伤实验室为什么可以完全不带标本发放？
::: solution
标本的职责是证明**当前**无同种抗体：输血或妊娠后数日内**回忆性IgG上升可在测不出的同时记忆存在**——[[#def-abo]]的延迟溶血布局（及Kidd抗体恶名的原因：滴度降到测不出、再暴露时爆发）。故暴露人群72小时规则、及电子发放要求**近期有记录在案的阴性筛查**。创伤例外是风险演算而非免疫学：**不配血O（D阴性或按方案选择）红细胞与AB血浆不携带受者抗体风险**（无相容供者抗原可反应）——接受的风险是**D免疫化**与O库存浪费、政策权衡写入重大事件指南。
:::

::: exercise TRALI对TACO {level=2}
两单位FFP后一小时患者SpO₂ 84%、双肺浸润、体温38.5 °C、血压85/50、颈静脉压不高、BNP轻度升高；同夜另一患者同样的低氧浸润而血压170/95、颈静脉怒张至下颌角、BNP 1400。分别处理并从机制论证。
::: solution
**第一例=TRALI**（发热、**低血压**、无容量负荷、供者抗体在肺微血管的中性粒启动——非心源性通透性水肿）：**停输、坐起、氧、必要时通气（ARDS生理的肺保护策略——[[respiratory/respiratory-failure]]的药）、低血压审慎补液、升压药、不用利尿剂（患者不湿——贴错标签的伤害）**、上报血袋做供者抗体检测（涉事供者被退档——多次生育女性血浆政策就因这例存在）。**第二例=TACO**（高血压、颈静脉充盈、BNP高、静水压）：**停或减速、直立、静脉呋塞米、氧±无创通气、后续制品的速度与容量重定**（小单位、间隔利尿覆盖、老年心肾者是流行病学）。床旁判别是**血压与颈静脉压多于胸片**——两者都可水肿、两者都可胸腔积液——并提醒两例都需**停输血并上报事件**：医护不打电话给血库，输血警戒的分母就填不满。
:::

::: exercise 困难交叉配血 {level=2}
温抗体自身免疫性溶血性贫血患者（Hb 45、心绞痛、DAT强IgG阳性、panel反应性抗体）需急诊手术。解释“最少不相合”、实验室的工作与临床决定。
::: solution
自身抗体与**每一袋**供者细胞反应（Rh核心共同决定簇——温AIHA抗体通常panel反应性），故**真正相容的交叉配血不存在**；实验室**用吸收（洗脱/差减）去除自身抗体、揭示潜在的同种抗体（10–30%并存——会造成真实反应的Kell、Duffy、Kidd）**、绕过包被定型（基因分型或预处理洗脱）、并发放**“最少不相合”单位**——交叉配血不劣于自身基线的单位。临床上：**缺血或出血时照样输（怕输血并不降低它所警告的反应风险——扣着携氧能力比同种免疫更快杀人**）、慢输并监测、通知上级血液科医师与实验室主任、加**激素（疾病修饰线用利妥昔单抗——[[blood/haemostasis-bleeding]]的AIHA阶梯）**使输注细胞活得更久，并记录抗人球蛋白试验将持续阳性、**输后“相容性评估”血清学上无法解释**——同一解读纪律适用于近期输过血者与多次同种免疫的镰状细胞患者扩展配型单位（[[blood/haemoglobin-disorders]]的方案）。
:::

::: exercise 谁需要照射血 {level=2}
列出照射制品的指征及各自预防的机制，并指出一个尽管理论上有风险、仍被认为无需足量照射的输血场景。
::: solution
**机制**：TA-GvHD由**活供者淋巴细胞**在不能拒绝它们的受者（免疫受损、或供受者HLA单倍型相同以致受者视之为己——亲属定向捐献与HLA纯合人群）植入所致；**照射（25 Gy）损毁淋巴细胞DNA而保留红细胞与蛋白功能**。指征：宫内/换血与新生儿输血、霍奇金淋巴瘤（历史惯例）、嘌呤类似物（氟达拉滨、克拉屈滨）与T细胞消耗治疗（抗胸腺细胞球蛋白、alemtuzumab）、造血干细胞移植受者、HLA相合血小板、**血缘关系供者的一切细胞成分**、及先天免疫缺陷（DiGeorge、重症联合免疫缺陷）。**无需照射的场景：普通人群的日常红细胞输注**——免疫健全受者会拒绝供者淋巴细胞、TA-GvHD的病例几乎全部落在上述名单内；英国等指南据此只保留指征清单（美国惯例更宽）。其余加工对照表：去白防发热反应/HLA免疫/CMV；洗涤防IgA过敏；而照射单独防这个最致命的少数派。
:::

::: exercise 血小板无效输入 {level=2}
骨髓增生异常患者每输两个混合血小板后两小时计数只升2×10⁹/L而非40；她已输过三十次、发热、用两性霉素、脾大。分开机制并给出检查与选项。
::: solution
**无效输入分为消耗/滞留（常见原因——发热与脓毒症、两性霉素B、脾大、DIC、活动性出血——本题干全部在场）与免疫性同种抗体（HLA I类——妊娠与既往输血的HLA抗体、更少为HPA血小板特异抗原）**：**10分钟至1小时校正计数增量**（10分钟增量差指向免疫；10分钟好而24小时差指向消耗）与**HLA抗体筛查（固相法）**。检查与管理：先治脓毒症与药物原因（占多数）；免疫性——**HLA/HPA抗体鉴定与抗原阴性或配血筛选血小板（转诊实验室服务）、ABO相合制品、避免不必要输注；不应答患者按临床出血阈值而非预防数字**（本例务实底线），记住预防性血小板阈值（10、发热/抗凝/操作时更高）是为防自发出血、而在完全消耗驱动的患者无法满足——血液科医师与该类患者的谈话是关于出血风险而非计数，这既是输血技术也是[[geriatrics-palliative]]与血液伦理的素材。

::: exercise 宗教拒绝者的开腹手术 {level=2}

为产科大出血制定医院大量输血方案：触发、制品比例与靶值、实验室支持、辅助与审计指标——每项以本章与[[blood/haemostasis-bleeding]]的生理论证。
::: solution
**触发**：临床——初始复苏无效血流动力学的大出血、产科出血车/铃激活与**双医师呼叫**、头几分钟通知实验室（产前入院的血型筛查是[[obstetrics-gynaecology/pregnancy-antenatal]]让第一分钟成为可能的政策）。**制品**：1:1:1时代固定比例（红细胞加FFP加血小板——6:1:1对照的更早止血与PROPP-ART时代生存趋势、纤维蛋白原优先纠正：**冷沉淀或纤维蛋白原浓缩物至>1.5–2 g/L、产科人群纤维蛋白原跌得最快**——妊娠的超生理纤维蛋白原本基线坠入低纤维蛋白原是最早的[[blood/haemostasis-bleeding]]异常）、**血小板靶>50（部分产科方案活动出血时>75）**、**三小时内TXA（WOMAN证据）**、**钙监测并补充（麻醉师绝不可把柠檬酸盐负荷低钙误当复苏失败）**、常温（液体加温、强制暖风、致死三角生理）、及**经验性首轮后的粘弹性引导升级**（ROTEM/TEG引导的产科算法在试验系列里减少红细胞与制品）。**实验室**：重大事件标本组（血细胞计数、凝血与纤维蛋白原、含钙与乳酸的生化、血气、相关时查Kleihauer的细胞计数）、**按方案规定单位间隔复查**、**方案后铁与抗体随访**、D阴性母亲按[[#ex-anti-d]]的抗D算术。**审计指标**：至首制品时间、交付比例、入ICU时纤维蛋白原、钙与温度、切除子宫与ICU率、每例红细胞单位数、反应与输血照护记录、及**模拟演练规划**（Motherhood时代的证据：方案的价值一半在演练一半在配比）——输血生理成为系统设计的完整示例。
