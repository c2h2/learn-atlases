止血是循环系统与自己的妥协：让血足够流动以灌注毛细血管，又足够密闭以让刀伤无足轻重。解答是空间与时间的——血小板与血管性血友病因子数秒内堵住破口（一期止血），血浆蛋白级联数分钟内以纤维网加固（二期），纤溶系统与天然抗凝药严阵以待、血管修复后把一切逆转。出血与血栓疾病几乎可以从这个设计机械地读出：**病史说血小板还是血浆，实验室说哪个因子，混合试验说缺乏还是抑制物。**

本章讲述血小板与血管壁生理、细胞基础的凝血级联、纤溶、实验室路径，及常见的遗传性与获得性出血病。

## 一期止血

::: definition 血小板栓 {#def-platelet}
动脉损伤暴露内皮下**胶原**，血小板直接结合（GPVI与α2β1）、并在动脉剪切下经**血管性血友病因子（VWF）**间接结合——这种内皮（Weibel-Palade小体）与巨核细胞糖蛋白的**A1域在高剪切下展开**、把血小板**GPIb-IX-V**连到基质：VWF是微动脉的血小板黏附分子的原因（也是其先天缺乏——血管性血友病——是皮肤黏膜出血问题、其极度缺乏——主动脉瓣狭窄的Heyde综合征、体外循环的剪切——产生血管发育不良出血的原因：**剪切感知分子两边都解释**）。黏附即激活：变形、血栓素A₂与ADP释放（阿司匹林与噻吩并吡啶的靶——COX-1与P2Y12）、**GPIIb-IIIa（αIIbβ3）激活**行纤维蛋白原桥联聚集（其缺乏是Glanzmann血小板无力症；其药物阻断是阿昔单抗与口服药的出血代价）、及促凝表面暴露（磷脂酰丝氨酸——[[#def-cascade]]的十聚酶与凝血酶原酶平台）。血小板阈值是外科背诵：**多数止血>50×10⁹/L、神经与眼科操作80–100、约10–20以下自发瘀点出血**，而**质的**缺陷（尿毒症、阿司匹林、体外循环）在通过上述数字的计数下出血——这就是出血时间的工作交给病史、需要时交给PFA-100闭合时间或聚集仪。
:::

## 二期止血：细胞基础的级联

::: definition 酶级联及其调控 {#def-cascade}
教学图（内源/外源途径在因子X会师）是**有临床用处的实验室人工物**；生理图像是**细胞基础**的：血管周细胞上的**组织因子（TF，因子III）**遇见循环**因子VII**，**TF-VIIa复合物**生成的凝血酶爆发、其规模足以被**抗凝血酶（肝素辅因子——药物的辅因子）、TFPI与血栓调节蛋白激活的蛋白C（凝血酶从促凝到抗凝信号的“开关”，其失灵——蛋白C或S缺乏——是一种静脉血栓的遗传、华法林皮肤坏死的机制）**刹住，而激活血小板表面的扩增运转**十聚酶（FIXa-FVIIIa）**与**凝血酶原酶（FXa-FVa）**复合物，FVIII与FV是**从VWF释放、被蛋白C灭活的辅因子**（血友病A与因子V Leiden之轴）。纤维蛋白原→**纤维**，被**因子XIII**交联（血块的凝固；其缺乏的延迟出血与愈合不良），而交联的后果——抗尿素——就是旧的血块溶解试验。两项临床筛查报告这台机器的片段：**PT/INR**报外源与共同臂（VII先跌——半衰期最短——然后X、V、II、纤维蛋白原：华法林与肝合成功能的监测）、**APTT**报内源与共同（VIII、IX、XI、XII——肝素与血友病的监测）、**混合试验**（1:1正常血浆纠正缺乏、不能纠正抑制物——伴狼疮抗凝物的特征**悖论**：一个预测**血栓**而非出血的实验室延长——[[blood/thrombosis-anticoagulation]]的问题），及纤维蛋白原抗原/活性加D-二聚体（纤维转换——血栓的纤溶反应、妊娠、炎症、癌症时升高：**高敏感/低特异**标志、其临床价值恰在对静脉血栓栓塞的极高**阴性预测值**——又见[[blood/thrombosis-anticoagulation]]）。
:::

::: definition 纤溶 {#def-fibrinolysis}
**纤溶酶原**经结合纤维赖氨酸位的Kringle域进入血块，被内皮**组织型纤溶酶原激活物（t-PA）**（及尿激酶）裂解为**纤溶酶**，反应**与纤维共定位**（链激酶与现代溶栓药纤维选择性及其颅内出血风险的根据）；**α2-抗纤溶酶**中和游荡的纤溶酶、**PAI-1**（内皮抑制物、代谢综合征时升高——所传的晨间心梗之说与真实的促血栓倾斜）终结该系统，而**氨甲环酸**（赖氨酸类似物、阻断纤溶酶原结合纤维——CRASH-2创伤与WOMAN产后出血的证据，也是它如今为这两类出血一线的原因）与**抑肽酶**（撤市后又在部分体系的心脏外科回归）是其药理刹车。
:::

::: example 幼儿的关节出血 {#ex-haemophilia}
18个月男孩因轻微磕碰后右膝肿痛不活动就诊；易瘀；母系舅舅“打针出过事”；PT正常、APTT 78秒、血小板240。
::: solution
**血友病A，直到因子检测否定**——图像即本章第一段：**深部组织出血（关节腔、肌肉血肿）=血浆问题；PT正常/APTT延长=内源因子缺乏（VIII、IX、XI、XII）；男孩母系舅舅患病=X连锁（[[genetics/mendelian-inheritance]]的经典家系）**——因子XII延长APTT却完全不流血，所以临床图像是半个诊断。以因子测定确证（VIII<1%重型：自发性关节肌肉表型；1–5%中型：小创伤后出血；>5%轻型：外科与产后才被发现）。即刻处理：**先因子替代（重组VIII；或预防治疗的儿童用emicizumab——重新定义重型血友病预防的双特异性“模拟抗体”；存在抑制物时用旁路药）**、镇痛、制动与早期理疗，且**新鲜血友病关节在因子覆盖运行后除诊断存疑外永不穿刺**。漫长的弧线是这个诊断至今仍需低声说出的原因：**抑制物产生**（对输注蛋白的同种抗体——历史与现实的主要风险、以滴度监测、用免疫耐受或旁路药处理）、**肝炎与HIV血友病队列**（1970至85年未因子之灾——现已治疗、现已治愈，及[[medical-ethics-law]]医疗伤害正义的案例分析）、**预防**（因子或emicizumab自童年把毁关节的病变成近乎正常的病，而其价格本身是伦理问题）、母系遗传咨询（携带者检测、产前选项、三分之一无家族史的起源——[[obstetrics-gynaecology/pregnancy-antenatal]]高危妊娠的讨论）。
:::
:::

::: example 止不住的口腔出血 {#ex-vwd}
21岁女性初潮起月经量多、每月两次鼻衄、拔牙后出血；其母亲病史相同；血小板260、PT正常、APTT 41秒（轻度延长）、因子VIII 28%、VWF抗原22%、瑞斯托霉素辅因子20%。
::: solution
**血管性血友病1型**——皮肤黏膜出血模式（月经、鼻、牙——血小板型病史）、**VWF抗原与功能均低而因子VIII被拖下水**（VWF是VIII的载体蛋白——故APTT适度延长、及在女性拖延诊断多年的血友病A模仿），常染色体显性遗传（两性、家族史），**1型（定量、最常见、轻中）** 对**3型（VWF测不出、VIII极低——重型隐性）** 之别，及**2型的质的缺陷**（2B变异功能获得性GPIb结合造成**去氨加压素加重的血小板减少**——本领域最危险的陷阱）。检查：上述组合复查（VWF是**急性时相反应物**——运动、应激、雌激素与炎症使其假性正常；查两次、停避孕药、非出血期），多聚体分析与RIPA做2型分型。按严重度治疗：**去氨加压素**（释放内皮VWF储池——试验剂量并附钠与液体说明、重复后快速耐受、2B型禁忌、老年人低钠风险慎用）、去氨加压素无效与3型用**VWF浓缩物**（血浆源、含或不含rVIII）、**抗纤溶辅助**（牙与月经出血用氨甲环酸；月经量多用激素避孕）、及**急救卡与术前计划**——这个曾有“假血友病”之名、在检测出现前漏掉半数患者的疾病。
:::

::: quiz
一位华法林患者治疗早期PT延长而APTT正常。最佳解释：
- [ ] 实验室误差
- [x] 因子VII（外源臂）半衰期最短，故PT先于内源臂因子下降而升高
- [ ] 肝素污染只影响APTT
- [ ] 华法林只抑制因子VII合成
::: solution
华法林阻断**II、VII、IX、X（及蛋白C与S）的γ-羧化**——四个都阻——但**因子VII约6小时的半衰期**先耗竭，PT（VII敏感）一两日内即延长而APTT（X、II、IX敏感；II半衰期约60小时）滞后：**抗栓效应随数日后的治疗INR才到**（凝血酶原本身必须降）——这就是急性血栓**肝素桥接**（[[blood/thrombosis-anticoagulation]]）与**早期短暂高凝**（蛋白C短半衰期先于X与II下降——华法林坏死与早期复发诸现象）的生理依据。一则有真实根基的口诀：INR测的是药物第一个牺牲者；抗栓效应等的是它最慢的。
:::

## 获得性出血疾病

::: example 健康孩子的低血小板 {#ex-itp}
5岁孩子病毒皮疹后三天瘀点与大片瘀斑、看似健康；Hb与白细胞正常、血小板8×10⁹/L、涂片其余正常、无脾大。
::: solution
**免疫性血小板减少（ITP）**——本来健康儿童孤立性血小板减少（即定义即诊断：涂片、其余系列正常、脾不缺位——若脾大或涂片古怪，诊断改成白血病、脾功能亢进或血栓性微血管病直到排除）。机制：**抗GPIIb-IIIa/IB自身IgG**（常为病毒后、与血小板糖蛋白交叉反应）调理血小板供脾巨噬清除——**破坏而非生成不足**，故涂片血小板巨大、巨核细胞正常到增生（如果有人去看的话——不该看：典型病例的检查不含骨髓）。令人意外的治疗规则：**治出血不治数字**——多数儿童ITP（三分之二）数周内自行缓解，故观察覆盖仅有皮肤表现的孩子；**糖皮质激素（或有重要黏膜出血/操作时）、IVIG升得最快（其脾内Fc受体饱和——机制解释速度）、抗D只用于Rh阳性未切脾人群并带溶血警诫**；复发/持续/慢性类别转向TPO受体激动剂（[[blood/haematopoiesis]]的TPO生理用作药物）与利妥昔单抗，切脾垫底（及其终身感染规则）。成人遵同一生理而自然史不同（慢性病程、治疗阈值——血小板<20–30或出血，及[[#def-platelet]]的术前数字）。看似健康的孩子逼你一眼扫过涂片与计数排除的危险鉴别：**TTP、DIC、白血病、再生障碍与脾功能亢进**——本章下一个示例处理头一个。
:::
:::

::: example 触发凝血系统的胎盘 {#ex-dic}
胎盘早剥胎死宫内三十分钟后，子宫每一边缘流出暗色不凝之血；输液针眼渗血；纤维蛋白原0.6 g/L、INR 2.4、血小板55、D-二聚体极高。
::: solution
**弥散性血管内凝血**——产科DIC是原型，因为组织因子（早剥、羊水栓塞、子痫、胎死滞留综合征中富含凝血活酶的蜕膜与肌层进入循环）是身体最强的[[#def-cascade]]全身激活剂：遍地生成的凝血酶把纤维铺进微循环（肾与皮质在危险中），而继发性**纤溶亢进**（加纤维蛋白原、血小板与因子II/V/VIII消耗——注意肝合成的辅因子V与VIII在DIC下降，而肝病时内皮来源的VIII保留——经典的判别）留下在伤口处无法凝固的血。处理按机制排序：**去除触发**（分娩、清除、必要时切除子宫——凝血活酶水龙头开着时没有任何制品有效）、**按目标导向的大成分复苏**（先补纤维蛋白原——冷沉淀或纤维蛋白原浓缩物至>1.5–2 g/L、血小板至>50、FFP按比例、[[blood/transfusion]]的大出血配比）、**早期氨甲环酸**（WOMAN试验三小时内创伤与产科出血的生存信号——[[#def-fibrinolysis]]之药证据最佳处）、肝素只用于罕见血栓主导图像（暴发性紫癜、胎死滞留的慢性低度DIC），及让级联残部工作的钙、温度与pH（低温-酸中毒-创伤文献的“致死三角”在产房同样适用）。实验室快照——纤维蛋白原低、两时间延长、血小板低、D-二聚体极高伴破碎细胞——是消耗与纤溶并存，而该配对是把DIC与本章每个单因子病变分开的签名。
:::
:::

::: history
血浆凝血理论由**Alexander Schmidt**与**Paul Morawitz**确立——其1903年凝血酶-纤维循环（配钙与凝血酶原）的陈述仍是每本教科书的开篇——此前是与对手机械理论十年之争。本世纪的药理把生化写进实践：**Henry Dale**发现实验室污染物降压引出**肝素的分离**（1916年Johns Hopkins学生McLean、1936年多伦多临床发布）与Quick凝血酶原时间（1935）；而双香豆素——威斯康星腐败三叶草牛群死亡之谜——鉴定后三十年内成为华法林。血小板一侧自**Bizzozero**1868年描述血小板与血小板栓，经1960年代释放反应生理，到前列腺素时代——Hamberg与Samuelsson的血栓素A₂、Vane（与Moncada）的前列环素——使血小板药理成为如今可药的级联。**Eric von Willebrand**1926–33年对奥兰群岛居民“假血友病”——一个显性、含女性、装不进X连锁教条的出血病——的记述被遗忘，直到1950年代因子检测将其找回，多聚体分析（及1990年代Moake与Zimmerman的超大vWF与ADAMTS13工作）隔了一生补全机制。纤溶系统沿同一弧线自纤维平板走到纯化激活物，而**emicizumab**2014–2018年的临床弧线闭合了一个世纪：级联的蛋白先后成为测量、药物与抗体模拟物。
:::

## 通向何处

血栓疾病、抗凝药与围术计划在[[blood/thrombosis-anticoagulation]]；血小板生成在[[blood/haematopoiesis]]；尿毒症与肝病出血在[[renal/chronic-kidney-disease]]与[[gastrointestinal/liver-disease]]；输血支持与大量输血凝血病在[[blood/transfusion]]；DIC的触发在[[infectious-diseases/fever-sepsis]]与[[obstetrics-gynaecology/pregnancy-antenatal]]。

::: summary
- 一期止血（血小板、VWF的剪切感知黏附、GPIIb-IIIa聚集）造血小板栓、失败时呈皮肤黏膜出血表型；二期止血（TF启动、血小板表面扩增的凝血酶爆发与纤维）失败时呈深部出血——病史是第一个定位试验。
- 级联是细胞基础的酶扩增器，带三个具名刹车（抗凝血酶、TFPI、蛋白C/S）；筛查试验报告其片段（PT——外源/共同，APTT——内源/共同），混合试验把缺乏与抑制物分开。
- 华法林的因子动力学（VII最先、II最后）、肝素对抗凝血酶的依赖、DOAC的单靶阻断，各自从级联设计读出——也各自规定自己的监测与逆转。
- 纤溶是与纤维共定位的纤溶酶生成；其抑制物与药物（氨甲环酸）如今是创伤与产后出血的一线。
- 最常见的出血病是免疫性（ITP——治出血不治数字）、遗传性（VWD——经期女性被漏掉的诊断；血友病——X连锁深部出血、其治疗满布抑制物与伦理）与获得性（肝、维生素K、DIC——凝血酶失控的凝血病）。
:::

## 练习

::: exercise 筛查、混合、测定 {level=1}
PT 12秒（正常）、APTT 90秒（正常25–37）、血小板正常、混合试验部分纠正、孵育后再延长。说出可能的疾病与两项确证检查。
::: solution
**纠正后再随孵育延长**的孤立APTT延长是**因子VIII自身抗体（获得性血友病）**的指纹——时间依赖、孵育依赖的抑制物（即刻纠正=单纯缺乏；零时不纠正=狼疮抗凝物或速效抑制物）。以**Bethesda试验**（抑制物滴度）与因子VIII水平（通常极低）确证，并同时治疗出血（旁路药——rFVIIa或FEIBA——而非更多VIII）与抗体（激素、环孢素或利妥昔单抗清除）。临床脸——老年或产后患者、突发大片瘀斑与肌肉血肿而无出血史——就是把实验室怪象变成值得几小时（不是几天）诊断的线索。

::: exercise 维生素K的时钟 {level=1}
为什么维生素K缺乏先延长PT后延长APTT？为什么新生儿风险特别？为什么有些母乳喂养婴儿的出血表现为新生儿出血病的颅内型？
::: solution
维生素K是**II、VII、IX、X**（加C与S）γ-羧化所必需；**VII的短半衰期**使PT（VII敏感）先动（与上文华法林的测验同一算术）。新生儿：**胎盘转运维生素K很差、肠道无菌（定植前无细菌维生素K₂）、母乳贫K**——故出生常规**肌注维生素K**（口服方案需依从并漏掉迟发型）。**迟发出血病（2–12周、经典为纯母乳未补充、胆汁淤积的婴儿——查结合胆红素找隐匿胆道闭锁）**以**颅内出血**起病，因为发育脑深部脑内静脉在II/IX/X耗竭、羧化贫乏的血浆最弱处相遇——该表现使普遍预防成为公共卫生措施、也使儿科在富裕国家继续书写“营养缺乏”。
:::

::: exercise 术前血小板计数 {level=2}
对下列每种：血小板12、45、60、90——判断患者能否a)服阿司匹林、(b)拔牙、(c)全髋置换、(d)椎管内麻醉，并给出含质性警诫的理由。
::: solution
工作阈值（外加警诫：**尿毒症、阿司匹林/抗血小板药、体外循环与单抗治疗能让任何计数变成质性缺陷**——问药史与出血史）：**12×10⁹/L**：禁阿司匹林、禁椎管内、禁大手术——自发瘀点风险地带、只为出血或计划操作输注（ITP中输注血小板几分钟即耗——与IVIG/激素覆盖并紧靠切口给）。**45**：拔牙与多数普外可接受（小操作配合局部措施时>50规则在45稳妥满足；部分牙科指南配氨甲环酸含漱更低也可）、**髋置换临界——多数麻醉医师在此数字附近拒绝腰麻**（椎管内阈值约70–80、机构间50–80之争：引用你单元的政策）、**有指征时阿司匹林可接受、监测计数**。**60**：所列各操作除部分单元的腰麻阈值外均可——多数可接受（SRA指南在70–80附近；以下即血肿对获益之辩）。**90**：包括腰麻的一切。总体模式：**止血能力=计数×功能×部位×操作**，硬膜外血肿的灾难定了最严阈值——[[clinical-skills/patient-safety]]核查表逻辑。
:::

::: exercise DIC对TTP对肝素诱导血小板减少 {level=2}
三位血小板减少的重症患者。给出判别试验及每项试验起作用的机制理由。
::: solution
三件套与其分流：**DIC**（脓毒症、产科灾难、癌症、创伤——**伴纤溶的消耗性凝血病**）：PT与APTT**延长**、纤维蛋白原**低**、血小板低、**D-二聚体极高**、涂片见若干破碎细胞——机制读数：凝血酶无对抗地跑了（因子消耗）、纤溶酶清了生成的纤维（D-二聚体）；治疗病因（出血时用血制品——FFP、血小板、低纤维蛋白原用冷沉淀；预防性“纠正正常”的试验逻辑归[[clinical-skills/patient-safety]]）。**TTP**（经典五联征很少齐全：血小板减少、**神经体征、相对不累肾的微血管病性溶血伴大量破碎细胞与LDH升高**、PT/APTT**正常**）：**ADAMTS13活性<10%伴抑制物**、微血管病性溶血源于未切割的超大VWF多聚体在富血小板微动脉血栓上剪切红细胞——**血浆置换（除抗体、补酶）加caplacizumab（抗VWF-A1）是急诊；输血小板相对禁忌（新血小板喂养富血小板微血栓——警告背后的加重）**。**肝素诱导血小板减少**（肝素第5–10天、计数下降、**血栓多于出血**）：**抗PF4-肝素IgG、血清素释放试验确证**——抗体经FcγRIIA激活血小板（[[#def-platelet]]机器的促凝面）——停全部肝素、换非肝素抗凝、详细生理在[[blood/thrombosis-anticoagulation]]。三种低血小板综合征：因子消耗、消耗加剪切、免疫激活——PT/APTT与涂片完成大部分区分。
:::

::: exercise 肝病患者的血 {level=2}
肝硬化患者INR 1.8、血小板70、纤维蛋白原1.4 g/L、利尿下血红蛋白稳定。解释为什么“INR就是他的出血风险”是错的，并给出择期腹腔穿刺的成分策略。
::: solution
肝硬化患者是**再平衡的止血系统**：肝造促凝蛋白太少（VII、X、II、纤维蛋白原——INR升高）**且**造抗凝蛋白也少（蛋白C、S、抗凝血酶）加纤溶酶原，而vWF**高**（内皮释放、ADAMTS13清除减少）、部分代偿血小板减少——故INR测到促凝缺项而漏掉抗凝缺项：决定出血与血栓的是比值而非单臂，肝硬化患者血栓与出血的比例与其他任何疾病该数字所能预言的相当。实用规则：**INR延长不是低出血风险操作的禁忌**（腹腔穿刺、牙科、多数内镜）——AASLD/EASL证据显示FFP“纠正”无效（容量负荷者、INR几乎不动、半衰期错配），而**血小板与纤维蛋白原（冷沉淀/浓缩物）对准真实缺口**：穿刺计数>50不补充（几乎全部患者合格）；高危手术用**粘弹性检测（TEG/ROTEM）**引导成分治疗、顽固低计数术前考虑TPO激动剂，早期给维生素K以防缺乏并存（营养不良的酒依赖者）、并认出肝病的**纤溶亢进**表型。总课：**INR在肝病是筛查人工物，凝血酶生成试验是研究时代的替代。**
:::

::: exercise 解读狼疮抗凝物 {level=2}
34岁术前APTT 58秒；混合不纠正；稀释蛇毒时间阳性；从未出血而过两次早期流产。解释悖论、血栓机制与产科处理。
::: solution
**狼疮抗凝物是针对磷脂结合蛋白（β2糖蛋白I、凝血酶原）的抗体，在试管里延长磷脂依赖的凝血试验、在体内却促进凝血**——体外抗凝、体内促凝：混合试验与DRVVT（低磷脂试验、揭开抗体的干扰）识别它，而**血小板表面、内皮组织因子、补体与蛋白C通路的激活**解释静脉与动脉血栓及**产科综合征**（胎盘血栓与补体介导的丢失——[[medical-ethics-law]]抗磷脂病例讨论的灾难谱系）。处理：孕期**低剂量阿司匹林加预防剂量LMWH**（标准产科抗磷脂方案、按流产史分层——血栓史者需治疗剂量抗凝）、血栓性抗磷脂综合征用华法林（三联阳性者DOAC的负面试验信号——绝不可想当然的例外）、动脉事件后终身复审，外科备忘**绝不为“纠正”APTT给FFP**（不是缺乏；除罕见低凝血酶原综合征并存，出血风险正常）。术前来电者的问题就此化解：这位患者**不需要因子制品——她需要VTE预防与她可能想要的妊娠的计划。**
:::

::: exercise 设计逆转 {level=2}
把出血场景配对到特异逆转：华法林颅内出血、阿哌沙班消化道出血、达比加群伴肾衰、溶栓相关腹膜后出血、氯吡格雷抑制血小板而需急诊手术者。
::: solution
每个逆转都是把级联设计倒读。**华法林+颅内出血**：**四因子凝血酶原复合物浓缩物（PCC——最快INR纠正、省容量优于FFP）加静脉维生素K**（持续合成修复；不给K的PCC只是推迟反弹）。**阿哌沙班/艾杜沙班（Xa抑制剂）**：有条件处**andexanet alfa（结合Xa抑制剂的诱饵蛋白）**，否则**大剂量PCC**；达比加群自身的逆转是**依达赛珠单抗（抗体片段——直接逆转；透析也能清除该药——唯一可透析的DOAC——题中肾衰的提示）**。**溶栓相关出血**：停输注、**氨甲环酸或EACA（[[#def-fibrinolysis]]的赖氨酸类似物）、已消耗的纤维蛋白原用冷沉淀/浓缩物、功能不良的补血小板**、支持性手术——溶解状态是药理性纤溶、给它的对抗刹车加底物。**氯吡格雷急诊手术**：**自发性脑出血中输血小板违反近期证据（PATCH试验的伤害信号）但药物相关手术出血仍是标准**、去氨加压素为辅助、及**椎管内时机规则**（择期椎管内前停氯吡格雷5–7天——P2Y12血小板的不可逆抑制意味着功能只随新血小板恢复（[[blood/haematopoiesis]]的10天周转）——阿司匹林COX乙酰化与氯吡格雷活性代谢物加合物的药理在[[pharmacology/drug-receptor]]是同一故事）。逆转在每种情况都是同一次三项审计：哪个分子被阻、哪个辅因子提供旁路、半衰期与肾对清除做什么。
:::

::: exercise 外科的血友病患者 {level=3}
26岁重型血友病A、emicizumab预防中，行阑尾切除。规划围术期止血管理，并解释其预防用药造成的两个实验室陷阱。
::: solution
**计划**：emicizumab（桥接FIXa与FX的双特异抗体——半衰期4周的**因子VIII模拟物**）提供相当于低正常VIII活性的持续止血覆盖、**全程不停**；外科附加是**大手术时重组因子VIII峰值（80–100%）、每日给药并按梯度谷值维持10–14天**（因子水平引导）、氨甲环酸辅助、及多学科血友病中心方案（每个住院医都问的问题的指南答案：可以开刀，而患者的预防是其安全的原因）。**陷阱1——APTT失效**：emicizumab（如肝素、如狼疮抗凝物）**在基线缩短APTT**，故APTT不再追踪任何因子缺乏、不能用于监测；用**发色因子X试验**——及**陷阱2——牛源试剂问题**：旧的一阶段牛源发色VIII试验遇emicizumab假性读值（其人FIX/FX表位），故必须开**人源试剂发色VIII或明确的emicizumab知情试验**。历史的镜子：同一双特异抗体时代的方案正穿过产房（[[obstetrics-gynaecology/pregnancy-antenatal]]产科血友病携带者方案——胎儿状态决定分娩方式）与急诊科，而**旁路药加emicizumab的血栓信号（早期试验中aPCC过用伴TMA事件）**意味着“存疑时给因子VIII、不给更多旁路药，并呼叫中心”。该病例即一章主题集于一人：现代血友病照护是药理、实验室警惕与规划，出血表型大体已是记忆。
