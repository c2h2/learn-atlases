淋巴瘤与骨髓瘤是成熟免疫系统的癌——淋巴细胞与浆细胞的肿瘤，把正常程序的行为带进恶性：淋巴瘤复制（或腐蚀）淋巴结与黏膜免疫系统的结构、交通模式与抗原应答，而骨髓瘤是那个正常分泌功能变成副蛋白、归巢骨髓习惯变成骨破坏的浆细胞克隆。分类跟随起源细胞及其分子病变；治疗自利妥昔单抗以来跟随同一生物学提供的表面与检查点靶标。

本章讲述作为淋巴瘤模板的淋巴结生物学、霍奇金与非霍奇金淋巴瘤，及带副蛋白并发症的骨髓瘤。

## 淋巴结作为模板

::: definition 淋巴结构与它孕育的肿瘤 {#def-node}
生发中心——活化的B细胞在此增殖（centroblast生发中心母细胞）、**体细胞高频突变**其免疫球蛋白基因（AID驱动）、在滤泡树突细胞抗原上按亲和力选择（centrocyte生发中心细胞）、并以记忆B或浆母细胞离场——是[[immunology/adaptive-responses]]的适应性免疫引擎，也是**淋巴瘤遗传学的摇篮**：AID的脱靶缺失造出经典易位——滤泡性淋巴瘤的**t(14;18) IGH::BCL2**（无法凋亡的生发中心B细胞——其抗凋亡病变有先于多数滤泡淋巴瘤、长达数十年的类MGUS潜伏期）、伯基特淋巴瘤的**t(8;14) MYC**（生发中心动力学的增殖停滞——最快的人体肿瘤、最高的化疗治愈率——一个实体里的生物学-治疗悖论），及套区、边缘区与MALT各实体、其细胞归巢并扩增至所居住的间隔（胃的MALT及其**幽门螺杆菌**驱动、抗原依赖的早期——首个一线治疗是抗生素的癌；桥本甲状腺淋巴瘤风险；干燥综合征与脾边缘区；[[gastrointestinal/bowel-disease]]的乳糜相关肠病型T细胞淋巴瘤）。结构的临床推论：淋巴瘤以**无痛增大淋巴结或按起源细胞组织逻辑分布的结外肿块**起病、经淋巴与血行按可预测的邻里方式播散（霍奇金的连续步进淋巴结扩散对非霍奇金更早、血行多灶模式）、产生**B症状**（发热、湿透的夜汗、消瘦——恶性与反应细胞的细胞因子输出、一个分期与预后变量），并要求**切除活检加流式、免疫组化、细胞遗传学与分子检查**——针芯显示“非典型淋巴细胞”是推迟而非取得的诊断，经典的被漏霍奇金淋巴瘤藏在无法展示结构的细针标本里。
:::

## 霍奇金淋巴瘤

::: definition Reed-Sternberg细胞及其微环境 {#def-hl}
霍奇金淋巴瘤多为年轻人的瘤（15–35，55后第二峰），其中肿瘤细胞——**Reed-Sternberg细胞及其变异型**、一个残废的**生发中心源B细胞**（克隆IGH重排、常伴B细胞程序丢失：CD15⁺CD30⁺、PAX5弱、CD20阴性或可变——一个逃逸而非身份的免疫表型、常带**EBV**基因组、混合细胞型与HIV相关型）——只占肿块的**少数**，其余多为反应性T细胞、嗜酸细胞、组织细胞与纤维：此瘤是一个**细胞因子器官**（RS细胞的配体与玫瑰花环募集并保护它——JAK-STAT与NF-κB依赖、检查点抑制剂利用的PD-L1基因9p24.3扩增、及疾病为何遇酒而痛、随B症状而烧）。经典亚型（结节硬化——年轻女性的纵隔肿块；混合细胞；富淋巴；贫淋巴）与**结节性淋巴细胞为主型HL**（CD20⁺“爆米花”/LP细胞变异、按惰性B淋巴瘤治疗）携带治疗逻辑。分期（**Lugano/PET-CT时代**：Ann Arbor I–IV带A/B与巨大修饰——被PET退役的分期剖腹）与**IPS国际预后评分**数危险因素，而治疗是肿瘤学的成功经验之一：**ABVD（或晚期病的强化brentuximab vedotin加AVD）配应答适配的PET引导放疗决定**，治愈绝大多数——留下**远期效应作为现代学科**：蒽环心肌病与斗篷照射时代的冠脉、瓣膜、肺与**第二肿瘤（乳、肺、甲状腺）及代谢综合征**，使生存者门诊、超声心动监测与放疗豁免试验（RAPID与HHSN268系列）成为今日霍奇金实践的实体——一个治愈率把谈话逼向未来三十年的病。
:::

::: example 护士的颈部肿块 {#ex-hl}
27岁女性右锁骨上无痛肿块六周、热水浴后发痒、湿透性夜汗与消瘦8公斤；胸片见前纵隔肿块。
::: solution
**经典型霍奇金淋巴瘤、结节硬化型直到活检否定**——年龄、连续颈/锁骨上扩散、纵隔肿块（结节硬化的签名：年轻女性、胸骨后区域病）与**B症状**（发热>38 °C、湿透夜汗、体重降>10%——本例三项齐全、分期修饰B；题干加的瘙痒是疾病的细胞因子痒、不特异但经典）。诊断：**切除淋巴结活检**（RS细胞——CD30⁺CD15⁺PAX5弱——在其富嗜酸、陷窝、分隔的结构中）、基线**PET-CT、骨髓现由PET替代、血液含ESR与白蛋白、HIV与肝炎血清学、治疗前超声心动与肺功能、首剂前讨论生育保存**（性腺毒性与性腺区放疗遗产——标准照护谈话）。治疗：早期预后好/不良的联合模式或PET适配的简短ABVD加累及部位放疗决定，晚期**brentuximab vedotin加AVD（ECHELON方案）**或A+AVD类方案；按中期PET应答适配（Deauville评分——决定升级降级的五点目测量表、本领域的影像生物标志化）、复发以**挽救加自体移植**管理（历史标准——HD系列对化疗敏感复发多数的治愈），如今难治与移植巩固场景用**检查点阻断（nivolumab、pembrolizumab）与brentuximab**组合。病例隐含的第二十年随访清单：幼年斗篷照射者每年乳MRI、心与甲状腺监测、疫苗与二次咨询——本章更大的论点：霍奇金淋巴瘤今天是慢病成功史、其遗留问题皆属医源性。
:::

## 非霍奇金淋巴瘤

::: definition 惰性-侵袭轴 {#def-nhl}
WHO/ICC分类按系别、起源细胞与驱动分拣NHL——但临床脊梁是**惰性对侵袭轴**：**惰性淋巴瘤**（滤泡1–2级、边缘区、小淋系/CLL-SLL、淋巴浆细胞样）单用化疗不可治愈却存活数年至数十年、以无痛全身淋巴结病与骨髓脾受累起病、无症状时以**观察等待**管理（“治影像可伤患者”的正式证明）、含obinutuzumab或利妥昔单抗方案（苯达莫司汀时代一线）、**局限I/II期的放疗（治愈意图）**——及一轮又一轮复发后的细胞治疗（**CAR-T CD19定向——ZUMA与TRANSCEND级缓解用于多次复发滤泡与套区病——双特异抗体、EZH2突变亚组的tazemetostat**：一个表观驱动者的分子医学展品）。**侵袭性淋巴瘤**（DLBCL——最常见NHL也是可治愈的那个：R-CHOP与**polatuzumab加R-CHP的晚期更新**，MYC/BCL2-BCL6双打击高级别B细胞淋巴瘤与TP53突变型要求强化与移植策略；套区（CCND1/MCL1 t(11;14)、侵袭与母细胞变异、如今BTK抑制剂——Bruton激酶依赖被伊布替尼、阿可替尼、pirtobrutinib利用及非共价类）；**伯基特（MYC成瘾的最大增殖肿瘤——短程强化B-NCC与DA-EPOCH-R类方案配TLS预防、儿童与青年治愈率90%以上）**，及**极侵袭与T/NK淋巴瘤**（鼻NK/T与EBV、肠病T细胞、成人T细胞白血病-淋巴瘤及其HTLV-1、皮肤蕈样肉芽肿/Sézary轴）完成地图。值得背诵的共同生物学：**CD19/CD20作为治疗表面**（利妥昔单抗的持有权抗体、CD20 CAR-T与CD19/CD20双特异——及其乙肝再激活黑框）、**抗原依赖作为治疗靶（MALT淋巴瘤的幽门螺杆菌根除、干燥综合征与HCV相关边缘区病——传染病章节的HCV-淋巴瘤病毒病因故事）**、及**转化作为惰性病向侵袭的出口**（滤泡→DLBCL、CLL→Richter——新肿块、LDH上升与PET高捕获灶要求再活检，因为治疗翻转为侵袭方案）。
:::

## 骨髓瘤

::: definition 浆细胞肿瘤谱 {#def-myeloma}
骨髓瘤是其骨髓壁龛里的恶性浆细胞：**MGUS**（M蛋白<30 g/L、克隆性骨髓浆细胞<10%、无靶器官标准——约3%/年进展风险、以FLC比值、M峰与游离轻链趋势追踪、世界高龄者的癌前状态与“别电泳条带”规则的来源）→**冒烟型骨髓瘤**（中等负荷；选定的高危生物学现依试验证据早治）→**症状性骨髓瘤**、以**CRAB**标准（高**C**钙、**R**肾损、**A**贫血、**B**骨病变）加现代**SLiM**生物标志（克隆浆细胞>60%、LC比值≥100、MRI局灶>1）及在骨架付账前识别骨髓瘤定义状态者。临床图像是副蛋白与壁龛的破坏：**骨病**（溶骨、病理与椎体压缩骨折、胸髓压迫的背痛——地塞米松加即刻放疗/神经外科的急症；生化上碱性磷酸酶正常、成骨静默的溶骨病变、及替代骨survey的**低剂量全身CT或PET-CT/全身MRI**）、**骨髓衰竭**（缗钱状红细胞与ESR高的正常细胞贫血、晚期血小板减少）、**免疫麻痹与肾丢失**（荚膜与非典型感染——头号死因、及轻链**管型肾病**——滤过游离轻链在远端小管与Tamm-Horsfall蛋白共同沉淀、由脱水、高钙与NSAID促成）、淀粉样变（AL）与轻链沉积肾小球病）、**高钙血症**（破骨激活——RANKL与MIP-1α驱动——水化-降钙素-双膦酸盐/地舒单抗的急诊）、及**高黏滞**（IgA与IgM——淋巴浆细胞病的Waldenström巨球蛋白血症、IgM五聚体的容量扩张：视觉模糊、头痛、黏膜出血与指端缺血、使**血浆置换**成为任何化疗前的即刻答案）。诊断：血尿电泳与免疫固定、**血清游离轻链**、骨髓（克隆浆细胞——CD138⁺、MRD标准化panel上FISH高危病变del17p、t(4;14)、t(14;16)、1q扩增）、上述影像、及PET在孤立浆细胞瘤与放疗规划的角色。治疗已变得靶标丰富：**RVd（来那度胺-硼替佐米-地塞米松）诱导、适合者大剂量美法仑与自体移植（年龄上限在抬高）、蛋白酶体抑制剂（硼替佐米、卡非佐米——免疫蛋白酶体成瘾细胞的未折叠蛋白崩解机制）、免疫调节剂（cereblon轴降解Ikaros因子——一堂分子机制课）、抗CD38抗体daratumumab与isatuximab（骨髓瘤CD38靶及其输血干扰警诫）、多重复发者的双特异T细胞衔接器（BCMA与GPRC5D定向）与CAR-T**、**带颌骨坏死牙科清查规则的双膦酸盐/地舒单抗骨剂**、感染预防（蛋白酶体抑制剂配阿昔洛韦、反复感染时IVIG替代之争）、及以电泳与游离轻链监测、**MRD正进入试验与实践**——几年前不可想象的结局：骨髓瘤五年生存曲线逐十年上弯。
:::

::: example 退休者的背痛 {#ex-myeloma}
71岁男性四个月胸背痛、活动加重；Hb 92、ESR 120、校正钙2.9、肌酐140、碱性磷酸酶正常；涂片见穿凿样颅骨灶、T8椎体压缩而椎间隙外观正常。
::: solution
**骨髓瘤直到电泳证明不是**——年龄段的CRAB图像齐全（高钙、肾损、贫血、骨病变）、**碱性磷酸酶正常是压制成骨细胞、与转移癌分开的判别**（颅骨穿凿无硬化灶是其影像孪生），ESR的缗钱状升高是廉价线索。顺序：**血清/尿电泳与免疫固定加血清游离轻链、全血细胞计数、钙与肌酐、及急诊全脊柱MRI——因为脊髓压迫（椎体压缩伴带状放射痛、进行性无力、膀胱受累）是那个急症：立即地塞米松，数小时（不是数日）内放疗或神经外科稳定。**然后骨髓与FISH分期、骨髓瘤定义事件评估（[[#def-myeloma]]的60%/SLiM标准）、按移植适合度诱导（RVd类±抗CD38移植、不适者用达雷妥尤-来那度胺-硼替佐米-地塞米松四药；管型肾病存在时用肾特异硼替佐米-地塞米松骨架、配水化、避免造影与NSAID、及挽救小管的降轻链）。支持束——骨剂配牙科复查、感染预防、贫血查并存的铁/B₁₂/肾原因、免疫调节剂在用时的VTE预防——与化疗各占管理的一半，而该病例的教学就是本章的总结：**副蛋白、骨架、肾与免疫系统是关于浆细胞的一个故事。**
:::

::: example 不是溃疡的上腹痛 {#ex-malt}
58岁上腹隐痛六周；内镜见胃体增厚结节伴浅溃疡；活检为致密小B细胞浸润伴淋巴上皮病变；染色见幽门螺杆菌；CT示胃壁增厚与少数胃周淋巴结。
::: solution
**胃MALT淋巴瘤（结外边缘区淋巴瘤）**——[[#def-node]]抗原依赖的一张图表：淋巴组织是*获得*的（慢性幽门螺杆菌胃炎在本无MALT处建起MALT），而早期淋巴瘤仍**依赖细菌驱动的T细胞帮助**而非完全自主。故一线治疗是**根除（[[gastrointestinal/oesophagus-stomach]]幽门螺杆菌章节的铋剂或标准四联）**，**约3–6个月内镜与组织学退缩评估达70–80%**——分子缓解慢于组织学、预测阴性的是**t(11;18) API2-MALT1**（使淋巴瘤对抗生素不依赖的易位——改放疗或免疫化疗）、深或巨大病、及十二指肠溃疡相关株的部分免疫。根除失败后的阶梯（累及部位放疗——局限胃病高效可治愈；播散或转化后用利妥昔单抗类全身治疗）沿同一生物学从抗原驱动走到自主；病例教的鉴别（淋巴上皮病变对反应性MALT增生对预后更差的弥漫大细胞转化）是病理医师版本的同一轴。**一句话教训：有些癌是慢性感染病，而抗生素就是肿瘤学。**

::: example 五岁孩子的颌肿 {#ex-burkitt}
赤道非洲4岁儿童颌部肿块数日内倍增、发热、LDH 2400；在其他地区同一肿瘤以儿童腹部肿块伴肠套叠起病。
::: solution
**伯基特淋巴瘤**——地理、年龄、生长分数（Ki-67近100%、肿瘤自身转换的“星空”巨噬图像）与分子病变（**t(8;14)把*MYC*置于免疫球蛋白重链增强子下——[[#def-node]]的生发中心增殖逃逸**）合成医学最优雅因果三角形之一：**EBV**（地方性非洲型——颌；[[infectious-diseases]]的疟疾免疫扰动作为辅因子假说）、**散发**型（腹部——回盲肿块、套叠、卵巢肾受累）与**免疫缺陷相关**型（HIV——艾滋病定义病）。治疗生理是本悖论的极大值：使它成为增长最快人体肿瘤的同一增殖驱动，也使其对**短程、强化、周期紧凑的治疗最可治愈**（剂量密集的B-NCC与DA-EPOCH-R类方案、成人加利妥昔单抗），两大管理危害是**肿瘤溶解**（[[blood/leukaemia]]急症——首剂前拉布立酶、水化、持续监测）与**腹部外科陷阱**（巨大肠病在溶解化疗中的穿孔与出血——外科与肿瘤医师必须共享日历）。CNS预防（鞘内与大剂量全身策略）完成方案——病例携带的历史脚注：伯基特1958年临床流行病学与其后的EB病毒发现，凭这一个颌开创了整个人类肿瘤病毒领域。

Reed-Sternberg细胞携带证明B细胞来源的克隆免疫球蛋白基因重排，却——经由异常NF-κB与JAK-STAT信号及9p24.3/PD-L1与玫瑰花环形成的微环境——丢失了多数B标志（CD20阴性或弱、CD79a常缺）而获得CD30与CD15（[[#def-hl]]）。免疫表型解释生物学（本该被凋亡处死的残废生发中心细胞、被BCL2与EBV-LMP1病变救回）、诊断panel、及治疗逃逸路径（CD30定向brentuximab、PD-1阻断——B细胞表面的丢失使利妥昔单抗在经典型无效、却定义了结节性富淋巴型CD20⁺、利妥昔单抗应答的生物学）。
:::
:::

::: history
**Thomas Hodgkin**1832年“淋巴腺疾病”讲座（后来以其名命名的病理）、**Virchow**的细胞学记述与1890年代“肉芽肿”与白血病的分离、**Reed**（1902）与**Sternberg**（1926）的巨细胞、及电镜时代的B细胞线索终于**Poppema**1977年富淋巴细胞型的区分；然后**Rye（1966）与Rappaport分类**、**工作方案（1982）**、及**REAL/WHO**起源细胞革命——含Alizadeh、Rosenwald、Staudt等（1999–2000）淋巴芯片工作给出的DLBCL生发中心对活化B细胞分类。治疗里程碑：**Henry Kaplan**在斯坦福的根治放疗时代、NCI的**DeVita与Freireich联合化疗规划（MOPP、随后ABVD）**造就第一个可治愈的成人转移癌；**Dalla-Favera、Tsujimoto与Kroemer**一代关于t(14;18) BCL2病变与凋亡；**Burkitt**的非洲颌瘤流行病学（1958年播种肿瘤病毒假说的论文、Epstein与Achong1964年的疱疹病毒、相隔数十年的zur Hausen HPV证明）；Waldenström巨球蛋白血症与使骨髓瘤成为蛋白病的1960年代免疫球蛋白化学；及利妥昔单抗（1997）、硼替佐米、来那度胺、抗CD38与CAR-T序列——把本章预后最差的一栏变成治疗最活跃的病房。
:::

## 通向何处

淋巴瘤与骨髓瘤在[[immunology/adaptive-responses]]孕育肿瘤的生发中心机器；白血病重叠在[[blood/leukaemia]]；EBV、幽门螺杆菌、HCV与HTLV病因在微生物与传染病章节；乳糜相关淋巴瘤在[[gastrointestinal/bowel-disease]]；MGUS的人群流行病学在[[epidemiology-ebm/observational-studies]]。

::: summary
- 淋巴瘤是生发中心与组织间隔之病：AID驱动的易位（BCL2、MYC）、起源细胞的归巢与抗原驱动（幽门螺杆菌、HCV、乳糜）写出临床地图。
- 诊断需要结构——切除活检——而分类现按WHO/ICC分子线路运行、起源细胞亚型指导治疗。
- 霍奇金淋巴瘤是一个残废B细胞、多数可治愈的细胞因子器官肿瘤，其现代前沿是远期效应与免疫靶向（CD30、PD-1）挽救。
- 非霍奇金淋巴瘤管理取决于惰性-侵袭轴：观察等待对治愈意图多药化疗加抗体，对复发则是BTK抑制剂、CAR-T与双特异序列。
- 骨髓瘤是浆细胞的壁龛与产物：CRAB加SLiM诊断、副蛋白的肾、黏滞与免疫麻痹并发症、及靶点丰富、曲线弯折的治疗（蛋白酶体、cereblon、CD38、BCMA/GPRC5D）。
:::

## 练习

::: exercise 为什么切除 {level=1}
一个PET高捕获的腋淋巴结：为什么针芯活检有时足够、有时切除是必须的？举两个例子。
::: solution
答案是结构与实体：**霍奇金淋巴瘤**（RS细胞在反应环境中的模式、陷窝分隔与结节性定义亚型——细针或短针芯“反应性/未知”率高、而亚型决定治疗）与**滤泡性对反应性增生**（背靠背肿瘤性滤泡无极性生发中心、BCL2染色模式——全依赖结构），对照良好针芯配**流式、免疫组化与分子检查已足够**的情形——已知淋巴瘤的复发活检、明显癌性淋巴结、或切除带神经器官风险的深部不可达部位（现代分期的EBUS/经支气管与骨/淋巴结核心路径）。规则：**组织即诊断、结构是半个组织，若标本答不了问题就再活检、而不是治疗一个假设。**
:::
:::

::: exercise B症状与分期 {level=1}
定义B症状与Lugano/Ann Arbor修饰符，并分期：(a) 同侧两颈部区加脾；(b) 腹主动脉旁淋巴结加骨病变。
::: solution
**B症状**：不明原因发热>38 °C、湿透夜汗、六月内不明原因体重降>10%（[[#def-node]]的细胞因子三联）。分期：**I**一个区、**II**膈同侧两个以上、**III**两侧（脾=淋巴性、故**III**）、**IV**结外（骨、肝、骨髓）；**A/B**修饰与巨大/“X”标志。故：(a) **按症状III期A/B**（膈上颈、膈下脾）；(b) **IV期**（结外骨病变）。临床用途：HL分期驱动联合模式强度，NHL里**FLIPI与IPI**数淋巴结、LDH、分期、体能与年龄——B症状的预后权重因实体而异。
:::
:::

::: exercise 观察等待 {level=2}
60岁III期滤泡淋巴瘤1级、无症状、Hb与血小板正常、淋巴结2–3厘米、LDH正常：肿瘤董事会建议观察。用试验证据论证，并定义启动治疗的扳机。
::: solution
**GELF/BNLI与PRIMA时代随机证据**：低肿瘤负荷晚期滤泡淋巴瘤立即对推迟治疗**无早期治疗的总生存优势**、代价是毒性、血细胞减少、免疫麻痹与（含苯达莫司汀方案）第二恶性与感染风险——故**无症状、非巨大、非器官威胁**者的标准是带复查的观察（“watch-and-wait”、指南里的正式名）。治疗扳机（GELF/BNLI标准作为清单）：B症状、巨大或进展性负荷（巨大淋巴结、积液）、骨髓替换致血细胞减少、症状性脾大、器官压迫或威胁（输尿管梗阻、[[#ex-myeloma]]脊柱逻辑的脊髓路径）、及转化嫌疑（局灶PET捕获、LDH升高——再活检，因为该发现把治疗转换为侵袭性DLBCL方案）。随访含FLIPI风险讨论、治疗时代的第二恶性与感染警惕、及一句诚实的话：此病一般不可治愈但可存活多年——慢病咨询，在骨髓瘤冒烟型状态带着同一伦理排练过。
:::
:::

::: exercise 抗体的两副面孔 {level=2}
利妥昔单抗革新了B细胞淋巴瘤治疗；它也再激活乙肝，并在骨髓瘤邻近的CD20阳性病引起长期B细胞再生障碍。从靶点解释每个后果。
::: solution
**CD20**从前B期表达到记忆B细胞——不在干细胞（故B细胞自骨髓储库数月恢复）也不在浆细胞（故利妥昔单抗大体豁免已建立的体液免疫）。治疗面孔：补体与ADCC溶解、直接信号与CD20⁺淋巴瘤的化疗增敏（滤泡、DLBCL、边缘区、套区——惰性与侵袭组合的骨架；[[#def-nhl]]的CD20 CAR-T与双特异延伸）。危害：**HBV再激活**——病毒的共价闭合DNA持久于B系细胞、其免疫控制部分依赖利妥昔单抗打乱的T-B协作、造成暴发性肝炎、使**HBsAg/抗HBV普遍筛查与血清阳性者的预防性核苷类似物**成为黑框规则（与检查点抑制剂、BTK抑制剂肝炎警惕同一逻辑）；**长期低丙种球蛋白与中性粒减少**（B细胞再生障碍、感染风险——有症状者IVIG替代、荚膜菌警惕）；**输注首剂细胞因子反应**（肿瘤与巨噬细胞细胞因子释放、预给药与剂量拆分——现代双特异剂量爬坡的同一病理生理减弱版）；及实务——肝炎与疫苗时机、治疗前后**活疫苗禁忌窗口**。
:::
:::

::: exercise 管型与病因 {level=2}
骨髓瘤患者胃肠炎后服一剂布洛芬出现慢性基础上的急性肾损伤；尿试纸蛋白微量而24小时蛋白6克。解释试纸不符、骨髓瘤的肾病变与管理。
::: solution
试纸测**白蛋白**；24小时法定总量蛋白含**轻链**——不符即**溢出性（本周）蛋白尿**的线索。病变按机制：**管型肾病**（游离轻链——经cubilin/megalin系统滤过重吸收分解[[renal/tubular-function]]；负荷超过能力时在远端小管与Tamm-Horsfall黏蛋白沉淀、形成梗阻伴巨细胞反应的管型——脱水、高钙、脓毒症与NSAID为扳机的经典AKI）、**轻链近端小管病（Fanconi综合征——[[renal/tubular-function]]转运失败的获得性碳酸氢盐、糖、磷与氨基酸丢失）**、**AL淀粉样变与轻链沉积病**（伴白蛋白尿级蛋白尿的肾小球结节图像、刚果红与非亲和沉积之比）、及慢性高钙/容量不足的肾钙质沉着。管理：**去除扳机（NSAID、钙、脱水）、快速静脉补液、紧急降低轻链生产（硼替佐米-地塞米松骨架配剂量调整的其他药——血液滤过与高截留分子量透析试验的诚实失败、血浆置换未定的位置）、治高钙与感染、及确立的透析依赖骨髓瘤肾的移植谈话（骨髓瘤时代的现代答案：深度应答后患者即是移植候选）**。本章生理课重现：副蛋白不是实验室奇闻，而是可滤过、可沉淀、可沉积的分子、其病理跟随其物理化学。
:::

::: exercise 巨球蛋白血症 {level=2}
74岁患者视物模糊、鼻衄、头痛、血浆黏度4.2（正常<1.8）；IgM 38 g/L；骨髓见小淋巴浆细胞样浸润伴MYD88 L265P。解释黏度算术与急诊处理。
::: solution
**伴症状性高黏滞的Waldenström巨球蛋白血症。**IgM是**五聚体（约970 kDa）**：留在血管内（每克占血管内容量25%、对IgG更小的分布而言）、故血清水平随适度肿瘤负荷陡升、血浆黏度随浓度**指数**攀升（[[physiology/homeostasis-body-fluids]]与[[cardiovascular/circulation-blood-pressure]]流变学章节的非牛顿、聚集驱动曲线）——视网膜静脉腊肠样淤张、黏膜出血（蛋白包裹并损害血小板与凝血因子功能——阿司匹林与抗凝药在此危险的原因）、及神经三联，**症状通常在相对黏度约4以上出现（IgM阈值随结合性质变）**。急诊：**血浆置换（即刻的物理——移除五聚体的血管内池、因IgM分布血管内而反弹温和）**先于任何红细胞输注（先输血会升黏度——输前置换规则），随后克隆定向治疗（**BTK抑制剂——伊布替尼、泽布替尼——加利妥昔单抗；MYD88 L265P驱动的MYD88/TLR高敏与CXCR4轴生物学、也解释其中枢（Bing-Neel）归巢**），带利妥昔单抗**IgM潮涌警诫**（可诱发黏滞的一过性升高——高负荷者先做置换覆盖或暂缓）。考试搭档的鉴别：高黏滞综合征（IgM的容量效应、IgA的聚合、[[blood/leukaemia]]白细胞滞留练习的髓系细胞）都以流量障碍起病、也先按流量障碍治疗。
:::

::: exercise Richter与转化 {level=2}
治疗中的CLL患者出现迅速增大的单侧扁桃体区、B症状与LDH 900；PET见一个淋巴结SUVmax 18而其余为4。两种可能是什么？如何分开？
::: solution
**Richter转化**——CLL向侵袭性大B细胞淋巴瘤的逃逸（多数克隆相关、少数为新发DLBCL、更少见的霍奇金变异），对照免疫抑制宿主的**增殖中心潮涌/感染/第二原发**。分开靠**组织与影像**：局灶SUV不匹配（18对4的逻辑——PET选择的活检部位）引导切除活检——形态（大片细胞）与**IGH克隆性共享或不同的重排**（克隆相关、化疗耐药者对新发DLBCL按标准R-CHOP类方案治疗），配EBV状态（[[immunology/immunodeficiency]]相邻文献的免疫抑制驱动EBV阳性淋巴增殖）与PET再分期。治疗后果：**克隆相关Richter预后最差、需强化方案并早期考虑细胞治疗（移植、CAR-T、双特异）；CLL患者的新发DLBCL按DLBCL治疗并规划与CLL治疗的相互作用**——总原则：**永不凭假设治疗转化；再活检改变方案与生存曲线。**
:::

::: exercise 设计生存者门诊 {level=3}
你主持一个25–40岁治愈霍奇金淋巴瘤的门诊。按治疗暴露（ABVD、brentuximab、检查点抑制剂、纵隔与斗篷放疗）构建监测计划、每一项以器官生理与试验时代证据论证。
::: solution
**心脏**（蒽环剂量相关心肌病——[[cardiovascular/heart-failure]]的射血分数生理——加纵隔放疗三联：加速冠脉病、瓣膜纤维化与传导/心包病）：**按剂量与野做超声监测、积极控脂控压控烟、缺血影像低门槛（年轻女性的非典型胸痛是一道冠脉病史题）**；**肺**（博来霉素与放疗纤维化——再治疗前后与症状后查肺活量/DLCO、博来霉素后氧敏感文献的麻醉可手术性警诫）；**内分泌/代谢**（颈野后甲状腺功能——斗篷时代的甲减；照射的代谢综合征；性腺功能与生育——[[endocrine/reproductive-endocrinology]]的AMH与精子发生数据）；**第二恶性**（幼年斗篷照射后的乳腺癌风险、**约25–30岁或照射后8–10年起每年乳腺X线加乳MRI**——所有生存指南中成本验证最充分的筛查；肺癌以戒烟为最高收益干预；按野的甲状腺与胃肠风险；治疗相关MDS/AML——计数监测与[[blood/haematopoiesis]]更早的CHIP教训）；**骨**（性腺衰竭与激素时代的骨密度）；**心理社会与经济毒性、复工、疫苗与感染计划**（淋巴结野放疗免疫丢失的无脾功能类比）。门诊的论证就是队列数据本身（儿童癌症生存者与英国霍奇金队列——早死如今常为非复发），组织原则是**按暴露而非按诊断的监测**（每种模态的剂量与野记录决定检查与间隔——治疗摘要文件就是处方），终点哲学即本章：治愈的患者是一种合并症可治的慢病——生存者门诊的全部事业。
