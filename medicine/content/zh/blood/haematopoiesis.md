一个成年人一升血液含五百亿红细胞、数千白细胞与二十万血小板——而其中每一个都由一个比肝更重、却装在骨头里的器官以每日四千亿个细胞的速率制造并更新。造血是身体研究得最清楚的干细胞系统：从单个自我更新的干细胞到循环末端的机器，其分叉层级由同样的生长因子治理，而它们的重组形式如今摆满了血液学药柜。血涂片是这座工厂产量的打印件，而血细胞计数的语言——分类、指数、网织红细胞——是医学的第一方言。

本章讲述干细胞层级及其壁龛、生长因子与各细胞系、血细胞的场所与寿命，以及骨髓衰竭的临床综合征。

## 层级

::: definition 造血干细胞 {#def-hsc}
所有血细胞都源自**造血干细胞（HSC）**——按功能而非形态定义：**自我更新**（子代干细胞补充池）加**多能性**（移植后重建每一系），此性质由Till与McCulloch的脾集落试验先在小鼠证明，后经连续移植与遗传条形码证实。层级为HSC → **多能祖细胞**（有系偏向；旧的严格“髓系对淋系分离”已知会漏——淋系倾向的多能祖细胞保留髓系潜能）→ 定向祖细胞（**CFU-GEMM**与限系的**CFU-G、CFU-E、BFU-E、CFU-Meg、CFU-GM/嗜酸/嗜碱**）→ 形态可辨的前体（**原红、原粒、早幼粒、中幼粒**——成熟池），骨髓在每步祖细胞上有约5天的转运扩增（单个干细胞每日约10⁶后代是扩增，不是干细胞的分裂——真干细胞大多**静止（G0）**，这是它能在杀死循环祖细胞的数十年细胞毒化疗中幸存的原因，也是它成为移植与CAR-T时代基因治疗靶点的原因）。使其静止又可逆的**壁龛**：骨内膜成骨与血管周基质（**表达CXCL12（SDF-1）的CAR细胞**、巨核-窦状单元），经**SCF–c-KIT、Thpo–c-Mpl、CXCL12–CXCR4与NOTCH/血管内分泌信号**传导；CXCR4–CXCL12系绳被药理切断时HSC迁向脾与肝——**一个受器对就是外周血干细胞动员的全部机制**（见示例）。
:::

::: definition 造血的场所与季节 {#def-sites}
造血一生在迁移：**卵黄囊**（原始、有核、胚胎第一波——[[anatomy/embryology]]的中胚层）、**胎肝**（妊娠中期主工厂，约28周起骨髓接种）、**脾**（短暂），最后是**骨髓**——先轴心骨骼（椎、肋、骨盆、胸骨），肢体骨髓由手指向心转为黄色（脂肪），故抽吸在婴儿选胫骨、成人选髂嵴，而**股骨与肱骨干是浸润时骨髓衰竭最先的牺牲品**。**髓外造血**——肝、脾与椎旁灶恢复胎儿功能——见于骨髓纤维化、浸润或耗竭时（骨髓纤维化、重型地中海贫血、严重慢性溶血），产生**幼红幼粒血象**（有核红与早期髓细胞被挤出紧张的髓窦）伴脾大：这词组的涂片描述在排除前就是骨髓侵犯的鉴别。
:::

::: example 释放干细胞的药 {#ex-mobilise}
一位妹妹移植的供者连用四天G-CSF，随后从臂静脉（而非骨髓穿刺）采集“干细胞”。
::: solution
健康HSC经**CXCR4–CXCL12**对与VLA-4–VCAM-1黏附攀附于骨髓基质，处于[[#def-hsc]]的血管周壁龛。**G-CSF**（粒细胞集落刺激因子——[[#def-factors]]的中性粒系生长因子）数日内重塑该壁龛：蛋白酶（中性粒细胞弹性蛋白酶与MMP-9）切割黏附配体、成骨支持撤除、经壁龛的交感信号改变，于是**HSC脱锚入血**，血细胞分离机在其中收集CD34阳性细胞（CD34——HSC邻近的表面标志；移植剂量按每公斤CD34⁺细胞数计）。临床算术随之而来：外周血移植物植入更快（采到更多干细胞、更多成熟T细胞——代价是非亲缘捐献中更高的慢性**移植物抗宿主**率，这使某些方案里骨髓采集仍是首选），而替代动员剂**普乐拉福**把机制讲明——**CXCR4拮抗剂**，数小时内释放细胞，用于单用G-CSF动员不佳者（年长或经多线治疗的供者）。同一轴组织日常交通：CXCR4–CXCL12对让淋巴细胞与浆细胞归巢骨髓与淋巴结，这就是其阻断不仅动员干细胞、也动员淋巴细胞的原因（也是HIV共受器的政治——CXCR4嗜性病毒、maraviroc的CCR5对应物——摆在这张生理货架上的原因）。
:::
:::

## 生长因子

::: definition 各系因子及其受体 {#def-factors}
| 因子 | 细胞系 | 来源 | 临床用途 |
|---|---|---|---|
| 促红细胞生成素（EPO） | 红系（把CFU-E从凋亡中救出） | 肾周小管纤维样细胞（85%；其余在肝） | 慢性肾病贫血与重组时代的体育滥用 |
| 血小板生成素（TPO） | 巨核/血小板（c-Mpl；肝组成性产生，被血小板清除） | 肝细胞 | 罗米司亭/艾曲泊帕——免疫性血小板减少的受体激动剂（激素本身太致抗原） |
| G-CSF | 中性粒 | 内皮、巨噬、成纤维——由IL-1与TNF诱导 | 化疗后中性粒减少、动员、慢性中性粒减少 |
| GM-CSF | 粒-单核；也有树突 | T细胞、巨噬细胞 | 少见；沙格司亭的角落 |
| SCF（kit配体） | 早期/肥大/嗜酸启动 | 基质 | 体外扩增；W位点的毛色突变 |
| IL-3、IL-5、IL-7 | 多能/嗜酸/淋系 | T细胞、基质 | 科研与试验工具 |
| TPO的反转设计：血小板质量调控自身信号——游离TPO被血小板c-Mpl收走，故**血小板减少升高血浆TPO**（[[blood/haemostasis-bleeding]]反应性计数的巨核质量反馈），而EPO随**肾HIF-脯氨酰羟化酶感知的缺氧**升高——从肾纤维细胞到颈动脉体保守的氧感知模块，也是新**HIF脯氨酰羟化酶抑制剂**（伐达杜他类）的靶点：骗细胞以为缺氧，用一粒药治肾性贫血 | | |
:::

总体设计是神经系统的倒置：**每系由自身的存活因子从程序性死亡中被救出**——没有EPO的CFU-E数小时内凋亡、无G-CSF的中性粒前体亦然——所以“生长因子”多为**抗凋亡的许可信号**，计数调控调的是因子水平而非细胞分裂：感染升高中性粒靠升高G-CSF（也靠**边缘释放**——骨髓的分裂后储池数小时内排空，这是白细胞在任何新细胞造出前先跳升的原因，储池见底则杆状核的**核左移**随后出现）；缺氧升高红细胞靠升高EPO（暴露高原数分钟血浆水平翻倍，而慢性低氧者——发绀型先心、睡眠呼吸暂停——的血细胞比容是EPO-红系轴在人群尺度的读数）。

::: definition 成熟细胞及其日期 {#def-cells}
**红细胞**：人在120天，膜是谱蛋白-锚蛋白细胞骨架（其缺陷即[[blood/anaemia]]的遗传性球形与椭圆形增多症），代谢厌氧（无线粒体——能量全走糖酵解、ATP养阳离子泵、磷酸戊糖路的NADPH保谷胱甘肽还原与高铁血红蛋白还原路运转——故G6PD与丙酮酸激酶缺陷是**红细胞限局的溶血病**，而不造蛋白的红细胞无法修复膜氧化：其衰老被巨噬读作磷脂酰丝氨酸暴露、在脾索清除）。**白细胞**：粒细胞血中约数小时（边缘加循环6–16小时，然后入组织；中性粒的外移与死亡——愈合伤口的脓就是耗尽的细胞），单核血中数日后成组织**巨噬**（也回收每个衰老红细胞铁的网状内皮系统——铁循环归属[[blood/anaemia]]），淋巴细胞**数年**（记忆）或数日（初始者在[[immunology/adaptive-responses]]的结内再循环）。**血小板**：约10天，巨核细胞前血小板穿窦脱落的碎片，由肝的去唾液酸酸化读取器清除。**脾**过滤全部三者：淤积（脾功能亢进——门脉高压的细胞减少从不到输血水平），与切脾后涂片（豪-周小体、靶形细胞、血小板增多，及[[infectious-diseases/fever-sepsis]]的荚膜菌脓毒症风险——无脾患者的疫苗规则归低脾功能箱）。
:::

::: example 交通：为什么激素升白细胞、为什么有些孩子从不化脓 {#ex-traffic}
一位哮喘患者静脉氢化可的松四小时后中性粒翻倍；另一例两岁幼儿脐残端坏死、脐炎，中性粒60×10⁹/L而周身无脓。
::: solution
两例都是[[#def-cells]]的外移步骤。循环中性粒松散地附于内皮（**边缘池**，约与循环池等量，肾上腺素与儿茶酚胺应激数分钟即释放——β激动剂输注或受惊孩子计数显示的“边缘解除”即是）；糖皮质激素随后**下调黏附分子（L-选择素脱落改变、整合素与选择素表达改动）并延迟凋亡**，于是中性粒更慢离开血管、在血中活得更久——良性、可预期、解读关键的白细胞增多（激素患者的20不是感染；核左移与杆状核才说话）。幼儿的麻烦是同一扇门被焊死：**白细胞黏附缺陷1型**——缺**CD18**、共享β2整合素亚基（LFA-1、Mac-1），无它则牢固黏附与跨内皮不可能——呈**脐带延迟脱落、无脓的反复细菌感染、显著静息中性粒增多**三联（骨髓造而不出），诊断靠流式（CD11/CD18染色），治疗靠感染控制、继而造血干细胞移植——矫正的ITGB2基因试验是其现代版（[[genetics/genomic-medicine]]）。两极端之间是日常门诊：β激动剂加激素的哮喘者其白细胞增多不该触发脓毒症检查；有感染而无脓的孩子，其计数永远不该被叫作“令人放心的白细胞增多”。
:::

::: quiz
一位化疗患者给药后三天中性粒降到零，但血小板与血红蛋白接近正常。最佳解释：
- [ ] 药物只靶向分裂中的干细胞
- [x] 各系转运时间、储池与寿命不同，故低谷落在不同天数
- [ ] G-CSF给得太晚
- [ ] 骨髓已再生障碍
::: solution
低谷随各系细胞动力学：中性粒池小、组织需求恒定，任何增殖阻断数日内即降；**血小板**（10天寿命、大储池）降得晚、恢复也晚；**红细胞**（120天、巨储池、无消耗）短周期内几乎不动——这就是化疗患者第7天粒细胞缺乏却不贫血，而慢性骨髓浸润先以粒系与血小板系起病。再生障碍会三系齐跌（以脂肪空虚的活检为证），杀死干细胞则无一系幸免但患者幸存（静止HSC活下来）——[[#def-hsc]]与[[#def-cells]]的动力学读成一张血细胞日历。
:::
:::

## 骨髓衰竭及其面貌

::: example 三种细胞减少，三种活检 {#ex-failure}
(a) 19岁，瘀斑、口腔溃疡、反复感染：Hb 62、中性粒0.3、血小板12、网织红0.2%。(b) 68岁，Hb 88、大细胞、中性粒1.2、血小板480：涂片见假佩-霍畸形粒细胞与双形态红细胞。(c) 55岁，Hb 90、泪滴形红细胞、涂片见有核红与髓细胞、脾达脐。
::: solution
三例都是“计数低”，而涂片与年龄分开这座工厂的三种病理。**(a)再生障碍性贫血**——**全细胞减少伴网织红为零、无异常细胞**：干细胞池被毁（多数为免疫、T细胞介导——与肝炎、药物、毒物的关联，及此年龄必须排除的罕见遗传性端粒与范可尼型）。骨髓**空虚而脂肪化**（诊断靠活检而非涂片），治疗为免疫抑制（抗胸腺细胞球蛋白加环孢素——清除T细胞即恢复产量的免疫学证据，及该疗法与阵发性睡眠性血红蛋白尿确有重叠——见[[blood/anaemia]]）或**HSC移植**（年轻、有相合供者路线——可治愈，且因[[#ex-mobilise]]的采集而成今日常规）。**(b)骨髓增生异常综合征**——细胞减少而骨髓**增生甚至高度增生**：无效造血、前体细胞髓内死亡（差克隆的凋亡），呈大细胞性贫血、发育异常中性粒（少分叶佩格尔样、颗粒缺如）与克隆性干细胞病易漏的计数，伴5q−、−7与复杂核型及可变的白血病风险——WHO/ICC分类与IPSS-R评分决定观察、来那度胺（5q−特异）、去甲基化或移植。**(c)骨髓纤维化**——**幼红幼粒血象、泪滴细胞（被挤过纤维化窦的dacrocyte）与髓外造血巨脾**：克隆性巨核肿瘤（JAK2/CALR/MPL——[[blood/thrombosis-anticoagulation]]近邻的骨髓增殖家族）以倾倒的PDGF与TGF-β纤维化骨髓，恰与[[#def-sites]]之则相反：“骨髓失败、脾来代偿”之则。三种活检——空虚、拥挤而死亡、纤维化——三机制——干细胞丢失、克隆低效、基质毁灭——而全血细胞计数加涂片已知是哪个。
:::
:::

::: example 吃掉三系的脾 {#ex-spleen}
一位肝硬化患者Hb 95、血小板70、中性粒2.5，超声脾18厘米，网织红细胞计数正常、骨髓活检正常。
::: solution
这是**脾功能亢进**——滞留而非生成不足：淤血脾扣留多达90%的血小板质量（正常三分之一）与三分之一的粒细胞池，于是计数下降而**代偿性骨髓增生**（网织红与髓细胞储备在干活；活检高度增生——与[[#ex-failure]]a相反）。区分滞留与失败的规则是**严重度上限**：单纯脾亢很少把血小板压到约40–50以下、中性粒压到约1.5以下，因为扩大的池会代偿；更低即意味着第二个过程（叶酸缺乏、酒精的髓毒性、肝炎相关再生障碍、肝硬化状态的血液稀释，或永远可能并存的免疫性细胞减少）。没有针对数字的治疗（输注的血小板几分钟即被扣留）；外科与放射选项——部分栓塞、针对门脉压的TIPS、带着终身感染代价的切脾——针对病因与有症状者，总原则是**骨髓在工作时的细胞减少是分布问题，分布问题不靠加细胞解决**——本章的间隔生理再次决定治疗。
:::
:::

::: history
层级先被推断、后才被看见：Ehrlich的三色染色（1877）与Pappenheim的命名给了细胞名字；Maximow的**一元论**（全部血液源于一个干细胞，与之竞争的家谱说持到1960年代）由**Till与McCulloch**在功能上证实——小鼠脾集落试验（1961）、连续移植（1963）、及单个注入细胞可重建致死量照射小鼠的证明——同一逻辑把**Donnall Thomas**从狗实验带到第一例人类骨髓移植（1957，1990年诺贝尔奖），再到今日全球的脐血、单倍体与动员外周血移植规划。生长因子时代自1970年代的促红素纯化与其基因克隆（1985，第一个分子定义的血生成素——故有重组EPO转化透析贫血、及它催生的兴奋剂产业），历经1980年代后期G-CSF与GM-CSF及1994年TPO的分子克隆；端粒生物学（先天性角化不良）与范可尼贫血遗传学提供了干细胞衰老与修复失败的遗传模型；现代篇章是**HSC单细胞转录组学**（连续谱取代家谱）与对地中海贫血、镰状细胞病的基因矫正自体HSC（[[blood/haemoglobin-disorders]]的最新一章）——[[genetics/genomic-medicine]]诸承诺的治疗，首先在血液中兑现。
:::

::: summary
- 血液是一个自我更新的器官，由一个静止、受壁龛看守的干细胞经分叉、系偏向的祖细胞与庞大的转运扩增池建成——小干细胞池服务巨大日产量的架构。
- 系存活因子（EPO、TPO、G-CSF）作为抗凋亡许可信号起作用；计数由因子水平调控（EPO看氧与HIF、TPO看血小板清除、G-CSF看炎症），重组因子与受体激动剂是医学最大的药物类别之一。
- 造血一生迁移（卵黄囊→肝→骨髓），骨髓失败时又复旧——髓外造血、脾大与幼红幼粒涂片是同一现象。
- 细胞寿命与储池各异，故每系按自己的日历失败与恢复；细胞减少的鉴别从哪几系、哪些指数、哪张涂片读出。
- 骨髓衰竭有三副面孔——再生障碍性（空虚）、增生异常性（拥挤而死亡）、浸润/纤维化（被侵犯）——各有定义性的活检、预后与治疗。
:::

## 练习

::: exercise 数一数储备 {level=1}
骨髓每天生产约2×10¹¹个红细胞。给定120天寿命与5天骨髓转运，估算循环红细胞总量与其骨髓前体池；造血减少一半时网织红细胞计数的数学意味着什么？
::: solution
稳态时池=产量×停留：循环总量=2×10¹¹/日×120日=**2.4×10¹³个**（约5升血、Hct 45%对应约25万亿——算术闭合）。骨髓红系前体池=2×10¹¹×5=**1×10¹²**——约4%的循环量，“5天预出库”。产量减半时，EPO上升、前体池扩张、网织红细胞本应上升；因此溶血性贫血时**网织红低即为生成不足**（缺料或骨髓问题），而生成减半但破坏加倍者（如遗传性球形增多症的代偿期）以高周转维持正常Hb——[[blood/anaemia]]的溶血箱里“无贫血的溶血”。
:::
:::

::: exercise 因子处方 {level=1}
把药对到生理与适应证：epoetin alfa、达贝泊汀、非格司亭、普乐拉福、罗米司亭、艾曲泊帕。
::: solution
**Epoetin alfa**——重组EPO、每周三次，慢性肾病贫血（[[#def-factors]]的控制器失效）与部分化疗贫血，补铁为强制联治（新红细胞需要底物：[[cell-biochemistry/nutrition]]）；**达贝泊汀**——唾液酸化延长、每周一次，同一生理、同一“靶Hb高于正常”的黑框警示（试验时代的血栓信号）；**非格司亭**——G-CSF，用于化疗中性粒缺乏预防与动员（扩髓的骨痛是把机制当副作用听见）；**普乐拉福**——CXCR4拮抗剂，动员不良者的快速干细胞动员（[[#ex-mobilise]]）；**罗米司亭/艾曲泊帕**——TPO受体激动剂（肽抗体与小分子），在慢性免疫性血小板减少升高血小板计数——生理反转成治疗，而警示（血栓、网硬蛋白）写在同一通路上（[[blood/haemostasis-bleeding]]）。
:::
:::

::: exercise 读涂片 {level=2}
一张幼红幼粒血涂片伴泪滴形红细胞；列出四个原因与开始检查的单项下一步试验。
::: solution
涂片意味着**骨髓浸润或足以挤出未成熟细胞、并经纤维化扭曲红细胞形状的重度应激**：骨髓纤维化（原发——[[#ex-failure]]c的JAK2/CALR生物学）、骨髓转移（癌——乳、前列、肺、胃：该去找原发灶的涂片）、血液肿瘤浸润（白血病、淋巴瘤、骨髓瘤），与反应性骨髓应激状态（重度脓毒症、烧伤、低氧、伴红系增生的显著溶血），另有肉芽肿性与贮积浸润（结核、结节病、戈谢）。单项下一步：**环钻活检**（单独抽吸常“干抽”——骨髓纤维化里的“tap”——网状/胶原染色与转移性角蛋白的免疫组化决定涂片点名的疾病），随线索进展加JAK2/分子检测与找原发灶的断层影像。
:::
:::

::: exercise 造血与脾 {level=2}
用本章生理逐条解释切脾后的所见：血小板增多、靶形细胞、豪-周小体与疫苗计划。
::: solution
脾索是血小板的**池**（约三分之一质量扣留于此）、膜的**改造器**（清除包涵体与冗余膜，故其丢失留下薄膜的**靶形细胞**与未清除的核残余——**豪-周小体**，涂片上的低脾功能标志——及可再生的挖空红细胞），也是**边缘区免疫器官**：荚膜菌（肺炎链球菌、流感嗜血、脑膜炎球菌）在此被捕获并呈递给[[immunology/adaptive-responses]]的抗体机器。故：切脾后数周血小板反弹上升（达输血水平的血小板增多罕见且为反应性——治患者不治数字）；涂片即诊断；无脾患者需要**三菌疫苗计划加加强、发热后抗生素备用与医疗警示牌纪律**——因为脾的首过滤过是其丢失会把菌血症变成[[infectious-diseases/fever-sepsis]]急诊里**切脾后暴发性感染**的天然防御。
:::
:::

::: exercise 缺氧感受器 {level=2}
高原居民、发绀型先心患者与高氧亲和力血红蛋白患者：三种状态经同一感知模块的三条不同路径升高EPO。解释之，然后说明为什么肾衰竭会取消代偿。
::: solution
**HIF脯氨酰羟化酶（PHD–VHL–HIF）模块**——氧依赖性羟化给HIF-α打上VHL介导降解的标记，故氧张力（或氧输送）下降稳定HIF，转而反式激活**EPO**、铁转运基因（TFRC、铁调素/膜铁转运调控——[[cell-biochemistry/nutrition]]的铁分支）与糖酵解程序——一个感受器、三种扳机：**高原**（吸入PO₂低→动脉含量低）、**右向左分流**（动脉血去饱和——发绀孩子的红细胞增多，现代教义是补铁、放血只留给症状性高黏滞）、**高亲和力血红蛋白与BPG缺乏**（解离曲线左移、组织供氧不足，在正常PO₂下开启同一HIF输出）。肾衰竭取消反应是因为**周小管间质细胞就是EPO工厂**——实质丢失毁掉感受-效应细胞本身（故贫血低增殖、EPO不适当地低：先排除一切其他原因——铁、B₁₂、炎症、溶血、骨髓瘤——再给重组激素），是唯一其治疗即缺失激素本身的贫血。
:::

::: exercise 设计移植制品 {level=2}
对HLA相合同胞移植，比较骨髓采集与G-CSF动员外周血：干细胞剂量、T细胞含量、植入速度、慢性移植物抗宿主病、供者体验——并说出髓系疾病现代通常选哪个。
::: solution
**外周血移植物**每次采集**给更多CD34⁺细胞**（约两倍于骨髓采集）、**植入更快**（中性粒约11对约16天——患者已脓毒症时就要紧的差），但携带**约10倍成熟T细胞**——明码标价是**更多的慢性移植物抗宿主病**（试验时代的荟萃：植入快、生存相当，代价在此）。**骨髓采集**（全麻下髂嵴、制品过滤）让供者腰痛一周，给出低GvHD的制品，在**再生障碍性贫血**（目标是免疫重建而同种反应最小、宿主预处理不同）与许多**儿童及非亲缘供者**方案里取胜；G-CSF动员（经两肘前静脉1–2天单采、骨痛前一天）在**快中性粒恢复占主导**处取胜——[[blood/leukaemia]]的髓系白血病与MDS及其预处理方案。故制品选择按疾病与方案而定——同一批干细胞、两种采集、一条轴（[[#ex-mobilise]]）与一个权衡，而移植物抗白血病收益使T细胞含量在[[blood/transfusion]]的输血医学回响里成为双刃量（预防输血相关GvHD的照射就是同一免疫学）。
:::
:::

::: exercise 数字与壁龛 {level=2}
一家移植中心报告其CD34⁺细胞剂量与中性粒及血小板植入相关，但与五年长期髓系重建不相关。用[[#def-hsc]]的层级调和之。
::: solution
制品的**短期与长期重建活性住在不同细胞**：CD34⁺大群体含转运扩增与定向祖细胞，数周内归巢、分化并恢复血液（故植入相关——“祖细胞”剂量），而稀有的真长期HSC（CD34⁺CD38⁻CD45RA⁻CD90⁺ Thy1⁺表型；连续重建滴度最高的Lin⁻CD34⁺CD38⁻侧群）只占计数的一小部分，其功能取决于**入龛与静止**而非数量。调和：早期计数追踪祖细胞质量；五年髓系产量（及克隆造血的多样性）追踪稀有干细胞池及其植入生物学——这就是剂量阈值按经验设定（CD34×10⁶/kg）、脐血单位按有核细胞总数与CD34含量定剂量而植入较慢（每份干细胞池更小、更受壁龛限制）、而本领域现行检测（极限稀释异种移植、条形码）为直接数长期组分而建的原因——本章第一个定义所对应的医学仍跑在生物学测量之前。
:::
:::

::: exercise 衰老、克隆造血与临床 {level=3}
定义意义未明的克隆造血（CHIP）、其最常见基因、以及它已进驻的三个临床领域——血液、心血管与肿瘤——并给出各自的机制推理。
::: solution
**CHIP**：**无血液肿瘤标准、但体细胞突变克隆已扩增（变异等位基因分数≥2%）**，源于干细胞竞争与衰老的正常过程——骨髓约5万个功能HSC渐被无论哪个突变赋予适合度的克隆主导（DNMT3A、TET2、ASXL1最常见，随后DNA损伤反应基因PPM1D/TP53，其携带者在化疗下扩张最快，也是“治疗相关”髓系肿瘤自有克隆起源故事的原因）。**血液**：通往MDS/AML的管道（风险按基因与克隆大小分级——DNMT3A小克隆近乎良性、TP53双击即恶性命运），及供者侧的**供源CHIP**问题（年长供者的克隆可植入、扩张并偶致供者细胞白血病或移植失败：移植登记库的新变量）。**心血管**：范式转变——TET2等**重编程巨噬炎症**（NLRP3/IL-1β/IL-6信号——CANTOS试验白介素假说的遗传学版），使心梗与卒中升高数倍，故CHIP现在是动脉粥样硬化的因果危险因素而非偶见基因型（本领域的当务之急：它该不该有门诊？）。**肿瘤**：游离DNA检测会捎带CHIP突变，为其他疾病做的“液体活检”中升高或高VAF的克隆会混淆结果（测序流程对配对白细胞对照的需求——现已写进每份cfDNA方案的分析前规则）。CHIP闭合本章弧线：干细胞层级不是稳态机器而是**不断演化的群体**，衰老的克隆生态原来是全器官的疾病，最先在血细胞计数里被看见。
:::
