血栓是放错位置的止血：Virchow三要素——瘀滞、内皮损伤与高凝——仍是“血栓为何在其处形成”的临床语法（腿与心房的静脉瘀滞与富含纤维的红色血栓；冠脉与颈动脉的动脉剪切、血小板白色血栓与斑块破裂），而抗凝药理不过是把上一章的凝血级联画上药物靶圈。临床综合征——深静脉血栓、肺栓塞、动脉血栓病、及预防它们的医源风险——是医学最常见、最方案化的遭遇之一，这使它们的生理值得完全拥有。

本章讲述静脉与动脉血栓的病理生理与流行病学、作为级联生理的抗凝药，及血栓性微血管病与肝素诱导血小板减少。

## 为什么血栓在其处形成

::: definition 应用于临床的Virchow三要素 {#def-virchow}
**静脉血栓栓塞（VTE）**——深静脉血栓与肺栓塞，发病率约1–2/1000/年、随年龄陡升——靠**瘀滞加高凝**运转：小腿静脉瘀滞（制动、长途飞行、心衰、瘫痪肢体）、术后与创伤后的炎症性凝血活酶与血小板激活环境（手术、恶性疾病——黏液腺癌的Trousseau现象、雌激素与[[obstetrics-gynaecology/pregnancy-antenatal]]再平衡止血——的获得性风险清单），及遗传性易栓症——**因子V Leiden**（R506Q删除蛋白C第一个裂解位点：活化蛋白C抵抗、欧洲最常见遗传风险、杂合约5%、只静脉不动脉）、**凝血酶原G20210A**（凝血酶原产量升高）、**蛋白C、蛋白S与抗凝血酶缺乏**（看似孟德尔式的经典家系——其抗凝血酶缺乏肝素无法完全抗凝——药物的辅因子就是病变）、**异常纤维蛋白原血症**与获得性**抗磷脂综合征**（[[blood/haemostasis-bleeding]]的“体外人工物、体内祸害”）。血栓的后果：血栓后肢体（瓣膜破坏与弹力袜产业）、肺栓塞、及其管理的悖论见下。**动脉血栓**——心梗、卒中、急性肢体缺血——靠**内皮病与剪切**运转：动脉粥样硬化破裂、脂质核心组织因子、动脉剪切下的血小板黏附（[[blood/haemostasis-bleeding]]血小板段的VWF、GPVI与血栓素生物学），给**抗血小板药**划出地盘，及房颤的瘀滞伴内皮异常之心房血栓（答案是抗凝而非抗血小板）。区分决定药物：**红血栓→抗凝；白血栓→抗血小板**——每张二级预防处方背后的那句话。
:::

::: example 肿胀的小腿及其规则 {#ex-dvt}
52岁护士长途飞行后左小腿疼痛四天；Wells评分中危；D-二聚体高；加压超声示腘静脉不可压闭。
::: solution
诊断生理很精确：**Wells模型**从病理生理预试验概率（癌症、制动、单侧肿胀、浅静脉偏移——[[epidemiology-ebm]]使用最多的临床预测规则）、**D-二聚体的高阴性预测值**在低概率患者排除（健康时纤维转换近基线——该试验的力气在排除而非确认，因为手术、妊娠、肿瘤与年龄都升高它）、**加压超声**——不可压闭即血栓、物理上——确证。处理跟随级联：**立即抗凝**（DOAC——阿哌沙班或利伐沙班负荷后维持，或LMWH导入——靶值见下）、激发事件（航班）治疗3–6个月、无激发者按复发与出血风险定延长治疗（性别、残留静脉血栓与治疗中D-二聚体问题）、**弹力袜**控制症状（其预防血栓后综合征的期望令试验失望——诚实的教学），与安全网：**头几天的栓塞风险才是我们治疗的原因，而非孤立小腿血栓的死亡风险**（远端DVT监测对治疗之争）。然后是病例藏着的强制搜寻：**任何成人的无激发VTE都值得按年龄性别的肿瘤警觉（不是盲目CT筛查——广泛筛查试验显示的是无伤害的成本平衡），而易栓检测只在其改变管理时做**（大多不改变：杂合因子V Leiden加首次激发血栓什么都不改——这句话该终止的过度检测流行病，除非雌激素、生育计划或华法林皮肤坏死使答案要紧）。
:::
:::

## 作为级联生理的抗凝药

::: definition 肝素类 {#def-heparin}
**普通肝素**是硫酸化糖胺聚糖，其五糖结合**抗凝血酶**、诱导构象改变、使其抑制凝血酶（IIa）加速**十万倍**——但只有长链（>13糖）把抗凝血酶桥到Xa **与**IIa两者，这就是UFH延长APTT（其凝血酶抑制）、可被鱼精蛋白逆转（碱性肽的盐沉淀——也是鱼精蛋白只部分中和LMWH的原因）、能以分钟滴定（短半衰期与中性粒、血小板对聚合物的清除：[[pharmacology/dosing-principles]]的药理）的原因。**低分子肝素**（依诺肝素、亭扎肝素——β消除或亚硝脱氨片段）大体保留抗Xa臂（抗Xa对抗IIa活性约2–4:1），带来可预测的药动（皮下、按体重、常规不监测——只在体重极端、肾衰与妊娠肾清除要紧处测抗Xa）、更低的**肝素诱导血小板减少**风险（链长依赖的PF4复合）、及癌栓与产科生态位。**磺达肝癸钠**——纯合成五糖——经抗凝血酶纯抗Xa（其试验造就的HIT-proof（HIT安全）选项、肾清除警诫不变）。[[blood/haemostasis-bleeding]]测验里APTT/INR的不对称在此回到治疗：**肝素作用于内源/共同、APTT可见的臂，华法林与Xa抑制剂先显于PT/INR可见的臂**，而只有UFH的凝血酶侧效应移动APTT——病房当作输注证明的实验室指纹。
:::

::: definition 华法林与维生素K循环 {#def-warfarin}
华法林抑制**维生素K环氧化物还原酶（VKORC1）**、抽干**γ-谷氨酰羧化酶**造功能II、VII、IX、X及蛋白C、S所需的还原醌辅因子：本药是**依赖膳食与抗生素的维生素K拮抗剂**（肠道菌群的K₂贡献、绿叶菜“保持稳定”的建议、CYP2C9与VKORC1多态使人群剂量需求相差两到四倍——FDA最早的药物基因组标签，[[pharmacology/patient-variation]]）。四个靶点的动力学驱动方案（VII短半衰期→INR数日即升而**抗栓覆盖要等因子II三天耗竭**——故肝素桥接；蛋白C下降解释**早期高凝窗口与隐匿蛋白C缺乏者的华法林皮肤坏死**）。监测是**INR**（ISI参考比值、标准化凝血活酶差异——每位护士都懂的WHO算术），靶值2.0–3.0（多数适应证）与2.5–3.5（机械二尖瓣与抗磷脂复发），及其逆转阶梯（无出血的高INR：停药±口服维生素K；大出血：**PCC加静脉维生素K**——[[blood/haemostasis-bleeding]]之则），而这一切正是DOAC被设计来逃离的。
:::

::: definition 直接口服抗凝药 {#def-doac}
**达比加群**（直接凝血酶抑制剂前药——给argatroban/bivalirudin注射家族一个口服未来）、**利伐沙班、阿哌沙班、艾杜沙班**（直接Xa抑制剂）打击单一级联酶、药动可预测（固定剂量、常规不监测——极端场景留抗Xa或稀释凝血酶时间、肾清除35–80%是剂量调整轴、及消化道出血的权衡：达比加群偏高、阿哌沙班偏低、半衰期5–17小时是漏一剂比华法林更不容情的原因）。其试验（RE-MODEL到Hokusai——疗效非劣到优、**颅内出血减半**、定义该类别的安全事实）使其成为VTE与房颤一线（[[cardiovascular/arrhythmias]]的卒中预防CHA₂DS₂-VASc与HAS-BLED算术），但有三个仍归华法林或LMWH的地盘：**机械瓣与抗磷脂综合征**（DOAC试验的伤害信号——一个非单酶疾病的凝血活酶通路推理）、**重度肾衰**（透析患者PK数据指南仍在犹豫）、及**妊娠**（DOAC的胎盘转运与动物毒性：LMWH仍是产科抗凝药，[[obstetrics-gynaecology/pregnancy-antenatal]]）。逆转即[[blood/haemostasis-bleeding]]练习的答案：达比加群用依达赛珠单抗、Xa抑制剂用andexanet alfa或PCC，最终裁决是半衰期与肾清除。
:::

::: example 第七天下降的血小板 {#ex-hit}
急诊剖腹探查并接受依诺肝素预防六天后，患者血小板从280降至95；腿部重新肿胀、出现新鲜股静脉血栓，尽管抗凝已达治疗剂量。
::: solution
**肝素诱导血小板减少II型**——本章最生理性的药物不良反应。第5–10天（IgG类应答时相——再暴露更早）、**血小板降幅>50%**（绝对计数很少降到出血水平）、而**血栓而非出血是签名**：抗**血小板因子4-肝素复合物**的IgG经**FcγRIIA**激活血小板（[[blood/haemostasis-bleeding]]血小板段的促凝激活——微颗粒与凝血酶生成风暴），未经治疗者静脉与动脉血栓风险达数十个百分点（4T评分——时相、血小板减少度、血栓、其他原因——预试验；**抗PF4/肝素免疫测定，随后功能学血清素释放或肝素诱导血小板激活试验**确证）。管理是三条命令加一个理由：**停掉每一次肝素冲管与包被**（动脉导管与LMWH交叉反应）、**启动非肝素抗凝药**（阿加曲班——肝清除、APTT滴定的直接凝血酶抑制剂，或比伐卢定，稳定者用磺达肝癸钠或DOAC——预防剂量不够，血栓负荷要求治疗量），且**绝不输血小板**（理论上的火上浇油、动脉病例的观察伤害）、血小板恢复前不启动华法林（HIT早期华法林的蛋白C崩解致肢体静脉性坏疽——与其皮肤坏死同一机制）。旧区分对得起其位置：**I型HIT**（第1–2天、轻、非免疫、可继续肝素）对此II型；第七天规则解释了为何术后预防中的患者是经典病例：暴露、然后免疫窗口、然后血栓。
:::
:::

::: example 护士疼痛的大腿 {#ex-necrosis}
38岁DVT患者华法林治疗（肝素桥接）第六天，乳房与大腿出现剧痛、边界清楚的紫癜斑、INR上升；血小板降至90。
::: solution
本章两个实体在此共享机制——**华法林诱导皮肤坏死**，教科书病人是**蛋白C缺乏**者：华法林早期蛋白C下降（半衰期约8小时、与[[#def-warfarin]]促凝窗口同一动力学）对抗仍循环的凝血酶原，在**蛋白C富集的脂肪组织（乳房、大腿、臀）微血管**制造**短暂高凝状态**、局部血栓伴血小板消耗——故计数下降与分布如此。**鉴别是HIT**（肝素暴露、第5–10天时相、4Ts与抗PF4试验——两者可并存、都要求停肇事药），处理：**停华法林、给维生素K**（尽管坏死时怕“反弹”——病理是低蛋白C不是INR）、**按HIT答案以非肝素或LMWH/阿加曲班足量抗凝**、**蛋白浓缩物或FFP恢复蛋白C**（有条件处用特异浓缩物）、早期伤口护理与整形、**恢复后查遗传性缺乏**（若重启华法林须重叠覆盖、缓慢启动——再挑战复发风险高）。应试搭档脚注：无蛋白C缺乏的华法林坏死见于HIT与抗磷脂场景，同一算术原因——药物第一个牺牲者是身体自己的抗凝物。
:::

::: example 找到胰腺的游走性血栓 {#ex-trousseau}
67岁男性三个月内两腿不同部位两次浅表血栓性静脉炎与一小腿DVT，伴背痛与体重下降8公斤；D-二聚体极高、血小板缓慢下降。
::: solution
**Trousseau综合征**——以**游走性、无激发与罕见部位血栓**起病的癌症相关血栓（非典型部位浅表血栓性静脉炎、内脏与脑静脉血栓、伴栓塞性卒中的非细菌性血栓性心内膜炎）：分泌黏液的腺癌（胰、胃、卵巢、肺）经**组织因子与癌促凝微颗粒、血小板与单核激活及NET网**驱动凝血——一种持续低度凝血酶生成的高凝，反映在极高D-二聚体与消耗的缓慢血小板漂移。教学点：**任何年龄的无激发或游走性静脉血栓都应唤起肿瘤之问**（尽管盲目全身CT筛查试验显示死亡更少、焦虑更多——按年龄性别评估加症状导向检查是证据答案，[[epidemiology-ebm]]的过度检查之衡又见）、**治疗是LMWH或按部位选择的DOAC**（前文练习的黏膜出血警诫），及该综合征的反读——癌症患者血小板下降伴INR与纤维降解产物升高是同一生物学的**慢性代偿性DIC**端。题干的背痛与消瘦是肿瘤自身的症状——该病例的目的是教：凝血系统可以是癌症的第一证人。

## 微血管病与紫癜

::: definition 血栓性微血管病 {#def-tma}
血栓被挤进微循环时三联同现——**微血管病性溶血性贫血（破碎细胞、LDH升高、触珠蛋白低）、血小板减少与器官损伤**——而鉴别是一堂生理研讨课：**TTP**（ADAMTS13缺乏——免疫性或Upshaw-Schulman体质型——超大VWF多聚体在血小板微血栓上剪切红细胞：神经波动、相对不累肾的图像，血浆置换与caplacizumab见[[blood/haemostasis-bleeding]]）、**溶血尿毒综合征**志贺毒素大肠埃希菌——血性腹泻前驱与补体、凝血受损的肾小球；**非典型HUS**——替代途径补体调控基因突变（CFH、CFI、MCP、C3、抗FH抗体）现以**依库珠单抗/雷夫利珠单抗**治疗——与PNH同一终端补体阻断（[[blood/anaemia]]）、**DIC**（[[blood/haemostasis-bleeding]]的消耗图像）、恶性高血压与子痫前期/HELLP微血管病（[[obstetrics-gynaecology/pregnancy-antenatal]]）、**硬皮病肾危象、放射性肾炎、药物毒性（奎宁、吉西他滨、VEGF抑制剂）、及移植相关TMA**。统一的病变是**内皮损伤或剪切伴血小板-VWF-补体激活**——压缩进一根微动脉的Virchow三要素——而工作顺序（涂片找碎片、ADAMTS13、粪便志贺PCR与补体检查）从两端读同一台机器。
:::

::: history
**Virchow**1856年血栓三要素（及其与Langer、Wegner的细胞血栓时代组织学）、1860年代维也纳学派的肺栓塞尸检系列（内科“最常见的隐匿杀手”、至今仍从尸检室引用），及1930–40年代——**Géza de Takats**的术后栓塞外科遇上**McLean与Scott**的肝素、及双香豆素到华法林的1940年代转换（de Takats自己的术后狗双香豆素预防实验）——开启抗凝世纪；其INR平台如今正被直接抑制剂替换一半：**水蛭素**的数个世纪（水蛭的腺体、然后重组去氨肝素与来匹肝素、达比加群的小分子后裔）、自蜱抗凝素生物学的Xa抑制剂规划、及HIT往事——**White与Bedford及Shapiro**1973年血小板减少报告、1990年代Warkentin与Kelton把PF4-肝素免疫复合物解剖成4Ts、检测与现代第七天规则。
:::

## 通向何处

级联及其出血之镜在[[blood/haemostasis-bleeding]]；房颤与急性冠脉应用在[[cardiovascular/arrhythmias]]与[[cardiovascular/coronary-artery-disease]]；妊娠与产后风险算术在[[obstetrics-gynaecology/pregnancy-antenatal]]；癌症相关血栓在[[pathology/cancer-biology]]；住院与术后预防政策在[[clinical-skills/patient-safety]]；剂量药物基因组学在[[pharmacology/patient-variation]]。

::: summary
- 静脉与动脉血栓在同一三要素、不同环境：瘀滞与血浆驱动的纤维血栓（抗凝药）对剪切与血小板驱动的白血栓（抗血小板药）。
- 肝素经抗凝血酶起效（UFH桥接IIa与Xa、可监测可逆转；LMWH抗Xa为主、药动可预测；磺达肝癸钠纯抗Xa），华法林抽干γ-羧化（需要INR、有桥接与坏死动力学），DOAC打单酶（固定剂量、无常规监测、颅内出血减半、有特异的逆转剂）。
- HIT是免疫性血小板激活：停一切肝素、非肝素抗凝、不输血小板——第七天规则、4Ts与抗PF4试验。
- 血栓性微血管病把Virchow三要素压进微循环：TTP、HUS与非典型HUS、DIC、HELLP，各有其确证试验与其终端补体或血浆治疗。
- 抗凝的并发症管理是算术：出血风险分层、按半衰期与清除途径选择逆转剂，而绝不在没有适应证时治疗一个实验室数字。
:::

## 练习

::: exercise 先Wells后开单 {level=1}
为什么D-二聚体只在低与中预试验概率中有用？为什么同一患者临床可疑小腿DVT而多普勒阴性不能排除？
::: solution
D-二聚体的似然比**只在能把验后概率压到影像触发线以下的那个阈值附近**起作用——高预试验概率时阴性D-二聚体无法把疾病概率拉低到停止影像（[[epidemiology-ebm]]的先验算术），而住院、术后、孕妇与老人的**特异度崩塌**（纤维转换随生活条件升高），于是试验常阳性而不告知任何事。小腿多普勒：远端与非阻塞血栓技术上更难看见（可压闭性、操作者依赖、等长静脉解剖），故高度可疑病例单次阴性应**5–7天复查或更早影像**——与D-二聚体反向的同一验前/验后逻辑：敏感度不完美的试验在临床怀疑幸存于阴性时必须复查或升级。
:::
:::

::: exercise 选择抗凝药 {level=1}
为每位患者选择并论证：(a) 34岁无激发PE、肾正常、无癌；(b) 70岁机械二尖瓣；(c) 45岁胰腺癌伴股静脉DVT；(d) 29岁孕20周伴鞍状PE。
::: solution
**(a) DOAC**（阿哌沙班或利伐沙班单药从头开始，或LMWH导入的达比加群/艾杜沙班）——疗效非劣、颅内出血减半、无监测；3–6个月停止并重估延长治疗。**(b) 华法林、靶2.5–3.5**——机械瓣与抗磷脂病是DOAC试验的伤害区（[[#def-virchow]]基质内皮驱动的凝血活酶生物学需要广谱阻断）；按瓣与出血风险LMWH桥接。**(c) 按现行癌栓指南LMWH或DOAC**（CLIP与SELECT-D、CARAVAGG比较使DOAC在多数肿瘤可接受、管腔胃肠与泌尿生殖癌除外——其黏膜出血信号偏向LMWH——细微处是瘤位与黏膜完整性）。**(d) 全程LMWH**（DOAC胎盘转运、华法林胚胎病窗口6–12周及后期胎儿出血与中枢风险——两者都排除；治疗剂量按体重LMWH、极端处抗Xa监测是产科标准、临产前转换、及产后计划——华法林可哺乳、DOAC未确立，[[obstetrics-gynaecology/pregnancy-antenatal]]）。
:::
:::

::: exercise 围华法林算术 {level=2}
华法林患者（INR 2.6、机械主动脉瓣）需拔牙；另一次服复方新诺明后INR 8.2而无出血。分别处理，并解释相互作用机制。
::: solution
**拔牙**：INR≤3–4的华法林小型口腔手术**不停华法林**（瓣与反弹血栓风险高、拔牙出血风险低）——24–72小时内查INR、局部措施（压迫、缝合、氨甲环酸含漱——[[blood/haemostasis-bleeding]]的抗纤溶药）、与牙科及抗凝门诊复查、且绝不为小操作给控制良好的华法林患者“肝素覆盖”（桥接试验：出血更多、事件不少——BRIDGE试验逻辑的应用）。**INR 8.2无出血**：**停华法林、口服维生素K 1–2.5 mg、24小时内复查**（静脉与PCC留给出血；皮下吸收不稳、不再推荐）、INR下降后以减量维持重启，并读懂病因：**复方新诺明抑制CYP2C9（S-华法林通路——[[pharmacology/metabolism-excretion]]）并置换蛋白结合、减少产维生素K的菌群**——经典相互作用，唑类、胺碘酮与甲硝唑同列；抗生素疗程正是每个门诊都有“用抗生素即查INR”常备医嘱的原因（[[clinical-skills/patient-safety]]）。
:::
:::

::: exercise 读一张混合试验 {level=2}
出血患者PT 22秒、APTT 70秒：1:1混合即刻PT 14、APTT 36；孵育2小时后APTT升至64。给出模式名称、可能靶点与确证试验。
::: solution
即刻纠正证明**缺乏**（正常血浆含两条通路共享的因子），而**孵育后APTT再延长**揭穿**针对内源通路因子的时间依赖性抑制物——经典为因子VIII自身抗体（获得性血友病A）**：自身抗体缓慢、温度依赖的中和在零时被隐藏（[[blood/haemostasis-bleeding]]练习的双胞胎）。以**因子VIII活性（低）、Bethesda滴度（定量抑制物）**确证，并排除模仿者（狼疮抗凝物——零时纠正差却不引起出血；肝素——查凝血酶时间/试剂中和）。治疗即[[blood/haemostasis-bleeding]]的急诊：出血用旁路药（rFVIIa、FEIBA）、清除用免疫抑制（激素±环孢素/利妥昔单抗/环磷酰胺）——临床课是同一条混合曲线可以意味着出血急诊或实验室奇闻，只有病史把两者分开。
:::
:::

::: exercise 延长治疗决定 {level=2}
46岁男性第二次无激发近端DVT。解释决定终身抗凝的复发风险推理、长期剂量选择、及你将布置的出血风险缓解。
::: solution
无激发VTE后停药复发风险一年约10%、五年约30%（男性更高、停后D-二聚体阳性与残留静脉血栓更高、**PADIS/CURE式的接近正常对异常推理**），而**第二次无激发事件使复发概率越过继续抗凝的挽救死亡超过出血死亡的几乎每个模型阈值**——故**终身治疗、每年重估**。剂量问题：**足量对减量DOAC延长**（阿哌沙班2.5 mg每日两次与利伐沙班10 mg每日一次的规划——AMPLIFY-EXT与EINSTEIN-CHOICE再减半复发、出血增加很少——许多人的现代默认），DOAC不可用时用华法林（瓣、抗磷脂、费用），使“终身”可耐受的是出血缓解：**避免同用NSAID与抗血小板药除非另有指征、GI风险者PPI覆盖、酒精审查、跌倒与职业风险讨论、肝肾监测、DOAC的加/停相互作用清单（[[pharmacology/metabolism-excretion]]）**、书面计划（每年停/不停备忘，防终身漂移也防过早停药）。生理总结：你在用一个易发血浆血栓的循环对抗一个比血栓风险老得更快的皮肤黏膜与颅内出血预算。
:::
:::

::: exercise 青腿之问 {level=2}
HIT患者（诊断前即启动）华法林第4天出现疼痛蓝肿的腿、动脉搏动存在、血小板下降。说出综合征与三步机制。
::: solution
**肢体静脉性坏疽/HIT中华法林相关肢体缺血**——把药理脚注变成黑框警示的综合征。机制：(1) **HIT的凝血酶生成在运转**（[[#ex-hit]]的FcγRIIA血小板激活与微颗粒风暴）；(2) **华法林最先压垮蛋白C**（其短半衰期、与[[#def-warfarin]]早期促凝窗口同一动力学），而因子II与X仍有功能、血小板驱动的凝血酶输出在升——**蛋白C对促凝的失衡**，测为蛋白C相对因子VII的陡降；(3) 随之的**微血管与静脉血栓**发生在本已被新鲜DVT堵塞回流的肢体——脉搏可及的坏疽（动脉流入完好、静脉回流与微循环被毁），重症呈DIC样图像。三条规则：**急性HIT永不启动华法林**（直至血小板恢复≥150）、**已运行的华法林一律维生素K逆转**、**以非肝素药抗凝**（阿加曲班等）——考试搭档是华法林皮肤坏死（同一算术的蛋白C缺乏版，[[#def-warfarin]]）。
:::
:::

::: exercise 卵圆孔未闭的卒中 {level=2}
32岁长途骑行自行车手左侧MCA区卒中；腿超声示腘静脉DVT；超声心动示卵圆孔未闭、Valsalva时右向左分流。解释通路，及封堵对药物之争。
::: solution
**反常栓塞**：静脉血栓（飞行后腘静脉血栓——又是瘀滞）在右房压短暂超过左房时经**PFO**进入体循环（咳嗽、用力、Valsalva释放相——与[[cardiovascular/cardiac-cycle]]右心充盈节的同一压力物理），栓子——常已破碎、“静脉到动脉”的通过可解释——落在脑（或冠脉、肾、肢体）。归因概率估计（**RoPE评分**——年龄、皮质影像、无血管危险因素、血栓可得性）挑出PFO是元凶而非无辜旁观者（成人约25%有）的患者，而试验（CLOSE、REDUCE、DEFENSE-PFO）支持在影像证实分流相关梗死的精心选择60岁以下者**经皮封堵加抗血小板优于单用药物**降低复发卒中，背景是器械风险（房颤、残余分流、罕见侵蚀）。**静脉血栓是当前活动问题**时首选抗凝而非抗血小板（DVT按其自身指征治疗——[[#def-doac]]的DOAC规则），而二级预防回到激发血栓逻辑：飞行相关近端DVT无论卵圆孔将来如何都要抗凝数月。
:::

::: exercise 设计预防政策 {level=3}
为综合外科病房写VTE预防政策：风险模型、机械对药物的决定、特殊人群与审计指标——并用本章生理逐项论证。
::: solution
**风险模型**：每位入院手术患者用验证工具评分（Caprini模型、RAM试验检验——年龄、恶性疾病、制动、既往VTE、易栓症、手术类型与时长），因为**[[#def-virchow]]的瘀滞加炎症性凝血活酶算术分布不均**，单一政策会过度治疗低危者（其出血预算不是免费的）。**机械法**（梯度弹力袜——尺寸正确与皮肤检查纪律、及间歇充气加压——直接逆转瘀滞的小腿泵生理）用于**出血高风险或药物禁忌者**，最高危（创伤、大癌、脊柱手术）者与药物联用，试验证据在高危组支持IPC优先联合优于单一。**药理默认**：LMWH（肾衰用UFH）术前或术后早期开始、**持续至出院并在腹盆大癌手术后延长（28–35天延长LMWH数据）**；DOAC的外科新角色（择期关节置换口服药试验——部分指南接受、多数综合外科政策仍以LMWH为锚）。**特殊人群**：妊娠（LMWH、[[obstetrics-gynaecology/pregnancy-antenatal]]的产科剂量与分娩时机）、肾衰（UFH或调整剂量LMWH配抗Xa）、椎管内导管（末次剂量与穿刺的间隔规则——应用药动学）、既往HIT（磺达肝癸钠或直接凝血酶抑制剂计划）、活动期癌症（前一练习的DOAC/LMWH规则）。**审计指标**：入院24小时内预防率、禁忌记录、癌手术的延长预防、尸检与影像证实的院内获得性VTE、出血并发症与再入院——政策证明**瘀滞可防、凝血活酶暂时、而医源性出血是你管理而非忽视的代价**。
