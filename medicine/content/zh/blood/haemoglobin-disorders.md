血红蛋白是本课程关于基因型经生物物理变成表型的最清楚例证：两α样与两β样链的四聚体，每条珠蛋白持一个血红素、以其生理围绕建设的亚铁铁结合氧，五个发育开关（胚胎、胎儿、成人——及逆转它们的应激造血）写在16号与11号染色体的基因簇里。突变对这个分子只做两件事之一——**改变它的行为**（结构变异：聚合、不稳定、氧亲和改变）或**改变它的数量**（地中海贫血：链不平衡）——而镰状细胞病、地贫重型与亲和变异的全部临床图像都由发生了哪种错误导出。

本章讲述血红蛋白的遗传与发育、以镰状细胞病为典型的结构变异，及进入输血与基因治疗时代的地中海贫血。

## 分子与它们的基因

::: definition 珠蛋白遗传学与发育 {#def-globins}
两个基因簇、两对旁同源家族：**16号的α样簇**（ζ → α2、α1；每红细胞每染色体两个α基因、共四个）与**11号的β样簇**（ε → Gγ、Aγ → δ → β），**成对的位点控制区增强子竞争**（HS位点每次成环到一个启动子）解释发育开关：胚胎（ζ2ε2——Gower与Portland）→ **胎儿HbF（α2γ2）**——高氧亲和因为γ链结合2,3-BPG很弱、是经胎盘偷氧的分子，而**γ→β开关（BCL11A与MYB/HBS1L调控子）**在出生后头几个月完成（8–12周的婴儿贫血——生理低谷加开关——也是镰状疼痛6月龄前从不出现的原因：**HbF保护新生儿**）。成人**HbA（α2β2）**带HbA₂（α2δ2，2–3%）与残余HbF（成人<1%；遗传性胎儿血红蛋白持续存在可达20%+——自然出现的疾病修饰因子）。出生后**应激造血**部分逆转开关（HbF上升，β地贫时电泳可见无效的δ/γ尝试），而同一可塑性的治疗利用——**羟基脲与新的γ抑制子靶向药升高HbF**、自体HSC的**慢病毒或CRISPR（BCL11A增强子）基因添加/编辑**现已在美英获批用于重型——闭合本章的圆：让胎儿镰状免疫的同一基因调控正被重新工程化去改造成人。
:::

::: definition 值得知道的结构变异 {#def-structural}
Hb变异逾千种；有临床意义的共享四种机制：**聚合**（HbS——β6谷氨酸→缬氨酸，造出疏水突起的谷→缬、对接邻近脱氧HbS四聚体的疏水袋（β85苯丙氨酸、β88亮氨酸），成核纤维组装、**把细胞扭曲成镰形**——延迟时间约为细胞内HbS浓度的15次方函数，这就是MCHC（细胞水合）与基因产物浓度同等重要的原因）；**亲和改变**（Hb Chesapeake与高亲和变异的家族性红细胞增多、低亲和变异的“气体正常的发绀”——氧解离曲线作为家系性状）；**不稳定**（不稳定血红蛋白——海因茨小体、脾咬痕细胞溶血、药物加重）与**M血红蛋白**（Fe³⁺稳定——对氧不应答的巧克力发绀，与获得性氧化剂原因（氨苯砜、苯佐卡因喷剂、井水）共同的高铁血红蛋白鉴别）。电泳/HPLC位置跟随电荷改变（HbS比A慢；HbC（β6谷氨酸→赖氨酸）更快，HbC的结晶形成给出靶形细胞多、病程轻的对应病），而**相互作用遗传学**（S/β地贫、SC、S-C、S-β⁰）把机制与链不平衡重组——复合杂合者的严重程度随其HbF含量与伙伴等位基因。
:::

## 镰状细胞病

::: theorem 危象病理生理及其修饰因子 {#thm-sickle}
聚合的HbS损伤红细胞（钙漏、K⁺-Cl⁻外流→**脱水抬高自身的HbS浓度**——恶性循环），并把膜变成黏附与促凝平台（VCAM/VLA-4与α4β1介导的对发炎内皮黏附、磷脂酰丝氨酸暴露、微颗粒），而血管内溶血释放的血浆游离血红蛋白**清除一氧化氮**——慢性期的血管病（肺动脉高压、阴茎异常勃起、肾浓缩与酸化缺陷、腿部溃疡）。叠加的**缺血-再灌注炎症**（NF-κB、P-选择素、中性粒与单核蜂群）产生**血管闭塞危象**——疼痛、发热，及各综合征：**急性胸部综合征**（新浸润伴发热/呼吸症状——感染、骨髓脂肪栓塞、局部镰闭与夹板样通气不足——感染模式下头号死亡）、**脾滞留**（自体梗死前的婴儿脾池积危象）、**再障危象**（细小病毒B19让红系工厂停摆——溶血患者的网织红归零）、**卒中**（儿童大血管moyamoya；筛查MRI上的隐匿梗死），及阴茎异常勃起与多器官镰状肾病。**胎儿血红蛋白是主修饰因子**（细胞内HbF低于约20%即把HbS拒于聚合之外——遗传性胎儿Hb持续存在与X连锁及Senegal/Benin单倍型病程轻的原因、每种疾病修饰药之靶），而**脾的早期丢失**（HbSS至童年中期即功能性无脾——豪-周小体）规定了感染预防包：**两月起青霉素、肺炎球菌与脑膜炎球菌与流感嗜血杆菌疫苗、发热即急诊规则**——血液学里最成功的一条基层医疗方案。
:::

::: example 发热而疼痛的孩子 {#ex-vaso}
4岁已确诊HbSS患儿，发热39.2 °C、双足肿痛性肿胀、Hb 58（基线75）、网织红12%、胸片清晰。
::: solution
两条规则同时触发。**功能性无脾儿童的发热是内科急症**：血培养、**一小时内广谱静脉抗生素**（青霉素预防与疫苗本要预防的荚膜菌脓毒症——会突破，而方案存在是因为HbSS的肺炎球菌死亡以小时计不以天计）、流行区查疟、住院整夜观察第2–3天才现形的呼吸综合征。**疼痛是血管闭塞危象**：快速镇痛（体重方案的胃肠外阿片加扑热息痛、肾功能允许再加NSAID；基线阿片耐受儿童要给家用量之上再加）、**加温与懂钠的补液**（镰变的算术：低渗液降血钠、恶化细胞肿胀动力学——用含等张液的葡萄糖并监测）、输血**只按指征**（Hb 58伴正常网织红是该儿的代偿性溶血——按自基线下降、再障危象、急性胸、卒中、滞留来输；简单补充至约100 g/L，重度器官综合征换血——目标是把HbS稀释到30%以下，不是把血红蛋白正常化）。随后维持审计：羟基脲资格与剂量（HbF与中性粒终点）、卒中风险的输血方案（经颅多普勒筛查方案——流速升高即慢性输血、STOP试验的逻辑）、疫苗与青霉素状态、及家系遗传咨询（同胞筛查与携带者问题——[[genetics/mendelian-inheritance]]的隐性算术）。
:::

::: example 耐力运动员的血细胞比容 {#ex-affinity}
24岁长跑运动员病毒感染后发现Hb 195 g/L、血细胞比容58%；其父与姑母“血稠”、偶尔放血；EPO低、血氧饱和正常、BCR-ABL阴性、氧解离分析报告曲线左移。
::: solution
**高氧亲和血红蛋白变异所致家族性红细胞增多**（Hb Chesapeake与Kemp Town一类——α与β链界面替换、经典为新发或显性）：变异的稳定**R态把氧抓得太紧**（低P50——[[#def-structural]]的左移），组织读出相对缺氧，肾HIF模块（[[blood/haematopoiesis]]）**短暂**升高EPO、红细胞质量扩张到输送匹配为止——新稳态是高血红蛋白伴**被压低到正常的EPO**（慢性状态的反馈重置）、饱和正常（排除肺与分流的病因）、无JAK2克隆（排除真性红细胞增多——其EPO亦低但中性粒与血小板升高、症状与血栓风险不同：亲和轴为红细胞增多检查补上的鉴别，由P50测定与珠蛋白测序完成）。临床要点是克制：**患者是已适应，不是规则性高黏滞**——放血只为症状（运动员的警诫：把质量减到适应水平以下会让氧输送更糟而非更好），不套用真性红增多症的血栓风险，遗传（显性）咨询与避免术前“纠正”完成管理——经同一使HbF保护、使Bart's致死的解离曲线生物物理到达的良性血红蛋白表型：**氧亲和是恰到好处的属性，而变异同时展示两条边。**

## 地中海贫血

::: definition 作为疾病的链不平衡 {#def-thal}
**α地中海贫血**几乎总是**缺失型**（−α、−−；四基因剂量：静止携带、两基因顺式缺失的α性状（东南亚−−/αα有**Hb Bart's胎儿水肿**之险——全无α链、γ4四聚体亲氧到拒绝卸氧——宫内致死伴母体水肿毒、现以宫内输血处理）、**HbH病**（−−/−α：β4四聚体、中度不稳定红系溶血、超活体染色高尔夫球），及**Hb Constant Spring**非缺失型加剧因子）；**β地中海贫血**则是数百种**点突变**（启动子、剪接——IVS变异——与无义；人群特异的奠基等位基因——地中海β⁰ IVS-I-110与IVS-I-6、亚洲密码子41/42移码、印度IVS-I-5），其**β⁺/β⁰产量给表型定级**：性状（轻度小细胞贫血伴HbA₂升高——开铁者漏掉的诊断）、**中间型**（大致不需输血、仍切脾仍被髓外造血变形），及**重型（Cooley贫血）**——β⁰/β⁰的**无效造血加外周溶血（γ链过量、不稳定包涵体负荷的红细胞）**、在HbF→HbA开关失败的6–24个月起病：发育停滞、黄疸、骨髓扩张（田鼠面容与毛发竖起颅、髓外肿块），及**无效造血自身的铁负荷**——成红细胞铁调素抑制铁调素、吸收最大化，故未输血者亦积铁。现代管理是**规律输血至约90–105 g/L（压制驱动与吸收）加螯合（地拉罗司/去铁胺/地拉罗昔酮、心肝T2* MRI监测）**——一套1980至2000年代方案把致死童年病变成带内分泌心肝后遗症的成年，再进入**基因治疗时代**（慢病毒β珠蛋白添加——betibeglogen autotemcel一类——与CRISPR编辑路径，[[genetics/genomic-medicine]]落地旗舰）与**成熟剂luspetercept（抑制素B配体捕获、纠正无效造血）**。人群筛查（塞浦路斯、撒丁、泰国——携带者检测与遗传咨询使出生率减半：模范公共卫生遗传学规划，[[epidemiology-ebm]]的筛查标准被尊重）与让基因簇落在它们所在处的疟疾选择解释并列（又见[[genetics/common-disease-genetics]]）。
:::

::: example 苍白而脾大的幼儿 {#ex-thalmajor}
14个月塞浦路斯婴儿、纯母乳未添铁，苍白、发育不佳、黄疸；Hb 52、MCV 58、靶形细胞、有核红、脾6厘米；父亲“β性状”。
::: solution
**β地中海贫血重型**直到证明不是——年龄（γ→β开关刚刚失败、揭穿缺席的β产量）、计数（最重的小细胞贫血伴最戏剧的涂片——膜损伤、珠蛋白贫乏红细胞的有核红与靶形细胞）、家系（双亲皆为携带者——母亲的“性状”未被诊断；咨询必须说明的四分之一再发）。以**血红蛋白电泳/HPLC**确证（无HbA、HbF 80–95%——诊断图像，对照中间型的更高HbF伴少量A）与服务家庭未来的**基因检测**。急性处理：**缓慢输血**（24小时限速的浓缩红细胞加利尿剂、或心衰性贫血的换血——该儿心脏在Hb 52上工作）、叶酸、及**输血方案决定**（规律输至90–105——生长、面容与心脏结局系于此），铁负荷后开始**铁螯合**（通常输血1–2年或铁蛋白>1000 µg/L）、**切脾问题**（只针对推高输血需求的症状性脾亢——带[[blood/haematopoiesis]]无脾疫苗与抗生素守则）、输血时代创建的内分泌监测（铁致糖尿病、甲状腺、性腺衰竭），及转诊谈话：**HLA相合同胞HSCT可治愈、在有条件处是现行标准；基因治疗把治愈扩展到无同胞者**——[[genetics/genomic-medicine]]伦理专栏先于诊室写好的决策树。
:::

::: example 本不该倒下的运动员 {#ex-trait}
19岁非裔美国新兵在初期高强度训练时倒下，伴极度肌痛与可乐色尿；入学时被告知“镰状试验阳性但你没事——只是性状”。
::: solution
**镰状细胞性状（HbAS）运动性虚脱伴横纹肌溶解**——罕见、真实、法医学上响亮的并发症。性状恰好在生理预测的场景里不无害：**极端运动加高热、脱水与酸中毒**（[[#def-structural]]的聚合延迟时间算术：细胞脱水酸化时即使约40%的HbS也聚合——故军训与消防员新兵的运动性横纹肌溶解与猝死聚集、经典为营期第一周）、**高原与低压环境**（肾髓质的生理性低氧与渗透应激，这就是**无痛血尿与罕见的肾髓质癌**同样归属性状的原因）、麻醉与危重的**低氧与酸中毒**，及**脾与运动性热卒中综合征**。管理后果：性状筛查与咨询（生殖咨询是其主要的医学用途——配偶查HbS、HbC、HbE与β地贫等位基因——决定后代是否发病的复合杂合风险）、死亡事件后写入军方与NCAA政策的保护性运动规则（渐进体能、补水、疼痛/痉挛即停、高温下不计时冲刺），及围术与产科对低氧酸中毒的警惕。性状 恰恰是**带若干极端状态注意事项的正常生活**——而这位运动员的案例是永远别说“没事”的警世故事。
:::

::: history
分子先有临床：**Herrick**1910年芝加哥病例——一位反复疼痛的学生血中“奇异的长形与靶形小体”（论文写于在既往疝修补术病历里翻找“器械病例”之后）、**Hahn与Gillespie**1927年证明镰变是细胞内且可逆、**Pauling、Itano、Singer与Wells**1949年电泳显示HbS是**分子异常**之病（造出“分子病”一词的论文——Pauling的化学诺奖，及镰状杂合子疟疾保护经由**Allison**1954年东非工作的发现）、**Ingram**1956年将单个谷→缬定位到氨基酸（指纹纸上完成的一突变一差异第一证），及**Weatherall与Crichton**的地贫生化、**Kan**1970年代α地贫产前诊断工作——使血红蛋白病成为首个常规产前分子应用；**塞浦路斯与撒丁**筛查规划（Cao及其同事推动的人群医学版）、**Thomas**的早期移植长成治愈标准、及**2023年首个针对单基因病的CRISPR疗法获批——对象是镰状细胞病与输血依赖β地贫**——把1956年的凝胶与基因之间的鸿沟一年闭合。
:::

## 通向何处

遗传算术在[[genetics/mendelian-inheritance]]；群体遗传学与疟疾选择在[[genetics/common-disease-genetics]]；产前与新生儿筛查在[[obstetrics-gynaecology/pregnancy-antenatal]]与[[paediatrics/newborn]]；铁螯合药理在[[pharmacology/adverse-reactions]]；基因治疗在[[genetics/genomic-medicine]]。

::: summary
- 血红蛋白病分为质性变异（聚合、不稳定、亲和改变）与量性地贫（链不平衡）；两者读自同一基因簇与同一发育开关。
- 镰状细胞病是聚合生物物理、带着炎症与一氧化氮清除的临床脸；HbF是主修饰因子，这就是羟基脲、基因添加与BCL11A编辑都靠升高它起效的原因。
- 无脾儿童的感染方案——青霉素、疫苗、发热即急诊——与输血/换血标准是改写该病流行病学的干预。
- 地中海贫血是不平衡之病：α为缺失、β为突变，无效造血与铁调素被抑致铁负荷甚至对未输血患者的治疗也是核心。
- 镰状性状是带极端状态注意事项（高热、运动、高原、低氧）的正常生活与一条生殖信息，不是健康的诊断。
- 筛查、咨询、输血、螯合与如今基因治疗，使血红蛋白病成为从凝胶电泳到编辑干细胞单基因病医学的模范。
:::

## 练习

::: exercise 产房的电泳 {level=1}
新生儿筛查示FSA型；六月龄时HbF下降、HbS 68%、HbA 0、HbF 30%。给出基因型推理，并说明为什么HbA为零排除了良性可能。
::: solution
出生时HbF占绝对优势，故筛查的**F与S/A带对“有”敏感、对严重度无信息**（筛出的是总HbS）；六月龄γ→β开关已跑完、构成即可读：**HbS主体而无HbA**意味着**HbSS**或**S/β⁰地贫**（S/β⁺会造出一些A；S-C与S/性状会显示伙伴带或仅有S伴计数正常），而**HbA为零排除镰状性状**（性状造A）并排除S/β⁺。鉴别资料：红细胞指数（S/β⁰的小细胞与A₂升高）与家系或DNA。该练习的临床要点：**新生儿筛查的职责是在九月龄前启动青霉素预防与家长教育**——首波感染与首个疼痛到来之前，这就是美国各州、NHS规划与WHO非洲框架都筛查的原因。
:::
:::

::: exercise 四基因算术 {level=1}
写出α地贫四个基因型类别及其缺失与临床图像，并说出哪些婚配产生胎儿水肿。
::: solution
**1缺失（−α/αα）**静止携带；**2缺失**或为**顺式（−−/αα）**（亚洲/地中海——有风险）或**反式（−α/−α）**（非洲——良性性状），两者均小细胞伴出生时Hb Bart's痕迹；**3缺失（−−/−α）=HbH病**——成人β4、高尔夫球包涵体、中度溶血性贫血伴脾大、间断输血；**4缺失（−−/−−）=Hb Bart's胎儿水肿**——γ4四聚体、氧亲和高到组织处无法卸氧：胎性贫血、心衰、母体镜像毒血症；存活者现需出生即换血随后慢性方案，HSCT治愈已有报道。**水肿需要双亲均为顺式（−−）携带者**——各传一条双缺失16号染色体；反式构型永不出−−/−−合子，这就是高危人群（东南亚）不同于单纯携带率地图的原因。咨询算术：顺式×顺式→每次妊娠25%水肿——故社群必须在产前筛查高危妊娠并做DNA携带者检测（[[obstetrics-gynaecology/pregnancy-antenatal]]）。
:::
:::

::: exercise 升高胎儿血红蛋白 {level=2}
列出升高镰状患者HbF的三种方法——一生理、一药理、一遗传——并解释每一种如何经聚合排斥机制起效。
::: solution
**生理**：**F细胞不对称与应激造血**——含HbF细胞（F细胞）分布不均并在红系应激下扩张（妊娠、再障恢复、非羟基脲的促红素驱动）；保护机制即聚合排斥——HbF超过约20–30%阈值的细胞把HbS浓度和/或混溶隙压到聚合以下。**药理**：**羟基脲**（细胞毒剂量时抑制核糖核苷酸还原酶；临床剂量时经信号通路——含一氧化氮与cGMP——汇聚到**募集F细胞祖细胞与激活γ基因**，加上中性粒与黏附分子效应）；数月HbF上升与危象减少及生存信号相关；更新的药攻击抑制机器本身——**下调BCL11A的慢病毒载体（β基因与抗BCL11A microRNA共表达）与CRISPR增强子编辑（已获批的exa-cel）**——及口服γ诱导类别（去甲基化剂与丁酸通路化合物）。**遗传**：**遗传性胎儿血红蛋白持续存在**（缺失型与非缺失型HPFH、非裔美国与希腊染色体、及全细胞F的δβ地贫——自然发生的概念验证：S/HPFH临床近乎正常）。三者沿同一生物物理：γ链无可聚合界面、把S稀释出纤维——疗法就是胎儿，被重新引入。
:::
:::

::: exercise 输血方案 {level=2}
两个镰状患者：一经颅多普勒异常，一首次缺血性卒中。分别给出指南输血策略与铁风险管理，并说明为什么“把血红蛋白正常化”不是目标。
::: solution
**TCD异常（条件性→异常流速，200+ cm/s）**：**慢性简单输血维持HbS<30%**（STOP试验的卒中一级预防结果；现低资源或不合格场景可选**羟基脲**——TWiTCH降级证据）——数月数年的方案、随铁蓄积做铁蛋白与MRI-T2*监测并螯合（每单位约200–250 mg铁；输血铁路径绕过[[blood/anaemia]]生理中被阻断的排泄）。**首次卒中**：**急性期换血**（自动化红细胞置换——不占容量不抬黏滞地快速降HbS），随后**慢性交换或简单方案**，moyamoya选择病例的外科问题**STA-MCA旁路**。目标是**HbS稀释而非血红蛋白正常化**：目标30% HbS、总Hb保持约100–110——把Hb推得更高会升高黏滞（镰状微循环是顺应性与流量问题；高黏滞生血管闭塞），积极正常化试验交付的是伤害不是益处。同一算术管辖急性胸与围术换血阈值——又是本章的生物物理：你治的是聚合比例，从不是瓶签上的数字。
:::

::: exercise α性状父母的黄疸新生儿 {level=2}
一东南亚足月儿出生时水肿、肝脾大、涂片10%有核红细胞碎片、Hb 40；电泳见大Hb Bart's峰（85%）伴Hb Portland、无HbA。解释之，先处理母亲，然后说出该诊断的产前签名。
::: solution
图像是**Hb Bart's胎儿水肿（−−/−−）**：全无α链，胚胎改用**γ4（Bart's）与ζ4（Portland）**组合——Bart's（四γ链血红蛋白）**基本没有Bohr效应卸氧、氧亲和远高于母胎转移梯度**，故尽管红细胞质量试图代偿、组织仍慢性缺氧：高输出心衰、肝脾大（髓外红系造血）、涂片上有核细胞的混乱。**母亲优先**：镜像综合征（随水肿胎盘娩出而缓解的母体水肿、高血压与毒血症样图像——期待管理并非被动的理由）、巨大胎盘与早产儿的剖宫产判断、及**新生儿救援方案**（立即换血清除Bart's支持氧合，随后慢性输血方案；存活者已是发表过的系列、多数由**HSCT**治愈、必须告知家属此选项存在）。**产前签名**：小细胞低色素胎儿、脐血或胎血采样见Hb Bart's（**MCH<24**升高伴核细胞与超声胎盘增大是更早线索）、**父母顺式（−−/αα）携带状态**、及现代路径的靶向胎儿DNA检测（绒毛膜绒毛取样或无细胞），及高危夫妇应在**孕中期前**就接触的种植前与产前选项。
:::

::: exercise 不稳定变异与用药史 {level=2}
30岁“G6PD正常”地中海裔患者因尿路感染服呋喃妥因后急性溶血伴海因茨小体与咬痕细胞；家族史包括因“先天性溶血性贫血”切脾。解释两个符合的诊断，及分开它们的检测。
::: solution
两种可能都是**氧化剂/不稳定血红蛋白溶血**，鉴别在胞性与酶：**(1) 不稳定血红蛋白变异**（β链突变——Hb Köln一类——在氧化剂或热应激下变性，给出海因茨小体、脾咬痕细胞图像、**终身黄疸与切脾的家族史**、G6PD正常）或**(2) 检测判为正常的G6PD变异**（网织红增多期的I/II型变异、或嵌合酶尚够的女性杂合子——检测的经典假阴性）。分开二者的检测：**热沉淀与异丙醇不稳定试验**、**层析/电泳与珠蛋白测序**找结构变异；**恢复后复查定量G6PD**、有条件的做缺乏基因型。统一的生理是血红素与珠链共享的脆弱——氧化应激把Fe²⁺转Fe³⁺（高铁血红蛋白）并交联珠蛋白（血色原、海因茨小体）除非NADPH保住还原谷胱甘肽——同一轴解释为什么**磺胺、呋喃妥因、氨苯砜、普拉喹、萘与大剂量维生素C**是共享的“避免”清单，及不稳定血红蛋白患者可以**药物诱发的溶血**、基线接近代偿的形式就诊；G6PD阴性不结案，家族史就是下一项检查。
:::

::: exercise β地贫中间型之问 {level=2}
12岁已证实β⁺/β⁰复合地贫，从未输血而Hb 85，脾大、胆石、铁蛋白850而心脏T2*正常。解释无效造血如何不经输血引起铁负荷，并按严重度给出现行治疗选项。
::: solution
机制穿过**成红细胞铁调素抑制因子（ERFE）**：扩张的、促红素驱动的红系前体分泌ERFE、**无论体铁如何都抑制铁调素**，故十二指肠膜铁转运持续全开、**吸收升至正常数倍**——不输血的患者经肠道载铁，先网状内皮、（超过其上限后）实质的模式随之。按级治疗：较轻者**观察加监测**（每年铁蛋白与T2* MRI、肝功与内分泌筛查）、症状性脾亢或推动输血的消耗做**切脾**（带无脾感染守则）、需要时**输血支持**（中间型的危象与妊娠）、铁负荷时**螯合**（首选地拉罗司——现代口服药）、γ胜任基因型用**羟基脲升HbF**（β⁺中间型最好的药理杠杆）、**成熟/抑制类别药（luspetercept——抑制素受体配体捕获、压制Smad2/5让红系前体成熟）**已在若干场景获批、进展病例**HSCT（中间型年轻患者日益接受）或基因治疗**。生理——不平衡、无效造血、铁调素抑制——规定了监测，因为中间型里**铁风险与输血需求同样真实而安静得多。**
:::

::: exercise 设计人群规划 {level=3}
为β地贫携带率8%而专科资源匮乏的国家设计血红蛋白病预防与照护规划。用经典规划（塞浦路斯、撒丁、伊朗、泰国）的证据论证每个要素。
::: solution
**预防（婚前/孕前携带者筛查加生殖咨询）**：塞浦路斯与撒丁证明**自愿、免费、以夫妇为单位、配套产前诊断与非指令性咨询的筛查**二十年内使患病出生减少90%以上——起作用的要素：婚育前学校层教育、阳性携带结果触发的配偶检测、可运作的产前诊断服务（11周绒毛取样、用奠基等位基因panel——便宜，奠基人群少数突变占多数等位基因；人群特异的多重PCR或Luminex panel，而非全测序）。伊朗的大学婚前规划把模型扩展到全国规模；陷阱（污名、性别选择争议、咨询必须真非指令性）是[[medical-ethics-law]]处理的伦理组件。**照护**：登记患者、**标准化输血与螯合方案**（最具成本效益的临床杠杆：国际地贫联合会指南、ELISA铁蛋白监测、可转诊处T2* MRI）、**培训地区血液科护士**、保障血供安全（输血传播感染的算术：地贫队列在筛查前被HIV与肝炎摧毁——患者识别号与血库审计是核心指标）、**为相合同胞病例开展HSCT**（伊朗与印度经验显示高流行处治愈成本可行），并为基因治疗的定价问题做准备。**监测**：出生发病率登记（证明规划有效的分母），非洲流行对应场景的新生儿镰状筛查。统一的证据：血红蛋白病是**生理、公共卫生与卫生经济学闭环**的范式——本章的全部弧线成为政策。
