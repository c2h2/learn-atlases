临床推理是所有其他操作继承的隐形操作：症状变成诊断、诊断变成计划的过程、及按诊断错误文献估计约二十分之一临床接诊中失败的过程——思维方式错误的失败多于知识缺口。**本章讲述临床思维如何实际工作（快速模式识别与慢速分析核查的双过程模型、专家构建的疾病脚本及其失灵条件）、鉴别诊断的技艺（锚定在基率上的概率、不可漏类别、结构记忆法的诚实职责）、失效模式及其对策（现已编目并测量的认知偏倚、有证据的去偏策略、自身确定度的校准、及作为推理工具的安全网）、及与技术的互动（决策支持、搜索即满足之问、及嵌入病历写法的推理审计）。**

## 思维如何工作

::: definition 双过程、疾病脚本与专长 {#def-dual}
**工作模型是双过程：系统1思维快速、自动、整体并带情绪标记（资深护士或医师“她看起来像脓毒症”的识别），系统2缓慢、刻意、循规则而费力（系统排除的工作检查）；专长在很大程度上是拥有一座大型疾病脚本图书馆——链接赋能条件、病理生理紊乱与临床图像关键特征的包裹——由数千次有信息结局的被策展患者接诊建成、这就是模式识别随年资进步又跨域崩塌的原因（胸腔出色而皮疹平平的医师、专长文献强调的“领域特异性”发现）。系统1是多数临床出色与多数临床错误的源头、因为它匹配而核查：它对代表特征敏感、对基率冷漠、并对会打破模式的缺失发现失明（“若这是肺炎我还期待什么——它在缺席吗？”系统2必须问而常常不问的问题）。发展弧可教并可测：新手收集线索、中间者收集带错误灵活度的疾病原型、专家跑模式识别带分析后备、并且关键地监控何时切换（把安全专家从自信的危险者分开的元认知）；为推理的刻意练习意味着对带推理（不只是答案）反馈的病例间隔暴露（疾病脚本构建文献的处方：比较对照、解释模仿者为何不是目标、揭示前先生成。）对学生或忙临床医师的实际后果有三：在收集更多数据之前生成鉴别（“若这是X我期待找到什么、什么会打破它”框架改善数据收集对乱开检查）、尊重情绪标记（资深观察者“有什么不对”是带似然比的发现、而“但数字正常”不是反驳）、及排期分析审计（对着病例自身脚本的刻意重读：缺失特征、基率违背、不相符的患者——这就是“不能解释”类别值得一个日记日期而不是耸肩的原因）。**
:::

## 鉴别

::: definition 概率、鉴别与不可漏清单 {#def-differential}
**好的推理从第一分钟就是概率的：验前概率是基率（年龄、性别、流行率、场景——19岁与79岁的胸痛是不同的病直到证明不是）被发现的似然比修正、而整个检查判读伦理立于把这个数字大致弄对、这就是查体与病史章不断回到它的原因。鉴别诊断是让概率保持诚实的工具：工作版尽早生成、被数据修剪、被治疗失败重开、而其书面形态（带排序候选与判别特征的问题清单）是最可迁移的一块推理文书；记忆法结构作为对抗过早闭合的清单用时干真活对未分化表现的VINDICATE家族扫描（血管、感染、肿瘤、退行、医源/中毒、先天、自免、创伤、内分泌/代谢）、及不同专科用来强制造广的“解剖、生理、心理”与“常见、并发、危重、罕见但灾难”框架。不可漏类别是每个表现自己的清单、值得像药量一样背、因为其成员在第二次就诊杀人（晕厥的心律失常与SAH与消化道出血与异位与睾丸扭转与会厌炎与马尾与脑膜炎球菌与主动脉夹层与张力性气胸、及把“普通病毒”翻车的儿童严重细菌感染）；相关安全语法是“拆成三问”：这会是杀手吗（概率）、我多有把握（检查阈值透明）、如果我错了计划是什么（带时间与扳机的显式安全网）。诊断惯性与标签惰性问题是鉴别的社会公敌：一个场景贴上的标签（“常客”、“学习困难”、“焦虑”）在每个后续场景招募知觉、而纠正靠程序不靠态度——把标签当假说、疾病不守规矩就重查（病史章奉为圭臬的治疗失败即数据规则）。最后向患者框定不确定性是鉴别完成的一部分：诚实的“我还不知道、我们在排除、时间线与回来的扳机”每次胜假性闭合、无论伦理（知情参与）还是流行病学（动员而非安慰时患者是可得的最好门诊监测装置）。**
:::

## 失效模式

::: definition 认知偏倚、去偏与安全网 {#def-bias}
**分类学如今附上结局数据（Croskerry与Singh及诊断错误联盟的工作）：过早闭合（停止错误、错误系列最常见）、锚定（第一个可得框架驱动其后一切、从分诊笔记到转诊信诊断）、可得性（上个月难忘病例扭曲今晚概率）、框架效应（同样统计以生存对死亡穿衣时选择不同）、沉没成本与承诺升级文献（“已做这么多检查、一定能找到”）、搜索满足（第一个异常找到后漏掉第二个——经典结肠镜与放射发现、在心电图判读与创伤巡视有直接类比）；病史引导性提问里的确认偏倚；“常见病常见”对刚发表斑马之间的可得性钟摆；遗漏偏倚（对作为的错误怕过不作为的错误、同样塑造开单与治疗迟疑）；及情绪与组织变异：负迁移邻近（“困难患者”反应压制好奇）、等级压抑的鉴别（看到替代方案却沉默的初级——敢言文献的诊断）、及疲劳与打断降级的系统2（为何凌晨3点决定与被呼机腰斩的病史是自己的错误类别）。有证据的去偏工具程序化而便宜：闭合时点强制的“还可能是什么？”提示；“万一我错了我会漏掉什么、它会杀人吗”安全查询；重大计划前的事后剖析；诊断暂停与第二意见仪式（“不能解释24小时”与“六周内三次以上入院”扳机）；病历里显式概率语言（低/中/高概率带及其触发的行动阈值、同时对后见改写可知性免疫）；红旗清单对现症的回查；“患者不在轨道上、诊断就没完成”重构（治疗失败是最被低估的数据点）；及元认知习惯——知道自己领域边界、校准训练（显示医师90%确定的病例只对70%的反馈环令人不适而有纠正性）、及对非紧急难题明智地“再想想”睡一觉。安全网闭环：显式时间与扳机（周三不好转或呼吸加重就今天打电话）、对未分化的记录计划（谁拥有待回检查、谁复审未解决）、及再就诊文化（诊断延迟文献偏好“不同就回来”胜过开放安抚）。系统层纠正属患者安全章（诊断错误报告与学习环）——但临床医师个人不可约的职责是诚实病历、用过的重开器、及传达的不确定性、因为多数晚诊断病例不是未知病而是重开得太晚。**
:::

::: example 常客 {#ex-momentum}
41岁伴学习障碍、“四次同一件事——行为性”就诊、呕吐两天、心率126、意识模糊“像平时但更重”；分诊与病房都记录“行为性、同前”；入夜她因大肠杆菌败血症开腹、粪便嵌塞伴粪性穿孔、已插管。
::: solution
**标签持续是双过程失败（[[#def-differential]]、[[#def-bias]]）：机制——标签是系统1的捷径被社会化：“行为性、同前”取代鉴别而非加入、然后认知文献的惯性+持续+锚定三重做完其余；尖声大喊的发现——心动过速与意识模糊是无法定位或叙述症状人群的生理体征（病史章为每个给不出典型病史者陈述的非典型表现规则）、而“比平时重”正是为此病例发明的红旗；本应程序化的对策——“每次就诊记录基线功能”惯例（没有“平时”就看不见“比平时重”）、“学习障碍患者得到与任何意识模糊者相同的生理工作检查”规则（反歧视与决定能力文献及合理便利职责汇聚于此）、及“新生理体征重置标签”政策（疼痛-心率-GCS组合覆盖任何精神或行为标签、学习障碍重症感染死亡复审索要了三十年）；及调查要求的推理审计——把鉴别记录为已考虑及为何不是、而非把标签当判决的病历、被驳回时的升级路径、及家属“她不是她自己”被记录为其法律与医学所是的知情者发现。**
:::

::: example 第二个发现 {#ex-sos}
66岁因肾绞痛做CT显示结石及偶然9 mm肺结节与甲状腺结节；结石路径完成、患者出院；结节报告在一封信里“供全科随访”；十八个月后肺病灶成3 cm肿块、甲状腺病灶良性而无关。
::: solution
**搜索满足与未决清单（[[#def-bias]]、[[clinical-skills/records-handover]]、[[respiratory/lung-cancer-pleura]]）：认知与系统失败可分离——搜索满足在放射被测量（第一个病灶找到后第二个漏检率上升、及双读与AI分诊文献的对策）、而其临床孪生是完成兴奋问题而遗弃偶然发现的出院流程；本该接住它的偶然瘤治理——出院小结带所有者与间隔的结构化“未决发现”段、需要有人应用规则的Fleischner与RCR邻近结节随访表、及让“供随访”的信变成带日期清单而非散文的全科系统；推理层——偶然发现移动验前概率（吸烟史9 mm结节的恶性风险是活跃计算、不是安慰）、而“这事归谁”是临床推理之问：鉴别不只是现症的、也是患者整个问题清单的；及漏诊病例的再入——带“延迟归属”复审的两转归分期路径（肺癌审计用的患者延迟对系统延迟对医师延迟类别）、赔偿与坦承谈话、及科室采纳未决发现登记——因为搜索满足文献唯一证明的修复是另一双新鲜的眼睛、这是披认知外衣的组织声明。**

## 通向何处

喂养推理的病史技术在[[clinical-skills/history-taking]]、查体的似然比在[[clinical-skills/physical-examination]]、检查阈值与预测值在[[clinical-skills/laboratory-tests]]与[[epidemiology-ebm/diagnostic-tests]]、安全网与记录文化在[[clinical-skills/patient-safety]]与[[clinical-skills/records-handover]]、诊断错误流行病学的母学科在[[public-health/health-systems-economics]]。

::: history
**临床推理的正式研究始于其教学所在：床旁。Reid与苏格兰诊所“实践指导”传统及课程在床旁的Osler格言设定了时代；William Gull爵士与大讲座传统把诊断“学派”编纂。第一个科学挑战来自行为主义：1940年代、放射医师与病理医师会在其共同商定的发现上出错（Rorschach时代信度研究）、播下诊断表现可测量且不完美的种子。1970-80年代认知革命产生该领域双发现：专家靠识别启动匹配而非算法推理（Chase与Simon国际象棋记忆工作由Elstein与Shulman等凯斯西储移植到医学、其1978年《医学问题解决》专论创立临床推断实验研究并发现医师概率估计校准得很糟）、及同一机制产生系统错误——Tversky-Kahneman启发式与偏倚规划（可得性与代表性及锚定、1973-1974）提供了“代表性”与“基率忽略”这两个正是1970-80年代诊断认知研究用来在医师中记录它的词汇。1980-90年代带来社会技术转向：Patel与Groen的“认知表征”模型、疾病脚本说明（Feltovich与Barrows及Schmidt与Norman与Boshuizen的“头十年模板、病理生理在后”专长研究）、及Croskerry 2000年代的论文把双过程模型（其后Kahneman对Stanovich与West 1990年代工作及更早“直觉专家”文献的System-1/System-2一般化）带着附表教学计划移植进临床医学。医学认知偏倚分类学（Croskerry的《认知去偏》与科罗拉多及弗吉尼亚联邦小组、带记忆法工具箱与联邦患者安全机构的事件调查者认知偏倚指数）把心理学变成清单。错误成为流行病学对象：2000年代医学研究所《跨越质量鸿沟》邻近的诊断错误转向、2009-2015研究系列（诊断优化医学研讨会及Singh-Sikka-Hidden邻近基层分析）、2013年美国内科委员会承认“错误诊断”索赔是赔偿顶类别、及2015年《改善卫生保健中的诊断》首次共识定义诊断错误并发布如今贯穿认证的推荐（报告系统、团队验证、患者参与）。阈值与决策规则谱系归循证医学本身：1980年Pauker与Kassirer阈值模型（每章引用而不点名的检查-治疗阈值几何）、1993起合理临床检查系列的似然比形式化、及把概率推理操作化为政策的决策规则正典（Wells、Centor、Ottawa、NICE路径算法）。其未决辩论是本章的活线：去偏的效力（2010年代试验显示提示助某些错误而害另一些、及元认知培训计划的谨慎证据）、校准反馈研究令人不适的数字、及诊断算法在主场上与临床直觉竞争时“AI作为第二系统1”之论、及最强错误相关项是组织性（疲劳、等级、不连续）而非个人性的持续发现——这就是推理课程不断结束于患者安全章的原因。** - [[clinical-skills/patient-safety]]、[[epidemiology-ebm/diagnostic-tests]]、[[clinical-skills/history-taking]]。**
:::

::: summary
- 临床思维双轨运行：由数千次带结局反馈病例建成的快速识别（疾病脚本）与慢速分析核查；专长多半是更好的图书馆加知道何时审计它的元认知。
- 推理是概率的：来自基率与发现似然比的验前概率驱动检查选择与判读；书面鉴别使其诚实并在临床医师间传递。
- 每表现的不可漏清单要背、因为病在第二次就诊杀人；安全语法是概率、确定度、及带时间扳机的显式错-则计划。
- 最常见错误是停止与锚定：过早闭合、标签持续与诊断惯性；治疗失败与“比平时重”是最便宜的重开器。
- 去偏靠程序不靠愿景：强制替代、事后剖析、诊断暂停、病历概率语言、校准反馈、及第二双新鲜眼睛（唯一证明的搜索满足对策）。
- 传达良好的不确定性（“还不知道什么、在排除什么、何时回来”）是诊断工具；多数晚诊断不是不可知而是重开得太晚。
:::

::: solution
**起作用的暂停（[[#def-bias]]、[[#def-differential]]、[[clinical-skills/patient-safety]]）：扳机——“不能解释72小时伴器官支持或激素或抗生素尝试失败”、“六周内三次同一问题入院或急诊”、“患者或家属说怎么都不对”、“罕见聚集”旗（三个以上同一癌症信号的就诊者及董事会只在死亡复审后才听说的我们都漏了什么病例）；参与者——停止规则（病例由从未见过它的最初级医师汇报、上级在护士之后发言因为等级压制文献正是要点）、诊断学家或未分化教育计划负责人、药剂与病理与放射席位——每个此类干预的报告都说它们在头六个月自我偿付（“我们2019年胶片上见过那个”与“药浓度从没抽过”发现）；议程——一页重建问题表征、鉴别的结构化重写（“什么不符、我们还没问什么”遍、“按流行率而非按门第考虑斑马”条款）、“能定论的检查”清单（基因panel与稀有病及肿瘤标志与自免组套及何时不用）、暂停项目从其最佳病例不断重学的“进屋再查患者”规则、及每个留置假说的带日期的所有者；文书——暂停笔记（当时的鉴别、追了什么、丢了什么及为何）既是法务珍贵文件又是学习资产；及被答复的治理异议——1“我们会把一切暂停”：不、扳机显式而被审计；2“它指责团队”：结构上无指责、含既往贴标签病例、公正文化政策点名；3“它延迟出院”：暂停为不出院的患者而存在、不能解释住院的床位与焦虑经济学付得起这一小时。**

::: exercise 与算法共推理 {level=2}
急诊部署ECG-AI标记“可能房颤”与“低射血分数”；其论文敏感度特异度均约90%。两个月后、肌钙蛋白与超声需求上升、一次出院被辩护为“算法说没事”。设定政策。

::: example 疫苗恐惧的胸痛 {#ex-anchoring}
35岁因两天非典型胸痛就诊；分诊记录“疫苗犹豫阴谋论者、博关注”；心电图示轻微PR压低、而抽血师因“只是惊恐发作”漏掉肌钙蛋白；到第6小时疼痛体位依赖、心包炎已显然。
::: solution
**负迁移是发现稽核员（[[#def-bias]]、[[#def-differential]]、[[clinical-skills/patient-safety]]）：叠着的两个错误——干别的病例中转诊信所干锚定工作的情绪标签（“博关注”）、及团队因患者表达的观点而安静许可降级生理主诉——诊断错误文献“人格归因”类别有记录的失败模式、平等伤害文献发现贫困、族裔与被标记的复杂都预测较少检查的疼痛；职业规则——负迁移是关于会面的数据、绝不是关于心肌的数据：你最不喜欢的患者得到同样的验前概率算术、若反应强烈到值得记录、就强烈到值得声明（“我发现自己在打发这个——我们一起重看”）；第6小时的医学——体位痛与PR压低与摩擦音及本应不论其对加强针的意见在第2小时由本科室胸痛规程自动化的肌钙蛋白配心电图时机；及活得比病例长的修复——“困难患者”措辞从模板退役、代之以构想（产生该表现的恐惧与历史及系统失败、精神科章同款建议的读法）、对被标记患者的复诊及其检查率复审、及对这六小时对本患者的坦承、不带“你早该坚持”的把心包炎变成投诉的语调。**

::: example 无人拥有的消瘦 {#ex-undifferentiated}
70岁六个月瘦9 kg；全科单独的“观察等待”合理、急诊查血与胸片没发现什么、门诊重复血检；每个临床医师的计划可辩护而无人拥有未解决鉴别；第10个月终于成像胰头。
::: solution
**无人拥有的不确定性是路径（[[#def-differential]]、[[#def-bias]]、[[gastrointestinal/pancreas-biliary]]）：推理真相——观察等待是带两项义务的诊断策略：陈述的假说清单与陈述的重看日期；这里发生的是无义务的策略、由患者分布在四位各自局部理性的临床医师产生；基率诚实——65岁以上不明原因消瘦一年内携带数个百分点癌症概率（丹麦与英国基层风险规则研究）、这不是人人扫描的理由、恰是带具名拥有的风险分层路径的理由；审计中起作用的修复——“一医师拥有未分化”规则（全科作默认拥有者配明确复查间隔因为连续性就是检查）、国家与信托消瘦路径（血检与CRP与粪隐血与胸片第一层加胸腹盆CT阈值及“跟轨不数数”复审扳机、及把十个月病例变得不可能而非不太可能的标记系统）；及安全网手艺——“如果……更快回来”具体化（新疼痛、黄疸、食欲改变）、患者带着数字与话语武装（“不明原因消瘦需要一个主人——问你的主人是谁”）、因为诊断延迟文献一致的发现是带着同一担忧复诊的患者是系统最好的传感器、而我们不断以安慰而非重评作答。**

::: exercise 使用阈值模型 {level=2}

::: solution
**说出口的阈值（[[#def-dual]]、[[#def-differential]]、[[clinical-skills/laboratory-tests]]）：几何——检查阈值之下、什么都不做胜过检查（疾病概率低到假阳性与伤害占主导）；两阈值之间、当结果将改变管理时检查；治疗阈值之上、治疗胜过检查、除非治疗带严重代价或伤害；结节的位置——低危患者无危险特征的8 mm结节可正当地坐在穿刺阈值之下（“今天不查是有监测日期的决定”记录）、而25 mm低回声伴突眼家族史的结节坐在做点什么阈值之上、承诺你做细胞学规则与分子邻近的FNA、不是年度超声的骑墙；头痛——6小时CT正常的雷击样病例坐在两阈值之间、决定明确是各指南解决不同的腰穿对CTA对等待小时之辩（这就是推理被记录的原因：你用的阈值是审计痕迹）；及承诺规则——出声越线（“概率在检查阈值之下；安全网如下；变了就复查”）是把概率推理变成可辩护医学的句子、而其预防的失效模式是不可用决定的医学：为安抚某人开的扫描、及因团队说不出口数字而回避的腰穿。**

::: exercise 教重开器 {level=2}
