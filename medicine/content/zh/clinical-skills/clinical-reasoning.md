临床推理是把病史、体格检查和一组检查结果转化为诊断和方案的思维过程。它在不确定的条件下进行，常常有时间压力，而且信息通常不完整。大多数时候它运作良好。当它失败时，原因更多是推理上的缺陷而不是知识的缺乏：临床医生知道正确的诊断，却没有想到它，或者过早地排除了它。

本章介绍临床医生如何产生和检验假设，概率和贝叶斯定理如何支撑每一个检查或治疗的决定，临床预测规则如何起作用，以及认知偏倚如何导致诊断错误。其中的定量概念在[[clinical-skills/laboratory-tests]]和[[epidemiology-ebm/diagnostic-tests]]中进一步展开。

## 作为过程的诊断

::: definition 鉴别诊断与工作诊断 {#def-differential}
**鉴别诊断**是可能解释患者表现的疾病清单，最好按可能性排序，并标出最危险的可能。**工作诊断**是临床医生当前据以采取行动的诊断，它是暂定的，随信息的到来而修正。**最终诊断**是在收集证据之后被接受的诊断；如果病程不符，它本身也可能被修正。
:::

诊断很少是一瞬间的事。它是一个产生假设、收集能区分各假设的信息、再加以更新的循环。患者接受治疗后，这个循环仍在继续：对治疗的反应是证据，治疗无效同样是证据。

### 两种思维模式

心理学家描述了两种思维模式，常称为**系统1**和**系统2**。这一区分由急诊医生Pat Croskerry在医学界推广，有助于理解专长和错误。

::: definition 双过程推理 {#def-dual}
**系统1**（直觉或非分析性）推理快速、自动，基于**模式识别**：临床医生之所以认出某种表现，是因为它与以前见过的病例相似。**系统2**（分析性）推理缓慢、审慎、费力：临床医生逐步解决问题，考虑概率和其他可能。专家两者都用，并在其间切换；系统1高效地处理熟悉的表现，而当模式不符、风险很高或病例不熟悉时，就需要系统2。
:::

模式识别并不是一种较差的推理。经验丰富的临床医生正是靠它隔着房间就认出带状疱疹，而且通常是对的。但当一种表现看起来像常见模式而实际不是时，它就很脆弱：被当作“偏头痛”的蛛网膜下腔出血，被当作“胃炎”的下壁心肌梗死。分析性推理较慢，但能把假设明确化。好的做法是让系统1提出、系统2检验，尤其是在让患者出院或确定诊断之前。

### 产生鉴别诊断

有几种策略有助于列出完整的清单：

- **解剖学**：逐一考虑该区域的结构。对于胸痛：皮肤和肌肉、肋骨、胸膜、肺、心包、心肌、主动脉、食管，以及来自腹部的牵涉痛。
- **病理学（“外科筛子”）**：依次考虑各类疾病：先天性、感染性、炎症性、肿瘤性、血管性、创伤性、代谢和内分泌性、退行性、药物和医源性，以及心理性。
- **生理学**：从机制出发推理。对于低钠血症：相对于钠而言水过多，或钠的丢失超过水；然后判断哪种机制符合。
- **常见、危险和可治疗**：列出最常见的病因、因危险而不可漏诊的病因，以及可治疗的病因。

两条古老的格言方向相反。**奥卡姆剃刀**主张寻找能解释所有发现的单一诊断，这对既往健康的年轻患者很适用。**希卡姆格言**（“患者想得几种病就可以得几种病”）则提醒我们，患有多种疾病的老年人往往对其症状有不止一种解释。

## 概率与贝叶斯定理

每一个诊断决定都建立在概率之上，即使从未明说。“这可能是肌肉骨骼问题”的意思大致是“我认为严重病因的概率很低”。把概率明确化，有助于决定何时检查以及如何解读结果。

::: definition 验前概率与验后概率 {#def-pretest}
**验前概率**是在得知某项检查结果之前，患者患有该病的概率。它来自类似患者中该病的患病率，并根据病史和体格检查加以调整。**验后概率**是得知结果之后的概率。患病的**比值**为$\text{比值} = \dfrac{p}{1-p}$，反之$p = \dfrac{\text{比值}}{1 + \text{比值}}$。
:::

::: theorem 比值形式的贝叶斯定理 {#thm-bayes}
对于似然比为$\text{LR}$的检查结果，

$$
\text{验后比值} = \text{验前比值} \times \text{LR}，
$$

其中阳性结果的$\text{LR}^+ = \dfrac{\text{灵敏度}}{1 - \text{特异度}}$，阴性结果的$\text{LR}^- = \dfrac{1 - \text{灵敏度}}{\text{特异度}}$。如果在给定患病状态的条件下几项发现彼此条件独立，它们的似然比可以依次相乘。
:::

::: proof 比值形式为何成立 {#prf-bayes}
设$D$为疾病，$T$为检查结果。贝叶斯定理给出$P(D \mid T) = \dfrac{P(T \mid D) P(D)}{P(T)}$和$P(\bar D \mid T) = \dfrac{P(T \mid \bar D) P(\bar D)}{P(T)}$。两式相除，消去$P(T)$：

$$
\frac{P(D \mid T)}{P(\bar D \mid T)} = \frac{P(D)}{P(\bar D)} \times \frac{P(T \mid D)}{P(T \mid \bar D)}.
$$

左边是验后比值，右边第一个因子是验前比值，第二个因子是似然比。对阳性结果，$P(T \mid D)$是灵敏度，$P(T \mid \bar D) = 1 - \text{特异度}$；对阴性结果，二者分别是$1 - \text{灵敏度}$和特异度。依次相乘各个比值，假定在已知患病状态时每项发现提供的是独立的信息，而这往往只是近似成立：反映同一过程的两项发现（例如两种炎症标志物）不应重复计算。
:::

由此得出诊断性检查中最重要的观点：**检查结果的意义取决于验前概率**。在极不可能患病的患者中，阳性结果往往是假阳性；在极可能患病的患者中，阴性结果往往是假阴性。

似然比可以让人大致感受到一个结果改变了多少。作为经验法则，LR约为2时概率适度升高，约为5时中度升高，10或以上时大幅升高；LR约为0.5时概率适度降低，约为0.2时中度降低，0.1或以下时大幅降低。LR接近1的结果几乎不改变任何东西，无论这项检查听起来多么了不起。

::: example 两位患者的D-二聚体 {#ex-ddimer}
某静脉血栓栓塞的D-二聚体检测，为便于说明，设其灵敏度为95%，特异度为45%。解读以下两种情况的阴性结果：(a)肺栓塞验前概率为10%的患者；(b)验前概率为60%的患者。

::: solution
$\text{LR}^- = \dfrac{1 - 0.95}{0.45} = \dfrac{0.05}{0.45} = 0.111$。

(a)验前比值$= 0.10/0.90 = 0.111$。验后比值$= 0.111 \times 0.111 = 0.0123$。验后概率$= 0.0123/1.0123 \approx 1.2\%$。这已低到在实践中通常可以认为排除了肺栓塞。

(b)验前比值$= 0.60/0.40 = 1.5$。验后比值$= 1.5 \times 0.111 = 0.167$。验后概率$= 0.167/1.167 \approx 14\%$。对一种危险的疾病来说，七分之一的可能性太高了，不能就此停止。在验前概率高的患者中，D-二聚体不能排除该病，这就是指南让此类患者直接做影像学检查的原因。

检查是同一项检查；结论却相反，因为起点不同。阳性的D-二聚体，$\text{LR}^+ = 0.95/0.55 \approx 1.7$，对两种概率都只会略有改变，因此D-二聚体阳性是做影像学检查的理由，而不是诊断。
:::
:::

### 检查阈值与治疗阈值

只有当检查结果可能改变后续处理时，检查才值得做。Stephen Pauker和Jerome Kassirer于1980年把这一观点形式化。

::: definition 检查阈值与治疗阈值 {#def-threshold}
**治疗阈值**是这样一个患病概率：高于它，临床医生就会不再检查而直接治疗，因为治疗的预期获益超过预期危害。**检查阈值**是这样一个概率：低于它，临床医生既不检查也不治疗，因为该病可能性极低，检查的危害和成本（包括假阳性）超过其获益。在两个阈值之间，检查是值得的。阈值取决于疾病的严重程度、治疗的获益和危害，以及检查的准确性、风险和成本。
:::

对于有安全有效治疗的危险疾病（例如细菌性脑膜炎），治疗阈值很低：临床医生在仍不确定时就给予抗生素。对于治疗有风险的疾病（例如溶栓），阈值较高。如果没有任何合理的结果能使概率越过某个阈值，这项检查就是浪费。

::: example 一位发热、嗜睡的学生的阈值 {#ex-threshold}
Tomás，19岁，大学生，头痛、发热12小时。他嗜睡，颈项强直，双腿有几处压之不褪色的皮疹。临床医生想在开始使用抗生素之前先做腰椎穿刺确诊，而安排腰穿至少需要一小时。用阈值的观点决定该怎么做。

::: solution
细菌性脑膜炎或脑膜炎球菌脓毒症的验前概率很高：发热、头痛、嗜睡、颈项强直和压之不褪色的皮疹放在一起，使它成为首要诊断。该病可在数小时内致死，而治疗（静脉抗生素）有效且相对安全。对于这样的疾病，**治疗阈值很低**，而他的概率远高于它。没有任何腰穿结果能把概率降低到足以支持暂缓治疗的程度，而延误本身就是有害的。因此，应在采集血培养（如果不造成延误）之后**立即**给予抗生素，并遵循当地和国家指南。腰椎穿刺以后仍可能有助于确定病原体，但绝不能延误治疗，而且他的意识水平下降或凝血功能障碍可能使腰穿成为禁忌。

一般的教训是：当疾病危险而治疗安全时，应依据概率行动，而不是等待确定。
:::
:::

## 临床预测规则

**临床预测规则**把病史、体格检查和简单检查中的若干项目组合成一个评分，用以估计某个诊断或结局的概率。经过良好验证的规则比单凭判断的变异性小，并使验前概率明确化。

::: definition 肺栓塞的二级Wells评分 {#def-wells}
NICE指南NG158（2020年）对疑似肺栓塞使用的**二级Wells评分**按下表计分：

| 项目 | 分值 |
|---|---|
| 深静脉血栓形成的临床症状和体征 | 3 |
| 其他诊断的可能性小于肺栓塞 | 3 |
| 心率超过100次/分 | 1.5 |
| 制动3天或以上，或过去4周内做过手术 | 1.5 |
| 既往深静脉血栓形成或肺栓塞 | 1.5 |
| 咯血 | 1 |
| 活动性癌症（6个月内接受过治疗，或处于姑息治疗） | 1 |

评分**大于4分**表示肺栓塞**可能**：NICE建议做CT肺动脉造影（如有延误，先给予临时抗凝）。评分**4分或以下**表示**不太可能**：先检测D-二聚体，只有阳性时才做影像学检查。
:::

其他常用的规则包括：评估社区获得性肺炎严重程度的**CURB-65**（意识混乱（Confusion）、尿素（Urea）高于7 mmol/L、呼吸频率（Respiratory rate）30次/分或以上、低血压（Blood pressure，收缩压低于90 mmHg或舒张压60 mmHg或以下）、年龄65岁或以上）；判断踝部损伤何时需要X线检查的**渥太华踝关节规则**；以及评估心房颤动卒中风险的**CHA₂DS₂-VASc**。一条规则的好坏取决于它在与使用人群相似的人群中的验证情况，而Wells评分中“其他诊断可能性较小”这一项表明，判断仍然是规则的一部分。

::: example 应用Wells评分 {#ex-wells}
Kowalski女士，54岁，膝关节置换术后10天突发胸膜性胸痛和气促。心率108次/分。没有深静脉血栓形成的体征，没有咯血或癌症。胸片清晰，临床医生认为肺栓塞是最可能的诊断。计算她的Wells评分并说明下一步。

::: solution
- 深静脉血栓形成的临床体征：无，0分。
- 其他诊断的可能性小于肺栓塞：是，3分。
- 心率超过100：是，1.5分。
- 过去4周内做过手术：是，1.5分。
- 既往深静脉血栓形成或肺栓塞：无，0分。
- 咯血：无，0分。
- 癌症：无，0分。

总分$= 3 + 1.5 + 1.5 = 6$，大于4，因此肺栓塞**可能**。按照NICE NG158，下一步是CT肺动脉造影；如果不能及时进行且无禁忌，先给予临时抗凝。在这里**不应**用D-二聚体排除肺栓塞：正如[[#ex-ddimer]]所示，阴性的D-二聚体不能把高验前概率降到足够低。而且近期手术后，D-二聚体很可能本来就升高。
:::
:::

## 推理出错的时候

**诊断错误**是指未能及时、准确地解释患者的健康问题，或未能将其告知患者。美国国家科学院的报告《改进医疗中的诊断》（*Improving Diagnosis in Health Care*，2015年）得出结论：大多数人一生中至少会经历一次诊断错误。错误来源于系统因素（结果丢失、交接不良、工作负荷）和认知因素，而且通常两者兼有。

::: definition 常见的认知偏倚 {#def-bias}
**认知偏倚**是判断中可能导致错误的系统性倾向。临床推理中常见的偏倚包括：

- **锚定**：固守第一印象，在新信息出现时未能调整。
- **过早下结论**：在诊断得到充分证实之前就接受它，并停止寻找其他可能。它是诊断错误中最常被发现的认知原因。
- **易得性**：因为某个诊断容易想到（例如最近遇到一个印象深刻的病例），就认为它可能性更大。
- **确认偏倚**：寻找或看重支持所偏好诊断的证据，而轻视反对它的证据。
- **基础概率忽视**：解读某项发现时忽视该病的患病率。
- **诊断惯性**：早期贴上的标签（来自患者、转诊者或同事）在人与人之间传递时越来越被当作确定无疑。
- **满足于搜索**：一发现一个异常（X线片上的一处骨折、贫血的一个原因）就停止寻找，漏掉了第二个。
- **情感偏倚**：让对患者的感受（沮丧、好感、污名）影响判断。患有精神疾病、学习障碍或有药物使用史的人，其躯体症状有被归因于已知疾病的风险，这有时称为**诊断遮蔽**。
- **过度自信**：认为自己的判断比实际更准确。
:::

::: example 频繁就诊的腹痛患者 {#ex-bias}
Barnes先生，46岁，一年中因与饮酒有关的腹痛到急诊科就诊六次。凌晨3点他又来了，满身酒气，上腹痛。前一班的交接写着“已知酒精滥用者，老毛病”。他被给予止痛药后留下睡觉。四小时后他出现低血压、腹部强直。CT显示十二指肠溃疡穿孔。指出其中的认知因素以及可以如何应对。

::: solution
- **诊断惯性**：交接中的标签（“老毛病”）被当作诊断传了下来，没有重新评估。
- **情感偏倚与诊断遮蔽**：这位男性的饮酒和频繁就诊降低了团队的警惕性，也许还降低了他们投入的意愿。带有污名的说法“酒精滥用者”可能起了作用；“一位大量饮酒的男性”描述的是同一事实，却不带评判。
- **锚定与过早下结论**：这次表现被直接对应到以往的就诊，没有检查这次有什么不同。
- **反向的基础概率忽视**：频繁就诊者患严重疾病的比率比一般人群更高，而不是更低；饮酒还会增加消化性溃疡、胰腺炎和其他外科病因的风险。

应对措施：无论以往诊断如何，每次就诊都做完整的体格检查和生命体征测量；明确地问“这次有什么不同？”和“我绝不能漏掉什么？”；在作决定之前查血（包括淀粉酶或脂肪酶）并复测生命体征；在交接中使用中性、不带污名的语言；营造一种团队中任何成员都可以要求重新评估的文化。
:::
:::

### 减少诊断错误

没有哪种技术能消除偏倚，仅仅知道偏倚的存在也不能防止它们。有些策略确有帮助：

- **诊断暂停**：在确定诊断之前停一下，问：还可能是什么？有什么不符合？最坏的可能是什么，我排除了吗？
- **考虑相反的可能**：刻意寻找反对所偏好诊断的证据。
- 针对常见主诉和“不可漏诊”疾病的**核查表**。
- **第二意见**和与同事讨论，包括在同事看到你的结论之前请他重新看一遍。
- **反馈**：随访患者，了解诊断是否正确。从不了解结局的临床医生无法校准自己的判断。
- **系统措施**：可靠的结果追踪、良好的交接和思考的时间（[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]）。
- **让患者参与**：告诉患者工作诊断是什么、接下来会怎样，以及什么情况提示诊断可能有误（安全网）。

::: warning 病历中的诊断是假设，不是事实
他人记录的诊断，包括你自己以前写下的，都可能是错的。当患者没有好转、出现新症状或有不符之处时，要回到原始资料：重新询问病史、重新检查，并亲自查看检查结果。“已知患有X”应促使你问：“X是怎样确诊的？”
:::

::: quiz
某疾病的检查灵敏度为90%，特异度为90%。在患病率为1%的人群中，阳性结果中大约有多大比例是真阳性？
- [ ] 约90%
- [ ] 约50%
- [x] 约8%
- [ ] 约1%
::: solution
1,000人中有10人患病，其中9人检测阳性。990名未患病者中有10%（99人）检测阳性。所以108个阳性结果中有9个是真的：约8%。忽视低患病率、以为“90%准确”就意味着患病概率为90%，就是基础概率忽视。
:::
:::

::: history
**托马斯·贝叶斯（Thomas Bayes）**牧师关于逆概率的论文在他去世后，于1763年由他的朋友**理查德·普赖斯（Richard Price）**发表。**Robert Ledley**和**Lee Lusted**在1959年发表于《科学》的论文《医学诊断的推理基础》（"Reasoning foundations of medical diagnosis"）中提出把它用于医学。20世纪70年代，**Arthur Elstein**及其同事研究了医生实际上是如何推理的，发现他们很早就产生少数几个假设；而**特沃斯基（Amos Tversky）**和**卡尼曼（Daniel Kahneman）**（1974年）描述了不确定条件下判断的启发法和偏倚。**Stephen Pauker**和**Jerome Kassirer**于1980年提出了检查的阈值方法。从21世纪初起，**Pat Croskerry**等人把偏倚心理学应用于急诊医学，而2015年美国国家科学院的报告使诊断错误成为公认的患者安全问题。
:::

## 后续内容

本章的工具在[[clinical-skills/laboratory-tests]]中应用于实验室结果，在[[clinical-skills/medical-imaging]]中应用于影像学。检查准确性的统计学，包括受试者工作特征曲线和诊断准确性研究的设计，见[[epidemiology-ebm/diagnostic-tests]]。导致诊断错误的系统因素见[[clinical-skills/patient-safety]]。

::: summary
- 诊断是产生假设、加以区分并不断更新的循环；工作诊断是暂定的。
- 专家把快速的模式识别（系统1）与审慎的分析（系统2）结合起来，在风险高或模式不符时用分析来检验直觉。
- 从解剖学、病理学或生理学角度产生鉴别诊断，并始终列出危险诊断。
- 验后比值等于验前比值乘以似然比；结果的意义取决于验前概率。
- 只有当结果可能使概率越过检查阈值或治疗阈值时才做检查。
- 二级Wells评分等临床预测规则使验前概率明确化，并决定先做D-二聚体还是影像学检查。
- 过早下结论、锚定、易得性、确认偏倚、诊断惯性和诊断遮蔽是常见的错误原因；诊断暂停、考虑其他可能、反馈、良好的系统和安全网能减少错误。
:::

## 习题

::: exercise 概率与比值 {level=1 check="0.25"}
把20%的概率换算为比值，以小数表示。
::: solution
$\text{比值} = 0.2/(1 - 0.2) = 0.2/0.8 = 0.25$，也写作1比4。
:::
:::

::: exercise 由四格表求似然比 {level=1 check="8"}
某检查灵敏度为80%，特异度为90%。计算其阳性似然比。
::: solution
$\text{LR}^+ = 0.80/(1 - 0.90) = 0.80/0.10 = 8$。其阴性似然比为$0.20/0.90 \approx 0.22$。
:::
:::

::: exercise 产生鉴别诊断 {level=1}
用外科筛子列出一位80岁女性急性意识混乱的至少六个病因。
::: solution
感染性：尿路感染、肺炎、脑膜炎或脑炎（较少见）。代谢性：低钠血症、高钙血症、低血糖、尿毒症、低氧血症或高碳酸血症。血管性：卒中、硬膜下血肿（尤其是跌倒后或使用抗凝药者）。药物性：阿片类、抗胆碱能药物、苯二氮䓬类、酒精或苯二氮䓬类戒断。肿瘤性：脑转移、恶性肿瘤相关高钙血症。其他：尿潴留、便秘、疼痛、脱水、癫痫发作后状态。许多患者不止一个诱因（希卡姆格言）。
:::
:::

::: exercise 验后概率 {level=2 check="round(100*(0.3/0.7*8)/(1+0.3/0.7*8))"}
一位患者某疾病的验前概率为30%。一项阳性似然比为8的检查结果为阳性。验后概率是多少？以百分数表示，四舍五入到整数。
::: solution
验前比值$= 0.3/0.7 = 0.4286$。验后比值$= 0.4286 \times 8 = 3.429$。验后概率$= 3.429/4.429 = 0.774$，即**77%**。
:::
:::

::: exercise 一个Wells评分 {level=2 check="4.5"}
一位38岁男性有胸膜性胸痛，左小腿肿胀、压痛，伴凹陷性水肿。心率104次/分。他没有其他危险因素，临床医生认为其他诊断至少与肺栓塞同样可能。计算他的二级Wells评分并说明其意义。
::: solution
深静脉血栓形成的临床体征：3分。其他诊断的可能性小于肺栓塞：否，0分。心率超过100：1.5分。制动或手术：0分。既往静脉血栓栓塞：0分。咯血：0分。癌症：0分。总分$= 3 + 1.5 = 4.5$。大于4，所以肺栓塞**可能**：按NICE NG158，下一步是CT肺动脉造影（如有延误，先给予临时抗凝），而不是D-二聚体。某一项的微小变化（心率98而不是104）就会把他归入“不太可能”组，这提醒我们评分是对连续性判断的简化。
:::
:::

::: exercise 序贯检查 {level=2 check="round(1000*(0.05/0.95*6*4)/(1+0.05/0.95*6*4))/1000"}
一位患者某疾病的验前概率为5%。两项相互独立的发现都存在，阳性似然比分别为6和4。验后概率是多少？以比例表示，四舍五入到三位小数。
::: solution
验前比值$= 0.05/0.95 = 0.05263$。验后比值$= 0.05263 \times 6 \times 4 = 1.263$。验后概率$= 1.263/2.263 = 0.558$。只有当两项发现条件独立时，似然比相乘才成立；如果二者反映同一个潜在过程，这样计算会高估概率。
:::
:::

::: exercise 该不该检查？ {level=3}
一位25岁、无危险因素的女性，搬家后右侧胸壁痛两天。按压一处肋软骨能完全重现疼痛。她的生命体征正常，临床医生估计她患肺栓塞的概率约为1%。一位同事建议“为了保险”查一个D-二聚体。讨论这是否是个好主意。
::: solution
她的验前概率很可能低于检查阈值。D-二聚体特异度低，所以未患肺栓塞的人中阳性很常见（为便于说明，若特异度为45%，则一半以上未患肺栓塞的人检测阳性）。阳性结果只会使概率略有升高（LR⁺约1.7，从约1%升至不到2%），却会导致CT肺动脉造影，带来辐射、对比剂、费用和意外发现的可能。阴性结果对本已很低的概率也几乎没有增益。PERC规则等临床决策工具正是为这种情况设计的：在低风险且符合全部标准的患者中，不建议做任何检查。更好的方案是清楚的解释和具体的安全网（突发气促、咯血、腿肿）。如果一项检查最可能的结局是因进一步检查而受害，它就不是“保险”的。
:::
:::

::: exercise 一次诊断暂停 {level=3}
一位67岁男性以“社区获得性肺炎”入院，接受抗生素治疗。第4天他仍气促、发热，胸片显示右下肺野阴影没有变化。进行一次诊断暂停：列出你要问的问题和要考虑的其他诊断。
::: solution
问题：最初的诊断是否有充分依据（病史、体格检查、影像学、炎症标志物）？有什么不符合？患者是否在服用并吸收抗生素，病原体是否可能被覆盖？有没有发生新的情况？其他诊断和并发症：肺炎旁胸腔积液或**脓胸**（检查有无浊音，做超声）；**肺脓肿**；**阻塞性肿瘤**导致的阻塞后肺炎（吸烟史、体重下降、咯血；考虑CT）；伴肺梗死的**肺栓塞**；**结核病**；误吸；非典型或耐药病原体；机化性肺炎、血管炎或心力衰竭等非感染性病因；以及新的医院获得性感染或药物热。诊断暂停把“抗生素治疗无效”从更换抗生素的理由，变成了质疑诊断的理由。
:::
:::
