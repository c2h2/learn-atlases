临床记录是患者的记忆、团队的协调系统及案件的未来辩护——融为一个物件；而证据显示它在每个转换处失效：没人读的出院小结、丢掉应急计划交接、把昨天的查体复制进今天病历的模板、及给错误名字开医嘱的错误患者合并。**本章讲述记录本身（良好病历记录的法律与职业标准——同步、可归属、清晰、带审计痕迹地纠正——及电子记录的特殊病理：复制粘贴医学、克隆病历、结构化对叙事的取舍、及塑造所写内容的警报与模板环境）、作为信息事件的转换（交接、转科、带药物重整的出院小结、转诊及其问题、及生命尽头的死亡证明）、及信息治理层（保密的实操规则、治疗用途对治疗邻近用途的共享、错误患者登记与停摆规程等信息学安全隐患、及患者日益增长的阅读权）。**

## 记录

::: definition 标准、电子病理与审计痕迹 {#def-record}
**职业底线：监管机构的病历职责——同步、下一位读者能读、签署、注明日期、可归属、符合事实而观点标为观点、患者自己的话在其要紧处、纠正以添加附理由进行而绝不擦除、及使病历成为诊室证人席的“没写就是没做”法理；记录在数年后被验尸官与原告律师阅读、他们寻找缺失安全网的技能超过书写者记住计划为何正确的技能。电子记录改变了媒介而非职责、并添加了信息学安全文献如今编目的失效模式：复制粘贴与克隆病历问题（查体向前复制数日——记录的发现从未重做、正常病历被克隆进恶化的患者、及病历重复率达多数的机构研究）；模板对叙事取舍（结构化数据使登记与决策支持成为可能、并可靠地生产模板说了临床医师未想的产物——住院医师从未读过的自动填充计划）；埋没新发现的病历膨胀与向前复制级联；归属衰减（谁查体、谁建议、谁只在名单上看到患者）；及纠正审计痕迹伦理——带日期与理由的附录、因为静默覆盖同时毁灭法律与学习记录、而系统自身的版本控制使删除反正可见。记录质量可测量可培训：病历审计工具（病史、查体、计划、同意、能力与安全网部分的存在与质量标准）、“这份病历能否挺过验尸官”教学、动词纪律（“我09:00查体”对被动的隐藏谁在何时做了什么）、及记录推理运动（记录鉴别及其排除——临床推理章的交付物）。记录的第二读者是数据层：登记、审计、研究抽取与质量指标都靠输入何处于何处、这就是为何结构化字段纪律——维护的问题清单、带日期去标签的过敏、活在可计算字段而非信件散文里的升级计划——是键盘上的公共卫生工作；及为何“记录在两处”问题（纸质天花板表对电子旗标对护理记录对等待国家基础设施的救护车方案）仍是若干卫生系统未完成的安全项目之一。**
:::

## 转换

::: definition 交接、转科、出院与转诊 {#def-transitions}
**交接是运动中的记录：沟通章的工具适用、而病历的加项是所说的必须与所归档的一致、因为两者之间的漂移就是责任藏身之处。科室与医院之间的转科是有法律分量的交接：医院间最小数据集（标识、时间史、当前观察、已给药、可得结果、升级天花板、家属联系、及谁来接）——撤回医学研究发现多数纸质转诊有所遗漏；对同级接收临床医师的口头交接；“影像随患者走或报告随患者走”规则；及网络方案——共享记录、转运护照、电子用药清单。出院小结是被研究最多也最可修复的失效：患者离开前写就、致全科、含研究要求的四项内容（做了什么发现什么；什么仍未解决及其所有者与日期；带理由与监测计划的用药变化；带大白话红旗的安全网）；作为药师级实际用药审查的药物重整（患者自己的药片装在门口袋里就是证据）；供回家头几天用的药；预约而非建议随访；开放记录文化下给患者的一份；及契约的社区侧——全科信件分诊及再入院文献命名的“有人为待定的结果打过电话吗”环。给夜间出院的诚实附录：小结必须在患者首次全科门诊之前到达、这是目标文化仍未达到的最低。转诊是微型出院：陈述的问题、附上的数据、以红旗突出的紧急度理由、设定的答复环期望、及“转给谁、在此之前谁拥有结果”被记录——因为孤立的转诊是孤立偶然发现的门诊等价物。死亡证明保持记录最后的职责：按知识而非委婉语写的死因链、2010-2020年代改革建立的验尸官与法医路径、火化表格的二检功能、及证明必须能从记录获得支持的纪律——因为它同时是家庭一生的文件与决定下一代预防政策质量的流行病学仪器。**
:::

## 治理

::: definition 保密、数据共享与信息学安全 {#def-governance}
**保密的实操语法（伦理课拥有原则；本章拥有设置）：Caldicott与数据保护工作规则——团队内需要知道对直接治疗是默认的（大查房不为每次讨论寻求同意）、而治疗之外的一切（雇主、保险、学校、媒体、研究）需要明确同意或定义的法定路径；保密职责在死后存续；公共利益与法定职责例外（保障、严重犯罪、法定报告疾病、交通与枪械邻近披露）可未经同意使用、但期望就共享了什么对患者诚实；家属请求问题（打病房电话的配偶、无授权书的成年子女）以能力、最佳利益与适度共享回答——不靠声音识别；及社交媒体最低（在你手机里可被识别的患者就是一次违规）用例子而非传单教。作为安全的信息公开治理：身份层（错误患者记录、合并与影子病历隐患、每次医嘱、标本、操作与转科的双标识纪律、及“结果发给了另一个John Smith”事件类别）；访问控制与审计（终结职业生涯并保护信任的访问日志、无通用登录规则、远程访问卫生）；警报与打断层（警报疲劳对危急值——用药安全的平衡——及网络攻击审查使成为韧性要求的停摆表格与恢复后重整）；及使公众同意保持活力的二次使用诚实（近期记录共享之争教会每位临床医师解释的治疗对商业边界、及数据最小化：抽取需要带治理审批的最小字段、不是因为某人可能想要就把整个病房的日志拿走）。患者访问时代完成闭环：结果在临床医师打电话前进入应用、记录对患者可见、纠正与评论权、及丧亲访问——早期采用者的诚实发现是患者阅读所写、理解的比临床医师害怕的更多、而当所有人都知道记录将被阅读时病历会改善。这就是本章以政策形式开的唯一药方：把每一份病历写成它如今在法律上就是的患者可读文件。**
:::

::: example 克隆病历与安静腹部 {#ex-clone}
ICU通气住院第6天：每份日常病历都含同一段查体、自第1天向前复制。第6天腹部检查——终于异常、伴新的乳酸升高——被记录在同一模板的“软、无压痛”行；第40小时开腹发现缺血肠。家属问为何没人早点写下来。
::: solution
**系统讲的记录谎言（[[#def-record]]、[[clinical-skills/patient-safety]]、[[gastrointestinal/pancreas-biliary]]）：机制——向前复制把记录从证据变成戏剧：克隆的段落让从未发生的检查每天可读、而新病理呈现进一份其结构说它已被排除的病历。验尸官会要的诚实回答：检查是否曾执行（克隆说不清——这正是要点）、谁读了自己没写的病历（大查房的口头文化）、及记录政策允许什么（供应商作为安全特性出售的带重确认复选框的向前复制设置）。三层修复：个体——同步动词病历（“我09:00查体；腹部膨隆伴新的全身压痛；乳酸6.2；09:14请求外科会诊”）；团队——问“变了什么、你发现什么”而非“昨天我们决定了什么”的查房标准；及系统——加入病历质量指标的克隆检测报告、因为复制粘贴率是记录文化的生命体征。及披露：当天的检查是真实而晚的；记录让早几天显得比实际记录得更好；两个失败都是组织的、而政策变更是家属有权听到被命名的。**
:::
:::

::: example 晚于患者到达的出院信 {#ex-discharge}
78岁在激素高血糖后于23:00带新胰岛素出院；小结在第3天生成、第8天到达全科、社区药师在第2天看到新笔并打电话给病房；患者从周二起服了双倍剂量、因为门诊卡凭记忆写。
::: solution
**出院是过程不是门（[[#def-transitions]]、[[clinical-skills/patient-safety]]、[[endocrine/diabetes]]）：失败链——无“药在手、计划在纸”规则的夜间出院（当天变化靠人类记忆传递）、因记录时间不在排班表而迟写的小结（伪装成的人员配置发现）、及社区唯一传感器药师不是任何人的正式收件人。医学上：双倍胰岛素伴低血糖风险对激素减量轨迹（随着激素停用胰岛素需求会下降——监测计划、减量说明与胰高血糖素教学应以患者自己的笔迹而非病房的回忆存在）、因剂量变了两次而即刻全科电话、及防止“临时胰岛素”变成误解的糖尿病团队转诊。防止重演的标准：当日药物重整伴社区通知、四项内容的信在48小时内到达全科否则系统追、离开前预约随访、及任何夜间出院都要有理由加额外计划。重读一遍：23:00由疲惫住院医写进四十份队列的信是系统属性——带夜间覆盖的出院协调与“没人能不带新药卡离开”政策的成本低于这次再入院。**
:::

## 通向何处

同意与保密及法律在[[medical-ethics-law/confidentiality]]与[[medical-ethics-law/consent-capacity]]、升级与天花板计划及用药安全在[[clinical-skills/patient-safety]]与[[pharmacology/adverse-reactions]]、死亡证明与临终文件在[[geriatrics-palliative/end-of-life-care]]、转诊与等待名单在[[public-health/health-systems-economics]]、及交接的口头工具在[[clinical-skills/communication]]。

::: history
**临床记录历史是患者的第二身体——纸质身体——的故事。职业职责随十九世纪的精神错乱法案与医院病历传统出现（志愿医院的病例簿与法务分量先于临床分量的收容所日志）；二十世纪使其成为法定对象——持有与提供记录的义务、保密判例法、及自1990年代（总医学会《良好行医》谱系）规定病历须同步、清晰、注明日期、可归属的职业守则。电子化转向始于1970-80年代的实验室与医嘱系统、然后是宏大的无纸病房规划：全科计算机合同、国家电子记录规划、及2009年美国HITECH时代以点击数记录文档的有意义使用指标。电子病历之后跟来一门新科学——医源性文档文献：向前复制与克隆病历研究、病历膨胀分析、及到2010年代测出键盘多于床旁的时间动作研究（使“睡衣时间”成为政策词）、而机构报告与信息学安全论文建立了自己的危害分类学：错误患者事件、警报疲劳、停摆失效、及作为其寓言的臭名昭著的输液泵编程错误。互操作是系统未完成的句子——HL7与FHIR标准工作、概要医疗记录与跨境指令、及重大医疗质量调查中反复出现的事后发现：信息存在于某处而不在这里。患者访问革命重定义了书写者：2010起的OpenNotes研究（患者读病历、理解更多、更安全——而记录改善）、2010-2020年代的应用与法定访问权、先给患者写信后给医院写信的性与生殖健康及肿瘤门诊公开信文化、及丧亲访问法。交接与出院证据基础一同成熟：I-PASS与SBAR试验、“交接是信息死亡之地”安全研究、2000-2010年代显示错误率减半的重整试验、及如今嵌入认证制度的出院小结内容标准与48小时规则。它最新的前沿是人工智能书写者：早期试验显示真实的时间节省与新型风险——幻觉计划与说得通的粘贴——带着复制粘贴时代以更大字号提出的同一问题到来：记录是关于发生了什么的承诺、而没有技术改变承诺属于谁。** — [[clinical-skills/patient-safety]]、[[clinical-skills/communication]]、[[medical-ethics-law/confidentiality]]。**
:::

::: summary
- 记录是证据、协调与记忆：同步、可归属、清晰、带审计痕迹地纠正——而如今也是患者可读与数据可复用的、这抬高而非降低书写标准。
- 电子记录添加特殊病理——克隆病历、模板书写的计划、向前复制埋没新发现、警报与收件箱过载——其对策是配置与审计、即患者安全、不是信息科。
- 每次转换需要一个命名的载荷：交接与病历相符；转科携带最小时据集伴高年资对高年资口头交接；转诊陈述一个问题；出院意味着当日药物重整、48小时内四项内容的信、预约的随访与患者自持副本。
- 保密基于设置：直接治疗默认、之外需同意或法定、带公共利益例外、审计日志的访问、及以例子教的社交媒体规则。
- 信息学安全是临床安全：双标识纪律、合并与错误患者审计、每半年停摆演练与恢复后重整。
- 死亡证明与收尾职责是临床行动、其质量是死因统计所依赖的；结果在具名临床医师读过、处理过或明确卸责之前不算归档。
:::

## 练习

::: exercise 写模范病历 {level=1}
把“62女性腹痛、血检尚可、大概胃肠炎、日常活动可”转成记录标准病房病历、并命名原文的缺陷。
::: solution
**验尸官会称赞的病历（[[#def-record]]）：重写——“我11:20访视B女士，绞榨性中央腹痛14小时伴两次呕吐胆汁；11:25查体——腹软、膨隆、中央压痛、无防御无反跳、站位查体无疝；血检CRP 140、乳酸2.4、白细胞18、脂肪酶正常、立位胸片正常；计划：液体、按表镇痛、鉴于乳酸与既往疝修补11:40请求外科会诊、16:00重查、已给红旗建议并被理解。”原文缺陷：无时间、无作者、无叙事（性质、时程、呕吐物）；主诉腹部却无查体——也没有疝状态、经典的漏掉病因；掩盖乳酸与白细胞的“血检尚可”；及“日常活动可”——一个用缩写代替重看时间与升级路径的计划。这里缺失的句子正是凌晨2点医师与律师会找的。**
:::

::: exercise 运行药物重整 {level=2}
服14种药的83岁养老机构居民跌倒后入院；“给药表”是一份复印件而机构添加“有时”用的药；计划第4天出院。在两端运行重整并命名陷阱。
::: solution
**作为临床审查的重整（[[#def-transitions]]、[[geriatrics-palliative/polypharmacy]]、[[clinical-skills/patient-safety]]）：入院——对真实药盒的药师级访谈（复印件的复印件是一个假说）、量化的“有时”清单（促成跌倒的按需镇静药与催眠药及抗胆碱膀胱药）、对照全科系统与给药记录的双标识核查、及带来源的“她实际服用什么”记录清单。院内的——每次查房“这一行还需要存在吗”审查及新症状查药习惯（跌倒自身的降压与镇静负担）。出院——离开前带停药谈话的重整（从未停的质子泵抑制剂与双膦酸盐年份及胺碘酮监测）、带回家药供给、到达发药人的机构指示（停用与起始同样明确）、及全科信件中带“为何与观察什么”列的已变更表。陷阱：未服用被记为服用；按需药隐形；门诊起始的药不在共享清单上；及因没人知道医院停过而静默推翻医院停药的全科重复。**
:::

::: exercise 处理访问请求 {level=2}
一男子打病房电话要妻子的出院小结，因为“她对付不了信”；她患痴呆且从未签署任何东西、两人“非常恩爱的老夫妻”。应用框架并写出回答脚本。
::: solution
**厨房里的保密（[[#def-governance]]、[[medical-ethics-law/confidentiality]]、[[geriatrics-palliative/delirium-dementia-care]]）：框架——婚姻不是同意、但正确输出不是摔门。先能力：她能否在支持下决定现在共享此事（“对付不了信”的问题关于格式、不是资格）？若她缺乏能力：最佳利益、寻求其过去与现在的意愿（“她总说什么都告诉Tom”——家属与旧病历可能承载它）、然后适度共享（Tom今晚管理她的照护需要什么对包括她瞒着他的部分的整份记录）、及带理由的记录决定。脚本：感谢他、中立地陈述职责（“记录是她的；我的工作是在其中帮助你们俩”）、提供支持路径——她能同意的共同门诊、大字或音频版本、经她同意提供给他的照护者培训——若共享符合她的利益、清楚说明将共享什么、与谁、为何。系统修复：痴呆诊断时的预先信息共享协议（记忆服务的标准实践）、默认纳入同意谈话的照护者、及给注册医师这二十分钟而不是付出信任与投诉代价的走廊“不行”的排班。**
:::

::: exercise 领导记录质量规划 {level=3}
贵信托：内科病房克隆病历率38%；48小时出院小结55%；本季度放射两次错误患者近失误；停摆表格上次演练在疫情前；初级调查中“文档占我半个班”。写出规划。
::: solution
**记录规划（[[#def-record]]、[[#def-transitions]]、[[#def-governance]]、[[clinical-skills/patient-safety]]）：把每一项当作设计或人员事实——克隆率是配置加文化；迟信是未排班的文档时间；近失误是身份流程事实；初级的“半个班”是系统最响的质量信号。流程：反克隆规划（未经重确认拒绝向前复制的字段、给病房主管的每月克隆检测报告、建立在真实克隆上的病例复习教学）；出院时间重设计（把协调员容量计为临床人员配置、夜间双人覆盖、离开前四项内容核查表、被追赶而非被盼望的48小时信）；身份安全（在登记、同意与操作的双标识审计、内部发布的近失误叙事——“错误John Smith”故事是可得的保持率最高的培训）、及重复合并的具名所有者与解决时钟；停摆韧性（每年两次带药房与血库及影像恢复重整运行单的停摆包演练、及供应商合同测试证据）；及时间问题、因为没有它其他一切都会失败（编制中的文档时间与按记录质量及节省时间评估的书写助手试点、及疲劳文献直接联系到安全的收件箱与警报负担审查）。治理：一位高管所有者、由护理与药房及信息及培训生参与的临床主导记录安全委员会、及董事会仪表板——克隆率、48小时信、错误患者近失误与关闭、停摆测试报告、培训生文档时间——锚定两个结局：出院药物重整率与触发工具病历质量分。记录是所有其他安全规划证据居住之地；一家不能安全书写其患者的信托尚未学会保障其安全。**
:::

::: example 发给另一个John Smith的结果 {#ex-identity}
门诊采血用前一位患者的腕带标记一组血脂标本——两人都是男性、都是六十多岁、都姓Smith。结果进入一位已在服他汀的活跃记录、其“控制欠佳”推动一次剂量升级与造影讨论。
::: solution
**身份是一项临床操作（[[#def-governance]]、[[clinical-skills/patient-safety]]）：机制——错误患者链：在两个要紧时刻（采集与结果归档）的双标识失效、同名同龄背景、及“他说他是Smith先生”就是全部核查的门诊文化。本该拦住它的层：护理点条码伴患者口述标识与出生日期（输血医学“单靠名字从来不是标识”规则的延伸）；结果入活跃记录的不合理审查（与剂量矛盾的LDL是药师可见的旗标）；及应按算法而非靠运气找到“两个John Smith”的重复合并检测扫描。后果是带所有者链的伤害：基于假数字的升级与侵入性检查是一个诊断伤害案例、按此披露（取消的造影与残留焦虑是伤害的边缘、而纠正带着附录规则要求的审计痕迹到达两人记录）。规划答案：报告并教授近失误（“差点是我”效应是文化最好的疫苗）、带本地审计实施的国家患者标识安全警报、及重复到乏味的标准——每个医嘱、标本、操作与转科、两个标识、只要患者能就由其口述。**
:::

::: example 无主的门诊结果 {#ex-orphan}
两周等待结肠镜在内镜报告“正常”、而非特异胃活检的组织学19天后返回示高级别上皮内病变。信件寄给“转诊临床医师”——早已轮换走的注册医师；全科从未看到。第9个月首发症状复发。
::: solution
**结果有角色不是地址（[[#def-transitions]]、[[#def-record]]、[[gastrointestinal/gi-bleeding-cancer]]）：解剖——结果被路由给人而不是角色；“操作正常”标签在所有人心智里关闭了案件而组织学走一条独立的邮政路线；及每份实验室政策都说必须电话通知具名负责临床医师并复述的严重意外发现路径未触发、因为上皮内病变藏在听来良性的申请里。规则：结果所有权是一个带收件箱与审计痕迹的角色（具名报告专科医师或本周顾问、绝不是“注册医师”）；24小时规则对组织学像对放射一样触发；作为开放记录默认，全科在二级结果中被抄送（只在门户的结果与“待续”信是孤儿的栖息地）；及在离开前被告知他们将如何得知及得知后做什么的患者。重入：第9个月的病例是坦承与复审病例——延迟归因几乎全部落在系统栏；现在再分期与治疗；及给新内镜信息系统的政策旗标：组织学进入同一报告行、带谁读什么及谁打电话给谁的规范。元课：在具名临床医师读过、处理过或明确卸责之前结果不算归档——而患者知情。还没有哪个收件箱能自动化这句话。**
:::

::: exercise 设计停摆包 {level=1}
贵信托下月将模拟两天全面临床系统中断。规定病房停摆包的内容及使模拟有意义的三个演练角色。
::: solution
**纸面就绪（[[#def-governance]]、[[clinical-skills/patient-safety]]）：包——按定义频率为当前住院患者打印的当前给药表（或“最后核实表”规程）、观察与液体平衡表、带实验室标识规则及其纸质接收流程的采血管与申请单、配血与交叉合血表格、带影像科人工日志的放射申请单、管制药物登记（可清点的那本）、分诊与床位板模板、升级联系人与院外总机、停摆SOP单页（谁宣布、谁记录、什么要人工回补——同意、过敏核查、“无电子过敏旗意味着问患者”规则）、及恢复后重整单（每次给药、每个结果、每次出入院双人核查录入并签名完成）。三个演练角色：端到端跑纸质入院的病房间管理员、对照打印表与实验室纸质结果重整的药师、及执行恢复并审计遗漏的信息主管——因为各卫生系统的攻击后复审重复同一发现：冗余存在、熟练不存在；而模拟的及格线不是“我们撑住了”而是“纸质日产生了多少医嘱与身份错误”、要测量、因为那个数字就是信托真实的停摆死亡率估计。**
:::

::: exercise 签署死亡证明 {level=2}
82岁在股骨骨折修复出院4天后死于家中；社区全科正在吃晚饭；社区护士发现她。她前一天换过敷料。写出决定链：认证路径、决定它的问题、及各答案强制什么。
::: solution
**认证三问（[[#def-transitions]]、[[geriatrics-palliative/end-of-life-care]]）：第一个问题属于法医不属于你——死亡迅速、无人陪伴、而近期住院与跌倒史提出验尸官会想问的手术链与静脉血栓及跌倒后遗之问：多数辖区中出院或治疗后死因不明的死亡走法医路径、而转介保护每个人包括家属的答案；决定之问——她最近被看过到足以凭个人知识认证死因吗（四天与门诊规则）、死因是否真的已知（“股骨骨折”不是死因；链条——跌倒机制、固定、并发症——必须能从你可能不持有的记录辩护）、及是否有任何使转介成为强制的怀疑（压疮、药物、“她一直在衰弱”的模棱）；无论如何都要做的家属工作——死亡证明上的时间不如它之前的谈话要紧（“我需要确定是什么杀了她才签字”解释、法医流程导航、火化表格二检及相关的器官捐献与尸检谈话、及“我将做些什么去查明”计划）；及记录职责——将成为法医最好文件的出院小结、全科的医院信件审查、及认证是临床行动的诚实：统计与调查及家属的文书都从这五分钟开始、给它应得的时间。**
:::

::: exercise 写公开信 {level=2}
34岁的阴道镜门诊结果需要一封信：宫颈细胞学史正常、异常活检已治、及“监测两年”计划。写给她的信、给全科的副本、及旧文化会隐藏的两个句子。
::: solution
**公开信手艺（[[#def-governance]]、[[#def-record]]、[[obstetrics-gynaecology/gynaecological-cancer]]）：给她的——先大白话（“活检显示细胞不正常但不是癌；我们完整切除了而边缘干净”）、以列表给计划（下次检查何时、谁发预约、如果没收到怎么办、要报告什么症状——出血与分泌物那句用来提醒而不是吓唬）、诚实而适度地命名不确定性（“它复发的机会低；检查就是我们保持其低的办法”）、及“你可以直接打门诊电话谈信引起的任何事——包括如果信本身让人担忧”；给全科的——同样的话加临床数据（组织学与边缘及监测间隔理由）、因为给患者和医师读起来不同的信滋生“他们没告诉我什么”的门诊；旧文化转而生产的两个被隐藏句——含糊的“可能存在一些异常细胞”（患者读作“也许是癌”而医师为回避确定性写下——公开信研究重复最多的发现是具体性降低焦虑）、及代之以“您的下次检查六个月后、已为您预约”的“有症状请再来”委婉语；及政策线：如果她读来会糟糕、谈话需要房间里更好的话、不是纸上更坏的话。**
:::

::: exercise 审计信息流 {level=3}
贵地区数据：22%养老机构居民的患者院内用药变更从未到达机构表；紧急门诊结果电话30%到达“某位工作人员”而无名字；救护车转运表的天花板计划字段60%的适格入院为空；医院间影像光盘每周丢失。绘制流程、分配所有者、设定六个月指标。
::: solution
**信息流工程（[[#def-transitions]]、[[#def-governance]]、[[clinical-skills/patient-safety]]）：地图——每个缺口都是一次没有契约的转换：机构到医院再到机构（其用药变更死在出院信与给药记录之间的居民）、结果到患者链（打了“诊所”电话而无复述或具名接收者的勾）、天花板计划字段（从入院到救护车无临床医师拥有的表格）、及影像（数字时代的物理物件）。所有者与修复——1)养老机构路径：带强制“机构表已更新是否”的结构化电子出院重整、及资助信息学修复的用药错误邻近再入院数据审计；2)结果电话：“具名临床医师、复述、时间记录”标准伴24小时与7天规则通过角色收件箱而非排班者升级、及严重结果的“患者听到了吗”第二环；3)天花板计划：存在时从入院升级计划自动填充的字段、授权并期望救护人员质询空白（交接时的“我们不做些什么”之问）、及给入院顾问的每月完整度报告；4)影像：被告知可防止重复扫描与辐射时国家规划资助的网络影像交换（读取与调阅服务）、及过渡期“影像随患者走或报告随患者走”SOP。六个月指标——机构表更新率、记录复述的结果电话、天花板字段完成度、重复影像率与影像丢失事件数；加一个患者侧指标（养老机构调查中“出院时你是否得到明确计划”条目）、因为流程是为某人存在的；及报告线——带护理与药房及基层和养老机构及救护车席位的区域转换委员会、因为整个审计发现就是一家组织的数据是下一家组织的伤害。**
