现代医疗由每隔几小时就轮换的团队提供。一位住院患者一周内可能被几十名专业人员诊治，其中许多人彼此从未见过面。把他们联系起来的是信息：书面的病历和口头的交接。信息清楚时，医疗就能在班次和场所之间安全地延续。信息不完整、含糊或丢失时，检查被遗漏，药物被重复给予或根本没有给，病情恶化也无人察觉。

本章介绍良好的病历书写、以问题为导向的病历和结构化记录、药物重整、保密、使用结构化工具的交接与上报、出院沟通，以及使信息顺畅流动的团队协作技能。本章建立在[[clinical-skills/communication]]和[[clinical-skills/history-taking]]之上，并引出[[clinical-skills/patient-safety]]。

## 临床病历

临床病历同时承担多种用途：

- **医疗的连续性**：告诉下一位临床医生已经发现了什么、决定了什么、做了什么。
- **沟通**：在不同职业、不同团队、初级与二级医疗之间，以及与有权查看病历的患者之间。
- **安全**：处方、过敏、上报决定和检查结果都记在病历中。
- **问责与法律**：它是发生了什么的证据，用于投诉、调查和法庭。
- **审计、研究和规划**：经过编码的病历产生用于改进服务的数据。

::: definition 良好病历书写的原则 {#def-records}
良好的临床病历应当：

- **及时**：在当时或之后尽快书写，注明事件的**日期和时间**，若与书写时间不同，也注明书写时间。
- **可追溯**：注明作者的姓名、职务、签名（或电子登录），医生还要注明英国医学总会（GMC）注册号；注明负责的上级临床医生的姓名。
- **清楚易读**：能被其他专业人员理解，而且越来越多地也要能被患者理解；避免含义不明确的缩写。
- **准确、基于事实**：记录观察到的、说过的和做过的事，区分发现与意见，并包括相关的阴性表现。
- **完整**：记录评估、所作的决定及其理由、向患者提供的信息和患者同意的内容、方案，以及每项行动由谁负责。
- **不被改动**：更正时用单线划去错误内容（使其仍然可辨认），并注明日期、时间和签名，电子病历中则以补充记录的方式更正；绝不删除或覆盖已有记录。
:::

GMC的《良好医疗实践》（*Good Medical Practice*，2024年）要求医生保持清楚、准确、易读的病历，并在当时或之后尽快书写；其他专业监管机构也规定了同等的标准。把患者当作读者来写是一种良好的自律：既然患者可以查阅自己的病历，就应避免带有评判或污名的用语（“拒绝”“不依从”“酒鬼”），而是描述行为和事实（“在我们讨论了理由之后，患者不同意抽血”“每周饮酒约40个单位”）。

::: warning 电子病历中的复制沿用和模板
电子病历使复制前一天的记录或调用模板变得很容易。这节省了时间，却会传递错误：从未重新检查的体格检查发现、已经完成的计划、记录有误的过敏。记录变得冗长，重要的变化被淹没。写下你今天发现的情况，删除不再属实的内容，签名前核对预填的内容。记录写着检查过腹部而实际没有检查，就是虚假记录。
:::

### 以问题为导向的病历

1968年，美国医生**劳伦斯·韦德（Lawrence Weed）**提出，病历应围绕患者的**问题**来组织，而不是按来源（医生记录、护士记录、检查结果）组织。这一理念，即**以问题为导向的医疗记录**，至今仍影响着临床记录的形式。

::: definition 问题清单与SOAP记录 {#def-soap}
**问题清单**是对患者当前问题和重要既往问题的编号清单，每个问题按已有的确定程度表述（“气促，原因未明”，而不是过早给出诊断），并随问题的解决或明确而更新。然后针对每个问题按**SOAP**格式书写病程记录：

- **S**ubjective（主观资料）：患者所述（症状、担忧）。
- **O**bjective（客观资料）：观察和测量所得（生命体征、体格检查、检查结果）。
- **A**ssessment（评估）：临床医生的解读，包括工作诊断、鉴别诊断，以及问题在好转还是加重。
- **P**lan（计划）：检查、治疗、监测、向患者提供的信息和上报决定，并注明由谁负责。
:::

::: example 一份SOAP查房记录 {#ex-soap}
Holloway女士，74岁，两天前因社区获得性肺炎入院，正在使用静脉抗生素。她还有心力衰竭和2型糖尿病。写出今天以问题为基础的查房记录。

::: solution
**2026/10/27 09:40。查房，A. Mensah医生（ST4）与FY1 J. Lee。**

**1. 右肺下叶肺炎（入院时CURB-65 2分）。**
S：感觉好些；气促减轻；咳痰减少。
O：体温37.4 °C，呼吸18次/分，吸空气SpO₂ 95%，血压128/76，心率84；NEWS2 1分。右肺底湿啰音减少。CRP 180 → 95 mg/L。血培养48小时无生长。
A：好转中。
P：今天按当地指南改为口服抗生素（总疗程5天）；除非病情恶化，否则无需复查CRP。

**2. 慢性心力衰竭（射血分数降低）。**
S：无端坐呼吸。O：体重68.2 kg（入院时68.9 kg）；轻度踝部水肿；颈静脉压不高。肌酐102 µmol/L（基线98）。
A：容量正常。P：继续平时的心衰药物；每日称体重。

**3. 2型糖尿病。**
O：指尖血糖7~13 mmol/L。A：急性病期间可以接受。P：现已进食且肌酐稳定，继续二甲双胍。

**上报状态：**可全面升级治疗，包括ICU；入院时已与患者讨论复苏问题：实施心肺复苏。
**出院计划：**如口服抗生素后病情稳定，可能明天出院；物理治疗师今天评估活动能力。
签名：J. Lee，FY1，GMC 1234567；上级：A. Mensah医生。

这种结构使任何读者都能一眼看出每个问题的状态和计划。
:::
:::

### 记录关于上报和复苏的决定

病历中一些最重要的信息涉及患者病情恶化时应当怎么做。英国许多机构使用**ReSPECT**流程（Recommended Summary Plan for Emergency Care and Treatment，紧急救治与治疗建议摘要计划），记录本人的意愿以及关于紧急治疗（包括心肺复苏）的临床建议。这些决定必须与患者讨论后作出（如果患者缺乏决策能力，则与其亲近的人讨论，并遵循《精神能力法》（Mental Capacity Act）），清楚地记录并易于查看，并在情况变化时重新审视（[[medical-ethics-law/end-of-life-ethics]]）。

## 用药记录与药物重整

药物是医院中可预防伤害最常见的单一原因，许多差错发生在转换环节：入院、转科和出院。

::: definition 药物重整 {#def-reconciliation}
**药物重整**是指从至少两个可靠来源确定一个人当前用药的准确清单，并与当前所开的药物进行比较，从而发现、解决并记录任何**差异**（遗漏、重复、剂量错误、本应停用的药物）的过程。NICE指南NG5（2015年）建议在入院后**24小时**内完成，临床需要时应更早，并在每次医疗交接时进行。信息来源包括患者和照护者、全科医生病历、摘要医疗记录（Summary Care Record）或共享医疗记录、社区药房记录、患者自带的药物和以往的出院小结。
:::

开处方本身就容易出错。有几条规则能降低风险：

- **绝不缩写“单位”**（“U”可能被看成0，把10 U变成100），也**绝不缩写“微克”**（“µg”和“mcg”可能被误读为“mg”，造成一千倍的错误）。要写全称。
- 避免末尾的零（写5 mg，而不是5.0 mg，后者可能被误读为50 mg），并使用前导零（写0.5 mg，而不是.5 mg）。
- 使用药品通用名，除非品牌很重要（如某些缓释制剂和免疫抑制剂）。
- 在每张处方单上记录**过敏**及反应性质（[[clinical-skills/history-taking#def-allergy]]）。
- 写明适应证，尤其是有多种用途的药物，并写明抗生素的预计疗程。

::: example 一处药物重整差异 {#ex-reconcile}
Taylor先生，70岁，因跌倒入院。入院医生根据全科医生信中的清单开药：雷米普利（ramipril）、氨氯地平（amlodipine）、阿托伐他汀（atorvastatin）和华法林（warfarin）。第2天，药师查看了摘要医疗记录，并与他的妻子交谈。她带来了他的药物：其中有阿哌沙班（apixaban）而不是华法林（三个月前已更换），还有一支他忘了提的每日一次的预充式胰岛素笔。应当怎么办？

::: solution
入院用药清单来自单一的、已过时的来源。有两处差异是严重的：

- **抗凝药**：他用的是阿哌沙班，而不是华法林。再开华法林会造成双重抗凝的风险；不抗凝则有卒中的风险。停掉华法林医嘱，判断是否应继续阿哌沙班（跌倒后要考虑他有无头部外伤或出血，以及他的肾功能），并记录决定。
- **胰岛素**：漏用胰岛素可导致高血糖，对某些人可导致酮症酸中毒。与他的妻子、全科医生病历和胰岛素笔本身核实胰岛素的种类、剂量和时间，开出医嘱，并监测血糖。

然后记录重整后的用药清单、所用的信息来源、发现的差异和采取的措施，并告知团队。这个病例说明了为什么需要至少两个来源，以及为什么患者自带的药物和照护者是有价值的信息来源。
:::
:::

## 保密与查阅

临床病历包含一个人最敏感的一些信息。在英国，病历的使用受普通法上的保密义务、**英国《通用数据保护条例》**（UK General Data Protection Regulation）和**《2018年数据保护法》**（Data Protection Act 2018）以及职业指引的约束。

**卡尔迪科特原则**（Caldicott principles）于1997年首次发布，2013年和2020年修订（2020年增加了第八条），用以指导对可识别患者身份信息的使用。概括如下：说明目的的正当性；只在必要时使用保密信息；使用必要的最少信息；严格按“需要知道”的原则授予访问权限；每个有权访问的人都必须了解自己的责任；遵守法律；认识到**为个人医疗而共享信息的义务与保护保密的义务同样重要**；并使患者和服务使用者对其信息如何被使用有所了解。

实际后果是：只查看你正在诊治的患者的病历；不在公共场所讨论患者，包括电梯里和社交媒体上；妥善保管交接单，并放入保密废纸箱销毁；同时也不要因为担心保密而不把另一位专业人员安全诊治患者所需的信息告诉他。患者有法定权利查看自己的病历（主体访问请求），通常应在一个月内答复。保密问题见[[medical-ethics-law/confidentiality]]。

## 交接

::: definition 临床交接 {#def-handover}
**临床交接**是把对一位患者或一组患者全部或部分医疗的专业责任和问责，暂时或永久地转交给另一个人或团队。它发生在换班时、团队之间（例如从急诊科到病房）、场所之间（从医院到社区），以及向上级上报时。
:::

交接是一个高风险的时刻，因为信息必须在两个人之间传递，常常有时间压力、有干扰，而且接收者无法核实交出者知道什么。遗漏比做错更常见：待出的验血结果、病情恶化时的计划、必须打电话通知的亲属。

::: theorem 安全交接的原则 {#thm-handover}
满足以下条件时，交接更安全：

1. 使用交出者和接收者都熟悉的**标准结构**，使遗漏显而易见。
2. **面对面**（或通过语音）**并有书面记录**，使谈话中可以提问，书面记录又能留存。
3. 在**受保护的时间和地点**进行，不受干扰，有合适的人员在场，包括上级医生。
4. **优先处理**病重和不稳定的患者以及待办事项。
5. 包括**应急计划**：如果发生某件具体的事该怎么做。
6. 以接收者**复述总结**（复述或综合）并提问结束，并明确**责任的转移**。
:::

::: proof 结构与复述为何有效 {#prf-handover}
在时间压力下，记忆是不可靠的，人们倾向于报告自己觉得突出的内容，而不是接收者需要的内容。共同的结构起到核对清单的作用，因此缺失的部分（“应急计划：未给出”）会被注意到。复述闭合了沟通环路：当接收者的总结与交出者的本意不同时，传递中的错误就会被发现。应急计划传递的是推理而不仅仅是事实，使接收者在情况变化时能够行动。在2014年发表的一项多中心研究中，Starmer及其同事在美国和加拿大的九个儿科住院医师培训项目中推行了I-PASS交接方案；医疗差错率下降了23%，可预防不良事件率下降了30%，而且没有增加交接所花的时间。
:::

::: definition SBAR与I-PASS {#def-sbar}
**SBAR**用于组织一次沟通，尤其是上报：

- **S**ituation（现状）：你是谁、哪位患者、现在的问题是什么。
- **B**ackground（背景）：相关的病史和背景情况。
- **A**ssessment（评估）：你认为发生了什么，包括生命体征和NEWS2。
- **R**ecommendation（建议）：你需要什么、什么时候之前（例如“请在30分钟内来看”）。

有些机构增加一个**I**，代表**Identify（身份识别）**（ISBAR）。**I-PASS**专为换班交接设计，包括**I**llness severity（病情严重程度：稳定、“需关注”、不稳定）、**P**atient summary（患者概况）、**A**ction list（待办清单，注明负责人和时间）、**S**ituation awareness and contingency planning（情境意识与应急计划），以及接收者的**S**ynthesis（综合复述）。
:::

::: example 用I-PASS进行晚间交接 {#ex-ipass}
晚上8:30，白班FY1把Begum女士（82岁）交接给夜班FY1。她因尿路感染和谵妄入院。今天下午她的血钾为5.9 mmol/L（之前为4.8），18:00送了复查标本。用I-PASS写出这次交接。

::: solution
**病情严重程度**：“需关注：现在不算不稳定，但可能变得不稳定。”

**患者概况**：“Nadia Begum女士，82岁，3号病室4床。昨天因尿路感染和谵妄入院，正在用静脉抗生素。背景：慢性肾脏病（基线肌酐约130）和心力衰竭，服用雷米普利和螺内酯（spironolactone）。今天她的肌酐升到168，血钾升到5.9；16:00的心电图没有高钾血症改变。我们已停用雷米普利和螺内酯，开始静脉补液，8小时1升。可全面升级治疗；她对某些决定有决策能力，但目前对复杂决定没有；她的儿子是主要联系人。”

**待办清单**：“(1)查看18:00送的复查血钾，大约21:00出结果。(2)午夜评估她的出入量和尿量。(3)早上抽血时复查尿素和电解质。”

**情境意识与应急计划**：“如果血钾达到6.5或以上，或者心电图有变化，按医院方案处理高钾血症并呼叫住院总医师。如果她更加躁动，在考虑任何镇静药之前先找原因（尿潴留、疼痛、低氧），尽可能避免使用镇静药。如果尿量连续6小时低于0.5 mL/kg/h，按急性肾损伤评估并呼叫住院总医师。”

**接收者综合复述**：夜班FY1复述：“Begum女士，需关注。21:00追18:00的血钾；如果6.5或以上或心电图有变化，按方案处理并呼叫住院总。午夜看出入量；早上查尿素和电解质；不先找原因就不用镇静药。”白班FY1确认，两人都在书面交接单上签名。
:::
:::

::: example 用SBAR上报 {#ex-sbar}
凌晨2:00，一位FY1被叫去看Lindqvist先生（见[[clinical-skills/physical-examination#ex-news]]），他肠切除术后第二天，NEWS2为9分。评估之后，她打电话给外科住院总医师。用SBAR写出这通电话。

::: solution
**现状：**“您好，我是Sarah Jones，外科夜班FY1。我打电话是关于Erik Lindqvist先生，71岁，7病区12床。我担心他是脓毒症：他的NEWS2是9分。”

**背景：**“他是直肠癌前切除术后第二天。昨天情况还好。他有高血压，在服雷米普利。”

**评估：**“呼吸24，吸空气血氧93%，血压98/60，心率112，体温38.4，清醒。腹部膨隆，有压痛，下腹部有肌紧张。我担心是吻合口瘘。我已经启动了脓毒症路径：吸氧、血培养、乳酸（3.1）、静脉补液冲击和抗生素，并停了雷米普利。”

**建议：**“我需要您现在来看他，我觉得他可能需要做CT并请重症医学科会诊。您能在15分钟内过来吗？在此期间还有什么需要我做的吗？”

住院总医师回答：“我10分钟内到；补液冲击后复测生命体征，并呼叫重症外展团队。”FY1复述：“补液冲击后复测生命体征，呼叫外展团队；您10分钟内到”，并记录这通电话及其时间。

## 出院与转出

出院是从一个团队到另一个团队的交接，接收方通常是患者的全科医生和社区服务，也包括患者本人。**出院小结**应及时送达全科医生，内容包括：诊断和主要问题；重要的检查及结果；操作；**用药变化及原因**（新开、停用、剂量调整）；明确写出的**需要全科医生采取的行动**；**尚未出来的结果**及其负责人；随访安排；向患者提供的信息；以及联系方式。患者应获得一份用通俗语言写成的副本。

待出结果是一个典型的漏洞：医院团队以为全科医生会跟进，全科医生以为医院会跟进。必须指明负责的人。同样，不应在未经同意的情况下把医院的工作交给全科医生（“请安排CT”），而且建议必须具体（“雷米普利加量后1周请复查血钾和肌酐”，而不是“请监测尿素和电解质”）。

## 团队协作与大胆说出

医疗结局既取决于个人技能，也取决于团队如何协作。关于团队协作的很多知识改编自航空业的**机组资源管理**，它源于对空难的分析：在那些空难中，本可避免事故的信息驾驶舱里有人掌握，却没有被采纳。

关键行为包括：

- **角色清晰、有领导**，领导者大声说出自己的思路（“我认为这是严重过敏反应；我的优先事项是肾上腺素和气道”）。
- **闭环沟通**：向指定的人发出具体指令，对方复述，完成后确认（“Sam，请在15分钟内输注500 mL哈特曼液。”“15分钟内输500哈特曼液。”……“液体已经在输了。”）。
- **共享的情境意识**：定期总结，使每个人都了解计划。
- **大胆说出**：无论资历如何，每个人都应提出安全方面的顾虑。

**分级坚持**工具帮助年轻员工说出顾虑。一个常见的例子是**CUS**：“我**担心**（**C**oncerned）……我**感到不安**（**U**ncomfortable）……这是一个**安全问题**（**S**afety issue）。”另一个是**PACE**：**P**robe（探询）（“我能确认一下血钾的处理计划吗？”）、**A**lert（提醒）（“我担心血钾6.8，而且心电图有变化”）、**C**hallenge（质疑）（“我认为我们需要现在就处理”）、**E**mergency（紧急）（“停下。我要呼叫内科急救团队。”）。上级员工通过主动欢迎质疑（“如果有人发现我漏了什么，请告诉我”）使大胆说出变得更容易。

::: quiz
下列哪一条是对一个决定的最佳记录？
- [ ] “与住院总讨论过。计划同上。”
- [ ] “患者不依从用药。准备出院。”
- [x] “2026/10/27 16:20。与Khan医生（外科住院总医师）讨论：今天行腹部CT以排除积液；如果CT无异常且生命体征稳定，明天带口服抗生素出院。已向患者解释，患者同意。J. Lee FY1 GMC 1234567。”
- [ ] “已看。没事。明天回家？”
::: solution
第三条记录有日期、时间，可追溯，写明了咨询的上级医生，说明了决定、其条件和理由，记录了向患者提供的信息和患者的同意，并有签名。其他几条含糊不清，使用带评判的语言（“不依从”）或缩写，让下一位临床医生只能猜测。

::: history
公元前5世纪**希波克拉底**的病例记录是最早的临床记录之一，写下来是为了从病程中学习。19世纪，医院开始系统地保存病例记录；20世纪初，波士顿的外科医生**Ernest Codman**等人主张记录每个病例的结局，以便从错误中学习。1968年，**劳伦斯·韦德（Lawrence Weed）**在《新英格兰医学杂志》发表《能指导和教学的医疗记录》（"Medical records that guide and teach"），提出了以问题为导向的病历和SOAP记录。**SBAR**由美国海军为核潜艇上的沟通而开发，21世纪初由Kaiser Permanente改编用于医疗，此后通过美国医疗改进研究所（IHI）和NHS传遍世界。2014年发表的**I-PASS**交接研究表明，结构化交接方案能够减少伤害。
:::

## 后续内容

这里描述的许多失误在[[clinical-skills/patient-safety]]中作为系统问题加以分析。保密及有关病历的法律见[[medical-ethics-law/confidentiality]]，处方见[[pharmacology/drug-development-prescribing]]。

::: summary
- 病历必须及时、可追溯、清楚、准确、完整，并且绝不被改动；书写时要假定患者会读这份记录。
- 以问题为导向的病历使用问题清单和SOAP记录，使每个问题的状态和计划一目了然。
- 关于上报和复苏的决定必须经过讨论、清楚记录并易于查看。
- 药物重整应从至少两个来源进行，在入院后24小时内及每次交接时完成；绝不缩写“单位”或“微克”。
- 遵循卡尔迪科特原则：保护保密信息，但共享医疗所需的信息。
- 使用标准结构、面对面加书面信息、受保护的时间、应急计划和复述，能使交接更安全；SBAR用于组织上报，I-PASS用于换班交接。
- 出院小结必须写明用药变化、具体行动、待出结果及其负责人。
- 闭环沟通、共享的情境意识和分级坚持帮助团队发现错误。
:::

## 习题

::: exercise 改正记录 {level=1}
改写下面这条记录，使其符合良好病历书写的标准：“看过患者。诉SOB。胸部?湿啰音。?LVF。给呋塞米40。查U+E。”
::: solution
改进后的版本：“2026/10/27 21:15。护士请求会诊：2小时来气促加重。背景：心力衰竭。生命体征：呼吸26，吸空气SpO₂ 91%，血压150/90，心率104，体温36.8，清醒；NEWS2 6分。双肺底至中肺野细湿啰音，颈静脉压升高5 cm，双侧踝部水肿。印象：急性肺水肿，可能为心力衰竭失代偿；鉴别诊断包括肺炎。计划：坐直，吸氧至目标94%~98%，已开呋塞米（furosemide）40 mg静脉注射，心电图，胸片，尿素和电解质及肌钙蛋白；记出入量并每日称体重；1小时后复评；已告知住院总医师。A. Patel FY1 GMC 7654321。”它有日期、时间和签名，避免了含义不明的缩写，记录了发现和推理，并给出了具体的行动。
:::

::: exercise 信息保留 {level=1 check="0.9^3"}
如果每次交接独立地以0.1的概率丢失某一条信息，那么这条信息经过三次交接后仍保留的概率是多少？给出精确值。
::: solution
$(1 - 0.1)^3 = 0.9^3 = 0.729$。三次交接后，这类信息约有27%会丢失，这就是为什么关键信息应当写下来并加以核对，而不只是口头传递。
:::
:::

::: exercise 出入量 {level=1 check="2350 - (1450 + 500)"}
24小时内，一位患者静脉输液2,000 mL，饮水350 mL。尿量1,450 mL，手术引流管引流500 mL。计算记录的液体平衡（mL）（正值表示入量多于出量）。
::: solution
入量$= 2{,}000 + 350 = 2{,}350$ mL。测得的出量$= 1{,}450 + 500 = 1{,}950$ mL。平衡$= +400$ mL。要记住，不显性失水（经皮肤和呼吸丢失，通常每天数百毫升，发热时更多）没有被测量，因此记录上略呈正平衡，实际可能接近平衡。
:::
:::

::: exercise 低血钾的SBAR {level=2}
心内科病房一位患者血钾2.8 mmol/L，监护仪上出现成串的室性早搏。写出给值班住院总医师的SBAR电话。
::: solution
S：“我是Tom，内科夜班FY1，打电话是关于4病区3床的Grey女士，66岁。她的血钾是2.8，正在出现成串的室性早搏。”B：“她昨天因心力衰竭入院，用了大剂量静脉呋塞米。她在服地高辛（digoxin）。”A：“生命体征稳定：血压118/70，心率88伴早搏，血氧96%，NEWS2 1分。她没有症状。我做了心电图：有U波和频发室性早搏，没有持续性心律失常。低血钾会增加心律失常和地高辛中毒的风险。”R：“我想按当地方案经外周静脉开始静脉补钾，查血镁和地高辛浓度，并继续心电监护。您能在一小时内来看她吗？还有别的需要我做的吗？”然后复述对方的答复并记录。
:::

::: exercise 出院小结的漏洞 {level=2}
一份出院小结写着：“诊断：胸部感染。用药：同前。随访：全科医生复查。血液检查结果待出。”列出缺失的内容以及每处缺失为何重要。
::: solution
缺失：具体诊断和主要发现（哪种肺炎，有无并发症）；**用药变化及原因**（是否给了一个疗程的抗生素，有无停用或调整的药物，例如暂停的降压药）；**哪些血液检查结果待出**以及**由谁**处理；要求全科医生做什么、何时做（“全科医生复查”很含糊）；向患者提供的信息和安全网；以及作者信息。每一处漏洞都有造成伤害的风险：一种没有恢复的药物、一个没有被查看的异常结果、一次不必要或被遗漏的预约。
:::
:::

::: exercise 选择工具 {level=2}
对下列每种情况，说出最合适的结构化工具并说明理由：(a)护士打电话给医生，报告一位病情恶化的患者；(b)内科团队之间30位患者的晚间交接；(c)一位年轻医生认为主任医师即将在错误的一侧手术。
::: solution
(a)SBAR（或ISBAR）：专为简明的上报设计，并以明确的请求结尾。(b)I-PASS（或当地的同类工具）：专为换班交接设计，包括用于排序的病情严重程度、待办清单和应急计划，以及接收者的综合复述。(c)PACE或CUS之类的分级坚持，必要时升级到“停下”；世界卫生组织手术安全核查表中的“暂停核查”正是为此而设，它赋予每个人叫停手术的权利。
:::

::: exercise 一次药物重整审计 {level=3 check="round(100*31/120)"}
对120例入院患者的审计发现，31例在入院24小时时至少有一处非故意的用药差异。这占多大百分比（四舍五入到整数）？然后提出三项降低这一比率的改变，以及你将如何衡量其效果。
::: solution
$31/120 = 25.8\%$，四舍五入为**26%**。可能的改变：由药师主导、在入院24小时内完成药物重整，包括周末；让入院医生可以访问全科医生病历或共享医疗记录；在电子入院模板中设置提示，要求使用两个来源并列出患者自带的药物；培训新医生专门询问胰岛素、抗凝药、吸入剂和注射剂。用同样的差异定义重复审计来衡量效果，最好绘制随时间变化的趋势图，以便看出每项改变的作用（见[[clinical-skills/patient-safety]]）。
:::

::: exercise 大胆说出 {level=3}
在繁忙的查房中，一位主任医师给一位病历记录有青霉素过敏（严重过敏反应）的患者开了静脉阿莫西林克拉维酸（co-amoxiclav）。FY1注意到了。描述她应如何用PACE提出这一问题，以及团队文化如何使这件事变得更容易。
::: solution
探询：“我能确认一下吗？这是阿莫西林克拉维酸，里面含有青霉素类？”提醒：“她的病历上写着2019年对青霉素发生过严重过敏反应。”质疑：“我认为我们不应该给这个药。能换一种吗？”紧急（只有在被忽视且伤害迫在眉睫时）：“我不能给这个药，也不能开这个药；我会请药师来，并阻止给药。”大多数主任医师在探询或提醒阶段就会作出回应。团队文化：上级员工在查房开始时明确欢迎质疑，过敏信息醒目显示并由电子处方系统核查，药师参加查房，并对说出顾虑的员工表示感谢，使提出顾虑成为常态，而不是个人冒险。
:::
