患者安全是最年轻的医学专科、也是唯一以机构自身失败为原材料的专科：它从航空与高可靠度工程借来思想——公正文化、系统观、人因设计、清单、危害的层级控制——并发现医学一直在患者身上运行一个庞大的试验规划而不记录不良事件。**本章讲述伤害的流行病学与分类学（十分之一住院患者受伤害的数字及其测量政治、可预防比例、永不事件、及“不可避免”并发症的事后争论）、好人做危险之事的科学（人因文献绘制注意与记忆与判断属性、防御本该抓住的错误截获、及瑞士奶酪事故模型）、真正移动数字的改进工具包（带其公正文化纪律的重大事件与根本原因分析、事件报告系统及其学习环、投产前的FMEA、清单与组套证据、及凌驾于劝诫之上的标准化与设计层级）、及最难的胜任力：敢说与倾听（分级断言与CUS短语、扁平团队的安全层级悖论、坦承职责与道歉）、伤害对临床医师的人事代价（第二受害者文献）、及测量与治理层（伤害指标、死亡漏斗政治、及为何“无不良事件报告”本身就是一个警报）。**

## 地形

::: definition 伤害的流行病学与系统模型 {#def-epidemiology}
**数字及其政治2018年医学质量回顾及先行的“十分之一住院患者受伤害”荟萃分析——哈佛METS研究1991年3.7%不良事件率与28%可预防的炸弹、昆士兰与犹他彩色编码病历审查、及发现真实率高于投诉率且测量本身就是干预的英国流行率调查（2004规划对测量辩论）、伤害分类学（不良事件对近失误对无伤害但犯了错误的定义、因为近失误是免费数据、A-E伤害严重度分级、及“避免的”对“不可避免的”并发症辩论——医师们抗争是因为当时每次病历审查旗标都像指控）、永不事件与严重伤害指标（错误部位手术与错误植入物与过量及遗留异物清单——卫生服务把它当系统失败警示发现、而即便最好的系统也有拒不到零的发生率——“这怎么可能”之问生产每一代的安全屏障）、及伤害分布：用药错误作为量的王者（用药生命周期每一步都有记录的失效模式——药理课程反引的现实）、医疗相关感染（装置相关与手术带组套证据基础）、静脉血栓与跌倒与压力性损伤（“护理敏感”标签本该读作“系统敏感”）、诊断错误（尸检时代与临床决策支持时代文献的10-15%诊断错误及血管与感染与恶性模拟的误诊三联——本章推理章会面的认知半边）、及多数事件系统从未抽样直到伤害研究单位强行推动的门诊与社区伤害盲点；事故模型（Reason瑞士奶酪：危害轨迹穿过组织影响-不安全监督-不安全条件-概率防御层、一线人员的活跃失败承担责备而潜在条件承担原因——整个领域的伦理重述、及从挑战者号调查借来的偏差正常化机制：规程想象的作业对人员实做的作业、而缺口就是事后事件归档之处）；及韧性修正（从航母与核潜艇研究来的Safety-I对Safety-II高可靠组织文献：多数工作成功是因为人适应、所以只数失败会错过同时也创造下一次事故的适应——这就是为何现代方法用定性调查作业实做、及“报告事件最多的科室不是最危险的、而是报告的那一个”——使事件数据解读本身成为专家的句子）。**
:::

## 工具包

::: definition 什么起作用：分析、设计、清单与公正文化 {#def-toolkit}
**分析方法重大事件分析的“发生了什么、为何、我们将做什么”问责、及根本原因分析框架、其质量取决于小组是否被允许触及排班表及有权点名的采购委员会、“促成因素而非唯一原因”的诚实；人因分类学（行动的口误与疏漏、记忆疏漏、规划错误与规则违反按“当时规则为何看起来错”分类：工作量、冲突优先、糟糕界面）；主动方法——FMEA（在新药递送装置病房布局投产前应用的失效模式与效应分析、使变更清单可处理的严重-发生-可探测评分）及“事前尸检”与“这要怎样才会杀死某人”之问、花几分钟而暴露没人审计过的人员假设；按层级控制顺序的防御医学仍使用不足的安全工程输入：消除与替代及工程控制（设计使错误不可能或使不安全行为不吸引人：结束一个十年错误途径死亡的肠内管接头重设计、椎管内对硬膜外接头、胰岛素泵与葡萄糖输注的硬极限与高矮人字母药名标签、及自动发药柜覆盖审计及条码给药、及处方集与安全用药研究所有名录不断打的相似听名之战）对管理控制（政策与教育改变知识而不改变危害、这就是“重新教育护士”作为行动计划是该领域被引用最多的坏习惯）及清单世代（2008年柳叶刀全球研究的WHO手术安全清单及其“错误部位手术没有消失而并发症下降”评估、及“清单起作用的前提是文化允许初级说话”警诫——把本段连到下一段）；改进科学（计划-做-研究-行动循环与从戴明输入的运行图与控制图的突破改进法、其对组套的证据——密歇根Keystone的呼吸机组套“18个月400条命”叙事及其后来方法学重辩本身就是阅读改进数据的案例研究——胜过单本期刊试验阅读）；及采纳与扩散文献（“证据有效而医院无法实施”——改进科学作者不断重述、同侪与协作模式及保真度审计）；及一切运行其上的文化层（多数机构如今使用的公正文化定义：对人类错误与近失误报告给予支持、对冒险行为给予辅导、只对鲁莽行为给予处分、及“用责备个人代替修复系统”本身就是鲁莽行为的精炼、及显示临床医师接受他们参与设计的调查结果的公平程序研究）；报告与学习环（漏报是最大的测量误差问题：匿名与实名混合系统及30天内反馈给报告者的设计规则、因为报告会消失在虚空里而报告崩塌；“摄入事件不是学习”的对仪表板数报告而不闭环的批评、及邻近指标集）；及也是安全工作的披露半边英国与加拿大及澳新的法定坦承与道歉职责：“道歉不是承认”法、“家属起诉的是沉默、粗鲁与拖延、不是并发症”的诉讼研究、及密歇根大学“早期提供”模型的成本中性发现；告诉患者真相是一项患者安全干预、因为近失误在信任存在之处被报告——及病房里说一句话就能预防法庭卷宗的调查案例巡回。**

## 人

::: definition 敢说、倾听、测量与人事代价 {#def-people}
**声音与层级科学（源自机组资源管理的分级断言工具——CUS（“我不舒服/我害怕/停下”）、两次挑战规则及DOPE与作为升级脚本邻近的SBAR、“为患者安全发言”调查、其发现是跨文化的规律：初级身份、性别、合同类型、夜班与移民身份预测沉默与不良结局——“谁可以叫停一台手术”的层级化作为最可修复的伤害预测因子）；简报与复盘纪律（作为言语行而非勾选框的暂停：回答初级问题的资深者改变那间手术室未来十年的发言率观察研究）及交接是安全屏障的SBAR-I-P-Assist邻近标准化（本课程的记录与交接课进一步展开）；个人的人类错误对策（复述与回授及推注前停顿及两护士核查伴真实药物真实计算的规则——是廉价的注意脚手架不是咒语——及诚实：疲劳与剥夺击败所有对策、这就是为何初级医师工时与护士比例及夜班后驾驶文献是穿职业服的患者安全文献）；测量层伤害指标工具包：触发工具病历审查（“给我用过纳洛酮或抢救药的患者”廉价找伤害法）、起作用的死亡与并发症会议（系统因素先行、以病例为基础、长幼发言顺序的格式对人们躲避的公审版本）及“患者在乎的不是你的SIRS率”的患者报告体验邻近问题、及 NHS头版指标公开时代的两种扭曲效应（移动测量而不移动伤害的目标锁定（操纵4小时等待与癌症等待研究）及公开迫使的收益——都真实、都教）、及死亡漏斗政治（“漏斗图不证明无能、它们引发谈话”的布里斯托时代教训及职业被迫学两遍的复审）；第二受害者与临床医师代价文献（“临床医师在不良事件后成为患者”综合征：侵入性回放与羞耻与酒精及自杀风险数据、伴外科与产科及新生儿与麻醉的“我不配行医”叙事及他们需要的：先是一个说“这会发生而你并不孤单”的人、不是一张表、及同伴支持与一日韧性规划——带“若替代修补参差的系统则韧性培训责怪受害者”辩论）；道德损伤区分（“在强加约束下被迫造成伤害或无法预防它”的伤害、疲劳文献把它与耗竭分开、这要紧因为修法不同：移除约束不是正念）；及治理与倡导层董事会患者安全胜任力框架（“用临床现实核查审查风险登记”、“为模式审读事件数据而不排联赛表”、“用最安静员工的调查审查自由发言政策”、“投诉与索赔数据作为危害源”）、法定调查时代（不列颠卫生体系的各复审：共同发现是“担忧在某处以某种方式提出过、而没有任何东西把它移到决策者”——这就是为何升级与发言自由保护为部分工作者入法、及临床医师的职业职责（“先提出担忧并保护患者、忠诚第二”条款）是可考行为不是情绪）；及领域自身的极限：伤害测量的粗糙、改进文献的复现失败、“清单作为护身符”批评、及诚实结论：安全是一种维持性活动——医学最接近卫生的东西、也同样容易受厌倦伤害。**

::: example 成了右边的左侧 {#ex-wrongsite}
54岁女性被松解了右侧腕管；她在门诊与入院时两次要求做左手（优势手、症状更重）；医院名单、同意书、标记及外科医师的记忆都说右、而“签到”打了勾。
::: solution
**每个奶酪孔都对齐了（[[#def-epidemiology]]、[[#def-toolkit]]）：错误解剖——房医师按一份在转录时颠倒侧别的门诊信继承的名单在错误一侧标记（根本原因分析钟爱的数据流追踪）、及从那份名单复制的同意书、及以念诵执行的暂停：大声说“右”的三个人正是从未清醒见过患者的三个人、而被告知“相信我们”且太礼貌不好意思纠正医师的患者——同意文献与本章声音文献都命名的不对称；本该抓住它的屏障——患者侧之问（“我们在操作哪只手？”）正是WHO清单为此加入、且只在护士说出来会被感谢的手术室起作用；“在患者在场并按其陈述侧别标记”规则；及诱导前核实影像与转诊信而非彼此的笔记、若两份文件不一致名单就停的硬停——是穿政策外衣的工程控制；回应——从病房而非投诉部开始的坦承职责（“我们错了；现在会这样”谈话伴多数辖区法律保护的道歉）、将永远忘不了这次查房的房医师的第二受害者支持、无反派且触及转录与排班潜在条件（深夜11点临时工名单打字、每位顾问每月一封门诊信队列）的重大事件分析、及按层级顺序的修复清单：转录消除（侧别作为编码必填字段并按患者话语确认的结构化电子转诊）先于再教育；及告诉你它成功的审计：“错误侧在这里从不发生”的主张用近失误报告率核查、因为报告“今年我们差点切错手四次”的科室才是安全的科室。**
:::

::: example 通宵运行的胰岛素 {#ex-insulin}
术后病房：换注射器后泵的输注基础速率未被停；61岁在交接时被发现出汗意识模糊；血糖1.9 mmol/L；她在观察区抽搐；遗留永久记忆后遗。事件报告写“人员错误、再教育”。
::: solution
**硬极限不是训诫（[[#def-toolkit]]、[[endocrine/diabetes]]、[[clinical-skills/clinical-reasoning]]）：系统追踪——“换注射器而管路清空”神话（泵死腔推注是工程属性：管路必须用单独的预冲步骤与换注射器规程及泵库与推注极限防御）；解剖“再教育”谬误（同一规程失败跨班次跨医院重复、因为危害在界面不在手——教育改变知识、设计改变行为文献的一个案例）；按层级顺序的防御——消除（病房尽可能皮下或可预测方案）；替代（带硬剂量极限的闭合系统与预填充卡式瓶及葡萄糖泵整合）；工程（剂量错误削减软件与基础速率锁止及“新注射器意味着清管路”强制步骤、及把两人核查做得与跳过一样容易的泵旁“签这一行”卡）；流程（高警示药物清单伴每次交接与每餐及转科的输注安全停、及附在每个胰岛素输注医嘱上的血糖核查频率规程、及贵信托同月失败的床旁检测质控）；文化（凌晨2点质疑泵而被感谢的护士调查条目——预测下次能否被抓住）；回应——永不事件邻近要求（若干体系中静脉胰岛素错误是可报告的严重危害）使“再教育”行动计划不为治理层接受、及坦承与康复包：认知康复转诊及糖尿病与保险与驾驶及能力与代理实务——“发生并发症”的病历从不触发；及临床医师的平行病例：对“午夜她看起来没事”交接的知识与疲劳复审——本事件SBAR形状的课。**

**医学创始的安全承诺——不造成伤害——比其证据基础更老、而测量这个缺口的学科始于三次冲击。首先是流行病框架：1972年Barber-Howie委员会的不良事件报告及1982年加拿大甲状腺激素事件皇家调查与血制品悲剧教会卫生系统：医源性伤害可以批量生产。然后是1991年哈佛医疗实践研究与澳大利亚昆士兰及犹他系列、由病历触发工具应用并找出使“我们怎么知道它是安全的”成为研究之问的数字、及1999年美国医学研究所《人非圣贤》报告——伴其每年4.4万至9.8万可预防死亡估计——以该领域仍在争论的数字把议题送上报纸头版。调查时代随之而来：布里斯托新生儿心脏与皇家医院等复审、米德斯塔福德郡调查2010年死亡人数发现及其“监管者满意而患者在死亡”的结论、及格伦费尔邻近时代的“文化就是原因”判决。智识装置来自医学之外：源自灾难心理学工作与正常事故及高可靠辩论的活跃对潜在失败框架；Reason的《人类错误》（1990）与瑞士奶酪模型（1997）、关于航母的高可靠组织研究（产生对失败的关注与不愿简化与对运营的敏感及服从专业——“最安全的房间是护士能叫停外科医师的房间”口号概括）、Dekker的安全II批评及Hollnagel韧性工程学派；及清单世代参差的证据——WHO手术安全清单2008年柳叶刀研究及其“有效沟通与无菌做了工作、勾选没有”的再分析及“清单作为护身符”批评、使实施科学成为一个子学科。改进科学的输入（2004与2008年循证手册、五百万生命运动的组套扩散及其后来关于多少改进是真实的多少是回归均值的自我批评、及Keystone呼吸机组套叙事）同时教会了其力量与阅读它所需的统计素养。披露半边经法律移动：美国各州1970-2000年代的道歉非承认法规、加拿大的道歉立法、“我很难过”运动、及英国2014年起的法定坦承职责——及美国沟通与解决规划（早期提供研究）显示赔偿与自杀都下降而预算中性。报告系统历史平行运行：从患者安全指标与国家报告学习系统及全球患者安全挑战的高警示药物与医疗相关感染及诊断错误运动（其2023年诊断错误专题终于命名了该领域最老也最少测量的伤害）到第二受害者运动（伤害的斯坦福一侧）及把“员工敢不敢说”变成可测预测因子的心理安全调查。其未决章节正是本课程不断触及的：门诊与基层测量缺口、诊断错误流行病学对尸检邻近数据的依赖、初级医师工时政治、及每个系统的安全数据都是由产生它的报告文化做出的估计这一事实。** — [[clinical-skills/clinical-reasoning]]、[[medical-ethics-law/professionalism-regulation]]、[[public-health/health-systems-economics]]。**
:::

::: summary
- 医疗伤害常见（最好调查中约每十次住院一起）、相当部分可预防、并集中于药物、感染、血栓栓塞、跌倒与压力性损伤、操作及诊断。
- 事故穿过奶酪：活跃失败在床旁、潜在条件（排班、采购、界面、人员）在董事会；因潜在条件责备个人是该领域的核心禁令——公正文化是妥协。
- 起作用的防御遵循层级控制：先消除与工程（接头重设计、泵硬极限、条码给药、高矮人标签）再劝诫；清单与组套在文化允许初级说话且实施被审计时起作用。
- 报告是信任仪器：近失误是免费数据、反馈环使其流动、而“无报告”是红旗；分析（重大事件/根本原因/FMEA）必须触及排班表与采购委员会才算数。
- 披露是安全工作：坦承、道歉与早期提供规划同时降低伤害的人事代价与诉讼代价。
- 伤害有两个患者：第二受害者与道德损伤文献要求为临床医师设福祉路径、而测量（触发工具、带谦逊的漏斗、患者报告条目）是董事会学习或表演的地方。
:::

## 练习

::: exercise 给行为分级 {level=1}
在公正文化下分类并给出正确组织回应：(a) 资深护士在供应商调换标签后把药X给成药Y；(b) 医师凭记忆为同事的患者签医嘱而不查观察；(c) 注册医师篡改管制药物记录以掩盖发药缺口；(d) 政策被未经协商重写四次后员工略去床栏核查。
::: solution
**四例公正文化（[[#def-epidemiology]]、[[#def-people]]）：(a) 来自相似危害的人类错误——支持、通知供应商并以警报移除相似标签；停在“护士错误”的根本原因分析对不起下一位患者；(b) 冒险行为（被工作量与“人人如此”正常化的捷径）——辅导加重设计（“开单前开单者可见观察”的电子病历界面是工程修复、谈话问为何签名可被接受）；(c) 鲁莽而欺骗——处分及康复流程及监管机构通报、因为诚信失败与口误有本质区别；(d) 实做作业击败想象作业——系统失败：“政策疲劳”发现意味着政策是受试干预、而“再教育”计划是渎职；元课——同一行动（漏掉的核查）依行为者为何认为它对而可以是四类中任何一类、这就是公正文化小组先访谈后判断的原因。**
:::

::: exercise 设计条码上线 {level=2}
贵信托将在40个病房部署条码给药。护士担心它会“管我们”、药房想要合规统计、供应商提供速赢、而信息主管要八周内上线。写实施临床安全计划。
::: solution
**实施作为安全干预（[[#def-toolkit]]、[[clinical-skills/records-handover]]）：FMEA先行立场——上线前可能出错什么：扫描覆盖缺口（按需药、紧急剂量、血制品、患者自带药、“洗澡时摘掉的腕带”）、绕行预测（缺失条码时打印标签贴在电脑上——今天的高效、明天的绕行文化）、及条码扫描必须明确解决而非为高警示药物静默消解的双人核查之问；人的设计——护士作为流程地图共同设计者（在写规程前于真实班次研究实做作业）、扫描被框为患者保护而非绩效监督、合规数据与个人纪律脱钩、近失误扫描警报每周分诊并有可见修复、及供应商合同里的警报疲劳预算以使系统绝不被允许训练员工糊弄过去；分阶段——两个病房的试点伴观察研究、含网络死角调查与演练过的停摆规程的去/留标准、然后由试点自己的护士（同侪扩散证据）而非供应商教扩散；及评估——正确结局不是合规百分比而是每千次扫描截获的给药错误、绕行率、护士信心调查条目（“按系统现状我能在我的夜班安全给药”）、及十二个月回望旧纸质系统曾抓住而没人想起来问条码的错误类型。**
:::

::: exercise 运行重大事件分析 {level=2}
某病房六周内三起带伤害跌倒；初始病历每次写“步态不稳、发现倒在地板”。引导重大事件分析以产出可辩护的改变、并命名糟糕分析的三种失效模式。
::: solution
**做好的重大事件分析（[[#def-epidemiology]]、[[#def-toolkit]]）：方法——由在场的人（拖地的护理员、管两个床区的夜班护士、挪起床栏的家属）重建每个事件的时间线、先访谈后判断并大声声明公正文化框架；促成因素地图——跌倒分类学审计（点名多沙唑嗪与催眠药——多重用药杠杆——的体位性药负荷审查）、如厕与呼救轨迹（没人调的呼叫铃应答间隔数据）、凌晨3点照明而非日光下的鞋与水箱垫与床栏与环境清扫、及把“不稳”变成诊断的谵妄与失禁与骨与心源性晕厥筛查；按层级顺序的行动计划——近消除（床警报与低床之辩并陈述其证据极限）、工程（床高与床栏与地垫与照明标准）、流程（带晕厥工作检查触发的跌倒后评估规程使第三次跌倒得到心电图）、然后才是教育——每项带所有者、日期与指标；及糟糕分析的三种失效模式：找出反派并关闭纪要版、行动等于再教育版、及报告归档而不反馈给报告者且不重看行动是否咬住——每一种都保证第四次跌倒。**
:::

::: exercise 读仪表板 {level=2}
董事会材料：A病房今年报2起事件、B病房报61起；投诉量两者相同；B病房跌倒伤害率是A的一半；两者都从未做根本原因分析。总监提议“事件削减目标负20%”。诊断仪表板并重写提议。
::: solution
**安全数据素养（[[#def-epidemiology]]、[[#def-people]]）：解读——报告计数测量的是报告文化不是伤害（B病房的61是向好方向的安全信号——近失误浮现；伴相同投诉量的A病房的2才是警报）、而要紧的伤害指标是每个占用床日严重伤害与触发工具阳性、材料完全遗漏；目标批评——“事件降20%”的数字是教科书古德哈特案例（数字下降是因为报告停止）：报告压制是可预测的行为答案、它在目标咬住的瞬间摧毁预警系统；重写——用以下替代目标：(i) 带员工心理安全分的比较解读报告率与质量指标、(ii) 以伤害流行率测量（触发工具、时点流行率调查）为结局、(iii) 模式审查规则（“同一病房同一班次的五份报告得到临床主导审查、不是电子表格”）、(iv) 根本原因/重大事件分析质量与行动完成度审计而非计数、及v) 明确的“安静病房会得到一次访问”条款、因为董事会在其患者安全胜任力框架下的职责是注意到数据缺失之处、不是在小数字之处祝贺。**
:::

::: exercise 支持第二受害者 {level=2}
一起孕产妇死亡次日、最先到场的高级助产士给团队发邮件道歉、不再参加交接、对主管说“我撑不下去了”、并婉拒信托的心理咨询传单。作为她的同事与本单元临床主管，你实际做什么——系统绝不能做什么？
::: solution
**第二受害者照护（[[#def-people]]、[[obstetrics-gynaecology/pregnancy-complications]]）：同侪——先做一个人再谈流程：私下、面对面、不带表格，说“晚我也在场；你的反应是正常人对 异常事件的正常反应；你并不孤单”、并连续数天陪伴（“我明天在；今晚我打电话给你”），因为侵入性回放与羞耻需要见证者而非档案；她可能真正需要的——把她在数周内带回安全接触（缩短的班次、可信的伙伴、无审判的重看），及一次真正筛查酒精与自杀的谈话——若筛查阳性，为她安排她自己会接受的照护（一位保守秘密同侪陪同的执业者）；系统必须做且公开做的——立即着手坦承与重大事件分析（她必须知道真相以及其中没有她假想的过失、而若确有系统因素、修复要被命名），把她从她不应当独自承担的角色——首访者、写信者、家属电话——中解放出来并说清原因；及系统绝不能做——“我们为你提供心理咨询”的传单（把系统责任私有化为个体韧性）、把她调离临床作为隐性惩罚、在走廊议论、或让她返回岗位却从不谈那件事、因为“回归并假装”是把急性创伤变成慢性道德损伤的配方；以及单元的功课——复盘那晚的公开、无反派学习会（她若愿意可以选择在场、但无论她在不在都要举行），因为剩下的团队也需要消化、而“这里如何对待我们中最好的人犯错”将定义这个单元十年。**
:::

::: example 没人读的覆盖 {#ex-overrides}
发药柜本季度在外科病房记录4100次覆盖事件；药房季度报告把该数以百分比显示并归档。一名夜班患者收到6克头孢菌素、因为“错误药物在错误药袋”配置被覆盖“为了省时间、又一次”；事件被标为“开单者错误”。
::: solution
**覆盖数据作为危害雷达（[[#def-toolkit]]、[[pharmacology/dosing-principles]]、[[clinical-skills/patient-safety]]）：原则——覆盖与绕行数据是用药系统的近失误流：安全用药研究所有邻近文献与柜商自身指南都说覆盖不是偏差而是信号——它们在确切的小时与药柜与药物处定位系统与临床现实不一致之处；方法——停止报告百分比：拉出条目级事件、按药物-配置-位置-时间分组（“药袋不匹配覆盖聚集在晚间补货排班制造的23:00-07:00换袋缺口”）、就设计让他们做错了什么访谈覆盖者、并把前十聚类当作风险登记；按顺序的修复——工程（补货时条码药袋核查步骤、硬极限、及肾剂量与相邻药物混淆的最大剂量护栏）、然后流程（用有人接的电话可联系到的夜班药师）、而“政策与教育”只作为点缀——加上使其公正的反馈环：病房看到“你覆盖了40次；这是我们改了什么；现在是6次”、把监管变成伙伴（及报告文化文献的要点）保持流量；及重贴标签的事件：以覆盖数据开头的根本原因分析找到补货排班与柜配置及凌晨2点人员现实——“开单者错误”版本以一份培训记录与下季度同一药袋同一小时的同一聚类收尾。**
:::

::: example 凌晨3:12被接听的电话 {#ex-escalate}
03:12夜班护士就一位胰腺切除后患者“就是不对劲”呼外科房医师；房医师说“给500 ml明早再看”；护士03:40再呼、然后出于礼貌呼叫注册医师；注册医师04:20到、患者05:00插管；24小时复审发现一张被当作数字而非线读取的观察表已向下漂移两小时而没人“看”到的出血。
::: solution
**升级是系统属性（[[#def-people]]、[[emergency-critical-care/acute-assessment]]、[[surgery/perioperative-care]]）：三个失败——被低度升级的“不对劲”（非结构化的担忧交接：SBAR就是为这句话存在）、被读作数字不作线的图表使两小时向下趋势不可见（绘制趋势的观察表设计及或未触发或触发进一个无强制响应系统的NEWS扳机）、及本不该是人情的“礼貌呼叫注册医师”（带有人接听电话的升级路径及任何护士都能触发复核并将被感谢的政策——把依赖个性的行动变成规程）；出血的医学——胰腺切除后出血病先于血红蛋白下降、及第一小时窗口CT上的动脉造影剂外渗、ERAS规程的早期警报正因患者先代偿后崩溃而存在；要做的重大事件分析——“不问谁问什么”版本（房医师凌晨独自管两个病区40床呼机名单的排班事实、以言语而非当面答复的呼叫、及趋势被旗标给无人接的界面事实）带正确顺序的行动（带模拟的入职升级胜任力、及每张胰腺切除床上的第二次出血规程卡设计修复）及对患者与24岁正处于同一十字路口的房医师双方的坦承与支持臂；及值得从恶化文献采纳的指标：从异常到复核的时间与无需医师许可的护士主导危重复核计数、因为那两个数字就是书写下来的“敢言文化”长什么样。**

::: exercise 写入职培训的安全部分 {level=1}
新医师周一报到。设计九十分钟患者安全入职培训以改变行为而不只是意识：命名五项内容及你不会做的两件事。
::: solution
**落地的入职（[[#def-people]]、[[clinical-skills/records-handover]]）：内容——1“这里出事怎么办”操作卡（有人应答的升级电话、带演示登录的事件系统、坦承职责首拨联系人、及明确声明的“停线”权限：你可以叫停这台手术而你会被支持）；2本地高警示现实（贵信托前十覆盖聚类、我们药柜里的相似对、及带“独立核查意味着我们俩都看”演示的胰岛素与抗凝路径）；3交接与记录标准伴在演员而非幻灯片上演练的带“我在担心什么”尾巴的SBAR；4人因自卫（疲劳与剥夺数据、“如果你没睡成告诉我们而我们会修排班不会修你的记录”文化伴初级医师工时文献为之争取的实际休息与交通规则）；5由曾经是第二受害者的顾问大声说的第二受害者承诺（“如果你伤害了患者、你第一个电话可以打给我、而系统的第一问将是你怎么样”——这是入职文献中产出最高的一句话）；及两个不做——不做点击合规戏剧（意识模块不改变行为的证据足以让它们退休）与不做“安全是人人的优先事项”海报时刻：检查的发现是员工能背诵价值观而同时点名不安全排班、意味着你用排班表和数字及具名者取代海报、并以告诉他们信托自己最近那起从中学习的伤害案例收尾、因为让安全变得真实最快的方式是展示它被诚实地讨论。**

::: exercise 处理道歉请求 {level=2}
一起漏诊骨折造成神经损伤六周后、患者家属来电要“漏诊的那位医师”来“解释他自己”。医师恐惧、投诉团队想“用一封信处理”、而患者想要为何漏诊及什么会改变的答案。为三个立场及会议设计提供建议。
::: solution
**坦承作为临床技能（[[#def-people]]、[[medical-ethics-law/professionalism-regulation]]）：框架——对家属：法定与道德的坦承职责意味着及时、当面、大白话的解释伴道歉（在法律上多数辖区不构成责任承认）及他们要的我们改了什么答案是只有临床医师能给的；对医师：道歉感觉像认罪的恐惧是有记录的第二受害者螺旋、而道歉与披露规划数据显示大多数准备带辅导与支持的会议进行良好并防止投诉变索赔的轨迹；对组织：“让我们写信”是研究已定价其结局的1990年代模型；设计——正确的房间（若可避免则不在其接受治疗的医院、寻呼机静音、双方临床医师及患者建议与慰问服务或同等者及家属支持者）、先时间线后“我当时在想什么”结构（家属报告听到推理——“X线被判读为正常而这就是它发生的原因”——与遗憾同样要紧）、不猜测赔偿的边界、及后续书面摘要与复审会议承诺把会议变成一个过程；及之后——学习被记录并喂入报告环使家属的下一个问题（“有什么改变了吗？”）有带证据的答案、及给临床医师的复盘伴患者得到的同等尊严。**
:::

::: exercise 审计你的单元 {level=3}
你有两周与一名数据分析师，除了事件报告之外找出你的病房到底多安全。设计审计：指标、方法、及你准备好听到的三个真相。
::: solution
**超出报告的审计（[[#def-epidemiology]]、[[#def-toolkit]]）：方法栈——1时点流行率伤害清扫（一天跨所有床的病历审查查跌倒与压力性损伤及静脉血栓预防状态与药物重整缺口、在三个不相关时点重复）、加触发工具清单（纳洛酮与鱼精蛋白与维生素K及抢救药与24小时内转ICU阳性作为伤害代理）；2实做作业观察（两天跟随伴偏差正常化清单：因为设计拒绝真实病房而人们表演的绕行、不具名记录）；3定性声音层（员工的“什么让你夜不能寐”之问及患者的“有人告诉你要发生什么吗”条目、及最安静的员工先调查原则——其沉默就是危害的护理员与夜班及临时工与国际员工群体）；4报告系统取证（反馈环测试：端到端追踪五份过去的报告——有人行动了吗、有人回复了吗、有人知道吗？）；及治理收尾——按层级控制可移除性排序的发现伴提前命名的三个准备好的真相：事件率将证明是报告梯度而非伤害差异、想象作业对实做作业将令你捍卫过的一份规程尴尬、及其中一部分将是人员不足——这是审计存在为使下次经费谈话无法回避的发现。**
