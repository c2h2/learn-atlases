医疗本意是帮助人，但它也会造成伤害。患者会因诊疗而发生感染，接受错误的药物或剂量，在医院里跌倒，被漏诊，或者病情恶化却无人察觉。世界卫生组织估计，约十分之一的患者在医疗中受到伤害，其中相当一部分是可以预防的。大多数伤害并不是由粗心的个人造成的。它产生于这样的情形：有能力、出于好意的人在一个使差错容易发生、却难以被发现的系统中工作。

本章介绍差错和伤害如何定义和分类，从系统角度看待事故以及人因科学，医院中常见的伤害类型，减少伤害的工具（核查表、设计、报告与学习、公正文化以及对患者坦诚），以及质量改进的方法。本章借鉴了[[clinical-skills/records-handover]]和[[clinical-skills/clinical-reasoning]]的内容。

## 问题的规模

自20世纪80年代以来，对医院病历的大规模审查一直在测量伤害。1991年发表的**哈佛医疗实践研究**（Harvard Medical Practice Study）发现，纽约州约3.7%的住院发生了不良事件。在英国，**Charles Vincent**及其同事2001年对伦敦两家医院病历进行的试点审查发现，约**10.8%**的患者经历了不良事件，其中约一半被判定为在普通诊疗标准下是可以预防的。1999年，美国医学研究所的报告《**人非圣贤，孰能无过**》（*To Err Is Human*）使这些数字引起公众关注，并认为大多数差错源于有缺陷的系统，而不是个人的鲁莽。不同的方法和场所得出的数字不同，但每一项研究都讲述着同一个故事：医疗造成的伤害很常见，常常很严重，并且常常是可以预防的。

::: definition 差错、伤害与事件 {#def-terms}
- **患者安全事件**是指患者在接受医疗时发生的、可能伤害或已经伤害患者的任何非预期或意外事件。
- **不良事件**是由医疗而不是患者的基础疾病造成的伤害。它可能可以预防，也可能不可预防。
- **差错**是未能按预期执行计划好的行动，或使用了错误的计划。并非每个差错都造成伤害，也并非每个不良事件都涉及差错（有些是正确治疗的已知并发症）。
- **未遂事件**（险兆事件）是在到达患者之前就被拦截的事件。**无伤害事件**到达了患者，但没有造成伤害。
- **可预防的伤害**是通过对流程作合理调整或遵循指南就本可避免的伤害。
:::

未遂事件和造成伤害的事件同样重要，因为它们暴露的是同样的薄弱环节，却不需要付出伤害的代价。一个能听到自身未遂事件的系统，可以在有人受伤之前把问题解决。

## 差错是如何发生的

心理学家**詹姆斯·里森（James Reason）**按出错的心理过程对差错进行了分类。

::: definition 不安全行为的类型 {#def-errors}
- **疏忽**（slips）是由于注意力失误而未能按计划完成的行动：拿错了注射器，或在屏幕上选错了患者。
- **遗忘**（lapses）是记忆的失误：忘了给一剂药，或忘了查看一个结果。
- **错误**（mistakes，计划失误）是计划的失误：行动按预期进行了，但计划是错的。**基于规则的错误**是在错误的情境中运用了好规则，或运用了坏规则；**基于知识的错误**发生在面对一个新问题而缺乏解决它所需的知识时。
- **违规**（violations）是有意偏离规则或程序。大多数违规并无恶意：**常规违规**之所以成为常态，是因为规则不切实际（“病房忙的时候大家都跳过那项核查”）；**情境违规**之所以发生，是因为当时的情况使遵守规则变得困难。
:::

差错的类型决定了补救方法。疏忽和遗忘会发生在专家身上，培训或劝诫（“要更小心”）并不能防止它们；减少它们要靠设计：强制功能、标准化、核查表和提醒。错误（计划失误）要靠培训、决策支持和督导来减少。违规要靠弄清规则为何被违反，并修正规则或条件来减少。

### 系统观

::: theorem 瑞士奶酪模型 {#thm-swiss}
在里森的**瑞士奶酪模型**中，组织防范伤害的防线（政策、核查、设备、员工培训、督导）被画成一片片奶酪。每一片都有孔洞，即薄弱环节。有些是**显性失误**（active failures，主动失误）：一线人员的不安全行为，其影响是即时的。另一些是**潜在条件**（latent conditions）：由更早、更高层的决定（人员配置、设计、采购、排班、培训）造成的薄弱环节，可能潜伏多年。当多层防线上的孔洞排成一线，使危险穿过每一道防线时，伤害就发生了。
:::

::: proof 为何多层防线能起保护作用，又为何会一起失效 {#prf-swiss}
如果一个危险必须穿过$n$道相互独立、各自以概率$p$失效的防线，那么发生伤害的概率是$p^n$，它随防线增加而迅速下降：三道各自十次失效一次的防线，只会让伤害在一千次中发生一次。这就是多层防线有效的原因。这个模型也解释了它们为何失效：孔洞**并不相互独立**。人员不足这样的潜在条件会同时扩大好几层防线上的孔洞：开处方的人很匆忙，药师同时负责两个病房，做第二次核对的护士被打断。当各层一起失效时，所提供的保护远小于按独立计算的结果。因此，安全工作要寻找潜在条件，而不只是盯住最后一个接触患者的人。
:::

::: definition 人因 {#def-human}
**人因**（human factors，或人类工效学）是研究人如何与其任务、设备、环境和组织相互作用的科学，并把这些知识用于设计适合人的能力与局限的系统。它承认，工作表现受**疲劳**、**工作负荷**、**干扰**、**压力**、**沟通**和**设计**（设备、软件、包装和工作空间的设计）的影响，而且“人为差错”通常是调查的起点，而不是结论。
:::

使人因在英国医疗界受到广泛关注的，是2005年**Elaine Bromiley**的死亡。在一次常规手术中，麻醉团队无法为她插管，也无法通气。经验丰富的临床医生执着于反复尝试插管，失去了时间感；护士们已经拿来了紧急外科气道的器械，却觉得无法有力地说出来。她的丈夫**Martin Bromiley**是一名航空公司飞行员，他要求进行航空业那样的公开、不追责的调查，并于2007年创立了临床人因小组（Clinical Human Factors Group）。这个病例如今被用来讲授情境意识、固着错误和大胆说出。

### 较强与较弱的干预

并非所有的安全措施都同样有效。常用的**控制层级**对它们进行了排序：

1. **消除和强制功能**（最强）：通过设计使差错不可能发生。例如：静脉与鞘内（脊髓）接头在物理上无法相互连接；从普通病房的库存中撤除浓氯化钾。
2. **自动化和计算机化**：带有剂量核查和过敏提示的电子处方；给药时扫描条形码。
3. **标准化和简化**：全院使用同一种输液泵；标准药物浓度；标准的病房布局。
4. **核查表和提醒**：如世界卫生组织手术安全核查表。
5. **规则、政策和培训**（单独使用时最弱）：必不可少，但依赖于记忆和注意力，而这恰恰是会失效的东西。

对事件的应对如果只是“已提醒员工保持警惕”或“重新培训”，很少能防止再次发生。

## 常见的伤害类型

- **用药差错**：发生在开处方、调配、给药和监测各环节。高风险药物包括抗凝药、胰岛素、阿片类、化疗药、钾及其他浓电解质。世界卫生组织第三项全球患者安全挑战“**无伤害用药**”（*Medication Without Harm*，2017年）旨在减少严重的、可避免的用药相关伤害。
- **医疗相关感染**：导尿管相关尿路感染、中心静脉导管相关血流感染、手术部位感染、艰难梭菌（*Clostridioides difficile*）感染和肺炎。在世界卫生组织的**五个时刻**（接触患者前、进行清洁或无菌操作前、有体液暴露风险后、接触患者后、接触患者周围环境后）进行手卫生，仍然是根本措施。
- **未能识别和应对病情恶化**：遗漏或误读生命体征，延迟上报；NEWS2等早期预警评分和快速反应团队针对的就是这一问题（[[clinical-skills/physical-examination#def-news2]]）。
- **静脉血栓栓塞**：通过入院时风险评估和适当的预防措施来减少。
- **跌倒**和**压力性损伤**，尤其是在衰弱的老年人中。
- **诊断错误**：漏诊、误诊或延误诊断，包括未对检查结果采取行动（[[clinical-skills/clinical-reasoning#def-bias]]）。
- **手术伤害**：手术部位错误、异物遗留和可避免的并发症。

::: definition 绝不应发生事件 {#def-never}
在英格兰，**绝不应发生事件**（Never Events）是指完全可以预防的严重事件，因为国家层面已有能提供强有力系统性防护屏障的指南或安全建议，所有医疗机构都应已落实。NHS England的《绝不应发生事件框架》（Never Events framework，2018年）列出了这些事件；例如手术部位错误、操作后异物遗留、给药途径错误（如把静脉用药经脊髓途径给予）、使用前未发现的鼻胃管或口胃管位置错误、因缩写或错误装置导致的胰岛素过量，以及输注ABO血型不相容的血液成分。其决定性特征是屏障已经存在；屏障的缺失是系统的失败。在2024年的一次咨询中，许多回复者认为该框架已不适用，NHS England于2025年宣布将制定一种与PSIRF相一致的新方法；截至2026年，在这项工作进行期间，2018年的框架仍在使用。
:::

::: example 分析一次胰岛素过量 {#ex-insulin}
Okoro先生，66岁，2型糖尿病。晚上11点，一位同时负责四个病房的初级医生在纸质医嘱单上写下“胰岛素10U”。一位护士与一名派遣护士同上夜班，她把剂量读成了100单位，并用一支普通1 mL注射器而不是胰岛素注射器抽取。因为另一位护士在照顾一位病情恶化的患者，没有进行第二次核对。Okoro先生发生严重低血糖，需要紧急处理。用瑞士奶酪模型找出显性失误和潜在条件，并提出强有力的干预措施。

::: solution
**显性失误**（一线）：用“U”表示单位；误读剂量；使用非胰岛素注射器；未经第二次核对就给予胰岛素。

**潜在条件**：没有剂量范围核查的纸质处方；配制胰岛素的地方备有普通注射器；人员配置和工作负荷使第二次核对无法进行；一位医生夜间负责四个病房；对不熟悉当地政策的员工培训或入职引导不足。

**较强的干预**：要求完整写出“单位”并对异常大剂量发出提示的电子处方（自动化）；只使用胰岛素注射器或胰岛素笔，并从胰岛素配制区域撤除普通注射器（强制功能和标准化）；使高风险药物双人核对切实可行的人员配置和上报安排；以及注射胰岛素后监测血糖。单单“提醒员工不要缩写单位”是一种弱应对。这一事件属于绝不应发生事件，必须根据坦诚义务把发生的事告诉患者及其家属。
:::
:::

## 核查表

核查表是一份简短、有结构的清单，列出容易被遗漏的关键步骤，在规定的时间点大声读出并加以确认。它并不取代专业技能；它保护专家在压力下不出现遗忘。

**世界卫生组织手术安全核查表**于2008年推出，分为三部分：**麻醉前核查**（麻醉诱导前：确认身份、手术部位、手术方式和知情同意，标记手术部位，麻醉安全检查，已知过敏，气道和误吸风险，失血风险）、**手术暂停核查**（切皮前：团队成员自我介绍，确认患者、部位和手术方式，预判关键事件，确认抗生素预防和必要的影像资料）和**离室前核查**（患者离开手术室前：器械、纱布和缝针清点，标本标识，设备问题，以及复苏期间需关注的要点）。

在2009年发表的一项研究中，**Alex Haynes**及其同事在世界各地八个城市的八家医院推行了这份核查表。院内死亡率从1.5%降至0.8%，并发症发生率从11.0%降至7.0%。这项研究是前后对照，而不是随机试验，因此部分效果可能来自其他变化以及被研究本身带来的关注；后来的评价表明，获益取决于核查表被使用得有多认真。如果核查表只是走过场地打勾，而没有它本应引发的交流，它提供的保护很小。

::: example 一次起了作用的暂停核查 {#ex-timeout}
在左膝关节镜手术前的暂停核查中，器械护士大声读出知情同意书。上面写的是“右膝”。外科医生之前与患者交谈后在病房里标记了左膝，他确信左膝是对的，说：“是笔误，我们继续吧。”应当怎么做？这次未遂事件暴露了什么？

::: solution
在差异得到解决之前，手术必须停下。暂停核查恰恰起到了它应起的作用：它揭示了两个信息来源相互矛盾。患者此时已经麻醉，无法询问，而书面同意书写的是另一侧，因此一个人的确信是不够的。团队应当核查独立的信息来源（门诊信件、影像资料、手术排程和部位标记），以弄清错误所在。在与已签署的同意书不同的一侧手术，有在没有有效同意的情况下手术的风险，因此只要对患者同意的内容仍有任何疑问，就应按当地政策推迟手术，直到患者能够确认并更正同意书。必须把这一差异告诉患者。

这是一次**未遂事件**，应当报告。它暴露了潜在条件：同意书填写有误，且没有与手术排程核对；诱导前的麻醉前核查本可以询问患者，却没有发现这一不符；外科医生的确信几乎压过了核查（权威梯度）。学习应对可以审视同意书的填写和核实方式，并强调任何人都可以在暂停核查时叫停手术。
:::
:::

## 从事件中学习

::: definition 事件报告与学习系统 {#def-reporting}
**事件报告系统**让员工记录患者安全事件和未遂事件，以便识别规律并采取行动。在英格兰，各地的报告汇入国家**从患者安全事件中学习**（Learn from Patient Safety Events，LFPSE）服务，它已于2024年完全取代国家报告与学习系统（NRLS）。自2022年起，**患者安全事件应对框架**（Patient Safety Incident Response Framework，PSIRF）取代了此前的严重事件框架，重点从按固定阈值调查单个事件，转向由各机构选择相称的、基于系统的学习应对，并让患者、家属和员工参与。
:::

报告率高通常表明安全文化健康，而不是医疗不安全：当员工相信报告会带来学习而不是惩罚时，他们才会报告。一个从不报告事件的科室，比一个报告很多轻微事件的科室更令人担忧。

调查使用**时间线**、**鱼骨图（因果图）**等工具，以及考察任务、团队、环境、设备和组织的结构化框架，而不是停留在犯下最后一个错误的人身上。

### 公正文化

::: definition 公正文化 {#def-just}
**公正文化**是这样一种文化：人们不因无心之失或超出其控制的系统失效而受到指责，并被鼓励报告这些事件；同时，**鲁莽行为**（有意识地无视重大且不合理的风险）和蓄意伤害是不能容忍的。NHS的《公正文化指南》（*Just Culture Guide*，2018年）就个人的行为提出一系列问题：是否有伤害的意图？当事人是否因疾病或物质而能力受损？是否偏离了既定程序？其他受过同样培训的人在同样情况下是否也会这样做（**替代测试**）？是否存在减轻责任的情况？
:::

公正文化不是“不追责”文化。它区分**人为差错**（需要支持和系统改变）、**冒险行为**（逐渐滑向不安全的习惯，需要辅导并消除走捷径的诱因）和**鲁莽行为**（可能需要纪律处分）。

### 对患者坦诚

当出了差错时，患者和家属希望知道发生了什么，得到道歉，并确信这种事不会发生在别人身上。

::: definition 坦诚义务 {#def-candour}
英国的每一位医疗专业人员都负有**职业坦诚义务**：当患者的医疗出了差错并造成或可能造成伤害或痛苦时，要对患者开诚布公；道歉；提供适当的补救或支持；并充分解释短期和长期的影响。在英格兰，在医疗质量委员会（Care Quality Commission）注册的医疗服务机构还负有**法定坦诚义务**（《2008年卫生和社会照护法（受监管活动）2014年条例》第20条，Regulation 20 of the Health and Social Care Act 2008 (Regulated Activities) Regulations 2014），要求它们在发生须通报的安全事件后告知当事人、提供支持、陈述事实经过、道歉，并以书面形式跟进。道歉并不等于承认法律责任。
:::

::: example 告诉患者发生了差错 {#ex-candour}
Williams女士，59岁，被注射了一剂本应给邻床患者的依诺肝素（enoxaparin）。她本来就在服用阿哌沙班（apixaban）。她没有出血迹象。团队应当如何应对？

::: solution
1. **确保患者安全**：评估有无出血；根据需要检查全血细胞计数和凝血功能；就监测问题征求血液科或药师的意见；如有建议，暂停下一剂阿哌沙班。
2. **及时告诉她**，当面告知，最好有上级临床医生在场：用通俗的语言解释发生了什么，真诚地道歉（“非常抱歉，您被注射了一针本应给别人的药”），解释可能的影响以及将如何监测，并回答她的问题。
3. 在当地系统中**报告**这一事件，它将汇入LFPSE。
4. **跟进**：根据法定义务，以书面形式确认这次谈话，包括道歉以及调查或学习应对将涉及的内容，并与她分享调查结果。
5. **学习**：审视系统，而不只是那位护士：给药时的患者身份识别（是否核对了腕带，是否使用条形码扫描？）、工作负荷，以及患者药物的存放方式。为涉事员工提供支持，他们往往也很痛苦（“第二受害者”）。
:::
:::

## 质量改进

质量改进（QI）是系统地运用各种方法，使医疗更安全、更有效、更以患者为中心、更及时、更高效、更公平。

::: definition 改进模型与PDSA循环 {#def-pdsa}
由Langley等人提出、并由美国医疗改进研究所（IHI）推广的**改进模型**（Model for Improvement）提出三个问题：

1. 我们想要实现什么？（一个具体、可衡量的目标。）
2. 我们怎么知道某个改变是一种改进？（测量指标。）
3. 我们可以作出哪些能带来改进的改变？（改变的设想。）

改变通过小规模、快速的**计划–执行–研究–行动（PDSA）**循环来检验：计划一次测试，小规模执行，把结果与预测相比较进行研究，然后采取行动：采纳、调整或放弃这一改变。测量指标分三类：**结局指标**（对患者的结果）、**过程指标**（各步骤是否被执行）和**平衡指标**（对其他方面的非预期影响）。
:::

改进数据通常用**趋势图**（运行图）或**统计过程控制图**按时间展示，因为对两个数字作前后比较无法区分真正的变化和普通的变异。一条常用的趋势图规则是：**连续六个或更多的点都在中位数之上或都在中位数之下**，表明出现了非随机的**偏移**。

::: example 改进静脉血栓栓塞风险评估 {#ex-pdsa}
在一个入院病房，只有62%的患者在入院后14小时内记录了静脉血栓栓塞风险评估。设计一个改进项目。

::: solution
**目标**：六个月内，95%的入院患者在入院后14小时内记录VTE风险评估。

**测量指标**：过程指标（每周在14小时内完成评估的患者百分比，绘制在趋势图上）；结局指标（医院相关VTE，在较长时间内追踪）；平衡指标（入院记录所需时间；出血风险高的患者接受不适当的预防措施）。

**改变的设想与PDSA循环**：
- 循环1：在一个班次中，把VTE评估设为电子入院记录模板的必填项，试行一周；研究完成情况和医生的反馈；加以调整。
- 循环2：在收治后查房核查表中加入VTE评估核查；先在一个主任医师团队中测试。
- 循环3：每天为当班护士长直观显示尚未完成评估的患者。

**研究**：把每周数据绘制在趋势图上，寻找偏移（连续六个点高于基线中位数）。推广有效的改变，放弃无效的改变。让从事这项工作的人参与设计改变。
:::
:::

### 安全-I与安全-II

传统的安全思维（有时称为**Safety-I**，安全-I）把安全定义为没有伤害，主要从出错的事情中学习。由Erik Hollnagel提出的**Safety-II**（安全-II）则补充研究为什么事情通常会顺利：员工如何适应不断变化的需求、人员配置和设备，从而保障患者安全。从日常工作中学习，包括了解是什么造就了顺利的一天，是对从事件中学习的补充。

::: warning “更小心一点”不是安全干预
事件发生后，人们很容易得出结论：当事人本应更努力一些，然后发一份提醒。这几乎没有用，因为疏忽和遗忘会发生在细心、能干的人身上，而且这样做会打击报告的积极性。应当转而问：是什么使这个差错成为可能？什么能使它难以重演？寻找潜在条件，并选择可行的最强控制措施。对于鲁莽行为，个人问责仍然重要，但这种情况并不常见。
:::

::: quiz
一位护士在11:00才给患者8:00应给的抗生素，因为病房唯一一把药车钥匙在另一位护士身上，而她正护送一位患者去放射科。最恰当的分类和应对是什么？
- [ ] 违规；应对这位护士进行纪律处分。
- [ ] 基于知识的错误；这位护士需要重新培训。
- [x] 主要由潜在条件造成的延误；应当修正取用药物的系统。
- [ ] 不算事件，因为没有造成伤害。
::: solution
这位护士的做法是合理的；延误源于一个潜在条件（只有一把钥匙，没有备用，持钥匙者离开病房时没有相应流程）。它仍应作为事件报告，因为抗生素延误可能造成伤害，而同样的薄弱环节还会再次出现。解决办法在系统：一种不依赖于某一个人的钥匙或取药系统。
:::
:::

::: history
1847年，维也纳的**塞麦尔维斯（Ignaz Semmelweis）**证明，医生在检查产妇前用漂白粉溶液洗手后，产褥热导致的死亡大幅下降；他的同事们大多拒绝接受这一发现。19世纪50年代，**南丁格尔（Florence Nightingale）**利用克里米亚战争的死亡统计数据倡导卫生改革；20世纪10年代，波士顿的**Ernest Codman**呼吁医院公布每一位患者的结局。现代患者安全运动始于**哈佛医疗实践研究**（1991年）、**詹姆斯·里森（James Reason）**的《人为差错》（*Human Error*，1990年）和美国医学研究所的《人非圣贤，孰能无过》（1999年）。世界卫生组织于2004年成立了世界患者安全联盟，并于2008年推出手术安全核查表。在英国，**Francis报告**（2013年）等对中斯塔福德郡NHS基金会信托医院失职问题的调查，促成了法定坦诚义务的确立。
:::

## 后续内容

患者安全贯穿本课程的每一章：沟通（[[clinical-skills/communication]]）、诊断推理（[[clinical-skills/clinical-reasoning]]）、检查结果（[[clinical-skills/laboratory-tests]]），以及病历与交接（[[clinical-skills/records-handover]]）。用药安全在[[pharmacology/adverse-reactions]]中展开，手术安全在[[surgery/perioperative-care]]中展开，职业监管见[[medical-ethics-law/professionalism-regulation]]。

::: summary
- 医疗造成的伤害很常见（按世界卫生组织的估计，约十分之一的患者），其中许多是可以预防的。
- 区分安全事件、不良事件、差错、未遂事件和可预防的伤害；报告未遂事件。
- 差错分为疏忽、遗忘、错误（计划失误）和违规；每一类需要不同的补救措施，疏忽和遗忘要靠设计而不是劝诫来减少。
- 瑞士奶酪模型区分显性失误和潜在条件；当多道防线上的薄弱环节排成一线时，伤害就会发生。
- 优先采用强控制措施（强制功能、自动化、标准化），而不是弱措施（提醒、单纯培训）。
- 世界卫生组织手术安全核查表等核查表，只有在引发真正的团队交流时才有效。
- 在英格兰，事件通过LFPSE报告，并按PSIRF作出应对；公正文化把人为差错与鲁莽行为区分开来。
- 专业人员和医疗机构负有坦诚义务：告知患者、道歉、提供支持并跟进。
- 运用改进模型、小规模PDSA循环、结局、过程和平衡指标以及趋势图来推动改进。
:::

## 习题

::: exercise 为差错分类 {level=1}
把下列各项归为疏忽、遗忘、基于规则的错误、基于知识的错误或违规：(a)一位医生本想给Smith先生开药，却在屏幕上选了Smyth先生；(b)一位护士被叫走后忘了给14:00的药；(c)一位医生不知道某药在肾衰竭时需要减量，开了常规成人剂量；(d)由于夜间只有一名注册护士，员工常规性地跳过管制药品的第二次核对。
::: solution
(a)疏忽（计划好的行动中的注意力失误）。(b)遗忘（记忆失误）。(c)基于知识的错误（因缺乏知识而计划错误）；带有肾功能剂量核查的决策支持会有帮助。(d)由潜在条件驱动的常规（情境）违规：人员配置使规则无法遵守。应对措施是改变人员配置或程序，而不仅仅是重申规则。
:::
:::

::: exercise 防线的层数 {level=1 check="0.1^3"}
一个危险必须穿过三道相互独立的防线，每道防线有10%的时间失效。它穿过全部三道防线的概率是多少？给出精确值。
::: solution
$0.1^3 = 0.001$，即千分之一。如果某个共同的潜在条件（例如人员不足）使失效相互关联，真实的概率可能高得多。
:::
:::

::: exercise 用数字看核查表 {level=2 check="round(1/(0.015-0.008))"}
在2009年的核查表研究中，院内死亡率从1.5%降至0.8%。如果这一差异完全归因于核查表，需要多少台手术使用核查表才能避免一例死亡？四舍五入到整数。
::: solution
绝对风险降低$= 0.015 - 0.008 = 0.007$。$1/0.007 = 142.9$，四舍五入为**143**台手术。相对降低为$0.007/0.015 \approx 47\%$。由于该研究是前后对照，真实的因果效应并不确定，可能更小。
:::
:::

::: exercise 强还是弱 {level=2}
把下列针对一起给药途径错误事件的应对措施按由强到弱排序，并说明理由：(a)发一封邮件提醒员工注意相关政策；(b)为脊髓用装置引入无法与静脉管路连接的接头；(c)给药前的双人核对程序；(d)强制性的网络学习课程。
::: solution
最强：(b)，一种在物理上使差错不可能发生的强制功能。其次：(c)，一项增加了一道防线的核对，但它依赖于注意力和人员配置。较弱：(d)，培训可能改变知识，却改变不了造成大多数给药途径错误的疏忽。最弱：(a)，提醒很快就会被遗忘。实际中会把几种措施结合起来，但只要有强制功能，就应首先采用。
:::
:::

::: exercise 一张趋势图 {level=2}
某病房12周内每周记录了跌倒风险评估的患者百分比为：60、58、64、61、59、63、70、74、72、77、75、79。第7周开始时引入了新的入院核查表。基线（第1~6周）中位数为60.5。有偏移的证据吗？
::: solution
从第7周起，连续六个点（70、74、72、77、75、79）都高于基线中位数60.5。按照常用的趋势图规则（连续六个或更多的点在中位数的同一侧），这是一次**偏移**，提示与核查表同时出现了非随机的改进。继续测量以观察是否得以维持，并检查一个平衡指标（例如花在入院文书上的时间）。
:::
:::

::: exercise 公正文化 {level=2}
运用替代测试讨论以下两种情况：(a)一位独自负责三个病房的药师，在工作负荷极高的时段漏掉了两种药物之间的相互作用；(b)一位医生不顾警告，屡次无视医院关于出院前必须亲自查看患者的规定，导致一位患者受到伤害。
::: solution
(a)其他受过同样培训的药师在同样情况下是否也会犯同样的错误？很可能会：工作负荷和覆盖范围是潜在条件。这是在一个使差错很可能发生的系统中的人为差错；应对措施是支持这位药师并改变系统（人员配置、相互作用提示）。(b)不顾警告、反复有意地偏离一条重要的安全规则，提示存在冒险行为甚至鲁莽行为。替代测试很可能显示大多数同行不会这样做。应对措施可能包括绩效管理，同时仍要追问系统中是否有什么因素助长了这种行为。
:::
:::

::: exercise 设计一次学习应对 {level=3}
在某外科病房，两个月内有三位患者在术后接受大量低渗静脉液体后发生严重低钠血症。按照PSIRF，概述一次相称的学习应对，包括应让哪些人参与，以及应考察哪些系统因素。
::: solution
把这一规律视为一个主题，而不是三个孤立的事件，并选择基于系统的学习应对（例如开展主题回顾，或以行动后回顾为改进计划提供依据）。让患者或其家属参与（并提供坦诚义务谈话），以及病房护士、开具补液医嘱的初级医生和麻醉医生、药师和液体治疗负责人。考察：病房储备的液体以及电子处方中的默认选项（低渗液体是不是最容易选的？）；当地补液指南及其与国家指南的一致性；术后对血钠和出入量的监测；对轮转员工的培训和入职引导；非工作时间的处方；以及补液计划的交接。可能的强措施：限制低渗液体的储备，使处方默认选项与指南一致，以及自动提示监测血钠。用过程指标（24小时内检测血钠）和结局指标（术后低钠血症发生率）衡量效果。
:::
:::

::: exercise 一个被遗漏的结果 {level=3}
一份显示可能为肺癌的CT报告被发给了一位已轮转到另一家医院的初级医生。患者五个月后才被告知。分析其中的潜在条件并提出系统改变，并解释为什么每项改变都比“医生必须查看自己的检查结果”更有力。
::: solution
潜在条件：检查结果发给个人而不是团队或主任医师；医生轮转时结果不会重新分配；系统不要求确认报告；对危急或重要发现没有提示；出院小结没有列出待出的检查；以及跨越轮转边界依赖于记忆。系统改变：把结果发送给负责的主任医师和团队收件箱；要求电子确认，对在规定时间内未确认的重要结果逐级上报；为疑似癌症设立放射科提示路径，直接通知指定的团队（例如肺癌快速通道协调员）；轮转时自动重新分配结果；在出院小结中列出待出的结果并指定负责人。每一项改变在个人忙碌、缺席或遗忘时依然有效，而这恰恰是最初差错发生时的情形。必须及时告知患者，并根据坦诚义务向其道歉。
:::
:::
