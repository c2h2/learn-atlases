病史是患者对自身疾病的叙述，由临床医生收集并加以组织。它是医学中最古老、至今仍最有力的诊断工具。在1975年发表的一项经典英国研究中，对内科门诊新患者，仅凭转诊信和病史就在80例中的66例得出了最终诊断；体格检查又帮助了另外7例，实验室检查帮助了另外7例。此后在其他场合进行的研究发现了同样的规律。当病史已经告诉你要找什么时，检查才最有用。

本章阐述病史的标准结构、各部分所需的细节、常见主诉的重点病史，以及如何向同事汇报病史。它建立在[[clinical-skills/communication]]所述的问诊技能之上。

## 病史的结构

病史有约定俗成的顺序。这个顺序并不是每次谈话都必须遵循的顺序：患者会用自己的方式讲述，急诊病史可能只是几个有针对性的问题。这一结构是一份核对清单，列出必须涵盖的内容，也是书写和汇报的模板。

::: definition 病史的组成部分 {#def-structure}
完整的病史包括以下部分：

1. **主诉（PC）**：主要问题，尽可能用患者自己的话，并注明持续时间（“胸痛2小时”）。
2. **现病史（HPC）**：对问题及相关症状的详细叙述，包括相关的阳性和阴性表现。
3. **既往内外科病史（PMH）**：以往的疾病、手术、住院和长期疾病。
4. **用药史（DH）**：所有现用药物，包括非处方药和草药制品，以及剂量、依从性，和注明反应性质的**过敏史**。
5. **家族史（FH）**：一级亲属的疾病及任何遗传性疾病。
6. **社会史（SH）**：职业、居住情况、功能状态、吸烟、饮酒和其他药物使用、驾驶，以及由谁提供支持。
7. **系统回顾（SR）**：简要筛查此前未涉及的各身体系统的症状。

患者的**想法、担忧和期望**与现病史一起探询（[[clinical-skills/communication#def-ice]]）。
:::

### 主诉与现病史

现病史是大部分诊断工作发生的地方。先用开放式的邀请（“请从头讲讲这次疼痛”），让患者讲完整个经过，再用聚焦的问题补充细节。

对任何症状，都要确定其**时间进程**：何时开始，起病是突然还是逐渐，持续性还是间歇性，正在好转、加重还是没有变化。疾病的节奏是判断病因最有力的线索之一。在一分钟内达到最大强度的头痛提示血管事件；数周内缓慢加重的头痛提示占位或颅内压增高；多年来以同样模式反复发作的头痛通常是原发性头痛。

对于疼痛，口诀**SOCRATES**提供了一份实用的清单。

::: definition SOCRATES {#def-socrates}
疼痛（经适当调整后，也包括许多其他症状）的特征包括：

- **S**ite（部位）：在哪里；请患者指出来。
- **O**nset（起病）：何时、如何开始（突然还是逐渐；当时在做什么）。
- **C**haracter（性质）：感觉如何（锐痛、钝痛、烧灼痛、压榨痛、绞痛）。
- **R**adiation（放射）：是否向别处放射。
- **A**ssociated symptoms（伴随症状）：如恶心、出汗、气促、发热。
- **T**ime course（时间进程）：持续时间、规律、频率、以往发作。
- **E**xacerbating and relieving factors（加重与缓解因素）：活动、呼吸、进食、体位、休息、药物。
- **S**everity（严重程度）：常以0到10分评分，以及对活动和睡眠的影响。
:::

**相关阴性表现**与阳性表现同样重要。如果记录只写“胸痛”，而没有说明是否有气促、出汗或呼吸时疼痛，读者就无法判断心脏病发作或肺栓塞的可能性。危险诊断中本应出现的某一特征缺如，是反对该诊断的证据；本来就常常缺如的特征缺如，则是薄弱的证据。[[clinical-skills/clinical-reasoning]]用似然比把这一点讲得更精确。

每份病史还需要检查**危险信号**：提示存在需要紧急处理的严重病因的特征。

::: definition 危险信号 {#def-redflags}
**危险信号**（red flag）是病史或体格检查中的这样一种特征：它使严重的、有时间紧迫性的诊断的概率升高到足以改变处理的程度，通常是促使紧急检查或转诊。危险信号因主诉而异。例如：

- **头痛**：突然起病、约一分钟内达到最大强度（雷击样）；新发头痛伴发热和颈项强直；新发头痛伴神经系统体征；癌症或免疫抑制患者的新发头痛；50岁以上者新发头痛伴下颌跛行或头皮触痛。
- **背痛**：双侧或交替出现的腿痛、鞍区麻木、新发膀胱或肠道功能障碍（可能为马尾综合征）；癌症病史、发热或免疫抑制、不明原因体重下降，以及胸背部疼痛。
- **消化不良**：吞咽困难、体重下降、呕吐、消化道出血或缺铁性贫血，尤其是年龄较大者。
:::

::: warning 危险信号筛查阴性不等于病情安全
危险信号是行动的提示，而不是一项完整的检查。许多患有严重疾病的患者首次就诊时并没有任何典型危险信号，而大多数有危险信号的患者并没有那种严重疾病。应把危险信号作为最低限度的筛查，结合整体情况判断，并在诊断不确定时始终做好安全网。
:::

### 既往病史

询问长期疾病、以往住院、手术和麻醉（以及其中出现的任何问题），以及重要的既往疾病，如风湿热、结核病或黄疸。对每种疾病，有几项细节很有用：何时诊断、如何治疗、控制得如何。“糖尿病”远不如“2型糖尿病12年，用二甲双胍和胰岛素，最近一次HbA1c 64 mmol/mol，伴视网膜病变”信息丰富。

患者可能不把某些疾病当作病，因此要专门询问常见病：心脏病、高血压、卒中、糖尿病、哮喘或慢阻肺、癫痫、肾脏或肝脏疾病、癌症和精神健康问题。对女性，在相关时询问妊娠情况；产科病史见[[obstetrics-gynaecology]]。

### 用药史与过敏史

用药史是病历中对安全最关键的部分之一，因为这里的错误会传递到处方中。它应列出每种药物的**名称、剂量、途径、频次**，必要时注明**适应证**。要专门询问患者可能不会主动提到的药物：吸入剂、滴眼液、外用药膏、在门诊注射的药物（如长效抗精神病药或每月一次的维生素B12）、非处方止痛药、草药和传统疗法，以及娱乐性药物。询问患者实际是怎样服药的，因为处方和实际服用常有差别。

::: definition 过敏与不耐受 {#def-allergy}
**药物过敏**是对药物的免疫介导反应，如荨麻疹、血管性水肿、支气管痉挛或严重过敏反应，或迟发的严重皮肤反应。**药物不耐受**或**副作用**是可预见的非免疫性效应，如阿片类引起的恶心或抗生素引起的腹泻。对每一个报告的反应，都要记录**药物**、**反应性质**、**发生时间**及处理方式。“青霉素：过敏”远不如“青霉素：2014年出现全身瘙痒性皮疹伴口唇肿胀，在急诊处理”有用。
:::

这一区分很重要。许多被标记为“青霉素过敏”的人在检测后并不过敏，而这个标签会导致使用广谱或效果较差的抗生素。反过来，真正的过敏如果只记为“不耐受”，可能被忽视。药物重整，即入院时比较来自多个来源的用药史，见[[clinical-skills/records-handover]]。

### 家族史

询问父母、兄弟姐妹和子女的健康状况，包括他们的年龄和死因。有些疾病需要专门询问：早发心脏病（按常用约定，男性一级亲属55岁以前或女性一级亲属65岁以前）、年轻亲属不明原因猝死、乳腺癌、卵巢癌和肠癌、糖尿病，以及家族中的遗传病。怀疑遗传病时要画出三代**系谱图**；[[genetics/mendelian-inheritance]]介绍如何解读。

### 社会史

社会史描述的是患病的那个人，以及疾病对其生活意味着什么。要涵盖的方面：

- **职业**，过去和现在，包括暴露（石棉、粉尘、化学品、动物），以及疾病如何影响工作。
- **居住**：与谁同住、住房类型（楼梯、适老化改造），以及照护责任，包括照顾儿童和需要依赖的成年人。
- **功能状态**：患者能自己做什么（洗漱、穿衣、做饭、购物、步行距离），是否有照护者或照护套餐，以及手杖等辅助用具。
- **吸烟**：现在还是过去吸，吸烟量和持续时间，以**包年**表示。
- **饮酒**：以**单位**表示的饮酒量和饮酒模式，以及依赖的迹象。
- **其他药物**：以不带评判的方式询问娱乐性药物的使用及途径。
- 相关时询问**驾驶**、旅行、宠物和饮食。

::: definition 包年数与酒精单位 {#def-units}
**包年数**衡量一生的烟草暴露量：

$$
\text{包年数} = \frac{\text{每天吸烟支数}}{20} \times \text{吸烟年数}。
$$

1包年相当于每天20支、吸一年。肺癌和慢阻肺的风险随包年数增加而升高。

在英国，1个**酒精单位**是10 mL（约8 g）纯乙醇。一份饮品所含的单位数为

$$
\text{单位数} = \frac{\text{容量（mL）} \times \text{ABV（\%）}}{1000}，
$$

其中ABV是酒精体积分数。自2016年起，英国首席医疗官的低风险饮酒指南是：男性和女性都不应经常每周饮酒超过**14个单位**，且应分散在三天或更多天中。
:::

::: example 计算暴露量 {#ex-exposure}
一位60岁男性说他“从18岁起每天大约吸30支”，并且“大多数晚上喝四品脱5%的拉格啤酒，周末喝得更多”。如果把“大多数晚上”按每周五晚计算，求他的包年数和每周最低饮酒量。英国1品脱为568 mL。

::: solution
**包年数。** 他每天吸30支，已吸$60 - 18 = 42$年：$\dfrac{30}{20} \times 42 = 63$包年。

**饮酒。** 一品脱5%的拉格啤酒含$\dfrac{568 \times 5}{1000} = 2.84$个单位。四品脱含$4 \times 2.84 = 11.36$个单位。每周五晚为$5 \times 11.36 = 56.8$个单位，周末还更多，因此每周至少约57个单位，是低风险指南的四倍。

他发生与吸烟相关的肺病和癌症的风险很高；他的饮酒情况需要一次不带评判的谈话，筛查是否存在依赖（例如用AUDIT问卷），并在他住院时注意戒断风险。
:::
:::

### 系统回顾

系统回顾是对现病史未涉及的各系统症状的快速筛查。它能发现患者认为无关的问题，偶尔会彻底改变诊断：一位因背痛就诊、在系统回顾中发现体重下降和盗汗的患者，与没有这些症状的患者，问题是不同的。典型的筛查询问：

- **一般情况**：体重下降、发热、盗汗、乏力、食欲。
- **心血管**：胸痛、心悸、劳力性或平卧时气促、踝部水肿、跛行。
- **呼吸**：咳嗽、咳痰、咯血、喘鸣。
- **消化**：吞咽困难、消化不良、恶心呕吐、排便习惯改变、便血、黄疸。
- **泌尿生殖**：尿频、排尿困难、血尿；相关时询问月经史和性生活史。
- **神经**：头痛、抽搐或晕厥、无力、麻木、视觉改变。
- **肌肉骨骼与皮肤**：关节痛、僵硬、皮疹、肿块。
- **情绪**：情绪低落、焦虑、睡眠。

保持简短，使用通俗的词语。如果重要的阳性发现属于同一问题，就把它记录在现病史中。

## 重点病史

实际工作中，大多数病史是**重点病史**：临床医生很早就形成假设，并提出最能在各假设之间作出区分的问题。这并不等于草率的病史。重点病史仍然涵盖整个结构，但把时间花在诊断不确定的地方。

::: theorem 以假设为导向的病史采集 {#thm-hypothesis}
专家的病史采集遵循一个循环：开场叙述中的早期线索产生少数几个**假设**；随后选择用来**区分**这些假设的问题（使一个假设可能性升高、另一个降低），而不是收集每一个可能的事实；随着回答的到来修正假设；并刻意检查**不可漏诊的危险诊断**，即使它们看起来不太可能。
:::

::: proof 为什么区分性问题效率高 {#prf-hypothesis}
一个问题只有当其答案会改变所考虑诊断之间的相对概率时才有用。在每个候选诊断中都同样常见的特征（例如胸痛患者的“疼痛”）不携带任何信息。在一种诊断中常见、在其他诊断中少见的特征（如胸膜炎与心绞痛相比，吸气时疼痛）则会强烈改变概率。选择这样的问题，可以用更少的步骤得出工作诊断。刻意进行“不可漏诊”的检查，是为了防范这一方法的主要弱点：错误的早期假设可能使所提的问题产生偏倚，这一问题在[[clinical-skills/clinical-reasoning]]中作为过早下结论加以讨论。
:::

### 胸痛

急性胸痛最常见的严重病因是急性冠脉综合征、肺栓塞、主动脉夹层、气胸和食管破裂。常见的较轻病因包括肌肉骨骼痛、胃食管反流和焦虑。

需要询问的区分性特征：

- **性质和部位**：胸骨后、沉重或紧缩感提示心肌缺血；锐痛、呼吸时加重（胸膜性）提示胸膜炎、肺栓塞、气胸或心包炎；突发撕裂样痛并向背部放射提示主动脉夹层。
- **起病及与用力的关系**：用力诱发、休息数分钟内缓解的疼痛是稳定型心绞痛的典型表现；静息时疼痛持续超过15~20分钟，应警惕急性冠脉综合征。
- **伴随特征**：心源性疼痛伴出汗、恶心和气促；肺栓塞伴腿肿、近期手术、制动或咯血；肺炎伴发热和咳嗽。
- **危险因素**：冠心病的危险因素有年龄、吸烟、糖尿病、高血压、高胆固醇和家族史；静脉血栓栓塞的危险因素有近期制动、手术、癌症、妊娠和既往血栓；夹层的危险因素有高血压和结缔组织病。

女性、老年人和糖尿病患者发生急性冠脉综合征时，更常没有典型的胸骨后胸痛，而表现为气促、乏力、恶心或上腹不适。病史与教科书描述不太相符，并不能排除这一诊断。

::: example 胸痛的重点病史 {#ex-chestpain}
Adeyemi女士，58岁，一小时前在园艺劳作时出现胸痛。概述重点病史，以及每个回答如何改变鉴别诊断。

::: solution
**开场。** 她描述为胸骨后沉重的压迫感，“像胸口压了块重物”，放射到左臂和下颌，伴出汗和恶心。休息后没有缓解。

**区分性问题及其作用。**
- 是否突然起病、呈撕裂样并穿透到背部？否。这降低了夹层的可能性。
- 吸气时或按压胸部时是否加重？否。胸膜性疼痛和可复现的胸壁痛的可能性降低。
- 近期有无旅行、手术、腿肿或咯血？无。肺栓塞可能性较低，但并未排除。
- 以前用力时有过类似疼痛吗？有，三周来上坡时出现，数分钟内缓解。这提示原有的心绞痛现在已变为静息痛。
- **危险因素**：吸烟25包年，2型糖尿病，父亲52岁时心脏病发作。

**工作结论。** 病史强烈提示急性冠脉综合征。下一步要立即进行：10分钟内完成心电图，测量生命体征，并按当地急性冠脉综合征路径进行评估和治疗，检测肌钙蛋白。在任何检查结果出来之前，病史已经决定了紧急程度。
:::
:::

### 气促

询问**节奏**（数秒到数分钟：气胸、肺栓塞、严重过敏反应、心律失常；数小时到数天：肺炎、哮喘、心力衰竭；数月：慢阻肺、间质性肺病、贫血、慢性心力衰竭）。用具体的说法询问**运动耐量**（“您在平地上能走多远才不得不停下？”），询问**端坐呼吸**（平卧时气促，以所用枕头数量化）和**夜间阵发性呼吸困难**（憋醒），两者都提示心力衰竭；询问**喘鸣**、咳嗽和咳痰；胸痛；腿肿；以及职业史和吸烟史。英国医学研究委员会（MRC）呼吸困难量表评估气促对功能的影响。

### 腹痛

仔细运用SOCRATES。**绞痛**（阵阵疼痛，间有缓解期）提示管腔梗阻：肠道、输尿管，较少见的是胆道。**持续性**疼痛、活动或咳嗽时加重，提示腹膜炎。**转移性**疼痛（如阑尾炎时由脐周转移到右下腹）反映了从内脏痛到壁腹膜刺激的变化。询问呕吐、排便习惯、排气、泌尿症状、黄疸；对任何可能怀孕的人询问末次月经：任何育龄女性出现腹痛都必须考虑异位妊娠。急腹症见[[surgery/acute-abdomen]]。

### 头痛

区分**原发性头痛**（偏头痛、紧张型头痛、丛集性头痛）和由其他疾病引起的**继发性头痛**。询问起病方式（是否雷击样？）、随时间的变化规律、伴随特征（先兆、呕吐、畏光、发热、颈项强直、皮疹）、神经系统症状、与体位的关系（平卧或咳嗽时加重提示颅内压增高）、药物过度使用、视觉症状和下颌跛行。完整的诊治思路见[[nervous-system/headache-pain]]。

## 特殊情况下的病史

### 旁证病史

**旁证病史**是来自患者以外的人的信息：亲属、照护者、目击者、急救人员、全科医生记录或养老院。当患者无法提供可靠病史时，例如谵妄、痴呆、意识水平下降、癫痫发作或晕倒，旁证病史必不可少；在许多其他情况下也很有用。目击者对一次晕倒的描述（脸色苍白吗？有抽动吗？没有反应多久？之后是否意识模糊？）往往是区分晕厥和癫痫发作最有价值的一条证据。保密原则仍然适用：你可以听取亲属的叙述而不透露信息；患者有决策能力时，应征得其同意后再分享信息。

::: example 一位意识混乱的老年男性 {#ex-collateral}
Hughes先生，84岁，因“糊涂了”被救护车从家中送来。他说不清发生了什么。应如何获取病史？哪些问题最重要？

::: solution
与最了解他的人（他的女儿，通过电话）交谈，并查看全科医生记录和救护车记录。关键问题是：**他平时的认知状态如何，变化有多快？**女儿说他平时生活自理，自己购物，自己管理药物；两天来他变得糊涂，白天嗜睡，夜间躁动。急性变化、病情波动和注意力不集中提示**谵妄**，而不仅仅是痴呆。

然后寻找病因：新出现的症状（咳嗽、泌尿症状、跌倒、疼痛、便秘、尿潴留）、药物变化（新用阿片类或抗胆碱能药物，漏服或多服一剂）、饮酒以及近期疾病。她说他一周前开始服用一种治疗膀胱症状的新药，并且一直在咳嗽。两者都可能是诱因。旁证病史把问题从“意识混乱”变成了“急性谵妄，可能原因为感染和一种抗胆碱能药物”，这指引了体格检查和辅助检查。谵妄见[[geriatrics-palliative/delirium-dementia-care]]。
:::
:::

### 老年人

对老年人，病史应包括**功能史**（活动能力、跌倒、日常生活活动）、认知、排尿排便控制、营养、社会支持，以及仔细的用药回顾，因为多重用药很常见，本身就可能导致跌倒和意识混乱等表现。疾病常表现不典型：感染可能表现为跌倒或意识混乱，而不是发热。这些主题在[[geriatrics-palliative/ageing-frailty]]中展开。

### 儿童

儿科病史通常由父母或照护者提供，对青少年还应在问诊的部分时间单独与其交谈。儿科病史增加了**出生史**（胎龄、出生体重、新生儿期问题）、**发育史**、**预防接种史**、喂养和生长情况，以及家庭和社会背景，包括儿童保护方面的顾虑。见[[paediatrics]]。

### 敏感话题

有些方面需要特别小心：**性生活史**、**家庭暴力**、**精神健康**、**自伤**和**物质使用**。说明你为什么要问（“这些问题我对每个人都会问，因为它们可能影响健康”），在私密环境中询问，用平实、不带评判的词语，不对性取向、性别或伴侣关系作任何假定。关于家庭暴力，要在与患者单独相处时直接询问（“您在家里感到安全吗？”），并了解当地的支持途径。关于自伤和自杀念头，直接询问并不会增加风险，而且是每一次精神健康评估的组成部分；要以关怀的态度回应，并遵循当地关于评估和支持的指引（[[psychiatry/self-harm-suicide-prevention]]）。

## 汇报病史

向上级同事清晰地汇报患者是一项核心技能。好的汇报简短、有条理，以评估和一个问题或计划结尾。一种广泛使用的格式是：

1. **一句话开场**：姓名、年龄、主诉及持续时间。
2. **现病史**，包括关键阳性和相关阴性表现。
3. **相关背景**：既往史、用药和过敏、家族史和社会史，只讲与问题有关的部分。
4. **体格检查所见**（检查后汇报时）。
5. **总结与评估**：一句话总结和你的鉴别诊断，最可能的诊断放在最前面，并点明危险的其他可能。
6. **计划或问题**。

::: example 汇报Adeyemi女士 {#ex-present}
把[[#ex-chestpain]]中的病史像向住院总医师汇报那样讲出来。

::: solution
“Adeyemi女士，58岁，胸骨后胸痛1小时。在园艺劳作时发作，呈沉重感，放射到左臂和下颌，伴出汗和恶心。休息后没有缓解。三周来有类似的劳力性疼痛，数分钟内缓解。疼痛不是胸膜性的，也不是撕裂样的，没有肺栓塞的症状。背景：2型糖尿病，服用二甲双胍，无已知药物过敏，吸烟25包年，父亲52岁时心肌梗死。总之，这是一位有多个危险因素的58岁女性，渐进性心绞痛进展为静息痛，所以我担心是急性冠脉综合征。心电图正在做。您能和我一起去看看她吗？”

这段汇报不到一分钟，包含了相关阴性表现，并以一个具体的请求结尾。
:::
:::

::: quiz
一位30岁女性因剧烈头痛就诊。病史中哪一个特征最强烈地要求紧急排查蛛网膜下腔出血？

::: history
采集和记录病史与临床医学一样古老。希波克拉底的《流行病》逐日记录个别患者的情况；以弗所的鲁弗斯（Rufus of Ephesus，约公元100年）写了一篇短文《医学问题》（*Medical Questions*），认为询问患者能揭示检查所不能发现的东西。在19世纪和20世纪初，结构化的病例病史成为床旁教学的核心，最著名的是**奥斯勒（William Osler）**在约翰斯·霍普金斯医院推行的临床见习制度，学生在那里自己采集并汇报所管患者的病史。1975年，**John Hampton**及其同事测量了病史的贡献，表明在大多数内科门诊新患者中，病史导出了最终诊断；后来的研究重复了这一发现。
:::

## 后续内容

病史产生的假设由体格检查加以检验（[[clinical-skills/physical-examination]]），并由辅助检查证实或排除（[[clinical-skills/clinical-reasoning]]、[[clinical-skills/laboratory-tests]]）。专科病史，例如精神科病史和精神状况检查（[[psychiatry/psychiatric-assessment]]），建立在同一结构之上。

::: summary
- 病史通常提供诊断所需的大部分信息；在病史明确了问题之后，检查才最有用。
- 标准结构为主诉、现病史、既往史、含过敏史的用药史、家族史、社会史和系统回顾，同时探询患者的想法、担忧和期望。
- 确定每个症状的时间进程；用SOCRATES描述疼痛；记录相关阴性表现，并检查与主诉相关的危险信号。
- 记录过敏史时注明反应性质，并区分过敏与不耐受。
- 用包年数量化吸烟，用单位数量化饮酒（每周14个单位是英国的低风险指南）。
- 专家采集以假设为导向的重点病史，并刻意检查不可漏诊的危险诊断。
- 当患者无法提供可靠叙述时，采集旁证病史；针对老年人、儿童和敏感话题调整病史采集方式。
- 汇报要简洁：一句话开场、含相关阴性表现的现病史、相关背景、带鉴别诊断的总结，以及计划或问题。
:::

## 习题

::: exercise 包年数 {level=1 check="22.5"}
一位女性每天吸15支烟，吸了30年后戒烟。这是多少包年？给出精确数值。
::: solution
$\dfrac{15}{20} \times 30 = 0.75 \times 30 = 22.5$包年。戒烟不会减少包年数，但戒烟后她的风险会随时间下降。
:::
:::

::: exercise 一瓶酒的单位数 {level=1 check="9.75"}
一瓶750 mL、ABV 13%的葡萄酒含多少英国酒精单位？给出精确数值。
::: solution
$\dfrac{750 \times 13}{1000} = 9.75$个单位。每周喝两瓶（19.5个单位）就已超过14个单位的低风险指南。
:::
:::

::: exercise 过敏还是不耐受 {level=1}
对下列报告的反应分类，并说明你将如何记录：(a)“可待因让我便秘”；(b)“吃了阿莫西林后我起了荨麻疹，舌头也肿了”；(c)“二甲双胍让我腹泻了几周”。
::: solution
(a)不耐受（阿片类药物可预见的副作用）；记为“可待因：便秘（不耐受）”。(b)过敏（荨麻疹和血管性水肿是免疫介导的表现）；记录药物、反应、日期和处理，在正式评估之前按青霉素过敏对待。(c)不耐受（常见的、往往与剂量相关的胃肠道副作用）；如实记录。准确记录这些信息，既能避免不必要地回避有用的药物，又能防范真正的过敏。
:::
:::

::: exercise 哪些问题有区分作用？ {level=2}
一位70岁男性气促三个月。主要假设是心力衰竭和慢阻肺。列出四个有助于区分二者的问题，并说明每个回答会如何改变你的判断。
::: solution
(1)“您平躺时会气促吗？夜里会憋醒吗？”端坐呼吸和夜间阵发性呼吸困难支持心力衰竭。(2)“您注意到脚踝肿了吗？”踝部水肿支持心力衰竭，尽管它还有其他原因。(3)“您吸过烟吗？吸了多少？大多数日子都咳痰吗？”大量吸烟史伴慢性咳痰支持慢阻肺。(4)“您有过心脏病发作、高血压或心脏瓣膜问题吗？”既往缺血性心脏病提高心力衰竭的概率。两种疾病并不互相排斥：二者在老年吸烟者中都很常见，常常并存，因此病史用来指导利钠肽、心电图、超声心动图和肺功能等检查。
:::
:::

::: exercise 背痛的危险信号筛查 {level=2}
一位43岁男性搬重物后腰痛三天。写出你用来筛查马尾综合征和严重脊柱病变的问题，并说明如果他报告新出现的排尿困难，你会怎么做。
::: solution
马尾综合征：“疼痛是否沿两条腿往下走？”“屁股周围或会阴部有没有麻木，比如擦拭时？”“排尿有没有变化，比如开始排尿困难、尿流变细，或者膀胱满了也没感觉？”“有没有控制不住大便？”“性功能有没有变化？”严重病变：癌症病史、发热或全身不适、免疫抑制或注射吸毒、不明原因体重下降、持续不缓解的夜间痛、胸背部疼痛、明显外伤。在这种情况下新出现的排尿困难是马尾综合征的危险信号：他需要当天紧急评估，并按当地路径急诊行MRI，因为预后取决于减压的速度。
:::
:::

::: exercise 一周的单位数 {level=2 check="round(7*(330*4.5/1000)*3 + 2*(25*40/1000))"}
一位男性每天喝三瓶330 mL、4.5%的啤酒，每周喝一次两份25 mL、40%的烈酒。计算他每周的饮酒量（单位），四舍五入到整数。
::: solution
一瓶啤酒：$\dfrac{330 \times 4.5}{1000} = 1.485$个单位。每天三瓶、共7天：$21 \times 1.485 = 31.185$个单位。一份烈酒：$\dfrac{25 \times 40}{1000} = 1$个单位，两份共2个单位。合计$= 33.185$，四舍五入为每周**33个单位**，是低风险指南的两倍多。
:::
:::

::: exercise 一次晕倒 {level=3}
一位19岁女性在音乐会排队时晕倒。她现在感觉良好。她的朋友目睹了经过。列出你要问的旁证病史问题，并说明哪些回答提示血管迷走性晕厥、心源性晕厥或癫痫发作。
::: solution
问她的朋友：晕倒前她在做什么（长时间站立、环境闷热、疼痛、情绪激动支持血管迷走性晕厥）；她是否说过觉得热、出汗、恶心或眼前发灰（血管迷走性晕厥的前驱症状）；晕倒是否发生在运动中，或在躺着、坐着时毫无预兆地发生（提示心源性晕厥，猝死家族史同样值得警惕）；她的脸色（苍白提示晕厥）；有没有抽动、持续多久（短暂抽动在晕厥中常见；长时间有节律的抽动提示癫痫发作）；当时眼睛是否睁着；是否咬伤舌侧或尿失禁（舌侧咬伤支持癫痫发作）；无反应持续了多久；之后情况如何（迅速恢复提示晕厥；长时间意识模糊提示癫痫发作）。任何提示心源性晕厥的危险信号都需要做心电图并进一步评估。
:::
:::

::: exercise 重写一份不合格的病史 {level=3}
一份入院记录写着：“腹痛。呕吐。既往史无。无已知药物过敏。计划：抽血，复查。”找出缺失的内容，并写出为一位24岁女性补全这份病史所需的问题。
::: solution
缺失：疼痛的时间进程及SOCRATES各要素（部位、起病、性质、放射、伴随症状、时间、加重与缓解因素、严重程度）；呕吐的细节（次数、内容物、有无血或胆汁）；排便习惯和排气；泌尿症状；发热；**末次月经、妊娠可能、避孕、阴道出血或分泌物**（必须考虑异位妊娠和盆腔炎）；既往手术；真正的用药史（包括口服避孕药和已服用的止痛药）；社会史；以及患者的担忧。“既往史无”和“无已知药物过敏”应当通过直接询问加以确认。计划应写明评估（鉴别诊断）和具体检查，包括妊娠试验。
:::
:::
