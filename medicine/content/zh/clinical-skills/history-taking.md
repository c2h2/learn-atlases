病史是最古老的检查、仍是产出最高的一项：经典系列中它在多数接诊里供给诊断、而现代综述不断发现病史错误或截断时、下游每一次扫描都继承错误。**本章把病史当作有部件的技术来对待：结构（从主诉到既往史到用药、过敏、社会与家族史、带使每节成为诊断而非事务性的边问边修正问题）、主要表现的症状分析（痛、呼吸困难、咳嗽、出血、消瘦、晕厥倒仆、意识模糊及其他）、其全部目的是把常见症状变成紧急转诊的红旗清单、病史采集的认知卫生（临床推理章展开的过早闭合与可得性及锚定效应、配“还可能是什么”“什么不可漏”纪律）、及技术必须改变的人群（带发育史的儿童、带不典型表现与衰弱背景的老年人、认知障碍者、以分钟而非小时采集的急性病者、及记忆、暗示与羞愧的诚实极限）。**

## 结构

::: definition 病史的解剖 {#def-structure}
**患者自己语言的主诉、尽可能照抄、带其持续时间——将在每张后续病历被引用的句子、临床医师必须 太早翻译的冲动。现病史展开症状分析：对疼痛、SOCRATES家族清单（部位、起病、性质、放射、伴随、时间、加重缓解、强度）是脚手架不是脚本——真正判别的问题由鉴别选择（胸膜性对中央压榨、绞痛对持续、胸膜性伴气促对胸膜性伴小腿痛）、而叙述版（“从今早起告诉我”）常跑赢清单并抓住未把咯血与咳嗽联系起来的患者。既往病史是疾病关联仪器：无脾状态与关节置换及PSC伴IBD、重新分类肿胀小腿的既往VTE、数年后解释狭窄的放疗野；用药史与患者一起重构处方清单地询问（非处方与草药与伴侣的药片及瓶内余量揭露的吸入技术）、过敏被定性（真青霉素过敏对学时的皮疹——去标签规划的安全与管理红利）、及把用药相关的现症状病因过一遍常见嫌疑（NSAID与ACE抑制剂咳嗽与胺碘酮肺与他汀肌肉与意识模糊老人的抗胆碱负荷）。家族史勾画遗传学课程规范化的遗传模式（三代草图带年龄与死亡、早发心脏死亡、达到转诊标准的癌聚集、相关处敏感询问的近亲婚配）、而社会史是会诊的物理：职业与暴露、量化的吸烟与饮酒（单位、不是“社交性”；开门的AUDIT-C问题）、不带评判正常化序列的药物、家与楼梯与照护者与宠物、改变管理的驾驶与工作问题、及“什么对你要紧”——资产文献补充之、因为与生活不相容的治疗计划是会失败的计划。系统回顾是守纪律的扫描（对发热或消瘦或呼吸困难的十问网抓住没人提到的肺外结核与下颌跛行）平衡其已知代价：过度标记附带症状、所以聚焦会诊中由工作鉴别引导而非仪式执行。整体被清单抓不住的两个技能首尾包住：邀请故事的开场（不被审查的第一分钟）与核对其的结尾（“我漏掉你担心的什么了吗？”）——浮现沟通章量化隐藏议题的问题。**
:::

## 症状分析

::: definition 表现、红旗与不典型 {#def-presentations}
**症状分析是穿问题外衣的决策树。胸痛按起病与性质与放射与伴随分开紧急三联（其后的ACS、夹层、PE与张力性气胸与食管破裂）、带令人安慰的事实：年轻人的胸膜性痛通常良性、而首个肌钙蛋白正常是时间依赖非绝对的安慰。呼吸困难问时机（急性、慢性、夜间阵发）、体位（端坐、平卧）、背景（静默胸、是心脏的哮鸣、与PE共存而非排除PE的焦虑）、带咯血与消瘦与突发的红旗。咳嗽计时（使感染后咳嗽成为有日历诊断的八到三周分类）并为严重度标志审问（咯血、吞咽困难、声嘶、吸烟史、消瘦——缩微的NICE两周等待咳嗽标准）、带药物与反流与哮喘与心衰病因作为常见可治的其余。消化不良与腹部症状分析守护其红旗（适龄新发、消瘦、吞咽困难、出血、缺铁性贫血、腹部包块）因为上消化道癌在被安慰的年龄组以“烧心”就诊；大便性状改变与出血的故事把痔疮的假设对结肠被影像的权利分开、带“男性缺铁性贫血是结肠癌直到证明不是”规则。晕厥倒仆要求病史里的心脏-神经-机械分诊（先前的心悸或劳力或体位；目击者的三问——之前、之中、之后；舌咬伤与失禁的差特异度及长时间意识模糊与催乳素研究；血管迷走背景）因为心源性晕厥是在第二次就诊杀人的那种。意识模糊与记忆主诉分开谵妄（急性、波动、注意缺失、在药物与感染与代谢因中追的病因——老年分诊）与痴呆（隐匿、进展、知情者功能史的必需）与抑郁（带“你丈夫去世后改变了什么”社会扳机的可逆模仿者）、配尽早的驾驶与能力与保护问题。出血史是血液学问卷（黏膜模式与药物与家族及操作出血问题找到被漏数十年的von Willebrand病、及说出因子缺乏的深肌与关节模式）、而消瘦是伟大内科医师的提示（体质问题、食欲与大便与情绪与甲状腺与药物、带诚实数据：老人不明原因消瘦携带观察等待必须排期而非跳过的有意义癌症概率）。不典型表现不是例外而是按人群的规则：老人以跌倒与意识模糊与失禁表现教科书给疼痛的心梗与肺炎与尿；糖尿病与去神经与女性缺血表现不典型；免疫抑制者不起热；而妊娠给每个红旗重排序（高位盲肠的阑尾切除课）。**
:::

## 卫生

::: definition 认知卫生与特殊人群 {#def-hygiene}
**病史采集的失效模式先于事实是认知的。过早闭合——标签感觉足够就停止采集——是诊断错误系列里最常见贡献因素；其解毒剂刻意便宜：三个时点的“还可能是什么”提示、每个红旗类别的“什么不可漏”安全问题、及患者说“但是……”时重新问（患者的迟疑是系统的错误旗）。锚定于转诊信或分诊护士第一句、可得性偏倚于上周的罕见病例、已开检查的沉没成本、及使每个漏诊只在结局已知后才显而易见的后见——都在临床推理章编目与反制、而病史是其最便宜的捕捉处因为代价只是多一个问题。疾病脚本是专家实际的思考方式（诊断跳入脑海的模式加条件知识模型）、诚实的教学法是模式识别既是专家的荣耀也是错误的源头、所以分析性检查——“这个脚本需要其验证吗、什么能反驳它？”——与之并行演练。暗示与框架双向切割：封闭式引导问题创造症状（“会不会向下串到腿？”制造阳性病史）、而患者少报其惧怕被评判的——体重、酒精、药物、性、家庭暴力、没吃的化疗——这就是为何敏感病史用正常化前言、不带亲属私下问、明说保密边界、及依从文献回报的不带评判的声音；保护与虚构与做作性疾病与伪装领地有各自规则（绝不仅凭病史指控；逐字记录；请专科团队）而觅药表现值得与任何疼痛同样的红旗纪律（“疼痛是患者说的疼痛；计划是证据支持的计划”）。特殊人群各自重写技术：儿童（从产前超声到新生儿程到里程碑与学校报告的发育史、疫苗接种、作为传记的生长曲线、及“总要问的儿童保护问题——家里还有谁、这块淤青怎么来的、早上谁叫醒孩子”属于保护章语法）；老人（作为首项检查的用药清单、作为真实结局指标的功能史——楼梯、购物、洗浴、跌倒、失禁、预测他们能耐受哪种治疗的衰弱评分、及把“她就是变慢了”变成痴呆亚型的知情者史）；认知障碍与失语（照护者作为史官、观察患者能告诉你什么、图片与沟通工具优先于你对标准模板的耐心）；急症（十五分钟复苏史——药物、过敏、最后进食、事件经过、SAMPLE与OPQRST微型脚本——完整病史由有幸面对稳定患者者补全）；及诚实的极限：记忆是重构的（患者时间线是近似的、临床医师的也必须如此、尤其对抗凝与传染接触窗口）、羞愧是病史的镇静剂、而“困难患者”标签是临床医师技术失败的诊断、直到用人格、神经发育、创伤与医源性焦虑解释以精神科章工具梳理完。结尾纪律处处相同：回读总结、认真对待患者的纠正（纠正是医学里最被低估的诊断数据点）、一个明确安全网、及按验尸官会读的方式写病历——因为有时他们真的会读。**
:::

::: example 表现为烧心的心梗 {#ex-atypical}
71岁糖尿病女性到全科医师处就诊三天“烧心”、恶心乏力；无热、舒适、上腹叩诊无异常；她说“不可能是我的心脏、我感觉在这里”指着胸骨；全科医师开PPI并两周不见好再诊。
::: solution
**不典型即典型（[[#def-presentations]]、[[#def-hygiene]]、[[cardiovascular/coronary-artery-disease]]）：病史挥舞的旗——“女性-糖尿病-老年三联是教科书非典型ACS人群（在这个年龄组、消化不良加乏力加恶心的表现比男性好莱坞捂胸更接近常态）、而三天是渐进演变心梗的自然史、不是安慰性病程；本该改变计划的两个句子——新发中央不适伴恶心的糖尿病女性在被允许诊断消化不良之前需要心电图、肌钙蛋白属于路径不属于出院反射；点名的锚——患者自己的“不可能是心脏”不是保护性证据（患者按感觉不按解剖定位）、而“相符”的上腹压痛是医学里最令人安慰的体征、恰恰因为它经常是错的；纠正——当日心电图与肌钙蛋白、PPI作为无关项续用、带面孔的安全网（”变了或加重今天就回来；这个号码是评估病房）；及诊所事后该问的审计问题——非典型表现提示是否存在于十分钟会诊压力撞上它的任何地方、因为这个误诊是冠脉死亡审计不断清点的最常见一个。“**
:::
:::

::: example 被遗忘的一半用药史 {#ex-drughx}
58岁因颅内出血入院；入院用药史记录“华法林-无”；家属后来提到“他的膝盖每两周打一次针”；关节门诊病历显示五年玻璃酸钠及八周由代班医师起始而任何共享病历都未携带的NSAID桥接。
::: solution
**作为重构的用药史（[[#def-structure]]、[[musculoskeletal/back-pain]]、[[clinical-skills/records-handover]]）：本该运行的技术——”处方清单是起始假说不是答案：问药剂师 配过什么、朋友给你什么、你在商店买什么、医院门诊开过什么？、配带药袋与泡罩板的习惯及找到患者忘的笔与从未告诉全科门诊给我看你的针剂问题；本例点名的具体陷阱——非处方NSAID（在有人问之前对所有电子系统不可见、及放大他抗凝伤害的相互作用）、门诊起始药物（共享病历倡导者引用的代班与私人注射问题）、及真实而无关的“无华法林”（出血的真实药理是血小板与肾、不是维生素K）；系统修复——药剂师拥有的入院结构化用药审查（在第一小时抓住一半此类错误的核对政策、这就是其编制以工资单形态呈现的患者安全）、必须可复核而非仅响亮的“红旗相互作用”提示（警报疲劳文献的警告）、及目前向自己孤岛记录的关节注射服务的跨机构病历交换；及病房学到的道德算术——五分钟用药史写成对来源的讯问而非对清单的抄写、是这栋楼里最便宜的颅内出血预防。“**
:::

## 通向何处

建立在病史上的推理在[[clinical-skills/clinical-reasoning]]、其触发的查体在[[clinical-skills/physical-examination]]、其该与不该开的检查在[[clinical-skills/laboratory-tests]]、儿科与保护病史在[[paediatrics/safeguarding]]、老年评估在[[geriatrics-palliative/ageing-frailty]]、精神科附章在[[psychiatry/psychiatric-assessment]]。

::: history
**鉴于首要地位、病史的正式正典短得令人惊讶：希波克拉底《箴言》已规定问题——他受过什么苦、何时、如何、伴随什么——而19世纪Laennec与斯德哥尔摩诊所的床旁问诊为其加上系统体格检查。二十世纪的大转折是病史在与机器的竞争失利：1900-1960年代的实验室与影像革命使病史显得前科学、恰在医院建检查科之时、而1970-1980年代的经典教学论文（Peterson 1965与1982年Sandler及Schwartzenberg图表分析、及常被引用的“仅病史即在约三分之一到二分之一的接诊给出诊断、查体与检查落后”）读起来像辩护备忘录。同几十年的认知科学写下下一章：1960-70年代de Dombal的计算机辅助腹痛诊断证明结构化病史与简单概率能在腹痛上胜过无辅助模式识别、是证据结构对临床直觉的早期胜利；Elstein与凯斯西储的问题解决实验室、然后Pat Croskerry对双过程思维认知进化论（直觉系统1对分析系统2、1998-2000年代）为错误提供了词汇（Kahneman与Tversky的过早闭合、可得性与框架偏倚移植到诊断）；2000-2010年代的《红皮书》与《症状词典》及NICE症状分诊指南最终编纂了所教内容：附敏感度特异度数字的红旗清单、两周等待标准即带法律效力的病史问题。单个问题的证据成熟为专科——1993起的JAMA《用户医学文献指南》系列与McGee《简明临床证据》谱系给经典评分（GERD体位症状与DVT小腿体征的似然比）、及JAMA的《合理临床检查》综合使床旁重新量化地体面。现代威胁是沟通章点名的那个：电子病历的拉扯、“访谈期间录入数据”时代的研究显示患者叙事被截断、发现被漏、及“展示屏幕”与重叙事反运动。非典型表现文献——1980-90年代女性与心脏病研究（Annals与JAMA系列记录表现与治疗的性别差异）、糖尿病神经病变与老年谵妄数据——纠正了另一个世纪的男性教科书症状清单、如今位于每个胸痛指南。其不耀眼的结论即本章不断重复的：病史仍是多数诊断最敏感的检查、也是唯一抓住两个最常改变管理事实的检查——患者最先注意到什么、及他们害怕什么。** - [[clinical-skills/clinical-reasoning]]、[[clinical-skills/physical-examination]]、[[public-health/screening]]。**
:::

::: summary
- 病史是结构加判断：原话开场、定制症状分析、重构（非抄写）的用药史、及抓住隐藏议题的结尾问题——还担心什么。
- 症状分析是决策树：胸痛、呼吸困难、晕厥、意识模糊、出血与消瘦各有命名的判别问题与红旗、其目的是转诊时机不是完整。
- 非典型表现是按人群的规则——老人、女性、糖尿病、免疫抑制、妊娠——而“不可能是X因为患者不合教科书”是漏诊的经典锚。
- 最常见的病史错误是认知的：过早闭合、锚定转诊信、引导问题的暗示、及患者对羞愧的沉默；对策是强制重开（“还有什么、什么不可漏”）、中性措辞、及私下不带评判的问题。
- 儿童、老人、认知障碍者与急症各需重写技术：发育时间线、功能与衰弱史、知情者陈述、及脚本化的十五分钟复苏史。
- 按推理的证据记录、包括你排除的问题与理由；验尸官与复审读第一份病历、而患者的纠正是最被低估的诊断数据点。
:::

::: exercise 采集晕厥倒仆史 {level=2}

::: exercise 写下红旗 {level=2}

::: exercise 带知情者的问诊 {level=2}

::: example 没有病史的头痛 {#ex-headache}

::: example 呼吸困难患者与缺失的三分之一病史 {#ex-breathless}
68岁男性因“COPD急性加重、吸烟者”被转诊；他今年吸入剂换了两次；入院医师发现四个月夜间盗汗、6公斤体重下降与没人联系起来的游走性关节痛、及三十多岁务农阶段从未写下。

::: exercise 筛查而不制造恐慌 {level=2}

::: exercise 纠正诊断 {level=2}
你继承一个55岁“伴躯体症状的抑郁”、六个月乏力、“脑雾”与弥漫疼痛；抗抑郁药毫无作用；重读原始病史时你注意到疼痛是肩髋近端伴90分钟晨僵、而ESR 62无人置评。管理再诊断：推理、谈话、记录。

::: exercise 采集复苏室病史 {level=3}
76岁从养老院无意识到达；无陪人；电子处方不可得。二十分钟内你需要SAMPLE量表病史、保尊严的床旁扫查、及计划。按你真会留下的病历写出。
::: solution
**限时的完整（[[#def-hygiene]]、[[emergency-critical-care/acute-assessment]]、[[geriatrics-palliative/polypharmacy]]）：二十分钟结构——S：从总在随身袋里的出院信获取手术史；A：用药记录表照片获取过敏；M：药物——打开并阅读床旁的发药盒（缺失处方藏着的“昨天开始的新阿莫西林与翻倍的夜间镇静剂”）、加电话问照护者“她晚上吃什么”；P：最后进食与糖尿病药问题（AKI伴二甲双胍与漏餐伴磺脲是杀死养老院患者的两个可逆病因）；L：事件——养老院的“周二以来的变化”笔记、跌倒日记、“她举着手”的行为片段即误吸或癫痫或谵妄；E：立即搜寻的预先照护计划文件（“某处存在的顶线不能在床旁凭空发明”）及通过养老院紧急名单找近亲；带尊严的床旁扫查——看这里摸那里的顺序、被单保留、病员服开一次不开三次、颈与骶与小腿及病历反正需要的受压区检查、第1分钟血糖及当场决定的纳洛酮与硫胺素与葡萄糖反射、随数字到达的脓毒症筛查与心电图；及写成的病历——注明时间的总结、点名的病史来源（图表、照护者电话、袋子）并明确列出仍未知处、带即刻检查的工作鉴别、声明的升级顶线状态（“未发现文件；21:40与女儿开始讨论”）、及复查时间——因为无意识患者的病史是活文件、第一则条目对自身缺口的诚实是夜班第二位医师会感谢或诅咒的。**

::: exercise 利用患者的纠正 {level=2}
在腹痛病史末尾你总结：“持续性疼痛、无大便改变、无尿路症状”。患者迟疑：“嗯……你确定不是我的肾？”探索纠正是什么、如何挖掘、及它何时胜过你的发现。
::: solution
**纠正作为数据（[[#def-hygiene]]、[[#def-structure]]、[[clinical-skills/clinical-reasoning]]）：理论——患者对你总结的纠正是最便宜可得的诊断检查、也最常被挥开；它编码要么是未提示的症状（你漏掉的腰腹股沟迁移）、值得独立治疗的疾病观（既往结石、家族记忆、网络的贡献）、或支配依从的隐藏恐惧；挖掘——停下总结、坐回去：“多说说肾”；追问分开结石史（绞痛的性质、规范问的镜下血尿、因“多年前且没看医生”被患者省略的既往排出）、女性尿路感染背景、及恐惧读数（死于肾衰的母亲、是关于会诊而非腹部的可治疗信息）；何时胜过发现——从不反过来、且双向怀疑：50岁吸烟者“消化不良”的镜下血尿正是患者看起来错误的直觉刚找到的泌尿两周等待、规则是当被提示的检查便宜而疾病凶险时纠正重开鉴别；及记录习惯——记录纠正及其解决、既因为下一位医师继承重开的问题、也因为被听见的患者纠正病历——被相信本身就是干预的依从文献安静发现。**
