医学影像已成为由第二位医师执行的全身检查：临床医师的问题穿过申请单、方案、报告和级联、而辐射剂量、造影反应、偶然发现与假阴性仍是开单团队的责任。**本章讲述作为带成本临床仪器的模态（平片、CT及其剂量哲学、碘与钆对比剂及其真实风险、超声的操作者依赖、MRI的磁生态、及核医学的功能窗口）、选择逻辑（决策规则、问题对模态匹配、及紧急-准确度-伤害算术）、有其命名陷阱的身体系统（漏诊的正常胸片、只排除出血而别无长物的头颅CT、起作用的踝规则、及能造成伤害的腰椎MRI）、及报告契约——临床问题、紧急发现电话、偶然瘤路径、及重大事件报告不断发现缺失的临床-放射对话。**

## 仪器

::: definition 模态、剂量与对比剂安全 {#def-modalities}
**普通X线摄影便宜、快速、对自己的极限诚实：一个对骨与气与液平问题出色而漏掉早期肿瘤与微妙骨折的投影重叠、所以其正当用途是不敏感度可接受的筛查——CT决定前的胸片、创伤系列、管线核查、梗阻与穿孔一看。CT是急性医学的主力也是剂量冠军：以毫西弗计的有效剂量（胸片占天然本底一年的零头而CT胸腹盆相当于几年）、由正当化与最优化治理——儿科与妊娠规程、低剂量与造影时相规程、及多数科室如今公布的方案优化审计。其临床算术是人群风险对个体收益：每次CT的终生癌症风险估计在流行病学层面诚实、而绝不能阻吓夹层或肺栓塞或腹内出血的搜寻——那里未言明的伤害就在今晚。CT的人工物是临床事实：时相不佳的团注、运动与硬化束模拟、多相问题的单相检查——所以规则是临床问题必须到达放射技师与报告放射医师、不只是申请单。碘对比剂有两种危害与一百个神话。过敏样谱从荨麻疹到循环虚脱：既往反应是下次的最强预测、轻度既往反应证明改用替代检查或预处理并观察合理、哮喘是严重度修饰因子、而“贝类过敏”与“碘过敏”是不该挡住必需CT的民间传说。肾危害被2010年代对照研究下调：除严重既存损害伴容量不足与大剂量动脉内检查外、标准静脉剂量的对比剂相关肾损伤大体是神话；二甲双胍暂停规则针对已确立AKI的乳酸酸中毒、不是对比剂本身；透析患者无需造影后紧急透析。外渗损伤与激素及抗组胺预处理文献完成账目。超声实时、无辐射、操作者依赖而不公地廉价：其准确度等于其问题（胆石与DVT及儿科髋与产科与肾与睾丸应用其特异度极佳、而“超声正常不排除”的适应证——阑尾炎与胆总管结石——同样有据）；多普勒层加上血管与产科生理；而超声造影与弹性成像辅助手段不断移动其边疆。MRI以辐射与速度换软组织至上：安全筛查是真正的仪轨（起搏器与记录仪现越来越多为MR条件化、需记录型号与模式核查、动脉瘤弹簧圈与夹子数据库、耳蜗与神经刺激器植入、金属碎屑与眼眶筛查、泵与支架与瓣膜记录）、幽闭恐惧与时间及镇静与监测后勤、钆自身的安全故事（大环试剂与GFR阈值政策使肾病源性系统性纤维化近乎消除的过敏力量时代、及临床意义未证但把实践改变为按指征使用的脑沉积发现）、及水与脂肪与血产物是答案之处的至上——脊柱、关节、盆腔、肝定性问题、MS与视神经与垂体问题、及CT一天看不到的卒中弥散加权。核医学与PET-CT成像生理学：骨扫描对MRI的高敏感低特异、通气灌注SPECT时代对造影与肾问题的肺栓塞之问及其自身剂量画像、FDG-PET的肿瘤分期再分期及感染炎症适应证伴炎症模拟假阳性、及放射防护咨询即临床工作的治疗性核素应用（碘131与PSMA及骨痛药物）。乳腺摄影、透视与介入室完成仪器表：筛查乳腺X线的年龄分层敏感度与断层合成及缩短MRI试验、钡餐透视检查对CT与内镜缩小而真实的角色、及介入放射的静默革命（出血与肌瘤栓塞及引流与活检与消融及取栓邻近的血管工作使放射医师成为治疗专科、并使创伤与卒中的“先成像、后手术”路径成为常态）。**
:::

## 选择

::: definition 决定影像什么：规则、时机与系统 {#def-choosing}
**影像第一规则是问题先于模态：疑似舟骨骨折得到专研视图或早期MRI而非“拍个腕”、疑似马尾综合征得到当天全脊柱MRI伴临床所见记录、疑似结石得到低剂量CT方案不是历史IVU、疑似肺栓塞循年龄与妊娠调整算法（D-二聚体然后CTPA对VQ伴肾与造影与乳腺剂量考量、2010年代指南战争裁决）。减少不必要影像的决策规则是患者安全真正的成功之一：Ottawa与加拿大颈椎规则、使拍片降五倍而无漏折的踝规则、轻型头伤的头颅CT规则（加拿大头颅CT与新奥尔良标准）以小的漏诊风险换大的辐射与偶然节省、及放射学会ACR式清单编码的儿童虐待与挥鞭伤及鼻窦炎适宜性标准；每条规则都是验前概率管理的陈述、在推导人群之外应用时失效（中毒与分散注意力损伤及移民解剖学警诫）。各系统的平片对断层对功能层级：胸（两天咳嗽伴红旗的胸片、CT管胸片答不了的PE与主动脉及间质之问、及“胸片正常、患者病重”反射——藏在投影视图上的纵隔气肿与早期食管破裂）；腹（X线退休到穿孔与梗阻与体表标记职责、超声先行的胆与肾与主动脉筛查逻辑、按临床问题定有无造影及时相的CT——阑尾与憩室与缺血与创伤方案各是不同的注射方案、及胆管的MRCP与EUS）；头（CT作为雷击样与创伤及首次伴特征发作的工具、MRI作为其他一切的工具——肿瘤与脱髓鞘及后颅窝与早期缺血与感染及代谢之问、及放射与急诊文献仍以黄变症窗口与CTA阈值争论的“6小时CT阴性排除SAH”路径之辩）；脊柱与肌肉（指南抗击的腰痛影像级联——只在红旗时早期影像、因为三十以后无症状椎间盘膨出是普遍的、而其报告把腰痛变成一种病——及临床诊断本已特异的运动医学MRI指征）；乳腺与儿科与产科领域（三重评估、子宫内ALARA与正当化文化、及带真正剂量表在适当时安抚的辐射妊娠之问及超声与MRI先行替代）；及肿瘤再分期经济（RECIST与PET时代的系列影像间隔、偶然与临界发现的报告规则、及“谁读生存者的片子谁关闭监测”之问——肿瘤生物学章继承）。时机是选择的一部分：早期卒中跑赢CT的弥散加权、及落后于舟骨骨折与骨髓炎与应力骨折数周的平片；造影时相与团注与禁食及膀胱方案；及“当扫描改变管理时再扫”规则——它使两天病毒图像的入院CT退休、并为需要间隔的那例预约随访。**
:::

## 契约

::: definition 申请、报告、偶然发现与对话 {#def-contract}
**申请单是法律与临床文件：皇家学院与NHS及认证机构对明确临床问题的要求、相关既往影像与所求的具体决定（“孤立肺结节管理”对“肺炎”）改变方案与报告的有用性、而妊娠与哺乳与肾功能及既往造影反应字段是安全层；适宜性文献奖励的“因担忧排除癌症”的诚实胜过掩盖红旗的委婉。报告为三件事被读、为另外三件事被写：看到什么、意味着什么、下一步做什么——而其读者是患者的整个未来、所以结构化报告时代（把“不确定结节”变成管理算法的放射结构模板与LI-RADS与BI-RADS与Lung-RADS分类、及关于偶然肾上腺与甲状腺与垂体发现尺寸阈值的“报告语言不过度召唤”研究）使亚专科重读经典偶然瘤文献并把阈值写进模板。紧急发现文化是契约最快的条款：“关键结果”路径（气胸与夹层与颅内出血及非动脉化缺血肢体结果必须在数分钟内以电话到达具名临床医师、带复述与记录、因为系统里的报告不是对患者采取的行动、及谈判式阅片的漏掉主动脉夹层是反复出现的警示案例）、多数认证制度如今要求的同班关键发现沟通审计、及院外升级阶梯（影像阅片服务初级到注册医师到顾问放射医师之路及有人接的电话）。临床-放射对话——研究显示预测诊断挽回的非正式走廊谈话——正被正式重建：放射医师电邮电话开放文化政策、作为定期对话的MDT、图像不符时的“请结合临床所见复审”请求、及报告与床旁不一致时保护患者的分歧解决路径（“治患者、质疑报告”规则及其推论：自信的临床表现推翻安心扫描多于反向）。假阴性清算统计学加勇气：感知对解释对知识错误分类学、双读与AI辅助证据（2010-2020年代获监管批准的颅内出血与气胸同步AI分诊产品及“自动化偏差使人停止核查”警诫）、筛查规划敏感度审计与召回率基准、国家报告制度（英国与澳大利亚的辐射与造影事件报告服务）、及漏掉的骨折或延迟的癌症报告造成伤害时的坦承职责——像其他伤害一样披露、因为影像有签名而患者如今能读到它。最后是适宜性与获取治理：等待名单与分诊与优先制度（癌症嫌疑两周规则与“可能卒中一小时内成像”时钟——整个系统绕它弯曲）、互助与网络影像（区域取栓与主动脉与儿科神经外科的扫描外送）、及院外最小数据集（“只有改变今晚的问题”学说）、及报告最后的职责——闭合环：活在系统而不只在散文里的监测间隔、发出去的召回信、及“无显著异常”以开单临床医师与患者在凌晨3点都正确解析的措辞意味着它所说的。**
:::

::: example 被放行的踝 {#ex-ankle}
24岁足球运动员凌晨2点“踝扭伤”：X线“无骨折”、出院；第9天持续的外侧与中足疼痛及首夜起无法负重使CT发现微妙内侧楔骨骨折与漏掉的第五跖骨撕脱。
::: solution
**应用规则对理解规则（[[#def-choosing]]、[[surgery/orthopaedics]]、[[musculoskeletal/fractures]]）：Ottawa逻辑——踝规则在避免不必要拍片上出色、而在阴性拍片后无视其编码的阳性所见时无用：本例有规则自身两个高危标记（自受伤起无法负重、中足骨压痛）强制影像——而高机制患者适应证拍片后的“初片无骨折”是一个计划、不是出院；凌晨2点片子漏掉的解剖——中足（Lisfranc与楔骨及跖跗问题配可行时负重片及隐匿者的MRI或CT）、第五跖骨底2区Jones对3区撕脱改变负重建议之别、及距骨与胫骨平台坑；正确路径——疑似舟骨与跟骨的专研视图与模板视图、“阴性拍片后持续疼痛与功能失败等于数天内重成像或MRI”规则（运动医学与NICE式服务如今作为门诊运行）、及“记录的出院负重状态与预约的随访”闭合；及系统解读——夜间沉默出院问题（急诊外科“不好再来”丢了九天的足球）——每个科室治理档案都有而少有行动的再就诊与漏折审计：规则减少过度使用；临床重看预防不足使用。**
:::

::: example 需要所有者的偶然发现 {#ex-incidental}
肾绞痛常规超声记“偶然2.4 cm低回声肝病灶、建议进一步影像”；患者已无结石无症状；信到达其全科、“进一步影像”被预约为14周后的常规门诊超声、而直到第4个月MRI显示来自她从未被诊断癌症的可切除结直肠转移才有人告诉她病灶可能是什么。
::: solution
**带临床问题的偶然发现（[[#def-contract]]、[[gastrointestinal/gi-bleeding-cancer]]、[[#def-choosing]]）：放射侧的对与错——发现被正确旗标（成人1 cm以上新发实性肝病灶在多数阈值上是要查的发现）、而“建议进一步影像”不带具名模态与紧急度是偶然发现文献批评十年的模板；多相肝方案CT或MRI（廓清填充定性及原发灶搜寻含义）是下一个检查、报告应带着病灶应得的间隔说出来；转诊侧的失败——肝病灶不是常规门诊：“不明肝病灶伴可能原发工作检查”的两周等待邻近疑似癌症路径（CT胸腹盆与CEA及肠镜决定——本例患者第一周就该进入、不是第四个月）、及病历里回答了的所有者之问（“全科管理转诊”带具名复查日期或急性医疗团队拥有）；预防它的系统——结构化的偶然发现管理规范（部分国家放射战略发布的尺寸与背景阈值及其强制间隔）、在6周核对所荐检查是否发生的建议到行动闭环、及在发现时点被告知在追什么到何时限的患者；及坦承与病例复审——延迟归因分析（发现到治疗间隔映射到周数丢失在何处）、仍然完成切除术与赔偿谈话一并举行、及信托偶然发现政策的肝病灶紧急度附录、因为偶然瘤在被某人拥有之前只是偶然。**
:::

**影像以一只猫著名地开始：Röntgen于1895年11月发现X线、第一张图像是他妻子戴婚戒的手、一年之内医学与大众世界接纳了“不可见的摄影”——连同无防护先驱放射医师的烧伤与癌症（墓志铭的早期放射墓地与产生剂量概念保护措施的1900年代辐射防护运动）。对比剂几乎立即到来（1900年代尿路造影与1921年的碘油）、血管造影由偶然与刻意几乎同时发明（Forssmann 1929年的自导管术与Seldinger 1953年的技术）、脑动脉造影谱系使放射学成为唯一能看见活体血管内部的专科。超声经战争及其后进入医学：1950年代产科绘图仪的回声及多普勒与实时时代、然后经阴道与造影及弹性成像波；核医学跟随同位素时代（碘131治疗与成为世界最常用放射性核素的锝99m发生器）；CT获诺贝尔奖的1971年引入（Hounsfield与Cormack、及脑室造影的即时取代）与MRI 1977-1980年的临床到来（Damadian与Mansfield与Lauterbur的工作）在一个人的寿命内使断层成像成为核心、而1990-2000年代数字放射与PACS革命删除了相机、把报告从打字机移进结构化模板。剂量政治并行发展：辐射防护框架（ICRP自1928年的建议、1950年代“合理可行尽量低”学说、1980-90年代指令的ALARA时代正当化与最优化法律、UNSCEAR风险估计）、2008-2012年CT剂量攀升恐慌（内医学档案的CT相关癌症预测及其产生的剂量指数与CTDIvol及剂量审计登记运动）、及把“按儿童定方案”变成认证的儿科影像改进运动。决策规则时代改变了谁被影像：加拿大与Ottawa踝与颈椎规则（1990-2000年代、有据证的减半以上不必要拍片及“规则被非推导者误用”的实施警诫）、头伤CT规则与NEXUS、PE诊疗管理研究（PIOPED与CTPA时代试验）、Choosing Wisely适宜性清单、及每个指南机构告诉临床医师无症状椎间盘流行率研究（1990-2000年代健康志愿者MRI系列、Jensen 1994年新英格兰杂志显示无症状者椎间盘异常）使其不可否认的腰痛影像战争。过度诊断运动（Welch邻近的筛查伤害文献）与偶然瘤文献（1980年代肾上腺邻近术语及甲状腺与肺与肝与胰腺发现日益增多的级联管理规范配其已发表尺寸衰减阈值）迫使报告变成管理算法——2010年代的Lung-RADS与LI-RADS及BI-RADS分类工程。对比剂安全修正是自己的循证医学课：2010-2020年代大型对照研究与荟萃分析（2017年放射与肾病学会联合声明）缩小了静脉标准剂量的对比剂肾病恐慌、修订了二甲双胍规则、确认大环试剂与GFR筛查使肾病源性系统性纤维化近乎消除——在建立在病例系列恐惧上的二十年实践之后。2020年代把人工智能带进阅片：获FDA与欧洲批准的邻近分诊产品（颅内出血与气胸及肺结节检测算法及糖尿病视网膜病变自主系统）、自动化偏差与泛化警诫、及谁签署机器辅助报告的未决之问。穿越每项技术、领域自己的综述不断命名一个失效：缺失的临床问题与未闭合的环——这就是影像的历史为何以一个沟通章结束、1896年的先驱们关于X线最危险的部件——持管者的乐观——早已得出的同一结论。** — [[clinical-skills/clinical-reasoning]]、[[clinical-skills/patient-safety]]、[[public-health/environmental-occupational]]。**
:::

::: summary
- 每个模态是带成本画像的仪器：平片快而不敏感；CT快、果断而带剂量；超声实时而绑定操作者；MRI软组织至上但需安全筛查；核医学生理而自带剂量逻辑；乳腺摄影与透视与介入有其命名生态位。
- 今日对比剂安全：既往反应预测再次反应；“贝类/碘过敏”是民间传说；现代剂量标准静脉对比剂很少伤肾；二甲双胍与NSF规则适用于定义的肾风险群体、不是每个人。
- 影像跟随问题：决策规则（Ottawa、头颅CT、PE路径）减少伤害；只认红旗的腰椎规则防住无症状椎间盘膨出级联；时机（卒中与马尾的早期MRI、舟骨的复查片）是适宜性的一部分。
- 申请单必须携带问题及剂量-妊娠-肾字段；报告必须携带分类与阈值；关键发现以复述电话传递；偶然发现需要带所有者与间隔的路径、不是散文。
- 假阴性是感知、解释或知识错误：双读、带自动化偏差意识的AI辅助、敏感度审计、及伤害落地时的坦承。
- 临床-放射对话是诊断工具：分歧通过治患者与重问问题来解决、而闭环（谁追、到何时、告知谁）是影像的患者安全契约。
:::

## 练习

::: exercise 选择检查 {level=1}
为下列选择并辩护首影像：(a) 7天上腹痛伴消瘦；(b) 30周妊娠右上腹痛发热；(c) 8岁髋痛跛行；(d) 68岁雷击样头痛神经正常、起病14小时。
::: solution
**问题对模态（[[#def-choosing]]）：(a) 上消化道癌路径：紧急直接胃镜就是检查（消化不良伴报警特征规则）、加超声回答胆胰肝之问及发现后的CT分期——平片与“万能腹部超声”拖延胃镜能做的诊断；(b) 妊娠胆囊：超声先行（结石敏感度及壁与胆管所见）、疑胆管时无钆MRCP或不用CT、感染同治而外科-产科判断并行、及用真实胎儿剂量表回答“妊娠辐射”焦虑——它说超声与MRI决定、母亲生命需要时用CT；(c) 痛髋：紧急超声查积液加血检——一过性滑膜炎对化脓性关节炎决定（邻近Kocher的发热与非负重与ESR与CRP逻辑）、只在诊断或股骨头血供（两者都先X线的Perthes与滑脱）需要时MRI；(d) SAH窗口：14小时CT高度敏感而不绝对——路径是本单元CTA或腰穿黄变症规程的本地决定（“CT阴性雷击样今晚仍需第二检查”规则）、正是选择节提到的指南之争、也正是临床医师必须在患者到达前知道本科室规程的原因。**
:::

::: exercise 解读“正常” {level=2}
三个背后有异常的正常：(a) 服复方避孕口服药胸膜痛患者的“胸片正常”；(b) 免疫正常发热头痛伴早期颈僵的“头颅CT正常”；(c) 3天机械性腰痛的“腰椎MRI正常、L4-5椎间盘膨出”。陈述各正常排除与不排除什么及管理后果。
::: solution
**正常是结果不是判决（[[#def-contract]]、[[#def-choosing]]）：(a) PE正常：胸片在PE常正常（Westermark与Hampton驼峰罕见）、此处正确读法是“这张片子回答不了我差点去问的问题”；Wells与D-二聚体然后CTPA或VQ路径成立、而口服避孕药与腿与旅行史就是检查的正当性；(b) 脑膜炎正常：早期细菌性脑膜炎尤其脑炎与立克次与蜱邻近模拟是CT正常的、而腰穿与抗生素及阿昔洛韦决定按临床运行（“临床需要腰穿者不要为影像延迟抗生素”规则及其免疫正常无定位体征无视乳头水肿含义）、正常CT允许腰穿而绝不能镇静综合征；(c) 带偶然语言的腰痛正常：椎间盘膨出是指南警告将被重读为病因的年龄流行噪音、所以报告与临床医师的共同工作是“无显著可治异常；保持活动；红旗同前”翻译——邻近报告语言研究的要点：命名偶然发现的正常制造出“坏椎间盘”患者、接受注射与恐惧；诚实的正常有时是影像中最有治疗力的句子。**
:::

::: exercise 处理造影反应 {level=2}
CTPA后20分钟45岁出现面部血管性水肿、荨麻疹与哮鸣、血压92/54；放射候诊区恐慌；刚报告的PE已确认。在同一份病历里治疗反应与血栓。
::: solution
**科室内过敏（[[#def-modalities]]、[[emergency-critical-care/anaphylaxis]]、[[cardiovascular/vascular-disease]]）：反应——现在肌注肾上腺素并平卧与氧与液体与雾化及第二第三剂及抢救车与麻醉支援呼叫及激素与抗组胺只是辅助及双相风险的观察期及“反应有分级所以处置是入院或HDU、不是回到扫描室”；双重急症——今天对进一步造影有禁忌的确诊PE仍要治疗：抗凝决定（肝素与DOAC对低分子对磺达肝癶钠背景、若不稳定则溶栓或取栓决定——造影过敏不取消它）、抗凝不能运行时的下腔静脉滤器之问、及用于随访不确定性的VQ或不再CT的替代；及之后——具名药物反应记录及把“造影剂过敏”标签做准（下次扫描的预处理对替代模态决定及确认反应的过敏转诊）、向辐射与造影事件计划报告（国家对比安全数据靠此存活）、及患者教育：她得的反应可治可防、她必须在未来每一扇放射门口大声说出来。**
:::

::: exercise 审计你的影像使用 {level=3}
贵科数据：CT利用五年升40%、18%的住院超声“出于规程原因”、6%的报告以“建议临床联系”结尾而无临床医师回应记录、40%的腰椎MRI在非特异腰痛2周内开出、而院外CT阈值未监测。写出改进规划。
::: solution
**影像管家规划（[[#def-contract]]、[[#def-choosing]]、[[clinical-skills/patient-safety]]）：诊断——利用增长分解为真实（系统强制的卒中与PE与癌症路径时钟）与文化（防御与便利与规程驱动扫描）；四个发现各是一个不同干预：(a) 规程超声——与开单临床医师（不只超声主管）的按指征目录与审计（带反馈的适宜性标准设计）、(b) “建议临床联系”死信——报告行动环（“建议”被替换为下一步建议或电话提示；结构化报告时代未闭环问题以“建议未执行”审计测量并通过把放射医师电话做成有人接电话的资助活动来修复）、(c) 早期腰椎MRI——带放射侧闸门的路径再教育（“无红旗<6周不推荐影像”申请提示带指南引用及开单者覆盖审计——邻近NICE的需求管理研究显示提示加反馈起作用、光海报不起作用）、及d) 院外CT——院外适宜使用规程（“今晚改变什么”规则、急问题最小数据集、及测量漏掉的外科腹与“因为病房要求而扫描”两者的院外扫描入院相关审计）；治理——影像适宜委员会（放射与临床主任与信息）、剂量审计与优化登记参与、面向临床医师的按科利用与产出仪表盘（Choosing Wisely时代研究显示能移动开单的透明）、AI分诊工具的本地评估（自己人群前后从敏感度与流程及自动化偏差数据）、及支付“放射医师读片并打电话”能力——唯一把四项审计变成照护的资源——的董事会条目。**

::: example 绝不能等的脊柱 {#ex-cauda-mri}
29岁鞍区麻木伴排尿犹豫周六晚到达；值班经理说MRI机房08:00开、“CT显示不了马尾”；外科注册医师记录“明早评估”。
::: solution
**时间是马尾的组织（[[#def-choosing]]、[[#def-contract]]、[[musculoskeletal/back-pain]]）：标准——马尾综合征是带减压窗口文献的影像急症：全脊柱MRI当晚、及这家医院正在辜负的服务义务（院外MRI获取政策与互助转运协议及“若我们的磁体关闭则网络的开着”电话树、国家脊柱服务标准所期望）；决定当夜的临床记录——会阴感觉与张力及膀胱扫描（残余尿）及球海绵体反射之辩带时间记录、使MRI呼叫以发现而非感觉被辩护；转运决定——“若本地无磁体、今晚转运到网络中心并现在与神经外科脊柱团队谈话、在接收中心做MRI”（“别让本地扫描器拖住外科医师”规则）、及转给外科医师的激素之问及等待所需的镇痛与导尿护理；及治理早晨——作为邻近永不事件发现的“这次等待了”审计（“漏掉的马尾是唯一没有指南辩护等待的诊断”）、由那晚短缺的人在大白天写的院外MRI获取与网络转运SOP、及把延迟真相及它可能造成的损失告诉患者、连同尿科随访与控尿及理疗及理赔者的坦承包在首次门诊全部启动。**

::: example 原来是Graves的甲状腺摄取 {#ex-hypo}
30周妊娠女性心悸、TSH<0.01、游离T4升高；急诊开“查PE”的CT肺动脉造影、未见血栓、记“偶然甲状腺肿、建议查甲功”——而她的甲状腺风暴轨迹正被错过；产科团队问CT是否伤害了胎儿。
::: solution
**妊娠剂量真相与模拟者（[[#def-modalities]]、[[#def-choosing]]、[[endocrine/thyroid]]）：剂量回答——CTPA胎儿剂量远低于确定性伤害阈值（妊娠辐射剂量表：保护机构发布的“母亲生命与肢体影像绝不遮蔽”与“不因诊断CT而终止妊娠”立场）、带着母亲应得的安抚与记录实际估计剂量的病历；诊断失误——模仿PE的甲状腺毒症（窦速与呼吸困难与焦虑与甲状腺肿与眼部体征、D-二聚体被妊娠本身抬高的陷阱、及“年轻心动过速孕妇在更多CT之前查甲功”教训）、甲状腺风暴识别及产科-内分泌共同管理（孕早期丙硫氧嘧啶之后甲巯咪唑的惯例与短程β阻滞剂、及CT造影剂引出的妊娠碘禁忌之问：母亲碘负荷后新生儿甲功检查建议、团队欠她的在第2小时不是第2周）；及闭环——升级为带所有者诊断的“偶然甲状腺肿”、母胎医学重复监测协议、及仪表板上的科室教学点：CT是血液检查90分钟能诊断的疾病的错误第二检查、而其造成的胎儿剂量焦虑是级联的利息。**

::: exercise 分诊筛查召回 {level=2}
贵乳腺单位的召回信有12%假阳性召回率；“三重评估”门诊把焦虑的首诊者列为“常规”；一些筛查发现的癌症被召回做超声、到第3个月才完成；起草修复。
::: solution
**召回是路径不是信（[[#def-contract]]、[[public-health/screening]]、[[surgery/breast-endocrine-surgery]]）：基准——欧洲与英国筛查规划标准（筛查委员会公布的召回率与阳性预测值及间期癌与两周最终报告基准——12%召回伴低PPV是阅片与阈值问题、不只是焦虑问题）；修复——1)评估架构：乳腺片加超声伴指征时同次粗针活检的联合门诊一站式模型（其试验数据的焦虑降低与最终评估加速）、2)放射医师配置与双读及召回阈值审查（召回率审计是同时是工作量与安全数据）、3)信的分诊语言（患者沟通研究编目的“常规召回”与“你得了癌”混淆——最好的规划如今印出的“这不意味着什么”句与具名联系电话）、4)“评估完成带结果7-10天”服务标准逐患者追踪、滑落时升级（使第3个月超声成为治理发现的间期癌与延迟诊断审计）、及5)假阳性长期伤害指标的召回审计（瑞典队列研究量化的短期焦虑与再就诊行为）。问责——到董事会的筛查规划仪表板：召回率、PPV、评估到结果间隔分布、一周患者报告焦虑、间期癌、及“谁晚召回为何”例外日志；因为筛查的契约是人群收益伴个体伤害最小化、而召回信就是那份契约被遵守或被撕毁之处。**

全科为34岁每日紧张型头痛、查体正常而重度疑病症患者开“头颅CT、脑瘤？”；患者期待扫描带来安心。协商影像、焦虑与安全网。
::: solution
**能造成伤害的影像（[[#def-choosing]]、[[clinical-skills/clinical-reasoning]]、[[psychiatry/anxiety-disorders]]）：反对扫描的证据——红旗阴性而查体正常的每日头痛其肿瘤概率与人群基线无法区分、脑CT/MRI偶然发现率（蛛网膜囊肿与松果体变异及白质斑点）制造指南表格计数的级联、而疑病症中正常扫描是以周计半衰期的安心——“求安慰循环”研究显示下次头痛更大；谈话——两个伤害都命名：“扫描不太可能发现肿瘤而很可能发现需要另一次扫描的东西；两者都不帮你的头痛”；给她能控制的红旗清单、并预约取代扫描的随访（“若模式改变或出现、我们当天成像”）；被正确治的替代诊断——紧张-偏头痛重叠的药物过度使用头痛筛查及疑病症转诊（CBT治疗疑病症证据及全科“这里同时治头和担忧”框架）；及共同决策逃生舱——若这一切之后她仍想要影像、双方面的记录决定（她对级联风险的理解、约定的正常结果关闭肿瘤之问及计划是随访不是更多扫描）是正当医学——带善后计划的自主、胜过一个把她无引导送到另一科室扫描器的隐性拒绝。**

::: exercise 设计院外影像政策 {level=3}
贵地区综合医院院外数据：夜间CT等于白天量的40%；三分之一用于低验前概率疾病“排除”；两次近失误（“正常”X线申请的漏掉骨筋膜室、因扫描仪被“肾绞痛”占用而延迟的夹层CT）。放射医师单干。写出带安全与人员条款的政策。
::: solution
**院外影像即分诊（[[#def-choosing]]、[[#def-contract]]、[[clinical-skills/patient-safety]]）：原则——夜间影像回答今晚的问题：“这改变患者今晚睡哪里或今晚是否进手术室”检验、写进申请屏幕并由放射医师可与开单顾问援引而非拒绝战的规程执行；指征清单——是清单（卒中代码与PE及夹层与AAA及创伤及关键出血及脊髓压迫及马尾及睾丸扭转邻近临床诊断及气道与深部间隙感染与缺血肢体及免疫受损发热路径）对早晨清单（“排除肿瘤”申请、两天病毒咳嗽、已知偏头痛的头、在走廊被镇痛安抚的肾绞痛——除非感染梗阻肾之问今晚所需、结石方案等科室超声先行与不确定时低剂量CT白天路径）；近失误教的安全条款——骨筋膜室是临床的而放射申请完全是错工具（所以政策含字出现在申请上的临床升级提醒）、及夹层绝不排队规则：带扫描仪“为杀手问题”覆盖的规程层级及台面真忙时的互助转运（主动脉网络发布的“带名字与时间的为扫描转运决定”）；人员——单干放射医师支持系统（带自动化偏差警诫的报告发现分诊AI、交叉覆盖及夜间正常片读片的远程放射、强制休息、及工作时长与疲劳文献明确点出的“凌晨3点无高年资二审”风险）、及“放射医师可以回电而且必须”文化；及审计——“今晚问题”合规率、使说不成为可能的晨间门诊补偿能力、杀手问题对网络基准的到扫描时间、及每个院外不扫描决定后转出患者的院外MDT复审——因为政策只有在早晨总有位置安放被推迟者时才安全。**

::: exercise 回答剂量之问 {level=1}
写出接待员应当能给的三句答案、及临床医师更完整版：(a)“与X线相比CT多危险？”；(b)“我孕8周、知道前拍过牙片”；(c)“我父亲做了PET——我有放射性吗？”。
::: solution
**剂量沟通语法（[[#def-modalities]]）：(a)“CT给比X线大的辐射剂量——大致是数年而非数天的天然本底辐射、这就是为何只在答案要紧时才做；对我们正在检查的问题、正确答案的收益远大于其添加的微小终生风险“（备好临床医师数字：毫西弗阶梯与人群风险估计、正当化与最优化句、及家长会问的”我们按儿童调方案“要点）；(b)”牙片到子宫的散射远低于任何与伤害相关的水平——助产士与产科单位的剂量表使它远远不到阈值；无需额外扫描、无需改变产前计划、而安抚就是医学“（引用确定性效应阈值及”我们稍后成像仍屏蔽并正当化“的职业性）；(c)”PET剂量大部分在一天内随尿排出；你对家人没有实质性放射性、尽管科室对与小孩和孕妇家庭在第一晚的密切接触给出具体建议”（重要的碘131对FDG区分——因为碘131患者确实作为放射源管理数日——隔离与迭代及卫生规则是临床团队负责解释的、不只是核医学科）；及三者共享的元规则：回答被问的问题、给出当事人已经信赖的比较（天然本底）、绝不让流行科学数字没有其分母就离开房间。**
