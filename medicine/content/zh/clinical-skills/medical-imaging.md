医学影像让临床医生不必打开身体就能看到其内部。每一种技术的原理，都是把能量送入人体（X射线、声波、磁场中的射频波，或注入的示踪剂发出的γ射线），并记录组织如何改变这些能量。大致了解其中的物理原理，就能明白每种技术擅长显示什么、会漏掉什么，以及会带来什么危害。

本章介绍选择影像学检查的原则、X线平片和胸片的系统阅片方法、计算机断层扫描、超声、磁共振成像和核医学，以及辐射和对比剂的风险。本章使用[[anatomy/anatomical-language]]中的解剖平面和影像学惯例。

## 选择影像学检查

影像学检查和其他诊断性检查一样，应当回答一个临床问题。选择取决于问题是什么、现有检查对它的准确性、检查的风险，以及需要多快得到答案。

::: definition 正当性与最优化 {#def-justification}
在英国，医疗中的电离辐射照射受**《2017年电离辐射（医疗照射）条例》**（Ionising Radiation (Medical Exposure) Regulations 2017）管理，简称**IR(ME)R**。每一次照射都适用两条原则：

- **正当性**：照射对个人的预期获益必须超过其风险，并考虑辐射较少或没有电离辐射的替代方法。正当性判断由受过培训的执业者（通常是放射科医生或放射技师）根据申请单中的临床信息作出。
- **最优化**：一旦判定为正当，就必须在获得所需诊断信息的前提下，使剂量**在合理可行的范围内尽可能低**。

英国皇家放射科医师学会发布转诊指南**iRefer**，为常见临床问题推荐合适的首选检查。
:::

一份好的影像学申请应写明临床问题、相关的病史和体格检查所见，以及影响检查选择或安全的因素（妊娠、肾功能、过敏、植入装置）。“？病变”不是一个问题；“膝关节置换术后10天突发胸膜性胸痛伴低氧；Wells评分6分；？肺栓塞”才是。

## X线平片

X射线是高能光子。它们穿过人体时，一部分被吸收或散射，其余到达探测器。致密的组织以及含高原子序数原子的组织（如骨中的钙，或对比剂中的碘和钡）吸收较多，显示为**白色**（不透X线）；吸收很少的组织，如肺内的空气，显示为**黑色**（透X线）。

::: theorem X射线的衰减 {#thm-attenuation}
单一能量的窄束X射线穿过厚度为$x$的均匀物质时，透射强度为

$$
I = I_0 \, e^{-\mu x},
$$

其中$I_0$是入射强度，$\mu$是物质的**线性衰减系数**，它随密度和原子序数的增大而增大，并取决于X射线的能量。
:::

因此，两种组织之间的图像对比度取决于它们衰减系数的差异。平片上有五种基本密度：**空气**（黑）、**脂肪**（深灰）、**软组织和液体**（中等灰，二者无法区分）、**骨**（白）和**金属**（亮白）。只有在两种不同密度相接处，边界才可见。

y: 0, 1
sliders: m=0.2:0.02:1:0.02; n=0.5:0.02:1.5:0.02

caption: 两种衰减系数（每厘米）不同的物质中，X射线透射强度的比例随厚度（cm）的变化。两条曲线之差就是探测器可利用的对比度。这是采用示例系数的简化单能模型。
:::

::: definition 轮廓征 {#def-silhouette}
两个密度相同、彼此相贴的结构在X线片上无法区分：它们之间的边界消失。这就是**轮廓征**（silhouette sign）。在胸片上，与心脏或膈肌相贴的肺叶发生实变，会使该处边界不可见。右心缘消失提示右肺中叶病变；左心缘消失提示舌段病变；一侧膈面消失提示该侧下叶病变。如果尽管存在阴影，某条边界仍然清晰，说明该阴影并不与之相贴。
:::

### 胸片的系统阅片方法

胸片是申请最多的影像学检查。系统的阅片方法可以避免最常见的错误，即发现第一个异常后就停止寻找（满足于搜索，[[clinical-skills/clinical-reasoning#def-bias]]）。

1. **基本信息**：患者、日期和时间是否正确；与以前的片子比较。
2. **投照方式**：**后前位（PA）**（站立；标准体位）或**前后位（AP）**（常为病重患者的坐位或卧位）。前后位片会放大心影，因此不能可靠地判断心脏大小。
3. **质量**：**旋转**（锁骨内侧端到棘突的距离应相等）、**吸气程度**（锁骨中线上膈肌以上可见约5~6根前肋或9~10根后肋）和**曝光**（心影后方的椎体刚好可见）。
4. **气道**：气管居中，隆突和主支气管。
5. **肺**：逐区比较双肺；寻找阴影、透亮区、肿块，以及胸膜边缘（气胸）和肋膈角（积液）。
6. **心脏**：心脏大小（在后前位片上，**心胸比**大于0.5提示心脏增大）、心缘、纵隔宽度和肺门。
7. **膈肌**：形态、高度和肋膈角；立位片上**膈下游离气体**提示空腔脏器穿孔。
8. **其他一切**：骨骼（肋骨、锁骨、脊柱）、软组织，以及各种管线：气管插管、中心静脉导管、鼻胃管、引流管、起搏器。
9. **复查区域**：异常容易隐藏的地方，如心影后方、肺尖、膈下和肺门。

::: example 肺炎在哪里？ {#ex-cxr}
Baptiste先生，49岁，发热、咳痰。他的后前位胸片显示右下肺野有一片边界不清的阴影。右心缘看不见，但右侧膈面清晰。阴影内可见空气支气管征。异常在哪里？可能是什么？

::: solution
右心缘消失（轮廓征）表明阴影与右心房相贴，即位于**右肺中叶**。右侧膈面保留，使右肺下叶的可能性降低。**空气支气管征**（在不透光的肺组织衬托下可见黑色分支状气道）表明肺泡被填满而气道仍然通畅，这是**实变**的表现。结合发热和咳痰，最可能的诊断是右肺中叶肺炎。对某些人群（如吸烟者和老年人），建议治疗后复查影像，以确认阴影消散，没有掩盖潜在的肿瘤。
:::
:::

::: example 核查鼻胃管位置 {#ex-ngtube}
Ibrahim女士，80岁，卒中后插入鼻胃管用于喂养。无法测定抽吸液的pH，因此拍了胸片来确认位置。在使用这根管之前必须满足哪些标准？

::: solution
在英格兰，经位置错误的鼻胃管（进入肺内）注入营养液、液体或药物是一种**绝不应发生事件**（Never Event）。当无法进行或无法确定抽吸液pH检测时，必须由有资质的人员按公认标准解读X线片。导管应当：

- 沿食管走行，**保持在中线**并**平分隆突**（从两侧主支气管之间向下走行，而不是沿其中一支走行）；
- **在中线穿过膈肌**；
- **尖端清楚地位于左侧膈下**，在胃内。

沿支气管走行、在食管内盘曲或末端位于膈上的导管都不能安全使用。X线片必须是本次插管后拍摄的，解读必须记录在案，如有任何疑问，都不得使用该导管。
:::
:::

### 腹部X线片

腹部X线片的用途有限：主要是疑似**肠梗阻**和某些异物。判断扩张的一个实用标准是**“3–6–9”法则**：小肠直径超过3 cm、结肠超过6 cm、盲肠超过9 cm即为扩张。小肠有横贯整个肠腔的**环状襞**；结肠有不完全横贯的**结肠袋**。对于成人急性腹痛，CT通常信息量更大；而要发现游离气体，立位胸片优于腹部平片。

## 计算机断层扫描

**计算机断层扫描（CT）**让一束旋转的扇形X射线穿过人体，利用众多投影重建横断面图像。每个像素被赋予一个以**亨氏单位（HU）**表示的数值，在这一标度上**水为0**，**空气为−1000**。

::: definition 亨氏单位与窗 {#def-hounsfield}
CT值的近似数值为：空气−1000 HU；脂肪约−100 HU；水0 HU；软组织约+20至+80 HU；急性血凝块略高于软组织（常约+50至+80 HU）；骨为数百至+1000 HU以上。**窗**选择以灰阶显示的数值范围。肺窗显示充气的肺；软组织窗显示器官；骨窗显示骨皮质细节。同一次扫描必须在多个窗下观看，因为在一个窗下可见的发现，在另一个窗下可能看不见。
:::

CT快速、普及，对许多急症都很准确：颅内出血、肺栓塞（CT肺动脉造影）、主动脉夹层、创伤、急腹症和肾结石。静脉注射的**碘对比剂**使血管和强化组织显影；口服对比剂则勾勒出肠道。

### 对比剂的风险

- 碘对比剂引起的**类过敏（超敏）反应**不常见，且大多轻微（荨麻疹、恶心）；严重反应罕见。既往对碘对比剂有过反应是重要的危险因素。对贝类或碘皮肤消毒剂过敏不是禁忌证。
- **对比剂相关急性肾损伤**：现代静脉对比剂的风险低于以往的认识，但肾功能明显下降（如eGFR低于30 mL/min/1.73 m²）或有急性肾损伤的患者，需要按当地和英国皇家放射科医师学会的指南进行风险评估，可能包括水化和审查肾毒性药物。
- **二甲双胍**：当地指南可能建议对肾功能明显受损的患者在注射对比剂后暂停二甲双胍，因为一旦肾功能下降，有小的乳酸酸中毒风险。

::: example 对比剂与肾功能下降 {#ex-contrast}
Patel女士，81岁，剧烈腹痛与查体所见不相称，有心房颤动，乳酸4.5 mmol/L。怀疑急性肠系膜缺血，申请了增强CT血管造影。她的eGFR为25 mL/min/1.73 m²。应该不用对比剂吗？

::: solution
不应该。急性肠系膜缺血死亡率高，诊断依赖于用静脉对比剂显示动脉；平扫无法回答这个问题。对比剂相关肾损伤的风险在使用现代对比剂时并不大，远小于漏诊或延误诊断的风险。她的肾功能下降是**评估和减轻**风险的理由，而不是拒绝检查的理由：与放射科医生确认临床需要，确保在复苏过程中给予充分水化，审查肾毒性药物（如服用二甲双胍也一并审查），并在检查后监测肾功能。记录决定和讨论过程。同样的原则广泛适用：当替代选择是危险的漏诊时，禁忌证是相对的。
:::
:::

## 辐射剂量与风险

**有效剂量**以**毫希沃特（mSv）**为单位，在考虑辐射类型和受照组织敏感性的基础上，估计一次辐射照射的总体风险。它是比较不同照射和人群的工具，而不是对个人风险的精确度量。

::: definition 典型有效剂量 {#def-dose}
成人的典型有效剂量因医疗机构和扫描方案而异，但其数量级为：

| 检查 | 近似有效剂量 | 相当的天然本底辐射 |
|---|---|---|
| 胸片（后前位） | 约0.02 mSv | 数天 |
| 头部CT | 约1.5~2 mSv | 数月 |
| 胸部CT | 约5~7 mSv | 约2年 |
| 腹盆部CT | 约8~10 mSv | 约3年 |

英国天然本底辐射的年平均剂量约为**2.7 mSv**，其中约一半来自氡气。超声和MRI不使用电离辐射。
:::

诊断性辐射的主要风险是一生中患癌风险的小幅增加。为规划目的，国际放射防护委员会对全人群使用约**每希沃特5%**（每mSv 0.005%）的名义风险系数。据此，一次10 mSv的CT会增加约两千分之一的终生患癌风险，而终生患癌的本底风险约为二分之一。**儿童**和年轻人的风险更高，因为他们的组织更敏感，且未来有更多年可能发生癌症；老年人的风险较低。这些都是针对人群的估计；不做扫描而漏掉严重诊断的风险往往大得多。

::: warning 电离辐射检查前要询问妊娠情况
在进行照射腹部或盆腔的检查之前，必须按当地IR(ME)R程序询问有生育可能的人（通常为12~55岁）是否已经或可能怀孕。如果不能排除妊娠，检查可以推迟、改用不使用电离辐射的技术，或在明确论证风险的正当性后进行。妊娠并不禁止必要的影像学检查：对疑似肺栓塞的孕妇做CT肺动脉造影或胸片，给胎儿带来的剂量很小，而漏诊的肺栓塞对母亲和胎儿都危险得多。
:::

## 超声

超声利用换能器向体内发射高频声波（通常为2~15 MHz）。声波在**声阻抗**不同的组织之间的界面处被反射，回声返回所用的时间决定其深度。液体传导声波而不产生回声，显示为黑色（无回声）；组织界面显示为灰色和白色。

超声安全、便携、便宜，并能提供实时图像，因此非常适合用于：

- **液体**：胸腔积液、腹水、心包、膀胱；
- **实质器官和管道**：胆囊结石和胆管扩张、肾脏和肾积水、肝脏；
- **妊娠**和女性盆腔；
- **血管**：多普勒超声测量血流，是深静脉血栓形成和颈动脉狭窄的首选检查；
- **引导操作**：置管、胸腔穿刺抽液、关节注射和活检；
- **心脏**：超声心动图。

它的局限来自物理原理：声波不能很好地穿过**气体**或**骨骼**，因此肠道气体、肥胖和颅骨限制了可见范围，而且结果在很大程度上取决于操作者的技术。临床医生在床旁进行的**床旁超声**（POCUS），例如在创伤中寻找游离液体，如今已广泛使用，但它回答的是狭窄的问题，需要培训和质量管理。

::: example 两位患者腰痛的影像学检查 {#ex-renal}
(a)Jones先生，38岁，右侧腰部剧烈绞痛，向腹股沟放射，尿试纸条潜血阳性。(b)Jaber女士，29岁，妊娠20周，有同样的症状。各自适合做什么影像学检查？

::: solution
(a)对于疑似肾绞痛的成人，NICE指南NG118建议做肾、输尿管和膀胱的**低剂量CT平扫**（CT KUB），最好在就诊后24小时内完成。它是诊断结石最准确的检查，能显示结石的大小和位置（这决定处理方式），还可能发现主动脉瘤等其他诊断。

(b)在**妊娠**期，超声是首选检查，因为它不使用电离辐射。它能显示肾积水和一些结石，但正常妊娠中右侧肾集合系统常有轻度扩张，使解读更加困难。如果诊断仍不确定而临床需要很强，可在专科讨论后考虑不用钆的MRI，少数情况下考虑低剂量CT。对两位患者都应考虑其他诊断的可能（在她，产科原因；在他，如果年纪较大，主动脉瘤渗漏）。
:::
:::

## 磁共振成像

**磁共振成像（MRI）**把患者置于强磁场中（通常为1.5或3特斯拉）。主要存在于水和脂肪中的氢原子核（质子）沿磁场方向排列。射频脉冲使它们偏离排列方向，在它们**弛豫**回去的过程中发出信号，用于形成图像。不同组织中质子的弛豫速度不同，可以通过选择扫描参数来突出某一种差异。

::: definition T1加权与T2加权 {#def-mri}
**T1**是质子恢复与主磁场方向一致排列的时间常数；**T2**是质子在横向平面上失去同步自旋的时间常数。在**T1加权**图像上，**脂肪呈高信号（亮）**，**水（液体）呈低信号（暗）**；T1图像能很好地显示解剖，而缩短T1的**钆**对比剂使强化组织变亮。在**T2加权**图像上，**液体呈高信号**，因此T2图像显示水肿、炎症和许多肿瘤。一个便于记忆的方法：在T2上脑脊液是白的。其他序列，如脂肪抑制、FLAIR（使脑脊液变暗，从而突出紧邻脑脊液的病变）和弥散加权成像（在数分钟至数小时内显示急性梗死），都建立在这些原理之上。
:::

MRI的软组织对比极佳，是检查脑和脊髓（包括疑似**马尾综合征**和脊髓压迫）、关节和软组织，以及许多盆腔和肝脏肿瘤分期的首选检查。其缺点是扫描时间长、噪声大、空间狭小（有些患者无法耐受）、普及程度有限和费用高。

::: definition MRI安全 {#def-mrisafety}
磁场始终存在。**铁磁性物体**可能变成飞射物，植入装置可能移动、发热或失灵。每位患者（和工作人员）在进入扫描室之前都必须经过筛查。重要的问题包括：**心脏起搏器和除颤器**（许多新型装置是“MR条件安全”的，可在特定条件下由心内科配合进行扫描；较旧的装置可能不安全）、**人工耳蜗**、某些**动脉瘤夹**、神经刺激器，以及眼内**金属异物**（有金属加工或打磨史者可能需要先拍眼眶X线片）。**钆对比剂**在严重肾功能损害者中有小的**肾源性系统性纤维化**风险，使用更稳定的大环类对比剂后已非常罕见；少量钆会滞留在组织中；只有在能增加诊断价值时才使用。
:::

## 核医学

核医学显示的是组织的**功能**而不是结构。给予**放射性药物**（与能到达特定组织的分子结合的放射性核素），由γ相机或PET扫描仪探测发出的辐射。例如：

- **通气–灌注（V/Q）扫描**用于肺栓塞，适用于不宜做CT（如某些孕妇或对比剂过敏的患者）且胸片正常的情况。
- **骨显像**用于骨转移和某些骨折。
- **氟代脱氧葡萄糖（FDG）PET-CT**：FDG是一种被代谢活跃组织摄取的葡萄糖类似物，用于许多癌症的分期和疗效评估。炎症也会摄取FDG，从而导致假阳性。
- **甲状腺显像**用于区分甲状腺功能亢进症的病因。

## 阅读报告并据以行动

大多数临床医生阅读的是放射科医生的报告，而不是亲自解读每一幅图像，但对于影响其当下决策的发现（气胸、导管位置），他们仍然必须亲自看图像。要阅读**整份报告**，而不只是结论，并且**据以行动**：未被确认和未被处理的结果是公认的伤害来源（[[clinical-skills/patient-safety]]）。**意外发现**很常见，例如在因其他原因做的扫描中发现的小的肾上腺或肺结节；大多数是良性的，国家或当地指南规定了哪些需要随访，因此应告知患者并安排随访，而不是置之不理或过度检查。

::: quiz
在后前位胸片上，左下肺野的一片阴影伴左侧膈面轮廓消失，而左心缘仍然清晰。异常最可能位于哪里？
- [ ] 舌段
- [x] 左肺下叶
- [ ] 左肺上叶（前段）
- [ ] 前纵隔
::: solution
膈面轮廓消失表明阴影与膈肌相贴，即位于下叶。舌段紧贴左心缘；由于左心缘保留，舌段不太可能受累。这就是轮廓征。
:::

::: history
1895年11月，**伦琴（Wilhelm Conrad Röntgen）**在维尔茨堡用阴极射线管做实验时，注意到房间另一头的荧光屏在发光；几周之内，他拍下了妻子手部的X线片，使X射线成为世界新闻，并于1901年获得首届诺贝尔物理学奖。早期的放射学家付出了惨痛的代价才认识到辐射的危害。1958年，**Ian Donald**及其同事在格拉斯哥发表了用超声检查腹部肿块的论文，为产科超声开辟了道路。EMI公司的**豪恩斯菲尔德（Godfrey Hounsfield）**制造了第一台临床CT扫描仪，1971年在伦敦扫描了第一位患者；他与独立推导出其数学原理的**科马克（Allan Cormack）**分享了1979年诺贝尔奖。**劳特伯（Paul Lauterbur）**和**曼斯菲尔德（Peter Mansfield）**因发展MRI而获得2003年诺贝尔奖。
:::

## 后续内容

特定急症的影像学在[[emergency-critical-care/acute-assessment]]和[[surgery/acute-abdomen]]中展开，在各系统课程中也有涉及，如[[respiratory/lung-cancer-pleura]]和[[nervous-system/stroke]]。检查准确性的统计学同样适用于影像学和血液检查（[[clinical-skills/laboratory-tests]]）。

::: summary
- 每项影像学检查都应回答一个明确的临床问题；按照IR(ME)R，电离辐射必须正当并最优化。
- X线的对比度来自衰减的差异；平片显示五种密度，轮廓征可以定位病变。
- 系统地阅读胸片：基本信息、投照方式、质量，然后是气道、肺、心脏、膈肌、其他一切和复查区域；核查每一根管线。
- CT值以亨氏单位表示（水为0，空气为−1000）；使用合适的窗；碘对比剂有发生反应和肾损伤的小风险。
- 有效剂量从约0.02 mSv（胸片）到约10 mSv（腹盆部CT）不等，而英国本底辐射约为每年2.7 mSv；儿童更敏感。
- 超声安全、便携，最适合检查液体、胆囊、肾脏、妊娠和血管，但受气体、骨骼和操作者技术的限制。
- MRI的软组织对比最好（T1：脂肪亮；T2：液体亮），但需要严格的安全筛查。
- 核医学和PET-CT显示功能；报告必须完整阅读并据以行动。
:::

## 习题

::: exercise 相当的本底辐射 {level=1 check="round(10/2.7*10)/10"}
一次腹盆部CT的有效剂量约为10 mSv。这相当于多少年的英国平均本底辐射（每年2.7 mSv）？四舍五入到一位小数。
::: solution
$10/2.7 = 3.70$，即**3.7年**。
:::
:::

::: exercise 衰减 {level=1 check="round(exp(-0.2*10)*1000)/1000"}
一束X射线穿过10 cm线性衰减系数为每厘米0.2的物质。透射的比例是多少？四舍五入到三位小数。
::: solution
$I/I_0 = e^{-0.2 \times 10} = e^{-2} = 0.135$。约13.5%的射线透过。
:::
:::

::: exercise 亮还是暗 {level=1}
分别说出下列各项是亮还是暗：(a)T2加权MRI上的脑脊液；(b)T1加权MRI上的皮下脂肪；(c)超声上的肠内气体（及其原因）；(d)CT软组织窗上肺内的空气。
::: solution
(a)亮（T2上液体呈高信号）。(b)亮（T1上脂肪呈高信号）。(c)气体在其表面反射几乎全部声波，形成一条亮线，其后伴声影和混响伪像，因此气体后方的结构看不见。(d)黑（−1000 HU，远低于软组织窗）。
:::
:::

::: exercise 估算终生风险 {level=2 check="1/(0.05*0.008)"}
用每希沃特5%的名义风险系数，估算一次8 mSv胸部CT增加的终生患癌风险，并表示为“N分之一”。给出N的精确值。
::: solution
$8 \text{ mSv} = 0.008$ Sv。风险$= 0.05 \times 0.008 = 0.0004$，即$1/0.0004 = 2{,}500$分之一。这是针对人群的估计；对儿童会更高，对老年人会更低，并且必须与诊断带来的获益相权衡。
:::
:::

::: exercise 选择检查 {level=2}
提出最合适的首选影像学检查并说明理由：(a)一位进食油腻食物后右上腹痛的女性，疑似胆囊结石；(b)疑似深静脉血栓形成；(c)一位突发剧烈头痛的男性，疑似急性颅内出血；(d)疑似马尾综合征。
::: solution
(a)超声：对胆囊结石和胆管扩张高度敏感，无辐射。(b)在临床概率评估（深静脉血栓形成的Wells评分）并在适当时检测D-二聚体之后，做下肢静脉加压多普勒超声。(c)头部CT平扫：快速，对急性出血非常敏感，尤其在早期。(d)急诊腰骶椎MRI：能显示神经根以及椎间盘或其他压迫原因。
:::
:::

::: exercise 评估片子 {level=2}
急诊科一张前后位仰卧胸片显示心胸比为0.58。一位同事写下“心脏增大”。这一判断有依据吗？你会怎么做？
::: solution
在这张片子上没有依据。前后位投照会放大心影，因为心脏离探测器较远，而仰卧位和吸气不足会使心影看起来更大，所以心胸比只在质量良好的后前位片上才有效。应描述为“在这张前后位片上无法评估心脏大小”。如果这个问题很重要，可在患者情况允许时拍后前位片，或做超声心动图来回答。
:::
:::

::: exercise 一份MRI申请 {level=3}
一位72岁男性疑因前列腺癌导致脊髓压迫，已预约紧急全脊柱MRI。他2009年装了永久起搏器，曾做过焊工。需要做哪些安全核查？如果MRI不安全，你会怎么做？
::: solution
根据他的病历或装置卡确认起搏系统（脉冲发生器和导线），并与心内科或装置团队以及放射科核实它是否为**MR条件安全**。2009年植入的装置可能不是；即使是MR条件安全的系统，也需要满足特定条件（程控、监护、场强）。他做过焊工，提示**眼内可能有金属碎屑**：询问眼外伤史，并考虑在MRI前拍眼眶X线片。如果MRI不安全或会被延误，可用**脊柱CT**（常需增强）作为替代来识别压迫；治疗（如糖皮质激素以及按当地转移性脊髓压迫路径转诊肿瘤科和脊柱团队）不应为了等待完美的影像而推迟。
:::
:::

::: exercise 意外发现的结节 {level=3}
一位58岁吸烟者的CT肺动脉造影未见肺栓塞，但报告写道：“右肺上叶见一7 mm实性结节；建议按指南随访。”他当天出院。描述其中的安全风险，以及系统应如何处理这一发现。
::: solution
风险：这一发现不是扫描的目的，忙碌的团队可能只看结论（“无肺栓塞”）而漏掉它；患者可能没有被告知；随访责任可能在急诊科、全科医生和呼吸科之间模糊不清；肺癌可能被漏诊。系统应当：确保申请医生以电子方式确认收到结果；在出院前或以书面形式告知患者并加以解释；在出院小结中写明由谁安排随访；使用一条明确的路径（如按英国胸科学会指南由放射科主导的意外结节服务）追踪患者，使随访不依赖于某一个人的记忆。还应提供戒烟支持。
:::
