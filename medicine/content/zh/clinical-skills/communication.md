医学的大部分工作是在谈话中完成的。诊断通常由患者所说的话提示；治疗只有在患者理解并选择接受时才会起效；许多对医疗的投诉针对的是话是怎么说的，而不是事情是怎么做的。因此，沟通是一项临床技能，与听诊同属一类：它有结构，可以观察和评估，并通过刻意练习和反馈得到提高。

本章阐述问诊的模型、倾听与解释的微技能、如何共同决策和沟通风险，以及如何应对学生觉得最难的谈话：坏消息、愤怒、不确定性和借助口译员的交流。下一章[[clinical-skills/history-taking]]将运用这些技能来采集诊断性病史。

## 为什么沟通是一项临床技能

良好的沟通并不只是态度友善。它能改变可以测量的结局。

- **诊断准确性。** 在普通门诊中，病史提供了得出诊断所用的大部分信息。过早被打断的患者也许永远不会说出那个关键症状。
- **依从性。** 人们无法执行自己没有理解或并不认同的方案。长期病的处方药物有相当一部分没有按医嘱服用，而解释不清是可以改变的原因之一。
- **安全。** 对抗凝药、胰岛素或何时求助的指导被误解，是公认的伤害来源。专业人员之间的沟通失败也是如此，[[clinical-skills/records-handover]]和[[clinical-skills/patient-safety]]将讨论这一点。
- **就医体验与信任。** 患者评判医疗，很大程度上看自己是否被倾听、被尊重；投诉和诉讼往往始于一次糟糕的谈话。

这些技能是可以学会的。教学时采用观察问诊、标准化病人和录像回顾，因为人们并不善于评判自己的沟通：几乎每位临床医生都认为自己会让患者把话说完，而录音显示许多人并非如此。

::: definition 问诊及其任务 {#def-consultation}
**问诊**（consultation）是临床医生与患者（常常还有亲属或照护者）之间有结构的会面，包含两类任务。**内容任务**是讨论什么：问题、发现、解释和方案。**过程任务**是如何讨论：顺序、提问、倾听、结构和关系。一次问诊可能内容完全正确却仍然失败，因为过程出了问题，例如正确的方案讲得太快，患者离开时并没有理解。
:::

## 问诊的模型

描述问诊的模型有好几种。英国和加拿大医学院最常教授的是**Calgary–Cambridge指南**，由Suzanne Kurtz和Jonathan Silverman于20世纪90年代提出，后来与Juliet Draper一起加以扩展。

::: definition Calgary–Cambridge指南 {#def-calgary}
**Calgary–Cambridge指南**把问诊分为五个依次进行的阶段：

1. **开始问诊**：做好准备、问候、介绍自己及身份，并弄清来访的所有原因。
2. **收集信息**：从生物医学和患者两个角度探究问题。
3. **体格检查**。
4. **解释与计划**：给予适量、适当类型的信息，帮助患者理解和记住，并达成共同的方案。
5. **结束问诊**：总结、商定下一步并做好安全网。

有两项任务贯穿全部五个阶段：**提供结构**（使问诊的组织方式清晰可见）和**建立关系**（融洽、共情并让患者参与）。
:::

这份指南不是剧本，而是一张地图，告诉你身处何处、哪些事尚未完成、每个阶段需要哪些技能。有经验的临床医生可能在各阶段之间来回切换；指南只是确保不遗漏关键内容。

### 开场：弄清患者为何前来

最初的一分钟在很大程度上决定了后面的走向。良好的开场包括几个要素：

- 核对患者的姓名和出生日期，说出自己的姓名和身份，并说明接下来要做什么（“我是医学生，我会先问一些问题，然后给您做检查，之后Patel医生会过来”）。
- 确保患者舒适，环境尽可能私密。
- 提一个开放式问题（“今天是什么情况让您来看病？”），然后**不打断地倾听**，直到患者说完。
- 在深入探究任何一个问题之前，先**筛查其他关注点**：“今天还有别的事想谈吗？”反复询问，直到回答是“没有”。
- **商定议程**：“您提到了膝盖和疲劳。我们先从疲劳说起好吗？因为那是您最担心的。”

之所以要筛查，是因为患者最先提到的问题往往不是最重要的那个。Beckman和Frankel在1984年的一项研究中发现，医生平均约18秒就会打断患者的开场陈述。Singh Ospina等人2019年对问诊录音的研究发现，临床医生只在约三分之一的就诊中询问了患者的议程；即使询问了，通常也在中位数11秒内就打断了患者。而那些被允许说完的患者只多用了几秒钟。让患者说话几乎不花时间，却可以免去临出门时那句“哦，对了，医生……”。

### 收集信息：由开放到封闭的漏斗

::: definition 开放式与封闭式问题 {#def-questions}
**开放式问题**请患者用自己的话讲述经过（“说说您的疼痛吧”）。**封闭式问题**询问某个具体事实，常常只需回答是或否（“疼痛会放射到手臂吗？”）。**诱导性问题**暗示了答案（“您吸气时疼痛不会加重，对吧？”），应当避免，因为患者倾向于附和。**复合问题**一次问好几件事（“有没有咳嗽、发热或体重下降？”），得到的单一回答并不可靠。
:::

标准的技巧是**由开放到封闭的漏斗**。每进入一个新话题，先用开放式问题，它能得到患者自己的叙述，并常常带出意料之外的信息。然后用聚焦的开放式问题缩小范围（“您上坡时会怎样？”），最后用封闭式问题核实具体特征。过早转向封闭式问题，会把病史变成一张核对清单，漏掉清单之外的一切。

若干**促进技巧**有助于患者继续讲下去：

- **专注的沉默**：停顿几秒往往能引出更多信息。
- **鼓励语**：点头、“请继续”、“嗯”。
- **重复**：把患者最后几个词复述一遍作为提示（“晚上更厉害？”）。
- **澄清**：“您说的头晕是什么意思？”患者说的“头晕”可能指眩晕、头重脚轻或站立不稳，三者的病因各不相同。
- **总结**：不时复述所听到的内容（“那么，疼痛是三周前开始的，在胸口正中，走到公交站时会发作。我说得对吗？”）。总结表明你在倾听，能纠正误解，也给你片刻思考的时间。
- **路标提示**：告诉患者谈话接下来的走向（“现在我想问几个关于您总体健康的问题，这些我对每位患者都会问”）。

### 患者的视角

患同一种病的两个人，可能有非常不同的病患体验。一位胸痛患者确信那只是消化不良；另一位的父亲在同样年纪死于心脏病发作，他非常害怕。他们对这次问诊的需求是不同的。

::: definition 想法、担忧和期望 {#def-ice}
**患者的视角**常概括为**ICE**：

- **Ideas（想法）**：患者认为出了什么问题、是什么引起的。
- **Concerns（担忧）**：患者对此担心什么。
- **Expectations（期望）**：患者希望在这次问诊中得到什么（一项检查、一次转诊、一句安慰、一张病假条）。

许多教师还加上**对生活的影响**：问题如何影响工作、家庭、睡眠和情绪。
:::

询问ICE并不意味着患者期望什么就做什么。它意味着最后的解释可以针对患者实际所想和所怕。一位认为自己的头痛是脑瘤的患者，不会因为一句“这是紧张型头痛”而放心，除非有人同时说：“我知道您担心是肿瘤；下面是我认为不是肿瘤的理由。”

患者常常给出**线索**，而不是直接说出担忧：一声叹息、语气的变化、一句随口的话（“我邻居死前也是这样”）。接住线索（“您刚才提到了邻居，这是您一直在担心的事吗？”）是最有价值、也最常被错过的技能之一。

### 共情与融洽关系

::: definition 共情 {#def-empathy}
**共情**是理解患者的处境和感受，并把这种理解传达给患者。它包含两部分：理解本身，以及表明这种理解的**共情陈述**（“听起来这几周真的让您很害怕”）。共情不同于**同情**（为某人感到难过）；共情把焦点保持在患者的体验上，而不是临床医生自己的反应上。
:::

回应情绪的一个实用框架是**NURSE**，出自严重疾病沟通培训项目VitalTalk：

- **N**ame（命名）情绪：“您看起来很担心。”
- **U**nderstand（理解）：“我能理解这为什么会让您难过。”
- **R**espect（尊重）：“您已经承受了很多。”
- **S**upport（支持）：“我们会一起想办法。”
- **E**xplore（探询）：“再跟我多说说您担心的是什么。”

非语言行为承载了大量信息。与患者坐在同一高度，面向患者，保持适当的目光接触（同时注意不同文化的习惯不同），患者在讲重要事情时不要打字。必须使用电脑时要说明：“我查一下您上次的验血结果，请稍等。”

## 解释与计划

解释是临床医生最常做不好的环节。关于记忆的研究表明，患者会忘记所听内容的很大一部分，而记得最牢的是最先听到的内容和理解得最好的内容。

::: theorem 有效解释的原则 {#thm-explain}
当临床医生做到以下几点时，信息更可能被理解、记住并付诸行动：

1. 开始前**先了解患者已经知道什么**、想知道什么。
2. **分成小块给出信息**，每块之后**核对理解**（*分块核对*，chunk and check）。
3. **使用通俗语言**，必须使用的专业词语要加以解释。
4. **分类并作路标提示**：“我想解释三件事：我认为是什么问题、要做的检查和治疗。”
5. **重复并总结**要点，并提供可带走的书面或图示材料。
6. **把解释与患者自己的想法和担忧联系起来**。
7. **请患者复述**他们将要做什么（*回授法*，teach-back）。
:::

::: proof 这些原则为何有效 {#prf-explain}
工作记忆一次只能容纳少数几项内容，而焦虑会使其进一步缩小。分块使每一部分都在这个限度之内；每块之后的核对能在下一部分建立在误解之上以前发现误解。路标提示给听者一个可以挂靠各部分的框架，有助于记忆。把解释与患者自己的信念相联系，是替换错误的认识，而不是另加一个可能被遗忘的竞争性认识。回授法直接检验理解：问“您明白了吗？”只会换来一句礼貌的“明白”，而“您能告诉我您打算怎样服用新药吗？这样我知道自己讲清楚了没有”则能暴露漏洞。把回授法表述为检查临床医生的解释，而不是考患者，能保持对患者的尊重。
:::

**健康素养**是获取、理解和使用健康信息的能力。健康素养不足很常见，从外表或学历上看不出来，并与较差的结局相关。实际的应对是采用**普遍预防**的做法：对每个人都使用通俗语言和回授法，而不是去猜谁需要。

临床医生觉得简单的词，常常被误解。“阳性”结果听起来像好事，却可能表示存在疾病；“慢性”可能被听成“严重”；“良性”和“恶性”可能完全听不懂；“病变”“未见异常”“阴性”都需要转换成日常说法。

::: example 解释新诊断的2型糖尿病 {#ex-explain}
Okafor先生，54岁，公交车司机，两次HbA1c均为58 mmol/mol，达到2型糖尿病的诊断阈值。解释应当如何组织？

::: solution
1. **了解他知道什么、害怕什么。** “以前有人跟您提过糖尿病吗？您对它了解多少？”他说母亲有糖尿病并截了一条腿，他还担心自己的驾驶执照。
2. **路标提示。** “我想解释三件事：这项检查说明了什么、糖尿病对您意味着什么、我们能做些什么。之后我再回答您关于开车的问题。”
3. **分块核对。** 用通俗的话解释，这项血液检查反映的是大约两到三个月内的平均血糖，而他的数值已经高到可以称为糖尿病。停一下：“到这里都清楚吗？”
4. **直接回应他的担忧。** 在他母亲那一代，截肢与多年高血糖以及没有被发现的足部问题有关；定期检查双脚和良好的控制能大大降低这种可能。关于开车，说明公交车司机的规定取决于治疗方式：饮食控制和许多口服药不会妨碍他开车，而某些治疗有他必须遵守的规定；告诉他你会和他一起查阅英国驾驶员与车辆执照局（DVLA）的现行指引，而不是凭猜测作答。
5. **共同制订计划**并**使用回授法。** 商定第一步（结构化教育课程、生活方式改变，并按英国国家卫生与临床优化研究所（NICE）的现行指南在合适时使用药物），请他把计划复述一遍。
6. **提供书面资料**并安排随访。

这种结构几乎没有多花时间，而每一部分都回应了患者在意的事。
:::
:::

### 共同决策

医学中的许多决定都有不止一个合理的选项，正确的选择取决于患者看重什么。**共同决策**就是临床医生和患者一起作出这类决定的过程。

::: definition 共同决策 {#def-sdm}
**共同决策**（shared decision-making）是一个协作过程：临床医生和患者根据关于各选项及其获益和危害的最佳现有证据，以及患者的价值观、偏好和处境，共同选择检查或治疗。NICE指南NG197（2021年）建议在英格兰把它作为常规医疗的一部分。患者可以使用一个简单的提示**BRAN**：有什么**B**enefits（获益）、**R**isks（风险）、**A**lternatives（替代方案），如果什么都不做（do **N**othing）会怎样？
:::

对这一过程常见的三步描述是：**团队对话**（说明存在选择、患者的意见很重要）、**选项对话**（描述各个选项，包括什么都不做，及其获益和危害）和**决策对话**（帮助患者权衡各选项并作出决定）。决策辅助工具，如选项卡（option grid）或NICE患者决策辅助工具，可以为此提供支持。

在英国法律中，告知信息的义务由最高法院在**Montgomery诉Lanarkshire卫生局案（Montgomery v Lanarkshire Health Board, 2015）**中确立：医生必须采取合理的注意，确保患者知晓所推荐治疗的任何**重大风险**以及合理的替代方案。如果处于患者位置的一个理性人很可能会重视某项风险，或者医生知道、或理应知道这位患者会重视它，这项风险就是重大的。英国医学总会（GMC）的指引《决策与同意》（*Decision making and consent*，2020年）遵循同一原则。同意与决策能力见[[medical-ethics-law/consent-capacity]]。

### 沟通风险

数字是共同决策的核心，却很容易被误解，临床医生和患者都是如此。

::: definition 风险的表达方式 {#def-risk}
设某项治疗把某事件的风险从基线风险$p_0$降低到治疗后风险$p_1$。

- **绝对风险降低**为$\text{ARR} = p_0 - p_1$。
- **相对风险降低**为$\text{RRR} = \dfrac{p_0 - p_1}{p_0}$。
- **需治疗人数**为$\text{NNT} = \dfrac{1}{\text{ARR}}$：在所述时间内，需要多少人接受治疗，才能使其中一人避免该事件。
:::

相对风险听起来比绝对风险大，单独使用时可能产生误导。“这能让您的风险减半”可能意味着从千分之二降到千分之一。良好的做法是：

- 给出带时间范围的**绝对风险**（“在100位像您这样的人中，大约10位会在今后10年内发生心脏病发作或卒中”）；
- 尽可能使用**自然频数**（“100人中有10人”），而不是百分数或小数；
- 始终使用**同一个分母**（“100人中10人”和“100人中7人”，而不是“10人中1人”和“14人中1人”）；
- 同时给出获益的机会和受害的机会；
- 使用图示，如图标阵列，许多人觉得它比数字更容易理解。

::: example 用数字谈他汀 {#ex-statin}
Rahman女士，62岁，估计10年内发生心脏病发作或卒中的风险为16%。假设（作为示例数值）他汀类药物能使这一风险相对降低约四分之一。请用她能够使用的方式表达获益。

::: solution
基线风险$p_0 = 0.16$。相对降低25%时，$p_1 = 0.16 \times 0.75 = 0.12$。

$\text{ARR} = 0.16 - 0.12 = 0.04$，所以10年内$\text{NNT} = 1/0.04 = 25$。

用自然频数表达：“在100位像您这样的女性中，如果不服他汀，大约16位会在今后10年内发生心脏病发作或卒中。如果这100人都服用他汀，大约是12位。也就是说，100人中大约有4人因此避免了发病，其余96人无论吃不吃，结局都一样。”这样她就能把这一点与每天服药的负担和出现副作用的可能相权衡。决定由她作出；临床医生的职责是把数字讲清楚。
:::
:::

- [ ] “这种药能把您的风险降低50%，所以非常有效。”
- [ ] “这种药对98%的人有效。”
::: solution
第二种说法给出了带时间范围、分母相同的绝对风险，患者能看出100人中大约2人获益。“风险减半”和“50%”是正确的相对表述，却掩盖了绝对变化很小这一事实。“对98%的人有效”是错误的：100人中的96人本来就不会骨折。
:::
:::

## 结束问诊

结束阶段是方案变成行动的地方。它应当包括：

- 对问题和方案的简短**总结**。
- 患者和临床医生双方**商定的下一步**：谁在什么时候之前做什么。
- **安全网**：需要留意什么、一旦出现该怎么办，以及即使没有变化也应在何时复诊。好的安全网是具体的：“如果疼痛变成持续性的，或者您发现尿中带血或发热，当天就给诊所打电话，下班时间打111。如果两周后还没好转，就预约再来看我。”
- **最后的确认**：“您还有别的想问的吗？”

::: warning 安全网不是一句含糊的“不好再来”
“如果加重了再来”并没有告诉患者“加重”是什么意思、该多快行动、该去哪里。许多严重的漏诊，包括儿童脑膜炎和在初级保健中就诊的癌症，都涉及一次安全网含糊或未作记录的首诊。要说明具体的警示特征、时间范围、就医途径，并把你说过的话记录下来。
:::

## 困难的谈话

### 告知坏消息

**坏消息**是任何急剧地、负面地改变一个人对自己未来看法的信息。什么算坏消息因人而异：对一个靠开车谋生的人，糖尿病的诊断可能是毁灭性的。

::: definition SPIKES模式 {#def-spikes}
**SPIKES**由Baile等人于2000年针对肿瘤科提出，是告知坏消息的六步框架：

- **S**etting（环境）：私密的房间，坐下来，备好纸巾，把呼叫机交给同事，合适的人在场（问患者希望谁陪在身边）。
- **P**erception（认知）：了解患者已经知道或怀疑什么（“关于为什么要做这次扫描，您听到了些什么？”）。
- **I**nvitation（邀请）：了解患者想知道多少、以什么方式知道（“您希望我详细讲讲结果吗？”）。
- **K**nowledge（告知）：先给一个**预警**（“恐怕结果不是我们所希望的”），然后用通俗的话分小块说出消息，避免术语和委婉语。
- **E**motions（情绪）：以共情回应情绪；允许沉默。
- **S**trategy and summary（策略与总结）：在患者准备好时，概述下一步并加以总结；安排随访并说明如何联系。
:::

这项技能很大程度上在于**节奏**。听到消息本身之后，许多患者几乎听不进别的内容，因此详细的计划可能需要第二次会面。沉默是可以接受的，而且常常是必要的。措辞很重要：如果诊断是“癌症”，就应当直接说出来，因为“一个肿块”或“一些异常细胞”之类的委婉说法会让人无所适从。

::: example 告诉儿子他的父亲已经去世 {#ex-death}
一位79岁男性在家中心脏骤停后，在急诊科去世。他的儿子刚刚赶到。SPIKES该如何运用？

::: solution
- **环境。** 带儿子到安静的家属室，由一位会留下来陪他的护士同行。各自作自我介绍，坐下，并确认他的身份。
- **认知。** “关于今天早上您父亲发生的事，您知道些什么？”他说急救人员告诉他父亲倒下了，他们“正在抢救”。
- **邀请与告知。** 在这种情况下，儿子需要立即知道。先给预警，然后用平实的话说出消息：“非常抱歉，我有一个非常坏的消息。您父亲在家里时心脏停止了跳动。急救人员和我们的团队努力了很长时间想让它恢复跳动，但是没能成功。非常抱歉，他已经去世了。”要用“去世了”这样明确的词，而不是“走了”或“我们没能留住他”，后者可能被误听。
- **情绪。** 停下来，允许沉默。回应他所表现出的情绪：震惊、哭泣、愤怒或提问。“我能看出这对您是个可怕的打击。”
- **策略与总结。** 在他准备好时，谈：他是否想见父亲、还需要通知谁、接下来会怎样（在相关情况下，死因裁判官或医学审查员的作用），以及可提供的丧亲支持。表示现在或以后都可以回答他的问题。
:::
:::

### 愤怒、投诉与道歉

愤怒通常是对恐惧、失去控制、疼痛、等待或感知到的医疗失误的反应。有效的做法是：**承认**这种情绪，不带防御地**倾听**，**弄清**具体的担忧，为出错之处或对方的经历**道歉**，并**说明**接下来会怎样。道歉并不等于承认法律责任。自2014年起，英格兰的医疗和照护机构在发生须通报的安全事件时负有法定的**坦诚义务**，而每一位医生和护士在出现差错时都负有开诚布公的职业义务（[[clinical-skills/patient-safety]]）。

人身安全第一：如果有人威胁或施暴，应离开、寻求帮助并遵循当地政策。

### 不确定性

许多问诊结束时并没有确定的诊断。只要有一个计划，患者通常能比面对虚假的确定更好地应对诚实的不确定：“我认为这不是什么严重的问题，但现在还不能完全确定。我们接下来这样做，而如果出现这些情况，我希望早点见到您。”这就是把安全网运用于不确定性。

## 跨越障碍的沟通

### 语言与口译员

当患者和临床医生没有一种足以进行医疗谈话的共同语言时，应当使用**专业口译员**。NHS England的指引不鼓励依赖家庭成员，除紧急情况外不应让儿童口译，因为家庭成员口译时可能过滤或改动所说的话，不能指望他们懂得医学术语，而且他们本身可能就是问题的一部分（例如在家庭暴力中）。

借助口译员的良好做法：

- 事先向口译员简要说明问诊目的。
- 用第一人称**直接对患者说话**（“您疼了多久了？”），而不是“问她疼了多久……”。
- 使用短句，并停顿以便口译。
- 避免俗语和术语。
- 留出更多时间，并通过口译员用回授法核对理解。
- 在病历中记录口译员的姓名或编号。

### 听力、视力、学习障碍与认知障碍

询问对方喜欢的沟通方式。对聋人可能需要英国手语口译员；对读唇的人，要在光线好的地方面对他们，不要遮住嘴。自2016年起，NHS的**无障碍信息标准**（Accessible Information Standard）要求各服务机构识别、记录并满足人们的沟通需求。有学习障碍的人可能随身带有“医院护照”，说明他们如何沟通、需要什么；家人和照护者往往最清楚如何提供帮助。使用简单的词，一次只讲一个意思，必要时借助图片。绝不能因为某个诊断或沟通困难就认定一个人缺乏决策能力。

### 远程问诊

电话和视频问诊会丢失大量非语言信息。它们需要明确核实患者身份、明确核对理解，在情况不符时更低门槛地安排面诊，并仔细记录安全网。

::: example 通过电话口译员进行问诊 {#ex-interpreter}
Nguyen女士，71岁，讲越南语，英语很少。她14岁的孙子陪她来门诊，并提出由他来翻译。她一直在消瘦。临床医生应当怎么做？

::: solution
感谢孙子，但说明本机构的每一次医疗谈话都使用专业口译员。孩子不应担任口译：他可能不懂这些词，谈话可能涉及祖母不希望他听到的内容（体重下降提示可能是癌症），而且这对他是不公平的负担。预约电话或视频口译员。向口译员说明：这是一次关于体重下降的新患者问诊。用短句直接对Nguyen女士说话，提开放式问题，停顿以便口译，并核实她的想法和担忧。结束时，请她通过口译员复述计划，并记录口译员的编号。如果孙子留在房间里，应通过口译员私下问Nguyen女士是否愿意他在场。
:::
:::

::: history
医学对谈话本身的关注由来已久。希波克拉底文集就对医生在床旁的举止提出了建议。20世纪50年代，精神分析学家**巴林特（Michael Balint）**在伦敦与全科医生举办研讨会，其成果出版为《医生、患者与疾病》（*The Doctor, His Patient and the Illness*，1957年），书中认为医生自身的行为就像一种药物，既有疗效也有副作用。1976年，**Patrick Byrne和Barrie Long**在《医生与患者的谈话》（*Doctors Talking to Patients*）中分析了一千多次英国全科问诊的录音，表明其中大多数是以医生为中心的。从20世纪80年代起，沟通成为讲授和考核的科目：**Suzanne Kurtz**和**Jonathan Silverman**在20世纪90年代发表了Calgary–Cambridge指南，**Walter Baile**、**Robert Buckman**等人于2000年描述了SPIKES。沟通考站如今是客观结构化临床考试（OSCE）和毕业后考试的标准组成部分。
:::

## 后续内容

本章的沟通技能是以下内容的基础：[[clinical-skills/history-taking]]中的诊断性病史、[[clinical-skills/laboratory-tests]]中检查结果的解释，以及[[clinical-skills/records-handover]]中的交接谈话。同意与决策能力见[[medical-ethics-law/consent-capacity]]，关于严重疾病和生命终末期的谈话见[[geriatrics-palliative/end-of-life-care]]。

::: summary
- 问诊包含内容任务和过程任务；Calgary–Cambridge指南把它们组织为五个阶段，结构和关系建立贯穿始终。
- 让患者说完开场陈述，筛查其他关注点（“还有别的吗？”），并商定议程。
- 运用由开放到封闭的漏斗、促进技巧、澄清和定期总结；探询患者的想法、担忧和期望，并接住线索。
- 分小块解释并核对理解，使用通俗语言，把解释与患者的信念联系起来，用回授法确认。
- 在存在合理选项时共同决策；给出带时间范围、分母相同的绝对风险，并把获益换算成NNT或自然频数。
- 以总结、商定的下一步和具体且有记录的安全网结束问诊。
- 用SPIKES告知坏消息，用共情陈述回应情绪（NURSE），使用专业口译员，并根据每个人的需要调整沟通方式。
:::

## 习题

::: exercise 开放、封闭还是诱导 {level=1}
把下列问题分别归为开放式、封闭式、诱导性或复合问题，并改写不好的问题：(a)“说说您的呼吸情况。”(b)“您没有咳血，对吧？”(c)“您有胸痛、心悸或脚踝肿吗？”(d)“疼痛会让您夜里痛醒吗？”
::: solution
(a)开放式；是很好的第一个问题。(b)诱导性；它引导患者回答“没有”。改写为“您咳过血吗？”(c)复合问题；一句“没有”并不能说明否认的是哪个症状。应分别询问。(d)封闭式；在患者用自己的话描述疼痛之后，在漏斗的后段使用是恰当的。
:::
:::

::: exercise 绝对与相对 {level=1 check="40"}
某疫苗使一个冬季内某种感染的风险从10%降到7.5%。需要给多少人接种，才能使其中一人在这个冬季避免感染？给出精确数值。
::: hint
先求绝对风险降低。
:::
::: solution
$\text{ARR} = 0.10 - 0.075 = 0.025$，所以$\text{NNT} = 1/0.025 = 40$。相对风险降低为$0.025/0.10 = 25\%$。
:::
:::

::: exercise 改写成自然频数 {level=1}
把下面这句话改写给患者听：“该操作有0.5%的大出血风险和2%的小出血风险。”
::: solution
“在1,000位做这项操作的人中，大约5人会有大出血，大约20人会有小出血。其余975人左右没有出血问题。”使用同一个分母（1,000）可以避免把“200人中1人”和“50人中1人”混在一起，那样人们很难比较。
:::
:::

::: exercise 第二个关注点 {level=2}
一位45岁女性因背痛就诊。问诊进行了十分钟，她起身要走时说：“哦，对了，我上周在乳房摸到一个肿块。”解释问诊开始时可能出了什么问题，以及临床医生现在应当怎么做。
::: solution
临床医生在开场时很可能没有筛查其他关注点（“今天还有别的想谈的吗？”），于是议程由最先提到的问题决定，而那个问题对她来说也许更容易开口。现在临床医生应当承认这一担忧，重新坐下，认真对待：新发乳房肿块需要询问病史、体格检查，并根据检查所见和年龄，按疑似癌症路径紧急转诊。如果时间确实不允许全面评估，最低限度是今天简要询问病史并检查，或很快安排一个确定的预约，而不是含糊地请她再预约。
:::
:::

::: exercise 用回授法确认心力衰竭的计划 {level=2}
一位68岁心力衰竭男性出院，带回一种利尿剂，并被告知每天称体重。写出你用来以回授法核对他理解的问题，并说明如果他答不上来你会怎么做。
::: solution
可能的问题（表述为检查你自己的解释）：“为了确认我讲清楚了，您能告诉我您什么时候称体重、看到数字后怎么做吗？”“出现什么情况您会给心衰专科护士打电话？”“哪一种是利尿药，您什么时候吃？”期望的回答：每天早晨排尿后、早餐前，穿相近的衣服称重；如果几天内体重增加超过与团队商定的数值，或者气促或脚踝水肿加重，就打电话。如果他答不上来，失败的是解释而不是患者：换一种说法重新解释他遗漏的部分，用写有他自己目标数值的书面计划，在他愿意时请家人参与，然后再核对一次。
:::
:::

::: exercise 选择口译员 {level=2}
对下列每种情况，说明家庭成员是否适合担任口译员及其理由：(a)心脏骤停抢救呼叫，患者的女儿是唯一能告诉团队发生了什么的人；(b)讨论宫颈筛查结果的常规门诊，患者的丈夫提出由他翻译；(c)一位成年患者在专业口译员已被提供并解释之后，仍希望由她的姐妹翻译。
::: solution
(a)紧急情况下可以接受：立即获得信息比其弊端更重要；在可行时尽快安排专业口译员。(b)不合适：应使用专业口译员。话题私密，丈夫可能过滤信息；不单独与她交谈，就无法排除胁迫或虐待的可能。(c)如果她有决策能力且是自愿选择，通常可以接受，但要记录提供口译员的情况和她的决定；即便如此，好的做法仍是在问诊的部分时间里借助专业口译员单独与她交谈，尤其是涉及敏感话题时。
:::
:::

::: exercise 重大风险 {level=3}
一位外科医生正在为一位35岁的职业小提琴手签署腕管松解术的知情同意。一种罕见并发症是手部持续麻木或无力。外科医生决定不提这一点，因为它不常见。根据Montgomery判决，说明这是否可以接受。
::: solution
不可以接受。按照Montgomery判决，风险是否重大要从患者的角度判断：如果处于患者位置的理性人会重视这项风险，或者医生知道、或理应知道这位患者会重视它，这项风险就是重大的。对一位职业小提琴手而言，任何手功能持久丧失的风险显然都很重要，无论多么罕见。外科医生必须告知这一风险以及替代方案（包括夹板、注射或不治疗），并给她提问的机会。仅仅罕见并不使一项风险变得不重大。这次讨论应当记录在案。
:::
:::

::: exercise 计划一次坏消息谈话 {level=3}
一位52岁女性因体重下降做了CT扫描，显示胰腺肿块伴肝脏病灶，极可能是转移性癌症。她明天将独自来门诊。用SPIKES计划这次谈话，包括告知消息时你要说的头两句话，以及你将如何应对“我还有多少时间？”这个问题。
::: solution
**环境：**私密的房间，预留足够的时间，专科护士在场，交出呼叫机；开始时问她是否希望有人加入，无论是到场还是通过电话。**认知：**“关于为什么要做这次扫描，您是怎么理解的？”**邀请：**“结果出来了。您希望我怎样跟您讲？”**告知：**先给预警，然后分小块用平实的话说，例如：“很抱歉，扫描发现了一个严重的问题。胰腺上有一个肿块，看起来已经扩散到了肝脏，这意味着它很可能是癌症。”然后停下来。**情绪：**沉默，命名并承认情绪，递上纸巾，给她时间。**策略与总结：**说明需要做活检以确定类型并指导治疗，团队会和她讨论各种选择，以及如何联系专科护士。对于“我还有多少时间？”：先探询她为什么这样问、想知道什么（“这是个重要的问题。我可以问问您在想什么吗？”）；以范围和不确定性诚实作答，而不是给出一个单一数字，并说明在活检和治疗讨论之后情况会更清楚。安排尽早随访，并提供书面联系方式。
:::
:::
