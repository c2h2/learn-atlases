临床沟通是证据基础最大而教学时间最少的手术：会诊、交接、披露、家属会议、关于风险/不确定性与死亡的困难谈话。**本章讲述医学访谈的解剖（Calgary-Cambridge地图及其议题设定与路标机制、倾听与提问比例及其结局数据、用于改变谈话的动机式访谈）、在医师之间安全传递信息的结构化工具（SBAR及其家族、床旁交接、复述规则）、困难谈话（用SPIKES告知坏消息、以绝对数字的风险沟通、带诚实语法的预后判断、及照护目标框架）、冲突与修复（投诉、道歉、愤怒家属、当着患者的分歧）、及同一套技能必须重新调音的特殊条件：口译、行为能力、儿童、孤独症与学习障碍、及电话与屏幕会诊。**

## 访谈

::: definition 作为操作的医学访谈 {#def-interview}
**地图：Calgary-Cambridge指南五个目的——发展共同理解、把患者的世界纳入决定、建立关系、找到患者的声音、使有效治疗成为可能——操作化为短会诊的编排。开场设定议题：尽早邀请患者自己的清单（“还有什么困扰你”动作）只花几十秒、却防住门把披露、终场告白效应、浪费数周。病史以开放式对封闭式问题的实用比例采集——经典影片显示医师在二十秒内打断、而纠正 simply 是让第一分钟不被审查地流走——配定期总结使理解的错误在便宜时浮现。结尾是患者语言里的计划：回授（“告诉我我们决定了什么、让我检查我解释清楚了”）、明确的红旗、书面或屏幕摘要、及定义的归来点。倾听数据不时兴但持久：更早披露主要担忧的患者结局与依从更好、而电脑是现代的打断——故有把你正在打字的内容口述与展示屏幕的微技能。建议一半知道单靠信息改变很少：改变谈话借用动机式访谈——开放问题、肯定、反映、总结；随阻力滚动而非追逐；决策平衡；引出-提供-引出而非说教——附诚实警诫：精神重于技术、而十一分钟的号源是每篇实施论文点名的真实障碍。共同决策层是数感：带分母的绝对风险胜过相对风险、框架可靠地移动选择（98%生存与2%死亡是同一台手术与不同决定）、决策辅助改善知识并减少后悔、及法律如今假定的同意标准是理解不是签名——使风险沟通成为应教的临床技能而非应发的传单。最后是安全网：回授、“如果一夜之间变了你会怎么做”脚本、及患者凌晨三点能读到的地方写下的计划。**
:::

## 传递信息

::: definition 交接、转诊与电话医学 {#def-handover}
**交接是信息死去之处、几乎每次恶化与用药错误审查都是、所以结构化工具挣得其训练：SBAR（情况、背景、评估、建议）及其变体——ISBAR加身份、SBAR-R加资源、SOAP用于查房、及儿科的I-PASS带其病情严重度评分与“若-则”应急条款。试验实际记功的有限而具体：标准格式、明确的提问机会（双向交接比独白错误少）、对任何剂量与指示的复述（“复述不粗鲁”）、带患者自己关于他担心什么原话的床旁交接、及带打断控制的受保护交接——“交接时无呼机”试点能否守住告诉你科室真实的安全文化。转诊信是临床物件：应携带转诊原因与转诊者希望回答的具体问题（“评估与处理”的含糊是有文献的接收科抱怨）、让红旗醒目而非埋没、并按坦承与病历文化如今标准化的做法抄送患者。电话是一间诊室：报身份并核实身份与号码、复述剂量与时长、命名升级阶梯与几点谁负责、使“我给 registrar 发了邮件”不能成为死胡同。而书面记录承载同一伦理：为下一个读者清晰、不用杀人的缩写、以“进行过对话的证据”而非“被辩护的决定”的语调记录——验尸官称赞而索赔律师引用的语调。**
:::

## 困难的谈话

::: definition 坏消息、风险、不确定性与目标 {#def-hard}
**坏消息规程源自1960年代发现多数医师隐瞒癌症诊断的研究及随后的患者权利逆转；工作仪器是SPIKES：布置房间（私密、就座、纸巾在手、谁应在场）；知觉核查（“你已经了解到什么？”）；邀请（你想知道多少——两个方向都受尊重、因为不知情的权利是真实的）；分块给知识、话语前先发预警弹、然后沉默——六个字后跟六十秒；对贴上标签而非争辩的情绪共情（“我能听到这有多可怕”而非“别担心”）；及带诚实希望的策略与总结——_best case_  hope、最坏打算——及家属离开房间前排好的复诊。预后判断有自己的语法：最好、最坏与平均区间取代单数字死亡线；姑息文献的“我希望”重构（“我希望我在这个可治愈问题上说错了”）；及认识到不确定性就是信息、不是信息的失败——家属记住送达远比记住统计可靠。风险谈话遵循数感规则：带分母的绝对风险、把量级翻译成意义（“你的风险从100分之5到100分之7——这对你改变了什么？”）、及记录的带回授使同意立于理解而非签名。照护目标架构——VitalTalk、PROCEED、重症对话模板——演练同四个动作：你理解什么、你希望什么、你最担心什么、给我们留下什么选择；价值观先于程序菜单；及被问到或家属停滞时给建议、因为“你觉得我们该怎么做？”是医师有权回答的问题。特殊谈话是同一技能带可见布景：口译三人组（对患者说话、排三倍时长的号、掂量家属兼口译的危害）；《行为能力法》下的能力谈话（先无辅助尝试、时间与地点及简化调整、及被尊重的不明智但有能力的拒绝——同意章的地基）；儿童（问他们已经担心什么、用具体诚实的词——“死了”、不是“睡着了”——并回答同胞的问题）；及孤独症与学习障碍适配（提前到访信息、默认而非争取的合理便利）、它们不是附加、而是修正了其假设的会诊。**
:::

::: example 门把披露 {#ex-doorknob}
12分钟的会诊结束；患者起身时说“哦，还有、我好像咳血了”。面对四个候诊患者的医师说：“听起来要紧、你周四能再来吗？”
::: solution
**没留余地的议题设定（[[#def-interview]]、[[clinical-skills/history-taking]]）：错误是被设计掉的物理——第2分钟问“还有什么担心你”只花三十秒；不问、它就在门口到达并消耗下一个星期。咯血在疑癌紧急规则下值得当日评估或加塞、不是仪式化再预约、而安全网必须明确：“如果咳起超过一勺、现在就去急诊。”补救是诚实的：承认清单挤压了会诊、给出今天选项并命名代价（谁的号被挪）、及在他离开前把红旗写下来。科室层面的修复正是癌症延迟文献不断请求的：门开之前的分诊、会诊时长数据、及真正的当日评估能力——加医师自己的复盘、因为对清单的愤怒是道德伤害、而本章结束于倡导章开始之处。**
:::
:::

::: example 未发生的交接 {#ex-handover}
ICU护士在走廊向病房护士交接新入院者：“92床、上机、脓毒症、DNR、家属知情”。病房团队到下午茶时间才知晓顶线复查仍待会诊医师、“家属知情”是女儿的语音留言、而患者当天早上两次问过谁来接他儿子。
::: solution
**结构即尊重（[[#def-handover]]、[[emergency-critical-care/critical-care]]）：走廊独白打破了交接试验记功的每个元素。没有带邀请提问的双向交流——频频点头的护士从未被问“DNR”实际指什么。没有床旁、所以患者是话题不是参与者、而他关于儿子的问题——并不软性软组织信息未提及。也没有纸：治疗顶线活在签名、注明日期、可复查的表格上、不在形容词里。正确仪器是床旁带“若-则”应急的SBAR（“如果他今晚再次去饱和、在任何人改变氧疗前先打给我”）、在病历里存在之前对话中不存在的顶线、记录谁听到了什么的家庭沟通、及一小时内转达的患者请求。科室层面的修复是带打断控制的受保护交接与接收者复述今晚可能杀他的三件事。因为“走廊里说的DNR是谣言——而谣言先到达家属、先于到达病历。”**
:::
:::

## 通向何处

访谈交付的病史在[[clinical-skills/history-taking]]、同意与能力谈话在[[medical-ethics-law/consent-capacity]]、照护目标会诊在[[geriatrics-palliative/palliative-care]]与[[emergency-critical-care/critical-care]]、坦承与道歉在[[clinical-skills/patient-safety]]、精神科应用在[[psychiatry/psychiatric-assessment]]。

::: history
**对医学访谈的现代研究始于它所取代的东西：Osler时代的查房、患者是朗读给学生的文本。纠正来自心理医学：1953年起Michael Balint在伦敦的全科医师研讨班——其1957年书中“医师即药物”传统——及1960年代多伦多与克利夫兰的沟通研究、把摄像机放进诊室并数实际发生了什么。幸存的发现是打断研究：医师先说且常说、经典在二十秒内、这个统计五十年来被反复测量反复确认。教学结构随之而来——1989-1991年Kurtz、Silverman等的Calgary与Cambridge指南、1975年John Harden小组在巴塞罗那发明的OSCE、使沟通在得到一致教学之前早就可考核、及把“沟通技能”从礼貌变成课程的认证浪潮。讲真话提供道德史：1961年的调查发现多数美国医师隐瞒癌症诊断；患者权利运动、医德教学的自由化、及从美国Salgo与Canterbury到苏格兰Montgomery v Lanarkshire的知情同意法学在一代人内逆转了规范——有记录以来最快的伦理大转弯之一、且在任何人证明多数患者确实想要全部事实之前完成（后来跨文化调查显示偏好差异巨大、使“你想知道多少？”成为成人之问）。风险沟通经行为经济学成熟：1970-80年代Tversky与Kahneman的框架与可得性工作、1990年代Gigerenzer学派的自然频率运动、及Cochrane协作患者分支试验的决策辅助文献。坏消息规程把肿瘤学痛苦学到的系统化：1990年代Maguire在贝尔法斯特的对情绪回应工作、2000年Baile等的SPIKES论文、及2010年代姑息复兴的重症对话框架（VitalTalk、PROCEED、“知-望-忧-重”演练）。交接科学自航空与麻醉到来：归于美国海军核潜艇沟通工作的SBAR工具、迁入Kaiser然后是2008年WHO外科核查表；2007年波士顿儿科住院医师的I-PASS（在交接教学试验之后）；及电话交接政策抵抗数十年的复述与闭环规则。数字转向仍在中途：电脑化病历时代的视线在屏幕研究、展示屏幕干预、门户消息与视频会诊、其疫情加速的试验不断发现、注意布景与视线后它多数工作可匹敌面对面、而可靠地失去查体、危机、与装不好应用的家庭。其未解之章是时间：每次沟通进步都在与由他人预算设定的会诊时长竞争、而自Balint以来本领域诚实的总结是：技能可学、测量真实、短缺是结构性的。** - [[clinical-skills/history-taking]]、[[clinical-skills/patient-safety]]、[[medical-ethics-law/consent-capacity]]。**
:::

::: summary
- 会诊是有改变结局步骤的操作：早建议题设定、先开后闭提问配总结、计划的回授、及明确的安全网。
- 建议悄悄失败；改变谈话带动机式访谈精神（伙伴、接纳、引出）好于说教、而风险以绝对数字传达、留意分母与框架。
- 交接是安全屏障：结构化（SBAR/I-PASS）、双向带邀请提问、指示复述、在床旁、写下应急——及只存在于签名表格上的治疗顶线。
- 坏消息靠规程与临在传达：SPIKES、分块后沉默、给情绪贴标签、诚实的希望、及任何人离开前预约的复诊；预后讲区间与“我希望”句。
- 照护目标谈话价值观先于程序（知-望-忧-重）并在被问时以建议收尾；坦承与道歉是对信任、诉讼与学习有测量效应的沟通治疗。
- 特殊布景是同一技能的重新调音：口译（对患者说话）、能力（先无辅助、不明智但自由）、儿童（具体诚实）、孤独症与学习障碍（默认便利）、及屏幕（对视线、沉默与谁进不来刻意）。
:::

## 练习

::: exercise 开场会诊 {level=1}
写出患者因“一个血检结果另外还有事”要求的11分钟号头九十秒。含议题及其协商。
::: solution
**有脚本无照读（[[#def-interview]]）：顺序——“起身迎接、姓名与角色、屏幕转向你或口述（我边谈边看你的病历、让你知道我打什么字）、如可能检查则征得同意；然后邀请：你要了结果还有别的事——今天希望我们处理完什么离开？及大白话协商：结果要两分钟是好消息；给你的另一件事留十五分钟——这个顺序对吗？”证据部分：不设限的开场邀请使真实担忧说出的机会翻倍、命名每个议题的时段防止门口排队、如果第二个问题是她已经轻视两次的乏力、第1分钟买来的议题正是发现它的地方。结尾带回授与红旗句闭环。“**
:::
:::

::: exercise 给出统计 {level=2}
45岁带乳腺癌基因变异的女性读了报纸标题后问“风险增加30%”是什么意思（基线100分之5升到100分之6-7——以此为工作）并核查理解。
::: solution
**自然频率实践（[[#def-interview]]、[[genetics/common-disease-genetics]]）：翻译——”把百分比扔掉：每100个活到六十多岁的女性约5个得乳腺癌；带这个变异约6或7个；即100中大约多1或2例——及视觉：100个点里圈出多出的点的图标阵列比任何句子做得多；然后意义层——要紧的不是数字而是我们能用它做什么：MRI监测与降险选项、在决策点各自以同样的绝对方式框架；及检查：说说你今晚怎么向你姐姐解释抓住两个经典扭曲（相对风险被读成近乎必然的末日、小的绝对上升被读成没什么）。框架纪律：不带偏向地给两个方向（100中93-94个不会）、命名不确定性（估计是像你这样女性的平均、不是对你的判决）、及预约她带着标题引发的焦虑而来真正要求取的遗传与心理随访。**
:::

::: exercise 处理愤怒的配偶 {level=2}
21:40恶化患者的丈夫堵住护士站、大喊“整天被敷衍”；护士要保安、会诊医师已回家、当天的更新是发短信做的。运行降级与修复。
::: solution
**愤怒即情报（[[#def-hard]]、[[clinical-skills/patient-safety]]）：降级——“安静空间与就座的医师（升级研究：愤怒随观众上升、没有观众则削减）、先给情绪贴标签再争内容（你害怕且愤怒、你应该被听见——告诉我你看到的天）、不防御地快速让步事实（短信是错的；对不起——这是我们的问题）、除非迫在眉睫的危险否则请保安为在场而非制服、因为对悲恸者的电击式升级是复审要写的第二起事件；修复——”现在由今晚临床负责人当面给出真正的更新、配明天的具名者与直线电话、把家属问题写下逐条回答、当晚开坦承义务日志；及系统读数——“恶化文献不断发现的短信受害沟通失败是人力与流程事实、所以SEA要问今天更新为何变成可选、21:40家属需要医师时病房怎么办——及人员复盘、因为吞下怒吼的护士需要同款丈夫最终听到的不是你的问题那句话。**
:::

床旁全科医生说“这个我绝不吃抗凝药”；与患者和女儿一起复盘的心脏血管会诊医师听到了。管理那一刻、其后的对话、及记录。
::: solution
**分歧医学（[[#def-handover]]、[[cardiovascular/vascular-disease]]、[[clinical-skills/clinical-reasoning]]）：一刻——”绝不越过患者争吵（临床医师冲突研究的共识：公开分歧摧毁信任、把真正的证据差异变成忠诚竞赛）；脚本——这是正当的视图差异、重要到我们该好好谈——给我们十分钟、然后一起回来找你、然后走廊或联合呼叫：交换真实证据（指征强度、数字、出血风险权衡、谁的试验适用于该患者的年龄与肾脏）、患者价值观当合法决胜因素而非遁词、及若分歧是真医学而非风格则给第二意见或MDT路径。然后计划以一个声音共同交付、诚实地界定不确定性（我们认为X；什么会改变我的想法在这里）；及记录写下推理与异议本身、因为继承这位患者的未来临床医师值得知道问题被辩论过、而非被糊过去——因为指南时代的真相是在边缘处、分歧是必须与其共存之人审计证据的方式。“**

::: exercise 运行虚拟会诊 {level=2}
你的诊所把40%复诊移到视频。两周后：全科医师报告病历获取更安全、患者体验参差、而一次双周心衰患者视频复诊漏掉了严重恶化。写出规程与复审发现。
::: solution
**屏幕医学（[[#def-interview]]、[[cardiovascular/heart-failure]]）：规程——”查体不是检查项时用视频（药物滴定复查、结果谈话、照护者在场的记忆门诊联合就诊）、身体承载信息时面对面（被漏掉的失代偿活在其中的负重与小腿与骶部水肿及颈静脉压发现、首诊、坏消息预约、及团队怀疑用不了平台的所有人）；公平条款（数据与设备与宽带与聋与痴呆盲区被审计、带电话后备与翻译材料、因为虚拟优先可靠地筛选谁能虚拟）；技术（视线对摄像头不对屏幕、你能看清听清我吗检查、容忍沉默不填充、镜头外记下家庭结构、及视频独有改善的今天你面前有什么的药物袋倾倒）；复审发现——“恶化在视频看不见的数字里可见：含糊报告的2公斤体重增加与无人升级的电话分诊笔记——所以修复不是多点还是少点视频、而是结构化患者自采体重与症状、每个心衰复查附上明确升级阈值、常设有任何红旗48小时内转面诊规则、及记录不可查体之处的文书、使下一位临床医师继承不确定性而非完成查体的幻觉。”**

::: exercise 教困难谈话 {level=3}
为ST1医师设计半天沟通工作坊、主题是“停止、限度与临终谈话”、又不变成对他们所缺技能的悼词或对被点名患者的侮辱。
::: solution
**带牙齿的工作坊设计（[[#def-hard]]、[[geriatrics-palliative/end-of-life-care]]、[[medical-ethics-law/end-of-life-ethics]]）：先声明框架——“谈话是步骤已知、结局可测的临床操作、不是人格天赋；且屋里有被谈话深深伤害过的人、所以契约为：这里没人经历过的东西不做角色扮演。结构——30%输入（预后不确定性语法、区间与我希望重构、知-望-忧-重序列、撤护语言含不予与撤除法律上等值的地基）、50%带训练演员扮演击垮初级医师原型的演练（什么都做的女儿、问我在死吗？的患者、外包谈话的同事）、20%由发表或从业该领域的引导者带的个人病例反思。演练的技能：不残忍地说出概率；给建议并保持沉默；我们可能在以无助你的方式治疗你的重构；系统式道歉；记录顶线使其活过换班。保障：设计中可见的福利支持（房间情绪化因为它真实）、观察而不表演的权利、演员的教具身份被当作安全设备。及文献支持的评估：不是满意度评分而是三月观察行为随访（他们自己开启谈话吗、坐下吗、问希望之问吗）、加给他们谈话所需一小时排班与时间政策改变——没有它工作坊就是勇气剧场、每篇沟通培训审计点名的失败模式。”**

::: example 门口的口译员 {#ex-interpreter}
34岁新发癫痫患者预约时由其丈夫口译；诊所有电话口译线但“她更信任他”；病史采集以丈夫回答每个问题、她沉默等待开始、并提到“但他说家里没人有过这个”。
::: solution
**正确的三人组（[[#def-interview]]、[[nervous-system/epilepsy]]）：布景问题——“家属口译同时是三个妥协（她不能说出她不愿对他说的——会诊本可捕捉的关于侵犯或酒精或避孕的披露）、准确性无法审计（他说的句式应让临床医师骤停：是谁的话？）、及房间的权力几何如今可见（沉默患者对他作答是数据、不是文化、除非另有证明）；礼貌的纠正——热烈谢他、解释诊所为每个人惯例支付专业口译（普遍规则框架移除侮辱与对侮辱的猜疑）、惯例地提供她在会诊中独处的片刻、并只在她听过口译为何存在之后才允许她拒绝专业口译；需要干净三角测量的癫痫特异病史——目击者陈述（丈夫对事件的描述是真实证据——向口译员叙述、向临床医师、按此顺序）、视频请求、不能外包给配偶的驾驶与安全谈话（这是法律对她的要求、这是我担心明天的地方）、及对双方说出的保密句；及为诊所记录的教训——惯例提供不可协商的口译政策配预约时标记与知道电话号码的员工、因为门口口译的会诊是最可能在任何人得到病史前被重约两次的那种。”**

::: example 被演练过的道歉 {#ex-apology}
81岁患者被发现压疮、社区护理笔记显示入院后九天“不可见”；家属愤怒地到达、病房文书不断说“医院的立场是”、最后记录她皮肤的护士躲在药室。
::: solution
**坦承作为技能不是危机（[[#def-hard]]、[[clinical-skills/patient-safety]]、[[geriatrics-palliative/ageing-frailty]]）：房间里的错误——“医院立场腔”（临床走廊里的法律姿态语言把悲恸变成战斗——投诉与诉讼研究直言不讳：招来律师的是拖延而非并发症）；起作用的脚本——资深临床医师、就座、无呼机、按顺序说三句真话：发生了什么（她起了压疮、我们九天没发现）、它将意味着什么（伤口规划、预计住院长度、具名护士）、及家属来的两样东西：道歉（多数司法辖区法律保护其不构成认罪）、及我们会告诉你我们改什么——还有我们会告诉谁；情绪被处理而非被管理——让愤怒把句子说完；回答被问的问题、不是被怕的问题；不在家属前猜测责难——这引出护士：第二受害者路径在药室接住她、配这发生在破碎的系统里、你会被支持、而你要把真相告诉复审那句话、因为缺席的护士意味着糟糕的根本原因分析；及闭环——以家属问题为议程的重大事件分析、带着日期与负责人回来的翻身与风险评估审计、及在道歉当场预约的复谈——研究说它把他们从没打电话从验尸官的短语变成那个家庭里没人需要说出的句子。“**

::: exercise 宣告卒中消息 {level=2}
62岁患者的妻子请你“告诉她真相、但他不能失去希望”；他有大面积恶性MCA梗死、几小时内决定舒适照护。排演谈话。
::: solution
**限时下的SPIKES（[[#def-hard]]、[[nervous-system/stroke]]）：布置——坐下、成年子女在走廊就双方都坐、监护仪可见使没人琢磨数字含义；先知觉核查——到目前为止你理解他发生了什么吗？——因为她那句话会告诉你希望意味着康复还是意味着他听得到你；两个方向都尊重的邀请——有些人要全部细节；要我一步步带过我们所知的吗？；预警弹与分块——恐怕扫描显示很大的卒中……脑水肿严重、在可能好转前会先加重……我们认为无法逆转——然后沉默、六个字六十秒；家属请求真正指向的诚实希望动作——我们可以希望、我们会：为舒适、为无恐惧、为美好的小时希望——而我们会为最坏打算、正是我现在必须谈的；把决定框架为许可不是预后——很多家属会说他此时会希望保持舒适；我无法知道、但我能告诉你有尊严的死是什么样子、选择它不是放弃、是睁着眼睛的爱；及之后——牧师、触觉与听觉事实（“他可能还能听见你——说你该说的话”）、留下的护士、回电话的号码、身后关上的门与写明原因的日记条目。”**

::: exercise 修复交接排班 {level=3}
你医院的审计：去年46%的临床事件涉及转移处的信息丢失；急诊到病房、病房到ICU与院际转运交接最差；员工说结构“花他们没有的时间”。设计转移安全规划。
::: solution
**转移作为系统（[[#def-handover]]、[[clinical-skills/patient-safety]]、[[emergency-critical-care/acute-assessment]]）：诊断——“审计自己的数字就是专科的：转移处信息丢失是患者安全里最安全的发现、因为它总部分为真、总能用结构修复——而员工那句话（没时间）是设计简报不是障碍：规划必须让安全交接比不安全更快；工具——与团队共选的每类转移一个格式（SBAR-SOAP-I-PASS菜单）、接收医师邀请提问规则作为脚本执行、剂量与顶线的指示复述规范、患者能听到自己计划处、及转运单上书面若-则应急（随患者出行的恶化患者护照、ICU升级计划与ICU回病房的今晚盯什么卡）；用时间回应时间论点——排班而非自愿的重叠分钟（麻醉与儿科的编制内资助交接重叠研究）、指定第三人接电话的受保护不受打断窗口、及让系统已知内容自动填入的电子转运摘要使结构花费击键而非分钟；测量——12个月重跑的触发工具伤害审计、交接观察研究（有表无表的实际工作）、按转移类型重编码的事件报告、及接手患者时我获得足够信息员工调查项作为文化指标；及问责——转质量委员会的转移仪表盘、转运接收科室互相审计（院际数据是互助医学、需要带名字的协议）、及使本周哪个交接坏了成为与哪条管路感染了同样例行问题的常设议程项——因为交接糟糕的患者安全半衰期是一个班次。”**
