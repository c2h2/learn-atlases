体格检查检验的是病史提出的假设。它也是一种关怀的仪式：对许多患者来说，被认真地检查是感到自己受到重视的一部分。好的体格检查是系统的，因此不会遗漏；是有重点的，因此时间花在要紧之处；也坦然承认自身的局限，因为每一个体征在疾病存在时都有一定的概率缺如。

本章介绍适用于所有检查的原则、一般检查和生命体征、主要身体系统，以及如何看待体征的准确性。本章以[[anatomy/thorax]]和[[anatomy/abdomen]]的解剖为前提，并承接[[clinical-skills/history-taking]]所述的病史。

## 检查的原则

在接触患者之前，有几个步骤能使检查安全并体现尊重。每一场客观结构化临床考试（OSCE）都考核这些步骤，因为它们在每一次真实的检查中都很重要。

::: definition 检查前的准备 {#def-prepare}
在任何检查之前，临床医生应当：

- **自我介绍**，核实患者身份，并说明检查的内容。
- **取得同意**：检查的同意通常是口头的，对私密部位检查必须明确具体。
- 进行任何私密部位检查（乳房、生殖器、直肠）时**提供陪护人员**，并记录提供的情况、患者的回应和陪护人员的姓名。
- 接触前后**清洁双手**。
- 让患者处于适当的**体位**（如检查胸部时取45度半卧位，检查腹部时平卧），**暴露**所需部位，同时维护尊严，遮盖不需要看的部位。
- **询问疼痛**，疼痛部位最后检查，动作轻柔。
:::

大多数系统的经典检查顺序是**视诊、触诊、叩诊和听诊**。顺序很重要：先看，才知道该在哪里触摸；先触诊再叩诊，才能在用声音界定器官边缘之前先找到它。在腹部，许多临床医生在触诊之前先听诊，因为触诊可能改变肠鸣音，但先看后做的原则始终适用。

检查所见应左右对比，因为患者就是自己的对照：一条腿肿、一条腿正常，比两条腿大小不确定更有信息量。

## 一般检查

一般检查在接触患者之前就开始了。站在床尾观察：

- **一般外观**：病情轻重、是否痛苦、静息时是否舒适、能否说完整的句子。
- **肤色**：苍白、发绀、黄疸、潮红。
- **呼吸**：频率、费力程度、辅助呼吸肌的使用、可闻及的哮鸣音或喘鸣。
- **体型**：消瘦或肥胖、姿势、明显畸形。
- **周围环境**：吸氧、输液、导管、药物、助行器、痰盂、没吃完的饭菜。

然后检查**双手**（温度、颜色、杵状指、震颤、指甲改变、肝掌、关节改变）、**面部和眼睛**（结膜苍白、巩膜黄染、睑黄瘤）、**口腔**（水合状态、中心性发绀、溃疡、牙齿）和**颈部**（淋巴结、甲状腺、颈静脉压）。

::: definition 苍白、发绀与黄疸 {#def-colour}
**苍白**是皮肤和黏膜颜色变淡；在结膜、手掌和甲床最易看出，提示贫血，但对贫血并不敏感。**中心性发绀**是舌和口唇呈青紫色，由动脉血中脱氧血红蛋白浓度升高引起；它表明存在明显的低氧血症，但在贫血时难以看出。**周围性发绀**只累及手指和足趾，可由外周循环不良引起，如寒冷或心输出量低。**黄疸**是胆红素升高引起的黄染；通常先在巩膜出现，然后才在皮肤上可见。
:::

::: warning 深色皮肤上的颜色体征
苍白、发绀、黄疸、皮疹和红斑在深色皮肤上的表现不同，而临床教学历来使用的是白皙皮肤的图片。在深色皮肤上，应在结膜、手掌、足底和甲床寻找苍白；在舌、口唇和结膜寻找发绀；在巩膜和硬腭寻找黄疸。红斑可能表现为紫色、褐色或比周围皮肤更深，而不是红色。脉搏血氧仪在深色皮肤的人身上也往往高估血氧饱和度，因此当临床表现提示低氧血症时，对令人放心的读数应谨慎解读，在关键时刻应做动脉血气分析。
:::

### 生命体征与早期预警评分

生命体征包括呼吸频率、血氧饱和度、血压、脉率、意识水平和体温。它们是医院中最重要的测量，因为病情恶化几乎总是首先在这些指标上表现出来。**呼吸频率**增快是重症患者最早、最敏感的体征之一，也是最常被估计而不是实际计数的生命体征。要完整计数30秒或1分钟。

在英国，生命体征被合并为**英国国家早期预警评分2（NEWS2）**，由英国皇家内科医师学会于2017年发布，在英格兰NHS急症和救护服务中通用。

::: definition NEWS2 {#def-news2}
**NEWS2**对七个参数分别评0到3分并相加。成人的评分如下：

| 参数 | 3 | 2 | 1 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|---|---|---|
| 呼吸频率（次/分） | ≤ 8 | | 9–11 | 12–20 | | 21–24 | ≥ 25 |
| SpO₂ 量表1（%） | ≤ 91 | 92–93 | 94–95 | ≥ 96 | | | |
| 空气或吸氧 | | 吸氧 | | 空气 | | | |
| 收缩压（mmHg） | ≤ 90 | 91–100 | 101–110 | 111–219 | | | ≥ 220 |
| 脉率（次/分） | ≤ 40 | | 41–50 | 51–90 | 91–110 | 111–130 | ≥ 131 |
| 意识 | | | | 清醒 | | | 新发意识混乱、V、P或U |
| 体温（°C） | ≤ 35.0 | | 35.1–36.0 | 36.1–38.0 | 38.1–39.0 | ≥ 39.1 | |

另有**SpO₂量表2**，用于已确诊高碳酸血症性呼吸衰竭、目标饱和度定为88%~92%的患者。**总分**决定临床应对：**5分或以上**是一个关键阈值，需要由具备急症处理能力的临床医生紧急评估；**7分或以上**需要紧急抢救应对，通常包括重症医学评估。**任何单项参数得3分**也应促使病房内紧急评估。具体的应对时限见当地的上报政策。
:::

“V、P或U”指**ACVPU**量表：清醒（Alert）、新发意识混乱（Confusion）、对声音有反应（Voice）、对疼痛有反应（Pain）、无反应（Unresponsive）。任何新发的意识混乱都计3分，因为急性意识混乱往往是脓毒症等严重疾病的首发征象。

::: example 为一位病情恶化的患者评分 {#ex-news}
Lindqvist先生，71岁，肠切除术后第二天。他的生命体征为：呼吸频率24次/分，吸室内空气时SpO₂ 93%，血压98/60 mmHg，脉率112次/分，清醒，体温38.4 °C。计算他的NEWS2并说明应对措施。

::: solution
血氧饱和度采用量表1：

- 呼吸频率24：**2**。
- SpO₂ 93%（量表1）：**2**。
- 室内空气：**0**。
- 收缩压98：**2**。
- 脉率112：**2**。
- 清醒：**0**。
- 体温38.4：**1**。

总分$= 2 + 2 + 0 + 2 + 2 + 0 + 1 = 9$。这高于7分的紧急应对阈值：他需要由上级临床医生立即评估，并有重症医学参与。腹部手术后出现发热、心动过速、呼吸急促和低血压，提示脓毒症，可能来自吻合口瘘，应启动当地脓毒症诊治路径。评分告诉你行动要多紧急；临床评估告诉你该做什么。
:::
:::

**格拉斯哥昏迷评分（GCS）**更详细地描述意识水平。它有三个分别计分的组成部分：**睁眼**（1~4分）、**语言**反应（1~5分）和**运动**反应（1~6分），总分为3~15分。要报告各组成部分，而不只是总分：“GCS 9（E2 V3 M4）”比“GCS 9”包含的信息多得多。运动评分是对预后最有用的组成部分。

## 主要系统的检查

### 心血管系统

一般视诊之后，心血管检查包括：

- **脉搏**：频率、节律（规则、规则的不规则、绝对不规则），以及性状和强弱（在颈动脉处最佳）。绝对不规则的脉搏提示心房颤动；由心电图确认。
- **血压**：使用大小合适的袖带测量；怀疑主动脉夹层或锁骨下动脉病变时比较双臂；怀疑体位性低血压时测量卧位和立位血压。
- **颈静脉压（JVP）**：患者取45度半卧位时，静脉搏动高出胸骨角的垂直高度。高于约3~4 cm提示右心房压升高，如右心衰竭或容量负荷过重。
- **心前区**：视诊有无瘢痕和搏动；触诊**心尖搏动**（正常位于第五肋间锁骨中线处；左心室扩大时向外侧移位）以及抬举性搏动和震颤。
- **听诊**：在四个经典听诊区，用膜型和钟型胸件，并以颈动脉搏动为参照判定时相。听第一和第二心音、附加心音和杂音。
- **外周**：肺底有无湿啰音、骶部和踝部水肿，以及外周动脉搏动。

::: definition 常见杂音 {#def-murmurs}
**杂音**是血流湍流产生的声音。描述杂音要说明时相、最响部位、传导方向、性质、响度以及对动作的反应。四种经典的瓣膜病变：

- **主动脉瓣狭窄**：喷射性收缩期杂音，在胸骨右缘第二肋间最响，向颈动脉传导；重度时脉搏缓慢上升、第二心音减弱。
- **二尖瓣关闭不全**：心尖部全收缩期杂音，向腋下传导。
- **主动脉瓣关闭不全**：胸骨左缘舒张早期杂音，患者坐位前倾、深呼气后屏气时最响；明显时出现水冲脉。
- **二尖瓣狭窄**：心尖部低调的舒张中期隆隆样杂音，患者左侧卧位时用钟型胸件听得最清楚；常伴心房颤动。
:::

杂音的响度并不能可靠地反映病变的严重程度；在重度主动脉瓣狭窄伴心室衰竭时，杂音反而可能变轻。病变由超声心动图明确。心脏生理见[[cardiovascular/cardiac-cycle]]，瓣膜病见[[cardiovascular/valve-congenital-disease]]。

### 呼吸系统

一般视诊（呼吸频率、呼吸费力程度、发绀、杵状指、二氧化碳潴留引起的扑翼样震颤）之后，检查：

- **气管**：在胸骨上窝处的位置。偏移提示纵隔移位。
- **胸廓扩张度**：双手置于下胸部，比较两侧。
- **叩诊**：正常肺为清音；实性组织或液体上为浊音；胸腔积液上为“实音”；气体上为过清音（气胸、肺气肿）。
- **听诊**：呼吸音（正常为肺泡呼吸音；在实变肺上可闻及**支气管呼吸音**，粗糙，吸气与呼气之间有间隙），以及附加音：**哮鸣音**（气道狭窄）、**湿啰音**（肺纤维化和肺水肿时为细湿啰音，有分泌物时为粗湿啰音）和**胸膜摩擦音**。
- **语音共振**：实变时增强，有液体或气体时减弱。

::: theorem 胸部体征的组合模式 {#thm-chest}
主要的局限性肺部异常在患侧产生特征性的体征组合：

| 病变 | 气管 | 扩张度 | 叩诊 | 呼吸音 | 语音共振 |
|---|---|---|---|---|---|
| 实变 | 居中 | 减弱 | 浊音 | 支气管呼吸音，湿啰音 | 增强 |
| 胸腔积液 | 居中，大量时偏向对侧 | 减弱 | 实音 | 减弱或消失 | 减弱 |
| 气胸 | 居中，张力性时偏向对侧 | 减弱 | 过清音 | 减弱或消失 | 减弱 |
| 肺叶不张 | 偏向患侧 | 减弱 | 浊音 | 减弱 | 减弱 |
:::

::: proof 体征为何不同 {#prf-chest}
声音在实性组织中传导良好，而在气体与液体的界面上传导很差。在**实变**时，肺泡被液体和细胞填满，但气道仍然通畅，于是大气道的声音经实变的肺传到胸壁：呼吸音变为支气管呼吸音，语音共振增强，实变的肺叩诊呈浊音。**胸腔积液**在肺与胸壁之间隔了一层液体；液体叩诊为浊音，但会把声音反射回去，因此呼吸音和语音共振减弱。**气胸**在肺与胸壁之间隔了一层气体，叩诊为过清音，同样阻断声音传导。在**肺不张**时，通向该肺叶的气道阻塞，肺叶容积缩小，牵拉纵隔，从而使气管偏向患侧。大量胸腔积液或张力性气胸则把纵隔推向对侧。
:::

::: example 右肺底的体征 {#ex-chest}
Osei女士，66岁，气促。右肺底扩张度减弱，叩诊呈实音，呼吸音和语音共振消失。气管居中。解读这些体征并概述下一步。

::: solution
实音伴呼吸音消失和语音共振消失，提示**右侧胸腔积液**：肺与胸壁之间的液体阻断了声音的传导。实变应表现为浊音伴支气管呼吸音和语音共振增强，肺不张则会把气管拉向右侧。气管居中提示积液量不是巨大。下一步是胸片，通常还需胸部超声，以确认积液、明确其特征并引导抽液，从而分析积液找出病因（[[respiratory/lung-cancer-pleura]]）。
:::
:::

### 腹部

让患者平卧，垫一个枕头，双臂置于身体两侧，暴露从剑突到耻骨联合的区域，同时遮盖外生殖器。视诊有无腹胀、瘢痕、造口、可见的肿块和搏动，以及慢性肝病的体征。依次触诊九个区域，先浅后深，同时观察患者面部有无痛苦表情，并从远离疼痛的部位开始。

- **压痛与肌紧张**：**肌紧张**（腹肌防御）是炎症部位上方腹肌的不自主收缩；全腹**强直**伴剧痛提示弥漫性腹膜炎。**反跳痛**是解除压力时出现的疼痛；轻叩引起的叩击痛能以更温和的方式提供同样的信息。
- **脏器**：让患者吸气，从右下腹开始向上触摸肝缘和脾尖，以免漏掉极度肿大的脏器。用浮球法触诊双肾。叩诊以确认脏器大小。
- **肿块**：描述部位、大小、形状、质地、活动度、压痛，以及能否触到其上缘。
- **腹水**：叩诊**移动性浊音**：侧腹部的浊音在患者转向对侧卧位时变为鼓音。
- **听诊**：肠鸣音（肠麻痹或腹膜炎时消失；梗阻时音调高、呈“叮当”样）和血管杂音。
- **完成检查**：疝口和外生殖器，以及有临床指征时在取得同意并有陪护人员在场的情况下行直肠指检。

::: warning 疝口和直肠是腹部检查的一部分
嵌顿的腹股沟疝和股疝是因为没有检查腹股沟而被漏诊的肠梗阻典型病因，在患股疝的老年女性中尤其如此。同样，如果有直肠指检的临床指征却没有做，便血、前列腺疾病和粪便嵌塞也可能被漏诊。如果有指征的私密部位检查被推迟，要写明它尚待完成以及由谁来做。
:::

::: example 右下腹痛 {#ex-abdomen}
Mensah女士，22岁，腹痛18小时。疼痛始于脐周，后转移到右下腹。体温37.8 °C，脉率104次/分。触诊右下腹有压痛和肌紧张，该处叩诊引起疼痛。肠鸣音存在。解读这些发现，并说明检查和评估还必须包括哪些内容。

::: solution
右下腹局限性压痛伴**肌紧张**和**叩击痛**，提示局部腹膜刺激。结合疼痛由脐周（中肠的内脏痛）转移到右下腹（壁腹膜）、低热和心动过速，这一表现是**急性阑尾炎**的典型表现。腹部并非全腹强直，因此尚无弥漫性腹膜炎的证据。

对育龄女性，如果不考虑妇科病因，评估就不完整：询问她的末次月经、性生活史和阴道分泌物，并做**妊娠试验**，因为异位妊娠可以有同样的表现且危及生命。卵巢扭转、卵巢囊肿破裂和盆腔炎是其他可能。检查疝口，查尿，并请外科团队参与。影像学检查按当地路径进行（[[surgery/acute-abdomen]]）。
:::
:::

### 神经系统

神经系统检查检验的是关于病变**在哪里**的假设。它包括精神状态和言语、脑神经、四肢（视诊、肌张力、肌力、反射、协调和感觉）以及步态。

肌力按**英国医学研究委员会（MRC）分级**从0到5级评定：0级无收缩，1级可见肌肉轻微收缩，2级在消除重力时能活动，3级能对抗重力活动，4级能对抗一定阻力活动，5级肌力正常。

::: definition 上运动神经元与下运动神经元体征 {#def-umn}
**上运动神经元（UMN）病变**累及从运动皮质到脊髓前角细胞的通路（如卒中或脊髓压迫）。它表现为**肌张力增高**（痉挛）、**锥体束分布**的无力（上肢伸肌弱于屈肌；下肢屈肌弱于伸肌）、**腱反射亢进**和**伸性跖反射**，肌萎缩不明显。**下运动神经元（LMN）病变**累及前角细胞、神经根或周围神经。它表现为**肌萎缩**、**肌束颤动**、**肌张力降低**、受累神经根或神经分布区的无力，以及**腱反射减弱或消失**。
:::

::: example 左侧肢体无力 {#ex-neuro}
Chen先生，74岁，醒来时左上肢和左下肢无力。检查：左上肢和左下肢肌张力增高，左肘伸展肌力3级、屈曲4级，左髋屈曲弱于伸展，左侧腱反射亢进，左侧跖反射为伸性。病变在哪里？

::: solution
肌张力增高、锥体束分布的无力、腱反射亢进和伸性跖反射都是**上运动神经元**体征。它们累及左上肢和左下肢。由于运动通路在延髓下部交叉，病变最可能位于右侧大脑半球或脑干；左侧高位颈髓病变是可能性较小的另一种情况。74岁突然起病，最可能的原因是右侧大脑半球卒中。寻找能进一步定位的伴随皮质体征（左侧忽视、视野缺损）。卒中后极早期，在上运动神经元体征出现之前，肌张力可能降低、反射可能消失；检查的时间很重要。卒中见[[nervous-system/stroke]]。
:::
:::

### 肌肉骨骼系统

肌肉骨骼检查遵循**视、触、动**（以及特殊试验）的顺序。视诊有无肿胀、畸形、肌萎缩和皮肤改变；触诊有无发热、压痛和积液；对关节做主动和被动活动，并测量活动范围。**GALS**筛查（步态、上肢、下肢、脊柱）是对任何患者的关节问题进行的快速筛查。单个关节红、肿、热、痛，在被证明为其他疾病之前应按化脓性关节炎处理，通常意味着需要关节穿刺（[[musculoskeletal]]）。

## 体征有多准确？

每一个体征与疾病之间的关系都不完美。有些体征见于疾病，也见于健康人；另一些即使疾病存在也常常缺如。有两个指标描述这一点。

::: definition 体征的灵敏度、特异度和似然比 {#def-accuracy}
体征的**灵敏度**是患病者中出现该体征的比例。其**特异度**是未患病者中该体征缺如的比例。**阳性似然比**$\text{LR}^+ = \dfrac{\text{灵敏度}}{1 - \text{特异度}}$表示该体征在患病者中出现的频率是未患病者的多少倍。**阴性似然比**$\text{LR}^- = \dfrac{1 - \text{灵敏度}}{\text{特异度}}$表示该体征在患病者中缺如的频率是未患病者的多少倍。$\text{LR}^+$远大于1的体征有助于确诊；$\text{LR}^-$远小于1的体征有助于排除。
:::

这有实际的后果。灵敏度低的体征缺如时不能排除疾病：许多肺炎患者没有湿啰音，许多深静脉血栓形成患者没有小腿压痛。特异度低的体征出现时不能确诊疾病。而且不同检查者之间体征的判断也会不同：许多体征（如心尖搏动移位或颈静脉压）的**检查者间一致性**只是中等水平。循证体格诊断教科书汇集的研究报告了各个体征的灵敏度、特异度和似然比，对你最常用的体征值得查一查。

下图显示体征的似然比如何把检查前的概率（验前概率）转换为检查后的概率。只有当起始概率处于中等水平时，一个强阳性体征才能把概率大幅提高；强阴性体征向下的作用也是如此。

::: quiz
某体征对某病的灵敏度为30%，特异度为98%。下列哪种说法正确？
- [ ] 该体征缺如使该病变得非常不可能。
- [x] 该体征出现强烈提示该病，但其缺如几乎不改变什么。
- [ ] 因为灵敏度低，该体征毫无用处。
- [ ] 它的阳性似然比是0.3。
::: solution
$\text{LR}^+ = 0.30/(1 - 0.98) = 15$，因此该体征出现时是支持该病的有力证据。$\text{LR}^- = 0.70/0.98 \approx 0.71$，接近1，因此其缺如几乎不改变什么。高度特异而不灵敏的体征适合用于确诊，而不是排除。
:::
:::

::: history
两项发明把体格检查从观察变成了测量。1761年，维也纳医生**奥恩布鲁格（Leopold Auenbrugger）**出版《新发明》（*Inventum Novum*），描述了胸部叩诊，据说这一技术是他从敲击酒桶中学来的；后来由**科维萨尔（Jean-Nicolas Corvisart）**在法国推广。1816年，**雷奈克（René Laennec）**不愿把耳朵贴在一位年轻女性的胸前，就把纸卷成筒，发现能更清楚地听到心音；他的《间接听诊法》（*De l'auscultation médiate*，1819年）把所听到的声音与死后解剖所见联系起来。随后出现了血压测量：**里瓦-罗奇（Scipione Riva-Rocci）**于1896年描述了充气袖带，**科罗特科夫（Nikolai Korotkov）**于1905年描述了用于听诊法测量的声音。20世纪后期，**David Sackett**和**Steven McGee**等临床医生开始测量体征本身的准确性。
:::

## 后续内容

体格检查与病史一起给出每个诊断的验前概率。[[clinical-skills/clinical-reasoning]]说明如何正式地综合各项发现，[[clinical-skills/laboratory-tests]]和[[clinical-skills/medical-imaging]]说明如何选择随后的检查。急危重症患者的快速ABCDE评估见[[emergency-critical-care/acute-assessment]]。

::: summary
- 做好准备：自我介绍、取得同意、私密部位检查时提供陪护人员、清洁双手、在维护尊严的前提下摆好体位并暴露。
- 视诊、触诊、叩诊和听诊，并左右对比。
- 实际计数呼吸频率；把生命体征合并为NEWS2，总分5分或以上需紧急评估，7分或以上需紧急抢救应对。
- 以各组成部分（E、V、M）报告GCS。
- 识别经典杂音、胸部体征的组合模式、腹膜炎的特征，以及上运动神经元与下运动神经元体征。
- 腹部检查要包括疝口，有指征时包括直肠指检。
- 在深色皮肤上到正确的部位寻找颜色体征，并谨慎解读脉搏血氧饱和度。
- 每个体征都有灵敏度、特异度和似然比；不灵敏的体征不能用于排除，不特异的体征不能用于确诊。
:::

## 习题

::: exercise GCS的组成部分 {level=1 check="11"}
一位患者听到声音时睁眼，说出不恰当的词语，对疼痛刺激能定位。他的GCS总分是多少？
::: hint
睁眼评1~4分，语言评1~5分，运动评1~6分。
:::
::: solution
睁眼：自动睁眼4分，呼唤睁眼3分，疼痛刺激睁眼2分，不睁眼1分，所以为**E3**。语言：定向正确5分，言语混乱4分，用词不当3分，只能发声2分，无语言1分，所以为**V3**。运动：遵嘱动作6分，疼痛定位5分，正常屈曲（回缩）4分，异常屈曲3分，过伸2分，无反应1分，所以为**M5**。总分为$3 + 3 + 5 = 11$，记作“GCS 11（E3 V3 M5）”。
:::
:::

::: exercise 一个NEWS2评分 {level=1 check="5"}
一位45岁女性吸室内空气，呼吸频率22次/分，SpO₂ 95%，血压108/70 mmHg，脉率104次/分，清醒，体温37.9 °C。计算她的NEWS2。
::: solution
呼吸频率22：2分。SpO₂ 95%（量表1）：1分。空气：0分。收缩压108：1分。脉率104：1分。清醒：0分。体温37.9：0分。总分$= 2 + 1 + 0 + 1 + 1 + 0 + 0 = 5$。这达到了需要由具备急症评估能力的临床医生紧急评估的阈值。
:::
:::

::: exercise 说出病变 {level=1}
把下列各组胸部体征与病因配对：(a)左肺底叩诊浊音、支气管呼吸音、语音共振增强；(b)右侧过清音、呼吸音消失，气管偏向左侧，血压低；(c)右上肺区叩诊浊音、呼吸音减弱，气管被拉向右侧。
::: solution
(a)左下叶实变。(b)右侧张力性气胸，这是需要立即减压的急症。(c)右上叶不张，应寻找阻塞性肿瘤等病因。
:::
:::

::: exercise 体征的似然比 {level=2 check="round(0.9/(1-0.6)*100)/100"}
某体征在90%的患病者中出现，在60%的未患病者中缺如。计算其阳性似然比，四舍五入到两位小数。
::: hint
特异度是未患病者中该体征缺如的比例。
:::
::: solution
灵敏度0.90，特异度0.60。$\text{LR}^+ = 0.90/(1 - 0.60) = 0.90/0.40 = 2.25$。其阴性似然比为$0.10/0.60 \approx 0.17$，因此它的缺如（用于排除）比它的出现（用于确诊）更有用。
:::
:::

::: exercise 上运动神经元还是下运动神经元 {level=2}
一位50岁男性右手小肌肉萎缩，右上肢肌束颤动，双侧膝反射亢进，双侧跖反射为伸性。这是什么模式？必须考虑什么诊断？
::: solution
他**同时**有下运动神经元体征（上肢肌萎缩和肌束颤动）和上运动神经元体征（下肢腱反射亢进、伸性跖反射）。上、下运动神经元体征混合而无感觉缺失，提示**运动神经元病**的可能。颈髓病变（如伴神经根压迫的脊髓型颈椎病）也可以在病变节段出现下运动神经元体征、在其以下出现上运动神经元体征，必须通过影像学检查排除。需要转诊神经科。
:::
:::

::: exercise 一位老年男性的杂音 {level=2}
一位82岁男性有劳力性胸痛，近期晕厥一次。他有一个在胸骨右缘第二肋间最响、向双侧颈动脉传导的喷射性收缩期杂音，脉搏缓慢上升，第二心音减弱。可能的诊断是什么？这些症状为何重要？
::: solution
这些发现提示**重度主动脉瓣狭窄**。向颈动脉传导的喷射性收缩期杂音是典型表现；脉搏缓慢上升和第二心音减弱提示病变严重。心绞痛、晕厥和气促是重度主动脉瓣狭窄的经典症状，不进行瓣膜干预则预后不良。他需要紧急超声心动图检查和心内科评估。注意，仅凭杂音的响度无法判断严重程度。
:::
:::

::: exercise 一次漏诊 {level=3}
一位80岁女性因呕吐和腹胀入院。入院医生记录：“腹软，膨隆，无压痛，肠鸣音呈叮当音。”次日CT显示右侧绞窄性股疝导致的小肠梗阻。分析检查中出了什么问题，并提出一种能降低此类情况发生可能的系统措施。
::: solution
检查不完整：没有检查疝口。叮当样肠鸣音和腹胀本应促使寻找梗阻的原因，而股疝是老年女性梗阻的典型病因；股疝常常很小，在衣服或病号服下容易被漏掉。促成因素可能包括时间压力、不愿检查腹股沟，以及锚定于“内科”原因的呕吐。系统措施：入院记录模板中包含“已检查疝口：是/否”；教学中强调不检查腹股沟的腹部检查是不完整的；对新入院的梗阻患者进行上级复核；营造一种把不完整的检查记录为“待完成”而不是直接省略的文化。
:::
:::

::: exercise 体征的价值取决于起点 {level=3 check="round(0.1*10/(0.1*10+0.9)*1000)/1000"}
某体征对某病的阳性似然比为10。对于验前概率为10%的患者，该体征出现时验后概率是多少？以比例表示，四舍五入到三位小数。
::: hint
把概率换算成比值，乘以似然比，再换算回来。
:::
::: solution
验前比值$= 0.1/0.9 = 0.111$。验后比值$= 10 \times 0.111 = 1.111$。验后概率$= 1.111/(1 + 1.111) = 10/19 \approx 0.526$。一个强有力的体征把概率从10%提高到约53%：意义重大，但并非确定无疑。如果起点是1%，同一体征只能使概率达到约9%。
:::
:::
