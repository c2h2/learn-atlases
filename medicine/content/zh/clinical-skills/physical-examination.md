体格检查是医学的具身推理：一项有可测量准确度的技术（合理临床检查文献的似然比）、一个伦理器物（需同意、陪诊与比例性的授权接触）、及一项正在消失的技能、其消失已被多个专科复审正式记录。**本章讲述一般检查（从门口开始的一般视诊、带预后力与测量误差的生命体征）、带值得知道的判别体征及其数字的按系统检查（颈静脉压与心尖与杂音、叩诊遗老对抗其听诊与超声继承者的胸部、腹部与疝与手术瘢痕、作为仍用手定位的神经系统、及其特殊试验多为筛查非判决的关节）、证据基础及其诚实极限（哪些体征已死、哪些从未活过、哪些胜过其取代的血检）、及检查的现代政治（床旁超声问题、课时减少文献、及仍在塑造双手的模拟与反馈方法）。**

## 一般检查

::: definition 一般视诊、生命体征与接触的伦理 {#def-general}
**一般视诊在接触患者之前开始、每秒携带比任何下游更多的诊断信息：门口到床旁评估（恶病质或水肿、步态与弯腰与用手撑起身、言语与注意力与气味——尿毒症与酮症酸中毒与肝臭、及老年科医师读作社会体征的临床忽视）、床头复查（被当作开放药物史数出来的吸入剂与利尿剂与激素与鱼油瓶）、及作为病历的身体（瘢痕与造口与引流口与注射脂肪萎缩、带着背景读的纹身与自伤疤、既是护理诊断又是治理文件一体的受压区）。生命体征同时是急性医学中最有预后力的测量（预警评分文献：呼吸频率是最早与被最忽视的标志、预测骤停与入院的各评分离群值）又是最不可靠的记录之一（观察表安慰剂效应——为表而非为患者测的生命体征、错过两次查房间恶化的四小时仪式、及测量误差课程：袖带大小效应、口 vs 鼓膜 vs 核心温度差、及脉搏血氧的灌注与色素限制现正被正式研究、因为脉搏血氧准确度随肤色变化、而那变化是患者安全发现不是脚注）。双手值得超越经典的研究（白甲与Mueckle线与杵状的真正流行率及其医源与心脏原因、掌红斑的差特异度、在床旁诊断硬皮病谱的甲褶毛细血管、作为诚实询问的肝与糖尿病与遗传标志的Dupuytren挛缩）：手臂持有对夹层与锁骨下病要紧的血压差、及肾病患者在一切之前必须检查的动静脉瘘。手与口与眼是一般内科医师的分诊层（中心性发绀与苍白与黄疸先巩膜后脸的顺序、从Behçet与IBD溃疡到作为心血管风险标志牙病的口腔体征、角膜老年环与睑黄瘤及仍送初级医师查铜的Kays­er-Fleischer环）；淋巴结检查作为最常被放弃而在患者带人人害怕之物就诊时最常有诊断价值的检查存活；及风湿与运动门诊重新量化的脊柱-姿势-步态筛查。伦理不是附录：每次接触被同意同意章详述的白话解释模型、作为职业律法而非礼貌为私密检查提供并记录陪诊、拒绝部分检查的权利与拒绝治疗一样真实、检查匹配问题的比例律（无反射的直肠指检、无仪式化宽衣）、创伤知情适配（预告每次接触、提供停止、六分钟时绝不说“这只需一会儿”、及使常规敏感成为临床工具要求而非床旁礼貌的侵犯幸存者流行率）、及卫生层（诺如与艰难梭菌与新冠时代不容争论地强化的WHO五时刻、及从脱衣与脱离监测患者开始的检查——占病房医学一半的监护线与导管与敷料巡视）。**
:::

## 系统

::: definition 各系统的判别体征 {#def-systems}
**心血管检查仍回答超声有时延迟的问题：作为压力波形的颈静脉（胸骨角法的不高可靠度但其独有信息——血压给不了右房压与V波及大炮波）、心尖的性质与位置（量化超声言语的抬举与移位）、脉搏的轮廓与时机（无线电-股延迟的老缩窄筛查及用袖带给填塞与哮喘分级的奇脉）、杂音的地理（主动脉瓣狭窄-喷射-合成时代的诚实发现：经典三联在老年与低流量不敏感、颈动脉放射的尚可特异度、及把HCM与其物分开的动态动作规则）；呼吸检查的大活辩论是其自身过时对抗其幸存者（胸腔积液的叩诊-触觉语颤对击败两者的超声、Velcro爆裂音对石棉与纤维化特异度的哮鸣-爆裂音鉴别、定位的断奏与单相变异、及属物理诊断急症的气管偏移与皮下气肿征）；腹部检查是轻柔的等级视诊-腹胀-瘢痕-脾大可见序列、肝缘及肝叩诊技术及其超声取代、腹水的移动性浊音对液波震颤敏感度差、肾区压痛与用双手不用体温计测的主动脉宽度、站立用力做的疝检查因为坐着什么都找不到、及急腹症的诚实证据（防御-反跳-强直的差判别对 活动与咳嗽疼痛发现及带记录时间的系列腹部检查的价值）；神经检查仍是无需技术就定位、必须按综合征要求的顺序做的（肌张力-反射-踝阵挛与Babinski即伸性跖反射在昏睡对清醒的真实含义、皮质感觉与否定征、小脑共济失调三联先眼征、髓病的感觉平面与马尾的会阴-张力-踝反射即由手定义的急症、周围神经病的袜套样及带诚实平平似然比激发试验的命名隧道单神经病、及在MRI预约前诊断颅底与脑干病变的脑神经）；肌骨检查是特殊试验文献最密的森林（肩部撞击试验的重叠弱项与肩袖撕裂的特异组合、膝的积液-关节线-半月板试验及其对MRI比较的幻灭及韧带松弛分级、髋的撞击及脊柱的直腿抬高-俯卧屈颈-股神经牵拉及其神经根病似然比、手的Phalen与Tinel及腕掌磨挫、及风湿科医师对抗每张“只查血”转诊的真正功力：小关节普查与掌指关节挤压试验）；及在证据与陪诊现实下萎缩的泌尿生殖与前列腺与盆腔检查（直肠指检永不单独筛查的教义及按指征的双合与窥器时代）、及儿科检查自身语法（父母怀里观察序列、生长标绘-畸形扫描及“最后检查痛处”规则、及徒手交付的癌症预防睾丸自查教学）。**
:::

## 证据与时代

::: definition 准确度、衰退与现代检查 {#def-evidence}
**证据基础有一根金线与一道长影：JAMA合理临床检查系列（1993起）及McGee与Finkel及悉尼与马斯特里赫特学派把似然比分配给床旁并发现真相参差——有些体征优秀（独立于超声医师检查时Murphy征阳性对急性胆囊炎的LR+、儿童早期阑尾炎皮肤过敏钝痛的尚可表现、瘦人触诊腹主动脉宽度在肥胖算术下失败、心衰颈静脉压的特异度伴其差敏感度）、许多平庸而一直被当作决定性教学（肝颈回流、除正确流行率外多数脑膜刺激征、Hoffman征在人群研究中被泄气对抗其反射序列的显赫、及被超声变为可选的“诊断性”叩诊征），而复合综合征最好（多发现串联逻辑——Wells与Centor与Ottawa及决策规则是穿流行病学外衣的体格检查）。衰退文献真实而被测量：1990-2010年代床旁时间的观察研究、被删除又恢复的物理诊断轮转、尸检之死移除了检查的答案册、及记录影像成为反射时发生了什么（“踝肿拍X线”医学与正常CT当安慰文化）的专科复审——反对它反证不断积累：检查的速度与成本（改变管理先于化验回报的呼吸困难鉴别床旁超声研究、D-二聚体获取慢处仍分诊的DVT小腿征、及远程皮肤病学邻近的手工）、检查开出更好检查的发现（使D-二聚体可解读的验前概率是检查判断）、及患者不信从未碰过他们医师的法务与信任现实。床旁超声问题正被判定为增强非替代（急诊与重症与风湿与麻醉课程的口袋超声证据——FAST与肺滑动与彗星及IVC与膀胱与DVT两点扫描带其认证与监督课时框架、及治理文献对超出能力过度扫描的警告与“超声即听诊器”辩论未决的资质）；模拟与反馈方法革命在床旁暴露萎缩时救了教学（人体模型与标准化患者与同伴教学、“看一个做一个教一个”被带登记监督重复的可托付专业活动及反馈间隔研究取代、因为检查技能无量则衰）；及留下的诚实课程立场：检查是体征加其间推理（哪个体征为哪个假说、哪个假说为哪个红旗）、其发现连同阴性被记录（“腹软、无防御——外科夜班要的是缺席不是形容词”）、其局限在有处被声明（“外周衰竭、脉搏触不到——记录为未评估、保护下一位医师的解读）、及其两个不时兴美德被捍卫：比例性（问题不需要就不查）与临在（找到扫描漏掉乳腺包块的手、只在患者忘记隐藏时出现的震颤、及Balint传统命名的治疗动作——被专注的人检查是患者就诊理由的一部分）。**
:::

::: example 被检查与未被检查的腿 {#ex-dvt}
长途飞行后44岁久坐患者：急诊医师“查一下DVT”、视诊双腿、记录“无小腿压痛、无肿”、并出院；年资护士提到她脱下的睡眠袜上不对称的小腿紧；03:00终于抽了D-二聚体；阳性。
::: solution
**验前概率是检查判断（[[#def-evidence]]、[[#def-systems]]、[[cardiovascular/vascular-disease]]）：技术错误——Wells评分要素是检查加病史合一（活跃肿瘤与制动与单侧肿与小腿差3 cm及侧支静脉及“替代诊断至少同样可能”枢轴）、而“无小腿压痛”是单个差敏感度体征在干整个评分的活；决策规则课——D-二聚体只对验前概率可解读（低或中Wells配高敏D-二聚体阴性排除；高Wells无论D-二聚体说什么都去超声）、而出院记录记录了一场不是评分的检查；重做——带测量的完整Wells与由评分不由情绪决定的超声预约路径、补全飞行-肿胀-避孕药-雌激素-心血管风险史、及带时间的安全网（“肿增加就回来；这是明天的扫描位”）；及SEA应提取的教学——“检查作为形容词收集”问题（读起来像检查实为仪式的三件套）对抗记录评分带组件文化、及诚实：这场面凌晨4点的版本需要在使用的地方印着规则、这就是决策规则如今住在电子处方订单集里也应住在纸卡上的原因。**
:::
:::

::: example 定位成功的背 {#ex-cauda}
跌倒后“只是背痛”的36岁患者：护士笔记记录肌力正常；查房时会诊医师让患者把臀部抬离床面、发现臀肌迟滞、检查鞍区（对擦拭有感觉、对针觉减退）、并膀胱扫描发现600 mL。
::: solution
**清单漏掉的检查（[[#def-systems]]、[[musculoskeletal/back-pain]]、[[emergency-critical-care/acute-assessment]]）：漏诊的解剖——大体动作肌力筛查放马尾一马、正如三件套DVT检查放小腿一马：马尾征活在不起眼的具体试验里（髋外展与拇长伸肌肌节、病史说有鞍区麻木或尿路症状时必须做的肛门张力与感觉、“患者排尿前扫膀胱”教义、及尿潴留先于无力的球部起病模式）；组装的综合征——鞍区感觉改变加膀胱（溢出与600 mL无尿意）加不对称臀迟滞就是马尾直到MRI证明不是、及关键时间窗（“48小时内减压”紧急协议的泌尿与脊柱外科路径配“导尿并记录残余尿”桥）是检查启动的时钟；记录文化——会阴感觉记录为已测正常并注明模态（“轻触”对“针”对“擦拭”——患者分得出、笔记也该分得出）、可趋势化的观察表里的残余尿、及按命名肌群MRC分级而非“肌力减退”的运动检查；及系统课——上次入院给这位患者的“红旗传单”没有会读它的检查者就没用：科室的下背痛路径需要“若有任何鞍区麻木、尿路症状、双侧坐骨神经痛、进展性缺失——检查会阴与膀胱、今天扫描”硬停、把患者的报告变成外科医师的电话、这就是患者安全章确切意义上作为安全屏障的检查。**

## 通向何处

为检查设问的病史在[[clinical-skills/history-taking]]、检查判读与验前概率在[[clinical-skills/laboratory-tests]]与[[epidemiology-ebm/diagnostic-tests]]、神经细节在[[nervous-system/motor-systems]]、体征背后的心脏力学在[[cardiovascular/cardiac-cycle]]与[[cardiovascular/valve-congenital-disease]]、床旁-升级链接在[[emergency-critical-care/acute-assessment]]。

::: history
**体格检查的历史是临床医学认识论的历史。床旁教学传统源自巴黎诊所——Auenbrugger的叩诊来自其酒馆老板父亲的敲击（1761年出版、两代后由其学生及Corvisart——拿破仑医师——的同僚平反）、Laennec1816年因对年轻女子直接听诊的羞怯与洁净反对而发明听诊器、19世纪伟大的症状分类学（维也纳与爱丁堡学派、及爱丁堡与格拉斯哥学派的检查正典）。牛津与John Radcliffe与麻省总院的病例传统把“完整检查”变成带自身礼仪的仪式（“从脚到顶”格式）、而同世纪的医师已在为比例性辩护：“不需要的绝不查”建议在每个时代的床旁手册反复出现。仪器互相增殖并互相废黜：检眼镜（Helmholtz 1851）、喉镜、Riva-Rocci袖带及其水银时代的血压计、Einthoven弦线电流计的心电图、每台新机器（往往）宣告手的过时；尸检统计的顶峰（19世纪中叶医院的临床病理讨论会、Osler的博物馆）使体征可证伪——“经典体征”是被反复确认的生前-死后关联的黄金时代、也是众多体征带着数尸者人名的原因。衰退叙事开始很早（1970-80年代“检查的艺术”被美国 医保时代与NHS自身化验驱动医学的“18项开单模式”取代的随笔）并变得可测：1990年代研究（对1965诊断产出基线的重测与1990-2000年代住院医师床旁时间研究）、尸检崩塌移除证伪、及哈佛物理诊断课1970年代被删除、十年后在学生压力下恢复。证据复兴来自三个方向：诊断试验准确度的流行病学（Sackett与Fletcher邻近的敏感度-特异度-似然比语法及1993起终于给正典评分的JAMA RCE系列）、决策规则运动（Wells与Centor与Ottawa规则——重构为加权体征的检查）、及影像经超声重回床旁（2000-2010年代的FAST与肺超声与聚焦心脏研究给了听诊与触诊一块可自查的屏幕、伴随口袋装置是拯救还是终结检查的资质辩论）。肤色-脉搏血氧发现（2018-2024年隐匿性低氧误分类随肤色变化的研究）是最新也最令人不安的一章、而矫正工作——新传感器与新算法与包容性设备研究议程——是关于测量偏倚如何在“客观”体征里藏数十年的案例。教学法史闭环：从1969年Barrows的神经病学患者经OSCE（Harden 1975）到今日间隔重复与可托付框架的标准化患者与模拟运动、及不断证明维多利亚医师早已知晓之事的刻意练习研究——手是被校准的、不是遗传的、而校准会在抽屉里悄悄漂移。** - [[clinical-skills/history-taking]]、[[epidemiology-ebm/diagnostic-tests]]、[[clinical-skills/patient-safety]]。**
:::

::: summary
- 检查先于接触开始（视诊、步态、气味、床旁器物）而其伦理是程序性的：同意、私密检查的陪诊、与问题的比例性、及创伤知情技术。
- 生命体征预后力强而常不可靠：呼吸频率预测、袖带大小与灌注与肤色失真、而为表格做的测量什么也不改变。
- 判别体征可知且被量化（颈静脉、杂音地理、积液与纤维化发现、马尾与会阴检查、命名的特殊试验）——而许多教科书经典弱于其教学、这是似然比文献已定案的事实。
- 检查的现代角色是开单判断：它供给验前概率、分诊谁需要哪个检查、并仍找到影像只能确认的急症（骨筋膜室、马尾、填塞、异位）。
- 无量、反馈与刻意练习则技能衰减；模拟、标准化患者与可托付里程碑是救援、而床旁超声在有到能力的资质时增强（非替代）。
- 记录你做了什么、没发现什么、及无法评估什么；“外周衰竭、脉搏触不到”保护下一位医师、而诚实的阴性就是发现。
:::

## 练习

::: exercise 给体征分级 {level=1}
给你本周用到的三个体征（真实或想象）的似然比逻辑：一个阳性时纳入、一个阴性时排除、一个是装饰。
::: solution
**SnNout与SpPin（[[#def-evidence]]、[[epidemiology-ebm/diagnostic-tests]]）：工作——高LR+体征纳入（SpPin逻辑：晚期达峰粗糙主动脉喷射杂音对显著狭窄的高LR+、或甲褶毛细血管脱失对硬皮病谱的LR+）；高敏感度体征的缺席排除（SnNout：低Wells下任何腿肿或压痛不对称的缺席把验后概率降得足以回答D-二聚体之问）；装饰（测试者间一致度差的肝颈回流、及因焦虑健康人假阳性率而被人群研究泄气的Hoffman征）；使其临床化的算术——把LR应用于验前比、同一体征在咯血60岁吸烟者是判决、在胸壁痛20岁是舍入误差——流行率不是噪音、它是医学的分母；及记录习惯——记录体征质量与对比（同标志点左小腿粗3.5 cm）、因为LR适用于测量、不适用于情绪。**
:::

::: exercise 设计查房的每日检查 {level=2}
你的内科团队把“检查”作为仪式执行。围绕比例性、绝不能跳过的筛查系统、及记录的阴性重写查房检查标准。
::: solution
**比例而不可漏（[[#def-general]]、[[clinical-skills/patient-safety]]）：原则——检查回答今天的问题加监测清单、不是教科书的目录；患者躺在床里并非每天宽衣的理由、是带听诊器的剧场；绝不跳过的监测层（每个住院患者每天的管路-引流-导管-敷料-受压区巡视——作为安全设备的装置日与皮肤完整性检查、团队忘了看的小腿与腋窝与口腔、及有指征的神经观察表）、问题驱动的核心（更气促的胸带超声邻近逻辑检查、疼痛的腹带系列记录与时间检查）、及改变出院不改变观察表的功能巡（坐立测试与握力及“讲讲你家楼梯”——老年科医师由此建起整套评估）；记录阴性标准——“无小腿肿、无压痛、无条索”与“脑神经完好、无下垂、四肢肌力5/4”作为模板训练、“无法评估-患者睡眠-已复查于”作为合格条目、及“未查”触发理由；及使其成真的审计——病历复查的“压疮发生率与装置日与导管评分带记录阴性率”、晨会的“你没看什么”之问、因为查了而漏的病例比没查而漏的罕见、而标准存在是为关闭那个差距。**
:::

::: exercise 教颈静脉压 {level=2}
住院医说“我不会看颈静脉、反正超声测压力”。十分钟内教这个体征：它给什么、如何找、噪声怎么办、何时信。
::: solution
**颈静脉十分钟（[[#def-systems]]、[[cardiovascular/heart-failure]]、[[cardiovascular/circulation-blood-pressure]]）：独有给什么——右房压及其波形是病房超声常规比不上的活测量（颈静脉升高在心衰中特异而不敏感的角色（基层呼吸困难研究的LR+）、急性二尖瓣反流的巨大V波、完全阻滞与室速伴房室分离的大炮波、低血容量出血的颈静脉不显、缩窄与右室梗死及近填塞生理的Kussmaul吸气升高）；如今教的技术——45度半卧（调角度、不是神话）、切线光与肝颈回流10秒及计时规则、“胸骨角上垂直高度加5”至少统一争论的惯例、及在彼此脖子上演练的“以搏动性与不塌陷性与不被遮蔽性区别颈动脉”三联；噪声——肥胖与不存在的脖子的现实（锁骨下与外颈静脉模仿者——阻断柱的外颈静脉瓣、及颈静脉干脆不可见时：记录“未经颈静脉评估、考虑下腔静脉与超声”、又是诚实阴性规则）、及“肥胖与COPD过度充气及坐在颈高处的三尖瓣反流巨波”警诫使下一位医师的谨慎成为你笔记的一部分；及何时信——作为趋势与综合征拼图、不是数字：颈静脉8 cm随利尿下降是护士量腿围比不了的治疗应答观察、而“颈静脉加S3加端坐呼吸”复合是旧医师与现代试验都先于BNP到达“心衰”的方式——作为带波形验前概率的检查。**
:::

::: exercise 处理被拒绝的检查 {level=2}
戴希贾布的穆斯林女性拒绝了其伴侣报告可触及包块后提供的乳腺检查、伴侣留在屋里；她会说一些英语。协商检查与会面安全。
::: solution
**适配不是例外（[[#def-general]]、[[medical-ethics-law/consent-capacity]]、[[surgery/breast-endocrine-surgery]]）：第一个纠正是结构不是文化——伴侣绝不能做口译、且讨论时绝不能在屋里（现在就叫口译线；乳腺检查常规提供女性医师与陪诊、这是尊严框架如今写下的服务设计职责、不是她恳求的人情）；临床事实不等人：可触及持续包块需要三重评估（检查-影像-取样路径）、所以协商是关于如何不是是否、及“我理解；我们可以安排女医师、从您舒服的地方开始”这句话配她离开前约好的号；需要隐私的安全筛查——疼痛模式与胁迫与谁发现包块的问题（乳腺门诊文献的家暴筛查邻近发现）、伴侣翻译或旁听时无法问；及退路伦理——若她今天仍拒绝、记录提供过什么、用过的口译、采取的具体替代（自查影像？朋友陪来？已约女医师）、用她复述的话给安全网、且不让拒绝变成出院——因为检查由她主导、而路径由你保持敞开。**

::: exercise 为检查辩护 {level=3}
业务院长提议削减一半物理诊断教学换“超声与模拟时间”、并让影像科室接住初级医师的“不确定”检查。写回复：支持的证据、反对的证据、及你会签的折中。
::: solution
**诚实打完的检查之争（[[#def-evidence]]、[[clinical-skills/patient-safety]]、[[epidemiology-ebm/diagnostic-tests]]）：替提案立最强论证——超声确实胜过若干命名体征（呼吸困难鉴别试验的胸腔积液、DVT、心衰B线）、模拟对技术习得确实胜过“看一个做一个”；初级“不确定检查”转放射是诚实升级；反证——检查的角色不是按影像的规则与影像竞争：它设定验前概率（D-二聚体与“意外瘤”伤害是检查判断）、它是凌晨4点与社区及资源环境里唯一可用的检查（骨筋膜室与马尾与异位与填塞综合征是临床诊断、影像确认）、它仍找到无人查体时扫描漏掉的东西（藏起的震颤、成像野下的乳腺包块、心内膜炎的甲褶、及扫描“正常”而检查说不是的患者——各是有记录的失败模式）、及患者信任与法务层是真实的（“他从没查过我”投诉与“有记录检查”辩护都在院长自己的数据里）；会签的折中——a) 保留物理诊断教学但重新加权到验证过的判别体征（扔掉叩诊礼仪、教似然比）、b) 把超声作为带能力登记适应证的检查整合物来教、不是单独的机器（口袋超声邻近资质框架）、c) “不确定检查转诊”保留但重定义：初级查体、记录、然后与上级共同扫查再影像、手留在患者身上、学习环闭合、及双方12个月约定的结局指标：升级病例的“影像前诊断”命中率、病历审计的检查记录质量、及“患者感觉被查了”项、没有院长会争因为它预测投诉、信任与下一位医师的准确度。**

::: example 是喉鸣的“哮喘” {#ex-stridor}
26岁今年第三次被当“重度哮喘急性发作”治疗；今晚复盘初级注意到声音是吸气相、颈部最响、雾化无改变；空气下血氧99%、峰流速“比上次好但仍低”。
::: solution
**重新分类的检查（[[#def-systems]]、[[respiratory/asthma-copd]]、[[nervous-system/sensory-systems]]）：判别发现——吸气相、体位依赖、雾化无反应的声音是上气道（胸外可变梗阻模式——流量环的吸气平坦）及它打开的鉴别（哮喘模仿登记的可诱导喉梗阻/声带功能障碍、插管后声门下狭窄、及平片漏掉的甲状腺肿与淋巴结肿块与气管肿瘤）；现在的检查——触诊颈部与气管居中与否及耸肩咳嗽动作及邻近纤维喉镜的耳鼻喉决定、及作为检查刚开出检查的流量环肺功能；标签的医学——三次住院加全身激素加吸入阶梯是带息的医源、而被当哮喘治的可诱导喉梗阻会更糟（恐慌环与下次发作被当“持续状态”镇静的插管风险）；及教的习惯——“胸听时看时钟”规则（吸气对呼气是每个噪音患者的第一岔路）、“与呼吸功不匹配的血氧是检查提示”（血氧正常的PE与血氧异常的焦虑都是）、及每个急性呼吸困难入院记录“喉鸣已评估：有/无”的病历、因为分诊笔记里的“哮鸣”在不止一份气道尸检系列里是棺材钉。**

::: example 做出诊断的手 {#ex-hands}
58岁“焦虑”转诊、“手麻乏力”：查体医师发现指关节皮肤增厚、紧绷蜡样捏不起的手指、及甲褶毛细血管脱失；ESR 4、反射正常。
::: solution
**手部的硬皮病谱系（[[#def-general]]、[[#def-systems]]、[[musculoskeletal/connective-tissue-vasculitis]]）：体征与其权重——不累及指间关节而掌骨紧绷的皮肤增厚模式、伴必然存在而从未被问的Raynaud史（“您的手指在冷水里发白发痛吗？”）、对硬皮病谱高LR+并预测小血管病的甲褶毛细血管脱失与灌木样袢征、及教科书列出而手真正找到的钙质沉着与毛细血管扩张及肌腱摩擦音；“焦虑”的尸检——被错名的手水肿相、没被注意并决定此病预后的呼吸困难即间质肺与肺动脉高压、将被贴上肠易激的反流与腹胀小肠、及必须在激素陷阱前给出的肾危象血压宣教；检查开出的检查——Scl-70与着丝点及RNA聚合酶抗体配甲褶毛细血管镜、HRCT与肺功能与超声筛查及年度肺高压与肾监护架构、及手治疗与钙通道阻滞剂转诊；及给诊所的元要点——“正常ESR不排除、正常反射从不排除：是带着问题被检查的手做到了四封转诊信没做到的、本例进入诊所”今天我们没碰什么“教学清单。”**

::: exercise 构建快速床旁超声课程 {level=2}
为你的内科团队设计口袋超声培训：适应证、能力、治理、及你在预防的两个失效模式。
::: solution
**带边界的超声（[[#def-evidence]]、[[emergency-critical-care/critical-care]]）：保持短而诚实的适应证清单——呼吸困难鉴别（B线与肺滑动与积液及正确背景的IVC）、骤停与休克的心活动与腔室估计之问、腹痛邻近场景的DVT两点与膀胱与主动脉筛查、及麻醉与肾与血管框架已有的操作引导；能力设计——学会发布的监督采集小时带登记与评估者标准（“是资质不是徽章”）、图像质量与鉴别包含你看不见什么的训练（“正常超声不排除PE或舒张衰竭或小积液填塞”警诫与胜利并列演练）、及退出规则：扫描从不取代检查、只重排其假说；治理——报告入病历纪律（法务复审要求的“由具名者采集-存储-解读”政策）、“超出你资质图像的绝不做治疗决定”规则、阳性与漏诊的质量保证复审、及对必然之问的清晰回答——超声医师转诊路径是否以你们自己数据的时间-到-诊断收回成本；及预防的两个失效模式——过度扫描级联（验前概率从不需要看的患者的附带发现、患者安全章列表的伤害）与萎缩的手（先摸探头后听诊器、因机器总是先答而从未学会颈静脉的初级）——这就是课程首项评估是“扫描前陈述你的验前概率与体格发现”的原因。**

::: exercise 记录阴性 {level=1}
重写三份病历：(a)“腹软”；(b)“神经系统未见正常”；(c)“不能耐受检查”。各自变成可辩护、有用的条目。
::: solution
**保护的阴性（[[#def-general]]、[[clinical-skills/patient-safety]]）：(a)”腹软、无胀、无防御无反跳、四象限与上腹无压痛、肠鸣音存在、未触及包块或脏器大；吸气右上腹无压痛——Murphy阴性；因使用阿片14:00复查、无变化“——记录外科的缺席因为下一位医师继承趋势不是形容词；(b)”脑神经II-XII完好含视野与眼底；四肢肌力5/5无下垂；共济与步态正常；四肢轻触觉完好；反射2+对称、跖屈；查脑神经因为头痛病史所问“——”未见正常“藏起了马尾与颅压与颞动脉之问里哪个真被回答；(c)”检查受限：剧痛与寒战使腹部评估止于轻触（防御存在、反跳无法评估）；麻醉科在场下镇静行CT；09:30重新尝试并完成全检——所见如上“——带计划与时间的诚实”不能“、是既辩护临床医师又拯救患者的条目、而沉默两者都不能。**

::: exercise 检查焦虑的患者 {level=2}
22岁因“心悸与麻刺”两次急诊正常、确信有器质之物被漏；你的检查发现窦律110、震颤、及她从未被告知的眼睑迟落。处理检查、重构与计划。
::: solution
**体征作为治疗（[[#def-general]]、[[#def-evidence]]、[[endocrine/thyroid]]、[[psychiatry/anxiety-disorders]]）：做对的检查就是干预——放缓安静的重查（脉搏与眼与手、下视追踪演示的睑迟落与拍下的震颤、反射及其他甲状腺毒症肌病的小腿检查）、然后口述（“您的心律正常而快、正是甲状腺素过多所做；您的手有一个我要您对着镜子看的震颤；您的眼在示迟落”）——体格发现把“他们以为是焦虑”变成“他们找到了什么”、是两次正常就诊给不出的治疗时刻；医学——甲功与抗体及摄取或扫描、甲状腺眼与房颤风险计划、及让她感到改善从而相信你其余一切的β阻滞剂；焦虑留在清单上——甲状腺毒症与惊恐共存、睑迟落不排除使其持续的恐惧成分（T4正常后仍存的过度通气叠加呼吸困难的获得自己的CBT转诊、不是耸肩）；及记录与修复——用患者自己的话写出示与解释的检查发现（“她认出震颤与睑迟落”）、为被漏的关注而非为急诊拥挤现实道歉（两次没人花十分钟的就诊）、及带日期具名的随访、因为这份病历不打破模式、这位患者的下次危机就是“又一个不查我的医师”。**
