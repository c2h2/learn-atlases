实验室医学是有信息量的数字及其三个敌人——生物变异、分析误差与临床误读——的学科。**本章讲述参考区间及其统计学诞生（95%谬误、年龄与性别与妊娠分层、及胜过差值核查的有生物学意义变化指数）、分析前与分析链（制造多数“异常结果”的止血带与溶血与采血管顺序事实、质控与总误差理念）、解释核心（应用于真实筛查的敏感度、特异度与预测值、反射检测与确证逻辑、危急值文化）、按临床问题的组套（作为模式语言的肝功能、甲状腺与炎症及肾与心脏标志物、肿瘤标志物的正当与不正当用途）、及进入临床的人群级检查（有症状患者的筛查结果、偶然与假阳性级联、及为何“更多数据”与“更好数据”是不同的问题）。**

## 数字与其制造者

::: definition 参考区间、变异与检测链 {#def-numbers}
**参考区间是有临床抱负的统计学人造物：通常是所选“健康”参考人群的中间95%、意味着二十分之一的正常人在构造上“异常”、而区间的出处（谁被采样、空腹、坐位、训练、族裔代表、排除妊娠、吃补剂）决定了旗标的大半含义；要紧的分层（碱性磷酸酶与PSA及肌酐eGFR报告的年龄曲线、血红蛋白与铁蛋白与肌酐的性别分裂、产科实验室因生理失真大而可预测而发布的妊娠三期区间、及生物季节性效应——维生素D与皮质醇昼夜与季节规则）是“对谁异常”的诚实答案。变异在三个层面运行：人与人之间（遗传与设定点差异）、人之内（昼夜节律、饮食、月经、运动与体位效应——使“参考变化值”与不精密度指数计算成为重复检查的正确比较、血液与内分泌差值核查自动化的两结果差异显著性算术）、及分析中（以变异系数表示的不精密度、对照计量学目标的不准确度、源自生物变异的质量规范——总误差与西格玛指标的世界解释为何同一分析物有不同质量要求、及实验室为何拒绝报两位小数）。分析前链是多数错误居住之处、而临床医师自己的贡献列在其中：局部抬高钾与胆固醇的止血带时间与握拳、采血管顺序与充盈（凝血学者礼貌拒绝的柠檬酸盐欠充盈问题）、溶血假性钾升高与脂血黄疸胆红素干扰、时机规则（谷浓度与皮质醇与胰岛素及血培养配对及抗生素前采样规程）及患者状态规则（运动后与体位的肾素醛固酮、在免疫分析平台自身化学中模拟Graves病的生物素补剂检测）。分析链被质控并被审计（Levey-Jennings谱系与Westgard规则、患者永远看不见却每小时依赖的外部质量评估计划与ISO-15189认证期望）、及“危急值”回叫文化（必须在数分钟内到达具名临床医师的结果——钾与肌钙蛋白与阳性血培养与低中性粒细胞规则）是任何医院运行的最高可靠度流程之一、其失效是警示事件。最后是其他一切服务的解释框架：没有检查能自我解释、流行率依赖的预测值意味着同一结果在这个患者是深刻、在那个患者是噪音（预测值章算术在台边的重引）、及反射检测规程（自动TSH到游离T4与HIV筛查到确证及PSA讨论路径）是临床推理不在键盘旁时实验室编码的临床推理。**
:::

## 解释

::: definition 组套、模式与确证逻辑 {#def-panels}
**肝功能是模式语言不是判决：肝细胞-胆汁淤积酶架构（ALT与AST及模式比与混合定义、ALP与GGT及胆红素胆汁淤积集伴骨ALP例外与妊娠胎盘ALP）、真正要紧的合成功能检查（带半衰期的慢性标志物白蛋白、作为真正急性肝功能的PT-INR、及血小板与脾大门脉高压推断）、“肝功紊乱”急诊算法（转氨酶数千的急性肝炎组套及黄疸疼痛发热Charcot三联急诊及药物与酒精与自免及Wilson与溶血的分叉）、及孤立异常的苦工（孤立ALP的影像与骨之问及孤立非结合胆红素血症——在溶血工作检查说不是之前通常是Gilbert）。甲状腺检查是确证逻辑的头牌：TSH作为筛查主规则及继发性甲减陷阱及非甲状腺疾病规则（急性病期间除非疑甲状腺病否则不查甲功、也别按门诊参考区间解读你拿到的）、游离T4与T3伴结合蛋白警诫及抗生物素-生物素检测人工物及胺碘酮与NSAID置换效应、TPO抗体作为预后非诊断、及“住院发现的甲功异常在6-8周后门诊复查”规程——它预防的内分泌比它制造的更多。炎症标志物最常倒着用：CRP作为筛查兼监测两用（系列测量下降CRP作为治疗应答证据及ESR的锚定遗产及其浆细胞与巨球蛋白敏感度）、降钙素原诚实的生态位（停抗生素试验证据对因高PCT而开抗生素的越界）、及铁蛋白的三重生活（铁贮、急性期反应物、及数千意味着全然不同东西的噬血与Still病标志）。心脏标志物按动力学运行：高敏肌钙蛋白0/1与0/2小时算法带99百分位及生物学与性别特异警诫、急性损伤的差值规则及肾损害慢性升高及需求缺血2型问题使肌钙蛋白是发现不是诊断、及BNP与射血分数保留心衰年龄肥胖悖论算术。肾组套的诚实极限（肌酐作为晚而依赖肌肉量的标志物及eGFR公式的种族系数辩论及其2020年代的移除与替换、胱抑素C在肌酐盲处的角色、尿ACR作为没人开得够的检查及试纸亚硝酸盐与血的含义及“治ACR不治培养”规则）。血常规作为叙事阅读：小细胞鉴别与慢病贫血铁检查逻辑及地贫判别指数、大细胞的B12与叶酸与网织及酒精与药物与MDS顺序、分类的核左移与异型淋巴与原始细胞转诊规则、及血小板计数对出血时间的退休及当真出血且计数正常时的vWF与血小板功能检测。最后肿瘤标志物属于随访不属于筛查（PSA知情选择时代论证、CA-125在基层的排除价值及反向使用时的扫描恐慌、及作为系列监测仪器的CEA与CA19-9——有症状患者的升高值是转诊从不是诊断）：本章的确证格言是检查的含义是它强制的下一个检查——HIV筛查到确证及CD4与病毒载量及基因型链、阳性新生儿筛查到汗试验到遗传学链、异常血红蛋白筛查到电泳到咨询链——而每条链需要具名所有者与记录终点、因为孤立的“待确证检查”是丢失变量在临床技能章的形态。**
:::

## 级联

::: definition 患者身上的筛查检查、级联与开单伦理 {#def-cascade}
**人群筛查检查用于有症状或焦虑个体时行为不同、必须不同地引用：阳性预测值随流行率下降而崩塌（乳腺邻近算术在自费套餐层面重跑：无症状低危患者的肿瘤标志物筛查产出的多为假阳性、其伤害——影像、活检、带自身半衰期的焦虑——在过度诊断文献中已被充分记录）、所以开单伦理是“为问题开检查”：验前概率要么证明该检查改变管理的能力、要么不（“结果会改变我今晚的做法吗”过滤器与“临界结果我怎么办”预先承诺、Choosing Wisely运动及澳美先声将其操作化）。偶然瘤问题是同一面孔的反向伦理失败（影像分辨率跑在医学决策规则前面的肾上腺与甲状腺与垂体与肺所见、及已发表的级联追踪研究——“一个检查引出N个检查”系列带其成本与并发症量化——使“按指征扫描、为问题成像”成为患者安全口号、使放射医师的“申请单须带临床问题”成为道德而非官僚要求）。组套对靶向检查是同一论点在台面层：入院全套文化的支持者引用漏掉的低钠与乳糜泻偶然流行率、批评者引用级联与假阳性克制文献、而定型的实践是风险分层组套（急症的入院生化、按麻醉指南证据由病史查体所见驱动的术前检查——随机检查几乎从不改变结局、及体检套餐菜单应是筛查规划讨论而非化验标签）。系列测量逻辑教学不足而强有力：两个结果间带参考变化值算术的差值对恶化与恢复患者胜过任何单值的旗标（定义AKI分期与移植监测及骨髓瘤M蛋白与PSA倍增时间系列规则的肌酐上升轨迹与平台与下降）、这就是为何“明早复查”医嘱应是带理由的“我在找什么、变化多少”医嘱而非仪式。报告就是产品：“病史重于结果”的实验室顾问格言、解释性评论行（“请结合临床”的诚实）、实验室因临床医师不断开单而加上的“不推荐用于筛查”免责声明、及公开承认错误率否则失去临床医师信任的标本拒收与重抽文化。最后开单临床医师自己的问责层：本不该开的检查产生带下游所有者（级联的当事人）的假阳性、本该开而未开的检查（漏掉的梅毒血清学、二甲双胍患者从未查的B12、高血压患者跳过的尿检）产生从未获得名字的伤害；两种错误都是本章主题、而诊断推理章的安全语法——概率、阈值、行动——决定哪个检查属于哪个。**
:::

::: example 等待的危急值 {#ex-critical}
地区医院晚间血检钾7.1 mmol/L；分析仪旗标、技师认定溶血“像前一份标本”、复查未被优先、而观察表上是一位服雷米普利与甲氧苄啶的AKI患者、其心电图自入院未被看过。
::: solution
**危急值是系统属性（[[#def-numbers]]、[[renal/potassium-calcium-phosphate]]、[[renal/acute-kidney-injury]]）：链失败——不经检视的溶血假定（区分真假高钾的目视检查或离心及溶血指数数字规则）、危急值政策的所有者与时间及闭环要求（“结果到具名人、复述、记录、数分钟内行动”规程——这家医院拿不出其审计痕迹）、及本应在分析仪开口之前运行的处方审查（ACE抑制剂加甲氧苄啶加AKI的可拦截组合、用药安全章不断列表）；现在的医学——不等复查的心电图（尖峰与P波平坦与QRS增宽与正弦波轨迹）、稳膜-转移-清除序列及取除颤器时给钙、及“这是不是入院漏掉的发现”重看（医嘱单、液体平衡、观察表尿量）；及治理——带实验室自身周转与回叫数据的危急值审计、“临床医师拒收结果须凭检视与一小时内复查”规则、及复审每代人写一次的观点：钾不是实验室的结果与患者的问题——它是负有职责人链中的一个物件、每个环节的“别人会管”都在调查会上被发现。**
:::
:::

::: example 不是甲状腺的甲状腺 {#ex-nti}
入院常规血检含甲功：TSH 0.3、游离T4 9、游离T3 3.1——实验室评注“生化异常、请复查”；入院团队开始为“甲状腺可解释的”淡漠与体重增加做工作检查、直到有人注意到入院是因为肺炎。
::: solution
**非甲状腺疾病与常规的滥用（[[#def-panels]]、[[#def-cascade]]、[[endocrine/thyroid]]）：生理——病态正常甲状腺/非甲状腺疾病模式感染与饥饿及术后状态的低T3伴低正常T4与可变TSH、被误贴甲状腺炎标签的恢复期TSH一过性升高、及“急性病期间不测或不信”规则及其声明的例外（规则为之存在的黏液水肿与甲状腺风暴嫌疑）；系统成因——因“旧电子病历模板里有”而含甲功的入院组套文化（Choosing Wisely与实验室发起的去实施运动的目标：其适应证与写模板的顾问一同被删除的检查）、及使旗标成为转诊的“异常旗标等于临床问题”认知反射；正确顺序——甲状腺病史查体及“6-8周后门诊复查并附解释评论并抄送全科”、及“若异常持续就是另一个患者与真正的内分泌问题”；及实验室与信息团队共同学到的去实施课——按指征开单的目录治理（“从模板删反射并拥有菜单”的工作是以数据库形态呈现的患者安全）、及显示复查甲功更少、“异常结果”信更少、“这是什么意思”电话更少的审计、这是患者自己账本上区分低价值与高价值检查的唯一结局指标。**
:::

## 通向何处

检查准确度数学在[[epidemiology-ebm/diagnostic-tests]]演算、筛查规划的标准与结果在[[public-health/screening]]、疾病特异判读在[[renal/filtration]]与[[endocrine/thyroid]]与[[blood/anaemia]]与[[gastrointestinal/liver-function]]、肿瘤标志物的肿瘤学用途在[[pathology/cancer-diagnosis]]、分析前链的错误文化在[[clinical-skills/patient-safety]]。

::: history
**实验室医学的历史是数字取代叙事、然后需要叙事回来的故事。十九世纪把化学带到床旁（中世纪尿检轮终究让位于Liebig与Hoppe-Seyler的定量化学、确立临床生化是一门有正常值的科学）、血液计数仪与计数（Gowers血红蛋白计与四位分类时代）、1906年Wassermann血清学及Kahn与VDRL谱系使血清学成科；及1920-30年代早期质控工作（Shewhart控制图从贝尔实验室经“正常值”辩论迁入临床实验室）。参考区间的统计学在1960-70年代成熟（IFCC“参考值”术语及Reichelt与Harris与Figueroa-Falún时代的非参数百分位与合理划分辩论、“95%谬误”批评、及1970年代Harris起、1988-2014斯德哥尔摩会议如今设定全球质量规范的生物变异规划）。自动分析使链工业化（连续流动与Technicon时代、然后创造现代周转时间纪律的随机存取与急优先架构）、及1990年代起的ISO-15189认证运动把质量从职业美德变成审计标准。分析前的发现是本章的患者安全脊柱：Lippi邻近与Carraro与Plebani及WHO邻近与2010年代“实验室错误与患者安全”系列及六西格玛与根本原因研究确立60-70%的实验室错误发生在标本到达分析仪之前——止血带与采血管顺序与识别与时机——终于把采血椅放进质量改进的中心。临床判读正典随循证医学到来：JAMA合理临床检查与“这位患者有……吗”系列（缺铁的铁检查与TSH甲状腺准确度数据及CRP对ESR比较）、肌钙蛋白的诊断之旅（从1990年代达峰与清除曲线研究到高敏检测2010年代性别特异99百分位与0/1-2小时算法指南——及统一定义修订编纂的当代“肌钙蛋白是发现”对心肌损伤对梗死的清算）、及eGFR公式政治（MDRD与CKD-EPI谱系、种族系数时代及其2021-2024移除辩论、及胱抑素C配对提案——实验室数字社会学最清晰的案例）。级联文献是最新也最令人清醒的：2000年代偶然瘤与级联追踪影像系列、肿瘤标志物与全身筛查试验伤害数据、Choosing Wisely（2011-）运动的实验室部分、过度诊断运动（Welch与《过度诊断》时代的筛查伤害量化）、及对常规住院甲功与入院组套的去实施研究。其结论——“检查只是一个过程的开始、而过程需要一个所有者”——成为2020年代实验室的报告标准与反射规程设计原则。最后一言属于最老的检查：尿仍距被过度解读一根试纸之遥、而实验室自己的历史不断以新衣生产同一建议：知道流行率、知道变异、知道分析前之罪、并知道正确的检查有时是你不开的那个。** - [[epidemiology-ebm/diagnostic-tests]]、[[clinical-skills/clinical-reasoning]]、[[public-health/screening]]。**
:::

::: summary
- 参考区间描述参考人群的95%、不是正常性；年龄、性别、妊娠、海拔、药物与生物变异决定旗标含义、而跨人差值需要参考变化值算术。
- 多数实验室错误发生在标本被分析之前：止血带技术、采血管顺序与充盈、时机与患者状态是临床职责、而危急值回叫环是像生命支持一样被审计的生命支持流程。
- 组套是模式语言：肝与甲状腺与炎症与心脏与肾检查逻辑各系于确证什么、何时复查、及验前概率使结果意味着什么；急性病使其中若干失效、甲状腺检查最可靠地失效。
- 预测值跟随流行率：低危有症状或焦虑患者用筛查级检查多产假阳性与级联、所以为问题开检查、并预先承诺每个结果将改变什么。
- 肿瘤标志物与多数“常规”添加属于定义的监测或按指征路径、不属于入院模板；目录治理是带账号的低价值医疗削减。
- 每个结果的下一个检查需要具名所有者与终点；孤立的待确证检查与无主的偶然瘤是实验室医学伤害其所警告患者的两种方式。
:::

::: exercise 纠正溶血 {level=1}
钾6.4在健康患者以溶血到达；另一个6.4在无尿透析患者23:00未溶血到达。处理两者并陈述各自决定背后的规则。
::: solution
**同数字两医学（[[#def-numbers]]、[[renal/potassium-calcium-phosphate]]）：第一个——溶血纠正：目视或指数确认、一小时内无止血带握拳新部位重抽并即刻风险评估（若有任何理由相信真值高则心电图——肾功与药物与症状决定）、因为假性高钾是标本而非患者的诊断；第二个——无尿肾衰竭23:00的6.4绝不是“明早复查”：现在心电图、现在稳膜与转移治疗、今晚安排透析、及“结果与临床背景一致意味着在标本问题有答案之前结果就被相信”规则；及共享语法——实验室数值的可信度与其临床风险是分离的两轴（心电图正常而6.4的高肌酐患者与困难静脉穿刺后6.4的健康人是相反世界）、告诉采血师怎么做的标本拒收重抽政策、及“若你错了、不告知需要据其行动的人就绝不丢弃结果”的沟通职责——整章浓缩于一句。**

**缺铁作为句子不是数字（[[#def-panels]]、[[blood/anaemia]]）：解读——小细胞低色素缺铁图像（低铁蛋白低饱和度高TIBC及血小板增多及正常ESR组合说明单纯缺铁、非铁蛋白处正常偏高的慢病贫血）、反应性血小板增多已解释（无需骨髓检查）；两段病史——1)失血：月经量化（垫与血块与时程及从青少年起病的慢性）与消化道（消化不良与NSAID与大便与乳糜泻按年龄的结直肠红旗）、及2)吸收不良-饮食-减重手术-PPI-幽门螺杆菌邻近层（“即使出血源明确也查乳糜泻血清学”指南细微）；处方——口服对静脉铁决定（不耐受与严重度与IBD及需要速度的静脉铁指征）、病因确认不只是补足规则、及随访算术网织5-10天然后每4周血红蛋白升2克的期待——“4周无应答意味着不依从或持续失血或诊断错误”重看、及正常化后再贮铁3个月与维持或治因决定——防止被无人转诊肌瘤的经产患者第六次缺铁入院。**

::: exercise 对临界预先承诺 {level=2}
无症状48岁者的私人“健康筛查”回报：CA-19-9轻度升高、筛查超声示甲状腺结节、及“遗传风险变异”组套结果。用级联算术给建议。
::: solution
**你在其中的级联（[[#def-cascade]]、[[epidemiology-ebm/diagnostic-tests]]）：算术——低流行率下即便优异特异度也淹没在假阳性中（练习器曲线：1%流行率疾病的99%特异度使多数阳性为假）；具体项——CA-19-9在任何指南都不是筛查检查（其正当用途是恶性胆道梗阻工作检查之问及被监测的胰胆肿瘤患者）、而良性胆汁淤积与甲状腺与妇科混淆因素是预期来源；“偶然甲状腺结节”现循非筛查影像路径自身规则（尺寸与特征分层的随访及其已发表的过度检出批评）、而“遗传风险变异”需要该变异的真实外显率与临床可操作性审计（遗传规划不断重报的直接面向消费者组套对复杂疾病低预测值发现）；建议结构——具名安心步骤（“这个结果不意味你得癌；它可能是什么及如果有、唯一理性的下一步检查是什么”）、一所有者规则（全科或定义门诊、不是五个）、及预先承诺纪律：检测前约定临界结果触发预先规定的行动且仅此而已；及系统层——合理应用标准运动推动的“检测前概率咨询”要求、及过度诊断文献作者称为换个词汇预防医学的面向患者“为何我不开这个”谈话。**

::: exercise 构建反射规程 {level=3}
你的实验室不断发现未管理的异常结果：没人开的维生素D复查、无记录所有者的“待确证”HIV与乳糜泻血清学、及每年制造40次内分泌式混乱会诊的乙肝核心抗体“孤立阳性”。写出带治理的检查管家与反射规程规范。
::: solution
**带所有者的反射（[[#def-numbers]]、[[#def-panels]]、[[clinical-skills/records-handover]]）：诊断——实验室一直在给设计假定为“临床医师会处理”的系统添加临床推理、而“处理”没有所有者也没有时钟；规程库——1)做好的经典反射树（TSH到游离T4带“急性病不建议筛查”旗逻辑、及HIV筛查到确证到CD4与病毒载量带具名倡导者与48小时沟通规则、乳糜泻筛查带总IgA与组织转谷氨酰胺酶及IgA缺乏反射规则及自动起草供临床医师签字的内镜转诊）、2)未决结果登记（每个“待确证”出生即带所有者字段与升级间隔；每月向申请科室报“谁关闭了它何时”）、3)写成单页的孤立阳性与模棱政策（HBc孤立阳性算法——既往假阳性对已解决对隐匿对疫苗应答决策表配何时呼叫肝病规则及每年审计其预防的混乱）、及4)低价值检查去实施（“维生素D给充足人群骨骼健康：无指征不复查”目录变更配结果屏幕指南引用及面向全科运动——去实施试验发现处方集式摩擦胜教育）；治理——拥有检查目录的实验室-临床主任与信息联合委员会（指征菜单、每年对照Choosing Wisely与专科指南审查的移出模板清单）、“按证据加入按审计移除”规则、带临床治理签署的反射规程变更控制（反射树是长期医嘱、得到处方级审查）、及孤儿结果的患者安全报告环成为证明登记有效的审计；及指标集——无主异常结果计数（本规范存在即为把它归零）、危急与确证结果的沟通时间、去实施检查的量与其反弹率、及年度报告“我们本不该产出的结果与本应追而未追的结果”——因为检查管家是无光环的抗微生物管家、两者终究是不做某些事的纪律。**

::: example 不是心梗的肌钙蛋白 {#ex-troponin}
79岁因肾盂肾炎脓毒症入院肌钙蛋白340 ng/L；急诊启动“心梗路径”给双联抗血小板并计划造影；女儿问他是否心梗、得到的回答是“是的、小的一次”。
::: solution
**心肌损伤对梗死（[[#def-panels]]、[[cardiovascular/coronary-artery-disease]]、[[infectious-diseases/fever-sepsis]]）：分类——统一定义的分裂：99百分位以上肌钙蛋白升高意味着心肌损伤；梗死需要损伤加缺血证据（症状与心电图与影像及差值动力学标准）；本例模式（脓毒症与心动过速与低血压及肾清除降低的需求缺血2型图像）是内科入院“肌钙蛋白阳性”最常见原因、而抗血小板与导管答案治的是数字不是患者；动力学纪律——升降对慢性稳定升高的区分（系列测量逻辑：从不趋势的心肌炎与慢性肾病与结构性心脏病平台）及检测自身警诫（嗜异性抗体与大分子复合怪象、年龄与性别百分位之辩）；正确的处理——治脓毒症及心电图与差值肌钙蛋白系列及诚实问临床缺血之问（“符合标准则为2型梗死、按其病因治”）及对照出血风险与真实冠脉概率而非路径惯性做抗栓决定；及谈话——“他的心脏检查异常是因为感染让心脏受累——我们在治感染并观察心脏；这不是堵血管的心梗”解释、女儿会向病房团队复述、既防假性安慰又防随患者走过每次未来入院并附上不必要导管的终身“他心梗过”标签。**
:::

::: example INR仪与草药茶 {#ex-inr}
66岁机械瓣服华法林、INR 8.9无出血就诊；她开始“一种中草药”、而其“新自测仪”上周给出“6几”、她报告后被告知“按原量继续”；她的靶值是2.5-3.5。
::: solution
**自测加相互作用加系统（[[#def-numbers]]、[[cardiovascular/vascular-disease]]、[[pharmacology/patient-variation]]）：即刻医学——无出血高INR规程（机械瓣维生素K途径与剂量——过度纠正血栓是瓣膜自身风险——及凝血酶原复合物只用于出血逻辑）、及“无出血须查体证实不靠问”；相互作用搜寻——作为教学类别的草药-华法林相互作用（含香豆素与影响CYP与含维生素K与抗血小板草药层：当归与丹参谱系及蒜与姜邻近、相互作用数据库因证据为病例报告级而引用不足却是真实的）、每个INR复查门诊都问因为患者不会主动说“草药不是药”；自测审计——仪器的质控与编码与操作技术核查、及谁在什么规程下解读了“6几”的关键治理之问（自我管理对自测区分：无滴定计划与响应性抗凝服务的自测是没有医学的测量）、及给超标机械瓣患者“按原量继续”的报告结果路径——需要升级标准及背后药师或护士处方者的电话复查规程；及收尾的教育——“每个新的一切都告诉抗凝门诊”规则（抗生素与扑热息痛疗程与草药与酗酒发作与维生素K饮食波动）配INR频率计划与“哪些症状让你今天来”卡、及做成可复核而非大喊的相互作用警报系统、这是本章自己的患者安全句：数字的含义包括谁测的与谁据其行动。**

::: exercise 处理被拒的标本 {level=2}
实验室来电：“两套血培养——一瓶凝固酶阴性葡萄球菌阳性；另一套清晰；我们标它污染、但患者有瓣膜假体。”协商科学与决定。
::: solution
**污染物对心内膜炎（[[#def-numbers]]、[[infectious-diseases/healthcare-infections]]、[[cardiovascular/valve-congenital-disease]]）：微生物——两瓶之一CoNS通常是皮肤菌群的算术（到阳性时间与仅液体对两种培养基及气泡计数的定量血培养逻辑）对瓣膜假体背景——它使CoNS成第三常见心内膜炎微生物、而“污染物”一词杀过瓣膜患者；决定结构——改良Duke应用（两次独立培养标准及假体与心内装置风险类别及经胸对经食道现已邻近CT与PET的超声策略）、及“稳定而亚急性者先抽重复培养再正规治疗、别先开始抗生素”IE指南对抗脓毒症反射的专科规则、及假体与心脏阻滞与栓塞轨迹的早期外科团队介入；过程——抗生素前重复培养及实验室自身对话（“在这个患者我们不叫它污染物”双方都记录的谈话）、阳性瓶与讨论进病历因为六位医师将继承这个发热；及元课——结果的含义是患者的背景、这是本章论点：实验室能识别微生物与概率；只有临床医师能说这位患者得的是哪一个。**
