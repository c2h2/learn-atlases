实验室检查是最常见的临床行为之一：一次典型的住院会产生几十个结果。每个数字只有在问题明确、标本采集和处理正确、并且对照正确的参考和眼前的患者来解读时，才能回答问题。本章讲的是如何正确地解读结果。内容包括参考区间是怎样制定的，误差如何在标本到达分析仪之前混入，检查的准确性和患病率如何决定结果的意义，以及如何解读最常见的血液检查、血气分析和尿液分析。

其中的概率推理来自[[clinical-skills/clinical-reasoning]]。实验室如何运作、组织标本如何处理，见[[pathology/diagnostic-pathology]]。

## 从患者到结果

一个结果要经过三个阶段，每个阶段都可能混入误差。

::: definition 检验全过程 {#def-process}
**检验全过程**分为三个阶段：

- **分析前阶段**：选择检查项目、识别患者、用正确的容器采集标本、贴标签、运送，以及分析前的保存。
- **分析阶段**：测量本身，由校准、室内质控和室间质评加以控制。
- **分析后阶段**：报告、标记异常、通报紧急结果，以及临床医生的解读和处理。

在现代实验室中，大多数误差出现在分析前和分析后阶段，而不是在分析仪中。
:::

常见的分析前误差会产生特征性的模式，识别它们可以避免去治疗一个假象：

- **溶血**使红细胞内容物释放到血清中，造成**血钾**假性升高，乳酸脱氢酶、AST和磷酸盐也会升高。原因包括静脉穿刺困难、针头过细、剧烈摇晃或用力把血液推过针头。
- 标本**分离延迟**（例如放置过夜，尤其在低温下）会使钾从细胞中漏出、葡萄糖被消耗，因此血钾升高、血糖降低。
- **EDTA污染**，来自采血管顺序错误或从全血细胞计数管中倒出血液，会造成极高的血钾伴极低的血钙，因为EDTA是一种钾盐并能结合钙。
- **输液侧手臂污染**，即从正在输液的手臂采血，会稀释标本并混入输液中的成分，如葡萄糖或氯化钠。
- **血液装错试管**，即标本贴上了另一位患者的信息，虽然少见但很危险，尤其是对输血而言。应在床旁根据患者的身份腕带填写标签，绝不能预先贴好标签。

::: example 血钾7.2 {#ex-potassium}
Fisher女士，76岁，上午10点在全科诊所做常规血液检查。标本于下午6点由快递取走，次日上午才分析。实验室打电话报告血钾为7.2 mmol/L。她上一次的血钾为4.3 mmol/L，没有服用升高血钾的药物，肌酐没有变化。应如何处理这一结果？

::: solution
血钾7.2 mmol/L如果是真实的，会危及生命，因此绝不能忽视。但有几个特点提示**假性高钾血症**：分离前延迟很久，上一次数值正常，肾功能稳定，没有药物原因。查看实验室是否报告了溶血。

安全的做法是当天联系患者。如果她情况良好，就紧急复查，确保标本及时送到实验室（或在条件允许时做床旁检测），并考虑做心电图。如果她不适、有症状或心电图显示高钾血症改变，她需要急诊评估。决策的出发点是存在危险的真实结果的可能性，而结果的模式则指导判断这种可能性有多大。记录推理过程和复查结果。
:::
:::

## 参考区间与“异常”的含义

::: definition 参考区间 {#def-reference}
**参考区间**（常称“正常范围”）通常是指健康参考人群检测结果中间**95%**所在的区间，即第2.5到第97.5百分位数。按照定义，有**5%的健康人**的结果落在区间之外。参考区间取决于检测方法和人群，许多参考区间针对年龄、性别或妊娠而设，因此应使用报告实验室印出的区间。
:::

由此得出三个推论。

第一，刚刚超出区间的结果往往对这个人来说是正常的。第二，做的检查越多，健康人出现“异常”结果的可能性越大。如果各项检查相互独立，健康人全部$n$项结果都在区间内的概率为$0.95^n$。做20项检查时约为36%，所以近三分之二的健康人至少会有一项结果被标记为异常。各项结果并非完全独立，但这一效应是真实存在的，它是反对无目的开检查单的有力论据。第三，在区间之内的结果不一定对这位患者来说是正常的：肌酐从60升到100 µmol/L，可能仍“在范围之内”，却代表肾功能显著下降。

### 随时间的变化

对于需要随访的患者，两次结果之间的变化可能比任何单个数值更重要。每个结果都会因**分析变异**（方法的不精密度）和**生物学变异**（个体内的自然波动）而变化。**参考变化值**估计两次结果之间的差异要多大，才不太可能仅由这些变异来解释：

$$
\text{RCV} = \sqrt{2} \times z \times \sqrt{\text{CV}_A^2 + \text{CV}_I^2},
$$

其中$\text{CV}_A$和$\text{CV}_I$分别是分析变异系数和个体内生物学变异系数，$z$在95%置信度（双侧）时为1.96。生物学变异小的指标（如肌酐）在百分比差异较小时就可能显示有意义的变化；生物学变异大的指标则需要更大的变化。

## 检查的准确性与患病率

::: definition 灵敏度、特异度与预测值 {#def-accuracy}
将某项检查与参考标准比较：

| | 患病 | 未患病 |
|---|---|---|
| 检查阳性 | 真阳性（TP） | 假阳性（FP） |
| 检查阴性 | 假阴性（FN） | 真阴性（TN） |

- **灵敏度** $= \text{TP}/(\text{TP} + \text{FN})$：患病者中检查阳性的比例。
- **特异度** $= \text{TN}/(\text{TN} + \text{FP})$：未患病者中检查阴性的比例。
- **阳性预测值**（PPV）$= \text{TP}/(\text{TP} + \text{FP})$：阳性结果中真阳性的比例。
- **阴性预测值**（NPV）$= \text{TN}/(\text{TN} + \text{FN})$：阴性结果中真阴性的比例。
:::

::: theorem 预测值取决于患病率 {#thm-prevalence}
对于灵敏度为$s$、特异度为$c$的检查，在患病率（验前概率）为$p$的人群中，

$$
\text{PPV} = \frac{s\,p}{s\,p + (1-c)(1-p)}, \qquad \text{NPV} = \frac{c\,(1-p)}{c\,(1-p) + (1-s)\,p}.
$$

随着患病率下降，PPV下降而NPV上升。因此，同一项检查在专科门诊和筛查项目中的表现截然不同。
:::

::: proof 推导 {#prf-prevalence}
在规模为$N$的人群中，有$pN$人患病，其中$s\,pN$人检查阳性；有$(1-p)N$人未患病，其中$(1-c)(1-p)N$人检查阳性。PPV是真阳性除以全部阳性，$N$被约去。NPV同样由真阴性$c(1-p)N$和假阴性$(1-s)pN$得出。当$p$很小时，即使$c$很高，假阳性$(1-c)(1-p)$也很容易超过真阳性$s\,p$。
:::

::: widget plot
f: s*x/(s*x + (1-c)*(1-x)); c*(1-x)/(c*(1-x) + (1-s)*x)
x: 0, 1
y: 0, 1
sliders: s=0.9:0.5:0.99:0.01; c=0.9:0.5:0.99:0.01
labels: \text{PPV}; \text{NPV}
caption: 对于灵敏度为$s$、特异度为$c$的检查，阳性和阴性预测值随患病率的变化。患病率低时，即使是好的检查，阳性结果也大多是假阳性。这是简化模型。
:::

::: example 一个筛查结果 {#ex-screen}
某检查对某病的灵敏度为90%，特异度为95%。它被用于：(a)受检者中30%患有该病的门诊；(b)患病率为1%的人群筛查。分别计算两种情况下的PPV。

::: solution
(a)在1,000名门诊患者中，300人患病，其中270人检查阳性；700名未患病者中，5%（35人）检查阳性。$\text{PPV} = 270/305 \approx 89\%$。

(b)在1,000名受筛查者中，10人患病，其中9人检查阳性；990名未患病者中，5%（49.5人）检查阳性。$\text{PPV} = 9/58.5 \approx 15\%$。

在筛查情况下，约85%的阳性结果是假的。这就是为什么筛查阳性之后要做确诊检查而不是直接诊断，也是为什么应针对临床问题选择检查，而不是“以防万一”地加做。
:::
:::

::: warning 治疗的是患者，不是数字
一位情况良好的患者出现异常结果，往往是假象、正常变异或轻微发现；而正常结果如果检查选错了或做得太早（胸痛发作后一小时内的肌钙蛋白、肺炎早期的胸片），并不能排除疾病。在根据结果采取行动之前，先问：它与临床表现相符吗？可能是分析前误差吗？与患者的基线相比有变化吗？然后根据综合情况行动。同样，绝不要在不复查的情况下把一个危险的结果当作假象而置之不理。
:::

## 常见血液检查

### 全血细胞计数

全血细胞计数报告血红蛋白、红细胞指数、白细胞计数及其分类，以及血小板。

- **血红蛋白**低于按性别划分的参考区间即为**贫血**。**平均红细胞体积（MCV）**用于分类：
  - **小细胞性**（MCV低）：缺铁（最常见的原因）、地中海贫血特征，有时为慢性病贫血；
  - **正细胞性**：急性失血、慢性病贫血、慢性肾脏病、骨髓衰竭、溶血；
  - **大细胞性**（MCV高）：维生素B12或叶酸缺乏、酒精、肝病、甲状腺功能减退症、某些药物（如甲氨蝶呤（methotrexate）和羟基脲（hydroxycarbamide）），以及网织红细胞计数升高。
- **铁蛋白**是反映铁储备的最佳单项检查：铁蛋白低可确诊缺铁，但炎症时铁蛋白会升高，因此存在炎症时铁蛋白正常不能排除缺铁。
- **白细胞**：**中性粒细胞增多**提示细菌感染、炎症、使用糖皮质激素或组织损伤；**淋巴细胞增多**提示病毒感染或慢性淋巴细胞白血病；**嗜酸性粒细胞增多**提示过敏、寄生虫或某些药物；**中性粒细胞减少**很重要，因为它易导致严重感染。
- **血小板**：血小板减少在计数很低时增加出血风险；血小板增多通常是反应性的（感染、炎症、缺铁），较少见的是骨髓增殖性肿瘤。

对成人缺铁性贫血，主要问题是**为什么**：在男性和绝经后女性中，必须排除消化道失血，包括肠癌。血液学见血液课程（[[blood]]）。

::: example 一位67岁男性的乏力 {#ex-anaemia}
Davies先生，67岁，乏力三个月。全血细胞计数显示血红蛋白98 g/L，MCV 72 fL，血小板460 × 10⁹/L；铁蛋白8 µg/L，CRP正常。他在服用阿司匹林，没有明显出血。解读结果并说明下一步。

::: solution
他有**小细胞性贫血**。铁蛋白低而CRP正常，可确诊**缺铁**（这里铁蛋白没有因炎症而假性升高）。血小板轻度升高是缺铁时常见的反应性表现。对于67岁的男性，在被证明是其他原因之前，缺铁都应归因于失血，而消化道是常见的来源；阿司匹林增加上消化道出血的风险，但不能想当然地认为它就是原因。按照英国疑似癌症指南，他这个年龄出现不明原因的缺铁性贫血，需要紧急检查消化道（通常按当地路径做上、下消化道内镜），并应检测乳糜泻血清学。补铁能纠正贫血，但回答不了贫血为什么会发生。
:::
:::

### 尿素、电解质与肾功能

- **肌酐**既反映肾功能，也反映肌肉量。**eGFR**由肌酐、年龄和性别计算得出；NICE（2021年）建议使用不作种族校正的CKD-EPI方程。eGFR只在稳态下有效：在急性肾损伤时，肌酐的变化滞后于滤过功能的下降。
- **尿素**除了在肾功能下降时升高外，还会因脱水、上消化道出血和高蛋白摄入而升高。
- **钠**代谢紊乱是水平衡的紊乱。**钾**代谢紊乱之所以危险，是因为它影响心脏。

急性肾损伤按肌酐的升高和尿量的减少分期；标准和诊治思路见[[renal/acute-kidney-injury]]。

许多英国实验室会报告根据白蛋白浓度**校正的钙**，因为血浆钙约40%与白蛋白结合。一个常用公式是

$$
\text{校正钙} = \text{实测钙} + 0.02 \times (40 - \text{白蛋白}),
$$

其中钙的单位为mmol/L，白蛋白的单位为g/L。各地公式有所不同；当白蛋白严重异常或对准确性要求高时，**离子钙**（在血气分析仪上测定）更好。

### 肝功能检查

“肝功能检查”大多测量的是肝脏**损伤**，而不是功能。应把它们作为一种模式来解读：

- **肝细胞型**：ALT和AST的升高超过ALP（病毒性肝炎、药物性肝损伤、缺血、脂肪性肝病、自身免疫性肝炎）。
- **胆汁淤积型**：ALP和GGT的升高超过转氨酶（结石或肿瘤引起的胆管梗阻、原发性胆汁性胆管炎、原发性硬化性胆管炎、药物）。ALP升高而GGT正常，提示来源是骨而不是肝；ALP在妊娠和儿童生长期也会生理性升高。
- **胆红素**：溶血时升高（非结合型）；Gilbert综合征时升高（非结合胆红素轻度升高，禁食或患病时上升，其他检查正常）；肝病和梗阻时升高（结合型）。
- **合成功能**：**白蛋白**（变化慢，患病和蛋白丢失时也会下降）和**凝血酶原时间/INR**（变化快；INR升高且不能被维生素K纠正，提示严重的肝衰竭）。

### 炎症标志物

**C反应蛋白（CRP）**是肝脏在白细胞介素-6作用下产生的一种急性期蛋白。它在炎症发生数小时内升高，炎症消退后迅速下降，因此可用于追踪治疗反应。**红细胞沉降率（ESR）**上升较慢，并受贫血、年龄和免疫球蛋白的影响；它在少数疾病中仍然有用，如巨细胞动脉炎和骨髓瘤。两者都不特异：CRP升高不能说明炎症在哪里或是否为感染；疾病早期CRP正常也不能排除严重感染。

### 心肌肌钙蛋白

**高敏心肌肌钙蛋白**检测能测出受损心肌释放的极微量肌钙蛋白。数值高于健康参考人群的**第99百分位数**表示**心肌损伤**。按照《第四版心肌梗死通用定义》（2018年），**心肌梗死**要求肌钙蛋白升高和/或下降，并有缺血的证据（症状、心电图改变、影像学或血管造影）。肌钙蛋白在许多非缺血性疾病中也会升高，包括脓毒症、肺栓塞、心力衰竭、心肌炎、肾功能损害和剧烈运动后。因此，解读取决于临床表现以及系列标本之间的**变化**，并使用当地方案中针对所用检测方法的路径（[[cardiovascular/coronary-artery-disease]]）。

## 血气分析

动脉血气测定pH、氧和二氧化碳分压，通常还包括电解质、乳酸和血红蛋白。海平面吸空气时成人的典型参考值为：**pH 7.35~7.45**；**PaCO₂ 4.7~6.0 kPa**（35~45 mmHg）；**PaO₂高于约10 kPa**（75 mmHg），随年龄下降；**碳酸氢根22~26 mmol/L**；碱剩余−2至+2 mmol/L。对于pH、碳酸氢根、钾、葡萄糖和乳酸，静脉血气往往就足够了。

::: theorem 血气分析的分步解读 {#thm-abg}
1. **氧合**：患者是否低氧血症？PaO₂与吸入氧浓度是否相称？（吸空气时，肺泡-动脉氧分压差有帮助；见下文。）
2. **pH**：酸血症（低于7.35）还是碱血症（高于7.45）？
3. **呼吸成分**：PaCO₂是升高（呼吸性酸中毒）还是降低（呼吸性碱中毒）？
4. **代谢成分**：碳酸氢根或碱剩余是降低（代谢性酸中毒）还是升高（代谢性碱中毒）？
5. **原发紊乱与代偿**：哪一种变化解释了pH？另一成分的代偿是否符合预期？
6. **代谢性酸中毒时，计算阴离子间隙**：$\text{AG} = [\text{Na}^+] - ([\text{Cl}^-] + [\text{HCO}_3^-])$。
:::

**阴离子间隙**代表未测定的阴离子，主要是白蛋白。其参考范围取决于分析仪，不计钾时通常约为8~16 mmol/L。**阴离子间隙增高型代谢性酸中毒**提示有酸的增加：乳酸（休克、脓毒症、缺血）、酮体（糖尿病或酒精性酮症酸中毒）、肾衰竭，或甲醇、乙二醇和水杨酸盐等毒物。**阴离子间隙正常（高氯性）酸中毒**提示碳酸氢根丢失（腹泻、某些肾小管酸中毒）或大量输注氯化钠。白蛋白低会降低阴离子间隙，可能掩盖阴离子间隙增高型酸中毒。

对于代谢性酸中毒，**Winter公式**预测预期的呼吸代偿：预期$\text{PaCO}_2$（mmHg）$= 1.5 \times [\text{HCO}_3^-] + 8 \pm 2$。PaCO₂高于预测值提示合并呼吸性酸中毒。其生理学见[[physiology/acid-base]]，临床紊乱见[[renal/acid-base-disorders]]。

**肺泡-动脉氧分压差（A–a梯度）**用来区分由通气不足引起的低氧血症（梯度正常）和由气体交换障碍引起的低氧血症（梯度增大）。肺泡氧分压由**肺泡气方程**估计：

$$
P_AO_2 = F_iO_2 \times (P_{atm} - P_{H_2O}) - \frac{P_aCO_2}{0.8},
$$

在海平面吸室内空气时约为$0.21 \times (101.3 - 6.3) - P_aCO_2/0.8 \approx 20 - 1.25\,P_aCO_2$ kPa。梯度为$P_AO_2 - P_aO_2$，年轻成人通常低于约2 kPa，并随年龄增大。

::: example 糖尿病酮症酸中毒的血气 {#ex-dka}
Ali先生，23岁，1型糖尿病，呕吐、腹痛。吸空气：pH 7.12，PaCO₂ 2.8 kPa，PaO₂ 13.5 kPa，碳酸氢根9 mmol/L，钠136 mmol/L，氯100 mmol/L，血糖28 mmol/L，血酮5.2 mmol/L。解读这份血气。

::: solution
1. **氧合**：吸空气时PaO₂ 13.5 kPa正常。A–a梯度为$20 - 1.25 \times 2.8 - 13.5 = 3.0$ kPa，略高，但在深大呼吸时可以接受。
2. **pH** 7.12：重度酸血症。
3. **PaCO₂** 2.8 kPa降低，这本身会导致碱中毒，所以呼吸改变不是原因。
4. **碳酸氢根** 9 mmol/L极低：原发紊乱是**代谢性酸中毒**。
5. **代偿**：预期PaCO₂ $= 1.5 \times 9 + 8 = 21.5 \pm 2$ mmHg，即约19.5~23.5 mmHg或2.6~3.1 kPa（1 kPa = 7.5 mmHg）。他的2.8 kPa（21 mmHg）在范围之内：呼吸代偿恰当，没有合并呼吸紊乱。
6. **阴离子间隙** $= 136 - (100 + 9) = 27$ mmol/L：增高。结合高血糖和5.2 mmol/L的血酮，这是**糖尿病酮症酸中毒**。

他符合英国糖尿病联合学会（JBDS）的DKA标准（血酮3.0 mmol/L或以上，血糖高于11 mmol/L或已知糖尿病，以及碳酸氢根低于15 mmol/L和/或静脉pH低于7.3）。处理遵循当地DKA方案（[[endocrine]]）。
:::
:::

## 尿液分析

**尿试纸条**检测血、蛋白、葡萄糖、酮体、白细胞酯酶、亚硝酸盐和比重。它便宜、快速，但有重要的局限。对于有尿路感染症状的65岁以下女性，试纸条结果可以支持诊断。对于**65岁以上**的人，英国指南建议**不要**用试纸条诊断尿路感染，因为无症状菌尿很常见，试纸条阳性会导致不必要的抗生素使用和其他诊断的漏诊。试纸条潜血阳性需要显微镜检查或复查；如果持续存在且原因不明，需要评估泌尿系统或肾脏病因；蛋白尿用白蛋白/肌酐比值定量。尿妊娠试验检测hCG，对任何可能怀孕的人，在进行电离辐射影像学检查、使用许多药物和手术之前都应进行。

::: quiz
一位40岁男性的标本由一名学生采集，学生先灌了全血细胞计数管，结果血钾6.9 mmol/L，血钙0.9 mmol/L。他情况良好，心电图正常。最可能的解释是什么？
- [ ] 急性肾损伤
- [ ] 甲状旁腺功能减退症
- [x] 标本被EDTA污染
- [ ] 横纹肌溶解
::: solution
在情况良好的患者中出现极高的血钾伴极低的血钙，提示EDTA污染：全血细胞计数管中的EDTA钾使血钾升高并螯合钙。按推荐顺序采集各管、绝不在管间倒血，可以防止这种情况。应尽快复查，因为这个结果无论哪个方向都不可信。
:::
:::

::: history
在20世纪，临床化学从少数几项手工检测发展为自动化分析。20世纪50年代，血气分析诞生于一场紧急事件：在1952年哥本哈根脊髓灰质炎流行期间，麻醉医生**Bjørn Ibsen**引入了经气管切开的手动通气，而实验室医生**Poul Astrup**开发了测定血液pH和CO₂的方法来指导通气。**Leland Clark**于1954年描述了氧电极，**John Severinghaus**于1958年描述了CO₂电极，它们是现代所有血气分析仪的基础。1959~1960年，**Rosalyn Yalow**和**Solomon Berson**发明了放射免疫分析，使测定血液中胰岛素等激素成为可能；Yalow于1977年获得诺贝尔奖。
:::

## 后续内容

本章的方法适用于每一个专科的检查。针对特定器官的解读在[[renal/acute-kidney-injury]]、[[gastrointestinal/liver-function]]和[[endocrine]]中展开，诊断性检查的评价见[[epidemiology-ebm/diagnostic-tests]]。影像学见[[clinical-skills/medical-imaging]]。

::: summary
- 大多数实验室误差发生在分析之前或之后；要识别溶血、分离延迟、EDTA污染和输液侧手臂采血的模式。
- 参考区间包含健康人中间的95%；检查做得越多，健康人出现“异常”结果的可能性越大。
- 与患者基线相比的变化可能比参考区间更重要；参考变化值量化有意义的变化。
- 预测值取决于患病率：患病率低时，即使准确的检查也会产生大多数假阳性。
- 按血红蛋白和MCV解读全血细胞计数，把肝功能检查作为模式解读，把CRP看作非特异、变化快的标志物，把肌钙蛋白看作心肌损伤的证据，并结合临床表现和系列变化解读。
- 分步解读血气：氧合、pH、呼吸和代谢成分、代偿和阴离子间隙。
- 不要用尿试纸条诊断65岁以上人群的尿路感染。
:::

## 习题

::: exercise 健康人做许多检查 {level=1 check="round(0.95^20*1000)/1000"}
如果一位健康人做20项相互独立的检查，每项检查的参考区间都包含95%的健康人，那么全部20项结果都在区间内的概率是多少？结果保留三位小数。
::: solution
$0.95^{20} = 0.358$。因此约64%的健康人至少有一项结果在区间之外。
:::
:::

::: exercise 阴离子间隙 {level=1 check="24"}
钠140 mmol/L，氯104 mmol/L，碳酸氢根12 mmol/L。计算阴离子间隙（不计钾）。
::: solution
$\text{AG} = 140 - (104 + 12) = 24$ mmol/L，增高。寻找乳酸、酮体、肾衰竭或毒物。
:::
:::

::: exercise 校正钙 {level=1 check="2.46"}
实测钙2.20 mmol/L，白蛋白27 g/L。用公式“校正钙 = 实测钙 + 0.02 × (40 − 白蛋白)”计算，给出以mmol/L表示的精确数值。
::: solution
$2.20 + 0.02 \times (40 - 27) = 2.20 + 0.26 = 2.46$ mmol/L，在典型的参考区间之内。实测值低是由白蛋白低造成的。如果对准确性要求高，应测定离子钙。
:::
:::

::: exercise 预测值 {level=2 check="round(1000*0.99*0.02/(0.99*0.02+0.01*0.98))/1000"}
某检查的灵敏度为99%，特异度为99%。在患病率为2%的人群中，阳性预测值是多少？以比例表示，保留三位小数。
::: solution
每10,000人中：200人患病，198人检查阳性；9,800人未患病，其中1%（98人）检查阳性。$\text{PPV} = 198/296 = 0.669$。即使灵敏度和特异度都是99%，在这一患病率下，三分之一的阳性结果是假的。
:::
:::

::: exercise A–a梯度 {level=2 check="20 - 1.25*4.0 - 8.0"}
一位吸室内空气的患者PaO₂ 8.0 kPa，PaCO₂ 4.0 kPa。用$P_AO_2 \approx 20 - 1.25\,P_aCO_2$ kPa计算A–a梯度（kPa），给出精确值。
::: solution
$P_AO_2 = 20 - 1.25 \times 4.0 = 15.0$ kPa。梯度$= 15.0 - 8.0 = 7.0$ kPa，明显增大。低氧血症源于气体交换障碍（如肺炎、肺栓塞或肺水肿），而不是通气不足；PaCO₂低表明他在过度通气。
:::
:::

::: exercise 解读肝功能检查 {level=2}
一位70岁女性无痛性黄疸伴体重下降。胆红素180 µmol/L，ALP 650 U/L，GGT 520 U/L，ALT 90 U/L，白蛋白32 g/L，INR 1.4。解读这一模式并提出下一步。
::: solution
ALP和GGT的升高远超过ALT：这是伴结合胆红素升高的**胆汁淤积型**模式。老年人无痛性黄疸伴体重下降，应警惕胆管的**恶性梗阻**，如胰头癌或胆管癌。INR升高可能反映胆汁淤积时维生素K（脂溶性）吸收不良，而不是肝衰竭；补充维生素K后可能纠正。下一步：紧急超声检查有无胆管扩张，然后做断层影像学检查（CT），并按疑似癌症路径转诊。
:::
:::

::: exercise 混合性酸碱紊乱 {level=3}
一位68岁慢阻肺男性患肺炎。吸空气：pH 7.18，PaCO₂ 8.5 kPa，PaO₂ 6.9 kPa，碳酸氢根18 mmol/L，钠138，氯100，乳酸5.0 mmol/L。解读这份血气。
::: solution
氧合：重度低氧血症（PaO₂ 6.9 kPa）。pH 7.18：酸血症。PaCO₂ 8.5 kPa升高：**呼吸性酸中毒**。碳酸氢根18 mmol/L降低：同时存在**代谢性酸中毒**，因为单纯呼吸性酸中毒会使碳酸氢根升高。阴离子间隙$= 138 - (100 + 18) = 20$ mmol/L，增高，与乳酸酸中毒（乳酸5.0）相符。这是**呼吸性与代谢性混合性酸中毒**，由于两种紊乱互不代偿，导致重度酸血症。在此情境下，它提示高碳酸血症性呼吸衰竭伴脓毒症和组织低灌注：他需要上级医生紧急评估，控制性氧疗至目标范围，评估是否需要无创通气，并进行脓毒症处理。
:::
:::

::: exercise 设计更安全的检查申请 {level=3}
某内科收治病房对每位入院患者都开一套包含18项血液检查的标准组合，其中包括甲状腺功能、维生素D、铁蛋白、PSA和肿瘤标志物。运用本章的观点，论证支持或反对这套组合，并提出替代方案。
::: solution
反对：对大多数患者来说，其中许多检查没有对应的问题。做18项检查时，健康人至少有一项结果超出参考区间的可能性很大（若相互独立，$1 - 0.95^{18} \approx 60\%$），而在急症患者中，许多结果会受疾病本身的干扰（非甲状腺疾病时甲状腺功能检查常常异常；炎症时铁蛋白升高）。在未经选择的患者中，肿瘤标志物和PSA的预测值低，会引发进一步检查、焦虑和意外发现，而且PSA检测应在与患者讨论后进行。这套组合还耗费时间和金钱，产生的结果需要有人审阅和处理。替代方案：对所有入院患者做一小组核心检查（全血细胞计数、尿素和电解质、CRP，以及当地根据人群商定的其他项目，如血糖和肝功能检查），其他检查针对明确的临床问题申请，在开单系统中加入决策支持，并审计其效果。
:::
:::
