运动是生理学的整合实验：开始攀登的第一口气之内，运动、心血管、呼吸、肾、内分泌与体温调节系统按工作量一起重设到新的工作稳态——而每一次重设都服从各分章发展出的同一控制逻辑。追踪一升氧气从环境空气到线粒体，就是对整门课程的审计，而系统的天花板（最大摄氧量）由其最弱一环设定，这就是运动生理同时是心、肺与血管受限临床生理的原因。

本章讲授对运动的整合性心血管、呼吸与热反应；高原、浸水与热的特殊整合应激；及训练的适应。

## 整合反应

::: definition 稳态适应：作为受控扰动的运动 {#def-homeorhesis}
运动稳态不是回到静息而是**新的受调节水平**（Cannon的homeorhesis，“同一通量”）：来自运动皮层与脑干的中枢指令在前馈第一步之前就启动交感浪涌（心率随意图而不在代谢物之后上升——开环预期的证明），而工作肌的**机械感受反射（III组）与代谢感受反射（IV组——乳酸、钾、ATP、前列腺素）**反馈真实需求，动脉压力反射（**向上重设**——运动升压的工作点）守住新的平台。定量签名：**心输出量随功线性上升**至静息的4–5倍（未训练者）与6–8倍（精英，25–35 L/min），经**大规模再分布**分配——静息肌在5 L中拿约1 L，运动肌可拿20+（股四头的分流从15%到85%），因为**胃肠、肾与失组织中的交感缩血管与局部代谢性舒血管（腺苷、K⁺、一氧化氮、切应力、泵）是同时发生的**——整合的典范，只有正在做功之处总体缩血管被覆盖。平均动脉压轻度上升（收缩升、舒张平或降——动力性运动总外周阻力最多降70%，全靠心输出量上升撑住压力：骤停后血管迷走性晕倒，肌泵停了而血管还扩着，是这笔算术反过来）。
:::

::: theorem 氧链及其天花板 {#thm-oxygen-chain}
**Fick原理**组织整个系统：VO₂=心输出量×动静脉氧差。静息（250 mL/min=5 L/min×0.05）；健康70 kg男性最大运动（4.4 L/min=22 L/min×0.20——摄取项：混合静脉氧降到25 mmHg以下，肌肉把血刮干净，动静脉差翻五倍而动脉含量不变）。每一环都可能是限制者，临床阶梯随之而来：**通气与弥散**（只在精英运动员峰值受限——极健康者最大运动的动脉血氧去饱和，及肺病夸张的运动去饱和——[[respiratory/gas-exchange]]）、**心输出量**（正常的限制者——中枢疲劳；心衰的峰值VO₂是其最强预后数字，而无氧阈——乳酸开始积累、通气不成比例上升的功率，**呼吸代偿点**——是其在心肺运动试验上的功能表达），及**外周摄取**（中等负荷下训练的主要红利：毛细血管密度——1918年Krogh的毛细血管募集——线粒体体积与脱氢酶含量、肌红蛋白，及2,3-二磷酸甘油酸、热与pH的氧解离右移）。天花板VO₂max约85%由基因决定，30岁后每十年降约10%（绝经后与停训更快），每失去3.5 mL/kg/min就预测心脏、外科与肿瘤结局的死亡率——它如今作为生命体征进入指南、作为“运动剂量”进入处方的原因。
:::

::: definition 热：代谢的整合代价 {#def-heat}
肌的效率约20–25%；其ATP水解的其余是热——跑一场马拉松以代谢爆发释放约2500 W的热，若无排放在一小时内可把核心从37烧到44 °C。排放靠壳的物理：**辐射、传导与对流**都要求皮肤比环境热（干燥空气约35 °C以上它们失效或倒转），留下**蒸发——每克汗2.4 kJ**——作为唯一通路，并带心血管代价：皮肤血流（交感胆碱能舒血管加局部因素）从约0.5升到**7–8 L/min**、与肌肉争夺心输出量，这就是炎热环境封顶表现、出汗的脱水（1–2 L/小时，最多3）必须部分补足、否则血浆容量与每搏量下降、心率上升以维持同一输出的原因（**心血管漂移**）。湿度决定余量：理论人体极限是**湿球温度约35 °C**（环境的蒸发能力在皮温处归零），即使在其下，超过耐受阈的持续作业产生**劳力性热病**——轻端是痛性痉挛与晕倒，**热射病（核心>40 °C伴意识模糊或昏迷）为急症**，降温（冷水浸泡——耐力赛事的方案，30分钟内施行几乎消灭死亡）先于一切其他检查，因为损伤是时间×温度，其后的横纹肌溶解、DIC与多器官衰竭就是这场烧伤的剂量-反应。
:::

::: example 马拉松的钠问题 {#ex-marathon}
冲线帐篷五小时后一名马拉松者意识模糊、呕吐、抽搐；他“每个站点都喝”，体重涨了3 kg，钠121 mmol/L。
::: solution
这是**运动相关低钠血症**，[[physiology/homeostasis-body-fluids]]的整合生理被刻意开到底：超过汗钠丢失地狂饮**低张液体**（汗约40–60 mmol/L NaCl——每小时2 L的出汗者盐与水一起丢），加长时间运动的**非渗透性血管加压素分泌**（疼痛、恶心、儿茶酚胺，及能在3 L水负荷中幸存的ADH）与糖原相关的水潴留，把血浆稀释到脑的适应力以下——脑水肿伴抽搐，罕见死亡案例来自病房里更多的低张急救液。改变治疗的诊断区分是容量状态与速度：**急性稀释性低钠在脑输出其渗透分子之前就去抽搐**，故治疗是**高张（3%）盐水100–150 mL单次**重复至神经改善——保护慢性病例防渗透性脱髓鞘的纠正上限在最初数小时是更松的约束（但仍被遵守）：让纠正过快变得危险的同一生理，也让治疗过慢变得致命。预防是本章给每个耐力赛医疗帐篷的话：**按渴觉喝、进出称重、超耐力赛补足体重丢失的盐分**——同一逻辑覆盖相反的错误：体位症状的脱水足球员（失盐型）与高钠脱水婴儿：三个人群，一个双间隔方程（[[renal/water-sodium]]的临床面孔）。
:::

::: example 停止出汗的前锋 {#ex-heatstroke}
33 °C的训练日，一名大块头进攻锋线球员在第四节倒下，意识模糊、好斗，皮肤潮红湿润；直肠温度41.4 °C。
::: solution
[[#def-heat]]里的一切都在场：绝对产热高（他的功是摔举质量，代谢热随肌质量缩放）、**体表面积对质量比低**（同样的瓦特摊在更少的皮肤上）、阻断蒸发的装备（球衣与护具困住汗的边界层——起作用的湿球是盔甲制造的那个），加上环境温度缩小梯度的那一天。伴**中枢神经系统衰竭（意识模糊、好斗、抽搐）在核心40 °C以上的倒下就是热射病**——不是单纯晕倒（是[[#def-heat]]的心血管漂移而神志正常）、不是低钠（查钠仍属应该——[[#ex-marathon]]）、不是任何39 °C的劳力性倒下。脑是定义器官，时钟是定义变量：**先降温——冷水浸泡，30分钟内降到39 °C以下**——因为损伤是温度×时间的积分，与烧伤一模一样，实验室随访（CK、钾、肌酐、血小板与INR追踪演进的DIC、尿肌红蛋白）在冰已上身时进行。归场决定、热适应方案（10–14天——血浆扩张与稀汗，漂移的可训练一面）与当日取消阈值是同一批方程写成规则；流行病学不留情：劳力性热射病是年轻运动员的主要死因之一，而近年的几乎每例死亡都涉及**延迟的直肠测温或延迟的降温**——一场按流程可防的病。
:::

::: example 徒步者的头痛 {#ex-ams}
飞抵3800米并徒步上升两天后，一名30岁女性搏动性头痛、恶心、睡眠差、对乙酰氨基酚无缓解；静息血氧饱和度82%。
::: solution
**急性高山病**是适应没有跟上——低压性缺氧（按[[#def-altitude]]的方程PAO₂在50出头）驱动颈动脉体通气、碱中毒，在易感者与快速上升中同批反应升级为脑与肺的并发症：头痛源于脑血管扩张与多半的间质水肿（高海拔脑水肿谱系的轻端，其红旗是共济失调与意识模糊），睡眠差源于周期呼吸——CO₂阈与缺氧驱动之间不稳定的反馈环、睡眠的自动控制把它暴露出来——而82%的血氧饱和是该海拔的预期，诊断暴露而非疾病（Louise湖评分以症状主导）。处理是[[#def-altitude]]的层级：**停止上升**（第一且绝对的规则）、镇痛、乙酰唑胺250 mg每日两次加速肾碳酸氢盐利尿、无法下降或症状升级则地塞米松——脑型或肺型：地塞米松或硝苯地平、氧气并**立即下降**，天气不许行走则便携高压袋。再上升纪律随之：3000米以上按阶梯增加睡眠海拔，个人史是最好的预测——得过的徒步者会再得，除非剖面更慢。本例是一天之内的本章论点：一个变量（吸入PO₂）、整个系统的重设，及按所利用生理速度排序的治疗——通气以分钟、肾代偿以天、促红素以周、下降即刻。
:::
:::

::: quiz
健康成人持续动力性运动（快骑）期间，预期的血压图形是：
- [ ] 收缩压与舒张压都陡升
- [x] 收缩压升、舒张压降或不变、脉压增宽
- [ ] 血管扩张两者皆降
- [ ] 平均动脉压降而心输出量维持频率
::: solution
动力性运动中总外周阻力最多降约70%（工作肌的代谢性舒血管压倒他处的交感缩血管），故**舒张压——阻力项——下降或保持**，而心输出量数倍上升抬高分子压、增宽脉压；平均动脉压只轻度上升（压力反射的重设点）。舒张压升>15 mmHg或收缩压不升都是试验异常（固定的心输出量；过度的后负荷反应），而等长（握力）升压反应——率压乘积随肌内血管受压、舒血管寥寥而上升——是自主实验室利用的对照实验（[[physiology/autonomic-nervous-system]]）。
:::

## 高原、浸水与潜水反射

::: definition 缺氧挑战 {#def-altitude}
5500米处气压约380 mmHg、吸入PO₂约70；肺泡气体方程**PAO₂ = PIO₂ − PACO₂/R**给未适应的海居者约35 mmHg的肺泡PO₂（动脉血氧饱和度80几，运动时降到60几——运动性低氧重于静息，考察队脉搏血氧仪背后的事实），驱动**缺氧通气反应**（颈动脉体——唯一名副其实动脉氧感受，其在睡眠呼吸暂停与肥胖低通气钝化的通气机中失效是[[respiratory/control-breathing-tests]]的整章）：过度通气降低PACO₂（把PAO₂抬高有用的几mmHg），代价是**呼吸性碱中毒**，由肾2–4天纠正（碳酸氢盐排泄——乙酰唑胺捷径，一个酸化并驱动通气的碳酸酐酶抑制剂，[[renal/tubular-function]]在临床服役的药）；适应追加**促红素驱动的红细胞增多**（数天到数周——高原训练者的血红蛋白总量，及“血液兴奋剂”是同一轴的药理学版本之原因：[[blood/haematopoiesis]]）、2,3-BPG右移、毛细血管密度与通气驱动增加，及——对跑赢这一切的快速上升——**急性高山病、高海拔脑水肿与肺水肿**诸综合征（后者是通气不均肺的缺氧缩血管在休息区造成过度灌注水肿——一顶帐篷里的弥散与循环课），治疗只有一个生理口令：**下降**（脑型给氧与地塞米松，肺型给硝苯地平与便携高压袋）。
:::

::: example 潜水者的心慢下来 {#ex-dive}
一名闭气潜水者的脸一入水，心率从70降到42；训练有素的自由潜水者更多，而深度超声下脾脏在缩小。
::: solution
**潜水反射**是哺乳动物的水中方案——三叉传入（V₁，与吞咽和咳嗽弧共享核团机器）受冷刺激驱动**强劲迷走性心动过缓**（最多降50%），随闭气延长加**交感性外周缩血管**把非必需循环（胃肠、肾、失活动肌）分流，心输出量留给心与脑——靠再分配而非储存的氧节省，辅以**血液转移**（胸腔血液与液体充血保护肺对抗深度挤压）与脾收缩（自体输血式红细胞释放使血红细胞压积在一串下潜中升高，赛季后可测）。该反射存在于婴儿（冷面浸水的新生儿呼吸暂停——溺水儿童的“冷水奇迹”及其保护性迷走与脑降温生理，低温溺水在常温下无效的复苏中幸存的原因），可训练（条件化闭气增加心动过缓——精英运动员的一堂经典条件反射实验），也有临床影子：作为迷走探针的**潜水者面浸试验**，易感心脏冷水游泳的三叉-迷走心动过缓性心律失常。与运动一样，潜水是一种整合应激，其体征——频率、分布、血液成分——是照着非凡环境读的普通自主与心血管生理。
:::

::: history
帕多瓦的Santorio的温差计与个人椅（1614）把运动、出汗与“不感蒸发”放上数字——第一部代谢生理；Lavoisier与Laplace的冰量热器（1780）确立动物热即燃烧、功使其增加；而氧链的现代运动生理属于**Lindhard**（哥本哈根，自行车的稳态功生理）、**A. V. Hill**（1922年诺贝尔，氧债，[[#thm-oxygen-chain]]指数动力学）与**August Krogh**（1920年诺贝尔，毛细血管募集，工作肌的弥散-灌注分析）。高原章以Paul Bert的舱与**Mossò**1890年代的意大利阿尔卑斯生理开篇（墨点体积描记时代的第一批血氧仪），由Haldane学派1905年Monte Rosa远征定量——Haldane与Guye自己的高原肺泡气与饱和度测量，这就是氧解离曲线与高山病在同一批夏季数据上被解决的原因；二十世纪的综合——Keys的明尼苏达饥饿与运动研究（1944–45）、Saltin的肌活检时代（纤维募集与训练适应）、Holmgren–Åstrand的临床功生理传统——供给功率计、心肺运动试验与“运动是药”处方，下一个世纪的指南正在书写。
:::

## 通向何处

心输出量的机器在[[cardiovascular/cardiac-cycle]]与[[cardiovascular/circulation-blood-pressure]]；气体交换在[[respiratory/gas-exchange]]及其控制在[[respiratory/control-breathing-tests]]；液体与钠在[[renal/water-sodium]]与[[physiology/homeostasis-body-fluids]]；肌能量学在[[physiology/muscle]]；促红素轴在[[blood/haematopoiesis]]；临床运动试验在[[cardiovascular/coronary-artery-disease]]。

::: summary
- 运动是前馈加反馈调节的新稳态：中枢指令加肌代谢感受反射、向上重设的压力反射，以及同时发生的交感缩血管（内脏）与局部舒血管（做功）。
- Fick关系定位限制：中枢性（心输出量——正常的天花板也是心衰的临床天花板）或外周性（摄取——可训练的间隔），通气与弥散只在精英或病变极端受限。
- 热是代谢的税：35 °C以上蒸发是最后通路，耗升级汗水与升级皮肤灌注，在湿球极限处失效——热射病是一场时间-温度烧伤，唯一特异治疗是快速降温。
- 高原是一个变量（吸入PO₂）考整条氧链：以肾碳酸氢盐排泄与促红素适应，以治疗下降。
- 潜水反射显示同一批自主与心血管组件为另一应激重新组合——整合生理就是一套零件、重新排列。
:::

## 练习

::: exercise 算出汗账 {level=1}
一名铸工连续两小时产生400 W净代谢热；对热空气辐射与对流可忽略，一切排放靠蒸发。他必须喝多少水才保持等渗？为什么风扇在40 °C以上有用，而把同一房间空调到35 °C几乎无用？
::: solution
待除热：400 J/s×7200 s=2.88 MJ；按每克汗蒸发2.4 kJ即**约1.2 L/小时、一个班次2.4 L**（现实中更多，因为空气潮湿时汗可能一点都没蒸发——滴落率不等于损失率）。风扇有用因为**蒸发取决于水汽压梯度（湿球）而非干球**：流动空气剥掉饱和边界层，让蒸发在45 °C也能进行；而把空气冷到35 °C只恢复35 °C气温归零的干梯度（辐射、对流）——管账的是湿球不是温度计，这就是潮湿洗衣房33 °C就危险、干热沙漠48 °C带水却能存活的原因。同一批数字决定耐力赛补给站的规模与热适应方案里上升的出汗率（更多输出，更咸或——训练后——更淡，都在[[#def-heat]]的限度内可训练）。
:::

::: exercise 走一遍氧 {level=1}
列出氧链从环境空气到线粒体消耗的各环节，并各命名一个限制它的疾病。
::: solution
**通气**（COPD、肥胖低通气、阿片）→**肺泡-毛细血管弥散**（纤维化、肺气肿的表面丢失——运动去饱和）→**灌注与匹配**（肺栓塞、任何V/Q失衡）→**血红蛋白携带**（贫血、一氧化碳、高铁血红蛋白——含量下降而链的后环完好，故它们在高负荷而非静息时耗竭）→**心输出量**（心衰、瓣膜病、β阻滞剂的变时不整——运动试验达不到预测心率）→**肌灌注**（外周动脉病——跛行在心肺之前设定天花板）→**摄取与线粒体**（去适应、老化、脓症的细胞病变性缺氧——慢性病的“外周”限制者，也是最先练起来的）。这条链就是呼吸困难按序的鉴别诊断，心肺运动试验一环一环地读它（[[cardiovascular/coronary-artery-disease]]的功能实验室）。
:::

::: exercise 做Fick算术 {level=1}
一名患者峰值运动：心输出量14 L/min，动脉O₂含量19 mL/dL，混合静脉9 mL/dL。计算VO₂，与静息250 mL/min对照；同一输出下静脉氧15 mL/dL提示什么异常？
::: solution
VO₂=14 L/min×(19−9)mL/dL=14,000 mL/min×0.10=**1400 mL/min**（静息5.6倍——普通日常近乎最大）。同一输出下混合静脉氧15意味着要么摄取失败（动静脉分流、线粒体毒物——氰化物及脓毒症与一氧化碳图景），要么流量超过需求（早期高输出脓毒症、甲状腺毒症、贫血的代偿）——这就是**热稀释与Fick心输出量连同静脉氧一起**能把衰竭的低输出循环（静脉氧低、差宽）与分布性高代谢者（静脉氧高、差窄）分开的原理。一个方程，两个临床世界，与[[#thm-oxygen-chain]]同一笔算术。
:::

::: exercise 心漂移及其病因 {level=2}
暖房间里恒定自行车功，心率40分钟升25次而每搏量下降。解释，并给出此漂移预测的耐力运动三类液体-钠病变。
::: solution
漂移是**代偿性心动过速**：皮肤舒血管加汗丢失把血搬到皮肤并搬出循环，静脉回流与舒张末容积下降（[[cardiovascular/cardiac-cycle]]的Frank–Starling项），每搏量掉，频率扛住压力反射要求的那个输出——脱水、高环境温度、低体能（更小的血浆容量、更低的搏出储备）与体位负荷各自加陡斜率。耐力运动三个可预测病变：**(1)劳力性热病**——漂移跑赢降温、核心失控上升；**(2)体位性低血压与终点线的“晕倒室”**（肌泵停止后血流进扩张床——即[[physiology/autonomic-nervous-system]]的体位算术加个热）；**(3)补水决策紊乱**——喝少了（漂移本身、高钠脱水）与喝多了（[[#ex-marathon]]的低钠），这就是补液指导用体重变化与钠意识而非单说容量的原因（[[renal/water-sodium]]）。
:::
:::

::: exercise 高原算术 {level=2}
海平面用PIO₂ 150与PACO₂ 40（R=0.8）计算PAO₂；在5500米PIO₂ 70、适应后PACO₂ 30再算一次；解释为什么乙酰唑胺有助上升，而任何原因（阿片、睡眠）的通气不足使其危险。
::: solution
海平面：PAO₂=150−40/0.8=**100 mmHg**。高原：PAO₂=70−30/0.8≈**32 mmHg**——5500米的低氧血症先是算术后才是诗意，而肺泡-动脉梯度保持接近正常（健康肺不是病灶）。通气不足在高原以同一方程两倍残酷地进入：PIO₂ 70时PACO₂ 50（一个镇静或呼吸暂停的夜晚）把PAO₂降到70−62=**8 mmHg**——与意识不相容的数字，阿片、镇静药与中枢通气不足在高原及刚抵达者中危险的原因。乙酰唑胺之助是方程的杠杆：碳酸酐酶抑制造成碳酸氢盐利尿（代谢性酸中毒），**以pH为代价抬高通气、降低PACO₂**，先适应化该系统（与[[renal/tubular-function]]的小管药理同一逻辑）——而真正的治疗仍是渐次上升，以及下降、氧与[[#def-altitude]]诸药。
:::

::: exercise 移植后运动员 {level=2}
心脏移植两周后患者开始行走方案。与对照比较，预测其对固定负荷的心率与心输出量反应，并解释每个差别的生理。
::: solution
移植心**去神经**：无迷走刹车（静息心率90–110）也**无直接交感变时变力连接**——运动心率只随**循环肾上腺素**上升，而其形成需数分钟，故心率**爬得慢、峰值晚、降得慢**——频率-功环滞后。故固定负荷下患者在稳态有高于预期的心率（同一输出处于频率驱动而非搏出驱动状态）、更低的峰值输出（只有搏出储备——Frank–Starling与长度依赖增强，无收缩力帮助——本人群[[#thm-oxygen-chain]]中枢限制的峰值VO₂钝化），频率是**糟糕的处方变量**（按自觉疲劳或校正靶心率训练）。同一解剖的额外褶皱：移植物血管病时**无心绞痛**（去神经传入——糖尿病无症状缺血的对应物）、对直接作用药物反应夸张（去神经超敏——阿托品无效、地高辛与拟交感药更猛），冷水面浸与Valsalva试验失去副交感肢体：在一具重新接线的器官上读本章的自主生理。
:::

::: exercise 无氧阈之争 {level=2}
定义乳酸阈并给出递增运动中乳酸积累的现代表述（作为穿梭体与信号的乳酸），然后解释为什么该阈仍标志通气上升。
::: solution
经典地，**乳酸阈**（约2 mmol/L，慢性乳酸抬升的起点）与**血乳酸积累起点**（4 mmol/L）在训练者分别落在VO₂max的50–60%与70–80%；旧读法是厌氧糖酵解外溢。现代读法（Brooks的**乳酸穿梭**教义）：乳酸持续产生并持续清除，其上升标记**乳酸转运体与氧化机器的设定点抬高**——运动募集糖解纤维与肾上腺素、抬高生产；阈是生产超过心、肌、肝摄取的氧化能力之处。逐口呼吸试验识别它的**通气上升**是同一事实的化学镜像：解离乳酸的氢离子缓冲到碳酸氢盐上、释放**超出代谢需要的额外CO₂**（[[#thm-oxygen-chain]]呼吸代偿点排掉的非代谢CO₂），过度通气随后由代谢性酸中毒的颈动脉体与延髓化学感受驱动。临床收获：阈（而非VO₂max）预测心衰的功能能力与死亡率，也是训练移动最多的变量；乳酸曲线成了功率计的血气轨迹——本章与上一章在功率自行车上相会。
:::

::: exercise 设计高温政策 {level=3}
你要为30 °C、湿度70%的群众性赛事提供建议。用湿球概念、热预算方程与漂移生理，设计：(a)赛事温度上限，(b)降温站间距，(c)倒下跑者的医疗流程，(d)高危人群。
::: solution
**(a)从预算定上限：**跑动配速下代谢热约1000 W/m²；干球一旦超过皮温（约35 °C）辐射、对流与传导全部失效，湿球是硬极限（理论约35 °C，长跑的操作性**WBGT约28–30 °C以上取消**——管理机构的卡片正是用综合热、湿、辐射与风项的湿球黑球温度；2019–21世锦赛马拉松的规则改写是这条方程，不是气象情绪）。**(b)每2–3公里一个站**按部分补足定规模（胃排空上限约0.8–1 L/小时，故站点给肠道所能，加为出汗者备的盐）、可及冰的降温（冷水浸泡与冰沙——相变物理）、给不跑者的遮阴与喷雾。**(c)按生理排序的倒下流程：**先测直肠温度**再做任何事**（多汗、风冷运动员的额温枪误差是经典野外科目错误）；>40 °C伴意识模糊——**先降温后转运**，冷水浸泡30分钟内到39 °C以下，降温已启动后才补液（“晕倒”是漂移；抽搐在钠说否则之前是低钠——[[#ex-marathon]]）。**(d)从热方程读出的风险清单**：体表面积-质量比问题（端点各自的重掷者与脱水耐力者）、既往热病（最强的单一预测因子——生理在其身后留下重置）、损害出汗（抗胆碱药）或心输出量（β阻滞剂）的药物、兴奋剂与酒精、未适应者（10–14天的适应扩张血浆容量、降低汗钠、移动漂移曲线——与[[#def-heat]]心血管代价同一可训练生理）。每一条款都是本章；取消决定是流行病学的成本-收益，而流程是生理学的。
:::
