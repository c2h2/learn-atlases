肌是身体的发动机：一套把ATP的化学能转为力与缩短的分子装置，其中一种组织由驱动它的神经控制，另一种由它自己的起搏器与其上铺陈的自主张力控制，第三种由激素、牵张与局部化学控制。三种类型——骨骼肌、心肌、平滑肌——共享一种收缩机制（肌动蛋白-肌球蛋白滑行丝），围绕它的一切却各不相同：升高钙的扳机、引导力的建筑，以及物理为之服务的目的。

本章讲授肌节与滑行丝机制、三种组织各自的兴奋-收缩耦联、力与缩短的力学，以及该机制所解释的临床疾病。

## 肌节

::: definition 收缩装置 {#def-sarcomere}
**肌节**——Z盘到Z盘——是横纹肌重复的发动机。**粗丝**约300个肌球蛋白II分子，每个有卷曲螺旋尾与两个携带ATP酶与肌动蛋白结合位的头；头在中央裸区与**H带**伸出。**细丝**是**肌动蛋白**的双螺旋（G-actin→F-actin，原肌球蛋白在沟内，**肌钙蛋白复合体TnC–TnI–TnT**：钙感受器、抑制者、原肌球蛋白锚），在Z盘由**α-辅肌动蛋白**固定并向内走行；**nebulin**设定细丝长度，**titin**——从Z到M的巨型弹簧——居中粗丝、提供被动刚度并展开以防过度牵张。收缩是**横桥循环**：肌球蛋白头（结合ADP·Pᵢ、由上一次ATP水解充能）结合肌动蛋白、释出磷酸（动力行程）、释ADP、保持（**僵直**）直到新的ATP结合并把头摘下；半肌节约5个头异步循环，最大缩短时循环率下降，约40–60%的化学能变为功与热。**A带**（粗丝长度）恒定；细丝滑行时**I带与H带缩短**——Huxley 1954年的证明一句话说完，而丝本身的长度不变。
:::

::: theorem 长度、速度与负荷：肌的力学 {#thm-mechanics}
**长度-张力**：活性力在静息肌节长度（约2.2 µm，最佳重叠）最大，随重叠减少（拉伸）或细丝相撞（缩短）而下降——心与肢的工作范围之基础，也是心功能曲线生理范围内的降支。**张力-速度**（Hill双曲线）：缩短速度随负荷呈双曲线下降，零负荷时V_max、**P₀**（等长最大值）时速度为零；其乘积——**功率**——在约P₀的三分之一处达峰，这就是投掷与跳跃轻负荷肢体的原因，也是收缩速度以轻而快的训练获得的原因。**叠加与强直**：单收缩（骨骼肌约10–100 ms）若下一次刺激在松弛前到达就与自己叠加——**波（时间）叠加**然后**强直**，融合而为单收缩的3–5倍——因为第二次钙瞬变落在仍饱和的肌钙蛋白与横桥群体上；**阶梯（treppe/Bowditch）**是另一种钙可用性效应，属于[[cardiovascular/cardiac-cycle]]里的心。**募集**：运动单位按**大小原则**（Henneman）加入——小的、慢的、抗疲劳的单位最先、大的快糖解的最后——因为小轴突输入电阻高、最先达阈；分级肌力主要是募集加频率编码，而非每纤维更多的钙。
:::

## 兴奋-收缩耦联，三种方式

::: definition 骨骼肌：机械偶联 {#def-sect}
运动终板电位扫过表面膜与**横（T）管**（哺乳动物在A-I交界处），掠过**二氢吡啶受体（DHPR，Cav1.1）**——其电压感受器结构域与肌浆网的**ryanodine受体RyR1** **机械偶联**——去极化打开释放通道而无须细胞外钙内流（骨骼肌收缩能在无钙培养液里存活一阵的原因，也是恶性高热是RyR1疾病的原因——见下文例题）。释放的钙饱和肌钙蛋白C（TnC）、TnI对肌动蛋白-肌球蛋白的抑制被解除、收缩运行；松弛需要**SERCA1/2a以ATP依赖方式逆陡峭梯度泵钙回库**、库内钙缓冲**集钙蛋白**，以及清除漏出物的**Na⁺/Ca²⁺交换体与质膜Ca-ATP酶**。快（IIx/IIb型）纤维线粒体少、SERCA动力学匹配快速松弛；慢（I型）纤维氧化性、抗疲劳、密布毛细血管与肌红蛋白——而运动单位由其运动神经元定义，故其纤维类型跟随放电模式与训练，耐力训练的纤维类型转换是生理学最可重复的可塑性。
:::

::: definition 心肌：钙诱导的钙释放 {#def-cicr}
心肌动作电位平台期的Ca²⁺（L型DHPR/Cav1.2）进入T管（更宽、Z线水平、每肌节一个），**由钙本身触发RyR2开放**——**钙诱导的钙释放**，亮点求和成结合肌钙蛋白C的瞬变。收缩强度因此由**触发的钙的规模**分级——正性肌力的机制：β肾上腺素能对L型通道（更多触发）、**受磷蛋白**（解除SERCA抑制、再摄取更快、库更大）与RyR2（更易漏，但有定时）的磷酸化增加力与松弛；**地高辛**作用下游一步，抑制Na⁺/K⁺-ATP酶使升高的胞内Na⁺减慢**NCX**外排、每搏留下更多钙——一台被读成钙药的泵抑制剂（见[[cardiovascular/heart-failure]]）。心不能被强直化，因为长动作电位的不应期跨越整个单收缩——保证它充盈的契约——而**静息增强与力-频率关系**（完整心的正阶梯、衰竭时反转）是同一套钙处理在不同频率的读数。
:::

::: definition 平滑肌：钙调蛋白-肌球蛋白轻链之路 {#def-smooth}
平滑肌**无肌钙蛋白、无肌节**：肌动蛋白从**致密体**（功能性Z盘）与致密斑走向肌球蛋白，构成可以重排的格架；收缩始于钙-**钙调蛋白**激活**肌球蛋白轻链激酶（MLCK）**、后者磷酸化肌球蛋白调节轻链、允许横桥循环。因为自由钙是扳机而没有为符合而设的脚手架，张力由**MLCK与肌球蛋白轻链磷酸酶之平衡**设定，并在远处被调制：激酶（Rho激酶）抑制磷酸酶，故同样的钙能产生更多的力（**钙致敏**——血管痉挛与哮喘文献之靶），而**锁住状态**（去磷酸化的横桥缓慢循环）以能量的一小部分维持张力，是小动脉全天几乎不耗ATP却撑住压力的秘密。松弛跟随钙的移除与NO–cGMP–使MLCK脱敏通路（[[cardiovascular/vascular-disease]]的硝酸酯与西地那非轴）。平滑肌是**肌源性**的：牵张增加张力（Bayliss反应，自身调节之基础），许多单位经缝隙连接作为合胞体收缩，肠道有起搏慢波（Cajal间质细胞——胃肠动力诸章）、膀胱、子宫（缩宫素的终点）与大血管有时相性张力。
:::

::: example 恶性的高热 {#ex-mh}
氟烷麻醉中一名患儿呼气末CO₂上升、咬肌抽动、体温十分钟升一度、肌肉硬如板、钾与乳酸外涌；开始输注丹曲林。
::: solution
**恶性高热**是骨骼肌RyR1通道在触发剂（挥发性麻醉药或司可林）下于易感突变者长开：肌浆网把钙持续倾入胞质、横桥无休止地循环、SERCA拼命泵回钙——两台引擎一起消耗ATP并产热快过身体散发——僵硬、呼吸性与混合性酸中毒、横纹肌溶解与致死的高钾。**丹曲林**是特异性解毒剂，恰因其靶就是缺陷通道：它结合RyR1、降低开放概率、在源头切断释放（剂量重复至见效，配合主动降温、处理钾与酸中毒，肌损需要时透析）。属于同一清单的鉴别——**抗精神病药恶性综合征**（抗精神病药多巴胺阻断、数日起病、强直伴高热、溴隐亭/丹曲林治疗，是中枢调定点与多巴胺问题而非通道病）与**5-羟色胺综合征**（阵挛、反射亢进、躁动、5-羟色胺能药物）——共享高热而不共享机制；遗传学以本章反复出现的主题收尾：易感等位基因是RyR1与CACNA1S变异，而恶性高热危机是一个无人称其为肌病的孩子**收缩蛋白病**的起病事件。同一批通道，同一套耦联，而家族史是唯一的预警。
:::

::: example 不肯拉长的腓肠肌 {#ex-spindle}
卒中六周后偏瘫患者的腓肠肌发紧：踝背屈越猛抗力越大、抗力在某个卡住点后让位；跖反射伸展、膝反射亢进。
::: solution
这抗力是**痉挛**——皮质脊髓与网状脊髓张力束失去之下**肌梭牵张反射**的高兴奋。环的解剖：来自肌梭核袋纤维的Ia传入随牵张与拉长速度放电、单突触同侧同名肌的α运动神经元（即叩膝反射），并经一个抑制性中间神经元及至其拮抗肌（交互抑制）；**γ运动神经元**由下行系统设定肌梭敏感度，上运动神经元损伤后其脱离高位控制的释放把环偏向高增益——故速度依赖的卡住感、亢进的叩膝、环振荡时的阵挛。对照帕金森病的**强直**——速度无关、全程均匀、基底节调定点问题而牵张反射近乎正常——及**挛缩**：抗力是组织弹性、任何速度都在且无叩膝。治疗在环的突触处打击它：巴氯芬（GABA_B、突触前抑制传入递质释放、突触后超极化）、地西泮与替扎尼定（GABA_A与α₂）、向过度活动的肌内注射肉毒毒素（[[physiology/synapses]]的释放机器转而治疗）、牵伸与负重方案、重肢体的鞘内泵——每一条都是本章与上一章的一句话。
:::

一名哮喘患者的气道对组胺的收缩只需对照者四分之一剂量，而沙丁胺醇几分钟内逆转。
::: solution
两套平滑肌教义运行这一图景。**气道高反应性**：气道张力由[[#def-smooth]]的磷酸化平衡设定——慢性炎症经三条路抬高它：感觉神经元与迷走驱动（冷空气与刺激物利用的反射弧）、受损上皮失去NO与前列环素的刹车、以及Rho激酶介导的**钙致敏**使同样的钙现在产生更多的力；结果是剂量反应曲线左移（乙酰甲胆碱激发试验的PC₂₀正是量出来的那条曲线）。**逆转**：β₂激动剂升高cAMP→PKA磷酸化MLCK（同样钙下活性更低）、开放K⁺通道（超极化关闭Cav）、驱动钙的泵-漏处理——从磷酸化一侧松弛，而不怎么降低钙；抗胆碱药切断IP₃一臂，而糖皮质激素以天为单位重建被炎症侵蚀的受体与一氧化氮机器（长期过度治疗者，β受体下调就是本章受体生物学预言的药理耐受）。支气管就是本章的一般教训化为一根管：**平滑肌是一个信号整合器，而气道疾病是它的输入集。**

## 从纤维到功能

整肌张力是**生理横截面积**乘比张力（约20–30 N/cm²），因为平行纤维与羽状肌用缩短距离（纤维长度）换取并联丝的数量（羽状角允许塞进更多纤维，代价是力传递的余弦损失）。行程由纤维长度设定，速度由肌球蛋白异构体（快IIx肌球蛋白的循环约为I型式的八倍）与串联弹性成分设定（腱刚度决定弹性势能的储存与返还——跑步的牵张-缩短环、袋鼠的经济性，以及腓肠肌像弹簧般工作而比目鱼肌是发动机的原因）。运动单位（一个运动神经元及其纤维）是随意控制的单位；其大小——从外直肌的十几根纤维到腓肠肌的上千根——是精确度层级，而其按大小的有序募集（[[#thm-mechanics]]规则）就是精细任务用小单位、肌电图募集模式是窥神经也是窥肌之窗的原因。

::: example 起不来的孩子 {#ex-duchenne}
一名五岁男孩从地板上站起时用手沿着自己的腿往上爬；腓肠肌粗大坚硬；CK 12,000 U/L。
::: solution
在基因说否则之前这就是**杜氏肌营养不良**——**Gowers动作**（髋膝伸肌太弱、无法抗重力起立，只能把躯干沿大腿杠杆般撑起）、被脂肪与结缔组织替代的腓肠肌假性肥大、以及报告膜漏的CK。机制是结构性的：**抗肌萎缩蛋白**——把细胞骨架经**抗肌萎缩蛋白-糖蛋白复合体**连接到体外营养不良聚糖-层粘连蛋白键的肌动蛋白结合杆——缺如（X连锁、破坏读框而截短蛋白的突变）；没有这根减震垫，每一次收缩都撕破肌膜、纤维坏死、替代性纤维化产生挛缩与**心肌病**（心与膈的抗肌萎缩蛋白异构体按同一时钟失效）——在三四十岁杀人，如今有了激素、ACE抑制与无创通气则更晚。Becker病是保留读框、蛋白部分存在的突变——同一基因、较轻的剂量。本章的生理学就是考卷答案：是膜脆弱，而非钙处理或收缩蛋白本身；诊断路线为CK→基因检测（先做缺失/重复分析，因多数突变为缺失）→少见的显示染色缺如的肌活检。糖皮质激素减缓衰退；外显子跳跃与通读药物及基因治疗针对具体突变类别——一个完全围绕这里描述的力学组织的药物家族。
:::
:::

::: history
滑行丝故事是生理学最干净的之一：Huxley与Hanson对收缩与舒张肌原纤维的电镜（1954）与Huxley的解释——丝滑行而丝不缩短——用几张图了断了一个世纪的手风琴式猜想，干涉带证据（A带长度不变）是一锤定音。横桥化学来自Szent-Györgyi的肌动蛋白与肌球蛋白及ATP酶环节（1937年诺贝尔，他的维生素C岁月已先得）、Lohmann与Meyerhof的肌生物能学（1922），以及Hill的张力-速度双曲线与缩短的热力学——凭肌热实验赢得1922年奖项。钙触发随Heilbrunner的争论而来，然后是结构时代：肌钙蛋白复合体（Ebashi）、由骨骼肌无钙收缩证明的DHPR-RyR机械偶联（Ríos、Brum与Melzer诸组，1980年代）对阵心肌钙诱导钙释放的亮点（Cheng、Stern、Lakatta与1993年的钙成像革命）。Henneman大小原则（1965）与运动单位生理从同一门电学生长出来——它也让肌电图安了临床的家。
:::

## 通向何处

心脏收缩在[[cardiovascular/cardiac-cycle]]；呼吸泵肌在[[respiratory/mechanics-breathing]]；平滑肌的气道药理在[[respiratory/asthma-copd]]与[[pharmacology/autonomic-drugs]]；肌病、肌强直与通道病在[[nervous-system/neuromuscular]]；胃肠动力及其疾病在[[gastrointestinal/bowel-disease]]。

::: summary
- 一台发动机——肌动蛋白-肌球蛋白横桥——三具身体：肌钙蛋白控制的横纹肌（骨骼与心）与钙调蛋白-MLC控制的平滑肌，各有各的钙来源与目的。
- 骨骼耦联是机械的（DHPR到RyR1），心肌是钙诱导钙释放（分级、可调、不可强直），平滑肌是磷酸化状态与锁住（经济、肌源性、药敏）。
- 张力-速度与长度-张力关系统治从一次投掷的功率峰到心室工作范围的一切；按大小原则募集是神经系统的音量旋钮。
- ATP摘下的头与SERCA松弛的纤维：同一分子驱动循环的两端，其缺席解释了尸僵、痉挛与疲劳的外周一侧。
- 临床清单——恶性高热、肌强直、肌营养不良、肌无力性接头——一一对应到机器的零件：通道、感受器、脚手架或突触。

## 练习

::: exercise 带与线 {level=1}
向心收缩期间A带、I带、H带与肌节长度各发生什么——真正缩短的分子距离是哪个？
::: solution
**A带不变**（粗丝长度）；**I带与H带缩短**；肌节长度从约2.2降到1.5 µm。细丝向内滑行——没有一个肌动或肌球蛋白分子缩短（1954年实验的全部要点）；收缩的是相邻Z盘之间的距离，而肌球蛋白头的工作行程（每次几纳米、每秒数十次）通过循环的无数次重复累积成它。
:::
:::

::: exercise 按大小募集 {level=1}
解释为什么经颅磁刺激皮质脊髓束优先激活大直径轴突，而随意收缩先募集小运动单位——每个观察对募集机制说了什么。
::: solution
TMS经感生的胞外电流使轴突去极化：**阈随直径下降**（内阻更低、捕获的膜更多），故最大最快的轴突最先放电——与天然相反。随意驱动经突触到达胞体与树突：**小运动神经元输入电阻更高**，同样的突触电流使其去极化更多、先达阈（大小原则）。这个对照就是生理性募集顺序是**突触整合而非轴突兴奋性**之属性的证明——也是肌电图募集模式（小单位先、放电率上升、然后大单位）成为诊断之窗的原因：神经病中幸存单位快而稀疏地放电，再支配的单位因出芽合并了池而变大。
:::
:::

::: exercise 肌力盘点 {level=2}
就急性正性肌力为下列排序并给出各利用的分子步骤：氯化钙、多巴酚丁胺、地高辛、米力农，及正常心率60升到110。
::: solution
全部作用于触发的钙，在四个步骤。**钙**直接抬高L型内流的梯度（低钙与高钾里危险的权宜）。**多巴酚丁胺**（β₁）——cAMP/PKA：L型通道磷酸化（更多触发钙）、受磷蛋白磷酸化（SERCA摄取更快、库更大、松弛更快——区别于纯钙的**松弛**红利）。**米力农**（PDE3抑制）——同一cAMP池不被销毁：肌力加血管扩张（“强心扩血管”），低输出衰竭心有用及其自身的低血压。**地高辛**——泵抑制→胞内Na⁺升→NCX正向工作减少→每搏更多钙；起效慢、迷走与毒性谱（中毒水平的各种心律失常）使它成为慢性而非急性药。**心率（60→110，正常心）**——**力-频率关系**：每分钟更多瞬变与更多钙装载，生理性阶梯，其失效（负阶梯）是心肌衰竭的早期迹象——清单里唯一属于机器属性而非药物的一项。
:::
:::

::: exercise 硬的肌，软的肌 {level=2}
先天性肌强直（ClC-1氯通道缺失）给出握力后“不肯松开”的肌；甲状腺功能减退在通道正常时给出同样的松弛延迟。解释前者并说出后者教什么。
::: solution
**ClC-1**通道携带骨骼肌静息电导的大部；其作用是把窄T管内K⁺积累本会在活动中与活动后造成的去极化分流掉——失去它使后放电反复引爆纤维（临床握肌强直、肌电图“俯冲轰炸机”声与反复运动的热身现象），而肌力与收缩本身近乎正常——一种**膜的而非收缩机器的**高兴奋性疾病。甲减性肌强直（反射或握力后松弛缓慢的假性肌强直）源于**SERCA介导钙再摄取的减慢**（甲状腺激素调节的异构体表达与ATP周转下降），故松弛时间常数变长而膜正常：教训是“松弛延迟”定位到两个截然不同的地方——表面膜或钙泵——肌电图瞬间分开它们（电后放电活动对安静的缓慢拉长），一个床旁鉴别值得本章诊断学的全部。
:::
:::

::: exercise 锁住与张力 {level=2}
去甲肾上腺素把一根小动脉收缩到直径的30%并保持数小时而ATP消耗几乎不变。用平滑肌磷酸化逻辑解释，并预测损伤内皮的改变。
::: solution
最初的收缩是受体（α₁）→IP₃/DAG→钙升高→MLCK磷酸化调节轻链→循环。维持靠**锁住状态**：横桥在仍连接时去磷酸化、极慢地循环（张力的经济性），并有**Rho激酶对肌球蛋白磷酸酶的抑制（钙致敏）**相助，故每单位钙的力保持高、每单位力的ATP降到骨骼循环的一小份——小动脉的全天坚守，也是“张力”不简单等于“收缩的钙”的原因。内皮损伤移走**NO/cGMP刹车**（连同前列环素与超极化因子），同一肌细胞现在以更高的致敏张力运行、更易进入锁住状态——血管痉挛与重构血管的机制之一（及其生长因子文献的长期版本），也是“剥去内皮的动脉收缩于健康动脉会稀释之物”这一临床事实的生理地基。
:::
:::

::: exercise 纤维类型与疾病 {level=2}
I型纤维主导适于姿势，IIx型适于投掷。哪些病理选择性地打击各自，凭什么机制？
::: solution
**I型（慢、氧化）**被持续募集，故持续供能障碍与突触后及膜内务管理的病在姿势与眼球肌肉宣告自己：线粒体肌病（“破碎红纤维”的氧化纤维在慢性进行性外眼肌麻痹的上睑下垂与眼外肌麻痹中失效）与肌无力易疲劳的眼与颈伸肌无力（用过头的终板先失败）。**II型（快糖解）**是废用、类固醇过量与老化时萎缩的（肌少症的速度与跌倒风险——IIx肌球蛋白的流失），也是爆发运动时抽筋的；糖酵解的代谢性肌病（McArdle病——肌磷酸化酶缺失——第二次呼吸现象与运动性肌红蛋白尿）打击它们，因其以糖原为生。两者的诊断习惯相同：无力的分布就是纤维工作的生理学，活检的ATP酶染色说出哪份工作失败了。
:::

::: exercise 设计疲劳实验 {level=2}
一名患者异常疲劳。用三种电诊断手法分开中枢疲劳、神经肌接头疲劳与外周（肌）疲劳，并说出各自的定位。
::: solution
(1)**颈或股磁刺激的中枢驱动评估（叠加抽搐/抽搐插值技术）**：最大随意收缩期间，叠加的运动神经或皮质刺激若产生额外力，说明中枢驱动不完整——**中枢疲劳**（疼痛、动机、中枢神经病变、去适应）。(2)**重复神经刺激与运动后增量试验**：3 Hz下>10%且休息后恢复的递减，或10秒最大随意收缩后的运动后**增量**（易化揭穿低概率的突触前接头），定位到**接头**（肌无力与Lambert-Eaton图形）。(3)**收缩前后绕神经刺激、比较肌肉抽搐与复合动作电位**，或更简单的静息对疲劳后刺激：若肌肉自身的抽搐（收缩后在静息时刺激）降低而神经与接头完好，失败在**外周——纤维内部**（代谢性：磷酸积累、肌浆网释放失败、此处描述的ATP与钙泵，或底物缺乏）。三个定位、三种治疗与诊断，而本章的机器——驱动、接头、耦联——恰是检查的顺序。
:::
:::

::: exercise 不肯松弛的心 {level=3}
一名舒张性心衰伴静息心动过速的患者开始减慢心率的策略后好转。用兴奋-收缩与松弛生理，解释为什么松弛是主动、ATP依赖的过程，为什么心动过速与缺血都使其恶化，为什么好转跟随心率。
::: solution
松弛是**钙的移除**——SERCA2a逆10⁴倍梯度泵（每水解一个ATP转运两个Ca²⁺）为主，NCX完成出口——而该过程**耗ATP、依赖温度与磷酸化**（受磷蛋白的磷酸化状态、β肾上腺素能与松弛）。舒张衰竭在力学上是**不完全或减慢的钙移除加上titin刚度的改变**，故心室松弛慢、以高压充盈。**心动过速**两面夹击：同样慢的泵在舒张期时间更少，（高频率时）每搏钙外排更少、繁忙的泵与交换体钠负荷更多——衰心负力-频率关系之源。**缺血**抽走收缩与不成比例地松弛都需要的ATP（松弛先失败——缺血或肥厚心最早的舒张异常），酸中毒又加重肌丝钙敏感、减慢横桥解离。**减慢心率**把舒张期拉长得超过收缩期、恢复充盈窗、减少钠负荷积累并让SERCA赶上，于是在任何收缩力改变之前改善充盈压与症状——这就是率控制是衰竭心室一种真实疗法的原因，也是松弛不是收缩之缺席、而是其自身那条代谢昂贵程序的床旁最清晰的演示。
:::
