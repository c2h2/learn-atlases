每一次思想、每一跳脉搏、每一丝抽动都始于化学制造的电。细胞花费ATP建造离子梯度——钠被挡在门外、钾被留在门内、钙被逐出胞质——然后花费梯度，由电压、配体或牵张设闸，以工程电缆望尘莫及的速度与精确跨膜移动电荷。本章是这种货币的物理：平衡电位、静息膜、动作电位及其不应机制、信号沿纤维的传导——并以临床清单（钾的麻痹、局麻药的阻滞、脱髓鞘神经的失效）作为演算例题。

## 梯度与平衡电位

::: definition 电化学平衡与Nernst电位 {#def-nernst}
跨膜的离子沿浓度梯度扩散，因其带电，便在一侧积累直到它制造的电位梯度恰好平衡扩散：**在平衡电位上净通量为零** $E_\text{ion} = \dfrac{RT}{zF}\ln\dfrac{[\text{ion}]_\text{out}}{[\text{ion}]_\text{in}}$，37 °C时即 $E_\text{ion} \approx \dfrac{61.5}{z}\log_{10}\dfrac{[\text{out}]}{[\text{in}]}$ mV。主要玩家（典型哺乳动物值：Na外145/内12；K外4/内155；Cl外110/内10；Ca外2 mM/内100 nM）：$E_\text{K} \approx -90$ mV，$E_\text{Na} \approx +60$ mV，$E_\text{Cl} \approx -70$ mV，$E_\text{Ca} \approx +120$ mV。静息膜电位是电位按通透性加权的**折中**——Goldman–Hodgkin–Katz方程——而静息细胞由**钾漏通道**（设定静息 $P_\text{K}$ 的双孔K2P/TREK与TASK通道）主导，故 $V_m$ 坐在 $E_\text{K}$ 附近约**−70 mV**，少量钠漏把它向正的方向拉了一点。
:::

::: definition 钠泵：生电而隐形 {#def-pump}
**Na⁺/K⁺-ATP酶**每水解一个ATP排出3个Na⁺、摄入2个K⁺：它**生电**（净外向电流、直接超极化几毫伏），但它对静息电位的主要贡献是**间接**的——维持漏通道所花费的梯度。因此抑制（缺血、洋地黄）使细胞缓慢而全局地去极化，而泵的胰岛素与儿茶酚胺驱动的刺激把钾移入细胞，是高钾血症急救治疗（沙丁胺醇、胰岛素加葡萄糖）的基础——药理学读的是同一台泵。
:::

::: example 为什么钾定下基调 {#ex-krest}
向患者静脉注射钾直至血钾从4升到7 mmol/L。用Goldman逻辑预测静息电位的变化方向，然后解释骨骼肌为什么先抽搐样兴奋后麻痹。
::: solution
升高细胞外K⁺**增强朝较不负的 $E_\text{K}$ 的 $P_\text{K}$ 加权驱动**——按Nernst方程，$E_\text{K}$ 从−90 mV移向−60 mV——而静息膜主要是钾的导管，故 $V_m$ **去极化**。轻度去极化使膜靠近阈（抽动、T波高尖与电兴奋神经的早期高兴奋性）；持续去极化到约−55 mV或更正**使钠通道的快闸门失活**——通道只在膜复极时从失活恢复，而慢性去极化的纤维里多数通道坐在失活性：能开放者更少、动作电位失败，患者以**弛缓性瘫痪**就诊，呼吸停止是终末一步。这是去极化（周）阻滞，与司可林使神经肌接头持续去极化（其最初肌束颤动之后）同一机制——以及临床规则：高钾血症是**膜**的疾病，其危险在心脏（见[[cardiovascular/arrhythmias]]），其肌无力随心电图同来而不是随后。
:::
:::

::: example 透析患者缺席的透析 {#ex-hyperk}
一名血液透析患者跳过两次透析，恶心与近端肌无力来诊；K⁺ 7.9 mmol/L；心电图P波消失、QRS 150 ms、T波高窄。
::: solution
先治膜，后治数字。**10%葡萄糖酸钙静脉**注射2–3分钟（或经中心静脉给氯化钙）恢复钠通道电压感受器的表面电荷屏蔽，逆转去极化所致失活并在数分钟内稳定传导——持续一小时，这正是降钾措施需要的跑道。然后**胰岛素10单位加50 g葡萄糖**（加雾化沙丁胺醇10–20 mg作为第二台泵驱动）经Na⁺/K⁺-ATP酶在20–60分钟把钾推入细胞；**锆硅酸钠或钾结合剂**开始缓慢清除；**透析是确定性清除**——唯一按跳过的透析积累钾的速率把钾移走的措施。心电图告诉患者在[[#def-nernst]]曲线上的位置：P波消失是心房失活阻滞，QRS增宽是心室慢传导，其后的正弦波是同一轨迹终结于心搏停止或颤动。整段插曲就是本章的一段话：梯度设定电位，电位设定通道状态，而急救顺序——稳定膜、转移钾、清除钾——就是生物物理学的排序演出。
:::
:::

## 动作电位

::: definition 动作电位及其不应期 {#def-AP}
达阈时，电压门控Na⁺通道开放（激活门）——内向电流进一步去极化、更多通道开放：**正反馈上升支**至约+30 mV，终止于同一电压**使通道失活**（胞内失活颗粒以一定延迟在+40 mV堵塞孔道）与延迟整流K⁺通道开放、向 $E_\text{K}$ 复极（后超极化）。**全或无**：任何阈上刺激给出同一个锋（其高度由 $E_\text{Na}$ 与电导决定，与刺激大小无关）；**强度由频率与募集编码**。**绝对不应期**（通道失活直到膜复极；设定最高放电率）与**相对不应期**（部分通道复原、K⁺电导仍高；更强刺激可引爆）是通道状态机的推论——也是Na⁺通道三态（静息、开放、失活）作为图纸的读数。**强度-时间曲线**（基强度与阈时长）描述整条纤维的兴奋性，而传导的**安全系数**——每个郎飞结产生的电流超出最低所需的部分——正是脱髓鞘所花费的东西。
:::

::: theorem 传导：直径、髓鞘与电缆的物理 {#thm-conduction}
轴突是一根有内阻 $r_i$ 与膜电阻电容的电缆；**长度常数** $\lambda = \sqrt{r_m/r_i}$ 决定电流被动扩散的距离，**时间常数** $\tau = r_m c_m$ 决定膜充电的速度。直径越大 $r_i$ 越低，故无髓C纤维以约1 m/s传导，而大的A纤维达约10–20 m/s。**髓鞘**提高 $r_m$（漏出的电流更少）并降低有效 $c_m$，并借通道在**郎飞结**的成簇把轴突变成中继线：每个结再生锋电位，给出最大人类纤维约120 m/s的**跳跃式传导**——其职责只涉三个结构：结、结间段，与钠通道的安全系数。
:::

::: proof
传导的临床清单是定理的逆否。**脱髓鞘**（多发性硬化、Guillain-Barré）降低 $r_m$、把 $\lambda$ 缩短到结间距离以下，安全系数丢失：传导在体温升高一度时**失败**（**Uhthoff现象**——MS患者泡澡时症状加重，因为温度加快通道动力学、缩短钠通道开放时间、进一步削减安全系数），或变慢变弥散（神经传导研究的远端潜伏期延长、传导阻滞与时间弥散——[[nervous-system/neuromuscular]]电诊断章的核心词汇）。**再髓鞘化**由施万细胞恢复髓鞘长度却恢复不了结的原始建筑（结间更短、通道更均匀），故恢复真实而不完全。**局麻药**从内侧阻断开放态钠通道，其作用是使用依赖的（放电越快→阻滞通道越多——这就是同类之中最活跃的纤维、含小的痛纤维，最先被阻尼的原因）且状态依赖的；神经内pH要紧，因为**带电形式跨髓鞘、不带电的碱基跨膜、阳离子结合受体**——故发炎酸化的组织阻滞不良（pKa与pH的物理，牙科医生的恼到处），而利多卡因里加碳酸氢钠加快起效。**高钾血症**如上所述去极化；**低钙血症**改变钠通道闸门对电压的依赖（表面负电荷的屏蔽减少→通道在更负的电位激活、神经高兴奋：手足搐搦、Chvostek与Trousseau）——二价阳离子的“膜稳定”效应写进通道的生物物理，这就是重度高钾血症第一支静脉药是葡萄糖酸钙：它恢复表面电荷屏蔽，为心脏买来其他治疗需要的那一小时。
:::

::: example 在浴缸里放电的神经 {#ex-uhthoff}
一名31岁新诊断多发性硬化患者报告每次洗热水澡双腿发软，二十分钟内恢复。
::: solution
她的无力是在安全边缘的部分脱髓鞘皮质脊髓纤维的传导阻滞，被温度变为完全。机制叠加：加温加快Na⁺通道闸门动力学、缩短开放时间与每结电流，同时增加膜漏电——到达下一个结的电流落到阈下，冲动死亡。降温恢复安全系数，这就是症状二十分钟可逆（没有新病灶；纯粹的生物物理）、“热、感染或用力时的短暂神经恶化”的鉴别是MS门诊**假复发**规则、处理是行为性（降温服、淋浴温度、运动时机）而非激素冲击的原因——尽管第一次真复发仍值得其检查。教学点可推广：神经系统对温度的敏感平时不可见，因为安全系数慷慨；疾病花费它们。随温度来去的缺失是时间里的**一次定位**，标记着有病而结构尚存的纤维——机制自身揭示的一个治疗窗口，一份预后的仁慈。
:::
:::

::: example 抽筋发麻的甲状腺患者 {#ex-tetany}
全甲状腺切除十二小时后患者口周麻刺、手抽筋、肌肉酸痛；Chvostek征阳性，校正钙1.9 mmol/L伴QT延长。
::: solution
这是**手术甲状旁腺损伤或去血管化的低钙血症**——通道层面的机制：细胞外钙（与其常同伴镁）减少使膜上固定负表面电荷的屏蔽减弱，钠通道电压感受器感受的电场实际变大、通道在离零更远的电位开放；神经自发放电（感觉异常、抽筋、Chvostek的抽动、Trousseau的手足痉挛），而肌肉的高兴奋与高钾阻滞方向相反。症状与心电图用**缓慢静脉葡萄糖酸钙**治疗，然后口服钙与**阿法骨化醇或骨化三醇**（依赖PTH的1α羟化随腺体一同失去——这是与营养性缺乏的区别，也是替代用活性维生素D而非胆钙化醇的原因）；查镁（低镁血症通过抑制残存的少许PTH并阻断其在骨的作用造成顽固性低钙）与磷酸盐；出院路上记录血钙，因为永久性甲状旁腺功能低下患者的长期管理——与过度替代的高钙尿——属于[[endocrine/bone-calcium]]。
:::

::: quiz
一条神经浸在细胞外钠减半的溶液里。它的动作电位有什么变化？
- [ ] 阈值减半
- [x] 峰超射下降（E_Na降约18 mV）、上升支变慢、传导安全下降；阈值几乎不动
- [ ] 因K⁺通道被阻断时程延长
- [ ] 无变化；全或无的阈值与[Na⁺]无关
::: solution
超射逼近 $E_\text{Na}$，而 $E_\text{Na} = 61.5\log_{10}([\text{Na}]_o/[\text{Na}]_i)$ 在细胞外钠减半时下降 $61.5\log_{10}0.5 \approx -18$ mV；驱动力与峰值双双下落，上升支的斜率（Na⁺电流）随之下降——传导变慢、安全系数缩水，极端时足以阻滞。阈值由通道的电压感受器及其表面电荷环境设定，而非梯度，故几乎不动；时程由K⁺电导的时间进程支配。同一算术支撑河豚毒素与石房蛤毒素的完全阻滞（孔道被塞——河豚与麻痹性贝毒作为纯粹的钠通道药理），与局麻药对其部分、状态依赖的版本。
:::

## 兴奋性在体液的化学之中

身体的内环境调谐通道蛋白，而调谐清单就是急症清单。**钾**经 $E_\text{K}$ 如上；**钙**经表面电荷（低钙高兴奋、高钙抑制，心的平台期同一逻辑）；**pH**经通道质子化（酸中毒抑制中枢与神经肌传递——那个迟钝的酸中毒患者——碱中毒使神经高兴奋、手足搐搦与感觉异常，且因碱中毒增加钙的蛋白结合、降低离子化钙而更糟）；**氧与葡萄糖**经泵（缺血性去极化：卒中半暗带的扩散性去极化就是泵在落败，而逆转转运体释放谷氨酸是同一事件化学的一端）；**温度与麻醉药**动力学与通道靶（吸入麻醉作用于GABA_A、甘氨酸与双孔通道；低温减慢传导与心电图的各间期——寒冷中的Osborn波）。整节的临床教训同一句：“可兴奋组织”是一套工程叠层，代谢紊乱以同一物理同时打击神经、肌与心肌——这就是钾7.5同时是一张心电图、一张肌力表与一支葡萄糖酸钙医嘱的原因。

::: history
节目单始于Galvani的蛙腿（1780）与Volta的反驳，成熟为Bernstein的膜理论（1902，钾选择性的静息膜）；枪乌贼巨轴突——群岛可达、一毫米宽因而能用微电极穿刺——给了Hodgkin与Huxley他们的方程（1939–1952；1963年诺贝尔奖），也给了电压钳其词汇；通透选择性与单通道物理随后而来（Hille的离子通道专著是集大成），膜片钳（Neher与Sakmann，1976；1991年诺贝尔）终于一个一个孔地数通道。钠通道阻断剂河豚毒素由日本化学家在1960年代从河豚纯化，而局麻药谱系自Willstätter及后来Einhorn的可卡因替代物（普鲁卡因，1905）开线，给出了工具——其临床的子代：神经阻滞、抗心律失常药分类、抗癫痫药的钠通道动力学——填满后来的数章。
:::

## 通向何处

突触在[[physiology/synapses]]使用这个电位；肌的兴奋-收缩耦联在[[physiology/muscle]]；心肌动作电位与心电图在[[cardiovascular/electrophysiology-ecg]]；钾紊乱在[[renal/potassium-calcium-phosphate]]；传导检查的实践在[[nervous-system/neuromuscular]]；局麻药药理在[[surgery/anaesthesia-pain]]与[[pharmacology/drug-receptor]]。

::: summary
- 静息电位是Goldman加权的、靠近E_K的折中，由钾漏设定；泵维持梯度而只直接写下几毫伏。
- 动作电位是正反馈的钠上升支、由钠通道失活与延迟钾流终止；全或无、由频率编码、被作为时间化的通道状态的不应期划界。
- 传导服从电缆物理：直径设定被动扩散，髓鞘抬高电阻削减电容，郎飞结是中继——花费安全系数的疾病制造温度敏感、易疲劳、好阻滞的失效。
- 高钾血症去极化进入失活阻滞：早期兴奋、随后瘫痪与心电死亡；钙经表面电荷屏蔽买时间；胰岛素、沙丁胺醇与透析以泵与清除移除钾。
- 局麻药是使用与状态依赖的钠通道阻断剂，以其阳离子形式从内侧起效；酸性组织与髓鞘解剖规定其极限。
- 体液的化学——K、Ca、H、O₂、温度——调谐同一套通道叠层；一次代谢急症就是三块组织同时的电学急症。
:::

::: exercise 手算Nernst {level=1}
37 °C时对[K]ᵢ 155、[K]ₒ 4 mmol/L计算E_K；并说出细胞外钾翻倍时E_K如何变化。
::: solution
$E_\text{K} = 61.5\log_{10}(4/155) = 61.5 \times (-1.588) \approx -98$ mV（教科书值随假定的活度而异，约−90至−98 mV）。外钾翻倍到8：$61.5\log_{10}(8/155) \approx -79$ mV——**约19 mV的去极化**，因为对数规则给出十倍约60 mV而正常附近很陡：这就是翻倍之危险的全部，也是心电图监测属于“治疗钾”一部分的原因。
:::

解释胰岛素缺乏与β受体阻滞剂各如何升高血钾，以及后者的效应为何温和却在临床上值得一提。
::: solution
两者都作用于**Na⁺/K⁺-ATP酶的调节**：胰岛素刺激肌与肝的泵活性（餐后钾入细胞的处置很大程度是胰岛素效应；其缺乏或抵抗把钾移到细胞外——酮酸中毒患者总体钾缺失而血钾正常或偏高，是泵加渗透性利尿的合著），β₂激动驱动泵，而**β阻滞（尤其非选择性）撤掉了儿茶酚胺驱动的处置**，在运动所致钾负荷后与透析人群中粗糙可见。临床句子：治糖尿病酮酸中毒时要知道钾是一个再分布的谎言（见尿后、随胰岛素把水平降下即补充）；预期肾处置已丧失的患者用普萘洛尔后钾小升；同一杠杆以雾化或静脉沙丁胺醇治疗性使用。
:::

::: exercise 髓鞘对轴突 {level=2}
在脱髓鞘性神经病中，为什么大纤维模态（触、振、深感觉、无力）早期受累而痛温相对幸免，恢复又为什么进入平台？
::: solution
髓鞘化与直径集中于大的A纤维（Aα、Aβ——Ia与II感觉传入与运动轴突），其长结间段使它们最依赖跳跃式的安全；小的轻髓鞘Aδ与无髓C纤维（痛、温、自主）结间短或无、依赖连续传导，故同一场对髓鞘的免疫攻击迟晚才累及它们。恢复进入平台，因为施万细胞的再髓鞘化不完美（结间短、通道分散），也因为**轴突缺失——任何足够严重的脱髓鞘之后的继发变性——在周围神经系统除缓慢而远端地再生外并不再生**，中枢则完全不；一第二事件电诊断签名是波幅下降（CMAP、SNAP）连同潜伏期延长，而患者的残余缺失通常跟随轴突缺失，而不是把他们带到门诊的那个传导阻滞。
:::
:::

::: exercise 牙科医生的难题 {level=2}
对一颗龋坏发炎的下颌磨牙行下牙槽阻滞麻醉失败；在神经附近换一种药却生效。用药物的生物物理学解释，并给出两个药理学变通。
::: solution
发炎组织是**酸性**的（pH约5–6，而利多卡因的pKa约7.7–7.9）：处于能跨髓鞘与轴膜的未解离碱基形式的药物大大减少、而在其进不去的细胞外液里解离者大增——从内侧阻断开放态钠通道所需的轴突内有效浓度永远到不了（且炎症升高细胞外钾使部分通道去极化失活，前列腺素上调在酸性中仍存续的钠通道亚型）。来自同一物理的变通：**在发炎野近端的神经阻滞**（下颌孔处的下牙槽神经），那里组织pH正常；用生理pH下脂溶性更高的药（甲哌卡因、含酯键而弥散占优的阿替卡因）或缓冲配方（利多卡因-碳酸氢钠混合抬pH、碱基多、起效快），再加下颌骨皮质板限制区域封闭、迫使神经阻滞成为必须的机械事实。
:::
:::

::: exercise 强度-时间 {level=2}
定义基强度与阈时长，并用这两个概念解释a)为什么用于运动阻滞的神经刺激器用长波低电荷而非短促高幅，(b)为什么低钙血症的临床“神经易激”出现在任何刺激阈值测定改变之前。
::: solution
**基强度**是无限时长刺激的最低电流幅值；**阈时长**是两倍基强度所需时长——合为强度-时间双曲线的两个地标，皆为膜 $\tau$ 与通道可用性的指数。(a)接近基强度的长脉冲以低峰电流输送所需的膜电荷，有利于大的低基强度运动轴突、减少伤害性峰电流对小伤害纤维与皮肤的激活——即神经定位与某些阻滞技术所用“长脉冲”刺激的舒适与选择性。(b)低钙血症不以朴素意义降低阈值测定；它通过减少表面电荷屏蔽把通道电压感受器的激活推向更负的电位，通道的自发开放（平时神经纤维安全系数能够容忍）产生异位冲动——先感觉异常后手足搐搦——而针对受控刺激的形式阈值测定此时可接近正常；易激在**噪声**里而不在阈值里，这就是Trousseau的激发手法——袖带充在收缩压以下、让自发放电在缺血、易碱中毒的神经里积累——胜过任何单一阈值测定的原因。
:::

::: exercise 读阻滞 {level=2}
止血带阻断一条手臂：按功能丧失排序（触、痛、冷、运动），并按纤维类型解释为什么神经的压力性缺血按该顺序麻醉。
::: solution
临床顺序（Bennett与经典产科麻醉教学）：**先失冷与触，然后痛温，然后运动（大纤维最先）**。大的髓鞘纤维对压力最敏感，因为其跳跃传导依赖压迫所变形的结间几何——几毫米的结变形就把安全系数降到零——而小的无髓C纤维以宽裕的余量连续传导，对压迫与局麻药都抵抗更久（故差异性的脊柱与区域阻滞：临床阶梯就是含普鲁卡因的Bier阻滞在足以取消手术麻醉的剂量下仍幸免某些纤维的原因，也是止血带痛——C纤维的募集——在一切都被阻滞之后到来、成为放下肢体或做浸润信号的原因）。同一逻辑反着运行恢复：返回的顺序跟随丧失的顺序。
:::

::: exercise 设计一条神经 {level=3}
既然两者解决同一个传导问题，进化为什么给枪乌贼一根巨轴突、给脊椎动物髓鞘？把权衡（空间、能量、速度、可靠性）写成一篇工程短文，并说出多发性硬化中最先断裂的脊椎动物折中。
::: solution
速度需要低内阻（直径）或高膜电阻加短充电（髓鞘）。枪乌贼的答案——一毫米宽的轴突——以获得逃生反射的潜伏期为代价，付出体积，而因为单位长度上每一处相当于结的膜都要充电，毫无代谢节省。脊椎动物的答案——髓鞘——在立方毫米之内买到同样的速度（一百米的每段一毫米的中继线）并节省能量：跳跃传导只在结处移动离子，泵的ATP账单降到同直径连续传导纤维的一个零头。代价：髓鞘建造起来代谢昂贵（一个少突胶质细胞支持许多纤维——单个细胞的死亡使许多轴突失灵，这就是脱髓鞘疾病所利用的脆弱）、每个跳到跳的时序余量使传导存在被拖慢的方式，并繁殖失效模式（自身免疫靶——MBP、MOG、结处的contactin/NF155复合体；代谢性白质病；投射到认知里程碑的发育髓鞘化时间表）。多发性硬化中最先断裂的折中是**郎飞结的安全系数**：一处自身免疫病变哪怕只剥掉一两个结间段的髓鞘就降低膜电阻、使该结的输出电流低于下一个结所需——传导阻滞、温度敏感、代谢昂贵却可能可逆，这就是上文Uhthoff例题里患者口述的同一句话。
:::
:::

::: exercise 去极化悖论 {level=3}
高钾血症与来自赤潮树藻的钠通道激活毒素（*Pyrodinium*——短裸甲藻毒素，神经性贝毒中毒）都造成无力与感觉异常；一个用钙与降钾治疗，另一个只能支持待毒素消退。在通道三态层面解释两者，并说出就诊时把两名患者分开的心电图特征。
::: solution
三态（静息、开放、失活）回答两者。**高钾血症**使静息膜去极化，更多通道静息时坐在**失活**位：可用者少、上升支慢、传导失败——心肌里同样失活并伴心电图序列（T波高尖、P波平坦PR延长、QRS增宽、正弦波）。**短裸甲藻毒素**反其道：结合开放态通道并**把它保持在开放**、阻断失活——持续的内向钠电流、膜去极化到通道*继发*失活的状态，而更重要的是感觉神经的重复放电产生感觉异常与口周烧灼，随后运动纤维的去极化失败造成无力。两者都以钠通道不能按需放电的纤维告终；差别在路径——从静息一侧的失活对从开放一侧的失活。心电图在床旁分开他们：高钾血症给出T波高尖、QRS增宽伴心动过缓倾向，而短裸甲藻毒素患者**血钾正常、心电图正常或心动过速**，由临床综合征（贝类暴露、口周感觉异常、胃肠炎、及作为雪卡毒素表亲的冷热颠倒错觉）做定位。钙、胰岛素与沙丁胺醇以恢复梯度驱动的状态拯救第一例；第二例只需要时间、支持治疗与一张安心的心电图。
:::
