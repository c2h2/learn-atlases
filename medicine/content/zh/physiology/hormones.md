激素是身体缓慢弥散的信号系统——自主神经系统的化学对应物，在分钟到天、厘米而非毫米的尺度上运行同一反射逻辑（感受器、整合器、效应器、反馈）。每一桩内分泌病都是四件事之一——激素过多、过少、时错、靶抗——而四者都能直接从本章的一般生理学读出：合成、储存、分泌控制、转运、受体作用与反馈。

本章讲授激素化学与受体机制、各轴的反馈组织、脉冲性与节律性分泌，及燃料与应激的整合控制。

## 化学：三类，两种信号策略

::: definition 激素类别及其药代动力学后果 {#def-classes}
**肽与蛋白**（胰岛素、ACTH、GH、ADH、糖蛋白激素）：前-原激素经内质网/高尔基加工、储于分泌囊泡、像任何突触一样胞吐释放（[[physiology/synapses]]的机器穿了内分泌的戏服）、水溶、**无须载体**、半衰期数分钟、作用于膜受体——故起效快而口服即毁（胰岛素不能吞）。**类固醇**（皮质醇、醛固酮、性激素）与**甲状腺激素**：亲脂、按需自胆固醇（类固醇）或酪氨酸（T3/T4）经系列细胞色素P450羟化合成、**不储存**——分泌即合成——在血浆中结合转运（皮质类固醇结合球蛋白、白蛋白、甲状腺素结合球蛋白），游离部分才是活性与可滤过的，并有经典陷阱：任何结合蛋白的改变（妊娠、肝病、避孕药）移动总激素而游离激素——因而反馈与效应——稳如泰山。**胺类**分裂：儿茶酚胺是水溶、作用于膜外受体的肾上腺髓质激素，而甲状腺激素——化学上是个胺——表现如亲脂的核受体激素。这个划分预言整个临床药理：哪些激素能口服、哪些需要载体、哪些效应延迟而反跳、哪些免疫测定测的是结合池。
:::

::: definition 受体机制：五种信号设计 {#def-receptors}
肽类激素使用三种设计的膜受体：**cAMP/蛋白激酶A**（ACTH、TSH、LH/FSH、ADH-V₂、胰高血糖素、β肾上腺素——Gs家族；其Gq/PLC-IP₃/Ca²⁺孪生用于TRH、GnRH、缩宫素、V₁，Gi用于生长抑素）、**酪氨酸激酶与JAK–STAT**受体（胰岛素的α₂四聚体自磷酸化IRS-1；GH、催乳素与促红细胞生成素对接细胞因子受体/JAK对），及Notch、Hedgehog与Wnt发育旁分泌信号家族（[[anatomy/embryology]]的词汇）。类固醇与甲状腺激素跨过膜（T3经MCT8转运体进入）到达**核受体超家族**——一种蛋白质建筑：锌指DNA结合域、激素域、二聚化界面——作为配体激活的转录因子起作用、**延迟以小时到天**，这就是皮质醇的允许与分解效应与T3的生热效应要一天才现、一天才退的原因，也是类固醇过多或过少在受体层面从来不是一个小时急事的原因（急症——下述塌陷——是盐皮质激素、儿茶酚胺与葡萄糖系统更快的那条边）。一般教训是突触章的倒影：信号速度住在离子通道与磷酸化里；信号的**容量与广度**住在基因转录里。
:::

## 反馈：控制的建筑

::: theorem 负反馈与垂体轴 {#thm-feedback}
典型的轴——下丘脑（释放激素）→垂体（促激素）→靶腺（激素）——是**一个放大器级联，带一条从终产物回到上面两级的负反馈路径**（皮质醇对CRH/ACTH，T4/T3对TRH/TSH——连同其垂体特有的脱碘酶-2 T4→T3转换，性激素对GnRH与促性腺激素，IGF-1额外回流）。三条定理由此生，每条都是一则诊断规则：(1)**病灶由配对定位**——皮质醇低而ACTH**高**是肾上腺（原发）；皮质醇低而ACTH低/正常是垂体或下丘脑（继发），而醛固酮系统（肾素-血管紧张素驱动、不依赖该轴）在继发病变中幸存——Addison病失盐、皮肤色素沉着（ACTH与MSH同源）而垂体衰竭两者皆无的原因。(2)**对数线性增益**——游离T4以对数线性压制TSH，故T4下降50%使TSH升约3倍、而T4升高20%（早期甲亢）把它埋葬：垂体测定把小的腺体漂移放大为大的促激素信号——为什么TSH是甲状腺状态的筛查试验、为什么低T4伴“不适当的正常”TSH是中枢病变而非正常。(3)**抑制是时间依赖的**：外源性糖皮质激素超过约7.5 mg泼尼松龙三周即抑制促肾上腺皮质轴、肾上腺废用萎缩；骤停留下本章下一示例搬演的Addison危象——轴的恢复是医学中最慢的药理学（6–12个月），而激素递减与生病日规则就是应用生理学。
:::

::: definition 脉冲性与节律 {#def-pulsatile}
释放激素经门脉系统到达垂体，而该系统**要求脉冲式输送**：GnRH以约90分钟脉冲到达，促性腺细胞解码频率（慢脉冲利于FSH、快脉冲利于LH；持续的受体占据**下调**GnRH受体并关断该轴——GnRH激动剂降调节治疗子宫内膜异位症、前列腺癌与中枢性性早熟的倒转疗法，其第一周的潮热峰必须被覆盖）。同一逻辑统治GH（脉冲、慢波睡眠中放大——故单次随机GH毫无价值，而IGF-1——肝脏的池化整合器——是筛查分析物）、催乳素（锁相于脉冲并被多巴胺抑制——一道紧张性刹车，被任何D₂拮抗剂解除、或被中断多巴胺流的垂体柄病变挤压而升高）、皮质醇（昼夜节律——ACTH脉冲幅度由视交叉上核的时钟驱动——醒前最高，故每日一次的激素剂量定在早餐、并混淆每一个随机皮质醇：查8点不查16点）、褪黑素（暗驱动的松果体输出，同步其余一切）。季节、月经与应激调制叠加于所有之上，而临床规则是普适的：**对脉冲激素，一个浓度是一桩轶事；轴要靠其整合器（IGF-1、24小时尿皮质醇、午夜唾液皮质醇、HbA1c）或动态试验来读。**
:::

::: example 读起来像激素的抗体 {#ex-ts}
一名28岁患者消瘦、出汗、眼睑退缩；TSH<0.01而游离T4高；放射性碘摄取弥漫增高——而她的妹妹产后三周有同样的激素但摄取近于零。
::: solution
两人都甲状腺毒症，在同一轴的两个不同点。第一位患者的病坐在腺体上一级：**甲状腺刺激免疫球蛋白（TSI）**——结合TSH受体胞外域却不清除而是**持续性占据**它的IgG自身抗体：一个滤泡细胞读作TSH的拟激素激动剂，cAMP升高、激素合成与腺体生长随之（甲状腺肿），反馈环的应答（TSH压到零）拦不住它，因为抗体不听任何恒温器——唯一作用为刺激而非阻断的常见自身抗体，也是甲状腺功能减退（阻断型抗TPO/破坏、漏出期的桥本甲亢）与Graves病能同出一门的原因。产后妹妹的图形是**破坏性甲状腺炎**——免疫介导的滤泡损伤释放储存的激素（一次倾倒，不是一次驱动：合成低，故**摄取空**，甲状腺毒症期自限，因为储能耗尽）；治疗顺机制而来——卡比马唑（阻断合成）对Graves有理、对漏出无理（β阻滞剂与时间，加上被毁腺体随后而来的甲减随访）。补上同一轴教会的妊娠褶皱：TSI是IgG、过胎盘——新生儿暂时性甲状腺毒症直到母体抗体清除；雌激素升高TBG使总T4上爬而游离的测定依旧。两个患者、一个反馈环、一个受体——及一张读出受体意图的核医学扫描。
:::

## 燃料整合：进食-空腹周期

::: definition 胰岛素：胰高血糖素比 {#def-fuel}
进食-空腹周期不靠任一激素单独运行，而靠门静脉**胰岛素：胰高血糖素比**作用于肝——把静脉回流当作营养缓冲器来感知的肝。**进食态**：胰岛素（β细胞，由葡萄糖代谢关闭K_ATP→去极化→Ca²⁺胞吐触发——同一突触机制，磺脲关闭该通道、GLP-1经cAMP放大）经**GLUT4转位**驱动糖原合成、脂肪生成、蛋白合成与肌和脂的葡萄糖摄取（胰岛素敏感转运体与运动平行的路径：收缩不经胰岛素移动GLUT4，1型糖尿病运动降糖的原因之一——那里胰岛素自己升不起来）。**空腹**：胰岛素下降与胰高血糖素上升先开糖原分解（头24小时）、再糖异生（肌蛋白分解的氨基酸、甘油、乳酸）、然后——第2–3天起、在胰岛素允许的低位下——**肝生酮**伴外周利用酮体，40天时脑约60%燃料由酮承担，省下本会耗掉的蛋白（饥饿的轻度酮症对糖尿病酮症酸中毒：同一个开关，只是刹车的胰岛素踏板全无，故脂解无对抗、生酮无对抗、酸中毒见[[endocrine/diabetes-complications]]）。GH与皮质醇在长时空腹中作为省蛋白的对抗调节者上升；脑的葡萄糖地板（约3 mmol/L）由对抗调节层级保卫——**先降胰岛素，然后肾上腺素（症状发生器与低血糖感知缺失的靶），然后皮质醇与GH（慢救援）**——每一次复发把阈值重置得更低（低血糖相关的适应性感知缺失；衰弱者宽松血糖目标的道理）。
:::

::: example 晨间的塌陷 {#ex-steroid}
一名患者三天前停了泼尼松龙（治巨细胞动脉炎）；如今呕吐、低血压、发热、意识模糊，正值胸部感染第四天。
::: solution
本章两条定理相撞：**轴被抑制了**（生理剂量以上的外源激素三个多月——促肾上腺皮质细胞沉睡、肾上腺萎缩、停药的此刻皮质醇输出为零），而**应激反应正被需要**（感染要求十倍升幅，正常肾上腺一小时内给出——她一点都给不出）。塌陷是被逐项列出的生理：无皮质醇→血管的允许性儿茶酚胺效应丢失（对补液顽固的低血压）、糖异生与对抗调节张力丢失（低血糖）、自由水清除丢失（稀释性低钠——皮质醇与ADH的失抑制）、细胞因子暴露解开那单靠感染未必有的发热；鉴别——单脓毒症还是两者——靠两个都治来定夺。处理是本章按顺序：**先血培养，后静脉氢化可的松100 mg**（替代加应激：每日200 mg分次）、积极输盐水（她因丢失盐皮质激素允许性张力而容量不足，尽管醛固酮常部分完好）、葡萄糖、治诱因，然后数日内递减回维持量，并把**激素卡教训**写在上面：生病日规则（发热时口服剂量翻倍或三倍；永不停药）、急救针与肌注氢化可的松包、警示卡——因为下一次塌陷将以同样的方式、同样的十分钟来诊。
:::

::: example 三个膀胱，一个激素 {#ex-di}
三名患者每日排出8 L稀释尿：一名颅伤少年；一名ADH高的长期锂剂患者；一名对脱水ADH反应正常的30岁精神科护士。
::: solution
稀释尿的多尿意味着集合管的水通道——**水通道蛋白-2**，ADH占据V₂受体时插入（cAMP/PKA——[[#def-receptors]]里该激素的第二信使）——不在工作；三个答案就是该轴的三处失效点。**(1)中枢性尿崩**——ADH未生成或未释放（外伤、手术、肿瘤、[[renal/urinary-tract]]肾小管间质一章的浸润；MRI上神经垂体亮点消失，**禁水试验**的去氨加压素反应是经典仲裁，如今加上copeptin兴奋作为实用标志）。**(2)肾性尿崩**——ADH存在而高、集合管聋：锂经ENaC进入主细胞并干扰水通道蛋白-2转录（靶而非轴的抵抗生理——故噻嗪、针对锂入细胞通道特异性的阿米洛利、前列腺素抑制：利尿剂悖论性抗利尿永远是本章的容量收缩机制，近端把仅存的无溶质水重吸收回去）。**(3)原发性烦渴**——轴完好但被长期冲走：低-正常渗透压、低ADH，**水负荷**试验缓慢浓缩而尿崩患者永远不能完全稀释；把烦渴的危险低钠（水中毒、抽搐阈值）与尿崩二人组分开，恰是[[physiology/homeostasis-body-fluids]]渗透压轴在两端的读数。一个表型、三个病灶、三个试验、一个激素。
:::

::: example 教室最后排的男孩 {#ex-growth}
一名14岁男孩是全年级最矮，无阴毛，骨龄11岁；他父亲“也晚长”、16岁才蹿个；过去一年身高速度5 cm。
::: solution
生长监测学在任何垂体试验前分开两个常见答案：**体质性延迟（“晚熟，晚长”）**对生长激素或其他病理。14岁年速度5 cm是青春期前正常但低于已入青春期生长激素-性激素浪潮同学圈的预期；**骨龄落后于实际年龄**（此处11岁）加晚长家族史说骺有时间在手——孩子将在同学停长后继续长，并预测与靶身高相符的成年高度；**病理图形**是速度跌到青春期前4–5 cm/年带之下、骨龄显著延迟伴畸形特征（甲减——查TSH——及[[endocrine/thyroid]]筛查的增长曲线）或提前（性早熟雄激素过多）、或青春期启动后身高速度仍不恢复。垂体检查随后遵循本章脉冲规则：**从不做随机GH**——用IGF-1筛查（肝整合器，本身营养敏感，故营养不良或甲减孩子的低IGF-1不是GH缺乏），激发试验确证（胰岛素低血糖或精氨酸-胰高血糖素——应激释放试验）——加下丘脑-垂体区MRI找躲在“家族性”组里的颅咽管瘤、隔-视发育不良与垂体柄病变。处理的答案就是把诊断做对：解释、每六个月记录曲线，若延迟确证而心理社会代价沉重，短程低剂量睾酮启动孩子自己的轴给足时间就会运行的过程。
:::

::: quiz
一名矮小、IGF-1正常的孩子上午10点随机生长激素0.4 µg/L，最佳的解读是：
- [ ] 生长激素缺乏——开始治疗
- [x] 无法解释的数值——GH是脉冲的，正常人在脉冲间检测不到
- [ ] 正常——生长足够
- [ ] 若TSH正常则提示垂体功能减退
::: solution
GH分泌是脉冲性的（[[#def-pulsatile]]），健康儿童谷值测不到；单一浓度既不能确立也不能排除诊断。筛查是**IGF-1**（整合输出，按年龄性别营养校正），筛查提示缺乏时做**激发试验**——两次激发峰低于切点——加辅助标志（IGFBP-3、比任何单一测定都重要的生长速度数据）。同一规则在内分泌缩影里统治催乳素（应激脉冲）、皮质醇（昼夜）与醛固酮-肾素比（采样条件）——定义一个数字能是什么意思的是脉冲性教义，不是测定。
:::

::: history
Starling在1905年从Bayliss与Starling的促胰液素造出“**激素**”一词——第一个化学信使，被发现是因为胰液分泌的迷走解释被否决后体液解释登场；Brown-Séquard的睾丸提取物（1889）、Addison与Cushing与Beck的临床分类学（先于其化学的各腺体）、Berthold的消毒鸡冠睾丸移植实验（1849）已把性激素定位于血液。化学时代从Collip与McLeod的胰岛素（1921——Banting与Macleod同十年获诺贝尔，同一病房第一个不死于糖尿病的年份）经Kendall的皮质醇与Hench的抗炎奖（1950）到Guillemin与Schally的下丘脑释放激素（1960年代——一场十年的竞赛，以数万枚垂体腺体计量的质谱收尾）与Yalow和Berson的**放射免疫测定**（1960）——把激素变成数字的抗体竞争戏法、1977年的诺贝尔——测定而非激素才是真正发现：它使反馈环可见为一条曲线，并使本章每条定理在日常实验室里可测。Selye的应激三联（一般适应综合征的警觉、抵抗与衰竭）提供了后续各节仍在使用的整合框架，无论细节对错。
:::

- 三种化学、两种信号策略：肽类在秒级经G蛋白与激酶第二信使设计作用于膜受体；类固醇与甲状腺激素经核受体起作用、有转录延迟；转运（囊泡对载体）由溶解度决定。
- 轴是放大的负反馈级联；终产物的定位逻辑（原发对继发、醛固酮例外）、使促激素成为筛查分析物的对数线性增益、抑制的下萎与反跳规则，在皮质醇、甲状腺与性腺系统普遍适用。
- 分泌是脉冲与节律的：脉冲传递激素的随机浓度骗人（GH、皮质醇、TSH的解读陷阱），频率本身是信息（GnRH），而轴要靠整合器或动态试验来读。
- 燃料生理是胰岛素：胰高血糖素比操作肝的进食-空腹开关，由严格的对抗调节层级防御低血糖——糖尿病治疗一再把它拆解。
- 靶抵抗（胰岛素、甲状腺、肾上腺、肾ADH）补全四症状清单——过多、过少、时错、无人应答。
:::

## 练习

::: exercise 结合与游离 {level=1}
一名桥本病服甲状腺素150 µg的孕妇受孕后游离T4正常、TSH正常，但总T4升40%。为什么不需要改剂量，什么时候需要？
::: solution
雌激素升高**甲状腺素结合球蛋白**（肝唾液酸化、分解变慢），故总T4上爬而**游离部分——反馈里、组织里、测定游离类似物里的那个物种——被完好的TSH环钳住**；游离T4与TSH正常意味着组织甲状腺功能正常、要追的数字未变。**需求**改变——而非结合改变——时才需要加量：分布容积增大与胎盘脱碘酶-3代谢通常自孕早期就要多25–30%的甲状腺素（妊娠期指南TSH目标针对游离激素状态，每4–6周查），避孕药、肝衰竭与肾病综合征同样把结合向两个方向移动。[[#def-classes]]的一般规则：**总浓度要想到结合蛋白来解读，游离浓度要想到反馈环来解读。**
:::
:::

::: exercise 第二信使归位 {level=1}
把主导信号设计（cAMP、IP₃/Ca²⁺、内在酪氨酸激酶、JAK–STAT、核受体）指派给：ACTH、TRH、胰岛素、GH、醛固酮、 集合管处的ADH、胰高血糖素——并给出cAMP一对在气道与心的药理推论。
::: solution
**cAMP/PKA**：ACTH（MC2R）、TSH、LH、FSH、胰高血糖素、ADH-V₂；**IP₃/Ca²⁺**：TRH、GnRH、缩宫素、ADH-V₁、α₁；**酪氨酸激酶**：胰岛素（IRS-1/PI3K/Akt——代谢臂，及MAPK生长臂，两臂的可分性解释了类似物中胰岛素有丝分裂与代谢效应的分道）；**JAK–STAT**：GH（→IGF-1基因转录）、催乳素、EPO；**核受体**：醛固酮（MR）、皮质醇（GR）、T3、类固醇。药理推论：气道β₂受体是一台cAMP机器（支气管扩张剂的震颤、心动过速与经Na⁺/K⁺-ATPase的低钾是同一信使在其他组织——茶碱对该信使的销毁者PDE的攻击是不挑边的老版本），而心的β₁-cAMP是正性肌力与心律失常之路。一种设计，整部处方集的剂量-反应对称。
:::
:::

::: exercise 定位病灶 {level=2}
给每一图形一个可能部位（下丘脑、垂体、靶腺、受体）：(a)TSH高、游离T4高、无甲状腺肿、家族史；(b)游离T4低、TSH正常、产后出血后；(c)皮质醇高、ACTH低；(d)睾酮高、LH低、睾丸小。
::: solution
**(a)受体抵抗**——看不见T4的垂体（THRB突变）把恒温器设在更高处：生化像甲亢、临床近乎正常、TSH正常或升高——与TSH腺瘤（α-亚基高、有肿块）的鉴别靠家族史与无甲状腺毒症状；绝不用抗甲状腺药治数字。**(b)垂体**——Sheehan综合征：增大的妊娠垂体在分娩出血后梗死，促性腺与促肾上腺皮质细胞先衰（无泌乳、无月经，然后下次感染时危机）；注意**甲减时的正常TSH就是异常**（“不适当的正常”=中枢）。**(c)靶腺（肾上腺皮质）**——自主腺瘤：皮质醇高、ACTH被压、对侧腺体萎缩，盐皮质激素与雄激素系统随肿瘤自身酶谱（纯皮质醇者从不潴盐——醛固酮是肾素的孩子不是ACTH的）。**(d)外源雄激素**——LH被抑制（反馈）、睾丸因失去促性腺刺激而缩小、合成类固醇使用的诊断指纹（或罕见的雄激素分泌肿瘤，睾丸同样小但睾酮高得多）。四条是同一定理——**把促激素对着靶激素读**——朝四个方向的应用。
:::

::: exercise 实验室里的对抗调节 {level=2}
在实验性低血糖钳夹中，按葡萄糖阈值排列激素反应顺序，并解释为什么长期自主神经病患者先丢失警告症状后丢失防御。
::: solution
葡萄糖下降：**胰岛素先降**（约4.5 mmol/L，第一道防御——肝糖输出上升），**肾上腺素与症状群**（心悸、震颤、焦虑——自主的、β受体介导的警告）约3.8，**皮质醇与GH**约3.5（慢、允许性、以小时计），**低糖神经症状**（意识模糊、抽搐、昏迷）约2.8以下——终末器官本身失效。反复低血糖把所有阈值**向下**移（中枢适应性重置）：交感肾上腺反应现在已在造成脑缺糖的低血糖才发射，患者遂无感知——而在**自主神经病**（糖尿病及[[physiology/autonomic-nervous-system]]的突触核蛋白病）中传出支被毁：肾上腺素反应迟钝或消失（胰腺**去甲肾上腺素**与交感驱动的肾上腺髓质都没了），自主症状永不出现（钳夹研究显示患者在2.5 mmol/L时自述毫无感觉），残存防御是直接脑对抗调节与胰高血糖素反应——而后者在多年1型糖尿病后随胰岛内信号死去而失效。这就是强化治疗风险的生理基础（DCCT的低血糖不可知）、β阻滞剂告诫（震颤与心悸被阻断；出汗幸存，因它是胆碱能——被阻滞患者的低血糖只以出汗报信的原因之一）、与现代实践中CGM报警的位置。
:::

::: exercise 允许作用 {level=2}
定义允许性相互作用，并用于：(a)甲状腺激素与儿茶酚胺；(b)皮质醇的两张血管面孔；(c)胰岛素对胰高血糖素生酮的奇特要求。
::: solution
**允许作用**：激素A以其自身浓度提供激素B在正常浓度下工作所需的受体或酶背景。**(a)**T3在心肌、肌与脂肪细胞上调β肾上腺素受体表达与Gs偶联——故甲亢的肾上腺素表型（心动过速、震颤、脉压宽、焦虑）大体是**儿茶酚胺致敏综合征**，在腺体重置期间用β阻滞治疗，而甲减的慢而钝的循环以同一货币读出。**(b)**皮质醇是血管对儿茶酚胺反应性所必需（允许性——Addison样低血压对补液与升压药顽固，直到给氢化可的松），过多时本身变成升压的（MR交叉占据、α₁上调、缩血管反应增强——Cushing的高血压）。**(c)**禁食与糖尿病脂肪流失时，皮质醇与GH的脂解进行，但完整的生酮要求**低胰岛素状态**放开肝HMG-CoA通路、胰高血糖素的门脉信号抬高乙酰CoA通量——反向意义的允许作用：允许激素被撤走，病理通路（酮酸中毒）狂奔。允许作用是内分泌综合征超出单激素地图被误读的原因：效应是**所有轴同时构成的背景**。
:::
:::

::: exercise 设计抑制试验 {level=2}
地塞米松抑制试验（1 mg过夜；2 mg×2天；8 mg大剂量）区分三种状态。说明每个剂量测什么，结果如何分开单纯肥胖、Cushing病与肾上腺肿瘤，假阳性藏在哪里。
::: solution
该试验是把[[#thm-feedback]]的反馈定理做成诊断：**1 mg**问“任何剂量的合成糖皮质激素今晚能否抑制该轴？”——失败意味着内源驱动自主；假阳性不被抑制在肥胖常见（分布容积增大、清除加快——每升的剂量变小）、抑郁、酒精、慢性病与午夜唾液测定的干扰因素（故过夜试验是筛查，需二线确证：午夜唾液皮质醇、24小时尿游离皮质醇、或2 mg/48小时尿排泄版）。**不被抑制→测ACTH**：ACTH被抑制（<5 pg/mL）意味肾上腺自主（肿瘤——影像，大剂量试验无关）；ACTH依赖再问“谁的垂体？”——**8 mg**剂量的部分抑制（促肾上腺皮质腺瘤保留设在高处的部分反馈）对异位ACTH毫无变化（小细胞癌，完全耳聋的肿瘤），加CRH兴奋、岩下窦采血（中枢对外周的梯度——确定性导管试验）与对已长出生物化学肿瘤的影像。肥胖以筛查假阳性的身份入场；算法结构就是本章的，而其误导边缘——皮质类固醇结合球蛋白对血皮质醇的影响、测定的交叉反应、跨实验室的测定标准化——属于[[endocrine/adrenal]]的检查学。
:::

::: exercise 频率作为信息 {level=2}
解释为什么GnRH激动剂既用于性早熟又用于前列腺癌、第一周为什么能加重症状、而GnRH拮抗剂避开该阶段——每半句的生理。
::: solution
促性腺细胞解码**GnRH脉冲频率**：约90分钟脉冲维持LH/FSH的转录与释放；**持续受体占据使GnRH受体内吞并下调**、沉默促性腺细胞——激动剂每日注射或储库制剂反而成为化学垂体切除的悖论（医学史上“频率即信息”最干净的实例）。性早熟（中枢、GnRH驱动）与前列腺癌（睾酮驱动）都在此步被关断——手术存在之前两者皆然，储库制剂的生态位。**第一周潮涌**：下调之前激动剂是刺激——LH、继而睾酮上升，在前列腺可加重梗阻或骨痛潮涌（头两周用抗雄激素覆盖；罕见的性早熟儿童反而短暂加速）。**拮抗剂**（受体阻断——地加瑞克）从不刺激：LH与睾酮直落、无潮涌，代价是注射部位反应与（临床试验的信号）可能失去激动剂似乎享有的心血管代谢保护平台——两种制剂里的同一受体占据药理，以及写方案的为何是药物的动力学而非其靶。
:::

::: exercise 作为内分泌环路的食欲轴 {level=3}
把体重调节建模为以脂肪为内分泌器官的反馈系统：指出感受器、传入激素、整合器、传出；陈述开创该领域的瘦素实验；并解释为什么“瘦素缺乏”几乎治不了任何肥胖患者，这对反馈调定点意味着什么。
::: solution
**感受器与传入**：脂肪按含量正比分泌**瘦素**（脂肪统计器信号；ob/ob小鼠对其缺乏与Coleman的双联共生实验、及Zhang 1994年的克隆开创该领域——加上较小的胰岛素进入）；胃在餐前分泌**生长素**（一餐的信号）；餐后肠的PYY、GLP-1与CCK终止进餐。**整合器**：**弓状核**——POMC/CART厌食与NPY/AgRP促食一级神经元，瘦素的JAK-STAT抑制后者、激活前者，下游黑素皮质素-4受体为传出路（其突变是最常见的单基因肥胖），下丘脑环路被边缘多巴胺享乐性推翻（现代肥胖药理——GLP-1激动剂正作用于此整合器与后脑——是[[endocrine/diabetes]]与[[gastrointestinal/clinical-nutrition]]的临床手臂）。**传出**：摄入，及经自主与甲状腺轴的消耗。**瘦素为何失败**：人肥胖是**高瘦素伴中枢抵抗**的状态——反馈环在以抬高处的脂肪统计器运行，[[#ex-steroid]]受体问题的垂体类比——所以给更多配体等于给胰岛素抵抗患者更多胰岛素。教训以本章框架收尾：一个轴可以病在受体或病在调定点，而抵抗的治疗从不是更多激素；整个学科的一般生理学——合成、反馈、脉冲性、抵抗——在肥胖问题上缩微可读：那里反馈完好、激素充足、而恒温器错了。
:::
