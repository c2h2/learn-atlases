生理学始于Claude Bernard在1860年代写在他讲座教室门上的那句话——内环境的固定是自由而独立生活的条件。其后的一切——神经、肌、肾、内分泌——都是研究这份稳定如何被产生、监测与保卫，以及数字漂移时会发生什么。这第一章建立课程其余部分所说的两种语言：**控制**（感受器、调定点、反馈、增益）与**间隔**（水与盐坐在哪里、如何测量，疾病把账目打乱时它们如何移动）。

每一张临床补液医嘱、每一个异常的钠、每一条水肿的肢体，都是这两部语法的应用句。

## 控制系统

::: definition 反射弧及其工程 {#def-control}
一个被控制的生理变量（温度、血钠、动脉压、葡萄糖、钙、pH）被感受器**感受**、在**整合器**中与**调定点**比对（常为下丘脑或延髓，常带内分泌中转），整合器驱动**效应器**（神经、激素、肌、肾）纠正偏差：**负反馈**中反应对抗扰动。系统的**增益**是其纠正之彻底——纠正量与残余误差之比；高增益系统（动脉压、钙、渗透压）几乎不留残余误差，因为其控制器便宜而快速；低增益者留下可见的偏差。两个变体完成词汇表。**前馈**控制先于扰动行动（餐前的头期胰岛素；平板跑步*开始*时的心血管调整），**正反馈**放大（分娩的收缩-缩宫素正反馈环；血小板栓；动作电位的上升支）——后者总被一个终止环路的事件封顶，因为没有限界的正反馈就是死亡。
:::

::: theorem 容量与张力是两个不同的变量，而身体给它们排了座次 {#thm-ranking}
渗透压调节者用血管加压素与渴觉保卫**张力**；压力感受器用肾素-血管紧张素-醛固酮系统、交感张力与血管加压素保卫**容量**。两者冲突时——出血、心衰、肝硬化、脓毒症——**容量获胜**：颈动脉与心脏压力感受器卸载在*低*渗透压下驱动血管加压素与渴觉，肾留盐留水，产生水肿性疾病的低钠与容量过多却不适当浓缩尿的患者。这个座次是本章临床产出最高的一句话：低钠通常是**水过多保卫一个低充盈**的问题而非缺盐，诊断问题永远是有效动脉容量，而不是总量。
:::

::: proof
证明就在重叠的生理里。血管加压素分泌 平时坐在渗透压的刀锋上（渗透压升高1–2%使血浓度翻倍），但**8–10%的容量不足通过低压（心房）与高压（动脉）压力感受器通路压过渗透压调定点**——一套进化算术：低容量休克以小时杀人，高钠脱水以天杀人。同一层级解释临床清单：**心衰**时动脉树低充盈（无论总量多少）驱动非渗透性血管加压素与远端输送减少，水滞留超过钠、血钠下降；**肝硬化**时内脏一氧化氮所致动脉扩张用同样结果卸载压力反射——稀释性低钠标记严重度，其纠正如今药理学上可能（vaptan阻断V₂受体，蓄意翻转身体的座次）；**脓毒症与术后状态**下疼痛、恶心与细胞因子在两种刺激都不存在时升高血管加压素，康复期的医源性水变成低钠。每一例都回答同样两个问题——患者是低容量、等容量还是高容量，尿渗透压是>100 mOsm/kg（血管加压素在作用）还是最大程度稀释（血管加压素关闭，故钠必由摄入或溶质驱动）——这就是[[renal/water-sodium]]的诊断算法在肾章需要它之前的陈述。
:::

## 分布间隔及其测量

::: definition 体液分布间隔 {#def-compartments}
年轻成年男性总体水平均为**体重的60%**（老年人50%，女性50–55%——差别是几乎不含水的脂肪；婴儿约75%）。它分为**2/3细胞内（体重的40%）**与**1/3细胞外（20%）**，细胞外又分**组织间液（约15%）与血浆（约5%）**，另有一小条**跨细胞液**（约1%——脑脊液、眼液、浆膜液与关节液，“分泌”于上皮之上）。两条间隔边界服从不同的溶质规则：**细胞膜**对细胞内阴离子与阳离子不通透（内有蛋白质与有机磷酸盐、K⁺及其磷酸盐；Na⁺与Cl⁻被钠钾ATP酶与通道选择性排除），故**ICF渗透压等于ECF渗透压**（约285 mOsm/kg），水随渗透梯度跨细胞移动；**毛细血管**自由放行水与小溶质却留住院血蛋白，故组织间液与血浆主要差在血浆带负电蛋白的Gibbs-Donnan效应。成分：血浆Na 140、K 4、Cl 102、HCO₃ 24、蛋白 7 g/dL；组织间液与血浆近乎相同而蛋白少（糖萼下蛋白浓度极低——见Starling）；ICF Na约10、K约140，以Mg²⁺与磷酸为主要阳离子与阴离子。
:::

**指示剂稀释**照间隔之原样测量它们：引入已知量示踪剂、让其在所属间隔平衡、稀释空间按**V=（注入量−排出量）/浓度**计算：**氚水或尿素测TBW，菊粉或甘露醇测ECF，放射性核素标记白蛋白测血浆容量**，组织间容积与红细胞总量由减法得到（血容量由血浆容量与血细胞比容恢复，校正滞留血浆与全身的**F细胞比**）。床旁算术用分数：TBW≈0.6×体重；ECF≈0.2（故1升0.9%盐水分布进全身约25%——而0.45%盐水与5%葡萄糖一旦其糖盐被处理，便分布进全部42 L）。

::: example 哪个间隔？ {#ex-shifts}
预测以下各例的间隔变化：(a)急性出血并立即以等张血浆替代；(b)未治疗的糖尿病伴高血糖与渗透性利尿；(c)原发性烦渴（每日15 L水）；(d)为症状性低钠输2 L 3%盐水。
::: solution
回答全部四题的规则：**等张溶液留在ECF；高张溶液把ICF的水拉出并扩充ECF；低张或纯水靠渗透分布到所有间隔并使细胞肿胀；等张血液的等张替代不改变张力**。(a)ECF容量失去又补回——张力不变（而真实出血时，血浆自组织间再充盈——Starling的钟摆最多以每小时升速倒摆——就是血细胞比容滞后、晶状体需要量约超失血量三倍的原因）。(b)葡萄糖是有效渗透分子：高血糖升高ECF张力、**把水从细胞拉出**（ICF收缩），渗透性利尿继而失水*与*盐——图景是ECF缺失加ICF缺失加假性低的实测钠，正常血糖以上每100 mg/dL（≈5.6 mmol/L）校正约+1.6–2.4 mmol/L。(c)正常肾（可排约12–18 L/日）面前15 L水压不倒什么，但只要血管加压素哪怕部分开启，水就被保留并分布到两个间隔——**细胞肿胀、ECF稀释：低张力性低钠**（水中毒的脑水肿）。(d)3%盐水（Na 513 mmol/L；约1026 mOsm/L）留在ECF并**自ICF抽水**，在纠正张力的同时缩小脑细胞——这正是重度症状性低钠的急救用3%而非生理盐水的理由，也是纠正速率必须封顶以防渗透性脱髓鞘的原因。
:::
:::

## 日常生活中的水钠平衡

一个久坐的成人每日摄入约2.5 L（约1.5饮用、0.7食物、0.3代谢水），以尿（0.5–1.5——由溶质排泄设定的必然最低值，约600 mOsm/日对最高1200 mOsm/L的浓缩）、**皮肤不感蒸发（约0.5 L）与呼吸道（约0.4 L）**、粪便（约0.1）与按需出汗丢失。发热每°C使不感蒸发增加约10–15%；不带湿化器的气管切开或呼吸机使呼吸丢失翻倍；创伤与分解代谢抬高必然氮与溶质排出。肾随后在ADH与醛固酮下记日常的账，但**大脑先记：渴觉**——渗透触发（器质血管与穹窿下器，缺乏血-脑屏障得以取样血浆的室周器官）与血管紧张素II触发（肾素系统的致渴臂）——是人类生理学增益最高的行为，其失效（老人的缺渴、下丘脑病变）或夸张（原发性烦渴、致渴性尿崩）产生钠的两个极端。

::: theorem 血浆渗透压是一个两个半溶质的数字 {#thm-osm}
计算渗透压=**2×[Na⁺]+[葡萄糖]+[尿素]**（mmol/L，即约2Na+葡萄糖+尿素；美制单位2Na+葡萄糖/18+BUN/2.8）。系数2数的是伴随每种钠盐的阴离子。尿素跨多数细胞膜是**无效**的渗透剂（经尿素转运体平衡）——故**张力**（渗透有效部分、决定水移动者）数钠与葡萄糖而不数尿素。**渗透压间隙**——实测（冰点下降法）减计算渗透压——因此是临床医生筛查未测的有效或无效渗透分子的手段：间隙>10 mOsm/kg提出乙醇、甘露醇、造影剂，或（经典地）代谢成酸并同时打开阴离子间隙中毒醇的问题（[[renal/acid-base-disorders]]）。
:::

::: example 两个钠 {#ex-tonicity}
两名患者血钠125 mmol/L：A，70 kg厌食女性，尿素40 mmol/L（BUN 112），葡萄糖6，Na 125；B，28岁，马拉松赛中饮8 L水后Na 125，尿素4，葡萄糖4.5。
::: solution
A：计算渗透压=2×125+6+40=296——实测渗透压接近正常而钠低：**尿素（无效渗透分子）正扛着张力**，钠只报告了故事的一部分；有效渗透压（张力）是2×125+6=256，故此患者*确实*低张而同时尿毒症——病例展示规则的两半（测渗透压，再按有效部分判断张力）。B：计算=2×125+4.5+4=259，真性低张：**运动相关低钠，源于非渗透性血管加压素（疼痛、恶心、用力）加自由水过多**——稀释模式，其神经症状（头痛、意识模糊、抽搐）跟随脑水肿，治疗是谨慎的3%盐水配防止渗透性脱髓鞘的速率上限。本例的语法：把数字写进方程，分开**实测渗透压**、**有效渗透压（张力）**与**容量状态**，病因自行落出。
:::
:::

::: example 每小时五十毫升，两个方向 {#ex-balance}
一名80 kg男性在病房查房时虚脱；观察：脉搏118，卧位90/60、立位70/50，黏膜干燥，皮纹回弹慢，六小时尿量20 mL/h，尿素22 mmol/L伴肌酐190（基线90），Na 148。
::: solution
这是**低容量伴肾前性急性肾损伤与高钠（失水性）脱水**——每个数字都是控制环在读自己的误差信号。脉压窄与体位性下降：压力感受器卸载伴交感代偿；尿素不成比例地超过肌酐（此比值有诊断性，因尿素在近端小管与水同被重吸收、其分泌随流量下降）加浓缩尿：肾在血管紧张素II、醛固酮与血管加压素下忠实地留盐留水；钠148：失水（不感蒸发、袢利尿剂带出的水，或干脆没喝——缺渴老人模式）超过失盐。处理是把两个缺失分开：**先以等张容量恢复循环（座次定理——容量高于张力），再缓慢纠正自由水缺失**（此处≈48×(148/140−1)≈2.7 L，48小时内，患者能喝就口服——渴觉是增益最高的控制器也通常是最好的）。尿量——20 mL/h而非无尿——是肾小管未受损的安心，而第一升水的反应（脉搏、体位压与一小时内科升的尿流）正是肾一直在提供的诊断试验。
:::
:::

## 组织间液与水肿

::: definition Starling力与修正的毛细血管关系 {#def-starling}
跨毛细血管的液体滤过由Starling（1896）写为**静水压**（P_c向外推、P_i向内推）与**胶体渗透压**（π_p向内拉住、π_i向外拉）在反射系数σ与导度L_p的膜两侧的平衡：$J_v = L_p\left[(P_c - P_i) - \sigma(\pi_p - \pi_i)\right]$。**修正的Starling原理**认识到内皮**糖萼**——而不是血管腔——才是渗透屏障：糖萼下π近乎零，只在血浆蛋白下降或血流下降时才上升，而淋巴管持续清扫组织间——故经典的微静脉端“重吸收臂”几乎不存在，**稳态是滤过与淋巴流的平衡**。组织间的**Starling电阻**行为（其胶原凝胶抵抗肿胀、抬高组织间压与淋巴引流）就是水肿只在安全裕度之后才出现的原因；临床水肿是方程的四种失效：**P_c升高**（心衰、静脉梗阻、下垂位双腿）、**π_p低**（肾病综合征、肝硬化、营养不良）、**毛细血管通透性增加**（脓毒症、炎症、烧伤），与**淋巴梗阻**（丝虫病、乳腺术后、肿瘤——唯一的高蛋白水肿原因，也是组织间纤维化后凹陷消失的原因）。
:::

::: example 读一名水肿患者 {#ex-oedema}
四名患者以腿肿就诊：(a)76岁，劳力性呼吸困难、颈静脉压升高、肝大；(b)8岁，面肿、尿蛋白4+；(c)55岁酗酒者，腹水、肝掌、白蛋白22 g/L；(d)60岁，同侧腹股沟黑色素瘤清扫后单侧腿肿。
::: solution
把Starling的各项分配下去。(a)**静脉充血所致毛细血管静水压升高**——升高的静脉压传遍整个毛细血管床，加上肾把动脉低充盈读作压力信号、驱动盐水潴留，再由静脉充血把潴留重新呈报为水肿（[[cardiovascular/heart-failure]]的肾适应环）；腹水、积液与肺水肿随之而来。(b)**血浆胶体渗透压低**——肾病综合征丢失白蛋白；机制的两派之争（充盈不足对微小病变病原发性潴钠的“充盈过度”）就是本章的告诫：疾病在物理之上加进肾性钠潴留。(c)**胶体渗透压低加门脉静水压高加淋巴溢流**：肝硬化腹水是Starling的全乐队——窦性门脉高压抬高内脏P_c、低白蛋白压低π_p、肝淋巴在引流不及处自肝表面涓涓渗出，解释了许多患者腹水先于腿肿。(d)**淋巴失效**——高蛋白、纤维化后不凹陷、单侧、清扫后的淋巴水肿，其不同在于水肿液自身蛋白高（四例中唯一），治疗靠理疗（压迫与引流）而非利尿剂缩小肢体从未需要的血浆容量。表格就是查体：颈静脉压、白蛋白、肝脏体征、单侧性、凹陷与不凹陷——每个Starling项占一样。
:::
:::

::: history
Bernard（1850–70年代）框定了内环境；Cannon命名并系统化了**稳态**（1929），其哲学脚手架是苏格兰生物化学家Lawrence J. Henderson的环境适切性论证（1913）。Starling的毛细血管交换假说来自1896年牛津的新肌肉制备；Landis在1920年代用蛙肠系膜、微量吸管与显微镜测量单根毛细血管压；糖萼修准则随电子显微与微量穿刺在1970–2000年代到来（Michel与Adamson的培养内皮数据在2004年前把教科书里的修正曲线做了出来）。Guyton的教材及其学派的肾功能-动脉压曲线给了容量层级定量形式，而1990–2000年代的V₂受体拮抗剂把非渗透性血管加压素一章变成了一个治疗类别。
:::

- [ ] 12 L
- [ ] 0.5 L
::: solution
标准估计：**自由水缺失=TBW×(([Na]/140)−1)=42×(1.143−1)≈6 L**。诚实地对待估计——总体钠通常也缺失、持续的丢失加进缺失、每4–6小时复测是强制的——并以至少48小时纠正，每日降钠不超过约10 mmol/L（过度纠正的报酬在此是脑水肿，正如反方向的脱髓鞘）。考试句是公式；临床句是复查。

## 通向何处

钠水紊乱的推演在[[renal/water-sodium]]与[[renal/urinary-tract]]；酸碱缓冲在[[physiology/acid-base]]；肾的处理机器在[[renal/filtration]]与[[renal/tubular-function]]；激素控制器在[[physiology/hormones]]与[[endocrine/adrenal]]；心衰的Starling灾难在[[cardiovascular/heart-failure]]；肾病综合征在[[renal/urinary-tract]]。

::: summary
- 生理学是控制工程：调定点、反馈、增益；身体以感受器重叠的平行环同时保卫渗透压、钠、压力、葡萄糖、钙、温度与pH。
- 容量在冲突时高于张力：心衰、肝硬化与术后的低钠通常是非渗透性血管加压素在保卫一个低充盈的循环。
- 间隔服从两条边界：等张留在细胞外，纯水到处分布并使细胞肿胀，而有效渗透分子（钠、葡萄糖）使细胞收缩；稀释技术与60/40/20分数就是记账。
- 渗透压是2Na+葡萄糖+尿素；张力排除尿素；渗透压间隙是外来渗透分子的筛查。
- 毛细血管是一个对着淋巴滤过的Starling系统，其四种失效——静水压、胶体渗透、通透性、淋巴——给每一条肿腿与每一份腹水分类。
- 渴觉与血管加压素把渗透的刀锋做成身体增益最高的控制，而临床医生的工作是读出身体决定保卫哪个变量。
:::

## 练习

::: exercise 稀释算术 {level=1}
注入200 mg菊粉并平衡；血浆浓度0.8 mg/dL，排出20 mg。测得的容积是多少，对应什么？
::: solution
V=(200−20)/0.8 mg/dL=180/0.008 mg/mL=22,500 mL=**22.5 L**——接近约75–110 kg成人预期的体重20%的ECF（菊粉/甘露醇空间）；消瘦患者小于预期、水肿患者大于预期，就是这个数字意义的床旁读法：示踪剂测的是标志物平衡进入的空间，非稳态（近期利尿剂、扩张的ECF）时它会偏离教科书。
:::
:::

::: exercise 维持液 {level=1}
用4-2-1规则与Holliday-Segar为一名70 kg术后患者计算24小时维持液，与本章摄入数字对照；说明现代方案为何常以0.9%盐水或平衡液加钾取代“5%葡萄糖”。
::: solution
**4-2-1：**40+20+50=110 mL/h≈**2.6 L/日**。**Holliday-Segar：**1000+500+20×50=**2.5 L/日**——两者一致，都贴近上文2.5 L/日的摄入预算。对旧葡萄盐水习惯的现代修正：手术患者分泌血管加压素（疼痛、恶心、应激）而不能排自由水，低张液制造院内低钠——等张容量加钾（见尿后）与最低有效速率是指南答案，就是把容量对张力的座次定理写成医嘱。
:::
:::

::: exercise 安全地纠正钠 {level=1 check=“8”}
一个慢性低钠118 mmol/L将被纠正。头24小时的最大安全升幅是多少？
::: solution
**8 mmol/L**（多数指南以每24小时8–10 mmol/L封顶，高危患者更低——噻嗪治疗者、低钾者、营养不良酗酒者，与经前雌激素效应的育龄女性）。理由是脑的容量调节：慢性低张使脑细胞排出特发性渗透分子、其容积恢复正常，而细胞外纠正过快会再次缩小它们并剥去髓鞘——**渗透性脱髓鞘综合征**（旧称“中央脑桥髓鞘溶解”），数日后以构音障碍、四肢瘫与闭锁状态就诊，是电解质医学中最医源性的灾难。若纠正跑得太多——常发生在血管加压素刺激关闭时（容量补足、停用噻嗪）并爆发水利尿——治疗是**用去氨加压素重新钳住肾、用葡萄糖重新压低钠**，一台纯粹应用生理学的操作。
:::
:::

::: exercise 间隙 {level=2}
实测渗透压330 mOsm/kg；Na 132，葡萄糖6，尿素8 mmol/L；阴离子间隙24；pH 7.15伴高间隙酸中毒。计算渗透压间隙并说出它添了什么。
::: solution
计算=2×132+6+8=278；**间隙=330−278=52**，显著升高。高渗透压间隙伴高阴离子间隙酸中毒是**中毒醇中毒**的经典组合——甲醇或乙二醇（母体醇早期抬高间隙；醇脱氢酶将其代谢成甲酸与乙醇酸/草酸时，间隙下降而阴离子间隙上升——同一座钟的两个指针），或伴乙醇的酒精性酮酸中毒。临床用途是同一座钟：合适病史中的高间隙证明**用fomepizole或乙醇阻断脱氢酶、用血液透析清除母体与酸**都是正当的，且都要在代谢物造成视神经或肾损害之前。渗透压间隙因此不是一个数字而是一场赛跑。
:::
:::

::: exercise 给输液排序 {level=2}
按张力排列：0.9%盐水、0.45%盐水、5%葡萄糖、3%盐水、Plasma-Lyte；并说出各自的糖或盐被代谢或排出后去哪里。
::: solution
**输液**的张力：3%（约1000 mOsm/L，高张）>0.9%≈Plasma-Lyte（约285–300，等张）>0.45%（约154，低张）>5%葡萄糖（名义约253，但**代谢后实际为零**）。处理后：**3%留在细胞外并使细胞收缩；0.9%与平衡盐留在细胞外（盐水的氯负荷就是大量时偏好平衡液的原因）；0.45%变成全身各占一份之半的水；5%葡萄糖变成分布到总体水的自由水（这就是它缓慢纠正高钠、却在血管加压素开启时快速制造低钠的原因）。**同一排序倒过来读解释了每一例院内血钠紊乱：查一查输液袋，就查了病因的大半。
:::
:::

::: exercise 踝上的水肿方程 {level=2}
一名慢性静脉功能不全患者膝以下凹陷性水肿，无低白蛋白血症或心衰。用Starling项解释为什么在腿、为什么凹陷、为什么压力袜有效而呋塞米有害。
::: solution
**为什么在腿：**行走时的静脉压就是[[anatomy/lower-limb]]的静水柱——小腿泵失效或瓣膜被毁时，踝部毛细血管P_c随笔立的柱起伏，滤过超过淋巴容量，组织间肿胀。**为什么凹陷：**水肿液是疏松皮下组织内的低蛋白漏出液——组织间凝胶尚未纤维化，压力排开液体留下印痕；长期者发展为纤维化与不凹陷硬结（终结袜套区溃疡路径的脂膜皮肤硬化）。**为什么用袜不用利尿剂：**问题是**区域性静水压故障**，不是全身盐过多——分级压迫抬高小腿周围组织间压，恢复对抗滤过的P_i项并协助肌泵与淋巴，而利尿剂缩小血浆容量、在老人造成低钾、夜尿与跌倒，对局部物理分毫未动：治疗决策两侧同样是那四个Starling项。
:::
:::

::: exercise 设计实验 {level=3}
给一名70 kg志愿者以氚水、菊粉、Evans蓝白蛋白与离心机：设计总体水、ECF、血浆容量、红细胞总量与淋巴储量的测量，并说出各示踪剂的注意事项。
::: solution
**方案。**(1)氚水（或D₂O）2–4小时跨总体水平衡；取血浆样，校正尿丢失与**可交换**（而非真实）氚——注意：约10%的身体H与蛋白及骨交换，故该空间是同位素意义的“TBW”。(2)菊粉（或甘露醇，或临床替身⁵¹Cr-EDTA）在细胞外且不被代谢；持续低速输注定时取样、或双样本平衡法得**ECF**；注意：体内菊粉空间对真实ECF略偏小，因深部结缔与跨细胞间隔渗透慢。(3)Evans蓝（放射性）白蛋白以十分钟平衡的单样本给**血浆容量**；注意：采样期染料自循环漏出、约5%白蛋白在血管外，用外推零时的系列样校正。(4)**红细胞总量**=⁵¹Cr标记红细胞；**血容量**=红细胞总量/(1−全身血细胞比容，**F细胞比**（约静脉血细胞比容的0.87–0.91）校正脾与大血管的血浆撇除——这个注意事项使“循环血容量”成为一个定义而非朴素的数字。(5)**淋巴储量**项不是稀释空间而是组织间的储备：测基线肢体容积（转换体积描记），输已知盐水负荷，液体滞留偏离Starling预测者即指示淋巴容量——旧的“白蛋白经毛细血管逃逸率”实验用放射性碘白蛋白做的就是这个设计。答案的一课就是本章的一课：间隔是由标志物检验的假说，其不完美必须带进判读。
:::
:::

::: exercise 病房急症 {level=3}
一名术后第二天患者，5%葡萄糖125 mL/h，定期用羟考酮，出现意识模糊并抽搐；Na 116。写出即刻处理与生理学论证，并说出肇事的激素。
::: solution
激素：**非渗透性血管加压素**——术后疼痛、恶心与阿片类不依赖渗透压刺激释放，肾不能排自由水，低张输液（125 mL/h葡萄糖=糖代谢后每日3 L自由水）被保留并分布进肿胀的脑。即刻：**停葡萄糖；治抽搐（苯二氮䓬，然后纠正病因）；给3%盐水——2 mL/kg单次或固定100–150 mL单次，可重复一两次，目标头几小时快速升高4–6 mmol/L以拆除水肿，然后把24小时总纠正封顶8 mmol/L**；每2–4小时查钠；给止吐药与镇痛策略以撤除血管加压素刺激；若钠升得太快（低钾、营养不良、酒精依赖与阿片自身停药性利尿使其风险翻倍），**用去氨加压素加葡萄糖重新压低**。预防才是全部要点：在血管加压素负荷的患者，低张维持液就是疾病——这就是现代指南把等张液、最低足够速率与高危者查钠作为默认、而意识模糊术后患者的抽搐图如今先于CT被检查的原因。
:::
