酸碱生理学是一门守着窄带里一个数字的学问——动脉pH 7.35–7.45，氢离子活度35–45 nmol/L——由三台不同时钟的系统维持：秒内起作用的化学、分钟级的肺、天级的肾。它也是本科生理中最值得练算术的分支，因为其紊乱靠方程辨认（Henderson–Hasselbalch关系、阴离子间隙、代偿规则），而其混合型——ICU与普通病房患者的真实来相——没有方程便隐形。

本章讲授酸生成与缓冲系统、pH的呼吸与肾调节，及读取血气的定量方法。

## 每日酸负荷及其第一道防线

::: definition 酸生成与pH控制 {#def-load}
代谢产生两股酸流：**挥发性酸**——呼吸性碳酸生成的约13 mol CO₂/日、潜在400 L呼出气体，因CO₂ + H₂O ⇌ H₂CO₃ ⇌ H⁺ + HCO₃⁻而呈酸性（凡需快速反应处由碳酸酐酶催化：红细胞、小管、肺）——及**固定（非挥发性）酸**：含硫氨基酸（甲硫氨酸与半胱氨酸来的硫酸）、磷蛋白（磷酸）与不完全有机酸氧化约0.7–1 mmol H⁺/kg/日，被蔬菜阴离子的每日碱负荷（柠檬酸、苹果酸——代谢成碳酸氢盐，故素食净产碱、现代西方饮食净酸负荷约25–50 mmol/日对骨与肾生理比教科书的牛排更要紧）抵消。动脉pH由**Henderson–Hasselbalch关系**设定，实用形式**[H⁺] ≈ 24 × pCO₂ / [HCO₃⁻]**（pCO₂以mmHg、碳酸氢盐以mmol/L）：pH是**肺对肾之比**，每个失衡都是分子或分母的失效而另一项代偿——这一行方程就是全部诊断方案，而床旁换算（pH 7.40 ↔ 40 nmol/L；正常附近pH每降0.01约+1 nmol/L）把它变成心算。
:::

::: definition 缓冲系统与等氢离子原理 {#def-buffers}
向5 L**未缓冲**体液加10 mmol强酸会杀人；在场缓冲液以可耐受的pH变化吸收100 mmol。**碳酸氢盐**尽管pK（6.1）远离生理pH仍是细胞外主力——因为它是**开放系统**：其酸组分（CO₂）由肺排放、其碱组分（HCO₃⁻）由肾再生，故与封闭烧杯缓冲不同，器官工作时永不枯竭；每日H⁺缓冲的2/3即时或最终是碳酸氢盐。**磷酸盐**（pK 6.8——理想的肾内与胞内缓冲）与**蛋白**（组氨酸的咪唑基，pK约6.8，伟大的胞内与血红蛋白缓冲——**等氢离子原理**：共同溶液中所有缓冲对平衡到同一个[H⁺]，测其一——碳酸氢盐——即报告全体）分担其余；**血红蛋白**是值得一行的特例，其组氨酸缓冲组织代谢的CO₂（**Haldane效应**——脱氧血红蛋白结合H⁺因而多载CO₂），而肺中的氧合逆转反应、把质子倒给碳酸氢盐排为CO₂（[[respiratory/gas-exchange]]运输章的化学版）。可交换骨碳酸盐（慢性酸中毒的基本缓冲，其耗竭即肾衰竭的**缓冲释放性骨质疏松**）是第四个间隔，也是慢性酸中毒花费钙的原因。
:::

## 肺与肾：两位调节者

::: definition 呼吸代偿与控制 {#def-lung}
外周（颈动脉体、主动脉体）与中枢（延髓、感CSF-H⁺）化学感受器按[H⁺]比例驱动通气、缺氧则较迟钝，故代谢性酸中毒**分钟级内被过度通气**——呼吸代偿的经验规则是**预期pCO₂ = 1.5 × [HCO₃⁻] + 8（±2）**（Winter公式），实测pCO₂高于预期意味着隐藏的呼吸性酸中毒（Kussmaul呼吸力不能及的COPD患者），低于则提示代谢性碱中毒或过度通气驱动（脓毒症、水杨酸、妊娠）。反过来，呼吸性失衡在分钟内被化学缓冲（pCO₂每升10 mmHg碳酸氢盐升约1 mmol/L——封闭系统的弱化学缓冲），然后由肾在2–5天纠正（每10 mmHg约3.5 mmol/L——**急性对慢性的签名**，说出通气患者的酸中毒有多老；其充分表达需要氯与容量补足：高碳酸血症患者因肾留碳酸氢盐同时缺氯，COPD患者的代偿只有在足够的盐水后才完成）。
:::

::: definition 肾的处理：先回收，再生成 {#def-kidney}
肾的酸任务分两班。**回收**：滤过的碳酸氢盐几乎全部重吸收约85%近端，经**NHE3/H⁺-ATP酶-碳酸酐酶II**系统——分泌的H⁺把滤过HCO₃⁻滴定为CO₂、扩散入胞再重组，故碳酸氢盐是*抢救*而从不被*排泄*，尿pH保持在6.5附近——这个精妙的戏法，也是乙酰唑胺的靶：其碳酸氢盐利尿与酸中毒是同一场阻断（[[renal/tubular-function]]的转运图）。**生成新碳酸氢盐**：每日固定酸必须以碳酸氢盐以外的形式离开——**可滴定酸**（磷酸盐携带H⁺，受滤过磷酸盐限制）与首要的**铵**（谷氨酰胺驱动的近端**氨生成**：NH₄⁺顶替钠分泌，再被髓质机器截留循环、送到能排泄的地方——该系统在酸中毒数日内**翻倍**，其失效（伴高钾的肾小管酸中毒——铵是阳离子，其丢失陪送钾与碳酸氢盐）是血肌酐正常时的排泄失效）。所有这一切都连着钾：**低钾血症造成碱中毒**（H⁺入细胞转移、肾H⁺/K⁺-ATP酶闰细胞切换与反常性酸性尿）而**高钾血症造成酸中毒**，盐皮质激素过多同时驱动钾丢失与H⁺丢失、其缺乏相反（[[renal/potassium-calcium-phosphate]]与[[renal/acid-base-disorders]]接手临床形式）。
:::

::: example 长不大的孩子 {#ex-rta}
一名两岁儿发育迟缓、多尿与脱水发作；pH 7.18、pCO₂ 18、HCO₃⁻ 7、Na⁺ 134、Cl⁻ 116、K⁺ 3.0、尿pH 6.0。
::: solution
先算术：Winter预期pCO₂=1.5×7+8≈18.5——代偿恰当；间隙=134−(116+7)=**11，正常**——**高氯性、正常间隙代谢性酸中毒**，幼儿意味着碳酸氢盐丢失（肠道——病史会点名的腹泻——或肾）或排酸失败。尿来定夺：血碳酸氢盐7时正常肾应把尿酸到5.3以下——**全身酸中毒中的尿pH 6.0就是诊断性罪证**，远端（1型）肾小管酸中毒：α闰细胞不能分泌H⁺，酸被滞留、钾经完好的醛固酮驱动交换流失（低钾）、枸橼酸钙处理出错（肾钙化与多尿的浓缩缺陷），而**生长失败因为慢性酸中毒是生长激素抵抗、骨缓冲、失钾的状态**——发育迟缓可能是唯一主诉。治疗就是生理学：大剂量口服碱（枸橼酸盐溶液——上一练习机制里的枸橼酸，为它的碳酸氢盐而给）、补钾，并认识噻嗪与失盐型的各自章节（分型见[[renal/acid-base-disorders]]，钾见[[renal/potassium-calcium-phosphate]]）。近端（2型）变体——碳酸氢盐阈值设低、Fanconi综合征的糖尿与磷酸盐尿——用另一种方式通不过同一酸试验：把血浆碱化到正常，尿又重新酸化（远端机制完好），一条试纸完成近端定位。
:::

## 读血气：定量方法

::: theorem 五步读法 {#thm-read}
(1)**有酸血症还是碱血症？**（pH 7.35/7.45；pH正常而组分异常意味着**混合**失衡。）(2)**哪一边动了？**pCO₂>45致酸、HCO₃⁻<22致酸——匹配的一边命名原发性失衡。3)**代偿恰当吗？**代谢性酸中毒——Winter公式；代谢性碱中毒——预期pCO₂每mmol/L碳酸氢盐升0.7；呼吸性酸中毒——急性1:10对慢性3.5:10的碳酸氢盐规则；呼吸性碱中毒——急性2:10、慢性5:10（碳酸氢盐低于12–14或代偿落在规则外意味着第二个失衡，**按定义**——不恰当的代偿就是这个词的意思。）(4)**任何代谢性酸中毒查阴离子间隙：**AG = Na⁺ − (Cl⁻ + HCO₃⁻)，正常约12 ± 4（按白蛋白校正：**白蛋白每低于4.0一g/dL，间隙加2.5**——ICU低白蛋白患者的间隙假性地友善）；**高间隙**=未测阴离子（助记词跑一遍毒物与灌注清单：乳酸——休克、缺氧、二甲双胍、利奈唑胺；酮——糖尿病、酒精、饥饿；尿毒症；摄入——水杨酸、乙二醇来的乙醇酸/草酸、甲醇来的甲酸）；**正常间隙高氯性酸中毒**=碳酸氢盐丢失（腹泻、输尿管乙状结肠吻合、乙酰唑胺）或肾酸化失败（各型RTA——[[renal/acid-base-disorders]]）。(5)**delta-delta**（ΔAG/ΔHCO₃⁻）：单纯高间隙酸中毒里碳酸氢盐大致与间隙同速下降（比约1–2）；**间隙过剩而碳酸氢盐降幅小于预期**暴露并存的代谢性碱中毒（呕吐的尿毒症、鼻胃引流的DKA患者），降幅更大则是并存的正常间隙酸中毒——把三个数字变成两个诊断的方法。
:::

::: example 三张血气，一个患者 {#ex-series}
一名19岁1型糖尿病：**血气1**——pH 7.12、pCO₂ 15、HCO₃⁻ 5、Na⁺ 138、Cl⁻ 101、葡萄糖34。**血气2**，治疗六小时——pH 7.28、pCO₂ 25、HCO₃⁻ 12、K⁺ 3.1。**血气3**，第二天，呕吐——pH 7.48、pCO₂ 30、HCO₃⁻ 22、Na⁺ 136、Cl⁻ 88、K⁺ 3.0。
::: solution
**血气1**：酸血症；碳酸氢盐低——代谢性酸中毒；Winter：预期pCO₂=1.5×5+8=**15.5±2**——实测15，呼吸代偿最大而恰当；AG=138−(101+5)=**32**——高间隙、酮症，葡萄糖佐证；Kussmaul呼吸就是看得见的算术（患者在通气上限呼吸）。**血气2**：在好转，但三个治疗信号——间隙关闭而碳酸氢盐滞后是正常的（酮阴离子被代谢成碳酸氢盐，富氯液体快速拉低间隙、留下暂时的高氯组分），而**六小时时的钾3.1就是危险**：总体钾已耗竭（酸中毒把它移出、尿把它带走）而胰岛素会把它赶回去——下一瓶胰岛素之前先补钾，[[#def-kidney]]的同一H⁺/K⁺闰细胞逻辑。**血气3**：pH碱血症，两项各不能单独解释——碳酸氢盐22“正常”而pCO₂ 30低，低pCO₂不可能是正常碳酸氢盐的代偿，故这是**呼吸性碱中毒**（疼痛、脓毒症、仍部分运行的Kussmaul惯性）**加藏在正常碳酸氢盐里的代谢性碱中毒**——氯88与呕吐史在大声说，delta-delta的逻辑反用：高间隙酸中毒之后，“正常”碳酸氢盐伴低氯是一个**新的碱负荷状态**（枸橼酸与吐掉的酸，加上维持它的收缩、缺氯容量——盐水反应性碱中毒：[[renal/water-sodium]]的失氯肾，这次由肠道来失）。一次住院，三幅完整图景，每一幅里治疗都从读数自行写出。
:::
:::

::: example 阿司匹林图形 {#ex-salicylate}
一名44岁自杀未遂者：耳鸣、出汗、体温38.4°C、呼吸30；pH 7.44、pCO₂ 21、HCO₃⁻ 14、Na⁺ 141、Cl⁻ 108、葡萄糖4.2、阴离子间隙19。
::: solution
近乎正常的pH是陷阱，方法是答案：pCO₂ 21远低于代偿碳酸氢盐14所需的任何值（Winter预期29），间隙19加摄入史——这是**两个在原发性pH上针锋相对的失衡**：水杨酸直接延髓**呼吸中枢兴奋（原发性呼吸性碱中毒）**与其氧化磷酸化解偶联伴乳酸与酮酸积累（**原发性高间隙代谢性酸中毒**），互相隐藏对方的pH效应而碳酸氢盐与间隙两头都报告——教科书级的演示：只要应用代偿规则，接近正常的pH是医学里*最*信息丰富的异常。成人晚期才通气不足（呼吸驱动的疲惫、水杨酸自己的中枢抑制），然后崩溃；儿童以酸中毒就诊且更早死亡；处理追随生理——**尿碱化**（弱酸水杨酸的离子捕获：pK 3.0意味着尿pH从5升到7.5在肾小管把阴离子捕获比转换100倍——[[renal/tubular-function]]的非解离扩散的倒车），补钾（低钾时碱化失败，[[#def-kidney]]的H⁺/K⁺交换），葡萄糖尽管水平正常（脑被解偶联的代谢与低糖神经风险），重症或恶化者血液透析——一小时纠正两条肢体。
:::

::: example 心跳骤停的血气 {#ex-arrest}
二十分钟心室颤动骤停期间：pH 6.88、pCO₂ 68、HCO₃⁻ 13、乳酸14。
::: solution
方程的两个隔室都朝酸性失效——**混合代谢性（乳酸、缺氧）与呼吸性（无通气，CO₂以低输出下约3–6 mmHg/分钟积累）酸中毒**，pH 6.88就是24×68/13≈126 nmol/L的算术。临床生理正是数字所禁止的：无心输出量时“呼吸”成分部分是**运输失效**——骤停组织生成的CO₂到不了肺（混合静脉pCO₂飙升而动脉读数低估它：动脉管路的血气低估细胞内酸中毒，这就是CPR中中心或静脉血气是更好充分性监测的原因），缓冲在细胞内（细胞外的碳酸氢盐几分钟耗尽；蛋白、磷酸盐与血红蛋白承担大部负荷，乳酸本身部分是胞内缓冲的产物——H⁺与单羧酸根一同输出）。处理按两个病灶顺序：**先血流**（按压质量恢复CO₂冲洗与乳酸清除胜过任何药物），伴可测二氧化碳波形的通气（骤停中ETCO₂ 2 kPa就是决定要不要继续的流量计——图形作为CPR监测是[[emergency-critical-care/acute-assessment]]版本的方程），**碳酸氢盐只用于特定指征**——长时间骤停伴确证的严重代谢性酸中毒、高钾、三环与水杨酸中毒、难治者备好肾替代——因为无血流时给碳酸氢盐只会制造骤停的肺排不掉的更多CO₂：开放系统缓冲在期间被关上，而本章核心规则——**酸碱的读数同时是灌注、通气与肾的读数。**
:::

::: history
Sørensen的pH（氢离子活度，1909）给出了标尺；Henderson然后**Hasselbalch**把质量作用方程用于碳酸氢盐（1916–17）得出该关系，并以最生理学的方式证明——这位丹麦人被人推着骑一台征用的医院健身车穿过哥本哈根街头，测定最大运动乳酸血症时血碳酸氢盐的下降（战争对德国期刊的封锁使他不得不用瑞典语发表，结果抵达巴黎时已很有名）。肾的角色——尿作为最后的公共通路——在1930年代随磷酸盐与氨的分析弄清；Pitts与Alexander的证明（1945）**铵排泄是适应通路**敲定了机制；Siggaard-Andersen的微量血pH电极、**Astrup**图码与碱剩余概念（1962）把酸碱变成今天每张床旁的算术，连同那场仍活的争论——Stewart的物理化学版本以强离子差与pCO₂而非碳酸氢盐为自变量——是生理学对同一批方程最持久、最有教益的重读之一。
:::

- [ ] 白蛋白丧失CO₂缓冲
- [ ] 水杨酸污染
::: solution
她的基线是**伴肾代偿的慢性呼吸性酸中毒**——以失氯为代价的高碳酸氢盐（约38），肾留碳酸氢盐依赖氯（[[#def-lung]]）。呋塞米如今收缩容量、进一步丢氯丢钾，给出经典三联——**收缩、缺氯、低钾**——每一个都独立地在近端小管重吸收碳酸氢盐、在集合管分泌H⁺；把pCO₂守在70的通气驱动降不了碳酸氢盐，而**高**碳酸氢盐与高pCO₂的pH 7.52就是读对了的混合图景（一条代偿规则的违反，定理第3步）。治疗命名机制：钾与氯（盐水）、能停就停利尿剂、接受CO₂——高碳酸血症后碱中毒本身危险的混合失衡推论（通气驱动下降、抽搐、心律失常），这就是通气COPD患者要把频率调低以*允许*CO₂再积累、因碳酸氢盐仍需要天数下降的原因。

- pH被缓冲（秒）、肺（分钟）与肾（天）守在0.04单位的带内，对抗约13 mol/日的挥发性CO₂负荷与约1 mmol/kg/日的固定酸负荷。
- 碳酸氢盐有效因为它是开放系统；血红蛋白的组氨酸与尿磷酸盐、铵分担其余，等氢离子原理让一对缓冲报告全体。
- 代偿是定量而有规则的：Winter公式、1:10/3.5:10高碳酸血症规则与氯依赖的肾极限，是揭穿混合失衡的检验。
- 阴离子间隙（按白蛋白校正）把代谢性酸中毒分为未测阴离子对碳酸氢盐丢失，delta-delta再把间隙的故事拆成隐藏的碱中毒与正常间隙组分。
- 钾与氯和氢一样确凿是酸碱离子：低钾致碱、高钾致酸，而氯耗竭维持着每一个值得治疗的碱中毒。
:::

## 练习

::: exercise 换算与定位 {level=1}
用[H⁺]≈24×pCO₂/HCO₃⁻计算：(a)pH 7.20、pCO₂ 30——求HCO₃⁻；(b)pH 7.55、HCO₃⁻ 32——求pCO₂。各命名原发失衡。
::: solution
pH 7.20⇒[H⁺]=63 nmol/L：(a)HCO₃⁻=24×30/63≈**11.4 mmol/L**——代谢性酸中毒伴通气象样？查Winter：预期pCO₂=25；实测30——**高于**预期，故伴发呼吸性酸中毒（二甲双胍之上又叠阿片）。(b)[H⁺]=28：pCO₂=28×32/24≈**37 mmHg**——慢性代谢性碱中毒的代偿应约40（0.7规则给40：0.7×(32−24)+40）；碱血症下pCO₂ 37意味着低pCO₂是**第二个、呼吸性的过程**（水杨酸或呼吸机）。一个代偿的小数位藏住两个混合失衡——诊断的是算术，不是直觉。
:::
:::

::: exercise 缓冲的时钟 {level=1}
按pH反应速度排列：化学缓冲、肺、肾、骨；按容量排列：碳酸氢盐、蛋白、磷酸盐、氨。为什么排序不同？
::: solution
速度：**缓冲（瞬间，约20 mmol H⁺动0.1 pH单位）、肺（分钟，通气最多升至基线4–6倍）、肾（2–5天才满幅）、骨（天到周，慢性储备）**；容量是另一排名：**碳酸氢盐居首**（开放系统——其容量是肺肾的通气与再生，不是该对的摩尔数）、**氨第二**（适应性——酸中毒时排泄率可升十倍、不受摄入限制）、然后蛋白与骨（有容量无速度）、磷酸盐（受滤过固定——经典考试对照：尿pH能顶着10⁵梯度到4.4，只因为氨先缓冲了膀胱负荷；游离H⁺单干每天只能排一毫当量）。排序不同，因为开放系统的容量由**供给该对缺失一臂的器官**设定，而非化学——一句说尽整个碳酸氢盐教义。
:::
:::

::: exercise 呕吐的血气 {level=2}
一名幽门狭窄婴儿：pH 7.52、pCO₂ 34、HCO₃⁻ 28、Na⁺ 136、Cl⁻ 88、K⁺ 3.0。解释每个数字，包括尿反常的低pH。
::: solution
胃丢失HCl带走酸（碱中毒的生成——本应有氯处碳酸氢盐无对抗）并带走盐水；容量收缩上调醛固酮（维持：远端Na⁺重吸收增强换K⁺与H⁺），低氯本身使近端小管随钠拼命重吸收碳酸氢盐——**缺氯、盐水反应性代谢性碱中毒**（[[renal/water-sodium]]的两种碱中毒规则）。碱中毒的代偿是通气不足（预期pCO₂≈基线以上每4升0.7+40≈43），实测34在其下——低容量低钾婴儿的驱动不获自由减速，故轻度呼吸性碱中毒骑在上面；病例到反常尿之前已是混合。**反常性酸性尿**是本章被引最多的转运事实：在氯尽钾空的肾小管，钠必须带着什么被重吸收，于是闰细胞分泌H⁺（酸性尿，进一步碱化血浆），K⁺/H⁺交换体一边酸化一边重吸收钾——先补钾才有碱尿。治疗：**先盐水（氯才是解药），次钾，然后手术**（止住酸丢失的幽门肌切开）——这段生理学的一份外科旧口述。
:::

::: exercise 乳酸与其间隙 {level=2}
一名休克患者乳酸9 mmol/L而阴离子间隙只有16。两个机制解释这一失配，另一个实验室假象解释常见的相反图形。说出三者。
::: solution
第一机制：**间隙与乳酸是两种货币**——一毫摩尔乳酸一毫摩尔阴离子，但间隙被稀释在**细胞外容积**（20 L）里而碳酸氢盐下降由总缓冲空间分摊；早期复苏**把乳酸从缺血床冲洗出来**，其代谢再生碳酸氢盐却慢。第二：**低白蛋白血症**每低于4.0一g/dL掩盖约2.5个间隙单位（白蛋白20 g/L的脓毒患者藏着约5个单位——校正强制，[[#thm-read]]第4步）。假象：动脉标本**肝素过多**（留在床旁的液体“气球”注射器）稀释并加入阴离子——血气上假高的间隙与假低的碳酸氢盐；相反的经典——搁置暴露空气的旧标本假**高**碳酸氢盐（CO₂逸出升pH并降实测pCO₂——酸碱实验室存在的意义就是巡查分析前误差）。解释规则：没有白蛋白、氯与采样史，从不审计一个间隙。
:::
:::

::: exercise 不存在的阴离子间隙 {level=2}
Na⁺ 132、Cl⁻ 112、HCO₃⁻ 14、葡萄糖28、甘油三酯40 mmol/L、pH 7.24、乳酸1.1。“间隙”是6——高氯性酸中毒伴“正常”间隙。然而这位患者有高阴离子间隙。解释两个骗局。
::: solution
间隙的两半都是谎言。**低白蛋白血症的假性正常化**（设白蛋白约20 g/L⇒藏5个单位——第4步的校正）与**测定方法的假性低氯/高氯**：间接离子选择性电极法（脂质过多时的火焰光度时代钠）——甘油三酯40 mmol/L时**假性低钠血症**压低报告的钠（间隙的分子假性低）而氯常正常报告，把约24的真实间隙压塌到6。用**直接电极或血气电解质**（不受脂质体积影响的液相测定）及乳酸、酮体、渗透压间隙、水杨酸组合核实——这里的渗透压间隙（实测对计算）是呼叫毒理科之前需要的第三道筛查。临床规则：对休克、脂血、低白蛋白与大量输注者，未校正的间隙是不可靠数字——[[clinical-skills/patient-safety]]的分析前一章，酸碱版。
:::

::: exercise 设计代偿研究 {level=2}
你要在清醒人体测量酸负荷的肾代偿。输什么、测什么、多长时间窗，第一小时与第三天尿pH、铵与可滴定酸各会怎样？
::: solution
标准化酸：**氯化铵**（口服或静脉——代谢成HCl伴氨排出，故加质子而不加未测阴离子；老的肾酸化临床试验）或膳食酸模型；固定盐水使容量与氯不是变量。**第1小时**：缓冲主导——碳酸氢盐降约2–4、pH降、通气分钟内上升（Kussmaul），尿pH向5下降（H⁺-ATP酶激活很快），但**铵排泄尚未上升**——净酸排泄只轻度增加而可滴定酸受磷酸盐限制。**第1–3天**：谷氨酰胺转运体（B0AT1）与产氨酶的适应性转录程序开机，**铵排泄上升数倍**（现在是酸排泄的主体，其碳酸氢盐出现在血浆——缓慢的“再生”组分），尿pH到底约4.4、由新来的氨在那儿缓冲它（游离H⁺之路贡献<0.1 mmol/日），血浆碳酸氢盐恢复到新稳态。测量输出：系列血气（碳酸氢盐、pH）、尿净酸排泄（pH可滴定酸+NH₄⁺−HCO₃⁻）与平衡框架；曲线的两相——即时的尿酸化、延迟的铵适应——就是**分泌快、生成是适应性**的生理学证明，也是近端碳酸氢盐重吸收与远端酸化两章从解剖上做过同一区分（[[renal/tubular-function]]）。
:::
:::

::: exercise 枸橼酸盐、碱与结石 {level=2}
枸橼酸钾被给草酸钙结石与尿枸橼酸低的患者。从口服剂量追踪生理到尿，并解释为什么碱负荷是要点而钾是第二重红利。
::: solution
枸橼酸被吸收后，在酸中毒或低钾状态被**近端小管更贪婪地重吸收**（钠-二羧酸转运体NaDC1，经胞内酸化上调其转录与膜插入而被酸中毒上调）——故尿枸橼酸低是**胞内酸负荷的标志**（也是造成同一胞内酸转移钾耗竭的标志）。小管液中的枸橼酸是尿的钙螯合剂：它把腔内钙螯成可溶复合物，故**可电离的钙可与草酸配对的更少**——低枸橼酸尿于是是真正的成石风险，而给予枸橼酸来纠正（在肝代谢成碳酸氢盐——每个枸橼酸产生三个碳酸氢盐，一个移除近端枸橼酸重吸收刺激的碱负荷，于是枸橼酸现在逃进尿里去做它的螯合工作）同时攻击标志与机制。用钾而非钠有两重要紧：钾盐纠正钾耗竭的胞内酸中毒（[[#def-kidney]]的H⁺/K⁺转移），而钠负荷会把钙拖着走（盐-钙耦合，这就是同一逻辑支持枸橼酸钾优于枸橼酸钠、及噻嗪降低尿钙的原因）。碱还碱化尿液，有助尿酸与胱氨酸溶解（与[[#ex-salicylate]]同一离子捕获物理）——一个分子治四种结石体质。一张处方里的肾生理。
:::

::: exercise Stewart异见 {level=3}
Peter Stewart的物理化学进路主张[H⁺]由强离子差、pCO₂与总弱酸（A_tot）设定——碳酸氢盐是因变量。把它与本章的Henderson–Hasselbalch教学调和，并给一个Stewart观点做出正确预测而碳酸氢盐观点错失的临床病例。
::: solution
两种说法解的是**同一个平衡系统**——一个完整的物理化学描述（电中性、质量作用、质量守恒）可以重排成任一组自变量，预测相同；不同的是**你在床旁实际能固定哪些量**。Henderson–Hasselbalch把pCO₂与HCO₃⁻当独立对，因为肺肾控制它们、测定报告它们。Stewart的变量——**强离子差**（[Na⁺+K⁺+Ca²⁺+Mg²⁺]−[Cl⁻+乳酸⁻+…]，必须由弱酸阴离子与碳酸氢盐平衡的净固定电荷）、**pCO₂**与**A_tot**（白蛋白、磷酸盐）——在输液选择设定它们的另一意义上是独立的。差别成为临床的病例：**心外科后pH迟迟不纠正而“碳酸氢盐正常”的患者**——病因是盐水的氯负荷（SID塌缩、碳酸氢盐看似寻常的高氯性酸中毒：碳酸氢盐观点说数字接近正常，而SID观点从电解质差直接预言酸的下降）与白蛋白稀释——A_tot下降造成**低蛋白血症性碱中毒**，藏在氯的后面——现代复苏以平衡晶体优于0.9%盐水（SMART与SPLIT试验小而真的酸中毒与肾损伤信号）就是一张**Stewart处方**：以乙酸根、葡萄糖酸根或乳酸根作可代谢阴离子而非氯，把强离子差保持在约38 mmol/L。调和之语：碳酸氢盐是生理学测量之处，强离子差是药理学发力之处——而任何同时用过碳酸氢盐与盐水碱化患者的临床医生，都在同一小时里使用两种表述。
:::
