自主神经系统是身体的自动驾驶：一组脊髓、脑干与下丘脑环路，在意识水平之下调节内脏，在不同位置、不同受体上使用与躯体系统相同的递质（乙酰胆碱、去甲肾上腺素）。其解剖解释其药理——每药作用于何处，取决于哪个神经元向哪个受体释放哪个递质——而其反射解释其病理：几乎每一个自主症状都是一条反射在其弧线的某一处对着病变正常地运行。

本章讲授交感与副交感两部分的结构方案与化学传递、神经节与终末器官生理、心血管控制连同压力反射的中枢整合，以及肠系与临床分部。

## 方案

::: definition 两级传出链 {#def-plan}
神经节前神经元（**交感**在中间外侧柱T1–L2；**副交感**在脑干III、VII、IX、X与S2–S4核；**肠系**系统是自成一体的肠壁神经系统，自有反射弧并接受两部分的调制输入）向神经节内节后细胞的**烟碱（Nₙ）受体释放乙酰胆碱**；节后**交感**神经元向α与β肾上腺素受体释放**去甲肾上腺素**（汗腺除外——解剖上交感、传递上胆碱能（M₃），以及肾上腺髓质——一个分泌肾上腺素与去甲肾上腺素入血的改良神经节）。节后**副交感**神经元向**毒蕈碱（M₃主导）受体**释放乙酰胆碱。推论机械地跟随：交感效应**弥散而整体**（短节前纤维多节后靶；循环儿茶酚胺到达每细胞；肾上腺素受体无处不在），副交感**离散而分区**（长纤维至终末神经节服务一个器官——眼可以缩一块肌而心照常跳）；自主轴突的**串珠状膨体**意味着递质在毫米范围以容量方式而非点状接头起效，这就是两类受体亚基与局部血流共同塑造反应、阿托品效应按副交感张力而非受体分布呈器官特异性的原因。
:::

| 特征 | 交感 | 副交感 |
|---|---|---|
| 起源 | T1–L2侧角 | 脑干III、VII、IX、X；S2–S4 |
| 神经节 | 椎旁/椎前，近脊髓 | 近靶或在靶内 |
| 节前递质 | ACh→Nₙ | ACh→Nₙ |
| 节后递质 | NA（汗腺、肌血管舒张为ACh） | ACh→M |

| 纤维长度 | 节前短、节后长 | 节前长、节后短 |
| 张力 | 血管交感张力（缩血管）主管血压 | 迷走张力在静息减慢心率 |

## 神经节、受体与共传递

::: definition 神经节传递 {#def-ganglion}
自主神经节是整合中心而非中继：每个节后细胞取样10–50条节前纤维，其输出由三种电导设定——**快EPSP**（Nₙ通道上的ACh，那个药物敏感的烟碱性突触，其阻断剂是六甲溴铵，如今只剩副作用的临床意义）、**慢EPSP**（毒蕈碱M₁，关闭K⁺漏；数分钟；神经节能在节前齐射之后久久放电的原因）与**长时程IPSP**（含DLC的LNPI细胞；间质细胞的多巴胺与γ-氨基丁酸）。共传递在两部分都是常态：输精管与膀胱小动脉的**ATP伴去甲肾上腺素**（α₁非依赖的嘌呤成分，在人膀胱与缺血时要紧）、唾液与阴茎舒血管神经的**VIP伴乙酰胆碱**，以及**NANC（非肾上腺素能非胆碱能）**肌间兴奋与抑制神经——其递质分别是P物质/脑啡肽与NO/VIP。Dale定律的修订版：一个神经元在其全部终末释放其全部递质，而反应是靶的受体集。药理章节一个突触一个突触地开发这一解剖——[[pharmacology/autonomic-drugs]]。
:::

## 中枢整合：血管运动系统

::: definition 压力反射弧 {#def-baroreflex}
动脉压在秒的尺度上由**颈动脉窦**（Hering神经→舌咽）与**主动脉弓**（迷走）的高压牵张感受器保卫，其放电率随跨壁压，投射到**孤束核**，后者兴奋**尾端腹外侧延髓**（GABA能）从而抑制**吻端腹外侧延髓**——那个脊髓交感张力中枢，其下行缩血管与心加速驱动在静息紧张性活动（交感缩血管张力握住容量血管、设定总外周阻力）——并解除对**疑核/背运动迷走**神经元的抑制。结果：**压力升→迷走性心动过缓与交感撤除**，两个搏动之内；**压力降→相反**。该弧增益高（开环三分之一压的变化产生近乎完全代偿的纠正），数日内向既有压力重置（这就是高血压不被该反射治疗、顽固性高血压试验外科减压带压力感受器颈动脉窦的原因），而其失效定义了下面的临床综合征。
:::

::: theorem 在患者身上读一个反射 {#thm-reflex}
压力反射是定量的临床仪器。去氧肾上腺素丸剂使MAP从90升到120 mmHg而心从75降到55：**反射增益=ΔHR/ΔMAP≈每mmHg −0.67次**；阿托品取消心动过缓（它是迷走性的），普萘洛尔直到阻断β受体本身都让低血压的心动过速完好（传出支是两条支）。立位应力是同一弧线到极限：站立使500–700 mL淤积于腿与内脏床，静脉回流与每搏量下降、收缩压下探、卸载反射发射——**心率升≤20、舒张压升、收缩压在20 mmHg内**为正常；**三分钟内降≥20/10 mmHg而无心率代偿**是神经源性体位性低血压（反射弧本身断了——多系统萎缩、糖尿病自主神经病），**升≥30次/分而血压不降**是体位性心动过速综合征（弧完好、代偿过度——去适应、低血容量、小纤维神经病、活动过度的结缔组织）。同一逻辑在自主衰竭中定位病灶：**卧位血浆去甲肾上腺素低、站起几乎不升**=节后（外周）衰竭；**正常到低、不升、神经节反应完好**=中枢/节前（MSA）。直立倾斜台、Valsalva（I相压力、IIa机械/IIb早期恢复、III释放、IV过冲伴反射性心动过缓——每一相都是一次弧线完好试验）、深呼吸心率变异（E:I比，糖尿病最早的迷走神经病标志）与定量交感神经轴突反射试验，是床旁量化的反射。
:::

::: example 成风暴而来的压力 {#ex-pheo}
一名43岁患者每次十分钟的搏动性头痛、心悸、大汗与苍白，血压220/130；单给β受体阻滞剂反而更高。
::: solution
这次发作是**嗜铬细胞瘤**在脉冲儿茶酚胺——三联（头痛、汗、悸）加阵发性高血压，及一个向不断清除再装载循环分泌肿瘤的“发作”生理（单给β阻滞剂的灾难就是本章受体逻辑成十诫的版本：β₂介导的血管舒张与心输出量被阻后，α₁收缩的血管面对无处可去的循环肾上腺素——压力上攀；**先α阻滞（酚苄明，一个靠不可逆跑赢儿茶酚胺浪涌的共价拮抗剂），再β阻滞对付反射性心动过速，然后加盐、手术**）。诊断镜像机制——**血浆游离甲氧基肾上腺素类**（肿瘤儿茶酚胺在胞内被COMT持续代谢，变肾上腺素是防漏标志）、尿分馏甲氧基肾上腺素类，然后CT/MRI与MIBG找那10%双侧、肾上腺外、恶性与家族性的，加上使每个病例成为家族筛查的RET/VHL/NF1/琥珀酸脱氢酶遗传学。围术期生理是整章的临床面孔：插管与碰瘤的浪涌（加深麻醉、危象用酚妥拉明或硝普钠或镁），然后是瘤被夹闭后的塌陷（儿茶酚胺撤入一个长期收缩、容量耗尽的循环——补液并渐停α阻滞）。影像上偶然发现的血压正常病例同样检测，因为未治疗的发作也就是卒中、夹层与肺水肿文献所称的起病。
:::

::: example 自我豁免的瞳孔 {#ex-pupil-sparing}
一名六十岁糖尿病患者的右睑下垂、眼位下外斜伴双影——但瞳孔对光反应正常、调节正常。
::: solution
这是把动眼神经当血管图解的解剖：**副交感瞳动纤维走在神经表面**、由软膜血管供应，而提肌与内直肌上直肌下直肌的躯体纤维深在束内。**微血管缺血**（糖尿病、高血压）梗死滋养血管的核心——躯体纤维死、表面纤维靠软膜弥散获救：疼痛性上睑下垂与眼肌麻痹**而瞳孔豁免**。**压迫性**病变（后交通动脉瘤、钩回疝）由外向内打击——瞳孔先去（外科红线：新发大固定瞳孔的动眼麻痹是今天的影像，不是观察），因为救了糖尿病患者瞳孔的同一表面位置判了这个死刑。瞳孔记录仪就是本章教条的应用：传出弧（Edinger-Westphal→睫状神经节→突触后M₃）用光、用近反射与药理滴眼 检验——胆碱阻断的散大瞳孔对毛果芸香碱收缩差，而睫状神经节去神经的**强直性Adie瞳孔**对使正常眼无动于衷的稀释甲胆碱收缩，这条超敏试验由写下体位性浪涌的同一受体上调定律写成。
:::

::: example 流的鼻涕与垂的眼睑 {#ex-horner}
一名58岁吸烟者左睑下垂、瞳孔小且在暗处扩得慢、与右眼相比暗处变化小、左面无汗；头痛与臂痛先来。
::: solution
三个体征是一个病灶的**眼交感通路**：睑下垂（Müller肌，交感性睑板平滑肌——轻，与提肌麻痹不同）、**缩瞳**（扩瞳肌瘫痪而括约肌——副交感、M₃——自由运行，故暗中差别更大的参差瞳：“交感麻痹在暗处显形”），及**无汗**（汗腺纤维在颈上神经节之后随颈动脉外膜走行——其有无定位病灶）。**肺尖Pancoast瘤**连同第一胸交感流出一起抓住该通路（C8–T1臂痛是根侵犯）——本章解剖预言、胸部CT必须排除的经典序列；颈动脉夹层是另一个急诊（痛、Horner，然后是内膜撕裂正在预告的卒中）。药理学确证跟随传递：**可卡因4%**阻断去甲肾上腺素重摄取、扩正常瞳而不扩一个本无交感驱动的瞳（Horner阴性）；**羟苯丙胺**从节后终末释放储存——扩张把病灶定位到第一或第二级（节前，储存完好），不扩张标记节后。同一组患者的流鼻涕——血管运动性鼻炎、味觉出汗（腮腺术后的Frey综合征：耳颞副交感纤维异常再生到汗腺，一个潮湿体征写尽异常再生主题）——提醒这些是平滑肌与腺体的反射，重新接线时天生会错。

::: example 不稳定的脖子 {#ex-barofailure}
一名喉癌颈部放疗十年后血压狂野波动——激动时收缩压220、吗啡后90——伴心动过速，无体位性下降。
::: solution
这是**压力反射衰竭**：放疗（或颈动脉手术、颈清扫、双侧颈体瘤）摧毁传入神经或窦压力感受器本身，于是把压力摆动变成纠正的那台缓冲器没了——动脉压变成**开环**，随任意中枢指令与体液系统给什么跑什么（激动-浪涌、镇痛-塌陷图形），失去迷走缓冲的固定心动过速与**完好**的交感传出功能（故无体位性低血压——与[[#thm-reflex]]传入完好/传出已死综合征的诊断性对照）。检查显示签名：对去氧肾上腺素与硝普钠的心率反应缺失或反常（压力反射斜率被压平），治疗是中枢给不了的药理性缓冲——可乐定与其他中枢性交感抑制药（它们恢复的增益是脑干自己的，这就是苯二氮䓬与控制传入风暴也有效的道理）、长效优于短效，并避开正是为相反生理设计的压力感受器神经毁损术（其患者被人为做成了这一种）。本例是反射弧方法的底片：每个自主综合征都按哪条肢体沉默而命名，而两级方案是让句子可读的语法。
:::

::: history
分部解剖属于十九世纪——Goll与Flexner的交感链，以及**Langley**精确的1898–1903刺激与变性实验：定义节前/节后之分、命名自主神经，甚至预言其化学传递。**Loewi**1921年的迷走灌注证明副交感递质是体液物质（乙酰胆碱，携Dale自己更早的工作）；**Euler父子**1946年鉴定去甲肾上腺素为交感递质，完成化学方案；**Cannon**的“应急”下丘脑整体放电学说及其去神经超敏定律（滴眼试验与体位性浪涌背后的受体上调生理）统治整合时代；现代篇章属于**中枢自主网络**——从脑岛、杏仁核与导水管周围灰质经RVLM的解剖追踪，解释了情绪、疼痛与呼吸为什么拨动脉与压，以及自主反射亢进综合征为什么归下丘脑而不归神经节。
:::

## 肠系分部与肠

::: definition 肠自己的神经系统 {#def-enteric}
肌层之间的**肌间（Auerbach）神经丛**主管动力（兴奋性运动神经元：ACh与P物质到平滑肌；抑制性：NO与VIP——口侧胃的容受性舒张与下食管括约肌的开放，其丧失给出[[gastrointestinal/oesophagus-stomach]]的贲门失弛缓）；**黏膜下（Meissner）神经丛**主管分泌、吸收与局部血流；**Cajal间质细胞**是起搏器，其慢波（胃3次/分、十二指肠约8次、沿肠下降——组织蠕动的那个梯度）去极化合胞体朝阈，只有兴奋超过它们才出锋。内在初级传入神经元在黏膜与肌肉启动蠕动反射（肠的“感受野”），该系统含约2000万–1亿神经元——多于脊髓——及身体的大部分5-羟色胺与相当的多巴胺，是“第二大脑”文献与5-羟色胺能药物肠病之源。迷走与交感输入**调制而非指挥**：没有它们肠的反射仍完整，这就是移植与去神经留下动力（紊乱但存在）、而内在缺失——**先天性巨结肠**神经嵴迁移入直肠失败、节段越长越近端的无神经节细胞——给出不排胎便的新生儿（直肠活检的金标准：无黏膜下丛、肥大的神经干；拖出手术）。
:::

- [x] 靶细胞表达哪种受体亚型、静息时运行着什么张力

两部分都带着乙酰胆碱在某个环节到达；靶以受体集与静息张力决定：窦房结**静息在迷走张力下**（阿托品加快率；交感效应只在应激下出现），皮肤血管在**交感缩血管张力下**（阻断致血管扩张与体位性跌落），成人支气管**静息基本无迷走张力**（阿托品作用寥寥；胆碱能支气管收缩大多是病理的——哮喘反射弧的迷走成分）——胃壁细胞则被迷走ACh（M₃）、胃泌素与组胺汇聚到一个钙-cAMP整合器上。自主药理中有临床意义的病灶是受体或张力，上表两者皆非地图——[[pharmacology/autonomic-drugs]]逐药算清。

## 通向何处

受体与药物细节在[[pharmacology/autonomic-drugs]]；血压控制的循环一半在[[cardiovascular/circulation-blood-pressure]]；作为内分泌器官的肾上腺髓质在[[endocrine/adrenal]]；胃肠运动生理回到[[gastrointestinal/digestion-absorption]]；排尿的脑桥弧在[[renal/urinary-tract]]；糖尿病的自主表现在[[endocrine/diabetes-complications]]。

::: summary
- 两条链、一种化学：到处是烟碱性神经节上的ACh，然后靶上是去甲肾上腺素（交感，弥散整体）或乙酰胆碱（副交感，分区离散）——连同界定临床图景的例外（汗腺、肾上腺髓质、共传递）。
- 自主神经节在做整合（快慢EPSP、抑制弧），而串珠状容量传递意味着设定效应的是受体、血流与张力，不是接头解剖。
- 动脉压由压力反射逐秒保卫（孤束核→CVLM→RVLM→脊髓，伴迷走传出）；其增益可测、随慢性压力重置，其失效定位为体位性低血压（神经源性、肾上腺素能衰竭）或POTS（代偿过度）。
- 共传递（ATP、VIP、NO、NANC）使膀胱、肠与性器官在药理上是三靶器官而非两靶。
- 肠神经系统在反射层面自主、只在张力上被指挥——其起搏器、中间神经元与神经嵴来源胞体使动力既是肠病也是神经系统的病。
:::

## 练习

::: exercise 说出部位 {level=1}
说出以下各处的递质与受体：神经节、皮肤交感血管、汗腺、心窦房结、支气管肌、逼尿肌、膀胱颈/前列腺、骨骼肌舒血管纤维。
::: solution
神经节：**ACh-烟碱（Nₙ）**；皮肤血管：**NA-α₁**（某些床有ATP共传递）；汗腺：**ACh-M₃**（交感胆碱能——汗动功能的阿托品试验）；窦房结：**ACh-M₂**（迷走，I_f与K⁺）加交感的**NA-β₁**；支气管：**ACh-M₃**收缩（也管黏液）与**β₂**舒张（肺从肾上腺拿的循环儿茶酚胺之路）；逼尿肌：**ACh-M₃**收缩（副交感；梗阻/膀胱流出道时有ATP嘌呤成分）；膀胱颈与前列腺：**NA-α₁**收缩（坦索罗辛的靶）；骨骼肌舒血管：防御反应中的**交感胆碱能（M₃加共释放的舒血管组）**——运动的“肌泵”与肾上腺素β₂成分合力，也是血管的α阻断不取消运动性充血（局部代谢物驱动）的原因。
:::

::: exercise 两滴眼药 {level=1}
一名参差瞳患者双眼滴4%可卡因：右扩左不扩。然后左眼滴羟苯丙胺：仍然无反应。定位病灶并给两个病因。
::: solution
可卡因扩瞳失败证明左侧**无交感通行**（Horner——可卡因阻断重摄取，需一个正在释放去甲肾上腺素的终末才起效）。羟苯丙胺从完好的节后终末释放**储存的**去甲肾上腺素；之后仍不扩意味着储存没了——**节后（第三级）**病变。病因：**颈动脉夹层**（痛、紧急的那个）、海绵窦或眶尖病变（伴其他颅神经），及旧清单里星状节以下节前图形的肺尖或纵隔蔓延（在羟苯丙胺后会扩张）。余下两种可能被序列排除：正常瞳对可卡因扩张，一/二级Horner对羟苯丙胺扩张——加上0.1%肾上腺素复核（慢性节后病变的去神经超敏使稀释肾上腺素使患瞳扩张而正常眼无动于衷）。
:::

::: exercise 紧张性与时相性 {level=2}
从张力教义解释：(a)为什么阿托品加快心率却很少降低血压；(b)为什么自主衰竭造成体位性低血压却卧位高血压；(c)为什么糖尿病患者的静息心动过速是早期征象。
::: solution
(a)**心在静息 占优势的迷走张力下运行**（压力barostat的副交感支）；**循环在交感缩血管张力下运行**、几乎无副交感血管输入——阿托品移走前者（率升）而没有血管张力可移（压几乎不动；是α阻滞剂的地盘）。(b)神经源性衰竭中压力反射的效应器已死：站立卸载而无代偿——静脉淤积、压降（体位性低血压）；平卧移除重力梯度，**上调α受体的去神经超敏**加上仍在起作用的任何残余体液儿茶酚胺过度收缩一个已中枢化的容量——卧位高血压，米多君时代的管理陷阱（夜间床头抬高、睡前不给药）。(c)长度依赖神经病中迷走先衰（心的长副交感弧）；静息失去刹车使交感与固有频率无对抗——**静息心动过速与丢失的深呼吸变异（E:I比<1.1，最早可测的自主体征）**，先于造成体位跌落的那场节后肾上腺素能衰竭。三个体征，一部教义：**功能是经受体集的紧张性活动，故病灶的顺序就是纤维的长度。**
:::

::: exercise 反射亢进发作 {level=2}
一名T6脊髓损伤男性股骨骨折后搏动性头痛、损伤平面以上出汗、血压240/130——并伴心动过缓。逐弧解释整幅图景及其治疗逻辑。
::: solution
在损伤平面以下保留完整的脊髓压力反射弧里，**没有下行抑制**：骨折的伤害输入激发节段性交感浪涌——平面以下大规模缩血管与压力尖峰；压力反射测得压力并在**平面以上**反应（迷走性心动过缓、头颈臂的血管扩张与出汗——患者学会畏惧的“平面以上潮红出汗、平面以下苍白干燥”签名），但脊髓无法把抑制送到内脏流出道。治疗是反着走弧线：**扶坐患者**（体位性卸载），移除扳机（膀胱要导尿管——最常见原因——骨折的痉挛、粪便嵌塞），然后速效血管扩张剂（历史上舌下硝苯地平、硝酸酯、肼屈嗪、二氮嗪）削减浪涌直到伤害刺激消失；长期避免扳机，麻醉推论（平面以上的椎管内麻醉阻断传出弧）——与交感阻滞下血管手术所用的同一椎管内麻醉逻辑。
:::

::: exercise 嘌呤与残余 {level=2}
梗阻的人膀胱对单用毒蕈碱拮抗剂反应差，而α阻滞与β₃策略的表现就像有第二套收缩系统参与；糖尿病患者的膀胱大而松弛。给出生理学理由。
::: solution
膀胱有**三层递质**：逼尿肌的M₃收缩（正常人为主）、来自上皮下传入-运动偶联的**ATP/嘌呤（P2X）**成分——在正常成人膀胱中小，但在**梗阻、去神经与年龄中大幅上调**（使抗毒蕈碱治疗显得不完整的“嘌呤迸发”——也是P2X3拮抗剂类别作为过度活动靶点被追逐的历史，其传入靶点不带口干），及驱动感觉与不稳定的**感觉支**（尿路上皮ATP与TRPV1信号传入）。糖尿病的大而松弛的膀胱是另一种病：**自主（与感觉）神经病**——传入胀满感丢失（故巨大容量与残余量）与传出收缩丢失——故治疗是行为性（定时排尿、二次排尿）与清洁间歇导尿而非药物；而过度活动的神经病性逼尿肌（损伤平面以上，如卒中后）才是抗毒蕈碱/β₃（米拉贝隆舒张）与肉毒毒素的地盘。全部临床药理按本章的问题划分：**哪条弧的哪条肢体断了**——见[[renal/urinary-tract]]。
:::

::: exercise 读Valsalva {level=2}
预测四相血压与心率曲线：(a)纯自主衰竭（节后）；(b)传出完好的压力反射衰竭；(c)低输出心衰。
::: solution
正常曲线：I相压力瞬变；IIa下降伴反射性心动过速（机械性）；IIb持续低压伴维持的心动过速与上升的总外周阻力；III释放性跌落；**IV相过冲**（过度收缩的血管床加重新充盈的心）**伴反射性心动过缓**——IIb与IV是肾上腺素能传出试验，心动过缓是心迷走试验。**(a)自主衰竭：**压力在II相进行性下降（无缩血管）、无过冲、无反射心动过缓——方形不见了的地方呈V形；卧位去甲肾上腺素低。**(b)压力反射衰竭：**缩血管与频率变化发生（传出活着）但**不受调制**——IIb与IV夸张而不稳定、没有平滑的心动过缓；曲线的噪声就是诊断。**(c)心衰：**过冲迟钝而心动过速夸张——低每搏量放大每一相、压力反射增益下降（中枢重置、颈动脉僵硬）、增高的肌神经反射驱动追加频率，这个图形追随β阻滞剂试验列为预后指标的交感神经过度活动。三条曲线、一个手法，两级弧在床旁十五秒内被审问完毕。
:::

::: exercise 冷、压力反射与老年 {level=2}
一名78岁因前列腺增生服哌唑嗪者，颈动脉窦僵硬、低肾素容量扩张，午餐后几乎跌倒。把四项生理组装成一次跌倒。
::: solution
餐后低血压：内脏血管扩张（消化的**肠系与VIP/嘌呤舒血管**支）使500–700 mL淤积于肠；正常人靠**压力反射介导的交感激活**代偿（心率与阻力上升）。本患者每个要素都在削弱代偿：**老年僵硬的压力感受器与低增益**（每mmHg传入放电更少）、**哌唑嗪**阻断α₁传出支（医源的那个，首剂后与高碳水午餐后最糟——葡萄糖-胰岛素-内脏机制）、低肾素容量扩张使压力反射成为唯一有效的杠杆（血管紧张素II对交感输出的支持已关机）。治疗照单读回：少量低碳水餐、餐前饮水（渗透-压力反射的容量负荷升压）、餐后平卧、移除α阻滞剂或换尿道选择性药物移到夜间。本例是老年处方形式的压力反射定理。
:::

::: exercise 设计自主功能实验室 {level=3}
设计一个五项组合，沿本章轴线（传入小纤维、中枢、节前、节后肾上腺素能、胆碱能汗动）定位病灶，并给出纯自主衰竭（节后）、多系统萎缩（中枢/节前）与糖尿病神经病（长度依赖混合）的预期图形。
::: solution
(1)**小纤维传入：**定量感觉检查、皮肤活检表皮内神经纤维密度与激光诱发电位。(2)**心迷走（传出副交感）：**深呼吸E:I比与Valsalva IV相心动过缓——迷走弧增益。(3)**交感肾上腺素能：**Valsalva II–III相与过冲（传出缩血管完好）、手指光电容积描记，加**卧立位血浆去甲肾上腺素**——定位杠杆：卧位测不到且不升（节后缺失，**纯自主衰竭**）对有而升幅迟钝（中枢，**MSA**），后者卧位压常保留-伴高血压、过冲存在而压力反射斜率平（传入完好、中枢整合死、传出活）——两行完成MSA/PAF鉴别。(4)**汗动：**QSART（节后胆碱能——从足起的长度依赖**糖尿病神经病**中减低，心迷走早失、肾上腺素能晚失）与体温调节出汗试验。(5)**瞳孔与写皮反射**作为定位补充——交感皮肤反应与冷加压升压。预期图形：**PAF**=卧位NA低、无过冲、QSART异常（神经节在外周的病）、心迷走早期保留；**MSA**=NA大致正常、卧位高血压伴过冲迟钝、QSART正常（外周完好）、脑干反射异常；**糖尿病**=各支均呈长度依赖梯度，心迷走最先。组合之所以奏效，因为本章的传出链是可逐段测试的串联，每段病灶都把邻居的体征留作对照——整门课程一直在用的反射弧方法。
