每两个神经元之间——以及每条运动神经与每根肌纤维之间——都横着一道二十纳米宽的间隙，电信号在其上翻译成分子信号再翻译回来。突触是神经系统完成其大部分计算与几乎全部药理学之处：它是麻醉药、镇痛药、抗焦虑药、抗精神病药、抗癫痫药、农药与神经毒气的靶；它的失效名为重症肌无力，其中毒名为肉毒中毒；而它的可变性——释放与反应的活动依赖增强减弱——是记忆的物理基础。

本章讲授化学突触的机制、量子传递及其安全裕度、抑制与反转电位逻辑、递质及其家族，以及突触前调制与可塑性。

## 化学突触，逐步分解

::: definition 突触序列 {#def-sequence}
到达的动作电位开放聚集在**活跃带**的**电压门控Ca²⁺通道**（P/Q型与N型）；局部Ca²⁺在毫秒内于感受蛋白（**突触结合蛋白**）处升至数百微摩尔，驱动**SNARE复合体**（囊泡上的突触小泡相关膜蛋白、膜上的syntaxin与SNAP-25）以对该Ca²⁺微域**四次方协同依赖**的关系融合突触囊泡——单个锋电位释放轴突终末易释放池数百个囊泡中的几个。递质在数十微秒内跨裂隙扩散、作用于**突触后受体**（离子型——配体门控离子通道，毫秒；代谢型——G蛋白偶联，数十毫秒到分钟），随后被**重摄取转运体**（DAT、SERT、NET、谷氨酸的GLT-1入胶质细胞）、**酶解**（神经肌接头与胆碱能突触的乙酰胆碱酯酶；肽类突触 径直扩散而去）或**扩散**终止。囊泡循环随后在数十秒内回收膜与SNARE（内吞蛋白、发动蛋白、Hsc70去衣），储备池按需动员——下一节测量的就是这台机器的统计学。
:::

::: definition 电突触与混合传递 {#def-electrical}
**缝隙连接**（连接蛋白构成的连接子；无脊椎动物为innexin）以几乎零延迟代谢性与电性地偶联细胞，双向或（亚基组成不对称时）整流：它们主导心肌（闰盘——[[cardiovascular/cardiac-cycle]]的功能合胞体）、平滑肌、星形胶质网络、若干脑干逃生回路与下橄榄计时网络；也允许使胶质成为合胞体性钾缓冲系统的代谢偶联。一些系统两者兼有（鱼类Mauthner细胞与甲壳类强直屈肌的经典混合电-化学突触），而间隙性偶联——活动对邻近膜的电场效应——已被承认存在于大脑高电阻的胞外空间、锥体细胞层所在之地。电突触传导快而不能放大，故中枢神经在需要计算处用化学传递，心脏在需要速度与统一处两者都用。
:::

## 量子传递与其裕度

::: definition 量子、包与安全系数 {#def-quantal}
突触后电位是**颗粒状的**：最小单位是**量子电位**——一个囊泡内容物的反应（神经肌接头**终板电位**处为几十毫伏，中枢神经元处为毫伏的几分之一），以类泊松的随机过程释放。**运动终板的终板电位**是约50–100个量子（量子含量）释放的总和，产生约40 mV去极化、以数倍**安全系数**引爆肌纤维——即使一半乙酰胆碱受体被阻断、一半钙内流被移除，接头仍工作。中枢突触反着精打细算：每锋**一个到几个量子**，释放概率约0.1–0.5，兴奋0.1–1 mV——皮层传递是设计上不可靠的，靠汇聚（数千输入）、靠回返环路、靠短时程可塑性挽救；同一统计学在抑制的相反方向，解释了为什么去极化中间神经元的高频爆发能否决一个锥体细胞，而单次释放事件不能。
:::

::: example 两种疲劳，一个接头 {#ex-junctions}
一名45岁女性睑下垂与双影、傍晚加重；一名60岁吸烟者近端无力、运动最初几分钟*好转*并口干；一名30岁在食用家庭罐装食品后下行性瘫痪。
::: solution
三位患者坐在同一装置的三个点上。**重症肌无力**——抗突触后烟碱型乙酰胆碱受体（或MuSK、LRP4）自身抗体——减少可用受体：终板电位仍求和但其安全系数已被花掉，重复活动（释放自然衰减下的一连串失败）把终板电位压到阈下、纤维失败——故易疲劳性无力、冰袋试验的物理（降温靠减慢通道动力学改善安全系数，与Uhthoff相反的同一生物物理），与重复神经刺激的诊断性增量。**Lambert-Eaton肌无力综合征**——抗突触前P/Q型Ca²⁺通道抗体，多为副肿瘤（小细胞癌）——减少量子**含量**：最初几下失败，但活动数秒内积累的残余钙（破伤后易化）募集释放，故肌力随用力*好转*，而自主症状（口干、阳痿）反映自主突触里的同一通道。**肉毒中毒**——梭菌轻链在胆碱能终末裂解SNARE蛋白（按型裂解SNAP-25、突触小泡相关膜蛋白、syntaxin）——干脆取消释放，弛缓性瘫痪伴瞳孔散大与球部呼吸衰竭，抗毒素只阻止进一步结合，恢复要等新终末出芽数周。模式识别规则：**眼起病的易疲劳无力——自主起病的破伤后增强——自主与瞳孔起病的下行性瘫痪**，分别是突触后、突触前钙、释放机器病变，各有确证电诊断签名与不同治疗（免疫治疗与吡啶斯的明；3,4-二氨基吡啶延长突触前去极化加免疫治疗；抗毒素与通气）。
:::
:::

## 抑制、反转电位与氯的调定点

::: definition 反转电位逻辑 {#def-reversal}
一个突触的符号不由其递质而由其受体的**反转电位**相对静息位决定：谷氨酸门控通道（AMPA：Na⁺/K⁺，E≈0 mV）去极化——**兴奋性突触后电位**；GABA_A与甘氨酸通道（Cl⁻，E_Cl在静息附近或其下）超极化，或更常见于成人皮层，**分流**——把膜钳在反转电位、短路同时的兴奋（使抑制超过其超极化之和的“电导阻断”）；K⁺电导的抑制反应（GABA_B经GIRK，E_K≈−90 mV）缓慢而持久地超极化。发育性的**钾氯同向转运体开关**（NKCC1高、KCC2低的新生儿神经元积累Cl⁻、把E_Cl翻到静息之正）使GABA**在未成熟神经系统中去极化**——是兴奋性的，这就是新生儿惊厥调用不同药物（苯巴比妥经GABA_A的去极化与长通道开放）的原因，也是升高胞内氯的制剂（KCC2操作）是实验性促惊厥剂、而KCC2上调是内源性抗惊厥方向的原因。GABA_B的代谢性抑制，突触前（阻断Ca²⁺通道）与突触后（GIRK），是巴氯芬与痉挛环路的慢抑制，在丘脑皮质中继神经元则连同T电流构成纺锤/失神振荡机器——其专章在[[nervous-system/epilepsy]]。
:::

::: theorem 汇聚与符合：神经元决定什么 {#thm-integration}
一个皮层锥体神经元接受约7000个突触，多数带棘而兴奋性在树突，抑制性的部署讲究——靶向胞体的吊灯（轴-轴）细胞在锋电位诞生的起始段、篮细胞在胞体周边负责符合窗口控制、靶向树突的中间神经元门控单个分支。因为兴奋向胞体静电学衰减而**抑制性分流作用在决策点**，又因为**树突棘内的NMDA受体检测前后符合**（去极化解除Mg²⁺阻断、钙内流作指令信号——Hebb突触、LTP与学习的基础——低而慢的钙升高则产生LTD），神经元不是求和节点而是两层网络（树突计算分支级的非线性、锋电位回写可塑性），胞体是其输出级。
:::

::: example 百毫秒的窗口：前馈抑制 {#ex-window}
刺激穿通通路在齿状回颗粒细胞诱发5 ms达峰的兴奋性电位与8 ms起始的抑制性电位；细胞只在缝隙内兴奋获胜时放电。
::: solution
这是**前馈抑制**——传入兴奋主细胞，同时以略长路线（经自身高电导、Kv3驱动高频放电的快放电篮细胞）并行驱动胞周GABA_A抑制，把兴奋截短。结果是**狭窄的符合时间窗**、对锋电位时序而非频率的精确控制——且因为抑制在胞体锋电位进入区分流（[[#thm-integration]]）——一个同步而精确的输入变成输出、弥散输入被抑制的除法电路。这一生理有临床的声音：篮细胞的parvalbumin系统、其NMDA轻/AMPA重的快速传递与其在精神分裂症的脆弱（GABA能中间神经元假说及其振荡与γ波段后果）、在颞叶癫痫（胞周抑制丧失与齿状回再兴奋）、在苯二氮䓬药理（镇静的含α1受体对解除焦虑的α2/3与遗忘的α5——同一批受体作为那个窗口，被亚基分别调音）。教训又是缩微的定理：**环路的符号是其电导的时序**，而迟到三毫秒的抑制不是刹车而是节拍器。
:::

::: example 突触前调制，两种药 {#ex-presyn}
吗啡压抑胶状质的痛中继；α₂激动剂右美托咪定与可乐定压抑交感流出并产生伴镇痛的镇静；N型钙通道阻断剂齐考诺肽虽是阻断每个神经元都需要的通道却成为最后手段的镇痛药。用同一原理解释。
::: solution
原理是**经位于终末的受体与通道的突触前抑制**，特异性由定位提供。阿片μ受体（Gi偶联，突触前关闭Ca²⁺通道、突触后开放GIRK）密集分布于初级传入终末与胶状质痛投射神经元的树突：谷氨酸与P物质的释放恰在伤害性信息首传之处下降，而呼吸与奖赏回路的受累是同一地理的剂量限制性一面。**α₂受体**在去甲肾上腺素能与痛通路中间神经元终末，减少交感传出与下行调制系统的释放——故镇痛伴镇静（蓝斑）与心动过缓和口干。**齐考诺肽**来自芋螺肽，阻断N型Ca²⁺通道本身——上述释放机器的正是该通道——而因为它**鞘内**给予，它到达治疗窗所在的后角终末，其全身或中毒效应（把其限制于输注泵与难治病例的精神与运动毒性）表明该通道的无处不在只能靠给药途径来逃脱。靠定位的抑制，三种药理：受体、受体、孔道——以及一堂课：中枢药物的兴亡在其解剖梯度，而不只在其分子靶。
:::

::: example 音量旋钮：溢出与张力性抑制 {#ex-spillover}
小脑颗粒细胞与海马齿状回颗粒细胞维持持续的、不脱敏的GABA_A电导，设定其输入电阻并阻尼兴奋性；据说麻醉药与乙醇夸大的正是类似之物。
::: solution
该电导靠**溢出**运行：逃离突触裂隙的GABA激活**突触外、高亲和、含δ亚基的GABA_A受体**，它们不脱敏、维持一个张力性的内向漏（未成熟时去极化、成人时分流），可达细胞总电导的百分之几——一个兴奋性的**音量旋钮**，与突触电流那离散、时相性的按键判然不同。这一生理解释了一门药理：神经类固醇与某些麻醉药（依托咪酯、丙泊酚、临床浓度的卤代药）优先增强张力性电流，而δ亚基敲除小鼠对某些镇静与遗忘效应抵抗；乙醇对同一受体的作用有其脱抑制与共济失调的分子贡献。同样有病理：同一胞外GABA蓄积由胶质转运体调节（GAT-1/3——抗癫痫药替加宾的靶），而转运体失灵、或设定张力的电导本身失灵，在不同的环路里把网络增益推向或拉离惊厥——本章的反转电位与汇聚定理再次宣告：大脑的兴奋性与其说是胞内化学，不如说是胞外化学。
:::

- [x] 接头处每纤维的量子含量与安全系数高、中枢处每输入低——以可靠性换调制性、整合性计算的权衡

- [ ] 中枢突触是电的

::: history
Sherrington在任何人看见突触之前命名了**突触**（1897，“战栗臣服之地”）；化学教条在与电学论战后存活，直到Otto Loewi 1921年的迷走神经灌注实验证明体液传递（1936年诺贝尔，以及那个想法来自他写下又几乎忘掉的梦的故事）。Fatt与Katz及Miledi在整个1950年代在终板证明量子释放—— 微型终板电位、二项统计学、钙依赖——Eccles则自中枢一侧把运动神经元的抑制与兴奋突触后电位做到同一结论（1963年诺贝尔，与Hodgkin和Huxley同享）。Arvid Carlsson证明多巴胺本身就是中枢递质（2000年诺贝尔）、Ulf von Euler的去甲肾上腺素、Katz与Burgen的后续世代绘出各家族；Kandel的海兔工作（2000年与Price、Greengard同享诺贝尔）把记忆定位于活动依赖的突触增益变化；NMDA受体的Mg²⁺阻断与钙通透（Nowak、Mayer、Ascher，1983–84）提供了Bliss与Lømo 1973年长时程增强早已暗示的符合检测器；Südhof、Rothman与Scheller的SNARE机器（2013年诺贝尔）完成了释放机制——在生理学已描述其统计学二十年的生物化学之后。
:::

## 通向何处

神经肌接头的肌侧在[[physiology/muscle]]；自主递质在[[physiology/autonomic-nervous-system]]；受体类别与药物靶在[[pharmacology/drug-receptor]]；重症肌无力与Lambert-Eaton在[[nervous-system/neuromuscular]]；肉毒中毒与破伤风的毒素与临床章节在[[infectious-diseases/fever-sepsis]]。

::: summary
- 突触传递是钙驱动、SNARE执行、四次方协同的胞吐，随后受体激活与快速终止——每一步都是药靶或毒靶。
- 传递是量子性而随机的；神经肌接头以巨大安全系数买可靠，皮层以低释放概率与海量汇聚买可塑性。
- 抑制由反转电位与分流定义而非分子；新生儿氯开关使GABA兴奋性，而起始段的抑制管住输出。
- NMDA受体读符合——Hebb突触、Mg²⁺阻断、作为LTP与LTD指令信号的钙，以及作为其病理性过导的兴奋毒性。
- 递质分成家族，其合成、囊泡装载、终止与受体签名几乎一一对应到临床药理。
- 突触前调制（自身受体、轴-轴突触前抑制、阿片、α₂激动剂、芋螺肽）在解剖集中之处调增益，这就是中枢药物效应跟随受体梯度而非分子普遍性的原因。
:::

## 练习

::: exercise 量子算术 {level=1}
神经肌接头处量子电位0.5 mV、终板电位30 mV。量子含量是多少？细胞外钙减半时它如何变化（假设四次方律）？
::: solution
含量=30/0.5=**60个量子**。钙减半使释放正比于$(1/2)^4=1/16$，故约4个量子——终板电位约2 mV：远在阈下、接头失败（经典实验；该制备耐得住50%受体阻断却耐不住50%钙减少的原因；低钙、镁过多与Lambert-Eaton都在同一统计学步骤表现为传递失败的原因）。
:::
:::

::: exercise 终止作为药靶 {level=1}
新斯的明、沙林、阿托品与普立非多都作用于乙酰胆碱的处理。各自指派一个环节，并预测其效应的毒蕈碱对烟碱主导性。
::: solution
**新斯的明**（可逆氨基甲酸酯类胆碱酯酶抑制药、季铵故留在外周）——到处延长内源性ACh：毒蕈碱样（心动过缓、分泌、肠道、缩瞳）与烟碱样（增强肌无力肌；过量致去极化阻滞与束颤）；**沙林**（不可逆有机磷——磷酸化酯解位点然后“老化”）——同样而全部且持久：SLUDGE/BUNBE毒蕈碱危机加烟碱性瘫痪（中枢呼吸暂停、气道闭合与膈肌麻痹构成的致死性呼吸混合）；**阿托品**（仅毒蕈碱拮抗剂）——干燥分泌、纠正心动过缓而对烟碱性接头无作为（有机磷患者仍需肟类的原因）；**普立非多**（老化前给药可再生酶）——攻击病因。这个划分是分子尺度的解剖：毒蕈碱对应副交感效应器图景，烟碱对应神经节与接头图景，脂溶性药物对应中枢（东莨菪碱可过、阿托品部分、格隆溴铵完全不）。
:::
:::

::: exercise 抽搐的新生儿 {level=2}
用本章的氯生理与受体亚基解释，为什么地西泮与苯妥英——成人惊厥的支柱——是糟糕的新生儿抗惊厥药。
::: solution
新生儿神经元**NKCC1高、KCC2低**，积累胞内氯，故E_Cl在静息之正、GABA_A开放**去极化**；苯二氮䓬策略（放大本该超极化的抑制）因此在氯层面薄弱或自相矛盾，而新生儿GABA_A受体的亚基构成（富含α2/α3、苯二氮䓬敏感性不同且脱敏更快、α1较低）削弱药物的效价曲线。苯妥英的钠通道阻断又因通道亚基的未成熟表达、及临床文献中飘忽的药代动力学而更吃亏。实践照此行事：苯巴比妥仍是新生儿首选之一，部分因它作用于未成熟受体的长通道开放与非突触受体——发育中脑的氯与亚基生物学 规定药物清单，是发育生理书写处方集的实例。
:::
:::

::: exercise 兴奋毒性 {level=2}
缺血性卒中里谷氨酸杀死半暗带。从突触到孔道追踪机制，并说出使死亡级联有选择性的受体与离子。
::: solution
缺血使泵停摆；GLT-1胶质摄取的逆转（及神经元释放与囊泡漏）抬高胞外谷氨酸，而去极化移除**NMDA受体的Mg²⁺阻断**——那个设计为只在前后活动一致时才开的符合检测器，到处地、无休止地开放。NMDA通道的**钙**内流（其Ca²⁺通透性就是选择性）触发线粒体通透性转换、一氧化氮合酶、脂肪酶蛋白酶与活性氧的产生；周围突触的AMPA成分驱动保持NMDA门不上锁的去极化——半暗带的扩散性去极化。治疗推论全在这条链上：NMDA拮抗剂临床失败（这通道是人人的，副作用窗消失），而成功的干预——再灌注、溶栓、取栓——在钙级联既遂之前恢复血流：本章要点，一件生理装置（符合检测）在错误的时空就是病理装置（兴奋毒性死亡）。
:::

::: exercise 自身受体 {level=2}
定义自身受体在增益控制中的角色，并用于解释：(a)为什么低剂量安非他明的初始效应可以温和、高剂量却大量动员储存而释放；(b)为什么SSRI不立即增强突触5-HT——以及伴随治疗时滞的受体延迟变化是什么。
::: solution
**自身受体**（突触前与终末多巴胺的D2/D3；胞体与树突的5-HT₁A、终末的5-HT₁B）报告胞外递质并对放电与释放**负反馈**——突触自己的增益盘。(a)安非他明逆转转运体并置换囊泡储存（VMAT抑制）；低释放速率时自身受体环把胞外多巴胺钳得很死，只有当释放压倒反馈时洪流才变得可见——阈值药理学。(b)SSRI数小时内升高胞外5-HT，但该升高**激活抑制性树突自身受体5-HT₁A**、减少中缝放电、部分抵消突触增益；随长期治疗自身受体脱敏（下调需1–3周），而终末5-HT₁B与突触后5-HT₁A以不同方式适应——抗抑郁时滞公认的细胞学解释，其治疗后果是最初数周带着副作用（恶心、坐立不安、突触后5-HT₂A与外周受体同样过度释放所致的初期焦虑）先于疗效。
:::

::: exercise 破伤风对肉毒 {level=2}
两者都是裂解SNARE的梭菌神经毒素；肉毒造成弛缓瘫痪而破伤风造成强直痉挛。从突触向外解开悖论。
::: solution
两者都是释放机器的锌蛋白酶，但其**细胞进入路径不同**：肉毒毒素在中枢突触不能越过血-神经屏障，作用于**胆碱能运动终板与自主终末**，阻断ACh释放——弛缓性瘫痪、干瞳孔、抗胆碱样的肠道。破伤风痉挛毒素在运动终板被摄入、**跨突触转运进脊髓的抑制性中间神经元**（RAB3相关的进入，正是它随后裂解的机器——突触小泡相关膜蛋白-2），阻断Renshaw与Ia抑制性中间神经元的甘氨酸与GABA释放：运动神经元**无 inhibition** 地运行，产生共收缩强直、牙关紧闭与苦笑面容、角弓反张与自主风暴。两个证明机制部位的细节：破伤风保存神经肌传递本身（终板对神经刺激反应正常——痉挛在中枢），而潜伏期跟随转运距离（伤口越近中枢，病得越快）。治疗不对称随之而来：伤口清创、甲硝唑、中和未结合毒素的人免疫球蛋白、对付脊髓去抑制的苯二氮䓬、自主神经的监护——以及对一种其毒素是已知最强细菌蛋白的疾病绝对有效的疫苗，这就是全部论证的一句话版本。
:::

::: exercise 读配对脉冲 {level=3}
神经传导研究报告配对脉冲比（PPR）——20–50毫秒间隔下第二次反应除以第一次。预测a)突触前Ca²⁺通道抗体、(b)突触后受体阻断、(c)琥珀胆碱样去极化药的PPR变化；并从钙与安全系数的生理各加论证。
::: solution
逻辑：20–50毫秒时第二次刺激受益于**残余突触前钙**（易化），而终末的钙通道部分失活；初始释放概率低则易化大（高PPR），初始概率高则抑制占优（低PPR）。(a)**突触前钙通道病变（Lambert-Eaton）：静息PPR升高伴运动后或破伤后显著恢复**——低释放概率、大易化——与低静息CMAP并列的电诊断签名。(b)**突触后受体阻断（肌无力）：静息PPR接近正常**（释放正常；终板电位在安全系数被一连串活动花光时更常通不过阈值检验——故慢速重复刺激的递减而非配对脉冲签名；纯突触后病变不应、也基本不会改变配对脉冲比）。(c)**去极化阻滞（司可林）：纤维被保持在去极化态、钠通道失活，两次反应同等下降——最初无衰减的一致性抑制**；长时间暴露后（“II相”脱敏阻滞）强直后四个成串刺激出现模仿非去极化阻滞的衰减，而真正突触前病变所显示的破伤后易化始终缺席——把去极化性膜失效与释放失败或受体丢失分开的图形。该检查的临床价值在于PPR是*突触前*探针，任何*突触后*机制的疾病都不碰它——本章的释放算术转换成一台电诊断仪器。
:::

::: exercise 设计一个突触 {level=3}
你在设计实验证明一个新发现的中间神经元与锥体细胞形成的是电而非化学突触。给出四个决定性观察及各自的操纵。
::: solution
(1)**潜伏期**：电偶联配对显示近乎零、无潜伏抖动的传递（亚毫秒，在生理温度范围内与温度无关）；测量潜伏期分布以替代化学传递长而可变时延——电偶联几乎没有任何抖动。(2)**双向性**：A细胞的锋引爆B细胞，B的锋又以同一潜伏期引爆A——双向传递；化学突触是单向的（靠控制哪只细胞被电流钳固定来检验）。(3)**钙无关性与温度**：化学释放需要外部Ca²⁺且强烈依赖温度；电传递在0-Ca²⁺/无钙/EGTA灌流液中持续、只轻度依赖温度——并且决定性地被**缝隙连接阻断剂**（羧苯磺胺、甲氟喹，或connexin36敲除）取消，而细胞自身兴奋性不变。(4)**装载示踪剂的配对记录**：注入一侧细胞的生物胞素或神经生物素出现在偶联的伙伴（染料偶联——同一通道导过的代谢偶联），双电压钳记录到线性的、不受递质-受体鸡尾酒（CNQX/AP5/荷包牡丹碱/ATP阻断剂介质）影响的缝隙电导 $g_j = I/(V_1 - V_2)$。四次操纵、四张已发表论文的图、一个结论：如果连接是双向的、瞬时的、钙无关的、对阻断剂与敲除敏感且染料可通的，突触就是电的——最初证明甲壳类屈肌与Mauthner细胞混合传递的同一逻辑。
:::
