职业精神是前七章变成一个机构的那一章：保密、同意与坦诚之所以是可执行的、而不是可 aspirational 的、是因为存在一个“拥有执行它们的机器”的职业、而那台机器被信任或不被信任的原因、是它在“信任很昂贵”的时候如何表现。**本章涵盖诸职业的社会契约（特许、职责、以及执行）、发声与揭发、与产业界的关系及利益的冲突、复认证与评估及能力的职责、监管在各国如何处理能力受损与不当行为、以及坦诚与“公正文化”。**

::: definition 职业的契约及其执行 {#def-compact}
**职业精神最好被理解为一种交易、而不是一种风度：社会把近乎垄断的特许授予一个自我治理的行业谁可以执业、部分在市场之外定价、控制准入、持有信息不对称与保密的知识、以换取市场与纯粹的法律无法提供的能力、利他与自我监管——份历史的“以患者为中心、而不是以特权为中心”的宪章语言、“职业精神作为社会契约”的文献、以及批评者的提醒：这一契约在历史上交付的是“带光环的寡头垄断”注册法专业控制的起源、行业工会的经济学、以及“伦理准则作为准入壁垒”的历史。现代执行的堆栈有三层值得区分：雇佣与评估的治理临床谈判与具名的高级临床医师的系统——在信任崩塌之后的架构里、“具名的临床医师”是问责单位的最小单位、外部的监管注册作为公共的保护、而不是成员体的荣誉、配有“执业的适格”的机器——监管者的改革规划正在搏斗的那个“医师不安全的阈值对医师无礼的申诉捕获”的问题、“无过错与低门槛与早期解决”的诸提案、以及“监管者惩罚沟通的失败多于惩罚认知的错误”这一发现：这个体制宁愿制裁无礼的人、也不愿修好疲惫的人、以及法律职业者自己的刑事暴露——虚假的证明与处方及账单的欺诈、以及对行为不当的起诉、以及监管者日益并行的程序做法。这一契约当前的摩擦：坦诚的职责“成文法与职业准则”的时代一项在法律上要在出问题时告知患者、并道歉和书面陈述的职责——其合规审计发现“通知的那一半在起作用、而道歉的那一半是真诚的”、以及那场防御性医学的争论从未真正被回答、因为关于诉讼节省的数据一直是含糊的——但伦理从来不是关于诉讼的、复认证与评估的系统“三年一周期的带多源反馈”的架构——在英国的案例之后国际的扩散、及其评价：对认真的人有用、对其他人是戏剧、作为信任的指标则昂贵、以及透明的浪潮结局与投诉的公布、“具名的顾问医师与外科审计公布”的政策。**
:::

::: definition 发声：揭发与为患者说话 {#def-speak}
**揭发的法律与职业的职责、保护的“在内部的通道失效或本身就是问题时、报告危险”这一行为；医学自己的经验供给了这个领域已确立的诊断：典型的失败不是勇气、而是结构——那条穿过“被报告的人”的报告通道、那个起着压制作用的“就地解决”的期待、任何具名的独立接收者的缺席、以及把关切归档为“人际冲突”的文化。按比较的法律与实践文献、能起作用的保护架构是：一条在管理链条之外有接收者的“受保护的披露”的路径监管机构、申诉专员、具名的官员、起效迅速反报复的临时保护、因为报复很快、而诉讼很慢、“对迫近的患者危险的合理相信”这一门槛——并不要求揭发者是对的在不完整的信息上作出有害的依赖、本是临床远见通常的状态、带反馈回路的保密与匿名的通道从金融监管输入的“发声”的改革、“心理安全”的测量的文献及其与结局的相关、以及每个系统都忽略的那“对报告采取行动”的一半如今安全监察机构公布的那份“收到的报告、未采取行动就关闭”的审计。职业职责的边缘是对同事的转介之问这一章邻近的那个定义里最难的动作：对一位不安全的同事提出关切的职责、首先指向“面对患者的即刻”现在就停止临床的暴露——名单、监督、解除职责的路径、然后是当本地的回应缺席或自我保护时向正当的机关、而“同侪情谊对忠诚”这一论证、在每一部于“沉默曾是造成伤害的机制”的案例之后写成的准则中、都被判给沉默的对面。个人代价的记账不是可选的伦理：揭发者的健康与家庭与职业生涯的结局、就是社会向保护它人开出的道德账单、而本章职业伦理的判决是：机构由“那个提出投诉的人后来怎么了”来评判、这就是为什么“对员工的坦诚以及对患者的坦诚”这一框架、以及“公正文化”的模板谴责系统、除非个体的行为越过了界限——不安全行为的那架十进制的阶梯。**
:::

::: definition 产业界、礼物与利益的冲突：影响的诚信 {#def-conflicts}
**医学对产业界的依赖研究的资助、器械、处方集的供应、培训课程与会议的生态、使“利益冲突的管理”成为一项核心的职业能力、而不是一个礼节问题、而其证据基础并不含蓄：处方与处方集的行为会随哪怕微小的款待而移动“一支笔与一顿午餐与会议室的座位”的文献、产业界支付公开披露数据集的发现——“小额支付、最多的条目、最大的总额”这个形状、指南与共识小组的捕获指南小组中的利益分析、以及世界卫生组织与医学机构关于冲突管理的标准——主席与投票多数的规则、而不是靠披露本身、以及代笔与“播种式研究”的机器“那篇发表就是营销”的案例、“被设计来奉承”的试验的注册审计、以及从赞助的专题会到处方集倡导的管道。监管回应的谱系：从“禁止一切推广的接触与多数由产业资助的继续教育”严格的机构与科室的政策、及其“教育活下来了的评价、经”披露一切并管理“登记与申报的模型——期刊的、委员会的、监管机构的申报架构、到”在公开的数据库里点名“披露作为社会规范的重造的假说、带着它那个诚实的发现：披露改变读者的信念、多于改变作者的行为。本章给个体临床医师的操作性规则：礼物的检验“如果这带着我的名字与他们的产品出现在当地报纸上、我会安然吗”、以及更严格的机构版本：不收个人礼物、也不去赴午餐、对自己处方关系的检验注意你选了却不曾注意到自己在选的那个药、并对着指南审计它、委员会的检验在讨论之前申报、而不是在发表时、并带有牙齿地回避主席与投票与起草、咨询之问由产业付费的讲者与顾问委员会的角色、作为个人的自由对机构的风险、“当你的专长被租出去时它属于谁”这个问题、以及“披露的诚实多于披露的数量”的规则一份“什么可能影响你”的真实清单、胜过一页谁也不会读的东西。**
:::

::: definition 复认证、评估与能力的职责 {#def-revalidation}
**职业者自己的能力、是这一契约的承重的义务、也是最不被信任的、所以现代的体制用“有记录的周期”取代了“假定的美德”：评估每年由雇主主持的谈话——负责官的结构、多源的反馈、个人发展的规划、以及对一份样本的外部审阅——及其被记录在案的弱点：愿意的人在那里勾选方框、对“看起来没事的挣扎者”没有信号、以及质量保障调查那个“评估作为鼓掌”的发现、复认证三年一周期的作品集与背书、以及“执业的许可的续期”这个提问——在英国模式之后的国际扩散、以及评价那句诚实的判断：它让公众安心的作用、多于它发现那个罕见的危险医师的作用——而这是一句设计的真相、不是一项指控、因为发现是监管者的职责、而“带一个触发点的安心”才是评估的职责、以及补救与不健康的路径每一个改革后的监管者如今都声称、而很少有执行得好的“先是健康、不是不当行为”的架构——“生病医师的政策”的文献关于医师为何向自己的系统隐藏疾病、以及“把雇主当作患者、而不是当作警察”的职业健康设计的修正。测量的问题是这个领域永久的尴尬：没有哪个体制能在“造成伤害的模式”的事件之前可靠地发现正在退化的临床医师结局的数据挖掘与同侪的比较、以及“统计信号对小样本”的文献——个体外科医师审计统计功效的问题、“按平均值监管”的批评者用麻醉与心脏外科提前退休的分析使它更尖锐、所以评估与复认证的诚实的设计目的是“一场有后果的、从而使早期的谈话成为可能的谈话”关于“在危机之前谈论退化”的训练、通向称职之处的同事关切的路径、以及“在监管者那里不出现意外”这个理想。文献生成的与培训生相关的职责：要知道你的评估是一份治理的文件写下你真正会执行的那个发展计划、说出你不会做的事、并收集那些会让你难受的多源反馈——“回避反馈作为安全风险”这一发现、最适用于你做得不错的时候、保持一份即刻的实践日志、因为复认证的背书与反思只有作为一种习惯才可信、以及把健康与成瘾及丧亲的问题当作职业的问题来处理。**
:::

::: example 那位具名临床医师糟糕的一周 {#ex-named}
你是某病房的责任顾问医师、而该病房的感染相关死亡在上升；你的医疗主任要求“在董事会之前给出临床治理的叙述”；两位住院医师分别互不知情地提到这个病房“在周末就不再升级”；而你自己的门诊审计恰好显示升级中的记录缺口。
::: solution
**问责而不找替罪羊（[[#def-compact]]、[[#def-speak]]、[[clinical-skills/patient-safety]]）：“具名临床医师”这个角色的意义恰在此刻：那个被要求的不是万能、而是精确的负责人、所以这份叙述的骨架是治理文献会奖励的那个次序：精确地描述这个信号这份感染的病例审计、带日期与升级的时间、而不是形容词、以及作为“一个可检验的假说”的那个周末的模式——来自两个独立的说法与你自己的数据、诚实地说出你自己这个部分的贡献用第一人称说那个记录缺口的发现——对你自己那一块的坦诚、正是为高于你薪级的部分买到可信性的东西、指明超出你权限的事你不掌握的人力编制与周末的决定权——这就是“负责官要有匹配的授权”这一论证、改革本应修好的东西、并承诺一个可测量的周期一套升级的方案、带周末的模拟演练、以及对“到抗生素的时间”与“到上级复审的时间”的审计、每月一块给董事会的仪表板。这一周需要的两场谈话：员工那一侧场“你们的关切就是证据、这是计划、而如果它不管用会发生”的会议、它把“害怕升级”转化为“带着支持的升级”、以及心理安全文献的发现：说出你自己也不具备的那个权限、正是让下级敢于说话的东西、以及面对患者的坦诚的职责死亡的家庭应得那个诚实的叙述、带着道歉、与“这是我们改变的东西”——因为法律现在这么要求、也因为另一条路就是那个教训教给世界的代价。让这个角色保持诚实的那条线：这份叙述带着你的签名、并附上它的数据附录送到董事会——不是“团队”、也不是让感染科邻近的服务主管组成一个合唱、而如果董事会想要一个咽喉、就把那个系统的设计的选择给他们那个由他们而非你做出的周末排班的决定、因为那才是责备真实的原因所在、也是唯一一种能改变下一个月的问责。**
:::

::: example 那个会议的邀请 {#ex-conf}
一家器械公司提出资助你们科室三个名额参加其国际专题会注册费、旅行、一家不错的酒店、并为你的顾问医师和你安排“讲者”的角色；而同一款器械正在你们机构的采购审查之中、你们俩发表文章的那本期刊要求披露利益的冲突。
::: solution
**款待的算术（[[#def-conflicts]]、[[#def-compact]]）：评判：这不是一份礼物、而是一段与采购相邻的关系、上面挂着两名临床医师、所以检验按次序运行：透明的检验公开的登记册会按名字记下它、并附上这家公司的产品、所以“没有人需要知道”这条路是不可用的、角色的检验在申办方自己的会议上做“讲者”是挂着一个证件的营销；真正教育性的讲者角色、经得起由大学或学会点名并由其支付、以及决定的检验你就在采购审查的影响半径之内——一旦审查启动、委员会的规则就把“回避或完全披露”这一岔路个人地适用于你。那个可允许的版本、因为纯粹主义也有代价科室确实需要的教育与网络与产业的伙伴关系：只接受你机构书面政策在事先批准之下允许的东西、把资金经由科室的教育账户、而不是个人的钱包、也不是旅行社的补贴、并把这层关系公布在采购的提交材料上、机构的登记册上、以及此后每一篇论文与每一次报告上、取那里的科学、不取那套豪华套房。结束这场谈判的那场与顾问医师的谈话：”这款器械也许对我们的患者好；如果我们接受这次出行、我们事后就必须能够这么说并被人相信——所以我们只在阳光下这一版下去、而无论哪种情形我都不会进入那个审查小组。“值得在你还在房间里时提出的系统修正：科室那条常设的”与产业界交往“的规则我们接受什么、从不接受什么、由谁书面批准——份让未来每一位副主任都免于同样那场周五下午之争的政策、以及采购办公室真能看见“这家公司带谁飞过”的那个机构级的登记册披露的架构只有当披露者与决定者读同一页时才起作用。**

::: example 那位手抖的同事 {#ex-tremor}
你们那位顾问医师的手抖在加重；本月两次中心静脉置管交给了第二位操作者；一名培训生提到停车时的剐蹭。此后你见过这位同事两次；他人缘很好、最近丧亲、而他在帮你准备清单。
::: solution
**忠诚是你为一个人做的事、不是你对他回避的事（[[#def-speak]]、[[#def-revalidation]]、[[#def-compact]]）：既勇敢又善良的次序：先和他谈、真正地谈一位同侪私下的一次谈话、不是一次代表团：用带日期的事实说出你看到的东西——置管的尝试、如果你们熟到可以谈就说停车、承认他的丧亲、并把那个请求作为医学来说出：一次健康检查、以及暂时减少需要他手操作的操作、用你希望一位同事对你说话时的说法；并带着“他也许早已知道”这个可能性去听他的回答、按行为、而不是按闲话升级如果他同意：支持那场与临床主管的谈话、在别人注意到之前把工作重新组织；如果他拒绝而尝试继续失败：职责已经越过他——向负责的临床医师或临床主管、用事实与日期、不用形容词、而中间那一步永远是临床的那一步：人操作现在由别人来做、这是一次排班的谈话、不是一项指控。“是健康、不是不当行为”这个框架不是软弱、而是流行病学（丧亲、抑郁、睡眠剥夺与神经系统的起病这一鉴别、正是为什么每一个改革后的监管者如今都运行健康优先的路径）；让你保持诚实的那条准则是：你的每一句话都不该关于“他是不是一位好医师”——而是关于“这双手今天能不能做这个操作”、因为这既是全部的问题、也是唯一给他的尊严留下立足之地的表述。不做的事：病房范围的耳语网络它把一个可解决的健康问题变成一场有观众的胜任力的法庭、先是匿名的信除非他对当前的患者构成即刻的危险、否则直接跳到“和他谈”、以及“我悄悄地替他把所有置管都做了”这种英雄式的自我掩护一种掩护会推迟唯一能帮到他的干预、也保护不了任何人的患者。这个系统为之而建的那个结局：在一个可治疗的阶段得到的诊断、他在知情同意而非被强行之下保留的调整后的实践、看着一位同事把它处理得当的培训生、以及他们将在三十年里彼此重新检验的那一课。**
:::

::: example 那条走红的好评 {#ex-viral}
一名患者关于“救了我的那位医师”的感恩视频在当地新闻里走红；片段拍到你们的病房、点名了你的住院医师、而医院的新闻办想转发它并引用顾问医师的话；那位住院医师有焦虑症、而并不同意为自己成为“那张脸”。

## 通向何处

患者安全的系统与人因学在[[clinical-skills/patient-safety]]、记录与交接的纪律在[[clinical-skills/records-handover]]、沟通中坦诚职责的应用在[[clinical-skills/communication]]、处方的冲突界面在[[pharmacology/drug-development-prescribing]]、研究诚信那一层在[[medical-ethics-law/research-ethics]]、而保密的执行在[[medical-ethics-law/confidentiality]]。

::: summary
- 职业精神是一份契约：以被特许的执业换取能力、利他与诚实的自我监管——而它的审计不是靠申报、而是靠“当发声要让说话者付出代价时会发生什么”。
- 执行的堆栈评估、监管、法律以可预测的方式失败——无礼被制裁、而疲惫被歌颂、复认证带来的安心多于它的发现——而称职的职业者对这套堆栈的盲点了解得足够深、以至于能刻意地报告进去。
- 发声的系统靠结构、而不是靠英雄主义起作用：独立的接收者、迅速的反报复保护、“合理相信”的门槛、以及“对报告采取行动”的审计；机构由那个提出投诉的人的命运来评判。
- 与产业界的关系是创新管道的价格、而诚信的工作是设计、不是禁欲：事先的批准、阳光下的登记册、有牙齿的回避、被隔离墙保护的教育、以及读者真正用得上的披露清单。
- 坦诚与具名的负责官的角色、把透明从美德变成例行；句道歉与那个诚实的叙述比一场调查便宜、而它们从来不是为了成本。
- 这一契约最后的检验是向内的：一个用“希望别人对自己有的那种同情”来监管成员健康、并在律师之前就读懂自己仪表板的职业、才挣得了它不断援引的那份自治。
:::

## 练习

::: exercise 定义这份交易 {level=1}
一名学生问：为什么医师“有自己的规则”、而不只是遵循法律与医院的政策。用九十秒给出社会契约的回答、并包括一个让这份特权不那么光彩的历史事实。
::: solution
**平实地解释这份契约（[[#def-compact]]）：”三样东西社会无法从市场或一般法律中获得：它无法检查那个缝合你肌腱的人是否称职（排队的人里没有谁能）、它无法阻止你利用患者的无知或她的秘密、它也迫使不了你在获得资格之后继续学习。于是社会委托：它让这个职业控制准入、设定标准、并自我监管——以换取把能力与对患者的忠诚、置于利益与方便之上的执业。段令人不适的历史：这份委托部分是以行业工会的保护赢得的——创建英国登记册的那部1858年的注册法、在此后数十年被收编为成员的特权、而二十世纪大量的自我监管保护执业者比保护患者更可靠；改革之所以存在、正是因为这种失衡被反复发现。这就是为什么现代的这份交易的执行既在外部也在内部——负有公共保护职责的监管机构、评估与复认证、坦诚法——也是为什么你真正会感受到的职业义务在造成伤害之后的坦诚、报告那位不安全的同事、拒绝那个被资助的周末、恰是你自己的利益与患者的利益分岔的那几个点。这份契约是真实的、它由那些不方便的行为来购买、而每一代医师继承它时都带着同一份“用小字写的审计职责”。“**

::: exercise 给诸系统评级 {level=2}
比较三条“对同事的关切”的路径：告诉顾问医师并寄望；医院保密的关切热线；监管机构的公共关切通道。就速度、保护、发现的能力、与患者安全的经济学为每一条评级、并给出你会教给实习医师的那条升级规则。
::: solution
**路径的法医学（[[#def-speak]]、[[#def-compact]]）：告诉顾问医师：最快、而且常常是对的多数关切是排班与负荷的问题、可以在本地解决、但当顾问医师本身就是那个关切时独立性为零、而且没有记录——这就是为什么它是第一步、而在危险持续时绝不是唯一的一步。热线：独立性与记录、但可信度各异热线在现实中的问题是行动那一侧的审计——“报告未采取行动就被关闭”的统计、使呼叫者失去可信度的匿名、以及教会员工“报告改变不了任何事”的那个反馈回路的缺席；发现的能力对模式尚可、对危机很差。监管机构的通道：当雇主不提供保护时、对那位“现在就危险”的同事正确的去处那个拥有“执业的适格”的权力与临时命令能力的公共保护的管辖、但按设计很慢它的门槛是公共的保护、不是人际的摩擦、而在没有反报复法律保护你时个人代价高昂。给实习医师的规则：面对患者的即刻停止暴露：临床上升级、名单与监督、那位有权暂停工作的值班顾问医师、今天就地留下记录事件报告与带日期的事实性的笔记——即刻的记录就是日后整个案件、以及当本地的行动没有在风险允许的时间内移动时走外部的路径——带着那两句让它可以存活的话：让你的报告保持事实、日期与副本、并知道你所在法域的揭发者保护的法律正是为“医院的忠诚看起来像对患者构成危险”的那个班次而存在的。**

::: exercise 为评估做准备 {level=2}
一名高性能的外科医师的评估文件：多源的反馈从未第二次索取、继续教育用会议的收据来记录、反思的条目都以“不需要任何改变”结束、而还有一个她从未打开过的处方离群报告。用一页纸把她教练到一份可辩护的作品集——并指出监管者会最先注意哪一项。
::: solution
**把评估当作治理、不是戏剧（[[#def-revalidation]]）：教练的一页：(1) 多源的反馈、要点在于摩擦这件工具能在看着你疲惫的团队里发现盲点与漂移的行为——所以向麻醉医师与手术室护士索取它、并把“回避反馈作为风险的信号”这一行带日期写进她的个人发展规划、(2) 继续教育的日志是投入、不是证据把两张收据变成一处她做出的改变：她采用或放弃的技术及其原因、她闭环了的那项审计——复认证标准那句“投入的证据、不是出席的证据”正是为此而存在、(3) 以“不需要改变”结束的反思、是这张表格在告诉你它没被读过一个真实的案例、带一次真实的不确定、以及她对此做了什么、值五段毫无瑕疵的文字——保护医师的作品集、是“学习看得见”的、(4) 那个处方离群的报告今天就被打开离群的报告是她的数据、要么是她的辩护、要么是她的起诉——经验法则：一位不能讨论自己仪表板的临床医师、在任何要紧的会议上都没有立场援引临床自主、以及 (5) 来自真正看见她的人的背书那位“靠猜测的负责人”是改革所针对的弱环。监管者的注意次序：先是那个未打开的离群报告一个未被审视的处方或实践的、正是造成伤害的调查里经典的先兆模式、然后是从未索取的反馈——那个回避的信号、正是当年的改革部分为捕获它而建造了评估。她那句诚实的反驳配得上诚实的回答：当什么都不取决于它时、这一切就是戏剧——这就是为什么这份作品集的价值在于：在它会被朗读出来的那一年它是可被发现的、而拥有一份真实文件的外科医师、是那次朗读后完好无损的人。**

::: exercise 写出那次坦诚的时刻 {level=2}
一次子宫切除术后的纱布遗留、在第4天被发现；患者现在脓毒症、被再次手术、正在恢复。她问：“你们怎么能这样对我？”写出这场谈话的结构：承载“坦诚的职责”的话、与违反它的两句话。
::: solution
**在伤害之下的坦诚（[[#def-compact]]、[[clinical-skills/communication]]、[[clinical-skills/patient-safety]]）：结构：坐下、自报身份、然后正面回答那个问题（是的、我们留下了它、绝不该发生、我很抱歉——法定职责设计的“道歉优先”的规则：说出发生了什么、说抱歉、不要用“但你也得理解”去给道歉加限定）、按今晚所知的程度给出叙述纱布计数是怎么出错的、诚实地说明未知之处、以及随后以书面的完整调查——因为这份草案不是这个故事的结尾、公平地陈述后果那次脓毒症与第二次手术对她的恢复意味着什么、以及对长期所知道的东西、实务的承诺一位具名的联系人、之后的会面、主动提供而不是等待的文书、以及她的病历及投诉与补偿的路径的解释——因为隐瞒路径的坦诚、是有礼貌的遮掩、以及那句改变的话间病房上已经有什么不同——这件事发生在她身上、而不是下一位患者身上、而预防是在伤害了某人之后唯一合乎伦理的用途。两句构成违反的话：“这样的事难免会发生”那种把责任化解于宿命的说法、被文献指认为患者会记很多年的那句与“因为律师的关系、我必须小心我说的话”句把道歉重构为策略、并在床边把这部法律的道德革命变成其反面的、防御性的自白。后续：数日内的书面叙述、真正共享的调查结论先通知、再把报告藏起来、就是重演那次违约、也是反复出现的调查展品、以及人员那一侧的支持“第二位受害者”的文献在那一天最适用于那台手术的团队、因为抛弃自己人的坦诚文化、会安静地不再是坦诚文化。**

**编辑部的诚信机器（[[#def-conflicts]]、[[medical-ethics-law/research-ethics]]）：记录优先的原则：科学的记录按证据被纠正、并与发现成比例——这个阶梯：关切声明一份“差异正在调查中”的通知附在文章上——当审计需要数月、而读者此刻就在处方时使用、更正或勘误注册的与发表的主要结局的不匹配不是一个笔误——注册处才是那份预先的承诺、而这个改变需要一份附在原文上的、公布的解释、或带理由公布的撤稿如果主要的分析未经注册被调换、而那个核心的主张建立在它之上——出版伦理委员会的流程图的存在、正是为使这一步是程序的、不是人身的。作者的程序：要求通讯与担保的作者提供统计分析计划、注册的记录、以及“谁分析、谁撰写”的文档；按期刊的政策、而不是稿件的题注重新运行申报；按规则点名那位医学写作人——“代笔”的发现本身很少导致撤稿、也很少导致惩罚、但那本账很重要。那些不属于你的职权、而每一项都要有具名负责人的转介：作者们机构的研究诚信办公室未申报的写作服务与结局的调换、属于他们的管辖、不是编辑的热心、批准这项研究的伦理委员会方案的偏离要送到他们那里、资助方以及任何“有申报依赖这一主张”的监管机构、以及注册处本身结果记录的纠正要经由申办方、而他们必须解释。保护期刊的那份透明：公布你自己处理的时间线发出关切的日期、作者的回应、最终的通知——“编辑维护的是记录、不是人”这个姿态既能扛住那封诽谤的信、更重要的是、扛住从这一页写出的下一张处方。**

::: exercise 处理监管机构的信 {level=3}
你收到监管机构在一封匿名投诉之后的要求：你的患者数量、一个他们视为离群的结局、三份临床信件、以及你的评估记录。你一贯谨慎地执业；而这封投诉点名了一起你至今仍在想的死亡。请回应：实务的步骤、你不该对自己隐藏的情感真相、以及你在法律上与明智上“可以不做”的事。
::: solution
**在信的另一侧（[[#def-compact]]、[[#def-revalidation]]）：实务的次序：确认它并把截止日写进日程监管机构“有期限、讲比例、有义务公正”、都由你排定的回应、而不是你的恐慌来更好地满足、按合同通知你的辩护组织或工会、以及你雇主的具名高级临床医师、因为你不知道的并行程序才是绊倒人的东西雇主在同一事件上可能有自己的职责、从原始来源而不是你的记忆收集记录即刻的记录、审计与多学科纪要、比你能想起来的最好的版本更能讲述这个案件、无论哪个方向、把那个统计的主张恰当地分析小分母的离群报告是有噪声的、而“按平均值监管”的批评在数字很少时是一种真实的辩护——但要让一个可信的人来做分析、并保留往来通信——为自己挑选统计学家、正是同事们因错误的理由被额外调查的方式、并按这个案件要求的书面形态作答每一位监管机构都说最重要的那种专业、不带情绪的语调、而临床医师恰恰对那件无法停止想的死亡做不到。不该向任何重要的人隐藏的情感真相：那件留在你心里的案子、与“是一名好医师”是同一件事、而不是有罪的证据“第二位受害者”与道德损伤的文献之所以存在、是因为这种“关切加暴露”的组合会安静地压垮人——职业健康或同侪支持或一条受保护全科诊断的路径、在临床上是明智的、不是策略性的。法律上允许而不明智的：不在正式的渠道之外与投诉人就投诉内容沟通接触会被读成恐吓、即使它是哀伤、不改写记录追溯填写的那一句会把一个临床的案件变成一个适格的案件、外加可能的欺诈——每一位辩护律师都会最先背诵的那条规则、以及在接受建议之前不签署一次安静的离职临床医师为了让它停下来而签的和解、会变成他们不知道自己在制造的公共记录。值得追求的那个结局：一份以监管机构自己要求的顺序展示“谨慎执业”的卷宗、以及一个在此之后仍在执业的你——因为这个过程既能让无辜者、也能让有罪者以糟糕的方式被存活、这正是“为什么这一契约的程序值得你完全的参与、即使它们感觉像是被这个职业背叛”的理由。**

::: exercise 设计那份政策 {level=3}
写下你们科室的“与产业界交往与透明”的政策：关于 (1) 教育的资助、(2) 个人的关系与登记册、(3) 委员会与处方集的冲突、(4) 研究的合作与发表自由、(5) 执行与复审，各一段——每一段都要有一句“连敌对的记者也改不动”的话。
::: solution
**一份有牙齿的政策（[[#def-conflicts]]、[[#def-compact]]）：教育的资助：”继续医学教育与教学由科室设计、由教员交付；产业界不向个人或课程直接资助任何款项、捐赠如有经由大学那笔不限用途的教育基金、资助方在公开的页面上被点名、而不对内容、讲者或主题拥有发言权“。个人的关系：”每一位临床医师每年把所有的产业界的支付、酬金、顾问角色与旅行申报进机构的登记册、按汇总公布、可按个人检索；在公开披露的数据库中被发现的未申报的关系、会触发对相关论文与相关委员会的自动重新申报“。委员会与处方集：”与某公司的任何角色、在其期间及之后一年内、取消就该公司产品担任主席、投票、评价或倡导的资格；回避被记录并公布在点名该产品的委员会纪要中“。研究的合作：”有资助的研究在大学或机构的合同之下运行、带注册的方案与预先设定的分析、数据由独立的保管、一条只允许三十天保密内容审阅的发表自由条款、按规则由具名担保人的署名含医学写作人的披露、而结果无论方向都发表；缺少条款的科室协议一律不签“。执行与复审：”本政策由研究诚信与治理办公室执行、拿公开的支付数据库与期刊的申报做抽样审计、公布年度的合规统计、声明一条从更正到免除委员会职务的惩戒阶梯、并由一个含患者代表且有权修正的小组做年度的公开复审“。给你自己留档的元教训：每一条款都是”为那些不信任你的人来检查“而写的——而这正是这个职业保住它自称珍视的那份自治的方式。**
