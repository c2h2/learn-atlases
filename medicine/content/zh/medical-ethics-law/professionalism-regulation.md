1984年至1995年间，在布里斯托尔皇家医院（Bristol Royal Infirmary）接受心脏手术后死亡的婴儿，比一个运作良好的单位预期的要多。一位麻醉医师斯蒂芬·博尔辛（Stephen Bolsin）收集数据并提出担忧达数年之久，才有人采取行动。由伊恩·肯尼迪（Ian Kennedy）教授主持、于2001年提交报告的公开调查没有找到某一个罪魁祸首。它描述了一种“俱乐部文化”、糟糕的团队协作、没有公认的结局监测方法，以及一个担忧无人倾听的体制。其建议重塑了NHS监测医疗质量的方式和医师受监管的方式。

患者把自己的身体、秘密和生命托付给医师。职业精神是这种信任的正当理由，而监管是社会检验这种信任是否名副其实的方式。本章涵盖职业精神的含义、英国如何监管医师、出现差错时的坦诚义务、提出关切、诚信与利益冲突、职业边界、医师自身的健康，以及适用于临床实践的刑法。

## 职业精神的含义 {#professionalism}

英国皇家内科医师学会在2005年把医学职业精神定义为“支撑公众对医师信任的一整套价值观、行为和关系”。这一定义着眼于信任：一个职业被授予某些特权，例如自我监管、从事某些工作的专有权利和高度的自主，作为交换，它承诺把患者的利益放在首位并保持高标准。

在英国，这些标准由**英国医学总会**（General Medical Council，GMC）在《良好医疗实践》（*Good medical practice*）中规定。现行版本于2024年1月30日生效，适用于所有在GMC注册的医师，也适用于自2024年12月起由GMC监管的医师助理（physician associates）和麻醉助理（anaesthesia associates）。

::: definition 《良好医疗实践》（2024年） {#def-gmp}
《良好医疗实践》在四个领域中规定了标准：

1. **知识、技能与发展**：提供良好标准的医疗，不断更新知识，认识到自己能力的限度，保持清晰的记录，安全地开具处方。
2. **患者、伙伴关系与沟通**：以善意和尊重对待患者，支持共同决策，尊重保密，公平对待他人而不歧视，并保持职业边界。
3. **同事、文化与安全**：营造积极的工作环境，提出关切并对关切采取行动，在出现差错时保持公开，并对欺凌、骚扰和歧视（包括性骚扰）采取行动。
4. **信任与职业精神**：诚实正直地行事，处理利益冲突，配合调查，并照顾好自己的健康。

GMC就知情同意、保密和生命末期医疗等主题发布的更详细的指南，解释了这些标准如何适用于具体情况。
:::

## 医师如何受监管 {#regulation}

GMC由《1858年医疗法》（Medical Act 1858）设立；现行立法是经修订的《1983年医疗法》（Medical Act 1983）。它的职能是维护医师注册名册，为执业和医学教育制定标准，并在医师的**执业适格性**（fitness to practise）受到质疑时采取行动。自2009年起，医师还需要持有**执业执照**。自2012年12月起，持照医师必须每五年进行一次**再认证**（revalidation），依据是年度考评、支持性信息（如患者和同事的反馈、重大事件和质量改进工作）以及一名**责任官员**（通常是其所在机构的医务主任）的推荐。

执业适格性听证由**医疗执业者裁判所服务处**（Medical Practitioners Tribunal Service，MPTS）主持，自2012年起它独立于GMC的调查职能运作。**专业标准管理局**（Professional Standards Authority）监督GMC和其他卫生专业监管机构。2026年，政府就改革GMC的立法框架进行了咨询，包括保护医师助理的职称；根据冷氏审查（Leng review，2025年），医师助理将更名为physician assistants。

::: theorem 监管的首要目标 {#thm-objective}
GMC在履行职能时，其首要目标（自2015年起规定于《1983年医疗法》中）是**保护公众**，包括：

1. 保护、促进和维护公众的健康、安全和福祉；
2. 促进和维护**公众对医学职业的信心**；
3. 促进和维护该职业成员**恰当的职业标准和行为**。

因此，执业适格性程序不是对过去行为的惩罚。它要回答的是，医师的执业适格性**目前是否受损**，以及需要采取什么行动来保护公众。
:::

::: proof
监管的目的解释了裁判所如何推理。由于目的是保护，裁判所着眼于未来：医师是否对出错的原因有认识（洞察力），是否已加以补救，是否可能再犯？一位犯了严重临床错误、承认错误、接受再培训并在此后安全执业的医师，可能根本没有受损；而一位犯了较小错误却否认并一再重犯的医师，则可能受损。

第二和第三项解释了为什么某些行为即使没有直接使患者处于危险之中，也会导致处分。不诚实、性不端行为或严重的刑事定罪，会削弱公众对医师整体的信心。一位捏造研究结果的医师可能在技术上是胜任的，但如果职业界容忍这种行为，公众就有理由对所有医师失去信任。这就是为什么即使临床工作合格，不诚实也常常导致除名。
:::

医师的执业适格性可能因以下原因而受损：**不当行为**、**专业表现不足**、**刑事定罪或警诫**、**不良的躯体或精神健康状况**、英语知识不足，或另一监管机构作出的裁定。可能的结果包括不采取行动、警告、商定的**承诺**、对执业施加**条件**（每次最长三年）、**暂停执业**（每次最长12个月）以及从注册名册中**除名**。如有必要保护公众，可在调查期间以临时令限制其执业。如果GMC认为裁判所的决定不足以保护公众，可以向高等法院提出上诉。

大多数向GMC提出的投诉并不会导致听证。许多投诉在本地得到解决，健康方面的问题通常通过商定的承诺和支持而不是处分来处理。

::: example 一位带着酒味的同事 {#ex-health}
一名基础培训医师注意到，她的专科住院医师本周有两个早班身上带着酒味，而且双手颤抖。今天他正要做腰椎穿刺。她应该怎么做？
::: solution
**即时安全**：患者安全第一。如果她认为他不适合操作，就不应让操作进行。她可以私下说：“你还好吗？我担心你现在身体状况不适合做这个操作。”必要时立即联系顾问医师。如果他坚持，她应立即上报。

**提出关切**：她应告知顾问医师或临床负责人，如实描述所观察到的情况（两次闻到酒味、手抖），而不是作为诊断。根据《良好医疗实践》，当她认为同事的健康或行为可能使患者处于危险中时，她有责任采取行动。

**对专科住院医师的支持**：酒精依赖是一种疾病。有成瘾问题的医师经过治疗通常能恢复安全执业。应支持他寻求帮助，例如求助于职业卫生服务和NHS执业者健康服务（NHS Practitioner Health）——一项为医师提供的保密服务。只有当患者面临严重风险或他不配合治疗时，GMC才可能介入；健康类案件通常以承诺而非处分来处理。

**对她本人的支持**：对上级同事提出关切是困难的。她可以向自己的教育导师、“自由发声守护人”（Freedom to Speak Up Guardian）或医疗责任保护机构寻求建议，并应记录自己观察到的情况和所采取的行动。
:::
:::

## 坦诚：出现差错时 {#candour}

医疗中的差错很常见，大多数是系统问题而非个人粗心的结果（[[clinical-skills/patient-safety]]）。临床医师如何应对差错，对患者、对学习和对信任都至关重要。

::: definition 坦诚义务 {#def-candour}
**职业坦诚义务。**当患者的治疗或护理出现差错，造成或有可能造成伤害或痛苦时，每一位卫生专业人员都必须对患者保持公开和诚实。他们必须告知患者（或在适当时告知与患者亲近的人），**道歉**，提供适当的补救或支持，并充分解释其短期和长期影响。这在GMC与护理和助产委员会（Nursing and Midwifery Council）的联合指南（2015年）中作了规定。

**法定坦诚义务。**在英格兰，在医疗质量委员会（Care Quality Commission）注册的服务提供者，根据《2014年健康与社会照护法2008（受监管活动）条例》（Health and Social Care Act 2008 (Regulated Activities) Regulations 2014）第20条，必须在发生**须通报的安全事件**（已造成或可能导致中度或以上伤害或死亡的事件）后，在合理可行的情况下尽快通知患者，如实说明经过，道歉，并以书面形式跟进。威尔士于2023年引入了机构层面的坦诚义务。
:::

道歉并不等于承认法律责任。根据《2006年赔偿法》（Compensation Act 2006）第2条，“道歉、提出治疗或其他补救，本身并不构成对过失或违反法定义务的承认”。因此，害怕诉讼不是回避说“对不起”的理由。得到公开解释和道歉的患者往往更不容易，而不是更容易，提出投诉。

英格兰NHS已用**患者安全事件应对框架**（Patient Safety Incident Response Framework，PSIRF）取代了旧的严重事件框架，该框架强调学习和系统改进，而不是追究责任。**玛莎法则**（Martha's Rule）在玛莎·米尔斯（Martha Mills）去世后自2024年起在英格兰的医院中推行，它赋予患者及其家属一项权利：如果担心患者病情正在恶化而未受到重视，可以要求进行紧急复核。

::: example 一次用药差错 {#ex-candour}
心内科病房的一名67岁女性，因药物医嘱单上的转抄错误，夜间被给予了双倍剂量的抗凝药。她没有出血，但凝血指标延长。书写医嘱单的二年基础培训医师（FY2）在早上发现了这一差错。应当怎么做？
::: solution
**患者安全**：立即评估她有无出血，寻求上级医师和药师关于监测以及是否需要逆转抗凝的建议，并调整方案。

**坦诚**：应及时告知她，最好由一名上级临床医师告知，FY2尽可能在场：发生了什么、这对她意味着什么、正在采取什么措施，并真诚地道歉（“对于发生这样的事，我很抱歉”）。解释应使用通俗的语言，并请她提出问题。触发职业坦诚义务的是潜在伤害，而不只是实际伤害。如果该事件达到须通报安全事件的标准，则适用包括书面跟进在内的法定程序。

**记录与报告**：在病历中记录差错、谈话和方案；通过事件报告系统上报。

**学习**：调查应着眼于差错发生的原因（手写转抄、夜间工作量、医嘱单的设计、核对流程），而不是简单地责怪FY2。FY2应与导师一起反思这一事件，并将其纳入自己的学习档案。一种医师可以无所畏惧地承认错误的文化，对每个人都更安全。
:::
:::

## 提出关切 {#raising-concerns}

对布里斯托尔以及后来对中斯塔福德郡NHS基金会信托（Mid Staffordshire NHS Foundation Trust）的调查，显示了不倾听的代价。2005年至2009年间，斯塔福德医院的患者受到了骇人的对待：被弃置在弄脏的床单上，食物和水放在够不着的地方，还发生了可避免的死亡。罗伯特·弗朗西斯（Robert Francis）御用大律师主持的公开调查于2013年提交报告，提出了290项建议，呼吁建立一种公开、透明和坦诚的文化。他的《自由发声》（*Freedom to Speak Up*）审查（2015年）促成了每个NHS信托设立**自由发声守护人**，并设立了国家守护人办公室（National Guardian's Office）。

GMC指南要求，当患者安全或医疗可能因同事的执业、系统或环境而受到损害时，医师必须提出关切。这一义务优先于个人和职业上的忠诚。诚实地提出关切的医师受到保护：《1998年公共利益披露法》（Public Interest Disclosure Act 1998）保护作出“受保护披露”的劳动者免受不利对待和不公平解雇。

通常的步骤是：

1. 向你的上级、导师或负责人提出关切，除非你认为他们本身就是问题的一部分。
2. 如果这样做无效或不合适，使用机构的程序：临床主任、医务主任、自由发声守护人或责任官员。
3. 如果关切未得到处理，或情况紧急而严重，向监管机构（如GMC或医疗质量委员会）提出。
4. 公开关切（例如通过媒体）只有在特殊情况下才是正当的：其他途径已经失败或显然不合适，而且不得披露可识别的患者信息。

在整个过程中，要记录所提出的关切和对方的回应；如有疑问，应寻求建议（向医疗责任保护机构、英国医学会或GMC的保密咨询热线）。

对临床结局的关切需要审慎对待：有些差异是由偶然造成的。在比较结局时，漏斗图等统计工具可以显示某个单位或外科医师是否超出了偶然所能解释的范围。

::: example 一年内四例死亡 {#ex-outlier}
一位顾问外科医师在某类择期手术中，60例手术后有4例死亡，而该类手术的全国30天病死率为3%。一位同事说该外科医师“显然很危险”，应禁止其手术。科室应如何应对？
::: solution
**统计**：预期死亡数为$60 \times 0.03 = 1.8$。如果该外科医师的真实风险为3%，仅凭偶然出现4例或更多死亡的概率约为0.11。死亡数偏高是需要调查的信号，而不是证据。

**病例构成**：这些患者的风险是否高于平均水平（年龄、合并症、紧急程度）？需要经风险调整的结局，全国审计数据可用于比较。

**病例复核**：对每例死亡进行独立、结构化的复核，可以显示医疗问题是否起了作用，以及这些问题有无共同模式。

**公平与安全**：调查应及时、保密，对该外科医师公平，并给予支持。如果复核发现问题，措施可以从指导、调整团队或病例选择，到限制执业。如果患者面临即时风险，在复核期间实施临时限制可能是正当的。

**公开**：如果发现了医疗问题，应根据坦诚义务告知家属。外科医师的结局既不应以“这是偶然”为由被置之不理，也不应仅凭小样本就被定罪。
:::
:::

## 诚信、利益冲突与边界 {#probity}

**诚信**（probity）是指诚实可信。《良好医疗实践》要求医师在所有职业活动中都保持诚实，包括病历、研究、简历、推荐信、财务往来以及向法庭和调查提供的陈述。不诚实是被从注册名册中除名的最常见原因之一，即使它与患者医疗无关。

当医师的判断可能受到、或看起来受到个人利益的影响时，就产生了**利益冲突**，例如经济利益、礼品、与企业的关系或拥有某些服务的所有权。医师不得让这些利益影响患者的医疗，必须公开申报，并且不得接受可能影响或看起来影响其判断的礼品或款待。在英国，制药行业的行为准则规范其与卫生专业人员的往来，向医师支付的款项在**英国信息披露数据库**（Disclosure UK）上公布。行贿或受贿是《2010年反贿赂法》（Bribery Act 2010）规定的刑事犯罪。

医师不应为自己或与自己有密切私人关系的人开处方，除非是在紧急情况下或没有其他选择时；在这种情况下，除非为挽救生命或避免严重恶化所绝对必需，绝不能开具受管制药品。

**职业边界**保护患者。医师不得利用其职业地位与患者或与患者亲近的人发展性关系或不正当的情感关系。如果这种关系涉及滥用先前职业关系所产生的信任，这一规定也适用于以前的患者。私密部位检查需要解释、取得同意，并提供陪护人员。《良好医疗实践》（2024年）明确规定，医师不得对同事有性方面的举动，包括发表不受欢迎的言论，并且在目睹性骚扰时必须采取行动。

::: warning 小礼品的滑坡
大多数医师相信自己不会受小礼品影响，却相信其他医师会受影响。关于与企业往来的研究提示，即使是小礼品和赞助的餐饮，也与处方行为的改变有关。要问的问题不是“这会改变我的决定吗？”（每个人都会说不会），而是“如果我的患者知道了，我会觉得自在吗？”以及“在一个理性的旁观者看来，这像不像是受到了影响？”要申报利益，拒绝可能被视为诱导的礼品，并以独立的证据作为处方的依据。
:::

::: example 一份会议邀请 {#ex-conf}
一家制药公司邀请一位全科医师在一次国际会议上介绍她使用该公司新糖尿病药物的经验，提供商务舱机票、在豪华酒店住宿三晚以及2000英镑的酬金。她应考虑什么？
::: solution
**这一安排**：根据行业准则，按公平市场价值为真实的服务（演讲、咨询）付费是允许的，款待必须合理且从属于会议的目的。为一次简短的演讲提供商务舱旅行和豪华住宿可能过度。

**利益冲突**：接受邀请会与一家她正在处方其药物的公司建立经济关系。她必须申报（该款项将在Disclosure UK上公布），确保她的处方仍以证据和指南为依据，并提供平衡的信息而不是宣传材料。

**雇主的规定**：NHS机构要求申报利益，并可能禁止某些安排。

**检验标准**：她的患者和同事会认为她的独立性受到了损害吗？如有疑问，她可以拒绝，或只接受合理的费用和适度的酬金，介绍包括该药局限性在内的证据，并向其诊所以及她所参加的任何指南小组申报这一关系。
:::
:::

## 医师自身的健康 {#wellbeing}

医师的职业倦怠、抑郁和物质滥用发生率很高，而且往往不愿求助。《良好医疗实践》要求医师在一位全科医师处登记，不要自己治疗自己，并在自身健康可能影响其判断或表现时寻求建议。《关爱医师，关爱患者》（*Caring for doctors, caring for patients*，2019年）等报告认为，工作条件，包括工作量、缺乏掌控感和团队支持不足，是主要原因，照顾好医疗队伍本身就是一个患者安全问题。NHS执业者健康服务等保密服务为有精神健康和成瘾问题的医师提供支持。

## 医师与刑法 {#criminal}

大多数临床差错通过民法、投诉和职业监管来处理。在少数情况下，因严重过失的医疗导致的死亡会引起**重大过失杀人罪**（gross negligence manslaughter）的起诉。其标准来自*R v Adomako*（阿多马科案，1994年）——该案中一名麻醉医师在数分钟内未发现患者的呼吸管已经脱开——要求：存在注意义务；违反了该义务；违反义务导致了死亡；以及在综合考虑所有情况后，过失严重到应被判定为犯罪的程度。后来的判例把所要求的标准描述为“确实异常恶劣”。

哈迪扎·巴瓦-加尔巴（Hadiza Bawa-Garba）医师的案件使这些问题受到广泛关注。2011年，6岁的杰克·阿德科克（Jack Adcock）在莱斯特皇家医院死于脓毒症；当时巴瓦-加尔巴医师是一名儿科受训医师，在包括信息系统故障和人员短缺在内的系统性失误下承受着巨大压力工作。她于2015年被判重大过失杀人罪。裁判所对她作出暂停执业的处分；经GMC上诉，高等法院于2018年下令将其除名，但上诉法院在同年晚些时候恢复了暂停执业的处分，强调裁判所对系统背景的评估以及她再犯风险较低。该案促成了对医疗领域重大过失杀人罪的多项审查，并引起医师们的强烈担忧：把差错刑事化会影响公开和学习。

全科医师哈罗德·希普曼（Harold Shipman）于2000年被判谋杀15名患者，希普曼调查发现他杀害了约250人。他的罪行显示了一名医师如何能够利用信任和薄弱的制度。该调查的建议促成了再认证、对受管制药品的管控，并最终促成了审查死亡的医学审查员制度（[[medical-ethics-law/end-of-life-ethics]]）。

::: quiz
一名医师因酒后驾车被定罪，未涉及患者，也没有健康问题的证据。下列哪项陈述正确？
- [ ] 该定罪与临床实践无关，因此与GMC无关。
- [x] 该医师必须立即告知GMC；GMC将结合所有情况考虑其执业适格性是否受损，既考虑患者安全，也考虑公众信心。
- [ ] 该医师将被自动从注册名册中除名。
- [ ] 该医师只需告知其雇主。
::: solution
《良好医疗实践》要求医师在世界任何地方接受警诫，或被控告、被判定刑事犯罪时，立即告知GMC。刑事定罪是执业适格性可能受损的依据之一，但结果取决于具体情况、医师的洞察力以及是否存在潜在的健康问题。一次酒后驾车定罪，若医师有洞察力，通常不会受到执业限制，但GMC会查找是否存在酒精问题的证据。除名并不是自动的。
:::
:::

::: history
《1858年医疗法》设立了英国医学总会和医师注册名册，使公众能够辨别合格的执业者。在一个多世纪里，GMC主要处理“在职业方面的可耻行为”，例如与患者通奸或做广告，而不是临床能力。

一系列丑闻之后，情况发生了变化。布里斯托尔调查（2001年）发现了结局监测方面的失误。哈罗德·希普曼的罪行和希普曼调查（2002—2005年）暴露了死亡证明以及对医师持续执业适格性的核查方面的薄弱环节。奥尔德黑器官保留丑闻促成了《2004年人体组织法》。GMC增加了非专业成员，2012年MPTS从调查职能中分离出来，再认证制度开始实施。中斯塔福德郡调查（2013年）促成了法定坦诚义务和自由发声守护人制度。2024年新版《良好医疗实践》更加强调工作场所文化、善意和防止骚扰。
:::

## 后续内容

患者安全、人因和事件分析见[[clinical-skills/patient-safety]]，病历记录和交接班见[[clinical-skills/records-handover]]，包括告知坏消息在内的沟通见[[clinical-skills/communication]]。科研不端行为在[[medical-ethics-law/research-ethics]]中讨论，职业义务背后的伦理原则在[[medical-ethics-law/ethical-principles]]中讨论。

::: summary
- 职业精神是“支撑公众对医师信任的一整套价值观、行为和关系”。在英国，其标准规定于GMC的《良好医疗实践》（2024年），分为四个领域。
- GMC维护注册名册，制定标准，监督教育和再认证（自2012年起），并处理执业适格性问题。听证由MPTS主持。首要目标是**保护公众**，包括公众信心和职业标准。
- 执业适格性要回答的是医师**目前是否受损**；洞察力和补救很重要。结果从不采取行动到除名不等。
- **职业坦诚义务**要求在出现差错时诚实并道歉；机构负有**法定坦诚义务**。道歉不等于承认法律责任。
- 医师必须就患者安全**提出关切**，先走本地途径，再向监管机构反映；举报者受《1998年公共利益披露法》保护。
- 解读结局数据时必须考虑偶然因素和病例构成。
- 诚信、利益冲突的处理和职业边界是核心义务；不诚实和性不端行为常导致除名。
- 医师应照顾好自身健康并寻求帮助。重大过失杀人罪要求过失严重到构成犯罪的程度（*Adomako*）；巴瓦-加尔巴案突显了系统的作用。
:::

## 习题

::: exercise 四个领域 {level=1}
下列各项义务分别属于《良好医疗实践》（2024年）的哪个领域？(a) 及时了解最新指南；(b) 支持一位报告受到欺凌的同事；(c) 申报在一家私立诊所的经济利益；(d) 向患者解释各种选择以便其作出决定。
::: solution
(a) 知识、技能与发展。(b) 同事、文化与安全。(c) 信任与职业精神。(d) 患者、伙伴关系与沟通。
:::

::: exercise 受损的依据 {level=1}
列出医师执业适格性可能被认定受损的四项依据。
::: solution
以下任意四项：不当行为；专业表现不足；刑事定罪或警诫；不良的躯体或精神健康状况；不具备必要的英语知识；另一卫生监管机构作出的裁定。
:::

::: exercise 预期死亡数 {level=1 check="1.8"}
某手术的全国30天病死率为3%。在60例此类手术中，平均预期有多少例死亡？
::: solution
$60 \times 0.03 = 1.8$例死亡。
:::
:::

::: exercise 仅凭偶然 {level=2 check="0.11"}
按二项分布，$n = 60$，$p = 0.03$，0、1、2、3例死亡的概率分别约为0.161、0.298、0.272和0.163。4例或更多死亡的概率是多少？结果保留2位小数。
::: hint
用1减去所给概率之和。
:::
::: solution
$1 - (0.161 + 0.298 + 0.272 + 0.163) = 1 - 0.894 = 0.106$，保留2位小数为$0.11$。一位真实风险处于平均水平的外科医师，在60例手术中出现4例或更多死亡的情况大约每10次中有1次，因此单个这样的结果需要调查，而不是评判。
:::
:::

::: exercise 一句道歉 {level=2}
一位顾问医师对一名低年资医师说：“不要为延误诊断向家属说对不起，那会在法庭上被用来对付我们。”这名低年资医师应如何回应？
::: solution
这一建议是错误的。当出现了已造成或可能造成伤害的差错时，职业坦诚义务要求道歉和诚实的解释，法定坦诚义务也可能要求机构正式这样做。《2006年赔偿法》第2条规定，道歉本身并不构成对过失的承认。公开与更少的投诉相关，并且有助于学习。这名低年资医师应礼貌地解释这些，引用GMC指南，必要时向临床负责人或患者安全团队寻求建议。不公开本身就可能成为一个执业适格性问题。
:::
:::

::: exercise 朋友请求开处方 {level=2}
一位并非你患者的好朋友请你开一个短疗程的佐匹克隆，因为她在一次重要面试前睡不着。你应该怎么做？
::: solution
友善地拒绝。GMC指南指出，医师应避免为与自己有密切私人关系的人开处方，除非是在紧急情况下，或者没有其他有处方权的人可提供帮助且处方为避免严重恶化所必需。本例两者都不是。佐匹克隆是受管制药品，为朋友开具它尤其不妥。你不掌握她完整的病史，也缺乏客观性，而且她的全科病历中不会有记录。建议她去看自己的全科医师，并以朋友的身份就睡眠和面试焦虑提供非药物的建议。
:::
:::

::: exercise 一系列关切 {level=3}
在六个月里，三名护士告诉一名FY2医师，一位上级同事对患者粗鲁、轻慢，有时拒绝为提出不适的患者做检查，还曾对一位有学习障碍的患者大声吼叫。这名FY2亲眼见过一次。她担心如果提出此事会影响自己的培训。她应该怎么做？有哪些保护措施？
::: solution
**义务**：所描述的行为可能损害患者安全和尊严，《良好医疗实践》要求她对关切采取行动。她自己的观察提供了直接证据；她也应鼓励护士们自己提出关切。

**途径**：记录具体的观察（日期、经过、在场人员），然后向她的临床导师或教育导师、临床主任或自由发声守护人提出关切。如果这位上级同事就是她的导师，则找其他人。如果本地途径失败，她可以联系GMC或医疗质量委员会。

**保护**：《1998年公共利益披露法》保护诚实地提出关切的劳动者免受不利对待；NHS信托不得打击报复发声者；如果培训受到影响，可以告知研究生教育院长和GMC。她应向自己的医疗责任保护机构或英国医学会寻求建议。

**公平**：对关切的调查应公平，应给这位同事回应的机会；可能存在需要支持的健康或工作量因素，也可能需要采取行动。
:::
:::

::: exercise 除名与否？ {level=3}
一位五十多岁、有25年无瑕疵执业记录的医师，被发现为在再认证中显得合规而伪造了继续职业发展（CPD）记录，声称参加了她并未参加的课程。对她的临床医疗没有任何担忧。她在早期就承认了，说当时因照顾一位临终的父母而不堪重负，此后已完成了各项要求。讨论裁判所可能如何决定处分。
::: solution
**受损**：在用于监管目的的记录中弄虚作假，触及再认证的完整性和公众对医学职业的信心。即使没有临床方面的担忧，由于首要目标的第二和第三项（公众信心和职业标准）受到影响，裁判所很可能以不当行为为由认定她的执业适格性受损。

**处分**：裁判所考虑能够保护公众的限制最少的处分。对她有利的因素：早期承认、真正的洞察力、个人背景、已作补救、无瑕疵的记录以及再犯风险低。对她不利的因素：不诚实是故意的，在多项声明中反复出现，而且涉及监管程序本身。严重的不诚实通常会导致除名，但并非自动如此；如果洞察力充分，一段时间的暂停执业可能被认为足以表明其严重性并维护信心。

**要点**：本案说明，监管并不只关乎临床安全。如果GMC认为处分不足以保护公众，可以提出上诉。
:::
:::
