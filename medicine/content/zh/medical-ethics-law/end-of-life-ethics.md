生命末端的伦理是原则那一章终于付完学费的地方：“致死与听其死亡”的区分在实践中被检验、比例性被写成输注的速度、而法律在止痛与安乐死之间的那条线、靠双重效应学说那一段最受审查的文字维持。**本章研习拒绝与撤除治疗（等效性的学说、营养与补液的地位、预嘱与代理）、姑息镇静及其边界、以及协助死亡之争及其保障、并注意法律在不同法域之间如何不同。**

## 拒绝与撤除

::: definition 不予、撤除与等效性的学说 {#def-withdraw}
**法律在英联邦传统中的核心动作是等效：不予一项本不欠的治疗、与撤除一项已开始的治疗、是同一个行为、由同样的理由来判断、所以“我们已经开始了、就必须继续”是一种感受、不是一条学说——这个结论来自那个分析：干预是医学的手段、而如果手段不再服务于患者的目的、使用它的许可就失效。抵抗并不只是情感上的al：心理与叙事上的差异是真实的关于人员与家属痛苦的“把撤除体验为致死”的研究、以及那种使“停下”像一个行为、而“开始”像一次失败仪式的不对称、伦理文献据此分裂为一种“弱的撤除与不予的差异”辩护的“象征性行为与承诺”的路径、对一致性论证：患者不该因为一台机器到达的时间不同而死得不同。人工的营养与补液承载着这一学说的成长的疼痛昆兰与克鲁赞时代的呼吸机案例、场把家庭之战展示给公众延续治疗的诉讼、以及“一根胃管是医学治疗还是基本照护”之争、其解决因法域而异——美国州法的“除非迫近的死亡、否则给食给水”条款、对英联邦“最佳利益的整体”的路径——同时持续的临床共识是：为晚期痴呆插管喂养不能预防误吸、也不能延长有意义的生存、试验的证据解决了医学的问题、而价值的问题一直在移动。生命末端的预嘱与替代“有效的、适用的拒绝维持生命的治疗有约束力”这一普通法规则、代理判断的文献发现：代席人系统性地高估患者忍受他们自己会拒绝的状态的意愿——为“在患者还能给出时进行那场治疗目标的谈话”辩护的“代席人的预测偏倚”研究、以及法院在施加时对负担与个人专属的意义越来越敏感的“生命总是值得活的”这一最佳利益的推定、以及那个结构着每一个帕金森与肌萎缩侧索硬化拒绝案例的不对称：“不予治疗不需要同意、但不能同意被杀”。呼吸机前那个“徒劳与覆盖”的问题“无益治疗”政策第二版的机构流程——提供转出的机制、按天数的通知、以及“分歧而不抛弃”的定框、加上“可能不可接受的治疗”的区分“治疗可以被提供、但不被要求、这与治疗是有害的不是一回事”这个澄清。**
:::

## 症状与镇静

::: definition 比例性的治疗、双重效应、与姑息镇静 {#def-symptom}
**生命末端的镇痛结构：意图、预见、比例性双重效应的装置——缓解难治的痛苦是被意图的效应、高剂量下的呼吸抑制与可能的缩短生命是被预见而不被意图、而善与被预见的伤害之间按症状的严重度来衡量比例；姑息文献提供的经验底层：“姑息剂量的阿片不缩短生存”的队列与审计的研究、使这一学说最难的应用在临床上多半不是一个真问题、而“终末滴定”的情形仍是这一学说为之存在的范例。批评者最好的形式：意图与预见的区分是心理学的“我们知道死亡会来、并为它调整剂量”的分析称这一学说是恶意，回答是那个临床的观察：意图在实践中是真实的、可被观察的“我们记录我们的推理与我们的监测”的回应：这一学说的功能与其说是形而上学的、不如说是强制问责的——它让临床医师说出他们在做哪一件事；“剂量足够高时、听其死亡与致死的区分就塌缩”的论证、在边界上由姑息镇静自己的流程纪律来回答。姑息终末镇静的边界工作：适应证难治的症状与终末躁动的定义——“为存在性的痛苦而镇静”这个次级的争论、其中“难治性”本身有争议、比例性的架构缓解所需的最小深度与最短时长、“比例性的对故意的深镇静”的区分、带复评的限时试验、补液的问题被镇静的患者与其人工液体被撤这一争议——“在此刻补液是舒适还是治疗”的分裂、以及必须告诉家人的血栓与分泌物的取舍、以及死亡时机的统计“从镇静到死亡的间隔”的审计文献——中位的天数、制造伦理摩擦的那少数迁延的案例、加上法律的位置镇静在一切地方都是“症状的治疗”、而“意图加速死亡”的案例的起诉边界、就是流程伦理所存在的、为使它不成为争议而守的那条线。镇静判例的表亲——直到死亡的深镇静、同时撤除维持生命的治疗最高法院的审查曾检视实践邻近的数据、“这是不是一场漫长睡眠中的安乐死”的指控、对“症状的处理与听其自然死亡的结合”的辩护、以及那个经验的发现：治理良好服务的审计显示、在绝大多数情形中这一区分被诚实地实践——这一点既是机构伦理的、也是哲学的。**
:::

## 协助死亡

::: definition 协助死亡的论证与其保障 {#def-assisted}
**先是措辞医师协助的自杀——患者自己服用；自愿的安乐死——由临床医师给予；这一区分的道德分量因法域、也因“最后那双手”而不同、而经验的结果数据提示：患者的理由与保障、比最后那双手更重要；支持的论证：自主与怜悯的组合“死亡的质量”文献中关于“身体的完整与死亡应有的形状”的论证、以及那句诚实的观察：“这种做法已经存在于终末镇静与撤除之中、只是没有一致性也没有选择权”、以及主导当前各议会的“终末镇静对协助死亡”的对称性论证；反对的论证：神圣与不可侵犯的传统“对残障者与依赖者的平等保护”这一论证及其最锋利的形式——一份“致命选项的菜单”会改变别人所获得的照护的代价与含义、滑坡证据的诚实状态俄勒冈对比利时与荷兰的比较的文献：“严格至今尚未成为滑坡”的阵营、对“标准已经漂移、而精神病与残障的案例已经到来”的阵营、以及关于“案例数的增长是滑坡还是正常化”的方法学僵局、以及残障运动那条常设的反对“谁会感到被期望去死”的证词、以及对自主的辩护低估了这一论证中正义的那一支。被实际建造起来保障的架构俄勒冈那条线的资格核心：能力、在六个月或十二个月的各变体之内的终末诊断、两位医师与请求的程序含书面的请求与见证人、以及精神科或专科会诊的触发、自己服用的要求、带独立复审的报告、“良心与机构不参与”的条款、以及被强制的“临终的选项”的咨询与姑息的转诊的设计、与加拿大及比利时及荷兰诸模式的差异成熟的意思能力对预先请求的覆盖、残障与精神疾病的资格之争及其“这是不是滑坡已到”的读法、“作为照护之延续的死亡、由临床医师的审查委员会治理”及其“审查委员会在正常化”的批评。**
:::

::: example 痴呆中的那根胃管 {#ex-tube}
一名晚期阿尔茨海默病的疗养院居民、基线时无语言、反复误吸；家庭分裂了——一半说“他绝不愿意这样”、一半说“你们在饿死他”。内科医师提议“不再用抗生素、只经口喂养；而那位做护士的女儿威胁要诉诸法律。
::: solution
**在晚期痴呆中“照护对治疗”（[[#def-withdraw]]、[[geriatrics-palliative/delirium-dementia-care]]）：要明白说出的证据：晚期痴呆中管饲的文献不减少误吸、在生存或质量上没有收益、以及“约束与躁动及经口护理更优”的发现使得“经口头喂养加积极的口腔护理”成为医学、而不是抛弃；而“对每一次反复的误吸都用抗生素、对设定一个上限”是一个独立的比例性问题、有其诚实的答案带复审的限时试验、舒适优先的定框、以及“我们会治疗每一次发作、权衡其负担与收益”的立场。替代判断的工作：“他绝不愿意这样”这一主张是可检验的——既往价值的访谈这位老人自己的陈述、他作为照护者的角色、他的教会、以及他遗嘱中的沉默、以及那位护士女儿“饿死”的定框、用家庭需要的那个区分来回答：我们停下的是一项不起作用的治疗、而不是一项起作用的喂养、并说明在此刻喂养一个正在死去的人意味着什么舒适的喂养流程与误吸风险的谈话、营养科与临终关怀团队在场。能在诉讼中存活的流程：与整个家庭及代议人一起的最佳利益会议、记录两位女儿的立场与推理的会议纪要、提供第二意见、以及限时试验的结构、好让没有任何不可逆的事在恐惧中被决定、以及当僵局是关于权力而不是关于证据时使用那条保护法院的路径——转诊是系统在起作用、不是家庭在失败。长远的一步：这所疗养院的预先照护规划、带着“何时转出、何时不转”的流程、以及人员的支持“喂养临终者是护理的道德核心”的文献警告：决定会被人员背负多年、因为那位女儿下一次的投诉、会更多关于“怎么说”、而不是“决定了什么”。**
:::

::: example 那次镇静后的转院 {#ex-sedation}
一名44岁的胶质母细胞瘤、化疗抵抗的呕吐与终末躁动的患者、在临终关怀中被按比例镇静；他已恶化、无法唤醒、而他的父母要求急性医院的“停止镇静、再试一次”。临终关怀与家属打电话给你——值班的姑息医学顾问医师。
::: solution
**压力之下的镇静的边界（[[#def-symptom]]、[[nervous-system/motor-systems]]、[[geriatrics-palliative/symptom-control]]）：先做临床的审计：重新核查“难治性”呕吐与躁动的原因重新筛查——颅内压升高的模式、激素的最优化与止吐阶梯的完整性、在“临终数日”这一现实之内的谵妄的检查、因为家属的请求有时是你所能得到的最好的症状监测器、并重新陈述镇静的深度与计划与症状成比例、而不是与生存成比例、按时限复审的节奏被记录下来。与父母的谈话：“停下再试一次”的请求、用双重的真相来回答我们可以减浅、看看什么会回来——意识、以及呕吐与躁动；而上一次尝试的记录就是那张地图、“他在挨饿吗、他在窒息吗”的问题、用查体的发现与用药计划的意图来回答、以及那种把“看着”变成“照护”的陪伴与仪式的支持给家属的“陪伴被镇静的亲人”的指导、告别音乐与触碰及后勤——哀伤文献说他们需要被允许去做。当家属升级时的治理：不带防御地共享的记录滴定的图表与复审与同意的谈话、若急性医院的团队询问则在转诊信中说明镇静的流程与适应证、在任何外部的复审被强加之前提供第二位资深姑息医师的复审、以及包含临终关怀护士在内的多学科与家庭的会议——父母真正在质疑的是他们的连续性。给培训生记录用的伦理语域：姑息镇静的正当性建立在比例性加难治性加透明之上——一次能够自我解释的镇静向家属、向检查员、事后向验尸官的档案、就是那个伦理、而家属的愤怒通常是“一个有问题在其中的哀伤”；回答那个问题、保持舒适、并不要让升级把团队拖入两种情形：停止一个必需的镇静、或对着重要的人把流程硬化。**

## 通向何处

临床的症状工作在[[geriatrics-palliative/symptom-control]]与[[geriatrics-palliative/palliative-care]]与[[geriatrics-palliative/end-of-life-care]]、痴呆中的应用在[[geriatrics-palliative/delirium-dementia-care]]、撤除与徒劳的流程在[[emergency-critical-care/critical-care]]、同意的机器在[[medical-ethics-law/consent-capacity]]、分配与正义在[[medical-ethics-law/justice-resources]]、而死亡证明与器官捐献在[[medical-ethics-law/professionalism-regulation]]。

::: summary
- 不予与撤除是同一个判断；要紧的差异是心理的与程序的、而伦理的工作是一致加支持——为患者、也为承载这一行为之意义的人员。
- 生命末端的营养与补液在不同法律下被分到“治疗”与“基本照护”两侧的方式不同；痴呆管饲的证据是清楚的、价值的争论不是、而那个流程妥善完成的替代判断、限时试验、必要时诉诸法庭是诚实的容器。
- 症状的滴定与姑息镇静由难治性、比例性与透明性治理；双重效应与其说是形而上学、不如说是问责的纪律、而它的实践形式是被记录下来的推理、与被守住的陪伴。
- 协助死亡的国际浪潮使“对法律与保障的素养”成为一项临床能力：各模式资格的核、漂移之争诚实的僵局、以及那个“把请求当作沟通来回应”的动作——无论法律站在何处都相同。
- 循环死亡后的器官捐献、死亡判定的公共信任、以及哀伤的职责把这一章延伸到死亡之后：生命末端的伦理结束于验尸官的法庭、移植的手术室与葬礼、而临床医师的义务不会在最后一次记录时停止。
- 本章的临床总结：当生命末端的决定是关于患者的目的、经由怀疑者可检查的流程做出、并伴随着没人能误认为抛弃的忠诚时、它们是正当的。
:::

**一份起作用的预嘱（[[#def-withdraw]]、[[clinical-skills/records-handover]]、[[nervous-system/motor-systems]]）：示范：”我在具备能力时、为我自己做出这个决定、适用于我患有运动神经元疾病、而我的呼吸或吞咽已失败到医师判断为不可逆的衰退的那种情形。在那种情形下我拒绝：心肺复苏；气管插管与机械通气除非是为了一个可逆的并发问题、且我能沟通并同意的限时试验；以及在我的医师判断它无法令人接受地维持我的情况下的人工营养。我不拒绝：对可治疗感染的抗生素与引流、为舒适的氧、在安全时长经口进食的乐趣、强效的症状用药、以及被保持清洁、温暖与有人陪伴。我的价值：我目睹过我的伴侣在呼吸机上的年的；比起我无法参与其中的几个月的生存、我更在意与家人说话、并死在家里。讨论的记录与副本：全科、神经科团队、我的两个孩子、我的律师；这份表格与其推理在我的病历里、也在我家的冰箱上、并请查我在登记册中的条目。“手艺的注解：特定性对笼统的平衡用一个凌晨三点的临床医师能认出的方式描述那种情形、例外的留出可阻止这份文件拒绝一场容易逆转肺炎的抗生素、本法域对拒绝维持生命的治疗所要求的见证与日期的形式、“在能力尚存时可以修改”的复审条款及其带日期的重签、以及可及性的架构病历、冰箱、急救系统的登记册、家人的副本——没有它、一份有效的文件就会在它唯一存在的时刻失效。**

::: exercise 处理捐献的请求 {level=2}
一名19岁的学驾者在车祸后脑干死亡、没有登记为捐献者；家人拒绝捐献、“他怕针、也怕事情没做完”。取出协调员提出“叙事重构”的方法。为重症医师出主意、并把说服的伦理说清楚。
::: solution
**同意、说服与信任（[[#def-withdraw]]、[[medical-ethics-law/justice-resources]]、[[emergency-critical-care/critical-care]]）：先给框架：本法域的同意模型选择加入对选择退出、家人的惯例对法律——多数临床医师工作在“软性的退出、而家人仍被询问”的体制中、以及这个决定的道德位置：捐献是一份由这个人的遗产或代席人可以给出的礼物、不是国家会发现的一种资源。说服的伦理：“叙事的重构”“他会成为英雄、他的死亡会拯救生命”脚本在“忠于这个人”时是正当的、而当它是一种技术时是不正当的——捐献的文献把这条线画在欺骗、压力与时机上——而家人那句“他害怕”的反对值得一个真正的回答操作的舒适保障、对遗体的处理及仪式及宗教的 安排。重症医师的次序：角色的分离捐献团队不参与最初的谈话、以及那句“现在这不是关于他是否适合由您来决定”的缓冲、有时间保护的空间与一位具名的联系人、并提供与家庭自己的顾问会面、以及一次诚实信息的陈述脑干死亡意味着什么、捐献会涉及什么、家人的回答会改变他的照护的什么：什么都不改变、并再说一遍。对拒绝的敬意：如果答案保持不、那么这个“不”被完全接受、而家人听到“对他来说这是正确的答案”、因为捐献系统真正的资产是“下一家的谈话赖以运行”的那份信任——实践中那条“同意的文化胜过转化率”的规则、这就是写进器官获取伦理准则中的、反对“叠加说服”的正义论证。**

::: history
**生命末端的实践、其伦理先于其措辞而改变：维多利亚时代死亡的居家编排、与疗养院那套“隐瞒诊断”的文化“医师不告知预后”的规范、肿瘤病房把它带进了1960年代、以及这个职业随后交给教会的葬礼仪式与哀伤的工作。二十世纪的机器逼迫出了伦理：铁肺病房的小儿麻痹之夏的分诊委员会1940年代哥本哈根与西雅图“法律假装看不见的上帝般的决定”、移植时代对死亡的重新定义1968年哈佛特设委员会的脑死亡报告、及其后医学编辑大会与“统一死亡宣布法”的诸战、日本与伊斯兰世界各异的接受、以及日本自己2009年《器官移植法》的翻转——它们是“文化进入法律”的案例、以及呼吸机与营养的判例1976至77年昆兰时代“死亡的权利”的诞生、1990年克鲁赞那一场“清晰且令人信服的证据”的对决及其反向的遗产、英格兰的布兰德案、以及各大陆近邻痴呆营养的判决——每一个法域都会重跑一遍“食物是治疗还是基本照护”这个论证。临终关怀运动的道德供给桑德斯时代的复兴、“总痛与家庭”的模型、及其1980年代内部的“镇静直到死亡”之争——在此后每一场终末镇静的争论中回响、“生前遗嘱”的复兴1969年的造词、1976年“生命终点决定法”的浪潮、与美国1990年《患者自决法》所要求的政策、以及“为什么文件在紧急时失效”的设计研究、以及荷兰的立法形成这条弧1990年的报告程序、2002年《按请求终止生命法》的“审慎的检验”、“因衰老而厌倦生活”与累积衰老的争论，给了协助死亡之争它的比较集；俄勒冈1997年《尊严死亡法》的存活、与各州效仿的浪潮、加拿大的卡特判决与两部法律及资格的扩张、以及国际残障权利的谴责、澳大利亚各州以“VIC模型”输出保障的全民公决时代、新西兰与欧洲各自的节奏、以及英国历次议会中关于“试验与机器人”的攻防及其“关于保障的经验证据本身就是有争议的”的评估——这一切使这门学科在其最核心处仍是一门有比较法、却没有共识的学科。**

::: example 那个限时的试验 {#ex-trial}
一名78岁的终末期慢阻肺合并肺炎的患者“作为一次试验”被插管；第3天、家人把血氧的改善读作康复、并拒绝任何关于上限的谈话；住院医师想“给家人一些时间”、而顾问医师想现在就定下复审的会议。
::: solution
**试验需要定义（[[#def-withdraw]]、[[emergency-critical-care/critical-care]]、[[respiratory/respiratory-failure]]）：住院医师的直觉是对的、但不完整：限时试验是这个领域最好的冲突技术、但只有在它于插管时被定义过才成立“必须改善什么、到什么时候、如何判断”这个三元组要在决定的那一刻记录——文献的发现是：未定义的“试验”会变成永久的默认、而这恰好就是这个家庭的轨迹、而血氧的改善是那种要预先化解的误读“监护仪不是患者”这场谈话：什么改善了、什么没有、以及她昨天做不到的事今天依然做不到。顾问医师的动作就是流程：与最初达成约定的同一批人、在具名的复审日期、“我们仍在这个试验之中、而这是第7天将要决定的东西”这个定框让家人留在计划之内、而不是与它对抗、以及“什么会使你们改变主意、什么会使我们改变”这个提问、检验是否有任何一方的立场是可被证伪的。当第7天说“不”时：上限以与试验同样特定的方式陈述“我们不会再次插管、而我们会治疗每一种不会延长痛苦的感染”这句话、把拔管编排成一次“转向临终关怀”而不是一次撤除症状的准备、家人在场的选项、包括他们害怕被要求离开的恐惧、以及那句“我们不是停止照护、我们在改变治愈的含义”——这句话人员也需要对自己说一遍、以及在家人必须要求之前就提供第二意见与伦理委员会。教学的要点：试验的伦理力量同时是认识的与关系的——它为预后的明朗与家人的移动争取时间、而这间病房展示的失败模式是：让时钟走、却没有“让试验的终点成为一个决定而不是一场搏斗”的定义。**

::: example 那张证明与那个家庭 {#ex-certificate}
你们姑息病房里的一次死亡：家人希望证明上写“心力衰竭”、“因为他工作的养老金需要这个措辞来给孩子”；而死亡源于基础的癌症、证明的规则是严格的、而那位遗孀在哭。
::: solution
**对逝者与生者的坦诚（[[#def-withdraw]]、[[medical-ethics-law/professionalism-regulation]]）：先说法律：证明陈述的是按最佳知识的因果链根本原因的规则、不是关于“死亡的机制”的愿望清单、而虚假的证明是那种比哀悼者活得更久的谎言——“当保险读到病历时、验尸官的转诊与医疗主管及逝者家属随后被拆解”的文献是存在的。同一口气里的人性：养老金与津贴的问题通常有一个诚实的答案“保单真正需要的是一份死亡证明及其顺序、而不是临床医师的意见”这样的指路、以及与她一同走过的路径：雇主与工会的计划、丧葬金与津贴的文书、哀伤的组织、以及当正确的证明在行政上令人尴尬时一封解释时间线的支持信。手艺：句“我不能写下并非他死亡原因的东西、而在他的死亡留给你们的亏欠上、我会与你们一起赴汤蹈火”——这个组合让真相与忠诚待在同一个房间；以及本单元的做法：这场谈话发生在遗体被照护好、而家人喝过茶并度过一天之后。教学的附加：死后的探访或电话哀伤结局文献那个“在黑暗的那个月打电话的团队”的发现、在家人进入第二周之前提供对验尸官、检察官与登记处的导航、以及针对这个请求本身的人员简述、因为“让文书为她行得通”是哀伤在说话、而听懂它的团队会被下一家、再下一家问到。**

一名医学生问：你怎么能“明知它也许会让他的呼吸停止、还加大吗啡”、却不能“给一次过量的药物来了结它”。给出那个在他第一次面对死亡时仍会相信的九十秒的回答。

**意图是一个事实（[[#def-symptom]]、[[geriatrics-palliative/symptom-control]]）：九十秒：”它们是不同的行为、而我们能证明自己言出有据。在第一种，目标是那份气促、我们给出能可靠平息它的最小剂量、我们观察自己做了什么、我们可以逆转或调整它、而如果他比我们期望的更早死去、不是计划、也不是这个药物起效的方式。在第二种、死亡是缓解的机制——那个剂量唯一的帮助方式就是杀死——而再多好的动机也不会改变我们做了哪一件事。医学一向接受可预见的死亡、服务于患者共享的目标——麻醉、化疗、我们每周都在用的镇静。它从未接受的、是把死亡本身变成治疗。而这是病房教给你的那部分：我们靠写下我们在做哪一件来让这个区分保持诚实、靠让家人从我们口中听到同一句话、而如果你什么时候分不清自己在做哪一种、不是哲学的问题、是一个去请上级并慢下来的问题。“记录的附加（滴定的图表与理由、被监测并可复审的模式）让这一学说可以被操作、而不仅仅是装饰、而见过这两种医嘱并排写出来的学生、永远不会忘记这个差别。**

::: exercise 发现漂移 {level=2}
你们姑息服务的审计发现：四分之一的案例中深镇静的医嘱没有记录难治性；从镇静到死亡的中位间隔在下降；交班时用“要不要让他一路舒适下去”这种措辞询问家属；而一名护士的离职面谈提到了“那条捷径的说法”。请调查并回应、区分流程的失败与边界的失败。
::: solution
**审计作为伦理的仪器（[[#def-symptom]]、[[clinical-skills/patient-safety]]）：调查的设计：记录的复审“难治性的证据——存在过什么、对试过什么”——在复审者开始查看之前就把“被记录的难治性”的定义操作化、间隔趋势的分析病例组合对实践的分解——患者是否本来就更早死亡、这是一个“镇静与临床医师访谈”的文献能分离开的人群问题、语言的审计“一路舒适”这个短语从“舒适的照护”到“声明镇静的深度”的语义漂移——交班短语研究的方法、以及保密的访谈把“捷径的说法”这一项当作道德困厄与正常化的信号来处理、并配安全科学文献提供的那条安全上报的通道。可能的模式：先是流程的侵蚀记录的习惯在工作量下失效、流程变成仪式、在家人感恩时跳过了复审的节奏、带着少数真正的边界模糊语言的审计通常是那个先行的指标。分层的回应：流程的重新发布把难治性的标准与限时复审及记录标准作为临床医学、而不是合规来教、对迁延的深镇静要求双签或第二次复审荷兰与比利时的报告架构中可移植的临床治理、语言的修正给家属谈话的“我们在做什么、为什么”的脚本、每一次交班都用同样的词、人员的支持与发声的系统把离职面谈作为安全信号的通道变成常规、以及带上名字的镇静与死亡的审计进入死亡与并发症的会议、因为“哨子只有在有人记分时才管用”。要公开守住的那条线：一个治理良好的镇静服务、正是一个法域能够抵御“把别的东西合法化”的理由、而保护那份声誉本身就是一个患者安全的论证。**

**一份为合法格局准备的政策（[[#def-assisted]]、[[medical-ethics-law/professionalism-regulation]]）：请求处理的核心：每一个请求都在数小时、而不是数周内得到回应、并带着同样三项承诺你不会遭到抛弃；我们会探索这个请求是关于什么的——份耗竭与被拖累感及恐惧及可治疗症状的评估；以及“合法的选项是你照护的一部分”这一信息、无论我们个人相信什么、“两个声音的规则”提出异议临床医师的职责：带着温度的移交、信息的完全可得、不阻挠、不说教、以及服务层面的保证：合法的请求会抵达它合法的去向、与个人的良心无关“良心在临床医师、可及性在服务”这个分工、是试验机构与对医师的报告趋同的结论。人员的架构：在雇佣时记录良心声明、不带污名、排班的设计不得悄悄地把这项工作派给愿意的人、而让异议者去覆盖病房“良心不得变成职业的结构性不平等”——护理监管者的指导明确这一点、为所有立场配备团队的简述与道德困厄的支持、以及那个“患者绝不会遇到一个藏不好自己异议的人”的专业性检验。临床的流程“请求作为沟通”的证据：结构化的探索访谈、抑郁与谵妄及存在性痛苦的筛查及精神科的会诊路径、症状优化试验的提供及其记录、由患者的主管者带队的家庭会议、以及“矛盾是正常的、而时间是药”的再次预约规则。每年的数据：收到的请求、探索的结局、交付的症状与精神科的干预、转诊及其完成时间、镇静与死亡间隔的审计、人员良心声明的人数而不含姓名、以及那张公平表按年龄、性别、族裔、贫困、诊断划分的“谁在询问”——因为“谁会觉得被期望去死”这个问题必须用本地的数字来监测、否则正义的争论会一直停留在假设。公布的诚实条款：即使结果令人不适、服务也报告自己的结局分布、因为在这个领域、停止公布的服务、正是批评者说对了的。**

::: exercise 教那场家庭会议 {level=3}
为高年资培训生设计一次45分钟的模拟：一个家庭、一条患者的轨迹、三名培训生轮流担任主持、带评估细则的五项行为。包括那两个能把“技术上正确”与“值得托付”区分开来的、写好的家属反应。
::: solution
**一次有牙齿的模拟（[[#def-withdraw]]、[[clinical-skills/communication]]）：案例：第7天的慢阻肺试验——故意复用前面那个例子、培训生在第3分钟才发现定义、这就是这一课。细则的五项行为：(1) 先弄清他们在哪里在给任何新信息之前先问“从星期二以来你们听说了什么？”——糟糕的会议那个心脏骤停般的原因是那个未被澄清的误解、(2) 把不确定与希望分开命名“他可能带着机器活几周；他不会回家；两句都是真的”、(3) 给出建议、而不是分发菜单“家庭会议中建议对菜单”的试验发现：一个锚定在价值上的建议会缩短痛苦与困厄、而不降低满意度、(4) 守住沉默与下一个问题“询问—许可—陈述—检查”的循环并计时、(5) 以计划与人作结“这是今晚我们要做的、这是我们下次会面的时间、我是某医师、这是你联系我的方式”。两个写好的反应：“所以你们就是希望他死”这个诱饵正确的动作：拒绝这个框、重新锚定目标——“不——我们是说这台机器给不了他告诉我们他想要的那样东西；这是我们能做的”、以及“我母亲说我们不能放弃”这个三角化正确的动作：尊重那位不在场的家人、把房间扩大——“告诉我你母亲希望什么；我们明天一起和她谈”、因为那位值得托付的临床医师、正是把家庭的战争变成家庭会议的人。简述：给家属演员的录像回放、把培训生自己的话返还给他们、因为习惯性的短语只有从外面才听得见、以及“写下一句你会在某个真实的星期四晚上使用的话”这个结尾——这就是模拟的意义。**
