2006年3月13日，6名健康的年轻男性在伦敦诺斯威克公园医院（Northwick Park Hospital）的一个研究单位参加了一种新单克隆抗体TGN1412的首次人体试验。每人都因参加试验而获得报酬。输注后约1小时内，6人全部因细胞因子的大量释放而病情危重，均需进入重症监护病房治疗多器官衰竭。他们都活了下来，其中一些人留下了持久的损害。随后的一项专家审查建议改变首次人体试验剂量的计算方法，以及相继给志愿者给药的间隔。

研究是医学了解什么有效的途径。本课程中的每一种治疗之所以存在，都是因为有人同意参加结果未知的研究。但研究与治疗有一点不同，这一点带来了特殊的伦理风险：研究的主要目的是获得帮助未来患者的知识，而不是帮助参加者本人。本章解释研究为什么需要自己的伦理、塑造这些规则的历史、使研究合乎伦理的要求、知情同意及其例外、英国如何监管研究，以及数据、组织和全球研究中的当前问题。

## 研究为什么需要特殊的伦理 {#why-special}

在临床医疗中，临床医师的职责是对患者负责：每一个决定都应以该患者的利益为目标。在研究中，参加者遵循为回答某个问题而设计的方案。他们可能被随机分配到研究者希望较差的那种处理，被给予安慰剂，或被要求接受对自己并无帮助的额外检查。他们承担风险，部分是为了他人的利益。这在伦理上是可以接受的，但必须有保障措施。

::: definition 研究、临床审计与服务评价 {#def-research}
- **研究**旨在获得**可推广的**新知识，例如检验一个假设或比较不同干预。它可能涉及随机分组或常规医疗以外的干预。在英国，凡涉及NHS患者及其组织或数据等情况的研究，须经**研究伦理委员会**（research ethics committee，REC）审查。
- **临床审计**按照既定标准衡量现行医疗，以在本地改进医疗。它不涉及随机分组，也不改变治疗。
- **服务评价**描述现行医疗或某项服务，以判断其效果如何，不参照标准。

临床审计和服务评价无须REC审查，但仍需本地批准、保密措施以及如实报告。**卫生研究管理局**（Health Research Authority，HRA）提供了一个用于判定项目类别的决策工具。
:::

一个反复出现的问题是**治疗误解**（therapeutic misconception）：参加者，有时还包括研究者，认为试验的目的是让每个参加者获益，而低估了接受安慰剂或较差处理的可能性。良好的知情同意过程力图纠正这种误解。

## 历史与准则 {#history-codes}

研究伦理在很大程度上是作为对滥用的回应而建立起来的。第二次世界大战期间，德国医师对集中营囚犯进行了致命的实验，包括暴露于冰水、高海拔和感染。战后，23名被告（其中大多数是医师）在纽伦堡受审。1947年的判决列出了十项原则，即现在所称的**《纽伦堡法典》**（Nuremberg Code），其第一条是“人类受试者的自愿同意是绝对必要的”。

滥用并未就此终止。在**塔斯基吉研究**（Tuskegee study，1932—1972年）中，美国公共卫生署追踪了亚拉巴马州约600名黑人男性，其中约400人患有梅毒，以观察未经治疗的梅毒的自然病程。这些男性没有被告知自己患有梅毒；在20世纪40年代青霉素成为标准治疗之后，他们也未得到青霉素。直到一名举报者的担忧被媒体报道，研究才告终止。在纽约的**威洛布鲁克**州立学校（Willowbrook State School），从20世纪50年代起，有学习障碍的儿童被故意感染肝炎，而同意参加的家庭有时更容易让孩子入校。1966年，麻醉医师亨利·比彻（Henry Beecher）在《新英格兰医学杂志》上发表了来自主流研究的22个伦理上有问题的研究实例。

在英国，20世纪90年代末发现包括布里斯托尔皇家医院（Bristol Royal Infirmary）和奥尔德黑儿童医院（Alder Hey Children's Hospital）在内的医院在家长不知情的情况下保留了死亡儿童的器官，由此产生了**《2004年人体组织法》**（Human Tissue Act 2004），使知情同意成为储存和使用人体组织的基础。

世界医学协会于1964年首次通过的**《赫尔辛基宣言》**（Declaration of Helsinki）是医学研究的主要国际准则。其最新修订版（2024年10月）用“参与者”取代了“受试者”一词，强调个体的易受伤害性而非整个群体的易受伤害性，并增加了关于社区参与、研究浪费以及数据和样本二次使用的要求。在美国，塔斯基吉事件之后撰写的**《贝尔蒙特报告》**（Belmont Report，1979年）提出了三项原则，这些原则影响了世界各地的研究伦理。

::: definition 贝尔蒙特原则 {#def-belmont}
1. **尊重个人**：把个体视为自主的行为者，并保护自主性减弱的人。通过**知情同意**来落实。
2. **行善**：不伤害；使可能的收益最大化，可能的伤害最小化。通过**风险与收益评估**来落实。
3. **公正**：公平地分配研究的负担与收益。通过**公平选择参与者**来落实，使弱势群体不承担为他人谋利的研究的风险，也不被不公平地排除在可能使其获益的研究之外。
:::

## 合乎伦理的研究的要求 {#requirements}

2000年，伊齐基尔·伊曼纽尔（Ezekiel Emanuel）、戴维·温德勒（David Wendler）和克里斯蒂娜·格雷迪（Christine Grady）提出了一套被广泛采用的要求，以可适用于任何研究的形式概括了各项准则。

::: theorem 合乎伦理的临床研究的七项要求 {#thm-requirements}
一项研究只有在具备以下各项时才合乎伦理：

1. **社会或科学价值**：它提出的问题的答案可能改善健康或增进知识。
2. **科学有效性**：其方法能够可靠地回答该问题。
3. **公平选择参与者**：出于科学理由选择参与者，而不是因为方便或对方易受伤害。
4. **有利的风险—收益比**：风险被降到最低，并且相对于参与者的收益和知识的价值是合理的。
5. **独立审查**：由没有利益冲突的人进行审查。
6. **知情同意**：来自参与者本人，或有正当理由的替代。
7. **尊重已入组的参与者**：保护其隐私，允许其退出，监测其健康状况，并告知其结果。
:::

::: proof
每一项要求都针对研究可能伤害人的一种方式。一项没有价值的研究，或方法太弱而无法回答其问题的研究，使参与者白白承受风险和不便；它还浪费资源，并可能产生误导性的证据。这就是为什么一项把握度不足的试验，或一项永远不会发表的试验，是伦理问题，而不仅是科学问题。

公平选择针对的是历史：塔斯基吉研究和威洛布鲁克研究选择参与者，是因为他们贫穷、是黑人或住在机构里。这一要求也指向另一方向：把女性、老年人或少数族裔排除在试验之外，会使他们只能使用在别人身上检验过的治疗。

风险—收益评估和独立审查之所以存在，是因为研究者有利益冲突：他们希望自己的研究得以进行。知情同意体现对自主的尊重。由于参与者在整个过程中都应受到尊重，而不只是在入组时，这些职责在同意之后仍然继续：监测伤害，当一组明显更好时停止试验，以及分享结果。
:::

### 临床均势与安慰剂 {#equipoise}

什么时候把患者随机分配到不同治疗是合乎伦理的？本杰明·弗里德曼（Benjamin Freedman，1987年）提出了**临床均势**（clinical equipoise）：当医学专家群体对哪种治疗更好确实存在不确定时，试验就是合乎伦理的。个别研究者可能有某种预感，但如果专家群体意见分歧或不能确定，就没有患者被明知地给予较差的治疗。

在没有有效治疗时，安慰剂对照在伦理上并无问题。当已有有效治疗时，《赫尔辛基宣言》规定，新干预应与已证实的最佳干预进行比较，除非没有已证实的干预，或者出于令人信服的科学理由必须使用安慰剂，且接受安慰剂的患者不会因此承受严重或不可逆伤害的额外风险。

试验还必须足够大，才能回答其问题。下图显示试验的把握度（检测出真实效应的概率）如何取决于样本量和效应量（[[epidemiology-ebm/randomised-trials]]）。

::: example 一项安慰剂对照试验 {#ex-placebo-trial}
一家公司提出在成人中开展一项为期12周、以安慰剂为对照的新药治疗中度抑郁的试验。有效的抗抑郁药和心理治疗都已存在。设置安慰剂组合乎伦理吗？
::: solution
**赫尔辛基标准**：已有已证实的干预，因此使用安慰剂需要有令人信服的科学理由，而且参与者不得承受严重或不可逆伤害的额外风险。

**科学理由**：在抑郁症中，安慰剂反应率高且变异大，因此只把新药与现有药物比较的试验可能无法显示在该试验中两者是否有效。药品监管机构常要求有安慰剂对照的证据。这可以构成令人信服的理由。

**风险**：12周不接受有效治疗的主要风险是抑郁持续或加重，包括出现自杀念头。方案必须排除高风险者，密切监测情绪，规定明确的规则以便让病情加重的参与者退出并给予治疗，并使安慰剂期尽可能短。增加使用现有药物的第三组（阳性对照）可提供有用的信息。

**知情同意**：参与者必须理解自己可能接受安慰剂，试验之外存在有效的治疗，并且可以随时退出并接受标准治疗。

**结论**：有了这些保障，在中度抑郁中开展短期安慰剂对照试验可以是合乎伦理的。而在重度抑郁中，或在未经治疗会造成不可逆伤害的疾病中，开展长期安慰剂试验则不合乎伦理。
:::
:::

## 研究中的知情同意 {#research-consent}

对研究的同意通常要求比对治疗的同意更高的标准。参与者会收到书面的知情信息表，有时间考虑（非紧急研究常为24小时或更长），并给予书面同意。他们必须被告知，可以随时退出、无须说明理由，且其医疗不会因此受到影响。信息必须涵盖目的、程序、风险、可能的收益（以及可能没有收益）、替代方案、保密、数据和样本的使用、报酬与赔偿，以及结果将如何分享。

**报酬。**报销费用和补偿时间是可以接受的。如果报酬高到足以使人接受原本会拒绝的风险，或隐瞒会使其被排除的信息，就成为**不当诱导**。REC会判断报酬是否适当。

::: warning 试验不是治疗，即使它带来希望
重病患者常怀着获益的希望参加试验，有些人确实获益。但试验的设计，包括随机分组、安慰剂、固定剂量和额外检查，是为了回答问题而选择的，而不是为了给每个参与者最好的个体化医疗。研究者必须清楚地说明这一点，避免以暗示已证实有效的方式把试验药物称为“新疗法”，并确保患者了解替代方案。招募自己患者的临床医师负有特别的责任区分自己的两种角色，因为患者可能很难对治疗自己的医师说“不”。
:::

**缺乏决策能力的成人。**在英格兰和威尔士，只有在特定法律条件下才允许开展涉及缺乏决策能力的成人的研究。

- 对于非药物试验的研究，适用**《2005年精神能力法》（Mental Capacity Act 2005）第30—34条**。研究必须经适当机构（REC）批准，必须与该人的致损病情或其治疗有关，而且不可能在有决策能力的人身上同样有效地开展。研究必须要么有可能使该人获益且不造成不成比例的负担，要么旨在提供关于该病情的知识，且风险可忽略、无显著干扰。研究者必须征询一名**个人咨询人**（如家庭成员），若无人可征询，则征询一名**指定咨询人**；如果该人看起来表示反对，研究者必须让其退出。
- 对于**研究用药品临床试验**（clinical trials of investigational medicinal products，CTIMP），则适用《2004年人用药品（临床试验）条例》（Medicines for Human Use (Clinical Trials) Regulations 2004），由**法定代理人**给予同意。
- 在**紧急研究**中，治疗必须在来得及征询任何人之前开始，两种框架都允许在经批准的条件下入组，并尽早事后向参与者或其代理人征求同意（有时称为**延迟同意**）。

**儿童。**对于CTIMP，16岁以下儿童由具有父母责任的人给予同意，并征求儿童本人的赞同。对于其他研究，具备吉利克能力（Gillick competent）的儿童可能能够给予同意，这取决于研究的性质和REC的意见。涉及儿童的研究是必要的，否则儿童将只能使用仅在成人中检验过的药物治疗。

::: example 一项心搏骤停试验 {#ex-emergency}
PARAMEDIC2试验在英国把8000多名院外心搏骤停的成人随机分配，由急救人员给予肾上腺素或安慰剂。30天生存率在肾上腺素组为3.2%，在安慰剂组为2.4%，但神经功能结局良好的生存率无显著差异。在患者无法给予同意、而且有些家属反对在复苏中使用安慰剂的情况下，这样的试验怎么会合乎伦理？
::: solution
**价值与均势**：肾上腺素已根据动物数据和观察性研究使用了几十年，但它是否改善有意义的生存，确实存在疑问。只有安慰剂对照试验才能回答这个问题，而答案对全世界数以百万计的患者都很重要。

**知情同意**：入组前取得同意是不可能的。该试验采用了临床试验条例中的紧急研究条款：事先获得REC批准，患者在未事先同意的情况下入组，并尽早告知幸存者或其亲属，就继续参与和数据使用征求同意。

**公众参与**：研究者公开宣传了该试验，征询了患者和公众的意见，并允许人们通过申领一个表明不愿参加的手环来事先选择退出。

**风险—收益**：由于肾上腺素的益处不确定，接受安慰剂的参与者并非被明知地剥夺了有效治疗。随后，试验结果为指南提供了依据，也帮助家属理解复苏。
:::
:::

## 英国的监督与监管 {#oversight}

在英格兰，依据《2014年照护法》（Care Act 2014）成为法定机构的**卫生研究管理局**（HRA）负责监督研究伦理并批准NHS研究。**研究伦理委员会**审查研究方案、知情信息表和同意安排；其成员除专家外还包括非专业人士。**药品和保健产品监管局**（Medicines and Healthcare products Regulatory Agency，MHRA）负责批准药品和医疗器械的临床试验。每项研究都需要一个**申办者**，即负责研究管理的组织，研究必须遵循**药物临床试验质量管理规范**（Good Clinical Practice）标准（即ICH指导原则，2025年更新为E6(R3)）。

经改革的临床试验条例（《2025年人用药品（临床试验）（修订）条例》，Medicines for Human Use (Clinical Trials) (Amendment) Regulations 2025）于2026年4月28日在全英国生效。该条例把MHRA审查与伦理审查合并，并使**透明度**成为药品试验的一项法律要求：试验必须在公共注册库中注册，必须公布结果摘要，并应与参与者分享研究发现。

透明度之所以重要，是因为**发表偏倚**会扭曲证据。阳性结果的试验比阴性结果的试验更可能发表，而且发表得更快。未注册或未发表的试验辜负了为获得知识而承担风险的参与者，并可能导致患者接受无效或有害的治疗。自2005年起，主要医学期刊要求试验在第一名参与者入组之前注册。

::: definition 科研不端行为 {#def-misconduct}
**科研不端行为**包括**捏造**（编造数据或结果）、**篡改**（操纵研究材料、程序或数据，使研究记录不准确）和**剽窃**（把他人的工作当作自己的）。其他严重过失包括未获得伦理批准或知情同意、未申报利益冲突以及虐待参与者。诚实的错误和意见分歧不属于不端行为。
:::

近年来英国危害最大的例子是安德鲁·韦克菲尔德（Andrew Wakefield）1998年在《柳叶刀》上发表的论文，该文提出麻疹—腮腺炎—风疹（MMR）疫苗与孤独症之间存在关联。调查发现，儿童在没有适当伦理批准的情况下接受了侵入性操作，数据也被歪曲。该论文于2010年被撤稿，韦克菲尔德于同年被从医师注册名单中除名。此后多年，人们对疫苗的信心都受到了损害（[[public-health/vaccination-programmes]]）。

::: example 一项未注册的试验 {#ex-unregistered}
一位顾问医师在自己的门诊开展了一项比较两种腿部溃疡敷料的小型随机研究，既未注册，也未获伦理批准，理由是“两种敷料都是标准的”。结果显示其中一种敷料更好，她将结果投给了一家期刊。存在哪些问题？
::: solution
**这是研究**：为获得可推广的知识而把患者随机分配到不同处理，属于研究而不是临床审计，即使两种处理都是标准的。它需要HRA和REC的批准、一个申办者，以及参与者对随机分组的知情同意。

**后果**：患者在不知情的情况下被纳入了一项实验，这侵犯了他们的自主。没有前瞻性注册，读者无法核查所报告的结局是否就是事先计划的结局，而大多数期刊也不会发表未注册的试验。

**现在该怎么做**：她应向所在机构的研究与发展办公室寻求建议；这些数据可能无法发表；此事可能需要通过研究管理程序上报。正确的做法本应是设计一项经批准、已注册的规范试验；对于两种标准敷料之间真正存在不确定性的问题，这本来很容易做到。
:::
:::

## 数据、组织与全球研究 {#data-tissue}

许多现代研究使用为其他目的收集的数据和样本。像英国生物样本库（UK Biobank）这样的**生物样本库**（2006—2010年间招募了50万名成人）储存样本和数据，供无法事先具体说明的未来研究使用。参与者在一个治理框架内对未来研究给予**广泛同意**，而不是对每项研究给予具体同意。2024年版《赫尔辛基宣言》在包括伦理委员会监督在内的条件下接受对数据和样本的这种同意。根据《2004年人体组织法》，储存和使用来自活体的组织用于研究需要同意，除非该组织已匿名化且研究已获REC批准。未经同意使用保密的患者数据开展研究需要法律依据，例如第251条支持（[[medical-ethics-law/confidentiality]]）。

**全球研究**引发了公正问题。1997年，在低收入国家开展的、以安慰剂为对照的预防母婴HIV传播的短程齐多夫定方案试验引起争议，因为当时已知较长的方案有效，而且在高收入国家是标准治疗。批评者称之为双重标准；辩护者则说长程方案在当地负担不起，问题在于什么方案能在当地起作用。这场争论使国际指南（国际医学科学组织理事会CIOMS指南，最近一次修订于2016年）提出了更严格的要求：研究应回应当地的健康需求，让社区参与，并规划**试验后可及性**，使被证明有效的干预能在试验后继续获得。

::: example 使用匿名化的影像 {#ex-scans}
某放射科希望把5万张匿名化的胸部X线片提供给一家科技公司，用于训练检测肺癌的人工智能系统。由此产生的产品将归该公司所有。是否需要同意？还会引发哪些伦理问题？
::: solution
**法律**：真正匿名化的数据不是个人数据，因此数据保护法和保密义务并不以同样方式适用。但影像中（图像本身或其元数据中）可能包含识别信息，罕见的发现也可能使人被识别出来，因此匿名化必须可靠。共享可识别的或假名化的数据则需要法律依据，用于研究时还需要批准。

**法律之外**：公众对NHS数据的信任取决于透明度和公平的条件。即使无法被识别，患者也可能反对用自己的数据来开发商业产品。医院信托应公开这一安排，考虑其能否给NHS带来回报（公平的价值、对产品的使用权），尽可能使用可信研究环境，并让患者和公众参与决策。

**公正与有效性**：数据集应能代表将使用该工具的患者，包括不同年龄、性别和族裔群体，以免产品对某些群体效果较差（[[medical-ethics-law/justice-resources]]）。
:::
:::

下列哪项研究需要研究伦理委员会批准？

- [ ] 一项关于患者对新门诊预约系统满意度的调查，用于本地服务改进。

::: solution
为获得可推广的知识而把患者随机分配到不同干预属于研究，在NHS中需要REC批准（以及参与者的知情同意）。其他几项属于临床审计或服务评价，需要本地批准并必须保护保密，但无须REC审查。HRA的决策工具有助于对界限不清的项目进行分类。
:::

::: history
关于人体实验的一些最早的伦理思考来自医师本身。1865年，克洛德·贝尔纳（Claude Bernard）写道，医师绝不应在人身上进行任何可能对其造成任何程度伤害的实验，即使其结果可能有益于科学。然而在20世纪，许多国家的研究滥用仍持续了很久。

《纽伦堡法典》（1947年）把自愿同意放在首位。世界医学协会的《赫尔辛基宣言》（1964年）把研究伦理纳入了医学界自己的准则，此后经多次修订，最近一次在2024年。比彻的论文（1966年）和塔斯基吉研究的曝光（1972年）促成了美国《国家研究法》（National Research Act，1974年）、《贝尔蒙特报告》（1979年）以及机构审查委员会制度。在英国，从20世纪60年代末起，人们开始期望设立地方研究伦理委员会，自1991年起NHS正式要求设立。TGN1412事件（2006年）改变了首次人体试验的设计，而2026年的英国试验条例使注册和结果报告成为法律义务。
:::

## 后续内容

试验的设计与分析见[[epidemiology-ebm/randomised-trials]]，药物研发和临床试验分期见[[pharmacology/drug-development-prescribing]]，依赖于研究完整发表的系统评价见[[epidemiology-ebm/systematic-reviews]]。知情同意与决策能力在[[medical-ethics-law/consent-capacity]]中讨论，保密与数据在[[medical-ethics-law/confidentiality]]中讨论。

::: summary
- 研究的目的是可推广的知识，因此参与者部分地为他人承担风险；这需要特殊的保障措施。应区分研究与临床审计和服务评价。
- 各项准则源于滥用：纳粹实验（《纽伦堡法典》，1947年）、塔斯基吉、威洛布鲁克、比彻列举的实例、英国的器官保留事件（《2004年人体组织法》）。《赫尔辛基宣言》最近一次修订于2024年；《贝尔蒙特报告》提出了尊重个人、行善和公正。
- 合乎伦理的研究需要社会价值、科学有效性、公平选择、有利的风险—收益比、独立审查、知情同意以及对参与者的尊重。
- 随机分组需要**临床均势**；在没有已证实的治疗时，或有令人信服的理由且不会造成严重或不可逆伤害时，可以使用安慰剂。把握度不足和未发表的试验是伦理上的失败。
- 对研究的同意是书面的、具体的，可自由退出且不得有不当诱导。缺乏决策能力的成人只能依据《精神能力法》第30—34条，或对于药物试验依据临床试验条例纳入；紧急研究允许延迟同意。
- 在英国，HRA和REC审查研究，MHRA监管药品试验；自2026年4月28日起，注册和公布结果成为药品临床试验的法律要求。
- 生物样本库采用广泛同意；全球研究必须回应当地需求并规划试验后可及性。
:::

## 习题

::: exercise 研究还是审计？ {level=1}
对下列项目进行分类：(a) 把本科室的抗生素处方与本地指南进行比较；(b) 通过把患者随机分配为接收或不接收短信提醒，检验短信提醒能否提高就诊率；(c) 描述有多少患者使用新的免预约诊所及其原因。
::: solution
(a) 临床审计：按标准衡量实践。(b) 研究：通过随机分组获得可推广的知识；需要REC批准。(c) 服务评价：描述现行服务，不参照标准。
:::
:::

::: exercise 贝尔蒙特原则 {level=1}
对每一项贝尔蒙特原则，给出它在研究中的主要实际应用。
::: solution
尊重个人：知情同意（以及保护自主性减弱的人）。行善：系统地评估风险与收益，使风险最小化。公正：公平选择参与者，使研究的负担与收益得到公平分担。
:::
:::

::: exercise 需治疗人数 {level=1 check="125"}
在PARAMEDIC2试验中，30天生存率在肾上腺素组为3.2%，在安慰剂组为2.4%。需要给多少名院外心搏骤停患者使用肾上腺素，才能使多1名患者存活到30天？
::: solution
绝对差值$= 3.2\% - 2.4\% = 0.8\% = 0.008$。需治疗人数$= 1/0.008 = 125$。由于神经功能结局良好的生存率无显著差异，额外存活者中有许多人遭受了严重的脑损伤，这就是为什么该结果引发了关于哪些结局对患者真正重要的讨论。
:::
:::

::: exercise 样本量与伦理 {level=2 check="63"}
一项试验将就某个连续变量结局比较新治疗与标准治疗。采用近似公式$n = 2(z_{\alpha/2} + z_\beta)^2 / d^2$（每组），其中$z_{\alpha/2} = 1.96$，$z_\beta = 0.84$（把握度80%），标准化效应量$d = 0.5$，每组需要多少名参与者？向上取整到下一个整数。
::: solution
$(1.96 + 0.84)^2 = 2.8^2 = 7.84$。$n = 2 \times 7.84 / 0.25 = 62.72$，向上取整为每组$63$人。每组只有比如20人的试验把握度低，很可能漏检真实效应；它会让参与者承受研究的负担，却没有很大机会回答问题。
:::
:::

::: exercise 报酬 {level=2}
一个Ⅰ期试验单位为一项为期3周、需住院的首次人体研究向健康志愿者提供4000英镑。一名负债的学生说，钱是她参加的唯一原因。这是否构成不当诱导？
::: solution
在Ⅰ期研究中，为时间、不便和不适支付报酬是被接受的，大多数志愿者参加在一定程度上是为了钱。如果报酬使人接受原本会认为不合理的风险、忽视信息，或隐瞒会使其被排除的疾病，就成为不当诱导。保障措施包括：REC根据时间和负担审查金额，仔细筛查，清楚解释风险（包括TGN1412事件后实行的错开给药及其原因），以及退出时按比例支付报酬。这名学生的动机本身并不使其同意无效，但她应理解风险，不应隐瞒任何会使研究对她不安全的情况。
:::
:::

::: exercise 研究与决策能力 {level=2}
一名研究者希望在缺乏同意能力的中度痴呆患者中研究一种新的记忆评估工具。研究包括30分钟的评估，不改变治疗。根据《精神能力法》，必须满足哪些条件？
::: solution
依据第30—34条：须经作为适当机构的REC批准；研究必须与致损病情（痴呆）有关；必须不可能在有决策能力的人身上同样有效地开展（针对中度痴呆的工具必须在这一群体中检验）；由于它不太可能使参与者直接获益，研究必须旨在提供关于该病情的知识，且风险可忽略，对其自由或隐私无显著干扰（30分钟的评估很可能满足这一点）。研究者必须征询一名个人咨询人（如家庭成员）或指定咨询人，了解该人是否应参加以及其意愿会是什么，并必须让任何看起来表示反对或感到痛苦的人退出。
:::
:::

::: exercise 全球试验设计 {level=3}
一个研究团队计划在一个低收入国家开展试验，把一种廉价的短程疗法与安慰剂比较，用于治疗一种常见感染，而在高收入国家，一种较贵的长程疗法是标准治疗。分析该试验能否合乎伦理。
::: solution
**均势与对照**：根据《赫尔辛基宣言》，对照应是已证实的最佳干预。如果长程疗法已被证实有效且能在试验中提供，安慰剂组就很难成立；把短程疗法与长程疗法比较（非劣效设计）会更合乎伦理。如果两种疗法在当地都无法获得，有人认为安慰剂反映了当地的医疗标准，但这一论点有争议，在1997年的HIV争论中曾受到强烈批评。

**回应性**：研究应针对东道国人群的健康需求，而且如果疗法有效，应在试验后在当地合理地可获得，试验后可及性应在试验开始前就作出规划。

**社区参与与审查**：当地研究者、除申办方所在国以外的当地伦理委员会、社区咨询委员会，以及适合当地语言和读写水平的知情同意程序。

**负担的公平性**：除非有与当地获益相关的有力理由，参与者不应承受在申办方本国不可接受的风险。
:::
:::

::: exercise 结局转换 {level=3}
一项已发表的试验报告某个次要结局（6个月时的生活质量）有统计学意义的改善。试验注册信息显示，主要结局是12个月时的病死率，而论文只是简单提到其“无显著差异”。讨论其中的伦理和科学问题。
::: solution
**科学方面**：在主要结局失败后强调次要结局是一种结局转换。结局多时，有些结局会因偶然而出现“显著”，因此这一发现至多只能用于提出假设（[[epidemiology-ebm/randomised-trials]]）。

**伦理方面**：参与者承担风险是为了回答已注册的问题；报告应如实、完整地交代这一问题。选择性报告误导临床医师和患者，可能导致使用无效的治疗，并浪费参与者的贡献。如果是故意的，可能构成科研不端行为。

**补救措施**：期刊和读者应把论文与注册信息和研究方案相比较；CONSORT报告规范要求明确说明主要结局及任何变更；英国2026年的试验条例要求公布结果摘要，因此无论论文强调什么，已注册结局的结果都可获得。
:::
:::
