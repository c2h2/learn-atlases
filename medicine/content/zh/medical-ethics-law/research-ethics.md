研究伦理之所以存在、是因为医学的知识是由它的受试者付过账的：被记录的滥用——纽伦堡的医师、塔斯基吉被扣留的治疗、短程齐多夫定的试验之争——定了这个领域的语法同意、风险、公平、与问责作为可执行的规则、而不是床旁的美德。**本章研习文件、同意的机器、作为伦理对象的试验未定论、安慰剂、试验后的义务、监管与数据时代、以及真实的困境：一场未注册的试验、对影像的二次使用、以及一个共同体说了“不”。**

## 文件

::: definition 历史的语法及其批评 {#def-documents}
**这份经典实际的内容值得精确地知道、因为临床医师会在没有读过它的情况下被引用来指责他们。纽伦堡法典1947年是法庭判决中的十点——自愿、成比例的风险、退出、其余的由法官们为回应“德国医师审判”的辩护而临时写下、而此后一直尴尬：它成为一个大体上想要防止“其作者当年所惩罚之物”的领域的奠基文件。赫尔辛基宣言1964年、反复修订、最重要的在2000、2008与2013年是那份工作的文件：一个医师协会的宣言、却成了世界事实上的研究宪法、也是唯一一份有可见的修订日志的伦理文书——它修订时的仗安慰剂的地位、照护标准的段落、注册与试验后的条款就是这个领域以编辑方式进行的争论。贝尔蒙特报告1979年提供了三条原则的语法、此后美国的法规把它工业化：对人的尊重同意及其保护、行善套“最小化对最大化”的系统风险与收益评估、至今仍在架构着方案、以及正义受试者的公平选择——塔斯基吉使之具体化的那条原则。从贝尔蒙特长出的那套共同规则——机构的审查委员会、知情同意的要素、最低风险的类别、以及对囚犯、孕妇、儿童与经济上脆弱者的附加部分——是研究伦理变成文书工作的原因、而这是它的成就、也是它永久的抱怨。国际的那一层国际组织的准则、对发展中国家的改编、药物临床试验质量规范的协调、以及欧盟法规近年的集中化回答了那份经典无法回答的问题：当申办方富而站点穷时、适用什么。批评朝两个方向而来。从下面：那种“帝国的伦理”的指控——以知情同意为中心与委员会的审查、输出了一种美国式的程序个人主义、成为本地研究能力的障碍、并忽视了共同的决策结构；以及它的回答：个人保护的那条地板不是文化的帝国主义被剥削的研究者的共同体需要那个审查委员会、恰恰因为它自己的制度辜负了它、以及那个更具建设性去殖民的规划：伙伴而非提取的试验设计、有权提出异议的社区协商、写入资助协议的能力转移、以及接下来的诸定义当作机器处理互惠的义务。**
:::

## 同意的机器

::: definition 研究同意的架构 {#def-consent}
**研究同意与治疗的同意在对象上不同：参与者接受的是“关于收益的不确定”这次试验也许谁也帮不到、而且也许根本不是为他们准备的、并常常授权尚未想象的未来用途。这个领域最扎实的经验发现是治疗的误解：随机试验的参与者系统性地相信“为他们选择的治疗是为他们而选的”、这是一次对“同意唯一要传达的东西”的理解失败——所以称职的回答是过程、不是纸：回述、一个明确随机的检验“没有人、包括你的医师、相信某一组更好——这正是这个问题被提出的原因、以及当方案的风险变化时重新同意。关于范围的设计：逐研究的同意试验的经典；广泛同意概括地同意未来研究的各个类别、在治理之下——生物样本库时代的折中、其批评者问：在一个概括的授权上签名的人究竟理解什么；分层的同意一份用途的菜单——诚实地说、选择的架构会改变人们选什么；通过应用实现的动态或元数据的同意同意作为一种被维持的习惯、而负担最重地落在最年长的参与者身上——那个反复出现的公平发现；以及同意的替代模型——基于记录的研究在英国的路径：在独立的、经过论证的批准之下、可识别的数据不经个体同意而进行那个“为保密而批准的机构”的架构：治理站在同意的位置上、当审查是真的、且通知与退出是公开的是正当的、而当两者之一不成立时恰恰是一个漏洞。偶发的与次要的发现逼出了下一条条款：基因组与影像的研究会在“为别的东西入组”的参与者身上产生临床相关的发现、而成熟的做法是前瞻的——方案与同意里有一份发现的计划寻找什么、回报什么、谁有能力接收、谁为确证付费、以及在安全允许时如何记录并尊重那个真正的“不知晓的权利”、因为在凌晨三点那次计划外的发现、是发明一套伦理所可能遇到的最糟的时刻。能力与代理的研究有其收紧的规则：与无能力的成人一起的研究必须与他们的疾病相关、带有“最低加”的风险上限、并咨询过那个了解他们的被征询者、且除了法律自己的保障之外没有任何东西可以推翻行为能力法的研究条款；在儿科、家长的许可加上孩子的赞同是那条地板、而那个父母同意却自己拒绝的青少年、是尚未解决的案例。**
:::

## 作为伦理对象的试验

::: definition 未定论、安慰剂与试验后的义务 {#def-trial}
**临床的未定论是使随机化成为伦理的那个论证：只要专家共同体对“哪一组更好”确实缺乏共识时才随机这个表述故意把确定性放在共同体、而不是放在研究者的心中、因为个人的确信是不稳定的、而试验的全部要点正在于“确信”应当是那种供应最少的东西。它的测量问题是真实的谁算作共同体；一个高声的少数何时击败共识、而它的保护是薄的对“这个问题”的未定论、无法安慰那位相信自己被分到较差一组的人、但实用的检验存活了下来：一场不敢面对自己的停止规则的试验、通常先失去了未定论、而数据安全监察委员会的章程就是这一伦理居住之处。安慰剂与照护标准之争在1990年代末的艾滋病试验中结晶齐多夫定短程方案的争论：当长程方案能减少传播时、给对照组的妇女“安慰剂加短程齐多夫定”、究竟是对穷人的剥削、还是一场“对照着无”的诚实科学、而它从未完全解决：在“对照着不理想的照护使用安慰剂”上、赫尔辛基、国际准则、与监管机构之间的分歧仍在；方法论的停战是“叠加”的设计在两组都把新的干预或安慰剂加到被优化的标准照护上——它回答了多数指控、却不能回答全部：有时只有“减去”才能证明效应、而残余的是一种委员会必须权衡的真实道德冲突：检测的敏感度试验必须能发现真实的差异对“扣留一种已知的获益”这一错误的重量。假的手术操作把这场论证延伸穿过身体：假手术的试验曾被抗拒为不可忍受安慰剂是一片药、而假操作是一把手术刀、又被它们的结果证明正当清创的试验、其假操作组表现完全相同、从而改写了实践——这个领域的检验是“风险的天花板加上问题的必要性”、不是器械的尊严。试验后的义务是正义那一支：当资助结束时、参与者与共同体将怎样1990年代的“合理的可获得性”之争、来自“正当的研究”文献的“提供成功干预的义务”的诸立场、申办方出于成本对“有期限的延续”的偏好、以及务实的机器：滚动的项目、具名的可及、同情使用的安排、随伦理批准一起提交的过渡计划、以及那个共同体层面的问题——一个被要求维持“试验所证明之物”的卫生系统、是否应得到做这件事的资源。注册与报告补全这一套：一场未注册、未报告的试验、在成为科学上的失败之前先是伦理上的失败——份“所有试验”的证据、注册处的强制、“入组之前注册”的规则、以及“结果在一年内发表”的义务。**
:::

## 监管与数据时代

::: definition 委员会、互惠与研究数据的伦理 {#def-oversight}
**研究伦理委员会或机构的审查委员会是这个领域的中心机构、而习惯地被误解：它不是一场伦理的研讨会、而是一个场所、在其中一份提案必须把它的风险、同意的过程、选择的公平、以及研究者的能力、呈现给“那些不从这门科学中获益的人”来检查——独立性就是要点一个为本机构的声望或其主管的资助盖章的委员会、已经不再是这样一个委员会、而认证与审计的体制就是为了抓住这一点。丑闻产生的病理清单：审查的购物一直提交到获批为止——这就是为什么称职的体制会共享决定并核实先前的拒绝、未经记录的方案的修正终点与同意文本的悄悄改动、顾问能力的表演对跨国方案的本地的审查四分钟完成、因为申办方的时间表才是真正的方案、以及低级别与豁免审查的缺口“质量改进对研究”这条边界的游戏、把发表置于审查之外——审计研究的文献中那场安静的丑闻。对研究站点的互惠是一种较新的义务： 承接试验的共同体常常贫穷、常常被反复使用欠的不只是那一笔同意的交易——各框架的家族关于社区获益与能力增强的国际准则的语言、艾滋病与疫苗及流行病研究中“利益共享与社区参与”的期待、以及“使本地的拒绝成为真实、从而让本地的同意有意义”的试验社区顾问委员会把“不伤害”转换成“值得这一份邀请”。数据时代移动了这个领域的重心：生物样本库使“储存”成为伦理的对象按前面那个定义的同意架构、加上治理：访问的委员会、关联的规则、公众与参与者的委员会、在利润到来之前就声明的收益与商业化的政策、以及“价值的回报对结果的回报”这一区分；基于记录的研究使“可识别性”成为危险那条“具备关联能力的数据就是可识别的数据”的假名化对匿名化的真相、以受控的访问取代隐蔽数据的那五种安全的架构与可信的研究环境、以及让这一点不至于多愁善感再识别的研究；而机器学习使数据集变成行动者训练数据的出处伦理——“为临床照护而同意、如今用于分类”的影像、作为“同意的书面轨迹”的数据集文档标准、“从你的医院的数据派生的模型属于你吗、你说过不吗”这个治理的真空、以及那个“部署之前的分布影响”的职责——正义那章为此布道的算法偏倚审计、以及生成式署名发表伦理的前线要求对每一个主张有人类问责的立场。**
:::

::: example 场未注册的试验 {#ex-unregistered}
你们科室在推动的一款药引用了一项2016年的试验、显示显著的获益；你在任何注册处都找不到它；而申办方的医学主管给你发邮件说：“结果在监管申报完成之前属于商业敏感——明年发表。”而科室希望凭这份证据包获得处方集的准入。
::: solution
**把注册当作被应用的伦理（[[#def-trial]]、[[epidemiology-ebm/systematic-reviews]]、[[pharmacology/drug-development-prescribing]]）：第一个动作是法医学的、不是修辞的：正当地检索注册处世界卫生组织的一级网络与各国的注册记录、包括已撤回与正在招募的状态条目、欧盟的临床试验注册与英国的对照试验注册、那些会泄露这项研究存在伦理批准的编号、以及“反正已经申报”的监管机构的公开评估文件、并向申办方索取方案、统计分析计划与伦理批准——一场经不起这三个要求的试验、从来就不是证据。判读：未注册加上延迟发表加上“只有口头报告”、正是报告的偏倚文献里最坏情形的确切画像未注册的试验的效应量系统性地偏向有利、而选择性发表时代抗抑郁药与抗流感药的重新分析就是教学案例、所以给处方集委员会的诚实总结是“这项试验也许是真的；而我们不被允许知道”、而委员会的决定因此是关于不确定、不是关于这个药。有效的反向压力：科室与期刊路径的提醒一起写信给申办方注册的强制、在存在申报时监管机构的检查权、以及机构审查者能够“把本站点伦理批准的条件设为在持续合作中发表结果”、而同一封信提出证据应得的那个折中在保密之下由独立的统计学家接触个体层面的数据——困难器械与罕见病情形使用的模板。本地的解决：你们机构的研究办公室采纳那条前瞻的条款——没有注册的条目与一个公布发表结果的承诺日期、就不启动有资助试验的站点——因为一个在自己的合作中执行注册的科室、就不再输入这个问题。而处方的后果：这个药留在“未证明但可获得”的药物该在的地方受限的适应证、附带数据的收集、以及那份用平实的话说“这是一次在披露罢工之下的决定”的会议记录——因为塞在会议室文件夹里的证据包、正是一场未注册的试验被处方十年的方式。**
:::

::: example 影像的二次使用 {#ex-scans}
一家商业的人工智能公司提出为你们的放射科免费提供算力、并分享收益、以用二十年的归档影像训练一款分类产品；机构的研究办公室说这批档案是为“临床照护与经批准的研究”而同意的。放射科医师很兴奋；而患者联络经理很紧张。
::: solution
**档案的同意就是那份资产（[[#def-oversight]]、[[#def-consent]]、[[medical-ethics-law/confidentiality]]）：在兴奋之前先审计：最初的同意与机构的通知实际覆盖什么“照护与经批准的研究”的同意、很可能覆盖一项公益的影像研究；它们并不自动覆盖“为机构带来收益的商业产品开发”——治理的问题不是“它是否匿名”、而是“这是不是患者做的那笔交易”、可识别性的现实影像的元数据与再识别的文献意味着“匿名”需要按标准机构的检验来适用并记录、而不是口头声明、以及这笔交易所需的“利益登记”框架机构的收益分享是一种在最终发表中必须披露的利益——代写与馈赠署名的教训、预先承诺。可以成为正当的路径：“同意的替代并加上透明”的模型在一个界定的公共利益理由之上、由真正的保密委员会做出的批准、对正在发生之事的明确公开声明并带一个“针对该档案的退出”的窗口、带发表自由条款的数据共享协议好让公司无法掩埋不便的验证、在任何临床主张之前的独立的外部验证、以及让患者代表真正在场、而不是事后被咨询的治理。在商业上值得为之“去死”的条款、与值得交换的条款：收益分享是可以交换的；发表自由、可审计、兑现退出、以及不把一项公共资产独家锁定、是不可交换的、因为这批档案既是患者的捐献、也是机构公共信任的抵押品、写在同一个文件里。给董事会的诚实的总结句：“我们大概能做好这件事、但前提是患者能够读完整个安排、并且仍然认出他们以为自己做过的那笔交易”——而如果这句话在起草阶段就不成立、它将在小报阶段、连同诊所的信头一起失败。**
:::

**这个领域的分期是“从丑闻到结构”：1947年的判决纽伦堡医师审判在一份法律意见之内产出了法典、以及那并行的一场尴尬：同一批战胜国自己战前的研究——美国的与日本的记录在此后数十年仍在被挖掘、其中包含731部队的豁免交易——未被审判、这也是去殖民的历史学家那条常设的提醒：这份经典的诞生同时也是一场政治；发现时代的暴露威洛布鲁克的肝炎研究、以及使“与易受伤害者一起的研究”成为一个公共类别的机构案例、及美国公共卫生署在塔斯基吉的梅毒研究从1932跑到1972年——1972年由简·海勒揭露、随后的诉讼与建议委员会的工作产出了贝尔蒙特的正义原则、而该研究的受试者们“名义上未被尸检”。赫尔辛基的起草1964年、世界医学协会对纽伦堡的法律主义自己的回答——由医师监管医师——及其修订之战：1975与1983年的修正案收紧同意、1989与2000年那场“安慰剂与照护标准”的爆发艾滋病的行动者与对发展中国家的批评、与流行病学家的“检测敏感度”的辩护相撞、以及2013年修订中作为“被编辑的停战”的注册与试验后及假操作的条款。机构的建设：1974年的国家研究法与审查委员会的体制、1991年的共同规则、1990年代使试验可以在各监管机构之间移动的协调、以及欧盟指令与法规的循环把多国的批准集中化带着“在贫穷的成员国做试验”的批评、把帝国伦理的论证在联盟内部重跑了一遍、以及平行的全球南方的能力运动各国的非洲研究伦理委员会的制度化十年、以及资助方学到的那个反转：“伦理的监管是研究的能力、不是障碍”。2000年代试验执行的丑闻监管失败的案卷——印度与尼日利亚及美国孤儿药的案例、其遗产是“共同体有当事资格”的条款运动、与把“试验后可及的延续规划”作为批准条件的实践、注册的革命2004年以来的强制与“没有注册就没有发表”这条线、以及至今仍发现报告不合规的监管审计——临床医师的版本这段历史更短：你现在觉得碍事的每一项保护、都有一串死亡人数附着在它身上、而你觉得方便的每一个缺口、都有一串在等待——[[medical-ethics-law/professionalism-regulation]]、[[epidemiology-ebm/randomised-trials]]。**
:::

::: example 那次快速的审查申请 {#ex-rapid}
一名顾问医师想在下个月启动一项病房的方案变更、与三家医院的数据收集捆绑在一起；他论证说这次“评估”不需要同意、因为它是审计；多国那一组的资助方是商业的；而他草拟的“批准”来自一家机构的研发办公室、日期是昨天。
::: solution
**审计与研究的边界（[[#def-oversight]]、[[#def-documents]]、[[clinical-skills/patient-safety]]）：先做分类、因为它决定下游的一切：一种为产生可普遍化的知识而做的系统性干预就是研究“审计对研究”的检验——要普遍化的意图、前瞻的操作、作为证据的可分析性——在这里诚实地适用：一个跨三个站点、带商业那一组的“方案加数据收集”的捆绑、形状像研究、注定要发表、而申办方的形状也是、所以“审计”是一条通道的跳跃者、不是一个类别。要在启动之前、而不是在撤稿之后说出的后果：伦理审查的要求而“一份昨天的、只有一个办公室的批准”这一事实、就是其他站点的委员会会问的那个先前的审查问题——由于决定如今是共享的、审查购物是可以被发现的、数据的“同意或有正当理由的豁免”的路径“因为这是审计所以不用同意”这条捷径以同样的方式失败——保密的批准路径需要真正的批准、商业那一组提出研究者的法规培训与保险的问题、以及注册与报告的责任它在有人把“评估”写进一篇论文的方法学那一刻就附着上来。保住这个好想法的修正：把实施科学的那个版本做对一个阶梯式或轮毂式的、“前瞻的伦理或治理的批准与推广并行、而不是依次”取得的设计、审计的部分做基准而不做普遍化的主张、商业那一组作为一份有独立监管的独立合同、在第一个站点启动之前完成注册、以及那个实践共同体的收益——把失败的模式也发表出来。句只说一次、并且带着善意的指导：“最快的研究、是那种事后不必被监管者或编辑叫停的研究；而病房不需要你的方案快、它需要你的方案可发表。”**
:::

::: example 那个说了“不”的共同体 {#ex-community}
一个多国团队提议在一个食品不安全的地区试验一种营养补充剂；当地的社区顾问委员会拒绝背书这种补充剂是申办方的商业产品、对照组是当前不足的口粮、而去年的那项疫苗研究从未共享结果。资助方向本地的站点施压：“孩子们需要这项研究。”
::: solution
**提出异议的权利就是伦理（[[#def-oversight]]、[[#def-trial]]、[[public-health/global-health]]）：正在被检验的架构：社区顾问委员会正是为这个决定而被创造的、而它们的权力只和本地站点“听见不”的意愿一样真实——“同意的提取对同意的关系”文献的那个核心案例。委员会指出的、用研究伦理的话来说的设计问题：对照组把“不足的口粮”作为对照未通过照护标准的检验——“叠加”的修正两组都得到足够的口粮；那时这个问题回答的是“补充剂在照护之上加了什么”、而不是“在饥饿之上”、商业性质的披露在一个买不起这个产品的人口中、阳性结果由谁获利、以及那笔未偿的债那项疫苗研究未归还的结果是一次“试验后与报告义务”的违反、它使这份提议的承诺在信用上不可注资、而不是不友好。本地站点团队可以辩护的立场：委员会的“不”连同理由被书面尊重；在同一口气里邀请反提议修好对照组、无论分组都为两组注资口粮、把本地的研究者列为共同的批准者并掌握发表、注册并预先承诺“在一年之内以本地语言、由具名负责人把结果交回社区”；而那项疫苗研究的结果被索取、若被扣留、就经由期刊、伦理投诉与资助方的路径追究执行的工具是存在的；它们之所以被少用、是因为它们会烧毁关系——这就是为什么这个领域把“执行”写进指南、却很少去做。资助方那句“孩子们需要这项研究”正是本章自己的检验：孩子们需要的是“共同体被允许拒绝”的那种研究——一项其本地伙伴被施压到接受的研究、会因为绝望而招募、因依赖而保留、并因指令而报告、而这个领域自己的档案里“提取数据”的历史一直在演示这一点。值得追求的那个结局：在六个月后、带着修好的对照组、签署收益交回的规划、与被修复的信任、以及先被归还的疫苗研究的结果——“修复是招募的前提”是那个去殖民规划被操作化后说出的话、而委员会的那个“不”、正是让最终那个“是”有价值的东西。**
:::

## 通向何处

试验的设计与其判读在[[epidemiology-ebm/randomised-trials]]与[[epidemiology-ebm/systematic-reviews]]、药物的批准管线在[[pharmacology/drug-development-prescribing]]、同意的机器在[[medical-ethics-law/consent-capacity]]、数据的职责在[[medical-ethics-law/confidentiality]]、研究收益的分配在[[medical-ethics-law/justice-resources]]与[[public-health/global-health]]、而发表的诚信在[[medical-ethics-law/professionalism-regulation]]。

::: summary
- 研究伦理的经典纽伦堡、带修订日志的赫尔辛基、贝尔蒙特与共同规则、国际的那一层是一套对丑闻的回应架构、旨在使滥用的前置条件变得不可能：独立的审查、被记录的理解、注册、以及共同体的当事资格。
- 研究同意是一个被理解的过程、不是一个签名：治疗的误解是要纠正的基线、广泛/分层/动态与同意的替代架构是带有公平后果的治理选择、而偶发的发现需要一份预先商定的计划、包括不知晓的权利。
- 未定论把确定性放在共同体；安慰剂与假操作之争是真实的道德冲突检测敏感度对扣留获益、由委员会来权衡、而“叠加”的设计解决了它能解决的大部分。
- 注册、报告与试验后的义务是正义那一支：参与者是在“他们的贡献会进入记录”这一承诺之下接受风险的——未注册与未报告的试验、无论其个体的结果如何、都是把人当作原材料。
- 数据时代把对象从被入组的身体移到被捕获的数据轨迹：生物样本库的同意架构、可识别性的诚实、受控访问的环境、人工智能训练数据的出处、以及对被署名主张的人类问责——同样是那四个问题、换了一个新的基底。
- 委员会、顾问小组与审计只有在“它们的答案能造成伤害”时才是机构：盖章的审查与被施压的社区同意、是这个领域继续以文书穿着旧滥用外衣的形式。
:::

::: exercise 给文件断代 {level=1}
把下列与出处及一行贡献配对：(a) 自愿、退出、比例性、作为判决中的十点；(b) 三条成为联邦法规的原则；(c) 份带修订历史的医师宣言；(d) “没有注册就没有发表”的规则；(e) 关于资源受限地区研究的指导。
::: solution
**经典的素养（[[#def-documents]]）：(a) 纽伦堡法典、1947年——在法庭里诞生的十点、这个领域那个尴尬的奠基文件；(b) 贝尔蒙特报告、1979年——对人的尊重、行善、正义、随后被编纂进共同规则及其审查委员会；(c) 赫尔辛基宣言——世界医学协会那份活的宪法、其修订之战安慰剂、照护的标准、注册是“以编辑的方式来进行的研究伦理”；(d) 期刊组织的注册要求、2004年前后——把报告的偏倚的解药变成发表的条件；(e) 国际组织的准则——份国际的改编、其对发展中国家的条款推动了“双重标准”的争论以及那个“帝国的伦理对保护的地板”的论证。考试的相关性是实务的：在你第一项获得资助的研究里、你至少会被引用其中的两份、而委员会的问题全都从线索中的一条派生而来。**

::: exercise 修好那份同意 {level=2}
重写这项研究最糟的那一段：“通过签署本表格、您同意参加研究、并免除研究者对任何风险的责任。”这是一项把新的降压药与常规照护对照的随机试验。教给你的重写必须满足的、面向参与者的原则。
::: solution
**作为理解的同意（[[#def-consent]]、[[medical-ethics-law/consent-capacity]]）：一段在三个方面失败：它把“带签名的同意”与“免除责任”混在一起同意不是一份弃权——因研究受伤获得补偿那句话应单独放在那里、并按本法域的规定诚实陈述、它隐藏了随机治疗误解的修正：“治疗将按机会分配、像抽签一样；既不是您也不是您的医师选择了哪一种；这正是我们弄清楚哪种有效的方式”、以及它没有命名任何风险、收益或替代要素：我们不知道什么、可能发生什么、我们期待什么、如果不参加您会错过什么、您如何退出——以及理解的检验：回述、随机的那个提问、以及“您可以退出而您的照护不受影响”的确认。重写的模型：”我们在把我们这款新的降压药片与您本来反正会接受的标准治疗做比较。两者都尚未被证明更好——如果我们知道、这项试验就是不伦理的。分配靠机会。我们会比平时更密切地监测您；副作用可能包括X；您可能不会个人获益；您可以随时停止、而您平常的照护继续进行；如果您被研究的治疗所伤害、这个国家的补偿是这样运作的。请用您自己的话告诉我们您理解了什么。“教学的原则：同意的质量由”参与者能说出什么“来测量、而不是由表单里装了什么——而表单存在的意义、正是让参与者能说出的话是真的。**
:::

::: exercise 评判安慰剂 {level=2}
一项急性偏头痛叠加治疗的试验、提议在两组都用安慰剂加标准的急救药物；第二项为一种慢病加用辅助治疗的试验、提议在撤除有效的标准药两周期间使用安慰剂。分别评判、然后说明你们的委员会应当公布的那条规则。
::: solution
**两个安慰剂、两个裁决（[[#def-trial]]、[[epidemiology-ebm/randomised-trials]]）：第一项通过：两组都接受被优化的标准照护、而试验的叠加药面对的是“之上的安慰剂”——这个叠加设计回答了“扣留”这一异议、因为没有已被证明的东西被扣留、而检测的敏感度来自叠加的差异。第二项是难的案例：把有效的治疗撤除两周、会让对照的参与者为了测量的方便而暴露于可预见的伤害反跳、复发、在某些疾病中不可逆的风险——正是短程齐多夫定之争的结构——而要过关就需要“有强制的科学理由、且不造成严重或不可逆的伤害”这一检验、而当“叠加”的设计能回答同一个问题时、偏头痛或湿疹的生活质量这一终点很少能通过。那条可公布的规则：(1) 安慰剂只允许“对照着没有确立的照护”、或“作为两组既有照护的叠加”；(2) 撤除的设计需要证明“这个问题无法以别的方式回答”、带短的且可逆的暴露、预先设定的救援规则与停止规则、以及有权揭盲的独立数据监察；(3) “对照组的预期伤害”一段要以平实的语言出现在给参与者的信息里、因为一个明白自己可能被要求停用一种有效的治疗的参与者、给出的是一种不同的、也更真实的同意、胜过只听说“一颗糖丸”的那位。伦理学者坚持的那个脚注：一项糟糕试验的伤害、不只对它参与者、也对其“回答得很差的那个问题”今后所有的患者。**
:::

::: exercise 撰写结果的条款 {level=2}
起草在你们的机构承接一项有资助的试验之前你会要求的三条条款250字：注册、结果的报告、以及试验后的可及——每条都要附上机制。
::: solution
**带牙齿的条款（[[#def-trial]]、[[#def-oversight]]）：第一条、注册：”本试验将在第一个参与者入组之前录入世界卫生组织承认的一级注册处；站点在没有注册编号时不予启动、而该编号出现在所有的方案与同意文件中。“执行：研究办公室的启动闸门资金与药房的准入跟着这个编号走——把那条原则反过来面向申办方的站点。第二条、结果的报告：”摘要与个体层面的匿名结果将在研究完成或终止后十二个月内张贴到注册处与一份同行评审的期刊、无论效应的方向或大小；主要研究者持有发表的权力、而协议中不含申办方的否决权、只有三十天的为医学与保密内容的审阅期。“执行：在协议中写明负责人与日期、以机构自己的开放获取政策作为后备、以及预先商定的升级当申办方拖延时由注册处自动张贴——困难的疫苗与器械的协议日益接受这一点。第三条、试验后的可及：”在试验期间从研究产品获益的参与者、将获得持续的、按界定费用承担的继续可及、直到它通过卫生系统被另行提供、或该产品获批并可获得；该计划随伦理申请一起提交、而其状态是这项试验年度治理复审的一项常设议题。“执行：这份计划的存在作为站点签署、以及社区参与委员会持续背书的条件——因为没有复审的那条条款、正是每一家申办方都签过、而每一个参与者论坛都看着它失效的那句话。起草的注记：条款单独看都平淡；它们的功能是累积的——它们让这场试验的承诺在钱已经走开之后仍可被审计、而这正是研究伦理从来要做的。**

你们研究的磁共振方案由自动报告标记出一例无法解释的垂体病变、而当事人是一名参加认知研究的健康志愿者；同意书上写着“偶发的发现将由神经放射科医师审阅、并在有临床重要性时予以告知”。走过接下来的72小时。
::: solution
**正在执行的发现计划（[[#def-consent]]、[[clinical-skills/medical-imaging]]）：流程就是脚本：预先设定的路径研究放射科医师的确证、在志愿者同意“把结果作临床处理”之后做临床级别的复阅、那位具名的、去打这通电话的临床主管——不是数据库管理员、也不是那位学生、以及同意书里那个裁决小组的问题在她签字时、“有临床重要性”意味着某种东西——计划的标准与由谁来适用。72小时：当天或次日的电话、用平实的话说出这个发现、并保留那份不确定一例无法解释的垂体偶发瘤很常见、而且多数是安静的——患病的资料与具名的下一步检查、比“我们会研究一下”带来更多宽慰、把内分泌与影像的随访“预约好”而不是“建议”、句“这不是你来的原因、而它不会终止你的参与”、以及记录这次披露、理解的检验、计划的记录——研究的档案与临床的记录讲同一个故事。事后的治理：这个案例进入这个研究的“偶发发现日志”份率与结局的审计、告诉下一个方案它的计划是否管用——这个领域的发现是：未被记录的偶发发现会安静地累积伤害、以及若同意书原本对此沉默时那份诚实的清算这个困境正是计划存在所要防止的——这就是为什么新的同意书在第一台扫描之前、而不是在放射科医师的肘边、写下那个类别的清单与再联系的规则。给那位志愿者的那句收尾的话：”我们发现了一个我们没有预料到的东西；这是它很可能是什么、这是我们明天要做的事、而你会从一位会持续与你联系的医师口中听到它。“**

::: exercise 教那个“幽灵” {level=2}
一家器械公司起草了你们科室的评价论文、挑选了分析人员、并要求把他们的统计学家“致谢”；而你们的住院医师做了数据的收集与方法部分的写作。列出关于署名与披露的裁定、以及那项避免“逐篇重新谈判”的内部政策。
::: solution
**作为分配正义的署名（[[#def-oversight]]、[[medical-ethics-law/professionalism-regulation]]）：按四条标准的裁定实质的贡献、加上起草或批判性的修订、加上最终的批准、加上问责：那位做了分析的公司统计学家、只有在其余三条也满足、且所属机构与角色被披露时才能成为作者；而当贡献是“受雇起草却无人署名”时、只能“致谢”——而那个“以任何别的名义都算代笔”的规则是双向的：公司不能在署名栏里隐身、却在市场里现身。住院医师们的应得：数据收集加方法的起草是一项实质的贡献——第一作者与方法作者的位置是他们凭权利、而不是凭客气得到的、而“我们为了引用量把顾问的名字加上”这个习惯、正是同一种腐败的“馈赠署名”一半、科室应当在训斥业界的“代笔”一半之前先管住它。披露的架构：指明通讯作者的“担保人”的角色、完整的申办方角色的陈述谁设计、谁分析、谁可以在投稿前评论、对谁做决定、数据可得性的立场、以及协议中的发表自由的条款份承接合同本应包含的条款——见注册条款那道练习：预防住在合同里、不在良心。防止重新谈判的那条常设政策：科室的署名宪章贡献者的角色分类在项目开始时说明并签署、与公司合作的文稿在投稿前经研究治理办公室审阅、以及每年把署名栏与贡献日志对照抽样的署名审计——是让宪章成为一种实践的那台机器。给公司医学主管那句礼貌而终结的话：“如果标准符合而披露完整、我们欢迎你们的统计学家作为作者；我们不能发表的、是一篇真正的作者是一份合同的论文。”**

::: exercise 回应你参与者的家长 {level=1}
一名参与者家长打电话来：“护士说他的扫描没有新的东西、可我读研究的同意书说发现会被回报——我的儿子是不是被隐瞒了什么？”给出回答、然后给出如果答案是“看情况”时的系统修正。
::: solution
**同意的界面与临床的照护（[[#def-consent]]）：回答：研究的影像是按研究方案来读的、而研究方案不是临床方案——一句“没有新的东西”的研究判读、可以合法地意味着“没有研究方案要找的发现、也没有今天临床医师需要的东西”、而一个预先设定偶发发现的路径管辖着会被回报什么同意书所描述的那个类别清单与那个裁决、而这位家长应得：把这个差别明白地说出、若政策如此就把实际的报告共享、并确认临床团队同一份判读。在“电话里的安抚”之前的核实：取出这个研究的发现计划类别清单、谁裁决、沟通的路径、检查放射报告实际的状态在有些机构里“研究级与临床级的判读是不同的文件”——正是下一个系统修正、并给临床团队打电话、好让家庭只听到一个说法。那个“看情况”的修正：同意书的措辞本应把路径具体到“能从这张表格上回答这通电话”——当同意的文本反复造成这种困惑时、触发重新同意与重大的修正、你们研究办公室采纳那份平实语言的“发现”部分的模板、以及单一记录的原则在可行之处、有临床相关性的研究影像被存储并在临床记录中标记、好让治疗的团队与家庭永远不会就同一个大脑读着不同的文件。这段关系的真相：这个问题背后的怀疑“这项研究在对我们隐瞒什么”通常是两套记录系统彼此说不到一起去的声音、而持久的修正是建筑学上的——同意书、报告、与临床医师用同样的话说同样的话、而这正是整节课赖以立足的那条“研究伦理与临床伦理之间的接缝”。**

::: exercise 设计这套治理 {level=3}
你们的学术健康科学中心今后要作为一套常设规划、把其临床影像档案授权给人工智能公司。起草这份治理的文书：同意的基础、可识别性的标准、收益与冲突的规则、发表自由的保障、以及问责的产出——每一条都写明由谁决定、以及如何公布。
::: solution
**一份档案治理的宪章（[[#def-oversight]]、[[#def-consent]]、[[public-health/health-systems-economics]]）：同意的基础：以“公共利益并有正当理由的批准”为先一条保密委员会的路径、带界定公共利益的检验、加上一个真正的、经宣传的、无损害的“针对该档案的退出”——同意的替代作为治理、而不是作为漏洞、并把这笔交易写在患者真正读得懂的一页纸上。可识别性的标准：禁止“匿名”的断言、除非标准机构的检验被记录并可复审、否则就是“假名化并受控地发布”可信研究环境/防火墙内的训练环境这一模型——数据不出去、模型出去、而关联钥匙的治理由一位独立的保管者、而不是商业办公室掌握。收益与冲突的规则：在第一笔交易之前就决定的收益政策命名的“再投入研究的比例”、不长于科学所能证明的独家锁定、没有“带预先注册方案及独立外部验证”的临床主张、以及利益的披露架构每一份派生的发表都带上由登记条目的、而不是由记忆生成的资助与数据来源及角色的陈述。发表自由的保障：一条合同条款——中心不会为“无论结果方向如何都不能发表的”研究授权数据、为保密内容的审阅期有边界且不留裁量、以及把预注册的要求映射到被授权的分析上道练习里的注册条款、如今是常设政策。问责的产出：每一份数据授权的公开登记伙伴、数据集、目的、收益的条款、给董事会的年度档案治理报告、由患者代表对续约投票、对已部署的派生物享有算法审计权正义那章写下的“按受保护群体的分布性能基准”的职责、以及撤销的路径违反宪章的授权将失去数据的访问——正是把一份宪章与一张海报区分开的执行。起草的检验：把每一条写成“让一名记者、一位监管者、以及你们最好的患者倡导者各自都能找到那句用来向你们追责的话”——因为他们之中总会有一个人这么做。**
