同意是法律与伦理共享的那个器官、它把一次“触碰”变成一项治疗、并把一项治疗变成一次协作；而行为能力是决定谁可以使用这个器官的那个唯一的变量。**本章研习同意的要素及其法律的架构（告知的标准、重要性、理解、自愿、授权）、作为“随决定而定”的能力的行为能力（带它的推定、评估、支持与替代）、预嘱与代理的决定、儿童与不断变化的能力、以及同意在研究与不确定之下的特殊形态。**

## 同意

::: definition 各要素及其法律 {#def-elements}
**同意的经典解剖有五个活的部分。告知：必须提供重要的风险、收益与合理的替代方案、而“重要性”的标准在普通法中从“执业惯例”医师通常告知什么迁移到“以患者为中心”的检验这位患者会赋予意义的是什么——蒙哥马利一线的判决把侵权法重新定心、并使风险的谈话成为定制的而不是仪式的；告知的生态包括指南与监管机构规定的清单、患者须知传单在理解上的问题、以及把不确定性诚实地定框以自然频率与分母表达的数字、绝对的风险、以及被传单的安慰性文字 悄悄洗掉的不确定。理解：被检验过的理解的现实同意理解的文献里持久的发现：对风险的回忆很差、治疗的误估会夸大预期的收益、而“你明白了吗——是的”这个勾选框什么也没测量、这使得“回述”成为唯一背后有证据的工具。自愿：免于诱导、不当的压力、以及权力的坡度研究伦理把它形式化、而临床实践大多否认的“医患关系的强制”、使“她同意了”成为一个社会学命题的家庭会议的动力学、以及“对无法负担照护的同意在任何有意义的层面上是自愿的吗”这个财务毒性的问题。能力：本章的第二个定义。授权：签名作为“一个过程的证据”的真实功能、由法律决定的需要书面同意的情形清单手术、研究、某些治疗、电话与电子同意的变通、以及治疗同意与研究同意之间各有独立法律基础的区分合同、侵权、人权的这几层因法域而异、但共享要素的逻辑。两个常设的例外各自带着自己的判例密度：紧急情况“合理的人与默示同意”的救助学说、以及它作为一种懒惰的万能钥匙的被滥用——“它真的是即刻而严重的吗”这一审计、及成文法的治疗体制精神卫生与行为能力法的替代决定框架、它们与《残疾人权利公约》第十二条的“支持性决定”解释的兼容性、是这个十年正在进行的法理。**
:::

## 行为能力

::: definition 能力：推定、评估、支持、替代 {#def-capacity}
**能力是随决定而定、也随时间而定的：理解、保持、权衡并表达的能力行为能力法一类的成文法把它编目、而功能的检验把它操作化的那“四项能力”的框架、并在两个承诺之下运作：能力的推定只有当“心智或脑的损害影响了此刻这个决定”的证据才能推翻、及最大支持的原则在下结论之前用尽一切可行的帮助——简化语言与图片的辅助、安排到服药与睡眠之后的时点、决策辅助与信任者在场、全都算作评估的必要铺垫、而不是礼貌。评估的手艺：诊断与功能的区分一个痴呆或谵妄的诊断不等于无能力；那种“被强制收住而谵妄未治疗”的无能力结论是医源性的、怀疑的滑动尺度严重性与不可逆性提高了评估者要求的证据门槛——普通法“谨慎对待”的传统被操作化、体会与推理的档位为何患者的理由不必好、只需是他自己的——“坏理由也受保护”这条规则把古怪与无能力分开、以及作为推理的记录能在复审中存活评估记录的是被检验的各项能力与回答、而不是被断言的结论。波动的能力有自己的流程谵妄与双相及“黎明时检测”的实践、及“先恢复能力”的规则、它使睡眠与血糖与氧合成为评估的一部分。支持性的决定公约第十二条的改革规划、与加拿大及爱尔兰的协助决定成文法引入了可指定的支持者、而在其纯粹的版本中完全取代了替代的判断——正在进行的争论是：是否有任何支持的模型能在最难的案例中存活、还是监护人仍不可避免、以及对“英国式的最佳利益法庭是按预约排期的正义”的批评。当能力缺席时的替代框架：预嘱这一层见下、持久的授权委托与福利授权的架构范围、登记、以及使这个角色“更像一份职务、而不是一份继承”的受托人的职责、用于重大或有争议的类似保护法院的宣告机器判例所收敛的那个“最佳利益作为带客观参数的替代判断”的混合体、以及保护人与独立代议人的保障——复审的文献不断记录着他们资源不足。儿科的能力有其自己的判例：渐进的能力学说“足够的心智成熟与理解”这一吉尔里克式的表述及其逐案的运作、亲权的责任对少年否决权的不对称“法庭很少推翻拒绝治疗的16与17岁者、却会为15岁者下令治疗”这一比较法上的混乱、成熟未成年人的输血与避孕及堕胎及穿身的适用、以及“儿童的利益、以福利为最高”这一连父母本人也无法放弃的标准——这个三层结构（有能力的儿童同意、亲权的责任、法庭的最终）就藏在这个书库每一章儿科的内容里。**
:::

## 困难的案例

::: definition 预嘱、代理、不确定与研究 {#def-hard}
**预嘱是把自主投射进作者无法观察的那个未来：文书的法律效力各不相同英格兰成文法中“拒绝治疗有约束、要求治疗仅供参考”的不对称、“生前遗嘱”运动的文书生态、以及“治疗范围医嘱与放弃文件”经由病历走的后门、而它的伦理是解释：为想象中的情形而写下的文字如何适用于眼前这个“未被选择的情境与意愿的具体化”这个问题、真实性的检验考虑到关于偏好改变的“痴呆悖论”文献、这是否仍表达作者的价值观、以及那种临床的保全反射、它使有效的拒绝因疾病与因患者而不均等地被尊重。代理的决定代席人与受托人依据一套伦理学家争论不休的层级运作替代的判断——这位患者会说什么；最佳利益——我们对一位患者欠什么；以及判例实际使用的那个混合体、并在可预测的方式上经验地失败乐观与投射的偏倚、把那个真正了解她的人边缘化的家庭层级的动力学、以及“代席人为患者做的选择比患者自己为自己预测的更糟”的研究——它们促使我们在患者仍能给出的时候进行那场价值的病史——句“什么会使生活值得承受”的访谈属于沟通章的重病谈话脚本。不确定之下的同意预后与诊断的是各要素绷紧得最厉害之处：风险沟通的工具绝对的数字、定框的相互抵消、以及“我们不知道、而这是我们能说的”这个档位、试验中治疗幻觉的管理“同意书写得像试验、试验写得像治疗”这个问题、以及理解检验的设计、及推迟与重新同意的实践同意作为一段关系、在每个阶段与每次重大变化时被重访、痴呆研究中“过程的同意”的证据。研究同意这个更严格的物种添上它自己的学说：激励与强制的梯度在不当的影响与正当的补偿之间的报酬伦理、“怀孕的受试者与安慰剂的暴露”特殊情形、生物样本库时代的广泛同意与未来使用及数据治理委员会“一次性、对逐项目、对使用的元数据”同意模型及其信任数据、紧急研究的豁免复苏科学的文献所建立的“无意识的患者与社区协商”的路径、以及入组之后的职责回报结果、重新联系、以及参与退出对数据退出的区分——基因组数据库把它变成了一个家常的法律问题。贯穿这一切的是本章那句唯一的实用之语：**同意是当它变得昂贵时、仍可以指望患者理解并选择了的东西**——而上面每一个要素的存在都是为了让这句话可以被检验。**
:::

::: example 拿着文件夹的儿子 {#ex-advance}
一名79岁的患者因脓毒症嗜睡被送来；他的儿子拿出一份打印的、拒绝“管饲与呼吸机”的“预嘱”、无签名也无日期、并要求“不进重症监护”。而病历里有一份六个月前更晚的疗养院照护计划复审、记录了这个人“除心肺复苏外全面治疗”的意愿。
::: solution
**文件需要被解释、而不是被指示（[[#def-capacity]]、[[#def-hard]]、[[geriatrics-palliative/end-of-life-care]]）：法律工程式的读法：一份有效且适用的、拒绝延长生命治疗的预嘱必须满足形式的检验成文法对特定性、自愿与适用性的要求；一份无签名无日期的笼统陈述很少对延长生命的治疗有约束力、而那份较新的照护计划的条目本来就是当前意愿更好的证据——层级是：患者当下被传达得最好的意愿第一、然后是有效的预先拒绝、然后是被记录的价值的整体、然后代理的判断、然后是最佳利益。临床的时刻：现在治疗脓毒症抗生素、液体、病房级别的治疗、因为这份文件的范围是拒绝指定的干预、而不是拒绝“一般的治疗”、而嗜睡是可能逆转的——“能力会波动、所以伦理也会”这个反射、它阻止一张旧纸做出不可逆的事。与儿子的谈话：那个文件夹的到来是一份礼物、不是一场伏击他是在试图履行对父亲的承诺；团队的工作是指出哪些部分会被自动尊重——心肺复苏的状态、今天讨论并记录下来治疗的上限、而哪些法律无法按面值接受、与老年科医师及姑息同事一起的家庭会议恰当地设定上限“在适当层级的最大治疗”这个定框、诚实地读、多数这类文件追求的正是这个、并把整段经历写回到照护计划里、同时提供一份规范制作的预嘱对的日子、对的谈话。系统的教训：碎片化的文书生态疗养院的表格、从网上打印的生前遗嘱、不同系统里的复苏指令正是为什么每一次严肃的照护计划复审都应产出一份规范的、有见证的、可获取的决定支持文件、以及为什么救护车与入院的文书应当指向它存放的地方。**
:::
:::

::: example 疫苗卡与成熟的十五岁 {#ex-gillick}
一名有针头恐惧史的15岁学生要求在学校接种人乳头瘤病毒疫苗、“因为其他人都在打”；父母反对、“直到我们讨论家庭的决定”。学校护士手里拿着同意书。
::: solution
**渐进的能力在实践中（[[#def-capacity]]、[[paediatrics/immunisation]]、[[clinical-skills/communication]]）：学说的应用：能力随决定而定、而这是一个消息灵通的15岁学生可能有能力做的决定“吉尔里克能力”这条判例的主场——护士对理解、保持、权衡与稳定选择的结构化评估、并记录下来、以及父母否决对同意的不对称有能力的未成年人的同意、即便违背父母、对常规预防级别的决定通常有效；而有能力的未成年人的拒绝、按判例的模式而非其规则、受到更多的顺从——“法庭很少强制治疗拒绝的青少年”这一现实——当能力被认定时、推定站在年轻人一边。真正决定这一天的实践层：先进行家庭的谈话父母的反对是关于程序与保护——两者都可以回应：护士提供信息、之后可以退出的机会、以及“她在任何时点都可以改变主意、包括之后”句脚本、若她透露想要的原因则负有隐私与保密的义务每一次青少年门诊都应做的保护筛查——“为什么是今天、还有谁知道”问题要做好、以及尊重她主动说出的针头恐惧的陪同与舒适的措施应用文献的技术——卧位与肌肉紧张与分散注意力的流程、它们把同意变成一种可忍受的经历、而这是下一次接种最好的推销员。系统的诚实检验：学校接种规划的同意架构的不一致自我同意的实践对家长通知的政策、其差异比它们的法律理论承认的更大、而公正的答案是公布并预先商定的路径：评估、除非年轻人的安全另有要求否则通知父母、在能力被记录时进行、并绝不让“其他人都在打”这种压力替代护士自己的谈话、因为群体的逻辑是她的理由、不是这个学生的理由。**
:::

## 通向何处

能力在精神科的应用在[[nervous-system/dementia-neurodegeneration]]与[[psychiatry/psychiatric-assessment]]、精神卫生法律的平衡在[[psychiatry/treatments-mental-health-law]]、儿童在[[paediatrics/safeguarding]]与[[obstetrics-gynaecology/contraception-fertility]]、同意的文化在[[clinical-skills/communication]]与[[surgery/perioperative-care]]、研究的同意在[[medical-ethics-law/research-ethics]]、而伦理的框架在[[medical-ethics-law/ethical-principles]]。

::: history
**同意的谱系从“殴打”走到“伙伴”：二十世纪初美国的案例施伦多夫那句“每一个成年且心智健全的人都有权决定要对自己的身体做什么”——这句话让自我决定成为一个法律的对象、尽管它的作者后来对它的使用更难看、治疗性豁免的时代告知是医师判断患者能承受的东西、萨尔戈1957年在一次类固醇瘫痪的案件中创造了“知情同意”、1972年坎特伯雷对桑纳森及昂加尔一线的判决向“理性的患者”的转向、以及蒙哥马利一代的判决完成了这场向“患者的重要性”的迁移在整个普通法世界的落地。能力的反面历史：无行为能力与遗嘱认证的传统及其机构的滥用、1960至70年代的去机构化与患者权利的诉讼怀亚特与拉德福德一线的“拒绝治疗的权利”的案件、以及对精神外科同意的委员会、总统委员会时代“能力是随任务而定”的重新表述、它给了法律现代的语法、2000年代的行为能力成文法英格兰2005年那部法律的“推定与最佳利益”架构、爱尔兰与苏格兰的变体、以及残疾人公约第十二条的挑战——2014年的一般性意见的解释把它变成了一场针对替代决定本身的改革规划——各法域正以不同的速度与方向解决这个问题。预嘱从1969年“生前遗嘱”的造词与1976年的那一代案例、经1990年《患者自决法》对医院政策的要求、一直长到便携医嘱与“不入医院复苏”这套机器——急诊文献不断统计着它们与文件之间的错配；痴呆悖论与真实性的争论随着疾病的流行病学一起到来。儿科同意的现代线索从“亲权至上”的时代、经过儿童作为人格的案例、到1985年吉利克在上议院的判决那个25岁以下者能力的表述、以它的俗名输出到整个普通法世界、上诉法院从未完全解决的“成熟未成年人与拒绝”的不对称、以及带有公共卫生例外的青少年保密成文法。研究同意的那条弧属于下一章的历史；而临床的章以签名地位的安静反转作结：从那份决定一台手术合法与否的文件、变成一段关系中的一个人工制品、而这段关系的道德核心是“患者仍是作者”——讽刺的是、表单在字数上的增长恰好测量着这一转变——[[medical-ethics-law/research-ethics]]、[[medical-ethics-law/end-of-life-ethics]]。**
:::

::: summary
- 同意是一个带有可检验要素的过程——重要的告知、理解要回述、自愿要抵御权力的坡度、能力、以及授权——而它的签名只能为其中最小的一项作证。
- 能力随决定而定、也随时间而定、并处于一项推定之下：按理解、保持、权衡与表达来评估、先提供支持、而证据的门槛随决定的严重性与不可逆性升高。
- 缺乏能力的是人、不是诊断、而且是在某些时刻：谵妄与睡眠与血糖铺垫属于评估本身、而受保护的古怪理由不同于缺席的权衡——法庭与病房至今仍在混淆这个区分。
- 预嘱与代理把“作者身份”翻译成能力缺席时的语言、但它们是解释、而不是指令：文件的层级、真实性的问题、以及“较新的照护计划优先”的原则决定了真实的案例、而一份规范制作的单一文件胜过一整个文件夹。
- 儿科的实践运行这个三层结构有能力的年轻人、亲权的责任、法庭的最终、两个方向的评估都要做扎实、而家庭的谈话应在其之前、而不是取代它。
- 研究的同意在自愿与理解上比临床的更严格、因为目的不同：必须拆穿治疗的幻觉、审计激励、并把同意当作一段持续的、在每次重大变化时被重访的关系。
:::

::: exercise 把评估记录下来 {level=1}
为一名68岁、有轻度认知损害、正在拒绝一次怀疑脊髓压迫的紧急磁共振、而谵妄已被筛查并纠正的患者、写出那段能力评估正如它应当出现在病历里的样子。
::: solution
**能在复审中存活的记录（[[#def-capacity]]、[[clinical-skills/records-handover]]）：示范文字：“针对磁共振这一决定的能力评估、14:20、感染与谵妄筛查阴性、血糖与钠与氧正常、日常用药已于09:00给予、未用镇静剂。理解：她用自己的话复述了脊髓压迫的顾虑、以及这次扫描决定治疗。保持：10分钟后未经提示回忆出讨论的要素。权衡：主动触及了取舍（我知道我可能落到轮椅上、但我不会回那家医院、我父亲死在那里）；这种厌恶在情感上与她的历史连贯——她的理由是她自己的、尽管在我看来不是好理由。表达：相隔四小时的两次谈话中、以及被单独询问而有女儿在场时选择一致。怀疑与支持的记录：留下了信息单、给出了决策辅助的数字说明了绝对的收益区间、女儿作为支持者而非决定者、征询了全科医师与平时主管医师的一致、并提供并记录了重新考虑。结论：此刻对这个决定能力存在；拒绝成立；安全网的计划已商定并写下再次联系的标准、次日晨全科医师的复审、并给出并确认理解了呼叫救护车的建议。”教学注解：每一个子句都对应框架的一个要素或一步支持、结论写明这个决定与时间、而这段文字是为不在场的那个读者写的——当能力日后有争议时、是唯一重要的读者。**
:::

::: exercise 处理代理之间的冲突 {level=2}
一名无能力的卒中患者由法庭指定的受托人、与他共同生活二十年的伴侣在目标上一致“舒适、而不是机器”、但在地点上不一致在家伴临终关怀、对受托人所控制的护理机构；患者旧日的病历写着“要么在家、要么哪儿也不去”。为临床团队出主意。
::: solution
**目标一致而地点冲突（[[#def-capacity]]、[[#def-hard]]、[[geriatrics-palliative/end-of-life-care]]）：框架：这场分歧是把行政问题装扮成道德问题——受托人必须适用替代判断的标准是患者本人表达过的价值观“要么在家、要么哪儿也不去”是直接的证据、而受托人的职责是忠于它、不是忠于方便或责任、而这位伴侣是那位价值的证人、法律默认低估他的证词临床团队可以现在就通过记录目标谈话及其来源、来强化那条“谁了解他”的证据规则。临床团队的动作：开一次“先讲共同部分”的会议在记录中明确确认目标上的一致——多数地点的冲突在目标被说出口时会瘪掉、把患者的那句话翻译成要求“要么在家、要么哪儿也不去”意味着什么——他的床、他的猫、不要在走廊里死去；之中哪些是“在家临终关怀”的套餐、哪些是一间优秀的机构房间能满足的、并恰当地对法律机器施压受托人的法定职责包括患者表达过的意愿、而如果伴侣的证据重要且无人代表、团队的路径是向法院申请宣告、而不是在病房里耗着——那个流程能在数日内带着理由解决它。公平与正义的注记：伴侣的地位因法域而异把“自选的家人”排除在外的“最近亲层级”成文法、改革的批评、以及为什么临床团队把“那个重要的人”记录下来、就是团队在任何人都还能被询问时可以做的倡导。病床边的真相：患者在多年前已经说了他的那一份、而那个执行尊重的装置——受托人、病历、法律——正是当前失灵的东西；临床医师的任务是把每一件工具朝向他的话、而不是朝向彼此。**
:::

::: exercise 修正同意的文化 {level=2}
你们机构的审计发现：同意书平均在进手术室前9分钟签署、日间手术关键风险的理解接近于零、口译员被预约了却没用上、“因为家人在这儿”、以及一种“把手术从取消名单上塞回去”的压力文化。带着证据的标签写出改进计划。
::: solution
**把同意当作系统设计（[[#def-elements]]、[[clinical-skills/communication]]）：按证据强度排列的工具：决策辅助与结构化的术前教育（循证分级显示在知识与现实的期待上的改善、在焦虑上较温和）、把回述作为“一项被检查的事项”而不是“一个勾选框”的要求（理解文献中唯一可靠的修补）、为非紧急手术设计“冷却期”的默认在另一次接诊或另一天进行同意的谈话——“提前9分钟”这个做法的解药是排程、不是说教、有牙齿的口译政策禁止“由家人口译”、除非紧急或患者选择、并且“使用率”默认被审计、因为“预约了却没用上”是一个已知的失败模式、而拒绝口译对结局的影响这类公平数据总被埋在指南的附录里、以及取消压力的对策为同意的质量保护时间的规则——外科医师与麻醉医师及名单管理的经济学、不得与患者的理解竞争、这意味着同意的谈话要作为临床工作配置人力、有自己的能力线。治理：把“同意的理解”审计作为机构的一块仪表板重复做抽样的回述、而不是签名的完整、由麻醉医师带头确立“手术可以等到理解为止”的规范他们的术前评估是最后一个站得住脚的拦截点、以及真正有效的训练带反馈的沟通技能的刻意练习的形式、不是那个电子模块。董事会文件需要的那个结尾数据：同意诉讼的环境已转向“患者的重要性”标准、这意味着那张9分钟的表单如今就是它一直是的那种伦理失败的法律债务。**

::: exercise 为试验的报酬出主意 {level=3}
一项健康志愿者的第一期试验为五天的住院提供4000英镑；招募偏向于负债者与学生。申办方说这笔报酬是「对时间的补偿」、而伦理委员会予以批准。用文献中的框架就报酬的伦理向委员会提出建议、并指出补偿在何时变成了逼迫。
::: solution
**报酬、强制与正义（[[#def-hard]]、[[medical-ethics-law/research-ethics]]）：各种框架：不当影响的标准（「会颠覆受试者原本会行使的自愿性」的报酬——那个经典的表述），对比正当补偿的标准（按公平的费率为时间与负担付费、带「工资的等值」的提案——以最低工资乘以付出的基准），对比结构性的正义之框（「招募偏向绝望者」的发现意味着这笔报酬的伦理是一个不平等的问题：同样的钱在不同的银行账户上是不同的诱惑）。委员会带条件的可辩护立场：按工资的等值工作定基准（不是按风险、也不是按市场的急迫），移除「按流失摊扣」的结构（在任何阶段的退出都按比例支付——强制文献中那个具体的修补：以记账方式造成的退出惩罚），声明风险与报酬的脱钩（报酬是给时间的、不是给承担风险的——这句让同意书诚实的话），在「报酬被知晓」与「同意被签署」之间的冷却间隔、以及把招募来源作为一项被监测的指标审计（「在筛选的资料袋里放债务咨询的传单」这一披露职责：如果你在招募经济上脆弱的人、就说清你在做什么、以及为什么它仍然是可以的）。被指出的那个逼迫的阈值：当这笔报酬在入组决定中的分量超过了研究自身风险沟通的清晰度——操作上以已筛选群体「你为什么来这里」的回答来测量、当「以报酬为主」的回答比例超过一个预设的水平就触发重新设计。句诚实的话：第一期的经济学（试验点供给市场的地理）是上游的变量、而一个顺着申办方的日程去优化其受试者福祉的委员会、至少必须把自己的妥协大声地标出价格。**
:::

::: example 那位没有出现的口译员 {#ex-interpreter}
一名罗马尼亚建筑工人的妻子为他的疝修补手术签署了同意书；她把他“既往对麻醉药有反应”的病史翻译成了“以前没有问题”。麻醉医师的术前评估写着“由家人口译、看起来没问题”。
::: solution
**由家人口译是一个安全事件（[[#def-elements]]、[[clinical-skills/communication]]、[[clinical-skills/patient-safety]]）：被记录在案的双重失败：口译员是被预约了的这一发现本身的讽刺——“预约了而没用”就是那个审计类别、而家庭的通道把两个关乎安全的数据点药物反应史与同意的理解朝着“让手术做成”的方向篡改了——“由家人口译”文献已知的危害遗漏、摘要、保护性的编辑、以及一位配偶的保护或遮蔽造成的权力倒转。即刻的职责：暂停手术、并通过专业的口译员重取病史药物反应这一问是任何名单压力下都不能跳过的一项——恶性高热与琥珀胆碱呼吸暂停的病史正是通过这道缝隙进来的、用同一通道重做同意并回述、并诚实地面对口译的可及性经济学视频与电话口译的服务、让正确的路径比诉讼与未遂事故更便宜。背后有证据的政策：禁止由家人口译、除非在低风险的情境中患者自主声明并记录选择、或真正的紧急；把“预约并使用”作为一项安全指标审计与手术安全清单的条目放在同一块仪表板上、因为它们属于同一类伤害；为接待与病房人员做“预约的对象是患者、不是这对夫妻”的训练“他们反正彼此听得懂”这个借口的存续已被记录；以及把公平这一框说清楚：拒绝口译集中在权力最小的患者身上、而它的代价由他们承担、这就是为什么指南机构如今把它同时归入歧视与安全。份同意文件的回溯价值：零——那个签名捕捉到的是错误的人的理解。**
:::

::: example 波动的那个夜晚 {#ex-fluctuation}
一名74岁的髋关节置换后第3天的患者在22:00愤怒地拒绝转往康复、而他素来有傍晚的意识混乱；白天的团队发现他“清楚并同意”。夜间的注册医师今晚必须决定。
::: solution
**波动能力的流程（[[#def-capacity]]、[[geriatrics-palliative/delirium-dementia-care]]）：先做临床的判读：住院的老年人在傍晚为主的意识混乱、在证明别的之前就是谵妄把“黄昏现象”当作诊断这个失败、而寻找它的驱动阿片、抗胆碱药、尿潴留、便秘、感染、低氧、睡眠、眼镜、助听器、以及床头柜上的食物既是伦理的干预、也是能力的干预——“先恢复能力”的规则配上一张治疗清单。伦理的机器：能力随时间而定、所以22:00的拒绝并不推翻上午的同意；正确的动作是推迟决定在他状态最好的钟点、有他习惯的支持者、用简化的重新解释来复评、而不是在夜里争论、今晚做最小限度的治疗这一天真正需要的：镇痛、清晨与理疗一起活动、安全检查——而不是强迫他转院、而他可以在早餐时同意、以及把波动的模式本身记录下来能力记录上带时间戳的一对——上午同意、夜晚伴谵妄特征的拒绝——这份记录保护最终成立的那个决定。只有当清晨带来一个意识清楚的、固定的拒绝时才升级那时做完整的评估、配通常的支持与第二意见、并把按严重度滑动的证据门槛适用于一个赌注——去适应化、跌倒、失去居家——值得严肃对待的拒绝。病房系统的教训：谵妄友好的流程房间内的定向辅助、保护睡眠的 bundle、家属在场政策就是伦理的基础设施、因为那场22:00的危机大多是病房自己医源性的环境、被反射回来伪装成一个能力问题。**

::: exercise 选择那个标准 {level=1}
说出下列各项适用的决定标准替代的判断、最佳利益、患者的作者身份、或某个具体的法律机制：(a) 一位痴呆患者长期说过的“我绝不会那样活着”、对比他现在的满足；(b) 一名没有任何已知意愿的创伤患者；(c) 一名有能力的透析患者一年前记录在案的拒绝输血、如今失去意识。
::: solution
**把标准与事实配对（[[#def-capacity]]、[[#def-hard]]）：(a) 痴呆悖论的熔炉：朝向那句早先陈述的替代判断、对比以当前体验到福利加权的最佳利益——法律的混合体“既往的价值作为强有力的证据、但在没有正式预嘱时无约束力”的立场、被那种“这句话表达的是一种价值、不是一个预测”的真实性读法所缓和、以及把选择讲明并记录下来的临床职责在那个悖论到来之前的价值病史访谈。(b) 紧急状态下的最佳利益：带合理人标准的即刻治疗学说、以及那场“任何有力的他价值观的叙述会建议什么”的搜寻、它绝不能变成家庭的否决。(c) 一份有效且适用的预先拒绝把成文法的形式与特定性的检验适用于这份文件、以及“她上次入院也拒绝过输血”的一致性证据——缺席在场的患者权威、它有约束力、而“临床保全反射”的文献显示它因疾病而被不均等地尊重；于是文件的范围是输血、不是所有治疗决定今晚的方案。这一练习的元要点：每个标准回答的是不同的问题他会怎么说、任何人会怎么说、他自己说了什么、而混淆哪一个是生效中的、正是病房冲突变得无法取胜的方式。**

::: exercise 给一个护理班次讲能力 {level=1}
给出那位护士长应当随身携带的五句话版本：推定、随决定而定、支持优先、“权衡”这一要素的作用、以及记录规则。然后再给一句忙碌病房用的一句话版本。
::: solution
**五句加一句的能力（[[#def-capacity]]）：五句：每一个成年人都被推定为自己做决定、直到此刻这个决定显示出心智或脑的损害在妨碍；能力是关于这个决定的同一个患者可以同意抽血而对截肢无能力、而在一天之中反过来也可以；在任何无能力的结论之前、先最大化眼镜、助听器、安静的房间、上午而不是夜里、信任的人、图片的辅助——支持是评估的前提、不是它的脚注；关键的那项能力通常是权衡患者可以为我们厌恶的理由做选择；他们必须在与理由发生接触——这是古怪与无能力之间的那条线；如果你写下“无能力”、就用那四项能力的语言写下为什么、因为这份记录可能会被一位从未进过那个房间的法官读到。一句话：今天问清楚这颗头脑对这个决定在做什么、尽一切可能帮它、并写下你发现了什么——这就是任何成文法之前的全部手艺。**
:::

::: exercise 审计未成年人政策 {level=2}
你们地区的青少年门诊指导写着：16岁以下需要父母的同意；16至17岁可以同意治疗、但他们的拒绝“可以被推翻”；对严重的拒绝“法庭有最终发言权”。指出每一句话压缩了哪条学说、以及压缩在何处误导了实践。
::: solution
**句子之下的学说（[[#def-capacity]]、[[paediatrics/safeguarding]]）：第一句压缩了吉尔里克能力有足够心智成熟与理解的16岁以下者可以自己同意——“需要父母同意”这条笼统的规定 在法律上是错的、在实践中是致命的：它吓退了依靠例外才能获得服务的避孕与堕胎及精神健康及物质的主诉；第二句压缩了成熟未成年人的不对称判例的模式：法庭很少强制治疗拒绝的青少年、尽管名义上保留了这个权力——“16与17岁者的拒绝在实践中很少被推翻”这一现实被这句话藏了起来、而门诊必须带着“是保护、不是剥夺”这个反射来应对；第三句是对的、但要加一个脚注：对严重的有争议的案件法庭有最终发言权、这意味着团队的职责是尽早的伦理会诊与申请宣告、而不是午夜那种会在复审中被撤销的强制。两个被指出的误导性压缩：16岁以下的笼统规则每一门青少年医学课程都与之矛盾的保密与能力的期待、以及把有能力的未成年人送回可能是问题一部分父母身边的保护代价与那个推翻的威胁“我们可以让你就范”的姿态会把一个可治疗的拒绝变成一次复发——青少年精神病学治疗联盟的发现。审计的产出：一份改写过的一页纸、带能力的评估模板、列出公共卫生与保护例外的保密规则、严重拒绝路径下“我们必须告诉谁”一节、以及给年轻人的传单版本——才是真正会被带走的文件。**

**作为一项“后果已被回答的权利”的退出（[[#def-hard]]、[[medical-ethics-law/research-ethics]]）：草稿：“参与者可以随时退出试验、无需理由、且不影响其临床治疗。退出后续参与在同意的谈话中与撤回已收集的数据被区分开：一汇合就无法实际召回汇总分析的数据、而政策要写明直到退出为止该参与者的个人记录将被如何处理保留并作为去标识的记录分析、对比应请求销毁、并与数据保护中的删除权及其研究豁免条件对应、按法域诚实地说明。生物样本遵循自己那一层的同意样本可以应请求销毁、除非已经匿名或已进入发表的分析这条规则要写在最初的同意里、因为它事后无法添加。临床关系被明确地隔开：只有在参与者同意时、治疗团队才会知道退出、而在有开放延长或同情用药时、退出试验绝不影响获得研究用药的机会。申办方不喜欢的那一段：退出的率及其原因是写在发表里的一个研究结局“参与者不是噪声”的可问责规则、没有它那句“随时可以退出”的承诺就一文不值——一项行使起来被藏起来的权利、是一项让人难堪的权利、而心理治疗与器械试验中退出被低报的文献显示了“报告职责”能纠正多少留存偏倚。操作的附录：退出谈话的脚本致谢、如果愿意才问是否可说的原因、确认数据的偏好、安排参与者接受的任何安全性随访、因为一旦参与者为退出而感到愧疚、那次同意就已经被追溯性地变成了一种义务。**
