纳丁·蒙哥马利（Nadine Montgomery）是一名患胰岛素依赖型糖尿病、身材矮小的孕妇。糖尿病母亲的婴儿往往偏大，她的产科医生知道，像她这样的女性发生肩难产（胎头娩出后胎肩被卡住）的风险约为9%～10%。医生没有告诉蒙哥马利夫人，因为她认为，如果提到这一风险，大多数女性会要求剖宫产。蒙哥马利夫人确实问过婴儿的大小是否会有问题。分娩中发生了肩难产，她的儿子出生时患有脑性瘫痪。2015年，英国最高法院裁定她本应被告知，并且关于必须向患者告知哪些风险的法律已经改变。

同意是尊重自主与日常实践的交汇点。几乎每一项检查、检验和治疗都需要同意。本章说明在英格兰和威尔士怎样的同意才有效、必须向患者提供哪些信息、如何评估一个人是否具有作出决定的**决策能力**、如何依据《2005年精神能力法》（Mental Capacity Act 2005）为缺乏决策能力的成年人作出决定，以及这些规则如何适用于儿童和青少年。

## 怎样的同意才有效 {#valid-consent}

无合法理由触碰他人构成**殴击**（battery），既是民事过错，也可能构成犯罪。正是同意使临床干预合法。1914年，美国法官本杰明·卡多佐（Benjamin Cardozo）用至今仍被引用的话表述了这一原则：“每一个成年且心智健全的人，都有权决定如何处置自己的身体。”

::: definition 有效同意 {#def-valid-consent}
对检查、治疗或照护的同意在下列情况下是**有效**的：

1. 当事人具有作出该决定的**决策能力**；
2. 已以其能够理解的方式，向其提供关于干预的性质和目的、重大风险以及合理替代方案（包括不采取任何措施）的充分**信息**；
3. 决定是**自愿**的：没有胁迫或不当影响。

同意可以是**明示**的（口头或书面），也可以是通过行为**默示**的，例如伸出手臂接受抽血。同意书上的签名是讨论曾经发生的证据；它本身不是同意，如果讨论不充分，签名也不能使同意有效。
:::

同意是一个**过程**，而非一个事件：GMC的《决策与同意》（*Decision making and consent*，2020年）描述的是医生和患者共同作出决定的对话。同意可以随时撤回，即使在操作进行到一半时，除非停止操作本身会使患者面临严重风险。

同意应由实施操作者或经过适当培训、能够回答患者问题的受托人取得。

英格兰法律区分两类缺陷。如果患者没有被**大致**告知操作是什么，则任何同意都不是真实的，临床医生可能承担殴击责任（*Chatterton v Gerson*，1981年）。如果患者知道操作的性质，但没有被告知本应告知的某项风险，则索赔属于**过失**，患者必须证明这一缺陷给其造成了损害。

## 信息告知：从博勒姆到蒙哥马利 {#information}

数十年来，“必须告诉患者什么？”这一问题与其他关于注意标准的问题以同样方式回答：看负责任的医生群体会怎么做。这就是**博勒姆**（Bolam）标准，英国上议院在*Sidaway v Bethlem Royal Hospital*（1985年，西达韦案）中将其适用于风险信息。按照这一标准，如果许多医生不会提及某项风险，那么未提及就不构成过失。

*Montgomery v Lanarkshire Health Board* [2015] UKSC 11（蒙哥马利案）在信息披露方面取代了这一标准。最高法院指出，患者如今被视为能够理解风险并作出决定的成年人，法律应当反映这一点。

::: theorem 蒙哥马利案确立的告知义务 {#thm-montgomery}
医生必须采取合理的注意，确保患者知晓任何推荐治疗所涉及的**重大风险**，以及任何**合理的替代或变通治疗**。

在具体病例的情况下，如果

- 处于患者位置的通情达理之人可能会重视该风险，**或者**
- 医生知道或理应知道这位特定患者可能会重视该风险，

则该风险是**重大**的。

重大性不能简化为百分比。它取决于风险的性质、风险对患者生活的影响、获益对患者的重要性、替代方案及其风险。信息必须通过对话、以患者能理解的方式提供，而不是“用技术信息轰炸患者”。存在一个狭窄的**治疗特权例外**，即披露会严重损害患者健康的情形，但不能因为医生担心患者会作出医生不赞成的选择而援引它来隐瞒信息。
:::

::: proof
法院为何在这里放弃博勒姆标准？博勒姆标准问的是医生作为专家所擅长的问题：治疗是否选择得当、实施得当？患者是否想知道某项风险，则是另一类问题。它取决于患者的价值观和处境，在这方面权威是患者而非医学界。以医生惯常的告知内容为标准，等于让医学界划定患者决定权的界限。

“通情达理之人”这一分支保护那些不提问的患者；“特定患者”分支保护那些特别在意某项风险的人，例如面临手部手术的小提琴手。蒙哥马利夫人两项都满足：大多数女性都会想知道9%～10%的肩难产风险，而且她问过婴儿的大小。

产科医生不提这一风险的理由，即患者会选择剖宫产，恰恰是该标准所排除的。因为获得了风险信息而选择不同的方案并不是损害，而正是告知的目的。
:::

此后有两项重要发展。在*McCulloch v Forth Valley Health Board* [2023] UKSC 26（麦卡洛克案）中，最高法院裁定，一项替代治疗是否“合理”从而必须讨论，由职业惯例标准决定：如果医生在负责任的医学意见支持下判断某替代方案不合理，则无需讨论。医生仍必须讨论所有合理的替代方案，而不仅仅是自己偏好的那一个。

在因果关系方面，在*Chester v Afshar* [2004] UKHL 41（切斯特案）中，一位外科医生未告知1%～2%的马尾综合征风险。患者只能证明她本会推迟手术去征求意见，但上议院多数意见仍判她胜诉，因为否则告知义务将形同虚设。

### 风险沟通 {#risk-communication}

履行蒙哥马利义务取决于良好的风险沟通。风险沟通研究给出的建议是一致的：

- 使用**绝对**风险和**自然频数**（“每100人中约有2人”），而不是单独使用相对风险（“使风险加倍”），并且对每个选项使用相同的分母。
- 既描述发生伤害的机会，也描述不发生伤害的机会；在有帮助时使用图标阵列。
- 用**回授法**（teach-back）核实理解：请患者用自己的话解释。
- 存在语言障碍时，使用专业口译员，而不是家庭成员。

::: example 腹腔镜胆囊切除术的同意 {#ex-montgomery}
一名52岁职业歌手因反复胆绞痛被列入腹腔镜胆囊切除术名单。外科医生的同意书列有出血、感染、胆漏、胆管损伤和中转开腹。讨论中她提到六周后有一场重要的巡回演出。同意讨论还应包括什么？
::: solution
**对通情达理之人而言的重大风险：**常见风险和严重风险，尽可能给出数字（胆管损伤罕见，每1,000例手术中有数例，但后果严重），以及恢复时间。

**对这位患者而言的重大风险：**她已告诉外科医生什么对她重要。全身麻醉对嗓音的影响，包括气管插管造成喉部或声带损伤的小风险，以及恢复到能在巡演中演唱所需的时间，对她而言是重大的，即使对大多数患者并非如此。外科医生应讨论这些问题，或许可与麻醉医生一起讨论，后者可考虑减少喉部风险的气道技术。

**合理的替代方案：**观察等待加饮食建议，或推迟到巡演之后手术，并说明在此期间再次发作或发生胆囊炎、胰腺炎等并发症的风险。

**过程：**给她时间和书面资料，并记录讨论过的具体风险以及她优先考虑的事项。
:::
:::

## 自愿 {#voluntariness}

同意必须是当事人自己的决定。以合理论证进行劝说是正当的，医生可以而且应当推荐自己认为最好的方案。**胁迫**（威胁）和**不当影响**（压倒当事人意志的压力）会使同意无效。

在*Re T (Adult: Refusal of Treatment)*（1992年，T案）中，一名在车祸中受伤的20岁女性，在与身为耶和华见证人的母亲单独相处后拒绝输血，尽管她本人并不是见证人。上诉法院裁定她的拒绝无效，部分是因为母亲的影响，部分是因为她不理解自己的生命可能取决于输血。该案还重申了核心规则：有决策能力的成年人可以出于任何理由拒绝治疗，无论理由是否合理，甚至可以没有理由。

压力也可能来自临床医生和医疗机构。在讨论中安排部分时间单独与患者交谈、给予时间，并明确拒绝不意味着被抛弃，都能保护自愿性。

## 决策能力与《2005年精神能力法》 {#capacity}

只有当事人具有决策能力，同意才有效。在英格兰和威尔士，**《2005年精神能力法》**（MCA）自2007年起施行，规定了检验标准，以及如何为16岁及以上缺乏决策能力者作出决定。与之配套的《实务守则》（*Code of Practice*，2007年）提供了详细指导；修订版守则已征求意见，但截至2026年尚未发布。

::: definition 《精神能力法》的五项原则（第1条） {#def-mca-principles}
1. 除非已确定某人缺乏决策能力，否则必须**推定其具有决策能力**。
2. 除非已采取**一切可行措施**帮助其作出决定而未获成功，否则不得视其为无法作出决定。
3. 不得仅因某人作出了**不明智的决定**而视其为无法作出决定。
4. 为缺乏决策能力者所做的行为或所作的决定，必须符合其**最佳利益**。
5. 在行动之前，应考虑能否以对其权利和行动自由**限制更少**的方式达到目的。
:::

::: definition 缺乏决策能力（第2～3条） {#def-capacity-test}
如果某人在相关时间，**由于**心智或大脑的损害或功能紊乱，**无法就该事项自行作出决定**，则其在该事项上缺乏决策能力（第2条）。这种损害可以是永久的，也可以是暂时的。

如果某人不能做到下列任一项，则其无法作出决定（第3条）：

1. **理解**与决定相关的信息；
2. **记住**这些信息（时间足以作出决定）；
3. 在作出决定的过程中**使用或权衡**这些信息；或
4. 以任何方式**表达**决定。

相关信息包括作出这样或那样的决定，或者不作决定，可合理预见的后果。这一问题按**盖然性权衡**标准判定。
:::

决策能力是**针对具体决定**和**针对具体时间**的：一个人可能能够选择吃什么，却不能管理复杂的财务；也可能在谵妄期间缺乏决策能力，治疗后又恢复。诊断本身永远不能决定这一问题；第2(3)条禁止仅凭年龄、外貌、某种状况或行为来认定缺乏决策能力。

在*A Local Authority v JB* [2021] UKSC 52（JB案）中，最高法院指出，最好按特定顺序适用这一检验。首先问**功能性**问题：参照四项能力，此人是否无法作出决定？只有在此之后，才问这种无能力是否**由于**心智或大脑的损害或紊乱。这一顺序可防止诊断影响对能力的评估，并明确二者之间必须存在因果联系。

“使用或权衡”往往是最难的要素。它并不意味着当事人必须像临床医生那样给予每个因素同样的分量，而是指他们必须能够在作出决定时运用这些信息。重度神经性厌食患者可能明白自己体重危险地过低，却由于疾病使对体重增加的恐惧压倒一切，而无法权衡这一信息。而一个只是价值观不同的人，例如理解拒绝输血的风险、仍选择遵循信仰的耶和华见证人，是在权衡信息，即使临床医生会作出不同选择。

::: warning 不明智的决定不能证明缺乏决策能力
临床医生往往只在患者拒绝建议时才质疑其决策能力，而对同意则不加怀疑。这两种习惯都是错误的。一个对什么都同意的人可能缺乏决策能力，一个拒绝的人可能具有决策能力。不寻常或有风险的决定是仔细审视决策能力的理由，尤其是当它与当事人的一贯作风不符时，但它永远不足以认定决策能力缺失。同样，决策能力不是“全有或全无”的：应记录评估的是哪个决定、何时评估、如何帮助当事人，以及四项能力各自的证据。
:::

::: example 谵妄之夜 {#ex-delirium}
一名81岁男性因尿路感染于凌晨2点入院。他烦躁、注意力不集中，以为自己在火车站。他拔掉了静脉套管，说要回家。上午10点，经抗生素和补液治疗后，他平静下来，定向力恢复。在这段时间内应如何处理决策能力和治疗问题？
::: solution
**凌晨2点：**他似乎患有谵妄，即大脑功能紊乱。首先问功能性问题：他能否理解自己有需要治疗的感染、记住这一点、权衡离开的风险并表达决定？如果在采取一切可行措施（平静的解释、眼镜和助听器、安静的环境、让熟悉的人打电话交谈）后他仍做不到，那么他此刻对治疗决定缺乏决策能力。团队随后可依据《精神能力法》第5条为其最佳利益行事：继续使用抗生素，如果他不能耐受套管，可改为口服；并以限制最少的方式保证他的安全，例如一对一护理而非镇静。任何约束都必须是防止对他造成伤害所必需的，并与该伤害的可能性和严重程度相称（第6条）。

**能否等待？**可以等到他可能恢复决策能力后再作的决定，例如更换居所，应当等待。

**上午10点：**重新评估。如果他现在有决策能力，就由他在充分讨论风险后作出决定。每次评估都应分别记录时间、所涉决定和证据。
:::
:::

## 为缺乏决策能力的成年人作出决定 {#best-interests}

如果16岁及以上的人对某一决定缺乏决策能力，《精神能力法》允许他人在一定限度内代其行事。

::: definition 最佳利益（第4条） {#def-best-interests}
为缺乏决策能力者作出决定的人，必须按照该人的**最佳利益**行事。决定者必须：

- 不得仅以其年龄、外貌、状况或行为为依据作出决定；
- 考虑其是否以及何时可能恢复决策能力；
- 允许并鼓励其尽可能充分地参与；
- 决定涉及维持生命治疗时，不得出于促成其死亡的愿望；
- 在可合理查明的范围内，考虑其**过去和现在的意愿与感受**（尤其是任何书面陈述）、可能影响其决定的**信仰和价值观**，以及其会考虑的其他因素；
- 考虑其指定的任何人、照护其或关心其福祉的任何人、任何受托人和任何代理人的意见。
:::

最佳利益并不等于“医学上的最佳利益”。在*Aintree University Hospitals NHS Foundation Trust v James* [2013] UKSC 67（艾因特里案）中，黑尔女男爵（Lady Hale）解释说，决定者必须从最广泛的意义上，即医疗、社会和心理方面，看待当事人的福祉，并设身处地站在患者的位置上，追问患者对治疗的态度是什么或可能是什么。检验标准仍是最佳利益，而不是“当事人本会作何选择”，但当事人的意愿和价值观分量很重。

《精神能力法》提供了几种法律工具：

- **预先拒绝治疗决定**（ADRT）（第24～26条）。有决策能力的成年人可以预先拒绝在特定情形下的特定治疗；有效且适用的预先拒绝治疗决定与当时作出的拒绝具有同等效力。拒绝**维持生命治疗**必须采用书面形式、签名、有见证人，并声明即使危及生命也适用。如果该决定已被撤回、被后来涵盖同一治疗的持续授权书取代，或与明显不一致的行为相矛盾，则无效；如果治疗或情形与所规定的不同，或出现了本会改变其决定的未预料情形，则不适用。它不能用来要求治疗。
- 关于意愿和偏好的**预先陈述**不具约束力，但在判断最佳利益时必须加以考虑。
- **持续授权书**（LPA）（第9条）。18岁及以上的人可以就**财产和财务事务**和/或**健康与福利**指定受托人。持续授权书必须在公共监护人办公室（Office of the Public Guardian）登记。健康与福利受托人只有在授权人缺乏决策能力时才能作出决定，必须按其最佳利益行事，并且只有在授权书明确授予此项权力时，才能拒绝维持生命治疗。
- **代理人**（deputy）可由**保护法院**（Court of Protection）任命，保护法院也裁决有争议或重大的案件。
- 当NHS机构拟为缺乏决策能力、且除有偿照护者外无人可咨询的人实施重大医疗时，必须委托一名**独立精神能力倡导人**（IMCA）。

没有持续授权书的亲属不能代成年人同意或拒绝。他们的作用是为最佳利益决定提供信息。告诉家属他们必须为成年患者“签同意书”，是一个常见错误。

**剥夺自由。**当照护安排剥夺一个人的自由时，《欧洲人权公约》第5条要求提供保障措施。在英格兰和威尔士的医院和养老院，这些保障措施是**剥夺自由保障措施**（DoLS，自2009年起）；计划中的替代制度“自由保护保障措施”（2019年立法）截至2026年尚未实施。2026年6月，最高法院推翻了2014年*Cheshire West*案（柴郡西案）关于剥夺自由的“试金石”标准（[2026] UKSC 16），相关指南正在修订中。

::: example 拿着文件夹的儿子 {#ex-advance}
一名79岁运动神经元病女性因呼吸衰竭入院，嗜睡到无法交流。她的儿子带来一个文件夹，里面有一份两年前写的文件：“如果我的疾病使我不能自主呼吸，我不希望使用呼吸机，包括面罩，即使这意味着我会死亡。”文件有她本人和一名见证人的签名。呼吸科团队认为无创通气（NIV）可以缓解症状，并将她的生命延长数月。他们应该怎么做？
::: solution
**这是预先拒绝治疗决定吗？**它拒绝的是特定治疗（通气，包括面罩通气），针对的是特定情形（她的疾病使她不能自主呼吸时）。

**它有效吗？**它是在她成年、且据目前所知具有决策能力时作出的。它采用书面形式，有签名和见证，并声明即使她会死亡也适用，因此符合拒绝维持生命治疗的形式要求。团队应核实她没有撤回该决定，此后没有订立涵盖通气的健康与福利持续授权书，也没有作出与之不一致的行为（例如最近同意开始无创通气）。

**它适用吗？**运动神经元病导致的呼吸衰竭正是她所预见的情形，没有迹象表明出现了会改变她想法的未预料情形。

**结论：**该决定对团队具有约束力，如同她此刻拒绝一样，因此他们不得开始无创通气，但必须用阿片类药物和姑息治疗等其他手段缓解她的呼吸困难。若确有疑问，可在保护法院作出裁决期间给予维持生命治疗（第26(5)条）；但不得人为制造疑问。
:::
:::

**紧急情况。**当患者无法表示同意，而需要立即治疗以挽救生命或防止严重恶化时，临床医生可以给予必要且符合其最佳利益的治疗（依据《精神能力法》，在此之前则依据普通法的紧急避险原则）。只能给予不能合理等待的治疗。已知的有效拒绝，包括有效的预先拒绝治疗决定，仍须得到尊重。

## 儿童和青少年 {#children}

**16岁和17岁的青少年**被推定有决策能力同意自己的医疗（《1969年家庭法改革法》［Family Law Reform Act 1969］第8条），《精神能力法》的大部分内容也适用于他们。只有成年人才能作出预先拒绝治疗决定或订立持续授权书。

**16岁以下的儿童**如果具有**吉利克能力**（Gillick competence），就可以表示同意。在*Gillick v West Norfolk and Wisbech Area Health Authority*（1985年，吉利克案）中，上议院裁定，16岁以下的儿童如果具有充分的理解力和智力，能够完全理解所提议的内容，就可以同意接受治疗。是否具备这种能力取决于儿童和决定本身：一个12岁儿童可能有能力同意骨折治疗，却没有能力同意复杂手术。

对于向16岁以下者提供避孕和性健康建议，弗雷泽勋爵（Lord Fraser）制定了指南。临床医生应确信：该青少年理解所给的建议；无法被说服告诉父母，也不愿让医生告诉父母；无论是否避孕都可能发生性行为；不避孕其身心健康可能受损；并且在未经父母同意的情况下提供避孕符合其最佳利益。这些**弗雷泽指南**专门适用于避孕和性健康；**吉利克能力**则是一般检验标准。任何涉及13岁以下儿童的性活动都是需要采取行动的儿童保护问题（[[paediatrics/safeguarding]]）。

缺乏这种能力的儿童，由**负有父母责任**的人同意接受治疗，该人必须按照儿童的最佳利益行事。当父母与临床医生在重大治疗上意见不一致时，由法院按照儿童的最佳利益作出裁决。

**青少年的拒绝。**英格兰法律在这方面是不对称的。在*Re R*（1991年）和*Re W*（1992年）中，上诉法院裁定，有能力的儿童或16、17岁青少年的拒绝，可以由负有父母责任的人或法院为其最佳利益而推翻。法院曾据此批准挽救生命的治疗，例如十几岁的耶和华见证人拒绝的输血。实践中，重大争议应提交法院，而不是依赖父母的同意。

::: example 一名15岁少女要求避孕 {#ex-gillick}
一名15岁少女独自到全科医生处要求避孕。她有一个16岁的男朋友，说两人已有两个月的性生活。她不想让父母知道。全科医生应如何回应？
::: solution
**能力：**评估她对各种选择、其获益和风险以及该决定所涉内容的理解。能讨论这些问题的15岁少女很可能具有吉利克能力。

**弗雷泽指南：**鼓励她让父母或其他信任的成年人参与，如果她不愿意，尊重她的决定。她是否可能继续有性行为？她说是的。不避孕她的健康会受损吗（怀孕和感染风险）？这符合她的最佳利益吗？如果全部满足，全科医生可以在未经父母同意的情况下开具处方。

**儿童保护：**两人年龄差距小，关系听起来是自愿的，但医生应敏感地询问是否存在胁迫、剥削，男朋友的年龄和行为，是否涉及酒精或毒品，以及她是否感到安全。任何剥削或虐待的迹象都会改变判断，并启动儿童保护程序。

**保密与建议：**她和成年人一样享有保密的权利，也有通常的限度（[[medical-ethics-law/confidentiality]]）。除避孕外，还应提供关于避孕套和性传播感染检测的建议（[[obstetrics-gynaecology/contraception-fertility]]），并记录能力评估和弗雷泽标准。
:::
:::

**精神卫生法。**《1983年精神卫生法》（Mental Health Act 1983，已被《2025年精神卫生法》［Mental Health Act 2025］大幅修订）允许在规定情形下未经同意治疗**精神障碍**（[[psychiatry/treatments-mental-health-law]]）。它不授权治疗无关的躯体疾病。在*Re C*（1994年，C案）中，一名被收治于布罗德莫尔医院（Broadmoor）的精神分裂症男性被认定有决策能力拒绝截除坏疽的腿，因为他理解、相信并权衡了相关信息。他没有截肢，并存活了下来。

::: quiz
一名45岁中度智力障碍男性需要在全身麻醉下拔牙。他很焦虑，看到麻醉面罩时说“不”。他的姐姐没有授权书，却说她代他同意。下列哪项说法正确？
- [ ] 他姐姐的同意就足够了，因为她是他的近亲。
- [ ] 他缺乏决策能力，因为他有智力障碍。
- [x] 必须在采取一切可行措施帮助他理解之后，评估他对这一决定的决策能力；如果他缺乏决策能力，则按其最佳利益作出决定，咨询他的姐姐，并采用限制最少的方案。
- [ ] 因为他说了“不”，手术永远不能进行。
::: solution
智力障碍并不能认定缺乏决策能力，没有持续授权书或代理人身份的亲属也不能代成年人同意。团队应帮助他理解（易读资料、事先参观、给予时间、请熟悉他的人在场），然后评估他对这一决定的决策能力。如果他缺乏决策能力，由临床医生作出最佳利益决定，咨询他的姐姐和照护者，并考虑他的意愿和感受，包括他的恐惧。脱敏或口服术前用药等限制较少的方案应优先于任何约束，而约束必须是必要且相称的。他的“不”是重要证据，但其本身并不阻止符合其最佳利益的治疗。
:::
:::

::: history
关于同意的普通法是从殴击案件中发展起来的，例如*Schloendorff*（1914年）。“知情同意”一词出现于美国的*Salgo*案（1957年），同年麦克奈尔法官（McNair J）在英格兰提出了博勒姆标准。*Sidaway*案（1985年）把信息披露交由医学意见决定，斯卡曼勋爵（Lord Scarman）对此持反对意见；同年，他在吉利克案中发表了主导意见。其他普通法国家率先转向以患者为中心的信息披露：美国的*Canterbury v Spence*（1972年）、加拿大的*Reibl v Hughes*（1980年）和澳大利亚的*Rogers v Whitaker*（1992年）。20世纪90年代法律委员会（Law Commission）关于无行为能力问题的工作，促成了《2005年精神能力法》，该法将C案（1994年）中已经适用的功能性检验确立为成文法。蒙哥马利案（2015年）终于采纳了斯卡曼勋爵的观点，时隔三十年。
:::

## 后续内容

对研究的同意有额外要求，见[[medical-ethics-law/research-ethics]]。关于维持生命治疗、预立医疗照护计划和不施行心肺复苏（DNACPR）的决定，见[[medical-ethics-law/end-of-life-ethics]]。《精神卫生法》及其与《精神能力法》的关系见[[psychiatry/treatments-mental-health-law]]，解释风险和核实理解的技能见[[clinical-skills/communication]]。

::: summary
- 有效同意需要**决策能力**、充分的**信息**和**自愿性**。签名是同意的证据，而非同意本身；同意是持续的过程，可以撤回。
- 根据蒙哥马利案（2015年），医生必须确保患者知晓**重大风险**（处于患者位置的通情达理之人或这位特定患者会认为重要的风险）和**合理的替代方案**。麦卡洛克案（2023年）对哪些替代方案属于合理适用职业惯例标准。
- 用绝对风险和自然频数沟通风险，并用回授法核实理解。
- **《2005年精神能力法》**推定当事人具有决策能力，要求提供一切可行的帮助，并保护不明智的决定。缺乏决策能力是指**由于**心智或大脑的损害或紊乱，而无法理解、记住、使用或权衡信息，或无法表达决定。决策能力针对具体决定和具体时间。
- 对缺乏决策能力的成年人，按其**最佳利益**作出决定，重视其意愿、感受、信仰和价值观，并选择限制最少的方案。没有持续授权书的亲属不能代为同意。
- 有效且适用的**预先拒绝治疗决定**对临床医生具有约束力；拒绝维持生命治疗必须采用书面形式、签名、有见证人，并声明即使危及生命也适用。
- 16～17岁青少年被推定能够表示同意；16岁以下者如具有**吉利克能力**可以表示同意；避孕适用弗雷泽指南。未成年人的拒绝可被法院推翻。
:::

## 习题

::: exercise 有效同意的要素 {level=1}
一名患者在护士只解释了肠道准备之后，就签署了结肠镜检查同意书。实施检查的医生没有和她交谈。她的同意有效吗？应该怎么做？
::: solution
很可能无效。她大致知道操作的性质，因此不构成殴击，但没有人告诉她重大风险（例如息肉切除后的穿孔和出血）、获益或替代方案（例如CT结肠成像）。签名并不能弥补这一点。在镇静之前，内镜医生或经过适当培训的受托人应与她讨论这些内容，核实她的理解，回答问题，并确认她仍希望继续。
:::
:::

::: exercise 四项能力 {level=1}
写出《精神能力法》第3条功能性检验中的四项能力，并各举一个支持该能力的可行措施。
::: solution
**理解**相关信息：使用简单的语言、图片、口译员或易读资料。**记住**信息直到作出决定：书面记录、重复讨论、选择当事人最清醒的时间段。**使用或权衡**信息：与当事人一起逐一讨论各选项及其后果，请其信任的人参与。以任何方式**表达**决定：言语和语言治疗师的支持、沟通辅助工具、通过眨眼或握手表示是/否。
:::
:::

::: exercise 自然频数 {level=1 check="3"}
某项操作发生严重并发症的风险为0.3%。用自然频数表示：每1,000名接受该操作的人中，预计有多少人会发生并发症？
::: solution
$0.3\% \times 1{,}000 = 0.003 \times 1{,}000 = 3$。每1,000人中约有3人。同时说明1,000人中有997人不会发生，可以给出平衡的图景。
:::
:::

::: exercise 相对风险与绝对风险 {level=2 check="100"}
一种预防药物使五年卒中风险从4%降至3%。一份宣传单说它“使卒中风险降低25%”。计算绝对风险降低，以及需要多少人服药五年才能预防一例卒中（需治疗人数）。需治疗人数以整数表示。
::: hint
绝对风险降低是两个风险之差；需治疗人数是其倒数。
:::
::: solution
相对风险降低$= (4 - 3)/4 = 25\%$，即宣传单引用的数字。绝对风险降低$= 4\% - 3\% = 1\% = 0.01$。需治疗人数$= 1/0.01 = 100$。用自然频数表示：100人服药五年，1人避免了卒中，3人仍发生卒中，96人本来就不会发生卒中。只给出25%会夸大对大多数患者的获益，符合蒙哥马利标准的讨论应包括绝对数字。
:::
:::

::: exercise 拒绝与决策能力 {level=2}
一名妊娠39周的34岁女性被告知胎儿出现窘迫征象，建议急诊剖宫产。她拒绝了，说想要自然分娩。助产士说：“她一定是缺乏决策能力：没有哪个母亲会拿自己的孩子冒险。”请分析。
::: solution
妊娠并不削弱女性拒绝治疗的权利；胎儿在出生前不具有独立于母亲的法律人格（*St George's Healthcare NHS Trust v S*，1998年）。助产士从不明智的决定推断缺乏决策能力，这是典型的错误。团队应向她提供相关信息，支持她理解，并恰当地评估决策能力。惊恐或针头恐惧可能暂时剥夺决策能力（*Re MB*，1997年），但前提是功能性检验表明如此。如果她有决策能力，她的拒绝必须得到尊重，并继续保留手术的提议；对决策能力确有疑问时，应紧急寻求法律意见。
:::
:::

::: exercise 持续授权书与预先拒绝治疗决定 {level=2}
一名男性曾作出有效的预先拒绝治疗决定，拒绝在患重度痴呆后因肺炎使用抗生素。两年后，他在有决策能力时订立了健康与福利持续授权书，指定女儿为受托人，并授予其处理维持生命治疗的权限。他现在患有重度痴呆和肺炎。女儿要求使用抗生素。由谁决定？
::: solution
根据《精神能力法》第25(2)(b)条，如果当事人后来订立了持续授权书，授权受托人同意或拒绝同一治疗，则预先拒绝治疗决定无效。本例中，在预先拒绝治疗决定之后订立的持续授权书涵盖维持生命治疗，因此预先拒绝治疗决定无效。由作为受托人的女儿作出决定，但她必须按父亲的最佳利益行事，这包括考虑他过去的意愿（例如预先拒绝治疗决定中表达的意愿）以及他现在的意愿和感受。如果临床医生认为她没有按父亲的最佳利益行事，可以请求保护法院裁决。
:::
:::

::: exercise 具有吉利克能力者的拒绝 {level=3}
一名15岁白血病男孩被治疗团队认定具有相应能力，他在第二个疗程发生严重感染后，拒绝第三个疗程的化疗。不治疗的话，他治愈的机会将大幅下降。他的父母希望继续治疗。讨论其伦理和法律状况。
::: solution
**法律：**根据*Re R*和*Re W*，有能力的未成年人的拒绝可以由负有父母责任的人或法院为其最佳利益而推翻，法院通常会批准挽救生命的治疗。然而，依靠父母的同意去治疗一个有能力且拒绝的青少年，在伦理上问题重重，在法律上也有风险；对于如此重大的决定，如果无法达成一致，向高等法院申请是适当的途径。

**伦理：**尊重他正在发展的自主分量很重，因为他的拒绝来自对治疗负担的真实体验；行善在另一方向上同样分量很重。团队应探究他的理由（害怕感染、疼痛、失去学业和朋友、抑郁），尽可能调整治疗计划，并寻求他能够接受的决定。如果需要诉诸法院，必须让他的意见得到表达。
:::
:::

::: exercise 同意书审计 {level=3}
你审计了40份择期髋关节置换的同意书。38份列有“感染、出血、深静脉血栓/肺栓塞、脱位、双下肢不等长”。只有6份记录了任何风险数字，3份记录了对替代方案的讨论，没有一份记录什么对患者重要。根据蒙哥马利案解读这些发现，并提出改进措施。
::: solution
**解读：**标准化的清单可能满足了“通情达理之人”这一分支，但几乎没有证据表明针对特定患者进行了个体化告知、给出了数字或讨论了替代方案（物理治疗、镇痛、减重、推迟手术）。蒙哥马利案要求通过对话告知对**这位**患者而言的重大风险和合理替代方案。没有记录并不证明没有讨论，但使讨论无从证明。

**改进：**门诊前提供以自然频数表示风险的书面资料；使用比较手术与非手术方案的决策辅助工具；在同意书中加入“什么对你重要”和“已讨论的替代方案”提示栏；由主刀医生或经培训的受托人取得同意，且不在手术当天进行；使用回授法；再次审计。
