1995年，一名在法庭上被称为“B儿童”（Child B）的10岁女孩在骨髓移植后急性髓系白血病复发。她的医生认为，进一步的强化治疗成功机会很小，并会带来相当大的痛苦。她的父亲找到了愿意尝试第二次移植的专科医生，但卫生局拒绝支付这笔总计约75 000英镑的费用。上诉法院拒绝推翻这一决定。案卷主事官托马斯·宾厄姆爵士（Sir Thomas Bingham）说：“必须作出艰难而痛苦的判断，决定如何分配有限的预算，才能使最多的患者获得最大的利益。”

每个卫生系统拥有的资金、人员和设备都少于它所能利用的。在一位患者或一项服务上多花钱，就意味着在其他方面少花钱：这就是**机会成本**。问题不在于资源是否被配给，而在于如何配给、由谁配给、依据什么原则。本章讨论分配正义的理论、健康获益与成本效果的测量、英国国家卫生与临床优化研究所（NICE）和NHS机构如何作出决定、公平程序及其法律检验、床旁配给与分诊，以及公共卫生和健康不平等中的正义。

## 分配的层级 {#scarcity}

资源在三个层级上分配。

- **宏观：**政府决定卫生支出与教育、住房或国防支出的比例，以及如何在各项服务之间分配卫生预算。
- **中观：**诸如NICE（国家卫生与临床优化研究所，National Institute for Health and Care Excellence）和英格兰的整合医疗委员会（integrated care boards，ICBs）等机构，决定为一个人群资助哪些治疗和服务。
- **微观：**临床医生决定如何为眼前的患者使用自己的时间、床位、手术排程和检查。

每一层级的决定都会影响其他层级。开具不必要扫描的临床医生，占用了另一位患者所需的能力。一项不资助某种药物的全国性决定，意味着个体医生无法在NHS中开具这种药物。

## 分配正义的理论 {#theories}

公正原则要求公平地对待人。亚里士多德（Aristotle）阐明了它的形式核心：相同者应同等对待，不同者应按其相关差异的比例区别对待。难点在于判断哪些差异是相关的。

::: theorem 公正的形式原则 {#thm-formal-justice}
相同者应同等对待，不同者应按道德上相关的差异的比例区别对待。因此，任何分配都必须说明：(1) 区分人们所依据的**标准**；(2) 为什么该标准与所分配的善品在**道德上相关**。
:::

::: proof
形式原则源于把人视为道德上平等者的理念。如果两位患者在与某项治疗相关的每一方面都相同，那么给一位治疗而不给另一位，就只能用财富、地位或临床医生的偏好等无关因素来解释，这是任意的。反过来，对不同的需要一视同仁（给每个人相同的剂量或相同的护理时间），会辜负需要更大的人。

这一原则并未说明哪些标准是相关的；那是实质性正义理论的任务。但它为任何提议提供了一个检验：说出标准并为其辩护。就医疗而言，“临床需要”和“获益能力”很容易通过检验。对于英国公共资助的医疗，“支付能力”或“社会价值”则通不过。年龄、生活方式和受抚养人存在争议，而关于它们的争论就是关于相关性的争论。
:::

::: definition 卫生领域的分配正义理论 {#def-theories}
- **功利主义：**分配资源以从预算中产生最大的总健康获益（例如最多的QALY）。
- **平等主义：**追求平等，即医疗可及性的平等或健康结局的平等。
- **优先主义：**给处境较差者的获益以额外权重，例如病情最重或最弱势的人。
- **罗尔斯主义：**约翰·罗尔斯（John Rawls，《正义论》（*A Theory of Justice*），1971年）认为，公平的原则是人们在“无知之幕”背后、不知道自己处境时会选择的原则。诺曼·丹尼尔斯（Norman Daniels）将其应用于健康：由于健康保护人们的**公平的机会平等**，医疗具有特殊的道德重要性。
- **自由至上主义：**人们有权拥有他们正当获得的东西；通过税收进行的强制再分配是有限的，医疗是一种市场商品。
- **基于需要：**资源应分配给临床需要最大的人，通常结合获益能力一并考虑。
:::

争论中还经常出现另外两个概念。**公平局数**（fair innings）论证（艾伦·威廉斯（Alan Williams），1997年）认为，每个人都有权享有一段“正常”的健康寿命，因此尚未享有的人比已经享有的人有更强的主张。**救援规则**（rule of rescue）是一种不惜代价拯救处于紧迫危险中的可识别个人的强烈冲动，它可能与能拯救更多统计学意义上生命的政策相冲突。

## 测量获益：QALY与成本效果 {#qaly}

为了比较针对迥然不同疾病的治疗，卫生经济学家需要一个共同的获益尺度。使用最广泛的是质量调整生命年。

::: definition QALY与成本效果 {#def-qaly}
**质量调整生命年**（quality-adjusted life year，QALY）把寿命长度与生命质量结合起来。完全健康地生活一年是1个QALY。在一个被赋值为0.6的健康状态下生活一年（在这个量表上，0等同于死亡，1为完全健康），是0.6个QALY。在英格兰，健康状态的赋值通常来自EQ-5D问卷和人群偏好调查。

**增量成本效果比**（incremental cost-effectiveness ratio，ICER）将新治疗与现行治疗进行比较：

$$\text{ICER} = \frac{C_{\text{新}} - C_{\text{旧}}}{E_{\text{新}} - E_{\text{旧}}},$$

其中$C$为成本，$E$为以QALY计的效果。它给出每多获得一个QALY所需的额外成本。
:::

NICE在其技术评估中使用ICER。治疗与一个**阈值**进行比较，该阈值代表这样一种估计：如果这笔钱用于新治疗，NHS其他地方会损失多少健康。2026年春，NICE根据政府决定，将其标准阈值从每获得一个QALY 20 000～30 000英镑提高到**每QALY 25 000～35 000英镑**。低于下限时，只要证据可靠，通常会推荐该治疗；高于下限时，NICE需要越来越有力的理由，例如估计中的不确定性偏向有利一方、QALY未能体现的创新，或疾病的严重程度。自2022年起，**严重程度修正因子**为导致预期未来健康大量损失的疾病的QALY赋予额外权重（1.2或1.7）。极罕见疾病在高度专科化技术（Highly Specialised Technologies）项目下评估，阈值高得多。当NICE在技术评估中推荐某项技术时，英格兰的NHS采购方通常必须在三个月内予以资助。

::: example 计算ICER {#ex-icer}
一种治疗某类型肺癌的新疗法每位患者花费48 000英镑，而现行治疗为12 000英镑。接受新疗法的患者平均存活1.5年，生命质量赋值为0.7；接受现行治疗的患者存活0.8年，赋值为0.6。计算ICER，并对照NICE的阈值加以解释。
::: solution
**QALY：**新疗法：$1.5 \times 0.7 = 1.05$；现行治疗：$0.8 \times 0.6 = 0.48$。增益$= 1.05 - 0.48 = 0.57$个QALY。

**成本差：**$48{,}000 - 12{,}000 = £36{,}000$。

**ICER：**$36{,}000 / 0.57 \approx £63{,}200$每获得一个QALY。

**解释：**这远高于25 000～35 000英镑。以这个价格，除非适用严重程度加权或其他因素，NICE不太可能推荐它。如果适用1.7的严重程度修正因子，加权增益约为$0.57 \times 1.7 \approx 0.97$个QALY，ICER约为37 200英镑，接近上限。实际中，生产商可能提供保密折扣，使ICER进入范围之内。（真实的评估会对未来成本和获益进行贴现，并对不确定性建模；本例作了简化。）
:::
:::

**对QALY的批评。**QALY很有力，但也有争议。

- **年龄。**针对年轻人的治疗往往产生更多QALY，因为他们可获得的年数更多。有人认为这对老年人不公平；另一些人援引公平局数论证，认为这是恰当的。
- **残疾。**如果一个永久性残疾者的生命质量被赋值低于1，他从挽救生命的治疗中获得的QALY可能更少，这似乎是把他的生命看得更轻。残障权利倡导者认为这是歧视性的。
- **加总。**QALY把许多人的小获益与少数人的大获益相加，仿佛它们是等价的。许多人认为，即使QALY总数相同，挽救一条生命也比缓解成千上万人的轻微症状更重要。
- **谁的价值？**健康状态赋值来自普通公众对疾病的想象，而不是来自患有这些疾病的人，后者往往对自己生命质量的评价更高。

NICE的方法部分回应了这些关切：它不使用年龄加权，采用严重程度修正因子，并在ICER之外考虑平等问题和社会价值判断。

## 公平程序：合理性问责 {#procedures}

由于人们在实质性原则上存在分歧，诺曼·丹尼尔斯和詹姆斯·萨宾（James Sabin）认为，正当性取决于公平的**程序**。他们的框架——**合理性问责**（accountability for reasonableness）——包含四个条件。

::: definition 合理性问责 {#def-a4r}
1. **公开性：**决定及其理由可公开获得。
2. **相关性：**这些理由是公正的人能够接受的、与在资源约束下公平满足健康需要相关的理由。
3. **修正与申诉：**存在质疑决定并根据新证据或新论证修正决定的机制。
4. **执行：**存在确保前三个条件得到满足的监管。
:::

英格兰公法也提出类似的要求。NHS机构可以设定优先次序，法院不会以自己对如何花钱的看法取而代之（*R v Cambridge Health Authority, ex parte B*，即B儿童案，1995年）。但决定必须合法、合理且程序公正。在 *R v North West Lancashire Health Authority, ex parte A, D and G*（1999年）中，一项不考虑个人情况而拒绝向所有人提供某种治疗的政策被认定为不合法。在 *R (Rogers) v Swindon NHS Primary Care Trust*（罗杰斯案，2006年）中，一项仅在“特殊情况”下为乳腺癌资助曲妥珠单抗（trastuzumab，赫赛汀）的政策被认定为不合理，因为在成本并非理由的情况下，该信托无法解释是什么使一位符合条件的患者的病例比另一位更特殊。

未被常规资助的治疗可以通过**个体资助申请**（individual funding request，IFR）提出，申请必须证明患者在临床上属于特殊情况：与患同一疾病的其他人不同，从而会获益更多。采购方还必须遵守《2010年平等法》（Equality Act 2010），包括公共部门平等义务，即考虑决定对具有受保护特征的群体的影响。

::: example 一项个体资助申请 {#ex-appeal}
一位34岁女性患一种罕见类型的癫痫，已有多种药物治疗失败。她的神经科医生希望开具一种获批用于另一种癫痫综合征的药物，而ICB并不为她的疾病资助该药。神经科医生提交了一份IFR。ICB评审组拒绝了申请，理由是“许多患者都会从这种药物中获益，资助她对他们不公平”。这一推理恰当吗？
::: solution
**检验：**IFR评审组要问的是患者在临床上是否特殊（她是否有某种情况，使她比患同一疾病的其他患者获益更多），以及该治疗是否是对资源的适当使用。

**评审组的推理：**“许多患者都会获益”可能是为整个群体制定采购政策的理由，而不是拒绝个人的理由。但对相似患者的公平是正当的关切：如果她与患同一疾病的其他人并无不同，只资助她一人就是不一致的。评审组本应考虑神经科医生提交的具体证据，例如既往反应、替代药物的副作用，或预测疗效的遗传学发现。

**下一步：**神经科医生可以要求书面说明理由，提供更多证明其特殊性的证据，并使用申诉程序。如果许多患者处境相同，正确的途径是请求ICB考虑为该群体制定政策。整个过程中，都应如实告诉患者正在发生什么以及原因（[[public-health/health-systems-economics]]）。
:::
:::

## 床旁配给与分诊 {#triage}

临床医生每天都在分配资源：急诊科谁先就诊，谁得到最后一张重症监护床位，查房时在每位患者身上花多长时间。GMC要求医生公平地作出这些决定，依据临床需要和可能的获益，除非具有临床相关性，否则不得以年龄、残疾、种族、性别或生活方式等为依据；并在因资源限制而无法提供治疗时如实告知患者。

**分诊**按紧急程度和可能获益对患者进行分类。在日常急诊中，目标是先治疗最紧急的患者。在人数压倒性的重大事件中，目标转为为最多的人做最多的好事，因此即使接受治疗也不太可能存活的患者，在稀缺干预措施上可能被给予较低的优先级（[[emergency-critical-care/major-incidents]]）。

COVID-19大流行检验了这些原则。2020年3月，NICE关于成人重症监护的快速指南建议使用临床衰弱量表（Clinical Frailty Scale）为重症监护收治决定提供参考。残障团体指出，该量表未在年轻人、长期稳定残疾者、学习障碍者或孤独症患者中得到验证，在这些群体中使用它可能会排除本可获益的人。NICE在几天之内修订了指南，明确该量表不应用于这些群体，决定必须个体化。这一事件表明，为某一人群设计的工具应用于另一人群时，可能会把不公平固化在其中。

::: warning 年龄、残疾和生活方式不是获益的替代指标
人们往往倾向于用年龄、某个诊断或某种生活方式因素作为判断谁会获益的捷径。这些捷径常常不准确，并可能构成《2010年平等法》下的非法歧视。关于获得治疗的决定，应当基于对该患者可能获益和负担的个体化评估。当吸烟等因素确实改变了某项操作的风险时，可以出于这一理由公开地加以考虑，并应向患者提供改变它的帮助，而不是简单地将其排除。
:::

::: example 吸烟者与手术排程 {#ex-twolists}
某ICB提议，吸烟者或体重指数超过40的人，在戒烟或减重之前不应被转诊接受择期髋关节和膝关节置换术。评价这一提议。
::: solution
**相关差异：**吸烟增加伤口感染和其他并发症的风险，高BMI与较高的并发症发生率相关。这些在临床上与手术的获益和伤害相关，是讨论它们的正当理由。

**问题：**一刀切的规定忽视了个体差异。许多肥胖者从关节置换中获益很大，手术可能帮助他们变得更加活跃。延误会使人长期处于疼痛和行动不便之中，这使减重更加困难。英国皇家外科医师学会（Royal College of Surgeons）和NICE都反对基于BMI或吸烟的一刀切限制。这类规定对贫困社区的人打击最大，因为这两种情况在那里都更常见，从而引发平等方面的关切。

**更公平的替代方案：**把吸烟和体重作为个体化风险–获益评估的一部分；在患者等候期间提供戒烟和体重管理支持，而不推迟转诊；并公开解释理由。这样既尊重证据，也尊重公正的形式原则。
:::
:::

## 正义、不平等与公共卫生 {#public-health}

正义不仅关乎谁得到治疗。健康在很大程度上受收入、教育、住房、工作和歧视的影响（[[public-health/determinants-inequalities]]）。在英格兰，最贫困地区的人比最富裕地区的人寿命短几年，而处于不良健康状态的年数则多得多。威尔士全科医生朱利安·图德·哈特（Julian Tudor Hart）于1971年描述的**逆向照护法则**（inverse care law）指出：“良好医疗的可得性往往与所服务人群对它的需要成反比。”马莫特评述（Marmot Review，2010年）建议采用**比例普遍主义**（proportionate universalism）：提供普遍性服务，并按需要的比例投入力量和资源。

公共卫生干预提出了它们自己的伦理问题，因为它们常常为了人群而限制个人。约翰·斯图尔特·密尔（John Stuart Mill）的**伤害原则**认为，违背一个人的意愿对其行使权力的唯一正当理由，是防止对他人的伤害。纳菲尔德生物伦理委员会（Nuffield Council on Bioethics，2007年）提出了一个**干预阶梯**，从什么都不做和提供信息，到通过激励和默认选项来促成和引导选择，再到限制和消除选择。在阶梯上越往上，需要的正当理由就越强。例子包括对含糖饮料征税、封闭公共场所禁烟（英格兰2007年）、以及位于阶梯顶端的检疫和强制接种疫苗。英格兰将接种COVID-19疫苗作为在护理院工作的条件（2021年实施，2022年撤销），显示了这类措施的争议有多大。

正义也适用于医学的工具。英国政府的医疗器械公平性独立评述（Independent Review of Equity in Medical Devices，2024年）发现有证据表明，脉搏血氧仪可能高估深色皮肤人群的血氧饱和度，从而漏掉低氧水平，并对以不具代表性的数据训练的人工智能工具中的偏倚表示关切。

::: example 一个有偏倚的算法 {#ex-algorithm}
一家医院使用一种算法识别应当被纳入一项额外照护管理项目的患者。它按预测的未来医疗费用对患者排序。一次审计发现，在疾病程度相同的情况下，黑人患者被选中的可能性低于白人患者。哪里出了问题，应如何纠正？
::: solution
**原因：**该算法预测的是**费用**，而不是**需要**。如果某一群体在历史上获得医疗的机会较少，那么在疾病程度相同时，花在他们身上的钱就较少，因此他们看起来风险较低。算法忠实地再现了既有的不公正。2019年发表在《科学》（*Science*）上的一项针对美国一种广泛使用的商业算法的研究，正是发现了这种模式。

**原则：**公正的形式原则要求依据道德上相关的标准进行分配。健康需要是相关的；过去的支出是一个有偏倚的替代指标。

**纠正：**把目标改为直接衡量健康需要的指标（例如活动性慢性病的数目或疾病控制指标），在部署前后分别检验该算法在不同群体中的表现，让患者和社区参与设计，并由人对最终决定负责。对偏倚的监测必须持续进行，因为数据和人群都在变化。
:::
:::

::: quiz
一家初级保健信托决定只为“特殊情况”的患者资助一种抗癌药物，但无法说明在符合临床标准的患者中什么情况算是特殊。成本并不是这项政策的理由。下列哪项陈述反映了英格兰的法律？
- [ ] 该政策合法，因为采购方对支出拥有完全的自由裁量权。
- [x] 该政策不合理且不合法，因为它没有为区分符合条件群体中的患者提供合理依据。
- [ ] 该政策合法，因为这种药物很昂贵。
- [ ] 法院可以命令采购方资助临床医生推荐的任何药物。
::: solution
这就是 *R (Rogers) v Swindon PCT*（2006年）案。采购方在设定优先次序方面有很大的自由裁量权，法院不会决定预算应如何花费（*ex parte B*）。但决定必须合理：一项声称只在特殊情况下资助某药、却不提供任何方法区分符合条件的患者中特殊与普通病例的政策，是任意的。法院不会命令提供特定治疗；它们要求决定以合法的方式作出。
:::
:::

::: history
1962年，美国记者沙娜·亚历山大（Shana Alexander）在《生活》（*Life*）杂志上描述了西雅图一个由普通人组成的匿名委员会，该委员会决定哪些肾衰竭患者可以接受当时新兴而稀缺的慢性血液透析治疗，部分依据是对社会价值的判断。这个“上帝委员会”成为不应如何配给的象征。1971年，朱利安·图德·哈特描述了逆向照护法则，约翰·罗尔斯出版了《正义论》。

20世纪90年代，美国俄勒冈州对数百个“疾病–治疗”组合进行排序，以决定其医疗补助（Medicaid）计划覆盖哪些项目，这是明确设定优先次序的一次早期公开尝试。B儿童案（1995年）将配给问题带入英国的公共讨论。NICE成立于1999年，负责就治疗的价值作出全国性的、以证据为基础的决定，终结了许多药物所谓的“邮编彩票”现象。它的方法屡经修订，包括2022年的严重程度修正因子和2026年更高的成本效果阈值。
:::

## 后续内容

卫生经济学和卫生系统的组织见[[public-health/health-systems-economics]]，健康不平等见[[public-health/determinants-inequalities]]，全球卫生正义见[[public-health/global-health]]。重大事件中的分诊见[[emergency-critical-care/major-incidents]]。单张稀缺床位的分配已在[[medical-ethics-law/ethical-principles]]中讨论，研究中的公平纳入见[[medical-ethics-law/research-ethics]]。

::: summary
- 资源总是有限的；每一次分配都有**机会成本**。分配发生在宏观、中观和微观三个层级。
- **公正的形式原则**要求依据道德上相关的标准同等对待相同的情况。临床需要和获益能力是相关的；支付能力和社会价值则不相关。
- 分配正义的理论包括功利主义、平等主义、优先主义、罗尔斯主义、自由至上主义和基于需要的路径；争论中常出现公平局数论证和救援规则。
- **QALY**结合了寿命长度与生命质量；**ICER**是每多获得一个QALY的额外成本。自2026年起，NICE的标准阈值为**每QALY 25 000～35 000英镑**，自2022年起采用严重程度修正因子。QALY因对老年人和残疾人的影响以及加总问题而受到批评。
- 公平程序（**合理性问责**）要求公开性、相关性、申诉和执行。英格兰法院要求决定合理、合法（*ex parte B*、*ex parte A, D and G*、*Rogers*），而不是要求特定的结果。
- 床旁决定必须基于个体的需要和获益，而不是年龄或残疾等替代指标；COVID-19衰弱量表事件显示了其中的风险。
- 正义延伸到健康不平等（逆向照护法则、比例普遍主义）、公共卫生干预（伤害原则、干预阶梯）以及器械和算法中的偏倚。
:::

## 习题

::: exercise 说出理论 {level=1}
下列每句话最符合哪种正义理论？(a)“我们应当把预算花在能买到最多健康的地方。”(b)“病得最重的人应当优先，即使我们本可以更多地帮助其他人。”(c)“如果你不知道自己会贫穷还是富有、健康还是患病，选择你会接受的规则。”(d)“一个已经活到85岁的人已经活够了；一个20岁的人有更强的主张。”
::: solution
(a) 功利主义。(b) 优先主义（或基于需要）。(c) 罗尔斯主义。(d) 公平局数论证。
:::
:::

::: exercise 计算QALY {level=1 check="3"}
一种治疗使患者在赋值为0.75的健康状态下生活4年。这相当于多少个QALY？
::: solution
$4 \times 0.75 = 3$个QALY。
:::
:::

::: exercise 一个ICER {level=1 check="25000"}
一种新药每位患者比现行治疗多花费40 000英镑，每位患者多产生1.6个QALY。计算ICER（英镑/每获得一个QALY）。
::: solution
$\text{ICER} = 40{,}000 / 1.6 = £25{,}000$每获得一个QALY。这处于NICE标准阈值范围（自2026年起为25 000～35 000英镑）的下限，因此如果证据可靠，通常会被认为具有成本效果。
:::
:::

::: exercise 严重程度修正因子 {level=2 check="30000"}
一种针对严重疾病的治疗，未加权的ICER为每QALY 36 000英镑。NICE判定该疾病符合1.2的严重程度权重，该权重乘以所获得的QALY。加权后的ICER是多少（英镑/每QALY）？
::: hint
把QALY增益乘以1.2，相当于把ICER除以1.2。
:::
::: solution
加权ICER$= 36{,}000 / 1.2 = £30{,}000$每QALY。这落在25 000～35 000英镑的标准范围内，因此严重程度修正因子可能改变推荐结论。该修正因子表达了这样一种判断：重病患者的健康获益值得额外权重，这是在一个以功利主义为主的方法中的优先主义成分。
:::
:::

::: exercise 加总 {level=2}
项目A为50人每人带来1年额外的完全健康。项目B为5 000名轻度花粉症患者每人带来0.01个QALY（约3.7天的完全健康）。两者花费相同。按QALY比较两者，并解释为什么许多人仍然更倾向于项目A。
::: solution
A：$50 \times 1 = 50$个QALY。B：$5{,}000 \times 0.01 = 50$个QALY。两者QALY相等。许多人更倾向于A，因为对每个人来说获益巨大、足以改变人生，而B对每个人的获益微不足道。这种直觉反映了对个人和需要严重程度的关切，而简单的QALY加总忽略了这一点。优先主义和基于需要的观点可以解释这种偏好；严格的功利主义则不能。
:::
:::

::: exercise 逆向照护法则 {level=2}
举出全科诊所可以在自己的服务人群中减轻逆向照护法则的三种方式。
::: solution
可能的答案：(1) 主动识别并邀请不来就诊的高风险人群（例如利用高血压、糖尿病或严重精神疾病登记册）；(2) 为有复杂需要、多种疾病或沟通困难的人提供更长的就诊时间；(3) 减少就医障碍，例如提供口译、灵活的预约时间以及面诊与远程相结合的方式，而不是让数字途径成为唯一途径；(4) 与社区组织和社会处方联络员合作，解决社会需要；(5) 按贫困程度和种族审计筛查和免疫接种的接受率，并针对差距采取行动。
:::
:::

::: exercise 激增期间的分诊 {level=3}
在一次严重的呼吸道传染病流行期间，某医院重症监护病房已满，有三位患者需要机械通气：一位32岁、无合并症的重症病毒性肺炎患者，一位58岁、糖尿病控制良好的类似肺炎患者，以及一位47岁、患唐氏综合征的类似肺炎患者。目前只有一台呼吸机可用；另一家医院可以在两小时后接收一位患者。讨论应当如何作出公平的决定。
::: solution
**标准：**决定应基于对每位患者现在接受通气可能获益（存活概率和需要的紧迫性）的个体化评估，而不是基于年龄段、学习障碍或对生命质量的笼统判断。

**个体化评估：**47岁患者的唐氏综合征本身并不是降低优先级的理由；问题在于是否有任何具体的临床因素（例如先天性心脏病或既往肺部疾病）改变了其可能的获益。58岁患者控制良好的糖尿病可能略微增加风险，但应与其他因素一并考虑。目前病情的严重程度很重要：谁在没有通气的情况下会恶化得最快，谁可以安全地等待转院？

**程序：**由高年资临床医生——最好是一个不直接照护这些患者的分诊小组——透明地应用已公布的标准；决定应有记录、经常复审，并如实告知患者和家属；未接受通气的患者应获得最佳的替代照护，包括无创支持以及在适当时提供姑息治疗。

**COVID-19的教训：**在某一人群中验证的工具（例如在老年人中验证的临床衰弱量表）不应应用于其他人群；即使在紧急情况下，平等义务依然适用。
:::
:::

::: exercise 没有好选项的资助决定 {level=3}
某ICB本年度还剩100万英镑可用于新投资。有两项提议：(A) 一种用于20位罕见、迅速致命疾病患者的新药，每人约增加1.5个QALY；(B) 为600名年轻人扩展社区精神卫生服务，估计每人获得0.08个QALY。每项花费均为100万英镑。计算每项的每QALY成本，并讨论除数字之外，一个公平的决定还应考虑什么。
::: solution
**数字：**A产生$20 \times 1.5 = 30$个QALY，约为$1{,}000{,}000/30 \approx £33{,}300$每QALY。B产生$600 \times 0.08 = 48$个QALY，约为$1{,}000{,}000/48 \approx £20{,}800$每QALY。B用同样的钱产生了更多的健康。

**其他考量：**严重程度（A的患者面临迅速死亡，优先主义观点会给予加权）；不确定性（B的估计有多可靠，它取决于长期效果）；公平（如果B能惠及贫困群体，可能减少不平等；A的患者没有替代选择）；救援规则（A的患者是可识别的个人）；法律义务（NICE批准的治疗必须资助；平等义务）；以及程序公平（公开理由、让患者和公众参与、提供申诉途径）。一个公平的程序可能基于成本效果资助B，同时为A寻求全国性的资助途径（例如NICE的高度专科化技术项目），并公开解释理由。
:::
