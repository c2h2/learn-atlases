临床实践中的分配正义、是多数临床医师体验为失败的那门伦理：门诊的长队、被拒绝的资金申请、分诊的推车、给了有关系的人的那个工作岗位、以及招不到人去需要他们的地方的那个专科。**本章提供分配的理论（结果的聚合、优先主义、充足主义、平等主义）、微观分配的机制（排队、分诊、申请与申诉）、宏观的层次（覆盖、成本效果、以及临床医师在其中的角色）、以及职业自己分配的东西：人手、任务、以及谁必须去最苦的地方。**

## 诸框架

::: definition 分配的理论 {#def-theories}
**临床医师实际用来争论的四个家族：后果主义的聚合使总收益最大——质量调整生命年的工程形态、成本效果阈值的伦理、以及它两个经典的反对：“人的分离性”的抱怨跨人与人与人的加总可以为碾碎一个人辩护与“水平”的异议总量忽视谁处境最差——那个“抢救略重一点而更便宜的群体、而不是濒死的少数”的反例、正是带公平权重项目预算的文献为回答它而被建造、优先主义给处境更差者更多权重、“优先的利维坦对聚合的利维坦”之争、带着它们的形式工具——优先的权重、以及残障权重的争议、充足主义确保每个人达到一条足够的地板——“基本卫生服务与基本药物清单”以及国际发展目标的架构、带着它“地板让顶层不受约束”的批评、与“地板才是人们实际能达成一致的东西”的辩护、以及平等主义减少可避免的健康差距——健康公平与“倒置的关怀”律的传统、及其定义性的劳动：水平对垂直的公平同等需要同等对待、不同等需要不同等对待、“这个差距是不公平、还是仅仅不同”的区分“因不义而不健康、对生物学的变异”这条界线、以及世界卫生组织的框架所追踪的“结局对可及对财务保护”这几个公平维度。责任与运气的争论“生活方式应当影响诉求吗”之辩——吸烟与肝移植与关节置换、及“前述烟草税的威慑对设置可及性条件的理论”的伦理、“责任契合”的观点、对“运气平等主义对弱者太残酷”的批评安德森与后来的关系平等主义的回答：问题不是你的选择是否造成了你的疾病、而是你能否作为平等者站立、以及实务的解决：以临床的适格性与证据为基础的规则——“戒烟或减重是否是成功的预测因子”提问由结局数据来回答、把道德的框架放到一边。**
:::

## 机器

::: definition 微观分配：队列、分诊、申诉 {#def-micro}
**等待名单的伦理规则设计的空间：先到先得作为道德的默认、其辩护者称之为尊重、其批评者称之为倒退；按“进入时的严重度”对“在名单上等待期间的进展”来排序“名单上的紧迫对慢性”之争——最病优先惩罚稳定的、奖励恶化的、以及按严重度加权的系统所记录的那种“等到最重才列入”的临床行为的扭曲、“按紧迫调整与按结局调整”的评分的工程学终末期肝病与心脏风险的评分、以及“按预期收益排序是否是一个伪装成效用评分”之争、取消与延迟及“患者是否死在名单上”的死亡审计的职责、以及自费与礼宾服务及“双轨医学”插队的伦理“第二条名单是不是二等的权利”这一分析、以及它“要透明、而不禁止”的默认折中。分诊另有一套伦理灾难与新冠呼吸机矩阵文献中已确立的内核：使被救的生命数最大化、排除徒劳的病例、“没有先到先得、分诊官看不到隐私、以及在激增的照护标准下的法律盾牌、以及不要把你自己的名字放进分配的那条分诊与治疗分离的规则、医护人员的“优先主义对工具价值”之争、其解决被疫苗接种的优先级表明确地写出来“在住户之后排 必要人员”与“互惠的论证”两行、以及残障社群有理的指控——“把值得活的生命年计入的分诊方案就是歧视”——以及已确立的纠正：不得按残障状态本身做效用的折减、只做临床的适格与共病负担的评估。资金申请与申诉的架构个体化资金申请那个“这是一项权利、还是一张彩票”的问题：“临床的优先对成本效果”这两问的表格、“让临床医师能够为患者辩护的申诉”这个功能、“灰姑娘式申诉”的批评——有雄辩基金会的疗法会赢、沉默的疾病会输——以及试图让取舍被公开做出的项目预算与人群资金的设计。**

## 宏观的层次

::: definition 覆盖、成本效果、以及临床医师的角色 {#def-macro}
**卫生技术评估的伦理技术评估与“不决策的覆盖”规则：“成本效果阈值是一块配给的斗篷、还是一条可问责的线”之争、各国评估机构的“这是科学、还是一个带区间的政策”这一透明性问题、“严重度修正与生命末期及罕见病”的例外它们是本国机构登记在册优先主义的让步、以及“例外既证明又掏空了规则”的论证、患者与公众参与评估委员会那个“谁代表谁”的批评、以及“保密的折扣与带条件准入的协议”套“基于价值的定价在暗中被谈定”这一合法性问题透明运动正对准它；基本药物与人人都有的那条地板这一层模型清单的“有效、公平、可行”三元的伦理、“自付与灾难性支出及因病致贫”的全球负担的文献——它使财务保护成为卫生系统正确性的问题、而不是福利的事后补充、以及“一百项基本干预对全民覆盖作为一个政治工程”的论证。“临床医师应当配给吗”这个双角的困境：病床边“眼前这位患者”的诉求有信义的力量——临床医师的辩护职责、“在床边不谈费用”的规范美国医学捍卫它、而英国医学悄悄打破它——文献对此做了测量、以及那个重新定框：有伦理临床医师的成本是系统应当看见的、因此有指南与资金、及“我的科室是否欠总体预算一份公平的份额”职责对人群“在采煤的最前线不可见的配给”这一真相：每一条带年龄或严重度截点的临床指南、本身就是由临床医师写成的配给、以及“辩护的悖论”——从不提及成本的临床医师、活该得到他们所拿到的预算——而专业精神的回答是：成本意识是你也被其雇佣的那个人群的一项职责、要经由系统的通道处方集、指南、以及委托购买的职务来行使、而不是在床边安静地限制——一切系统研究的结论都是“沉默的床边配给是最坏的世界”。全球正义的延伸：缺员国家卫生人力移出的伦理“从来源国招募、与关于国际招募的行为准则及其自愿的牙齿”的文献、“人才流失与循环迁移及汇款经济学”框架、以及“一种资助来源国培训的招募税、是公正的价格、还是一种拿走他人的许可证”立场、以及研究优先级的正义。**

## 临床医师自己的位置

::: definition 人手的正义与这个职业自己的分配 {#def-workforce}
**医学以自己的物品做不正义的、而且多半是安静的分配：培训管道的正义“专科短缺与沙漠中的全科医师”的市场失灵分析“劳动力市场看不见需要、它只看见愿意的人与有关系的人”这个问题、招生数与资助与编制的设定那套看不见的政治、以及面向农村与服务不足地区的“带奖学金与合约”的安排及“合约管用吗”的规划评估、“轮转与排班及人力自己的健康”的伦理“睡眠不足的医师既是器械又是患者”这个双重的职责、欧洲工时的指令尚未完成、以及美国住院医师六十至八十小时的文化及其“这个科室需要一个牺牲者”的负担分配、“在指导与署名与信用上谁欠谁”的学术分配正义、“临时与旅行医师及两层劳动力”的内部市场、以及“不稳定性会伤害患者吗”的人员连续性研究、报酬的平等与合同、以及“女性的大多数劳动力与男性的领导层及学术医学”分配、招募与晋升中的歧视及公民身份与语言要求的可及的正义国际毕业生管道、以及“先招募、再责怪他们流失”的系统、以及“专业人员自己的疾病与残障及重返工作”的正义——这个职业最后才把它用在自己身上、而失败在自己身上。“公平的保险与过失诉讼、以及由谁为错误付钱”的分配无过错补偿方案的北欧与新西兰及疫苗伤害及国家补偿体系的比较文献、以及“补偿是正义、而诉讼也是发现”这个双功能的论证、“对不正义的法律的服从”与拒绝的法医及专业共谋的伦理传统这一支中的正义这个学科自己的忠诚层级之问、以及临床医师每天都在行动中的代际正义那一支：债务与投资及气候及“下一批人继承什么”的框架、规划应当把它命名出来。本章的规则：一个用可辩护的流程分配陌生人的死亡率、却用方便来分配自己的负担与回报的职业、两者都还没有挣得它的权威——公平的审计先向内运行、而排班与招募及病假管理的政策、同那封拒绝信一样是伦理的文件。**
:::

::: example 那次资金的申诉 {#ex-appeal}
你那名患罕见神经疾病、需要一个每质量调整生命年9万而你的系统不予资助的药的患者；同一款药在边界另一侧是被资助的、而在那个试验的“对照转为开放”这一组也是。家人要你去“上那个评审会”；而委托方要你“现实一点”。
::: solution
**把个体化资金申请打好（[[#def-micro]]、[[#def-macro]]、[[clinical-skills/records-handover]]）：先给诚实的框架：那个评审会不是道德的法庭、而是一个“程序公平”的装置、所以提交材料靠它的相关性取胜：按证据分级的、对这位患者的收益、对试验的人群对她重要的结局、而不是公司提交材料倚赖的替代终点、“为什么她不是那次评估的平均值”的论证系统自己的规则中已包含的修正标准：严重度、罕见、模型遗漏的照护者与非正式的成本、以及工作与依赖的后果、比较负担的诚实把边境的差异与试验可及的不对称、说成评审会可以不尴尬地据此行动的公平论证、以及评审会没想到的务实的提议带条件准入与试验及联合采购的路径、以及带预先商定的停止规则与具名临床主管的限时试验——那个“什么会使这个决定可逆”的包裹、才是会被认真对待的东西。与家人的谈话：“申诉支持这段关系”的规则由你写提交材料、而他们看着你做、具名的时间表、以及不许诺、不带行话地解释“开放标签对受资助的可及性”的区分在签字之前先问“如果它停了、她会怎样”的那个计划、以及那句“无论评审会怎么决定、在此期间我们都会照顾她”的承诺——它让这场争斗不至于变成治疗本身。系统之诚实的收尾：把评审会的决定连同他们给出的理由记录下来、并把“下个月一个相似的患者会再次需要它”这一层级的问题升级到临床网络与委托组、而不要等下一波申诉——一场不产生任何政策的个体之战、只是请了好律师的不正义。**

::: example 两条名单 {#ex-twolists}
你的单位按国家的标准运行一条移植名单；两小时外的一家私人机构按同样的标准列入同样的患者、但多加了一道你不做的“复杂手术的适格性”审查。你两名等待已久的患者被提供转出、“为了一条更快的名单”。家属打电话请你出主意。
::: solution
**两条名单、一种正义（[[#def-micro]]、[[#def-macro]]）：第一职责是信息：按名单、按血型、按致敏度的实际等待时间的分布“更快的名单”这一说法的真假随免疫学而变——私人机构典型的队列效应：低致敏的患者在哪里都更快结束、以及“他们是不是正把我更难的患者筛给我”这个问题——总量结局与名单构成的数据要么提出、要么回答它、而在你发表意见之前应当向网络索取。临床的实质：“适格审查的差异”要么是国家标准的委托交由地方做的真正的风险分层那样这家私人中心对某些患者可能更安全、而你应该这么说、要么是一道与财富相邻的过滤器那样“完全相同的标准”这句营销就是不诚实的、而监管机构对名单完整性的职责就是那条路径。面向患者的建议：带数字的中立”对你这样一个人、每条名单的等待看起来是什么样、这两家单位公布的每手术量与结局的数字是什么、而转出你在交通与家庭支持与连续性上付出什么——以及这是我诚实的解读“、句”无论你选哪一个、在这里都不会被另眼看待“的保证要早说、因为它永远是那个没有被问出口的问题、以及转出的行政协助病历与共享协议及医师对医师的电话无论如何都是你的职责。系统正义那一支：这段经历进入网络的公平日志“第二部门的筛选是否在把容易的病例从公共名单上掏空”这一监测正是为这种模式而存在、因为对双轨问题的公正答案不是怨恨、而是数据、公布、以及对标准诚实的执行。**

::: example 一项临床试验的地理学 {#ex-trialgeo}

::: solution
**研究中的参与正义（[[#def-theories]]、[[medical-ethics-law/research-ethics]]、[[public-health/determinants-inequalities]]）：伦理的对象：试验站点的选择是一个有下游效应的分配决定这款药的证据基础、说明书与指南将在“没有承担疾病负担的那部分人群”的情况下被生成、而在评估之后的可及性谈判中会引用那份证据——试验公平的文献如今正式命名的那个“有提取、无纳入”的批评、而申办方那个“可行性”的类别通常是一个成本函数、不是一条法律。你真正能给的帮助：以“能力、而不是排除”作反提议一份“站点的准备度包裹”：由这家市立医院自己审计记录的招募优势、把基础设施的缺口逐项拆成“多少资金能补上什么”研究护士的全时当量、数据录入、以及审计时间——模型本来就在付给大学站点、以及经由主要研究者与国家研究所的路径送出那封“你们的可行性名单就是我们的公平风险”的信、“不”是对的条件一个无法安全运行方案的站点本就不该加入、而团队要说出具体是哪个缺口要紧、以及结构层面的升级资助方要求参与计划的资格规则、以及英国与澳大利亚及美国的研究所如今写入的公共卫生机构的研究公平条件。小的折中的正义也重要：如果试验在没有你们的情况下进行、患者仍应得到信息社区的联络、用平实语言写的结果摘要、以及应当迫使申办方声明的试验后可及性的立场、因为本章的规则是：被排除的人群至少应当得到从未请他们参与生成的结果。**

- 分配的理论分为聚合、优先、充足与平等几个家族；没有哪位临床医师或哪家机构一贯地持有一种、这就是为什么程序公平公开、相关、可修订、可执行是共享的伦理、也是审计的工具。
- 微观分配是一门设计的学科：排队的规则、分诊的矩阵、与资金的申请、各自嵌着一种理论、而它们的不正义多半在于“不可见”——公正的服务会公布规则、等待、名单与结局。
- 分诊已确立的纠正：在激增之下使收益最大化、绝不按残障状态做效用的折减、把分诊与治疗的团队分开、并通过“互惠的那几行、而不是英雄惯例”来保护人手的诉求。
- 成本效果的机构无论是否承认都是优先主义的混合体；它们的合法性取决于阈值、例外与折扣的透明、而临床医师的角色是在系统的通道中辩护、绝不是沉默地在床边配给。
- 这个职业自己的分配——培训名额、排班、报酬、信用、疾病、移出式的招募——都是正义的文件；一场止于患者的公平审计不是公平审计。
- 本章对你做出或遇到的任何分配的实用检验：这条规则能否经受它自己的新闻发布、它的理由是否与患者共享的目的相连、它能否被争论、以及是否必须有人回应？
:::

::: exercise 为那个优先群体论证 {level=2}

**四种诉求、一辆车（[[#def-theories]]、[[#def-micro]]、[[public-health/vaccination-programmes]]）：各项诉求：疗养院的居民——“在机构内处境最差且有暴露”死亡的证据压倒性；照护者——暴露、系统的功能、与互惠“谁来保护保护者”一行、及其“必要的人力直接缓冲脆弱者”的版本；严重精神疾病——贫困、共病、以及一个无法隔离的照护系统大流行使“超额死亡与聚集性环境”的数据变得可引用；那个手工劳动者的地区——传播动力学与家庭及工作场所的结构有效繁殖数与暴发的数据的论证、加上“这里的居民正是倒置的关怀律所赖以生存的未满足的需要”的健康公平论证。各自需要的证据：死亡的风险、对传播的贡献、系统的临界性、与可避免性——这四种货币与它们不同的数据来源“模型对公平对互惠”的诸优先级框架。被迫时的书面规则：一个由“即刻避免的死亡、传播、与系统功能”构成的复合、带一个明确的公平权重、且不做沉默的取舍例如：基于死亡与功能的综合理由、先给机构的居民与人员及一线的健康与照护者；然后按被测量的繁殖数给出最高暴露与最贫困的地区、再给出临床上极端的其他人；而精神疾病的队列通过其机构与家庭的暴露路径、在有实据之处处理、带着它自己经过推理的诉求、而不是一个“谁更值得”的层级。程序的职责：用平实语言公布的理由、在之前而不是之后的社区与残障倡导的协商、“没有任何职业、没有任何财产可以占一行”这个诚实的检验、以及当供应或证据改变时的复审触发——因为在一个为公共善而做的排序中、理由本身就是药。**

::: history
**分配之问和分诊这个词一样古老拿破仑与拉里埃时代战场的“分拣”、南丁格尔时代的病房分类、以及小儿麻痹铁肺委员会1940年代哥本哈根那种“上帝般的角色”——“谁得到肺”成为一个被命名的伦理对象、但它的现代机器是随“让生存变得昂贵”的技术一起到来的：透析长队的时代1960至70年代西雅图的人工器官可获得性委员会——一个由十二名市民组成的法庭、其“包括称职的医生对那个酒鬼在内的社会价值筛选”的纪要、成为此后每一个分配框架都引用的反面展品、移植的分配工程学的那十年各国的移植协调机构的准入之战：“社会价值对医学标准”的诸裁决、终末期肝病评分与效用与正义的名单设计之争、活体捐献的配对与链式移植的创新浪潮、器官短缺的经济学那个“该不该有市场”的论证、以及“存在过的市场是在交易的一方、而不是器官”这个结论、给活体捐献者带薪假的伦理作为近期的政策、以及伊朗与新加坡的对照实验。成本效果的机构时代：阿拉斯加医疗补助的优先级列表实验1992年那场“在一本蓝皮书上按名字记录配给”的冲击及其公开的听证、俄勒冈的豁免优先级列表、以及“膝盖对一条命哪个更糟”的投票之战、2000年的国家评估机构及其阈值的区间、及“它是一个配给的机构、还是照护质量的监察署”的立基之争、世界卫生组织的选择、以及博茨瓦纳与墨西哥及泰国及巴西的技术评估机构对全球南方的改编、以及那个使美国成为这个领域的对照组的比较：“国家层面从不给质量调整生命年定价、保险市场替他们做了”。公平的测量革命怀特霍尔与马克罗特时代的社会决定因素的研究发现、给“倒置的关怀”律与“设计出的不平等”——两份报告与“数十年的超额死亡”的英格兰的证据基础、健康公平的评估工具、以及美国系统中的差异监测、及第二次马克罗特复审那个“健康不平等的政治”的纲领、以及大流行那堂强制的现场课被演练并公布、或未被公布的分诊矩阵、“年轻对年长、以及公平的局数在公众面前复兴”、以及对分诊官的保护。**

::: example 队列里的那个算法 {#ex-algorithm}
你们地区新的预约分诊工具按一个来自理赔数据模型的“预测的12个月死亡率”来排优先级；六个月后、贫困城市的等待名单在变长、而它的富裕郊区的在缩短。供应商说模型没有偏倚；而那位数据分析师说：去查那个标签。
::: solution
**按标签审计（[[#def-micro]]、[[public-health/determinants-inequalities]]、[[clinical-skills/laboratory-tests]]）：分析师指出的那个技术真相：模型的公平只和它的目标一样好——“预测的死亡率、对预测的需要、对预测的支出”这一标签的选择是一个装扮成特征的公共政策医疗记录分配工具的审计发现：基于支出的标签编码了可及性的历史、于是“被贫困压低的利用率”变成“被贫困压低的优先级”；一个模型可以“在支出上无偏”、而在疾病上不正义。诊断：按十分位与族裔的差异效应表用结局、而不是理赔被测量的一份样本、把模型与临床的需要做基准——“标签偏倚的审计”的设计、重新分配的模拟在基于需要、基于支出、基于严重度的标签之下、优先级看起来是什么样、以及本不该缺失的那项按地理的等待名单死亡率的监测。回应：“暂停、而不是抛弃”的立场在重新标注与重新验证之前、该工具不用于活的分诊——分配软件的“先证明有益、再谈个体无害”的标准、这与药物许可的预防性不对称正好相反、而它应当比现在更让董事会担忧、与公平团队及患者代表一起重新规定、由他们把一个目标标签作为治理的决定来选择、重新校准并带监测与日落的复审、以及把这一切发表——医疗保健中算法透明框架的规则它做什么、用什么数据、谁的价值观、何时被复审正是为这一刻而存在。给董事会备忘的正义那一支：一个对“有偏的目标”技术上准确的分配工具、不是一个中立的仪器、而是一条“连辩论这点体面都不给”的倒退政策、而它的修正以需要为基础的标签、并在上线之前公布其分布的影响与它将要缩短的名单相比是便宜的。**

一名带着一名令人同情的患者站在门外的记者问：为什么你们的系统“不愿为一款有效的药付钱”。给出那个两分钟的回答：对配给诚实、对患者公平、又不是新闻稿。
::: solution
**大声说出的配给（[[#def-macro]]、[[clinical-skills/communication]]）：结构：先承认这个事实（”诚实的回答是：每一个卫生系统都会决定它不为哪些东西付钱——我们只是一部分把它做进等待名单、一部分做进委员会；选择只在于公开的配给与藏起来的配给之间“），然后用平实的语言讲机制”这款药的证据与它的价格，必须与这笔钱本可做的每一件事相比——髋关节置换、抗癌药、化疗支持、社区护理——而委员会认为在这个价格上的性价比还没有达到，然后是那名患者的现实“我们今天为她做什么、以及申诉与试验的路径”的具体——才是记者真正需要印出去的答案，然后是可问责那句（“如果你想听委员会真实的理由与他们拿到的价格，它们是公布的、这里是地址”），然后是那句“这是价值、不是专业”的诚实“当我们买不起所有的东西时、一年生命值多少、这确实是艰难的取舍；我宁愿与你在公众面前争论、也不假装这里没有选择”。禁忌：不归咎“官僚”、不在明明是“带临床投入的经济决定”时暗示它是临床的那种欺骗会让信任付两次钱、以及在“我们不会以这个价格付钱”就是那句话时、不用“目前未被推荐”这种委婉。后续的务：写一封给患者自己团队的信并支持那次申诉、因为一个好的媒体回答若以“患者觉得被针对”告终、就是一个坏的回答。**

::: exercise 纠正那个邮编彩票 {level=2}
描绘你们地区在三项服务上的变异例如：减重手术、宫腔内人工授精的生育治疗、以及脊髓损伤的康复。解释每项变异的机制明确的政策、能力、委托购买的、以倡导的不对称、并设计那个用“最少的新官僚”实现均等化的工具。
::: solution
**变异的法医学（[[#def-micro]]、[[#def-macro]]）：机制的诊断：减重手术通常是明确的委托标准之变异——指南与本地适格性的漂移、以及“是政策、不是科学”的减重排除清单、人工授精经典的“政策的彩票”、带着它的法律挑战的历史——被规定的最少周期数、无视它的委托方、以及“是指南、不是政策”这一法律修补、以及脊髓损伤的康复能力与委托设计的问题——小人群的超专科、一个原已不平等的网络、以及“为单位定价、而不是为需要定价”的合同扭曲。工具的设计（最少官僚的版本）：带“公布或解释”职责的国家最低标准“每个地区把它的标准、等待与结局公布在一页纸上”这个机制——公开即执行、这是被评估过的最便宜的工具、一个单一跨边界的可及资金对低于既定阈值的服务采用“居住地的委托方付款、无需申诉之战”的规则——把地方的配给变成国家的资助、而不新增机构、任何适格性的限制都必须做公平影响的评估“在你关上适格性那扇门之前，先给我看那张贫困的表”这道闸门、以及向委托方大会提交年度变异报告并指定一个有名字的改进责任人——套“在系统尺度上对合理性的问责包裹”。本章布道的那种临床辩护的手艺：各专科学会自己的变异地图生育与外科与康复学院的审计证明：临床医师记录不平等比各部门做得更好、以及那条“像在不敢申诉的那个地区等看你自己的母亲那样写下标准”的检验、每一个委托的岗位都应当被要求大声说出它。**

::: exercise 为拒绝辩护 {level=3}
一家制药公司为你的医院提供一个同情使用与早期准入的项目、针对一款能保住在你们每周都治的疾病中的肢体的器械；数据只有一个单臂的病例系列、而它的价格日后会锚定国家的评估、你们的伦理委员会以“因为患者会获益”放行了它。写出你的异议备忘录：正义的分析、关于“同情”这一框架的同意真相、以及那份既保护患者又不预先为价格背书的反提议。
::: solution
**同情、正义、与价格的形成（[[#def-macro]]、[[medical-ethics-law/research-ethics]]、[[epidemiology-ebm/diagnostic-tests]]）：正义的分析：这个项目的两种分配——谁瞥见了这款器械宣传充分的医院、被转诊的、识字的患者——一个新的“邮编彩票”的轴与谁日后付钱国家的评估被锚定在“在患者的影子里谈定的早期准入价格”上、参照价格与国际的锚定、以及“同情的组成为上市的市场”商业的机制——透明的文献对此有记录；单臂病例系列这个真相（“我们无法知道谁本来也会保住那条肢体”这个问题——自然史与同期对照的缺席使那个“获益”有一部分无法测量、这就是为什么这个项目是“穿着分配外衣的研究”）。同意的纠正：“同情使用”这一框架的“如实标贴”的职责要告诉患者：用于此目的尚未证明、不付费、若有害或无获益的退出计划、以及“你的参与会塑造这个国家日后买什么”——这三句正是同情的框架通常藏起来的话。反提议：以“把慷慨转化为证据与价格纪律”为条件接受带保密价格与结局承诺的带条件准入协议、国家登记册的纳入——每一个患者、每一个站点、不只是你们的、以及预先注册的停止规则与公开的报告、并邀请评估机构作为伙伴而不是事后被惊到——以“基金与共享指导”的机制为模板与分配的规则适格的标准在全国公布、站点轮换准入、好让这场彩票至少公平地摇号。备忘录的结尾那一段是整章的缩影：“问题不是患者是否应有一个机会——他们应该——而是我们是否允许一家公司把他们的绝望用两次：一次用来生成那本该在器械之前的证据、一次用来设定全国将要为它支付的价格。我们可以对患者说是、对这个结构说不、而这就是做法。”**
