生命始端的伦理是医学的能力跑得最快、把共识甩在身后的那片领域：从体外受精的最初几十年那时“试管婴儿”的反应定下了这场争论的措辞、到基因组编辑的可遗传谱系的红线在技术到来的数年之内被画出又被争论。**本章涵盖道德地位之争及其结构（潜在的人、物种的成员身份、感受能力、关系性的理论）、把它应用于避孕与堕胎与辅助生殖、植入前的检测与产前检测、治理的模式与可遗传编辑的边疆、以及日常真实的临床困境：救一个已有的孩子的配型、一个筛查的结果、以及一个良心拒绝的转诊。**

## 这场论证

::: definition 道德地位及其诸理论 {#def-status}
**先说“坏客观性”的问题：道德地位之争的结构解释了它的持久——相互竞争的理论各自内部自洽、而回答的是不同的问题。潜在性的理论合子主动的发展轨迹构成它的诉求继承了连续性的困难正是同一条轨迹、使双胎分裂与重组的情形中囊胚的毁灭成为一种该理论无法指出的道德荒谬；物种成员身份的理论自受孕起即为人有机体在描述上干净、在哲学上孤立来自功利传统的“有物种身份而无感受能力就是物种歧视”的指控、以及它的辩护者不得不消化的“配子也是人”这个归谬；感受能力的理论体验的能力、随丘脑的结构在第二孕期一个可辩护而模糊的阈值到来在受孕处做得最少、在出生处做得最多、而它是唯一一个带有可争论的神经发育时刻表的理论“出生作为感受能力的连续事件”的文献与感觉皮层起病的数据；以及关系与社会的理论地位由关系与筹划构成——那种“被想要的、不被想要的、与现实的”、多数实际的道德生活靠它运转准确地描述了现象学、却有把人之为“人格”变成一个程度问题的风险、而法律无法容忍程度。务实的体制理论多数法律体系实际施行渐进主义的“随发育推进而增加保护”的模型、把早期的决定安放在怀孕者法律人格之中的“女性作为第一个环境”的框架、以及堕胎法的判例不断重造的“阈值加胎儿存活力的监督”的架构是“不解决而立法”的尝试——取决于你对这场论证的看法、这要么是政治智慧、要么是回避。本课程为临床医师辩护的那个综合：形而上学的问题在你的职业生涯内不会被解决、而实践的问题在没有它的情况下已被解决避孕、植入前检测、对界定的胚胎窗口的研究、在不同法律下的堕胎提供——被把它括起来的程序所解决、这意味着职业的职责是诚实地争论程序由谁决定、什么信息、谁承担代价、而不是重新打那场形而上学的仗。**
:::

## 应用

::: definition 从避孕到选择：实践中的争论 {#def-applications}
**避孕的伦理多半是“可及性”的伦理、外加两场残余的仗：机制与良心那一层关于受精后作用的“它是避孕还是抗植入”之争——一场双方大体同意生物学、而在道德地位上分歧的争论、这就是为什么它不去解决、而是转移到药房的良心规则与处方集的政治、以及长效方法的同意问题长效可逆避孕的强制史——原住民与残障人士的绝育滥用、其赔偿诉讼正在开始、“把避孕作为出院条件或社区照护条件”这种伦理上不可接受的邻近做法、保护审查不断发现、以及同意那章所辖的“能力与避孕”的界面。辅助生殖的问题跟随技术的次序：配子的捐赠与代孕的伦理终结匿名制改革的证据——由供精者所生后代自己的登记与倡导、正在改变欧洲多国的法律、“知道你来处的权利”对合同式亲子关系的论证、以及商业代孕的剥削之争、其立场按法域而硬化、按“对实际安排的证据”而软化；附加项目这一行业对“无证据的生殖诊所附加服务”的审计、与监管机构对患者伤害的职责——这里的伦理近乎是标准消费者保护、穿上了生殖的外衣；以及植入前的遗传检测、这一“选择”章的核心诊所实际在航行的“疾病的严重度光谱”——从泰-萨克斯病到严重度光谱那端的耳聋与失明、晚发的疾病、以及“BRCA1究竟算反对还是算赞成”的问题；关于性别选择与“家庭平衡”的理由与伤害之争；人类白细胞抗原配型与“救命同胞”文献那个“作为有权利的后备的孩子”的细微；以及残障权利的批评——植入前检测表达的是“残障的人生不值得过”这个判断——其诚实的答案是：这一批评前后一致地适用于父母的理由、而对“面对真正疾病的那个家庭的替代方案的残酷”什么也不改变、这是遗传咨询的哲学文献比任一阵营的修辞都建模得更好的一场分歧。高序多胎的选择性减胎在高序妊娠的减胎中通过结束一些来挽救一些、以及它承载的流产史的咨询负担、与无创产前检测（无创检测与21三体的终结之间的联系、及其残障社群的政治性批评）都挤在同一个“筛查改变了谁被出生”的标题下、而“残疾是否是一种伤害”的问题在每个诊室里都被重新问一遍。**
:::

## 治理与边疆

::: definition 监管的模式与可遗传的编辑 {#def-governance}
**“胚胎与人类受精学法案”的许可模式英国的监管机构架构——法定的许可、作为一道象征性边界的“14天体外培养”规则比较文献肯定其合规的容易与立范的力量、逐中心逐操作的批准、以及登记册，在1990至2000年代与“专业指导”模式美国的普通法与学会伦理委员会的路径以及“禁止型”德国与意大利的胚胎保护成文法、比较研究测量了它们对研究以及对患者出行的影响相竞争；此后的趋同是混合的法定的地板、专业的细节、对“接近可遗传”的技术的许可、因为每一种纯粹的模式都在某处失败了。线粒体置换这一案例研究：“三人婴儿”这一定名的命名之战这项技术实际的遗传学——线粒体DNA那37个基因、不涉及外貌或人格、对公众的定框、安全性与伦理委员会审查的两道门设计先许可这项技术、再批准这位患者并追踪孩子——“一个新谱系的第一个人”的药物警戒类比、以及它对“特洛伊木马”论证的处理编辑与置换的区分、被可遗传编辑的反对者斥为修辞；2023年那个出生的安静、对比2016年那次投票的戏剧、是一种“以疲惫为风格的治理”。可遗传的基因组编辑：2018年的那次破裂“CRISPR婴儿”丑闻的法医学——伪造的伦理审查、不充分的安全性论证、以及“选择HIV不一致的伴侣”这一“不必要的风险”的结论、回应的架构世界卫生组织专家委员会的建议与治理框架、国家科学院2020年那份“可遗传编辑的试验条件、而当前从未被满足”的表述、以及国际观察站与暂停的提议、其范围从“呼吁”到“强制”、以及漏洞的重力“诊所在无监管的法域、以及为编辑而医疗旅行”这一这个领域自己推演的场景、“体细胞与可遗传边界的侵蚀”这个论证睾丸干细胞工作这类“接近生殖系的体细胞技术”提出的、以及当治疗的清单变长时“增强对治疗”这条线被重新越过。逼近的那一组保持着同样的形状、却带着新的物理学体外配子的伦理：无限的胚胎生产、以及胚胎模型的伦理地位。**
:::

::: example 那个“救命同胞”的问题 {#ex-saviour}
一对有一个依赖输血的β地中海贫血女儿的父母、询问能否做体外受精并选择人类白细胞抗原匹配的胚胎、“为了帮助我们的孩子、而不是为了取用她”；他们被告知附近没有诊所愿意做。
::: solution
**为他者而选择、为两者而同意（[[#def-applications]]、[[genetics/common-disease-genetics]]、[[blood/haemoglobin-disorders]]）：实践中的伦理：做人类白细胞抗原配型、而不做“针对遗传病的植入选择”这个孩子无论如何都是健康的——“救命同胞”文献那个已确立的中间立场：在多数框架下带保障是允许的、在少数法域被禁止，其关键正在于保障、所以要沿着它们为这个家庭做咨询：捐赠的限度以受者在其有能力时对“骨髓采集”这一操作的知情同意为准——那个“先用脐血、最后才用骨髓”的设计要向捐赠者的孩子说明、这个同胞自己未来的同意与福祉“捐赠而不对捐赠者造成伤害”的规则、以及带心理随访队列给出的“令人安心但有保留”的数据、对父母理由在压力下的审查许可机构要求的、关于“已有一个患病的孩子与婚姻及家庭期待的动力学”的咨询、以及家庭在第一个周期之前需要的“如果没有匹配怎么办、如果匹配了却不再需要怎么办”的计划。本案暴露的可及性的不平等“附近的诊所说不”、于是前往允许的法域这一模式是生命始端的治理从未解决的监管套利问题——把咨询指向“其伦理与许可文书你真的能读懂”的诊所、这与生殖旅行警示标签的方向相反。记录：咨询自身的记录双方父母都有可用的独立建议、未出世孩子的福祉作为一个人而不是作为一种资源被权衡并写进病历、以及登记册承载长期随访的承诺、因为救命同胞文献那个持久的发现是：当这个过程把“这个孩子的独立性”明确做成计划的一部分、而不是压力下给出一句安心的话时、家庭会过得很好。**
:::

::: example 那个无创产前检测的结果 {#ex-nipt}
一名低风险妊娠患者的游离DNA筛查报告“21三体高风险、四分之一”；她孕12周、独自一人、并要求你“安排减掉一个”。确证的路径是孕15周的羊膜穿刺。
::: solution
**筛查在临床上与伦理上都不是诊断（[[#def-applications]]、[[public-health/screening]]、[[obstetrics-gynaecology/pregnancy-antenatal]]）：先算数：即使是低风险人群中筛查试验给出的“四分之一”这个检测后的数字、也带着可观的假阳性份额诊断那章的阳性预测值对患病率的教训——无创检测的敏感度很高、特异度几乎同样高、但在低患病率下假阳性与真阳性的比例仍然要紧；她需要的数字不是“高风险”、而是“拿这个结果来看，你的孩子真正患21三体的机会大约是百分之X——而下一次检查会告诉我们什么”、而确证的那一步绒毛取样或羊膜穿刺、带其自身被量化的操作风险不是延迟、而是她尚未得到的那个诊断。咨询的手艺：当日或次日的结构化会谈“非指导性地给出数字”的标准、关于伴侣与时间的提问这个请求的速度是关于她先前决定的信息——“我是不是早就在做决定了”场谈话：关于因非整倍体终止的自主文献坚持说它是正当的、而残障权利的批评坚持说它是有条件的——她应当把这场分歧当作信息来接洽、而不是当作一堂课、由该病儿童的家属创办并为其服务的组织制作的“我们的数字意味着什么”的材料筛查规划的指南如今以双向的具名来源写入的那种平衡信息的义务、以及路径中立的原则：确证的诊断平等地打开所有的门带着支持继续妊娠、计划收养、在法律与服务可及范围内的终止、而临床医师的工作是这张地图、不是目的地。系统的诚实：羊膜穿刺的两周等待是一个伦理变量较晚终止的风险与决策疲惫的数据、所以这条路径的设计——快速通道的咨询、最近的可确证的时段、以及“结果出来后我们再一起见一次”的预约——正是本章真正能开出的处方。**
:::

::: example 场出于良心的转诊 {#ex-conscience}
一名小镇的全科医师出于良心拒绝为终止妊娠开具转诊；最近的替代临床医师在80英里之外、而当地的媒体得知了“拒绝的医生们”。一名19岁的患者需要本周内转诊。
::: solution
**在可及性之内的良心（[[#def-applications]]、[[medical-ethics-law/professionalism-regulation]]、[[clinical-skills/communication]]）：已确立的框架：执业者可以出于良心拒绝亲自参与一项合法的服务、但“有效可及”的职责在于服务机构与专业组织——转诊必须发生、而不仅仅是“可能发生”：那个“提出异议并即刻移交”的模型一位具名的、会采取行动的替代者、在患者离开之前就被联系上、并且记录显示的是移交而不是拒绝、准则所执行的那条“不说教、不道德化、不拖延”的行为规则患者的紧急情况才是那个时钟、而媒体的故事不是她的、以及在说出第一次拒绝之前就要知道本地的可及性地图出于良心的执业者自己的义务：一个没有可行替代的拒绝、是由提出异议者亲自造成一次服务的失败。这个小镇层面的问题才是真问题：单医师的诊所让良心成为一道公共的屏障生殖健康服务通过“孕早期远程优先”的路径、临时医师的轮值覆盖、以及药房与远程医疗的通道来解决“农村的良心拒绝者安排”、以及专业组织安静的执行把转诊的职责作为执业的一项条件、而不是一条建议。这一周给这位年轻女性的照护：同一小时安排好的他处预约“可及性的实际障碍”的文献说、决定了“一项法定的权利是否是真实的权利”：交通与费用及陪同的支持、这次接诊仍然有尊严地提供的性传播感染筛查与避孕及连续性照护、以及那位“拒绝了却做出了安排”的全科医师那句“在这里和在那里、都不会有人评判你”——因为异议针对的是那个行为、而对患者的职责是完整的、而这两者之间的差别正是职业良心之为职业良心的意义。**
:::

## 通向何处

能力的争论与堕胎的判例在[[medical-ethics-law/ethical-principles]]与[[medical-ethics-law/justice-resources]]；同意的要素在[[medical-ethics-law/consent-capacity]]；筛查的方案在[[public-health/screening]]；产前与生殖的内容在[[obstetrics-gynaecology/pregnancy-antenatal]]与[[obstetrics-gynaecology/contraception-fertility]]；遗传的咨询在[[genetics/genetic-testing]]；生命的末端与它在同一批人身上相遇之处在[[medical-ethics-law/end-of-life-ethics]]。

::: summary
- 道德地位之争之所以持久、是因为诸理论回答的是不同的问题；实践伦理与法律通过把它括起来而前行——渐进的保护、决定的程序、以及向怀孕者的委托——这既不是怯懦也不是回避、而是多元社会唯一维持得住的共识。
- 生殖技术的争论通常是同样三个变量的化装：由谁决定父母、临床医师、国家、未出世的孩子、依据什么信息筛查对诊断、平衡的或不平衡的、以及由谁承担代价养育的、残障服务的、以及技术本身的。
- 选择性的技术植入前检测、无创产前检测把私人的生殖决定变成公共的问题——关于残障、性别比例、以及“知情”的含义——而可辩护的临床姿态是“数字加所有选项加路径的中立”、不是“感受的中立”。
- 治理的许可模式法定的地板、逐操作的监督、像14天规则那样的象征性边界、登记册表现优于纯粹的行业自治与禁止、而它在新胚胎模型与体外配子技术之下的修订是这个领域下一场的争论。
- 可遗传基因组编辑在那次破裂之后的共识条件未满足、国际观察站的治理、在治疗与增强之间写于文本并在诊所中被检验的那条线是一场活的实验：一项技术能否在它的理由成熟之前被治理。
- 临床医师在这里的能力是咨询的能力、外加对分歧的诚实：处在边疆的患者需要数字、选项、服务、以及陪伴他们走过一场他们的社会尚未结束的争论。
:::

::: exercise 为监管机构出主意 {level=2}
一家生物技术公司申请许可、以创建用于植入研究的28天培养的胚胎模型未校正基因组印记、由干细胞来源、不涉及配子。为许可机构出主意：地位的问题、规则修订的问题、以及能在公共争论中存活的监督设计。

**模型对胚胎的治理（[[#def-status]]、[[#def-governance]]）：以行政方式处理的地位问题：按法律的定义性条款、这个模型不是胚胎受孕中没有父源与母源的基因组、在成文法的措辞中没有有机体的连续性——许可法案的定义是为体外受精实体写的、而这正是14天规则修订之争真正害怕的那个定义的空隙、所以诚实的答案既不是“它是胚胎”、也不是“它只是细胞”、而是“它是一个新的实体、其道德诉求并不确定、而它的研究用途可以在一个受目约束的许可下、并在形式上尊重那道象征性边界的情况下进行”。规则的修订问题：14天培养上限的功能是一道清晰界线式的折中、而它的科学时代的假设没有原始条纹形成就无法继续培养已经反转；该机构必须权衡的选项——带着新的条件延长时间、保持时间并接受模型的悬置、或用一条“发育阶段”的规则取代时间的规则没有条纹、没有神经板、没有功能性的组织、由界定的检测来监测——以及阶段规则的优点它追踪的是道德直觉的内容：个体化与感受能力的前驱、而不是一本日历对它的执行成本这个领域将会打官司的“检测如何定义”的争论。监督的设计：目的清单式的许可植入与胎盘形成的疾病、早期妊娠丢失——正是该模型独特地涉及的疾病、因为公众接受的正当化是那个疾病、不是那份知识、在阶段上限销毁并带审计的条件、以及绝对写明的“禁止子宫内转移与禁止试图制造一个人”、带残障与信仰及患者机构的利益相关者协商、并真的把结果公开摘要那条数据治理的教训：协商的可见性比它的次数更重要、以及让许可随科学超前时回到同一个委员会的定期修订与日落条款。委员会应当从你这里接受的那句建议：为研究发放许可、把边界从日历移到有机体的发育、明白地说出你们正在移动它、并保留那条人们真正在乎的禁令。**

::: history
**这个领域的时间顺序是“先有能力、后有争论”。避孕的那十年口服避孕药1960至61年的许可、以及从“生育控制”到“避孕政治”的法庭时代，随后是生殖技术的冲击：1978年第一个试管婴儿的出生斯台普顿与爱德华兹的项目、其伦理委员会在十五分钟内批准、小报那个“试管婴儿”的定框为一代人定下了公共的语域、以及“要不要销毁剩余的胚胎”这个问题在第一支冻存管之前到达、那时谁都还没有词汇；沃诺克报告1984年与《人类受精与胚胎学法》1990年在一次立法的呼吸之间发明了许可与胚胎学的模式14天规则在委员会数小时之内的起草、捐赠者登记册终结匿名制在数十年后的2005年的修订；美国的对立模式没有成文法、由专业伦理委员会与学会的实践委员会治理、以及“定义性的案例经由侵权法、而不是经由生命伦理学到来”——怀特黑德的“宝贝M”代孕案把合同法教给了这个摇篮。产前这条线：羊膜穿刺与甲胎蛋白时代筛查的诞生1970年代早早写下的“筛查神经管缺陷要在检测之前取得同意”的教训、羊膜穿刺对绒毛取样的风险之争、超声成像伦理的安静到来“胎儿作为第二位患者”这一框架的批评者与辩护者、以及无创产前检测的冲击从验证到市场的五年、“21三体的终止率与残障权利的抗议”使一项血液检查成为一个政治的行动者、以及性别选择禁令的立法后果之争。堕胎论证的现代形状来自判例“以存活力为架构”的那套判决及其2022年被拆除、证明了这个安排始终是法律立场的；“存活力随技术移动”这一观察被22周的重症结局数据证实、以及全球自由化浪潮的对流——相反方向的十年记录了“法律会双向旅行”的比较文献。胚胎研究治理的仗：2000年代的治疗性克隆与干细胞研究的资助之战、诱导多能突变的绕道它一夜之间溶解了一个维持边界的论证、这是这个领域关于“技术如何给形而上学降级”的一课、胚胎模型当前对14天规则的压力、以及线粒体置换技术从投票到出生的这条弧作为许可模式最完整的一次演出。CRISPR的两个时刻：体细胞编辑的狂热与2018年的破裂场丑闻与其“奔向治理”的判决、2020与2021年的科学院与世界卫生组织框架的回答。**

::: example 那个22周的提问 {#ex-22week}

## 练习

::: exercise 给这场争论断代 {level=2}
把立场与它们那个时代的技术配对：“捐赠者必须保持匿名”、“14天规则必须变成21天规则”、“间性婴儿不应接受整形手术”、“为研究而创造的胚胎是一个人”、“无创产前检测应当纳入公共医疗”。解释每个论证在其陈述的对象之下真正在争论什么。
::: solution
**技术解码论证（[[#def-applications]]、[[#def-governance]]）：强制匿名人工授精的繁荣时代、1960至80年代：这个论证实际上是诊所的供给经济学与父母的法律亲子焦虑、当“身份之问”变成一个公民权利的问题时、由供者所生者自己的证词与登记册的模式解决。14天变21天胚胎模型的时代、那次科学的请愿：实际上是这条规则的“日历形式”与其“道德内容”之间的冲突——关于象征性边界住在哪里的“阶段对时钟”之争。间性婴儿的手术患者倡导的时代：旧的“父母需要一个性别来登记”的行政便利、对孩子身体完整性的诉求、以及本章那条缓慢的教训：同意的时机就是全部的伦理。“研究用的胚胎是人”剩余的胚胎与干细胞之争的时代：一个关于道德地位的立场、而运动的能量来自把“保护潜在的生命”从堕胎之争移植过来的框架——这两个论证很少被诚实地分开。筛查纳入公共系统基因组医学时代的配给之争：陈述的论证是关于试验的性能与成本效果、真正的论证是关于“国家在促成谁的生殖决定、以及系统希望就哪些出生被告知”。这一练习的要点：生命始端的争论几乎从不是它们所说的东西；分析者的任务是命名那项让这个问题“重新可被提出”的技术、以及那个答案所服务的利益。**

::: exercise 为那位肿瘤患者做咨询 {level=2}

**作为肿瘤急症的生育力保存（[[#def-applications]]、[[obstetrics-gynaecology/contraception-fertility]]、[[clinical-skills/communication]]）：医学：随机起始的促排方案把两周的路径变成几天的那套药物方案、以及肿瘤生殖的试验所敲定的“不延迟治疗”的结论、卵子对胚胎对卵巢组织的选择对青春期前与无法延迟者的组织冻存路径、以及费用的架构团队应当牢记于心的、“因医学指征而作公共生育力保存”的资格标准、慈善与试验资金的后备、以及当那就是事实时“你能负担什么决定你能保存什么”的诚实。伦理的次序：当天的生育力保存谈话“癌症影响的生育”的沟通文献关于信息时机的发现——她会记住很少、所以要书面数字加具名的联系人加预定第二次谈话、日后无法即兴补做的伴侣与同意的问题“死后的使用与关系的变化”的同意书要在平静时填完、保存的期限与复审的规则、以及不抛弃的条款“如果我们因时机而未做保存、这就是我们失去的东西、以及是谁决定的”份记录、它保护她未来对团队的信任。本身就是伦理的后勤：肿瘤与生殖服务之间已经商定的快速转诊“72小时内到诊室”路径的结局数据、围绕她实际的治疗日期安排的药物获取与周期的监测、以及一位具名的协调者、因为夹在两个服务之间的患者损失的时间比任何一个团队察觉的都多。临床的底线：“你的癌症治疗必须在它必须的时候开始；而生育的谈话今天无论如何都要发生、因为这是你的照护中那个日后无法逆转的决定。”**

**三部法律、一份证据基础（[[#def-applications]]、[[public-health/determinants-inequalities]]）：证据的输入：性别比例扭曲的数据“性别选择性终止可获得的时代”“儿子偏好与出生次序”的分析、其最扎实的工作显示这一做法跟随的是可及性、而不是文化的改变、出行与不安全替代的有效性文献禁令的效果：一些人出行减少、另一些人更加决心、以及永不被统计的地下结局、以及自主与平等之争的相撞生殖自由的位置、对“性别选择是在身体层面的性别歧视、而父权压力之下的同意正是问题、不是答案”的女性主义批评——两个阵营之间一场真正的分歧：个人的选择是否会聚合为伤害。评级：全面的禁令在有效性与妇女安全的检验上失败继续妊娠或秘密堕胎的影响落在最没有能力出行的女性身上、在家庭规划这一端过度伸展自主、而在象征上谴责一种做法；孕周阈值的版本内部不自洽性别很早就已知；这个阈值针对的是错的变量；有条件的许可模型家庭已完成的背景、咨询的要求、受监管的诊所路径贴合真正的伤害之问的形状个体的家庭对人群的比例这个问题、但在行政上脆弱、在哲学上令人不安国家在为生育的理由排序——而其他任何生殖法律都不这么做。给立法者诚实的综合：比例的伤害是真实的、但它是人群层面的、并由“女儿的安全”政策更好地处理关于儿子偏好之驱动的继承与安全及养老的数据、个人的决定落在被承认的生育自由之内、而四项标准复审后仍能存活的法律、是“咨询加禁止诊所广告加监测比例”这一揽子的方案、而不是对该适应证的禁止。本章的那句话：这是唯一一种总量与个体的伤害真正分道扬镳的选择问题、这就是为什么每一个简单的答案都会错两次。**

::: exercise 设计死后取配子的政策 {level=2}
一位丧偶伴侣在她的丈夫突然去世后请求取精并使用；他没有留下任何书面的东西。起草诊所委员会的程序：同意的问题、孩子的利益、家庭的反对、以及决定的可复审性。
::: solution
**死后生殖的程序（[[#def-applications]]、[[medical-ethics-law/consent-capacity]]）：同意的问题在法律上最难、在伦理上最容易：取出是一具尸体上的身体干预权威的路径：伴侣的当场同意、对监管或法庭的授权、因法域而异——取出通常照常进行；争执总是关于使用、而使用取决于死者记录在案或可令人信服推断的意愿“没有同意就没有使用”的架构、以及各法域法院的推翻、其模式在于当这对伴侣的生育治疗历程证明了意图时偏向伴侣。孩子利益这一支“被故意造成无父的孩子”这一反对、用实际的福利文献来回答——家庭的进程重于家庭的结构、但在它关系到申请人必须面对的登记与继承及安排的支撑时要诚实地权衡。家庭的反对那些不希望有一个法定继承人祖父母的问题——遗产与亲子关系的后果使委员会的法律建议这一支成为必须、以及申请人自己独立于诊所的法律咨询。让决定可复审的程序：在生物学的窗口之内紧急召集委员会取出的小时数限制、诚实地命名这个时钟、写下来的证据标准任何书面或录音、对生育计划的证词、及其分级的分量、申请人的独立倡导者、决定的匿名公布、以及一条向法院的上诉路径、因为一家诊所是一个孩子法律起点的错误终局裁判者。政策的起草原则：这对伴侣的生育筹划失去了一个伴侣；委员会的工作不是准予或拒绝悲伤、而是决定在此处的生殖究竟是“一个共同决定的延续”、还是“另一个人的开始”——并以书面的形式说出它认定是哪一种、以及为什么。**
