阿米拉36岁，怀孕13周。她的孕早期筛查结果显示胎儿患唐氏综合征的可能性较高，医院为她提供进一步的血液检测，之后可能还有侵入性诊断检测。她和丈夫还没有想过拿到结果后会怎么做。她的助产士必须在不引导他们的前提下解释各种选择，同时清楚：有些人把筛查视为预防痛苦的手段，另一些人则视之为一种表态，即像他们表亲那样的生命不那么值得活。

生命始端的伦理涉及深刻而持久的分歧。同样认同四原则的人，仍可能在胚胎或胎儿的道德地位上意见不一，因而在人工流产、胚胎研究和产前检测上意见不一。临床医师需要理解主要的论证，了解法律，并能够照护观点与自己不同的患者。本章涵盖道德地位、英格兰和威尔士关于人工流产的法律、产前筛查、辅助生殖与《人类受精与胚胎学法》、代孕，以及关于新生儿的决定。

## 道德地位 {#moral-status}

生殖伦理中许多最困难的问题，都取决于一个在先的问题：我们对胚胎或胎儿负有什么义务？如果一个存在者的利益因其自身而具有道德上的重要性，从而它可能受到不公正对待，那么它就具有**道德地位**。

::: definition 关于胚胎和胎儿道德地位的观点 {#def-moral-status}
- **受孕观：** 人类胚胎从受精起就具有完整的道德地位，因为它是一个有生命的人类有机体，具有发育为成人的潜能。按照这一观点，终止妊娠在道德上相当于杀死一个已出生的人。
- **人格观：** 完整的道德地位取决于意识、自我意识以及珍视自身未来的能力等能力。胚胎和胎儿缺乏这些能力，因此不具有完整的道德地位，尽管它们可能具有某种价值。
- **渐进观：** 道德地位随着胚胎和胎儿的发育而增加，具有道德意义的阶段包括原条出现（约第14天，此后不再可能形成双胎）、具备感受能力，以及具备存活能力。
- **关系观：** 道德地位部分取决于关系，例如被孕妇和其他人所期待和珍视。
:::

每种观点都有众所周知的难题。受孕观必须解释：为什么自然受孕中早期胚胎的高丢失率，没有被视为与儿童死亡同等规模的悲剧；为什么常规地产生不会被移植的胚胎的体外受精（IVF）会被广泛接受。人格观似乎意味着同样缺乏自我意识的新生儿，其地位并不高于晚期胎儿，而大多数人拒绝这一结论。渐进观被广泛持有，也符合许多法律的结构，但它必须解释为什么界线恰好划在那些位置。

另一个论证由朱迪斯·贾维斯·汤姆森（Judith Jarvis Thomson）在1971年提出并广为人知，它追问：胎儿是否是人，这一点是否真的要紧？她认为，即使胎儿是人，也没有人有义务让另一个人利用自己的身体来存活。按照这一观点，核心问题是**身体自主**，而不仅是道德地位。

英格兰和威尔士的法律为其自身目的采取了明确的立场。胎儿不是法律上的人。它在活着出生时才取得法律人格。父亲不能阻止人工流产（*Paton v British Pregnancy Advisory Service*，帕顿案，1979）。法院不能把胎儿置于法院监护之下来控制孕妇的行为（*Re F (in utero)*，1988）。有决策能力的女性可以拒绝剖宫产，即使她的胎儿会因此死亡（*St George's Healthcare NHS Trust v S*，1998）。欧洲人权法院把生命权何时开始的问题留给各国自行决定（*Vo v France*，2004）。

## 大不列颠的人工流产法律 {#abortion-law}

在英格兰和威尔士，依据《1861年侵害人身罪法》（Offences Against the Person Act 1861）第58–59条，以及（胎儿具备存活能力之后）《1929年婴儿生命（保护）法》（Infant Life (Preservation) Act 1929），人工流产仍然是一项刑事罪行。适用于英格兰、威尔士和苏格兰的**《1967年堕胎法》（Abortion Act 1967）**规定，在其条款范围内实施的人工流产可作为抗辩事由。

::: definition 《1967年堕胎法》（经修订）规定的终止妊娠理由 {#def-abortion-grounds}
当**两名注册医师**基于善意形成以下意见时，注册医师可以合法地终止妊娠：

- **(a)** 妊娠未超过**第24周**，且继续妊娠对孕妇或其家庭中任何现有子女的身体或精神健康造成损害的风险，大于终止妊娠的风险；或
- **(b)** 终止妊娠是防止孕妇身体或精神健康遭受严重永久性损害所必需的；或
- **(c)** 继续妊娠对孕妇生命的风险大于终止妊娠的风险；或
- **(d)** 存在重大风险，即孩子如果出生，将患有身体或精神异常，以致严重残障。

理由(b)、(c)和(d)**没有时间限制**。在判断健康风险时，可以考虑该女性实际的或可合理预见的环境。在紧急情况下，一名医师即可为挽救该女性的生命或防止严重永久性损害而采取行动。
:::

在实践中，英格兰和威尔士绝大多数人工流产是依据理由(a)、在10周之前进行的，其中大多数是先用米非司酮、后用米索前列醇的早期药物流产。自2022年8月30日起，在英格兰，经过远程问诊后，早期药物流产的两种药物都可以在家中服用，适用于妊娠9周6天以内；威尔士也将同样的安排定为永久性措施。除此以外，人工流产必须在NHS医院或经批准的场所进行，每一例人工流产都必须向首席医疗官报告。

近期有两项重要改革。在**北爱尔兰**，威斯敏斯特议会的立法于2019年将人工流产去罪化，2020年以来的条例允许在12周以内应要求进行人工流产，此后则依据其他理由。在**英格兰和威尔士**，于2026年4月29日获得御准的**《2026年犯罪与治安法》（Crime and Policing Act 2026）**，将女性就终止自身妊娠而言排除在刑法之外。《堕胎法》规定的理由和时间限制没有改变，在该法条款之外实施或协助人工流产的人仍可能构成犯罪。

**良心拒绝。** 1967年法第4条规定，任何人都没有义务参与其出于良心而反对的、该法所授权的治疗，但为挽救该女性的生命或防止严重永久性损害所必需的治疗除外。在 *Greater Glasgow Health Board v Doogan* [2014] UKSC 68（杜根案）中，最高法院认定"参与"是指以亲身操作的方式参与，而不包括诸如分配人员之类的管理或监督工作。GMC要求持反对意见的医师告诉患者可以去看其他医师，确保她们有足够的信息以便不受延误地这样做，并且绝不阻碍其获得服务或表达不赞成。

::: example 11周时提出的请求 {#ex-request}
一名17岁的学生告诉她的全科医师，她怀孕11周，希望做人工流产。她没有告诉父母，并担心自己的考试。这位全科医师个人认为人工流产是错误的。全科医师负有哪些义务？
::: solution
**她的权利：** 17岁时，她被推定具有同意治疗的能力（《1969年家庭法改革法》（Family Law Reform Act 1969）第8条），并享有保密权利。《堕胎法》的理由(a)很可能得到满足：两名医师可以合理地基于善意形成意见，认为继续妊娠对她精神健康的风险大于终止妊娠，尤其是早期人工流产的风险低于继续妊娠至足月的风险。

**全科医师的良心：** 依据第4条，全科医师可以拒绝直接参与，例如拒绝签署证明。但全科医师必须及时告诉她，她可以去看另一位医师，或自行转诊至人工流产服务机构（许多机构接受自行转诊），向她提供不受延误地这样做所需的信息，并且不表达不赞成，也不试图劝阻她。时间很重要：延误会缩小选择范围并增加风险。

**良好的照护：** 如果她愿意，在不施加压力的情况下与她讨论各种选择（在支持下继续妊娠、收养、人工流产）；鼓励她让一位可信赖的成年人参与；考虑保护问题，例如伴侣的年龄和行为，以及她是否受到胁迫；并在之后提供避孕和性健康建议。
:::
:::

## 产前筛查与检测 {#prenatal}

在英格兰，所有孕妇都可通过NHS胎儿异常筛查项目接受筛查。**联合检测**（约在11–14周进行的颈项透明层扫描和血液检测）估计21、18和13三体的可能性。可能性较高（定义为1/150或更高）的女性，可以选择通过**无创产前检测**（NIPT，分析母体血液中的游离DNA，其中很大部分来自胎盘）进一步筛查，选择诊断性检测（绒毛取样或羊膜腔穿刺，有较小的流产风险），或不再做进一步检测。孕中期在18至20+6周提供胎儿结构异常扫描（[[obstetrics-gynaecology/pregnancy-antenatal]]）。

筛查不是诊断。即使是非常准确的检测也会产生假阳性；当所检测人群中该疾病并不常见时，阳性结果中可能有相当一部分是错误的。

产前检测引发一些特殊的伦理问题。

- **知情选择。** 筛查是提供给孕妇的，而不是推荐的。其目的是为人们提供作出自身决定的信息，包括决定不接受筛查。有些女性拒绝筛查，是因为她们不会终止妊娠，或者不想承受焦虑。
- **非指导性咨询。** 专业人员应准确地提供信息，包括带着该疾病生活的情况，而不引导父母走向任何特定结果。
- **残障批判。** 一些残障权利倡导者认为，以发现唐氏综合征等疾病为目标的筛查项目，表达了对患有这些疾病者生命的负面评价（**表达主义反对**），并可能减少对这些人的支持。另一些人回应说，个人的选择未必表达了对他人的任何评价，而知情选择尊重了生殖自主。
- **性别与非医学特征。** 胎儿的性别本身不是合法的终止妊娠理由；理由(d)涉及的是严重异常。对胎儿进行更广泛的基因组检测，会引发关于不确定发现的问题，以及检测成年期发病疾病的问题，因为后者会剥夺孩子将来自己决定是否要知道的选择。

::: example NIPT阳性结果 {#ex-nipt}
本章开头的阿米拉选择了NIPT。结果报告21三体的可能性高。她问自己是否应该预约终止妊娠。胎儿医学团队应如何回应？
::: solution
**解释结果：** NIPT是一项筛查试验。在她的情况下，大多数阳性结果是正确的，但仍有相当一部分不正确，原因常常是所检测的DNA主要来自胎盘，而胎盘可能带有胎儿并不具有的染色体差异。专业指南的意见是，在作出任何终止妊娠的决定之前，应提供诊断性检测（羊膜腔穿刺或绒毛取样）以确认结果。

**解释诊断性检测：** 其目的、时机、较小的流产风险，以及出结果需要多长时间。

**提供平衡的信息：** 关于唐氏综合征本身（能力和健康状况的范围、可获得的支持、家庭的经历），以及关于所有选择，包括继续妊娠、收养和终止妊娠。如果她愿意，提供与支持组织的联系。

**尊重她的决定：** 无论她作出什么决定，包括拒绝进一步检测，都是她的决定。依据理由(d)的终止妊娠没有时间限制，因此有时间审慎地作出决定；但较晚的终止妊娠操作更为困难，她应当了解实际的时间线。
:::
:::

## 辅助生殖与胚胎研究 {#assisted-conception}

**《1990年人类受精与胚胎学法》（Human Fertilisation and Embryology Act 1990）**于2008年经过大幅修订，规范体外受精（IVF）、供体受孕、配子和胚胎的储存、胚胎植入前遗传学检测以及胚胎研究。**人类受精与胚胎学管理局**（HFEA）为诊所和研究颁发许可并进行检查。该法是在沃诺克报告（Warnock Report，1984）之后制定的，该报告撰写于1978年首个IVF婴儿路易丝·布朗（Louise Brown）出生之后。

::: definition 《人类受精与胚胎学法》的主要规定 {#def-hfe}
- **14天规则：** 胚胎在受精后14天或原条出现之后（以较早者为准），不得再被保存或用于研究。
- **允许的胚胎：** 只有核DNA和线粒体DNA未被改变的胚胎才可以植入女性体内，但条例允许为预防严重线粒体疾病而进行**线粒体捐赠**的情形除外（自2015年起允许）。禁止以生殖为目的的生殖系基因组编辑。
- **孩子的福祉：** 在提供治疗之前，诊所必须考虑可能出生的任何孩子的福祉，包括孩子**对支持性养育的需要**。
- **胚胎植入前遗传学检测（PGT）：** 在HFEA授权下，可以对胚胎检测严重遗传病、染色体异常，或与需要治疗的兄弟姐妹的组织相容性。只有为避免严重的性连锁疾病才允许进行性别选择。
- **供体身份：** 使用2005年4月1日之后捐赠的配子受孕的人，可以从18岁起获知其供体的身份。
- **法律上的亲子关系：** 分娩的女性是法律上的母亲；有专门规则确定谁是第二位法律上的父母。
:::

2025年，开创线粒体捐赠技术的纽卡斯尔团队在《新英格兰医学杂志》（*New England Journal of Medicine*）上报告，经原核移植后已有8名儿童出生，其母亲受累的线粒体DNA水平很低或检测不到。与此形成对照的是，2018年中国科学家贺建奎宣布，一对其胚胎经他进行基因组编辑的双胞胎已经出生；他受到广泛谴责并被判入狱，他的工作也加强了国际上暂时禁止可遗传基因组编辑的呼声。

::: theorem 适用于新生殖技术的伦理检验 {#thm-reproductive-tests}
英国对一项新生殖技术的监管，一般会提出四个问题：

1. **安全性：** 根据现有证据，该操作对女性和未来的孩子是否足够安全？
2. **目的：** 它是否服务于严肃的医学目的，例如避免一种严重的遗传病？
3. **福祉：** 是否考虑了未来孩子的福祉，包括其身份认同和人际关系？
4. **公共正当性：** 是否进行了公众咨询并获得了议会的明确批准？
:::

::: proof
这些问题把各项原则与生殖领域的特有特征结合起来。不伤害和行善适用于两个人：女性，以及一个无法表示同意的未来孩子。由于孩子的存在本身取决于这一选择，通常的比较（"比不这样做时更好还是更差"）难以适用，这就是福祉和安全性受到明确关注的原因。公正以及对多元主义的尊重要求公共正当性，因为这些决定涉及公民之间存在深刻分歧的共同价值。英国对线粒体捐赠的处理遵循了这一模式：在议会于2015年批准相关条例之前，经过了多年的科学评估和公众咨询，之后再逐案颁发许可。
:::

::: example 救命兄弟姐妹 {#ex-saviour}
一对夫妇4岁的儿子患有重型β地中海贫血，需要定期输血。来自配型相合的兄弟姐妹的造血干细胞移植可以治愈他，但没有家庭成员配型相合。父母双方都是携带者。他们要求进行IVF并做胚胎植入前检测，以选择一个未受累且组织配型相合的胚胎。请讨论。
::: solution
**法律：** 《人类受精与胚胎学法》允许在HFEA授权下，当兄弟姐妹患有可用脐带血干细胞、骨髓或其他组织治疗的严重疾病时，检测胚胎的组织相容性。上议院在 *R (Quintavalle) v HFEA*（昆塔瓦莱案，2005）中维持了HFEA授权这样做的权力。

**支持的论证：** 父母会因新孩子本身而珍视他；这一操作可能挽救他们儿子的生命；被选中的孩子本身也不会患该病。

**反对的论证：** 这个孩子部分是作为一种手段而被创造出来的；这个孩子以后可能在能够表示同意之前被要求捐献骨髓；患病兄弟姐妹的期望可能影响整个家庭。

**回应：** 这些担忧是真实的，但可以加以管理。HFEA只对严重疾病允许这一操作，孩子以后的任何捐献都要另行审查是否符合该孩子的最佳利益。应告知这个家庭每个周期成功的可能性很低。父母双方都是携带者时，每个胚胎未受累的概率为3/4，而独立地，HLA配型相合的概率为1/4，因此只有$3/16$的胚胎是合适的（见习题“救命兄弟姐妹的机会”）。
:::
:::

**代孕。** 依据《1985年代孕安排法》（Surrogacy Arrangements Act 1985），代孕在英国是合法的，但禁止商业性安排和广告，代孕协议不具有强制执行力。代孕者在孩子出生时是法律上的母亲。意向父母随后可以申请**亲子令**（parental order），成为孩子法律上的父母。英格兰和威尔士法律委员会与苏格兰法律委员会于2023年建议进行改革，包括在某些情况下允许意向父母从孩子出生起即为法律上的父母。

## 关于新生儿的决定 {#newborn}

极早产出生或患有严重疾病的婴儿，会引发重症监护何时符合孩子最佳利益的问题。父母通常是决策者，但他们必须按照孩子的最佳利益行事；如果父母与临床医师无法达成一致，则由法院裁决。

对于极早产，英国围产医学协会的框架（2019；请核查之后是否有修订）建议，决定应基于对风险的评估，评估内容包括胎龄、估计胎儿体重、性别、胎数以及是否使用了产前糖皮质激素，而不只是胎龄。从22周0天起即可考虑以存活为目标的照护。婴儿按照估计的死亡或严重损伤风险分组：风险**极高**（超过90%）时，建议以舒适为目标的照护；风险**高**（50%–90%）时，以存活为目标或以舒适为目标的照护都可能符合婴儿的最佳利益，由父母的意愿指导选择；风险**中等**（低于50%）时，通常建议以存活为目标的照护。

当治疗不符合孩子的最佳利益时，可以不予或撤除治疗，并将重点转向姑息治疗。英国皇家儿科与儿童健康学院的框架（2015）描述了这样做可能适当的情形，例如治疗无法有意义地延长生命，或治疗的负担超过其益处。

若干判例检验了这些原则。在 *Re A (Children) (Conjoined Twins)*（连体双胞胎案，2000）中，上诉法院批准了分离一对连体双胞胎的手术，尽管手术必然导致较弱的那个孩子死亡，因为不手术两个孩子都会死亡。在查理·加德（Charlie Gard，2017）和阿尔菲·埃文斯（Alfie Evans，2018）的案件中，法院违背父母的意愿，认定继续维持生命的治疗，或把孩子送往国外接受实验性治疗，不符合孩子的最佳利益。这两起案件都引发了关于父母、法院和国家各自角色的激烈公共辩论。

::: warning 不要让单一数字决定一切
关于极早产儿或患有某种诊断的婴儿的结局统计，描述的是群体。这些数据往往基于若干年前出生、在实践不同的单位接受治疗的婴儿，而个体风险随许多因素而变化。应使用现有最好的数据如实告知父母，说明两个方向上的不确定性，并随着婴儿病情的变化重新评估。决定针对的是这个婴儿，与这对父母一起作出。
:::

::: example 22周的分娩 {#ex-preterm}
一名女性因早产临产在22周4天时入院。她怀的是单胎，估计胎儿体重520 g，24小时前已使用产前糖皮质激素。她和伴侣询问新生儿团队，孩子出生时会发生什么。
::: solution
**评估风险：** 按照BAPM框架，一个22+4周、已使用产前激素、体重尚可的单胎婴儿，很可能属于高风险组而非极高风险组。如果没有使用激素，或体重更低，风险会更高。

**与父母讨论：** 新生儿科医师应以通俗的语言，如实地带着不确定性解释存活的可能性以及无严重损伤存活的可能性；以存活为目标的照护包括什么（复苏、重症监护、住院数周至数月，以及如果治疗失败以后可能撤除治疗）；以舒适为目标的照护包括什么（抱着孩子、保暖、缓解症状、共度时光）。

**共同决定：** 在高风险组中，以存活为目标或以舒适为目标的照护都可能符合婴儿的最佳利益，应由父母的意愿指导决定。计划应记录在案，并在出生时重新评估，因为那时婴儿的状况可能改变这一计划。
:::
:::

::: quiz
关于英格兰和威尔士的法律，下列哪项陈述是正确的？
- [ ] 在24周以内，因任何理由进行人工流产都是合法的。
- [ ] 为挽救胎儿，可以推翻孕妇拒绝剖宫产的决定。
- [x] 以严重胎儿异常为理由的终止妊娠没有时间上限，但需要两名医师基于善意形成意见。
- [ ] 父亲在法律上有权在人工流产前被征求意见。
::: solution
《1967年堕胎法》的理由(d)没有时间限制。有时间限制的理由(a)并不是"任何理由"：它要求两名医师基于善意判断，继续妊娠对健康的风险大于终止妊娠，尽管在实践中这一条件常常得到满足。有决策能力的女性可以拒绝剖宫产（*St George's v S*，1998），父亲无权被征求意见或阻止人工流产（*Paton*，1979）。
:::
:::

::: history
在英格兰，人工流产首次被规定为成文法上的罪行，是1803年的《埃伦伯勒勋爵法》（Lord Ellenborough's Act）；《1861年侵害人身罪法》规定了至今仍然存在的罪名。在 *R v Bourne*（伯恩案，1938）中，妇科医师亚历克·伯恩（Aleck Bourne）公开为一名被强奸的14岁女孩终止妊娠后被判无罪，法官向陪审团指示，保全母亲的生命可以包括防止她成为"身体或精神上的废人"。由戴维·斯蒂尔（David Steel）提出的《1967年堕胎法》，源于公众对非法人工流产所致死亡的关注。

首个经IVF受孕的孩子路易丝·布朗于1978年在奥尔德姆出生，这得益于罗伯特·爱德华兹（Robert Edwards）和帕特里克·斯特普托（Patrick Steptoe）的工作。沃诺克委员会于1984年提交报告，提出了14天限制和设立法定监管机构的建议，《1990年人类受精与胚胎学法》设立了HFEA。2015年议会批准了线粒体捐赠。2019年北爱尔兰将人工流产去罪化；2026年，《犯罪与治安法》使英格兰和威尔士的女性不再因终止自身妊娠而承担刑事责任。
:::

- 关于胚胎和胎儿**道德地位**的观点包括受孕观、人格观、渐进观和关系观；汤姆森的论证则转而聚焦于身体自主。

- 当两名医师基于善意证明某一理由得到满足时，**《1967年堕胎法》**提供抗辩：理由(a)限于24周以内；理由(b)、(c)和(d)没有时间限制。居家早期药物流产已成为永久性安排（2022），自2026年起女性不再因终止自身妊娠而承担刑事责任。
- **良心拒绝**涵盖亲身操作的参与（*Doogan*，2014），不适用于紧急情况，且绝不允许阻碍患者获得服务。
- 产前筛查的目标是**知情选择**。NIPT等筛查结果必须经诊断性检测确认；咨询应为非指导性的；残障批判值得认真回应。
- **《人类受精与胚胎学法》**和HFEA规范IVF、PGT、供体受孕和胚胎研究：14天规则、孩子的福祉、允许的胚胎、线粒体捐赠（2015）以及供体身份公开。
- 代孕是合法的，但必须是非商业性的，且不具有强制执行力；亲子令转移亲子关系。
- 关于新生儿的决定基于孩子的**最佳利益**。对于极早产，BAPM（2019）建议基于风险的评估，并从22+0周起考虑以存活为目标的照护。
:::

::: exercise 四种观点 {level=1}
对于下列每一陈述，指出它最能反映哪种关于道德地位的观点：(a)"从受孕起，胚胎就是我们中的一员。"(b)"一个10周的胎儿不能感到疼痛也不能思考，所以它不具有与婴儿相同的诉求。"(c)"对5天胚胎的研究不同于终止一个20周的胎儿，而后者又不同于伤害一个新生儿。"(d)"这次怀孕对她来说就是一个宝宝，所以它很重要。"
::: solution
(a)受孕观。(b)人格观（以及与之相关的感受能力标准）。(c)渐进观。(d)关系观。
:::

::: exercise 解读法律 {level=1}
在26周时，发现一个胎儿有严重的脑畸形，婴儿期之后无法独立生存。依据《堕胎法》的哪一理由终止妊娠可以是合法的，需要满足什么条件？
::: solution
理由(d)：存在孩子将严重残障的重大风险。该理由没有时间限制，因此在26周时适用。两名注册医师必须基于善意形成这一意见，终止妊娠必须由注册医师在NHS医院或经批准的场所进行。根据专业指南，约21–22周之后，通常在药物终止妊娠前先实施胎儿灭活术。还应向父母提供继续妊娠并接受围产期姑息照护的选择。
:::

::: exercise 筛查试验的阳性预测值 {level=1 check="0.8"}
一项21三体筛查试验的灵敏度为99%，特异度为99.9%。在每1,000例妊娠中有4例受累的群体中，阳性结果中真阳性所占的比例是多少？答案保留1位小数。
::: hint
在100,000例妊娠中，计算真阳性和假阳性的数量。
:::
::: solution
在100,000例中：400例受累，其中$0.99 \times 400 = 396$例检测阳性。99,600例未受累，其中$0.001 \times 99{,}600 = 99.6$例检测阳性。阳性预测值$= 396/(396 + 99.6) \approx 0.799$，约为$0.8$。大约每5个阳性结果中有1个是假阳性，这就是为什么要提供诊断性确认。
:::
:::

::: exercise 救命兄弟姐妹的机会 {level=2 check="0.1875"}
父母双方都是某种常染色体隐性疾病的携带者。假设胚胎是否受累与其是否与患病兄弟姐妹HLA配型相合相互独立，且HLA配型相合的概率为1/4，那么既未受累又配型相合的胚胎占多大比例？答案以小数表示。
::: solution
$P(\text{未受累}) = 3/4$（未受累包括携带者）。$P(\text{配型相合}) = 1/4$。假设二者独立，$P(\text{两者兼具}) = 3/4 \times 1/4 = 3/16 = 0.1875$。合适的胚胎不到五分之一，而且并非所有合适的胚胎都能着床，因此可能需要多个IVF周期。（实际上，HLA基因与致病基因可能存在连锁，这会改变某个特定家庭的计算结果。）
:::
:::

::: exercise 团队中的良心 {level=2}
妇科病房的一名护士说，她反对照护做过人工流产的女性，不会为她们测量生命体征或给予镇痛。一名医师说他不会开具术后的抗生素。*Doogan* 案和《堕胎法》第4条如何适用？
::: solution
第4条保护的是拒绝参与该法所授权的治疗，而 *Doogan* 案将参与解释为在终止妊娠的治疗过程中亲身操作。人工流产之后的照护，例如为已经接受了手术的女性测量生命体征、给予镇痛和抗生素，并不属于参与终止妊娠。护士和医师都不能依据第4条拒绝这些照护，拒绝将违反他们不加歧视地提供照护的职业义务。应支持他们二人讨论自己的观点，但患者必须得到照护。
:::
:::

::: exercise 非指导性咨询 {level=2}
写出助产士在解释联合筛查高可能性结果时可能说的两句简短的话：一句是指导性的，一句是非指导性的。
::: solution
**指导性：**"结果是高风险，所以您会想做羊膜腔穿刺，这样就可以决定是否终止妊娠。"这句话同时预设了检测和决定。

**非指导性：**"您的结果意味着宝宝患唐氏综合征的可能性比一般情况高，大约是1/80。这也意味着得到这一结果的妊娠中，每80例有79例并未受累。您可以选择用血液检测做进一步筛查，选择能给出确定答案但有较小流产风险的诊断性检测，或者不再做进一步检测。无论您怎么决定，我们都可以谈谈每种选择对您意味着什么，也可以谈谈唐氏综合征本身。"
:::
:::

::: exercise 可遗传基因组编辑是否应当被允许？ {level=3}
分别构建支持和反对允许用可遗传基因组编辑预防一种严重单基因疾病的最有力论证，并说明监管机构在允许之前需要看到哪些条件。
::: solution
**支持：** 对少数夫妇而言（例如一方携带某显性致病变异的两个拷贝，或双方均为某隐性疾病的纯合子），PGT无法产生未受累的胚胎，而编辑可以让他们拥有一个没有严重疾病、与自己有遗传关系的孩子。预防严重疾病是一个被广泛接受的目标，而线粒体捐赠为经过审慎监管的生殖系改变提供了先例。

**反对：** 编辑的安全性（脱靶改变、嵌合现象）尚未确立；伤害会传递给无法表示同意的后代；通常存在替代方案（供体配子、收养，在大多数情况下还有PGT）；存在从治疗滑向增强的风险；全球尚无共识。贺建奎的实验表明事情可能多么迅速地出错。

**条件：** 关于安全性和准确性的可靠临床前证据；一种没有合理替代方案的严重疾病；对孩子的长期随访；逐案的独立许可；与线粒体捐赠一样，进行公众咨询并获得议会的明确批准；以及国际协调。
:::

::: exercise 关于一名新生儿的分歧 {level=3}
一名足月出生的婴儿患有严重的缺氧缺血性脑病。经过两周的重症监护，MRI和临床表现显示脑损伤非常严重；婴儿不太可能自主呼吸，如果存活，将有深度残障。团队认为继续通气不符合她的最佳利益。父母希望一切治疗都继续。应如何处理？
::: solution
**首先是沟通：** 与高年资团队进行多次会谈，给予时间和支持（院牧、口译员、心理支持），如实解释检查发现，并倾听父母的希望、信念和恐惧。寻求一位独立专科医师的第二意见，父母可以参与选择这位医师。

**最佳利益：** 决定基于婴儿的最佳利益，并作广义的考虑：继续治疗的负担、她获得舒适和愉悦的能力、有意义恢复的前景，以及父母的意见，父母的意见很重要但不具决定性。

**可选做法：** 在约定复查节点的前提下限时继续治疗；调解；请临床伦理委员会参与。

**如果无法达成一致：** 医院信托应像查理·加德案和阿尔菲·埃文斯案那样，向高等法院申请宣告。在法院作出裁决之前，治疗通常继续进行。自始至终，应以同情心对待这个家庭，不要让他们觉得自己在与团队作战。姑息治疗可以与重症监护同时引入。
:::
:::
