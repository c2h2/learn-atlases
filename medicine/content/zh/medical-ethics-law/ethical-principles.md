奥卡福（Okafor）先生74岁，患有胸部感染。他的血氧饱和度偏低，急诊医生建议住院。他拒绝了：他的妻子患有痴呆，他是她唯一的照护者，他不愿让她独自过夜。医生知道住院可能更安全。她也知道奥卡福先生意识清楚，理解她所说的内容，并且有自己的理由。她应该怎么做？

药理学和生理学都无法回答这个问题。这是一个关于**应当**做什么的问题，涉及患者的决定权、医生的帮助义务、伤害的风险以及另一个人的需要。这样的问题每天都会出现，多数发生在普通病房和诊室，而不是著名的诉讼案件中。**医学伦理学**研究的就是如何妥善回答这些问题：如何识别临床情境中在道德上重要的因素，如何权衡相互冲突的考虑，以及如何作出能够解释和辩护的决定。

本章介绍主要的工具：生物医学伦理的四原则、其背后的道德理论、贯穿本课程的若干重要区分、英格兰和威尔士伦理与法律的关系，以及分析病例的结构化方法。后续各章将把这些工具应用于知情同意、保密、生命始端与末端、资源分配、研究和职业监管。

## 伦理为什么需要方法 {#method}

道德直觉是重要的：觉得某件事不对，往往是它确实不对的第一个信号。但直觉因人而异，会随问题的表述方式而变化，还可能带有偏见。仅凭直觉作决定的临床医生既无法解释自己的决定，也无法检验这种感觉是否可靠。

伦理方法有三个作用。它帮助你**注意到**情境中与道德相关的特征，包括容易忽略的特征，例如照护者的利益或决定对信任的影响。它为你提供与观点不同的人讨论这些问题的**词汇**。它还要求你给出**理由**，使决定可以被审视、质疑和改进。

方法不会机械地产生答案。两位深思熟虑的临床医生使用同一框架，在疑难病例中可能得出不同结论。方法所排除的，是根本无法辩护的决定：图方便而作的决定、因害怕投诉而作的决定，或者因为“我们一向这样做”而作的决定。

## 四原则 {#four-principles}

临床伦理中使用最广泛的框架由汤姆·比彻姆（Tom Beauchamp）和詹姆斯·邱卓思（James Childress）在《生物医学伦理原则》（*Principles of Biomedical Ethics*）中提出，该书初版于1979年，现已出至第8版（2019年）。这一框架常被称为**原则主义**。

::: definition 生物医学伦理的四原则 {#def-principles}
- **尊重自主**：尊重有决策能力者按照自己的价值观就自身生活和身体作出决定的权利，包括作出他人认为不明智的决定。它包括积极的义务：向人们提供所需的信息，并支持他们作出决定。
- **行善**：为患者的利益而行动，即预防或消除伤害，增进其健康和福祉；在已知患者自身目标时，以患者的目标为判断标准。
- **不伤害**：避免造成伤害。由于几乎每项干预都有一定风险，实践中这意味着不造成与预期获益不相称的伤害。
- **公正**：公平地对待人。这包括获益、风险和成本的公平分配（分配公正）、尊重人的权利以及尊重道德上可接受的法律。
:::

这些原则是有意保持一般性的。宗教和哲学观点迥异的人，都会以某种形式接受其中每一条。比彻姆和邱卓思称之为**共同道德**：各文化中深思熟虑的人都认可的共同道德规范核心。四原则是组织这一共同核心的方式，而不是一种新的道德理论。

在现代西方医学中，自主常被视为首要原则，但这一框架并不对原则排序。作者将它们描述为**初始**（prima facie）义务：每一项都具有约束力，除非它与当时情境中更强的另一项义务相冲突。

::: theorem 原则是初始义务，冲突通过具体化和权衡解决 {#thm-prima-facie}
每项原则都表述了一项真实的义务，但没有一项是绝对的。当原则在具体病例中发生冲突时，以两种方式解决：

1. **具体化**：通过说明原则适用于何处、何时、为何、如何以及由谁适用，使其更加明确，从而使表面上的冲突消失或缩小。
2. **权衡**：说明理由，判断在本病例中哪项义务的分量更重。被违背的原则仍会留下“余量”：临床医生应选择对其违背最小的方案，并承认这一损失，尽可能加以弥补。
:::

::: proof
假设四原则是绝对的，那么在它们指向不同方向的任何病例中，就根本没有可允许的行动。这样的病例很常见：几乎每种有效治疗都有一定伤害风险，因此每次治疗患者时，行善与不伤害都会相互牵制。一组经常无法同时满足的绝对义务，无法指导行动。把它们视为初始义务，既保留了每项原则在道德上的严肃性，又使决定成为可能。

日常工作主要靠具体化完成。“尊重自主”过于含糊，无法解决任何问题；“尊重对该决定有决策能力的成年人在知情基础上的拒绝，即使拒绝会导致严重伤害”则给出了明确答案，英格兰法律中也有几乎相同的规则（[[medical-ethics-law/consent-capacity]]）。具体化无法解决时，就需要权衡；而给出理由、选择违背最小的方案这一要求，可防止权衡沦为做自己本来就想做的事的借口。
:::

就奥卡福先生而言，自主支持他的拒绝，行善和不伤害指向住院，公正则提醒我们注意他的妻子。只有当他对这一决定具有决策能力时，尊重自主才完全适用，因此首先要核实这一点。如果他有决策能力，权衡并不意味着推翻他的决定，而是寻找既符合他的目标又能降低风险的方案。

::: example 拒绝住院 {#ex-refusal}
继续上述病例。奥卡福先生呼吸频率24次/分，吸空气时血氧饱和度92%，对情况理解清楚。他能解释自己夜间可能加重甚至死亡，并说明他已决定承担这一风险，因为妻子不能独自留在家中。急诊医生应如何处理？
::: solution
**第1步：弄清事实。**风险有多高（CURB-65等严重程度评分有帮助）？他能否在家中安全地接受口服抗生素治疗并早期复查？

**第2步：核实对该决定的决策能力。**他理解、记住并权衡了相关信息（他明确地把自己的风险与妻子的安全作了比较），并表达了选择。决策能力是被推定的，此处也得到了确认；不能因为医生会作出不同决定，就认为他的决定无效。

**第3步：明确相关原则和相关的人。**自主支持他的选择。行善和不伤害要求医生降低风险。妻子的福祉是正当的考虑，他有权将其纳入权衡。

**第4步：寻找能同时满足更多原则的方案。**社会服务机构或亲属能否为他的妻子安排紧急照护，使住院对他来说变得可以接受？如果不能，能否在家中给予抗生素、脉搏血氧仪、安全网建议（联系谁、出现哪些症状需要返院），并由居家医院团队或全科医生次日复查？

**第5步：作出决定、记录在案并保留回旋余地。**如果他仍拒绝住院，医生应尊重这一决定，提供最佳的替代照护，并记录决策能力评估、讨论过的风险和处理计划。她告诉他随时可以改变主意。尊重拒绝不等于抛弃患者。
:::
:::

### 对原则主义的批评 {#criticisms}

这些批评揭示了该框架可能遗漏的东西。

- **过于单薄。**原则本身没有说明如何权衡，因此可被用来支持相反的结论。
- **过于个人主义。**许多患者与家人共同作决定，有些人更愿意听从家人或医生。尊重自主也包括尊重让他人参与或委托他人决定的选择。
- **缺少要素。**该框架很少直接谈到关系、品格、信任或尊严。

拉南·吉伦（Raanan Gillon）在英国推广这一方法方面贡献很大，他补充了**范围**的概念：我们还必须追问每项义务是**对谁**负有的。我们对自己的患者负有强的行善义务，但对世界上所有人并不负有同样的义务；而不伤害义务是对所有人负有的。

## 原则背后的道德理论 {#theories}

四原则源于更早的道德理论。了解这些理论有助于解释原则为何冲突，以及每项原则保护的是什么。

::: definition 主要伦理理论 {#def-theories}
- **后果主义**以结果评判行动。其最著名的形式**功利主义**（杰里米·边沁［Jeremy Bentham］、约翰·斯图尔特·密尔［John Stuart Mill］）认为，正确的行动是产生最大总体福祉的行动。它是成本效果分析和公共卫生推理的基础。
- **义务论**以行动是否符合义务、是否尊重权利来评判行动，而不论某些后果如何。伊曼努尔·康德（Immanuel Kant）认为，人必须始终被当作目的本身，而决不能仅仅被当作手段。它是知情同意、讲真话以及禁止未经同意将人用于研究的基础。
- **美德伦理**可追溯到亚里士多德（Aristotle），它追问一个好人，或一位好医生，会怎样做。它关注诚实、同情、勇气和实践智慧等品格特质。
- **关怀伦理**由卡罗尔·吉利根（Carol Gilligan）、内尔·诺丁斯（Nel Noddings）等人发展，强调关系、依赖以及对具体个人的回应，而非抽象规则。
- **决疑法**从案例出发推理。它把新病例与答案已有共识的清晰“范例”病例相比较，看它最像哪一个（阿尔伯特·琼森［Albert Jonsen］与斯蒂芬·图尔敏［Stephen Toulmin］，《决疑法的滥用》［*The Abuse of Casuistry*］，1988年）。
- **叙事伦理**关注患者的故事：疾病如何融入其生活，一个决定在其中意味着什么。
:::

这些理论没有一个在哲学争论中胜出，每个都有众所周知的问题。纯粹的功利主义可能为牺牲一人以拯救数人辩护。严格的义务论可能禁止一个能救命的谎言。美德伦理在“该做什么”上可能含糊不清。因此，临床伦理倾向于把它们当作**透镜**来使用：每种理论都能使人注意到其他理论可能忽略的病例特征。

::: example 一张重症监护床位 {#ex-alloc}
凌晨3点，一家地区医院只有一张重症监护床位，却有两名患者需要。一名46岁女性患重症肺炎，接受机械通气后康复的机会很大。一名82岁男性患晚期心力衰竭并新发卒中，存活至出院的机会低得多。其中一人可以转往另一家医院，但需要两小时。请把各种理论当作透镜来分析。
::: solution
**后果主义透镜：**哪种分配的预期获益最大？这名女性存活的概率更高，预期生命年更多。这支持把本院床位给她，并在转运对该男性临床上合适时为他安排转院。

**义务论透镜：**两名患者有同等的权利受到尊重，任何一方都不得仅因年龄而被排除。决定必须基于能预测获益的临床因素，而非价值或地位。应向该男性及其家人诚实地解释。

**美德与关怀透镜：**一位富有同情心且公正的临床医生会怎么做？与双方家属沟通，避免由最年资低的医生仓促决定，请主治医师参与，并确保没有得到床位的一方仍能获得良好照护，包括在升级治疗不符合其利益时提供姑息治疗。

**决疑法：**如果其中一名患者几乎肯定不会获益，很少有人认为“先到先得”是公平的；如果年长患者获益同样多，大多数人认为仅因年龄而拒绝其床位是不公平的。

**结论：**推理指向按预期临床获益分配，对每名患者进行评估而不是以年龄为替代指标，同时确保另一名患者获得最佳的替代方案。重症监护是否真能使这位82岁患者获益，应就其本身来判断，最好与他本人或其亲近之人一起决定。这正是正式的重症监护分诊指南背后的逻辑，见[[medical-ethics-law/justice-resources]]。
:::
:::

## 反复出现的区分 {#distinctions}

医学伦理中有几种区分反复出现。它们是准确描述病例的工具，本身并不是答案。

### 作为与不作为

造成伤害与听任伤害发生之间有道德差别吗？许多人认为有：杀死似乎比任其死亡更坏。英格兰法律在生命末期于此处划了一条清晰的界线。如果继续维持生命治疗不符合患者的最佳利益，医生可以合法地不予或撤除这种治疗，但不得采取行动结束生命，英国上议院在*Airedale NHS Trust v Bland*（1993年，布兰德案）中对此作了阐述。一些哲学家认为这一区分本身没有道德分量，重要的是意图和结果。这一争论将在[[medical-ethics-law/end-of-life-ethics]]中再次出现。

### 双重效应原则

::: definition 双重效应原则 {#def-double-effect}
**双重效应原则**认为，一项既有好效应又有可预见的坏效应的行动，在满足以下全部四个条件时可以被允许：

1. 行动本身不是错误的；
2. 行为者只意图好效应；坏效应是可预见的，但不是被意图的；
3. 坏效应不是实现好效应的手段；
4. 接受坏效应有相称的理由。
:::

经典的医学例子是在生命末期使用阿片类药物或镇静药缓解严重痛苦。在*R v Adams*（1957年，亚当斯案）中，德夫林法官（Devlin J）对陪审团说，医生有权采取一切适当和必要的措施缓解疼痛和痛苦，即使这些措施可能附带地缩短生命。在现代姑息治疗中，按症状滴定的阿片类药物很少被证明会缩短生命，因此需要援引双重效应的情形比人们想象的少。但这一原则仍然重要，因为它解释了意图为何重要：为缓解症状而滴定剂量使用的同一种药物是合法的，而为结束生命而选择的剂量则不合法。

### 相称的治疗

过去“普通”治疗（必须始终给予）与“非常”治疗之间的区分，已让位于追问一项治疗是否**相称**：按照患者自己的价值观，该治疗对这位患者的预期获益是否超过其负担。同一台呼吸机，对一位患者可能是相称的，对另一位则不然。

### 良知

医生也是道德主体。**良心拒绝**是基于良知拒绝参与一项合法的医疗操作。法律对人工流产（《1967年堕胎法》［Abortion Act 1967］第4条）和某些生育治疗（《1990年人类受精与胚胎学法》［Human Fertilisation and Embryology Act 1990］第38条）规定了这种保护；在其他情形下，英国医学总会（GMC）只有在患者仍能及时获得医疗服务时才允许良心拒绝（见习题“良知与可及性”）。

::: warning 伦理不等于法律，二者也都不等于医生的个人意见
三个不同的问题常被混为一谈：**法律要求什么？**、**职业指南要求什么？**以及**伦理上什么是最好的？**答案通常一致，但并不总是如此。某事可能合法但不道德（在取得有效同意的过程中无谓地冷漠），或者原则上合乎伦理却不合法（有人对协助死亡持此看法）。而且，法律和伦理意义上的“最佳利益”并不意味着“医生会选择的”。它指的是对**这位**患者最好的，要考虑其本人的意愿、信仰和价值观。学生写“这符合患者的最佳利益”来表示“这是医学上推荐的”，是一个严重而常见的错误。
:::

## 英格兰和威尔士的伦理与法律 {#ethics-law}

本课程首先遵循**英格兰和威尔士**的法律，因为英国大多数医学院和GMC的指南都以此为背景。苏格兰和北爱尔兰有各自独立的法律体系，部分法律差异很大，例如在决策能力（《2000年成年人无行为能力（苏格兰）法》［Adults with Incapacity (Scotland) Act 2000］）和人工流产方面。世界其他地区的法律差异更大。本课程对法律的描述是为了教学，而非法律意见。

英格兰和威尔士的医事法主要有四个来源：

- **制定法**：议会法案，例如《2005年精神能力法》（Mental Capacity Act 2005）、《2004年人体组织法》（Human Tissue Act 2004）和《1967年堕胎法》。
- **普通法**：法官在已判决案件中发展出的原则，例如过失法和关于同意的法律。上级法院的判决约束下级法院。
- **《欧洲人权公约》**（European Convention on Human Rights），通过《1998年人权法》（Human Rights Act 1998）在英国法中生效。包括NHS机构在内的公共机构必须以符合公约权利的方式行事。最相关的是第2条（生命权）、第3条（免受不人道或有辱人格的待遇）、第5条（人身自由）、第8条（私人和家庭生活受尊重）、第9条（思想、良心和宗教自由）和第14条（禁止歧视）。
- **职业监管**：GMC的指南，首先是《良好医疗实践》（*Good medical practice*，2024年），本身不是法律，但严重或持续地不遵守可能危及医生的注册资格，法院也会将其纳入考虑（[[medical-ethics-law/professionalism-regulation]]）。

**刑法**惩罚危害社会的不法行为：未经同意进行治疗可能构成殴击（battery），重大过失致人死亡可能构成过失杀人。**民法**允许个人索赔，最常见的是过失侵权。

::: definition 医疗过失 {#def-negligence}
要在**医疗过失**索赔中胜诉，索赔人必须按盖然性权衡标准证明：

1. **注意义务**：临床医生对患者负有义务。一旦存在专业关系，几乎总是如此。
2. **违反义务**：临床医生的行为低于注意标准。根据*Bolam v Friern Hospital Management Committee*（1957年，博勒姆案），如果医生的做法被负责任的医学意见群体认为恰当，医生就不存在过失。*Bolitho v City and Hackney Health Authority*（1997年，博利托案）补充说，该意见必须经得起逻辑分析。就告知患者风险的义务而言，博勒姆标准已被*Montgomery v Lanarkshire Health Board*（2015年，蒙哥马利案）的标准所取代。
3. **因果关系**：违反义务导致了损害，通常通过追问“若无”违反义务损害是否仍会发生来判断。
4. **损害**：患者遭受了法律认可的那类损害。
:::

法律规定的是底线而非上限：GMC期望医生的执业水平远高于避免法律责任所需的最低标准。

## 分析一个病例 {#structured-approach}

分析临床病例的一个有用结构，是阿尔伯特·琼森、马克·西格勒（Mark Siegler）和威廉·温斯莱德（William Winslade）的**四主题法**（《临床伦理学》［*Clinical Ethics*］，第9版，2022年）。它先整理事实再讨论原则，从而避免一种常见错误：真正的分歧在于事实，却在价值观上争论不休。

::: definition 临床伦理病例的四个主题 {#def-four-topics}
1. **医学指征**：诊断和预后、治疗目标、各种选择及其成功和伤害的概率。（行善与不伤害。）
2. **患者偏好**：患者是否有决策能力？他们想要什么，以前说过什么？如果缺乏决策能力，谁能说明其意愿，是否有预先决定？（尊重自主。）
3. **生活质量**：从患者的角度看，接受和不接受治疗时其生活会是怎样的？临床医生的评估中是否存在偏见？（行善、不伤害、自主。）
4. **情境特征**：家庭、照护者、宗教和文化、资源、法律、保密、利益冲突、研究。（公正与忠诚。）
:::

然后列出现实可行的选项，用原则逐一检验，选择最能辩护的一个，并计划应由谁参与、决定如何记录和复核。许多医院设有**临床伦理委员会**，其建议不具约束力。严重的、无法解决的分歧可诉诸法院：缺乏决策能力的成年人由保护法院（Court of Protection）处理，儿童由高等法院处理。

行善的很大一部分是在不确定性下作判断：治疗的预期获益是否超过其负担。一个简单模型可以清楚地显示其结构。假设一项治疗如果有效（概率为$p$）可带来获益$B$，并对每个接受者施加负担$H$（副作用、住院时间、个人付出的代价）。其预期净获益为

$$E = pB - H.$$

按这一简单模型，当$E > 0$，即$p$超过**阈值概率**$p^* = H/B$时，治疗值得提供。实际决策涉及的不止一个数字，$B$和$H$的值取决于对患者重要的东西。但这一模型说明了为什么同一诊断的两位患者可以合理地作出不同选择：如果一个人更看重可能的获益，或不太在意负担，其阈值就更低。

::: widget plot
f: B*x - H; 0
x: 0, 1
y: -10, 10
sliders: B=10:1:20:0.5; H=3:0:10:0.5
labels: \text{治疗的预期净获益}; \text{不治疗}
caption: 一个简化的决策模型。横轴是治疗有效的概率$x$；纵轴是以任意单位表示的预期净获益$Bx - H$。直线位于零以上，即$x > H/B$时，治疗值得提供。增大负担$H$（例如一位非常希望避免住院的患者），可见阈值升高；增大成功的价值$B$，可见阈值降低。仅作示意，不是临床计算器。
:::

::: example 医学生与麻醉下检查 {#ex-student}
一名四年级医学生在妇科手术室，被一位住院医师要求为一名已麻醉的患者做阴道检查，“用来学习”。该学生不知道患者是否同意过。学生应该怎么做？
::: solution
**事实：**为教学目的对已麻醉患者进行私密检查，只有在麻醉前取得患者的专门同意时才是合法的。否则，该检查将构成殴击，并严重违背信任。GMC关于私密检查的指南要求，任何不属于计划操作的麻醉下检查，包括由学生进行的检查，都必须取得同意。

**原则：**尊重自主和身体完整性是决定性的考虑。对学生以及未来患者的教育获益，不能为未经允许使用患者身体辩护：用康德的话说，这是把她仅仅当作手段。

**行动：**学生应礼貌地询问患者是否同意由学生进行检查。如果回答是否定的或不清楚，学生应拒绝。这需要勇气，因为学生与住院医师之间存在权力不平衡。一句清楚、平静的话会有帮助：“抱歉，在不知道她是否同意的情况下，我不方便为她检查。”学生之后应向导师或通过医学院的关切反映程序提出此事。好的结果是手术室的做法得到改变，使教学同意总是事先讨论，这也是现在的标准做法。提出关切是一项职业义务，见[[medical-ethics-law/professionalism-regulation]]。
:::
:::

::: example 安慰剂处方 {#ex-placebo}
一位全科医生多次接诊一名35岁持续疲劳的女性。各项检查均正常。她请求“给点有帮助的东西”。医生考虑给她开一种自己认为没有特异作用的维生素补充剂，并告诉她“这对像你这样的人常常有帮助”。这样做合乎伦理吗？
::: solution
**事实与偏好：**安慰剂对主观症状的效应是真实的，但因人而异，而且这种补充剂不太可能造成身体伤害。但她并未同意在误导性的理由下接受无活性的治疗；她的自主依赖于准确的信息。

**分析：**“这对像你这样的人常常有帮助”是有意误导，即使就安慰剂反应而言在字面上成立。欺骗会损害信任，一旦被发现会让她感到被敷衍，还可能使人忽视她疲劳的真正原因。GMC的指南要求医生不得误导患者。

**更好的选择：**认真对待症状，诚实解释检查结果显示了什么以及对疲劳已知的情况，提供有循证依据的方法，例如逐步恢复活动和睡眠建议，筛查抑郁，并持续随访。一些研究发现“公开标签”安慰剂（告诉患者药片无活性）有一定益处。它在常规实践中是否有一席之地尚有争议，但至少避免了欺骗。
:::
:::

::: quiz
一名有决策能力的30岁男性因是耶和华见证人，拒绝为严重出血输血。外科医生认为行善必须压倒自主，因为他不输血就会死亡。在英格兰和威尔士适用四原则时，哪种回应最恰当？
- [ ] 生命危急时行善压倒自主，因此应当输血。
- [x] 原则是初始义务；针对本病例具体化后，尊重有决策能力的成年人在知情基础上的拒绝占优，而行善通过采用每一种可接受的输血替代方案来实现。
- [ ] 如果家属同意，医生应当输血。
- [ ] 由于患者拒绝了标准治疗，外科医生可以完全拒绝手术。
::: solution
在英格兰和威尔士，有决策能力的成年人可以拒绝任何治疗，即使拒绝会导致死亡（*Re T*，1992年；*Re B*，2002年），家属无权代他同意。原则不分先后，但针对这一情境（有决策能力的成年人在知情基础上的拒绝）具体化后，自主是决定性的。行善并未消失：它要求团队采用患者接受的每一种替代方案，例如在他接受的情况下使用自体血回收、氨甲环酸、精细止血以及纠正贫血，并私下核实拒绝确实出于他本人而非来自压力。拒绝手术会使他面临更坏的结局，等于抛弃他。
:::
:::

::: history
希波克拉底誓言（Hippocratic Oath）可能写于公元前5世纪或前4世纪，它要求医生帮助病人、避免伤害并保守秘密。两千年间，医学伦理主要关乎医生的品格和礼仪；托马斯·珀西瓦尔（Thomas Percival）的《医学伦理》（*Medical Ethics*，1803年）塑造了英国和美国的职业准则。

现代生命伦理学兴起于第二次世界大战之后。《纽伦堡法典》（1947年）在审判纳粹医生之后写成，把自愿同意置于研究伦理的中心。1966年，哈佛大学的麻醉医师亨利·比彻（Henry Beecher）发表了美国主流期刊中22个不道德研究的例子，表明滥用并不限于独裁国家。20世纪60—70年代的新技术，包括透析、呼吸机和器官移植，提出了谁应接受治疗、何时应停止治疗的问题。比彻姆和邱卓思于1979年出版《生物医学伦理原则》，同年发表了关于研究伦理的《贝尔蒙报告》（Belmont Report）。在英国，拉南·吉伦在20世纪80—90年代的著述使四原则成为标准教学框架，医学伦理与法律也成为医学课程的核心部分。
:::

::: summary
- 医学伦理追问临床照护中应当做什么，并要求以理由为决定辩护。
- 四原则是**尊重自主**、**行善**、**不伤害**和**公正**。它们是初始义务，不分先后；冲突通过**具体化**和**权衡**解决。
- 原则主义借鉴了后果主义、义务论、美德伦理、关怀伦理、决疑法和叙事伦理，这些理论最好作为互补的透镜使用。
- 反复出现的工具包括作为与不作为的区分、**双重效应原则**以及**相称**治疗的检验。
- 法律、职业指南和伦理相互重叠但并不等同。在英格兰和威尔士，医事法来源于制定法、普通法、《1998年人权法》和职业监管。
- 过失需要具备义务、违反义务（博勒姆案、博利托案；风险告知适用蒙哥马利案）、因果关系和损害。
- 用四个主题分析疑难病例：医学指征、患者偏好、生活质量和情境特征。先弄清事实，再讨论价值观。
- “最佳利益”指按照患者自己的价值观对这位患者最好的，而不是医生会选择的。
:::

## 习题

::: exercise 指出原则 {level=1}
对于下列每句话，指出最直接相关的原则：(a)“我解释了三种选择及其风险，她选了我本不会选的那一种。”(b)“新药每年花费80,000英镑；为它买单意味着髋关节置换手术会减少。”(c)“我们停止了化疗，因为其副作用超过了可能的获益。”(d)“我安排了物理治疗，让他能早点回家。”
::: hint
想一想每句话保护的是谁的利益或权利，涉及的是帮助、避免伤害、选择还是公平。
:::
::: solution
(a)尊重自主：提供信息并尊重患者的选择。(b)公正，具体而言是分配公正：有限资源的公平分配。(c)不伤害，与行善相权衡：治疗的伤害已变得不相称。(d)行善：积极增进患者的福祉。
:::
:::

::: exercise 以理论为透镜 {level=1}
简述功利主义者、康德主义者和美德伦理学者分别会如何看待是否告诉患者一次未造成伤害的轻微用药差错。
::: solution
**功利主义者**比较后果：告知可能引起一些焦虑，但能维护信任并使系统吸取教训，而隐瞒一旦被发现会造成更大伤害；多数人会选择告知。**康德主义者**认为，欺骗患者，即使是对涉及其自身身体的事保持沉默，也未能把患者当作理性主体来尊重，因此必须告知。**美德伦理学者**会问，一位诚实而富有同情心的医生会怎么做，并会选择告知和道歉。在英国，职业坦诚义务无论如何都要求告知（[[medical-ethics-law/professionalism-regulation]]）。
:::
:::

::: exercise 双重效应 {level=1}
一名肺癌终末期患者呼吸困难、恐惧不安。姑息治疗医生逐步增加吗啡剂量，直至痛苦得到控制。请应用双重效应原则的四个条件。
::: solution
(1)行动本身，即给予吗啡缓解呼吸困难和痛苦，并不错误。(2)医生意图缓解症状；任何生命缩短（如果发生）是被预见为可能的，但不是被意图的。根据症状逐步滴定就是这种意图的证据。(3)缓解是通过药物对呼吸困难的作用实现的，而不是通过患者死亡实现的。(4)生命最后几天的严重痛苦是相称的理由。该行动是可允许的。实践中，按症状谨慎滴定阿片类药物很少被证明会缩短生命。
:::
:::

::: exercise 治疗阈值 {level=2 check="0.25"}
一位考虑手术的患者说，如果手术成功，对她而言相当于12个月高质量生活的价值。手术后的恢复过程（每个手术者都必须经历）她估价为相当于损失3个月。用模型$E = pB - H$计算：手术对她具有正的预期价值时，最低的成功概率是多少？以小数表示。
::: hint
令$E = 0$，解出$p$。
:::
::: solution
$p^* = H/B = 3/12 = 0.25$。如果成功概率高于25%，手术对她就有正的预期价值。一位把成功估价为6个月的患者则需要$p > 0.5$，这就是为什么同样的概率可以使通情达理的人作出不同选择。
:::
:::

::: exercise 将原则具体化 {level=2}
一名19岁1型糖尿病患者屡次不来门诊，这时“尊重自主”似乎与“行善”相冲突。请将自主原则具体化，使之能够指导行动，并说明行善仍然要求什么。
::: solution
一种有用的具体化：“尊重有决策能力的年轻成年人就自身糖尿病照护作出的知情决定，包括不来就诊，同时以他可能接受的形式提供照护。”门诊无法强制他就诊，但行善仍要求付出努力：了解他为何不来（工作、交通费用、倦怠、抑郁、进食障碍）；提供灵活或远程的预约；确保他知道酮症酸中毒的预警症状；并保持大门敞开。不探究原因就因失约让他出院，就是未尽行善之责。
:::
:::

::: exercise 过失的要件 {level=2}
一名初级医生未核查患者的过敏史就开了青霉素。患者有记录在案的青霉素过敏，但碰巧没有发生反应。这在法律上构成过失吗？是伦理上的失误吗？
::: solution
过失索赔会失败：存在注意义务，很可能也违反了义务，但没有损害。但在伦理上这仍是失误，因为它使患者面临严重的、本可避免的风险。应向患者告知，通过不良事件系统报告以便系统吸取教训，并进行反思。没有法律责任并不意味着行为可以接受。
:::
:::

::: exercise 四个主题 {level=3}
一名88岁晚期痴呆女性住在养老院，今年第三次患肺炎。她无法安全吞咽。她的女儿坚持“必须尽一切努力”，包括进入重症监护病房。请用四个主题整理病例，并概述合理的处理方法。
::: solution
**医学指征：**晚期痴呆患者反复发生吸入性肺炎，预后不良；抗生素可治疗这一次发作，但不能消除病因；重症监护不太可能使她恢复到原有状态，且负担沉重。

**患者偏好：**她对这一决定缺乏决策能力。是否有预先决定、健康与福利持续授权书，或她既往表达的意愿、信仰和价值观的任何记录？女儿的看法是关于这些情况的重要证据，但除非她持有相关的授权书，否则不具决定性；即使持有，她也必须按照母亲的最佳利益行事。

**生活质量：**她是否舒适；她是否享受食物、音乐、陪伴？不要假定痴呆患者的生命没有价值。

**情境特征：**女儿的痛苦、养老院提供临终照护的能力、文化或宗教信仰、《精神能力法》的框架。

**处理：**与女儿、养老院工作人员和临床团队召开最佳利益会议：探讨她母亲本会想要什么，诚实解释重症监护能做到和做不到什么，讨论以舒适为中心、在有帮助时处理可逆问题的计划，并记录在ReSPECT等计划中。如果无法达成一致，可寻求第二意见、伦理咨询，最终可诉诸保护法院。
:::
:::

::: exercise 良知与可及性 {level=3}
一位全科医生出于真诚的宗教信仰，反对开具紧急激素避孕药。一名17岁少女在周六上午前来要求开这种药。分析该医生的义务。
::: solution
紧急避孕不受《1967年堕胎法》中法定良知条款的保护，因为它在着床前起作用，在法律上不属于人工流产。GMC允许医生出于良知不提供某种治疗，但有严格条件。医生必须：毫不拖延地告诉患者她可以去找其他医务人员；确保她有足够的信息及时就诊，以便治疗仍然有效（左炔诺孕酮服用越早越有效，宫内节育器是最有效的方法）；避免表达任何不赞成或道德评判；不得阻碍她获得服务。如果没有其他医务人员能及时提供，而延误会造成伤害，医生对患者的义务优先。这名17岁少女和其他患者一样享有保密的权利。如果医生的良心拒绝会经常妨碍患者及时获得医疗，就应调整诊所安排，避免出现这种情况。
