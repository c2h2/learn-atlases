医学伦理不是生物化学与临床医学之间一门装饰性的课程：它是那门处理“技术能力无法回答的剩余问题”的学科、而这个书库里每一章临床的内容都安静地依赖着它的四问装置。**这开篇的一章研习主导英语世界生命伦理学的原则主义框架（自主、行善、不伤害、正义）、它的德国与欧陆的表亲（尊严、团结）、临床医师实际用来推理的竞争理论（案例推理、叙事伦理、关怀伦理、德性的理论、以及契约论的两个版本）、这个框架的批评者（它的抽象、它在“原则主义”与“诸原则”之间的含混、它对关系与制度的忽视）、以及它的实验室应用——在同意、拒绝、不确定、以及“询问的伦理”中这四原则的实际行为。**

## 框架

::: definition 四原则及其逻辑 {#def-principles}
**比彻姆与蔡尔德里斯的综合（“原则式的生物医学伦理”这条谱系、自1979年的第一版直到它被法庭引用的时代）把临床伦理组织成四项临时性的承诺。尊重自主：承认这个人对其自己生活的、经过考虑的权威——在知情同意与拒绝中被操作化、以密尔的伤害与自由之论与康德“人自身即是目的”的公式为根据、并通过它自身的发展历程被理解：从家父主义的“医师决定”时代、经1960至90年代以权利为基础的同意法、直到今天的关系性自主的理论（自主是在家庭与疾病之中行使的、而不是由孤岛式的自我行使——这一批评软化了这个框架、却没有把它抛弃）。行善：给予利益的积极义务、而临床医学把它膨胀为整个职业的自我形象、伦理学则使它保持谦抑（利益不是临床医师所看重的任何东西；它是“按患者自己对自身善好的叙述而值得选择”的东西——稀薄的善对厚重的善之争）。不伤害：那条“首先勿伤害”的传统“勿伤害”这句格言的希波克拉底邻近的出处比口号更复杂、而“首先勿伤害”是在经院哲学的注疏中出现的、它在临床各章所依赖的三个区分中承担着分析的重活：作为对对比容许撤除对不予的等值、生命末端的法律已经解决了这一点、致死对听其死亡这一学说在镇静与营养的边界上其融贯性有争议、及常规对非常规比例对不成比例的手段的现代表述、它驱动着关于徒劳的争论。正义：其余三条在病房门口留下的分配问题分配的各章拥有、加上程序的要求——一致、透明、可申诉——罗尔斯式与丹尼尔斯式的可问责性把形式化。原则是“可具体化的”而非自我应用的原则主义对诸原则之争：这个框架给出的是诸理由的权重、不是一个算法、它们按设计就会冲突真正的工作是个案中对话语次序的论证、而它们共同的产出是那次四问的临床复审——患者想要什么、医学能提供什么、什么不可以做、以及当答案超出这位患者的要求时由谁决定——这就是为什么本课程的章序把伦理放在同意与死亡之前无论哪一个。**
:::

## 竞争者

::: definition 竞争的理论及其临床用途 {#def-rivals}
**案例推理杨森与图尔明1988年对耶稣会案例方法的重新评价所开启案例法的复兴以范例与类比推理、而不是以原则的应用：它的临床优点是熟悉案例的形态那种“带家庭压力的拒绝”模板、那种“能力不明确的感染”模板、而它的危险是共识的漂移范例编码了它们那个时代的偏见——教会了“善意的欺骗”的疯人院时代的案例。叙事伦理与弗兰克及吉利根邻近的学派把患者的故事当作道德的数据：谁在对谁讲述、疾病威胁着哪些身份、这次讲述要求被承认什么——这套装置背后是叙事医学规划被记录在案的影响：在共情的测量与临床结局柔软的终点上。关怀伦理道德发生学传统中的吉利根、经特朗托与赫尔德的系统化把道德的场景从两个陌生人的选择、迁到那张持续的依赖之网上照护者、子女、资源不足的团队——病房实际上就由构成、由此产生同意的关系性自主的重新解释家庭参与的同意模式的正当的多元、对它们被滥用风险的告诫、以及那篇道德残余的文献尽管决定是正确的、错误仍然存在——这就是临床医师之哀的研究如今出现在伦理学期刊上的原因。德性伦理在医学中的回归从佩勒格林开始的“医学作为道德实践”的传统、直到以品格为核心的教员发展问的不是该做什么、而是行动者正在成为谁：坦诚与谦抑的文献、用于不公正对待研究的职业恶习的分类、以及经验的转向品格在情境中是脆弱的——行为伦理的发现支持用系统的路径而不是英雄崇拜。契约论的伦理斯坎伦的“没有人能合理地反对”的表述提供了研究伦理与公共卫生正当化的语法为什么强制需要连被强制者也无法合理反对的理由——锡拉库萨与纳菲尔德邻近的比例性检验。结果主义在其精化的形式中规则对行为、优先主义与充足主义的变体主宰着卫生经济学的伦理底层质量调整生命年的“平均主义否则免谈”之争、而功利的速记法曾经统治那里。以尊严为基础的框架从康德经受基本法影响的生物伦理公约的欧陆与战后的权利传统做着原则主义做不到的工作：酷刑与治疗禁令背后的不可侵犯性的直觉、与“死亡中的尊严”法理的对立的读法尊严作为固有的价值、对尊严作为质量——这个论证从两侧塑造着协助死亡的争论。本章所教的评判习惯：理论没有一个像定理那样“正确”；它们是器具、而称职的临床医师知道每一个临床的时刻需要哪一件器具——同意的表单是原则主义的、拒绝的谈话是叙事的、人手的溃败是关怀伦理的地盘、而分诊是在审查之下的结果主义。**
:::

## 应用

::: definition 同意、拒绝、不确定与询问 {#def-applications}
**同意是这个框架的第一个实验室：要素对重要的风险与收益及替代方案的告知、以患者语言实现的理解、不受诱导与压力的自愿、能力、以及授权在法律上已经确定、在实践中却一团糟同意证据的文献记录了那种“签名不是过程”的文化、以及在“理性的患者”标准与专业标准之间的告知阈值的争论、蒙哥马利时代的判决把天平重新向患者的“重要性”一侧校正。拒绝把容易与困难分开：有能力的成人拒绝救命治疗的权利“决定即权威”的学说、在普通法的输血与呼吸机的案例中已确定、而在别处都未确定——耶和华见证人的预嘱架构作为“有远见的拒绝”的工作模型对比三个困难的类别：能力受损的拒绝评估、与那个按严重度滑动的标准文献、代理的判断与最佳利益的体制在各法域之间“预嘱对亲属”的争论光谱、以及在胁迫或未治疗的精神疾病之下的拒绝“协助自杀对拒绝性自杀”的法理、与精神科各章继承的那套“收住对治疗”之争。不确定是伦理的默认状态、而它的工具是：比例性的审查、 预防原则的分级形式、“最佳利益作为整体”的权衡把患者的价值先验写进去、与能力法的框架邻近、从“徒劳”到“无益的治疗”的词汇迁移政策的共识是：关于徒劳的主张需要机构的流程、而不是独断——二次复审与提供转出的程序、及对团队道德残余与道德困厄的记账“道德困厄作为人力的伤害”这一文献、它把一个伦理学的概念变成人才流失的变量。以及询问——整章所服务的那项临床技能：治疗目标谈话的架构“重病谈话”模板的证据基础、沟通各章的“引出—提供—支持”的建议序列、价值优先的病史“什么会让下一个月值得活下去”作为一种有近验证血统的工具、以及那句谦抑的条款：伦理咨询自身的结局数据“伦理会诊降低的是治疗的限度、而不是冲突的分数”这一发现教导说：这门学科真正的产品、是人们在事后能够与之共存的过程。本章在临床伦理居住的地方结束：不是解决困境、而是让剩下的困境变得可见、共享、并有记录。**
:::

::: example 病房上的拒绝 {#ex-refusal}
一名61岁的糖尿病足的坏死伴脓毒症的患者拒绝截肢、反复地、表面上有理解；外科的住院医师确信这拒绝是“抑郁在说话”她已治疗抑郁八年、并请作为值班顾问的你“和她认真谈一次”。
::: solution
**拒绝需要的是评估、不是说服（[[#def-principles]]、[[#def-rivals]]、[[clinical-skills/communication]]）：次序是：恰当地评估能力四项能力的框架——理解、保持、权衡、表达——由受过训练的人来做、并作为推理而不是感觉记录下来；抑郁不等于无能力、而“这个拒绝是抑郁的症状还是患者的价值”这个问题、由“权衡”这项能力的质量来回答、而不是由它是否与你的意见一致；请精神科来治疗与评估、而不是来否决伦理咨询文献警告的那种双重角色的陷阱；检验这个拒绝的稳定与信息的根基她是否在此刻拒绝这件事、知晓疼痛与脓毒症的轨迹、以及她可能从未被提供的替代——单用抗生素与姑息的路径；并开启那场“拒绝本身就是对它的回答”的价值谈话“你更害怕什么——死去、还是以截肢者的身份活着”是一个最高等级的病史问题、以及在那个做对了的关系模型中“家庭是背景、不是陪审团”。只有在评估支持时才升级第二份能力的意见、以及在极端情形下类似保护法院的宣告路径——那个流程即使怀疑患者、也把她当作权利的持有者、这就是它慢的原因、而它应当比现在更罕见。团队的伦理工作：住院医师的确信是“穿着认识论外衣的道德困厄”道德困厄预测道德越界的发现、护理团队的分歧值得一次伦理会诊的请单那个把分歧变成议程的流程、以及保护所有人的诚实记录：附上能力的评估、记录已提供并被拒绝的替代、以及那段“我们会继续治疗脓毒症并重新讨论这件事”的文字——当外科医师的职责是救一条命、而患者的职责是决定这条命属于谁时、它让这段关系保持敞开。**
:::

::: example 只剩下那一剂 {#ex-alloc}
地区医院里只有一剂稀缺的抗蛇毒血清、两名被咬伤的患者：一名9岁的儿童、与把她送来的34岁的教师；两人都将失去肢体、其中一人可能死亡；而这位教师的家人已经在你们的急诊科帮了三天忙。
::: solution
**病床边的分配（[[#def-principles]]、[[medical-ethics-law/justice-resources]]、[[emergency-critical-care/acute-assessment]]）：先框架、后情绪：论证的问题是“哪一个决定是各自都无法合理拒绝的”契约论的检验、而候选的答案排开：救孩子公平的局数 与生命年的优先的直觉、在预后不同时最有力、救预后较好的结果主义的按生命年加权的临床现实主义、先到先得排队的规范——在极端情形中很弱、而且它偏向于交通条件更好的人、救那位在你手中受伤的帮助者对卫生工作者的特别义务这条通道、并延伸到她这个行为的后果、就是教师自身的牺牲——这是一个病房会提出的论证、而伦理学者必须诚实地权衡、而不是压制。鉴于事实的正确程序：临床的紧迫优先死亡风险的差异若大就由高下决定——医学的排序沉默之处、正是伦理开始的地方、然后是医院在新冠时代的框架所确定预先约定的决胜规则公平局数的儿童优先、除了始终如一并书面适用的特别义务例外之外不给社会价值加分、并由负责的临床医师在记录之下做出决定、而不是由走廊里的家属做出可问责与一致的要求——“一致作为正义”这条规则、让凌晨三点的同一案例得到同一个答案。残余的处理：落败那一家与团队的简述新冠时代文献产生的“分配之后”的道德损伤的流程、医院本应在决定之前就有的那份透明的政策自1940年代的铁肺委员会以来反复讲的那一课：“框架先行、而不是事后补、以及记录中对这位教师的致谢——感激不是一种货币、而把这句话说出口、正是它让特别义务的例外不变成一个阶级制度。**

::: history
**医学伦理比医学的文字记载更古老希波克拉底文集的誓言、以及它那套“行善、勿伤害、加上忠诚”的职责结构、而又比它的现代形态所应得的更年轻：十八世纪的爱丁堡与莱顿的讲座作为一门被命名的科目的“医学伦理”、格里高利与情感学派、格里高利与安德伍德的论著、以及十九世纪把职责变成教学大纲的“医学伦理教席”。二十世纪逼出了现代的机器：纽伦堡法典1947年与纳粹审判之后的赫尔辛基宣言的谱系研究伦理各章的基础、民权时代患者自主的案例1957年萨尔戈与卡茨创造了“同意”一词、施伦多夫的“自我决定”表述影响深远、把审查委员会制度化并催生贝尔蒙特报告原则清单的塔斯基吉与威洛布鲁克及海拉丑闻也是这套框架第一版问世的1979年、死亡权利法理的第一波昆兰与克鲁赞及布兰德附近的呼吸机与营养及体液的案例、把权威从医学移到法庭再移到患者、以及英国把权利纳入国内法时代的精神卫生与行为能力法的架构套“最佳利益与能力的推定”的成文伦理、被广泛输出。原则主义的十年1979至2000年代与它的批评者并行推进：乔治城大学的中心及其共识机器和教科书的多版、肯尼迪研究所的百科全书式的转向、生命伦理委员会的时代沃诺克与英国广播公司附近的公共生命伦理学、把这个领域变成了报纸的内容、“美国与患者的相遇”一派的反抗文献、以及批评者的账目——从吉利根谱系出发关怀伦理的女性主义挑战、医学人文学的叙事转向、以及后殖民与全球健康正义的指控：原则主义把一个西方的二人关系普遍化、而世界的伦理是集体的、且被资源所围困、以及把伦理委员会当作仪式的社会学研究。世纪末留下来的东西：一个制度化的领域临床伦理的咨询服务、认证的要求、以及法律对这套框架词汇的吸纳、一场关于其基础的永久争论、以及大流行那残酷的演示分诊的方案、在停车场里的姑息治疗、疫苗的分配：当哲学沉默时、原则主义所命名的剩余问题由过程来决定——这既是这套框架的证明、也是它的起诉——[[medical-ethics-law/research-ethics]]、[[medical-ethics-law/justice-resources]]。**

::: summary
- 四原则是一份“理由的清单”、不是一个算法：它们指出什么算数患者的作者身份、医学的利益、伤害的优先、分配的诉求、而把权重留给经过论证的判断——这就是为什么同样的原则既能支撑好的病房决定、也能支撑坏的专栏文章。
- 竞争的理论是器具：案例推理用于案例的形态、叙事用于身份与承认、关怀伦理用于依赖之网、德性伦理用于行动者的养成、契约论用于强制的正当化、而尊严的语言用于原则主义低估的不可侵犯性的直觉。
- 同意是一个要素在法律上已确定、而深度在实践中未确定的过程；拒绝是它的证明、而有能力的拒绝即使违背医学的统计也有约束力——能力的评估是怀疑一次拒绝的唯一执照、而它必须靠训练与记录挣得。
- 不确定是默认状态：比例性、流程、伦理会诊与残余管理的文献之所以存在、是因为正确的答案常常留下一个错误、而团队需要把道德困厄当作一个变量来记账。
- 分配的决定需要在紧急状况之前写好的框架公平的局数、决胜的规则、被始终如一地适用的特别义务例外、因为病床边的临场发挥正是让伦理话语变成摧毁信任的机会主义的方式。
- 终点不是“困境被解决”、而是决定变得可见、共享、有记录、可共存——对患者、对家庭、对必须接下一例的那个团队。
:::

::: exercise 选择你的理论 {level=2}
一名72岁的严重衰弱、无亲无故的患者、在跌倒后以“社会原因”入院、累积了七位专科与每日十一项操作；她告诉那位学生她希望他们“别再折腾了”。用本章提到的三种理论各一件工具设计伦理的回应、并说明哪一种承担最重的部分。
::: solution
**三件工具一间病房（[[#def-rivals]]、[[geriatrics-palliative/ageing-frailty]]、[[clinical-skills/communication]]）：案例推理：找到范例老年与姑息文献奉为经典的那个“在她身上累积技术性的照护、而没有人问过她”的模板——平行的不是“徒劳”而是“没有目标的治疗负担”、这把每一条医嘱都重新定义为需要一个受益者、而类比完成第一个上午的工作围绕一个陈述的目标整合药物与抽血。叙事伦理：她的那句话就是这个案例的标题——结构化生命故事的工作怎样的一天是值得过的、哪些干预已经变成了“折腾”、哪些是“让这一天值得的粥”不是病床边的装饰；它是改变计划的证据基础。德性伦理及它的系统表亲：台十一项操作的机器靠每个人的善意运转、所以回应要指出它奖励的恶习专科的地盘覆盖、“怕漏了什么”的记录与会议必须制度化的德性“今天谁负责这个人”的协调、它的缺席才是真正纵容恶习的东西。最重的部分：关怀伦理、它不在上面的清单里、却藏在三者之中——这是一张依赖之网、而最细的那一端她本人握着最少的权力、道德的对象是这张网的组织：具名的协调者、替代家人的倡导、以及在凌晨四点那位实习生能看见的地方写下目标。结局的指标：更少的医嘱、一个她认得出的决策者、以及她那句话从“别再折腾了”变成关于星期二的什么。**
:::

::: exercise 撰写那份政策 {level=2}

::: exercise 为这个框架辩护 {level=3}
一位哲学系的同事主张原则主义是“带引文的应用常识”、而伦理属于道德哲学、不属于清单。给出这一批评的最强版本、然后就该框架实际的目标为它辩护、最后给出你会教的那个综合。
::: solution
**原则主义的审判（[[#def-principles]]、[[#def-rivals]]）：最强的批评：四条原则是不决定的任何判决都可以被论证——“具体化与权衡”动作没有被形式化、所以这套框架的应用就是临床医师先验直觉穿了白大褂；它们是被借来的理论而没有借来基础康德与密尔的机器、而这张清单把它们的分歧压平——“原则是现象学而不是理论”的指控；它们的道德分析单位是“二人的决定”、掩盖了制造多数临床错误的结构人力、市场、不公；而它们的制度化同意表单、伦理会诊模板把道德的推理变成风险管理的礼仪——“伦理洗涤”的指控并有记录在案的案例。就其实际目标的辩护：原则主义被设计为多元社会与多学科团队的工作共识“凌晨两点、由一群对神的看法不同的人决定、由谁决定”这个问题、作为一种让决定可被质疑的审计语言你可以与一条被命名的原则争论、但你无法与感觉争论、以及作为一个地板、而不是天花板——框架作者自己的“应用的四条具体化”规划明确把它从属于论证、而经验的文献显示结构化的理由会改变决定、不只是装饰它们。所教的综合：原则作为理由的分类学、理论作为理由的生成器、过程作为分歧的消解者、而德性作为动机的守护者——一个运转中临床伦理的四层知道什么算数、知道它为何算数、知道当算数的东西冲突时如何裁决、并且做一个在没有人考核你时仍然去做的那种人——以及那位哲学同事挤出来的那句诚实的承认：没有第二层、第一层只是一块写字夹板、而那才是应当作为反面教材的失败模式、不是框架本身。**

::: example 处方里的安慰剂 {#ex-placebo}
一位焦虑的女儿请求全科医师“给她父亲开点药”、针对他不承认的早期痴呆；他因自己记性的失误而痛苦。医师考虑用一个不标注的安慰剂。用本章的工具来评判。
::: solution
**在善意与欺骗之间的安慰剂（[[#def-principles]]、[[#def-rivals]]、[[clinical-skills/communication]]）：各原则的对齐：行善在这里真正的对象是那份痛苦、而它有诚实的治疗记忆门诊的路径、结构化的告知谈话、以及那份痛苦通常会搬去的地方——照护者的支持；自主的主张正是不标注这条路所消耗的患者在服一片“记忆药片”时解读自己症状的能力、家庭为未来的不标注干预开的先例——“欺骗的债务”这个论证、而开放标签的安慰剂文献“带诚实标签的安慰剂也有效”的试验规划、以及仪式与意义的机制提供了同时保全两者的替代：一种不含活性成分、透明地对症的治疗、并被定框为帮助那份痛苦、而不是那个疾病。关怀伦理的读法重新定义了那个请求：女儿是在请求从无助的目睹中被解脱与她进行的那场信息与支持的谈话才是效果最大的干预、而叙事的读法记下这位父亲的否认在保护什么记忆门诊必须被告知如何处理的那个“受到失去威胁的身份”。多数临床医师永远触及不到的政策一层：关于欺骗的职业行为准则、隐蔽给药的同意含义、以及那个使安慰剂“在研究中成为禁忌、在公开执业中被禁止、却在私下被实践”的研究伦理双重标准——它的诚实是一个关于“谁得到真相”的正义问题：能言善辩者得到解释、被否认者得到糖。判决：公开地治疗那份痛苦、直接地面对女儿的负担、并记录为什么这条捷径被拒绝、因为下一位临床医师会被同一种善意诱惑。**

::: example 那位学生的一句话 {#ex-student}
一名医学生告诉你她在一次心肺复苏中“僵住了”、而顾问医师在家人面前斥责了她；她在考虑退学；而那位顾问坚持那次的反馈是“需要的、也是诚实的”。
::: solution
**德性、正义与团队（[[#def-rivals]]、[[clinical-skills/patient-safety]]、[[medical-ethics-law/professionalism-regulation]]）：分层的读法：德性伦理指出那个失败模式当众的斥责是那一刻的恶习——“蓝色紧急代码的压力被转移的攻击”、人因学文献在团队表现下对它做了编目、而在不公正对待的研究中它有一个名字、并与错误及流失有着结局的联系、关怀伦理重设场景这名学生嵌在一张依赖之网里——患者家人的恐惧是否被那次吼叫处理了、团队的心理安全——它的测量能预测发声与错误的捕获、而正义提供程序的要求反馈要被送达、记录、并可申诉——“当众羞辱对私下纠正”这个区分在职业监管准则中是行为规则级别的、以及学生走一条不依赖斥责者慷慨路径的权利。回应的组合，按次序：与层级之外的人为学生做一次简述不公正对待报告系统使用率低的问题是信任、所以第一个回应要示范它、与那位顾问的谈话被定框为教育、并逐字引用准则的相关条款而不是暗示（“照字面引用行为标准”这个技巧让反馈保持非人格）、考虑向家人当面道歉患者体验与坦诚的角度：那次斥责也伤害了他们、以及事件所暴露的课程修正模拟的压力接种与分级责任——“僵住”是一个训练的缺口、不是对品格的判决。关于退学这个问题：尽早命名它、因为流失的文献显示“离开的决定”是在数周未被处理的羞耻中做出的、而系统因失去她付出的代价是这个专科的——最后把德性伦理的观点一般化：文化是“谁留下来”的总和、而谁会留下正是在这样的时刻被决定的。**

::: exercise 翻译这场冲突 {level=1}

::: exercise 处理研究中的强制 {level=2}

::: exercise 为两边辩护 {level=2}

::: solution
**筛查与儿童的开放未来（[[#def-principles]]、[[public-health/screening]]、[[medical-ethics-law/justice-resources]]）：支持“普遍”的那一段：新生儿无法同意、而国家对其未来自主的利益正是默认纳入的正当理由；这个组合的收益延迟会以大脑为代价的代谢病、以及当退出与贫困相关时获得的公平增益恰恰落在父母的自主被援引的同一些孩子身上；默认不是强制——被保留的、不急迫且免费的退出路径让选择留在它属于的地方、而架构做它的工作、这就是行为文献允许的自由至上主义的家父主义。重构：“普遍并允许退出”在实践中塌缩为强制“你要怎样拒绝那管已经在抽的血”这个反对、而这个组合的新成员才是问题：发病不确定的疾病把新生儿筛查从一个“治疗的启动器”变成一个风险分类的服务、其结果超出了最初的正当性儿童期发病伦理学所做的“知晓的责任对知晓之后随之而来的责任”这一论证、人群收益依赖于被削弱的卫生系统并不具备的随访基础设施使这个规划在人群层面成为一个知情同意的虚构、而儿童的开放未来被收窄、不是靠治疗、而是靠一个被归档在某个概率之下的童年。病房需要的那个综合：筛查组合的伦理是关于“结果出来之后会发生什么”的伦理、而规划是一次一种可治疗的疾病、在公众面前、并在抽血之前先把随访资金到位，才挣得它们的默认。**

**卒中病房上的四个问题（[[#def-applications]]、[[clinical-skills/history-taking]]）：例子：一名84岁的大面积卒中患者、三个月前有一段有人目击的谈话“不要胃管”、以及一位从国外赶来的、希望“尽全力”的女儿。四问的推演：患者想要什么段有人证言既往价值的证据、对那份非正式预嘱的评估、向女儿解释“替代判断”的标准是“他会说什么、而不是什么对他有帮助、医学能提供什么这种卒中模式下胃管的数据——这个干预实现他所反对之物的诚实概率、什么不可以做插管的伤害、对“场斗争”的伤害、比例性的定框、由谁决定这棵决策树：患者的作者身份缺席、接着是记录下来的意愿、接着是替代的判断、接着是最佳利益、而团队的分歧由伦理审查——而不是由层级——解决。被禁止的问题：“我们怎么做？”那个让护士请医生去承担家属冲突的决定权外包的反射、先于“她在问什么、为什么？”；以及“家人明白了吗？”那个把责任推给理解的反射、先于“我们的解释是否以一种他们能够回答的方式？”——这两个问题的次序、决定了这次相遇是变成一个伦理案例还是一个共同的决定、这就是教学的全部内容。**
