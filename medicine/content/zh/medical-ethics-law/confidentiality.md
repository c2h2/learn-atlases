一名48岁的公交车司机首次出现强直-阵挛发作。经检查后诊断为癫痫。他的神经科医师告诉他必须停止驾驶，并通知驾驶员与车辆许可局（Driver and Vehicle Licensing Agency，DVLA）。三周后，这位神经科医师看到他驾驶着公交车来到门诊。他说自己丢不起这份工作，请求医师替他保守这个秘密。

患者会把从不告诉别人的事情告诉医师，并允许医师检查他们的身体、查阅他们的记录。他们这样做，是因为相信这些信息会被保密。这种信任是保密的理由，也正因如此，打破保密需要充分的正当理由。本章阐述英格兰和威尔士的保密义务、可以或必须共享信息的情形、如何作出披露决定，以及数据保护法如何规范健康记录的使用，包括用于研究和规划。

## 保密为何重要 {#why}

支持医疗保密的论证主要有三条。

- **后果。** 如果患者担心自己说的话会被传出去，许多人就会隐瞒信息，甚至完全回避就医。这会伤害他们自己；在传染病或对他人有风险的情况下，也会伤害公众。患有性传播感染、精神疾病或使用药物的人尤其可能远离他们不信任的服务。
- **自主与隐私。** 关于一个人身体和健康的信息，在重要的意义上属于这个人。尊重自主包括让人们控制谁能知道关于他们的事。
- **承诺与信任。** 自希波克拉底誓言以来，医师就公开承诺保守秘密。患者在开口时依赖的正是这一隐含的承诺。

这些论证既解释了这项义务的分量，也解释了它的限度。由于主要的正当理由在于后果，存在一些保守秘密本身就会造成严重伤害的情形，此时同样的推理可以为披露提供正当理由。

::: definition 保密义务 {#def-duty}
医师对患者负有**保密义务**：以职业身份获知的个人信息，没有合法的正当理由不得披露。在英格兰和威尔士，这项义务有多个来源：

- **普通法**上的保密：在可以合理期待其被保密的情境下提供的信息受到保护；
- 《欧洲人权公约》（European Convention on Human Rights）**第8条**（尊重私人和家庭生活），通过《1998年人权法》（Human Rights Act 1998）在国内生效；
- **数据保护法**：《英国通用数据保护条例》（UK GDPR）和《2018年数据保护法》（Data Protection Act 2018）；
- **职业监管**：英国医学总会（GMC）的指南《保密：处理患者信息的良好实践》（*Confidentiality: good practice in handling patient information*，2017）和《良好医疗实践》（*Good medical practice*，2024）；
- 雇佣合同和英国国家医疗服务体系（NHS）的政策。

这项义务涵盖关于患者的一切可识别信息，包括其是患者这一事实本身，并在患者死亡后继续存在。
:::

## 何时可以披露信息 {#lawful-disclosure}

GMC的指南把可以披露保密信息的情形归纳为少数几类。

::: theorem 披露的合法依据 {#thm-disclosure}
可识别的患者信息在且仅在以下情形下可以披露：

1. 患者**同意**：在为其提供直接诊疗的团队内部共享时，同意可以是**默示**的；用于其他目的时须为**明示**同意；
2. 披露是**法律要求**的，例如依据成文法或法院命令；
3. 披露基于**公共利益**而具有正当性，因为对某个人或社会的益处，超过了患者的利益以及保守秘密本身所承载的公共利益；
4. 对于缺乏决策能力的患者，披露符合其**最佳利益**，或为法律另行允许。

在任何情况下，都只向合适的人、为明确的目的披露**最低必要**的信息；凡匿名化信息足以达到目的时，都应使用匿名化信息。
:::

::: proof
这一结构源自保密的理由。患者同意时，其自主得到尊重，信任没有被辜负，因此并未违反义务。法律要求披露时，议会或法院已就这一类案件权衡了私人利益与公共利益；医师的职责是遵从，同时不披露超出要求的内容。两者都不适用时，披露必须逐案论证，其检验标准正是最初奠定这项义务的同一后果推理：披露所能防止的伤害，是否严重到足以超过对这位患者的伤害，以及对医疗保密信任的更广泛伤害？

最低必要原则也由此而来。为某一目的而具有正当性的披露，并不意味着可以共享一切。一位就患者的癫痫发作通知DVLA的医师，没有理由提及他的饮酒史，除非这与驾驶适合性有关。
:::

### 为直接诊疗而共享 {#direct-care}

大多数信息共享都是常规且必要的：全科医师写转诊信、病房团队讨论患者、药师核对处方。患者一般预期会有这样的共享；只要已告知他们信息如何共享（例如通过宣传单和告示），且他们没有反对，其同意即为**默示**同意。有决策能力的患者可以反对共享某些特定信息，这种反对应当得到尊重，但临床医师应说明这是否可能影响其诊疗。

不向需要信息来治疗患者的人提供信息，本身就可能造成伤害。规范英格兰卫生和社会照护中患者信息使用的卡尔迪科特原则（Caldicott principles）明确包含了这一点。

::: definition 卡尔迪科特原则（2020） {#def-caldicott}
1. 说明使用保密信息的目的。
2. 仅在必要时使用保密信息。
3. 使用最低必要的保密信息。
4. 对保密信息的访问应严格遵循"有必要知道"的原则。
5. 每一个能接触保密信息的人都应了解自己的责任。
6. 遵守法律。
7. 为个人诊疗共享信息的义务与保护患者隐私的义务同等重要。
8. 告知患者和服务使用者其保密信息是如何被使用的。
:::

每个NHS机构都有一名**卡尔迪科特监护人**（Caldicott Guardian），这是一位负责保护保密性并就披露决定提供建议的高级人员。卫生和社会照护**国家数据监护人**（National Data Guardian）自2018年起成为法定职位，为整个英格兰提供建议。

## 法律要求的披露 {#legal-requirement}

有些披露是法律所要求的。医师应当披露所要求的内容，不多披露，并通常应告知患者。

- **法定报告传染病。** 依据《2010年健康保护（报告）条例》（Health Protection (Notification) Regulations 2010），英格兰的注册医师必须向当地卫生防护团队（英国卫生安全局，UK Health Security Agency）报告特定传染病的疑似病例，例如脑膜炎球菌病、麻疹和结核病（[[public-health/communicable-disease-control]]）。威尔士有相应的条例。HIV不属于这些条例规定的法定报告疾病。
- **女性生殖器切割（FGM）。** 自2015年起，英格兰和威尔士受监管的卫生和社会照护专业人员以及教师，必须向警方报告18岁以下女孩中"已知"的FGM病例：即女孩本人告知，或观察到似乎显示FGM的体征。
- **法院命令。** 法官可以命令披露记录，或要求医师出庭作证。医师可以就披露无关信息向法院提出异议，但必须遵守最终命令。警方或律师在没有法院命令时提出的要求，不属于法律要求。
- **道路交通。** 依据《1988年道路交通法》（Road Traffic Act 1988）第172条，任何人（包括医师）在被要求时，都必须向警方提供可能识别涉嫌犯有某些罪行的驾驶员的信息。这仅限于身份识别信息，不包括临床细节。
- **恐怖主义。** 依据《2000年恐怖主义法》（Terrorism Act 2000），不披露可能有助于阻止恐怖行为或抓获恐怖分子的信息，属于犯罪。
- **其他法定义务**包括报告出生和死亡、向验尸官报告某些死亡、向首席医疗官报告人工流产，以及答复监管机构依法提出的要求。

## 基于公共利益的披露 {#public-interest}

最困难的决定出现在：没有法律要求披露，患者拒绝同意，而医师认为他人处于风险之中。在不披露可能使他人面临**死亡或严重伤害**的风险，且披露的益处超过其害处时，普通法和GMC允许基于**公共利益**进行披露。

英格兰的主导判例是 *W v Egdell*（埃格德尔案，1990）。W在杀害五人后被收治于一所安全医院。他向审裁庭申请转院，其律师委托一位独立精神科医师埃格德尔医生撰写报告。报告揭示了W长期对枪支和爆炸物抱有兴趣，而医院对此并不知情，并得出结论认为W仍具危险性。W的律师撤回了申请，没有提交这份报告。埃格德尔医生将报告副本寄给了医院和内政部。上诉法院认定披露是正当的：公众面临真实的危险，负责W的当局需要这些信息来就其释放作出决定。

在美国，加利福尼亚州最高法院在 *Tarasoff v Regents of the University of California*（塔拉索夫案，1976）中认定，一位治疗师的患者曾威胁要杀害一名可识别的女性，治疗师负有采取合理措施保护她的义务。英格兰法律没有确立警告第三方的一般法律**义务**；它赋予医师基于公共利益进行披露的**权力**，并由职业指南说明何时行使这一权力。

::: definition 作出基于公共利益的披露 {#def-public-interest}
在未经同意而基于公共利益进行披露之前，医师应考虑：

1. **能否获得同意？** 应当征求同意，除非这样做不安全、不可行，或会妨碍披露的目的（例如惊动正受警方调查的人）。
2. **伤害有多严重、多可能？** 通常只有在他人面临死亡或严重伤害的风险，或为预防或侦破严重犯罪时，披露才具有正当性。
3. **披露是否必要且相称？** 披露能否真正降低风险？有没有侵扰性更小的方式？
4. **向谁披露、披露什么？** 只向合适的人披露，只披露最低必要的信息。
5. **告知患者**已经披露，除非这会使某人处于风险之中。
6. **记录**理由；在时间允许时，向高年资同事、卡尔迪科特监护人或医疗执业保障机构寻求建议。
:::

一些常见情形有GMC的专门指南：

- **驾驶适合性。** 患者在法律上有责任将可能影响安全驾驶的疾病告知DVLA。如果患者在不适合驾驶时继续驾驶且无法被劝阻，医师应通知DVLA的医学顾问，并在事前和事后告知患者。
- **枪伤和刀伤。** 当有人带着枪伤或被刀具或其他利器袭击所致的伤口前来就诊时，通常应告知警方，最初不提供身份识别信息。此后，只有在获得同意或满足公共利益标准时，才披露身份识别信息。
- **严重传染病。** 如果一位患有严重性传播感染的患者拒绝告知面临风险的性伴侣，医师在尝试劝说患者自行告知之后，可以向该伴侣披露，并尽可能不说出患者的名字。通过性健康服务进行性伴侣通知是通常的途径。
- **遗传信息。** 患者的基因检测结果可能显示其亲属面临风险。

遗传学的情形很特殊，因为这些信息同样关乎亲属。在 *ABC v St George's Healthcare NHS Trust* [2020] EWHC 455 (QB)（ABC诉圣乔治医院案）中，一名杀害了妻子的男子在被羁押期间被发现患有亨廷顿病。他拒绝让女儿知道此事。女儿当时正在怀孕，后来发现自己遗传了这种疾病。高等法院认定，临床医师对她负有一项法律义务：**权衡**她获知信息的利益与他的保密利益，并按照权衡的结果行事；就本案事实而言，这项义务并未被违反。该判决明确限于临床医师知道该亲属及其风险的亲密关系。

::: example 患癫痫的公交车司机 {#ex-dvla}
回到本章开头的公交车司机。他在被诊断为癫痫后仍在驾驶公交车，并请求神经科医师替他保密。她应当怎么做？
::: solution
**第1步：理解与劝说。** 神经科医师再次清楚而富有同情地解释：他的病情意味着他在法律上不适合驾驶，尤其是公交车，DVLA对公交车的标准远比小汽车严格；而且他在法律上有义务告知DVLA。她探究他对失业的担忧，并为他指明可获得的帮助：雇主可能有替代岗位，也可以获得关于就业权利的咨询。她记录这次谈话。

**第2步：评估风险。** 驾驶公交车时发作可能导致他本人、乘客和其他道路使用者死亡。这是对他人死亡或严重伤害的明确风险。

**第3步：作出决定。** 如果他不肯停止驾驶，或她得知他仍在继续驾驶，GMC的指南规定她应以保密方式将相关医疗信息披露给DVLA的医学顾问。她应事先告诉他自己打算这样做，并在事后写信向他确认。

**第4步：最低必要。** 她向DVLA而不是向他的雇主披露诊断和相关临床事实。是否告知雇主是另一个问题；如果存在DVLA途径无法应对的紧迫风险，告知雇主可能是正当的，但她应首先寻求建议。

**第5步：维持关系。** 她继续为他诊治，并明确表示披露是出于安全考虑，而不是惩罚。
:::
:::

::: example 凌晨2点的刀刺伤 {#ex-knife}
一名19岁男子因大腿刀刺伤前来就诊。他说自己在一家夜总会外遭到袭击，拒绝提供细节，并要求工作人员不要报警。急诊团队应当怎么做？
::: solution
首先处理伤口。按照GMC的指南，团队应告知警方有一名遭袭击致刀伤的人前来就诊，此时不提供他的姓名，以便警方评估对公众的风险（持械的袭击者可能仍然在逃）。是否披露他的身份是另一项决定：这需要他的同意，或基于公共利益的正当理由，例如对他人的严重风险。团队应告诉他报告了什么及其原因，记录这一决定，并考虑保护需求，因为被刀刺伤的年轻人往往持续面临风险。
:::
:::

基于公共利益的决定往往取决于预测一个人会做什么，而预测是不确定的。特别是，当所要预防的结局很罕见时，即使是相当准确的风险评估，也会标记出许多根本不会造成伤害的人。这并不意味着应当忽视风险，而是意味着披露决定应基于具体、严重且有充分证据的担忧，而不是基于某个类别或评分；临床医师也应了解一条规则会产生多少误报。

::: example 父亲的基因检测结果 {#ex-genetic}
一名52岁男子被诊断为由错配修复基因致病性变异引起的遗传性结直肠癌（林奇综合征）。他的两个成年女儿各有50%的可能携带该变异；如果携带，定期结肠镜检查和其他措施可以大大降低她们死于癌症的风险。他拒绝让她们知道，因为他已多年没有和她们说话。遗传学团队应当怎么做？
::: solution
**探究与支持。** 大多数起初拒绝的患者，在给予时间和支持后最终会同意。团队应了解他拒绝的原因，解释这些信息对女儿们可能有多大帮助，并提供不需要他本人和女儿交谈的告知方式，例如由遗传学服务机构发信。

**权衡利益。** 女儿们面临的风险是严重的（终生患癌风险高），知情的益处很大（有效的监测和预防）。披露对他造成的伤害是真实的，但较为有限，尤其是在不透露其详细信息的情况下。依据 *ABC* 案，当临床医师知道某位具体亲属面临严重风险时，他们有义务权衡这些利益。

**如有正当理由，最低限度地披露。** 如果他仍然拒绝且权衡结果支持披露，团队可以联系女儿们，告诉她们家族中有一种疾病可能影响她们，并可提供遗传咨询，而不透露他的诊断或超出必要范围的细节。应将这一决定告知他。英国皇家内科医师学会、英国皇家病理学家学会和英国遗传医学学会的专业指南支持这种做法。

**记录并寻求建议**，向高年资同事和卡尔迪科特监护人咨询。
:::
:::

## 儿童、保护与处于风险中的成人 {#safeguarding}

年轻人与成人一样享有保密权利；除非存在合法依据，否则未经有能力的年轻人同意，不应将其信息告诉其父母。担心医师会告诉父母，是年轻人回避性健康和心理健康服务的主要原因之一。

例外是**保护**（safeguarding）。当儿童或年轻人面临重大伤害的风险，例如虐待、性剥削或忽视时，即使未经同意，也应将信息与相应机构（通常是儿童社会服务，有时是警方）共享。法定指南《共同努力保护儿童》（*Working Together to Safeguard Children*，2023）明确指出，数据保护法并不妨碍共享为保障儿童安全所需的信息。应告诉儿童将共享什么以及原因，除非这会增加风险（[[paediatrics/safeguarding]]）。

对**成人**而言，情况有所不同。有决策能力的家庭暴力受害者通常自行决定是否让警方或社会服务介入。如果他人（尤其是儿童）面临风险、涉及严重犯罪、该成人正受到胁迫，或其缺乏作出该决定的能力，未经同意的披露可能是正当的。当有照护和支持需求的成人面临虐待或忽视的风险时，地方当局有义务进行调查（《2014年照护法》（Care Act 2014）第42条）。

::: example 一个保护方面的两难 {#ex-safeguarding}
一名26岁女性因腕部骨折来到急诊科。她怀孕20周，家中有一个3岁的儿子。她说是摔倒所致，但损伤的形态以及她手臂上新旧不一的瘀伤提示遭受了殴打。在与医师单独相处时，她承认是伴侣打了她，但恳求医师不要告诉任何人，因为"那只会让情况更糟"。
::: solution
**首先是尊重与安全。** 医师感谢她说出实情，处理她的损伤，准确记录损伤和她的陈述，并询问她眼下的安全：今晚回家是否安全？家里有没有武器？暴力是否在升级？她是否被掐过脖子？这些问题可以识别高风险情况。

**决策能力与同意。** 她看起来具有决策能力。就她自身的安全而言，她的意愿分量很重，医师应提供支持而不是推翻她的意愿：转介给独立家庭暴力援助顾问（IDVA）、提供求助热线号码，并制订安全计划。

**他人面临的风险。** 她的儿子住在家中，而且她正在怀孕。有儿童的家庭中存在家庭暴力，是对该儿童的保护问题。医师应与她以及医院保护团队讨论此事，很可能需要转介至儿童社会服务；最好在她知情并同意的情况下进行，但必要时也可以在未经同意时进行。

**高风险。** 如果结构化风险评估提示高风险，可以转介至多机构风险评估会议（MARAC）；在风险足以为之提供正当理由时，这可以在未经同意的情况下进行。

**解释。** 应如实告诉她将共享什么、与谁共享以及原因，并说明目的是支持她、保护她的孩子，而不是惩罚她。
:::
:::

## 记录、沟通与数据 {#records}

违反保密更多是由于疏忽，而不是故意披露：在电梯里的交谈、遗落在咖啡馆的交班清单、发给错误患者的信息、出于好奇查看名人的病历。即使没有向外传递任何内容，无正当理由访问病历本身就是违规，NHS的系统会审计谁查看了什么。在社交媒体上发布描述可识别患者的内容，或发布能让人识别出患者的细节，都属于违规，也是向GMC投诉的常见原因。

依据数据保护法，患者有权查看自己的记录（**数据主体访问请求**），例外情形有限，例如可能对患者或他人造成严重伤害的信息，或关于第三方的信息。患者死亡后，保密义务继续存在；《1990年健康记录访问法》（Access to Health Records Act 1990）赋予死者的遗产代理人以及因该死亡而有索赔的任何人查阅相关记录的权利。可以告诉家属有助于他们理解这一死亡的信息，除非患者曾要求不让他们知道。

::: definition 数据保护与二次使用 {#def-data}
依据UK GDPR，健康数据属于**特殊类别数据**。处理这类数据需要第6条规定的合法依据，以及第9条规定的条件，例如提供卫生保健或公共卫生。法律要求处理须合法、公平且透明，限于其目的，数据最小化，准确，安全，且保存时间不超过必要的期限。

健康数据在直接诊疗之外的用途，例如研究、审计、服务规划和服务采购，属于**二次使用**。在英格兰，这些用途通常需要满足以下之一：

- 患者的**同意**；
- **匿名化**数据，即无法合理地从中识别出个人；
- 依据《2006年国家医疗服务体系法》（NHS Act 2006）**第251条**和《2002年卫生服务（患者信息控制）条例》（Health Service (Control of Patient Information) Regulations 2002）获得批准；在无法获得同意且匿名化数据不能满足需要时，这些规定允许根据保密咨询小组（Confidentiality Advisory Group）的建议，为特定目的搁置普通法上的义务。

英格兰的患者可以登记**国家数据退出选项**（national data opt-out），以阻止其保密信息被用于研究和规划，但有一些例外。
:::

::: warning "匿名化"的数据未必是匿名的
删除姓名和NHS号码并不能使数据匿名。一条包含罕见诊断、完整出生日期、邮政编码和入院日期的记录，可能让任何认识这个人的人识别出他。表格中的小数字（"本诊所有1例X病"）也可能如此。用代码替换了标识符的数据属于**假名化**数据，在法律上仍然是个人数据。在向诊疗团队以外共享任何数据之前，要问一问：有没有人能推断出这是关于谁的？并遵循最低必要原则。
:::

::: quiz
一名警官来到病房，询问一名初级医师某位指名的患者昨晚是否入院，以及他受了什么伤。没有法院命令。警官说此人是一起入室盗窃案的嫌疑人。最恰当的回应是什么？
- [ ] 提供这些信息，因为警方在法律上有权获得。
- [ ] 无论如何都拒绝与警方交谈。
- [x] 解释没有患者的同意或合法依据，不能披露这些信息；询问患者是否同意；如果他拒绝，就是否满足公共利益标准寻求高年资医师的建议，而对于非暴力犯罪，这一标准不太可能满足。
- [ ] 确认他是患者，但不描述他的伤情。
::: solution
没有法院命令或具体的法定权力，警方对保密的医疗信息并没有一般性的权利。即使只是确认某人是患者，也属于披露。医师应询问患者是否同意。如果他不同意，披露就需要以公共利益为正当理由，而这通常保留给预防或侦破严重犯罪，例如涉及死亡或严重伤害的犯罪。单纯的入室盗窃通常达不到这一门槛。医师应请高年资同事和卡尔迪科特监护人参与，记录这一要求和所作的决定，并对警官保持礼貌。
:::
:::

::: history
希波克拉底誓言包含一项承诺：对行医过程中所见所闻严守秘密。然而在英格兰法律中，医疗保密从来不是一项绝对的特权。在1776年金斯顿公爵夫人（Duchess of Kingston）重婚案的审判中，外科医师凯撒·霍金斯（Caesar Hawkins）被要求就他作为她的医疗看护人所获知的情况出庭作证；与律师不同，医师在法庭上没有法律特权。

20世纪，法院发展出一套带有公共利益例外的一般保密法（*W v Egdell*，1990）。计算机化记录的增长促成了卡尔迪科特报告（Caldicott Report，1997）；该报告是在人们对NHS中患者数据流动的担忧之后委托撰写的。菲奥娜·卡尔迪科特女爵士（Dame Fiona Caldicott）提出的六项原则在2013年增至七项，在2020年增至八项。随后有了《1998年数据保护法》、GDPR（2018）和法定的国家数据监护人（2018）。关于全国性数据项目的争论，例如因公众担忧而于2016年放弃的care.data项目，表明公众对数据使用的信任取决于透明度和真正可行的退出选择。
:::

## 后续内容

研究中的保密以及研究中的数据使用，在[[medical-ethics-law/research-ethics]]中讨论。儿童保护程序见[[paediatrics/safeguarding]]，传染病报告见[[public-health/communicable-disease-control]]，家族中的遗传信息见[[genetics/genetic-testing]]。病历记录实践在[[clinical-skills/records-handover]]中介绍。

::: summary
- 保密保护信任、隐私以及患者寻求诊疗的意愿。这项义务来源于普通法、第8条、数据保护法和GMC指南，并在患者死亡后继续存在。
- 在以下情形可以披露信息：**同意**（直接诊疗为默示同意）、**法律要求**、**公共利益**，或符合缺乏决策能力患者的**最佳利益**。始终只披露**最低必要**的信息。
- 法律要求包括法定报告传染病、18岁以下女孩的FGM、法院命令、依《道路交通法》要求识别驾驶员，以及恐怖主义相关信息。没有法院命令的警方要求不属于法律要求。
- 基于公共利益的披露要求存在对他人死亡或严重伤害的风险或严重犯罪，向合适的人作相称的披露，并通常告知患者。*W v Egdell*（1990）是主导判例；*ABC v St George's*（2020）要求临床医师权衡已识别的、具有遗传风险的亲属的利益。
- 对儿童的保护担忧为未经同意的共享提供了正当理由；对于有决策能力的成人，通常需要同意，除非他人面临风险或涉及严重犯罪。
- 数据的二次使用需要同意、有效的匿名化或第251条批准；患者可以登记国家数据退出选项。假名化数据仍然是个人数据。
- 卡尔迪科特原则既包括保护的义务，也包括为个人诊疗而共享的义务。
:::

## 习题

::: exercise 依据是什么？ {level=1}
对于下列每一项披露，说明其合法依据：(a)全科医师将一名患者转诊给心脏科医师，并附上她的病史摘要；(b)一名医师向卫生防护团队报告疑似麻疹；(c)一名精神科医师告诉警方，一位患者描述了一个杀害某位指名邻居的可信计划；(d)一家医院依据法院命令向法院提供记录。
::: solution
(a)为直接诊疗的默示同意。(b)法律要求（《2010年健康保护（报告）条例》）。(c)公共利益：对一名可识别人员的死亡或严重伤害的风险。(d)法律要求：法院命令。
:::
:::

::: exercise 打电话的亲属 {level=1}
一名男子打电话到病房，询问他已成年的姐姐术后情况如何。护士无法核实他的身份，患者也没有说过可以告诉谁。护士应该怎么说？
::: solution
在不知道来电者身份或患者意愿的情况下，护士不应提供临床信息，甚至不应确认超出患者同意范围的细节。她可以记下他的电话号码，说会询问患者是否希望让他知道最新情况，或请患者给他回电话。许多科室会在患者入院时与其约定一个密码或指定联系人，以便于处理此类情况。
:::
:::

::: exercise 阳性预测值 {level=1 check="0.14"}
一项风险评估工具会标记被预测将实施严重暴力的人。在一个有2%的人会实施严重暴力的人群中，该工具的灵敏度为80%，特异度为90%。被标记的人中，实际会实施严重暴力的比例是多少？答案保留2位小数。
::: hint
使用自然频数：在1,000人中，真阳性和假阳性各有多少？
:::
::: solution
在1,000人中，有20人会实施暴力；该工具标记出其中$0.8 \times 20 = 16$人。在不会实施暴力的980人中，有$0.1 \times 980 = 98$人被错误标记。阳性预测值$= 16/(16 + 98) = 16/114 \approx 0.14$。被标记的人中约七分之六不会实施暴力。
:::
:::

::: exercise 误报 {level=2 check="98"}
采用同样的数据，在一个1,000人的门诊人群中，有多少人会被标记为高风险但实际上并不会实施严重暴力？
::: solution
在不会实施暴力的980人中，有$10\%$被错误标记：$0.1 \times 980 = 98$人。如果每一次标记都导致未经同意的披露，那么为了识别出16个真正的病例，就有98人的保密被不必要地打破，同时还会漏掉4个真正的病例。这有力地说明，披露决定应基于关于具体个人的具体证据。
:::
:::

::: exercise HIV与伴侣 {level=2}
一名被诊断为HIV感染的男子告诉他的全科医师，他没有告诉妻子，也不打算告诉她，而且他们不使用安全套。他的病毒载量尚未被抑制。概述全科医师应采取的做法。
::: solution
全科医师应解释他妻子面临的风险以及她知情的益处（检测、治疗、预防），并说明能抑制其病毒载量的治疗可以防止性传播。提供帮助他告知妻子的方式，包括通过性健康诊所进行性伴侣通知，诊所可以在不说出患者姓名的情况下联系伴侣。探究他的理由，例如害怕遭到暴力或被抛弃。如果他仍然拒绝，而一名可识别的人面临严重风险，GMC指南允许在告知他将这样做之后，向其伴侣披露，以便她能够保护自己。全科医师应寻求建议，只披露必要的内容，并记录推理过程。如果这位妻子也是该全科医师的患者，全科医师对她同样负有照护义务，这使确保她知情的理由更加充分。
:::
:::

::: exercise 研究数据 {level=2}
一名专科住院医师希望通过查阅病历，研究其所在医院五年内所有因糖尿病酮症酸中毒入院患者的结局，并发表结果。她需要哪些批准和保障措施？
::: solution
如果这项工作属于研究（而不是对照标准审计医院自身的诊疗），就需要卫生研究管理局（Health Research Authority）和研究伦理委员会的批准（[[medical-ethics-law/research-ethics]]）。未经同意查阅可识别的病历需要合法依据：要么由直接诊疗团队查阅病历，只为研究提取匿名化数据；要么她通过保密咨询小组获得第251条支持，因为联系数百名既往患者征求同意可能并不可行。在需要时必须执行国家数据退出选项。她必须只提取最低必要的数据，对其进行假名化，安全存储，并以无法识别任何个人的方式呈现结果，例如对小数字进行抑制处理。
:::
:::

::: exercise 一条社交媒体帖子 {level=3}
一名基础培训医师在一个仅限医师加入的封闭社交媒体群组中发帖："利兹急诊科的夜班太精彩了：一个19岁的人打赌吞了一节电池，现在没事了！"帖子中没有提及姓名。分析这是否违反保密以及存在哪些风险。
::: solution
这很可能构成违规。其中的细节（地点、大致时间、年龄、不寻常的损伤）可能让患者本人、其家人或朋友认出这个病例，而封闭群组既不安全也不私密：截图会被转发。患者并没有同意分享自己的经历。GMC指南规定，医师不得在社交媒体上分享关于患者的可识别信息，并应记住多个细节结合起来就可以识别出某人。把患者受到的伤害当作娱乐的语气，也有损公众信任的风险。这名医师应删除该帖子。如果这个病例有教学价值，可以在获得同意后，或经过适当匿名化（修改非关键细节）后，在合适的场合介绍。
:::
:::

::: exercise 义务的冲突 {level=3}
一名16岁的1型糖尿病患者告诉她的主治医师，她为了减肥一直在漏打胰岛素，并且有几次呕吐发作都是在家自行处理的。她要求他不要告诉她的父母。请讨论。
::: solution
16岁时她被推定具有决策能力，并享有保密权利。主治医师必须首先考虑她的安全：故意漏用胰岛素与反复发生的糖尿病酮症酸中毒相关，后者可能危及生命，也与进食障碍相关。她的呕吐发作可能就是酮症酸中毒。

他应探究发生了什么，以及她不希望告诉父母的理由；提供支持，包括转介至糖尿病心理服务，并评估是否存在进食障碍；共同制订安全计划，包括何时需要寻求急诊帮助；并鼓励她让父母参与进来，也许由他来协助。

如果她具有决策能力，且风险虽然真实但并不紧迫，他应在与她密切合作的同时尊重她的意愿。如果风险变得严重（反复发生酮症酸中毒、体重极低），或者她的进食障碍损害了她就治疗作出决定的能力，那么为了她的最佳利益或保护她的生命而向其父母披露可能是正当的，并且可能需要启动保护程序。他应告诉她将共享什么以及原因，并记录他的推理过程。
:::
:::
