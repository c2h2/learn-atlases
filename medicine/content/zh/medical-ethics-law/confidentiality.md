保密是一件没有人建造的临川工具：它让患者说出真相、而被“记录他们被告知的内容”的系统每天威胁着。**本章涵盖这一职责及其正当化的理由（信义、工具、与隐私权利这几条论证、以及希波克拉底那样古老的出处）、例外的架构（同意、为公共利益的披露、法定的义务、以及“最小必要”的原则）、数据时代的转变（电子记录、二次使用、应用、基因组学、以及数据的治理）、以及日常的困难：家人、雇主、警察、媒体、遗传的信息、与保护的责任。**

## 这一职责

::: definition 保密为何有约束力、它属于谁 {#def-duty}
**这一职责的三条腿各做不同的工作：信义的论证临床关系内部的规范——希波克拉底那句“我见到的、我不宣扬”的出处、以及那个“允许披露的实践会自我毁灭”的论证，因为下一位患者会隐瞒那个要紧的症状——这一工具性的正当化、其证据是现实中的隐瞒数据：性传播感染与精神健康及物质使用方面的“回避就医”的研究、它们恰恰在保密的例外最被需要的地方量化了保密的公共卫生价值；权利的论证隐私作为对个人信息的控制——从沃伦与布兰代斯到波尔申再到数据保护体制的这条谱系、以及那个自主的读法：披露会伤害尊严、无论它是否伤害效用；以及德性这条腿忠诚与职业身份的理论——总会式的誓词、与“信任作为医师的资产”的经济学。这一职责的边界与其核心同样是临床的：它属于患者幸存者、未成年人、与逝者的法律地位各不相同——职业准则的“职责在死亡之后仍然存续”对比各法域的证据规则、一片不好看的拼布、它覆盖一切形式的可识别信息“家人早就知道了”与“患者自己告诉了整条街”论证、法庭大多予以拒绝——起作用的理论是“控制、而不是隐蔽”、并且它延伸到房间里的每一个人接待员与清洁工与医学生与口译员的职责——职业准则把它们扩展开、而培训部门把它们忘了。接下来发展的例外架构才是这一职责真正形状显现之处：一条人人知道其例外、而没有人记得其程序的规则、这就是为什么实务临床医师的风险不是那次戏剧性的披露、而是那次未被记录、未被计划、不成比例的披露——场患者已经明确关闭了的、与家人的“我们总得告诉某人”的谈话、投诉文献所记录的那一类最严重的错误。**
:::

## 例外

::: definition 未经同意的披露：正当化的阶梯 {#def-exceptions}
**披露按其权威的来源分类。同意明示或默示——日常照护赖以运转的、由治疗情境默示的那张网：转诊信、共享的处方、多学科团队的讨论——其外部的边界，即“为你的照护所必需、对服务有用”这条线、被数据最小化的规则每次修订都收紧。法定的义务传染病与死亡及出生的报告体制、女性生殖器切割的报告命令那套“有争议的公共卫生证据与信任代价”的辩论、道路交通与枪械伤害的披露、以及决定临床判断能否存活的“应当报告对可以报告”词汇——保密研究关于“义务叠加”的担忧、是一个有实测的就医影响的立法的缺陷。法庭的强制传唤与令状层次、医学种类本就薄弱的特免权主张、以及临床医师的路径：通知、由患者提出异议、按原则出庭、只出示被命令的东西——这套流程多数临床医师从未运行过、而每一个人都应当读过一次。以及公共利益最宽也最受监管的：带有“预防伤害”的正当化与比例性检验——“对某个可识别的人或公众的严重的、可预防的伤害”、在可能时先取得同意、向对的机构做最小必要的披露、以及把推理记录下来以使这次披露可被复审——塔罗多夫一线的“警告的义务”的判例、连同其关于被预测的危险性的基础率与其种族分布后果的持续争论。“最小必要”的原则是贯穿所有类别的工作纪律“雇主需要的是一张适岗证明、不是诊断”、“警方需要的是谁在开车、不是他的HIV状态”、以及“信息治理要公布、不要临场发挥”这条规则、而它的同伴——在安全时事后告知患者——则修复了那个例外不得不刺破的关系。本章最难的判例位于“例外遇到人群”之处：HIV与传染病披露的案例职业准则“特殊情形”的路径、其“致接触者的信”的项目在与患者合作时效果更好——公共卫生伦理文献的“协助的通知”的设计、把一个披露的例外转化成一个同意的模型、以及保护职责、其强制报告的证据儿童保护研究记录的“低报对家庭破裂”的取舍、以及“青少年保密并带有例外”的架构让这场权衡保持诚实。**
:::

## 数据时代

::: definition 记录、二次使用与基因组学 {#def-data}
**电子记录把保密的物理学从“隐蔽”改成了“访问控制”：审计痕迹的革命每一次读取都被记录——这件工具既威慑、又发现、并在“窥探丑闻”时代的改革中成为面向患者的问责装置：那个“谁读了我的记录”的日志、如今被当作权利来讨论、并被当作功能来建造、拆散孤塔的张力互操作性的临床收益、对比它被扩大的再识别的面——关联数据文献中的“隐私与效用”的前沿、假名化对匿名化的标准、及其“k匿名与差分隐私”技术答案、而其临床意义是那种多数临床医师必须学会审问的治理委员会语言、以及内部人这一类的伤害名人与邻居与同事的查询的研究、“窥探即解雇”的政策与其审计不足的执行、以及当员工的职工健康记录遇上人事记录时“临床医师作为数据主体”的问题。二次使用是这个时代新的社会契约：从“逐项目同意”到“广泛同意”到“退出”到“带独立授权的公共利益”这条光谱英格兰的“第251条”与苏格兰的“国家数据退出”邻近的架构、研究豁免及其保障、以及参与之争中“数据的捐献者”对“数据的公民”的定框、塑造了它的信任危机那次数据规划的退场与其后继的治理教训：透明与“命名一个用途”胜过法律的充分性、以及“匿名后发布”的事件——如按信息自由法发布的基层医疗数据集——证明了“结合情境的发布”会让人重新可识别、商业的前线健康应用与可穿戴的数据、其“不是临床记录因而不受覆盖”的缺口正被监管机构不均等地填补——广告标识与月经记录与生育应用的丑闻、让“它不是医疗记录”成为一个消费者保护的问题、以及研究公地的模型受控访问的实验室、如某生物样本库的研究者批准机制与“数据使用协议加发表把关”这套机器、其他国家的生物样本库与全球健康的共享系统既复制了它、又因访问的不平等批评了它。基因组学最后才打破“个体”这个单位：家族信息的问题“你的序列有一半属于他们”这个事实、使“对亲属的遗传警告义务”之争不可避免——各法域之间那些不协调的指导、以及实际的缓解：在首次接触时就写下“便于级联检测的同意”、“可与亲属共享”的同意条款、以及那位先证者作为“家庭的传递者”的角色。**
:::

::: example 病房上的弟弟 {#ex-brother}
一名因新诊断的HIV入院的患者要求团队不要告诉任何人、“包括我弟弟——他在这家医院工作、他会去问护士”。两天后、那位做搬运工的弟弟来到护士站、“就想看看我弟弟怎么样了”。
::: solution
**摩擦之下的边界（[[#def-duty]]、[[#def-exceptions]]、[[infectious-diseases/hiv]]）：即刻的手艺：病房的回答是什么也不说“他有一张床、情况稳定、这是我所能确认的全部、而我不能与工作人员的亲属讨论患者、方式不会有区别——你也不会希望我那样做”、以及这句话背后的系统记录的访问标志不是盾牌、而是带审计日志的威慑、本机构应当张贴的那条“作为家属的工作人员是使用者、不是内部人”的政策、以及与患者当天就“他在怕什么、计划是什么”的那场谈话。临床的提供：给他的性伴走“协助的通知”的路径他自己的能动性、那支做“不具名的接触者、也不构成违约”的HIV外展服务——这个把披露伦理变成公共卫生实践的模型、承认他的弟弟是一个“人、而不是风险”、但不把他纳入披露的决定、以及诊断那一周常规藏起来的“能力与痛苦”的检查“谁最在意、谁正从网眼里漏下去”的复审。更长的架构：若审计显示病房的泄露确实发生时记录访问的违约回应适用于医务人员窥探、也适用于黑客的违约通知义务、以及与那位搬运工关于“这条边界也在保护他”的修复性谈话、以及医院那种多数机构只存在于一封邮件里、而应当存在于一道访问控制规则里的“员工家属”政策。伦理的语域：这次相遇中这一职责的意义、在于让患者能够在一个满是爱他的人的楼里守住一个秘密——而这正是保密不再只是礼貌、而开始成为“让检测与治疗成为可能”的那件东西的时刻。**
:::
:::

::: example 父亲的结果 {#ex-genetic}
一名40岁的男性拒绝为他家族已知的LMNA变异做基因检测“我已经想通了”；他33岁、有心悸的弟弟问你——这位家族的长期全科医师——“你总能告诉我爸爸是否携带它吧”。
::: solution
**家族信息的导航（[[#def-data]]、[[#def-duty]]）：先说那条硬线：那位40岁的检测决定与任何结果都属于他；全科医师不能确认携带状态、不能确认拒绝、也不能应要求把另一个成人的健康信息给这位弟弟——这是这一职责的核心、不是它的例外。正当的动作、按次序：把那位弟弟作为他自己的患者来提供（级联的教育：“这就是家族变异的意义、这就是一个检测会告诉你的、路径是这个——遗传服务可以把您作为高风险亲属来看”），提议重新与那位40岁者接触、请他同意“一般性的信息共享”遗传指导日益形式化的“家庭沟通协议”——为这场谈话在需要之前设计好的同意、以及那句关于沉默之理由的诚实：“如果我能告诉你什么、我第一件会告诉你的是你应当去检测”。指导留给人的那层粗糙的残余伦理：职业准则“为预防严重伤害的特殊披露”的路径应用于遗传信息“对可预见的亲属的警告义务”的争论——从塔罗多夫到基因组学的移植、带着它们的比例性检验：严重、可预防、在“有已知监测方案的遗传性心脏病”的意义上近乎迫近、以及经诊所而非经信件披露、遗传专业的实际答案亲属通过先证者自己的分享获得的“不具名的风险信息”、以及“家族史本身就已经是一次披露”的现实主义、以及对所选路径的记录记录下推理、在考虑披露时通知患者——这个流程让一次例外要么可辩护、要么不可辩护。本案实际允许的临床终局：这位33岁者因自己的症状被评估心悸本身就是一个带着自己的检查的就诊理由、家族门诊的再提议对那位40岁者永远敞开、而全科医师对“你总能吧”的回答是那句让两兄弟都值得信任的话：“我可以告诉你关于你的风险的一切、而不能告诉你关于他的任何——因为明年可能是你来要求我保护你的。”**
:::

## 通向何处

传染病的报告在[[public-health/communicable-disease-control]]与[[microbiology/infection-control]]、HIV披露的实践在[[infectious-diseases/hiv]]、遗传服务在[[genetics/genetic-testing]]、保护的职责在[[paediatrics/safeguarding]]、数据系统在[[clinical-skills/records-handover]]与[[clinical-skills/medical-imaging]]、人员的职责在[[medical-ethics-law/professionalism-regulation]]、而伦理的框架在[[medical-ethics-law/ethical-principles]]。

::: history
**保密规则比它的例外更古老希波克拉底那句“无论所见所闻……我都应当沉默”、而它的现代形态是职业架构的一个意外：十八世纪医院的病历文化把私人的知识变成了机构的那种对“匿名病房之前”的分析——在治疗性的家庭关系里人人皆知时、“保密”是什么、而十九世纪职业准则的编纂医学编辑协会、其后是美国医学会与英国医学会的信条把沉默变成一项由职业而非由法庭执行的责任。法律的汇流是通过隐私与数据的革命、而不是伦理的那一场：沃伦与布兰代斯1890年的论证、水门事件与斯塔西委员会之后的信息监管机构、与美国与健康保险可携性及数据生命周期准则相邻的规则、以及从欧盟数据保护指令到通用数据保护条例的这条弧——它把患者变成了一个拥有访问与删除权的数据主体、而信息学的文献至今仍在测量这个概念的反转在临床上的接受度“我的记录在什么意义上是我的？”。艾滋病流行是这门学科的压力测试从“塔罗多夫”一线案例开始的“保护第三方的义务”的判例、以及塔罗多夫本人源于一起谋杀的临床出处、被“以同意为先”的设计所解决的性伴通知之战、以及由“记录访问与知情需要”架构赢得的“病历里的HIV状态给谁看、何时看”的政策之争、而基因的时代在家族的尺度上重启了这场争论“对亲属的警告义务”的学术文献、遗传信息反歧视法及其在就业与保险上的悬置、以及各服务最终确定的级联检测的同意设计。数据的泄露写下了近几章：那个“丢了一张磁盘”的一代事件2005至2015年医院与保险公司丢失的统计迫使确立了加密与违约通知的规范、那次健康数据规划的崩盘2014年退出风暴的治理教训——同意的架构就是信任的基础设施、而法律的充分性不等于公众的正当性、对窥探的起诉与解雇“谁读了我的记录”的透明提案、应用商店那个“不是医疗记录”的丑闻月经与生育与祈祷应用的披露案例、把消费者保护与监管机构推到了可穿戴的岸边、以及大流行的紧急数据共享检测与追踪的数据保留与“功能蔓延”的争论、以及公民自由文献那种“要的是临时的监视、写进历史的是永久的”的怀疑、以及接触者追踪应用数据删除的承诺——如今这个领域在审计它们是否被遵守。贯穿的线索：每一项让信息安静移动的技术、都随之移动了例外的边界、而这个职业的任务仍是誓言所命名的那一个——把患者的故事留在线的那一边、只是如今附上了日志、目的的限制、与一条信息治理的条款——[[clinical-skills/records-handover]]、[[genetics/genetic-testing]]。**
:::

::: summary
- 保密首先是一件临床的工具、而不是伦理的装饰：回避就医与隐瞒症状的数据量化了披露风险的代价、而它在“例外最想追逐的人群”那里代价最高。
- 这一职责属于患者、覆盖任何形式的可识别信息、约束每一个接触它的人、并在一次接诊之后仍然存续——它在死亡之后与跨境之间的变化是法律的拼布、却是伦理的常量。
- 例外有权威的来源——同意明示或默示、法律、法庭的命令、以及带比例性检验的公共利益——而工作的纪律是“最小必要”与“安全时告知”、它们把违约变成一次正当的披露。
- 电子记录用“隐蔽”换来了“访问控制”：审计痕迹、违约的义务、与面向患者的“谁读了我的记录”日志是新的机器、而内部人查询的问题是这一职业自己的卫生检验。
- 二次的数据使用与基因组学溶解了“个体”这个容器：广泛同意的架构、受控访问的研究公地、以及家族信息的问题、都是每一位临床医师终将以患者提问形式遇到的治理问题。
- 实务的能力：知道那架阶梯、记录下你踩的那一级、并绝不让“家人想知道”成为这家机构的供词。
:::

::: exercise 指出权威 {level=1}
指出每次披露的法律或伦理的权威、以及它要求的纪律：(a) 一例确诊麻疹的报告；(b) 因患者自己提起的索赔而向律师提供病历；(c) 告知一位患者的女儿（她也是护士）她父亲的诊断、“因为她是照护者”；(d) 在有许可时向驾照管理局披露未治疗的晕厥。
::: solution
**权威与纪律的训练（[[#def-exceptions]]）：(a) 法定的义务报告的法规：纪律是完整与迅速、加上随之而来的与患者那场公共卫生的谈话报告是一个协助过程的开始、不是一次背叛——接触者追踪的伙伴模型。(b) 同意明示的、以及原告在这起索赔范围内对特免权的默示放弃：纪律是范围诉状定义了相关性；律师那张“全都给我”的要求不是权威——“只披露被要求的且相关的、不是全部”这条规则、以及患者持续地知道“什么东西离开了”的权利。(c) 完全没有权威：“她是家人、又是护士”这个论证是经典的——解药是“由患者许可把照护者纳入”的那场谈话、以及那个正确的路径：“如果患者无能力、而她是有权就这个决定做主的代席人或受托人”、它让这个请求变得可被回答。(d) 法定许可加公共利益那条路径、带着它的程序：先告诉患者并争取同意、只披露监管机构需要的医学事实、记录下推理、以及那项实际阻止了披露的临床职责把晕厥管理到这个问题消失——“驾驶建议与门诊的依从”这一随访才是保护保密的那个干预。这一练习的规则：每一次披露都需要它那一页被命名的依据部法律、道命令、份同意书、段准则、而能引用它的临床医师已经从“违约”走到了“治理”。**
:::

::: exercise 写出那句政策 {level=1}
为你医院手册起草那段“员工即家属”的政策段落、涵盖记录的访问、口头信息、升级与审计、并用一位搬运工也能认出的语言。
::: solution
**一段写给人的政策（[[#def-duty]]、[[#def-data]]）：草稿：“如果你认识的人在这里成为患者、他们拥有与其他任何患者完全相同的保密——包括对你的。这意味着：不要查看他们的病历每一次访问都被记录、被信息治理阅读、而对一个熟人病历的无解释访问是一项足以解雇的违规、即使你的理由是爱；不要向任何人确认、否认或讨论他们是否在此或他们的治疗、包括他们的家人、他们的管理者、或他们病房里的护士——病房不会告诉你任何、这是政策在起作用、不是粗鲁；若你需要传递信息、请团队把你通常会说的那个人该知道的、经过对方并带患者的同意交给他；如果有人向你打听一位你猜与你有关联的患者、请病房事务员联系主管护士、然后走开。员工的家属收到同一封信与同一个解释：我们的沉默也在保护你的亲人。”给起草者的注解：这段话命名了四种行为查看、确认、转述、回避、惩戒及其理由、升级的路径、以及那个让接受变得理性的互惠论证——反窥探复审推荐的这种“审计日志的威慑加常态化”的设计、胜过只有威胁的版本。**

::: exercise 处理验尸官的请求 {level=2}
验尸官要求提供一名已故患者的完整全科病历；家属指示你反对、“因为他告诉过我们一些关于孩子们的事”。请给出意见：法律的位置、保密的分析、以及人道的中间地带。
::: solution
**强制披露的实践（[[#def-exceptions]]、[[medical-ethics-law/justice-resources]]）：法律：在死亡调查中验尸官的请求是法定的、保密的职责要向它让步“逝者的病历与验尸官”在该法域是最清晰的一种情形；拒绝不是临床医师手里的选项、尽管注册官规则中关于相关性与第三方标识的异议是这个职业的声音。要当着家属说出来的分析：调查的目的一起被调查的死亡、就是法律为生者的保护而阅读这份病历、保密中幸存的部分病历进入验尸官的办公室、而不是公众；不相关的第三方的身份可以被标注；这次披露被记录并有边界、以及对“关于孩子们的事”的诚实回答如果所披露的涉及有风险的在世的儿童、那么一项单独的保护职责可能早已存在、而验尸官不会是唯一的读者——在谈话之前先做一次“义务叠加”的复审、好让家属听到一个连贯的说法。人道的中间：提议向验尸官的职员询问“完整病历还是相关的摘录”是否足够实践中他们会说病历是标准的、缩小范围对谁都没好处、但这个问题示范了倡导、为家属指一条他们自己申请法律援助的路他们不知道自己拥有的“利害关系人在审讯中的代理”的权利、以及诊所对这场谈话的记录、好让下一位临床医师不必重新打一次官司。教学的收尾：本案中这一职责的形状是最令人安心的——它只向法律让步、从不向好奇让步、而在强制的披露中、临床医师的职责是同时做律师礼貌的对手与家属诚实的翻译。**
:::

::: exercise 设计二次使用的治理 {level=2}
你的学术医学中心想要一个研究数据的平台、把日常的记录再用于嵌套的试验与观察性研究。设计这套治理的包裹：合法的基础、同意的立场、透明的制品、访问的控制、以及那个因其缺席而推翻了那次数据规划改革的“社区的声音”结构。
::: solution
**治理即架构（[[#def-data]]、[[public-health/health-systems-economics]]、[[medical-ethics-law/justice-resources]]）：合法的基础：关于“法定健康目的与公共任务”加研究豁免的分析在同意不可行的类似第251条的批准、通用数据保护条例第九条的处理条件及其保障、以及把“不对治疗造成损害”的承诺写进去、并逐项目说明、而不是一次说明。同意的立场：那个诚实的“不采用逐患者同意、理由是”的公共论证仅有同意模型的选择偏倚批评——只有同意的研究会系统性地歪曲病人群体、与“退出”路径实际的功能：一个选择的信号、而不是一个许可的引擎、所以它的设计容易、可见、退出时无惩罚承担着法律分析无法承担的那种正当性。透明的制品：份平实语言的目的登记每项研究一页、没有缩写汤、在数据流动之前公布、份“谁申请了、什么被批准、什么被拒绝”的日志、违约与事件的披露规范、以及每年那份“这个平台发现了什么、帮助了谁”的报告——那个被“数据捐献”文献反复发现的“把故事送回去”的职责。访问的控制：受控访问的分层模型去标识的开放以利于复现、假名化仅供批准的项目在安全环境中使用并带产出的披露审查、可识别的仅作为例外并被记录、研究者的训练与宣誓要求、以及在技术上诚实之处使用差分隐私与合成数据的前沿。社区的声音：那个常设的、有权力的公众小组后危机时代评估推荐的“外行人可以否决项目、而不只是斟酌辞令”的设计、由临床医师与患者共同设计透明的制品、收益公平的条款平台必须公布它为其数据被汇集的贫困群体做了什么、以及那种让这套架构始终处于“被论证”而非“被继承”状态的日落与复审节奏。整套包裹那一句设计的原则：假设公众在收益面前是讲道理的、而面对意外时是苛刻的、并为那个意外做工程。**
:::

::: example 那个知道得太多的应用 {#ex-app}
一名癫痫患者问她是否应当删除一个“好像什么都知道”的发作记录应用——它记录事件、睡眠、位置历史、并同步到一家美国的云端；同时她也想把它的数据放进她的医疗记录。
::: solution
**在诊室与广告商之间的消费者数据（[[#def-data]]、[[clinical-skills/records-handover]]、[[nervous-system/epilepsy]]）：给患者的评判：这个应用的条款是一块“医疗设备隐私说明书”的倒影那个“不是健康记录、因此隐私法规较轻、也没有HIPAA”的分析、月经与生育应用的丑闻使“出售或分享给广告商的软件开发工具包”成了人人皆知的事、以及“位置历史作为发作日记的推断”问题——一份发作记录加上位置、就是一份任何临床医师都无法合法保存的“诊断加行踪”的档案。用两只手的临床答案：数据确实有用应用生成的发作频率与触发因素的证据如今正喂给癫痫门诊的决定——“诊室中的患者生成数据”的文献、所以动作是“导入、而不背书”：索取导出事件日志的表格或文档、把它当作一份病史来审阅、并把临床相关的那份摘录归档把“最小必要”用到患者这一边、而原始的数据流与它的云端留在医疗系统的边界之外。记录：在病历中写下应用的名称与版本监管机构仍在敲定的那个“作为治疗邻近记录的装置”的问题、记录患者自己“同意与诊所共享”、并把她应得的建议明白地说清：“这个应用是一本有商业模式的日记；保留日记的价值、控制共享、而这里是两款其隐私文件连药师也能替它辩护的应用。”服务层面的要求：患者平台的互操作标准的路径那些能让她选择性地与应用共享记录数据的架构——“数据携带权作为临床基础设施”这个论证、以及公平的注记推荐应用的不平等：除非处方也包含隐私与成本的评估、否则“数字治疗的合格者”就是“数字上被服务的人”。她下次复诊会重复的那句话：“这个应用知道我的发作；我的诊室是唯一一个必须把它们保密的地方。”**

::: example 那个保护的困境 {#ex-safeguarding}
一名15岁的哮喘患者在接诊中承认她的继父“检查她的手机、不让她独自和医生在一起”、并请求你不要告诉她母亲；她的生长曲线与出勤的模式亮起了警示。
::: solution
**保护所在的保密（[[#def-exceptions]]、[[paediatrics/safeguarding]]、[[clinical-skills/communication]]）：框架：青少年的保密是一份让治疗成为可能的信任、带有被命名的例外保护的职责是最大的一类、而这个呈现——对一个孩子的控制性监视、回避披露的行为、生长与出勤的警示——不是一道保密的谜题、而是一个戴着保密面具的保护评估。手艺的次序：这次谈话自身的处理先确认、再尽早解释限度——套“有三件事我可能必须分享、以及为什么”的事先披露的脚本、它是这个承诺在伦理上可辩护的版本、尊重危险的信息收集“在家受虐的披露若处理笨拙会升级风险”的文献；“谁是安全的、你能容忍什么”问题；学校护士与教师的意见——不需要违约、因为他们是同一个团队的职责、阈值的决定她的陈述加上指标、在多数框架里达到了“有需要儿童对重大伤害”的评估线、而与指定的保护负责人协商、正是那个把决定从一位全科医师肩上移走的流程、以及披露到来时的执行告诉她什么会发生、何时、对谁、提供让她出席那次策略会议邻近谈话的机会、以及把警方与社会照护的路径的时机围绕她的安全而不是临床医师的解脱来安排。母亲这个提问：她可能是一位保护的同盟、也可能是一场被管理的欺骗的宿主；由评估来决定、而“要告诉母亲因为她就是母亲”并不是这一职责实际包含的规则。记录：即刻的、尽可能逐字的、保护词汇要精确的、因为一年后可能有法庭读到它、并把保密决定的推理记录下来、好让继任的临床医师继承那个“为什么”。教学的收尾：青少年的信任与孩子的安全是同一个利益在不同时点的计数、而临床医师的技巧在于让系统注意到、同时不变成这个女孩所命名的那种监视。**

::: exercise 评判一次研究中的泄露 {level=2}
一名研究者在她在审计的关联医院数据集中发现、她的一位旧日患者——多年前曾要求“精神科的病史永远不要离开本机构”——出现在一个多中心协作的提取数据里。这项研究已获批准、而数据是假名化的。为她与治理给出意见。
::: solution
**一个标记对一份批准（[[#def-data]]、[[#def-exceptions]]、[[medical-ethics-law/research-ethics]]）：即刻的分析：这次披露属于那个数据集批准与那种独立专家的授权涵盖了在既定条件之下的处理；被合法共享的假名化数据、是一个在她看到之前就已被回答的合法基础问题、而她的发现在法律上对那份提取没有改变任何东西——数据不是“她的”、这个项目不是一系列私人的谈话、而单方面删除一行会破坏一个研究数据集“已批准研究数据的完整性”这条规则——临场的临床仁慈同样不是数据处理的合法基础。她必须做的事：把这一冲突与这一标记的存在报告给数据保护官与数据的伦理治理特殊类别与敏感标记的问题——这个项目的合法基础本应对精神健康的数据配有加强的保障、而对“这一行能否被回溯关联”的回答、审计的线索就是治理的条目、如果她的临床关系可能使决定有偏、就回避涉及那一群体的分析研究伦理框架规定双重角色的管理、并在能做到的地方确保患者最初的要求被兑现现代记录系统提供的“带访问限制的敏感记录标记”——那个让承诺可以被遵守、而不是被祝愿的技术控制。下次会议上要提出的系统发现：本机构的导出配置应当让患者的访问限制标记穿过假名化“偏好作为随管线流动的数据”这个设计的缺口、国家的评估一直在记录、以及研究界那句诚实的话：假名化是风险的管理、不是匿名、而对患者做出的承诺应当在做出之前先对着可关联的面测试过。个人的注记：她不是那个泄露；她是发现了架构缺口的那次审计、而治理的回应应当感谢这位临床医师、同时不为这个系统免责。**

::: exercise 给一年级学生讲 {level=1}
给新医学生做一个两分钟的保密版本、包括：它为何存在、句三句话的实用规则、以及你下周要用来考他们的那个例子。
::: solution
**能记住的两分钟（[[#def-duty]]、[[#def-exceptions]]）：为何存在：“患者只在那个讲述是安全的地方才说真相、而他们隐瞒的东西恰好是会致命的——保密是你为什么能得到用药史、性史、以及他们从未向别人提过的那个症状；在病房的听力范围内破坏它一次、你就花掉了你并未挣得的职业的信用。“三句话的规则：”患者告诉你的东西留在团队里、用于他的治疗、除非有同意、法庭或法律的规定、否则不去任何别的地方；当你必须说时、把最少的量告诉对的人、并告诉患者你要这么做、除非那会让事情更糟；当你在凌晨两点拿不准时、答案永远是同一句话：在我说任何话之前、我会先弄清楚谁能授权这件事。“下周的考题：那位开出租车的患者请你别告诉他雇主他患有用胰岛素治疗的糖尿病、并想把处方寄到单位——答案要把寄药的风险谈话”把处方寄到工作场所就是一次披露“这一洞见、与驾驶执照通道的提问、以及那个”你实际在怕什么”的、位于请求背后临床病史的动作结合起来；他们应当带着一个既保住这一职责、又让执照的问题保持诚实、又保住这个患者的计划到来。**
