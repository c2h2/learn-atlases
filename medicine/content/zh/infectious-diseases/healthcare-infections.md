医院治愈感染，也制造感染。每一根静脉套管、导尿管、呼吸机管道和每一个手术切口都突破了机体的防御，而医院又把脆弱的人群、耐药微生物以及在他们之间来回接触的双手集中在一起。欧洲疾病预防控制中心（ECDC）估计，2022–2023年，欧盟和欧洲经济区的急症医院中每年约有430万患者发生至少一次医疗保健相关感染。呼吸道感染是最常见的类型，其次是尿路感染和手术部位感染。

这些感染中有许多是可以预防的。最重要的措施很简单：手卫生、无菌技术、只在需要时使用器械并及时拔除，以及合理使用抗生素。只有每一位工作人员每一次都可靠地做到，它们才会起作用。本章介绍医疗保健相关感染如何发生及如何预防、与器械和手术相关的感染、艰难梭菌，以及耐多药微生物的控制。英国的做法遵循NICE和英格兰国家感染预防与控制手册；治疗以原则形式描述。

## 医疗保健相关感染如何发生

::: definition 医疗保健相关感染 {#def-epidemiology}
**医疗保健相关感染（HCAI）**是由医疗保健导致、在医疗开始时既不存在也不处于潜伏期的感染。为了监测，住院患者的感染如果在入院第3天或以后（入院48小时或以上）出现症状，通常被计为**医院起病**。出院后不久在社区起病的感染，或与透析、化疗等门诊医疗相关的感染，也可以属于医疗保健相关感染。

每一次HCAI都遵循一条**感染链**：来自某个**传染源**（患者自身菌群、其他患者、工作人员、环境或设备）的微生物，通过某种**传播途径**到达**易感宿主**：

- **接触传播**，直接（手）或间接（设备、物体表面）：医院中最常见的途径，例如MRSA、艰难梭菌和耐药革兰氏阴性菌。
- **飞沫传播**：较大的呼吸道颗粒，传播距离短（流感、百日咳）。
- **空气传播**：悬浮在空气中的小颗粒（结核病、麻疹、水痘）。

**标准感染控制预防措施**适用于每一位患者：手卫生、根据操作选用个人防护装备、安全处理锐器、血液和体液、呼吸道卫生，以及清洁的设备和环境。当已知或怀疑某种特定感染时，再加上**基于传播途径的预防措施**（接触、飞沫、空气）。
:::

许多HCAI是由患者自身的微生物引起的，它们通过器械和伤口进入无菌部位。另一些则在患者之间传播，最常见的是通过工作人员的手。按照WHO“手卫生的五个时刻”（接触患者前、进行清洁或无菌操作前、有体液暴露风险后、接触患者后、接触患者周围环境后）在正确的时刻进行**手卫生**，是最重要的单项控制措施。对于大多数微生物，含酒精的手消毒剂比肥皂和水更快、更有效；例外是芽孢，例如艰难梭菌的芽孢，需要用肥皂和水。

## 器械相关感染

::: definition 器械相关感染与集束化干预 {#def-devices}
**器械相关感染**是由于医疗器械绕过了正常防御而发生的感染。主要类型有：

- **中心静脉导管相关血流感染（CLABSI）**：有中心静脉导管的患者发生菌血症，且无其他感染源。微生物从皮肤沿导管外壁进入（早期），或经接头和管腔进入（后期）。常见病原体为凝固酶阴性葡萄球菌、金黄色葡萄球菌（*Staphylococcus aureus*）、革兰氏阴性杆菌和念珠菌（*Candida*）。
- **外周静脉套管感染**：静脉炎，以及重要的是留置过久的套管引起的金黄色葡萄球菌菌血症。
- **导尿管相关尿路感染（CAUTI）**：细菌在数天内定植于导管表面，形成**生物膜**。几乎所有长期导尿管都有定植，因此单纯菌尿不等于感染。
- **呼吸机相关肺炎（VAP）**：气管插管48小时以后发生的肺炎，源于导管气囊周围定植分泌物的误吸。

**集束化干预（care bundle）**是一小组循证措施，每次都一起执行并接受审核。对于中心静脉导管：置管时的手卫生和**最大无菌屏障**；用**2%氯己定的70%酒精溶液**进行皮肤准备；选择穿刺部位（尽可能避开股静脉）并在超声引导下操作；每次使用前消毒接头；保持敷料清洁干燥；以及**每日评估导管是否仍有必要**。导尿管（避免不必要的导尿、无菌置管、密闭引流、尽早拔除）和机械通气患者（床头抬高30–45°、每日镇静中断、口腔护理、声门下分泌物引流）也有类似的集束化干预。
:::

::: theorem 器械日原则 {#thm-device-days}
器械相关感染的风险随器械留置的每一天而累积。如果一种器械每日的感染风险（风险率）大致恒定为$\lambda$，那么到第$t$天已发生感染的概率为

$$
P(t) = 1 - e^{-\lambda t} \approx \lambda t \quad \text{当 } \lambda t \text{ 较小时。}
$$

因此，感染率以每**1000器械日**报告（例如，每1000中心静脉导管日的CLABSI数），而预防器械感染的两种最有效的方法是：降低每日风险率（通过集束化干预）和缩短天数（在不再需要时尽快拔除器械）。
:::

密歇根州重症监护病房的Keystone项目展示了集束化干预的威力，彼得·普罗诺沃斯特（Peter Pronovost）等于2006年报告了这一项目：通过置管核查清单、授权工作人员叫停不合规的置管以及每日评估，CLABSI的中位发生率在三个月内从每1000导管日2.7例降至零，平均发生率在18个月内下降了约三分之二。

::: example 重症监护中的发热 {#ex-clabsi}
一名61岁男性急诊肠道手术后在重症监护病房第9天，体温升至38.9 °C，去甲肾上腺素需要量增加。他入院时置入了右颈内静脉中心静脉导管。穿刺点轻度发红。同时从导管和外周静脉采集的血培养均生长成簇的革兰氏阳性球菌，次日鉴定为对氟氯西林（flucloxacillin）敏感的金黄色葡萄球菌。导管血培养比外周血培养早三小时报阳。
::: solution
**诊断**：**导管相关金黄色葡萄球菌血流感染**。两套培养为同一种细菌，且导管血培养比外周血培养早两小时或以上报阳（**报阳时间差**），提示导管是感染源。

**金黄色葡萄球菌菌血症的处理**有固定原则，因为这种细菌会播散到心脏瓣膜、骨、关节和其他部位：
1. **拔除导管**（以及其他不必要的导管）。保留导管会导致复发。
2. 48–72小时后**复查血培养**以确认清除。
3. **超声心动图**检查有无心内膜炎；常常需要经食管超声心动图。
4. 用**静脉抗葡萄球菌β-内酰胺类**（此处为氟氯西林）治疗，非复杂性病例自首次培养阴性起至少**14天**；如有心内膜炎、迁徙性感染、持续性菌血症或人工植入物，则更长（通常4–6周）。
5. **感染病专科会诊**，这与较低的死亡率相关。

**监测**：该病房去年在2400个中心静脉导管日中发生6例CLABSI，发生率为每1000导管日$6/2400 \times 1000 = 2.5$例。随后应审核集束化干预的依从性，尤其是接头护理和每日导管评估。
:::
:::

::: example 感染的起搏器 {#ex-cied}
一名79岁女性四个月前植入了双腔起搏器。起搏器囊袋表面的皮肤变红变薄，现在一小块区域破溃，露出金属。她不发热，血培养阴性。
::: solution
**诊断**：**心脏植入式电子装置（CIED）囊袋感染**。装置侵蚀穿出皮肤，意味着无论培养结果如何，囊袋和装置都已被感染，因为装置表面覆盖着抗生素无法清除的细菌**生物膜**。常见病原体为凝固酶阴性葡萄球菌和金黄色葡萄球菌。

**处理**：单用抗生素会失败。标准做法是**完全移除脉冲发生器和所有电极导线**，通常在专科中心经皮拔除，同时对囊袋组织和导线尖端做培养，并进行抗生素治疗。血培养和超声心动图用于检查有无**导线或瓣膜心内膜炎**，如有则需延长疗程。感染控制、血培养阴性后，通常在对侧植入新装置；若她依赖起搏器，期间使用临时起搏。只有未累及囊袋的小的浅表切口感染才单用抗生素处理，且需密切复查。
:::
:::

## 手术部位感染

::: definition 手术部位感染 {#def-ssi}
**手术部位感染（SSI）**是手术后30天内（有植入物留置时最长90天）发生在手术部位的感染。按深度分类：

- **表浅切口感染**：切口的皮肤和皮下组织。
- **深部切口感染**：筋膜和肌层。
- **器官/腔隙感染**：手术中打开或操作过的任何解剖部位，例如腹腔脓肿或人工关节感染。

风险取决于**切口类别**：**清洁**切口（未进入呼吸道、消化道或泌尿生殖道）、**清洁-污染**切口（在控制下进入上述腔道）、**污染**切口（大量溢出、新鲜开放性创伤）和**感染（污秽）**切口（已有感染、空腔脏器穿孔）。患者因素（糖尿病、肥胖、吸烟、营养不良、免疫抑制、鼻腔金黄色葡萄球菌携带）和手术因素（手术时间长、低体温、组织操作粗糙）会增加风险。
:::

预防包括术前、术中和术后的措施，如NICE指南（NG125）所述：患者术前淋浴；只在必要时去除毛发，用**剪毛器**而不是剃刀；对有植入物的清洁手术、清洁-污染手术和污染手术，在切皮前单次给予**预防性抗生素**（时机应确保手术开始时组织浓度充足），术后**不**常规继续使用；用含酒精的消毒剂（最好是氯己定）进行皮肤准备；保持患者体温；控制血糖；用合适的敷料覆盖伤口。在心脏手术和骨科植入物手术等某些高风险手术前，对金黄色葡萄球菌携带者进行去定植。感染切口手术需要的是治疗，而不是预防。

::: example 与体征不相称的疼痛 {#ex-necfasc}
一名55岁2型糖尿病男性三天前在花园台阶上擦伤了胫部。现在小腿剧痛，远比轻微的发红所提示的严重，肿胀延伸至膝部。体温38.8 °C，脉率每分钟122次，血压95/55 mmHg。肿胀处皮肤呈暗紫色，有几个水疱，触之如“木板样”；该区域感觉减退。白细胞计数24 × 10⁹/L，血钠130 mmol/L，血糖19 mmol/L，肌酐160 µmol/L，CK升高。
::: solution
**诊断**：在被证明之前都应视为**坏死性软组织感染（坏死性筋膜炎）**。警示特征是**疼痛与可见体征不相称**、迅速扩散、全身中毒表现、皮肤变色、大疱、坚硬的硬结和皮肤感觉丧失（由皮神经破坏所致）。I型为多种微生物混合感染（常见于糖尿病以及腹部或会阴手术后，包括富尼埃坏疽）；II型通常由化脓性链球菌（*Streptococcus pyogenes*）引起，有时合并金黄色葡萄球菌，可发生于健康人的轻微外伤之后。

**处理以外科为主**：紧急请高年资外科医生评估，**尽早彻底清创**所有坏死组织，通常在随后几天内反复进行。影像学检查不能延误手术。LRINEC等实验室评分不够可靠，不能用来排除诊断。

**抗生素**：按本地指南广谱覆盖链球菌、葡萄球菌（有风险时包括MRSA）、革兰氏阴性菌和厌氧菌，**加用克林霉素（clindamycin）**，以抑制链球菌和葡萄球菌感染中的毒素产生。脓毒症处理、血糖控制和重症监护支持。链球菌中毒性休克时有时使用静脉注射免疫球蛋白。侵袭性A群链球菌感染在英国是法定报告疾病，家庭接触者可能需要抗生素预防。
:::
:::

::: example 心脏手术后的聚集性病例 {#ex-surgeon}
三个月内，某心脏外科病房在冠状动脉旁路移植术后出现五例甲氧西林敏感金黄色葡萄球菌引起的胸骨深部伤口感染，而通常的发生率约为每季度一例。应如何调查？
::: solution
这是一次**可能的暴发**，按与任何暴发相同的步骤调查（[[infectious-diseases/stewardship-outbreaks]]）：

1. **确认聚集**：核实这些病例按标准定义确为SSI，且增加不是由监测方式或病例构成的变化所致。
2. **对分离株分型**：全基因组测序显示这五株分离株是密切相关（提示共同来源）还是彼此无关（提示操作上的普遍疏漏）。
3. 按时间、手术室、术式、在场的工作人员和术后病房**描述病例**。
4. **审查操作**：皮肤准备、预防性抗生素的时机、手术室通风、器械消毒、伤口护理以及去定植方案的执行情况。

假设测序显示五株分离株为同一菌株，且所有病例都涉及同一位外科医生。员工筛查发现，这位外科医生的鼻腔和一块慢性手部皮炎处携带同一菌株。通过职业健康部门对这位外科医生进行保密处理：治疗皮炎、**去定植**，并在确认清除之前暂停手术。这是一个员工健康问题，而不是纪律问题。持续监测确认聚集已经结束。
:::
:::

## 艰难梭菌感染

::: definition 艰难梭菌感染 {#def-cdiff}
**艰难梭菌（*Clostridioides difficile*）**是一种形成芽孢、产生毒素的革兰氏阳性厌氧菌。**艰难梭菌感染（CDI）**是由其毒素A和毒素B损伤结肠上皮所引起的腹泻（24小时内三次或以上不成形便）或结肠炎；重症病例发生**假膜性结肠炎**。芽孢可在物体表面存活数月，耐受酒精，并通过手和环境传播。

**危险因素**：扰乱结肠菌群的抗生素（尤其是克林霉素、头孢菌素类、氟喹诺酮类和阿莫西林-克拉维酸）、高龄、住院或居住在护理院、质子泵抑制剂以及重症疾病。

**诊断**采用对液状粪便的两步检测：先做灵敏的筛查试验（谷氨酸脱氢酶抗原或毒素基因PCR），再做**毒素**免疫测定。毒素检测阳性即确诊感染；筛查阳性而毒素阴性可能意味着定植。检测成形便或治愈后复查都没有意义。

**严重程度**（英国指南）：白细胞计数高于15 × 10⁹/L、肌酐急剧升高（比基线高50%以上）、体温高于38.5 °C或有严重结肠炎的证据，提示重症；低血压、部分或完全性肠梗阻或中毒性巨结肠提示**危及生命**。

**治疗**（NICE NG199，2021年）：尽可能停用致病抗生素，并评估减慢肠蠕动或抑酸的药物。首次发作时，一线治疗为**口服万古霉素（vancomycin）**10天，二线为**非达霉素（fidaxomicin）**。症状消退后12周内的再次发作（复燃）用非达霉素治疗；12周后的发作（复发）用万古霉素或非达霉素治疗。危及生命的病例需要专科处理，常需外科干预，用口服万古霉素加静脉甲硝唑。既往发作两次或以上后，考虑**粪便微生物群移植**。
:::

在英格兰，自2007年起的强制性监测和国家行动——包括限制头孢菌素类和氟喹诺酮类、隔离以及用杀芽孢剂清洁——与CDI的急剧下降同时发生。这是**抗微生物药物管理能预防感染**的最清晰证明之一。

::: warning
**不要治疗定植，不要送检错误的标本。** 许多HCAI的“诊断”其实是定植。导尿患者几乎总有菌尿；导尿患者不用尿试纸检测，只有出现感染症状时才使用抗生素。MRSA筛查拭子阳性是进行去定植和采取预防措施的理由，而不是全身使用抗生素的理由。成形便不应送检艰难梭菌；腹泻另有原因的患者GDH阳性而毒素阴性，可能代表携带状态。治疗定植会助长耐药和艰难梭菌感染，而对患者毫无帮助。
:::

## 耐多药微生物

在医疗机构中传播的耐药微生物在[[infectious-diseases/stewardship-outbreaks]]中详细讨论。主要包括：

- **耐甲氧西林金黄色葡萄球菌（MRSA）**：携带*mecA*基因，编码一种对β-内酰胺类亲和力低的改变了的青霉素结合蛋白（PBP2a）。在英国通过对高风险入院人群筛查、用鼻腔莫匹罗星（mupirocin）和氯己定沐浴去定植、接触预防措施以及导管护理来控制；英格兰的MRSA菌血症发生率在21世纪头十年急剧下降。
- **耐万古霉素肠球菌（VRE）**：定植于血液科、肾脏科和重症监护病房患者的肠道。
- **产超广谱β-内酰胺酶（ESBL）的肠杆菌目细菌**：对大多数青霉素类和头孢菌素类耐药；现在在社区和医院中都很常见。
- **产碳青霉烯酶的肠杆菌目细菌（CPE）**：产生KPC、OXA-48、NDM、VIM或IMP等能破坏碳青霉烯类的酶；常对几乎所有抗生素耐药，并由能在菌种间传播的质粒携带。从国外医院或已知有CPE的英国医院转来的患者，入院时要做直肠拭子筛查，在结果出来之前予以隔离。
- **非发酵革兰氏阴性菌**，如铜绿假单胞菌（*Pseudomonas aeruginosa*）和鲍曼不动杆菌（*Acinetobacter baumannii*），它们能在水槽、下水道和设备上存活。
- **耳念珠菌（*Candida auris*）**：一种定植于皮肤、在物体表面长期存在、在重症监护病房引起暴发、并常对抗真菌药耐药的酵母菌。

控制依靠同样的支柱：通过筛查早期识别、对定植和感染患者进行隔离或分组安置、接触预防措施、彻底清洁（包括注意水槽和下水道）以及降低抗生素压力。

::: history
1847年，伊格纳兹·塞麦尔维斯（Ignaz Semmelweis）在维也纳总医院产科诊所工作时注意到，由从解剖室过来的医生和学生接生的产妇死于产褥热的比例，远高于由助产士接生的产妇。他要求用含氯石灰溶液洗手后，医生病房的产妇死亡率大幅下降；他的观点在他生前遭到普遍拒绝。弗洛伦斯·南丁格尔（Florence Nightingale）在克里米亚战争（1854–1856年）中的工作用统计数据表明，死于疾病的人远多于死于伤口的人，而卫生措施能挽救生命。1867年，约瑟夫·李斯特（Joseph Lister）在巴斯德细菌学说的基础上，报告了用石炭酸预防伤口感染。在甲氧西林问世后不到两年，英格兰于1961年报告了MRSA。在现代，WHO“清洁的医疗更安全”运动（2005年）以及普罗诺沃斯特基于核查清单减少中心静脉导管感染的工作（2006年）表明，系统而可靠的操作能大规模地预防感染。
:::

::: quiz
一名护士即将护理一位艰难梭菌腹泻患者。接触后需要采用哪种手卫生方法？
- [ ] 含酒精的手消毒剂
- [x] 用肥皂和流动水洗手
- [ ] 氯己定酒精凝胶
- [ ] 只戴手套，不做手卫生
::: solution
艰难梭菌芽孢不能被酒精杀灭。用肥皂和流动水洗手能机械地清除它们。接触时要戴手套和围裙，但脱手套后仍要洗手，因为手套可能被污染或破损。
:::
:::

## 后续内容

感染预防与控制的原则在[[microbiology/infection-control]]中介绍，耐药生物学和抗微生物药物见[[microbiology/antimicrobials]]。抗微生物药物管理和暴发调查在[[infectious-diseases/stewardship-outbreaks]]中展开。手术伤口见[[surgery/wounds-surgical-infection]]，重症监护见[[emergency-critical-care/critical-care]]，集束化干预背后的安全文化见[[clinical-skills/patient-safety]]。

::: summary
- 医疗保健相关感染常见且常可预防；大多数通过接触（常经手）传播，或由患者自身菌群经器械和伤口进入而引起。
- 按WHO五个时刻进行手卫生是最重要的控制措施；艰难梭菌芽孢需要肥皂和水。
- 器械感染风险按器械日累积；集束化干预降低每日风险率，尽早拔除减少天数。发生率按每1000器械日报告。
- 金黄色葡萄球菌菌血症需要拔除导管、复查培养、超声心动图和至少14天的静脉治疗；感染的心脏装置需要完全移除。
- 通过恰当的预防用药（切皮前单剂）、剪毛而非剃毛、含酒精氯己定皮肤准备、维持正常体温和控制血糖来预防SSI。坏死性筋膜炎是外科急症。
- 艰难梭菌感染继发于抗生素暴露；诊断需要毒素检测，治疗遵循NICE NG199（一线为口服万古霉素），抗微生物药物管理和环境控制可预防其发生。
- 耐多药微生物（MRSA、VRE、产ESBL和产碳青霉烯酶的细菌、耳念珠菌）通过筛查、隔离、清洁和降低抗生素压力来控制。
:::

## 习题

::: exercise 导管感染率 {level=1 check="2.5"}
某重症监护病房在3600个中心静脉导管日中记录到9例中心静脉导管相关血流感染。每1000导管日的发生率是多少？
::: solution
$9/3600 \times 1000 = 2.5$，即每1000导管日2.5例。
:::
:::

::: exercise 一个月的风险 {level=1 check="round(1000*(1-exp(-0.06)))/10"}
某导尿管的每日感染风险恒定为0.002（每1000导尿管日2例）。用[[#thm-device-days]]计算30天内感染的概率。答案以百分比表示，保留一位小数。
::: solution
$P = 1 - e^{-0.002 \times 30} = 1 - e^{-0.06} = 0.0582$，即**5.8%**。由于$\lambda t$较小，近似值$\lambda t = 0.06$（6%）很接近。如果改为10天后拔除导尿管，风险将降至约2%。
:::
:::

::: exercise 切口类别 {level=1}
按切口类别对下列手术分类：(a) 择期腹股沟疝补片修补术；(b) 择期右半结肠切除术；(c) 阑尾穿孔伴盆腔积脓的剖腹探查术；(d) 两小时前受伤的开放性骨折急诊修复。说明哪些需要预防性抗生素，哪些需要治疗。
::: solution
(a) **清洁**手术，有植入物（补片），因此单剂预防用药。(b) **清洁-污染**（在控制下进入肠道）：预防用药。(c) **感染**切口（已有感染）：需要**治疗**疗程，而不是预防。(d) **污染**（新鲜开放性创伤）：按骨科指南，早期使用抗生素是开放性骨折治疗的一部分，同时进行清创。
:::
:::

::: exercise 尿袋里的细菌 {level=2}
一名84岁长期留置导尿管的女性因跌倒住院。她情况良好，不发热，没有新出现的意识混乱。常规导尿管尿标本培养出奇异变形杆菌（*Proteus mirabilis*）超过10⁵ CFU/mL。一位医生开了抗生素。这样做对吗？
::: solution
不对。长期导尿管几乎总是有细菌以生物膜形式生长，导尿患者的**无症状菌尿**不应治疗：抗生素不能清除生物膜，反而筛选耐药并引起艰难梭菌感染。只有在出现感染征象（发热、寒战、无其他原因的新发意识混乱、腰痛、耻骨上压痛、脓毒症）时，才对导尿患者做尿培养。如果她日后出现感染症状，应先更换导尿管再取标本并开始治疗。变形杆菌还会形成堵塞导管的结晶性生物膜，这是评估导尿管的理由，而不是治疗尿液的理由。
:::
:::

::: exercise 是重症吗？ {level=2}
一名76岁男性在肺炎治疗第8天出现腹泻。艰难梭菌GDH和毒素均阳性。体温38.0 °C，白细胞计数18 × 10⁹/L，肌酐145 µmol/L（基线85），血压128/74 mmHg，腹软、轻压痛，肠鸣音存在。评估严重程度并概述处理。
::: solution
**严重程度**：白细胞计数高于15 × 10⁹/L，肌酐升高了$(145-85)/85 \approx 71\%$，比基线高50%以上，因此属于**重症**CDI。没有危及生命的特征（无低血压、肠梗阻或巨结肠）。**处理**：采取肠道隔离措施；评估并尽可能停用或降阶梯肺炎的抗生素；尽可能停用质子泵抑制剂和止泻药；评估并纠正液体和电解质平衡；开始**口服万古霉素**（NICE NG199中的一线治疗）；每日评估有无恶化征象（白细胞或乳酸升高、腹胀、肠梗阻），对腹部影像检查和外科会诊保持低门槛。按本地和国家监测要求上报。
:::
:::

::: exercise 何时给予预防用药 {level=2}
在一例择期髋关节置换术中，麻醉医生在切皮前两小时给予预防性抗生素，手术团队“因为有植入物”在术后继续用药五天。指出问题并解释原则。
::: solution
**时机**：预防用药的目的是在**切皮时**及整个手术期间达到足够的组织浓度，因此在切皮前不久（通常在麻醉诱导时）给药，手术时间长或失血多时追加剂量。提前两小时给药，取决于药物的半衰期，切皮时浓度可能已在下降。**疗程**：术后持续数天的预防用药并不能减少SSI，即使有植入物也是如此；反而增加不良反应、艰难梭菌感染和耐药。单剂（或按本地政策仅限于手术期间的预防用药）是标准做法。其他措施（剪毛、含酒精氯己定皮肤准备、维持正常体温、金黄色葡萄球菌携带者去定植、关节置换手术中的层流手术室）与抗生素同样重要。
:::
:::

::: exercise CPE警报 {level=3}
在一个普通内科病房，一名两周前从国外医院转来的患者直肠筛查拭子发现携带产NDM碳青霉烯酶的肺炎克雷伯菌（*Klebsiella pneumoniae*）。到目前为止他一直未被隔离。概述应对措施。
::: hint
考虑指示病例、接触者、环境、实验室确认和沟通。
:::
::: solution
**指示病例**：把他转入带独立卫生间的单人间，采取接触预防措施（手套和围裙、专用设备），并在病历中标记，以便今后入院时及时隔离。他是定植而不是感染，因此除非发生感染否则不给抗生素；如需使用，要与微生物科共同选择，因为产NDM的细菌对几乎所有β-内酰胺类耐药。

**接触者**：找出曾与他同住一个病区隔间或共用卫生设施的患者，对其做直肠拭子筛查（常需多次），对阳性者进行隔离或分组安置。如果他在病房停留时间很长，考虑筛查整个病房。

**环境**：加强清洁，包括可能藏匿CPE的水槽、下水道和厕所。

**实验室与监测**：确认碳青霉烯酶类型，把分离株送参考实验室，并通知感染预防与控制团队，按要求通知卫生防护团队。

**经验教训**：入院时的筛查触发条件（从国外医院转入）被遗漏了。应审查入院流程，并提醒工作人员：对此类转院患者进行筛查和预防性隔离是标准做法，因为CPE可在患者之间无声传播，而且极难根除。
:::
:::

::: exercise 被遗忘的套管引起的金黄色葡萄球菌感染 {level=3}
一名因卒中入院的68岁女性在第6天出现发热。急诊科置入的左前臂外周静脉套管仍在原位；静脉发红、有压痛。两套血培养生长MRSA。她其他方面情况稳定。概述处理，包括疗程及其决定因素，以及如何预防此类感染。
::: solution
**处理**：立即拔除套管（如本地规定则送检尖端）。与感染专科讨论后开始**针对MRSA的静脉治疗**（例如按本地指南用万古霉素或达托霉素（daptomycin））。48–72小时后复查血培养。行**超声心动图**检查（经胸，如有任何疑虑则经食管），并检查有无迁徙性感染（脊柱、关节、脓肿）。**疗程**：如果属于非复杂性（导管来源已拔除、72小时内血培养转阴、发热消退、无心内膜炎、无植入假体、无迁徙性感染），自首次培养阴性起至少静脉治疗**14天**；否则4–6周。感染病专科会诊是标准做法。

**预防**：外周静脉套管只在需要时置入，置入和操作要无菌，至少每日用静脉炎目测评分检查，并在**不再需要时**或出现静脉炎时**立即拔除**。MRSA筛查和去定植以及记录置管日期有助于做到这一点。许多医院把套管相关金黄色葡萄球菌菌血症作为患者安全事件进行审查。
:::
:::
