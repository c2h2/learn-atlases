大多数感染不需要多少帮助就能顺利结束。感冒的儿童、膀胱炎的成人、咽痛的学生，靠休息、补液或短程抗生素就能康复。但有一小部分人并非如此。在他们身上，机体对感染的反应损伤了自身的器官，病情可以在数小时内从“不舒服”发展到“濒临死亡”。这就是**脓毒症**，在全球范围内，它夺去了约五分之一患者的生命。

本章讲授两项相互关联的技能。第一项是发热患者的诊治思路：判断病情有多重、寻找感染源、选择第一种抗生素。第二项是在最初数小时内识别和治疗脓毒症——正是在这一阶段，良好的基础处理挽救的生命最多。致病微生物通常是普通的。结局好坏的差别通常在于速度、感染源控制和复苏，而不在于罕见的诊断。

全章所述的处理均为原则和典型的成人做法。剂量和具体药物的选择以现行国家及本地指南为准；本页优先采用英国指南（NICE），并在国际指南（拯救脓毒症运动，Surviving Sepsis Campaign）有所不同之处加以说明。

## 发热：是什么，提示什么

::: definition 发热 {#def-fever}
**发热**是由下丘脑体温调定点上移引起的核心体温升高。成人通常以**38.0 °C及以上**作为工作阈值。**过热（体温过高）**则不同：调定点正常，但产热或获热超过散热（中暑、5-羟色胺综合征、神经阻滞剂恶性综合征、某些药物）。**不明原因发热（FUO）**是指体温多次超过38.3 °C、持续三周以上、经过规定时间的检查仍未明确诊断的发热（最初的定义为住院检查一周；后来的定义也接受三次门诊就诊或住院三天）。
:::

在床旁区分发热与过热很重要。发热时，机体在维持一个更高的目标，所以患者觉得冷、寒战、裹紧衣被，而体温在不断攀升。过热时，机体在与热量的对抗中失利，皮肤通常发烫，患者自觉燥热。对乙酰氨基酚（paracetamol）等解热药能降低调定点，对发热有效；对中暑则无效，中暑需要主动降温。

::: proof
**发热是如何产生的。** 微生物产物（例如革兰氏阴性菌的脂多糖）被单核细胞和巨噬细胞上的模式识别受体识别。这些细胞释放**内源性致热原**——白细胞介素-1、白细胞介素-6和肿瘤坏死因子。这些细胞因子作用于下丘脑周围室周器的内皮，那里缺乏完整的血脑屏障。在该处，环氧合酶-2被诱导，产生**前列腺素E₂**。PGE₂作用于视前区神经元，使调定点上移。

此时机体“感到”太冷。皮肤血管收缩以保存热量，肌肉寒战以产生热量。剧烈寒战伴体温迅速上升称为**寒战（rigor）**；寒战提示菌血症，但也见于疟疾、流感和输血反应。当刺激减弱，调定点回到正常，对于新的目标而言患者此时太热，于是面色潮红、出汗。对乙酰氨基酚和非甾体抗炎药（NSAID）能退热，是因为它们抑制前列腺素的合成。
:::

发热是一个体征，而不是诊断。体温高低与病情严重程度只有松散的相关。旧的热型名称（稽留热、间歇热、回归热）偶尔有用：例如，从非洲归来的人每48小时发热一次提示疟疾。但解热药和早期抗生素已使大多数热型变得模糊，热型分析绝不能取代结构化的评估。

### 第一个问题：这个人病得有多重？

第一项临床行为是判断严重程度，用ABCDE法在几分钟内完成（[[emergency-critical-care/acute-assessment]]）。依次检查并处理气道、呼吸、循环、神经功能障碍（意识水平和血糖）及暴露（皮疹、伤口、导管）。在英国的医院和救护车中，**国家早期预警评分2（NEWS2）**把这一判断量化。它对呼吸频率、血氧饱和度、是否吸氧、收缩压、脉率、意识水平（包括新出现的意识混乱）和体温进行评分。分数越高，病情恶化的风险越大，需要越快、越高年资的响应。

任何发热患者出现以下特征都应引起警惕：新出现的意识混乱、呼吸频率每分钟25次及以上、收缩压低于90 mmHg、心率每分钟超过130次、皮肤花斑或灰白、不褪色的皮疹、18小时无尿，以及乳酸2 mmol/L及以上。每一项都提示器官正在衰竭。

### 第二个问题：感染在哪里？

患者一旦安全，就开始寻找感染源。大多数感染源靠仔细的病史和查体发现，而不是靠影像检查。

- **按系统询问症状**：咳嗽和气促（胸部）、排尿困难和腰痛（泌尿道）、腹痛和黄疸（胆道）、头痛和颈强直（中枢神经系统）、肢体红肿热痛（皮肤软组织、骨或关节）、腹泻（肠道）。
- **暴露史**：旅行及其日期、动物、食物和饮水、性接触、注射吸毒、近期医疗接触、患病的接触者。
- **宿主**：年龄、妊娠、糖尿病、化疗、糖皮质激素或生物制剂、脾切除、HIV、器官移植。免疫力低下的宿主会改变可能的病原体（[[infectious-diseases/immunocompromised-host]]）。
- **医疗器械和异物**：静脉导管、导尿管、人工关节和人工心脏瓣膜、起搏器（[[infectious-diseases/healthcare-infections]]）。

查体要从头到脚，包括皮肤（皮疹、蜂窝织炎、压疮）、静脉导管和导尿管部位、心脏（新出现的杂音）、腹部、关节和脊柱。随后进行床旁检查：尿试纸和尿培养、血培养、全血细胞计数、肾功能和肝功能、C反应蛋白、乳酸，呼吸受累时加做胸部X线片。

::: example 出皮疹的学生 {#ex-meningococcus}
一名19岁大学生被室友送到急诊科。她发热、呕吐已12小时，现在双腿剧痛，手脚冰冷。脉率每分钟132次，血压92/50 mmHg，呼吸频率每分钟28次，毛细血管再充盈时间4秒。她意识清醒但焦虑。双腿上有几个紫色斑点，用玻璃杯按压不褪色。

最可能的诊断是什么？第一小时内应该做什么？
::: solution
**识别模式。** 年轻成人出现发热伴**不褪色皮疹**、肢体疼痛和外周发冷，在被排除之前都应视为**脑膜炎球菌败血症**。腿痛、手脚冰冷和皮肤颜色异常是早期征象；颈强直和畏光可能根本不出现，因为败血症可以不伴脑膜炎。

**评估严重程度。** 她有心动过速、呼吸急促、临界低血压和外周灌注不良。她发生重症和死亡的风险很高。

**立即行动。**
1. 若有低氧血症给予高流量吸氧，建立两条大口径静脉通路。
2. 采血做血培养和脑膜炎球菌PCR，但**抗生素绝不能等待这些检查**。英国指南（NICE NG240，2024年）规定，一旦怀疑脑膜炎球菌病就应给予胃肠外抗生素；在院外，若不延误转运则给予青霉素G（benzylpenicillin），在院内则给予第三代头孢菌素，如头孢曲松（ceftriaxone）。
3. 液体复苏并仔细再评估，尽早请重症医学科参与。在她处于休克或皮疹正在扩散时**不**做腰椎穿刺；这会延误治疗，并可能伤害她。
4. **公共卫生。** 脑膜炎球菌病是法定报告疾病。当地卫生防护团队会为密切接触者（如她的室友）安排抗生素预防（通常为单剂环丙沙星（ciprofloxacin））并给予疫苗接种建议。

本病例的启示：一旦识别出模式，先给抗生素，诊断性检查随后进行。
:::
:::

## 脓毒症：定义与机制

25年来，脓毒症一直被定义为感染加上全身炎症反应（SIRS）。这个定义灵敏但不特异：一个扭伤脚踝、脉搏偏快的人也符合。2016年，一个国际工作组围绕**器官功能障碍**重新定义了脓毒症，因为预测死亡的正是器官功能障碍。

::: definition 脓毒症与脓毒性休克（Sepsis-3） {#def-sepsis}
**脓毒症**是由宿主对感染的反应失调所引起的危及生命的器官功能障碍。临床标准上，器官功能障碍是指**序贯器官衰竭评估（SOFA）评分**急性**升高2分或以上**；该评分对六个系统（呼吸、凝血、肝脏、心血管、中枢神经系统、肾脏）各按0至4分评级。除非已知存在既往器官功能障碍，否则假定基线为零。

**脓毒性休克**是脓毒症的一个亚型，其循环和细胞代谢异常严重到足以显著增加死亡率。临床上，它是指脓毒症患者**需要血管加压药才能将平均动脉压（MAP）维持在65 mmHg或以上**，且**经充分液体复苏后血清乳酸仍高于2 mmol/L**。
:::

在用于建立该定义的数据中，脓毒症的院内死亡率高于10%，脓毒性休克高于40%。一项基于2017年数据的全球分析估计有4890万病例和1100万脓毒症相关死亡，约占全球死亡的五分之一，负担最重的是低收入和中等收入国家。

该定义不是筛查工具。工作组还提出了**qSOFA**（快速SOFA）作为床旁提示：呼吸频率每分钟22次及以上、意识改变、收缩压100 mmHg及以下，各计1分。2分及以上提示不良结局风险较高。qSOFA特异性高，但会漏掉许多处于病程早期的患者，因此2021年拯救脓毒症运动指南建议**不要**单独用它筛查脓毒症。在英国，使用的是NEWS2。

::: theorem 氧输送 {#thm-delivery}
组织氧输送是心输出量与动脉血氧含量的乘积：

$$
\dot{D}\mathrm{O_2} = \mathrm{CO} \times C_a\mathrm{O_2} \times 10, \qquad C_a\mathrm{O_2} = 1.34 \times \mathrm{Hb} \times S_a\mathrm{O_2} + 0.0225 \times P_a\mathrm{O_2}
$$

其中$\dot{D}\mathrm{O_2}$的单位为mL/min，心输出量（CO）为L/min，血红蛋白为g/dL，$S_a\mathrm{O_2}$为小数，$P_a\mathrm{O_2}$为kPa，$C_a\mathrm{O_2}$为每dL血液所含的mL O₂（系数10把dL换算为L）。几乎所有的氧都与血红蛋白结合运输；溶解的氧只是一个很小的项。休克的复苏旨在通过改善每一个因素来恢复氧输送：心输出量（补液、正性肌力药）、血红蛋白（严重贫血时输血）和饱和度（吸氧）。
:::

::: proof
**脓毒症中器官为何衰竭。** 细菌成分（病原体相关分子模式）和受损细胞的产物（损伤相关分子模式）激活固有免疫细胞上的Toll样受体及其他受体。本应局限的反应溢入血液循环：

1. **血管扩张。** 血管壁中的诱导型一氧化氮合酶产生大量一氧化氮；小动脉扩张，对儿茶酚胺反应差。体循环血管阻力和血压下降。
2. **毛细血管渗漏。** 炎症介质损伤内皮及其糖萼，使液体和白蛋白进入组织。患者出现水肿，但血管内容量却不足。
3. **凝血。** 组织因子表达驱动微血管血栓形成，消耗血小板和凝血因子（弥散性血管内凝血），阻塞小血管。
4. **细胞功能障碍。** 线粒体利用氧的效率下降，因此即使氧输送已恢复，器官仍会衰竭。
5. **免疫抑制。** 在早期的风暴之后，淋巴细胞发生凋亡，单核细胞反应性降低，使幸存者容易发生继发感染。

当组织灌注不足时**乳酸**升高，但肾上腺素驱动糖酵解、肝功能衰竭使清除减少时乳酸也会升高。因此乳酸升高是严重程度的标志，而不是缺氧的证据；乳酸下降则是复苏有效的有用征象。
:::

::: warning
**体温正常不能排除脓毒症。** 老年人、使用糖皮质激素或免疫抑制剂者以及感染极其严重者，体温可以正常甚至**过低**（低于36 °C）；脓毒症伴低体温的预后更差。β受体阻滞剂会掩盖心动过速；长期高血压的患者在110/70 mmHg这样“正常”的血压下也可能灌注不足。要整体判断患者：新出现的意识混乱、呼吸急促、皮肤花斑和尿量减少。
:::

## 第一小时：初始处理

早期脓毒症处理的核心很简单，二十年来没有改变：识别它，留取培养，尽快给予正确的抗生素，恢复灌注，清除感染源。英国把这一套教为**“脓毒症六项”（Sepsis Six）**：给氧至目标饱和度、留取血培养、静脉给予抗生素、静脉补液、测定乳酸（并查全血细胞计数）、监测尿量。

**抗生素的时机。** 观察性研究显示，抗生素每延迟一小时，死亡率就会上升，在脓毒性休克中最为明显。在纽约的一个大型队列中（Seymour等，2017年），完成脓毒症集束化治疗每延迟一小时，院内死亡的比值约升高4%。然而，对并非脓毒症的人仓促使用广谱抗生素会通过副作用、艰难梭菌感染和耐药造成伤害。因此，指南按风险分级确定紧迫程度：

- **NICE NG253**（2025年11月发布，取代了NG51中有关成人的部分）对16岁及以上、未妊娠的人使用NEWS2。疑似脓毒症且评分**7分或以上**为高风险：**1小时内**给予广谱抗生素，并由高年资医生评估。评分**5或6分**需要及时评估并测定乳酸；如感染仍是最可能的原因，应在**3小时内**给予抗生素，若乳酸高于2 mmol/L或存在急性肾损伤则应更早。较低的评分允许有时间进行评估，以临床关切为指导。
- **拯救脓毒症运动（2021年）**建议：对可能的脓毒性休克或脓毒症可能性高者在1小时内给予抗生素；对无休克者应迅速评估，若对感染的担忧持续存在，在3小时内给予抗生素。

**血培养**在不会造成明显延误的前提下于抗生素前留取：至少两套（每套一个需氧瓶和一个厌氧瓶），分别从不同部位静脉穿刺采集，血量要充足。其他培养根据可疑感染源进行：尿、痰、伤口拭子、脑脊液和关节液。

**补液。** 低血压或乳酸4 mmol/L及以上提示灌注不足。以晶体液分次冲击补液（首选平衡液如哈特曼液（Hartmann's solution），而非大量0.9%氯化钠），每次冲击后再评估：脉搏、血压、毛细血管再充盈、精神状态、尿量、乳酸以及液体过负荷的体征。拯救脓毒症运动建议对灌注不足者在最初3小时内至少给予30 mL/kg，这是一项弱推荐；比较限制性和开放性补液策略的试验并未显示哪一种更好，因此个体化再评估比固定的液体量更重要。

**血管加压药。** 初始补液后MAP仍低于65 mmHg时，开始使用血管加压药。**去甲肾上腺素（noradrenaline）**为一线药物；去甲肾上腺素需要量不断增加时加用血管加压素（vasopressin），心功能障碍时可使用肾上腺素（adrenaline）或正性肌力药。在建立中心静脉通路的同时，可经外周静脉开始使用血管加压药。对于需要去甲肾上腺素至少0.25 µg/kg/min持续4小时或以上的持续性休克，建议静脉使用氢化可的松（hydrocortisone）。

**感染源控制。** 抗生素很难渗入脓液、坏死组织和被感染的器械。引流脓肿、解除肾脏或胆管梗阻、清除坏死组织、拔除感染的导管，与药物同样重要，应在可行时尽快进行，通常在数小时内完成。

::: example 第一小时的算术 {#ex-numbers}
一名体重70 kg的肺炎男性，血压84/42 mmHg，脉率每分钟118次，血红蛋白10 g/dL，$S_a\mathrm{O_2}$ 0.88，$P_a\mathrm{O_2}$ 7.0 kPa。估算：(a) 他的MAP；(b) 相当于30 mL/kg的液体量；(c) 他的动脉血氧含量。
::: solution
(a) $\text{MAP} \approx 42 + (84-42)/3 = 42 + 14 = 56$ mmHg，低于目标65。

(b) $30 \times 70 = 2100$ mL。这是最初3小时内分次冲击并逐次再评估的上限，而不是不管情况如何都要输完的量。

(c) $C_a\mathrm{O_2} = 1.34 \times 10 \times 0.88 + 0.0225 \times 7.0 = 11.79 + 0.16 = 11.95$ mL/dL。正常值约为20 mL/dL。贫血和低氧血症都降低了氧输送；给氧使饱和度达到94%–98%（对有高碳酸血症风险者目标更低），比对溶解氧这一项做任何处理都更能改善氧输送。
:::
:::

### 选择第一种抗生素

第一种抗生素是**经验性的**：在病原体明确之前，根据可能的感染源、可能的病原体、本地耐药情况、患者的过敏史和近期抗生素使用史来选择。在48–72小时内，培养结果使抗生素得以降阶梯（**目标治疗**）。

::: definition 按感染源的经验性治疗 {#def-templates}
**经验性方案**是能覆盖某一宿主某一部位最可能致病微生物的抗生素选择。成人的典型感染源和病原体：

| 感染源 | 常见病原体 | 经验性选择的原则 |
|---|---|---|
| 社区获得性肺炎 | 肺炎链球菌（*Streptococcus pneumoniae*）、流感嗜血杆菌（*Haemophilus influenzae*）、非典型病原体（*Mycoplasma*、*Legionella*） | 按严重程度（CURB-65）选择；β-内酰胺类，较重者加大环内酯类或多西环素以覆盖非典型病原体 |
| 泌尿道感染/肾盂肾炎 | 大肠埃希菌（*Escherichia coli*）及其他肠杆菌目细菌、肠球菌（*Enterococcus*） | 根据本地耐药情况覆盖革兰氏阴性菌；考虑ESBL风险 |
| 腹腔内和胆道感染 | 肠杆菌目细菌、厌氧菌、肠球菌 | 覆盖革兰氏阴性菌和厌氧菌，并控制感染源 |
| 皮肤软组织感染 | 化脓性链球菌（*Streptococcus pyogenes*）、金黄色葡萄球菌（*Staphylococcus aureus*） | 抗链球菌和抗葡萄球菌的β-内酰胺类；有MRSA定植者覆盖MRSA |
| 脑膜炎 | 肺炎链球菌、脑膜炎奈瑟菌（*Neisseria meningitidis*）；老年人和免疫力低下者还有李斯特菌（*Listeria*） | 大剂量第三代头孢菌素；有李斯特菌风险者加阿莫西林 |
| 感染源不明的脓毒性休克 | 以上任何一种 | 按本地脓毒症指南广谱覆盖，尽早降阶梯 |

本地指南把这些原则转化为具体药名，因为各医院和各国的耐药情况不同。
:::

::: example 没有发热的意识混乱老人 {#ex-occult-source}
一名78岁女性因意识混乱两天从家中被送来。体温36.4 °C，脉率每分钟104次，血压98/56 mmHg，呼吸频率每分钟24次。双肺清，尿试纸白细胞微量。血液检查：白细胞计数17 × 10⁹/L，胆红素58 µmol/L，碱性磷酸酶410 U/L，ALT 160 U/L，肌酐150 µmol/L（基线80），乳酸3.4 mmol/L。触诊右上腹时她有痛苦表情。

这是尿路感染吗？感染源是什么？除了抗生素，处理还需要什么？
::: solution
尽管体温正常，**脓毒症是存在的**：新出现的意识混乱、呼吸急促、相对低血压、乳酸升高和急性肾损伤（肌酐几乎翻倍）。

**尿液结果是干扰项。** 无症状菌尿和尿试纸白细胞阳性在老年女性中很常见，不能解释这一临床表现。贴上“尿路感染”的标签会漏掉真正的感染源。

**感染源是胆道。** 胆汁淤积型肝功能异常伴胆红素升高、右上腹压痛和脓毒症，提示**急性胆管炎**，通常由结石阻塞胆总管引起。发热、黄疸和右上腹痛的经典三联征在老年人中常不完整。

**处理。** 留取血培养，然后按本地指南给予覆盖肠杆菌目细菌和厌氧菌的抗生素；液体复苏并再评估；紧急超声检查有无胆管扩张；以及作为感染源控制的**胆道引流**（通常行ERCP）。不引流，单用抗生素常常失败。
:::
:::

## 第一小时之后

### 解读结果

**血培养**通常在12–48小时内报阳。革兰氏染色提供第一条线索（成簇的革兰氏阳性球菌提示葡萄球菌；革兰氏阴性杆菌提示肠杆菌目细菌或假单胞菌（*Pseudomonas*）），随后是菌种鉴定和药敏结果。快速分子方法可以进一步缩短时间（[[microbiology/laboratory-diagnosis]]）。

并非每个阳性培养都是真的。**凝固酶阴性葡萄球菌**、皮肤杆菌（*Cutibacterium*）和类白喉杆菌在多套培养中只有一瓶阳性时，通常是皮肤污染菌。同一病原体在多套培养中生长、报阳时间短，或患者体内有人工植入物，则真正感染的可能性更大。血培养中的金黄色葡萄球菌**绝不能**当作污染菌而忽视。

**炎症标志物**（C反应蛋白、降钙素原）可以支持但不能确立诊断。它们的主要价值在于观察趋势，并帮助决定何时停用抗生素。

### 48–72小时评估

每一张抗生素处方都要在48–72小时结合检查结果进行评估。可选的处理是：**停用**（无感染，或另有诊断）、由静脉**转换**为口服、**更换**为窄谱药物、**继续**并确定疗程，或转为门诊胃肠外抗生素治疗。这就是英国的“明智开始，然后聚焦”（Start smart, then focus）方法，在[[infectious-diseases/stewardship-outbreaks]]中进一步展开。试验一再显示较短的疗程对许多感染有效；例如，对于许多医院血流感染，7天疗程不劣于14天（BALANCE试验，2024年；金黄色葡萄球菌菌血症被排除在外）。

### 培养阴性的脓毒症与类似疾病

相当一部分脓毒症患者的培养为阴性，常常是因为先用了抗生素。在接受“培养阴性脓毒症”之前，要考虑看起来与之相似的疾病：

- **非感染性炎症**：急性胰腺炎、大面积烧伤、严重创伤、血管炎、成人斯蒂尔病。
- **心血管疾病**：肺栓塞、心肌梗死伴心源性休克、主动脉夹层。
- **内分泌和代谢疾病**：肾上腺危象、甲状腺危象、糖尿病酮症酸中毒。
- **药物和毒物**：药物热、DRESS（药物反应伴嗜酸性粒细胞增多和系统症状）、5-羟色胺综合征、神经阻滞剂恶性综合征、水杨酸中毒、酒精戒断。
- **严重过敏反应**和**输血反应**。
- **恶性肿瘤**，尤其是淋巴瘤，以及噬血细胞性淋巴组织细胞增多症。

::: example 术后发热 {#ex-wind-water-wound}
一名64岁男性因癌症行右半结肠切除术。术后第1天体温38.1 °C，未经治疗即消退。第5天体温骤升至38.9 °C，腹部压痛加重，脉率升至每分钟115次，白细胞计数21 × 10⁹/L。起病的时间如何指导思路？最可能的原因是什么？
::: solution
**时间是有用的线索。** 大手术后最初48小时内的发热通常是对组织损伤的炎症反应的一部分，常常不经治疗即消退，正如本例第1天那样。大约从第3天起，感染的可能性增大：肺炎、与导尿管相关的尿路感染以及静脉导管感染。大约第5–7天，典型的是**吻合口瘘**、腹腔内脓肿和切口感染。第一周之后，还要考虑静脉血栓栓塞、药物热和艰难梭菌感染。学生用的英文助记词“wind, water, wound, walking, wonder drugs”（肺、尿、切口、静脉血栓、药物）涵盖了这些来源，但时间段有重叠。

**本例患者**在肠吻合术后第5天出现新的发热、腹部压痛加重和心动过速。必须首先排除**吻合口瘘**。他需要脓毒症评估、血培养、广泛覆盖革兰氏阴性菌和厌氧菌的抗生素、紧急腹部增强CT以及尽早的外科评估，因为吻合口瘘需要**感染源控制**（引流或再次手术）。只检查他的胸部和尿液，就有漏掉外科急症的风险。
:::
:::

::: history
现代的脓毒症概念还很年轻。1991年，罗杰·博恩（Roger Bone）主持的一次共识会议将脓毒症定义为感染加上**全身炎症反应综合征**（SIRS）。2001年的修订增加了更多体征，但保留了这一概念。2001年，伊曼纽尔·里弗斯（Emanuel Rivers）等报告，在一个急诊科中，采用中心静脉监测、按方案进行的“早期目标导向治疗”降低了死亡率。这塑造了此后十年的脓毒症救治，直到三项大型试验——ProCESS（美国，2014年）、ARISE（澳大拉西亚，2014年）和ProMISe（英国，2015年）——发现它并不优于常规治疗。到那时，常规治疗本身已经改善：集束化治疗中真正起作用的是早期识别、早期抗生素和充分复苏。2016年，由默文·辛格（Mervyn Singer）和克利福德·多伊奇曼（Clifford Deutschman）主持的第三次国际共识定义（Sepsis-3）把定义的重心从炎症转向器官功能障碍。2017年，世界卫生大会通过决议，把脓毒症列为全球卫生优先事项。
:::

::: quiz
根据Sepsis-3定义，哪位患者为**脓毒性休克**？
- [ ] 肺炎患者，体温39.5 °C，脉率每分钟120次，白细胞计数18 × 10⁹/L
- [ ] 肾盂肾炎患者，输注1升晶体液后血压由85/50升至112/68 mmHg
- [x] 胆管炎患者，液体复苏后需要去甲肾上腺素才能维持MAP 65 mmHg，乳酸4.1 mmol/L
- [ ] 蜂窝织炎患者，乳酸2.5 mmol/L，血压正常
::: solution
脓毒性休克**同时**要求：需要血管加压药才能维持MAP 65 mmHg或以上，**并且**经充分补液后乳酸仍高于2 mmol/L。第一位患者符合旧的SIRS标准，但没有描述器官功能障碍。第二位对补液有反应，不需要血管加压药。第四位乳酸升高，可能有脓毒症，但没有休克。
:::
:::

## 后续内容

休克的生理学和液体选择在[[emergency-critical-care/shock-fluids]]中展开，器官支持在[[emergency-critical-care/critical-care]]中讨论。免疫力低下者的感染（包括中性粒细胞减少性脓毒症）见[[infectious-diseases/immunocompromised-host]]。与医疗器械和住院相关的感染见[[infectious-diseases/healthcare-infections]]。如何选择、评估和停用抗生素见[[infectious-diseases/stewardship-outbreaks]]，药物本身见[[microbiology/antimicrobials]]。发热的归国旅行者见[[infectious-diseases/tropical-infections]]。

::: summary
- 发热是由IL-1、IL-6、TNF和前列腺素E₂驱动的下丘脑调定点升高；过热是调定点正常而散热失败。
- 发热患者分两步评估：先看病得多重（ABCDE、NEWS2、危险信号），再找感染在哪里（病史、暴露、宿主、器械、查体）。
- 脓毒症（Sepsis-3）是由对感染的反应失调所引起的危及生命的器官功能障碍，以SOFA评分升高2分或以上衡量。脓毒性休克还需要血管加压药才能维持MAP 65 mmHg，且补液后乳酸仍高于2 mmol/L。
- 体温正常、血压看似正常或尿试纸阴性都不能排除脓毒症。
- 初始处理：留取培养，按风险分级尽早给予抗生素（最高风险者1小时内），分次冲击补液并再评估，持续低血压时用去甲肾上腺素，尽早控制感染源。
- 在48–72小时评估抗生素：停用、转换、降阶梯或确定疗程。培养阴性时要考虑脓毒症的类似疾病。
:::

## 习题

::: exercise 平均动脉压 {level=1 check="60"}
一位患者的血压为88/46 mmHg。用 MAP ≈ DBP + (SBP − DBP)/3 估算平均动脉压（mmHg）。
::: solution
$\text{MAP} \approx 46 + (88-46)/3 = 46 + 14 = 60$ mmHg。低于通常的目标65 mmHg。
:::
:::

::: exercise qSOFA评分 {level=1 check="2"}
一名55岁蜂窝织炎男性，呼吸频率每分钟24次，血压108/66 mmHg，脉率每分钟112次，体温38.6 °C，新出现时间定向障碍。他的qSOFA评分是多少？
::: solution
呼吸频率22次及以上：1分。意识改变：1分。收缩压100 mmHg及以下：否（108）。脉率和体温不属于qSOFA。评分为**2**，提示不良结局风险较高，应促使寻找器官功能障碍。评分低于2也不能排除脓毒症。
:::
:::

::: exercise 液体量 {level=1 check="1920"}
一名体重64 kg的女性患脓毒性休克，乳酸5 mmol/L。30 mL/kg晶体液相当于多少mL？
::: solution
$30 \times 64 = 1920$ mL。实践中是分次冲击给予，每次之后再评估灌注和液体过负荷的体征，而不是一次输入一个固定的量。
:::
:::

::: exercise 四瓶中的一瓶 {level=2}
一名因卒中入院的70岁男性体温升至37.9 °C。留取了两套血培养。40小时后，四瓶中的一个需氧瓶生长出凝固酶阴性葡萄球菌。他体内没有静脉导管，也没有人工植入物，现在已不发热。一位低年资医生建议开始使用万古霉素（vancomycin）。你的建议是什么？
::: hint
想一想是哪种细菌、有几瓶阳性、报阳用了多长时间，以及宿主体内有什么植入物。
:::
::: solution
这几乎肯定是**污染菌**。凝固酶阴性葡萄球菌是皮肤共生菌；四瓶中仅一瓶生长、报阳时间长、患者没有导管或人工植入物、也没有持续发热，符合静脉穿刺时的污染。万古霉素只会增加毒性、费用和耐药压力而没有益处。建议是不予治疗，对患者进行临床复查，只有在他病情变差时才复查培养。如果他有人工心脏瓣膜、起搏器或中心静脉导管，或者同一细菌在多套培养中生长，答案就会不同。
:::
:::

::: exercise 氧输送 {level=2 check="round(1.34*8*0.9*60 + 0.0225*8*60)"}
一位患者血红蛋白8 g/dL，$S_a\mathrm{O_2}$ 0.90，$P_a\mathrm{O_2}$ 8 kPa，心输出量6 L/min。用[[#thm-delivery]]计算氧输送（mL/min），四舍五入到整数。
::: solution
$C_a\mathrm{O_2} = 1.34 \times 8 \times 0.90 + 0.0225 \times 8 = 9.648 + 0.18 = 9.828$ mL/dL。

$\dot{D}\mathrm{O_2} = 6 \times 9.828 \times 10 = 589.68 \approx 590$ mL/min。正常静息值约为1000 mL/min。这里的不足大部分来自低血红蛋白和低饱和度，而不是心输出量。
:::
:::

::: exercise 第6天的腹泻 {level=2}
一名72岁女性因胸部感染静脉使用阿莫西林-克拉维酸（co-amoxiclav）第6天。她出现每天6次水样腹泻，体温38.2 °C，白细胞计数19 × 10⁹/L。最可能的诊断是什么？如何确诊？处理的第一步是什么？
::: solution
最可能的诊断是**艰难梭菌（*Clostridioides difficile*）感染**，由扰乱结肠菌群的广谱抗生素诱发。确诊方法是检测液状粪便标本：先做筛查试验（谷氨酸脱氢酶抗原或毒素基因PCR），再做毒素检测。第一步处理：将她安置在单人间，采取肠道隔离措施，用肥皂和流动水洗手（酒精凝胶不能杀灭芽孢）；评估并尽可能停用阿莫西林-克拉维酸；尽可能停用减慢肠蠕动或抑酸的药物；评估脱水情况和严重程度（白细胞计数高于15 × 10⁹/L为重症）；开始口服万古霉素，这是英国指南中的一线治疗。详见[[infectious-diseases/healthcare-infections#def-cdiff]]。
:::
:::

::: exercise 卫生棉条之后的休克 {level=3}
一名23岁女性在月经第3天就诊，体温39.8 °C，呕吐、腹泻，全身弥漫性晒伤样红疹，血压78/40 mmHg，意识混乱。血小板70 × 10⁹/L，肌酐210 µmol/L。请给出鉴别诊断和最可能的诊断，并解释为什么抗生素方案与标准的脓毒症治疗不同。
::: hint
哪些细菌产物起超抗原作用？抗生素如何能减少毒素的产生？
:::
::: solution
**鉴别诊断**：脑膜炎球菌败血症、其他来源的链球菌中毒性休克、革兰氏阴性菌脓毒症、严重药物反应，以及伴休克的病毒性疾病。

**最可能的诊断**：**葡萄球菌中毒性休克综合征**，与残留或高吸收性卫生棉条有关。金黄色葡萄球菌产生中毒性休克综合征毒素-1，这是一种**超抗原**，它在正常抗原结合槽之外交联MHC II类分子和T细胞受体，一次激活全部T细胞中的很大一部分，释放细胞因子风暴。结果是发热、弥漫性红皮病（之后手掌和足底脱屑）、低血压和多器官衰竭。

**处理**包括取出卫生棉条（感染源控制）、复苏，以及能杀灭细菌的抗生素**加上克林霉素（clindamycin）等蛋白质合成抑制剂**。克林霉素能减少已不再快速分裂的细菌产生毒素，而单用作用于细胞壁的药物做不到这一点。重症病例有时使用静脉注射免疫球蛋白中和毒素。同样的逻辑适用于链球菌中毒性休克和坏死性筋膜炎（[[infectious-diseases/healthcare-infections]]）。
:::

::: exercise 计算SOFA评分 {level=3 check="9"}
一名60岁腹膜炎男性：呼吸空气（FiO₂ 0.21）时PaO₂ 10.5 kPa；血小板90 × 10⁹/L；胆红素40 µmol/L；未用血管加压药时MAP 68 mmHg；格拉斯哥昏迷评分14；肌酐180 µmol/L。假定他的基线SOFA评分为0。使用以下SOFA分级：呼吸（PaO₂/FiO₂）低于53.3 kPa = 1；血小板低于150 = 1，低于100 = 2；胆红素20–32 = 1，33–101 = 2；MAP低于70 mmHg = 1；GCS 13–14 = 1；肌酐110–170 = 1，171–299 = 2。他的SOFA总分是多少？他是否符合Sepsis-3的脓毒症标准？
::: solution
呼吸：$\text{PaO}_2/\text{FiO}_2 = 10.5/0.21 = 50$ kPa，低于53.3：**1**。血小板90：**2**。胆红素40：**2**。未用血管加压药时MAP 68：**1**。GCS 14：**1**。肌酐180：**2**。

总分$= 1 + 2 + 2 + 1 + 1 + 2 = 9$。较基线升高9分，远超2分的阈值，因此他患有累及多个器官的**脓毒症**。按定义他不属于脓毒性休克，因为他不需要血管加压药，但他需要紧急复苏、抗生素和外科感染源控制。
