在医学中很少有领域像感染与脓毒症这样早期识别如此有回报：**微生物常常是普通的、综合征是可重复的、而好结局与坏结局之间的差别通常以适当抗生素与源头控制及复苏的小时数来衡量、而不是以聪明的诊断来衡量。**本章是整个感染性疾病课程的急性内科脊柱、也是每一次急诊轮转中最先被读到的一章。

本章涵盖发热患者与脓毒症综合征、它的复苏、溯源、及使每条规则变形的模仿者与修正因素。

## 发热患者

::: definition 发热与它的即时问题 {#def-fever}
**生理学（致热细胞因子的级联——固有髓系细胞的白介素1与白介素6及肿瘤坏死因子、通过前列腺素信号重设下丘脑的调定点、发热与寒战的机制、及出汗退热的阶段、与[[pathology/acute-inflammation]]的血管与细胞脚本及[[physiology/homeostasis-body-fluids]]的恒温器算术对照阅读；仍然有用的热型词汇——持续、间歇、复发、每日、及周期热——及在抗生素与退热药时代读热型的诚实局限；及作为一个有定义问题的发热待查——三周、三次门诊或一周住院、及那个隐匿感染与恶性肿瘤及炎症性疾病的三匹马诊断清单、在高龄者中带颞动脉炎与成人Still病及隐匿脓肿的加权——[[musculoskeletal/connective-tissue-vasculitis]]、[[blood/lymphoma-myeloma]]、[[infectious-diseases/tuberculosis]]）。即时的评估（“病重还是还好”的判断作为第一个诊断动作、及早期预警评分作为分诊的语言而非诊断标准；发热患者的ABCDE方法与那个需要液体或升压药的低血压、及那个需要葡萄糖与硫胺素及氧气的意识障碍——[[emergency-critical-care/acute-assessment]]、[[emergency-critical-care/resuscitation]]；及在数分钟内改变鉴别的暴露史——旅行与水及动物及咬伤及性行为及药物使用及职业及饮食及手术及器械史——[[clinical-skills/history-taking]]、[[infectious-diseases/tropical-infections]]）。特殊的热（中性粒细胞减少发热作为一个一小时内给抗生素的急症、带它自己的方案逻辑、及导管与肠及肺的来源思维——[[immunology/immunodeficiency]]、[[blood/leukaemia]]、[[infectious-diseases/immunocompromised-host]]；假体关节与瓣膜及器械的发热、那里的微生物是熟练的生物膜居民、而溯源意味着影像与多套血培养、先于经验性用药摧毁阳性率——假体的感染见[[musculoskeletal/fractures]]、[[cardiovascular/valve-congenital-disease]]、[[infectious-diseases/healthcare-infections]]；在恰当临床背景下总是查HIV总是做培养、及归国旅行者中总是想疟疾的规则、带当日厚薄血涂片或快速抗原检测——[[infectious-diseases/hiv]]、[[infectious-diseases/tropical-infections]]；及非感染的冒名者——药物热与肿瘤热及静脉血栓及酒精戒断及导管冲管及做作的模式——[[pharmacology/adverse-reactions]]、[[blood/thrombosis-anticoagulation]]）。**
:::

::: example 皮疹与小时钟 {#ex-meningococcus}
一名19岁学生被送来时意识障碍、呕吐、四肢冰冷、伴不褪色的紫癜皮疹；血压82/40、心率138、膝部花斑、毛细血管再充盈5秒、乳酸6.8；六小时前全科医生在电话里说“病毒性”。
::: solution
**在证明之前就是脑膜炎球菌脓毒症、并按脑膜炎路径以分钟而非小时治疗（[[#def-sepsis]]、[[microbiology/bacteria]]）：第一小时的Bundle——ABCDE与高流量氧、两处粗针通路或骨内、伴再评估的静脉液体冲击、及静脉抗生素、不要等腰穿或培养或断层、按本地的脑膜炎指导紧急给青霉素或头孢曲松、若怀疑细菌性脑膜炎则加地塞米松、及通知公共卫生团队为接触者做化学预防——脑膜炎部分见[[nervous-system/neuroinflammation]]、[[public-health/communicable-disease-control]]、[[microbiology/antimicrobials]]；并行的升级通道——高级医师复苏与重症监护、对液体难治的休克用升压药、对难治性休克用氢化可的松、及考虑入院时的出血与暴发性紫癜、及血制品与植皮的远期——[[emergency-critical-care/shock-fluids]]、[[emergency-critical-care/critical-care]]、[[blood/haemostasis-bleeding]]、[[musculoskeletal/skin]]；治疗开始之后妥善完成的诊断残留——安全时的血培养与腰穿及聚合酶链、及咽部携带状态、及一次重症侵袭性病例之后的补体与切脾的免疫学问题——[[clinical-skills/laboratory-tests]]、[[immunology/immunodeficiency]]、[[nervous-system/neuroinflammation]]；及那通六小时前全科电话的后续——诚实义务、与从可避免死亡复盘中学习、及对不褪色皮疹的安全网标准、及每一例对公众与媒体教育的价值——[[clinical-skills/patient-safety]]、[[clinical-skills/records-handover]]、[[public-health/prevention-promotion]]。**

## 脓毒症

::: definition 脓毒症综合征与它的最初数小时 {#def-sepsis}
**定义与生物学（脓毒症作为由宿主对感染的失调反应造成的危及生命的器官功能障碍、带器官衰竭评分的差值算术、及快速器官衰竭与全身炎症反应及危重评分的分诊现实、及从识别到抗生素之间的存活差距以每小时死亡的增量被测量——炎症溢流的病理生理——内皮病与微血管血栓及线粒体休眠及儿茶酚胺抵抗——建立在[[pathology/acute-inflammation]]、[[cell-biochemistry/metabolic-integration]]的细胞能量一行、及[[immunology/innate-immunity]]的免疫机制之上）；诚实形态的六小时Bundle（测乳酸并重复它、在给药前取血培养但绝不因此把抗生素拖过这段时间、在一小时内给予广谱的经验性抗生素、由综合征与本地耐药模式塑形、及对低血压或乳酸不低于4时给予每千克30毫升晶体、并反复评估反应性与危险——液体的种类与伤害的极限见[[emergency-critical-care/shock-fluids]]与[[renal/acute-kidney-injury]]；升压药以维持约65的平均动脉压、早期的去甲肾上腺素优于多巴胺、并考虑加用血管加压素、对难治性休克给应激剂量的氢化可的松——[[emergency-critical-care/critical-care]]、[[endocrine/adrenal]]；及这个“起始要广”的抗生素管理——在48-72小时按培养与临床反应降阶梯、并刻意地选择口服转换——[[microbiology/antimicrobials]]、[[infectious-diseases/stewardship-outbreaks]]）。来源、来源、来源（必须与Bundle同时进行的搜寻——尿路与肺及皮肤及导管及腹部及中枢及关节及牙科及器械的模板、及为隐匿腹部来源的增强断层、及胆道与盆腔及脓胸问题的超声、及外科与介入放射的引流决定、因为单靠抗生素打不赢一个未引流的积聚——胆管炎见[[gastrointestinal/pancreas-biliary]]、[[renal/urinary-tract]]、脓胸见[[respiratory/lung-cancer-pleura]]、[[surgery/acute-abdomen]]、[[clinical-skills/medical-imaging]]、损伤控制见[[emergency-critical-care/critical-care]]）；及使每条规则变形的修正因素无发热、以谵妄作为唯一信号的高龄与衰弱者——[[geriatrics-palliative/delirium-dementia-care]]；掩盖脓与微生物的免疫抑制者——[[immunology/immunodeficiency]]、[[infectious-diseases/immunocompromised-host]]；使查体与通路更困难的肥胖与水肿；那个每千克30毫升对他们像悬崖的心衰与慢性肾病患者、及小量滴定冲击加乳酸及灌注轨迹的哲学——[[cardiovascular/heart-failure]]、[[renal/chronic-kidney-disease]]；左侧倾斜复苏并考虑产科来源的孕妇——[[obstetrics-gynaecology/pregnancy-complications]]；及那个必须通过照护目标的谈话而非反射来过滤Bundle的不施行心肺复苏与治疗上限的患者——[[geriatrics-palliative/end-of-life-care]]、[[medical-ethics-law/consent-capacity]]。**
:::

::: example 那次其实是足部的意识障碍 {#ex-occult-source}
一名80岁糖尿病患者因“不是平时的她”被送来——无热、血压96/54、心率104、呼吸24、乳酸3.6、尿试纸清亮；她的脚裹着绷带“因为鸡眼”、而家人提到两周前有一个黑的趾甲。
::: solution
**带着那个靠脱光衣服才找到来源的脓毒症——在证明之前就是糖尿病足（[[#def-sepsis]]、[[endocrine/diabetes-complications]]）：脱衣的原则——无热、完整的查体、每个孔道每个器械每个绷带、及足部的神经缺血分类、及探针触骨、及隐匿足底积聚的搜寻——[[clinical-skills/physical-examination]]、神经病变见[[nervous-system/motor-systems]]；综合征的Bundle——培养、及为混合的糖尿病足与严重度及近期抗生素及耐药菌风险塑形的广谱经验覆盖、及为骨髓炎与产气及深间隙走行的影像——[[microbiology/bacteria]]、[[clinical-skills/medical-imaging]]；源头控制的现实——抗生素无法灭菌死骨或未引流的脓肿、及在清创与血运重建及截肢之间的血管外科与足病及骨科的分诊、谈话要早做、而不是第二周之后、及休克加深时的重症监护重叠——[[surgery/vascular-urological-surgery]]、[[surgery/orthopaedics]]、[[emergency-critical-care/critical-care]]；及决定她这一个月的次要问题——糖化血红蛋白与随访及鞋具及趾甲护理的计划、及为造影与容量决定的心血管与肾复审、及与糖尿病团队一起诚实完成的照护目标与保肢还是保命的谈话——[[endocrine/diabetes-complications]]、[[geriatrics-palliative/polypharmacy]]、[[clinical-skills/communication]]、[[medical-ethics-law/consent-capacity]]。**
:::
:::

::: example 术后第三天的发热 {#ex-wind-water-wound}
因穿孔性憩室炎急诊开腹后第3天、一名67岁患者突发39.1、心率114；切口一角轻度红斑、肺清、尿检见12个白细胞且留置导尿管、而引流液变浑浊；她自手术起在用阿莫西林克拉维酸与甲硝唑。
::: solution
**正确地跑一遍外科发热的分类——肺、尿、伤口、行走、可疑药物、以及此处真正重要的那个：腹部（[[#def-templates]]、[[surgery/gastrointestinal-surgery]]）：在第三天、肺不张与肺炎及导管及深静脉血栓的问题是真的、但在穿孔之后浑浊的引流液在断层说话之前就是吻合口或积聚的问题——带造影的断层区分局限性积聚对弥漫腹膜炎对缺血、及那位上级外科医师的重新查体、而不是低年资医师的抗生素升级反射——[[clinical-skills/medical-imaging]]、[[surgery/acute-abdomen]]；综合征的Bundle——从血与尿及伤口及引流液、及有指征时的呼吸道采样、及重复乳酸与全血细胞及肾功能、及对肠源性微生物在耐药背景下复审抗生素的充分性、及CT引导引流对重返手术室的决定——[[microbiology/bacteria]]、[[microbiology/laboratory-diagnosis]]、[[emergency-critical-care/critical-care]]；不要漏掉的模仿者——药物热与导管感染及艰难梭菌这个附带损害、及发热的重症患者中艰难梭菌与无水结石性胆囊炎的附带检查——[[gastrointestinal/bowel-disease]]、[[gastrointestinal/pancreas-biliary]]；及升级的诚实——把“源头控制优先”的论证清晰地告诉病房团队、及当再次开腹本身带有死亡率时进行一次目标的复审、及在48-72小时记录在案的抗生素限时——[[surgery/perioperative-care]]、[[infectious-diseases/stewardship-outbreaks]]、[[medical-ethics-law/consent-capacity]]。**
:::

## 模仿者、综合征与系统

::: definition 综合征的模板 {#def-templates}
**脑膜炎与中枢感染（头痛-发热-颈强-畏光的理由、带那个“紫癜性脑膜炎球菌脓毒症不需要脑膜刺激征”的皮疹与休克的警诫、及免疫缺陷与新生儿及60岁以上者的李斯特菌覆盖清单、及“只在特定指征时才先做断层再腰穿”的规则、及肺炎球菌与b型流感嗜血杆菌的地塞米松证据、及结核性脑膜炎与HIV共感染的慢性化、带它自己的脑积水与梗死命运、及脑炎：单纯疱疹要经验性治疗、早期给阿昔洛韦、以人格改变与癫痫及嗅幻觉作为线索——[[nervous-system/neuroinflammation]]、[[infectious-diseases/hiv]]、[[infectious-diseases/immunocompromised-host]]）；肺炎（按严重度分层的门诊对住院对危重路径、带严重度评分的现实、及非典型与军团菌及病毒后葡萄球菌及误吸的风味、及旁肺炎积液与脓胸的引流反射、及“不要常规复查胸片”的规则——[[respiratory/respiratory-infections]]、[[respiratory/lung-cancer-pleura]]、[[microbiology/bacteria]]）；尿路与腹腔的模板（梗阻造成的尿路脓毒症、紧急减压、经皮肾造瘘或支架的决定、及胆管炎的小时钟与内镜时代的逻辑、及阑尾炎与穿孔及憩室及肠缺血“手术就是抗生素”的模板——[[renal/urinary-tract]]、[[gastrointestinal/pancreas-biliary]]、[[gastrointestinal/bowel-disease]]、[[surgery/acute-abdomen]]、[[surgery/gastrointestinal-surgery]]）；血管内与器械的感染（感染性心内膜炎的诊断标准逻辑、与那段延长静脉或口服降阶梯的抗生素马拉松、及针对心衰与脓肿及持续菌血症及金黄色葡萄球菌的早期外科讨论指征、及导管感染诊断的配对、带差异阳性时间、及保留对拔除的决定、及假体关节与移植物的关联——[[cardiovascular/valve-congenital-disease]]、[[infectious-diseases/healthcare-infections]]、假体关节感染见[[surgery/orthopaedics]]）；及骨、关节与皮肤的模板（化脓性关节炎的当日冲洗、及骨髓炎的延长、按培养定向的治疗、及坏死性筋膜炎的“疼痛程度不符、中毒、外科医师现在就来”的规则、及艰难梭菌与中性粒细胞减少性小肠结肠炎及中毒性巨结肠的领地——化脓性关节见[[musculoskeletal/bones-joints]]、[[surgery/orthopaedics]]、[[microbiology/bacteria]]、[[gastrointestinal/bowel-disease]]、[[surgery/gastrointestinal-surgery]]）。**

::: example 抗生素之后的腹泻 {#ex-cdiff}

**艰难梭菌感染、重度、接近复杂性——仍在增长的医源性流行（[[#def-templates]]、[[gastrointestinal/bowel-disease]]、[[microbiology/bacteria]]）：严重度分级与检测的算法——粪便毒素与谷氨酸脱氢酶或核酸扩增、带预先形成的毒素检测、及“不成形的粪便不要测、也不要拭子”的规则、及乳酸与肌酐及白蛋白及白细胞的严重度列、及低血压与肠麻痹及巨结肠与腹膜炎的复杂性标志——[[clinical-skills/laboratory-tests]]、[[gastrointestinal/clinical-nutrition]]；现在的治疗集——若临床可能则停用诱发的抗生素、并按现行指导开始口服万古霉素或非达霉素、及在肠麻痹时考虑直肠万古霉素加静脉甲硝唑、及针对复杂性疾病的早期外科与重症共管、带结肠切除对转流性回肠造口的决定、及液体电解质与血栓预防及营养支持——[[microbiology/antimicrobials]]、[[surgery/gastrointestinal-surgery]]、[[emergency-critical-care/critical-care]]、[[blood/thrombosis-anticoagulation]]；感染控制的反射——接触隔离、及用流水与皂而不是手消液因为芽胞、及单间或定住肠道感染的房间、及用杀芽胞剂的环境清洁、及通知微生物与感染控制团队的病房暴发阈值——[[infectious-diseases/healthcare-infections]]、[[microbiology/infection-control]]、[[infectious-diseases/stewardship-outbreaks]]；及以预防为纲的账本——产生这个病例的抗生素管理审计、及非达霉素与贝洛度尤单抗及粪菌移植证据的复发策略、及院内传播链的测绘、及对她质子泵抑制剂与缓泻剂背景的药物复审——[[infectious-diseases/stewardship-outbreaks]]、炎症性肠病的模仿见[[gastrointestinal/bowel-disease]]、[[microbiology/microbiota]]。**

## 宿主决定剧本

两个带相同微生物的患者可能需要相反的医学、因为感染是微生物与宿主之间的谈判。糖尿病足、腹水感染的肝硬化患者、在数小时内被有荚膜微生物压垮的无脾患者、肾系统梗阻而感染的肾病患者、产褥脓毒症的女性、被酒精性酮症酸中毒掩盖腹部灾难的男性、以及以尿毒症脓毒症唯一表现是谵妄的老年人——他们教的都是同一句话：先问这具身体能与不能做什么、再问这具身体藏着什么来源（[[immunology/immunodeficiency]]、[[endocrine/diabetes-complications]]、[[gastrointestinal/liver-disease]]、[[renal/urinary-tract]]、[[obstetrics-gynaecology/pregnancy-complications]]、[[geriatrics-palliative/delirium-dementia-care]]、[[renal/acid-base-disorders]]）。同样的原则支配着永远找不到微生物的发热：中性粒细胞减少与药物修饰的宿主培养阴性、是因为抗生素或时机或挑剔的微生物在合谋、而正确的回应是更好的溯源与影像、有时是无论如何都治疗这个综合征、而不是在两瓶无菌之后放弃诊断（[[microbiology/laboratory-diagnosis]]、[[clinical-skills/medical-imaging]]）。

## 康复之后：去向与后遗症

决定一个脓毒症患者在哪里被照护、是一个带着生存率的临床决定。需要重症监护的是需要升压药、呼吸衰竭、意识改变、酸中毒清除失败、或需要一个立即干预来源的患者；在普通病房死去的、不成比例地是周五下午四点钟“看起来没那么糟”的人、这就是为何升级的标准、观察的频率与上级医师到场的阈值必须被写下来、被教学、被遵守、而不是临场发挥（[[emergency-critical-care/critical-care]]、[[clinical-skills/patient-safety]]）。同样、存活下来的患者需要一个命名的出院身份、因为“脓毒症后”是一种真实的综合征——疲乏、认知迷雾、肌病与神经病、新发或加重的肾功能、与创伤后应激及抑郁及焦虑无法区分且常常共病的精神后遗症、以及随后可测量地增加的再感染与心血管事件风险。因此好的服务在交接时会给出一份书面的脓毒症摘要、一个药物与器官随访的计划、对那些没人问就没人查的心理后遗症的筛查、及一次关于复发风险与何时再诊的坦率谈话——最后这一句是最可能预防下一次“一小时延迟”的话（[[psychiatry/mood-disorders]]、[[psychiatry/anxiety-disorders]]、[[renal/chronic-kidney-disease]]、[[clinical-skills/records-handover]]、[[public-health/prevention-promotion]]）。在侵袭性疾病之后接种肺炎球菌与流感、以及在有指征时接种脑膜炎球菌与流感嗜血杆菌、是这次住院的收尾动作、而且常常是那个从未发生的动作（[[public-health/vaccination-programmes]]、[[immunology/immunodeficiency]]）。

## 通向何处

每个方案背后的微生物、毒力机制与耐药在[[microbiology/bacteria]]与[[microbiology/bacterial-pathogenesis]]与[[microbiology/antimicrobials]]；塑造非典型呈现的宿主缺陷在[[immunology/immunodeficiency]]与[[infectious-diseases/immunocompromised-host]]；复苏的科学在[[emergency-critical-care/shock-fluids]]与[[emergency-critical-care/critical-care]]；抗菌药物的治理在[[infectious-diseases/stewardship-outbreaks]]。

在模板之前有一个用词的警告：定植、感染与疾病这三个词携带着治疗的决定。一名留置导管或高龄患者的无症状阳性尿培养是定植、抗生素通常造成的害多于利；同一株微生物在血流中伴休克则是“一小时治疗”的理由。学会说出你面前是三者中的哪一个——并把它这样写在记录里、好让下一位临床医师不去“治疗一个结果”——是任何病房医师都能练的最高产出的管理技能之一、也是每一次微生物对话的日常内容（[[infectious-diseases/stewardship-outbreaks]]与[[microbiology/laboratory-diagnosis]]）。

**作为移动靶的脓毒症思维：古代的“脓毒症艺术”与19世纪的外科热与产褥热的流行病学——在细菌理论之前的洗手、及那场卫生之战[[medical-ethics-law/research-ethics]]与[[infectious-diseases/healthcare-infections]]；Lister的抗菌外科与它所奠定的院内感染科学；20世纪中叶的休克生理学、与把脓毒症重新定框为一个循环与代谢的综合征；两次共识对全身炎症反应与重度脓毒症及感染性休克的建构、与那场地改变急诊室复苏的目标导向治疗风暴、及随后数个大型试验的泄气、及使“一小时抗生素”成为全球仪式的拯救脓毒症运动的Bundle政治、及2016年把脓毒症重新定义为器官功能障碍并放弃全身炎症反应——[[epidemiology-ebm/randomised-trials]]、[[epidemiology-ebm/systematic-reviews]]、[[public-health/health-systems-economics]]；氢化可的素的荟萃分析与平衡盐溶液对生理盐水的试验——[[endocrine/adrenal]]、[[emergency-critical-care/shock-fluids]]；及从痢疾病房的隔离逻辑、到处方即犯罪的行动主义、及使抗菌药物治理成为世界卫生组织全球行动计划主题的碳青霉烯耐药警报的管理谱系——[[microbiology/antimicrobials]]、[[public-health/global-health]]。**

::: summary
- 发热是一个体征、不是诊断：先评估病容与器官功能、按模板搜寻来源、并让暴露史收窄微生物的清单。
- 脓毒症是时间依赖的器官损伤；Bundle 之所以有效是因为小时数有分量——抗生素、不因此延迟的培养、有测量的液体、早期的去甲肾上腺素、源头控制。
- 溯源是并行的、不是顺序的：脱光衣服、不确定时做影像、并引流或切除抗生素到不了的地方。
- 特殊的宿主会重写呈现——高龄、中性粒细胞减少、免疫抑制、妊娠、带器械——而一次正常体温从未排除严重感染。
- 医源性感染——导管、尿管、抗生素本身——是唯一完全由我们控制的发热；预防与管理是每个脓毒症章节的一部分。
- 幸存者带着一种叫“脓毒症后”的新慢性病出院；出院信、器官随访、心理筛查与疫苗计划是Bundle的组成部分、不是额外的善意。

::: exercise 应用旅行规则 {level=2}
一名34岁患者在没有预防的情况下从撒哈拉以南非洲旅行一个月归来；发热第4天、寒战、头痛与腹泻；而诊所在40分钟后关门、他看起来“有点像流感”。决定并论证。
::: solution
**归国旅行者的发热在证明之前就是疟疾、而疟疾以小时而不是天数杀人（[[#def-fever]]、[[infectious-diseases/tropical-infections]]）：绝不在未检查的情况下让患者回家——同一小时的快速抗原检测与厚薄血涂片、若第一组阴性则每12-24小时重复、及电话呼叫值班的寄生虫学服务、及闭着眼睛也要找的严重度标志：黄疸与意识障碍及出血及酸中毒及肾衰竭及贫血及原虫血症的百分比——[[clinical-skills/laboratory-tests]]、[[renal/acute-kidney-injury]]、[[blood/anaemia]]；松松握住的其他诊断——登革热与伤寒及立克次体及肝炎及虫媒病毒及新冠邻近、及“不要开始经验性氯喹而漏掉严重度检测”这一点——[[microbiology/bacteria]]、[[microbiology/viruses]]；阳性时的路径——单纯型口服青蒿素衍生物对重症型静脉青蒿素、重症监护的领地、及公共卫生的报告、及不能献血的时限——[[emergency-critical-care/critical-care]]、[[blood/transfusion]]、[[public-health/communicable-disease-control]]；及对那间6点关门诊所的系统尸检——那条本该存在的院外疟疾检测路径、及那个事后才学到的行前旅行门诊的教训——[[public-health/health-systems-economics]]、[[public-health/prevention-promotion]]。**

::: exercise 教中性粒细胞减少发热 {level=2}
写下交给每一位化疗患者的一页病房卡：发热意味着什么、该做什么、不该做什么。
::: solution
**那张卡（[[immunology/immunodeficiency]]、[[infectious-diseases/immunocompromised-host]]、[[public-health/health-systems-economics]]）：阈值——一次不低于38的体温、或两次高于37.5的读数、或寒战、或“发热而且很不对劲”也算、及“为什么不能等一次寒战”的解释；行动——无论昼夜拨打指名的肿瘤分诊专线、来就诊采血与尿与胸片、并在一小时内给静脉抗生素、若发热则不要独自开车、及不要自行服抗生素或退热药然后继续堵在车流里；理由——你可能没有脓也没有热型、因为中性粒细胞制造了体征、而常见的微生物是你自己的肠与皮肤与导管——[[microbiology/bacteria]]、[[clinical-skills/patient-safety]]；日常预防的清单——洗手与食品安全及避开生病的接触者及牙刷对剃刀及袜子与园艺及淋浴对盆浴、及口腔护理的常规——[[public-health/prevention-promotion]]；及本地改变了什么——中性粒细胞脓毒症的绿色通道与直接采血培养、及肿瘤科与微生物科之间正午的碰头会、是那张卡成真的原因——[[microbiology/laboratory-diagnosis]]、[[clinical-skills/records-handover]]。**

::: exercise 解读乳酸 {level=2}

::: solution
**乳酸清除是一个反应的生物标志物、不是一个目标、而灌注的终点同样重要（[[#def-sepsis]]、[[emergency-critical-care/shock-fluids]]）：血流动力学稳定下的小幅下降提示复苏不完全、或非低灌注的乳酸贡献者肝的清除与B型机制、或来源未获控制的疾病在继续——[[gastrointestinal/liver-disease]]、[[cell-biochemistry/metabolic-integration]]；下一步——动态地评估液体的反应性被动抬腿或每搏量变异而不是继续盲目冲击、开始去甲肾上腺素而不是追逐毫升、复查乳酸、并为隐匿的来源做影像、及按重症的意见升级血管加压素与氢化可的松——[[emergency-critical-care/critical-care]]、[[clinical-skills/medical-imaging]]、[[endocrine/adrenal]]；及不要做的——不要用碳酸氢盐、或给一个无反应的、通气的、心脏的患者更多液体去治疗一个数字——[[renal/acid-base-disorders]]、[[cardiovascular/heart-failure]]。**

::: exercise 做腰穿的决定 {level=2}
