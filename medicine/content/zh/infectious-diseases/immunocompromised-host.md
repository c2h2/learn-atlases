如今，免疫力低下的人比以往任何时候都多。化疗、器官和干细胞移植、长期使用糖皮质激素，以及越来越多用于类风湿关节炎、炎症性肠病、多发性硬化和癌症的生物制剂，都在挽救生命，也都损害了免疫系统的某一部分。在这些人身上，感染更频繁、表现不典型、进展迅速，而且常由很少困扰健康人的微生物引起。

推理这类感染的关键是问：**免疫系统缺失的是哪一部分？** 中性粒细胞、T细胞、抗体、补体和脾脏各自防御特定的几类微生物，因此了解缺陷就能预测可能的感染、指导经验性治疗，并告诉我们哪些预防用药和疫苗能预防这些感染。第二个问题是**此人现在和过去接触过什么**：多年前获得的病原体，如结核或类圆线虫，可能在免疫力下降时再激活。

本章介绍免疫缺陷及其相应病原体、中性粒细胞减少与中性粒细胞减少性脓毒症、移植后感染，以及与糖皮质激素、生物制剂和脾脏缺失相关的感染。HIV是全球最常见的获得性免疫缺陷，另有专章（[[infectious-diseases/hiv]]）。英国的做法遵循NICE和专科学会的指南；治疗以原则形式描述。

## 缺陷与病原体的对应

::: definition 免疫缺陷及其感染 {#def-defects}
**免疫功能低下宿主**是指由于疾病或治疗而抗感染防御能力降低的人。主要缺陷及其易感病原体：

| 缺陷 | 常见原因 | 典型病原体 |
|---|---|---|
| **中性粒细胞减少**或中性粒细胞功能障碍 | 化疗、白血病、再生障碍性贫血、某些药物 | 革兰氏阴性杆菌（包括假单胞菌（*Pseudomonas*））、金黄色葡萄球菌（*Staphylococcus aureus*）、链球菌；中性粒细胞减少持续时间长时有念珠菌（*Candida*）和曲霉（*Aspergillus*） |
| **细胞介导（T细胞）免疫** | HIV、移植免疫抑制剂、大剂量糖皮质激素、淋巴瘤、某些化疗药物和生物制剂 | 疱疹病毒（HSV、VZV、CMV、EBV）、肺孢子菌（*Pneumocystis*）、隐球菌（*Cryptococcus*）、分枝杆菌、李斯特菌（*Listeria*）、诺卡菌（*Nocardia*）、弓形虫（*Toxoplasma*）、类圆线虫（*Strongyloides*） |
| **抗体（体液）缺陷** | 常见变异型免疫缺陷病、骨髓瘤、慢性淋巴细胞白血病、利妥昔单抗（rituximab） | 有荚膜细菌（肺炎链球菌（*Streptococcus pneumoniae*）、流感嗜血杆菌（*Haemophilus influenzae*））、肠道病毒、贾第鞭毛虫（*Giardia*） |
| **补体缺陷** | 遗传性缺陷；依库珠单抗（eculizumab）等补体抑制剂 | 脑膜炎奈瑟菌（*Neisseria meningitidis*）及其他奈瑟菌（终末途径）；有荚膜细菌 |
| **无脾或脾功能低下** | 脾切除、镰状细胞病、乳糜泻 | 有荚膜细菌、二氧化碳嗜纤维菌（*Capnocytophaga*，犬咬伤）；重症疟疾和巴贝虫病 |
| **屏障破坏** | 黏膜炎、中心静脉导管、手术、烧伤 | 皮肤和肠道菌群：葡萄球菌、链球菌、革兰氏阴性菌、念珠菌 |

许多患者同时存在多种缺陷：干细胞移植后的人在几个月内可能先后出现中性粒细胞减少、黏膜炎、中心静脉导管、T细胞抑制和抗体缺陷。
:::

::: theorem 免疫抑制的净状态 {#thm-net-state}
免疫功能低下者的感染风险由两个因素的相互作用决定：

1. **流行病学暴露**：社区中的、医院中的、供体器官携带的病原体，以及过去以潜伏状态携带的病原体（疱疹病毒、结核、乙型肝炎、类圆线虫、弓形虫）。
2. **免疫抑制的净状态**：免疫抑制药物的种类、剂量、疗程和组合；中性粒细胞减少；皮肤和黏膜的破损；糖尿病、尿毒症和营养不良等代谢因素；以及CMV等具有免疫调节作用的病毒感染。

在免疫抑制很强时，少量暴露即可致病；在免疫抑制较轻时，大量暴露也可致病。预防同时作用于两者：减少暴露（筛查、预防用药、饮食和饮水建议、为接触者接种疫苗），以及把免疫抑制降至最低有效水平。
:::

::: warning
**免疫功能低下者的感染表现不同：不要等待通常的体征。** 没有中性粒细胞就没有脓：肺炎在胸片上可能几乎看不出，尿路感染时尿中可能没有白细胞，蜂窝织炎可能只是一片淡粉色的斑。糖皮质激素抑制发热和腹部体征，因此肠穿孔可以无痛。发热可能是唯一的体征，也可能没有发热。要根据怀疑进行治疗，广泛检查（血培养、CT等影像学检查以及来自任何可能部位的标本），并尽早请感染专科参与。
:::

## 中性粒细胞减少与中性粒细胞减少性脓毒症

**中性粒细胞绝对计数（ANC）**是白细胞计数乘以中性粒细胞（包括杆状核）所占的比例。ANC降至$1.0 \times 10^9$/L以下时感染风险上升，低于$0.5 \times 10^9$/L时风险高，低于$0.1 \times 10^9$/L时风险最高；中性粒细胞减少的**持续时间**越长，风险越高。大多数细胞毒性化疗后，中性粒细胞计数在治疗后约7–14天降至最低点（**最低值**），然后恢复。

::: definition 中性粒细胞减少性脓毒症 {#def-neutropenic}
按NICE指南，**中性粒细胞减少性脓毒症**是指接受抗癌治疗者中性粒细胞计数为$0.5 \times 10^9$/L或更低，同时体温高于38 °C，或有其他符合有临床意义的脓毒症的体征或症状。这是一种**医学急症**：感染可在数小时内进展为脓毒性休克。

**处理原则**（NICE CG151和英国急症肿瘤学实践）：
- **立即给予经验性抗生素**，通常在到院后一小时内；如果患者近期接受过化疗且病情不佳，不必等待中性粒细胞计数结果。
- NICE指南中通常的首选是**哌拉西林-他唑巴坦（piperacillin–tazobactam）单药治疗**；除非有患者特异或本地的原因，不常规加用氨基糖苷类，也不因为有中心静脉导管就加用糖肽类。
- 抗生素前留取**培养**：从中心静脉导管每个管腔及外周采集血培养，并从任何可疑部位取标本。
- **风险分层**，例如用MASCC评分，可识别出能早期改为口服抗生素或门诊治疗的低风险患者。
- 抗生素治疗数天后**持续发热**，应寻找真菌感染（胸部CT、血清半乳甘露聚糖），并考虑经验性或抢先性抗真菌治疗。
:::

预防措施包括：对某些化疗方案使用生长因子（G-CSF）；对预计会出现严重中性粒细胞减少的某些成人用氟喹诺酮类进行抗菌预防；对霉菌感染高风险者（如急性髓系白血病诱导化疗者）进行抗真菌预防；以及患者教育：接受化疗的人随身携带说明，一旦发热立即就医。

::: example 第九天的发热 {#ex-febrile-neut}
一名54岁女性正在接受乳腺癌辅助化疗；最近一个周期在九天前。她因寒战和体温38.6 °C打电话给肿瘤科热线，被告知立即就诊。到院时：脉率每分钟112次，血压108/64 mmHg，呼吸频率每分钟20次，呼吸空气时SpO₂ 97%。她有一根隧道式中心静脉导管。白细胞计数$0.9 \times 10^9$/L，中性粒细胞22%。
::: solution
**ANC**：$0.9 \times 0.22 = 0.198 \approx 0.2 \times 10^9$/L，远低于0.5：这是**中性粒细胞减少性脓毒症**。

**紧急措施**：
1. 用ABCDE和NEWS2评估；她心动过速但没有低血压。
2. 从中心静脉导管和外周采集血培养，并留取尿液及其他相关标本，但不延误抗生素。
3. 在一小时内**静脉给予哌拉西林-他唑巴坦**（青霉素过敏者用本地替代方案）。
4. 补液、观察，病情恶化时升级处理。

**随后**：检查感染源，包括导管出口和隧道、口腔（黏膜炎）、肛周、皮肤和胸部；拍胸片。计算风险评分：如果她保持稳定且没有复杂因素，可能适合早期改为口服抗生素并在密切随访下出院。如果培养显示导管相关感染，可能需要拔除导管。如果四到七天后仍持续发热且原因不明，要检查真菌感染。今后的化疗周期可考虑使用G-CSF。
:::
:::

## 移植后感染

::: definition 移植后感染时间线 {#def-transplant}
**实体器官移植**后，感染遵循一条可预测的时间线，由手术、免疫抑制水平和所给予的预防用药决定：

- **第一个月**：与**手术和住院医疗**相关的感染（切口、吻合口瘘、肺炎、导管和尿路感染、艰难梭菌）以及随器官传播的**供体来源**感染。由于免疫抑制尚未累积，机会性感染不常见。
- **一至六个月**：免疫抑制最强的时期。没有预防用药时，会出现**巨细胞病毒（CMV）**、肺孢子菌、李斯特菌、诺卡菌、弓形虫、乙型和丙型肝炎再激活、**BK多瘤病毒**（肾移植肾病）和真菌感染。在现代预防用药下，其中许多被推迟而不是被消除。
- **六个月以后**：大多数患者使用稳定的较低剂量免疫抑制，发生的是**社区获得性感染**，往往比通常更严重；部分患者出现晚发CMV、VZV再激活、**移植后淋巴组织增生性疾病（PTLD）**，或因排斥反应加强免疫抑制后发生感染。

**造血干细胞移植（HSCT）**的模式不同：**植入前**期中性粒细胞严重减少和黏膜炎（细菌、念珠菌、曲霉、HSV）；**植入后**期以T细胞缺陷、移植物抗宿主病及其治疗为主（CMV、腺病毒、肺孢子菌、霉菌）；**晚期**抗体应答不足和功能性脾功能低下（有荚膜细菌、VZV），这就是受者需要重新接种疫苗的原因。

**预防**包括：用复方磺胺甲噁唑（co-trimoxazole）预防肺孢子菌（以及弓形虫和诺卡菌）；通过**预防用药**（例如对接受CMV血清阳性供体器官的CMV血清阴性受者，即D+/R−，使用缬更昔洛韦（valganciclovir），或对CMV血清阳性的HSCT受者使用来特莫韦（letermovir））或通过**抢先监测**血液CMV DNA、在升高时治疗来预防CMV；对高风险人群进行抗真菌预防；以及在移植前为患者、并为家庭接触者接种疫苗。
:::

::: example 预防用药结束后的发热 {#ex-cmv}
一名46岁男性六个月前接受了来自CMV血清阳性供体的肾移植；他本人CMV血清阴性（D+/R−）。他在最初200天服用缬更昔洛韦预防，三周前停药。他现在发热、乏力、腹泻，肌酐从120升至165 µmol/L。白细胞计数$2.6 \times 10^9$/L，血小板$95 \times 10^9$/L，ALT 110 U/L。他的免疫抑制方案是他克莫司（tacrolimus）、吗替麦考酚酯（mycophenolate）和泼尼松龙。
::: solution
**可能的诊断**：**CMV病**。D+/R−组合风险最高，因为受者对供体器官中潜伏携带的病毒没有免疫力，疾病常在预防用药停止后不久出现。CMV引起发热、白细胞减少、血小板减少、肝炎、结肠炎，在肾移植受者中还引起移植肾功能障碍。它也增加排斥反应和其他机会性感染的风险。

**检查**：血液**CMV定量PCR**；怀疑结肠炎时行结肠镜加活检（血液PCR可能低估肠道疾病）；他克莫司血药浓度；移植肾评估，必要时活检，以区分排斥反应与CMV或BK病毒肾病；血培养和艰难梭菌检测。

**治疗**：静脉**更昔洛韦（ganciclovir）**（较轻者口服缬更昔洛韦），剂量根据肾功能调整，持续至病毒载量检测不到、症状消失；在安全的前提下与移植团队讨论**减少免疫抑制**（常为吗替麦考酚酯）；监测血细胞计数，因为更昔洛韦有骨髓抑制作用。如果病毒载量不下降，随后检测耐药突变。此后监测CMV DNA以发现复发。
:::
:::

::: example 一年后的淋巴结肿大 {#ex-ptld}
一名22岁女性14个月前接受了肝移植。移植前她EBV血清阴性；供体血清阳性。她现在发热、盗汗，颈部淋巴结肿大。血液EBV DNA载量很高，CT示多发淋巴结肿大和一个小肠肿块。
::: solution
**可能的诊断**：**移植后淋巴组织增生性疾病（PTLD）**。在T细胞免疫被抑制的人体内，通常由细胞毒性T细胞控制的EBV感染B细胞不受控制地增殖。其谱系从多克隆增生到侵袭性单克隆淋巴瘤。风险最高的是**接受血清阳性器官的EBV血清阴性受者**、儿童、移植后第一年以及强免疫抑制（尤其是T细胞清除性抗体）。

**诊断**需要对受累淋巴结或肿块进行**活检**，做组织学、克隆性和EBV染色检查，随后进行分期。

**治疗**首先是**减少免疫抑制**，使恢复的T细胞能控制EBV驱动的增殖，同时权衡排斥反应的风险。CD20阳性者加用**利妥昔单抗**（抗CD20），疗效不足时加用化疗。对高风险受者监测EBV DNA可以更早发现。
:::
:::

## 糖皮质激素、生物制剂与脾脏

::: definition 医源性免疫抑制 {#def-iatrogenic}
许多药物会增加特定感染的风险，而这些风险大多可以通过**治疗前筛查**、**疫苗接种**和**预防用药**来预见：

| 治疗 | 主要感染风险 | 预防 |
|---|---|---|
| **糖皮质激素**（风险随剂量和疗程增加；常以泼尼松龙约20 mg/天或以上、持续四周或更长作为阈值） | 细菌感染、肺孢子菌、VZV、结核再激活、类圆线虫过度感染、真菌感染 | 与其他免疫抑制剂联用或存在高风险情况时预防肺孢子菌肺炎；对来自流行区者筛查类圆线虫或经验性使用伊维菌素（ivermectin） |
| **TNF抑制剂**（英夫利西单抗（infliximab）、阿达木单抗（adalimumab）等） | **结核再激活**，常为肺外或播散性；还有李斯特菌、地方性真菌、乙型肝炎再激活 | **治疗前做IGRA和胸片**，并治疗结核感染；检测乙型肝炎、丙型肝炎和HIV |
| **抗CD20抗体**（利妥昔单抗） | **乙型肝炎再激活**，包括既往感染已恢复者（抗-HBc阳性）；低丙种球蛋白血症；疫苗应答差；进行性多灶性白质脑病（PML） | 治疗前检测乙型肝炎血清学；对既往或现症感染者给予抗病毒预防；治疗前接种疫苗 |
| **补体抑制剂**（依库珠单抗、雷夫利珠单抗（ravulizumab）） | **脑膜炎球菌病**，可呈暴发性 | 开始治疗前至少两周接种A、C、W、Y群和B群脑膜炎球菌疫苗（否则在此之前给予抗生素覆盖），并按指南进行抗生素预防；患者警示卡 |
| **JAK抑制剂** | 带状疱疹 | 重组（非活）带状疱疹疫苗 |
| **那他珠单抗（natalizumab）** | 由JC多瘤病毒引起的**PML** | 检测JC病毒抗体进行风险分层；MRI监测 |

在显著免疫抑制期间一般避免使用活疫苗，因此疫苗接种最好在治疗**开始前**完成。

**无脾和脾功能低下**使机体失去了清除血液中有荚膜细菌、调理过的细菌和被感染红细胞的主要过滤器。危险在于**脾切除后凶险性感染（OPSI）**：暴发性脓毒症，最常由肺炎球菌引起，死亡率高。预防措施包括：**疫苗接种**（肺炎球菌、b型流感嗜血杆菌、A、C、W、Y群和B群脑膜炎球菌，以及每年的流感疫苗）、**抗生素预防**（常为长期青霉素或替代药物，尤其是在最初几年和对风险较高者）、发热时立即开始服用的**备用应急**抗生素、**警示卡**、犬咬伤后的建议，以及旅行时严格预防疟疾。
:::

::: example 发热变成了紫癜 {#ex-opsi}
一名35岁男性十年前因交通事故切除了脾脏。他没有接种推荐的疫苗，服用青霉素一年后就停药了。他在晚上6点突然发热、寒战；到午夜时意识混乱，血压78/40 mmHg，紫癜性皮疹在扩散。血涂片见中性粒细胞内有革兰氏阳性双球菌。
::: solution
**诊断**：**脾切除后凶险性感染**，几乎可以肯定是肺炎链球菌（革兰氏阳性双球菌）所致，并发脓毒性休克和弥散性血管内凝血（暴发性紫癜）。在外周血涂片中可见细菌，说明细菌负荷巨大，缺失的脾脏无法将其清除。

**处理**：立即按本地脓毒症指南静脉给予大剂量抗生素（例如第三代头孢菌素，在青霉素耐药肺炎球菌流行地区加用其他覆盖）；复苏和血管加压药；重症监护；处理弥散性血管内凝血。即使治疗最佳，死亡率仍很高，幸存者可能失去手指、足趾或肢体。

**本可预防**：疫苗接种（择期脾切除最好在术前至少两周，急诊脾切除则在术后两周）、抗生素预防、一出现发热征象即服用的备用抗生素，以及警示卡。每一位脾功能缺失者都应登记在册，并被召回接种疫苗。
:::
:::

::: history
1952年，哈罗德·金（Harold King）和哈里斯·舒马克（Harris Shumacker）描述了婴儿脾切除后的凶险性脓毒症，首次引起人们对脾脏抗细菌防御作用的关注。1954年，约瑟夫·默里（Joseph Murray）的团队在波士顿进行了首例成功的肾移植，供受者为同卵双胞胎；只有在出现免疫抑制药物后，非同卵个体之间的移植才成为可能，最初是硫唑嘌呤（azathioprine）和糖皮质激素，20世纪80年代初起有了环孢素（ciclosporin），由罗伊·卡恩（Roy Calne）引入临床移植。E·唐纳尔·托马斯（E. Donnall Thomas）发展了治疗白血病的骨髓移植；他与默里分享了1990年的诺贝尔奖。1966年，杰拉尔德·博迪（Gerald Bodey）等表明，急性白血病患者的感染风险随中性粒细胞计数下降而上升，且低值持续越久风险越高，这是现代中性粒细胞减少性脓毒症救治的基础。20世纪70至80年代，菲利普·皮佐（Philip Pizzo）等人的研究确立了对发热性中性粒细胞减少立即使用经验性广谱抗生素的做法，后来又确立了对持续发热的经验性抗真菌治疗。
:::

::: quiz
一名30岁女性因阵发性睡眠性血红蛋白尿症接受依库珠单抗治疗，出现发热和头痛。最需要考虑并立即治疗的病原体是哪一种？
- [ ] 耶氏肺孢子菌（*Pneumocystis jirovecii*）
- [ ] 巨细胞病毒
- [x] 脑膜炎奈瑟菌
- [ ] 烟曲霉（*Aspergillus fumigatus*）
::: solution
依库珠单抗阻断补体C5的裂解，从而阻止膜攻击复合物（C5b–9）的形成，而后者是杀灭奈瑟菌所必需的。使用该药者即使接种了疫苗，脑膜炎球菌病的风险也大大增加。这类患者发热时要按可能的脑膜炎球菌感染处理，立即给予抗生素。
:::

## 后续内容

这些缺陷背后的免疫机制见[[immunology/immunodeficiency]]和[[immunology/transplant-tumour-immunology]]。白血病及其治疗见[[blood/leukaemia]]。获得性T细胞缺陷最常见的原因HIV见[[infectious-diseases/hiv]]，关键的再激活风险结核病见[[infectious-diseases/tuberculosis]]。类圆线虫及其他来自既往旅行的感染见[[infectious-diseases/tropical-infections]]，疫苗接种规划见[[public-health/vaccination-programmes]]。

::: summary
- 首先识别免疫缺陷：中性粒细胞减少（细菌，继而真菌）、T细胞缺陷（病毒、肺孢子菌、隐球菌、分枝杆菌、李斯特菌）、抗体缺陷和无脾（有荚膜细菌）、补体缺陷（奈瑟菌）。
- 感染风险既反映暴露（包括多年前获得的潜伏病原体），也反映免疫抑制的净状态。
- 感染的体征不明显；要根据怀疑进行治疗，并广泛检查。
- 中性粒细胞减少性脓毒症（中性粒细胞 ≤ $0.5 \times 10^9$/L伴发热或脓毒症征象）是急症：留取培养，并在一小时内立即给予经验性抗生素，通常为哌拉西林-他唑巴坦。
- 移植后感染遵循时间线：第一个月为手术相关和供体来源感染，一至六个月为机会性感染（CMV、肺孢子菌），此后为社区感染和晚期并发症（PTLD）。预防用药和监测会改变这一模式。
- 使用糖皮质激素和生物制剂前：酌情筛查结核、乙型肝炎、HIV和类圆线虫，开始前接种疫苗，并给予针对性预防用药。
- 脾功能缺失者需要疫苗、抗生素预防、备用抗生素和警示卡，以预防凶险性脓毒症。
:::

## 习题

::: exercise 中性粒细胞计数 {level=1 check="1.2*0.2"}
一位患者白细胞计数为$1.2 \times 10^9$/L，中性粒细胞15%，杆状核5%。中性粒细胞绝对计数是多少（单位$10^9$/L）？
::: solution
$\text{ANC} = 1.2 \times (0.15 + 0.05) = 1.2 \times 0.20 = 0.24 \times 10^9$/L。这低于0.5，因此一旦发热即符合中性粒细胞减少性脓毒症的定义。
:::
:::

::: exercise 匹配缺陷 {level=1}
对每位患者，说出其免疫缺陷和一种典型感染：(a) 慢性淋巴细胞白血病、免疫球蛋白低、一年内患三次肺炎的男性；(b) 服用泼尼松龙每日40 mg和甲氨蝶呤（methotrexate）、干咳伴低氧血症的女性；(c) 脾切除后被狗咬伤的男性；(d) 急性髓系白血病诱导化疗后第五天的女性。
::: solution
(a) **抗体缺陷**：反复发生肺炎球菌或流感嗜血杆菌肺炎；可考虑免疫球蛋白替代治疗。(b) 大剂量激素加第二种药物导致的**T细胞抑制**：**肺孢子菌肺炎**，预防用药本可帮助预防。(c) **无脾**：暴发性**犬咬二氧化碳嗜纤维菌（*Capnocytophaga canimorsus*）**脓毒症，因此任何犬咬伤后都要给予抗生素。(d) **中性粒细胞减少**和黏膜炎：革兰氏阴性菌菌血症（包括假单胞菌）、链球菌菌血症，中性粒细胞减少持续时间长时还有曲霉。
:::
:::

::: exercise 疫苗与脾切除 {level=1}
一名40岁女性将在六周后因免疫性血小板减少症行择期脾切除术。另一位患者今天因创伤行急诊脾切除术。两人各应在何时接种疫苗？为什么时机不同？
::: solution
对于**择期**手术，疫苗（肺炎球菌、Hib/MenC、MenACWY、MenB、流感）在术前**至少两周**接种，使抗体应答在脾脏仍存在时形成，脾脏有助于应答。**急诊**脾切除后，在术后约**两周**接种（若随访不确定则在出院前接种），因为在创伤和手术的急性应激过去后应答更好。两人都需要抗生素预防、备用抗生素、警示卡和相关建议。
:::
:::

::: exercise 使用英夫利西单抗之前 {level=2}
一名出生于菲律宾的28岁克罗恩病男性即将开始使用英夫利西单抗。列出首次输注前的筛查和预防步骤，并说明每一步的理由。
::: solution
- **结核**：症状评估、胸片和**IGRA**；TNF对维持肉芽肿至关重要，因此结核感染可再激活为严重、常为肺外的疾病。如发现结核感染，在专科建议下开始治疗，通常在使用英夫利西单抗前至少几周。
- **乙型肝炎**（HBsAg、抗-HBc、抗-HBs）：有再激活风险；无免疫力者接种疫苗；既往感染者给予抗病毒预防或监测。
- **丙型肝炎和HIV**：未被诊断的感染会影响安全性和处理。
- 无水痘病史者检测**VZV血清学**：水痘疫苗（活疫苗）必须在治疗开始前接种。
- **疫苗接种**：肺炎球菌、每年的流感、COVID-19，并酌情接种HPV；治疗开始后避免活疫苗。
- 考虑到他的来源地，应考虑**类圆线虫血清学**检测，尤其是同时使用激素时。
- **教育**：发热或出现新症状时及时就医，并告诉任何医生他在使用英夫利西单抗。
:::
:::

::: exercise 核心抗体阳性 {level=2}
一名66岁淋巴瘤女性即将接受含利妥昔单抗的化疗。她的乙型肝炎检测结果为：HBsAg阴性，抗-HBc阳性，抗-HBs阴性，HBV DNA检测不到。解读结果并概述处理。
::: solution
**解读**：**已恢复的（既往）乙型肝炎感染**。病毒以共价闭合环状DNA的形式持续存在于肝细胞中，并由免疫系统控制。利妥昔单抗清除B细胞，可导致**再激活**，进而引起严重肝炎和肝衰竭。

**处理**：由于在这种情况下利妥昔单抗的再激活风险高，通常给予**抗病毒预防**（恩替卡韦（entecavir）或替诺福韦（tenofovir）），在化疗前或与化疗同时开始，并在最后一剂利妥昔单抗后持续数月（通常至少12–18个月），同时监测肝功能和HBV DNA。在风险较低的情况下，替代方案是密切监测并在出现再激活的最初迹象时治疗，但对于利妥昔单抗，一般按肝病专科建议首选预防。
:::
:::

::: exercise 不退的发热 {level=2}
一名58岁急性髓系白血病男性在诱导化疗后中性粒细胞减少的第12天。尽管使用了哌拉西林-他唑巴坦，他已发热五天，血培养阴性。他现在出现干咳和胸膜炎性胸痛。胸部CT示多个结节，其中一个周围有磨玻璃样晕圈。血清半乳甘露聚糖阳性。诊断和治疗是什么？
::: solution
**诊断**：拟诊**侵袭性肺曲霉病**。长时间严重的中性粒细胞减少是主要危险因素。伴**晕征**的结节（血管侵袭导致结节周围出血）和**半乳甘露聚糖**（曲霉细胞壁的一种成分）阳性是典型的早期表现；支气管镜灌洗液半乳甘露聚糖和培养可提供进一步支持。

**治疗**：一线使用对曲霉有效的抗真菌药**伏立康唑（voriconazole）**或**艾沙康唑（isavuconazole）**，伏立康唑需进行治疗药物监测，并注意其众多的相互作用；两性霉素B脂质体是替代药物，它还能覆盖毛霉病，而CT表现可能与之相似。中性粒细胞的恢复是决定预后的最重要因素。在中性粒细胞减少且发热期间继续广谱抗生素。考虑当初是否适合进行抗真菌预防，并为之后的化疗计划二级预防。
:::
:::

::: exercise 肾移植后的头痛 {level=3}
一名52岁女性两年前接受肾移植，使用他克莫司、吗替麦考酚酯和泼尼松龙，出现头痛、低热和轻度意识混乱一周。最近全科医生因胸部感染给她开了克拉霉素（clarithromycin）。讨论鉴别诊断和处理问题，包括药物相互作用。
::: hint
想一想T细胞缺陷相关的中枢神经系统感染，以及与她所用药物相关的非感染性原因。
:::
::: solution
**感染性鉴别诊断**（T细胞缺陷）：**隐球菌性脑膜炎**（亚急性头痛，常伴颅内压升高；血清和脑脊液隐球菌抗原）、**李斯特菌**脑膜炎或菱脑炎、**结核性脑膜炎**、**PML**（JC病毒）、弓形虫病、**病毒性脑炎**（HSV、VZV、HHV-6）以及诺卡菌脑脓肿（常伴肺部病变）；还有常见的细菌性脑膜炎。

**非感染性鉴别诊断**：**钙调神经磷酸酶抑制剂毒性**。克拉霉素是强效**CYP3A4抑制剂**，会升高他克莫司浓度，引起头痛、震颤、意识混乱、抽搐、高血压和急性肾损伤，以及**可逆性后部脑病综合征（PRES）**。脑内PTLD也是一种可能。

**处理**：紧急检测他克莫司浓度和肾功能；头颅MRI；血培养、血清隐球菌抗原；腰椎穿刺（如安全）测初压、细胞计数、葡萄糖、蛋白、革兰氏染色、培养、隐球菌抗原和PCR组合检测；在结果出来之前，经验性治疗覆盖细菌性脑膜炎**包括李斯特菌**（在头孢菌素基础上加阿莫西林）并加用阿昔洛韦。停用克拉霉素，并与移植团队一起调整他克莫司。本病例说明两条规则：对移植受者，每一种新药都要核查相互作用；对任何新的神经系统症状，既要考虑机会性感染，也要考虑药物毒性。
:::
:::

::: exercise 干细胞移植后的腹泻 {level=3}
一名41岁男性接受非亲缘供者异基因干细胞移植后60天，出现大量水样腹泻（每天两升）、腹部绞痛和手掌新发皮疹。他使用环孢素，以及复方磺胺甲噁唑、阿昔洛韦和来特莫韦预防。给出鉴别诊断、如何区分各种原因，以及为什么这很重要。
::: solution
**鉴别诊断**：**急性胃肠道移植物抗宿主病（GVHD）**，植入后期出现大量腹泻伴手掌皮疹提示此病；**CMV结肠炎**（使用来特莫韦预防时可能性较小，但仍有可能）；**腺病毒**和**诺如病毒**（可在HSCT受者中引起迁延性腹泻）；**艰难梭菌**感染；其他肠道细菌和寄生虫；以及药物作用（如使用吗替麦考酚酯、镁补充剂）。

**鉴别方法**：粪便检测艰难梭菌毒素、细菌、病毒（诺如病毒、腺病毒、轮状病毒PCR）和寄生虫病原体；血液CMV和腺病毒PCR；皮疹活检；以及**内镜加活检**（结肠，常同时做上消化道），可显示GVHD的隐窝细胞凋亡改变、免疫组化中的CMV包涵体或其他病原体。

**为什么重要**：两者的治疗方向相反。GVHD通过**加强免疫抑制**（大剂量糖皮质激素及其他药物）治疗，而感染需要抗微生物治疗，并尽可能**减少**免疫抑制。如果病因是CMV或腺病毒，却按推定的GVHD开始使用激素，可能使感染播散；漏诊GVHD则会导致严重的液体丢失和损伤。两者可以同时存在，这就是为什么要同时进行活检和微生物学检查。
:::
:::
