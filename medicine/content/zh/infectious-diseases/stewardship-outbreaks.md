抗生素对医学的改变几乎超过任何其他发明。它们使肺炎、脑膜炎和分娩变得可以存活，并支撑着外科手术、化疗、移植和重症监护。每一次使用抗生素也都会筛选出耐药，而耐药会在人、动物和环境之间传播。全球抗微生物药物耐药性研究（GRAM）项目估计，2021年细菌耐药直接导致约114万人死亡，与471万人死亡相关；并预测如果趋势持续，2025至2050年间耐药直接导致的死亡将超过3900万。

本章讨论感染病学中属于公共卫生的那一半。内容包括细菌如何耐药、药理学和实验室如何指导合理处方、**抗微生物药物管理**的实践，以及**暴发**的调查与控制。英国的做法遵循NICE（NG15）、英国卫生安全局的指南（包括“明智开始，然后聚焦”），以及英国国家行动计划《应对抗微生物药物耐药性2024至2029》；全球做法遵循WHO。

## 细菌如何耐药

::: definition 抗微生物药物耐药性 {#def-resistance}
**抗微生物药物耐药性**是指微生物在通常能将其杀灭或抑制的药物浓度下仍能存活或生长的能力。**固有耐药**是整个菌种的特性（例如，万古霉素分子较大，不能穿过革兰氏阴性菌的外膜，因此对其无效）。**获得性耐药**出现在原本敏感的菌株中，通过**突变**或从其他细菌**获得基因**而产生。

耐药机制分为四类：

1. **破坏或修饰药物**：β-内酰胺酶水解β-内酰胺环。从简单的青霉素酶，到能破坏第三代头孢菌素的**超广谱β-内酰胺酶（ESBL，如CTX-M）**，再到还能破坏碳青霉烯类的**碳青霉烯酶（KPC、OXA-48、NDM、VIM、IMP）**。氨基糖苷修饰酶的作用方式与之类似。
2. **改变靶点**：MRSA产生一种对β-内酰胺类亲和力低的替代青霉素结合蛋白（PBP2a，由*mecA*编码）；携带*vanA*的肠球菌构建末端为D-Ala–D-Lac的细胞壁，万古霉素与之结合很弱；DNA旋转酶突变导致氟喹诺酮类耐药，*rpoB*突变导致利福平耐药。
3. **减少药物进入**：革兰氏阴性菌外膜孔蛋白的丢失。
4. **把药物泵出**：外排泵，常同时作用于多类药物。

**水平基因转移**使耐药基因在细菌之间传播，包括在不同菌种之间：质粒的**接合**（ESBL和碳青霉烯酶基因的主要途径）、游离DNA的**转化**以及噬菌体的**转导**。质粒常同时携带多个耐药基因，以及消毒剂和金属耐药基因。
:::

::: proof
**为什么抗生素使用会筛选出耐药，以及为什么耐药很少消失。** 假设一个细菌群体中有一小部分耐药细胞。没有抗生素时，耐药基因通常带有**适应度代价**：耐药细胞生长稍慢，因而一直罕见。有抗生素时，敏感的大多数被杀死，耐药的少数扩增并填补空间。一个群体（在一位患者、一个病房、一个农场或一个国家中）暴露得越频繁，耐药就越富集。这就是为什么在不同医院和国家之间，抗生素用量与耐药率相关。

如果停止使用，人们可能会认为耐药会随着有代价的基因丢失而下降。实际上它常常持续存在，原因有三：细菌获得降低适应度代价的**补偿性突变**；耐药基因与其他基因一起位于质粒上，因此使用**任何**一种其耐药基因位于同一质粒上的药物都会把它们全部共同筛选；社区、动物和环境中的储存库不断重新引入耐药菌株。因此，抗微生物药物管理的目标是防止耐药出现和传播，而不是指望它自行消失。
:::

黏菌素的故事说明了这一过程可以多么迅速。黏菌素是一种古老而有毒性的药物，被保留作为碳青霉烯类耐药感染的最后手段，但它曾在牲畜中大量使用。2015年，中国的研究人员在来自猪和患者的细菌中发现了*mcr-1*，一种由质粒携带的黏菌素耐药基因；几个月内，它已在许多国家被发现。这是一个**“同一健康”**问题：人类、动物和环境中的抗生素使用与耐药是相互联系的。

## 合理使用抗生素：药理学

::: theorem 药代动力学–药效学靶标 {#thm-pkpd}
抗生素的效果取决于其浓度随时间的变化与病原体**最低抑菌浓度（MIC）**的比较。抗生素分为三类：

- **时间依赖性杀菌**（β-内酰胺类）：关键是**给药间隔内游离药物浓度超过MIC的时间比例**（$fT_{>\text{MIC}}$）。频繁给药或延长输注可以达到这一目标。
- **浓度依赖性杀菌**（氨基糖苷类）：关键是**峰浓度与MIC之比**（$C_{\max}/\text{MIC}$）。每日一次大剂量给药可达到高峰值，并使药物在下一剂前被清除，这也能减少肾毒性。
- **暴露依赖性杀菌**（万古霉素、氟喹诺酮类）：关键是**浓度–时间曲线下面积与MIC之比**（$\text{AUC}/\text{MIC}$）。

对于按一级动力学消除的药物，$C(t) = C_0 e^{-kt}$，半衰期$t_{1/2} = \ln 2/k$，因此浓度从$C_0$降至MIC所需的时间为

$$
t_{>\text{MIC}} = \frac{\ln(C_0/\text{MIC})}{k} = t_{1/2} \log_2\!\left(\frac{C_0}{\text{MIC}}\right).
$$
:::

x: 0, 8

sliders: h=1:0.5:4:0.25; m=2:0.25:16:0.25

caption: 单次静脉给药后某β-内酰胺类的浓度（峰值40 mg/L），半衰期为$h$小时，给药间隔8小时，针对MIC为$m$ mg/L的病原体。曲线保持在MIC线以上的时间即$fT_{>\text{MIC}}$。MIC加倍会使其缩短一个半衰期，因此MIC较高的病原体需要更频繁给药或延长输注。数值仅作说明；实际给药以处方集和治疗药物监测为准。
:::

::: example 高于MIC的时间有多长？ {#ex-pkpd}
某β-内酰胺类每8小时给药一次，游离峰浓度达40 mg/L，半衰期为1小时。(a) 浓度高于MIC 2 mg/L的时间有多长？(b) 这占给药间隔的多大比例？(c) 如果病原体的MIC为8 mg/L会怎样？
::: solution
(a) $t_{>\text{MIC}} = 1 \times \log_2(40/2) = \log_2 20 = 4.32$小时。

(b) $4.32/8 = 0.54$，因此浓度在54%的间隔时间内高于MIC。对于青霉素类，约50%的目标通常已经足够。

(c) $t_{>\text{MIC}} = \log_2(40/8) = \log_2 5 = 2.32$小时，仅占间隔的29%。可选方案是把同样的总剂量分得更频繁（每6或4小时）、使用**延长或持续输注**，或换用其他药物。这一推理是重症监护中延长输注β-内酰胺类以及使用把MIC与可达剂量联系起来的折点的基础。
:::
:::

## 合理使用抗生素：实验室

::: definition 药敏试验与抗菌谱 {#def-antibiogram}
**药敏试验**通过测定**MIC**（抑制可见生长的最低浓度）或纸片扩散法来衡量分离株对抗生素的反应。结果用EUCAST（英国使用）等机构制定的**临床折点**解读：**S**（标准剂量下敏感）、**I**（“敏感，增加暴露”：如能在感染部位达到更高剂量或浓度则有效）和**R**（耐药）。

**抗菌谱（antibiogram）**是对某医院或地区在一段时间内各种病原体分离株对各种抗生素敏感百分比的汇总，通常每位患者只计第一个分离株。它描述本地的耐药情况，是**经验性**处方指南的基础：如果可能的病原体中有相当比例（常为10–20%以上）对某抗生素耐药，一般不将其用于严重感染的经验性治疗。
:::

快速诊断正在改变这一局面：分子检测可以在数小时内直接从阳性血培养中检出*mecA*或碳青霉烯酶等耐药基因，从而更早开始目标治疗。“诊断管理”是指对正确的患者使用正确的检测：对有症状者做尿培养而不是常规筛查，只对液状粪便做艰难梭菌检测。

::: example 耐药的大肠埃希菌 {#ex-esbl}
一名72岁2型糖尿病女性因肾盂肾炎入院，经验性静脉使用头孢曲松（ceftriaxone）。48小时后仍发热。血培养和尿培养生长大肠埃希菌（*E. coli*），对头孢曲松、阿莫西林-克拉维酸和甲氧苄啶耐药，对美罗培南（meropenem）、哌拉西林-他唑巴坦（MIC接近折点）、庆大霉素、替莫西林（temocillin）和环丙沙星敏感。实验室报告其为**产ESBL菌株**。
::: solution
**解读**：ESBL水解第三代头孢菌素，这解释了头孢曲松治疗失败。ESBL基因常与其他类别的耐药基因一同携带，本例即如此。

**治疗选择**：对于产ESBL大肠埃希菌引起的**血流感染**，MERINO试验（2018年）发现哌拉西林-他唑巴坦组30天死亡率高于美罗培南组（12.3%对3.7%），因此严重感染一般首选**碳青霉烯类**。根据药敏和本地建议的替代药物包括替莫西林和氨基糖苷类。一旦她病情好转、复查培养阴性且能口服，改为病原体敏感的口服药物（此处为环丙沙星）完成治疗；对于反应良好的非复杂性肾盂肾炎伴菌血症，总疗程通常为7天。影像学检查（超声或CT）寻找梗阻或脓肿，如有则需引流。

**抗微生物药物管理与感染控制**：在患者病历中标记为ESBL携带者，以指导今后的经验性治疗；每日评估碳青霉烯类的使用，一旦可以改为口服就停用，因为碳青霉烯类的使用会筛选碳青霉烯酶。
:::
:::

## 抗微生物药物管理

::: definition 抗微生物药物管理 {#def-stewardship}
**抗微生物药物管理**是在组织或整个系统层面推动和监测审慎使用抗微生物药物、以保持其未来有效性的做法（NICE NG15）。其目标是改善患者结局，减少包括艰难梭菌感染在内的不良反应，并限制耐药的出现和传播。

典型干预措施：
- 基于抗菌谱的**本地指南**，并限制部分广谱药物。
- 由抗微生物药物管理团队（感染专科医生和药师）进行**前瞻性审核与反馈**。
- **48–72小时评估**：按英国“明智开始，然后聚焦”，结合结果评估每一张抗生素处方，并记录决定：**停用**、从静脉**转为**口服、**更换**（通常改为窄谱）、在设定疗程和复查日期的前提下**继续**，或转为**门诊肠外抗微生物治疗**。
- 在有证据支持时使用**较短疗程**，例如NICE指南中大多数社区获得性肺炎为5天，许多血流感染为7天而不是14天（BALANCE试验，2024年）。
- **青霉素过敏评估与撤除标签**。
- **剂量优化**和治疗药物监测。
- **初级医疗措施**：自我护理建议、呼吸道感染的**备用（延迟）处方**，以及床旁检测。

在全球层面，WHO的**AWaRe**分类把抗生素分为**可及类（Access）**（常见感染的一线和二线抗生素）、**观察类（Watch）**（耐药潜力较高，用于特定适应证）和**备用类（Reserve）**（最后手段药物）。英国2024–2029年行动计划的目标是：到2029年，人用抗生素总量比2019年基线减少5%，且抗生素用量的70%来自可及类。
:::

::: warning
**青霉素过敏标签不是无害的预防措施。** 约十分之一的住院患者带有青霉素过敏标签，而经检测，其中90%以上可以安全使用青霉素。许多标签记录的是副作用（恶心、腹泻）、儿童病毒感染期间的皮疹或家族史。带标签的人接受更多广谱和二线抗生素，艰难梭菌和MRSA感染更多，住院时间更长。要仔细询问过敏史（发生了什么、何时、用药后多久、需要什么治疗），准确记录，并在适当时转诊撤除标签。过敏性休克、严重皮肤反应或其他严重反应的病史要予以尊重并记录。
:::

::: example 第三天的评估 {#ex-cdiff-switch}
一名67岁男性三天前因疑似社区获得性肺炎（CURB-65评分2分）入院，由于病历中一条含糊的“青霉素过敏？”记录而开始静脉使用哌拉西林-他唑巴坦；经询问，那是儿时服用阿莫西林后出现的恶心。他现在已退热36小时，能进食饮水，心率每分钟82次，呼吸空气时氧饱和度96%。CRP从190降至70 mg/L。血培养阴性；痰培养为正常菌群。胸片示右下叶实变。
::: solution
**按“明智开始，然后聚焦”评估**：肺炎诊断成立；他临床稳定且在好转，能吞咽和吸收，没有需要静脉治疗的情况（如脑膜炎、心内膜炎、未引流的脓肿或中性粒细胞减少）。决定是**转为**口服抗生素。

**选择**：哌拉西林-他唑巴坦的谱比所需的宽；过敏史描述的是不耐受而非过敏，因此应更新标签，他可以使用口服青霉素。对于中度社区获得性肺炎，按本地指南用窄谱口服药物（例如阿莫西林，怀疑非典型病原体感染时加用大环内酯类）完成治疗。

**疗程**：NICE建议大多数成人社区获得性肺炎使用**5天疗程**，前提是到第3天病情稳定。他已治疗3天，因此再口服2天就足够了。

**为什么重要**：每多一天广谱静脉治疗都会增加导管感染、艰难梭菌感染和耐药的风险，却没有益处。在转换时就在处方上写明停药日期，可以防止疗程默认延续下去。
:::
:::

## 暴发及其调查

**暴发**是指在特定地点、时间或人群中，某种疾病的病例数多于预期，或出现两例及以上相互关联的少见感染。暴发的范围从医院病房的诺如病毒，到婚礼上的食源性暴发，再到国际性流行。

::: definition 暴发调查 {#def-outbreak}
**暴发调查**遵循公认的顺序，但在实践中几个步骤同时进行，而且**一旦对传染源有合理怀疑就开始控制措施**：

1. **准备**：组建团队（暴发控制小组），明确分工。
2. **确认诊断**（临床和实验室）并**确认暴发存在**，排除检测或报告方式改变、实验室污染等假象。
3. **制定病例定义**：临床和实验室标准，按**时间、地点和人群**加以限定，常分为确诊、很可能和可能病例。
4. 系统地**搜索病例**。
5. 按时间（**流行曲线**）、地点（地图、病房平面图）和人群（年龄、性别、暴露）**描述暴发**。**点源**暴发在一个潜伏期内形成一个尖锐的单峰；**持续性共同来源**形成平台；**人传人（传播性）**扩散形成相隔约一个潜伏期的连续波峰。
6. 对传染源和传播途径**提出假设**并通过分析性研究**检验**：**队列研究**比较暴露者与未暴露者的**罹患率**（得出**相对危险度**），或**病例对照研究**比较病例与对照的暴露情况（得出**比值比**）。微生物分型（现在常用全基因组测序）把病例彼此联系起来，并与传染源联系起来。
7. **控制和预防**：清除传染源，阻断传播（隔离、分组安置、卫生措施、关闭），保护高危人群（疫苗接种、预防用药）。
8. 与工作人员、患者和公众**沟通**，并**评估和报告**，包括对预防的经验教训。
:::

::: theorem 再生数与群体免疫 {#thm-r0}
**基本再生数**$R_0$是在完全易感的人群中一名传染者平均引起的继发病例数。当人群中易感比例为$s$时，**有效再生数**为$R = R_0 s$。$R > 1$时暴发增长，$R < 1$时下降。因此，一旦免疫比例超过**群体免疫阈值**，传播就无法持续：

$$
H = 1 - \frac{1}{R_0}.
$$

麻疹的$R_0$通常估计为12–18，阈值高于90%，这就是需要极高疫苗接种率的原因；流感的$R_0$约为1.5，阈值约为三分之一。
:::

:::

::: example 婚礼后的疾病 {#ex-outbreak}
一场有100位宾客参加的婚宴后12至36小时，许多人出现呕吐和腹泻。所有宾客都填写了问卷。吃了鸡肉菜的60人中有45人发病；没吃的40人中有6人发病。吃了米饭沙拉的70人中有36人发病；没吃的30人中有15人发病。分析这些数据。
::: solution
这是一项**回顾性队列研究**，因为整个暴露群体（宾客）都可以调查。

**鸡肉**：吃了的人罹患率$= 45/60 = 75\%$；没吃的人$= 6/40 = 15\%$。**相对危险度**$= 0.75/0.15 = 5.0$。

**米饭沙拉**：罹患率$36/70 \approx 51\%$对$15/30 = 50\%$；相对危险度$\approx 1.03$，无关联。

**鸡肉菜**被强烈怀疑，风险高五倍。六位自称没吃却发病的人可能记错了、尝了一点或是继发病例。12–36小时的潜伏期和症状符合例如产气荚膜梭菌（*Clostridium perfringens*）或沙门菌（*Salmonella*）感染；检测病例的粪便标本和剩余食物，并由环境卫生部门检查厨房操作（大批量肉类的冷却和复热）。预计流行曲线呈单峰的**点源**模式。
:::
:::

::: example 假暴发 {#ex-pseudo}
在两个月内，一家医院十一位患者的支气管肺泡灌洗标本培养出铜绿假单胞菌，而此前每月只有一两例。大多数患者没有肺炎的体征，其中几位是因怀疑癌症而接受支气管镜检查的。这可能如何解释？你会如何调查？
::: solution
这种模式（看起来未受感染的患者阳性培养增多，且都与某项操作相关）提示**假暴发**：标本或设备污染，而非真正的感染。可能的来源包括被污染的支气管镜（损坏的管道可藏有能耐受消毒的生物膜）、被污染的自动内镜清洗机或其冲洗水、被污染的局部用溶液，或实验室污染。

**调查**：确认病例定义并评估每位患者的临床状况；列出每份标本对应的支气管镜序列号、清洗机和日期；**对分离株分型**（全基因组测序），看它们是否相同；培养支气管镜、清洗机和水；审查消毒流程。**控制**：停用可疑的内镜或清洗机，通知患者的主管医生（有些患者可能接受了不必要的抗生素），并上报事件。假暴发很重要：它们导致不必要的治疗，而同样的设备故障也可能传播真正的感染。
:::
:::

**新发感染与全球卫生安全。** COVID-19大流行、西非埃博拉疫情（2014–2016年）、猴痘以及反复出现的禽流感表明，新出现或再出现的病原体可以传播得多么迅速。**《国际卫生条例（2005）》**要求各国发现、评估并报告可能构成**国际关注的突发公共卫生事件**的事件，由WHO总干事宣布。在国内，英格兰的医生必须向卫生防护团队报告所列传染病的疑似病例，不必等待实验室确认，以便尽早采取公共卫生行动（[[public-health/communicable-disease-control]]）。

::: history
1854年，约翰·斯诺（John Snow）绘制了伦敦宽街水泵周围霍乱死亡病例的地图，表明病例在水泵周围聚集，并说服当局拆除了水泵手柄：这是暴发调查的奠基性范例。1907年，对纽约家庭伤寒病例的调查追查到玛丽·马伦（Mary Mallon），一位从事厨师工作的无症状携带者。在青霉素研发期间，爱德华·亚伯拉罕（Edward Abraham）和恩斯特·钱恩（Ernst Chain）描述了一种能破坏青霉素的细菌酶（1940年）。1945年，亚历山大·弗莱明（Alexander Fleming）在诺贝尔奖演讲中警告，剂量不足会让耐药微生物出现。1951年，亚历山大·朗缪尔（Alexander Langmuir）在美国传染病中心创建了流行病情报服务，培训现场流行病学的“疾病侦探”。2015年，世界卫生大会通过了《抗微生物药物耐药性全球行动计划》；2016年，由吉姆·奥尼尔（Jim O'Neill）主持的英国评估报告使耐药的经济和人员代价受到广泛关注。
:::

::: quiz
一家护理院腹泻暴发的流行曲线显示先出现一个小峰，随后两周内大约每两天出现一个更大的峰。最可能是哪种类型的暴发？
- [ ] 来自一餐饭的点源暴发
- [ ] 持续性共同来源，如被污染的供水
- [x] 人传人（传播性）扩散，如诺如病毒
- [ ] 由实验室错误导致的假暴发
::: solution
相隔约一个潜伏期（诺如病毒为一到两天）的连续波峰提示人传人的传播性扩散。一餐饭会引起一个尖锐的单峰；持续性来源会形成病例平台。控制重点是隔离或分组安置患病住户、患病员工在症状停止后48小时内不上班、用肥皂和水洗手、加强清洁，以及限制收治和转出。
:::
:::

## 后续内容

抗微生物药物本身见[[microbiology/antimicrobials]]，感染预防与控制见[[microbiology/infection-control]]和[[infectious-diseases/healthcare-infections]]。淋病的耐药见[[infectious-diseases/sexually-transmitted-infections]]，耐药结核见[[infectious-diseases/tuberculosis]]。暴发中使用的流行病学研究设计见[[epidemiology-ebm/observational-studies]]，国家层面的传染病控制见[[public-health/communicable-disease-control]]。

::: summary
- 耐药通过突变和水平基因转移（尤其是质粒）产生，机制为药物灭活、靶点改变、进入减少和外排。抗生素使用筛选出耐药，共同筛选和补偿性突变使其不会消失。
- PK/PD靶标指导给药：β-内酰胺类看高于MIC的时间，氨基糖苷类看峰浓度/MIC，万古霉素和氟喹诺酮类看AUC/MIC。
- 药敏试验（MIC和折点）指导目标治疗，抗菌谱指导经验性选择。
- 抗微生物药物管理：本地指南、48–72小时评估（停用、转换、更换、继续、门诊肠外治疗）、有循证依据的较短疗程、青霉素过敏撤标，以及WHO AWaRe分类；英国的目标是到2029年可及类用量占70%。
- 暴发调查：确认、定义病例、搜索病例、按时间、地点和人群描述、检验假设（罹患率和相对危险度；比值比）、尽早控制并沟通。
- $R > 1$时暴发增长；群体免疫阈值为$1 - 1/R_0$。
:::

## 习题

::: exercise 群体免疫 {level=1 check="1-1/4"}
某感染的$R_0 = 4$。人群中必须有多大比例具有免疫力才能阻止持续传播？答案以小数表示。
::: solution
$H = 1 - 1/R_0 = 1 - 1/4 = 0.75$，即人群的75%必须有免疫力。如果疫苗并非完全有效，接种率还需更高：疫苗效力为90%时，需要$0.75/0.9 \approx 83\%$的接种率。
:::
:::

::: exercise 相对危险度 {level=1 check="8"}
在一次学校午餐暴发中，吃了鸡蛋三明治的30名学生中有24人发病，没吃的50人中有5人发病。与鸡蛋三明治相关的发病相对危险度是多少？
::: solution
罹患率：$24/30 = 0.8$和$5/50 = 0.1$。相对危险度$= 0.8/0.1 = 8$。
:::
:::

::: exercise 求半衰期 {level=1 check="2"}
静脉给药后，某抗生素在1小时时浓度为20 mg/L，5小时时为5 mg/L。假定按一级动力学消除，其半衰期是多少小时？
::: solution
浓度在4小时内从20降至5 mg/L，降低为原来的四分之一，即两个半衰期。所以$t_{1/2} = 2$小时。等价地，$k = \ln 4/4 = 0.347$每小时，$t_{1/2} = \ln 2/k = 2$小时。
:::
:::

::: exercise 高于MIC的时间 {level=2 check="1.5*log2(32)"}
某β-内酰胺类游离峰浓度达32 mg/L，半衰期1.5小时，每8小时给药一次。其浓度超过MIC 1 mg/L的时间是多少小时？对于50% $fT_{>\text{MIC}}$的目标，这一给药方案是否足够？
::: solution
$t_{>\text{MIC}} = 1.5 \times \log_2(32/1) = 1.5 \times 5 = 7.5$小时，占间隔的$7.5/8 = 94\%$，远高于50%的目标。如果MIC为8 mg/L，时间将为$1.5 \times \log_2 4 = 3$小时（37.5%），就需要更频繁给药或延长输注。
:::
:::

::: exercise 青霉素过敏标签 {level=2}
一名45岁蜂窝织炎女性的病历中有“青霉素过敏”。列出你会问的问题，并说明答案如何改变处理。
::: solution
询问：**哪种药物**、**发生了什么**（皮疹及其外观和范围；嘴唇、舌头或喉咙肿胀；呼吸困难；虚脱；皮肤起疱或脱皮；口腔溃疡；器官受累）；首剂后**多久**发生；**多久以前**；是否需要**治疗**（肾上腺素、住院）；**此后**是否曾使用过任何青霉素类或头孢菌素类而无问题；以及标签是否来源于**家族史**或恶心、腹泻等副作用。

**解读**：胃肠道不适或家族史**不是过敏**，因此应撤除标签并使用青霉素类（如氟氯西林）。久远、轻微、非荨麻疹样的皮疹风险低，可能适合按本地方案直接口服激发或转诊撤标。速发反应的特征（荨麻疹、血管性水肿、支气管痉挛、过敏性休克）意味着避免青霉素类、选择替代药物，并转诊至过敏专科。史蒂文斯-约翰逊综合征或DRESS等严重迟发反应意味着永久避免致敏药物及相关药物。结果要准确记录。
:::
:::

::: exercise 根据抗菌谱选择 {level=2}
某医院血培养大肠埃希菌的抗菌谱显示敏感率：阿莫西林42%、阿莫西林-克拉维酸68%、甲氧苄啶64%、环丙沙星84%、头孢曲松88%、哌拉西林-他唑巴坦91%、庆大霉素93%、美罗培南99.9%、替莫西林96%。疑似尿源性脓毒症的经验性治疗指南正在修订。哪些药物是合理的经验性选择，哪些不是？你还需要哪些信息？
::: solution
敏感率远低于80–90%的药物（阿莫西林、阿莫西林-克拉维酸、甲氧苄啶，环丙沙星也有争议）**不适合单独**用于严重感染的经验性治疗，因为会有太多患者接受无效药物。合理的选择包括**庆大霉素**（93%，常在等待培养结果期间单剂或短程与另一种药物联用）、**替莫西林**或**哌拉西林-他唑巴坦**，选择时注意肾功能和过敏情况。**美罗培南**虽然几乎全部敏感，但最好保留给已知携带ESBL或有危险因素的严重脓毒症患者，以限制碳青霉烯类压力。其他信息：克雷伯菌及其他尿路病原体的药敏；社区起病与医院起病感染的耐药差异；患者既往的培养结果和近期使用的抗生素；以及本地艰难梭菌感染率，这可能是不使用广谱β-内酰胺类的理由。
:::
:::

::: exercise 病房里的诺如病毒 {level=3}
三天内，某28张床位的老年病房有八位患者和四名工作人员突然出现呕吐和腹泻。写出病例定义，列出控制措施，并说明如何判断暴发已经结束。
::: hint
诺如病毒的潜伏期为12–48小时，症状停止后仍会排出病毒一段时间。
:::
::: solution
**病例定义**（示例）：自[首例发病日期]起，X病房的任何患者或工作人员，在24小时内出现两次或以上呕吐和/或腹泻（5–7型粪便），且无其他原因可以解释。**确诊**病例粪便中检出诺如病毒；**很可能**病例符合临床定义且有流行病学关联。

**控制措施**：用首批病例的粪便标本确认；把有症状患者**隔离**在单人间或**分组安置**在一个隔间；关闭受累隔间（或病房），停止收治和转出，并进行兼顾患者流转的风险评估；**患病员工**在症状停止后48小时内**不上班**；**用肥皂和水洗手**（含酒精手消毒剂对诺如病毒效果较差）；戴手套和围裙；用含氯消毒剂加强清洁，尤其是厕所和频繁接触的表面；限制探视并告知探视者；与感染预防与控制团队、床位管理人员和卫生防护团队沟通；每日更新病例一览表和流行曲线。

**宣布暴发结束**：按本地政策，通常在**没有新病例出现、且最后一例症状消失至少48小时后**（有些政策采用72小时），随后对受累区域进行**终末清洁**再重新开放。
:::
:::

::: exercise 病例对照研究 {level=3 check="9"}
询问40名沙门菌感染者（病例）和80名未感染者（对照）是否在某家餐馆就餐。30名病例和20名对照报告曾在那里就餐。计算比值比，解释为什么采用病例对照而不是队列设计，并解读结果。
::: solution
2×2表：病例中暴露30人、未暴露10人；对照中暴露20人、未暴露60人。

$$
\text{OR} = \frac{30 \times 60}{10 \times 20} = \frac{1800}{200} = 9
$$

**为什么用病例对照**：在这家餐馆就餐的人无法全部确定（它面向公众营业），因此无法计算罹患率；但可以通过实验室报告找到病例，并从同一人群中招募对照。**比值比**为9，意味着病例在该餐馆就餐的比值是对照的九倍，这是关联的有力证据。但这不是证明：必须考虑机遇（计算置信区间）、偏倚（病例回忆暴露的方式可能与对照不同，对照必须与病例来自同一人群）和混杂。微生物学证据，如通过全基因组测序把病例分离株与食物或厨房样本联系起来，将加强结论，并为在该餐馆采取控制措施提供依据。
:::
:::
