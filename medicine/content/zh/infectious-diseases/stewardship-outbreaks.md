抗菌药物的耐药是医学中最清晰的一个例子：收益由私人享受、而代价由公共支付：**每一程抗生素都帮助了一个患者、并消耗了一个分子、而没有任何个体处方者会获得他们这次处方所消耗掉的未来敏感性。**管理是一门把那个未来变得可见并可被追问的学科；而暴发的控制是同一项技能应用于传播而不是选择——早发现、断链条、清楚沟通、并公开地学习。

本章涵盖耐药的机制及其临床判读、管理的科学、抗菌药物的治理、及暴发的发现与处理。

## 耐药与如何读它

::: definition 临床的耐药工具箱 {#def-resistance}
**四种机制（酶的破坏或修饰——β内酰胺酶：从青霉素酶到超广谱酶到AmpC到碳青霉烯酶（KPC、NDM、OXA-48）——及氨基糖苷的修饰酶、及氯霉素的乙酰转移酶；靶标的保护或改变——mecA改变的PBP2a、及D-Ala-D-Lac的万古霉素靶标、及大环内酯的核糖体甲基化、及喹诺酮耐药决定区、及四环素与利奈唑胺的核糖体保护蛋白；及通透性与外排的排列组合——孔蛋白的丢失、与把单一机制变成泛耐药的外排泵；及旁路——万古霉素的操纵子与甲氧苄啶磺胺的旁路——[[microbiology/bacteria]]、[[microbiology/bacterial-pathogenesis]]、[[microbiology/antimicrobials]]）；基因的后勤（被选择的染色体突变、对获得的质粒传播：接合、转导、转化、整合子把整排耐药基因堆叠、转座子在种之间跳跃、而质粒才是真正的流行病学单位——那个可移动的基因库，就是淋病与克雷伯菌的教训会旅行的原因——[[microbiology/bacterial-pathogenesis]]、基因转移的类比见[[microbiology/bacteria]]）；适合度、代价与补偿（耐药带有代价、而撤药可以让敏感性回来、带那段著名的“黏菌素之后氨苄西林”时代的乐观、被补偿性突变 被打折、以及对长周期数据的需要、及协同敏感与异质性耐药、及把“耐受”与“耐药”分开的生物膜庇护所——这对器械很重要——[[infectious-diseases/healthcare-infections]]、[[microbiology/microbiota]]）；及为何微生物组才是那个患者（抗生素的生态学——菌群失调与艰难梭菌及抗生素后腹泻、及菌群“恢复力对替代的稳定状态”之问、及新生儿与衰弱高龄附带损害的窗口、及粪移植时代作为应用微生物学——[[gastrointestinal/digestion-absorption]]、菌群的一行见[[paediatrics/growth-development]]、[[infectious-diseases/healthcare-infections]]）。**
:::

::: definition 读药敏图谱 {#def-antibiogram}
**从表型到基因型的推断（报告的判读纪律——头孢曲松与头孢他啶及氨曲南上的超广谱酶签名、及SPACE 菌群中的AmpC与可诱导的表达、及为何“超广谱酶阳性的大肠埃希菌”是一个处方事件、而不是一行报告；及耐甲氧西林对甲氧西林敏感葡萄球菌的基础、及肠球菌对柠檬明串珠菌与片球菌陷阱、及葡萄球菌与链球菌中诱导性克林霉素耐药的D试验、及金黄色葡萄球菌与复方磺胺的细微之处、及头孢他啶阿维巴坦对美罗培南法硼巴坦对头孢地尔、按碳青霉烯酶的类别配对、并诚实记住这些是与药学与微生物学的对话——[[clinical-skills/laboratory-tests]]、[[microbiology/laboratory-diagnosis]]、[[microbiology/antimicrobials]]、[[pharmacology/metabolism-excretion]]）；监测的一层（时点患病率的调查、与带分母的、而不是一张贴在墙上的纸的药敏图谱、及全院对重症对病房层面的趋势、及血培养专特的对尿液为主的数据库、及全球与区域的监测报告、及带聚簇检测的基因组叠加、及“不要把定植与感染合并统计”的规则、及耐药归因的模型、在“归因的死亡”对“相关的死亡”上的诚实——[[epidemiology-ebm/measuring-disease]]、[[public-health/communicable-disease-control]]、环境的几行见[[public-health/environmental-occupational]]、[[infectious-diseases/tropical-infections]]）；不确定之下的临床决定（经验对目标对抑制的定框、及按风险因素加权的经验选择：近期抗生素与转诊史及旅行与本地生态、及预后严重度与源头控制的优先、及在48-72小时降阶梯作为管理的核心动作、及缩短疗程的证据基础——对许多革兰阴性菌血症与社区肺炎及源头控制后的腹腔感染，“更短”是非劣的、及骨髓炎与心内膜炎及假体的例外、带口服降阶梯试验的结果——[[microbiology/antimicrobials]]、[[emergency-critical-care/shock-fluids]]、[[cardiovascular/valve-congenital-disease]]、[[surgery/acute-abdomen]]、[[musculoskeletal/bones-joints]]、[[infectious-diseases/healthcare-infections]]）。**
:::

## 管理与治理

::: definition 管理规划实际做什么 {#def-stewardship}
**核心的干预前瞻性的审计与反馈、由感染病专科复审超过48-72小时的抗生素、及对被列为储备的药物的预授权——要节制地使用这个机制、因为审批的队列也会杀人、及处方集的架构：受限对不受限类别的逻辑、及把本地的药敏图谱放进每一本处方集、及静脉转口服的切换、带临床稳定的标准与高生物利用度的药物（利奈唑胺、氟喹诺酮、甲硝唑、多西环素、克林霉素的原理、及门诊静脉抗感染治疗的安全系统——[[microbiology/antimicrobials]]、[[pharmacology/dosing-principles]]、[[pharmacology/absorption-distribution]]、[[clinical-skills/clinical-reasoning]]）；诊断的一半（在抗生素之前采血培养、及标本的质量与污染率作为绩效指标、及快速诊断与它们能回答的问题：质谱鉴定的速度、血培养阳性组合、耐药基因聚合酶链、半乳甘露聚糖、与结核的快速分子检测、以周转时间为终点、及在发热综合征中由快速检测指导的抗生素决策、及降钙素原的算法、带诚实的荟萃分析：它们显示抗生素天数减少、但没有一致的死亡率信号、及剂量与安全的邻近：万古霉素按曲线下面的治疗药物监测与肾功能的调整、及药学的责任——[[microbiology/laboratory-diagnosis]]、[[clinical-skills/laboratory-tests]]、[[pharmacology/dosing-principles]]、[[renal/acute-kidney-injury]]、[[emergency-critical-care/acute-assessment]]）；沟通的一层（抗生素敏感的中心、与咽痛及咳嗽的延迟处方、及有效的接诊脚本、对比那些没用的传单、及兽医与农业及水产及社区药房的维度：同一健康、及公众参与的运动的证据：知识对期待的落差、及“不要为坚持要药的父母开药”这一说法的检验、及在低收入地区的耐药中占主导的自我用药与非正式市场的经济——[[public-health/prevention-promotion]]、[[public-health/determinants-inequalities]]、[[public-health/global-health]]）；及占据多数的基层与长期照护中的管理（数十亿的门诊限定日剂量、与呼吸道感染及尿路及皮肤的处方、及以问题为基础的教育对作为背景板的审计干预、及疗养院抗生素处方决策支持的试验、及减少无症状菌尿的治疗、及牙科与视光及非处方柜台的声音——[[public-health/health-systems-economics]]、[[geriatrics-palliative/polypharmacy]]、[[renal/urinary-tract]]、淋病的前线见[[infectious-diseases/sexually-transmitted-infections]]）。**
:::

::: definition 治理、激励与研发管线 {#def-governance}
**全球的架构（世界卫生组织的行动计划、与重要抗菌药物的清单、及“人类医学中最高优先级的重要药物”的分类、及各国行动计划及其监测、及同一健康的国家间协调、及把耐药列为政治宣言的主题——[[public-health/global-health]]、[[microbiology/antimicrobials]]）；经济学与管线（市场失灵的科学：抗生素是短期使用、低利润、且成功即意味着少用的商品、及试点的“订阅式”付费模型、脱离销量而按价值付费、及研发管线的现状：以组合包装的旧分子与窄谱为主、及新诊所的抗生素、及被取消的与靠资助续命的、及把耐药当作一个创新问题来讨论时必须带上的诚实——[[pharmacology/drug-development-prescribing]]、[[public-health/health-systems-economics]]）；准入的双重使命（在过度使用之外还有使用不足：基本抗生素的供应链中断、及贫困国家对肺炎与新生儿脓毒症的可及性、及“可及对管理”这对孪生的目标、及疫苗与水质与诊断作为减少抗生素需求的杠杆、及在抗生素时代之前疾病负担的那条曲线——[[public-health/global-health]]、[[public-health/vaccination-programmes]]、[[infectious-diseases/tropical-infections]]）；本地的治理（处方集与委员会、及带绩效指标的抗微生物药物学与感染控制在国家计划下的义务、及多学科团队：药学与微生物学与感染控制与管理层的四方、及审计与反馈与教育的规划、及那个“谁拥有第61小时的决策”的问题——[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]、[[microbiology/infection-control]]）；及话语与诊断的可及性（快速分子检测的支付方、在“少用抗生素”这一收益难以入账时、及把耐药叙事保持为“我们仍可以做事”而不是宿命、及在患者那里对抗“超级细菌”恐惧营销的做法、好让必要的抗生素不被拒绝——[[epidemiology-ebm/diagnostic-tests]]、[[clinical-skills/communication]]、[[public-health/prevention-promotion]]）。**
:::

::: example 病房上的超广谱酶 {#ex-esbl}
一名78岁的疗养院居民因跌倒入院；导尿管标本的尿培养长出产超广谱酶的大肠埃希菌；她没有尿路症状；而那位基础培训的医师因为“它耐药”而去拿美罗培南。
::: solution
**一张医嘱里的两个错误——治疗定植、并误读报告（[[#def-antibiogram]]、[[#def-stewardship]]）：无症状菌尿的规则——留置导管的疗养院居民是被定植的、而治疗买到的是耐药与艰难梭菌、不是保护；发热与症状及来源的决定要建立在临床的框架上——[[renal/urinary-tract]]、[[infectious-diseases/healthcare-infections]]、[[geriatrics-palliative/ageing-frailty]]；“超广谱酶”在处方上意味着什么——超广谱酶阳性的肠杆菌目常常在体外并对膀胱炎在临床上仍可用呋喃妥因、及敏感时可用复方磺胺或环丙沙星、及一剂小剂量氨基糖苷、及那个碳青霉烯之问：当确实是侵袭性感染且没有口服选项时、及关于梗阻与结石与导管本身的源头控制思维——[[microbiology/antimicrobials]]、[[clinical-skills/medical-imaging]]；降阶梯与沟通这个动作——打电话给微生物学家问背景、而不只是看报告、并把适应证与停止日期写进病历、及与疗养院的沟通、因为一张写着“超广谱酶”的标签会永远跟着她、并改变未来的经验性选择——[[clinical-skills/records-handover]]、[[microbiology/laboratory-diagnosis]]；及面向未来的审计——本季度同一病房有多少例超广谱酶、它们是否相关、感染控制团队看传播、而管理看最初是什么驱动了这次筛查——[[public-health/communicable-disease-control]]、[[infectious-diseases/healthcare-infections]]。**
:::
:::

::: example 那个并不是暴发的聚簇 {#ex-pseudo}
六周内有三名重症患者痰中长出嗜麦芽窄食单胞菌；其中两人用过同一台支气管镜；实验室问你们“有没有看到什么奇怪的”。
::: solution
**假暴发对真实聚簇——快速回答实验室（[[#def-resistance]]、[[#def-governance]]）：微生物的信号——嗜麦芽窄食单胞菌作为低毒力但高信号的微生物、带水与潮湿的流行病学、及选择性抗生素的压力碳青霉烯及“这个重症监护室用得最多的药是什么、在什么时候”之问、及它是真肺炎还是带异常痰的定植——[[microbiology/bacteria]]、[[infectious-diseases/healthcare-infections]]；流行曲线与名单——按支气管镜的场次、及湿化器、与水槽、及再处理记录的复查、与感染控制与内镜团队及重症主管一起、及对同一班次的员工访谈——[[epidemiology-ebm/observational-studies]]、[[microbiology/infection-control]]；环境与微生物的工作——标本与水槽与机器的采样、及药敏的配对、及全基因组的比较以区分共同来源与独立出现、及那个诚实的类别：因采集与运送不完善而造成的污染——[[microbiology/laboratory-diagnosis]]、[[genetics/genomic-medicine]]；及不确定之下的行动——暂时撤下支气管镜或越过再处理的流程、加强清洁、剪存记录、及向重症的医护、家属与转诊医院沟通检测的取消若再处理确实失败、带那次改变再处理设计而不只是几分钟的事后复审——[[public-health/communicable-disease-control]]、[[clinical-skills/patient-safety]]、[[medical-ethics-law/professionalism-regulation]]。**
:::

::: example 活过了自己适应证的那支抗生素 {#ex-cdiff-switch}
一名81岁的误吸性肺炎患者、在静脉用阿莫西林克拉维酸的第7天出现每日四次的水样腹泻；她现在无热、血氧好、C反应蛋白在降、但病房说“疗程要到第10天结束”。
::: solution
**早切换、早停止——两根管理的杠杆同时触发（[[#def-stewardship]]、[[infectious-diseases/healthcare-infections]]）：修订停止日期——那些是化学性肺炎对细菌性肺炎误吸事件的轨迹、及在有支持时的5至7天的标准、及“C反应蛋白下降且临床良好”的患者作为停止的许可、而不是按习惯把疗程做完、并把理由记录在案、好让夜班团队不会重启——[[respiratory/respiratory-infections]]、[[microbiology/antimicrobials]]、[[clinical-skills/records-handover]]；腹泻的检查——只在明显不成形的粪便时检测艰难梭菌、及缓泻剂的复审与药物的原因、及尽早经口进食与营养、及感染控制的即刻动作：在等待时接触预防与用肥皂和水——[[gastrointestinal/bowel-disease]]、[[microbiology/laboratory-diagnosis]]、[[microbiology/infection-control]]；“下次别这样”的一课——这次住院的哪几天是不必要的、及预防对治疗的漂移、及“不要因为一个痰臭的故事就升级到广谱的厌氧覆盖”、而普通的氨苄西林加甲硝唑或阿莫西林克拉维酸的短程就够了——[[pharmacology/adverse-reactions]]、剂量见[[renal/chronic-kidney-disease]]；系统的另一半——审计本病房超过72小时未经复审的抗生素天数、及那份切换清单、及高生物利用度的口服选项、及若她确实是艰难梭菌阳性且有传染性时对疗养院的通报——[[public-health/communicable-disease-control]]、[[infectious-diseases/healthcare-infections]]、[[public-health/health-systems-economics]]。**
:::

::: example 那次作为哨兵的治疗失败 {#ex-gc-resistance}
一名用肌注头孢曲松1克治疗淋病的患者一周后带持续分泌物复诊；复测的核酸检测阳性、而实验室报告培养上头孢菌素敏感性下降。
::: solution
**同时治疗这个微生物与这个流行病学（[[#def-antibiogram]]、[[infectious-diseases/sexually-transmitted-infections]]）：患者的流程——立即不是一周后联系微生物专家与公共卫生、并重取带日期与性伴及旅行的详细性史、并按专科指导以高剂量头孢曲松加第二种药物治疗、及在第7至14天以核酸检测做治愈的确认、带培养的确认——[[infectious-diseases/sexually-transmitted-infections]]、[[microbiology/antimicrobials]]、[[clinical-skills/laboratory-tests]]；流行病学的仪器——送分离株做参考的测序、与最低抑菌浓度的参考实验室组合、及与国家的输入事件做系统发育的比较、及紧急追溯暴露的网络、因为第二个未治疗的性伴就是放大的一步——[[public-health/communicable-disease-control]]、[[genetics/genomic-medicine]]；门诊的回应——复审所有近期淋病治疗的治愈确认状态、并考虑加强的经验剂量、及与同事一起复审双重覆盖的策略、及把指导的变化通知到性健康与急诊的同事，好让指导一起改变——[[microbiology/infection-control]]、[[infectious-diseases/healthcare-infections]]；及沟通这条线——对患者不带责备地解释：他们为什么是一朵重要的一次重要流行的尖端、以及现在的禁性生活与性伴治疗能保护什么、及与公共卫生共同进行的媒体联络——[[clinical-skills/communication]]、[[public-health/determinants-inequalities]]。**

## 处方者三个诚实的问题

本章的一切可以压缩成三个值得教成本能的问题。第一：考虑到培养的结果与源头，对这个患者而言仍然安全的最小疗程与最小谱是什么？医院里几乎所有的过度使用，都是在第72小时没有想到这个问题、而不是因为相信抗生素能治好比它实际更多的病。第二：这一程抗生素正在让“患者未来的自己”付出什么代价——下一次尿路感染、下一次手术、下一次抗生素？这个问题没有问错的时候、而它的答案因定植状态、年龄、居住地与地理而差别极大。第三：什么会让我今天停？在开始时写下一个停止的条件、就把抗生素治疗从一个漂流的默认、变成一个被有意更新的决定。管理规划、储备药物的政策、同一健康的规则与管线的补贴、是同样三个问题的制度化；而当房间里没有人记得问题是临床的、而不是行政的，制度就恰好在那时失效。

再给暴发的值班台一条：速度本身就是一种控制措施。怀疑与行动之间的每一小时都会缩短流行曲线、这就是为什么本章小结末尾那个实验室的电话不是一天的干扰、而是这一天最有价值的数据。

## 为何乐观仍然是正确的立场

把本章读成一场慢动作的失败很容易、而诚实的版本既不凯歌式也不末日式。耐药的趋势是真实的、在局部是严峻的、但同样是这二十年、包含了b型流感嗜血杆菌疫苗几乎彻底逆转了侵袭性的疾病、外科预防从每周的输注变成一次及时的给药、若干国家通过不体面的Bundle把医院的耐甲氧西林金葡菌减半、以及丙肝与结核方案的治疗革命——在1995年听起来会像科幻小说。胜利没有一项来自一个新的分子；它们来自测量、反馈、激励与沟通——管理真正的工具箱——应用于特定的微生物与特定的时刻。这份记录支持把耐药当作一个“附带未解科学的、可解决的管理问题”、而不是一场什么都不管的洪水。

对你执业第一年的推论是温和而完全可达成的。在花几分钟的前提下、于第一剂之前留取培养。在开始时写下适应证与停止日期。即使在病房很忙时也在第72小时复审、因为这一个动作就是那个证据最好的干预。像记药物剂量那样记住你本地的药敏图谱。接微生物学家的电话、并回电话。这五个习惯、由普通的临床医师保持整个职业生涯、就是每一份国家行动计划试图用政策语言描述的全部内容、也是下一个分子无论何时到来、在你需要它的那一天仍然有效的原因。

最后一个值得保留的框架：抗生素是唯一一类“它对你的价值主要取决于别人如何使用它”的治疗。这个奇特的属性、就是它们招来别的药物都不承受的治理的原因、也是临床医师与微生物实验室的关系不是一种服务安排、而是一份关于未来的社会契约的可见边缘的原因。在日常的小事上遵守它、这个抽象就不再重要；忽视它、那么没有任何政策文件能挽回局面。这份契约可以一句话说完：把这个分子当作有限的来开处方、因为它确实是你药箱里唯一一件有限东西。

::: history
**耐药的历史是一场有着可预测排名的赛跑：弗莱明在1943年提纯青霉素的时代就发出警告——马虎的使用会孕育耐药——从诺贝尔的讲台上说出来、听来已像预言；金黄色葡萄球菌对青霉素的耐药在最初的试验中就已经存在、1959至61年给出了甲氧西林这个答案、而它自己在医院的数十年内衰落——[[microbiology/bacteria]]、[[infectious-diseases/healthcare-infections]]；四环素的拓宽、与1960年代痢疾杆菌监测与日本流行病学的那场质粒革命——它第一次教会了人们多重耐药的可传播性——[[microbiology/bacterial-pathogenesis]]、痢疾见[[infectious-diseases/tropical-infections]]；1940至70年代那台抗生素发现的黄金时代引擎、随后因革兰阴性的缺口而停转、及1990年代之后“紧邻医院的发现实验室”模式的几近灭绝、及大型药企退出的那一年、及奥尼尔评审与耐药经济学报告的时代及它们的订阅式付费试点——[[pharmacology/drug-development-prescribing]]、[[public-health/global-health]]；管理的科学谱系——1990年代的感染病会诊医师审计与反馈试验、及预授权对审计的比较、及缩短疗程的试验浪潮：革兰阴性菌血症的14天对7天、肺炎的5天对10天、源头控制后腹腔感染的短程研究、及口服降阶梯与骨髓炎的试验——[[microbiology/antimicrobials]]、骨髓炎见[[musculoskeletal/bones-joints]]；及基因组公共卫生的时代——对淋病与结核耐药的实时测序监测、及基于废水的耐药与抗生素监测规划、及新冠期间关于继发感染处方激增的观察、作为最新的一次演示：管理是系统的一种属性、而不是一张海报——[[infectious-diseases/tuberculosis]]、[[infectious-diseases/sexually-transmitted-infections]]、[[public-health/environmental-occupational]]。**

::: summary
- 耐药是遗传学加上选择加上传播；管理攻击选择、预防攻击传播、而诊断改善了驱动两者的处方。
- 把药敏图谱当作推断来读：超广谱酶的签名、可诱导的耐药、储备药物的配对，是与药学和微生物学的对话、而不是一行报告。
- 在72小时审计并反馈、按培养降阶梯、短疗程、尽早转口服、及诊断的管理、是有证据的干预；海报不是。
- 不要治疗定植、导管或尿试纸；不要在呋喃妥因就够的地方派出碳青霉烯。
- 耐药的治理是经济学：市场无法为一个分子的未来定价、所以可及性的目标、订阅式的试点、与同一健康的规则正在试图做到。
- 暴发与假暴发都从实验室的一通电话开始；尽早接、列出暴露、比较基因组、对传播采取行动、并把教训发表出来。
:::

## 继续深入

用一段话概括感染性疾病的思维：按来源、途径、宿主与时间思考。在给综合征命名之前先确定来源；问暴露史允许什么、以及本地的耐药地图让什么变得可能；一切都按站在你面前的那个宿主来调整；并把时钟当作一种药——脓毒症与心内膜炎及脑膜炎的结局是小时数的函数。然后用这个专科的两种失败模式审计自己：在那些不典型的呈现继续演变时锚定在第一个可信的微生物上、以及永远不降阶梯——那个本该在第三天发生的窄谱转换没有发生。两种失败都能靠一个习惯治好：在每一次复审时重新问一遍，昨天的病史说了什么、而今天它不再说什么。
