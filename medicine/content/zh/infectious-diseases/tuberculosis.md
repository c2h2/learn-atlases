结核病（TB）是一种古老的疾病，用廉价药物即可治愈，但它仍然是全球单一感染性病原体所致死亡的首要原因。WHO 2025年全球报告估计，2024年有1070万人患结核病，123万人死亡。据认为，世界人口中约四分之一曾在某个时候被感染。他们中的大多数人永远不会发病；细菌终身被控制住。挑战在于发现并治愈传播疾病的活动性患者，并对进展风险高的人治疗其感染。

结核病要求缓慢而细致的思考。它的症状含糊，在数周内逐渐出现。它几乎可以累及任何器官。它的治疗要持续数月，需要多种药物联合。它的管理总有公共卫生的一面：每一个病例都是从某人那里感染的，也可能已经传给了别人。

本章介绍病原体以及感染如何发展为疾病、肺结核、治疗、无疾病的结核感染、肺外结核和耐药。英国的做法遵循NICE（NG33）和英国卫生安全局的指南；国际做法遵循WHO。治疗方案以原则形式描述；治疗总是由结核病专科服务监管。

## 病原体与感染

::: definition 结核分枝杆菌 {#def-mtb}
**结核分枝杆菌（*Mycobacterium tuberculosis*）**是一种生长缓慢、专性需氧的杆状细菌。它与牛分枝杆菌（*M. bovis*，来自牛）和非洲分枝杆菌（*M. africanum*）共同构成结核分枝杆菌复合群，均可引起结核病。其细胞壁富含长链**分枝菌酸**，使它防水、能抵抗许多消毒剂和药物，并具有**抗酸性**：一旦用石炭酸复红（齐-内染色，Ziehl–Neelsen）或金胺（荧光染色）等染料着色，就能抵抗酸和酒精的脱色。它大约每天才分裂一次，因此培养需要两至六周。

结核病通过**空气中的飞沫核**传播：咳嗽排出的微小颗粒在空气中悬浮数小时，小到足以到达肺泡。只有肺部或喉部患病的人才有传染性；痰涂片阳性者和有空洞者风险最大，风险还取决于接触的密切程度和持续时间。
:::

::: proof
**从感染到发病。** 吸入的杆菌被肺泡巨噬细胞吞噬。与大多数细菌不同，结核分枝杆菌能阻止吞噬体与溶酶体融合，从而在巨噬细胞内存活。它缓慢繁殖，扩散到肺门淋巴结，并有少量经血流播散到其他器官。

两至八周后，细胞介导的免疫应答形成。CD4辅助性T细胞1型释放**γ干扰素**，激活巨噬细胞杀灭细胞内细菌；**肿瘤坏死因子**帮助组织并维持**肉芽肿**：由活化的巨噬细胞（上皮样细胞和多核巨细胞）组成、外周环绕淋巴细胞的结构。其中心常发生**干酪样坏死**，即奶酪样的坏死组织。最初的肺部病灶是**Ghon灶（原发灶）**；它与受累的肺门淋巴结共同构成**Ghon复合征（原发综合征）**，日后可能钙化。

在大多数人中，肉芽肿把感染局限住：杆菌以缓慢复制的状态存活而不引起症状。这就是**结核感染**（传统上称“潜伏性结核”）。当平衡被打破时便发病：或在感染后不久（**原发性结核病**，尤其见于幼儿和HIV感染者），或在多年以后（**内源性复燃**）。没有HIV的感染者中，约5%–10%终生会发病，其中一半在最初两年内。HIV感染、使用TNF抑制剂或其他免疫抑制剂、近期感染、糖尿病、慢性肾脏病、硅沉着病、营养不良、吸烟、酗酒和年幼都使风险急剧上升。复燃时，细菌在氧供充足的**肺尖**繁殖；干酪样中心液化并排入支气管，留下一个**空洞**，其中可能含有十亿个杆菌，并通过痰液把它们播散出去。
:::

## 肺结核

::: definition 活动性肺结核 {#def-pulmonary}
**活动性肺结核**是由不断繁殖的结核分枝杆菌引起的肺部疾病。典型表现在数周至数月内出现：**持续两到三周以上的咳嗽**、咳痰，有时咯血、发热、**盗汗**、体重下降和乏力。胸片的典型表现是上叶实变伴**空洞**，但也可表现为肺门淋巴结肿大、胸腔积液、由血行播散引起的弥漫微小结节（**粟粒型**），或几乎正常，尤其是在HIV感染者中。

**诊断**依靠在呼吸道标本（痰、诱导痰或支气管肺泡灌洗液；至少两到三份，包括一份清晨痰）中找到病原体：

- 抗酸杆菌**涂片镜检**：快速、廉价，但每毫升需要约5000–10,000个杆菌，因此会漏掉许多病例。
- **核酸扩增试验（NAAT）**，如Xpert MTB/RIF Ultra：数小时内检出结核分枝杆菌DNA，同时检测导致**利福平耐药**的*rpoB*基因突变。WHO推荐把快速分子检测作为首选的初始诊断试验。
- **培养**，最好用液体培养基：最灵敏的检测方法，也是全面药敏试验所必需的。在英格兰，培养分离株要做**全基因组测序**，以鉴定菌种、预测耐药，并显示病例之间是否存在传播关联。
:::

在英国，结核病是**法定报告疾病**。诊断会启动**接触者追踪**：对家庭和其他密切接触者评估是否有活动性疾病和结核感染。住院的疑似传染性肺结核患者被安置在单人间并采取空气传播预防措施（怀疑耐药时用负压病房）；药物敏感者在接受两周有效治疗后通常被认为不再具有传染性。

每一位确诊结核病的人在治疗前都要接受**HIV检测**，并检测乙型和丙型肝炎、糖尿病以及肾功能和肝功能。

::: example 持续数月的咳嗽 {#ex-cavitary}
一名45岁男性八年前从印度移居英国，咳嗽咳痰三个月，伴盗汗和体重下降7 kg。他与妻子和两个十几岁的孩子同住。胸片示右上叶实变和一个3 cm的空洞。痰涂片抗酸杆菌阳性；Xpert MTB/RIF Ultra检出结核分枝杆菌，**未检出利福平耐药**。HIV检测阴性；肝肾功能正常。
::: solution
**诊断**：涂片阳性的空洞型肺结核，在培养和测序结果出来之前推定为药物敏感。

**治疗**：药物敏感肺结核的标准方案是**两个月的强化期**，用异烟肼（isoniazid）、利福平（rifampicin）、吡嗪酰胺（pyrazinamide）和乙胺丁醇（ethambutol），随后是**四个月的巩固期**，用异烟肼和利福平（记作**2HRZE/4HR**）。与异烟肼同服吡哆醇（pyridoxine）以预防神经病变。一旦确认对异烟肼敏感即停用乙胺丁醇。开始治疗前：检查基线肝肾功能，并因乙胺丁醇而检查视力和色觉。剂量按处方集根据体重确定。

**感染控制与公共卫生**：他有传染性。在接受两周治疗之前应予隔离（适当时可居家隔离，避免接触新的人）。病例要报告给卫生防护团队，他的妻子和孩子要筛查活动性结核和结核感染。

**依从性**：治疗失败主要是因为没有服药。在英国，指定的个案管理员、固定剂量复合片以及必要时的直接督导或视频督导治疗是标准做法。两个月时复查痰液；如果届时培养阳性，就需要评估依从性和耐药情况。
:::
:::

## 结核病的治疗

::: theorem 结核病治疗的原则 {#thm-treatment}
1. **多药联合。** 大量的细菌群体中总是含有耐药突变株；联合使用菌株敏感的多种药物，可以确保没有能耐受所有药物的突变株存活。
2. **治疗以月计。** 干酪样物质中和巨噬细胞内的杆菌复制缓慢，被杀灭也缓慢。多药的**强化期**迅速降低细菌负荷；用药较少的**巩固期**杀灭残留的“持留菌”，防止复发。
3. **确保服药。** 治疗不完整会导致复发和获得性耐药。整个疗程都要提供支持，有时需直接督导。
:::

::: proof
**单药治疗为何失败。** 导致耐药的自发染色体突变以特征性的频率出现：大约每$10^{6}$个杆菌中有一个对异烟肼耐药，每$10^{8}$个中有一个对利福平耐药。一个空洞可含有$10^{8}$–$10^{9}$个杆菌，因此在任何治疗之前就已含有约$10^{2}$–$10^{3}$个异烟肼耐药菌和$1$–$10$个利福平耐药菌。由于这些突变相互独立，同时对两药耐药的杆菌频率约为$10^{-6} \times 10^{-8} = 10^{-14}$，在单个患者体内预计不会存在这样的细菌。单用异烟肼会杀死敏感的多数，留下耐药的少数繁殖；两药联用则能杀死全部细菌。1948年链霉素试验正是揭示了这一逻辑：单药治疗数月内即出现耐药。
:::

| 药物 | 主要不良反应及要点 |
|---|---|
| 异烟肼（H） | 肝炎；周围神经病变（用吡哆醇预防，尤其是糖尿病、酒精依赖、营养不良、肾脏病、HIV感染或妊娠者） |
| 利福平（R） | 肝炎；尿液、泪液和汗液呈橙红色；**强效酶诱导剂**，降低激素避孕药、华法林（warfarin）、美沙酮（methadone）、许多抗逆转录病毒药物及其他药物的浓度；少见血小板减少和流感样反应 |
| 吡嗪酰胺（Z） | 肝炎（四种药中肝毒性最强）；尿酸升高和痛风；皮疹 |
| 乙胺丁醇（E） | **视神经炎**，伴视力下降和红绿色觉丧失；肾脏病时减量 |

**药物性肝损伤**是最常见的严重毒性。转氨酶轻度升高很常见且无害。如果ALT升至正常上限的五倍以上、伴症状时升至三倍以上，或者胆红素升高，通常要停药，然后在专科监督下逐一重新加用。

**更短的方案。** 截至2026年，WHO还推荐对12岁及以上的药物敏感肺结核患者使用由利福喷丁（rifapentine）、异烟肼、莫西沙星（moxifloxacin）和吡嗪酰胺组成的**四个月方案**，并对非重症儿童使用四个月方案。**更长的疗程**用于结核性脑膜炎（通常12个月），有时也用于骨关节结核。结核性脑膜炎和心包炎要加用**糖皮质激素**。

::: example 有多少耐药杆菌？ {#ex-mutants}
一个空洞约含$10^{9}$个杆菌。采用异烟肼耐药频率$10^{-6}$和利福平耐药频率$10^{-8}$，估算对下列药物耐药的杆菌期望数：(a) 异烟肼；(b) 利福平；(c) 两者。
::: solution
(a) $10^{9} \times 10^{-6} = 10^{3}$，约1000个异烟肼耐药杆菌。

(b) $10^{9} \times 10^{-8} = 10$个利福平耐药杆菌。

(c) $10^{9} \times 10^{-14} = 10^{-5}$：平均每100,000个这样的空洞中才有一个含有单个双重耐药杆菌。因此，只要所有药物都按时服用，联合治疗杀灭每一个细菌的机会是压倒性的。耐多药主要发生在治疗中断或实际上成为单药治疗时，这使耐药性被逐药筛选出来。
:::
:::

## 无疾病的结核感染

::: definition 结核感染（潜伏性结核） {#def-latent}
**结核感染**（结核潜伏感染）是对结核分枝杆菌持续存在免疫应答、而没有活动性疾病的临床、影像学或微生物学证据的状态。感染者没有症状，胸片正常（或只有陈旧性钙化灶），**没有传染性**。它通过间接方法检出：

- **γ干扰素释放试验（IGRA）**测定受检者T细胞暴露于抗原（ESAT-6和CFP-10）时释放的γ干扰素；这些抗原存在于结核分枝杆菌中，而BCG和大多数环境分枝杆菌中没有。
- **结核菌素皮肤试验（TST，Mantoux试验）**测定皮内注射结核菌素后48–72小时的皮肤硬结。它较便宜，但与BCG接种和环境分枝杆菌有交叉反应。

两种试验都不能区分感染和活动性疾病，在免疫力低下时都可能出现假阴性。
:::

只有在阳性结果会导致治疗时，检测结核感染才有意义。在英国，检测对象包括：肺结核患者的密切接触者；过去五年内从结核病高发国家来英的16–35岁者；HIV感染者；以及在使用TNF抑制剂或其他生物制剂、器官移植和透析之前的人。治疗能大幅降低日后发病的风险。**NICE**推荐**三个月异烟肼加利福平**或**六个月异烟肼**（均同服吡哆醇）。WHO还列出了**三个月每周一次利福喷丁加异烟肼**、四个月每日利福平，以及一个月每日利福喷丁加异烟肼。

::: example 筛查家庭成员 {#ex-contact}
[[#ex-cavitary]]中那位男性的妻子41岁，身体健康，服用复方口服避孕药。她的IGRA阳性，胸片正常。他们15岁的儿子身体健康；他在父亲确诊三周后做的第一次IGRA为阴性。两人各应如何处理？
::: solution
**妻子**没有症状，胸片正常，因此是**结核感染**而不是活动性疾病。来自家庭病例的近期感染进展风险高，所以应提供治疗：按NICE指南，三个月异烟肼加利福平，或六个月异烟肼，均同服吡哆醇。如果使用利福平，她的**口服避孕药会变得不可靠**，在治疗期间及停药后四周内需要采用其他方法（如宫内节育器）。基线时检查肝功能，并告知她一旦出现肝炎症状就停药并就医。

**儿子**可能感染时间太短，IGRA尚未转阳：免疫应答需要两至八周才能形成。他应在**最后一次暴露后约六周复查**。如果转为阳性，则排除活动性结核后治疗结核感染。如果他在任何时候出现症状，无论IGRA结果如何，都要立即评估是否有活动性疾病。
:::
:::

## 肺外结核

::: definition 肺外结核 {#def-extrapulmonary}
**肺外结核**是经血行或淋巴播散引起的肺实质以外的疾病。它约占英国病例的近一半，在HIV感染者、儿童、女性以及南亚和非洲裔人群中更常见。主要类型：

- **淋巴结结核**，最常见：无痛、缓慢增大的淋巴结，通常在颈部，可融合成团、出现波动或破溃流脓（瘰疬）。
- **结核性胸膜炎**：渗出性、以淋巴细胞为主的胸腔积液，腺苷脱氨酶常升高；胸膜活检的阳性率高于胸水培养。
- **结核性脑膜炎**：亚急性头痛、发热和意识混乱，脑神经麻痹、脑积水和卒中。
- **脊柱结核（Pott病）**：相邻椎体及其间椎间盘的破坏，通常在胸椎，伴椎旁或腰大肌脓肿、后凸畸形（驼背）以及脊髓受压的风险。
- **腹腔结核**：类似克罗恩病的回盲部病变，以及伴腹水的腹膜炎。
- **泌尿生殖系统结核**：无菌性脓尿、血尿、输尿管狭窄、不孕。
- **结核性心包炎**：心包积液，后期出现缩窄性心包炎。
- **粟粒型（播散性）结核**：广泛的血行播散，在肺、肝、脾、骨髓和眼脉络膜形成微小结节。

诊断通常需要从受累部位获取**组织或液体**，送检组织学（干酪样肉芽肿）、NAAT和培养。培养还能进行药敏试验，因此总应尽量进行。
:::

::: example 缓慢加重的头痛 {#ex-tb-meningitis}
一名26岁女性头痛和发热两周，现在嗜睡、意识混乱。她因左侧第六对脑神经麻痹而出现复视。血钠128 mmol/L。CT示轻度脑积水。脑脊液：初压升高，白细胞240个/µL（淋巴细胞85%），蛋白2.1 g/L，葡萄糖1.6 mmol/L，同时血糖6.0 mmol/L。革兰氏染色阴性。
::: solution
**解读**：亚急性脑膜炎，脑脊液以**淋巴细胞**为主，**蛋白很高**、**葡萄糖低**（脑脊液与血液比值$1.6/6.0 \approx 0.27$，低于正常的约0.6），伴脑神经麻痹、脑积水和低钠血症，是**结核性脑膜炎**的典型表现。鉴别诊断包括隐球菌性脑膜炎（检测脑脊液隐球菌抗原和HIV）、部分治疗过的细菌性脑膜炎、李斯特菌感染、病毒性脑炎、神经梅毒和癌性脑膜炎。

**检查**：留取大量脑脊液做抗酸涂片、Xpert MTB/RIF Ultra和培养；HIV检测；胸片（可能显示粟粒型或肺部病变）；头颅MRI。

**治疗绝不能等待确诊**：微生物学检查常为阴性，延误会危及生命。一旦临床怀疑即开始治疗：标准四药治疗两个月，再用异烟肼和利福平完成**十二个月**的疗程，并加用**地塞米松（dexamethasone）**——一项越南的试验显示它降低了HIV阴性成人的死亡率；它对HIV感染者的益处尚不确定。脑积水可能需要神经外科引流。结局在很大程度上取决于开始治疗时的病期：这位女性已经嗜睡并有局灶体征，死亡或残疾的风险相当大。
:::
:::

## 耐药结核病

::: definition 耐药结核病 {#def-resistance}
WHO分类（2021年定义）：

- **利福平耐药结核病（RR-TB）**：对利福平耐药，伴或不伴对其他药物耐药。
- **耐多药结核病（MDR-TB）**：至少对**异烟肼和利福平**耐药。
- **准广泛耐药结核病（pre-XDR-TB）**：MDR/RR-TB加上对任何一种**氟喹诺酮类**药物耐药。
- **广泛耐药结核病（XDR-TB）**：pre-XDR-TB加上对**贝达喹啉（bedaquiline）或利奈唑胺（linezolid）**耐药。

当治疗不充分筛选出耐药突变株时，耐药是**获得性**的；当人被耐药菌株感染时，耐药是**传播性**的；今天大多数新发MDR-TB是传播所致。危险因素包括既往抗结核治疗史、与耐药结核患者接触，以及来自MDR-TB高发国家。
:::

WHO估计每年约有40万人发生MDR/RR-TB，其中得到诊断和治疗的不到一半。治疗已有巨大改善。直到约2020年，MDR-TB的治疗要持续18–24个月，包括数月的每日注射，常常导致耳聋。截至2026年，WHO对大多数MDR/RR-TB患者推荐全口服六个月方案，例如**BPaLM**（贝达喹啉、普托马尼（pretomanid）、利奈唑胺和莫西沙星），对氟喹诺酮耐药者用BPaL（不含莫西沙星）。毒性监测包括利奈唑胺相关的全血细胞计数、神经和视力，以及贝达喹啉和氟喹诺酮类相关的心电图QT间期。在英国，所有耐药病例都在国家临床咨询服务的建议下管理。

::: history
1882年3月24日，罗伯特·科赫（Robert Koch）在柏林生理学会上报告了他对结核杆菌的鉴定，采用了新的染色方法和凝固血清培养；这一天现在是世界防治结核病日。阿尔贝·卡尔梅特（Albert Calmette）和卡米耶·介朗（Camille Guérin）用牛分枝杆菌减毒株研制出BCG疫苗，1921年首次给儿童接种；它能保护幼儿免患结核性脑膜炎等重症结核，但对成人肺结核的保护作用不一。1943年，在塞尔曼·瓦克斯曼（Selman Waksman）实验室工作的阿尔伯特·沙茨（Albert Schatz）分离出链霉素。英国医学研究理事会于1948年发表的链霉素试验是最早的随机对照试验之一；它表明该药有效，也表明单独使用时耐药很快出现。随后出现了对氨基水杨酸与异烟肼（1952年）的联合治疗，20世纪60年代末又有了利福平。20世纪70年代，华莱士·福克斯（Wallace Fox）领导的东非和英国试验确立了六个月短程化疗。1993年，WHO宣布结核病为全球紧急事件；几十年来首批新的抗结核药物贝达喹啉和普托马尼分别于2012年和2019年获批。
:::

::: quiz
哪项基线检查是专门因为**乙胺丁醇**而需要的？
- [ ] 血尿酸
- [x] 视力和色觉
- [ ] 听力测定
- [ ] 神经传导检查
::: solution
乙胺丁醇可引起视神经炎，最先影响视力和红绿色觉。基线检查以及嘱咐患者一旦视力有变化立即报告，可以在造成永久损害前停药。吡嗪酰胺升高尿酸；听力测定是过去用于MDR-TB的注射药物所需要的；异烟肼引起的神经病变是用吡哆醇预防，而不是用神经检查来监测。
:::
:::

## 后续内容

分枝杆菌的微生物学见[[microbiology/bacteria]]，肉芽肿性炎症见[[pathology/chronic-inflammation-repair]]。结核病最强的危险因素HIV见[[infectious-diseases/hiv]]，使用生物制剂前的筛查见[[infectious-diseases/immunocompromised-host]]。其他呼吸道感染见[[respiratory/respiratory-infections]]。接触者追踪和传染病控制在[[public-health/communicable-disease-control]]和[[infectious-diseases/stewardship-outbreaks]]中展开。

::: summary
- 结核分枝杆菌是一种生长缓慢、抗酸、经空气传播的病原体。在大多数人中，感染被局限在肉芽肿内；没有HIV的人中约5%–10%会发病，HIV、TNF抑制剂、糖尿病等因素会提高这一风险。
- 肺结核表现为数周的咳嗽、盗汗和体重下降；诊断采用涂片、快速NAAT（同时检测利福平耐药）以及培养加药敏试验。
- 药物敏感结核病用2HRZE/4HR治疗；联合治疗防止耐药，长疗程杀灭缓慢分裂的持留菌。支持依从性是治疗的一部分。
- 主要毒性：肝炎（H、R、Z）、神经病变（H，用吡哆醇预防）、酶诱导（R）和视神经炎（E）。
- 结核感染用IGRA或TST检出，在排除活动性疾病后对高风险者进行治疗。
- 肺外结核需要组织才能诊断；结核性脑膜炎一经怀疑即开始治疗，疗程12个月，并加用糖皮质激素。
- MDR-TB对异烟肼和利福平耐药；BPaLM等全口服六个月方案现已成为标准。
:::

## 习题

::: exercise 毒性配对 {level=1}
把每种药物（异烟肼、利福平、吡嗪酰胺、乙胺丁醇）与其最典型的不良反应或特性配对：(a) 痛风；(b) 红绿色盲；(c) 周围神经病变；(d) 复方口服避孕药失效。
::: solution
(a) 吡嗪酰胺升高血尿酸，可诱发痛风。(b) 乙胺丁醇引起视神经炎。(c) 异烟肼通过耗竭吡哆醇引起周围神经病变。(d) 利福平诱导肝药酶，降低激素避孕药的作用，因此需要宫内节育等可靠的替代方法。
:::
:::

::: exercise 小病灶中的耐药突变株 {level=1 check="100"}
一个非空洞病灶约含$10^{8}$个杆菌。如果每$10^{6}$个杆菌中有一个对异烟肼耐药，预期有多少个异烟肼耐药杆菌？
::: solution
$10^{8} \times 10^{-6} = 10^{2} = 100$。即使不大的病灶也含有耐药突变株，这就是为什么治疗活动性结核从不用单一药物。
:::
:::

::: exercise 谁有传染性？ {level=1}
下列结核病患者中，谁可能对他人有传染性：(a) 涂片阳性的空洞型肺病男性；(b) 颈部淋巴结结核、胸片正常的女性；(c) 患原发性结核伴肺门淋巴结肿大的四岁儿童；(d) 喉结核男性？
::: solution
(a) 是，传染性很强：空洞向痰中释放大量杆菌。(b) 否：没有肺部受累的淋巴结结核不经空气传播（但对破溃流脓的窦道要小心处理）。(c) 通常没有：患原发性结核的幼儿体内杆菌少，咳嗽无力；首要任务是找到感染这个孩子的成人。(d) 是：喉结核传染性很强。
:::
:::

::: exercise 护士的IGRA阳性 {level=2 check="round(100*0.01*0.8/(0.01*0.8 + 0.99*0.02))/100"}
一名在英国出生、无已知暴露的护士在职业筛查中常规检测IGRA。假设这一人群结核感染患病率为1%，IGRA灵敏度80%，特异度98%。阳性结果为真阳性的概率是多少？答案保留两位小数，并加以评论。
::: hint
按每筛查10,000人计算。
:::
::: solution
每10,000人中：100人被感染，其中80人检测阳性。9900名未感染者中，$9{,}900 \times 0.02 = 198$人假阳性。

$$
\text{PPV} = \frac{0.01 \times 0.8}{0.01 \times 0.8 + 0.99 \times 0.02} = \frac{0.008}{0.0278} \approx 0.29
$$

阳性结果中真阳性不到三分之一。筛查低风险人群会产生许多假阳性，导致不必要的胸片检查和数月可能有毒性的治疗。这就是为什么检测要针对有真实感染和进展风险的人，也是为什么低风险者的临界阳性结果常要复查。
:::
:::

::: exercise 肝酶升高 {level=2}
一名58岁女性在肺结核标准治疗三周时出现恶心、呕吐和尿色加深。ALT 410 U/L（正常上限40），胆红素46 µmol/L；基线检查正常。可能的原因是什么？应该怎么做？
::: solution
这是**药物性肝损伤**，最可能由吡嗪酰胺、异烟肼或利福平引起。ALT超过正常五倍、有症状且出现黄疸，都意味着必须**停用**有肝毒性的药物。要排除其他原因（病毒性肝炎、酒精、其他药物、胆道梗阻）。如果她病情很重或仍有传染性，在肝脏恢复期间给予无肝毒性的药物（例如在专科建议下用乙胺丁醇加一种氟喹诺酮类及其他药物）。肝功能恢复到接近正常后，在监测下**逐一重新加用**药物，通常先用利福平，再用异烟肼，吡嗪酰胺常被省略；随后延长疗程以作补偿。所有决定都要与结核病专科团队共同作出。
:::
:::

::: exercise 颈部肿块 {level=2}
一名27岁女性五年前从巴基斯坦移居英国，左颈部有一个无痛肿块，三个月来逐渐增大。除轻度盗汗外她感觉良好。淋巴结3 cm，质韧，轻度波动，表面皮肤呈紫红色。胸片正常。给出鉴别诊断，并说明如何确立诊断。
::: solution
**鉴别诊断**：**淋巴结结核**（考虑到她的来源地、缓慢无痛的病程以及波动伴皮肤改变，可能性最大）、淋巴瘤、转移癌（以她的年龄可能性较小）、非结核分枝杆菌感染（主要见于幼儿）、猫抓病、弓形虫病和结节病。

**诊断需要组织**：超声引导下粗针活检或细针穿刺（如果不能确诊则切除活检），标本**同时**送组织学检查（干酪样肉芽肿；排除淋巴瘤）**和**微生物学检查（抗酸涂片、NAAT和培养）。把全部标本放入福尔马林会使培养无法进行，失去做药敏试验的机会。应提供HIV检测。如果确诊为结核，她接受六个月的标准治疗；治疗期间淋巴结可能矛盾性增大，这并不意味着治疗失败。
:::
:::

::: exercise 并非机械性的背痛 {level=3}
一名52岁男性来自索马里，胸背痛五个月，夜间加重，伴体重下降。上周以来双腿无力，排尿困难。MRI示T8和T9椎体及其间椎间盘破坏，椎旁积液延伸入椎管。讨论鉴别诊断、检查和紧急处理。
::: hint
每种诊断倾向于累及椎骨的哪个部位？神经功能恶化要求怎样处理？
:::
::: solution
**鉴别诊断**：**脊柱结核（Pott病）**、**化脓性脊柱椎间盘炎**（如金黄色葡萄球菌，病程常更急，炎症标志物更高）、布鲁菌病（有食用未经巴氏消毒奶制品的饮食史），以及**转移性恶性肿瘤**或骨髓瘤。两个相邻椎体及其间椎间盘受累、巨大的椎旁脓肿和缓慢的病程支持感染，尤其是结核；肿瘤往往不累及椎间盘。

**检查**：血培养、炎症标志物、HIV检测、胸片，以及对积液进行**CT引导下活检或手术取样**，送组织学、抗酸涂片、NAAT和培养加药敏试验。

**紧急处理**：进行性无力和尿潴留提示**脊髓受压**，这是外科急症。他需要紧急的脊柱外科评估以行减压和固定；手术中取得的标本可以确立诊断。取样后立即开始标准抗结核治疗，疗程通常比肺结核更长。随后进行康复，并监测神经功能恢复情况。
:::
:::

::: exercise 检出利福平耐药 {level=3}
一名35岁女性六年前在另一个国家接受过结核治疗，三个月后自行停药，现因咳嗽和新出现的空洞就诊。Xpert MTB/RIF Ultra检出结核分枝杆菌，**检出利福平耐药**。解读结果并概述处理，包括公共卫生措施。
::: solution
**解读**：既往治疗不完整是**获得性耐药**的主要危险因素。分子检测发现的利福平耐药按**RR-TB**处理，多数情况下同时存在异烟肼耐药（MDR-TB）。标准一线治疗将相当于用异烟肼、吡嗪酰胺和乙胺丁醇进行单药治疗，必然失败。

**处理**：在负压病房采取空气传播预防措施进行隔离；紧急转诊至结核病专科服务和国家耐药结核病咨询服务；快速分子检测氟喹诺酮和异烟肼耐药；培养并做全面的表型药敏试验和全基因组测序。在等待结果期间，若已排除氟喹诺酮耐药，通常采用WHO推荐的全口服方案，如六个月的**BPaLM**。需要基线心电图（QT间期）、全血细胞计数、肝功能、视力检查和神经病变评估，并在治疗期间反复检查。HIV检测、依从性支持和直接督导治疗是标准做法。

**公共卫生**：报告病例，并进行接触者追踪，优先考虑家庭接触者和儿童。对接触者筛查活动性疾病；MDR-TB接触者感染的处理属于专科范畴，至少要密切随访两年。
:::
:::
