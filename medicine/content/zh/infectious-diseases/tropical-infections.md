“热带”感染并不局限于热带。每年有数以百万计的人往来于各大洲，许多生活在欧洲的人出生于或经常回访疟疾、登革热和伤寒常见的国家。同样的发热，在一直待在家里的人身上可能只是轻微的病毒性疾病，在两周前从西非回来的人身上却可能是危及生命的疟疾。对发热患者来说，最有用的一个问题往往是：**“你去过哪里？”**

全球负担是巨大的。WHO《2025年世界疟疾报告》（*World Malaria Report 2025*）估计，2024年全球有2.82亿疟疾病例和61万例死亡，约95%的死亡发生在非洲，其中大多数是五岁以下儿童。登革热已在热带和亚热带广泛蔓延，血吸虫病和土源性蠕虫等被忽视的感染影响着世界上最贫困的数亿人。

本章先讲归国旅行者发热的诊治思路，然后深入讨论疟疾，再讨论登革热和其他虫媒病毒、肠热症和其他细菌感染、新发和高后果传染病，以及蠕虫。英国的做法遵循英国疟疾治疗指南和英国卫生安全局的指南；全球做法遵循WHO。治疗以原则形式描述；方案和剂量来自现行指南和专科意见。

## 发热的归国旅行者

::: definition 归国旅行者发热 {#def-fever}
**归国旅行者发热**是指曾出国旅行（通常在过去一年内，尤其是去热带或亚热带地区）的人出现的发热。其评估依靠四个问题：

1. 确切地说去了**哪里**，包括农村地区、中转地和海拔？
2. **何时**抵达和离开，何时开始发热？把暴露与发病之间的间隔与每种候选感染的**潜伏期**进行比较。
3. **做了什么**：在淡水中游泳、被昆虫和动物叮咬、不安全的食物和饮水、性接触、医疗接触、探亲访友、照顾病人？
4. 采取了**什么防护**：疫苗、正确服用的疟疾化学预防药物、防蚊措施？

第一条规则是绝对的：**任何去过疟疾流行区的发热者都必须紧急检测疟疾**，无论其他诊断看起来多么可能。
:::

归国旅行者的大多数发热是由流感、肺炎和尿路感染等普通感染引起的，不要忘记它们。在与旅行特有相关的感染中，英国临床最常见的是**疟疾**（首先来自撒哈拉以南非洲）、**登革热**（南亚和东南亚、拉丁美洲、加勒比地区）、**肠热症**（南亚）和**立克次体感染**（非洲南部和亚洲）。

潜伏期可以缩小鉴别范围：

| 暴露后发病时间 | 典型感染 |
|---|---|
| 10天以内 | 登革热、基孔肯雅热、立克次体感染、流感、旅行者腹泻；病毒性出血热（最长21天） |
| 10–21天 | 恶性疟（至少7天）、肠热症、钩端螺旋体病、急性HIV感染、病毒性出血热 |
| 21天以上 | 疟疾（尤其是间日疟和卵形疟，可在数月后复发）、结核病、甲型、乙型和戊型肝炎、阿米巴肝脓肿、急性血吸虫病、内脏利什曼病 |

如果在离开某地21天以后才开始发热，登革热、立克次体感染和病毒性出血热实际上可以排除；疟疾则永远不能排除。

## 疟疾

::: definition 疟疾 {#def-malaria}
**疟疾**是**疟原虫属（*Plasmodium*）**原虫对红细胞的感染，通过雌性**按蚊（*Anopheles*）**叮咬传播，按蚊主要在黄昏至黎明之间叮咬。常见感染人类的有五种：

- **恶性疟原虫（*P. falciparum*）**：造成全球大部分死亡，是重症疟疾的病因；在撒哈拉以南非洲占主导。
- **间日疟原虫（*P. vivax*）**和**卵形疟原虫（*P. ovale*）**：形成休眠的肝内期（**休眠子**），可在数月或数年后引起复发。
- **三日疟原虫（*P. malariae*）**：低度、持久的感染；与肾病综合征有关。
- **诺氏疟原虫（*P. knowlesi*）**：东南亚的一种猴疟原虫，周期为24小时，可迅速发展为重症。

**生活史。** 蚊子注入的子孢子到达肝脏，在肝细胞中繁殖一至两周（无症状），然后把数千个裂殖子释放入血。每个裂殖子侵入一个红细胞，在其中繁殖，然后使红细胞破裂，释放更多的裂殖子：恶性疟、间日疟和卵形疟约每**48小时**一次，三日疟为72小时。红细胞同步破裂引起发热。部分疟原虫变为**配子体**，感染下一只蚊子。

**诊断。** 由有经验的镜检人员检查**厚血膜和薄血膜**仍是标准方法：厚血膜灵敏，薄血膜用于鉴定虫种并计算**原虫血症**（被感染红细胞的百分比）。检测疟原虫抗原的**快速诊断试验**与镜检同时使用。一次阴性不能排除疟疾：英国指南要求重复检测，直至**48–72小时内的三份标本**均为阴性。
:::

::: proof
**恶性疟原虫为何致命。** 三个特点使它有别于其他虫种：

1. **它能侵入任何年龄的红细胞**，因此原虫血症可以无限升高；间日疟和卵形疟原虫偏好年轻的网织红细胞，这使它们的原虫血症保持在较低水平。
2. **隔离（扣押）。** 被感染的红细胞在表面的突起上表达一种疟原虫蛋白PfEMP1。它与小血管内皮上的受体结合（细胞黏附），也与未感染的红细胞结合（玫瑰花环形成）。因此成熟的疟原虫从循环血液中消失，塞满脑、肾、肠、肺和胎盘的微循环，阻碍血流并激发炎症。外周血涂片可能低估总的原虫负荷。
3. **代谢后果。** 疟原虫消耗葡萄糖并产生乳酸；微循环阻塞加重**乳酸酸中毒**。**低血糖**源于疟原虫的消耗、肝脏糖异生受损，以及过去奎宁（quinine）引起的胰岛素释放。**贫血**源于被感染和未被感染红细胞的破坏以及骨髓抑制。

重症疟疾的临床综合征（昏迷、酸中毒、肾损伤、呼吸窘迫、严重贫血）都由这些机制而来。在无免疫力的旅行者身上，它们可在数小时内出现，这就是恶性疟被当作医学急症处理的原因。
:::

::: definition 重症恶性疟 {#def-severe}
**重症疟疾**是指恶性疟原虫（或诺氏疟原虫，偶尔为间日疟原虫）感染伴有以下一项或多项特征，根据WHO成人标准改编：

- **意识障碍**（格拉斯哥昏迷评分低于11）或**极度衰弱**；**反复抽搐**（24小时内超过两次）。
- **酸中毒**（碱缺失大于8 mmol/L、碳酸氢盐低于15 mmol/L或乳酸5 mmol/L及以上）。
- **低血糖**（血糖低于2.2 mmol/L）。
- **严重贫血**（成人血红蛋白低于70 g/L）。
- **急性肾损伤**（肌酐高于265 µmol/L）。
- **黄疸**（胆红素高于50 µmol/L）伴高原虫血症。
- **肺水肿**或急性呼吸窘迫；**休克**（收缩压低于80 mmHg伴灌注不良）；**明显出血**。
- **高原虫血症**：WHO标准为高于10%。英国指南建议，对无免疫力的旅行者，即使没有其他特征，只要被寄生红细胞**超过2%**就静脉治疗。
:::

**治疗。** **重症疟疾**用**静脉青蒿琥酯（artesunate）**治疗，它能在年轻疟原虫被隔离之前将其杀灭。两项大型试验确立了它的地位：SEAQUAMAT（亚洲成人，2005年）发现死亡比奎宁少约三分之一，AQUAMAT（非洲儿童，2010年）少约五分之一。患者一旦能口服，就用一个完整疗程的口服**青蒿素类复方疗法（ACT）**完成治疗。患者需要高依赖病房或重症监护、频繁监测血糖、谨慎补液（液体过负荷会引起肺水肿），并在青蒿琥酯治疗后数周内监测**迟发性溶血**。**非重症恶性疟**用蒿甲醚-本芴醇（artemether–lumefantrine）等口服ACT治疗，最初几天常在医院进行，因为无免疫力的患者可能恶化。**间日疟和卵形疟**用ACT或（在仍有效的地区）氯喹（chloroquine）治疗，随后用**伯氨喹（primaquine）**或**他非诺喹（tafenoquine）**杀灭休眠子；用药前要检测**G6PD缺乏症**，因为这些药物会使G6PD缺乏者发生溶血。

**耐药。** 由疟原虫*kelch13*基因突变引起的对青蒿素类药物的部分耐药，最先出现在大湄公河次区域，现已在东非部分地区得到证实，威胁着作为疟疾控制基石的药物。

**预防。** 旅行者要学习**ABCD**：了解风险（**A**wareness）、防止叮咬（**B**ite avoidance：含避蚊胺（DEET）的驱避剂、遮盖皮肤、杀虫剂处理的蚊帐）、适合目的地并按要求服用的化学预防（**C**hemoprophylaxis），以及任何发热都及时诊断（**D**iagnosis）。在流行区长大、现居国外的人会在几年内失去部分免疫力，而**探亲访友**者占英国输入性病例的大多数。在流行国家，WHO已推荐两种儿童疫苗——**RTS,S/AS01**（2021年）和**R21/Matrix-M**（2023年）——与杀虫剂处理的蚊帐、室内喷洒和季节性化学预防一起使用。

::: example 探亲之后的发热 {#ex-malaria-severe}
一名38岁男性已在伦敦生活15年，10天前从尼日利亚探亲一个月后回国。他未服用疟疾预防药物。发热、头痛四天，现在意识混乱。体温39.6 °C，脉率每分钟118次，血压104/60 mmHg，GCS 13，轻度黄疸。薄血膜：恶性疟原虫，在4500个红细胞中计数到270个被寄生细胞。血糖3.1 mmol/L，肌酐290 µmol/L，胆红素64 µmol/L，血小板38 × 10⁹/L，乳酸4.2 mmol/L。
::: solution
**原虫血症**：$270/4500 = 0.06 = 6\%$。

**严重程度**：按多项标准，他患有**重症恶性疟**：意识障碍、急性肾损伤（肌酐高于265 µmol/L）、黄疸伴高原虫血症，以及原虫血症高于英国2%的阈值。血小板减少在疟疾中几乎普遍存在，本身不是严重程度的标准；他的血糖处于正常低限，需要密切观察。

**处理**：
1. 立即**静脉给予青蒿琥酯**；不要等待重症监护床位。如果不能立即获得青蒿琥酯，先开始静脉奎宁，随后再转换。
2. 收入重症监护病房或高依赖病房；频繁监测血糖并治疗低血糖。
3. **谨慎的液体复苏**：重症疟疾引起肺毛细血管渗漏，过量补液会诱发肺水肿。肾损伤加重时行肾脏替代治疗。
4. 留取血培养并考虑使用广谱抗生素，因为重症疟疾常合并细菌感染。
5. 每日检测原虫血症直至下降，然后完成一个完整的口服ACT疗程；在青蒿琥酯治疗后数周内检查血红蛋白以发现迟发性溶血。
6. 与热带医学专科中心讨论。

他是一个典型的输入性病例：在流行国家长大，已失去免疫力，探亲时没有服用预防药物。
:::
:::

::: warning
**一次检测阴性和服用过预防药物都不能排除疟疾。** 感染早期或疟原虫被隔离时，第一次血涂片可能为阴性；要重复检测，直到48–72小时内三份标本均为阴性。预防药物能降低但不能消除风险，尤其是漏服或药物不适合该地区时。疟疾还可以表现为腹泻、黄疸或咳嗽，因此归国旅行者被贴上“胃肠炎”或“胸部感染”的标签，绝不能因此停止疟疾检测。
:::

## 登革热和其他虫媒病毒

**虫媒病毒**是由节肢动物传播的病毒。**登革病毒**（四个血清型）由**伊蚊（*Aedes*）**传播，伊蚊白天叮咬，在城镇的小容器积水中繁殖。经过3–14天的潜伏期，大多数感染为轻症或无症状。有症状的登革热分三期：

1. **发热期**（2–7天）：突发高热、剧烈头痛、眼眶后痛、肌肉和关节痛、恶心，常有潮红或压之褪色的皮疹；白细胞减少，血小板下降。
2. **危重期**，在热退前后（通常为第3–7天）：少数患者毛细血管**血浆渗漏**，导致血细胞比容上升、胸腔积液和腹水，并可发展为休克；随后可出现出血和器官受累。
3. **恢复期**：渗出的液体被重吸收；可出现“红海中的白色小岛”样的恢复期皮疹；此时补液过多会导致液体过负荷。

WHO把登革热分为**无预警征象的登革热**、**有预警征象的登革热**（腹痛或压痛、持续呕吐、临床可见的液体积聚、黏膜出血、嗜睡或烦躁、肝脏增大，以及血细胞比容上升伴血小板迅速下降）和**重症登革热**（严重血浆渗漏伴休克或呼吸窘迫、严重出血或严重器官受累）。感染不同血清型的第二次感染发生重症的风险更高，部分原因是**抗体依赖性增强作用**。

诊断方法是在最初五天内检测**NS1抗原**或**PCR**，之后检测IgM血清学。没有抗病毒治疗；以支持治疗为主，在危重期仔细监测血细胞比容和液体平衡，并因出血风险而避免使用**阿司匹林和NSAID**。一种疫苗（TAK-003）已在英国获得许可；英国的建议把它的使用限于既往感染过登革热的人。

其他虫媒病毒包括**基孔肯雅病毒**（发热和使人丧失活动能力、有时持久的关节痛）、**寨卡病毒**（通常为轻症，但妊娠期感染可导致先天性小头畸形）和**黄热病毒**（肝炎、出血、死亡率高，可通过疫苗预防）。

::: example 曼谷归来后的第五天 {#ex-dengue}
一名25岁女性在泰国旅行三周、乘机回国前两天出现发热、剧烈头痛和眼眶后酸痛。病程第5天她已退热，但出现腹痛，呕吐四次。脉率每分钟108次，血压102/80 mmHg。24小时内血小板从110降至40 × 10⁹/L，血细胞比容从0.38升至0.46。疟疾检测阴性；NS1抗原阳性。
::: solution
**诊断**：**有预警征象的登革热**，正在进入**危重期**。退热之时正是危险的高峰，而不是危险的结束。预警征象包括腹痛、持续呕吐，以及血细胞比容上升伴血小板迅速下降，这些共同提示**血浆渗漏**。血细胞比容上升了$(0.46-0.38)/0.38 \approx 21\%$，这种程度的血液浓缩提示明显的渗漏。脉压变窄（102/80）是即将休克的早期征象。

**处理**：收住院；频繁观察脉率、血压、灌注和尿量；连续监测血细胞比容；**谨慎静脉输注晶体液**，根据临床状况和血细胞比容调整，而不是固定地大量输注，因为渗漏在24–48小时后停止，此后液体需求迅速下降。不用阿司匹林或NSAID；用对乙酰氨基酚退热止痛。不能仅因血小板计数低就输注血小板；它只用于明显出血。应告知她，日后感染不同血清型时发生重症的风险更高。
:::
:::

## 肠热症和其他细菌感染

**肠热症**（伤寒和副伤寒）由**肠道沙门菌伤寒血清型和副伤寒血清型（*Salmonella enterica* serovars Typhi and Paratyphi）**引起，经被人类粪便污染的食物和水传播；英国的大多数病例是在南亚感染的。经过1–3周，发热在数天内隐匿地升高，伴头痛、不适、腹部不适以及便秘或腹泻。体征包括相对缓脉、躯干上淡粉色的“玫瑰疹”和脾大。未经治疗时，第三周的并发症包括**肠出血和肠穿孔**。诊断依靠**血培养**（骨髓培养更灵敏）；旧的肥达（Widal）血清学试验不可靠。抗生素的选择取决于感染地：氟喹诺酮类耐药在南亚很普遍，而巴基斯坦自2016年起发现的一种**广泛耐药**菌株对第三代头孢菌素也耐药，因此使用阿奇霉素（azithromycin）或碳青霉烯类。少数人成为胆囊内的慢性带菌者。伤寒结合疫苗现已在流行国家使用。

**立克次体感染**包括**非洲蜱咬热**（发热、头痛和一个或多个蜱咬部位的黑色**焦痂**，常见于在非洲南部参加野生动物游猎或农村旅行之后）和亚洲的**恙虫病**。它们对**多西环素（doxycycline）**反应迅速，一经临床怀疑即开始使用。**钩端螺旋体病**通过淡水接触鼠尿感染（漂流、洪水、农耕），引起发热、肌痛和结膜充血，重症时出现黄疸、肾损伤和肺出血（Weil病）。

## 新发和高后果传染病

::: definition 新发传染病与高后果传染病 {#def-emerging}
**新发感染**是指在人群中新出现的感染，或发病率、地理分布范围迅速扩大的感染。大多数人类新发感染是**人兽共患病**，在人、动物和环境发生变化时从动物传给人类：森林砍伐、养殖业、野生动物贸易、旅行和气候变化。“同一健康”（One Health）方法把人类、动物和环境监测联系起来。

在英国，**高后果传染病（HCID）**是指病死率高、无治疗或治疗有限、能在社区和医疗机构中传播、需要专门应对的急性感染。例子有经接触传播的**病毒性出血热**（埃博拉、马尔堡、拉沙、克里米亚-刚果出血热）以及某些经空气传播的感染（中东呼吸综合征冠状病毒、某些禽流感毒株）。离开有病毒性出血热发生的地区**21天**内发热的归国旅行者，或接触过病例的人，在送常规检查之前要接受结构化的**风险评估**。
:::

高风险患者要隔离，并仍要紧急检测疟疾（必要时在高等级防护实验室进行），因为疟疾仍然是可能性最大的诊断。确诊病例转至专门的HCID病房。2014–2016年西非埃博拉疫情表明，决定疫情规模的主要因素是当地卫生系统的强弱、感染控制和社区信任，此后的疫情中采用了有效埃博拉疫苗的环形接种。近年来，**猴痘（mpox）**在国际上传播，WHO于2022年和2024年两次宣布其为国际关注的突发公共卫生事件。

## 蠕虫和其他寄生虫

::: definition 蠕虫 {#def-helminths}
**蠕虫**是寄生性的虫体：**线虫**、**吸虫**和**绦虫**。除一个重要例外（类圆线虫，*Strongyloides*），成虫**不在人体内增殖**：虫负荷取决于获得了多少感染期幼虫，因此重症反映的是反复暴露。幼虫在组织中移行引起**嗜酸性粒细胞增多**，这是归国旅行者的有用线索。

- **土源性蠕虫**（蛔虫（*Ascaris*）、钩虫、鞭虫（*Trichuris*））感染约15亿人，主要是贫困社区的儿童，引起贫血、营养不良和发育障碍。控制依靠定期用阿苯达唑（albendazole）或甲苯达唑（mebendazole）进行群体治疗、改善卫生设施和穿鞋。
- **血吸虫病**是在游泳或洗涤时，由淡水螺释放的幼虫（尾蚴）穿透皮肤而感染的，例如在马拉维湖。埃及血吸虫（*S. haematobium*）引起泌尿和生殖系统疾病（血尿、膀胱纤维化和膀胱癌、女性生殖器血吸虫病）；曼氏血吸虫（*S. mansoni*）引起肠道和肝脏疾病，伴门静脉周围纤维化和门静脉高压。暴露后2–8周的急性感染可引起**片山综合征**（发热、荨麻疹、咳嗽、嗜酸性粒细胞增多）。治疗用吡喹酮（praziquantel），它能杀灭成虫但不能杀灭未成熟虫体，因此要据此安排或重复治疗。
- **粪类圆线虫（*Strongyloides stercoralis*）**能在宿主体内完成生活史（**自体感染**），因此离开流行区几十年后感染仍持续存在。
- **囊尾蚴病**是吞食了人体带虫者排出的猪带绦虫（*Taenia solium*）虫卵所致；幼虫囊肿寄居在肌肉和脑（**脑囊尾蚴病**），是全球获得性癫痫的主要原因之一。
:::

::: example 激素之后的脓毒症 {#ex-strongyloides}
一名68岁男性在牙买加长大，45年前移居英国，因慢阻肺急性加重接受大剂量泼尼松龙治疗。十天后他出现腹痛、腹泻、气促加重伴双肺浸润，随后发热、意识混乱和颈强直。血培养生长大肠埃希菌；嗜酸性粒细胞计数正常。经询问，他回忆起多年来臀部和大腿上有一种瘙痒、匍行的皮疹。
::: solution
**诊断**：**类圆线虫过度感染综合征**，伴革兰氏阴性菌脑膜炎和菌血症。数十年前获得的慢性低度类圆线虫感染一直被他的免疫力所控制。大剂量糖皮质激素使自体感染爆发：大量幼虫穿透肠壁，经肺和其他器官移行，把肠道细菌带入血液和脑膜。他描述的移行性皮疹是**幼虫流（larva currens）**，是慢性类圆线虫病的特征。过度感染时嗜酸性粒细胞增多常常**缺如**，部分原因是激素的作用。

**处理**：尽可能减少免疫抑制；**伊维菌素（ivermectin）**（疗程比非复杂性感染更长，需专科意见）；针对革兰氏阴性菌脑膜炎的抗生素；在粪便、痰和其他标本中查找幼虫；重症监护支持。死亡率很高。

**预防**才是真正的教训：来自流行区的人，即使移居数十年后，在使用大剂量激素、器官移植或其他免疫抑制之前，也应进行筛查（血清学）或经验性治疗（[[infectious-diseases/immunocompromised-host]]）。
:::
:::

::: example 首次癫痫发作 {#ex-neurocysticercosis}
一名32岁女性四年前从玻利维亚移居英国，出现首次全面性癫痫发作。她偶有头痛。头颅MRI示右额叶一个1.5 cm的单发囊性病灶，内有一个小的偏心结节，周围有水肿。
::: solution
**诊断**：含偏心**头节**（绦虫的头部）的囊肿是**脑囊尾蚴病**的特征，由猪带绦虫的幼虫期引起，在拉丁美洲、亚洲和非洲部分地区常见。当死亡中的囊肿激发炎症和水肿时，便出现癫痫发作。血清学可支持诊断。单发环形病灶的鉴别诊断包括结核瘤、脓肿、弓形虫病和肿瘤。

**处理**：抗癫痫药物；对存活的囊肿，用**阿苯达唑**进行抗寄生虫治疗（多发囊肿时加用吡喹酮），同时给予**糖皮质激素**以限制囊肿死亡时的炎症反应；并随访影像学。由大量囊肿引起颅内压升高时，在其得到控制之前不用抗寄生虫药。由于囊尾蚴病是从**人体绦虫带虫者**排出的虫卵感染的，可对家庭成员筛查肠道猪带绦虫感染。
:::
:::

::: history
1880年，法国军医阿方斯·拉韦朗（Alphonse Laveran）在阿尔及利亚看到疟疾患者血液中有活动的寄生虫。帕特里克·曼森（Patrick Manson）此前已于1877–1878年证明蚊子传播丝虫。1897年，罗纳德·罗斯（Ronald Ross）在印度工作时，在叮咬过感染者的按蚊肠道中发现了疟原虫，并于1898年描述了鸟类疟疾的完整传播周期；同年，乔瓦尼·巴蒂斯塔·格拉西（Giovanni Battista Grassi）等证明按蚊传播人类疟疾。罗斯（1902年）和拉韦朗（1907年）获得诺贝尔奖。20世纪70年代，屠呦呦领导的中国研究项目受一部四世纪文献的启发，从黄花蒿（*Artemisia annua*）中提取出青蒿素；她于2015年获得诺贝尔奖，青蒿素衍生物如今是全世界疟疾治疗的基石。
:::

::: quiz
一名旅行者在肯尼亚度假两周后回国，30天后出现发热。根据时间，哪种诊断实际上可以**排除**？
- [ ] 恶性疟
- [x] 登革热
- [ ] 阿米巴肝脓肿
- [ ] 急性血吸虫病
::: solution
登革热的潜伏期为3–14天，因此在最后一次可能暴露后30天才开始的发热不是登革热。恶性疟通常在几个月内发病，但也可能更晚；阿米巴肝脓肿和急性血吸虫病通常在暴露后数周至数月出现。
:::
:::

::: summary
- 对任何发热的归国旅行者，都要问去了哪里、何时、做了什么、采取了什么防护；如果去过流行区，要紧急检测疟疾。
- 潜伏期可以缩小鉴别范围：离开21天以后才开始发热，可排除登革热、立克次体感染和病毒性出血热，但永远不能排除疟疾。
- 恶性疟原虫之所以致命，是因为它侵入各年龄的红细胞并在小血管中隔离，引起昏迷、酸中毒、低血糖、肾损伤和贫血。
- 重症疟疾（WHO标准；在英国还包括原虫血症高于2%）用静脉青蒿琥酯治疗，随后口服ACT；间日疟和卵形疟需在G6PD检测后用伯氨喹或他非诺喹。
- 登革热在热退前后变得危险，此时血浆渗漏可导致休克；预警征象和血细胞比容上升指导谨慎的液体治疗，并避免使用NSAID。
- 肠热症需要血培养，并根据当地耐药情况选择抗生素；立克次体感染对多西环素有效。
- 蠕虫引起嗜酸性粒细胞增多；类圆线虫可持续数十年，在使用激素后可引起致命的过度感染，因此有风险的人在免疫抑制前要筛查或治疗。
:::

## 习题

::: exercise 计数疟原虫 {level=1 check="3"}
在薄血膜上，1500个红细胞中有45个含恶性疟原虫。原虫血症的百分比是多少？
::: solution
$45/1500 = 0.03 = 3\%$。这高于英国2%的阈值，对无免疫力的旅行者，即使没有其他严重特征，也建议静脉使用青蒿琥酯。
:::
:::

::: exercise 推算叮咬时间 {level=1}
一名女性在印度果阿度过十天，回国后18天出现发热。登革热、恶性疟、间日疟和肠热症中，哪些仍有可能？请解释。
::: solution
暴露发生在发热前18至28天之间。**登革热**（3–14天）可能性很小，尽管最后一天获得的感染已接近其上限。**间日疟**在印度常见，有可能，并可在数月后发病。**恶性疟**在印度较少见但存在，有可能。**肠热症**（通常1–3周）完全可能来自南亚。疟疾检测和血培养都需要做。
:::
:::

::: exercise 血液浓缩 {level=1 check="round(100*(0.46-0.38)/0.38)"}
登革热患者的血细胞比容从0.38升至0.46。上升了百分之多少？答案取最接近的整数。
::: solution
$(0.46-0.38)/0.38 = 0.08/0.38 = 0.2105$，上升约**21%**。这种幅度的上升，加上血小板下降和临床预警征象，提示明显的血浆渗漏。
:::
:::

::: exercise 一年后的复发 {level=2}
一名30岁男性去巴布亚新几内亚旅行后患间日疟，仅用ACT治疗。十一个月后，在没有再次旅行的情况下，他每48小时发热一次，血涂片再次发现间日疟原虫。解释原因，以及当初应该怎么做。
::: solution
间日疟原虫在肝脏中形成休眠的**休眠子**，ACT或氯喹等血液期药物不能杀灭它们。它们可在数周至数月后重新激活，在没有新暴露的情况下引起**复发**。间日疟或卵形疟的治疗应包括对休眠子有效的药物——**伯氨喹**或**他非诺喹**——用药前要检测**G6PD缺乏症**，因为这些药物可使G6PD缺乏者发生严重溶血。妊娠也是禁忌；这种情况下推迟对休眠子的治疗，期间用氯喹进行抑制性治疗。他现在需要血液期治疗和根治性治疗。
:::
:::

::: exercise 拉合尔归来后的发热 {level=2}
一名19岁学生在巴基斯坦拉合尔待了三周后回国，发热逐渐升高一周，伴头痛、腹部不适和便秘。体温39.5 °C时脉率每分钟84次；脾可触及。疟疾检测阴性。最可能的诊断是什么？如何确诊？什么因素影响抗生素的选择？
::: solution
**最可能的诊断**：**肠热症**（伤寒），依据是南亚旅行史、隐匿升高的发热伴头痛和腹部症状、**相对缓脉**（39.5 °C时脉率84次）和脾大。**确诊**：血培养（多套；如果血培养阴性而怀疑程度高，骨髓培养更灵敏）；粪便培养；不应依赖肥达试验。**抗生素选择**：巴基斯坦正流行**广泛耐药伤寒**，对氟喹诺酮类和第三代头孢菌素耐药，因此对来自巴基斯坦、病情严重的患者，经验性治疗应包括**碳青霉烯类**，较轻者用阿奇霉素，药敏结果出来后再调整。肠热症是法定报告疾病，公共卫生部门会随访接触者和食品从业人员。
:::
:::

::: exercise 马拉维湖之后的嗜酸性粒细胞增多 {level=2}
一组八名学生在间隔年旅行中在马拉维湖游泳。六周后，其中三人出现发热、荨麻疹、干咳，嗜酸性粒细胞计数3.5 × 10⁹/L。最可能的诊断是什么？如何确诊？整个小组应如何处理？
::: solution
**最可能的诊断**：**急性血吸虫病（片山综合征）**，是在血吸虫病流行区淡水暴露后2–8周，对移行的童虫和早期产卵的超敏反应。**确诊**：血清学（可能需要长达三个月才转阳），以及之后尿液和粪便镜检查虫卵。**处理**：糖皮质激素可缓解严重的片山症状；给予**吡喹酮**，但它对未成熟虫体无效，因此要在虫体成熟后给予或重复给予（通常在暴露后约8–12周）。**整个小组**都应在暴露后至少6–12周进行血清学筛查，阳性者即使没有症状也要治疗，因为未经治疗的感染日后可引起膀胱、生殖器、肝脏或脊髓疾病。
:::
:::

::: exercise 发热的医务人员 {level=3}
一名34岁护士在埃博拉病毒病疫情期间于一个治疗中心工作，七天前回到英国。她现在体温38.4 °C，肌痛、腹泻。讨论紧急措施、鉴别诊断以及应如何组织检测。
::: hint
想一想风险评估、感染控制，以及去过撒哈拉以南非洲后发热最常见的严重原因。
:::
::: solution
**风险评估**：离开疫区21天内发热，且在职业中直接接触过患者，在英国风险评估流程中属于病毒性出血热**高度可能**。**紧急措施**：将她隔离在单人间（最好有前室），限制工作人员进入，使用规定的个人防护装备，并紧急通知当地感染专科医生、卫生防护团队和国家HCID网络。理想情况下，从事此类工作归来的人已处于主动监测之下，知道在就诊前先打电话，以便能被安全地接诊和评估。

**鉴别诊断**：埃博拉病毒病；**疟疾**（仍是撒哈拉以南非洲归国旅行者发热最常见的危险原因，尤其是在预防不完善时）；伤寒；流感、COVID-19和其他常见病毒感染；胃肠炎；细菌性脓毒症。

**检测**：在指定的高等级防护实验室紧急进行埃博拉PCR；**疟疾检测绝不能延误**，在适当的防护条件下进行；其他常规检查要有所限制，并按方案处理。如果确诊埃博拉，她将被转至高等级隔离病房；如果阴性，则按其他诊断继续治疗，若第一份标本采集于病程很早期则需复查。
:::

::: exercise 从百分比到疟原虫数 {level=3 check="0.04*4.5e6"}
一名恶性疟患者的原虫血症为4%，红细胞计数为4.5 × 10¹²/L。每微升血液中有多少个被寄生的红细胞？与WHO和英国的严重程度阈值相比如何？为什么外周计数可能低估总的原虫负荷？
::: hint
1 L = 10⁶ µL。
:::
::: solution
每微升红细胞数$= 4.5 \times 10^{12}/10^{6} = 4.5 \times 10^{6}$。被寄生细胞$= 0.04 \times 4.5 \times 10^{6} = 1.8 \times 10^{5}$，即**每微升180,000个**。

4%的原虫血症低于WHO 10%的高原虫血症阈值，但高于英国对无免疫力旅行者静脉使用青蒿琥酯的2%阈值。外周血涂片主要显示年轻的环状体：成熟的恶性疟原虫被**隔离**在微血管中，因此总的原虫生物量可能比计数所显示的大得多，这也是严重程度要由患者的临床状况而不是单凭计数来确定的原因之一。
