性健康医学就是把病史问好的普通内科：**大多数性传播感染的综合征是少数几种微生物以可重复的模式出现、检测便宜而准确、治疗很短、而困难的部分是谈话——保密、性伴通知、同意、权力、胁迫与污名决定了药理最终是否发生。**一个能够不怯懦地谈论性、并在查体时不使人羞耻的临床医师、已经走完了一半的教学大纲。

本章涵盖接诊与检测的原则、溃疡性与分泌物综合征、病毒性性传播感染、作为性传播感染的HIV、及公共卫生的控制。

## 病毒性性传播感染与控制

::: definition 作为性传播感染的人乳头瘤病毒、肝炎与HIV {#def-viral}
**人乳头瘤病毒（总体上最常见的性传播感染、多数清除、及那条持续感染到疾病的连续谱——肛门生殖器的疣、带角化型对内生型对扁平型的形态、及高危型与宫颈上皮内瘤变及阴道及外阴及阴茎及肛门及口咽癌、及筛查对疫苗的策略分野、及疣的治疗菜单：患者自用的足叶草毒素或咪喹莫特、对比门诊的冷冻或酸或手术或激光、带复发与“无法清除潜在感染”的咨询、及男性接种与补种的公平胜利、及披露与关系的谈话：对人乳头瘤病毒而言它意味着“这个病毒很常见、这里是监测的含义”——[[obstetrics-gynaecology/gynaecological-cancer]]、[[public-health/vaccination-programmes]]、[[musculoskeletal/skin-cancer]]、[[public-health/screening]]）；作为性传播感染的病毒性肝炎、及在男性同性性行为者与旅行者暴发中的甲肝与疫苗的回应、及丙肝：男性同性性行为者中持续病毒血症与再感染之问、及直接抗病毒药物的治愈、及检测即治疗的公平缺口、及“接种、检测、治疗”这三联预防——[[gastrointestinal/liver-disease]]、[[microbiology/viruses]]、[[public-health/vaccination-programmes]]；作为性传播感染的HIV（检测的正常化与“测不到等于传不了”、及暴露前预防与暴露后预防及指示病例检测、及长效治疗的地平线——在[[infectious-diseases/hiv]]中详述）；猴痘（分支与网络的流行病学、及病灶的诊断、及接触者与风险网络的接种、及很快被应用的、来自HIV的污名管理教训——[[infectious-diseases/tropical-infections]]、[[public-health/communicable-disease-control]]）；及公共卫生的架构（HIV与梅毒的报告系统、及淋病的耐药监测、及社区的检测、及数字的建议应用与在线的检测结果、及在线治疗的伦理：在便利之上保住安全网的质量——[[public-health/health-systems-economics]]、[[public-health/screening]]、[[medical-ethics-law/professionalism-regulation]]）。**

::: example 不一致的乙肝结果 {#ex-hep-b}
一名健康28岁孕妇建档的血检显示表面抗原阴性、表面抗体阳性、核心抗体阴性；她对“自己得了肝炎”感到焦虑。
::: solution
**血清学的素养、不是肝病学（[[#def-viral]]、[[microbiology/viruses]]、[[obstetrics-gynaecology/pregnancy-antenatal]]）：这个模式——有表面抗体、而无核心抗体、也无抗原——是疫苗诱导的免疫、正是我们希望看到的样子、意味着既非现在也过去感染；与之对照、记录应当标记的模式：抗原阳性的传染性、带产前抗病毒与婴儿预防的决定、及孤立的核心抗体阳性、带隐匿与再激活之问、及伴随表面抗体血清转换的已 resolutions——[[clinical-skills/laboratory-tests]]、[[gastrointestinal/liver-disease]]、移植相关的几行见[[infectious-diseases/immunocompromised-host]]；咨询——她的结果对妊娠意味着什么：什么也不、对她的孩子：什么也不、对她的性伴：无需行动、及她仍应问的接种问题：风疹不免疫时的麻腮风、及水痘、及在妊娠期定时接种的流感与百日咳——[[public-health/vaccination-programmes]]、[[obstetrics-gynaecology/pregnancy-complications]]；记录——把判读而不是只把数字写进病历、好让下一位临床医师不重播这段焦虑、并写明“不需要重复抽血”——[[clinical-skills/records-handover]]；及产房与分娩计划的接口——除了标准预防之外无需额外的感染控制措施、及“哺乳没问题”的安抚、助产士需要像患者一样清楚地在纸上看到这句话——[[obstetrics-gynaecology/labour-birth]]、[[obstetrics-gynaecology/postnatal-period]]。**

::: example 反复回来的分泌物 {#ex-recurrent}
一名22岁患者在一年内有三次的“衣原体”、每次都被治疗、每一次都是新的性伴；她现在有深部盆腔疼痛与发热；她透露她前一任伴侣“不接受不这个答案”。
::: solution
**再感染、而不是治疗失败、加上一次性传播感染接诊中的保护性披露（[[#def-bacterial]]、[[#def-consultation]]）：临床的评估——按盆腔炎治疗、用足够的方案、住院的标准：重症、输卵管卵巢脓肿、妊娠、无反应、及外科的排除、及妊娠试验、及HIV与梅毒及淋病及衣原体的复测、及为脓肿与卵巢扭转问题的影像——[[obstetrics-gynaecology/menstrual-pelvic-disorders]]、[[microbiology/laboratory-diagnosis]]、[[clinical-skills/medical-imaging]]；不带责备地解释再感染的机制——每一个未治疗的性伴都是一张微生物的返程票、及如果妊娠风险是图景的一部分就谈长效避孕、及在证据与政策已落地的相关人群中讨论多西环素的暴露后预防——[[obstetrics-gynaecology/contraception-fertility]]、[[microbiology/antimicrobials]]；那次披露——“不接受不”是一个性胁迫的信号、需要在没有伴侣在场时私下询问、及基于性别的暴力与家庭暴力的路径、及动态的风险评估、及16岁以下与易受伤害成人的保护责任框架、及用患者自己的话记录这段谈话——[[paediatrics/safeguarding]]、[[medical-ethics-law/confidentiality]]、[[clinical-skills/communication]]；及纵向的设计——每次接触时常规提供避孕与接种及筛查、及护士主导的重复随访系统、开放可及而不是预约的门槛、及一份说明“为什么需要或不需要治愈检验”的记录——[[public-health/screening]]、[[public-health/prevention-promotion]]、[[clinical-skills/records-handover]]。**

::: example 调酒师肿胀的手腕 {#ex-dgi}

::: example 建档本一切正常的死胎 {#ex-congenital}

## 未完成的议程

三条诚实的脚注为本章收尾。第一、按综合征的处理在世界大部分地区仍然主宰：在核酸检测与培养都不可得的地方、世界卫生组织的彩色卡片算法依据体征做推定治疗、它们在同一口气里既救命也造成过度治疗——正确的回应是投资可负担的现场检测正在落地的是支原体与淋病的检测、而不是对这个选择进行道德说教。第二、性传播感染的污名是一个临床的决定因素：人们会拖延、性伴会漏追、而感觉像审讯的门诊比感觉像药店的门诊产出更糟的公共卫生；每一项缩短“我觉得我得了什么”到“我已经治好了”之间距离的质量改进、都是一个值得被说出的干预。第三、淋病奈瑟菌的抗菌药物耐药是为整个感染性疾病歌唱的那只金丝雀——一个依次击败了尝试过的每一类药物的微生物、而其背景是无症状的咽部携带充当着全球混合的容器；作为最后防线的头孢菌素终将加入那份清单、而那个日期与一支淋病疫苗之间的竞赛、是本章未来最重要的单场较量。

## 保密、青少年与记录

两个反复出现的两难值得排练、因为每位临床医师每周都会遇到。青少年的接诊由能力而非生日决定：那个理解决定、无法被说服告知家长、否则就将得不到照护或去别处得不到建议的16岁以下者、可以依据弗莱瑟的原则在保密下治疗——把推理记录在案、提议一次“是否告知家长”的谈话、对性剥削保持保护性的透镜、并记住保密有其命名的限度严重伤害的风险、保护的责任、它们必须在开始时说明、而不是在被打破时才被发现（[[medical-ethics-law/consent-capacity]]、[[medical-ethics-law/confidentiality]]、[[paediatrics/safeguarding]]）。成人披露的两难——一名拒绝告知其新诊断感染之伴侣的患者——有一个递进的答案：探索障碍、并提议通过健康顾问或匿名短信服务通知、当存在持续的高风险暴露时通过上级与公共卫生的建议升级、并把强制披露视为一个例外的、有记录的、相称的、与上级及法律及公共卫生共同作出的决定、绝不是在一个即将结束的门诊里独自行动（[[public-health/communicable-disease-control]]、[[medical-ethics-law/ethical-principles]]、[[clinical-skills/records-handover]]）。

有一个预防的细节属于每一次产后与每一次计划生育的就诊、而不只属于性健康门诊：产前梅毒与HIV筛查、配上可靠的结果流转、以及在流行率或风险支持时于妊娠晚期复筛、已在做得好的系统中把先天梅毒与垂直传播的HIV接近消除、而每一例漏过的都能追溯到一个坏掉的工作流程、从不追溯到生物学。

记录本身是一件性传播感染的器械。暴露部位的记录让下一位临床医师采样正确；窗口期的日期让下一个阴性结果可被解释；性伴数目与通知状态让审计成为可能；而一个接种状态的常规标记把每一次未来的就诊变成一次补种的机会。相反、含糊的记录——“分泌物、已治疗”——没有部位、日期、结果或性伴状态、保证下一位临床医师要么重做整个搜寻、要么更糟地从错误的性别去猜。好的性传播感染记录读起来像一个里面有人的公共卫生数据集、因为它们正是那样——一个由其他临床医师、顾问与审计者依赖的数据集、在患者无法自己讲述这段病史的时候。

::: history

::: summary
- 性史是一件临床的器械：五个P、解释保密、提供口译与陪护、筛查胁迫、并把日期写下来。
- 采集每一个暴露的部位；血不能诊断衣原体或淋病、而漏掉的那支咽拭子是“表面治疗失败”最常见的原因。
- 当可能性高时按综合征同时覆盖衣原体与淋病、然后按结果降阶梯；淋病的耐药是一个永久的急症。
- 梅毒的血清学是一个“两种检测的故事”、是一种判读、不是一个数字；妊娠让每一个不一致的结果都变得紧迫。
- 溃疡加淋巴结加旅行或网络史需要单纯疱疹的核酸检测、密螺旋体的配对、并留意性病性淋巴肉芽肿、软下疳与腹股沟肉芽肿。
- 接种人乳头瘤病毒、甲肝与乙肝、性伴通知、筛查的提议与暴露前预防才是终结暴发的临床动作；处方是容易的部分。

## 继续深入

用一段话概括感染性疾病的思维：按来源、途径、宿主与时间思考。在给综合征命名之前先确定来源；问暴露史允许什么、以及本地的耐药地图让什么变得可能；一切都按站在你面前的那个宿主来调整；并把时钟当作一种药——脓毒症与心内膜炎及脑膜炎的结局是小时数的函数。然后用这个专科的两种失败模式审计自己：在那些不典型的呈现继续演变时锚定在第一个可信的微生物上、以及永远不降阶梯——那个本该在第三天发生的窄谱转换没有发生。两种失败都能靠一个习惯治好：在每一次复审时重新问一遍，昨天的病史说了什么、而今天它不再说什么。
