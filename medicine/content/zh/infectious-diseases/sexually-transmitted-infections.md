性传播感染（STI）是世界上最常见的感染之一。WHO估计，全球每天新发可治愈的性传播感染超过一百万例。许多感染完全没有症状，却可导致不孕、异位妊娠、慢性盆腔痛、癌症、死产和新生儿感染，并增加感染和传播HIV的风险。在英格兰，淋病诊断数在2023年达到约85,000例的创纪录水平，2024年的梅毒诊断数是1948年以来最高的。

性健康医学有其自身的特点。诊断依赖于敏感、不带评判的病史采集。检测针对暴露部位，受检者常常没有症状。只治疗一个人而不治疗其性伴，治疗就不完整。保密至关重要，必须识别保护方面的问题，尤其是在年轻人中。而淋病奈瑟菌（*Neisseria gonorrhoeae*）这一种病原体，已成为抗微生物药物耐药性的试金石。

本章介绍性健康诊疗、细菌性性传播感染、生殖器溃疡与梅毒、病毒性性传播感染以及预防。英国的做法遵循英国性健康与HIV协会（BASHH）的指南；治疗以原则形式描述，具体方案依据现行指南。

## 性健康诊疗

::: definition 性健康评估 {#def-consultation}
**性健康评估**包括结构化的性生活史采集、必要时的体格检查，以及由病史指导的检测。

**性生活史**包括：症状；**性伴**（人数、性别、是新性伴还是固定性伴，以及与每人最后一次性行为的日期）；**性行为方式**（阴道性交、肛交或口交，以及暴露的部位）；**防护**（安全套、HIV暴露前预防、疫苗接种）；**既往性传播感染**及检测史；**妊娠**风险和避孕；性行为前后的药物和酒精使用（包括“化学性爱”）；以及对强迫、剥削或虐待的任何担忧。

**检测**按暴露部位进行。对衣原体和淋病，使用**核酸扩增试验（NAAT）**：男性取**首段尿**，女性取**自采外阴阴道拭子**；相应部位有暴露时加取直肠和咽拭子。血液检测**HIV**、**梅毒**，并根据风险检测乙型和丙型肝炎。暴露后不久进行的检测可能漏掉感染：**窗口期**约为衣原体和淋病NAAT两周，梅毒血清学最长十二周，第四代HIV检测45天。
:::

诊疗是保密的。在英国，性健康服务是开放就诊的：无需转诊即可就诊，病历与一般医疗记录分开保存。16岁以下的年轻人如有能力表示同意，可获得保密的医疗服务，但必须评估其福祉，并对可能存在的性剥削或性虐待采取行动。

**性伴通知**是告知性伴他们可能已暴露、以便其接受检测和治疗的过程。可以由患者本人、由诊所（不透露指示病例的身份）或由两者共同完成。通知范围是**回溯期**内的性伴，回溯期因感染而异：例如，有症状的淋菌性尿道炎男性约两周，其他情况的淋病三个月，有症状的衣原体尿道炎男性四周，无症状衣原体感染六个月。

## 细菌性性传播感染

::: definition 衣原体、淋病及相关感染 {#def-bacterial}
**沙眼衣原体（*Chlamydia trachomatis*）**是一种专性细胞内寄生的细菌，是最常见的细菌性性传播感染。大多数女性和许多男性感染后**没有症状**。症状包括尿道炎和排尿困难、阴道分泌物增多、经间期或性交后出血以及直肠症状。并发症包括**盆腔炎（PID）**——可导致输卵管性不孕、异位妊娠和慢性盆腔痛；附睾睾丸炎；性获得性反应性关节炎；以及受感染母亲所生婴儿的结膜炎和肺炎。由侵袭性血清型引起的性病性淋巴肉芽肿（LGV）导致直肠炎，主要见于男男性行为者。按BASHH指南，非复杂性衣原体感染用七天疗程的**多西环素**治疗，妊娠期有替代方案。

**淋病奈瑟菌**是一种革兰氏阴性双球菌。在男性中，它通常在暴露后几天引起**伴脓性分泌物的尿道炎**；在女性中，以及在所有人的咽部和直肠，感染常常没有症状。并发症包括盆腔炎、附睾炎和**播散性淋球菌感染**。由于耐药问题，**治疗前要取标本做培养和药敏试验**。BASHH（2019年）建议在药敏未知时单次肌内注射**头孢曲松**，并对所有接受治疗者进行**治愈检测**。

**生殖支原体（*Mycoplasma genitalium*）**引起尿道炎、宫颈炎和盆腔炎；对大环内酯类和氟喹诺酮类耐药很常见，因此治疗以耐药检测为指导。**阴道毛滴虫（*Trichomonas vaginalis*）**是一种原虫，引起泡沫状阴道分泌物和外阴炎，用甲硝唑（metronidazole）治疗。
:::

细菌性阴道病和外阴阴道念珠菌病是阴道分泌物增多的常见原因，通常意义上并不属于性传播感染，但在每次评估中都是鉴别诊断的一部分。

::: warning
**疑似盆腔炎要根据临床表现进行治疗。** 盆腔炎是一种临床诊断：有性生活的女性出现下腹痛，双合诊有附件压痛或宫颈举痛，并已排除妊娠、异位妊娠和外科急症。衣原体和淋病检测阴性**不能**排除盆腔炎，因为许多病例涉及其他微生物，或感染位于上生殖道。延误治疗会增加输卵管损伤和不孕的风险，因此应立即开始覆盖淋病、衣原体和厌氧菌的广谱抗生素治疗，并通知性伴。
:::

::: example 周末出游之后的尿道分泌物 {#ex-urethritis}
一名26岁男性排尿困难、尿道有黄色分泌物三天。五天前他与度假时认识的一名女性发生了无套阴道性交，他在家中有一位固定的女性伴侣。尿道涂片革兰氏染色见大量多形核白细胞，内有**细胞内革兰氏阴性双球菌**。
::: solution
**诊断**：**淋菌性尿道炎**，由革兰氏染色推定确诊；在有症状的男性中，该染色的灵敏度和特异度都很高。

**治疗前**：取尿道拭子做**培养和药敏**试验，并做淋病和衣原体NAAT；提供HIV和梅毒检测（并在各自的窗口期后复查）。询问口交和肛交暴露，如有则需取咽部或直肠标本。

**治疗**：按现行指南单次肌内注射头孢曲松。如同时发现衣原体，也要一并治疗。在他和他的性伴都接受治疗之前，他应避免性生活。

**性伴**：对有症状尿道炎的男性，淋病的回溯期约为症状出现前**两周**；他的度假性伴（如能联系上）和固定伴侣都需要检测和治疗。这次谈话需要技巧：诊所可以在不透露他姓名的情况下通知性伴。

**治愈检测**：治疗后约两周做NAAT（或三天后做培养），因为英格兰现已报告对头孢曲松耐药的菌株，常与前往亚太地区旅行有关。
:::
:::

::: example 关节痛和脓疱 {#ex-dgi}
一名24岁女性发热三天，疼痛在腕、膝和踝关节之间游走，左手背沿肌腱有疼痛性肿胀。前臂和腿上有六个红色基底上的小脓疱。她有一位新的男性伴侣，月经结束后三天。
::: solution
**模式**：发热、游走性多关节痛、**腱鞘炎**和散在的**脓疱性皮损**构成**播散性淋球菌感染（DGI）**的经典三联征，它是由常无症状的黏膜感染经血行播散而来。月经、妊娠和补体缺陷会增加风险。主要的另一种情况是单关节化脓性关节炎，即DGI的另一种形式；反应性关节炎、脑膜炎球菌病和急性风湿性疾病也在鉴别诊断之列。

**检查**：血培养；如有关节积液则抽液做革兰氏染色和培养；**宫颈、尿道、直肠和咽部**的NAAT和**培养**；HIV和梅毒检测；妊娠试验。

**治疗**：收住院**静脉使用头孢曲松**，临床好转后根据药敏改为口服治疗，总疗程通常至少七天。检测并治疗衣原体。随后进行性伴通知和治愈检测。反复发生奈瑟菌感染时应检测**补体缺陷**。
:::
:::

## 生殖器溃疡与梅毒

::: definition 生殖器溃疡病 {#def-ulcers}
**生殖器溃疡**是生殖器或肛周皮肤或黏膜的破损。在英国，最常见的感染性原因是**生殖器疱疹**，典型表现为多发、表浅、疼痛的溃疡。**梅毒**典型地引起单个、无痛、质硬的溃疡（**硬下疳**），伴有质韧的区域淋巴结肿大，但也有不典型和多发的硬下疳。较少见的原因有**性病性淋巴肉芽肿**，旅行者中还有软下疳和腹股沟肉芽肿。非感染性原因包括外伤、固定性药疹、白塞病和癌症。每一个生殖器溃疡都要检测疱疹（PCR）和梅毒（条件允许时做病灶PCR，并做血清学检查），因为临床外观并不可靠。
:::

**梅毒**由螺旋体**梅毒螺旋体（*Treponema pallidum*）**引起，未经治疗时分期进展：

- **一期**：在接种部位出现硬下疳，通常在暴露后约三周（范围9–90天），数周内自行愈合。
- **二期**：数周至数月后出现全身性疾病，有常累及**手掌和足底**的广泛皮疹、口腔黏膜斑、湿润的疣状**扁平湿疣**、淋巴结肿大、斑片状脱发，有时有肝炎、肾脏受累或脑膜炎。
- **潜伏期**：无体征，只有血清学阳性；最初两年内为**早期潜伏梅毒**（英国和WHO的定义），此后为**晚期潜伏梅毒**。
- **三期**，多年以后：树胶肿（破坏性肉芽肿）、心血管梅毒（主动脉炎和主动脉瓣关闭不全）以及晚期神经梅毒（脊髓痨、麻痹性痴呆）。

**神经梅毒、眼梅毒和耳梅毒**可发生在包括早期在内的任何阶段。任何梅毒患者出现视觉症状、听力下降或耳鸣，或神经系统症状，都需要紧急评估。

::: theorem 解读梅毒血清学 {#thm-serology}
梅毒血清学使用两类检测：

- **梅毒螺旋体试验**（酶免疫测定、TPPA）检测针对梅毒螺旋体抗原的抗体。它们最先转阳，并且即使治疗成功后**通常也终身阳性**，因此它们表明曾经感染过，但不能说明感染是否活动。
- **非梅毒螺旋体试验**（RPR、VDRL）检测针对受损细胞释放的脂质抗原的抗体。结果以滴度报告（1:2、1:4、1:8……），**反映疾病活动性**：活动性感染时升高，治疗后下降。

筛查用梅毒螺旋体试验；阳性结果用第二种梅毒螺旋体试验确证，并用RPR定量。RPR滴度**下降四倍（两个稀释度）**表明治疗充分，通常在6–12个月内出现；升高四倍提示再感染或复发。梅毒螺旋体试验阳性而RPR阴性，通常意味着既往已治疗，或感染处于很早期或很晚期，需结合病史解读。
:::

早期梅毒的**治疗**是单次肌内注射**苄星青霉素（benzathine benzylpenicillin）**，晚期潜伏梅毒为每周一次、共三次；神经梅毒需要脑脊液中更高的药物浓度，用每日青霉素治疗约两周。非妊娠期青霉素过敏者有替代药物。首剂后24小时内，许多早期梅毒患者会出现**吉海反应（Jarisch–Herxheimer reaction）**（发热、头痛、肌痛和皮疹加重），由梅毒螺旋体产物的释放引起；它在一天内消退，但在妊娠期可诱发宫缩。

**先天性梅毒**由经胎盘感染引起，可导致流产、死产、早产，以及婴儿的一系列表现（皮疹、肝脾大、鼻塞流涕、骨病变，以及后来的哈钦森牙和耳聋）。通过对每一次妊娠进行筛查并及时用青霉素治疗即可预防；英国在初次产检时筛查。

::: example 初次产检时筛查阳性 {#ex-congenital}
一名27岁女性第一次妊娠12周，初次产检梅毒筛查阳性。确证性梅毒螺旋体试验阳性，RPR 1:32。她没有症状，也不记得有过皮疹或溃疡。过去两年她唯一的性伴是丈夫。前一年她在终止妊娠前做的筛查为阴性。
::: solution
**解读**：梅毒螺旋体试验阳性、RPR滴度高，而两年内的筛查为阴性，提示**早期潜伏梅毒**：近期的活动性感染，目前没有体征。

**治疗**：紧急肌内注射苄星青霉素。**青霉素**是唯一被证明能可靠治疗胎儿的药物；如果她过敏，应考虑脱敏而不是改用其他药物。告知她**吉海反应**，在妊娠期它可引起宫缩或胎儿窘迫，一旦出现要寻求帮助。对她检测HIV、乙型肝炎和其他性传播感染，并检查有无二期梅毒的体征。

**随访**：孕期监测RPR以确认下降四倍；妊娠后期做胎儿超声检查有无胎儿感染的征象。出生时由儿科医生检查和检测婴儿，并把婴儿的RPR与母亲的进行比较。

**性伴**：她的丈夫需要紧急检测和治疗，在他们再次发生性行为之前完成，否则她会再次被感染。这需要一次敏感、保密的谈话，诊所可以协助性伴通知。
:::
:::

## 病毒性性传播感染

::: definition 疱疹、HPV及其他病毒性性传播感染 {#def-viral}
**单纯疱疹病毒（HSV）**1型和2型感染黏膜细胞，随后在感觉神经节（生殖器感染为骶神经节）中建立**终身潜伏**，并可再激活。生殖器HSV-1常经口交获得，现已占年轻成人首次生殖器发作的很大比例。**首次发作**可以很严重：多发疼痛性溃疡、排尿困难、腹股沟淋巴结肿大、发热，有时有尿潴留或无菌性脑膜炎。用口服抗病毒药（阿昔洛韦（aciclovir）或伐昔洛韦（valaciclovir））治疗约五天。**复发**较轻、较短，HSV-2复发最频繁。病毒也会从外观正常的皮肤排出（**无症状排毒**），这解释了大多数的传播。妊娠晚期的原发感染有导致**新生儿疱疹**的风险，后者可能致命。

**人乳头瘤病毒（HPV）**：低危型（主要是6型和11型）引起**肛门生殖器疣**；高危型（主要是16型和18型）引起宫颈癌、肛门癌、阴茎癌、外阴癌、阴道癌和口咽癌。感染非常常见，通常在两年内清除。**HPV疫苗**可预防其覆盖型别的感染；在英国，青少年可接种（自2023年起为单剂），45岁以下的男同性恋者、双性恋者及其他男男性行为者也可接种。

**乙型肝炎**可经性传播，可用疫苗预防；对性风险较高的人提供疫苗接种。**甲型肝炎**和**丙型肝炎**也可经性传播，尤其是在男男性行为者中。**HIV**见[[infectious-diseases/hiv]]；**猴痘**自2022年起在性网络中传播，表现为疼痛性肛门生殖器皮损、直肠炎和淋巴结肿大。
:::

::: example 疱疹又复发了 {#ex-recurrent}
一名28岁女性两年前被诊断为生殖器HSV-2感染。过去一年她复发了八次，每次持续四至五天，影响了她的感情生活和情绪。她和伴侣正在计划怀孕。
::: solution
**选择**：每年复发六次或以上时，**抑制性抗病毒治疗**（每日阿昔洛韦或伐昔洛韦）能显著减少复发次数，并减少（但不能消除）无症状排毒和传播。治疗约一年后评估复发是否已减少。复发较少的人也可以选择在首个先兆症状出现时开始的发作期治疗。

**传播与告知**：传播可发生在两次复发之间。安全套和抑制性治疗都能降低风险。如果她的伴侣从未感染过HSV-2，检测其HSV-2抗体可以明确他的风险。是否告知由她决定，支持性咨询会有帮助。

**妊娠**：复发性感染导致新生儿疱疹的风险较低，因为她有可通过胎盘的抗体。从约36周开始抑制性使用阿昔洛韦，可减少分娩时的复发和剖宫产的需要。最大的危险是在妊娠晚期获得的**原发**感染，其处理方式不同，通常采用剖宫产。还应关注她的精神健康；复发性疱疹常引起痛苦。
:::
:::

## 预防与耐药问题

性传播感染的控制综合了多种方法：

- 对有症状者以及无症状但有风险者进行**检测和治疗**，并通过**性伴通知**阻断传播链。
- **安全套**，能大大减少大多数性传播感染的传播；以及**HIV暴露前预防**。
- 为有风险者接种HPV、甲型和乙型肝炎以及猴痘**疫苗**。2025年8月，英格兰启动了一项计划，为较高风险的男同性恋者和双性恋者接种B群脑膜炎球菌疫苗4CMenB，因为它对淋病有部分交叉保护作用。
- **多西环素暴露后预防（doxyPEP）**：性行为后72小时内单次服药，可减少梅毒和衣原体感染。BASHH指南（2025年）建议对梅毒风险较高的男同性恋者、双性恋者及其他男男性行为者以及跨性别女性使用，同时指出了对抗微生物药物耐药性和微生物组影响的担忧。

**淋病奈瑟菌对用于治疗它的每一种抗生素都产生了耐药**：磺胺类、青霉素、四环素类、氟喹诺酮类，以及近来的口服头孢菌素和阿奇霉素。头孢曲松是最后一种可靠的经验性治疗药物，而英国和其他地方已报告了耐药菌株。应对措施包括治疗前培养、治愈检测、结合基因组分型的国家监测、对耐药病例的快速接触者追踪，以及唑氟达星（zoliflodacin）和吉泊达星（gepotidacin）等已完成3期试验的新型口服抗生素。这与[[infectious-diseases/stewardship-outbreaks]]中讨论的更广泛问题相联系。

::: history
阿尔伯特·奈瑟（Albert Neisser）于1879年描述了淋球菌。1905年，弗里茨·绍丁（Fritz Schaudinn）和埃里希·霍夫曼（Erich Hoffmann）在梅毒病灶中发现了梅毒螺旋体，1906年奥古斯特·冯·瓦色曼（August von Wassermann）推出了第一种梅毒血液检测。1910年，保罗·埃尔利希（Paul Ehrlich）和秦佐八郎（Sahachiro Hata）推出了治疗梅毒的胂凡纳明（arsphenamine，商品名Salvarsan），这是第一种合成抗微生物药物。1943年，美国的约翰·马奥尼（John Mahoney）等证明青霉素能治愈早期梅毒，它至今仍是首选治疗。性传播感染的历史还包括医学史上最严重的伦理失败之一：在塔斯基吉研究（1932–1972年）中，美国公共卫生署在未获知情同意的情况下观察数百名黑人男性未经治疗的梅毒，并在青霉素成为标准治疗后仍不予治疗。这一事件的曝光促成了现代研究伦理和知情同意的规则（[[medical-ethics-law/research-ethics]]）。
:::

::: quiz
一名45岁男性梅毒螺旋体EIA和TPPA阳性，RPR阴性。他八年前接受过梅毒治疗，RPR当时适当下降。他没有症状，也没有新的性伴。最可能的解读是什么？
- [ ] 活动性二期梅毒
- [x] 既往已治疗的梅毒，梅毒螺旋体抗体持续存在
- [ ] 梅毒螺旋体试验假阳性
- [ ] 神经梅毒
::: solution
治疗后梅毒螺旋体抗体通常终身存在，而RPR阴性表明目前没有疾病活动。有充分治疗的记录且没有新的风险，这属于“血清学瘢痕”。若出现新的风险、症状或RPR升高，解读就会改变。
:::
:::

## 后续内容

HIV见[[infectious-diseases/hiv]]。相关病原体在[[microbiology/bacteria]]和[[microbiology/viruses]]中介绍。避孕以及盆腔炎对生育的影响见[[obstetrics-gynaecology/contraception-fertility]]，宫颈筛查和HPV相关癌症见[[obstetrics-gynaecology/gynaecological-cancer]]。年轻人的保密和同意问题见[[medical-ethics-law/confidentiality]]，淋病的耐药见[[infectious-diseases/stewardship-outbreaks]]。

::: summary
- 性传播感染常见且常无症状；检测以不带评判的性生活史为指导，针对每一个暴露部位，并注意窗口期。
- 衣原体是最常见的细菌性性传播感染，通常没有症状，可引起盆腔炎和不孕；用多西环素治疗。
- 淋病在治疗前做培养，用头孢曲松治疗，随后做治愈检测；它已对用于治疗它的每一类抗生素产生耐药。
- 盆腔炎根据临床怀疑进行治疗；检测阴性不能排除它。
- 生殖器溃疡要同时检测疱疹和梅毒。梅毒有一期、二期、潜伏期和三期，并可在任何阶段累及眼、耳和神经系统。
- 梅毒螺旋体试验终身阳性；非梅毒螺旋体试验滴度（RPR）反映活动性，下降四倍表明治疗充分。青霉素治疗梅毒并预防先天性感染。
- 性伴通知、安全套、PrEP、疫苗（HPV、乙型肝炎、4CMenB）和doxyPEP可预防传播。
:::

## 习题

::: exercise 计算稀释度 {level=1 check="3"}
一名男性的RPR滴度从诊断时的1:64降至治疗后九个月的1:8。下降了多少个两倍稀释度？
::: solution
$64 \to 32 \to 16 \to 8$：**三个**两倍稀释度，即下降八倍。这超过了表明治疗充分的四倍（两个稀释度）下降。
:::
:::

::: exercise 为时过早 {level=1}
一名女性在与新性伴发生无套性行为五天后就诊，担心被感染。她没有症状。现在哪些检测有用？应何时复查？
::: solution
现在的检测能发现更早获得的感染，但可能漏掉这次暴露所致的感染。现在可以做衣原体和淋病NAAT，但应在**暴露后两周复查**。第四代HIV检测应在**45天**时复查，梅毒血清学在约**十二周**时复查。应讨论紧急避孕（她仍在宫内节育器或口服方案的时间窗内）；如果性伴已知感染HIV或来自高患病率人群，应考虑HIV暴露后预防（PEP必须在72小时内开始）。
:::
:::

::: exercise 衣原体筛查与假阳性 {level=2 check="round(100*0.01*0.95/(0.01*0.95 + 0.99*0.005))/100"}
一种衣原体NAAT的灵敏度为95%，特异度为99.5%。在患病率为1%的人群中，阳性预测值是多少？答案保留两位小数。
::: solution
$$
\text{PPV} = \frac{0.01 \times 0.95}{0.01 \times 0.95 + 0.99 \times 0.005} = \frac{0.0095}{0.01445} \approx 0.66
$$

在这一患病率下，约三分之一的阳性结果是假阳性。对于一个会影响人际关系的诊断来说，这很重要，这就是为什么低患病率场合和某些部位（如淋病的咽部）要做确证检测。
:::
:::

::: exercise 乙型肝炎血清学 {level=2}
三名到性健康诊所就诊的人乙型肝炎检测结果如下。逐一解读。(a) HBsAg阴性，抗-HBc阴性，抗-HBs 150 IU/L。(b) HBsAg阴性，抗-HBc阳性，抗-HBs 80 IU/L。(c) HBsAg阳性，抗-HBc阳性（IgG），抗-HBs阴性，相隔六个月的两次检测结果相同。
::: solution
(a) **接种疫苗获得免疫**：只有抗-HBs，没有抗-HBc（抗-HBc只出现在自然感染之后）。(b) **既往感染已清除**，具有自然免疫；此人在利妥昔单抗等强免疫抑制下可能发生病毒再激活（[[infectious-diseases/immunocompromised-host]]）。(c) **慢性乙型肝炎感染**：表面抗原持续超过六个月。此人需要检测HBeAg、病毒载量，评估肝脏，检测丁型肝炎，转诊专科，并为性伴和家庭接触者接种疫苗和进行检测。
:::
:::

::: exercise 盆腔痛 {level=2}
一名19岁女性下腹痛、深部性交痛和经间期出血一周。体温37.8 °C。检查有宫颈举痛和双侧附件压痛。妊娠试验阴性。已取拭子。诊断是什么？必须排除什么？如何处理？
::: solution
**诊断**：临床**盆腔炎**。**需排除**：异位妊娠（妊娠试验阴性有帮助）、阑尾炎、卵巢扭转或囊肿意外，以及子宫内膜异位症；如果病情很重，要排除输卵管卵巢脓肿（超声）。**处理**：**立即**开始抗生素治疗，不等待结果，按现行BASHH指南采用覆盖淋病、衣原体、有指征时覆盖生殖支原体以及厌氧菌的方案；如果病情严重、妊娠、有脓肿或不能口服治疗，则收住院。72小时后复查。性伴通知和治疗对防止再感染至关重要。应告知她将来不孕和异位妊娠的风险，以及早期治疗能降低这些风险。
:::
:::

::: exercise 睾丸疼痛 {level=2}
一名22岁男性右侧睾丸疼痛肿胀两天，伴排尿困难。附睾压痛，睾丸位置正常；提睾反射存在。重要的鉴别诊断有哪些？与一名有相同症状的70岁男性相比，处理有何不同？
::: solution
**鉴别诊断**：必须首先排除**睾丸扭转**，因为它需要在数小时内手术；起病缓慢、排尿困难、睾丸位置正常和提睾反射存在使扭转的可能性降低，但只要真有疑问就意味着要紧急手术探查。最可能的诊断是**附睾睾丸炎**，在年轻、有性生活的男性中通常由**衣原体或淋病**引起。检测：NAAT和尿道培养；治疗覆盖两种病原体，并进行性伴通知。对**70岁**男性，附睾睾丸炎通常由与尿路感染或膀胱出口梗阻相关的**肠道革兰氏阴性菌**引起，因此要送中段尿培养，选择针对泌尿道病原体的抗生素，并检查泌尿道。
:::
:::

::: exercise 治疗失败 {level=3}
一名30岁男男性行为者因直肠淋病接受了头孢曲松治疗。三周后的治愈检测NAAT为阳性。他说治疗后没有性行为。讨论可能发生了什么、应该做什么，以及为什么这个病例的意义超出了个人。
::: hint
考虑再感染、核酸持续存在和真正的耐药；想一想监测。
:::
::: solution
**可能的解释**：(1) **再感染**，如果他有过性行为（他说没有，但应敏感地进一步询问，包括与未经治疗的固定性伴的接触）；(2) **假阳性或核酸持续存在**，治疗后三周可能性较小；(3) **头孢曲松耐药导致的治疗失败**，或直肠部位治疗不充分。

**措施**：在任何进一步治疗前**从所有暴露部位取培养**，以便测定病原体的药敏；通知当地卫生防护团队，并把分离株送国家参考实验室做药敏试验和基因组分型；按专科意见治疗，采用以药敏为指导的替代方案；重复治愈检测；紧急追踪并检测所有性伴，如有可能包括在国外的性伴。

**更广泛的意义**：头孢曲松是淋病最后一种可靠的经验性治疗药物。每一个耐药病例都可能是在性网络中扩散的开端，国家监测有赖于迅速发现和报告此类病例。本病例说明了为什么培养和治愈检测是英国指南中的标准做法。
:::
:::

::: exercise 累及眼睛的梅毒 {level=3}
一名HIV控制良好的38岁男性双眼视物模糊、眼前漂浮物一周。两个月前他手掌上有皮疹，后来消退了。眼科发现双侧葡萄膜炎。RPR 1:128，梅毒螺旋体试验阳性。讨论诊断、检查和处理。
::: solution
**诊断**：并发于**二期梅毒**（手掌皮疹）的**眼梅毒**。眼梅毒、耳梅毒和神经梅毒可发生在任何阶段，在HIV感染者中更常见，但并非只见于他们。RPR高滴度证实为活动性感染。

**检查**：紧急眼科评估；全面的神经系统检查和听力评估；按当地指南做**腰椎穿刺**，检查脑脊液细胞计数、蛋白和VDRL以寻找神经梅毒（无论脑脊液结果如何，眼梅毒都按神经梅毒处理）；HIV病毒载量和CD4；其他性传播感染检测。

**处理**：按**神经梅毒**治疗，使用大剂量静脉青霉素G（或能在中枢神经系统达到杀螺旋体浓度的等效方案）约两周，并与眼科联合处理，眼科可能加用糖皮质激素控制炎症。吉海反应可使眼部炎症暂时加重。随访包括RPR、眼科检查，以及在脑脊液异常时复查脑脊液。性伴通知覆盖过去六个月或更长时间，并可讨论今后使用doxyPEP以及接种HPV和肝炎疫苗。
:::
