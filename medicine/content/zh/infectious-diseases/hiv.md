HIV同时是一种已被解决的和未被解决的疾病、完全取决于它何时以何种方式被发现：**一个早期诊断、接受治疗并留在照护中的人有接近正常的预期寿命、并且不会经性传播病毒；而仍有成千上万的人因为污名、检测的缺口与随访的丢失而晚诊、带着机会性感染就诊。**下面医学容易记住；真正重要的能力是检测、分期、在同一周启动治疗、预防并识别机会性疾病、以及照护一个慢性病毒患者的整个生命周期。

本章涵盖病毒学与免疫发病机制、检测与诊断、抗逆转录病毒治疗、机会性感染、及与HIV共同衰老的非艾滋病共病。

## 病毒与免疫的破坏

::: definition HIV的病毒学与免疫发病机制 {#def-virology}
**病毒（一种有包膜的逆转录病毒、带表面的gp120与gp41及核心糖蛋白、一条正链RNA的双倍体基因组、及逆转录酶与整合酶及蛋白酶——正是那三个酶靶标构成了大部分的药物类别——附HIV-2的内源性奈韦拉平耐药与多替拉韦敏感性较低之注、及辅助受体从CXCR4到CCR5嗜性的转换、及单药治疗时击败治疗的逃逸突变——逆转录病毒的家族逻辑见[[microbiology/viruses]]、逆转录的步骤见[[cell-biochemistry/gene-expression]]）；靶细胞与储库（CD4 T细胞作为家中的贼——gp120结合CD4、然后辅助受体的结合与膜融合、及作为潜伏前病毒整合入宿主基因组、及解剖的储库：肠淋巴组织与巨噬细胞及小胶质细胞及静息的记忆CD4细胞、这解释了为何治疗是终生的、而治愈仍是研究的远景、带中枢神经系统穿透与中枢逃逸的问题——T细胞的家园见[[immunology/adaptive-responses]]、小胶质细胞见[[nervous-system/neuroinflammation]]）；免疫学的弧线（急性病毒血症与单核细胞增多症样的疾病、及部分的免疫控制进入一个临床潜伏期、带按表型每年数百个的CD4下降、及罕见的精英控制者那个调定点与病毒载量的例外、及数周内发生的肠黏膜CD4耗竭、驱动全身免疫激活、及那个恰好产生[[#def-opportunistic]]中所列机会性微生物与肿瘤的功能免疫崩塌）；及传播与预防的方式（性、血液与围产途径、带病毒载量作为主控变量——治疗即预防与“测不到等于传不了”的证据基础、及避孕套与暴露前预防及暴露后预防及针具交换及已检测的血液供应及母婴传播预防这个叠层、及那个解释为何数十年的疫苗仍未解决免疫学——包膜糖衣的屏蔽与胚系靶向的尝试——[[public-health/vaccination-programmes]]、母婴传播见[[obstetrics-gynaecology/pregnancy-complications]]、血液供应见[[public-health/health-systems-economics]]）。**
:::

## 检测、分期、启动

::: definition 诊断与初始管理 {#def-diagnosis}
**检测的策略（第四代的联合检测、同时检出抗体与p24抗原、带窗口期的算术——血清转换的病常常是被回顾性诊断的——及针对急性可疑病例的病毒核糖核酸或核酸扩增、及确诊阳性总是用补充的鉴别试验、及“不要把单一反应性的筛查报出去”——[[microbiology/laboratory-diagnosis]]、[[microbiology/viruses]]；提供的责任——在急诊与产科及门诊服药诊所及性病诊所及任何有风险呈现时的被动与主动提供的规划、及对着高龄异性恋及跨性别及移民人群的视而不见——[[public-health/screening]]、[[obstetrics-gynaecology/pregnancy-antenatal]]、[[infectious-diseases/sexually-transmitted-infections]]、[[public-health/determinants-inequalities]]）。基线与分期（确诊阳性后以CD4与病毒载量作为分期的对、及治疗前的耐药基因型——传播的药物耐药突变——及使用阿巴卡韦之前的HLA-B*5701、及共感染的筛查——乙肝与丙肝及结核及性病及弓形虫血清学及水痘免疫——及为器官功能与共病的基线化验——[[clinical-skills/laboratory-tests]]、[[pharmacology/patient-variation]]）；作为预防阈值清单的分期（触发肺孢子菌与弓形虫预防的CD4计数、及“抗逆转录病毒治疗立即开始并解决根本问题”的哲学、带在等待免疫恢复期间何时加复方磺胺——[[infectious-diseases/immunocompromised-host]]、[[microbiology/antimicrobials]]）；及抗逆转录病毒治疗（现代的默认——两个核苷或核苷酸的主干、加一个整合酶抑制剂、或一个增强的蛋白酶抑制剂、或非核苷类逆转录酶抑制剂、带比克替拉韦与多替拉韦时代的首选、及为依从性设计的每日一片架构——带各自毒性的药理类别：替诺福韦的肾与骨、及丙酚胺的改进、及拉米夫定、阿巴卡韦的超敏与HLA的关联、及整合酶抑制剂的体重增加与失眠及二价阳离子的螯合相互作用、及非核苷类的皮疹与神经精神及CYP诱导的相互作用——CYP的逻辑见[[pharmacology/drug-receptor]]、[[pharmacology/adverse-reactions]]、骨的一行见[[endocrine/bone-calcium]]）；同周“带着一切开始”的路径（在结果出来之前的快速启动、通常用比克替拉韦或多替拉韦为基础的方案、及关于食物与隐私及记得服药及随访间隔的依从性谈话、及那个可能被诊断引爆家庭暴力的安全规划——[[clinical-skills/communication]]、[[obstetrics-gynaecology/contraception-fertility]]，血清不一致伴侣的更安全受孕的邻近在那一章、[[public-health/communicable-disease-control]]，性伴通知见[[infectious-diseases/sexually-transmitted-infections]]）。**
:::

::: definition 治疗时代的机会性疾病 {#def-opportunistic}
**按CD4下降的清单肺孢子菌肺炎、如今在晚诊者中仍是最常见的艾滋病定义性表现——亚急性的干咳与低氧及乳酸脱氢酶升高、及与听诊不相称的低氧、及断层的磨玻璃综合征、及大剂量的治疗、对低氧者加辅助激素、及诊断的聚合酶链对银染、及诱导痰对支气管肺泡灌洗的现实——肺孢子菌的邻近见[[respiratory/respiratory-infections]]、分类见[[microbiology/fungi-parasites]]、[[renal/acute-kidney-injury]]——复方磺胺的肾与钾及低钠的监测——[[renal/potassium-calcium-phosphate]]、[[microbiology/antimicrobials]]；中枢——弓形虫脑炎的环形强化病灶与效应、带血清学指导的推定治疗对活检、及两性霉素与氟胞嘧啶的巩固与维持马拉松、带脑脊液压力的管理、及“隐球菌不要急着上抗逆转录病毒治疗”的时机规则、及进行性多灶性白质脑病的JC病毒、及中枢淋巴瘤对感染的影像两难——[[nervous-system/neuroinflammation]]、[[nervous-system/motor-systems]]、[[pathology/cancer-diagnosis]]，中枢淋巴瘤见[[blood/leukaemia]]；分枝杆菌——利福霉素与整合酶抑制剂的剂量调整之舞、及处于最底层如今因早期治疗而更少见的鸟胞内分枝杆菌复合群——[[infectious-diseases/tuberculosis]]、[[microbiology/bacteria]]；消化与眼——巨细胞病毒结肠炎与食管炎及视网膜炎：那个视物模糊与飞蚊的眼科急症、及巨细胞病毒性脑炎与神经根综合征——食管溃疡的鉴别见[[gastrointestinal/oesophagus-stomach]]、视网膜炎见[[nervous-system/sensory-systems]]、[[microbiology/viruses]]；及肿瘤的三联——卡波西肉瘤与人类疱疹病毒8、累及皮肤与口腔及内脏及淋巴、及非霍奇金淋巴瘤（全身性与中枢、及宫颈癌的不典型增生筛查强化、带男性同性性行为者与跨性别女性的肛门癌筛查论证——卡波西的一行见[[musculoskeletal/skin-cancer]]、[[blood/lymphoma-myeloma]]、[[obstetrics-gynaecology/gynaecological-cancer]]、[[public-health/screening]]）；免疫重建炎症反应综合征（在抗逆转录病毒治疗最初数周内、对已知感染的矛盾性加重或对隐匿感染的揭开、带早期的发热与淋巴结炎及脑膜炎的恶化、及“通常不要停抗逆转录病毒治疗、治疗微生物、并在选定的综合征中使用激素”的路径——一个排除性的诊断、需要临床的警觉、及它最危险的隐球菌与结核的邻里——[[infectious-diseases/immunocompromised-host]]）；及预防与预先治疗的政策（复方磺胺覆盖肺孢子菌与弓形虫、带磺胺过敏的脱敏、或阿托伐醌或氨苯砜或雾化喷他脒的退路、及在极低CD4时的隐球菌抗原筛查策略、及疫苗的优先清单——相关风险人群中的猴痘——及活疫苗的CD4阈值规则——[[public-health/vaccination-programmes]]、[[immunology/immunodeficiency]]）。**
:::

::: example 听诊正常的肺炎 {#ex-pjp}
一名直到今天才被诊断的40岁HIV阳性男性、干咳3周、活动时血氧从98%降到89%、发热、体重下降；查体几乎毫无声音、乳酸脱氢酶升高、氧梯度宽、断层显示弥漫磨玻璃影；CD4为60、病毒载量90万。
::: solution
**作为艾滋病起病表现的肺孢子菌肺炎——低氧与查体之间经典的错配（[[#def-opportunistic]]、[[microbiology/fungi-parasites]]）：可能的话确证——诱导痰或支气管肺泡灌洗做聚合酶链或免疫荧光、及作为支持而非唯一证据的血β葡聚糖、及在同一份标本上对巨细胞病毒与结核及真菌的共病原巡视——[[clinical-skills/laboratory-tests]]、[[microbiology/laboratory-diagnosis]]、[[infectious-diseases/tuberculosis]]；按严重度治疗——大剂量的复方磺胺、按肠道功能决定静脉对口服、及给低氧患者辅助的糖皮质激素、因为淋巴细胞的裂解会先加重气体交换、及“不要安静地插管、要盯着血氧下降”的规则——[[microbiology/antimicrobials]]、[[respiratory/gas-exchange]]、[[emergency-critical-care/airway-ventilation]]；抗逆转录病毒治疗之问——通常在抗生素开始之后两周内开始、对中枢共感染在权衡之下例外、及住院隔离与公共卫生的卫生——[[immunology/immunodeficiency]]；共诊断的检查——隐球菌抗原与弓形虫血清学、及为其他机会性微生物的胸部检查、及性病的筛查与肝炎血清学、及对隐匿的隐球菌与进行性白质脑病及淋巴瘤的中枢症状审计——[[nervous-system/neuroinflammation]]；及打开整个人生的路径——“新诊断伴进展期疾病”的路径、不带责备的依从性支持、及性伴通知与工作保险及病毒性肝炎的治疗、及那套让预防在若干年后可以停下的免疫恢复时间表——[[clinical-skills/communication]]、[[public-health/communicable-disease-control]]、[[infectious-diseases/stewardship-outbreaks]]，公共卫生的报告义务见[[public-health/communicable-disease-control]]。**

::: example 开始治疗之后的头痛 {#ex-crypto}
一名35岁新诊断HIV的患者、CD4为40、12天前开始抗逆转录病毒治疗；现在头痛逐步加重10天、伴发热、颈强与视物模糊；意识障碍、呕吐；腰穿的初压为40厘米水、脑脊液清亮、以淋巴细胞为主的细胞增多、糖低、隐球菌抗原高滴度阳性。
::: solution
**被早期免疫重建揭开的隐球菌脑膜脑炎——这个综合征的存在就是为了教时机的课（[[#def-opportunistic]]、[[nervous-system/neuroinflammation]]）：诱导的方案——脂质体两性霉素B加氟胞嘧啶、带治疗药物监测与肾功能及血细胞的监视、及积极的脑脊液压力管理——连续的腰穿或引流或分流、每天查头痛与视力及神经、因为在药物起效之前压力就会杀人并致盲——[[microbiology/antimicrobials]]、[[microbiology/fungi-parasites]]、[[renal/acute-kidney-injury]]、[[blood/haematopoiesis]]；反过来问的抗逆转录病毒治疗——先开始抗真菌治疗、并与感染科专家讨论是暂停还是继续、按严重度定时机、及氟康唑的巩固与维持马拉松、带肝与QT的监测、及以隐球菌抗原趋势做复发监测——[[pharmacology/adverse-reactions]]、[[cardiovascular/arrhythmias]]；中枢之外的巡视——血培养、及肺与前列腺及皮肤的隐球菌、及引流的决定、及威胁视力的疾病与颅高压相关视盘水肿的眼科急诊——[[clinical-skills/medical-imaging]]、[[nervous-system/sensory-systems]]；及预后的诚实——神经认知的后遗与耳聋及失明及分流依赖、及在免疫恢复之前终生的复发阈值、及关于一种“可治但致命”的感染与家属的沟通——[[clinical-skills/communication]]、[[nervous-system/dementia-neurodegeneration]]，神经认知见[[nervous-system/neuroinflammation]]。**
:::

::: example 侵犯之后的那个周末 {#ex-pep}
一名23岁女性在周日早上来到急诊、距被陌生人性侵20小时；她惊魂未定但血流动力学正常、并问在暂时不报警的情况下“能不能预防HIV”。
::: solution
**暴露后预防是一个时间关键的紧急治疗、不是一个政策问题（[[#def-diagnosis]]、[[#def-virology]]）：时钟——当暴露可能具传染性时立即提供暴露后预防、在72小时内开始、用首选的以替诺福韦为基础加整合酶抑制剂的28天疗程、并且现在就给第一剂、而不是推到周一的门诊、及那个“已知测不到的源意味着通常无需暴露后预防”的源状态逻辑、及本地方案对病毒载量未知时的诚实；绝不能为一个药而牺牲的并行照护——性侵犯转诊中心的路径、及紧急避孕、及乙肝疫苗（必要时加免疫球蛋白）、及HIV检测的提供而非强制、及性病的推定覆盖、及伤口处理、及未成年人保护与家庭暴力的风险评估、及独立的性暴力倡导的提议——[[obstetrics-gynaecology/contraception-fertility]]、[[public-health/vaccination-programmes]]、[[infectious-diseases/sexually-transmitted-infections]]、[[clinical-skills/communication]]；后续的落实——对一个在危机中开始的28天疗程的依从性支持、及按间隔重复HIV检测、及肝肾的毒性检查、及漏服一剂怎么办、及就与警方联络的边界明确解释保密——[[pharmacology/adverse-reactions]]、[[medical-ethics-law/confidentiality]]、[[clinical-skills/records-handover]]；及那长长的阴影——创伤后应激的筛查与随访、及“暴露后预防高度有效但并非绝对”的安慰、及她关于是否报案的选择仍属于她——[[psychiatry/anxiety-disorders]]、[[psychiatry/lifespan-psychiatry]]、[[medical-ethics-law/consent-capacity]]。**

::: example 口腔的病变与体重下降 {#ex-kaposi}
一名HIV状态不明的45岁患者、两个月体重下降、发热与腿肿、上腭与小腿有紫红色的斑片；胸片见结节与胸腔积液；CD4为90、病毒载量120万；上腭活检证实人类疱疹病毒8阳性的梭形细胞病变。
::: solution
**播散性卡波西肉瘤作为艾滋病定义性的表现、伴淋巴水肿及内脏及肺累及（[[#def-opportunistic]]、卡波西的一行见[[musculoskeletal/skin-cancer]]）：分期与严重度——胸腹盆的断层、及消化道出血与梗阻及积液的评估、及那个“需要抗肿瘤治疗而不只是抗逆转录病毒治疗”的肺性卡波西的危险信号、及水肿的浸润机制——[[clinical-skills/medical-imaging]]、[[respiratory/lung-cancer-pleura]]；双重治疗——对局限的皮肤疾病把开始抗逆转录病毒治疗作为主要治疗、而对巨块的内脏或进展的疾病按肿瘤科加多柔比星脂质体或紫杉醇、带免疫重建加剧的咨询与共感染的筛查、及人类疱疹病毒8的淋巴增殖邻居：多中心型Castleman病与原发渗出性淋巴瘤——[[blood/lymphoma-myeloma]]、[[immunology/immunodeficiency]]；决定尊严的症状层——疼痛、与溃疡病变的院内感染、及淋巴水肿的加压与伤口护理、及关于容貌与性影响的谈话、及对毁容病变的姑息放疗——[[geriatrics-palliative/symptom-control]]、[[musculoskeletal/skin]]、[[clinical-skills/communication]]；及处在两个时代之间的预后谈话——现代的抗逆转录病毒治疗加化疗让播散性卡波西对许多人都成为可控、同时承认这个诊断曾意味着数周的那个时代——一个把希望校准到证据上的定框——[[public-health/health-systems-economics]]、[[clinical-skills/communication]]。**

## 与HIV共同生活

::: definition 非艾滋病的共病、妊娠与日常实务 {#def-longterm}
**与HIV共同衰老的议程（慢性免疫激活与炎症性衰老、带加速的心血管疾病、及对选定风险者使用他汀的论证、及早期使用富马酸替诺福韦二吡呋酯造成的骨丢失、及骨折风险经济学、及替诺福韦的肾与遗留的茚地那韦结晶、及代谢与体重及非核苷与整合酶时代的血脂与糖尿病的变化、及尽管病毒抑制仍存在的HIV相关神经认知障碍、带抑郁与睡眠及教育的邻近、及超出艾滋病定义性肿瘤那套之外的癌症风险——[[cardiovascular/hypertension]]、[[cardiovascular/coronary-artery-disease]]、[[endocrine/bone-calcium]]、[[renal/chronic-kidney-disease]]、[[endocrine/diabetes-complications]]、[[nervous-system/dementia-neurodegeneration]]、[[psychiatry/mood-disorders]]、[[public-health/screening]]）；作为慢性病的共感染（乙肝：以替诺福韦为基础的双重活性方案、及停药时的复燃、及治愈的搜寻、及丙肝的直接抗病毒治愈时代、及“人人皆治”的策略与再感染风险、及结核：HIV感染者治疗潜伏结核的节奏、及性传播感染的再感染筛查节奏——[[microbiology/viruses]]、[[gastrointestinal/liver-disease]]、[[infectious-diseases/tuberculosis]]、[[infectious-diseases/sexually-transmitted-infections]]）；妊娠与家庭（多替拉韦的神经管信号及其后续的安心、与现行的推荐、及胎盘的转移与母婴传播预防的叠层、及在替代品可接受且安全时避免哺乳、及那个围产感染青少年的依从性与披露及性健康的发展——[[obstetrics-gynaecology/pregnancy-complications]]、[[obstetrics-gynaecology/contraception-fertility]]、[[obstetrics-gynaecology/pregnancy-antenatal]]、[[paediatrics/adolescent-health]]、[[paediatrics/safeguarding]]，披露支持的邻近见[[clinical-skills/communication]]）；及日常医学的一层（药物相互作用：利福霉素与抗癫痫药及麦角及美沙酮与丁丙诺啡及质子泵抑制剂、及二价阳离子与整合酶抑制剂的吸收陷阱、及增效剂与激素避孕的药代动力学相互作用、及依从性与漏服一剂的规则、及药物辅助的性侵犯与物质使用及心理健康及污名、及市区诊所候诊室里决定上述药理能否真正发生的问题——[[pharmacology/adverse-reactions]]、[[pharmacology/patient-variation]]、[[psychiatry/substance-use]]、[[psychiatry/mood-disorders]]、[[public-health/determinants-inequalities]]）。**

## 当诊断来迟：进展期HIV的临床解剖

晚诊者需要的不只有同情、还有一张清单、因为疾病会成簇、而顺序的决策会成倍增加。在CD4低于100的那一天：开始复方磺胺预防肺孢子菌与弓形虫、除非已在治疗其中之一；在极低计数时筛查血清隐球菌抗原、并对抗原血症预先治疗以预防脑膜炎；检查眼底并专门询问视觉症状、以发现巨细胞病毒性视网膜炎；检查口腔、皮肤与淋巴结、以发现卡波西肉瘤；并采集一段把意识障碍、头痛与定位症状当作急症的神经病史、它们各自在[[nervous-system/neuroinflammation]]中有一章。在头两周内：以一段按相互作用与中枢穿透选择的方案开始抗逆转录病毒治疗、安排结核症状筛查、并在有指征时治疗潜伏感染、并展开那段按CD4决定活疫苗时机的接种谈话（[[public-health/vaccination-programmes]]）。在头三个月：重复性病筛查、对发现的乙肝与丙肝进入治疗、复审肾与骨及代谢的基线、并且——最常被跳过的一项——询问情绪与住房及收入及安全、以及这个诊断会影响到的人、因为进展期HIV常常是一个带病毒原因的社会危机、而不是相反（[[psychiatry/mood-disorders]]、[[public-health/determinants-inequalities]]、[[clinical-skills/records-handover]]）。这一纪律的回报可以测量：预防避免了第一次机会性事件、早期治疗在数月内恢复免疫的阶梯、而那个在第一年中病毒抑制并存活下来的患者、日益面对的是与其他人相同的衰老议程。

## 两种公共卫生

HIV在不同地理上的表现不同、而只读过其中一种的临床医师在另一种里会看得很糟。在高收入地区、流行集中在关键人群——与男性发生性行为的男性、跨性别者、注射毒品者、性工作者、及来自高流行地区的移民——工作是定点的检测、为持续风险者提供暴露前预防、诊断后的快速衔接、以及对使人远离照护的污名与刑事法律环境的持续关注。在南非与东非的高负担地区、流行是普遍型的、治疗队列极为庞大、而胜利——母婴传播接近消除、预期寿命曲线的恢复——既是物流的胜利也是药理学的胜利、而失败则来自供应链与人力及冲突。两种公共卫生如今共享同一地平线：可能把依从性从每日的秘密变成诊所记忆之中一件往事的长效治疗、及一个以其“治疗后控制”的病例报告作为灯塔而非蓝图的治愈研究议程。对任何阅读本章的人、临床的含义是一致的：熟悉本地的流行病学、把本地的检测与暴露前预防路径记成电话号码、并把预防的处方与治疗视为同一个专科、因为在这个领域里两张处方共享一间诊所、一份记录与一个结局。

::: history
**HIV的四十年医学与社会之镜：识别的弧线——年轻男性中肺孢子菌与卡波西肉瘤的病例系列、及免疫崩塌的聚集、然后是两个团队的分离工作与其命名之战、及患者行动主义的爆发、改写了试验与药物可及性治理的平行治疗与平行审批路径——[[medical-ethics-law/research-ethics]]、[[epidemiology-ebm/randomised-trials]]；单药治疗的错误时代、与把艾滋病从死刑变成慢性病的联合治疗革命、及它所发明的依从性科学——[[pharmacology/dosing-principles]]；治疗可及性的战斗——南非的治疗倡导与专利法的抗辩、及让三药治疗在政策上虽不总在实践中成为全球权利的基金与全球基金的建立——[[public-health/global-health]]、[[medical-ethics-law/justice-resources]]；“检测即治疗”与“测不到等于传不了”的证据规划——早期治疗的随机试验——[[epidemiology-ebm/randomised-trials]]、[[public-health/prevention-promotion]]；及那本医学没有造成、也无法用处方开掉的污名账簿——长效的衣壳抑制剂、与每月或每两月的口服及注射选项、让依从性成为一个不同于“在充满敌意的门口吞下九片药”的问题——[[public-health/determinants-inequalities]]、[[pharmacology/drug-development-prescribing]]。**
:::

::: exercise 处理矛盾性的发热 {level=2}
一名初始CD4为30的肺结核患者、在成功抗逆转录病毒治疗八周后、本已好转，此刻出现高热、浸润加重与纵隔淋巴结增大；病毒载量已下降2个对数；痰的核酸扩增检测现已阴性；他无低氧。
::: solution
**结核相关的免疫重建炎症反应综合征是首要诊断、而陷阱是停用抗逆转录病毒治疗或去追逐耐药（[[#def-opportunistic]]、[[infectious-diseases/tuberculosis]]）：重述“结核治疗正在起效、这是免疫学的”——定义的要点：初始好转后的矛盾性加重、带病毒载量的快速下降、并排除治疗失败与新的感染、及那个“免疫重建炎症反应综合征与良好的病毒学应答相关”的证据——[[clinical-skills/clinical-reasoning]]；排除其他诊断的检查——为耐药与再感染的培养与药敏、及淋巴瘤与巨细胞病毒及鸟胞内分枝杆菌及肺孢子菌及药物热、及对结核药物的依从性与呕吐造成的吸收不良、及妊娠与肾脏的背景——[[microbiology/laboratory-diagnosis]]、[[blood/lymphoma-myeloma]]；处理——继续抗逆转录病毒治疗与抗结核治疗、对中重度的免疫重建炎症反应综合征用非甾体或糖皮质激素、带激素减量的计划、并想清楚感染的覆盖、以及“不要永远加抗生素”的反射——[[microbiology/antimicrobials]]、[[endocrine/adrenal]]；及后续的落实——为患者写下免疫重建的解释、好让他继续吃那种“让他更难受”的药、及监测气道与淋巴结的压迫罕见但危险——[[clinical-skills/communication]]、[[clinical-skills/records-handover]]。**
:::

::: exercise 保守秘密还是不说 {level=2}
一名HIV阳性的男性拒绝告诉他的伴侣；他17岁的儿子住在家中、有哮喘、独自来你的门诊做喘息复审、并提到“我爸爸从不告诉我们事情”。你做什么、为什么？
::: solution
**保密的核心（[[#def-longterm]]、[[medical-ethics-law/confidentiality]]）：这位成年患者的HIV信息不属于你、不该被披露、而儿子的诊室不是一个后门——而这次接诊仍欠他一些东西：关于性与生殖健康及检测服务的普遍指引、及“HIV是一种可治疗的慢性病”这一事实、既不证实也不否认任何事——[[clinical-skills/communication]]、[[paediatrics/adolescent-health]]；确实存在的责任是面向有风险的成年人——探索患者的障碍与恐惧、通过专科服务提供有支持的性伴通知、并把这一提议记录在案、及向当局而非向家属披露的公共卫生报告规则、及那个例外情形的覆盖：它要求可识别的人、严重的伤害、与相称性、以及上级与法律的意见、而不是临床上的烦躁——[[public-health/communicable-disease-control]]、[[medical-ethics-law/ethical-principles]]、[[medical-ethics-law/professionalism-regulation]]；这里真正属于此地的儿童保护核查——对儿子福祉与任何家庭紧张按其自身的依据评估、而那位可能怀孕的女儿或妻子是另一条通知路径——[[paediatrics/safeguarding]]、[[obstetrics-gynaecology/pregnancy-antenatal]]；及系统的回答——性伴通知服务与同伴支持及伴侣共同检测的存在、就是为了让这场谈话能更早发生、而不让急诊科去继承它——[[public-health/health-systems-economics]]、[[infectious-diseases/sexually-transmitted-infections]]。**

::: summary
- HIV在数年间摧毁肠道与全身的CD4免疫；整合前病毒的储库使治疗成为终生、而治愈是研究的远景。
- 第四代检测加针对急性可疑的病毒核糖核酸；广泛地提供检测，因为在今天的艾滋病中起决定作用的是晚诊、而不是病毒学。
- 在同一周开始有效的、以整合酶抑制剂为基础的治疗；监测病毒载量、并预期“测不到等于传不了”的谈话本身就是一次治疗谈话。
- 机会性疾病沿着一架CD4的阶梯下行——肺孢子菌、隐球菌、弓形虫、巨细胞病毒、结核、鸟胞内分枝杆菌、卡波西与淋巴瘤——每一个都有名字明确的治疗、预防的阈值、与免疫重建时机的陷阱。
- 与HIV共同衰老是心血管与骨及肾及代谢及神经认知及肿瘤及心理的照护、由一个懂相互作用的处方者交付。
- 妊娠、披露、物质使用、心理健康与污名都是依从性的变量；忽视它们的诊所会让药理学失败。
:::

## 练习

::: exercise 解读窗口期 {level=1}
一名患者在无保护的性接触后第9天要求做HIV检测、接触期间他此刻感到不适；全科医生在考虑等6周。解释正确的检测与时机。
::: solution
**有症状的近期暴露现在就需要病毒核糖核酸（[[#def-diagnosis]]、[[microbiology/laboratory-diagnosis]]）：急性的血清转换病常常是非特异的、而第四代的联合检测在头两周仍可能是阴性的——所以要送HIV病毒载量或核酸扩增、加上联合检测、并在窗口期结束时复查联合检测、并解释第9天的阴性几乎什么也排除不了——以及除非指导如此、不要在专科方案之外开始经验的抗逆转录病毒治疗；而那个真正的问题是“是否还在72小时内提供暴露后预防”——暴露后预防的路径在此处与[[infectious-diseases/sexually-transmitted-infections]]一章；及咨询与安全网——预约好的随访、窗口期内的传播预防、对伴侣的支持、以及时刻到来时的复测——[[clinical-skills/communication]]、[[clinical-skills/records-handover]]。**
:::

::: exercise 选择首个方案 {level=1}
给出一名28岁、CD4为520、肾小球滤过率118、乙肝阴性、希望今晚就开始了的患者，其现代默认方案的架构与处方前的核查。
::: solution
**架构——两个核苷（酸）的主干加一个整合酶抑制剂——丙酚替诺福韦或替诺福韦、加恩曲他滨或拉米夫定是常见的当日默认——[[#def-diagnosis]]、[[pharmacology/dosing-principles]]；核查——耐药检测出结果后按其调整、及乙肝的状态、因为主干通常也在治疗乙肝、而停药可能引发复燃、及替诺福韦盐型选择的肾与骨、及药物相互作用：二价阳离子与利福霉素及抗癫痫药、及避孕与妊娠的计划、及若用阿巴卡韦则查HLA-B*5701、及依从性与储存及隐私的谈话——[[gastrointestinal/liver-disease]]、[[renal/chronic-kidney-disease]]、[[endocrine/bone-calcium]]、[[obstetrics-gynaecology/contraception-fertility]]、[[pharmacology/adverse-reactions]]；及随访的计划——按间隔的病毒载量、及最初一至两年的CD4、及“测不到等于传不了”的日期与它何时成立、及接种与性病及筛查的日历——[[public-health/vaccination-programmes]]、[[infectious-diseases/sexually-transmitted-infections]]。**

::: exercise 安排治疗的时机 {level=2}
对隐球菌性脑膜炎、结核性脑膜炎、CD4为60的肺结核、及巨细胞病毒性视网膜炎，分别给出抗逆转录病毒治疗的时机逻辑与理由。
::: solution
**那张时机表（[[#def-opportunistic]]）：隐球菌性脑膜炎——推迟数周、因为试验中早期治疗增加了死亡率、而中枢的免疫重建炎症反应是毁灭性的、先治疗并把压力降下来——[[nervous-system/neuroinflammation]]；结核性脑膜炎——同样的谨慎、数周、用同一个免疫重建的论证——[[infectious-diseases/tuberculosis]]；CD4低于50的肺结核——利福霉素与整合酶抑制剂的剂量调整、及对免疫重建的警觉；巨细胞病毒性视网膜炎——在全身治疗开始后尽早治疗、带那个免疫恢复性葡萄膜炎的激素之问、及眼科的共同负责——[[nervous-system/sensory-systems]]；共同的规则——除非危及生命，绝不因免疫重建而停用抗逆转录病毒治疗，治疗微生物、并对选定的综合征考虑激素——[[immunology/immunodeficiency]]、激素的逻辑见[[endocrine/adrenal]]。**
:::

::: exercise 绕开相互作用来处方 {level=2}
一名用依非韦伦为基础方案的女性要求复方口服避孕药；另一名用多替拉韦者在服碳酸钙与奥美拉唑；第三名因结核需要利福平。逐一解决。
::: solution
**相互作用的三联（[[#def-longterm]]、CYP与转运体的逻辑见[[pharmacology/drug-receptor]]）：依非韦伦是一个CYP诱导剂、会降低避孕药激素的水平——按感染科的意见使用合适的方法与剂量调整、或换一个方案、并做好紧急避孕的教育——[[obstetrics-gynaecology/contraception-fertility]]；多替拉韦被钙与铁及镁及抗酸剂螯合——按指导把服药间隔数小时或随餐服用、而质子泵抑制剂影响阿扎那韦与奈非那韦、对多替拉韦影响不大、并把非处方药的清单记录在病历里——[[pharmacology/absorption-distribution]]、[[gastrointestinal/oesophagus-stomach]]；利福霉素：每日两次的多替拉韦、或对特定增强型蛋白酶抑制剂的调整、或以利福布汀替换的策略、及利福霉素对避孕药与泼尼松龙水平的影响——[[infectious-diseases/tuberculosis]]、[[microbiology/antimicrobials]]。**

::: exercise 处理妊娠病例 {level=2}
一名26岁、孕11周的孕妇建立产科档案、被发现HIV阳性、病毒载量22000、未接受任何治疗。为头两周的照护建立结构。
::: solution
**同一周内做完所有事（[[#def-longterm]]、[[obstetrics-gynaecology/pregnancy-complications]]）：确证并分期——CD4与耐药及肝炎及性病及弓形虫血清学、并立即开始以妊娠期首选方案优化的抗逆转录病毒治疗——现在推荐以多替拉韦为基础、配叶酸、并把旧的神经管信号放回语境、及以替诺福韦加恩曲他滨或拉米夫定作为主干——[[obstetrics-gynaecology/pregnancy-antenatal]]、[[pharmacology/patient-variation]]；多学科的包——HIV与产科与助产及新生儿及儿科的团队、及伴侣的检测与支持、及带着权益意识去问家庭暴力与住房及身份状态、及铁与维生素D及接种的复审——[[public-health/determinants-inequalities]]、[[public-health/vaccination-programmes]]；分娩与喂养计划的路径——整个孕期的病毒载量监测、及按本地指导决定分娩方式与喂养、及婴儿的预防与检测时间表——[[paediatrics/newborn]]、[[paediatrics/immunisation]]；及这次接诊的心理急救——“治疗后母婴传播接近于零”这一好消息的现实、以及那个决定她是否会回来的“这不是你的错”的语气——[[clinical-skills/communication]]、[[psychiatry/anxiety-disorders]]。**

## 继续深入

用一段话概括感染性疾病的思维：按来源、途径、宿主与时间思考。在给综合征命名之前先确定来源；问暴露史允许什么、以及本地的耐药地图让什么变得可能；一切都按站在你面前的那个宿主来调整；并把时钟当作一种药——脓毒症与心内膜炎及脑膜炎的结局是小时数的函数。然后用这个专科的两种失败模式审计自己：在那些不典型的呈现继续演变时锚定在第一个可信的微生物上、以及永远不降阶梯——那个本该在第三天发生的窄谱转换没有发生。两种失败都能靠一个习惯治好：在每一次复审时重新问一遍，昨天的病史说了什么、而今天它不再说什么。
