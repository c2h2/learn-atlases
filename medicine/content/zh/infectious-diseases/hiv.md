1981年，一种新的疾病开始夺去原本健康的年轻成人的生命。此后十五年间，HIV诊断通常意味着大约十年内死亡。今天，早期诊断并得到良好治疗的人可以期望接近正常的寿命，而病毒被治疗抑制的人不会把HIV传给性伴。医学中很少有如此巨大的变化。

这场流行并未结束。据联合国艾滋病规划署（UNAIDS）估计，2024年全球约有4080万人感染HIV，130万人新感染，63万人死于HIV相关原因，其中大多数在撒哈拉以南非洲，而且大多是因为诊断太晚或未能坚持治疗。在英国这样的国家，主要问题是诊断延迟、污名化，以及日益老龄化的HIV感染者群体的长期健康。

本章介绍病毒及其生命周期、传播与自然史、诊断、抗逆转录病毒治疗、晚期疾病的机会性感染以及预防。英国的做法遵循英国HIV协会（BHIVA）和英国性健康与HIV协会（BASHH）的指南；全球做法遵循WHO。药物选择以原则形式给出：具体方案由HIV专科服务按现行指南制定。

## 病毒及其生命周期

::: definition HIV及其复制周期 {#def-virology}
**人类免疫缺陷病毒（HIV）**是逆转录病毒科慢病毒属的有包膜RNA病毒。**HIV-1**引起全球几乎所有的感染；**HIV-2**主要见于西非，传播性较弱，进展较慢，并对某些药物天然耐药。每个病毒颗粒携带两份约9700个碱基的单链RNA基因组，以及三种病毒酶：**逆转录酶**、**整合酶**和**蛋白酶**。

复制周期分七步，每一步都是药物靶点：

1. **吸附**：包膜糖蛋白gp120与辅助性T细胞、巨噬细胞和树突状细胞上的**CD4**分子结合。
2. **结合辅助受体**：gp120随后与趋化因子辅助受体**CCR5**（大多数被传播的病毒）或**CXCR4**（常见于感染后期）结合。
3. **融合**：gp41驱动病毒膜与细胞膜融合，衣壳进入胞质。
4. **逆转录**：逆转录酶把RNA基因组复制成双链DNA。它没有校对功能，错误频发。
5. **整合**：整合酶把病毒DNA插入宿主染色体，成为**前病毒**，在细胞的整个生命期中持续存在。
6. **转录与翻译**：宿主的机器合成病毒RNA和长的多聚蛋白。
7. **装配、出芽与成熟**：新的病毒颗粒从细胞膜出芽，蛋白酶把多聚蛋白切割成有功能的组分；没有这一步，病毒颗粒就没有感染性。
:::

::: proof
**CD4计数为何下降，治疗为何须终身。** 感染最初数周，病毒呈爆发式复制，尤其是在肠相关淋巴组织中——体内大部分记忆性CD4 T细胞都在那里。其中许多在数周内被破坏。此后，CD4细胞因病毒直接杀伤、顿挫感染细胞的炎症性死亡、细胞毒性T细胞的杀伤以及驱使细胞耗竭的慢性免疫激活而持续丢失。骨髓和胸腺跟不上，在未治疗的情况下，血液CD4计数平均每年下降约50–100个/µL，个体差异很大。

少数被感染的细胞是**静息记忆性CD4 T细胞**。在这些细胞中前病毒已经整合但处于沉默状态，因此细胞不产生病毒，免疫系统和药物（只作用于正在复制的病毒）都看不见它。这个**潜伏库**衰减极其缓慢，半衰期以年计。一旦停止治疗，病毒会从中重新出现，通常在数周之内。这就是为什么抗逆转录病毒治疗能控制HIV却不能治愈它。
:::

## 传播与自然史

HIV通过**性接触**、**血液**（共用注射器具、输入未经筛查的血液、针刺伤）以及在妊娠、分娩或哺乳期间**由母亲传给孩子**而传播。它不会通过接吻、共用餐具、蚊虫叮咬或一般社交接触传播。

来自未经治疗的感染源的单次暴露风险虽低，但不可忽视。美国CDC的估计为：接受性肛交约1.4%，注射吸毒共用针头约0.6%，针刺伤约0.2%–0.3%，接受性阴道性交约0.1%。若不加干预，HIV感染母亲所生婴儿中有15%–45%会被感染。其他性传播感染、感染源病毒载量高以及急性感染都会增加风险。感染源接受治疗且病毒载量被抑制，则完全消除了性传播风险。

未经治疗的感染经历三个阶段：

- **急性（原发性）HIV感染**，暴露后2–4周：许多人出现类似传染性单核细胞增多症的疾病，有发热、咽痛、皮疹、淋巴结肿大、口腔溃疡，有时有无菌性脑膜炎。病毒载量极高，因此这是传染性最强的阶段，而抗体可能尚未能检出。
- **慢性无症状感染**，中位时间约十年：患者自觉良好，而CD4计数在下降。可出现带状疱疹、脂溢性皮炎、持续性淋巴结肿大、血小板减少和反复细菌性肺炎。
- **晚期疾病和艾滋病（AIDS）**：当CD4计数降至约200个/µL以下时出现机会性感染和肿瘤。WHO把成人**晚期HIV病**定义为CD4计数低于200个/µL或出现WHO临床3期或4期事件；所有五岁以下的HIV感染儿童均被视为晚期疾病。

## 诊断

::: definition HIV检测 {#def-diagnosis}
标准的实验室筛查试验是**第四代检测**，可同时检测HIV-1/2抗体和HIV-1 **p24抗原**。由于p24先于抗体出现，大多数感染在暴露后约四周即可检出；英国指南（BHIVA/BASHH/BIA，2020年）指出，在最后一次可能暴露后**45天**第四代检测阴性即可排除感染。只检测抗体的即时检测和自我检测窗口期较长，最长可达**90天**。

筛查试验有反应时，总是要在另一份标本上用不同的方法**确证**后才能作出诊断。诊断后的基线评估包括**CD4计数**（免疫状态）、**HIV RNA病毒载量**（复制情况）、**基因型耐药检测**、**HLA-B\*57:01**（用阿巴卡韦前）、乙型和丙型肝炎血清学、性传播感染筛查，以及CD4计数低时检查机会性感染。
:::

检测是通向其他一切的大门，而良好结局的主要障碍是诊断延迟。在英国，诊断时CD4计数低于350个/µL即为“晚诊”。减少晚诊的策略包括**选择退出式检测**（除非本人拒绝，否则常规检测）——英国国家医疗服务体系英格兰（NHS England）自2022年起在患病率极高地区的急诊科推行——以及对任何有**指征疾病**的人进行检测：指征疾病是在HIV感染者中更常见的疾病。例如结核病、任何性传播感染、乙型或丙型肝炎、淋巴瘤、宫颈癌或肛门癌、较年轻成人的带状疱疹、不明原因的体重下降或淋巴结肿大、类传染性单核细胞增多症样疾病、社区获得性肺炎、口腔念珠菌病和不明原因的血小板减少。

::: warning
**没有检测HIV之前，不要称之为传染性单核细胞增多症。** 急性HIV感染看起来像传染性单核细胞增多症：发热、咽痛、淋巴结肿大和皮疹。如果EB病毒检测阴性，或者此人近期有可能的暴露，就要用第四代检测检测HIV（如果第一次检测在窗口期内，则需复查）。在这一阶段诊断HIV，可以在潜伏库最小时开始治疗，并防止在传染性最强的几周内传播。
:::

## 抗逆转录病毒治疗

::: theorem 抗逆转录病毒治疗的原则 {#thm-art}
1. **人人治疗。** 建议所有HIV感染者接受抗逆转录病毒治疗（ART），无论CD4计数多少，一旦本人准备好就开始。
2. **联合用药。** 方案至少包含两种、通常三种完全有效的药物，一般来自至少两个类别。
3. **以抑制为目标。** 目标是病毒载量低于50拷贝/mL，通常在3–6个月内达到，并终身维持。
4. **检测不到 = 不具传染性（U=U）。** 病毒载量持续低于200拷贝/mL的人不会经性途径传播HIV。
:::

::: proof
**联合治疗为何能防止耐药。** 数字可以说明这一点。逆转录酶每复制一个碱基约出现$3 \times 10^{-5}$个错误。基因组约$9.7 \times 10^{3}$个碱基，每个复制周期每个基因组新突变的期望数为

$$
3 \times 10^{-5} \times 9.7 \times 10^{3} \approx 0.29,
$$

因此大约四分之一的新基因组至少带有一个突变。一个未经治疗的人每天产生约$10^{10}$个病毒颗粒。于是每一种可能的单碱基改变每天都会出现许多次；任何只需一个突变即可对某单一药物耐药的病毒，在治疗开始之前就已经存在。单药治疗会在数周内把它筛选出来，正如20世纪80年代末齐多夫定（zidovudine）单药治疗所显示的那样。

如果病毒必须同时携带两个或三个特定突变，而每个位点的概率约为$10^{-5}$量级，那么每个基因组出现这种病毒的概率约为$10^{-10}$至$10^{-15}$。当三种有效药物几乎完全抑制复制时，新基因组本身就很少产生，这种病毒出现的机会就微乎其微。联合治疗下的耐药主要来自**依从性不完全**——这使病毒在药物浓度不足以抑制它的情况下得以复制。
:::

START试验（2015年）解决了何时开始治疗的问题：与等到CD4计数降至350个/µL以下再治疗相比，立即开始ART使严重艾滋病事件和非艾滋病事件减少了一半以上。大多数人在诊断后数天至数周内开始治疗。

| 类别 | 举例 | 要点 |
|---|---|---|
| 核苷/核苷酸类逆转录酶抑制剂（NRTI） | 替诺福韦（tenofovir，TDF或TAF剂型）、恩曲他滨（emtricitabine）、拉米夫定（lamivudine）、阿巴卡韦（abacavir） | 大多数方案的骨干。替诺福韦和恩曲他滨/拉米夫定也能治疗乙型肝炎。阿巴卡韦在携带HLA-B\*57:01者中引起严重超敏反应。TDF可影响肾脏和骨密度 |
| 非核苷类逆转录酶抑制剂（NNRTI） | 依非韦伦（efavirenz）、利匹韦林（rilpivirine）、多拉韦林（doravirine） | 单个突变即可导致高水平耐药。依非韦伦有神经精神方面的副作用。利匹韦林需要胃酸才能吸收 |
| 整合酶链转移抑制剂（INSTI） | 多替拉韦（dolutegravir）、比克替拉韦（bictegravir）、卡博特韦（cabotegravir） | 强效、耐受性好、耐药屏障高（多替拉韦、比克替拉韦）。抗酸药、铁剂和钙剂会减少其吸收。有体重增加的报道 |
| 蛋白酶抑制剂（PI） | 达芦那韦（darunavir）、阿扎那韦（atazanavir） | 需与药代动力学**增强剂**（利托那韦（ritonavir）或考比司他（cobicistat））同服，增强剂抑制CYP3A4，引起许多药物相互作用。耐药屏障高 |
| 进入抑制剂及其他 | 马拉维若（maraviroc，CCR5拮抗剂）、福替沙韦（fostemsavir，吸附抑制剂）、来那卡帕韦（lenacapavir，衣壳抑制剂） | 主要用于有治疗经历者。长效来那卡帕韦也用于预防 |

截至2026年，BHIVA和WHO指南建议大多数人以**两种NRTI加一种整合酶抑制剂**（如多替拉韦或比克替拉韦）开始治疗。WHO推荐的成人首选一线方案是每日一片的富马酸替诺福韦二吡呋酯、拉米夫定和多替拉韦复合片。两药方案（例如多替拉韦加拉米夫定）以及每两个月注射一次的长效卡博特韦加利匹韦林，是特定人群的选择。开始治疗后的监测包括大约第1个月和第3个月测病毒载量，抑制后每6–12个月一次，并根据所用药物检查肾功能等。治疗中经确认的病毒载量高于200拷贝/mL即为**病毒学失败**，需要评估依从性、药物相互作用和耐药情况。

::: warning
**含增强剂的方案与许多常用药物相互作用。** 利托那韦和考比司他强烈抑制CYP3A4。此时吸入或注射的氟替卡松（fluticasone）或曲安奈德（triamcinolone）会蓄积，引起**医源性库欣综合征**伴肾上腺抑制；辛伐他汀（simvastatin）可引起横纹肌溶解；某些镇静药变得危险。利福平（rifampicin）、卡马西平（carbamazepine）和圣约翰草则相反：它们诱导代谢，可使抗逆转录病毒药物浓度降低到足以导致治疗失败。每一张新处方，包括非处方药和草药制品，都要用HIV药物相互作用资源进行核查。
:::

::: example 耐药的算术 {#ex-mutation}
采用每个碱基$3 \times 10^{-5}$的逆转录酶错误率：(a) 估算平均需要复制多少份基因组，才能在某一位点产生一个特定的单碱基改变；(b) 解释这对一个每天产生$10^{10}$个病毒颗粒的人意味着什么。
::: solution
(a) 一个特定的碱基可以突变为三种其他碱基中的一种，因此某一位点上某一特定改变的概率约为每份复制$3 \times 10^{-5}/3 = 10^{-5}$。平均约需要$10^{5}$份复制才能产生一次。

(b) 每天有$10^{10}$个新病毒颗粒，这一特定突变**每天**约出现$10^{10}/10^{5} = 10^{5}$次。因此，在未经治疗的人体内，任何单突变耐药都已预先存在。对于两个特定突变的组合，概率降至每份复制约$10^{-10}$，三个则约为$10^{-15}$：这已足够罕见，只要药物浓度保持充足，一旦三种药物把病毒产生几乎降为零，多重耐药病毒就极不可能出现。
:::

## 机会性感染

::: definition 机会性感染与CD4计数 {#def-opportunistic}
**机会性感染**是由在免疫功能正常者中很少致病的微生物所引起的感染。在HIV感染中，风险随CD4计数而变化：

| CD4计数（个/µL） | 典型疾病 |
|---|---|
| 任何水平 | 结核病、细菌性肺炎、带状疱疹、卡波西肉瘤、淋巴瘤（风险随CD4下降而升高） |
| 低于200 | 耶氏肺孢子菌（*Pneumocystis jirovecii*）肺炎（PCP）、食管念珠菌病、进行性多灶性白质脑病 |
| 低于100 | 脑弓形虫病、隐球菌性脑膜炎 |
| 低于50 | 巨细胞病毒视网膜炎、播散性鸟分枝杆菌复合群（*Mycobacterium avium* complex）感染 |

**一级预防**防止首次发病：CD4计数低于200个/µL者用复方磺胺甲噁唑（co-trimoxazole）预防PCP，在更低计数时也预防弓形虫病。在WHO指南中，CD4计数低于100个/µL（低于200时也可考虑）的人要筛查血液**隐球菌抗原**，以便通过抢先治疗预防脑膜炎。ART使CD4计数恢复到指南阈值以上后即停止预防。
:::

**卡波西肉瘤**由人类疱疹病毒8型引起，在皮肤、口腔、胃肠道和肺部形成紫色斑片、斑块或结节；单用ART常可使其消退，病变广泛时加用化疗。淋巴瘤、宫颈癌和肛门癌也更常见。

**免疫重建炎症综合征（IRIS）**是开始ART后出现的矛盾性恶化。随着免疫系统的恢复，它对早已存在的感染（例如结核、隐球菌或巨细胞病毒）发动炎症反应。起始CD4计数很低时最容易发生。机会性感染后开始ART的时机需要在IRIS风险和免疫功能进一步下降的风险之间权衡：对大多数感染（包括PCP和结核病），在两周内开始ART；对**隐球菌性**和**结核性脑膜炎**，由于颅内炎症很危险，推迟约四至八周。

::: example 气促和血氧下降 {#ex-pjp}
一名34岁男性干咳、低热和劳力性气促逐渐加重已三周。他有口腔鹅口疮。静息血氧饱和度95%，但爬一层楼后降至86%。胸片示双侧肺门周围淡薄模糊影。HIV检测阳性，CD4计数40个/µL；呼吸空气时动脉$P_a\mathrm{O_2}$为8.6 kPa。
::: solution
**诊断。** 亚急性干咳、劳力性血氧下降、肺门周围浸润和口腔念珠菌病，加上CD4计数低于200个/µL，强烈提示**耶氏肺孢子菌肺炎**。通过诱导痰或支气管肺泡灌洗液的PCR或免疫荧光确诊；血清β-D-葡聚糖通常升高。气胸是公认的并发症。

**治疗。** 一线治疗是大剂量复方磺胺甲噁唑，疗程21天。由于他的$P_a\mathrm{O_2}$低于9.3 kPa，应尽早给予**辅助性糖皮质激素**，因为在中重度病例中它能降低死亡率和机械通气的需要。不能使用复方磺胺甲噁唑的人有替代药物。

**随后。** 在两周内开始ART，之后服用复方磺胺甲噁唑预防，直到CD4计数恢复。应为他的性伴提供检测。本病例也显示了一个错失的机会：口腔鹅口疮和体重下降都是指征疾病，本应更早促使进行HIV检测。
:::
:::

::: example 不能缓解的头痛 {#ex-crypto}
一名29岁女性三年前从津巴布韦移居英国，头痛、恶心和视物模糊逐渐加重已两周。她新诊断HIV感染，CD4计数35个/µL。头颅CT正常。腰椎穿刺：初压38 cm H₂O，脑脊液白细胞12个/µL，蛋白轻度升高，葡萄糖正常低限；隐球菌抗原强阳性，墨汁染色可见有荚膜的酵母菌。
::: solution
**诊断**：由新型隐球菌（*Cryptococcus neoformans*）引起的**隐球菌性脑膜炎**，这是撒哈拉以南非洲HIV相关死亡的主要原因之一。脑脊液可以看起来几乎正常，因为能做出反应的白细胞太少。极高的**初压**解释了头痛和视物模糊，它本身也是死亡原因之一。

**诱导治疗**：WHO（2022年）推荐单次大剂量**两性霉素B脂质体（liposomal amphotericin B）**联合14天**氟胞嘧啶（flucytosine）**和**氟康唑（fluconazole）**，依据是AMBITION-cm试验，该试验显示此方案与较长疗程的两性霉素方案同样有效且副作用更少。没有两性霉素B脂质体时，使用其他以两性霉素为基础的联合方案。随后是巩固期和维持期氟康唑治疗。

**颅内压升高**通过反复治疗性腰椎穿刺处理，直至压力恢复正常；乙酰唑胺和糖皮质激素无效，糖皮质激素还有害。

**推迟ART**约四至六周：COAT试验发现在一至两周内开始ART死亡率更高，可能是由于脑内的IRIS。
:::
:::

## 预防与带HIV生活

::: definition HIV预防与长期照护 {#def-longterm}
**综合预防**同时使用多种方法：

- **治疗即预防**：能抑制病毒载量的ART可防止性传播（U=U）。HPTN 052试验（2011年）显示伴侣间关联传播减少96%，PARTNER系列研究在数万次无套性行为中未发现来自病毒已被抑制的伴侣的关联传播。
- **暴露前预防（PrEP）**：HIV阴性者在暴露前服用抗逆转录病毒药物。口服富马酸替诺福韦二吡呋酯加恩曲他滨，每日服用或（用于肛交）在性行为前后按需服用，按要求服用时非常有效。在试验中，每两个月注射一次的长效**卡博特韦**比口服PrEP更有效。每年注射两次的**来那卡帕韦**于2025年6月在美国获批用于PrEP，2025年7月获WHO推荐，2025年12月在英国获得许可；截至2026年，NHS的常规使用仍在评估中。
- **暴露后预防（PEP）**：在明显暴露后尽快开始为期28天的ART，最好在24小时内，最迟不超过72小时。
- **预防垂直传播**：产前检测、整个孕期的ART、根据病毒载量安排分娩方式，以及婴儿短程ART。在英国，这已使垂直传播率降至远低于1%。
- 安全套、无菌注射器具、经过筛查的血液以及治疗其他性传播感染。

对病毒已被抑制的HIV感染者，**长期照护**的重点是衰老相关疾病，这些疾病出现得更早、更常见：心血管疾病、肾脏和骨骼疾病、某些癌症，以及认知和精神健康问题。戒烟、血压和血脂管理、宫颈癌和肛门癌筛查、疫苗接种（CD4计数低于200个/µL时避免使用活疫苗）以及应对污名化的支持，都是常规照护的一部分。
:::

::: example 病房里的针刺伤 {#ex-pep}
一名护士被一根用于为已知HIV感染者采血的空心针深度刺伤。传播风险大约是多少？她需要PEP吗？如果该患者已接受ART且病毒载量检测不到两年，答案会如何改变？
::: solution
**急救处理**：鼓励伤口出血，用肥皂和流动水冲洗，不要擦洗或吸吮伤口，并立即向职业健康部门或急诊科报告。

**风险**：来自未经治疗感染源的经皮损伤约为0.3%（约1/300）；深部损伤、器械上可见血液以及曾插入静脉的针头风险更高。感染源的病毒载量是关键事实。

**如果感染源的病毒载量未知或可检出**：建议PEP：抗逆转录病毒联合用药（通常为两种NRTI加一种整合酶抑制剂），尽快开始，最好在一两个小时内，最迟不超过72小时，持续28天。她在基线时检测，窗口期后再次检测，并随访副作用和依从性。

**如果感染源的病毒载量经确认检测不到**：传播风险可以忽略，现行英国指南（BHIVA/BASHH，2021年）在这种情况下不推荐PEP。她仍需进行基线和随访检测，并报告这次损伤。每一次针刺伤都要单独评估乙型和丙型肝炎的风险。
:::
:::

::: history
1981年6月5日，美国CDC的《发病率与死亡率周报》（*Morbidity and Mortality Weekly Report*）描述了洛杉矶五名原本健康的年轻男同性恋者患肺孢子菌肺炎，报告者是迈克尔·戈特利布（Michael Gottlieb）等人。1983年，巴斯德研究所的弗朗索瓦丝·巴尔-西诺西（Françoise Barré-Sinoussi）和吕克·蒙塔尼耶（Luc Montagnier）分离出致病的逆转录病毒，这项工作于2008年获得诺贝尔奖；1984年，美国罗伯特·加洛（Robert Gallo）的团队证实它就是病因。1985年出现了用于筛查血液的抗体检测，1987年第一种抗逆转录病毒药物齐多夫定获得许可。单药治疗因耐药而失败。1996年，含蛋白酶抑制剂的联合治疗——借助何大一（David Ho）等人的病毒动力学研究——彻底改变了生存状况。由迈伦·科恩（Myron Cohen）领导的HPTN 052试验（2011年）证明治疗能预防传播，START试验（2015年）证明人人都能从立即治疗中获益。
:::

## 后续内容

原发性和继发性免疫缺陷见[[immunology/immunodeficiency]]，病毒本身见[[microbiology/viruses]]。HIV感染者的首要死因结核病见[[infectious-diseases/tuberculosis]]。其他性传播感染见[[infectious-diseases/sexually-transmitted-infections]]，其他免疫功能低下宿主的感染见[[infectious-diseases/immunocompromised-host]]。人群检测项目在[[public-health/screening]]中讨论。

::: summary
- HIV是一种逆转录病毒，借助CCR5或CXCR4感染带CD4的细胞，整合入宿主基因组并建立潜伏库，因此ART能控制但不能治愈它。
- 未经治疗的感染从急性血清转换期开始，经过多年无声的CD4下降，发展为CD4低于约200个/µL时伴机会性感染的晚期疾病。
- 第四代检测可检出抗体和p24抗原；暴露后45天检测阴性即可排除感染。有反应的结果总要确证。
- 建议人人接受ART，联合至少两种（通常三种）有效药物；通常以两种NRTI加一种整合酶抑制剂开始。目标是病毒载量低于50拷贝/mL。
- 联合治疗能防止耐药，因为需要同时具备多个突变的病毒极为罕见；耐药主要源于依从性差。
- 机会性感染随CD4计数而变化；复方磺胺甲噁唑和隐球菌抗原筛查能预防常见的致死性疾病。机会性感染后ART的时机要在IRIS与免疫功能持续下降之间权衡。
- 预防综合了U=U、PrEP、72小时内的PEP以及预防垂直传播。
:::

## 习题

::: exercise 计算对数下降 {level=1 check="round(10*log10(250000/50))/10"}
一名男性的病毒载量从治疗前的250,000拷贝/mL降至ART三个月后的50拷贝/mL。下降了多少个log₁₀单位？答案保留一位小数。
::: solution
$\log_{10}(250{,}000/50) = \log_{10}(5000) = 3.699 \approx 3.7$个log₁₀单位，即下降了5000倍以上。有效治疗第一个月内预期至少下降1个log₁₀。
:::
:::

::: exercise 窗口期 {level=1}
一名男性在与HIV感染状况不明的伴侣无套性行为20天后前来检测。实验室第四代检测阴性。你告诉他什么？何时应该复查？同一时间的抗体自我检测阴性，提供的信息更多还是更少？
::: solution
20天时他仍在窗口期内，因此第四代检测阴性不能排除感染。他应在暴露后**45天**复查；届时阴性即可排除HIV。只检测抗体的自我检测窗口期更长（最长90天），因此在20天时提供的信息更少。20天时已不能进行PEP，因为PEP必须在暴露后72小时内开始；应与他讨论今后的PrEP，并提供全面的性传播感染筛查。
:::
:::

::: exercise 低患病率人群中的检测 {level=1 check="round(100*0.002*0.999/(0.002*0.999 + 0.998*0.002))/100"}
一种HIV筛查试验的灵敏度为99.9%，特异度为99.8%。在患病率为0.2%的人群中使用。单次有反应结果的阳性预测值是多少？以小数形式给出，保留两位小数。
::: hint
在100,000人中，有多少人感染HIV且检测阳性？又有多少人未感染HIV但检测阳性？
:::
::: solution
每100,000人中：200人感染HIV，其中$200 \times 0.999 \approx 199.8$人检测阳性。99,800名未感染者中，$99{,}800 \times 0.002 = 199.6$人假阳性。

$$
\text{PPV} = \frac{0.002 \times 0.999}{0.002 \times 0.999 + 0.998 \times 0.002} = \frac{0.001998}{0.003994} \approx 0.50
$$

在这种情况下，有反应的筛查结果中只有约一半是真阳性，这就是为什么每个有反应的结果都要在第二份标本上用不同方法确证后才能诊断。
:::
:::

::: exercise 吸入剂与增强剂 {level=2}
一名52岁HIV感染男性服用利托那韦增强的达芦那韦加替诺福韦和恩曲他滨已六年。四个月前全科医生因哮喘给他开了吸入性氟替卡松。现在他满月脸、容易瘀青、腹部体重增加，并新出现高血压。解释发生了什么以及应如何处理。
::: solution
利托那韦强烈抑制代谢氟替卡松的酶**CYP3A4**。于是，即使是吸入的氟替卡松也会达到很高的全身浓度，引起**医源性库欣综合征**，伴下丘脑-垂体-肾上腺轴抑制。处理：与HIV团队讨论后，换用较少依赖CYP3A4的吸入性糖皮质激素（例如倍氯米松（beclometasone）），或改用不含增强剂的抗逆转录病毒方案。由于他自身的肾上腺功能已被抑制，不能简单地停用激素：他有发生**肾上腺危象**的风险，需要评估肾上腺功能，可能需要暂时使用生理剂量的糖皮质激素并遵守患病期间的用药规则。本病例说明了为什么对接受ART者的每一张新处方都必须核查相互作用。
:::
:::

::: exercise 并非传染性单核细胞增多症 {level=2}
一名24岁女性发热、咽痛一周，躯干有细小皮疹，颈部淋巴结肿大，有两个疼痛的口腔溃疡。EB病毒单斑试验阴性。肝酶轻度升高，血小板110 × 10⁹/L。给出鉴别诊断、关键检查，以及为什么现在诊断很重要。
::: solution
**鉴别诊断**：急性HIV感染、巨细胞病毒感染、早期EB病毒感染（单斑试验早期可能假阴性）、二期梅毒、链球菌性咽炎、弓形虫病和药物反应。口腔溃疡、皮疹和单斑试验阴性使排除**急性HIV**尤为重要。

**关键检查**：第四代HIV抗原/抗体检测（急性感染时即使抗体尚未出现，p24抗原通常也呈阳性），结果可疑时加测HIV RNA，同时做梅毒血清学检查。需要询问性生活史。

**为什么是现在**：急性感染时病毒载量非常高，因此这几周内传给伴侣的风险最高。早期开始ART可限制潜伏库的大小，保护免疫系统并防止进一步传播；对暴露在72小时内的伴侣可提供检测和PEP。
:::
:::

::: exercise 妊娠期HIV {level=2}
一名妇女在妊娠12周初次产检的血液检查中被发现感染HIV。CD4计数420个/µL，病毒载量35,000拷贝/mL。概述预防婴儿感染的照护原则。
::: solution
**应尽快开始ART**，采用已知在妊娠期安全有效的方案，目标是在分娩前很早就使病毒载量检测不到；孕期及约36周时监测病毒载量。**分娩方式**取决于足月前后的病毒载量：按英国指南，36周时病毒载量低于50拷贝/mL支持计划阴道分娩，400拷贝/mL或以上则建议计划剖宫产，病毒载量高于1000拷贝/mL或未知时在产程中静脉给予齐多夫定。**婴儿**接受短程抗逆转录病毒预防，并定期检测以确认未感染HIV。**喂养**：在英国，配方奶喂养可避免一切产后风险；对于病毒被完全抑制并选择母乳喂养的妇女，BHIVA指南在对母婴密切监测的前提下予以支持。应为她的伴侣和其他年长子女提供检测。经过这样的照护，垂直传播率远低于1%。
:::
:::

::: exercise 解读耐药报告 {level=3}
一名40岁男性服用富马酸替诺福韦二吡呋酯、恩曲他滨和依非韦伦已三年。他承认经常漏服。相隔一个月的两次病毒载量均为4500拷贝/mL。基因型检测显示逆转录酶M184V和K103N突变。解释这些结果并概述下一步处理。
::: hint
M184V影响拉米夫定和恩曲他滨；K103N影响第一代NNRTI。
:::
::: solution
**解释**：两次病毒载量高于200拷贝/mL，确认为**病毒学失败**。**M184V**导致对恩曲他滨和拉米夫定的高水平耐药（但它也降低病毒适应性，并使病毒对替诺福韦的敏感性略有增加）。**K103N**导致对依非韦伦和奈韦拉平（nevirapine）的高水平耐药，但单独存在时不影响多拉韦林或依曲韦林（etravirine）等较新的NNRTI。实际上，他一直在服用只有一种完全有效药物（替诺福韦）的方案，如果不做改变，很可能出现进一步的耐药。

**下一步**：先处理原因：了解漏服的原因（如依非韦伦引起的多梦等副作用、精神健康、住房、污名化、服药负担）并提供支持。核查药物相互作用。在耐药报告和专科意见指导下（常通过虚拟多学科门诊），制定含**至少两种完全有效药物**的新方案，通常包括多替拉韦或增强的达芦那韦等耐药屏障高的药物。在约第1个月和第3个月复查病毒载量，以确认再次抑制。
:::
:::

::: exercise HIV与结核病并存 {level=3}
一名33岁涂片阳性肺结核男性新诊断HIV感染，CD4计数60个/µL。他正在开始包括利福平在内的标准抗结核治疗。讨论：(a) 何时开始ART；(b) 主要的药物相互作用及其处理；(c) 之后数周内需要警惕的并发症。

(a) **时机**：应在抗结核治疗开始后约两周内开始ART，尤其是CD4计数如此低时，因为早期ART能降低晚期HIV患者的死亡率。例外是结核性脑膜炎，由于有颅内炎症的风险，ART要推迟数周。

(b) **相互作用**：利福平是CYP3A4和UGT1A1的强诱导剂。它降低多替拉韦的浓度，解决方法是在服用利福平期间及停药后两周内，把多替拉韦由每日一次改为每日两次。利福平不能与增强的蛋白酶抑制剂、比克替拉韦或长效卡博特韦/利匹韦林合用，这就是为什么方案要由结核病团队和HIV团队共同选择。

(c) **结核相关IRIS**：开始ART后数周内，随着免疫系统恢复，可出现发热、淋巴结增大、胸片加重或浆膜腔积液。必须与抗结核治疗失败、耐药或新的感染相鉴别；大多数病例继续两种治疗即可，中度病例用泼尼松龙（prednisolone）可减轻症状。对高风险者在开始ART时给予泼尼松龙也能减少IRIS。
