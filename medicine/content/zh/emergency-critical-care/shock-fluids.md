休克是氧输送无法满足细胞需求的状态；急性循环照护整个专科就是找出四台机器哪一台坏了（容量、泵、管道或阀门堵塞）、给对的第一升而不是接下来十升、并在乳酸写出讣告之前逆转灌注。**本章讲述休克生理学及其床旁测量（为何在一项试验中毛细血管再充盈击败中心静脉管、及乳酸为何是秒表不是评分）、液体之辩（晶体类型与平衡溶液时代、ROSE框架、及“早期目标导向治疗” 塌缩为个体化照护、液体反应性及其诚实的极限、作为被诊治的液体过负荷）、及按类型的复苏：带损伤控制与血制品算术的失血性休克、脓毒性休克的血管问题与升压药阶梯、心源性休克的残酷药理与装置接口、及梗阻性与内分泌模拟者。其两条口号：“液体是有剂量与毒性的药”，及“最好的液体是匹配你失去的那种、在停止也是一个计划时给出。”**

## 生理与测量

::: definition 休克：机制与床旁血流动力学 {#def-shock}
**机制：氧输送（心输出量乘含量的产物）对摄取与临界需求（厌氧阈值与乳酸——当摄取无法弥合差距时出现——这是乳酸真正唯一的含义：差距的标志，不是剂量的，也不是液体的），及四种失败模式：低血容量（丢失的容量——血、血浆、水、盐：出血与脱水与烧伤及第三间隙、及老年科无力肠与摄入不足的生理）、心源性（泵——梗死与心肌炎与瓣膜及填塞邻近地形及终末衰竭状态、冷而湿的画像其自身在下文）、分布性（管道扩张而渗漏——脓毒症与过敏与肾上腺危象与神经源性及药物过量血管麻痹、欺骗眼睛直到晚期收缩的暖休克）、及梗阻性（泵之前管道被堵——填塞与张力性气胸及大块栓塞、及罕见的心房黏液瘤与主动脉夹层冠脉开口表现）。临床测量的复兴：旧的监测时代（2001年Rivers方案的CVP与早期目标导向治疗组套）被更好的试验与更好的生理推翻（ProCESS与ARISE及ProMISe复制试验杀死了规程化的65%CVP与ScvO2仪式、而没杀死早期识别与抗生素及合适液体与升压药的根本美德、及ANDROMEDA-SHOCK使毛细血管再充盈时间——一个拇指和一块表——非劣于乳酸指导的复苏并对所有人更舒适）：现代床旁套装是脉压与再充盈时间及贝叶斯物理（心率除以收缩压大于0.8作为隐匿休克旗、及花纹评分与耳垂灌注侦探）、动态对静态液体反应性概念（CVP从未预测过任何东西、及呼吸变异与被动抬腿及小剂量液体挑战——向心脏问一个问题而不是测它的静息状态、及诚实的极限：反应性不是获益——给一个不需要液体的液体反应性患者液体就是液体过负荷被开出来的方式）、床旁超声作为循环分诊（自主呼吸患者仔细读取的下腔静脉塌陷性、四腔收缩质量、心包与胸腔与游离液体及肺滑动对彗星尾及无搏动——数分钟内站在填塞对低血容量对泵衰竭对栓塞一边——这是休克超声心动文献真正的进步、及“看复苏者的手臂”的下腔静脉与颈静脉生命体征）、及值得教的阶段（代偿的年轻人代偿然后崩溃然后骤停轨迹、血压正常而毛细血管死亡的隐匿休克、及不可逆休克概念被现代化为“长时间休克无救援造成内皮与线粒体损伤而液体随后加重它”——这是早期几分钟就是一切的深层理由）。考试爱而病房忽视的轨迹工具：休克中没人乳酸清除正常、而乳酸上升的没人正在改善——重复乳酸与重复临床检查才是监测仪、不是第一个数字。**
:::

## 液体

::: definition 液体治疗：类型、阶段与伤害 {#def-fluids}
**菜单及其证据：晶体（0.9%氯化钠的医源性高氯性酸中毒及其肾血管收缩信号——来自急诊试验信号、合起来把多数指南推向大容量复苏的平衡溶液（Hartmann与Plasma-Lyte型）伴诚实注记：酸中毒效应温和、死亡率差异不确定除肾脏信号外、而盐水仍属于脑与低氯碱中毒及钠特定情形——这是盐水对平衡的圣战不断压平的细微）、胶体（白蛋白的脓毒症时代信号在SAFE试验更早的“没有哪种到处都安全”结论之下存活、及羟乙基淀粉因监管禁令及肾与凝血病伤害的彻底死亡——这是一个月度风味药物30年的警世故事）、及替换匹配逻辑（血对血、溶液对盐水、糖对水、及任何手术日的“外科说盐水、麻醉说胶体、重症说都不要”会诊剧场）。阶段（到处在教的ROSE邻近框架）：复苏（挽救生命的快速剂量以恢复灌注、配一个叫做再评估的停止规则）、优化（缺口补充与液体反应性测试——不确定性是真实的）、治疗维持与药物载体及丢失替换悄悄运行、及带每小时毫升数与理由与停止时间的液体处方、及演变——2005年液体阳性的患者成为2020年代顺序器官衰竭会话的再复苏与负平衡患者（利尿与超滤证据成熟邻近的实践、及ARDS与AKI数据的30%正平衡——这就是为何一张有液体平衡行的病历表是一项临床仪器）。命名的伤害：没人称为错误的肺水肿（骨科病房在生理盐水中打盹的正平衡伴实为过度利尿的低血压被更多盐水处理、然后缺氧被更多盐水处理——这是每次审计都发现的医源性漂移环）、十升的组织水肿与伤口及肠及肾囊后果（腹腔间隔室综合征邻近的谱系末端）、晶体液复苏的稀释性凝血病（这就是为何出血规程说血制品早而盐水永不）、及错误溶液给错误患者的低钠与高氯及高钾化学（肝与心及肾及神经外科禁忌对、液体按共病选择表正确教授）。及一切治理：静脉液体管家运动指南三日复查规则及“每个静脉液体医嘱需要一个指征一个速率和一个停止复查”病历字段、及护理观察点滴还在跑——因为在一项医院过负荷调查中、第十袋最常见的原因是没人对第九袋做过决定。**
:::

## 各种复苏

::: definition 按类型的休克管理 {#def-types}
**失血性休克：年轻与年长者的失血性休克伴血管可定位而生理未知时代的教训（动脉瘤破裂与不可压迫躯干出血直至外科止血的容许性低血压平衡、及直接压迫与止血带及骨盆带及REBOA邻近机械止血拖延——其证据时代正在与自己争论、及酸中毒与低温及凝血病的致死三联、其解药是损伤控制外科生理温血与速度——这是外科领域从复苏侧接近）；大量输血规程（1:1:1或2血浆血小板红细胞的作战起源并经试验验证、及第一小时因子替代邻近凝血酶原复合物与纤维蛋白原浓缩物、及早给不晚给的氨甲环酸——三小时内或根本不给的CRASH-2时代与产后WOMAN试验时机、及黏弹性止血检测引导的替代规程——试验说安全并可能保存同种血小板、及血小板计数与纤维蛋白原与钙与pH及乳酸清除与温度的系列组合——这才是真正的麻醉重症记分板）；钙维持在正常与加温的血及抗凝逆转邻近药物特定规则（中毒与止血章详述）；脓毒性休克：血管麻痹治疗范式（“30 ml/kg然后升压药早”的指南、及试验时代的个体化伴仍未决的问题、因为动态评估胜过规程化容量、及去甲肾上腺素第一与血管加压素第二及多巴胺或肾上腺素用于心功能邻近阶梯、及难治升压药依赖表型的氢化可的松、及源头控制时钟——因为没有升压药能修好脓胸或死肠、及休克第一小时抗生素而不是分诊小时、及到针与分诊改革数字——这是感染章自己的、及维生素C与治疗血浆及为乳酸不是现象的碳酸氢钠——这是复苏时尚的墓地）。心源性休克：“冷而湿不是冷而干、暖而湿不是困惑”分类（Forrester与SCAI分期及心梗相关休克发生率萎缩而心衰加重休克增长的流行病学转变——这改变你见到谁）及其药理地理低血压用去甲肾上腺素伴心律失常警诫、及多巴酚丁胺或米力农正性肌力伴氧耗与低血压代价、及血压耐受时的后负荷降低、及机械支持阶梯（被IABP-SHOCK-II缩小的主动脉内球囊泵、及Impella与ECMO及外科与移植桥接决定——活跃的、依中心而定的争论、意味着在乳酸反驳之前早转诊）；及绝不可拿脓毒症组套代替针头的模拟者：带奇脉与淤血及超声三秒诊断的填塞、及按怀疑不按X线减压的张力性气胸、及肾上腺危象——激素停药者或被氢化可的松拉平的低血压或低钠高钾Addison、及带心动过缓低体温及诱因史的黏液水肿、及神经源性休克带温暖软瘫心动过缓截瘫及其液体然后升压药及其心动过缓用阿托品、及围产期、及过敏反应其肾上腺素是其章的第一句。**
:::

::: example 被给了九升的食管胃底静脉曲张出血者 {#ex-overload}
58岁酒精性肝硬化、呕血、血压84/50；院前与急诊团队在配血时给了4升盐水；到达时他缺氧有湿啰音、INR 2.4、Hb 68、腹张力高、仍在出血；病房计划写“更多液体保护肾”。
::: solution
**重排的失血性休克医学（[[#def-types]]、[[#def-fluids]]、[[gastrointestinal/liver-disease]]）：纠正——在出血性休克中晶体是一个带两种伤害的占位符（稀释他本来就没有的凝血因子、及对抗凝块和门脉压力的压迫再出血——这是“直至止血前的容许性低血压”逻辑、加上他现在已经有的肺水肿来自那四升——这就是大量输血而非大量盐水原则存在的原因）；重排——现在输血（O型阴性或紧急血型及1:1:1规程、及低水平的纤维蛋白原或冷沉淀、及按本地静脉曲张实践的氨甲环酸、及钙与温液体、及内脏血管收缩剂、及减少肝硬化出血再出血与死亡的抗生素预防——这是此场景最被忽视的药、及内镜时钟、及对未控制者的球囊压迫作为桥梁不是计划）；目的地——出血的肝硬化患者需要一个有内镜与放射TIPS及外科能撑住它的单位、及早与ICU及移植中心谈话因为他的Child与MELD是预后句的一部分、及“在麻醉在场时插管做内镜”的顺序——它避免诱导时骤停这一本人群标志性事件、及病房想要的肾保护是灌注与血及拒绝肾毒药、不是他的肾会报告为更差的生理盐水。**
:::

::: example “液体有反应”的脓毒症ICU患者 {#ex-responsive}
肾盂肾炎脓毒性休克第2天、已给6升、去甲肾上腺素0.2微克/公斤/分、乳酸从5.8降到3.1、无尿、体重增9公斤；被动抬腿使每搏量升18%；注册医师说“更多液体、她有反应”、ICU顾问说“她已经够了”。
::: solution
**反应性对责任（[[#def-shock]]、[[#def-fluids]]、[[renal/acute-kidney-injury]]）：调和——两人都对但问题不同：被动抬腿回答“每搏量会升吗”（会）、重症医师在问“她会获益吗”（大概不会——在9公斤正平衡无尿的等容到过负荷范围内的反应者通常把液体转化为肺与肠及肾囊水肿、而患者越是液体充足却仍低血压、答案越是“修血管”不是“填水箱”）；你面前的决定——升压药升级（这个表型通常65以上的MAP滴定的去甲肾上腺素及带保存数据的血管加压素添加、及按指南倾向对此升压药轨迹考虑应激剂量激素）而不是第七升、把液体当可逆决定的再评估（200-300毫升小剂量液体挑战伴预先规定的无信号即停止及一个停止的计划——因为液体是带停止规则的检查不是仪式、及重看超声查泵与通气效应）、源头控制复审（梗阻感染的肾：泌尿外科与肾造瘘或支架决定——这是唯一改变这条乳酸曲线的干预、及第3天液体策略——在9公斤正平衡无尿患者中是带CRRT规划的再复苏讨论、它同时在一个决定里治疗高钾与容量及尿毒症、及作为预后句追踪的肾恢复轨迹）。教学：液体反应性是一场你可以体面输掉的辩论；液体耐受性属于患者、而9公斤说她已花完了她的。**
:::

::: example 被叫做哮喘的过敏反应 {#ex-epi-missed}
34岁花生暴露、哮鸣、血压78/40、舌肿；按“重症哮喘”用沙丁胺醇雾化与氢化可的松及2升盐水治疗；十分钟后昏迷伴喘鸣。
::: solution
**肾上腺素窗口（[[#def-types]]、[[emergency-critical-care/anaphylaxis]]、[[respiratory/asthma-copd]]）：纠正——低血压加气道征加皮肤或暴露史就是过敏反应、而缺失的治疗是大腿前外侧肌注肾上腺素、必要时每几分钟重复——在这个场景它比任何临床医师的心脏焦虑都安全、而“它看起来像哮喘”陷阱就是为何算法在血压低时把大腿放在第一位——因为哮喘不会舌肿也不会掉血压、而单给液体会淹没扩张渗漏的血管床而不修好它；现在救援——高流量氧与肾上腺素及平卧举腿（坐着过敏的静脉回流塌陷会因体位相关细节杀人、及气道设备在床边——因为舌与喉水肿进展以分钟计、及预先计划无法插管时早叫高年资麻醉、及难治性休克的肾上腺素输注带中心或良好外周滴定、及不反应的β阻滞剂患者用胰高血糖素——这是中毒与过敏章重叠考试爱问的）；及之后——观察足够长以覆盖双相反应及带培训的肾上腺素装置处方及过敏转诊及书面计划、因为第二次就诊多半发生在带着抗组胺和一个故事被送回家的人身上。**

::: exercise 解读乳酸 {level=1}
给下列的鉴别与下一步：(a) 二甲双胍与脓毒症患者血压正常而乳酸4.2；(b) 哮喘发作服沙丁胺醇、红润灌注好而乳酸3.8；(c) 乳酸6.0伴腹部平坦与房颤及“疼痛与体征不相称”。
::: solution
**背景中的乳酸（[[#def-shock]]）：(a) B型与A型混合——二甲双胍相关与脓毒症邻近的清除减少加隐匿低灌注图像：治感染并再灌注并复查（并在造影与肾计划中停二甲双胍）；(b) 沙丁胺醇与呼吸功及轻度低氧的B型乳酸不是休克：不要给灌注好的患者冲击、治哮喘并观察趋势；及c) 跑赢查体的外科乳酸：房颤栓子到肠系膜动脉而早期腹部柔软（疼痛不相称加乳酸、X线看起来正常的肠）——现在CT血管造影并现在血管外科、因为这个乳酸是房间里唯一诚实的东西、而肠比数字上升得更快。**
:::

::: exercise 选择液体 {level=2}
为下列选择并辩护：(a) 糖尿病酮症酸中毒、96岁体重50公斤、校正钠128、钾3.1；(b) 肝硬化自发性细菌性腹膜炎伴AKI；(c) 创伤到达Hb 55；(d) 高钠脱水82岁、钠162。
::: solution
**匹配液体（[[#def-fluids]]）：(a) 首先0.9%氯化钠或平衡液、然后胰岛素前补钾、及老年CKD邻近心脏风险的12.5-25 ml/kg首小时范围——意味着每升后重评不是按规程、及年轻人的脑部考量（老年DKA液体速率之辩）；(b) 按腹膜炎与AKI邻近指南用白蛋白、伴腹腔穿刺与抗生素及需要时去甲肾上腺素、因为肝肾生理只有靠短暂留在血管内的容量才自愈；(c) 除了血什么都不给：正如静脉曲张例子教导的大量输血优于盐水、及晶体只为维持通路；(d) 缓慢纠正的低渗溶液算术5%葡萄糖或半张盐水计算伴钠每日下降小于10 mmol及48小时与复查时间表、因为一个下午从162到140就是制造四肢瘫的方法、及可行时经鼻胃管或口服水路径——因为口渴而清醒的患者喝水是最老也最好的低渗液。**

**从四次死亡得出的五条规则（[[#def-types]]、[[clinical-skills/patient-safety]]）：规则1——血匹配丢失：出血复苏从大量输血启动标准与平衡制品开始、按名字查纤维蛋白原、氨甲环酸进时钟、及钙与加温与它们一起开而不是第三袋之后——因为那个规程是整包进口的创伤文献、也救肝硬化患者；规则2——低血压病史核查：激素吸入剂或泼尼松龙或免疫治疗或产后出血Sheehan病史及低钠高钾低血糖一瞥使氢化可的松成为第二筛查而不是第三意见、及“治休克不治标签”反射——激素不花钱；规则3——升压药早而液体带停止规则：“第二升还在争论时就去甲肾上腺素”规则及动态重评及降级记录；规则4——目的地决定就是复苏：心梗休克在骤停前转诊（带院前心电图分诊的区域心脏骤停与休克网络）及出血目的地（内镜与介入放射及移植能力）及过敏与肺栓塞路径各有有人接的电话、因为“我们有药而失去了医院”是一类任何液体都修不好的可预防死亡；规则5——审计环：每次休克死亡对照四种机制复审并把每个决定的时机对乳酸作图、规程在月内在纸上修订、因为休克照护在规程-复现-修订的循环中改进、而替代方案就是同样四次死亡换上新患者的名字。**

::: solution

**哮喘里的脉压反常不是心包填塞而是胸腔（[[#def-shock]]、[[respiratory/asthma-copd]]、[[emergency-critical-care/airway-ventilation]]）：生理——用力吸气的人的低血压与奇脉：巨大的胸腔负压增加左室后负荷并增加静脉回流到已经膨胀的右室、而正压通气与PEEP可能同时消除低血压和它（这就是动态过度充气患者插管后骤停的机制——容量与药物不足以修复动态过度充气的机械问题）；正确的动作——治哮喘（支气管扩张剂与激素与镁）、让她安静地呼吸、不要为了一个数而把盐水灌进这个肺、及若插管则断开呼吸机几分钟以呼出并降压、然后小剂量液体伴重新评估及去甲肾上腺素用于镇静后血管扩张、及升压药用于血管张力而不是容量反应性、及避免让初级在低钾伴心率140时做“低血压就多巴胺”的选择；及教学句——“这里的灌注压是胸腔压力问题、所以先解决力学、再填管道、把泵留给超声。**

## 通向何处

脓毒症特异药理与组套在[[infectious-diseases/fever-sepsis]]、出血与损伤控制外科在[[surgery/trauma]]与[[obstetrics-gynaecology/pregnancy-complications]]、移植与肝背景在[[gastrointestinal/liver-disease]]、ICU接口在[[emergency-critical-care/critical-care]]、及中毒相关血管麻痹在[[emergency-critical-care/poisoning]]。

::: history
**休克的历史是医学发现血压只是一个症状。世界大战使它成为科学：精神病学的“弹震休克”与毛细血管床外科医师为名称争论、而Wiggers与Cannon及同时代人在动物模型中建立失血性休克生理、朝鲜战争时代证明库存柠檬酸盐血液可规模化运作——及把白蛋白与合成胶体当作替代品销售的血浆扩容产业在泄漏、字面上与证据上、一课终结于羟乙基淀粉的肾与凝血病试验及监管机构的2013年黑函、一个坏药的三十年生涯浓缩为一条。中心静脉压时代随后加冕又倒下：始于审慎生理学的东西退化成一个要击败的数字、Rivers 2001年早期目标导向治疗试验把规程变成急诊教条、而2014-15年ProCESS与ARISE及ProMISe复制显示美德是早期识别与抗生素及时恢复灌注——不是仪式化的六升与导管：现代重症循证社会学最富教益的一幕。升压药故事朝另一个方向运行、走向精化：去甲肾上腺素从1940年代化学到一线、血管加压素作为节约的第二药、2018年激素试验（APROCCHSS与ADRENAL）终结了1980年代开始的战争、血管紧张素II找到生态位、而多巴胺被自身心律失常安静降级——证据战胜惯例的一次罕见干净胜利。出血线从战场输出：损伤控制剖腹术在美军外科被造词、1:1:1血浆血小板红细胞的止血复苏在伊拉克与阿富汗被认可、氨甲环酸早给时的运气（创伤的CRASH-2、产后出血的WOMAN试验）、不可压迫躯干出血的容许性低血压、及REBOA与主动脉压迫装置时代带着它的开放试验与开放争论。同时过负荷反革命在积累：2000年代正液体平衡的结局流行病学、液体保守的ARDS时代试验、及2020年代再复苏试验浪潮、以“液体过负荷”作为编码诊断而非事故告终。本章从自身历史得到的道德：当复苏不再相信它最爱的数字——中心静脉压、卧位血压、单个乳酸、规程——而开始相信被重评的患者时，它进步最快。** — [[physiology/integrative-physiology]]、[[surgery/trauma]]、[[infectious-diseases/fever-sepsis]]。**
:::

::: summary
- 休克是带四种机制的氧输送失败；床旁套装（毛细血管再充盈、休克指数、花纹、乳酸趋势、聚焦超声）比任何单一监测仪更快定位坏掉的机器。
- 液体是有剂量的药：匹配丢失的平衡晶体、在复苏期间以重评的冲击给出、然后停止、然后常常逆转；反应性不是获益、而第十升有自己的证据。
- 出血用血优先的损伤控制生理治疗（制品早、钙与加温、氨甲环酸早、止血即复苏）、及文献支持处的容许性低血压。
- 脓毒性休克是血管问题：抗生素与源头控制作为治愈、早期去甲肾上腺素、只有在带停止规则时更多液体、难治者用激素、没有维生素C民间药理。
- 心源性休克需要支持阶梯（升压药、正性肌力、机械支持）及早转到存在该阶梯之处；其心梗与心衰亚组有不同的证据与不同的顾问。
- 模拟者——填塞、张力性气胸、肾上腺危象、黏液水肿、神经源性——通过查患者识别、并被一针、一个激素或一个升压药治愈、不是一升。
:::

## 练习

::: exercise 分类休克 {level=1}
指定机制与即刻行动：(a) 22岁脾切除后第2天、心率128、血压92/64、引流400 ml血；(b) 68岁心梗第3天、少尿、发凉、颈静脉搏动到耳、湿啰音；(c) 30岁T6脊髓损伤、心率48、血压80/45、温暖干燥；(d) 55岁免疫治疗中、血压78/40伴低钠与高钾。
::: solution
**四台机器（[[#def-shock]]、[[#def-types]]）：(a) 出血直到证明不是：输血并现在问回手术室（引流输出轨迹与凝血组合及1:1:1及损伤控制思维——晶体只为保持手臂可及）；(b) 心源性冷而湿：超声与乳酸及避免液体冲击的直觉、及去甲肾上腺素与正性肌力及转诊支持决定及血运重建之问——因为那根血管可能仍然可通；(c) 神经源性：液体然后升压药、及有症状心动过缓用阿托品、及“不是脓毒症的暖休克”模式识别、及脊髓休克与硬膜外及自主反射失调邻近的神经外科背景；及d) 肾上腺危象：现在氢化可的松与糖与培养及液体、并为内分泌稍后确认举起免疫治疗垂体炎或肾上腺炎旗、因为垂体炎是检查点抑制剂类别已知效应、而这是唯一一分钟内回答激素的低血压。**

::: exercise 写大量输血医嘱 {level=2}

::: exercise 停止液体 {level=2}
胰腺炎后液体聚集患者、HDU第8天、曾正14公斤；现在去甲肾上腺素在减、血氧下降、腹紧、膀胱压24、肌酐上升、乳酸平；同事建议“更多液体、她的压力随体位下降”。论证再复苏处方。
::: solution
**作为处方的再复苏（[[#def-shock]]、[[#def-fluids]]、[[gastrointestinal/pancreas-biliary]]）：论证——体位下降是一个太满而无法充盈腹部的静脉回流、而膀胱压24伴肌酐上升及顺应性下降就是濒临间隔室综合征的腹腔高压：液体会恶化你试图跑赢的同一套生理；处方——负平衡计划（静脉停止或减到必需药物载体——意味着抗真菌与质子泵抑制剂需要审查不是盐水式的雨衣）、大剂量利尿伴肾应答监测或CRRT缓慢超滤、因为这个肾可能不应答呋塞米而CRRT就是这里的容量工具、及让腹部耐受其内容的镇静与镇痛及胃肠减压及营养路径审查、及外科与放射重查可引流聚集及坏死清除时机、因为感染坏死就是升压药不断记起的源头、向后升级（真正间隔室综合征的减压剖腹或经皮引流、带其死亡率与开腹与造口病率的谈话、两者都诚实）、及在其间决定的监测系列膀胱压与呼吸机压力及肾与乳酸轨迹及灌注复查——不是体位试验。**
