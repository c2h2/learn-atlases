休克不等于低血压。它是循环系统不能向组织输送足够的氧以满足其需要，而此时血压可能仍然正常。缺氧的细胞转向无氧代谢，产生乳酸，最终衰竭；随后器官相继衰竭，休克持续足够长时间的患者，即使病因得到纠正，也会发生多器官功能衰竭。尽早识别休克、判断其类型、在不造成新伤害的前提下恢复氧输送，是本章的核心技能。

本章从氧输送和血压的生理学讲起，然后把休克分为四种类型，再讲床旁评估、静脉补液及其危害、血管加压药和正性肌力药，以及出血性、脓毒性、心源性和梗阻性休克的具体处理。所依据的是英国指南（NICE关于静脉补液的CG174、NICE关于脓毒症的NG253）和国际指南（拯救脓毒症运动2021）；剂量和容量以教学为目的给出典型成人数值，临床实践以本地流程为准。

## 休克的生理学 {#sec-physiology}

组织需要氧。每分钟输送的氧量取决于心脏泵出多少血以及这些血携带多少氧。

::: theorem 氧输送 {#thm-do2}
**氧输送**（$\dot{D}O_2$）是心排血量与动脉血氧含量的乘积：

$$
\dot{D}O_2 = \text{CO} \times C_aO_2 \times 10
$$ {#eq-do2}

其中CO的单位为L/min，$C_aO_2$为每dL血液中氧的mL数，系数10把dL换算为L。动脉血氧含量主要是与血红蛋白结合的氧，另有一小部分溶解氧：

$$
C_aO_2 = 1.34 \times \text{Hb} \times S_aO_2 + 0.0225 \times P_aO_2
$$ {#eq-cao2}

其中Hb单位为g/dL，$S_aO_2$以小数表示，$P_aO_2$单位为kPa。健康成人静息时每分钟获得约1,000 mL氧，消耗约250 mL。
:::

::: proof
每克完全饱和的血红蛋白约结合1.34 mL氧，因此每dL血液中结合的氧为$1.34 \times \text{Hb} \times S_aO_2$。血浆中溶解的氧遵循亨利定律，数量很小：$P_aO_2$每kPa约为0.0225 mL/dL（每mmHg 0.003 mL/dL）。每dL的含氧量乘以每分钟泵出的容量即为输送量。这个方程显示了氧输送可能失败的三种方式：心脏泵出太少（低血容量性、心源性或梗阻性休克）；血液携氧太少（贫血、低氧血症、一氧化碳）；或者氧已输送却不能到达细胞或不能被细胞利用（分布性休克中的血流分布不均、脓毒症中的线粒体功能障碍）。它还说明，把$P_aO_2$提高到远超正常几乎没有增益，而纠正低血红蛋白或低心排血量则增益很大。
:::

血压是被调节的，而不是被输送的。平均动脉压（MAP）大致等于心排血量与体循环血管阻力（SVR）的乘积：

$$
\text{MAP} \approx \text{CO} \times \text{SVR}, \qquad \text{MAP} \approx \text{DBP} + \tfrac{1}{3}(\text{SBP} - \text{DBP})
$$ {#eq-map}

心排血量下降时，交感神经系统通过收缩小动脉提高SVR，血压得以维持。这就是为什么早期休克在出现低血压之前，先表现为心动过速、四肢末梢凉而苍白、毛细血管再充盈缓慢、脉压变窄和尿量减少。脑和肾等器官在一定压力范围内能自动调节血流，成人通常以约**65 mmHg**的MAP作为最低目标，部分慢性高血压患者需要更高。

## 休克的类型 {#def-shock}

::: definition 休克及其四种类型 {#def-shock-types}
**休克**是危及生命的循环衰竭，此时氧输送不足以满足组织的代谢需要，导致细胞氧利用障碍。它通常伴有低血压（MAP低于65 mmHg或收缩压低于90 mmHg）、灌注不良的征象和血乳酸升高，但这些都不是必需的。

| 类型 | 机制 | 举例 | 典型发现 |
|---|---|---|---|
| **低血容量性** | 循环血量丢失，前负荷低 | 出血、呕吐和腹泻、烧伤、糖尿病酮症酸中毒 | 四肢末梢凉，颈静脉塌陷，低心排血量，高SVR |
| **心源性** | 泵衰竭 | 心肌梗死、心肌炎、心律失常、急性瓣膜衰竭 | 四肢末梢凉，颈静脉压升高，肺水肿，低心排血量 |
| **分布性** | 血管张力丧失，血流分布不均 | 脓毒症、严重过敏反应、脊髓损伤（神经源性）、肾上腺危象 | 早期常四肢温暖，脉搏洪大，低SVR，心排血量高或正常 |
| **梗阻性** | 心脏充盈或排空受阻 | 张力性气胸、心脏压塞、大面积肺栓塞 | 颈静脉压升高，肺部清晰，低心排血量 |

患者常同时有不止一种类型：脓毒性休克伴心肌抑制，或服用β受体阻滞剂的患者发生出血。
:::

**乳酸**是有用的指标。疑似感染的患者血乳酸高于2 mmol/L提示低灌注或细胞应激，高于4 mmol/L与高死亡率相关。乳酸并不只是氧债的标志：肾上腺素、肝衰竭、二甲双胍和癫痫发作也会使其升高。治疗后乳酸下降令人放心；上升则不然。

**休克指数**即心率除以收缩压，是快速的床旁指标。正常约为0.5–0.7；高于1提示明显休克，尤其在出血时，即使血压仍在正常范围内。

::: example 为休克分类 {#ex-classify}
三位患者到达复苏室。

(a) 71岁男性，压榨性胸痛，血压82/56 mmHg，脉率112次/分，双手湿冷，双肺中野湿啰音，颈静脉压升高。
(b) 34岁女性，发热，一侧小腿红肿，血压78/40 mmHg，脉率128次/分，双手温暖，脉搏洪大，乳酸5.2 mmol/L。
(c) 25岁摩托车手，左胸刺伤，血压74/50 mmHg，脉率136次/分，颈静脉怒张，心音遥远，双侧呼吸音对称。

分别为其分类。
::: solution
(a) **心源性休克**，几乎肯定由心肌梗死引起：四肢末梢凉（低心排、高SVR），伴充盈压升高的征象（颈静脉压升高和肺水肿）。补液冲击可能加重水肿；他需要心电图、紧急再灌注和心排血量支持。

(b) 由蜂窝织炎或坏死性筋膜炎引起的**分布性（脓毒性）休克**：早期血管扩张，四肢温暖、脉压增宽，乳酸高。治疗是抗生素、控制感染源（坏死性感染需紧急外科评估）、补液和去甲肾上腺素。

(c) 由**心脏压塞**引起的**梗阻性休克**：胸部穿透伤、低血压、颈静脉怒张和心音遥远（Beck三联征），双侧呼吸音对称使张力性气胸的可能性降低。他需要立即解除心包压迫，创伤时通常通过开胸进行。
:::
:::

## 评估休克患者 {#sec-assessment}

评估遵循ABCDE（见[[emergency-critical-care/acute-assessment]]），并回答以下具体问题：

1. **患者是否处于休克？**寻找心动过速、低血压、毛细血管再充盈缓慢、皮肤花斑、意识模糊、尿量低于0.5 mL/kg/h和乳酸升高。
2. **是哪种类型？**触摸四肢末梢（温暖或凉），观察颈静脉，听诊肺和心脏，寻找出血、感染和病因。**床旁超声**可显示左右心室的大小和收缩、心包积液、下腔静脉、腹腔游离液体和气胸，熟练者可在数分钟内为休克分类。
3. **患者是否可能对液体有反应？**见下文。
4. **病因是什么，现在能解决吗？**出血需要止血，脓毒症需要抗生素和感染源控制，闭塞的冠状动脉需要再灌注，张力性气胸需要减压。

### 液体反应性

如果补液试验后患者的每搏量显著上升（通常为10–15%或更多），则称其**有液体反应性**。这取决于患者处于其Frank–Starling曲线的哪一段。在曲线的陡峭段，增加前负荷会拉伸心室并增加每搏量；在平坦段，额外的液体只会升高充盈压而不增加排血量，只会渗入肺和组织。危重患者中，任一时刻只有约一半有液体反应性。

**被动抬腿试验**是一种可逆的补液试验：在躯干平卧的情况下把双腿抬高至45°，约有300 mL静脉血回流至心脏。如果每搏量或心排血量（用超声心动图或心排血量监测仪测量，而不是只看血压）上升约10%或更多，患者很可能对液体有反应。单次中心静脉压读数等静态指标对液体反应性的预测很差。

caption: 简化的Frank–Starling曲线：每搏量（mL，纵轴）对前负荷（舒张末期充盈，任意单位，横轴）。滑块设定心肌收缩力。在曲线陡峭的左段，补液冲击可提高每搏量；在平坦的右段，同样的冲击只升高充盈压、收益甚微，这正是液体导致水肿的区间。收缩力弱的心室（收缩力低）更早进入平坦段。该模型仅为示意，不是临床工具。

## 静脉补液 {#def-fluids}

::: definition 静脉液体的种类与补液的目的 {#def-fluid-types}
**晶体液**是电解质（有时含葡萄糖）的水溶液。**等渗盐水**（0.9%氯化钠）含钠和氯各154 mmol/L，氯高于血浆。**平衡晶体液**（如Hartmann液或Plasma-Lyte）的成分更接近血浆，以乳酸、醋酸或葡萄糖酸替代部分氯。**5%葡萄糖**在葡萄糖被代谢后分布于全身水分，不是复苏用液体。**胶体液**含有在循环中停留时间更长的大分子：**人血白蛋白溶液**以及明胶和淀粉等人工胶体。

NICE指南CG174（医院内成人）按目的描述补液，即**“5R”**：**复苏**（Resuscitation）、**常规维持**（Routine maintenance）、**补充持续丢失**（Replacement）、**再分布**（Redistribution，例如脓毒症时液体进入组织）和**再评估**（Reassessment）。对于复苏，它建议在15分钟内输入500 mL含钠130–154 mmol/L的晶体液作为一次冲击，然后再评估。成人常规维持量约为每日25–30 mL/kg水，钠、钾、氯各约每日1 mmol/kg，葡萄糖每日50–100 g。
:::

等渗晶体液冲击只有约四分之一能较长时间留在血浆中；其余进入组织间隙，引起水肿。在脓毒症和炎症中，内皮表面的糖萼受损，连胶体液也会渗漏。这就是为什么液体在休克早期有益，而一旦患者不再有反应就变得有害。

**用哪种晶体液？**大量0.9%盐水会引起高氯性代谢性酸中毒。在SMART试验（2018）中，美国ICU中接受平衡晶体液的成人比接受盐水者略少发生主要肾脏不良事件（死亡、新需透析或持续肾功能障碍的复合结局）。两项大型试验（BaSICS，2021；PLUS，2022）未发现死亡率有显著差异。平衡晶体液现在是大多数患者的常规选择，某些情况下首选盐水，如创伤性脑损伤（因为部分平衡液略为低渗）或呕吐引起的低氯性碱中毒。

**胶体液。**淀粉溶液被发现有害：在6S试验（2012）中，羟乙基淀粉增加了严重脓毒症患者的死亡率和肾脏替代治疗需求；在CHEST试验（2012）中，它增加了肾脏替代治疗的使用。它们在英国和欧洲已被暂停使用或严格限制。白蛋白在普通ICU患者中被证明与盐水同样安全（SAFE试验，2004），但在创伤性脑损伤中与更高的死亡率相关；它被选择性使用，例如肝病大量放腹水时。

**给多少？**复苏的分期有助于判断：早期**抢救**期，液体可以救命；**优化**期，只有在每次冲击可能有益时才给；**稳定**期，只给维持量和补充丢失；**降阶梯**期，清除多余的液体。ICU患者的液体正平衡与更差的结局相关。在脓毒性休克中，CLASSIC（2022）和CLOVERS（2023）试验发现，初始复苏后限制性与较宽松的补液策略在死亡率上没有差异，这支持谨慎、反复评估的做法，而不是大量的固定容量。

::: warning 治疗数字而不是治疗患者
已输入数升液体的患者出现低血压或少尿，往往并不说明需要更多液体。不检查上一次冲击是否有效就反复冲击以“把油箱加满”，会导致肺水肿、腹腔间隔室综合征、肠道水肿和伤口愈合不良。每次冲击前都要问患者是否仍有液体反应性；如果没有，答案通常是血管加压药、正性肌力药或治疗病因。
:::

## 血管加压药和正性肌力药 {#sec-vasopressors}

**血管加压药**收缩血管、提高SVR；**正性肌力药**增强心肌收缩力。

| 药物 | 主要受体作用 | 主要用途 |
|---|---|---|
| **去甲肾上腺素** | α₁ ≫ β₁ | 脓毒性及大多数血管扩张性休克的一线血管加压药 |
| **血管升压素** | V₁受体 | 脓毒性休克中加用于去甲肾上腺素 |
| **肾上腺素** | β₁、β₂和α₁ | 严重过敏反应；心脏骤停；脓毒性休克的二线药 |
| **多巴酚丁胺** | β₁（兼有部分β₂） | 低心排血量时的正性肌力药（心源性休克、脓毒性心肌抑制） |
| **间羟胺** | α₁ | 短期外周血管加压药（如麻醉期间或建立中心静脉通路之前） |

拯救脓毒症运动（2021）推荐去甲肾上腺素作为一线血管加压药，初始MAP目标为65 mmHg，去甲肾上腺素剂量上升时加用血管升压素。在置入中心静脉导管期间，可经良好的外周套管开始使用血管加压药，以免延误。对持续需要血管加压药的脓毒性休克，建议使用氢化可的松。

## 按类型的具体处理 {#def-types}

### 出血性休克

出血要靠止血来治疗。液体能争取时间，但不能替代外科、内镜或介入放射学止血。

::: algorithm 大出血处理原则 {#def-haemorrhage}
1. **控制出血**：直接压迫、肢体出血用止血带、骨盆带、手术、内镜或介入放射学。
2. **启动大出血预案**，使血液成分以套餐方式及时送达。
3. 创伤中在出血控制前采取**允许性低血压**：以可触及桡动脉搏动或收缩压约80–90 mmHg为目标，而不是正常血压；但创伤性脑损伤除外，此时需要更高的血压以保护脑灌注。
4. **输血液成分而不是晶体液**：红细胞和血浆按高比例输注，并在实验室或床旁检测指导下补充血小板和纤维蛋白原（冷沉淀或纤维蛋白原浓缩物）。
5. 创伤中尽早（伤后3小时内）使用**氨甲环酸**。
6. **预防致死三联征**——低体温、酸中毒和凝血病：加温所有液体并为患者保暖，纠正钙（血制品中的枸橼酸盐会结合钙）。
:::

这些原则的证据来自创伤试验。**CRASH-2**（2010）纳入两万多名创伤患者，发现3小时内给予氨甲环酸可降低全因死亡率（14.5%对比16.0%）；3小时后给予则无益。**PROPPR**（2015）在重伤患者中比较了血浆、血小板与红细胞按1:1:1和1:1:2比例输注。1:1:1组更常实现止血，24小时内死于失血的人更少，但24小时和30天的全因死亡率没有显著差异。输血实践详见[[blood/transfusion]]，创伤救治见[[surgery/trauma]]。

### 脓毒性休克

**脓毒症**是机体对感染反应失调导致的危及生命的器官功能障碍；**脓毒性休克**是在充分液体复苏后仍持续低血压、需要血管加压药才能维持MAP 65 mmHg或以上，且乳酸高于2 mmol/L的脓毒症（2016年Sepsis-3定义）。处理的基础是早期识别（见[[emergency-critical-care/acute-assessment]]），做血培养后对最高危者在1小时内给予抗生素，控制感染源，以反复评估的冲击方式补液，并使用去甲肾上腺素。拯救脓毒症运动建议，对脓毒症所致低灌注在最初3小时内给予约30 mL/kg晶体液，这是一项弱推荐，应根据患者调整。详见[[infectious-diseases/fever-sepsis]]。

### 心源性休克

最常见的原因是急性心肌梗死，最重要的治疗是**早期血运重建**：在SHOCK试验（1999）中，急诊血运重建未显著降低30天死亡率，但6个月死亡率较低。补液要谨慎，甚至不补。低心排血量用多巴酚丁胺等正性肌力药支持，低血压用去甲肾上腺素。机械循环支持的结果不一：主动脉内球囊反搏在IABP-SHOCK II试验（2012）中未降低死亡率；而在DanGer Shock试验（2024）中，经选择的ST段抬高型心肌梗死合并心源性休克患者使用微轴流泵降低了180天死亡率，但并发症更多。引起休克的心律失常按[[emergency-critical-care/resuscitation#def-periarrest]]处理。

### 梗阻性休克

三种主要病因各需一种机械性解决办法：**张力性气胸**（减压）、**心脏压塞**（心包穿刺或外科引流）和**大面积肺栓塞**（溶栓，或外科、导管取栓）。三者都导致颈静脉压升高，可通过床旁查体和超声加以区分。

### 过敏性及其他分布性休克

严重过敏反应首先需要肾上腺素；持续低血压时加用补液。详见[[emergency-critical-care/anaphylaxis]]。**神经源性休克**发生于高位脊髓损伤后，因交感神经传出丧失而同时出现低血压和心动过缓；治疗为补液、血管加压药，心动过缓时用阿托品。**肾上腺危象**需要静脉氢化可的松。

## 实例分析

::: example 贫血时的氧输送 {#ex-do2}
一名66岁女性有缓慢的上消化道出血，Hb 80 g/L（8 g/dL），SaO₂ 97%，PaO₂ 12 kPa，心排血量5 L/min。计算她的氧输送；如果她的Hb正常（150 g/L），维持同样的氧输送需要多少心排血量？这对她的心脏意味着什么？
::: solution
按[[#eq-cao2]]：

$$
C_aO_2 = 1.34 \times 8 \times 0.97 + 0.0225 \times 12 = 10.40 + 0.27 = 10.67 \text{ mL/dL}
$$

按[[#eq-do2]]，$\dot{D}O_2 = 5 \times 10.67 \times 10 \approx 533$ mL/min，约为正常的一半。

如果Hb为15 g/dL、饱和度相同，$C_aO_2 \approx 1.34 \times 15 \times 0.97 + 0.27 = 19.77$ mL/dL，同样的输送量只需$533 / (19.77 \times 10) \approx 2.7$ L/min。反过来，在她现在的Hb水平下要输送正常的1,000 mL/min，需要约$1000 / 106.7 \approx 9.4$ L/min的心排血量。贫血迫使心脏更加努力地工作；对冠心病患者，这额外的负荷可能诱发心肌缺血，这就是为什么对活动性心脏病患者要调整限制性输血阈值。
:::
:::

::: example 被输了九升液体的静脉曲张出血患者 {#ex-overload}
一名52岁男性患酒精相关性肝硬化，发生静脉曲张出血。第一夜，为使收缩压保持在110 mmHg以上，他接受了6 L 0.9%盐水和3 L其他晶体液，外加2单位红细胞。早晨他气促，双肺湿啰音，腹部胀紧，Hb 62 g/L，血氯118 mmol/L。哪里出了问题？
::: solution
有好几处。

- **用晶体液代替血液。**用盐水补充失血，稀释了血红蛋白和凝血因子，且不能携氧。需要的是红细胞（静脉曲张出血时通常采用约70–80 g/L的限制性目标）和纠正凝血病。
- **追求正常血压。**静脉曲张出血时，过度输血和过度补液会升高门静脉压，可能诱发再出血。出血控制前应接受较低的目标血压。
- **盐水过量。**六升0.9%盐水引起高氯性酸中毒，钠负荷加重了腹水和肺水肿。
- **遗漏确定性治疗。**优先事项是特利加压素（terlipressin）、预防性抗生素以及紧急内镜套扎；液体只是通往这些治疗的桥梁。

他现在需要利尿或谨慎地清除液体、输血纠正贫血，如尚未内镜治疗则进行内镜治疗。见[[gastrointestinal/liver-disease]]。
:::
:::

::: example “有液体反应性”的脓毒症患者 {#ex-responsive}
一名59岁女性因肺炎发生脓毒性休克，在急诊科已接受3 L平衡晶体液，并正在使用去甲肾上腺素。在ICU，她的MAP为62 mmHg。被动抬腿使她的每搏量（超声心动图测量）从52 mL升至55 mL。她的双肺出现新的湿啰音，PaO₂/FiO₂比值在下降。她应该再接受一次冲击吗？
::: solution
每搏量上升$(55 - 52)/52 \approx 5.8\%$，低于通常约10%的阈值。她**没有液体反应性**，而且已显示出液体的危害（氧合恶化）。再一次冲击不太可能提高她的心排血量，却很可能加重肺部病变。

更好的做法是**增加去甲肾上腺素**使MAP达到至少65 mmHg，考虑加用血管升压素，检查左心室收缩是否不佳（脓毒性心肌病），如是则考虑多巴酚丁胺，并确认感染源控制和抗生素是否充分。一旦稳定，目标转为使液体平衡回到接近零。
:::
:::

::: example 被当作哮喘的严重过敏反应 {#ex-epi-missed}
一名27岁男性在餐馆倒地。他喘息，胸部有荨麻疹，血压70/40 mmHg，脉率140次/分。一位旁观者给他用了他的沙丁胺醇吸入器，急救人员开始补液冲击。到达时他仍然低血压、喘息。遗漏了什么？
::: solution
这是**严重过敏反应**，伴**分布性休克**和支气管痉挛：在可能的食物触发后突然发病，有皮肤表现、呼吸受损和低血压。沙丁胺醇只治疗喘息，单靠补液无法克服严重的血管扩张和毛细血管渗漏。

遗漏的治疗是**肌内注射肾上腺素**：成人于大腿前外侧注射500微克（1 mg/mL溶液0.5 mL），无改善则5分钟后重复，同时让患者平卧（能耐受时抬高双腿）并给予高流量氧。持续低血压时补液冲击仍然适当。如果两剂肌内注射肾上腺素无效，则为**难治性严重过敏反应**，需在重症监护指导下静脉输注肾上腺素。见[[emergency-critical-care/anaphylaxis]]。
:::
:::

::: example “脓毒症”病床上的心脏压塞 {#ex-tamponade}
一名68岁女性正在因肺癌接受化疗，因气促、37.9 °C发热和低血压（血压84/60 mmHg，脉率120次/分）入院。她被按中性粒细胞减少性脓毒症治疗，给予抗生素和2 L补液，但气促和低血压反而加重。她的颈静脉压升至下颌角，双肺清晰，收缩压在吸气时下降15 mmHg。心电图显示QRS波低小，且高低交替。发生了什么？
::: solution
**心脏压塞**，最可能由恶性心包积液引起。线索包括：低血压伴颈静脉压升高而双肺清晰（梗阻性而非分布性生理），**奇脉**（吸气时收缩压下降超过10 mmHg），以及心脏在积液中摆动导致的低电压和**电交替**。补液通过提高充盈压可能暂时有帮助，但确定性治疗是紧急**超声心动图**和**心包穿刺**。感染可能同时存在，因此继续使用抗生素。教训是：按预期治疗后反而恶化的患者需要重新分类，要看颈静脉、用超声探头。
:::
:::

::: quiz
一名45岁男性脓毒性休克患者已接受30 mL/kg晶体液。他的MAP为58 mmHg，乳酸4.8 mmol/L。被动抬腿未引起心排血量变化。最恰当的下一步是什么？
- [ ] 再输2 L 0.9%盐水。
- [ ] 输500 mL羟乙基淀粉冲击。
- [x] 开始或增加去甲肾上腺素，使MAP至少达到65 mmHg。
- [ ] 等待6小时后复查乳酸。
::: solution
他没有液体反应性，因此继续补液不太可能有益，还可能有害。去甲肾上腺素是脓毒性休克的一线血管加压药。淀粉溶液会增加脓毒症患者的死亡率和肾损伤，不应使用。
:::
:::

::: history
静脉补液始于霍乱。1832年，在波及英国的那次流行中，爱丁堡医生Thomas Latta把盐溶液注入垂死患者的静脉，其中一些人康复了；但这一技术随后在数十年间几乎被遗忘。19世纪80年代，Sydney Ringer在伦敦大学学院用蛙心进行研究，发现生理溶液除钠以外还需要钙和钾；1932年，美国儿科医生Alexis Hartmann在林格液中加入乳酸以治疗酸中毒，形成了Hartmann液。Ernest Starling约在1896年关于毛细血管壁两侧作用力的研究，以及1918年关于心脏充盈与排血量关系的研究，为液体复苏提供了生理学基础。2001年，Emanuel Rivers报告了脓毒性休克的早期目标导向治疗；2014年三项大型试验（ProCESS、ARISE和ProMISe）发现该方案并不优于常规治疗，这是一个重要教训：背景治疗的改进可以抹去一项方案的效果。
:::

## 后续内容

休克患者的救治在重症监护病房继续（[[emergency-critical-care/critical-care]]）。脓毒症见[[infectious-diseases/fever-sepsis]]，心力衰竭和心源性休克见[[cardiovascular/heart-failure]]，血液制品见[[blood/transfusion]]，肾脏对休克的反应见[[renal/acute-kidney-injury]]，休克的病理学见[[pathology/haemodynamics]]。

::: summary
- 休克是组织氧输送不足；低血压是晚期征象。氧输送 = 心排血量 × 动脉血氧含量。
- 四种类型：低血容量性、心源性、分布性和梗阻性。四肢末梢温凉、颈静脉、肺部和超声可加以区分。
- 乳酸高于2 mmol/L提示低灌注；休克指数高于1提示明显休克。
- 以500 mL晶体液冲击方式补液并再评估；只有有液体反应性的患者才获益，被动抬腿试验可加以检验。通常首选平衡晶体液；淀粉有害。
- 去甲肾上腺素是一线血管加压药（目标MAP 65 mmHg）；多巴酚丁胺支持衰竭的心室。
- 出血：止血，创伤时采用允许性低血压，按高比例输注血液成分，3小时内给予氨甲环酸。PROPPR（2015）：1:1:1对比1:1:2，止血更多、24小时内死于失血者更少，24小时和30天死亡率无显著差异。
- 心源性休克需要血运重建；梗阻性休克需要减压或清除血栓。
:::

## 习题

::: exercise 平均动脉压 {level=1 check="83"}
一名患者血压为110/70 mmHg。用[[#eq-map]]中的公式估算平均动脉压，四舍五入到整数mmHg。
::: solution
$\text{MAP} \approx 70 + \tfrac{1}{3}(110 - 70) = 70 + 13.3 = 83.3$，四舍五入为**83 mmHg**。
:::
:::

::: exercise 休克指数 {level=1 check="1.4"}
一名腹部刺伤男性脉率126次/分，收缩压90 mmHg。计算他的休克指数（保留一位小数）并解读。
::: solution
休克指数$= 126 / 90 = 1.4$。高于1提示明显失血，尽管他的收缩压仍在正常下限。他需要启动大出血预案并请外科会诊。
:::
:::

::: exercise 氧输送 {level=2 check="764"}
一名患者心排血量5 L/min，Hb 120 g/L，SaO₂ 95%，忽略溶解氧，计算其氧输送（mL/min，四舍五入到整数）。
::: hint
先把Hb换算为g/dL，然后用不含溶解项的[[#eq-cao2]]和[[#eq-do2]]。
:::
::: solution
Hb为12 g/dL。$C_aO_2 = 1.34 \times 12 \times 0.95 = 15.276$ mL/dL。$\dot{D}O_2 = 5 \times 15.276 \times 10 = 763.8$，四舍五入为**764 mL/min**。
:::
:::

::: exercise 液体平衡 {level=1 check="800"}
24小时内，一名患者经静脉和口服共摄入3,200 mL液体。尿量1,100 mL，鼻胃管丢失600 mL，不显性失水估计为700 mL。估计的液体净平衡是多少mL（正值表示增加）？
::: solution
丢失量为$1100 + 600 + 700 = 2400$ mL。净平衡$= 3200 - 2400 = +800$ mL。不显性失水是估计值（发热、呼吸急促和开放伤口时增加），因此每日称体重是有用的核对手段。
:::
:::

::: exercise 选择液体 {level=2}
为下列每位患者建议一种合适的液体并说明理由：(a) 30岁，腹泻，血压92/60 mmHg，血钠正常；(b) 70岁肝硬化患者，正在放出6 L腹水；(c) 25岁枪伤患者，血压70/40 mmHg；(d) 40岁，严重颅脑损伤伴低血压。
::: solution
(a) 500 mL平衡晶体液（如Hartmann液）冲击并再评估，随后补充包括钾在内的持续丢失。
(b) 人血白蛋白溶液，以预防放腹水后循环功能障碍（按肝病学指南，通常按每升放出的腹水给予）。
(c) 通过大出血预案输注血液成分（红细胞和血浆高比例，并在检测指导下补充血小板和纤维蛋白原），氨甲环酸，允许性低血压，立即外科止血；尽量少用晶体液。
(d) 等渗晶体液（常优先选用0.9%盐水，而非略为低渗的平衡液），有出血时输血；创伤性脑损伤避免用白蛋白，且不适用允许性低血压，因为必须维持脑灌注压。
:::
:::

::: exercise 解读乳酸 {level=2}
一名服用二甲双胍（metformin）的63岁2型糖尿病男性因呕吐和急性肾损伤入院。血压118/72 mmHg，脉率88次/分，毛细血管再充盈2秒，乳酸6.1 mmol/L，pH 7.18。他处于休克吗？
::: solution
他的循环看来是充分的：血压、心率和毛细血管再充盈都正常。乳酸很高伴酸中毒却没有低灌注征象，提示休克以外的原因。可能是**二甲双胍相关性乳酸酸中毒**，由急性肾损伤减少二甲双胍排泄所诱发。停用二甲双胍，补液纠正脱水，严重酸中毒时可能需要肾脏替代治疗，因为它能同时清除酸和药物。乳酸是细胞应激或清除受损的标志，而不是单纯的灌注指标。
:::
:::

::: exercise 大量输血医嘱 {level=2}
一名41岁女性在交通事故后被送来，骨盆骨折，血压78/50 mmHg，脉率140次/分。以编号计划的形式写出她最初15分钟的处理。
::: solution
1. 呼叫创伤团队，评估时先控制灾难性出血，然后进行ABCDE。
2. 在大转子水平上骨盆带。
3. 启动大出血预案；抽血，包括交叉配血、凝血功能、纤维蛋白原以及含乳酸和离子钙的静脉血气。
4. 伤后3小时内给予氨甲环酸（按本地创伤流程，成人1 g静脉注射10分钟以上，随后1 g在8小时内输注）。
5. 经加温器按高比例输注红细胞和血浆；根据结果加用血小板和冷沉淀；离子钙低时补钙。
6. 允许性低血压：在止血前以可触及桡动脉搏动或收缩压约80–90 mmHg为目标（未怀疑颅脑损伤）。
7. 安排确定性止血：根据本地资源和反应，选择介入放射学栓塞或外科填塞。
8. 为她保暖并反复再评估。
:::
:::

::: exercise 何时停止补液 {level=3}
一名72岁女性因憩室穿孔（已手术）所致脓毒性休克入住ICU第3天，已停用去甲肾上腺素。她的累计液体平衡为+7.5 L，有外周及骶部水肿，PaO₂/FiO₂比值在下降，尿量0.4 mL/kg/h。护士问她是否需要再冲击一次以纠正少尿。请讨论。
::: solution
她已经从抢救期和优化期进入**降阶梯**期。她的循环不再需要支持，而且显示出液体的危害：水肿、气体交换恶化，可能还有肾静脉淤血，后者本身就会减少尿量。少尿本身并不是补液的指征。计划是尽可能停用维持液（浓缩药物和营养液），通过查体和超声评估她的容量状态，一旦血流动力学稳定即试用利尿剂，并监测肾功能和电解质。如果利尿剂无效而液体超负荷威胁到肺，可以用肾脏替代治疗脱水。目标是让她的累计平衡回到接近零。
:::
:::

::: exercise 有两个问题的休克患者 {level=3}
一名79岁男性因缺血性心脏病服用比索洛尔，因黑便入院。脉率78次/分，血压92/58 mmHg；面色苍白、意识模糊，Hb 71 g/L。低年资医生记录他“没有心动过速，所以大概没有休克”。讨论这个错误和处理。
::: solution
β受体阻滞剂会削弱失血时的心动过速反应，因此心率正常并不能排除休克；低血压、苍白和意识模糊提示明显的低血容量。他的心脏病意味着贫血和低血压都会威胁心肌供氧（[[#thm-do2]]）。处理：ABCDE，两根大口径套管，交叉配血并输血（鉴于他有缺血性心脏病，按本地指南采用略高的Hb阈值是合理的），Glasgow–Blatchford风险评分，暂停β受体阻滞剂以及任何抗血小板药或抗凝药并与心内科团队权衡风险，复苏后紧急内镜检查。见[[gastrointestinal/gi-bleeding-cancer]]。
:::
:::
