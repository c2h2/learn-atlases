重症监护病房（ICU）收治器官正在衰竭的患者，在治疗基础疾病或等待其恢复的同时，用机器和药物支持这些器官。技术令人印象深刻，但真正影响结局的大部分工作并不起眼：避免治疗本身带来的伤害、预防感染、保持浅镇静、让患者活动起来、合理营养，以及与患者和家属坦诚交谈。重症监护也是医学中许多最艰难决定的发生地：何时治疗是在帮助患者，何时只是在延长死亡过程。

本章介绍重症监护的组织方式、收治对象及原因、每日查房、器官支持、脓毒症和器官功能障碍评分、镇静与谵妄、机械通气撤离、营养与血糖控制、ICU获得性并发症的预防、沟通与临终照护、器官捐献，以及危重病后的康复。所依据的是英国的组织方式和指南（英国重症监护学会、重症医学学院、NICE），并介绍塑造了临床实践的国际试验。

## 病房 {#def-unit}

::: definition 照护级别 {#def-levels}
在英国，照护以患者所需的支持水平而不是所住的病房来描述（英国重症监护学会，《成人重症监护级别》，第二版，2021）：

| 级别 | 患者 |
|---|---|
| **0** | 普通病房即可满足需要 |
| **1** | 有恶化风险，或刚从更高级别照护转出，需要在病房内增加监测或由重症监护外展团队介入 |
| **2** | 需要单一器官支持（高级呼吸支持除外）、更细致的观察或干预，或从3级转出（传统上的高依赖病房） |
| **3** | 单独需要高级呼吸支持（有创通气），或需要两个及以上器官系统的支持 |

器官支持包括有创通气、无创通气、血管活性药物、肾脏替代治疗，以及在专科中心进行的体外膜氧合（ECMO）。
:::

**收治谁？**重症监护适用于患有可逆性疾病、需要在其他地方无法提供的器官支持、且本人愿意接受的患者。这一决定要在获益可能性（急性病的可逆性、患者的衰弱程度和慢性健康状况、生理储备）与治疗负担之间权衡，并尊重患者已知的意愿。衰弱程度（例如用**临床衰弱量表**衡量）对老年患者的结局有很强的预测作用。收治并非全有或全无：患者可以为一次有明确目标的**限时治疗试验**而入住，也可以在病房接受有明确治疗上限的照护。

### 每日查房

每位患者每天至少由多学科团队（重症医生、护士、药师、物理治疗师、营养师、微生物学家）按系统评估一次：神经系统与镇静、呼吸、心血管、肾脏与液体平衡、胃肠道与营养、血液、感染与导管、皮肤，以及家属的理解和治疗目标。许多科室使用核查表以免遗漏。一个常用的记忆口诀是**FAST HUGS BID**：营养（**F**eeding）、镇痛（**A**nalgesia）、镇静（**S**edation）、血栓预防（**T**hromboprophylaxis）、床头抬高（**H**ead of bed elevation）、应激性**U**溃疡预防、血糖控制（**G**lucose control）、自主呼吸试验（**S**pontaneous breathing trial）、肠道管理（**B**owel care）、拔除留置导管（**I**ndwelling catheter removal）、抗生素降阶梯（**D**e-escalation of antibiotics）。

## 器官功能障碍与脓毒症 {#sec-sepsis}

::: definition 脓毒症、脓毒性休克与SOFA评分 {#def-sofa}
根据**Sepsis-3**定义（2016），**脓毒症**是机体对感染反应失调导致的危及生命的器官功能障碍。器官功能障碍以**序贯器官衰竭评估（SOFA）**评分急性增加**2分或以上**来识别。**脓毒性休克**是指在充分液体复苏后仍需血管加压药才能维持MAP 65 mmHg或以上、且血清乳酸高于2 mmol/L的脓毒症。

SOFA评分对六个系统各评0–4分（总分0–24）：

| 系统 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 呼吸：PaO₂/FiO₂，mmHg | ≥400 | <400 | <300 | <200且有呼吸支持 | <100且有呼吸支持 |
| 凝血：血小板，×10⁹/L | ≥150 | <150 | <100 | <50 | <20 |
| 肝脏：胆红素，µmol/L | <20 | 20–32 | 33–101 | 102–204 | >204 |
| 心血管 | MAP ≥70 mmHg | MAP <70 mmHg | 多巴胺≤5或任意剂量多巴酚丁胺 | 多巴胺>5，或肾上腺素或去甲肾上腺素≤0.1 µg/kg/min | 多巴胺>15，或肾上腺素或去甲肾上腺素>0.1 µg/kg/min |
| 中枢神经：格拉斯哥昏迷量表 | 15 | 13–14 | 10–12 | 6–9 | <6 |
| 肾脏：肌酐，µmol/L（或尿量） | <110 | 110–170 | 171–299 | 300–440（或<500 mL/天） | >440（或<200 mL/天） |

2025年发布了修订版评分**SOFA-2**，六个系统不变，但更新了变量和阈值以反映当前实践；各科室正开始采用。
:::

SOFA评分的意义不在于诊断，而在于描述患者病情有多重以及如何变化。最初几天SOFA评分上升预示死亡；评分下降提示恢复。在ICU中，脓毒症的处理是寻找并控制感染源（引流积液、拔除感染的导管、手术），根据培养结果选择并逐步收窄抗生素，并按[[emergency-critical-care/shock-fluids]]所述支持衰竭的器官。许多患者有**急性肾损伤**，按KDIGO标准分期（[[renal/acute-kidney-injury]]）；肾脏替代治疗用于难治性高钾血症、酸中毒、液体超负荷或尿毒症并发症。STARRT-AKI试验（2020）发现，在没有这些指征时提早开始并无生存获益。

::: example 计算SOFA评分 {#ex-sofa}
一名67岁男性因粪性腹膜炎接受机械通气，FiO₂ 0.5时PaO₂ 10.5 kPa。血小板85 × 10⁹/L，胆红素40 µmol/L，去甲肾上腺素0.15 µg/kg/min，肌酐190 µmol/L。镇静前他的GCS为15。计算他的SOFA评分。
::: solution
PaO₂/FiO₂ $= 10.5 / 0.5 = 21$ kPa，即$21 \times 7.5 \approx 158$ mmHg：在有呼吸支持时低于200，得**3分**。

| 系统 | 数值 | 分数 |
|---|---|---|
| 呼吸 | 158 mmHg，机械通气 | 3 |
| 凝血 | 85 | 2 |
| 肝脏 | 40 | 2 |
| 心血管 | 去甲肾上腺素0.15 | 4 |
| 中枢神经 | GCS 15（镇静前） | 0 |
| 肾脏 | 190 | 2 |

总分：$3 + 2 + 2 + 4 + 0 + 2 = 13$。这提示严重的多器官功能障碍。对镇静患者，GCS通常按假定未镇静时的数值评分。
:::
:::

## 器官支持与“解放”集束 {#def-support}

### 通气、镇静与谵妄

机械通气（见[[emergency-critical-care/airway-ventilation]]）需要镇痛，常常还需要镇静。深镇静曾是常规，现已知它会延长通气时间、增加谵妄和肌无力，并可能提高死亡率。现代做法是**镇痛优先**，然后使用能保证患者安全和舒适的**最浅镇静**，并用**Richmond躁动–镇静量表（RASS）**定期评估，该量表从+4（好斗）经0（清醒而平静）到−5（不能唤醒）。大多数患者以0到−2为目标。丙泊酚和右美托咪定优于苯二氮䓬类，后者与更多谵妄相关。

::: definition 重症监护中的谵妄 {#def-delirium}
**谵妄**是由基础疾病引起的注意力和觉知的急性、波动性紊乱，伴思维紊乱或意识水平改变。在ICU中它很常见（常影响三分之一或更多的机械通气患者），常为**低活动型**（安静、退缩）而非躁动型，因而容易漏诊，并与住院时间延长、死亡率升高和长期认知损害相关。至少每天用经验证的工具筛查一次，如**ICU意识模糊评估法（CAM-ICU）**：(1) 急性起病或病程波动，加上(2) 注意力不集中，再加上(3) 意识水平改变或(4) 思维紊乱之一。
:::

谵妄的处理是治疗病因（感染、低氧血症、代谢紊乱、药物戒断、疼痛、尿潴留、便秘、有抗胆碱能或镇静作用的药物），采用非药物措施（定向、眼镜和助听器、昼夜作息、睡眠、早期活动、家属探视），除酒精戒断外避免使用苯二氮䓬类。抗精神病药未被证明能缩短谵妄；它们只用于令人痛苦的躁动。

::: definition ABCDEF集束 {#def-abcdef}
**ABCDEF（“解放”）集束**汇集了可减少呼吸机使用天数、谵妄和肌无力的循证做法：

- **A**：评估（Assess）、预防和处理疼痛。
- **B**：**同时**（Both）进行自主唤醒试验（每日中断或减浅镇静）和自主呼吸试验。
- **C**：镇痛和镇静药物的**选择**（Choice）。
- **D**：**谵妄**（Delirium）：评估、预防和处理。
- **E**：**早期**（Early）活动和锻炼。
- **F**：**家属**（Family）参与和赋能。

在大型观察性研究中，集束依从性越高，死亡率越低、谵妄越少、通气天数越少。
:::

### 撤离机械通气

随着病情好转，每天评估患者是否准备好撤机：导致呼吸衰竭的病因好转、在适度FiO₂和PEEP下氧合充分、血流动力学稳定、能够自主呼吸。**自主呼吸试验（SBT）**通常在低压力支持或T管下进行30–120分钟，检验患者能否应付。如果通过，且能咳嗽和保护气道，即予拔管。

需要长时间通气的患者可能需要**气管切开**，它更舒适，允许更浅的镇静，并使撤机更容易。在英国TracMan试验（2013）中，早期气管切开（4天内）与10天或更晚的气管切开相比，未降低30天死亡率，而且晚期组中许多患者最终并不需要气管切开，因此通常推迟到明确需要长时间通气时再做。

### 其他器官支持

- **心血管**：在超声心动图和心排血量监测指导下使用血管加压药和正性肌力药。
- **肾脏**：血流动力学不稳定的患者使用连续性肾脏替代治疗（血液滤过）；稳定的患者使用间歇性血液透析。
- **呼吸**：严重呼吸衰竭时在专科中心使用**静脉–静脉ECMO**。在英国CESAR试验（2009）中，转诊至ECMO中心提高了6个月时无严重残疾的存活率；国际EOLIA试验（2018）在重度ARDS中未显示60天死亡率有统计学显著差异，尽管结果倾向于ECMO。在英国，ECMO集中在少数指定中心。

### 营养与血糖

危重病导致肌肉迅速丢失，不能进食的患者需要营养支持。**肠内营养**（经鼻胃管）优于肠外营养，通常在患者复苏后24–48小时内开始。最初几天能量目标适中（早期足量喂养可能使结局变差），在第一周内逐步增加；典型目标约为每天20–25 kcal/kg能量和约1.3 g/kg蛋白质，由营养师调整。多日几乎未进食的患者有**再喂养综合征**的风险，表现为磷、钾和镁下降，应缓慢开始，并补充硫胺素、监测电解质。隐性热量也要计算：丙泊酚以脂肪乳剂形式给予，每mL约提供1.1 kcal。

**血糖控制**：应激性高血糖很常见。过去曾推崇非常严格的控制，但NICE-SUGAR试验（2009）纳入6,000多名ICU患者，发现4.5–6.0 mmol/L的目标与10 mmol/L或以下的目标相比提高了死亡率，主要是由于低血糖。目前大多数科室以约6–10 mmol/L为目标。

## 预防重症监护的并发症 {#sec-prevention}

ICU中的许多伤害来自治疗本身。预防它们是日常照护的一部分。

| 并发症 | 预防 |
|---|---|
| **呼吸机相关性肺炎** | 床头抬高30–45°，浅镇静和每日镇静中断，尽早撤机，声门下分泌物引流，口腔护理，避免不必要的再插管 |
| **中心静脉导管相关血流感染** | 置管集束（手卫生、最大无菌屏障、氯己定皮肤消毒、尽可能避免股静脉部位），每日评估是否需要，及时拔除 |
| **导尿管相关尿路感染** | 尽可能不留置导尿管；尽早拔除 |
| **静脉血栓栓塞** | 无禁忌时用低分子量肝素；不能抗凝时用机械性预防 |
| **应激性溃疡出血** | 高危患者（如机械通气者）使用抑酸药；在REVISE试验（2024）中，泮托拉唑减少了机械通气患者具有临床意义的上消化道出血，而不改变死亡率 |
| **压力性损伤** | 定期翻身，减压床垫，营养，皮肤检查 |
| **ICU获得性肌无力** | 浅镇静，早期活动和康复，血糖控制，尽量少用神经肌肉阻滞剂和激素 |
| **抗微生物药物耐药性和艰难梭菌** | 每日复核抗生素，短疗程，根据培养结果降阶梯 |

简单集束的价值在2006年由Peter Pronovost领导、在密歇根州100多个ICU开展的研究中得到证明：以核查表为基础的中心静脉置管项目大幅减少了导管相关血流感染，且效果持久。

::: warning 被遗忘的导管
不再需要的导管、尿管和引流管是可预防感染的主要来源。它们容易被遗忘，因为它们今天并没有造成问题。每一个留置装置都应每天用一个问题来复核：还需要它吗？五天前在急诊科为补液冲击置入的套管，或在已能饮水的患者身上为“严格记录液体平衡”而保留的导尿管，都是只有风险没有获益。
:::

## 患者与家属 {#def-person}

危重患者通常无法参与决策，他们的家属往往惊恐而疲惫。良好的沟通是重症监护的核心临床技能。

::: definition 共同决策与限时试验 {#def-tlt}
对缺乏决策能力的患者作出维持生命治疗的决定时，应以患者的**最佳利益**为准（在英格兰和威尔士依据《2005年心智能力法》），即考虑患者本人会想要什么，征询其亲近之人以及持有健康与福利持久授权书者的意见，并尊重任何有效的**拒绝治疗预先决定**。临床医生没有义务提供他们判断不会带来整体获益的治疗。**限时试验**是一项约定：在规定时间内提供全面支持，设定明确目标并计划复审，之后如果治疗有效就继续，无效就撤除。
:::

向家属通报情况最好通过定期、有计划的会面，由高年资医生和床旁护士在安静的房间进行：先询问他们已经了解什么，用通俗语言提供信息，承认不确定性和情绪，并商定下一步。**ICU日记**由工作人员和家属在住院期间撰写，帮助患者日后理解记忆中的空白，在一些研究中与较少的创伤后应激相关。

当治疗已不能实现患者所珍视的康复时，重点转向舒适。有计划地撤除维持生命的治疗（血管加压药、通气、透析），处理气促、痛苦和分泌物等症状，并支持家属。撤除无益的治疗与不开始这种治疗在伦理和法律上是等同的。

### 器官捐献

许多器官捐献者在重症监护中死亡。捐献可以在**依神经学标准确认死亡**（脑干死亡）之后进行，也可以在有计划地撤除治疗后的**循环死亡**之后进行。在英国，每一位潜在捐献者都应被识别并转介给英国国家医疗服务体系血液与移植机构（NHS Blood and Transplant）的专科护士，由其主导与家属的谈话。英国各地区现在都实行选择退出（“视为同意”）制度：威尔士自2015年起，英格兰自2020年起，苏格兰自2021年起，北爱尔兰自2023年起。家属始终参与其中，撤除治疗的决定与任何关于捐献的讨论分开进行，并且先于后者。

## 重症监护之后 {#sec-recovery}

存活并不是故事的结局。许多存活者有**重症监护后综合征（PICS）**：新出现或加重的躯体问题（肌无力、疲劳、气促、疼痛）、认知损害（记忆、注意力、执行功能）以及心理问题（焦虑、抑郁、创伤后应激障碍）。家属也可能出现心理症状（“家属PICS”）。康复可能需要数月或数年，有些患者再也无法重返工作。

NICE指南CG83（危重病后康复，2009）建议：在ICU住院期间评估患者发生躯体和非躯体问题的风险，制订个体化康复计划，出院前进行评估，并在转出重症监护后2–3个月进行随访评估。许多科室开设随访门诊和同伴支持小组。

转出后再次入住ICU与高死亡率相关。危险因素包括夜间转出、生理状态仍不稳定时转出、转出时SOFA评分高以及多种合并症。重症监护外展团队在患者转回病房后继续随访，以便尽早发现病情恶化。

## 实例分析

::: example 有治疗上限的机械通气老奶奶 {#ex-ceiling}
一名84岁女性患中度痴呆（临床衰弱量表6级），住在养老院，因重症肺炎和Ⅰ型呼吸衰竭入院。她正在接受经鼻高流量氧疗，FiO₂ 0.7时SpO₂ 90%。她的儿子要求“尽一切努力”。团队应如何处理是否进行有创通气的决定？
::: solution
这是一个最佳利益判断，因为她现在无法参与决定。

1. **获益可能性**：她的衰弱、痴呆和重症肺炎意味着有创通气会带来很高的死亡风险，存活者也有进一步丧失功能的高风险。这本身并不决定问题，但必须坦诚说明。
2. **她的意愿和价值观**：询问她的儿子和养老院，她曾经怎样谈论住院治疗、什么对她重要。查看有无预先照护计划、ReSPECT表格、预先决定或持久授权书。
3. **插管以外的选择**：在病房或2级区域继续经鼻高流量氧疗或无创支持、抗生素、物理治疗、症状控制，以插管为不逾越的上限。
4. **沟通**：高年资医生解释，凡是能帮助她的都会“尽一切努力”去做，团队会继续积极治疗，但插管不太可能帮助她恢复到她所珍视的生活，反而可能带来痛苦。临床医生没有义务提供不符合她最佳利益的治疗，但应寻求共识，在有分歧时提供第二意见，并记录讨论。

清晰的计划可以使她免于凌晨三点的危机决策。
:::
:::

::: example 可预防的三分之一住院时间 {#ex-bundle}
一名45岁男性因肺炎接受机械通气。第4天，他的氧合已改善（FiO₂ 0.35，PEEP 5），但他在咪达唑仑输注下处于深镇静（RASS −4），从未做过自主呼吸试验，也没有下过床。ABCDEF集束会带来哪些改变？
::: solution
- **A**：用经验证的工具评估疼痛并治疗，镇痛优先。
- **B**：今天进行**自主唤醒试验**（停止或减少镇静），如果他清醒且呼吸充分，随后进行**自主呼吸试验**。他符合撤机的基本标准。
- **C**：把镇静药从咪达唑仑（一种苯二氮䓬类，与谵妄和通气延长相关，且在体内蓄积）换为丙泊酚或右美托咪定的浅镇静（如仍需镇静），以RASS 0到−1为目标。
- **D**：一旦能唤醒，用CAM-ICU筛查谵妄并处理病因。
- **E**：由物理治疗师进行早期活动：坐在床沿、站立，安全时行走，即使仍在机械通气。
- **F**：让家属参与重新定向和目标制订。

无明确理由的深镇静是通气时间比必要时间长出数天的主要原因之一。
:::
:::

::: example 留置未拔的导管 {#ex-line}
一名51岁女性因胰腺炎入住ICU，第9天出现发热（38.9 °C）、寒战和低血压。她有一根第1天置入的股静脉中心静脉导管和一根导尿管。腹部情况无变化。可能的感染源是什么？应该怎么办？
::: solution
很可能是**中心静脉导管相关血流感染**：导管已留置9天，位于股静脉（感染风险较高），突然出现发热、寒战和低血压。其他可能包括感染性胰腺坏死、呼吸机相关性肺炎（如果在机械通气）、尿路感染和艰难梭菌感染。

1. 复苏并按脓毒性休克治疗。
2. **经导管和外周分别采集血培养**，并采集其他部位的培养。
3. **拔除导管**（如需要，在另一部位重新置管），导管尖端送培养。
4. 按本地指南开始覆盖皮肤菌（包括MRSA）和革兰阴性菌的经验性抗生素；培养结果回报后收窄。金黄色葡萄球菌菌血症需要超声心动图检查和延长疗程。
5. 复查导管为何仍在原处，以及科室的导管护理集束。
:::
:::

::: example 可以预见的再入住 {#ex-readmission}
一名70岁慢阻肺男性因肺炎机械通气，第6天23:30因ICU需要床位被转到呼吸科病房。他的呼吸频率26次/分，咳嗽无力，痰液黏稠。两天后他因呼吸衰竭再次入住ICU。本可以怎样做得不同？
::: solution
存在几个已知的再入住危险因素：**夜间**转出、转出时**呼吸频率**升高、近期拔管后**咳嗽无力**伴分泌物，以及慢性肺病。预防措施包括：尽可能推迟到白天转出（或把床位压力上报给管理者，而不是在夜间转移高危患者）；向病房团队进行有明确计划和治疗上限的结构化交接；胸部物理治疗和分泌物清除计划（可能需要NIV或咳嗽辅助）；以及转出后数小时内由**重症监护外展**团队评估并定期随访。夜间转出和过早转出是系统问题，应当审计。
:::
:::

::: quiz
关于危重成人的血糖控制，NICE-SUGAR试验支持下列哪一项？
- [ ] 所有ICU患者的血糖都应保持在4.5–6.0 mmol/L。
- [x] 10 mmol/L或以下的目标比4.5–6.0 mmol/L的严格目标死亡率更低。
- [ ] ICU中应避免使用胰岛素。
- [ ] ICU中的高血糖无需治疗。
::: solution
NICE-SUGAR（2009）发现强化血糖控制的死亡率更高，主要是由于低血糖。目前大多数科室以约6–10 mmol/L为目标，用胰岛素治疗高血糖，但避免两个极端。
:::
:::

::: history
现代ICU源于1952年哥本哈根脊髓灰质炎流行。当时麻醉医生易卜生（Bjørn Ibsen）证明，呼吸肌麻痹患者可以通过气管切开和手动正压通气维持生命，由一队队医学生昼夜轮流施行。把这类患者集中在一个区域、给予持续的护理和医疗照护，成为重症监护病房的模式，并在20世纪50和60年代传遍欧洲和北美。曾在巴尔的摩从事复苏研究的Peter Safar于1958年在美国建立了最早由医生值守的ICU之一。在英国，随着2010年重症医学学院的成立，重症医学成为一个独立专科。20世纪90年代以来的大型随机试验——其中许多由英国、澳大利亚、新西兰和加拿大的试验协作组主导——一再表明，少做（更低的潮气量、更浅的镇静、更宽松的血糖控制、更少的输血）往往更好。
:::

## 后续内容

休克和液体治疗见[[emergency-critical-care/shock-fluids]]；通气见[[emergency-critical-care/airway-ventilation]]；心脏骤停后的救治见[[emergency-critical-care/resuscitation]]。急性肾损伤见[[renal/acute-kidney-injury]]，脓毒症见[[infectious-diseases/fever-sepsis]]，医院获得性感染见[[infectious-diseases/healthcare-infections]]，营养见[[gastrointestinal/clinical-nutrition]]，撤除治疗和器官捐献的伦理与法律见[[medical-ethics-law/end-of-life-ethics]]。

::: summary
- 重症监护按支持级别（0–3级）组织。收治需权衡可逆性、衰弱程度和患者意愿；限时试验和治疗上限都是合理的选择。
- Sepsis-3：脓毒症是伴器官功能障碍的感染（SOFA升高2分或以上）；脓毒性休克需要血管加压药维持MAP 65 mmHg，且乳酸高于2 mmol/L。
- 镇痛优先，浅镇静（RASS 0到−2），避免苯二氮䓬类，筛查谵妄（CAM-ICU），实施ABCDEF集束。
- 每日自主唤醒和呼吸试验可缩短通气时间；气管切开通常推迟进行（TracMan）。
- 尽早肠内喂养，初始目标适中，警惕再喂养综合征，血糖保持在约6–10 mmol/L（NICE-SUGAR）。
- 用简单的日常集束预防呼吸机相关性肺炎、导管感染、静脉血栓栓塞、应激性溃疡出血、压力性损伤和肌无力；拔除不再需要的导管。
- 尽早并定期与家属沟通；撤除无益的治疗，提供良好的临终照护，并转介潜在的器官捐献者。
- 存活者常有重症监护后综合征；随访和康复是重症监护的一部分（NICE CG83）。
:::

## 习题

::: exercise PaO₂/FiO₂比值 {level=1 check="20"}
一名机械通气患者FiO₂ 0.4时PaO₂为8 kPa。计算PaO₂/FiO₂比值（kPa）。
::: solution
$8 / 0.4 = 20$ kPa（约150 mmHg）。如果他在接受呼吸支持，SOFA评分为3分（低于200 mmHg）；若其他标准也满足，则按柏林标准相当于中度ARDS。
:::
:::

::: exercise 隐性热量 {level=1 check="528"}
一名患者以20 mL/h输注1%丙泊酚24小时。若脂肪乳载体每mL提供1.1 kcal，丙泊酚每天提供多少kcal？
::: solution
每日体积$= 20 \times 24 = 480$ mL。能量$= 480 \times 1.1 = 528$ kcal。这在能量目标中占相当大的比例，开具营养医嘱时应计算在内，以免过度喂养。
:::
:::

::: exercise 一次SOFA评分 {level=2 check="9"}
一名机械通气患者PaO₂/FiO₂ 250 mmHg，血小板45 × 10⁹/L，胆红素18 µmol/L，未用血管加压药时MAP 66 mmHg，镇静前GCS 15，肌酐320 µmol/L。计算SOFA评分。
::: solution
呼吸：250低于300，**2**分。凝血：45低于50，**3**分。肝脏：18低于20，**0**分。心血管：未用血管加压药时MAP低于70，**1**分。中枢神经：**0**分。肾脏：320在300–440之间，**3**分。总分$2 + 3 + 0 + 1 + 0 + 3 = 9$。
:::
:::

::: exercise 开始营养支持 {level=1}
一名70 kg男性因肺炎机械通气第2天。他在低剂量去甲肾上腺素下血流动力学稳定，胃肠功能正常。入院前一周他几乎未进食。概述他的营养计划。
::: solution
在24–48小时内经鼻胃管开始**肠内营养**，以适中速率开始，数天内逐步增加到约每天20–25 kcal/kg（约1,400–1,750 kcal）的目标，蛋白质约每天1.3 g/kg（约90 g），由营养师调整。由于他一周几乎未进食，有**再喂养综合征**的风险：给予硫胺素，缓慢开始，每天检查磷、钾和镁并按需补充。如在使用丙泊酚，应计算其热量。监测胃耐受情况、血糖（目标约6–10 mmol/L）和排便。
:::
:::

::: exercise 筛查谵妄 {level=2}
第5天，一名机械通气女性平静地睁眼躺着（RASS 0）。让她在听到一串十个字母中的字母“A”时捏护士的手，她出错六次。护士说她昨天更清醒些。按CAM-ICU她是否有谵妄？应该怎么办？
::: solution
特征1（急性变化或病程波动）存在：与昨天相比她的精神状态有波动。特征2（注意力不集中）存在：注意力测试出错超过两次。特征3（意识水平改变）不存在，因为她的RASS为0，所以需要用简单的是非问题和一个指令测试特征4（思维紊乱）。如果出错超过一次，她就是**CAM-ICU阳性**：她有**低活动型谵妄**。寻找病因（感染、代谢紊乱、药物、疼痛、睡眠剥夺），减少镇静药和抗胆碱能药物，采用非药物措施（定向、眼镜和助听器、活动、睡眠、家属探视）。安静型谵妄不需要使用抗精神病药。
:::
:::

::: exercise 气管切开还是不切开？ {level=2}
因重症肺炎机械通气第3天，一名58岁男性的家属问是否应该现在就做气管切开，“早做完早了事”。证据怎么说？
::: solution
TracMan试验发现，早期气管切开（4天内）与10天或更晚的气管切开相比并未降低死亡率，而且晚期组中许多患者未经气管切开就成功拔管。气管切开是有风险的操作，因此通常的做法是继续每日镇静中断和呼吸试验，在明确需要长时间通气或撤机反复失败时再做气管切开。解释这一思路有助于家属理解，等待是一个主动的决定，而不是拖延。
:::
:::

::: exercise 主持家属会议 {level=3}
一名62岁男性在心脏骤停继发多器官衰竭后已在ICU住了3周。神经学评估显示严重的缺氧性脑损伤，没有实现有意义恢复的可能。他的妻子和两个女儿相信他是“一个斗士”。规划这次家属会议。
::: solution
会前：高年资医生复核全部信息并与同事商定计划（包括请另一位顾问医生对预后给出第二意见）；安静的房间，床旁护士在场，留出足够时间，如需要安排翻译。

会中：相互介绍；询问他们了解什么、注意到了什么；先预告消息很严重；用清楚、不带术语的语言解释：他心跳停止时大脑受到了严重损伤，有哪些检查显示了这一点，他不会醒来认出她们或与她们交流。停顿，允许情绪流露。询问他珍视什么、在这种情况下他会想要什么，把决定表述为团队基于他最佳利益的建议，而不是压在家属身上的负担。解释不能帮助他的治疗将被撤除，他的舒适将是首要任务，她们可以陪在他身边。只有在撤除治疗的决定被理解之后，才由专科护士或与其一起提出器官捐献。商定下一步并确认理解。

会后：记录谈话，支持工作人员，并为家属提供丧亲支持。
:::
:::

::: exercise 运营外展服务 {level=3}
一个外展团队被要求减少转出后48小时内非计划性再入住ICU的情况。根据你对危险因素的了解，提出三项措施和一种衡量其效果的方法。
::: solution
1. **避免高风险转出**：停止非紧急的夜间转出，以及仍符合“未准备好”标准（NEWS2升高、呼吸频率快、咳嗽无力伴分泌物、近期拔管）的患者的转出，改为把床位压力上报给管理者。
2. **结构化交接和随访**：向病房提供包含治疗计划和照护上限的书面及口头交接，并在转出后4–6小时内由外展团队评估，之后48小时内每天评估。
3. **病房支持**：开展早期预警评分和升级处理的培训，并让有分泌物问题的患者能迅速获得物理治疗。

每月衡量48小时再入住率（以及再入住后的死亡率），用运行图观察随时间的变化，并对每一例再入住进行审计，找出是哪项措施失效。
:::
:::
