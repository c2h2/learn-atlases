重症监护室是医院关于“死亡值得工程投入”的论点：一名护士对一至两名患者、按时刻表支持器官、及一套完整到该专科自身的疾病——谵妄、无力、重症后综合征、家属的创伤记忆——必须被命名然后再被拆开的监测技术。**本章讲述现代ICU的组织与入院逻辑（分级重症照护层与外展、入院-升级-分诊决定及其记录）、比任何监测仪都更决定结局的日常实践（ABCDEF时代的组套：镇痛优先镇静与每日中断、自主呼吸试验、早期活动、谵妄筛查与预防、睡眠与营养及血糖、及导管与管道及压疮及血栓的伤害预防组套）、带其指征与伦理天花板的器官支持菜单（通气、升压药与机械循环、肾替代、及升级到难治的决定）、沟通与以家庭为核心的机器（每日通报节奏、家庭会议、ICU日记、及重症后综合征的长尾）、及该专科最难的胜任力——识别支持何时变成了延续、并领导好那场谈话。**

## 病房

::: definition ICU是什么：层级、入院与每日查房 {#def-unit}
**结构（分级重症照护医学：0级病房伴基本监测与外展及预警评分（NEWS族评分及其证据基础与“评分触发复查而不是安心”的实施科学）、1级降阶与HDU伴单器官支持或近期撤机患者、2级单元伴无创通气与升压药邻近中间照护（“我们需要一张在病房与ICU之间的床”问题——欧洲以不同方式解决而美国叫“渐进照护”）、及2个以上器官支持与专科功能的3级ICU——心脏骤停与ECMO及移植及神经重症及烧伤及儿科与新生儿邻近三级模式、带网络与转运医学如今通过电话与召回服务安排而不是跑遍医院）；入院与升级三位一体“什么可逆而什么治疗天花板”谈话由ICU顾问与转诊团队进行并记录在每日重访的治疗限制或升级计划中（CPR与ICU入院决定分开而不打包——ICU培训以其为反面定义的“一个病房的天花板”谬误）、及稀缺中的分诊诚实（激增能力规划与带“最大化被救生命不是先到先得”逻辑的重症分诊规程、在各国疫情教训中公布、及由伦理委员会而不是夜班直觉审查的残障与可逆性标准）、及最佳单元每日查房的实际内容（每个器官支持杠杆的带撤机计划与停止日期的系统复查、液体平衡、通气患者48小时内开始营养、及在严格控制时代低血糖修正试验后8-10 mmol/L的血糖目标、及深静脉血栓与应激溃疡及压疮及导管护理由组套作为一张签署的清单——因为组套就是医院获得性伤害居住之处、及按ICU规程每天筛查的谵妄——听起来官僚而是可获得的最以患者为中心的行为）；监测（动脉置管与中心静脉及无创超声心动及其他动脉波形心输出量设备及尿量、及ICU对数字的诚实立场（病房教的、而ICU因数字每秒到来而将其完善的“先治患者再治数字”文化）、及床旁超声作为ICU医师听诊器时代——肺与膀胱及下腔静脉及心脏视图在检验返回之前改变了呼吸机与液体决定、及仍滞后的培训科学文献）；及ICU自身并发症清单，查房与之每日作战导管脓毒症与照护组套针对的呼吸机相关事件、导管与约束及丙泊酚耐受与戒断、使十日住院变成轮椅的重症性多发性神经病与肌病、没有药物能预防的谵妄、及主要减少它的光与噪音及定向与睡眠及家属在场及昼夜及助听器与眼镜及早期活动的组套、及员工道德困扰——如今单元把它当作一个安全变量：死亡后的复盘与在疫情证明它们不人性化之前本来就人性化的排班。**
:::

## 实践

## 人

::: definition 沟通、不确定性与ICU中的生命尽头 {#def-person}
**家属作为第二患者（由负责医师用大白话定时的每日通报、不是短信值班也不是语音留言、及开放ICU探视时间证据——在多数国家结束了关门时代除非感染控制压倒、及由护士领导讲她们看到什么的家庭会议、因为在每种文化的研究中护士是最先知道患者将要死亡的人、及“预后判断是一个概率不是一个判决”的诚实带结局研究警诫：ICU预测因子是人群陈述、及一代重症医师在看到那位“不可能撤机”的邻居撤机后学到的80%谨慎规则）；照护目标谈话架构（严重疾病谈话框架与各训练改编的2010年代姑息重症文献：“我们知道什么、希望什么、担心什么、对他们什么要紧”语法、及作为伦理工具的限时强化治疗试验（“我们将给这个器官支持一个界定的窗口并按诚实终点复查”）、及代理决定标准层级（替代判断、最佳利益、其人先前的价值观）、及生命尽头实践国际调查记录的法律多元主义：有约束力对咨询性预嘱的区分、医师决定对家庭共识文化、及撤除对不启动的等同性——每个法律体系都确认而每个受训者直到第一次仍觉得抽象）；ICU中死亡医学为死亡拔管规程伴注射泵吗啡与咪达唑仑及分泌物与流涎处理及温和气流、及拔管前夹管之辩——里程碑试验显示无差异、及ICU姑息照护伙伴模式、及器官捐献接口（脑死亡与马斯特里赫特III类标准邻近流程、及把复苏从转荐从谈话分开的防火墙——它保护家属的信任也保护移植规划、及多数国家已完成的登记与退出法变更——这将谈话变成关于他们已经决定的事）；长尾门诊（覆盖ICU获得性无力的康复医学与认知康复（缺氧与镇静及谵妄与脓毒症的前额与记忆缺陷）、及创伤后应激与焦虑及照护者负担筛查、及“我为何如此疲惫”“我为何记不起那个月”的正常化带计划、及ECMO与气管切开及ARDS生存者邻近的生存者与家属支持小组——其成员是组套只在有人检查患者走出去时才起作用的最好证据）；及数据与问责层带严重度校正死亡率与标化死亡比的审计及患者安全邻近、及“漏斗图不证明胜任或不胜任而引发谈话”的文化、及反复建议的国家重症审计报告——48小时内营养、谵妄筛查、家属在场、随访门诊、及诚实的升级天花板——是本章阅读清单的清单形式。**

::: example 带天花板的通气祖母 {#ex-ceiling}
84岁、两个升压药下呼吸机治疗肺炎脓毒症第3天、女儿报告“她说过从不想插管”；无书面预嘱；团队分裂在“她可能好转”与“我们在折磨她”之间。
::: solution
**天花板对悬崖（[[#def-unit]]、[[#def-person]]、[[medical-ethics-law/end-of-life-ethics]]）：工具——旧的口头陈述在英格兰与威尔士不是拒绝治疗的有法律约束力预嘱（针对特定治疗的要求与“非情形”适用性检验）、但它是价值观的有力证据、而最佳利益决定有义务权衡它；及未被公证的次要证据：儿子与女儿陈述的差异及既往住院拒绝、及“她讨厌她母亲的死亡方式”背景——定性研究说它与文件同等要紧；流程——目标照护会议：ICU顾问与认识她的护士及所有代表同时在真实的电话上或在同一个房间（不是三次走廊谈话变成三个故事）、使用“我们知道-希望-担心-及若能告诉她什么要紧”语法、及若轨迹真的模棱则限时试验提议（另24-48小时全支持带明确终点：升压药需求、乳酸、胸部、肾脏）、及保住信任的诚实不确定句（“我不能保证她恢复；我能保证不会无缘无故地对她做她害怕的事）；决定及其所有权——若团队在窗口后的观点是继续通气无法被辩护、那么撤除是一个医学决定、不是家属的许可或过错、及同样的记录流程在某些辖区包括第二意见与通知顾问、及带尊严执行的姑息拔管规程及若愿意家属在场及资深护士与牧师及ICU日记提供、及给从未主导过这场谈话的初级的复盘——胜任力就是这样买来的；及审计痕迹——治疗天花板复查记录带时间戳附件文档、下次它就成了保护包括她在内所有人的记录。**

::: example 可预防的三分之一住院 {#ex-bundle}
39岁多发伤ICU住院：因呼吸机相关肺炎到第12天、因股静脉导管长出念珠菌到第18天、因连续镇静七天未试验后“瘫倒”且不能吞咽到第25天；家属靠短信被通报。
::: solution
**组套尸检（[[#def-unit]]、[[#def-support]]、[[clinical-skills/patient-safety]]）：伤害与其组套——呼吸机相关肺炎预防集群（床头抬高与口腔护理及声门下吸引邻近文化、及每日镇静中断伴自主呼吸试验筛查）；中心静脉组套（带最大化屏障与氯己定的置入核查表、及每次查房上“这根导管还需要吗”行——本单元打印了却没签）、及本应在镇静减浅而不是第25天拔管时做的吞咽筛查；及谵妄-活动-营养的逐日缺席——病历里没有ICU意识模糊评估法筛查、第3天后没有理疗、医师记录里没讨论肠内营养——这不是三个疏忽而是一个文化：“她镇静着所以今天是一无所事日的天”、ABCDEF的存在就是为杀死它；及作为临床失败的沟通——短信通报不是恶意只是容量崩塌、而每份家属调查与每卷投诉档案都说同一句：我们不知道发生了什么而我们不在房间里；修复是指定的每日家庭通报带具名医师、是每天一小时顾问时间、比一次投诉、一本创伤ICU日记、一场诉讼都便宜、也比让护士在沉默与恐惧之间翻译的道德损伤便宜得多；及单元级行动——由护士拥有核查表的组套合规审计及给重症治理会议的每周“错过组套日”报告、因为在多数规划中呼吸机相关肺炎与导管脓毒症是邻近警示的永不事件、而重复发生的是流程不是人。**

::: example 留着的导管 {#ex-line}
ICU第8天：通气患者发热骤升；第1天凌晨2点在急诊条件下置入的颈内静脉中心导管“仍需用于去甲肾上腺素撤离”、置入核查表“大致做了”、而护理组已两次旗标穿刺点发红。导管与外周血培养均生长凝固酶阴性葡萄球菌。
::: solution
**作为查房条目的导管相关血流感染（[[#def-unit]]、[[microbiology/infection-control]]、[[clinical-skills/patient-safety]]）：解读——导管感染是一个诊断加预防失败合体：微生物（皮肤共生凝固酶阴性菌带导管对比阳性时间或定量配对培养逻辑区分污染与真感染）与病灶搜寻（出口处、隧道、持续菌血症中的心脏瓣膜之问、“只是一根导管”会漏掉的脓毒性血栓性静脉炎与心内膜炎）；处理——依微生物与严重度移除或至少经导丝交换并送 tip、抗生素剂量与疗程匹配复杂对非复杂菌血症（金黄色葡萄球菌自动4-6周及超声及转移种植之辩对凝固酶阴性菌拔管常治愈逻辑）、及现在执行导管必要性审计、因为去甲肾上腺素只有0.04微克而有一个白昼团队从未认真考虑的外周选项；组套取证——急诊置入“大致做了”的核查表（最大化屏障与超声及氯己定及手卫生要素在病历中逐项列：跳过了哪些步骤、谁觉得不能喊停）、及两次旗标却未引发行动的发红出口处——升级层级发现：护理关闭一根导管关出的生命多于任何抗生素政策；及单元级修复——印在查房核查表上的每日“这根导管需要存在吗”之问伴授权护理人员移除符合移除标准者、及记录停止权力的置入核查表、因为导管感染率是一个只有当核查表变成文化而不是装饰时才移动结局的经典例子、及把本例多出的14天反馈给拥有规程的群体。**

::: example 可预测的再入院 {#ex-readmission}
67岁通气6天后拔管、“因ICU降阶床位已满转回病房”；病房第2天NEWS 11、当班团队拒绝“她是ICU-适合出院的”、凌晨4点她因痰栓骤停。
::: solution
**降阶是一个服务不是一条走廊（[[#def-unit]]）：失败链——出口标准之问（ICU-适合意味着ICU级观察或没有：一个咳嗽无力与近期镇静及分泌物的患者是一个需要神经观察的2级患者、而“没有的”那张床就是整个案件）、交接作为技术（“她ICU-适合出院”这句话就是恶化文献所称的默认降级——给员工一个状态不是一个计划）、及下午茶时NEWS 11谁复查了她——才是骤停的真正原因（评分到应答延迟审计及“护士能不能叫醒医师”层级之问）；痰栓的医学——吸引与再插管及ICU再收住、24小时骤停后复审会把它框为用三件工具可预防：随转科记录附上“凌晨3点分泌物增多怎么办”的书面升级计划、外展团队每日查房把近期降阶者作为具名清单覆盖、及带公布的资助的进出标准的可降阶HDU或2级——因为“ICU或病房”二元系统恰好制造骤停；及人与系统的善后——在坦承职责下诚实更新家属（伤害有名字而复审有日期）、员工复盘、因为一次“困难出院”后的凌晨4点骤停正是道德损伤复利之处、及72小时内再入院指标带趋势线进治理会议、因为医院的骤停率与其降阶设计是一个数字不是两个。**

一名通气55岁多发伤患者在第30小时到达、无禁忌、低剂量去甲肾上腺素。开营养路径与血糖目标、及各自取代的两个错误。
::: solution
**早喂养、温和设目标（[[#def-unit]]）：处方——在24-48小时内为无休克抵抗、无肠道禁忌、无开腹限制的通气患者开始肠内营养（点滴到滋养型到全量的推进、胃残余量的模糊由体位与促动力之辩管理而不在100毫升就停喂、营养师拥有的规程、胃不耐受者放鼻空肠管、及按指南对不工作的肠在3-7天内给胃肠外营养、记住早期胃肠外营养的导管脓毒症与高血糖代价）；血糖目标——共识的8-10 mmol/L（144-180 mg/dL）、持续高血糖用胰岛素输注、及低血糖规避算法、因为NICE-SUGAR（2009）显示严格的4.5-6.0目标增加死亡率——重症监护最被修正的正统之一、如今作为每个“越低越好”代谢数字的警世故事教授；被取代的两个错误——出于谨慎饿着患者（萎缩的肠与营养不良买来的通气日）及对8的滑动量表恐惧（按遗产目标滴定的胰岛素泵由低血糖的大脑付账）、及再喂养的低磷与硫胺素及镁监测——营养规程第一页应带着它、因为在单元第二页才会被读到。**
:::

::: exercise 决定气管切开 {level=2}
第14天通气的ARDS生存者、清醒、遵嘱、咳嗽无力、有分泌物、对“根管子”焦虑；家属问这是否“意味着她在死去”。给出会诊与谈话。
::: solution
**气管切开是一个舒适与撤机决定（[[#def-support]]、[[#def-person]]）：决定——第10至21天气管切开之问、试验显示无死亡率差异而在某些研究中对通气日与镇静及ICU时长有真实效应、患者报告结局中对舒适与沟通有真实效应（“撤机促进”逻辑：更少镇静的更安全气道、口腔护理、说话瓣膜邻近选项、及早期对晚期切开的荟萃分析从未证明救命、这就是为何时机是与团队及家属共同做的判断）；对家属的诚实回答——这根管不是她要死的征象；它是我们让她更快离开呼吸机和这张床的方式、在多数人它是暂时的、有拔管路径与言语治疗计划、及这段延迟使没人问过“她要什么、她怕什么”之问；实际的——经皮或外科伴ICU麻醉与外科协作、及术后第1天沟通板与呼叫铃邻近辅助沟通、因为“她两周不能交流”是生存者报告的最常见悔恨、及在拔管前开始的造口护理教学计划、及驾驶与复工及随访门诊之问、及气管切开局部问题规程（整个夜班团队需要的意外脱管演练就像抢救团队需要骤停演练一样）；及底层要点——你在一年时见到的ARDS生存者逐周记得ICU而最鲜明的就是那根管子——这是呼吸机参数从不显示的结局指标、也是“她今天能说话、能被扶着走吗”是ICU质量标准的原因。**
:::

::: exercise 处理ECMO目的地之问 {level=2}
34岁流感后ARDS在ECMO第11天（在你的回答中澄清模式）、无撤机进展、本地无移植挂榜、抗凝下胸壁出血。团队争论“再多一周”。结构化这个决定。
::: solution
**ECMO需要一个目的地（[[#def-support]]、[[#def-person]]、[[medical-ethics-law/end-of-life-ethics]]）：先语法——静脉-静脉ECMO为低氧性呼吸衰竭买来肺恢复（或移植）的时间、其决策树是肺恢复轨迹对移植桥对决定桥；静脉-动脉支持循环（心源性休克、心肌炎、肺栓塞）带自身左室减压与灌注并发症——正确命名模式是论证的前提；临床复审——第11天的肺诚实评估（顺应性与影像对纤维化期ARDS及俯卧战役及神经肌肉阻滞邻近病史及继发感染、及作为抗凝代价的胸壁出血——ECMO就是这样计分的）、及ECMO网络规程在决策点要求的标准化多学科与第二中心意见通知流程（“再多一周”只有带具名终点时才是医学）；目的地检验——可能恢复则继续并列里程碑/可能移植则为挂榜转诊并诚实地做社会与适格评估、或桥至决定带限时窗口及与家属书面议定的终点/无目的地——则诚实谈话：撤离ECMO是一个邻近姑息拔管的计划、带全镇静与症状医学、而团队把这次死亡支持为一个医学决定不是机器故障——这正是ECMO规划进行并在其伦理文献中发表的那场谈话、因为除非有人做语言工作、泵会让死亡看起来像拔插头；及任一路径的善后——ICU日记与家属在场政策及员工复盘、因为ECMO死亡病例制造使重症医师离开的“我们做了吗我们该吗”道德困扰、及带登记基准的规划复审、因为登记数据就是个体目的地了解自家曲线所在之处。**

::: exercise 建设重症后综合征服务 {level=3}
你的ICU让患者很好地活下来：18个月随访显示一半有功能受限、三分之一有创伤后应激或抑郁症状、家属带着自身的创伤评分、而不存在门诊。写商业论证。
::: solution
**重症后门诊（[[#def-unit]]、[[#def-support]]、[[public-health/health-systems-economics]]）：证据框架——重症后综合征文献（2009共识声明与医学研究所报告及随访队列研究）：带康复需求的ICU获得性躯体无力、执行与记忆域的认知损害、及生存者20-50%比例的焦虑-抑郁-创伤后应激心理疾病（依队列）、加家属版本带与生存者相当的创伤后应激率；服务规范——出院后2-6个月由专科护士与顾问主导的门诊带：躯体评估6分钟步行与手握力及肌力评分伴康复与理疗作业转诊路径、及疲劳与呼吸困难调查邻近临床推理（ICU入院揭开的漏诊心衰与慢阻肺及糖尿病是反复出现的随访发现）、认知筛查（认知评估量表或神经心理测验伴康复与驾驶及复工咨询、经济论证就住在这里）、心理筛查（带等价创伤后应激路径的工具（创伤聚焦认知行为治疗与眼动脱敏再处理路径）及家属成员筛查——是门诊最便宜的行为）、“一个电话与一个具名门诊”原则、及ICU日记复诊让生存者与家属和解ICU那个月——北欧与英国日记研究显示那是治疗性工作；钱——避免的再入院与急诊就诊（随访门诊前后研究）、来自北欧与澳大利亚残障医学文献的就业回归与福利退出论证、及随访而非失去家属时避免的投诉与索赔和解、及人力留存要点（看到生存者康复的员工会留下）带按每次ICU入院建模的成本对照每位生存者每年省一张床日；及问责——带生存者与家属体验引述的年度重症后报告给董事会——因为ICU对“它把谁落在身后”的唯一关键指标就是一间门诊、而你那间还不存在。**

## 通向何处

呼吸机力学在[[emergency-critical-care/airway-ventilation]]、休克与血管活性药在[[emergency-critical-care/shock-fluids]]、谵妄预防与处理在[[geriatrics-palliative/delirium-dementia-care]]、姑息接口在[[geriatrics-palliative/end-of-life-care]]与[[medical-ethics-law/end-of-life-ethics]]、脓毒症在[[infectious-diseases/fever-sepsis]]、及器官特异性重症在[[respiratory/respiratory-failure]]与[[renal/acute-kidney-injury]]。

::: history
**重症监护由一场流行病和一场战争发明。第一次世界大战的休克与呼吸伤产生了Cushing的术后“医院中的医院”、而1919-20脊髓灰质炎流行产生了铁肺；1952-53哥本哈根脊髓灰质炎流行——Bjørn Ibsen等人用医学生与家庭主妇昼夜手动通气瘫痪患者、把病死率从约90%降到40%——是该专科公认的新生、因为它证明长期人工呼吸可以被组织为一个单元而不是一次临时拼凑。伊丽莎白女王医院的脊髓灰质炎单元与Birmingham、及Florence Nightingale的先见笔记（她在几十年前把病房描述为一个重症照护空间）、及为它配备的麻醉师、连同美国的铁肺病房——国家基金会病房与呼吸器及后来的坦克呼吸机世代记忆——把该模式带过1950年代。然后监测使它成为一门医学而不只是护理壮举：Bjørk与Swan及Ganz的导管在1970年代把循环带到室内、呼气末正压与血气分析带来肺、及肾替代与胃肠外营养的成长使多器官支持可想象；1960年代首批冠心与外科ICU（Belfast与Kansas City的存在及休克病房谱系）并入综合ICU。1990年代开启审计时代——急性生理学与慢性健康及器官衰竭评分、首批标化死亡比联赛表（1993年美国医保ICU报告实验、在其医院级死亡率预测被证明极不精确后废弃、这是其后每张联赛表都必须重学的一课）、及英国与澳大利亚及新西兰的数据系统。2000年代带来改变实践的临床：急性呼吸窘迫综合征的低潮气量通气（2000）、早期目标导向治疗潮流及其后来对照试验的修正（在2014-19年后）、严格血糖控制的反转（2009）、俯卧生存信号（2013）、镇静与活动试验、及2016年脓毒症重定义；及伤害发现——1960年代“ICU精神病”被改名并测量为谵妄、1990年代的ICU获得性无力文献、及重症后综合征与家属版本（2009-2011共识声明与研究所报告）迫使该领域把成功定义为患者变成什么人、而不只是器官是否被支持。伦理主线并行：1976年Karen Ann Quinlan案与委员会时代的撤除支持法理、英国的Bland（1993）及后来关于预嘱与最佳利益的判决、及各种宪法对谁决定的不同回答、及疫情时代分诊规程之辩（“最大化被救生命”框架与残障权利异议）——它将自成一章。2020年大流行提供了该专科最新的流行病学：ECMO在重度呼吸衰竭中的复兴带早期试验混乱与后来观察性清晰、来自急诊病房的家中自助俯卧建议、跨卫生系统的死亡率比较、及ICU仍在付账的道德损伤与人力退出数据——及如今写在每个2020年代策略文件里的认识：重症监护的天花板不是技术、而是愿意上夜班受训者的数量。它的历史结束在每个ICU查房开始之处：一名护士今天决定昨天的哪些支持可以移除。—— [[geriatrics-palliative/end-of-life-care]]、[[medical-ethics-law/end-of-life-ethics]]、[[respiratory/respiratory-failure]]。**
:::

::: summary
- ICU是分级的（病房外展、降阶、中间与全重症照护）、入院由可逆性与升级天花板谈话治理并每日记录、而稀缺中的分诊遵循公布的“最大化被救生命”框架。
- 结局跟随每日组套多于监测仪：镇痛优先浅镇静带每日中断与呼吸试验、早期活动、谵妄筛查、睡眠保护、48小时内营养、导管与呼吸机护理组套、及血栓预防。
- 器官支持是一份带指征与天花板的菜单：肺保护通气与俯卧、去甲肾上腺素优先血管活性策略、连续肾替代、及只在有目的地时的机械循环（ECMO）。
- 家属是第二患者：定时的白话通报、开放探视、会议、ICU日记；家属创伤后应激是一个结局指标、不是一项软指标。
- 预后判断是概率性的；支持的限时试验与目标照护谈话（知道-希望-担心-要紧）取代判决、而带尊严撤除规程是ICU核心胜任力。
- 生存留下后遗症——ICU获得性无力、认知与心理疾病——所以重症后门诊与随访是干预的一部分、不是附录。
:::

## 练习

::: exercise 在满床的单元分诊 {level=2}
你的3级ICU有一张床与八个升级：46岁心脏骤停后低温候选；71岁开腹后出血伴乳酸上升；29岁哮喘者在最大内科治疗下储备耗尽；84岁伴转移性疾病与肺炎脓毒症；四个病房报NEWS 9。推理这一分配并记录它。
::: solution
**一床分诊（[[#def-unit]]、[[medical-ethics-law/justice-resources]]）：框架——公布的重症分诊逻辑：预期获益与ICU治疗下生存可能性第一、无先到先得（队列是临床的不是道德的）、及反歧视底线（年龄、残障、贫困不用作粗略代理；使用可逆性与生理）、及具名高级决定可由第二位顾问复查、因为分诊不是夜班的秘密；分配——29岁即将呼吸骤停者、无床则即刻死亡率最高、获得它；骤停后低温候选者的ICU路径证据有组织而窗口明确、及71岁的出血轨迹使他成为即刻第二优先、现在电话转向网络ICU；84岁的目标照护谈话与内科病房带天花板复查是正确答案、并以通报而不是拒绝的形式对家属说出口；四个NEWS 9——外展与降阶的意义就在于他们多数需要一次高级复查、一个升级计划与一次病房转移动、而不是最后一张ICU床、而发现”NEWS 9“如何变成床需求通货而不是复查触发器的审计就是今天的课；记录——注明框架与临床事实及所提供替代（转诊、降阶、天花板复查）及复查时间的分诊记录、与转诊顾问共享、因为稀缺决定在可见时可辩护而在低语中不可辩护。**
:::

::: exercise 筛查并处理谵妄 {level=2}
第5天通气脓毒症生存者：躁动、拔导管、ICU意识模糊评估法阳性；团队计划氟哌啶醇与约束。用组套改进计划。
::: solution
**ICU谵妄是处理而不只是镇静（[[#def-support]]、[[geriatrics-palliative/delirium-dementia-care]]）：重构——危及气道与导管的躁动型激越为安全而治疗、用仍与评估相容的最轻有效镇静、右美托咪定在戒断相关情形中有其角色带其心动过缓与低血压警诫；但抗精神病药在试验中不预防也不缩短ICU谵妄、而约束增加谵妄——所以问题不是“哪个药让她安静”而是“今天是什么在引起这个”；今日清单（低氧与低血压及脓毒症源头控制及尿潴留与从第1天重建的用药清单带苯二氮䓬与抗胆碱负荷定量、及酒精与戒断概率评分、及代谢与内分泌及神经病因（包括不明原因时用脑电图查非抽搐性癫痫持续状态）、及“她什么都听到了并记得声音”的家属访谈——它有时说出触发因素）；执行组套（定向与安抚伴钟和窗及助听器和眼镜及家属在场记录进病历、及睡眠规程（昼夜光与照护成簇及除报警外无噪音、及证据温和的诚实）及作为真正治疗的活动（床上坐起到椅子到理疗阶梯）、及喂养与补液与缓泻剂、及导管约束每日移除之问）；随访——记录谵妄天数因为持续时间预测认知长尾、及重症后认知筛查及教导家属创伤后应激与记忆问题有名字也有治疗、在诊室里由有人说“这就是谵妄留下的、这就是我们要做的”。**

写出一次目标照护会议的结构：58岁心梗后在静脉-动脉ECMO上、疑似缺氧性脑损伤、第9天、配偶与两名成年子女意见不一。包括语言与保障。

**会议（[[#def-person]]、[[medical-ethics-law/end-of-life-ethics]]）：之前——先取得临床一致（重症医师与灌注及心脏科及神经重症带标准化预后计划与第二意见通知顾问、护士被简报并在房间里或视频上、因为她们承载着家属的问题）、及预先安排家属到场带私人房间水和纸巾而不是走廊、及确定决策人与价值观病史（他有过偏好？他对人说过什么？）；结构——用大白话开场讲我们知道什么、检查理解、听问题背后的问题（“他疼吗”有时是“你们觉得他在受苦吗”或“必须由我决定的是我吗”）、然后我们希望什么与担心什么带ECMO的目的地规则（“泵买来天数；大脑决定这一年”）、然后“若他能听见我们、什么对他要紧”并邀请每位家庭成员、及善意命名而不裁判分歧（“你们两个都爱他而你们从他那里听到的是不同的话”）、及在欠一个建议时给建议（家属始终想要临床医师的观点；“我相信他不会接受这台机器、理由如下、改变路径会是什么样以及不会是什么样”）、及若窗口真的开放则限时试验或第二次会议选项、及“我们不会在任一决定中抛弃你们”句；保障——向任何感觉被多数的一方提供伦理会诊或患者倡导者、及撤除建议的第二医师复查、及记录谁说了什么、及带尊严死亡拔管或撤机计划、器官捐献转荐之问由指定专家而非当场问会议主持处理、及善后——丧亲电话与死亡时家属在场政策及随访门诊及团队复盘、因为一次9天ECMO伴脑损伤是那间单元每个人都会记住并排练的病例、而它被处理的方式就是下一位家属被对待的方式。**

::: exercise 运营外展服务 {level=2}
贵医院的心脏骤停率与ICU再入院在上升；围手术期团队想要“什么都要ICU床”；内科团队拒绝从HDU接回“不稳定”患者。设计解决真实问题的外展与升级服务。
::: solution
**不是床位服务的外展（[[#def-unit]]、[[clinical-skills/patient-safety]]、[[surgery/perioperative-care]]）：诊断——骤停上升加再入院上升加“床位政治”意味着坏的是升级文化不是床位数量（研究：快速反应与预警评分试验显示评分与团队干预并非普遍拯救死亡率、而实施科学与骤停地点数据显示起作用的是一支有行动权力与目的地的受信任应答）；设计——重症照护外展团队（护士主导的每日查室加值班医师应答带“任何员工都可触发”规则）、及与强制升级计划记录配对的预警评分触发系统（“复查触发计划而不是床”原则：若她下午茶时恶化怎么办写在观察表上）、及带公布的进出标准的可降阶HDU（内科团队害怕的那个用于近期撤机与升压药剂量封顶及神经观察患者的HDU正是2级的用途——由外展覆盖使它不是由借调护士填充的迷你ICU）；治理——24小时心脏骤停后复审及骤停与再入院病例记录由具名临床医师在一天内致电病房（恶化文献作者不断证明的“不责备、修系统”文化：被漏掉的异常生命体征先是人力与层级问题才是知识问题）、及与外科及内科团队的季度联合审计、及向阅读死亡率漏斗图的董事会报告线、及员工调查项“我能升级并被感谢”；及指标集——与非预期的病房到ICU未计划入院、按病房与小时的骤停生存、72小时内再入院、快速反应触发到应答时间、天花板记录率、及病房员工信心调查、加外展团队自身给医疗人力队伍的年度报告、因为只测量患者的服务最终发现自己已烧尽了它的人——是没有监测仪会报警的失败模式。**
