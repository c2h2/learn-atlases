急性病患者很少带着诊断来就诊。他们来时气促、意识模糊、皮肤湿冷，或只是“不对劲”，临床医生必须在弄清病因之前就采取行动。本章所讲的方法通过换一个问题来解决这个难题。临床医生不问“诊断是什么？”，而是问“什么即将夺去这个人的生命，我能阻止它吗？”，并按各系统衰竭致死由快到慢的顺序依次处理。

本章介绍这种结构化方法（ABCDE）、帮助病房人员发现病情恶化的早期预警评分、急诊科入口处使用的分诊系统，以及把识别转化为行动的沟通与升级处理。所依据的是英国复苏委员会（RCUK）、英国皇家内科医师学会（NEWS2）和NICE的指南；各地政策在细节上有所不同。

## 为什么需要结构化方法 {#sec-why}

对普通病房中发生心脏骤停或意外转入重症监护的患者进行研究，反复发现同一模式：在此前的数小时里，他们的观察指标已经异常，异常已被记录，却无人采取行动，或者反应太慢、处理者资历太浅。2005年英国全国患者结局与死亡保密调查（NCEPOD）的报告《一个急性问题？》（*An Acute Problem?*）描述了英国医院中的这一现象，NICE 2007年关于住院急性病成人的指南CG50提出了对策：定期观察、用评分系统触发升级、分级响应并明确职责。

解决办法有两部分。第一是一种**可靠的检查方法**，用于检查危重患者而不依赖于已知诊断。第二是一个**可靠的体系**，确保异常发现能引起响应。

::: theorem 先处理第一个问题 {#thm-order}
对急性病患者，按**气道（Airway）、呼吸（Breathing）、循环（Circulation）、神经功能障碍（Disability）、暴露（Exposure）**的顺序评估和处理问题。在某一步发现的问题要先处理再进入下一步；任何干预或病情变化之后，都要从头重新评估。
:::

::: proof
这一顺序遵循各种衰竭导致死亡的快慢。气道完全梗阻几分钟内即可致死，因为输送到大脑的氧中断了。呼吸衰竭（通气或气体交换不足）致死稍慢一些，因为肺和血液中储存的氧会被逐渐耗尽。循环衰竭（休克）随着组织缺血在数分钟到数小时内致死。神经系统问题（神经功能障碍），以及全面暴露时发现的问题（如皮疹或隐匿性出血），通常作用更慢。对气道梗阻的患者纠正低血压毫无意义，因为泵出的血液不携带氧。之所以需要重新评估，是因为患者的状态在变化：原本通畅的气道可能随意识下降而梗阻，已经改善的氧饱和度可能再次下降。
:::

## ABCDE评估 {#def-triage}

::: definition ABCDE法 {#def-abcde}
**ABCDE法**是对急性病患者进行的系统评估和即时处理，依次检查**A**气道、**B**呼吸、**C**循环、**D**神经功能障碍（神经状态和血糖）和**E**暴露（全面检查皮肤和身体，以及体温）。每一步，临床医生都要看、听、触，处理所发现的问题，并尽早呼救。在处理完即刻威胁之后，再进行完整的病史采集和二次检查。
:::

开始之前，临床医生要确认环境安全，穿戴适当的防护装备，并形成第一印象：患者看起来病重吗？一句简单的“您怎么样？”可以同时检查气道、呼吸和大脑。能用完整句子回答的患者，目前气道通畅、气息足以说话、脑灌注足够。

### A：气道

寻找梗阻的征象：呼吸有杂音（鼾声、咕噜声、喘鸣）、胸腹呈“跷跷板”样运动、辅助呼吸肌参与，以及完全梗阻时尽管用力呼吸却寂静无声。常见原因有意识水平下降（舌和软组织后坠）、呕吐物或血液、异物、肿胀（严重过敏反应、血管性水肿、烧伤、感染）和创伤。

先用简单处理：仰头抬颏或推举下颌、直视下吸引、口咽或鼻咽通气道，以及经带储氧袋的面罩给予高浓度氧。不能保护自身气道的患者需要尽早得到熟练人员的帮助。气道管理见[[emergency-critical-care/airway-ventilation]]。

### B：呼吸

完整数满15–30秒的**呼吸频率**；它是疾病最敏感的单一体征，也是最常被估计而非实测的体征。注意呼吸的深度和模式、呼吸功、发绀，以及脉搏血氧测得的氧饱和度。触诊气管和胸廓扩张，叩诊并听诊。

异常发现指向可治疗的病因：哮鸣音（哮喘、慢阻肺、严重过敏反应）、重症哮喘的“沉默胸”、呼吸音消失伴一侧胸部叩诊过清音（气胸；如为张力性，伴低血压和气管移位，应立即减压）、湿啰音（肺水肿或肺炎）以及叩诊浊音（胸腔积液或实变）。按英国胸科学会（BTS）指南给氧至目标饱和度，通常为**94–98%**，有高碳酸血症性呼吸衰竭风险者为**88–92%**。动脉血气可测定氧合、通气（PaCO₂）和酸碱状态。

脉搏血氧仪可能高估深色皮肤者的氧饱和度，因而可能漏诊低氧血症；当读数与临床表现不符时，应查动脉血气。

### C：循环

观察手和面部的颜色，触摸四肢末梢的温度。测量**毛细血管再充盈时间**：将患者手指举至心脏水平，按压指尖五秒；正常再充盈时间少于2秒。数脉率，注意节律和强弱，测血压，寻找颈静脉怒张、出血征象和尿量减少。听诊心脏。

急性病成人休克最常见的原因是低血容量（出血、呕吐、腹泻、脓毒症相关的血管扩张），但必须考虑心源性和梗阻性病因（见[[emergency-critical-care/shock-fluids]]）。置入一到两根大口径套管，抽血（如可能有感染则包括血培养、含乳酸的静脉血气，如有出血则做交叉配血），并给予一次补液冲击（成人通常为500 mL平衡晶体液，在15分钟内输完），除非有心力衰竭的证据，每次冲击后重新评估。胸痛或心律失常时做12导联心电图。

### D：神经功能障碍

用**ACVPU**（清醒Alert；新出现的意识模糊Confusion；对声音有反应Voice；对疼痛有反应Pain；无反应Unresponsive）或格拉斯哥昏迷量表（GCS）评估意识水平。观察瞳孔（大小、是否对称、对光反应），寻找局灶性神经体征和癫痫发作。**一定要测毛细血管血糖**：低血糖（血糖低于4 mmol/L）容易治疗，是意识模糊、癫痫发作或昏迷的常见原因。复核可抑制意识的药物，尤其是阿片类和镇静药；纳洛酮可逆转阿片类中毒。

::: definition 格拉斯哥昏迷量表 {#def-gcs}
**格拉斯哥昏迷量表**对三种反应按最佳刺激下的表现评分，从3分（无反应）到15分（完全清醒）：

| 反应 | 评分 |
|---|---|
| **睁眼**：自发睁眼 / 声音刺激睁眼 / 压力刺激睁眼 / 不睁眼 | 4 / 3 / 2 / 1 |
| **言语**：定向正确 / 混乱 / 词语 / 声音 / 无 | 5 / 4 / 3 / 2 / 1 |
| **运动**：遵嘱动作 / 定位 / 正常屈曲 / 异常屈曲 / 伸展 / 无 | 6 / 5 / 4 / 3 / 2 / 1 |

GCS 8分或以下常被粗略地用作患者可能无法保护气道的标志，但它提示的是需要高年资医生评估，而不是插管的自动指征。
:::

### E：暴露

在维护尊严、防止散热的前提下充分暴露患者。寻找皮疹（脑膜炎球菌病的压之不褪色皮疹）、出血、伤口、肿胀或疼痛的肢体、注射部位和压力性损伤的征象。测体温。查看用药记录、液体平衡记录和病历。

初次评估之后，临床医生进行有重点的病史采集（常常来自亲属、急救人员或病历），完成体格检查，复核检查结果，作出工作诊断和计划，并决定合适的救治地点。**AMPLE**病史是一个实用的简要格式：**A**过敏史（Allergies）、**M**用药（Medicines）、**P**既往史（Past medical history，及妊娠情况）、**L**最后一次进食（Last meal），以及**E**发病经过（Events）。

::: warning 正常值不等于令人放心的值
年轻健康的患者在大量失血时可以通过血管收缩和心动过速维持正常血压；低血压可能只在代偿失败时才出现。急性哮喘时，“正常”的PaCO₂是疲竭的征象，因为气促的患者本应把二氧化碳呼出去。服用β受体阻滞剂的患者可能不出现心动过速。老年人患脓毒症时可能不发热。每一个数字都要结合患者本人、变化趋势和其他体征来解读，不要让一项正常的观察指标推翻患者病情不佳的临床印象。
:::

## 早期预警评分 {#def-critill}

病房患者通常是逐渐恶化的。生理变化往往在心脏骤停前数小时就能察觉，但它们分散在多项观察指标中，单独看很容易遗漏。**早期预警评分**把它们合成一个数字，并配以既定的响应。

::: definition 国家早期预警评分2（NEWS2） {#def-news2}
**NEWS2**由英国皇家内科医师学会于2017年发布，在整个NHS使用。它对七项参数各评0–3分，然后相加。

| 参数 | 3 | 2 | 1 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|---|---|---|
| 呼吸频率（次/分） | ≤8 | | 9–11 | 12–20 | | 21–24 | ≥25 |
| SpO₂ 量表1（%） | ≤91 | 92–93 | 94–95 | ≥96 | | | |
| 空气或吸氧 | | 吸氧 | | 空气 | | | |
| 收缩压（mmHg） | ≤90 | 91–100 | 101–110 | 111–219 | | | ≥220 |
| 脉率（次/分） | ≤40 | | 41–50 | 51–90 | 91–110 | 111–130 | ≥131 |
| 意识 | | | | 清醒 | | | 新出现的意识模糊、V、P或U |
| 体温（°C） | ≤35.0 | | 35.1–36.0 | 36.1–38.0 | 38.1–39.0 | ≥39.1 | |

对已确诊高碳酸血症性呼吸衰竭、目标饱和度为88–92%的患者，使用单独的**SpO₂量表2**，以免他们因处于目标范围而被评为异常。

响应是分级的：总分**1–4**分由注册护士在病房内响应；**任何单项3分**需由病房医生紧急评估；总分**5–6**分是关键阈值，需要由具备急症处理能力的临床医生**紧急**响应；**7分或以上**则需**急救级**响应，通常由重症监护外展团队或医疗急救团队处理。
:::

NEWS2是工具，不是诊断。它善于识别在未来24小时内死亡或转入ICU风险较高的患者，但不能取代判断。一位经验丰富的护士担心的低分患者也值得评估；而一个评分稳定、长期偏高的患者（例如长期家庭氧疗的慢阻肺患者被用错了量表）可能不需要反复呼叫急救团队。多组观察指标的趋势往往比单个数值更有意义。

早期预警评分也是脓毒症处理路径的基础。根据NICE指南NG253（2025，取代了NG51中16岁及以上人群的部分），急症医院中疑似感染且NEWS2为7分或以上的成人属高危，应在1小时内给予抗生素；5或6分需在1小时内评估，并在3小时内给予抗生素，除非存在提高风险的征象，如乳酸高于2 mmol/L或急性肾损伤。详见[[infectious-diseases/fever-sepsis]]。

## 入口处的分诊 {#def-system}

急诊科按临床需要而不是到达顺序诊治患者。**分诊**（triage，源自法语*trier*，意为“分拣”）就是决定这一顺序的快速评估。

::: definition 急诊科分诊 {#def-edtriage}
**分诊**是患者到达时进行的简短、结构化评估，为每位患者确定一个优先级类别，据此决定其必须在多长时间内由临床医生接诊。英国广泛使用**曼彻斯特分诊系统**。它使用针对不同主诉的流程图和关键鉴别项（生命威胁、疼痛、出血、意识水平、体温、急迫程度），将患者归入五个类别之一：

| 类别 | 颜色 | 接诊目标时间 |
|---|---|---|
| 1 立即 | 红色 | 0分钟 |
| 2 非常紧急 | 橙色 | 10分钟 |
| 3 紧急 | 黄色 | 60分钟 |
| 4 标准 | 绿色 | 120分钟 |
| 5 非紧急 | 蓝色 | 240分钟 |

如果患者在等待期间病情变化，需重新分诊。
:::

分诊刻意求快，不可能发现所有问题。有些时间紧迫的疾病表现不典型：心肌梗死表现为气促或“消化不良”，尤其在老年人、女性和糖尿病患者中；主动脉夹层表现为背痛；脓毒症表现为意识模糊。因此急诊科使用**时间紧迫路径**，如直达直接经皮冠状动脉介入治疗的ST段抬高型心肌梗死路径、卒中溶栓和取栓路径、重大创伤网络以及脓毒症路径，一旦满足触发条件就绕过常规排队。

重大事件中同时对大量伤员进行分诊使用的是另一套更简单的工具，见[[emergency-critical-care/major-incidents]]。

## 沟通与升级 {#sec-escalation}

识别出危重患者，只有在合适的人足够快地赶到时才有用。清晰的沟通是一项临床技能。

::: definition SBAR {#def-sbar}
**SBAR**是交流患者情况、尤其是请求帮助时使用的结构化格式：

- **现状（Situation）**：你是谁、你在哪里、是哪位患者，以及一句话概括的问题（“我打电话是关于12床的Khan女士，她的NEWS2是9分，我认为她有脓毒症”）。
- **背景（Background）**：相关病史和入院原因。
- **评估（Assessment）**：ABCDE发现以及你认为发生了什么。
- **建议（Recommendation）**：你需要什么、什么时候需要（“我需要你在15分钟内来看她”）。

接电话的人复述关键事实和商定的行动。
:::

升级处理还包括明确**治疗上限**。对于患有严重、不可逆疾病的衰弱患者，病情恶化时正确的应对可能是病房内治疗和舒适照护，而不是重症监护。这一决定最好事先与患者和家属冷静地商定并记录下来（例如记录在ReSPECT表格上），而不是在凌晨三点临时决定。关于复苏的决策见[[emergency-critical-care/resuscitation]]。

患者和家属往往最先察觉病情恶化。自2024年起，NHS英格兰逐步推行**玛莎法则**（Martha's Rule），赋予患者、家属和工作人员一项权利：如果担心患者病情正在加重而其担忧未得到处理，可以要求重症监护外展团队进行紧急的独立评估。

最后，大多数医院都设有**重症监护外展团队**或**快速反应团队**，负责评估病情恶化的病房患者。这类团队能否降低死亡率的证据并不一致（2005年发表的澳大利亚MERIT整群随机试验未显示其复合结局下降），但它们现已成为标准做法，其获益似乎取决于病房是否真的尽早呼叫它们。

## 实例分析

::: example 自称“消化不良”的64岁男性 {#ex-atypical}
一名患2型糖尿病的64岁男性凌晨三点就诊，上腹部不适伴恶心两小时。他在出汗。呼吸频率22次/分，未吸氧时SpO₂ 96%，脉率108次/分，血压96/60 mmHg，清醒，体温36.7 °C。他说“只是消化不良”，要一片抗酸药。应如何评估他？
::: solution
**第一印象与ABCDE。**他能说话（A通畅），呼吸稍快而氧饱和度正常（B），心动过速、低血压伴出汗（C）：他有休克的征象。他的NEWS2为$2 + 0 + 0 + 2 + 1 + 0 + 0 = 5$（呼吸频率22得2分，血压96得2分，脉率108得1分），需要紧急临床响应；在急诊科他应被分诊为非常紧急。

**即刻行动。**置入套管，抽血（包括肌钙蛋白和乳酸），并**在10分钟内完成12导联心电图**。糖尿病男性出现上腹痛伴出汗和低血压，在被证明不是之前都应视为心肌梗死；尤其是下壁梗死，可引起上腹痛、恶心、心动过缓或低血压。鉴别诊断包括胰腺炎、溃疡穿孔、腹主动脉瘤破裂和胆道脓毒症，它们同样需要紧急处理。

如果心电图显示ST段抬高，他就进入直接PCI路径。普遍的教训是：糖尿病、高龄和女性使心肌缺血的不典型表现更为常见，而患者对自己症状的解释不是诊断。
:::
:::

::: example 氧饱和度“正常”的22岁哮喘患者 {#ex-asthma}
一名22岁哮喘女性在喘息加重两天后就诊。她只能说出短语。呼吸频率30次/分，未吸氧时SpO₂ 94%，脉率124次/分，血压118/74 mmHg。呼气峰流速为其最佳值的40%。未吸氧时动脉血气显示PaO₂ 8.6 kPa，PaCO₂ 5.6 kPa。她在好转吗？
::: solution
没有。根据英国哮喘指南，有几项特征使她属于**危及生命的急性哮喘**：峰流速为最佳值的33–50%定义为急性重症哮喘，而急性发作时**PaCO₂正常（4.6–6.0 kPa）**是危及生命的特征。一个气促、呼吸急促的患者本应PaCO₂偏低；数值正常意味着她正在疲竭，已不能充分通气。她94%的饱和度仅略高于危及生命的阈值（低于92%）。

治疗遵循ABCDE顺序：高流量氧使SpO₂达到94–98%，雾化沙丁胺醇（salbutamol，常以氧气驱动并连续给予）联合异丙托溴铵（ipratropium），口服或静脉糖皮质激素，现在就请高年资医生和重症监护会诊，并考虑静脉硫酸镁。她需要反复查血气；PaCO₂上升或疲竭意味着需由经验丰富的麻醉医生插管。更多内容见[[emergency-critical-care/anaphylaxis]]和[[respiratory/asthma-copd]]。
:::
:::

::: example 背痛并“感觉怪怪的”55岁男性 {#ex-aaa}
一名吸烟的55岁男性突发剧烈下背痛并向左腹股沟放射，随后感到要晕倒。脉率118次/分，血压88/54 mmHg，面色苍白，毛细血管再充盈时间4秒。因为他是自己走进来的，前台把他分诊为“肌肉骨骼性背痛”。应该怎么办？
::: solution
他处于**休克**（心动过速、低血压、毛细血管再充盈延迟、苍白），伴突发背痛和腹股沟痛。对于50岁以上吸烟男性，在被证明不是之前，这都是**腹主动脉瘤破裂**；最常见的替代诊断肾绞痛不会引起休克。

1. 立即把他转入复苏区，呼叫血管外科团队和急诊高年资医生。
2. 两根大口径套管，抽血包括交叉配血，如病情恶化则启动**大出血预案**。
3. **允许性低血压**：不要用大量补液去追求正常血压，否则可能加重出血；按本地流程，在出血控制前以维持意识、收缩压大约70–90 mmHg为目标。
4. 床旁超声可以迅速显示动脉瘤。只有病情足够稳定时才做CT血管造影；已知有动脉瘤且不稳定的患者应直接进手术室或接受腔内修复。

分诊错误——凭第一印象而不是生理指标贴标签——正是教学要点：异常的观察指标永远优先于主诉。
:::
:::

::: example “喝醉了来的”19岁男性 {#ex-drunk}
一名19岁男性凌晨一点被朋友送来，满身酒气，嗜睡、言语含糊不清。朋友说他一直在喝酒，“早些时候摔了一跤”。呼吸频率14次/分，未吸氧时SpO₂ 97%，脉率58次/分，血压158/92 mmHg。他在压力刺激下睁眼，只发出无法理解的声音，对压力刺激能定位。他的GCS是多少？必须排除什么？
::: solution
GCS：压力刺激睁眼**E2**，无法理解的声音**V2**，定位**M5**：总分**9**。

酒精是排除性诊断。饮酒者GCS下降，在核查以下各项之前，不能归咎于酒精：

- **低血糖**：立即测毛细血管血糖；酒精抑制糖异生。
- **颅脑损伤**：他摔倒过。脉搏慢伴血压高（库欣反应的一部分）提示颅内压升高。按NICE颅脑损伤指南，他需要紧急头颅CT，如发现血肿则请神经外科会诊。
- **其他药物或毒物**，包括阿片类（看瞳孔和呼吸频率）和合并摄入的物质。
- **气道保护**：GCS 9分且有呕吐风险，应把他安置在有监护、有吸引设备的区域，并请高年资医生评估气道。

朋友的叙述有帮助，但“喝醉了”这个标签是漏诊硬膜外血肿的经典途径之一。
:::
:::

::: quiz
一名68岁女性住在内科病房，NEWS2为3分，全部来自每分钟26次的呼吸频率。恰当的响应是什么？
- [ ] 12小时后复查观察指标，因为总分低。
- [x] 由病房医生紧急评估，因为单项参数得3分。
- [ ] 立即呼叫心脏骤停团队。
- [ ] 在评分达到5分之前不采取行动。
::: solution
任何单项参数得3分都会触发病房内的紧急评估，即使总分低于5分。呼吸频率26次/分是脓毒症、肺栓塞、心力衰竭或代谢性酸中毒常见的早期征象，而且往往是最先变化的观察指标。
:::
:::

::: history
按伤情需要而非军衔对伤员进行分拣的思想，可追溯到拿破仑的首席外科医生拉雷（Dominique-Jean Larrey）。他在18世纪90年代组织了“飞行救护车”，按伤势轻重而不是按军衔救治士兵。急诊科作为一个专科则要年轻得多：急诊医学于1979年在美国获得认可；在英国，这一专科在20世纪下半叶由“伤员”（casualty）科室发展而来。ABCDE顺序来自创伤救治，经高级创伤生命支持课程推广——该课程1978年首次在内布拉斯加州开办，1980年被美国外科医师学会采用——后由英国复苏委员会改编用于内科患者。早期预警评分于20世纪90年代末在英国医院发展起来；英国皇家内科医师学会于2012年发布了标准化的国家早期预警评分，2017年发布了NEWS2。
:::

## 后续内容

心脏骤停和围骤停期心律见[[emergency-critical-care/resuscitation]]；循环一步扩展为[[emergency-critical-care/shock-fluids]]；气道和呼吸两步扩展为[[emergency-critical-care/airway-ventilation]]；中毒患者的D一步扩展为[[emergency-critical-care/poisoning]]。初次评估之后使用的病史采集和体格检查技能见[[clinical-skills/physical-examination]]，使升级处理得以运转的安全文化见[[clinical-skills/patient-safety]]。

::: summary
- 按气道、呼吸、循环、神经功能障碍、暴露的顺序评估和处理急性病患者；先处理发现的问题再往下进行，尽早呼救，每次干预后重新评估。
- 认真数呼吸频率；它是病情恶化最敏感的体征。意识改变的患者一定要查血糖。
- NEWS2综合七项观察指标；1–4分需病房内响应，单项3分需病房内紧急评估，5–6分需紧急响应，7分或以上需急救级响应。只有确诊高碳酸血症性衰竭者才使用SpO₂量表2。
- 正常的数字可能给人虚假的安慰：年轻人的代偿、β受体阻滞剂、哮喘中的疲竭、老年人不发热、深色皮肤者的血氧仪误差。
- 急诊科分诊（如曼彻斯特系统）依据生理指标和鉴别项确定优先级；异常观察指标优先于主诉。
- 用SBAR升级，说明你需要什么、什么时候需要，并提前规划治疗上限。
:::

## 习题

::: exercise 为观察指标评分 {level=1 check="7"}
一名58岁男性：呼吸频率21次/分，未吸氧时SpO₂ 93%（量表1），血压132/80 mmHg，脉率96次/分，清醒，体温39.3 °C。计算他的NEWS2，并说明所需的响应。
::: hint
按[[#def-news2]]中的表格为七项参数逐一评分，记住呼吸空气得0分。
:::
::: solution
呼吸频率21得2分；SpO₂ 93%得2分；空气得0分；血压132得0分；脉率96（91–110档）得1分；清醒得0分；体温39.3 °C得2分。总分为$2 + 2 + 0 + 0 + 1 + 0 + 2 = 7$，需要具备重症监护能力的团队进行急救级响应。
:::
:::

::: exercise 格拉斯哥昏迷量表 {level=1 check="10"}
一名患者在声音刺激下睁眼，说出不恰当的词语，对疼痛刺激以正常屈曲方式缩回手臂。她的GCS是多少？
::: solution
声音刺激睁眼E3，词语V3，正常屈曲M4：$3 + 3 + 4 = 10$。
:::
:::

::: exercise 用哪个量表？ {level=1}
一名71岁男性患重度慢阻肺，既往有记录在案的高碳酸血症性呼吸衰竭，因急性加重入院。医嘱目标饱和度为88–92%。他吸氧1 L/min时SpO₂为90%。应使用哪个SpO₂量表？他的饱和度得几分？
::: solution
使用SpO₂量表2，因为他已确诊高碳酸血症性呼吸衰竭且医嘱目标为88–92%。在量表2上，饱和度88–92%得0分。（他仍因吸氧得2分。）用量表1为他评分会多出3分，可能引发不必要的急救呼叫；而对未确诊高碳酸血症性衰竭的人使用量表2，则会掩盖低氧血症。
:::
:::

::: exercise SBAR电话 {level=2}
为[[#ex-news2]]中的女性（肠切除术后第2天，NEWS2为9分）写一份打给外科专科住院医师的SBAR交班。
::: solution
**现状**：“我是7号病房的一年级住院医生Alex。我打电话是关于4床74岁的Grace Adeyemi女士。她的NEWS2是9分，我担心她有脓毒症。”
**背景**：“她是癌症前切除术后第2天。昨天情况良好。”
**评估**：“气道通畅。呼吸频率23，吸氧2 L时SpO₂ 95%，肺部清晰。脉率112，血压104/62，四肢末梢凉，毛细血管再充盈3秒。清醒，血糖7.2。体温38.4，腹部压痛比昨天明显。我已做了血培养和血气；乳酸3.1。我认为她可能有吻合口瘘。”
**建议**：“我已开始用抗生素和补液冲击。我需要你在15分钟内来看她，我认为应呼叫外展团队。你到之前还需要我做什么吗？”住院医师复述关键细节和约定的时间。
:::
:::

::: exercise 分诊类别 {level=2}
为下列每位患者确定曼彻斯特分诊颜色（红、橙、黄、绿或蓝）并给出一个理由：(a) 40岁，压榨性胸痛伴出汗；(b) 30岁，两周前扭伤脚踝，行走正常；(c) 75岁，新出现意识模糊，体温39 °C；(d) 25岁，没有呼吸。
::: solution
(a) 橙色（非常紧急）：剧烈疼痛，可能为急性冠脉综合征；10分钟内做心电图。
(b) 蓝色或绿色（非紧急或标准）：无生命威胁，疼痛轻微，慢性问题。
(c) 橙色（非常紧急）：意识水平改变伴发热，提示脓毒症或脑膜炎。
(d) 红色（立即）：气道和呼吸受损；这是复苏病例。
具体类别由本地流程图确定；原则是由生理指标和关键鉴别项决定优先级。
:::
:::

::: exercise 虚假安慰的血压 {level=2}
一名28岁女性妊娠7周，下腹痛。脉率122次/分，血压112/70 mmHg，毛细血管再充盈3秒，面色苍白。分诊护士记录她血压正常。解释为什么这位患者可能处于休克，以及必须排除什么诊断。
::: solution
年轻健康的成人通过血管收缩和心动过速代偿失血，在丢失相当大比例的循环血量之前都能维持血压。尽管收缩压正常，她的心动过速、苍白和毛细血管再充盈缓慢表明存在明显的低血容量。她的休克指数（脉率除以收缩压）为$122/112 \approx 1.1$，偏高。妊娠早期伴腹痛，必须排除**异位妊娠破裂**：请高年资医生紧急评估，两根大口径套管，交叉配血，床旁超声，并转诊妇科。
:::
:::

::: exercise 夜间恶化 {level=3}
一名82岁男性因肺炎入院。他的NEWS2在20:00为2分，00:00为4分，04:00为6分（呼吸频率24，吸氧2 L时SpO₂ 93%，脉率104，血压108/64，清醒，体温37.9）。他有一份ReSPECT表格，写明他不希望插管或心肺复苏，但希望“其他一切”。护士问是否值得叫人。讨论应如何响应。
::: solution
值得。评分稳步上升，已越过紧急响应阈值，需要具备急症处理能力的临床医生评估。趋势与数值同样重要。排除插管和心肺复苏的治疗上限并不排除升级：他仍希望接受抗生素、氧疗、补液，如果符合他的意愿且可能有帮助，还可能接受无创通气或更高级别的照护。前来评估的临床医生进行ABCDE评估，复核抗生素的选择和用药时机，考虑并发症（脓胸、脓毒症、心力衰竭、肺栓塞），查血气，并与患者和家属共同决定是否适合尝试更高级别的照护。“不做心肺复苏”从来不等于“不必评估”。
:::
:::

::: exercise D步中的低血糖 {level=3}
一名47岁1型糖尿病女性被伴侣发现大汗淋漓、言语不清。急救人员记录GCS 11分，毛细血管血糖1.9 mmol/L，脉率102次/分，血压138/84 mmHg。她不能安全吞咽。概述治疗，以及她回家前需要回答的问题。
::: solution
她有伴意识水平下降的严重低血糖，因此口服葡萄糖不安全。治疗（按本地流程）是**静脉葡萄糖**（例如10%葡萄糖），如无静脉通路则**肌内注射胰高血糖素**。10–15分钟后复查血糖，反复治疗直至高于4 mmol/L，待她能进食后再给予长效碳水化合物。

出院前：为什么会发生（漏餐、饮酒、运动、胰岛素使用错误、肾功能损害、新出现的肾上腺或甲状腺问题）？胰岛素剂量是否合适？是否为长效胰岛素，可能导致反复低血糖而需要更长时间观察？她是否存在低血糖感知受损？她需要关于驾驶的建议（英国驾驶员与车辆执照局DVLA关于严重低血糖的规定），并由其糖尿病团队随访。
:::
:::
