急诊与急性医学评估是未分化患者的学科：在数分钟内决定这个人病得多重、接下来一小时什么会杀死他们、及必须按什么顺序发生什么——在诊断存在之前。**本章讲述分诊层（系统、其评分逻辑及其已知失效模式）、结构化人工评估（作为触发治疗算法而非仪式做的ABCDE、作为轨迹与背景读取的生命体征、聚焦病史及“为何是现在”之问）、未分化危重成人的识别与初始处理（脓毒症、休克、气促、虚脱、意识模糊者）、升级机器（预警评分、恶化组套、及心脏病与卒中和创伤及毒物摄入的时间关键网络）、及作为系统的科室（拥挤作为死亡风险、出院安全网、及记录的法务语法）。本章的脊柱是写在每间复苏室墙上的一句话：“没人死于诊断——他们死于有人等待诊断时没人治疗的生理。”**

## 分诊与结构

::: definition 分诊与ABCDE法 {#def-triage}
**分诊不是速度，是分配：四个以上国家系统（曼彻斯特分诊系统伴其基于表现的流程图与五类时限、加拿大分诊与急性敏感度等级、澳大利亚ATS、美国五级急诊严重指数及照护网络等价物）都解决同一个不可能的问题——预测今天到达者中谁会恶化——而都共享同样的已知漏掉：被推出队列计时的行为健康与自伤表现、“看起来正常”的生命体征掩盖肺炎与心梗与脓毒症老年人（非典型表现文献与老年分诊错误簇）、被分诊为焦虑的女性心脏病患者（胸痛研究的性别差距与症状被敷衍的数据）、疼痛评估的种族偏倚发现、及第五次就诊包含过敏反应的“常客”——这就是好的部门分诊两次（正门与候诊室重分诊伴护士再评估间隔、因为椅子上恶化是多数急诊死亡中有记录的系统失败）。人人共享的方法：作为同步治疗的初级评估ABCDE（伴咳嗽与喘鸣及“你能全部咽下吗”之问的气道；伴血氧与呼吸功及“你能说完一个句子吗”测试——房间里最好的监测仪——的呼吸；伴脉压与毛细血管再充盈及乳酸及卧位坐位两版病史的循环；伴AVPU与格拉斯哥昏迷量表及运动项及血糖（因为低血糖模拟卒中）及瞳孔伴眼药水与胰岛素史问题；及伴体温与皮疹及压疮区域及发热肥胖患者有人必须真正查看的后颈与腹股沟）；同一算法带其辅助的复苏室版本（做三个检查工作的血气、做生理猜测工作的超声——E-FAST与肺滑动与下腔静脉与血栓及心包积液数分钟内、及四骑士任何表现中的12导联因为心电图是急诊医学最廉价的一条命）；稳定后的次级评估（由同行者与急救员及全科系统获得的AMPLE/SAMPLE病史、药物与过敏及抗凝及近期器械清单、及产生机制的“你之前在做什么”之问——高处坠落对平地跌倒每次都是不同的病）；及作为临床仪器的记录（时间、镇痛与液体改变之前的初始生命体征、你依赖的阴性发现、因为验尸官与律师及下一家医院都读你在02:00写的病历、而班次不存在病历之外的版本）。**
:::

## 未分化的重病患者

::: definition 未分化危重成人 {#def-critill}
**识别优先范式：结局研究不断产出同一发现（到抗生素与到升压药及到除颤文献）——头几小时的死亡更跟随识别到治疗间隔而非诊断优雅、这就是急性内科医师的工作问题就是分诊问题：(1)这个人是否死于氧（血氧与呼吸功与血气、及哮喘与慢阻肺与肺炎与肺水肿及肥胖低通气表现中升级到无创通气或插管的决定、各有其陷阱——慢阻肺患者的氧致高碳酸血症与88-92目标带、及血氧正常而二氧化碳上升即将骤停的哮喘患者）；(2)灌注（下一章的休克识别伴乳酸与脉压与花纹及再充盈时间及“她躺下就晕”病史及人员会用的床旁超声）；(3)脓毒症（筛查标准从SIRS到SOFA到qSOFA到各脓毒症组套的演变伴诚实立场：组套救了命而标准过度触发、“一小时内脓毒症六项”文化、带口腔与尿与导管与皮肤及艰难梭菌及睾丸与前列腺及脊柱与关节之问（腹痛工作检查会漏）的病灶搜寻、及“不是所有发热都是脓毒症、而所有脓毒症发热在75岁以上可表现为跌倒与意识模糊”——两个方向的错误）；(4)毒物代谢（每个神志改变患者的血糖、钠与钙与镁、及每个有自杀意图与每个“误服”的对乙酰氨基酚浓度、阿片毒理综合征的瞳孔-通气-昏迷模式、呼吸像脓毒症的水杨酸、及一家人一屋子的CO头痛簇、及自带意识模糊的肝肾衰竭表现）；(5)仍在走表的四骑士（心电图与肌钙蛋白与CTPA与头颅CT及脑膜炎的腰穿及“我这辈子最痛的头痛”的蛛网膜下腔出血微妙、及双臂血压相等核查的无主动脉夹层、及睾丸与会厌及肠系膜与肢体缺血“时间就是器官”综合征——疼痛与体征不相称这句话就是全部临床艺术）；及恶化患者机器（预警评分与其诚实证据——试验中NEWS2对ICU与骤停转诊适度而真实的减少、重症监护外展模型、及“即使诊断错了也早升级”文化及以患者为中心的恶化患者教学大纲、及研究显示比任何药物预防更多伤害的SBAR交接）。老年与精神扩展因为它们是现代评估量的多数：以功能下降为首发主诉的老年人（“她不动了”可能是骨折或尿源性脓毒症或硬膜下、及每个意识模糊老人都应得的谵妄筛查——老年章覆盖）及急性激越患者（排除医学病因伴血糖与缺氧与头颅损伤与药物、及约束的医学与法律在他处覆盖、及“她带着人在这栋楼里安全吗”之问——是精神科分诊不是药理学）。**
:::

## 作为系统的科室

::: definition 急诊科与时间关键网络 {#def-system}
**作为带副作用临床工具的时间目标：4小时等待标准及其8小时与12小时表亲、及美国的到球囊与到针及到CT时代（到针与到球囊时间数据救心肌与脑、伴院前通知与一站式CT及CTA及取栓网络的卒中路径、及时钟漏掉的“卒中变色龙”——夹层与低血糖及发作后与年轻患者）、主要创伤分诊标准与创伤网络启动伴直升机坪的初级评估及由艰苦环境判定为“装上并喊人”的“快送对就地治”之辩及成分转运教训、及诚实的反文献（目标驱动医学的扭曲——走廊推车医学、“操纵”自身到达时间的迟到者、及把4小时时钟变成人质谈判的救护车交接延迟——这是2020年代急诊照护危机的定义机制）；拥挤的医学（全院流程失败的结局被测量：等待后入院患者死亡升高、未诊而离开然后死亡的病例及验尸官叙事、作为压疮与跌倒及用药错误环境的走廊推车、及有实际证据的需求-容量缓解——评估单元与虚拟病房及当日门诊及带当日复查绕行的养老院——这就是老年与姑息章的服务如何在远处实际减少急诊的死亡）；出院契约（用患者自己的话说的“我们有没有解释要观察什么与做什么”安全网、镇痛与抗凝及职业治疗与全科信及离开前预约而非安排、“拒绝治疗的神志清楚者”及其能力与记录语法、及用具名全科与单一照护计划治整个人的常客方案——因为替代要么忽视要么疲惫收住）；使每条规则弯曲的儿科与产科例外（儿童是不同的物理学及按体重剂量算术及儿童预警评分及“再想脓毒症”、及保障邻近骨折模式与非意外伤害考量（儿科覆盖）、及倒下的孕妇其生理与鉴别属于产科章——两者都证明科室两套复苏文化合理）；及人因层（初级决策阈值与“拿不准就喊人”升级文化作为死亡变量、疲劳与夜班错误数据、对急诊人员的暴力作为安全与人力危机、及复盘与学习系统——因为科室一年见的低概率高后果事件比多数专科一生见的还多、而有最糟的日程去处理它们）。**
:::

::: example 凌晨3点“消化不良”的64岁 {#ex-atypical}
患糖尿病与高血压的女性因两小时上腹痛恶心就诊；分诊3类“大概胃炎”；附全科信；初始观察心率96、血压104/68、呼吸20、血氧97%；等待3小时；现在“出汗而乏力”。没人给她重分诊。
::: solution
**三幕的死亡模式（[[#def-triage]]、[[#def-critill]]）：第一幕——糖尿病女性的非典型下壁/后壁心梗：上腹与恶心与乏力表现是胸痛医学的性别与年龄差距、而“她可能在心梗”不需要胸痛、它需要一份不花钱、九十秒、按全国每个胸痛与上腹痛流程图都该在分诊时做的心电图；第二幕——候诊室里的恶化：三小时、无重分诊、“出汗而乏力”这句话是骤停前描述、本应是一个重评估触发（NEWS2伴休克指数在心及现在显示ST改变的重做心电图、及一小时前在另一家医院的心导管室启动）；第三幕——验尸官要求的系统修复：分诊流程图合规审计（上腹算法是否含对糖尿病与女性及50岁以上者的心电图规则）、带护士再评估时钟的候诊室观察间隔政策（及“员工能看出谁在恶化”假设被检验而非假定）、及护理自主启动心电图的胜任力与“她看着不对”路径培训——因为在每次候诊室死亡复中，问题不是为什么没人诊断它、而是为什么没人再看一眼。临床底线：她的STEMI路径从任何人做心电图那一刻开始、而抗血小板与肝素与启动就是治疗——而重分诊系统就是本科室疾病的诊断。**
:::

::: example 血氧“正常”的22岁哮喘 {#ex-asthma}
哮喘持续状态：空气下血氧98%、呼吸28、无法完成句子、听诊沉默胸、衰竭、血气二氧化碳6.1 kPa；初级想“多雾化一小时后重评”。
::: solution
**戴着正常血氧仪的近致死哮喘（[[#def-critill]]、[[respiratory/asthma-copd]]）：解读——血氧饱和度是哮喘中唯一说谎的数字：接近正常的血氧伴上升或正常偏高的二氧化碳及沉默胸及衰竭是骤停前模式（梗阻严重到气体和声音都不动）、而不会疲劳的哮喘患者二氧化碳应该低——这个临床图像中的“正常”二氧化碳是伪装着的呼吸衰竭；接下来十分钟——高流量氧与沙丁胺醇及异丙托溴铵雾化、或重症发作方案中更好的带储雾罐气雾剂、早期给的静脉镁而不是第四瓶雾化之后、首次评估即给静脉激素、静脉液体、及按复苏委员会与哮喘指南路径对邻近骤停者的肾上腺素之问、及现在就叫高年资麻醉支援而不是一小时后——因为给这套生理插管是这栋楼里最难的气道、团队应该在挑选时机、不是在骤停中迎接它；及升级与ICU谈话无创通气在哮喘对慢阻肺的弱证据之别、氯胺酮诱导邻近的通气策略与允许性高碳酸血症、及ICU到来——因为这患者需要一个通气床或近乎通气的床、及按指南记录严重度分类近致死/危及生命、病房与ICU与全科与哮喘护士及随访激素与吸入器与技术扳机计划都挂在它上面。**
:::

::: example 55岁“背痛和古怪感觉” {#ex-aaa}
从候诊室椅子打来的电话：突发肩胛间疼痛、出汗、血压88/60、脉搏存在、心电图“陈旧T波改变”、分诊护士因假定肌肉骨骼痛给了吗啡；十分钟后她倒下。
::: solution
**破裂正在一个分诊类别里发生（[[#def-critill]]、[[cardiovascular/vascular-disease]]）：即刻——50岁以上吸烟者突发重度背痛伴低血压伴“古怪感觉”伴需吗啡，就是正在破裂的腹主动脉瘤或正在夹层的胸主动脉瘤直到证明不是：动作是同步的（复苏室、两条大口径留置针与备血交叉合血启动、通知CT室、及按名字呼叫血管外科或心脏外科医师——不靠呼机链也不靠排班希望）及血压目标判断（夹层的容许性低血压与β阻滞对破裂的液体不同、而扫描与外科医师在数分钟内决定这是哪种病）；复审要命名的错误——跳过一位女性血压的“背痛”分诊类别（与非典型ACS漏诊同一文献：疼痛加低血压不是肌肉骨骼直到别的东西被解释）、无第二组观察的吗啡（镇痛是对的、其周围的观察缺口才是发现）、及本例几乎加入的CT门口推车死亡统计；及系统——分诊时“背痛伴红旗”的决策支持（50岁以上突发疼痛加低血压提示就是一个警报里的动脉瘤夹层与肺栓塞与脓毒症组套）、及急诊自身规则：任何需要阿片镇痛的患者得到一个医师的鉴别而不只是一张处方、因为镇痛就是诊断已经在问的那个检查。**
:::

::: example “喝醉送来”的19岁 {#ex-drunk}
凌晨1点由警察送来、“喝醉”、对声音无反应、呼吸8、空气下血氧91%、血糖5.8；护士想“恢复体位睡一觉”。
::: solution
**两个安静杀人的诊断看起来像喝醉（[[#def-critill]]、[[emergency-critical-care/poisoning]]）：逐分钟——呼吸抑制不是醉酒：气道——通气不足就捏球囊、给纳洛酮并按通气（不是按清醒）滴定（阿片毒理综合征伴共服药物或超过标准剂量的合成物——重复并考虑输注）、复查血糖（她的正常、而对乙酰氨基酚浓度不正常、而在被询问之前永远不会）、头颅损伤搜寻（“喝醉”者无人见证的倒下与袭击模式就是硬膜下直到CT说不是、而警方羁押请求不高于CT）；被“喝醉”一词取代的工作检查——血气（每个故意或不确定的摄入中的共服药物与阴离子间隙及对乙酰氨基酚与水杨酸浓度）、妊娠试验、任何定位体征或长时间抑制或抗凝或无人见证头部撞击时的头颅CT、体温（读作睡觉的低体温）及保障层（饮品下药与性侵犯考量、及她完全恢复自己时的精神健康评估——几小时内她可能都不是）；及文化——“喝醉”分诊标签是三个词（连同“焦虑”“常客”“寻药者”）之一，它们在验尸官叙事中先于可预防死亡的出现次数比多数疾病都多、而科室规则应该是：中毒是在血气、血糖、头颅与气道安全之后做出的排除诊断、不是之前。**

::: solution

::: exercise 跑一个恶化患者电话 {level=2}
值班时护士报告“他不对劲”；你见到一位70岁保守治疗的憩室炎患者、嗜睡、花纹、心率126、血压82/48、乳酸5.4。外科团队说“我们知道他在恶化”。管理接下来一小时，包括目标谈话。

**带病史的脓毒性休克（[[#def-critill]]、[[surgery/acute-abdomen]]、[[geriatrics-palliative/palliative-care]]）：一小时——追赶式跑脓毒症组套：培养、一小时内广谱抗生素——是的但分钟更好、30 ml/kg平衡晶体并重新评估应答（重复乳酸与血压与尿量、及液体失败时经良好通路早开升压药——因为“液体优先”不是“液体永远”）、由床旁带CT的外科医师而非电话回答的源头控制之问（穿孔对可引流积液对弥漫腹膜炎的决定决定是ICU稳定后进手术室还是现在进还是舒适照护——不由CT机 dictated）、邀请ICU与想到去甲肾上腺素在同一分钟、及“我们知道他在恶化”这句话按面值接受而以后审计——今天它不是冲突、是一条说识别已晚的病史、它改变你对他下次扫描的做法、不是你此刻对谁吼；及目标——他的基线（那个有自己痴呆的独立男人？）与其既往记录的偏好及在场的家属听诚实的并行轨道句（“我们在治感染而我担心他会死于它；这是我们在做的、及如果他今晚恶化我们会做什么不会做什么”）、写在ICU会读的病历里的照护天花板、及作为症状专家而非投降邀请的姑息医学团队——这是姑息章的同步照护模型以最快速度应用。**

::: exercise 修好出院 {level=2}
26岁镰状细胞病反复就诊患者凌晨5点离开你的急诊，带着“镇痛与全科随访”：没有长期镇痛处方、没有补液计划、一个没人核查的羟基脲疑问、而信上写“排除血管闭塞危象”。出院本该包含什么、此处的常客陷阱是什么？
::: solution
**作为临床人工制品的出院（[[#def-system]]、[[blood/haemoglobin-disorders]]）：本例的标准——具名危象方案（WHO阶梯加规律加突破镇痛带回家伴止吐与通便、及“我的血液科方案”文件——好的服务把它作为个体化病假与危象规程发布并记录在这里有效的阿片剂量、因为“病历说她寻药”常常等于“病历上她实际需要的从未被写下”）、安全网（发热与胸痛与神经症状及“这次比平时重”用她话给的建议、及预期的归途（哪个科室、哪个团队）、若出血或过度溶血的血红蛋白之问、及随访镰状细胞团队而非只有全科——因为羟基脲与输血状态与血管病是专科医学、而“羟基脲疑问”行是装扮成诊断的转诊失败）；陷阱——镰状细胞与其他慢性疼痛疾病中的常客标签是真实疾病与门诊治疗不足及污名的交汇、而修复是由专科团队与急诊共同拥有的个体化方案（单一文件与一个电话号码与“本方案每年复审”文化）、因为否则系统在两个错误之间摆动——镰状细胞死亡审计不断发现的阿片污名治疗不足、及本应由日间单元或家庭治疗路径提供的六小时急诊疼痛就诊——两者都不是患者的行为、而两者都在你今晚的出院数据里。**

::: exercise 设计科室的能力与安全规划 {level=3}
贵市各急诊：4小时超标率35%、每日100余次超过60分钟的救护车交接、每夜走廊推车、及院外入院的75岁以上者7天死亡比工作日白天高30%。写一份临床医师与行政长官都能签署的规划。
::: solution
**作为患者安全的能力（[[#def-triage]]、[[#def-system]]、[[public-health/health-systems-economics]]）：共同前提——两位签署人必须同意这个发现：拥挤、交接延迟与院外入院是有效应量的临床暴露、不是舒适问题、而规划的杠杆就是证据的杠杆；需求侧——按真实救护车到达模式而非合同数字建设的当日通道与紧急社区应答及虚拟病房容量（带真正吸引低危需求之临床人员配置的全科与紧急照护中心平行路径、因为关上的门只会移动救护车）、养老院与衰弱绕行（“救护车门口评估衰弱老人与一站式评估单元”模型及其入院减少数据——即老年章的服务被复用为急诊干预）、及精神健康危机替代方案（同一份报告里4小时压力与残忍都来自此处）；流程侧——带真实权力与每日可预期困境的升级委员会（出院休息厅与搬运及运输作战室、及带出院与康复绕开的“社会照护不是医疗”床位——这是被变成临床问题的护理与职业治疗资金决定、因为入住率危机随后在凌晨3点抵达你的复苏区）、及交接改革（带受监测救护车的护理交接湾、及与工会及救护服务议定临床人员配置的“10分钟内交接”目标作为安全干预、因为交接椅是一台治疗延迟机器）；正面回答院外死亡之问——七天安全编制（凌晨2点在复苏区做决定的高年资者而不是只是待命、按危重度曲线而非办公时间曲线建模的顾问内外在场、使诊断差异与死亡缺口成为排班表问题的夜间放射与检验与超声通道、及专门在夜间做的恶化规程可靠性审计——这是查明为何“我们知道他在恶化”发生在午夜到七点之间的唯一办法）；及透明——每日报告的指标（交接延迟与走廊推车计数与救护车改道小时及带理由的每日可预期升级决定公开、因为关于急诊失败的公共辩论用的是比这更差的数据、而安全地瞄准排班表的羞耻是医学拥有最廉价的安全干预）。若临床医师不能签它，规划就不安全；若行政长官不能资助它，它就不是规划。**

## 通向何处

休克生理与液体在下一章（[[emergency-critical-care/shock-fluids]]）、气道与通气决定在[[emergency-critical-care/airway-ventilation]]、骤停在[[emergency-critical-care/resuscitation]]、毒理综合征在[[emergency-critical-care/poisoning]]、及老年人与精神健康评估扩展在[[geriatrics-palliative/ageing-frailty]]与[[psychiatry/psychiatric-assessment]]。

::: history
**急诊医学的历史是分诊、复苏与队列。祖先是军事与市政的：Larrey的流动救护车与分诊的词源（法国外科医师“分拣伤员”）、十九世纪城市的铁路与工厂事故病房、及首个专门建造的事故服务（1930年伦敦事故站与直到世纪中叶通常是外科最低声望角落的美国医院“事故室”）。专科自身在1960-70年代几乎同时在三大洲建立——辛辛那提与美国整顿运动、澳大利亚与英国的复苏室学派——并通过复苏委员会与专科委员会职业化、把“急诊医师”从轮转者变成职业；创伤系统建设（Cowley与马里兰直升机服务及Cook县时代的外科及美国外科医师学会创伤中心认证体系、及英国2000年代在网络重建——其调查报告发现伦敦人死于可治损伤——这一发现在历史上有趣主要因为它晚了五十年）、及从另一方向发明的心脏冠脉监护（1960年代各医院冠脉监护时代、随后是最初几小时决定梗死面积的领悟——这就是监护仪迁入急诊科的方式）、及1995-2015溶栓-介入-取栓网络时代、它教会所有人时间目标就是药物：NINDS组织型纤溶酶原激活剂试验、直接血管成形路径试验、及“边滴边送对先送后滴”的物流之辩、这是医学在做运筹学。分诊科学（1990-2000年代的曼彻斯特分诊系统及加拿大分级与急诊严重指数及其验证队列）其信度文献在各国的审计中不断产出同样的分诊不足发现——老年人、心脏痛女性与行为健康表现；及预警评分运动（1990年代改良早期预警遗产、2005年《患者置于中心》课程、NEWS2推广与国家报告时代、及国家患者安全机构的识别-评估-沟通工具包）代表同一住院化的理念：恶化对有规程与升级路径的普通员工是可见的。队列的流行病学是最新也最丑陋的一章：2010-2020年代拥挤与救护车交接延迟文献（各学院与质量委员会及卫生信息研究所报告及关于滞留死亡信号的社论、终结于使“四小时”成为政治脏话的冬季危机与使夜间走廊照护正常化的全面医院政策时代）、对急诊人员暴力研究、及“急诊作为卫生系统压力表”的发现（当基层照护与社会照护与精神健康危机服务及床位失败时、他们的需求到达救护车湾、而死亡附着在无法入院或无法安全出院的人身上）。历史以借来的力量教授本章的方法：时间目标与预警及网络启动技术是医学中唯一起效方式为改变人们何时看、而不只是做什么的干预——这就是为何本专科最伟大的发现是排班表。** — [[cardiovascular/coronary-artery-disease]]、[[nervous-system/stroke]]、[[surgery/trauma]]。**
:::

::: summary
- 分诊在诊断缺席时分配风险并有可预测的失败（老年人、女性、行为健康与低信誉患者）；候诊室的系列再评估是证据要求的安全网。
- ABCDE是触发治疗的算法不是检查：每步有命名的救援、而稳定后的次级评估提供第一次跳过的病史与机制。
- 在未分化患者中并行运行氧-灌注-脓毒症-代谢-骑士之问；在诊断整齐之前治疗时间关键的生理。
- 正常血氧能隐藏骤停前哮喘而正常体温能隐藏老年脓毒症：读趋势、背景与患者的形态。
- 时间目标在联网时起作用（导管室、卒中、创伤）、在被操纵时造成伤害；拥挤是一个死亡变量与一个系统输出。
- 出院是一个临床行动：用患者话语的安全网、离开前预约的随访、及告诉下一位临床医师排除了什么及如何排除的记录。
:::


::: exercise 读生命体征 {level=1}
解读并行动：(a) 30岁、呼吸32、血氧99%、心率110、“只是焦虑”；(b) 78岁跌倒后、服比索洛尔心率60、血压90/60、温暖、意识模糊；(c) 45岁、心率120、血压160/95、激越、瞳孔散大、出汗。
::: solution
**三形态三行动（[[#def-critill]]）：(a) 伴气促与心动过速的“焦虑”在排除前是生理诊断——代谢性酸中毒伴代偿性过度通气鉴别（伴尿糖正常的SGLT2抑制剂邻近史或早期脓毒症或肺栓塞或水杨酸——在贴标签之前做血气与血糖与妊娠试验）；(b) β阻滞削弱老年出血或脓毒症者的心率反应：跌倒后相对心动过缓伴低血压与意识模糊就是出血与休克直到证明不是（创伤初级评估、骨盆与腹部及头颅损伤之念、及血与交叉合血与现在就找上级——因为“老年跌倒”是一个分诊类别不是诊断）；(c) 拟交感毒理综合征（可卡因与苯丙胺与致幻剂清单及来自药物与精神病史的抗胆碱与5-羟色胺与恶性综合征及甲状腺风暴鉴别、降温与苯二氮䓬优先的处理、及“别只用身体约束对抗兴奋剂”的安全教训、若瞳孔与发热与强直指向他处则查头颅CT）。三个答案共享本章习惯：生命体征是患者在说话、药物清单与年龄是翻译。**

::: exercise 分诊大规模伤亡班次 {level=2}
客车相撞、30分钟40名到达、你的急诊已经满：用系统逻辑分诊第一波、并陈述你将在法庭或验尸官面前辩护的三个决定。
::: solution
**灾害分诊是道德不同的分诊（[[#def-triage]]、[[emergency-critical-care/major-incidents]]）：方法——数-分类-标记-沟通：按事件规划类别分紧急-急-延-轻-预期不良（威胁生命而可存活者得到手术室与导管与气道——张力性气胸与可压迫出血及受损气道胜过无望颅脑损伤与濒死腹伤、因为在大规模伤亡场景中资源分配给可存活的生理而非最惨的观感——这是事件医学与常规医学之间的伦理差异、必须对团队大声说出）、两遍规则（没有第二核查与指定官员不得宣布死亡、因为“expectant”（放弃救治）有邻近尸体清点误差率）、及无人陪伴儿童的隔离与家庭团聚台——不是心软、是事件的核查系统；及三个可辩护的记录——带时间及由谁做的分诊类别（标记被保存）、对照宣布的规划做出的资源决定（ICU床位分配与CT顺序理由）、及“这是重大事件”的宣布时间——因为法律与调查判断系统是否依其公布规划一致行动、而规划的合法性取决于决策可追溯、及expectant患者接受了其姑息与尊严照护——事件医学把它记录为照护不是遗弃。**

::: exercise 打恶化电话 {level=2}

::: exercise 设计科室安全规划 {level=3}
贵急诊的重大事件聚类：候诊室恶化、漏掉的非典型ACS、儿科镇痛延迟、在同一4小时压力中的精神健康患者、及两个结局糟糕的“神志清楚拒绝治疗者”。写出带干预、所有者与指标及公平分析的规划。

**按失效模式的急诊安全（[[#def-triage]]、[[#def-system]]、[[clinical-skills/patient-safety]]）：候诊室恶化——带规程的重分诊时钟（护士再评估间隔与护理自主心电图及血气胜任力、及“任何人可要求重分诊”患者信息卡、及4小时后没人未被评分坐着的观察单元；指标：临床区外恶化与到心电图时间）；漏掉的非典型ACS——分诊表单上针对上腹与女性与糖尿病及50岁以上者的决策支持（“考虑心电图”提示 精准而非滥发、因为警报疲劳就是旧规则死亡的原因）、及科室简报中的性别与年龄差距教学——因为女性胸痛被敷衍的数据不是神话、而修复是第二眼不是责备；指标：按性别与年龄分组的肌钙蛋白阳性与漏掉ACS到达及到心电图时间；儿科镇痛——体重带与预混注射器与口服蔗糖及先夹板文化和“儿童安静地死”观察规程——因为儿科急诊镇痛延迟文献与各母婴死亡调查发现就是论据；4小时机器里的精神健康——平行路径（单人房间不是走廊伴索具风险减少与精神健康从业者评估在等待内、变革改变了等待时间目标、因为把4小时目标用于精神病是带指标的残忍、而合适评估场所标准是法律底线）、及按真实到达而非2015编制配置的外展团队；神志清楚拒绝治疗者——能力评估用表格伴支持步骤与具名复审者及“她能拒绝这个而这是我们还能提供的”家属谈话、因为两例中验尸官之问都是“实际上谁和她谈过”；公平分析——整个规划按性别、年龄段、族裔、贫困、残障与翻译需求报告、因为科室的失效模式不是随机分布的、两个死亡的拒绝者与镇痛缺口及分诊不足的78岁老人将恰好聚集在国家数据所说的地方——而规划的成功以缺口闭合来测量、不是以总体4小时百分比改善、因为汇总值就是安全规划藏身的方式。**
