人体的氧储备很少。呼吸空气的成人，肺和血液中储存的氧大约只够用几分钟，而大脑是最先因供氧中断而受损的器官。因此，保持气道通畅、把氧送进肺内并把二氧化碳排出，以及在患者无法自主呼吸时接管呼吸，是急救的首要任务，也是重症监护病房日常工作的主体。

本章介绍气道（评估、简单手法、辅助装置、气管插管以及插管失败时的预案）、呼吸衰竭及其类型、氧疗、经鼻高流量氧疗、CPAP和无创通气，以及有创机械通气的原则，包括急性呼吸窘迫综合征的肺保护性通气。所依据的是英国指南：氧疗和无创通气依据英国胸科学会（BTS），插管依据困难气道学会（DAS）。实际的气道技能要在培训课程中、在督导下学习，而不是从书页上学会。

## 气道 {#def-airway}

::: definition 气道梗阻及其识别 {#def-obstruction}
**气道**是从鼻和口到肺泡的通路；在急救中这个词通常指直到气管为止的上气道。**气道梗阻**可以是部分性的，也可以是完全性的。

- **部分梗阻**有声音：**鼾声**（意识下降患者的舌和软腭所致）、**咕噜声**（血液或呕吐物等液体）、**喘鸣**（喉部或喉以上狭窄引起的高调声音，通常为吸气性）和**哮鸣音**（下气道狭窄，通常为呼气性）。
- **完全梗阻**时尽管有呼吸动作却寂静无声：吸气时胸部内陷而腹部外鼓（“跷跷板”样或矛盾呼吸），口边感觉不到气流。

意识丧失患者气道梗阻最常见的原因是肌张力丧失，使舌和软组织后坠抵住咽后壁。
:::

**简单手法**先行，而且往往就已足够。**仰头抬颏**可使舌离开咽后壁；**推举下颌**能起到同样作用而不移动颈部，在可能有颈椎损伤时首选。用硬质吸引管在直视下清除液体。

**气道辅助装置**用于维持气道开放：

- **口咽（Guedel）通气道**，按切牙到下颌角的距离选择型号，只有意识明显下降的患者才能耐受；会因其产生呕吐反射的患者并不需要它。
- **鼻咽通气道**更易被半清醒的患者耐受。怀疑颅底骨折时慎用。
- **声门上气道装置**（如i-gel或喉罩）位于喉部上方，无需通过声带即可通气。它放置迅速，用于心脏骤停以及插管失败时的补救，但不能可靠地防止误吸。

### 气管插管

通过声带把带套囊的导管置入气管，可以保护肺免于误吸，允许以较高压力通气，并可吸引下气道。急诊中通常采用**快速顺序诱导（RSI）**：预充氧后，快速相继给予诱导药和速效神经肌肉阻滞剂，尽可能不进行手动通气就置入导管，以降低误吸胃内容物的风险。

指征包括：不能维持或保护气道（意识下降、烧伤或肿胀）；在较少创的支持下仍有氧合或通气衰竭；预期病情恶化（如严重颅脑损伤患者转运之前）；以及需要深度镇静或麻醉。

危重患者的插管是危险的。插管前后的心血管崩溃、低氧血症和心脏骤停很常见，因为诱导药引起血管扩张和心肌抑制，正压通气减少静脉回流，而患者可能几乎没有氧储备。正因如此，2025年DAS指南强调**生理性困难气道**，即危险来自患者的生理状态而非解剖结构。

::: algorithm 插管失败预案（DAS 2025） {#def-das}
困难气道学会关于成人未预料困难气管插管的指南（2025年发布）保留了一个简单的顺序，全程持续给氧：

- **方案A，气管插管**：优化体位、预充氧和首次尝试成功率（可视喉镜、探条、喉外按压），尝试次数有限。
- **方案B，声门上气道**：插管失败时，置入第二代声门上气道进行氧合，然后停下来思考：唤醒患者、继续使用声门上气道，或经其尝试插管。
- **方案C，面罩通气**：如声门上气道失败，以最佳技术尝试面罩通气；如果有效，唤醒患者或制订计划。
- **方案D，紧急颈前气道**：如出现**“不能插管、不能氧合”（CICO）**，大声宣布，并建立颈前气道，通常经环甲膜行手术刀–探条–导管环甲膜切开术。
:::

每次插管都要用**二氧化碳波形图**确认：每次通气都有持续、规则的二氧化碳波形。看见导管通过声带、胸廓起伏和导管内雾气都不可靠。心脏骤停时，低但存在的波形仍可确认导管位置；平直的波形在被证明不是之前都意味着导管不在气管内（“没有波形，位置错误”）。英国皇家麻醉医师学院第四次全国审计项目（NAP4，2011）发现，未使用二氧化碳监测是重症监护中许多气道相关死亡的促成因素，如今二氧化碳监测已是所有机械通气患者的标准。

::: warning “没有波形，位置错误”
插管后看到平直的二氧化碳波形时，临床医生有时会归咎于监护仪、采样管或“低心排”，而把导管留在原处。食管插管会在数分钟内因低氧血症致死。如果没有波形，就拔出导管，用面罩或声门上气道给氧，然后再试。心脏骤停时的平直波形尤其容易被误读，因为在有效心肺复苏期间，位置正确的导管仍会给出低但明确的波形。
:::

## 呼吸衰竭 {#def-syndromes}

::: definition 呼吸衰竭 {#def-respfailure}
**呼吸衰竭**是呼吸系统不能维持充分的气体交换。它由动脉血气定义：

- **Ⅰ型（低氧性）呼吸衰竭**：PaO₂低于8 kPa（60 mmHg），PaCO₂正常或偏低。问题在于肺内气体交换：通气–血流比例失调或分流（肺炎、肺水肿、ARDS、肺栓塞）。
- **Ⅱ型（高碳酸性）呼吸衰竭**：PaCO₂高于6.0–6.5 kPa（45–49 mmHg），通常伴低氧血症。问题在于通气不足：呼吸泵衰竭（慢阻肺急性加重、哮喘疲竭、神经肌肉疾病、胸壁疾病、肥胖低通气）或呼吸驱动下降（阿片类、镇静药、脑损伤）。

急性高碳酸血症引起**呼吸性酸中毒**（pH低于7.35）。慢性高碳酸血症时肾脏潴留碳酸氢根，pH接近正常；在此基础上的急性升高（“慢性基础上的急性”）使pH下降。
:::

肺泡气方程可以把低通气与肺部疾病区分开来。

::: theorem 肺泡气方程与A–a梯度 {#thm-aa}
肺泡氧分压近似为

$$
P_AO_2 = F_iO_2 \times (P_{\text{atm}} - P_{H_2O}) - \frac{P_aCO_2}{R}
$$ {#eq-alveolar}

海平面大气压约101.3 kPa，37 °C时水蒸气压6.3 kPa，呼吸商$R \approx 0.8$。**肺泡–动脉（A–a）氧分压梯度**为$P_AO_2 - P_aO_2$。年轻成人呼吸空气时，该梯度低于约2 kPa（15 mmHg），随年龄增大而升高。
:::

::: proof
吸入气在气道中被加温加湿，因此其氧分压为$F_iO_2 \times (P_{\text{atm}} - P_{H_2O})$：呼吸空气时约20 kPa。在肺泡内，氧被摄取、二氧化碳被加入；由于消耗的氧多于产生的二氧化碳（二者之比为$R$），氧分压下降$P_aCO_2/R$，这里用动脉PaCO₂估计肺泡PCO₂。如果肺的气体转运正常，动脉PO₂只比肺泡略低。单纯低通气（如阿片类中毒）使PaCO₂升高、$P_AO_2$降低，但梯度保持正常。梯度增宽则意味着问题出在肺本身：通气–血流比例失调、分流，较少见的是弥散障碍。
:::

::: example 低氧血症来自大脑还是肺？ {#ex-aa}
两位患者在海平面呼吸空气。(a) 34岁女性，海洛因过量后：PaO₂ 7.5 kPa，PaCO₂ 8.0 kPa。(b) 34岁男性，肺炎：PaO₂ 9.0 kPa，PaCO₂ 5.0 kPa。分别计算A–a梯度并解读。
::: solution
(a) $P_AO_2 = 0.21 \times 95 - 8.0/0.8 = 19.95 - 10.0 = 9.95$ kPa。梯度$= 9.95 - 7.5 = 2.45$ kPa，接近正常。她的低氧血症几乎完全可以用**低通气**解释（呼吸抑制所致的Ⅱ型衰竭）。治疗是恢复通气：气道支持、球囊面罩通气和纳洛酮。

(b) $P_AO_2 = 19.95 - 5.0/0.8 = 13.7$ kPa。梯度$= 13.7 - 9.0 = 4.7$ kPa，明显增宽。他的低氧血症来自肺内的**气体交换问题**（实变造成的V/Q比例失调和分流），属Ⅰ型衰竭。治疗是给氧和治疗肺炎。
:::
:::

## 氧疗 {#def-ventilation}

氧是一种药物。开具氧疗时要规定**目标饱和度范围**，并调整剂量使其保持在范围内。

::: definition 目标氧饱和度（BTS） {#def-targets}
英国胸科学会关于急救用氧的指南（2017）建议：

- 大多数急性病成人为**94–98%**。
- 有**高碳酸血症性呼吸衰竭**风险的患者为**88–92%**，在血气结果出来之前即应如此：慢阻肺、重度肥胖、囊性纤维化、胸壁畸形和神经肌肉疾病。
- 危重情况（心脏骤停、休克、脓毒症、重大创伤、严重过敏反应）开始时经储氧面罩以15 L/min给予**高浓度氧**，患者稳定后再调整到目标范围。

不能仅因患者气促或胸痛就给没有低氧血症的人吸氧；在没有低氧血症的急性心肌梗死和卒中中，吸氧没有益处。
:::

为什么氧会伤害部分慢阻肺患者？在慢性高碳酸血症患者中，高浓度氧使PaCO₂升高，主要是因为通气–血流匹配恶化（通气不良区域的低氧性肺血管收缩被解除）以及Haldane效应，呼吸驱动下降的作用较小。结果可能是危险的酸中毒。解决办法不是对低氧血症患者停止给氧，而是用文丘里面罩等可控装置把饱和度调整到88–92%。

**给氧装置**从鼻导管（1–4 L/min）、普通面罩，到能提供固定氧浓度（24%、28%、35%、40%、60%）的**文丘里面罩**，再到储氧（“非重复呼吸”）面罩。

**经鼻高流量氧疗（HFNO）**以最高约60 L/min的流量输送加温加湿、氧浓度设定的气体。高流量满足患者的吸气需求，冲洗无效腔，并提供少量气道正压。它舒适，允许进食和说话，广泛用于Ⅰ型呼吸衰竭。

## 无创呼吸支持 {#sec-niv}

**持续气道正压（CPAP）**通过密闭面罩或头罩在整个呼吸周期施加相同压力。它使塌陷的肺泡复张、改善氧合，因此用于Ⅰ型衰竭：急性心源性肺水肿和部分肺炎。它不直接增加通气。

**无创通气（NIV）**，常称BiPAP，在较低的呼气压（呼气相气道正压，EPAP）之上，于吸气时增加较高的压力（吸气相气道正压，IPAP）。两者之差支持每次呼吸、增加潮气量，因此NIV用于治疗**高碳酸性（Ⅱ型）衰竭**。

::: definition 慢阻肺中NIV的指征 {#def-niv}
BTS/英国重症监护学会关于急性高碳酸血症性呼吸衰竭的指南（2016）建议：慢阻肺急性加重患者在立即给予最佳药物治疗（控制性氧疗、雾化支气管扩张剂、激素，有指征时用抗生素）后，仍持续**pH低于7.35且PaCO₂高于6.5 kPa**者，使用NIV。开始之前应明确NIV失败后怎么办：患者是否插管，还是以NIV为治疗上限。1–2小时内复查血气并调整参数。
:::

NIV不适用于不能保护气道、分泌物多、呕吐、面部外伤或未处理的气胸的患者，也不适用于病情过重、推迟插管会有危险的患者。

::: example “只是慢阻肺急性加重”的72岁女性 {#ex-niv}
一名72岁慢阻肺女性由救护车送来，途中经储氧面罩吸氧15 L/min达40分钟。她嗜睡。SpO₂ 99%。动脉血气：pH 7.21，PaCO₂ 10.4 kPa，PaO₂ 24 kPa，碳酸氢根33 mmol/L。发生了什么？应该怎么办？
::: solution
她有**慢性基础上急性加重的高碳酸性（Ⅱ型）呼吸衰竭**伴呼吸性酸中毒。碳酸氢根升高说明慢性二氧化碳潴留；pH低说明急性升高。她的PaO₂ 24 kPa远高于所需，无控制的氧疗很可能促成了PaCO₂上升和嗜睡。

1. 立即**下调氧疗**，用文丘里面罩（如28%）使目标为88–92%。不要完全撤除氧气：PaO₂会迅速下降。
2. 给予雾化支气管扩张剂（以空气驱动，必要时经鼻导管补充氧）、激素，怀疑感染时给予抗生素。
3. 复查血气。如果pH仍低于7.35且PaCO₂高于6.5 kPa，开始**NIV**，并尽可能事先与她及家人商定治疗上限。
4. 开始NIV后1–2小时复查血气。尽管NIV实施良好仍酸中毒加重或嗜睡加深，就需要决定是否插管。
:::
:::

## 机械通气 {#sec-mv}

有创通气通过气管导管或气管切开导管以正压把气体推入肺内。呼吸机控制一个变量，其余变量随之变化。

- **容量控制**时，临床医生设定潮气量；气道压取决于肺的顺应性和阻力。
- **压力控制**时，临床医生设定吸气压；潮气量取决于肺。
- **压力支持**时，每次呼吸都由患者触发，呼吸机给予设定的压力辅助，因此呼吸频率由患者控制。用于撤机阶段。

每种模式还要设定**呼气末正压（PEEP）**，使肺泡在呼气末保持开放，以及**吸入氧浓度（FiO₂）**。氧合主要由FiO₂和PEEP（平均气道压）控制；二氧化碳清除由分钟通气量（潮气量乘以频率）控制。

### 呼吸机相关肺损伤与肺保护性通气

机械通气本身可以损伤肺，方式包括过度扩张（**容积伤**）、高压（**气压伤**）以及肺泡反复开放和塌陷（**萎陷伤**）。ARDS中受损的肺在功能上很小，即“婴儿肺”：输送给它的正常潮气量会使其中有通气的部分过度牵张。

::: definition 急性呼吸窘迫综合征（ARDS） {#def-ards}
**ARDS**是急性、弥漫性、炎症性肺损伤，导致肺泡–毛细血管屏障通透性增加、双肺阴影和不能完全用心力衰竭或液体超负荷解释的低氧血症。根据**柏林定义**（2012），它在已知诱因后一周内起病，并在PEEP至少5 cmH₂O时按PaO₂/FiO₂比值分级：

| 严重程度 | PaO₂/FiO₂（mmHg） | PaO₂/FiO₂（kPa） |
|---|---|---|
| 轻度 | 200–300 | 26.7–40 |
| 中度 | 100–200 | 13.3–26.7 |
| 重度 | ≤100 | ≤13.3 |

2023年提出的**全球定义**把它扩展到接受经鼻高流量氧疗（至少30 L/min）的患者，在无法查血气时允许使用SpO₂/FiO₂比值，并接受肺超声作为影像学依据，使资源有限的地区也能识别ARDS。
:::

ARDS救治的基石是**肺保护性通气**。ARDS协作网试验（2000）比较了按预测体重计6 mL/kg和12 mL/kg的潮气量：较低潮气量使死亡率从39.8%降至31.0%。

::: algorithm 肺保护性通气 {#def-lpv}
1. 根据身高和性别计算**预测体重**（PBW），而不是用实际体重：男性$50 + 0.91 \times (\text{身高cm} - 152.4)$ kg；女性$45.5 + 0.91 \times (\text{身高cm} - 152.4)$ kg。
2. 潮气量设为约**6 mL/kg PBW**（范围4–8）。
3. 保持**平台压≤30 cmH₂O**。
4. 使**驱动压**（平台压减PEEP）尽可能低；高于约15 cmH₂O与更高的死亡率相关。
5. 使用足够的PEEP保持肺泡开放，以FiO₂/PEEP对照表或对调整的反应为指导。
6. 只要pH可以接受（常为高于约7.20），接受PaCO₂升高（**允许性高碳酸血症**）。
7. 中至重度ARDS（PaO₂/FiO₂低于150 mmHg，约20 kPa）时，每天至少16小时**俯卧位通气**。
:::

俯卧位改善通气与血流的匹配，并使应力在肺内分布更均匀。在PROSEVA试验（2013）中，重度ARDS早期长时间俯卧位使28天死亡率从32.8%降至16.0%。重症时的其他选择包括短期使用神经肌肉阻滞剂，以及在专科中心为经选择的患者使用**静脉–静脉ECMO**，在体外为血液氧合，让肺得到休息。

::: example 设定呼吸机 {#ex-pbw}
一名45岁男性，身高180 cm，体重110 kg，因重症肺炎插管。PEEP 10 cmH₂O时PaO₂/FiO₂比值为15 kPa（约113 mmHg），双肺阴影。为他的ARDS分级，计算初始潮气量；如果平台压为28 cmH₂O，核查他的驱动压。
::: solution
PaO₂/FiO₂为15 kPa（113 mmHg），属于**中度**（100–200 mmHg）。

预测体重：$50 + 0.91 \times (180 - 152.4) = 50 + 25.1 = 75.1$ kg。按6 mL/kg PBW，潮气量为$6 \times 75.1 \approx 450$ mL。（用他的实际体重110 kg会得到660 mL，这是危险的高估：肺的大小取决于身高，而不是体脂。）

驱动压$= 28 - 10 = 18$ cmH₂O。平台压在30的限值以内，但驱动压偏高。团队可以进一步降低潮气量（向5 mL/kg靠近），接受较高的PaCO₂，重新评估PEEP；由于PaO₂/FiO₂比值低于150 mmHg，应开始俯卧位通气。
:::
:::

::: example 引发心脏骤停的插管 {#ex-periintub}
一名61岁女性因肺炎发生脓毒性休克，经高流量氧疗FiO₂ 0.8时SpO₂ 89%，使用去甲肾上腺素时血压86/50 mmHg，呼吸频率38次/分。一名低年资麻醉医生计划进行标准RSI。诱导后一分钟内，她的血压测不到，发生了PEA骤停。为什么？本可如何预防？
::: solution
她是**生理性困难气道**：严重低氧血症、氧储备极少，休克伴交感张力高，呼吸频率快（常提示她正在代偿严重的代谢性酸中毒）。

诱导时三件事同时发生：诱导药消除了她的交感张力并抑制心肌；正压通气减少了静脉回流；置管期间的呼吸暂停使饱和度下降、二氧化碳升高，加重了酸中毒。

预防：插管前先复苏（有液体反应性则补液，血管加压药持续输注并加量，抽好推注用的血管加压药）；用经鼻高流量氧或NIV预充氧，喉镜操作期间保持给氧；选用对心血管影响小的诱导药并减量；由经验最丰富的操作者插管；把呼吸机频率设定为与插管前分钟通气量相匹配；并向团队简报骤停时的预案。插管前后的骤停按[[emergency-critical-care/resuscitation#def-als]]处理。
:::
:::

::: example 甲状腺切除术后的肿胀 {#ex-haematoma}
一名48岁女性甲状腺切除术后四小时出现焦虑、气促、喘鸣，颈前出现张力性肿胀。发生了什么？即刻治疗是什么？
::: solution
甲状腺术后颈部**血肿**不断扩大，压迫静脉和淋巴管，引起喉水肿和进行性气道梗阻。这是急症。

即刻治疗是**在床旁打开伤口**：剪开皮肤缝线和深层肌肉缝线以释放血肿（SCOOP法：暴露皮肤Skin exposure、剪断缝线Cut sutures、打开皮肤Open skin、打开肌层Open muscles、填塞伤口Pack wound），同时呼叫高年资麻醉医生和外科医生并给予高流量氧。减压后气道常迅速改善。之后她返回手术室止血，由经验丰富、做好困难气道准备的麻醉医生插管，因为减压后喉水肿可能仍然存在。
:::
:::

::: example 双肺清晰的气促患者 {#ex-clear-chest}
一名39岁男性气促，未吸氧时SpO₂ 88%，呼吸频率30次/分，脉率118次/分。听诊双肺清晰，胸片正常。未吸氧时动脉血气：PaO₂ 7.4 kPa，PaCO₂ 4.0 kPa。应考虑什么？
::: solution
低氧血症伴双肺清晰、胸片正常，意味着肺实质看起来正常而气体交换受损。$P_AO_2 = 19.95 - 4.0/0.8 = 14.95$ kPa，A–a梯度约7.6 kPa：明显增宽。

首要病因是**肺栓塞**，它引起V/Q比例失调而无可见的肺部改变。其他可能包括心内或肺内分流、早期肺炎（尤其是免疫抑制患者的*Pneumocystis*肺炎），以及高铁血红蛋白血症（此时SpO₂偏低而PaO₂正常；本例并非如此，因为他的PaO₂偏低）。他需要按目标给氧、计算Wells评分、做CT肺动脉造影，如肺栓塞可能性大则抗凝。见[[respiratory/interstitial-vascular-disease]]。
:::

::: quiz
一名机械通气患者原本正常的二氧化碳波形突然变平，氧饱和度开始下降。首先应检查的最可能原因是什么？
- [ ] 过度通气。
- [x] 气管导管移位或脱开，或者回路或导管完全堵塞。
- [ ] 心排血量改善。
- [ ] 脉搏血氧仪故障。
::: solution
机械通气患者的二氧化碳波形突然消失，意味着肺内没有气体呼出：导管脱出气管、脱开或堵塞，或者（如果患者同时失去心排血量）发生了心脏骤停。立即检查患者和导管。机械通气患者突然恶化时，一个有用的记忆口诀是DOPES：移位（Displacement）、阻塞（Obstruction）、气胸（Pneumothorax）、设备故障（Equipment failure）、呼吸叠加（Stacked breaths）。
:::
:::

::: history
1952年哥本哈根脊髓灰质炎流行期间，Blegdam医院收治的呼吸肌麻痹患者多得无法应对，被放进为数不多的负压呼吸机（“铁肺”）的患者大多死亡。麻醉医生易卜生（Bjørn Ibsen）提出改用气管切开和橡皮囊手动正压通气来治疗。数百名医学和牙科学生轮班昼夜挤压气囊，死亡率大幅下降。把病情最重的患者集中在一个区域并给予持续照护，成为重症监护病房的模式。几年之内，机械正压呼吸机取代了学生。1967年，丹佛的David Ashbaugh、Thomas Petty及其同事描述了ARDS；2000年的ARDS协作网试验表明通气本身可以造成伤害，改变了全世界的呼吸机使用方式。
:::

## 后续内容

气体交换生理和氧–血红蛋白解离曲线见[[respiratory/gas-exchange]]和[[respiratory/respiratory-failure]]；慢阻肺和哮喘见[[respiratory/asthma-copd]]。机械通气患者的长期照护、镇静和撤机见[[emergency-critical-care/critical-care]]。麻醉（包括常规气道管理）见[[surgery/anaesthesia-pain]]。

::: summary
- 部分气道梗阻有声音，完全梗阻寂静无声；先用仰头抬颏或推举下颌、吸引和辅助装置。
- 急诊气管插管采用快速顺序诱导；危重患者生理上处于危险之中，因此诱导前先复苏。
- DAS 2025：方案A插管，方案B声门上气道，方案C面罩，在“不能插管、不能氧合”时用方案D颈前气道。每根导管都要用二氧化碳波形图确认：没有波形，位置错误。
- Ⅰ型呼吸衰竭是低氧血症伴PaCO₂正常或偏低；Ⅱ型另有PaCO₂高于约6.5 kPa。A–a梯度可以区分肺部疾病和低通气。
- 开具氧疗要有目标：大多数人94–98%，有高碳酸血症风险者88–92%。
- CPAP改善氧合；NIV支持通气，用于药物治疗后pH仍低于7.35且PaCO₂高于6.5 kPa的慢阻肺患者。
- ARDS：潮气量约6 mL/kg预测体重，平台压30 cmH₂O或以下，低驱动压，足够的PEEP，PaO₂/FiO₂低于150 mmHg时俯卧位通气。
:::

## 习题

::: exercise 预测体重 {level=1 check="342"}
一名女性身高165 cm，体重95 kg。按6 mL/kg预测体重计算潮气量，四舍五入到整数mL。
::: solution
PBW $= 45.5 + 0.91 \times (165 - 152.4) = 45.5 + 11.466 = 56.966$ kg。潮气量$= 6 \times 56.966 = 341.8$，四舍五入为**342 mL**。她的实际体重与肺的大小无关。
:::
:::

::: exercise 驱动压 {level=1 check="18"}
一名机械通气患者平台压30 cmH₂O，PEEP 12 cmH₂O。驱动压是多少cmH₂O？
::: solution
驱动压$= 30 - 12 = 18$ cmH₂O。它高于约15，而高于15与更高的死亡率相关；降低潮气量可以使其下降。
:::
:::

::: exercise A–a梯度 {level=2 check="4.7"}
一名患者在海平面呼吸空气，PaO₂ 9.0 kPa，PaCO₂ 5.0 kPa。取$P_{\text{atm}} = 101.3$ kPa、$P_{H_2O} = 6.3$ kPa、$R = 0.8$，计算A–a梯度（kPa，保留一位小数）。
::: solution
$P_AO_2 = 0.21 \times (101.3 - 6.3) - 5.0/0.8 = 19.95 - 6.25 = 13.7$ kPa。梯度$= 13.7 - 9.0 = 4.7$ kPa，增宽，提示问题在肺。
:::
:::

::: exercise 呼吸衰竭的类型 {level=1}
把下列动脉血气（均为呼吸空气时）分类为正常、Ⅰ型或Ⅱ型呼吸衰竭，并给出一个可能的病因：(a) PaO₂ 7.2 kPa，PaCO₂ 4.1 kPa；(b) PaO₂ 7.0 kPa，PaCO₂ 8.9 kPa，pH 7.26，HCO₃⁻ 30 mmol/L；(c) PaO₂ 12.5 kPa，PaCO₂ 5.1 kPa。
::: solution
(a) Ⅰ型：低氧血症伴PaCO₂偏低（过度通气）。肺炎、肺水肿或肺栓塞。
(b) Ⅱ型：低氧血症伴高碳酸血症和酸中毒；碳酸氢根升高提示慢性基础上急性加重。慢阻肺急性加重。
(c) 正常。
:::
:::

::: exercise 开具氧疗 {level=2}
为下列患者开具氧疗医嘱：(a) 55岁肺炎患者，未吸氧时SpO₂ 90%，无肺部疾病；(b) 68岁慢阻肺患者，未吸氧时SpO₂ 85%，既往有高碳酸血症性衰竭；(c) 50岁胸痛患者，未吸氧时SpO₂ 97%。
::: solution
(a) 目标94–98%；先用鼻导管2–4 L/min或普通面罩，调整至目标范围。
(b) 目标88–92%；24%或28%文丘里面罩，查动脉血气以了解PaCO₂和pH，调整后复查。
(c) 不吸氧；他没有低氧血症。监测饱和度，如出现低氧血症则以94–98%为目标。
:::
:::

::: exercise 紧急气道的顺序 {level=2}
一次急诊插管中，第一次用可视喉镜的尝试失败，饱和度为90%。按DAS预案描述接下来的步骤。
::: solution
尽早呼救，保持给氧。在方案A内优化后，如合适可再作有限次数的尝试（调整体位、使用探条、喉外按压、换用不同镜片或操作者）。如果插管失败，宣布失败并转入**方案B**：置入第二代声门上气道并给氧。如果有效，停下来思考：可能的话唤醒患者，或继续使用声门上气道，或经其用纤维支气管镜插管。如果无效，转入**方案C**：双人配合辅助装置进行面罩通气。如果这也失败且饱和度下降，宣布**“不能插管、不能氧合”**，毫不迟延地实施**方案D**——手术刀环甲膜切开术。
:::
:::

::: exercise 用不用NIV？ {level=2}
一名65岁慢阻肺男性在雾化和激素治疗一小时后，吸28%氧时pH 7.31，PaCO₂ 7.8 kPa，PaO₂ 8.4 kPa。他清醒，咳出中等量的痰。他应该用NIV吗？还必须决定什么？
::: solution
应该。他符合标准（最佳药物治疗后pH低于7.35且PaCO₂高于6.5 kPa），清醒且能清除分泌物。开始之前，团队必须商定并记录NIV失败后怎么办：升级到插管和ICU，还是以NIV为治疗上限。这应当让他本人参与。1–2小时内复查血气；如无改善，应复核参数、面罩密合度和计划。
:::
:::

::: exercise 设计拔管 {level=3}
一名58岁女性因肺炎机械通气6天。现在为压力支持8 cmH₂O，PEEP 5 cmH₂O，FiO₂ 0.35，SpO₂ 96%，呼吸频率18次/分，能遵嘱动作、咳嗽有力。30分钟自主呼吸试验成功。拔管前还应评估什么？拔管失败的危险因素有哪些？
::: solution
拔管前：意识水平和遵嘱能力；咳嗽力量和分泌物量；气道通畅性（怀疑喉水肿时可做套囊漏气试验）；血流动力学稳定；液体平衡；以及拔管后的支持计划。失败的危险因素包括年龄超过65岁、心力衰竭、慢阻肺、咳嗽无力、分泌物多、液体正平衡、通气时间长和体重指数高。对高危患者，拔管后预防性使用NIV或经鼻高流量氧可降低再插管风险。撤机的进一步内容见[[emergency-critical-care/critical-care]]。
:::
