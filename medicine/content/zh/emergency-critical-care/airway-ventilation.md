气道与呼吸是每个复苏的前两个字母是有原因的：缺氧在数分钟内杀人、而干预是急性医学中技术与认知要求最高的之列。**本章讲述从体位与吸引到声门上装置到快速顺序插管、及“无法插管无法氧合”逃生（颈前入路）的气道评估与管理、作为自身复苏的插管围期（多数课程仍教学不足的血流动力学与低氧风险管理）、作为带目标范围与毒性处方药的氧（自由对保守氧试验时代）、无创与高流量呼吸支持及其诚实指征、及按ARDS证据做肺保护的气道内机械通气（潮气量与平台压及PEEP及俯卧位及麻痹层级）及用脱机规程撤机。其支配事实是：手术室外的插管是一个血流动力学与低氧事件、必须像对待这样一个事件那样准备、而呼吸机是一个加压给药装置、其剂量能治愈也能撕裂肺。**

## 气道

::: definition 气道评估与管理 {#def-airway}

## 呼吸支持

::: definition 氧、无创支持与通气患者 {#def-ventilation}

## 接口处的综合征

::: definition 急性低氧与高碳酸衰竭：各项决定 {#def-syndromes}

130公斤BMI 47睡眠呼吸暂停女性因肺炎低氧恶化需紧急插管。什么使预充氧成功或失败、而“失败”改变你计划的什么？
::: solution
**预充氧作为预后（[[#def-airway]]）：成功因素——被审计而非假定的坡位（外耳道高于胸骨切迹、反Trendelenburg与简报及枕头及谁知道怎么给这个患者摆坡位）、清醒体位选择（她可能已经坐位数周、而把她放平做喉镜是你仍能避免的对气道的损伤：考虑坐位插管计划）、带良好密封的高流量或非再吸入面罩及鼻滴窒息氧合、及“排氮时间比你想的短：测量、观察下降、并在你的脱饱和阈值下20%停下”——因为你已经失去了三分之一安全窒息时间。失败——若预充氧无法让她安全、那么清醒插管就是正确操作、不是勇气的失败（保持她自主呼吸的局麻清醒技术、及计划好并在场或可召的耳鼻喉与外科气道后备）、及“大声说出B到Z计划”、因为BMI 47脓毒症患者的60秒脱饱和就是你没有发生的第二次尝试中的骤停。对尝试体位与时间的记录既为她下次插管也为你下次。**
:::

::: exercise 判断拔管 {level=2}
ICU第8天、慢阻肺与肥胖、因高碳酸衰竭插管现改善：套囊漏气存在但小、咳嗽弱、分泌物频繁、她在压力支持5-PEEP 5下通过30分钟自主呼吸试验、呼吸26、血氧93%。拔管、再插管、还是气管切开？与自己辩论。
::: solution
**脱机判断呼叫（[[#def-airway]]、[[#def-ventilation]]）：赞成的理由——试验通过伴轻度气促、但试验不是水晶球：真正的预测因子是咳嗽强度与分泌物量及意识状态轨迹、及她能否保护气道并清除她产生的东西、而小套囊漏气伴弱咳就是长了脸的拔管失败画像；现在反对气管切开——第8天对一个可能可脱机患者的气管切开是一个过早的造口、带其并发症与长期气管切开及污名及沟通与丧葬安排含义、不是中立的安全动作、而14天经验法则证据（早期对晚期试验）说晚期不致命、许多单位以“我们拔管到预防性无创或高流量并在48小时重评脱机、只有她失败两次或分泌物负荷占主导才谈气管切开”协商。这位患者应得的那一版——计划的分级拔管（慢阻肺高碳酸患者试验结束时立即上无创、这就是预防性无创证据、及“带着计划而不是希望拔管”的儿科与心脏类比）、及吸痰管在手及再插管设备核查、及“为喘鸣而不是恐慌叫我们”的教育、及72小时ICU或HDU观察、及理疗与咳嗽辅助及黏液动力计划、及吞咽与营养及义齿与活动工作——这才是“拔管成功”实际由什么构成、而若她失败、气管切开决定会得到第二次会议。**
:::

::: exercise 审计氧安全 {level=2}
你的审计：96%的氧处方没有目标范围、夜间血氧84%按规程“调大”处理、慢阻肺患者从养老院带着6升无监测到来。设计指南标准隐含的氧治疗规划。
::: solution
**氧治理（[[#def-ventilation]]、[[clinical-skills/patient-safety]]）：规划——氧作为药物写入用药记录伴指征与目标范围及复查日期、因为指南明确而系统不明确、及每个床旁一页的装置与流量升级阶梯、在流量计下印着“查患者不查刻度”步骤（体位、密封、依从、分泌物）、及护理规程：记录的脱饱和触发一次评估而不是经验性加大、因为“调大”是坏医学的理疗。低氧与高碳酸安全网——“低血氧升级”计划在慢性潴留者要求血气、并做快速反应审查并记录理由、因为治低氧是对的而治过度氧合也是对的、而悄悄进入麻醉的隐匿2型癌今晚就在你的养老院队列里。教育与审计——所有处方者与护士的氧胜任力伴年度消防演练式审计（无理由编码的“血氧差”病例及未复查的氧撤离拒绝）、及带门诊呼吸随访的出院氧规则——因为家庭氧是一项有指征的治疗、不是永远留着的舒适物品、而其证据要求动脉验证。要紧的指标：氧曾被停止的患者比例、因为没人停止的治疗就是一个习惯、而氧的全部历史就是这个习惯的传记。**
:::

::: exercise 主持院前气道辩论 {level=3}
贵急救医疗主任提议允许急救员在院外心脏骤停中放置声门上装置、行氯胺酮辅助插管与针环甲膜切开；麻醉与急诊顾问反对说“气道管理的证据薄弱”。诚实地用证据层级与系统视角写决策备忘录。
::: solution
**急救气道政策决定（[[#def-airway]]、[[emergency-critical-care/resuscitation]]、[[public-health/prevention-promotion]]）：诚实的证据总结——气道管理文献被观察性数据主导、因为对骤停气道做随机几乎不可能；我们有的是：CPR质量文献（任何中断按压的气道都有害）、院前插管的误吸对面部创伤对插管失败的观察性系列权衡、基础气道与球囊面罩胜任力及CICO规程的强共识、及声门上与（在有经验者手中）高级气道可安全而不损害生存的队列数据、加上近期视频辅助与首次成功强调的试验大多改变如何做而不是做不做；所以“证据薄弱”作为死亡陈述是对的、而作为不作为陈述是错的；系统设计答案——操作绝不可与按压和电击及转运竞争（“不为第二次插管尝试停止CPR”规则、及“送到有ECMO与气道能力的医院”替代哲学——比较研究比欧洲争论更好地说明了它）、及胜任力模型（“低容量操作需要高容量操作者”问题、靠把技能组限制在做够量的机组或不提供来解决、及“针环甲膜从没用过也没人培训”悖论——预备状态本身会衰减）、及测量（启动规划所需的“气道精通”指标伴首次成功率与并发症、及“无法通气”或“从未用外科救援”事件触发培训暂停、因为规划只有能在它不再好时被关掉才是好的）；备忘录收尾段——顾问们说得对：没有试验会祝福这件事；而他们说因此什么都不该改是错的：证据支持一个胜任力闸门、保护按压、升级封顶、带实时质量监测的规划、困难气道的延后路径（更早更频繁地落地、装载并移交给医院气道团队）、及向公众诚实声明：对骤停最强的院前干预仍然是手按胸、一台除颤器和一趟快车、而这项气道扩展为少数患者买来一座桥、不是一种治愈。**

## 通向何处

底层生理在[[respiratory/gas-exchange]]与[[respiratory/mechanics-breathing]]与[[respiratory/control-breathing-tests]]、哮喘与慢阻肺细节在[[respiratory/asthma-copd]]、ARDS与ICU接口在[[emergency-critical-care/critical-care]]、麻醉气道实践在[[surgery/anaesthesia-pain]]、及照护天花板谈话在[[medical-ethics-law/end-of-life-ethics]]。

::: history
**气道与呼吸机各有独立的历史、在重症病房汇合。气道历史始于器械：1870年代McEwen的插管、1890年代Kirstein的直接喉镜、Guedel通气道与1930年代初的带套囊管使控制通气安全到可以常规、及Sells 1941年专著分类插管技术及其失败——住院医师仍在学同一分类学。然后流行病学作为灾祸到来：Beecher 1956年的麻醉死亡审计、及1980-2000年代澳大利亚与美国的结案索赔分析把“困难气道”从工匠传说转变为核查表、强制二氧化碳描记图、及困难气道学会与麻醉师学会的指南；2013年第四次国家审计项目提出现代控诉——许多灾难性气道死亡涉及非麻醉人员、无气道计划的镇静、或夜间独处的初级被独自留下——这就如今天教授的每次围插管简报的祖先。外科气道从19世纪气管切开的名望、经战间期的感染伤痕、平行移动到作为复苏技能的环甲膜切开、带说明书标签的套件、因为当它被需要时操作者通常从未做过。呼吸机历史是工程加流行：1928年Drinker-Shaw铁肺、及1952年哥本哈根脊髓灰质炎之冬——Ibsen的方案（麻痹、长时间通气、湿化、让他们保持清醒并一对多护理）把死亡率从约90%降到40%、并几乎在一个动作里发明了重症监护医学、而Lassen的单元正式化了正压脊髓灰质炎病房谱系。医源性阶段随之：PEEP与高频及一氧化氮时代教导支持气体交换并非无害、1994-2012年ARDS定义使损伤肺成为一个研究对象、而2000年ARDSNet试验——仅潮气量就把死亡率从31%降到12%——仍是重症监护最有后果的实验、并证明呼吸机输送的是一个剂量。俯卧位在1976年Douglas-Fishman观察积尘二十年后由2013年PROSEVA平反、而2015-2024高流量与无创病房试验潮、及2020年的俯卧位与呼吸机分诊速成班、完成了装置经济学图景。氧闭合了环：从“生命空气”乐观主义经1950年代早产儿视网膜病的反转、到2017-2024保守氧试验显示过度氧合是一个值得五万患者去反驳的暴露——这就是历史的警告浓缩为一句：每一项呼吸干预都被发现两次、一次作为救援一次作为伤害、而间隔以患者计。** — [[respiratory/gas-exchange]]、[[surgery/anaesthesia-pain]]、[[medical-ethics-law/justice-resources]]。**
:::

::: summary
- 气道管理是一门准备学科：预测困难、优化体位与预充氧、用二氧化碳描记图验证、并在麻痹之前知道你的逃生路线（声门上救援、然后颈前入路）。
- 围插管是一次复苏：可能的话先纠正低血压、缺氧、酸中毒与低血容量、为这颗心选择诱导药、并把首次尝试优化当作一个安全结局。
- 氧是有目标范围与毒性的处方药；自由氧时代安静地一次试验一次试验地结束——正常血氧不是一个目标。
- 无创通气在慢阻肺酸中毒与心源性水肿救命；高流量帮助选定的低氧患者；在新发低氧衰竭中别让装置延迟一个有指征的插管。
- 肺保护通气是算术：每公斤预测体重6毫升、平台压上限、PEEP滴定、重度ARDS俯卧位、及带自主呼吸试验的脱机规程。
- 不插管的决定与插管一样是临床的：天花板、照护天花板记录、及诚实谈话与喉镜属于同一胜任力。
:::

## 练习

::: exercise 编排崩溃气道 {level=1}
你诱导一位95公斤重度血管性水肿患者；直接喉镜4级、两次尝试失败、血氧88%且在下降、面罩无法通气。陈述接下来四个动作及其时机。
::: solution
**执行的CICO（[[#def-airway]]）：四个——呼叫困难气道车与第二位高年资者并具名宣布“这是CICO”（Z计划声门上救援尝试一次——尺寸正确的第二代装置——同时定位并标记颈部、因为指南把这算作最后的非外科步骤、而这里的时钟是分钟不是尝试次数）；若通气未建立、现在颈前入路（甲状腺切迹前方环甲膜切开技术及“我已宣布、有人在拿套件、外科知情”的团队简报、及导丝引导的管或导管及套囊充气及ETCO2确认）、及“我能通过外科气道通气所以别再跟口腔纠缠”逻辑、及救援后耳鼻喉与ICU的正式确定性气道计划及事件同班次报告与复盘、因为操作者需要的是一位同事不是一位心理咨询师、及时间与尝试次数的记录、因为患者可能在验尸官邻近的争论中醒来——争论你有没有遵循本该遵循的算法。**
:::

::: exercise 滴定呼吸机 {level=2}
中度ARDS、P/F 140、通气8毫升/公斤于12、平台压31、pH 7.24二氧化碳6.5：写出接下来24小时的通气管理及其救援阶梯顺序。
::: solution
**保护阶梯（[[#def-ventilation]]）：纠正——降到每公斤预测体重6毫升（按男女身高做预测体重算术、不是实际体重）、接受允许性高碳酸的pH底线（碳酸氢盐与肾代偿时间及缓冲之辩答案保守）、并把平台压压到28以下（镇静并可能早期麻痹以停止双重触发、并为平台而不是为二氧化碳降呼吸频率）；氧合侧——PEEP-FiO2表伴对照顺应性与可招募性滴定PEEP（开放肺与复张手法试验教训应用于CT均质可招募型而不是纤维化型）、及对此P/F的早期俯卧位考虑、在能安全运行时以16小时为目标（带训练有素团队的俯卧位及血气及电阻抗或顺应性反应追踪、及与俯卧位决定配对的重度神经肌肉阻滞作用）；24小时其余——驱动的治疗（无休克后的液体保守策略及找到并治疗病因及血小板与呼吸机相关肺炎组套）、及呼吸机同步审计（带呼气时间纠正的内源性PEEP及分泌物及匹配镇静深度的不同步模式）、及从第2天而不是第8天开始想自主试验、因为脱机是一个策略不是一个事件。**
:::

::: exercise 正确开氧 {level=2}
为下列写氧医嘱（装置、目标、复查、撤离）：(a) 慢阻肺加重、既往插管、肥胖；(b) 骤停后ROSC、救护车空气下血氧99%；(c) 社区获得性肺炎、12岁、血氧90%、WHO快速通道标准。
::: solution
**三个医嘱（[[#def-ventilation]]）：(a) 文丘里24或28%或控制系统伴目标88-92及急性呼吸方案下30-60分钟血气、及无创标准与天花板计划好、及体重与睡眠呼吸障碍之问、因为“既往插管肥胖慢阻肺”是高碳酸帽子戏法、及写下升级与停止复查使护士能双向滴定；(b) 下调路径（救护车氧继续而时代说正常血氧已足够而过度氧合信号不令人安心、所以设目标94-98伴血气与滴定、及每日的“氧去处方化”复查、因为骤停后过度氧合是试验命名的暴露）；(c) 儿科版本94以上目标伴氧治疗指南与临床审查及WHO儿童住院标准被遵守、及发热与液体及抗生素与安全网、及“氧在儿童也是药”的撤离计划、因为为了安全把他留在氧上就是让出院被一个父母在家能跑赢的血氧延迟。**

**气道安全系统（[[#def-airway]]、[[clinical-skills/patient-safety]]）：结构——一位带临床治理牙齿的单一气道负责人（气道委员会伴麻醉与急诊及ICU及耳鼻喉及外科及护理代表、因为事件发生在科室之间而规划也必须如此）、风险分层的人员规则（“预期困难气道及ICU及急诊及肥胖及血管性水肿及部分梗阻气道得到两名顾问或一名顾问加一名从业者并带计划好的技术”政策——这是国家审计项目与困难气道学会邻近的期望、及夜间规则：第二位到场是一项权利不是人情、因为你三起事件中两起是单独行动）；培训——原位困难气道与CICO及外科气道演练伴测量到刀时间（模拟与团队演练及耳鼻喉在沟通计划上、及“是排练不是讲座”证据、及麻醉与急诊及ICU注册医师共用课程、因为共同语言就是使两名高年资者能协作的东西、及护理与高级实践者的气管固定与早期恶化升级）；设备——全院标准化的困难气道车每月审计带图片与核查表及车上的视频喉镜带充电纪律、及每个气道辖区车上的环甲膜切开套件带说明卡、因为在50秒时记忆会失败、及气管切开应急包及面向病房员工的“气管切开在位警报”升级卡——他们绝不该是第一个自己琢磨明白的人；测量——按操作者年资与时段审计的首次成功率及失败与并发症率（登记参与、因为你的数字在被计数时改善）、围插管骤停与心脏并发症作为警示邻近追踪事件、每起在48小时内复盘并报告给规划、及每次ICU拔管与气管切开决定的“计划对非计划”分类、带使“何时”决定及时的撤机与气切门诊、及内部公布的年度气道安全报告伴死亡率与死亡并发症数字及员工信心调查、因为一个不能产出对手术刀自在的人的规划只是半个规划。**
