重大事件医学是以非凡数量做普通医学的学问：把混乱变成分类检伤、指挥结构与容量激增的学说、事先写成、因为在头十分钟里它无法被发明。**本章讲述事件系统（宣布及其阶段、指挥与控制架构、四个C、及2005年伦敦与2017年曼彻斯特的互通性与术语教训）、大规模伤亡条件下的临床学说（START与JumpSTART分类检伤语法及其预期死亡类别的伦理、现场医学与洗消决定、及爆炸与挤压及火灾及化学制剂的伤害模式）、及医院自身的重大事件（内部容量激增、关闭系统的网络攻击、及升级到疫情规模）加善后文献（恢复阶段、员工福利与道德损伤数据、演练与调查循环、及为何行动后报告是应急规划中最救命的一份文件。）**

## 系统

::: definition 宣布、指挥结构与四个C {#def-system}
**定义与宣布（重大事件是任何事件需求超出服务常规容量的情形——这一相对定义使“好天气里的单车事故”与“没有空救护车的持刀伤人”都成为被宣布时的重大事件、由第一响应责任人或控制室或医院值班行政官宣布、而坦承职责与记录规则适用于宣布本身及其即时复审）；阶段（减缓-备灾-响应-恢复循环：英国应急秘书处与卫生应急备灾指导及美国事件管理系统及澳大利亚全危害学说都教它——事件前的危害地图与计划和演练及储备工作、响应的数小时、恢复者调查的数周、及公共卫生与工程师争论下一次是被预防还是仅被幸存的减缓）；指挥架构（从警务借用的金-银-铜战略-战术-作战分层、为消防与救护与医院使用、多机构协调中心、及医院的应急班子或事件管理团队带其角色写在塑封卡上、因为记忆会在错误的时刻失效、及其实体或虚拟事件室带“计划就是知道计划的人”格言）；四个C（指挥、控制、协调、沟通、加教训不断补充的第五个：语言的清晰）及写下学说的两个著名失败综合征：2005年7月7日伦敦响应中三个应急部门在空中无法互相通话（互通性复审、专用网络投资、及各部门如今无穷演练的各种首字母词）、及通讯室超载与医院到达含糊（2017年曼彻斯特竞技场复审后的“每个接收医院一条热线”实践、及伦敦桥同夜系列中患者在任何部门知晓前就自行就诊的前送到院信息问题）；作为共享语法的分类系统（军民两用的“重伤但能走”学说带标准化的METHANE报告（位置-类型-危害-通道-伤亡人数-应急部门-需求）、及急诊演练的到达分类）；医院侧的容量激增杠杆（内部重大事件计划的分级行动：“召集与取消”带必须演练的电话树因为名单会烂掉、及“额外重症照护与手术室与病房容量”计划带每月更新的设备与床位数据库、及血液大量输血规程与放射与检验与太平间（伤亡身份识别标准作业程序带警方与消防身份辨认及没人喜欢而每个做过的人都说值得的对账演练）、及“家属接待中心远离急诊入口”的2005与2017教训、因为挤满接收医院的家属是另一个名字的第二事件）；及调查不断击中的沟通层大白话无线电规程与避免多机构间不被理解的代号（“对医院毫无意义的代号”教训）、每事件单一信息线与对公众的“医院已满”信息——它把能走的轻伤者从不正确的门自救、及新闻官作为临床安全角色、因为一次广播“来我们急诊”的错误会淹没一家医院、及如今包括联合信息中心演练的重大事件通讯培训。**

## 临床工作

::: definition 大规模伤亡条件下的分类检伤与伤害模式 {#def-clinical}

## 善后

::: definition 恢复、福利与学习系统 {#def-aftermath}
**恢复阶段（“解除了是一个临床事件”规则：分阶段回归正常带补货与设备维修清单用大白话口述并签署、因为事件后的库存恰恰在被假定已满的备件柜处失败、及复盘与行动后复审文化带其“按学说行事不责备而完全问责忽视学说”的平衡、及演练与真实事件——英国与澳大利亚及加拿大及美国的演练报告公开摘要在事件之间使学说保持活力）；人的因素文献响应者士气与道德损伤研究（“头72小时没事；崩溃在第3周”模式、福利团队必须为此排班、及2005伦敦与2017曼彻斯特非正式教给而疫情正式化的“睡眠、食物、补液与一个坐的地方”领导科学、及哀伤与同伴支持及职业健康路径、及“坚忍就是专业”的文化变更——各部门仍在抗争、及家属侧善后：急性应激与创伤后应激及复杂性哀伤流行病学、灾害精神医学文献（世界卫生组织紧急状态心理健康指导邻近、及“单次心理疏导不工作”证据、及静观等待与认知行为治疗及社区恢复的替代）——这是响应的公共卫生半边、及“事件后的儿童与学校”学说带其“回归常规就是治疗”的证据）；学习系统（组织教训的调查与复审——7/7报告与曼彻斯特竞技场与伦敦桥及疫情公开调查及美国9/11与卡特里娜飓风行动后分析、其发现押韵：通讯、指挥清晰、容量激增现实核查、弱势人群计划、及“计划假定上一次审计已经砍掉的资源”发现）及韧性与减缓文献（2015-2030仙台减灾框架与“重建更好”及世界卫生组织医院安全指数（“灾害中一家安全的医院就是灾害的ICU”逻辑：结构改造、设备与发电机及制氧机的非结构锚固、及电力与水务及网络邻近公用业务的业务连续性）——这是灾害医学与公共卫生与土木工程汇在同一条预算之处）；及临床医师的个人备灾“知道你的计划、知道你的角色、收拾你的包”个人就绪学说、让你能在风暴中离家“谁照看我的孩子”终结了比恐惧更多响应的家庭照护计划、及被宣布事件中普通临床医师的专业与法律素养：在合理安全内出勤的义务、重大事件学说下改变照护标准（“你按可能的而不是理想的被评判”的赔偿与指导现实直白说出、使它在分类点改变行为而不是稍后让任何人吃惊）、及混乱中的记录最低量名字、时间、标签、及事件日志的副本——每次事件后的民事诉讼与死因审讯证明它们在数年后被逐行阅读。**

::: example 系统变白的星期二 {#ex-cyber}

::: example 风暴之后的那一周 {#ex-weekthree}

节场上两次持刀伤人：三名伤者、持同一工作证；急诊“目前”有容量；救护部门问是否宣布。宣布实际改变了什么、由谁决定？
::: solution
**宣布是一个工具不是一个判决（[[#def-system]]）：决定权——宣布权限（第一响应责任人、控制室、或内部事件的医院值班行政官——救护部门的问题正当而答案是有理由的是或否、这里通常是）；宣布买来什么——升级架构：“召集与取消”带员工通讯树、大量输血与手术室与ICU待命在需求自证之前“免费”启用、单一信息线与医院热线（“正送来的患者中也有能走的伤者——预期没人登记的到达”）、家属接待与班子清单（“同一工作证”模式意味着来自一个地点的多名伤员带警方现场记录会需要的共同暴露）、互助与创伤网络启动、及若损伤致命则太平间与身份识别计划（验尸官与警方与伤亡识别演练的决策树）、及把能走的伤者挡在你急诊之外的公共沟通纪律；它买不来什么——以上无一要求公众恐慌（宣布是内部语法；“来我们急诊或别来”的信息由信息席撰写）、而早解除几乎不花钱、这就是学说教授的诚实不对称：早宣布、廉价解除。**
:::

::: exercise 组织接收医院 {level=2}
地铁爆炸第一小时：热线来电到达；你的医院“最近”但不是指定的创伤或烧伤或儿科中心。管理到达：接收决定、分流、与信息。
::: solution
**接收医院第一小时（[[#def-system]]、[[#def-clinical]]、[[surgery/trauma]]）：接收学说——“最近不总是对的”输送现实（你接收你能确定性治疗的、与你能稳定后转诊的、及爆炸与持刀模式的“直接进CT或手术室”路径就是“为会破溃的不是为可生存的装了就走”决定；儿科与烧伤患者一旦稳定就去它们的中心、因为母亲最深的噩梦是一家说“我们稳定了他然后转走了他”的医院）；分流机器——由人类临床医师回答一个有形状问题的救护车热线（你能接收什么、你对什么已满、你的“走廊与复苏室只剩两个间”状态是什么）、及门口保持的到达登记使事件室在家属提问之前就知道谁在哪里、及“载运单变成登记册”的对账；信息层——向伙伴诚实发布的单一真相性病床状态板（防止自行就诊洪流的“我们满了”诚实）、及设在不远处社区场馆而不是你家大厅的家属接待中心带口译与哀伤邻近计划、及被简报“任何医院”式回答就是患者安全回答的新闻官；及内部重置——择期与急诊列表取消决定（外科容量是一次性花掉的储备）、及每家医院重大事件记录里的教训：自行到达的召集员工是一个高级在门口带着角色卡而不是指示牌迎接他们的时刻、及补货与行动后复审时钟在最后一辆救护车驶离时开始。**
:::

::: exercise 编写弱势人群计划 {level=2}
洪水计划覆盖建筑而不覆盖人：护理院、居家透析、需氧与机械支持患者、美沙酮与胰岛素冷链、及韧性复审不断发现的“没有撤离”人群。写出你分担的那部分计划。
::: solution
**为人不是为建筑的计划（[[#def-system]]、[[public-health/determinants-inequalities]]、[[geriatrics-palliative/ageing-frailty]]）：登记问题——“医学弱势”登记册需氧与透析及电动设备及妊娠及免疫抑制及临终居家患者名单由提供者与市政持有、带数据共享与合规基础在风暴之前而不是风暴之中定好、及每次洪水与热浪复审的真相：登记册不完整、所以计划假定不完美知识并主动排查（“那位会为帕特尔太太给我们打电话的邻居”渠道管用）；实际会发生的行动——“停电是一个医学事件”规程（电动设备患者优先通报给公用公司、带医疗应急登记式方案、及有电与充电及为胰岛素和美沙酮留冰箱空间的休整点、及按洪水预报而不是洪水到达定时的“现在走不是若走”信息）、透析与化疗及血液网络连续性计划（你的单元在水下所以你这一周在另一家医院的预先协议）、及护理院“一页纸洪水计划带具名钥匙持有人与药品储备”支持包（监管检查制度已学会索要它）、及“没有离开”人群（行动能力、坚忍、宠物、语言、创伤史、与“我不会离开这是我仅有的一切”理由——撤离调查编目了它们、用更早且重复且可信的信息与交通协助回答、而不是靠救援广告牌上的愤怒）；及公平框架——热浪与洪水死亡数据是公共卫生的证据：灾难按贫困与年龄分布；计划的成功指标不是“医院撑住了”而是“谁死了而不在任何人的登记册上”、这就是为何行动后阶段包括与验尸官发现并排的登记册审计。**

::: exercise 评判照护标准 {level=2}
大规模伤亡现场的一名初级医师在通常在场的顾问不在时截除了一条挤压的肢体；患者存活但失去了腿。投诉指称过失。解释法医与职业框架、不安慰也不谴责任何人。
::: solution
**被宣布事件下的学说医学（[[#def-aftermath]]、[[medical-ethics-law/professionalism-regulation]]）：框架——照护标准按当时情形下合理可能的评估（赔偿机构与指导陈述的“已宣布重大事件与改变学说”现实：你按分类检伤规则、升级尝试、记录与相称性被评判、不按平静一日的路径）；调查将审查什么——是否遵循学说（分类决定权限、预期死亡与延迟类别、按挤压医学逻辑在有任何可及高级的电话支持下做的为命舍肢决定、及紧急或最佳利益同意的记录）、什么本可升级（远程会诊与你没有请求的互助之问）、及记录了什么（事件日志与标签及“谁在何时决定了什么”笔记——这就是为何存在混乱中的记录最低量）；职业义务——对患者与家属带事件背景诚实陈述的坦承职责（“你是在已宣布的重大事件下被分类与治疗的；这是我们下次会不同的地方”谈话、既不是为过失道歉也不是辩护）、对临床医师的支持（“第二受害者”文献：在爆炸中截肢随后面临投诉的初级需要赔偿机构与评估制度及福利路径同时到位——在学说下把学说临床医师抛下海的部门下次永远找不到志愿者）、及学习不是责备的平衡（“决定在事件条件下是否处于合理范围”是复审之问、而“学说不算好医学”是规划之问、两个答案可以正当地不同）；给受训者的诚实结尾：投诉流程会慢、案卷就是你的声音、按标签记录的方式讲真话、而让你遵循过的学说恰当地为你辩护。**

## 通向何处

对个体患者的分类始于[[emergency-critical-care/acute-assessment]]、大量输血物流在[[blood/transfusion]]与[[surgery/trauma]]、化学事件洗消与毒理在[[emergency-critical-care/poisoning]]、传染病大流行在[[public-health/communicable-disease-control]]、灾害中医院安全在[[public-health/environmental-occupational]]、及精神卫生善后在[[psychiatry/lifespan-psychiatry]]。

::: history
**平民灾害医学是由火灾与坍塌写成的。1919-1920年代的空袭救护思考与伦敦闪电战的伤员转运站、英国国民服役的民防学说、及1966年阿伯凡和1966-68年一系列工业灾难给了英国首批严肃的应急规划法规。现代是分类与通讯的时代：1980年代大规模集会医学（海塞尔与布拉德福德复审、泰勒调查的医学规划后果）、1987年泽布吕赫渡轮灾难——其“死者在前舱而没人知道”的混乱教给伤亡身份识别与家属接待学说、及1988年泛美103洛克比响应的跨辖区教训。2001年浪潮——世贸中心袭击（院前输血的首次记录现场使用、及“指挥混乱：80辆无协调救护车到达”与“医院热线”及重塑美国应急通讯的“大白话无线电”事件后改革）、2004年马德里火车爆炸、及2005年伦敦爆炸（四弹近同时产生三部门通讯复审与互通性投资）、2008年孟买袭击、2011年挪威于特亚响应、及2015年巴黎袭击（“平民急诊中的战术火伤医学”改革与“头十分钟：奔走的伤者与直接进复苏室”学说）。2017年曼彻斯特竞技场爆炸（22分钟内宣布重大事件）与同周伦敦桥袭击巩固了“热-温-冷”区域学说、社区“反应者优先急救”运动、及疫情压力测试过的“英国重大事件是他国研究的模型”自评。技术转折随2017年想哭网络攻击到来、它教会国家卫生系统“网络重大事件”（多家机构与“照护不是安全”复审及网络韧性测试与认证邻近规划）、及2020年代大流行把“容量激增”“四个C”与“基于演练的备灾在人的因素处崩解”变成家常词汇。减灾框架随之成长：1990年代国际减灾十年、2005年兵库与2015年仙台框架、及世界卫生组织医院安全规划、其在地震之后又地震的核心发现——倒塌或断电的医院杀死的患者比地震本身更多——使结构与公用韧性成为一门临床学科。福利半边最新：响应者创伤后应激与道德损伤文献（9/11响应者队列十余年的健康登记及其医学监测权利、应急部门自杀与创伤后应激研究、“第3周崩溃”发现）、及灾害精神医学的修正：单次心理疏导不预防创伤后应激（1998-2010试验）、而静观等待与技能支持与社区恢复能——一个改变全球指导的少见循证反转。调查时代继续：每次事件产生一份复审（曼彻斯特竞技场调查2022-24卷论应急资源分配、及“7/7的教训已被学到并被部分遗忘”发现）、而该学科的诚实总结是：它的知识随每个安逸的一年衰减、而它的考试从不预告。—— [[surgery/trauma]]、[[public-health/health-systems-economics]]、[[psychiatry/lifespan-psychiatry]]。**
:::

::: summary
- 重大事件是任何需求超出常规容量的事件；宣布是一个带记录的临床安全行为、而学说按减缓-备灾-响应-恢复运转。
- 指挥结构（金-银-铜）、四个C、METHANE报告与共享分类语言之所以存在、因为大调查（2005伦敦、2017曼彻斯特）发现同样的失败：各部门无法通话、数字错误地移动资源、家属挤满接收医院。
- 大规模伤亡分类（START与JumpSTART）在稀缺下分拣；预期死亡类别是资源相对的、给舒适治疗、被记录、被再分类——其伦理被训练与复盘、不是临时发挥。
- 伤害模式（爆炸、挤压、火烟雾氰化物、化学、大规模伤亡出血）各有各的具名临床时钟、而洗消逻辑（“仍受污染的伤员是一个危害、还不是一个患者”）保护救援行动。
- 医院宣布自己的重大事件：网络攻击、系统宕机、内部灾难与大流行都按停机计划、优先级重置与互助网络运转。
- 恢复是计划的一部分：补货、行动后复审、响应者福利（“第3周崩溃”）、家属精神卫生、及医院自身的结构韧性——仙台的那句：安全的医院就是灾害的ICU。
:::

::: exercise 分类学校礼堂 {level=2}

你医院宣布的内部重大事件（化学泄漏伴12名已洗消伤员）在凌晨3点结束。员工欢欣鼓舞；行政想在早餐时宣布全面解除。在宣布正常之前必须发生什么？

**解除是一个流程（[[#def-aftermath]]、[[clinical-skills/patient-safety]]）：临床长尾——已洗消但仍有风险的患者（迟发制剂：光气与有机磷老化邻近观察窗口、及带具名负责人的“现在无症状不等于第6小时安全”观察病区）、伤员计数对账（谁在这里、记录在哪里、“谁不顾建议离开了”清单）、及“我们的员工中有人暴露吗”事件（洗消团队的恶心与头痛要现在报不是下周报）；物资真相——签署的设备与库存盘点（用掉的洗消淋浴耗材与解毒剂库存、及“从未被记录的阿托品抽吸”审计）、及停机表格对账（走廊里的纸质用药卡与打印的输血表格与事件日志对病历——它在第3天变成临床风险的“记录债”）；人——食物饮水休息与一个坐的地方的即时福利、及附上职业健康与同伴支持联系方式的“72小时没事而第3周是崩溃”福利电话、及“经理的工作是注意到安静的人”指令、及家人在事件现场学校的员工（“谁照看我的孩子”休假问题被公开命名）；及治理——48小时内的热复盘（什么崩了、什么撑住了）、及进资本计划的补货与维修清单、及宣布与结束宣布带理由记录（事件的开始与停止是决定、要有会议记录）、及设定行动后报告到期日并命名计划复审负责人——因为事件结束了而下一次会读你今晚写下的任何东西。**
