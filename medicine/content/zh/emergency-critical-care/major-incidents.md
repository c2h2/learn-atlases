医学的大部分工作都假定资源与需求相匹配：每位患者都能得到可提供的最佳照护。重大事件打破了这一假定。拥挤场所发生爆炸、列车相撞、建筑倒塌、化学品泄漏、洪水，或使医院计算机瘫痪的网络攻击，都可能产生超出常规系统承受能力的患者数量或运行中断。应对的成败更多取决于准备、组织和沟通，而不是任何单一的临床技能。

本章介绍英国如何界定和宣布重大事件、指挥与控制结构、各应急服务联合工作的原则、大批伤员的检伤分类、大规模伤亡事件特有的损伤类型（爆炸伤、挤压伤、穿透伤，以及化学、生物、放射和核事件）、照护配给的伦理、接收医院的职责，以及事后的恢复和总结学习。文中描述的是英国的安排（《2004年民事应急法》、英格兰国家医疗服务体系的应急准备、韧性与响应框架，以及应急服务联合互操作原则）；其他国家以不同名称采用类似的结构。

## 体系 {#def-system}

::: definition 重大事件 {#def-mi}
对国家医疗服务体系（NHS）而言，**重大事件**是指对社区健康构成严重威胁，或造成的伤员数量或类型需要启动特别安排的任何事件。关键词是*特别*：当常规工作方式无法应对时，事件就是重大事件。

重大事件包括**突发型**事件（爆炸或撞击）、在数天或数周内逐渐累积的**渐进型**事件（大流行、热浪、冬季压力）、**可预见型**威胁（预期的风暴或劳资行动）、引起公众关注的**新闻焦点型**事件、**化学、生物、放射、核和爆炸物（CBRNe）**事件、**大型集会**，以及**内部事件**，如医院内的火灾、水浸、停电或信息系统故障。**大规模伤亡事件**是指伤员数量多到无法为所有人提供通常标准照护的事件。
:::

在英格兰，NHS机构根据**《2004年民事应急法》**承担法定职责。该法界定了**第一类响应者**（应急服务、NHS信托、地方政府等处于响应核心的机构）和**第二类响应者**（配合并共享信息的机构，如公用事业和交通公司）。第一类响应者必须评估风险、维持应急计划和业务连续性计划、共享信息并向公众发出警告。NHS England的**应急准备、韧性与响应（EPRR）**框架规定了NHS机构如何履行这些职责，包括培训和定期演练。

### 宣布

任何一个应急服务机构或医疗机构都可以宣布重大事件。在NHS实践中，医院可能收到以下通知：

- **“重大事件——待命”**：事件可能需要重大事件响应；做好准备。
- **“已宣布重大事件——启动计划”**：执行计划。
- **“重大事件——解除”**：恢复正常工作，这本身也需要计划。

第一个到达现场的应急服务人员向其控制中心发送初步报告。英国的标准格式是**METHANE**：

| 字母 | 含义 |
|---|---|
| **M** | 已宣布重大事件或处于待命状态 |
| **E** | 确切位置 |
| **T** | 事件类型 |
| **H** | 现有和潜在的危险 |
| **A** | 进出路线 |
| **N** | 伤员的数量、严重程度和类型 |
| **E** | 已在场和需要的应急服务 |

METHANE报告随着情况变化而重复和更新。它让每个控制中心在同一时间掌握同样的情况。

### 指挥与控制

::: definition 指挥层级与联合原则 {#def-command}
英国应急服务采用三个指挥层级：

- **战略级（金）**：确定响应的总体目标和政策，分配资源，处理更广泛的后果；通常在远离现场的战略协调小组中。
- **战术级（银）**：计划和协调响应以实现战略目标；常在现场附近。
- **执行级（铜）**：在现场开展具体工作，常按划定的区域或职能分工。

**应急服务联合互操作原则（JESIP）**描述了不同服务的指挥官如何协同工作。五项原则是**同地办公**、**沟通**、**协调**、**共同理解风险**和实现**共享态势感知**。JESIP还提供了一个**联合决策模型**（收集信息和情报；评估风险并制订工作策略；考虑权限、政策和程序；确定方案和应急预案；采取行动并复盘发生了什么），所有环节都围绕拯救生命和减少伤害这一共同目标。
:::

医院有自己的指挥结构，对应同样的层级：战略负责人（常为一名执行董事）、战术级**医院控制小组**（一名高年资临床医生、一名高年资护士和一名管理人员），以及急诊科、手术室和重症监护等各区域的执行负责人。每位工作人员都有一张**行动卡**，写明最初几分钟该做什么。

## 临床工作 {#def-clinical}

### 检伤分类

在常规实践中，病情最重的患者最先得到治疗。在大规模伤亡事件中，目标改变了。

::: theorem 大规模伤亡检伤分类的原则 {#thm-triage}
当伤员数量超过可用于救治的资源时，照护的优先顺序以**为最多的人带来最大的益处**为原则：伤员按需求的紧迫程度以及治疗改变其结局的可能性排序，而不是仅按严重程度排序；用于任何单个伤员的资源受到限制，以便挽救更多的人。
:::

::: proof
可以把每个伤员看作有接受治疗时的存活概率、不接受治疗时的存活概率，以及一项资源成本（人员时间、手术室时间、血液、呼吸机）。在常规实践中，资源实际上不受限制，因此治疗每个人、从最重者开始是合理的。在大规模伤亡事件中，最初数小时内资源是固定的。把资源用在无论如何处理存活机会都变化不大的伤员身上（要么因为伤势轻微，要么因为以现有资源几乎肯定无法存活），留给存活机会关键取决于及时治疗的伤员的资源就更少。对伤员进行排序，使单位资源获益最大者最先得到治疗，可以使预期存活人数最大化。这就是为什么检伤分类的类别关乎优先级，为什么类别要随资源变化而重新评估，以及为什么“期待治疗”类别只在资源被压垮时才存在。
:::

检伤分类反复进行：在现场（**初次检伤分类**，快速而简单）、在伤员集结点和到达医院时（**二次检伤分类**，更详细），并在患者病情和资源变化时再次进行。英国使用的类别是：

| 优先级 | 颜色 | 含义 |
|---|---|---|
| **P1** | 红 | 立即：现在就需要挽救生命的干预 |
| **P2** | 黄 | 紧急：需要在数小时内干预 |
| **P3** | 绿 | 延迟：能行走的轻伤员，可以等待 |
| **期待治疗** | 蓝（如使用） | 伤势严重到以现有资源不太可能存活；给予舒适照护，资源允许时重新评估 |
| **死亡** | 白或黑 | 已死亡 |

::: definition 初次检伤分类：十秒检伤分类 {#def-tst}
2023年，NHS England宣布，救护车服务自2013年起使用的检伤分类筛选法将被两种工具取代，并于2023至2024年推行：**十秒检伤分类（TST）**，其设计使包括警察和消防人员在内的任何响应者都能使用；以及供NHS临床响应人员使用的**重大事件检伤分类工具（MITT）**。TST依次询问：

1. **能行走吗？**如能，**P3**。
2. **有严重出血吗？**如有，控制出血（压迫、填塞、止血带），归为**P1**。
3. **能说话吗？**如能，检查胸部、腹部、背部或颈部有无**穿透伤**：如有，**P1**；否则**P2**。
4. **有呼吸吗？**（开放气道后）如有，置于复苏体位：**P1**。如无，该伤员归为**无呼吸**。

它不使用任何生理测量，因此很快，也能教给非临床人员。在国际上，类似的工具包括20世纪80年代在加利福尼亚开发的**START**（简单分类和快速治疗），以及2008年在美国开发的**SALT**（分拣、评估、挽救生命的干预、治疗/转运）。
:::

检伤分类并不完美。**过度分类**（给予高于需要的优先级）把稀缺资源浪费在可以等待的人身上；对恐怖爆炸事件的分析发现，高过度分类率与危重伤员较高的死亡率相关，因为医院被伤势较轻者挤满。**分类不足**（给予过低的优先级）延误了急需治疗者的救治。每一种检伤分类系统都在两者之间权衡。

### 损伤类型

**爆炸伤**按机制分类：

- **一级**：压力波损伤含气器官：鼓膜、肺（**爆震肺**，出血和挫伤可能数小时后才出现）和肠道。
- **二级**：碎片和瓦砾造成穿透伤，常为多处，并有污染。
- **三级**：伤员被抛向物体，造成钝性伤、骨折和创伤性截肢。
- **四级**：其他一切，包括烧伤、挤压伤、吸入烟尘以及原有疾病加重。

爆炸伤员常有多发伤，最显眼的损伤不一定最危险。爆炸袭击还可能有针对响应人员的二次爆炸装置，因此现场安全至关重要。

**挤压伤**发生于人被重物压住时，例如在倒塌的建筑中。压力解除后，受损肌肉中的钾、肌红蛋白和酸进入循环（**挤压综合征**），引起高钾血症、心律失常、低血容量和急性肾损伤。解压前液体复苏、心电监护和尽早具备肾脏替代治疗能力是关键。

**穿透伤**由枪支或刀具造成，在流窜式恐怖袭击中占主导。损伤控制的原则（止血、止血带、迅速送往手术）与[[surgery/trauma]]中的创伤救治相同。

**CBRN事件**。在化学事件中，伤员可能未经预警就到达医院并污染科室。英国面向公众和第一响应者的**“撤离、脱除、清除”**方法是：**撤离**到远离现场的地方，**脱除**外衣（可去除大部分污染），以及通过吸干和冲洗从皮肤上**清除**有害物质。医院有在患者进入科室之前进行洗消的计划和防护装备。特异性解毒剂，如用于神经毒剂的阿托品和肟类药物，见[[emergency-critical-care/poisoning]]。生物事件更像渐进型事件，通过异常疾病的聚集被识别。

### 接收医院

宣布重大事件后，医院通常：

1. 开设**控制室**，按行动卡分配角色。
2. **腾空急诊科**：转移或让现有患者出院以腾出空间。
3. 在全院**创造容量**：取消择期手术，加快病情允许的患者出院，开放更多重症监护床位，并按计划召集人员。
4. 在入口设立由高年资临床医生领导的**检伤分类点**，并设立P1、P2和P3患者区域。
5. 采用**损伤控制**原则：先做有限的、挽救生命的手术，确定性手术留待以后。
6. 建立**患者识别**（重大事件编号）、追踪、与警方的**伤亡登记处**联络以及向亲属提供信息的系统。
7. 为已在院的患者保持**业务连续性**。

所需的投入不只在最初几个小时：伤情复杂的患者可能需要数周的反复手术、重症监护和康复，医院必须为这种持续的负荷做计划。

::: warning 把最先到达的伤员当作最重的伤员
在重大事件中，最先到达医院的往往是伤势最轻的人：自行前来或由旁观者送来的能行走的轻伤员。如果他们占用了复苏间和手术室，后来经解救后由救护车送达的危重伤员可能就没有容量了。医院的检伤分类必须牢记事件的规模，为需要的人保留复苏能力，并把P3患者引导到单独的区域。
:::

### 大规模伤亡救治的伦理

在大规模伤亡事件中，照护标准从对每个个体最好的，转向对伤员整体最好的，常被称为**危机照护标准**。这在伦理上令人不安，但在以下情况下是站得住脚的：基于透明、预先商定的标准，一致地执行，不因与临床需要无关的理由（如社会地位、残疾本身或支付能力）而歧视，定期复审，并在资源允许时立即停止。期待治疗类别是最清楚的例子：它不意味着放弃，而是给予舒适照护并重新评估。必须作出这些决定的临床医生需要机构的支持，并应尽可能由高年资人员作出决定。这些原则在[[medical-ethics-law/justice-resources]]中有进一步讨论。

儿童、老年人、残疾人、孕妇和不会说英语的人在灾难中更脆弱，计划应明确把他们包括在内：儿科设备和剂量、无障碍的信息和沟通、翻译，以及无人陪伴儿童的保护。

## 事后 {#def-aftermath}

### 恢复与解除

解除是一个有管理的过程，而不是一个时刻。医院恢复正常服务，补上取消的工作，补充物资，并支持工作人员。事后立即进行的**即时复盘**捕捉新鲜的经验教训并关注工作人员的身心状况；数周内进行的**结构化复盘**和**正式报告**明确哪些有效、哪些无效，并促成计划的修改。

### 心理照护

许多幸存者、遇难者亲属和响应人员在重大事件后会感到痛苦；大多数人在实际支持和时间中恢复。证据不支持对每个人进行常规的单次心理晤谈，这甚至可能有害；目前的做法是**心理急救**（实际帮助、信息以及安全感和联结感）、**主动监测**以识别出现持续症状的人，以及对创伤后应激障碍进行循证治疗，如聚焦创伤的认知行为治疗。工作人员的福祉包括休息、饮食、认可，以及获得职业健康服务和同伴支持。

### 总结学习

重大事件及其调查塑造了现行实践。在英国，对**2005年7月7日伦敦爆炸案**的响应促使各服务之间的通信受到审查；**2017年5月22日曼彻斯特体育场爆炸案**引发了公开调查，其关于应急响应的报告（2022年）发现了应急服务之间联合工作和沟通的严重失误，包括消防救援人员约两小时后才到达现场，并得出结论认为，若响应得当，其中一名遇难者很可能会存活。这类报告正是重视JESIP培训、联合演练和互通通信的原因。定期**演练**（桌面推演、指挥所演练和实战演练）在需要之前检验计划。

## 实例分析

::: example 人行天桥的检伤分类 {#ex-triage}
一座跨越双向分隔车道公路的人行天桥在节日活动中倒塌。第一位到达的救护车临床人员发现40名伤员。使用十秒检伤分类：24人能行走；在16名不能行走者中，3人有肢体损伤导致的严重出血；在其余13人中，8人能说话，其中2人有瓦砾造成的躯干穿透伤；在5名不能说话者中，4人在开放气道后有呼吸，1人无呼吸。分配类别并计数。
::: solution
- 能行走：**24名P3**。
- 严重出血：以压迫或止血带控制出血，**3名P1**。
- 能说话且有躯干穿透伤：**2名P1**；能说话无穿透伤：**6名P2**。
- 不能说话但有呼吸：复苏体位，**4名P1**。
- 开放气道后无呼吸：**1名无呼吸**。

合计：P1 $= 3 + 2 + 4 = 9$；P2 $= 6$；P3 $= 24$；无呼吸 $= 1$；总数 $9 + 6 + 24 + 1 = 40$。METHANE报告应给出这些数字。24名P3伤员应被引导至单独的区域，以免挤满最近的急诊科，所有伤员都将在二次检伤分类时重新评估。
:::
:::

::: example 系统一片空白的那个星期二 {#ex-cyber}
一个工作日的09:15，勒索软件攻击使一家医院的电子病历、检验和放射系统瘫痪，病理结果不再传来。没有伤员。这是重大事件吗？应该怎么做？
::: solution
是。重大事件由是否需要特别安排来界定，而不是由伤员来界定。这是一起威胁全院患者安全的**内部事件**：结果无法报告，处方和观察记录无法电子录入，影像无法查看。

医院按计划宣布内部危急事件或重大事件，并建立指挥与控制。响应包括切换到（事先准备好的）**纸质停机流程**，电话通报危急结果，优先处理紧急的检验和影像工作，考虑分流救护车和转送时间紧迫的患者，通知地区NHS团队和国家网络安全机构，并与工作人员和患者清楚沟通。恢复可能需要数周，包括把纸质记录补录进电子系统。针对正是这种情景的业务连续性计划是EPRR的一部分。
:::
:::

::: example 发现了发电机问题的演练 {#ex-exercise}
在一次模拟停电合并重大事件的实战演练中，医院发现其备用发电机能为手术室供电，却不能为新建扩建楼中重症监护的呼吸机插座供电，而且重大事件行动卡上仍列着两年前就已离职的人员。医院应如何利用这些发现？
::: solution
这正是演练的目的：在安全的情况下发现失误。这些发现记录在正式的**演练报告**中，附有行动计划、责任人和期限：紧急进行电气改造，把关键设备接入保障电源（并采取临时缓解措施，如转移机械通气患者或提供不间断电源）；更新行动卡和召集名单，并建立定期复核的流程；改造后重新测试。向董事会和地方韧性论坛报告这些发现以确保问责。什么也没发现的演练通常是检验得还不够严格。
:::
:::

::: example 风暴之后的几周 {#ex-weekthree}
一场强风暴使一个镇子部分被淹。急性期持续两天，只有少数人受伤，但在随后几周，当地急诊科接诊了更多跌倒、感染和慢性病失代偿的老年人，社区护理服务无法到达受损房屋中的患者，两名透析患者错过了透析。这说明了什么？
::: solution
许多灾难在其健康影响上是**渐进型**事件。住房、电力、交通、药品、照护服务和社会网络的中断，会伤害慢性病患者和依赖常规照护的人，如需要透析、氧气、胰岛素和居家照护者。计划应事先识别**脆弱人群**（通过地方政府、社区服务和公用事业持有的登记册），保持透析等关键服务的连续性（备用透析单位和交通），并包括心理健康支持。恢复期造成的疾病和死亡可能比急性期更多，因此急性响应的解除并不意味着健康响应的结束。
:::
:::

::: quiz
在一次爆炸现场，一名使用十秒检伤分类的响应者发现一名男子不能行走，无严重出血，能说话，胸部背侧有一处小的穿透伤。他属于哪一类？
- [ ] P3，因为他能说话。
- [ ] P2，因为他能说话且没有严重出血。
- [x] P1，因为能说话但有躯干穿透伤的伤员被列为立即处理。
- [ ] 无呼吸。
::: solution
在TST中，不能行走、无严重出血但能说话的伤员要检查胸部、腹部、背部或颈部有无穿透伤。如有，则为P1，因为即使伤员起初看起来情况良好，此类损伤也可能因内出血或张力性气胸而迅速恶化。
:::
:::

::: history
按伤情紧迫程度而非军衔对伤员进行分拣的做法，归功于拿破仑军队的首席外科医生**拉雷（Dominique-Jean Larrey）**。他在18世纪90年代引入了“飞行救护车”，把伤员迅速从战场上运出，并按需要的先后顺序进行治疗。第一次世界大战期间，法语词*triage*（分拣）成为标准的军事医学实践，20世纪的战争完善了后送链和损伤控制手术。民用检伤分类工具随之出现：**START**于20世纪80年代初在加利福尼亚州纽波特比奇开发；英国的重大事件培训课程（如20世纪90年代首次开办的MIMMS，即重大事件医疗管理与支持课程）向一代临床医生讲授了检伤分类筛选法和指挥结构。**《2004年民事应急法》**为英国的应急规划提供了现行法律框架；在对2005年伦敦爆炸案等事件的调查揭示了联合工作的失误之后，**JESIP**于2012年启动。
:::

::: summary
- 重大事件是任何需要特别安排的事件；它可以是突发型、渐进型、CBRN或内部事件，可有或没有伤员。
- 英国的职责来自《2004年民事应急法》和NHS的EPRR框架；计划通过定期演练加以检验。
- 宣布：待命、已宣布、解除。现场的首次报告使用METHANE。
- 指挥分为战略级（金）、战术级（银）和执行级（铜）；JESIP要求各服务同地办公、沟通、协调、共同理解风险并共享态势感知。
- 大规模伤亡检伤分类旨在为最多的人带来最大的益处。十秒检伤分类：能行走（P3）、严重出血（P1）、能说话（P2，若有躯干穿透伤则为P1）、有呼吸（P1）或无呼吸。
- 过度分类压垮医院；分类不足延误危重伤员的救治。
- 爆炸伤分为一级、二级、三级和四级；挤压综合征引起高钾血症和肾损伤；化学事件需要“撤离、脱除、清除”和洗消。
- 医院腾空急诊科、创造容量、在入口进行检伤分类并采用损伤控制手术；恢复、工作人员福祉、心理急救和总结学习在解除之后仍将长期持续。
:::

## 习题

::: exercise 写一份METHANE报告 {level=1}
一辆载有30名学童和3名成人的大巴在雨中于高速公路匝道上侧翻，燃油正在泄漏。你是第一位到达现场的护理人员，粗略数出约8名不能行走的伤员。消防和警察尚未到场。写一份METHANE报告。
::: solution
**M**：已宣布重大事件。**E**：确切位置（高速公路名称、交叉口编号、匝道及方向，如有可提供what3words或网格坐标）。**T**：大巴侧翻，多名伤员，许多是儿童。**H**：燃油泄漏（火灾风险）、车流未中断、路面湿滑、车辆可能进一步失稳。**A**：从主车道经匝道进入；建议封路并设集合点。**N**：约33名伤员，约8名不能行走；检伤分类后报告数量和严重程度；大量儿科患者。**E**：一辆救护车在场；需要消防救援（解救和燃油危险）、警察（交通和现场管理）、更多救护车、一名高年资临床医生和一支危险区域响应队；通知能接收儿科患者的医院。
:::

::: exercise 统计类别 {level=1 check="9"}
在[[#ex-triage]]的人行天桥倒塌中，有多少伤员被归为P1？
::: solution
$3$（严重出血）$+ 2$（能说话且有躯干穿透伤）$+ 4$（不能说话但有呼吸）$= 9$。
:::
:::

::: exercise 激增容量 {level=2 check="105"}
一家医院有900张成人床位，宣布重大事件时占用率为95%。计划预计可以迅速让60名患者出院。将有多少张床位可用？
::: solution
占用床位：$0.95 \times 900 = 855$，因此$900 - 855 = 45$张空闲。加上60名快速出院，得$45 + 60 = 105$张床位。床位只是容量的一部分：人员、手术室时间、重症监护床位和血液制品可能才是真正的限制。
:::
:::

::: exercise 过度分类率 {level=2 check="67"}
事后复盘显示，在现场被归为P1的9名伤员中，只有3人的损伤需要立即进行挽救生命的干预。P1伤员中被过度分类的比例是百分之几？答案取最接近的整数百分比。
::: solution
过度分类人数：$9 - 3 = 6$。比例$= 6/9 = 0.667$，即**67%**。简单的初次检伤分类工具常有较高的过度分类，为了保持低分类不足而被接受；伤员集结点和医院的二次检伤分类会加以纠正。
:::
:::

::: exercise 学校礼堂的检伤分类 {level=2}
一所学校屋顶倒塌后，对以下人员使用十秒检伤分类：(a) 一名前臂撕裂伤、能行走的教师；(b) 一名静静躺着、不能说话、开放气道后有呼吸的10岁儿童；(c) 一名大腿喷射性出血、正在尖叫的14岁少年；(d) 一名因腿伤不能站立、能说话、无穿透伤的12岁儿童。
::: solution
(a) 能行走：P3。
(b) 不能行走，无严重出血，不能说话，有呼吸：复苏体位，P1。
(c) 不能行走，严重出血：上止血带或直接压迫，P1。
(d) 不能行走，无严重出血，能说话，无穿透伤：P2。
在TST中，太小而不会说话的儿童按“不能说话”处理，这可能提高他们的优先级。
:::
:::

::: exercise 组织接收医院 {level=2}
一个购物中心发生持刀袭击，估计有15名伤员，你的医院接到“已宣布重大事件——启动计划”的通知，你是当班的高年资急诊医生。列出你最初十分钟的行动。
::: solution
拿起你的行动卡；与救护车控制中心确认宣布情况、预计人数和到达时间；建立急诊科指挥并通知医院控制小组。腾空科室：把已收入院的患者转到病房，让轻症患者出院或转往他处。在救护车入口设立由高年资临床医生领导的检伤分类点，设P1、P2和P3区域以及能行走轻伤员的单独区域。分配团队（每个复苏间一名高年资医生、一名护士和辅助人员），通知手术室、重症监护、放射科、血库（大出血血液包）和创伤团队。按召集计划请求增援人员。确保用重大事件编号标识患者并设追踪板，设立亲属等候区。向工作人员简要说明穿透伤的处理重点（止血、止血带、损伤控制手术）和安保问题：袭击可能尚未结束，医院本身也可能成为目标。
:::
:::

::: exercise 判断照护标准 {level=3}
在一次大流行高峰期间，一家医院只剩两张重症监护床位，而有五名患者可以从机械通气中获益。一名临床医生提议把床位分配给最年轻的两名患者。讨论这在伦理上是否可以接受，以及更好的流程是什么样的。
::: solution
仅凭年龄是一个粗糙且可能带有歧视的标准。它可能与获益的可能性相关，但两者并不相同；分配决定应基于临床需要以及从稀缺资源中获益的可能性和程度。更好的流程采用预先商定并公布的标准（如根据器官功能障碍评分估计的短期存活概率，并审慎地考虑衰弱程度），由高年资临床医生或不直接治疗这些患者的分诊小组一致地执行，定期重新评估（包括在标准如此规定时，从没有好转的患者身上撤回资源），做好记录，提供申诉途径，并为未获分配的患者提供良好的姑息照护。这些决定应对公众透明，并在资源允许时尽快放宽标准。程序的公平与标准本身同样重要。
:::
:::

::: exercise 制订脆弱人群计划 {level=3}
一个地方韧性论坛请NHS参与制订冬季长时间停电的计划。指出三类健康风险特别高的人群，并为每类提出一项措施。
::: solution
1. **依赖电动医疗设备的人**（家用制氧机、家用呼吸机、居家透析、电动床）：维护与电力公司共享的登记册（如优先服务登记册），提供备用氧气瓶，并制订转往医院或社区设施的计划。
2. **独居的老年人和衰弱者**：由社区服务和志愿者主动上门探视，提供取暖场所，并检查药品储备。
3. **需要冷链药品的人**（胰岛素、某些生物制剂）：提供储存建议，并由社区药房制订替换计划。
其他答案包括接受居家照护的人、痴呆或精神疾病患者，以及有幼儿的家庭。每项措施都需要一个负责机构、一种联系到这些人的途径，并在演练中加以检验。
:::
