中毒是成人急诊入院最常见的原因之一。大多数病例是在痛苦中故意过量服用药物，但中毒也发生于家中或工作中的意外、娱乐性药物使用、用药差错，以及接触一氧化碳等气体。绝大多数患者在良好的支持治疗下都能存活。少数人摄入的物质有特异、时间紧迫的治疗，识别出这些患者是主要的临床技能。

本章介绍中毒患者的一般处理方法、毒物综合征的识别、去污染与加速清除、常见严重中毒的解毒剂和处理，以及对过量服药者本人的照护。所依据的是英国实践：国家毒物信息服务（NPIS）及其在线数据库**TOXBASE**提供最新的、针对具体毒物的建议，临床医生对每一例严重中毒都应查询。与本网站其他内容一致，本章讲授识别和处理原则，不提供任何物质的有害剂量。

## 中毒患者的处理方法 {#def-approach}

::: definition 中毒处理原则 {#def-principles}
中毒患者的处理遵循固定顺序：

1. 用ABCDE进行**复苏和支持治疗**：保护气道、氧合、循环、血糖、体温和控制癫痫发作。大多数患者不需要更多处理。
2. **风险评估**：摄入了什么、多少、何时、经何途径、同时还有什么（酒精和其他药物的合并摄入很常见），以及患者自身的危险因素。这可以预测可能的病程以及是否需要特异性治疗。
3. **检查**：心电图、血糖、尿素和电解质、肝功能、静脉血气，以及**对每一例故意过量者测定对乙酰氨基酚和水杨酸盐浓度**，因为这两种中毒早期可能毫无症状，却需要时间紧迫的治疗。
4. 有指征时进行**去污染**以减少吸收。
5. 对少数毒物进行**加速清除**。
6. 有解毒剂且有指征时使用**解毒剂**。
7. **心理社会评估**和对本人的照护，包括评估决策能力和再次自伤的风险。
:::

病史中有几项内容并不可靠：摄入的时间和数量常不确定，患者可能不说自己吃了什么。仔细的体格检查、心电图和实验室检查往往提供更多信息。药盒、给家人打电话或急救人员在现场的观察都很有用。

### 心电图与血气

心电图能发现许多药物最危险的作用。**QRS增宽**（超过约100 ms）提示钠通道阻滞，例如三环类抗抑郁药所致；**QT间期**延长易诱发尖端扭转型室速（许多抗精神病药、抗抑郁药、美沙酮）；**心动过缓和传导阻滞**提示β受体阻滞剂、钙通道阻滞剂或地高辛。

静脉血气和电解质可以发现代谢性酸中毒。**阴离子间隙**用于估计未测定的阴离子：

$$
\text{阴离子间隙} = [\text{Na}^+] - ([\text{Cl}^-] + [\text{HCO}_3^-])
$$ {#eq-ag}

正常范围约为8–16 mmol/L，视实验室而定。中毒患者出现**阴离子间隙增高型代谢性酸中毒**，提示乳酸酸中毒（休克、癫痫发作、二甲双胍、氰化物、一氧化碳所致）、酮症酸中毒、**甲醇**或**乙二醇**的酸性代谢产物，或**水杨酸盐**中毒。**渗透压间隙**即实测与计算血浆渗透压之差（计算值为$2[\text{Na}^+] + [\text{尿素}] + [\text{葡萄糖}]$，单位mmol/L），在有毒醇类中毒早期、尚未代谢的醇仍存在时升高，随着酸性代谢产物蓄积而下降。

### 毒物综合征

**毒物综合征**是一类毒物产生的一组体征。在病史不清时，识别出某一综合征可以缩小可能范围。

::: definition 主要的毒物综合征 {#def-toxidromes}
| 毒物综合征 | 典型药物 | 主要特征 |
|---|---|---|
| **阿片类** | 海洛因、吗啡、羟考酮、美沙酮 | 意识下降，呼吸慢而浅，瞳孔针尖样 |
| **镇静催眠类** | 苯二氮䓬类、Z类药物、酒精、GHB | 意识下降，言语含糊，共济失调；除非合并使用，呼吸抑制通常比阿片类轻 |
| **抗胆碱能** | 三环类、抗组胺药、部分抗精神病药、颠茄等植物 | 激越性谵妄，瞳孔散大，皮肤干燥潮红，高热，心动过速，尿潴留，肠鸣音消失 |
| **拟交感** | 可卡因、苯丙胺类、MDMA | 激越，瞳孔散大，心动过速，高血压，高热，**出汗**（据此与抗胆碱能综合征相区别） |
| **胆碱能** | 有机磷和氨基甲酸酯类杀虫剂、神经毒剂 | 流涎、流泪、排尿、腹泻、呕吐，支气管黏液溢和支气管痉挛，心动过缓，瞳孔缩小，肌束震颤和无力 |
| **5-羟色胺毒性** | SSRI、单胺氧化酶抑制剂、曲马多、MDMA，尤其联合使用时 | 激越，震颤，**阵挛**（诱发性或自发性，以下肢最明显），反射亢进，高热，出汗，腹泻 |
:::

## 去污染与加速清除 {#def-elimination}

### 去污染

大多数药物吸收很快，因此去污染只有尽早实施才有用，而且本身也有风险。

- **活性炭**在肠道内吸附许多药物。当患者在约**一小时**内摄入了可能中毒量的、能被活性炭吸附的药物，且气道受到保护时（误吸活性炭会引起严重的肺炎），可以考虑使用。它不吸附醇类、铁、锂、酸、碱或其他金属。
- 用聚乙二醇进行**全肠灌洗**仅用于特定情况，如大量缓释制剂、铁或体内藏毒包，须在专科建议下进行。
- **洗胃**和催吐已不再常规使用。
- 对有机磷和腐蚀剂等化学品，**皮肤和眼睛去污染**至关重要：脱去衣物，用水冲洗，并保护工作人员。

### 加速清除

::: theorem 一级消除与半衰期 {#thm-halflife}
对大多数药物而言，在大多数浓度下，消除速率与浓度成正比（一级动力学），因此浓度呈指数下降：

$$
C(t) = C_0 \, e^{-kt}, \qquad t_{1/2} = \frac{\ln 2}{k} = \frac{0.693 \times V_d}{CL}
$$ {#eq-firstorder}

其中$V_d$为分布容积，$CL$为总清除率。血液透析等体外清除方法会在机体自身清除率之上加上它的清除率，从而缩短半衰期，但前提是药物位于血液中、机器能够触及。
:::

::: proof
单位时间清除的药量等于清除率乘以浓度，$CL \times C$。体内药量为$V_d \times C$，因此清除分数速率为$k = CL / V_d$，对$dC/dt = -kC$积分即得指数下降。减半所需时间为$\ln 2 / k$。由此可得出两个与中毒有关的推论。第一，分布容积很大的药物（如三环类抗抑郁药，大部分存在于组织中）在血液中所占很少，因此即使高效的透析器也只能清除体内药量的极小部分。第二，当药物分布容积小、蛋白结合率低、自身清除比透析器所能增加的清除慢时，清除才值得进行，如水杨酸盐、锂、甲醇和乙二醇。在高浓度时，有些药物（水杨酸盐、乙醇、苯妥英）会使其消除酶饱和而转为零级动力学，每小时下降固定的量而不是固定的比例，从而使毒性延长。
:::

主要方法有：

- **多剂活性炭**，用于少数有肠肝循环或会扩散回肠道的药物，包括卡马西平、氨苯砜、苯巴比妥、奎宁和茶碱。
- **碱化尿液**，用静脉碳酸氢钠治疗水杨酸盐中毒：碱性尿液中更多的水杨酸盐被离子化并滞留在肾小管液中，排泄增加。
- **血液透析**，用于严重的水杨酸盐、锂、甲醇、乙二醇中毒，二甲双胍相关乳酸酸中毒，丙戊酸和茶碱中毒等。国际EXTRIP工作组就哪些毒物、哪些情况适用发布了循证推荐。

## 时间紧迫的中毒 {#def-specific}

### 对乙酰氨基酚

对乙酰氨基酚（paracetamol）是英国最常被过量服用的药物。其危险在于早期症状缺如或轻微（恶心、呕吐），而肝损伤在两到四天内逐渐发展。它有一种有效的解毒剂，在摄入后8小时内开始使用效果最好。

**机制。**大部分对乙酰氨基酚与硫酸和葡萄糖醛酸结合成无害的代谢物。一小部分经细胞色素P450（主要是CYP2E1）氧化为活性代谢物**NAPQI**，正常情况下由谷胱甘肽解毒。过量时谷胱甘肽被耗尽，NAPQI与肝细胞内的蛋白结合，引起小叶中央坏死。也可发生肾损伤。**乙酰半胱氨酸**补充谷胱甘肽，若尽早开始几乎可以完全保护。

::: definition 英国对乙酰氨基酚治疗线 {#def-paracetamol}
自2012年起，根据人用药品委员会的审查，英国对所有患者在对乙酰氨基酚列线图上使用**单一治疗线**。该线从摄入后**4小时100 mg/L**起，以约4小时的半衰期下降（15小时时约为15 mg/L）。

- 单次急性摄入后**4小时或更晚**采集的对乙酰氨基酚浓度标在列线图上。如果位于**治疗线上或线以上**，给予乙酰半胱氨酸。
- 4小时之前采集的浓度无法解读，因为吸收尚未完全。
- 如果摄入时间不明、过量为**分次**摄入（历时超过一小时），或患者就诊较晚且肝功能检查异常，则不能使用列线图，按TOXBASE标准决定治疗，通常倾向于治疗。
- 如果患者在可能有意义的摄入后超过8小时就诊，应**立即**开始乙酰半胱氨酸，不必等待浓度结果，因为其获益随时间下降。
:::

传统的静脉乙酰半胱氨酸方案是21小时内分三次输注。目前许多英国医院采用**SNAP**方案，这是一种在苏格兰开发、两袋输注、历时12小时的方案，其随机试验发表于2014年，类过敏反应和呕吐更少；TOXBASE自2020年起推荐该方案，尽管它属于超说明书使用。治疗结束时检查INR、ALT、肌酐和对乙酰氨基酚浓度，如有异常则继续治疗。

发生急性肝衰竭的患者应尽早与肝病中心讨论。对乙酰氨基酚中毒后转诊肝移植的**国王学院标准**包括：复苏后动脉pH低于7.30，或INR高于6.5、肌酐高于300 µmol/L且有Ⅲ或Ⅳ级肝性脑病三者同时存在。

### 水杨酸盐

阿司匹林中毒引起恶心、呕吐、耳鸣、出汗和过度通气。水杨酸盐直接兴奋呼吸中枢，引起**呼吸性碱中毒**，同时使氧化磷酸化解偶联，引起**阴离子间隙增高型代谢性酸中毒**。成人通常表现为混合型；儿童更常表现为单纯酸中毒。严重中毒引起高热、肺水肿、意识模糊、癫痫发作和死亡。

处理包括补液、纠正血钾、用静脉碳酸氢钠**碱化尿液**，以及对严重中毒（浓度极高、严重酸中毒、肾衰竭、肺水肿或神经系统表现）进行**血液透析**。严重水杨酸盐中毒时插管很危险：如果呼吸机不能匹配患者极高的分钟通气量，pH下降，更多水杨酸盐进入大脑，患者可能发生心脏骤停。专科建议必不可少。

### 三环类抗抑郁药

阿米替林等三环类药物阻断心脏钠通道，以及毒蕈碱、组胺和α肾上腺素能受体。毒性发展迅速，出现抗胆碱能综合征、意识下降、癫痫发作、低血压和心律失常。心电图显示窦性心动过速、**QRS增宽**，aVR导联常有高R波。

对QRS增宽、心律失常或低血压，关键治疗是**静脉碳酸氢钠**，它提高血钠和pH，部分克服钠通道阻滞。癫痫发作用苯二氮䓬类治疗。避免使用同样阻断钠通道的抗心律失常药（Ⅰa类和Ⅰc类）。

### 阿片类

阿片类中毒引起意识下降、呼吸抑制和瞳孔缩小。竞争性拮抗剂**纳洛酮**可以逆转。对阿片类依赖者，纳洛酮以小剂量反复静脉给予，恢复足够的呼吸而不诱发严重戒断；如呼吸不足，首先用球囊面罩通气。纳洛酮的作用时间比许多阿片类（美沙酮、缓释制剂）短，因此患者需要观察，可能需要持续输注。为阿片类使用者及其家属提供可带回家的纳洛酮，以减少死亡。

### 苯二氮䓬类

单用苯二氮䓬类很少引起危险的呼吸抑制，但与酒精、阿片类或其他镇静药合用时会。治疗以支持为主。拮抗剂**氟马西尼**很少适用：在苯二氮䓬类依赖或合并三环类摄入的患者中，它可诱发癫痫发作。

### β受体阻滞剂和钙通道阻滞剂

两者都引起心动过缓、传导阻滞和低血压；氨氯地平等钙通道阻滞剂（二氢吡啶类）引起明显的血管扩张，维拉帕米和地尔硫䓬引起严重心动过缓。钙通道阻滞剂中毒常引起高血糖，因为胰岛素分泌被阻断。缓释制剂可导致延迟而持久的毒性。

治疗包括补液、阿托品、静脉钙剂、血管加压药和正性肌力药等支持措施，以及在专家建议下的特异措施：**大剂量胰岛素正常血糖疗法**（胰岛素加葡萄糖以维持血糖正常，改善心肌能量利用）、β受体阻滞剂中毒时用胰高血糖素、起搏、难治病例使用脂肪乳，以及ECMO。

### 地高辛

地高辛中毒常为老年人肾功能下降时的慢性中毒，引起恶心、呕吐、意识模糊、视觉障碍（黄绿视）和几乎任何心律失常，典型的是心动过缓伴传导阻滞，或房性心动过速伴阻滞。高钾血症是严重急性中毒的征象。**地高辛特异性抗体片段**与地高辛结合，用于危及生命的心律失常、明显高钾血症或终末器官受累。

### 有毒醇类

**甲醇**（见于某些溶剂和非法酿造的烈酒）和**乙二醇**（防冻液）本身毒性不大，经乙醇脱氢酶形成的代谢物才有毒。甲醇生成甲酸，损伤视神经并导致失明；乙二醇生成乙醇酸和草酸，引起酸中毒以及伴草酸钙结晶的肾衰竭。患者起初可能看似醉酒，随后出现严重的阴离子间隙增高型代谢性酸中毒。

治疗是用**甲吡唑**（fomepizole，无此药时用乙醇）阻断乙醇脱氢酶，纠正酸中毒，并用**血液透析**清除醇及其代谢物。

### 一氧化碳

一氧化碳（CO）来自故障的锅炉、取暖器、汽车尾气和火灾，与血红蛋白的结合力约为氧的200–250倍，使氧–血红蛋白解离曲线左移，并损害线粒体功能。症状不具特异性：头痛、恶心、头晕、意识模糊，严重时癫痫发作、昏迷和心肌缺血。同一住所内几个人或宠物同时发病是典型线索。

普通脉搏血氧仪**无法区分碳氧血红蛋白与氧合血红蛋白**，读数会假性正常。诊断依靠碳氧血氧仪（大多数血气分析仪具备）测定**碳氧血红蛋白（COHb）**。治疗是经密闭储氧面罩给予**高流量氧**，缩短COHb的半衰期，持续到症状消失、COHb降至低水平。对部分重症病例与专科讨论高压氧；其获益尚不确定。可能出现迟发性神经精神问题，患者回家前必须确保污染源已被排除。

### 有机磷

有机磷杀虫剂抑制**乙酰胆碱酯酶**，使乙酰胆碱在毒蕈碱和烟碱突触处蓄积，产生胆碱能综合征。死亡通常由呼吸衰竭所致：支气管黏液溢、支气管痉挛和呼吸肌无力。

处理首先是**保护工作人员和去污染**（脱去衣物、清洗皮肤），然后给予**阿托品**，剂量迅速递增，直到胸部分泌物清除、心率足够、血压得以维持；可能需要很大的量。肟类药物（如解磷定）可能使酶复活，但试验中的获益尚不确定。患者可能需要插管和机械通气。部分患者在一到四天后出现**中间综合征**，即近端肌和呼吸肌无力。

::: warning “只吃了几片”
中毒中最危险的两个假设是：看起来没事的患者就没事，以及病史是准确的。对乙酰氨基酚、缓释制剂、有毒醇类和某些心脏毒性药物在致命毒性发展时，早期可能几乎没有体征。患者可能轻描淡写或不记得自己吃了什么。每一例故意过量都要查对乙酰氨基酚和水杨酸盐浓度，做心电图，并用TOXBASE针对可能摄入的物质、而不仅仅是患者承认的物质确定观察期。
:::

## 过量服药背后的人 {#sec-person}

大多数故意过量服药的成人是在痛苦状态下这样做的，相当一部分人会再次自伤。每一次就诊都是提供帮助的机会。NICE指南NG225（自伤：评估、处理与预防复发，2022）建议，每一位自伤者都应得到同情和尊重的对待，并由受过训练的精神卫生专业人员进行**心理社会评估**。它不建议用风险评估工具或量表来预测未来的自杀或决定谁接受照护，因为其预测能力差；评估应聚焦于本人的需要、处境和安全计划。

用词很重要：说“自伤的人”或“故意过量”，而不是暗含指责或操纵意味的说法。工作人员的态度在很大程度上影响人们是否会再次求助。更多内容见[[psychiatry/self-harm-suicide-prevention]]。

**拒绝治疗**是常见而棘手的情况。在英格兰和威尔士，决定依据**《2005年心智能力法》**作出：16岁及以上者被推定有决策能力，针对特定时间的特定决定进行评估。如果一个人因心智或大脑的损害而不能理解、记住、使用或权衡信息，或不能表达决定，则其缺乏决策能力。有决策能力的成人可以拒绝治疗，即使拒绝可能导致死亡。缺乏决策能力者按其最佳利益接受治疗。《1983年精神卫生法》授权治疗精神障碍，而不是治疗中毒的躯体后果，不能把两部法律混淆。必须有高年资医生和精神科的参与，并仔细记录评估。

## 实例分析

::: example 分次摄入的对乙酰氨基酚过量 {#ex-para}
一名23岁女性说她因牙痛和情绪低落，在过去一天里分几次服了“几片”对乙酰氨基酚，最后一次约在6小时前。她感觉良好。对乙酰氨基酚浓度38 mg/L，ALT 64 U/L（正常低于40），INR 1.1。低年资医生把6小时的38 mg/L标在列线图上，发现位于线以下，打算让她出院。哪里错了？
::: solution
这是**分次**摄入，历时多个小时，没有单一的摄入时间，因此不能使用列线图。用治疗线解读浓度的前提是单次服药且时间明确。此外，她的ALT已经升高。

按照英国指南，分次摄入可能中毒量的患者，或对乙酰氨基酚浓度可测出且ALT异常的患者，应接受**乙酰半胱氨酸**治疗。治疗结束时复查血液，如ALT或INR异常则继续治疗。TOXBASE给出现行标准。

她还需要牙科评估以处理疼痛，并且因为她提到情绪低落，出院前需要一次富有同情心的**心理社会评估**。因疼痛分次自行服药导致的非故意过量很常见，而且正因为患者看起来很好，常常被漏诊。
:::
:::

::: example 氨氯地平的迟发性恶化 {#ex-cacb}
一名58岁男性在故意过量服用其缓释氨氯地平（amlodipine）3小时后被送来。到达时清醒，血压112/70 mmHg，脉率96次/分。六小时后他嗜睡，血压72/38 mmHg，脉率112次/分，四肢温暖，血糖14.2 mmol/L，乳酸4.8 mmol/L。解释病程并概述处理。
::: solution
氨氯地平是**二氢吡啶类钙通道阻滞剂**，主要作用于血管平滑肌，因此过量引起严重的**血管扩张**伴反射性心动过速（不同于使心率减慢的维拉帕米或地尔硫䓬）。缓释制剂解释了延迟出现的恶化。高血糖反映胰腺β细胞的胰岛素释放受阻，是病情严重的标志。

在TOXBASE或NPIS的建议下处理：

1. ABCDE，尽早请重症监护会诊，动脉置管。
2. 如在时间窗内且气道安全，可考虑活性炭（此时已太晚；就诊时本可考虑）。
3. 静脉补液冲击并再评估；**静脉钙剂**。
4. 针对血管扩张使用**血管加压药**（去甲肾上腺素），如超声心动图显示收缩不良则加用正性肌力药。
5. **大剂量胰岛素正常血糖疗法**，频繁监测血糖和血钾。
6. 难治性休克：在专科建议下使用脂肪乳，有条件时转诊ECMO。

康复后，他需要接受心理社会评估。
:::
:::

::: example 头痛的一家人 {#ex-co}
一月份，一名34岁女性带着两个孩子（4岁和7岁）来到急诊科，因为三人两天来都头痛、恶心，早晨加重，外出后好转。家里的狗也无精打采。她未吸氧时SpO₂ 99%。可能的诊断是什么？如何确诊和处理？
::: solution
很可能是**一氧化碳中毒**：同一家庭的几名成员（和一只宠物）同时出现非特异性症状，在家时和冬季使用取暖设备时加重。SpO₂正常并不令人放心，因为普通脉搏血氧仪无法区分碳氧血红蛋白。

确诊依靠静脉或动脉血气碳氧血氧仪测定**COHb**（分诊时可用呼气CO监测仪）。三人都经储氧面罩接受**高流量氧**治疗，直到症状消失、COHb正常。成人查心电图和肌钙蛋白，所有人都做神经系统检查。重症病例（意识丧失、神经体征、心肌缺血、妊娠）与专科讨论。

在设备检查之前不得再进入房屋：通知燃气紧急服务和地方当局，并建议这家人安装CO报警器。同一建筑内的其他住户也可能有危险。
:::
:::

::: example 分泌物增多的农场工人 {#ex-organophosphate-household}
一名在农场工作的46岁男性在棚屋里喝了一个无标签瓶子里的东西后被送来。他出汗、流涎、呕吐，伴腹泻，瞳孔针尖样，全身肌肉抽动，心率每分钟44次，伴哮鸣音和大量支气管分泌物。他的衣服散发化学品气味。这是哪种毒物综合征？首要任务是什么？
::: solution
这是**胆碱能综合征**，最可能由**有机磷**杀虫剂引起：毒蕈碱样表现（流涎、出汗、呕吐、腹泻、瞳孔缩小、心动过缓、支气管黏液溢和支气管痉挛）加上烟碱样表现（肌束震颤）。

1. **保护工作人员**：个人防护装备；脱下他的衣物并装袋；清洗皮肤。
2. **ABC**：吸引，高流量氧；准备插管，因为呼吸衰竭是主要死因。
3. 静脉**阿托品**，每隔数分钟剂量加倍，直到胸部分泌物清除、心率高于约80次/分、收缩压高于约80 mmHg。不以瞳孔大小作为终点。
4. 在专科建议下考虑**肟类药物**；癫痫发作用苯二氮䓬类治疗。
5. 在随后几天观察有无**中间综合征**：屈颈肌、近端肌和呼吸肌无力。

如果是故意摄入，他康复后需要接受心理社会评估。
:::
:::

::: example 解读间隙 {#ex-gaps}
一名41岁男性被发现意识模糊。血液结果：Na⁺ 140，Cl⁻ 100，HCO₃⁻ 8，尿素5，葡萄糖5 mmol/L；pH 7.08；乳酸2.0 mmol/L；实测渗透压330 mOsm/kg。计算阴离子间隙和渗透压间隙并加以解读。
::: solution
按[[#eq-ag]]计算阴离子间隙：$140 - (100 + 8) = 32$ mmol/L，明显升高。

计算渗透压：$2 \times 140 + 5 + 5 = 290$ mOsm/kg。渗透压间隙：$330 - 290 = 40$，明显升高（正常低于约10）。

阴离子间隙增高型代谢性酸中毒伴渗透压间隙升高、乳酸低到不足以解释酸中毒、血糖正常，指向**有毒醇类中毒**（甲醇或乙二醇）。乙醇本身也会升高渗透压间隙，但不会引起这种程度的酸中毒，因此应测定其浓度。治疗是**甲吡唑**、碳酸氢钠纠正酸中毒，以及紧急**血液透析**，同时把有毒醇类浓度送参比实验室检测并听取NPIS的建议。做眼科检查以寻找甲醇性视神经损伤；乙二醇中毒时尿镜检可见草酸盐结晶。
:::
:::

::: quiz
一名30岁女性10小时前故意过量服用对乙酰氨基酚，刚到急诊科。她感觉良好。最恰当的第一步是什么？
- [ ] 测对乙酰氨基酚浓度，等结果出来再决定是否治疗。
- [x] 立即开始乙酰半胱氨酸，待对乙酰氨基酚浓度和肝功能结果出来后再调整。
- [ ] 给予活性炭。
- [ ] 因为她感觉良好，给予建议后让其出院。
::: solution
在可能有意义的摄入后超过8小时，乙酰半胱氨酸的获益正在下降，因此应立即开始治疗，如果之后浓度低于治疗线且血液检查正常再停药。摄入10小时后活性炭不太可能有帮助。在对乙酰氨基酚中毒的这一阶段，看起来没事是意料之中的。
:::
:::

::: history
毒理学始于16世纪医生帕拉塞尔苏斯（Paracelsus）的一句名言：“剂量决定毒性”，即任何物质只要足够多都有毒。1814年，在巴黎工作、出生于西班牙的化学家奥尔菲拉（Mathieu Orfila）出版了第一部系统的毒物学专著，并开创了在组织中检测毒物的方法，奠定了法医毒理学。现代临床毒理学发展于20世纪下半叶。英国国家毒物信息服务成立于1963年，为临床医生提供咨询。1975年，Barry Rumack和Henry Matthew发表了把对乙酰氨基酚浓度、时间与肝损伤风险联系起来的列线图；20世纪70年代，爱丁堡的Laurie Prescott及其同事证明静脉乙酰半胱氨酸可以预防肝损伤，这是解毒剂治疗最清楚的成功之一。
:::

药物处置和毒性背后的药理学见[[pharmacology/metabolism-excretion]]和[[pharmacology/adverse-reactions]]。酸碱解读见[[renal/acid-base-disorders]]。对药物使用者的照护见[[psychiatry/substance-use]]，对自伤者的照护见[[psychiatry/self-harm-suicide-prevention]]。严重中毒患者的器官支持见[[emergency-critical-care/critical-care]]，中毒所致心脏骤停见[[emergency-critical-care/resuscitation]]。

::: summary
- 用ABCDE进行支持治疗是基础；大多数中毒患者不需要更多处理。每一例严重中毒都应查询TOXBASE或NPIS。
- 每一例故意过量都要测定对乙酰氨基酚和水杨酸盐浓度，做心电图，查血糖和血气。
- 病史不清时，毒物综合征（阿片类、镇静类、抗胆碱能、拟交感、胆碱能、5-羟色胺）有助于判断。
- 在约一小时内且气道安全时考虑活性炭；加速清除（碱化尿液、血液透析）对少数分布容积小的毒物有用。
- 对乙酰氨基酚：英国单一治疗线从4小时100 mg/L起；就诊超过8小时，或分次、时间不明的摄入，应立即开始乙酰半胱氨酸。
- 特异治疗：三环类QRS增宽用碳酸氢钠，阿片类用滴定的纳洛酮，有毒醇类用甲吡唑和透析，一氧化碳用氧，有机磷用阿托品，地高辛用抗体片段。
- 照护人本身：对每一位自伤者进行富有同情心的心理社会评估；如拒绝治疗，依据《心智能力法》评估决策能力。
:::

## 习题

::: exercise 阴离子间隙 {level=1 check="24"}
一名患者血液检查显示Na⁺ 138、Cl⁻ 104、HCO₃⁻ 10 mmol/L。计算阴离子间隙（mmol/L）。
::: solution
$138 - (104 + 10) = 24$ mmol/L，升高。应寻找乳酸、酮体、肾衰竭、水杨酸盐和有毒醇类。
:::
:::

::: exercise 读取治疗线 {level=1 check="25"}
治疗线在4小时为100 mg/L，每4小时减半。单次急性摄入后12小时，治疗线的数值是多少（mg/L）？
::: solution
从4小时到12小时为8小时，即两个半衰期：$100 \times 0.5^2 = 25$ mg/L。单次、时间明确的摄入后12小时，浓度为25 mg/L或以上提示需用乙酰半胱氨酸。
:::
:::

::: exercise 渗透压间隙 {level=2 check="40"}
实测渗透压330 mOsm/kg，Na⁺ 140 mmol/L，尿素5 mmol/L，葡萄糖5 mmol/L。用$2[\text{Na}^+] + [\text{尿素}] + [\text{葡萄糖}]$计算渗透压间隙。
::: solution
计算渗透压$= 280 + 5 + 5 = 290$。渗透压间隙$= 330 - 290 = 40$ mOsm/kg，明显升高：怀疑有毒醇类或乙醇。
:::
:::

::: exercise 说出综合征 {level=1}
说出毒物综合征：(a) 音乐节上一名19岁青年，激越，瞳孔散大，体温39.4 °C，心率140次/分，大汗淋漓；(b) 一名76岁老人开始服用一种新的抗组胺药后，意识模糊，皮肤干燥潮红，瞳孔散大，膀胱膨胀；(c) 一名服用SSRI的50岁患者加用曲马多后，震颤、出汗、持续性踝阵挛。
::: solution
(a) 拟交感综合征（如MDMA、可卡因或苯丙胺类）；出汗可与抗胆碱能综合征相区别。
(b) 抗胆碱能综合征：“热如兔、干如骨、红如甜菜、瞎如蝙蝠、疯如帽匠”，伴尿潴留。
(c) 联合用药所致的5-羟色胺毒性；阵挛是关键体征。
:::
:::

::: exercise 用不用活性炭 {level=2}
对下列每位患者，说明活性炭是否适当及理由：(a) 30岁，45分钟前过量服用一种缓释β受体阻滞剂，完全清醒；(b) 25岁，30分钟前喝了防冻液；(c) 40岁，30分钟前混合药物过量后GCS 8分，未插管；(d) 60岁，40分钟前服用了锂。
::: solution
(a) 是，可以考虑：时间早、清醒、气道受保护，药物能被吸附且可能引起严重毒性。
(b) 否：活性炭不吸附乙二醇。
(c) 除非先插管保护气道，否则不用，因为误吸活性炭很危险。
(d) 否：活性炭不吸附锂。锂中毒用补液处理，严重时血液透析。
:::
:::

::: exercise 处理胆碱能危象 {level=2}
一名有机磷中毒患者已接受数剂阿托品。他的瞳孔现在大小正常，心率92次/分，但仍有广泛湿啰音和大量分泌物，SpO₂ 88%。阿托品化是否已经完成？
::: solution
没有。阿托品化的终点是胸部清晰（无支气管黏液溢）、心率高于约80次/分、收缩压高于约80 mmHg以及腋下干燥；瞳孔大小不是可靠的终点。持续的支气管黏液溢意味着需要更多阿托品，应迅速加量，同时给氧、吸引并准备插管。
:::
:::

::: exercise 决定是否透析 {level=2}
下列哪些中毒可能从血液透析中获益？为什么？(a) 伴意识模糊和肾损伤的严重锂中毒；(b) 严重阿米替林中毒；(c) 伴酸中毒的严重甲醇中毒；(d) 伴肺水肿的严重水杨酸盐中毒。
::: solution
(a) 是：锂分布容积小、不与蛋白结合、经肾清除，而肾功能正在衰竭。
(b) 否：阿米替林分布容积极大、蛋白结合率高，透析清除极少（[[#thm-halflife]]）。治疗以支持为主，QRS增宽时用碳酸氢钠。
(c) 是：透析清除甲醇和甲酸，并纠正酸中毒。
(d) 是：水杨酸盐可被透析清除，透析还能纠正酸中毒和液体超负荷。
:::
:::

::: exercise 拒绝治疗的患者 {level=3}
一名28岁男性6小时前故意过量服用对乙酰氨基酚，浓度高于治疗线。他拒绝乙酰半胱氨酸，想要离开。团队应如何处理？
::: solution
首先认真对待他的拒绝，并与他交谈：他为什么想离开，他了解什么，他害怕什么？平静而富有同情心的谈话往往就能解决问题。清楚地解释：现在治疗非常有效，以后就差得多；肝损伤可能很严重，而且要到后来才会感觉到。

然后依据《2005年心智能力法》评估他对这一决定的**决策能力**：他能否理解信息、记住信息、使用或权衡信息并表达决定？急性痛苦、醉酒或精神障碍可能削弱他权衡信息的能力，但并不自动意味着缺乏决策能力。如果他有决策能力，必须尊重他的拒绝，同时为他留着回来的门，并制订安全计划。如果他缺乏决策能力，可按其最佳利益、采用限制最少的方式给予治疗。《精神卫生法》可能与评估和治疗精神障碍有关，但其本身并不授权治疗过量服药。应请高年资急诊医生和精神科同事参与，并完整记录评估。
:::

::: exercise 地高辛中毒 {level=3}
一名84岁女性因心房颤动服用地高辛，因呕吐、意识模糊和黄视就诊。监护仪显示心率40次/分、节律规整；血钾5.9 mmol/L；肌酐从90升至210 µmol/L。解释这些发现及治疗。
::: solution
这是由**急性肾损伤**减少地高辛排泄所诱发的**慢性地高辛中毒**。已知心房颤动的患者出现规整的缓慢节律，提示**完全性心脏阻滞伴交界性逸搏**，这是地高辛中毒的典型征象（房颤被“规整化”）。高钾血症反映Na⁺/K⁺-ATP酶受到抑制。

治疗：停用地高辛，纠正脱水和肾损伤，心电监护，并针对危及生命的缓慢性心律失常和高钾血症给予**地高辛特异性抗体片段**，剂量按TOXBASE。阿托品可暂时有效。末次服药至少6小时后采集的地高辛浓度有助于确诊，但对明显中毒的患者不应因此延误治疗。
