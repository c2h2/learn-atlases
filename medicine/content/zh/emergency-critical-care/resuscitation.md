心脏一旦停止泵血，大脑在约十秒内丧失意识，并在数分钟内开始遭受不可逆的损伤。复苏是在这几分钟里维持一定血流、在可能时恢复有灌注的心律、随后保护曾经缺血的器官的一整套措施。它是医学中少数几个领域之一：一套固定的流程，练到成为本能，就能明确地挽救生命。

本章按事件的进程追随患者。先讲心脏骤停是什么以及胸外按压为何有效，再讲基础与高级生命支持、可逆病因、特殊情况下的骤停、骤停前后出现的心律，以及自主循环恢复后的救治，最后讨论是否应当尝试复苏的决策。流程依据英国复苏委员会（Resuscitation Council UK，RCUK）2021年成人指南；2025年10月的更新保留了相同的给药时机。文中引用的剂量是这些流程图中印出的标准成人剂量，仅供教学；临床实践以现行本地指南为准。

## 心脏骤停是什么 {#sec-arrest}

::: definition 心脏骤停 {#def-arrest}
**心脏骤停**是有效心排血量的突然丧失。患者无反应，且没有正常呼吸。实践中靠临床表现识别，而不是靠摸脉搏，因为无论受过训练与否，人们摸脉搏判断都不可靠。

监护仪上的心律分为两组：

- **可电击心律**：**心室颤动（室颤，VF）**，即没有有组织收缩的紊乱电活动；以及**无脉性室性心动过速（pVT）**，即不产生排血量的快速宽QRS心律。除颤器电击可以终止这两种心律。
- **不可电击心律**：**心脏停搏**，即没有电活动；以及**无脉性电活动（PEA）**，即通常应当产生脉搏、实际上却没有脉搏的有组织心律。电击无益；治疗是心肺复苏、肾上腺素以及寻找病因。

**自主循环恢复（ROSC）**指有灌注的心律重新出现，表现为可触及脉搏、呼气末二氧化碳上升或动脉压力波形。
:::

两组心律在病因和预后上都不同。成人因急性心肌缺血或遗传性、结构性心脏病而突然倒下时，首个心律通常是室颤。它是最可治疗的骤停：只要在最初几分钟内使用除颤器，相当大比例的患者能够存活。心脏停搏和PEA更常是其他问题的终末结果，如缺氧、出血、肺栓塞或代谢紊乱，或者是无人干预时室颤衰变而成。它们的结局取决于能否找到并逆转病因。

总体结局令人警醒。在英国，由急救服务处理的院外心脏骤停患者中大约十分之一能存活出院，院内骤停者大约五分之一能存活出院。在有目击的室颤、早期旁观者心肺复苏和早期除颤的情况下，存活率要高得多，这就是为什么骤停发生时的外部体系与医院同样重要。

### 胸外按压为何有效

::: theorem 冠状动脉灌注压 {#thm-cpp}
心肺复苏期间，心肌在每次按压的放松期得到灌注，就像在舒张期一样。驱动压力是**冠状动脉灌注压（CPP）**：

$$
\text{CPP} = P_{\text{主动脉舒张压}} - P_{\text{右心房舒张压}}
$$ {#eq-cpp}

只有当CPP足够高时，ROSC才有可能（人体研究中，CPP低于约15 mmHg时复苏很少成功）。良好的胸外按压大约产生正常心排血量的四分之一到三分之一。
:::

::: proof
每次按压把血液从胸腔挤入主动脉。由于主动脉瓣在放松时关闭，胸廓回弹时主动脉压仍保持升高，主动脉与右心房之间的压差推动血液流经冠状动脉。这一压力要经过一连串按压才逐步建立，并不会在第一次按压时就出现。按压一旦停止——无论是为了摸脉搏、检查心律还是换人——主动脉压在数秒内下降，CPP随之崩溃。重新开始后，需要许多次按压才能回到原来的水平。这就是指南坚持尽量减少中断的原因，也是胸廓充分回弹之所以重要的原因（倚靠在胸壁上会升高右心房压、降低CPP），以及除颤器充电时继续按压的原因。
:::

值得追踪的数字是**胸外按压比例**：骤停过程中实际进行按压的时间所占的比例。团队的目标是远高于80%。每一秒的停顿都有代价。

::: widget plot
f: 100*exp(-0.12*x); 100*exp(-0.06*x)
x: 0, 20
y: 0, 100
labels: \text{无旁观者心肺复苏}; \text{有旁观者心肺复苏}
caption: 一个简化的教学模型，显示室颤骤停的存活机会如何随首次电击前的分钟数下降。数值仅为示意，并非临床数据：没有心肺复苏时，存活机会下降陡峭，每分钟大约下降当前值的10%；良好的旁观者心肺复苏使下降速度大致减半。两条曲线说明了为什么生存链是围绕早期心肺复苏和早期除颤、而不是围绕医院建立的。
:::

## 基础生命支持 {#sec-bls}

基础生命支持（BLS）是任何施救者在设备到达之前所做的事。成人流程是：

1. 确认接近患者是安全的，然后通过呼叫并轻拍双肩检查有无反应。
2. 用仰头抬颏法开放气道，观察是否有正常呼吸，时间不超过十秒。**濒死呼吸**——缓慢、不规则的喘息——在骤停最初几分钟很常见，绝不能误认为正常呼吸。
3. 如果患者无反应且没有正常呼吸，呼救（院外拨打999或112；院内拨打医院的心脏骤停呼叫号码），并要求取来自动体外除颤器（AED）。
4. 开始胸外按压：双手置于胸骨下半部，深度5–6 cm，频率每分钟100–120次，让胸廓充分回弹；如果施救者受过训练并愿意人工呼吸，则按压30次后给2次通气。未受过训练的施救者只做按压，由急救调度员在电话中指导。
5. AED一到立即接上并按其提示操作。两次分析之间继续心肺复苏。

**生存链**包括四个环节：早期识别并呼救、早期心肺复苏、早期除颤，以及复苏后救治。公共除颤器、调度员指导的心肺复苏和志愿急救者手机应用都加强了前三个环节，它们对结局的影响最大。

## 高级生命支持 {#sec-als}

高级生命支持（ALS）在此基础上增加了手动除颤器、气道管理、血管通路、药物和对病因的结构化寻找。其主干是两分钟循环：两分钟不间断的心肺复苏，短暂停顿观察心律，有指征时电击，然后立即恢复按压。

::: algorithm ALS流程（RCUK 2021） {#def-als}
1. 确认心脏骤停，呼叫复苏小组，以30:2开始心肺复苏，贴上除颤电极片或连接监护仪。
2. 短暂停顿评估心律。
3. **如为可电击心律（VF或pVT）：**电击一次（双相波，首次电击至少150 J，或按厂商建议），然后立即恢复心肺复苏两分钟，不检查脉搏或心律。每个循环结束时重新评估心律，如仍为可电击心律则再次电击。
   - **第三次电击**后：给予**肾上腺素1 mg IV/IO**和**胺碘酮300 mg IV/IO**。
   - 此后每3–5分钟重复肾上腺素1 mg（实践中为每隔一个循环）。
   - **第五次电击**后：再给**胺碘酮150 mg**。
4. **如为不可电击心律（PEA或心脏停搏）：**恢复心肺复苏，**一旦建立通路即给予肾上腺素1 mg IV/IO**，此后每3–5分钟一次。
5. 全程：高质量按压并尽量减少中断；给氧；使用二氧化碳波形监测；有熟练人员时建立高级气道；建立静脉通路（不能建立时用骨髓腔内通路）；识别并处理可逆病因。
6. 如出现ROSC，转入复苏后救治。
:::

有几个细节决定了流程在实践中能否奏效。

**电击。**除颤器充电时继续按压；电击本身的停顿应少于约五秒。电击后立即恢复按压。即使电击成功，被击昏的心脏通常也会有一段时间几乎没有排血量，因此停下来摸脉搏只会浪费灌注，而且很少摸得到。电极片位置很重要：侧方（心尖）电极片应放在腋中线上，2025年RCUK更新特别指出它常被放得过于靠前。在**有目击、有监护的室颤骤停**中（例如在心导管室），如果除颤器已经连接好，可以在开始按压前连续快速给予最多三次电击。

**气道与呼吸。**起初用球囊面罩通气（常配合口咽通气道）就足够了。只有当操作者足够熟练、能让按压中断少于约五秒时，才放置声门上气道或气管导管。高级气道建立后，按压改为连续进行，通气频率约为每分钟10次。**二氧化碳波形图**可以确认导管位置，显示心肺复苏的质量（按压越好，呼气末二氧化碳越高），并常常以骤然上升给出ROSC的第一个信号。

**通路与药物。**首先尝试静脉通路，无法建立时用骨髓腔内（IO）通路。PARAMEDIC-3试验（2024）将英格兰和威尔士约6,000例院外骤停随机分为IO优先或静脉优先策略，结果30天存活率没有差异。肾上腺素提高ROSC的机会。在PARAMEDIC2试验（2018）中，院外骤停使用肾上腺素提高了30天存活率（3.2%对比安慰剂的2.4%），但没有显著提高神经功能良好的存活率（2.2%对比1.9%）。这就是流程保留肾上腺素、却把按压和除颤放在首位的原因。胺碘酮用于电击后仍持续的VF或pVT；没有胺碘酮时，利多卡因是替代药物。

::: warning 为做别的事而中断按压
真实骤停中最常见的错误不是用错药，而是停顿太长：为置入静脉套管、插管、抽血气、做超声或讨论计划而停止心肺复苏。这些事情都可以在按压进行中或在几秒钟的停顿里完成。一个始终保持双手在胸壁上的组长，对患者的贡献比一个每种药物都准时给到的组长更大。
:::

### 可逆病因

::: definition 4H与4T {#def-hts}
心脏骤停的可逆病因记为：

| 4H | 4T |
|---|---|
| **缺氧**（Hypoxia） | **血栓形成**（冠状动脉或肺动脉）（Thrombosis） |
| **低血容量**（Hypovolaemia） | **张力性气胸**（Tension pneumothorax） |
| **低钾或高钾血症及其他代谢紊乱**（Hypo-/hyperkalaemia） | **心脏压塞**（Tamponade） |
| **低体温或高体温**（Hypothermia/hyperthermia） | **中毒**（Toxins） |

每次骤停都要考虑这些病因，在不可电击骤停中它们是团队的主要工作。
:::

每种病因都有床旁线索和特定治疗。心肺复苏期间的血气在一分钟内就能给出血钾、血红蛋白、血糖和pH。经过训练的操作者在检查心律的停顿期间进行床旁超声，可以显示心包积液、提示肺栓塞的右心室扩大，或提示低血容量的空虚心脏。病史也很重要：错过透析的透析患者、创伤患者、留置中心静脉导管后突然恶化的患者、已知的药物过量。

| 病因 | 典型线索 | 特定治疗 |
|---|---|---|
| 缺氧 | 窒息、气道梗阻、先有呼吸停止 | 给氧和有效通气 |
| 低血容量 | 出血、创伤、脓毒症 | 补液和输血，控制出血 |
| 高钾血症 | 肾衰竭、错过透析、骤停前出现宽QRS波 | 静脉钙剂、胰岛素–葡萄糖、碳酸氢钠；透析 |
| 低体温 | 暴露、浸水 | 复温，最好体外复温 |
| 血栓形成（肺栓塞） | 近期手术、制动、右心室扩大 | 溶栓；之后继续心肺复苏60–90分钟 |
| 血栓形成（冠状动脉） | 倒地前胸痛、室颤 | 冠状动脉造影，有时在机械心肺复苏下进行 |
| 张力性气胸 | 创伤、机械通气、中心静脉置管 | 减压（手指胸廓造口或穿刺） |
| 心脏压塞 | 穿透伤、心脏手术后 | 心包穿刺或开胸 |
| 中毒 | 病史、中毒综合征 | 特异性解毒剂（见[[emergency-critical-care/poisoning]]） |

### 团队

ALS由团队实施，它的许多失败都是团队协作的失败。好的团队有一名不亲自操作、站在后面统筹的组长，有明确分工（按压、气道、除颤、药物与通路、记录），并采用**闭环沟通**：指令发给指定的人，对方复述，完成后确认。组长在停顿前就把下一个循环的计划说出来，这样停顿短暂，每个人都知道将要发生什么。按压者每两分钟轮换一次，因为按压质量随疲劳下降，而下降远早于施救者自己察觉。

::: example 可电击骤停中的给药时机 {#ex-timing}
一名63岁男性在医院停车场倒地。团队带着除颤器赶到；首个心律为室颤。第一次电击在第0分钟给予，此后每次检查时心律仍为室颤。假设两分钟循环完全准确，第一剂肾上腺素、第一剂胺碘酮和第二剂胺碘酮分别在什么时间给予？
::: solution
两分钟一个循环，电击发生在第0、2、4、6、8分钟，依此类推：第三次电击在第4分钟，第五次在第8分钟。

- 第一剂肾上腺素1 mg和胺碘酮300 mg：第三次电击后、恢复按压时给予，约在第4分钟。
- 后续肾上腺素：每3–5分钟一次，实践中即每隔一个循环，约在第8、12、16分钟。
- 第二剂胺碘酮150 mg：第五次电击后，约在第8分钟。

整个过程中，团队都在追问这名男性为何发生室颤。冠状动脉闭塞是最可能的原因，ROSC后的12导联心电图，或在室颤难治时尽早与心内科讨论，都是计划的一部分。
:::
:::

::: example 血钾8.1 mmol/L的骤停 {#ex-k-arrest}
一名46岁的血液透析女性患者错过了两次透析。她被送来时嗜睡，心电图为宽QRS心动过缓，心率每分钟30次；到达后不久，心电图变成缓慢的正弦波样图形，脉搏消失。心肺复苏期间的静脉血气显示血钾8.1 mmol/L，pH 7.12。骤停的原因是什么？如何治疗？
::: solution
这是由**高钾血症**（4H之一）引起的PEA。缓慢的宽QRS波逐渐融合为正弦波，是典型的演变过程。

1. 继续高质量心肺复苏，按不可电击分支给予肾上腺素。
2. 给予**静脉钙剂**（氯化钙或葡萄糖酸钙，按本地高钾血症指南）。它在数分钟内稳定心肌细胞膜，但不降低血钾。
3. 用**胰岛素加葡萄糖**使钾转移入细胞，并密切监测血糖；严重酸中毒或骤停时间延长时可给予碳酸氢钠。
4. 安排清除血钾：**透析**是确定性治疗，在一些中心可在复苏期间或复苏后不久开始。

高钾血症性骤停在长时间复苏后仍可能对治疗有反应，因此在纠正病因期间团队不应过早停止。ROSC后，她需要反复测定血钾和血糖、心电监护和紧急透析。相关生理见[[renal/potassium-calcium-phosphate]]。
:::
:::

## 特殊情况下的骤停 {#sec-special}

有些病因会改变流程本身。

- **低体温。**低温的心脏对药物和电击都不敏感，而低温的大脑对低血流的耐受更好。如果核心体温低于30 °C，最多给三次电击，并暂停肾上腺素直到体温升至30 °C；在30–35 °C之间，肾上腺素的给药间隔加倍。体外复温（ECMO或体外循环）是首选治疗，复苏常常持续到患者复温之后。
- **妊娠。**从约20周起，平卧时子宫压迫下腔静脉，因此心肺复苏时要用手把子宫推向左侧。如果约四分钟内仍无ROSC，团队准备进行**复苏性子宫切开术**（濒死剖宫产），目标是在五分钟内娩出胎儿。排空子宫可改善静脉回流，主要目的是帮助母亲。
- **肺栓塞。**如果肺栓塞是可能的病因，在心肺复苏期间给予溶栓，随后继续心肺复苏60–90分钟，让药物有时间起效。
- **淹溺。**骤停属窒息性，因此早期通气很重要：在按压之前先给五次初始人工呼吸。
- **创伤。**创伤性骤停通常由出血、张力性气胸、心脏压塞或缺氧引起，处理这些问题优先于胸外按压，因为对空虚的心脏按压作用甚微。
- **严重过敏反应与中毒。**分别见[[emergency-critical-care/anaphylaxis]]和[[emergency-critical-care/poisoning]]。某些毒物需要延长复苏，因为在心肺复苏维持血流期间，药物可能逐渐失效或被清除。

**体外心肺复苏（ECPR）**，即让难治性骤停患者接受静脉–动脉ECMO，在部分中心可用于经过严格选择的患者：通常是有目击的骤停、有旁观者心肺复苏、可电击心律，且距ECMO团队到达时间短。它是一座桥梁，为治疗病因（如闭塞的冠状动脉）争取时间。

::: example 难治性室颤的58岁男性 {#ex-ecpr}
一名58岁男性在健身房倒地。一名工作人员立即开始心肺复苏，健身房的AED在四分钟内完成电击。救护车组继续ALS。25分钟后，他已接受七次电击、三剂肾上腺素和两剂胺碘酮，仍为室颤。按压期间呼气末二氧化碳为3.5 kPa。一名低年资医生提议停止，因为“已经快半小时了”。团队应如何考虑这个问题？
::: solution
在有目击骤停、立即有旁观者心肺复苏的较年轻患者中，**难治性室颤**正是延长复苏最值得的人群。心律仍可电击，呼气末二氧化碳提示按压产生了一定血流，而急性冠状动脉闭塞是最可能的病因。

- 单凭时长不是停止的理由。可电击骤停的终止规则看的是整体情况，而不是时钟。
- 如果当地有ECPR服务，应尽早联系，因为能否入选取决于时间。机械按压装置可以在转运途中保证良好的心肺复苏。
- 在可电击流程内，团队可以检查电极片位置并考虑改变电极片方向；2022年一项加拿大试验（DOSE VF）报告，在难治性室颤中改变电极片方向或采用双重序贯电击可提高存活率，一些急救服务已把这些选项纳入其规程。
- 再次复核可逆病因：血钾、张力性气胸、肺栓塞。

这一决定由高年资临床医生负责，向团队解释清楚，无论结局如何事后都要进行复盘。
:::
:::

## 骤停前后：围骤停期心律 {#def-peri}

许多骤停之前都有本可治疗的心律紊乱，许多ROSC后的患者也有不稳定的心律。RCUK围骤停期流程首先问一个问题：**是否存在不良特征？**它们是**休克**（低血压、苍白、出汗、意识模糊）、**晕厥**、**心肌缺血**（胸痛或缺血性心电图改变）和**心力衰竭**（肺水肿、颈静脉压升高）。

::: definition 围骤停期心动过缓与心动过速的处理 {#def-periarrest}
**心动过缓。**如存在不良特征，给予**阿托品500微克静脉注射**，必要时重复，总量最多3 mg。如果反应不足，或存在心脏停搏的高风险（近期发生过心脏停搏、莫氏Ⅱ型阻滞、伴宽QRS的完全性心脏阻滞，或心室停顿超过3秒），安排**起搏**，以异丙肾上腺素或肾上腺素输注或经皮起搏作为过渡，直至经静脉起搏。

**伴不良特征的心动过速。**在镇静或麻醉下给予**同步直流电复律**，最多三次；如不成功，静脉给予胺碘酮300 mg（10–20分钟内），再重复电复律。

**无不良特征的心动过速。**观察QRS宽度和节律是否规整。规则的窄QRS心动过速先用迷走神经刺激手法，再快速静脉推注**腺苷**（6 mg，必要时12 mg，再18 mg），同时记录心电图。不规则的窄QRS心动过速通常是心房颤动，予以控制心室率。宽QRS心动过速除非有明确相反证据，否则按室性心动过速处理。
:::

有两个陷阱值得强调。第一，心率慢有时是另一个问题的结果，需要针对该问题治疗：高钾血症、低体温、颅内压升高，或β受体阻滞剂、钙通道阻滞剂、地高辛中毒。第二，预激综合征（Wolff–Parkinson–White综合征）中的**预激性心房颤动**表现为不规则、极快的宽QRS心动过速。阻断房室结的药物，包括腺苷、维拉帕米和地高辛，会加快旁路传导并诱发室颤。这类患者不稳定时，同步电复律是安全的选择。更多细节见[[cardiovascular/arrhythmias]]。

## ROSC之后：复苏后救治 {#def-post}

ROSC是一场新的危重疾病——**心脏骤停后综合征**——的开始。它包括四个部分：无血流期造成的脑损伤；可持续数天的心肌功能障碍（顿抑）；缺血再灌注引起、可类似脓毒症的全身炎症反应；以及导致骤停的原发疾病。

::: definition 复苏后救治的主要目标 {#def-postcare}
ROSC后，按照英国采用的ERC–ESICM指南，优先事项是：

- **气道与呼吸**：患者未清醒时建立确定性气道；SpO₂目标**94–98%**（低氧血症和过高的动脉氧均应避免），动脉PaCO₂维持正常。
- **循环**：做12导联心电图；平均动脉压目标高于约**65 mmHg**（收缩压高于100 mmHg），按需补液和使用血管加压药；治疗病因。
- **冠状动脉造影**：心电图ST段抬高者立即进行；无ST段抬高者，当急性冠状动脉病因可能性大时考虑，而不是常规进行。
- **体温**：对仍处于昏迷的患者，主动**预防发热**（体温高于37.7 °C）至少72小时。
- **大脑**：治疗癫痫发作，避免低血糖和明显高血糖，对昏迷患者记录脑电图。
- **预后**：至少**72小时**后、待镇静药作用消退，才评估神经功能预后，并联合使用多项检查。
:::

复苏后救治有两个方面的变化值得了解。体温管理曾经是32–34 °C的“治疗性低温”。TTM试验（2013）发现33 °C与36 °C之间没有差异，更大规模的TTM2试验（2021）发现33 °C并不优于积极治疗发热的常温管理。因此目前的做法是预防发热，而不是降温。冠状动脉造影也类似：对复苏后无ST段抬高的患者，COACT（2019）和TOMAHAWK（2021）试验发现，与延迟或选择性造影相比，立即常规造影没有生存获益。

**神经功能预后评估**有意放慢进行。头几天的临床检查会受到镇静药、神经肌肉阻滞剂、低体温和器官衰竭的干扰，而过早的悲观预测一旦导致撤除治疗，就会自我应验。ERC–ESICM的方法把检查（瞳孔和角膜反射、运动反应）、神经电生理（脑电图模式和体感诱发电位，其中双侧N20反应消失预示不良结局）、血液生物标志物（如神经元特异性烯醇化酶）以及脑影像结合起来。只有当两项或更多结果一致时，才预测不良结局。存活者常有疲劳、认知问题、焦虑和情绪低落，应为他们提供随访和康复；他们的家人也需要支持。

::: example ROSC后的患者 {#ex-postrosc}
一名70岁女性在院内骤停15分钟后恢复自主循环（首个心律为PEA，病因考虑为气管切开导管堵塞导致缺氧，现已更换）。她接受机械通气。观察指标：FiO₂ 1.0下SpO₂ 100%，PaO₂ 48 kPa，PaCO₂ 3.2 kPa，血压84/46 mmHg（平均59），体温36.4 °C，血糖14 mmol/L。12导联心电图为窦性心动过速，无ST段抬高。哪些数值偏离目标？应作哪些调整？
::: solution
将每项数值与[[#def-postcare]]中的复苏后目标比较：

- **氧**：FiO₂ 1.0下PaO₂ 48 kPa远高于正常。降低FiO₂，使SpO₂维持在94–98%。
- **二氧化碳**：PaCO₂ 3.2 kPa偏低（过度通气），会使脑血管收缩。降低分钟通气量，使PaCO₂回到正常范围。
- **血压**：平均动脉压59 mmHg低于约65。如果她可能对液体有反应，给予补液冲击，并开始使用去甲肾上腺素等血管加压药；超声心动图有助于区分心肌顿抑与低血容量。
- **体温**：36.4 °C可以接受；目标是在接下来72小时内预防发热。
- **血糖**：14 mmol/L偏高，应按本科室流程处理，同时避免低血糖。

这次骤停是缺氧性的，不是冠状动脉性的，也没有ST段抬高，因此没有急诊造影指征。至少72小时内不对预后作定论性讨论。
:::
:::

## 关于复苏的决策 {#sec-decisions}

心肺复苏是一种医疗措施。对于大多数在进行性疾病终末期死亡的人来说，它无法让心脏恢复跳动并维持有意义的时间，反而使他们承受有失尊严、往往痛苦的死亡。在英国，不尝试心肺复苏的决定（**DNACPR**决定）由负责的高年资临床医生提前作出，最好作为更全面计划的一部分，记录患者想要和不想要哪些治疗。许多地区为此使用**ReSPECT**程序（Recommended Summary Plan for Emergency Care and Treatment，急救与治疗建议摘要计划）。

有几条原则已经确立。DNACPR决定只适用于心肺复苏，并不意味着停止其他治疗，如抗生素、补液或入院治疗。患者应当参与决定，除非这样做会对其造成身体或心理伤害：在**Tracey v Cambridge University Hospitals**案（2014）中，上诉法院认定，未让患者参与决定侵犯了她根据《欧洲人权公约》第8条享有的私人生活受尊重的权利。如果患者缺乏决策能力，应征询其亲近之人的意见，但临床医生没有义务提供不会奏效的心肺复苏。决定必须记录在紧急情况下能找到的地方，并在情况变化时复审。相关法律和伦理见[[medical-ethics-law/end-of-life-ethics]]。

终止复苏是高年资医生依据整体情况作出的决定：无心肺复苏的时间、首个心律、对治疗的反应、呼气末二氧化碳的趋势、尚待处理的可逆病因，以及对患者已知的情况。长时间ALS后呼气末二氧化碳偏低与不良结局相关，但不单独据此决定。许多急救服务现在允许亲属在复苏期间按其意愿在场，并安排一名工作人员陪伴支持；关于家属在场的研究没有显示其对复苏有害，并提示对亲属有一定益处。

::: example 养老院的呼叫 {#ex-notrial}
一名91岁女性患有晚期痴呆和严重心力衰竭，近三个月内住院两次。早餐时养老院工作人员发现她无反应、没有呼吸。工作人员拨打999并开始按压。找不到任何复苏计划。她的女儿在国外。四分钟后急救人员到达；监护仪显示心脏停搏。他们应依据什么作出决定？
::: solution
在没有有效的DNACPR决定或预先决定的情况下，默认做法是开始复苏，养老院工作人员开始按压是正确的。但临床人员没有义务继续不可能成功的心肺复苏。急救人员的指南允许他们在复苏属徒劳时停止，需考虑的因素包括：无目击的骤停、心脏停搏，以及预计会导致死亡的晚期不可逆疾病。在可行时尽快给女儿打一个简短而坦诚的电话，说明发生了什么。

更大的失误发生在更早之前。一位患有晚期痴呆和终末期心力衰竭、近期两次住院的人，本应在她还能参与时与她及其家人讨论紧急救治计划。从事件中吸取教训应留到第二天的复盘，而不是在现场。如果在下一次出院时用ReSPECT表格记录下计划，所有人——包括她本人——都可以免于这样的结局。
:::
:::

::: example 跌倒后的缓慢脉搏 {#ex-ppi-arrest}
一名79岁男性在毫无先兆的晕倒后被送来。脉搏每分钟32次，血压78/40 mmHg，面色苍白、出汗。心电图显示伴宽QRS的完全性心脏阻滞。他服用比索洛尔（bisoprolol）和雷米普利（ramipril）；血钾5.2 mmol/L。应如何处理？
::: solution
他是伴不良特征（休克和晕厥）的心动过缓，因此立即开始治疗。

1. ABCDE评估，如有低氧血症则给氧，建立静脉通路，持续监护并贴上可起搏的除颤电极片。
2. **阿托品500微克静脉注射**，可重复至3 mg。阿托品对伴宽QRS的完全性心脏阻滞往往效果不大，因为阻滞部位在房室结以下。
3. 他有心脏停搏的高风险（伴宽QRS的完全性心脏阻滞），因此安排**经静脉起搏**。过渡期间可开始异丙肾上腺素或肾上腺素输注，或在镇痛镇静下行**经皮起搏**。
4. 寻找可逆的促发因素：停用β受体阻滞剂；血钾仅轻度升高；用心电图和肌钙蛋白排除心肌梗死（尤其是下壁）。

如果β受体阻滞剂作用消退后他仍为完全性心脏阻滞，则有植入永久起搏器的指征。
:::
:::

::: history
1960年，约翰斯·霍普金斯大学的William Kouwenhoven、James Jude和Guy Knickerbocker描述了闭式胸外心脏按压；此前Knickerbocker注意到，把除颤电极板用力压在狗的胸壁上会使其动脉压升高。它与20世纪50年代后期Peter Safar和James Elam倡导的口对口通气相结合，成为心肺复苏。早在1947年，Claude Beck已在暴露的心脏上进行除颤；20世纪60年代初，Bernard Lown研制了直流电除颤器和用于电复律的同步电击。1966年，贝尔法斯特的Frank Pantridge和John Geddes把便携式除颤器装上救护车，建立了第一个移动冠心病监护单元，证明除颤可以送到患者身边。成立于1992年的国际复苏联络委员会（ILCOR）如今负责审阅证据，各国指南（包括英国复苏委员会的指南）均以此为基础。
:::

## 后续内容

休克和液体复苏的生理见[[emergency-critical-care/shock-fluids]]；气道管理和通气见[[emergency-critical-care/airway-ventilation]]；ROSC后的器官支持见[[emergency-critical-care/critical-care]]；心律失常本身见[[cardiovascular/arrhythmias]]；应在骤停前发现病情恶化的评估方法见[[emergency-critical-care/acute-assessment]]。

::: summary
- 心脏骤停依据无反应和没有正常呼吸来识别。心律分为可电击（VF、pVT）和不可电击（PEA、心脏停搏）。
- 按压产生的冠状动脉灌注压建立缓慢，一停止就崩溃：深度5–6 cm，频率每分钟100–120次，充分回弹，尽量减少停顿。
- RCUK ALS（2021，2025年给药时机未变）：可电击心律在第三次电击后给予肾上腺素1 mg和胺碘酮300 mg，此后每3–5分钟给肾上腺素，第五次电击后给胺碘酮150 mg；不可电击心律尽早给予肾上腺素1 mg，此后每3–5分钟一次。
- 每次骤停都要寻找4H和4T；某些病因（低体温、妊娠、肺栓塞、创伤）会改变流程。
- 围骤停期心律的处理先问有无不良特征：休克、晕厥、心肌缺血、心力衰竭。
- ROSC后：SpO₂ 94–98%，PaCO₂正常，平均动脉压高于约65 mmHg，ST段抬高者行冠状动脉造影，预防发热72小时，72小时前不作预后判断，且只依据多项一致的检查。
- 不尝试心肺复苏的决定应提前作出、让患者参与、只适用于心肺复苏，并记录在能被找到的地方。
:::

## 习题

::: exercise 按压比例 {level=1 check="0.84"}
在一次10分钟的复苏中，没有按压的时间（心律检查、电击、放置气道）合计96秒。胸外按压比例是多少？以小数表示，保留两位小数。
::: hint
按压比例等于有按压的时间除以总时间。
:::
::: solution
总时间600秒；有按压的时间为$600 - 96 = 504$秒。按压比例为$504/600 = 0.84$，达到了通常高于0.8的目标。
:::
:::

::: exercise 冠状动脉灌注压 {level=1 check="18"}
心肺复苏期间，动脉导管显示主动脉舒张期（放松期）压力为30 mmHg，同一时刻中心静脉导管显示右心房压为12 mmHg。计算冠状动脉灌注压（mmHg）。
::: solution
按[[#eq-cpp]]，$\text{CPP} = 30 - 12 = 18$ mmHg。这刚刚高于人体研究中很少能实现ROSC的水平（约15 mmHg）；更深的按压加上充分回弹的目标就是把它提高。
:::
:::

::: exercise 胺碘酮总量 {level=1 check="450"}
一名成人在六次电击期间始终为室颤，完全按照RCUK流程处理。到第六次电击时，共给予了多少胺碘酮（mg）？
::: solution
第三次电击后给予胺碘酮300 mg，第五次电击后给予150 mg：$300 + 150 = 450$ mg。流程在第五次电击后不再追加胺碘酮。
:::
:::

::: exercise 计算肾上腺素剂数 {level=2 check="3"}
在一次可电击骤停中，两分钟循环完全准确，第一次电击在第0分钟，心律一直为室颤。肾上腺素在第三次电击后给予，此后每隔一个循环一次。到第14分钟心律检查时共给了几剂肾上腺素（第14分钟才给的一剂不计入）？
::: solution
电击发生在第0、2、4、6、8、10、12和14分钟。第一剂肾上腺素在第4分钟第三次电击后给予，之后每隔一个循环，在第8和第12分钟各一剂。下一剂应在第16分钟。因此在第14分钟检查前共给了**3**剂。
:::
:::

::: exercise 可电击还是不可电击 {level=1}
对下列每种情况，说明心律是否可电击以及首先给予的药物：(a) 第一次电击后仍持续的室颤；(b) 心率每分钟60次的窄QRS节律PEA；(c) 核心体温27 °C的低体温患者出现心脏停搏。
::: solution
(a) 可电击。第三次电击之前不给药，第三次电击后给予肾上腺素1 mg和胺碘酮300 mg。
(b) 不可电击。一旦建立通路即给予肾上腺素1 mg，并积极寻找病因，如低血容量、心脏压塞或肺栓塞，它们常导致窄QRS的PEA。
(c) 不可电击。体温低于30 °C时暂停肾上腺素，直到患者复温到30 °C；重点是心肺复苏和复温，最好是体外复温。
:::
:::

::: exercise 有线索的PEA骤停 {level=2}
一名67岁男性在髋关节置换术后第5天突发呼吸困难，随后倒地。监护仪显示每分钟120次的窄QRS节律，无脉搏。在一次心律检查期间的床旁超声显示右心室扩大，左心室小而收缩有力，无心包积液。最可能的病因是什么？特定治疗是什么？它如何改变复苏？
::: solution
骨科手术后突发呼吸困难，继而出现伴右心室扩大的PEA，提示**大面积肺栓塞**（4T之一）。特定治疗是在心肺复苏期间**溶栓**（有条件时，外科或导管取栓是替代方案）。由于溶栓药需要时间起效，给药后应继续心肺复苏60–90分钟，才可判定复苏失败。近期手术增加出血风险，但在肺栓塞所致的心脏骤停中，不溶栓的死亡风险超过了出血风险。
:::
:::

::: exercise 解读ROSC后的救治 {level=2}
一名55岁男性院外室颤骤停后恢复自主循环，两小时后在ICU接受镇静和机械通气。他的体温为38.3 °C。一位亲属问他是否会醒来。你如何处理体温？如何回答这个问题？
::: solution
38.3 °C高于37.7 °C的阈值，而心脏骤停后发热与更差的神经功能结局相关。ICU会积极处理（退热药、体表或血管内温度控制），并持续预防发热至少72小时。

对亲属：现在知道还为时过早。镇静药和骤停本身的影响使至少72小时内的检查都不可靠，之后团队会联合使用多项检查（体格检查、脑电图、血液检查和影像）再形成判断。诚实地说明不确定性，同时给出计划和下一次谈话的时间，是正确的回答。
:::
:::

::: exercise DNACPR决定 {level=3}
一名76岁女性患转移性肺癌，现已卧床、大部分时间在睡眠，因肺炎入院。她有决策能力。专科住院医师认为心肺复苏不会成功。描述应如何作出并记录这一决定，并说明它会改变和不会改变她的哪些治疗。
::: solution
这一决定是关于心肺复苏不会成功的临床判断，由负责的高年资临床医生作出。由于她有决策能力，应当告知她并请她参与讨论，除非有充分理由相信谈话本身会对她造成身体或心理伤害（Tracey案，2014）。谈话最好围绕对她重要的事以及哪些治疗有帮助、哪些没有帮助来展开，而不是请求她允许不给予一项徒劳的干预。经她同意，可以让家人参与。

决定记录在医院的表格（或ReSPECT计划）上和病历中，传达给团队，出院时告知她的全科医生和社区服务。它只适用于心肺复苏：她仍可接受抗生素、氧疗、补液、症状控制，并在适当时升级到其他治疗。如果她的病情或意愿发生变化，决定应予复审。
:::
:::

::: exercise 另有隐情的心动过缓 {level=3}
一名81岁女性服用地高辛（digoxin）、呋塞米（furosemide）和雷米普利，因意识模糊和呕吐被送来。心率每分钟38次（交界性心律），血压86/50 mmHg，血钾6.4 mmol/L，肌酐较基线升高。讨论她心动过缓的鉴别诊断，以及处理与标准心动过缓流程有何不同。
::: solution
这种心动过缓有不良特征（休克），但其可能原因是**地高辛中毒**（呕吐、意识模糊、交界性心律），由**急性肾损伤**减少地高辛排泄所诱发；以及**高钾血症**，它既反映地高辛中毒，又加重传导障碍。还应排除心肌缺血。

处理仍从ABCDE开始，使用阿托品也是合理的，但特异性治疗更为重要。**地高辛特异性抗体片段**可逆转地高辛中毒，在此情况下适用于危及生命的心律失常或明显的高钾血症。高钾血症按常规用胰岛素加葡萄糖处理；在地高辛中毒时使用钙剂历来存在争议，应遵循当地毒理学建议（在英国为TOXBASE或国家毒物信息服务）。停用地高辛和雷米普利，补液治疗肾损伤，起搏仅用于无效的心动过缓。总的教训是：在伸手去拿起搏导线之前，先问一问心脏为什么慢。
:::
