复苏是最后五分钟的应用科学：循环骤停的生理学、在病因被逆转之前买时间的序列、以正确剂量在正确心律到达的医学、及关于何时开始——及何时停止——对患者有利的判断。**本章讲述骤停本身（心律及其机制、作为手法给药的高质量CPR、ALS算法与可逆病因、及低温与溺水与妊娠及毒物的特殊情形）、算法真正为之下设的骤停前后状态（不稳定心动过缓与快速性心律失常及其实是停搏的晕厥）、复苏后阶段（冠脉造影之问、体温管理、必须等待的预后判断）、及CPR周围的决定（照护天花板与复苏计划谈话、终止抢救规则、及系统——从调度员辅助单纯按压CPR到公共除颤器到体外复苏）。其文化是团队文化：算法容易而表现不容易、这就是为何现代课程既是人因培训也是药理学。**

## 骤停

::: definition 心脏骤停：机制、算法与可逆病因 {#def-arrest}
**机制：有效循环停止（缺血心肌电风暴的心室颤动与无脉室速——这是多数目击的成人骤停、也是除颤器修复的那一种、及空心心脏与耗尽心肌及下述病变的心脏停搏与无脉电活动——它们是迟到到达与非心脏病因的骤停心律），而整个学科就是流量欠账的算术（大脑的分钟、心肌与肾的小时、CPR产生的流量替代正常流量的一小部分——这就是为何按压是一种有剂量的药：深度与频率与充分回弹及最少中断各带试验与登记来源的死亡效应、及使机械装置成为有趣辅助而非替代的身心疲劳曲线、及每个团队演练的120次每分与5-6 cm及“别离开患者”文化）。ALS算法作为两分支决策树：可电击（尽早除颤伴双相150-200J或递增方案、及按复苏委员会方案在电击之间给肾上腺素与第三次电击后给胺碘酮、及用于难治性室颤的双序贯除颤——2020年代进行中的试验——及“电击周围最少停顿”纪律）与不可电击（尽早肾上腺素作为区分因子、及每两分钟复查心律——也是心电图判读窗口、因为被误读为停搏的细颤室颤就是一些死亡翻转的那次纠正）——一切由带具名角色的团队对表运行（领导而非按压者、计时与记录者、气道、通路、除颤、及来自机组资源管理文献的可测量改善心智单独会忘之事物的闭环沟通与明确暂停及“谁在何时前做什么”）。在按压期间追查可逆病因、因为没有H与T的算法只是节拍器（低氧与低高钾与低温及氢离子酸中毒与低血糖与低血容量及张力性气胸与填塞及血栓冠脉与肺及表格毒物摄入：各带其CPR期间的床旁诊断——血气与钾与超声看心脏与肺与容量及管道史及救护车的院前12导联——是保存在停搏中的证据、及“高钾或低血钙就给钙——高钾症是治愈最快的骤停病因”的肾单位文化）及各带其翻转复苏（高钾的ROSC后透析或持续肾替代、针减压与胸管、心包穿刺、大块肺栓塞骤停的溶栓或取栓伴“溶栓后CPR更久”打破团队终止习惯的规则、及出血骤停的液体与血）。特殊情形重写规则：低温（“不暖死不罢休”及ECLS复温转运决定及30度以下不治疗的室性心律失常及甲状腺素与肾上腺及脓毒症及药物贡献）、溺水（通气优先的CPR与不必执着的颈椎及即使在冰水中一小时后仍换来神经恢复的冲浪与溺水时间）、孕妇（左手子宫左移与五分钟时的死亡期剖宫产——是最快的双患者产科操作、最令人畏惧也最反复演练、及对胎儿的除颤安全——不是问题）、毒物（局麻药与亲脂药物中毒的脂肪乳及三环类QRS的碳酸氢钠及中毒章的特效解毒剂）、及依赖起搏与装置患者（起搏器与ICD查询及ICD上放磁铁停止治疗及电极避开装置的体外贴片、及“ICD是在向导线断裂放电还是向室颤放电”鉴别——由电击日志诊断）。以及ROSC：骤停后综合征是其自身的复苏阶段再灌注损伤与心肌顿抑的骤停后综合征及血管加压药与通气策略以正常氧正常二氧化碳及避免低血压为目标——因为动脉压就是脑灌注压、及冠脉造影直接进STEMI阳性或按2020年代COCA与TOMAHAWK时代细微对选定的非STEMI在血流动力学稳定下进导管室、及在重症监护章覆盖而不在第六小时——那时还没人能告诉你。**

## 骤停前后

::: definition 骤停前后状态、尝试的决定与系统 {#def-peri}
**算法为其存在的骤停前后医学：不稳定心动过缓（阿托品不适用于完全心脏阻滞伴宽QRS或移植心脏邻近的诚实极限及起搏选择——肾上腺素或多巴胺输注作为桥梁及经电话建议、因为症状性2:1或三度阻滞伴晕厥是住院与起搏计划、不是门诊复查——及需要自身治疗而不是起搏的高钾与低温及药物过量心动过缓、及“垂死者的心动过缓通常是保护性的、不是问题”的照护天花板条款——它防止了对心脏作为死亡一部分而停止的人阿托品然后起搏然后肾上腺素的升级）。不稳定快速性心律失常（不稳定者的同步复律伴镇静绝不为完美空腹条件延迟、及能量与贴片位置与同步模式核查表——这是抢救车胜任力中最常演练也最常手抖的操作、特发性对退化的规则宽或窄室上性心动过速的腺苷、及稳定室速的胺碘酮——随后需要缺血与结构工作检查作为住院而不是带信出院、及预激陷阱：任何给维拉帕米或地高辛或腺苷就会杀人的WPW伴房颤、及“年轻人宽规则快速想旁路”纪律——在每个毒理与心律失常安全清单上）。曾是停搏或风暴的晕厥（心脏停搏警报与颈动脉窦及固有传导病及致心律失常右室心肌病与长QT与Brugada及CPVT背景——心脏与老年章覆盖、及“劳力性或卧位或反复伴家族史”的立即住院旗）。尝试CPR的决定：生理与价值观的医学判断伦理，不是对一张表的行否（复苏委员会与总医学会及各皇家学院时代的声明及TM与Winston-Paterson邻近案例后的英国法时代关于同意与CPR及人工营养补水、及ReSPECT与照护升级计划记录——它们把默认复苏与永不尝试的辩论终结为一门程序医学：一项建议、尽可能与患者或家属讨论、记录、在危机时刻可获得、可重议、及关于患者对不被抢救之同意的医患法律辩论仍未均匀落定）；终止复苏规则（ALS与BLS停止标准一并应用不挑拣——未疑可逆病因、无可电击心律、无目击无旁观者CPR的“无流量”间隔、及训练有素的眼睛在监测环境下见证并持续CPR的骤停、及谦逊的经验规则：决定由复苏负责人做出而团队的道德困扰得到复盘、因为人因研究显示“我们何时停”是未回答的团队压力与疲劳问题的危机）；及院外心脏骤停周围的系统生存链：调度员辅助电话CPR指导与“外行一律按压”的简单、及公共通道除颤与AED及志愿者应答应用、其瑞典与荷兰及日本登记数据显示当他们在救护车之前到达时真实的生存提升、及“目击倒下先电击”逻辑、及机械CPR与ECPR时代（2020年代的试验与观察数据显示难治可电击骤停在ECMO下可存活、及如今派ECMO团队飞往骤停现场的医院——这是复苏医学正在变成一项物流运动）、及不断出现的不平等数据（若干国家按社区收入与种族的公共骤停生存——旁观者CPR培训与AED布点是带附加条件的公共卫生医学、因为在现场人们惧怕诉讼或警察的社区实时生产无人触碰的遗体）。最后：床旁的家属“家属在场参与复苏”伴具名支持者证据显示无伤害而被感激、许多服务如今实施的标准、及亲属事后才知道他们本可以在场时验尸官对相关论证。**

## 复苏后医学

::: definition 复苏后照护与预后判断 {#def-post}
**ROSC是一种新的危重症（骤停后综合征：带血流动力学波动与血管麻痹及需要同时避免高血压与低血压——低血压就是脑灌注罪——的心肌顿抑（MAP目标文献及其“到某一点越高越好”细微及去甲肾上腺素邻近一线实践）、看起来像脓毒症而照样得到抗生素的缺血再灌注炎症级联、及早喂养及不太低也不要12 mmol/L狂热的血糖、及以正常为目标的通气（2020年代空气对氧及ICU试验时代的过度氧合伤害信号、及落在“避免极端”的高碳酸对正常碳酸试验）、及癫痫检测——因为骤停后非惊厥状态常见而昏迷生存者应常规持续脑电图、因为无论治不治脑电图都改变处理与预后）。体温管理被修正的一章（2013年TTM与2016年TTM2时代把“治疗性低温32-34”转换成“预防发热”在大型阴性试验之后、及2023年TTM3院前预降温的失望、及诚实的当前立场：避免发热、除非是规程演练过的单元否则不要在33度抖几个小时——这是一个值得教授的循证修正故事、因为整份指南被重写、医院停止了演练十年的操作）。冠脉再灌注（STEMI明显的紧急造影、及COCA与TOMAHAWK及EMERGE及FOAM邻近时代回答“昏迷非STEMI的ROSC常规立即造影平均无帮助”、而被试验排除而被导管室纳入的心源性休克与电不稳定患者——这些都是试验运作的方式、及存在ECPR路径处保持决定并行而专业）。神经预后判断作为专科最难的时钟多模式而必须等待的规则：临床检查延至镇静与肌松与复温之后伴瞳孔与角膜及肌阵挛状态、及“不早于ROSC后72小时且正常体温且无镇静混淆”的底线、各指南编码它因为早期检查是错误而自我实现的、及带各自特异度的辅助模态（神经元特异性烯醇化酶趋势及其检测变异警诫与S100B、及双侧缺失N20与肌阵挛状态及弥散MRI皮层受限级联及脑电图背景反应性、及GCS运动1分3天时代——绝不单用因为错误就是单一检查）。撤除生命支持流程（英国与欧洲的并行咨询模型不是单一医师决定、及“我们一边继续一切一边查明”的对家属桥梁句、及器官捐献桥梁——捐献之问绝不能在同一个家属耳中与预后判断之问赛跑、及撤除后循环死亡捐献流程——医院已学会以连续的尊严两者兼顾、这是伦理章的分析与本章的清单）。及指南才刚追上的生存者医学活着者的骤停后综合征：认知与疲劳与焦虑与创伤后应激及就业与驾驶咨询及ICU获得性无力及心脏康复及心律失常基质的ICD、及家庭的第二诊断、及“为何是我又为何不是我”随访门诊——这是本章写出的唯一圆满结局。**

健身房目击室颤骤停CPR 45分钟；七次电击、肾上腺素4次、已给胺碘酮；仍是室颤；团队疲惫、急救员说“再来一个”、新医师想停止因为“已经一小时了”。

::: example 养老院呼叫的“直线” {#ex-notrial}

在浴室地板被发现、呼吸4而鼾声、血氧84%、瞳孔针尖样、GCS 6、脉搏62、温暖；伴侣说“她在走上次的强效止痛药，也许还有安眠药”。
::: solution
**仍是呼吸性骤停的骤停（[[#def-arrest]]、[[emergency-critical-care/poisoning]]、[[geriatrics-palliative/delirium-dementia-care]]）：ABC现实——低氧心动过缓无反应而有脉搏的成人是一个气道与呼吸问题、要在它变成骤停问题之前治疗：带阿片毒理综合征在口袋前方的球囊面罩通气（针尖瞳孔与呼吸抑制及肠鸣音减少与病史）、按通气不是按清醒滴定的纳洛酮（小剂量重复、因为阿片依赖者的0.4 mg冲击产生疼痛与呕吐与误吸及戒断风暴而击败自身目的、及长效与缓释制剂的输注或重复剂量决定——其吸收因伴侣的“也许是安眠药”而不可预测）、及共服药物的现实（加深昏迷的苯二氮䓬或酒精或加巴喷丁类——氟马西尼绝不能碰因为混合与依赖患者的癫痫风险、这是中毒章规则在床旁的重述）；初级评估其余——血糖已做、头颅损伤与低体温与脓毒症及卒中模拟搜寻（瞳孔不是一切——脑桥与有机磷及可乐定与镇静催眠鉴别）、心电图（QT与钠通道阻滞共服药物）、及对乙酰氨基酚与水杨酸浓度在每个不确定的摄入中被要求即使在深夜、因为肝脏不在第二天报告自己的背叛；及处置——ICU或高级依赖单元通气与否取决于气道保护轨迹、伴简报“她来时不呼吸”在每次交接被理解、及精神健康与依赖支持及带回家纳洛酮及邻近戒毒服务转诊——这是这位患者明年唯一需要的CPR。**

::: exercise 处理骤停中的ICD患者 {level=2}
55岁双腔ICD患者在候诊室倒下；监护示室颤；装置每90秒可闻及电击；AED已体外给予两次电击。围绕装置安排ALS并陈述磁铁的作用。
::: solution
**带着植入心脏转复除颤器的CPR（[[#def-peri]]、[[cardiovascular/arrhythmias]]）：顺序——装置是盟友不是障碍：继续ALS并把贴片避开发生器（前后位是经典）、按建议时正常电击（装置电击与外除颤彼此不会使除颤不安全——治心律不是治硬件）、并把磁铁放在手边：ICD上的磁铁暂停进一步快速性心律失常检测与治疗（在现代装置中它不重排起搏模式也不停止心动过缓起搏），在装置电击能量不恰当时有用（向灌注心律放电的室上速或肌电位或导线断裂过度感知）、而若在真正的室颤期间你的装置正在你的电击之间正确地试图救她则是有害的——可闻电击对监护心律的相关性是告诉你处于哪种情形的床旁试验；ROSC后——装置作为最好见证者被查询（存储的心内电图给出骤停前心律与起始——尖端扭转型对缺血对装置失败对导线断裂的诊断及QT与兴奋剂史及电击恰当性之问）、及磁铁使用暴露依赖的起搏依赖患者（备用起搏与把起搏程控仪带到床旁的文化）、及若感染是病因则囊袋与无菌移除记录、及出院小结中ICD门诊与心内科共享的随访——因为装置比任何见证者都更了解这位患者的骤停、而它应当在正确的时刻作证、不是在抢救呼叫时。**

::: exercise 管理ROSC后一小时 {level=2}

## 通向何处

心律失常基质在[[cardiovascular/arrhythmias]]与[[cardiovascular/electrophysiology-ecg]]、休克状态在[[emergency-critical-care/shock-fluids]]、插管中与插管后的气道在[[emergency-critical-care/airway-ventilation]]、毒理综合征在[[emergency-critical-care/poisoning]]、及骤停后ICU与预后判断细节在[[emergency-critical-care/critical-care]]。

::: history
**复苏的历史始于医学决定：停止的心脏与停滞的呼吸是有机械补救的机械问题。十八世纪的”“貌似溺亡者复苏协会”“——荷兰与人道机构在北欧推广口对口、风箱与保暖的运动——是第一批公共复苏教育、完整带着产生安全棺材与警铃的活埋焦虑。现代三位一体以三次跳跃到来。1960年Kouwenhoven与Jude及Knickerbocker在约翰霍普金斯报告闭式胸外按压、十年之内CPR从手术室扩散到急救手册。除颤器的弧线从1899年电可以使心脏陷入颤动的观察、经过1947年Beck对开心脏的直接电击、1956年Zoll的体外装置与1960年代初Lown的同步复律、到西雅图与贝尔法斯特的流行病学：Pantridge的工作显示多数院前死亡是心室颤动、而入院前除颤救命——这个论证创造了急救员除颤器、后来又有公众通道除颤。第三次跳跃是组织：1960-70年代首批国家CPR标准、使各国收敛到同一滴答规程的国际联络委员会时代、及复苏登记系统（CARES、EuReCa及瑞典与挪威与英国登记）——其公开报告比多数药物更移动了生存曲线。院外系统随后成为一个比较科学领域：哥本哈根与休斯顿与菲尼克斯及西雅图就急救模型竞争；调度员辅助单纯按压CPR改变了急救电话听起来的样子；及2010-2020年代体外复苏试验（ARREST与INCEPTION及ECMO运输队列及CIRCUS时代争议）把难治性骤停变成转运医学。体温管理提供了教科书的谦逊课：33度预防性降温是指南教条直到TTM2试验发现对比预防发热无优势、而医院停止了演练十年的操作。在技术历史之下流淌着伦理历史：一旦CPR常常有效到要紧、医学就必须决定何时不用它——1975年“不复苏”医嘱的正式化、1980年代无效医疗辩论、总统委员会及Cruzan之后的自决法、及英国从“永不尝试”惯例经由TM与Winston-Paterson判决到ReSPECT记录的漫长路径——残障权利对生活质量终止规则的异议仍在记录上。复苏最大的发现终究是一双手、一次电击、一通电话、一份登记、以及停止的纪律——而其中每一项都必须被发现、被辩护、被演练。** — [[cardiovascular/arrhythmias]]、[[medical-ethics-law/end-of-life-ethics]]、[[public-health/health-systems-economics]]。**
:::

::: summary
- 心脏骤停是流量欠账：高质量CPR（深度、频率、充分回弹、最少停顿）是一个有剂量的干预、而可电击骤停的存活在除颤前逐分钟衰减。
- 用具名角色跑算法并并行追查可逆病因；H与T就是鉴别、而若干项有胜过肾上腺素的床旁诊断与治愈。
- 骤停前后医学就是预防：不稳定心动过速得到同步复律、伴晕厥的阻滞得到住院与起搏计划、而预激房颤绝不可遇到房室结阻滞剂。
- 终止复苏决定遵循议定标准加临床判断、由具名高年资者做出并简报团队；无效医疗是一个建议流程、不是反射或经验法则。
- ROSC开始一种新的危重症：避免低压与高压、正常氧与正常碳酸、有指征时造影、预防发热、及只在72小时正常体温无镇静之后多模式神经预后判断。
- 生存链是公共卫生：调度指导、旁观者CPR、人们所在之处的除颤器、及公平的布点在药物到达之前很久就决定了多数骤停。
:::

## 练习

::: exercise 跑这个心律 {level=1}
AED/监护示粗室颤；旁观者CPR持续；你有双相贴片除颤器与一位同事。安排前四分钟。
::: solution
**四分钟的ALS（[[#def-arrest]]）：顺序——确认并按压不停直到贴片贴好（最少停顿文化：只每两分钟查心律）、若装置允许先充电再停、同步模式关闭、清场并电击150-200J或递增、立即恢复按压两分钟且电击后不查心律（电击后机电停顿谬误会浪费40秒）、两分钟时第二次电击然后肾上腺素1mg、第三次后胺碘酮300mg按规程、及第二分钟起大声列出可逆病因清单（钾与低氧与创伤及血栓筛查、及如果存在的院前12导联）；团队——一个手不按压的领导、闭环（“电击已给、恢复按压于110、时间04:12”）、及第三分钟前“谁管气道谁管通路”、因为插管决定可以等而灌注不能、及早考虑骨内通路作为第二条给药路径——花在静脉上的分钟就是没花在大脑上的分钟。**

::: exercise 转复不稳定者 {level=2}
34岁心悸患者头晕、心率210、规则宽QRS、血压82/50；清醒而焦虑。写出接下来五分钟、你不会给的药、及若她有WPW的陷阱。
::: solution
**不稳定宽QRS心动过速（[[#def-peri]]、[[cardiovascular/arrhythmias]]）：五分钟——呼援并具名呼叫麻醉、监测同步模式在每次动作后再查（R波上的同步标记否则你就是意外除颤、贴片已贴且尽可能前后位）、不是空腹审计的镇静（丙泊酚或依托咪酯小滴定伴头部旁留置针与球囊——因为有镇静的这次复律更好、而五秒的意识丧失让人忘了在她还能听见时简短问一句同意的话）、电击（典型150-200J双相同步递增方案）、之后立即心电图、及为什么34岁会有这个的住院工作检查（结构与缺血及通道病及电解质与兴奋剂工作检查——因为复律是诊断的开始不是结束）；不给的药——维拉帕米与地尔硫䓬进入未分化的宽QRS心动过速是一种死亡模式（预激房颤与被误称的伴低血压室上速）；及WPW陷阱——若心律不规则而极快且宽（预激房颤）、胺碘酮与腺苷及所有房室结阻滞剂都是错的（旁路是前向肢）而同步复律是安全的答案、这就是除颤器要在药房之前的原因。**

::: exercise 给阻滞起搏 {level=2}
72岁因晕厥就诊；心电图：间断三度房室阻滞、心室率34、低血压、因“心悸”服比索洛尔与地高辛；服雷米普利的心衰患者钾6.9。处理顺序是什么、什么绝不可假定？
::: solution
**多重用药晕厥的一课（[[#def-peri]]、[[cardiovascular/arrhythmias]]、[[renal/potassium-calcium-phosphate]]）：顺序——第一别继续制造问题（停比索洛尔与地高辛与雷米普利并记录为已停）、第二把可逆病因当作真正的心律失常治疗（高钾伴心电图变化的膜稳定用葡萄糖酸钙——数分钟起效、然后胰岛素加葡萄糖、及在这个肾与地高辛背景下考虑透析伴地高辛浓度与地高辛抗体片段、因为高钾加地高辛中毒是一个双头心动过缓、而肝功与肾功及容量与尿量及心电图演变决定解毒剂对起搏对透析的顺序）、第三桥梁（阿托品对此机制可能无效——肾上腺素或多巴胺输注或临时起搏、经静脉通路时机对照钾轨迹、及即使不适也立即贴体外起搏贴片、因为她是“可能因一次停搏而骤停”的表型）；及不可假定——药物是贡献者、但72岁晕厥伴高度阻滞在电解质与药物纠正之后需要传导病工作检查与永久起搏决定（“只是β阻滞剂”的出院就是这位患者带着起搏器和淤青回来或者不回来的原因）；及给全科信的药物审查课：老年心衰患者的比索洛尔-地高辛-雷米普利三联是一张房室阻滞与高钾及跌倒处方、这是多重用药章在这位女士骤停中的章节。**

::: exercise 写你单位的心脏骤停政策 {level=3}
为900床教学医院设计全院复苏与恶化政策：培训、设备、应答结构、照护天花板记录、公平、及包含道德困扰的测量。
::: solution
**作为系统的复苏（[[#def-arrest]]、[[#def-peri]]、[[clinical-skills/patient-safety]]）：培训与胜任力——按风险配比的课程（每位临床医师每年ALS或BLS伴动手时间、及在真实走廊做原位抢救呼叫的基于模拟的团队培训、因为原位模拟文献显示团队行为在骤停发生的房间里改变、不是在技能实验室、及给观察到的按压分数计分的模拟抢救审计）；设备——全院标准化的抢救车伴每月核查及绘制并测试的注射器与除颤器位置、因为“车在哪里”的分钟是可测量的、及ICU与病房贴片及回路适用性和成人儿科切换文化（错误钥匙与错误能量事件是经典的潜在错误发现）；应答结构——一个骤停号码一个算法一套角色、每个预期骤停有重症或麻醉高年资在场或电话、及写下来而非盼望的机械CPR与ECMO转运协议、及24小时心电图判读与超声通道、把“要不要按”的决策变成证据；照护天花板层——单一全院治疗与建议记录（ReSPECT邻近模型）伴对被旗标群体的强制完成（衰弱老年与晚期器官衰竭及痴呆入院在入院审查时而不是在骤停时做“你们会尝试CPR吗、为何”的记录）、及内建入院流程的预嘱登记核查、及随患者在养老机构与信托之间流动且人人都在升级计划——是没人资助而每个验尸官都会问的数据整合项目；公平与道德困扰测量——按年龄与衰弱及族裔及残障及是否住在机构报告的CPR尝试与存活及未尝试率、因为未尝试决定文献与残障权利批评值得一个仪表板不是辩论、及骤停后有行动阈值的员工复盘与困扰调查、因为报告零道德困扰的医院不是安全的医院、而是沉默的医院。使一切保持诚实的年度报告条目：“去年在尝试CPR后死亡的患者中、多少人在六个月前有记录的、讨论过的复苏计划”——因为政策真正的交付物不是更好的骤停、而是更少的骤停。**
