严重过敏反应可以让一个健康人在吃下一颗坚果、被黄蜂蜇伤或接受一剂抗生素后数分钟内发生心脏骤停。它也是最可治疗的急症之一：尽早一次肌内注射肾上腺素，就能逆转大多数反应。严重过敏反应的死亡大多与肾上腺素给药延误、反应期间保持直立体位或未能识别病情有关。本章讲述如何迅速识别严重过敏反应、正确治疗并降低再次发作的风险。

本章介绍发病机制和触发因素、诊断标准和类似严重过敏反应的疾病、按英国复苏委员会（RCUK）2021年指南进行的急救、对治疗无反应的反应的处理、观察、肥大细胞类胰蛋白酶检测和随访、不伴荨麻疹的血管性水肿，以及急性重症哮喘——它与严重过敏反应有许多相同的特征和治疗。文中引用的剂量是英国指南中印出的标准数值，仅供教学；临床实践以现行本地指南为准。

## 发病机制 {#def-mechanism}

::: definition 严重过敏反应 {#def-anaphylaxis}
**严重过敏反应**是一种严重的全身性超敏反应，通常起病迅速，可以致死。重度严重过敏反应的特征是潜在危及生命的**气道**、**呼吸**和/或**循环**受损，可以在没有典型皮肤表现或循环性休克的情况下发生。

大多数反应是**IgE介导**的（变应性）：已致敏的个体有针对触发物的IgE抗体结合在肥大细胞和嗜碱性粒细胞的高亲和力IgE受体（FcεRI）上，再次接触时这些抗体发生交联，引起介质的快速释放。有些反应是**非IgE介导**的，通过直接激活肥大细胞（例如某些药物经MRGPRX2受体）、补体激活或其他途径发生；它们在临床上无法区分，治疗方法相同。
:::

介质解释了临床表现。**组胺**从预先形成的颗粒中在数秒内释放，引起血管扩张、血管通透性增加、瘙痒和平滑肌收缩。**类胰蛋白酶**也是预先形成的，是肥大细胞活化的标志物。新合成的**白三烯**和**前列腺素**引起持久的支气管收缩和血管渗漏，**血小板活化因子**参与低血压，并与反应的严重程度相关。在重度严重过敏反应中，多达三分之一甚至更多的循环血浆可在数分钟内进入组织，同时造成分布性休克和低血容量性休克。

常见触发因素因年龄而异：

- **食物**是儿童和青年最常见的触发因素：花生、树坚果、牛奶、鸡蛋、芝麻、鱼类和贝类。
- **药物**是成人最常见的触发因素，也是英国致死性严重过敏反应最常见的原因：抗生素（尤其是β-内酰胺类）、麻醉中的神经肌肉阻滞剂和氯己定、非甾体抗炎药，以及放射造影剂。
- 黄蜂和蜜蜂蜇伤的**毒液**。
- **特发性**严重过敏反应，即找不到触发因素，此时应检查有无肥大细胞疾病。

辅助因素使反应更易发生或更严重：运动、酒精、非甾体抗炎药、发热、月经和睡眠不足。在**食物依赖-运动诱发严重过敏反应**中，某种食物（典型的是小麦）在静息时可以耐受，但进食后运动就会引起严重过敏反应。致死性食物反应更多见于青少年和青年、哮喘患者（尤其控制不佳者），以及肾上腺素延误给药时。

::: theorem 为什么用肾上腺素治疗 {#thm-adrenaline}
肾上腺素是严重过敏反应唯一的一线药物，因为它能同时对抗反应的所有主要机制：

- **α₁肾上腺素受体**激动引起血管收缩，升高血压并减轻黏膜水肿（包括喉水肿）；
- **β₁**激动增加心率和心肌收缩力；
- **β₂**激动引起支气管扩张，并**减少**肥大细胞**进一步释放介质**。
:::

::: proof
严重过敏反应的致命特征是喉水肿引起的上气道梗阻、支气管痉挛，以及血管扩张和毛细血管渗漏引起的休克。抗组胺药只阻断H₁受体，因此能缓解瘙痒和荨麻疹，但起效慢，对白三烯和PAF驱动的部分以及已形成的支气管痉挛和休克无效。糖皮质激素需要数小时才起效。肾上腺素无论是哪种介质，都能在数分钟内作用于终末器官（血管、支气管、心脏），其β₂作用通过升高肥大细胞内的环磷酸腺苷抑制更多介质的释放。首选肌内注射而非皮下注射，因为肌肉吸收更快、更可靠；也不用静脉推注，因为对仍有循环的患者静脉推注肾上腺素会引起危险的高血压和心律失常。
:::

## 识别 {#def-recognition}

::: definition 严重过敏反应的诊断标准（WAO 2020） {#def-criteria}
世界变态反应组织（2020）的标准规定，满足以下任一条时，严重过敏反应的可能性很大：

1. 疾病**急性起病**（数分钟至数小时），累及**皮肤和/或黏膜**（全身性风团、瘙痒或潮红，嘴唇、舌或悬雍垂肿胀），**并且至少有以下一项**：呼吸受损（呼吸困难、哮鸣、喘鸣、低氧血症）；血压下降或伴有终末器官功能障碍的症状（虚脱、晕厥、失禁）；或严重胃肠道症状（剧烈绞痛样腹痛、反复呕吐），尤其是在接触非食物性变应原之后。
2. 接触该患者已知或高度可能的变应原后（数分钟至数小时）**急性出现低血压、支气管痉挛或喉部受累**，**即使没有典型的皮肤受累**。
:::

RCUK指南以便于快速使用的方式表达了同样的意思：当症状突然出现并迅速进展，出现**危及生命的气道和/或呼吸和/或循环问题**，且通常伴有皮肤和黏膜改变时，很可能是严重过敏反应。A、B、C问题是：

- **气道**：咽喉和舌肿胀，吞咽或呼吸困难，声音嘶哑，喘鸣。
- **呼吸**：呼吸急促，哮鸣，持续咳嗽，因用力而疲乏，缺氧引起的意识模糊，发绀，呼吸停止。
- **循环**：休克征象（苍白、湿冷、心动过速、低血压），头晕，虚脱，意识水平下降，心脏骤停。

多达约五分之一的病例没有皮肤改变，尤其是以循环衰竭为表现时；在深色皮肤者中皮肤改变也可能难以看出，荨麻疹可能隆起却不发红，潮红可能看不见。要仔细检查嘴唇、口腔、眼睛和手掌，并询问患者是否瘙痒。

### 类似疾病

有几种情况可以类似严重过敏反应：

| 情况 | 如何区分 |
|---|---|
| **血管迷走性晕厥** | 苍白、出汗、恶心和**心动过缓**，平卧后迅速恢复；无荨麻疹、哮鸣或血管性水肿 |
| **急性哮喘** | 哮鸣而无皮肤表现、低血压或触发物接触史；但哮喘患者的严重过敏反应可以表现为支气管痉挛 |
| **惊恐发作** | 气促、麻刺感和心动过速，无低血压、低氧血症、哮鸣或荨麻疹（可有潮红） |
| **泛发性荨麻疹或孤立性血管性水肿** | 有皮肤和黏膜表现，但无气道、呼吸或循环受损 |
| **缓激肽介导的血管性水肿**（ACE抑制剂、遗传性血管性水肿） | 肿胀而无荨麻疹或瘙痒；对肾上腺素反应不可靠 |
| **脓毒性休克、鲭鱼中毒、潮红综合征** | 背景不同；鲭鱼中毒是食用变质鱼类后因鱼体内的组胺引起潮红和头痛 |

如有疑问，就给肾上腺素。对没有严重过敏反应的成人肌内注射肾上腺素危害很小；对严重过敏反应患者不给肾上腺素则可能致命。

## 急救 {#def-management}

::: algorithm 严重过敏反应的急救（RCUK 2021） {#def-algorithm}
1. 用ABCDE**识别**严重过敏反应，呼救，尽可能**去除触发物**（停止输注；不要试图挤出蜂刺，把它弹掉）。
2. **体位**：低血压者平卧并抬高双腿；呼吸困难者可坐起（但不要站立或行走）；无意识但有呼吸者取复苏体位。突然站起或坐直可导致致命的心血管崩溃（“空心室”）。
3. 于**大腿前外侧**肌内注射**肾上腺素**（1 mg/mL，即1:1000）：
   - 成人和12岁以上儿童：**500微克（0.5 mL）**；
   - 6–12岁儿童：**300微克（0.3 mL）**；
   - 6个月至6岁儿童：**150微克（0.15 mL）**；
   - 6个月以下婴儿：**100–150微克（0.1–0.15 mL）**。
4. 如A、B或C问题持续，**5分钟后重复肌内注射肾上腺素**。
5. **高流量氧**，监测（脉搏血氧、心电图、血压），建立静脉通路。
6. 有循环问题时**静脉补液冲击**：成人500–1,000 mL晶体液（儿童10 mL/kg）。
7. 如**两剂肌内注射肾上腺素**后A、B或C问题仍持续，按**难治性严重过敏反应**处理。
8. 发生心脏骤停时开始心肺复苏并遵循ALS流程。
:::

有几点常被误解：

- **抗组胺药不是一线药物。**RCUK 2021把氯苯那敏从急救流程中删除。患者稳定后可口服非镇静性抗组胺药处理皮肤症状。
- **糖皮质激素不再常规使用。**没有充分证据表明它们能预防双相反应。初始复苏后，对难治性反应或持续的哮喘或休克可以给予。
- **吸入支气管扩张剂**有助于缓解肾上腺素后仍持续的哮鸣，与哮喘中一样，但不能代替肾上腺素。
- 静脉肾上腺素**只能由有经验的专科人员**在有监护的环境中以输注方式给予（心脏骤停时除外，此时使用ALS剂量1 mg静脉注射）。

::: definition 难治性严重过敏反应 {#def-refractory}
**难治性严重过敏反应**是在给予**两剂恰当的肌内注射肾上腺素**后，呼吸和/或心血管问题仍然持续的严重过敏反应。处理（尽早请重症监护参与）包括：

- 每5分钟继续肌内注射肾上腺素，直至有经验的人员开始**低剂量静脉肾上腺素输注**；
- 快速静脉补液冲击（休克部分属于低血容量性）；
- 如梗阻进展，尽早处理气道；
- 持续休克时考虑其他血管加压药（去甲肾上腺素、血管升压素、间羟胺），服用β受体阻滞剂者考虑**胰高血糖素**，因为β受体阻滞剂可使严重过敏反应对肾上腺素抵抗；
- 上气道梗阻时考虑雾化肾上腺素，支气管痉挛时考虑支气管扩张剂，与全身性肾上腺素同时使用而不是代替它。
:::

::: warning 肾上腺素给得太晚，或给错了地方
严重过敏反应中最常见的错误是：肾上腺素延误（等着看抗组胺药是否有效，或没有皮疹就没认出严重过敏反应）、途径错误（皮下注射，或把用于肌内注射的1 mg/mL肾上腺素静脉推注，可引起致命的心律失常和高血压），以及体位错误（让低血压患者坐起或站立）。肾上腺素应尽早给予，肌内注射于大腿，同时让患者躺下。
:::

## 急救之后 {#sec-after}

### 观察

严重过敏反应在明显恢复后可以复发，称为**双相反应**，通常在12小时内。RCUK指南（2021）根据风险分层，在症状消失后确定观察时间：

- 至少**2小时**：对在反应后30分钟内给予的单剂肾上腺素反应良好、已配给两支肾上腺素自动注射笔并接受了使用培训、且有足够看护的患者；
- 至少**6小时**：需要两剂肌内注射肾上腺素或既往有双相反应的患者；
- 至少**12小时**：严重反应需要两剂以上肾上腺素者、重度哮喘或呼吸受累严重者、触发物可能仍在吸收者（如缓释药物）、深夜就诊者，以及居住在难以获得急救服务地区的患者。

儿童通常收入儿科团队（NICE CG134）。

### 肥大细胞类胰蛋白酶

血清**肥大细胞类胰蛋白酶**有助于证实一次反应是严重过敏反应，在诊断不确定时（例如麻醉期间）尤其有用。类胰蛋白酶在症状出现后约1–2小时达到峰值，半衰期约2小时。

::: definition 类胰蛋白酶采样与解读 {#def-tryptase}
按照英国指南（NICE CG134和RCUK），类胰蛋白酶的采血时间为：

1. 急救开始后尽快采集（不延误复苏）；
2. 第二份样本最好在症状出现后**1–2小时**内采集（不迟于4小时）；
3. **基线**样本在完全恢复至少24小时后采集（或在变态反应门诊随访时采集）。

如果峰值超过**（1.2 × 基线）+ 2 ng/mL**（“20% + 2”规则），则认为升高有意义。类胰蛋白酶正常并不能排除严重过敏反应，尤其是食物反应。基线升高提示肥大细胞疾病或遗传性α-类胰蛋白酶血症。
:::

### 出院与随访

按照NICE CG134和RCUK指南，每一位发生过严重过敏反应的患者回家前都应：

- 转诊至**变态反应专科服务**以确定触发因素；
- 配给**两支肾上腺素自动注射笔**（英国监管建议是，处方了自动注射笔的人应随时携带两支），并接受如何以及何时使用的培训，最好使用训练装置；
- 获得关于严重过敏反应、避免可疑触发物的书面资料和应急行动计划；
- 复核其他药物和疾病，如控制不佳的哮喘以及β受体阻滞剂或ACE抑制剂的使用，它们可能使反应更严重或更难治疗；
- 了解患者支持组织的信息。

对黄蜂或蜜蜂毒液有全身反应者，毒液免疫治疗可大大降低今后蜇伤时发生严重反应的风险；部分花生过敏儿童可通过专科服务接受口服免疫治疗。

## 不伴荨麻疹的血管性水肿 {#sec-angioedema}

**血管性水肿**是皮肤或黏膜深层的肿胀，常见于嘴唇、舌、面部、外生殖器或肠壁。大多数病例伴有荨麻疹，由组胺介导，对抗组胺药有反应；若属于严重过敏反应的一部分，则对肾上腺素有反应。**不伴荨麻疹或瘙痒**的血管性水肿提示**缓激肽介导**的病因：

- **ACE抑制剂所致血管性水肿**：ACE降解缓激肽，因此抑制ACE使其水平升高。它可以在任何时候发生，即使在用药多年后，在非洲或加勒比黑人后裔中更常见。必须永久停用ACE抑制剂并换用替代药物。
- **遗传性血管性水肿（HAE）**：C1酯酶抑制物缺乏或功能障碍的常染色体显性遗传病，引起反复的皮肤肿胀、腹部发作和可能致命的喉部肿胀。发作时用**C1酯酶抑制物浓缩物**或缓激肽B2受体拮抗剂**艾替班特**（icatibant）治疗。补体C4降低。

缓激肽介导的血管性水肿对肾上腺素、抗组胺药或激素的反应都不可靠，但如果不能排除严重过敏反应，仍应给予肾上腺素。首要任务是气道：尽早请高年资麻醉科和耳鼻喉科参与，并做好困难气道的准备。

## 急性重症哮喘 {#sec-asthma}

哮喘与严重过敏反应相互重叠：哮喘是致死性严重过敏反应的危险因素，两者都表现为哮鸣和气促。英国成人急性哮喘按BTS/SIGN指南（2019）处理；2024年BTS、NICE与SIGN联合指南涵盖哮喘的诊断和长期管理。

::: definition 成人急性哮喘的严重程度（BTS/SIGN） {#def-asthma}
- **中度**：症状加重；呼气峰流速（PEF）高于最佳值或预计值的50–75%；无急性重症哮喘的特征。
- **急性重症**：以下任一项：PEF为最佳值或预计值的33–50%；呼吸频率每分钟25次或以上；心率每分钟110次或以上；不能一口气说完一句话。
- **危及生命**：在重症哮喘患者中出现以下任一项：PEF低于33%；SpO₂低于92%；PaO₂低于8 kPa；**PaCO₂正常（4.6–6.0 kPa）**；沉默胸；发绀；呼吸无力；心律失常；疲竭；意识水平改变；低血压。
- **濒死**：PaCO₂升高和/或需要以较高充气压进行机械通气。
:::

治疗遵循ABCDE：给氧使SpO₂目标为94–98%；雾化**沙丁胺醇**（以氧气驱动），严重发作时重复或连续给予，重症或危及生命的哮喘加用雾化**异丙托溴铵**；**糖皮质激素**（口服泼尼松龙，不能口服时静脉氢化可的松）至少五天；对初始支气管扩张剂无效的急性重症哮喘，单剂静脉**硫酸镁**；出现危及生命的特征时尽早请高年资医生和重症监护评估。SpO₂低于92%或有危及生命的特征时需查血气。重症哮喘的插管是高风险操作，应由有经验的麻醉医生实施，通气必须留出足够的呼气时间以防动态过度充气。慢性管理见[[respiratory/asthma-copd]]。

## 实例分析

::: example 聚会上的花生 {#ex-peanut}
一名已知花生过敏并患哮喘的16岁男孩在聚会上吃了一块蛋糕。15分钟内出现瘙痒性皮疹、嘴唇肿胀、声音嘶哑和哮鸣。朋友让他坐在椅子上。急救人员到达时，他的SpO₂ 89%，脉率132次/分，血压80/48 mmHg。他没有带自动注射笔。描述处理。
::: solution
他符合**严重过敏反应**的标准：接触已知变应原后迅速发病，有皮肤和黏膜表现，以及气道（声音嘶哑）、呼吸（哮鸣、低氧血症）和循环（低血压）问题。他有两个致死性反应的危险因素：青少年和哮喘。

1. **让他平卧**并抬高双腿；如果呼吸非常困难可以稍微坐起，但绝不能站立。
2. 立即于大腿前外侧**肌内注射肾上腺素500微克**（1 mg/mL溶液0.5 mL）。
3. 高流量氧；监测；建立静脉通路，因低血压给予500–1,000 mL晶体液冲击。
4. 无改善则**5分钟后重复肌内注射肾上腺素**；如两剂后A、B或C问题仍持续，按难治性严重过敏反应处理，由有经验的人员静脉输注肾上腺素。
5. 肾上腺素后仍持续哮鸣时雾化沙丁胺醇。
6. 在医院：采集类胰蛋白酶样本，如需两剂则观察至少6小时（如需更多剂量，或鉴于他严重的呼吸受累，则观察12小时），然后配给两支自动注射笔并培训，转诊变态反应科，复核哮喘控制情况。

让他坐直是危险的：静脉回流减少可导致虚脱。
:::
:::

::: example 麻醉诱导后的虚脱 {#ex-anaesthetic}
一名52岁女性接受择期手术麻醉。在给予阿莫西林克拉维酸和一种神经肌肉阻滞剂后3分钟内，她的血压从128/78降至56/30 mmHg，心率升至140次/分，呼吸机压力上升。手术单下看不到皮疹。诊断是什么？如何处理？
::: solution
在被证明不是之前，这是**围手术期严重过敏反应**：在使用常见致敏药物（抗生素、神经肌肉阻滞剂、氯己定）后数分钟内出现严重低血压和支气管痉挛。皮肤体征常常缺如或被手术单遮盖；接触可能变应原后出现低血压和支气管痉挛，即符合WAO定义的第2条。

麻醉医生呼救，停用所有可能的触发物，给予100%氧；因为她在手术室、有静脉通路和监护，按麻醉指南允许有经验的人员采用的做法，以小剂量滴定方式给予**静脉肾上腺素**，必要时继以输注。快速静脉补液，尽可能推迟手术。如发生心脏骤停，开始ALS。

按[[#def-tryptase]]中所述的时间采集类胰蛋白酶样本。她被转诊至围手术期变态反应专科门诊；英国皇家麻醉医师学院第六次全国审计项目（NAP6，2018）研究了围手术期严重过敏反应，发现抗生素是最常见的已明确病因。在检测完成之前，所有可疑药物都记录为可能的变应原。
:::
:::

::: example 两次倒下的跑步者 {#ex-fdeia}
一名24岁女性慢跑时两次出现全身荨麻疹、嘴唇肿胀和虚脱，两次都在吃三明治后约30分钟。她平时大多数日子都吃面包而没有问题。应考虑什么诊断？如何确诊？
::: solution
**食物依赖-运动诱发严重过敏反应**，最常由**小麦**（对ω-5麦醇溶蛋白致敏）引起。静息时可以耐受这种食物；运动（以及非甾体抗炎药或酒精等其他辅助因素）降低了发生反应的阈值。

她应转诊变态反应门诊，在那里检测针对ω-5麦醇溶蛋白的特异性IgE和皮肤试验可支持诊断。处理是在进食触发食物后数小时内避免运动（或运动前避免该食物），随身携带两支肾上腺素自动注射笔，有人陪同运动，并在出现第一个症状时停止运动。如果病史不典型，应考虑肥大细胞疾病。
:::
:::

::: example ACE抑制剂引起的嘴唇肿胀 {#ex-angioedema}
一名63岁英国黑人男性服用雷米普利（ramipril）4年，下唇和舌在3小时内显著肿胀。他没有皮疹、瘙痒或哮鸣，血压正常。他能说话和吞咽。可能的机制和处理是什么？
::: solution
**ACE抑制剂所致血管性水肿**：服用ACE抑制剂者出现不伴荨麻疹或瘙痒的肿胀（可在治疗多年后出现，在非洲或加勒比黑人后裔中更常见）。机制是**缓激肽蓄积**，而不是肥大细胞活化。

1. **气道优先**：评估喘鸣、声音改变和流涎；尽早请高年资麻醉科和耳鼻喉科同事参与；做好困难气道准备（若进展，可能需要清醒纤维支气管镜插管或外科气道）。
2. 由于并不总能排除严重过敏反应，如对气道有任何担忧可肌内注射肾上腺素，尽管它对缓激肽介导的肿胀效果不可靠。抗组胺药和激素不太可能有帮助。
3. **永久停用ACE抑制剂**，记录为药物不良反应，换用其他降压药。血管紧张素受体阻滞剂有小的复发风险，须在专科建议后谨慎使用。
4. 观察到肿胀明确消退；这可能需要24–72小时。
:::
:::

::: example 儿童剂量 {#ex-childdose}
一名体重17 kg的4岁女孩吃鸡蛋后出现喘鸣和荨麻疹。按RCUK年龄分段，应肌内注射多大剂量的肾上腺素，需用多少体积的1 mg/mL肾上腺素？
::: solution
6个月至6岁儿童的剂量为**150微克**。浓度为1 mg/mL（1,000微克/mL）时，体积为$150 / 1000 = 0.15$ mL，注射于大腿前外侧。无改善则5分钟后重复。RCUK指南使用年龄分段而不是精确体重，以便迅速给药。儿童自动注射笔有固定剂量，由专科医生在随访时选择合适的规格。
:::
:::

::: quiz
一名34岁男性服用阿莫西林20分钟后出现全身荨麻疹和嘴唇肿胀。他呼吸平稳，没有哮鸣、喘鸣或声音改变，SpO₂ 98%，血压128/80 mmHg。对这一反应的最佳描述是什么？
- [ ] 需要立即肌内注射肾上腺素的严重过敏反应。
- [x] 不具备严重过敏反应特征的急性变态反应，因其可能进展而需要观察。
- [ ] 缓激肽介导的血管性水肿。
- [ ] 血管迷走反应。
::: solution
他有皮肤和黏膜表现，但没有气道、呼吸或循环受损，也没有严重的胃肠道症状，因此目前不符合严重过敏反应的标准。他需要观察，用非镇静性抗组胺药处理皮肤症状，备好肾上腺素以防病情恶化，并在变态反应评估之前把这次反应记录为可疑青霉素过敏。有荨麻疹以及在用药后发生，使缓激肽介导的血管性水肿可能性不大。
:::
:::

::: history
1901年，在摩纳哥亲王阿尔贝一世组织的一次航海考察中，生理学家里歇（Charles Richet）和波尔捷（Paul Portier）研究了僧帽水母的毒素。回到巴黎后，他们发现：在首次给药数周后再给狗注射小剂量海葵毒素，狗在数分钟内虚脱死亡。1902年，他们把这一现象命名为**anaphylaxis**，意为“反保护”，因为首次接触非但没有使动物获得免疫，反而使其更加脆弱。里歇于1913年获得诺贝尔生理学或医学奖。1901年，高峰让吉（Jōkichi Takamine）已分离出纯的肾上腺素。1921年，Carl Prausnitz和Heinz Küstner证明，过敏者血清中的某种因子可以把敏感性转移到另一个人的皮肤上；1966–1967年，美国的石坂公成（Kimishige Ishizaka）与石坂照子（Teruko Ishizaka），以及瑞典的Gunnar Johansson与Hans Bennich分别独立地确定，这一因子是一类新的抗体——IgE。
:::

::: summary
- 严重过敏反应是严重、迅速的全身性超敏反应，伴危及生命的气道、呼吸或循环问题，通常有皮肤和黏膜改变，但也可能没有。
- 肾上腺素对抗血管扩张、支气管痉挛和介质释放；它是唯一的一线药物。
- RCUK 2021：让患者平卧，于大腿肌内注射肾上腺素（成人和12岁以上儿童500微克；6–12岁300微克；6个月至6岁150微克），5分钟后重复，给氧和补液。抗组胺药和激素不是一线药物。
- 难治性严重过敏反应（两剂肌内注射无效）需要有经验的人员进行低剂量静脉肾上腺素输注并给予重症监护支持。
- 根据风险观察2、6或12小时；采集类胰蛋白酶样本（治疗后尽快、1–2小时时，以及24小时后的基线；峰值 > 1.2 × 基线 + 2 ng/mL为有意义）。
- 出院时配给两支肾上腺素自动注射笔，进行培训，提供行动计划并转诊变态反应科。
- 不伴荨麻疹的血管性水肿提示缓激肽介导的病因（ACE抑制剂、遗传性血管性水肿），对肾上腺素反应差。
- 急性重症哮喘：PEF 33–50%、呼吸频率≥25、心率≥110或不能说完整句话；PaCO₂正常是危及生命的特征。
:::

## 习题

::: exercise 类胰蛋白酶阈值 {level=1 check="9.2"}
一名患者的基线类胰蛋白酶为6 ng/mL。按“20% + 2”规则，峰值高于多少（ng/mL）时急性升高才被视为有意义？
::: solution
阈值$= 1.2 \times 6 + 2 = 9.2$ ng/mL。峰值高于此值支持肥大细胞活化。
:::
:::

::: exercise 肾上腺素体积 {level=1 check="0.3"}
一名8岁男孩发生严重过敏反应。按RCUK 2021，应肌内注射多少体积（mL）的1 mg/mL肾上腺素？
::: solution
6–12岁儿童的剂量为300微克。按1,000微克/mL计算，体积为$300 / 1000 = 0.3$ mL。
:::
:::

::: exercise 峰流速 {level=1 check="40"}
一名女性的最佳峰流速为450 L/min，急性哮喘发作时峰流速为180 L/min。这是其最佳值的百分之几？单凭这一项提示什么严重程度？
::: solution
$180 / 450 = 0.40$，即**40%**。PEF为最佳值的33–50%是**急性重症**哮喘的特征。还必须检查其他特征（SpO₂、PaCO₂、说话能力、疲竭）以寻找危及生命的征象。
:::
:::

::: exercise 区分晕厥与过敏反应 {level=2}
一名19岁学生在疫苗接种门诊注射后一分钟晕倒。她面色苍白、出汗，脉率48次/分，平卧后1分钟内恢复。另一名学生注射后10分钟出现潮红和哮鸣，脉率130次/分，血压82/50 mmHg。区分两者。
::: solution
第一名学生是**血管迷走性晕厥**：立即发生、苍白、**心动过缓**、平卧后迅速恢复，无皮肤、气道或呼吸表现。她需要安慰和观察。

第二名学生是**严重过敏反应**：接触后数分钟内发病，潮红、哮鸣、**心动过速**和低血压。她需要立即肌内注射肾上腺素500微克、平卧、给氧，并执行完整的严重过敏反应流程。疫苗接种门诊正是为此备有肾上腺素。
:::
:::

::: exercise 解读类胰蛋白酶 {level=2}
一名男性在麻醉期间发生可疑反应。1小时时类胰蛋白酶为21 ng/mL；6周后采集的基线样本为4 ng/mL。这一升高是否有意义？正常的基线能排除什么？
::: solution
阈值为$1.2 \times 4 + 2 = 6.8$ ng/mL。21 ng/mL的峰值远高于此，因此升高有意义，支持严重过敏反应。正常的基线使潜在的肥大细胞疾病或遗传性α-类胰蛋白酶血症的可能性降低。他需要接受围手术期变态反应专科检测以确定致敏药物。
:::
:::

::: exercise 服用β受体阻滞剂的患者 {level=2}
一名66岁女性服用比索洛尔（bisoprolol），被黄蜂蜇伤后发生严重过敏反应。她已间隔5分钟接受两剂肌内注射肾上腺素，仍然低血压（血压74/40 mmHg）、心动过缓（脉率52次/分）。发生了什么？下一步是什么？
::: solution
她发生了**难治性严重过敏反应**，β受体阻滞使其更具抵抗性：β受体阻滞削弱了肾上腺素的β₁和β₂作用，并可能导致心动过缓。下一步：呼叫重症监护；每5分钟继续肌内注射肾上腺素，直至有经验的人员开始**低剂量静脉肾上腺素输注**；快速静脉补液冲击；考虑**胰高血糖素**，它不经β受体而升高心肌内的环磷酸腺苷；如休克持续，考虑其他血管加压药。之后，她应转诊变态反应门诊考虑毒液免疫治疗，并复核她是否需要β受体阻滞剂。
:::
:::

::: exercise 写出院计划 {level=2}
一名30岁女性在吃了含腰果的咖喱后发生严重过敏反应，已经康复；她只需要在10分钟内给予的一剂肌内注射肾上腺素。列出她出院计划的要素。
::: solution
- 症状消失后至少观察2小时（她对一剂早期给药有反应），前提是满足其他条件：她有两支自动注射笔、已接受培训且有人陪同。
- 处方**两支肾上腺素自动注射笔**，用训练装置培训，并建议随时携带两支。
- 书面资料和应急行动计划；建议在评估前避免腰果和其他树坚果，以及外出就餐时如何阅读食品标签和询问配料。
- 转诊**变态反应专科服务**。
- 记录已采集的类胰蛋白酶样本，并安排基线检测。
- 提供支持组织的信息，并给她的全科医生写信。
:::
:::

::: exercise 哮喘还是严重过敏反应？ {level=3}
一名患哮喘的26岁男性在一家泰国餐馆吃饭后30分钟被送来，严重哮鸣，SpO₂ 90%，脉率128次/分，血压94/58 mmHg。他没有皮疹。他的朋友说他对花生过敏，但“从来没严重过”。讨论鉴别诊断和最初的处理步骤。
::: solution
这可能是哮喘急性加重，但在接触可能的变应原（泰国菜中常用花生）后主要表现为支气管痉挛和低血压的严重过敏反应，即使没有皮肤受累也符合WAO第2条标准。他的哮喘使致死性反应的可能性增大，而且单纯哮喘伴严重哮鸣时很少出现低血压。

他应按**严重过敏反应**治疗：立即肌内注射肾上腺素500微克，为便于呼吸取平卧或半卧位，高流量氧，低血压时静脉补液，雾化沙丁胺醇和异丙托溴铵处理支气管痉挛，必要时5分钟后重复肌内注射肾上腺素。可加用哮喘治疗（激素、镁）。类胰蛋白酶样本有助于事后明确诊断。他需要自动注射笔、转诊变态反应科并复核哮喘。如有疑问，就给肾上腺素。
:::
:::
