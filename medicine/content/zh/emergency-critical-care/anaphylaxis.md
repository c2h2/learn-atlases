过敏反应是床旁的免疫学：肥大细胞与嗜碱粒细胞脱颗粒释放一场介质风暴、把气道、血管与肠道变成一个受攻击的器官系统——而一个简单的处理算法（肌注肾上腺素、平卧、重复、呼救）使每一起死亡都是一次等待发生的系统审计。**本章讲述机制及其临床面孔（IgE介导的食物与药物及毒液及乳胶综合征；造影剂与NSAID及直接肥大细胞激活剂的非IgE路径；肥大细胞增多症与哮喘风险层）、诊断标准及靠模拟杀人的鉴别（被给了肾上腺素的血管迷走晕厥与什么都没给的哮喘发作、遗传性血管性水肿与肥大细胞肿瘤）、从第一分钟到难治性休克与ICU的处理、及之后（类胰蛋白酶时机、过敏转诊、肾上腺素自动注射器培训、双相观察判断、及预防第二次的登记与回避医学——大多数可预防死亡实际发生之处、在那个从未发生的随访）。**

## 机制

::: definition 机制、触发因素与致命表型 {#def-mechanism}
**免疫学：已致敏者的再暴露（产生与肥大细胞及嗜碱粒细胞高亲和力Fcε受体结合的特异IgE的既往无症状接触）遇到同一过敏原、把表面IgE交联成脱颗粒信号、释放预成颗粒（组胺、类胰蛋白酶、胃促胰酶、肝素）并合成脂质介质（前列腺素D2与白三烯C4这对雷暴双雄）及细胞因子——一份其器官效应拼出该综合征的介质画像：小动脉扩张与静脉渗漏（低血压与水肿及第三间隙——使过敏性休克同时是容量与张力急症）、支气管痉挛与黏膜肿胀及黏液（哮鸣与喘鸣及作为前驱症状的儿童版咳嗽）、腹绞痛与呕吐及腹泻（被低估的“她刚吐了就倒了”表现）、及子宫与膀胱收缩和濒死感——一个值得事后询问的有记录症状；作为流行病学的触发类别（儿童与青年期的食物（花生与树坚果及鸡蛋与牛奶及小麦ω5醇溶蛋白依赖的运动版本及贝类与芝麻、带新的过敏原标签时代、及α-Gal蜱相关的延迟肉类过敏到达）、围手术期与医院生活的药物（神经肌肉阻断剂仍是首要的围手术期病因、带氯己定与乳胶及箭毒样交叉反应及抗生素尤其释放类胰蛋白酶的及阿片直接肥大细胞脱颗粒模拟剂及铂类与单克隆抗体邻近输注反应、及药物脱敏方案——都是过敏门诊医学）、毒液（膜翅目伴肥大细胞增多症风险旗及毒液免疫治疗治愈率——是本章最有效的预防）、辅因子依赖的（运动或NSAID或酒精或月经或降温伴食物依赖运动性过敏作为标志性的可逆诊断及什么都给了而触发是11点三明治的围手术期病例）、及非免疫学激活剂（放射造影剂直接肥大细胞与嗜碱粒细胞效应带“既往反应预测下次反应而预处理只减少轻度突破”的现实、及NSAID加重的呼吸疾病及ACE抑制剂缓激肽血管性水肿——不是过敏反应、是另一章的教训在此重述因为它到达同一复苏舱）；致命过敏反应的危险层（哮喘伴未控制或重度气道病作为呼吸性死亡易感、及心血管疾病及β与ACE抑制剂治疗相关严重性的邻近文献、及在成人毒液与特发病例中不断出现的肥大细胞增多症及基础类胰蛋白酶升高及克隆性肥大细胞病发现、及隐瞒配料及延迟肾上腺素作为反复尸检发现的青少年与青年表型）；及值得记住的致命表型因为它们在随访与急诊中同样导向（成人死于心源性虚脱常伴极少皮肤征、儿童与哮喘患者死于气道梗阻、几乎每份复审里都有“只是哮喘”的错误标签——英国国家登记数据及澳大利亚与美国死亡系列在三十年的四课上一致：没用肾上腺素或用得太少太晚、诊断错、触发未识别、及未转诊。**
:::

## 诊断

::: definition 识别、标准与模拟者 {#def-recognition}
**标准（实用定义：数分钟至数小时急性起病伴皮肤黏膜受累（普遍的荨麻疹-潮红-血管性水肿-痒或肿块及喉紧开放句）加上至少一项呼吸受损（哮鸣-喘鸣-低氧及邻近心动过缓缺氧死亡征）或循环受损（低血压与虚脱及“我觉得我要死了”的心输出量警告）、或在已知过敏原暴露后单有消化道即算——及诚实附录：严重反应可以只从一个系统起病且无任何皮肤征（带荨麻疹然后骤停的虚脱、及麻醉患者“ETCO2下降然后血压跟随”的最初征象版本——这就是为何麻醉规程把无法解释的术中虚脱当作过敏反应并把工作检查放在之后）；分级系统（Ring-Messer及Brown及世界过敏组织严重度分类带“分级是回顾的而治疗不是”警诫——第1分钟“只是”2级的患者决定她第10分钟是不是4级）与时机指纹（IgE食物反应通常数分钟至30分钟、药物与围手术期在暴露后数分钟、而α-Gal与某些蜱相关肉类综合征在3-6小时、这就是它们如何逃过食物日记检测及运动依赖病例在公园不在餐厅到达）；因三者治疗相反而要紧的鉴别（伴心动过缓与苍白安静皮肤的血管迷走晕厥——最常见的肾上腺素误用——而正确答案是平卧与液体、除非循环真正失败否则不给肾上腺素（迷走发作中肌注肾上腺素很难受但对年轻人通常不致命、而判断之问属于见过两者的人）；肾上腺素非一线的急性重症哮喘及吸入支气管扩张剂与激素及氧及镁方案、伴哮喘与过敏反应在同一发作中共存的识别（体位下降与荨麻疹及食物史决定它）；遗传性与ACE抑制剂缓激肽血管性水肿（无荨麻疹、无痒、缓慢进展的肿胀、腹部发作、家族或药物史、及C4与C1酯酶抑制缺陷检测及艾替巴夫或C1抑制物浓缩物或ecallantide邻近特异药物——它们对组胺无效反之亦然、及气道手术麻醉警告）；其他模拟者（观察值正常的惊恐与过度通气、及类癌与嗜铬细胞瘤及甲状腺髓样癌潮红综合征、及鲭鱼鱼组胺中毒——另一条路径的过敏反应、用同样的肾上腺素与抗组胺治疗、及上腔静脉与血管迷走及任何病因晕厥鉴别——一个血压与一个血氧加一次皮肤视诊在60秒内分开疾病）；及记录机制的检查（肥大细胞类胰蛋白酶：1-2小时的升高急性样本加24小时或每周基线样本强制、因为没有基线的“正常类胰蛋白酶”会漏掉肥大细胞增多症、而急性样本高于基线的价值在临床模棱时确认诊断、且阴性类胰蛋白酶不排除、因为食物反应释放少于药物与毒液反应、而时机就是一切）及随访过敏工作检查（皮肤点刺与特异IgE及组分诊断（分子程序决定谁真正需要避免花生而对谁的阳性血检是既往致敏）、及激发试验与嗜碱粒细胞活化试验及肥大细胞增多症工作检查带KIT突变与骨髓及介质症状轨迹、及“谁需要肾上腺素自动注射器对一疗程泼尼松龙与一个春季过敏门诊号”决定——这才是急诊医师转诊要紧的实际理由。**
:::

## 治疗

::: definition 处理：肾上腺素、液体、难治性过敏反应与之后 {#def-management}
**第一分钟（救命的识别与摆位秒数：停止触发（输注夹闭、毒液螫针刮除不是挤压、食物吐出）并呼救及平卧举腿（坐起致死综合征：坐位或立位过敏患者的空心室性猝死——各委员会体位警告把它变成一个大胆的设施设计课）、及肾上腺素肌注大腿前外侧中部——按分子逆转病理生理的药（血管与水肿的α1张力、β1正性肌力与变时、β2支气管扩张与肥大细胞稳定、及抗组胺与激素不能替代的理由）；剂量语法（成人1:1000的500微克肌注带儿童10微克每公斤的按体重剂量、及1:10000静脉途径保留给复苏团队在骤停或近骤停中稀释滴定使用、带“肌注早而静脉小心”使人存活的规则、及必要时每5分钟重复、因为剂量不足与延迟才是真正的致死变量）；接下来十分钟（高流量氧与雾化沙丁胺醇治哮鸣及肾上腺素持续、及大剂量晶体冲击——因为10分钟内40%的容量离开循环、及难治性休克的肾上腺素输注——是现在的ICU电话不是之后的病房决定、带β阻滞剂患者肾上腺素找不到受体的胰高血糖素、及专科难治病例清单中亚甲蓝或血管加压素的考虑）；诚实的辅助（抗组胺与激素作为二线安慰药物、对反应本身作用不确定、而激素已被证明不缓解双相风险——这就是它们跟肾上腺素之后而不是取代它、及每张过敏反应海报上“绝不让抗组胺延迟肾上腺素”句）；难治与ICU期（鉴别复查（它究竟是不是过敏反应——填塞与张力性气胸及肺栓塞与肾上腺危象休克模拟者重筛）、肾上腺素输注与动脉置管及为肿胀气道的通气策略带“早插管、可能则清醒、或计划外科气道”决定、严重反应的ICU观察、及渗漏闭合时的升压药撤离——通常在数小时内发生、因为这就是它可逆的原因）；观察与双相决定（少数严重病例中无再暴露的第二波症状在数小时内达峰、严重或多系统或迟到反应收住6小时以上、每份验尸官档案里的“两小时后送回家”病例、及被观察恢复的患者得到肾上腺素处方与培训的出院胜任力）；及之后（肾上腺素自动注射器处方伴带回授及训练装置、及“带两支并给每个照看你的人看”文化、及附上类胰蛋白酶结果的过敏转诊触发调查、及回避与标签阅读及辅因子咨询、及叮咬过敏反应的毒液免疫治疗——对毒液有95%以上保护率的治愈、及病历旗标与学校及工作场所方案、及卡片上的过敏反应行动计划、及妊娠与驾驶及冒险保险之问得到回答因为肾上腺素决定、及登记与流行病学环——各国死亡与严重度登记不断产出同样的可预防因素、而本章唯一的治愈是会回电的随访门诊。**
:::

::: solution
**一次带三个可修复错误的死亡排练（[[#def-management]]、[[#def-recognition]]）：错误——两个系统受累的过敏反应被呼叫而肾上腺素未给：抗组胺治皮肤而沙丁胺醇治哮鸣、两者都不碰血管扩张与渗漏、而学校政策里“不确定”的瘫痪正是指南通过声明“有已知过敏者出现呼吸或循环体征时拿不准就治”所废除的；复苏——现在肾上腺素500微克肌注并每5分钟重复至有效（平卧举腿与高流量氧及20 ml/kg液体冲击、加雾化沙丁胺醇、及难治者的肾上腺素输注与ICU、及激素与氯苯那敏在肾上腺素之后而不是代替、及类胰蛋白酶样本定时1-2小时加一周基线——入院第一次没开、也在发现清单上）；处置——严重多系统发作伴双相风险及哮喘共病优化的6小时以上观察、因为她朋友的医院现在是一个儿科过敏紧急转诊（组分诊断与口服食物激发计划、及家长而非孩子被难为的重写学校与俱乐部行动计划、及孩子自己携带的第二支自动注射器、因为青少年是致死性过敏反应的最高危群体而勇气问题正是杀他们的东西）；及系统修复——写“拿不准就用”的学校用药政策伴全员培训及没有单一负责人、及病历里急救医学持有的她的计划副本、及全世界自1992年以来一直在说同样两句话的死亡复审委员会：早给肾上腺素、之后转诊。**

**执行的围手术期过敏反应（[[#def-mechanism]]、[[#def-management]]）：几分钟——宣布并治疗（“这是过敏反应直到证明不是”）、停止并记录所有近期给予的药剂及时间（触发清单：神经肌肉阻断剂第一、带皮肤上的氯己定及乳胶手套及需分离的抗生素时机）、对全麻下通气并虚脱的患者静脉滴定肾上腺素冲击（按麻醉医师协会指南递增50微克、或严重休克100-1000微克、及监护较少场合的肌注路径重述、因为静脉肾上腺素是复苏医师技能不是反射）、呼高年资援并取困难气道车、因为气道会肿、及100%氧与对毛细血管渗漏的大量液体及升压药输注、及考虑胰高血糖素与哮喘方案邻近治疗对付不缓解的支气管痉挛；手术决定——若之后可完成则停止手术对停止危险则完成、由外科医师宣布并在同一口气里决定ICU目的地；之后——类胰蛋白酶样本1-2小时及24小时以上基线、及带记录时间的用药清单用于皮肤点刺与特异IgE及类似安全性检测的紧急过敏转诊、及致病剂在病历中标为“避免”/“已查”/“不明”、及确认神经肌肉阻断剂或乳胶或氯己定者的医疗警示手环文化——因为他们终有一天要再面对麻醉、而麻醉过敏最常复发于工作检查未做之时、及向国家过敏警戒登记报告——这就是下一家医院的处方集改变的方式。**

::: example 两次倒下的跑者 {#ex-fdeia}

62岁服雷米普利患者出现18小时进展的上唇肿胀、无痒、无疹、上周轻度腹部绞痛；一名临时医师“以防万一”给了肾上腺素与氢化可的松及氯苯那敏、并预约“过敏随访”。
::: solution
**缓激肽不是组胺（[[#def-recognition]]、[[cardiovascular/hypertension]]）：区分——缓慢进展的无荨麻疹无瘙痒水肿伴既往腹部发作就是缓激肽ACE抑制剂血管性水肿、它能进展到舌、喉与肠道、而肾上腺素与抗组胺对它作用甚微这一事实是诊断信息不是治疗失败；计划——永久停ACE抑制剂并记录为药物反应而不是“血管性水肿不明”、及ARB警诫与DPP-4抑制剂及沙库巴曲邻近相互作用注记、及按轨迹决定的气道观察并对舌与口底进展早期请麻醉介入（清醒纤维喉镜或外科气道计划、不是系列插管尝试）、及特异药物之问（艾替巴夫与C1抑制物浓缩物及ecallantide的证据主要来自遗传性血管性水肿、在ACE抑制剂中结果不确定、这就是为何“支持加气道路径”仍是诚实答案、及该把试验文献读给问为何什么都没在消的她家人听）；工作检查——C4与C1抑制物水平及功能及遗传性血管性水肿I、II型及正常C1INH变异型检测、尤其反复或有家族史者、因为藏在“ACE血管性水肿”诊断里的遗传性I型是带终身含义的漏诊（触发因素与避孕及雌激素回避、妊娠与牙科操作规划、及C1抑制物浓缩物与依兰珠单抗及慷慨预填充注射器家庭治疗、及肠内发作被误诊为外科急腹症的病史）、及一级亲属筛查——才是过敏随访实际该做的；及系统要点——临时医师的“以防万一”肾上腺素教导本章后半：在选择拮抗剂之前先识别通路。**

::: exercise 管理难治性反应 {level=2}

::: solution

## 通向何处

肾上腺素的受体药理在[[pharmacology/drug-receptor]]与[[pharmacology/autonomic-drugs]]、免疫学机制在[[immunology/hypersensitivity]]、围手术期触发在[[surgery/anaesthesia-pain]]、食物过敏与儿科背景在[[paediatrics/acute-childhood-illness]]、及毒物模拟者在[[emergency-critical-care/poisoning]]。

::: history
**过敏反应的历史始于一个关于狗的词：Portier与Richet于1902-1903年的工作、他们在摩纳哥Albert一世的科学考察队上试图针对海葵毒液免疫、发现再暴露戏剧性地杀死某些动物而不是保护它们、将此现象命名为ana-phylaxis——“无保护”——并使Richet获得1956年诺贝尔奖、而反复给自己注射的Portier于1929年死于自己实验性的黄蜂毒液致敏、该领域从未停止引用这一死亡。二十世纪解剖了这个反应：1921年Prausnitz-Küstner转移实验证明一个血清因子（1966年被Ishizaka夫妇找回为IgE）承载过敏的特异性；肥大细胞与组胺药理及其阻滞剂使过敏反应的皮肤与消化道症状可治而心血管与气道成分不可；及Coca等人对特应综合征的临床分类学。然后1966年、改变一切的治疗安静到来：复苏委员会与Simons及Levine的工作及麻醉文献确立肌注自行给药肾上腺素为干预、随后的肾上腺素笔时代使它可随身携带、带过敏反应套件与学校政策、及仍未解决的发现：这药救命而太少人愿意用它。流行病学转折随死亡登记到来：英国国家登记自1990年代初的报告及澳大利亚与美国系列及法国与北欧研究趋同于同一幅死亡画像——社区中的食物、围手术期与院外的药物与毒液、肾上腺素缺席或晚、诊断错误、转诊缺失——及2011-2021年使定义标准化以便计数发病率的各指南（报告率上百倍变异显示驱动数字的是定义而非生物学）。肥大细胞生物学提供现代一章：类胰蛋白酶时代的诊断（1980年代的测定）、遗传性与获得性血管性水肿的分离（1960年代起的C1抑制物故事）、藏在“特发性”与毒液病例中的肥大细胞增多症与克隆性肥大细胞病的识别、及α-Gal综合征——蜱相关、延迟、糖抗原的肉类过敏、从美国东南部的临床奇事开始并成为如何缓慢发现一种新过敏的全球案例研究（兽医与患者倡导的先声及孤星蜱研究及2010-2020年的图谱）——一种新到许多临床医师仍漏掉其4小时延迟的过敏。治疗创新持续（肾上腺素输注泵与鼻内给药试验、2020年代食物过敏脱敏许可的单克隆抗IgE奥马珠单抗、及自1911-1957蜜蜂毒液谱系以来的毒液免疫治疗治愈率文献及过敏原免疫治疗管线）、而核心药物仍是一个世纪前的肾上腺提取物。历史的政策半边：从丹麦与澳大利亚到美国FASTER法案的食品标签运动、及美国“Ryan法”各州的学校用药法浪潮（以一个在派对上因隐藏配料死亡的男孩命名）、及英国的Edelman与Leaf邻近复审及14克规则之辩、及学校与餐厅的公共肾上腺素自动注射器争议——这是民主为登记所发现东西立法的方式。** — [[immunology/hypersensitivity]]、[[pharmacology/autonomic-drugs]]、[[public-health/prevention-promotion]]。**
:::

::: summary
- 过敏反应是肥大细胞与嗜碱粒细胞脱颗粒——通常IgE介导——造成同时的气道、循环、皮肤与消化道衰竭；诊断是临床的、而标准（急性起病加呼吸或循环、或暴露后消化道）存在的目的就是阻止犹豫。
- 大腿中部肌注肾上腺素、每5分钟重复、是唯一一线治疗；平卧举腿与早期大容量静脉补液治疗空循环生理；抗组胺与激素是绝不可延迟肾上腺素的辅助。
- 致命表型是延迟的肾上腺素、哮喘患者的气道死亡及成人心血管虚脱；各登记中最常见的错误相同：没认出、没注射、没平卧、没转诊。
- 三个模拟者改变处理：血管迷走晕厥（不给肾上腺素、液体与体位）、重症哮喘（支气管扩张剂优先、而共存过敏反应要肾上腺素）、及缓激肽血管性水肿（抗组胺与肾上腺素抵抗、需特异药物）。
- 带基线样本的类胰蛋白酶、过敏转诊、带回授的自动注射器培训、书面行动计划、按触发的预防（毒液免疫治疗、药物标签、食品计划）、及对双相反应的观察是治疗之后的治疗。
- 过敏反应高复发也高可预防：随访门诊、学校与工作场所方案、及登记册是其死亡率曲线真正转弯之处。
:::

::: exercise 区分晕倒与过敏反应 {level=2}

**过敏反应出院胜任力（[[#def-management]]）：组套——与严重度及双相风险及哮喘状态相称的观察期、及两支肾上腺素自动注射器处方带演示与用训练器的回授及有效期与储存及旅行及随时携带咨询、及书面过敏反应行动计划、及已开或已约急性与基线类胰蛋白酶的过敏转诊、及皮肤点刺与特异IgE及组分计划、及含辅因子的触发调查（NSAID与酒精及运动依赖之问及贝类类型与剂量及餐厅对家里的故事）、及回避与标签阅读及交叉污染教育、及按情况的注意事项（鱼过敏与烹饪蒸汽、及“煮熟的贝类常能耐受对不能”的细微稍后与过敏科医师决定而不是今晚）、及有同住者在场的安全网与何时叫急救、及医疗警示手环讨论及驾驶工作与生育规划之问、及今天通知全科、因为下一次可能不在医院附近发生；两个错误——因“只有一次”而未开肾上腺素是错误一、及因“她看起来很好”而未约转诊是错误二：随访门诊的常客是发生了第二次更重反应的人、或因一个贴错标签的阳性血检而避免整类食物的人、而两种结局都能被今晚的文书与今晚的电话预防。**

::: exercise 设计地区的过敏反应规划 {level=3}
贵地区：仅一半院前过敏反应呼叫给了肾上腺素、三所学校没有政策、全科诊所没有可接受成本的自动注射器供应路径、成人过敏随访40周、及无死亡复审路径。带法律、培训与数据成分构建规划。
::: solution
**过敏反应系统（[[#def-mechanism]]、[[#def-management]]、[[public-health/prevention-promotion]]、[[immunology/hypersensitivity]]）：院前半边——救护车与急救员肾上腺素审计伴“拿不准就给”的规程变更与培训及无针的简单、因为国际证据明确、而障碍是信心与诉讼恐惧、用规程与解释清楚的好撒玛利亚人法律回答、及公共自动注射器试点评估按试验而不是新闻稿做、先修好药房与全科供应及资金路径、因为青少年无法携带六周后才到的处方；学校与工作场所——法律支持的个体医疗计划（学校用药职责框架：每校储备自动注射器带培训及无单人瓶颈、及挽救餐厅死亡的食品告知课）、及餐厅与餐饮商过敏原标签及14克规则邻近执法——这是穿贸易标准服装的预防医学；临床路径半边——“所有过敏反应都转诊”规则伴按转诊量预测论证的成人与儿科过敏服务容量（40周等待正是回避错误与重复急诊就诊复利的方式）、及过敏专科护士主导的肾上腺素与行动计划及毒液免疫治疗同门诊可得（毒液免疫治疗的治愈率意味着候诊名单是被延迟的命）、及药物过敏与脱敏及青霉素平行路径、因为医院药物再激发与回避决定目前靠专科间邮件进行；及数据与问责半边——过敏反应发病率与严重度及肾上腺素给药及随访完成率指标报告、死亡经国家患者调查或重大事件路径复审并编码死因方法、因为“食物诱发过敏反应”常被错编为哮喘死亡、从而抹掉为该规划提供资金的流行病学、及点名没有政策的学校与不开类胰蛋白酶急诊的地区的年度过敏反应报告、因为本章的死亡不断发生在医学与行政之间任何董事会都能闭合的缺口里。**
