月经与盆腔的疾病是妇科门诊的全部重量所在：**出血、疼痛、包块、急性腹痛，这四个入口决定了多数女性一生的妇科就诊，而其中两类病——子宫腺肌病与内膜异位症——长期因“女人都是这样”而被延误七到十年。**本章覆盖异常子宫出血的分期与评估（含青春期）、疼痛的原发与继发（含内膜异位症与腺肌病）、包块与急症（肌瘤与卵巢的扭转与囊肿与妊娠的合并），并把识别与转诊作为重点而不是手术技巧。

## 出血

::: definition 异常子宫出血 {#def-bleeding}
**异常子宫出血用两个轴描述：先说模式（稀发、频发、不规则、经期过长、经量过多、周期间出血、绝经后出血），再说子宫内膜的来源（结构性的或不定为结构的），后者的九个字母可以背下来：全身凝血、无排卵、内膜的、息肉、腺肌病、肌瘤、恶性与增生、医源、以及未分类。经量过多的定义不再依赖失血毫升数，而是“影响身体、社会、情绪与身体的表现”，因为她的功能受损就是治疗的理由。评估按年龄分岔。青春期：初潮后头两年的无排卵周期很常见，因此轻度不规则不需检查；但若一次出血导致住院或血红蛋白低于七十，或有月经以来的大量出血与拔牙与鼻出血与家族史，就要查凝血，尤其是冯威廉因子缺陷与血管性假血友病，后者在因经量过多就诊的青少年中可占相当比例。育龄期：妊娠相关的出血永远先排除（包括异位妊娠与流产），然后是甲状腺与催乳素与排卵的有无；单房的子宫超声可以看肌层的改变与内膜的厚度。四十岁以上或有内膜风险者（肥胖、多囊、长期无排卵、他莫昔芬）需要内膜的组织学，而不是先试药三个月。绝经后：任何出血都要评估，路径见[[obstetrics-gynaecology/gynaecological-cancer]]。要问而常被漏问的三句：一个卫生巾用多久、有没有睡着后漏出、有没有一次连续用两个小时以上；“我没有贫血所以我没事”不成立，因为经量与铁储备的关系常在她适应之后才被察觉。治疗按她是否想要妊娠与是否愿意保留生育分层：不想要妊娠者可先用药物（若干的左炔诺孕酮宫内系统为一线，其次为氨甲环酸与非甲体抗炎药与周期的孕激素与若干的口服避孕药），想要妊娠者先处理原因（黏膜下的肌瘤与息肉与腺肌病的宫腔问题）；子宫切除是可选的终点而不是失败的同义词，但它必须在她理解了不可逆之后被选择（[[obstetrics-gynaecology/menopause]]、[[blood/haemostasis-bleeding]]、[[endocrine/reproductive-endocrinology]]、[[clinical-skills/laboratory-tests]]）。**
:::

## 疼痛

::: definition 痛经、盆腔痛与内膜异位症 {#def-pain}
**疼痛按时间分为两类，而这一分法决定要不要找原因。原发性痛经在初潮后一至两年内出现，呈痉挛性、与月经的最初一到两天重合、可用非甲体抗炎药缓解，查体与超声正常，其机制是内膜的前列腺素；若它在初潮后不久即存在、影响学业、且止痛药只能部分缓解，就要想到梗阻性的畸形与（在青少年中的）内膜异位症，而不是“以后会好的”。继发性痛经指原本不痛或较轻者后来变痛、或疼痛提前于月经数天开始并向经期后延伸、或逐年加重——这一条曲线（逐年加重的经期疼痛）是内膜异位症与腺肌病最有价值的病史。内膜异位症的定义是有功能活性的内膜样组织在子宫外，常见于盆腔的腹膜与骶韧带与卵巢，腺肌病则是内膜样组织进入肌层。它的症状并不只是痛经：慢性盆腔痛、深部的性交痛、排便痛与周期性的肠道症状、周期的血尿与（在罕见的膈肌病灶的）肩痛与（在若干人的）不育；但也有病灶广泛而几乎无症状者与病灶微小而剧痛者，所以疼痛的程度与术中所见的分期不平行，这一点要反复告诉患者，因为她需要被相信。诊断的现实是没有可靠的无创检查：腹型的超声与核磁可以发现卵巢的内膜样囊肿与深部的病灶，但腹膜的小病灶只能腹腔镜下看到，因此经验性的治疗是合理的而非妥协——通常先给非甲体抗炎药与激素的抑制（若干的连续口服避孕药与孕激素与宫内系统），若无效则升级；激素的治疗抑制病灶但不治愈疾病，所以症状会在停药后回来。腺肌病的表现是经期加重的疼痛伴经量多与子宫均匀增大（在若干体系中的球形子宫），诊断常在超声或核磁上被提示，治疗在药物失败后包括子宫的切除。要在疼痛章节里排除的其他原因：泌尿的间质性膀胱炎、胃肠的肠易激、腹壁的神经卡压（在压痛最明显处吸气时加重）、以及盆腔的静脉与肌肉骨骼的原因；慢性盆腔痛从来不是单一器官的疾病，最失败的做法是把它交给三个科各治一半。最后，“疼到不能上学与不能工作”就是需要治疗的强度，与影像的正常与否无关（[[obstetrics-gynaecology/gynaecological-cancer]]、[[gastrointestinal/bowel-disease]]、[[renal/urinary-tract]]、[[clinical-skills/history-taking]]）。**
:::

## 包块与急性问题

::: definition 包块与急症 {#def-lumps}
**盆腔的包块按位置与年龄想来源：子宫（肌瘤与腺肌病与妊娠）、卵巢（功能的囊肿与内膜样囊肿与皮样的囊肿与肿瘤）、输卵管（积水与积脓）、以及非妇科（肠与输尿管与腹膜的与腹壁的）。育龄女性的任何一个包块先做妊娠试验，因为异位妊娠与黄体囊肿的鉴别直接决定处理的路径。超声是首选的影像：报告要说清大小与囊实性与分隔与乳头状的突起与血流与（在绝经后的）自由的液体；肿瘤的标志物只在提示的语境下解读（若干的 CA125 在内膜异位症与肌瘤与盆腔炎中都可以升高，故它既不是筛查也不是确诊）。处理的三条原则。第一，简单囊肿在育龄期绝大多数是功能性的，五厘米以下不复查也可，较大的可观察至两到三个月经周期后。第二，畸胎瘤（皮样的囊肿）在年轻女性中最常见发生扭转，因为它的密度不均，所以五六厘米以上通常建议切除而不是观察。第三，扭转与破裂与出血是急症：突发的单侧剧痛伴恶心呕吐、超声见卵巢的血流减少或消失（但血流存在不能排除扭转，因为双重供血）、以及“疼痛在几小时内自行缓解后又复发”的既往史，都提示不全扭转；扭转的处理是急诊的腹腔镜下复位并保留卵巢，而不是切除，尤其在年轻女性——这一句在很多地方仍被延误。肌瘤的位置决定一切：黏膜下引起出血，肌壁间影响宫腔形态与生育，浆膜下可引起压迫但很少出血；治疗按症状与生育意愿，包括宫腔镜下切除与肌瘤剔除与子宫动脉的栓塞与若干的药物（在若干体系中的促性腺激素释放激素的类似物与拮抗剂用于术前缩小）；要提醒的是术前用激素缩小后病灶可能变得难以触清，并且见[[obstetrics-gynaecology/gynaecological-cancer]]中肉瘤的一例。盆腔炎与输卵管卵巢的脓肿表现有发热与宫颈举痛与附件的压痛，需要足量的抗生素并考虑脓肿的引流与（在避孕器在位者的）取出。最后一条与本章所有例子有关：年轻女性的剧痛与“检查正常”之间常有一段时间差，而把疼痛的主诉当作客观资料记录，是唯一可靠的保险（[[surgery/acute-abdomen]]、[[obstetrics-gynaecology/early-pregnancy]]、[[infectious-diseases/healthcare-infections]]、[[clinical-skills/medical-imaging]]）。**
:::

::: example 十四岁的“每次都这样” {#ex-adolescenthmb}
一名14岁女孩初潮后十个月，这次月经已持续九天、每小时浸透一片、头晕；血红蛋白62；她的母亲说“我们家里女人都这样”；查体无异常，未查妊娠。
::: solution
**这是需要今天处理的出血，不是“下次干净了再来”（[[#def-bleeding]]、[[blood/haemostasis-bleeding]]、[[emergency-critical-care/acute-assessment]]）。即刻的四步：一是评估循环并按症状决定输血（血红蛋白62伴头晕与活动后气促即输血的指征，不因她“看起来尚可”而延后）；二是查妊娠（青少年也必须查，这既是为了诊断也是为了安全）与凝血的路径（全血计数与凝血与铁代谢，并按出血史筛查血管性假血友病：拔牙后出血、鼻出血反复、产后大出血的家族史）；三是止血的治疗，大剂量激素的方案（在若干体系中的结合雌激素静脉、或口服避孕药每日三次递减、或大剂量的孕激素）通常数小时内减少出血，配合氨甲环酸与补铁；四是住院的门槛：出血未减、血红蛋白继续下降、或有凝血缺陷者。要与她本人谈，而不是只与母亲谈：单独问诊五分钟，问性生活与暴力的可能（在出血的主诉下藏着妊娠与损伤）与她的学校与情绪。家庭的那句话“家里女人都这样”要正面回应：这不是体质，而很可能是一种遗传的凝血缺陷，它可以在分娩与手术与牙科操作时造成危险；一旦诊断成立，她的母亲与姐妹也应被告知，并且这张诊断在她一生中都改变处理。长期计划包括补铁三个月以上（在月经恢复后仍继续）、避孕与出血的双重管理（若干的宫内释放系统在她这个年龄是可选的，且不影响未来的生育）、与血友病团队的联系（在确诊时）。最后把“若再次大量出血去哪里”写下来，因为这类家庭常在急诊与门诊之间来回数周（[[paediatrics/adolescent-health]]、[[pharmacology/adverse-reactions]]、[[clinical-skills/communication]]）。**
:::

::: example 被说“忍一忍”的内膜异位症 {#ex-endo}
一名29岁的女性七年来经期疼痛到呕吐、排便痛、深部性交痛，止痛药效果下降；两次超声“未见异常”；她想一年后怀孕，问“是不是只能做腹腔镜”。
::: solution
**七年的延误是她病史中典型的部分，而不是她的表达不足（[[#def-pain]]、[[clinical-skills/communication]]）。第一件要做的事是承认并命名：告诉她“逐年加重的经期疼痛伴排便痛与深部性交痛”这一组表现本身就构成内膜异位症的高度可疑的诊断，正常的超声不能排除腹膜的病灶，因此她不是“没病”。第二，把治疗按她的生育时间表排：她现在不想立即妊娠，那么首选的是激素的抑制（连续的口服避孕药或孕激素或若干体系中的宫内系统）配合非甲体抗炎药与肠道的对症（排便痛与肠易激的重叠常见，需要解释这不是心理问题）；这不会延误将来妊娠的机会。第三，回答她的问题：腹腔镜不是唯一的下一步，但它有明确的适应证——激素治疗无效、疑似较大的内膜样囊肿、深部病灶侵犯肠道或输尿管、以及不育的评估；手术的价值在切除病灶与松解粘连以缓解疼痛与改善生育，但复发常见，且手术本身可能造成粘连，因此应由有经验的团队在她了解局限之后进行。第四，处理她的伴侣关系与（在性交痛上的）沟通，并提供性的康复的信息，因为多数门诊从不主动问这一项。第五，别把她的生育问题推迟：她计划一年后妊娠，那么现在就该说明试孕的时间与何时转诊生殖门诊（在若干年龄与试孕时间下的规则），并把卵巢的储备评估放在手术之前讨论，因为反复的卵巢病灶切除会降低储备。要给她一句可以带走的总结：这是一种需要长期管理的病，治疗的目标是让她过正常的日子，而不是等到“足够严重”才治（[[obstetrics-gynaecology/contraception-fertility]]、[[gastrointestinal/bowel-disease]]、[[clinical-skills/records-handover]]）。**
:::

::: example 其实是黏膜下的肌瘤 {#ex-fibroid}
一名41岁女性经量增多伴乏力两年，血红蛋白102、铁蛋白8；超声见子宫增大，多个肌瘤最大的五厘米，报告未说明位置；她希望保留子宫。
::: solution
**她的关键信息不在“有肌瘤”而在肌瘤在何处（[[#def-lumps]]、[[#def-bleeding]]、[[clinical-skills/medical-imaging]]）。要做的是把超声报告变成可决策的描述：黏膜下（在宫腔内的或突向宫腔的）、肌壁间（是否变形宫腔）、浆膜下（是否带蒂），必要时用宫腔的灌注超声或核磁；同时把内膜看一眼（在四十岁以上或持续异常出血者）。补铁按疗程给（在元素铁的剂量与三个月以上，并在八到十二周复查血相与铁蛋白），因为只治肌瘤而不纠正缺铁会让她的乏力持续半年。按她的意愿排治疗阶梯：一线是左炔诺孕酮的宫内系统（在若干体系中对经量减少的效果最持久且保留子宫），或氨甲环酸与非甲体抗炎药在经期使用；宫腔镜下切除适用于黏膜下的病灶（尤其带蒂且小于若干厘米者），效果立即可见但可复发；子宫动脉的栓塞适用于不愿意手术或多发者，需要交代再干预的比率与对卵巢功能的可能影响与（在若干人的）术后的疼痛；肌瘤剔除适用于肌壁间变形宫腔与希望妊娠者，但妊娠期子宫的瘢痕需要产科的讨论与（在若干情形中的）剖宫产的规划；子宫切除在她完成生育且其他方法失败时是合理的选择，而不是“最后的手段”或“过度治疗”。要明确一条容易被忽略的诊断：她的出血若伴 容易淤青 与既往出血史，仍需筛查凝血；以及四十岁以上者若内膜异常，需要在治疗前排除增生与癌，见[[obstetrics-gynaecology/gynaecological-cancer]]。最后写明复评的时间（在若干周的出血量表与三个月的血相），并以“减少出血与纠正铁”作为共同的目标而不是“让肌瘤变小”（[[endocrine/reproductive-endocrinology]]、[[surgery/gastrointestinal-surgery]]、[[pharmacology/dosing-principles]]）。**
:::

::: example 右侧疼痛与已知的囊肿 {#ex-dermoid}
一名26岁女性右侧附件有五厘米的成熟畸胎瘤（超声见脂肪与钙化），两日内三次突发单侧剧痛伴呕吐、每次一小时后自行缓解；今天无痛，超声见卵巢血流存在。
::: solution
**她的表现是卵巢扭转的典型而不全的形式：突发剧痛、伴呕吐、反复发作后自行缓解（在扭转后自发复位）；今天不痛与血流存在都不能排除，因为双重供血与复位使超声的阴性预测值很低（[[#def-lumps]]、[[surgery/acute-abdomen]]）。做法：把病史当作诊断的主要依据，请妇科当天评估；若再次发作或压痛持续，行急诊的腹腔镜探查；处理是复位并保留卵巢（在年轻女性中），而不是因为卵巢“发黑”就切除——外观缺血并不等于坏死，多数在复位后恢复；囊肿本身在同一次或择期的手术中剥除，因为畸胎瘤会继续增大并再次扭转。鉴别要一并考虑：黄体破裂（常在周期的后半、可有腹腔的积液）、异位妊娠（因此先查妊娠试验）、阑尾炎（在右侧总是需要想到）、以及肾绞痛的放射。她的门诊教育要包含三句：什么时候必须立刻回医院、不要再等“它自己好”、以及若被建议切除卵巢，可以问是否可以先复位——这一句话在许多病例中保住了卵巢。若她正在助孕或囊肿较大，择期的腹腔镜剥除是常规，术式的要点是保留卵巢的皮质（在卵巢与囊肿壁之间的层面）与避免用电凝的广泛止血以保护卵巢的储备。最后要记录的是她的疼痛描述与发作的次数，因为下一个看到她的人在无痛时很难做出判断（[[obstetrics-gynaecology/early-pregnancy]]、[[clinical-skills/clinical-reasoning]]、[[clinical-skills/records-handover]]）。**

::: exercise 把出血分级 {level=1}
请为下列四人各说出模式与首要处置：初潮后八个月每两到三月来一次、量少；45岁经量增多伴周期缩短；33岁周期间出血三个月；62岁绝经后出血一次。
::: solution
**第一人属于正常的初潮后不排卵周期，无需检查，只需说明两三年内会规律，并给出大量出血时就诊的门槛。第二人有结构性的原因的可能（在肌瘤与腺肌病与内膜的病变上），需要妊娠试验与血相与铁与超声与内膜的组织学（在四十岁以上），然后按是否保留生育选择治疗。第三人的周期间出血提示息肉与黏膜下的肌瘤与宫颈的病变与（在若干的）内分泌的原因，处理是妊娠试验与宫颈的视诊与超声与（若干情形中的）宫腔镜，而不是直接上药。第四人的绝经后出血是当周必须评估的，无论量多少，路径见[[obstetrics-gynaecology/gynaecological-cancer]]：内膜的厚度或取样，加上宫颈与阴道的来源排除在激素治疗与（在抗凝药物上的）（[[#def-bleeding]]、[[endocrine/reproductive-endocrinology]]、[[blood/haemostasis-bleeding]]）。**
:::
:::

::: exercise 给内膜异位症的手术做咨询 {level=2}
一名32岁的深部内膜异位症患者同意腹腔镜，她问三件事：“切干净了吗”“我还能生吗”“会复发吗”。请逐条回答。
::: solution
**第一条：手术能切除看得见的病灶并松解粘连，但腹膜的微小病灶不可能被一一清除，因此“切干净”不是一个可以承诺的结果；疼痛的改善在多数的研究中明确，且在有经验的团队中更大，深部病灶累及肠道时的并发症风险需要提前谈。第二条：生育的机会取决于她的年龄与卵巢的储备与病灶的范围；切除卵巢的内膜样囊肿会略微降低储备（在反复的切除中更明显），因此若她打算妊娠，应在手术前评估储备并商定是手术先行还是生殖的路径先行；若她暂不妊娠，术后用激素抑制并不影响将来的机会。第三条：会复发，停药后常回来，因此治疗的设计是长期的管理而不是这一次的手术；要同时给非药物的部分（睡眠与运动与肠道的症状与性的康复与疼痛的应对），因为在慢性疼痛中单纯的手术不能解决问题。最后要确认她的期望（在“不再疼”与“能怀孕”之间的优先次序），并把术式的选择与可能的肠道的准备与避孕器的处理一并说明（[[#def-pain]]、[[obstetrics-gynaecology/contraception-fertility]]、[[clinical-skills/communication]]、[[medical-ethics-law/consent-capacity]]）。**
:::
:::

::: exercise 处理扭转的判断 {level=2}
凌晨三点，一名23岁的女性说右下腹绞痛伴呕吐，超声未见血流异常，白细胞轻度升高，她的疼痛需要阿片才缓解。外科认为“不像阑尾炎”。请给出你接下来的两小时。
::: solution
**两小时之内要做的事：复查她的疼痛的曲线与体征而不是只看化验（在阿片之后仍然要求继续加药，是有分量的信号）；查妊娠试验；请妇科到场而不是留观（在卵巢扭转中，从疼痛到手术的时间影响卵巢的存活）；把超声的“血流正常”当作不能排除的证据写进记录；若疼痛不缓解或反复加重，行增强的影像或直接腹腔镜探查（在年轻女性中探查的阴性率是可以接受的代价）；同时给补液与止吐并留置静脉通路，并做好麻醉的准备（在若干情形中的禁食时间需要权衡）。要处理的两个系统问题：其一是“不像阑尾炎”这类排除性的语言不能替代诊断的责任，需要有人写下“目前考虑什么、排除了什么、谁负责复评”；其二是凌晨的镇痛不足在年轻女性中是常见的质量问题，疼痛评分与给药的间隔要写进护理记录以便被看见。若最终是别的诊断（在黄体破裂与肾绞痛与肠系膜的淋巴结炎与（在若干的）卵巢的囊肿破裂），把她的复诊时间与“何种情况立刻回来”写在纸上再让她离开（[[surgery/acute-abdomen]]、[[#def-lumps]]、[[emergency-critical-care/acute-assessment]]、[[clinical-skills/patient-safety]]）。**
:::

::: exercise 设计盆腔痛的服务 {level=3}
请为一个地区设计慢性盆腔痛与内膜异位症的服务，说明诊断的加速、多学科的内容、手术的门槛与评价。
::: solution
**四条支柱（[[#def-pain]]、[[public-health/health-systems-economics]]、[[clinical-skills/patient-safety]]）。加速诊断：把“逐年加重的经期疼痛伴排便痛或深部性交痛”写成初级照护可以直接开始治疗的依据，并在培训中明确“正常的超声不能排除内膜异位症，不要等影像”；同时把青少年的大量出血与疼痛的转诊路径与凝血的筛查连起来，因为这两组人在同一批家庭里。多学科的内容：妇科与疼痛与胃肠与泌尿与物理治疗（在盆底肌的张力过高的处理上很关键）与心理的支持与性的康复与（在慢性疼痛中的）睡眠；重点是把“这不是想象出来的痛”这句话写成服务的一致口径，因为她的信任常在多次否认之后被消耗。手术的门槛要写清并公开：激素抑制失败、较大的内膜样囊肿或迅速增大、深部病灶伴肠道或输尿管的症状、不育的评估、以及诊断的不确定；同时规定此类手术需转至有经验的中心（在肠道的切除与输尿管的手术需要多学科的准备）。评价：从症状出现到诊断的间隔与到治疗开始的间隔、激素治疗的实际使用率、手术的并发症与再手术率、以及患者报告的两项（疼痛对生活的影响与是否被相信）；并按年龄与族群分层，延误往往集中在同一个群体。最后要有一条防止过度治疗的规则：不能把手术作为唯一的解释，因为不是所有的盆腔痛都来自盆腔（[[gastrointestinal/bowel-disease]]、[[renal/urinary-tract]]、[[geriatrics-palliative/symptom-control]]、[[public-health/determinants-inequalities]]）。**
:::

## 通向何处

绝经与出血的评估见[[obstetrics-gynaecology/menopause]]；肿瘤的路径见[[obstetrics-gynaecology/gynaecological-cancer]]；妊娠早期的疼痛见[[obstetrics-gynaecology/early-pregnancy]]；避孕与生育见[[obstetrics-gynaecology/contraception-fertility]]；凝血障碍见[[blood/haemostasis-bleeding]]；青春期与少女的健康见[[paediatrics/adolescent-health]]；急腹的鉴别见[[surgery/acute-abdomen]]；症状控制见[[geriatrics-palliative/symptom-control]]。

::: history
**妇科对出血与疼痛的认识经历了两次 reversal。第一次发生在疼痛上。十九世纪的欧洲医学把痛经当作“子宫的神经症”，治疗从卧床与吗啡到宫颈的烧灼与切除，而一位美国医生在1860年代提出宫颈的狭窄会造成经血的滞留与“子宫的抽搐”，并推广了宫颈的扩张术，这一做法在几十年间被大量施行，甚至被用于一切无法解释的盆腔痛，直到二十世纪初的批评指出这些手术大多没有指征。真正的转向在1921年：一位伦敦的医生在切除的子宫标本上描述了子宫外存在的、组织学上似内膜的腺体与间质，并把这一现象命名为内膜异位症；这一发现的意义在当时并不明显，因为接下来的五十年里学界把多数盆腔痛归因于心理的因素。1920年代雌激素被分离出来，1930年代孕酮被合成，1950年代口服避孕药问世，第一次出现了可以长期抑制排卵与减少月经量的药物，内膜异位症的治疗从此有了非手术的选择；1960年代，一位巴西的医生在切除的内膜异位病灶中发现其摄取染料的能力与正常内膜不同，1970年代初他提出了经血通过输卵管逆流到盆腔的机制，也就是至今仍在教科书中占据核心地位的那一套解释。同一时期，腹腔镜使诊断从开腹的偶然所见变成了可重复的观察，1970年代多国建立了内膜异位症的分期系统；而正是这些分期在随后的二十年里暴露了它们的限度——一项1990年代初的随访研究显示，未经治疗的轻微病变在多数人中自行改善，而疼痛的强度与分期无关，这促使学界在1970年代末开始质疑以烧灼与切除为主的“为诊断而做的手术”，并在1990年代出现了随机试验对手术后疼痛的获益的争论。第二次 reversal 发生在出血上。1960年代以前，经量过多常导致子宫切除；1960年代之后，激素避孕与随后宫内释放左炔诺孕酮系统的出现提供了有效的替代，1990年代子宫内膜的去除术风靡一时，直到它与子宫切除的比较被系统评价后，适应证被收紧。同时，血液学的贡献是本章最重要的新认识之一：1990年代的多项研究显示，因经量过多就诊的青少年与年轻女性中有可观的比例存在凝血功能的缺陷，尤其是血管性假血友病，这一发现把一部分“妇科的月经过多”改写为“未被诊断的全身性出凝血病”，并推动了两科联合门诊的出现。肌瘤的治疗同样在技术转向：子宫动脉的栓塞在1990年代被引入妇科，高强度聚焦超声与多种药物（在若干体系中的促性腺激素释放激素的类似物与口服的拮抗剂）在2010年代陆续获批，使“要么吃药要么切子宫”的两难被替换成一份可谈的选择。卵巢扭转的故事则是一部被反复延误的历史：它最早在十九世纪的尸检中被描述，二十世纪初的病例系列指出多数被切除的卵巢其实可以保留，而1990年代之后的超声时代带来一个悖论——影像的使用增加了，误切的比例却仍在若干中心居高不下；随后的小样本研究说明缺血发黑的卵巢在复位后多数能恢复功能，于是当代的原则变成复位与保留而非切除。这段历史的教训是本章反复出现的主题：在妇科，最常见的伤害不是手术技巧的失败，而是把女性的主诉当作不可靠的资料；把她的疼痛与出血记录为需要解释的事实，才是诊断的起点。**
:::
::: summary
- 异常子宫出血用模式加九个字母描述；青春期的大量出血要查凝血，四十岁以上要取内膜。
- 逐年加重的经期疼痛伴排便痛或深部性交痛即可高度可疑内膜异位症，超声正常不能排除。
- 疼痛的程度与术中所见不平行；激素抑制是长期管理的一线，手术有明确门槛而非默认。
- 育龄女性的任何盆腔包块先查妊娠试验；简单的小囊肿观察，畸胎瘤考虑择期剥除。
- 卵巢扭转靠病史诊断：突发剧痛伴呕吐、发作后自行缓解、超声血流存在也不能排除；处理是复位并保留卵巢。
- 肌瘤的治疗按位置与生育意愿分层，纠正缺铁与减少出血同样重要，子宫切除是选项而非失败。
:::

## 练习

::: exercise 判断原发性还是继发性 {level=1}
三份病史：16岁，自初潮起经期第一天绞痛，止痛药有效；34岁，近四年疼痛提前三天开始且逐年加重；45岁，疼痛伴经量多与子宫均匀增大。请各给类别与首要检查。
::: solution
**第一人符合原发性痛经：自初潮起、与经期重合、药物有效、查体正常；不需要影像，但如果止痛药效果减退或影响上学，则重新评估并在青少年中考虑内膜异位症与梗阻性畸形。第二人是典型的继发性、逐年加重、疼痛跨越经期前后——高度提示内膜异位症（在深部病灶上伴排便痛者更甚）；首要的检查是盆腔的触诊（在骶韧带的结节与触痛）与定向的超声（在卵巢的内膜样囊肿与深部病灶），并按她的生育计划开始激素的抑制，诊断性治疗是合理的第一步。第三人提示腺肌病：疼痛伴经量多与子宫均匀增大；需要超声（在肌层的不均与小的囊样间隙与结合带的增厚）与血相与铁的评估，并排除内膜的病变（在四十岁以上）。共同的一条：这三个人都需要一个明确的名字与被相信的治疗计划，而不是“忍一忍”（[[#def-pain]]、[[clinical-skills/history-taking]]、[[clinical-skills/medical-imaging]]）。**
:::

::: exercise 选择避孕与出血的方案 {level=2}
一名39岁女性经量多伴痛经，已完成生育但不愿意切除子宫；她有偏头痛伴先兆。请给出方案的次序与理由。
::: solution
**她的偏头痛伴先兆排除了含雌激素的复方方法（在缺血性卒中的风险上），这一点要先说，因为它常常被忽略（[[#def-bleeding]]、[[obstetrics-gynaecology/contraception-fertility]]）。次序：一线是左炔诺孕酮的宫内系统，它对经量与痛经的效果持久且满足她保留子宫的意愿；放置前需要排除宫腔的变形（在有肌瘤者用超声评估）；若不能放置或不愿放，可用孕激素的口服方案（在若干体系中的连续或经期的给药）或单纯孕激素的注射与埋植（需注意不规律出血的告知与接受度）；经期的氨甲环酸与非甲体抗炎药是对症的有效加项，且不涉及激素。要明确她不需要避孕时这些药同样能治出血（因为很多女性拒绝“避孕药”这个名字，而解释其用途能提高依从）。若药物失败，再谈宫腔镜的评估（在黏膜下的肌瘤与息肉上）、子宫内膜的去除（在若干体系中的适应与限制）与子宫的动脉栓塞；把子宫切除作为最后但仍合理的选项说明，并记录她已经了解其不可逆。随访用出血的日历与三个月的血相与铁蛋白，同时筛查甲状腺功能与（在溢乳与闭经时的）催乳素（[[endocrine/reproductive-endocrinology]]、[[pharmacology/adverse-reactions]]、[[nervous-system/headache-pain]]）。**
:::
:::

::: exercise 处理妊娠合并的附件包块 {level=2}
一名31岁的初孕妇十周，超声见右附件六厘米的单纯囊肿；她说“能不能现在开刀拿掉，我怕它扭”。请给出处置与谈话。
::: solution
**多数妊娠期的单纯囊肿是黄体的，会在十六周前后自行缩小，因此默认的处置是观察（[[#def-lumps]]、[[obstetrics-gynaecology/early-pregnancy]]）。谈话的要点：现在手术有麻醉与手术与流产的风险，而她这个大小与形态的囊肿扭转的概率不高；若在孕期需要手术，第二孕期（在若干的十四到二十周之间）是相对安全的窗口，腹腔镜在有经验的中心可用。什么情况下改变策略：持续或反复的疼痛（在扭转的可能上）、囊肿迅速增大或形态可疑（在实性的成分与乳头与厚的分隔上）、以及直径明显超过若干厘米的畸胎瘤。要交代她自己识别的信号（突发的剧痛、呕吐、发热），并说明这些情况下手术不会因为怀孕而被推迟——保住 母亲 与减轻痛苦都可以通过及时的处理实现。产科一侧的记录要写明囊肿的大小与位置与（在需要时的）随访的超声时间，以免分娩时无人知道它存在；若她是辅助生殖后妊娠，则双侧的黄体囊肿更常见且更大，更倾向观察（[[clinical-skills/communication]]、[[clinical-skills/medical-imaging]]、[[clinical-skills/records-handover]]）。**
:::

::: exercise 审查一次延误 {level=3}
一名36岁女性在内膜异位症的诊断前就诊十九次、被说过“这是你的心理问题”，她提出正式投诉。请主持这次审查并提出五项系统改动。
::: solution
**审查的框架不是“谁错了”而是“哪些环节允许了这一串否认”（[[#def-pain]]、[[clinical-skills/patient-safety]]）。要读的十九次记录：她的描述是否被原文记录；每次的处理是否有一个未完成的动作与责任人；检查的正常结果是否被写成“没有问题”而不是“尚未发现”；谁提出过内膜异位症的可能、是否被上级驳回；以及她是否被转诊过（并被如何解释拒绝）。五项改动：一，把“逐年加重的经期疼痛”作为疼痛的分诊关键词，规定其诊断路径与不做的事（在不用一次正常超声结束讨论）。二，规定病历必须记录患者的主诉原句与疼痛对功能的影响，使十七次就诊的模式在下一个人眼中可见。三，规定“排除性的语言”（在“检查都正常”）之后必须写“考虑什么、下一步是什么、何时复评”。四，给门诊的医生一次关于内膜异位症与慢性疼痛的培训，内容包括把疼痛当作真实的、以及在无客观体征时如何给治疗。五，把患者的报告作为服务的常规输入：让她参与一次讨论并把她写的那句话放进培训的 slides（在若干体系中这比任何通知都有效）。评价：同类投诉的再发与她的十九次就诊是否可以被压缩为三次；同时公开一条指标——从首次主诉到开始规范治疗的间隔（按年龄分层）。要对她说的一句话是：延误不是她的表达不足造成的（[[public-health/health-systems-economics]]、[[clinical-skills/records-handover]]、[[medical-ethics-law/ethical-principles]]）。**
