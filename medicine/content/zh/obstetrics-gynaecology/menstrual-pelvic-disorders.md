月经过多、痛经、月经不规律和盆腔痛是妇女就医最常见的原因之一，也是最常被轻视的疾病之一。许多妇女被告知月经量多或痛经是正常的，要等上好几年才被诊断出子宫内膜异位症，或才得到对出血所致缺铁的治疗。本章中的疾病很少致命，但会影响工作、学业、人际关系和生育力，而且其中大多数是可以治疗的。

每种症状的处理思路都一样。首先确定什么是正常的，然后排除妊娠，在相关时排除癌症，再用一个分类系统逐一梳理病因，最后提供符合妇女本人优先需求的治疗：控制出血、缓解疼痛、避孕或生育。月经周期的激素调控见[[endocrine/reproductive-endocrinology]]；妇科恶性肿瘤见[[obstetrics-gynaecology/gynaecological-cancer]]。

## 正常月经周期

FIGO系统（2018年）用四个特征描述正常月经：

| 特征 | 正常 |
|---|---|
| 频率 | 每24至38天 |
| 持续时间 | 不超过8天 |
| 规律性 | 最短和最长周期相差不超过7至9天 |
| 经量 | 妇女本人不觉得量多 |

两次月经之间的出血（**经间期出血**）和性交后的出血（**性交后出血**）都不正常，需要评估，因为它们可能由宫颈或子宫内膜病变（包括癌症）引起。

## 异常子宫出血

::: definition 月经过多与PALM–COEIN {#def-hmb}
**月经过多（HMB）**是指干扰妇女身体、社交、情感或物质生活质量的过多月经失血（NICE NG88，《月经过多》，2018年，2021年更新）。它以对生活的影响来定义，而不是以测得的量来定义。研究中曾使用每个周期失血超过80 mL作为标准。

FIGO的**PALM–COEIN**系统对育龄妇女异常子宫出血的病因进行分类：
- **结构性（PALM）**：**P**息肉（polyp）、**A**子宫腺肌病（adenomyosis）、**L**平滑肌瘤（leiomyoma，即子宫肌瘤）、**M**恶性肿瘤和增生（malignancy and hyperplasia）。
- **非结构性（COEIN）**：**C**凝血功能障碍（coagulopathy）、**O**排卵功能障碍（ovulatory dysfunction）、**E**子宫内膜疾病（endometrial disorders）、**I**医源性（iatrogenic，例如抗凝药或激素）以及**N**未分类（not otherwise classified）。
:::

### 评估

病史包括出血的模式和影响（经血涌出、血块、夜间需要更换卫生用品、因此请假）、贫血症状、疼痛、压迫症状、经间期或性交后出血、避孕情况和生育计划、用药，以及出血性疾病的症状。NICE建议：

- 所有HMB妇女都查**全血细胞计数**，并治疗缺铁；
- 自初潮起就有HMB、或个人或家族史提示出血性疾病的妇女，检查**凝血功能障碍**，尤其是血管性血友病；
- 如果腹部可触及子宫、检查发现盆腔包块，或症状提示子宫肌瘤或子宫腺肌病等结构性病因，做**盆腔超声**；
- 如果怀疑黏膜下肌瘤、息肉或子宫内膜病变，例如持续的经间期出血，做**门诊宫腔镜检查**；
- 对有子宫内膜癌危险因素的妇女做**子宫内膜活检**，例如45岁或以上有持续经间期出血或HMB治疗失败，或较年轻但有肥胖和无排卵。

### 缺铁

HMB是育龄妇女缺铁性贫血最常见的原因，算一算就明白为什么。血红蛋白为130 g/L的血液，每毫升约含0.45 mg铁。妇女每天还从皮肤、肠道和尿液中丢失约1 mg铁。而她的饮食通常每天只能让她吸收约1–2 mg。

::: example 月经过多与贫血 {#ex-hmb}
一位42岁妇女两年来月经越来越多，经血渗透衣物并有血块。她感到疲倦，上楼梯时气促。她的月经规律，无经间期出血。血红蛋白92 g/L，平均红细胞体积72 fL，铁蛋白6 µg/L。检查时腹部未触及子宫。她不想再要孩子。应如何评估和治疗？
::: solution
**评估。** 她患有HMB伴**缺铁性贫血**。她的月经规律、无经间期出血、子宫不能触及，这些使重大结构性病因的可能性较小；但由于她已40多岁且有症状，做盆腔超声评估有无子宫肌瘤或子宫腺肌病是合理的。如果超声提示黏膜下肌瘤或息肉，则需门诊宫腔镜检查。如果她有子宫内膜癌的危险因素或一线治疗失败，则需要子宫内膜活检。

**治疗。**
1. **补铁**：口服铁剂（每日一次或隔日一次可提高吸收和耐受性），并给予饮食建议；如果她不能耐受或吸收口服铁剂，或需要迅速纠正，则静脉补铁。
2. **出血**：如果子宫正常或肌瘤较小，NICE推荐**LNG-IUS**作为一线治疗；它能大幅减少失血，同时提供避孕。替代方法有经期使用氨甲环酸或甲芬那酸（mefenamic acid）等NSAID（非激素类），无禁忌证时使用复方激素避孕，或周期性口服孕激素。
3. 如果药物治疗失败或她倾向于手术，可讨论**子宫内膜消融术**或**子宫切除术**。

她的月经过多已经造成了可测量的健康问题，应当治疗，而不是被当作正常现象接受。
:::
:::

## 子宫肌瘤与子宫腺肌病

**子宫肌瘤（子宫平滑肌瘤）**是子宫肌层的良性肿瘤。它们非常常见，在绝经前随年龄增长而增多，在黑人妇女中更常见、更大且发病更早。按位置描述为：**黏膜下**（突入宫腔）、**肌壁间**（位于肌壁内）和**浆膜下**（从外表面突出，有时有蒂）。它们的生长依赖雌激素和孕酮，因此绝经后会缩小。

许多肌瘤没有症状。出现症状时，主要问题是**月经过多**（尤其是黏膜下肌瘤）、**压迫症状**（尿频、便秘、腹部包块）以及**生育力低下或流产**，主要见于使宫腔变形的黏膜下肌瘤。妊娠期间，肌瘤可因生长超过其血供而发生**红色变性**，引起急性疼痛。

治疗取决于症状、大小和位置，以及妇女是否希望保留生育力：
- **药物**：上述HMB的治疗；**GnRH激动剂**通过抑制卵巢激素使肌瘤缩小，但会引起绝经症状和骨量丢失，因此短期使用，常用于术前；**瑞卢戈利复方疗法（relugolix combination therapy）**（一种口服GnRH拮抗剂，加用反向添加的雌二醇和炔诺酮）被NICE推荐用于中至重度症状。由于罕见的严重肝损伤，醋酸乌利司他在英国的使用受到限制。
- **手术和放射介入**：黏膜下肌瘤的**宫腔镜切除术**；**子宫肌瘤剔除术**（切除肌瘤，保留子宫）；由介入放射科医生施行的**子宫动脉栓塞术**；以及作为根治方法的**子宫切除术**。

**子宫腺肌病**是指子宫肌层内存在子宫内膜组织。它导致子宫增大、压痛、"质软饱满"，月经量多且痛经，最常见于四十多岁的经产妇。通过超声或MRI诊断。治疗与HMB相似，LNG-IUS常常有效；子宫切除术是唯一的根治方法。

## 子宫内膜异位症

::: definition 子宫内膜异位症 {#def-endometriosis}
**子宫内膜异位症**是指子宫外存在子宫内膜样组织，引起慢性炎症反应。它最常累及盆腔腹膜、卵巢（在卵巢形成称为**子宫内膜异位囊肿**的囊肿）、子宫骶韧带和子宫直肠陷凹，有时累及肠道、膀胱或远处部位。它影响约十分之一的育龄妇女。
:::

::: theorem 子宫内膜异位症依赖雌激素 {#thm-endometriosis}
异位病灶像子宫内膜一样，随卵巢激素的周期性变化而生长和出血。因此，抑制排卵或月经的治疗可以缓解症状，而症状通常在绝经后消退。激素治疗能抑制疾病但不能治愈，所以停止治疗后症状常常复发。
:::

::: proof
关于子宫内膜组织如何到达盆腔，最常见的解释是**经血逆流**：经血经输卵管倒流，这在大多数妇女中都会发生。在一些妇女中，由于免疫、遗传或局部因素，这些细胞种植并存活下来。其他理论，包括腹膜化生以及经血液或淋巴播散，解释了远处部位的病灶。一旦形成，病灶表达雌激素受体，并且不同寻常地拥有自己的芳香化酶，在局部合成雌激素。每个周期，它们增生并向周围组织出血。血液和包括前列腺素在内的炎症介质引起疼痛、纤维化和粘连，把盆腔器官粘连在一起。通过抑制排卵或诱导闭经来去除周期性刺激，可以中止这种出血和炎症的循环，这就是为什么复方激素避孕、孕激素、LNG-IUS和GnRH类似物都有帮助。然而，病灶仍然存在，当卵巢功能恢复时可被重新激活。
:::

**症状**包括严重痛经，常在月经前开始并持续整个经期；**深部性交痛**（性交时盆腔深处疼痛）；慢性盆腔痛；经期排便痛或排尿痛；以及生育力低下。有些妇女没有症状。症状的严重程度与病变范围相关性不好。在英国，从首次出现症状到确诊的平均时间约为八到九年。

**诊断。** NICE NG73（《子宫内膜异位症》，2017年，2024年更新）建议临床医生根据症状怀疑子宫内膜异位症，不必等待确诊就开始治疗，并将症状严重、持续或复发的妇女转诊。经阴道超声可以发现子宫内膜异位囊肿和深部病变，但超声正常不能排除子宫内膜异位症。确诊依靠**腹腔镜**，最好同时活检，并且可以同时进行治疗。

**治疗**取决于妇女本人的优先需求：
- **疼痛**：镇痛（NSAID和对乙酰氨基酚）；用复方激素避孕（常连续使用）、孕激素或LNG-IUS进行激素治疗；这些失败时用GnRH激动剂加反向添加HRT；以及腹腔镜**切除或消融**病灶。累及肠道、膀胱或输尿管的深部子宫内膜异位症妇女应转诊至专科中心。
- **生育**：激素治疗会阻止妊娠，并不能改善生育力。对微小或轻度病变进行手术可能提高自然受孕率；较重的病变常需要IVF。

::: example 从上学时起就痛经 {#ex-endometriosis}
一位27岁妇女从十几岁起就痛经，现在严重到尽管服用布洛芬，每月仍要请两天假。她还有性交时深部疼痛和经期排便痛。她尝试受孕已六个月。盆腔检查后穹窿压痛，经阴道超声显示右卵巢有一个4 cm的囊肿，内部为均匀的低回声。可能的诊断是什么？你会如何计划她的诊疗？
::: solution
**诊断。** 严重痛经、深部性交痛、经期排便痛和后穹窿压痛提示**子宫内膜异位症**，而卵巢囊肿呈"磨玻璃样"回声是**子宫内膜异位囊肿**的典型表现。排便痛和后穹窿压痛提示可能有累及直肠阴道隔或肠道的深部病变。

**计划。** 应将她转诊至有子宫内膜异位症诊治专长的妇科，并安排专科影像检查（专家超声或MRI）以明确深部病变的范围。由于她正在尝试受孕，目前不宜使用会阻止妊娠的激素治疗；疼痛用镇痛药处理。在任何卵巢手术之前都应评估她的卵巢储备，因为切除子宫内膜异位囊肿可能使其下降。应与她和她的伴侣讨论腹腔镜手术（诊断、切除病灶，可能同时切除子宫内膜异位囊肿）或转诊进行生育评估和IVF的选择。应承认她多年来经受的疼痛，并为她提供支持组织的信息。
:::
:::

## 痛经

**原发性痛经**是没有盆腔病变的经期疼痛。它通常在初潮后一两年内开始，即周期开始有排卵之后。它由子宫内膜前列腺素引起，后者导致子宫收缩和缺血。治疗用抑制前列腺素合成的NSAID和激素避孕。**继发性痛经**由盆腔病变引起，如子宫内膜异位症、子宫腺肌病、子宫肌瘤或盆腔炎性疾病。提示继发性病因的特征包括：初潮多年后才开始、疼痛逐渐加重、深部性交痛、经间期出血，以及对NSAID和避孕药无效。

## 多囊卵巢综合征

**多囊卵巢综合征（PCOS）**是育龄妇女最常见的内分泌疾病，影响约10%–13%的妇女。它兼有排卵功能障碍、雄激素过多和胰岛素抵抗。

::: definition 鹿特丹标准 {#def-pcos}
在排除其他病因后，成人具备以下**三项中的两项**即可诊断PCOS：
1. **稀发排卵或无排卵**，通常表现为月经周期不规律。
2. **临床或生化高雄激素血症**：多毛、痤疮或雄激素性脱发，或游离睾酮等雄激素水平升高。
3. 超声显示**多囊卵巢形态**（使用现代设备时至少一侧卵巢有20个或更多卵泡），或者根据2023年国际循证指南，成人抗米勒管激素水平升高。

在青少年中，需要同时具备月经周期不规律和高雄激素血症，且不使用超声和AMH，因为初潮后几年内出现多个卵泡是正常的。
:::

必须排除可能表现相似的其他疾病：甲状腺疾病、高催乳素血症、非经典型先天性肾上腺皮质增生症、库欣综合征，以及在男性化进展迅速或睾酮很高时的分泌雄激素的肿瘤。

其机制涉及一个恶性循环。胰岛素抵抗导致胰岛素水平升高，后者刺激卵巢卵泡膜细胞产生雄激素，并减少肝脏生成性激素结合球蛋白，使游离雄激素增加。LH脉冲频率增加也促进雄激素生成。局部雄激素水平高使卵泡发育停滞，于是许多小卵泡堆积，排卵不能发生。

**远期健康。** PCOS妇女发生2型糖尿病和妊娠期糖尿病、心血管危险因素、睡眠呼吸暂停、抑郁和焦虑，以及**子宫内膜增生和子宫内膜癌**的风险增加，后者是因为没有排卵时，子宫内膜暴露于雌激素而缺乏孕酮的保护作用。

**处理**取决于妇女本人关注的问题：
- **生活方式**：超重妇女减重5%–10%可恢复排卵并改善代谢风险。
- **月经不规律和子宫内膜保护**：复方激素避孕、周期性孕激素或LNG-IUS。月经极少的妇女应至少每三到四个月诱导一次撤退性出血；如果长时间没有出血，应做超声，必要时做子宫内膜活检。
- **多毛和痤疮**：复方激素避孕、美容方法、面部毛发外用依氟鸟氨酸（eflornithine），以及抗雄激素药（必须与有效避孕同时使用，因为它们可使男性胎儿女性化）。
- **代谢风险**：定期筛查糖尿病（HbA1c或葡萄糖耐量试验）和心血管危险因素；经过挑选的妇女使用二甲双胍。
- **生育**：用来曲唑诱导排卵（[[obstetrics-gynaecology/contraception-fertility]]）。

::: example 月经不规律与痤疮 {#ex-pcos}
一位24岁妇女每两到四个月来一次月经，有持续的痤疮，下巴上有又黑又粗的毛发，她每天拔除。BMI为31。总睾酮轻度升高；TSH、催乳素和17-羟孕酮正常；妊娠试验阴性。她是否患有PCOS？优先事项是什么？
::: solution
**诊断。** 她有稀发排卵（周期两到四个月）以及临床和生化高雄激素血症（多毛、痤疮、睾酮升高）。这符合鹿特丹标准三项中的两项，因此只要排除了其他病因，无需超声即可诊断**PCOS**：她的检查已排除甲状腺疾病、高催乳素血症和非经典型先天性肾上腺皮质增生症。睾酮轻度升高且病程缓慢，不提示肿瘤。

**优先事项。** 问她最在意的是什么：毛发和痤疮、月经、将来的生育，还是体重。如果没有禁忌证，复方避孕药可以调节出血、保护子宫内膜并改善高雄激素症状。减重的生活方式支持可以改善所有表现。她应接受2型糖尿病和心血管危险因素的筛查，并被问及情绪和睡眠。应告诉她，PCOS并不意味着她不能生育：如果她以后想怀孕，诱导排卵通常是有效的。
:::
:::

## 闭经

**原发性闭经**是指第二性征正常的女孩到15岁仍无月经，或到13岁仍无第二性征发育。**继发性闭经**是指既往月经规律的妇女停经三个月，或既往月经不规律的妇女停经六个月。

第一项检查永远是**妊娠试验**。然后可按层面梳理病因：
- **下丘脑**：体重过低、运动过度和应激（功能性下丘脑性闭经），促性腺激素低或正常，雌激素低。
- **垂体**：高催乳素血症（催乳素瘤或抗精神病药等药物），罕见情况下为其他垂体疾病，包括严重产后出血后的希恩综合征。
- **卵巢**：PCOS、早发性卵巢功能不全（[[obstetrics-gynaecology/menopause]]），以及原发性闭经中的特纳综合征。
- **子宫和流出道**：手术或感染后的宫腔粘连（Asherman综合征），以及原发性闭经中的先天性异常，如处女膜闭锁或子宫缺如。

初始检查为FSH、LH、雌二醇、催乳素、TSH和睾酮，再根据结果进一步检查。

::: example 八个月没有月经 {#ex-amenorrhoea}
一位20岁的大学生每周跑步约60公里，已经八个月没有月经；之前她的周期规律。BMI为17.5。妊娠试验阴性。FSH和LH处于正常低值，雌二醇低，催乳素、TSH和睾酮正常。解读结果并概述处理。
::: solution
**解读。** 继发性闭经（月经规律后停经八个月）伴雌二醇低、促性腺激素正常偏低，指向卵巢以上层面的问题。催乳素和甲状腺功能正常，又有体重低和大运动量训练的病史，可能的诊断是**功能性下丘脑性闭经**：能量可利用度低抑制了GnRH的脉冲式释放。这种模式不同于早发性卵巢功能不全（FSH高），也不同于PCOS（雌激素通常正常，雄激素常升高）。

**处理。** 主要的担忧是**骨骼健康**：在骨量本应增加的年龄雌激素偏低，会导致骨密度降低和应力性骨折。处理的目标是通过增加摄入和减少训练来恢复能量可利用度，配合营养师支持，并在相关时评估有无进食障碍，询问时应注意方式。如果闭经已持续六个月或以上，应考虑骨密度扫描。如果月经不能恢复，需要专科关于激素替代的建议；复方避孕药会产生撤退性出血，但不能可靠地保护骨骼，而且会掩盖恢复情况。如需避免妊娠，她也需要避孕，因为排卵可能在第一次月经之前恢复。
:::
:::

## 阴道分泌物与盆腔炎性疾病

生理性分泌物随周期变化。分泌物改变有三种常见的感染性原因：**细菌性阴道病**（稀薄、白色、有鱼腥味的分泌物，阴道pH高于4.5；是厌氧菌过度生长，不是性传播感染）、**外阴阴道念珠菌病**（稠厚白色分泌物，伴瘙痒和疼痛；pH正常）和**滴虫病**（泡沫状黄绿色分泌物；经性传播）。分泌物也可以是衣原体和淋球菌宫颈感染的首发表现。

**盆腔炎性疾病（PID）**是从宫颈上行至子宫内膜、输卵管和卵巢的感染。沙眼衣原体（*Chlamydia trachomatis*）和淋病奈瑟菌（*Neisseria gonorrhoeae*）是重要的病原体，还有生殖支原体（*Mycoplasma genitalium*）和厌氧菌，但常常找不到病原体。症状为下腹痛、深部性交痛、异常出血和分泌物，检查时有宫颈举痛和附件压痛。由于未经治疗的PID后果严重，包括**输卵管性不孕**、**异位妊娠**和**慢性盆腔痛**，又没有任何检查可以排除它，因此在临床怀疑时即开始治疗，按照国家指南（BASHH）使用覆盖可能病原体的抗生素方案。必须排除妊娠，性伴侣需要检测和治疗。重症、输卵管卵巢脓肿或妊娠时需要住院。见[[infectious-diseases/sexually-transmitted-infections]]。

::: warning 多普勒血流正常时也可能发生卵巢扭转
**卵巢扭转**是卵巢沿其蒂扭转，引起突然剧烈的单侧盆腔痛，常伴恶心呕吐，通常发生在因囊肿而增大的卵巢上。它是外科急症，因为卵巢可能梗死。超声可显示卵巢增大，但扭转的卵巢多普勒血流可能正常，因为扭转可能先阻塞静脉和淋巴回流，再影响动脉流入，或者扭转可能是间歇性的。当临床表现提示扭转时，患者需要诊断性腹腔镜检查，通常应将卵巢复位并保留，而不是切除，即使它颜色发暗。
:::

## 盆腔器官脱垂

**盆腔器官脱垂**是指子宫、膀胱（膀胱膨出）、直肠（直肠膨出）或阴道穹窿下降进入阴道。它由盆底肌肉和结缔组织支持结构减弱引起，分娩、衰老、绝经、肥胖、慢性咳嗽和便秘是危险因素。症状包括阴道内有肿物感或下坠感、排尿和排便症状以及性生活困难。治疗从**盆底肌训练**和阴道子宫托到手术修补不等。自2018年起，英国限制使用经阴道网片治疗脱垂，原因是严重的并发症。尿失禁见[[renal/urinary-tract]]。

::: quiz
一位30岁妇女下腹痛10天，有新出现的阴道分泌物和性交痛。体温37.8 °C，宫颈举痛，双侧附件压痛。妊娠试验阴性。最好的下一步是什么？
- [ ] 等衣原体和淋球菌检测结果出来后再开始治疗。
- [x] 取拭子后，按国家指南开始盆腔炎性疾病的经验性抗生素治疗，并安排通知性伴侣。
- [ ] 治疗前安排诊断性腹腔镜检查。
- [ ] 安慰她，因为拭子阴性就可以排除PID。
::: solution
这是PID的典型表现。取拭子后应在临床怀疑时就开始治疗，因为延误会增加输卵管损伤的风险，而拭子阴性并不能排除诊断。约72小时后应复查，如病情很重则收入院，她的性伴侣应接受检测和治疗。
:::
:::

::: history
子宫内膜异位症在十九世纪曾以各种名称被描述，包括1860年卡尔·冯·罗基坦斯基（Carl von Rokitansky）的描述，但现代的认识始于纽约的约翰·桑普森（John Sampson），他在1927年提出经血逆流是其病因，并命名了子宫内膜异位囊肿。多囊卵巢由芝加哥的欧文·斯坦（Irving Stein）和迈克尔·利文撒尔（Michael Leventhal）于1935年描述，对象是七名有闭经、多毛和卵巢增大的妇女，他们用卵巢楔形切除术治疗这些妇女；2003年欧洲和美国生殖医学学会的鹿特丹共识制定了至今仍在使用的诊断标准，并在2018年和2023年的国际指南中加以完善。子宫动脉栓塞治疗子宫肌瘤由雅克·拉维纳（Jacques Ravina）于1995年在巴黎首次报告。由马尔科姆·芒罗（Malcolm Munro）主导的FIGO PALM–COEIN分类于2011年发表、2018年修订，用以取代"月经过多症（menorrhagia）"和"功能失调性子宫出血"等不统一的术语。
:::

::: summary
- 正常月经（FIGO）：周期24至38天，出血不超过8天，周期变化不超过7至9天。经间期出血和性交后出血需要评估。
- HMB以对生活质量的影响来定义。病因按PALM–COEIN分类。所有HMB妇女都查全血细胞计数；超声、宫腔镜和活检有针对性地进行。
- 无重大结构性病变时，LNG-IUS是HMB的一线治疗；氨甲环酸、NSAID、CHC和孕激素为替代选择；内膜消融和子宫切除是手术选择。
- 子宫肌瘤是常见的子宫肌层良性肿瘤；黏膜下肌瘤引起HMB和生育力低下。治疗包括药物治疗、肌瘤剔除、栓塞和子宫切除。
- 子宫内膜异位症影响约十分之一的妇女；它引起痛经、深部性交痛、慢性疼痛和生育力低下；它依赖雌激素；在临床怀疑时即开始治疗，腹腔镜是确诊检查。
- 排除其他病因后，符合鹿特丹标准三项中的两项即可诊断PCOS。它带来代谢和子宫内膜风险；处理遵循妇女本人的优先需求。
- 闭经在妊娠试验之后按层面逐一检查。
- PID在临床怀疑时即治疗；未经治疗会导致输卵管性不孕、异位妊娠和慢性疼痛。
- 卵巢扭转是外科急症，多普勒血流正常不能排除它。
:::

## 习题

::: exercise 每个周期丢失的铁 {level=1 check="54"}
按每毫升血液约含0.45 mg铁计算，失血量为120 mL的一次月经丢失多少毫克铁？
::: solution
$120 \times 0.45 = 54$ mg。按28天周期平均，每天约1.9 mg，再加上每天约1 mg的基础丢失，超过了大多数饮食所能提供的量。
:::

::: exercise PALM–COEIN {level=1}
用PALM–COEIN对以下各例异常出血的可能病因分类：(a) 一位母亲患血管性血友病的妇女，自初潮起月经过多；(b) 一位PCOS妇女不规则、不可预测的出血；(c) 一位服用华法林（warfarin）的妇女大量出血；(d) 经间期出血，宫腔镜下见1 cm子宫内膜病灶。
::: solution
(a) **C**：凝血功能障碍。(b) **O**：排卵功能障碍。(c) **I**：医源性。(d) **P**：息肉，待组织学检查排除**M**，即恶性肿瘤或增生。
:::

::: exercise 闭经的定义 {level=1}
给出原发性和继发性闭经的定义，并说出每例都要做的第一项检查。
::: solution
**原发性闭经**：第二性征正常者到15岁仍无月经，或无第二性征发育者到13岁仍无月经。**继发性闭经**：既往月经规律者停经三个月，或既往月经不规律者停经六个月。第一项检查永远是**妊娠试验**。
:::

::: exercise 原发性还是继发性痛经？ {level=2}
一位35岁妇女一生中月经都无痛，但近两年来痛经越来越重，经量增多，检查发现子宫增大、压痛、呈球形。可能的诊断是什么？如何确诊？
::: solution
初潮多年后才出现疼痛、症状进行性加重、子宫增大呈球形且有压痛，指向**继发性痛经**，最可能由**子宫腺肌病**引起，也可能合并子宫肌瘤。经阴道超声可以确诊，超声不能确定时做MRI。子宫内膜异位症常同时存在，如果她有性交痛或其他盆腔症状应予考虑。
:::
:::

::: exercise PCOS的子宫内膜保护 {level=2}
一位29岁PCOS妇女去年只来过两次月经，不想使用激素避孕。为什么这令人担忧？你会提供什么？
::: solution
没有排卵就没有孕酮使子宫内膜转化并脱落，因此子宫内膜暴露于无对抗的雌激素之下，**子宫内膜增生和子宫内膜癌**的风险增加。应为她提供孕激素，至少每三到四个月诱导一次撤退性出血，或者使用LNG-IUS，它可以在不使用全身雌激素的情况下保护子宫内膜。由于她长时间没有月经，做经阴道超声测量子宫内膜厚度是合理的，如果增厚则做子宫内膜活检。在适当的情况下减重可能恢复排卵。
:::
:::

::: exercise 一位子宫肌瘤患者 {level=2}
一位38岁妇女子宫如孕12周大小，月经过多，尿频，有一个7 cm的肌壁间肌瘤。她希望保留妊娠的可能。讨论她的选择。
::: solution
当肌瘤很大或使宫腔变形时，LNG-IUS效果较差且更易脱落，而治疗出血的药物（氨甲环酸、NSAID、CHC）不能解决压迫症状。**瑞卢戈利复方疗法**或GnRH激动剂可以使肌瘤缩小、减少出血，但由于它们会阻止排卵，对想要妊娠的人来说并非长期解决办法。由于她希望保留生育力，**子宫肌瘤剔除术**通常是首选的根治性选择；它有出血（罕见情况下导致子宫切除）和肌瘤复发的风险，根据手术范围，以后妊娠可能需要计划剖宫产。**子宫动脉栓塞术**可以保留子宫，但对生育力的影响不太确定，因此对计划妊娠的妇女一般不太推荐。如果她希望保留生育力，子宫切除术不合适。
:::
:::

::: exercise 铁平衡 {level=3 check="round(28*(1.5-1)/0.45)"}
使用图中的模型（基础铁丢失每天1 mg，每毫升血液约含铁0.45 mg，28天周期），求出使平均每日需要量等于每天1.5 mg吸收量的每周期月经失血量。答案以mL表示，取最接近的整数。并说明其含义。
::: hint
解方程$1 + 0.45x/28 = 1.5$求$x$。
:::
::: solution
$0.45x/28 = 0.5$，所以$x = 0.5 \times 28 / 0.45 \approx 31.1$，即每个周期约**31 mL**。超过这一水平，按模型计算她丢失的铁多于从典型饮食中吸收的铁。许多妇女的失血量大约就是这么多，这就是为什么即使没有HMB，缺铁在育龄妇女中也如此常见；也是为什么常常失血超过80 mL的HMB妇女如此容易贫血。实际上，储备下降时吸收会增加，这能延缓但不能阻止大量丢失时铁的耗竭。
:::
:::

::: exercise 急性盆腔痛 {level=3}
一位19岁女性在踢足球时突然出现剧烈的右侧盆腔痛，伴呕吐。妊娠试验阴性。无发热。超声显示右卵巢7 cm囊肿，动脉多普勒血流正常。给出鉴别诊断和你的处理。
::: solution
**鉴别诊断。** **卵巢扭转**最重要也最可能：运动中突然剧烈疼痛伴呕吐，卵巢因大囊肿而增大。多普勒血流正常不能排除它。其他可能有囊肿内出血或破裂、阑尾炎，以及在妊娠试验阴性时可能性较小的异位妊娠。起病如此突然且无发热，PID的可能性不大。

**处理。** 镇痛和止吐，建立静脉通路并抽血（全血细胞计数、C反应蛋白、血型鉴定与抗体筛查），紧急请妇科会诊。由于临床表现提示扭转，她需要立即进行**诊断性腹腔镜检查**。如果卵巢扭转，将其复位，可切除囊肿（囊肿剔除术），即使卵巢颜色暗紫也要保留，因为大多数可以恢复。囊肿送组织学检查。应告诉她，目标是保留她的卵巢和生育力。
:::
