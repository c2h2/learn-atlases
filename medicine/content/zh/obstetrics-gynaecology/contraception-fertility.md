本章讨论同一生理过程的两个方面。避孕通过打断从排卵到着床这条链条中的某一环节来防止妊娠；而当妊娠未能发生时，生育力低下的诊疗则寻找链条中断裂的环节，并加以修复或绕过。两者都依赖于月经周期和下丘脑-垂体-卵巢轴，见[[endocrine/reproductive-endocrinology]]。

这两个领域也都是由数字推动良好咨询的领域。一种"有效率99%"的方法，在一年的实际使用中可能有十分之一的妇女避孕失败；而一对在一年后被告知"不孕"的夫妇，通常在下一年仍有相当大的机会自然受孕。临床医生需要了解这些数字并清楚地加以解释。本章中的英国实践遵循性与生殖保健学会（FSRH）、《英国避孕方法使用医学适用标准》（UKMEC，2016年，2019年修订）和NICE CG156（《生育问题》，2013年，2017年更新）。

## 避孕方法如何起作用

每种方法阻断生殖过程中的一个或多个步骤：

- **抑制排卵。** 复方激素避孕（避孕药、贴片和阴道环）、注射剂、皮下埋植剂和去氧孕烯单纯孕激素避孕药通过对下丘脑和垂体的负反馈，抑制周期中期的LH峰。
- **阻挡精子。** 孕激素使宫颈黏液变稠，不利于精子通过。屏障方法（避孕套、子宫帽）在物理上将精子与宫颈隔开。输精管结扎术使射出的精液中不含精子。
- **阻止受精或着床。** 宫内节育器释放的铜离子对精子和卵子有毒性，并在子宫内膜引起炎症反应。左炔诺孕酮宫内节育系统主要作用于子宫内膜和宫颈黏液。
- **通过安排时间或阻断输卵管来阻止受精。** 易受孕期知晓法在排卵前后避免性交；女性绝育术阻塞输卵管。

## 衡量有效性

::: definition 完美使用、典型使用与Pearl指数 {#def-efficacy}
**完美使用失败率**：正确并坚持使用某种方法时，第一年内妊娠的妇女百分比。

**典型使用失败率**：在第一年的真实世界使用中妊娠的妇女百分比，包括漏服药片、注射延迟和不坚持使用避孕套等情况。

**Pearl指数**：每100妇女年使用中的妊娠次数，
$$
\text{Pearl 指数} = \frac{\text{妊娠次数} \times 1200}{\text{暴露总月数}}.
$$ {#eq-pearl}
:::

完美使用和典型使用之间的差距是咨询的关键点。对于依赖使用者的方法，典型使用的有效性要低得多。对于不依赖使用者的长效方法，两者几乎相同。

| 方法 | 典型使用（第一年妊娠%） | 完美使用（%） |
|---|---|---|
| 皮下避孕埋植剂 | 0.05 | 0.05 |
| 左炔诺孕酮宫内节育系统（LNG-IUS） | 0.2 | 0.2 |
| 含铜宫内节育器（Cu-IUD） | 0.8 | 0.6 |
| 女性绝育术 | 0.5 | 0.5 |
| 输精管结扎术 | 0.15 | 0.1 |
| 单纯孕激素注射剂 | 6 | 0.2 |
| 复方避孕药、贴片或阴道环 | 9 | 0.3 |
| 单纯孕激素避孕药 | 9 | 0.3 |
| 男用避孕套 | 18 | 2 |
| 易受孕期知晓法 | 24 | 0.4–5 |
| 不采取任何方法 | 85 | 85 |

这些是FSRH和NHS引用的数字，来自Trussell对美国的估计（2011年）；它们是近似值，在不同人群中有所不同。

::: theorem 小的年风险会累积 {#thm-cumulative}
如果一种方法的年失败率为$p$，且每年风险大致相同，则$n$年内至少发生一次妊娠的概率为
$$
P(n \text{ 年内妊娠}) = 1 - (1-p)^n.
$$ {#eq-cumulative}
当$p$和$n$较小时，它接近$np$。
:::

::: proof
单独一年中不发生妊娠的概率为$1-p$。如果各年相互独立，连续$n$年都不发生妊娠的概率为乘积$(1-p)^n$，而至少发生一次妊娠的概率为其补数。当$p$很小时，二项式展开给出$(1-p)^n \approx 1 - np$，因此累积风险约为$np$。实际上，随着夫妇使用某种方法的经验增加，失败率会随时间下降，所以该公式会略微高估长期风险；但它仍然是说明以下问题的有用方法：对于一个必须多年避免妊娠的人来说，年失败率为9%的方法并不可靠。
:::

::: widget plot
f: 100*(1-(1-p/100)^x); 100*(1-(1-0.0005)^x)
x: 0, 10
y: 0, 100
sliders: p=9:0.05:30:0.05
labels: \text{年失败率为 } p\% \text{ 的方法}; \text{埋植剂（每年0.05\%）}
caption: 使用"原理"中的公式，妊娠妇女的累积百分比（纵轴）对使用年数（横轴）的关系。滑块设置典型使用的年失败率p。在避孕药的典型使用率9%时，预计五年内超过三分之一的妇女至少会妊娠一次；使用埋植剂则不到三百分之一。这是一个假设每年风险相同的简化模型。
:::

::: example 计算Pearl指数 {#ex-pearl}
在一项新型避孕阴道环的研究中，400名妇女每人使用该方法24个月，共发生12次妊娠。计算Pearl指数。
::: solution
总暴露为$400 \times 24 = 9600$个月。使用[[#eq-pearl]]，
$$
\text{Pearl 指数} = \frac{12 \times 1200}{9600} = 1.5.
$$
每100妇女年使用中有1.5次妊娠。注意这是在试验中测得的，试验中的使用通常比日常生活中更仔细；典型使用率可能更高。
:::
:::

## 各种方法

### 长效可逆避孕（LARC）

LARC方法包括皮下埋植剂、宫内方法和注射剂。由于它们不依赖每日的操作，埋植剂和宫内方法是最有效的可逆方法，NICE和FSRH建议向所有寻求避孕的妇女提供这些方法。

- **皮下埋植剂**是一根含依托孕烯（etonogestrel）的柔软小棒，植入上臂皮下，有效期三年。它抑制排卵。主要缺点是出血模式不可预测，这是取出的最常见原因。取出后生育力迅速恢复。
- **LNG-IUS**向子宫内释放左炔诺孕酮（levonorgestrel）。根据装置不同，其避孕的许可使用期为5至8年。大多数使用者月经变少，许多人完全没有月经，因此它也是月经过多的一线治疗（[[obstetrics-gynaecology/menstrual-pelvic-disorders]]），并可提供激素替代治疗中的孕激素部分。
- **Cu-IUD**不含激素，根据装置不同有效期为5至10年。月经可能变多、痛经可能加重。它也是最有效的紧急避孕方法。
- **单纯孕激素注射剂**（醋酸甲羟孕酮（medroxyprogesterone acetate））每13周注射一次。它抑制排卵。它会引起骨密度轻度、基本可逆的下降，可能导致体重增加，停用后生育力可能需要长达一年才能恢复。

宫内方法的风险包括放置时疼痛、最初三周内感染（主要发生在存在性传播感染时）、脱落（约1/20）和子宫穿孔（每1000次放置中最多约2次，哺乳期妇女更常见）。如果在节育器在位时发生妊娠，异位妊娠的可能性高于通常情况，但由于妊娠极少发生，异位妊娠的绝对风险仍低于不避孕时。

### 复方激素避孕

**复方激素避孕（CHC）**含有一种雌激素（通常为炔雌醇（ethinylestradiol））和一种孕激素。它抑制排卵；孕激素还使宫颈黏液变稠。它有口服片、贴片和阴道环几种剂型。传统方案每月有七天停药期，会引起撤退性出血；FSRH支持停药期更短或更少的个体化方案，可降低漏服后排卵的机会并减少出血的次数。

除避孕外的**益处**包括月经量减少、更规律、痛经减轻，痤疮改善，以及卵巢癌、子宫内膜癌和结直肠癌风险降低，这种降低在停药后可持续多年。

**风险。** 雌激素成分增加肝脏凝血因子的生成，从而增加**静脉血栓栓塞**的风险。绝对风险很小，但取决于所含的孕激素。欧洲药品管理局（2014年）估计，每10,000名妇女每年的风险在未使用者约为2例，使用含左炔诺孕酮、炔诺酮或诺孕酯的避孕药者为5–7例，使用含去氧孕烯、孕二烯酮或屈螺酮的避孕药者为9–12例。相比之下，妊娠期和产后的风险要高得多。CHC还会轻度增加动脉疾病（卒中和心肌梗死）的风险，尤其是吸烟、患高血压或有先兆偏头痛的妇女；使用期间还会轻度增加乳腺癌和宫颈癌的风险。

::: definition 英国避孕方法使用医学适用标准 {#def-ukmec}
**UKMEC**针对每种疾病对每种方法进行分级：
- **UKMEC 1**：使用不受限制。
- **UKMEC 2**：优点通常超过理论上或已证实的风险。
- **UKMEC 3**：风险通常超过优点；使用需要专家的临床判断。
- **UKMEC 4**：不可接受的健康风险；不应使用该方法。

复方激素避孕属于UKMEC 4的情况举例：有先兆的偏头痛；年龄35岁或以上且每天吸烟15支或以上；血压达到或超过160/100 mmHg；当前或既往VTE；已知的易栓基因突变，如凝血因子V Leiden突变；当前乳腺癌；缺血性心脏病或卒中；以及哺乳期妇女产后不足六周。
:::

**药物相互作用。** 酶诱导药物，如卡马西平（carbamazepine）、苯妥英（phenytoin）、利福平（rifampicin）和圣约翰草，会加快CHC、单纯孕激素避孕药和埋植剂中激素的代谢，使其不可靠。它们不影响注射剂或宫内方法，因此服用这些药物的妇女首选后者。

### 单纯孕激素避孕药

**单纯孕激素避孕药（POP）**不含雌激素，因此大多数不能使用雌激素的妇女都可以使用，包括有先兆偏头痛的妇女、35岁以上吸烟的妇女和哺乳期妇女。去氧孕烯POP抑制排卵，延迟服药有12小时的窗口期；较老的POP主要作用于宫颈黏液，窗口期为3小时。不规则出血是主要的副作用。在英国，一些POP无需处方即可在药房购买。

### 屏障方法、易受孕期知晓法与绝育术

**避孕套**是唯一同时能预防性传播感染的方法，因此建议有风险的人在使用其他方法之外加用避孕套。**易受孕期知晓法**利用周期长度、基础体温和宫颈分泌物来识别易受孕日；它们需要培训和积极性，典型使用时有效性低得多。**女性绝育术**通过腹腔镜阻塞或切除输卵管，是永久性的，应视为不可逆；其有效性与LARC相近。**输精管结扎术**更简单，并发症更少，但要到精液分析显示没有精子后才有效，通常约需12周。

::: example 选择方法 {#ex-ukmec}
一位37岁每天吸烟20支的妇女，因月经量多且痛经，要求开始服用复方避孕药。她的血压为128/78 mmHg，BMI为27。你会给出什么建议？
::: solution
年龄35岁或以上且每天吸烟15支或以上，复方激素避孕属于**UKMEC 4**：心肌梗死和卒中的风险不可接受。不应为她提供CHC。

同样有助于缓解月经量多和痛经的合适替代方法包括**LNG-IUS**，它既是高效的避孕方法，又是月经过多的一线治疗；还有注射剂或去氧孕烯POP，它们常可减少出血。埋植剂是有效的选择，但出血不可预测。应为她提供戒烟支持。如果她戒烟至少一年，CHC的UKMEC分级会改变，但仍需评估其他危险因素。她的月经过多也应作为一个问题单独评估，包括检查全血细胞计数。
:::
:::

### 紧急避孕

紧急避孕用于无保护性交或避孕失败之后。FSRH指南描述了三种选择：

- **Cu-IUD**可在一个周期内第一次无保护性交后120小时（5天）内放置，或在最早可能的排卵日之后5天内放置。它是最有效的选择，几乎能防止所有妊娠，且不受体重或其他药物影响。之后它还能提供持续避孕。
- **醋酸乌利司他（ulipristal acetate）**是一种选择性孕激素受体调节剂，可在性交后120小时内服用。即使在LH峰之前不久服用，它也能推迟排卵。随后五天内服用孕激素会减弱其效果，因此在服用它五天后再开始激素避孕。
- **左炔诺孕酮**可在性交后72小时内服用。它推迟排卵，但一旦LH峰已经开始便无效。对BMI超过26 kg/m²或体重超过70 kg、或正在服用酶诱导药物的妇女，建议使用双倍剂量，尽管这方面的证据有限。

口服方法仅通过推迟排卵起作用，因此如果排卵已经发生则无效，也不能保护同一周期内之后的性交。

::: example 漏服药片 {#ex-missed-pills}
一位22岁妇女按传统方案服用复方避孕药：21片活性药片后停药7天。停药期后她忘了开始新的一板药，直到新一板的第3天才意识到漏服了前两片活性药片。她两天前有过无保护性交。她应该怎么做？
::: solution
在一板药开始时漏服会延长无激素间期，而此时排卵最有可能逃脱抑制。根据FSRH指南，漏服两片或以上（延迟超过48小时）时，她要立即服用最近漏服的那一片，继续服完这一板，并使用避孕套或禁欲，直到连续服用七片活性药片。由于漏服发生在第一周，而且她在延长的停药期内有过无保护性交，她还需要**紧急避孕**。Cu-IUD最有效。如果她选择口服方法，左炔诺孕酮允许她立即继续服用避孕药；如果使用乌利司他，她应等待五天后再重新开始服用避孕药，并在重新开始后的七天内使用避孕套。建议三周后做妊娠试验。这也是讨论无每月停药期的个体化方案或LARC方法的好时机。
:::
:::

## 生育力低下

::: definition 生育力低下 {#def-subfertility}
NICE将**不孕症**定义为育龄妇女在规律的无保护阴道性交一年后未能受孕，且无已知原因。人们常更倾向于使用**生育力低下**一词，因为大多数这样的夫妇并非绝对不育，许多人无需治疗也能受孕。在一般人群中，约84%的夫妇在一年的规律无保护性交内受孕，两年内约92%。
:::

当女方年龄36岁或以上，或存在已知原因时，例如闭经、既往盆腔感染或手术，或男方有隐睾或化疗史，NICE建议更早转诊。女性生育力随年龄下降，尤其是从三十五岁左右开始，因为卵子的数量和质量都在下降；这是决定任何治疗能否成功的最重要的单一因素。

**病因。** 通常引用的大致分布为：男方因素约30%，原因不明约25%，排卵障碍约25%，输卵管损伤约20%，子宫或腹膜疾病约10%。合计超过100%，因为许多夫妇存在不止一个因素。

**检查**由双方共同进行：

- **排卵。** 21至35天的规律周期通常表明有排卵。通过**黄体中期血清孕酮**确认，在下次预期月经前约7天（28天周期的第21天）采血；高于约30 nmol/L提示已排卵。周期不规律的妇女要测定促性腺激素（FSH和LH），如有症状还要查催乳素和甲状腺功能。抗米勒管激素或窦卵泡计数可估计**卵巢储备**，并预测对卵巢刺激的反应，但不能预测自然受孕的机会。
- **精液分析。** 结果与WHO（2021年）参考下限比较，包括精液量1.4 mL、浓度每毫升1600万、精子总数3900万、前向运动精子30%和正常形态精子4%。结果异常时应复查，最好在三个月后，因为精子生成大约需要这么长时间，且结果有波动。
- **输卵管通畅性。** 无已知危险因素的妇女做子宫输卵管造影（经宫颈注入造影剂的X线检查）或子宫输卵管超声造影。有危险因素的妇女，如既往盆腔感染或子宫内膜异位症，做腹腔镜加通液检查，同时可以评估和治疗其他盆腔疾病。

**治疗**取决于病因：

- **无排卵**：BMI过高或过低时优化体重；对于多囊卵巢综合征，2023年国际PCOS指南现在推荐**来曲唑（letrozole）**作为诱导排卵的一线药物，克罗米芬（clomifene）、二甲双胍、促性腺激素或腹腔镜卵巢打孔术为替代选择。下丘脑性闭经（例如体重过低所致）的妇女需要增加体重，有时需要脉冲式GnRH或促性腺激素。高催乳素血症用多巴胺受体激动剂治疗。
- **输卵管疾病**：经过挑选的病例行手术；大多数行体外受精（IVF）。输卵管积水在IVF之前要切除或夹闭，因为其中的液体会降低着床率。
- **男方因素**：纠正可逆的原因；严重异常时行**卵胞质内单精子注射（ICSI）**，即把单个精子注入每个卵子；梗阻性无精子症行手术取精；供精。
- **不明原因的生育力低下**：NICE建议在IVF之前总共尝试自然受孕两年，因为许多夫妇在这段时间内会受孕。

**IVF**包括用促性腺激素刺激卵巢、在超声引导下取卵、在实验室受精，以及将一个胚胎移植到子宫内。NICE建议为两年后仍未受孕的40岁以下妇女提供三个完整周期，为符合附加标准的40至42岁妇女提供一个周期，但各地的资助情况不同。成功率随女方年龄急剧下降。主要风险是**卵巢过度刺激综合征**（卵巢增大，液体向腹腔和胸腔转移，有血栓形成和肾损伤的风险）和**多胎妊娠**。在英国，选择性单胚胎移植已使IVF后的多胎分娩率从2000年代的约四分之一降至远低于十分之一。

::: example 一对未能受孕的夫妇 {#ex-subfertility}
一对夫妇尝试受孕已18个月。女方33岁，月经周期规律，为35天；男方35岁，身体健康。女方在第21天测的黄体中期孕酮为8 nmol/L。男方精液分析显示：精液量2.5 mL，浓度每毫升1200万，前向运动精子25%，正常形态3%。解读这些结果。
::: solution
**孕酮。** 对于35天的周期，下次月经预计在第36天，所以黄体中期样本应在约7天前，即**第28天**采集。第21天的样本是在卵泡期采集的，因此结果低并不表明无排卵。应在正确的时间复查；周期规律时，她很可能有排卵。

**精液分析。** 浓度（每毫升1200万，低于1600万）、前向运动（25%，低于30%）和形态（3%，低于4%）都低于WHO 2021参考下限。这种模式称为少弱畸形精子症。应在约三个月后复查，并评估他的病因（病史、包括睾丸在内的体格检查，以及精子计数很低时做内分泌检查）。

**下一步。** 还应评估输卵管通畅性。如果复查精液分析结果相似，应将这对夫妇转诊给生殖专科医生；根据严重程度，可能建议IVF或ICSI。为双方提供生活方式建议（吸烟、饮酒、BMI，男方还要避免高温和合成代谢类固醇）。
:::
:::

::: warning 不要在每个周期都在第21天查孕酮
"第21天孕酮"只有在28天周期中才是第21天。这项检查应在黄体中期，即下次预期月经前约7天进行。对于35天周期的妇女，第21天的样本是在排卵前采集的，会得到假性偏低的结果，可能导致错误地诊断为无排卵并进行不必要的治疗。
:::

::: quiz
一位妇女在规律28天周期的第13天有过无保护性交，距今已96小时。她不服用其他药物，BMI为24。哪种紧急避孕方法是最有效的选择？
- [ ] 左炔诺孕酮1.5 mg。
- [ ] 醋酸乌利司他。
- [x] 含铜宫内节育器。
- [ ] 都不行，因为紧急避孕已经太晚了。
::: solution
96小时已超出左炔诺孕酮的72小时窗口期。乌利司他可在120小时内服用，但由于排卵很可能已在第14天左右发生，通过推迟排卵起作用的口服方法可能无效。**Cu-IUD**可在性交后5天内或在最早可能的排卵日之后5天内放置，是最有效的选择。如果她拒绝放置节育器，应提供乌利司他。
:::
:::

::: history
1916年，玛格丽特·桑格（Margaret Sanger）在布鲁克林开设了一家节育诊所，并因此被捕；1921年，玛丽·斯特普斯（Marie Stopes）在伦敦开设了英国第一家节育诊所。第一种复方口服避孕药由格雷戈里·平卡斯（Gregory Pincus）、张明觉（Min Chueh Chang）和约翰·洛克（John Rock）在1950年代研制，其基础是卡尔·杰拉西（Carl Djerassi）和弗兰克·科尔顿（Frank Colton）合成的口服有效孕激素；它于1960年在美国、1961年在英国被批准用于避孕。早期的避孕药所含雌激素比现代避孕药多得多，1960年代报告的与静脉血栓形成的关联促使剂量逐步降低。宫内节育器由恩斯特·格拉芬贝格（Ernst Gräfenberg）在1920年代、杰克·利佩斯（Jack Lippes）在1960年代研制，含铜宫内节育器在1960年代末随之出现。在生育领域，决定性的一步是1978年路易丝·布朗（Louise Brown）在奥尔德姆出生，这得益于罗伯特·爱德华兹（Robert Edwards）、帕特里克·斯特普托（Patrick Steptoe）和琼·珀迪（Jean Purdy）的工作；爱德华兹于2010年获得诺贝尔奖。英国1990年《人类受精与胚胎学法》设立了HFEA，它是最早对辅助生殖进行法定监管的机构之一。卵胞质内单精子注射由詹皮耶罗·巴勒莫（Gianpiero Palermo）及其同事于1992年在布鲁塞尔首次报告，使许多精子严重异常的男性得以成为遗传学意义上的父亲。
:::

::: summary
- 避孕方法抑制排卵、阻挡精子或阻止受精或着床；许多方法作用于不止一个步骤。
- 对于依赖使用者的方法，典型使用失败率远高于完美使用失败率（避孕药每年9%对0.3%）；LARC方法在两种情况下几乎同样有效。
- $n$年内至少发生一次妊娠的概率为$1-(1-p)^n$，因此小的年风险会累积。
- UKMEC将每种方法分为1级（不受限制）至4级（不可接受的风险）。有先兆偏头痛、年龄35岁或以上且每天吸烟15支或以上、既往VTE或易栓基因突变时，CHC为UKMEC 4。
- CHC的VTE风险在绝对值上很小（取决于孕激素，每年每10,000名妇女约5–12例，未使用者为2例）。
- 酶诱导药物使避孕药和埋植剂不可靠，但不影响注射剂或宫内方法。
- Cu-IUD是最有效的紧急避孕方法（120小时内，或可能排卵后5天内）；乌利司他在120小时内有效，左炔诺孕酮在72小时内有效。
- 生育力低下是一年后未能受孕；大多数夫妇在两年内受孕。双方都要检查：排卵（预期月经前7天的黄体中期孕酮）、对照WHO 2021下限的精液分析，以及输卵管通畅性。
- 来曲唑是PCOS诱导排卵的一线药物；IVF和ICSI可绕过输卵管和男方因素；OHSS和多胎妊娠是治疗的主要风险。
:::

## 习题

::: exercise 累积风险 {level=1 check="round(100*(1-0.91^5))"}
使用[[#eq-cumulative]]，典型使用复方避孕药（每年失败率9%）的妇女中，预计有百分之几会在五年内至少妊娠一次？答案取最接近的整数百分比。
::: solution
$1 - (1 - 0.09)^5 = 1 - 0.91^5 = 1 - 0.624 = 0.376$，约**38%**。近似公式$np$会得到45%；精确公式的值更低，因为一位妇女只可能有一次"第一次"妊娠。
:::
:::

::: exercise 孕酮检测的时间 {level=1 check="28"}
一位妇女的月经周期规律，为35天。黄体中期孕酮应在周期的第几天采血？
::: solution
下次月经预计在第36天。黄体中期样本在此前约7天，即第**28**天采集。
:::

::: exercise UKMEC分级 {level=1}
给出以下各情况下复方激素避孕的UKMEC分级：(a) 一位25岁无先兆偏头痛的妇女；(b) 一位30岁有先兆偏头痛的妇女；(c) 一位28岁妇女，其母亲45岁时患DVT，她本人未做易栓症检查；(d) 一位40岁不吸烟、无其他危险因素的妇女。
::: solution
(a) 无先兆偏头痛的妇女开始使用CHC，为UKMEC 2。(b) **UKMEC 4**：有先兆偏头痛与缺血性卒中风险增加相关，而雌激素会进一步增加这一风险。(c) 一级亲属在45岁以下患VTE的家族史为UKMEC 3；45岁或以上为UKMEC 2。不建议常规进行易栓症检查。(d) 年龄40岁或以上使用CHC为UKMEC 2。
:::

::: exercise 相互作用 {level=2}
一位24岁服用卡马西平的癫痫妇女正在使用复方避孕药。解释问题所在并建议合适的替代方法。
::: solution
卡马西平诱导肝酶（细胞色素P450 3A4），加快炔雌醇和孕激素的代谢，使避孕药不可靠；单纯孕激素避孕药和埋植剂也是如此。合适的替代方法是**Cu-IUD**、**LNG-IUS**或**单纯孕激素注射剂**，它们的有效性不受影响。还应提供关于抗癫痫药和叶酸的孕前咨询（[[obstetrics-gynaecology/pregnancy-antenatal]]）。
:::
:::

::: exercise 根据试验计算Pearl指数 {level=2 check="4"}
在一项新型避孕贴片的试验中，共纳入250名妇女。其中200人使用了12个月；另外50人在6个月后停用，未再随访。共发生9次妊娠，均在使用贴片期间。计算Pearl指数。
::: hint
总暴露是每位妇女实际使用该方法的月数之和，而不是妇女人数乘以12。
:::
::: solution
暴露：$200 \times 12 + 50 \times 6 = 2400 + 300 = 2700$个月。使用[[#eq-pearl]]，Pearl指数为$9 \times 1200 / 2700 = 10800/2700 = 4$，即每100妇女年4次妊娠。如果错误地用$250 \times 12 = 3000$个月计算，会得到3.6，使该方法看起来比实际更好。
:::
:::

::: exercise 男方因素 {level=2}
两次精液分析均未见精子（无精子症）。该男子睾丸体积正常，FSH正常。可能的机制是什么？有哪些治疗选择？
::: solution
睾丸大小和FSH正常提示精子生成正常，问题在于**梗阻**，例如先天性双侧输精管缺如（与CFTR变异相关，因此需要基因检测和遗传咨询），或感染后或手术后的阻塞，包括输精管结扎术。选择包括从附睾或睾丸手术取精后行ICSI、某些情况下行手术重建（如输精管复通术），或供精。相比之下，睾丸小而FSH升高提示睾丸功能衰竭（非梗阻性无精子症），此时手术取精成功率较低。
:::
:::

::: exercise 关于LARC的咨询 {level=3}
一位19岁女性在使用避孕套和避孕药期间已有两次意外妊娠。她想要"一种不用操心的方法"，但担心体重增加和不规则出血。比较她可以选择的方法及其优缺点。
::: solution
**皮下埋植剂**：最有效的可逆方法（失败率0.05%），有效期三年，可迅速逆转；缺点：出血不可预测，这是取出的最常见原因（某些出血模式经治疗可改善）。尚未证明埋植剂会导致体重增加。

**LNG-IUS**：高效（0.2%），根据装置不同可用5至8年，通常使月经量减少；缺点：放置是一项盆腔操作，最初几个月有不规则点滴出血，有小的脱落和穿孔风险。

**Cu-IUD**：高效，不含激素，最长可用10年；缺点：月经可能变多、痛经可能加重。

**注射剂**：按时注射时非常有效（因漏打，典型使用失败率为6%）；缺点：需要每13周注射一次，可导致体重增加（BMI超过30的年轻女性更常见），生育力恢复延迟，以及可逆的骨密度下降。

还应建议她继续使用避孕套以预防性传播感染，并提供衣原体和淋病筛查。选择由她本人作出，并基于清楚、客观的信息，不施加压力。
:::
:::

::: exercise 复杂的生育力低下病史 {level=3}
一位38岁妇女尝试受孕已8个月。她15岁时曾因阑尾穿孔患腹膜炎，现有痛经和性交痛。她的伴侣与前一段关系中育有一个孩子。她的病史中哪些特征重要？应如何检查？
::: solution
**时机。** 38岁时，她应该现在就转诊，而不是等满一年：NICE建议36岁或以上的妇女更早转诊，而且她有可能的病因。

**病史。** 阑尾穿孔引起的腹膜炎可导致盆腔粘连和输卵管损伤。痛经和深部性交痛提示**子宫内膜异位症**，它可扭曲盆腔解剖并损害生育力。伴侣与他人有过妊娠并不能排除目前存在男方因素。

**检查。** 卵巢储备（AMH或窦卵泡计数），因为她的年龄和可能的子宫内膜异位症都可能使其下降；确认排卵；伴侣的精液分析；经阴道超声检查子宫内膜异位囊肿及其他盆腔病变；由于她有危险因素，做**腹腔镜加通液**而不是子宫输卵管造影，这样可以在同一次手术中评估输卵管，并诊断和治疗子宫内膜异位症和粘连。如果她的输卵管严重受损或卵巢储备低，应尽早讨论IVF，因为她的年龄限制了可用的时间。
:::
