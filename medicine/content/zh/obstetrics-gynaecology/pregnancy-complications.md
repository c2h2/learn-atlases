妊娠的并发症以可预测的家族来临——高血压的、胎盘的、生长相关的、早产的；以及“恰好发生在女性身上、而不只是因为妊娠”的“内科与外科的急症”——而每一种都有一份方案，其第一个词通常是硫酸镁、激素、收住或分娩，而最后一个词是一场与资深者的谈话。**本章的逻辑是：胎儿让常见的疾病变得危险，而妊娠让不常见的疾病以非典型的方式登场。**

## 高血压的疾病

::: definition 子痫前期与子痫及高血压的谱系 {#def-hypertension}
**先做分类：慢性的高血压（既往存在的、或在20周之前）；妊娠的高血压20周之后新发的高血压，不伴蛋白尿或脏器的特征；子痫前期20周之后新发的高血压，加上蛋白尿或母亲的脏器的受累——注意蛋白尿不再被要求：肾的与肝的及神经的及血液的及“子宫胎盘的功能障碍”的特征就足以定义它；叠加在慢性高血压上的子痫前期；子痫发作；以及“溶血与肝酶的升高及血小板的减少”这一综合征溶血——乳酸脱氢酶与胆红素的上升、珠蛋白与纤维蛋白原的下降；肝的酶升高；血小板低——它可以表现为“上腹的疼痛而血压正常”，而诊断靠一份“血细胞计数与涂片及肝与肾及凝血的筛查按产前一章生理的基线来解读”。一句病理生理学：异常胎盘的植入伴母亲的“内皮的功能障碍与血管的痉挛及毛细血管的渗漏”，解释了高血压与蛋白尿及水肿及并发症——脑的头痛与视觉的扰乱及发作及“可逆的后部的脑病”、肝的包膜的牵张与破裂、肾的、血液的、以及胎盘的生长受限与早剥及死产。评估——规范地测量并反复地量化的血压；尿的分析加“蛋白与肌酐的比值”；血液；胎儿的评估配生长与多普勒；以及每日“严重的特征”的问题——头痛与视觉的症状及上腹或右上腹的疼痛及呼吸困难及“尿的减少”——它们是把监测转化为分娩的症状。按方案的管理：妊娠中轻中度的高血压用拉贝洛尔在多数指南中是一线或“缓释的硝苯地平或甲基多巴”治疗，目标是“130到140上下的收缩与80上下的舒张”而不是“正常化”胎盘的灌注与“更严格的目标”的小试验的证据，正随着近期的试验把辩论定于“在140/90时治疗”；重度的高血压作为急症“在数分钟到一小时内”用静脉的拉贝洛尔或肼屈嗪或口服的硝苯地平治疗按急期方案的图表。分娩的决定：伴严重特征的子痫前期是一场“稳定之后分娩”的过程硫酸镁防子痫与“按急期的协议控制血压”，而分娩的时机按严重程度与孕周决定，激素若能争取到就用；“不伴严重特征”则在“住院或日间单元的监测”下期待地处理。人们会忘记的产后那段尾巴：血压在第3到5天会再次到达峰值；子痫前期可以在一次正常的分娩之后开始那次重新入院的头痛；硫酸镁在产后继续24小时；抗高血压药需要“与哺乳相容”的选择；以及出院时要告诉她的长期真相——子痫前期显著提高了她终身的心脏的风险：“每年查血压与体重，以及这一次为之付了钱的下一次的阿司匹林的计划”[[cardiovascular/hypertension]]、[[renal/filtration]]、[[obstetrics-gynaecology/pregnancy-antenatal]]。**
:::

## 胎盘、生长与时机

::: definition 胎儿的生长受限与“胎盘早剥”及“前置的胎盘” {#def-growth}
**小不等于生长受限：小于孕周的胎儿可能是体质上健康的最大的决定因素是母亲的大小与产次——定制的曲线图试图捕捉这一点、而仍有争议，也可能是胎盘在衰竭；临床上重要的那区分靠“系列的生长与羊水羊水过少与胎盘的衰竭同行及脐动脉的多普勒及胎心监护或生物物理的评分”；而多普勒的阶梯讲出了分娩时机的故事——“搏动指数的升高，然后舒张末血流的消失，然后舒张末血流的反向”，每一级都更坏、也更早；“大脑中动脉脑保护的比值与静脉导管的波形及颈的透明层”为“决定29周的胎儿是今天出来还是再住三天被监测”的三级团队补充信息。管理属于胎儿医学的单元：激素；“在约30到32周之前分娩时用硫酸镁做神经的保护”；按严重度决定“住院对日间单元的监测”；以及跟随试验证据分娩的时机生长受限试验给出的“诚实的形状”——“早发的、多普勒正常且监测令人安心的在36到37周；舒张末血流消失的在34到36周；舒张末血流反向或导管的异常或胎心的事件的在30到34周或立即“——个体化，而不是照表办事。早剥（伴”子宫绷紧疼痛的出血“——临床的诊断，有时是隐匿的：”下降的血红蛋白与弥散性的血管内的凝血的图景，在子宫的后壁会变成致命的）的跨度从“观察与激素的收住”一直到“带大量输血方案紧急的剖宫产、以及与麻醉科关于凝血病的谈话”；复发的风险是真实的，所以下一次妊娠的生长监测要早开始。前置胎盘盖住宫颈内口——无痛的出血；“在排畸时用经阴道的超声定位，并在32周复查，因为大多数低置的胎盘会自己解决”：当它遇上植入的疾病时就危险了——“既往的剖宫产加前壁的胎盘”这一组合产出“胎盘粘连与植入及穿透”；其管理是在“有介入的放射与自身的血液的回收及血库的事先预警”的中心“计划一个较早的分娩常在34到36周”，以及”做过模拟演练的资深产科与麻醉的团队——因为异常粘连的胎盘正是英国的母亲死亡集中的两三种情况之一：失血与子宫的切除，以及那个好的路径存在的目的就是让它变得乏味的重症的夜晚“[[blood/haemostasis-bleeding]]、[[obstetrics-gynaecology/postnatal-period]]、[[paediatrics/neurodevelopment]]。**
:::

## 早产与急症

::: definition 早产与“产程前的胎膜破裂”及母亲的急症 {#def-preterm}
**早产——37周之前的临产或宫颈的改变，并从22到24周起就有“关于存活边界的决定”——靠四项干预运转：产前的糖皮质激素倍他米松或地塞米松用于24到34周；以及“在本地采纳试验证据时的34到36周的迟发早产的那一剂”，记住“新生儿低血糖的取舍”；短暂而审慎使用的“宫缩的抑制剂”在用时用硝苯地平或“阿托西班”；不是为了推迟不可避免的事、而是为了买到激素的窗口与转运；在绒毛膜的羊膜炎时禁忌，并在“重度的子痫前期或早剥”中受限；以及在“30到32周之前的分娩看起来不可避免时”用硫酸镁做胎儿的神经的保护；以及“转运到一家新生儿存活与结局与孕周相称的单位”——因为“集中的新生儿照护”的证据与围产医学中任何东西一样强，而“未经筛查的母亲的临死的转运”正是报告反复点名的失败。预防是部分的：用“宫颈长度的筛查配阴道的孕激素”，或“为短的宫颈或那经典的无痛的第二三月丢失的模式做按病史或按长度指征的环扎”；而环扎的决定要在“经阴道的超声与一份书面的计划”之下做出，因为“在一个正在收缩的、已感染的子宫里做补救的环扎”正是“医源性的极度早产发生的方式”。产程前的胎膜早破：诊断靠无菌窥器下的病史与积液及羊齿化的结晶或那种可测的标记物，而不是手指的检查；处理取决于孕周——“从34到36周本地的界限各不相同在激素之后分娩”；在那之前是期待的通路口服的红霉素段证据、不常规重复的抗生素、“每日的体温与脉搏及血液和炎症的标记”、单剂的激素、对乙型链球菌状态的思考；以及那句诚实的咨询——“时钟在与她作对：绒毛膜的羊膜炎与早剥及脐带脱垂，就是计划在夜里被改变的理由”。妊娠中母亲的急症遵循“带着两位患者外科的规则”：阑尾炎被推移的疼痛，以及“无论如何都会升高的正常的白细胞”；以及“从超声或磁共振开始的影像”、而不是拒绝去看；胆囊炎第三季的“脂质的风暴”；以及“如今倾向于同一次收住手术的腹腔镜对保守的辩论”；创伤（“母亲为先的复苏配左侧的倾斜”；Rh 阴性者的“母胎出血的量化”；“即便母亲看起来没事也要做的胎心监护”；以及那条五分钟内围死亡期剖宫产的规则——其逻辑是“胎儿是第二位患者，而只有第一位的循环能救任何一位”）；以及虚脱——“羊水栓塞与灾难性的出血的复苏其算法与非妊娠的完全相同，只是多了倾斜，以及在第二剂升压药之前就呼叫资深的产科与新生儿团队”——[[emergency-critical-care/resuscitation]]、[[infectious-diseases/fever-sepsis]]、[[obstetrics-gynaecology/labour-birth]]。**
:::

::: example 那次32周的“上腹的疼痛” {#ex-hellp}
一名32周的初产妇因“反流与消化不良”被她的全科医师送来：血压148/94、血小板78、丙氨酸氨基转移酶142、乳酸脱氢酶890、有蛋白尿；胎儿在第2百分位伴“脐的搏动指数的升高”；而她说“只是真的饿了”。
::: solution
**在被推翻之前都是“溶血与肝酶升高及血小板减少”的综合征，而它推翻不了（[[#def-hypertension]]、[[#def-growth]]）：识别——”上腹的疼痛加高血压加血小板的减少加转氨酶的升高加溶血的标记就是这一综合征；胎儿的生长受限证明胎盘已经衰竭了几周；而一位年轻的初产妇身上还算正常的血压是这一页上最危险的那个数字；这位女性已经被送回家过一次，因为没有人把这四项结果写成一句话“。一小时之内的集束——”现在就告诉资深的产科医师与麻醉师及新生儿团队；开始硫酸镁；用静脉的抗高血压药把处于严重范围的血压安全地降下来；给激素，并带着交叉配血的送检盯着血小板与凝血及纤维蛋白原的趋势；液体的限制伴尿的减少与水肿的告诫；以及出于正确的理由做出的分娩的决定——不是那个数字，而是那条轨迹“：在32周的综合征加上生长受限加上多普勒的异常，通常指向”在母亲的稳定与激素的效应之后分娩，并在宫颈或胎儿的状态要求时剖宫产“；以及谈话的四个角落——对她：”这是一桩严重妊娠的并发症，我们很快要把你的孩子分娩出来，这是为什么今晚比下周更安全“；对麻醉科：决定”脊柱的麻醉“的是”当天那一整天的趋势、而不是单个的数字“；对新生儿科：”一个32周的生长受限的婴儿对过渡的处理比一个体重正常的更差“；以及病历：预约好长期的随访产后的血压与”心血管的风险及下一次的阿司匹林的计划“（[[cardiovascular/hypertension]]、[[obstetrics-gynaecology/postnatal-period]]）。**

::: example 那次26周的“破水”与那场长长的谈话 {#ex-pprom}
一名26周加2的经产妇报告“一阵涌出与持续的渗漏”；窥器下见积液；胎心监护令人安心；她在问“我能待多久、机会有多大”；而同一个下午她的体温升到38.2、脉搏112。
::: solution
**“处在边界上产程前的胎膜早破”（[[#def-preterm]]）：一瞬间的重构——”一次发热与一次心动过速，把一场期待通路的谈话变成了一桩绒毛膜的羊膜炎与早产的临产的急症：在这个孕周，答案是治疗、稳定、并在安全可能时于激素之后分娩——把一桩脓毒性的妊娠延长下去，会杀死她正在保护的那个孩子；这就是她首先需要的那句话，而不是存活的统计“。立即的集束——”血液与培养；按本地的早产的临产中脓毒症的方案用广谱静脉的抗生素；若分娩不至于快到可以省去就给那一剂激素；开始硫酸镁神经的保护；尽管有宫缩也刻意不给宫缩的抑制剂感染正是那条经典的禁忌“；告知资深的麻醉与新生儿团队；以及”就位“的乙型链球菌预防的思考。分娩与之后——”方式由她的状态与胎儿的状态决定：绒毛膜的羊膜炎本身并不是剖宫产的适应证；经阴道分娩，在胎儿的适应证出现时做器械的分娩；胎盘送组织学；与新生儿科协调孩子脓毒症的检查；以及她自己产后对这一图景所预示的子宫内膜炎与持续发热的监测“；以及路径的记录——”一剂的抗生素与定时的观察，以及用她的话记下的讨论；因为同一个夜晚若被不同地管理，就是那桩投诉“；以及公平与咨询的那条尾注——”在某些家庭里，这类谈话在这个孕周被反复进行，在另一些家庭里则从不；所以那位做谈话的人与谈话的内容都要被记录“（[[clinical-skills/communication]]、[[clinical-skills/records-handover]]）。**

::: example 那次“重新入院的头痛” {#ex-postpartum}
::: solution
**产后的子痫前期（[[#def-hypertension]]）：规则——”子痫前期可以在分娩之后最多六周内首次出现、并在第3到6天到达峰值；而正常的产前的血压并不能排除它。一位新妈妈身上雷击样的头痛加视觉的症状加高血压加反射亢进就是即将子痫，要给硫酸镁与抗高血压的方案、现在就给；同时并行地（而不是作为替代地）追逐那份鉴别——脑的静脉的血栓产后、脱水、“头痛加发作加灶的体征”，所以当图景非典型、或“计算机断层正常而怀疑仍在”时就要给静脉做影像、可逆的后部的脑病；以及麻醉的穿刺后的头痛——它是体位的、并且不是上面任何一种“。处理——”与产前的疾病同一个集束：静脉或口服的急期的抗高血压药；硫酸镁24小时；血液包括那套溶血与肝酶的筛查；以及这场头痛值得多少检查的决定要看检查与轨迹；而影像的阈值要低——因为产后的头痛的法医学的文献就是一部被漏掉的静脉的血栓的目录“。以及系统的教训——”她出院时的血压与第5天的产后检查的血压都是某人的职责：相关的标准是“妊娠中有高血压疾病的女性要在社区被监测血压，并配明确的阈值与一个真的会响的电话号码”；而在产后首次出现的人，就是“我们通路的失败”（[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]）。**

::: example 那对双胞胎与“不一致的扫描” {#ex-ttts}
::: solution
**双胎之间的输血（[[#def-preterm]]、[[paediatrics/newborn]]）：诊断与它的诚实——“按胎儿医学单元所用的分期，这是二期或更重的双胎输血；未经治疗的自然史在晚发的病例中对两者都是大多数的死亡；而对她的问题的回答是在不治疗时你可能失去一个或两个；治疗给两者一个真实的机会；而治疗本身也可能让妊娠付出代价——数字是：对吻合处做激光的消融，在接受治疗的病例中约80%到90%至少存活一位、而两位都存活在大多数中实现；具体的结局取决于分期与孕周“。路径——”当天转运到胎儿医学的中心；详细解剖与胎盘及静脉导管的评估；激光对系列的羊水的减量对一期的期待的讨论对晚期的疾病，激光是有证据的答案；而羊水的减量只是拖延这一真相要被平实地说出；宫缩的抑制剂与激素及在膨出时的环扎由做手术的团队决定；以及产后激光监测的进度表针对那两种经典的并发症——复发的双胎输血与突然的双胎的死亡它会让存活的那位处于神经的风险之下——这也是随访包含与新生儿相邻的脑的影像、而不只是生长的原因“。以及咨询的架构——”一位临床医师对这一系列的谈话负责、伴侣也在场；语言是分阶段的、而不是一步到位的”（[[clinical-skills/communication]]、[[medical-ethics-law/ethical-principles]]）。**

**30周的舒张末血流的消失（[[#def-growth]]）：安置——“在30周时舒张末血流的消失就是严重的胎盘的衰竭：住院、或至少在日间单元监测；胎心监护与多普勒的进度由胎儿医学的单元设定；产前的激素已给；把硫酸镁的神经的保护的计划写成文件，以迎接它变成急症的那一天；而生长与羊水的轨迹要被描绘出来、而不是被反复辩论“。分娩的触发条件——”舒张末血流的反向；静脉导管的a的波的异常或升高；胎心监护的减速或生物物理的恶化；羊水过少的加深；或母亲的恶化——每一项都是一个今天的理由；而只有舒张末的血流消失、其余都正常能在监测之下买到数日到数周，朝向那有试验支持的33到36周的窗口、而不是到足月“。以及谈话——”她在30周怀着生长受限的孩子，可以对她说出三句真话：孩子小是因为胎盘在衰竭；我们每日观察，因为它改变的那一天就是我们行动的那一天；而越早分娩，孩子活得好的机会越大——直到某个点之后相反才成立。这正是监测存在的原因，也是为什么我们会告诉你算术在什么时候翻转”（[[paediatrics/newborn]]、[[obstetrics-gynaecology/pregnancy-antenatal]]）。**

## 通向何处

疾病产前的发现在[[obstetrics-gynaecology/pregnancy-antenatal]]，分娩的决定在[[obstetrics-gynaecology/labour-birth]]，产褥分娩后的子痫及伤口及血栓的问题在[[obstetrics-gynaecology/postnatal-period]]，重症的医学在[[emergency-critical-care/critical-care]]，新生儿s 的结局？不——新生儿的结局在[[paediatrics/newborn]]。

::: history
**妊娠的并发症的史，是一部“学会哪些是医学能修好的、哪些只能被预见”的史。子痫前期——那“子痫前的中毒症”、那“高血压的怪物”它的抽搐从十八世纪起就在分娩的医院里杀死初产妇“——抵制了每一种治疗，直到诊断被移到抽搐之前：1920到30年代产前门诊的运动建立了那三联水肿与体重的增加及蛋白尿——前两项后来被证据降级；1970年代甲基多巴的试验证明了“治疗轻度的高血压可以是安全的”；2002年那次关于硫酸镁的大型试验“在一次发表之中使它成为标准”；而“英格兰与威尔士的母亲的死亡保密的调查”用“把死亡聚成一小撮可预防的模式——被漏掉的高血压的疾病与出血——然后逐一盯住它们”，“把死亡率带到了历史的最低”（[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]）。早产的那一段则被另一条线索改写：激素的发现与“神经保护的试验与新生儿的存活的地图”，它把“24周的婴儿”从“几乎不可能”变成“可预期的”、并随之带来了“关于存活边界的困难而必要的谈话”（[[paediatrics/newborn]]、[[respiratory/respiratory-failure]]）。**
:::

::: summary
- 子痫前期由整个图景来诊断、只能靠分娩来治愈；重度的血压要在数分钟内处理、为子痫给硫酸镁；并记住这病可以在一次正常的分娩之后首次登场。
- “溶血与肝酶的升高及血小板的减少”表现为“上腹的疼痛而血压还算正常”；一句话里放四项异常的血液结果就是诊断。
- 生长受限是一桩“按多普勒分期”的疾病：系列的生长加羊水加脐带的以及大脑中动脉与静脉导管的检查加胎心监护决定的是那一周、而不是那个百分位。
- 前置伴植入与早剥是出血的疾病：管理靠计划、与血库的关系及模拟演练，而不是靠临场发挥。
- 早产有四件证据的工具——激素、审慎选择宫缩的抑制剂、硫酸镁神经的保护、以及正确的新生儿单元——而“产程前的胎膜早破”是“在感染与早产之间做交换”，其中红霉素买到了中间那一段。
- 每一次妊娠的虚脱都是出血或血栓栓塞或羊水栓塞或“被揭示出来既往存在的疾病”；用标准的算法加倾斜来复苏母亲，并同时呼叫产科与麻醉及新生儿科。
:::
