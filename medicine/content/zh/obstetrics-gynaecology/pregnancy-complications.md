大多数妊娠并发症可归入少数几组。有些由胎盘引起：子痫前期、胎儿生长受限和胎盘早剥都始于一个植入不良的胎盘。有些是被妊娠揭示出来的母体代谢异常，如妊娠期糖尿病和肝内胆汁淤积症。有些是机械或时间问题：胎盘位于宫颈之上、胎膜过早破裂、26周就开始的分娩。知道所属的组别有助于你预测还应寻找什么。患子痫前期的妇女需要检查婴儿的生长；婴儿偏小的妇女需要监测血压。

这些疾病还有一个共同的核心临床决策。对大多数疾病来说，根本的治疗是分娩，问题在于何时分娩。分娩能治愈子痫前期，但可能使婴儿面临早产的风险。等待能为婴儿争取时间，却使母婴双方都暴露于不断进展的疾病。本章的大部分内容都是关于如何评估这种权衡。

本章介绍妊娠期高血压疾病、妊娠期糖尿病、肝内胆汁淤积症、妊娠后半期出血、早产与胎膜破裂、胎儿生长受限和多胎妊娠。正常生理和产前检查安排见[[obstetrics-gynaecology/pregnancy-antenatal]]。

## 妊娠期高血压疾病

妊娠期高血压疾病影响约十分之一的妊娠，在全世界仍是孕产妇和围产儿死亡的主要原因之一。英国的实践遵循NICE NG133（《妊娠期高血压》，2019年，2023年更新）。

::: definition 妊娠期高血压疾病 {#def-hypertension}
妊娠期高血压是指血压达到或超过140/90 mmHg。**重度高血压**是指达到或超过160/110 mmHg。

- **慢性高血压**：妊娠前已存在或在20周之前诊断的高血压。
- **妊娠期高血压**：20周之后新发、且无子痫前期特征的高血压。
- **子痫前期**：20周之后新发高血压，并伴有以下一项或多项新出现的特征：
  - 蛋白尿（尿蛋白/肌酐比值达到或超过30 mg/mmol，或白蛋白/肌酐比值达到或超过8 mg/mmol）；
  - 母体器官功能障碍：肾脏（肌酐达到或超过90 µmol/L）、肝脏（转氨酶升高，伴或不伴右上腹或上腹痛）、神经系统（子痫、意识状态改变、失明、卒中、阵挛、剧烈头痛、持续视野暗点）或血液系统（血小板低于150 × 10⁹/L、溶血或弥散性血管内凝血）；
  - 子宫胎盘功能障碍：胎儿生长受限、脐动脉多普勒异常或死产。
- **慢性高血压并发子痫前期**：慢性高血压妇女发生的子痫前期。
- **子痫**：子痫前期妇女发生的强直-阵挛性抽搐。
- **HELLP综合征**：**H**溶血（haemolysis）、**EL**肝酶升高（elevated liver enzymes）和**LP**血小板减少（low platelets）。它是子痫前期的一种重症形式，可在血压仅中度升高时发生。
:::

诊断不再需要蛋白尿。一位34周新发高血压、无蛋白尿、血小板计数为90 × 10⁹/L的妇女患有子痫前期。

### 胎盘为什么会引起疾病

::: theorem 子痫前期是一种伴有母体综合征的胎盘疾病 {#thm-two-stage}
子痫前期分两个阶段发展。第一阶段，胎盘植入异常，灌注不良。第二阶段，处于应激状态的胎盘向母体循环释放因子，损伤全身的内皮。母体的各种体征，包括高血压、蛋白尿、水肿、肝损伤和抽搐，都源于这种广泛的内皮功能障碍。只有娩出胎盘，疾病才会消退。
:::

::: proof
在正常妊娠中，滋养细胞在妊娠前半期侵入母体螺旋动脉，并取代其肌性血管壁。这些动脉变成宽阔的低阻力通道，无论母体血管张力如何，都能向胎盘输送高流量的血液。

在子痫前期中，这种重塑不完全。螺旋动脉保留了肌层，管腔仍然狭窄，只能输送间断、低容量的血流。胎盘反复经历缺血和再灌注，并以释放抗血管生成蛋白作为反应，主要是**可溶性fms样酪氨酸激酶1（sFlt-1）**和可溶性内皮糖蛋白。sFlt-1结合并中和血管内皮生长因子和**胎盘生长因子（PlGF）**，而内皮需要它们来维持健康。

结果是影响每个器官的母体内皮功能障碍。血管收缩，使血压升高。肾小球内皮肿胀，导致蛋白尿和滤过下降。毛细血管渗漏，引起水肿，严重时引起肺水肿。肝窦受损，导致转氨酶升高和肝包膜牵张引起的疼痛。血小板在受损内皮上被消耗。大脑失去调节血流的能力，导致头痛、视觉障碍和抽搐。由于病源在胎盘，只有娩出胎盘才能去除病因，尽管疾病可能需要数天才能缓解，也可能在分娩后才首次出现。

同样的推理解释了两种临床工具。母体PlGF水平低是胎盘功能障碍的标志，NICE建议在20至36+6周之间使用基于PlGF的检测，帮助在疑似患病的妇女中排除子痫前期。而在妊娠早期、第二阶段出现之前开始使用阿司匹林，可以降低早发型（早产期）子痫前期的风险。
:::

### 处理

对20周之后出现高血压的妇女，评估包括反复测量血压、尿蛋白定量、血液检查（全血细胞计数、肾功能和肝功能）、寻找重症的症状，以及通过超声评估生长和脐动脉多普勒、并做CTG进行胎儿评估。

**降压治疗。** NICE建议对高于140/90 mmHg的血压进行治疗，目标为135/85 mmHg或以下。拉贝洛尔（labetalol）为一线药物；不适合使用拉贝洛尔时使用硝苯地平（nifedipine），甲基多巴（methyldopa）是第三种选择。妊娠期避免使用血管紧张素转换酶抑制剂和血管紧张素受体阻滞剂。治疗可以控制血压、预防重度高血压和卒中；但它不能治疗根本的疾病。

**重度高血压**（达到或超过160/110 mmHg）是急症，因为它有颅内出血的风险。它需要在医院内按照当地方案，用口服或静脉拉贝洛尔、口服硝苯地平或静脉肼屈嗪（hydralazine）治疗，并密切监测母亲和胎儿。

**硫酸镁（magnesium sulfate）**可预防和治疗子痫抽搐。它用于子痫妇女，对重度子痫前期妇女也应考虑使用，尤其是计划在24小时内分娩时。基于子痫协作试验的典型方案是：5–10分钟内静脉给予负荷量4 g，随后以每小时1 g的速度输注24小时；再次抽搐时追加一次推注。必须遵循当地方案。镁经肾脏清除，中毒时先出现膝反射消失，继而呼吸抑制，最终心脏停搏。接受硫酸镁的妇女需要每小时检查反射、呼吸频率和尿量，并且必须备有解毒剂葡萄糖酸钙（calcium gluconate）。

**分娩时机。** NICE NG133建议，对于34周之前的子痫前期，通常在密切监测下继续妊娠，如有母体或胎儿指征则计划分娩：血压无法控制、血液检查结果恶化、神经系统表现、HELLP综合征、胎盘早剥、肺水肿或胎儿窘迫。在34+0至36+6周之间，决定需权衡母体获益与较早分娩带来的新生儿风险。从37+0周起，应在24–48小时内启动分娩。如果计划早产分娩，在有指征时给予产前糖皮质激素和用于胎儿神经保护的硫酸镁。

**分娩后。** 血压常在产后3–6天再次达到高峰，子痫前期和子痫也可能在分娩后才首次出现。妇女在出院后需要监测血压，使用与母乳喂养相容的降压药（如依那普利（enalapril）、硝苯地平、氨氯地平（amlodipine）或拉贝洛尔），并被告知出现头痛或视觉症状时返回就诊。子痫前期还提示该妇女远期发生高血压和心血管疾病的风险增加，因此应告知她，并由初级保健机构复查血压。

::: example 32周的"消化不良" {#ex-hellp}
一位27岁初产妇孕32周，因上腹痛两天就诊，她以为是消化不良。血压148/96 mmHg。尿蛋白/肌酐比值85 mg/mmol。血液检查：血红蛋白104 g/L，血小板78 × 10⁹/L，ALT 142 U/L，乳酸脱氢酶890 U/L。超声显示胎儿腹围位于第5百分位，脐动脉阻力升高。诊断是什么？下一步应如何处理？
::: solution
**诊断。** 20周之后新发高血压、蛋白尿、血小板减少、转氨酶升高和LDH升高（提示溶血），构成**子痫前期合并HELLP综合征**。胎儿检查结果显示子宫胎盘功能障碍。上腹或右上腹痛是HELLP的典型表现，常被误认为消化不良。血压只是中度升高，但这并不意味着病情轻微。

**下一步。**
1. 收入产房，立即请顾问产科医生和麻醉医生参与。
2. 按方案控制血压。
3. 给予硫酸镁预防子痫。
4. 由于孕周不足34周，如时间允许，给予产前糖皮质激素促进胎肺成熟。
5. 检查凝血功能、血涂片并做血型鉴定与抗体筛查；仔细监测液体平衡，因为子痫前期妇女有因液体过多而发生肺水肿的风险。
6. 病情稳定后计划分娩。无论孕周如何，HELLP综合征都是分娩的指征。分娩方式取决于宫颈情况、胎儿状况和病情恶化的速度。血小板计数低会影响麻醉方式的选择，因为区域麻醉可能不安全。
:::
:::

### 预防子痫前期

小剂量阿司匹林是唯一被广泛使用的预防性治疗。NICE建议有一项高危因素或两项及以上中危因素的妇女从12周起直至分娩每日服用阿司匹林75–150 mg（[[obstetrics-gynaecology/pregnancy-antenatal]]）。最好的证据来自ASPRE试验（2017年）：在早孕期筛查中被识别为高风险的妇女，从11–14周起至36周每晚服用阿司匹林150 mg或安慰剂。阿司匹林组早产期子痫前期的发生率为1.6%，安慰剂组为4.3%。

一位妇女从一种预防性治疗中获益多少，取决于她的起始风险。**需治疗人数（NNT）**是绝对风险降低值的倒数。如果治疗后的相对危险度为$r$，基线风险为$p$，则绝对风险降低值为$p(1-r)$，且
$$
\text{NNT} = \frac{1}{p\,(1-r)}.
$$ {#eq-nnt}

::: widget plot
f: 100/(x*(1-r))
x: 1, 10
y: 0, 250
sliders: r=0.4:0.2:0.9:0.02
labels: \text{需治疗人数}
caption: 需治疗人数（纵轴）与以百分比表示的基线风险（横轴）的关系，治疗使风险乘以r。当r = 0.4（大致相当于ASPRE中阿司匹林对早产期子痫前期的效果）时，基线风险为4.5%的妇女约需治疗37人才能预防一例，而基线风险为1%时约需170人。同样的相对效果对低风险妇女意义要小得多，这就是为什么阿司匹林针对有危险因素的妇女使用。
:::

::: example ASPRE中的需治疗人数 {#ex-nnt}
利用ASPRE的结果（阿司匹林组早产期子痫前期1.6%，安慰剂组4.3%），计算绝对风险降低值和需治疗人数。
::: solution
绝对风险降低值为$4.3\% - 1.6\% = 2.7\%$，即0.027。需治疗人数为$1/0.027 \approx 37$。约37位高风险妇女需要在整个妊娠期服用阿司匹林，才能预防一例早产期子痫前期。相对危险度为$1.6/4.3 \approx 0.37$，接近报告的比值比0.38。由于在这些剂量下阿司匹林便宜而安全，这一需治疗人数被认为非常值得。
:::
:::

## 妊娠合并糖尿病

### 妊娠期糖尿病

**妊娠期糖尿病（GDM）**是妊娠期首次发现、但未达到显性糖尿病标准的高血糖。它的发生是因为妊娠晚期的胰岛素抵抗（[[obstetrics-gynaecology/pregnancy-antenatal#thm-new-normal]]）超过了妇女分泌胰岛素的能力。

::: definition 妊娠期糖尿病的诊断 {#def-gdm}
NICE NG3（《妊娠合并糖尿病》，2015年，2020年更新）规定，在24–28周进行75 g口服葡萄糖耐量试验（OGTT），若**空腹血浆葡萄糖达到或超过5.6 mmol/L**，或**2小时值达到或超过7.8 mmol/L**，即诊断为GDM。

许多其他国家使用的WHO（2013年）和IADPSG标准更低，并包括1小时值：空腹5.1–6.9 mmol/L、1小时达到或超过10.0 mmol/L，或2小时8.5–11.0 mmol/L。更高的数值则诊断为妊娠期显性糖尿病。
:::

母体高血糖能通过胎盘，而胰岛素不能。胎儿胰腺以高胰岛素血症作为反应，促进脂肪沉积和生长。其后果是**巨大儿**（肩难产和产伤的风险更高）、羊水过多、断脐后的新生儿低血糖，以及死产风险增加。

治疗从饮食和体力活动开始。NICE的血糖目标是空腹低于5.3 mmol/L、餐后1小时低于7.8 mmol/L（或餐后2小时低于6.4 mmol/L）。如果在一到两周内未达标，则使用二甲双胍（metformin），必要时加用或换用胰岛素。如果诊断时空腹血糖达到或超过7.0 mmol/L，则从诊断时起就开始胰岛素治疗。通过超声监测胎儿生长。NICE建议无并发症的GDM妇女最迟在40+6周分娩，有并发症时更早。

GDM通常在分娩后缓解，但多达一半的妇女在约十年内发展为2型糖尿病。她们应在产后检查空腹血糖或HbA1c（产后13周起查HbA1c），并每年检查一次HbA1c。

### 孕前糖尿病

患1型或2型糖尿病的妇女面临更高的风险：先天畸形（尤其是心脏和神经管缺陷）、流产、子痫前期、巨大儿和死产。畸形的风险随受孕前后HbA1c的升高而增加。孕前保健的目标是在可以安全达到的情况下使HbA1c低于48 mmol/mol，每日服用叶酸5 mg，调整用药（停用他汀类和血管紧张素转换酶抑制剂），并评估视网膜和肾脏。妊娠期间，胰岛素需要量在中、晚孕期急剧增加。为1型糖尿病妇女提供持续葡萄糖监测。基础疾病见[[endocrine/diabetes]]。

::: example 一份OGTT结果 {#ex-ogtt}
一位33岁南亚裔妇女在26周进行75 g OGTT。空腹血糖5.4 mmol/L，2小时值8.1 mmol/L。按NICE标准和WHO 2013标准，她是否患有妊娠期糖尿病？
::: solution
**NICE。** 空腹值（5.4）低于5.6 mmol/L，但2小时值（8.1）高于7.8 mmol/L。她患有GDM。

**WHO 2013。** 空腹值至少为5.1 mmol/L，所以即使2小时值低于8.5 mmol/L，她也患有GDM。

两种标准都诊断为GDM，但依据的是不同的数值。在边缘情况下，这种差异很重要：空腹5.2 mmol/L、2小时7.0 mmol/L的妇女按WHO标准患GDM，按NICE标准则不是。这就是为什么在不了解诊断标准的情况下，不同国家的GDM患病率数字无法比较。
:::
:::

## 妊娠期肝内胆汁淤积症

妊娠期肝内胆汁淤积症表现为**无皮疹的瘙痒**，典型部位为手掌和足底，夜间加重，通常发生在晚孕期。在排除其他肝病原因之后，瘙痒伴血清胆汁酸浓度升高（按RCOG指南（2022年）为19 µmol/L或以上）即可诊断。它在南亚和南美裔妇女中更常见。主要的担忧是死产，而风险集中在胆汁酸极高的妇女：峰值达到或超过100 µmol/L时风险明显增加，可考虑在约35–36周计划分娩；峰值较低的妇女通常可以等到晚孕期更晚时候。熊去氧胆酸（ursodeoxycholic acid）可能缓解瘙痒，但PITCHES试验（2019年）表明它不能减少不良围产结局。该病在分娩后缓解，应复查肝功能加以确认。

## 妊娠后半期出血

::: definition 产前出血 {#def-aph}
**产前出血（APH）**是从24+0周起直至婴儿娩出期间的生殖道出血。其主要原因有：
- **胎盘早剥**：位置正常的胎盘在分娩前剥离。
- **前置胎盘**：胎盘全部或部分覆盖宫颈内口。胎盘边缘距宫颈内口20 mm以内者称为**低置胎盘**。
- **前置血管**：胎儿血管走行于覆盖宫颈的胎膜中，没有胎盘或脐带的保护。
- 局部原因，如宫颈柱状上皮异位、息肉、感染，罕见情况下为宫颈癌。
:::

| | 胎盘早剥 | 前置胎盘 |
|---|---|---|
| 疼痛 | 通常存在，常为持续性 | 通常无痛 |
| 子宫 | 压痛，可变硬（"板状"） | 软，无压痛 |
| 出血 | 可能少量或不可见（隐性）；休克可能与可见失血量不相称 | 可见出血，常反复发作，与临床状态相符 |
| 胎位 | 通常正常 | 常异常，或先露部高浮 |
| 胎心 | 常异常 | 通常正常，除非母亲休克 |
| 危险因素 | 子痫前期、吸烟、可卡因、腹部外伤、既往胎盘早剥 | 既往剖宫产、多胎妊娠、辅助生殖、吸烟 |

前置胎盘通常在畸形筛查超声时发现。大多数低置胎盘会随着子宫下段的形成而远离宫颈，因此低置胎盘在约32周复查超声，如仍低置，约36周再次复查。有前置胎盘且既往剖宫产的妇女有**胎盘植入谱系疾病**的风险，即胎盘侵入子宫壁，分娩时不能剥离。这是大出血的原因之一，需要在专科中心计划分娩。

::: warning 在排除前置胎盘之前，绝不要用手指检查宫颈
对胎盘位置不明的妇女进行指检，可能诱发前置胎盘的灾难性出血。应先查看畸形筛查超声报告或进行超声检查。轻柔的窥器检查是安全的，有助于评估出血量和出血来源。
:::

::: example 34周的出血 {#ex-aph}
一位35岁妇女第三次妊娠，既往两次剖宫产，孕34周时突然无痛性流出约200 mL鲜红色血液。脉搏96次/分，血压118/72 mmHg。子宫软、无压痛，胎儿呈横位，CTG正常。她的畸形筛查超声报告为"胎盘前壁，低置"。可能的诊断是什么？优先事项有哪些？
::: solution
无痛性出血、子宫软、胎位异常和前壁低置胎盘，指向**前置胎盘**。既往两次剖宫产且为前壁前置胎盘，**胎盘植入谱系疾病**是一个严重的顾虑。

优先事项：
1. 复苏：建立大口径静脉通路，查全血细胞计数、凝血功能，交叉配血（而不仅是血型鉴定与抗体筛查），并准备好大出血方案。
2. 不做指检；通过窥器检查和超声确认胎盘位置。
3. 由于很可能在35周前分娩，给予产前糖皮质激素；如为RhD阴性则给予抗D。
4. 上级产科、麻醉科和血液科参与；如病情稳定，紧急进行胎盘植入的专科影像检查。
5. 如果出血持续或母亲或胎儿受到危害，由有经验的团队施行剖宫产，并做好应对大出血和可能切除子宫的准备。
:::
:::

## 早产与胎膜破裂

**早产**（37+0周之前分娩）约占英格兰分娩的7%–8%，是全世界幼儿死亡和残疾的首要原因。约三分之二继发于自发性早产临产或未足月胎膜早破（PPROM）；其余是因母体或胎儿原因计划提前分娩的。危险因素包括既往早产或晚期流产、宫颈手术（如大范围环形切除）、多胎妊娠、子宫畸形、感染和吸烟。

**预测与预防。** 为高风险妇女在中孕期提供经阴道宫颈长度测量。宫颈短（16至24周之间为25 mm或以下）可根据病史采用阴道孕酮或宫颈环扎术治疗。

**早产临产的诊断。** 仅有疼痛性宫缩是不够的，因为许多先兆早产的妇女并不会分娩。NICE NG25（《早产临产与早产》，2015年，2022年更新）建议使用经阴道宫颈长度测量或胎儿纤连蛋白（一种在胎膜开始分离时漏入阴道的蛋白质）来识别近期不太可能分娩的妇女。宫颈长度超过15 mm或纤连蛋白低于50 ng/mL时，早产临产的可能性不大。

**改善婴儿结局的干预措施。**
- **产前糖皮质激素**加速胎肺成熟，减少新生儿死亡、呼吸窘迫综合征和脑室内出血。NICE建议在预期早产时于24+0至33+6周之间给予，并在34+0至35+6周考虑给予。在首剂后24小时至7天内分娩时获益最大。
- **用于神经保护的硫酸镁**降低脑瘫风险。在24+0至29+6周之间预期24小时内分娩时给予，在30+0至33+6周之间考虑给予。
- 用硝苯地平（不适合时用阿托西班（atosiban））进行**抑制宫缩**，可以将分娩推迟足够长的时间，以完成糖皮质激素疗程或将母亲转运到具备相应新生儿医疗条件的单位。它本身尚未被证明能改善结局。
- **在合适的地点分娩**：分娩前转运至有新生儿重症监护病房的医院（宫内转运）比出生后转运婴儿更安全。
- 分娩期针对**B族链球菌**的抗生素，以及出生时的最佳脐带处理和保暖（[[paediatrics/newborn]]）。

**PPROM。** 37周之前且临产之前发生的胎膜破裂，通过窥器检查见到液体积聚来诊断，诊断不明确时对阴道液进行床旁检测。其风险包括早产临产、**绒毛膜羊膜炎**（胎膜和羊水的感染）、脐带脱垂，以及孕周很早时的肺发育不良。给予红霉素（erythromycin）10天或直至临产、糖皮质激素，适当时给予硫酸镁，并监测感染。如果没有感染或其他问题，NICE建议考虑期待治疗至37周。无论孕周如何，绒毛膜羊膜炎都是分娩的指征。

::: example 26周胎膜破裂 {#ex-pprom}
一位30岁妇女孕26+2周，诉阴道突然流液。窥器检查见清亮液体积聚。她无发热，脉搏84次/分，CTG令人放心。概述她的处理；如果第二天她的体温为38.2 °C、脉搏112次/分、子宫压痛且液体有臭味，处理又有何改变？
::: solution
**就诊时。** 这是26周的PPROM。她被收入有新生儿重症监护的单位（或转运至这样的单位）。给予红霉素、产前糖皮质激素，若分娩迫近则给予用于神经保护的硫酸镁。定期记录体温、脉搏和胎心等观察指标，并以趋势追踪包括C反应蛋白和白细胞计数在内的血液检查。新生儿团队与父母会面，讨论在这一孕周出生意味着什么。如果她一直状况良好，计划为期待治疗。

**第二天。** 发热、心动过速、子宫压痛和液体有臭味提示**绒毛膜羊膜炎**，它可进展为孕产妇脓毒症。她需要脓毒症处理，包括血培养和按当地指南使用广谱静脉抗生素，并需要**分娩**，因为在妊娠继续的情况下无法治疗受感染的子宫。通常引产或任其自然进展；剖宫产保留给常规的产科指征。分娩时新生儿团队必须在场。
:::
:::

## 胎儿生长受限

如果胎儿的估计体重或腹围低于第10百分位，即为**小于胎龄儿（SGA）**。许多SGA婴儿是体质性偏小而健康的。**胎儿生长受限（FGR）**是指婴儿未能达到其生长潜能，通常是由于胎盘功能不全。一项国际共识（Gordijn等，2016年）将早发型FGR（32周之前）定义为腹围或估计体重低于第3百分位、脐动脉舒张末期血流缺失，或大小低于第10百分位并伴多普勒异常。FGR是死产最大的可识别危险因素。

超声可以区分两者。在胎盘性FGR中，系列超声显示生长曲线向下跨越百分位线，羊水减少，多普勒研究显示**脐动脉**阻力逐渐增加：先是搏动指数升高，然后是舒张末期血流**缺失**，最终**反向**。胎儿将血液重新分配到大脑，使大脑中动脉阻力降低。**静脉导管**波形的晚期改变提示心功能失代偿。分娩时机需在胎儿状况恶化与早产之间权衡，依据多普勒结果和计算机化CTG，并遵循专科指南（例如RCOG关于SGA胎儿的指南）。

## 多胎妊娠

在英国，约每65次分娩中有一次是双胎，辅助生殖后更常见。关键概念是**绒毛膜性**，在早孕期通过超声确定。**双绒毛膜**双胎各有自己的胎盘。**单绒毛膜**双胎共用一个胎盘，两个循环之间有血管吻合。约10%–15%的单绒毛膜双羊膜囊妊娠会发生**双胎输血综合征**：经吻合血管的净血流使一个双胎容量负荷过重并伴羊水过多，另一个灌注不足并伴羊水过少。治疗方法是胎儿镜激光消融吻合血管。因此单绒毛膜双胎从16周起每两周做一次超声。所有双胎妊娠发生子痫前期、贫血、GDM、早产和FGR的风险都更高。NICE NG137（2019年）建议无并发症的双绒毛膜双胎从37+0周起计划分娩，无并发症的单绒毛膜双羊膜囊双胎从36+0周起计划分娩。

::: quiz
一位36周子痫前期妇女正在接受硫酸镁治疗。输注开始两小时后，她的膝反射消失，呼吸频率为每分钟14次。过去两小时尿量为30 mL。最恰当的即时措施是什么？
- [ ] 加快输注速度，因为反射消失提示抽搐即将发生。
- [x] 停止输注，检查血镁水平并紧急评估；如有呼吸抑制则给予葡萄糖酸钙。
- [ ] 继续输注，四小时后复查。
- [ ] 给予呋塞米以增加尿量，并继续输注。
::: solution
膝反射消失是镁中毒的最早征象，而少尿解释了药物蓄积的原因：镁经肾脏排泄。应停止输注，抽血查血清镁水平，并安排上级医生评估。呼吸抑制或呼吸停止用葡萄糖酸钙和气道支持处理。反射消失并不预示抽搐。
:::
:::

::: history
子痫——这种使一小部分妊娠复杂化、并夺去许多患者生命的抽搐——早在其病因被了解之前就已有描述。1920年代和1930年代普及的产前门诊，主要就是为了发现子痫之前出现的血压升高和蛋白尿。1995年，子痫协作试验表明，硫酸镁预防子痫再次抽搐的效果优于地西泮或苯妥英；2002年，Magpie试验表明，它使子痫前期妇女发生子痫的风险大约减半。阿司匹林预防经历了从1980年代中期最初的小型试验，到二十年结果不一的研究，才在2010年进入NICE指南（CG107：有一项高危因素或两项中危因素的妇女从12周起每日75 mg），后经ASPRE试验（2017年）强化，并以75–150 mg延续于NICE NG133（2019年）。在早产方面，决定性的发现来自新西兰：格雷厄姆·利金斯（Graham Liggins）在1969年注意到，胎内输注糖皮质激素后早产娩出的羔羊肺部出乎意料地已能充气；利金斯与罗斯·豪伊（Ross Howie）的随机试验于1972年发表，表明产前糖皮质激素减少了早产人类婴儿的呼吸窘迫和死亡。又过了二十多年，加上帕特里夏·克劳利（Patricia Crowley）1990年的荟萃分析，糖皮质激素才被常规使用。
:::

## 后续内容

分娩，包括引产、手术分娩和分娩期急症，见[[obstetrics-gynaecology/labour-birth]]。产后并发症，包括产后高血压、出血和VTE，见[[obstetrics-gynaecology/postnatal-period]]。早产儿和生长受限婴儿的护理见[[paediatrics/newborn]]，慢性高血压及其药物见[[cardiovascular/hypertension]]。

::: summary
- 妊娠期高血压是指血压达到或超过140/90 mmHg；重度高血压是指达到或超过160/110 mmHg，属于急症。
- 子痫前期是20周之后新发高血压，伴蛋白尿、母体器官功能障碍或子宫胎盘功能障碍；不需要蛋白尿。
- 子痫前期始于螺旋动脉重塑不良；处于应激状态的胎盘释放sFlt-1等抗血管生成因子，引起广泛的内皮功能障碍。只有娩出胎盘才能去除病因。
- 拉贝洛尔为一线治疗；硫酸镁预防和治疗子痫，需要监测反射、呼吸和尿量。通常从37周起计划分娩，重症时更早。
- 从12周起服用阿司匹林可降低风险增加妇女的早产期子痫前期；需治疗人数取决于基线风险（[[#eq-nnt]]）。
- NICE以空腹血糖达到或超过5.6 mmol/L或2小时值达到或超过7.8 mmol/L诊断妊娠期糖尿病；WHO标准更低。胎儿高胰岛素血症解释了巨大儿和新生儿低血糖。
- 胎盘早剥典型表现为疼痛、子宫压痛，出血可能为隐性；前置胎盘典型表现为无痛。在排除前置胎盘之前绝不用手指检查宫颈。
- 预期早产时，糖皮质激素（24+0至33+6周）、用于神经保护的硫酸镁（24+0至29+6周）以及在有新生儿重症监护的单位分娩可改善结局。
- FGR根据生长下降而怀疑，经多普勒确认；绒毛膜性决定双胎妊娠的风险。

## 习题

::: exercise 疾病分类 {level=1}
分类以下各例：(a) 12周时血压150/95 mmHg，之前无血压记录；(b) 30周时血压145/92 mmHg，血液检查正常，无蛋白尿，建档时血压为112/70 mmHg；(c) 同(b)，但肌酐为98 µmol/L。
::: solution
(a) **慢性高血压**，因为在20周之前就已存在；几乎可以肯定是孕前就有的。(b) **妊娠期高血压**：20周之后新发、无子痫前期特征的高血压。她需要持续监测，因为部分妇女会进展为子痫前期。(c) **子痫前期**：20周之后新发高血压伴肾功能障碍（肌酐达到或超过90 µmol/L），即使没有蛋白尿。
:::
:::

::: exercise 镁中毒的征象 {level=1}
按通常出现的顺序列出镁中毒的征象，并解释少尿的妇女为什么风险特别高。
::: solution
最先出现深腱反射消失（通常检查膝反射），继而呼吸抑制，然后心脏停搏。也可能出现肌无力、嗜睡和言语含糊。镁几乎完全经肾脏排出，因此尿量减少（在重度子痫前期中很常见）会导致蓄积。所以监测反射、呼吸频率和尿量，并备好葡萄糖酸钙，是每个方案的组成部分。
:::
:::

::: exercise 34周的瘙痒 {level=1}
一位孕34周的妇女手掌和足底剧烈瘙痒，夜间加重，无皮疹。你怀疑什么疾病？什么检查可以确诊？主要风险是什么？
::: solution
**妊娠期肝内胆汁淤积症。** 在排除病毒性肝炎、胆结石和子痫前期等其他肝病之后，发现血清胆汁酸浓度升高（19 µmol/L或以上）即可诊断。主要风险是死产，集中在胆汁酸峰值达到或超过100 µmol/L的妇女。熊去氧胆酸可能有助于缓解瘙痒，但不能减少不良围产结局。
:::
:::

::: exercise 需治疗人数 {level=2 check="round(1/(0.03*(1-0.4)))"}
一位妇女不服用阿司匹林时发生早产期子痫前期的风险为3%。如果阿司匹林使风险乘以0.4，需治疗人数是多少？四舍五入到最接近的整数。
::: hint
使用[[#eq-nnt]]，其中$p = 0.03$，$r = 0.4$。
:::
::: solution
绝对风险降低值为$0.03 \times (1 - 0.4) = 0.018$。需治疗人数为$1/0.018 \approx 55.6$，即在这一风险水平下约需**56**位妇女服用阿司匹林才能预防一例。
:::
:::

::: exercise 胎盘早剥还是前置胎盘？ {level=2}
一位患子痫前期的孕37周妇女突然出现剧烈腹痛。她的阴道流出约100 mL暗红色血液，脉搏125次/分，血压95/60 mmHg。子宫坚硬、压痛，CTG显示胎心率每分钟80次。可能的诊断是什么？什么解释了她的观察指标之间的不一致？即时的优先事项是什么？
::: solution
**胎盘早剥。** 子痫前期是危险因素，疼痛、子宫坚硬压痛和胎儿心动过缓都是典型表现。大部分出血隐藏在胎盘后方和子宫壁内，所以她的休克程度远大于100 mL可见失血量所提示的程度。还要注意，她"正常"的血压对子痫前期妇女来说是偏低的。胎盘早剥还会消耗凝血因子，可引起弥散性血管内凝血。

**优先事项。** 呼叫支援并启动大出血方案；建立两条大口径静脉通路；送检全血细胞计数、包括纤维蛋白原在内的凝血功能和交叉配血；用血液和血液制品复苏。胎儿存活且有心动过缓时，通常需要立即行1类剖宫产，同时纠正凝血功能障碍。要预见到产后出血。
:::
:::

::: exercise 双胎 {level=2}
在12周超声检查时发现双胎，只有一个胎盘，分隔膜很薄（"T征"）。绒毛膜性是什么？这种类型特有的并发症是什么？它如何改变产前保健？
::: solution
单个胎盘伴T征提示**单绒毛膜双羊膜囊**双胎（"λ征"，即胎盘组织伸入分隔膜基部，提示双绒毛膜双胎）。由于双胎共用一个有血管吻合的胎盘，他们有发生**双胎输血综合征**的风险，还有选择性生长受限的风险，以及一胎死亡时另一胎发生急性损伤或死亡的风险。保健在专科门诊进行，从16周起每两周做一次超声，观察羊水和生长的差异；如无并发症，从36+0周起计划分娩。
:::

::: exercise 多普勒的解读 {level=3}
一个29周胎儿的估计体重低于第3百分位。脐动脉多普勒显示舒张末期血流缺失；大脑中动脉搏动指数降低；静脉导管波形正常；计算机化CTG正常。解释每项发现及处理原则。
::: solution
**发现。** 估计体重低于第3百分位符合FGR的定义。脐动脉舒张末期血流缺失意味着胎盘阻力如此之高，以致舒张期没有前向血流，反映胎盘血管床的大部分已丧失。大脑中动脉搏动指数降低显示**脑保护效应**：胎儿正在将血液重新分配到大脑。静脉导管波形正常和计算机化CTG正常意味着胎儿尚未失代偿。

**处理。** 在有新生儿重症监护的胎儿医学单位进行管理。当分娩可能发生时给予产前糖皮质激素和硫酸镁。继续通过频繁的多普勒和计算机化CTG进行监测，当静脉导管或CTG出现异常时计划分娩；即使它们没有异常，也要在专科指南规定的孕周分娩，因为舒张末期血流缺失本身就与死产相关。这一阶段的分娩通常采用剖宫产，因为受损的胎儿难以耐受分娩。还要评估母亲是否患有子痫前期，后者常伴随胎盘性FGR出现。
:::

::: exercise 产后头痛 {level=3}
一位34岁妇女五天前顺利阴道分娩，妊娠过程正常。她因剧烈头痛和眼前闪光返回就诊。血压168/108 mmHg，尿试纸蛋白2+。给出鉴别诊断和处理的第一步。
::: solution
**鉴别诊断。** **产后子痫前期**伴子痫先兆最有可能，也最紧急：子痫前期可在分娩后首次出现，血压常在产后3–6天达到高峰。产后剧烈头痛的其他重要原因包括**硬脊膜穿破后头痛**（如果她做过硬膜外麻醉；呈体位性，无高血压）、**脑静脉窦血栓形成**（妊娠和产褥期是易栓状态）、**蛛网膜下腔出血或脑出血**、可逆性后部脑病综合征，以及偏头痛（此时为排除性诊断）。

**第一步。** 按方案紧急治疗重度高血压；因有神经系统症状给予硫酸镁；检查全血细胞计数、肾功能和肝功能及尿蛋白/肌酐比值；并进行神经系统检查。如果头痛不典型、有局灶体征或治疗后症状持续，安排紧急脑部影像检查。现在就需要内科或产科上级医生评估，而不是等到早上。
