产前的保健是产科真正发生大部分工作的地方：十五六次的常规访视、几次扫描、以及一整套“其全部目的就是在少数会出问题的妊娠出问题之前把它们找出来”的筛查的方案。**本章涵盖产检的日程表与它的证据的基础、作为“症状的解释者”的母亲的生理、从孕周的确定到生长的筛查与监测的方案、以及产前的门诊真正拥有常见的“既往存在的与妊娠特有的”状况**

## 日程表与它的生理

::: definition 产检的日程表与母亲的生理 {#def-schedule}
**一份标准低风险的日程表是这样的：在8到10周建档病史包括产科的与内科的及精神的及用药的及家族的；体质指数与血压及尿的检查；血液——血型与抗体、血细胞计数与铁蛋白、在有指征时的“红细胞的叶酸”、风疹的免疫、人类免疫缺陷病毒与乙型肝炎及梅毒；并按流行度与家族来源做“血红蛋白病的筛查”；在有危险因素时做“糖化血红蛋白或血糖”的血液检查；在11到14周做孕周的确定的超声在被提供时加“颈的透明层的测量；在18到22周做”系统排畸的联合筛查“；从28到36周做生长的监测系列的”耻骨联合到宫底的高度“，并对对被描绘成离群者或”小于孕周“者做超声，并为高风险的组别更早地做系列的扫描；以及在36周前后”关于乙型链球菌与胎位的“问题为臀位进行”外部的转胎位“的谈话。由助产士主导的与共同照护的模型对低风险的生育的女性在证据上是等价的——正是创造它们的研究——而技能在于知道”哪一项发现会把一桩妊娠移到另一边“，因为对母亲与胎儿双方的危险都是那位”在建档时低风险、而在30周变得不再低风险、却没有人盯着那个发生了变化的部分“的女性：高血压的疾病与子痫前期在晚期才自报家门，糖尿病在妊娠的中期出现，”胎儿的生长受限“是一桩第三季的疾病；而那本手册如今是随身携带与数字版的职责就是”让每一个见到她的人都能看到变化“。生理是解释者：”血压的下降与心率的上升及心输出量的增加“既解释了”正常的晕倒“、也解释了”隐匿的出血时被掩盖的休克“；生理的贫血血浆的容量上升40%到50%、而红的细胞的总量上升20%到30%意味着”第二季的血红蛋白低于10.5克/分升“是病理的，而决定补铁的是铁蛋白、不是平均红细胞的体积；那”伴代谢代偿碱性呼吸的碱中毒“使一个”正常的碳酸氢盐“成为”脓毒症或哮喘的失代偿“的危险信号；以及那条”左侧卧位避免主动脉与下腔静脉的压迫“的教学。”**

## 筛查与监测

::: definition 筛查的方案与它诚实的限度 {#def-screening}
**产前的筛查是任何一位临床医师都会接触到的最大的人群筛查的方案，而它服从筛查的教义：疾病、检查、治疗的通路、以及知情的选择。非整倍体的筛查国家的方案：早孕的联合筛查——“颈的透明层加生化”；或“按本地的委托而定的游离的脱氧核糖核酸无创的产前检测”；而“绒毛膜的取样或羊膜穿刺”被留给“选择诊断性的检查”的人——咨询的算术才是那份工作：“150分之一的高风险”意味着“150位这样的女性中有149位的妊娠是正常的”；假阳性会造成“与操作相邻的焦虑与小的操作相关丢失的风险”；而“游离的脱氧核糖核酸”无论对21三体多么准确，它仍是一项筛查——“其阳性预测值随流行度而下降，而其发现包含性染色体的与偶发的基因组的问题（各自披露的政策随国家而不同）”。结构的筛查：18到22周的系统筛查“按器官检出可变比例的主要畸形”无脑儿接近百分之百、而心脏的缺陷少得多“并随着切面的改进而在提高”；它的目的是分娩的规划与咨询，以及——对一份越来越长的清单而言——“胎儿的治疗或计划的产后的手术”，而不仅仅是终止。生长扫描的职责是“小于孕周与大于孕周”的检出在有指征时加多普勒；它诚实的限度是“耻骨联合到宫底的高度会漏掉三分之一的小于孕周的婴儿”——这就是为什么“超声的监测会在高风险的组别高血压与既往的小于孕周及糖尿病及吸烟及族裔与人口学的风险中被扩大”、以及为什么“定制的曲线图至今仍在辩论而未定论”。感染的常规人类免疫缺陷病毒与乙型肝炎及梅毒之所以存在，是因为“垂直的传播是可预防的、而治疗就在那本手册里”——“默认的检查并被记录的提供”是标准，它消除了“先天梅毒在英国近乎复燃的窗口”、并让乙型肝炎的“出生的剂量与随后的免疫”保持住它的良好记录。“**
:::

## 产前的门诊所拥有的状况

::: definition 产前的门诊所拥有的状况 {#def-conditions}
**门诊真实的病例构成：高血压的疾病（子痫前期急期的处理见[[obstetrics-gynaecology/pregnancy-complications]]）在这里以风险的评估开始——“20周的界限、为高风险的女性从12周起用阿司匹林75到150毫克、以及触发监测的血压与蛋白尿的阈值”；因为“产前的保健对可预防的死亡的最大的一份贡献，就是反复地、尽早地发现高血压的疾病”。贫血——为铁蛋白低者补铁；“为胎盘植入与剖宫产的出血的计划”设定输血的阈值与“自身血液的回收”；以及那份“血红蛋白病的方案镰状细胞与地中海贫血的筛查，配同伴的检测与宫内及输血的路径”——它是筛查在公平上的一大成功。代谢与内分泌：糖尿病的筛查与处理的路径对已知的糖尿病的“孕前糖化血红蛋白的目标”——因为“器官的发生在多数女性知道自己怀孕之前就完成了”；血糖的目标与胰岛素或二甲双胍；生长与畸形的监测；以及分娩的时机；甲状腺的疾病带“按妊娠三月特定的参考范围”与“多数女性在早期都需要增加的左甲状腺素的剂量”；以及剧烈呕吐的路径（硫胺素在葡萄糖之前；止吐药“一直用到安全的”；以及“当妊娠的晨起反应被过早地当成一个排除性的诊断时就会重演的韦尼克病的教训”）。神经与精神：癫痫——“孕前避免丙戊酸”作为医学中最成功的“致畸原的回避”的方案；抗癫痫浓度的监测与维生素K；以及围产的精神的健康在某些“保密的调查”的年度里它是母亲死亡的最大的单一原因——“药物对疾病”的辩论未治疗的严重的疾病有它自己胎儿的风险；能揭示既往发作的那段病史“上一次妊娠发生了什么？”是产科中产出最高的问题之一；以及“产后抑郁情绪的低落对抑郁对精神病”的区分它属于产褥的那一章，但要在这识别。物质的使用——阿片用“美沙酮或丁丙诺啡的维持、而不是在胎儿的应激下解毒”；酒精作为“已知的致畸原”；以及“烟草的支持与治疗”。感染——“曾经常规而在有症状时仍然重要无症状菌尿的筛查”；“关于李斯特与弓形的食物的建议是把你的回答里的软奶酪外皮洗掉的短版”；那位“带着水痘的暴露与水痘带状疱疹免疫问题来诊的女性”；教师中的“细小病毒B19的暴露”；以及“在接受治疗、病毒载量检测不到的”人类免疫缺陷病毒阳性的妊娠——“不需要择期的剖宫产”——是“当通路被资助时产前的内科学所能达成的一个故事”。再加上“伴其单绒毛膜的逻辑”的多胎的监测；少数“被 Rh 致敏的”；以及“子宫的瘢痕与胎盘的前置”的时间轴；门诊就靠清单运转，而技能在于“先问出这位女性有什么不同，再去套用清单”——[[cardiovascular/hypertension]]、[[endocrine/diabetes]]、[[psychiatry/lifespan-psychiatry]]、[[infectious-diseases/hiv]]。**
:::

::: example 那位“建档正常”却藏着病史的34岁女性 {#ex-booking}
一次12周的建档的预约：体质指数38、“两次在别人医院挺好的分娩”、血压138/88、无用药；当被问“还有别的吗？”，她提到她的姐姐“胎盘有些问题”、而她的两个孩子都小。
::: solution
**这里的一切都是可行动的（[[#def-schedule]]、[[#def-conditions]]）：会改变计划的病史——”两个孩子都小加一段胎盘的故事，就是能预测复发的生长受限与子痫前期的家族与产科的病史；来自没有人去调取的被转移的住院记录的那句挺好不算病史；而一次接受一切都挺好的建档是一桩行政的动作、不是临床的动作：去要记录，同时把被报告的模式当作数据“。随之而来的药理——”从现在开始用阿司匹林75到150毫克12周还在为高风险的子痫前期的预防的有效窗口之内——她的体质指数加上生长受限的病史加上妊娠间隔的因素；而那份指南的风险的清单要被当作一份清单、不是一条建议来读“；到晚期重新评估”血栓的预防“的风险；在这个体质指数下补维生素D；以及”早期的糖化血红蛋白加妊娠糖尿病筛查的计划“。随之而来的监测——”按单位的政策在系统的排畸时为子痫前期的高风险做子宫动脉的多普勒；因为她过去的孩子都小，从26到28周起做系列的生长扫描；以及那次明确的安全网的谈话——用她能复述的话谈胎动的减少与头痛及视觉的症状危险信号“。以及让这一切能运转的语气——把关于体质指数的谈话”记录为健康而不是责备——我们的工作是多看紧几样东西“；因为建档的病史采集里的污名，正是女性们在28周仍”带着她们真实的病史“到来的原因（[[clinical-skills/communication]]、[[clinical-skills/records-handover]]）。**

::: exercise 设计一场“胎动的觉察”的运动 {level=3}
::: solution
**胎动的运动（[[#def-screening]]、[[#def-conditions]]）：先说临床的真相——“胎动的减少是一个带良好阴性值的弱预测器：大多数感到减少女性的结局是正常的；这正是为什么把它打发走在九十次里是安全的、而在第九十一次是致命的；胎心监护的作用是有限的，而让人安心的监护并不能排除那个小的、缺氧的或贫血的胎儿——这就是为什么对一个成立担忧的响应是一次有结构的评估症状与宫底的高度及胎位、在孕周提示时做监护、以及当可能偏小时做生长及羊水及多普勒、而不是被当作判决的一项检查“。文化的工作——”每一位专业人员都要学的三句话的脚本：这很可能什么也不是——而我们要查，因为有时它是唯一的信号；在这个阶段这是常事这句话被加进模拟中的绝不能说的清单；以及当日可及的规则：一位为胎动减少而接受评估的女性离开时要知道查了什么、意味着什么、何时再来；出院的记录要写成今晚可以念给她伴侣听的形式“。引产的平衡——”关于晚期的预约性的引产试验诚实的数字并不支持为焦虑而一概引产；而这场运动的测量指标不是每一千例的引产数，而是被报告的胎动减少之后的死产数加上从报告到评估的时间；对诉讼的恐惧由文件的标准与遵循指南路径的抗辩来回答，而不是由教会女性不话来回答”（[[public-health/screening]]、[[clinical-skills/patient-safety]]）。**

::: example 那位28周“低置的胎位”与体质指数42 {#ex-anaemia}
一位28周才建档第一次就诊、没有病历的女性，体质指数42、血红蛋白8.9克/分升、铁蛋白4、“O型 Rh 阴性”的血型，以及一只有肌瘤的子宫它让“宫缩的时机”难以判断。
::: solution
**一次全办（[[#def-schedule]]、[[#def-conditions]]）：晚建档者的顺序——“第一天的集束：即便在28周也要安排孕周的确定与畸形的评估晚期的扫描仍能回答胎盘的位置与胎位及生长；重复的血液检查，并把铁蛋白4的缺铁现在就读——立即开始口服的铁，考虑到到分娩的短跑道以及体质指数与肌瘤加上出血的风险，同时考虑静脉的铁；血型与抗体被确认，并安排抗 D 的预防因为她是 Rh 阴性，而任何出血或操作都是一次致敏的事件；子痫前期的那套包——现在并反复地查血压与蛋白及血小板及肝与肾的功能；阿司匹林仍值得开始尽管预防的窗口最好在16周之前；以及被记录的血栓的风险的评估与第三季及产褥的计划——因为在28周以42的体质指数建档，意味着血栓的预防的谈话不能等一位资深者注意到她“。贫血的检查——”这里的两个原因是缺铁，以及若家族来源符合地中海贫血的特征——先治铁、复查血细胞计数与铁蛋白；而输血与血液的回收的谈话属于分娩的计划，不属于剖宫产的那个夜晚“。以及连续性的修补——”一位具名的助产士为碎片负责；随身携带的记录从今天开始把所有东西复印一份；今天就把全科与社区的服务通知到；以及那次“分娩地点”的谈话——诚实地框定，而不是把风险最小化（[[blood/anaemia]]、[[clinical-skills/records-handover]]、[[obstetrics-gynaecology/labour-birth]]）。**

::: example 那次16周的水痘的接触 {#ex-varicella}
一位16周的教师的班在两天前出现了水痘；她记不得自己得过水痘；而本地的“水痘带状疱疹的免疫球蛋白 M”的结果要三天后才回来；她很害怕，并在问“扫描会不会显示损害”。
::: solution
**水痘暴露的咨询（[[#def-conditions]]、[[#def-screening]]）：把恐惧组织起来的事实——”她的风险在于她是否有免疫：大多数的成人大都是；从接触到皮疹的窗口是10到21天，所以今天是第2天，而有传染性的风险更晚才开始；胎儿风险的数字是小的且有时间的特定性——胚胎病基本上是一个20周之前的风险以每一百例被暴露并感染的个位数的百分比来衡量；而新生儿的危险是妊娠最后几周感染，不是现在“。路径——”现在就去查免疫球蛋白 M 与 G不管等待时间的尴尬——在正确地请求时，结果常常可以被加急；若她是易感的、并处在提供预防的窗口之内，给水痘带状疱疹的免疫球蛋白；避免进一步的暴露与出现的征象的建议避开更多的接触；从皮疹出现起就隔离；一旦出现皮疹就尽早就诊——带着那条让怀孕成为尽快用抗病毒药的理由而不是等待的理由的母亲肺炎的告诫；以及按政策决定复查扫描的时机，因为详细的排畸的扫描会去找胚胎病的征象并诚实地解释正常的扫描无法证明一个本就不太可能发生的东西。以及那门元课程——“一位害怕的孕妇等一张化验单的这三天本身就是一个临床的事件：把数字给她、把时间线给她、把会带着结果打电话来的人的名字与打电话的时间给她；并把计划写在她的助产士与非办公时间的服务都能找到的地方，因为这正是那通凌晨的电话能被避免的原因”（[[infectious-diseases/hiv]]、[[clinical-skills/communication]]）。**

## 通向何处

高血压的与内科的急症在[[obstetrics-gynaecology/pregnancy-complications]]，分娩的力学在[[obstetrics-gynaecology/labour-birth]]，产后的照护与出血在[[obstetrics-gynaecology/postnatal-period]]，早孕的综合征在[[obstetrics-gynaecology/early-pregnancy]]，而筛查的教义在[[public-health/screening]]。

::: history
**产前的保健比产科这个专科更老、又比助产士更年轻：最早的“产前的门诊”作为“婴儿的福利与妊娠的门诊的服务”出现在“爱德华时代与两次大战之间的英国”——那1918年的关于“产科的设施与助产士的讨论”、以及那本“主张妊娠本身就能使人生病”的1914年的教科书、以及“把分娩从家中搬到院里”的那次世纪中叶的位移它让孕妇第一次变成了患者。科学的脊柱来自在三个不同的国家被重复的三项观察：建档手册的监测降低了“高血压与生长受限的少数人”中的死产战后的试验、以及“母亲死亡自愿的编码”——始于1926年的“母亲死亡保密的调查”——发明了“每一次死亡都教导这个服务”的现代审计的文化、并早于“全球卫生的词汇”给出了“三次延误”这个短语；筛查必须被赢得——1960到70年代的那段 Rh 的疾病的故事抗 D 的免疫球蛋白把“新生儿溶血的疾病”这一最常见的原因变成可预防的，并创造了整个方案所遵循的那个模板检查、预防、审计；以及某些“常规的”检查是坏医学——1970到80年代“胎心监护带来不必要的干预”的辩论、以及“雌三醇与胎盘的功能的检测在试验显示无益之后被抛弃”、以及“至今仍在进行的常规地引晚期的论证”。技术的浪潮——超声与“电脑的普及与如今的数字的手册”——一再重演同一课：“工具本身不降低死亡率，被一致执行的路径才会”（[[public-health/screening]]、[[clinical-skills/patient-safety]]、[[epidemiology-ebm/measuring-disease]]）。**
:::

::: summary
- 日程表是一整套“为那1%到10%的尾巴”的监测的系统：建档病史的质量决定了下游的一切，而生理改写了“每一项检查被读出来的方式”。
- 用阿司匹林预防子痫前期、用铁蛋白处理贫血、用“默认的检查”预防垂直的感染——产前的保健最大的几场胜利既便宜又依赖时机。
- 筛查仍然是筛查：咨询是算术；“游离的脱氧核糖核酸”是一项“有阳性预测值的”检查；而报告应当被写成“患者能读懂的”。
- 每一种内科的疾病都有一个妊娠的版本：孕前是最好的一次产前的访视；而“上一次妊娠发生了什么”是整本手册中产出最高的问题。
- 生长的曲线是第三季的生命征：跨越百分位线是一次转诊，不是一次重测。
- 公平与精神的健康是产前的安全的问题：保密的调查那反复出现的发现是通路的失败、而不是生物学；而两者在同一台查房上被测量。
:::

::: exercise 搭建那次建档的会诊 {level=1}
::: solution
**建档的要点（[[#def-schedule]]、[[#def-conditions]]）：“变化的管理者”——既往的剖宫产或大的子宫的手术分娩方式的谈话与瘢痕的时间轴；高血压或肾的疾病阿司匹林与监测；既往静脉的血栓“贯穿妊娠与产褥的血栓的预防的规划”；癫痫与精神的药物丙戊酸与锂的咨询，并在可能时做孕前；自身免疫的疾病抗体与发作的规划；“镰状细胞或地中海贫血的家族来源”同伴的检测；减重的手术贫血与“微量营养素的监测”；以及当前的用药包括非处方的与草药的。两个会揭示问题的问题——“用你自己的话，说说你其他几次妊娠发生了什么？”既往的死产与子痫前期或早产就藏在这里、没有被说出来，因为没有人问得足够久；以及“有什么是你担心的却没有提到过的？”——因为那位要交代酒精或“伴侣的愤怒”或“她停掉甲状腺的药片”的女性，在等的是一扇门、不是一张表格。以及记录的规则：“每一个回答都要落在下一位临床医师能检索到的一个字段里”，因为“机构之间的病历的转移是这个系统最古老的失败”（[[paediatrics/newborn]]、[[clinical-skills/history-taking]]）。**

::: exercise 解读三个“异常的”结果 {level=2}
::: solution
**三个数字（[[#def-conditions]]）：（1）缺铁的贫血“正常的”妊娠的稀释并不会让铁蛋白9变成正常——口服的铁配维生素C；“如今更被看好的隔日的给药为了吸收与耐受”；2到4周复查；并在同一口气里问“饮食与献血的问题”，以及“若是难治的”就想想出血的来源。（2）15周时升高的血压：按“妊娠高血压的风险”建档；用重复的测量、“在边界时动态的监测”来确认；若尚未用阿司匹林就用到16周“预防的窗口就变窄了”；加上监测的包；以及那句教学——“症状只在数字之后才重要”——这位女性会成为子痫前期的统计数字还是幸存者，只取决于随访。（3）24周的糖化血红蛋白6.0：“在早期空腹血糖正常的前提下，这处在妊娠糖尿病的边界上；本地的路径在糖负荷筛查的结果与糖化血红蛋白之间各不相同，所以要遵循本单位的筛查；如果在边界，诚实的计划是不带罪感的生活方式的建议，加上两周的“空腹与餐后的毛细血管的血糖的监测”，以及在图形越过目标时治疗“。三个病例、三种被避免的推理的错误：把铁当作稀释而打发；把血压当作”白大衣”而在没有数据的情况下打发；以及治疗一个数字而不是一个图形（[[endocrine/diabetes]]、[[cardiovascular/hypertension]]）。**
