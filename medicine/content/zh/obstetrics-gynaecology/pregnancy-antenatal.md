大多数妊娠只需很少的医疗帮助就能顺利结束。产前检查是为少数不顺利的妊娠而设的，其难点在于，两组人在开始时看起来完全一样。一位胎盘正开始衰竭的妇女，在12周时的感觉与一位妊娠将完全正常的妇女一样好。因此，产前检查依靠反复、有结构的检查来发挥作用：建档时仔细的病史采集、一小组血液检查、两次超声检查、每次就诊时测量血压和检查尿液，以及绘制在图表上的胎儿生长测量值。每一项内容之所以存在，是因为它能发现可以处理的问题。

要解读这些检查，首先必须知道妊娠期什么是正常的，而妊娠期的正常是不同的。血容量增加近一半，肾脏滤过增加，呼吸模式改变，凝血系统向血栓形成倾向偏移。一个在非孕妇女中正常的血红蛋白、肌酐或血气结果，在妊娠期可能是一个警示信号，反之亦然。

本章介绍描述妊娠所用的术语、母体生理、英国常规产前检查的时间安排和内容、胎儿疾病的筛查，以及妊娠对用药提出的原则。并发症本身见[[obstetrics-gynaecology/pregnancy-complications]]；激素背景见[[endocrine/reproductive-endocrinology]]。

## 描述一次妊娠

### 孕龄与日期

按照惯例，**孕龄**从末次月经（LMP）的第一天开始计算，而不是从受孕开始。在规律的28天周期中，排卵和受精发生在末次月经后约两周，所以一位"怀孕6周"的妇女所怀的胚胎在受孕后约4周。孕龄以完整的周和天书写：32+4表示32周零4天。

**预产期（EDD）**是末次月经后280天（40周）。内格莱规则（Naegele's rule）是传统的简便算法：加一年，减三个月，再加七天。由于各月天数不等，简便算法与280天计数可能相差一两天。周期长于28天会使排卵推迟，使按末次月经推算的孕龄偏大。

在英国的实践中，日期通过超声来核实，并且通常以超声结果取代。在10+0至13+6周之间，**头臀长（CRL）**给出的孕龄误差约在五天以内。如果头臀长超过84 mm，则改用头围。一旦以超声确定了孕龄，后续超声就不再更改它，因为此后的大小差异反映的是生长情况，而不是日期。

::: definition 妊娠的时间界标 {#def-landmarks}
- **早孕期（孕早期）**：至13+6周。**中孕期（孕中期）**：14+0至27+6周。**晚孕期（孕晚期）**：自28+0周起。
- **早产**：37+0周之前分娩。**足月**：37+0至41+6周。**过期**：42+0周或以后。
- **流产**：24+0周之前的妊娠丢失。**死产**：在24+0周或以后娩出的无生命迹象的婴儿。这些是英国法律和实践中使用的定义；WHO在国际比较中使用22周或28周，因此在比较不同国家的发生率之前，应先核对所用的阈值。
:::

### 孕次与产次

产科病史用两个数字概括，许多学生会弄错。

::: definition 孕次与产次 {#def-gravidity-parity}
**孕次**是一位妇女怀孕的次数，无论结局如何，**包括当前这次妊娠**。双胎妊娠算作一次妊娠。

**产次**在英国实践中是24+0周之后分娩的次数，无论婴儿是活产还是死产，再加上任何24周之前的活产。通常写作**P a+b**，其中*a*是此类分娩的次数，*b*是在24周之前丢失的妊娠次数（流产、异位妊娠、葡萄胎和人工流产）。

从未怀孕过的妇女称为**未孕妇女**。从未分娩过的妇女称为**未产妇**；处于第一次妊娠的妇女称为**初孕妇**。曾经分娩过的妇女称为**经产妇**。
:::

这种记法是一个概括，而不是故事本身的替代。不同单位对多胎分娩的计法不同：有些单位把一次双胎分娩算作一次产次，有些按每个婴儿计数。稳妥的做法是用文字逐次写出每次妊娠：年份、孕周、分娩方式、结局、出生体重和并发症。"P1"并不能说明那次分娩是顺利的阴道分娩，还是因子痫前期在28周行急诊剖宫产，而后一个事实会改变本次妊娠的计划。

::: example 写出概括 {#ex-gp}
一位妇女现孕20周。她曾在39周阴道分娩一子，曾在9周流产一次，还曾因胎盘早剥在30周娩出一死产女婴。写出她的孕次和产次，并说明这一概括掩盖了什么。
::: solution
包括本次在内，她共怀孕四次，所以是**孕4次**。有两次妊娠以24周之后的分娩告终（足月分娩和死产），一次在24周之前结束，所以产次为**2+1**，记作G4 P2+1。

这一概括掩盖了最重要的事实：既往因胎盘早剥发生过死产。胎盘早剥在之后的妊娠中复发的概率高于一般人群，而既往死产会改变本次妊娠的生长监测计划、分娩时机以及她所需要的情感支持。病史必须用文字写出，而不能只用代码。
:::
:::

## 母体生理

妊娠几乎改变每一个器官系统。大多数变化由孕酮、雌激素、人绒毛膜促性腺激素（hCG）、人胎盘催乳素和松弛素驱动，也由增大子宫的机械作用引起。这些变化有其目的：为一个足月时约重3.5 kg、接受约十分之一母体心输出量的胎儿提供供给，并使母亲做好准备，以便在分娩失血时得以存活。

::: theorem 妊娠重设了正常范围 {#thm-new-normal}
许多实验室和临床指标在妊娠期有不同的参考范围。解读结果时应对照该孕周的妊娠期范围，而不是非孕期范围。一个对非孕成人来说"正常"的数值，在妊娠期可能代表严重的疾病。
:::

::: proof
这些变化源于几项生理上的转变。

**循环。** 孕酮和一氧化氮使血管平滑肌松弛，因此在早孕期外周血管阻力下降。肾脏对较低的血压作出反应，通过肾素-血管紧张素-醛固酮系统潴留钠和水。到晚孕期，血浆容量增加约40%–50%，而红细胞量只增加约20%–30%。结果是血红蛋白浓度下降，即妊娠期**生理性稀释性贫血**。心输出量增加30%–50%，这既来自每搏输出量增加，也来自心率加快约每分钟10–15次。血压通常在中孕期下降，至足月时回升至接近孕前水平。

**肾脏。** 肾血浆流量和肾小球滤过率增加约50%，因此血清肌酐和尿素下降。一个在妊娠以外属于正常的肌酐值，对孕妇来说可能意味着滤过功能的大量丧失。

**呼吸。** 孕酮提高呼吸中枢对二氧化碳的敏感性。潮气量增加约30%–40%，而呼吸频率几乎不变，因此每分通气量增加，动脉血$P_{\text{CO}_2}$降至约4 kPa（30 mmHg）。肾脏排出碳酸氢盐加以代偿，形成轻度代偿性呼吸性碱中毒。一位气促的孕妇如果$P_{\text{CO}_2}$"正常"为5.3 kPa，提示她正在疲劳并潴留二氧化碳。

**凝血。** 纤维蛋白原及凝血因子Ⅶ、Ⅷ、Ⅹ升高，血管性血友病因子升高，蛋白S下降，纤溶受到抑制。再加上盆腔静脉受压导致的静脉淤滞，使妊娠期和产后数周成为一种易栓状态，以便在胎盘剥离时止血。其代价是静脉血栓栓塞（VTE）的风险增加数倍。

**代谢与激素。** 胎盘激素，尤其是人胎盘催乳素，使母亲在妊娠后半期胰岛素抵抗逐渐加重，从而为胎儿保留葡萄糖。胰腺不能足够增加胰岛素分泌的妇女会发生妊娠期糖尿病。hCG具有较弱的促甲状腺活性，因此在早孕期游离甲状腺素可升高而TSH下降。碱性磷酸酶升高，因为胎盘会产生自己的同工酶。
:::

| 指标 | 妊娠期的变化 | 实际意义 |
|---|---|---|
| 血红蛋白 | 因稀释而下降 | 贫血定义为早孕期Hb < 110 g/L，中、晚孕期< 105 g/L，产后< 100 g/L（英国） |
| 肌酐 | 下降（常为45–70 µmol/L） | 肌酐达到或超过90 µmol/L是子痫前期肾脏受累的标志 |
| $P_{\text{CO}_2}$ | 降至约4 kPa | 非孕期的正常值可能意味着呼吸肌疲劳 |
| 白细胞计数 | 升高，分娩时更高 | 轻度中性粒细胞增多本身不是感染的证据 |
| 碱性磷酸酶 | 升高（胎盘来源） | 在晚孕期不是肝脏或骨骼疾病的可靠标志 |
| 纤维蛋白原、D-二聚体 | 升高 | D-二聚体在妊娠期不能用于排除VTE |
| 游离T4、TSH | 早孕期TSH下降 | 使用各孕期特异的范围 |

有两种机械效应在床旁很重要。从约20周起，平卧的妇女会被子宫压迫下腔静脉和主动脉，静脉回流和心输出量下降，她可能出现低血压和晕厥（**主动脉-腔静脉压迫**）。这就是为什么对孕妇进行检查和复苏时要采取左侧倾斜体位，或用手将子宫推向左侧。其次，孕酮使食管下括约肌松弛并减慢胃排空，引起烧心，并增加全身麻醉时误吸的风险。

::: example 这个结果正常吗？ {#ex-bloods}
一位31岁妇女孕30周，常规血液检查：血红蛋白108 g/L，肌酐82 µmol/L，血小板165 × 10⁹/L，碱性磷酸酶210 U/L。血压128/80 mmHg。解读各项结果。
::: solution
- **血红蛋白108 g/L**高于晚孕期105 g/L的阈值，按英国妊娠期标准她没有贫血。但仍应与建档时的数值比较，因为大幅下降提示正在发生缺铁。
- **肌酐82 µmol/L**在非孕妇女中属正常，但对孕30周来说偏高，因为此时滤过应当是增加的。它低于子痫前期所用的90 µmol/L标志，但值得复查并测定尿蛋白。
- **血小板165 × 10⁹/L**正常。妊娠晚期血小板计数轻度下降很常见（妊娠期血小板减少症），但呈下降趋势时需要关注，因为血小板减少是子痫前期和HELLP综合征的特征之一。
- **碱性磷酸酶210 U/L**在晚孕期是预期之中的，原因是胎盘同工酶，单独出现不需要进一步检查。

教训正是[[#thm-new-normal]]：如果使用非孕期范围，肌酐是会被忽略的那个结果，而它恰恰是重要的那个。
:::
:::

## 英国的产前检查

### 检查安排

在英格兰，产前检查遵循NICE指南NG201（《产前检查》，2021年）。首次就诊即**建档就诊**，最好在10+0周之前完成。一位健康的未产妇如果妊娠无并发症，会得到约十次检查，经产妇约七次。患有内科疾病或既往有并发症的妇女还会在顾问医生主导的门诊接受额外随访。

建档就诊承担三项任务：

1. **信息与预防。** 建议每日服用叶酸400微克至12周，以降低神经管缺陷的风险；对风险较高的妇女建议更高剂量（5 mg），例如患有糖尿病、既往妊娠有神经管缺陷、BMI达到或超过30，或服用某些抗癫痫药物者。建议在整个妊娠期和哺乳期每日补充维生素D 10微克。咨询内容包括吸烟（对所有妇女提供一氧化碳检测）、饮酒（不存在已知的安全饮酒量）、食品安全和疫苗接种。
2. **风险评估。** 病史采集要寻找既往产科并发症、内科疾病、精神健康问题、保护方面的问题以及家庭暴力；家庭暴力常在妊娠期开始或加剧。应在妇女单独就诊时询问家庭暴力问题。记录身高、体重和BMI、血压及尿液检查。
3. **筛查试验。** 在建档时提供，见下文。

在之后的就诊中，助产士测量血压、检测尿蛋白、询问胎动和健康情况，并从24周起以厘米测量**宫高（耻骨联合-宫底高度）**，绘制在生长曲线图上。在36周检查胎方位，因为臀位可以提供外倒转术。

### 妊娠期疫苗接种

2026年在英国，孕妇可接种百日咳疫苗（从16周起，最好在32周之前，使母体抗体在婴儿自身接种疫苗之前保护婴儿）、在流感季节任何孕期的流感疫苗，以及从28周起的RSV疫苗。妊娠期避免接种MMR等活疫苗，对无免疫力的妇女在产后接种。接种安排随季节变化；见[[paediatrics/immunisation]]。

### 常规筛查试验

::: definition 产前筛查 {#def-screening}
**筛查**是向无症状的人提供一项检查，以识别出患某种疾病概率较高的人，从而为其提供诊断性检查或治疗。筛查试验将人分为**较高概率**组和**较低概率**组；它并不作出诊断。每一项产前筛查都是自愿的，需要知情同意。
:::

英格兰的常规项目（NHS筛查项目，2026年）包括：

| 检查 | 时间 | 目的 |
|---|---|---|
| 血型和红细胞抗体 | 建档时和28周 | 识别RhD阴性妇女和可导致胎儿溶血病的抗体 |
| 全血细胞计数 | 建档时和28周 | 贫血 |
| 镰状细胞病和地中海贫血 | 建档时（最好在10周之前） | 识别携带者；阳性时检测婴儿父亲；提供产前诊断 |
| HIV、乙型肝炎、梅毒 | 建档时 | 治疗和干预可预防向婴儿传播 |
| 尿培养 | 建档时 | 治疗无症状菌尿，它在妊娠期可进展为肾盂肾炎 |
| 唐氏综合征、爱德华兹综合征和帕陶综合征筛查 | 10+0至14+1周（联合筛查）或14+2至20+0周（四联筛查） | 较高概率时提供进一步检查 |
| 超声定孕龄检查 | 10+0至13+6周 | 确定孕龄、胎儿数目和绒毛膜性，以及部分重大畸形 |
| 胎儿畸形筛查超声 | 18+0至20+6周 | 结构畸形、胎盘位置 |
| 口服葡萄糖耐量试验 | 24至28周，有危险因素时 | 妊娠期糖尿病 |

英格兰于2016年停止了风疹免疫筛查，因为风疹在英国现已十分罕见，而且筛查并不能及时识别出妇女以保护本次妊娠。

**染色体疾病的筛查。** **联合筛查**利用超声测量的颈项透明层（胎儿颈后充满液体的间隙）、母亲年龄和两种血液标志物——游离β-hCG和妊娠相关血浆蛋白A（PAPP-A）——计算胎儿患21三体（唐氏综合征）的概率，并分别计算18三体或13三体（爱德华兹综合征或帕陶综合征）的概率。概率达到或高于1/150报告为较高概率。此后妇女可以选择不再进一步检查、选择**无创产前检测（NIPT）**——分析其血液中来自胎盘的游离DNA——或选择诊断性检查：**绒毛取样**（约11周起）或**羊膜腔穿刺**（15周起）。诊断性检查带有少量额外的流产风险，通常引用约0.5%。NIPT的检出率远高于联合筛查，假阳性率更低，但NIPT阳性结果在作出任何不可逆的决定之前，仍需要诊断性检查确认。

使用图中的示例数值：该疾病影响1/250的妊娠，筛查试验检出85%的受累妊娠，未受累妊娠中有2.5%筛查阳性。在10,000名接受筛查的妇女中，有多少人筛查阳性？其中受累妊娠占多大比例？
::: solution
受累妊娠：$10\,000 \times 0.004 = 40$。其中$40 \times 0.85 = 34$例筛查阳性（真阳性），6例漏检。

未受累妊娠：$9\,960$。其中$9\,960 \times 0.025 = 249$例筛查阳性（假阳性）。

筛查阳性总数：$34 + 249 = 283$。阳性预测值为
$$
\text{PPV} = \frac{34}{283} \approx 0.12,
$$
因此在得到较高概率结果的妇女中，约12%的妊娠受累，88%未受累。这就是为什么筛查阳性结果引出的是进一步检查的提议，而绝不是诊断，也是为什么咨询时使用"较高概率"而不是"阳性"这样的措辞。

### 血型与抗D

红细胞缺乏RhD抗原的妇女（RhD阴性，约占白人欧洲妇女的15%，在许多其他人群中更少），如果胎儿的RhD阳性红细胞进入其循环，就可能产生抗D抗体。这种**致敏**可发生在分娩时、出血后、腹部外伤或操作后，有时在晚孕期悄然发生。在之后的妊娠中，抗D抗体通过胎盘破坏RhD阳性胎儿的红细胞，引起**胎儿和新生儿溶血病**：贫血、水肿，以及出生后严重的黄疸。

给予抗D免疫球蛋白可预防致敏，它在母体免疫系统产生应答之前清除胎儿细胞。英国的做法是：

- 晚孕期**常规产前抗D预防**，根据当地方案，或在约28周单次给药，或在28周和34周分两次给药。
- 12周之后发生**潜在致敏事件**（出血、腹部外伤、外倒转术、羊膜腔穿刺）后给予抗D，最好在72小时内。
- 分娩后检查婴儿血型。如果婴儿为RhD阳性，母亲接受抗D，并检测胎母输血量（Kleihauer试验或流式细胞术）以决定是否需要追加剂量。

许多服务机构现在提供基于母血游离DNA的**胎儿RhD基因分型**。如果预测胎儿为RhD阴性，就不需要抗D，这样可以避免给约40%并不需要的RhD阴性妇女使用血液制品。

::: warning 抗D对已经致敏的妇女无效
抗D免疫球蛋白预防抗体的形成；它不能清除已经存在的抗体。抗体筛查显示存在免疫性抗D的妇女需要另一条路径：系列抗体水平监测、转诊至胎儿医学中心，以及超声测量胎儿大脑中动脉峰值流速以发现胎儿贫血。给予预防之前务必核对抗体筛查结果；在预防性给药后不久检出抗D时，未与实验室讨论之前不要将其解读为致敏。
:::

### 识别风险并采取行动

建档病史也被用于开始预防性治疗。有两个标准的例子。

**阿司匹林降低子痫前期风险。** 根据NICE NG133（《妊娠期高血压》，2019年，2023年更新），建议子痫前期高风险的妇女从12周起直至分娩每日服用阿司匹林75–150 mg。高风险是指存在**一项高危因素**：既往妊娠有高血压疾病、慢性肾脏病、系统性红斑狼疮或抗磷脂综合征等自身免疫病、1型或2型糖尿病，或慢性高血压。也指存在**两项或以上中危因素**：首次妊娠、年龄40岁或以上、距上次妊娠超过10年、建档时BMI达到或超过35、子痫前期家族史，或多胎妊娠。

**血栓预防。** 每位妇女在建档时、任何一次入院时和分娩后都要有记录在案的VTE风险评估，遵循英国皇家妇产科医师学院（RCOG）的指南。既往有VTE，或有多项危险因素（如肥胖、年龄超过35岁、产次达到或超过三次、吸烟、制动和某些内科疾病）的妇女，按其风险评分接受一段时间的低分子量肝素（LMWH）。

其他危险因素引出具体的计划：对BMI超过30、既往婴儿体重达到或超过4.5 kg、既往患妊娠期糖尿病、一级亲属患糖尿病或祖籍来自糖尿病高患病率人群的妇女，在24–28周进行**葡萄糖耐量试验**；对小婴儿风险较高的妇女进行**系列生长超声**；对既往有严重精神疾病的妇女进行**精神卫生转诊**。

::: example 建档时的风险评估 {#ex-booking}
一位41岁妇女首次妊娠，在10周建档。BMI为36，血压132/84 mmHg。无既往病史。她的母亲曾患子痫前期。她需要哪些预防措施？
::: solution
**子痫前期风险。** 她没有高危因素，但有四项中危因素：首次妊娠、年龄40岁或以上、BMI达到或超过35、子痫前期家族史。两项或以上中危因素即达到NICE的阈值，因此建议从12周起直至分娩每日服用阿司匹林75–150 mg，剂量遵循当地指南。

**妊娠期糖尿病。** BMI超过30是危险因素，因此应在24–28周为她提供口服葡萄糖耐量试验。

**VTE。** 年龄超过35岁和肥胖是危险因素。她需要正式评分；根据其他因素，她可能需要产前或产后LMWH。

**其他。** 由于她的BMI达到或超过30，建议使用较高剂量的叶酸（5 mg）。应使用尺寸合适的袖带仔细测量血压，因为对上臂较粗的妇女，袖带过小会高估血压。她应在顾问医生主导的门诊随访；由于肥胖使宫高测量不可靠，通常在晚孕期为她提供系列生长超声。
:::
:::

### 胎儿生长与胎动

胎儿生长的监测方法是从24周起测量宫高、绘制在图表上，如果单次测量低于第10百分位，或系列测量显示生长减慢，则安排超声检查。对有小婴儿危险因素或宫高无法准确测量的妇女，则改为提供系列超声。在出生前发现小婴儿很重要，因为胎儿生长受限的婴儿死产风险增加，而及时分娩可以降低这一风险（[[obstetrics-gynaecology/pregnancy-complications]]）。

大多数妇女在约18至20周时开始感觉到胎动。胎动逐渐增加至约32周，此后维持在相近水平直至分娩；接近足月时胎动通常不会减少。应告知察觉胎动减少的妇女当天就联系产科病房，而不要等到下一次产检。胎动减少可能先于死产出现，评估通常包括胎心监护（CTG），并根据检查结果和危险因素进行超声检查。

## 妊娠期用药

几乎所有药物都能在一定程度上通过胎盘。一种药物是否伤害胎儿，取决于药物、剂量，最重要的是**时间**。

- 受孕后的头两周内，暴露往往导致妊娠丢失或毫无影响（"全或无"）。
- 受孕后约3至8周（孕5至10周），器官正在形成（**器官发生期**）。此时最容易发生结构畸形。
- 之后的暴露可影响生长和器官功能，例如胎儿肾脏或动脉导管。

重要的例子：**丙戊酸钠（sodium valproate）**导致神经管缺陷和其他畸形，并损害神经发育，在英国，除非已实施妊娠预防计划，否则不得用于可能怀孕的妇女；**异维A酸（isotretinoin）**和**甲氨蝶呤（methotrexate）**是主要的致畸药物；**华法林（warfarin）**在早孕期引起胚胎病，之后引起胎儿出血；**血管紧张素转换酶抑制剂和血管紧张素受体阻滞剂**在中、晚孕期损害胎儿肾功能；**四环素类**使牙齿和骨骼着色；**非甾体抗炎药**在约20周起使用可降低胎儿肾功能，在晚孕期可使动脉导管过早关闭。

妊娠也改变药代动力学。分布容积增大、肾清除率升高和肝酶诱导会降低拉莫三嗪（lamotrigine）和左乙拉西坦（levetiracetam）等药物的浓度，因此癫痫妇女在整个妊娠期可能需要监测和调整剂量。一般原则（[[pharmacology/patient-variation]]）是使用安全记录长期良好的药物，采用最低有效剂量，并且不要突然停用必需的药物：未控制的癫痫、哮喘或抑郁症本身就是对母亲和婴儿的风险。

::: example 确定孕龄 {#ex-dating}
一位妇女的末次月经于2026年3月9日开始。她的周期规律，每28天一次。分别用280天规则和内格莱规则计算她的预产期。在2026年6月2日的超声检查中，头臀长对应于11+1周。按日期和按超声，她在6月2日的孕龄各是多少？应采用哪一个？
::: solution
**280天规则。** 从2026年3月9日起计280天，为2026年12月14日。

**内格莱规则。** 3月9日加一年、减三个月、再加七天，得2026年12月16日。相差两天是因为3月至12月之间各月并非都是30天；280天计数才是定义。

**6月2日的孕龄。** 从3月9日到6月2日共85天，即按日期为12周零1天（12+1）。超声显示为11+1，少七天。

**采用哪一个。** 英国的做法是在10+0至13+6周之间做超声时，以头臀长确定孕龄，因此她的孕龄为11+1，预产期推后七天，即2026年12月21日。七天的差异完全符合排卵比第14天晚几天的情况。新的预产期随后固定，不再因后续超声而更改。
:::
:::

::: quiz
一位孕34周的妇女因气促抽取动脉血气。她的$P_{\text{CO}_2}$为5.4 kPa，pH为7.38。哪种解读最恰当？
- [ ] 正常，因为这些数值在成人参考范围内。
- [x] 令人担忧，因为孕妇的$P_{\text{CO}_2}$正常约为4 kPa，所以这提示二氧化碳潴留。
- [ ] 令人放心，因为妊娠通常引起轻度呼吸性酸中毒。
- [ ] 没有乳酸值就无法解读。
::: solution
孕酮驱动的过度通气使妊娠期$P_{\text{CO}_2}$降至约4 kPa，肾脏代偿使pH维持在7.40或略高。$P_{\text{CO}_2}$为5.4 kPa而pH处于正常低限，对妊娠而言偏高，提示她的通气没有达到预期，例如在重症哮喘中开始疲劳。这是[[#thm-new-normal]]的一个例子。
:::
:::

::: history
有组织的产前检查是二十世纪的产物。在爱丁堡，约翰·威廉·巴兰坦（John William Ballantyne）从1900年代起就主张建立一所"产前医院"，以便在出生前研究和治疗胎儿，1901年爱丁堡皇家产科医院设立了最早的产前病床。产前门诊在1910年代和1920年代遍及英国，主要是为了发现子痫之前出现的血压升高和蛋白尿。超声于1958年出现，当时格拉斯哥的伊恩·唐纳德（Ian Donald）、约翰·麦克维卡（John MacVicar）和汤姆·布朗（Tom Brown）发表了盆腔肿块和早期妊娠的图像，此后数十年间定孕龄超声和畸形筛查超声成为常规。1960年代，利物浦的西里尔·克拉克（Cyril Clarke）和罗纳德·芬恩（Ronald Finn），以及纽约的文森特·弗雷达（Vincent Freda）、约翰·戈尔曼（John Gorman）和威廉·波拉克（William Pollack）发展出抗D预防，使Rh血型疾病从围产期死亡的常见原因变为罕见原因。唐氏综合征筛查从单纯依据母亲年龄，发展到1980年代末的中孕期血液检查，再到早孕期联合筛查，最近又发展到游离DNA检测；后者于2021年进入英格兰的NHS筛查项目。
:::

::: summary
- 孕龄从末次月经算起；预产期为其后280天。在英国，10+0至13+6周的头臀长超声确定孕龄，之后的超声不再更改。
- 孕次计算包括本次在内的所有妊娠。产次计算24周之后的分娩（活产或死产）以及24周之前的活产；24周之前的丢失写在加号之后。同时务必用文字写出病史。
- 妊娠改变正常范围：血红蛋白、肌酐和$P_{\text{CO}_2}$降低，凝血因子和碱性磷酸酶升高。应对照妊娠期范围解读结果。
- 20周之后，主动脉-腔静脉压迫引起仰卧位低血压，因此孕妇应取左侧倾斜体位。
- NICE NG201规定了英国的产检安排：10周前建档、常规血液检查、定孕龄超声、三体筛查、18+0至20+6周的畸形筛查超声、每次就诊测血压和查尿，以及24周起测宫高。
- 筛查试验将妇女分为较高概率和较低概率；由于这些疾病罕见，大多数较高概率结果来自未受累的妊娠。
- RhD阴性妇女在产前、致敏事件后以及分娩RhD阳性婴儿后接受抗D预防；抗D对已致敏的妇女无效。
- 有一项高危因素或两项中危因素的妇女，建议从12周起服用阿司匹林以预防子痫前期。
- 药物对胎儿的影响取决于时间：器官发生期（受孕后3至8周）是发生畸形风险最高的时期。
:::

::: exercise 计算天数 {level=1 check="85"}
一位妇女的末次月经于2026年3月9日开始。按日期计算，她在2026年6月2日怀孕多少天？
::: hint
先数三月剩余的天数，再加上四月和五月，然后加上六月的天数。
:::
::: solution
三月有31天，所以从3月9日到3月31日为22天。四月加30天，五月加31天，到5月31日共83天。再加两天到6月2日：$22 + 30 + 31 + 2 = 85$天，即12周零1天（12+1）。

::: exercise 孕次与产次 {level=1}
一位妇女处于第五次妊娠，曾有一次足月阴道分娩、一次34周剖宫产双胎且两个婴儿均存活、一次异位妊娠和一次8周的人工流产。写出概括，并解释为什么还要完整写出病史。
::: solution
她为孕5次（四次既往妊娠加本次）。有两次妊娠以24周之后的分娩告终。若每次分娩只计一次，她的产次为2+2；若单位按每个婴儿计数，产次数字为3+2。正是这种不确定性使得病史必须用文字写出：34周剖宫产双胎很重要（子宫瘢痕、早产），既往异位妊娠也很重要（本次妊娠建议早期超声确认妊娠部位）。

::: exercise 妊娠期贫血的阈值 {level=1}
给出英国各孕期以及产后定义贫血的血红蛋白阈值，并解释为什么它们低于非孕妇女的阈值。
::: solution
早孕期血红蛋白低于110 g/L、中晚孕期低于105 g/L、产后低于100 g/L即为贫血。血浆容量增加约40%–50%，而红细胞量只增加约20%–30%，所以即使红细胞量正常，血红蛋白浓度也会因稀释而下降。最低值出现在中、晚孕期，此时血浆容量扩张最大。
:::
:::

::: exercise 再算一个阳性预测值 {level=2 check="round(100*0.8*0.85/(0.8*0.85+99.2*0.025))"}
[[#ex-ppv]]中的示例筛查试验（检出率85%，未受累妊娠的筛查阳性率2.5%）用于年龄较大的妇女，其患病率约为1/125（0.8%）。筛查阳性结果中有百分之多少来自受累妊娠？答案取最接近的整数百分比。
::: hint
同样以10,000名妇女计算，或以100名妇女和小数计算。
:::
::: solution
10,000名妇女中有80例受累妊娠，$80 \times 0.85 = 68$例筛查阳性。9,920例未受累妊娠中，$9\,920 \times 0.025 = 248$例筛查阳性。阳性预测值为$68 / (68 + 248) = 68/316 \approx 0.215$，即**22%**。患病率加倍使阳性预测值几乎加倍，而试验本身并未改变。
:::

::: exercise 谁需要阿司匹林？ {level=2}
对下列每位妇女，判断是否符合NICE关于使用阿司匹林降低子痫前期风险的标准：(a) 一位28岁妇女第二次妊娠，第一次妊娠并发妊娠期高血压；(b) 一位35岁妇女首次妊娠，BMI为31；(c) 一位30岁妇女首次妊娠，怀有双胎；(d) 一位26岁1型糖尿病妇女。
::: solution
(a) **是。** 既往妊娠有高血压疾病是高危因素。(b) **否。** 未产是一项中危因素；她不到40岁，BMI低于35，因此只有一项。(c) **是。** 首次妊娠和多胎妊娠是两项中危因素。(d) **是。** 1型糖尿病是高危因素。每种情况下的决定都应遵循当地指南并与妇女本人讨论。
:::

::: exercise 出血后的RhD阴性妇女 {level=2}
一位无抗D抗体的RhD阴性妇女孕22周，腹部着地摔倒后就诊。她有少量阴道出血。本次妊娠早些时候的胎儿基因分型预测胎儿为RhD阳性。她需要什么？为什么？
::: solution
12周之后的腹部外伤是潜在致敏事件，而胎儿为RhD阳性，因此她需要抗D免疫球蛋白，最好在72小时内给予。20周之后要进行胎母输血检测（Kleihauer试验），以决定标准剂量是否足够。她还需要对外伤本身进行评估：伴有出血的摔倒可导致胎盘早剥，因此必须评估胎心和子宫，并告知她如出现腹痛或再次出血应返回就诊。28周的常规产前预防仍要进行；这次事件并不能取代它。
:::
:::

::: exercise 妊娠期的血气 {level=3}
一位29岁哮喘妇女孕32周，因气促就诊。吸空气时动脉血气：pH 7.44，$P_{\text{O}_2}$ 9.8 kPa，$P_{\text{CO}_2}$ 4.1 kPa，碳酸氢盐20 mmol/L。治疗一小时后，她显得疲惫；血气为pH 7.37，$P_{\text{CO}_2}$ 5.3 kPa。解读这两次血气。
::: solution
**第一次血气。** pH、$P_{\text{CO}_2}$和碳酸氢盐符合妊娠期正常的代偿性呼吸性碱中毒。$P_{\text{O}_2}$为9.8 kPa偏低，说明哮喘正在损害氧合。妊娠期低氧血症还会减少对胎儿的氧输送，因此她需要吸氧并治疗哮喘。

**第二次血气。** $P_{\text{CO}_2}$为5.3 kPa在妊娠以外属于正常，但远高于预期的4 kPa，且pH已下降。结合她的疲惫，这是危及生命的哮喘发作伴呼吸肌疲劳的征象。她需要紧急的上级医生评估，包括重症监护和麻醉科的参与。保护胎儿的最好办法是充分治疗母亲；不应因为妊娠而停用包括糖皮质激素在内的哮喘药物。

::: exercise 设计一段咨询说明 {level=3}
一位38岁妇女的联合筛查报告唐氏综合征的概率为1/40。她问："那我的孩子是唐氏综合征吗？"解释这一结果的含义，并概述她的选择，包括每种选择的优点和局限。
::: solution
**含义。** 1/40的概率意味着，在40位得到这一结果的妇女中，约有一位的婴儿患唐氏综合征，另外39位没有。这一结果将她归入较高概率组（1/150或更高），但并不是诊断。

**选择。**
1. **不做进一步检查。** 这是一个合理的选择；有些妇女宁愿不知道，或者无论结果如何都不会改变计划。
2. **NIPT。** 一项没有流产风险的血液检查。它能检出大多数受累妊娠，假阳性很少，但NIPT的"较高概率"结果仍需诊断性检查确认，偶尔也会得不到结果。
3. **诊断性检查。** 现在做绒毛取样或15周起做羊膜腔穿刺可以给出确定的答案，但带有少量额外的流产风险（约0.5%）。绒毛取样偶尔会显示胎儿并不存在的胎盘嵌合。

**方式。** 使用简明的数字和两种表述方式（"1/40"，"40人中有39人不是"），提供书面资料，给予时间，并支持她作出的任何决定而不加引导。如果诊断得到证实，应为她提供专科服务和家长组织关于这种疾病意味着什么的信息，以及她的选择。
