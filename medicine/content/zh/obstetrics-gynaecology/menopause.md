绝经不是一次事件而是一段过渡，而这段过渡里的处方决定常常被两类恐惧扭曲：**一类是“激素等于乳腺癌”，它让有症状的女性不必要地痛苦多年；另一类是“激素能防老”，它让年过六十的人才开始治疗并期待心血管的获益。两者的纠正都依赖同一件事：按她的年龄与症状与风险与（在是否已切除子宫上）来谈绝对数字。**本章覆盖过渡期与早发的卵巢功能不全的诊断、激素治疗的证据与处方、以及常被忽略的“长尾”（泌尿生殖的综合征与骨与心与情绪）。

## 诊断与过早的结局

::: definition 绝经过渡与卵巢功能早衰 {#def-diagnosis}
**绝经是回顾性的诊断：末次月经后连续十二个月无月经在（在自然过渡的女性中不需要化验）。过渡期在（绝经的晚段）的诊断是临床的：四十五岁以上的女性出现在月经周期的缩短或在跳过的月份与在潮热与在夜汗与在（（睡眠的破碎））即可诊断并开始治疗，不必测激素，因为在（周期中的波动使单次数值无法解释）。要记住的例外是在（激素的避孕正在使用时）——她不会有月经，因此症状与年龄是唯一线索，而不要以“她在避孕所以不可能绝经”结束思考。卵巢功能早不全在（四十岁以前）需要实验室的确证：两次间隔至少四周的在促卵泡激素升高与在（（雌二醇低下）），并加做在妊娠试验与在催乳素与在甲状腺与在（（雌二醇））；它的病因只有一部分是明确的在染色体与在基因的与在自身免疫与在医源的在放化疗与在（（手术）），多数找不到原因，这一句要提前告诉她，因为“为什么”是家属第一个问题。早发的诊断带来四件事：其一，症状常更重在（骤然的雌激素撤除比自然过渡更难耐）；其二，骨与心与在神经的在（长期风险）需要提前处理；其三，生育的问题必须当天谈，而不是留到下次在（约五成的患者此前从未听说过这一可能）；其四，激素的补充应持续到在（自然的绝经年龄，约五十岁上下），这不是“滥用”而是替代她本该有的暴露。要在诊断时排除的模仿包括在妊娠与在甲状腺与在高催乳素与在多囊的续发表现与在体重的骤减与在（运动的负荷）；以及在（宫腔的粘连）在近期的刮宫或在（感染）之后。对手术绝经的女性，要在术前谈话时就说明在术后的症状可能与在乳糜的在（补充的必要性）并把在（是否保留卵巢）的决定写成可以记住的两三句话（[[obstetrics-gynaecology/contraception-fertility]]、[[endocrine/reproductive-endocrinology]]、[[genetics/genome-chromosomes]]、[[clinical-skills/laboratory-tests]]）。**
:::

## 激素治疗的证据与处方

::: definition 绝经的激素治疗 {#def-hrt}
**激素治疗是治疗潮热与夜汗与睡眠破碎最有效的干预，其收益在（从绝经过渡期开始的女性）中最大、风险最低。三条原则。第一，有子宫者必须给在（子宫的对抗）：单用雌激素会显著增加子宫内膜的增生与癌，因此子宫完整的女性需要在周期性的或在（（连续的孕激素）），出现不规则出血时要按出血路径评估而不是安慰。第二，经皮的路径在若干情形下更合适：在肥胖与在偏头痛与在高血压与在（静脉血栓的风险）者用在（透皮的雌激素）不增加在（血栓的额外风险），因为避开了首过的代谢。第三，谈风险要谈绝对数而不是相对的百分比：在五十岁的女性中使用在（雌孕联合）每千人每年约增加一例乳腺癌在（约在数年的使用后），这一量级与在每天一杯酒与在肥胖与在（夜班）的可比；而在（单用雌激素）的观察数据接近于中性甚至略低，这两者不可混为一谈；多数指南因此认为在六年以上使用联合方案时的在（（风险的信号更明确））。“时间窗”的假说解释了为何不同研究结论相反：在过渡期开始者可能得到在冠脉的在中性的或在（轻度有益），而在六十岁以后或在（停经十年后）才起始者不产生在（心脏的获益）并可能有害。非激素的选择要放在同一张表上在（若干的）：选择性血清素与去甲肾上腺素在（再摄取抑制剂）与在（加巴喷丁的类似物）与在若干体系中的在（神经激肽受体的拮抗剂）与在（认知行为的治疗）与在催眠的在对睡眠的在（（结构化））；它们对潮热有在（部分的效果）并且在（在乳腺癌幸存者中）常成为选择。处方之后要有随访：在四周与在（三个月）以判断症状与出血与在（剂量是否可降），之后在（每年一次）重新评估继续的理由；“因为一直在吃”不是理由。禁忌要写清：在活动的血栓与在不明的阴道出血与在雌激素依赖的肿瘤与在（（急性的肝病））；而在（乳腺癌的家族史）本身在（不是禁忌），在（乳腺癌的现症）则是在需要肿瘤科共同决策的在（例外）（[[surgery/breast-endocrine-surgery]]、[[cardiovascular/circulation-blood-pressure]]、[[pharmacology/adverse-reactions]]、[[public-health/screening]]）。**
:::

## 长尾

::: definition 泌尿生殖的综合征、骨、心与情绪 {#def-longtail}
**雌激素的长期撤退会改变阴道与尿道与膀胱三角的上皮，这一组表现被统称为泌尿生殖的绝经综合征：干涩、灼痛、性交疼痛、反复的尿路感染、尿急与轻度的漏尿。它需要医生主动命名，因为多数女性不会自己提出来——她被问过“还有性生活吗”就以为已经答完了。局部阴道的雌激素是最有效的治疗，全身吸收极低，因此即使在乳腺癌的幸存者中也可以在肿瘤科同意之后使用；保湿剂与润滑剂能缓解症状但不改变组织；选择性的雌激素受体调节剂的口服方案是另一条路。骨的部分要按绝对风险谈：绝经后数年的骨吸收加速造成骨量的丢失，髋部与椎体骨折的比率在晚绝经与早绝经之间差别很大。激素治疗能减少骨折，但六十岁以后单纯为骨而使用它通常不是首选，此时双膦酸盐等抗吸收药物更有证据。骨密度的评估要按本地路径进行，风险评分工具在四十岁以下与早绝经未治疗的人群中会低估风险，这又是一个卵巢功能早不全者需要更早评估的理由。心的部分要说清两件事：绝经后血压与血脂的曲线上移，女性的心血管事件在六十岁以后快速增加；因此绝经的门诊是一次心血管风险筛查的机会，应把血压与体重与腰围与血脂与血糖与吸烟状态写进记录并按指南处理，而不只是谈潮热。这一点对女性尤其重要，因为她们长期被排除在试验之外，而服务也长期把她们的症状当作非致命的问题。情绪的部分最常见的一句是“这不是我的想象”：过渡期抑郁的风险确实升高，尤其在既往有产后抑郁史的人；激素治疗对情绪的作用有限，重性抑郁时抗抑郁药与心理治疗是一线。要注意睡眠与情绪的因果常被打乱：睡眠的碎片会被误诊为焦虑或抑郁，而夜间不出汗、白天不困的人往往在睡眠改善后情绪自行好转。所以次序是：先治睡眠，再评情绪。也要说明潮热的频次与严重度在年轻女性中与血压的控制相关，这是把症状的记录当作风险信号的理由之一（[[endocrine/bone-calcium]]、[[cardiovascular/hypertension]]、[[psychiatry/mood-disorders]]、[[geriatrics-palliative/ageing-frailty]]）。**
:::

::: example 停了药而受苦的五十一岁 {#ex-hrtfear}
一名51岁女性绝经两年，潮热每天十几次、夜间无法连续睡三小时；两年前因看到一篇“激素增加乳腺癌”的报道自行停药，此后症状未缓解；她的母亲七十岁后患乳腺癌。
::: solution
**她需要的是把相对风险换成绝对风险的一次谈话（[[#def-hrt]]、[[clinical-skills/communication]]）。要说的事实：在五十岁使用雌孕联合的激素治疗，每千人每年约增加一例乳腺癌，这一数字在用药数年后出现，停药后回落；而她的母亲在七十岁后发病属于散发性的年龄相关，不等于她携带高危的变异；单用雌激素的观察结果接近中性，两者不能混在一起引用。要把她的症状量化成可以比较的东西：每天十几次潮热与三年的睡眠剥夺本身就是致病的，它会带来工作的损失与情绪的继发的损害，而“忍”不是无风险的选择。方案：因为她有子宫，给经皮或口服的雌激素加孕激素对抗，优先经皮（她的血压偏高且偏头痛史未除外）；从低剂量起，四周复诊评估效果与出血，三个月后判断是否需要调整；同时把局部阴道雌激素作为独立的一条说清，因为它不会因全身用药而必然解决泌尿生殖的症状。要主动处理她的恐惧而不是嘲笑它：说明那篇报道的来源与它的局限，并约定“我们每一年重新评估一次继续的理由，如果那时候你不想继续，我们就减停并换非激素的方案”。她的睡眠要单独处理（固定的作息与卧室的温度与夜间给药的时点），因为潮热改善后仍可能残留失眠。最后写下随访的日子（两周与三个月与每年），并给她一份书面的、可携带的说明——因为下一次遇到“激素有害”的说法时，她需要一句有出处反驳（[[surgery/breast-endocrine-surgery]]、[[pharmacology/adverse-reactions]]、[[public-health/screening]]）。**
:::

::: example 停经四个月的二十九岁 {#ex-poi}
一名29岁的女性停经四个月，曾有两次自然流产，近两个月潮热与阴道干涩；她的催乳素与甲状腺正常；她已有一次促卵泡激素为28，雌二醇低。
::: solution
**四十岁以前的闭经伴激素的升高与症状，是卵巢功能早不全，需要当天开始处理而不是“过半年再来”（[[#def-diagnosis]]、[[endocrine/reproductive-endocrinology]]）。诊断的确证：间隔至少四周再测一次促卵泡激素与雌二醇，并做妊娠试验与催乳素与甲的功能，加做核型与若干基因的panel与（在若干临床线索下的）自身免疫的筛查；她本人的两次流产要另行评估，但不应因此推迟对卵巢功能的处理。要当天谈三件事。第一是生育：自然妊娠的机会低但存在，卵子捐赠的辅助生殖是多数人可以实现的途径，应转介生殖门诊，并明确“我们现在不知道你是否会自行恢复，所以不会给你绝育性质的建议”。第二是治疗：激素的补充应持续到自然绝经的平均年龄，因为它对她不是“更年期用药”而是替代本该有的暴露，对骨与心与泌尿生殖的功能都有意义；有子宫者加孕激素对抗；不需要避孕这一说法要纠正——若她不想妊娠，仍需避孕措施，因为偶发的排卵可以发生。第三是骨与生活方式：钙与维生素的摄入、抗阻的运动、避免吸烟与过量饮酒；若在四十岁前诊断且有其他风险因素，可较早做骨密度的评估。她的情绪需要单独照顾：这一诊断的冲击常来自“我不能生育”这一层，而不是潮热，因此很多医生处理了症状而漏掉了真正的问题；给她第二次会谈（不带化验单）与同伴支持的信息。最后，把诊断写进她的病历首页（在若干体系中的患者携带卡），因为下一个见到她的医生很可能又从头查一遍（[[genetics/genome-chromosomes]]、[[obstetrics-gynaecology/contraception-fertility]]、[[endocrine/bone-calcium]]、[[psychiatry/lifespan-psychiatry]]）。**
:::

::: example 反复“念珠菌感染”的58岁 {#ex-gsm}
一名58岁女性一年内被诊断外阴阴道念珠菌感染五次并反复用抗真菌药；她其实说不清是痒还是灼痛与性交痛，且绝经八年；检查见阴道黏膜苍白、皱褶消失、有点状出血。
::: solution
**这不是反复的真菌感染而是泌尿生殖的绝经综合征被误诊了五次（[[#def-longtail]]、[[clinical-skills/physical-examination]]）。她的检查所见有特征性：黏膜苍白、湿润度下降、皱褶消失、点状的出血与阴道的pH升高，而真菌的培养多半阴性。要做的事：停止经验性的抗真菌治疗并在下次发作时做pH与镜检与培养，把诊断落在证据上；给局部阴道的雌激素（在开始数日内的灼痛是常见的，可通过隔日给药与减少单次剂量度过），并说明它需要两到四周才见效、之后需要维持使用，否则组织会回到原状；性交痛的同时给润滑剂与保湿剂并解释两者的分工。也要处理她被误诊这件事：为五次不正确的治疗道歉并解释机制，因为她很可能已经不相信任何建议；同时筛查她没说出口的问题——尿路感染、排尿后的滴漏、以及因疼痛而停止的性生活对关系的影响。若她有乳腺癌的现症或在用芳香化酶抑制剂，局部雌激素需要与肿瘤科共同决策，而保湿剂与非激素的方案可以先上。最后安排八到十二周的复评（不是“有再来”），并让护理门诊接手长期的重复处方，因为这一治疗的依从性常在半年内脱落（[[obstetrics-gynaecology/menstrual-pelvic-disorders]]、[[infectious-diseases/sexually-transmitted-infections]]、[[clinical-skills/communication]]）。**

::: example 以为是脑瘤的四十七岁 {#ex-brainfog}
一名47岁的女性两个月来“脑子像蒙了一层”、忘记熟悉的词、夜里心跳醒来；她自付费用做了头颅核磁（正常），并被建议看神经科；她的月经已变成两到三个月一次。
::: solution
**这是围绝经期的认知与睡眠症状，而她的周期改变与夜间的唤醒是关键线索（[[#def-diagnosis]]、[[#def-hrt]]、[[nervous-system/movement-disorders]]）。要做的事：先给出一个解释——睡眠的碎片化会造成注意与语言的困难，被体验为“变笨”，而这一现象在过渡期常见且可逆；她已经做过的正常核磁在这里是有用的，可以明确地告诉她这排除了她担心的东西，因此不需要神经科的进一步检查（除非出现局灶的体征或进行性的认知下降）。第二，把睡眠当作治疗目标：评估潮热与夜汗、把夜间给药安排在睡前、检查是否有打鼾与呼吸暂停与共病的不宁腿；若月经已不规则且年龄大于四十五，可以直接按过渡期开始激素治疗而不必等十二个月的闭经。第三，用一次简短的认知筛查排除少数情形（如抑郁相关的假性认知下降），并记录她自己的主诉为可比较的项目，例如“忘记熟悉的词每周几次”。第四，处理她的健康焦虑与经济上的自付检查：她需要被告诉哪些检查值得做，也要被告诉“我们已经排除了最坏的可能”，并约定六周后的复评（若认知无改善则再走神经的路径）。要提醒团队：中年女性的这一组主诉在门诊里极易被归入“压力”而被敷衍，或者被推向昂贵的检查，两条路都无益；真正有效的是一次认真的解释加上对睡眠的治疗，通常在六周内可以看到改变（[[psychiatry/mood-disorders]]、[[clinical-skills/clinical-reasoning]]、[[public-health/health-systems-economics]]）。**

::: exercise 给乳腺癌幸存者建议 {level=1}
一名54岁的女性在三阴乳腺癌术后两年，现症是每天八次潮热与严重睡眠剥夺，内分泌治疗未在用上；她说“我绝不敢用激素”。请写出谈话的要点。
::: solution
**先承认她的顾虑有依据，再给事实的边界（[[#def-hrt]]、[[clinical-skills/communication]]）。三阴乳腺癌术后、未在用内分泌治疗，是雌激素相关问题最少的一类情形；观察性的研究在乳腺癌幸存者中使用激素治疗并未显示复发的增加，而随机试验的规模小、结论未定，所以这是共同决策而不是有标准答案的问题。要把选择摆全：非激素的药物（选择性血清素与去甲肾上腺素再摄取抑制剂要避开与部分化疗药相互作用的品种，加巴喷丁类在夜间给药可兼顾睡眠）、睡眠与认知行为的治疗、以及阴道局部的雌激素用于泌尿生殖的症状。若她仍希望尝试激素治疗，需要的是与肿瘤科一起、在明确记录风险后、以最低有效剂量与经皮路径开始，并把复评的时间定在四周与之后每三月。要明确说出的一个反对：不要因为害怕而让她独自使用来源不明的制剂，这一现象在幸存者中相当常见。她的骨与心血管的管理要同时安排（骨密度的评估在芳香化酶抑制剂未用的情况下按风险决定），并且给她书面的一页说明，供她的初级照护与她的家人读（[[surgery/breast-endocrine-surgery]]、[[psychiatry/mood-disorders]]、[[pharmacology/adverse-reactions]]、[[endocrine/bone-calcium]]）。**

::: exercise 解读两次促卵泡激素 {level=2}
一名43岁女性闭经五个月，第一次促卵泡激素32、雌二醇40，第二次（间隔三周）促卵泡激素11、雌二醇180；她问“我到底是不是绝经了”。
::: solution
**她的两次结果都真实，而这正是过渡期的特征：卵泡的池子在耗竭的过程中间歇地仍有反应，激素因此大幅波动，单次的数值不能诊断（[[#def-diagnosis]]、[[clinical-skills/laboratory-tests]]）。要解释的是：第二次的高雌二醇说明她的卵巢仍在工作，而这也意味着她仍可能排卵并妊娠——在闭经未满十二个月时不能宣布绝经，需要避孕直到满足十二个月的条件（或在四十岁前用其他方法确认）。她四十三岁，属于过渡期的正常年龄范围，因此诊断靠症状与周期而不是化验。要处理的三件事：症状的治疗可以按过渡期开始；若她有子宫且出现不规则出血，需要在治疗前后按出血路径评估以排除内膜的病变；以及她需要被告知——卵巢功能在此年龄的衰退是正常的，但如果在四十岁以前完全停止，则构成卵巢功能早不全并有骨与心的长期含义，因此要教她识别信号。最后约定一次三个月的复评（用症状的表而不是激素的水平），并写下“不要再用单次的化验定义她”（[[obstetrics-gynaecology/contraception-fertility]]、[[endocrine/reproductive-endocrinology]]、[[clinical-skills/communication]]）。**
:::
:::

::: exercise 做一次心与绝经的检查 {level=2}
一名56岁女性绝经五年，主诉睡眠差与乏力；她的血压138/86、腰围94厘米、血脂与血糖未查、不吸烟、母亲六十岁心梗。请在一次门诊中完成心血管风险的评估与计划。
::: solution
**绝经的门诊是女性心血管风险筛查最被浪费的机会，所以不能只谈症状（[[#def-longtail]]、[[cardiovascular/hypertension]]、[[public-health/prevention-promotion]]）。这次门诊要完成：重复的血压测量并按高血压的路径确认（单次138/86不能定诊）；血脂与糖化血红蛋白与肾功与尿白蛋白；用风险计算器估算十年的风险，同时指出该工具在女性中的不足，以及她的早发绝经与家族史（母亲六十岁心梗属早发的界限附近）是加权项而非唯一决定；生活方式的具体处方（每周累计的活动、抗阻训练、饮食的结构、酒精、以及睡眠——这里要把她的睡眠差当作独立的风险因素与治疗的靶点）。她的主诉乏力与睡不好需要单独处理（甲状腺与血相与情绪与睡眠的呼吸暂停）；若考虑激素治疗以缓解症状，它对心血管不构成禁忌，在过渡期开始者也不增加事件。计划要写成一个有日期的清单：三周内复测血压、空腹抽血、三个月后复评生活方式的执行；并把她的风险数字告诉她本人而不是只写进病历，因为女性的风险常被低估而她本人往往不知道（[[psychiatry/mood-disorders]]、[[endocrine/diabetes]]、[[clinical-skills/communication]]、[[public-health/screening]]）。**
:::

::: exercise 撰写一份职场的规定 {level=3}
某机构的员工中五十岁左右的女性占相当比例，缺勤与离职集中在这一群体。请为它写一份关于绝经的规定，并说明如何衡量它是否有效。
::: solution
**一份有效的规定要包含六条可执行的内容，而不是同情的语言（[[#def-hrt]]、[[public-health/prevention-promotion]]、[[public-health/determinants-inequalities]]）。第一，环境与设备的承诺：可调节的温度与通风、可用的冷水与（在若干情形中的）降温的设备、可开的窗与不强制佩戴不透气的制服或领带。第二，时间的弹性：可以因夜间睡不好而弹性到岗、可以因就诊与治疗的安排请假而无需说明细节。第三，谈话的通道：指定受过培训的联系人与保密的通道，并允许与同性别的人谈；把绝经纳入健康管理的常规而不是人事的个案。第四，信息与转介：内部提供一份有出处的说明与（在若干体系中的）职业健康的评估，鼓励就诊并明确这不是“个人问题”。第五，对管理者的培训：多数人不是不想谈而是不知道能问什么，需要一组可以直接使用的句子。第六，与职业暴露与轮班的政策联动（夜间轮班的岗位对睡眠的影响是可调节的）。衡量要用能观察的东西：这一群体的缺勤天数与离职率与内部调查中的“我可以在工作中谈这件事”的比例、弹性安排的申请与批准比、以及（在若干体系中的）职业健康的转介量；同时要按岗位级别分层，因为高层可以自行开窗而流水线不能。要提醒的一条：把绝经写成女性特有的问题会带来反向的污名，规定应写成对中年员工健康的通用条款并在其中明确绝经一项，这样它既能被落实又不制造差异（[[public-health/determinants-inequalities]]、[[public-health/environmental-occupational]]、[[clinical-skills/communication]]）。**
:::

## 通向何处

月经与盆腔疾病见[[obstetrics-gynaecology/menstrual-pelvic-disorders]]；避孕与生育见[[obstetrics-gynaecology/contraception-fertility]]；产后与哺乳见[[obstetrics-gynaecology/postnatal-period]]；生殖内分泌见[[endocrine/reproductive-endocrinology]]；骨与钙见[[endocrine/bone-calcium]]；心血管风险见[[cardiovascular/hypertension]]；情绪与睡眠见[[psychiatry/mood-disorders]]；筛查与乳腺癌见[[public-health/screening]]。

::: history
**绝经在二十世纪中叶以前几乎不是一个医学问题。多数女性在最后一次月经后只活十年左右，医生的注意力在生育与结核与产褥热；一篇1940年代广被引用的社论甚至声称绝经后的女性可以正常工作、家务与性生活在十年内都会保持，因此不需要治疗。转折发生在人口与理论两端。1944年，一位布里斯班的医生提出卵巢的衰竭是一个独立的内分泌疾病，会造成潮热与情绪与代谢的改变，并把雌激素称为“抗衰老的”物质；他的名字从此与这一领域绑在一起，也为此后六十年的过度承诺定了调——包括他本人晚年在公开场合宣称雌激素能让健康的女性保持年轻与防止衰老。1963年，美国食品药品管理局批准结合雌激素用于更年期症状，此后十年处方的增长是现代医学史上最快的之一。第二次转折在1966年，罗伯特·威尔逊的《著名的绝经期》把雌激素描述为对“女性气质的阉割”的替代，并以通俗的语言说服了整整一代美国女性长期服用，这本书销量以百万计，而它同时把一种本来没有症状的生理过程定义为需要终身用药的疾病。此后是证据的年代：1970年代的两项研究独立地证明单用雌激素显著增加子宫内膜癌，促使孕激素的对抗成为标准，处方的模式从连续改为周期；1980年代骨密度的测量技术使骨质疏松成为可以被诊断与预防的疾病，雌激素的抗骨吸收作用被随机试验证实，它一度被推荐为骨质疏松的一线预防；1980年代末起，观察性研究显示服用激素的女性冠心病事件更少，医学界因此期待一项试验去证明它。2002年，妇女健康倡议的试验中途停止，因为联合方案在五年内增加了乳腺癌与血栓与卒中，尽管也减少了结肠癌与骨折；这一结果以极其简化的方式进入公众意识，处方在数周内下降近三分之一，许多女性在没有替代方案的情况下停掉了药，此后多年关于这一“停药的流行”与随之而来的骨折与痛苦的争议一直持续。试验的重新分析带来了更细的图景：在五十到五十九岁或绝经十年内的女性中，联合方案的绝对风险很小而症状的获益很大；在六十岁以上起始者未见心脏的获益；而单用雌激素的队列在长期随访中甚至显示乳腺癌的下降。这些差异后来被总结为时间窗的假说，也就是本章的第三条原则。各国指南在2010年代相继修正，把激素治疗重新定位为中重度血管舒缩症状的一线，并强调按年龄分层与按绝对风险沟通；剂量与剂型也随之分化，经皮的路径因为不增加血栓的风险而获得明确的地位。泌尿生殖的症状则走了另一条更安静的路：它在很长的时间里被当作“老年性阴道炎”而无人治疗，直到2012年前后一个新名称被提出以取代带有贬义的表达，研究也显示多数有症状的女性从未向医生提起，而医生也很少主动问。卵功能早不全的历史则是关于失访的历史：从1994年世界卫生组织给出的定义与四十岁的界值，到各国在2010年代制定的诊断与长期随访的指南，反复出现的结论是诊断平均延迟数年、生育的信息不及时、以及骨与心的长期风险在停药后被完全忽略。这一段历史对本章是一个双重的提醒：激素治疗既被过度承诺过也被过度恐惧过，而两次错误的代价都由具体的人承担；因此医生要做的不是选边，而是把她的年龄与她的症状与她的风险放到同一张纸上，把数字给她看，并且每年重新问一次。**
:::
::: summary
- 四十五岁以上有典型症状即可诊断过渡期，不要用单次的激素化验做决定。
- 有子宫者必须加孕激素对抗；经皮的路径不增加血栓的额外风险。
- 风险要用绝对数谈：五十岁使用联合方案约每千人每年一例额外的乳腺癌，单用雌激素接近中性。
- 卵巢功能早不全需要两次间隔四周的化验确证，并把生育与骨与心的议题在当天就开始谈。
- 泌尿生殖的绝经综合征需要医生主动命名，局部雌激素有效且吸收极低，常被误诊为反复的真菌感染。
- 绝经的门诊是一次心血管风险的筛查机会：血压与血脂与血糖与腰围要写成有日期的清单。
:::

## 练习

::: exercise 开出方案 {level=1}
为下列三人各给一个合理的激素方案并说明随访：50岁有子宫、潮热明显；54岁已切除子宫、症状轻；46岁子宫完整、周期两月一次且经量多。
::: solution
**第一位（有子宫、症状重）：雌激素（优先经皮以避开血栓的额外风险）加孕激素对抗，可选周期的方案（每月十二到十四天）以观察出血的模式，或选择若干体系中的微粒化的雌二醇与孕酮的组合；四周与三个月复评，之后每年重新评估继续的理由，并做乳腺筛查的常规安排。第二位（已切除子宫、症状轻）：可先不用全身激素而用非激素的办法与生活方式的调整；若她仍希望用药，单用雌激素即可且不需要孕激素对抗，这使她的风险曲线更接近中性；把局部阴道雌激素作为独立的一条说明；随访以症状的量表为主。第三位（经量多、周期两月一次）：这是过渡期常见的无排卵周期，她的出血本身需要按异常子宫出血评估，排除内膜的病变与妊娠与凝血的问题；治疗上宫内释放左炔诺孕酮的系统既避孕又控制出血，配合外源的雌激素以缓解潮热（需要按本地说明补充孕激素以避免内膜的暴露），或在若干情形中使用短期的激素调节；出血量多者同时查血相与铁并处理缺铁。共同的一点：这三种方案都必须在一年内被重新评估一次，因为“一直在吃”不是继续的理由（[[#def-hrt]]、[[obstetrics-gynaecology/menstrual-pelvic-disorders]]、[[pharmacology/dosing-principles]]）。**
:::

::: exercise 处理用药期间的出血 {level=2}
一名52岁女性开始连续联合的激素治疗三个月，近日出血量类似月经并持续十天；她的超声示内膜4毫米、宫腔清晰。她问“是不是药有问题”。
::: solution
**先给时间与解释，再给检查，顺序取决于出血的特征（[[#def-hrt]]、[[obstetrics-gynaecology/gynaecological-cancer]]）。连续联合方案在起始的三到六个月内出现不规则出血是常见的，多数会自行停止；她的超声内膜薄且宫腔清晰，这不增加恶性可能，因此不需要立即刮宫。要做的是：查妊娠（在闭经未满十二个月时仍可能）、查宫颈与阴道的原因与感染的筛查、复核她的剂量与给药时间（漏服与不规律的服用时间是常见的原因）、以及确认她是否在同时服用影响雌激素代谢的药物（在若干的酶诱导剂）。若她在连续联合的第六个月后仍出血，或出血量多、伴疼痛，则需要内膜的取样而不是继续观察。若为周期方案且出血过长或影响生活，可以缩短孕激素的天数（在若干体系中的十日方案）或换更低剂量，也可换为另一种孕激素。要说一句她常问的话：出血不等于药物“有毒”，也不等于癌症，但它是一个需要被记录与随访的信号；给她一份出血的日历（在若干周内），因为书面的模式比记忆更能指导调整。最后写明复评的日期与“什么情况下要提前联系”（[[obstetrics-gynaecology/menstrual-pelvic-disorders]]、[[clinical-skills/communication]]、[[clinical-skills/records-handover]]）。**
:::

::: exercise 做骨的评估 {level=2}
一名53岁女性，绝经三年，腕部曾经在轻微跌倒后骨折，骨密度示椎体T值为-2.7；她拒绝双膦酸盐，问“我能不能只吃钙和维生素D”。
::: solution
**她已经处于骨质疏松并发生了脆性骨折，仅补充钙与维生素不能把骨折风险降到她应处的水平（[[#def-longtail]]、[[endocrine/bone-calcium]]）。要做的是把治疗讲成可谈的选项而不是唯一的命令：她的骨折史与T值都构成明确的治疗指征，一线是抗吸收的药物，也可考虑促骨形成的药物在若干重度的情形中；她拒绝的原因要问出来（在若干人是对下颌骨坏死的报道或对每日药片的疲惫），因为不同的原因对应不同的解决——每年一次的静脉给药与每月的皮下注射与每日的口服在便利上差异很大，而她可能只是不了解。也要说明钙与维生素的角色：它们是治疗的基础而非替代，摄食优先、必要时补充至推荐量，过量并不更好。她的其他风险要一并处理：吸烟与酒精与体重的下限与维生素的不足与跌倒的预防（在若干体系中的平衡的评估与力量的训练）以及正在使用的会伤骨的药物（在若干的糖皮质激素与质子泵抑制剂）。若她最终仍拒绝全部药物，要记录她的选择与已告知的内容，并把复评定在骨密度的一年后与每一次新发疼痛时的评估。最后一条：她这个年龄的女性常被告知“年纪大了骨头会脆”，需要明确说这是可以被治疗并可以显著降低骨折的疾病（[[pharmacology/adverse-reactions]]、[[geriatrics-palliative/falls]]、[[clinical-skills/communication]]）。**
:::

::: exercise 设计一个绝经的服务 {level=3}
请为一个地区设计绝经的诊疗服务，覆盖诊断的入口、治疗的可及、特殊人群与评价，并说明如何在资源有限时排优先级。
::: solution
**服务的骨架是四条与一个顺序（[[#def-hrt]]、[[public-health/health-systems-economics]]、[[public-health/prevention-promotion]]）。入口要设在初级照护而不是专科：把“四十五岁以上有典型症状即可诊断、化验通常不需要”与“绝经后出血两周内检查”这两条写成路径与培训，因为绝经服务的一半失败是诊断的延误与不必要的化验。治疗的可及要看三件事：药物是否在目录内且剂型齐全（经皮的品种常缺货）、医生是否能开（把激素治疗的处方权下放到经过半天培训的全科与妇科门诊护士）、以及非激素的方案是否同步可得（因为有一部分人永远不该被诱导去等待专科）。特殊人群要有明确的通道：卵巢功能早不全（当天的生育与骨与心的路径、并把补充治疗持续到平均绝经年龄）、乳腺癌的幸存者（与肿瘤科共同决策、非激素的方案先给足）、以及被反复误诊的泌尿生殖的症状（把局部雌激素写成不需要专科的常规）。顺序上优先做三件低成本的事：一份给患者的书面的绝对风险说明、一个“每年重新评估继续理由”的病历提醒、以及把泌尿生殖的症状写进问诊清单。评价要包含过程的与结果的：从症状出现到处方的间隔、经皮制剂的处方比、非激素方案的可用率、一年后的继续率、按剥夺指数分层的覆盖差、以及一个患者报告的条目（她是否觉得被认真对待）。资源有限时的取舍原则很明确：优先解决“被误诊而受苦的人”（例如反复被当真菌感染的与因恐惧自行停药的）而不是扩大检查的容量，因为后者的边际收益极低（[[public-health/determinants-inequalities]]、[[clinical-skills/patient-safety]]、[[obstetrics-gynaecology/gynaecological-cancer]]）。**
