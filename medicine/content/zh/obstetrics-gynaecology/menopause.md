绝经是人生的正常阶段，而不是疾病，但它的症状可能严重而持久，其激素变化还会影响骨骼、心血管系统、泌尿生殖道和情绪。2002年之后的约二十年间，由于对证据的片面解读而产生的对激素替代治疗（HRT）的恐惧，许多妇女得不到有效的治疗。现行指南的目标是以绝对数字向妇女提供关于获益和风险的准确信息，让她们自己作出选择。

本章解释绝经的生理、诊断、短期和长期影响、早发性卵巢功能不全，以及激素和非激素治疗。英国实践遵循NICE NG23（《绝经：识别与处理》，2015年，2024年更新，此后又有修订）和FSRH关于避孕的指南。激素背景知识见[[endocrine/reproductive-endocrinology]]。

## 生理与定义

女性出生时约有一百万至两百万个原始卵泡，到青春期降至约30万–40万个，并在整个生育期内持续减少，大部分是通过闭锁而不是排卵。当卵泡池接近耗竭时，卵巢功能变得紊乱，然后停止。

::: definition 绝经的各个阶段 {#def-stages}
- **绝经**是由于卵巢卵泡活动丧失而导致的月经永久停止。它是回顾性诊断的，即在**12个月无月经**之后（且无其他原因）。英国的平均绝经年龄为51岁。
- **围绝经期**是从开始出现月经周期不规律和其他症状起，直到末次月经后12个月的时期。通常持续数年。
- **绝经后期**是绝经之后的时期。
- **早绝经**是指在40至45岁之间绝经。
- **早发性卵巢功能不全（POI）**是指40岁之前卵巢功能丧失。约每100名妇女中有1人发生。
:::

::: theorem 反馈机制解释绝经的激素模式 {#thm-feedback}
随着卵泡耗竭，卵巢产生的**抑制素B**减少，最终**雌二醇**也减少。两者通常都通过负反馈抑制FSH的分泌，因此**FSH升高**，先是间歇性升高，然后持续升高。在围绝经期，高水平的FSH可以驱动一些剩余的卵泡产生阵发性的雌二醇分泌，因此雌激素水平在高低之间波动。绝经后，雌二醇水平低，FSH和LH持续升高。
:::

::: proof
发育中卵泡的颗粒细胞分泌抑制素B和雌二醇。抑制素B选择性地抑制垂体释放FSH，而雌二醇同时抑制GnRH和促性腺激素。卵泡减少时，抑制素B首先下降，而雌二醇可能仍然正常，因此FSH在围绝经期早期就开始升高。较高的FSH更快地募集剩余卵泡，可引起过高的雌二醇峰和较短的周期；在另一些周期中没有卵泡发生反应，导致无排卵的长周期。这种波动解释了为什么症状时有时无，为什么单次FSH水平对45岁以上妇女不可靠，以及为什么围绝经期妇女仍能排卵和受孕。当卵泡耗竭时，卵巢停止产生雌二醇；脂肪组织中仍通过肾上腺雄激素的芳香化继续产生少量雌激素，这就是为什么肥胖的绝经后妇女雌激素水平较高，患子宫内膜癌的风险也较高。
:::

## 症状与远期影响

大多数妇女会注意到症状，其严重程度和持续时间差别很大。

- **血管舒缩症状**：约四分之三的妇女有潮热和盗汗。其持续时间的中位数约为七年，在一些妇女中可持续更久。其发生是因为雌激素下降使下丘脑的体温调节区间变窄，部分原因是**神经激肽B**神经元的信号增强，因此核心体温的小幅上升就会触发散热反应。
- **心理症状**：情绪低落、焦虑、易激惹、注意力和记忆力差（"脑雾"），以及睡眠差，部分是由盗汗所致。
- **绝经期泌尿生殖综合征**：阴道干涩、疼痛、性交痛、尿频尿急以及反复尿路感染，由依赖雌激素的阴道和尿道组织变薄引起。与潮热不同，这些症状如不治疗往往会逐渐加重。
- **肌肉骨骼症状**：关节和肌肉疼痛。
- 性欲减退。

**远期影响。** 雌激素抑制破骨细胞的骨吸收。雌激素缺乏使绝经后数年内的骨量丢失加速，增加**骨质疏松**和脆性骨折的风险（[[endocrine/bone-calcium]]）。绝经后心血管风险也会增加，较早绝经与较高的心血管疾病和骨质疏松风险相关；POI如不治疗，还与预期寿命缩短相关。

## 诊断

NICE NG23建议，对于45岁以上、其他方面健康的妇女，**根据临床表现、无需实验室检查**即可诊断围绝经期和绝经：
- **围绝经期**：血管舒缩症状和月经不规律；
- **绝经**：至少12个月无月经（如未使用激素避孕），或无子宫的妇女出现症状。

45岁以上的妇女**不应使用FSH**诊断绝经，因为其水平会波动。对于40至45岁有症状或月经周期改变的妇女，以及疑似POI的40岁以下妇女，可以考虑检测FSH。在使用复方激素避孕或大剂量孕激素的妇女中，FSH也不可靠，因为这些药物会抑制FSH。

::: example 49岁的潮热 {#ex-perimenopause}
一位49岁妇女一年来月经不规律，间隔最长达三个月，每天潮热数次，夜间会热醒。她感到疲倦，工作时易激惹。她要求做血液检查"看看是不是绝经了"。你会给出什么建议？
::: solution
**诊断。** 她已超过45岁，有血管舒缩症状和月经不规律，因此按NICE指南可以临床诊断为**围绝经期**。不需要FSH检测，而且它可能产生误导，因为围绝经期FSH会波动，结果正常也不能排除围绝经期。如果有甲状腺疾病的其他表现，可以检查甲状腺功能。

**讨论。** 应向她提供关于围绝经期、症状可能的病程以及各种选择的信息：HRT是血管舒缩症状最有效的治疗；还有非激素选择和生活方式措施，如规律运动、减少酒精和咖啡因摄入、戒烟。由于她仍有月经，如果她有子宫，**序贯联合**HRT方案（持续使用雌激素，每个周期的一部分时间加用孕激素）或雌激素加LNG-IUS是合适的。应告诉她仍然需要避孕：HRT不能避孕，她可能仍会排卵。
:::
:::

## 早发性卵巢功能不全

POI是40岁之前卵巢功能丧失。40岁以下妇女出现包括无月经或月经稀发在内的绝经症状，并且**FSH升高**，即可诊断。NICE建议间隔四到六周测定两次FSH；ESHRE指南（2024年）在临床表现典型时接受单次FSH升高（高于25 IU/L），不确定时再复查。

大多数病例找不到原因。已知原因包括化疗、盆腔放疗和卵巢手术；自身免疫性疾病（包括自身免疫性甲状腺和肾上腺疾病）；遗传原因，如**特纳综合征**和**脆性X前突变**（*FMR1*）；以及感染。为POI妇女提供核型分析和脆性X检测，并检查肾上腺和甲状腺自身免疫。

POI的重要后果不止于症状：丧失生育力、过早的骨量丢失以及心血管风险增加。应为这些妇女提供**激素替代**，即HRT或复方激素避孕，**至少用到平均绝经年龄**，即约51岁，以补充她们的卵巢原本会产生的激素。在这一人群中，HRT是恢复生理状态而不是增加风险，针对年长妇女引用的乳腺癌风险并不以同样的方式适用。部分妇女的卵巢功能呈间歇性，约5%会自然受孕，因此不想受孕的妇女需要避孕。想要受孕的妇女通常被建议使用供卵进行IVF。这一诊断可能令人痛苦，应提供心理支持。

::: example 一位36岁闭经的妇女 {#ex-poi}
一位36岁妇女六个月没有月经，伴潮热和阴道干涩。妊娠试验阴性。她的FSH为68 IU/L，五周后为72 IU/L；雌二醇低；催乳素和TSH正常。诊断是什么？应为她提供什么？
::: solution
**诊断。** 40岁以下，闭经、绝经症状，以及间隔四到六周的两次FSH升高，可确诊**早发性卵巢功能不全**。

**检查。** 核型分析（排查特纳综合征嵌合体）和*FMR1*前突变检测；肾上腺和甲状腺抗体；以及作为基线的骨密度扫描（DXA）。

**治疗。** **HRT**（如果她愿意且无禁忌证，也可用复方激素避孕）至少用到约51岁，由于她有子宫，需加用孕激素保护子宫内膜。阴道干涩可加用阴道雌激素。采取有利于骨骼和心血管健康的生活方式措施。应告诉她，她的卵巢偶尔仍可能工作，所以妊娠虽然可能性不大但仍有可能；如果她想避免妊娠，就需要避孕；如果她想受孕，应转诊到生殖服务机构。如果发现*FMR1*前突变，她和她的亲属需要遗传咨询。应为她提供心理支持以及患者组织的信息。
:::
:::

## 激素替代治疗

HRT补充雌激素。有子宫的妇女还需要**孕激素**，因为单用雌激素会刺激子宫内膜，增加子宫内膜增生和子宫内膜癌的风险。

::: definition HRT方案 {#def-hrt}
- **单纯雌激素**：用于已切除子宫的妇女。
- **序贯（周期）联合**：每天使用雌激素，每月有10至14天加用孕激素，每月产生一次撤退性出血。用于围绝经期和末次月经后的第一年，此时持续使用孕激素往往引起不规则出血。
- **连续联合**：每天使用雌激素和孕激素，目标是不出血。用于停经满一年后，或序贯HRT使用一年后。
- **LNG-IUS**可以同时提供孕激素和避孕。
- **替勃龙（tibolone）**是一种具有雌激素、孕激素和雄激素作用的合成类固醇，是绝经后妇女的一种替代选择。
:::

**给药途径。** 雌激素可口服，也可**经皮**以贴片、凝胶或喷雾形式给药。口服雌激素经肠道吸收后首先通过肝脏，在那里增加凝血因子的合成。经皮雌激素避免了这种首过效应，在标准剂量下与VTE或卒中风险增加无关。因此，对于VTE基线风险较高的妇女（如肥胖者）和偏头痛妇女，首选经皮雌激素。

小剂量**阴道雌激素**治疗泌尿生殖症状，全身吸收极少。它不需要加用孕激素，可以长期使用，也可以与全身HRT同时使用。对有乳腺癌病史的妇女，是否使用要与她们的肿瘤团队讨论。

### 获益与风险

**获益。** HRT是血管舒缩症状最有效的治疗，NICE将其列为一线治疗。它常能改善情绪、睡眠和关节症状，并治疗泌尿生殖症状。使用期间它可以防止骨量丢失并降低骨折风险。

**风险。** NICE NG23（2024年）以绝对数字呈现风险，风险取决于HRT的类型、给药途径、妇女的年龄和使用时间：
- **乳腺癌**：**联合**HRT与乳腺癌风险增加相关，风险随使用时间延长而上升，停药后下降，但部分超额风险会持续多年。**单纯雌激素**HRT与乳腺癌风险的变化很小或无变化相关。
- **VTE**：口服HRT增加风险；标准剂量的经皮HRT不增加风险。
- **卒中**：口服雌激素与风险的小幅增加相关；经皮雌激素不增加。由于60岁以下妇女卒中的基线风险很低，绝对增加量很小。
- **心血管疾病**：60岁以下开始使用的HRT不增加心血管疾病风险。
- **子宫内膜癌**：有子宫的妇女使用单纯雌激素HRT会增加风险；恰当的联合HRT不增加风险。
- **痴呆**：在绝经前后开始使用HRT不影响痴呆风险。

对个人而言，重要的是绝对风险。如果一位妇女在某一时期内发生某事件的基线风险为$b$，而HRT使其乘以相对危险度$R$，则**额外病例数**为
$$
\text{额外病例数} = b\,(R - 1).
$$ {#eq-extra}

::: example 把相对危险度变成数字 {#ex-absolute}
假设在一组五十多岁的示例妇女中，不使用HRT时每1000人中有30人会在十年内被诊断为乳腺癌，而某种联合HRT方案使用五年与该时期内的相对危险度1.3相关。这相当于每1000名妇女有多少额外病例？你会如何描述？
::: solution
使用[[#eq-extra]]，额外病例数$= 30 \times (1.3 - 1) = 30 \times 0.3 = 9$，即每1000名妇女9例。用文字描述："在1,000名像你这样不使用HRT的妇女中，十年内约有30人会被诊断为乳腺癌。在1,000名使用这种HRT五年的妇女中，约有39人，也就是多出约9人。这意味着1,000人中约有961人不会患乳腺癌。"这种表述方式还便于与其他风险进行比较，例如饮酒或肥胖对乳腺癌的影响。这些数字只是示例；实际工作中，临床医生使用NICE讨论辅助工具中的绝对数字，这些数字因年龄、HRT类型和使用时间而异。
:::
:::

::: warning HRT不能避孕
使用HRT的围绝经期妇女仍可能排卵和妊娠，因为激素剂量太低，不能可靠地抑制排卵。需要避孕到55岁；或者，如果末次自然月经发生在50岁或以上，避孕至其后一年；如果发生在50岁以下，避孕至其后两年。LNG-IUS既可以避孕，又可以提供HRT中的孕激素成分。使用激素避孕的妇女不能依据有无月经来判断自己是否已经绝经。
:::

::: example 选择方案 {#ex-regimen}
一位52岁妇女末次月经在18个月前。她有严重的盗汗和情绪低落。BMI为34，有无先兆偏头痛。她有子宫，本人和家族都没有VTE或乳腺癌病史。哪种HRT适合她？
::: solution
她已绝经（末次月经超过12个月），所以适合**连续联合**方案，目标是不出血。由于她的BMI（VTE的危险因素）和偏头痛，首选**经皮雌二醇**而不是口服，因为在标准剂量下它不增加VTE或卒中风险。孕激素可以是口服微粒化孕酮或其他孕激素，也可以是LNG-IUS。最初几个月之后出现的任何计划外出血都应检查。应向她提供绝对风险信息，包括联合HRT与乳腺癌风险的小幅增加相关，且增加幅度取决于使用时间。她的情绪低落可能会随HRT改善；如果没有改善或很严重，应评估是否为抑郁。通常在三个月时复查，之后每年复查一次。
:::
:::

## 非激素治疗

有些妇女不能或不想使用HRT，例如乳腺癌之后。血管舒缩症状的选择包括：
- 专为绝经症状设计的**认知行为治疗**，NICE建议在HRT之外或代替HRT，考虑将其用于血管舒缩症状、情绪低落和睡眠问题；
- **SSRI和SNRI**，如文拉法辛（venlafaxine），可减少潮热；服用他莫昔芬的妇女不应使用帕罗西汀（paroxetine）和氟西汀（fluoxetine），因为它们抑制将他莫昔芬转化为活性形式的CYP2D6酶；
- **可乐定（clonidine）**和**加巴喷丁（gabapentin）**；
- **非唑奈坦（fezolinetant）**，一种作用于上述下丘脑体温调节通路的神经激肽3受体拮抗剂；它于2023年在英国获批，并经NICE评估，NICE已考虑将其用于不适合HRT的妇女；
- 生活方式措施，如减重、规律运动，以及避免酒精和咖啡因等诱因。

黑升麻和圣约翰草等草药制剂的效果和质量都不确定，而且圣约翰草与许多药物有相互作用，包括他莫昔芬和激素避孕药。如果单用HRT无效，对性欲低下的妇女可以考虑使用**睾酮**。

::: quiz
一位47岁妇女正在使用序贯联合HRT，开始使用前她的月经不规律。她问是否可以不再使用避孕套。哪个回答是正确的？
- [ ] 可以，因为HRT能抑制排卵。
- [ ] 可以，只要她已经12个月没有自然月经。
- [x] 不可以；HRT不能避孕。她需要避孕到55岁，如果末次自然月经在50岁以下，则至其后两年；LNG-IUS可以同时满足两种用途。
- [ ] 不可以；她必须停用HRT一年，以确定自己是否已绝经。
::: solution
HRT中的激素剂量不能可靠地防止排卵，而序贯HRT引起的规律出血不能说明自然月经是否已经停止。FSRH指南建议继续避孕到55岁，或者末次自然月经在50岁或以上时至其后一年，在50岁以下时至其后两年。LNG-IUS可以提供避孕和子宫内膜保护。
:::
:::

::: history
"ménopausie（绝经）"一词由法国医生夏尔·德·加尔达纳（Charles de Gardanne）于1821年提出。雌激素在1920年代和1930年代被分离出来，分离者包括埃德加·艾伦（Edgar Allen）和爱德华·多伊西（Edward Doisy）等人，结合马雌激素于1942年在北美上市。1960年代，罗伯特·威尔逊（Robert Wilson）的著作《永远的女性》（*Feminine Forever*）将雌激素宣传为保持青春的方法，其使用迅速增加，直到1970年代中期它被发现与子宫内膜癌有关；为有子宫的妇女加用孕激素解决了这一问题。2002年，妇女健康倡议（WHI）——一项在平均年龄63岁的妇女中进行的大型美国试验——的联合HRT组因乳腺癌和心血管事件增加而提前终止；2003年，英国百万妇女研究报告了与乳腺癌的关联。HRT的使用在全世界急剧下降。后来的分析表明，风险在很大程度上取决于开始使用的年龄、HRT的类型和给药途径以及使用时间，而对于60岁以下有症状的妇女，获益通常超过风险。乳腺癌激素因素协作组于2019年发表了一项关于乳腺癌风险的大型荟萃分析，这些数据是现行NICE指南中所用绝对风险数字的基础。
:::

::: summary
- 绝经即最后一次月经，在闭经12个月后诊断；英国平均年龄为51岁。POI是40岁之前卵巢功能丧失，约每100名妇女中有1人发生。
- 抑制素B和雌二醇下降解除了负反馈，因此FSH升高；围绝经期激素水平波动，所以45岁以上不用FSH诊断绝经。
- 血管舒缩症状影响约四分之三的妇女，持续时间中位数约七年；泌尿生殖症状如不治疗往往会加重。
- 40岁以下FSH升高即可诊断POI；这些妇女至少到约51岁都需要激素替代，并需检查遗传和自身免疫原因。
- 有子宫的妇女使用雌激素时需要加用孕激素。围绝经期使用序贯方案，绝经后使用连续联合方案。
- HRT是血管舒缩症状最有效的治疗，并能防止骨量丢失。联合HRT与乳腺癌风险小幅、随使用时间而增加相关；单纯雌激素HRT与之变化很小或无变化。经皮雌激素不增加VTE或卒中风险。
- 用绝对数字讨论风险：额外病例数$= b(R-1)$。
- HRT不能避孕；避孕要持续到55岁，或末次自然月经后1至2年。
- 非激素选择包括CBT、SSRI或SNRI（与他莫昔芬合用时避免帕罗西汀和氟西汀）、可乐定、加巴喷丁和非唑奈坦；小剂量阴道雌激素可安全地治疗泌尿生殖症状。
:::

## 习题

::: exercise 额外病例数 {level=1 check="6"}
一组妇女在十年内发生某事件的基线风险为每1000人20例。某种治疗的相对危险度为1.3。预计每1000名妇女会有多少额外病例？
::: solution
$20 \times (1.3 - 1) = 20 \times 0.3 = 6$，即十年内每1000名妇女有6例额外病例。
:::
:::

::: exercise 何时算绝经？ {level=1}
一位53岁妇女的末次月经在10个月前。她是否已绝经？如果她有子宫并希望治疗，哪种HRT方案合适？
::: solution
按定义还不算：绝经要在12个月无月经后才能诊断，所以她仍处于围绝经期。现在适合使用**序贯联合**方案；停经满一年后（或使用序贯HRT一年后），她可以改用连续联合HRT。过早使用连续联合HRT往往会引起不规则出血。
:::
:::

::: exercise 谁需要孕激素？ {level=1}
以下哪些人在使用全身雌激素时需要加用孕激素：(a) 因子宫肌瘤行全子宫切除术的妇女；(b) 做过子宫内膜消融术的妇女；(c) 行次全子宫切除术、保留宫颈的妇女；(d) 只使用小剂量阴道雌激素的妇女？
::: solution
(a) 不需要；没有子宫时使用单纯雌激素HRT。(b) **需要**；消融后可能残留岛状子宫内膜，可能发生增生。(c) 通常**需要**；宫颈残端中可能残留一些子宫内膜组织，因此一般建议加用孕激素（专科意见可能不同）。(d) 不需要；小剂量阴道雌激素全身吸收极少，不需要加用孕激素。
:::
:::

::: exercise 绝对获益 {level=2 check="round(40*(1-0.7))"}
假设在一组示例妇女中，每1000人中有40人会在五年内发生脆性骨折，而HRT使其降低，相对危险度为0.7。HRT在五年内每1000名妇女可预防多少次骨折？答案取最接近的整数。
::: solution
额外病例数$= 40 \times (0.7 - 1) = -12$，所以HRT在五年内每1000名妇女可**预防12次骨折**。用相同的单位（"五年内每1000名妇女"）表示获益和危害，能让妇女直接进行权衡。
:::
:::

::: exercise 乳腺癌与血管舒缩症状 {level=2}
一位50岁妇女已完成雌激素受体阳性乳腺癌的治疗，正在服用他莫昔芬，有严重潮热。有哪些选择？
::: solution
乳腺癌后一般不建议使用全身HRT，任何相关讨论都要有她的肿瘤团队参与。非激素选择包括**CBT**；**文拉法辛**或其他SNRI，或西酞普兰（citalopram）等SSRI，但**不用帕罗西汀或氟西汀**，因为它们抑制CYP2D6，减少他莫昔芬向其活性代谢物恩多昔芬的转化；**加巴喷丁**或**可乐定**；以及生活方式措施。根据其许可范围和当地指南，非唑奈坦可能是一种选择。对于阴道干涩，非激素类保湿剂和润滑剂是一线选择；与她的肿瘤科医生讨论后可考虑小剂量阴道雌激素。应避免使用圣约翰草，因为它与他莫昔芬有相互作用。
:::
:::

::: exercise 阴道症状 {level=2}
一位64岁妇女绝经已十年，有阴道干涩、性交痛，过去一年有三次尿路感染。她五十多岁时使用过三年HRT，不想再用。你会建议什么？
::: solution
这些是**绝经期泌尿生殖综合征**的表现，不治疗往往会加重。**小剂量阴道雌激素**（乳膏、栓剂或阴道环）有效，全身吸收极少，不需要加用孕激素，并可长期使用；它还能降低反复尿路感染的风险。她可以同时或改用阴道保湿剂和润滑剂。使用期间出现任何绝经后出血都必须检查。她对全身HRT的顾虑并不以同样的方式适用于小剂量阴道雌激素，这一点应向她解释。
:::
:::

::: exercise 解读FSH {level=3}
一位47岁正在服用复方口服避孕药的妇女询问自己是否已经绝经。她的全科医生在停药周测了FSH，结果为12 IU/L。这个结果意味着什么？关于避孕和绝经，你会给她什么建议？
::: solution
这个结果无法解读。复方激素避孕会抑制FSH，虽然在停药周FSH会上升，但可能达不到绝经后的数值；此外，围绝经期FSH还会波动。FSH正常并不意味着她不处于围绝经期，FSH升高也不能证明她已绝经。无论如何，NICE不建议用FSH检测来诊断45岁以上妇女的绝经。

**建议。** 如果她没有危险因素，可以继续使用复方激素避孕到50岁（它也能控制围绝经期症状），然后改用单纯孕激素方法，如LNG-IUS、皮下埋植剂或单纯孕激素避孕药，直到55岁，那时自然生育力已可忽略，可以停止避孕。如果改用后出现血管舒缩症状，可以在单纯孕激素方法的基础上加用HRT（使用LNG-IUS时它提供子宫内膜保护，否则另加孕激素）。
:::
:::

::: exercise 解读WHI {level=3}
2002年，妇女健康倡议的联合HRT组因乳腺癌和心血管事件增加而提前终止。解释为什么其结果导致了对较年轻有症状妇女的治疗不足，以及现行指南如何解读这些结果。
::: solution
WHI纳入的妇女平均年龄为63岁，其中许多人绝经已超过十年，大多数没有明显症状，而且使用的是一种特定的口服方案（结合马雌激素加醋酸甲羟孕酮）。开始口服HRT带来的心血管风险集中在已有动脉粥样硬化的年长妇女；在60岁以下或绝经十年以内的妇女中，后来的分析没有发现冠心病增加。乳腺癌的结果主要以相对危险度报告，在没有给出很小的绝对数字时听起来令人担忧。这些结果随后被推广到所有妇女和所有类型的HRT，处方量急剧下降，使许多妇女的症状和骨量丢失得不到治疗。现行指南（NICE NG23）考虑开始使用的年龄、类型、给药途径和使用时间；将HRT列为血管舒缩症状的一线治疗；以绝对数字呈现风险；并指出经皮雌激素不增加VTE或卒中风险。普遍的启示是：要检查试验人群是否与眼前的患者相符，并且要沟通绝对风险，而不仅仅是相对风险。
:::
