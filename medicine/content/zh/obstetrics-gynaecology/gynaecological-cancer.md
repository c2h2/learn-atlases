各种妇科恶性肿瘤在生物学行为和早期发现的可能性上差别很大。宫颈癌经过由病毒引起的癌前阶段缓慢发展，因此可以通过疫苗接种和筛查来预防。子宫内膜癌通常很早就以绝经后出血的形式表现出来，因此关键在于及时检查这一症状。卵巢癌在扩散之前通常只引起模糊的症状，而且没有任何筛查试验被证明能降低死亡率，所以重点在于识别症状，以及找出有遗传性高风险的妇女。外阴癌罕见，主要发生在老年妇女，常发生在受慢性疾病影响的皮肤上。

本章依次介绍每种癌症：它如何发生、如何表现、如何发现，以及治疗原则。本章还借每种癌症说明一个普遍的概念：筛查能做什么、不能做什么，针对症状的检查如何作为排除检查发挥作用，以及风险评分如何综合信息。癌症生物学的一般原理见[[pathology/cancer-biology]]，筛查项目的一般原理见[[public-health/screening]]。英国实践遵循NICE NG12（《疑似癌症：识别与转诊》，2015年首次发布，此后多次更新）和NHS筛查项目。

## 宫颈癌

### HPV与自然病程

几乎所有宫颈癌都由高危型**人乳头瘤病毒（HPV）**的持续感染引起。HPV经性传播，非常常见；大多数感染在两年内被免疫系统清除。在少数人中，高危型感染持续存在，尤其是HPV 16和18型，两者合计导致约70%的宫颈癌。病毒癌蛋白**E6**和**E7**结合并灭活宿主的肿瘤抑制蛋白**p53**和**视网膜母细胞瘤蛋白（pRb）**，使细胞分裂失控、遗传损伤不断累积。

这一过程始于**转化区**，即宫颈管的柱状上皮与宫颈外口鳞状上皮交界、并发生化生的区域。这些变化在数年内经历癌前阶段，这正是筛查有效的原因。

::: definition 宫颈上皮内瘤变 {#def-cin}
**宫颈上皮内瘤变（CIN）**是宫颈鳞状上皮的癌前病变，按上皮全层中含异常细胞的比例分级：
- **CIN 1**：下三分之一。通常反映一过性HPV感染，会自行消退；以监测处理。
- **CIN 2**：最多三分之二。常需治疗，但部分较年轻的妇女可以选择观察。
- **CIN 3**：超过三分之二或全层（原位癌）。需要治疗，因为如不治疗，相当一部分会在数年内进展为浸润癌。

腺上皮的癌前病变（**宫颈腺上皮内瘤变**，CGIN）较少见，也更难通过细胞学检出。
:::

### 预防

**HPV疫苗**可预防疫苗所含型别的感染。在英国，自2008年起为12–13岁女孩接种，2019年起扩展到男孩，2023年起改为单剂接种。效果非常显著：英格兰2021年发表的一项研究发现，在12–13岁时被提供疫苗的妇女中，宫颈癌发病率比未接种队列低约87%。WHO的全球战略（2020年）目标是消除作为公共卫生问题的宫颈癌，定义为每年每10万妇女少于4例。

英格兰的**宫颈筛查**邀请25至64岁的妇女和有宫颈的人参加。样本先检测高危型HPV（**HPV初筛**），只有HPV阳性的样本才做细胞学检查。自2025年7月起，25至49岁HPV阴性者的召回间隔从三年延长为五年，这一间隔此前已用于50至64岁的人群以及苏格兰和威尔士。流程为：

- **HPV阴性**：回到常规召回。
- **HPV阳性，细胞学异常**：转诊做**阴道镜检查**。
- **HPV阳性，细胞学正常**：12个月后复查。如果12个月时HPV仍阳性而细胞学正常，24个月时再复查；如果24个月时仍阳性，则做阴道镜检查。

做**阴道镜检查**时，在涂抹醋酸（使异常上皮变白）和碘液之后，在放大下观察宫颈，并对异常区域取活检。CIN 2和CIN 3通常用**转化区大环切除术（LLETZ）**治疗，即用电热金属丝环切除异常区域，通常在局部麻醉下进行。切除过深或反复切除会轻度增加以后妊娠早产的风险，这是避免过度治疗的原因之一。

::: example HPV阳性结果之后 {#ex-screening}
一位32岁妇女的宫颈筛查样本HPV阳性，细胞学正常。她担心自己得了癌症，并问是不是她的伴侣不忠。你会如何解释这个结果和下一步？
::: solution
**含义。** HPV非常常见，大多数感染者在一到两年内会清除它。检测阳性而细胞学正常意味着没有看到异常细胞。这并不意味着她得了癌症，也不意味着她很快就会得癌症。HPV感染后可在多年内检测不到，因此阳性结果并不能说明何时、从谁那里感染，也不意味着不忠。

**下一步。** 按照英格兰的流程，她会在12个月后被邀请复查，看她的身体是否已清除病毒。如果12个月时HPV仍存在而细胞学正常，她会在24个月时再次检测；如果那时仍阳性，或任何时候细胞学变为异常，就会转诊做阴道镜检查。戒烟有助于清除HPV。应告诉她，如果出现性交后出血或经间期出血，要及时找全科医生就诊，不要等到下一次筛查。
:::
:::

### 临床表现与治疗

宫颈癌最常见于30至45岁的妇女。大多数为鳞状细胞癌；约五分之一为腺癌。早期癌可能只能通过筛查发现。症状包括**性交后出血**、**经间期出血**、绝经后出血和恶臭的分泌物；晚期病变引起盆腔痛、腿部肿胀以及输尿管梗阻所致的肾衰竭。有症状的妇女需要检查宫颈，如果宫颈外观异常，则按疑似癌症途径转诊；宫颈筛查不是诊断性检查，不应用于检查症状。

分期采用**FIGO 2018**系统，结合临床检查、影像学检查（通常为MRI）和病理。Ⅰ期局限于宫颈；Ⅱ期超出子宫，但未达盆壁或阴道下三分之一；Ⅲ期累及阴道下段或盆壁、引起肾积水，或累及盆腔或腹主动脉旁淋巴结；Ⅳ期累及膀胱或直肠黏膜或远处部位。

治疗取决于分期。极早期癌可用锥切活检治疗，希望保留生育力的妇女可行**根治性宫颈切除术**（切除宫颈，保留子宫）。其他早期癌用根治性子宫切除术加盆腔淋巴结评估治疗。局部晚期癌用**同步放化疗**（外照射放疗加顺铂（cisplatin））后续近距离放疗治疗。

::: example 性交后出血 {#ex-pcb}
一位38岁妇女性交后出血已三个月。她上一次宫颈筛查在四年前，HPV阴性。她问能不能再做一次筛查就行。应如何评估？
::: solution
**不是筛查检查。** 筛查是为没有症状的人设计的。有症状的妇女需要诊断性评估，而以前的阴性筛查结果或新的筛查都不能排除癌症：一小部分癌症，尤其是腺癌，会被筛查漏掉。

**评估。** 必要时做妊娠试验；窥器检查观察宫颈；取拭子检测衣原体和淋球菌，因为宫颈炎是性交后出血的常见原因；并做双合诊。常见的良性发现包括宫颈**柱状上皮异位**（宫颈外口上的柱状上皮，容易出血）或息肉。

**转诊。** 如果宫颈外观可疑为癌症，NICE建议按疑似癌症途径转诊。如果宫颈外观正常但出血持续，应转诊做阴道镜检查。没有经过这些步骤，不应认定可见的柱状上皮异位就是病因，因为早期癌可能看起来很相似。
:::
:::

## 子宫内膜癌

子宫内膜癌是英国最常见的妇科恶性肿瘤，其发病率随肥胖的增加而上升。它主要发生在绝经后，发病高峰在六十多岁。

**无对抗的雌激素**是核心危险因素。雌激素刺激子宫内膜增生，而排卵后产生的孕酮使增生停止，并使子宫内膜转化以便脱落。任何有雌激素而孕酮很少的情况都会增加风险：
- **肥胖**，因为脂肪组织通过芳香化酶将雄激素转化为雌激素；这是最重要的可改变危险因素；
- **无排卵**，如PCOS；
- 有子宫的妇女使用**单纯雌激素HRT**；
- **他莫昔芬（tamoxifen）**，它对子宫内膜起雌激素激动剂作用；
- 初潮早、绝经晚和未产。

2型糖尿病也是危险因素。**林奇综合征**是DNA错配修复基因的遗传性缺陷，带来很高的子宫内膜癌和结直肠癌终生风险。复方激素避孕、LNG-IUS和妊娠具有保护作用。

**子宫内膜样腺癌**是最常见的类型，通常经子宫内膜增生发展而来，常为低级别，预后良好。浆液性癌和透明细胞癌较少见，与雌激素无关，侵袭性更强。自2023年起，FIGO分期纳入了按遗传学特征对肿瘤分组的**分子分类**：**POLE**突变型（预后极好）、**错配修复缺陷型**、**p53异常型**（预后差）和**无特异性分子特征型**。NICE建议对所有子宫内膜癌检测错配修复缺陷，这也能识别可能患有林奇综合征的妇女。

### 绝经后出血

::: definition 绝经后出血 {#def-pmb}
**绝经后出血（PMB）**是末次月经12个月或以上之后发生的阴道出血。约十分之一的PMB妇女患有子宫内膜癌，因此PMB一定要检查。NICE NG12建议55岁或以上的PMB妇女按疑似癌症途径转诊，55岁以下者考虑转诊。
:::

第一项检查是**经阴道超声**测量**子宫内膜厚度**。对未使用HRT的妇女，子宫内膜薄（英国实践中小于4 mm）使癌症的可能性很小。子宫内膜较厚，或子宫内膜薄但出血持续，则需取组织样本：门诊pipelle活检，或宫腔镜检查加直视下活检。

::: theorem 好的排除检查可以有很低的阳性预测值 {#thm-rule-out}
对于灵敏度高的检查，即使特异度只是中等，阴性结果也能大大降低患病的概率。而同一检查的阳性结果仍可能使大多数人并未患病。这样的检查用来**排除**疾病，并筛选出需要做更确定检查的人。
:::

::: proof
阴性预测值为$\text{NPV} = \dfrac{\text{TN}}{\text{TN} + \text{FN}}$。灵敏度高时，假阴性（FN）很少，因此无论特异度如何，NPV都接近1。阳性预测值为$\text{PPV} = \dfrac{\text{TP}}{\text{TP} + \text{FP}}$。当患病率不高、特异度中等时，来自人数众多的无病组的假阳性（FP）多于真阳性，PPV就很低。PMB中的子宫内膜厚度正是如此：许多良性疾病，如息肉和肌瘤，会使子宫内膜增厚，而几乎所有癌症都会使其增厚。图和[[#ex-pmb]]给出了具体数字。
:::

::: widget bayes
mode: test
prevalence: 0.09
sensitivity: 0.95

caption: 经阴道超声作为绝经后出血的排除检查，使用示例数值：子宫内膜癌患病率9%，子宫内膜厚度4 mm或以上的灵敏度95%，特异度55%。超声阴性时残留的癌症风险很小，而大多数子宫内膜增厚的妇女并没有癌症，需要活检才能弄清。试着提高特异度，看它如何改变阳性预测值，却几乎不改变阴性预测值。
:::

::: example 检查绝经后出血 {#ex-pmb}
使用图中的数值，设想1,000名PMB妇女。有多少人患子宫内膜癌？多少人子宫内膜厚度为4 mm或以上？阳性和阴性预测值是多少？
::: solution
患病率为9%时，**90**名妇女患癌，910名未患癌。

90名患癌者中，$90 \times 0.95 = 85.5$人子宫内膜增厚（真阳性），4.5人未增厚（假阴性）。

910名未患癌者中，$910 \times 0.55 = 500.5$人子宫内膜薄（真阴性），$910 \times 0.45 = 409.5$人子宫内膜增厚（假阳性）。

阳性结果：$85.5 + 409.5 = 495$。**PPV** $= 85.5/495 \approx 17\%$。

阴性结果：$500.5 + 4.5 = 505$。**NPV** $= 500.5/505 \approx 99.1\%$。

因此约一半的妇女仅凭超声就可以放心，残留风险不到1%；另一半继续做活检，其中约六分之一患癌。子宫内膜薄但持续出血的妇女仍需进一步检查，因为这项检查并不完美。
:::
:::

### 治疗

大多数子宫内膜癌在Ⅰ期诊断，用**全子宫切除术加双侧输卵管卵巢切除术**治疗，通常经腹腔镜进行，并根据风险进行淋巴结评估（越来越多地采用前哨淋巴结活检）。根据分期、分级和分子分型给予辅助放疗（常为阴道近距离放疗）或化疗。晚期或复发性疾病可用化疗、激素治疗（孕激素）治疗，错配修复缺陷型肿瘤还可用免疫治疗。**子宫内膜不典型增生**是一种前驱病变，同时存在或将来发生癌症的风险相当大，通常建议行子宫切除术；对希望保留生育力或不能耐受手术的妇女，可选择LNG-IUS等孕激素治疗，并密切进行活检监测。

## 卵巢癌

约90%的卵巢癌是**上皮性**的。最常见也最致命的类型**高级别浆液性癌**，常常起源于输卵管远端的浆液性输卵管上皮内癌，然后扩散到卵巢和腹膜。这一发现解释了为什么切除输卵管能降低风险。其他类型包括子宫内膜样癌和透明细胞癌（与子宫内膜异位症相关）、黏液性肿瘤、交界性肿瘤，以及年轻妇女中的生殖细胞肿瘤和性索间质肿瘤。

**危险因素**有年龄、家族史，尤其是遗传性突变：**BRCA1**突变携带者的卵巢癌终生风险约为40%，**BRCA2**约为15%–20%；林奇综合征也会增加风险。减少排卵或阻断输卵管的因素具有保护作用：复方激素避孕、妊娠、母乳喂养、输卵管结扎和输卵管切除。

**临床表现。** 由于盆腔宽大，腹膜腔又能容纳肿瘤播散，大多数妇女就诊时已是晚期，症状常见而无特异性。NICE（CG122，2011年）建议，对于持续或频繁出现以下症状（尤其是每月超过12次）的妇女，特别是50岁或以上者，应考虑卵巢癌：**腹胀或胀气**、**早饱或食欲减退**、**盆腔或腹部疼痛**、**尿急或尿频**。50岁以上妇女新出现肠易激综合征的症状也应引起怀疑。腹水或盆腔、腹部包块需要紧急转诊。

**检查。** 在初级保健中测定血清**CA-125**；如果达到或超过35 IU/mL，随后做腹部和盆腔超声。在二级医疗中，**恶性风险指数（RMI）**综合超声结果、绝经状态和CA-125，以决定哪些妇女应由妇科肿瘤专科团队处理。

::: definition 恶性风险指数 {#def-rmi}
$$
\text{RMI} = U \times M \times \text{CA-125},
$$ {#eq-rmi}
其中CA-125为血清水平（IU/mL），并且：
- $U$为**超声评分**：多房囊肿、实性区域、转移、腹水和双侧病变每项计1分；无任何特征时$U = 0$，有一项特征时$U = 1$，有二至五项特征时$U = 3$。
- $M$为**绝经评分**：绝经前妇女$M = 1$，绝经后妇女$M = 3$。

NICE CG122建议RMI达到或超过250的妇女转诊至专科多学科团队。
:::

CA-125并不特异：子宫内膜异位症、子宫肌瘤、妊娠、月经、盆腔感染、肝病以及任何刺激腹膜或胸膜的疾病都会使其升高。这就是为什么它要与超声和绝经状态结合使用，也是为什么绝经前妇女CA-125升高的意义小于绝经后妇女。

::: example 计算RMI {#ex-rmi}
一位64岁妇女腹胀和早饱已六个月。超声显示双侧多房卵巢包块，有实性区域，并有少量腹水。CA-125为180 IU/mL。计算她的RMI，并说明下一步应怎么做。
::: solution
**超声评分。** 她有多房囊肿、实性区域、腹水和双侧病变：四项特征，所以$U = 3$。

**绝经评分。** 她已绝经，所以$M = 3$。

**RMI** $= 3 \times 3 \times 180 = 1620$。

这远远超过250。应将她紧急转诊至妇科肿瘤多学科团队，并做胸部、腹部和盆腔CT进行分期。如果不计划进行初始手术，可在治疗前抽取腹水做细胞学检查，并取组织活检以确诊。
:::
:::

晚期上皮性卵巢癌的**治疗**结合了以切除所有肉眼可见病灶为目标的**肿瘤细胞减灭术**和**铂类化疗**（卡铂（carboplatin）加紫杉醇（paclitaxel）），化疗可在手术后进行，或在最初无法完全切除时于手术前后进行（新辅助化疗）。使用奥拉帕利（olaparib）和尼拉帕利（niraparib）等**PARP抑制剂**的维持治疗改善了生存，尤其是在有BRCA突变或其他同源重组修复缺陷的妇女中。PARP抑制剂利用**合成致死**：缺乏BRCA介导修复的细胞依赖PARP介导的修复，同时阻断两者即可杀死它们。所有非黏液性上皮性卵巢癌妇女都应接受胚系基因检测，因为发现BRCA突变既能指导治疗，又能让亲属接受检测（[[genetics/cancer-genetics]]）。

**筛查。** 英国卵巢癌筛查协作试验（UKCTOCS）将20多万名绝经后妇女随机分为每年基于CA-125的筛查组、超声筛查组和不筛查组，于2021年报告：筛查使一些癌症被更早发现，但**没有降低**卵巢癌死亡率。因此没有人群筛查项目。遗传性高风险妇女在完成生育后可接受**降低风险的输卵管卵巢切除术**：BRCA1携带者通常在35至40岁之间，BRCA2携带者在40至45岁之间。手术绝经有其后果，对没有乳腺癌的妇女，通常提供HRT直至自然绝经年龄。

::: warning 不要把老年妇女的腹胀轻易归为肠易激综合征
肠易激综合征很少在50岁以后才首次出现。50岁以上的妇女新出现持续腹胀、早饱、盆腔痛或尿频时，在将症状归因于IBS之前，应查CA-125，升高时做超声。CA-125正常也不能完全排除卵巢癌，症状持续时应重新评估。
:::

## 外阴癌

外阴癌不常见，主要影响60岁以上的妇女。大多数为鳞状细胞癌，有两种发生途径。在较年轻的妇女中，它与HPV和一种称为**普通型外阴上皮内瘤变（VIN）**的前驱病变相关。在老年妇女中更常见的是，它在没有HPV的情况下，经由一种称为分化型VIN的前驱病变，发生在受**硬化性苔藓**影响的皮肤上；硬化性苔藓是一种慢性炎症性皮肤病，引起瘙痒以及白色、变薄、脆弱的皮肤。用强效外用糖皮质激素治疗硬化性苔藓可以控制症状，并可能降低癌症风险；患有硬化性苔藓的妇女需要长期随访，并被告知出现任何新的肿块、溃疡或不愈合的区域时要及时就诊。

外阴癌表现为肿块、溃疡、出血，或持续的瘙痒或疼痛。任何不明原因的外阴肿块、溃疡或出血都应按疑似癌症途径转诊并活检。治疗以手术为主：广泛局部切除加腹股沟淋巴结评估，小肿瘤采用前哨淋巴结活检，晚期病变采用放疗。

::: quiz
一位58岁妇女在末次月经两年后出现一次少量阴道点滴出血。她未使用HRT，自觉良好。最恰当的措施是什么？
- [ ] 安慰她，因为绝经后单次少量出血很常见。
- [ ] 安排宫颈筛查。
- [x] 按疑似癌症途径转诊做经阴道超声，必要时取子宫内膜样本。
- [ ] 检查CA-125。
::: solution
末次月经12个月或以上之后的任何出血都是绝经后出血，必须检查，因为约十分之一的PMB妇女患有子宫内膜癌。NICE建议55岁或以上的妇女按疑似癌症转诊。经阴道超声测量子宫内膜厚度，如果增厚或出血持续则做活检。宫颈筛查不是针对症状的诊断性检查，而CA-125是针对卵巢癌而不是子宫内膜癌的检查。
:::
:::

::: history
1928年，乔治斯·帕帕尼科拉乌（Georgios Papanicolaou）报告可以在阴道涂片中看到癌细胞；1943年，他与赫伯特·特劳特（Herbert Traut）发表专著，表明宫颈细胞学可以在症状出现之前发现癌症。有组织的细胞学筛查于1940年代末在不列颠哥伦比亚省引入，1988年在英国作为全国性的召回项目推行，大大降低了宫颈癌的发病率和死亡率。1970年代末和1980年代初，哈拉尔德·楚尔·豪森（Harald zur Hausen）提出乳头瘤病毒导致宫颈癌，他的团队于1983年和1984年分别从宫颈癌组织中分离出HPV 16和HPV 18，这项工作获得了2008年诺贝尔生理学或医学奖。1990年代初，伊恩·弗雷泽（Ian Frazer）和周健开发了病毒样颗粒，由此产生了自2006年起获批的HPV疫苗。在卵巢癌方面，玛丽-克莱尔·金（Mary-Claire King）于1990年将一个乳腺癌易感基因定位到17号染色体，*BRCA1*于1994年被克隆，为基因检测、降低风险的手术以及2014年首批PARP抑制剂获批用于BRCA突变卵巢癌开辟了道路。
:::

## 后续内容

绝经前的异常出血见[[obstetrics-gynaecology/menstrual-pelvic-disorders]]。包括BRCA和林奇综合征在内的遗传性肿瘤综合征见[[genetics/cancer-genetics]]。HRT与子宫内膜见[[obstetrics-gynaecology/menopause]]。作为人群干预措施的筛查见[[public-health/screening]]，诊断试验的准确性见[[epidemiology-ebm/diagnostic-tests]]。

::: summary
- 持续的高危型HPV感染导致几乎所有宫颈癌；E6和E7灭活p53和pRb。HPV 16和18导致约70%。
- CIN 1通常会消退；CIN 2和3通常用LLETZ治疗。
- 英格兰对25至64岁人群采用HPV初筛；自2025年7月起，所有年龄的HPV阴性者均在五年后召回。HPV阳性而细胞学正常者在12和24个月时复查；细胞学异常者转诊阴道镜。
- HPV疫苗（英国青少年现为单剂接种）已使接种队列的宫颈癌大幅减少。
- 子宫内膜癌由无对抗的雌激素驱动：肥胖、无排卵、单纯雌激素HRT和他莫昔芬。绝经后出血必须检查，首选经阴道超声。
- 子宫内膜厚度小于4 mm是很好的排除检查：PPV虽低，NPV很高。
- 卵巢癌就诊晚、症状无特异性；初级保健先查CA-125再做超声；RMI $= U \times M \times$ CA-125，达到或超过250时转诊。
- 在UKCTOCS中，对一般人群筛查卵巢癌没有降低死亡率；BRCA携带者可接受降低风险的输卵管卵巢切除术。
- 外阴癌在较年轻妇女中经由HPV相关的VIN发生，在老年妇女中经由硬化性苔藓发生；任何持续的外阴肿块或溃疡都需要活检。
:::

## 习题

::: exercise RMI计算 {level=1 check="270"}
一位60岁绝经后妇女有一个单侧卵巢囊肿，有实性区域，无其他特征。CA-125为90 IU/mL。计算她的RMI。
::: solution
一项超声特征（实性区域），所以$U = 1$；已绝经，所以$M = 3$。RMI $= 1 \times 3 \times 90 = 270$。超过250，因此应转诊至专科多学科团队。
:::
:::

::: exercise CIN分级 {level=1}
一位27岁妇女的阴道镜活检显示CIN 1。这意味着什么？通常如何处理？
::: solution
异常细胞局限于上皮的下三分之一。CIN 1通常反映一过性HPV感染，大多数无需治疗即可消退，因此以监测（复查）而不是切除来处理。治疗会让她承受LLETZ的小风险，包括早产风险的轻度增加，而获益很小。
:::
:::

::: exercise 子宫内膜癌的风险 {level=1}
列出子宫内膜癌的五个危险因素和三个保护因素，并解释其中大多数因素的共同机制。
::: solution
**危险因素**：肥胖、PCOS和无排卵、有子宫的妇女使用单纯雌激素HRT、他莫昔芬、未产、初潮早和绝经晚、2型糖尿病、林奇综合征。**保护因素**：复方激素避孕、LNG-IUS、妊娠、与单纯雌激素HRT相比的复方（雌激素加孕激素）HRT。**机制**：其中大多数增加或减少子宫内膜在没有孕酮对抗作用下暴露于雌激素的程度。林奇综合征则是通过DNA错配修复缺陷起作用。
:::
:::

::: exercise 阳性预测值 {level=2 check="round(100*85.5/495)"}
在[[#ex-pmb]]中，子宫内膜厚度为4 mm或以上的妇女中有百分之几患子宫内膜癌？答案取最接近的整数百分比。
::: solution
PPV $= 85.5/495 \approx 0.173$，即**17%**。大多数子宫内膜增厚的妇女是良性原因，如息肉或伴有积液的萎缩，这就是为什么诊断要靠组织取样而不是超声。
:::
:::

::: exercise 绝经前妇女的CA-125 {level=2}
一位34岁痛经妇女有一个5 cm的卵巢囊肿，呈"磨玻璃样"回声，CA-125为95 IU/mL。计算她的RMI，并解释为什么此时CA-125升高不那么令人担忧。
::: solution
内容为"磨玻璃样"的单房囊肿不具备五项超声特征中的任何一项，所以$U = 0$；她未绝经，所以$M = 1$。她的RMI为$0 \times 1 \times 95 = 0$，即使有一项特征（$U = 1$）也只有95，远低于250。临床表现提示**子宫内膜异位囊肿**：子宫内膜异位症常使CA-125升高，绝经前妇女的月经、子宫肌瘤和盆腔感染也会使其升高，因此该标志物在绝经前的特异性要低得多。年轻妇女有实性包块时要考虑生殖细胞肿瘤，如果影像提示，则检查AFP和hCG等标志物。
:::
:::

::: exercise 一位BRCA1携带者 {level=2}
一位33岁妇女刚得知自己携带致病性*BRCA1*变异。她有一个孩子，可能还想再要一个。关于她的卵巢癌风险，你会讨论什么？
::: solution
她的卵巢癌（和输卵管癌）终生风险约为40%，从四十多岁起急剧上升，而且没有有效的筛查。建议在她完成生育后行**降低风险的输卵管卵巢切除术**，BRCA1携带者通常在35至40岁之间；它能大大降低卵巢癌和输卵管癌的风险。它会导致手术绝经，因此如果她没有患过乳腺癌，通常建议使用HRT至约51岁，并要关注骨骼和心血管健康。在此期间服用复方避孕药可降低卵巢癌风险。她的乳腺癌风险（MRI筛查、降低风险的乳房切除术）以及对亲属的影响（可为亲属提供检测）应通过临床遗传科处理（[[genetics/cancer-genetics]]）。
:::
:::

::: exercise 为什么UKCTOCS很重要 {level=3}
在UKCTOCS中，筛查组发现了更多早期癌症，但卵巢癌死亡并未减少。解释两者为何可以同时成立，以及这对评价筛查有何启示。
::: solution
诊断时分期更早是一个替代结局。筛查可以改变分期而不改变死亡，原因有：**领先时间偏倚**（诊断更早，所以从诊断起算的生存看起来更长，但死亡时间不变）、**病程长度偏倚**（筛查更容易发现生长较慢、本来预后就较好的肿瘤），以及对本不会造成危害的肿瘤的**过度诊断**。在UKCTOCS中，Ⅳ期病变的减少幅度不大，没有转化为死亡的减少，可能是因为高级别浆液性癌在能被CA-125或超声发现之前，就已经从输卵管早期扩散。启示是：筛查项目必须通过以**疾病特异性或全因死亡率**为结局的随机试验来评判，而不是看分期迁移或从诊断起算的生存。见[[epidemiology-ebm/bias-confounding]]。
:::
:::

::: exercise 外阴症状 {level=3}
一位74岁妇女多年来外阴瘙痒，断断续续用抗真菌乳膏治疗。检查见外阴和肛周皮肤有白色、变薄、起皱的区域，左侧大阴唇上有一个1 cm的质硬溃疡性病灶。可能的诊断和处理是什么？
::: solution
外阴和肛门周围呈"8"字形分布的白色、变薄、起皱的皮肤是**硬化性苔藓**的典型表现，一直被误诊为念珠菌感染。患有硬化性苔藓的老年妇女出现溃疡性肿块，在证明并非如此之前应视为**外阴鳞状细胞癌**。她需要按疑似癌症途径转诊，并对病灶活检。如果确诊为癌症，治疗通常为手术切除加腹股沟淋巴结评估（小肿瘤做前哨淋巴结活检），由专科团队计划。她的硬化性苔藓应使用强效外用糖皮质激素治疗，并长期随访。老年妇女对抗真菌治疗无效的慢性外阴瘙痒应当进行检查，而不是一次次在电话里开药。
:::
