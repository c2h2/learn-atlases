妇科肿瘤的诊断常常依赖一句被说出口的症状：**绝经后出血、持续的腹胀与盆部的包块、异常的宫颈筛查、以及“绝不可能”的年轻患者，这四个入口决定了绝大多数病例是被早期发现还是被错过。**本章覆盖子宫内膜癌与卵巢癌与宫颈癌（含外阴与妊娠滋养细胞）的识别、筛查与遗传的评估（在 BRCA 与林奇综合征上）、以及从转诊到姑息的整个路径；治疗原则只在需要理解预后的地方展开，而服务的失败模式是重点。

## 子宫内膜癌

::: definition 绝经后出血与子宫内膜癌 {#def-endometrial}
**绝经后出血是一个症状而不是一个诊断，它约九成因萎缩性阴道炎与内膜萎缩与息肉所致，但在全部病例中约百分之四到十最终是子宫内膜癌，而这一比例随年龄上升，因此不能靠“她出血很少”来分级。评估的第一件事是内膜的厚度：经阴道超声在绝经后子宫中的意义在于，若内膜线薄于四到五毫米，则癌的可能极低在（阴性的似然比很低）从而可以安全地不活检；若内膜厚、看不清、或有宫腔的液体与在（回声不均），则需要内膜的取样在（门诊的吸引管）或在门诊无法完成在（因颈管狭窄与疼痛）时做宫腔镜与在（扩张刮宫）。要在第一次就处理的技术问题包括：她是否仍在用在（激素替代治疗）在开始后的前几个月内的在（（不规则出血是常见的）而持续或迟发的出血仍需评估）、是否服用他莫昔芬在其内膜的拟雌激素作用与息肉与在（罕见的肉瘤）、以及是否有抗凝在（抗凝可以揭示出血而不造成出血）。诊断性诊室的关键：出血的伴随症状在（绝经后任何阴道流血或排液都要检查，无论量多少）与在（宫颈的视诊）与在（性传播感染的筛查）以及在（若在若干年前已切除子宫则仍需评估残端与阴道）。风险因素在解释时有用：无对抗的雌激素暴露在肥胖与在多囊卵巢与在（（单用雌激素））、初潮早与绝经晚与在（不育）、林奇综合征在（她应被问结直肠与子宫内膜的家系）、以及在他莫昔芬与在（（糖尿病））。分期与治疗按手术后的病理在肌层的浸润深度与在分级与在（（淋巴血管的间隙））决定在是否需要辅助的放疗与在（化疗），而多数病例在早期因出血被发现在（I 期的五年生存率在九成左右），因此本章的重点不是治疗而是不要把第一次出血当作“更年期还没结束”（[[obstetrics-gynaecology/menopause]]、[[obstetrics-gynaecology/postnatal-period]]、[[genetics/cancer-genetics]]、[[clinical-skills/medical-imaging]]）。**

## 卵巢癌

::: definition 卵巢、输卵管与原发腹膜的癌 {#def-ovarian}
**卵巢癌是妇科肿瘤中最难早期发现的，也是唯一筛查试验未能降低死亡率的常见癌：两项大样本的随机试验显示在经阴道超声与在（（肿瘤标志物的联合筛查））增加了假阳性与在（不必要的手术）而不改变死亡，因为早期病例少且在（多数早期病例并无症状）。因此识别依赖症状的组合与在（持续的时间）：新发的在（在一个月内出现十二次以上）的腹胀、盆或腹的疼痛、进食快或饱胀、以及泌尿的急迫或频密，尤其在六十岁以后；英国据此制定的单日血标志物路径把 CA125 作为入口——若升高则影像与转诊，同时用全血计数与其他炎症指标避免把良性的腹胀送去手术。要知道卵巢的包块在绝经后与在（绝经前）的含义完全不同：绝经后任何可触及的卵巢都应评估在（正常的绝经后卵巢体积小且通常摸不到），而绝经前的单纯性囊肿在五厘米以下多为功能性，可以观察。风险的咨询是本章最实用的部分：终身风险约百分之一点三，而 BRCA1 与 BRCA2 的致病变异可把它抬到在约四成与在（（近两成））、林奇综合征约百分之十，一级亲属中有一例者风险约翻倍；因此新诊断的上皮性卵巢癌患者本人应接受基因的检测在（胚系的与肿瘤的），因为这既影响治疗也影响家属。治疗的原则只需记住预后：发现于早期的比例低，全部期别的五年生存率在四成左右在（晚期显著低于早期），手术的质量与在（肿瘤细胞的减灭）与在铂类的化疗与在若干分子分型上的在（（靶向维持治疗））决定病程；而输卵管与在（原发腹膜）的癌在生物学上与处理上与卵巢相似在（并且是多数高级别浆液性癌的起源部位），这也解释了在降低风险的手术为何以在（输卵管切除为核心）（[[obstetrics-gynaecology/contraception-fertility]]、[[genetics/cancer-genetics]]、[[pathology/cancer-diagnosis]]、[[public-health/screening]]）。**

## 宫颈、外阴与滋养细胞

::: definition 宫颈筛查与其他妇科肿瘤 {#def-cervical}
**宫颈癌是本章中唯一可被筛查几乎完全预防的癌：持续的在（高危型人乳头状瘤病毒的）感染是必要条件，从感染到高级别的病变常需十年以上，这给了筛查以足够的时间窗。现代筛查以在（病毒的检测为首选）在（分子的方法比细胞学更敏感），阳性的分流靠在细胞学与在（阴道镜），因此“筛查正常”不再等于“没有病毒”。要看懂筛查的三个陷阱。第一，年轻女性的低级别改变多为自限性的感染，过度治疗会带来在宫颈的机能不全与在（妊娠的风险），所以年轻组别要更保守地随访而不是更早地切。第二，高级别的报告不等于癌：需要阴道镜下的定位活检，且在（细胞学与组织学可以不一致）。第三，间期癌在（筛查正常后到下次筛查前发生的癌）的最常见原因不是检验的错误，而是在（她从未被叫去筛查）或在取材不合格与在（采样未取到转化区），因此治理上要审的是在覆盖率与在不合格率与在（间隔的长短）而不是化验的显微镜。症状要记牢：接触性出血在（性交后）与在（绝经后）与在（异常的排液）与在（盆腔的疼痛）与晚期的腿肿；早期常无症状，因此接触性出血在任何年龄都应被检查，包括已筛查正常者。外阴癌多见于年长女性，常在多年在的外阴营养不良与在（瘙痒）后出现在不能愈合的溃疡或在（（白色的增厚）），因被当作在皮肤病与在（“老年改变”）而被长期延误，其确诊靠在（活检）而不是外用药的试验。妊娠滋养细胞疾病在（妊娠试验阳性）的女性中与在子宫明显大于孕周与在剧烈的呕吐与在（早期的高血压）时想到在（葡萄胎），其后的监测靠在（绒毛膜促性腺激素的曲线），而它对化疗高度敏感，是实体瘤中可治愈的典范。最后一条是关于服务的：这三类癌的共同失败不是治疗而是识别，因此本章所有例子都关于门诊、护士、全科与在（筛查的程序）（[[obstetrics-gynaecology/menstrual-pelvic-disorders]]、[[infectious-diseases/sexually-transmitted-infections]]、[[public-health/screening]]、[[pathology/cancer-biology]]）。**

## 通向何处

绝经与激素治疗见[[obstetrics-gynaecology/menopause]]；月经与盆腔疾病见[[obstetrics-gynaecology/menstrual-pelvic-disorders]]；妊娠与滋养细胞见[[obstetrics-gynaecology/early-pregnancy]]；产后见[[obstetrics-gynaecology/postnatal-period]]；筛查的方法学见[[public-health/screening]]；遗传的评估见[[genetics/cancer-genetics]]；肿瘤的一般生物学见[[pathology/cancer-biology]]；症状控制与姑息见[[geriatrics-palliative/palliative-care]]。

::: history
**妇科肿瘤的历史是一部关于“谁的症状被相信”的历史。十九世纪的医生已经描述过子宫的癌，但外科手术长期被败血症与出血挡住；1890年代，无菌技术成熟之后，经腹的广泛子宫切除被提出，用切除宫旁组织与阴道上段的方式治疗宫颈癌，这一思路统治了半个世纪，直到放疗在二十世纪上半叶被系统引入，形成了今天仍在使用的“早期可以手术或放疗、局部晚期以放化疗为主”的格局。宫颈癌的转折来自筛查。1928年，一位希腊出生的医生在纽约的会议上提出用阴道涂片发现早期的病变，报告未被采纳，直到1940年代一位英国妇产科医生在《柳叶刀》上为其撰写社论、且美国的团队开展了大规模试验，细胞学筛查才真正落地；1980年代的团队用流行病学的方法证明了筛查能降低死亡，此后多国建立了以人群为基础的邀请系统，覆盖率与不合格率与间期癌由此成为可被审计的数字。病毒的因果是二十世纪后半叶最重要的肿瘤学发现之一：从1930年代在兔的乳头瘤病毒上做的移植实验，到1970年代有人在人疣上提出病毒与癌的联系，再到1980年代科学家从宫颈癌组织中克隆出人乳头状瘤病毒的脱氧核糖核酸并证明其在病变中表达，这一路被主流学界拒绝了十余年，而他在2008年获得诺贝尔奖。因果明确之后，疫苗在2006年前后被批准，最先大规模接种的国家在年轻女性中观察到高级别病变与生殖器疣的大幅下降，并使“消除宫颈癌”在2020年成为世界卫生大会通过的目标，这是实体瘤史上第一次以免疫接种作为消除的手段。卵巢癌的故事更沉。它长期被称为“沉默的杀手”，而这个标签本身造成伤害：它暗示无症状，从而让医生不去理会腹胀与泌尿的症状；1990年代的研究提出高级别浆液性癌多起源于输卵管的伞端，这改变了降低风险手术的做法，也解释了为何保留卵巢的子宫切除并不能完全消除风险。标志物 CA125 自1981年报道以来一直是双面的工具：它对监测复发有用，作为筛查则被两项大样本随机试验证明无效；2010年代多国推行的单日路径，以一次血中的 CA125 结合全血计数决定当日是否转诊与影像，是这一领域少见的、在真实世界中同时缩短诊断间隔并减少不必要转诊的改革。子宫内膜癌走的是另一条路：它因出血而被早期发现，因此它的改善主要来自把“绝经后出血必须在两周内被检查”写成可执行的服务承诺，而非新的治疗；而肥胖与糖尿病发病率的上升正在推高它的发病率。林奇综合征的历史具有示范意义：从1966年之后的家系研究，到1990年代错配修复基因的相继克隆，使“子宫内膜癌患者常规做免疫组化与（在若干体系中的普遍筛查）”成为标准，从而让一个家族性癌症综合征从个案报告变成可被系统检出的项目。最后不得不提被反复重复的错误：外阴癌被当作皮肤病治疗数年，年轻女性的异常出血被归因于不规则的月经，年长患者的症状被归因于年龄；这些错误不是知识的失败，而是对女性与老年人的症状报告的偏见被写进了分诊的规则。这段历史对本章的要求很具体：把症状的时限写成制度，包括检查的时限与转诊的时限与检测的时限，把她说出的话当作客观资料记录，并且永远不要用年龄代替评估。**
:::
::: summary
- 绝经后出血是症状不是诊断；内膜薄于四到五毫米可安全随访，厚或看不清则需要取样。
- 卵巢癌没有可用的筛查；识别靠新发、持续、成组的症状加一次 CA125，然后走单日的转诊路径。
- 高级别的筛查报告不是癌；妊娠期做阴道镜与定位活检，多数治疗推迟到产后复查再定。
- 接触性出血在任何筛查状态下都要检查；间期癌最常源于未参加筛查与取材不合格，而非读片错误。
- 外阴不愈合的溃疡需要活检，年龄不是不转诊的理由；基因的检测改变她本人与家属的路径。
- 在拟切除的子宫上使用粉碎器前必须评估恶性可能并写明同意，否则可能把可切除的病灶播散。
:::
