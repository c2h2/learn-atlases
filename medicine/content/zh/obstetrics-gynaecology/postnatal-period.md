产褥期是医学中最被忽视的那12周：女性们在“孩子已娩出、一切良好”中被出院，而“整段妊娠最大的三个风险——出血与血栓栓塞及精神疾病的失代偿——仍在前面或正在到达峰值”。

## 第三与第四产程

::: definition 产后出血与立即的照护 {#def-pph}
**先生理：第三产程胎盘的娩出可以被主动地管理（在胎儿娩出时或随即给子宫的收缩药——催产素10单位肌注或静脉，或在“不是高血压”时用含麦角新碱的复方；延迟脐带的结扎或脐带的检查按政策；以及带子宫的对抗的支撑受控脐带的牵引“），或被生理地管理（不给子宫的收缩药、直立位的分娩、生理的排出——而胎盘滞留的阈值略有不同）；主动的管理把出血的风险降低大约三分之二，这正是它被提供的原因；而对那位问起的低风险的女性，要诚实地讨论取舍（麦角新碱造成的恶心与血压，以及更多需要取出滞留的胎盘）。子宫的内翻（罕见灾难性的“这是什么肿块”伴与失血量不相称的休克——识别、阻止哺乳与催产素驱动的收缩把它锁住、三个名字的重位顺序、用宫缩的抑制剂松解环、以及开腹与水压的最后的手段）是全团队绝不可错过的一个诊断。产后出血——原发的（24小时之内；超过500毫升为轻、超过1000毫升为重；是被测量而不是被估计的失血：刻度的单与称重棉垫，因为“目测会把量低报一半”，而趋势比单个的数字更重要）靠那四个”T“运转：张力70%——“过度膨胀与催产素的暴露及绒毛膜的羊膜炎及急产”造成柔软的子宫：宫底的按摩与双手的压迫及子宫的收缩药的阶梯——催产素的输注、非高血压时用麦角新碱、非哮喘时用卡前列素、米索前列醇；以及尽早的氨甲环酸（那项在三小时内给药就能减少死于出血的试验）；创伤（宫颈与阴道及会阴，以及”与肛门括约肌损伤相邻的裂伤——在镇痛下或在手术室里好好地检查；三度与四度的修补是一项由有专科兴趣的资深者来做的工作，配那份抗生素与软化大便及盆底的方案）；组织（胎盘的部分——在解剖与时间允许时的手取，以及需要时开腹配压迫的缝合与子宫动脉的结扎及切除——而“因植入而做的计划的切除对绝望中的切除”就是致病的与致命的手术之间的分别）；以及血栓子宫的张力与凝血病。继发的产后出血（24小时到12周——在家把卫生巾浸透伴发热与有异味的恶露：子宫内膜炎与残留的妊娠的组织——抗生素，以及/或之后的清宫；以及带剖宫产伤口的血肿这一细微差别）完成了那份“从24小时到六周”的警惕——每一张出院的传单与给全科的信都该包含它，因为“多数因出血而重新入院都发生在回家后的头72小时”[[blood/haemostasis-bleeding]]、[[emergency-critical-care/shock-fluids]]、[[obstetrics-gynaecology/labour-birth]]。**

## 常规的照护与它的并发症

::: definition 产后的这几周：检查、并发症与产褥的三联 {#def-routine}
**常规的照护是“证据少而避免伤害多”：日程表（从第1天到第10天的社区的母亲与孩子的检查，以及在第6到8周取代旧的第6周的常规复查的对新生母亲的新的一次复查）；要紧的内容（对有高血压风险的女性测血压并记得第3到5天的峰值；伤口与恶露及乳房与膀胱及肠的问题；那个“真的用一个量表（如爱丁堡的量表）去问、而不是从外表去假定”的精神健康的筛查；以及那个界定懊悔的问题——“你现在怎么喂奶，一切顺利吗？”）。产褥的三联：子宫内膜炎与伤口的感染在危险因素之后——尤其未做预防的剖宫产及破膜的时间延长及多次的阴道的检查——的发热与子宫的压痛及有异味的恶露；按本地的处方集的广谱的联合；以及那个“没有响应”的检查——残留的组织或伤口的积脓，或那疼痛与全身的中毒的程度都超出外表坏死性的筋膜炎（这是一位外科医师、不是一通电话的情形）；静脉的血栓（与妊娠相关的高凝在产后达到峰值；按那份“绿色文件式”的指导做危险因素的加总——体质指数与制动及剖宫产及子痫前期及易栓症及既往的血栓——配上产前与产后的低分子肝素预防的决定与疗程；那条“避免反射性的计算机断层”的诊断的路径（“在产后D的二聚体毫无用处”，用下肢的超声与只做灌注的计算机断层的策略，并在怀疑髂血管时做腹盆的压迫的超声）；以及“躺在2号床突然虚脱并发绀”的大块血栓的复苏；还有“直接口服的抗凝药对华法林对低分子肝素”在哺乳上的细微差别）；以及乳房的疾病“皲裂的乳头与哺乳的疼痛”——在乳房发热并呈楔形的红肿之前就是乳腺炎；积乳的囊肿对脓肿（超声下确认并引流“; 以及那需要被命名并被转诊的炎症性的乳腺癌；还有”那条哺乳并非常识的教学“——体位与含乳及不靠止痛药硬撑）。横跨各条的原则：一位哺乳的母亲仍然需要她的药——”哺乳安全数据的库与专科的围产精神科的服务之所以存在，是为了让把一切都停掉是一个决定、而不是一种默认“；而上面每一种情况都可能表现为”累了的妈妈“——这就是为什么任何一位不适的产后女性的”生命体征都要留在评估里，直到她的血压与脉搏及体温及尿在她被打发走的那一天仍是正常并被记录的“[[paediatrics/newborn]]、[[renal/water-sodium]]、[[clinical-skills/clinical-reasoning]]。**

## 避孕、生育与心智

::: definition 产后的避孕与围产的精神的健康 {#def-after}
**避孕从第21天开始、不是从第6周的复查开始：排卵可以先于第一次的出血，而“在月经回来之前，可生育的窗口已经回来了”；而那份“长效的可逆的方法”的谈话皮下的埋植与宫内节育器产后放置的方案——埋植在剖宫产时或48小时之内或第4周之后；宫内节育器在48小时之内或4周之后放入配穿孔与脱落的咨询；注射剂的时机与哺乳的位置；以及“任何时间都可开始、只需两天预防的单纯孕激素片”的那份简单，对比“含雌激素的复方在6周或更久之前被排除”（按指导“）是基层与产科最要紧的一次被错过的预约——审计的问题是”有多少女性在产前谈过、并在出院之前把方法放好了“，而不是”有多少人回来了”。生育与妊娠间隔：有证据的建议——短的间隔少于6个月到一年会带来不良的结局的更高的风险；这与她的年龄与产科的病史及愿望一起构成那场间隔的谈话；以及流产之后与足月之后的排卵的恢复的事实它们取代了旧的“等三个周期”的传说。围产精神的健康是这一章的死亡的故事：婴儿期情绪的低落第3到10天、自限的；它配得上支持安慰这个名字、而不配被医学化；产后抑郁流行率从10%往上；隐匿的或急性的表现；“爱丁堡的量表是对话的开端、不是判决”；而第一个问题是被问过的抑郁——“你以前或在某一次的前一次的妊娠中抑郁过吗？；以及治疗的阶梯（对轻度的：同伴的支持与志愿的部门及”把伴侣包括进来实际的帮助“；心理的治疗；以及”在有哺乳安全数据的抗抑郁药——按她的病史选择，包括既往的响应、而不是家族偏好这个迷思“）。需要精神科现在就在场的疾病：已存在的双相的疾病妊娠的晚期与产后的头两周是一生中的复发的风险的峰值——与精神科医师做产前的规划（锂的继续对分娩前停用；场哺乳对用药的谈话要提前谈并有书面的计划；以及“属于治疗、不属于纵容”的保护睡眠的策略）；产褥的精神病（数日到数周之内的高昂的情绪或混乱及失眠及偏执——这是一次精神的收住，“在安全可能时让母亲与孩子留在一起”；对稳定情绪治疗的快速响应；以及那使它成为新闻的伤害孩子的头条的罕见——风险可怕地集中在未经治疗的急性的那几周）；以及分娩的创伤后的应激的障碍（产程中的对死亡的恐惧被重新经历；对预约的回避与对下一次妊娠决定的扭曲；用聚焦创伤的治疗来处理——而预防就是上一章那种复盘并相信的文化）。保密的调查不断要求的那套服务的架构：有门诊与社区团队的“专科围产精神健康的服务”，以及“在一次紧急的收住之前就被建立的那条路径”[[psychiatry/lifespan-psychiatry]]、[[psychiatry/mood-disorders]]、[[obstetrics-gynaecology/contraception-fertility]]。**

一名29岁在剖宫产后4周，想放宫内节育器、但不想要激素；她有一次既往盆腔感染的病史；而一次性产后的性行为已经发生了。

**时机、适应证与知情（[[#def-after]]）：时间——”产后4周可以放置在48小时与4周之间的窗口之外，因为更早的放置带来更高的脱落率；以及一次新的妊娠被排除既然已有一次产后的性行为——要么现在确认没有怀孕、要么等下一次“。含铜的宫内节育器——”无激素的选择、长效的、在哺乳期可用；关于经量增多与疼痛的告诫在产后贫血的背景之下；感染性盆腔炎的绝对风险低，而既往的感染并不是禁忌那次现症的感染才是；以及对有出血性疾病者含铜的更差于是激素的那一种就进入了讨论“。以及那件被搞错的事——”一次咨询不能只是关于装置，而是关于她的偏好：非意愿妊娠复发的可能；性传播感染筛查的提供；脱落与穿孔的百分数，以及知道尾丝的方法“；并把随访的预约写下来[[obstetrics-gynaecology/contraception-fertility]]、[[infectious-diseases/sexually-transmitted-infections]]。**

::: exercise 抓住那例心肌病 {level=2}
一名31岁的初产妇在产后第12周因“在夜里气短与躺平时咳嗽及踝的肿胀”就诊，被认为“只是累了、又有一个孩子”；心率106、颈静脉的搏动可见、第三心音。

## 通向何处

“制造了产褥的并发症的产时的决定”在[[obstetrics-gynaecology/labour-birth]]，高血压的那条尾巴在[[obstetrics-gynaecology/pregnancy-complications]]，避孕的细节在[[obstetrics-gynaecology/contraception-fertility]]，而精神的健康s 的实践？不——精神照护的实践在[[psychiatry/lifespan-psychiatry]]与[[psychiatry/mood-disorders]]。

::: history
**产褥的史是产褥的热的史、以及“去注意到”的政治史：那位先“一切都好”、随后“变差”的女性，在三个世纪里是一桩病区卫生的问题——塞麦尔维斯与霍姆斯在1843到1847年那“洗手的异端”；以及分娩的医院的死亡率表1%到3%的母亲死去，而从解剖室走向产房的学生们把病因带在手上。然后是“对手足与观察的制度化的那一代”：无菌与消毒、温度计被放在每一张床旁、以及“产褥的热的链球菌与其他的细菌学”。“20世纪的那一半把注意力从感染转向了出血与栓塞——三种仍杀人的原因中的另外两种”；而“在保密调查的时代被加上的那第三种是精神的健康——它成了主要的母亲的死亡的原因，这一事实”最终催生了“专科围产的服务”。而在最近的一段历史里是”被注意到的人的转换：从婴儿的存活到母亲整个的恢复——包括尿失禁与性的问题及情绪与疲劳曾被认为是不体面的抱怨[[public-health/health-systems-economics]]、[[clinical-skills/patient-safety]]。**
:::

::: summary
- 第三产程：主动的管理把出血的风险减半；测量失血、跑完那四个“T”的阶梯、尽早给氨甲环酸；并且“在休克超过了可见的失血时”认得出子宫的内翻。
- 原发的产后出血是一场“带着药物的沟通的演练”；继发的出血与子宫内膜炎属于头两周、也属于每一次的出院的谈话。
- 产褥的三联——感染与血栓及乳房的疾病——加上被忽视的甲状腺，以及那条“我这辈子最厉害的痛”的规则：脓毒症与坏死性的感染排在 C的反应蛋白的数字之前。
- 避孕是一场“第21天的、并把方法放好了的”谈话、不是一张第6周的处方；“产后长效的方法”的方案之所以存在，是因为第二次妊娠常常是非意愿的。
- 围产精神的疾病是母亲的死亡的首要的原因；直接地问；区分“侵扰性的念头与精神病的念头”；保护睡眠；并在计划上写下一个具名跟进的日期。
- “累了的妈妈”从来不是一个诊断：生命体征与鉴别及复查的日期，对产褥与对产前同样适用。
:::

“产后出血的第一通电话（[[#def-pph]]）：医嘱——”是的，这是一次重大产后出血的方案呼叫：我正在赶来，而呼叫第二位助产士与资深的产科医师及麻醉师这件事是和你一起做的、不是在我到来之后；两条大口径的套管，血液包括血型的预留与血细胞计数及凝血及纤维蛋白原；氨甲环酸1克现在静脉给；双手的压迫，同时有人在准备麦角新碱查血压与卡前列素查哮喘的剂量；让催产素的输注继续快速地跑；插导尿管并测尿；开始限量到所需容量平衡的晶体液，并把血库叫到电话上按血型或O型的阴性的单位；还有一个人在大声地把时间线写下来“。路上的决定——”下一个问题是组织与创伤：胎盘完整吗，会阴与宫颈缝合了吗——检查是与复苏一起做的、不是在其后；球囊填塞的决定在1500毫升而子宫仍无力时就做出、而不是等到3000毫升；以及转诊到有介入的放射与充足的血及能处理植入手术室的单位这一问在第二种药失败时就要问、不是在半夜[[blood/haemostasis-bleeding]]、[[emergency-critical-care/shock-fluids]]。**

::: exercise 理清产后的发热 {level=2}
::: solution
**三种发热（[[#def-routine]]）：（甲）常见的那种混合——用相容的抗生素治疗尿路的感染；而“在楔形的红肿与寒战出现之前，乳房是充盈、不是乳腺炎”，所以是“引流与哺乳的建议”；伤口保持观察；“亚硝酸盐阳性加剖宫产加发热”值得一次尿的培养，若复发还要有尿道的念头。（乙）“在头孢的预防之下的剖宫产后的子宫内膜炎”：升级到“按本地的处方集的广谱的联合”“她实际接受了什么”这一核查；并为“残留的组织与伤口的积脓——在48小时没有响应的问题”做影像——不应答者得到超声与资深的复查，不是由电子邮件加上的第二种药。（丙）上面被描述的那场外部的急症：复苏、同时升级到两位资深的医师、并进手术室“把伤口打开并查看”——因为“坏死性感染的死亡率就是在清创之前经过的小时数；而血压低加心跳快在决策上超过一切血液的检查”。这三个病例就是那三种错误：“治错了发热、把对的发热治得太窄、以及只用抗生素去治那致命的发热”[[infectious-diseases/healthcare-infections]]、[[renal/urinary-tract]]。**

::: exercise 在产前给那位双相的母亲建议 {level=2}
