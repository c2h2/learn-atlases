分娩后的数小时和数周，是大多数孕产妇死亡发生的时期。第一天的危险是出血；随后几周是血栓形成、感染、高血压、心力衰竭，而到第一年末则是自杀。这些疾病大多始于一些很容易被归因于照顾新生儿的寻常疲惫的症状：疲劳、气促、头痛、情绪低落、腿痛。良好的产后保健依赖于知道哪些症状是预期之中的，哪些是警示信号。

**产后期**或**产褥期**按惯例是指分娩后六周，在此期间生殖器官恢复到非孕状态。英国的孕产妇死亡报告还统计妊娠结束后一年内的**晚期死亡**，因为一些最重要的死因，包括自杀，发生在六周之后。

本章介绍正常恢复、产后出血、感染、血栓栓塞、围产期精神健康、母乳喂养和产后避孕。第三产程见[[obstetrics-gynaecology/labour-birth]]，产后高血压见[[obstetrics-gynaecology/pregnancy-complications]]。

## 正常恢复

**子宫复旧。** 分娩后立即可在约平脐水平触及收缩的子宫。随着肌细胞体积缩小，子宫迅速缩小，约10–14天时在耻骨联合上方已不能触及。子宫大于预期、质软或有压痛，提示有组织残留或感染。

**恶露。** 产后的阴道排出物最初几天为红色，然后变为褐色，再变为淡色，通常在约四到六周时停止。大量鲜红色出血、排出大血块或有臭味都不正常。

**生理。** 血容量和心输出量在数周内恢复到接近非孕水平。凝血系统在约六周内仍处于易栓状态，产后最初几周的VTE风险高于妊娠期的任何时候。糖耐量通常在数天内恢复正常，这就是为什么妊娠期糖尿病的胰岛素在分娩时即停用。

**常规保健。** NICE NG194（《产后保健》，2021年）建议每位妇女都有个体化的保健计划，最初几天由助产士上门或在门诊接触，每次接触时检查其身心健康，并在产后六到八周由全科医生复查。每次接触都应询问妇女的情绪，并告知她需要紧急求助的症状：大量出血、发热、胸痛或气促、单腿疼痛肿胀、剧烈头痛，以及自伤的念头。

## 产后出血

::: definition 产后出血 {#def-pph}
**原发性产后出血（PPH）**是指分娩后24小时内生殖道失血500 mL或以上。RCOG指南（2016年）将其分为**轻度**（500–1000 mL）和**重度**（超过1000 mL），重度产后出血又分为中度（1001–2000 mL）和严重（超过2000 mL）。

**继发性产后出血**是指分娩后24小时至12周之间生殖道异常或过多的出血。

2025年WHO、FIGO和ICM指南建议更早开始治疗：当测得的失血量达到300 mL并伴有任何异常体征（脉搏超过100次/分、休克指数超过1或血压低），或无论有无体征失血量达到500 mL时，即诊断为产后出血。
:::

转向更早诊断反映了两项观察。目测估计失血量不准确，而且通常偏低，因此应通过称量纱布或使用带刻度的集血单来测量失血量。而且，一位血容量大的年轻健康妇女在脉搏和血压出现变化之前可以失去大量血液；当她出现低血压时，可能已经失去了三分之一的循环血容量。

### 原因：四个T

::: theorem 产后出血的四个T {#thm-four-ts}
胎盘附着部位的止血主要依靠**子宫肌层的收缩**，它使原先供应胎盘的螺旋动脉扭结受压，其次依靠凝血。因此产后出血有四组原因：
- **张力（Tone）**：子宫收缩乏力，最常见的原因（约占70%）。
- **创伤（Trauma）**：会阴、阴道或宫颈裂伤，子宫破裂，或剖宫产切口延裂。
- **组织（Tissue）**：胎盘、胎盘碎片或胎膜残留，妨碍有效收缩；还包括胎盘植入谱系疾病。
- **凝血酶（Thrombin）**：凝血功能障碍，可为原有的（如血管性血友病），也可为获得性的（胎盘早剥、羊水栓塞、脓毒症、子痫前期、大量输血的稀释）。
:::

::: proof
足月时每分钟约有500–700 mL血液流经胎盘床。胎盘剥离时，开放的螺旋动脉可在数分钟内使母亲失血而死。这些动脉的管壁在妊娠早期已被重塑为宽阔、无肌层的通道（[[obstetrics-gynaecology/pregnancy-complications#thm-two-stage]]），因此它们自身不能有效收缩。取而代之的是，子宫肌层交织的肌纤维起着"活结扎线"的作用，在子宫收缩时勒紧血管。任何妨碍收缩的因素（漫长产程或缩宫素输注后疲劳的肌肉、双胎或羊水过多导致的子宫过度膨胀、组织残留，或膀胱充盈）都会导致完整胎盘床的出血。创伤即使在子宫收缩良好时也会出血。凝血功能障碍妨碍血凝块封闭血管，它既是大出血的原因，也是大出血的结果，因为出血会消耗凝血因子，尤其是纤维蛋白原。这就是为什么子宫收缩良好而出血持续时指向创伤或凝血功能障碍，也是为什么总是首先检查子宫。
:::

危险因素包括既往产后出血、前置胎盘或胎盘植入、多胎妊娠、巨大儿、羊水过多、产程延长或引产、手术分娩、子痫前期、贫血和肥胖。许多产后出血发生在没有危险因素的妇女身上，因此每个单位都必须随时准备好处理。

### 处理

预防从第三产程开始：使用缩宫素积极处理第三产程使风险大约减半（[[obstetrics-gynaecology/labour-birth]]）。治疗产前贫血意味着妇女有更多的储备。

发生产后出血时，多项措施同时进行：

1. **呼叫支援**并清楚说明问题。重度产后出血时，上级助产士、产科医生、麻醉医生以及血液科和血库都要参与，必要时启动大出血方案。
2. **复苏**：气道、呼吸和高流量吸氧；两条大口径静脉通路；抽血查全血细胞计数、包括纤维蛋白原在内的凝血功能、交叉配血以及带乳酸的血气；输注加温液体，一旦需要立即输血和血液制品。保持妇女体温，监测脉搏、血压、血氧饱和度和尿量。
3. **测量**失血量并持续累计总量。
4. **找到原因以止血**：
   - **张力**：按摩宫底以促进收缩，排空膀胱，并依次给予宫缩剂：缩宫素（推注和输注）、麦角新碱（ergometrine，高血压时避免使用，因为它引起血管收缩）、卡前列素（carboprost，一种肌注的前列腺素F2α类似物，哮喘时避免使用，因为它引起支气管痉挛）和米索前列醇。**双手压迫**子宫是一种临时措施。
   - **创伤**：在良好的照明和镇痛下检查生殖道，修补裂伤。
   - **组织**：检查胎盘是否完整；在手术室徒手取出残留组织。
   - **凝血酶**：在实验室或床旁检测指导下纠正凝血功能障碍，在持续出血时使纤维蛋白原保持在约2 g/L以上。
5. **氨甲环酸（tranexamic acid）**：WOMAN试验（2017年）纳入20,060名产后出血妇女，表明静脉注射1 g可降低出血导致的死亡，获益见于产后3小时内给药。它现在已是标准治疗的一部分。
6. 如果出血持续，采取**手术和放射介入措施**：宫腔球囊压迫、子宫压迫缝合（如B-Lynch缝合）、子宫动脉或髂内动脉结扎、介入放射栓塞，以及在其他方法都失败时切除子宫。切除子宫的决定应由上级产科医生在妇女濒危之前作出。

**E-MOTIVE**试验（2023年）是一项在肯尼亚、尼日利亚、南非和坦桑尼亚约210,000例阴道分娩中进行的整群随机试验，将带刻度集血单的早期发现与一次性而非逐步给予的治疗组合方案相结合：子宫按摩、宫缩药物、氨甲环酸、静脉补液、检查和升级处理。严重出血、剖腹手术或出血导致的死亡下降了约60%。2025年WHO指南推荐这种组合方案。

::: example 漫长产程后的出血 {#ex-pph}
一位29岁妇女在使用缩宫素加速的14小时产程后经阴道分娩。胎盘娩出十分钟后，助产士注意到持续出血；测得失血量900 mL。子宫质软，位于脐上。脉搏112次/分，血压108/70 mmHg。发生了什么？应如何处理？
::: solution
**评估。** 900 mL的失血按任何定义都是产后出血，她的心动过速说明她正在代偿。在使用缩宫素加速的漫长产程后，子宫软而大，提示**宫缩乏力**。

**同时进行的措施：**
1. 呼叫支援：上级助产士、产科医生和麻醉医生。
2. 复苏：吸氧，两条大口径静脉通路，全血细胞计数、凝血功能和纤维蛋白原、交叉配血；开始输注加温液体并申请血液。
3. 处理宫缩乏力：按摩宫底促进收缩，导尿排空膀胱，按方案给予缩宫素，如无高血压随后给予麦角新碱，如无哮喘给予卡前列素，以及米索前列醇。
4. 由于仍在产后3小时内，按当地方案静脉注射氨甲环酸1 g。
5. 子宫收缩后检查胎盘是否完整，并检查生殖道有无创伤。
6. 继续测量失血量。如果这些措施后出血仍持续，送往手术室在麻醉下检查，必要时行球囊压迫或手术措施。

紧急情况过后，她在高依赖病房密切监测，复查血红蛋白和凝血功能，考虑VTE预防（出血和输血增加VTE风险），并向她解释所发生的事情。
:::
:::

::: example 休克指数 {#ex-shock-index}
一位刚分娩的妇女心率每分钟120次，收缩压90 mmHg。计算她的休克指数并加以解读。
::: solution
**休克指数**是心率除以收缩压：$120 / 90 \approx 1.33$。健康妇女产后通常约为0.7–0.9。高于1（WHO 2025定义所用的阈值）提示明显失血，即使可见失血看起来很少；如此高的值提示她可能已失去很大比例的血容量。她需要立即评估出血情况，包括隐性出血。
:::
:::

## 感染

**产褥期脓毒症**仍是孕产妇死亡的重要原因。最常见的部位是子宫（**子宫内膜炎**）、泌尿道、剖宫产切口、乳房和胸部。侵袭性**A族链球菌**（化脓性链球菌，*Streptococcus pyogenes*）是与病情迅速恶化和死亡关系最密切的病原体；它可从家庭接触者处获得，例如咽痛的孩子。

子宫内膜炎表现为发热、下腹痛、子宫压痛以及恶露有臭味或量多。危险因素包括剖宫产、胎膜破裂时间长、徒手剥离胎盘和组织残留。按当地指南使用广谱抗生素治疗，可能需要超声检查寻找残留物。

产后妇女出现脓毒症的征象，如发热或体温过低、心动过速、呼吸急促、低血压、意识模糊、尿量减少或乳酸升高，需要立即升级处理、做血培养并在一小时内静脉使用抗生素，如[[infectious-diseases/fever-sepsis]]所述。**孕产妇早期预警评分**是一种按妊娠特异范围对生理观察指标评分的图表，有助于医护人员识别病情恶化。与体征不相称的剧烈疼痛、腹泻呕吐或皮疹可能是侵袭性A族链球菌感染的最早征象。

::: warning 不要为产后心动过速找借口
产后妇女持续的心动过速应当得到解释。"她焦虑"、"她疼"和"她刚生完孩子"都是排除性诊断。心动过速常常是出血、脓毒症、肺栓塞或心脏疾病最早的征象，而在英国的孕产妇死亡审查中，虚脱前数小时记录到的不明原因心动过速是一个反复出现的发现。
:::

## 静脉血栓栓塞

根据2025年发表的MBRRACE-UK报告，血栓形成和血栓栓塞是2021–23年英国孕产妇死亡的首要直接原因。风险在产后最初几周最高，尤其是剖宫产后。

预防依赖于在建档时、任何一次入院时和分娩后进行**风险评估**，遵循RCOG绿顶指南37a。产后，有危险因素的妇女给予LMWH **10天**，高风险者（例如既往VTE或多项危险因素）给予**6周**。早期活动和充足的水分对每个人都很重要。LMWH和华法林都与母乳喂养相容。

**诊断。** 深静脉血栓形成典型表现为腿部疼痛肿胀，常为左腿，因为左髂总静脉被右髂总动脉跨越。肺栓塞可引起气促、胸膜炎性胸痛、咯血、心动过速或虚脱。D-二聚体在妊娠期或产后不久没有用处，因为它会正常升高。疑似DVT用加压双功能超声检查；疑似肺栓塞先拍胸片，再做CT肺动脉造影或通气-灌注扫描。除非有禁忌，应在等待影像检查期间开始治疗剂量的LMWH。

**围产期心肌病**是一种左心室射血分数降低（通常低于45%）的心力衰竭，发生于妊娠末期或产后数月内，且没有其他可识别的病因。气促、端坐呼吸、踝部水肿和疲劳很容易被误认为是正常的产后症状。通过超声心动图诊断，按心力衰竭治疗，药物的选择要考虑与母乳喂养的相容性，射血分数很低时需要抗凝。见[[cardiovascular/heart-failure]]。

::: example 产后三周的气促 {#ex-breathless}
一位31岁妇女急诊剖宫产后三周，告诉健康随访员她走到商店就气促，夜间不能平卧。她有心悸。吸空气时血氧饱和度95%，脉搏110次/分，血压104/66 mmHg，双肺底有湿啰音。主要的可能是什么？应如何检查？
::: solution
**主要可能。** 端坐呼吸和双肺湿啰音提示**心力衰竭**，在产后三周必须首先考虑**围产期心肌病**。**肺栓塞**是另一个关键诊断，因为她正处于剖宫产后风险最高的时期。其他可能包括肺炎、出血后贫血，以及罕见的因妊娠而暴露的原有心脏病。不经检查不能把她的症状归因于焦虑或疲劳。

**检查。** 当天到医院评估：心电图、胸片、全血细胞计数、肾功能、肌钙蛋白和利钠肽（BNP或NT-proBNP），以及**超声心动图**。如有任何肺栓塞的怀疑，除非有禁忌应开始治疗剂量的LMWH，并安排CT肺动脉造影。如果确诊围产期心肌病，她需要心内科诊治、与母乳喂养相容的心力衰竭治疗，并就今后妊娠复发风险很高接受咨询。
:::
:::

## 围产期精神健康

精神疾病在妊娠期和产后很常见，而在英国，自杀是产后六周至一年间孕产妇死亡的首要原因。这些疾病从轻微且自限，到危及生命不等。

::: definition 产后的精神健康问题 {#def-mental}
- **产后情绪低落（baby blues）**：在产后约第3–5天开始的流泪、易激惹和情绪不稳，约一半的妇女会出现。它在约两周内无需治疗即可缓解。症状持续超过两周提示抑郁。
- **产后抑郁**：产后第一年内的抑郁发作，影响约10%–15%的妇女。症状与抑郁症相同，常伴有因不能应付或不爱孩子而产生的内疚，以及对婴儿健康的焦虑。焦虑障碍、强迫症以及创伤性分娩后的创伤后应激障碍也很常见。
- **产后（产褥期）精神病**：一种急性精神病性疾病，通常在产后头两周内开始，影响约1–2/1000的妇女。典型特征是快速变化的情绪（躁狂、抑郁或混合状态）、意识模糊、妄想和幻觉，常涉及婴儿。这是一种**精神科急症**。
:::

产后精神病最强的危险因素是**双相障碍**，或既往有产后精神病发作：约五分之一的双相障碍妇女会在产后严重复发。有严重精神疾病病史的妇女应在孕前或妊娠早期与围产期精神卫生团队共同制定计划，涵盖用药、睡眠和早期预警征象。

**识别。** NICE建议在每次产前和产后接触时询问情绪，例如使用两个**Whooley问题**："在过去一个月里，你是否经常因感到情绪低落、抑郁或绝望而烦恼？"以及"在过去一个月里，你是否经常因做事情缺乏兴趣或乐趣而烦恼？"。**爱丁堡产后抑郁量表（EPDS）**是一份广泛用于进一步评估症状的十项问卷。需要紧急专科评估的危险信号包括：近期精神状态的显著变化、新出现的暴力自伤念头或行为，以及新出现并持续表达自己作为母亲无能或与婴儿疏离。

**处理。** 轻至中度抑郁用心理治疗，中至重度加用抗抑郁药；许多抗抑郁药，包括舍曲林（sertraline），可在哺乳期使用。产后精神病需要紧急入院，最好入住**母婴病房**，使母亲和婴儿能够待在一起。

如果你受到本节所述问题的影响，可以向你的全科医生、助产士或健康随访员寻求支持，也可以拨打NHS 111，在英国还可以联系撒玛利亚会（Samaritans，116 123）。

::: example 精神状态的快速变化 {#ex-psychosis}
一位28岁有双相障碍病史的妇女在妊娠早期停用了锂盐（lithium），八天前分娩。她的伴侣说，两天来她几乎不睡觉，说话很快，认为婴儿在医院被调换了，有时显得意识模糊。诊断是什么？即时处理是什么？
::: solution
**诊断。** 一位停用心境稳定剂的双相障碍妇女在产后头两周内迅速出现躁狂症状、关于婴儿的妄想和意识模糊，在证明并非如此之前应视为**产后精神病**。

**即时处理。** 这是精神科急症：由危机干预团队或围产期精神卫生团队当天评估，进行体格检查和血液检查以排除感染、甲状腺疾病或引起谵妄的产后并发症等器质性原因，并评估对她本人和婴儿的风险。需要入院，通常入住母婴病房。治疗使用抗精神病药和心境稳定剂，选药时要注意母乳喂养，她的伴侣和家人也需要支持和信息。经过治疗，大多数妇女完全康复，但今后分娩后复发的风险很高，因此为任何未来的妊娠制定计划至关重要。
:::
:::

## 母乳喂养

母乳喂养为婴儿提供理想的营养和抗感染保护，并降低母亲患乳腺癌和卵巢癌的风险。WHO建议纯母乳喂养六个月。

**生理。** 胎盘娩出后，孕酮下降使**催乳素**得以启动全面的泌乳，通常在产后二至四天。吸吮刺激腺垂体释放催乳素以维持泌乳，并刺激神经垂体释放**缩宫素**，使腺泡周围的肌上皮细胞收缩，引起**喷乳反射**。缩宫素还使子宫收缩，这就是为什么最初几天哺乳时会引起腹部绞痛。乳汁的供应取决于频繁而有效地排空乳汁。

**问题。** 乳头疼痛或皲裂通常反映含接不良，熟练的助产士或喂养专家可以纠正。**乳腺炎**是乳房的炎症，常由乳汁淤积引起，表现为疼痛、发红、发热的区域和发热；继续用患侧乳房哺乳或吸出乳汁有帮助，如果症状持续或感染可能性大则给予抗生素。**乳腺脓肿**表现为有波动感的压痛肿块，需要引流。

**药物与母乳喂养。** 大多数药物以少量进入乳汁，与母乳喂养相容。少数药物不相容或需谨慎，因此开药者要查阅专业资料，如英国哺乳期用药咨询服务（UK Drugs in Lactation Advisory Service）。

## 产后避孕

不哺乳的妇女最早可在产后约**第21天**恢复排卵，因此从三周起就需要避孕。母乳喂养会推迟排卵：如果婴儿不满六个月、妇女完全或几乎完全母乳喂养且产后没有月经，**哺乳期闭经避孕法**的有效率超过98%。

可选择的方法包括：
- **单纯孕激素方法**（皮下埋植剂、单纯孕激素避孕药、注射剂）可在产后任何时候开始，包括哺乳期。
- **宫内节育器或宫内节育系统**可在产后48小时内放置，或在产后四周起放置。
- **复方激素避孕**因VTE风险在最初几周避免使用：产后头三周不使用，哺乳者头六周不使用。

两次妊娠间隔过短与早产和其他不良结局相关，因此要在出院前讨论避孕。各种方法见[[obstetrics-gynaecology/contraception-fertility]]。

::: quiz
一位妇女产后4天就诊。她每天哭好几次，感到不知所措，但婴儿睡时她也能睡，照顾婴儿很好，没有伤害自己或婴儿的念头。最可能的解释是什么？
- [x] 产后情绪低落，通常在两周内缓解；应给予支持并复查她的情绪。
- [ ] 产后精神病，需要紧急入院。
- [ ] 产后抑郁，需要立即使用抗抑郁药。
- [ ] 正常行为，无需随访。
::: solution
在产后第3–5天左右开始的流泪和情绪不稳是产后情绪低落的典型表现，约一半的妇女会出现，约两周时缓解。应安慰和支持她，并复查她的情绪：如果症状持续超过两周或加重，应考虑产后抑郁。没有精神病性特征。
:::
:::

::: history
1795年，阿伯丁的亚历山大·戈登（Alexander Gordon）提出，产褥热是由照料产妇的医生和助产士从一位妇女带给另一位妇女的。1843年，奥利弗·温德尔·霍姆斯（Oliver Wendell Holmes）在波士顿提出了同样的观点；1847年，维也纳的伊格纳茨·塞麦尔维斯（Ignaz Semmelweis）表明，要求检查者用含氯石灰溶液洗手后，他病房里的产褥热死亡人数急剧下降。1879年，路易·巴斯德（Louis Pasteur）证明了其病原体是链球菌。直到1930年代磺胺类药物问世后，产褥期脓毒症的死亡率才大幅下降。1829年，詹姆斯·布伦德尔（James Blundell）报告为一位产后出血的妇女成功输入人血。英格兰和威尔士的孕产妇死亡保密调查始于1952年，并一直延续至今（现为MBRRACE-UK），是医学中持续时间最长的审查之一。其发现多次促成了实践的改变，包括常规血栓预防、早期预警评分和专门的围产期精神卫生服务。
:::

::: summary
- 产褥期是分娩后六周；孕产妇死亡审查统计一年内的晚期死亡，而自杀是其首要原因。
- 原发性产后出血是24小时内失血500 mL或以上；轻度为500–1000 mL，重度超过1000 mL。WHO 2025建议在失血300 mL伴生命体征异常时即诊断产后出血。
- 原因是四个T：张力（约70%）、创伤、组织和凝血酶。子宫收缩良好而出血持续提示创伤或凝血功能障碍。
- 处理同时进行：呼叫支援、复苏、测量、针对病因治疗（宫缩剂、修补、清除组织、纠正凝血功能障碍）、3小时内给予氨甲环酸，必要时采取手术措施。
- 产后不明原因的心动过速必须查明原因；休克指数超过1为异常。
- 血栓栓塞是英国孕产妇死亡的首要直接原因；根据风险给予产后LMWH 10天或6周。D-二聚体没有用处。
- 产后情绪低落常见而短暂；产后抑郁影响10%–15%；产后精神病是急症，双相障碍是其最强的危险因素。
- 排卵最早可在第21天恢复；复方激素避孕在3周内（哺乳者6周内）避免使用。
:::

## 习题

::: exercise 休克指数 {level=1 check="0.75"}
一位产后妇女心率每分钟84次，收缩压112 mmHg。计算她的休克指数。
::: solution
休克指数$= 84/112 = 0.75$。这在产后通常范围内（约0.7–0.9），但单次数值不能排除出血；随时间的趋势和测得的失血量更重要。
:::
:::

::: exercise 出血的分类 {level=1}
按RCOG定义对以下情况分类：(a) 阴道分娩后第一小时内失血650 mL；(b) 剖宫产术中失血2400 mL；(c) 产后10天大量出血伴血块。
::: solution
(a) 原发性产后出血，**轻度**（500–1000 mL）。(b) 原发性产后出血，**重度**，严重（超过2000 mL）。(c) **继发性产后出血**（分娩后24小时至12周之间）；最常见的原因是组织残留和子宫内膜炎。
:::
:::

::: exercise 宫缩剂的禁忌 {level=1}
子痫前期妇女应避免使用哪种宫缩剂？哮喘妇女应避免使用哪种？解释原因。
::: solution
高血压（包括子痫前期）时避免使用**麦角新碱**，因为它引起血管收缩，可导致血压危险地升高。哮喘时避免使用**卡前列素**（一种前列腺素F2α类似物），因为它可引起支气管痉挛。缩宫素和米索前列醇两种情况下都可使用。
:::
:::

::: exercise 血容量的百分比 {level=2 check="round(100*1500/(55*100))"}
假设足月血容量为每千克100 mL。一位55 kg的妇女失血1500 mL。这占她循环血容量的百分之几？答案取最接近的整数百分比。
::: solution
她的血容量为$55 \times 100 = 5500$ mL。失血量为$1500/5500 \approx 0.273$，即约**27%**。这已接近出现低血压的水平；对体型较小的妇女，同样的绝对失血量更加危险。
:::
:::

::: exercise 剖宫产后发热 {level=2}
一位妇女因产程延长行急诊剖宫产，术后第三天发热38.6 °C。列出可能的感染来源，以及你要做的检查。
::: solution
**来源**：子宫内膜炎（产程延长后行剖宫产时最有可能）、切口感染、尿路感染（导尿后）、胸部感染（麻醉后）、乳腺炎、血肿感染，以及VTE（可引起发热）。如果她病情较重，必须考虑侵袭性A族链球菌感染。

**体格检查**：包括早期预警评分在内的全套观察指标；胸部；乳房；腹部和切口；子宫大小和压痛；恶露；小腿。

**辅助检查**：血培养、全血细胞计数、C反应蛋白、乳酸、肾功能；尿培养；切口和阴道高位拭子；必要时痰标本；如有指征，超声检查组织残留或积液。如果她符合脓毒症标准，应在一小时内按当地指南开始静脉抗生素。
:::
:::

::: exercise 为双相障碍妇女制定计划 {level=2}
一位双相障碍妇女用药后病情稳定，现孕16周。她的围产期精神健康计划应包括什么？
::: solution
转诊至专科围产期精神卫生团队；审查她的用药，权衡每种药物在妊娠期和哺乳期的风险与停药后复发的高风险（避免使用丙戊酸盐）；一份与妇女本人、她的伴侣、助产士、产科医生、全科医生和健康随访员共享的书面计划，涵盖早期预警征象、联系谁以及病情变化时怎么做；产后保护睡眠的措施；延长产后住院时间或早期复查；并安排在产后精神病风险最高的头几周进行密切监测。应记录她本人对喂养和用药的意愿。
:::
:::

::: exercise 大出血 {level=3}
一位前置胎盘妇女在剖宫产术中失血3000 mL。子宫收缩良好，但胎盘床持续出血。结果：血红蛋白68 g/L，血小板72 × 10⁹/L，纤维蛋白原1.2 g/L，凝血酶原时间延长。解读结果并描述处理。
::: solution
**解读。** 子宫收缩良好，所以出血来自子宫下段的胎盘床（其收缩不良，尤其是在前置胎盘或胎盘植入时）以及**凝血功能障碍**：纤维蛋白原1.2 g/L、血小板减少和凝血酶原时间延长反映了消耗和稀释。纤维蛋白原低是进展为严重产后出血的有力预测因素。

**处理。** 启动大出血方案。在实验室或床旁检测以及血液科建议的指导下，输注红细胞，给予纤维蛋白原浓缩物或冷沉淀使纤维蛋白原升至约2 g/L以上，输注血小板和新鲜冰冻血浆。如尚未给予，给予氨甲环酸。保持体温，纠正血钙和酸中毒。手术方面，对胎盘床采取措施（缝合、球囊压迫），然后考虑子宫动脉结扎、在条件具备且病情稳定时行介入放射治疗，如出血持续则切除子宫。上级产科医生、麻醉医生和血液科医生都应参与。之后她需要重症监护、出血控制后的VTE预防，以及事后解释。
:::
:::

::: exercise 解读一份症状清单 {level=3}
一位妇女在产后十天给产科分诊热线打电话。以下哪些情况需要当天评估？为什么？(a) 恶露从红色变为褐色；(b) 与她平时头痛不同的剧烈头痛；(c) 左小腿疼痛肿胀；(d) 感到疲劳；(e) 一侧乳房有一处红肿疼痛区域，体温38.5 °C；(f) 认为她的婴儿没有她会更好的想法。
::: solution
**当天**：(b) 新出现的剧烈头痛可能提示产后子痫前期、脑静脉窦血栓形成或颅内出血；(c) 疑似DVT需要评估，很可能需要影像检查和抗凝；(e) 伴发热的乳腺炎需要评估有无脓毒症，可能需要抗生素；(f) 认为婴儿没有她会更好，提示严重抑郁并可能有自杀念头，需要紧急的精神卫生评估，并以同情心对待。

**本身不紧急**：(a) 恶露从红色变为褐色是正常的；(d) 疲劳是预料之中的，但如果严重或伴有气促、心悸或情绪低落，应进一步了解。
:::
