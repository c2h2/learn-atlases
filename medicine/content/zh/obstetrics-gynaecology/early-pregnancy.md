早孕是产科的急诊门诊：流产与宫外孕与妊娠的剧吐与“例被威胁的妊娠的出血”，以及那位“还不想要却已到来、并且附带着一个决定”的妊娠。

## 诊断早孕

::: definition “妊娠部位未知”与宫外孕的问题 {#def-diagnosis}
**工具与它们的限度：经阴道的超声在看到卵黄囊或胎儿的极时确立宫内的妊娠；“那个判定的hCG的区域历史上是在一个外观正常的子宫中看到妊娠囊的1000到2000国际单位每升”是一条群体的规则，各个单位在第4到5周“围绕它做自己的校准”；而在边缘情形，“单次的扫描既不能证明妊娠在失败、也不能证明它正常”。48小时系列的人绒毛膜促性腺激素的趋势（早期正常的上升依起始的水平而定为48小时至少35%到53%，而下降至少21%到35%有利于流产或消退）是概率的语言、不是证明；而“正常的与失败的及宫外孕的曲线的交叉”，正是“妊娠部位未知”的方案存在的原因：“hCG在决策的阈值之下而宫内未见”——48小时复查hCG并按轨迹行动；有疼痛或血流动力学的威胁、或hCG在超过阈值后仍在上升而宫内无妊娠——宫外孕的路径就启动。附件的肿块伴空虚的子宫就是宫外孕，直到被反证；而线样的内膜的积液的假妊娠囊是那个经典的误读。宫外孕：“输卵管壶腹部的多数”加上危险的少数——“间质部的处在宫角、会灾难性地晚出血的、剖宫产瘢痕的胎盘植入的前身、宫颈的、卵巢的、腹腔的；以及在助孕之后的宫内的合并宫外孕的那一对（宫内有妊娠并不能排除第二个宫外孕）”。危险因素既往的宫外孕与输卵管及盆腔的手术及盆腔的炎症及衣原体及吸烟及内异症；带着宫内节育器在位时的妊娠不成比例地是宫外孕；以及那句诚实的话：一半的宫外孕发生在未被识别出危险因素的女性身上。绝不可令人安心的表现——“她看起来很安好，而输卵管已经破了”这一模式：肩尖的疼痛与昏厥及直肠的疼痛“，以及”被掩盖的腹部的体征“。处理——”手术腹腔镜输卵管的切除是标准；输卵管的切开被对侧的输卵管已损坏而渴望未来的生育并有随访的能力者选用；药物叶酸的拮抗剂（单剂的方案配第4天与第7天的规则及抗叶酸的咨询——不喝酒、不吃叶酸、晒伤与口腔的炎症警示的征象，以及那间把“流产的疼痛与破裂”区分开随叫随到疼痛的复查）；以及在被选定的低hCG的正在消退病例中期待的路径“。”Rh 阴性者按本地的剂量规则给抗 D 的免疫球蛋白“；以及那条”在被证明别的之前都是破裂的宫外孕“的分诊的规则：”任何有疼痛与出血及血流动力学异常的早孕，当天都要有血型预留与资深的复查及一次扫描“[[obstetrics-gynaecology/contraception-fertility]]、[[clinical-skills/medical-imaging]]、[[blood/haemostasis-bleeding]]。**
:::

## 流产

::: definition 早期与较晚的妊娠的丢失 {#def-miscarriage}
**定义与诊断：流产是“在24周之前的妊娠的丢失那条法律与临床的线因国家而异”；12周的那道悬崖把多数分开——大约10%到15%的被识别的妊娠以丢失告终，而在被识别之前结束的远多于此；而那句令人安心的推论是“在8周看到胎心的、检查正常低风险的女性，其后的丢失率只有百分之几”。术语是带着处理的：先兆的（出血、宫颈口闭合、妊娠仍可存活）、不可避免的（口开而妊娠的组织在口处）、不完整的部分的排出伴出血的风险、完整的、以及稽留的或安静的（滞留的死胎；按“被定义的头臀长与平均妊娠囊直径的阈值”的没有胎心来诊断——诊断的标准必须被严格地满足，因为误诊是这个专科最要紧的错误；而“当测量处在边界时7到14天后再扫描”这条规则正是为此而存在）。按情形的处理，而证据是明确的：在临床稳定且被选择时，期待的处理是不完全与稽留流产的一线（稽留在较早孕周的完成率约60%到80%）；米索前列醇辅助药物的路径阴道或颊黏膜配重复的剂量提高完成；而”手术的清宫（手动真空的吸引或在局部或全身麻醉下的吸引刮宫）的适应证是血流动力学的不稳定与感染及药物或期待的处理失败、或女性在咨询后明确的偏好“。而”把这项工作从全身麻醉的手术室移到门诊局部麻醉实践早孕吸引的单位，是重大的去实施的成功之一更少的手术的时间、相同或更好的结局、以及病人对在清醒时被做完的强烈的偏好“——见下一段。复发性流产三次；而”两次就开始检查“如今被广泛接受：检查包括抗心脂质的抗体（那个可被治疗的——”低剂量的阿司匹林加低分子肝素改善活产的证据，使抗心脂质的检测成为一种责任而不是一种仪式“）、为识别结构重新排列父母双方的核型、甲状腺与泌乳素及糖尿病的控制在最优化、宫腔的评估（”间带隔膜切除争论的宫腔镜或浅层的盐水灌注的超声造影）；以及那诚实的剩余——超过一半没有被识别的病因；而“经验性的在早孕期用孕激素治疗有出血且既往流产者试验的证据微粒化的孕激素400毫克每日两次被纳入指导”如今与“早期让人安心复查扫描的服务”并列——后者本身就是一项“值得被测量的干预”[[obstetrics-gynaecology/pregnancy-antenatal]]、[[endocrine/reproductive-endocrinology]]。**
:::

## 剧吐、葡萄胎与“那个被期待的决定”

::: definition 妊娠的剧吐与妊娠的滋养细胞的疾病及终止妊娠的照护 {#def-hyperemesis}
**妊娠的剧吐是“伴体重的下降与酮尿及脱水及电解质的紊乱和甲状腺的紊乱的呕吐”——它是“被用在对的女身上的排除的诊断、不是给任何早孕期的恶心贴的标签”。处理是方案化的、而且要早：在任何含葡萄糖的液体之前给硫胺（韦尼克脑病的病例报告说的都是同一句话：先输了含糖的液体）；一层一层止吐的阶梯抗组胺的与丙氯拉嗪及甲氧氯普胺及多潘立酮类的选项；昂丹司琼优势的转移，带着它关于唇裂与黄疸的保留的注脚“正在沉淀为令人安心的”；以及“在10周之后按指导用皮质激素的救援”（因为较早时的口腔的裂隙的信号）；“让女性不必待在隔离病房、也不因社会的精疲力竭而走向终止妊娠”的日间的单位与居家的输液的路径；以及那句“这是一种医学的情况、不是晨吐”的权利——“而被误标成精神病正是一次妊娠如何被意外地结束的”。加上“反流与幽门螺杆菌”的“不必常规去想的”念头；以及制动与脱水带来血栓的风险（在剧吐中小腿的疼痛是一次扫描、不是一次耸肩）；以及难治者的收住，“带着对纠正低钠速度的尊重与中心的静脉的导管的谨慎”。妊娠滋养细胞的疾病：完全的葡萄胎（“雪暴样的影像与囊肿样的黄素化的囊肿及hCG远高于孕周的图景；子宫大于孕周；以及在20周之前的子痫前期——是那个被点名的线索“）与部分的（常常只在”一次稽留流产的清宫之后的组织学“才被诊断）；处理靠”吸引的清宫（绝不对葡萄胎的子宫做锐利的刮匙的刮除——避免出血与穿孔及滋养细胞栓塞的逻辑；由资深的妇科医师并在有需要时配血的准备）；以及那份随访：hCG的监测至正常、“并避孕（通常一年，或按方案）”、因为在监测期间的妊娠会让一切变得混乱。终止妊娠的照护：”一个由药物的或手术的与由她的偏好及孕周及共病所塑造的路径；在手术之前的关于出血与危险的征象的信息，以及那间由会接听的人值守的安全网的热线；手术的那条路径的真空的吸引，带着同样的对知情的选择的尊重与按孕周与偏好的麻醉的决定“；同日的避孕（埋植与宫内节育器）与”排卵在两到三周就恢复“的咨询；”按孕周与本地的指导用的Rh 的免疫球蛋白“；一次感染筛查的机会；以及咨询的现实：”情感的结局最能被两件事预测——决定是不是她做的，以及她是否被尊重地对待；这就是为什么虐待与胁迫及这次妊娠是否被强加于你“问题属于保护、不属于评判”。这三者——剧吐与葡萄胎及终止——每一种都是“女性对自己身体与意图的叙述本身就是首要的临床数据”的疾病；这一章的技能是在扫描之前先听她说[[obstetrics-gynaecology/pregnancy-antenatal]]、[[obstetrics-gynaecology/gynaecological-cancer]]、[[paediatrics/safeguarding]]。**
:::

::: example 那次六周的疼痛 {#ex-ectopic}
一名29岁按末次月经为6周加2、4天前验孕阳性，因“8小时右髂部的疼痛与肩尖的疼痛”就诊；血压104/66、心率96、hCG 3400；经阴道的超声“未见宫内的妊娠、子宫直肠陷凹有游离的液体、而右侧的附件有一个4厘米的环”。
::: solution
**这是一个正在破裂或已破裂的宫外孕（[[#def-diagnosis]]）：算术——“hCG远超任何单位的判定的区域、宫内无妊娠、一个附件的环、游离的液体、以及膈上的血造成的反射性肩尖的疼痛——诊断已经成立；决定是手术室、不是叶酸的拮抗剂；因为游离的液体加反射的疼痛加心跳加快与脉压变窄的模式就是外科的指征；而在这一图景中我们来观察hCG的每一分钟，都会成为日后索赔书里的那一句话“。第一个小时——”血型预留与血细胞计数与凝血及生化、并把交叉配血一起送——因为这是一种被量化的失血的病、不是一种阴道的流的病可见的丢失只是一部分”；通知麻醉师与资深的妇科医师；用血的制品复苏而不是灌盐水；腹腔镜或开腹按资深的判断与稳定性，很可能做输卵管的切除——而第二台的腹腔镜与血的回收的念头是为已塌陷的患者准备的；Rh 阴性者的抗 D 的剂量在大量输血时按母胎出血的量化规则做检测“。第二重念头的清单——”若她接受过任何助孕，则宫内的合并宫外孕；以及那个看起来像个环黄体的模仿者——这就是为什么外科医师在关闭之前要看两条输卵管与子宫“。以及之后——”经组织学确认的诊断；恢复与开车及淋浴的建议；以及hCG降到零的安全网——持续的滋养细胞是罕见的，但一旦它就意味着治疗；以及那两场谈话：下一次的妊娠要早做扫描；而失去的那次妊娠不会因为被保住过而回来[[emergency-critical-care/acute-assessment]]、[[emergency-critical-care/shock-fluids]]。**
:::

::: example 例“伴肌瘤子宫稽留的流产” {#ex-missed}
一名36岁、11周加4、无症状；按方案的扫描显示“没有胎心、而头臀长31毫米”；她那被肌瘤变形的子宫与“一枚9厘米壁内的肌瘤”使选项并不平等；她问“你会怎么做”。
::: solution
**“让选项变得个人化”（[[#def-miscarriage]]）：先是诊断——“在头臀长31毫米处没有胎心，按严格的标准就是确定的妊娠的丢失；而告诉她这件事的是一位读了那个数字的医师、不是一份扫描报告的措辞——这就是这场谈话里全部的尊严“。带着这个子宫看那三条路径——”期待的可能，但在紧邻肌瘤的宫腔下更难预测，并有出血与贫血的念头；药物的（米索前列醇；“在肌瘤的子宫下更重的疼痛与出血的咨询；血红蛋白的基线与手边的氨甲环酸实际的事；以及那句诚实的”可能最后还是需要做手术”的百分比）；以及手术的（11周已接近手动真空吸引的边界，所以很可能是一次按规格吸引的清宫——肌瘤与穿孔及清宫不完整及需要第二次操作的风险要用数字讲出来，并提供由资深者来做这一选项、而不是假定它）“。对”你会怎么做“的回答——”诚实的版本：如果我带着你这样的一枚肌瘤、而我的血红蛋白是105，我会选那台手术——配一位事先看过扫描资深的医师与麻醉师；而如果我很稳定并想避免手术，那么今晚就在这家单位吃药也是合理的；这里是什么让每一种对某些女性来说是错的。“以及照护的那一圈——”一间私人的房间；命名与纪念的选项；在她选择时把伴侣包括进来；用一句话解释清楚病理的送检与同意涉及Rh 与葡萄胎的组织学；以及下一次的预约[[clinical-skills/communication]]、[[medical-ethics-law/consent-capacity]]。**

::: example 例“15周的稽留的流产”却不是 {#ex-borderline}
一次在15周加2的扫描报告“无胎心、妊娠囊存在”；操作超声的人请你确认；双顶径小于孕周，而这位母亲的“末次月经不确定、周期是晚但规律的”。
::: solution
**那个绝不可“在一次扫描上下”的诊断（[[#def-miscarriage]]）：标准的纪律——“妊娠丢失的标准之所以严格是有原因的：在末次月经不确定时，一个生物测量值偏小而单次不佳的图像上看不到心脏的胎儿，可能只是一个11周的胎儿；而那套诊断的规则头臀长的阈值与平均妊娠囊直径的差距、以及不确定时7到14天后重扫这一条正是为此而存在的；正确的做法是由资深的操作者配上一段间隔重扫，以及敢于对这对父母说“我还不确定的”——错一次是可以承受的，错在终止妊娠上则不可以“。流程——”第二意见被具名地记录；孕周的核对若有早期的扫描则用它、以及周期的长度与宫底的高度；用同一台机器重扫并把图像集打印出来放进病历；以及在那个等待中由具名的联系人继续的咨询——“让她们在家在地狱里过两周的替代，正是日间单位或48到72小时收住存在的原因”。以及“被确认之后”的路径——”当丢失按标准被确认，上一个例子中的那场处理的谈话就开始了；而保护她免受错误诊断的那同一种严谨，如今也保护她免于一个错误的一切都会好的。这一章被法律引用最多的一课：“报错孕周是误诊的母亲”；而那些会说“我还不知道”的超声的操作者与医师，是房间里最安全的人“[[clinical-skills/clinical-reasoning]]、[[clinical-skills/medical-imaging]]。**

::: example 例“验孕阳性、带着宫内节育器、而看不到妊娠” {#ex-iud}
一名31岁“带着在位的含铜的宫内节育器”、按末次月经6周加4、尿检阳性、hCG 2100；经阴道的超声：空虚的子宫、节育器在位、未见附件的肿块、极少量的游离液体、以及“她称为像月经的那一点隐痛”。
::: solution
**带着节育器的妊娠的检查（[[#def-diagnosis]]）：规则——”节育器不会造成宫外孕，但带着节育器发生的妊娠不成比例地可能是宫外孕；而hCG超过判定的区域而子宫是空的就是宫外孕或异常的妊娠，直到被证明别的——不论那个形容疼痛的词多么像月经；而空虚的子宫加节育器的扫描还需要一次节育器是不是它看起来的那个位置的核查，因为移位了的装置与宫角的妊娠在疲惫的眼睛看来可能相似“。这一小时——”现在就由资深者复查的方案；血型预留；以及48小时复查hCG这一当面的决定并指定门诊的预约绝不是一句“周一打电话给全科医生”；份写成文字严格宫外孕的说明及虚脱就打急救；今晚她是不是一个人这一问家里有谁；以及若Rh 阴性的抗 D 的决定“。接下来的一两天——”由轨迹来决定：走部位未知的期待的路径、或未破裂且能被随访的宫外孕的药物治疗、或手术室；若宫内妊娠被期待且可能就取出节育器；而在宫外孕或丢失的路径上取出它配抗生素与咨询“。以及其后的咨询——”在问题解决之后的避孕的谈话，因为在她的脑海里她的节育器显然失效了，而它多半尽到了职责，她只是那不幸的少数；关于失败率与宫外孕的占比的诚实的数字；以及包括那款她差点因此出事的长效的方法在内的选择[[clinical-skills/communication]]、[[obstetrics-gynaecology/contraception-fertility]]。**

**“甲氨蝶呤的出院”（[[#def-diagnosis]]）：方案——“单剂的肌注甲氨蝶呤，配第4天与第7天的hCG的复查预期最初的上升之后的下降；若按方案下降不足则给第二剂；以及随访到零的那个她不可退出的时间表——因为持续的滋养细胞就是那个在凌晨四点发作的并发症“。副作用与安全的规则——”不吃叶酸的补充剂、也不过度地摄入被叶酸强化的食物饮食正常；最少或不喝酒；防晒光敏；预期口腔的炎与恶心及转氨酶的升高，以及第2到3天的输卵管流产样的疼痛必须被评估、不可被假定为良性——因为破裂在同一时间窗达到峰值；以及按方案的“用对乙酰氨基酚而不是非甾体的”这一念头。以及那张她随身带的卡——“任何突然的疼痛、发晕、肩尖的疼痛或气短——叫救护车，并说我正在为宫外孕接受治疗”；以及那份“计划的安排：在三到六个月之内不要有新的妊娠按方案、在随访期间避孕（因为hCG的上升也可能是妊娠）、以及”下次妊娠要早做扫描”[[clinical-skills/communication]]、[[pharmacology/adverse-reactions]]。**
:::

::: exercise 处理那例“伴低钠的剧吐” {level=2}
::: solution
**有病史的低钠（[[#def-hyperemesis]]）：推理——“呕吐加上容量不足时的恰当的抗利尿激素，再加上一幅只喝茶和面包或输入低渗液体的图景：钠低是因为她在潴留水，而入院的液体的选择可能把这两个来源都加重；3%的盐水只留给有严重症状的低钠抽搐、明显的木僵，以被控制的小容量的输注给予，而不是为一个数字和一个双关语去修——而她那奇怪的表现也要为其他的原因被检查，包括她自入院起就有风险的韦尼克的脑病；这是那位年资低的医师在下任何高渗的医嘱之前都应该想到的同一个鉴别“。医嘱——”现在就给硫胺并记录如果还没有；停下所有低渗的来源；等渗或略高渗的盐的策略，以4到6小时重复的钠与她的液体的出入量为指导；严格的出入量与观察；以及“写在床头纠正上限的规则”[[renal/water-sodium]]、[[endocrine/endocrine-emergencies]]。**
:::

::: exercise 处理那次“葡萄胎随访中妊娠的惊慌” {level=2}
::: solution
**被监测的那次妊娠（[[#def-hyperemesis]]）：错误的答案——”终止并不是监测的一项要求：在葡萄胎后的随访中一次非意愿的妊娠是今天就与滋养细胞疾病中枢联系的理由、不是结束一次妊娠的理由；那种为了数字而终止的反射“把她生育的意愿献给了监测的便利，而它出现在投诉的档案里是有充分理由的”。正确的路径——“紧急地转诊到全国的中枢，做孕前或早孕的风险的评估：大多数在葡萄胎之后的继续的妊娠都很好；那个较小的复发与胎盘异常的风险值得一次按孕周早期的扫描与一份计划在妊娠的晚期与产后复查hCG“；而如果她继续，”中枢会围绕妊娠来调整监测、而不是围绕监测来调整妊娠“；以及那个决定的记录——”如果她自己想终止，是她的决定并被尊重；但我们不会替监测做这个决定”[[obstetrics-gynaecology/gynaecological-cancer]]、[[medical-ethics-law/consent-capacity]]。**
:::

## 通向何处

“在一次的丢失之后的”一次建档产前的照护在[[obstetrics-gynaecology/pregnancy-antenatal]]，清宫手术安全的语境在[[surgery/perioperative-care]]，滋养细胞的肿瘤学在[[obstetrics-gynaecology/gynaecological-cancer]]，而生育力的检查在[[obstetrics-gynaecology/contraception-fertility]]。

::: history
**早孕的医学是产科中最年轻的部分，因为它的疾病在大部分的历史中是不可见的：妊娠的丢失只是“几个月”；宫外孕是18世纪几乎必然的死亡“变得感染了的腹腔的与晚期的病例，而最早成功的手术属于把输卵管切掉的那个时代”——即1880到1900年代；而葡萄胎——它的hCG的很高被助产士与医师记录成“伴有水泡的那一种”。真正的转折是技术的：尿的妊娠的试验它把妊娠变成了一件“在停经的当月就能知道的事”；放射免疫的测定法与随后的血清的测量；以及经阴道的超声，它把“宫内的与宫外、存活的与失败的”变成了“同一个下午的两个图像”。然后是药物：甲氨蝶呤为未破裂的宫外孕提供了一种不切开的治疗；而米索前列醇与手动真空的吸引改变了流产的处理——“照护从被施加于她变成被她选择；而那场关于终止妊娠的政治史”也在这里被写就“它的法律的与安全的路径及仍然横亘在获取上的不平等。最近的一段历史是这个专科”与遗传学的交叉——妊娠产物的核型与芯片、“胚胎植入前的检测与复发性流产的基因的组合的辩论”，以及那片希望的免疫治疗帝国系统的评价不断发现并未被证实的输脂与父系的淋巴细胞及自然的杀伤细胞的疗法——以及说出这一点的专科的纪律。贯穿的主线是：这一章的疾病先是变得可以存活、然后变得有人情味；而这两次转向既依赖技术探针与测定法与药片，也依赖女性的倡议——“她们坚持说能活下来并不是终点”[[obstetrics-gynaecology/pregnancy-antenatal]]、[[clinical-skills/communication]]、[[public-health/determinants-inequalities]]。**
:::

::: summary
- 在任何早孕的疼痛伴出血的病例中，三个问题并行运转：妊娠在哪里、它是否在发育、以及母亲在血流动力学上是否安全；hCG的趋势与经阴道的超声回答前两个，而肩尖的疼痛回答第三个。
- “妊娠部位未知”是一套方案、不是一个诊断：系列的hCG直到阈值或消退，配宫外孕的说明与一个“打得通的电话号码”。
- 伴游离的液体与反射的疼痛的宫外孕要去手术室；未破裂的宫外孕是一场“与她一起做、而不是绕开她做”的三向的决定手术与药物与期待。
- 流产的处理是在“按证据大致等价的路径之间由患者来选择”，而路径因她的解剖与她的血细胞计数及她的偏好而不平等；“手动真空的吸引”与居家的药物的路径把照护移到了它应在的地方。
- 剧吐要先给硫胺、再给含糖的液体，并尽早用一层层的止吐药；葡萄胎要吸引的清宫与登记及hCG的随访——而这份随访绝不可为一次被期待的妊娠而被跳过。
- 每一次早孕的接触都是一次避孕与保护及精神的健康的机会，因为生育力在随访的预约之前就回来了。
:::

## 练习

::: exercise 解读“部位未知”的数字 {level=1}
::: solution
**上升但缓慢（[[#def-diagnosis]]）：可能性——”一种异常的宫内的妊娠正在失败的或上升慢的、一种持续的宫外孕、以及一种仍在阈值之下的正常上升的极早期的宫内妊娠——按对行动的重要性排这个次序，因为其中三种里有两种在没人看时会变得危险“。计划——”48小时复查hCG，并按单位的阈值决策的规则在阈值之上而宫内无妊娠就把她移到宫外孕的检查：在有条件时用磁共振或资深的超声的意见；场保留手术选项的谈话；以及日间单位或每日的联系的监测的规则；严格宫外孕的说明要写成一张卡、不是一句话；并给出24小时的可联系的具名的名字“。两个错误——”在hCG已经超过阈值时假定大概是太早了，如果更痛再打电话；以及在第一次上升的数值上就动手术——轨迹才是那项检查“[[obstetrics-gynaecology/contraception-fertility]]。**

::: exercise 开出剧吐收住的医嘱 {level=2}

**剧吐的那一天（[[#def-hyperemesis]]）：补液的纪律——”硫胺100到200毫克静脉（加上含硫胺复合的B族的维生素）在任何含葡萄糖的液体之前并在其期间；以0.9%的盐水做初始的容量低钠的纠正要慢——目标是24小时之内少于8到10毫摩尔每升，并在4到6小时复查钠；钾的补充“按速率与总量与外周的耐受性的友好的浓度，并复查镁与磷——因为饥饿而呕吐的患者会耗竭除了酮体之外的一切，随后再喂养的风险就会出现“。阶梯——”按固定的时间给药而不是需要时：环丙嗪或丙拉明的抗组胺的静脉或肌注带着抗胆碱的心跳加快的注记，加上一种多巴胺的拮抗剂丙氯拉嗪或甲氧氯普胺，带着年轻女性的肌张力障碍与静坐不能的警告——这正是与抗组胺的一起处方不只是为了镇静的理由；加上或换成昂丹司琼带着Q-T与便秘的注记，它常常最有效；以及皮质激素的救援氢化可的松或甲泼尼龙的一个短疗程，按指导在10周之后使用，并把她的决定记录下来；以及”酸的与碱的图景低钾低氯性的碱中毒可能加重她的手的抽搐[[renal/acid-base-disorders]]、[[gastrointestinal/clinical-nutrition]]。**

::: exercise 在一次的早期丢失之后给建议 {level=2}

**丢失之后的咨询（[[#def-miscarriage]]）：标准的回答——“在身体上她想什么时候试就可以试——生育力在两到三周之内恢复；等三个周期的建议是为了算孕周、不是为了安全；而证据并不要求延迟、从年龄的理由看甚至可能不延迟更好；不，在一次丢失之后做全面的检查并不被指征——背景人群的丢失率让单次的检查成为错误的安心与错误的发现的来源“；以及”两种会改变答案的情形——（甲）那次丢失是葡萄胎的或组织学说了些什么那么随访与监测期间避孕的回答就取代了上面的回答；（乙）她的病史比一次丢失更丰富既往的血栓与甲状腺的疾病，或血栓倾向与反复丢失的家族史——触发抗心脂质与甲状腺的检验的念头“。以及”让计划被记住的那句话”——“你下一次的风险是七分之一，因为那就是所有人的风险，不是你个人的风险；而我们不会为了一个统计学上属于每个人的东西去抽血”[[clinical-skills/communication]]、[[endocrine/reproductive-endocrinology]]。**
