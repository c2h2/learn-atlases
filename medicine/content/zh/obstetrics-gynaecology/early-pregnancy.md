早孕期出血或腹痛是妇女到妇科急诊就诊最常见的原因之一。这些妊娠中的大多数要么会正常继续，要么会以流产告终，而流产需要的是支持而不是紧急治疗。少数是异位妊娠，可能破裂并引起危及生命的内出血。早孕保健的技巧在于可靠地识别出这少数病例，而不让每位妇女都接受不必要的检查，同时认识到流产本身就是一种值得关怀的丧失。

大部分工作由两种工具完成：**经阴道超声**，它显示妊娠位于何处、是否在发育；以及**血清hCG**，即滋养细胞产生的激素，在超声无法回答时，其水平及变化速度可以提供信息。本章解释如何将两者结合使用，并介绍流产、异位妊娠、妊娠滋养细胞疾病、妊娠剧吐和复发性流产。英国实践遵循NICE NG126（《异位妊娠与流产》，2019年，2023年更新）和RCOG指南。

## 正常的早孕期

受精发生在输卵管内，之后胚胎经约五天到达子宫，约在第6–7天植入子宫内膜（**蜕膜**）。外层细胞即**滋养细胞**侵入蜕膜，并产生**人绒毛膜促性腺激素（hCG）**。hCG作用于黄体，维持孕酮的分泌，直到约8–10周胎盘接替这一功能。

在正常的早期妊娠中，血清hCG水平急剧上升，在最初几周大约每两天翻一番，然后在约8–11周达到峰值，再下降到较低的平台。尿妊娠试验从大约月经过期时起就能检出hCG。

在经阴道超声上，正常发育的宫内妊娠呈现一个可辨认的序列：

| 大致孕周 | 所见 |
|---|---|
| 约4+3至5周 | 妊娠囊，蜕膜内的一个小液性暗区 |
| 约5+3周 | 妊娠囊内的卵黄囊（确认宫内妊娠） |
| 约6周 | 可见心管搏动的胚芽 |

这些时间点随日期的准确性而变化，这就是为什么单次超声很少能证明妊娠已经失败，也是为什么下面的标准使用大小而不是日期。

## 未知部位妊娠

如果一位妇女妊娠试验阳性，而经阴道超声在子宫内或其他部位都看不到妊娠，她就是**未知部位妊娠（PUL）**。这是一个描述，而不是诊断。它有三种可能的结局：太早而看不到的宫内妊娠、将会自行消退的失败妊娠（宫内或异位），或太小而看不到的异位妊娠。

::: theorem 未知部位妊娠中的hCG比值 {#thm-hcg-ratio}
NICE NG126建议，对于临床情况稳定的PUL妇女，间隔48小时测量两次血清hCG：
- **升高超过63%**提示正在发育的宫内妊娠，但不能排除异位妊娠。在7–14天内提供经阴道超声，如果hCG达到或超过1500 IU/L则更早。
- **下降超过50%**提示妊娠失败。14天后做尿妊娠试验；如为阴性，则无需进一步处理。
- **介于两者之间的变化**（升高63%或以下，或下降50%或以下）意味着可能是异位妊娠，应在24小时内到早孕门诊复查。

症状优先于数字：有明显疼痛或出血征象的妇女，无论hCG如何都需要紧急评估。
:::

::: proof
有活力的宫内妊娠有不断增长的健康滋养细胞团块，其hCG分泌速率不断增加，因此水平急剧上升。在失败的妊娠中，滋养细胞正在死亡，hCG以约一两天的半衰期被清除，因此水平迅速下降。异位妊娠通常植入在血供不良的部位，如输卵管，因此滋养细胞虽在生长，但生长不良：其hCG水平通常缓慢上升、进入平台或缓慢下降。选择63%和50%的界值，是为了使很少有有活力的妊娠被错误地归为无活力；代价是少数异位妊娠会表现出"正常"的上升，这就是为什么升高超过63%也不能排除异位妊娠。
:::

::: example 解读两次hCG值 {#ex-pul}
一位28岁妇女按日期约孕5周，有少量出血。她状况良好，只有轻度腹部绞痛。经阴道超声未见宫内或宫外妊娠，也没有游离液体。她的hCG为1200 IU/L，48小时后为2100 IU/L。解读结果。
::: solution
上升为$2100/1200 = 1.75$，即增加**75%**，超过63%。这提示首次超声时太早而看不到的正在发育的宫内妊娠。由于这种幅度的上升不能排除异位妊娠，应为她复查经阴道超声；由于她的hCG现已超过1500 IU/L，超声应尽快进行，而不是等待7–14天。给她书面资料，并告知如果腹痛加重、出现肩尖痛、晕厥或大量出血应立即返回。
:::
:::

## 流产

::: definition 流产的类型 {#def-miscarriage}
**流产**是24周之前的妊娠丢失。约五分之一的已知妊娠以流产告终，大多数在12周之前；最常见的原因是胚胎的染色体异常。临床类型有：
- **先兆流产**：有出血，宫内妊娠有活力，宫颈口闭合。大多数会正常继续。
- **难免流产**：有出血，宫颈口开放；妊娠将会丢失。
- **不全流产**：部分妊娠组织已排出，但仍有部分留在子宫内。
- **完全流产**：所有妊娠组织均已排出；出血停止，子宫腔空虚。如果超声从未见过宫内妊娠，就不能有把握地诊断"完全流产"，应按PUL处理。
- **稽留流产（延迟流产或无症状流产）**：超声发现宫内妊娠已停止发育，常无症状。
- **感染性流产**：并发宫内妊娠物感染的流产。
:::

**稽留流产的诊断。** 由于误诊可能终止一次想要的妊娠，NICE采用保守的超声标准。经阴道超声：
- 如果**头臀长达到或超过7 mm**而未见心管搏动，应由第二位操作者确认，或至少7天后复查超声确认。
- 如果**平均妊娠囊直径达到或超过25 mm**而未见胚芽，处理同上。
- 低于这些大小时，至少7天后复查超声再作诊断。

**处理。** 为确诊流产的妇女提供以下选择：
- **期待治疗**：等待流产自然发生，通常为7–14天，是大多数妇女的一线选择。三周后做尿妊娠试验确认已完全排出。
- **药物治疗**：对稽留流产，NICE建议口服米非司酮（mifepristone），48小时后使用米索前列醇；对不全流产，单用米索前列醇。提供镇痛药和止吐药。
- **手术治疗**：门诊局部麻醉下**手动负压吸引**，或在手术室行电动负压吸引，清除妊娠组织。如果出血量大、有感染或既往有创伤性经历，或妇女本人选择，则优先手术。

每种选择各有优点。期待治疗和药物治疗可避免手术，但需在家中经历出血和疼痛，有时之后仍需手术。手术更快、更可预测，但有少量感染、子宫穿孔和宫腔粘连的风险。妇女本人的选择是核心。

**抗D。** NICE建议对接受**手术**处理流产或异位妊娠的RhD阴性妇女进行抗D预防。单纯药物治疗、先兆流产、完全流产或PUL不建议使用。

**情感关怀。** 许多妇女在流产后经历悲伤、焦虑、抑郁和创伤后应激。医护人员应使用清晰而富有同情心的语言（对妇女本人说"你的妊娠已停止发育"，而不是"妊娠产物"），解释将会发生什么，并提供随访以及支持组织的信息。

**先兆流产与孕酮。** 继PRISM试验（2019年）之后，NICE（2021年）建议，对早孕期阴道出血、已确认宫内妊娠且既往有过流产的妇女，提供阴道用微粒化孕酮，持续至16周。获益主要见于既往有流产史的妇女。

::: example 已停止发育的妊娠 {#ex-missed}
一位34岁妇女按日期孕9周，因褐色点滴出血来做早期超声。经阴道超声显示宫内妊娠囊，胚芽头臀长8 mm，未见心管搏动。如何确认诊断？她有哪些选择？
::: solution
头臀长达到或超过7 mm而无心搏，符合NICE关于**稽留流产**的标准，但在采取行动之前，必须由第二位操作者确认，或至少7天后复查超声确认。应在安静的房间告知她，并给她提问的时间。

如果确认，为她提供**期待**、**药物**（米非司酮，48小时后米索前列醇）或**手术**（局部麻醉下手动负压吸引，或在手术室负压吸引）治疗，并附上每种方法的书面资料，包括预期会发生什么、镇痛、何时求助（大量出血、发热、剧烈疼痛）以及如何确认完全排出。只有当她为RhD阴性并接受手术治疗时才需要抗D。应告诉她，首次流产非常常见，通常由染色体问题引起，一般不会降低她今后成功妊娠的机会。
:::
:::

## 异位妊娠

**异位妊娠**是指植入于子宫腔以外的妊娠。在英国约每90次妊娠中有一次。约95%位于输卵管，大多数在**壶腹部**；其他位于宫颈、输卵管间质部（壁内段）、剖宫产瘢痕、卵巢或腹腔。随着妊娠生长，它可使输卵管破裂并引起严重的腹腔内出血。异位妊娠在英国仍是孕产妇死亡的原因之一，通常是在漏诊时。

**危险因素**是任何损伤输卵管或妨碍其运输功能的因素：既往异位妊娠、盆腔炎性疾病（尤其是衣原体感染）、既往输卵管手术（包括绝育术）、辅助生殖、吸烟，以及在宫内节育器或单纯孕激素避孕在位时受孕。约三分之一的妇女没有危险因素。

**临床表现**多种多样。经典特征是腹痛或盆腔痛、阴道出血和停经，但妇女也可能以腹泻、头晕或肩尖痛（血液刺激膈肌所致）就诊。NICE强调，任何育龄妇女出现腹痛都应考虑异位妊娠，凡有这些症状的育龄妇女都应做妊娠试验。**破裂**引起剧烈疼痛、腹膜刺激征和低血容量性休克的征象；年轻妇女代偿能力强，因此心动过速和面色苍白可能先于低血压出现。

**诊断**依靠经阴道超声，可显示与卵巢分开的附件包块，有时内含卵黄囊或胚芽，而子宫腔空虚。子宫直肠陷凹内的游离液体提示出血。如果什么也看不到，则按PUL进行系列hCG检测。

::: definition 输卵管异位妊娠的治疗选择 {#def-ectopic-treatment}
遵循NICE NG126：
- **期待治疗**可提供给临床稳定、无疼痛、输卵管异位妊娠小（小于35 mm）且未破裂、无可见心管搏动、hCG为1500 IU/L或以下且正在下降的妇女。
- **甲氨蝶呤**作为一线治疗提供给能够返院随访且无明显疼痛、未破裂的输卵管异位妊娠、附件包块小于35 mm且无可见心管搏动、hCG低于1500 IU/L、且无宫内妊娠的妇女。
- **手术**作为一线治疗用于不能返院随访，或有明显疼痛、包块达到或超过35 mm、可见胎心搏动或hCG达到或超过5000 IU/L的妇女。
- hCG在1500至5000 IU/L之间、其他方面符合甲氨蝶呤标准的妇女，可以选择甲氨蝶呤或手术。
:::

**甲氨蝶呤（methotrexate）**是一种叶酸拮抗剂，可阻止快速分裂的滋养细胞。治疗后第4天和第7天测hCG，之后每周测一次直至转阴；第4天至第7天之间下降不足15%提示治疗失败，可能需要第二剂或手术。甲氨蝶呤治疗后腹痛很常见，必须进行评估，因为可能是破裂。由于该药的致畸性，建议妇女在治疗后至少三个月内避免妊娠。

**手术**通常经腹腔镜进行。如果对侧输卵管健康，首选**输卵管切除术**。如果对侧输卵管受损，为保留生育力可提供**输卵管切开术**（切开输卵管取出妊娠物），但之后约五分之一的妇女需要因持续性滋养细胞进一步治疗，因此必须随访hCG。

::: example 选择治疗 {#ex-ectopic}
一位31岁妇女按日期孕6周，有轻度左髂窝痛。经阴道超声显示子宫腔空虚，左附件区22 mm包块，未见胎心搏动，子宫直肠陷凹内有少量游离液体。她的hCG为1100 IU/L。她情况稳定，住在医院附近，没有甲氨蝶呤的禁忌证。她有哪些选择？
::: solution
她患的是未破裂的输卵管异位妊娠：包块小于35 mm、无心搏、hCG低于1500 IU/L、无明显疼痛，且能够随访。在检查全血细胞计数、肝功能和肾功能之后，她符合NICE关于**甲氨蝶呤**作为一线治疗的标准。如果她愿意，手术是另一选择。只有当复查hCG正在下降时才可期待治疗。

如果她选择甲氨蝶呤，需要在第4天和第7天测hCG，之后每周一次直至转阴；明确告知她如腹痛加重或头晕要返院；建议她在治疗期间避免饮酒和含叶酸的补充剂，并在三个月内避免妊娠。药物治疗不需要抗D。
:::
:::

::: example 急诊科的晕厥 {#ex-rupture}
一位26岁妇女在工作时晕倒后被送来。她有剧烈的下腹痛和右肩尖痛。末次月经在七周前。脉搏128次/分，血压86/50 mmHg，腹部板状强直。尿妊娠试验阳性。诊断是什么？如何处理？
::: solution
在证明并非如此之前，诊断为**异位妊娠破裂伴失血性休克**。肩尖痛反映腹腔内的血液刺激膈肌。

处理：立即呼叫上级妇科医生和麻醉医生并通知手术室；建立两条大口径静脉通路，交叉配血，查全血细胞计数和凝血功能；启动大出血方案并输血。复苏不应延误手术，因为在手术控制之前出血不会停止。床旁超声显示游离液体可支持诊断，但不是手术前所必需的。她需要**急诊腹腔镜或剖腹手术**（取决于稳定程度和术者经验）并行输卵管切除术。由于这是手术治疗，如为RhD阴性应给予抗D。
:::
:::

## 妊娠滋养细胞疾病

**妊娠滋养细胞疾病**包括滋养细胞的异常增生。最常见的形式是**葡萄胎**，在英国约每600次妊娠中有一次。

- **完全性葡萄胎**通常具有二倍体、完全来自父方的核型（最常见为46,XX），产生于一个没有母方染色体的卵子与一个精子受精后精子染色体自我复制，或与两个精子受精。没有胎儿，绒毛普遍水肿。
- **部分性葡萄胎**通常为三倍体（例如69,XXY），有两套父方染色体和一套母方染色体。可有部分胎儿组织。

葡萄胎可表现为早孕期出血、子宫大于孕周、剧烈呕吐，罕见情况下表现为甲状腺功能亢进（hCG刺激TSH受体）。hCG水平常常很高。现在许多病例是在流产后经组织学诊断的。完全性葡萄胎的超声可呈"落雪状"表现。治疗方法是负压吸引清宫。在英国，所有妇女随后都在专科筛查中心（伦敦的查令十字医院、谢菲尔德或邓迪）登记，进行hCG监测直至正常。约15%的完全性葡萄胎和0.5%–1%的部分性葡萄胎发展为**妊娠滋养细胞肿瘤**，即持续性或侵袭性疾病（包括绒毛膜癌），通过hCG上升或进入平台而被发现。它对化疗高度敏感，通常使用甲氨蝶呤，经专科中心治疗的治愈率接近100%。

## 恶心、呕吐与妊娠剧吐

大多数妇女在妊娠早期有恶心和呕吐，通常在约6周开始，约16–20周时缓解。**妊娠剧吐**处于这一谱系的严重一端。RCOG指南（2024年）将其描述为妊娠期持续的恶心和呕吐，伴体重下降超过孕前体重的5%、脱水和电解质紊乱。必须考虑呕吐的其他原因，如尿路感染、胃肠炎、葡萄胎和甲状腺疾病，尤其是呕吐在10周之后才开始时。

严重程度可用**PUQE评分**（妊娠特异性呕吐量化评分）评定。治疗是阶梯式的，通常可在日间病房进行：静脉补液（生理盐水，必要时加氯化钾）、止吐药（一线选择包括赛克利嗪（cyclizine）和异丙嗪（promethazine）等抗组胺药、丙氯拉嗪（prochlorperazine）等吩噻嗪类，以及多西拉敏与吡哆醇（doxylamine/pyridoxine）；二线选择包括甲氧氯普胺（metoclopramide）和昂丹司琼（ondansetron）），难治病例在专科监督下使用糖皮质激素。对长期呕吐的妇女给予**维生素B1（硫胺素）**以预防韦尼克脑病，在给予硫胺素之前避免使用含葡萄糖的液体。对住院妇女考虑VTE预防，因为脱水和制动会增加风险。心理负担相当沉重，应询问妇女的精神健康状况。

::: warning 妊娠剧吐的妇女常常治疗不足
妊娠期严重恶心呕吐的妇女常常不愿服药，临床医生有时也不愿开药。未经治疗的妊娠剧吐会导致脱水、电解质紊乱、韦尼克脑病、VTE、营养不良和极度痛苦，一些妇女甚至因此终止了想要的妊娠。妊娠期使用的止吐药有大量安全性数据；及早并充分地治疗比不治疗更安全。
:::

## 复发性流产

RCOG（绿顶指南17，2023年）将**复发性流产**定义为三次或以上早孕期流产，不要求连续。如有理由怀疑存在潜在病因，临床医生可在两次流产后进行检查，而中孕期流产本身即应检查。复发性流产影响约1%的夫妇。检查包括：
- **抗磷脂抗体**（狼疮抗凝物、抗心磷脂抗体和抗β2糖蛋白Ⅰ抗体），间隔至少12周检测两次。对于**抗磷脂综合征**，在下次妊娠中使用小剂量阿司匹林和肝素可提高活产率；
- **甲状腺功能**和甲状腺抗体；
- **盆腔超声**检查子宫畸形，如纵隔子宫；
- 对第三次及以后流产的妊娠组织进行**细胞遗传学分析**，如发现不平衡的结构异常，则对父母进行核型分析。

约一半的夫妇找不到原因。他们下次妊娠成功的机会仍然很好，而在早孕门诊接受支持性照护本身就与更好的结局相关。

## 人工流产

在大不列颠，人工流产依据1967年《堕胎法》是合法的：在两名医生同意的情况下，可在24周之前基于法定理由进行，在某些情况下没有孕周限制。在北爱尔兰，人工流产于2019年除罪化，并自2020年起由单独的立法规范。大不列颠的大多数人工流产是使用米非司酮后续以米索前列醇的早期药物流产；自2022年起，英格兰和威尔士的妇女在远程医疗咨询后，可在家中服用这两种药物，适用于9+6周以内。保健遵循NICE NG140（2019年）。伦理和法律框架在[[medical-ethics-law/beginning-of-life]]中讨论。

::: quiz
一位妇女妊娠试验阳性，经阴道超声显示子宫腔空虚，无附件包块。她状况良好。她的hCG为800 IU/L，48小时后为900 IU/L。下一步是什么？
- [ ] 安慰她：hCG上升意味着正常的宫内妊娠。
- [ ] 14天后复查尿妊娠试验。
- [x] 24小时内在早孕门诊复查，因为hCG上升不足意味着可能是异位妊娠。
- [ ] 立即给予甲氨蝶呤。
::: solution
上升为$900/800 = 1.125$，即12.5%，介于上升63%和下降50%两个阈值之间。根据[[#thm-hcg-ratio]]，可能是异位妊娠，她需要在24小时内到早孕门诊由上级医生复查，并进一步做超声和hCG测定。在没有诊断的情况下不给予甲氨蝶呤，对持续的PUL也要经上级医生仔细评估后才能使用。
:::
:::

::: history
异位妊娠的首例有记录的手术治疗是1759年纽约的约翰·巴德（John Bard）完成的，他从一位妇女的腹腔中取出了一个死胎，该妇女存活下来。1883年，伯明翰的罗伯特·劳森·泰特（Robert Lawson Tait）为破裂的异位妊娠施行了首例成功的手术，结扎了输卵管，并报告了一系列从这种几乎必死的疾病中存活下来的患者。第二次革命是诊断上的：1972年，美国国立卫生研究院的朱迪丝·瓦伊图凯蒂斯（Judith Vaitukaitis）、格伦·布朗斯坦（Glenn Braunstein）和格里夫·罗斯（Griff Ross）建立了hCG β亚单位的放射免疫测定法，使人们能够在任何症状出现之前检出妊娠；1980年代的经阴道超声则使人们能够看到妊娠的位置。两者共同使异位妊娠从一种在破裂时才诊断的外科急症，变成了一种通常能够早期诊断的疾病，并使甲氨蝶呤药物治疗（1982年首次报告用于异位妊娠）成为现实的选择。绒毛膜癌曾几乎总是致命的，1956年李敏求（Min Chiu Li）和罗伊·赫兹（Roy Hertz）在美国国家癌症研究所使用甲氨蝶呤之后，它成为第一种单用化疗即可治愈的实体瘤。
:::

::: summary
- 未知部位妊娠通过间隔48小时的两次hCG进行处理：升高超过63%提示正在发育的宫内妊娠，下降超过50%提示妊娠失败，介于两者之间需在24小时内复查以排查异位妊娠。
- 头臀长达到或超过7 mm而无心搏，或平均妊娠囊直径达到或超过25 mm而无胚芽时诊断稽留流产，并由第二位操作者或7天后复查超声确认。
- 流产可以期待治疗、药物治疗（稽留流产用米非司酮后米索前列醇）或手术治疗；妇女本人的选择是核心。只有手术治疗时才给予抗D。
- 异位妊娠约占每90次妊娠中的一次；任何育龄妇女出现腹痛都要考虑，并做妊娠试验。
- 对病情稳定、异位妊娠小且未破裂、无心搏、hCG低于1500 IU/L的妇女，甲氨蝶呤是一线治疗；有明显疼痛、包块达到或超过35 mm、有心搏或hCG达到或超过5000 IU/L时手术。破裂的异位妊娠需要立即手术。
- 完全性葡萄胎通常为二倍体且来自父方；部分性葡萄胎为三倍体。所有病例都需要在专科中心随访hCG；持续性疾病对化疗反应非常好。
- 妊娠剧吐引起体重下降、脱水和电解质紊乱；应及早用补液、止吐药和硫胺素治疗。
- 复发性流产（三次或以上早孕期流产）需检查抗磷脂综合征、子宫畸形和父母的染色体重排。
:::

## 习题

::: exercise 百分比变化 {level=2 check="round(100*(1850/1400-1))"}
一位未知部位妊娠妇女的hCG为1400 IU/L，48小时后为1850 IU/L。计算百分比变化（取最接近的整数），并说明按照NICE指南它意味着什么。
::: solution
$1850/1400 = 1.321$，上升**32%**。这低于63%，也不是下降，因此处于中间范围：可能是异位妊娠，她应在24小时内到早孕门诊复查。
:::

::: exercise 流产的类型 {level=1}
说出每种情况的流产类型：(a) 8周时出血，宫颈口闭合，超声显示有心搏的胎儿；(b) 大量出血伴血块，宫颈口开放，宫颈口可见组织；(c) 12周超声显示胎儿头臀长25 mm，无心搏，无症状。
::: solution
(a) **先兆流产**：大多数此类妊娠会继续。(b) **难免流产或不全流产**：宫颈口开放并有组织堵塞意味着妊娠不能继续；取出宫颈口的组织可缓解宫颈休克（迷走神经受刺激引起的心动过缓和低血压）。(c) **稽留流产**：在处理之前由第二位操作者或复查超声确认。
:::

::: exercise 谁需要抗D？ {level=1}
对于RhD阴性妇女，按照NICE NG126，以下哪些情况需要抗D：(a) 9周先兆流产；(b) 10周稽留流产的药物治疗；(c) 10周稽留流产的手术治疗；(d) 因异位妊娠行腹腔镜输卵管切除术；(e) 用甲氨蝶呤治疗异位妊娠？
::: solution
(c)和(d)这两项手术操作建议使用抗D。(a)、(b)和(e)不建议使用。应遵循当地方案；12周以后阈值不同，此时致敏事件按妊娠后期处理（[[obstetrics-gynaecology/pregnancy-antenatal]]）。
:::

::: exercise 葡萄胎的核型 {level=1}
解释为什么完全性葡萄胎可以有看起来正常的46,XX核型，却仍然是异常的。
::: solution
在完全性葡萄胎中，两套染色体都来自父亲：一个失去了母方染色体的卵子与一个精子受精，该精子的基因组自我复制（得到46,XX），或与两个精子受精。染色体数目正常，但没有母方基因组。由于某些基因只从母方或父方的拷贝表达（**基因组印记**），纯父源的基因组会驱动滋养细胞过度生长而没有胚胎。见[[genetics/non-mendelian-inheritance]]。
:::
:::

::: exercise 妊娠剧吐 {level=2}
一位孕9周的妇女体重从孕前62 kg下降了7 kg。尿酮体3+，血钠131 mmol/L，血钾3.1 mmol/L，不能进食任何液体。计算她体重下降的百分比，并概述处理。
::: solution
体重下降：$7/62 \approx 11\%$，远超过5%。伴有脱水和电解质紊乱，她患有**妊娠剧吐**。

处理：根据反应收住院或在日间病房治疗；检查尿液排除感染，查甲状腺功能，并安排超声确认妊娠、排除多胎或葡萄胎；静脉输注生理盐水加氯化钾，根据反复测定的电解质调整；在任何葡萄糖之前给予**硫胺素**；规律使用止吐药，从一线药物开始，必要时加用二线药物；进行VTE风险评估和预防；并支持她的精神健康。如果她没有反应，上级医生可考虑使用糖皮质激素。应为她制定症状复发时及早治疗的计划。
:::
:::

::: exercise 甲氨蝶呤后的随访 {level=2}
一位因异位妊娠接受甲氨蝶呤治疗的妇女，第4天hCG为1300 IU/L，第7天为1250 IU/L。这是否令人满意？下一步怎么办？
::: solution
第4天到第7天的下降为$(1300 - 1250)/1300 \approx 3.8\%$，远低于预期的15%。治疗很可能无效。应对她进行临床和超声复查，并根据她的症状、检查结果和意愿，提供第二剂甲氨蝶呤或手术。如果任何时候出现明显疼痛或破裂征象，她需要紧急外科评估。
:::
:::

::: exercise 腹痛与阳性妊娠试验的鉴别诊断 {level=3}
一位22岁妇女右髂窝痛12小时，伴恶心和低热。末次月经在六周前，妊娠试验阳性。给出鉴别诊断，并解释如何区分主要的可能。
::: solution
**鉴别诊断。** 异位妊娠；流产；急性阑尾炎（妊娠期可发生，妊娠试验阳性不能排除）；黄体囊肿出血或破裂；卵巢扭转（黄体增大时更有可能）；尿路感染或肾盂肾炎；以及肾绞痛。

**区分方法。** 经阴道超声是关键检查：它显示是否有宫内妊娠、附件包块、游离液体、卵巢囊肿或卵巢血流异常。超声不能确定时，血清hCG有帮助。尿液分析和培养评估感染。炎症标志物和体格检查（疼痛的转移、麦氏点肌紧张）有助于诊断阑尾炎，妊娠期可用超声或MRI检查阑尾。在确认宫内妊娠之前，异位妊娠必须一直保留在鉴别清单上。宫内外同时妊娠（宫内妊娠和异位妊娠同时存在）在自然受孕后很罕见，但在辅助生殖后更常见。
:::
:::

::: exercise 第三次流产 {level=3}
一位35岁妇女已有三次早孕期流产。她和她的伴侣询问将会做哪些检查、能做些什么。概述你的回答。
::: solution
**检查**：间隔12周两次检测抗磷脂抗体；甲状腺功能和抗体；盆腔超声（最好是三维超声）检查子宫畸形；对本次流产的组织进行细胞遗传学检测，如发现不平衡易位则对父母进行核型分析。审查生活方式因素（吸烟、饮酒、BMI）。

**治疗**取决于检查结果：抗磷脂综合征用阿司匹林加肝素；对经过选择的病例宫腔镜切除子宫纵隔；父母存在易位时转诊至临床遗传科。对于不明原因的复发性流产，尚无经证实有效的药物治疗，但如果她在下次妊娠中出血，可提供阴道孕酮（依据PRISM）。应为她提供早孕门诊的支持性照护和早期的安心超声，并告诉她大多数不明原因复发性流产的夫妇最终都能成功妊娠。应承认这对情感的影响，并提供心理支持。
:::
