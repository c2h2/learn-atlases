分娩是一连串“伪装成生理过程的决定”：这是分娩吗？这是进展吗？这个孩子还好吗？此刻这间房间合适吗？而正在看着的这位临床医师是对的人吗。

## 产程、监护与进展

::: definition 生理、进展与胎儿的监护 {#def-labour}
**诊断与阶段：临产是“伴宫颈改变规律的宫缩”。潜伏的产程漫长、难受、并常常被“错误地推销成活跃期的分娩”以致女性被过早地收住——也正是因此，新的收住的approach的试验更赞成“较晚的收住配社区的支持”；活跃的第一产程如今被合理地定义为“约5到6厘米的扩张”、而不是3到4厘米；第二产程从宫口开全到分娩——依赖产次；而那个源自世界卫生组织的初产妇2小时、经产妇1小时的标尺，指的是“值得评估的延迟”、而不是自动的干预；以及第三产程胎盘——“用子宫的收缩药主动地处理、或按脐带的照护的规则生理地处理”——出血见产褥的那一章。进展是一条曲线、不是一个点：宫缩与“随时间变化宫颈的评估”定义了停滞——现代的“安全的照护”的框架是“在一位被良好监护、可以自由活动、被支持的女性身上，产程的进展在被证明之前都是慢的”；而“活跃期的斜率与每小时1.2厘米的下限”这一弗里德曼的遗产已被“为正常的变异等得更久、但要求对真正的停滞升级”的产程图所取代——分辨靠整个图景：宫缩与胎膜的状态及位置及镇痛及下降及母亲的疲惫及孩子的状况。胎儿的监护：间断的听诊是低风险的分娩中有证据的默认；持续的胎心监护在适应证时被提供在许多单位是催产素、以及发热与胎粪及生长受限及“剖宫产后的阴道分娩”、以及那位“已经决定继续”的母亲这一组，带着它诚实的记录——胎心监护是一项“高敏感度、低特异度”的检查，其预测值的算术意味着“几乎每一条图形的异常对于缺氧都是一次假阳性”；所以异常的意义存在于鉴别睡眠的周期与体位及母亲的体位与水化及下降时正常减速的模式，以及存在于趋势、加上“胎头取血的刺激与第二意见的相邻”。血气的取样“正在让位于与刺激与胎儿的取血的样本相邻”的实践、并在“剖宫产后的阴道分娩与生长受限”的场景中“最被需要”。这一整章的流行病学的锚：保密的调查与围产的审计的时代在“不良的产时的结局”中不断发现同样三个失败——“未能识别并升级异常的图形或母亲的恶化；未能对升级采取行动那个从决定到分娩在紧急的剖宫产中应当是30分钟、而在被诉讼的病例中有时是一个小时的延迟；以及在急期的决定周围的沟通的失败。三者都是人的因素的课题；而把它们修好的演练，正是接下来的这几节读起来像方案的理由——它们本来就是方案[[obstetrics-gynaecology/pregnancy-complications]]、[[paediatrics/newborn]]、[[clinical-skills/patient-safety]]。**
:::

## 引产与手术的分娩

::: definition 引产、加强宫缩与手术的分娩的决定 {#def-operative}
**引产：适应证分为母亲的高血压的疾病与糖尿病及子痫前期的时机、胎儿的生长受限与“配计划胎动的减少”及过期——“在37周到40周加之间提供引产”的足月的试验带来了如今被强化的证据：“朝向更少的死产、而剖宫产或小幅增加或不增加取决于试验”，这场辩论仍在沉淀进指南；以及社会的与物流的它本身从来不是适应证，而是“其他的被拖到晚些时候”的一个理由。方法——前列腺素的栓剂或地诺前列酮配如今“被广泛列出的米索前列醇阴道给药的替代”；球囊导管的时代；以及“对条件好的宫颈做人工的破膜加催产素”——全都带着“过度刺激与持续的监护”这一取舍，以及“为避免既往子宫的破裂”的细微差别。咨询的标准是：引产是一项“被建议的干预带着被说明的目的与被定义的复查的时点”、不是一道命令；而女性拒绝的理由值得被倾听，因为同一位女性“否则会在更糟的情形下在这里分娩”。加强宫缩：为“张力低的宫缩”用催产素，配“被定义的起始的剂量与滴定的表格及持续的监护”——因为“制造了过度刺激与缺氧的诉讼的那种药，也正是防止了一半因停滞而做的紧急的剖宫产的那种药”；技能在于方案的纪律，以及“当宫颈不肯动时”的资深者的复查。器械的分娩：标准是“宫口开全、胎膜已破、胎头已入盆且位置已知、充分的镇痛、排空的膀胱、一份包括失败时怎么办的被告知的计划”，以及“对这一情形称职的操作者”。产钳对吸引器的选择有证据的指导吸引器造成更少的母亲的损伤、产钳在特定情形下失败更少、以及“两次尝试后换第二种器械”的那条序贯的器械的规则“；而”该由谁做“的问题”取决于资深的者的在场、以及那位被叫来时能在一分钟内到位的人“。剖宫产：分级即刻威胁生命的对”分娩室的即时“的对”当天的“的对”择期的“，以及”为紧急的那种争取到30分钟的演练手术团队的激活；麻醉途径的决定——需要十分钟脊柱的麻醉对那只需要三分钟但带气道风险的全身麻醉——是一场被排练过的临床的判断，不是临场发挥“。以及那个”与剖宫产后阴道分娩相邻的真相“：每一次剖宫产都是”关于未来的妊娠的决定“——破裂的风险与”试产对重复的剖宫产“的数字、下一次妊娠的”胎盘植入的风险“；以及那份”把切除与粘连的可能性点出来“的同意谈话——因为在”率超过30%的国家里，剖宫产长期的病残率粘连与瘢痕处的妊娠及切除“是一桩”公共卫生量级的问题”[[obstetrics-gynaecology/pregnancy-complications]]、[[obstetrics-gynaecology/postnatal-period]]。**

## 产程中的急症

::: definition 肩难产与脐带脱垂及子宫的破裂 {#def-emergencies}
**肩难产：诊断是“那个在复位之后仍不分娩的胎头加龟缩的征”；处理是那套“记在心里”的顺序、并把演练变成真的——呼救（第二位助产士与儿科医师及麻醉师，以及“这栋楼里资深的产科医师）；抬腿先用”把腿贴向腹部的那一招“，因为它大多数时候管用；”耻骨联合上的压迫“；手法旋转——”两式旋转的手法“；”会阴的切开是为了空间、不是原则“；以及最后的手段清单”绕到背后的手法与有意地折断锁骨，以及四肢着地的姿势——后者越来越被当作第一线的，因为重力是免费的“。每一次演练都被点名的两个”时间关键的错误“：拉胎头与”宫底的压迫“，以及忘记时间——时钟要每分钟读出来、并记录”到分娩到胎头“的时长，因为”臂丛麻痹的索赔与缺氧的损伤的抗辩都系于这几分钟“。之后：为臂丛与骨折做新生儿的检查；对第三产程的警惕；以及与那位”被留下困惑的人“相比、”被告知那是九分钟，这是我们做的“的女性会更好地消化一次创伤。脐带脱垂：诊断是”可见或可触及的脐带伴突然深度的减速“；处理是”一套靠肌肉记忆执行的演练“——呼救、”戴手套的手把先露部向上顶助手的手、不是此后那位主刀的手“、经”三通的导尿管“充盈膀胱、”让母亲头低位“、用宫缩的抑制剂”让正在收缩的子宫松下来“；以及”在从产房到手术室的路上做出的分娩方式的决定“——”经最短的路径做即刻的剖宫产也许就是产房自己的手术室“，只有”宫口开全且胎头足够低时“才经阴道分娩。子宫的破裂：诊断常常靠图形、而不是靠疼痛——”在瘢痕子宫上突然胎心的减速或变异性的消失就是子宫的破裂，直到被证明别的“；而它最快被做出的是”当有人问出那个问题的时候“。没有瘢痕并不是百分之百的保护无瘢痕的破裂会发生——”宫底前置穿透性的胎盘与结缔组织的异常“；而瘢痕也不是一份判决”大多数的剖宫产后阴道分娩会成功，而破裂的风险大约在百分之零点五到百分之一之间“——正是这个数字决定了咨询的成败。统一的结构：三者都是演练；而演练的证据肩难产模拟训练的试验、以及产时出血的项目对结局的影响，就是“值班每年要拿出一个下午来练它们”的理由——[[emergency-critical-care/resuscitation]]、[[clinical-skills/patient-safety]]、[[obstetrics-gynaecology/pregnancy-complications]]。**
:::

::: example 那次凌晨四点的“胎心的过缓” {#ex-cord}
一名39周加2的经产妇、宫口7厘米、“为胎粪做了人工的破膜”；一圈脐带脱出；宫颈7厘米、“腹部可触及的胎头还有3/5”；胎心监护显示“长达55的持续的过缓”。
::: solution
**7厘米时的脐带脱垂（[[#def-emergencies]]）：最初的那六十秒决定了这个孩子——”手放进去、不要拿出来；句说清楚脐带脱垂、即刻的剖宫产、把剖宫产包和麻醉师带到我这儿来的升级的呼叫；按方案开始膀胱的充盈与宫缩的抑制剂的助产士；把母亲摆成能让那只手继续有效的体位；把时钟大声地启动；以及立刻做出的这是一台剖宫产的决定因为7厘米与一个高位胎头无法在图形死去之前经阴道分娩“。第二到第十分钟——”预先把一切摆好的产房手术室是演练在买这几秒钟；为速度做出的麻醉的决定——通常是带着困难的准备的气道的全身麻醉，或者如果它比孩子能承受得更快的脊柱的麻醉——由值班的那一对判断、并在事后由病历来说明理由；在转运同时刷手的效率；以及从一开始就站在旁边的新生儿团队因为一个胎心过缓的39周的孩子一出生就是一场阿普加的3到5分的谈话“。以及之后——”脐带的长度与受压的时长被记录；孩子脐带的血气与系列的神经的随访的警惕；与新生儿科讨论降温中心的阈值；以及当天为这位女性与团队做的复盘——她那边是因为她经历了一场黑暗中的手术，团队那边是因为那一晚唯一的表现指标就是从决定到分娩的时长，必须有人把这个数字写下来并从中学习“；以及下一次的妊娠的咨询：”复发的风险虽小但真实，分娩要被计划，而医院的产房的分级与深夜的路径要事先被确认“（[[paediatrics/newborn]]、[[clinical-skills/patient-safety]]）。**

::: example 那个“停下来的第二产程” {#ex-secondstage}
一名26岁的初产妇、硬膜的镇痛、“用力了两小时”、“在骨盆入口之上还有3/5”、“持续的后枕位”、宫口开全、宫缩变弱；胎心监护令人安心；她精疲力竭并说“直接把我剖开吧”。
::: solution
**停滞的第二产程（[[#def-labour]]、[[#def-operative]]）：在器械之前的评估——”这是停滞还是疲劳？重新核查（她真的开全了吗？位置真的是后枕位吗？膀胱是空的吗？硬膜的镇痛是否浓到把用力的感觉都消除掉了），因为答案会把计划从手术室改成再一个小时，支持宫缩并变换体位“——世界卫生组织式的界限是指南，而那位”生理性地慢但仍在进展的经产妇或用硬膜的病例“值得”带着被记录的理由的耐心“。决定的阶梯——”旋转的评估：一个在骨盆条件不好、用力两小时之后仍处在3/5的后枕位，做剖宫产的比率高于安全的旋转的产钳；而凌晨四点的住院医应当知道，诚实的话是我需要资深者在床边来定这件事、而不是我必须试一试什么；如果胎头够得着而位置可以被纠正并且有计划——遵守吸引器然后产钳的规则与两次尝试的上限、以及进展费力加可疑的不称的危险信号；而如果答案是剖宫产，是一台胎头在盆腔深处第二产程的剖宫产——是教科书中最难、出血最多的一种：把胎头向上推手法的知识、对产后出血的准备、以及说明为什么的同意“。以及她说出的那句话——”直接把我剖开吧是疲惫加一个合理的要求加一个问题；回答是如果那是最安全的，我们现在就可以做；先让我改变三样东西，看看你的身体是否同意——如果一小时后我们还在这里，答案就是手术“（[[clinical-skills/communication]]、[[obstetrics-gynaecology/pregnancy-antenatal]]）。**

::: example 那次凌晨三点的“从家中的转诊” {#ex-transfer}

::: exercise 处理那例过度刺激 {level=1}
::: solution
**过度刺激（[[#def-operative]]）：识别——”宫缩过频每10分钟多于5次或一次持续超过两分钟的宫缩，通常伴图形的改变：这就是过度刺激；在催产素与人工破膜之后它最常被预料到，也最可被预防“。三十秒——”停下催产素它的半衰期以分钟计——这是选择它的理由，也是它造成诉讼的理由；改变母亲的体位；给氧气只在血氧低时这一原则在这里同样适用；考虑宫缩的抑制剂以打断一次强直的收缩；并呼救——因为如果五分钟内不能缓解，你正在走向一台紧急的剖宫产“。以及之后的责任——”把时间记录下来：停止给药与宫缩变弱及分娩之间的间隔；因为对过度刺激与缺氧的复盘的核心问题永远是谁在什么时候注意到了子宫收缩得太紧，而当时为什么没有停下“（[[clinical-skills/patient-safety]]、[[pharmacology/dosing-principles]]）。**

**分娩的地点（[[#def-labour]]、[[obstetrics-gynaecology/pregnancy-antenatal]]）：证据——”对低风险的经产妇，在家或在生育中心的分娩带来更少的干预与相似的或更好的结局、但带着转运这一真实的可能；对初产妇，在家的计划伴随着明显更高的转运率，而生育中心处在一个中间的位置——而有合并症或引产或双胎或既往的分娩的创伤通常意味着选择并不存在“。被给出的不是数字而是风险——”把数字给她：转运的概率、在两种地点的她的种情形的紧急的剖宫产的概率、以及距离有分娩室单位的路程与时间——并且把孕周与体位及产次变数纳入“。连续性才是隐藏的那一项——”被承诺的那件事是同几个人陪着你，所以社区与产科之间的路径要为她而写：谁在半夜来、什么会让她被转走、以及她在半夜有权改变主意。“（[[clinical-skills/communication]]、[[public-health/health-systems-economics]]）。**

## 通向何处

“触发较晚分娩的”高血压的与胎儿的状态的决定在[[obstetrics-gynaecology/pregnancy-complications]]，第三与第四产程出血的管理在[[obstetrics-gynaecology/postnatal-period]]，新生儿复苏的接口在[[paediatrics/newborn]]，而“人的因素的教训”在[[clinical-skills/patient-safety]]。

::: history
**分娩的史是“谁在看着”的史。在大部分的历史里那是助产士与邻居——十八世纪的“男性的助产士”与随后“只被叫来处理困难的病例”的产科医师；把“作为某个家族的秘术”的产钳；以及“分娩的医院里那一场产褥的热的灾难”塞麦尔维斯在1847年的洗手的观察被忽略了一代人——它让“在医院里的分娩比在家更危险”，直到消毒与随后的麻醉把这笔算术翻了过来。然后是“监测与干预的工具”的登场：产后听诊的筒与“电子胎心监护的引入随之而来的是一场关于它究竟减少了什么——脑瘫还是剖宫产的辩论，它至今未息”；催产素的滴注与“引产的方案它们把一次分娩变成了一串需要被记录的时间”; 以及“在二十世纪后半叶从被忍受的变成作为一种权利被提供的分娩的镇痛的那条弧线”。而”最近的一段历史属于审计：把每一次的死亡与不良的结局变成一次关于监护与沟通的教训——保密的调查与国家的孕产妇与婴儿的审计，它们“发现了那三种失败、并给出了那一套演练与升级的方案”（[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]）。**
:::

::: summary
- 进展是“数小时之上的趋势”、不是一次单独宫颈的检查；现代的产程图等得更久而升级得更快。
- 胎心监护是一项“特异度很差的筛查的检查”：病理性意味着复查、纠正、再看、并升级——动刀决定用的是整个临床的图景。
- 引产与催产素是“带着方案的纪律的证据的工具”；“在足月引产”的辩论已从“绝不可”走到“提供并数清数字”。
- 器械分娩靠它的标准与“两次尝试的上限”活着；第二产程的剖宫产是产科中最难的手术，要求同样的敬意。
- 肩难产与脐带脱垂及破裂是演练的疾病——呼叫、体位、手法的顺序、时钟，以及“把分钟点出来”的复盘。
- 硬膜的镇痛与“一对一的照护”都是干预；证据支持提供前者并资助后者，而保密的调查关于人员配置说的是同一句话。
:::

## 练习

::: exercise 读这份胎心监护 {level=1}
::: solution
**三条图形（[[#def-labour]]）：（甲）正常模式的生理——“伴正常变异性的早期胎头压迫的减速”不是缺氧；继续常规照护并把分类记录下来。（乙）“可疑到病理性”——“变异极小加深长变异的减速”这一组合意味着“脐带的受压与一个不在代偿的孩子”：宫内的复苏体位、停下任何催产素、考虑宫缩的抑制剂、以及在母亲缺氧时给氧；在合适且可行时做“胎头的刺激或胎儿的取血”；现在就呼叫资深者；以及“按轨迹做出的分娩的方式的决定”——开全而胎头低就用器械、否则即刻的剖宫产。（丙）正常——以及那个教学要点：“一条令人安心图形买到的是让宫缩建立起来的时间，而不是从警惕中出院，因为真正要紧的那条图形是下一条——这一句就是胎心监护解读的总结”（[[obstetrics-gynaecology/pregnancy-complications]]）。**
:::

::: exercise 给“剖宫产后阴道分娩”做咨询 {level=2}
一名33岁有过一次“因产程进展失败做的子宫下段的剖宫产”无其他病史，在36周问“剖宫产后的阴道分娩是否值得”。请给出数字与告诫。
::: solution
**场“剖宫产后阴道分娩”的谈话（[[#def-operative]]）：数字——“在一次简单子宫下段剖宫产的情形中，成功的比率大约在60%到80%；句关于严重风险的话是：子宫的破裂发生在大约0.5%到1%的试产中，并伴随之的胎儿与母亲的风险；而“择期重复的剖宫产”的风险是外科的、以及胎盘的植入与未来的妊娠的——两条路都站得住；而诚实的比较不是更安全对更糟，而是不同的风险的形状“。修饰的因素——”因进展失败的病史会小幅降低成功的把握她自己产程的模式是最好的预测者；用前列腺素引产的问题需要“关于宫颈与催产素的那种特定的谨慎”；没有24小时手术室的生育中心这一问题自己就有答案对她不行；而持续的监护与有医师在场的要求，正是让在家试产成为一个不安全的想法的原因——这场谈话要温和地进行“。方法——”用带图形的频数给出数字；问她最希望避免什么与最希望得到什么既往产程的创伤与减少未来的盆腔的手术及亲密感与照顾年长孩子的理由都是正当的动机；明确地说出“计划包含产程中持续的监护与快速的通道到手室，而如果进展停下，我们先谈再动”；并把这场讨论连同她选定的计划一起记录（[[clinical-skills/communication]]、[[medical-ethics-law/consent-capacity]]）。**
:::

::: exercise 主持第三产程 {level=2}
一名37周的女性在“催产素加强宫缩”之后分娩了一个4.2公斤的婴儿；在胎儿娩出后12分钟，胎盘仍未剥离、子宫柔软，而患者面色苍白、脉搏112。请给出顺序。
::: solution
**正在出问题的第三产程（[[#def-labour]]、[[obstetrics-gynaecology/postnatal-period]]）：规则集——“胎盘滞留到”被定义的30到60分钟的阈值就要在手术室并在有麻醉的情况下取出；而这位“一边出血、子宫一边软、一边心跳加快”的女性现在就在产后出血的方案上——因为12分钟加上一只凝血不佳的子宫已经不再是一个看时钟的问题”。“双手的压迫与麦角新碱与催产素及卡前列素或那类氨甲环酸与米索前列醇的阶梯“与”两条大口径静脉的通路和血型的预留、以及晶体液限量而不是灌四升盐水“及”第二个人专门记录数量因为目测会谎报一半“并行推进。同时的念头——”胎盘滞留意味着手动取出的决定、而不是拉脐带；而4.2公斤加强化的宫缩这一混合让产后出血的其他病因处于活动状态：在稳定之后检查那份创伤的清单宫颈与阴道及与肛门括约肌损伤相邻的，以及那伪装成摸不到任何东西的柔软的子宫的内翻；那个其实属于其他原因的凝血病的念头；以及尽早的麻醉的呼叫——因为很晚才安定在手术室里的那位女性，就是会心跳停的那位“。以及结局的状态——”被量化的失血量被记录；被提供而不是被要求的高依赖的床位；Rh 阴性者的抗 D 的免疫球蛋白配母胎出血的量化；以及一份关于下一次妊娠的说明，以及复盘”（[[blood/haemostasis-bleeding]]、[[clinical-skills/records-handover]]）。**
:::

::: exercise 为硬膜外的问题做分诊 {level=2}
::: solution
**“胎心监护与器械的分娩的麻醉”（[[#def-labour]]、[[#def-operative]]）：第一——“位置与孩子的状态决定方式：一位胎心图形病理性的、而胎头已在会阴上的经产妇，可能是在产房里用局部浸润或用超短效的阿片做产钳的情形，而不是一台全身麻醉即刻的剖宫产；而在8厘米，是剖宫产，而追加还是脊柱的还是全身麻醉这一问题就是整个决定“。第二——”带着真实的时间的麻醉的决定阶梯：如果她来得及穿刺并起效就做脊柱的麻醉对接近第二级常常是对的；在分钟要紧时走带着饱胃的气道的团队全身麻醉的快速通道；以及快速的序列与环状软骨的压迫及最小的管子及双人的技术这一套纪律困难妊娠气道的指南正是为了把它刻进肌肉而存在；而对已有的硬膜外的追加只有在曾被验证过的工作的试验剂量与交感被阻断的核查之后才安全“。第三——”那位为上次的那一针而喊叫的女性有权听到那句诚实的话：最快的安全的做法是某个方案，而为了让麻醉安全我需要你的胃是空的——一边说一边手要动；她想要的那场镇痛的谈话，是团队今晚真能给的那一场“。之后——”复盘的记录写下麻醉的计划是什么以及为什么；为药物经过孩子准备的新生儿团队；以及第5天的泌乳与情绪的复查——它会抓住那位曾被麻醉过而现在仍在解释自己怎么了的女性”（[[surgery/anaesthesia-pain]]、[[clinical-skills/communication]]）。**

::: exercise 审计“从决定到分娩的间隔” {level=3}
::: solution
**间隔的改进（[[#def-labour]]、[[clinical-skills/patient-safety]]）：重构——“30分钟的目标不是官僚，而是一次急性缺氧事件的生物学窗口；而41分钟的中位数带一条70分钟以上的尾巴是两种不同的疾病：平均的问题流程的摩擦与尾巴的问题在方向盘上睡着的人“。治平均的办法——”由具名的人做出分级的决定值班的资深者或产房的分诊的一对，受过训练并有方案的辅助并记录时间；手术的激活由分级触发、而不是由麻醉师的到来触发；预先摆好剖宫产的器械包，以及排练凌晨三点的那条路的演练；以及当天复查每一台即刻的剖宫产，并把间隔写在病区的白板上可见的指标会改变行为“。治尾巴的办法——”把电话联系的升级换成现场或待命的资深的产科与麻醉的呼叫的模式；你可以为任何事打电话给我的文化被测量并被教授那位升级而没有受罚的助产士正是安全文化调查的结果变量；以及被从择期的手术的轮值中保护起来夜间的名单——间隔的那条尾巴就住在连续上下班的临床医师站着的地方“。公平与沟通的层——”把间隔与分级按族裔与语言报告：句她在抱怨而不是在描述会把一位不被相信的女性的分级压低”（[[public-health/determinants-inequalities]]、[[epidemiology-ebm/measuring-disease]]）。**
