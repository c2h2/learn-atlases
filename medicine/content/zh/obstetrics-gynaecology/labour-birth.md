分娩是一个由生理学解决的力学问题。一个横径约9.5 cm的胎头必须沿着一条弯曲的通道，穿过一个径线并不比它大多少的骨盆，推动它的是一块肌肉：这块肌肉收缩必须足够有力以将婴儿推出，又必须足够频繁地放松，好让血液到达胎盘。大多数情况下，这一切无需帮助就能完成。分娩期的照护就在于发现它何时对母亲或婴儿不起作用，并在恰当的时刻、而不是更早地进行干预。

本章解释分娩如何开始和进展、如何监测母亲和婴儿、镇痛的选择、引产和加速产程、手术助产和剖宫产，以及分娩期急症。本章中的英国实践遵循NICE NG235（《产时保健》，2023年）、NICE NG229（《分娩期胎儿监护》，2022年）、NICE NG207（《引产》，2021年）、NICE NG192（《剖宫产》，2021年）和RCOG指南。骨盆的解剖见[[anatomy/pelvis-perineum]]。

## 分娩是如何进行的

### 三要素

产程进展取决于三个因素，传统上称为**产力**（子宫收缩和母亲的用力）、**胎儿**（胎儿的大小、先露和方位）和**产道**（骨性骨盆和软组织）。分析产程缓慢时，要问是这三者中的哪一个出了问题。

**产力。** 分娩时子宫肌层以协调的波形收缩，从宫底附近开始向下扩散。每次收缩使肌纤维缩短，且不会完全恢复原长（**缩复**），因此上段增厚，而薄的下段和宫颈被向上牵拉并扩张。有效的产程通常每十分钟有三到四次宫缩，每次持续约一分钟。

**胎儿。** 必须通过骨盆的胎头径线取决于胎头俯屈的程度。

| 胎头姿势 | 先露径线 | 长度（约） |
|---|---|---|
| 充分俯屈的顶先露（枕前位） | 枕下前囟径 | 9.5 cm |
| 俯屈不良的顶先露（常为枕后位） | 枕额径 | 11.5 cm |
| 额先露 | 枕颏径 | 13 cm |
| 面先露 | 颏下前囟径 | 9.5 cm |

足月时额先露通常无法经阴道分娩；充分俯屈的枕前位胎头呈现最小的径线。胎方位异常，尤其是枕后位，是产程缓慢的常见原因。

**产道。** 骨盆入口以横径最宽，出口以前后径最宽，因此胎头以侧向的方位入盆，必须旋转到面向母亲背侧才能娩出。胎头的高低用两种方法描述：腹部检查时可在骨盆入口上方触及的胎头的五分之几，以及**胎头位置**，即胎头骨质最低点相对于坐骨棘的位置，以厘米表示（从上方的−3到下方的+3）。

### 分娩的启动

人类分娩的确切触发机制尚未完全了解。妊娠晚期，子宫从由孕酮维持的静息状态转变为活跃状态：子宫肌层获得缩宫素受体和使收缩得以扩散的缝隙连接，胎膜和蜕膜产生前列腺素，宫颈**成熟**——其胶原被重塑，使宫颈变软、变短并能够扩张。一旦分娩开始，宫颈和阴道受到牵拉，反射性地引起神经垂体释放缩宫素（**弗格森反射**），以正反馈的方式增强宫缩。

### 分娩机转

在典型的头位分娩中，胎头经历一系列动作，每一个动作都由骨盆的形状决定：

1. **衔接**：胎头最宽部分进入骨盆入口，通常为枕横位。
2. **下降**，贯穿整个产程。
3. **俯屈**：胎头遇到盆底时俯屈，呈现最小的径线。
4. **内旋转**：枕部向前旋转到耻骨联合后方（枕前位）。
5. **仰伸**：胎头在耻骨联合下方仰伸而娩出。
6. **复位和外旋转**：胎头转回与双肩对齐，双肩旋转进入出口的前后径。
7. **胎肩娩出**：前肩从耻骨联合下方娩出，随后后肩娩出，胎体随之娩出。

## 产程分期

::: definition 产程分期（NICE NG235） {#def-stages}
- **潜伏期（第一产程）**：疼痛性宫缩伴有一定的宫颈变化，包括宫颈管消退和扩张至4 cm。
- **活跃期（第一产程）**：规律的疼痛性宫缩伴宫颈自4 cm起进行性扩张。
- **第二产程**：从宫颈口开全到胎儿娩出。分为**被动期**（宫口开全但无不自主的排出性宫缩）和**主动期**（有排出性宫缩、胎头可见或主动用力）。
- **第三产程**：从胎儿娩出到胎盘和胎膜娩出。
:::

WHO（2018年）将活跃期第一产程定义为从5 cm开始，这反映了产程在此之前常常进展缓慢的证据。两种定义有同一个教训：一位处于潜伏期的妇女，如果被收入院并被期望按活跃期的速度进展，就有接受不必要干预的风险。

**进展与延迟。** 在活跃期，NICE建议在初产妇宫口扩张在4小时内少于2 cm，或经产妇进展减慢时怀疑第一产程延迟，同时还要考虑胎头的下降和旋转以及宫缩的变化。在第二产程，大多数初产妇预计在主动第二产程开始后3小时内分娩，大多数经产妇在2小时内分娩；初产妇主动第二产程达2小时、经产妇达1小时时诊断为延迟。

产程进展记录在**产程图**上，即宫口扩张对时间的图表，同时记录胎头下降、宫缩、胎心和母体观察指标。一种常见的设计是从活跃期第一次检查起画一条以每小时1 cm上升的**警戒线**，并在其右侧四小时处画一条平行的**处理线**。越过处理线时应进行评估，通常需要干预。WHO的《产程照护指南》（2020年）用宫口扩张每一厘米的时间限度取代了这些线。

一位26岁初产妇于22:00检查：宫口开4 cm，胎头腹部可触及3/5，每十分钟两次宫缩，胎膜未破。02:00时宫口开5 cm。胎心正常。是否存在延迟？如何处理？
::: solution
**评估。** 宫口在4小时内扩张了1 cm。初产妇4小时内少于2 cm提示活跃期第一产程延迟。每十分钟两次宫缩属于宫缩稀少，所以最可能的问题在**产力**。

**处理。** 按照NICE，提供人工破膜，两小时后复查。如果这两小时内进展仍少于1 cm，即确认延迟，由产科医生进行评估，通常会建议静脉滴注缩宫素以增强宫缩。一旦开始使用缩宫素，就需要持续CTG监护，因为更强的宫缩会减少胎盘血流。开始缩宫素之前应为她提供硬膜外镇痛，并检查她的体位、水化状态和膀胱。如果进展仍不理想，产科医生要重新评估是否存在胎方位异常（胎儿）或头盆不称（产道）。
:::
:::

### 第三产程

胎盘娩出可以是**生理性的**，即等待胎盘剥离并由母亲用力娩出；也可以是**积极处理**。积极处理是指给予宫缩剂（通常在前肩娩出时或胎儿娩出后不久肌注缩宫素10 IU），然后钳夹脐带（除非婴儿需要复苏，否则不早于一分钟），并在出现剥离征象后控制性牵拉脐带。积极处理使产后出血的风险大约减半，NICE推荐使用，但低风险妇女经讨论后可以选择生理性处理。积极处理超过30分钟、生理性处理超过60分钟时，第三产程即为**延长**。

### 会阴损伤

大多数阴道分娩的妇女都有某种程度的会阴损伤。裂伤按深度分类：

- **Ⅰ度**：仅累及皮肤。
- **Ⅱ度**：累及会阴肌肉，但未累及肛门括约肌。
- **Ⅲ度**：累及肛门括约肌复合体。**3a**：肛门外括约肌撕裂厚度小于50%；**3b**：大于50%；**3c**：肛门内括约肌也撕裂。
- **Ⅳ度**：累及肛门括约肌复合体和肛门黏膜。

Ⅲ度和Ⅳ度裂伤称为**产科肛门括约肌损伤（OASI）**。每次伴有会阴损伤的阴道分娩之后，都必须通过仔细的直肠检查来识别它们，由有经验的术者在手术室修补，并进行随访，因为未被识别的损伤会导致大便失禁。**会阴切开术**是有意切开会阴，需要时采用侧斜切开（偏离肛门的方向），例如在器械助产时。

## 胎儿监护

宫缩时流向胎盘的血液减少。储备良好的健康胎儿很容易耐受；胎盘功能不良的胎儿则可能发生缺氧。胎儿监护的目的是及时识别出后一组胎儿。

对于低风险妇女，NICE建议用手持多普勒或Pinard听诊器进行**间断听诊**：活跃期第一产程每15分钟在一次宫缩之后听诊至少一分钟，第二产程每5分钟听诊一次。存在危险因素时建议**持续胎心宫缩监护（CTG）**，例如子痫前期、FGR、胎粪、使用缩宫素、硬膜外镇痛、母体发热、既往剖宫产，或听诊发现异常。

::: definition CTG的特征 {#def-ctg}
- **胎心率基线**：10分钟内的平均心率，不包括加速和减速。正常为**每分钟110–160次**。
- **基线变异**：心率围绕基线的波动。正常为**每分钟5–25次**。长时间变异减少可能反映缺氧，但也见于胎儿睡眠和某些药物作用后。
- **加速**：升高每分钟15次或以上、持续15秒或以上。出现加速令人放心。
- **减速**：下降每分钟15次或以上、持续15秒或以上。**早期减速**与宫缩同步，反映胎头受压。**变异减速**起始和恢复都很迅速，反映脐带受压；它们很常见，除非持续时间延长或伴有其他改变，否则通常为良性。**晚期减速**在宫缩高峰之后开始，在宫缩结束后才恢复；反复出现时提示子宫胎盘功能不全。**延长减速**持续3分钟或以上。
:::

NICE NG229要求临床医生将CTG作为全面评估的一部分来解读，包括妇女的危险因素、产程阶段和进展以及随时间的变化，并将总体情况分为正常、可疑或病理性。**病理性**图形，例如持续的晚期减速伴变异减少，或延长的心动过缓，需要紧急处理：纠正可逆的原因（停用缩宫素、改变母亲体位、处理硬膜外麻醉后的低血压），如果图形没有改善，则加快分娩。心动过缓低于每分钟100次并持续3分钟或以上是产科急症。

::: warning 看起来正常的基线并不能排除缺氧
CTG要综合所有特征及其变化来评估。一个产程开始时基线为120、现在为150的胎儿，相对于其自身已经出现了心动过速，这可能是缺氧或感染的早期征象。同样，一个没有减速、但变异持续减少且没有加速的图形也可能是异常的。要回顾从监护开始以来的整个图形，而不只是最近10分钟。
:::

::: example 读一份监护图 {#ex-ctg}
一位正在静脉滴注缩宫素的初产妇宫口开7 cm。过去40分钟的CTG显示基线每分钟165次，变异每分钟3次，每次宫缩都伴有晚期减速。她的体温为38.0 °C。对图形进行分类并概述处理。
::: solution
**分类。** 每一项特征都异常：基线心动过速（高于160）、变异减少（低于5）和反复晚期减速。图形为**病理性**。伴有母体发热时，宫内感染很可能是原因之一，而缩宫素可能导致宫缩过频。

**处理。** 呼叫上级产科医生。停用缩宫素，让妇女取左侧卧位，检查血压，并处理发热和可能的脓毒症（培养，按当地指南使用抗生素）。由于图形为病理性且宫口未开全，如果不能迅速改善，应通过剖宫产加快分娩。新生儿团队应在场。在感染存在时出现异常CTG尤其令人担忧，因为感染会降低胎儿因缺氧而发生脑损伤的阈值。
:::
:::

## 镇痛

分娩疼痛来自子宫收缩和宫颈扩张（内脏纤维在T10至L1进入脊髓），在第二产程还来自阴道和会阴的牵拉（经阴部神经的躯体纤维，S2至S4）。镇痛选择包括：

- **非药物方法**：持续一对一的陪伴支持、水中浸泡、活动、呼吸技巧。
- **Entonox**（50%氧化亚氮与氧气混合），在宫缩时吸入；作用时间短，可引起恶心和头晕。
- **阿片类药物**，如肌注二醋吗啡（diamorphine）或哌替啶（pethidine），或患者自控的瑞芬太尼（remifentanil）。可引起母亲嗜睡和恶心，在接近分娩时使用可抑制婴儿呼吸。
- **硬膜外镇痛**：将局部麻醉药加小剂量阿片类药物输注到硬膜外腔。这是最有效的方法。它与第二产程延长和器械助产率升高有关，但与剖宫产率升高无关。并发症包括低血压、发热、运动阻滞过深，以及罕见的意外穿破硬脊膜引起的硬脊膜穿破后头痛。效果良好的硬膜外置管可以追加药物用于手术分娩，从而避免全身麻醉。

## 引产与加速产程

**引产**是指人工启动分娩。当继续妊娠的风险超过引产的风险时提供引产。最常见的原因是过期妊娠：NICE NG207建议从41+0周起讨论引产，因为足月后死产风险缓慢上升。其他指征包括子痫前期、糖尿病、FGR、足月胎膜早破以及某些母体疾病。

**Bishop评分**通过对宫口扩张、宫颈长度、质地和位置以及胎头位置评分，来评估宫颈对分娩的准备程度。评分6分或以下一般认为不利，8分或以上为有利。

| 评分 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 宫口扩张（cm） | 未开 | 1–2 | 3–4 | 5或以上 |
| 宫颈长度（cm） | 大于4 | 2–4 | 1–2 | 小于1 |
| 胎头位置 | −3 | −2 | −1或0 | +1或+2 |
| 质地 | 硬 | 中 | 软 | |
| 位置 | 后 | 中 | 前 | |

方法取决于宫颈情况。产检时进行**剥膜**，即用手指将胎膜与宫颈分离，可增加自然临产的机会。对不利的宫颈使用**阴道前列腺素E2**、口服米索前列醇（misoprostol）或**机械方法**（如球囊导管）促宫颈成熟。宫颈条件有利时，进行**人工破膜**，必要时随后**静脉滴注缩宫素**。药物引产的主要风险是**子宫过度刺激**，即宫缩过频或过长，会减少胎盘血流，可能导致胎儿窘迫。对既往剖宫产的妇女，前列腺素和缩宫素会增加子宫破裂的风险，因此常优先选用机械方法。

**加速产程**是指通过人工破膜或缩宫素加快已经开始的产程，如[[#ex-delay]]所示。

## 臀位

足月时约3%–4%的胎儿为臀位。对于臀位的妇女，在36周（初产妇）或37周（经产妇）提供**外倒转术（ECV）**，即通过腹部施压使胎儿转位，约一半成功。如果胎儿仍为臀位，可选择计划剖宫产，或在有经验的接生者协助下计划阴道臀位分娩。足月臀位试验（2000年）发现计划剖宫产的短期围产期并发症和死亡率较低，剖宫产因此成为通常的选择，但后来的随访和观察性数据使这一结论对经过仔细挑选的妇女有所缓和。

## 手术助产与剖宫产

### 手术阴道助产

**手术（器械）阴道助产**使用胎头吸引器或产钳协助第二产程，用于产程延迟、胎儿窘迫，或母亲不宜用力的疾病。在尝试之前，RCOG指南要求：宫口开全且胎膜已破，腹部可触及的胎头不超过五分之一，胎头方位确切已知，镇痛充分，膀胱排空，术者有经验，并且计划在没有进展时放弃尝试。胎头吸引器造成的母体会阴损伤较少，但失败更多，并与头颅血肿有关；产钳成功率更高，但造成更多的母体损伤，包括OASI。

### 剖宫产

在英格兰，现在十次分娩中有四次以上是剖宫产，而且比例仍在上升。非计划剖宫产的紧急程度用**分类**描述：

- **1类**：对妇女或胎儿的生命有即刻威胁（例如延长的心动过缓、脐带脱垂或子宫破裂）。目标是决定后30分钟内娩出。
- **2类**：母体或胎儿受到危害，但不会立即危及生命。目标是75分钟内娩出。
- **3类**：没有危害，但需要尽早分娩。
- **4类**：在适合妇女和团队的时间计划分娩。

剖宫产总体上是安全的，但有出血、感染、VTE、膀胱或肠道损伤的风险，恢复时间也更长。在以后的妊娠中，它会增加子宫破裂、前置胎盘和胎盘植入谱系疾病的风险。39周之前计划剖宫产出生的婴儿有更多的呼吸问题。

**剖宫产后阴道分娩（VBAC）。** 有一次子宫下段剖宫产史且无其他禁忌证的妇女，通常可以在计划VBAC和择期再次剖宫产之间进行选择。RCOG指南（2015年）给出的计划VBAC成功率约为72%–75%，子宫破裂风险约为1/200（0.5%）。子宫破裂是最严重的风险；再次剖宫产时子宫破裂更少见，但并非为零。建议分娩时持续CTG监护，出现延长的心动过缓或宫缩间歇期新出现的疼痛时，应紧急评估是否发生子宫破裂。

::: example VBAC的咨询 {#ex-vbac}
一位32岁妇女在第一次分娩宫口开6 cm时因胎儿窘迫行急诊剖宫产。她现在第二次妊娠36周，妊娠过程无并发症，询问是否可以尝试阴道分娩。在1,000位像她这样计划VBAC的妇女中，预计有多少人会经阴道分娩？有多少人会发生子宫破裂？
::: solution
成功率约为72%–75%，因此1,000位妇女中约有**720至750**位会经阴道分娩；其余的会在产程中行急诊剖宫产。子宫破裂风险约为0.5%，因此1,000位妇女中约有**5**位会发生子宫破裂。她上次剖宫产是因为胎儿窘迫而不是产程停滞，这与较高的成功率相关。

咨询还应涵盖VBAC的优点（恢复更快，如果成功，以后妊娠的并发症更少）、择期再次剖宫产的优点（日期计划好，子宫破裂风险极低）、如果在计划的剖宫产日期之前临产会怎样，以及需要持续CTG监护并在能立即进行剖宫产的医院分娩。决定由她作出，并应记录在案。
:::
:::

## 分娩期急症

产科急症单个看都很少见，并在数分钟内发生。团队通过定期演练进行培训，使用结构化流程和明确的角色分工，因为真实急症中的表现取决于演练。

::: definition 肩难产 {#def-dystocia}
**肩难产**是指头位阴道分娩中，胎头娩出后轻柔牵引失败，需要额外的产科手法才能娩出婴儿。其原因是前肩嵌顿于耻骨联合后方（或较少见的后肩嵌顿于骶岬）。它在约0.6%–0.7%的头位阴道分娩中发生。危险因素包括巨大儿、糖尿病和既往肩难产，但大多数病例发生在体重正常的婴儿，无法预测。
:::

RCOG的处理流程是：
1. **呼叫支援**：上级助产士、产科医生、新生儿科医生和麻醉医生。记下胎头娩出的时间。
2. **McRoberts手法**：将母亲的髋部强力屈曲并外展贴向腹部，使腰椎变平、耻骨联合向上旋转。停止用力。
3. **耻骨上加压**：从胎背一侧向前肩后方施压，使其内收并旋转到耻骨联合下方。
4. 如果以上方法失败，进行**阴道内手法**：娩出后臂或在阴道内旋转胎肩，如有助于操作可行会阴切开。另一种方法是让母亲转为四肢着地的体位。
5. 很少需要进一步措施，由资深人员实施。

必须避免用力牵拉胎头和按压宫底，因为它们会增加**臂丛神经损伤**（Erb麻痹）的风险，却毫无帮助。婴儿可能缺氧，需要新生儿评估。母亲有产后出血和会阴损伤的风险。

::: example 娩不出来的胎头 {#ex-dystocia}
一位34岁妊娠期糖尿病妇女在漫长的第二产程后娩出胎头。胎头回缩紧贴会阴（"龟缩征"），下一次宫缩和轻柔牵引都未能娩出胎肩。下一步应该怎么做？
::: solution
这是**肩难产**。助产士通过紧急呼叫系统呼叫支援，并清楚说明问题（"肩难产"），记下胎头娩出的时间。她让母亲停止用力，把床放平。两名助手实施**McRoberts手法**，同时一名助手从胎背一侧进行**耻骨上加压**，只用常规力度牵引。如果胎肩仍不能娩出，由最有经验的人实施**阴道内手法**，通常是娩出后臂。新生儿团队准备复苏，并采集成对的脐血标本。预见到产后出血，积极处理第三产程，仔细检查会阴和婴儿，并记录事件经过，包括哪一侧肩为前肩以及各个时间。向父母进行事后解释。
:::
:::

**脐带脱垂**是指胎膜破裂后脐带降至先露部以下。它发生在约0.1%–0.6%的分娩中，在先露部高浮或非头先露、羊水过多以及胎头高浮时人工破膜的情况下更常见。脐带受压和痉挛导致胎儿缺氧。在准备立即分娩的同时，处理是**解除脐带受压**：用阴道内的手或用生理盐水充盈膀胱将先露部向上推，并让妇女取膝胸卧位或头低的加强左侧卧位。尽量少触碰脐带以避免痉挛。通常通过1类剖宫产分娩，除非宫口已开全且能迅速阴道分娩。

**子宫破裂**表现为胎心率异常（常为延长的心动过缓）、腹痛、阴道出血、母体休克、胎头位置上升或宫缩停止。主要危险因素是既往剖宫产。它需要立即剖腹探查。

分娩中的**孕产妇心搏骤停/虚脱**鉴别诊断范围很广，包括出血、血栓栓塞、羊水栓塞、脓毒症、子痫、药物毒性（包括局部麻醉药毒性）和心脏疾病。复苏遵循标准原则并加以修改：用手将子宫推向左侧以解除主动脉-腔静脉压迫，由有经验的麻醉医生尽早插管，并在约20周以后，如果心搏骤停后约4分钟内循环未恢复，则娩出胎儿，目标是在5分钟内娩出。排空子宫可提高母体复苏的效果。见[[emergency-critical-care/resuscitation]]。

::: quiz
一位39周的妇女正在分娩，宫口开7 cm，胎头高浮。人工破膜后立即，CTG显示胎心率每分钟70次，在阴道内触及一段脐带。首先应采取哪项措施？
- [ ] 尝试将脐带送回子宫。
- [ ] 鼓励妇女用力以迅速经阴道分娩。
- [x] 呼叫支援，用手将先露部从脐带上推开，让妇女取膝胸卧位或头低的左侧卧位，同时准备1类剖宫产。
- [ ] 等待5分钟，看心动过缓是否缓解。
::: solution
这是伴有胎儿心动过缓的脐带脱垂。当务之急是通过上推先露部和调整母亲体位来解除脐带受压，同时安排1类剖宫产。不建议将脐带送回，而宫口开7 cm时不可能阴道分娩。延误有导致严重胎儿缺氧的风险。
:::
:::

::: history
在历史的大部分时间里，一次无法完成的分娩意味着母亲的死亡或婴儿的毁损。产钳由钱伯伦（Chamberlen）家族在十七世纪初发明，作为家族秘密保守了约一个世纪。1847年，爱丁堡的詹姆斯·扬·辛普森（James Young Simpson）首先用乙醚、然后用氯仿缓解分娩疼痛；1853年，约翰·斯诺（John Snow）在利奥波德王子出生时为维多利亚女王施用氯仿，使分娩镇痛被社会所接受。十九世纪末，马克斯·森格（Max Sänger）于1882年描述了缝合子宫壁的方法，剖宫产变得可以存活；随着无菌术、输血和抗生素的出现，它变得更加安全。1953年，弗吉尼亚·阿普加（Virginia Apgar）发表了评估新生儿的简单评分；1954年，伊曼纽尔·弗里德曼（Emanuel Friedman）发表了宫口扩张对时间的曲线图，这是后来由休·菲尔波特（Hugh Philpott）在非洲南部发展的产程图的基础。电子胎儿监护在1970年代普及，而后来的试验表明，它对低风险妇女的益处比人们设想的要小得多。
:::

## 后续内容

第三产程和产后数周的并发症，包括产后出血，见[[obstetrics-gynaecology/postnatal-period]]。使分娩成为高风险的疾病见[[obstetrics-gynaecology/pregnancy-complications]]。新生儿的评估和复苏见[[paediatrics/newborn]]，麻醉见[[surgery/anaesthesia-pain]]。

::: summary
- 产程进展取决于产力、胎儿和产道；分析产程缓慢时要问是哪一个出了问题。
- 充分俯屈的枕前位胎头呈现其最小径线（9.5 cm）；俯屈不良和枕后位使产程减慢，额先露通常不能娩出。
- NICE：活跃期第一产程从4 cm开始；初产妇4小时内扩张少于2 cm时怀疑延迟；初产妇主动用力2小时、经产妇1小时后诊断第二产程延迟。
- 低风险妇女采用间断听诊；有危险因素时需要持续CTG。正常基线为每分钟110–160次，变异为5–25次。反复晚期减速伴变异减少为病理性。
- 从41+0周起以及有母体或胎儿指征时提供引产；Bishop评分指导方法的选择。过度刺激是主要风险。
- 手术阴道助产要求宫口开全、腹部可触及胎头不超过1/5且方位已知。剖宫产的紧急程度分为四类；1类目标为30分钟内娩出。
- 计划VBAC约72%–75%的妇女成功，子宫破裂风险约为0.5%。
- 肩难产：呼叫支援、McRoberts手法、耻骨上加压，然后阴道内手法；避免用力牵拉和按压宫底。
- 脐带脱垂：解除脐带受压并紧急分娩。孕产妇心搏骤停：将子宫推向左侧，20周以后在骤停约5分钟内娩出胎儿。
:::

## 习题

::: exercise Bishop评分 {level=1 check="7"}
使用本章中的表格，计算以下宫颈的Bishop评分：宫口开2 cm，长1.5 cm，质软，位置居中，胎头位置−2。
::: solution
扩张2 cm得1分；长度1.5 cm得2分；胎头位置−2得1分；质软得2分；位置居中得1分。总分为$1 + 2 + 1 + 2 + 1 = 7$。这介于不利（6分或以下）和有利（8分或以上）之间；根据当地做法和产次，可能可以人工破膜，也可能仍选择促宫颈成熟。
:::
:::

::: exercise 裂伤的分度 {level=1}
产钳分娩后检查发现，裂伤累及会阴肌肉和约三分之二厚度的肛门外括约肌，肛门内括约肌和肛门黏膜完整。对裂伤进行分度并概述处理原则。
::: solution
肛门外括约肌撕裂超过50%，内括约肌完整：**Ⅲ度裂伤，3b级**。这是产科肛门括约肌损伤，应由有经验的医生在手术室、在良好的镇痛和照明下修补。通常给予广谱抗生素和缓泻剂，并随访有无肛门失禁，配合物理治疗。应与她讨论这一损伤及其对今后分娩的影响。
:::
:::

::: exercise 何时听诊 {level=1}
一位低风险妇女处于活跃期，选择了间断听诊。在第一产程和第二产程中，应多长时间听诊一次胎心、每次听多长时间？说出三项会让你建议改用持续CTG的发现。
::: solution
活跃期第一产程中，每15分钟在宫缩结束后立即听诊至少一分钟；第二产程中每5分钟一次。同时触摸母亲脉搏，以与胎心相区别。改用持续CTG的原因包括：胎心率超出每分钟110–160次或听到减速；明显的胎粪；母体发热或心动过速；新鲜阴道出血；需要使用缩宫素；硬膜外镇痛；或产程进展延迟。
:::
:::

::: exercise 到达处理线的小时数 {level=2 check="8"}
在图中的简化产程图里，产程首次记录于警戒线上的4 cm处，处理线位于警戒线右侧四小时。如果宫口以恒定的每小时0.5 cm扩张，多少小时后产程会到达处理线？
::: hint
处理线为$y = 4 + (t - 4) = t$（以厘米计，时间$t$以小时计）。产程沿$y = 4 + 0.5t$进行。
:::
::: solution
令$4 + 0.5t = t$，得$0.5t = 4$，$t = 8$小时。此时宫口开8 cm。以每小时0.5 cm的速度，产程在4小时后也已达到NICE关于怀疑延迟的阈值（4小时内少于2 cm），通常会在到达处理线之前就促使进行评估。
:::
:::

::: exercise 37周的臀位 {level=2}
一位第二次妊娠的妇女在37周时胎儿为臀位。她上一次是顺利的阴道分娩。你会讨论哪些选择？
::: solution
首先提供**外倒转术**，因为她是经产妇且已37周；约一半妇女成功，经产妇成功率更高，并发症率低（最常见的是一过性胎心率异常；罕见出血或需要急诊剖宫产，因此要在能进行剖宫产的地方施行）。如为RhD阴性需要给予抗D。如果外倒转失败或她拒绝，可选择**计划剖宫产**（通常在约39周）或在有经验人员的单位**计划阴道臀位分娩**。应告知她，在足月臀位试验中计划剖宫产与较低的短期围产期风险相关，告知剖宫产对她本人和今后妊娠的风险，以及如果她先临产会怎样。
:::
:::

::: exercise 选择器械 {level=2}
一位接受硬膜外镇痛的初产妇已主动用力2小时。胎头位置+2，腹部可触及0/5，为正枕前位；产瘤和颅骨重叠很轻。CTG正常。诊断是什么？手术阴道助产是否合适？开始之前必须做好哪些准备？
::: solution
初产妇主动第二产程2小时后，这是**第二产程延迟**。前提条件已满足：宫口开全、胎膜已破（需确认）、胎头腹部可触及0/5且位于+2、方位已知（正枕前位），产瘤和颅骨重叠很轻（不支持头盆不称）。经讨论并取得口头同意后，手术阴道助产是合适的。开始前：确认硬膜外镇痛充分，排空膀胱，必要时请新生儿团队到场，并制定计划：每次牵拉若无进展即停止（并在设定的牵拉次数后放弃）。对于低位枕前位胎头，胎头吸引器或产钳均可，选择取决于术者和具体情况。随后积极处理第三产程，并检查会阴损伤，包括OASI。
:::
:::

::: exercise 两种减速 {level=3}
比较CTG上的早期减速和晚期减速：它们相对于宫缩的时间、机制和临床意义。为什么变异减速随着时间推移可能变得令人担忧？
::: solution
**早期减速**随宫缩开始，在宫缩高峰时降到最低点，在宫缩结束时恢复。它们由胎头受压引起，后者触发迷走神经反射，通常为良性，多见于第一产程后期和第二产程。

**晚期减速**在宫缩开始之后才开始，在高峰之后降到最低点，在宫缩结束后才恢复。它们反映每次宫缩期间胎盘血流减少时胎儿氧合下降，由化学感受器感知。反复晚期减速提示子宫胎盘功能不全，尤其是伴有变异减少或基线上升时。

**变异减速**反映脐带受压，很常见。如果它们加深、持续时间延长（超过60秒）、恢复缓慢、伴有基线上升或变异减少，或在很长一段时间内伴随大多数宫缩出现，就会令人担忧。反复缺氧的胎儿会逐渐耗尽储备，首先表现为基线上升，然后是变异消失。解读时始终要考虑随时间变化的趋势和临床背景。
:::
:::

::: exercise 产房里的虚脱 {level=3}
一位38周的妇女在人工破膜后不久突然出现气促和意识模糊，随后虚脱。她面色苍白，摸不到脉搏。给出鉴别诊断和复苏的关键步骤，并解释如果没有反应为什么要娩出胎儿。
::: solution
**鉴别诊断。** 胎膜破裂或分娩前后的突然虚脱，常随后出现凝血功能障碍所致的出血，提示羊水栓塞。其他原因包括大面积肺栓塞、出血（包括隐性胎盘早剥或子宫破裂）、如有硬膜外置管则为局部麻醉药毒性、子痫、脓毒症、严重过敏反应，以及围产期心肌病或主动脉夹层等心脏原因。

**复苏。** 呼叫产科急救团队（包括上级产科医生、麻醉医生和新生儿科医生）和心搏骤停团队。按成人生命支持开始胸外按压和通气，并**用手将子宫推向左侧**以解除主动脉-腔静脉压迫。尽早建立气道（由有经验的麻醉医生实施，因有误吸风险），在膈肌以上建立静脉通路，并处理可逆的病因。如果约4分钟内循环未恢复，就地施行**复苏性子宫切开术**（濒死剖宫产），目标是在5分钟内娩出。

**原因。** 约20周以后，子宫压迫腔静脉和主动脉，使胸外按压的效果大打折扣。排空子宫可改善静脉回流和心输出量，因此娩出胎儿首先是对母亲的复苏措施；它也给婴儿最好的机会。
:::
:::
