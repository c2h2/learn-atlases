流行病学是人群的生理学：发病与患病是它的生命体征、研究设计是它的查体动作、偏倚是它的鉴别诊断。**这开篇一章提供测量与它们的算术——发病（累积发病与发病率、学生绝不该混淆的风险对比率之别）、患病及其决定因素（与发病和病程的稳态关系、筛查与生存含义）、人人都引用的率与比（相对风险、比值比、风险比、可归因与人群可归因分数带其因果政治）、及标准化装置（粗率对调整率、直接对间接标准化、为何国际比较多半是方法论）——外加筛查与接种各章所建立其上的生命统计与病例定义手艺。**

## 生命体征

::: definition 发病、患病及其关系 {#def-measures}
**患病率是某一时点患病的比例（时点患病率、期间患病率）；它是一张照片、而多数“X的负担”标题实际报告的就是它。发病率是危险人群随时间的新事件：累积发病（风险——一个比例、需要说明随访窗口）与发病率（人时分母、这就是为何它必须总是带窗口）。关系——稳态下患病近似发病乘平均病程——是本章最多产的一个公式：当发病上升、或人们存活更久而未愈时疾病的患病上升（HIV与心衰的患病悖论：治疗成功抬高了负担统计）、而筛查通过更早检出使诊断时的患病膨胀（筛查章对这一行的欠债）。危险分母是一种技能：分子需要人群（除以错误基数的“Y患者得X的风险”标题）、发病率计算需要人时卫生（“直到事件、死亡或退出前处于危险”的删失逻辑、它是生存章的序言）、而绝对对相对的区分统辖两者（风险翻倍而病罕见仍很小、常见风险降低5%是一间忙碌的门诊）。测量带有设计后果：累积发病适合固定队列、率适合动态人群、患病适合规划而发病适合因果、因为只有发病率在事件之前观察到暴露。临床转化到处都是：10年心血管风险是竞争风险模型的累积发病（忽略死亡作为竞争事件造成的过高估计）、需治数是绝对风险差的倒数（只报相对风险试验的长期欺骗）、而暴发的罹患率是暴露定义人群中的累积发病。测量层来得很早：病例定义（监测查寻中的敏感度特异度取舍）、诊断漂移与编码变更（编码潮造成的患病假象）、及变动的分母（移民、老龄化、及一个更好的检验造成的表观流行）。四个应灌输的永久问题：分子的定义是什么、分母的人群是什么、时间窗口是什么、比较是什么——这一反射能在每次媒体扭曲中存活。**
:::

## 比较人群

::: definition 率、比与因果算术 {#def-ratios}
**比较动物园、各有其生境：风险比（相对风险——直观、队列原生）、风险差（绝对——公共卫生真相信号与需治数之母）、比值比（病例对照的主力、逻辑回归的输出、及罕见病时对风险比的近似、其违反造成多数误读的文献——“比值比3其实是风险比1.6”一类）、率比（人时比较）、及风险比（瞬时率之比、其比例风险假设必须在讲单数字故事之前检验）。分数家族带着政策重量：暴露者中的可归因分数（暴露者疾病中可通过去除暴露而预防的比例）与人群可归因分数（依赖暴露患病率的人群份额）——带常设警诫：人群可归因分数算术继承其风险比的每一个混杂失败、所以它是解读不是实验。比与差的择取是分配政治：一个新治疗把常见风险减半会扩大高危与低危组之间的绝对不平等（预防不平等发现）、这就是为何公平审计如今出现在指南里。生存装置：Kaplan-Meier曲线（乘积极限估计、其随机删失假设、及试验悄悄犯下的信息性退出）、log-rank检验（一个自由度比较整条曲线）、中位对定点阅读问题（曲线交叉时的风险比）、及比例风险失效时的限制平均生存时间与其他摘要。跨人群率比较需要标准化、因为粗率把生物学与年龄结构混杂：国际“最佳癌症生存”排名多数测量的是人口学与诊断时尚、而医院结局联赛表先是统计工具后才成为质量陈述——漏斗图与小数字素养属于评价各章。**
:::

## 调整

::: definition 标准化、生命统计与有效计数 {#def-standardisation}
**标准化回答“这个地方是更病还是只是更老”之问。直接标准化把各组的年龄别率应用于一个共同标准人群（世界与欧洲标准传统）——直观、但它需要每组同样的细节。间接标准化把标准率应用于各组的结构以产出标准化死亡比（观察除以期望）、职业队列研究与医院结局表的引擎、带两个陷阱：不同结构人群之间的标准化死亡比彼此不可比、而期望率随参考人群变健康而漂移、使工业队列的比几乎自行下降。生命统计层：死因判定（直接原因链对促成状况逻辑、及使国际死亡数据成为一个法律与医学构造的根本死因选择规则）、登记完整度（出生与死亡未登记之处率无法存在——民事登记发展问题）、及定义不清原因垃圾编码（由疾病负担方法重新分配）。计数教训长存：守护分母（普查之间的人群估计、事实对法律人口问题、及扭曲小人群比较的移民调整错误）、分子（诊断能力、尸检与死因调查可得性、及伪装成时间趋势的疾病分类修订效应）、及危险人群（职业人时、健康工人效应、及粗率到死因特异率到标准化率的层级）。还有一条手艺要点：一个率就是一个模型——分子定义、分母、窗口与调整的择取编码着理论——而好的流行病学家在引用数字之前先陈述模型、这就是本课程评价所演练的习惯。**
:::

::: example 读这个标题 {#ex-headline}
一份新闻稿：“新零食习惯使肾癌风险翻倍、研究称。”来源是一项前瞻队列：10年中暴露组40000人中41例、非暴露组80000人中82例、报告为风险比2.0（95%置信区间1.3至3.0）。
::: solution
**四个问题加一个（[[#def-measures]]、[[#def-ratios]]）：绝对对相对：累积发病是41/40,000（每千1.0）对82/80,000（每千1.0）——翻倍活在带协变量调整的模型化人时比较里；10年风险差接近零而需要戒除的人数是天文数字。窗口：风险比2.0需要说明随访分布；一个十年研究第九年的“风险翻倍”对第二年什么也没说。比例风险：未报告曲线检查、所以单数字摘要是暂定的。混杂与测量：零食习惯如何测量、一次、在基线？暴露错分类通常把偏倚推向无效、这让一个来自粗糙暴露测量的2.0更不令人印象深刻而不是更；而反向因果（诊断前症状改变饮食）是常设替代。加一的那个：事件计数（共123例）——小数字不稳定、区间的宽度、及发表场所的先验。诚实的翻译：“在本队列中10年肾癌风险两种方式都约千分之一；相对信号大致真实而绝对风险极小；没人该为此改变饮食、尽管饮食作为肾风险标志值得自己设计更好的研究。”**
:::
:::

::: example 患病悖论 {#ex-prevalence}
贵卫生局糖尿病简报显示一个地区十五年间患病率增至三倍、而登记册新登记发病六年持平。公共卫生总监问流行是否“真实”。
::: solution
**分解之后再惊慌（[[#def-measures]]、[[#def-standardisation]]、[[endocrine/diabetes]]）：先看患病方程：发病持平而患病增至三倍意味着病程延长——诊断上（检出激增抬高了已登记池）与治疗上（生存改善；永不到来的治愈使患病上升、与HIV及心衰曲线同一算术）。分解：发病趋势（带危险分母自身变化——肥胖、老龄化、移民）、检出强度（筛查与病例发现年份、诊断码变更、诊断发病对疾病发病之问）、及生存（使人们留在登记册中的心血管与肾结局改善）。每个含义指向不同的卫生局行动：真实发病上升支持预防支出；检出驱动的上升支持报告中保持发病持平；生存驱动的上升支持并发症服务（视网膜、肾与足规划——成功要花门诊空间）。标准化陷阱：粗的地区比较在流行甚至被定位之前必须先做年龄标准化——一个地区新来的年长劳动力可能把标题年龄调整掉。诚实的简报：三条曲线（年龄标准化发病、患病、一年生存）、登记册完整度估计、及卫生局需要那句话：“流行有一部分是我们做对了；不是的那部分才是你的钱该去的地方。”**
:::
:::

## 通向何处

研究设计在[[epidemiology-ebm/observational-studies]]评价、其错误在[[epidemiology-ebm/bias-confounding]]；效应测量在[[epidemiology-ebm/statistics-for-clinicians]]重现；筛查的患病算术在[[public-health/screening]]；暴发率在[[public-health/communicable-disease-control]]；及评价实践在[[epidemiology-ebm/critical-appraisal]]。

::: history
**该领域的测量先由文书后由哲学家建成。John Graunt的死亡通报表（1662）把教区死亡记录变成第一个人群算术（“由烟与瘟疫”的死因累计与性别比观察）；William Petty的政治算术提议统计一切移动与花费之物。Halley的生命表使死亡率成为一个数学对象（Halley的布雷斯劳表、后来成为保险精算师的引擎）。十九世纪使计数工业化：Chadwick的卫生调查把死亡率算术用作控诉证据、注册总长的分类使死因成为一个统计问题（而“自杀对意外死亡”编码之辩提前150年预演了今天的争论）、而流行病学三位一体被组装起来：Snow的霍乱比较（1854年两水公司罹患率表作为第一个率比论证）、从磷毒性颌骨坏死到棉尘症的工业疾病（职业率表）、及卫生医官的地区患病统计。二十世纪使测量形式化：“队列对横断面”词汇、发病-患病-死亡关系的明确陈述（Greenwood与Major Greenwood学派）、“人时”装置（生命表与精算方法被引入流行病学）、及1950年代工业队列研究来的“标准化死亡比”传统。效应测量之争有自己的史学：从该领域最早辩论起的相对对绝对风险之争、由病例对照方法与逻辑回归建立的比值比帝国、及现代修正（“重新思考比值比”论文、风险差与需治数改革、及风险比的比例风险审计运动）。人口转型及其测量在二十世纪末成为一个全球规划：民事登记与生命统计强化议程、为未被计数死者的口头尸检方法、全球疾病负担工程（伤残调整生命年与混合方法的综合及其伤残权重之争）、及疫情的取证人口学时刻（使“数死者”成为头版方法之辩的超额死亡定义之争）。—— [[epidemiology-ebm/observational-studies]]、[[public-health/global-health]]。**
:::

::: summary
- 发病随时间在危险人群中数新事件（风险或率）；患病在某一时点数已有疾病；P ≈ I × D 解释了多数“负担上升”标题而真实风险毫无变化。
- 比不是差：相对风险卖座、风险差统辖（需治数是其倒数）、而人群可归因分数加上暴露患病率来制造——但其因果解读首先要求混杂一章的怀疑。
- 比值比在不该的时候被当作风险比传播（常见结局）、风险比很差地摘要非比例风险、而每个单数字效应测量都值得一次曲线检查。
- 比较人群需要标准化因为年龄结构不同：同等细节用直接标准化、小数字用标准化死亡比、两者都不在没有公布的假设。
- 死亡数据是被构造的：判定链、根本死因规则、登记完整度与分类修订都属于一个趋势的警诫清单。
- 分子、分母、窗口与比较是四个永久问题——本课程在后续每个设计上演练的数感反射。
:::

## 练习
::: example 翻倍的登记册 {#ex-registry}
一个地区卒中登记册报告20年间发病翻倍而死亡减半。两位顾问在读者来信版争论：一位主张流行、另一位主张假象。用测量工具箱裁决。
::: solution
**按各自比例两者都对（[[#def-measures]]、[[#def-standardisation]]）：要量化的假象通道：检出（卒中单元与影像时代的扩张、“短暂性脑缺血与轻型卒中如今被编码”效应、救护车改道与私立入院捕获变化）、分类（国际疾病分类编码漂移、死亡证明对出院诊断差异、及“尸检退场”效应在院内计数下降时抬高社区发病）、及分母（老龄化——最强的真实增加候选——移民、及危险人群估计）。流行的通道：真实的危险因素变化（肥胖与糖尿病患病、空气污染文献、及“更早起病”信号）。裁决方法：把发病序列年龄标准化、限制到首次入院与影像证实子集（最稳定的查寻）、随时间绘制轻对重病例分割（若翻倍全是轻型卒中就为检出庆祝）、并把发病与死亡及生存一起读（下降的病死率使患病上升、而长期生存使人均首次事件更罕见——竞争风险修正要紧）。裁决模板：“大约三分之二的翻倍是旧的计数与旧的人；65岁以下一个残余的真实增加经受住了调整、是预防规划的任务书。”社论教训：发病主张需要附上查寻审计、而读者来信版很少带上它们。**
:::
:::

::: example 讨人欢心的标准化死亡比 {#ex-smr}
一个工厂工人职业队列显示肺癌标准化死亡比对全国人群为0.8；厂医得出结论说工作场所是保护性的。识别两种偏倚并设计纠正分析。
::: solution
**健康工人与参照者（[[#def-standardisation]]、[[#def-ratios]]、[[public-health/environmental-occupational]]）：偏倚一、健康工人效应：就业人群在受雇时按健康被选择并靠持续胜任而留任、所以全国人群参考率低估其期望死亡（“所有事的标准化死亡比都是0.8”的签名——检查是否所有原因都低、就是破口）。偏倚二：参照者的选择（全国率混合了曾就业与从未就业者、并随去工业化漂移；正确的比较者是内部的）。纠正分析：队列内部的暴露反应分层（没有任何选择假象能干净产出的剂量反应）、就业时长层（健康工人留任偏倚随工龄增长——带自首次受雇时间滞后的“受雇时长”建模）、“同一工厂其他白领”参照者、若记录允许则吸烟数据调整（内部比较者部分处理的混杂通道）、及健康工人留任偏倚的滞后与删失处理（现代职业软件包处理的左截断与就业退出删失技术层）。沟通：0.8是一个有方向的假象——对照全国没有过多是弱证据；没有剂量反应才是更强的主张、且仅在暴露重建充分时。工会代表应得到同一句话：“我们无法从这个数字告诉你它安全；我们可以告诉你一个更好的研究会显示什么。”**
:::

## 练习

::: exercise 计算四个测量 {level=1}
一个10000人队列随访5年：100个新发疾病事件；基线时40人已患此病；结束时120人患病。计算累积发病、发病率、入组与退出的时点患病率、并说明每个假设。
::: solution
**带假设的算术（[[#def-measures]]）：累积发病：5年间100/9,960危险者（约1.0%；入组患病的40人离开分母——“处于危险”要求）。发病率：人时分母近似为9,960人乘5年减去事件损失时间（约49,600人年；确切数字需要事件日期——说明均匀风险近似）、得到约每1000人年2.0。患病率：入组40/10,000（0.4%）、退出120/10,000（1.2%；假设迁入与死亡净为零——一个值得脚注的假设）。然后教学要点：P ≈ I × D 大致校验（每年每1000中1.0乘约12年平均病程≈1.2%）、而若窗口、危险规则或人口核算变化，数字每一个都会变——这就是为何定义那一段要跟着数字一起走。**
:::
:::

::: exercise 修好标题 {level=1}
把这三句新闻改写成流行病学诚实但仍可读的句子：“咖啡致癌（风险上升30%）”；“糖尿病病例创历史新高”；“疫苗在试验中使死亡减半”。
::: solution
**带诚信的翻译（[[#def-measures]]、[[#def-ratios]]）：咖啡：“在本研究中、喝咖啡者这种罕见癌比不喝者多30%（10年间约每10000人中3例对4例）；绝对差别很小、关联不证明因果、而吸烟混杂与反向因果是有活力的替代。“糖尿病：”登记为糖尿病的人数创历史新高；因为发病持平而生存改善、这一上升多数反映更长的病程与更好的检出、不是今年更多的新发疾病。“疫苗：”在随机试验中、接种参与者在随访期间死亡率为安慰剂的一半（每10000人中12对24例死亡）；绝对获益取决于所考虑人群中死亡有多常见。”所演练的手艺规则：每个效应主张都说出分子、分母、窗口、比较、及产生它的设计——而符合约束的改写几乎从不如扭曲那么可引用、这就是流行病学家对好沟通收的税。**

::: exercise 选择测量 {level=2}
对每个情景选出你会主打的效应测量并为选择辩护：(a) 向患者咨询一种药的获益；(b) 决定是否资助一个筛查规划；(c) 估计戒烟能预防贵院慢阻肺入院的比例；(d) 比较两家医院的外科死亡率。
::: solution
**测量有受众（[[#def-ratios]]、[[#def-standardisation]]）：(a) 在她基线风险下的风险差与需治数（没有绝对的比就是操纵；她的数字来自她的风险、不是试验的平均）。(b) 来自一个效应输入既是比也是绝对的模型之每质量调整生命年成本（资助方需要每人群的绝对事件与贯穿的不确定度）。(c) 你的患者中的人群可归因分数（病例中暴露患病率版本对医院服务区域更干净）、带诚实的警诫：它假定因果、而若混杂被去除它会缩小。(d) 标准化死亡比或带漏斗图限值与病情严重度调整的直接标准化率（粗比较不可辩护；标准化死亡比对期望的模型必须说明其参考与其置信）、加小医院关于区间宽度的警告。元答案：测量跟随决策——个体选择要绝对值、人群规划要分数与率、而公平比较要标准化并公布其假设。**
:::

::: exercise 调和两项调查 {level=2}
贵国成人哮喘的两个患病估计相差三倍：一份问卷调查（12%）与基于健康档案的登记数据（4%）。解释两个数字背后的方法、及各自回答什么问题。
::: solution
**患病就是一种方法（[[#def-measures]]、[[#def-standardisation]]、[[respiratory/asthma-copd]]）：问卷的12%：“终生曾被告知加基于症状的定义使其膨胀（当前对终生对医生诊断定义层级）、而喘息表型问题抓到的是肥胖相关气促与病毒后喘息而不是哮喘；翻译与回忆在不同调查波次之间的差异也要紧。登记数据的4%：已记录诊断患病测量的是求医加编码加登记（“可见人群中的哮喘”问题：未治疗的、出院未编码的、私立照护不可见的）、而它恰好漏数有获取障碍的群体。所以答案：问卷估计症状体验患病（“哮喘流行病学”文献的国际哮喘与变应性疾病研究及欧洲呼吸队列时代与客观检测的可比性——显示问卷过度诊断的甲基胆碱子集研究）；登记估计系统内已诊断患病（服务规划的分母：配出的药、门诊负荷、重症哮喘候选比例）。调和方法：一个链接或验证样本研究（问卷阳性而肺功能正常的人量化缺口）、并把两个数字带定义一起报告、及给董事会的教学要点：“这8%的差就是你未诊断与过度诊断的人群、而两半都是临床工作。”**

::: exercise 设计生命统计升级 {level=2}
一个伙伴部门请你的公共卫生团队帮助改善死因数据。写出技术援助计划：法律层、判定链、编码装置、审计工具、及改进指标。
::: solution
**认真地数死者（[[#def-standardisation]]、[[public-health/global-health]]）：法律层——民事登记职责、埋葬与火化之前的死亡登记与火化许可、带死亡原因证明人资格标准的医学证明要求（“谁可以签证明”政策之问）、及电子登记的法律等同。判定链：第一部分链对第二部分状况的培训（“不要写心搏骤停”学派带其例子）、无医务人员在场之处的口头尸检系统、及暴力与未定死因的法医尸检与死因调查路径（登记官与验尸官模式比较）。编码装置：国际疾病分类实施（版本过渡及其通过双编码期管理造成的趋势断裂）、死因解读与自动编码（“垃圾码”与“无效条目”反馈环）、及死亡数据库与医院记录的链接（口头报告对医院记录的冗余消解）。审计工具：证明人层面的定义不清原因看板、再判定信度研究（病历对证明一致性抽样）、及抓住真实流行与编码洪峰的“红旗死因骤变”监测。指标：登记完整度、医学证明比例、垃圾码份额、及死因特异死亡与哨点监测一致性的比较。诚实的第一年：随着系统改善，已登记死亡预期会上升——经典的误读是为下降庆祝。**
:::

::: exercise 评价这个比 {level=3}
一项常见结局（基线30%）研究报告某暴露的比值比2.2并称之为“风险翻倍有余”。第二项在低基线（2%）人群中有同样2.2比值比的研究用同一说法。展开两者、然后说明比值比与风险比何时相差多少、带公式直觉。
::: solution
**“或”的背离一课（[[#def-ratios]]、[[epidemiology-ebm/bias-confounding]]）：算术：基线风险30%时、比值比2.2对应风险56.7%、风险比1.9、风险差27个百分点；基线2%时同样比值比给出风险4.2%、风险比2.1、风险差2.2个百分点。“翻倍有余”这一说法在罕见结局研究中大致正确、而在常见结局中两个方向的解读都是错的（风险比不到2、而公共卫生分量相差12倍）。公式直觉：比值比比较的是比、而当风险超过约10%时比快于概率——因此病例对照比值比在静默中要求罕见病假设才能作为风险比阅读；给评审者的校正公式存在（风险比=比值比/(1-基线风险+基线风险×比值比）。这树立的评价反射：在接受任何比之前先问基线风险（需治数与需害数都需要它）、检查回归实际打印的是哪个测量（逻辑比值比被作为相对风险呈现是医学文献中最常见的单一错误）、并记住对数线性对逻辑模型的选择是一个有解读后果的建模决定（修正泊松与对数二项补救）。论文级的收尾句：没有分母的比是修辞；比值比是一个数学上便利的量、必须被翻译、不能被引用。**
:::

::: exercise 审计疫情数字 {level=2}
在一次呼吸道疫情早期、A国报告400例死亡而B国报告4000例；评论称B国疫情严重十倍。写出列出一切可能误导比较之理由的统计警诫备忘录、及你会构造的更好测量。
::: solution
**比较不可比之物（[[#def-standardisation]]、[[#def-measures]]）：误导清单：死因判定政策（仅确诊对疑似与超额定义——“超额死亡”文献正因这一点而存在）、检测覆盖（未检测的死者被漏计）、人口与结构差异（年龄、共病患病、家庭密度、职业——任何比较之前一切需要标准化的东西）、医疗获取差异（在家对在医院死亡改变判定）、计报日期对死亡日期的延迟（报告滞后的“流行曲线假象”）、人群分母（旅游、移民、小目的地的“游客心脏病发作”效应）、及报告的政治经济学（没有统计调整能修的“少报激励”治理变量）。更好的测量：年龄标准化周全因死亡对基线年（超额死亡标准、对判定稳健但对病因盲目）、检测阳性率加权的感染估计（血清流行病学调查）、及可比子人群内部的人均率（市对市、区对区、结构相似之处）。备忘录的收尾规则：报告超额死亡的比、而不是具名死亡的计数；并在同类系统之前先比较同类结构——这就是多数关于疫情能力的说法跳过的部分。**
:::

::: exercise 正确地教需治数 {level=3}
为住院医师设计一场30分钟的绝对与相对效应课、使用他汀一级预防数字。包括演算、使其顿悟的图、及每种框架各自诚实的临床情景。
::: solution
**需治数工作坊（[[#def-ratios]]、[[clinical-skills/communication]]、[[cardiovascular/coronary-artery-disease]]）：演算核心：一名55岁10年心血管风险11%者；他汀按每毫摩尔低密度脂蛋白降低约25-30%相对风险（荟萃分析）——10年绝对获益约3个百分点、需治数约30；她65岁风险31%的兄弟得到约9个百分点、需治数11；框架之问：“他汀把心梗减少四分之一”对两人都真而对两人都无意义。让人顿悟的图：治疗前后两个风险分布叠加、显示移动的曲线与其间的小面积——“人群移动对个体治疗”的Rose图、它同时预告预防不平等结果（移动曲线会扩大两端之间的绝对差距）。诚实情景：相对风险适合机制与药物比较的正确主打（生物学是乘性时，比在基线之间的传播好于绝对值）；绝对风险适合知情同意、去实施、及资源谈话的正确主打；而需害数必须坐在需治数旁边（肌痛与糖尿病数字带各自的绝对值、否则这场练习就是说服戏剧）。评估：给他们一份只有一个比而缺一个分母的新闻稿；他们必须产出它可能隐藏的需治数范围。收尾句：“一个比是一种关系；一个绝对值是一个人——处方发生在人身上。”**
:::
