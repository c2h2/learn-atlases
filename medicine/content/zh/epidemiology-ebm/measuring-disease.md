某地区报告有300名多发性硬化患者，今年新确诊12例。一份报纸说某种癌症的死亡“翻了一番”。一份药品说明书说某种不良反应“常见”。这些说法都是对疾病的测量，而每一种都可能因计数的对象、人群和时间段不同而含义迥异。

流行病学从计数开始。在追问吸烟是否导致肺癌、某种药物能否预防卒中之前，我们需要精确的方法来说明疾病有多少、新病例出现得有多快。本章建立这套词汇：患病率、发病率、死亡与生存指标、标准化，以及比较两组人群的指标。后续各章会用到其中的每一个术语。

## 病例的计数 {#counting}

每一个疾病频率指标都是一个分数。分子计数病例，分母计数可能成为病例的人。阅读流行病学数字时的大多数错误，都源于没有追问分数两边各是什么。

::: definition 病例定义与危险人群 {#def-case}
**病例定义**是一个人被计为患有某病所必须满足的一组标准。它可以基于临床表现（症状与体征）、实验室检查或两者结合，并常分为不同的确定程度，如*疑似*、*很可能*和*确诊*。

**危险人群**是在观察期内有可能发生该病的一组人。已患该病或不可能患该病的人，应从发病指标的分母中排除。
:::

两个例子说明两部分都很重要。做过子宫切除术的女性不存在宫颈癌的风险，把她们算入分母会降低表观发病率。又如，监测系统若改变病例定义，比如从“培养确诊”改为“培养或PCR确诊”，病例数可能骤增，而人群中其实什么也没有变化。当计数突然跳升时，首先要问的总是：定义、检测方法或报告方式是否改变了。

## 患病率 {#prevalence}

::: definition 患病率 {#def-prevalence}
**患病率**是某一时间人群中患有该病者所占的比例：

$$
\text{患病率} = \frac{\text{患病人数}}{\text{人群总人数}}
$$

**时点患病率**指某一时刻（例如1月1日）的患病率。**期间患病率**计入在一段时间内（例如过去12个月）任何时候患病的所有人。患病率是一个比例，没有单位，介于0与1之间，但常写成百分比，或每1000人、每10万人中的人数。
:::

患病率描述疾病负担。它告诉卫生服务机构有多少人需要糖尿病门诊、要采购多少吸入器、有多少病床被痴呆患者占用。横断面调查测得的正是患病率，因为调查是在某一时点观察人群。

患病率并不告诉我们风险。一种疾病患病率高，可能是因为它容易发生，也可能是因为人们带病生存的时间长。2型糖尿病，以及在抗逆转录病毒治疗可及性好的国家中的HIV感染，患病率高主要是因为患者能带病生存数十年。而一种迅速致死的癌症可以发病率高、患病率低。

## 发病率 {#incidence}

发病指标测量的是*新*病例的发生。它有两种形式，回答的问题不同。

::: definition 发病：风险与发病率 {#def-incidence}
**累积发病率**，即**风险**，是起初未患病的人群在规定时期内发生该病的比例：

$$
\text{风险} = \frac{\text{期间新发病例数}}{\text{期初危险人群人数}}
$$

风险是一个概率，必须同时注明时间段（“10年心肌梗死风险为12%”）。

**发病率**（incidence rate）用新发病例数除以危险中的**人时**总数，即每个人在未患病状态下被观察的时间之和：

$$
\text{发病率} = \frac{\text{新发病例数}}{\text{危险人时总数}}
$$

其单位是“每人年”（或每1000人年等）。率不是概率。它描述新病例出现得多快，正如速度描述走过距离有多快。
:::

当每个人都被随访相同时间时，例如在短期试验或一次暴发中，风险是自然的指标。当人们在不同时间进入和离开观察时，就需要用率：有人晚登记，有人迁走，有人死于其他原因，有人发生结局从而不再贡献危险时间。人时法统一处理了这些情况，每个人只按其实际被观察且处于危险中的时间计入。

::: example 透析单元中的人时 {#ex-persontime}
某透析单元对40名患者随访最多2年，以测量导管感染的发生。30名患者完成2年随访且未感染。6名发生感染，平均在第1年时。4名在6个月时转往其他单元，当时未感染。计算发病率，并解释为什么“40人中6人”不是令人满意的答案。
::: solution
把危险时间加起来：

- 30名患者 × 2年 = 60人年
- 6名患者 × 1年 = 6人年（每人在感染时停止贡献时间）
- 4名患者 × 0.5年 = 2人年

总人时 = 68人年。发病率为$6/68 = 0.088$每人年，即约每1000人年88例。

6/40 = 15%这一数字把4名转出患者当作已被随访满2年且一直未感染。我们并不知道这一点，他们转出后可能发生了感染。人时法恰好使用我们掌握的信息，不多也不少。
:::
:::

::: warning “率”不是“比例”的同义词
报纸以及许多论文把任何分数都称为“率”：“患病率”“病死率”“罹患率”。严格地说，率的分母中含有时间。8%的患病率不是率，5年风险12%也不是。比较研究时这一区别很重要：每1000人年10例的率与10%的10年风险不是同一个量，只有在结局不常见时二者才近似一致。读到“率”时，请检查单位；如果没有时间单位，它就是一个比例。
:::

## 发病率与患病率的联系 {#linking}

把人群想象成一个浴缸。新病例以发病率从水龙头流入；病例通过痊愈或死亡从排水口流出。任一时刻浴缸中的水就是患病者池。如果龙头和排水口都保持稳定，水位会稳定在流入等于流出的位置。

::: theorem 患病率、发病率与病程 {#thm-prev-inc}
在一个稳定人群中，若发病率$I$与平均病程$D$不随时间变化，则

$$
\frac{P}{1-P} = I \times D
$$ {#eq-prev-odds}

其中$P$为患病率。当疾病不常见（$P$低于约10%）时，$1-P$接近1，于是

$$
P \approx I \times D.
$$ {#eq-prev-approx}
:::

::: proof
设人群有$N$人，其中$NP$人患病，$N(1-P)$人未患病。新病例只发生在未患病者中，因此每年新病例数为$I \times N(1-P)$。病例以每例每年$1/D$的速率因痊愈或死亡而结束，因此每年离开患病者池的人数为$NP/D$。

在稳态下流入等于流出：

$$
I \, N(1-P) = \frac{NP}{D}.
$$

两边同除以$N(1-P)$再乘以$D$，得$P/(1-P) = I D$。当$P$很小时，$P/(1-P) \approx P$，即得近似式。
:::

这一关系解释了几个出人意料的现象。一种能延长生存而不能治愈的治疗会*提高*患病率，因为$D$增加了。有效的抗逆转录病毒治疗问世后的HIV就是如此，随着生存改善，许多癌症也是如此。反过来，一种疾病患病率下降，可能是因为发病的人少了，也可能是因为患者死得更快了。仅凭患病率无法区分这两种情况。

::: example 由发病率和病程推算患病率 {#ex-prevalence}
在一个虚构人群中，某慢性病的发病率为每1000人年4例，患者平均带病生存20年。假定处于稳态，估计其患病率。
::: solution
$I = 0.004$每年，$D = 20$年，故$I \times D = 0.08$。

近似式给出$P \approx 0.08$，即8%。

精确关系给出$P/(1-P) = 0.08$，故$P = 0.08/1.08 = 0.074$，即7.4%。

由于该病并不罕见，近似式略微高估了患病率。两个答案都依赖稳态假设；如果发病率在上升、生存在改善，或迁移改变了人群，这一假设就不成立。
:::
:::

## 死亡与生存 {#mortality}

死亡是记录最可靠的健康事件，死亡统计是流行病学中最古老的数据。常用的指标有好几种，它们的分母各不相同。

::: definition 常用死亡与生存指标 {#def-mortality}
- **粗死亡率**是一年内死亡人数除以年中人口数，通常以每年每1000人或每10万人表示。
- **死因别死亡率**只计入某一原因的死亡，分母相同。
- **病死率**（case fatality）是患某病者在规定时期内死于该病的比例。其分母是病例，而不是全人群。
- **婴儿死亡率**是同年每1000例活产中未满1岁死亡的人数。
- **孕产妇死亡比**是每10万例活产中孕产妇死亡的人数。
- **5年生存率**是确诊某病者5年后仍存活的比例。**净生存率**（或相对生存率）将其与同年龄、同性别一般人群的预期生存相比较，从而扣除其他原因造成的死亡。
:::

病死率与死亡率常被混淆。设一个5万人的小镇发生一次暴发，有400例病例、12例死亡。病死率为12/400 = 3%：它描述的是感染者面临的危险。这次暴发造成的死亡率为12/50,000，即每10万人24例：它描述的是对全镇的影响。一种疾病如果感染的人很少，可以病死率高而人群死亡率低，反之亦然。

生存数字同样需要小心。从确诊时起算的生存期会因确诊提前而变长，即使死亡日期完全没变。这就是**领先时间偏倚**，在[[epidemiology-ebm/bias-confounding]]中讨论；这也是为什么筛查项目要用死亡率而不是确诊后生存来评价。

当研究对象被随访的时间长短不一时，生存用**Kaplan–Meier法**估计。随访时间在每次死亡处被分段。在每次死亡时，挺过该时刻的概率等于存活者人数除以仍在观察中的人数。把这些概率相乘就得到生存曲线。存活离开研究的人被**删失**：他们在离开之前计入分母，之后退出。该方法以及比较两条曲线所用的风险比，见[[epidemiology-ebm/statistics-for-clinicians]]。

## 公平地比较人群：标准化 {#standardisation}

粗死亡率主要受年龄支配。一个满是退休者的海滨小镇，粗死亡率会高于大学城，即使海滨小镇每个年龄组都更健康。要比较年龄结构不同的人群，就需要标准化。

::: definition 直接标准化与间接标准化 {#def-standardisation}
**直接标准化**把每个研究人群的年龄别死亡率应用于同一个**标准人口**（例如2013年欧洲标准人口）。所得的**年龄标准化率**是该人群若具有标准年龄结构时应有的率。直接标准化要求每个人群都有可靠的年龄别率。

**间接标准化**方向相反。它把参照人群（常为全国）的年龄别率应用于研究人群的年龄结构，得出**期望**死亡数。**标准化死亡比**为

$$
\text{SMR} = \frac{\text{观察死亡数}}{\text{期望死亡数}},
$$

常乘以100表示。SMR为100表示死亡水平与其年龄结构的预期相符；150表示死亡比预期多50%。当研究人群较小、其自身的年龄别率不稳定时，采用间接标准化。
:::

::: example 两个小镇 {#ex-direct}
两个虚构小镇各有1万居民。它们的年龄结构和年龄别死亡率（每年每1000人死亡数）如下：

| 年龄组 | A镇人口 | A镇死亡率 | B镇人口 | B镇死亡率 | 标准人口 |
|---|---|---|---|---|---|
| 45岁以下 | 2,000 | 1 | 6,000 | 1.5 | 5,000 |
| 45–64岁 | 3,000 | 5 | 3,000 | 7 | 3,000 |
| 65岁及以上 | 5,000 | 40 | 1,000 | 50 | 2,000 |

比较粗死亡率和年龄标准化死亡率。
::: solution
**粗死亡率。** A镇死亡$2 + 15 + 200 = 217$人，粗死亡率为每1000人21.7。B镇死亡$9 + 21 + 50 = 80$人，粗死亡率为每1000人8.0。A镇看起来糟糕得多。

**直接标准化率。** 把每个镇的率应用于1万人的标准人口：

- A镇：$5 \times 1 + 3 \times 5 + 2 \times 40 = 100$人死亡，即每1000人10.0。
- B镇：$5 \times 1.5 + 3 \times 7 + 2 \times 50 = 128.5$人死亡，即每1000人12.85。

标准化之后，B镇的死亡水平更高。B镇每个年龄别死亡率都高于A镇。A镇粗死亡率高完全是因为其人口偏老。这里年龄起着混杂因素的作用，它是一个同时与“暴露”（住在A镇）和结局（死亡）相关的第三因素。混杂是[[epidemiology-ebm/bias-confounding]]的主题。
:::
:::

::: example 职业人群的SMR {#ex-smr}
一个由8000名工厂工人组成的虚构队列在一年中记录到45例死亡。全国死亡率（每年每1000人）在20–39岁为0.8，40–59岁为4，60–64岁为12。该队列在这三个年龄组分别有4000、3000和1000名工人。计算SMR。
::: solution
按全国死亡率计算的期望死亡数：

- $4{,}000 \times 0.8/1{,}000 = 3.2$
- $3{,}000 \times 4/1{,}000 = 12$
- $1{,}000 \times 12/1{,}000 = 12$

期望死亡合计27.2。SMR $= 45/27.2 = 1.65$，即165。工人的死亡比全国同龄人多约65%。

解释这一结果需要谨慎。工人通常比一般人群*更健康*，因为病重的人往往没有工作。这种**健康工人效应**会把职业人群的SMR压到100以下，所以165比表面看来更为突出。此外，不同队列的SMR不宜直接相互比较，因为每个SMR都是按其自身年龄结构标准化的。
:::
:::

## 比较组别：关联指标与影响指标 {#association}

大多数流行病学问题都是比较暴露组与非暴露组。比较有两种方式：相除，得到相对指标；相减，得到绝对指标。

::: definition 关联与影响的指标 {#def-association}
设$R_1$为暴露组的结局风险，$R_0$为非暴露组的风险。

- **危险比**（相对危险度）为$RR = R_1/R_0$。**率比**是用发病率计算的同类指标。
- **危险差**（绝对危险差）为$RD = R_1 - R_0$。
- 结局的**比值**（odds）为$R/(1-R)$。**比值比**为

$$
OR = \frac{R_1/(1-R_1)}{R_0/(1-R_0)}.
$$

- **暴露者归因分数**为$(RR-1)/RR$：若关联是因果性的，暴露者中的病例有多大比例在没有暴露时不会发生。
- **人群归因分数**是人群全部病例中，没有该暴露就不会发生的比例。设$p$为人群中暴露者的比例，

$$
PAF = \frac{p(RR-1)}{1 + p(RR-1)}.
$$
:::

比值为1、差值为0都表示无关联。危险比为2表示暴露者的风险是非暴露者的两倍，但它没有说明任一风险有多大。

相对指标描述关联的*强度*，是病因研究的通用语言。绝对指标描述效应对个人和卫生服务的*大小*。需治人数就是危险差的倒数，在[[epidemiology-ebm/statistics-for-clinicians]]中展开。

::: example 一个队列，五个数字 {#ex-cohort-measures}
在一个虚构队列中，200名接触某种溶剂者和800名未接触者被随访5年。接触者中30人、未接触者中40人发生某种肝病。计算RR、RD、OR、暴露者归因分数和人群归因分数。
::: solution
$R_1 = 30/200 = 0.15$，$R_0 = 40/800 = 0.05$。

- $RR = 0.15/0.05 = 3$。
- $RD = 0.15 - 0.05 = 0.10$：5年内每100名接触者多出10例。
- $OR = (30/170)/(40/760) = 0.1765/0.0526 = 3.35$。由于结局并不罕见，OR比RR离1更远。
- 暴露者归因分数$= (3-1)/3 = 2/3$。若该关联是因果性的，接触溶剂的工人中约三分之二的病例在没有该溶剂时不会发生。
- 这里队列本身就是人群，$p = 200/1{,}000 = 0.2$。$PAF = 0.2 \times 2/(1 + 0.2 \times 2) = 0.4/1.4 = 0.286$。验证：总体风险为$70/1{,}000 = 0.07$，而$(0.07 - 0.05)/0.07 = 0.286$。消除该暴露可预防约29%的病例。
:::
:::

::: example 解读新闻标题 {#ex-headline}
一份报纸报道某种新型口服避孕药使静脉血栓栓塞风险“翻倍”。在其所依据的虚构研究中，使用旧药者的年风险为每1万名女性2例，使用新药者为每1万名女性4例。临床医师应如何向一位正在选择避孕药的女性解释？
::: solution
相对危险度为$4/2 = 2$，所以标题是准确的。危险差为$4 - 2 = 2$，即每年每1万名女性2例。换言之，如果1万名女性改用新药一年，大约会多出2名女性发生血栓。

两个数字都是真实的，也都需要。相对危险度显示该药对凝血确有作用。绝对风险显示这一作用对一名女性一年来说有多小，并且可以与其他选择的绝对风险对照，包括妊娠期远高于此的血栓风险。只呈现相对变化往往会夸大危害和获益，因此好的患者信息会给出绝对数字，最好用自然频数表示（“1万人中2人”）。
:::
:::

- [ ] 不可能改变，因为患病率只取决于发病率。
::: solution
患病率同时取决于发病率*和*病程（[[#thm-prev-inc]]）。如果发病率不变而人们带病生存更久，平均病程$D$增加，患病者池就会扩大。因此，患病率上升本身并不能证明一种疾病变得更常见了。
:::
:::

## 数据来源 {#data}

流行病学指标的质量取决于其背后的数据。在英国和大多数高收入国家，主要来源有：

- **生命登记**：出生和死亡，死因根据死亡证明按国际疾病分类（ICD）编码。
- **人口普查**：大多数人群率的分母。
- **疾病登记**：癌症登记、先天异常登记等，力求收录特定地区的每一例新病例。
- **报告与监测系统**：用于传染病，由临床医师和实验室报告。
- **常规卫生服务数据**：住院记录、初级保健记录和处方数据。这些数据内容丰富，但其收集目的是诊疗而非研究，因此诊断可能不完整或编码不一致。
- **调查**：健康调查测量那些从未进入卫生服务的疾病和危险因素的患病率。

每种来源都有典型的弱点。对患有多种疾病的老年人，死亡证明的准确性较低。登记依赖于报告的完整性。编码规则或支付制度改变时，常规数据也随之改变。常规数据集中出现的趋势，总应核查数据收集方式是否发生了变化。

::: history
系统地对疾病计数始于伦敦的布商**约翰·格朗特**（John Graunt）。1662年，他出版了《关于死亡统计表的自然与政治观察》（*Natural and Political Observations Made upon the Bills of Mortality*），分析了伦敦每周的埋葬名单。他注意到出生的男孩多于女孩，死亡集中在幼儿期，而且城市的死亡数经常超过洗礼数，因此伦敦只能靠移民增长。他还编制了一张粗略的分年龄生存表，这是寿命表的雏形。

两个世纪后，**威廉·法尔**（William Farr）于1839年成为新成立的英格兰和威尔士户籍总署的统计摘要编制官。法尔设计了死因分类，用恰当的分母计算率，并以此比较不同地区和职业。他的统计为**约翰·斯诺**（John Snow）提供了数据：1854年，斯诺比较了由两家伦敦供水公司供水的住户中的霍乱死亡，其中一家从被污水污染的泰晤士河段取水。斯诺的研究实际上是暴露组与非暴露组之间的发病比较，也就是队列研究的基本设计。
:::

## 后续内容

本章的指标是每一种研究设计的原材料。[[epidemiology-ebm/observational-studies]]说明每种设计能估计哪些指标。[[epidemiology-ebm/bias-confounding]]解释一个指标如何被扭曲，正如年龄扭曲了[[#ex-direct]]中的粗死亡率。[[epidemiology-ebm/statistics-for-clinicians]]则加入了每个估计值周围的不确定性。

::: summary
- 每个频率指标都是一个分数：要核查什么被计为病例、谁在分母中。
- **患病率**是某一时间人群中患病者的比例。它衡量疾病负担，是横断面调查所估计的量。
- **风险**（累积发病率）是起初未患病者在规定时期内发病的比例。**发病率**用新病例数除以人时，单位为“每人年”。
- 稳态下$P/(1-P) = I \times D$，因此对于不常见的疾病$P \approx I \times D$。带病生存期延长会提高患病率。
- 病死率的分母是病例；死亡率的分母是全人群。确诊提前会虚增确诊后的生存。
- 粗率受年龄结构扭曲。直接标准化得到年龄标准化率；间接标准化得到SMR（观察数/期望数）。
- 相对指标（RR、率比、OR）描述关联的强度；绝对指标（危险差、归因分数）描述其大小和公共卫生意义。两者都应报告。
:::

## 习题

::: exercise 时点患病率 {level=1 check="8"}
一项对4250名成人的调查发现340人目前患有哮喘。时点患病率是多少（以百分比表示）？
::: solution
患病率$= 340/4{,}250 = 0.08$，即8%。
:::
:::

::: exercise 发病率 {level=1 check="5"}
一个队列累计随访3600人年，记录到18例某病新发病例。发病率为每1000人年多少例？
::: solution
率$= 18/3{,}600 = 0.005$每人年，即每1000人年5例。
:::
:::

::: exercise 用哪个指标？ {level=1}
下列每个问题最适合用哪个频率指标回答？(a) 一个地区有多少人需要长期胰岛素供应？(b) 住在繁忙道路附近是否会增加儿童发生哮喘的机会？(c) 一种新的流感毒株对感染者有多危险？
::: solution
(a) 患病率，因为问题关乎当前的负担和服务需求。(b) 暴露与非暴露儿童中的发病（风险或率），用危险比或率比比较，因为问题关乎新发疾病。(c) 病死率，即病例中死亡的比例，因为分母应是感染者，而不是全人群。
:::
:::

::: exercise 死亡率与病死率 {level=2 check="24"}
一个5万人的小镇发生一次暴发，造成400例病例和12例死亡。这次暴发造成的死亡率是每10万人多少？病死率是多少？
::: hint
两个指标的分子相同，分母不同。
:::
::: solution
死亡率$= 12/50{,}000 = 0.00024$，即每10万人24例。病死率$= 12/400 = 3\%$。前者描述对全镇的影响；后者描述感染者面临的危险。
:::
:::

::: exercise 由发病率推算患病率 {level=2 check="2.91"}
某病发病率为每1000人年2例，平均病程15年。用精确的稳态关系$P/(1-P) = I \times D$求患病率，以百分比表示，保留2位小数。
::: solution
$I \times D = 0.002 \times 15 = 0.03$。于是$P = 0.03/1.03 = 0.029126$，即2.91%。近似式$P \approx I \times D$会给出3.00%。
:::
:::

::: exercise 计算SMR {level=2 check="125"}
一个职业队列中40–49岁者2000人，50–59岁者1500人，60–64岁者500人。这些年龄组的全国死亡率分别为每年每1000人3、8和12。一年中该队列记录到30例死亡。计算SMR，以100表示“符合预期”。
::: solution
期望死亡数$= 2{,}000 \times 0.003 + 1{,}500 \times 0.008 + 500 \times 0.012 = 6 + 12 + 6 = 24$。SMR $= 30/24 \times 100 = 125$。按其年龄结构，该队列的死亡比预期多25%；考虑到健康工人效应，真实的超额可能更大。
:::
:::

::: exercise 人群归因分数 {level=2 check="33.3"}
某人群中四分之一的成人暴露于某危险因素，该因素使某病风险增至三倍（RR = 3）。假定关联是因果性的，人群全部病例中有百分之多少可归因于该暴露？保留1位小数。
::: solution
$PAF = \dfrac{p(RR-1)}{1+p(RR-1)} = \dfrac{0.25 \times 2}{1 + 0.25 \times 2} = \dfrac{0.5}{1.5} = 0.333$，即33.3%。一个只影响少数人的强危险因素，所占病例份额可能小于一个几乎影响所有人的弱危险因素。
:::
:::

::: exercise 直接标准化 {level=3 check="11.35"}
一个虚构地区0–39岁、40–69岁和70岁及以上的年龄别死亡率分别为每年每1000人0.5、6和60。标准人口中0–39岁占50%，40–69岁占35%，70岁及以上占15%。计算直接年龄标准化死亡率（每年每1000人）。
::: hint
用标准人口中各年龄组所占比例对年龄别率加权，然后相加。
:::
::: solution
标准化率$= 0.50 \times 0.5 + 0.35 \times 6 + 0.15 \times 60 = 0.25 + 2.1 + 9 = 11.35$，每年每1000人。这一结果只有在与按同一标准人口标准化的另一人群比较时才有意义。
:::
:::

::: exercise 常见结局的比值比 {level=3 check="2.43"}
在一个虚构队列中，400名暴露者中120人、600名非暴露者中90人发生某结局。计算危险比和比值比，比值比保留2位小数，并解释二者为何不同。
::: solution
风险：$120/400 = 0.30$，$90/600 = 0.15$，故$RR = 2.0$。

比值：$120/280 = 0.4286$，$90/510 = 0.1765$，故$OR = 0.4286/0.1765 = 2.43$。

由于结局常见，OR大于RR。只有当风险很小时，比值与风险才接近，因为此时$1-R \approx 1$。把2.43的OR描述为“风险的2.4倍”会夸大效应。[[epidemiology-ebm/observational-studies]]说明OR何时能很好地近似RR。
:::
:::

::: exercise 解读上升的患病率 {level=3}
在一个虚构国家，儿童1型糖尿病的记录患病率在20年内翻了一番，而发病率仅上升了20%。提出可能的解释，并说明哪些进一步的数据有助于在它们之间作出判断。
::: solution
由$P \approx I \times D$可知，患病率可以通过发病率或病程上升。发病率上升20%本身不能使患病率翻倍，因此可能还有其他解释：

1. **在该年龄段内的病程更长。** 发病年龄更小的儿童在“患糖尿病儿童”池中停留的年数更多。即使1型糖尿病在任何年龄都无法治愈，发病年龄提前也会增加儿童期患病率中的$D$。
2. **病例发现更完整。** 新的全国登记或初级保健中更好的编码，可能收录了以前漏掉的病例。这改变了记录的数字，而疾病本身并无真正变化。
3. **人口变化**，例如有患病儿童的家庭迁入，或分母发生变化。
4. **非稳态。** 如果发病率是近期急剧上升的，患病率会滞后，简单关系不再成立。

有用的数据包括：历年的确诊年龄、病例发现的起始日期和方法、患病儿童的死亡率（在高收入国家非常低），以及用人口普查数据核对分母。
:::
:::
