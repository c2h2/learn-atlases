1992年，Joseph Lau及其同事发表了一项关于心肌梗死后静脉注射链激酶试验的累积荟萃分析。他们按发表顺序逐一加入试验，每加入一项就重新计算一次合并结果。到20世纪70年代初，一致且具有统计学意义的死亡率降低就已显现。然而在随后十五年里又进行了更多试验，纳入了数万名患者，而在答案早已清楚之后很久，教科书和专家综述给出的建议仍不一致。

单项试验很少能一锤定音。试验在规模、质量和情境上各不相同，其结果因机遇而分散。“全部证据显示了什么？”这一问题，需要一种与试验本身同样严谨的方法。这种方法就是系统评价，其统计学部分就是荟萃分析。本章说明它们如何进行、如何阅读森林图、如何识别异质性和发表偏倚，以及如何对一组证据的确定性进行分级。

## 叙述性综述与系统评价 {#reviews}

::: definition 系统评价 {#def-sr}
**系统评价**通过明确的、预先规定的方法来识别、筛选、评价和综合所有相关研究，从而回答一个表述清晰的问题。其方法在评价开始前写入方案，并报告得足够详细，使他人能够重复。

**叙述性综述**根据作者的知识和所选参考文献概述一个主题，不采用系统的方法。它对教学和背景介绍可能很有价值，但其结论取决于作者碰巧选择了哪些研究。
:::

这一区别很重要，因为选择性引用很容易发生，而且通常是无意识的。相信某种治疗有效的专家更容易记住阳性试验。系统评价通过事先决定纳入什么、并检索所有符合标准的研究来防范这一点。

## 系统评价的步骤 {#steps}

1. **问题。** 评价问题以PICO（人群、干预、对照、结局）形式表述，并规定合格的研究设计。
2. **方案与注册。** 在开始检索之前写下方法并注册，例如在PROSPERO（2011年启动的国际系统评价方案注册平台）注册。注册使人们能够在事后核查评价是否在看到数据后改变了结局或方法。
3. **检索。** 检索多个文献数据库，如MEDLINE、Embase和Cochrane对照试验中心注册库，使用与信息专家共同设计的高灵敏度检索策略。还要检索试验注册库、会议摘要、监管文件和参考文献列表，以找到未发表的和“灰色”文献。尽可能避免语言限制。
4. **筛选。** 对照纳入标准依次筛选题目、摘要和全文，通常由两名评价者独立进行，分歧通过讨论或由第三名评价者解决。
5. **数据提取**，同样最好双人进行，使用经过预试的表格。
6. 对每项纳入研究进行**偏倚风险评估**。
7. **综合**：研究足够相似时进行荟萃分析，否则进行结构化的叙述性综合。
8. **证据确定性评估**，通常使用GRADE。
9. **报告**，遵循**PRISMA 2020**声明（系统评价和荟萃分析优先报告条目），其中包括一张流程图，显示检出、筛选、排除（附理由）和纳入的记录数。

偏倚风险用结构化工具而不是单一的质量评分来判断。对于随机试验，Cochrane的**RoB 2**工具（2019年）询问随机化过程、偏离既定干预、结局数据缺失、结局测量和报告结果选择方面的偏倚。对于干预的非随机研究，**ROBINS-I**（2016年）对照一项假想的理想试验来评判每项研究，尤其关注混杂。

::: example 撰写评价问题 {#ex-question}
一位临床医生想知道“运动是否有助于抑郁”。把它转化为一个适合系统评价的问题。
::: solution
一个结构化的版本：

- **人群**：诊断为抑郁的成人（按公认诊断标准，或经过验证的量表得分超过阈值），任何情境。
- **干预**：持续至少4周的结构化运动项目，任何类型。
- **对照**：不治疗、等待名单、常规诊疗或注意力对照；另外单独考虑与心理治疗或抗抑郁药的比较。
- **结局**：主要结局为治疗结束时经过验证的量表上抑郁症状的变化；次要结局为缓解、不良事件、生活质量以及较长随访时的症状。
- **研究设计**：随机对照试验。

分别规定对照很重要：“运动对比什么都不做”和“运动对比抗抑郁药”是不同的问题，把它们合并会得到一个无法解释的平均值。由于无法对参与者设盲，由设盲评估者评估结局就成为一个重要的偏倚风险条目。
:::
:::

## 荟萃分析 {#meta-analysis}

::: definition 荟萃分析 {#def-meta}
**荟萃分析**是对两项或多项研究的结果进行统计合并，得出一个带置信区间的单一汇总估计值。每项研究贡献一个效应估计值（如对数危险比、对数比值比或均数差）及其标准误。各研究按其精确度加权。

比值类指标在对数尺度上合并，最后再变换回来。
:::

::: theorem 倒方差加权 {#thm-inverse-variance}
设$k$项研究估计同一个真实效应$\theta$，估计值为$y_i$，标准误为$s_i$。给每项研究赋予权重$w_i = 1/s_i^2$。则合并估计值

$$
\hat\theta = \frac{\sum_i w_i y_i}{\sum_i w_i}
$$ {#eq-pooled}

的标准误为

$$
SE(\hat\theta) = \frac{1}{\sqrt{\sum_i w_i}},
$$ {#eq-pooled-se}

并且在$y_i$的所有加权平均中，它的方差最小。
:::

::: proof
对于任何总和为$W$的权重$w_i$，加权平均$\sum w_i y_i / W$的期望值为$\theta$，因为每个$y_i$的期望值都是$\theta$。如果各研究相互独立，其方差为$\sum w_i^2 s_i^2 / W^2$。取$w_i = 1/s_i^2$时，每项$w_i^2 s_i^2$等于$w_i$，因此方差为$\sum w_i / W^2 = 1/W$，即得上述标准误。

要说明这些权重是最优的，可在$\sum c_i = 1$的约束下使$\sum c_i^2 s_i^2$最小，其中$c_i$为归一化权重。用拉格朗日乘数法，最小值出现在$c_i s_i^2$对所有研究都相同之时，即$c_i$与$1/s_i^2$成正比。直观地说，精确的研究携带更多信息，因此应得到更大的权重。由于合并方差$1/\sum w_i$小于任何单项研究的方差，合并提高了精确度。
:::

上述方法是**固定效应**（共同效应）荟萃分析。它假定每项研究估计的是同一个真实效应，结果之间的差异仅源于机遇。

**随机效应**荟萃分析则假定真实效应在研究之间存在差异，原因是患者、剂量、情境或结局定义的不同，并假定这些真实效应服从某一分布。它估计的是该分布的均值。最常用的方法由DerSimonian和Laird于1986年描述，在加权之前把研究间方差的估计值$\tau^2$加到每项研究的方差上。这使小型研究获得相对更大的权重，并产生更宽的置信区间。当异质性较大时，**预测区间**显示的是新情境中的效应可能所处的范围，它往往比均值的置信区间更有用。

::: example 合并三项试验 {#ex-pooling}
三项关于一种预防住院药物的虚构试验报告的危险比分别为0.70（对数RR的SE为0.20）、0.85（SE 0.15）和0.60（SE 0.30）。计算固定效应合并危险比及其95% CI。
::: solution
对数危险比：$\ln 0.70 = -0.357$，$\ln 0.85 = -0.163$，$\ln 0.60 = -0.511$。

权重$w = 1/s^2$：$25$、$44.4$和$11.1$，合计$80.6$。第二项试验最精确，占权重的55%；第一项占31%；第三项占14%。

合并对数RR $= (25 \times -0.357 + 44.4 \times -0.163 + 11.1 \times -0.511)/80.6 = -0.271$。

$SE = 1/\sqrt{80.6} = 0.111$。

合并RR $= e^{-0.271} = 0.76$，95% CI为$e^{-0.271 \pm 1.96 \times 0.111}$，即0.61至0.95。

只有第一项试验单独接近显著；合并估计值明确低于1，且比任何单项试验都精确。
:::
:::

## 异质性 {#heterogeneity}

在合并之前，要问各研究是否足够相似，可以合并。这有两个方面。**临床与方法学多样性**涉及人群、干预、对照、结局和设计是否足够相似，使平均值有意义。**统计学异质性**涉及结果的变异是否超出了机遇所能预期的范围。

::: definition Cochran Q与I² {#def-heterogeneity}
**Cochran Q**是各研究估计值与固定效应合并估计值之差的加权平方和：

$$
Q = \sum_i w_i (y_i - \hat\theta)^2.
$$

如果所有研究共享一个真实效应，$Q$近似服从自由度为$k - 1$的卡方分布，因此其期望值为$k - 1$。

**I²统计量**描述研究间变异中由异质性而非机遇造成的百分比：

$$
I^2 = \frac{Q - (k-1)}{Q} \times 100\%,
$$ {#eq-i2}

当$Q < k - 1$时取0。粗略地说，约25%、50%和75%的值常被描述为低、中和高异质性，但解释还取决于效应的大小和方向。
:::

研究很少时，Q检验的效能很低，因此Q不显著并不能说明各研究同质。I²不以同样的方式依赖研究数目，因此被广泛报告。但I²衡量的是*比例*，而不是变异的绝对量：当研究非常大且精确时，即使很小的、临床上不重要的差异也会产生很高的I²。

发现异质性时，首先要寻找其原因：患者、剂量、随访或偏倚风险的差异。**亚组分析**和**荟萃回归**可以探索这些原因，但它们是研究之间的观察性比较，容易受混杂影响，应事先规定并谨慎解释。有时正确的答案是根本不合并。

在上面三项试验的例子中，$Q = 1.35$，自由度为2。由于$Q$小于其期望值2，I²为0：没有超出机遇的异质性证据。

## 阅读森林图 {#forest}

荟萃分析的结果以**森林图**展示。每项研究占一行。方块标示其点估计值，方块大小与其权重成正比，横线表示其置信区间。一条竖线标示无效应（比值为1，差值为0）。合并估计值以菱形显示在底部，菱形的宽度即其置信区间。比值类指标画在对数尺度上，使得例如0.5和2与1的距离相等。

阅读森林图时，要核查：

1. 竖线的哪一侧有利于治疗（应有标注）。
2. 各研究的区间是否重叠；重叠差提示存在异质性。
3. 哪些研究占据了主要权重，它们的偏倚风险是否低。
4. 异质性统计量，通常印在图的下方。
5. 菱形的区间是否跨越无效线，以及是否排除了小到无关紧要的效应。

::: example 阅读森林图 {#ex-forest}
一张关于某药治疗急性支气管炎的8项虚构试验的森林图显示，两项偏倚风险低的最大试验，其“第7天仍有症状”的危险比接近1.0，区间很窄。六项小型试验（其中几项未设盲）的危险比在0.4至0.7之间，区间很宽。随机效应合并危险比为0.72（95% CI 0.55至0.94），I² = 68%。你会得出什么结论？
::: solution
合并结果提示有获益，但图讲述的是另一个故事。大型、实施良好的试验显示几乎没有效应。表观获益来自偏倚风险较高的小型试验，而它们在随机效应模型中获得了相对更大的权重。异质性很高，而且似乎可以由研究规模和质量来解释。

这种小型研究显示更大效应的模式称为**小样本研究效应**。它可能反映小型试验中的偏倚、发表偏倚（小型阴性试验未发表），或所研究患者的真实差异。限于低偏倚风险试验的敏感性分析很可能不会显示明确的获益。诚实的结论是：该药可能作用甚微，合并估计值的确定性低。
:::
:::

## 发表偏倚 {#publication-bias}

有阳性、统计学显著结果的研究更可能被发表，更可能被快速发表，更可能以英文发表在广泛阅读的期刊上，也更可能被引用。在已发表的试验内部，有利于干预的结局更可能被报告（**结局报告偏倚**）。因此仅基于已发表文献的评价往往高估获益。

**漏斗图**是一种简单的检查方法。把每项研究的效应估计值对其精确度（通常是标准误）作图。大型、精确的研究紧密聚集在真实效应周围；小型研究则分散得更宽。没有偏倚时，散布是对称的，像一个倒置的漏斗。如果缺少显示无获益的小型研究，漏斗就不对称。**Egger回归检验**（1997年）对这种不对称进行统计学评估。

:::

不对称并不能证明存在发表偏倚。它也可能因为小型研究是在不同人群中进行的，或在研究很少时由机遇造成；通常至少需要约十项研究，漏斗图才有参考价值。防范发表偏倚的最好办法是前瞻性的试验注册（[[epidemiology-ebm/randomised-trials]]），它使评价者能找到已完成但从未发表的试验。

::: warning 合并并不能消除偏倚
对有偏倚的研究进行荟萃分析，得到的是精确而有偏倚的答案。如果大多数试验的分配隐藏不充分，合并它们会在一个被夸大的效应周围得到狭窄的置信区间。同样，合并观察性研究也就合并了它们的混杂。荟萃分析的质量取决于其纳入研究的质量，因此偏倚风险评估和限于低风险研究的敏感性分析是必不可少的，而不是可有可无的。
:::

## 证据确定性分级 {#grade}

荟萃分析给出一个估计值。使用者还需要知道对它可以有多大信心。**GRADE**方法（推荐分级的评估、制定与评价）首次发表于2004年，现已被世界卫生组织、NICE、Cochrane以及许多其他机构采用。

::: definition GRADE证据确定性 {#def-grade}
GRADE把每个结局的一组证据的确定性评为**高**、**中**、**低**或**极低**。

来自随机试验的证据起始为高；来自观察性研究的证据起始为低。然后：

- 因偏倚风险、不一致性（无法解释的异质性）、间接性（研究的人群、干预或结局与所关注问题之间的差异）、不精确性（置信区间宽或事件少）和发表偏倚而**降级**；
- （主要针对观察性证据）因效应量大、存在剂量反应梯度，或所有可能的残余混杂都会减小观察到的效应而**升级**。
:::

各等级有朴素的含义。高确定性意味着真实效应很可能接近估计值。中等意味着可能接近，但也可能有实质差别。低意味着可能有实质差别。极低意味着很可能有实质差别。GRADE的结果以**结果总结表**呈现，对每个重要结局给出相对效应、每1000人的绝对效应、参与者人数和研究数，以及确定性等级。

::: example 对一组证据分级 {#ex-grade}
六项虚构随机试验（共1200名参与者）评估一种预防偏头痛的药物。其中四项分配隐藏不明确、结局评估未设盲。合并后每月偏头痛天数平均减少1.2天（95% CI 0.1至2.3），I² = 20%。试验纳入的是专科门诊的成人，与评价问题一致。由于只有六项试验，漏斗图无参考价值。对证据的确定性进行分级。
::: solution
起始为**高**，因为证据来自随机试验。

- **偏倚风险**：大多数试验在分配隐藏和盲法上存在严重局限，且偏头痛天数是自我报告的，因此降一级。
- **不一致性**：I²为20%，属低，没有理由降级。
- **间接性**：人群和情境与问题相符，因此不降级。
- **不精确性**：置信区间从微不足道的0.1天到有价值的2.3天。如果最小重要差异约为1天，该区间既包含重要的效应也包含不重要的效应，因此降一级。
- **发表偏倚**：只有六项试验，难以充分评估；在没有具体疑虑时不降级，但应予注明。

因此确定性为**低**：真实效应可能与估计值有实质差别。概括性的表述可以是：“该药可能使偏头痛天数略有减少；证据确定性低。”
:::
:::

## 超越标准评价 {#beyond}

- **个体参与者数据（IPD）荟萃分析**获取每项试验中每个参与者的原始数据。它使各试验的定义和分析得以统一，亚组分析也更可靠，代价是需要多得多的时间和协作。
- **网状荟萃分析**通过把直接比较（同一试验中A对B）与间接比较（A对C和B对C）结合起来，同时比较多种治疗。它依赖**可传递性**假设：除所比较的治疗外，各试验足够相似，间接比较才有效。
- **动态系统评价**（living systematic review）随新证据出现而持续更新。它们在COVID-19大流行期间变得引人注目，当时证据每周都在变化。
- **伞形评价**概括多项关于相关问题的系统评价。
- **快速评价**简化了部分步骤以便快速得出答案，相应地遗漏证据的风险也增加了。

::: quiz
一项包含12项试验的荟萃分析报告合并比值比为0.80（95% CI 0.70至0.91），I² = 0%。漏斗图显示所有小型试验都有利于治疗，而没有显示有害的小型试验。最恰当的应对是什么？
- [ ] 接受该结果：没有异质性，因此估计值可靠。
- [x] 考虑可能的发表偏倚或小样本研究效应，检索试验注册库中的未发表试验，并查看最大的几项试验的结果。
- [ ] 从固定效应模型换成随机效应模型以纠正偏倚。
- [ ] 排除小型试验，只报告最大的那一项。
::: solution
低异质性并不能排除发表偏倚：如果缺失的是阴性的小型试验，剩余研究可以彼此一致，同时都朝同一方向偏倚。不对称的漏斗是一个警示信号。下一步是检索未发表的试验，与最大、最精确的试验比较，并考虑因发表偏倚而降低确定性等级。随机效应模型会给小型试验更大的权重，只会使问题更糟。
:::
:::

::: history
英国流行病学家阿奇·科克伦（Archie Cochrane）在其1972年的著作《效果与效率：关于卫生服务的随想》（*Effectiveness and Efficiency: Random Reflections on Health Services*）中主张，卫生服务应使用经随机试验证明有效的治疗。1979年他写道，医学界没有按专科组织、并定期更新一份对所有相关随机对照试验的批判性总结，这是对这一职业的重大批评。

伊恩·查默斯（Iain Chalmers）及其同事在围产医学领域接受了这一挑战，汇编了妊娠与分娩试验的注册库，并在20世纪80年代末发表了对这些试验的系统评价。最著名的评价之一涉及给予预计早产妇女的糖皮质激素。格雷厄姆·利金斯（Graham Liggins）和罗斯·豪伊（Ross Howie）于1972年报告了第一项试验。到20世纪80年代初，这些试验合在一起已显示产前糖皮质激素降低了早产儿的死亡，但由于无人将它们合并，这一治疗多年来一直使用不足。这项评价的森林图成为1993年成立的Cochrane协作网的标志，该组织旨在编制、维护和传播卫生保健的系统评价。统计学术语“荟萃分析”（meta-analysis）则是由心理学家吉恩·格拉斯（Gene Glass）于1976年创造的。
:::

## 后续内容

系统评价是临床指南的基础，指南在[[epidemiology-ebm/critical-appraisal]]中讨论。合并估计值的统计学建立在[[epidemiology-ebm/statistics-for-clinicians]]的思想之上，偏倚风险的各个领域则建立在[[epidemiology-ebm/randomised-trials]]和[[epidemiology-ebm/bias-confounding]]之上。

::: summary
- **系统评价**以预先规定、可重复的方法回答一个明确的问题：方案与注册（PROSPERO）、全面检索、双人筛选与提取、偏倚风险评估、综合，以及按PRISMA 2020报告。
- 随机试验的偏倚风险用RoB 2评估，非随机研究用ROBINS-I评估。
- **荟萃分析**合并各研究的估计值，按其方差的倒数加权。合并SE为$1/\sqrt{\sum w_i}$。比值在对数尺度上合并。
- 固定效应模型假定只有一个真实效应；随机效应模型假定真实效应有一个分布，给出的区间更宽。
- 异质性用Cochran Q和$I^2 = (Q - df)/Q$评估。合并之前先寻找其原因。
- 在森林图中，方块大小反映权重，菱形显示合并估计值。要核查哪些研究驱动了结果。
- 发表偏倚和小样本研究偏倚会夸大合并效应；漏斗图和Egger检验可检出不对称，而试验注册是最好的防范。
- **GRADE**把确定性评为高、中、低或极低，因偏倚风险、不一致性、间接性、不精确性和发表偏倚而降级，因效应量大、剂量反应和会减小效应的混杂而升级。
:::

## 习题

::: exercise 一项研究的权重 {level=1 check="80"}
两项试验在固定效应荟萃分析中合并。试验A的对数危险比标准误为0.1；试验B为0.2。试验A获得总权重的百分之多少？
::: solution
权重分别为$1/0.1^2 = 100$和$1/0.2^2 = 25$。试验A获得$100/125 = 80\%$。标准误减半使权重增至四倍，在实践中大致相当于参与者增至四倍。
:::
:::

::: exercise 合并标准误 {level=1 check="0.1"}
四项试验的对数比值比标准误均为0.2。固定效应合并对数比值比的标准误是多少？
::: solution
每项权重为$1/0.04 = 25$，合计100。合并$SE = 1/\sqrt{100} = 0.1$。四项相同的研究使标准误减半，与一项规模为其四倍的研究效果相同。
:::
:::

::: exercise 评价的步骤 {level=1}
一名学生在PubMed中检索“drug X AND asthma”，阅读前20篇摘要，并总结了看起来最相关的五项试验。列出这种做法达不到系统评价要求的四个方面。
::: solution
以下任意四点：没有预先规定的方案或纳入标准；只检索了一个数据库，未检索试验注册库或灰色文献；检索词不是为高灵敏度设计的（没有同义词或主题词）；只筛选了前20条记录；由一人根据“相关性”而不是双人按标准进行选择；没有正式的偏倚风险评估；没有结构化的综合或确定性评估；报告方式不可重复（未按PRISMA）。
:::
:::

::: exercise 计算I² {level=2 check="55"}
一项纳入10项研究的荟萃分析报告Cochran $Q = 20$。计算$I^2$，以百分比表示。
::: solution
自由度$= 10 - 1 = 9$。$I^2 = (20 - 9)/20 = 0.55$，即55%：中等异质性。在依赖单一合并估计值之前，应先探究其原因。
:::
:::

::: exercise 合并两项试验 {level=2 check="0.63"}
两项虚构试验的危险比分别为0.5和0.8，对数危险比的标准误均为0.25。计算固定效应合并危险比，保留2位小数。
::: hint
权重相等时，合并对数RR就是两个对数RR的简单平均。
:::
::: solution
$\ln 0.5 = -0.693$，$\ln 0.8 = -0.223$。平均值为$-0.458$，$e^{-0.458} = 0.63$（即几何平均数$\sqrt{0.5 \times 0.8} = 0.632$）。合并SE为$1/\sqrt{32} = 0.177$，因此95% CI为0.45至0.89。这里$Q = 1.77$，自由度为1，故$I^2 = 43\%$。
:::
:::

::: exercise 对证据分级 {level=2}
八项队列研究一致显示，某种虚构的职业暴露与膀胱癌相关，合并危险比为4.5（95% CI 3.6至5.6），且风险随暴露年数明显增加。你会给出什么GRADE确定性等级？为什么？
::: solution
观察性证据起始为**低**。假定各研究的偏倚风险可以接受，没有明显理由因不一致性或不精确性降级（区间窄且远离1）。可以因效应量大（危险比大于约2且结果一致，甚至可以说非常大）和存在**剂量反应梯度**而**升级**。升一级或两级得到**中**或**高**确定性。推理过程必须明确，包括是否充分处理了吸烟（膀胱癌的强病因）造成的混杂。
:::
:::

::: exercise 解读异质性 {level=3}
一项纳入15项老年人防跌倒项目试验的荟萃分析报告跌倒的合并危险比为0.85（95% CI 0.75至0.96），$I^2 = 72\%$。这些试验的对象从衰弱的养老院居民到居家的健康老人不等。评价作者应该怎么做？临床医生应如何解读这一结果？
::: solution
高异质性意味着各试验的效应差别很大，因此合并估计值是不同效应的平均。作者应寻找方案中预先计划的解释：情境（养老院或社区）、跌倒的基线风险、项目内容和强度，以及偏倚风险。按这些因素进行的亚组分析或荟萃回归（谨慎解释）可能显示该项目对某些人群有效、对另一些无效。带**预测区间**的随机效应模型会显示在新情境中可预期的效应范围，其中可能包括无获益。除非异质性得到解释，否则应因不一致性降低证据确定性。

临床医生不应假定15%的降低适用于自己的患者，而应寻找与自己人群最相似的亚组。如果找不到解释，诚实的信息是：该项目平均而言能减少跌倒，但在任何特定情境中获益的大小是不确定的。
:::
:::

::: exercise 可疑的漏斗 {level=3}
二十项关于某抗抑郁药的虚构试验被合并。三项由生产商资助、事先注册的大型试验报告了小的获益。十七项小型试验（很少注册）报告了更大的获益。检索监管机构的文件发现五项已完成但从未发表的试验，均未显示显著获益。描述可能存在的偏倚以及评价应如何处理它们。
::: solution
这一模式提示存在**发表偏倚**（阴性试验未发表）、**小样本研究效应**（小型试验显示更大的效应，可能因为方法较弱），以及小型未注册试验中可能存在的**结局报告偏倚**。评价应当：

1. 利用监管机构、临床研究报告或试验注册库的数据纳入未发表的试验，并比较纳入与不纳入它们时的结果。
2. 评估每项试验的偏倚风险，包括选择性报告，在可能时核对注册结局与发表结局。
3. 进行限于大型或低风险试验的敏感性分析。
4. 呈现漏斗图和Egger检验，并注明其局限。
5. 如果缺失的结果仍可能改变结论，在GRADE中因发表偏倚降低确定性。

纳入未发表数据的合并估计值很可能显示比已发表文献所提示的更小的获益。在监管机构的数据被审查之后，针对抗抑郁药和其他药物的真实评价中确实出现过这种情况。
:::
:::
