系统综述是把一个问题当作证据的单位而不是一篇论文时会发生的事：定义问题、找到回答它的每一项研究、评价它们、并把幸存的东西合并起来。**本章涵盖方法（作为PICO片段的问题、方案注册、检索的查全对查准取舍及其图书馆员经济学、筛选与资料提取的信度）、综合（偏倚风险工具、从固定效应到随机效应到预测的元分析模型、异质性的诊断、亚组与元回归纪律）、发表与报告偏倚装置（漏斗、注册库、“灰色”之问、及网络元分析的扩张）、及围绕该方法建立的生态系统：Cochrane、GRADE与指南复合体、综述之综述层、对证据速度的活综述回应、及把一个为诚实而设计的方法变成争议工具的政治经济学。**

## 方法

::: definition 从问题到证据基础 {#def-method}
**问题先于一切：干预问题以PICO片段到来（人群、干预、对照、结局——这一框架决定了纳入标准、并通过对照决定综述与实践的全部相关性：“所纳入研究没有一项使用可获得的替代方案”否决那一类）、而诊断、预后与定性问题有自己的架构（PICOS与PCC及SPIDER相邻框架）、其从方案中的缺席预示着综述将无法回答任何东西。方案在前瞻注册（综述的PROSPERO、以试验方案为锚的比较——方案对综述偏离的审计显示系统综述内部的终点更换模仿了试验的罪）、它固定：检索、标准、综合计划与亚组假说——把综述从论证变成预先指定的测量。检索是一种查全纪律：MEDLINE、Embase、CENTRAL与专科数据库、带检索策略的透明串、“手工检索与参考文献表与灰色文献与试验注册库”补充、其产出被方法学子样本量化（“5%的纳入研究来自灰色来源、并在六分之一的综述中改变结论”的发现）、语言与日期限制之罪及其偏倚方向、及如今有自动化辅助（也被自动化动摇）的引文候选去重——机器学习筛选验证对便利性的文献、其裁决是自动化必须被验证、对照双人筛选测量、而绝不允许它悄悄定义证据基础。筛选与提取的信度：双人独立筛选作为标准（使流程图可审计的评估者间统计）、单人加核验的折中、及PRISMA流程图作为综述的胸片——识别筛选纳入的计数、其算术必须对得上。研究评价是另一个定义的主题（见下）；提取层安静的错误（结局定义不匹配、单位换算、“24周应答对连续变量比值比”这类不当事物的综合）是元分析在方法学上死亡之地、这就是为何试提取表与裁定会议是方案条目、不是礼节。最后是更新经济学：综述会老化（下文对速度的“活综述”回应；抗栓与肿瘤等快速移动领域“发表即过时”审计）、而“自检索以来有多少新证据”应当成为每一次使用比其领域半衰期更老的综述的标题。**
:::

## 综合

::: definition 偏倚评价、元分析与异质性 {#def-synthesis}
**偏倚风险工具使怀疑形式化：Cochrane的RoB 2（随机试验——五个域与总体判断算法、带其“有一些担忧而无方向”的解读文化）、非随机研究的ROBINS-I（混杂作为独立域的架构）、预后与诊断的QUIPS与QUADAS-2、及“关于综述的综述”的AMSTAR-2元偏倚工具；它们共同的创新是域的分解（使批评能命名一个机制）、效应方向的判断、及“偏倚风险不是研究质量”场针对记分卡时代加法胡话的运动。元分析模型在统计学章的决策定义中已介绍（逆方差加权、从DerSimonian-Laird到REML限制最大似然的血脉、Hartung-Knapp区间校正、及当小的有害研究缺失时使随机效应合并产生偏倚的小研究效应不对称——“存在发表偏倚时随机对固定效应”值得重读的违反直觉结果）。异质性是综合的主题对象：Q检验的低效能、I平方依赖情境的阅读、tau平方自身从少数研究得到的宽区间、及预测区间诚实的可运输性陈述。在发现异质性之处，分析回应及其规则：亚组分析（交互检验、绝不是组内显著性——试验序贯与假发现率方法所尝试的“亚组作为多重性沼泽”修正）、元回归（研究水平协变量、生态学谬误的“试验平均数据”警告、及“少协变量多试验”约束使多数发表的元回归只是描述性）、及敏感性规划（按偏倚判断排除、排除不明确者对纳入者、“从作者处获得未发表数据”分支——在审计文献中以令人不安的频率改变结论）。实际上是判断而应如此陈述的综合决定：跨临床异质人群合并（“合并的仍是水果的苹果与橙子”检验——合并均值服务于某个真实决定吗？）、跨结局定义（核心结局集改革的角色）、及跨偏倚风险（仅低危作为主要、全部研究作为支持的惯例——及其相反者的辩护）。网络元分析完成现代工具箱：通过共同对照合并直接与间接证据、带可传递性假设（效应修饰因子在网络间的均衡——那个没有统计量能检验的假设）、不一致性检验（节点分裂与设计按治疗模型、效能温和）、及排序统计的警诫（累积曲线下面积排名与“排名图不是联赛”建议）、及混合治疗比较在监管与指南中的扎根、尽管其方法学文献不断重述每一条经典警诫。**
:::

## 生态

::: definition 报告、分级与综合的经济学 {#def-ecosystem}
**报告偏倚是综合的生态问题：试验从未发表的文献（“冰箱里的试验”调查、WHO注册库与国际医学期刊编辑委员会政策时代对注册的可测量效应而不完整报告持续存在、“跨注册库报告完整度”审计）、研究内部的终点更换（Chan与Altman及Moore相邻的注册库对论文比较）、及用于探测与补救它们的方法（带其强假设的选择模型、“联系所有注册库与申办方”的劳动密集型真相）。“这份摘要诚实吗”这一文体（结论与自身结果不一致——“包装”文献跨专科的量化）也属于这一层。GRADE是该生态采纳的裁决语法：按结局的确定性（高、中、低、极低）、因偏倚风险、不精确、不一致、不直接发表偏倚而降级、因大效应与剂量反应而升级、带证据到决策框架把证据质量与建议强度分开（“强推荐而低质量证据”一类、价值、公平与资源越过界线——及GRADE的算术把判断走私进小数的论点）。机构堆栈：Cochrane（1993年沉积的规划、其活综述转型及其许可经济学——“面向全球南方的Cochrane可及性”辩论）、国家机构（NICE与CADTH及其证据综述生产线）、奖励新的而非更新的元分析的期刊层激励（“六千余个注册方案在发表前被放弃”审计——该方法自身的流失问题）、及结论与其资助相关的商业综合（产业赞助综述文献如今延伸到带客座与挂名作者模式的“看似独立”元分析）。活综述（疫情的方法学礼物：持续检索、快速核实、带版本控制的更新、及“行进中的信任”治理问题——英国医学杂志与自然试点记录的编辑速度对完整性取舍）、综述之综述与总揽层（“许多综述同一问题”扩散问题——相邻的去重方法）、及证据缺口登记册（期刊缺口部分正式化的“综述作为研究议程”功能）是当前前沿。本章的终点仍是临床医师的：一篇系统综述是一个关于人类证据总和的主张、由可错的检索、可错的评价与可错的统计建成、而其权威恰恰是其条件性的透明度——这就是为何批判性评价下一章把该方法转向综述本身。**
:::

::: example 指南的引文 {#ex-citation}
一份指南“基于来自网络元分析的高确定性证据”推荐药物X优于Y。你发现：该网络元分析的可传递性假设建立在其未展示的年龄均衡上；九个直接比较中有三个来自共用一个结局定义的单个试验系列；两项符合标准的研究不在参考文献表中、而未被报告地躺在一个注册库里。
::: solution
**审计一张网络（[[#def-synthesis]]、[[#def-ecosystem]]、[[epidemiology-ebm/critical-appraisal]]）：审计轨迹：可传递性要求效应修饰因子（年龄、严重度、共干预）在每一个比较环之间分布相当——基线特征表与“他们是否检查了各节点之间关键修饰因子”之问、不只是统计不一致性检验；单一来源聚簇问题（一个试验系列主导一个直接比较、使该边的“网络”成为一个误称——严肃软件如今产出的贡献矩阵与影响诊断图、及丢弃该聚簇的敏感性分析、如果它改变排名指南摘要就必须报告）；及缺失的试验（注册库对书目核对如今是第一遍——“未报告但已注册”一类、其效应方向由漏斗不对称与向该试验申办方报告的要求填补、而Cochrane与各数据共享机制是正式路径）。GRADE后果：不直接与疑似报告偏倚是降级触发器；“高确定性”标签最多可能是中等、而推荐强度（在证据到决策下、中等证据仍可能强——是正当的）必须重新检查其价值与成本分析是否注意到同样的缺席。要写的信：具体（三个具名问题带引文）、建设性（能解决其中两项的那个敏感性分析）、及公开（期刊的读者来信与指南的活更新渠道）——至少改善了一部抗精神病药与一部抗凝指南透明度的问责机制。**
:::

你医院感染的控制委员会需要在72小时内得到关于紫外线C房间消毒的证据摘要；Cochrane综述已有四年且属疫情前；三份预印本声称获益；两项产业研究被引用在采购文件中。
::: solution
**紧急速度的证据（[[#def-method]]、[[#def-ecosystem]]）：方法分诊：声明“快速综述”的改造（限定数据库并说明查全取舍、单人带核查的筛选、偏倚风险限于设计与混杂、叙述性综合而只在明显可辩护处做元分析）、而“快速对潦草”的界线就是对所跳过之事的透明。来源普查：活文献数据库与WHO全球研究库（“未被收录的预印本与配对数据”收获）、预印本状态被标注（尚未同行评审、方法尚未审计——“预印本是估计不是裁决”规则）、检索试验注册库寻找其最终结果将重写本摘要的进行中研究（附在摘要上的“行进中的证据”登记册）、及不带阴谋反射而带利益冲突与终点定义审计地评价产业研究（其设计中“自然实验对照试验”的差异）。综合的诚实形状：一张带按结局确定性的结果摘要表（紫外线C文献的“表面灭活对临床感染”结局层级——替代终点因不直接而降级、包含采购需要的“整群设计与成本及维护失败”实务）、推荐被框定为证据加价值（“不存在高确定性的临床有效性证据；替代数据与机制支持在终末清洁被延迟时作为辅助使用；每房间每年成本带维护核实输出的假设）、及公布综述的失效条件（强制重新综述的触发清单——这就是活综述文化永久走出疫情的方式）。委员会的保护：记录这一决定是基于可获得的最快诚实证据作出的、附带未来十八个月将解决的具名不确定性。**

## 通向何处

偏倚工具的原始材料在[[epidemiology-ebm/bias-confounding]]；合并的统计在[[epidemiology-ebm/statistics-for-clinicians]]；试验水平的判断在[[epidemiology-ebm/randomised-trials]]；评价的顶点在[[epidemiology-ebm/critical-appraisal]]；而指南机制在[[clinical-skills/clinical-reasoning]]与[[public-health/prevention-promotion]]。

::: history
**系统综述的史前是临床教科书脚注传统——到二十世纪中叶意味着一章的证据基础就是其作者的阅读清单的“专家意见相邻版本”问题。方法学祖先：Karl Pearson 1904年对相关系数的汇总（“是否存在一个相关”之问）、心脏与外科试验小样本量的“不是Cochrane算术”、及“对照试验文件”时代那个顽固的发现——著名的阴性试验（“略微有效的著名失败疗法”反转）掩盖的与其显示的同样多。现代领域围绕1970-80年代三项创新结晶：Archie Cochrane的《有效性与福利》（1972）带其“对哪种治疗有效一无所知没有借口”的按专科持续更新试验登记册论点、牛津对照试验协作组的产科注册、及元分析这个词的铸造（Glass 1976、在教育“千个小试验”问题中）加Hedges与Olkin及DerSimonian与Laird成熟的统计（1986年的随机效应时刻）。机构建设：科克伦协作网1993年成立（带其编辑办公室、其综述方案及“偏倚风险不是质量”文化）、EPPI中心与方法学生产线的牛津CRD、Sackett的牛津中心及使该方法是临床医学语法的循证医学重命名、GRADE 2000年起的采纳、及PRISMA声明2009年对元分析报告质量标准血脉的修订。反历史也要紧：医学期刊中元分析1970-2010的扩散（三万篇综述与注册方案而许多被放弃的审计）、来自临床专科的“错误问题正确答案”批评、“干预对机制综述混淆”文体战争、及使该领域把资金来源宣布为一个相关领域的产业收编调查。疫情是该方法的强制成熟：活综述格式（“行进中的证据”带差异的版本）、纳入预印本之辩、快速综述方法标准、及令人尴尬的总揽之总揽显示数十个近乎重复的活综述、其分歧多数追溯到检索日期——一次演示：没有注册纪律的速度重建了该方法建立时要修复的文献。前沿是机器辅助而人问责的：自动化被验证而不是被信任、综述注册库因被放弃而被审计、及创始人一贯意图的“综述作为基础设施而不是出版物”重新定位。—— [[epidemiology-ebm/critical-appraisal]]、[[clinical-skills/clinical-reasoning]]。**
:::

::: summary
- 系统综述是对一支文献的测量：其问题、方案与检索是它的装置、而其结论只与其查全、评价与报告同样有效——这就是为何注册方案与PRISMA流程是审计把手、不是形式。
- 偏倚风险工具命名有方向的机制而不是发布质量分数；综合的敏感性分析就是机制被定价之处。
- 合并是建模：模型的、什么可被合并的、及预测区间的选择是后果为临床的决定；异质性是关于情境依赖性的信息、不是统计天气。
- 发表偏倚是一个生态、由注册库、灰色文献手艺与带假设声明的选择模型处理——而最强的补救仍是把每个试验都拿到。
- GRADE与证据到决策把证据确定性与推荐强度分开、使指南推理可检查、而批评者指出它把价值走私进标准化算术——一场该领域应当公开进行的争论。
- 综述生态的病态（被放弃的方案、重复的综述、未被引用的更新、包装）在方法上可处理而日益被处理——活综述、总揽去重、及报告审计；临床医师的工作是在读结论之前先读最新那篇综述的检索日期。
:::

把以下四个模糊要求改写成可综述的问题（带人群、干预、对照、结局，并注明结局类型）：“脉冲冲洗是否清洁伤口更好”；“远程监护是否有效”；“我们是否应该筛查肾功能”；“苯二氮䭨类在老人中是否值得”。
::: solution
**先框架化再检索（[[#def-method]]、[[public-health/screening]]）：问题1（外科冲洗）：在成人创伤性伤口（P）中、脉冲冲洗（I）对常规冲洗（C）、伤口感染发生率（O、二分类、随访14天）；注意：“清洁更好”是一个替代度量、必须被拒绝。问题2（远程监护）：在纽约心脏协会III至IV级慢性心衰老年人中、远程患者监护（I）对标准心衰照护（C）、全因再入院与死亡（O、二分类与时间-事件、6与12个月）——“有效”若不说明结局与时间窗就没有意义。问题3（肾功能筛查）：在2型糖尿病成人（无已知慢性肾病）中、基于估算肾小球滤过率与白蛋白尿的常规筛查（I）对当前照护实践（C）、ESKD、心血管事件、过度检查与伤害（O、混杂层级——因此这是一个带危害结局的筛查综述、按筛查规划标准判断；[[public-health/screening]]）。问题4（苯二氮䭨类）：在65岁以上长期使用苯二氮䭨者中、结构化减停（I）对持续用药（C）、跌倒与骨折及睡眠与生活质量及减停成功（O、获益与危害混合）——“值得”之问要求按预设权重同时报告获益与危害（[[geriatrics-palliative/polypharmacy]]）。规则：如果一个注册方案无法容纳这个问题、那么一个综述就不能回答它。“是否更好”“是否有效”“是否值得”每一个都必须变成有对照与时间窗的数字（[[epidemiology-ebm/critical-appraisal]]）。**

::: exercise 给证据分级 {level=2}
为一项关于静脉铁治疗心衰合并缺铁的综述给主要结局分级：九项随机试验、共1400人、心衰再入院的风险比0.70（0.58至0.85）、其中两项试验有高偏倚风险、异质性I平方为0、及两项试验的资助来自同一厂商。写出你的GRADE判断与每一升降级决定的理由。
::: solution
**有理由的GRADE（[[#def-synthesis]]、[[#def-ecosystem]]、[[cardiovascular/heart-failure]]）：起点：随机证据从高确定性开始、而再入院是一个直接、患者重要的结局（[[epidemiology-ebm/statistics-for-clinicians]]）。偏倚风险：降一级——两项试验有高偏倚风险而合计贡献了约三分之一的权重（需要一张敏感性分析表：把它们排除后风险比变为0.74、0.60至0.91；结论不变、而降级是诚实的）。不精确：不降——区间把效应限于16%到42%的相对降低、而两者都可能改变实践。不一致性：不降——I平方为0、各试验间人群与剂量相似（尽管这本身可能提示试验的局限性：外部效度窄）。不直接：考虑半级——只有两项试验纳入纽约心脏协会III级以上患者、而实践关心更广泛的人群（按证据到决策框架不降）。发表偏倚：降一级——漏斗不对称性中等、而两项未注册的试验只作为摘要存在（剪补校正后0.78、0.62至0.96——仍然阳性但更弱）。厂商资助不作为一个独立的降级域处理；它通过偏倚风险与报告偏倚进入、并且必须在指南的冲突声明部分说明。净结果：中等确定性（两级降级、都量化）。推荐措辞：”对于合并缺铁的心衰成人，静脉铁可能减少心衰再入院（中等确定性证据）——效应一致而精确，但对厂商资助试验的依赖以及小的发表偏倚信号限制了确定性“——正是把读者带到证据限制而不是结论的写法（[[clinical-skills/clinical-reasoning]]）。**

::: exercise 抵御攻击 {level=3}
你对一种广泛使用药物的元分析显示心血管风险小幅增加（风险比1.12、1.02至1.23）、在很大程度上由登记队列研究驱动；仅试验的综合给出1.04。制造商称你的结果是“观察性噪声”；一个临床医师团体称你的方法是“猎巫行动”。写出回应的统计学核心。
::: solution
**跨设计的三角互证（[[#def-synthesis]]、[[#def-ecosystem]]、[[epidemiology-ebm/bias-confounding]]）：先陈述数字：仅试验的估计（1.04、区间包含轻害与轻利）回答的是“试验条件下的效应、多为较短疗程与较健康人群”；全证据估计（1.12）反映真实世界的疗程、共病、及可往两个方向走的队列残余混杂（“按适应症与严重度混杂——谁得到这个药”通道并明确论证其方向）。回应的统计学核心：预先指定的设计层级决定及其理由（为何纳入队列——罕见与长潜伏期结局是试验无法发言的——“试验是沉默而不是受保护”这一点）、按设计的亚组与元回归并报告其交互检验（设计效应差自身的置信区间）、混杂调整审计（“最充分调整对最小调整”扫描、及估计是否随调整质量趋势——药物流行病学比较系统化的观察性证据校准方法）、阴性对照结局（在同一队列中该暴露是否也“导致”与心血管机制无关的疾病？如果是、残余混杂分担责任）、及报告偏倚装置（心血管安全性试验的注册完整度、其选择性发表不对称有利于安慰——“安全信号最后才发表”文献）。立场：既不是“猎巫行动”也不是“噪声”——估计不同是因为它们测量的是不同人群与设计、带着不同偏倚、两者都未被充分理解；临床转化是诚实的（“如果该药对你的患者获益很大、数据不改变使用；如果边缘、那么合理的危害范围现在包括相对12%”）、研究要求是具体的（针对目标试验方案的预注册模拟试验设计、及个体受试者数据请求）、而数据与代码被发表，因为这是被攻击者唯一应该携带的货币。**

::: exercise 评价这个检索 {level=1}
一篇发表元分析的方法写道：“我们检索了PubMed中2010至2020年间以英文发表的关于X与Y的文章。”列出查全失败及其可能的偏倚方向。
::: solution
**一个数据库一个窗口（[[#def-method]]、[[#def-ecosystem]]）：失败：单一数据库（仅有MEDLINE对Embase收录的欧洲与药理重文献的查全缺口、其幅度有记录）、仅英文（语言偏倚、其方向跟随哪国试验在哪里发表——“阳性结果发在英文期刊而本地语言复现”文献）、日期窗口（更老的试验被一道法令排除——“窗口迁就资助周期”的破口、及窗口之前的证据可能有决定性）、无灰色或试验注册库来源（未发表试验的缺席、其方向有利于阳性效应——该领域最多产的偏倚）、无公布的策略（不可审计）、及无手工检索或向后引文（综述找不到自己领域的经典）。偏倚算术：每一个过滤器都是一个假设——被过滤研究效应为零或不存在——主张必须被论证、不能被假定。补救模板：检索该领域的各数据库并公布策略、为语言限制辩护或翻译、以证据问题论证窗口、收获注册库与会议摘要、及把整个流程放进PRISMA图。可教的那句话：一次检索是带有设计与已知选择机制的文献概率样本——这就是为何一个糟糕的检索比一个小试验更糟。**

::: exercise 教会这个区别 {level=1}
在一分钟内向一名医学生解释系统综述与叙述性综述的区别、及活综述与迅速过时综述的区别。给出学生对任何综述的阅读顺序规则。

::: example 森林图说谎 {#ex-forest}
一张会议幻灯片显示八个试验的森林图带一个显著的合并效应；该图没有固定的坐标范围、两个试验的权重条对其样本量来说看起来太宽、而合并菱形的标签写着“合并比值比0.62***”。审计这张图在做什么。
::: solution
**森林图取证（[[#def-synthesis]]）：坐标：对数尺度的比值比坐标默认关于1对称的范围；被压扁或被截断的坐标制造戏剧——检查1在哪里、网格是否为对数。权重：逆方差权重与样本量和事件数相关、所以一个小试验上的宽方块要么意味着许多事件（一个值得追查的病例组合线索）、要么意味着一个输错的标准误——“权重不一致”检验（从印出的区间重新近似计算权重）是会议图表常失败的。缺失的部分：没有预测区间（合并菱形被作为“它在这里有效吗”的答案呈现）、没有偏倚风险列或符号阴影（GRADE相邻的Cochrane风格图的特征）、研究标签缩写掩盖人群差异、及三星惯例把显著性戏剧引入一个阅读区间的领域。合并标签检验：从两个试验心算重新合并——如果印出的菱形与图中方块加权中心不一致、那么软件的模型（固定对随机）正在做幻灯片没有命名的事。在会上做口头审计：“哪个模型、什么预测区间、及权重与区间匹配吗？”——这个三问检验在评价文献收集的尴尬事中终结过三张新药发布幻灯片自信弧线。**
