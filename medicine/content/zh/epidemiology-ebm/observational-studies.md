医学中许多最重要的事实从未经过随机试验的检验。没有人会随机安排人们去吸烟、去喝受污染的水，或在孕期服用某种药物来看它是否伤害胎儿。这些病因是通过观察人们在日常生活中发生了什么、并仔细比较不同组别而发现的。这类研究称为**观察性研究**，因为研究者观察暴露和结局，但并不分配暴露。

本章介绍主要的观察性研究设计、每种设计能测量和不能测量什么，以及如何在它们之间选择。本章使用[[epidemiology-ebm/measuring-disease]]中的频率和关联指标。威胁这些设计的偏倚在[[epidemiology-ebm/bias-confounding]]中详细讨论。

## 让设计与问题相匹配 {#question}

研究设计是回答问题的策略。阅读或计划任何研究的第一步，是把问题精确地表述出来。大多数临床和公共卫生问题属于以下几类：

- **它有多常见？** 这需要特定人群中的患病率或发病率指标。
- **它由什么引起？** 这需要比较有暴露者和无暴露者的结局。
- **这种治疗有效吗？** 这需要对治疗者与未治疗者进行能防范混杂的比较，最好通过随机化（[[epidemiology-ebm/randomised-trials]]）。
- **这位患者将会怎样？** 这是预后问题，通常通过对一组患者进行纵向随访来回答。

各种观察性设计的区别在于观察的方向。**队列研究**从暴露出发，向前追踪结局。**病例对照研究**从结局出发，向后回溯暴露。**横断面研究**同时测量两者。每个方向都有其优势，也都有其典型的弱点。

## 描述性设计 {#descriptive}

::: definition 病例报告、病例系列、横断面研究和生态学研究 {#def-descriptive}
**病例报告**描述单个患者。**病例系列**描述患有同一疾病或有同一暴露的一组患者。两者都没有对照组。

**横断面研究**在某一时点测量人群样本中的暴露和结局。它估计患病率，也能比较各组间的患病率，但通常无法说明孰先孰后。

**生态学研究**以群体，如国家、地区或年份，作为分析单位。暴露和结局以群体平均值测量，例如全国食盐消费量与全国卒中死亡率。
:::

病例报告和病例系列常常是新事物的第一个信号。1981年关于艾滋病的最早报告，就是年轻男性患*肺孢子菌*肺炎和卡波西肉瘤的病例系列。沙利度胺与肢体缺陷的关联，最初也是由注意到一批不寻常病例的临床医师发现的。这类信号能产生假设，但没有对照组，就无法检验假设。

横断面调查是公共卫生监测的主力。例如，英格兰健康调查（Health Survey for England）每年测量肥胖、高血压和吸烟的患病率。它们用于病因问题时的弱点是**时间顺序不明**。如果调查发现失业者更常抑郁，它无法区分是失业导致了抑郁，还是抑郁导致了失业。横断面研究计入的是现患病例，因此会过多地代表那些带病生存时间长的人。

生态学研究成本低，因为它使用常规数据；当暴露确实作用于群体层面时，如一项法律、氟化供水或全城的空气污染，它是恰当的设计。它的危险在于**生态学谬误**：以为群体之间观察到的关联在个体之间同样成立。

::: example 各国膳食与乳腺癌 {#ex-ecological}
在1975年一项著名的分析中，Armstrong和Doll比较了许多国家，发现平均膳食脂肪消费量与乳腺癌死亡率之间存在强相关。能否据此得出结论：吃更多脂肪的女性乳腺癌风险更高？
::: solution
不能。数据显示的是脂肪消费较高的*国家*乳腺癌率较高。在这些国家内部，我们并不知道患乳腺癌的女性是否正是那些吃更多脂肪的人。

脂肪消费高的国家在许多其他方面也不同：更富裕，女性生育更少、更晚，身材更高，获得诊断的机会也更多。其中任何一点都可以解释国家层面的模式。后来测量个体女性膳食的队列研究发现，脂肪摄入与乳腺癌之间的关联远弱于国际比较所提示的。

这项生态学研究的价值在于提出了一个假设，而检验这一假设需要个体数据。
:::
:::

## 队列研究 {#cohort}

::: definition 队列研究 {#def-cohort}
**队列研究**选定一组未发生结局的人，测量其暴露，并随时间随访以记录新发结局。比较暴露者与非暴露者的结局发生（风险或率），通常以**危险比**或**率比**表示。

在**前瞻性**队列研究中，现在测量暴露，然后向未来随访参与者。在**回顾性**（历史性）队列研究中，暴露和结局都已发生，需从现有记录中重建，但逻辑相同：先界定暴露，再计数此后的结局。
:::

队列研究有几项优势：

- 它们显示暴露与结局的**时间顺序**，这是支持因果关系的最有力论据之一。
- 它们直接测量**发病**，因此既能给出相对风险，也能给出绝对风险。
- 一个队列可以研究同一暴露的**多种结局**。始于1951年的英国医生研究最终报告了吸烟与肺癌、心脏病、慢性肺病以及许多其他死因的关系。
- 暴露在结局已知之前就被记录，从而防止了**回忆偏倚**。

它们的弱点与这些优势相对应。前瞻性队列耗时且昂贵，对罕见结局效率很低：要观察到50例发病率为每年1/10,000的疾病，需要10万人年的随访。参与者会失访，如果失访者与留下者的风险不同，估计就会有偏倚。而且由于暴露不是随机分配的，暴露者与非暴露者可能在影响结局的其他方面存在差异。这就是混杂，它是所有观察性设计的核心弱点。

::: example 夜班与糖尿病 {#ex-cohort}
一个虚构的职业队列对5000名夜班护士和10,000名白班护士随访10年。随访期间，300名夜班护士和400名白班护士发生2型糖尿病。计算10年风险、危险比和危险差。认为夜班导致糖尿病这一结论面临哪些主要威胁？
::: solution
夜班护士的风险$= 300/5{,}000 = 0.06$（6%）。白班护士的风险$= 400/10{,}000 = 0.04$（4%）。

危险比$= 0.06/0.04 = 1.5$。危险差$= 0.02$，即10年内每100名护士多出2例。

对因果解释的威胁：

- **混杂。** 夜班工作者在年龄、体重指数、吸烟、膳食、体力活动或社会经济地位上可能不同。这些需要测量并加以调整。
- **进入和退出夜班的选择。** 不能耐受夜班的护士可能转做白班，因此夜班组的选择性越来越强。如果疾病使人离开夜班工作，比较就会被扭曲。
- **失访**，如果离开队列的人风险不同。
- **结局发现。** 如果夜班工作者接受更多的职业健康检查，他们的糖尿病可能被诊断得更完整。

危险比1.5是中等强度的关联，适度的混杂就可能产生。与其他研究结果一致、与夜班年数呈剂量反应关系，以及合理的机制（昼夜节律对糖代谢调节的紊乱），都会加强这一论证。
:::
:::

有些队列成了里程碑。**弗雷明汉心脏研究**于1948年在马萨诸塞州的一个小镇开始，招募成人并每两年检查一次。它确立了血压升高、胆固醇升高、吸烟和糖尿病是冠心病的危险因素，“危险因素”一词本身也是通过它的报告而广泛使用的。英国生物银行（UK Biobank）在2006年至2010年间招募了约50万名成人，把问卷、体格、遗传和影像数据与健康记录相连接，是一个现代的例子。

## 病例对照研究 {#case-control}

当结局罕见时，队列研究的大部分精力都浪费在随访那些从未成为病例的人身上。病例对照研究把逻辑颠倒过来。

::: definition 病例对照研究 {#def-case-control}
**病例对照研究**从有结局的人（**病例**）和一个无结局的对照组（**对照**）出发，比较他们过去的暴露。由于研究者决定纳入多少病例和对照，这类研究无法估计结局的风险。它估计的是**比值比**：病例中暴露的比值除以对照中暴露的比值。

用通常的四格表表示，

| | 病例 | 对照 |
|---|---|---|
| 暴露 | $a$ | $b$ |
| 非暴露 | $c$ | $d$ |

$$
OR = \frac{a/c}{b/d} = \frac{ad}{bc}.
$$ {#eq-or}

对照应来自产生病例的同一人群。指导性的问题是：如果这名对照者发生了该病，他会被纳入为病例吗？
:::

病例对照研究快速、廉价，对罕见病效率高，并可就一种结局考察多种暴露。正是这种设计最先把吸烟与肺癌、儿童服用阿司匹林与瑞氏综合征、母亲使用己烯雌酚与女儿的阴道腺癌联系起来。

两个问题最为突出。第一是**对照的选择**。医院对照方便易得，但他们住院是有原因的，而这一原因可能与暴露有关。如果肺癌研究的对照取自慢性支气管炎患者，其中许多人吸烟，关联就会被低估。第二是**回忆偏倚**。患重病的人会在记忆中搜寻病因，因此病例报告过去暴露可能比对照更完整。使用结局发生之前形成的记录而不是访谈，可以避免这一问题。

::: example 一项关于吸烟的病例对照研究 {#ex-case-control}
一项仿照早期吸烟研究的虚构医院病例对照研究，招募了200名肺癌患者和200名因其他疾病入院的对照。病例中180人吸烟；对照中120人吸烟。计算并解释比值比。
::: solution
四格表为：病例暴露$a = 180$，病例非暴露$c = 20$；对照暴露$b = 120$，对照非暴露$d = 80$。

$$
OR = \frac{180 \times 80}{120 \times 20} = \frac{14{,}400}{2{,}400} = 6.
$$

肺癌患者曾吸烟的比值是对照的6倍。由于肺癌在整个人群中罕见，比值比近似于危险比（见[[#thm-rare-disease]]），因此吸烟者的风险大约是不吸烟者的6倍。

注意不能计算的是：吸烟者患肺癌的风险。病例与对照各占一半是研究者选定的，所以$180/(180+120)$不是任何东西的风险。
:::
:::

### 为什么比值比近似于危险比 {#rare-disease}

::: theorem 罕见病假设 {#thm-rare-disease}
设一个源人群中有$N_1$名暴露者和$N_0$名非暴露者，其中分别有$A_1$和$A_0$人发病。如果对照是**未**发病者的随机样本，则病例对照研究的比值比估计的是

$$
OR = \frac{A_1/(N_1-A_1)}{A_0/(N_0-A_0)},
$$

即源人群中的比值比。当疾病在两组中都罕见时，$N_1 - A_1 \approx N_1$且$N_0 - A_0 \approx N_0$，于是

$$
OR \approx \frac{A_1/N_1}{A_0/N_0} = RR.
$$

如果对照是在每个病例发生时从仍处于危险中的人中抽取的（**发病密度抽样**），比值比无须罕见病假设即可直接估计**率比**。
:::

::: proof
在源人群中，病例中暴露的比值为$A_1/A_0$。如果对照是抽样比例为$f$的非病例随机样本，其中约含$f(N_1-A_1)$名暴露者和$f(N_0-A_0)$名非暴露者。病例通常全部纳入，抽样比例为$g$。于是

$$
OR = \frac{gA_1/gA_0}{f(N_1-A_1)/f(N_0-A_0)} = \frac{A_1/(N_1-A_1)}{A_0/(N_0-A_0)}.
$$

抽样比例相互抵消，这就是为什么研究者选择招募多少对照不会使比值比产生偏倚。当$A$相对于$N$很小时，每组发病的比值$A/(N-A)$趋近于风险$A/N$，因此比值比趋近于危险比。

在发病密度抽样中，从每个暴露组抽取的对照数与该组处于危险中的人时$T_1$和$T_0$成正比。比值比变为$(A_1/A_0)/(T_1/T_0) = (A_1/T_1)/(A_0/T_0)$，即率比。
:::

这一推理由Jerome Cornfield于1951年提出，正是它使病例对照研究在定量上站得住脚。

f: r*(1-x)/(1-r*x); r
x: 0, 0.45

labels: \text{比值比}; \text{危险比}

:::

::: warning 结局常见时，比值比不是危险比
逻辑回归给出的是比值比，因此比值比不仅出现在病例对照研究中，也出现在队列研究和试验中。当结局常见时，比值比为3并不意味着“风险的3倍”。例如，如果20%的非暴露者发生结局且危险比为2，比值比为2.67。把比值比当作危险比报告会夸大效应。当基线风险高于约10%时，应要求给出危险比或绝对风险。
:::

::: example 当结局常见时 {#ex-common}
一项对1000名成人的虚构横断面研究发现，睡眠不足6小时者中40%报告背痛，而睡眠更长者中为25%。论文报告比值比为2.0，其新闻稿称“睡眠短的人背痛风险加倍”。这样说对吗？
::: solution
患病率比为$0.40/0.25 = 1.6$。比值分别为$0.40/0.60 = 0.667$和$0.25/0.75 = 0.333$，因此比值比为$0.667/0.333 = 2.0$。论文的比值比是正确的，但新闻稿把它说成风险“加倍”，而实际的比例之比为1.6。

还有第二个问题。这是一项横断面研究，测量的是患病率而不是风险，也无法说明是睡眠短导致背痛，还是背痛干扰了睡眠。更准确的表述是：“睡眠不足6小时者背痛的常见程度是其他人的1.6倍，关联的方向不明。”
:::
:::

## 变体与混合设计 {#hybrids}

有几种设计结合了队列研究和病例对照研究的特点。

- **巢式病例对照研究**在现有队列内部进行。队列中出现的所有病例都被纳入，并为每个病例从当时仍处于危险中的队列成员中抽取若干对照。暴露数据，如储存的血样，只需对病例及其对照进行分析。这既节省了经费，又保留了队列对暴露的前瞻性测量。
- **病例队列研究**把所有病例与起始时抽取的一个随机子队列进行比较。同一子队列可作为多种不同结局的比较组。
- **病例交叉研究**以每个病例作为自身对照，比较事件发生前不久的暴露与同一人较早时期的暴露。它适用于效应即刻出现的短暂暴露，如心肌梗死前的剧烈用力，或车祸前使用手机。
- **自然实验**利用某一事件，该事件大致随机地改变了一组人而非另一组人的暴露。斯诺1854年对两家供水公司所供住户的比较是经典例子。现代变体包括政策变化前后的比较，以及孟德尔随机化，后者以影响暴露的遗传变异作为天然的随机分配。

::: example 为罕见结局选择设计 {#ex-design}
一家监管机构收到报告，称一种新获批的抗生素可能导致急性肝衰竭。急性肝衰竭的本底发病率约为每年1/100,000。全国初级保健记录覆盖数百万患者，包括处方和住院诊断。你会选择哪种设计？
::: solution
专门招募的前瞻性队列需要数百万人年才能观察到足够的病例，因此不可行。

在初级保健数据库中开展**巢式病例对照研究**效率很高。每名急性肝衰竭患者都作为病例。为每个病例抽取若干同年龄、同性别、在病例确诊之日位于数据库中且未发生肝衰竭的对照。该日期前规定时间窗内的抗生素暴露取自处方记录。由于处方记录早于任何人发生肝衰竭，避免了回忆偏倚。由于对照是在每个病例发生时从处于危险中的人中抽取的，比值比估计的是率比。

主要威胁是指征混杂（所治疗的感染，或其他药物和饮酒，本身可能导致肝损伤）、处方药未实际服用造成的暴露错分，以及结局错分。把新抗生素与用于相同感染的另一种抗生素比较，而不是与不用抗生素比较，可减少指征混杂。这称为**阳性对照药物**设计。
:::
:::

## 各种设计的比较 {#comparison}

| 设计 | 出发点 | 主要指标 | 适用于 | 主要弱点 |
|---|---|---|---|---|
| 病例系列 | 病例 | 无（描述） | 新疾病、罕见不良事件 | 无对照组 |
| 生态学研究 | 群体 | 群体率之间的相关 | 群体层面的暴露、提出假设 | 生态学谬误、混杂 |
| 横断面研究 | 某一时点的样本 | 患病率、患病率比或OR | 疾病负担、服务规划 | 时间顺序不明、现患病例 |
| 队列研究 | 暴露 | 风险、率、RR、率比、危险差 | 常见结局、罕见暴露、多种结局 | 耗时、昂贵、失访、混杂 |
| 病例对照研究 | 结局 | 比值比 | 罕见结局、多种暴露 | 对照选择、回忆偏倚、混杂 |

不存在单一的最佳设计。最佳设计是在现有时间、经费和数据条件下能够回答问题、且其弱点能被识别和处理的设计。

观察性研究应按照**STROBE**声明（加强流行病学观察性研究报告）报告，该声明首次发表于2007年。它列出了读者判断队列、病例对照或横断面研究所需的条目，包括参与者如何选择、暴露和结局如何测量、缺失数据如何处理，以及调整了哪些混杂因素。

::: quiz
一名研究者想知道，妊娠早期服用一种常用抗癫痫药是否会增加一种罕见先天性心脏缺陷（约1/2000出生）的风险。哪种设计效率最高？
- [ ] 服用与未服用该药的孕妇的前瞻性队列
- [x] 有与无该缺陷婴儿的病例对照研究，暴露取自妊娠期间形成的处方记录
- [ ] 对患有心脏缺陷儿童的横断面调查
- [ ] 比较该药使用率高与低的国家的生态学研究
::: solution
结局罕见，因此病例对照研究效率高：它汇集所有可得的病例，而不是等待病例发生。从妊娠期间形成的处方记录中获取暴露，避免了回忆偏倚，而在访谈患儿母亲时这是一个现实的问题。队列研究是有效的，但需要非常大的样本。横断面调查没有暴露的比较组，生态学比较也无法把暴露与个体妊娠联系起来。
:::
:::

::: history
1950年，两项关于吸烟与肺癌的病例对照研究相隔数月相继发表：恩斯特·温德（Ernst Wynder）和埃瓦茨·格雷厄姆（Evarts Graham）发表于《美国医学会杂志》，理查德·多尔（Richard Doll）和奥斯汀·布拉德福德·希尔（Austin Bradford Hill）发表于《英国医学杂志》。多尔和希尔访谈了伦敦各医院的肺癌患者，并把他们与因其他疾病入院的患者比较。他们发现病例中重度吸烟远为常见，而且关联随吸烟量增加而增强。

批评者认为，病例对照研究在对照选择和患者记忆方面容易产生偏倚。多尔和希尔以一项前瞻性队列作为回应。1951年，他们写信给英国医学登记册上的所有医生，询问其吸烟习惯，然后追踪他们的死亡。1954年的首次报告证实了与肺癌的关联。该研究持续了五十年。其2004年的报告显示，1900年至1930年间出生、终生吸烟的男性平均比终生不吸烟者早死约十年，而在任何年龄戒烟都能赢得生命年数。

与此同时，1951年Jerome Cornfield从数学上证明，当疾病罕见时，病例对照研究的比值比近似于相对危险度。这些进展共同为慢性病流行病学提供了两种基本设计。
:::

## 后续内容

每种观察性设计都可能被选择偏倚、测量误差和混杂所扭曲。[[epidemiology-ebm/bias-confounding]]解释如何识别和减少它们，以及如何判断一个关联是否为因果性的。当干预可以分配时，随机试验通过设计消除了混杂：见[[epidemiology-ebm/randomised-trials]]。

::: summary
- 观察性研究观察暴露和结局而不加以分配。它们常常是研究病因和治疗危害唯一合乎伦理或可行的方法。
- 病例报告和病例系列产生假设，但没有对照组。横断面研究测量患病率，但通常无法显示孰先孰后。生态学研究比较群体，有陷入生态学谬误的风险。
- **队列研究**从暴露出发，向前随访并测量发病，给出危险比、率比和危险差。它们显示时间顺序，适合罕见暴露和多种结局，但耗时且会失访。
- **病例对照研究**从结局出发，比较过去的暴露，给出比值比$ad/bc$。它们适合罕见结局，但依赖恰当选择的对照，且易受回忆偏倚影响。
- 结局罕见时，比值比近似于危险比；采用发病密度抽样时，它估计率比。对于常见结局，比值比会夸大危险比。
- 巢式病例对照、病例队列和病例交叉设计兼顾效率与良好的测量。STROBE说明观察性研究应如何报告。
:::

## 习题

::: exercise 队列研究的危险比 {level=1 check="3"}
在一个虚构队列中，1500名暴露者中45人、3000名非暴露者中30人在5年内发生某结局。危险比是多少？
::: solution
风险分别为$45/1{,}500 = 0.03$和$30/3{,}000 = 0.01$。危险比为$0.03/0.01 = 3$。
:::
:::

::: exercise 病例对照研究的比值比 {level=1 check="3.5"}
一项虚构病例对照研究发现，100名病例中60人、100名对照中30人有暴露。计算比值比。
::: solution
$a = 60$，$c = 40$，$b = 30$，$d = 70$。$OR = (60 \times 70)/(30 \times 40) = 4{,}200/1{,}200 = 3.5$。
:::
:::

::: exercise 说出设计类型 {level=1}
说出设计类型：(a) 研究者比较30个国家的全国结直肠癌率与全国肉类消费量；(b) 询问400名白血病患儿和800名非白血病儿童过去的X线暴露情况；(c) 2万名成人填写膳食问卷，并通过医院记录随访15年；(d) 一项调查询问3000名成人目前是否吸烟和是否咳嗽。
::: solution
(a) 生态学研究。(b) 病例对照研究。(c) 前瞻性队列研究。(d) 横断面研究。
:::
:::

::: exercise 配对设计 {level=2 check="2.5"}
在一项虚构的个体配对病例对照研究中，每个病例配一名同年龄、同性别的对照。在40对中，病例有暴露而对照没有；在16对中，对照有暴露而病例没有；其余各对中两人都有或都没有暴露。估计配对比值比。
::: hint
只有不一致对携带关于关联的信息。
:::
::: solution
对于配对设计，比值比是两种不一致对数之比：$40/16 = 2.5$。一致对不提供任何信息，因为在这些对中病例与对照的暴露没有差别。
:::
:::

::: exercise 时间顺序不明 {level=2}
一项横断面调查发现，慢性疼痛患者服用阿片类药物的可能性是无慢性疼痛者的两倍，且服用阿片类药物者报告的疼痛评分更差。一位评论者得出结论：阿片类药物使疼痛加重。请讨论。
::: solution
该调查同时测量暴露（阿片类药物使用）和结局（疼痛），因此无法显示孰先孰后。最明显的解释是，疼痛严重的人被开具了阿片类药物：“结局”导致了“暴露”。这是**反向因果**，在治疗情境下也称为**指征混杂**。阿片类药物引起的痛觉过敏是真实存在的现象，但这种设计无法检测到它。需要一项从治疗开始时随访、并与接受不同治疗的相似人群比较的队列研究，随机试验则更好。
:::
:::

::: exercise 失访 {level=2 check="2.25"}
一个虚构队列纳入1000名暴露者和1000名非暴露者。暴露者中800人完成随访，其中100人发生结局。非暴露者中900人完成随访，其中50人发生结局。计算完成随访者中的危险比。然后求出：如果已知失访者的结局，真实危险比可能的最低值和最高值。
::: solution
完成随访者中：$(100/800)/(50/900) = 0.125/0.0556 = 2.25$。

最低可能值：200名失访暴露者都未发生结局，100名失访非暴露者都发生了结局。RR $= (100/1{,}000)/(150/1{,}000) = 0.67$。

最高可能值：200名失访暴露者都发生了结局，失访非暴露者都没有发生。RR $= (300/1{,}000)/(50/1{,}000) = 6$。

极端情形不太可能，但从0.67到6的范围表明，当10%–20%的失访人数大于结局人数时，会造成多大的不确定性。好的队列会努力保持低失访率，并比较失访者与留下者的特征。
:::
:::

::: exercise 由危险比到比值比 {level=3 check="2.67"}
在一个虚构队列中，非暴露者的结局风险为20%，暴露的危险比为2。比值比是多少（保留2位小数）？评论读者可能如何被误导。
::: solution
暴露者的风险为$2 \times 0.2 = 0.4$。比值：$0.4/0.6 = 0.667$和$0.2/0.8 = 0.25$。比值比为$0.667/0.25 = 2.67$（精确值为$8/3$）。

等价地，$OR = RR(1-R_0)/(1 - RR \cdot R_0) = 2 \times 0.8/0.6$。把2.67理解为“风险的2.67倍”的读者把效应高估了三分之一。结局如此常见时，应报告危险比。
:::
:::

::: exercise 医院研究的对照 {level=3}
一项关于饮用咖啡与胰腺癌的虚构病例对照研究，从消化内科招募病例，并从同一科室因其他胃肠疾病（如消化性溃疡和反流病）入院的患者中招募对照。研究发现与咖啡有强关联。可能的问题是什么？你会如何重新设计这项研究？
::: solution
对照不能代表产生病例的人群。消化性溃疡和反流病患者常被建议减少咖啡，或因咖啡加重症状而停饮。因此他们的咖啡消费低于一般人群，相比之下病例显得喝咖啡更多。这一关联可能完全是由对照的选择造成的。

重新设计时应从产生病例的人群中抽取对照，例如从同一服务区域的全科医生登记名单中抽取，按年龄和性别配对。如果使用医院对照，应取自与该暴露无关的多种疾病。病例和对照应采用同一标准化问卷测量咖啡消费，且最好指症状出现之前的时期。吸烟必须测量并加以调整，因为它既与饮咖啡有关，也与胰腺癌有关。
:::
:::

::: exercise 设计一项研究 {level=3}
某卫生当局想知道，住在一座新建垃圾焚烧厂附近是否会增加儿童哮喘的风险。哮喘很常见，约每10名儿童中有1人患病。概述一种合适的观察性设计，以及你需要防范的主要偏倚。
::: solution
由于结局常见且暴露由地点界定，利用常规记录的**队列**设计是可行的：识别住在距焚烧厂不同距离、或模拟所得排放暴露不同的儿童，比较焚烧厂启用后初级保健记录中新诊断哮喘的发生。将启用前后发病的变化与一个没有焚烧厂的相似地区相比较，可以加强设计（双重差分自然实验）。

主要偏倚：

- 社会经济地位、住房质量、父母吸烟和交通污染造成的**混杂**，这些因素在工业场所附近往往更差。必须测量这些因素，或使比较地区在这些方面相匹配。
- **结局发现偏倚**：如果有关焚烧厂的宣传使附近的父母更常就医，或使医生更容易诊断哮喘。使用客观指标，如预防性吸入器处方或急诊入院，会有所帮助。
- **暴露错分**：如果距离不能很好地代表实际排放，而实际排放取决于风向和烟囱高度。扩散模型优于简单的距离。
- **迁移**：有哮喘患儿的家庭可能迁离或迁往该场所附近。

比较焚烧厂附近与远处各选区哮喘率的生态学比较会更快，但更易受混杂和生态学谬误的影响。
:::
