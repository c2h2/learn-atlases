观察性研究设计是医学在实验不可能、不合伦理或仅仅昂贵时从生活中学习的方式。**本章教授这一层级及其诚实的限度：病例报告与系列（假说诞生地、证明力弱）、横断面调查（患病及其快照、时序性的缺席）、队列研究（风险的主力——设计、人时、随访丢失、及它们建立的环境与职业王朝）、病例对照研究（罕见病效率、匹配的讨价还价、及暴露查寻手艺）、及生态与自然实验设计（人群水平的暴露变异作为偶然试验）。贯穿全章的道德是：设计固定了能问什么问题、而评价者的第一份工作就是把答案读出来。**

## 目录

::: definition 描述性设计：报告、系列、调查与生态学研究 {#def-descriptive}
**病例报告是流行病学一个人的病例对照（带故事的n=1）：不能建立率或原因、却对难忘的发现有功（邻近“反应停致畸识别”的“临床医师信号发现”传统、药物不良反应文献的脊梁、及新发感染的“首篇描述”论文）。它的评价问题是要素归属问题：还有别的能解释这一序列吗（偶然并存的基础率、去激发与再激发作为自然的迷你实验、及把判断形式化的Naranjo与世界卫生组织通用因果量表）。病例系列加上一个无分母的模式（“一地罕见事件聚集”作为假说发生器——一个镇的肉瘤与一条街的白血病、其著名调查多半发现巧合、教给人们的正是癌症聚集调查所制度化的向均值回归与多年期望计数算术）。横断面调查在同一口气里测量暴露与结局：患病、没有时间方向的关联（经典的“是疲乏导致抑郁还是相反”）、及其设计手艺——抽样框、应答率与无应答偏倚（“健康志愿者”与难以触及群体的偏斜）、问题措辞与方式效应、及推广所需的加权。尽管如此它们承担着真正的规划（国民健康与营养调查的体格测量传统、职场筛查、及代表性算术比实验室更要紧的疫情抗体调查）。生态学研究比较人群（“膳食脂肪对乳腺癌”那次举起笔又放下的争论、“盐与血压跨村庄”的国际盐血压与血压线、及自身转向准实验的空气污染与入院率时间序列）：便宜、假说丰富、而易受生态学谬误（群体关联不必在个体内成立、甚至可能反转、Robson关于识字率与移民的经典）、这就是为何生态学证据引领政策辩论但在因果裁决上跟随个体水平证据——带一个常设例外：真正的群体水平暴露（水氟化、税收与消费、及禁烟与心梗研究、其单位必须是人群、而其方法长出了一支自然实验文献来回应批评）。**
:::

## 队列

::: definition 队列研究：架构、偏倚预算与著名产出 {#def-cohorts}
**队列研究的逻辑——在结局发生前按暴露分类——用时间、金钱与损耗换来时序性与发病率。架构：前瞻性（Framingham与Doll及Hill英国医生血脉、医师与护士及女性健康队列王朝、及现代生物样本库其“招募然后等待永恒之病”的设计使无假说组学成为可能）、回顾或历史队列（重建数十年暴露的就业记录——职业主力）、及行政数据队列（北欧与国民保健服务数据库传统中整个国家是队列而暴露是一项政策或一张处方）。它产出的测量就是本章的：风险与率、风险比与率比、生存曲线及其风险。偏倚预算有具名条目：招募时的选择（使队列参与者比全国更瘦更少烟的“健康志愿者效应”——外部效度安静的税）、随访丢失（完整病例幻想、其分析实际需要的大数缺失假设、逆概率加权与多重插补的补救、及诚实规则：差异性丢失——暴露者消失更多——是致命品种）、测量漂移（基线暴露错分类推向无效对时变暴露的方法学要求——职业与药物流行病学的“累积平均当前暴露”分析）、及下一章独占的混杂。队列的优点使它成为常见暴露与多种结局的默认（一份数据、许多疾病——资助大型队列的效率）、也适合研究罕见暴露（随机化不可想象的暴露工人与独特人群队列）。它的缺点：对罕见结局缓慢而昂贵（“一万人换一个白血病”的算术把罕见病问题送去病例对照设计）、对短于访视间隔的结局无用、而被人气的暴露劫持使生命历程主张危险的“队列效应对年龄效应”年龄时期队列识别问题。报告标准（加强流行病观察性研究的报告规范）与阴性对照（高风险队列日益被要求的“与暴露无关疾病的关联”证伪检验）是评价者的核查表；因果重构工具（目标试验模拟与克隆删失加权设计从流行病学方法学期刊迁入临床流行病学实践）标志着该领域当前的雄心：把观察性设计工程化，以便在随机化不可能之处借用随机化的逻辑。**
:::

## 病例对照

::: definition 病例对照研究与自然实验 {#def-case-control}
**病例对照研究从结局出发并回头看暴露：所有患此罕见病者（病例）、一个抽样的比较集（对照）、然后比较暴露比——比值比作为该设计的原生输出（结局罕见时有效的风险比替代、学生应连同其例外一起背诵的“罕见病假设”条款）。对照就是这个设计：它们代表来源人群的暴露分布（“本应成为病例”原则）、所以对照选择是偏倚预算最大的条目——医院对照（入院率差异造成的Berkson偏倚）、邻里与人群登记对照（电话簿时代及如今的电话与地址抽样传统）、密度对风险集抽样（队列内部的巢式病例对照、其中按风险时间和风险集结构匹配使比值比成为率比估计而无需调查所有人）。匹配的讨价还价（效率与对年龄与中心等关键混杂的控制）以分析严格性为代价（匹配分析是强制的——条件逻辑回归——而匹配掉的变量无法被研究）、这是新手两个方向都会忘记的交易。该设计的签名脆弱：回忆偏倚（患儿母亲更强而更焦虑的记忆使“母体药物与畸形”文献成为一个鉴诫故事）、访问员偏倚（对病例的差异追问——标准化盲法量表的回答）、及选择（致命结局的“幸存者作为病例”问题）。它的签名优点：对罕见或长潜伏期结局的速度与把握度（己烯雌酚与阴道癌病例对照系列作为该设计最辉煌的一刻、仍是数月内达成的候选因果里程碑）、及病例交叉变体（对一过性暴露与急性事件每个人是自己的对照——“用力与争论作为心梗触发”设计）。自然实验设计利用谁被暴露中仿佛随机的变异（“抽签征兵”与“到机构距离”及“政策推行时点”工具、带自身自相关校正分析的前后对照双重差分与中断时间序列、阈值周围的断点回归、及使用遗传变异作为暴露代理的孟德尔随机化——工具有效性假设诚实陈述：相关性、独立性、排除）。层级的诚实摘要：设计通过设计与分析逼近随机化、但从不通过期望中的均衡逼近、这就是为何混杂一章的怀疑是永久家具。**
:::

::: example 一条街上的聚集 {#ex-cluster}
八年间一条300米街道上有6例罕见淋巴瘤；家长们组成了一个团体；当地健康保护团队请你加入应对。
::: solution
**先算期望计数再上头条（[[#def-descriptive]]、[[epidemiology-ebm/measuring-disease]]、[[public-health/communicable-disease-control]]）：第一道算术：按全国年龄性别特异率该人群的期望病例数是不到一例——所以朴素地看6例令人警觉；但多重比较问题是真正的统计学家：城里有许多300米路段、“地图上的热点”扫描（Morris与Kulldorff扫描统计量传统把嚷嚷的聚集与空间连贯的聚集分开）、及带泊松尾的期望计数加时空交互检验。调查模板（癌症聚集规程）：核实诊断与定义（病理复审——聚集曾死于错分类）、建立真实队列（谁在何时住在哪里——登记册缺的地址史）、然后按地址而不是邮编意愿用人时计算率、若有任何东西幸存再找暴露：某种特异致癌物的存在、其暴露反应、及文献中被调查聚集找到原因（罕见：环境性的多为阴性）与生活被打扰的清醒清单。算术必须服务的沟通：“我们还不能告诉你这是偶然、而我们可以告诉你偶然常常长这样——以下是接下来90天我们要做的和该联系谁。”团队常忘的人文医学：受影响的家庭、“什么会改变我们的答案”的透明、及无论结果如何都发表——因为该领域对著名聚集的处理（Dover与Woburn及Layton街往事）显示不确定性传达得晚或传达得错时的代价。**
:::

::: example 巢式样本 {#ex-nested}
你的队列有120000人、十年400例新发胰腺癌、及保存的基线血清；项目预算支持600项实验室检测。设计研究与其分析。
::: solution
**做对的巢式病例对照（[[#def-case-control]]、[[#def-cohorts]]）：设计：全部400例病例加约1200对照（每例3-4个、效率曲线的收益递减点）、按风险集密度抽样——每个对照从其对应病例确诊时处于危险的人中选出——这保留了人时、并产出估计率比的比值比而无需全队列检测。暴露问题需要基线样本可比性：保存时间、冻融周期与标本处理必须被屏蔽并平衡（曾经毁掉巢式研究的“分析前”偏倚）、并使实验人员对病例对照状态盲。匹配：风险集时间在设计上强制；年龄与性别与空腹状态在抽样或模型中处理；而你匹配掉的变量无法研究。分析：尊重匹配集的条件逻辑回归、并为抽样设计计算把握度（对全队列分析的病例对照近似）、并说明仅新发病例规则对现患病例污染。升级：把对照当作生物样本库复用（未来暴露需要在打开冷冻柜之前写好的同意与数据保护条款）、结果的绝对风险转化（队列人时给出比值比缺的基线风险——评价者缺失的分母）、及阴性对照暴露（一个不受假设通路影响的生物标志物）作为评审者会要求的证伪。报告：巢式研究的报告规范核查表、抽样对来源人群的流程图、及对设计无法给出的那个数字（暴露者的发病、没有全队列检测就无从得知）的诚实陈述。**
:::

## 通向何处

错误分类学在[[epidemiology-ebm/bias-confounding]]；效应测量机制在[[epidemiology-ebm/statistics-for-clinicians]]；实验对照在[[epidemiology-ebm/randomised-trials]]；评价演练在[[epidemiology-ebm/critical-appraisal]]；暴发应用在[[public-health/communicable-disease-control]]；及筛查证据设计在[[public-health/screening]]。

::: summary
- 设计决定被允许的问题：报告与系列归属单个序列、调查测量无方向的患病、队列在结局之前观察暴露、病例对照抽样结局以寻找暴露、而生态与自然实验设计把人群或政策变异作为单位。
- 队列研究买来时序性与发病率；其偏倚预算是健康志愿者选择、差异性随访丢失、与暴露测量漂移、而它对罕见结局在经济上失败。
- 病例对照研究是罕见病主力、其成败在于对照选择；匹配以强制的匹配分析为代价换来精度、而回忆与访问员偏倚是该设计的永久嫌疑者。
- 比值比是原生输出、并在风险集抽样与罕见条件下是诚实的率比替代；评价者应总是问这个比作为绝对值会是什么样子。
- 自然实验通过工具变量、双重差分与断点回归借用随机化的逻辑；其可信度建立在既陈述又可检验的假设上、而不是“观察性”这个词上。
- 每个设计的裁决都附带着它的假设：报告标准式的规范存在是为了让假设可读、而评价者应当先读它们。
:::

## 练习
::: history
**设计从实验解决不了的顽固问题中生长出来。病例系列的直觉——把奇怪的病例收集起来——从Pott 1775年观察到烟囱清洁工的阴囊癌共享一种烟灰、经过填满医学学的首批描述、一直延续到现代药物警戒的信号发现委员会。队列思想诞生于记录比记忆长命之处：Farr为水公司编制的霍乱死亡统计表（1849-54年报告、其比较被Snow变成武器）、十九世纪的人寿保险与工厂记录、然后是二十世纪的流行病学王朝——Framingham心脏研究（1948）发明了“危险因素”、英国医生研究（1951-2001）抽到最后一个吸烟者为止地证明了Doll与Hill关于吸烟的因果推断、护士健康研究的女性健康目录、及赫尔辛基与其子代出生队列围产遗产。战后职业医学从工资档案建造了历史队列模板、而北欧个人身份编号登记册把整个国家变成了队列（Thyessen与Lynoe记录的“登记册作为时间机器”学派）、而英国的普通实践研究数据库传统使药物流行病学成为监管者的常规工具。病例对照设计成熟得更慢：1920-50年代结核家庭接触的“回顾性”研究、Li 1961年脊髓灰质炎扁桃体切除的病例对照表述与“用非患者对照病例”的方法语言、然后是它著名成果的风暴——1971年己烯雌酚透明细胞腺癌论文（数月内禁了一种药的病例对照系列）、子宫内膜癌与雌激素、及随后的方法学修正（Breslow与Day 1980年代的两卷圣经、对照选择论著、及Berkson偏倚以其命名的鉴诫）。匹配、比值比与逻辑回归在1970-80年代一起到来、对致畸药物药物流行病学中回忆偏倚的警告也是如此。生态学传统带着自己著名的战斗：膳食与癌症地图（Armstrong与Doll的国际相关）、Keys的七国相关（建立膳食共识及其反弹的脂肪对心脏病地图）、及盐与血压的村庄调查；每场战斗最终不是被更好的相关而是被个体水平与试验证据解决、这就是生态学设计的永久判决。自然实验方法通过计量经济学的可信度革命进入医学（双重差分、断点回归与工具变量在1990年代Card与Krueger辩论之后迁入卫生服务期刊）、而孟德尔随机化（Gray与Smith在2000年代对Katan 1986年思想的正式化）在混杂拒绝死去时给了流行病学一件遗传工具。当前的综合是“目标试验”规划（Hernan与Robins把观察性问题重述为假设试验的规划）与超大证据时代（英国生物样本库五十万人对每一条旧暴露主张的重新分析）、它不断产出该领域最古老的裁决：关联消散、设计改进、而因果始终是关于假设的争论。—— [[epidemiology-ebm/bias-confounding]]、[[epidemiology-ebm/statistics-for-clinicians]]。**
:::
::: example 让临床医师高兴的调查 {#ex-survey}
一次全国健康调查的报告显示：报告每周饮酒三次以上的人糖尿病患病率更低。一份报纸标题写着“新研究表明红酒预防糖尿病”；糖尿病协会要求你写一份两段的解读。
::: solution
**横断面加一个选择偏倚（[[#def-descriptive]]、[[#def-cohorts]]、[[endocrine/diabetes]]）：第一段必须说明测量学：一次调查在同一口气里测量饮酒与糖尿病（无方向）、而诊断的糖尿病是登记或自报的患病（漏掉了未诊断者、而他们也喝酒）。第二段是著名的病人禁忌谬误：已患病者戒酒或减酒、所以“偶尔饮酒者”池子装满了前饮酒者、而把戒酒者作为参照时看起来不健康。加上混杂与选择：高收入与健康饮食表型及医疗获取和整体健康都使规律饮酒更可能、而健康志愿者与无应答在两个暴露组之间不均匀分布。诚实的措辞：“在这份调查中、饮酒与较低的已诊断糖尿病患病相关联；这不能告诉我们饮酒预防什么。已经有的随机证据关于酒精与血压、体重及癌症风险——足以让任何预防建议保持简短。”两段都要以四个永久问题结束：分子、分母、窗口、比较——报纸省略的那四个。教学价值在于谬误的持久性：它们在每一代标题里重新出现、因为设计不能给予的东西从不因为故事好卖而消失。**
:::
:::

::: example 作为实验的政策 {#ex-policy}
一项急性心梗到达医院后1小时内给予β阻滞剂的强制政策在2016年7月实施；行政数据给你36个月的术前与36个月的术后月度死亡率。设计分析、并命名它无法解决的三个问题。
::: solution
**中断时间序列（[[#def-case-control]]、[[epidemiology-ebm/statistics-for-clinicians]]、[[cardiovascular/coronary-artery-disease]]）：设计：术前与术后的月度序列对水平与斜率变化做中断时间序列回归、用自相关校正（新息过程模型或预白化）、并把死亡率与达到目标的给药率一起作图（机制检验——效果应当随依从性摆动）。三个无法解决：共干预（同一时间推出的其他心梗照护改善——需要同期未采用政策的对照医院或地区做双重差分）、病例组合漂移（入院标准与老龄化与冬季流感疫情）、及位移（被拯救者稍后死亡而把死亡率降低变成暂时效应）。诚实的措辞：“在36个月中、调整后月度死亡率偏离既定趋势下降了约0.4个百分点、而其时序与政策依从性曲线一致。这与因果效应一致、而未被同期对照证实。”这就是自然实验的教训：设计让你借用变异、而借用从不免费。**
:::

## 练习

::: exercise 选择设计 {level=1}
把每个问题匹配到最佳设计并说出该设计永远无法确立的一件事：(a) 新疫苗后罕见的Guillain-Barré综合征；(b) 职业柴油暴露后的长期癌症风险；(c) 全国维生素D缺乏的患病率；(d) 一个校内反欺凌规划能否减少缺课？
::: solution
**设计就是被提出的问题（[[#def-cohorts]]、[[#def-case-control]]、[[#def-descriptive]]）：(a) 疫苗安全信号：被动与主动的自发报告系统、以及为率而设的接种者队列对同期未接种对照（对一过性结局的“自身对照风险间期”设计——每个人在时间轴上自己的对照）——没有任何设计能修好的：仅有报告的分子与背景率假设。(b) 用暴露矩阵从就业记录建立历史队列、或其中的巢式病例对照——它无法证明1975年已故个体的暴露准确性。(c) 带概率抽样与血液测量标准化的横断面调查——没有时序也没有因果（及维生素D文献著名的“检测季节”混杂）。(d) 若可行按学校分组的整群随机试验、否则带对照的阶梯式推进——观察性退路无法排除自愿的学校在每个要紧方面都不同。元要点：设计选择跟随发病、潜伏期、伦理、及谁能被随机化；无法修好的东西总是一个假设、而评价者读出是哪一个。**
:::

::: exercise 修好病例对照 {level=2}
评审者否决了一项染发剂与淋巴瘤的病例对照研究、其对照是骨科与耳鼻喉科住院患者。就这一比较具体地解释Berkson偏倚、并用三个可辩护的选项及其代价重新设计对照选择。
::: solution
**对照代表暴露（[[#def-case-control]]）：Berkson机制：医院对照按入院率被选择、而如果与染发相关的疾病（或与染发使用同行的职业和生活方式）在不同对照诊断之间以不同方式抬高入院概率、对照中的暴露分布就不再代表来源人群——经典例子：耳鼻喉对照过度代表常去门诊的吸烟与饮酒阶层、扭曲了与习惯相关的任何暴露。选项：来自地址登记的人群对照（最干净的暴露代表性、昂贵而合作率下降、及无应答文献记录的人口学偏斜问题）；朋友或邻里对照（匹配住为研究混杂的环境暴露、引入社会阶层与生活方式的过度匹配）；及按入院率选择意识的医院对照（现代多疾病设计的“与暴露无关诊断”规则、带跨对照组的敏感性分析——经典方法论文提出的“对照组一致性”检验）。重新设计还要修好：新发而非现患病例（幸存者偏倚——“侵袭性淋巴瘤在入组前死亡”子集问题）、带产品特异问卷的盲法结构化暴露访谈（旧文献“染发剂”定义灾难）、及对病例状态保密的访问员。评价者那句话：每个病例对照研究就是它的对照组；暴露量具排第二。**

::: exercise 评价这个队列主张 {level=2}
一项20年队列报告喝咖啡者更长寿（风险比0.88、95%置信区间0.83至0.93）。列出你会要求作者解决的七个设计与分析问题、及哪一个额外分析最能加强这一主张。
::: solution
**咖啡因果核查表（[[#def-cohorts]]、[[epidemiology-ebm/measuring-disease]]、[[epidemiology-ebm/bias-confounding]]）：(1) 暴露测量：仅基线自报（一杯还是四杯？过滤还是浓缩？“量化然后遗忘”问题）——需要时变模型；(2) 反向因果：病人禁忌效应（人生病就少喝咖啡——“滞后分析与排除早期随访”补救）；(3) 健康咖啡饮用者表型的混杂（收入、活动、饮酒节制）——有向无环图要陈述、而调整项要有理由不是装饰；(4) 残余混杂——“社会经济地位残余”敏感性分析；(5) 选择：健康志愿者与幸存者偏倚及其方向；(6) 比例风险与曲线检查（0.88可能是十年0.99然后一个悬崖）；(7) 剂量反应与生物学合理性框架加阴性对照暴露（一个无可信机制的诱饵饮料——如果它也“保护”、模型就有罪）。最强的单一补充：关于咖啡代谢的家族内或孟德尔随机化或至少一个暴露基因型代理分析（CYP1A2变异作为工具）——它不能替代试验、但它打破任何调整清单都从未完全杀死的健康使用者混杂。评价裁决模板：“关联对许多东西稳健、只有在您接受未测混杂假设时才是因果；列出偏倚的方向大体都偏向咖啡、这正是一个爱咖啡者会预测的、而方法必须超越而不是确认的东西。”**

::: exercise 设计罕见结局研究 {level=2}
你必须研究一种生育治疗是否导致卵巢交界性肿瘤（发病约每10万妇女年2例；全国暴露人群为每年40000名接受治疗的女性）。带数字设计研究、并说明天真的队列为何失败及设计牺牲了什么。
::: solution
**算术先行的设计（[[#def-case-control]]、[[#def-cohorts]]）：天真的队列：40000名暴露女性每年产生约0.8例期望肿瘤——随访她们十年所得病例少于一个病例系列所需、所以纯前瞻队列是一份零的普查。设计：基于全国登记册的巢式病例对照（全国每一例新发肿瘤——与治疗登记链接后十年间可能有60-80例暴露年病例、并从已治疗而处于危险人群中每例抽4-10个对照、按年龄与日历时间密度抽样）、暴露作为治疗登记记录（若干北欧研究利用的“完整捕获”金标准：产次、体质指数与亚型、在登记允许处）。分析：带剂量（周期、方案）的条件逻辑回归、治疗后的时间窗（潜伏逻辑）、及定义所问因果对照的“登记内未治疗的生育力低下女性”比较者之问（治疗对未治疗的不孕不是治疗对生育——下一章使其著名的适应症混杂）。牺牲：从登记拿不到原发肿瘤组织或组织学细节（验证子研究）、没有治疗前的症状学、及比值比作为率比的阅读（在此罕见度下可辩护）。赢得资助的把握度那句话：4:1抽样带登记链接对文献争论的效应量给出80%把握度、而其成本让队列幻想显得像虚荣。**

::: exercise 批评这个生态学主张 {level=2}
一项跨90个国家层面糖可用量与糖尿病患病率的相关（r=0.8）产生了一位部长的主张：糖解释了糖尿病流行的多数。给出这一主张中三个层次的错误、及个体水平证据会增加什么。
::: solution
**生态学错误三重（[[#def-descriptive]]、[[epidemiology-ebm/bias-confounding]]）：错误一、生态学谬误：国家总量相关而个体并未暴露且受害（糖尿病病例可能在低糖国家的贫困五分位、而糖流向了富人——Robinson一类例子教给人们的组内对组间分解）。错误二、混杂公地：国家糖可用量跟随城市化、久坐工作、份量、超加工食品渗透、及筛查强度（被测量的糖尿病随其检出而上升）；多国回归无法调整登记不记录的东西。错误三、测量不对称：食物平衡表的“可用量”高估消费、而糖尿病患病定义与诊断强度各国不同（“糖尿病诊断的表观流行”文献）。个体水平证据增加：含糖饮料摄入的队列研究带总能量与脂肪度的调整（“是肥胖介导还是直接效应”分析——多数个体水平效应经由体重走）、饮料替代的试验（随意进食试验的体重结局——机制证据）、及糖税的国内自然实验（墨西哥与南非的饮料购买数据——最干净的准实验线）。与政策相邻的诚实：个体证据支持减糖作为肥胖环境的一部分；它不支持“糖解释了大部分”、而生态地图对假说与倡议仍有用、这就是r=0.8实际能承受的主张。**
:::

::: exercise 调和两项研究 {level=3}
一项队列发现夜班工作与乳腺癌强关联；一项大型病例对照研究未发现；一项合并二者的荟萃分析报告低异质性与阳性汇总。裁决、然后说出荟萃分析做错了什么。
::: solution
**设计因理由而分歧（[[#def-cohorts]]、[[#def-case-control]]、[[epidemiology-ebm/systematic-reviews]]）：队列一方：工作女性（健康工人效应保护轮班者的基线健康——会把偏倚推向无效的方向）、暴露错分类（已退休已改岗数十年的职务名称）、及队列处理不完善的混杂（生育史、体质指数、饮酒、筛查——轮班者以不同方式接受乳腺X线筛查的“筛查检出偏倚”双向切割）。病例对照一方：回忆偏倚（病例对夜班的记忆过度报告会向上偏倚——这里的无效在这一点上更“干净”）、幸存者偏倚（出现症状的女性离开了夜班或劳动力——一个无效生成器）、及定义问题“曾轮班对轮班年数对当前”——不是同一暴露的暴露对比。裁决：剂量反应问题决定——若队列的效应集中在轮班最久与照暗最多的女性、则昼夜节律机制（褪黑素抑制、维生素D、进食时点）获得合理性；若它在曾对未轮班之间均匀、则健康轮班工人的衰减说明队列的信号是在错误方向存活的混杂。于是病例对照的无效是幸存与回忆假象、而队列的阳性是检出与混杂假象、而两者可能都错于真相。荟萃分析的罪过：跨不兼容暴露定义合并（“垃圾进精度出”失败）、被低把握度掩盖的异质性（I平方95%区间那一类）、及在诚实裁决应是“设计分歧是因为它们在不同人群中测量了不同东西”时使用了“汇总效应”语言——好的综述代之以亚组与元回归再限定文献。**
