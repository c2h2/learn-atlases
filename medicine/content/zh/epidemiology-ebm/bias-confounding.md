如果研究设计决定一项研究能显示什么，那么偏倚决定它虚假地显示什么。**本章是每个评价者随身携带的错误分类学：选择偏倚（谁进入谁留下——Berkson、健康工人、随访丢失）、信息偏倚（暴露与结局的错分类、差异性与非差异性、及产生它们的回忆与访问员机器）、及混杂（第三变量问题带其因果图形式主义、其调整陷阱——对撞、中介、过度调整——及其残余与未测阴影）。它以纠正工具箱收尾：限制、匹配、分层与建模、有向无环图及其反直觉的对撞教训、定量偏倚分析、及把评价者与批评者区分开的阴性对照与证伪习惯。**

## 谁能进来

::: definition 选择偏倚及其命名者 {#def-selection}
**选择偏倚是构成研究人群的对象中的错误、而它在三道门上运作。入口：成为受试者的人与本来可能成为的人不同——使队列参与者比其邮编对应人群更瘦更少烟的健康志愿者效应；健康工人效应及其两幕（雇健康的、留耐受好的）压低职业死亡低于全国、并制造出“炼铜工更长寿”的荒谬、而参照者选择文献正是为揭穿它而存在；及Berkson入院率偏倚、其扭曲比值比的机制病例对照章已经画出：医院对照按受暴露影响的入院被选择。保留：随访丢失只在丢失与暴露和结局同时相关时才产生偏倚——学生应记住这个合取、因为单纯的退出百分比什么也证明不了、而按暴露与结局状态的丢失二乘二说明了一切；信息性删失纠正（逆概率加权、最坏情形定界）把担忧转化为陈述的不确定度。时间窗选择：不朽时间偏倚——要求存活足够久才能被分类的暴露定义（首次处方之前的区间不可能包含死亡的使用者人时设计、制造出虚假保护、而定点法或检验阴性设计或恰当滞后的定义能把它移除）。评价习惯：问谁本可以进入而没有；问丢失者必须看起来什么样才能改变答案（“退出e值”算术）；及问存活、入院或就诊是否悄悄成了暴露定义的一部分。选择问题还困扰研究从未认为可能的比较：选择偏倚与因果文献之间“对撞分层”的统一意味着诊断混杂的同一张图也诊断、这就是为何本章与下一章读起来是一门课。**
:::

## 测量到了什么

::: definition 信息偏倚与错分类 {#def-information}
**信息偏倚是变量自身的错误。当错误率取决于另一个变量时错分类是差异性的——病例对照的双重恐怖：母亲按畸形的情况回忆致畸物、访问员对病例更用力追问——而当不取决于时是非差异性的、后者通常减弱（推向无效定理）、带教科书例外：相关错误会制造关联。评价者应掌握的定量层：暴露与结局测量的敏感度与特异度应用于一个二乘二（随着分类退化观察比值比向1收缩、这使不完美的量具只在对称下保守）、定量偏倚分析背后的校正公式、及暴露特异微妙：回忆偏倚（有方向的、对罕见与令人焦虑的暴露更糟）、社会期许的少报（营养流行病学在其上建立其警诫的体重、酒精与膳食数据）、访问员偏倚（盲法作为预防）、及诊断或监测偏倚——被筛查人群有更多疾病的假象、使乳腺X线、前列腺、甲状腺与心房颤动检出的研究被检测强度劫持（筛查章的老朋友）。结局错分类有自己的政治：硬终点对软终点层级（死亡对疼痛评分）、试验的裁定委员会、及基于登记的流行病学必须发表否则就该被折价的编码对病历验证研究。纠正习惯：带回归校正纠正的测量验证子样本、跨站点量具标准化（同样的秤、同样的时间、同样的技术员——跨国调查要么出资要么后悔的计量学纪律）、及预先指定的缺失数据处理（完整病例分析是一个穿着务实外衣的“完全随机缺失”假设）。账上再记一条：向均值回归跟随任何在阈值处带误差测量的变量——治疗最高读数的分诊、其极端值自行下降、这一现象使治疗前后与观察等待比较中的表观获益膨胀、而这就是对照存在的理由。**
:::

## 第三变量

::: definition 混杂：问题、工具、陷阱 {#def-confounding}
**混杂因子是与暴露相关、对结局是原因、且不在暴露的因果通路上——三条款定义、其第三条款正是临床医师在为一个药物自身效应的中介做调整时所违反的：问钙通道阻滞剂能否降低血压时调整水肿，回答的是另一个问题。混杂是真实的人群结构、不是偏倚：原则上可由设计纠正（随机化在期望中使它均衡；限制去除其变异；匹配在所选变量上使它均衡、代价是变量无法研究且必须做匹配分析）也可由分析纠正（分层——Mantel-Haenszel传统、及定义Simpson反转的分层对粗率比较；回归调整、带其函数形式依赖及随模型里还进入什么而变的解读转移）。有向无环图把混杂从算术变成几何：后门通路与阻断它们的调整集；对撞——调整会制造关联的共同效应（条件于入院、于一个选择指标、或于暴露与结局共享的任何下游变量，会创造出从未存在的路径）；把“是通过体质指数吗”从忏悔变成一个可估计量的中介分解；及M偏倚与表偏倚模式——看似安全的朴素调整会开门。当图形沉默时（而它们关于幅度通常沉默）、定量偏倚分析提供未测者的算术：e值与敏感性表背后的混杂患病率与强度计算——“一个未测混杂必须多强才能解释结果”是可以回答的且日益强制、而诚实的答案有时是“不可能那么强”、有时是“一个与吸烟相邻的生活方式因素”。工具可以组合：阴性对照暴露与结局经验性地探测残余混杂（通过发现它对事故的“保护”关联而被发现的健康使用者效应）、活性比较者设计取代不可能的“服药者对无人”对比、个体内设计（病例交叉、自身对照风险间期、跨一个人自己时间的固定效应）一次性减去所有稳定混杂、及跨不同假设设计的三角互证——统计变异律的年长表亲——是因果主张最终成熟的方式。**
:::

::: example 健康使用者效应 {#ex-huser}
一项观察性研究发现激素替代使用者冠状动脉疾病低40%；随机试验后来发现增加。解释产生这一观察性结果的偏倚结构。
::: solution
**由服用者健康造成的混杂（[[#def-selection]]、[[#def-confounding]]、[[pharmacology/patient-variation]]）：结构：激素替代的接受被整个健康使用者表型选择（更高的社会经济地位、更好的膳食、更多运动、更多筛查与医疗接触——服药者对不服药者的对比是两种作为患者方式的比较）、加上易感者耗竭（现使用者设计移除了现用者中的早期事件）、加时机（试验随机化了绝经后多年的年长女性——“时机假说”重新解读而非抹除了部分差异）。评价者的取证工具、当时就有而至今仍被少用：活性比较者设计（用另一种女性健康药的使用者作对照——显示几乎每种预防处方都有健康使用者效应的双膦酸盐与维生素比较研究）、阴性对照结局（事故与伤害、真正心脏保护的药物在那里什么也不该做、而健康使用者效应在那里也“保护”）、及敏感性分析（社会经济调整必须多偏才能解释40%？不可能——这就是试验前的警告）。该领域保留的教训：临床问题所问的对比很少是“任何东西的服药者对不服药者”、而是“这个药对这名患者现实替代方案”、而尊重该对比的设计——随机化、活性比较者、个体内设计——才是存活下来的。**
:::
:::

::: example 说谎的调整 {#ex-adjust}
一项围手术期药物的登记研究报告：在调整了“所有已记录协变量、包括该药本要预防的并发症”之后，死亡率有益。评审者要求重新分析。
::: solution
**中介调整与对撞陷阱（[[#def-information]]、[[#def-confounding]]、[[epidemiology-ebm/statistics-for-clinicians]]）：被命名的错误：调整了因果通路上的一个变量（并发症在该药机制的下游、所以条件于它估计的是直接效应、而问题是总效应——抹除获益的过度调整）、更糟的是当协变量是给药分配与患者脆弱性的共同效应时调整了对撞（以入院为条件诱导虚假保护关联——药物流行病学的索引事件偏倚文献）。重新分析：预先指定目标估计量（治疗策略的总效应、意向治疗的类比）、仅调整暴露前协变量（从图上读出的时序规则）、把并发症用于中介分析（多少效应经由它传递——有信息量的那个问题）而不是作为混杂、并把倾向评分对回归的不一致检验作为模型误设警报运行。社论应陈述的通用启发：调整清单是论证、不是家务（调整一切是一个范畴错误——按图选择变量、不按软件逐步默认值选择）、而每个协变量都应带着它的因果地址：原因、代理、中介、对撞、还是后裔。该研究的挽救：诚实的重构（检测不到总效应获益；直接效应估计不变）通常能放进同一份摘要、如果目标估计量是在建模之前写下的。**
:::

## 通向何处

偏倚出现在[[epidemiology-ebm/observational-studies]]每个设计内部；其量化方法在[[epidemiology-ebm/statistics-for-clinicians]]重现；混杂控制就是[[epidemiology-ebm/randomised-trials]]中随机化买到的东西；检测偏倚的双生子在[[public-health/screening]]；而评价实践在[[epidemiology-ebm/critical-appraisal]]演练。

::: history
**偏倚词汇围绕尴尬事件堆积而成。回忆偏倚文献从1961-62年的致畸恐慌生长出来（记忆因结局而不同的母亲们）、访问员偏倚来自同数十年的方法学尸体解剖。Berkson 1946年关于医院对照的论文给了选择偏倚它的命名者、并在数十年后给了它正式的对撞数学。健康工人偏倚从1950-60年代职业死亡的意外中被命名（所有原因死亡率“低”的砷工人）、并由Checkoway与Kriebel的建模一代装上仪器。混杂有Simpson 1903年的反转与Yule对相关分析的批评作为早期理论；三条款定义、1959-73序列的Mantel-Haenszel估计量、及Cornfield的分块与调整装置使它成为算术；Rothman与Greenland及Robins及同事1979-83年的定义性论文确定了“混杂作为偏倚对结构”的分类学。Miettinen的流行病学传统（混杂作为设计问题、精度作为其兄弟）与Lilienfeld的教科书固定了教学。因果图革命来自计算机科学：Neyman与Rubin的潜在结局（1920-70年代）、然后是Greenland与Robins及Pearl的干预演算（1990-2000年代）把调整变成图上手术、并与统计学建制派“没有操纵就没有因果”的保留意见——字面意义上——相撞。2010年代的对撞灾难文献（体质指数与骨折、入院与暴发、及妊娠调整撤稿——图方法早在数年前就预测了它们）把几何变成了临床警告、而2010年代的报告与可重复改革使敏感性分析成为评审者的要求而不是讨论部分的一个姿态。随机化故事的另一半——它溶解的混杂及其保留的一般化与诚实盲法问题——属于试验一章。—— [[epidemiology-ebm/randomised-trials]]、[[epidemiology-ebm/critical-appraisal]]。**
:::

::: summary
- 选择偏倚是被研究谁中的错误：入口（健康工人、健康使用者、志愿者）、保留（需要暴露与结局合取的差异性丢失）、及时间窗（不朽时间）机制各有具名修复——参照者选择、敏感性定界、与设计卫生。
- 信息偏倚是所测之物的错误：差异性错分类制造或反转关联；非差异性通常减弱；验证子样本、盲法、标准化量具与诚实的缺失假设是对策。
- 混杂是人群结构、不是偏倚：由限制、匹配、分层与建模处理、并通过比较粗估计与调整估计及读分层模式（Simpson反转）来诊断。
- 因果图是调整的语法：为原因及其代理调整、绝不为中介（当问总效应时）或对撞（其调整会诱导出关联、而研究随后把它们“调整掉”）调整。
- 残余与未测混杂是被定界而不是被打发：e值、阴性对照、活性比较者与个体内设计让观察性主张携带陈述的不确定度。
- 评价者的立场：偏倚之问是有方向的（“哪个方向、多少？”）、从不是存在性的（“所以什么都不知道”）、而最好的研究预先阻止了答案。
:::

## 练习
::: example 筛查组的优势 {#ex-leadtime}
一项队列显示筛查检出的癌症比症状检出者生存两倍久；医院在其癌症资助申请中引用这一点。识别两个经典偏倚及部分挽救这一比较的分析。
::: solution
**领先时间与病程长度（[[#def-information]]、[[public-health/screening]]）：领先时间偏倚：筛查使诊断日期提前而不改变死亡、所以从检出算起的生存被领先时间膨胀（所有从诊断起算的生存比较都继承的“同样的死亡更早开始”几何）；长度偏倚：生长缓慢的肿瘤在筛查检出病例中被过度代表（使筛查对惰性显得有效的停留时间分布）、加过度诊断极限（注定永不造成伤害的肿瘤——作为鉴诫故事的前列腺与甲状腺弧线）。部分挽救：比较筛查与可比人群的死亡率（不是生存）（资助申请应该用的随机试验终点）、直接估计领先时间（建模或试验重构）并减去、按肿瘤级别与生物学分层（长度偏倚探针）、及带发病趋势分解报告过度诊断的多余。特别对于症状检出的比较、“间隔癌”框架（两次筛查之间发生、生物学侵袭）是诚实的参照类。申请级别那句话：“仅凭算术筛查检出的病例看起来生存更久；纠正了算术的死亡率证据才是我们应当引用的数字。”**
:::
:::

::: example 在未依从者中看起来最好的他汀 {#ex-adherence}
一项队列发现他汀依从者（药片计数超过80%）死亡为不依从者的一半；作者得出结论“他汀使死亡减半”。哪一层偏倚占主导、及除试验之外有哪些设计纠正？
::: solution
**健康依从者（[[#def-selection]]、[[#def-confounding]]）：主导层：依从行为是整个有利于生存套餐的标志（就诊、膳食、运动、因终末衰退而更少的用药中断——“最漂亮的反向因果”：濒死者在死亡前数月就停了他的汀、易感者耗竭与健康使用者的混合）。没有随机化的纠正：活性比较者新使用者设计（他汀起始者对另一种慢性药起始者、在可比承诺者中对比依从——在经典重新分析中大幅缩小效应的该设计）、带滞后窗的时变依从（把近期停药者从“依从”风险集中排除——易感者与早期停药者耗竭的处理）、以治疗与切换策略而不是“曾用者”民间类别为目标的条件与边际结构模型、工具变量尝试（处方者偏好与到药房距离的工具——有效的工具比声称它的论文稀有）、及阴性对照结局（揭穿健康依从者残余的事故与轻微感染检验）。教学版本：依从是一个携带生活方式传记与预后的暴露变量；那50%多数是传记、一部分是药物、而只有把承诺与化学分开的设计——最终是随机化——才能说出分配比例、这就是为何依从信息参与的务实试验与平台设计是这支文献诚实弧线的终点。**
:::

**命名与修复（[[#def-selection]]、[[#def-information]]、[[#def-confounding]]）：(a) 选择偏倚（Berkson式；疼痛门诊患者按与用药行为相关的方式被选择）——修复：从来源人群抽样对照。(b) 反向因果/时序错误（代码之后包含因症状而开的处方）——修复：新使用者、带滞后的设计。(c) 非差异性错分类（单次读数相对诊室外平均；向均值回归）——修复：重复测量与回归校正、并预先报告血压作为一个带误差的连续变量。(d) 健康使用者与检测偏倚的组合（体检者更早检出其他疾病、而更少癌症死亡可能反映筛查的结直肠切除与混杂）——修复：活性比较者（另一种预防服务的使用者）与阴性对照结局（事故）。模式：每个偏倚都有一个方向、而命名它的价值在于预测它把数字推向哪边及什么能把它拉回来。**
:::

::: exercise 画出这张图 {level=2}
一项研究估计咖啡摄入与胰腺癌的关联；吸烟是咖啡摄入的强预测因子、也是胰腺癌的原因；而胰腺癌的前驱症状改变咖啡摄入。画因果图、标出混杂与反向因果路径、并说明你的调整集及你不能调整什么。
::: solution
**图即论证（[[#def-confounding]]）：咖啡→吸烟→胰腺癌是一条需要通过吸烟（作为咖啡与癌症共同原因的后门路径）阻断的后门；咖啡→（胰腺癌）的反向路径经由前驱症状（胰腺癌→症状→减少咖啡）是时序性的问题而不是可通过调整修复的混杂。调整集：调整吸烟的量与年限、及（若可测）诊断前的体重变化或糖尿病发生作为症状通路的代理——但要小心：如果你条件于一个受暴露影响的中介，你就扼杀了部分真实效应、而如果你条件于症状本身（癌症的下游、咖啡的下游）、你就打开了一个对撞。不可调整：癌症诊断、及任何诊断后的变量；也不要把“无糖尿病”作为“健康”的代理条件于它（一条通路上的对撞）。诚实的说明：图无法量化残余混杂、所以增加一个阴性对照（对咖啡同样相关而对胰腺癌无关的结果，如事故）与一个吸烟强度假设的敏感性表。评审者真正想要的就是这个图加三个箭头标签加一句：这些是我们主张的效应、这些是我们无法识别的。**

::: exercise 量化未测者 {level=2}
一项研究报告某处方与痴呆风险降低30%（比值比0.70），并调整了年龄、性别、共病与药物。教育水平与虚弱未测量。用敏感性表论证一个未测混杂在何种强度下能解释这一结果。
::: solution
**定界未测者（[[#def-confounding]]）：构造表格：混杂—暴露关联（受教育较少者更少获得该处方的程度——比与吸烟相邻的因素弱？强？）乘混杂—结局关联（教育与痴呆诊断的风险关联），带偏差因子的标准公式；然后回答“需要多强”。经验结果通常这样：要造出0.70，未测因素需要在两侧都达到吸烟级关联（比值比2.0以上）、而一个只有1.3乘1.3差距的教育效应给出约0.85的残余。这就是解释：关联“对适度残余混杂稳健、对吸烟级混杂不稳健”——这是e值风格陈述的口语版。强化它：为教育本身加一个阳性对照（它无法影响处方但影响痴呆诊断的方面——诊断检出）、及一个阴性对照结局（骨折、它应与该药无关而健康使用者会做出关联）。诚实的收尾：方向性偏倚（开处方给看起来更健康的人）几乎总是向下、而调整表只是把故事定界、并未证明因果。**

::: exercise 挽救病例对照 {level=2}
一项病例对照研究在访谈期间收集暴露与协变量，发现当前使用者结局更好；批评者说访谈员知道病例状态并追问暴露。提出三项不需要重新招募整个队列就能执行的分析性修复。
::: solution
**对差异性查寻的补救（[[#def-information]]、[[#def-selection]]）：修复一：用访谈时长与追问次数作为差异查寻的记录——若可得，按查寻强度分层并检验暴露-效应梯度是否消失。修复二：记录验证子样本——重抽一部分病例与对照、由不知状态的访谈员用标准化的问卷重测暴露、并运行带校正比值比的定量错分类分析。修复三：限制到查寻几乎不重要的暴露——记录验证药物（给药记录、而非记忆）作为对自报暴露的敏感性检验。全部三项都承认同一件事：差异性访谈是一个无法调整掉的偏倚、只能被定界、被测量、或被绕过。最后加一条：发表盲法重新测量的一致率——kappa统计量本身就是一个偏倚估测器、而一个诚实的表格能挽救一条有时挽救不了的结论。**

::: exercise 找出这段不朽时间 {level=2}
一个移植受者队列报告移植后接种使死亡减半（风险比0.5）、用的是“不依赖时间”的分析。识别不朽时间机制并重建分析。
::: solution
**活到被接种（[[#def-selection]]、[[epidemiology-ebm/observational-studies]]）：机制：如果接种状态在移植时被固定、而接种者是活得够久够好才被接种的人、那么从移植到接种的区间是不朽的（一个已接种者早期时间中不可能发生死亡、否则他会被分类为未接种）——一个被走私进暴露标签的生存保证、其幅度随滞后长度增长（从无到有产生“风险比一半”的经典模拟）。重建：时变暴露（接种作为人们在日历时间进入的状态、人时重新分配——“在那一刻处于危险”的记账）、或带分析的目标试验模拟（定点法）（定点在第180天：只有在世者进入风险集、接种状态以定点为准、结局在其后）、或风险集抽样设计（巢式自身对照变体）。评价者对整个这一家族的两分钟检验：问“一名患者能否在变成暴露之前死亡？”——如果能、就要求时变分析；移植与促红细胞生成素与机械通气与康复转诊文献各自包含着被这一问未能成立的论文。报告的增加：在方法中说明不朽时间评估、因为2010年代方法学运动之后它的缺失本身就是一个红旗。**

::: exercise 为这个观察性发现辩护 {level=3}
你的队列显示早期农场暴露使哮喘减少45%。一份期刊要求提供对抗混杂的证明；你所在地区的遗传、移民模式与医疗保健都不均衡。写出证伪规划：五项分析、各自排除了什么、及没有一项能排除什么。
::: solution
**一个三角互证规划（[[#def-confounding]]、[[epidemiology-ebm/observational-studies]]）：分析1、阴性对照暴露：一个与农场无关的健康生活方式标志（有机农产品、养狗而无牲畜）——排除任何富裕乡村生活方式携带这一保护关联；如果它也“保护”，则关于农场特异机制什么也没排除。分析2、阴性对照结局：伤害与非特应性湿疹——卫生假说预测对特应性结局的选择性效应；一切结局上均匀的效应有意义于健康使用者残余。分析3、剂量反应与时机：来自儿童记录的动物接触强度与“六岁后迁入农场”的对比——混杂因子很少模仿的关键窗口结构。分析4、同胞内设计：同一父母的农场与非农场家庭（固定效应家族模型减去共享的遗传、社会经济与家庭文化——家族水平代理漏掉的混杂）。分析5、孟德尔随机化邻近或分子中介：巢式子样本中与农场粉尘相关的微生物与免疫标志物（机制链：暴露到微生物群到调节性T细胞到表型——不是效应的证明、但是一条混杂必须从头到尾捏造的链）。没有一项能排除：任何在别处都未测量而与农场相关且贯穿童年的混杂（诚实那句话）、以及这一关联只是有呼吸易感性的家庭选择进入和退出务农（职业流行病学不断宣讲的健康农民与适宜性改变偏倚）。投稿信的这句话：因果未被证明但被定界——幸存下来的解释是具体的、可测量的、而合起来不太可能、这就是人群医学所能达到的最接近之处。**

::: exercise 纠正试验分析 {level=2}
一项随机试验中干预组12%失访而对照组4%、集中在最穷与最病者。发表的分析是完整病例的、带一句“敏感性：基线无显著差异”的安慰。为统计编辑提建议。
::: solution
**差异性删失与完整病例幻想（[[#def-selection]]、[[epidemiology-ebm/statistics-for-clinicians]]）：诊断：大数随机缺失下的完整病例分析要求丢失与协变量给定后的结局无关——集中在最病者（事件风险最高组）使这一假设不仅未被证明、而且方向上受威胁（丢失最病的接受治疗患者会低估治疗危害或高估获益、取决于结构）。被要求的重新分析：带转折点敏感性的多重插补（“如果每个退出患者都差x倍会怎样”曲线要放在正文而不是补充材料——决定结论是否翻转的模式）、带丢失模型协变量与诊断的删失逆概率加权、最坏与最好情形定界（“可辩护结果范围”呈现）、及若任何子集可通过记录链接随访则执行最小结局追回扫描（使最困难层从缺失变为已知的死亡登记核查）。报告要求：按组按疾病负担的丢失表、按组的失访原因、及缺失患者必须看起来什么样试验结论才会翻转的陈述——用“delta”框架取代安慰而代之以量化。编辑的裁决规则：差异性丢失不是宿命论（“所有试验都有退出”）而是一个目标估计量问题；当敏感性曲线在合理界限内越过无效、结论的措辞就必须限定在界限内。给未来方案的预防注记：随访保留资金与结局追回规划（随机化时的登记同意）是设计特征、而本案例正公开地为它们的缺失付账。**

::: exercise 十分钟教会你对撞 {level=3}
设计一个十分钟小组教学环节、用一个易懂的例子让临床医师亲身感受对撞偏倚。包括数值演示、它控告的常见临床实践、及他们离开时应带走的那一句规则。
::: solution
**靠感受教对撞（[[#def-confounding]]）：例子：入住医院。焦虑与严重创伤都提高入院概率；把一项研究限制在住院患者、焦虑就显得对创伤有保护作用、因为在那个房间里每个人入院都有理由、而对于平静的患者理由必须是别的什么。这一负关联只存在于被条件的人之中——完全由抽样框创造。数值演示（小而手可算的二乘二乘二）：来源人群中独立的暴露与结局（风险比全为1.0）、然后用简单概率条件于共同效应；仅住院者的表给出一个可见的非1.0关联——当他们自己算出来时课堂上的惊呼时刻。它控告的临床实践：为入院、重症转科、“因为被诊断所以诊断”、或“完成治疗”状态做调整；“仅研究住院患者”的设计；登记分析中的健康幸存者过滤器；及甲乙与服务评价中“按入组标准做条件”的陷阱（“上网用户调查流行病学”一类）。离开时应带走的一句话：绝不要为一个暴露与结局共同造成的东西做调整、限制或分层——如果不确定一个协变量是否是对撞、画出两条箭头并看它们落在哪里。后续阅读：使这成为期刊俱乐部常备的对撞悖论病例系列（高血压与体重的例子、其条件化产生了著名的反转）、因为当教训有受害者时它才贴得住。**
