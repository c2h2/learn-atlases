20世纪80年代和90年代，大型观察性研究发现，绝经后接受激素替代治疗的女性，冠心病发生率约为未接受者的一半。这一发现结果一致、在生物学上说得通，并被广泛采纳。随后，2002年报告的妇女健康倡议（Women's Health Initiative）随机试验发现完全没有保护作用：雌激素联合孕激素并未减少冠脉事件，在治疗早期反而使之增加。

那些观察性研究并非粗心大意。它们的问题在于，选择使用激素的女性平均而言比不使用的女性更健康、更富裕、更注重健康，而再多的调整也无法完全消除这种差异。本章讨论此类关联如何在没有因果关系的情况下产生，如何识别它们，以及如何判断一个关联何时可能是因果性的。

## 两类误差 {#errors}

::: definition 随机误差与系统误差 {#def-bias}
**随机误差**是由于研究测量的是样本而不是全人群，研究估计值因机遇而产生的变异。它使估计不精确，但不会把估计推向某个特定方向。它随研究规模增大而缩小，用置信区间和p值来量化。

**系统误差**，即**偏倚**，是由研究的设计、实施或分析方式造成的估计值对真值的一致偏离。偏倚不会随样本增大而缩小。一项有偏倚的大型研究给出的是对错误答案的精确估计。

流行病学家把偏倚分为三大类：**选择偏倚**、**信息偏倚**和**混杂**。
:::

这一区分很重要，因为处理工具不同。随机误差由统计学处理（[[epidemiology-ebm/statistics-for-clinicians]]）。偏倚必须通过设计加以预防，或在可能时于分析中校正。狭窄的置信区间对偏倚一无所知。

## 选择偏倚 {#selection}

::: definition 选择偏倚 {#def-selection}
**选择偏倚**是指人们进入或留在研究中的方式，使参与者中暴露与结局之间的关系，不同于研究意图描述的人群中的关系。
:::

常见形式包括：

- **无应答。** 同意参加调查的人通常比不参加者更健康、更富裕。对于与贫困相关的疾病，来自志愿者的患病率估计往往偏低。
- **失访。** 在队列研究中，如果发生结局的暴露者比非暴露者更可能退出，关联就会被低估，反之亦然。
- **病例对照研究中对照选择不当**，见[[epidemiology-ebm/observational-studies]]。
- **健康工人效应。** 在业者比一般人群更健康，因此把工人与一般人群比较会使职业显得比实际更安全。
- **伯克森偏倚。** 由约瑟夫·伯克森（Joseph Berkson）于1946年描述，发生在研究仅限于住院患者时。如果两种疾病各自都会增加住院机会，那么在住院患者中它们可能显得相关，即使在人群中二者相互独立。

伯克森偏倚是一种普遍机制的例子。如果暴露和结局都影响一个人是否被纳入研究，那么把分析限于被纳入者，就会在二者之间制造虚假关联。用因果图的语言来说，纳入是一个**对撞变量**（collider），即同时由暴露和结局所导致的变量。以对撞变量为条件，会在其原因之间打开一条虚假路径。这就是为什么选择或调整一个同时是暴露和结局之后果的变量，会在原本没有偏倚的地方制造偏倚。

## 信息偏倚 {#information}

::: definition 信息偏倚与错分 {#def-information}
**信息偏倚**源于测量暴露、结局或其他变量时的误差。当被测变量为分类变量时，这种误差称为**错分**。

如果测量一个变量的误差不依赖于另一个变量，例如在病例和对照中暴露测量得同样糟糕，错分是**无差异的**。如果误差在各组之间不同，例如病例比对照更好地记得过去的暴露，错分是**有差异的**。

对于二分类暴露，无差异错分通常使关联偏向**无效值**（偏向危险比为1）。有差异错分可以使关联偏向任一方向。
:::

常见的信息偏倚类型：

- **回忆偏倚。** 在病例对照研究中，病例常在记忆中搜寻病因，因此报告过去暴露比对照更完整。例如，先天异常婴儿的母亲回忆妊娠期用药和疾病，可能比其他母亲更详细。
- **访谈者偏倚或观察者偏倚。** 知道参与者患病状态的访谈者可能更深入地追问暴露。知道患者治疗分组的评估者可能以不同方式记录结局。盲法可以防止这一点。
- **检出偏倚。** 如果暴露者接受检查更频繁，他们的结局也会更常被发现。服用口服避孕药的女性定期看医生，因此她们的轻微疾病更常被诊断。

::: example 无差异错分 {#ex-misclass}
在一项虚构病例对照研究中，真实情况是100名病例中50人、100名对照中25人有暴露，比值比为3。暴露通过一份问卷测量，其灵敏度为0.8、特异度为0.9，在病例和对照中相同。研究将观察到多大的比值比？
::: solution
病例中被归为暴露的人数为$0.8 \times 50 + 0.1 \times 50 = 40 + 5 = 45$。第一项是被正确检出的真正暴露的病例；第二项是被错误归为暴露的非暴露病例（1 − 特异度 = 0.1）。

对照中：$0.8 \times 25 + 0.1 \times 75 = 20 + 7.5 = 27.5$。

观察到的比值比$= \dfrac{45 \times 72.5}{55 \times 27.5} = \dfrac{3{,}262.5}{1{,}512.5} = 2.16$。

真实比值比3被观察为约2.2。两组中的误差相同，却并未相互抵消。把一些暴露者和非暴露者混入错误的组，使两组更加相似，关联因而被稀释。这就是为什么暴露测量粗糙的研究，如仅用一份膳食问卷，往往低估效应。
:::
:::

## 混杂 {#confounding}

::: definition 混杂 {#def-confounding}
**混杂**是暴露与结局之间的关联被一个与暴露交织在一起的第三因素，即**混杂因素**，所扭曲。一个变量成为潜在混杂因素需满足：

1. 它是结局的原因（或此种原因的标志），且独立于暴露；
2. 在所研究的人群中，它与暴露相关；
3. 它**不**位于暴露与结局之间的因果路径上。

混杂可以在不存在关联时制造关联、掩盖真实关联、夸大关联，甚至使关联方向逆转。
:::

第三个条件很重要。如果一种降压药通过降低血压来预防卒中，那么治疗后的血压是**中介变量**，而不是混杂因素。对它进行调整会去除药物的部分真实效应。因此，决定调整哪些变量需要了解因果结构，而不仅仅是统计关联。画出一张**因果图**（有向无环图），用箭头从原因指向结果，是把这些假设明确化、并看清应调整哪些变量、不应调整哪些变量的实用方法。

::: example 咖啡、吸烟与心肌梗死 {#ex-confounding}
一项关于饮用咖啡与心肌梗死的虚构病例对照研究纳入150名病例和200名对照。总体结果及按吸烟分层的结果如下：

| | 病例，喝咖啡 | 病例，不喝咖啡 | 对照，喝咖啡 | 对照，不喝咖啡 | 比值比 |
|---|---|---|---|---|---|
| 吸烟者 | 80 | 20 | 40 | 10 | 1.0 |
| 不吸烟者 | 10 | 40 | 30 | 120 | 1.0 |
| 合计 | 90 | 60 | 70 | 130 | 2.79 |

解释发生了什么。
::: solution
粗比值比为$(90 \times 130)/(70 \times 60) = 2.79$，提示咖啡使心肌梗死的比值几乎增至三倍。

在每个吸烟层内，比值比恰为1：吸烟者中$(80 \times 10)/(40 \times 20) = 1$，不吸烟者中$(10 \times 120)/(30 \times 40) = 1$。在吸烟状况相同的人中，喝咖啡者与不喝咖啡者成为病例的可能性相同。

吸烟满足混杂因素的全部三个条件。它导致心肌梗死。在这些数据中它与饮用咖啡强相关：吸烟对照中80%喝咖啡，不吸烟对照中为20%。而且它不位于从咖啡到心肌梗死的因果路径上。喝咖啡者更常吸烟，吸烟解释了全部粗关联。调整后的比值比，即Mantel–Haenszel比值比，为1.0。
:::
:::

### 辛普森悖论 {#simpson}

混杂可以强到使关联反转。这称为**辛普森悖论**，一个真实的例子来自Charig及其同事1986年比较肾结石治疗方法的研究。

::: example 肾结石与辛普森悖论 {#ex-simpson}
开放手术与经皮肾镜取石术（PCNL）的成功率如下：

| 结石大小 | 开放手术 | PCNL |
|---|---|---|
| 小（2 cm以下） | 81/87（93%） | 234/270（87%） |
| 大 | 192/263（73%） | 55/80（69%） |
| 全部结石 | 273/350（78%） | 289/350（83%） |

哪种治疗的结果更好？
::: solution
在每种结石大小中，开放手术的成功率都更高：小结石93%对87%，大结石73%对69%。而总体上PCNL似乎更好，83%对78%。

原因在于结石大小是一个混杂因素。大结石用任何方法都更难治疗，而外科医生主要为大结石选择开放手术：350例开放手术中263例为大结石，而350例PCNL中只有80例。因此开放手术组中困难病例的比例高得多。合并各层会把治疗的效应与病例难度的效应混在一起。

分层比较更为公平，因为结石大小既影响治疗的选择，也影响结局。这是**指征混杂**的一种形式，也是治疗的观察性研究中最常见的问题：患者因某些也影响其预后的特征而接受某种治疗。
:::
:::

### 效应修饰 {#effect-modification}

::: definition 效应修饰 {#def-effect-modification}
**效应修饰**，也称**交互作用**，是指暴露对结局的效应确实因第三个变量的水平不同而不同。各层的指标彼此不同，这种差异是生物学或人群的真实特征，而不是偏倚。
:::

混杂与效应修饰容易混淆，因为两者都是通过分层发现的。区别在于各层显示了什么：

- 在**混杂**中，各层估计值彼此相似，但与粗估计值不同。正确的做法是报告一个调整后的单一估计值。
- 在**效应修饰**中，各层估计值彼此不同。正确的做法是分别报告，因为单一的汇总会掩盖重要信息。

一个经典例子是石棉暴露与吸烟。二者各自都增加肺癌风险，同时暴露于二者的人风险远大于任何一种单独暴露，大致为二者之积。对吸烟者来说，石棉在绝对意义上的效应远大于对不吸烟者。效应修饰也解释了为什么一种治疗的相对效应在不同患者中可能相近，而其绝对获益在高风险患者中要大得多（[[epidemiology-ebm/critical-appraisal]]）。

## 控制混杂 {#control}

混杂可以在设计阶段或分析阶段处理。

**在设计阶段：**

- **随机化**使所有混杂因素，无论已知或未知，平均而言在各组间均衡分布。它是唯一能处理无人想到的混杂因素的方法，这就是为什么随机试验是治疗问题的标准（[[epidemiology-ebm/randomised-trials]]）。
- **限制**把研究限于混杂因素的一个水平，例如只纳入不吸烟者。它简单有效，但限制了结果的推广。
- **匹配**使比较组在选定的混杂因素上相似，如年龄和性别。在病例对照研究中，分析时必须考虑匹配。

**在分析阶段：**

- **分层**在混杂因素的各水平内分析关联，然后合并各层估计值。**Mantel–Haenszel**法给出加权平均值。对于以$i$标记的病例对照分层，第$i$层有$n_i$人，

$$
OR_{MH} = \frac{\sum_i a_i d_i / n_i}{\sum_i b_i c_i / n_i}.
$$ {#eq-mh}

- **多变量回归**（logistic回归、Cox回归、泊松回归）可同时调整多个混杂因素。
- **倾向性评分**概括了在给定可测特征时接受某种治疗的概率。评分相近的患者可以配对，或用评分进行加权或调整。

所有分析方法都有一个共同的局限：它们只能调整那些被测量、且被准确测量的混杂因素。当混杂因素测量粗糙时（例如吸烟只记录为“是/否”），会留下**残余混杂**；当混杂因素根本没有记录时，会留下**未测量混杂**。本章开头的激素替代治疗故事就是标准例子。那些研究调整了许多因素，但“属于会服用预防性药物的那类人”是它们无法测量的。

该图说明了Jerome Cornfield及其同事在1959年首次提出的论证，当时批评者提出某种隐藏的体质因素同时导致吸烟和肺癌。要使这样一个因素单独产生观察到的九倍危险比，它在吸烟者中的流行程度必须至少是不吸烟者的九倍，而且必须与肺癌强相关。没有任何合理的候选因素接近这一要求。这类敏感性分析，包括现代的**E值**，追问的是：未测量混杂需要多强，才能把观察到的关联完全解释掉。

## 与时间有关的偏倚 {#time}

有几种重要的偏倚来自时间的计算方式。

**领先时间偏倚。** 筛查使疾病更早被发现，因此即使死亡发生在完全相同的年龄，从确诊起算的生存期也会更长。一个人65岁因症状确诊癌症、70岁死亡，其生存期为5年。如果筛查在62岁发现同一癌症，而死亡仍在70岁，那么从确诊起算的生存期将为8年，而实际上什么都没有改变。

**病程长度偏倚。** 生长缓慢的肿瘤在可检出的无症状期停留更久，因此筛查优先发现它们。所以即使筛查毫无益处，筛查发现的癌症也比有症状的癌症预后更好。

**过度诊断**是极端情况：发现了在此人一生中永远不会引起症状或死亡的疾病。韩国自1999年起在全国筛查项目中加入甲状腺超声后，1993年至2011年间确诊的甲状腺癌数量增加了约15倍，而甲状腺癌死亡率保持平稳（Ahn、Kim和Welch，2014年）。多出来的癌症大多是小的乳头状肿瘤，它们本不会伤害被发现者。

**永生时间偏倚。** 当队列研究根据随访开始后才发生的事件把人归为“治疗组”时，就会出现这种偏倚。一个人必须活得足够久才能接受治疗，因此治疗前的时间对治疗组而言是“永生”的，却被计入他们的随访。

::: example 永生时间 {#ex-immortal}
一项虚构研究从心肌梗死患者出院之日起随访。在随后12个月内任何时候领取过某种新药处方的患者被归为“使用者”，其他人为“非使用者”。使用者在这一年中的死亡率低得多。这一分析有什么问题？
::: solution
在第6个月领取处方的患者，按定义必须已经活过了前6个月。这6个月有保证的存活被计为使用者时间，尽管患者当时还未服药。与此同时，早期死亡的患者根本没有机会领取处方，全都被计为非使用者。即使该药毫无作用，它也会显得有保护作用。

正确的分析把用药作为**随时间变化的**暴露：每名患者在开始用药之前贡献非使用者人时，之后贡献使用者人时。另一种方法是**界标分析**，在一个固定时间点（比如3个月）界定暴露，并从该时间点开始对所有人随访。一种较新的方法是**目标试验模拟**，把观察性分析设计成模仿一项假想的随机试验，有一个明确的零时点，使入选资格、治疗分配和随访开始在该时点重合。
:::
:::

::: warning 调整一切并不等于正确调整
人们很容易把所有可得变量都放进回归模型。但调整中介变量会去除部分真实效应，而调整对撞变量（暴露与结局的共同后果，或通过其他路径受二者影响的变量）会在原本没有偏倚的地方制造偏倚。调整变量多并不是质量的标志。重要的是，这些变量是否根据合理的因果模型选择、测量是否良好，以及是否在暴露之前记录。
:::

::: quiz
一项队列研究发现，服用维生素补充剂的人死亡率低于不服用者。在调整年龄、性别、吸烟和体重指数后，风险比为0.85。在得出补充剂能延长寿命的结论之前，最需要考虑哪种解释？
- [ ] 随机误差，因为风险比接近1
- [x] 由注重健康的行为和社会经济地位造成的残余混杂和未测量混杂
- [ ] 回忆偏倚，因为补充剂使用是自我报告的
- [ ] 领先时间偏倚
::: solution
服用补充剂的人在许多难以测量的方面不同：膳食、运动、收入、教育、获得医疗服务的机会以及对症状的关注。这种**健康使用者效应**是一种混杂，仅调整少数几个变量无法消除。许多补充剂的随机试验总体上并未显示队列研究所提示的死亡率获益。回忆偏倚关系不大，因为补充剂使用是在死亡之前记录的；领先时间偏倚涉及的是从确诊起算的生存。
:::
:::

## 从关联到因果 {#causation}

没有任何观察性研究能证明因果关系。但因果判断必须作出，而且往往很紧迫，因为公共卫生无法等待那些永远不会进行的试验。1965年，奥斯汀·布拉德福德·希尔（Austin Bradford Hill）提出了流行病学家至今仍在使用的几点考虑。

::: theorem 布拉德福德·希尔关于因果关系的考虑 {#thm-hill}
在发现一个关联、并考虑了机遇和偏倚之后，下列特征使因果解释更可能或更不可能：

1. **强度**：大的相对危险度更难用混杂来解释。
2. **一致性**：该关联被不同研究者、在不同人群中、用不同方法反复发现。
3. **特异性**：暴露与某一特定疾病相关，而不是与一切相关。
4. **时间顺序**：暴露先于结局。
5. **生物学梯度**：风险随暴露剂量或持续时间增加而上升。
6. **合理性**：存在可信的生物学机制。
7. **连贯性**：这一解释与已知的疾病自然史和生物学相符。
8. **实验证据**：去除或减少暴露会减少结局。
9. **类比**：已知类似的暴露会引起类似的效应。

只有时间顺序是必要的。其余各项都不是必要的，也都不是充分的。
:::

::: proof
每一点考虑的作用都在于使其他解释变得不太可能。

强关联需要一个相应强且分布不均的混杂因素才能被解释掉，如上图所示。在混杂结构和偏倚各不相同的多种情境中保持一致，使得某一种共同偏倚解释所有结果的可能性变小。剂量反应关系较难由混杂产生，除非混杂因素也随剂量同步变化。时间顺序是“原因”一词的含义所要求的：结果不能先于原因。实验，包括人们停止某暴露后疾病率下降这样的自然实验，消除了比较选择不同暴露的人时所固有的大部分混杂。

特异性和类比最弱。吸烟导致多种疾病，因此缺乏特异性并不构成否定因果的理由。合理性取决于当前的知识，而知识可能不完整：斯诺在霍乱弧菌被确认为霍乱病原之前就采取了行动。希尔本人强调，他的这些考虑是辅助判断的工具，而不是用来打分的清单。
:::

::: history
约瑟夫·伯克森（Joseph Berkson）于1946年描述了以他命名的偏倚，他用医院数据说明入院模式如何在疾病之间制造虚假关联。20世纪50年代，吸烟与肺癌之争迫使流行病学家认真思考混杂问题。当时最负盛名的统计学家、本人也吸烟的罗纳德·费希尔（Ronald Fisher）认为，某种共同的遗传体质可能既导致吸烟的冲动，也导致癌症。1959年，Jerome Cornfield及其同事以一个定量论证作答：任何这样的混杂因素都必须与吸烟有着难以置信的强关联，才能解释观察到的风险。

1965年，奥斯汀·布拉德福德·希尔在英国皇家医学会作了一次演讲，发表为《环境与疾病：关联还是因果？》（“The environment and disease: association or causation?”）。他的九点考虑成为医学中引用最多的因果判断框架。自20世纪80年代以来，因果图以及由朱迪亚·珀尔（Judea Pearl）、詹姆斯·罗宾斯（James Robins）、桑德·格林兰（Sander Greenland）等人发展的反事实框架，使混杂、中介和对撞偏倚的逻辑变得精确。
:::

## 后续内容

消除混杂最可靠的方法是随机化，这是[[epidemiology-ebm/randomised-trials]]的主题。诊断准确性研究中的偏倚，如核实偏倚，见[[epidemiology-ebm/diagnostic-tests]]。系统评价用偏倚风险工具对偏倚进行正式评估（[[epidemiology-ebm/systematic-reviews]]）。

::: summary
- 随机误差使估计不精确，并随样本量增大而缩小。偏倚使估计出错，且不会缩小。
- **选择偏倚**源于人们进入或离开研究的方式。当纳入同时取决于暴露和结局时，会出现伯克森偏倚和其他对撞偏倚。
- **信息偏倚**源于测量误差。二分类暴露的无差异错分通常使结果偏向无效值；有差异错分，如回忆偏倚，可以向任一方向偏倚。
- **混杂因素**与暴露相关、导致结局，且不在因果路径上。混杂可以制造、掩盖或反转关联，如辛普森悖论。
- **效应修饰**是亚组之间效应的真实差异；应报告它，而不是把它调整掉。
- 混杂在设计阶段通过随机化、限制和匹配控制，在分析阶段通过分层（Mantel–Haenszel）、回归和倾向性评分控制。残余混杂和未测量混杂依然存在。
- 领先时间、病程长度和过度诊断会扭曲筛查中的生存比较；永生时间偏倚有利于在随访开始后才开始的治疗。
- 布拉德福德·希尔的考虑有助于判断因果关系。只有时间顺序是必不可少的。
:::

## 习题

::: exercise 说出偏倚 {level=1}
说出每种情况中的主要偏倚。(a) 一项出生缺陷的病例对照研究访谈母亲孕期的用药情况。(b) 一项队列研究把核电站工人的癌症死亡率与一般人群比较，发现其较低。(c) 某筛查项目开始后，某癌症确诊后的生存期改善了，但该癌症的死亡率没有变化。
::: solution
(a) 回忆偏倚，一种有差异的信息偏倚：患儿母亲可能更完整地记得暴露。(b) 健康工人效应，一种选择偏倚：在业者比一般人群更健康。(c) 领先时间偏倚，可能还有病程长度偏倚和过度诊断：更早确诊延长了从确诊起算的生存，却没有改变死亡日期。
:::
:::

::: exercise 更大的研究 {level=1}
一项对2000人的队列研究发现一个置信区间很宽的关联。一位同事说，对20万人的研究将同时消除机遇和偏倚。这对吗？
::: solution
不对。更大的研究会减少随机误差，因此置信区间会更窄。偏倚是系统性的，不会随样本量缩小。一项存在混杂或选择偏倚的超大型研究给出的是错误值的精确估计，其狭窄的置信区间可能使错误更具说服力。
:::
:::

::: exercise 混杂因素还是中介变量？ {level=1}
一项研究探讨规律的体力活动是否降低2型糖尿病风险。分析是否应调整(a) 年龄，(b) 坚持活动数年后测得的体重，(c) 社会经济地位？
::: solution
(a) 应当：年龄既影响活动又影响糖尿病风险，且不由活动引起。(b) 可能不应当，至少在主要分析中不应当：体力活动部分是通过减轻体重来降低糖尿病风险的，因此后来的体重是中介变量。调整它只能估计不经由体重作用的那部分效应。（在活动期*之前*测得的体重则不同，它可能是混杂因素。）(c) 应当：社会经济地位既影响活动又影响糖尿病风险。
:::
:::

::: exercise Mantel–Haenszel比值比 {level=2 check="2.19"}
一项虚构病例对照研究有两个年龄层。60岁以下：暴露病例40，非暴露病例60，暴露对照20，非暴露对照60。60岁及以上：暴露病例25，非暴露病例25，暴露对照20，非暴露对照50。计算Mantel–Haenszel比值比，保留2位小数。
::: hint
对每一层，设$a$为暴露病例、$b$为暴露对照、$c$为非暴露病例、$d$为非暴露对照，计算$ad/n$和$bc/n$，其中$n$为该层总人数。
:::
::: solution
60岁以下：$n = 180$；$ad/n = 40 \times 60/180 = 13.333$；$bc/n = 20 \times 60/180 = 6.667$。（该层OR = 2.0。）

60岁及以上：$n = 120$；$ad/n = 25 \times 50/120 = 10.417$；$bc/n = 20 \times 25/120 = 4.167$。（该层OR = 2.5。）

$OR_{MH} = (13.333 + 10.417)/(6.667 + 4.167) = 23.75/10.833 = 2.19$。

粗比值比为$(65 \times 110)/(40 \times 85) = 2.10$，与调整值接近，因此这里年龄不是强混杂因素。
:::
:::

::: exercise 被错分稀释 {level=2 check="2.27"}
在一项虚构病例对照研究中，真实情况是100名病例中40人、100名对照中20人有暴露。暴露测量的灵敏度为0.9、特异度为0.95，两组相同。计算真实比值比和观察到的比值比，观察比值比保留2位小数。
::: solution
真实比值比$= (40 \times 80)/(60 \times 20) = 2.67$。

病例中被归为暴露者$= 0.9 \times 40 + 0.05 \times 60 = 36 + 3 = 39$；非暴露者$= 61$。

对照中被归为暴露者$= 0.9 \times 20 + 0.05 \times 80 = 18 + 4 = 22$；非暴露者$= 78$。

观察比值比$= (39 \times 78)/(61 \times 22) = 3{,}042/1{,}342 = 2.27$。无差异错分使估计偏向1。
:::
:::

::: exercise 未测量混杂因素的强度 {level=2 check="1.75"}
某暴露对某结局并无真实效应。一个未测量的二分类混杂因素使结局风险增至4倍，在暴露者中的流行率为60%，在非暴露者中为20%。用图中的公式，研究将观察到多大的危险比？
::: solution
表观$RR = \dfrac{0.6 \times (4-1) + 1}{0.2 \times (4-1) + 1} = \dfrac{2.8}{1.6} = 1.75$。

1.75这样的中等危险比完全可以由一个合理的混杂因素产生。这就是为什么观察性研究中的弱关联需要格外谨慎地解释。
:::
:::

::: exercise 解读分层结果 {level=3}
一项关于某药物与消化道出血的虚构队列研究报告粗危险比为2.0。按年龄分层后，65岁以下者的危险比为1.1，65岁及以上者为3.5。年龄是混杂因素、效应修饰因素，还是两者兼有？结果应如何报告？
::: solution
各层的危险比彼此差别很大（1.1和3.5），因此年龄是**效应修饰因素**：该药在老年人中似乎更大幅度地增加出血。如果老年人更可能用药，年龄也可能起混杂作用，但主要发现是各层之间的差异。

单一的调整危险比会对差别很大的效应取平均，掩盖临床上重要的一点。结果应按年龄组分别报告，附置信区间，最好还附绝对风险，因为老年人出血的基线风险也更高。应报告交互作用的正式检验，并检查这一发现的合理性和可重复性，因为亚组差异可能由机遇产生。
:::
:::

::: exercise 运用这些考虑 {level=3}
不同国家的数项队列研究发现，大量饮酒与食管鳞状细胞癌风险升高相关，危险比为3至5，随每日饮酒量增加而上升，在戒酒者中下降。酒精代谢为乙醛，一种已知的致癌物。用布拉德福德·希尔的考虑评估该关联是否为因果性的，并指出主要的替代解释。
::: solution
- **强度**：3至5的危险比属于中等偏强；混杂因素需要与饮酒和癌症都强相关。
- **一致性**：在不同国家的多个队列中发现。
- **时间顺序**：队列设计在确诊之前测量饮酒。
- **生物学梯度**：风险随每日饮酒量上升。
- **实验证据**：戒酒后风险下降，属于自然实验。
- **合理性与连贯性**：乙醛具有致癌性，且酒精直接接触食管黏膜。
- **特异性**较弱，因为酒精与多种癌症相关，但这并不构成否定因果的理由。

主要的替代解释是**吸烟造成的混杂**：吸烟与大量饮酒强相关，且本身就是食管鳞状细胞癌的病因。必须仔细测量并调整吸烟；限于从不吸烟者的分析是一个有用的检验。还应考虑膳食和社会经济地位造成的残余混杂。总体而言，证据支持因果解释。
:::
:::

::: exercise 重新设计分析 {level=3}
一项虚构的登记研究比较了心力衰竭患者中曾被转诊至专科门诊者与从未被转诊者的10年生存，发现转诊与死亡风险降低40%相关。指出两种可能解释这一结果的偏倚，并提出更好的分析方法。
::: solution
1. **永生时间偏倚。** 患者必须活得足够久才能被转诊。如果把转诊归为“曾经”，而随访从确诊开始，那么转诊前的等待时间就成为记在转诊组名下的有保证存活，而早期死亡则累积在从未转诊组中。
2. **指征混杂与选择。** 临床医生可能转诊更年轻、更健康、更可能获益的患者，而不转诊衰弱或临终的患者。这些差异影响生存。

更好的分析把转诊作为随时间变化的暴露，或使用界标时间（例如按确诊后6个月时是否已转诊，计算自该时起的生存）。需要调整确诊时测得的预后因素（年龄、射血分数、肾功能、合并症）。把分析设计为对目标试验的模拟，并设定明确的零时点，能使这些选择明确化。即便如此，未测量的衰弱仍可能存在，因此在没有试验证据时，应谨慎对待这一结果。
:::
:::
