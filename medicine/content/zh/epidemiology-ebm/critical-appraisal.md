一位68岁的男性带着一份剪报来就诊。报道说，一项新试验显示一种广泛使用的药物“使痴呆风险降低三分之一”。他想知道自己是否应该服用。要好好回答他，需要用到本课程的全部内容：知道这是哪种研究，判断其结果是否可能为真，弄清获益的绝对大小，看看试验中的人是否与他相似，了解危害是什么，以及他自己看重什么。这就是**批判性评价**：对研究进行系统的评估，判断其真实性、结果及其与某一具体决策的相关性。

最后这一章把前面各章汇集成一套实用的方法。内容包括循证实践的步骤、评价任何研究的框架、如何把结果应用于个体患者、研究被误导性呈现的常见方式，以及临床指南如何制定和评判。

## 循证实践 {#ebm}

::: definition 循证医学 {#def-ebm}
用戴维·萨基特（David Sackett）及其同事（1996年）的话说，**循证医学**是“认真、明确和审慎地运用当前最佳证据，为个体患者的诊疗作出决策”。它整合了三样东西：可得的最佳研究证据、临床医生的专业技能，以及患者的价值观和具体情况。

它通常被描述为五个步骤：

1. **提出**一个可回答的临床问题。
2. **获取**回答该问题的最佳证据。
3. **评价**证据的真实性、结果和适用性。
4. **应用**证据，结合临床专业技能和患者的价值观。
5. **评估**结果以及自己的表现。
:::

循证医学有时被讽刺为忽视患者的“照本宣科式医学”。其定义说的恰恰相反。证据为决策提供信息，但并不替人作决策。一种平均获益明确的治疗，对于一个优先考虑、其他疾病或具体情况与试验参与者不同的人来说，可能是错误的选择。

### 提出问题与获取证据 {#asking}

一个好的临床问题有四个部分，即**PICO**要素：患者或**人群**、**干预**（或暴露、检测）、**对照**和**结局**。“他汀类药物能预防痴呆吗？”变成“在无痴呆的65岁以上成人中（P），他汀类药物（I）与不用他汀（C）相比，能否降低5年痴呆发病率（O）？”每个要素都提示了检索词，而问题的类型提示了最佳研究设计：

| 问题类型 | 最佳原始研究设计 |
|---|---|
| 治疗或预防 | 随机对照试验 |
| 诊断 | 以参考标准对照、纳入连续患者的横断面研究 |
| 预后 | 在疾病早期共同时点纳入患者的队列研究 |
| 危害或病因 | 可行时用随机试验；通常为队列研究或病例对照研究 |

忙碌的临床医生应先检索**经过预评价的**资源：循证指南、系统评价（如Cochrane图书馆）和证据摘要，然后再看单项研究。一篇好的系统评价已经完成了单个读者无法完成的检索和评价。

## 评价的框架 {#framework}

::: theorem 三个评价问题 {#thm-appraisal}
每项研究，无论其设计如何，都可以按顺序提出三个问题来评价：

1. **结果真实吗？** 研究的设计和实施是否能防范偏倚？
2. **结果是什么？** 效应有多大，估计有多精确？
3. **结果对我的患者有帮助吗？** 参与者、干预和结局是否与我的情况足够相似，获益是否超过危害和成本？
:::

::: proof
顺序很重要，因为每个问题都依赖于前一个。如果一项研究存在严重偏倚，其效应大小就不值得解读，因为它可能反映的是偏倚而不是真相；所以真实性排在第一。如果一项真实的研究显示的效应太小或太不精确，无关紧要，那就没有什么可应用的；所以结果排在第二。只有一项真实且结果重要的研究，才会引出适用性的问题，而适用性取决于个体患者和情境，研究本身无法回答。结构化的清单，如批判性评价技能项目（CASP）的清单，是针对特定设计对这三个问题的细化。
:::

具体问题因研究类型而异。

**治疗（随机试验）**

- 分配是否随机并隐藏（[[epidemiology-ebm/randomised-trials]]）？
- 各组基线是否相似？
- 参与者、临床医生和结局评估者是否尽可能设盲？
- 随访是否完整，参与者是否按其被随机分配的组进行分析？
- 主要结局是否预先规定、已注册，且对患者重要？
- 结果：绝对效应和相对效应、NNT及置信区间（[[epidemiology-ebm/statistics-for-clinicians]]）；危害。

**诊断（检测准确性研究）**

- 是否与适当的参考标准进行了独立的、盲法的比较？
- 患者是否涵盖实践中将使用该检测的疾病谱？
- 是否无论检测结果如何，每个人都接受了参考标准？
- 结果：灵敏度、特异度，最好还有似然比（[[epidemiology-ebm/diagnostic-tests]]）。

**预后（队列研究）**

- 样本是否有代表性，是否在病程中的共同时点组建（**起始队列**）？
- 随访是否足够长且完整？
- 结局是否客观定义，并在不知道预后因素的情况下评估？
- 结果：结局随时间发生的概率及置信区间；如涉及预测模型，是否经过验证？

**危害（队列研究或病例对照研究）**

- 比较组除暴露外是否相似，混杂因素是否被测量和调整（[[epidemiology-ebm/bias-confounding]]）？
- 各组的暴露和结局是否以相同方式测量？
- 随访是否足够长？是否存在剂量反应关系？关联在各研究中是否一致？
- 结果：相对危险度或比值比，以及需害人数。

CONSORT（试验）、STARD（诊断准确性）、STROBE（观察性研究）和PRISMA（系统评价）等报告规范列出了论文应报告的内容。一项研究没有报告某个条目，就无法就该条目评价它；但遵循报告规范本身并不是质量的标志：设计糟糕的研究也可能报告得很好。

::: example 评价一篇试验摘要 {#ex-appraisal}
一篇虚构的摘要写道：“在一项双盲试验中，4000名60–80岁的高血压成人被随机分配到药物X或安慰剂组。4年内，由心血管死亡、心肌梗死、卒中或因心绞痛住院组成的主要复合结局在药物X组发生率为6.0%，安慰剂组为8.0%（风险比0.74，95% CI 0.60至0.92）。药物X使心血管事件减少了26%。”请评价。
::: solution
**真实性。** 随机分组且称为双盲，这是好的开端。摘要没有说明分配如何隐藏、有多少人失访，以及是否按意向性治疗分析；这些必须在全文及其CONSORT流程图中核查。要核查复合结局是否就是注册的主要结局。

**结果。** 相对降低为26%；绝对降低为4年内$8.0 - 6.0 = 2.0$个百分点，NNT为50。区间不含1，但与小至8%的相对降低相容。复合结局把严重事件（死亡、心肌梗死、卒中）与一个较“软”的事件（因心绞痛住院）混在一起。应查看论文中按组成部分的分解：如果差异主要来自心绞痛住院，其临床价值就小于标题所暗示的。

**适用性。** 试验纳入的是60–80岁的高血压患者；他们在风险、合并症和其他治疗方面与我的患者相似吗？不良反应和停药率如何，费用是多少？

标题“使心血管事件减少26%”是复合结局上的相对效应。公允的概括应是：“4年内，每100名接受治疗的人中约有2人避免了其中一种事件，主要是[某组成部分]，副作用如下。”
:::
:::

## 从研究到患者 {#applying}

试验报告的是经过选择的人群中的平均效应。有两种调整有助于把它们转化到个体。

**我的患者是否差异大到结果不能适用？** 与其问患者是否符合每一条纳入标准，不如问是否有令人信服的生物学或临床理由，使该治疗在此人身上无效或危害更大。高龄、衰弱或多病共存的患者、孕妇和儿童常被排除在试验之外，对他们进行外推需要格外谨慎。

**我的患者获益有多大？** 相对效应在不同基线风险下往往相当恒定，绝对效应则不然。若相对危险降低为$RRR$，患者未经治疗时的预期事件率为$PEER$，则患者的绝对危险降低为$PEER \times RRR$，其NNT为

$$
NNT_{\text{患者}} = \frac{1}{PEER \times RRR}.
$$ {#eq-nnt-patient}

患者的基线风险可以来自经过验证的风险评分（例如英国用于10年心血管风险的QRISK3），也可以来自以试验对照组风险的倍数表示的临床判断。

::: widget plot
f: 1/(x*r)
x: 0.01, 0.5
y: 0, 200
sliders: r=0.25:0.05:0.8:0.05
labels: \text{NNT}
caption: 对于相对危险降低由滑块设定的一种治疗，基线风险为横轴数值的患者的需治人数。同一种治疗在高风险患者中NNT可以是10，在低风险患者中则远超100。这是一个假定相对效应在不同基线风险下恒定的简化模型。
:::

::: example 两位患者，一项试验 {#ex-individual}
某治疗使10年心血管事件相对降低25%。患者A是一位吸烟且患糖尿病的70岁男性，10年风险为20%。患者B是一位胆固醇轻度升高、无其他危险因素的50岁女性，10年风险为5%。计算每位患者的NNT，并讨论决策可能有何不同。
::: solution
患者A：$ARR = 0.20 \times 0.25 = 0.05$，故10年$NNT = 20$。

患者B：$ARR = 0.05 \times 0.25 = 0.0125$，故10年$NNT = 80$。

用自然频数表示：在100名像患者A这样的人中，约5人通过治疗在10年内避免一次事件；在100名像患者B这样的人中，约1人。

如果该治疗在比如每100人中引起1人出现副作用，那么对患者A而言利弊权衡明显有利，对患者B则接近得多。患者B可以合理地认为，10年内1/80的获益机会不值得每天服药，而另一个风险相同的人可能选择治疗。两者都是循证的决策。证据列出了选项；由患者的价值观在其间作出选择。
:::
:::

**共同决策**是临床医生与患者共同作出这类决策的过程。NICE指南NG197（2021年）规定了在NHS中应如何进行：讨论包括不采取任何措施在内的各种选项，以自然频数、在规定时间内用绝对风险呈现获益与危害，对所有选项使用相同的分母，并在有患者决策辅助工具时加以使用。风险沟通研究表明，人们对“100人中5人”的理解比对“5%”或“降低25%”更准确，图标阵列也有帮助。

## 证据如何产生误导 {#misleading}

即使是真实的研究，也可能以夸大其信息的方式呈现。

- **只有相对效应而没有绝对效应。** “风险减半”可能意味着从万分之二降到万分之一。
- **替代结局。** 把对血液检测或影像的作用说成对健康的作用。[[epidemiology-ebm/randomised-trials]]中的CAST是警示性的例子。
- **复合结局**由其最不重要的组成部分驱动。
- **粉饰**（spin）。在主要结局无统计学意义时强调次要结局或亚组，或结论比结果所能支持的更为有利。把摘要的结论与预先规定的主要结局相比较，是一种快速的检查方法。
- **选择性报告。** 结局或分析与注册的不同。请核查试验注册库。
- **不恰当的对照**，如低剂量的阳性对照药，或在已有有效治疗时使用安慰剂。
- 对长期治疗**随访过短**，可能遗漏迟发的危害并高估持久的获益。
- **利益冲突。** 即使偏倚风险看起来相似，企业资助也与更有利于资助方产品的结论相关。利益冲突应予声明并加以考虑，但不应据此自动否定一项研究。
- **发表偏倚**，在[[epidemiology-ebm/systematic-reviews]]中讨论。

::: warning “有统计学意义”不等于“值得做”
对患者而言，问题不在于差异是否有统计学意义，而在于在相关时间段内，以绝对值计的预期获益是否超过危害、负担和成本，并考虑其优先考虑。一项超大型试验中高度显著的结果，可能对应几百的NNT。在讨论之前，总要把结果换算为绝对获益和绝对危害。
:::

## 临床指南 {#guidelines}

::: definition 临床实践指南 {#def-guideline}
**临床实践指南**是一套经过系统制定的推荐意见，用以帮助临床医生和患者在特定情况下作出诊疗决策。一份值得信赖的指南基于证据的系统评价，由包括患者在内的多学科小组制定，管理了利益冲突，明确说明证据与每条推荐之间的联系，经过外部评审，并会更新。

在GRADE框架下，每条推荐都有一个**方向**（支持或反对）和一个**强度**：当指南小组确信对几乎所有人而言期望效应都明显超过不良效应时为**强推荐**；当利弊较为接近或取决于价值观、因而不同的人作出不同选择都合理时为**有条件推荐**（弱推荐）。
:::

英格兰的NICE按照其手册《制定NICE指南》（*Developing NICE guidelines*）中的方法制定指南，大多数评价问题使用GRADE评估确定性，委员会的判断被明确记录。其措辞体现推荐强度：强推荐用“offer”（提供），有条件推荐用“consider”（考虑）。GRADE的**证据到决策**框架要求小组不仅考虑获益、危害和确定性，还要考虑价值观、资源使用、公平性、可接受性和可行性。

不同国家和机构的指南各不相同，因为各小组对证据、成本和价值观的权衡不同，也因为它们写于不同时期。指南制定的质量可用**AGREE II**工具（2010年）评估，其23个条目涵盖范围与目的、利益相关者参与、制定的严谨性、表述的清晰性、适用性和编辑独立性。

指南是工具，不是规则。它们描述的是在特定情况下对大多数患者最好的做法。出于充分理由偏离指南，并加以记录且与患者讨论，与循证实践是一致的；对指南并非为之设计的患者机械地照搬指南，则不是。

::: example 两份指南意见不一 {#ex-guidelines}
一位医生发现，一份英国指南建议在10年风险达到或超过10%时提供某种预防性药物，另一个国家的指南使用7.5%的阈值，而某专业学会的第三份指南建议所有具有某一特定危险因素的人都使用。对一位患者而言，应如何调和这些意见？
::: solution
首先，核查这些指南是否回答同一个问题、是否使用同一种风险计算工具，因为不同的风险评分对同一个人会给出不同的数字。其次，比较它们的证据基础和日期：较新的指南可能纳入了较旧指南没有的试验。第三，看看每份指南如何权衡成本和价值观。一个必须为整个卫生系统考虑成本效果的国家机构，与一个关注个体获益的专业学会，可能设定不同的阈值，而二者都可能是合理的。第四，用AGREE II判断每份指南的严谨性和独立性，包括小组成员是否存在利益冲突。

7.5%或10%这样的阈值，是在连续的获益尺度上作出的政策选择。对于接近阈值的患者，推荐很可能是有条件的，决策应基于此人的绝对获益、危害和负担以及其偏好，如[[#ex-individual]]所述。在英国实践中，NICE指南通常是参照点，如果决策偏离它，应记录理由。
:::
:::

::: example 评价一项诊断研究 {#ex-diagnostic}
一项虚构研究在一家医院对300名腹痛儿童评价超声诊断阑尾炎的价值。在120名患阑尾炎的儿童中，超声阳性100例；在180名未患病儿童中，阳性18例。超声阳性的儿童接受手术，诊断由组织学证实；超声阴性的儿童在2周时通过电话随访。请评价这项研究。
::: solution
**真实性。** 人群是恰当的：连续纳入的疑似阑尾炎儿童，即使用该检测的疾病谱。但存在**差异核实**：阳性者以组织学核实，阴性者以随访核实。随访可能遗漏一些病例（自行好转或到其他医院就诊的儿童），这会夸大灵敏度。做超声的人是否对临床表现设盲？很可能没有，这会使结果向任一方向偏倚。

**结果。** 灵敏度$= 100/120 = 83\%$；特异度$= 162/180 = 90\%$。$LR^+ = 0.833/0.10 = 8.3$；$LR^- = 0.167/0.90 = 0.19$。超声阳性大大提高了阑尾炎的概率；超声阴性使之中度降低，但在临床怀疑程度高时不足以排除。

**适用性。** 超声的准确性在很大程度上取决于操作者的技能和儿童的体型；专科中心的结果可能无法推广到由经验较少的人员在非工作时间做超声的医院。
:::
:::

- [ ] 该试验本应使用复合结局。
- [x] 粉饰：在主要结局未改善的情况下，结论强调了次要结局和一个亚组。

- [ ] 本应排除65岁以下的患者。
::: solution
试验预先规定的问题已有答案：对1年死亡率无显著效应。在不清楚说明主要结果的情况下突出次要结局和亚组，就是**粉饰**。次要结局和亚组的发现只能产生假设，需要证实。公允的结论应首先陈述主要结果，并把其他发现描述为探索性的。
:::
:::

::: history
“循证医学”一词由加拿大汉密尔顿市麦克马斯特大学的戈登·盖亚特（Gordon Guyatt）于1991年在《ACP Journal Club》的一篇社论中提出，并通过循证医学工作组1992年在《美国医学会杂志》（*JAMA*）上发表的文章而广为人知，该文称之为“一种教授医学实践的新方法”。它源于戴维·萨基特（David Sackett）及其同事自20世纪60年代末起在麦克马斯特发展的临床流行病学，他们在20世纪80年代初以一系列“读者指南”教临床医生批判性地阅读文献。

萨基特于1994年移居牛津，在那里领导新成立的循证医学中心；1996年他和同事在《英国医学杂志》（*BMJ*）上发表社论《循证医学：它是什么，不是什么》（“Evidence based medicine: what it is and what it isn't”），给出了本章引用的定义，并强调了临床专业技能和患者选择的作用。在英格兰，NICE于1999年成立，负责根据证据和成本效果的系统评价制定全国性指导意见。2000年成立的GRADE工作组创建了如今大多数指南制定者用于证据和推荐分级的体系。
:::

## 后续内容

本章是本课程的最后一章。[[epidemiology-ebm/measuring-disease]]中的指标，[[epidemiology-ebm/observational-studies]]和[[epidemiology-ebm/randomised-trials]]中的设计，[[epidemiology-ebm/bias-confounding]]中的威胁，[[epidemiology-ebm/diagnostic-tests]]和[[epidemiology-ebm/statistics-for-clinicians]]中的算术，以及[[epidemiology-ebm/systematic-reviews]]中的综合，都是工具；评价则是把这些工具用于到达诊室的每一份证据的习惯。人群视角在[[public-health]]中继续展开。

::: summary
- 循证医学把最佳研究证据与临床专业技能和患者的价值观整合起来，分五步：提出问题、获取、评价、应用、评估。
- 用PICO构建问题，使问题类型与最佳设计相匹配，并先检索经过预评价的资源（指南、系统评价）。
- 评价每项研究时按顺序提问：结果真实吗？结果是什么？对我的患者有帮助吗？
- 用患者自身的基线风险把相对效应换算为绝对效应：$NNT = 1/(PEER \times RRR)$。同一种治疗可能对一位患者明显值得、对另一位则处于边缘。
- 共同决策（NICE NG197）使用以自然频数表示的绝对风险和决策辅助工具。
- 警惕只报告相对效应、替代结局和复合结局、粉饰、选择性报告、不当对照、随访过短和利益冲突。
- 值得信赖的指南基于系统评价，管理利益冲突，并把推荐分为强推荐或有条件推荐；AGREE II评估其质量。指南为决策提供信息，但不能替代判断。
:::

## 习题

::: exercise 构建问题 {level=1}
一位反复发生尿路感染的30岁女性询问蔓越莓制品是否有帮助。写出一个PICO问题，并指出回答它的最佳研究设计。
::: solution
P：反复发生尿路感染的成年女性。I：规律服用蔓越莓制品（果汁或胶囊）。C：安慰剂或不治疗。O：12个月内有症状、经培养证实的感染次数；以及不良反应和依从性。最佳设计：随机安慰剂对照试验，或此类试验的系统评价。
:::
:::

::: exercise 个体NNT {level=1 check="34"}
某治疗的相对危险降低为20%。一位患者在相关时间段内的基线风险为15%。该患者的NNT是多少（向上取整为整数）？
::: solution
$ARR = 0.15 \times 0.20 = 0.03$。$NNT = 1/0.03 = 33.3$，向上取整为34。
:::
:::

::: exercise 换算试验的NNT {level=1 check="17"}
一项试验报告NNT为50。你的患者基线风险是该试验对照组的三倍，并假定相对效应相同。估计你的患者的NNT，向上取整。
::: solution
绝对获益随基线风险按比例变化，因此NNT除以同一倍数：$50/3 = 16.7$，向上取整为17。
:::
:::

::: exercise 每1000人预防的事件数 {level=2 check="24"}
一位患者某事件的5年风险为12%。某治疗的相对危险度为0.8。每1000名这样的患者治疗5年，可以预防多少次事件？
::: solution
治疗后风险$= 0.12 \times 0.8 = 0.096$。ARR为$0.024$，即5年内每1000名患者预防24次事件（NNT 42）。
:::
:::

::: exercise 从论文计算似然比 {level=2 check="5"}
一项诊断准确性研究报告灵敏度为75%，特异度为85%。阳性似然比是多少？
::: solution
$LR^+ = 0.75/(1 - 0.85) = 0.75/0.15 = 5$。阳性结果使患病概率中度提高。
:::
:::

::: exercise 找出问题 {level=2}
一份新闻稿写道：“一项里程碑式的试验发现，一种新药使LDL胆固醇降低50%，并使糖尿病患者的心肌梗死风险减半。”该试验注册的主要结局是全体参与者的主要不良心血管事件，且未显著降低。列出这份新闻稿的问题。
::: solution
- LDL降低是**替代结局**；重要的是临床事件。
- “风险减半”是**相对**效应，没有绝对数字和时间段。
- 糖尿病患者的心肌梗死结果是**亚组中的次要结局**，而不是主要结果；在主要结局不显著时，它至多只能产生假设。
- 未提及没有改善的主要结局：**粉饰**和选择性报告。
- 未提及危害和费用。
公允的概括应首先说明不显著的主要结局。
:::
:::

::: exercise 获益与危害 {level=3 check="30"}
为便于说明，假设一位心房颤动患者在不抗凝时每年卒中风险为5%。某抗凝药使卒中风险相对降低60%，并使每年大出血风险增加1.5个百分点。每1000名这样的患者每年可预防多少次卒中？与额外的大出血次数相比较，并加以讨论。
::: solution
预防的卒中$= 1{,}000 \times 0.05 \times 0.60 = 30$，每年每1000人（NNT约34）。额外大出血$= 1{,}000 \times 0.015 = 15$，每年每1000人（NNH约67）。

因此，每多出15次大出血，约可预防30次卒中。比较还取决于严重程度：心房颤动所致的缺血性卒中常导致残疾或死亡，而许多大出血可以治疗，但有些（如颅内出血）是灾难性的。对于大多数处于这一风险水平的患者，利弊权衡有利于抗凝，这也是指南推荐抗凝的原因；但对于卒中风险低得多或出血风险高得多的患者，权衡就会改变。这些数字只是示例；实际决策使用经过验证的卒中和出血风险评分以及现行指南。
:::
:::

::: exercise 评价一项预后研究 {level=3}
一项虚构研究报告：“Z病患者预后极好：95%在5年时存活。”患者从一家三级专科门诊招募，从确诊到首次就诊的中位时间为3年，30%失访。请评价这一说法。
::: solution
- **不是起始队列。** 患者在确诊后中位3年才到达三级门诊，因此早期死亡或病情迅速进展者从未进入研究。这种幸存者偏倚使预后显得比实际更好。
- **转诊偏倚。** 三级门诊看到的是经过选择的人群，可能病情更重（预后更差），也可能更稳定、资源更好（预后更好）；无论哪种情况，结果都可能不适用于在全科医疗中新确诊的患者。
- **30%的失访**很多。如果失访者结局更差，例如因病重无法就诊，5年生存率就被高估了。假定失访者结局更差的敏感性分析会显示95%这一数字有多脆弱。
- 生存应从一个明确的早期时点（确诊）起算，用Kaplan–Meier法估计，并给出置信区间。
对于新确诊的患者，“预后极好”的说法缺乏依据。
:::
:::

::: exercise 评判一份指南 {level=3}
一份关于某种新筛查检测的指南由八名专科医生组成的小组撰写，其中五人从该检测的生产商处领取咨询费。它引用两项观察性研究，强烈推荐50岁以上的所有人接受该检测，并未提及危害。运用值得信赖的指南制定原则和AGREE II对其进行评判。
::: solution
- **利益相关者参与**：小组中缺少全科医生、方法学家、患者和公众代表。
- **编辑独立性与利益冲突**：小组大多数成员与生产商有经济关系，且没有证据表明有冲突的成员被排除在投票之外。
- **制定的严谨性**：没有描述系统评价；对于筛查检测而言，两项观察性研究是薄弱且很可能经过挑选的证据基础，而领先时间、病程长度和过度诊断偏倚在筛查中都很严重。筛查的证据最好来自以死亡率或其他对患者重要的结局为终点的随机试验。
- **推荐强度**：基于低或极低确定性证据作出强推荐，与GRADE不符，少数明确界定的情况除外。
- **危害**：未考虑假阳性、进一步检查、过度诊断和成本，因此无法判断利弊权衡。
- **适用性**：未涉及资源影响和实施问题。
这份指南不应被依赖。临床医生应寻找独立机构的指导意见，例如关于筛查项目的英国国家筛查委员会。
:::
