批判性评价是对已发表主张的临床查体：对每一篇想要改变实践的论文都问一句它测量了什么、可能出了什么错、及数字能否承受其结论的习惯。**这一顶点章节把课程的工具组装成阅读程序：按设计的评价问题（一名能干的临床医师在二十分钟内运行的过滤与取证法）、特殊病态（包装、选择性报告、利益冲突、香肠式发表、图像诚信层、及掠夺性出版）、指南复杂性层（把指南作为“证据加价值”的文献来评价）、及实践终点：在不确定下阅读、改变想法包括你自己的、及把这一习惯教给在摘要与海报上长大的一代。**

## 程序

::: definition 按设计评价、按阅读顺序 {#def-procedure}
**能干的读者带着问题到来、而每种设计的问题就是其效度条件的倒读。对一项随机试验（各章的演算例子）：受试者是否明确合格而有代表性（人群问题）、分配是否隐藏而分组出人意料（选择）、对在意信念的结局是否有人设盲（测量）、随访是否按组不同而理由被制表（流失）、分析是否按分配组而结局是否为注册的结局（报告链）、及效应的区间能否以绝对方式临床辨读（解读层）——把Cochrane偏倚风险域转换成一个阅读顺序而不是一张评分表。对诊断研究：谱系（连续无选择对两杂货店设计）、参考标准的现实性与盲法、检验阴性者的确认路径、及论文自己结论所使用阈值上的操作特征。对预后与病因队列：选择机制、结局查寻独立于暴露测量、作为图可见或作为借口缺席的混杂规划、及持续时间对潜伏期的充分性。对系统综述：问题匹配、检索日期、流程、偏倚工具的使用、及模型与预测区间。对定性研究（课程正在重建对其的评价素养）：该范式自身的担保——抽样逻辑、数据饱和的可辩护主张、反身性陈述、分析方法的审计轨迹——按该传统的标准判断、而不是一个变形的定量模仿。跨领域的取证：基线表讯问（使若干试验下马的“好得不像随机化”均衡模式）、方法对结果一致性一遍（所描述的分析是否产生所报告的分析）、及图与补充材料审计（抓住单位与坐标之罪的“重画主要结果”纪律）、及整座装置为之服务的收尾临床问题：考虑到这一证据的诚实分量、它是否改变我行动阈值——循证医学三一体的原始表述（最佳证据、临床专长、患者价值）、其第二与第三条腿是评价文献不断任其萎缩的。**
:::

## 病态

::: definition 以遗漏与虚构误导 {#def-pathologies}
**误导创新文献值得在每一门课程中占一席之地：“包装”分类学（结论与主要结果不一致——“转移到次要终点”与“安全性被省略”两类及其在非劣效试验摘要中被量化的流行度）、阳性结果包装工业（作为标题的亚组、只有相对风险的摘要、及论文自己结果都不承认的主驱动成分的复合终点锚定）、及其探测启发：在读结论之前先读主要终点的结果；把摘要的主张与注册库记录的主要终点对比；及在接受复合终点之前先读次要终点的森林图。选择性与扭曲报告：终点更换（注册库对论文比较）、“一项试验多次发表”的香肠经济（揭示发表计数膨胀的试验注册库交叉参照）、及事后重新定义（“应答者指数改善”各种文体）。利益冲突如今是一个证据质量域、不是一句忏悔：赞助一致性文献（经济关联在产业资助试验与指南小组之间效应方向的一致性）、幽灵与客名作者审计（产业撰写文件中赠礼署名流行度）、及被作为数据来源来读的披露表（谁设计、谁分析、谁有否决权——“关键问题”的翻译）。研究诚信取证已经专业化：图像重复与篡改筛查（PubPeer传统的公民科学起源、撤稿机器研究、及被撤稿论文被引用的半衰期）、统计取证工具（基于末位数字与生日悖论的异常、GRIM与StroopTest与MatchTables一类的工具、其假阳性率由从业者自己报告）、及该领域很晚才学会的诚实姿态：诚信筛查是概率性的、只在汇总时才具指控性、而最好内置于期刊而不是在推文之后螺栓补装。出版伦理较轻的接触：掠夺性出版生态（图书馆科学文献记录的“特刊垃圾与假影响因子与名誉编辑”装置）及其评价启发（谁邀请了这个、花了多少钱、编辑班子是否真实）。本章的元规则：病态会聚——一个分配隐藏失败加终点更换加未披露赞助的试验是常见模式、这就是为何评价读起来是一个可信与不可信的格式塔、而练习部分对此演练。**
:::

## 实践

::: definition 指南、不确定性与教授这一习惯 {#def-practice}
**评价指南是隔一层的评价：问题集——谁写的（委员会的利益结构与患者参与的现实）、什么证据引擎（系统综述的时新性与去重完整性）、推荐如何分级（证据到决策表的可见性——“强推荐而证据稀薄”案例、其中价值或资源完成了工作、而理由值得论文自己的字数）、它关于变异与公平说了什么（对服务不足人群的外推）、何时更新及异议如何被记录（少数票传统的衰落及其对合法性的代价）、及其现实性（推荐的资源假设对照本地能力——“指南作为乌托邦”失败模式）。在不确定下阅读的实践——一切服务于这个终点——有可学习的行为：命名你的先验（“如果方向相反它会改变我的想法吗”检验暴露了动机的阅读）、把效应估计作为包含零邻域的区间持有、区分“没有证据”“有无效的证据”及“证据不成熟”、及校准习惯（“如果我每天都依此行动”把相对主张变成门诊行为的绝对风险算术）。实施文献给阅读提供了背景：证据通过摘要、意见领袖及临床医师自己患者的问题到达（知识转化框架——“缺口不在图书馆”时代综合而无应用的发现、被审计反馈与本地支持者干预不完全地移动）、这就是为何评价与沟通各章配对：为自己评价是统计、为患者评价是语言。教授这一习惯：评价课程的证据（“有结构化工具的期刊俱乐部对自由讨论”研究的小效应、带间隔与评估反馈设计的优越性、及带案例的刻意练习发现）、比课程活得更久的工作场所工具（一页的设计特异问题单、查注册库的反射、及“先读方案”文化）、及本章以其收尾的智识诚实层：评价最严地应用于证实你实践的那篇论文、让你得意的那个发现、及你写的那份指南——因为这座装置的目的不是抓住坏作者、而是保护你未来的患者免于你现在的信念、这就是没有任何工具能从外部探测的唯一偏倚。**
:::

::: example 二十分钟 {#ex-twenty}
在坐火车的时间里评价这份试验报告：“他汀对常规照护在75岁以上无心血管病成人中：3000名受试者、5年、主要终点为心血管死亡与住院合并；风险比0.81（0.68至0.96）、P=0.015；由一个基金会资助。”
::: solution
**巡视一遍（[[#def-procedure]]、[[epidemiology-ebm/statistics-for-clinicians]]）：人群：75岁以上、一级预防——一个被多数他汀试验排除的组、所以这一问题确实有政策相关性、而合格与同意模式需要检查（“最年长者的代表性”之问——健康志愿者偏斜会削弱获益的可推广性）。结局：那个复合——什么驱动了它？结果表的成分：如果住院（软、受求医影响、在一个开放标签设计中无法盲）驱动了一个死亡中性的效应、主张就变弱；检查死亡率单独是否报告及其区间。设计：它设盲了吗（在这个年龄的安慰剂对照试验罕见；开放标签状态会把一个软复合大幅降级——“知道自己在被治疗”的入院行为通道）。报告：注册了吗？主要终点与注册一致吗？流程图按组的流失（5年随访中最年长者的差异性丢失之问、其中死亡与住院相互竞争——死亡与患病复合结局文献的处理方式）。效能：3000人5年是温和的——区间下限（0.68）可能超过一个无症状人群的最小重要获益；绝对风险差（事件表除以分母）才做决定。阅读裁决三行：“在一个未被充分研究的人群中与获益一致的信号、很可能由复合的软成分驱动、而其效应量的合理性取决于摘要省略的绝对值；对衰弱与极高龄者、共享决策现在就应该改变；而该试验使均势而非终结均势。”培训要点：整个流程就是读对四张表并问设计的五个问题、而p值没有贡献任何其中一项不能更好说出的东西。**
:::

::: example 指南与村庄 {#ex-village}
一份国家高血压指南的治疗达标阈值更新（130/80）在你的诊所被逐字实施；你的审计发现新符合条件者中22%超过80岁、而该阈值的试验证据建立在75岁以下成人、其基线风险多数高于你登记册的人群。
::: solution
**在实地评价指南（[[#def-practice]]、[[epidemiology-ebm/statistics-for-clinicians]]、[[cardiovascular/hypertension]]）：评价：在其人群层面重读阈值的证据基础（SPRINT与降压试验的资格、衰弱老人排除、“动态对门诊测量”背景、及指南自身对极高龄者的确定性降级——“过度治疗在衰弱中的可能危害”遇上“选定老年人群的心血管获益”的证据到决策表）、实施忠实性的失败（跳过年龄交互的目标人群映射）、及公平与工作量的算术（登记册的22%是一个队列、而队列会降低证据充分多数人的照护）。回应集：在指南允许的裁量之内记录诊所层面的调整（若干国家机构明确允许的“80岁以上与衰弱者个体化阈值带共享决策”方案）、把审计作为触发记录、对新符合条件者的去处方与晕倒发作及跌倒风险复审（“治疗整个人”年度复审相邻路径）、及向指南实施支持的反馈回路（指南机构日益作为修正案发表的“实地发现外推缺口”报告）。教学版本：指南是一份技术转让文献、而其证据在其人群结束之处停止；在证据之外实施不是依从而是权宜、它必须要么记录为本地政策、要么说明理由拒绝。给82岁新被贴上高血压标签者的门诊翻译：她这个年纪人群的绝对获益数字（获益更小危害更快的算术）、她自己的优先事项（“什么对你要紧”框架）、及诚实那句：“主要设定这个数字的那个试验没有纳入很多像你这样的人；这是我们确实知道的、而这是我们要猜的部分。”**
:::

## 通向何处

每一章都是本章的先修：设计在[[epidemiology-ebm/observational-studies]]与[[epidemiology-ebm/randomised-trials]]、错误在[[epidemiology-ebm/bias-confounding]]、数字在[[epidemiology-ebm/statistics-for-clinicians]]、检验在[[epidemiology-ebm/diagnostic-tests]]、综合在[[epidemiology-ebm/systematic-reviews]]、而临床应用与指南文化在[[clinical-skills/clinical-reasoning]]与[[clinical-skills/records-handover]]。

::: history
**批判性评价的史前是治疗时尚与怀疑之间的走索：十八世纪关于放血的辩论（支持与反对双方数十年来从病例与理论立论）、Louis的数值方法（1825-1834年的肺炎计数小册子、使“它有用吗”成为一个算术问题、并激起该职业第一次有记录地对同行数据的方法学拒绝）、及随之而来的治疗虚无主义世纪。现代装置与试验在同一片战后土壤中生长：Bradford Hill 1966年的《医学统计学原理》（“读你自己的图”传统）、Mainland坚持临床研究中统计作者身份、1960-70年代“临床生物统计与JAMA编辑”学派、及McMaster小组1981-82年的医学文献使用者指南系列——以杂志形式命名了这一学科并把问题做成全国流通的索引卡。循证医学1992年的JAMA声明（“Sackett与Guyatt及Guyer”宣言、带其“持续自我教育与检验证据”框架）、合理查体系列的床旁数字、及Cochrane与GRADE的建制化到2000年代使评价成为英语世界课程的主干、而“循证医学被批评”文献（定性研究与临床判断的辩护传统）使该运动对其化约倾向保持诚实。病态层更新：1980-90年代“未发表试验”调查（“它们从不发表”丑闻的量化）、2000-10年代的包装与终点更换文献、2010年后的图像取证与PubPeer时代、撤稿潮分析、可重复性危机的跨学科传染、及使评价成为公民而非职业能力、疫情快速、有缺陷而争议论文的洪流抹平了读期刊与读新闻区别的2020年代科学信任紧急状态。当前前沿就是实践定义所命名的：融入临床工作流的评价（带自己偏倚审计的床旁证据工具）、以能留住的反馈来教（“期刊俱乐部有效性”文献终于产出一个可用设计）、及对自己实践——承认评价是预防自己未来的错误而不是起诉别人过去错误的反身转向。—— [[public-health/screening]]、[[clinical-skills/communication]]。**
:::

::: summary
- 评价因设计而异：每种研究类型的效度条件（隐藏、盲法、流失、确认、谱系、检索、可传递性）成为阅读问题、而一次二十分钟的结构化巡视胜过一个钟头的凭感觉。
- 病态聚集并指向同一方向：包装、终点更换、选择性纳入与未披露冲突与赞助及奉承现有实践的发现相关——才是应当拉响警报的模式、不是单个缺陷。
- 注册库对论文比较是产出最高的单一取证；第二是从表格重新计算标题。
- 指南是证据加价值加资源：评价证据引擎与决策表、并把未标注的外推（年龄、衰弱、全球南方）当作它们本来的实施风险。
- 在不确定下阅读是可训练的行为：命名你的先验、阅读绝对效应、区分三种零、并把装置最严地用于它证实你的地方。
- 评价是课程的终点、因为临床判断正是证据、专长与患者价值被调和之处——而只有在证据先被诚实地读过之后、这一调和才是可审计的。
:::

## 练习

::: exercise 运行注册库检验 {level=1}
一项2023年的试验论文声称其预先指定的主要终点是“12周时抑郁量表应答率”；你在注册库中找到该试验、其注册的主要结局是“8周时的量表均数”。写出你会在评审意见中提出的三个问题及作者的三种可能诚实回答。
::: solution
**先审计再相信（[[#def-procedure]]、[[#def-pathologies]]、[[epidemiology-ebm/statistics-for-clinicians]]）：三个问题：方案或注册记录是否有任何时间戳版本或版本历史能证明更换在入组前作出？两个测量都报告了吗、其区间是否指向同一方向？这一更换是否出现在结果表格被填充之前的某个公开场所（会议摘要不是）（[[clinical-skills/records-handover]]）？三种诚实答案：（a）“在入组开始前更换、带小组决定日期”——可以接受、但论文必须报告两者（[[epidemiology-ebm/randomised-trials]]）；（b）“论文按原注册分析、而摘要强调了更显著的8周均数”——一种包装，必须撤下并重写；（c）“我们在数据锁定后更换”——一个需要更正或撤稿的报告完整性事件，取决于更换是否改变了结论（[[medical-ethics-law/professionalism-regulation]]）。教学收获：这次检验耗时六分钟、而它已经回答了关于每个效应主张完整链条最重要的问题：所测量的与所声称的是否是同一件事（[[epidemiology-ebm/systematic-reviews]]）。**
:::

选一份你在过去一年读过的研究论文（或编造一份可信的摘要），并按设计的偏倚风险域对它评分，说明每一域的担忧方向；然后用同样的严格给自己对这个主题的先验评分。
::: solution
**双向审计（[[#def-procedure]]、[[#def-practice]]、[[clinical-skills/clinical-reasoning]]）：设计到评分（示例答案，一项务实的随机试验）：分配——低担忧（中心随机化，序列不可预测；[[epidemiology-ebm/randomised-trials]]）；偏离既定干预——一些担忧（参与者未盲、物理治疗与行为结局相关；担忧方向：高估获益）；缺失数据——低（每组流失5%、按原因制表）；结局测量——严重（患者报告的主要结局未盲；一个客观次要结局的敏感性分析未预先指定）；报告选择——一些（注册的第二个结局被作为主要结果呈现）。总体：有一些担忧，主要因测量。然后先验评分：我是否比批评一个方法更愿相信这个结果？它是否与我已开的处方一致？我能否说出会改变我想法的一个结果？如果我在读结论之前说不出，那么我的先验就是这篇论文在我这里的偏倚风险域（[[clinical-skills/communication]]、[[medical-ethics-law/professionalism-regulation]]）。收获：把同一份核查表用两次——先对论文、后对自己——是把评价从批评变成纪律的唯一方法。**
:::
:::

::: example 图像说话了 {#ex-image}
一名读者注意到一篇高影响力信号通路论文图2b中“独立”的免疫印迹泳道是图3a对照泳道的镜像裁切；资深作者的回复提供“组装时诚实的重复错误”。写出你的评价与其升级阶梯。
::: solution
**图像取证的相称性（[[#def-pathologies]]）：技术说明：镜像而重复使用的panel是该类别最具诊断性的签名（意外重复确会发生；跨图的朝向翻转复用是一个组装选择、而“诚实错误”辩护需要检查其他panel的完整性与作者的数据可得性）、而评价应精确陈述发现了什么、带坐标与图像处理证据（按取证方法论文的灰度图与边缘匹配）、并区分“无法解释的相似”与“学术不端”——该领域谨慎的撤稿声明已学会这样的措辞。阶梯：索取原始未裁剪图像（期刊的数据可得性政策是杠杆；拒绝或“硬盘坏了”本身就是发现）；期刊通信与编辑升级（来自撤稿案例法的撤稿对更正决策树、而核心图像中的图像级错误倾向于撤稿、因为结果的可信度无法存活）；期刊拖延时的机构通报（研究诚信办公室路径及其时限）；及公开讨论层（PubPeer出版前同行评审的正当角色、规避诽谤的措辞、及作者确实拿出干净原件时更正记录的义务）。本案例教给读者的纪律：绝不从像素指控意图、始终报告可见的东西、并把指控交给“索取原件”这个动作去做。系统性脚注：此类声明之后该论文的引用半衰期、及显示被撤稿发现在引用与教科书中 持续存在的撤稿偏倚文献、就是评价各章坚持在指南更新引用之前重新核查承重文献实时状态的原因。**
:::
:::

::: example 掠夺性的邀请 {#ex-predatory}
一位受尊敬的临床医师接受了一个在线期刊的“杰出教授”头衔、该刊电邮发出邀请、承诺快速发表、并列出系里从未听说过的编辑；同一站点如今正在向你的住院医师项目的病例报告约稿。
::: solution
**评价掠夺性（[[#def-pathologies]]、[[#def-practice]]）：分类学：掠夺性出版作为引用农场与费用倒置商业模式（Beall清单时代的谱系、继任清单的打地鼠、及图书馆文献细化的“它是掠夺性还是只是新而低收入”假阳性问题）、本案例显示的特征：无请自来的荣誉头衔、快速发表的承诺、无法核实的编委会（“已故编辑与被劫持期刊”审计的发现：把现任编委与本人核对）、及与真实期刊相邻的刊名。精确命名的风险：对住院医师、一个无法在任何晋升或评价审查中存活而教会错误引用习惯的“发表”；对科室、授予头衔站点所货币化的资历清洗、及最微妙的危害：看似合法的引用污染未来系统综述的检索结果（筛选工具包记录的纳入掠夺性期刊论文）。回应：通过出版伦理委员会行为准则与开放获取期刊目录交叉核查、书面谢绝并附上科室的引用伦理政策、用五分钟教学警告培训生（谁邀请、收费多少、编委是否真实、网站是否工作、是否在被审计的索引中被收录）、并在该临床医师级别足够重要时向相关欺诈与资历机构举报头衔农场。机构层：晋升委员会如今对照掠夺性清单筛选投稿目标、并为正当的新期刊保留申诉路径——这一政策让下一次的个人谢绝成为不必要。**

## 练习

::: exercise 冷读这份摘要 {level=1}
一份摘要以“治疗Z显著改善生存（P=0.03）、安全性可接受”结尾。列出这句话无法回答的六个问题、及哪些文献部分掌握每个答案。
::: solution
**摘要怀疑演练（[[#def-practice]]、[[#def-pathologies]]）：六个：绝对生存差是多少（结果表的事件计数、不是p值）；哪个生存——总生存还是方法命名的那个复合（结局部分）；针对什么以及多长期间显著（试验设计与随访时长）；排除了谁、读这份摘要的人里有谁像他们（资格与流程图）；生存是否是注册的主要结局（注册库比较）；及“安全性可接受”掩盖了什么（危害表——“试验中安全性报告不充分”文献的核心投诉、因不良事件退出与预先预期的特异危害是要看之处）。部分映射要紧、因为所演练的技能不是怀疑而是导航：知道哪张表掌握哪种纠正就能在几分钟之内把一行主张变成一次评价、而“安全性可接受”短语自己的历史（事后安全性合并各种文体）就是指南各章把摘要当作带引文广告的原因。**
:::
:::

::: exercise 找出冲突 {level=2}
一位指南小组成员共同主持一个由该指南所推荐药物的制造商资助的学会委员会。披露表写着“无冲突”。写出评价备忘录中关于这一点的段落、及证据支持的结构改革。
::: solution
**作为结构的冲突（[[#def-pathologies]]、[[#def-practice]]）：评价段落：披露表捕捉已申报的财务关系；委员会共同主席关系是一种结构性冲突（对资助方的信义责任加上起草推荐的角色）、多数表格依设计漏掉它（指南冲突审计记录的“间接、既往与组织冲突”缺口）、而其方向已被经验确立（产业关联系一致性文献在小组构成与推荐广度上一贯的发现）。备忘录还应记录相反的可能——那位成员可能是对的——因为补救是程序不是人格。有证据的结构改革：指南小组的无冲突多数要求（医学研究所改革相关标准及若干资助方的采纳）、带表决与异议的公开决策记录（指南透明批评者哀悼其消失的“异议段落”）、学会资助与指南预算之间的防火墙（专款模式）、及主席级别被排除在特定推荐的表决之外（“回避并记录”惯例）。给评价的诚实收尾句：该指南的推荐或许能在实质重新评价中存活——审计之问是这一过程本可能否知道自己在做什么、而按事实、它本不可能知道。**
:::
:::

::: exercise 评价这项定性研究 {level=2}
一项对疫苗犹豫父母的定性访谈研究（22次访谈、主题分析）得出结论：犹豫“由信任失败驱动、而不是错误信息”。一位委托方官员提议引用它以重新引导一笔传播预算。按该传统的标准评价。
::: solution
**认真地做定性评价（[[#def-procedure]]、[[#def-pathologies]]）：要检查的担保：抽样逻辑（“最大变异与饱和”主张——22人中有谁、谁无法被接触：积极拒绝与难以纳入是人群的决定性层）、数据质量（访谈提纲与时长——20分钟电话陈述与一小时长谈的差别）、分析透明度（从编码本到主题的审计轨迹、异议案例是否被编码、“一直就在那里的主题”先验检查）、反身性（团队对接种的立场陈述——犹豫研究的不对称问题：确信的访问员可能偶然地抽取信任的陈述而不是信念的陈述）、及主张的抬升（“由……驱动”是一个22人访谈研究无法承受的因果加权短语——恰当的发现是“参与者通过信任关系体验犹豫”、这不同而仍然有用）。给委托方的翻译：该研究支持基于信任的沟通假说（并与调查实验文献“信使重要”发现趋同——跨方法元推断这一动作）、不支持整体转移错误信息项目预算、而证据支持的引文是“定性工作提示框架对犹豫比单纯的事实接触更要紧”——一句设计假说、不是一个拨款公式。教学补充：评价词汇（饱和、反身性、可转移性）不是仪式；每个术语都命名定性主张可能超出其数据的一种特定方式、与定量各章列举的罪行只是方言不同。**
:::
:::

::: exercise 评价这个模型 {level=2}
一项新筛查规划的成本效果分析报告“占优”（省钱而更有效）。其模型：终生视野、依从性假设来自单个试验、对过度诊断无失效用权重、及由该技术的制造商资助。写出评价的四步及那个决定你是否信任其经济学的问题。
::: solution
**模型评价步骤（[[#def-procedure]]、[[public-health/screening]]、[[public-health/health-systems-economics]]）：第一步、结构：决策树或Markov模型是否匹配疾病自然史与规划的真实比较对象（“对不筛查对对当前优化照护”之问决定了结果是否有政策相关性）；转移概率来源被标注。第二步、参数：来自单个试验的依从性推广（被筛查人群依从性文献更低真实世界率——而“占优”结果恰恰对这一参数的敏感性、论文自己的单向龙卷风图应当显示）、过度诊断的遗漏（没有假阳性失效用、获益一侧只有好处——筛查模型评价核查表强制纠正的结构性乐观）、及效用值的出处。第三步、不确定性：概率敏感性分析存在吗？（只有确定性的就是红旗）、及“占优”能否在参数分布的尾部存活（低于约80%的占优概率值得那个委婉标签）。第四步、独立性：制造商资助并列出模型的假设由谁选择——独立重新分析文献记录的“设定假设即倡导”机制。决定性之问：是否存在使用同样方法处理试验数据的独立或公共委托分析（卫生技术评估世界制度化的评价捷径、双重审查相邻）、因为一个模型就是电子表格上的一篇论证、而唯一的审计是别人的电子表格。**
:::

::: exercise 写出局限性 {level=2}
你是作者、正在写你自己队列研究的局限性段落。根据本课程写出它：四个具名偏倚、各自的方向与幅度推理、及你必须忍住不加的那一句。
::: solution
**作为取证的局限性（[[#def-procedure]]、[[epidemiology-ebm/bias-confounding]]）：范例段落：“选择：参与率54%、而未参与者可能更年轻也更不健康；因为两种特征同时预测暴露与结局、健康志愿者机制使暴露对比偏离无效、方向朝向更健康暴露者的模式、未被量化但被无应答调查的差异定界。暴露测量：基线自报摄入的错分类带有年龄与回忆模式、应当使关联减弱（一个推向无效的偏倚、会使观察到的效应保守）。随访丢失：12%、按暴露有差异而按最终结局状态无明显差异；对缺失事件的最坏情形分配使点估计保持在8%以内。残余混杂：调整覆盖了测量的决定因素；一个混杂因子需要在本研究e值计算所命名数值附近的患病率差与强度才能解释全部效应——与吸烟的相伴因素相当、所以不太可能但不是不可能。“要忍住的那句：”本研究有许多局限性”——句什么都承认也什么都不解释的不可证伪的缓冲；本课程灌输的纪律是每个局限性都必须带一个方向与一个数量级、而这一段只有在告诉读者答案可能错多少、朝哪边错时才配得上它的字数。**
:::

::: exercise 向患者教评价 {level=1}
一名患者带来一份报纸主张（“培根致癌、研究称”）并问是否该戒掉。用本课程面向患者的装置：你们一起问的三个问题、及你就加工肉与风险给出的诚实摘要。
::: solution
**出声评价（[[#def-practice]]、[[public-health/non-communicable-disease]]）：翻译后的三个问题：“它是怎么研究的——是随访了人还是给人喂食？”（队列与分类证据对实验、及为何标题里的“致癌”几乎总是意味着“在另外五十个方面也不同的人群中相关”）；“大还是小？”（绝对风险框架：加工肉分类把终生肠癌风险在几个百分点的基线上抬高几个百分点、而吸烟是十倍以上、筛查有可测量的死亡降低——这一排序才是真正的医疗建议）；及“如果方向相反这会改变什么吗？”（价值谈话——相对于绝对数字、培根对她值多少）。诚实的摘要：分类是真实的（关于结直肠癌、专著与国际机构机制的证据质量来自许多一致的研究类型、这正是“证据错了”文体无法说的）、每片每周的效应温和、及“如果你喜欢就减少、想戒就戒、但别让它分散你对肠筛查与血压数字的注意、承载着更大的绝对值”——本章为使门诊成为常规而存在的这次咨询：评价不是对证据愤世嫉俗、而是一同把不确定性算进来。**
