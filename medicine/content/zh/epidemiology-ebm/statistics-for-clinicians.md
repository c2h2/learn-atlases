统计学是临床证据的语法：p值、置信区间、风险比与回归系数是词、其含义由本章的规则确定、而多数发表的误读是语法错误、不是算术错误。**本章涵盖推断（抽样变异、标准误、作为诚实的“估计加不确定度”格式的置信区间、及带其误读与2016-2019改革之辩的p值）、比较（检验的选择作为模型的选择、参数与非参数之问、及多重检验的预算）、关联（相关、回归——线性与逻辑——及生存分析的删失与比例风险合同）、及决策统计（绝对风险、需治数、荟萃分析的逆方差逻辑、及等同与非劣效算术）。**

## 推断

::: definition 变异、标准误与置信区间 {#def-inference}
**每个样本都是从可能的样本分布中抽一次；标准误量化那一散布（平方根n律、其政策后果——精度翻倍要求样本量增至四倍——是本章被引用最多的一条事实）、而中心极限定理为几乎任何母分布的均数批准正态式区间（“小样本用t分布”的精化、及当连这一许可都可疑时自助法的回答——把数据重抽一万次以经验地读出抽样分布）。置信区间是本章坚持的报告格式：95%区间的正确定义（一个在95%的样本中覆盖真实的程序——2010年代看到统计学家公开辩护其被误用为“参数在此区间内有95%概率”的覆盖定义）、其阅读纪律（把区间的界限翻译成临床后果——“排除了15%的降低但无法排除2%”是一句话、“p>0.05”是一个耸肩）、及其与p值的关系（区间就是未被拒绝的原假设之家族——这一对偶使p值的信息在区间存在之后就属多余）。p值的改革弧线属于历史：原假设显著性检验的混合体（Fisher的显著性对Neyman与Pearson的决策程序、一桩两者都不会接受的婚姻）、“小于0.05”惯例作为一个1925年编辑习惯而握有法律权力的地位、美国统计学会2016与2019年声明（“p值与统计显著性”的交锋、提出的术语撤退）、及该领域保留的实务结论：报告带区间的效应、在看到数据之前定义阈值、把0.05当作栅栏桩而不是悬崖、且绝不把两个不显著结果的比较称为显著差异（“显著与不显著之间的差”错误自己的撤稿浪潮）。多重性预算完成推断：十次检验在alpha 0.05下族系假阳性概率接近40%（Bonferroni与守门校正的算术、及使次要主张诚实的预注册加层级纪律）。最后是估计对决策框架（“新统计学”辩论的建设性残余：试验服务于累积证据、所以喂给荟萃分析的区间比接受拒绝的裁决更要紧——这就是本网站练习处处阅读区间的原因）。**
:::

## 关联

::: definition 检验、模型及其假设 {#def-models}
**检验的选择就是模型的选择：t检验在样本均数近似正态（不是原始数据的正态——“差值正态”假设的务实版本）下比较均数、其非参数对应者（Mann-Whitney与Wilcoxon）比较分布或中位数的秩并回答一个微妙不同的问题（当散布不同时“位置检验对形状检验”的歧义——许多配错的分析把它藏起来这一事实）；卡方与Fisher精确检验按期望计数规则处理比例；而“正确检验”决策树实际上是“目标估计量是什么、数据生成过程是什么”这一问。回归把比较扩展到调整：线性回归的假设（参数中的线性——不是数据正态；方差齐性与独立对区间要紧、而稳健标准误补救存在）、逻辑回归的比值比输出（病例对照章关于常见结局比率膨胀的警告重述：逻辑模型在数学上便利、不是天生可解释、而现代软件提供的风险比回归与标准化概率输出对临床受众应被偏爱）、及计数与时间的Poisson与负二项及生存家族对应者。评价者应掌握的模型机制：样本量对参数比（“每个变量十个事件”规则适度的现代表护及其自助法时代的修订）、共线性（在各规格之间互换位置的系数——诊断是不稳定、不是显著）、参照类效应（针对软件选择的那一组读比值比）、交互对分层（主效应加乘积项检验较低的效能、及“亚组即交互”规则）、及预测对解释的离婚（必须行动的模型用交叉验证与大样本校准；解释的模型用系数解读——两个文献词汇表的相撞）。生存分析是自己的合同：删失的非信息性假设（“在观察到的历史给定下退出与未来事件无关”条件及其通常的违反）、Kaplan-Meier曲线作为主要视觉（其下方的“处于危险”表是必读——来自剩余二十名患者的曲线是带置信带的轶事）、log-rank检验与风险比的比例风险要求（Schoenfeld残差与对数对数曲线检查、2010年代心脏与肿瘤试验使其成为标准因为它们的疗法剧烈违反比例性——“延迟治疗效应”例子带其早期平坦晚期分开的曲线、及限制平均与加权风险补救）、及竞争风险的微妙（在老年人群中问题是死因特异的、累积发生率函数对把死亡当作删失）。本章对这一切的规则：统计量的名字告诉你它回答哪个问题；评价者的第一动作就是问那是不是临床问题。**
:::

## 决策

::: definition 效应量、荟萃分析与等同算术 {#def-decisions}
**显著性之前先效应量：绝对风险差及其倒数（需治数——带其区间版本在差越过零时的渐近线陷阱、及需治数协调提案）、带其基线风险依赖的相对风险（使基于风险的治疗阈值成为合理的“同样相对风险不同绝对获益”算术）、及连续结局的标准化均数差（Cohen的d民间说法的“小、中、大”标签、被效应量改革文献斥为无临床锚的无量纲胡话）。等同与非劣效是把决定明确化的问题：边际作为临床无差异的陈述（由谁设定——试验对指南对申办方之争）、两侧单侧检验程序（完全位于边际内的区间）、及试验一章继承的检验灵敏度条件（当活性对照表现不佳时一个劣的治疗被宣布非劣——“生物漂移”与“历史对照”文献）。荟萃分析是效应的逆方差加权平均（固定效应模型的共同真实假设、随机效应模型用研究间方差tau平方正式放松它——及批评：随机效应区间仍假定可交换、小研究效应把合并估计向小研究的夸大肠胀、及tau平方自身从少数研究估计不可靠——Hartung-Knapp与Paule-Mandel调整置信区间精化、及为未来场景推荐预测区间）。漏斗图与Egger检验的不对称装置（发表偏倚探测的低效能名声）、剪补法补救的脆弱、“联系作者否则失去数据”的灰色文献原则、及如今胜过一切偏倚统计的注册库挖掘修正：把每个试验都拿到。异质性阅读：I平方的按情境解读警诫（一种药一种疾病各试验之间高的I平方是值得追捕的异常；跨异质文献中中等的I平方是预期的）、亚组与元回归的多重性纪律、及试验序贯分析对“多少个荟萃分析我们才知道”的回答（告诉指南小组证据何时完成而不只是阳性的累积信息边界）。临床终点：统计学提供证据的规模、精度与一致性；决定需要价值（患者与临床医师）、适用性（你所在人群的基线风险）、及成本与危害框架——这就是本章最后一个定义是批判性评价章第一个的原因。**
:::

::: example 读这个区间 {#ex-interval}
一项试验报告“主要心血管事件：9.8对10.1%、风险比0.97（95%置信区间0.86至1.10）、新预防药P=0.65”。为你的指南小组写三句证据陈述、并指出什么额外证据会改变它。
::: solution
**区间先开口（[[#def-inference]]、[[#def-decisions]]、[[cardiovascular/coronary-artery-disease]]）：陈述：“在这项20000人治疗五年的试验中、新预防药把主要事件按绝对0.3个百分点降低（风险比0.97）；置信区间排除了大于14%的降低与大于10%的增加、所以为这类疗法辩护的那种规模的有临床意义的获益可能性很低、而一个小获益与一个小危害都与数据相容。”正在演示的阅读纪律：把区间界限翻译成临床后果（对这一成本与危害特征的预防药、14%相对是相关性阈值）、绝对框架（五年0.3个百分点——指南通俗摘要中说明五年需治数约330）、及p值的角色（0.65确认点估计邻近噪声；区间已经说了全部）。会改变它的：事件计数（试验的2000个事件对年轻患者要紧的10-15%效应可能效能不足——下一个试验的信息要求、或增加低危分层的个体受试者数据荟萃分析）、终点的构成（这支文献著名的软成分驱动的风险比——死亡或硬事件的重新分析）、及人群的基线风险（区间的绝对阅读取决于10%这一起点；2%风险之问需要自己的试验或模型）。指南结论：“除现有标准治疗外不推荐新预防药；残余不确定在于低危组的小效应、是一个研究优先项、不是一个处方执照。”**
:::
:::

::: example 漏斗图反驳 {#ex-funnel}
一项对孕期广泛使用止吐药的荟萃分析合并31个试验：畸形的比值比0.94（0.86至1.02）、漏斗图不对称、Egger P=0.004；作者得出结论“无增加的风险、而小研究效应在已发表文献中夸大了安全性”。评价。
::: solution
**不对称是一个场景不是裁决（[[#def-decisions]]）：阅读：合并的无效而紧密的区间是指南阅读的标题、而剪补法校正的“修正”估计（0.99）令人安心；但不对称的来源不可互换：发表偏倚（小的有害效应试验未发表或未分析——注册库挖掘文献对抗抑郁药与外科补片发现的“而它们从不发表”一类）、小研究偏倚（方法学质量更低、人群与剂量不同、“早期试验乐观在不同方向”的模式）、真实异质性（剂量、时机、适应症——“早孕反应严重度”对谁根本能得到止吐药的混杂、任何观察性安全性数据的荟萃分析都无法完全关闭的通道）、及偶然（Egger检验在少于四十个研究时效能低、这是双刃）。数据支持的裁决：“在合成的随机证据中没有畸形信号的证据、带残余不对称、其最合理的原因是旧试验的报告习惯而不是真实危害”——这比“安全”更弱、正如止吐文献学到的：编辑们援引的止吐与反应停相邻的历史记忆、正确的比较不是“荟萃分析是否完美”而是“ 底层试验与其注册库的质量如何”（真正为罕见结局安全性提供效能的姊妹安全性数据库与队列研究）。行动：就整个证据提出建议（试验加大队列加带自身偏倚结构的药物警戒）、在指南的证据档案中诚实说明不对称、并让因疑似报告偏倚而GRADE降级停留在它应在的地方。**
:::
:::

::: example 过拟合的预测模型 {#ex-overfit}
一个在40000次入院上开发的脓毒症风险评分报告曲线下面积0.92并带“10折交叉验证的内部验证”及38个预测因子；两家医院的外部验证得到0.71与0.66。供应商的宣传册仍写着0.92。
::: solution
**表观对真实性能（[[#def-models]]、[[#def-decisions]]）：乐观偏倚解释：开发站点的信号（本地患病率、开具习惯、记录风格）被当作普适来学习；38个预测因子在中度事件数上即便有交叉验证也有过拟合风险（交叉验证共享开发数据的分布——“内部验证探测的是乐观偏倚而非可运输性”教训）、而站点特异的关系（“我们的乳酸开具不同”一类）如预期在外部失败。宣传册必须达到的评价标准：按TRIPOD与PROBAST（预测模型偏倚工具）报告的时间与地理上分离数据的外部验证、校准以及区分度（一个0.71面积配完美校准在其自身阈值上可用；0.92配系统性误校准是危险的——决策曲线与校准图一对、不是单一指数）、更新或重新校准分析（常以一个系数为代价挽救可用性能的“局部截距与斜率校正”路径）、影响研究（使用评分是否改变临床医师行为与患者结局——诊断章建立的三层证据阶梯：验证、核实、效用）、及公平亚组表（年龄、性别、族裔、剥夺分层——采购如今要求的模型表现均等审计）。采购答案：该模型是一个有前途的产品草稿；购买重新校准与前瞻影响研究、不是宣传册。教学那句话：一个预测模型的曲线下面积同样是其人群而非其数学的属性——这就是本网站统计各章坚持论文中每个数字都带着它数据的地址。**
:::

## 通向何处

每个设计章都使用这套词汇：[[epidemiology-ebm/observational-studies]]、[[epidemiology-ebm/randomised-trials]]、[[epidemiology-ebm/diagnostic-tests]]；合并在[[epidemiology-ebm/systematic-reviews]]扩展；决策阈值在[[public-health/screening]]；而评价演练在[[epidemiology-ebm/critical-appraisal]]。

::: summary
- 报告带区间的效应并把区间的界限读作临床陈述；p值是对同样数据的摘要、带一个因被误读而赢得的坏名声——它确实名副其实。
- 置信区间的定义是关于跨样本的程序、检验的假设是关于目标估计量、而检验之间的选择就是关于向数据提出哪个问题的选择。
- 多重性是一个预算：十次检验无论分析者是否承认都在花掉alpha；预注册、守门与诚实的次要主张标签是账目。
- 比值比是便利的、不是可解释的；风险比要求比例风险；生存曲线要求它们的处于危险表；而亚组主张要求交互检验。
- 荟萃分析用逆方差权重平均并继承每个试验的偏倚；漏斗不对称命名的是一个嫌疑者不是罪者、而预测区间比合并均值更好地向指南小组讲述新的场景。
- 等同与非劣效把决策边际放进统计内部、这是本章最后的教训：数字从不没有价值护送就走向结论。
:::

**本章的机制有两个很晚才相遇的祖系。数学的：de Moivre与Bernoulli的概率、Gauss与Laplace的误差理论与最小二乘（变成回归的彗星追踪数学）、Galton的相关与向均值回归（统计学从未完全摆脱的优生学词汇表、而评价者应当带着它的历史来发音）、Pearson的系数与假设检验、Student即Gosset以一个啤酒厂笔名写下的小样本t分布、及Fisher 1920年代的综合——最大似然、方差分析、0.05栅栏桩的1925年付印、及试验章遇到的农业试验田所成就的随机化实验设计崇拜。决策论的：Neyman与Pearson的效能与错误框架（alpha与beta架构及置信区间的覆盖定义、刻意与Fisher的归纳解读分开——2016至19年声明重新诉讼的那场离婚监护权之战）、Wald的序贯与统计决策理论（战争年代工业抽样使停止规则与操作特征思维方式诞生）、及贝叶斯恢复（Raiffa与Schlaifer的决策论规划、及成为基率文献的人类概率推理描述性发现、经Kassirer与Kopelman的诊断推理教科书进入临床贝叶斯时代）。临床婚姻通过慢性病试验及其计数问题到来：从精算科学借来的生命表、然后Kaplan与Meier 1958年的乘积极限估计（病毒学稀释测定的起源作为该命名者的脚注保留）、Cox 1972年的部分似然（使风险比成为临床散文的半参数简化）、及Greenfield与Fleiss的荟萃分析正式化（从Glass 1976年造词起的“平均试验”之辩、经Chalmers兄弟的产科汇总规划、“对照试验文件”时代坚持文献本身需要系统综述、及科克伦协作网1993年的建制化带其偏倚风险与漏斗图装置）。2010年代的改革潮跟随可重复性危机的自我审查（“p曲线与p操纵”文献、注册报告运动、美国统计学会2016与2019显著性声明、“退休统计显著性”与“退休p值”的交锋、及使其建议可执行的开放数据与代码基础设施）、而预测模型革命（机器学习诊断的外部验证审计及相关评估框架）重开了本章模型定义所结束的解释对预测之问。该领域反复重学的教训：统计学是把不确定性的逻辑应用于人类制度、而如果方法部分不被当作审计来读、制度会悄悄地腐蚀这一逻辑。—— [[epidemiology-ebm/critical-appraisal]]、[[epidemiology-ebm/systematic-reviews]]。**
:::

## 练习
::: example 什么都没隐藏的回归 {#ex-regression}
一项关于抗生素时长的研究报告：在一个对480个事件使用22个协变量的逻辑模型中、每多一天与30天再入院高4%相关（每日调整比值比1.04、1.01至1.07）。写出你对建模的评价、列出你在相信方向之前要做的四项检验。
::: solution
**每日比值比及其陷阱（[[#def-models]]、[[#def-decisions]]）：检验一、对数发生比中的线性：“每日”假定一个恒定的乘性效应——绘制非参数或样条版本（短住院与长住院携带混杂的适应症；“按适应症与严重度混杂”的信号通常生活在两端）。检验二、每个变量的事件数：22个协变量除480个事件接近规则下限、并低于现代模拟认为能获得稳定调整估计的安全值——寻找缩减模型或惩罚（岭或套索）敏感性分析、并注意协变量清单是否由图预先指定（被调整的感染严重度标志物可能是时长自身效应的中介——“把机制调整掉”的风险在这里反方向运行）。检验三、结局的竞争风险：再入院与死亡相互竞争（“死者不再入院”问题——死因特异对累积发生率方法改变目标估计量）。检验四、聚集与多重性：同一病房、处方者与医院内的患者诱导相关结局（方法必须说明的设计效应校正）、而“每日”加二十二个协变量加次要终点招来无人支付的多重性预算。它无法回答的方向之问：时长是按严重度开的——相似文献的倾向评分与工具变量重新分析通常把这类效应减半的严重度调整残余混杂。评价摘要：“一个假说生成的关联、其方法目前无法把处方逻辑与因果危害分开；那4%是一个未校准的信号、不是一个效应估计。”**
:::

::: exercise 翻译统计量 {level=1}
把每一个转换成给患者手册的两句通俗陈述、保留不确定度：(a) 风险比0.80（0.65至0.98）；(b) 均数差在100分量表上-3.2分（-6.1至+0.3）；(c) 风险比1.05（0.99至1.12）。
::: solution
**区间翻译演练（[[#def-inference]]）：(a)“在研究期间、100名接受治疗者中12人发生事件、而100名未接受者中15人发生。真实获益可能大到把事件减少三分之一、也可能小到几乎为零；我们有信心它不会增加事件。”(b)“平均而言患者在100分量表上好3分、而真实均值可能是好6分到略差之间的任何地方；我们无法说该治疗造成了真实的差别。”(c)“结果与事件率高5%或略低的率相容；最可能的是该治疗两个方向都没有什么区别。“评分标准：在患病率已知之处用绝对数字、把区间的界限翻译成后果、不把”显著“当作”真实”的同义词、及在区间不给承诺时不做承诺——通过的那份手册是机构的法律顾问与患者都认为诚实的那份。**
:::

::: exercise 选择分析方法 {level=2}
为每个指定主要分析：(a) 双臂试验、二分类结局、组间例数不等、罕见事件；(b) 三家独立诊所之间的生活质量评分（偏态、有下限效应）；(c) 研究结束时30%仍在院的时间至出院；(d) 检验阴性设计的疫苗效果。为每个说出目标估计量。
::: solution
**估计量先行的选择（[[#def-models]]、[[#def-inference]]）：(a) 风险差（或带罕见警诫的比值比）配Fisher精确或中项p区间、若存在聚集则带其设计效应；用带治疗对比的逻辑回归做调整——不只是卡方p；目标估计量：对接受治疗人群的绝对效应。(b) 秩的Kruskal-Wallis然后Dunn路径、或鉴于下限效应更好的序数或分位数回归框架（“位移对严格随机排序”目标估计量）；均数差方差分析回答的是一个被偏态数据降为次要的问题。(c) Kaplan-Meier加Cox作为风险比摘要、带比例风险诊断与作为稳健伴侣的限制平均；目标估计量：对出院时间分布的效应、带删失机制一起说明。(d) 来自检验阴性设计病例对照式逻辑模型的比值比——疫苗效果作为1减比值比、假设被命名（求医与检测行为在暴露决策通路之间相等）；目标估计量：对需要检测才能确诊的感染的效果。本练习的规则：检验是目标估计量的仆人、而讨论部分绝不该不得不去发现方法选择了什么。**
:::

::: exercise 找出p操纵 {level=2}
一篇论文的方法写道：“检验了正态性并对非正态数据做对数变换；主要终点在6、12、24个月分析、而报告了12个月的结果；基线吸烟不平衡通过在其改变估计值时作为协变量加入来纠正。”列出灵活点及其多重性代价。
::: solution
**分叉花园审计（[[#def-inference]]、[[#def-models]]）：灵活性清单：事后变换选择（检验正态然后变换——“检验假设”循环、其膨胀温和且被承认）、结局时机的选择（三个时点分析、报告一个——经典的时间樱桃采摘：三次检验在第一类错误率0.05给出约14%的族系假阳性概率、还没算别的）、依协变量的调整（“如果它改变估计就加入吸烟”就是规格搜索的定义——调整应遵循来自图的预先指定模型、因为“改变了估计”可能意味着去除混杂、或去除中介、或买到显著性）、及未声明的默认（意向治疗对按方案、离群值排除、论文补充材料揭露的应答者二分）。累积多重性无法量化因为它不是检验次数而是一棵决策树——Gelman与Loken的“分叉花园”表述、预注册与注册报告改革从结构上回答了它。评价裁决：“所报告效应的p值以一条论文诚实记录而任何校正都无法定价的分析者旅程为条件；把这一发现当作一个待重新检验的预注册假说、不是一个主张。”教学补充：破口不在于单个选择（每一个孤立看都可辩护）、而在于它们全部对结果本身的依条件性。**
:::

::: exercise 解释这个荟萃分析 {level=2}
一项荟萃分析报告合并风险比0.85（0.78至0.93）、I平方62%、九个试验的预测区间0.68至1.04。向一个指南小组解释该得出什么结论、及预测区间在置信区间之外增加了什么。
::: solution
**两个区间两个问题（[[#def-decisions]]、[[epidemiology-ebm/systematic-reviews]]）：置信区间回答：“试验之间的平均效应是什么”（均值带其精度）。预测区间回答：“在一个新的场景中效应可能是什么”——纳入合并均值抹平的研究间变异；这里它包含了1.0、所以一个未来人群可能看不到获益。62%的I平方说明试验效应变异超出抽样所能解释——所以合并的0.85是一个其分布要紧的平均、而追捕开始了：什么不同（人群、剂量、偏倚风险——元回归与亚组探索、除非预先指定否则是假说生成器）。小组能辩护的结论：“平均而言可能有益、而在特定场景中无效或无作用的真实可能性存在；有条件地推荐、识别预测获益的调节因素、并考虑能够恰当检验它们的个体受试者数据更新。“双区间格式教导的教训：统计异质性不是要被最小化的噪声、而是关于干预情境依赖性的信息——”它有效“与”它在这里、对患者、在这个剂量有效”的差别、才是指南获准说的话。**
:::

::: exercise 修好样本量 {level=2}
一项试点可行性研究（n=24）被提出“以显示干预减少跌倒（效能80%、alpha 0.05、效应量d=0.5）”。诊断每个样本量的罪过并诚实地重建计算。
::: solution
**量度问题（[[#def-inference]]、[[#def-decisions]]）：罪过：可行性与效果混为一谈（一个试点对标准化效应的置信区间在n=24时横跨整个可能的宇宙——“试点只为试点本身”改革立场）、效应量从一厢情愿的文献而非最小临床重要差引入（跌倒的d=0.5——跌倒结局是偏态零膨胀计数；标准化差是错误的货币；目标估计量应是率比或风险差带来自患者的临床重要差）、没有方差、聚集结构或脱落的alpha与效能（养老院跌倒试验的组内相关  常常 使所需样本量翻倍；跌倒计数过散样本量方法存在）、及“效能80%”是抄来的而不是针对试验的成本与伦理挣来的（伦理样本量文献的最优信息框架）。重建：定义目标估计量（护理院居民跌倒的发病率比、干预对常规照护）、来自居民与指南小组的最小重要效应（比如相对25%）、来自登记数据的对照率、从试点方差来的过散与聚集参数（才是试点的用途）、来自该场所历史的脱落膨胀、及带其敏感性表的最终样本量。试点的正当角色：可行性、方差与保真度——及其方案中的“不作效果主张”句、因为该领域的审计轨迹显示被当作证据重新分析的试点正是乐观剂量诞生之地。**
:::

::: exercise 给这个风险比评级 {level=3}
一项肿瘤学试验的主要分析报告风险比0.74（P=0.008）、而其Kaplan-Meier曲线在四个月内重叠然后分开；补充附录没有提供比例风险诊断。写出统计审查：诊断、带其计算草图的替代目标估计量、及你会要求的报告。
::: solution
**非比例风险审查（[[#def-models]]、[[#def-inference]]）：诊断：曲线早期重叠然后分开是延迟效应模式（免疫疗法机制的典型）、在此之下log-rank检验保留一些效能、而风险比是两个不同体制的时间平均混合物——“0.74”不描述试验的任何时刻、而置信区间的覆盖逻辑（假定比例风险）只是名义的。替代目标估计量、各有草图：限制平均生存时间差（曲线下的面积到一个预先指定的视界——假设少且可作为“24个月时获得的月数”临床报告）、带Greenwood区间的关键时点生存差（12与24个月率——指南与患者都理解的格式）、加权log-rank检验（max-combo与Fleming-Harrington的晚期加权家族用于发现、带声明的加权选择多重性）、分段风险比（前四个月对分开之后、带警诫：变化点由数据驱动的选择是一个灵活点）、及混合治愈或延迟效应模型（在肿瘤类型显示时估计治愈比例与长期生存者平台）。必需的报告：Schoenfeld或Smirnov诊断与负对数负对数图（本审查控告其缺失的那个视觉检验）、预先指定的主要终点与其预先指定的替代（本应预见自身机制的“延迟效应作为已知可能”设计——统计分析计划的教训）、每条曲线各组的处于危险表与删失模式、及每个相对摘要旁边在临床相关视界上的绝对获益。审查底线：“该试验很可能显示真实获益；它发表的数字是其自身证据的错误摘要、而正确的数字——两年时获得的月数与平台比例——一旦诚实地读曲线，只会更有说服力。”**

::: exercise 向临床医师教回归 {level=3}
为将一生阅读指南的住院医师设计一个20分钟互动课教调整比值比。包括调整改变答案的那个演算数据集时刻、要在他们自己实践中追捕的那个误读、及迁移任务。
::: solution
**靠冲突教调整（[[#def-models]]、[[#def-inference]]）：引子：一个他们自己计算的二乘二乘二表（吸烟咖啡胰腺炎或治疗年龄Simpson反转的经典——粗比值比有害、分层后良性、因为年龄或吸烟集中在一个组）——调整改变了答案、而他们用双手做了Mantel-Haenszel加权。八分钟讲授：回归作为分层的延续（“一个模型做完所有层”的思想）、逻辑输出作为对数发生比与取指数得比值比那一步（带比率一章常见结局膨胀的数值重推：30%基线上调整比值比1.8是接近1.4的风险比——他们算出来）、及把偏倚章“为原因调整、不为结果不为中介”的图用一张幻灯片引进来。要追捕的误读：“独立相关”被背诵成“是原因”——及其指南后果（“保护因素处方”谬误、他汀与激素替代健康使用者的鉴诫电影）。迁移任务：一份真实指南的证据表带两个调整效应主张；他们写出命名了调整了什么、本不该调整什么、及什么仍然是混杂的那句话——然后对照指南自己的脚注检查。收尾装置：每位住院医师下一次期刊俱乐部分到“这个模型调整了什么、它本该调整吗？”作为其在批评中的指定台词——习惯就是这堂课；算术在每间病房的墙上都能找到。**

::: exercise 判断这次中期分析 {level=2}
一项试验的第二次中期分析（55%信息）显示主要终点的P=0.048；数据监察委员会的建议以“试验达到主要终点”见报。解释边界逻辑、终止决定的统计、及公众应得的发表。
::: solution
**边界对标题（[[epidemiology-ebm/randomised-trials]]、[[#def-inference]]）：边界逻辑：组序贯设计在每次窥视时花掉alpha；在55%信息处的O'Brien-Fleming边界通常在P=0.02-0.03左右、所以那次窥视时P=0.048并未越过设计的横杆——继续是方案的答案（在此终止会花掉设计的诚实、并产出一个乐观偏倚的估计——早期终止文献记录的赢家诅咒性质）。而如果越过了一个边界、终止的统计是：点估计有条件向上偏倚（序贯似然与中位无偏校正存在而很少发表）、安全性与次要终点不成熟（开香槟时它们所缺的信息）、而置信区间的名义覆盖只由考虑边界的方法恢复。公众应得的发表：中期分析的存在与设计在窥视之前注册；边界与估计一起报告（“p值相对边界”格式、不是“达到终点”）；随访承诺的说明（终止随机化但仍随访的设计及其伦理审查条件）；及荟萃分析的框架（试验序贯分析风格：跨试验的累积证据是否超过所需信息？一个不成熟文献内部单次越界的试验是心脏与溶栓历史反复排练的经典过早共识格局）。委员会自己应当发布的新闻室纠正：“这次分析未越过预先指定的终止边界；试验按计划继续”——这正是数据监察委员会章程的用途、而它缺席新闻周期才是真正的故事。**
