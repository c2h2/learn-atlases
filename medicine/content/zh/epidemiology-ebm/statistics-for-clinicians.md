一篇试验摘要报告：“新治疗降低了卒中（7.5%对12.0%；相对危险度0.63，95% CI 0.40至0.97；p = 0.03）。”读到它的临床医生需要知道每个数字的含义，哪些数字回答了患者会问的问题，以及哪些是这些数字都无法说明的。本章介绍几乎每篇临床论文中都会出现的统计学概念：变异与标准误、置信区间、p值、绝对效应与相对效应、需治人数、生存分析和回归。目的不是让你成为统计学家，而是让你能准确阅读结果并诚实地加以解释。

我们全章使用同一个虚构试验：800名卒中高危者被随机分配，400人接受新治疗，400人接受标准治疗。3年内，治疗组30人、对照组48人发生卒中。

## 描述数据 {#describing}

**均数**是算术平均值；**中位数**是观测值排序后居中的值。对于偏态数据，如住院天数或收入，少数大值会把均数拉高，因此中位数是更好的概括。数据的离散程度用**标准差**（SD）描述，偏态数据则用四分位数间距描述。

::: definition 标准差与标准误 {#def-se}
**标准差**（SD）描述个体观测值围绕其均数的变异程度。它是总体的特性，不会随测量人数增多而变小。

**标准误**（SE）描述一个样本统计量（如均数）估计相应总体值的精确程度。对于$n$个独立观测值的均数，

$$
SE = \frac{SD}{\sqrt{n}}.
$$

对于由$n$人估计的比例$p$，$SE = \sqrt{p(1-p)/n}$。标准误随样本增大而缩小。
:::

二者常被混淆，有些论文报告SE，因为它更小，使数据显得更整齐。规则很简单：描述研究中的人用SD，描述估计值的不确定性用SE（更好的是用置信区间）。

## 置信区间 {#ci}

::: definition 置信区间 {#def-ci}
**95%置信区间**（CI）是由数据通过某种方法计算出的一个范围；如果研究重复多次，该方法在95%的重复中所得的区间会包含真实的总体值。

对于近似正态分布的估计值，95% CI为

$$
\text{估计值} \pm 1.96 \times SE.
$$ {#eq-ci}

比值类指标，如危险比、比值比和风险比，在对数尺度上计算后再变换回来，因此其区间并不围绕估计值对称。
:::

实际的解释是：区间内的值与数据合理相容，远在区间之外的值则不相容。宽区间意味着研究不精确。窄区间意味着研究精确，但不一定无偏：置信区间只考虑随机误差（[[epidemiology-ebm/bias-confounding]]）。

说“真值有95%的概率位于这个区间内”并不完全正确。真值是固定的，随研究而变化的是区间。下图直接展示了这一点。

caption: 五十项模拟研究，每项都从20人的样本估计同一个真实均数。每条线是一项研究的95%置信区间。约95%的区间包含真值，但任何单个区间要么包含、要么不包含。改变样本量，看区间变窄；改变置信水平，看宽度与覆盖率之间的权衡。
:::

::: example 比例的置信区间 {#ex-ci-proportion}
一项外科稽查在200例手术中发现40例并发症。计算并发症发生率及其95%置信区间。
::: solution
$p = 40/200 = 0.20$。

$SE = \sqrt{0.20 \times 0.80/200} = \sqrt{0.0008} = 0.0283$。

95% CI $= 0.20 \pm 1.96 \times 0.0283 = 0.20 \pm 0.055$，即14.5%至25.5%。

这位外科医生真实的并发症发生率可能在约15%至25%之间的任何位置。如果全国水平为15%，这些数据并不能有力地证明这位外科医生更差。这一简单的（Wald）区间在这里足够；对于小样本或接近0或1的比例，应使用更好的方法，如Wilson区间。
:::
:::

## p值与假设检验 {#p-values}

::: definition p值、显著性与错误 {#def-pvalue}
**原假设**表述各组之间不存在差异（例如真实危险比为1）。**p值**是在原假设为真时，获得至少与观察结果同样极端的结果的概率。

如果p值低于预先规定的**显著性水平**$\alpha$（惯例为0.05），结果称为**具有统计学意义**。拒绝一个真的原假设是**I类错误**（概率为$\alpha$）；未能拒绝一个假的原假设是**II类错误**（概率为$\beta$）。**检验效能**$1 - \beta$是检出特定大小效应的概率。
:::

p值很容易被误读。它**不是**：

- 原假设为真的概率；
- 结果“由机遇”产生的概率；
- 效应大小或重要性的度量。

大型试验可以为一个微不足道的效应给出极小的p值。小型试验可以为一个重要但它太小而无法检出的效应给出很大的p值。2016年美国统计协会发表正式声明阐明了这些要点，并建议p值应结合估计值、置信区间和背景来解释，而不是孤立地看。

**多重检验**会增加假阳性。如果在不存在真实差异的情况下进行20次独立比较，至少有一次达到$p < 0.05$的概率为$1 - 0.95^{20}$，约64%。因此试验要事先指定一个主要结局，而对多个结局或亚组的分析，除非经过多重性校正，否则应视为产生假设的分析。

::: theorem 置信区间与p值一致 {#thm-duality}
对于常用的检验，双侧p值低于0.05，当且仅当95%置信区间不包含无效值（差值为0，比值为1）。
:::

::: proof
二者由同一个估计值和标准误构建。检验统计量为$z = (\text{估计值} - \text{无效值})/SE$，双侧$p < 0.05$恰好对应$|z| > 1.96$。这一不等式等同于说无效值距估计值超过$1.96 \times SE$，也就等同于说它位于区间$\text{估计值} \pm 1.96 \times SE$之外。对于比值，同样的论证在对数尺度上成立，此时无效值为$\ln 1 = 0$。（当检验和区间用略有不同的方法计算时，可能出现微小的不一致。）
:::

因此置信区间包含了p值所说的一切，而且更多：它显示了效应的大小以及与数据相容的取值范围。这就是为什么期刊按照Gardner和Altman在1986年提出的论点，要求作者报告置信区间而不仅仅是p值。

::: example 统计学意义与临床意义 {#ex-significance}
在一项20,000人的试验中，一种虚构药物使收缩压比安慰剂平均多降1.5 mmHg（95% CI 1.0至2.0 mmHg，$p < 0.001$）。在一项60人的试验中，另一种虚构药物使收缩压比安慰剂多降8 mmHg（95% CI −1至17 mmHg，$p = 0.08$）。哪个结果更重要？
::: solution
第一个结果具有高度统计学意义，但整个区间位于1至2 mmHg之间，这一效应对大多数个体患者来说太小，无足轻重。这项大型试验精确地测得了一个小效应。

第二个结果没有统计学意义，但点估计值很大，区间从轻微升高一直到下降17 mmHg。数据既与无效应相容，也与非常大的效应相容。这项试验太小，无法判断，有理由进行一项更大的试验。

两个p值都没有告诉你要紧的东西。对照具有临床重要性的最小差异（**最小临床重要差异**，MCID）来判断置信区间，才能做到。
:::
:::

## 绝对效应与相对效应 {#effects}

::: definition 治疗效应指标与需治人数 {#def-nnt}
设对照组的结局风险为$R_C$（**对照组事件率**），治疗组为$R_T$。

- **绝对危险降低**：$ARR = R_C - R_T$。
- **相对危险度**：$RR = R_T/R_C$。
- **相对危险降低**：$RRR = 1 - RR = (R_C - R_T)/R_C$。
- **需治人数**：$NNT = 1/ARR$，即在规定时间内需要治疗多少人才能使多一人获益。按惯例**向上**取整为整数。

当一种治疗增加某种不良结局时，相应的**需害人数**为该结局的$NNH = 1/(R_T - R_C)$。

NNT只有同时注明对照、结局和时间段才有意义（“40人治疗5年可预防一次心肌梗死”）。
:::

::: example 贯穿全章的试验 {#ex-nnt}
在本章开头所述的试验中，治疗组30/400、对照组48/400在3年内发生卒中。计算ARR、RR、RRR和NNT，并给出ARR和RR的95% CI。
::: solution
$R_T = 30/400 = 0.075$；$R_C = 48/400 = 0.12$。

**ARR** $= 0.12 - 0.075 = 0.045$（4.5个百分点）。其SE为$\sqrt{0.075 \times 0.925/400 + 0.12 \times 0.88/400} = 0.0209$，因此95% CI为$0.045 \pm 0.041$，即0.4至8.6个百分点。

**RR** $= 0.075/0.12 = 0.625$；**RRR** $= 37.5\%$。在对数尺度上，$\ln RR = -0.470$，且

$$
SE(\ln RR) = \sqrt{\tfrac{1}{30} - \tfrac{1}{400} + \tfrac{1}{48} - \tfrac{1}{400}} = 0.222.
$$

95% CI为$\exp(-0.470 \pm 1.96 \times 0.222)$，即0.40至0.97。

**NNT** $= 1/0.045 = 22.2$，向上取整为23：23人治疗3年可预防一次卒中。把ARR的置信限取倒数，得NNT的CI为12至250：数据既与可观的获益相容，也与非常小的获益相容。

RR的区间不含1，ARR的区间不含0，这与摘要中引用的约0.03的p值一致。
:::
:::

相对指标和绝对指标讲述不同的故事，两者都需要。相对效应在基线风险不同的患者之间往往相当恒定，绝对效应则不然。25%的相对危险降低，对风险为10%的患者意味着2.5个百分点的ARR（NNT 40），而对风险为2%的患者只有0.5个百分点（NNT 200）。这就是为什么是否治疗取决于个体的基线风险，这一点在[[epidemiology-ebm/critical-appraisal]]中展开。

只呈现相对效应会使治疗显得更令人印象深刻。“使卒中风险降低37%”听起来比“3年内从12%降到7.5%”更有说服力，尽管二者描述的是同一结果。拿到相对数字时，医生和患者对治疗的评价都更正面。良好的做法是以自然频数给出有治疗和无治疗时的绝对风险，并注明时间段。

::: warning 向均数回归
患者常因某项测量值异常偏高而被选出接受治疗或纳入研究：血压170 mmHg、胆固醇处于范围顶端、症状糟糕的一周。任何测量都包含随机变异，因此因极端读数而被选出的人，下一次读数平均而言会不那么极端，即使完全没有治疗。这就是**向均数回归**。它使未经治疗的患者显得好转，也使在极端读数之后给予的任何治疗显得有效。同样会发生回归的随机对照组是解决办法。这也解释了为什么在作出诊断之前，单次的高读数应当复查。
:::

## 生存分析 {#survival}

许多试验测量的是事件发生的时间，如死亡、复发或住院。参与者被随访的时间长短不一，有些人到研究结束时也未发生事件。他们的观测是**删失**的：我们只知道他们的事件（如果有的话）发生在最后一次随访之后。

::: definition Kaplan–Meier曲线与风险比 {#def-hr}
生存的**Kaplan–Meier估计**是一个在每个事件时间点下降的阶梯函数。在每个事件处，挺过该时刻的概率等于未发生事件的人数除以仍处于风险中的人数；删失的参与者退出风险集，但不引起下降。生存曲线是这些概率的乘积。

**风险**（hazard）是仍处于风险中的人发生事件的瞬时速率。**风险比**（HR）比较两组的风险。HR为0.75意味着在任何时刻，治疗组发生事件的速率是对照组的四分之三。它通常用**Cox比例风险模型**估计，该模型假定这一比值不随时间变化。
:::

阅读生存结果时，要看曲线，而不只是看HR。核查后期仍处于风险中的人数（常显示在图下方）：仅基于寥寥数人的曲线尾部是不可靠的。注意曲线是否交叉，交叉提示风险不成比例，单一的HR不是好的概括。并且尽可能把HR换算为绝对数值，如5年存活比例的差异或中位生存期的差异。

::: example 解读生存结果 {#ex-survival}
一项虚构的癌症试验报告总生存的HR为0.80（95% CI 0.70至0.92）。新药组中位生存期为14个月，标准药组为12个月。3年时分别有18%和13%的患者存活。你会如何向患者概括这一结果？
::: solution
HR意味着在任何时刻，新药组的死亡速率低约20%，区间（0.70至0.92）不含1，因此结果不太可能仅由机遇造成。用绝对数值表示：新药组一半患者活过14个月，标准药组为12个月，中位生存期相差约2个月。3年时，每100名患者中新药组约18人存活，标准药组为13人。

对患者的公允概括可以是：“平均而言，人们多活了约2个月，3年后仍存活的人也多了几个：每100人中约18人对13人。”这要与副作用、生活质量和患者自己的优先考虑一起权衡。仅用“死亡风险降低20%”这一相对数字，会对获益大小造成误导性的印象。
:::
:::

## 回归与预测 {#regression}

回归模型描述结局如何同时依赖于多个变量：

- **线性回归**用于连续结局，如血压。
- **logistic回归**用于二分类结局，给出比值比。
- **Cox回归**用于事件发生时间，给出风险比。
- **泊松回归**用于计数和率，给出率比。

在观察性研究中，这些模型用于调整混杂因素。其系数被解释为“保持其他变量不变”时与某一变量的关联，而这种解释的好坏取决于其他变量的选择和测量。

回归也用于构建**临床预测模型**，如心血管风险评分。有两点警告。第一，用过少事件拟合的模型会**过拟合**：它描述的是建模数据中的噪声，对新患者的预测很差。一个常见的粗略指引是每个候选预测因子至少有10个结局事件，不过现在的方法会更仔细地计算所需样本量。第二，模型必须在新数据中**验证**，最好来自不同的情境，并检查**区分度**（c统计量，即ROC曲线下面积；见[[epidemiology-ebm/diagnostic-tests]]）和**校准度**（预测风险是否与观察风险相符）。

相关不等于因果，强相关系数也说明不了效应的大小。冰淇淋销量与溺水相关，是因为二者都在炎热天气中上升。

::: example 门诊中的向均数回归 {#ex-rtm}
一家诊所邀请200名上次胆固醇高于7.5 mmol/L的患者参加一次新的膳食教育课。六周后，该组的平均胆固醇下降了0.6 mmol/L。诊所经理得出结论：这门课有效。还有什么能解释这一下降？
::: solution
这些患者*正是因为*上次读数高而被选出。胆固醇逐日变化，也有实验室误差，因此许多高于7.5 mmol/L的人那次读数高于其平常水平。复查时，即使没有任何干预，他们的数值也倾向于更低。这就是向均数回归，它很容易就能解释这种幅度的下降。

其他解释包括患者得知结果后自行作出的改变（他们可能独立地开始服药或改变膳食）以及季节性变化。要弄清这门课是否有效，诊所需要一个以同样方式选出的对照组，最好随机分配到上课与不上课，两组都在六周时复查。用两次基线测量的平均值来选择患者也能减小这一效应。
:::
:::

::: quiz
一项试验报告死亡的风险比为0.85，95% CI为0.72至1.01（$p = 0.06$）。哪个结论最有依据？
- [ ] 该治疗对死亡率没有影响。
- [ ] 该治疗使死亡率降低15%。
- [x] 数据与最多约28%的死亡率降低相容，也与非常小的增加相容；试验没有定论。
- [ ] 若用单侧检验结果就会显著，因此治疗有效。
::: solution
区间包含1，因此试验没有显示统计学显著的效应，但它也没有显示“无效应”：区间大部分位于获益一侧。诚实的概括是不确定。看到数据后改用单侧检验是不正当的。将本试验与其他试验合并的系统评价可能会解答这个问题。
:::
:::

::: history
都柏林健力士酒厂的化学家威廉·西利·戈塞特（William Sealy Gosset）于1908年以笔名“Student”发表了*t*分布，用于处理质量控制中的小样本。罗纳德·费希尔（Ronald Fisher）在20世纪20年代发展了显著性检验，并推广把5%作为一个便利的阈值；耶日·奈曼（Jerzy Neyman）和埃贡·皮尔逊（Egon Pearson）则在20世纪20年代末和30年代建立了包含I类和II类错误的假设检验框架。奈曼还于1937年提出了置信区间。

生存分析在爱德华·卡普兰（Edward Kaplan）和保罗·迈耶（Paul Meier）于1958年发表其估计量、戴维·考克斯（David Cox）于1972年提出比例风险模型后形成了现代形态。在医学领域，马丁·加德纳（Martin Gardner）和道格拉斯·奥尔特曼（Douglas Altman）1986年在《英国医学杂志》发表论文，主张报告置信区间而不仅仅是p值，各期刊随即修改了投稿须知。安德烈亚斯·劳帕西斯（Andreas Laupacis）、戴维·萨基特（David Sackett）和罗宾·罗伯茨（Robin Roberts）于1988年提出需治人数，作为表达治疗效应的一种具有临床意义的方式。
:::

## 后续内容

这些思想在[[epidemiology-ebm/systematic-reviews]]中被用于合并研究，在[[epidemiology-ebm/critical-appraisal]]中被用于判断某一结果是否适用于特定患者。使统计结果可信的设计特征见[[epidemiology-ebm/randomised-trials]]。

::: summary
- SD描述人与人之间的变异；SE描述估计值的精确度，按$1/\sqrt{n}$缩小。
- 95% CI为估计值 ± 1.96 SE（比值在对数尺度上计算）。它显示效应的大小和与数据相容的范围，且只反映随机误差。
- p值是在原假设为真时出现至少如此极端数据的概率。它不是原假设为真的概率，也不衡量效应大小。多重检验会增加假阳性。
- 当且仅当$p < 0.05$时CI不含无效值，因此CI携带更多信息。
- 报告相对效应（RR、RRR）的同时报告绝对效应（ARR、NNT = 1/ARR，向上取整）。绝对获益取决于基线风险。
- 统计学意义不等于临床重要性：应把CI与最小临床重要差异相比较。
- 生存分析用Kaplan–Meier曲线处理删失；风险比比较随时间变化的事件速率，并假定风险成比例。
- 回归可同时调整多个变量；预测模型必须避免过拟合，并在区分度和校准度方面经过验证。
- 向均数回归使极端值在重复测量时向平均水平移动；只有对照组能防范它。
:::

## 习题

::: exercise 标准误 {level=1 check="2"}
36名患者的样本平均血红蛋白为128 g/L，标准差为12 g/L。均数的标准误是多少（g/L）？
::: solution
$SE = 12/\sqrt{36} = 12/6 = 2$ g/L。均数的95% CI为$128 \pm 3.9$，约124至132 g/L。
:::
:::

::: exercise 需治人数 {level=1 check="20"}
在一项虚构试验中，对照组20%、治疗组15%的患者在2年内发生结局。NNT是多少？
::: solution
$ARR = 0.20 - 0.15 = 0.05$。$NNT = 1/0.05 = 20$：20人治疗2年可预防一次结局。RRR为25%。
:::
:::

::: exercise 需害人数 {level=1 check="50"}
在同一试验中，某副作用在治疗组发生率为3%，对照组为1%。需害人数是多少？
::: solution
绝对危险增加为$0.03 - 0.01 = 0.02$，因此$NNH = 1/0.02 = 50$。每治疗50人2年，就多一人出现该副作用，而每20人中有一人避免了结局。
:::
:::

::: exercise 比例的置信区间 {level=2 check="17.2"}
一个筛查项目发现，受邀的150人中有18人未参加。用简单（Wald）法计算未参加率的95%置信区间，给出上限，以百分比表示，保留1位小数。
::: solution
$p = 18/150 = 0.12$。$SE = \sqrt{0.12 \times 0.88/150} = 0.0265$。$1.96 \times SE = 0.052$。区间为0.068至0.172，因此上限为17.2%。
:::
:::

::: exercise 危险比的置信区间 {level=2 check="0.82"}
在一项虚构试验中，200名治疗患者中20人、200名对照中40人发生事件。用$SE(\ln RR) = \sqrt{1/a - 1/n_1 + 1/c - 1/n_0}$计算危险比及其95%置信区间的上限，上限保留2位小数。
::: solution
$RR = (20/200)/(40/200) = 0.5$。

$SE(\ln RR) = \sqrt{1/20 - 1/200 + 1/40 - 1/200} = \sqrt{0.065} = 0.255$。

上限$= \exp(\ln 0.5 + 1.96 \times 0.255) = 0.5 \times e^{0.4997} = 0.82$。下限为$0.5 \times e^{-0.4997} = 0.30$。区间0.30至0.82不含1。
:::
:::

::: exercise 个体NNT {level=2 check="42"}
某治疗使某结局的相对危险降低30%。一名患者未经治疗时的5年估计风险为8%。估计该患者5年的NNT，向上取整为整数。
::: solution
$ARR = 0.08 \times 0.30 = 0.024$。$NNT = 1/0.024 = 41.7$，向上取整为42。基线风险为24%的患者，同一治疗的NNT为14。
:::
:::

::: exercise 多重比较 {level=2 check="64.2"}
一项研究在20个独立结局上比较两组，其中没有一个结局真正存在差异。每次检验用$\alpha = 0.05$。至少有一次比较具有统计学意义的概率是多少（以百分比表示，保留1位小数）？
::: solution
没有一次显著的概率为$0.95^{20} = 0.358$。因此至少一次显著的概率为$1 - 0.358 = 0.642$，即64.2%。在众多结局中出现的一个“显著”发现是弱证据，除非它是预先规定的主要结局，或分析经过了多重性校正。
:::
:::

::: exercise 当NNT区间跨越无穷大时 {level=3}
一项虚构试验发现ARR为2个百分点，95% CI为−1至5个百分点。NNT是多少？其置信区间应如何描述？
::: solution
$NNT = 1/0.02 = 50$。把置信限取倒数得$1/0.05 = 20$（获益）和$1/(-0.01) = -100$，即NNH为100。由于ARR的区间包含0，NNT的区间经过无穷大（无效应）。应报告为“NNT 50（95% CI：NNT 20至无穷大至NNH 100）”，意思是数据与每治疗20人有1人获益、与无效应、或与每100人有1人受害都相容。报告为“NNT 50（−100至20）”令人困惑且是错误的。Altman于1998年描述了这一惯例。
:::
:::

::: exercise 解读两项试验 {level=3}
两项虚构试验检验同一种药物减轻疼痛的效果，疼痛用0–100量表评分，最小临床重要差异为10分。试验A：均数差4分（95% CI 2至6）。试验B：均数差12分（95% CI −2至26）。解读每项试验，并说明临床医生应得出什么结论。
::: solution
**试验A**显示了统计学显著的差异，但整个区间都低于MCID 10分。该药可能有真实的、但在临床上不重要的平均效应。（某些个体患者的获益仍可能高于平均。）

**试验B**没有统计学意义，因为区间包含0。但点估计值超过了MCID，且区间远远延伸到MCID之上。这项试验不精确：该药可能毫无效应，也可能效应很大。

综合来看，精确的试验A提示大的平均效应不太可能，因为其上限为6。临床医生应得出结论：平均获益可能很小，并应寻找合并所有试验的系统评价。两项试验都不能仅凭其p值支持“该药有效”或“该药无效”的说法。
:::
:::
