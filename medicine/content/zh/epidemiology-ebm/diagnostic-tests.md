一位45岁、没有症状的女性接受了一项癌症筛查血液检测。该检测被描述为“灵敏度90%、特异度95%”，她的结果为阳性。她患这种癌症的可能性有多大？向医生和医学生提出这个问题时，许多人回答“约90%”或“约95%”。如果这种癌症在像她这样的女性中的患病率为1/100，正确答案约为15%。

直觉与算术之间的这一差距，正是本章的缘由。检测结果是证据，而证据改变的是检测之前就已存在的概率。要解读一项检测，需要两样东西：检测区分有病者与无病者的能力有多好，以及该病一开始的可能性有多大。本章用四格表、预测值、似然比和贝叶斯定理来阐述这两者，然后讨论准确性研究如何可能产生误导。

## 四格表 {#table}

检测的准确性是通过把检测与**参考标准**（有时称金标准）比较来测量的，参考标准是判定谁真正患病的最佳可用方法。活检、血管造影、培养或长期随访是典型的参考标准。

::: definition 四格表 {#def-2x2}
把一项结果为阳性或阴性的检测与参考标准比较时，每个人都落入四个格子之一：

| | 患病 | 未患病 |
|---|---|---|
| 检测阳性 | $a$：真阳性（TP） | $b$：假阳性（FP） |
| 检测阴性 | $c$：假阴性（FN） | $d$：真阴性（TN） |

列由参考标准界定；行由检测界定。本章的每个准确性指标都是这个表中格子之比。
:::

研究中的**患病率**，也称**验前概率**，为$(a + c)/(a + b + c + d)$：受检者中真正患病者的比例。

## 灵敏度与特异度 {#sens-spec}

::: definition 灵敏度与特异度 {#def-sens-spec}
**灵敏度**是*患病*者中检测阳性的比例：

$$
\text{灵敏度} = \frac{a}{a+c} = \frac{TP}{TP + FN}.
$$

**特异度**是*未患病*者中检测阴性的比例：

$$
\text{特异度} = \frac{d}{b+d} = \frac{TN}{TN + FP}.
$$

灵敏度沿“患病”一列读取；特异度沿“未患病”一列读取。二者都不取决于样本中有多少人患病，因此原则上都是检测本身的特性。
:::

高灵敏度的检测很少漏诊，因此*阴性*结果令人放心。高特异度的检测很少把健康人判为患病，因此*阳性*结果信息量大。大多数检测需要在二者之间权衡：降低阳性阈值使检测更灵敏，通常也会使其特异度降低。

实际上，灵敏度和特异度并不像定义所暗示的那样固定。检测通常更容易发现晚期疾病而非早期疾病，因此在重症病例集中的医院人群中，其灵敏度高于筛查人群。在患有类似目标疾病的其他疾病的人中，特异度往往较低。这种变异称为**疾病谱效应**，这也是为什么从一种情境得出的准确性数字迁移到另一种情境时需要谨慎。

## 预测值 {#predictive}

灵敏度和特异度回答的问题是“如果一个人患病，检测阳性的可能性有多大？”患者和临床医生想知道的是反过来的问题：“已知检测阳性，患病的可能性有多大？”

::: definition 预测值 {#def-predictive}
**阳性预测值**（PPV）是检测阳性者中患病者的比例：

$$
PPV = \frac{a}{a+b}.
$$

**阴性预测值**（NPV）是检测阴性者中未患病者的比例：

$$
NPV = \frac{d}{c+d}.
$$

预测值沿表的*行*读取。它们既取决于检测的灵敏度和特异度，也取决于受检人群中该病的患病率。
:::

::: example 同一检测用于两种情境 {#ex-prevalence}
某检测的灵敏度为90%，特异度为95%。计算其PPV和NPV：(a) 在患病率为1%的筛查人群中；(b) 在30%的转诊患者患病的专科门诊中。
::: solution
使用自然频数：设想10,000人。

**(a) 患病率1%。** 100人患病：90人检测阳性（TP），10人检测阴性（FN）。9900人未患病：其中5%即495人检测阳性（FP），9405人检测阴性（TN）。

$PPV = 90/(90 + 495) = 90/585 = 15.4\%$。$NPV = 9{,}405/9{,}415 = 99.9\%$。

**(b) 患病率30%。** 3000人患病：2700 TP，300 FN。7000人未患病：350 FP，6650 TN。

$PPV = 2{,}700/3{,}050 = 88.5\%$。$NPV = 6{,}650/6{,}950 = 95.7\%$。

检测完全相同，但在筛查情境中约85%的阳性结果是假的，因为少数真阳性被来自庞大健康人群的假阳性所淹没。在专科门诊中，大多数阳性是真的。这就是本章开头问题的答案。
:::
:::

如本例所示，自然频数是向患者和同事解释检测结果最容易的方式。说“在1000名像你这样的女性中，约10人患有这种癌症，其中9人会检测阳性；990名未患病者中也有约50人检测阳性”，远比条件概率容易理解。

::: widget bayes
mode: test
prevalence: 0.01
sensitivity: 0.9
specificity: 0.95
caption: 以自然频数表示的贝叶斯定理。把患病率滑块从筛查水平（约1%）移到门诊水平（30%或更高），观察在灵敏度和特异度不变时阳性预测值如何变化。然后看看特异度需要提高多少，筛查阳性结果才更可能是真阳性而不是假阳性。
:::

## 似然比与贝叶斯定理 {#lr}

预测值必须针对每个患病率重新计算。似然比避免了这一点，因为它把检测的贡献与验前概率的贡献分开了。

::: definition 似然比 {#def-lr}
某一检测结果的**似然比**，是该结果在患病者中出现的概率除以其在未患病者中出现的概率。

阳性结果：

$$
LR^{+} = \frac{\text{灵敏度}}{1 - \text{特异度}}.
$$

阴性结果：

$$
LR^{-} = \frac{1 - \text{灵敏度}}{\text{特异度}}.
$$

似然比大于1使患病可能性增大；小于1使之减小；等于1则结果无用。对于有多个结果水平的检测（例如分段报告的血液检测），每个分段都有自己的**多水平似然比**，即患病者落在该段的比例除以未患病者落在该段的比例。
:::

使用似然比时，要把概率转换为比值。若概率为$p$，比值为$p/(1-p)$；比值$o$转换回概率为$o/(1+o)$。

::: theorem 比值形式的贝叶斯定理 {#thm-bayes}
对于似然比为$LR$的检测结果，

$$
\text{验后比值} = \text{验前比值} \times LR.
$$ {#eq-bayes-odds}

在疾病状态给定的条件下结果相互独立的检测，可以通过相乘其似然比而依次应用。
:::

::: proof
设$D$为患病，$R$为检测结果。贝叶斯定理给出

$$
P(D \mid R) = \frac{P(R \mid D)\,P(D)}{P(R)}, \qquad P(\bar D \mid R) = \frac{P(R \mid \bar D)\,P(\bar D)}{P(R)}.
$$

前式除以后式，消去$P(R)$：

$$
\frac{P(D \mid R)}{P(\bar D \mid R)} = \frac{P(R \mid D)}{P(R \mid \bar D)} \times \frac{P(D)}{P(\bar D)}.
$$

左边是验后比值，右边第一个因子是似然比，第二个是验前比值。对于阳性结果，$P(R \mid D)$为灵敏度，$P(R \mid \bar D)$为$1 - $特异度，从而得到$LR^+$。如果第二个检测结果$R_2$在患病组内和未患病组内都与$R_1$独立，则$P(R_1, R_2 \mid D) = P(R_1 \mid D)P(R_2 \mid D)$，$\bar D$亦然，因此似然比相乘。
:::

粗略地说，大于10或小于0.1的似然比通常会引起很大、往往是决定性的概率变化。5至10或0.1至0.2的似然比引起中等程度的变化。0.5至2之间的似然比很少改变处理。**Fagan列线图**以图形方式完成这一换算：从验前概率经过似然比画一条直线，即得验后概率。

::: example 排除性检测 {#ex-ruleout}
在本例中，一种用于肺栓塞的D-二聚体检测灵敏度为95%、特异度为40%（数量级合适的示例数字；实际数值取决于检测方法和人群）。计算其似然比。阴性结果后的验后概率是多少：(a) 临床验前概率为15%的患者；(b) 验前概率为50%的患者？
::: solution
$LR^- = (1 - 0.95)/0.40 = 0.125$，$LR^+ = 0.95/(1 - 0.40) = 1.58$。

**(a)** 验前比值$= 0.15/0.85 = 0.176$。验后比值$= 0.176 \times 0.125 = 0.022$。验后概率$= 0.022/1.022 = 2.2\%$。这已低到大多数临床医生不会再进行影像检查。

**(b)** 验前比值$= 1$。验后比值$= 0.125$。验后概率$= 0.125/1.125 = 11.1\%$。这仍然太高，不能停止检查。

阳性结果几乎不改变概率（$LR^+ = 1.58$），所以D-二聚体阳性并不能诊断栓塞。该检测只对排除有用，而且只有在临床概率本已较低时才有用。这就是为什么包括NICE静脉血栓栓塞指南在内的指南首先使用Wells评分等临床概率评分，而把D-二聚体留给临床概率低的患者。
:::
:::

::: example 多水平似然比 {#ex-multilevel}
血清铁蛋白用于诊断缺铁。为便于说明，假设铁蛋白低于15 µg/L时缺铁的似然比为50，15–34 µg/L时为3，35–100 µg/L时为0.5，高于100 µg/L时为0.1。一位贫血的老年男性缺铁的验前概率为30%。如果他的铁蛋白为(a) 20 µg/L、(b) 120 µg/L，验后概率是多少？
::: solution
验前比值$= 0.3/0.7 = 0.429$。

**(a)** 验后比值$= 0.429 \times 3 = 1.29$；概率$= 1.29/2.29 = 56\%$。

**(b)** 验后比值$= 0.429 \times 0.1 = 0.043$；概率$= 4.1\%$。

如果把检测简化为“阳性”（低于35）或“阴性”，铁蛋白20就会与铁蛋白5被同等对待，而后者携带的证据要强得多。保留分段就保留了信息。还要注意，铁蛋白会随炎症升高，因此在有活动性炎症性疾病的患者中，“正常”的铁蛋白作为否定缺铁的证据较弱；似然比本身也取决于人群。
:::
:::

::: warning SnNout和SpPin是经验法则，不是保证
这两个助记词是说：**灵**敏的检测**阴**性时可以**排除**（SnNout），**特**异的检测**阳**性时可以**确诊**（SpPin）。它们有助于记住每种特性指向哪个方向。但正如[[#ex-ruleout]]所示，灵敏度95%的检测阴性只有在验前概率低时才能排除疾病。而一项“特异”但灵敏度低的检测，似然比可能仍然一般。一项检测只有结合验前概率才能确诊或排除诊断，似然比才是衡量其强度的诚实指标。
:::

## 检测的联合使用 {#combining}

两项检测可以**串联**使用，即仅在第一项阳性时才做第二项，两者都阳性才诊断；也可以**并联**使用，即任一阳性即算阳性。

如果两项检测的误差相互独立，则：

- 串联时，灵敏度$= s_A \times s_B$，特异度$= 1 - (1 - c_A)(1 - c_B)$，其中$s$为灵敏度，$c$为特异度。串联检测提高特异度、降低灵敏度。筛查项目常这样运作：先做一项廉价的灵敏检测，再做一项更特异的确认检测。
- 并联时，灵敏度$= 1 - (1 - s_A)(1 - s_B)$，特异度$= c_A \times c_B$。并联检测以牺牲特异度为代价提高灵敏度，适用于漏诊很危险的情况。

独立性假设常常不成立。两项都难以发现小病灶的影像检查往往会漏掉同样的患者，因此联合使用的增益小于公式所示。

::: example 依次进行的两项检测 {#ex-serial}
一名患者某病的验前概率为10%。检测A阳性（$LR^+ = 4$），随后检测B阳性（$LR^+ = 6$）。假定条件独立，验后概率是多少？
::: solution
验前比值$= 0.1/0.9 = 0.111$。两项检测后，比值$= 0.111 \times 4 \times 6 = 2.67$。概率$= 2.67/3.67 = 72.7\%$。

单独每项检测会得到31%（检测A）或40%（检测B）。二者合起来使该病变得很可能。如果两项检测测量的是相互重叠的特征，真实的联合似然比小于24，这一估计就偏高。
:::
:::

## ROC曲线与阈值 {#roc}

许多检测给出连续结果，如肌钙蛋白、PSA或血糖的浓度。选择一个切点把结果变成“阳性”或“阴性”，而每个切点都给出不同的灵敏度与特异度组合。

::: definition ROC曲线与曲线下面积 {#def-roc}
**受试者工作特征（ROC）曲线**针对连续检测的每一个可能阈值，以灵敏度（真阳性率）对$1 - $特异度（假阳性率）作图。无用的检测落在对角线上。完美的检测经过左上角。

**曲线下面积**（AUC，也称c统计量）概括了所有阈值下的区分能力。它等于随机选取的一名患者的检测结果比随机选取的一名非患者更异常的概率。AUC为0.5表示没有区分能力；1.0表示完美区分。

**约登指数**$J = \text{灵敏度} + \text{特异度} - 1$是选择阈值的一种方法：曲线上离对角线最远的点。
:::

ROC曲线上任一点的斜率等于该阈值处结果的似然比，这把曲线与贝叶斯定理联系了起来。

::: example 选择阈值 {#ex-threshold}
一种用于发热儿童严重细菌感染的示例性生物标志物，在四个阈值下的准确性如下：

| 阈值 | 灵敏度 | 特异度 | 约登指数$J$ |
|---|---|---|---|
| 10 | 0.98 | 0.40 | 0.38 |
| 20 | 0.92 | 0.70 | 0.62 |
| 30 | 0.80 | 0.85 | 0.65 |
| 40 | 0.60 | 0.95 | 0.55 |

应该使用哪个阈值？
::: solution
约登指数在30处最高。但约登指数对假阴性和假阳性赋予同等权重，而这里二者并不相等。漏诊儿童的严重细菌感染可能致命；假阳性只导致进一步检查，也许还有一个短疗程的抗生素。

如果用该检测决定哪些儿童可以安全回家，低阈值10或20是合理的，因为灵敏度最重要：在10处，只有2%的感染被漏诊，阴性似然比为$0.02/0.40 = 0.05$。如果用该检测挑选需要接受有创操作的儿童，较高的阈值才合适。

正确的阈值取决于每种错误的后果和受检人群的患病率，而不是某一个统计量。
:::
:::

## 何时值得做检测？ {#thresholds}

只有能改变患者处理的检测才有用。Pauker和Kassirer在1980年用两个阈值描述了这一点。低于**检测阈值**时，患病概率低到任何可能的结果都不足以支持治疗，因此不应做检测。高于**治疗阈值**时，概率高到无论结果如何都应开始治疗。只有在二者之间检测才值得做，因为这时结果可以使概率越过治疗变得更可取的那条线。

这解释了为什么对低风险人群做检测常常弊大于利。在疾病非常罕见的人群中，大多数阳性结果是假阳性，每一个都可能导致进一步检查、焦虑，有时还有有害的治疗。这也解释了为什么一项在专科门诊中表现优异的检测，在全科医疗中可能帮助不大。

## 准确性研究如何出错 {#study-bias}

准确性数字的好坏取决于产生它们的研究。常见偏倚有：

- **疾病谱偏倚。** 把明确患病的患者与健康志愿者比较，即“诊断性病例对照”设计，会同时夸大灵敏度和特异度。检测应在一系列连续的、诊断确实存疑的患者中评价。
- **部分核实偏倚。** 如果只有检测阳性的患者接受参考标准，假阴性就很少被发现，从而高估灵敏度、低估特异度。
- **差异核实偏倚。** 如果阳性和阴性患者接受不同的参考标准（比如阳性者做活检，阴性者做临床随访），这些参考标准之间可能不一致。
- **纳入偏倚。** 如果检测结果是参考标准的一部分，一致性会被夸大。
- **评阅偏倚。** 如果解读检测的人知道参考标准结果，或反之，解读可能受到影响。盲法解读可以防止这一点。
- **不完善的参考标准。** 如果参考标准本身会出错，一项比参考标准更好的新检测可能显得更差。

诊断准确性研究应按照**STARD**（诊断准确性研究报告标准；现行版本为STARD 2015）报告。诊断准确性的系统评价用**QUADAS-2**（2011年）评估原始研究的偏倚风险。

最后，准确性并不等于获益。更准确的检测只有在带来更好的决策、而这些决策又带来更好的结局时，才对患者有益。证明一项检测值得使用的最有力证据，来自比较不同检测策略的随机试验，它们测量的是患者结局而不是准确性。

::: quiz
一种新的感染快速检测灵敏度为98%、特异度为98%。它被提供给一个音乐节的所有参加者，那里该感染的患病率约为0.1%。哪种说法是正确的？
- [ ] 阳性结果意味着此人几乎肯定已感染。
- [x] 大多数阳性结果将是假阳性。
- [ ] 该检测的灵敏度在音乐节上会低得多。
- [ ] 阴性预测值会很低。
::: solution
在10万人中，约100人感染，98人检测阳性。在99,900名未感染者中，2%（1998人）也检测阳性。PPV为$98/(98 + 1{,}998) = 4.7\%$，因此约95%的阳性是假阳性。NPV非常高，因为几乎所有人都未感染。灵敏度和特异度没有改变；改变的是验前概率。阳性结果需要用另一种检测来确认。
:::
:::

::: history
*灵敏度*和*特异度*这两个词是雅各布·耶鲁沙米（Jacob Yerushalmy）于1947年引入医学统计学的，当时他研究的是放射科医生阅读结核病胸片的一致性。其数学则古老得多：托马斯·贝叶斯（Thomas Bayes）关于逆概率的论文在他去世后，于1763年由其友人理查德·普赖斯（Richard Price）发表。

1959年，罗伯特·莱德利（Robert Ledley）和李·卢斯特德（Lee Lusted）在《科学》（*Science*）上提出，医学诊断可以用概率和贝叶斯定理来描述；为雷达信号检测而发展的ROC分析不久便被应用于医学影像。1975年，特伦斯·费根（Terrence Fagan）发表了用似然比把验前概率换算为验后概率的列线图。1980年，斯蒂芬·波克（Stephen Pauker）和杰罗姆·卡西雷尔（Jerome Kassirer）描述了检测阈值和治疗阈值，使临床医生有办法判断一项检测究竟是否值得做。20世纪80年代和90年代，麦克马斯特大学的临床流行病学家，包括戴维·萨基特（David Sackett），把这些方法带到了床旁，他们的教学使似然比成为循证医学的常规工具。
:::

## 后续内容

筛查还带来领先时间、病程长度和过度诊断等问题，见[[epidemiology-ebm/bias-confounding]]。如何评价一篇诊断准确性论文见[[epidemiology-ebm/critical-appraisal]]，准确性研究的合并见[[epidemiology-ebm/systematic-reviews]]。

::: summary
- 检测的准确性是在真假阳性与真假阴性构成的四格表中对照参考标准测量的。
- **灵敏度**是患病者中检测阳性的比例；**特异度**是未患病者中检测阴性的比例。它们随疾病谱而变化。
- **预测值**回答临床问题，但强烈依赖患病率：在低患病率下，即使是好的检测，阳性结果也大多是假阳性。
- **似然比**（$LR^+ = $ 灵敏度$/(1-$特异度$)$，$LR^- = (1-$灵敏度$)/$特异度）与验前比值相乘：验后比值 = 验前比值 × LR。多水平似然比保留了分级结果中的信息。
- SnNout和SpPin是粗略的指引；一项检测能否确诊或排除取决于验前概率。
- 串联检测提高特异度；并联检测提高灵敏度。独立性常被假定，但并不成立。
- ROC曲线显示各阈值间的权衡；AUC概括区分能力；最佳阈值取决于每种错误的代价。
- 准确性研究会因疾病谱不具代表性、部分或差异核实、纳入以及非盲法解读而产生偏倚。STARD指导报告；QUADAS-2评估偏倚。
:::

## 习题

::: exercise 灵敏度 {level=1 check="90"}
一项对1000名患者的研究发现72例真阳性、8例假阴性、45例假阳性和875例真阴性。计算灵敏度，以百分比表示。
::: solution
灵敏度$= 72/(72 + 8) = 72/80 = 0.90$，即90%。（特异度为$875/920 = 95.1\%$。）
:::
:::

::: exercise 阳性预测值 {level=1 check="61.5"}
仍用该研究（72例真阳性、45例假阳性），计算阳性预测值，以百分比表示，保留1位小数。
::: solution
$PPV = 72/(72 + 45) = 72/117 = 0.6154$，即61.5%。这只适用于与该研究患病率相同的人群，这里为$80/1{,}000 = 8\%$。
:::
:::

::: exercise 似然比 {level=1 check="18"}
某检测的灵敏度为90%，特异度为95%。其阳性似然比是多少？
::: solution
$LR^+ = 0.90/(1 - 0.95) = 0.90/0.05 = 18$。
:::
:::

::: exercise 验后概率 {level=2 check="81.8"}
一名患者的验前概率为20%。一项$LR^+ = 18$的检测结果为阳性。验后概率是多少（以百分比表示，保留1位小数）？
::: solution
验前比值$= 0.2/0.8 = 0.25$。验后比值$= 0.25 \times 18 = 4.5$。概率$= 4.5/5.5 = 0.818$，即81.8%。
:::
:::

::: exercise 低患病率下的筛查 {level=2 check="19.9"}
某筛查检测的灵敏度为99%，特异度为98%。受筛人群中该病的患病率为0.5%。计算阳性预测值，以百分比表示，保留1位小数。
::: hint
以10万人计算，或使用$PPV = \dfrac{\text{灵敏度} \times p}{\text{灵敏度} \times p + (1-\text{特异度})(1-p)}$。
:::
::: solution
10万人中500人患病，495人检测阳性。99,500名未患病者中2%（1990人）检测阳性。$PPV = 495/(495 + 1{,}990) = 495/2{,}485 = 0.199$，即19.9%。尽管检测极好，每5个阳性结果中仍有4个是假阳性。
:::
:::

::: exercise 并联检测 {level=2 check="94"}
两项独立检测的灵敏度分别为80%和70%，特异度分别为90%和95%。并联使用，任一检测阳性即判为阳性。联合灵敏度是多少（以百分比表示）？联合特异度是多少？
::: solution
联合灵敏度$= 1 - (1 - 0.8)(1 - 0.7) = 1 - 0.2 \times 0.3 = 0.94$，即94%。联合特异度$= 0.90 \times 0.95 = 0.855$，即85.5%。并联检测以更多假阳性为代价发现更多病例。
:::
:::

::: exercise 阴性结果不足以排除时 {level=2 check="13.0"}
一名症状典型的患者某病验前概率为60%。一项$LR^- = 0.1$的检测结果为阴性。验后概率是多少（以百分比表示，保留1位小数）？该病是否应视为已排除？
::: solution
验前比值$= 0.6/0.4 = 1.5$。验后比值$= 1.5 \times 0.1 = 0.15$。概率$= 0.15/1.15 = 0.130$，即13.0%。八分之一患严重疾病的可能性不算排除。临床怀疑程度高时，好的检测阴性能降低概率，但往往降得不够，需要进一步检查。
:::
:::

::: exercise 部分核实 {level=3 check="97.6"}
一项新检测在1000名患者中评价，其中100人真正患病。该检测真实灵敏度为80%，真实特异度为90%。所有检测阳性的患者都接受参考标准，但检测阴性者中只有随机10%接受。如果研究者仅用接受核实的患者计算灵敏度，他们将报告多少（以百分比表示，保留1位小数）？
::: hint
先填出完整的四格表。然后保留全部阳性者和10%的阴性者。
:::
::: solution
完整表：80 TP，20 FN，90 FP，810 TN。170名阳性者全部核实。830名阴性者中10%被核实：2 FN和81 TN。

报告的灵敏度$= 80/(80 + 2) = 0.976$，即97.6%，而真实值为80%。报告的特异度$= 81/(81 + 90) = 47.4\%$，而真实值为90%。部分核实夸大灵敏度、压低特异度。纠正办法是对阴性者随机抽样核实并加权还原，更好的是对所有人都使用参考标准。
:::
:::

::: exercise 新情境中的新检测 {level=3}
一家公司报告其结直肠癌血液检测的灵敏度为95%、特异度为97%，依据是200名已知晚期癌症患者和200名健康献血者。一位全科医生询问是否应在腹部症状含糊的患者中使用它。请给出建议。
::: solution
该研究采用了**诊断性病例对照**设计：明显的晚期患者对比健康志愿者。这会使表观准确性最大化。晚期癌症比早期癌症更易检出，因此在初级保健中有症状的患者（其中许多是较早期的癌症）中，灵敏度可能更低。健康献血者没有那些会引起假阳性的疾病，如炎症性肠病或其他癌症，因此在真实患者中特异度也可能更低。

即使照单全收这些数字，在初级保健中症状含糊的患者中，结直肠癌的患病率也很低，也许只有百分之几。在2%的患病率下，PPV $= 0.95 \times 0.02/(0.95 \times 0.02 + 0.03 \times 0.98) = 39\%$，因此大多数阳性仍是假阳性。

在采用之前，该检测应在一系列连续的、有症状的初级保健患者中评价，每个人都接受适当的参考标准（结肠镜检查，或对未检查者进行随访），盲法解读，并按STARD报告。然后应将其与现有方法比较，如粪便免疫化学检测，NICE推荐在初级保健中用它指导疑似结直肠癌的转诊。理想情况下，还应研究它对患者结局的影响，而不仅是其准确性。
:::
