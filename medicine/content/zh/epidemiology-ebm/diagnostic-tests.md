诊断试验是应用的贝叶斯定理：一个检验结果是一条证据、以其似然比移动试验前概率、而这一职业慢性病就是忘记了那句话的任何一半。**本章教授二乘二及其衍生（敏感度、特异度、预测值及其患病依赖）、似然比及它们强制推行的列线图纪律、受试者工作特征曲线及其比较陷阱、腐蚀整座建筑地基的参考标准与确认偏倚问题、及本章为其存在而要到达的决策分析终点：一个检验何时改变你做的事、是唯一有临床意义的有用性定义。**

## 算术

::: definition 敏感度、特异度与患病率陷阱 {#def-measures}
**检验对真相的二乘二定义了检验自有的一对与患者自有的一对。检验的内在一对：敏感度（真阳性率——排除的雄心、SnNout那个不完美的助记）与特异度（真阴性率——SpPin的对应说法、两个陈述只在100%时严格为真而在任何不足时有用作为直觉）。患者的一对：阳性与阴性预测值——临床医师实际引用的概率——它们不是检验的属性而是检验在某人群中的属性：预测值随患病率滑动（一个在筛查患病率1%人群主要返回假阳性的检验、在患病率40%的专科门诊主要返回真阳性）、这就是为何只报告敏感度与特异度的检验批评论文回答了错误的问题、及为何同样的检测在急诊室赢得糟糕名声而在专科门诊赢得优秀名声。知情临床医师的工具集：阳性似然比（敏感度除以1减特异度）与阴性似然比（1减敏感度除以特异度）、它们在任何患病率上把试验前概率合并成试验后概率、是一个检验真正拥有的稳定量；试验前概率是一个有名字的临床估计（预测规则与入院率的“带引用的直觉”）、而整章化约为诚实地使用它。阈值机制：敏感度与特异度沿决策切点交换（受试者工作特征曲线存在的证明）、而切点选择引入了患病率、危害与成本（肌钙蛋白第99百分位与性别特异阈值之争、糖化血红蛋白6.5对7.0之辩）——所以一个连续检验的“”操作特征是家族、而从一个曲线上引用一个数字而不给曲线的论文只报告了一半。多重检验与序贯策略：平行检验提高敏感度（任一阳性即可排除）、串联提高特异度（两者阳性即可确认）、而组合的算术是本章带临床名字的小型代数（可疑血栓的Wells然后D二聚体然后影像序列作为经典的串联设计——带其条件独立警诫：似然比只在检验的误差在给定疾病下不相关时才相乘、而同机制的组合违反了它）。**
:::

## 曲线与比较

::: definition 受试者工作特征分析、曲线下面积及其不满 {#def-roc}
**受试者工作特征曲线在每个阈值上把敏感度对1减特异度作图（它源自雷达信号检测理论、作为词汇存活下来：d′与等相关正态模型的理想化）。曲线下面积（一致性统计量——一个随机病例得分高于一个随机对照的概率）用一个数字摘要跨阈值的区分度、而它的每个正当用途都带着统计手册很少对读者重复的警诫：曲线下面积通过在无人会用的阈值上取平均而忽略临床效用（一个优秀的面积可以伴随一个无用的操作区）、在患者与疾病另有决定时把假阳对假阴的交换当作对称、恰恰以预测值不盲的方式对患病率盲（“面积在富集样本中看起来很棒”陷阱）、而比较很危险（来自配对设计的相依曲线需要DeLong或自助法；面积对面积的较技常反映参考标准多于检验本身）。更好的决策展示：临床可信特异度范围上的部分面积、决策曲线分析（跨阈值的净获益——预测与诊断模型的现代表准）、及朴素的临床效用框架：在这个人群的阈值上使用这个检验、会改变管理并改善结局吗？——三步阶梯（检验的效力、检验策略的效果、患者结局）是筛查与诊断研究文献共同达到的、而多数检验评价只爬了第一级。比较设计：配对参考设计（两个检验用在连续系列上并盲法与裁定）、增量价值研究（新检验是否增加旧模型的面积或净获益——Delong与IDI及NRI统计量的统计时尚与其随后的批评都以学术速度运行）、及预测规则时代的交叉验证纪律（同一数据既推导又验证时的乐观偏倚风险——报告预测模型的TRIPOD改革）。临床流行病学经典不断教学：“肌钙蛋白对心梗不是肌钙蛋白对缺血”的语义陷阱（测量心肌损伤、决定梗死）、D二聚体的年龄调整阈值与患病依赖的排除能力、及钙卫蛋白与C反应蛋白的故事——检验兴旺或失败取决于照护路径位置而非内在质量。**
:::

## 地基

::: definition 参考标准、确认偏倚与检验评价设计 {#def-reference}
**一个检验的表面质量受其金标准现实性的限制：不完美参考问题（用来评判心电图的血管造影自身满是误差——“为不完美参考校正”的方法及其不受欢迎）、参考标准级联（培养阴性心内膜炎与活检阴性疾病、真相是一次临床裁定、所以诊断标签的不确定度传播到操作特征——经典研究人群的“更病的对照与气喘的病例”）、及差异性确认（对阳性与阴性结果使用不同的参考标准——一个制造有利数字的设计）。确认（查寻）偏倚是该领域的签名错误：只有检验阳性者（或临床上令人担忧者）真相被揭示、所以敏感度在已揭示病例上计算而特异度假定在健康者上；补救：把未确认者随访到硬终点、盲法独立确认、及假设很强而很少被检验的统计校正。纳入偏倚——当被研究的检验是参考诊断的一部分（临床影像诊断中的影像、心肌损伤标签中的肌钙蛋白）——依构造夸大一致性、而因为它流行而可否认，值得自己的一段。评价金字塔映射对患者诊断的评估：分析有效性（检测方法测量它声称的东西吗——计量学、精密度、干扰）、临床有效性（适当人群中的操作特征——诊断试验的三期）、临床效用（检验策略的随机试验——被忽视的塔尖、它解释了为何那么多有真实数字的检验什么也不改变：前列腺特异抗原与肿瘤标志物及“检验而无治疗阈值”文献）、及实施与经济层（报告时间作为临床变量、检验堆叠作为行为现象、及指南如今计算成本的“正常结果锚定”与“偶发瘤级联”危害）。报告标准（诊断准确性研究报告规范及其扩展）把评价核查表操作化：连续而无选择的设计、盲法、预先指定的阈值、两种结果命运的确认。临床教学以贝叶斯收尾、用本章最强的一句实践话：一个检验值得开的时机恰恰是结果能改变管理之时——试验前概率之问（“如果阳性我会做什么不同？”）既是伦理也是算术过滤器、而未通过它的检验产生了本网站安全各章算作危害的偶发发现级联。**
:::

::: example 偶发瘤 {#ex-incidental}
一名健康40岁者“体检”CT显示一个9毫米肾上腺结节；随访路径开始。本章关于它有帮助的概率会说什么？
::: solution
**患病率遇上特异度（[[#def-measures]]、[[#def-reference]]、[[endocrine/adrenal]]）：算术：肾上腺偶发瘤绝大多数良性（尸检与现代影像的腺瘤患病率数据：数个百分点的成人、功能性分泌比例在个位数低位）、所以一个“发现结节”的阳性结果其显著性的预测值由随访路径的阈值设定、不是由扫描的分辨率。级联：生化筛查（非分泌者中的假阳性地塞米松抑制试验——又是特异度对患病率问题）、影像特征化轮次、带辐射与焦虑预算的重复扫描、及罕见带真实并发症的手术——整条照护之箭由一个临床重要性试验前概率接近人群基线的影像发现触发。指南辩护：结构化路径恰恰存在是因为结节的预测值取决于有公布操作特征的尺寸与密度切点、而9毫米良性外观病变这一类如今在若干系统中已有明确的“最少或不随访”推荐。给患者的临床裁决：诚实的数字（“在这个尺寸与外观下、需要治疗的任何东西概率远低于百分之一；路径的检验有自己的假阳性尾巴”）、按指南框定的观察性重新影像选项、及给转诊者的教学要点：体检CT才是那个改变管理概率被假定而非被估计的检验——本章规则的反面。系统教训：筛查不可筛者是带着新放射学的旧恶习；偶发瘤率是检验开具质量的指标、不是影像质量的指标。**
:::
:::

::: example 排除掉真排除了的检验 {#ex-ddimer}
一个肺栓塞患病率4%的急诊科采用D二聚体加临床评分排除栓塞。两年后、在死亡病例讨论会上讨论漏诊率：三个漏诊、全部“D二聚体阴性”。
::: solution
**策略的安全对检验的属性（[[#def-measures]]、[[#def-roc]]、[[cardiovascular/vascular-disease]]）：要分开的数字：D二聚体敏感度接近95-99%而特异度在40-60%范围、在4%患病率下给出99.5%以上的阴性预测值（阴性结果加低或中评分的试验后概率——阴性似然比算术给出大约数百分之一）——所以大系列中三个漏诊在统计期望之内、不一定是失败；评价之问：评分是否诚实地应用（绕过排除的医师“直觉升级”）、高患病率呈现（产后、恶性、近期手术、既往血栓栓塞）是否按规程要求从路径中排除（条件依赖与患病率上限条件——排除法在试验前概率抗拒该检测排除能力之处失败）、及漏诊是否真正D二聚体阴性还是记录阴性（“检验在症状进程中开得太晚”与“结果未被处置”审计分开的类别）。策略层面的证据：来自随机路径试验血脉的管理结局安全数据（策略的漏诊率终点、定义可接受排除安全的30天随访设计）对检验独自的数字。会议的产出：不是抛弃路径（计算机断层摄影辐射与对比剂与住院日的节省巨大且有证据）而是收紧它的边缘——本地记录在案的患病率上限、教授的高危情况覆盖、被审计的记录链、及带自己置信区间的漏诊率监测、好让三个漏诊被读成统计而不是丑闻。**
:::

## 通向何处

筛查的人群版本在[[public-health/screening]]；预测规则及其验证出现在[[clinical-skills/clinical-reasoning]]；影像方式的操作特征在[[clinical-skills/medical-imaging]]；实验室医学的分析有效性在[[clinical-skills/laboratory-tests]]；及决策分析工具在[[epidemiology-ebm/statistics-for-clinicians]]。

::: history
**诊断检验逻辑有三重谱系。临床体征学传统（Corvisart的叩诊、Laennec的听诊器、及十九世纪医院从体征到疾病的推断链）在任何人写下分数之前就把床旁发现变成概率证据（1960-80年代的“物理诊断复兴”——Feinstein与Sackett的诊断宣言时代——把体格检查变成测量过的似然比：“哮鸣对喘鸣观察者间”研究、及至今仍教学其数字的肝硬化体征论文）。实验室时代始于从雷达转移来的受试者工作特征（1950-60年代Greenwald与Swets的检测理论迁徙）、同数十年的筛查规划流行病学（从肺筛查失败来的“治疗时代疾病自然史”概念、领先时间与病程长度偏倚在1970年代结核与乳腺辩论中的临床诞生）、及肌钙蛋白与免疫测定时代的阈值之争。贝叶斯通过1970-80年代临床流行病学学派重新进入临床医学（80年代的Casscells与Greinstein及Pauker及Pauker“试验后概率列线图”、“预测值特质”之辩——Schulman与“检验的流行病学”论文教导临床医师抛弃预测值语言——及那个教学计划失败、仍有教益）。循证医学的诊断产物（1993年起的合理临床查体系列、美国医学会使用者指南的诊断综述、2003年及其2015年修订的诊断准确性报告标准）使评价标准化；预测模型繁荣（从Framingham经QRISK到“机器学习诊断2018-2023时代”的外部验证审计——“许多外部验证没有一个高于偶然”的裁决、及相关实施教训）大规模供应了现代警世故事。前沿就是本章终点所要求的：检验策略的随机试验（胸痛与抗凝排除规划的“先检验后治疗”设计）、及去实施文献的发现——多数诊断过度使用（每日血液、监测影像、无行动阈值的肿瘤标志物）靠习惯而非证据存活、这使检验开具像筛查本身一样成为一支带听诊器的行为公共卫生问题。—— [[clinical-skills/clinical-reasoning]]、[[public-health/screening]]。**
:::

::: summary
- 检验是证据不是裁决：敏感度与特异度是检验的属性；预测值——临床医师引用的——是检验在某人群中的属性、而带诚实试验前概率的似然比是把两者连接的方式。
- 阈值是穿着测量外衣的决定：敏感度与特异度沿切点交换、而切点选择引入患病率、危害与成本、这就是为何连续检验的“”操作特征是一条曲线不是一对。
- 曲线下面积在隐藏效用时摘要了区分度：阅读临床医师将使用的操作区、偏爱部分面积与净获益展示、并把跨研究面积对决当作参考标准之争。
- 检验评价兴落于参考标准与确认设计：纳入、查寻与不完美参考偏倚在多数论文从不检查的地基处腐蚀结果。
- 有效性阶梯（分析、临床、效用）解释了为何准确的检验常什么也不改变；随机证据属于策略层、而开具之问永远是“这会改变管理吗？”。
- 诊断级联（偶发瘤、假阳性尾巴、检验不可检验的患病率）是实验室医学的危害章；检验开具是一个带人群规模后果的临床决定。
:::

## 练习
::: example 验证得很差的AI分诊 {#ex-ai}
一个深度学习胸片分诊工具在其开发数据上报告曲线下面积0.97；部署的机构计划削减夜间报告。三家医院的外部验证得到0.83、在夜间、床旁片与少数族裔肤色相邻输入变异上更差。
::: solution
**从面积到审计（[[#def-roc]]、[[#def-reference]]、[[clinical-skills/medical-imaging]]）：下降的惯用名字：谱系偏倚（开发数据富集于明显疾病与干净采集——“富集患病率与设备均一性”膨胀）、标签泄漏或薄弱参考标准（训练标签自身的噪声与影像方案相关）、带乐观的过拟合（重复使用同样分布的内部验证——外部验证文献的“同院同洗牌”批评）、及部署转移（床旁片、摆位、人群构成）。采购本应强制的评价标准：TRIPOD加AI报告、带目标人群与设备的独立多站点外部验证、校准以及区分度（操作点的预测对观察风险——一个0.97面积的模型在所选阈值上仍可能无用）、按采集类型与人口学层的带置信区间亚组表现、及在可信阈值处的决策曲线或净获益分析。临床治理的现实：一个夜间分诊部署改变人在回路中的试验前概率与责任面、所以前瞻的静默试验评价（在任何工作流改变之前测量一致性与漏诊模式的影子模式）、“AI建议放射医师决定对AI优先排序队列”及其不同错误轮廓的区分、及带预先指定漂移警报的上市后监测。验证浮现的公平维度：跨采集条件的表现差距映射到谁能得到床旁片与夜间覆盖——混杂一章的人群结构教训用硅写成。放行决定：不是标题面积、而是亚组校准加净获益加影子模式三联、而转向夜间自动化取决于这三项在部署自身数据中都成立。**
:::

::: example 肿瘤标志物随访 {#ex-marker}
一个随访方案在看似治愈的卵巢癌后每三个月开具CA-125；五年间队列显示“更早发现复发”但无生存获益、而因良病切除胆囊者增多。审查这个方案。
::: solution
**监测就是一种检验策略（[[#def-reference]]、[[#def-measures]]、[[obstetrics-gynaecology/gynaecological-cancer]]）：证据层级：分析有效性（该检测没问题）、临床有效性（CA-125在多数复发中先于症状上升——真实）、临床效用（比较强化标志物与影像随访对症状导向随访的随机试验在卵巢癌中未发现生存优势、而更早挽救治疗无症状复发带来更多毒性——“监测试验比被监测的疾病更稀有”问题、及与肿瘤标志物监测文献的科克伦裁决同一逻辑）。方案的算术：上升的PSA与CA-125一类标志物对可操作复发的预测值对治疗阈值结构（如果对无症状复发的更早治疗不改善生存或生活质量、那么更早的知晓就是更早的焦虑加其级联——因手术候选良病切胆囊这个细节就是把级联变得可见）。审查的产出：使随访间隔与生存曲线的风险期对齐（复发风险时间线证据）、把影像与二线准备保留给有症状或按方案定义的确认、在开具之前就定义标志物的行动阈值（“绝不开具一个对每个结果没有计划的检验”规则）、同样严格地提供症状复发教育（试验的非劣效组值得知情选择）、及审计方案的危害看板（活检、切除、扫描偶发瘤、及生活质量文献如今认真对待的焦虑测量）。治理那句话：监测方案比它们的证据多活几十年；这一个应当附上试验数据关闭、而不是因为关闭它感觉像撤除照护而继续。**
:::

## 练习

::: exercise 计算后果 {level=1}
一个检验敏感度90%、特异度90%。在各1000人被检验的人群中、计算患病率1%、10%、50%时的阳性预测值与假阳对真阳比、并为每个患病率说出一个真实临床场景。
::: solution
**患病率漫步（[[#def-measures]]）：1%时：10个真阳性（检出9）加99个假阳性（990名健康者乘10%）——阳性预测值8.3%、每个真阳性对应十个假阳性：低患病率筛查与偶发瘤领地（一般人群动脉瘤与甲状腺癌一类筛查的经典算术）。10%时：90个真阳性（检出81）加81个假阳性——阳性预测值50%、许多二级照护转诊的抛硬币区（“在10%诊所开的检验”一类、其中一半阳性是噪声）。50%时：450个真阳性（检出405）加225个假阳性——阳性预测值64%、预先选择的高危场景（有症状队列、中心人群患病率）、而即便这里一个阳性也远非确定——教训是：没有任何检测改进能像更好的转诊过滤器那样便宜地修好一个糟糕的试验前概率。教学附加：同一检验的阴性预测值处处令人安心（即使在50%患病率仍高于98%）——这就是本章嘲笑的排除雄心常常奏效而确认失败的原因。**
:::

::: exercise 修好这个研究 {level=2}
一种新的尿抗原检验在200例确诊病例（全部培养阳性肺炎）与200名健康献血对照中评价、得到敏感度95、特异度97。列出设计缺陷并重建评价以产出临床医师能用的数字。
::: solution
**两个杂货店不是一条谱（[[#def-reference]]、[[#def-roc]]）：缺陷：极端病例（两杂货店）设计使两个测量都膨胀（病例是最重的培养阳性部分；对照比任何鉴别诊断人群都更健康、使数字在床旁消失的“谱系效应”）；无连续入组或临床可疑框定（该检验服务的人群是未分化的呼吸道呈现）；献血对照漏掉共享抗原性或炎症的混杂；无对检验阴性者的确认（培养阴性肺炎、参考标准自身漏掉的——带不完美参考的确认偏倚、因为培养是那个镀金的金标准：敏感度远离1）。重建：在原发、二级与重症各层连续纳入社区获得性肺炎可疑成人；带盲法裁定的复合参考标准（30天时的临床、微生物与影像随访、裁定小组对该新检验盲）、完整谱系包括模仿者（心衰、支气管炎急性加重、“检验阳性的其他诊断”类别）；预先指定的阈值与带部分面积报告的曲线；按严重度、年龄与先前抗生素分层的亚组操作特征（生物学梯度文献）；及按诊断准确性报告标准并附谁接受了哪种参考结局的流程图。对临床医师有用的输出：按结果带并按照护场景分层的似然比、及代入本地呼吸人群患病率的决策曲线或治疗阈值分析的数字。**
:::

::: exercise 组合检验 {level=2}
对可疑心内膜炎、血培养（敏感度0.85、特异度0.99）与超声心动图被使用；一位同事提议“两者阳性=确定、任一阳性=可能”。评价串联对平行的算术及其条件独立假设。
::: solution
**带警诫的串联与平行（[[#def-measures]]）：代数：平行检验（任一阳性）提高敏感度而降低特异度（0.85加超声对培养漏诊的贡献——在漏掉心内膜炎是灾难性时有用）；串联检验（两者阳性）提高特异度而降低敏感度（用于高风险治疗决定的确认策略）。所述规则是一个混合体：“两者阳性”作为串联确认规则（确定）与“任一阳性”作为平行排除规则（可能触发查寻）——如果操作点与本地患病率及各层的后果匹配、作为管理网格在临床上合理。独立陷阱：用于组合检验的似然比相乘只有当在给定疾病状态下检验的误差不相关时才有效；培养与超声发现共享决定因素（先前抗生素同时抑制两者；小赘生物与阴性培养并存；瓣膜同时扭曲两者）——所以朴素的组合敏感度与特异度是乐观的、必须用配对数据的经验联合分布（改良Duke标准时代论文发表的“两个检验对最终诊断的二乘二乘二”表）取代相乘。临床流行病学的补充：Duke标准自身作为一个贝叶斯证据组合工具（主要与次要标准作为带似然比加权并有针对病理学的经验验证的发现）、这就是“组合检验”在做对时的样子：不是代数、而是一个其联合行为被测量过的、经过验证的评分系统。**
:::

::: exercise 选择阈值 {level=2}
肌钙蛋白阈值：第99百分位参考上限、对带性别特异与年龄调整切点的高敏检测、对差值变化算法。用本章的阈值机制框定这个决定、并说出每种选择付出的代价。
::: solution
**阈值就是分诊政策（[[#def-measures]]、[[#def-roc]]）：坐标轴：降低决策阈值提高敏感度（更少漏掉心肌损伤）而以特异度为代价（更多2型损伤与慢性肾病与心肌炎候选阳性——假阳性尾巴以监护床位与血管造影货币支付）；第99百分位惯例是一个有临床后果的统计制品（“按构造1%的健康者高于它”问题）、而性别特异阈值纠正了诊断不足女性的男性偏向参考（切点公平性文献最强的发现）。差值变化与算法策略（0/1或0/2小时升降规则）通过要求动力学损伤而不是高于阈值的一个水平来买回特异度——同时也缩短胸痛单元停留的系列测量设计（路径试验证据）。按选择命名的代价：漏诊损伤之害、下游造影与入院负荷、慢性升高人群的心理与经济拖累、及“心肌损伤不是梗死”的语义教育账单。框定：阈值是照护路径能力设定操作点之处——高敏检测加路径加临床医师估计胜过任何单一数字、这就是为何每份指南如今公布算法而不是切点；及对任何新阈值论文的评价检验：整个算法的操作特征、前瞻的、带30天主要不良心血管事件终点、不是检验独自的曲线。**
:::

::: exercise 审计这个筛查检验项目 {level=2}
你的职业健康服务用静息12导联心电图为2000名无症状仓库员工筛查“心脏适应性”；对冠心病敏感度约50%、特异度90%。预测级联并写废除备忘录。
::: solution
**筛查无症状低危者（[[#def-measures]]、[[#def-reference]]、[[public-health/screening]]）：在工作年龄患病率近2%时的算术：40例真实疾病（检出20）与196个假阳性——每个真实发现对应十次误报、而每次都要启动心电图解读漂移级联（重复描记、带自己假阳性尾巴的运动试验、计算机断层血管造影与导管室及罕见真实伤害、工作限制、保险与焦虑效应——职业医学文献的“心脏正常但不适合上岗”队列）。本章的裁决标准：没有证据表明筛查无症状低危成人改善结局（美国预防服务工作组从不推荐那一类）、没有结果在症状出现之前会改变的行动阈值、及保证在此患病率净危害的假阳性率。备忘录结构：上面的数字（以每千工作者语言、工会与管理层都能读）、指南引文、危害路径预测、每例检出然后再治疗的真实病例成本（终结这类规划的六位数每质量调整生命年那一类算术）、及替代：用有据路径做心血管危险因素筛查（血压、按年龄与风险规则的血脂、吸烟、糖尿病）加保护免受污名化的症状上报路径。政治：心电图感觉是负责的；审计显示它是一场带导管室尾巴的表演；替代方案保留岗位职责而去掉心电图。**

::: exercise 设计策略试验 {level=3}
设计一项随机试验、证明在急诊科把一种新的快速脓毒症生物标志物加入标准评估能改善结局。说明受试者、干预、对照、终点、过程结局层、及检验策略试验特有的分析陷阱。
::: solution
**检验策略试验设计（[[#def-reference]]、[[#def-roc]]、[[infectious-diseases/fever-sepsis]]）：受试者：跨科室疑似脓毒症的连续成人（保持谱系诚实的务实入组）；干预：在治疗决定之前返回标志物结果并带方案锚点（“检验加临床评估对从决定中扣留检验的临床评估”设计）；对照：标准照护、该检测被测量但隐瞒（把检验效应从试验效应的霍桑效应分开的“仅测量对照”）。终点：从抗生素到重症到死亡的阶梯（先过程：入门到针刺及抗生素前血培养率；然后器官衰竭无病日；死亡率除非样本巨大否则把握度不足——策略试验会预先公布的样本量诚实）。使试验困难的陷阱：治疗阈值交互（一个检验只在不确定超过治疗阈值宽度之处有帮助——按临床确定层分层）、共干预漂移（对照臂从试验的脓毒症集束热情中学习、掩埋效应的“背景改善”）、抗生素副作用（过度治疗尾巴：耐药与艰难拟梭菌要计为危害、否则试验就是宣传）、依从（两臂中医师都忽视检验——“检验使用作为中介”分析）、及按方案而不是按检验确认结局（本章地基要求的参考标准独立性）。分析：对策略的意向治疗、预先指定的按确定性亚组、并列的成本效果（每避免一个重症日的检验价格——支付方的终点）、及按检验策略扩展核查表报告。收尾的设计那句话：一个在3%患者中改变管理的检验必须显示大于那3%的不确定区间所能隐藏的获益、这就是为何多数脓毒症标志物试验测量的是希望而不是帮助。**

::: exercise 解释似然比 {level=1}
一名医学生问为什么似然比“好于”预测值、以及为什么没人用它们。给出十行解释、带一个演算数字、并诚实地命名行为障碍。
::: solution
**比对习惯（[[#def-measures]]）：解释：一个似然比在任何患病率上把试验前概率转换成试验后概率（概率的乘子性质）、所以检验的信息量与患者的背景分离——预测值把两者熔在一起、因此在诊所之间移动时会误导；演算数字：一个阳性结果似然比8、在10%试验前概率（概率0.11）上给出试验后概率0.89——约47%——然后临床医师问唯一剩下的问题：47%会改变我做的事吗？被命名的障碍：概率在认知上是陌生的（列线图与百分比概率教学研究表明人们用百分比推理、所以这一领域教“概率条”与列线图）、指南把似然比埋在表里、而电子开具系统显示参考范围而不是后果。诚实的补充：似然比教学改变开具行为的证据有限——计算容易而习惯不容易、这就是为何本章不断回到试验前概率作为检验开具的道德中心。**
:::

::: exercise 评价这篇比较论文 {level=2}
一篇论文声称检验A胜检验B：曲线下面积0.91对0.84、p小于0.001、但A是年轻女性中新的数字乳腺断层摄影而B是年长队列中旧的胶片乳腺摄影、两者都是单中心。写出你的同行评议段落。
::: solution
**比较诚信评审（[[#def-roc]]）：评审应走四步：先命名设计缺陷（不同年龄与风险结构及不同设备世代的未配对人群把方式与队列和时代混杂——这一比较回答的是“女性中的A对2004年女性中的B”、而面积对患病率的敏感意味着更年轻更低患病率队列可能偏爱更差的检验——“面积悖论与富集样本”文献）、要求配对设计的补救（历史读数或交叉隐式刺激设计、两种方式在同一批女性上阅读、DeLong或自助法配对比较）、追问操作区（在筛查相关的90%以上范围内部分面积或在固定特异度下的敏感度——整个面积的优势可能生活在没有临床决定发生的地方）、并质疑终点（癌检出率一类产出对间期癌及召回率与活检率、及筛查试验所测量的最终死亡结局）。建设性要求：在旧胶片队列后继人群上的外部验证、成本与通量报告、及该期刊预测模型指南已经要求的净获益或决策曲线展示。语气：这种方式可能确实更好；而按设计进行的比较无法证明它、而乳腺摄影史（数字对胶片的替换试验）恰恰显示这一风格的主张在前瞻审计中失败。**

::: exercise 解决假阳性危机 {level=3}
你的新生儿筛查项目新的质谱检测panel对每种疾病敏感度95、特异度99.9、每年在30种疾病上筛查500000名婴儿；确诊疾病产出为400名婴儿、而1500个家庭收到异常结果信。设计该项目在沟通、确认路径、数据治理、及疾病选择伦理上的应对。
::: solution
**规模化筛查伦理（[[#def-measures]]、[[#def-reference]]、[[paediatrics/newborn]]、[[medical-ethics-law/justice-resources]]）：公开陈述的算术：即使99.9%的特异度在二层检验层之前也会在500000名被筛者中产生500次以上误报；观察到的每400例1500封信反映疾病倍增、及阈值被刻意设低的“按可疑处理”规程——项目的任务是使这一交换可见、而不是假装它不存在。沟通：异常结果信的设计证据（父母把“异常”读成“患病”；减少危害的第二封信对电话及指定护士路径）、公平与解读要求（语言服务、适龄读写材料、“接下来几天会发生什么”时间表）、及显示对假阳性坦诚能保住接受率而靠隐瞒的安慰会摧毁它的父母信任数据。确认路径：当日二层检验与紧急联络结构（报告时间作为临床危害的指标）、与假阳性尾巴（而不是确诊数——多数扩容提案重复的资源错误）相匹配的代谢团队容量、及结果回传治理、好让没有家庭悬在实验室之间。数据治理：保存血斑的研究使用规则（同意模式之争、可识别对编码对匿名各层、保存期限政治、及监测对获益之辩）、按族裔的疾病检出残余风险公平审计、及包括误报负担的项目级操作特征公布。疾病选择伦理：诚实应用的Wilson-Jungner及持续证成标准（治疗可得性与有效性阈值、扩容panel文献争论的轻表型与过度诊断问题、“谁的疾病获得panel名额及谁代言”的政治经济学）、并把残障社群证词作为常设议程项而不是一个评论框。项目的成绩单：找到的病例、挺过的误报、到答案的时间、接受公平、及家庭自己的调查——最后一项作为向董事会报告的指标、因为一个只按检出优化的筛查项目是一篇议论文、不是一项服务。**
