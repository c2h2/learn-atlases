20世纪80年代，许多心肌梗死幸存者的心电图上有频发的室性早搏，已知这些患者猝死风险较高。氟卡尼和英卡尼等药物能非常有效地抑制早搏。它们能挽救生命，似乎是理所当然的。心律失常抑制试验（CAST）通过把患者随机分配到这些药物或安慰剂来检验这一点。1989年试验提前终止：使用活性药物的患者死亡率高于使用安慰剂者。

CAST说明了为什么随机对照试验位于治疗证据的核心。合理的机制、良好的观察性数据和专家的信心，都可能指向错误的方向。本章解释随机化如何起作用，试验如何设计和分析，以及阅读试验时应注意什么。

## 为什么要随机化？ {#why}

治疗的观察性比较存在**指征混杂**：患者接受某种治疗的原因也影响其预后（[[epidemiology-ebm/bias-confounding]]）。调整只能处理那些被测量的混杂因素。随机化一次性处理了所有混杂因素。

::: theorem 随机化能做到什么 {#thm-randomisation}
如果参与者通过一个任何人都无法预测或影响的随机过程分配到各治疗组，那么：

1. 参与者的每一项特征，无论可测与否、已知与否，在期望意义上在各组中分布相同，因此各组之间只在所分配的治疗上存在系统差异；
2. 任何残余的不均衡都源于机遇，其可能大小可用标准统计方法量化，因此这些方法能为治疗效应给出有效的置信区间和p值。
:::

::: proof
设某特征$X$（年龄、疾病严重程度、某个尚未被发现的遗传变异）在试验人群中有任意分布。如果分配是随机的，每个参与者被分配到治疗组的概率都相同，无论其$X$取何值。因此分配在统计上独立于$X$，$X$在两组中的期望分布相同。由于这一点对每项特征同时成立，它对治疗以外的每一个结局原因都成立。

在任何单个试验中，各组都会因机遇而有所不同，小型试验更是如此。但由于分配过程是已知的，可以计算出任意大小差异出现的概率，这正是p值或置信区间所描述的。在观察性研究中，决定治疗的过程是未知的，因此任何这类计算都无法考虑偏倚。
:::

随机化只在分配的那一刻保护比较。此后，各组可能因诊疗不同、测量不同或分析对象不同而再次变得不均衡。试验设计的其余部分都是为了维持随机化所创造的均衡。

## 构建试验 {#framing}

::: definition 随机对照试验的要素 {#def-rct}
**随机对照试验**（RCT）把参与者随机分配到两种或多种干预并比较结局。其问题通常以**PICO**形式表述：

- **人群**（Population）：谁符合条件（纳入和排除标准）；
- **干预**（Intervention）：被检验的治疗；
- **对照**（Comparator）：安慰剂、常规治疗或另一种有效疗法；
- **结局**（Outcomes）：测量什么、何时测量、如何测量。

**主要结局**是主要结论和样本量所依据的单一结局。**次要结局**起支持作用。**替代结局**是用来代替对患者有意义的结局的实验室指标或体征，例如用胆固醇代替心肌梗死。**复合结局**把几种事件合并，如“心血管死亡、心肌梗死或卒中”。
:::

结局的选择决定了试验能显示什么。替代结局使试验小而快，但只有当通过该治疗改变替代指标确实能改变临床结局时，它才值得信赖。CAST是经典的警示：抑制早搏这一替代结局，伴随的是*更多*的死亡。复合结局增加事件数从而提高检验效能，但当各组成部分重要性不同、而治疗效应主要由最不严重的部分驱动时，它可能产生误导。

对照的选择同样重要。在没有有效治疗时，安慰剂对照是恰当的。当已有有效治疗时，《赫尔辛基宣言》（最近一次修订于2024年）要求新治疗与已证实的最佳干预进行比较，少数情况除外。试验还必须从**临床均势**出发：专家群体对哪种治疗更好确实存在不确定性。

## 分配与盲法 {#allocation}

::: definition 序列产生与分配隐藏 {#def-concealment}
**分配序列**是决定每个参与者接受何种治疗的列表。它应由真正随机的方法产生，例如计算机生成的随机数。变体包括：

- **简单随机化**，如同为每个参与者掷一次硬币；
- **区组随机化**，在一定间隔内保持组间人数均衡（例如每个4人区组中两种治疗各2人）；
- **分层随机化**，在重要的预后组（如中心或疾病分期）内分别随机化；
- **最小化法**，把每个新参与者分配到能使选定预后因素最均衡的组，并带有随机成分。

**分配隐藏**指招募参与者的人在参与者被不可撤回地纳入试验之前，无法知道或预测下一个分配。常用方法是通过电话或网络系统进行中央随机化。
:::

分配隐藏不同于盲法，在某些方面更为重要。如果负责招募的临床医生能看出下一个信封是“手术”，他可能推迟纳入一位虚弱的患者，直到下一个分配是“内科治疗”。即使无人有意作弊，各组也会变得不均衡。比较分配隐藏充分与不充分的试验的研究发现，隐藏不良的试验往往报告更大的治疗效应。交替分配、按出生日期或住院号分配，以及对着光就能看透的信封，都是不充分的。

::: definition 盲法 {#def-blinding}
**盲法**（或设盲）指参与试验的一类或多类人员不知道每个参与者接受的是哪种治疗。可以设盲的人员包括参与者、照护他们的临床医生、评估结局的人员和分析数据的人员。

“单盲”“双盲”等标签的使用并不一致。试验报告应准确说明谁被设盲以及如何设盲。
:::

盲法防止诊疗上的差异、症状报告上的差异和结局评估上的差异。其重要性取决于结局。死亡很难误判。疼痛、功能以及是否收治入院的决定则更容易受影响。当无法对参与者设盲时，如大多数外科或物理治疗试验，对结局评估者设盲通常仍然可行且有价值。

::: example 分配泄漏的试验 {#ex-concealment}
在一项比较髋部骨折早期手术与保守治疗的虚构试验中，某中心的外科医生拿到一叠密封信封，每当一位患者同意参加就打开下一个。试验结束后发现，该中心随机分到手术组的患者比分到保守组的更年轻、更健康，而其他中心的各组相似。可能发生了什么？应如何防止？
::: solution
信封由负责招募患者的人打开，而且很可能不是不透光的或未严格按顺序使用。如果外科医生能看到或猜到下一个分配，他可能（也许是无意识地）在下一个信封是“手术”时纳入一位健康的患者，而在是“保守”时等待。分配序列也许是随机的，但**分配隐藏**失败了，因此各组是被挑选出来的，而不是随机分配的。

预防措施：中央的网络或电话随机化，只在记录患者的入选资格和同意之后进行。如果必须使用信封，应按顺序编号、不透光、密封，并且只有在患者信息写在信封上之后才打开，同时对顺序进行稽查。分析时应按中心报告基线特征，并谨慎解释试验结果。
:::
:::

## 试验设计 {#designs}

- **平行组设计**：每个参与者在整个试验中接受一种干预。这是默认设计。
- **交叉设计**：每个参与者以随机顺序先后接受两种治疗，中间有洗脱期。每个人都作为自身对照，因此所需参与者较少。它适用于病情稳定的慢性病、且治疗效应会消退的情况，如某些偏头痛预防或慢性疼痛的治疗；当治疗能治愈疾病或有持久效应（**残留效应**）时则不适用。
- **析因设计**：通过把每个参与者随机分配到每种干预，同时检验两种或多种干预。2×2析因设计（用或不用A，用或不用B）几乎以一个问题的代价回答两个问题，前提是两种治疗没有交互作用。下文讨论的ISIS-2把患者随机分配到链激酶、阿司匹林、两者或两者都不用。
- **整群设计**：随机分配的是群体，如全科诊所、病房或村庄，而不是个人。它适用于以群体为单位实施的干预，可避免组间沾染，但同一群内的结局相互关联。样本量必须乘以**设计效应**$1 + (m-1)\rho$，其中$m$为平均群大小，$\rho$为组内相关系数。
- **解释性试验与实用性试验**：解释性试验问的是治疗在理想条件下（经过挑选的患者、严格的方案）能否起效。实用性试验问的是它在常规实践中（宽泛的入选标准、常规诊疗）是否有效。大多数试验介于两极之间。
- **适应性试验与平台试验**允许随着数据积累进行预先规定的调整，例如淘汰无效的组。**平台试验**以共享的对照组检验多种治疗，并随时间加入新的治疗。英国的RECOVERY试验于2020年启动，用这一设计检验因COVID-19住院者的治疗。数月之内它就显示，地塞米松降低了接受吸氧或机械通气患者的28天死亡率，而其他几种广泛使用的治疗并无帮助。

### 优效性与非劣效性 {#non-inferiority}

大多数试验问的是新治疗是否优于对照：**优效性**试验。有时新治疗更便宜、更安全或更方便，问题只是它是否不会差到不可接受的程度。

::: definition 非劣效性试验 {#def-noninferiority}
**非劣效性试验**检验新治疗与阳性对照相比，是否不比后者差出一个预先规定的**非劣效界值**$\Delta$以上。界值在试验之前根据临床和统计理由选定，应小于对照治疗已知的相对安慰剂的效应。

如果差值（对有害结局而言为新治疗减标准治疗）的整个置信区间都低于$+\Delta$，即显示了非劣效。
:::

非劣效性试验有特殊的弱点。实施质量差，如许多参与者未服用所分配的治疗，会使两组看起来相似，从而有利于得出非劣效的结论。因此对符合方案分析的重视程度至少应与意向性治疗分析相同。而且一系列非劣效性试验，每次都接受一种略差的治疗，可能逐渐滑向一种并不优于安慰剂的治疗，这一问题称为**生物蠕变**（biocreep）。

::: example 解读非劣效性结果 {#ex-ni}
一项虚构试验比较一种新型口服抗凝药与华法林预防心房颤动患者的卒中。预先规定的界值为2年内卒中绝对增加2个百分点。解读危险差（新药减华法林）的三种可能结果：(a) 0.5个百分点，95% CI −0.5至1.5；(b) 0.3，95% CI −0.3至2.6；(c) −1.2，95% CI −2.2至−0.2。
::: solution
**(a)** 上限1.5低于界值2，因此显示了非劣效。区间包含0，因此未显示优效。

**(b)** 上限2.6超过界值，因此**未**显示非劣效。试验没有定论：新药可能差出多达2.6个百分点，超过了可接受的范围。但这并不表明该药更差。

**(c)** 整个区间都低于0。显示了非劣效，新药也是优效的。在显示非劣效之后检验优效是可以接受的，前提是事先规定，因为置信区间是同一个。

在每种情况下，都要核查界值是否事先设定并有充分理由，以及符合方案分析是否与之一致。
:::
:::

## 需要多少参与者？ {#sample-size}

::: definition 检验效能与样本量 {#def-power}
试验可能犯两类错误。**I类错误**是在不存在差异时得出存在差异的结论；其概率为显著性水平$\alpha$，通常为0.05。**II类错误**是未能检出真实存在的差异；其概率为$\beta$。**检验效能**$1 - \beta$是试验检出特定大小真实差异的概率。试验通常按80%或90%的效能设计。

比较两个比例$p_1$和$p_2$时，每组所需人数近似为

$$
n = \frac{(z_{1-\alpha/2} + z_{1-\beta})^2 \,[\,p_1(1-p_1) + p_2(1-p_2)\,]}{(p_1 - p_2)^2},
$$ {#eq-samplesize}

其中双侧$\alpha$为0.05时$z_{1-\alpha/2} = 1.96$，效能80%时$z_{1-\beta} = 0.84$，效能90%时为$1.28$。
:::

这个公式显示了主要的驱动因素。样本量取决于待检出差异的平方：把目标差异减半，样本量约增至四倍。当结局相对于所寻求的差异而言较为罕见时，样本量更大。所要求的效能和严格程度越高，样本量越大。

目标差异应是具有临床意义的最小差异，或对效应的现实估计。为使试验负担得起而选择一个乐观的大效应是常见做法，其结果是效能不足的试验以“无显著差异”告终，而一个较小但有价值的效应很可能是存在的。

::: example 样本量计算 {#ex-samplesize}
一项虚构试验将检验一种新的康复方案能否把卒中后1年再入院率从10%降到7%。要在双侧显著性水平0.05下达到80%效能，每组需要多少参与者？
::: solution
$p_1 = 0.10$，$p_2 = 0.07$，$(1.96 + 0.84)^2 = 7.84$。

$p_1(1-p_1) + p_2(1-p_2) = 0.09 + 0.0651 = 0.1551$。

$(p_1 - p_2)^2 = 0.0009$。

$n = 7.84 \times 0.1551/0.0009 = 1{,}351.1$，**向上**取整为每组1352人，共2704人。考虑10%的失访，每组应招募约1503人（$1{,}352/0.9$，向上取整）。

要检出3个百分点的绝对降低需要一项大型试验。如果该方案预计以群体形式实施，整群设计还会按设计效应进一步增加人数。
:::
:::

## 分析 {#analysis}

::: definition 意向性治疗与符合方案 {#def-itt}
在**意向性治疗**（ITT）分析中，每个参与者都按其被随机分配的组进行分析，无论其实际接受了何种治疗、是否完成治疗。

在**符合方案**分析中，只纳入按规定接受了所分配治疗的参与者。在**实际治疗**分析中，参与者按其实际接受的治疗分组。
:::

ITT保持了随机化所创造的均衡，因此是优效性试验的主要分析。它估计的是在实践中*提供*一种治疗的效应，包括人们停药或换药的影响。符合方案分析和实际治疗分析破坏了随机化，因为坚持治疗或换组的人并不是随机子集。

::: example 组间交叉 {#ex-itt}
在一项虚构试验中，1000名血管疾病患者被随机分配到手术或内科治疗，每组500人。手术组中，50名患者病情过重不能手术而接受了内科治疗，其中15人死亡；在接受手术的450人中，36人死亡。内科组中，30名患者后来仍做了手术，其中3人死亡；坚持内科治疗的470人中，47人死亡。比较ITT、符合方案和实际治疗分析的结果。
::: solution
**ITT**：手术组$51/500 = 10.2\%$；内科组$50/500 = 10.0\%$。没有差异。

**符合方案**（排除交叉者）：手术$36/450 = 8.0\%$；内科$47/470 = 10.0\%$。

**实际治疗**：接受手术$(36 + 3)/480 = 8.1\%$；接受内科治疗$(15 + 47)/520 = 11.9\%$。

符合方案分析和实际治疗分析使手术显得有益。但病情过重不能手术的患者死亡率为30%，而他们被移出了手术组。手术显得好，部分原因是最重的患者没有做手术。保持随机分组完整的ITT分析显示，提供手术的策略并无优势。
:::
:::

**缺失数据**威胁着每一项试验。如果各组退出者的预后不同，比较就会有偏倚。当缺失的原因清楚时，多重插补等方法会有帮助，并应进行敏感性分析，检验结论在多大程度上依赖于对缺失结局的假设。最好的保护是把失访降到最低。

**亚组分析**问的是效应是否因患者群体而异。它们常常产生误导。亚组一多，有些亚组就会因机遇而显出不同的效应。1988年发表的大型试验ISIS-2显示阿司匹林降低了心肌梗死后的死亡。为说明这一点，研究者按星座分析了患者：对于双子座或天秤座的人，阿司匹林似乎没有益处。可信的亚组效应为数不多，它们是预先规定并预测了方向的，有正式的交互作用检验支持，在生物学上合理，并得到重复验证。

**因获益提前终止**有时是正确的，但提前终止的试验，尤其是事件数少的，往往高估治疗效应，因为它们恰在随机高点停了下来。期中分析应事先计划，有严格的终止规则，并由独立的数据监查委员会监督。

::: warning “无统计学意义”的试验并未证明“无效应”
没有发现统计学显著差异的试验并没有证明两种治疗等效。如果差值的置信区间很宽，它既与有价值的获益相容，也与伤害相容，试验只是太小了。在得出“无效应”的结论之前，先看置信区间：它是否排除了对患者有意义的差异？只有这样，“无重要差异”才是公允的结论。要证明等效或非劣效，需要为此专门设计的试验。
:::

## 注册与报告 {#reporting}

没有发现效应的试验较少被发表，看起来不利的结局有时也被从报告中删去。两者都会扭曲证据。已有两项保障措施成为标准做法。

**注册。** 2004年，国际医学期刊编辑委员会宣布，其成员期刊只考虑发表在第一位参与者入组之前已在公共注册平台注册的试验；该政策适用于2005年7月1日或之后开始招募的试验。ClinicalTrials.gov和ISRCTN注册库等注册平台事先记录了主要结局，使读者能核查所发表的结局是否就是原计划的结局。

**方案与报告规范。** **SPIRIT**声明（2013年，2025年更新）列出了试验方案应包含的内容。**CONSORT**声明首次发表于1996年，并于2001年、2010年和2025年更新，列出了试验报告应包含的内容：CONSORT 2025有一份30个条目的清单和一张参与者流程图，并新增了关于开放科学的部分，如数据共享和方案的获取。流程图显示每组有多少人被筛选、随机化、分配、随访和分析，它是阅读试验时应首先查看的内容。

::: quiz
一项试验把400名患者随机分配到一种新药或安慰剂。用药组中20%的人因不良反应停药。作者报告了显示显著获益的符合方案分析，以及显示获益较小且无统计学意义的意向性治疗分析。哪种说法最准确？
- [ ] 符合方案结果更有效，因为它反映的是实际服药的患者。
- [x] 意向性治疗结果是主要的无偏比较；符合方案结果可能有偏倚，因为能耐受该药的人与不能耐受的人不同。
- [ ] 两种结果同样有效；真相介于二者之间。
- [ ] 试验证明该药无效。
::: solution
只有意向性治疗比较保持了随机化所形成的组别。因不良反应停药的人，其健康状况和预后可能与继续用药者不同，因此排除他们会造成非随机的比较。ITT对中等获益的估计伴有较宽的区间，这是公允的总结：该药可能有帮助，但这项试验并未令人信服地证明这一点。它当然也没有证明该药无效。
:::
:::

::: history
1747年，皇家海军“索尔兹伯里”号上的军医詹姆斯·林德（James Lind）把12名坏血病水手两两分组，给予不同的疗法，包括苹果酒、醋、海水以及橙子和柠檬。吃柑橘的两人迅速康复。林德的研究是对照比较，但不是随机比较。

随机化来自农业科学：罗纳德·费希尔（Ronald Fisher）在20世纪20年代以及《实验设计》（*The Design of Experiments*，1935年）中论证，正是随机分配使统计检验有效。奥斯汀·布拉德福德·希尔（Austin Bradford Hill）把这一思想引入医学。英国医学研究理事会关于链霉素治疗肺结核的试验于1948年发表在《英国医学杂志》上，它用随机抽样数分配患者，分配结果装在密封信封中保存于中央办公室，并与仅卧床休息的患者比较。链霉素当时供应短缺，这使得用机遇来分配它在伦理上可以接受。

这项试验通常被称为第一项真正随机化的临床试验。它的方法，包括隐藏的中央分配以及由不知道治疗分组的阅片者评估胸片，为现代试验树立了范本。
:::

## 后续内容

阅读试验结果所需的统计学，包括置信区间、p值、需治人数和风险比，见[[epidemiology-ebm/statistics-for-clinicians]]。合并多项试验是[[epidemiology-ebm/systematic-reviews]]的主题，而为临床决策评价单项试验见[[epidemiology-ebm/critical-appraisal]]。

::: summary
- 随机化在期望意义上均衡已知和未知的预后因素，并赋予统计检验意义。它消除了指征混杂。
- 试验用PICO构建。主要结局应对患者有意义；替代结局和复合结局需谨慎对待，正如CAST所示。
- **分配隐藏**在招募时保护随机化；**盲法**在此后保护各组。应报告谁被设盲，而不是笼统地说“双盲”。
- 设计包括平行、交叉、析因、整群（样本量乘以$1 + (m-1)\rho$）、实用性、适应性和平台试验。
- 当整个置信区间位于预先规定的界值之内时，即显示了**非劣效**。
- 样本量取决于目标差异的平方、基线风险、$\alpha$和效能。效能不足的试验得不出定论。
- **意向性治疗**是优效性试验的主要分析；符合方案和实际治疗分析破坏了随机化。
- 对亚组结论和因获益提前终止的试验保持怀疑。无统计学意义的结果并不证明没有效应。
- 试验应在入组前注册（ICMJE政策自2005年起实施），遵循SPIRIT方案，并按CONSORT 2025报告。
:::

## 习题

::: exercise 分配隐藏还是盲法？ {level=1}
解释分配隐藏与盲法的区别，并说明为什么分配隐藏在每项试验中都可行，而盲法则不然。
::: solution
分配隐藏是在参与者入组之前，向负责招募的人隐藏*下一个*分配。它保护随机化过程免受选择偏倚。盲法是在分配*之后*向参与者、临床医生、结局评估者或分析者隐藏分组，防止诊疗和测量上的差异。分配隐藏总是可行的，因为它只要求序列被集中或安全地保存。当治疗明显不同时，如手术对比药片，盲法就不可能实现，不过结局评估者通常仍可设盲。
:::
:::

::: exercise ITT危险差 {level=1 check="4.5"}
在一项虚构试验中，随机分配到新治疗的400名参与者中30人、分配到标准治疗的400人中48人发生卒中。按意向性治疗计算绝对危险降低（以百分点表示）。
::: solution
风险分别为$30/400 = 7.5\%$和$48/400 = 12.0\%$。绝对危险降低为$12.0 - 7.5 = 4.5$个百分点。
:::
:::

::: exercise 设计效应 {level=1 check="1.95"}
一项整群试验以全科诊所为单位随机化，每个诊所平均20名参与者，组内相关系数为0.05。设计效应是多少？
::: solution
设计效应$= 1 + (m - 1)\rho = 1 + 19 \times 0.05 = 1.95$。要达到相同效能，该试验所需参与者几乎是个体随机化试验的两倍。
:::
:::

::: exercise 样本量 {level=2 check="196"}
一项试验旨在检出某结局从20%降到10%，双侧$\alpha$为0.05，效能80%。使用$z$值1.96和0.84以及[[#def-power]]中的公式，每组需要多少参与者？
::: solution
$n = (1.96 + 0.84)^2 \times [0.2 \times 0.8 + 0.1 \times 0.9]/(0.2 - 0.1)^2 = 7.84 \times 0.25/0.01 = 196$，每组196人。
:::
:::

::: exercise 更小的目标 {level=2 check="902"}
同一批研究者认为从20%降到15%也是值得的。使用相同的$z$值，每组需要多少参与者？向上取整。
::: solution
$n = 7.84 \times [0.2 \times 0.8 + 0.15 \times 0.85]/(0.05)^2 = 7.84 \times 0.2875/0.0025 = 901.6$，向上取整为每组902人。目标差异减半使样本量增加到四倍多，因为方差项也略有上升。
:::
:::

::: exercise 选择设计 {level=2}
为下列每个问题建议一种设计。(a) 在全科诊所中由护士主导的教育项目能否减少哮喘急诊入院？(b) 在稳定期哮喘中，一种新吸入器缓解症状是否优于现用吸入器？(c) 维生素D补充剂和ω-3脂肪酸是否各自能预防癌症？
::: solution
(a) **整群随机试验**，以诊所为单位随机化，因为该项目针对整个诊所实施，个体随机化会导致沾染。样本量必须考虑设计效应。(b) 可以用**交叉试验**，因为稳定期哮喘在洗脱后会回到基线，每名患者都可作为自身对照；如果担心残留效应，可改用平行试验。(c) **2×2析因试验**，把每名参与者随机分配到维生素D或安慰剂、以及ω-3或安慰剂，在一项试验中回答两个问题，前提是二者没有交互作用。
:::
:::

::: exercise 解读亚组结论 {level=3}
一项关于某降压药的大型虚构试验显示卒中相对降低15%。作者报告了24项亚组分析；在其中一个亚组，即60岁以下女性中，该药似乎没有效应（危险比1.02，95% CI 0.80至1.30）。一份新闻稿称“该药对年轻女性无效”。请评价这一说法。
::: solution
这一说法站不住脚。有24个亚组时，即使所有亚组的真实效应相同，也预计至少有一个会因机遇而显得不同。该亚组结果的置信区间很宽，包含了总体效应0.85，因此它与该药在年轻女性中同样有效是相容的。相关的问题是这一亚组的效应是否与其他亚组不同，这需要交互作用检验，而不是在亚组内单独检验。该分析很可能没有预先规定并预测方向，也没有明显的生物学理由支持这一差异。年轻女性卒中很少，因此该亚组的效能很低。在有预先规定的分析或另一项试验显示不同结果之前，对年轻女性的最佳估计仍是总体效应。
:::
:::

::: exercise 设计一项外科试验 {level=3}
外科医生希望比较关节镜手术与物理治疗对退行性半月板撕裂所致持续性膝痛的疗效。概述该试验的关键设计特点，并说明如何应对设盲困难和组间交叉。
::: solution
- **问题与人群**：经过一段初始保守治疗后仍有持续性膝痛、影像学显示退行性半月板撕裂的成人，无交锁或晚期骨关节炎。
- **对照**：结构化的物理治疗方案。设立安慰剂（假手术）组，即进行关节镜检查但不做治疗性操作，可以对参与者和评估者设盲，这一问题的试验中曾采用过；它引发伦理问题，必须以真正的不确定性和知情同意作为正当理由。
- **随机化**：计算机生成、中央进行、分配隐藏，按中心、或许也按年龄分层。
- **盲法**：如果没有假手术组，参与者和外科医生无法设盲，因此使用经过验证的患者报告结局，并要求结局评估者和分析者设盲。承认存在期望偏倚的风险。
- **主要结局**：12或24个月时经过验证的膝关节疼痛与功能评分，以预先规定的最小临床重要差异来确定样本量。
- **交叉**：一些物理治疗组患者会要求手术。记录交叉情况；如有临床理由则不加阻止；以意向性治疗为主要分析，符合方案分析为次要分析。清楚报告交叉率。
- **注册与报告**：入组前注册，按SPIRIT发表方案，按CONSORT（包括非药物治疗扩展版）报告，并报告两组的危害。
:::
:::
