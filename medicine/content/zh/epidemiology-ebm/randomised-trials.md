随机试验是唯一一种把关联转化为带保证的比较的设计、而这个保证值得精确理解：随机化在期望中均衡了测量与未测量的混杂、而这一职业关于试验的一切其他信念——盲法、分配隐藏、意向治疗、注册——存在的目的都是保护这一保证不受它实际失败的方式。**本章涵盖这一原则与其历史、架构（平行、交叉、析因、平台、自适应与整群设计及其分析义务）、实施与报告（CONSORT式报告、分配隐藏对盲法、意向治疗所统辖的失访与方案违背处理）、解读（意向治疗对按方案阅读的一对、非劣效的算术、及亚组虚构）、及试验的伦理与政治（均势、注册与发表偏倚、安慰剂的争议位置、及国际研究的社区同意问题）。**

## 原则

::: definition 随机化为何有效及它买到什么 {#def-principle}
**混杂是人群结构；随机化依构造把它溶解：掷硬币分配使观察与未观察的混杂在各臂中等可能、所以结局之差估计的是造成之差——在期望中、在可能掷币的平均上、这就是为何试验的效度是一个关于设计而非关于特定样本的陈述（允许无分布假设精确推断的“随机化检验”概念基础）。每个临床医师都应拥有的三条推论。一：均衡是概率性的、所以观察到的不平衡除非极端否则不是效度威胁、偶然不平衡由分析的方差而不是调整处理、而“两组基线不同”的批评通常是追噪声（协变量调整之问比口号更微妙：对随机化数据的调整分析仍然有效、而精度的提高是正当的；在随机化之后重新加权会重新打开设计关上的那扇混杂之门）。二：随机化买不到外部效度：试验人群是一个被选择的人群（资格标准、同意、站点地理——“随机化人群的代表性”文献及务实试验运动的回答）而推广始终是一个论证、从不是一个保证。三：保证覆盖的是目标估计量——在试验照护条件下对试验合格人群的平均效应——而每一次外推（对你多病共存的82岁患者、对你资源不足的地区综合医院）都是一个应当陈述的可运输性假设。效能、精度、及“无效应”与“无效应的证据”之别也属于这里：效能不足的试验在伦理上可疑因为它什么也没回答（用“无信息试验即不道德”取代“小的阳性试验胜过没有大的”的立场）、而无效区间阅读（置信区间的排除界限作为有临床意义的陈述）是一个不显著结果的正确报告。本章的历史锚点是这些没有一样是显而易见的：1948年之前治疗文献是病例系列与信念、而Bradford Hill的链霉素试验——带它的硬币试管随机化、其方案定义的标准、及同时代批评它未治疗对照的人——在同一个十年确立了模板、而Fisher的《研究人员的统计方法》提供了数学、及英国医学杂志1950年代“柳叶刀自己的社论之战”把这一争论制度化。**
:::

## 架构

::: definition 设计及其义务 {#def-designs}
**平行组优效试验是默认：两个或以上组、随机化、尽可能盲、为主要终点评定效能并带次要终点所需的多重性校正（把“它还减少了抑郁与骨折”变成要么预先指定的层级要么假说生成的色彩的族系错误算术）。交叉试验（每个受试者自己的对照）通过移除人际变异买到精度、代价是延续效应条件（清洗期与短稳定疾病逻辑）、时相效应、及必须尊重设计的分析（顺序、时期、治疗效应；“两顺序两周期交叉”等同检验的微妙、及监管对假定延续效应分析的不信任）。析因设计一次检验两种干预、带效率与交互估计的警诫（“B族维生素与叶酸复发试验”作为经典成功那一类）。整群随机（诊所、学校、病房被随机化）为无法逐人给予的干预而存在（外科技术、筛查规划、手卫生运动）、而其义务是组内相关使样本量膨胀的算术、报告核查表所追捕的个体水平分析谬误、及盲法无法修好的招募偏倚风险。现代扩张：平台与篮子及伞式设计（国际医学期刊编辑委员会2018年改革与平台定义文献；平台内部对比较的优效多重性结构；肿瘤篮子试验共享分子靶点的逻辑、及伞式的不依赖肿瘤部位审批相邻的争论）、自适应设计（样本量重新估计、反应自适应随机化与早期停止规则带其I类错误与解读警诫——“自适应是创新还是带额外步骤的可选停止p操纵”之辩）、及务实与登记试验（“解释性对务实”连续谱的二维分类、相关指南、及当队列存在时使随机化便宜队列内试验设计）。在设计端属于等同与非劣效机制的统计学、解读定义将长篇处理。**
:::

## 实施与解读

::: definition 实施、报告与阅读的一对 {#def-conduct}
**分配隐藏不是盲法：隐藏（中心或药房控制的随机化；密封信封时代有记录的选拔失败）保护分配的瞬间、而盲法保护测量、失访与共干预——而两种失败都朝研究者的希望倾斜、这就是为何偏倚风险工具（带其信号问题的Cochrane RoB 2）分别审问它们。盲法更深的文献是经验性的：疼痛与帕金森病中开放对隐蔽给药的研究使治疗的期望成分变得可测量、安慰剂反应研究显示其规模、而“外科手术与理疗中无法盲”问题推动了实施定义所涵盖的假对照解决方案。报告是同一场战斗拉长到论文长度：CONSORT声明及其扩展（整群、非劣效、务实、试点）把“描述你随机化了什么”变成一份其缺失本身就是质量信号的核查表；注册运动（入组之前在ClinicalTrials注册、国际医学期刊编辑委员会政策、WHO注册库及其数据元最小集）存在是因为从未报告的试验是医学中最大的偏倚（结局报告偏倚研究——“改变主要终点”的流行度调查、及Turner等人关于抗抑郁药发表的元研究显示注册加报告能修正的治疗效应扭曲）；而“方案对论文”审计——把注册的结局与发表的比较——如今是一项标准评价动作、这就是本章练习让读者去做它的原因。分析层：意向治疗是一种按分配组分析的纪律、使随机化对比在非依从、交叉与退出之后仍然存活——带它诚实的伴生陈述（按实际治疗的分析回答“如果被服用”、按方案分析需要自己的选择偏倚辩护、而非劣效试验以足够不同方式阅读这两者、以致指南要求一致性）；失访是意向治疗的敌人（20%丢失阈值的民间说法、及正确规则：当丢失按组以与结局相关的方式不同时才要紧、这就是为何没有表格而只有“各组原因相似”断言是红旗）；而多重性是意向治疗安静的预算（中期分析的alpha消耗、次要终点的守门、把确证主张与假说生成分开的族系算术）。本章的终点是阅读技能：一项试验的估计、它的区间、它的偏倚地形与它的可运输性是四个分开的问题、而多数临床争议——及多数期刊错误——是四者之一被走私进另一个。**
:::

::: example 非劣效之问 {#ex-ni}
一种新的每周一次抗生素寻求在肺炎中对每日标准治疗的非劣效：影像学治愈的边际12个百分点、观察到的差为-3个百分点（95%置信区间-9至+3）、并把不显著的差异宣称“等同”。先批评、然后给出正确的解读。
::: solution
**边际与继承的偏倚（[[#def-conduct]]、[[#def-principle]]）：算术：当置信区间的上限保持在边际之下时宣布非劣效（+3低于12、所以统计非劣效成立）；“等同”的主张是语言滥用——非劣效意味着“不比我们选择的边际差太多”、而边际是一个政策决定（影像学治愈的12个百分点是巨大的：临床上新药可能实质更差而仍然通过）。藏在里面的威胁：检验灵敏度（试验有没有能力发现任何差异？如果标准臂表现不佳——“生物漂移与毒力下降”问题、安慰剂敏感的终点、轻症人群选择——非劣效就变成“两臂都差”——历史荟萃分析与“恒常性假设”文献）、及意向治疗对按方案的张力（非劣效中的意向治疗分析可能通过把两臂相互稀释而有利于新药——两种分析必须一致的原因、及主要方案违背为何等同于破盲）。正确解读一句话：“在这一人群中、用这一治愈定义、每周抗生素未被证明比每日治疗差过预设的12点边际；该边际与该终点对你的患者是否要紧是另一个判断。”评价者的收尾习惯：问活性对照者历史上取得了什么（让检验灵敏度可见）、终点是否是临床医师在意的终点、及边际是由申办方的监管统计学家还是由临床共识设定。**
:::
:::

::: example 因获益而终止的试验 {#ex-stop}
一项心血管结局试验在中位1.8年后终止、因为主要终点越过了其中期边界：已发表报告中风险比0.78、P=0.004。指南小组辩论如何权衡它。
::: solution
**早期终止的统计（[[#def-conduct]]、[[#def-principle]]、[[cardiovascular/coronary-artery-disease]]）：效应量膨胀机制：在一个随机高点触及边界时终止会高估真实获益（组序贯设计“赢家诅咒”与“在峰值停止”的偏倚相邻性质——序贯似然方法校正而已发表点估计很少应用的条件偏倚）、而置信区间的名义覆盖度以终止规则为条件、所以报告的0.78是真实值可能规模的实际上限、不是它的最佳猜测。其他扭曲：被截断的随访（事件少于计划、次要终点与安全性的精度更低——早期终止论文低报的“死亡不确定性与硬终点不成熟”问题）、危害信号的不完整积累（早期获益早期危害盲区不对称）、及对剩余试验团队的信息审查（“终止对证据生态其余部分的影响”文献——其他试验失去招募、荟萃分析失去随机比较）。指南小组的补救：试验序贯分析与累积荟萃分析框架（所有试验的累积信息是否越过了所需信息前沿？在总体而不仅是单个试验的窥视中、无效或获益边界是否被越过）、把点估计当作乐观的、并把带有其多样性的合并估计作为锚、并要求终止使不可能实现的长期安全与死亡随访——通过方案修订、继续登记随访或试验自己的扩展研究、最好的小组如今会与中期计划一起预先指定。**
:::
:::

::: example 发生了延续效应的交叉试验 {#ex-crossover}
一项在稳定哮喘中对一种控制吸入器的两期交叉试验报告新药肺功能更优（晨间峰值呼气流速差25升/分、P<0.001）、用的是简单配对差分析；第一期9%退出、全部来自新药顺序；未使用清洗期因为“药物是吸入而局部的”。
::: solution
**延续效应是一个设计问题（[[#def-designs]]、[[#def-conduct]]）：叠在一起的技术错误：抗炎效应持续数周的控制性吸入糖皮质激素却没有清洗期——第二期测量是两种治疗的混合物（两顺序交叉试验的顺序乘时期交互本应发现的延续效应、而简单配对差分析已通过忽略顺序与时期把它假定掉）；集中在一个顺序的9%退出是带着时期与治疗结构被混杂的差异性失访（“交叉试验伴退出者在第一期之后化约为平行分析”的补救牺牲一半数据——这就是设计脆弱性的代价）；及哮喘自身的变异与季节（设计本应均衡而失访使它不均衡的时相效应）。正确的重新分析：先检验顺序、时期与延续效应（平行检验退路——只比较第一期的组间均值——及其诚实的效能损失）；在交叉模型与平行模型估计不一致时两个都报告、而它们现在不一致；并说明目标估计量（完全清洗下的个体内效应对策略的人群效应）。给读者的教训：交叉试验从个体内比较借入精度、并用延续效应与时期条件偿还、这就是为何监管机构与报告核查表（关于顺序与清洗期的交叉试验扩展条目）把没有延续效应诊断的阳性交叉结果最多当作暂定。临床摘要：“分析假定了方案跳过的清洗期；有效的部分是第一期比较、而那个差更小且不显著——该药的论证是未完成、不是已被证明。”**
:::

## 通向何处

同意、均势与安慰剂的伦理在[[medical-ethics-law/research-ethics]]阐述；试验的系统合并在[[epidemiology-ebm/systematic-reviews]]；评价演练在[[epidemiology-ebm/critical-appraisal]]；统计学在[[epidemiology-ebm/statistics-for-clinicians]]；而源自试验的证据在每个临床课程的指南中。

::: summary
- 随机化在期望中均衡了所有混杂、测量过的与没有的——一个关于设计而非样本的保证；协变量不平衡通常是噪声、而调整是正当的精化、不是修补。
- 随机化买不到外部效度：从试验合格者推广到你的患者是一个需要陈述的假设、而务实试验与效果文献存在就是为了检验它。
- 分配隐藏保护分配、盲法保护测量与失访；两者都朝研究者的希望失败、所以偏倚风险评估把它们当作分开的工程控制。
- 意向治疗在受试者偏离时保护随机化对比；按方案对比回答“服用时会发生什么”并需要自己的设计逻辑——这一对应一起阅读、而非劣效翻转它们的层级。
- 非劣效边际是政策选择、而检验灵敏度是设计的承重假设；“等同”是试验赢不到的一句话。
- 因获益而早期终止会放大效应估计并截断安全性与死亡证据；把终止试验的点估计读作乐观的上限、而把全部试验读作证据。
- 注册与报告纪律（前瞻注册的主要终点、完整的结局报告、个体受试者数据共享）就是一部试验与一份宣传材料的区别。
:::

## 练习

::: exercise 解释随机化 {level=1}
一位患者问为什么试验为她的治疗掷硬币而不是让最好的医生决定。给出三句话的回答与一句诚实的警诫。
::: solution
**最朴素的真答案（[[#def-principle]]）：三句话：“两种治疗都合理、而没人知道哪种更好——这就是试验存在的原因；如果由医生选择、更健康与更幸运的患者会漂向医生怀疑的那种治疗、而这一比较测量的将是怀疑、不是医学；硬币使两组在我们能看到的一切方面、而更重要的是在我们不能看到的一切方面都相似、所以结果之差就是治疗造成的差。“警诫：”你放弃了医生的判断比硬币更适合你的机会——我们只在不确定是真实的时候接受这一点、而你可以随时退出；还有，无论这个试验发生什么、我们仍会把她当个体治疗——硬币决定的是研究用药、不是你的照护。“给培训生的教学附加：这段对话就是外行的临床均势（伦理所面向临床的翻译）、而”没人知道哪种更好”这句话是试验的全部辩护——如果对她而言并非如此、诚实的回答是转诊、不是随机化。**
:::
:::

把偏倚风险推理用于一项试验：各站点密封信封分配、药师盲而受试者不盲的设计（活性对外观相同的活性）、18%的失访集中在干预组并被断言“各组原因相似”、及主要终点在数据库锁定前的一次会议报告中被更换。逐域报告并说明担忧的方向。
::: solution
**作为叙事的偏倚风险（[[#def-conduct]]）：随机化过程：站点密封信封——高度担忧（信封与站点生成清单的分配隐藏失败模式有记录；偏倚方向有利于研究者的期望）。偏离既定干预：两个活性药而受试者不盲——一些担忧（对主观结局与对共干预的期望效应；“外观相同的活性”对照至少部分防止了差异性退出的叙事）。缺失结局数据：18%差异性失访配一句断言而不是一张表——高度担忧（与治疗及结局都相关的差异性丢失是使每种分析产生偏倚的信息性删失条件；在任何主张之前敏感性分析——最坏情形、带转折点的最多重插补——是强制的）。结局测量：对客观终点被药师盲部分缓解、对患者报告的则令人担忧。所报告结果的选择：数据库锁定前在会议上报告的终点更换——高度担忧（有其已知效应方向偏倚的选择性结局报告；评审者应当要求的方案与注册比较、及“结果先出然后才取回方案”的失败模式）。总体裁决：该试验不能支持其所声称精度的因果主张；其无偏残余是最坏最好定界之后的比例差、而正确的总结句是“不确定、可能有益、需要一个分配隐藏、盲法、终点预先注册的试验”。教学要点：偏倚风险评估不是勾表格；每一域都命名一个有方向的机制、而评估就是这个机制的故事。**
:::

::: exercise 设计外科试验 {level=2}
对退行性膝半月板撕裂的关节镜部分半月板切除对监督下运动：针对外科研究的特定偏倚设计决定性试验、使用运动方案已发表的假手术先例。
::: solution
**假手术的严谨（[[#def-principle]]、[[#def-conduct]]、[[musculoskeletal/back-pain]]）：设计：平行优效、分配隐藏的中心随机化、及假关节镜对照（切口、关节镜插入、不切除——先例自身的伦理与可行性论证在伦理部分处理）、带关闭后外科医师对分配盲的现实与受试者盲的保持；使它奏效的共干预对称：两组都接受相同的监督运动（理疗文献以惨痛代价学到的“运动剂量标准化与依从审计”）、相同的随访接触频率（“治疗性接触等同”要点）、及相同的镇痛阶梯方案并以挽救用药消耗作为过程终点。结局：以患者报告的疼痛与功能（试验使用的最低核心结局集）为主要、带机械症状分量表（绞锁与卡住那一类、外科可能真正不同——主张退行性撕裂诊断自身要紧的症状定义亚组文献）、及再手术与交叉作为危害。分析：把交叉计入的意向治疗（“按分配治疗效应”估计量的限度被明确）、按机械症状与X线骨关节炎分级预先指定的亚组、及运动剂量等同性检验。先例的教训：已发表的试验（Moseley与Katz及Sihonen相邻的假手术规划结果——在退行性撕裂中运动与假手术在1至2年时与真正手术统计上无法区分、这一重塑指南并留下绞锁症状残余争论的“超说明书操作习惯”发现）既显示设计的威力、也显示专科的抵抗：招募、外科医师均势、及“当你相信时真正手术就不同”的表演效应、盲法检查必须测量。报告：非药物治疗的CONSORT扩展、并逐字附上批准文件中的假手术伦理辩护。**

::: exercise 解读亚组森林图 {level=2}
一项心衰试验的亚组图显示糖尿病者有益（风险比0.6）而非糖尿病者无（1.1）、交互P=0.07、而新闻稿以“对糖尿病者更有效”开头。为你的期刊俱乐部写解读备忘录。
::: solution
**亚组、交互与多重性（[[#def-conduct]]、[[epidemiology-ebm/statistics-for-clinicians]]、[[cardiovascular/heart-failure]]）：备忘录三步。第一：先交互、绝不组内：0.6与1.1之间的差必须作为交互检验（检验了：P=0.07——非常规阈值、而亚组交互按设计效能不足、因为试验的效能计算忽略了这次切分）。第二：多重性：亚组图是“条条大路通标题”结构（二十个亚组在alpha 0.05保证一些表面异质性；假发现率与亚组发现方法文献——2000年代被报告指南吸收的“亚组分析与森林图时尚”批评）。第三：合理性与先验：是否有糖尿病亚组会利用的机制（类别生物学效应、及被二甲双胍相邻的混杂、药物相互作用意识分析所追捕）、及该发现是否与该药其他试验和该疾病的流行病学一致？裁决：“除非一个令人信服的、预先指定的交互能在考虑多重性的检验中存活、试验的总体估计适用于两组；对糖尿病者按常规治疗——亚组发现是下一个试验分层的假说、而新闻稿是一个制造出来的差异。”给读者的收尾习惯：唯一应当改变实践的亚组发现是试验为其而设计去检验的那个（预先指定带效能的分层随机化设计）——其余都是明日问题的流行病学。**

::: exercise 论证安慰剂对照 {level=3}
一项新抗抑郁药治疗中度抑郁的试验提出安慰剂对照臂并带既往用药两周清洗期。写出伦理争论的双方、然后给出伦理学家与监管机构已接受的折中设计。
::: solution
**科学与责任之间的安慰剂（[[#def-conduct]]、[[medical-ethics-law/research-ethics]]）：支持方：检验灵敏度论证（抗抑郁药安慰剂反应文献——期望、仪式与向均值回归产生的反应率使活性对活性试验在首次审批时无法解读；使非劣效设计效能不足的“无效应的证据对无证据”不对称）、及科学价值创造伦理的论证（一个无法回答其问题的试验本身就不道德——均势要求双向切割）。反对方：《赫尔辛基宣言》“经证实的最佳方法”条款及其解释史（1990年代后艾滋病试验辩论的永久疤痕）、清洗期之问（原本治疗稳定的受试者为试验变得有症状——“设计诱导的危害与无替代臂”批评、自杀风险监测义务）、及结构性论点：中度抑郁有可接受效应量的已证实治疗、所以“比没有好”不是患者需要被问的那个问题。如今成为标准的折中架构：叠加设计（新药对加入稳定标准治疗的安慰剂——回答增量价值、牺牲检验纯度）、带早期逃逸与挽救方案缩短安慰剂暴露的设计（精神药理试验伦理批准所要求的“挽救用药与预定终止标准”装置）、带通过历史与同期生物标志物锚证明检验灵敏度的活性对照非劣效、富集入组设计（“富集入组随机化反应”带其知情同意披露义务与“撤药混杂”批评）、及只随机化处于均势者的患者偏好试验（同时保住盲法与自主的偏好设计文献）。对实际方案的裁决结构：当有效治疗存在且监测能捕捉恶化时、中度抑郁的单纯安慰剂加清洗期难以辩护；叠加加挽救加短暴露设计在伦理约束内回答了监管之问、而试验的注册与同意必须说明它在回答哪个问题、因为“安全性与有效性”两者都涵盖。**

::: exercise 写出统计分析计划 {level=3}
为一项双臂随机优效试验起草一份能经受“方案对已发表报告”审计的统计分析计划各节：受试人群、结局、违背处理、缺失数据、中期分析、及多重性。
::: solution
**作为合同的统计分析计划（[[#def-conduct]]、[[epidemiology-ebm/statistics-for-clinicians]]）：受试人群：由随机化定义的意向治疗集、“按分配”变量冻结在基线（随机化之后的改变是结局不是协变量的规则）、及若生物学合理性窗口要紧则带修正意向治疗集、声明为主要或支持性并说明理由。结局：一个主要终点、带其测量、时点与应答者定义在第一位受试者之前固定；带守门的次要层级（“不通过闸门就没有主张”的多重性结构——点名 Hochmuth与Bonferroni与守门相邻的选择、而不是临时拼凑）；安全性作为完整清单的纪律而不是假说追捕。违背：按类别陈述的处理（交叉——按分配为主要、按实际治疗用于机制讨论及其假设；依从——在主要主张中绝不按随机化后的行为调整；方案合格但被错误随机化——报告并按分配分析、带敏感性排除）。缺失数据：每个结局假定的机制、插补策略（带协变量的最多重插补、非单调退出的模式混合）、及当丢失超过命名阈值时为主要终点预先指定的转折点分析。中期分析：次数、时点、边界（点名O'Brien-Fleming保守的早期标线带alpha消耗函数）、独立数据监察委员会章程、中期结果的盲态、及终止规则的偏倚承认（效应量乐观陈述与继续随访计划）。多重性：整个家族的alpha预算带展示的账目（哪些检验花掉哪一部分、及剩余怎么办）、及“不通过预先指定树的交互检验就没有来自主要模型的亚组主张”规则。最后一节说明将共享什么（方案、带版本历史的统计分析计划、分析代码、个体受试者数据可得性条款）、因为检验上述一切的审计是别人把注册条目与论文比较、而最好的统计分析计划是为经受住那一点而写的、不只是为统计学家。**

::: history
**试验的谱系始于没人称之为试验的实验：Lind 1747年在海上的柑橘比较（六对、每对一种干预、六天的时长与仍然定义这一形式的小问题）与同一世纪的接种与海军膳食比较。十九世纪的临床医学大规模地生产干预、而把评价留给轶事与信念。正式机制在1920-40年代到来：Fisher在Rothamsted的随机化与显著性装置（产生了方差分析的农业地块、及那位至今警告不要把机制读入显著性的品茶女士）、然后是医学研究委员会的结核链霉素试验（1948）带它的信封硬币随机化、其未治疗对照之争及“随机化合乎伦理吗”的读者信——七十年来未变的论证——随后是百日咳疫苗现场试验、及1954年的Salk脊髓灰质炎试验、有史以来最大的安慰剂对照实验。有条理的深化：1950年代的双盲与安慰剂时代（Beecher 1955年测量安慰剂事业的论文；退伍军人管理局对降压药与抗凝药的比较临床试验、其与治疗判断学派的“比较试验合乎伦理吗”之争由证据与结果的谦逊解决）；意向治疗原则在同一批退伍军人与冠心药物文献中诞生；CONSORT声明1996年作为方法学家对不可读报告的安静反抗而诞生、其2010年修订、及其扩展家族（整群、非劣效、试点与可行性、务实）；注册运动（2004年国际医学期刊编辑委员会的截止日期使前瞻注册成为现实、WHO注册库及其最小数据集、及伴随运行的“代理试验”法律论点）；及2010年代的可重复与改革浪潮从心理学来的注册报告运动、个体受试者数据荟萃分析基础设施、肿瘤学与疫情试验的自适应与平台设计改革、及把方案对论文比较变成一项常设公共卫生监测职能的试验注册库审计——因为该领域成熟的裁决是：一项完成而未报告的试验与一个伪造的数据集同样是研究不端事件。—— [[medical-ethics-law/research-ethics]]、[[epidemiology-ebm/systematic-reviews]]。**
:::

::: example 登记试验 {#ex-registry}
你医疗系统的电子病历能在没有各臂同意书的情况下把20000名高血压患者随机化到两种治疗算法。起草治理备忘录：均势、同意层级、数据保护、及结果回传义务。
::: solution
**作为常规照护的研究治理（[[#def-principle]]、[[#def-conduct]]、[[medical-ethics-law/research-ethics]]）：均势论证：两种算法是真正有争议的指南选项（试验从未在人群规模解决的“少强化治疗对按目标治疗”之辩）——临床均势被记录在案、这是伦理前提也是公共辩护。同意层级：为可行性做完整同意试点；然后“广泛同意带退出”模式（储存数据与生物样本库的同意架构、“警报覆盖实际审查”警告）、许多务实试验对最小风险比较效果随机化使用的“通知加退出”模式（临床均势作为风险降低的论证：患者接受的是他们本来也会接受的选项之一）、退出路径与入组路径一样容易而两种选择都不影响照护。数据保护：数据最小化与假名化层、控制访问审计痕迹、及“临床数据的研究使用”合法基础并为其公共的信息治理访问批准被记录。结果回传：一年内向参与者的医师与公众发布的汇总看板；个体结果之问由试验自身的照护逻辑处理（在一个设计良好的登记试验中、有临床重要性的结果由照护而不是研究产生——值得一陈述的设计特征）；及终止与变更治理（能叫停随机化的独立委员会、预先指定的条件、及试验中途指南变更如何处理——“背景漂移”方案修订路径）。社区层：患者公众参与算法对的选泽（“患者看重的结局”框架同时也固定了终点）、无论方向发表两组的结果（写进资助的注册与报告承诺）、及备忘录必须包含的诚实那句：试验的效力来自患者仍然是患者、而每一个治理选择都必须让这一点保持正当、而不只是合法。**

## 练习

::: exercise 指出这份报告的罪过 {level=1}
识别每个中的报告失败：(a) 一个试验注册的主要终点是“90天全因死亡”、而论文报告“90天心血管死亡加一个复合终点”；(b) 1000名受试者中960名完成、而流程图把40名归入“其他”；(c) 方法部分引用“适当的统计检验”；(d) 讨论以“未发现显著差异、证明等同”开头。
::: solution
**CONSORT四步（[[#def-conduct]]）：(a) 终点更换——选择性报告问题、而注册正是为监管它而创建；正确的做法是以方案为锚的报告、披露更换并把两个结果都呈现。(b) 流失不透明——流程图的工作是让丢失可检查（按组与原因的丢失二乘二）；“其他”使它失效、也使缺失数据判断失效。(c) 分析不透明——CONSORT要求方法识别“所使用的一切统计方法”、包括主要分析如何处理删失、不平衡与多重性；“适当的检验”是随机化试验版的“处理得很保守”。(d) 缺失证据谬误与非劣效篡夺——一个不显著的优效检验既不证明等同也不证明无差异；等同主张需要等同设计、边际、及针对边际阅读的区间。这个练习的要点：四项都是核查表条目、而核查表失败不是文书工作——每一项都是有方向的机制、这正是分级练习教读者去看的。**
:::

::: exercise 为设计选择辩护 {level=2}
一个资助小组把你的开放标签试验提案斥为“不可靠”。用陈述的偏倚结构为开放盲终点设计辩护（开放标签带客观终点的先例文献）、并承认盲法仍然强制的终点。
::: solution
**盲法是一种特定辩护（[[#def-conduct]]、[[clinical-skills/patient-safety]]）：论证：盲法防御对主观结局的期望驱动效应、差异性流失与共干预；当结局是客观且中心裁定的（死亡、按预设影像标准的再梗死、实验室确认的感染、出院行政终点）、期望通道就变窄、而设计的成本效果与推广优势占主导——“开放标签带盲法终点评估”先例文献与“轻度偏倚而便宜得多”的建模辩护、及假对照手术与器械试验对身体操作的盲法自身带危害（麻醉与切开的风险）及自身的破盲失败（“患者通常能猜到”研究）。承认：主观的患者报告结局（疼痛、疲乏、心境——安慰剂文献的主场）要求盲法、或至少由统计师保密的盲态评估者做分配隐藏的评估；依从驱动的终点被知晓分配污染（“开放的抗病毒试验中差异性退出”的例子）；而“开放”仍必须意味着分配隐藏、预先注册的终点、盲法结局委员会与客观主要终点——开放试验的报告指南存在是为了让“开放标签”是一个设计、不是一个借口。给资助小组的一句话回答：“我们在信念改变测量之处设盲、在信念无法改变之处测量；替代方案——对我们无法设盲的东西做假随机——买到的是表演、不是效度。”**
