**自身免疫病**是针对自身的适应性免疫应答造成的组织损伤。它很常见。在2023年一项对英国2200万人初级保健记录的研究中，Conrad等发现约十分之一的人至少患有19种常见自身免疫病中的一种，女性受累几乎是男性的两倍。这些疾病包括1型糖尿病、自身免疫性甲状腺病、类风湿关节炎、乳糜泻、银屑病、多发性硬化、恶性贫血、白癜风、炎症性肠病和系统性红斑狼疮。

上一章[[immunology/tolerance-regulation]]描述了耐受通常如何控制自身反应性淋巴细胞。本章要问：在常见疾病中耐受为何失败，损伤如何造成，自身抗体在诊断中如何被使用和误用，以及治疗原则是什么。各个疾病的临床细节属于器官系统课程；这里的重点是所有自身免疫病共通的免疫学推理。

## 什么算自身免疫

::: definition 自身免疫与自身免疫病 {#def-autoimmunity}
**自身免疫**是针对自身抗原的适应性免疫应答（抗体或T细胞）的存在。它很常见，而且往往无害：许多健康人体内可检出低滴度自身抗体，其频率随年龄增长而增加。

当这种应答造成组织损伤或功能障碍时，即存在**自身免疫病**。证明一种疾病属于自身免疫的最佳证据是抗体或T细胞能转移该疾病。在人类中，这见于母体IgG穿过胎盘、使新生儿出现一过性疾病，如新生儿格雷夫斯病、新生儿重症肌无力和新生儿狼疮。
:::

自身免疫病传统上分为两组：

- **器官特异性**疾病，免疫应答针对单一器官的抗原：1型糖尿病、桥本甲状腺炎、格雷夫斯病、艾迪生病、恶性贫血、重症肌无力、多发性硬化；
- **系统性**疾病，靶标是广泛分布的、常位于细胞内的抗原，如核蛋白和DNA：系统性红斑狼疮（SLE）、干燥病、系统性硬化症、炎性肌病，以及以关节受累为主的类风湿关节炎。

器官特异性疾病在同一人和同一家族中聚集。1型糖尿病患者患自身免疫性甲状腺病、乳糜泻和艾迪生病的风险增加，这就是甲状腺和乳糜泻筛查成为常规糖尿病管理一部分的原因。

## 耐受为何失败

常见自身免疫病是**多因素**的：需要遗传易感性、环境触发因素，往往还有偶然性。没有一个因素是充分的。

::: theorem 自身免疫的多因素模型 {#thm-multifactorial}
当几处耐受的部分失败同时出现时，就产生常见的自身免疫病：

1. **遗传易感性**，主要来自许多效应很小的变异，其中最大的通常位于HLA区域；
2. 提供抗原、炎症或共刺激的**环境触发因素**，如感染、吸烟、药物和紫外线；
3. 应答一旦开始后的**放大**，即组织损伤释放新的自身抗原（**表位扩展**）。

由于每个因素只起部分作用，同卵双生子的一致率并不完全，因疾病不同通常在约15%至50%之间，但远高于异卵双生子。
:::

::: proof
如果自身免疫病仅由基因决定，那么所有基因都相同的同卵双生子几乎总会一致；事实并非如此，所以非遗传因素必定起作用。如果仅由环境决定，同卵双生子的一致率不会高于异卵双生子或普通同胞；但实际更高，所以基因也起作用。这种中等程度的一致率正是若干相互作用的部分病因模型所预测的。同一模型还解释了为什么自身抗体可以在发病前存在多年：应答已经开始，但还需要另一个事件才能使自身免疫变成疾病。
:::

### 基因

最强的遗传关联来自**HLA**等位基因，因为它们决定把哪些自身肽提呈给T细胞：1型糖尿病中的HLA-DR3和DR4（伴DQ2和DQ8），类风湿关节炎中的HLA-DRB1共享表位等位基因，强直性脊柱炎中的HLA-B27。HLA之外，许多风险变异位于设定淋巴细胞激活和调节阈值的基因中。磷酸酶**PTPN22**的一个变异增加1型糖尿病、类风湿关节炎、SLE和自身免疫性甲状腺病的风险，**CTLA4**和**IL-2受体**附近的变异也有类似的共同效应。这些共享基因解释了为什么不同的自身免疫病在同一家族中聚集。

### 性别

大多数自身免疫病在女性中更常见。SLE和干燥病的男女比例约为1比9，类风湿关节炎约为1比3。雌激素增强B细胞存活和抗体产生，X染色体上的一些免疫基因（如RNA感受器**TLR7**）部分逃逸X失活，因此女性可能表达更多。SLE常在育龄期起病，并可在妊娠期加重。

### 环境

- **感染。**通过**分子模拟**，针对微生物的免疫应答与自身发生交叉反应：风湿热中抗A组链球菌M蛋白抗体与心肌肌球蛋白交叉反应，部分吉兰–巴雷综合征中抗空肠弯曲菌（*Campylobacter jejuni*）脂寡糖抗体与神经节苷脂交叉反应。感染还可通过提供共刺激引起**旁观者激活**。一项针对美国军人的超大型纵向研究（Bjornevik等，2022年）发现，EB病毒感染后多发性硬化的风险增加约32倍，有力地证明EB病毒是主要病因之一。
- **吸烟**增加肺内蛋白的瓜氨酸化，在携带共享表位HLA等位基因的人中，大大增加伴**抗瓜氨酸化蛋白抗体**（ACPA）的类风湿关节炎的风险。
- **药物**可引起自身免疫。肼屈嗪、普鲁卡因胺和异烟肼引起**药物性狼疮**，典型表现为抗组蛋白抗体阳性；检查点抑制剂引起器官特异性自身免疫，见[[immunology/tolerance-regulation]]。
- **紫外线**损伤角质形成细胞并释放核抗原，这就是日晒可诱发狼疮发作的原因。

::: example 服用老药出现关节痛 {#ex-drug-lupus}
一名68岁男性因难治性高血压服用肼屈嗪2年。近2个月出现手部小关节疼痛、胸膜炎性胸痛和低热。ANA阳性，滴度1:640，均质型；抗组蛋白抗体阳性；抗dsDNA阴性，补体正常。肾功能和尿液分析正常。可能的诊断是什么？与特发性SLE有何不同？
::: solution
**诊断。**服用肼屈嗪的人出现关节痛、浆膜炎和发热，伴高滴度均质型ANA和抗组蛋白抗体，提示**药物性狼疮**。

**与SLE的不同。**药物性狼疮通常见于年龄较大者，男女发病相当，这反映了服药人群的构成；通常引起关节、浆膜和全身症状，很少累及肾脏或中枢神经系统；大多数病例存在抗组蛋白抗体，而抗dsDNA和抗Sm通常阴性，补体正常。肼屈嗪和普鲁卡因胺经乙酰化代谢，遗传上为**慢乙酰化者**的人风险更高，这说明了遗传因素与环境触发因素如何结合。抗TNF药物也可诱发狼疮样综合征，且更常为抗dsDNA阳性。

**处理原则。**停用该药，改用其他降压药。症状通常在数周至数月内消退，但ANA可在更长时间内保持阳性。可用非甾体抗炎药或短疗程糖皮质激素控制症状。
:::
:::

## 损伤如何造成

自身免疫病利用与超敏反应相同的机制，见[[immunology/hypersensitivity]]。识别机制可以告诉你哪些检查有意义、哪些治疗可能有效。

| 机制 | 例子 | 靶标 | 效应 |
|---|---|---|---|
| 抗体破坏细胞（Ⅱ型） | 自身免疫性溶血性贫血、免疫性血小板减少症 | 红细胞或血小板抗原 | 脾脏清除 |
| 抗体刺激受体（Ⅱ型） | 格雷夫斯病 | TSH受体 | 甲状腺毒症、甲状腺肿 |
| 抗体阻断或移除受体（Ⅱ型） | 重症肌无力 | 乙酰胆碱受体 | 易疲劳性无力 |
| 抗体针对基质（Ⅱ型） | 抗肾小球基底膜病 | Ⅳ型胶原α3链 | 肾小球肾炎、肺出血 |
| 免疫复合物（Ⅲ型） | SLE | 核抗原 | 肾炎、血管炎、关节炎、皮疹 |
| T细胞（Ⅳ型） | 1型糖尿病、多发性硬化 | 胰岛β细胞抗原、髓鞘 | β细胞破坏、脱髓鞘 |

许多疾病兼有多种机制。在类风湿关节炎中，T细胞、B细胞、自身抗体以及TNF和IL-6等细胞因子都参与滑膜炎症。在桥本甲状腺炎中，抗甲状腺过氧化物酶抗体是很好的标志物，但腺体主要被T细胞破坏。

::: example 傍晚加重的无力 {#ex-myasthenia}
一名34岁女性注意到复视和眼睑下垂在傍晚加重，吃饭到最后咀嚼困难。查体显示持续向上凝视时上睑下垂加重。解释其机制、抗体检测，以及胸腺为何相关。
::: solution
**机制。**眼肌和延髓肌的易疲劳性无力提示**重症肌无力**。大多数患者体内针对神经肌肉接头**乙酰胆碱受体**（AChR）的IgG抗体通过三种方式减少功能性受体数量：交联受体加速其内化，激活补体损伤突触后膜，部分抗体阻断乙酰胆碱结合。反复放电时每次神经冲动释放的乙酰胆碱略有减少，受体减少后安全余量丧失，因此持续使用时出现无力。

**抗体检测。**约85%的全身型重症肌无力患者可检出AChR抗体，单纯眼肌型较少。在无AChR抗体者中，部分有针对**肌肉特异性激酶**（MuSK，受体聚集所需）的抗体；MuSK型重症肌无力由IgG4介导，不固定补体，常以延髓症状为主，对利妥昔单抗反应特别好。

**胸腺。**胸腺异常很常见：年轻起病的AChR阳性患者常有胸腺增生，约10%至15%的患者有胸腺瘤。胸腺含有表达AChR的肌样细胞，被认为是启动自身免疫应答的部位。需要做胸部CT寻找胸腺瘤，胸腺切除术对部分患者有益。治疗包括乙酰胆碱酯酶抑制剂、糖皮质激素和节省激素的免疫抑制剂，以及阻断补体或新生儿Fc受体的新药。神经病学细节见[[nervous-system/neuromuscular]]。
:::
:::

### 抗核抗体检测

**ANA**检测采用HEp-2细胞（一种核较大的人上皮细胞系）**间接免疫荧光法**。将患者血清系列稀释后加到细胞上，用荧光标记的抗人IgG检测结合的IgG。结果报告为仍有荧光的最高稀释度（**滴度**）以及染色**核型**（均质型、斑点型、着丝点型、核仁型），后者提示靶抗原。阳性结果之后要检测特异性抗体，如抗dsDNA和可提取核抗原（Ro、La、Sm、RNP、Scl-70、Jo-1）。

两个事实主导着它的解读。第一，几乎所有活动性SLE患者ANA阳性，因此ANA阴性使SLE的可能性很小。第二，ANA在健康人中很常见。在一项健康人多中心研究中（Tan等，1997年），31.7%在1:40稀释度阳性，13.3%在1:80，5.0%在1:160，3.3%在1:320。女性、老年人以及自身免疫病患者的亲属阳性更常见。因此，只有当患者的临床特征已使ANA相关疾病具有相当可能性时，ANA阳性才有意义。

::: widget bayes

caption: 以自然频数表示的ANA作为SLE诊断试验。灵敏度98%、特异度87%（大致对应健康人在1:80时13%的阳性率）、验前概率2%时，大多数阳性结果是假阳性。把患病率提高到0.3，代表一位有颧部红斑、关节炎、蛋白尿和血小板减少的患者，看看预测值如何变化。数字仅为示意。
:::

::: example “你的ANA阳性” {#ex-ana}
一名29岁女性因病毒感染后乏力3个月就诊于全科医生。她没有关节肿胀、皮疹、口腔溃疡、脱发、雷诺现象或其他特征。血常规、肾功能、尿液分析和CRP均正常。医生开了ANA检测，结果在1:80阳性，斑点型。为便于说明，假设检测前她患SLE的概率为1/50，该滴度ANA对SLE的灵敏度为98%、特异度为87%。检测阳性后她患SLE的概率是多少？
::: solution
以1000名类似女性计算。

- 患SLE者：$1000 \times 0.02 = 20$。真阳性：$20 \times 0.98 = 19.6$。
- 未患SLE者：$980$。假阳性：$980 \times (1 - 0.87) = 980 \times 0.13 = 127.4$。

阳性预测值为

$$
\frac{19.6}{19.6 + 127.4} = \frac{19.6}{147} \approx 0.133.
$$

检测阳性后，她患SLE的概率只有约13%；像她这样ANA阳性的女性中约87%并不患SLE。检测并没有作出诊断，只是把一个低概率稍微提高了一点。

**怎么办。**重新审视病史和查体中有无特异性特征；若仍有临床怀疑，检查抗dsDNA和可提取核抗原抗体、补体水平和尿液分析。如果都正常且她没有特异性特征，阳性ANA很可能是偶然发现，可以安慰她，并建议出现新特征时复诊。更深层的教训是：不应把ANA当作单纯乏力的筛查试验；对低概率患者进行检测最常见的后果是焦虑和不必要的转诊。
:::
:::

:::warning
不要把一种自身抗体等同于一种疾病。在健康老年人以及心内膜炎和丙型肝炎等慢性感染中，类风湿因子阳性的比例相当高；多达约十分之一的健康女性可检出抗TPO抗体；多达三分之一的健康人低滴度ANA阳性。解读每个自身抗体结果都要结合验前概率、滴度和具体抗体，不要在没有明确临床问题的情况下开“自身免疫全套筛查”。
:::

### 分类标准不是诊断标准

风湿性疾病有**分类标准**，其目的是为研究界定统一的患者群体。它们有意设计得很特异，患者可能患有某病而不符合标准，尤其在早期。尽管如此，它们是对关键特征的有用概括。

- **2019年EULAR/ACR SLE分类标准**要求在任何时候HEp-2细胞（或等效检测）ANA滴度至少1:80作为**入选标准**。然后对加权的临床项目（发热、血液学、神经精神、皮肤黏膜、浆膜、肌肉骨骼和肾脏）和免疫学项目（抗磷脂抗体、低补体、抗dsDNA或抗Sm）计分；总分**10分或以上**且至少有一项临床标准，即分类为SLE。
- **2010年ACR/EULAR类风湿关节炎分类标准**适用于至少有一个关节存在明确滑膜炎、且不能用其他疾病更好解释的人。对关节受累、血清学（类风湿因子和抗CCP）、急性期反应物（CRP或ESR）以及至少6周的症状持续时间计分；**10分中得6分或以上**即分类为类风湿关节炎。

## 以系统性红斑狼疮为模型

SLE显示了几种免疫异常如何组合成疾病。一个有用的顺序是：

1. **核抗原暴露增加。**凋亡细胞产生增多（紫外线、感染）或清除减少（C1q或其他经典途径早期补体成分缺乏；见[[immunology/innate-immunity]]）。
2. **对核酸的固有感知。**含DNA或RNA的免疫复合物被浆细胞样树突状细胞摄取，其中的TLR7和TLR9感知核酸，驱动大量**I型干扰素**产生。大多数患者的血细胞有“干扰素特征”。
3. **B细胞耐受丧失。**干扰素和B细胞存活因子**BAFF**促进自身反应性B细胞的存活和激活，后者在自身反应性T细胞的辅助下产生针对DNA、组蛋白和核糖核蛋白的抗体。
4. **免疫复合物损伤。**复合物沉积于肾小球、皮肤、关节和浆膜并激活补体（Ⅲ型），而部分抗体直接破坏血细胞（Ⅱ型）。

每一步都是治疗靶点。**羟氯喹**干扰内体TLR信号，除非有禁忌，几乎所有SLE患者都推荐使用，并需定期视网膜筛查。**贝利尤单抗**阻断BAFF；**阿尼鲁单抗**阻断I型干扰素受体；**利妥昔单抗**清除B细胞。糖皮质激素以最低有效剂量用于发作期，重症狼疮性肾炎按EULAR和国家指南使用吗替麦考酚酯或环磷酰胺。

SLE在非洲裔黑人、加勒比裔黑人、南亚裔和东亚裔女性中比在欧洲裔白人女性中更常见，且往往更严重，肾炎发生率更高。颧部红斑在深色皮肤上可能更难看出，可表现为色素沉着或紫罗兰色而非红色皮疹；这是诊断延误的原因之一。

::: example 有蛋白尿的年轻女性 {#ex-sle}
一名23岁加勒比裔黑人女性3个月来手部关节疼痛肿胀，并反复口腔溃疡。现出现踝部水肿。血压152/96 mmHg。尿液分析示蛋白3+和潜血；尿蛋白/肌酐比值升高。血红蛋白98 g/L，血小板$85 \times 10^9$/L，淋巴细胞$0.6 \times 10^9$/L。ANA阳性，1:640，均质型；抗dsDNA强阳性；C3和C4降低；CRP正常。解释其免疫学表现和下一步处理。
::: solution
**诊断。**关节炎、口腔溃疡、血细胞减少和肾脏受累，伴高滴度ANA、抗dsDNA和低补体，强烈提示**SLE伴狼疮性肾炎**。按2019年EULAR/ACR标准，她满足ANA入选标准，得分远超10分。

**机制。**抗dsDNA抗体形成免疫复合物沉积于肾小球，激活补体经典途径，消耗C3和C4（Ⅲ型）。针对红细胞和血小板的抗体引起血细胞减少（Ⅱ型）。活动性SLE中淋巴细胞减少很常见。疾病活动而CRP正常是SLE的典型表现，部分原因是I型干扰素抑制CRP生成；狼疮患者CRP升高应考虑感染或浆膜炎。

**下一步。**这是可能危及器官的疾病。她需要紧急转诊至风湿科和肾内科，并做**肾活检**以确定狼疮性肾炎的分型，指导治疗。控制血压和减少蛋白尿很重要。治疗通常包括羟氯喹、糖皮质激素和吗替麦考酚酯等诱导药物，依现行指南进行。妊娠计划是治疗的一部分，因为SLE及其许多治疗药物影响妊娠，还需检查抗磷脂抗体和抗Ro抗体。
:::
:::

## 器官特异性疾病：两个例子

**自身免疫性甲状腺病**是最常见的器官特异性自身免疫。在**桥本甲状腺炎**中，T细胞破坏腺体，引起甲状腺功能减退；抗TPO和抗甲状腺球蛋白抗体是标志物。在**格雷夫斯病**中，IgG抗体**刺激**TSH受体，模拟TSH，引起甲状腺毒症和弥漫性甲状腺肿；眼眶中同样的自身免疫过程引起甲状腺眼病。由于TRAb是IgG，它们能穿过胎盘，因此一位现患或曾患格雷夫斯病的女性即使自己在治疗后已经甲减，其婴儿仍可能患新生儿甲状腺毒症。见[[endocrine/thyroid]]。

**1型糖尿病**是T细胞介导的胰岛β细胞破坏。针对胰岛素、GAD、IA-2和ZnT8的自身抗体在诊断前数月或数年出现；有两种或以上此类抗体的儿童终生发生临床糖尿病的风险很高。抗CD3抗体**替普利珠单抗**（teplizumab）已被证明能在有两种或以上自身抗体且糖耐量异常的高风险亲属中延迟临床1型糖尿病的发生，这是第一种在诊断前改变疾病进程的治疗。见[[endocrine/diabetes]]。

## 治疗原则

治疗的目的是替代丧失的功能、抑制免疫应答，或两者兼顾。

- **替代**对于许多器官被破坏的器官特异性疾病已足够：桥本甲状腺炎用甲状腺素，1型糖尿病用胰岛素，恶性贫血用维生素B12，艾迪生病用糖皮质激素和盐皮质激素。
- **广泛免疫抑制**：糖皮质激素，然后是甲氨蝶呤、硫唑嘌呤和吗替麦考酚酯等节省激素的药物。
- 针对机制的**靶向治疗**：抗TNF抗体、IL-6受体阻断（托珠单抗）、B细胞清除（利妥昔单抗）、共刺激阻断（阿巴西普）、JAK抑制剂，以及针对BAFF、I型干扰素、补体或FcRn的新药。
- **清除抗体**：抗肾小球基底膜病和肌无力危象用血浆置换；某些抗体介导的疾病用静脉注射免疫球蛋白。

每种免疫抑制策略都会增加感染风险，需要筛查（乙型肝炎、丙型肝炎、HIV、潜伏结核），尽可能在治疗前接种疫苗，并进行监测。

::: quiz
一名52岁女性乏力，舌大而痛，有大细胞性贫血。维生素B12降低。哪项结果最特异地支持恶性贫血是病因？
- [ ] 胃壁细胞抗体阳性
- [x] 内因子抗体阳性
- [ ] ANA 1:80阳性
- [ ] 抗TPO抗体阳性

内因子抗体对恶性贫血高度特异，但只见于约一半患者。壁细胞抗体更灵敏但特异性差得多，在老年人和其他自身免疫病中很常见。ANA和抗TPO抗体不能确定B12缺乏的原因，不过自身免疫性甲状腺病常与恶性贫血并存。

::: history
1901年，埃尔利希（Paul Ehrlich）和Julius Morgenroth发现，给山羊注射其自身的红细胞，山羊不会产生针对它们的抗体；埃尔利希用*horror autotoxicus*（“自身中毒恐惧”）一词来描述机体对自我攻击的回避。这个词常被误读为声称自身免疫不可能发生，但埃尔利希其实认识到调节机制可能失灵。1904年，Julius Donath和兰德施泰纳（Karl Landsteiner）描述了引起阵发性冷性血红蛋白尿的抗体，这是第一个与疾病相联系的自身抗体。

现代这一领域始于20世纪50年代。1956年，Ivan Roitt、Deborah Doniach、Peter Campbell和Vivian Hudson在桥本甲状腺炎患者体内发现了抗甲状腺球蛋白抗体，这种病是桥本策（Hakaru Hashimoto）在1912年描述的；同年，Noel Rose和Ernest Witebsky用甲状腺提取物免疫兔子，诱发了甲状腺炎。1948年，Malcolm Hargraves在狼疮患者骨髓中描述了LE细胞，由此发现了抗核抗体；20世纪50年代，George Friou引入了检测抗核抗体的免疫荧光法。
:::

## 后续内容

风湿性自身免疫病的深入内容见[[musculoskeletal/inflammatory-arthritis]]和[[musculoskeletal/connective-tissue-vasculitis]]。免疫缺陷与自身免疫常常并存，下一章[[immunology/immunodeficiency]]将说明这一点。这里提到的药物将在[[immunology/vaccines-immunotherapy]]中再次出现。

::: summary
- 自身免疫病是针对自身的适应性应答造成的组织损伤；在英国约十分之一的人至少患有一种常见自身免疫病，女性多于男性。
- 它是多因素的：HLA和许多小效应基因（PTPN22、CTLA4）、女性，以及感染（分子模拟、旁观者激活；EB病毒与多发性硬化）、吸烟（类风湿关节炎中的瓜氨酸化）、药物和紫外线等环境触发因素。
- 损伤遵循超敏反应机制：针对细胞或受体的抗体（Ⅱ型）、免疫复合物（Ⅲ型）和T细胞（Ⅳ型）。
- 自身抗体是诊断工具，其价值取决于验前概率。ANA对SLE灵敏，但在健康人中常见（1:80时13.3%，1:160时5%）；抗dsDNA和抗Sm特异。
- 分类标准（SLE用2019年EULAR/ACR标准，类风湿关节炎用2010年ACR/EULAR标准）界定研究人群并概括关键特征；诊断并不要求满足这些标准。
- 在SLE中，凋亡物质清除受损、TLR7/9感知和I型干扰素、BAFF驱动的B细胞存活以及免疫复合物沉积相互结合；每一环都是治疗靶点。
- 治疗包括替代丧失的功能、广泛抑制免疫应答或针对特定机制，并通过筛查和接种疫苗限制感染风险。
:::

## 习题

::: exercise ANA的阳性预测值 {level=1 check="0.1*0.98/(0.1*0.98 + 0.9*0.13)"}
一位风湿科医生诊治的一组患者SLE验前概率为10%。1:80的ANA灵敏度为98%，特异度为87%。ANA阳性的阳性预测值是多少？给出未取整的小数。
::: hint
以1000名患者计算，或用$\text{PPV} = \dfrac{p \cdot \text{sens}}{p \cdot \text{sens} + (1-p)(1-\text{spec})}$。
:::
::: solution
真阳性$= 0.1 \times 0.98 = 0.098$；假阳性$= 0.9 \times 0.13 = 0.117$。PPV $= 0.098/(0.098 + 0.117) = 0.098/0.215 \approx 0.456$。验前概率为10%时PPV约为46%，而验前概率为2%时约为13%。验前概率与检测本身同样重要。
:::
:::

::: exercise 抗体配对 {level=1}
说出与下列每种抗体关联最强的疾病：(a) 抗着丝点；(b) 抗MuSK；(c) 抗PR3 ANCA；(d) 抗线粒体；(e) 抗组织转谷氨酰胺酶IgA。
::: solution
(a) 局限性皮肤型系统性硬化症。(b) 重症肌无力（MuSK亚型）。(c) 肉芽肿性多血管炎。(d) 原发性胆汁性胆管炎。(e) 乳糜泻。
:::
:::

::: exercise 阴性预测值 {level=1 check="0.98*0.87/(0.98*0.87 + 0.02*0.02)"}
验前概率2%、灵敏度98%、特异度87%时，计算ANA阴性对SLE的阴性预测值（未取整的小数）。
::: solution
真阴性$= 0.98 \times 0.87 = 0.8526$；假阴性$= 0.02 \times 0.02 = 0.0004$。NPV $= 0.8526/(0.8526 + 0.0004) \approx 0.99953$。在低概率患者中ANA阴性几乎可以排除SLE，这就是为什么ANA适合用来排除而非确立诊断。
:::
:::

::: exercise 令人误以为放心的乳糜泻检测 {level=2}
一名12岁男孩生长不良、缺铁，抗组织转谷氨酰胺酶IgA阴性。他的总IgA测不出。解释为什么不能依赖这一抗体结果，以及应该怎么做。
::: solution
抗tTG IgA是一种IgA抗体。选择性IgA缺乏者根本不能产生IgA，因此无论是否患乳糜泻，该检测都会是阴性。IgA缺乏本身与乳糜泻相关（在乳糜泻患者中约比普通人群常见十倍），所以他的风险只会更高。这就是每次做乳糜泻IgA血清学检测时都要测总IgA的原因。应改做基于IgG的检测（IgG抗tTG、IgG抗脱酰胺麦胶蛋白肽或IgG抗肌内膜抗体），如果怀疑仍在，应在他仍食用麸质时转诊做十二指肠活检。
:::
:::

::: exercise 妊娠期格雷夫斯病 {level=2}
一名31岁女性4年前因格雷夫斯病接受放射性碘治疗，现服用左甲状腺素。她已妊娠20周。为什么她的婴儿仍有患甲状腺病的风险？哪项检查能回答这个问题？
::: solution
放射性碘破坏了她的甲状腺组织，但并未清除产生**TSH受体抗体**（TRAb）的B细胞克隆和长寿浆细胞。TRAb水平可在多年内保持较高，放射性碘治疗后尤其如此。这些是IgG抗体，经FcRn转运穿过胎盘，主要在妊娠后半期。它们可以刺激胎儿甲状腺，引起胎儿和新生儿甲状腺毒症，尽管母亲本人甲减并在服用左甲状腺素。孕期测定母体TRAb可识别这一风险；若升高，应监测胎儿（心率、生长、甲状腺肿）并在出生后评估新生儿。新生儿疾病是一过性的，随着母体IgG在数周至数月内被清除而消退。
:::
:::

::: exercise 类风湿关节炎计分 {level=2}
按2010年ACR/EULAR标准，关节受累（0至5分）、血清学（0至3分）、急性期反应物（0至1分）和症状持续时间（0至1分）分别计分。一名患者有12个肿胀压痛关节（包括小关节，5分），抗CCP高滴度阳性（3分），CRP和ESR正常（0分），症状持续4周（0分）。得分是多少？是否分类为类风湿关节炎？这是否意味着她没有类风湿关节炎？
::: solution
得分为$5 + 3 + 0 + 0 = 8$，达到10分中至少6分，因此该患者被分类为类风湿关节炎。分类标准是为研究和早期识别设计的；得分低于6分的患者仍可由风湿科医生根据临床诊断为类风湿关节炎，并应随访，因为她以后可能符合标准。早期转诊专科很重要，因为在起病最初几个月内治疗可改善结局。
:::
:::

::: exercise 疾病在家族中聚集 {level=3}
一名9岁女孩患1型糖尿病。她父亲患格雷夫斯病，姑姑患恶性贫血，哥哥患白癜风。解释这些疾病为何在家族中聚集、为何它们大多累及不同器官，以及作为常规管理的一部分，女孩应接受哪些筛查。
::: solution
**聚集。**器官特异性自身免疫病有共同的遗传易感性，包括HLA单倍型（尤其是含DR3/DQ2和DR4/DQ8者）以及改变免疫调节的非HLA变异，如*PTPN22*和*CTLA4*变异。这些基因提高的是打破耐受的总体倾向，而不是决定哪个器官被攻击。攻击哪个器官取决于其他因素，包括提呈特定器官肽的特定HLA等位基因、器官特异性基因（如影响胸腺中胰岛素表达的变异）、环境触发因素和偶然性。

**女孩的筛查。**作为常规糖尿病管理的一部分，她应在诊断时及之后定期检查甲状腺功能（常加测抗TPO），并在诊断时及出现症状时检查乳糜泻血清学（抗tTG IgA加总IgA）。临床医生应警惕艾迪生病的表现（不明原因的低血糖、胰岛素需要量下降、色素沉着、嗜盐）和恶性贫血，尽管这些在儿童期罕见得多。如果模式不寻常或起病很早，应考虑APS-1或IPEX等罕见单基因综合征。
:::
:::

::: exercise 解读低补体 {level=3}
一名35岁已知SLE女性肌酐上升，新出现蛋白尿。她的抗dsDNA翻倍，C3和C4降低。一位同事说低补体说明她有遗传性补体缺乏。评价这一说法，并解释如何区分。
::: solution
这一说法很可能是错误的。在活动性SLE，尤其是肾炎中，免疫复合物激活经典途径并**消耗**C3和C4，因此低水平是疾病活动的标志。抗dsDNA升高和新出现的肾脏受累支持一次伴补体消耗的发作。遗传性缺乏则不同：C1q、C2或C4的纯合缺乏使单一受累成分缺如或极低，在疾病静止时仍持续存在，且CH50缺如。C4基因拷贝数变异导致的部分C4缺乏很常见，可与消耗并存。区分方法：疾病控制后复查C3和C4（消耗会恢复正常，遗传性缺乏则持续）；测定CH50和单个成分；怀疑C1q缺乏时直接测定C1q。SLE起病早、家族史明显和皮肤病变严重时，应怀疑遗传性早期成分缺乏。
:::
:::
