在大多数时候，免疫系统的武器瞄准得很准：对准微生物，用力恰到好处，清除感染而几乎不造成伤害。**超敏反应**指的是造成与任何益处都不相称的组织损伤的免疫应答。其靶标可能是无害的环境物质（花粉、花生、镍）、药物、输入的血液或自身，而造成损伤的正是前几章所述的那些效应机制。

1963年，Philip Gell和Robin Coombs按免疫机制把这些反应分为四型。这一分类历史悠久且并不完美，许多真实疾病混合了几种类型。但它仍然有用，因为每一型都有特征性的时间进程、特征性的检查和特征性的治疗。只要能判断是哪种机制在起作用，通常就能预测反应发展多快、哪项检查能确诊、哪种药物有效。

本章描述四种类型，其中Ⅰ型反应和严重过敏反应占最大篇幅，因为它们常见，并可在数分钟内致死。

::: definition Gell和Coombs分类 {#def-types}
- **Ⅰ型（速发型，IgE介导）**：变应原交联结合在肥大细胞和嗜碱性粒细胞上的IgE，这些细胞在数分钟内释放组胺和其他介质。例如：变应性鼻炎、过敏性哮喘、食物过敏、严重过敏反应。
- **Ⅱ型（抗体介导的细胞毒型）**：IgG或IgM结合细胞表面或细胞外基质中的抗原，导致细胞破坏或受体功能改变。例如：ABO血型不合输血、自身免疫性溶血性贫血、Goodpasture病、重症肌无力、格雷夫斯病。
- **Ⅲ型（免疫复合物型）**：可溶性抗原–抗体复合物沉积于血管壁、肾小球和关节，激活补体。例如：血清病、Arthus反应、链球菌感染后肾小球肾炎、狼疮性肾炎。
- **Ⅳ型（迟发型，T细胞介导）**：致敏T细胞释放细胞因子或杀伤细胞，在接触后24至72小时达峰。例如：变应性接触性皮炎、结核菌素皮肤试验、许多药疹、肉芽肿性炎症。
:::

Ⅰ至Ⅲ型由抗体介导，可通过血清在动物之间转移。Ⅳ型由T细胞介导，只能通过细胞转移。

## Ⅰ型：速发型超敏反应

### 致敏与效应阶段

Ⅰ型反应分为两个阶段。

**致敏。**首次接触变应原时，树突状细胞将其提呈给初始CD4 T细胞，在易过敏者中后者分化为Th2细胞。Th2细胞提供IL-4和IL-13，使B细胞转换产生**IgE**。IgE结合于肥大细胞和嗜碱性粒细胞上的高亲和力受体**FcεRI**，并在那里停留数周至数月。此时这个人已被致敏，但没有症状。

**效应阶段。**再次接触时，变应原结合并**交联**肥大细胞表面的IgE分子。激活细胞的是交联，而不仅仅是结合。肥大细胞在数分钟内释放三组介质。

::: definition 肥大细胞介质 {#def-mast}
- **预先合成的介质**，储存在颗粒中，在数秒至数分钟内释放：**组胺**，引起血管扩张、血管通透性增加、瘙痒和支气管收缩；**类胰蛋白酶**，一种用作肥大细胞活化实验室标志物的蛋白酶；肝素；以及TNF。
- **新合成的脂类介质**，在数分钟内由膜花生四烯酸生成：**半胱氨酰白三烯**（LTC4、LTD4、LTE4），强效支气管收缩剂；**前列腺素D2**；以及**血小板活化因子**。
- **细胞因子和趋化因子**，在数小时内转录：IL-4、IL-5、IL-13等，招募嗜酸性粒细胞、嗜碱性粒细胞和Th2细胞，在接触后4至12小时引起**迟发相反应**。
:::

迟发相解释了为什么哮喘患者接触变应原后在第一个小时好转、数小时后又再次加重，以及为什么变应性鼻炎在反复接触后会变成持续性鼻塞。

**特应性**是对常见环境变应原产生IgE应答的遗传倾向。它是湿疹、食物过敏、哮喘和变应性鼻炎这一“特应性进程”的基础。遗传因素包括皮肤屏障蛋白丝聚蛋白的变异，使变应原得以穿过皮肤并有利于致敏；环境因素包括生命早期微生物接触减少。

并非所有肥大细胞反应都需要IgE。某些药物，包括阿片类、万古霉素、神经肌肉阻滞剂和放射造影剂，可直接激活肥大细胞，例如通过受体MRGPRX2。非甾体抗炎药可在易感者中通过抑制环氧合酶1、使花生四烯酸代谢转向白三烯而触发反应。这些反应看起来可能与IgE介导的过敏完全一样，但皮肤试验和特异性IgE为阴性。

### 严重过敏反应

::: definition 严重过敏反应 {#def-anaphylaxis}
**严重过敏反应**是一种严重的、危及生命的全身性超敏反应。其特征是迅速出现**气道**（喉头水肿、喘鸣、声音嘶哑）、**呼吸**（支气管痉挛、喘息、低氧血症）和/或**循环**（低血压、虚脱）问题，通常但并不总是伴有荨麻疹、潮红或血管性水肿等皮肤或黏膜改变。大多数病例由IgE介导，但非IgE的肥大细胞活化也会产生相同的临床表现。
:::

最常见的诱因在儿童和年轻成人中是食物（尤其是花生、坚果、牛奶、鸡蛋、鱼和贝类），在年长成人中是药物（尤其是抗生素、非甾体抗炎药和麻醉用药），以及昆虫毒液（黄蜂和蜜蜂）。许多成人找不到诱因。部分病例没有皮肤表现，尤其是以低血压为主时，因此没有皮肤表现并不能排除严重过敏反应。

::: theorem 为什么用肾上腺素治疗 {#thm-adrenaline}
肾上腺素是严重过敏反应的一线药物，因为它能对抗肥大细胞介质的每一种危及生命的效应，还能减少介质的进一步释放：

- **α1肾上腺素能**效应引起血管收缩，升高血压并减轻包括喉头水肿在内的黏膜水肿；
- **β1**效应增强心肌收缩力和心率；
- **β2**效应松弛支气管平滑肌，并**抑制**肥大细胞的进一步脱颗粒。

抗组胺药只阻断H1受体，起效慢，对低血压或白三烯引起的支气管痉挛毫无作用；糖皮质激素需要数小时才起效。两者都不能替代肾上腺素。
:::

英国的指南是英国复苏委员会（Resuscitation Council UK）的《严重过敏反应的紧急处理》（2021年）。其原则概括如下，实际操作细节见[[emergency-critical-care/anaphylaxis]]：

- 用ABCDE方法识别严重过敏反应，并呼叫帮助。
- 一旦怀疑严重过敏反应，立即在大腿前外侧**肌内注射肾上腺素**；剂量取决于年龄并依指南确定（成人标准剂量为500微克，即1 mg/mL溶液0.5 mL）。如果气道、呼吸或循环问题持续，5分钟后重复。
- 让患者平卧（呼吸困难时可坐位），不要让其站立或行走，因为体位突然改变可引起心脏骤停。
- 给予高流量吸氧，休克时静脉快速补液。
- 如果两次肌内注射肾上腺素后问题仍持续（**难治性严重过敏反应**），尽早寻求专家帮助，使用肾上腺素静脉输注。
- 抗组胺药用于病情稳定后的皮肤症状；紧急处理中已不再推荐常规使用糖皮质激素。

紧急处理之后，患者需要一段观察期（在英格兰和威尔士，2026年的NICE指南NG258采纳了复苏委员会关于观察时长的风险分层方法），出院前获得**两支肾上腺素自动注射器**并接受培训，得到书面资料，并转诊至过敏专科以明确诱因。

::: example 餐馆中的虚脱 {#ex-anaphylaxis}
一名已知花生过敏的22岁男性在餐馆吃了咖喱10分钟后虚脱。他全身荨麻疹，嘴唇肿胀，声音嘶哑，可闻及喘息。脉搏130次/分，血压70/40 mmHg。解释细胞层面发生了什么，并概述紧急处理。
::: solution
**机制。**从肠道吸收的花生蛋白进入血液，交联了全身肥大细胞和血液嗜碱性粒细胞上的花生特异性IgE。组胺引起血管扩张和毛细血管渗漏，产生低血压和荨麻疹；喉部渗漏引起声音嘶哑；组胺和白三烯使支气管收缩。液体渗入组织和血管扩张共同减少静脉回流，于是心输出量下降。

**紧急处理。**这是伴气道、呼吸和循环问题的严重过敏反应。呼叫帮助。立即在大腿前外侧肌内注射肾上腺素（英国复苏委员会指南中成人为500微克），若无改善5分钟后重复。若呼吸允许，让他平卧并抬高双腿，不要让他坐起或站立。给予高流量吸氧，建立静脉通路并快速输注晶体液。持续监护。若两次注射后仍不稳定，呼叫重症医学团队使用肾上腺素输注。在不延误治疗的前提下，按时采血检测肥大细胞类胰蛋白酶。

**之后。**他需要一段观察期、两支肾上腺素自动注射器及培训、一份过敏行动计划，并在过敏专科复诊。
:::
:::

### 测定肥大细胞活化：类胰蛋白酶

严重过敏反应时血清**类胰蛋白酶**升高，因为它从肥大细胞颗粒中释放。它在症状出现后约1至2小时达峰，以约2小时的半衰期下降，因此6至8小时后可能已恢复正常。为此英国复苏委员会建议最多采集三次定时样本：

1. 开始治疗后尽快采集（不得延误治疗）；
2. 理想情况下在症状出现后1至2小时采集，最迟不超过4小时；
3. 在完全恢复至少24小时后或在过敏门诊采集**基线**样本。

基线很重要，因为不同人的类胰蛋白酶水平不同。有些人基线天生偏高，例如遗传了额外的类胰蛋白酶基因（*TPSAB1*）拷贝；基线升高也可能提示系统性肥大细胞增多症等肥大细胞疾病。一项国际共识提出，急性期升高超过**基线的120%加2 µg/L**提示有临床意义的肥大细胞活化：

$$
\text{阈值} = 1.2 \times \text{基线} + 2\ \mu\text{g/L}.
$$ {#eq-tryptase}

::: example 解读类胰蛋白酶 {#ex-tryptase}
一名46岁女性在静脉注射阿莫西林克拉维酸10分钟后发生低血压反应。起病后90分钟类胰蛋白酶为15 µg/L。6周后测得的基线类胰蛋白酶为11 µg/L。是否发生了有意义的肥大细胞活化？基线提示什么？
::: solution
按共识公式，阈值为$1.2 \times 11 + 2 = 13.2 + 2 = 15.2$ µg/L。她的急性期值15 µg/L刚好**低于**这一阈值，因此尽管15 µg/L的绝对值高于许多实验室的参考范围，类胰蛋白酶结果本身并不能证实肥大细胞活化。

解读必须结合临床。静脉注射抗生素后数分钟内发生低血压反应高度提示严重过敏反应，类胰蛋白酶正常或处于临界值并不能排除它：有些反应（尤其是食物诱发的）类胰蛋白酶升高较少，采样时间也影响结果。她的**基线11 µg/L**处于通常参考范围的上端（常引用的上限约为11.4 µg/L，因检测方法而异）。如此高的基线提示可能存在遗传性α-类胰蛋白酶血症或克隆性肥大细胞疾病。这些情况与更严重的反应相关，过敏专科会考虑进一步检查。
:::
:::

### 诊断过敏

**致敏并不等于过敏。**皮肤点刺试验或特异性IgE阳性只说明存在IgE。许多检测阳性的人吃这种食物或用这种药物毫无问题。因此检查必须针对临床病史提出的问题来选择。

- **皮肤点刺试验**：把一滴变应原引入表皮；15分钟内出现风团和红晕提示皮肤肥大细胞上有IgE。检测前必须停用抗组胺药。
- 血清**特异性IgE**：在无法做皮肤试验时（广泛湿疹、正在使用抗组胺药）有用。**组分解析诊断**测定针对单个蛋白的IgE；例如，针对花生储存蛋白Ara h 2的IgE预测临床花生过敏的能力远好于针对花生全提取物的IgE，后者常反映与花粉蛋白的交叉反应。
- 在监护下进行**口服食物激发**或**药物激发**：这是参考标准，用于病史和检查仍存疑问时。

在英国约十分之一的人带有**青霉素过敏**标签，其中大多数经正规检测后被证明并不过敏。这一标签导致使用更广谱的抗生素、更多的艰难梭菌和MRSA感染以及更差的结局，因此通过风险评估和直接口服激发来“去标签”现已成为抗菌药物管理的一部分。

### 改变应答的治疗

**变应原免疫治疗**通过注射或舌下途径给予逐渐递增、然后维持剂量的变应原，疗程约3年。它使应答从Th2转向产生IL-10的调节性T细胞，并诱导变应原特异性**IgG4**，与IgE竞争变应原（“封闭抗体”）。它对毒液过敏和花粉所致鼻炎非常有效。

**奥马珠单抗**（omalizumab）是抗IgE单克隆抗体，阻止IgE与FcεRI结合，并降低肥大细胞上FcεRI的表达。它用于重症过敏性哮喘和慢性自发性荨麻疹。

## Ⅱ型：针对细胞和基质的抗体

::: definition Ⅱ型机制 {#def-type2}
在Ⅱ型超敏反应中，IgG或IgM结合作为细胞表面或细胞外基质一部分的抗原。随后通过三种途径之一造成损伤：

1. **补体介导的溶解**，发生在血管内（血管内溶血），见于能高效固定补体的抗体，如IgM抗A和抗B。
2. **调理和吞噬**：IgG或C3b包被的细胞主要在脾脏和肝脏中被巨噬细胞清除（血管外），如温抗体型自身免疫性溶血性贫血和免疫性血小板减少症。
3. 抗体结合基质并激活补体和带Fc受体的细胞时，在局部引起**炎症**，如抗肾小球基底膜病。

有一亚组抗体并不破坏细胞，而是**改变受体功能**：刺激受体（格雷夫斯病中的促甲状腺激素受体抗体），或阻断并耗竭受体（重症肌无力中的乙酰胆碱受体抗体）。有些分类将其称为Ⅴ型。
:::

**直接抗球蛋白试验**（DAT，直接Coombs试验）显示患者红细胞在体内是否被IgG或补体包被。抗球蛋白试剂交联被包被的细胞，使其凝集。它在自身免疫性溶血性贫血、新生儿溶血病和溶血性输血反应中呈阳性。

::: example 输错的一袋血 {#ex-transfusion}
一名74岁O型血女性被输入了一袋原本给另一患者的A型红细胞。10分钟内她出现发热、寒战、腰背部和输注部位疼痛、低血压以及深红色尿。解释机制和紧急措施。
::: solution
**机制。**O型血的人天然产生**IgM抗A和抗B**抗体，可能是对肠道细菌上类似碳水化合物结构的应答。输入的A型红细胞立即被IgM抗A结合，后者非常高效地激活补体经典途径。攻膜复合物在**血管内**溶解红细胞（血管内溶血）。游离血红蛋白出现在血浆和尿液中。C3a、C5a和释放的炎症细胞因子引起发热、寒战和低血压，反应可进展为弥散性血管内凝血和急性肾损伤。

**紧急措施。**立即停止输血，用生理盐水保持静脉通路。复苏（ABCDE），核对患者身份与血袋，通知输血科，后者还会核查这袋血原本的受血者是否面临输错血的风险。送检样本做复查血型和交叉配血、DAT、血常规、溶血指标、凝血筛查、肾功能和尿液分析。维持尿量，寻求上级医生和血液科的帮助。该事件经医院系统上报，并报告英国血液警戒系统SHOT（Serious Hazards of Transfusion）。

ABO血型不合输血几乎总是由身份识别错误造成，这就是床旁身份核对比任何实验室检查都重要的原因。见[[blood/transfusion]]。
:::
:::

其他Ⅱ型的例子包括**胎儿和新生儿溶血病**（母体抗D IgG穿过胎盘）、**药物诱导的免疫性溶血和血小板减少**、**抗肾小球基底膜病**（针对肾小球和肺泡基底膜Ⅳ型胶原α3链的抗体，引起急进性肾小球肾炎和肺出血），以及**寻常型天疱疮**（针对桥粒芯糖蛋白3的抗体使角质形成细胞分离）。这些疾病见[[immunology/autoimmunity]]。

## Ⅲ型：免疫复合物病

抗体时时刻刻都在结合可溶性抗原，形成的免疫复合物通常由补体和肝脾中的吞噬细胞无害地清除。当复合物大量形成、其大小不易被清除（在轻度抗原过剩时形成的小复合物），或清除失败（如补体缺陷）时，就会致病。复合物沉积在血液以高压或湍流方式滤过的部位：**肾小球、小血管壁、关节和脉络丛**。它们在那里激活补体，并通过Fc受体和C5a吸引中性粒细胞，引起血管炎、肾小球肾炎和关节炎。

::: theorem 免疫复合物病的特点 {#thm-type3}
免疫复合物病具有可识别的共同临床和实验室模式：

- 病变位于复合物沉积处：**肾小球肾炎、小血管炎（常为可触及性紫癜）、关节炎或关节痛**，以及发热；
- **补体被消耗**，因此疾病活动时血清C3和C4常降低；
- 活检免疫荧光显示免疫球蛋白和补体呈**颗粒状（“团块状”）沉积**，不同于Ⅱ型抗肾小球基底膜病平滑的**线性**沉积。
:::

::: proof
这一模式由机制决定。由于抗原是可溶的并在循环中，复合物可滞留于任何血管床，但优先被截留在滤过和湍流最强的部位。沉积后，它们经经典途径固定补体，消耗C4和C3，产生的C5a招募中性粒细胞，后者的酶损伤血管壁。沉积物呈离散的团块，因为复合物以颗粒形式沉积；而抗体结合均匀分布于基底膜的抗原时，则形成连续的线条。
:::

**血清病**是经典的全身性例子。20世纪初在接受马抗白喉毒素血清的儿童中被描述。大剂量外来蛋白注入后约1至2周，机体产生抗体，而此时仍有大量抗原在循环。复合物形成，引起发热、皮疹、关节痛、淋巴结肿大，有时出现蛋白尿。随着抗原被清除而自愈。现代的病因包括抗胸腺细胞球蛋白和其他动物来源的抗血清，如某些抗蛇毒血清。某些药物会引起临床上类似的“血清病样反应”，尤其在儿童中。

**Arthus反应**是局部的对应形式：给已有高水平相应IgG的人皮内注射抗原，会在血管壁局部形成复合物，4至12小时后出现疼痛性肿胀，有时坏死。过于频繁地加强接种含破伤风或白喉成分的疫苗可引起这种反应。

其他免疫复合物病包括**链球菌感染后肾小球肾炎**、**狼疮性肾炎**、**IgA血管炎**（过敏性紫癜）、**冷球蛋白血症性血管炎**（常与丙型肝炎感染有关）以及感染性心内膜炎的肾小球肾炎。

## Ⅳ型：迟发型超敏反应

Ⅳ型反应由T细胞而非抗体介导。由于需要在组织中招募和激活抗原特异性T细胞，再次接触后需要**24至72小时**才发生。

::: definition 迟发型超敏反应 {#def-type4}
**Ⅳ型超敏反应**是抗原特异性T细胞造成的组织损伤。CD4 T细胞（主要是Th1，有时是Th2或Th17）释放细胞因子，招募并激活巨噬细胞、嗜酸性粒细胞或中性粒细胞；CD8 T细胞直接杀伤细胞。反应在24至72小时内形成，不能通过血清转移。
:::

重要的例子：

- **变应性接触性皮炎。**镍、铬酸盐、香料、防腐剂、染发剂成分以及毒葛毒素漆酚等小分子活性化学物（半抗原）渗入皮肤并结合自身蛋白。朗格汉斯细胞和真皮树突状细胞把修饰后的蛋白带到淋巴结，使T细胞致敏。再次接触时，T细胞在接触部位引起瘙痒性湿疹样反应。诊断检查是**斑贴试验**：把可疑变应原封闭贴敷48小时，约在48小时和96小时判读。
- **结核菌素皮肤试验。**给既往接触过分枝杆菌或接种过BCG的人皮内注射纯化蛋白衍生物，硬结在48至72小时达峰。
- **肉芽肿性炎症**，如结核病、麻风、结节病和克罗恩病，是一种慢性Th1驱动的反应（见[[immunology/adaptive-responses]]）。
- **迟发型药物反应**，从轻度斑丘疹到伴嗜酸性粒细胞增多和系统症状的药物反应（DRESS）以及Stevens–Johnson综合征/中毒性表皮坏死松解症等严重反应。在SJS/TEN中，细胞毒性CD8 T细胞和NK细胞杀伤角质形成细胞。其中一些与HLA等位基因强相关（见[[immunology/antigen-recognition]]）。
- **乳糜泻**有核心的T细胞成分，由麦胶特异性CD4 T细胞驱动损伤，但它也有自身抗体。

::: example 美发师的双手 {#ex-contact}
一名27岁美发师双手背和指间出现瘙痒、脱屑、皲裂的皮炎已6个月。度假时好转，回到工作后1至2天内加重。对常见吸入性变应原的皮肤点刺试验阴性。解释可能的机制、为什么皮肤点刺试验没有帮助，以及如何找出病因。
::: solution
**机制。**这一模式提示**变应性接触性皮炎**，属于Ⅳ型反应。工作中使用的某种小分子活性化学物——最可能是对苯二胺或相关的染发剂成分，或洗发水中的防腐剂或香料——作为半抗原：它渗入受损的皮肤，结合自身蛋白，由朗格汉斯细胞带到淋巴结，使T细胞致敏。每次再接触都会把致敏T细胞带回皮肤，其细胞因子在24至72小时内引起湿疹样炎症，与回到工作后的延迟相符。湿作业和洗涤剂（刺激性接触性皮炎）常同时存在，并帮助半抗原进入皮肤。

**为什么皮肤点刺试验没有帮助。**皮肤点刺试验检测肥大细胞上的IgE，这是在15分钟内出现反应的Ⅰ型机制。它对T细胞致敏毫无提示。

**找出病因。****斑贴试验**：把标准系列加上美发系列变应原封闭贴敷于背部48小时，约在第2天和第4天判读。阳性结果是相应变应原部位出现湿疹样反应。处理包括避免接触（选用适合该化学物的手套、改变工作方式，有时需调换岗位）、使用润肤剂和外用糖皮质激素；职业性皮炎还涉及就业和报告方面的问题。
:::
:::

:::warning
从接触到反应的时间是判断机制最有用的线索之一，却常被误用。在阿莫西林疗程第7天出现的皮疹不是速发型（IgE）反应；它通常是迟发型T细胞反应，今后发生严重过敏反应的问题与之完全不同。传染性单核细胞增多症（EB病毒感染）期间使用阿莫西林的儿童常出现广泛皮疹，这并不意味着终身青霉素过敏。应准确记录发生时间、皮疹类型和其他特征，而不是简单地写上“青霉素过敏”。
:::

## 四型综合比较

| | Ⅰ型 | Ⅱ型 | Ⅲ型 | Ⅳ型 |
|---|---|---|---|---|
| 介导者 | IgE、肥大细胞 | 针对细胞或基质的IgG或IgM | IgG–抗原复合物、补体 | T细胞 |
| 接触后发生时间 | 数分钟（迟发相4–12 h） | 数分钟至数天 | 数小时（Arthus）至1–2周（血清病） | 24–72小时 |
| 原型 | 严重过敏反应 | ABO输血反应 | 血清病 | 接触性皮炎 |
| 关键检查 | 皮肤点刺试验、特异性IgE、类胰蛋白酶 | 直接抗球蛋白试验、特异性自身抗体 | C3/C4、活检免疫荧光 | 斑贴试验 |

输血反应同时体现了几种类型。对ABO不合血液的**急性溶血**反应属Ⅱ型。输血后5至10天的**迟发性溶血**反应是对受血者此前已被致敏的次要红细胞抗原的再次（回忆）抗体应答。伴荨麻疹的**过敏**反应属Ⅰ型。罕见的严重过敏性反应发生在有抗IgA抗体的IgA缺乏者中。**输血相关移植物抗宿主病**是供者T细胞攻击免疫功能低下的受血者，属Ⅳ型机制，通过对高危患者的血液成分进行辐照来预防。

::: quiz
一名30岁女性开始接受兔抗胸腺细胞球蛋白治疗10天后，出现发热、荨麻疹样皮疹、关节痛和轻度蛋白尿。她的C3和C4降低。最可能是哪种类型的超敏反应？
- [ ] Ⅰ型
- [ ] Ⅱ型
- [x] Ⅲ型
- [ ] Ⅳ型
::: solution
大剂量外来蛋白注入后1至2周出现发热、皮疹、关节症状和蛋白尿，伴补体消耗，这是**血清病**，即典型的Ⅲ型免疫复合物病。这种延迟反映了在兔蛋白仍大量循环时产生针对它的抗体所需的时间。荨麻疹并不使其成为Ⅰ型反应；荨麻疹样皮疹在血清病中很常见。
:::
:::

::: history
1902年，里歇（Charles Richet）和波蒂埃（Paul Portier）试图使狗对海葵毒素产生免疫。几周后再给予的一小剂量在数分钟内使狗死亡。里歇将这一现象称为*anaphylaxis*（“反保护”），并获得1913年诺贝尔奖。1906年，儿科医生皮尔凯（Clemens von Pirquet）创造了*allergy*（变态反应）一词来表示反应性的改变，并与Béla Schick描述了接受马抗血清治疗的儿童所患的血清病。Maurice Arthus于1903年描述了以他名字命名的局部反应。

速发型过敏的原因一直是个谜，直到1966年，石坂公成（Kimishige Ishizaka）和石坂照子（Teruko Ishizaka）鉴定出一类新的抗体IgE，即引起过敏的“反应素”；瑞典的Gunnar Johansson和Hans Bennich研究组也独立地在一例骨髓瘤中发现了同一种蛋白。Philip Gell和Robin Coombs——后者曾于1945年与Arthur Mourant和Rob Race一起建立了抗球蛋白试验——在1963年发表了四型分类。
:::

## 后续内容

针对自身的Ⅱ型和Ⅲ型机制是[[immunology/autoimmunity]]中自身免疫病的基础。严重过敏反应的紧急处理见[[emergency-critical-care/anaphylaxis]]，药物过敏见[[pharmacology/adverse-reactions]]，常与之相伴的哮喘见[[respiratory/asthma-copd]]。

::: summary
- 超敏反应是免疫介导的组织损伤。Gell和Coombs按机制将其分为四型：Ⅰ型（IgE、肥大细胞）、Ⅱ型（针对细胞或基质的抗体）、Ⅲ型（免疫复合物）和Ⅳ型（T细胞）。
- Ⅰ型需要事先致敏（Th2、FcεRI上的IgE）。IgE交联先释放组胺和类胰蛋白酶，然后是白三烯和前列腺素，再后是引起迟发相的细胞因子。
- 严重过敏反应是迅速出现的、危及生命的气道、呼吸或循环问题。肌内注射肾上腺素是一线治疗，必要时5分钟后重复；抗组胺药和激素不能替代。
- 类胰蛋白酶在1至2小时达峰，半衰期约2小时；需要定时样本和基线样本，升高超过$1.2 \times \text{基线} + 2$ µg/L提示有意义的肥大细胞活化。
- 致敏不等于过敏。检查回答病史提出的问题；激发试验是参考标准。大多数青霉素过敏标签是错误的。
- Ⅱ型反应引起血管内溶解、脾脏清除或受体刺激/阻断；直接抗球蛋白试验检测红细胞上的抗体。
- Ⅲ型反应使免疫复合物沉积于肾小球、血管和关节，消耗补体，免疫荧光呈颗粒状；血清病在外来蛋白注入后1至2周出现。
- Ⅳ型反应由T细胞介导，在24至72小时达峰：接触性皮炎（斑贴试验）、结核菌素反应、肉芽肿和迟发型药疹。
:::

## 习题

::: exercise 类胰蛋白酶阈值 {level=1 check="1.2*6.5 + 2"}
某患者的基线类胰蛋白酶为6.5 µg/L。按共识公式，急性期类胰蛋白酶高于多少（µg/L）时可认为发生了有意义的肥大细胞活化？
::: solution
$1.2 \times 6.5 + 2 = 7.8 + 2 = 9.8$ µg/L。急性期值高于9.8 µg/L即符合标准，尽管许多实验室的参考上限约为11 µg/L。这就是基线样本有用的原因：一个处于“正常范围”内的数值，对这个人来说仍可能是有意义的升高。
:::
:::

::: exercise 对反应分类 {level=1}
说出下列各项的Gell和Coombs分型：(a) 戴新手表2天后在表带下出现瘙痒性湿疹；(b) 被黄蜂蜇伤5分钟后出现喘息和荨麻疹；(c) 开始某种药物后出现DAT阳性的溶血性贫血；(d) 链球菌咽炎2周后出现伴颗粒状IgG和C3沉积的肾小球肾炎。
::: solution
(a) Ⅳ型（镍接触性皮炎）。(b) Ⅰ型。(c) Ⅱ型。(d) Ⅲ型（链球菌感染后肾小球肾炎）。
:::
:::

::: exercise 类胰蛋白酶半衰期 {level=1 check="40*0.5^3"}
类胰蛋白酶峰值为40 µg/L。假设高于基线的部分以2小时半衰期下降且基线可忽略不计，峰值后6小时类胰蛋白酶应为多少µg/L？
::: solution
6小时是3个半衰期，因此$40 \times (1/2)^3 = 40/8 = 5$ µg/L。这么晚采集的样本很可能落在正常范围内，这就是第二份样本理想情况下应在症状出现后1至2小时、最迟不超过4小时采集的原因。
:::
:::

::: exercise 为什么抗组胺药在严重过敏反应中无效 {level=2}
一名低年资医生给一名伴低血压的严重过敏反应患者首先静脉注射了氯苯那敏。参照所涉及的介质，解释为什么这样做是不够的。
::: solution
抗组胺药只阻断组胺H1受体。严重过敏反应中的低血压不仅由组胺引起，还由血小板活化因子、白三烯、前列腺素和其他引起血管扩张和毛细血管渗漏的介质引起；支气管痉挛主要由半胱氨酰白三烯驱动。抗组胺药起效也需要时间，并且不能阻止肥大细胞的进一步脱颗粒。需要肌内注射肾上腺素，因为其α1效应逆转血管扩张和黏膜水肿，β1效应支持心脏，β2效应松弛支气管平滑肌并抑制进一步的介质释放。延误给予肾上腺素与致死结局相关。病情稳定后可用抗组胺药处理皮肤症状。
:::
:::

::: exercise 线性还是颗粒状？ {level=2}
一名吸烟的24岁男性出现咯血和肌酐迅速升高。肾活检显示新月体性肾小球肾炎，IgG沿肾小球基底膜呈平滑线性分布。解释机制、为什么累及肺，以及它与狼疮性肾炎有何不同。
::: solution
沿基底膜的线性IgG提示**抗肾小球基底膜（Goodpasture）病**，属于Ⅱ型反应。自身抗体结合Ⅳ型胶原α3链的非胶原结构域，该结构域沿肾小球基底膜均匀分布，因此免疫荧光呈连续线条。同一抗原也存在于肺泡基底膜；它通常是隐蔽的，但吸烟或感染造成的损伤使其暴露，导致肺出血。狼疮性肾炎是Ⅲ型疾病：免疫复合物以离散颗粒形式沉积，产生IgG、IgA、IgM、C3和C1q的颗粒状沉积，并伴补体降低。抗肾小球基底膜病是内科急症，用血浆置换清除抗体并联合免疫抑制治疗。
:::
:::

::: exercise 迟发的喘息 {level=2}
一名患哮喘和猫过敏的9岁男孩去拜访一位养了两只猫的朋友。他在20分钟内出现打喷嚏和轻度喘息，使用缓解吸入剂后缓解。到睡前他一切正常，但在拜访9小时后的凌晨3点因喘息加重而醒来。解释这两次发作。
::: solution
第一次发作是Ⅰ型反应的**速发相**：猫变应原（Fel d 1）交联其气道肥大细胞上的IgE，后者在数分钟内释放组胺和白三烯，引起对β2激动剂有反应的支气管收缩。第二次是**迟发相反应**：肥大细胞在数小时内释放的细胞因子（IL-4、IL-5、IL-13）和趋化因子把嗜酸性粒细胞、嗜碱性粒细胞和Th2细胞招募到气道，在4至12小时后引起炎症、水肿和黏液，支气管再次收缩。迟发相单用支气管扩张剂效果差，是吸入性糖皮质激素的作用靶点。它提醒我们，过敏接触后迅速好转的人之后仍可能恶化。
:::
:::

::: exercise 应用类胰蛋白酶规则 {level=3}
两名患者在麻醉期间发生反应。患者A：基线4 µg/L，急性期9 µg/L。患者B：基线14 µg/L，急性期17 µg/L。对每人应用共识标准，并讨论患者B基线的临床意义。
::: solution
**患者A。**阈值$= 1.2 \times 4 + 2 = 6.8$ µg/L。急性期值9 µg/L超过阈值，因此发生了有意义的肥大细胞活化，尽管9 µg/L落在许多参考范围之内。

**患者B。**阈值$= 1.2 \times 14 + 2 = 18.8$ µg/L。急性期值17 µg/L未达到阈值，因此类胰蛋白酶不能证实肥大细胞活化；是否为严重过敏反应仍由临床表现决定。基线14 µg/L是升高的。原因包括遗传性α-类胰蛋白酶血症（*TPSAB1*额外拷贝）、系统性肥大细胞增多症和其他髓系肿瘤，以及慢性肾脏病。基线类胰蛋白酶升高和肥大细胞增多症与更严重的严重过敏反应相关，尤其是对昆虫毒液和在围手术期，因此患者B应在过敏门诊接受肥大细胞疾病评估。

这个例子说明为什么急性期和基线样本都需要：同一个绝对值在一个人身上有意义，在另一个人身上则不然。
:::

::: exercise 使用抗生素时皮疹的鉴别诊断 {level=3}
一名19岁学生咽痛、发热、颈部淋巴结肿大，被处方阿莫西林。五天后他出现全身瘙痒性斑丘疹。没有呼吸困难、黏膜受累或水疱。血涂片显示异型淋巴细胞。(a) 最可能的解释是什么？(b) 哪些特征会让你担心重症皮肤不良反应？(c) 他应该被终身标记为青霉素过敏吗？
::: solution
(a) 最可能的解释是：大多数**传染性单核细胞增多症（EB病毒感染）**患者在使用阿莫西林或氨苄西林后会出现斑丘疹。这是一种迟发型T细胞介导反应，可能反映了病毒驱动的免疫激活；它在开始用药数天后出现，排除了速发型IgE反应。

(b) 重症皮肤不良反应的警示特征包括：黏膜受累（口、眼、生殖器）、皮肤疼痛、水疱或皮肤剥脱、尼氏征阳性（SJS/TEN），以及在开始用药后2至8周出现的面部水肿、发热、淋巴结肿大、嗜酸性粒细胞增多和肝炎等器官受累（DRESS）。出现其中任何一项都需要停药、紧急专科评估并永久记录过敏。

(c) 不应自动标记。应准确记录这次反应（药物、时间、皮疹类型、EB病毒背景）。许多这样的患者日后能耐受阿莫西林，过敏评估（常包括口服激发）可以去掉不必要的青霉素过敏标签，否则他余生都将不得不使用更广谱的抗生素。
:::
