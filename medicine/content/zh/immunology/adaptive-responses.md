上一章介绍了B细胞和T细胞如何识别抗原。仅有识别什么也做不成。结合了自身抗原的初始淋巴细胞必须被激活，必须分裂许多次以形成足够大的克隆，还必须发育成能针对威胁做正确工作的效应细胞。威胁消失后，克隆的大部分死亡，但会留下一群记忆细胞。于是第二次相遇时应答更快、更强、更好。

本章按这一顺序展开：适应性应答在哪里发生，T细胞如何被激活以及不同T细胞亚群做什么，B细胞如何在T细胞辅助下产生抗体，每类抗体有何作用，以及记忆如何运作。这些机制是解读血清学检查、设计疫苗以及大多数免疫抑制药物作用的基础。

## 适应性应答在哪里发生

淋巴细胞在**中枢淋巴器官**中发育：B细胞在骨髓，T细胞在胸腺。它们在**外周淋巴器官**中遇到抗原：淋巴结、脾脏以及扁桃体和肠道派尔集合淋巴结等黏膜相关淋巴组织。

系统面临的是一个数量问题。任何特定的肽–MHC只被大约$10^5$至$10^6$个初始T细胞中的一个所识别，而感染可能发生在一个脚趾上。解决办法是把抗原和淋巴细胞带到同一个地方。树突状细胞经输入淋巴管把抗原从组织运送到引流淋巴结。初始淋巴细胞借助L-选择素和趋化因子受体CCR7，穿过专门的**高内皮微静脉**，不断从血液进入淋巴结；若一无所获，便经输出淋巴管离开。脾脏对血液中的抗原承担同样的工作。

在淋巴结内，T细胞聚集在**副皮质区**，B细胞聚集在皮质的**滤泡**中。引流感染部位的淋巴结肿大，是淋巴细胞在那里被滞留并分裂的结果。

## 激活初始T细胞

::: theorem T细胞激活的三个信号 {#thm-three-signals}
初始T细胞只有从树突状细胞接收到三个信号才能被完全激活：

1. **信号1，抗原**：TCR结合其肽–MHC，CD4或CD8作为共受体。
2. **信号2，共刺激**：T细胞上的**CD28**结合树突状细胞上的**CD80或CD86**（B7分子）。
3. **信号3，细胞因子**：树突状细胞分泌的细胞因子决定T细胞分化为哪类效应细胞。

只有信号1而没有信号2不会激活细胞，反而可能使T细胞失去反应性（**失能**）。树突状细胞只有在其模式识别受体检测到微生物产物或组织损伤后，才会强烈表达CD80和CD86。
:::

::: proof
需要两个信号是一种安全机制。自身肽始终由MHC提呈，因此单靠信号1不可能足以触发应答，否则逃过胸腺的自身反应性T细胞将不断被激活。共刺激分子只有在固有感知检测到感染或损伤时才出现在树突状细胞上。把T细胞激活与固有危险信号耦联，意味着T细胞只有在危险情境下遇到其肽时才会应答。这就是固有免疫系统“指导”适应性免疫系统的方式，也是疫苗需要佐剂的原因。
:::

在T细胞内，TCR信号使胞内钙升高，激活磷酸酶**钙调神经磷酸酶**。钙调神经磷酸酶使转录因子**NFAT**去磷酸化，NFAT进入细胞核，与CD28激活的NF-κB和AP-1一起开启**IL-2**基因。IL-2与高亲和力IL-2受体α链（CD25）驱动T细胞分裂。多种免疫抑制药物正作用于这些步骤，见[[immunology/transplant-tumour-immunology]]：

- **环孢素和他克莫司**抑制钙调神经磷酸酶（信号1）；
- **阿巴西普和贝拉西普**是CTLA-4–Ig融合蛋白，结合CD80/CD86，阻断信号2；
- **巴利昔单抗**阻断IL-2受体α链CD25；
- **西罗莫司**（mTOR抑制剂）阻断IL-2下游的增殖信号。

T细胞一旦被激活，还会表达**CTLA-4**，它与CD80/CD86的结合比CD28更强，从而关闭应答。治疗性阻断CTLA-4可解除这一“刹车”，这是免疫检查点抑制剂治疗的基础。

### 克隆扩增

被激活的T细胞在数天内大约每6至8小时分裂一次。一个克隆可在一周内从几百个细胞扩增到数百万个。这就是初次应答需要一周或更久才能见效、以及淋巴结肿大的原因。

::: example 需要分裂多少次？ {#ex-expansion}
某人约有200个针对某一病毒肽的初始CD8 T细胞。一周后应答高峰时，针对该肽的细胞约有$2 \times 10^6$个。假设每个细胞都分裂且存活，需要多少轮分裂？以每8小时分裂一次计，需要多长时间？
::: solution
克隆扩大了$2 \times 10^6 / 200 = 10^4$倍。每次分裂使数量加倍，因此分裂次数$n$满足$2^n = 10^4$：

$$
n = \log_2 10^4 = \frac{4}{\log_{10} 2} \approx 13.3.
$$

大约需要13至14次分裂。按每次分裂8小时计，细胞开始分裂后约需$13.3 \times 8 \approx 106$小时，约4.5天。再加上树突状细胞到达和T细胞找到它所需的一两天，结果与实际观察到的初次CD8应答约一周达峰相符。实际上部分子代细胞会死亡，因此需要的分裂次数稍多。
:::
:::

## 辅助性T细胞亚群

初始CD4 T细胞可分化为几类辅助细胞，各自专门应对不同的威胁。这一决定主要取决于激活时存在的细胞因子（信号3），而后者又取决于树突状细胞感知到了什么。每个亚群由一个**主转录因子**和一组**标志性细胞因子**来界定。

::: definition 辅助性T细胞亚群 {#def-help}
- **Th1**细胞在**IL-12**（由检测到胞内细菌或病毒的树突状细胞和巨噬细胞产生）影响下分化。主调控因子为**T-bet**。它们产生**γ干扰素**，激活巨噬细胞杀灭分枝杆菌和沙门菌（*Salmonella*）等胞内微生物。
- **Th2**细胞在**IL-4**影响下分化。主调控因子为**GATA3**。它们产生**IL-4、IL-5和IL-13**，驱动IgE类别转换、嗜酸性粒细胞生成和活化、黏液分泌以及肠道平滑肌收缩：这是针对蠕虫的应答，也是过敏的基础。
- **Th17**细胞在**IL-6和TGF-β**影响下分化，由**IL-23**维持。主调控因子为**RORγt**。它们产生**IL-17和IL-22**，招募中性粒细胞并刺激上皮产生抗菌肽，在皮肤和黏膜表面防御胞外细菌和念珠菌（*Candida*）等真菌。
- **滤泡辅助性T（Tfh）细胞**表达转录因子**BCL6**和趋化因子受体CXCR5，后者引导它们进入B细胞滤泡。它们产生**IL-21**并提供CD40配体，给予B细胞形成生发中心所需的辅助。
- **调节性T细胞**（Treg）以**FOXP3**为标志，抑制应答；见[[immunology/tolerance-regulation]]。
:::

这些亚群并非僵硬的分隔，许多T细胞具有混合或变化的表型。但这一框架能很好地预测临床模式，因为每个亚群缺失都会留下特征性的缺口。

| 亚群 | 威胁 | 缺陷 | 典型后果 |
|---|---|---|---|
| Th1（IL-12、IFN-γ） | 胞内细菌 | IL-12/IFN-γ轴的遗传缺陷 | 弱毒分枝杆菌（包括BCG疫苗株）和沙门菌的严重感染 |
| Th2（IL-4、IL-5、IL-13） | 蠕虫 | 临床问题是过度而非缺乏 | 过敏、嗜酸性粒细胞性哮喘 |
| Th17（IL-17、IL-22） | 胞外细菌、真菌 | STAT3缺乏（常染色体显性高IgE综合征）；IL-17通路缺陷 | 慢性皮肤黏膜念珠菌病、葡萄球菌皮肤和肺脓肿 |
| Tfh（IL-21、CD40L） | 抗体应答 | CD40配体缺乏 | 高IgM综合征 |

现代生物制剂以这些通路为靶点。抗IL-5或其受体的抗体（美泊利珠单抗、贝那利珠单抗）用于重症嗜酸性粒细胞性哮喘；度普利尤单抗阻断IL-4和IL-13共用的受体，用于特应性皮炎和哮喘；抗IL-17（司库奇尤单抗）或抗IL-23（古塞奇尤单抗、利生奇珠单抗）的抗体用于治疗银屑病。IL-17阻断可预见的副作用是皮肤黏膜念珠菌病，与亚群框架的预测完全一致。

## 细胞毒性T细胞与巨噬细胞活化

::: definition 细胞介导的细胞毒作用 {#def-cytotoxic}
**细胞毒性T淋巴细胞**（CTL）是效应CD8 T细胞，杀伤在MHC I类分子上展示其特异性肽的细胞。它与靶细胞形成紧密接触（免疫突触），把颗粒中的**穿孔素**和**颗粒酶**释放到靶细胞内；颗粒酶触发凋亡。CTL还能通过**Fas配体**与靶细胞上的Fas结合进行杀伤。一个CTL可相继杀伤多个靶细胞。CTL还分泌γ干扰素和TNF。
:::

以凋亡而非溶解方式杀伤很重要：靶细胞从内部被拆解，病毒核酸被降解，残骸由吞噬细胞清除，不会散播有感染性的病毒。

良好的CD8应答需要CD4辅助。辅助性T细胞通过CD40配体与CD40与同一个树突状细胞相互作用，“许可”该树突状细胞向CD8 T细胞提供更强的共刺激。没有这种辅助，CD8 T细胞应答不良，形成的记忆也少。这是HIV感染中CD4 T细胞丢失最终会削弱对巨细胞病毒和EB病毒等其他病毒控制的原因之一。

Th1细胞介导的**巨噬细胞活化**是细胞免疫的另一支。巨噬细胞能吞入分枝杆菌，但只有被γ干扰素和TNF激活后才能有效杀灭它们。活化的巨噬细胞使溶酶体与吞噬体融合，产生活性氧和活性氮，并形成**肉芽肿**：由活化巨噬细胞（上皮样细胞和多核巨细胞）组成、外围有淋巴细胞的致密细胞团，用以包围它们无法清除的微生物。维持肉芽肿需要TNF。

::: example 使用抗TNF药物之前 {#ex-anti-tnf}
一名出生于印度、10年前移居英国的38岁女性即将因克罗恩病开始使用英夫利昔单抗。她的胸片正常，身体健康。γ干扰素释放试验（IGRA）阳性。解释检测的免疫学原因以及结果的意义。
::: solution
**检测。**IGRA测定其T细胞暴露于结核分枝杆菌（*Mycobacterium tuberculosis*）特异性肽时γ干扰素的释放。阳性结果意味着她有针对结核分枝杆菌的记忆Th1细胞，因此曾在某个时候受到感染。胸片正常且无症状，属于**结核潜伏感染**：活菌被控制在肉芽肿内。

**为何重要。**肉芽肿由TNF维持，TNF使巨噬细胞保持活化、使结构保持有序。用英夫利昔单抗阻断TNF可使肉芽肿瓦解，潜伏结核再激活，常在治疗最初几个月内以播散性或肺外结核的形式出现。

**后续处理。**排除活动性结核后，英国现行指南（NICE和英国胃肠病学会）建议在抗TNF治疗之前或开始时治疗潜伏结核，通常采用由结核病专科监督的公认方案，并在治疗期间警惕结核症状。具体方案和时机遵循当地结核病专科的规程。对于已在接受免疫抑制的人，IGRA阴性并不能完全排除感染，因为该试验依赖T细胞应答。
:::
:::

## B细胞活化与抗体产生

B细胞可通过两种方式被激活。

**T细胞非依赖性应答**针对具有许多相同重复表位的抗原，尤其是细菌**荚膜多糖**。这类抗原同时交联许多BCR，无需T细胞辅助即可激活B细胞。应答主要由脾脏**边缘区B细胞**产生，以IgM为主，亲和力几乎不成熟，留下的记忆很少。约2岁以下儿童对多糖抗原应答不良，这就是他们易受有荚膜细菌感染、以及单纯多糖疫苗在婴儿期无效的原因。脾缺失使边缘区消失，这部分解释了脾切除后的感染风险。

**T细胞依赖性应答**针对蛋白质，产生经过类别转换的高亲和力抗体并留下记忆。它们需要**连锁识别**：

1. B细胞通过BCR结合蛋白抗原，将其内化，并在MHC II类分子上提呈来自该抗原的肽。
2. 一个曾被提呈同一抗原的树突状细胞激活过的CD4 T细胞，识别B细胞上的该肽–MHC。
3. T细胞提供辅助：**CD40配体**（CD154）结合B细胞上的CD40，并释放细胞因子（IL-21、IL-4等）。

B细胞和T细胞识别同一抗原的不同部分（B细胞识别表面表位，T细胞识别内部的肽），但两者必须物理上连在同一个分子中。结合疫苗正是利用了这一点：把荚膜多糖连接到载体蛋白上，可使多糖特异性B细胞获得载体特异性T细胞的辅助。

### 生发中心

部分被激活的B细胞在滤泡外成为短寿的**浆母细胞**，产生早期以IgM为主的第一波抗体。另一些与Tfh细胞一起进入滤泡，形成**生发中心**，抗体应答在那里经数周得到精炼。

::: theorem 生发中心选择 {#thm-germinal}
在生发中心内，B细胞快速分裂，**活化诱导胞苷脱氨酶**（AID）向其已重排的可变区基因引入点突变（**体细胞高频突变**）。突变后的B细胞随后竞争捕获**滤泡树突状细胞**上保存的抗原，并将其提呈给Tfh细胞。突变提高了亲和力的B细胞捕获更多抗原、获得更多辅助并存活；其余的凋亡。反复循环产生**亲和力成熟**。AID还驱动**类别转换重组**：在T细胞细胞因子和CD40信号的指导下，用Cγ、Cα或Cε替换重链恒定区（Cμ），而可变区保持不变。存活的B细胞以长寿浆细胞或记忆B细胞的形式离开。
:::

两种遗传缺陷证明了这一过程。在**X连锁高IgM综合征**中，T细胞上缺乏CD40配体。B细胞不能进行类别转换，因此IgM正常或升高，而IgG、IgA和IgE极低；巨噬细胞和树突状细胞的活化也需要同一CD40信号，因此患病男孩还会发生肺孢子菌肺炎和隐孢子虫（*Cryptosporidium*）感染。在常染色体隐性的**AID缺乏**中，类别转换和高频突变均失败，淋巴结因巨大生发中心而肿大，但由于T细胞对巨噬细胞的辅助正常，不发生机会性感染。

## 抗体类别及其作用

抗体通过五种方式发挥保护作用：

- **中和**：结合毒素或病毒，使其不能附着于靶细胞；
- **调理**：包被微生物，使带有Fc受体的吞噬细胞将其摄取；
- 经经典途径**激活补体**；
- 由NK细胞介导的**抗体依赖细胞介导的细胞毒作用**；
- **致敏肥大细胞和嗜酸性粒细胞**（IgE）。

::: definition 免疫球蛋白同种型 {#def-isotypes}
| 同种型 | 形式 | 主要特点 |
|---|---|---|
| **IgM** | 血清中为五聚体 | 初次应答中最先产生的抗体；强补体激活剂；亲合力高；不能通过胎盘 |
| **IgG** | 单体 | 血清中含量最多；四个亚类（IgG1至IgG4）；调理、激活补体（IgG1和IgG3最强）并介导ADCC；经新生儿Fc受体（FcRn）主动转运通过胎盘；血清半衰期约3周（IgG3较短） |
| **IgA** | 血清中为单体，分泌液中为二聚体 | 黏膜表面的主要抗体；由多聚免疫球蛋白受体转运穿过上皮，留下分泌片；中和而不引起炎症；也存在于母乳中 |
| **IgE** | 单体 | 血清水平极低；结合肥大细胞和嗜碱性粒细胞上的高亲和力受体FcεRI；防御蠕虫，也是速发型过敏的原因 |
| **IgD** | 单体 | 主要与IgM一起作为初始B细胞上的受体 |
:::

IgG半衰期长有一个具体原因。内皮细胞中的**新生儿Fc受体**（FcRn）结合经胞饮摄入的IgG，使其免于溶酶体降解并送回血液。同一受体把母体IgG转运过胎盘，主要在妊娠晚期，这就是早产儿IgG低、以及孕期母体接种疫苗能保护幼小婴儿的原因。FcRn还解释了为什么基于IgG的治疗性单克隆抗体可以每隔数周给药一次，以及为什么阻断FcRn的新药能降低IgG水平，被用于重症肌无力等抗体介导的疾病。

每天产生的IgA比所有其他同种型加起来还多，几乎全部在黏膜表面。选择性IgA缺乏症是欧洲血统人群中最常见的原发性抗体缺陷，常无症状，见[[immunology/immunodeficiency]]。

## 初次应答与再次应答

::: definition 初次应答、再次应答和免疫记忆 {#def-memory}
**初次应答**发生在首次接触抗原之后。在可检测到抗体之前有约5至10天的**潜伏期**，IgM先出现，随后是IgG，峰值不高，亲和力中等。

**再次（回忆）应答**发生在再次接触之后。它在数天内开始，峰值高得多，主要由类别转换后的IgG（或IgA、IgE）组成，亲和力更高。

**免疫记忆**是使再次应答与众不同的特性。其载体是：

- 骨髓中的**长寿浆细胞**，无需进一步刺激即可分泌抗体数年乃至数十年；
- **记忆B细胞**，对再次接触迅速应答；
- **记忆T细胞**：**中央记忆**细胞（表达CCR7，在淋巴结中再循环）、**效应记忆**细胞（巡逻组织），以及留在既往感染部位（皮肤、肠道或肺）的**组织驻留记忆**细胞。
:::

### 解读血清学检查

抗体应答的动力学使血清学诊断成为可能。

- 针对某病原体的**IgM**通常提示近期初次感染。不过IgM假阳性很常见，原因包括交叉反应和多克隆B细胞活化（如EB病毒感染），而且IgM可持续数月。
- **IgG**表明既往感染或接种过疫苗，单独一项不能确定感染时间。
- 急性期样本与2至4周后的恢复期样本（双份血清）之间**IgG滴度上升**提示现症感染。常规阈值是**升高四倍或以上**，因为滴度按两倍稀释测定，相差一个稀释度在检测误差之内。
- **IgG亲合力**随亲和力成熟在数月内增加。低亲合力IgG提示过去几个月内的感染；高亲合力提示较早的感染。亲合力检测尤其用于孕期确定巨细胞病毒和弓形虫等感染的时间。

::: example 确定孕期感染的时间 {#ex-avidity}
一名31岁女性在一家托儿所工作，妊娠14周时做了常规血液检查。她的巨细胞病毒（CMV）IgG和IgM均阳性。这是近期初次感染吗？还有什么检查有帮助？
::: solution
**结果能说明和不能说明什么。**IgG阳性表明她在某个时候感染过CMV。IgM阳性可能意味着过去几个月内的初次感染，但CMV IgM也可在初次感染后持续许多个月，或在再激活或再感染时出现，或为假阳性。单凭它不能确定感染时间。

**下一步检查。**对同一样本做**IgG亲合力**检测会有帮助。如果亲合力**高**，说明这些IgG是数月亲和力成熟的产物，因此初次感染很可能发生在约3个月以前，即怀孕之前，胎儿严重受损的风险就低得多。如果亲合力**低**，感染很可能是近期的，她应转诊至胎儿医学专科接受咨询，并可能进行羊膜腔穿刺做CMV PCR和系列超声检查。如果孕前留取的样本（例如保存的初诊血清）IgG阴性，血清转换即证明是近期初次感染。

原理是：抗体应答随时间的成熟可以用作一个时钟。具体的亲合力阈值和解读因检测方法而异，应遵循实验室的指导。
:::
:::

::: example 双份血清 {#ex-paired}
一名50岁男性患非典型肺炎。入院时肺炎支原体（*Mycoplasma pneumoniae*）抗体滴度为1:32，两周后为1:256。假设检测采用两倍稀释，滴度上升了多少？如何解读？
::: solution
升高倍数为$256/32 = 8$，相当于三个两倍稀释度（$2^3 = 8$）。这超过了四倍升高的常规诊断阈值，提示现症或近期感染。单次1:32的滴度可能只反映既往感染。

双份血清是一种**回顾性**诊断：到采集恢复期样本时，患者通常已经接受了治疗。因此，需要答案来指导治疗时首选抗原或PCR检测，双份血清学主要用于流行病学或其他检测不可用时。
:::
:::

:::warning
抗体检测阴性并不总意味着没有感染。在初次感染早期（“窗口期”）、抗体缺陷患者或使用利妥昔单抗等B细胞清除药物的患者中，以及在接受免疫球蛋白替代或血液制品之后，抗体可能检测不到；后者也可能因被动转移的抗体而造成*阳性*结果。解读血清学之前，要问清采样时间与接触时间的关系，以及患者能否产生抗体或是否接受过抗体。
:::

::: quiz
一名6岁男孩曾患耶氏肺孢子菌肺炎，并反复发生鼻窦感染。他的IgM升高，IgG和IgA极低，B细胞数量正常。最可能缺陷的是哪个分子？
- [ ] RAG1
- [ ] 布鲁顿酪氨酸激酶
- [x] CD40配体
- [ ] IL-12受体
::: solution
IgM升高或正常而IgG和IgA缺如，意味着B细胞存在但不能进行类别转换。肺孢子菌感染意味着T细胞对巨噬细胞和树突状细胞的辅助也受损。活化T细胞上的CD40配体同时提供这两种信号，因此X连锁CD40配体缺乏（高IgM综合征）可解释全部表现。布鲁顿酪氨酸激酶缺乏会导致B细胞缺失和IgM降低；RAG1缺乏导致T细胞和B细胞都缺失；IL-12受体缺乏导致分枝杆菌和沙门菌感染而抗体正常。
:::
:::

::: history
1956年，Bruce Glick发现切除法氏囊的鸡抗体应答不良；1961年，Jacques Miller证明出生时切除胸腺的小鼠不能排斥皮肤移植物且淋巴细胞很少。1965年，Max Cooper和Robert Good把这些发现综合为两个淋巴细胞谱系的概念：产生抗体的法氏囊来源（B）细胞和介导细胞免疫的胸腺来源（T）细胞。James Gowans在1959年证明淋巴细胞不断从血液再循环到淋巴，解释了稀少的特异性细胞如何找到其抗原。

1986年，Tim Mosmann和Robert Coffman描述了两类细胞因子谱不同的小鼠辅助性T细胞克隆，命名为Th1和Th2。Th17谱系于2005年加入，滤泡辅助性T细胞在21世纪头十年得到界定。1999年，Federica Sallusto和Antonio Lanzavecchia根据淋巴结归巢受体CCR7的表达区分了中央记忆和效应记忆T细胞。
:::

## 后续内容

适应性应答的“刹车”失灵时，结果就是自身免疫；这些刹车如何工作是[[immunology/tolerance-regulation]]的主题。调节正常、但针对无害抗原的应答会引起[[immunology/hypersensitivity]]。本章各步骤的缺陷见[[immunology/immunodeficiency]]，有意诱导记忆的疫苗见[[immunology/vaccines-immunotherapy]]。

::: summary
- 初始淋巴细胞在淋巴结和脾脏中再循环，树突状细胞把抗原从组织带到那里。
- T细胞激活需要抗原（TCR与肽–MHC）、共刺激（CD28与CD80/CD86）和细胞因子。只有信号1会导致失能。钙调神经磷酸酶、NFAT、IL-2和CD25驱动增殖，每一个都是药物靶点。
- CD4 T细胞分化为Th1（IFN-γ；胞内细菌）、Th2（IL-4、IL-5、IL-13；蠕虫和过敏）、Th17（IL-17、IL-22；胞外细菌和真菌）、Tfh（辅助B细胞）和Treg亚群。各亚群的缺陷产生特征性的感染。
- CD8细胞毒性T细胞用穿孔素、颗粒酶和Fas配体杀伤感染细胞；Th1细胞通过IFN-γ和TNF激活巨噬细胞并维持肉芽肿，因此抗TNF治疗可使潜伏结核再激活。
- 对多糖的T细胞非依赖性应答较弱且以IgM为主，2岁以下尤甚；T细胞依赖性应答需要连锁识别和CD40配体。
- 在生发中心，AID驱动体细胞高频突变和类别转换，滤泡树突状细胞上的选择产生亲和力成熟。
- IgM最先出现；IgG是血清中的主要抗体，经FcRn通过胎盘，半衰期约3周；IgA保护黏膜；IgE武装肥大细胞。
- 再次应答更快、更强、经过类别转换且亲和力更高。血清学利用IgM、双份血清四倍升高和IgG亲合力来确定感染时间。
:::

某患者急性期抗某病毒抗体滴度为1:20，三周后为1:320。滴度升高了多少倍？
::: solution
$320/20 = 16$，升高十六倍（四个两倍稀释度）。这远超四倍阈值，支持现症感染。

::: exercise 细胞因子配对 {level=1}
说出与下列各项最相关的辅助性T细胞亚群及其主转录因子：(a) γ干扰素；(b) IL-5；(c) IL-17；(d) B细胞滤泡中的IL-21。
::: solution
(a) Th1，T-bet。(b) Th2，GATA3。(c) Th17，RORγt。(d) 滤泡辅助性T细胞，BCL6。

::: exercise 被动IgG的衰减 {level=1 check="0.125"}
一名新生儿出生时有抗麻疹的母体IgG。假设半衰期为21天且无新的生成，63天时剩余该IgG的比例是多少？以小数作答。
::: solution
63天是$63/21 = 3$个半衰期，因此剩余比例为$(1/2)^3 = 1/8 = 0.125$。母体抗体在出生后数月内的这种下降，是婴儿变得易感麻疹的原因，也是过早接种麻疹疫苗可能被残余母体抗体中和的原因。
:::
:::

::: exercise 结合疫苗为何有效 {level=2}
用连锁识别解释：为什么b型流感嗜血杆菌荚膜多糖与破伤风类毒素蛋白结合的疫苗能在婴儿中产生持久的、经过类别转换的抗多糖抗体，而单纯多糖却不能。
::: solution
单纯多糖是T细胞非依赖性抗原。它交联多糖特异性B细胞上的BCR，但不能由MHC提呈，因此得不到T细胞辅助。应答主要是边缘区B细胞产生的IgM，而边缘区B细胞在约2岁以前尚不成熟，产生的记忆也很少。在结合疫苗中，多糖特异性B细胞用其BCR结合多糖，并内化包括所连接蛋白在内的整个结合物。它在MHC II类分子上提呈破伤风类毒素的肽。类毒素特异性Tfh细胞识别这些肽并提供CD40配体和细胞因子。于是这个B细胞进入生发中心，转换为IgG，亲和力成熟并形成记忆，尽管B细胞和T细胞识别的是不同的分子。
:::
:::

::: exercise 钙调神经磷酸酶抑制剂的机制 {level=2}
一名肾移植受者服用他克莫司。解释为什么这种药物会减少T细胞激活，却仍使她能对T细胞非依赖性抗原产生抗体应答，以及为什么她感染病毒的风险仍然增加。
::: solution
他克莫司与亲免蛋白FKBP-12结合，形成的复合物抑制钙调神经磷酸酶。于是TCR信号不能使NFAT去磷酸化，IL-2和其他细胞因子基因不被转录，T细胞不能增殖或分化。依赖T细胞辅助的应答，包括T细胞依赖性抗体应答，都会减弱。T细胞非依赖性应答通过广泛的BCR交联激活B细胞，对钙调神经磷酸酶驱动的T细胞辅助依赖较少，因此相对保留（B细胞受体信号也利用钙，所以并非完全不受影响）。病毒的控制依赖CD8 T细胞及CD4对它们的辅助，因此她感染巨细胞病毒、BK多瘤病毒以及发生EB病毒驱动的淋巴增殖的风险增加。
:::
:::

::: exercise 解读单项IgG结果 {level=2}
一名25岁医学生乙型肝炎表面抗体（抗-HBs）阳性，乙型肝炎核心抗体（抗-HBc）阴性。这说明什么？自然感染后结果会有何不同？
::: solution
抗-HBs针对表面抗原产生，表面抗原就是乙肝疫苗中的抗原。抗-HBc针对核心蛋白产生，核心蛋白只存在于病毒中而不在疫苗中。因此抗-HBs阳性而抗-HBc阴性提示**疫苗接种获得的免疫**。清除了自然感染的人抗-HBs和抗-HBc均阳性。慢性感染者HBsAg和抗-HBc阳性，但通常无抗-HBs。选择病原体中有而疫苗中没有的抗原，使血清学能把感染与免疫接种区分开。
:::
:::

::: exercise 推算初次应答的时间 {level=3 check="ceil(log2(5*10^5/50))"}
某疫苗激活了50个针对某一肽的初始CD4 T细胞。高峰时此类细胞有$5 \times 10^5$个。假设所有细胞同步分裂且无死亡，至少需要多少次（整数）分裂才能达到这一数量？
::: hint
求满足$50 \times 2^n \geq 5 \times 10^5$的$n$。
:::
::: solution
所需扩增倍数为$5 \times 10^5 / 50 = 10^4$。需要$2^n \geq 10^4$，即$n \geq \log_2 10^4 \approx 13.29$。最小整数为$n = 14$（$2^{14} = 16\,384$，而$2^{13} = 8192$不够）。按每6至8小时分裂一次计，连续分裂约需3.5至4.7天，与接种后约一周达峰相符。
:::
:::

::: exercise 接种BCG后发生分枝杆菌感染的男孩 {level=3}
一名9个月男孩出生时接种过BCG疫苗，现出现持续发热、肝脾肿大和淋巴结肿大；活检显示形成不良的肉芽肿，内有大量抗酸杆菌，鉴定为BCG株。他的中性粒细胞功能、免疫球蛋白和淋巴细胞数量正常，也没有其他不寻常的感染。提出最可能的免疫缺陷，解释其机制，并说出在某些类型中可能有用的一种治疗。
::: solution
弱毒BCG株的播散性感染、形成不良的肉芽肿，而其他方面免疫正常，提示**IL-12/γ干扰素轴**缺陷，称为孟德尔遗传性分枝杆菌病易感性。例如IL-12受体β1链或γ干扰素受体的缺陷。吞入分枝杆菌的巨噬细胞产生IL-12，驱动T细胞和NK细胞产生γ干扰素；γ干扰素反过来激活巨噬细胞，使其杀灭胞内分枝杆菌并组织肉芽肿。这一环路断裂后，巨噬细胞连减毒的分枝杆菌都无法杀灭，而对大多数其他微生物的防御仍然完好。沙门菌感染是另一个典型特征。对于γ干扰素受体上游的缺陷（如IL-12受体β1缺乏），在抗分枝杆菌治疗之外加用重组γ干扰素可能有帮助；对于完全性γ干扰素受体缺乏则无效，可能需要干细胞移植。在英国，BCG只提供给结核风险增高的婴儿，有重症联合免疫缺陷或此类易感性家族史者应推迟接种。
:::
