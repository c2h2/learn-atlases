疫苗接种是免疫学最成功的应用。天花已被根除；三型野生脊髓灰质炎病毒中已有两型不复存在；白喉、破伤风、麻疹、b型流感嗜血杆菌脑膜炎和先天性风疹曾是儿童死亡和残疾的常见原因，在疫苗覆盖率高的地方都已变得罕见。乙型肝炎和人乳头瘤病毒疫苗正在预防肝癌和宫颈癌。

疫苗的作用是给适应性免疫系统一次安全的预演，使其第一次真正遇到病原体时引发的是再次应答而非初次应答。前几章的所有内容都与此相关：决定应答能否启动的固有信号（[[immunology/innate-immunity]]），产生高亲和力、经过类别转换的抗体和记忆所需的T细胞辅助和生发中心（[[immunology/adaptive-responses]]），以及使某些人无法应答的缺陷（[[immunology/immunodeficiency]]）。

本章后半部分转向**免疫治疗**：有意使用抗体、细胞因子、细胞和小分子来增强、重新引导或抑制免疫应答。单克隆抗体如今已是使用最广泛的药物之一。

## 被动免疫和主动免疫

::: definition 被动免疫和主动免疫 {#def-immunisation}
**被动免疫**是输入现成的抗体。保护是即时的但只是暂时的，因为抗体会逐渐被降解（IgG半衰期约3周），而且不形成记忆。天然被动免疫来自穿过胎盘的母体IgG和母乳中的IgA。人工被动免疫使用人免疫球蛋白（混合的或特异性的，如乙型肝炎、狂犬病、破伤风或水痘–带状疱疹免疫球蛋白）、单克隆抗体或抗蛇毒血清等动物抗血清。

**主动免疫**是通过感染或疫苗刺激人自身的免疫应答。它需要数天至数周才能形成，但会产生可持续数十年的免疫记忆。
:::

两者常常联合使用。乙肝母亲所生的婴儿出生时接种乙肝疫苗，如果母亲传染性高，还要注射乙型肝炎免疫球蛋白：免疫球蛋白立即提供保护，疫苗则产生持久免疫。未完成全程接种的人发生易感染破伤风的伤口后，要接种含破伤风成分的疫苗，高风险伤口还要注射人破伤风免疫球蛋白。被可能患狂犬病的动物咬伤后，要接种狂犬病疫苗；如果暴露风险高且此前未接种过，还要在伤口周围浸润注射狂犬病免疫球蛋白。

::: example 园艺叉刺穿了脚 {#ex-tetanus}
一名78岁女性踩到园艺叉上，叉子穿透鞋子刺入脚中。伤口很深，被泥土和粪肥污染。她记得20世纪70年代割伤后打过“破伤风针”，但没有完成全程接种的记录。解释她伤口处理背后的免疫学推理。
::: solution
**威胁。**土壤中的破伤风梭菌（*Clostridium tetani*）芽孢在深而缺氧、被污染的伤口中萌发。细菌停留在局部，但释放**破伤风痉挛毒素**，该毒素沿神经上行至脊髓，阻断抑制性神经传递，引起强直和痉挛。致病的是毒素而非细菌侵袭，因此保护取决于毒素结合神经末梢之前血液中有**中和性IgG抗毒素**。患破伤风并不能可靠地使幸存者获得免疫，因为致病的毒素量太小，不足以引发强烈应答。

**她的免疫状态。**初次免疫程序不明或不完整，就不能假定她有保护性抗毒素（至少0.1 IU/mL）。老年人，尤其是没有在服兵役时接种过的女性，是英国免疫水平最低的人群。

**处理原则。**彻底清创以去除芽孢和坏死组织。由于疫苗需要数天至数周才能诱导抗体，未完成全程免疫者的高风险伤口需要**被动**保护：注射人破伤风免疫球蛋白，立即提供抗毒素。她还要在另一部位接种一剂含破伤风成分的疫苗（**主动**免疫），之后完成全程接种，以便将来受到保护。具体选择遵循《绿皮书》中针对易感染破伤风伤口的表格，取决于免疫状态和伤口风险。
:::
:::

给婴儿使用的长效抗RSV单克隆抗体**尼塞韦单抗**（nirsevimab），是被动免疫发展成人群项目的一个例子。在英国，婴儿的RSV保护通过另一条途径提供：孕妇自28周起接种疫苗，使母体IgG穿过胎盘（该疫苗也提供给75岁的成人）。

## 疫苗的类型

::: definition 疫苗平台 {#def-vaccine}
- **减毒活疫苗**含有在体内复制但不致病（或只引起轻微疾病）的弱化病原体。例如：麻疹、腮腺炎、风疹和水痘（MMRV），轮状病毒，BCG，鼻喷减毒活流感疫苗，黄热病，口服伤寒疫苗。它们通常只需一两剂就能产生强而持久的免疫，包括T细胞应答。
- **灭活全病原体疫苗**含有被杀死的病原体：灭活脊髓灰质炎疫苗（IPV）、甲型肝炎、狂犬病、部分流感疫苗。
- **亚单位和重组蛋白疫苗**只含选定的蛋白：酵母表达的乙肝表面抗原、无细胞百日咳、重组带状疱疹疫苗。**病毒样颗粒**是不含遗传物质、自我组装的病毒衣壳蛋白，如HPV疫苗。
- **类毒素疫苗**含有经甲醛灭活的毒素：破伤风和白喉。
- **多糖疫苗**含有细菌荚膜多糖（23价肺炎球菌多糖疫苗，PPV23）。**结合疫苗**把多糖连接到载体蛋白上：Hib、肺炎球菌结合疫苗（PCV）、ACWY和C群脑膜炎球菌疫苗。
- **病毒载体疫苗**利用无害、不复制的病毒（通常是腺病毒）把编码病原体蛋白的基因送入宿主细胞：部分COVID-19和埃博拉疫苗。
- **核酸疫苗**把信使RNA包裹在脂质纳米颗粒中递送，宿主细胞制造其编码的蛋白：COVID-19疫苗和部分RSV疫苗。
:::

每种平台的优缺点都源于免疫学。

**活疫苗**能复制，因此在正确的部位、伴随天然的固有信号持续提供抗原，而且抗原在细胞内产生并提呈在MHC I类分子上，产生CD8 T细胞应答。但正因为能复制，它们可在无法控制它们的人中致病。它们**禁用于严重免疫抑制者**（例如SCID、大剂量糖皮质激素、化疗、许多生物制剂）和**孕妇**，罕见情况下还会恢复毒力，如口服脊髓灰质炎疫苗产生的疫苗衍生脊髓灰质炎病毒。

**非复制型疫苗**在免疫抑制时是安全的，但通常需要多剂，并需要**佐剂**来激活固有免疫。抗原从细胞外摄取，因此主要提呈在II类分子上，产生抗体和CD4 T细胞应答，而不是强烈的CD8应答。病毒载体和mRNA疫苗是例外：蛋白在细胞内产生，因此也诱导CD8 T细胞，而且核酸本身就能激活固有感受器。

**结合疫苗**解决了婴儿对多糖抗原的问题，原理见[[immunology/adaptive-responses]]。单纯多糖引起T细胞非依赖性应答，2岁以下应答很差，也不留下记忆；把它连接到蛋白上就能招募T细胞辅助，于是婴儿能产生经过类别转换的抗体和记忆。结合疫苗还减少细菌在鼻咽部的携带，因此也保护未接种的人。

### 佐剂

**佐剂**是加入疫苗中以增强免疫应答的物质。它们提供纯化蛋白所缺乏的固有“危险”信号（信号2和信号3）。使用了数十年的**铝盐**形成储库并激活NLRP3炎症小体，有利于抗体应答。**水包油乳剂**（MF59、AS03）用于部分流感疫苗。**AS01**把TLR4激动剂（单磷酰脂质A，一种去毒的LPS）与皂苷QS-21结合，使重组带状疱疹疫苗在老年人中具有很高的效力，而老年人对无佐剂疫苗的应答很弱。

## 疫苗如何提供保护

::: theorem 疫苗必须做到什么 {#thm-vaccine-principles}
一种成功的疫苗必须：

1. 通过病原体自身的分子或佐剂**激活固有免疫**，使树突状细胞提供共刺激和细胞因子；
2. **提呈正确的抗原**：保护性抗体的靶标（常为进入细胞所需的表面蛋白或毒素）或保护性T细胞的靶标；
3. **调动T细胞辅助**，推动生发中心应答、类别转换、亲和力成熟和记忆；
4. 在正确的时间和地点**产生保护性效应**：针对毒素和病毒血症性感染的血液中和性IgG，针对某些肠道和呼吸道感染的黏膜IgA，针对胞内病原体的T细胞；
5. 通过长寿浆细胞以及记忆B细胞和T细胞**持久**维持，在其减弱时加强接种。
:::

**保护相关指标**是能预测保护的可测量免疫应答。对破伤风，抗毒素水平至少0.1 IU/mL被认为具有保护性；对乙型肝炎，基础免疫后抗-HBs至少10 mIU/mL表示有应答。对其他感染，包括百日咳和结核，不存在简单的保护相关指标，这使疫苗研发更加困难。

### 接种程序为何如此安排

- 非活疫苗的基础免疫需要**多剂**：最初几剂起致敏作用，后续剂次加强并推动亲和力成熟。各剂之间必须间隔**最短时间**（常为4周），让生发中心反应得以进行；间隔太近反而应答更差，并不会更快。
- 过早接种活疫苗可能被**母体抗体**中和。这是英国在约12月龄接种含麻疹成分疫苗的主要原因。
- 在免疫减弱时给予**加强**接种，如百日咳和破伤风。
- **妊娠**是通过经胎盘IgG保护新生儿的机会：在英国，孕妇自妊娠16周起可接种百日咳疫苗（最好在约20至32周之间），流感季节的任何孕期均可接种流感疫苗，28周起接种RSV疫苗。

英国儿童免疫程序于2025年7月和2026年1月更新（包括引入MMRV），见[[paediatrics/immunisation]]；项目组织见[[public-health/vaccination-programmes]]。

## 群体免疫

疫苗不仅保护接种者。如果有足够多的人具有免疫力，每次感染平均引起的新感染不到一例，疫情就会消退，从而保护无法接种或接种后未应答的人。

::: definition 基本再生数和群体免疫阈值 {#def-herd}
**基本再生数**$R_0$是在完全易感人群中一个传染者平均引起的继发病例数。如果人群中比例为$p$的人具有免疫力，有效再生数为$R = R_0(1 - p)$。当$R < 1$时传播下降，由此得出**群体免疫阈值**

$$
p_c = 1 - \frac{1}{R_0}.
$$ {#eq-hit}

由于疫苗并非100%有效，所需的**临界接种覆盖率**更高：若疫苗预防感染的有效率为$E$，

$$
V_c = \frac{1 - 1/R_0}{E}.
$$ {#eq-coverage}
:::

这些是简化的结果。它们假设随机混合、终身免疫和人群同质。现实中，人们按家庭、学校、社区和信仰聚集，因此即使全国覆盖率很高，覆盖率低的地区仍可能维持疫情。

hlines: 1

caption: 随$R_0$（横轴）增大，群体免疫阈值和临界接种覆盖率的变化。麻疹的$R_0$通常引用为12至18，阈值超过90%；疫苗有效率为0.95时，所需覆盖率接近95%。降低$e$可以看到，对于传播力很强的感染，有效率一般的疫苗无论覆盖率多高都无法实现群体免疫（曲线升到1以上）。假设均匀混合的简化模型。
:::

::: example 学校里的麻疹 {#ex-measles}
麻疹的$R_0$约为15。两剂MMR预防麻疹的有效率约为97%。(a) 群体免疫阈值是多少？(b) 需要多高的两剂覆盖率才能达到它？(c) 一所中学有1000名学生，其中850人接种了两剂，其余人一剂未接种。麻疹能在那里传播吗？
::: solution
(a) $p_c = 1 - 1/15 = 14/15 \approx 0.933$，因此约93%的人必须具有免疫力。

(b) $V_c = 0.933/0.97 \approx 0.962$，因此需要约96%的两剂覆盖率。这是WHO两剂覆盖率至少95%这一目标的依据。

(c) 有免疫力的学生：$850 \times 0.97 \approx 824.5$，约82%具有免疫力。这远低于93%，因此$R = 15 \times (1 - 0.8245) \approx 2.6$：每个病例平均会感染两人以上，疫情可在约175名易感学生中传播。未接种的学生聚集在同样的班级和朋友圈中，这在现实中使传播更为可能。公共卫生行动包括为未接种的学生和教职工提供MMR，并按UKHSA指南对易感接触者（尤其是孕妇和免疫抑制者）采取隔离措施并给予暴露后建议。
:::
:::

## 疫苗安全性

疫苗接种对象是健康人，常常是儿童，因此安全标准非常高。大多数不良事件属于**反应原性**：局部疼痛、肿胀和发红，以及短暂的发热和不适，由使疫苗起效的同一种固有激活引起。发热之后可能出现热性惊厥，尤其在MMR接种后7至10天（减毒病毒复制时），与长期损害无关。

真正的禁忌证很少：

- 对前一剂疫苗或其某一成分发生**严重过敏反应**；
- 对于**活疫苗**：严重免疫抑制和妊娠。

许多情况被错误地当作禁忌证。鸡蛋过敏**不是**MMR的禁忌证（MMR在鸡胚成纤维细胞而不是鸡蛋中培养），在英国也不是大多数流感疫苗的禁忌证。无发热的轻微疾病、早产、不良反应家族史、稳定的神经系统疾病和母乳喂养都不是暂缓接种的理由。UKHSA《绿皮书》是英国关于禁忌证的参考依据。

罕见的严重不良事件由监测系统追踪，如英国MHRA的**黄卡**计划。一些例子说明这一系统行之有效：轮状病毒疫苗后**肠套叠**的小幅增加促使对第一剂规定了严格的年龄上限；2021年，腺病毒载体COVID-19疫苗接种后由抗血小板因子4抗体引起的**疫苗诱导的免疫性血栓性血小板减少症**在数周内即被识别；mRNA COVID-19疫苗后发现了**心肌炎**，大多为轻症，主要见于第二剂后的年轻男性。在每个例子中，风险都被量化，并针对不同人群与接种的获益进行了权衡。

:::warning
不要把“之后”与“因为”混为一谈。给数百万婴儿接种的疫苗之后，必然会偶然地出现婴儿在这个年龄会发生的每一种疾病。MMR导致自闭症的说法来自1998年的一篇论文，该论文后来被证明存在造假，并于2010年被撤稿；许多大型研究都未发现关联。评估疫苗是否引起某一事件，需要比较接种者与未接种者的发生率，或比较同一人群在风险期和对照期的发生率，而不是依据个例故事。当父母表达担忧时，倾听并尊重地解释证据比不屑一顾更有效。
:::

## 为免疫受损者接种

免疫缺陷者既是最需要保护的人，也是疫苗效果最差或最不安全的人。

- 严重原发性免疫缺陷、免疫抑制治疗期间及之后一段时间（间隔见《绿皮书》），以及CD4计数低的HIV感染者，应避免接种**活疫苗**。
- **灭活疫苗**是安全的，但应答可能较弱；最好在免疫抑制开始前接种，尽可能提前至少2周。
- **家庭接触者**应完成全部接种（包括每年接种流感疫苗），为易感者形成“蚕茧”保护。大多数活疫苗，包括MMR和水痘疫苗，都可以给接触者接种。
- **无脾**者需要特定的疫苗，见[[immunology/immunodeficiency]]。

::: example 暴露于英夫利昔单抗的婴儿 {#ex-infant}
一名克罗恩病女性因病情严重在整个孕期使用英夫利昔单抗。她的足月婴儿将在8周龄开始常规免疫接种，并因家庭结核风险而符合接种BCG的条件。哪些疫苗值得担心？为什么？
::: solution
**机制。**英夫利昔单抗是一种IgG1抗体。与母体IgG一样，它主要在妊娠晚期由新生儿Fc受体主动转运穿过胎盘，婴儿出生时的药物浓度可能比母亲还高，并持续数月。因此婴儿实际上在接受抗TNF治疗。

**BCG。**BCG是减毒活分枝杆菌。分枝杆菌的控制依赖TNF依赖的肉芽肿，在子宫内暴露于英夫利昔单抗、出生后早期接种BCG的婴儿中，已有播散性BCG感染包括死亡的报告。英国指南一直建议，孕期暴露于免疫抑制性生物制剂的婴儿应将BCG推迟到6月龄。

**轮状病毒。**这也是活疫苗，但即使在暴露的婴儿中也只引起轻微疾病，有害的证据弱得多。关于轮状病毒疫苗的建议随时间有所变化，且因药物不同而不同（例如暴露于利妥昔单抗等B细胞清除药物后应避免），因此决定应遵循现行《绿皮书》相关章节和专科意见。

**其他疫苗。**所有非活疫苗（六联疫苗、肺炎球菌结合疫苗、B群脑膜炎球菌疫苗）都应按时接种。可以继续母乳喂养：进入乳汁的英夫利昔单抗极少，且在婴儿肠道中吸收不良。最好在出生前就制定好这一计划，以免婴儿在产后病房被默认接种BCG。
:::
:::

## 免疫治疗

### 单克隆抗体

**单克隆抗体**是由单一细胞克隆产生的完全相同的抗体。最早的治疗性单抗是鼠源抗体，会引起人抗鼠抗体，将其中和并引发反应。随后基因工程产生了**嵌合**抗体（鼠可变区连接人恒定区）、**人源化**抗体（只把鼠的CDR移植到人的框架上）和全**人源**抗体。它们的通用名传统上反映了这一点：*-ximab*（嵌合，如英夫利昔单抗和利妥昔单抗）、*-zumab*（人源化，如托珠单抗和帕博利珠单抗）和*-umab*（人源，如阿达木单抗）。自2021年起新药名采用另一套体系，但旧的名称仍在使用。

::: definition 治疗性抗体的作用机制 {#def-mab}
治疗性单克隆抗体通过以下方式起作用：

- **中和可溶性分子**：细胞因子（抗TNF的英夫利昔单抗和阿达木单抗；抗IL-5的美泊利珠单抗；抗IL-17的司库奇尤单抗）、IgE（奥马珠单抗）或补体C5（依库珠单抗）；
- **阻断受体**：IL-6受体（托珠单抗）、IL-4受体α（度普利尤单抗）、淋巴细胞上的α4整合素（那他珠单抗），或检查点受体CTLA-4和PD-1；
- 通过ADCC、补体和吞噬**清除靶细胞**：B细胞上的CD20（利妥昔单抗、奥瑞珠单抗）、淋巴细胞上的CD52（阿仑单抗）、骨髓瘤细胞上的CD38（达雷妥尤单抗）；
- 把毒素**递送**到靶细胞（抗体偶联药物，如恩美曲妥珠单抗）；
- **桥接两个细胞**（双特异性抗体，如把T细胞上的CD3与白血病细胞上的CD19连接起来的博纳吐单抗）。

**融合蛋白**把受体连接到IgG Fc区上，获得类似抗体的半衰期：依那西普（TNF受体–Fc）和阿巴西普（CTLA-4–Fc）。
:::

这些药物可预见的风险源于其靶点：

- 与被阻断通路相关的**感染**：抗TNF药物使结核再激活；利妥昔单抗使乙型肝炎再激活并导致长期低丙种球蛋白血症；C5抑制剂导致脑膜炎球菌病；阻止淋巴细胞进入脑的那他珠单抗导致**进行性多灶性白质脑病**（PML），即JC病毒引起的脑部感染；
- **输注反应**，尤其是首剂淋巴细胞清除抗体，由细胞因子释放引起；
- **免疫原性**：患者可产生**抗药抗体**，降低药物浓度和疗效。抗TNF抗体联合甲氨蝶呤或硫唑嘌呤可减少这种情况。

开始生物制剂治疗前，要筛查潜伏结核、乙型和丙型肝炎以及HIV，并更新疫苗接种（活疫苗在治疗前而不是治疗期间接种）。**生物类似药**是专利到期后生产的与原研生物制剂高度相似的产品，大大降低了费用，使其得以更广泛使用。

### 其他免疫调节治疗

- 来自数千名供者的混合**免疫球蛋白**在抗体缺陷中以替代剂量使用（每3至4周静脉注射或每周皮下注射），在免疫性血小板减少症、川崎病、吉兰–巴雷综合征和其他一些疾病中以大剂量作为免疫调节剂使用，其作用之一是使FcRn和Fc受体饱和。
- **细胞因子**作为药物使用：复发型多发性硬化用β干扰素，部分乙型肝炎用聚乙二醇α干扰素，慢性肉芽肿病用γ干扰素，G-CSF用于缩短中性粒细胞减少期。
- **小分子免疫调节剂**：**JAK抑制剂**（托法替布、巴瑞替尼、乌帕替尼）同时阻断许多细胞因子受体的信号，用于类风湿关节炎、特应性皮炎和炎症性肠病；其风险包括带状疱疹、血栓形成，以及在有心血管危险因素的老年人中的主要心血管事件和癌症，这促使监管机构在2022年和2023年限制了它们的使用。
- **变应原免疫治疗**诱导对变应原的耐受（见[[immunology/hypersensitivity]]）。
- CAR-T细胞等**细胞治疗**（见[[immunology/transplant-tumour-immunology]]）。

::: example 使用那他珠单抗期间出现无力 {#ex-pml}
一名38岁复发型多发性硬化女性用那他珠单抗治疗4年。她的JC病毒抗体阳性，此前用过硫唑嘌呤。3周内她出现逐渐加重的左侧偏瘫和找词困难。MRI显示白质中一个新的大病灶，无强化，无占位效应。最需要考虑的诊断是什么？她为何处于风险之中？
::: solution
**诊断。****进行性多灶性白质脑病**（PML），由感染少突胶质细胞的JC多瘤病毒引起的脱髓鞘性脑部感染。

**为何有风险。**那他珠单抗阻断淋巴细胞上的α4整合素（VLA-4），阻止其结合脑内皮上的VCAM-1并进入中枢神经系统。这正是它减少多发性硬化复发的原理，但它也阻止了T细胞对脑的监视，使潜伏的JC病毒得以再激活和复制。使用那他珠单抗时PML风险随三个因素增加，而这里三者俱全：抗JC病毒抗体阳性（表明既往感染）、治疗超过2年，以及既往使用过免疫抑制剂。

**检查和处理原则。**脑脊液JC病毒PCR和神经科专科评估。停用那他珠单抗，可用血浆置换更快地将其清除，使免疫监视得以恢复；恢复的免疫应答可引起免疫重建炎症综合征，需要谨慎处理。这个病例说明了为什么PML风险分层、MRI监测以及考虑延长给药间隔或换药是那他珠单抗治疗的组成部分。
:::
:::

一名30岁男性肾移植后接受大剂量泼尼松龙和吗替麦考酚酯治疗。以下哪种疫苗可以安全地给他接种？
- [ ] MMR
- [ ] 水痘（活疫苗）
- [x] 灭活流感疫苗
- [ ] 黄热病疫苗

灭活流感疫苗不含可复制的病毒，推荐移植受者每年接种，尽管应答可能因免疫抑制而减弱。MMR、水痘活疫苗和黄热病疫苗都是减毒活疫苗，可在严重免疫抑制者中引起播散性感染，属于禁忌。他的家庭接触者应接种疫苗，包括流感疫苗。可以为他接种非活的重组带状疱疹疫苗以预防带状疱疹。

::: history
早在疫苗出现之前，中国、印度和奥斯曼帝国的人们就在实行**人痘接种**，即有意用天花脓疱中的物质进行感染；18世纪20年代，玛丽·沃特利·蒙塔古夫人（Lady Mary Wortley Montagu）在英格兰推广了这一方法。1796年，詹纳（Edward Jenner）用挤奶女工Sarah Nelmes手上牛痘病灶的物质给James Phipps接种，后来证明这个男孩对天花具有了保护力。vaccine（疫苗）一词来自拉丁文*vacca*，即母牛。19世纪80年代，巴斯德（Louis Pasteur）以鸡霍乱、炭疽和狂犬病减毒疫苗推广了这一原理，并为纪念詹纳将它们命名为疫苗。1890年，贝林（Emil von Behring）和北里柴三郎引入了抗毒素血清疗法；20世纪20年代，Gaston Ramon研制了类毒素和第一批佐剂。

WHO强化天花根除规划采用监测和环形接种，1977年在索马里出现了最后一例自然病例，1980年宣布天花被根除。1975年，克勒（Georges Köhler）和米尔斯坦（César Milstein）制成第一批产生单克隆抗体的杂交瘤（1984年诺贝尔奖）。考里科（Katalin Karikó）和韦斯曼（Drew Weissman）发现修饰mRNA中的核苷可减少其对固有感受器的激活，这一工作使mRNA疫苗成为可能，并获得2023年诺贝尔奖。
:::

## 后续内容

疫苗接种项目及其人群效应见[[public-health/vaccination-programmes]]和[[public-health/communicable-disease-control]]，儿童免疫程序见[[paediatrics/immunisation]]。免疫抑制药物的药理学在[[pharmacology/adverse-reactions]]以及使用这些药物的各器官系统课程中讨论。

::: summary
- 被动免疫输入抗体，提供即时、暂时的保护；主动免疫诱导记忆。暴露后两者常联合使用（乙型肝炎、破伤风、狂犬病）。
- 疫苗平台包括减毒活疫苗、灭活疫苗、亚单位和病毒样颗粒疫苗、类毒素、多糖和结合疫苗、病毒载体疫苗和mRNA疫苗。活疫苗产生强而广泛的免疫，但禁用于严重免疫抑制者和孕妇。
- 佐剂提供固有危险信号；结合使婴儿能为多糖招募T细胞辅助。
- 接种程序反映免疫学：有最短间隔的致敏和加强，避开母体抗体的时机安排，以及通过孕期母体接种以IgG保护新生儿。
- 群体免疫阈值$p_c = 1 - 1/R_0$；临界覆盖率$V_c = (1 - 1/R_0)/E$。麻疹需要约95%的两剂覆盖率。
- 大多数疫苗不良事件属于反应原性；真正的禁忌证很少。监测系统发现罕见事件，确定因果关系需要比较发生率，而不是依靠个案。
- 单克隆抗体中和细胞因子、阻断受体、清除细胞、递送毒素或桥接细胞；其感染风险与靶点相应（抗TNF与结核、利妥昔单抗与乙型肝炎、C5抑制剂与脑膜炎球菌、那他珠单抗与PML）。
- 使用生物制剂前筛查潜伏感染并更新疫苗接种；活疫苗在免疫抑制之前而不是期间接种。
:::

## 习题

::: exercise 群体免疫阈值 {level=1 check="1 - 1/4"}
某感染的$R_0 = 4$。人群中必须有多大比例具有免疫力才能阻止持续传播？以小数作答。
::: solution
$p_c = 1 - 1/4 = 0.75$，即人群中75%必须具有免疫力。
:::
:::

::: exercise 是不是活疫苗？ {level=1}
把下列疫苗分为减毒活疫苗或非活疫苗：(a) BCG；(b) 婴儿六联疫苗；(c) 轮状病毒疫苗；(d) HPV疫苗；(e) 重组带状疱疹疫苗；(f) 黄热病疫苗。
::: solution
(a) 活疫苗。(b) 非活疫苗（类毒素、无细胞百日咳、灭活脊髓灰质炎、Hib结合疫苗和乙肝表面抗原）。(c) 活疫苗（口服）。(d) 非活疫苗（病毒样颗粒）。(e) 非活疫苗（含AS01佐剂的重组糖蛋白E）。(f) 活疫苗。
:::
:::

::: exercise 疫苗有效率 {level=1 check="1 - 0.02/0.2"}
在一次疫情中，接种者的罹患率为2%，未接种者为20%。疫苗有效率为$1 - (\text{接种者罹患率})/(\text{未接种者罹患率})$。以小数计算。
::: solution
$1 - 0.02/0.20 = 1 - 0.1 = 0.9$，即90%。注意，在高接种率人群中，许多病例仍可能出现在接种者中，仅仅因为他们占多数；有效率取决于发生率，而不是病例中所占的份额。
:::
:::

::: exercise 临界覆盖率 {level=2 check="(1 - 1/10)/0.9"}
某感染的$R_0 = 10$，疫苗预防感染的有效率为90%。需要多高的接种覆盖率才能达到群体免疫阈值？给出未取整的小数并评论结果。
::: solution
$V_c = (1 - 1/10)/0.9 = 0.9/0.9 = 1$。需要100%的覆盖率，这在实践中无法实现。如果疫苗有效率稍低或$R_0$更高，即使人人接种也无法实现群体免疫。对于此类感染，疫苗仍能保护接种者个人，但要消除疾病需要更有效的疫苗或其他措施。
:::
:::

::: exercise 为何给婴儿接种肺炎球菌结合疫苗 {level=2}
一位母亲问，为什么她1岁的孩子接种的是覆盖血清型较少的肺炎球菌结合疫苗，而孩子的曾祖母接种的却是覆盖23种血清型的多糖疫苗。解释其免疫学原因。
::: solution
单纯多糖抗原无需T细胞辅助就能激活B细胞。约2岁以下的儿童对这类T细胞非依赖性抗原应答很差，因为其边缘区B细胞尚未成熟，所以23价多糖疫苗不能保护婴儿。把每种多糖结合到载体蛋白上，可使多糖特异性B细胞获得载体特异性T细胞的辅助，即使在婴儿期也能产生经过类别转换的高亲和力抗体和记忆。结合在技术上要求更高，因此结合疫苗覆盖的血清型较少，选择的是引起侵袭性疾病最常见的那些。结合疫苗还能减少所含血清型在鼻咽部的携带，从而通过群体效应保护未接种者（包括祖辈），尽管其他血清型会随时间部分取而代之。新一代结合疫苗覆盖更多的血清型。
:::
:::

::: exercise 使用利妥昔单抗之前 {level=2}
一名50岁男性即将因类风湿关节炎开始使用利妥昔单抗。应筛查哪些感染？应在何时提供哪些疫苗？为什么？
::: solution
**筛查。**乙型肝炎（HBsAg和抗-HBc）：利妥昔单抗清除B细胞，可引起致命的乙型肝炎再激活，包括已恢复的感染者（抗-HBc阳性），这些人可能需要抗病毒预防。丙型肝炎和HIV检测也是生物制剂治疗前的标准检查，通常还筛查潜伏结核。

**疫苗。**利妥昔单抗清除B细胞6至12个月，在此期间对疫苗的抗体应答很差。因此非活疫苗（肺炎球菌、每年的流感疫苗、按推荐接种的COVID-19疫苗、符合条件时的重组带状疱疹疫苗）最好在首次输注前至少2周、最好更早接种。治疗期间及之后一段时间内按《绿皮书》避免活疫苗。家庭接触者应接种疫苗。

**原因。**利妥昔单抗治疗后的保护主要依赖治疗前已有的记忆和抗体；长寿浆细胞不表达CD20，会继续产生已有的抗体，但在B细胞恢复之前无法产生新的应答。
:::
:::

::: exercise 解读疫苗应答 {level=3}
一名34岁医护人员接种了三剂乙肝疫苗。第三剂后2个月测得抗-HBs为4 mIU/mL。(a) 这意味着什么？(b) 哪些因素与应答差相关？(c) 接下来应怎么做？
::: solution
(a) 全程接种后1至2个月抗-HBs低于10 mIU/mL，意味着她是**无应答者**（或低应答者），不能认为她受到了保护。

(b) 应答差与年龄较大、男性、肥胖、吸烟、慢性肾脏病、糖尿病、免疫抑制以及某些HLA型（某些HLA II类等位基因提呈乙肝表面抗原肽的能力差）相关。未确诊的慢性乙型肝炎感染也会造成表面上的无应答，因为病毒产生过量的表面抗原，与抗体结合。

(c) 应检测HBsAg和抗-HBc以排除现症或既往感染。若均阴性，再接种一个疗程（常换用不同或免疫原性更强的疫苗），并复查抗-HBs。如果仍然无应答，就按易感者处理：任何有意义的暴露后都需要注射乙型肝炎免疫球蛋白（被动免疫）。这遵循《绿皮书》和职业健康指南。
:::
:::

::: exercise 设计一种疫苗 {level=3}
运用本课程的原理解释，为什么研制有效的破伤风和麻疹疫苗比研制结核或HIV疫苗容易得多。
::: solution
**破伤风和麻疹**具有有利于疫苗接种的特点。破伤风完全由单一毒素致病，针对它的中和性IgG抗体（由类毒素诱导）足以提供保护；存在明确的保护相关指标。麻疹病毒的表面蛋白稳定，抗原变异很少，自然感染产生终身免疫（说明免疫是可以实现的），中和抗体加T细胞能预防感染；减毒活疫苗再现了自然的免疫应答。

**结核**是巨噬细胞内的胞内感染，主要由Th1细胞、γ干扰素和肉芽肿而非抗体控制，自然感染也不能可靠地防止再感染。没有公认的保护相关指标，因此候选疫苗必须在大规模、长期的试验中检验。BCG能保护幼儿免患严重的播散型结核，但对成人肺结核的保护效果不一。

**HIV**序列多样性极大，在每个人体内都迅速突变；其包膜蛋白高度糖基化并有构象遮蔽，因此广谱中和抗体罕见，且只在多年的亲和力成熟后才出现；它整合进宿主基因组，在数天内建立潜伏储存库；它还感染协调免疫应答的CD4 T细胞。没有人能自然清除HIV，因此没有可供模仿的保护性免疫的天然模型。目前的研究目标是引导生发中心经历产生广谱中和抗体所需的多轮亲和力成熟。
