疫苗是人类部署过的最具成本效益的医学技术、而免疫治疗是同一门科学最新的半个世纪：**两者都在操纵身体优先安排哪些免疫应答——疫苗针对选定的目标教出保护性的记忆、变应与自身免疫的治疗教出克制、而肿瘤的免疫治疗松开克制——所以本章教佐剂与保护的对应物、规划的设计与犹豫、及治疗性免疫调节的工具箱。**

本章涵盖疫苗的免疫学与平台、规划的交付与犹豫、不良事件的推理、变应原与自身免疫的耐受治疗、及肿瘤免疫治疗与一般内科的接口。

## 疫苗的科学

::: definition 疫苗如何起作用 {#def-vaccine}
**疫苗在免疫学上的工作（长期中和抗体的诱导、带生发中心的选择与滤泡辅助T细胞、及决定生发中心持续时间的质量、及使继发应答快速——即使抗体衰减——的记忆B与T细胞架构、及黏膜免疫的问题、及“路径很重要”的肠外对活口服对鼻内疫苗的教训——[[immunology/adaptive-responses]]、[[immunology/antigen-recognition]]）；带其免疫签名的平台目录减毒活疫苗、带它们的复制与广泛的抗原展示、及CD8与黏膜的应答、及一两剂的优雅、及它们的排出与妊娠及免疫缺陷的警诫——麻疹与水痘及黄热及轮状病毒及麻腮风家族的活疫苗、及反向遗传学的减毒方法、及它们来源的历史伦理——至今仍被教在伦理课上；与灭活/亚单位/裂解疫苗、带它们对佐剂的依赖与2型偏向的危险（增强性呼吸道疾病的历史、带福尔马林灭活疫苗的时代、及最初呼吸道合胞病毒F蛋白疫苗的失败、及登革热疫苗按血清状态的增强教训——[[respiratory/respiratory-infections]]、[[infectious-diseases/tropical-infections]]）；结合多糖的革命、把非T依赖转为T依赖的记忆、用于肺炎球菌与脑膜炎球菌及b型流感嗜血杆菌、及母体接种的抗体转移策略（呼吸道合胞病毒的母体疫苗与妊娠期的百日咳逻辑、带Fc受体的转移算术——[[obstetrics-gynaecology/pregnancy-complications]]、[[paediatrics/immunisation]]）；载体与核酸的平台（腺病毒载体带转基因的表达与抗衣壳免疫、及那个罕见的伴血小板减少的血栓综合征、带血小板活化因子抗体激动机制与肝素的两难、及信使核糖核酸脂质纳米颗粒、带它先天刺激的与设计可调的特点、及冷链、及年轻男性的心肌炎风险被量化、及历史上最快的平台响应、及带新佐剂的蛋白亚单位（AS01与Matrix-M及CpG 1018谱系、带它们反应性的代价、及人乳头瘤病毒那病毒样颗粒几何学递呈抗原之美、及重组带状疱疹糖蛋白E带AS01、及纳米颗粒展示与嵌合纳米颗粒及计算设计的蛋白疫苗时代）——广谱中和抗体疫苗的失败与抗体输注的试验见[[infectious-diseases/hiv]]、序列设计的流程见[[genetics/genomic-medicine]]）；及测量的问题保护的对应物、及在存在对应物时以血清学桥接试验滴定到保护——麻疹与风疹及乙肝的数字——对比在不存在时用保护作为终点指标的试验、及为毒株更新的免疫桥接、及衰减对持续对疾病严重度保护这三者的区分T细胞的保护持续比抗体阻止感染更久、这正是“重症”成为诚实终点的原因——[[epidemiology-ebm/measuring-disease]]。**

::: definition 人群中的疫苗 {#def-programme}
**规划的机制（日程设计的逻辑——母体抗体的干扰窗口、及基础免疫加加强、及青少年与成人及妊娠期及高龄的加强时段、及针对母婴传播疾病的出生剂次（乙肝出生剂次的证据与母婴阻断的包——[[infectious-diseases/hiv]]、[[obstetrics-gynaecology/pregnancy-complications]]）；覆盖度的架构——冷链与多剂次西林瓶的政策及浪费及接种场次规划、及微观规划与5岁以下及学校及工作场所及药房及产科的接种点、及默认的预约提醒与常备医嘱及护士主动接种、及国家的接种信息系统及记录质量及互操作、带绝不能靠记忆的补种算法）——[[public-health/vaccination-programmes]]、[[clinical-skills/records-handover]]；人群的效果群体免疫阈值、及异质性、及传播与疾病的对应物、及型别替换与血清型漂移的现实（每次结合疫苗引入后的肺炎球菌血清型生态、及覆盖度的地区差异导致未接种者聚集而漏出——欧洲与也门及索马里的麻疹暴发、及区域消除地位的侵蚀——[[public-health/determinants-inequalities]]）；经济学与政策儿童规划的成本效益、及肺炎球菌与轮状病毒及人乳头瘤病毒及麻腮风的动态传播模型、及技术评估机构（联合免疫接种委员会与国家卫生与临床优化研究所及全球疫苗安全咨询委员会及免疫战略咨询专家组、它们的咨询流程与证据分级值得了解、及决定谁能及时得到下一支疫苗的采购与共融资架构、及分级的定价辩论——[[public-health/health-systems-economics]]、[[public-health/global-health]]）；及需求侧从“不方便”到“拒绝”的疫苗犹豫谱、带接种专特的原因——对机构的信任、及那篇被撤稿的欺诈性自闭症论文的持续阴影（一个撤稿的论文与它的媒体生命周期至今仍造成麻疹死亡的教训、及信任与方便及自满的模型、及风险感知的不对称——自愿时疫苗的损害被放大、而成功时疾病的风险不可见——[[medical-ethics-law/justice-resources]]、[[public-health/prevention-promotion]]）。**

## 治疗性地调节免疫

::: definition 不良事件、变应原与自身免疫的治疗 {#def-adverse}
**不良事件的推理接种前对接种后巧合的规则、与时机的窗口、按病例定义、及因果的框架不良事件随访的因果评估、及“生物学合理性”对“人群信号”的角色、及真实存在的综合征、带它们的机制与真实的发生率——带聚乙二醇及聚山梨酯及明胶赋形过敏分层的过敏性休克、及晕厥与青少年跌倒造成的伤害、通过坐15分钟管理、并且绝不站着接种、及信使核糖核酸疫苗后的心肌炎、按年龄性别剂次间隔的量化、对比感染造成的心肌炎、及上述的伴血小板减少的血栓综合征、及格林-巴利、在流感与新冠疫苗及感染之间并列计数、及伴佐剂的疫情流感疫苗后的发作性睡病流行病学、带一个抗体交叉反应的假说、及肠套叠与轮状病毒疫苗、按产品与剂次时机、及因技术造成的肩部注射损伤；及并不存在的综合征（麻腮风自闭症的欺诈与其诉讼与调查的尾声、铝佐剂的大纤维性肌炎的主张、及作为诊断垃圾桶的辅助剂诱发的自身炎症综合征、用把它们关掉的流行病学方法一并复习（基于登记表的对照与自身对照的病例系列设计）——[[epidemiology-ebm/observational-studies]]、[[clinical-skills/patient-safety]]）；报告与补偿的系统（自发报告及其低报的数学、及信号检测对假说检验的区分、及与登记链接的主动监测、及无过错补偿方案的比较、带它们在公平对诉讼之间的取舍）——[[clinical-skills/patient-safety]]、[[public-health/communicable-disease-control]]；及诱导耐受的治疗变应原的免疫治疗、带皮下及舌下及口腔含片的途径、及它的机制——封闭性IgG4与调节性T及效应细胞的耗竭、及皮肤试验反应性的降低、及3年后的疾病修饰、及它的过敏性休克安全系统——见[[immunology/hypersensitivity]]与[[immunology/tolerance-regulation]]；自身免疫病的生物制剂及其感染与接种及恶性肿瘤的邻近、已在[[immunology/autoimmunity]]讨论；及抗原专特耐受的管线1型糖尿病与多发性硬化及乳糜泻中的DNA及多肽及纳米颗粒的抗原专特方案、及耐受性树突细胞与微囊化细胞的临床测试、带那个让这个领域保持谦逊的、诚实的失败史——[[immunology/tolerance-regulation]]。**

::: definition 一般内科门诊中的肿瘤免疫治疗 {#def-cancer}
**检查点抑制剂作为一般内科的责任（药物的清单与适应证的广度——PD1/PD-L1及CTLA4及LAG3的抗体、跨越黑色素瘤与肺及肾及头颈及霍奇金及微卫星高度不稳定的癌症——及按器官的免疫相关不良反应综合征、带分级与激素节约的升级、及内分泌的永久性、及心肌炎与神经病变的“罕见但致命”的模式——见[[immunology/tolerance-regulation]]、[[immunology/autoimmunity]]、[[gastrointestinal/bowel-disease]]、[[respiratory/interstitial-vascular-disease]]、[[endocrine/hypothalamus-pituitary]]）；细胞治疗与抗体的患者来到其他科室（嵌合抗原受体T与双特异性患者出院后的现实——长期的血细胞减少与低丙种球蛋白血症及感染预防及免疫球蛋白及疫苗重启、及第二原发T细胞恶性肿瘤的报告、及落在非专科身上的妊娠与生育及驾驶与工作的问题、及重症监护与急诊对晚期细胞因子释放与神经毒性及噬血样毒性的识别——[[immunology/immunodeficiency]]、[[emergency-critical-care/critical-care]]）；及治疗性疫苗的接口个体化的新抗原信使核糖核酸疫苗联合检查点阻断、及带佐剂的癌症疫苗的失望史、及树突细胞治疗、及用于膀胱的卡介苗灌注最古老的成功免疫治疗、仍在泌尿科的常规使用、及它在穿孔时的脓毒症风险——[[pathology/cancer-diagnosis]]。**

::: example 一次疫苗反应的少年 {#ex-myocarditis}
一名17岁少年接种第二剂信使核糖核酸疫苗、3天后出现中心性胸痛与心悸；心电图显示轻度ST段抬高、肌钙蛋白480、超声心动正常；他血流动力学稳定。他的父母想知道是否是疫苗引起的、以及他是否该接种第三剂。
::: solution
**接种后的心肌炎——因果、风险的算术与诚实（[[#def-vaccine]]、[[#def-adverse]]）：这个病例——典型的“年轻男性、第二剂后、短间隔”表型来自监测的绝对风险、带感染后心肌炎的数字作为对照、总体上在感染后更高且常常更重、及常见的轻病程与保留的心室功能、及运动的暂停与恢复的协议、与心血管及运动医学3-6个月的限制、及心脏磁共振与恢复的记录——[[cardiovascular/circulation-blood-pressure]]；沟通——把“时间的关联”对“因果”解释得平实脂质纳米颗粒反应的生物学合理性、及年龄性别的信号、及机制上的不确定、及把一个真实但小的风险与在下一波中不接种的风险相权衡、及个体自主的定框、留出让家庭价值发言的空间；及未来剂次的决定——复发风险的数据、及延长间隔与更换平台的考虑、及书面的共享决定、及向国家的不良事件系统上报、及若症状持续的转诊路径心包性疼痛与劳力性呼吸困难及心悸、及休息期对学期体育与考试的含义、提前主动处理——[[clinical-skills/patient-safety]]、[[public-health/vaccination-programmes]]、[[paediatrics/adolescent-health]]。**

::: example 病房里发热的未接种儿童 {#ex-measles-ward}
一名8月龄未接种的婴儿因发热、卡他症状与皮疹收入院；母亲提到“社群里在传麻疹”。病房里还有3名其他婴儿与2名怀孕的员工。
::: solution
**急性儿科病房中的疑似麻疹——感染控制即临床照护（[[#def-programme]]、[[paediatrics/immunisation]]、[[infectious-diseases/healthcare-infections]]）：即时的行动——一有怀疑就隔离、员工戴过滤颗粒面罩、儿童若能耐受则戴外科口罩、有负压房间则用、立即通知感染控制与公共卫生、停止病房的流动、并启动一次病房事件、以及诚实地向家长解释为什么要关门与戴口罩——[[public-health/communicable-disease-control]]；暴露的矩阵——传染期出疹前4天到出疹后4天对着员工与患者的记录映射按本地政策的两剂接种或出生世代的免疫、及免疫球蛋白M与聚合酶链及基因型的采样、及暴露的非免疫者的管理：符合条件的接触者72小时内接种麻腮风、及婴儿与孕妇及免疫缺陷者在6天内用人免疫球蛋白、及自出疹后第5天前停止上学与工作、及继发攻击率与法定报告率——[[public-health/vaccination-programmes]]；期间的临床照护——麻疹的并发症中耳炎与肺炎及喉气管炎及腹泻及低白蛋白及低钠、及数十年后的亚急性硬化性全脑炎的咨询、及两剂维生素A的证据——[[paediatrics/acute-childhood-illness]]、[[gastrointestinal/clinical-nutrition]]；及系统的学习——这次事件所暴露的接种状态记录的质量、及员工免疫的检测与补种政策、及社群聚集点的伙伴合作健康访视员与校医及难民健康服务的外展、及事件后的复盘、因为麻疹的控制主要是在公众关注下的团队合作——[[clinical-skills/patient-safety]]、[[public-health/determinants-inequalities]]。**

::: example 需要卡介苗的婴儿与用英夫利西单抗的母亲 {#ex-infant-vaccine}
在结核高发病率地区、一名母乳喂养的6周龄婴儿需要接种卡介苗；母亲因克罗恩病在妊娠晚期全程使用了英夫利西单抗；全科医生在休假、而儿童健康门诊询问是否继续进行卡介苗与常规疫苗。
::: solution
**被生物制剂暴露婴儿的接种（[[#def-vaccine]]、[[immunology/tolerance-regulation]]、[[paediatrics/immunisation]]）：机制——英夫利西单抗一种抗肿瘤坏死因子的免疫球蛋白G1主要在20周后经胎盘主动转运、所以新生儿体内的药物水平会持续数月半衰期与婴儿代谢的数字、及在活疫苗之前建议的回避窗口——对抗肿瘤坏死因子暴露的婴儿通常是6个月、视产品与本地政策而定、及“母乳转移极微”的区别口服生物利用度低了十亿分之一、保护了被喂养的婴儿——[[gastrointestinal/bowel-disease]]；适用的规则——避免活疫苗的清单这里是卡介苗与轮状病毒——轮状病毒的规划政策各国不同、有的继续有的推迟、所以要引用本地的方案而不是猜、及接触者使用吸入与鼻内活疫苗的问题、及可以放心给的灭活清单整个常规日程照常进行、及在不确定病例中、在接种卡介苗之前测药物水平或抗药物抗体的选项、与专科的决定；及规划的课程——生物制剂暴露婴儿中播散性卡介苗的病例集合改变了全世界的指南——[[infectious-diseases/tuberculosis]]——及一张写明的6个月计划卡、带补种的日程与谁在何时给什么、及“妊娠期继续使用药物是有益的”的定框、好让母亲下次不再被说服停掉有效的治疗、及妊娠用药登记的参与、及助产士与新生儿科及接种团队的沟通链条、让这个决定在6周而不是6个月做出——[[obstetrics-gynaecology/pregnancy-complications]]、[[clinical-skills/records-handover]]。**

::: example 养老院的流感疫苗之问 {#ex-care-home}

::: summary
- 疫苗靠买下生发中心的时间起作用：佐剂、平台与日程都是控制这段教育的质量与持续时间的方式。
