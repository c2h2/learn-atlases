移植和癌症给免疫系统提出了相反的问题。在移植中，免疫应答是敌人：来自另一个人的肾脏是外来组织，不加治疗的话，受者的T细胞和抗体会摧毁它。目标是抑制或避开这一应答，同时又不让患者对感染毫无防御。在癌症中，免疫应答是盟友，但肿瘤由自身构成，并已进化出逃避免疫的能力。目标是增强或重新引导应答，同时又不释放自身免疫。

两个领域建立在同样的科学之上：MHC分子及其被T细胞识别（[[immunology/antigen-recognition]]），共刺激和抑制性受体（[[immunology/adaptive-responses]]、[[immunology/tolerance-regulation]]）。用来阻止排斥的药物与用来治疗癌症的药物互为镜像：一类阻断钙调神经磷酸酶或共刺激，另一类阻断CTLA-4和PD-1。本章先讲移植，再讲肿瘤免疫学和免疫治疗。

## 移植物为何被排斥

从一个人身体的一处移植到另一处（**自体移植物**）或来自同卵双生子（**同基因**移植物）的移植物会被接受。来自同一物种中遗传背景不同的个体的移植物（**同种异体移植物**）会被排斥，除非免疫应答受到抑制。来自另一物种的移植物（**异种移植物**）被排斥得更加剧烈。

主要靶标是供者的**HLA分子**，在这一情境下称为**同种抗原**。ABO血型抗原既表达于红细胞也表达于内皮，同样重要；次要组织相容性抗原（来自其他蛋白的多态性肽）尤其在干细胞移植中起作用。

T细胞对外来HLA的应答异常强烈。一个人全部T细胞中约有1%至10%会对某一外来HLA型发生应答，而对普通微生物肽的应答细胞或许只有$10^5$分之一。原因在于T细胞在胸腺中被选择为能微弱识别自身HLA；其中许多会与携带自身肽的外来HLA分子发生强烈交叉反应，因为后者类似于自身HLA加外来肽。

::: definition 同种异体识别的途径 {#def-allorecognition}
- **直接同种异体识别**：受者T细胞识别**供者**抗原提呈细胞（随移植物带入的过客树突状细胞）上完整的供者HLA分子。由于应答的T细胞非常多，这一途径驱动移植后早期的**急性**排斥。随着供者树突状细胞消失，它逐渐减弱。
- **间接同种异体识别**：**受者**抗原提呈细胞摄取供者HLA蛋白，像处理任何外来蛋白一样，把其肽提呈在受者MHC上。这一途径在移植物的整个存活期持续存在，为**供者特异性抗体**的产生提供辅助，并参与**慢性**排斥。
:::

### HLA配型与交叉配型

肾移植的配型集中于**HLA-A、HLA-B和HLA-DR**，错配等级从0（无错配，“000”）到6（三个位点各两个错配，“222”）。错配越少，移植物长期存活越好，尤其是HLA-DR。由于每个人从父母双方各继承一个HLA单倍型，一个同胞与患者HLA完全相同的概率为四分之一。

**致敏**指存在针对HLA的抗体。它源于通过**妊娠**、**输血**或**既往移植**接触外来HLA。致敏受者如果接受了带有其抗体所识别HLA型的肾脏，就面临即刻抗体介导排斥的风险。因此移植前要用包被单个HLA抗原的微珠筛查受者血清（检测**供者特异性抗体**，DSA），并进行**交叉配型**：直接交叉配型（用受者血清检测供者淋巴细胞）或虚拟交叉配型（将抗体谱与供者HLA型比较）。交叉配型阳性通常意味着不能进行移植。高致敏患者要等待长得多的时间才能得到相容的器官。

::: example 想要捐肾的丈夫 {#ex-sensitised}
一名39岁女性因IgA肾病导致肾衰竭，她与丈夫育有三次妊娠，末次分娩后接受过输血。血型相容的丈夫愿意捐出一个肾。她的抗体筛查显示针对HLA-B7和HLA-DR15的强抗体，而她丈夫恰好携带这两种抗原，与丈夫细胞的交叉配型阳性。解释她为何有这些抗体，以及还有哪些选择。
::: solution
**原因。**每次妊娠期间，尤其在分娩时，携带丈夫HLA（由孩子遗传）的胎儿细胞和碎片进入了她的血液循环。这些父源HLA分子对她来说是外来的，她产生了针对它们的IgG抗体；输血进一步增加了与外来HLA的接触。长寿浆细胞和记忆B细胞维持着这些抗体。来自丈夫的肾脏会带有同样的HLA-B7和HLA-DR15，预存抗体会立即结合移植物内皮，有发生超急性或早期抗体介导排斥的风险。交叉配型阳性证实了这一点。

**选择。**英国活体肾脏共享计划允许不相容的供–受者配对与其他配对交换供者，于是她丈夫可以把肾捐给与他相容的人，而她接受一位其HLA不被她的抗体识别的供者的肾。她仍留在尸体供肾等待名单上，高致敏状态会给她一定的优先权。在专科中心，经脱敏（血浆置换、静脉注射免疫球蛋白和针对B细胞的治疗以降低抗体水平）后进行抗体不相容移植也是可能的，但排斥风险更高。具体选择由移植团队与她共同决定。
:::

## 排斥的类型

::: definition 同种异体移植排斥的类型 {#def-rejection}
- **超急性排斥**发生在数分钟至数小时内。它由受者体内针对供者ABO抗原或HLA的**预存抗体**引起，这些抗体结合移植物内皮，激活补体，使移植物血管内形成血栓。它无法治疗，因此通过ABO配型和交叉配型来预防；现在已很罕见。
- **急性T细胞介导排斥**通常发生在最初数周至数月，但可发生在任何时候，尤其在免疫抑制减少时。受者T细胞浸润移植物；在肾脏中它们侵入肾小管（**肾小管炎**）和间质，严重时侵入动脉。通常对加强免疫抑制（如糖皮质激素冲击）有反应。
- **抗体介导排斥**由供者特异性抗体结合内皮引起。活检显示小血管炎症（肾小球炎、管周毛细血管炎），常有补体片段**C4d**在管周毛细血管沉积。它可以是急性或慢性的，较难治疗。
- **慢性排斥**在数月至数年中发展，是晚期移植物丢失的主要原因。它主要由抗体和间接同种异体识别介导，引起进行性瘢痕形成和动脉狭窄（**移植物血管病**）：在肾脏为间质纤维化和移植肾肾小球病，在心脏为心脏移植物血管病，在肺为闭塞性细支气管炎。
:::

不同器官引起排斥的强度不同。**肝脏**相对耐受：可以跨越阳性交叉配型移植，患者往往需要较少的免疫抑制。**角膜**无血管且有免疫豁免，因此角膜移植通常不做HLA配型。**小肠**、**肺**和**皮肤**的免疫原性很强。

## 免疫抑制

免疫抑制治疗分两个阶段。移植时的**诱导**治疗在排斥风险最高时给予强力抑制：标准风险受者用IL-2受体抗体如**巴利昔单抗**，高风险受者用淋巴细胞清除剂如**阿仑单抗**（抗CD52）或**抗胸腺细胞球蛋白**。随后的**维持**治疗贯穿移植物的整个存活期，通常联合作用于T细胞激活不同步骤的药物。

::: theorem 维持免疫抑制针对三个信号 {#thm-immunosuppression}
| 药物类别 | 例子 | 靶点 | 主要不良反应 |
|---|---|---|---|
| 钙调神经磷酸酶抑制剂 | 他克莫司、环孢素 | 信号1：钙调神经磷酸酶–NFAT，因此IL-2不转录 | 肾毒性、高血压、移植后糖尿病、震颤、高钾血症 |
| 抗增殖药 | 吗替麦考酚酯、硫唑嘌呤 | 增殖中淋巴细胞的DNA合成 | 骨髓抑制、胃肠不适；吗替麦考酚酯致畸 |
| 糖皮质激素 | 泼尼松龙 | 多种促炎基因 | 糖尿病、骨质疏松、体重增加、感染 |
| mTOR抑制剂 | 西罗莫司、依维莫司 | 信号3：IL-2驱动的增殖 | 伤口愈合不良、高脂血症、口腔溃疡、肺炎 |
| 共刺激阻断剂 | 贝拉西普 | 信号2：CD80/CD86 | EB病毒阴性受者中的移植后淋巴增殖性疾病 |

英国常用的肾移植方案联合他克莫司、吗替麦考酚酯和泼尼松龙，药物选择和目标浓度由移植中心确定。
:::

他克莫司和环孢素治疗窗窄，经**CYP3A4**代谢。抑制该酶的药物（克拉霉素、唑类抗真菌药、地尔硫䓬、西柚汁）可使血药浓度升至中毒范围，诱导剂（利福平、卡马西平、圣约翰草）则可使浓度降低并引起排斥。要监测血药浓度，给移植受者开任何新处方都应检查相互作用。

免疫抑制的代价可以从被抑制的内容推知：

- **感染**：第一个月主要是普通的手术和医院感染；第1至6个月是**巨细胞病毒**、**BK多瘤病毒**和肺孢子菌等机会性感染，这就是在此期间给予预防的原因；之后是社区感染，风险持续存在。
- **癌症**：通常受T细胞控制的病毒所驱动的癌症风险增加。皮肤**鳞状细胞癌**最常见，比普通人群多许多倍，由紫外线损伤以及可能的乳头瘤病毒驱动。**移植后淋巴增殖性疾病**（PTLD）通常由EB病毒驱动。卡波西肉瘤（HHV-8）和肛门生殖器癌（HPV）也增加。
- **药物毒性**，尤其是钙调神经磷酸酶抑制剂的肾毒性，可能被误认为排斥。

::: example 肾移植后肌酐上升 {#ex-bk}
一名49岁女性5个月前接受了尸体供肾移植。她服用他克莫司、吗替麦考酚酯和泼尼松龙。3周内肌酐从110升至165 µmol/L。她感觉良好。他克莫司浓度在目标范围内。血浆BK病毒PCR显示病毒载量高且在上升。可能的原因有哪些？如何鉴别？
::: solution
**鉴别诊断。**移植后5个月肌酐上升可能由急性排斥（T细胞介导或抗体介导）、**BK多瘤病毒肾病**、钙调神经磷酸酶抑制剂毒性、输尿管梗阻或狭窄、肾动脉狭窄、脱水、感染或原发肾病复发引起。

**BK线索。**大多数人在儿童期感染BK病毒，病毒潜伏于泌尿道。强力免疫抑制使其在移植肾小管细胞中再激活，造成肾小管损伤和炎症。移植后2至6个月血浆BK载量高且上升强烈提示BK肾病。

**鉴别方法。**超声排除梗阻。**移植肾活检**是关键检查。BK肾病显示肾小管细胞内病毒包涵体，SV40大T抗原免疫组化阳性；T细胞介导排斥显示肾小管炎而无病毒致细胞病变；抗体介导排斥显示微血管炎症，常有C4d染色和循环供者特异性抗体。

**为何重要。**两者的治疗相反。BK肾病的治疗是**减少**免疫抑制（常减少或停用吗替麦考酚酯），让T细胞控制病毒；急性排斥的治疗是**加强**免疫抑制。对BK肾病患者按推测的排斥给予激素冲击会加重感染。由于两者可以并存，且减少免疫抑制可诱发排斥，患者需由移植团队密切监测。
:::
:::

## 造血干细胞移植

在**造血干细胞移植**（HSCT）中，受者先接受化疗（加或不加放疗）“预处理”，然后其骨髓被供者干细胞替代。异基因HSCT用于治疗白血病、淋巴瘤、骨髓衰竭以及SCID和血红蛋白病等遗传性疾病。

在这里，免疫问题的方向反过来了。移植物带有一个供者免疫系统，而受者是靶标。

::: definition 移植物抗宿主病和移植物抗白血病 {#def-gvhd}
当异基因移植物中的供者T细胞把受者的HLA和次要组织相容性抗原识别为外来物并攻击受者组织时，就发生**移植物抗宿主病**（GvHD）。**急性GvHD**主要累及**皮肤**（斑丘疹，始于手掌和足底）、**肠道**（腹泻、腹痛）和**肝脏**（胆汁淤积性黄疸）。**慢性GvHD**类似自身免疫病，有皮肤硬化、眼干和口干、肺部疾病（闭塞性细支气管炎）和肝脏受累。

**移植物抗白血病**（GvL）效应是针对残留恶性细胞的同一过程：供者T细胞和NK细胞识别并杀伤受者的白血病细胞。这是异基因HSCT能治愈单靠化疗无法治愈的白血病的主要原因。
:::

这两种效应很难分开，因为两者都依赖供者T细胞识别受者抗原。去除移植物中的T细胞可减少GvHD，但会增加复发和植入失败。移植后**供者淋巴细胞输注**在白血病复发时有意增强GvL效应，代价是GvHD。HSCT的HLA配型比实体器官更严格，通常要求HLA-A、-B、-C、-DRB1和-DQB1相合（“10/10”相合），因为移植物含有免疫细胞。移植后给予环磷酰胺以清除同种反应性最强的T细胞，使**单倍体相合**供者（共享一个单倍型，通常是父母、子女或同胞）得以使用，这意味着现在几乎每位患者都有潜在的供者。

[[immunology/hypersensitivity]]中提到的输血相关GvHD是一种相关的、几乎总是致命的疾病，由输血中存活的淋巴细胞在无法排斥它们的受者体内植入引起。通过对高危受者的血液成分进行辐照来预防。

## 肿瘤免疫学

### 免疫监视与免疫编辑

免疫系统能防御癌症的想法由埃尔利希（Paul Ehrlich）于1909年提出，伯内特和Lewis Thomas在20世纪50和60年代将其发展为**免疫监视**假说。临床证据部分支持这一假说：移植后或HIV感染导致免疫抑制的人，癌症风险大大增加，尤其是病毒驱动的癌症。在许多实体瘤中，细胞毒性T细胞的密集浸润与更好的生存相关。

::: theorem 癌症免疫编辑 {#thm-immunoediting}
正在发展的肿瘤与免疫系统之间的相互作用可分为三个阶段：

1. **清除**：固有和适应性免疫系统发现并摧毁转化细胞。
2. **平衡**：存活下来的肿瘤细胞被免疫系统控制住，有时长达数年，同时不断积累新的突变。
3. **逃逸**：变得免疫原性差或具有免疫抑制性的肿瘤变异体生长，并在临床上显现。

一个在临床上出现的肿瘤按定义已经逃逸，因此其特性反映了免疫系统的选择。
:::

### 肿瘤抗原

T细胞能识别肿瘤，是因为肿瘤含有不同于正常组织的抗原：

- **新抗原**，由改变蛋白序列的体细胞突变产生。它们是真正的外来物，不受中枢耐受覆盖。突变多（**肿瘤突变负荷**高）的肿瘤，如黑色素瘤、吸烟相关肺癌和**错配修复缺陷**（dMMR，或微卫星高度不稳定，MSI-high）的癌症，新抗原更多，对检查点抑制剂反应更好；
- 病毒驱动癌症中的**病毒抗原**：宫颈癌和口咽癌中的HPV E6和E7，某些淋巴瘤和鼻咽癌中的EB病毒，肝细胞癌中的HBV和HCV，卡波西肉瘤中的HHV-8；
- **癌–睾丸抗原**，通常只表达于生殖细胞（生殖细胞缺乏MHC I类分子），在某些肿瘤中重新表达；
- 起源组织的**分化抗原**，如B细胞肿瘤上的CD19和CD20、黑色素瘤中的黑素细胞蛋白；以它们为靶点也会损伤同一谱系的正常细胞；
- **过度表达**的蛋白，如某些乳腺癌和胃癌中的HER2。

### 肿瘤如何逃逸

- **抗原提呈丧失**：HLA基因、β2微球蛋白或抗原加工机制的突变降低MHC I类分子表达，使肿瘤躲开CD8 T细胞（但可能使其暴露于NK细胞）。
- **抑制性配体**：肿瘤和浸润的髓系细胞表达**PD-L1**，常由攻击它们的T细胞所分泌的γ干扰素诱导，从而关闭PD-1阳性T细胞。
- **免疫抑制性微环境**：调节性T细胞、髓系来源抑制细胞和肿瘤相关巨噬细胞；TGF-β和IL-10等细胞因子；吲哚胺2,3-双加氧酶（IDO）和腺苷造成的代谢性抑制。
- **排斥在外**：某些肿瘤（“冷”肿瘤）的间质使T细胞根本无法进入。

## 癌症免疫治疗

### 检查点抑制剂

**免疫检查点抑制剂**是阻断T细胞上抑制性受体的抗体。**伊匹木单抗**（抗CTLA-4）于2011年被批准用于晚期黑色素瘤，抗PD-1抗体**帕博利珠单抗**和**纳武利尤单抗**于2014年获批；随后是**阿替利珠单抗**和**度伐利尤单抗**等抗PD-L1抗体。它们现已用于许多癌症，包括黑色素瘤、肺癌、肾癌、膀胱癌、头颈癌、霍奇金淋巴瘤以及任何部位的dMMR肿瘤，有时单用，有时与化疗联用，并越来越多地用于手术前后。

它们并不直接攻击肿瘤细胞，而是解除已识别肿瘤的T细胞所受的刹车，因此在新抗原多、原本就有T细胞浸润的肿瘤中效果最好。起效时，应答可持续多年。预测性生物标志物包括肿瘤或免疫细胞上的PD-L1表达、错配修复状态和肿瘤突变负荷，但没有一个是完美的。

由于它们普遍地解除耐受，检查点抑制剂会引起**免疫相关不良事件**（irAE），见[[immunology/tolerance-regulation]]。它们几乎可以累及任何器官：常见于皮肤、结肠、肝脏、肺、甲状腺、垂体和关节，罕见于心脏（心肌炎）、神经系统和胰岛。抗CTLA-4和联合治疗时更常见。ESMO等指南列出的一般原则是：早期识别，严重程度分级，排除感染等其他原因，对中重度事件暂停用药并开始糖皮质激素，对激素难治的病例进一步免疫抑制。甲状腺功能减退和垂体炎等内分泌irAE通常用激素替代处理，且常为永久性。

::: example 错配修复缺陷的癌症 {#ex-dmmr}
一名44岁女性患转移性结直肠癌。肿瘤检测显示错配修复蛋白MLH1和PMS2缺失（dMMR，MSI-high）。解释为什么这一结果使她适合检查点抑制剂治疗，以及它对其家人意味着什么。
::: solution
**免疫学推理。**错配修复纠正DNA复制过程中的错误。没有它，肿瘤细胞积累数以千计的突变，尤其是重复序列中的插入和缺失，造成读码框移位，产生全新的肽序列。其中许多作为**新抗原**被提呈在MHC I类分子上，被T细胞识别为外来物。因此dMMR肿瘤有大量T细胞浸润，而这些T细胞受到PD-1/PD-L1信号的压制。用帕博利珠单抗阻断PD-1可释放这些T细胞。在转移性dMMR结直肠癌中，KEYNOTE-177试验显示一线帕博利珠单抗比化疗改善了无进展生存，NICE推荐在此情况下使用。大多数结直肠癌错配修复功能正常，单用检查点抑制剂效果差。

**对家人的意义。**年轻人的dMMR结直肠癌可能由**林奇综合征**（一种遗传性错配修复基因变异）引起。MLH1缺失常由获得性MLH1启动子甲基化（在老年患者中常见）而非林奇综合征引起，因此下一步是检测MLH1启动子甲基化（或*BRAF* V600E），必要时再做胚系基因检测，并提供遗传咨询。被发现携带林奇变异的亲属将接受结肠镜监测和其他措施。见[[genetics/cancer-genetics]]。
:::
:::

### 工程化T细胞和抗体

**嵌合抗原受体（CAR）T细胞**是采集患者自身T细胞并经基因改造、使其表达人工受体的细胞。CAR把来源于抗体的结合结构域（例如识别B细胞上的**CD19**或骨髓瘤细胞上的**BCMA**）与CD3ζ信号结构域以及CD28或4-1BB等共刺激结构域结合在一起。CAR T细胞不受MHC限制地识别天然表面抗原，在患者体内扩增并杀伤靶细胞。第一种CAR-T疗法tisagenlecleucel于2017年在美国获批，用于复发的B细胞急性淋巴细胞白血病儿童和年轻成人。CAR-T疗法能治愈部分难治性B细胞白血病和淋巴瘤患者，并使骨髓瘤获得长期缓解。

其特征性毒性源于其机制：

- **细胞因子释放综合征**（CRS）：大规模T细胞激活释放IL-6和其他细胞因子，引起发热、低血压和低氧，通常发生在最初数天至两周内。用IL-6受体抗体**托珠单抗**治疗，必要时加用糖皮质激素。
- **免疫效应细胞相关神经毒性综合征**（ICANS）：意识模糊、言语障碍、癫痫发作和脑水肿。
- **靶向非肿瘤毒性**：CD19 CAR-T细胞摧毁正常B细胞，引起长期B细胞缺失和低丙种球蛋白血症，可能需要免疫球蛋白替代。

**双特异性T细胞衔接器**是有两个结合位点的抗体，一个结合T细胞上的CD3，另一个结合肿瘤抗原；**博纳吐单抗**（blinatumomab，CD19 × CD3）把任何T细胞与白血病细胞连接起来。针对肿瘤抗原的传统**单克隆抗体**，如**利妥昔单抗**（CD20）和**曲妥珠单抗**（HER2），通过ADCC、补体激活和阻断信号发挥作用（见[[immunology/vaccines-immunotherapy]]）。

::: example CAR-T治疗后发热 {#ex-crs}
一名58岁复发弥漫大B细胞淋巴瘤男性接受了靶向CD19的CAR-T细胞治疗。三天后体温39.5 °C，心率125次/分，血压88/50 mmHg，未吸氧时血氧饱和度92%。CRP和铁蛋白非常高。解释其机制和处理原则。
::: solution
**机制。**这最可能是**细胞因子释放综合征**。CAR T细胞遇到淋巴瘤细胞和正常B细胞上的CD19后被激活并迅速增殖，释放γ干扰素和其他细胞因子。这些因子激活巨噬细胞，后者释放大量**IL-6**和IL-1。IL-6引起发热、急性期反应（CRP和铁蛋白极高）、毛细血管渗漏、低血压和低氧。时间上在输注后数天，与CAR-T扩增相符。

**处理原则。**按严重程度（发热、低血压、低氧）对CRS分级，并依治疗中心的方案决定治疗。由于他在淋巴细胞清除化疗后处于中性粒细胞减少和免疫抑制状态，必须同时假定存在感染并予以治疗：血培养并立即给予广谱抗生素。补液和吸氧。有低血压和低氧时给予IL-6受体抗体**托珠单抗**，反应不足时加用糖皮质激素；可能需要转入重症监护使用血管活性药物。密切监测**ICANS**（定期进行神经系统评估，如简单的书写和命名测试），一旦发生用糖皮质激素治疗。现代处理已使CRS在大多数情况下可控，而不必消除抗肿瘤效应。
:::
:::

:::warning
不要以为免疫抑制患者会表现出通常的感染或排斥征象，也不要以为使用检查点抑制剂的患者“只是感染”或“只是副作用”。移植受者因使用激素，可能在严重感染时几乎不发热；使用检查点抑制剂的腹泻患者可能患艰难梭菌感染、免疫相关结肠炎或两者兼有。在这两种情况下，针对一种原因的治疗（加强或减少免疫抑制）都可能加重另一种，因此只要病情允许，就要先查明机制再治疗。
:::

::: history
第二次世界大战期间，梅达沃研究烧伤飞行员的皮肤移植，并在兔子身上证明来自同一供者的第二块移植物比第一块排斥得更快：排斥是一种有记忆的免疫应答。1954年，Joseph Murray在波士顿的团队在同卵双胞胎Ronald和Richard Herrick之间移植了肾脏，完全避免了排斥。20世纪60年代初由Roy Calne等人引入的硫唑嘌呤使非同卵供者之间的移植成为可能；20世纪70年代Jean-François Borel发现环孢素的免疫抑制作用，随后由Calne用于临床，在20世纪80年代初改变了移植结局。Murray与骨髓移植先驱E. Donnall Thomas分享了1990年诺贝尔奖。

19世纪90年代，纽约外科医生William Coley把细菌混合物（“Coley毒素”）注射到无法手术的肉瘤中，报告了一些消退，这是癌症免疫治疗早期的粗糙尝试。一个世纪后，James Allison在1996年证明阻断CTLA-4能使小鼠排斥肿瘤；本庶佑（Tasuku Honjo）的团队在1992年发现了PD-1，并证明了它作为抑制性受体的作用。两人分享了2018年诺贝尔奖。Zelig Eshhar及其同事在1989年描述了第一批嵌合抗原受体，这是CAR-T疗法的起点。
:::

## 后续内容

移植受者的临床诊疗见[[renal/chronic-kidney-disease]]和[[infectious-diseases/immunocompromised-host]]；血液系统移植见[[blood/leukaemia]]；癌症生物学见[[pathology/cancer-biology]]。针对致癌病毒的疫苗和治疗性抗体在[[immunology/vaccines-immunotherapy]]中讨论。

::: summary
- 同种异体移植物被排斥主要是因为HLA差异。许多T细胞（1%–10%）直接识别供者抗原提呈细胞上的外来HLA；受者细胞间接提呈供者肽，驱动供者特异性抗体和慢性排斥。
- 肾移植配型侧重HLA-A、-B和-DR；妊娠、输血或既往移植引起的致敏通过抗体筛查和交叉配型来发现。一个同胞HLA相同的概率为1/4。
- 排斥可为超急性（预存抗体，数分钟）、急性T细胞介导（肾小管炎；对激素有反应）、抗体介导（DSA、微血管炎症、C4d）或慢性（血管病和纤维化）。
- 维持免疫抑制联合钙调神经磷酸酶抑制剂、抗增殖药和激素，针对T细胞激活的各个信号。其代价是机会性感染（巨细胞病毒、BK病毒、肺孢子菌）、病毒驱动的癌症和药物毒性；他克莫司与CYP3A4抑制剂和诱导剂相互作用。
- 在HSCT中，供者T细胞引起GvHD（皮肤、肠道、肝脏），也产生有益的移植物抗白血病效应。
- 肿瘤通过新抗原、病毒抗原和其他肿瘤抗原被识别；它们通过丢失MHC I类分子、表达PD-L1和营造抑制性微环境而逃逸（免疫编辑）。
- 检查点抑制剂（抗CTLA-4、抗PD-1、抗PD-L1）在dMMR癌症等新抗原多的肿瘤中效果最好，并引起免疫相关不良事件。
- CAR-T细胞和双特异性衔接器把T细胞重新引向CD19和BCMA等表面抗原；细胞因子释放综合征（IL-6，用托珠单抗治疗）、神经毒性和B细胞缺失是其典型毒性。
:::

## 习题

::: exercise 计算错配数 {level=1 check="3"}
受者分型为HLA-A1、A2；B8、B44；DR3、DR4。供者分型为HLA-A1、A3；B8、B7；DR4、DR15。HLA-A、-B和-DR共有多少个错配（计算受者没有的供者抗原）？
::: solution
A：供者A1（受者有）和A3（受者没有）：1个错配。B：B8（有）和B7（没有）：1个错配。DR：DR4（有）和DR15（没有）：1个错配。合计3个，即“111”错配。
:::
:::

::: exercise 同胞作为供者 {level=1 check="1 - (3/4)^3"}
一名白血病患者有三个全同胞。假设独立遗传且不发生重组，至少一个同胞HLA相同的概率是多少？给出精确值或小数。
::: solution
某一同胞不相同的概率为$3/4$，因此三个都不相同的概率为$(3/4)^3 = 27/64$。至少一个相同的概率为$1 - 27/64 = 37/64 \approx 0.578$。
:::
:::

::: exercise 说出排斥类型 {level=1}
说出下列各例最可能的排斥类型：(a) 手术室中再灌注后数分钟内肾脏变暗并出现斑驳；(b) 3周时肌酐上升，活检显示肾小管炎；(c) 心脏移植10年后，血管造影显示冠状动脉弥漫性同心性狭窄。
::: solution
(a) 超急性排斥，由预存的抗供者抗体引起（由于交叉配型，现已非常罕见）。(b) 急性T细胞介导排斥。(c) 慢性排斥：心脏移植物血管病。
:::

::: exercise 新开的抗生素 {level=2}
一名服用他克莫司的心脏移植受者因胸部感染被非工作时间值班医生开了克拉霉素。五天后她因震颤、意识模糊、高钾血症和急性肾损伤入院。解释其机制以及本可如何预防。
::: solution
克拉霉素是**CYP3A4**（以及P-糖蛋白）的强抑制剂，而这两者是他克莫司代谢和外排的主要途径。她的他克莫司浓度会大幅升高，造成毒性：神经毒性（震颤、意识模糊）、入球小动脉收缩所致的肾毒性以及高钾血症。预防方法包括：开处方前检查相互作用（用相互作用查询工具或BNF）；选择无相互作用的抗生素，如在合适时用阿莫西林或多西环素；如果必须用克拉霉素，则与移植团队商量减少他克莫司剂量，并在数天内复查浓度。应告诉移植受者向任何开处方的医生说明自己在服用他克莫司。
:::
:::

::: exercise 肝脏和角膜为何不同 {level=2}
解释为什么角膜移植通常不做HLA配型也不用全身免疫抑制，而肺移植需要强力免疫抑制。
::: solution
角膜**无血管**，中央部分没有淋巴管，因此供者抗原和过客树突状细胞很难到达受者的淋巴结。眼具有免疫豁免，前房中有Fas配体、TGF-β和其他抑制性信号。因此大多数角膜移植物仅用局部激素即可存活；当受者角膜因既往炎症而血管化时风险增加。相反，肺血管丰富，淋巴引流充沛，供者树突状细胞多，并持续暴露于吸入的微生物和颗粒，后者激活固有免疫并提供共刺激。因此肺移植会引起强烈的直接和间接同种异体识别，在常见实体器官中急性和慢性排斥（闭塞性细支气管炎）发生率最高。
:::
:::

::: exercise 移植后皮肤癌 {level=2}
一名接受肾移植15年的63岁男性已发生第六个皮肤鳞状细胞癌。解释他的风险为何如此之高以及可以采取什么措施。
::: solution
器官移植受者的皮肤鳞状细胞癌比普通人群多许多倍，且随免疫抑制的时间和强度而增加。紫外线在角质形成细胞中造成大量突变，产生通常会被T细胞识别的新抗原；免疫抑制削弱了这种监视，某些药物（使DNA对UVA敏感的硫唑嘌呤，以及钙调神经磷酸酶抑制剂）可能还有直接作用。人乳头瘤病毒也可能起一定作用。措施包括严格防晒和定期皮肤检查，早期治疗癌前病变，并与移植团队商量调整免疫抑制，例如减少剂量，或从钙调神经磷酸酶抑制剂换成西罗莫司等mTOR抑制剂，后者有抗增殖作用，可减少部分患者新发的皮肤癌。部分患者使用口服烟酰胺或阿维A来减少新发肿瘤。
:::
:::

一名66岁男性的移植肾功能良好，现患转移性黑色素瘤。肿瘤科医生考虑使用PD-1抑制剂。讨论其免疫学风险以及如何权衡。
::: solution
PD-1和PD-L1参与对移植物的外周耐受：移植物内皮和肾小管细胞表达PD-L1，抑制同种反应性T细胞。因此阻断PD-1可诱发**急性排斥**，在接受检查点抑制剂治疗的肾移植受者中有相当比例的报道（一般认为抗PD-1的风险高于抗CTLA-4），有时导致不可逆的移植物丢失。他现有的免疫抑制也可能削弱抗肿瘤应答。需要权衡未经治疗的转移性黑色素瘤的高死亡率和移植物丢失的后果：肾移植受者可以回到透析，而心脏或肝脏移植物丢失通常是致命的。决策需要患者、肿瘤科和移植团队共同参与；选择包括在检查点治疗前调整免疫抑制（例如改用mTOR抑制剂加小剂量激素）、密切监测移植物功能，并事先商定一旦发生排斥如何处理。
:::

::: exercise GvHD与GvL {level=3}
一名35岁急性髓系白血病女性接受了来自相合无关供者的异基因HSCT。6个月时有轻度皮肤GvHD，白血病仍处于缓解期。12个月时，在停用免疫抑制后，骨髓检查显示早期复发。解释为什么有一定程度的GvHD与较低的复发率相关，以及可以如何使用供者淋巴细胞输注。
::: solution
GvHD和移植物抗白血病效应都源于供者T细胞（和NK细胞）识别受者抗原：存在HLA错配时识别错配的HLA，在相合移植中主要识别次要组织相容性抗原，即供受者之间不同、且同时表达于正常组织和白血病细胞的多态性肽。轻至中度GvHD患者平均而言有更活跃的同种反应性供者T细胞，复发率更低；去除移植物中的T细胞可减少GvHD但增加复发。对于她的早期复发，免疫抑制已经停用；从同一供者采集的**供者淋巴细胞输注**可增加同种反应性T细胞以增强GvL效应，常在化疗或去甲基化药物降低白血病负荷之后进行。主要风险是诱发或加重GvHD，因此剂量要谨慎递增。寻找只表达于造血细胞的抗原或使用工程化T细胞，是把有益效应和有害效应分开的途径。
:::
