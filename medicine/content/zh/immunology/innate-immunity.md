## 屏障与吞噬细胞

::: definition 物理、化学与细胞的第一线 {#def-barriers}

## 感知与信号

::: definition 模式识别与炎症小体 {#def-prr}

::: definition 补体 {#def-complement}

::: example 患过氧化氢酶阳性脓肿的孩子 {#ex-cgd}
一名3岁男孩一年内有过肛周脓肿、一次曲霉肺炎、一次葡萄球菌肝脓肿；检查发现肉芽肿性胃出口梗阻；他的母系舅舅“死于感染”；氧化爆发检测异常。
::: solution
**慢性肉芽肿病——写成家谱的氧化酶缺陷（[[#def-barriers]]、[[genetics/mendelian-inheritance]]）：机制——还原型辅酶氧化酶组装失败（X连锁的gp91-phox最常见也最重、及常染色体的p47与p67与p22-phox及NCF变异），所以吞噬细胞能吞入却无法生成超氧化物及其次卤酸盐衍生物、使过氧化氢酶阳性的微生物（葡萄球菌与沙雷菌与伯克霍尔德菌与诺卡菌与曲霉——过氧化氢酶为它自己保住过氧化物免于宿主的）留在未被杀死的吞噬溶酶体里、并被隔离成肉芽肿——[[microbiology/bacteria]]、[[microbiology/fungi-parasites]]；诊断——二罗丹明流式细胞术或四氮唑蓝刺激试验、带上X连锁中女性携带者偏斜嵌合现象的说明、及确认并做遗传咨询的基因学携带者母亲获得产前与着床前选项的机会、及扩展家系筛查——[[genetics/genetic-testing]]、[[clinical-skills/laboratory-tests]]；改变了生存的预防架构——终生的复方磺胺与伊曲康唑及干扰素γ带它的免疫调节机制、针对过氧化氢酶阳性那群微生物的抗菌药物管理、及包括“使用卡介苗处禁用活疫苗”这一警诫的疫苗规划——[[microbiology/antimicrobials]]、[[public-health/vaccination-programmes]]、[[infectious-diseases/tropical-infections]]用于卡介苗；急性发作的医学——针对曲霉与肝脓肿表型的积极长期抗真菌与抗菌治疗带引流决定的源头控制、及被肉芽肿与不良愈合复杂化的外科、及用于失调性炎症梗阻并发症胃肠与泌尿梗阻与误吸的糖皮质激素、与感染风险相权衡；及决定性的未来——按年龄与供者及预处理方案看造血干细胞移植的结果、带移植医学的合作、及基因治疗试验、及成年器官损害存活者门诊炎症性肠病样结肠炎与盘状红斑狼疮样皮损及淋巴瘤风险、这个孩子的照护最终实际落在那里管理——[[immunology/transplant-tumour-immunology]]、[[gastrointestinal/bowel-disease]]、[[infectious-diseases/immunocompromised-host]]。**

::: example 不痒的面部肿胀 {#ex-hae}
一名19岁女性反复2-3天的无痛性面部与唇部肿胀发作、一次带腹部绞痛及计算机断层显示肠壁水肿与腹水；无荨麻疹、无触发因素、抗组胺药与肾上腺素“从来没用”；她母亲有过“腹部发作”。

## 通向何处

适应性的交接在[[immunology/adaptive-responses]]；过敏与过敏反应效应器在[[immunology/hypersensitivity]]；临床免疫缺陷在[[immunology/immunodeficiency]]；肾与血液的补体疾病在[[renal/filtration]]与[[blood/haemoglobin-disorders]]。

::: history
**先天免疫的观念比免疫学这个名字更古老：十九世纪医学的身体屏障隐喻、与梅奇尼科夫1882年在海边由幼虫胸腺细胞获得的顿悟、及他对抗体液学派的吞噬细胞理论、及消耗了两代诺贝尔奖的细胞对体液免疫这场决斗科学的框架；埃利希的补体（抗素）作为体液的一面、及博代-热纳 的溶血素与吸附工作、使补体成为一种可测定的物质、并使免疫复合物溶血血清学成为一种一个世纪后仍用于梅毒诊断的技术——[[microbiology/laboratory-diagnosis]]、[[infectious-diseases/sexually-transmitted-infections]]；内毒素的弧线——十九世纪末的破伤风毒素与休克的工作、及煮沸细菌的发热现象、及鲎变形细胞溶解物与致热原检测时代的药典、及1990-2000年代经由果蝇Toll突变体的脂质A结构时代的TLR4与MD2与CD14的发现从果蝇Toll突变体到梅德日托夫等人的哺乳动物TLR4这一谱系——一个果蝇发育基因成为哺乳动物炎症的核心受体、遗传学最了不起的意外馈赠；1990-2000年代的炎症小体与自身炎症革命——迪纳雷洛的白介素1纯化、及冷冻蛋白病与家族性地中海热及周期性发热综合征的分子诊断、把“周期性发热”患者从心身病例报告变成有靶向治疗的细胞因子通路疾病、及卡那奴单抗的抗炎心血管事件减少试验那个意外的发现、证明炎症是动脉粥样硬化中的一个治疗靶点；及补体医学的弧线——从博代与埃利希及免疫溶血与阿瑟反应及血清病肾损伤的工作、到1980年代C3b调理素与膜攻击复合物的分子生理、再到依库珠单抗时代用于阵发性夜间血红蛋白尿与非典型溶血尿毒症的补体抑制剂药物、及如今的抗体与移植适应证及肾小球疾病管线——[[renal/filtration]]、[[pathology/acute-inflammation]]、[[public-health/health-systems-economics]]。**
:::

::: summary
- 屏障完成了大部分防御；破损（皮肤、导管、肿瘤、烧伤）在日常感染风险上比多数免疫细胞计数更重要。
- 中性粒细胞需要调理素：脾与抗体及C3b的三联解释了有荚膜微生物的脓毒症、及为何“只是中性粒细胞计数低一点”低估了风险。
- 模式识别把微生物与损伤相关分子模式转成白介素1与白介素18及肿瘤坏死因子及干扰素的词汇；通路中的人类突变是有名字的疾病、配有有名字的生物制剂。
- 补体调理、溶解复合物、引发炎症、并裂解；它的缺陷拼出微生物专特的感染、而它的调节子失败拼出溶血、血栓与肾炎。
- 不痒的血管性水肿是缓激肽的医学、不是组胺的医学——用C1抑制剂与激肽通路药物治疗、并保护气道。
- 先天系统指导适应性系统：本章决定下一章的应答有多强、是什么类型、以及持续多久。
:::

**低C4是一张地图、不是一个诊断（[[#def-complement]]）：先把遗传对消耗括起来——遗传性血管性水肿（发作间C4低而C3正常、带家族与肿胀史）对获得性C1抑制剂缺陷C1q低的淋巴增殖与自身免疫关联——所以计算机断层与血清蛋白电泳及脂肪垫及血液科门诊复审对经典通路消耗的免疫复合物病早期狼疮与冷球蛋白血症及感染相关及低补体性荨麻疹血管炎综合征——抗C1q抗体检测对实验室技术性与先天性C4缺陷的良性变异——[[clinical-skills/laboratory-tests]]；荨麻疹对血管炎的区分——单个皮损的持续时间与淤斑及灼痛、及带白细胞碎裂的组织学、及补体水平对活动的监测——[[musculoskeletal/skin]]；血清学的时机与复查纪律——抗核抗体与双链脱氧核糖核酸及可提取核抗原及Sm与核糖核蛋白的细微之处、及已确立疾病中C3与C4及C4结合蛋白的轨迹、及任何抗凝决定前的抗磷脂筛查；及随访规划——若获得性C1抑制剂缺陷则淋巴瘤监测、及针对亚临床肾小球肾炎的肾内科与尿检、及具名临床医师的复审日期、及患者携带的那份“低补体”意谓与不意谓什么的摘要、因为他们今晚就会去搜这个词——[[blood/lymphoma-myeloma]]、[[clinical-skills/communication]]。**

::: exercise 解读发热综合征 {level=2}

::: solution
**自身炎症而非自身免疫的发热（[[#def-prr]]）：诊断框架——规律性与钟表般的准时、及良好的间期、及无触发因素的荨麻疹、及显著的淀粉样蛋白A与C反应蛋白、及自身抗体阴性、及对抗生素无应答、及一个家族史或新发的显性突变、及冷冻蛋白相关周期性发热的NLRP3功能获得谱、带其斑块样中性粒细胞皮肤活检——[[clinical-skills/laboratory-tests]]、及组胺对中性粒细胞荨麻疹的对比在[[musculoskeletal/skin]]；遗传服务的交界——NLRP3与其他基因的panel肿瘤坏死因子受体超家族1A与甲羟戊酸激酶与地中海热基因、及NLRC4与蛋白酶体综合征、带体细胞嵌合而血检阴性的警诫、及基因型表型治疗匹配的说法；治疗——白介素1阻断作为疾病替代治疗、带药物专特的准入与妊娠及疫苗及生物制剂安全的背景、及淀粉样蛋白A与尿蛋白的淀粉样变监测、及激素节省与生长及学校及运动正常化的规划——[[genetics/genetic-testing]]、[[public-health/vaccination-programmes]]、[[paediatrics/growth-development]]；及成人和儿童的不明发热纪律、其鉴别包括感染结核与脓肿与心内膜炎、恶性肿瘤白血病与淋巴瘤与免疫疾病狼疮与血管炎与炎症性肠病、及诚实的停止规则、好让活检与影像与经验治疗的旋转木马不取代诊断推理——[[infectious-diseases/tuberculosis]]、[[blood/leukaemia]]、[[pathology/cancer-diagnosis]]。**
