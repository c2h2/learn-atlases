我们每天吸入、吞下和接触数以百万计的微生物，其中几乎没有一个会致病。原因不在于抗体或T细胞——它们对新事物作出应答需要一周甚至更久——而在于**固有免疫系统**：一组与生俱来的防御机制，它识别的是大类微生物而非单个微生物，并在数分钟至数小时内发挥作用。

固有免疫承担三项任务。第一，它自身就能控制大多数感染。第二，它为适应性应答的组织争取时间。第三，它告诉适应性免疫系统面对的是哪一类威胁，从而引出合适类型的淋巴细胞应答。固有免疫任何一个环节失灵时，临床表现都很有特征，往往仅凭病史就能说出缺失的是哪一部分。

本章介绍屏障、固有免疫细胞、这些细胞识别微生物的方式、补体系统，以及随后出现的炎症反应和急性期反应。下一章[[immunology/antigen-recognition]]将讨论适应性免疫系统的受体。

## 屏障

第一道防线是把微生物挡在外面。完整的皮肤干燥、偏酸、不断脱屑，表面覆有抗菌脂质。黏膜表面更薄更湿润，因此依靠运动和分泌物来防御：黏液捕获颗粒，气道纤毛把它们向上清扫，蠕动和尿流把它们冲走，胃酸杀死大部分吞下的微生物。

::: definition 屏障防御 {#def-barriers}
**屏障防御**是上皮表面阻止微生物进入组织的物理、化学和生物学特征，包括：

- **物理屏障**：角化的皮肤、上皮细胞之间的紧密连接、黏液、纤毛和液体的流动；
- **化学屏障**：低pH（皮肤、胃、阴道），泪液和唾液中的溶菌酶，以及防御素、cathelicidin等破坏微生物膜的**抗菌肽**；
- **生物屏障**：常驻的**微生物群**，它们占据了病原体原本会利用的空间和营养。
:::

屏障失效是感染常见而现实的原因，而且常常由医疗活动造成。烧伤去除了皮肤屏障。静脉留置针或导尿管提供了一条直接绕过屏障的通路。吸烟和病毒感染使纤毛麻痹。广谱抗生素清除了起保护作用的微生物群，这就是抗生素使用后会发生艰难梭菌（*Clostridioides difficile*）结肠炎的原因。质子泵抑制剂降低胃酸，使肠道感染风险轻度增加。在这些情况下免疫细胞都是正常的，问题在于微生物到达了它们通常不会到达的地方。

微生物群的详细内容见[[microbiology/microbiota]]。

## 固有免疫细胞

越过屏障的微生物首先遇到组织常驻细胞，然后是从血液中招募来的细胞。

**巨噬细胞**几乎存在于所有组织中，并各有本地名称：肝脏中的库普弗细胞、肺中的肺泡巨噬细胞、脑中的小胶质细胞。它们吞噬微生物和死亡细胞，在发现微生物时释放细胞因子，启动炎症。

**中性粒细胞**是血液中数量最多的白细胞。它们在骨髓中大量生成，在血液中循环数小时，感染发生后数分钟至数小时内被招募到组织。它们寿命很短，死亡的中性粒细胞构成脓液的大部分。中性粒细胞是抵御胞外细菌和真菌的主要防线。

**树突状细胞**驻留在组织中，不断采集周围环境的样本。当它们在拾取微生物物质的同时接收到危险信号时，便经淋巴管迁移到淋巴结，向T细胞提呈抗原。它们是固有免疫与适应性免疫之间的主要纽带。

**肥大细胞**位于皮肤和黏膜中血管和神经的附近，胞内含有储存组胺和其他介质的颗粒。补体片段或微生物产物可直接激发它们。它们是过敏反应的核心细胞，见[[immunology/hypersensitivity]]。

**嗜酸性粒细胞**和**嗜碱性粒细胞**专门对付多细胞寄生虫，并参与过敏性炎症。

**自然杀伤细胞（NK细胞）**是没有抗原特异性受体的淋巴细胞。它们杀伤病毒感染细胞和恶性细胞，详见下文。

### 中性粒细胞如何离开血液

中性粒细胞在血管中快速流动，因此离开循环需要一系列步骤，称为**白细胞黏附级联**。

1. **内皮活化。**组织巨噬细胞释放的细胞因子（TNF和IL-1）使附近的内皮细胞表达称为**选择素**的黏附分子。
2. **滚动。**选择素与中性粒细胞表面的糖（唾液酸化路易斯X）结合。这些键迅速形成又断开，于是中性粒细胞减速并沿血管壁滚动。
3. **牢固黏附。**内皮上的趋化因子，尤其是CXCL8（IL-8），使中性粒细胞的**整合素**（如由CD11a和CD18组成的LFA-1）转变为高亲和力状态。整合素与内皮上的ICAM-1结合，细胞停止移动。
4. **跨内皮迁移。**中性粒细胞从内皮细胞之间挤入组织。
5. **趋化。**随后它沿趋化物质的浓度梯度移动：C5a、白三烯B4、CXCL8和细菌甲酰肽。

每一步都有一种人类疾病证明其重要性。在**白细胞黏附缺陷1型**中，CD18的隐性缺陷使整合素无法形成。中性粒细胞不能离开血液，因此血中中性粒细胞计数很高，而组织却得不到充分防御。患儿表现为脐带脱落延迟、脐炎，以及不形成脓液的皮肤和牙龈感染。诊断依靠流式细胞术显示CD18缺失。在较少见的2型中，缺失的是含岩藻糖的选择素配体。

### 吞噬与杀伤

如果颗粒表面包被有吞噬细胞具有相应受体的分子，吞噬细胞就更容易吞入它。这种包被称为**调理作用**，两种主要的调理素是补体片段**C3b**和**IgG抗体**。肺炎链球菌、b型流感嗜血杆菌和脑膜炎奈瑟菌等有荚膜细菌除非被调理，否则能抵抗吞噬，这就是抗体缺陷、补体缺陷和脾缺失都易发生这些细菌感染的原因。

微生物进入吞噬体后，通过两种机制被杀死：

- **氧依赖性杀伤。**酶复合物**NADPH氧化酶**在吞噬体膜上组装，将电子传递给氧，生成超氧化物。超氧化物转化为过氧化氢，再经**髓过氧化物酶**生成次氯酸。这种骤然的耗氧称为呼吸爆发。
- **非氧依赖性杀伤。**颗粒内容物，包括防御素、溶菌酶、乳铁蛋白和蛋白酶，被释放到吞噬体中。

中性粒细胞还能把自身的DNA和颗粒蛋白排出胞外，形成**中性粒细胞胞外陷阱**（NETs），它可固定微生物，但也会损伤组织并促进血栓形成。

**慢性肉芽肿病**（CGD）由NADPH氧化酶某个亚基的缺陷引起；约三分之二的病例为X连锁遗传（*CYBB*基因）。中性粒细胞能正常吞入细菌，却不能杀死其中一部分。CGD患者反复发生深部感染和脓肿，病原体如金黄色葡萄球菌（*Staphylococcus aureus*）、曲霉（*Aspergillus*）、洋葱伯克霍尔德菌复合群（*Burkholderia cepacia* complex）、沙雷菌（*Serratia*）和诺卡菌（*Nocardia*）；由于巨噬细胞不断试图包围它们无法杀死的微生物，患者还会形成肉芽肿。诊断检测是**二氢罗丹明（DHR）流式细胞术检测**，它直接测定氧化爆发。

::: example 肝脓肿男孩 {#ex-cgd}
一名6岁男孩因发热和右上腹痛入院。影像学显示肝脓肿，引流液培养出金黄色葡萄球菌。他此前住院两次：2岁时颈部淋巴结脓肿，4岁时曲霉肺炎。血常规显示中性粒细胞计数升高，免疫球蛋白正常。他的一位舅舅童年时死于“肺炎”。最可能的诊断是什么？如何确诊？治疗原则是什么？
::: solution
**模式。**儿童出现深部脓肿（肝、淋巴结）和侵袭性真菌感染，提示吞噬细胞杀伤缺陷，而非抗体问题。抗体缺陷通常引起有荚膜细菌所致的反复鼻窦和胸部感染，而他的免疫球蛋白正常。

**为什么不是中性粒细胞数量或迁移的问题？**他的中性粒细胞计数升高，而脓肿的形成说明中性粒细胞能够到达组织。它们到达了，却不能杀伤。

**家族史。**男孩的舅舅受累，符合X连锁遗传，这是慢性肉芽肿病最常见的类型。

**确诊。**DHR流式细胞术检测显示受刺激中性粒细胞的氧化爆发缺失或显著降低。随后的基因检测可确定受累亚基（最可能是*CYBB*），从而可对其母亲进行携带者检测，并为家庭提供遗传咨询。

**治疗原则。**当前脓肿需引流，并在培养结果指导下长期抗微生物治疗。长期抗细菌和抗真菌预防是标准做法；部分中心使用γ干扰素。造血干细胞移植可以治愈，并越来越多地在早期进行。具体选择遵循专科免疫学指南。
:::
:::

## 自然杀伤细胞

NK细胞解决了T细胞无法解决的一个问题。许多病毒以及许多肿瘤会降低细胞表面**MHC I类**分子的表达，以躲避细胞毒性T细胞（见[[immunology/antigen-recognition]]）。NK细胞带有识别自身MHC I类分子的**抑制性受体**（在人类为杀伤细胞免疫球蛋白样受体，KIR）。MHC I类表达正常的健康细胞会使NK细胞处于关闭状态。

::: theorem “丢失自我”原理 {#thm-missing-self}
当激活信号超过抑制信号时，NK细胞杀伤靶细胞。自身MHC I类分子的丢失解除了抑制（**丢失自我**），感染细胞或转化细胞上应激诱导的配体则增加了激活（**诱导自我**）。任何一种变化都能使平衡倒向杀伤。
:::

NK细胞通过释放**穿孔素**和**颗粒酶**杀伤靶细胞：穿孔素在靶细胞膜上形成孔道，颗粒酶经孔道进入并触发凋亡。NK细胞还带有Fc受体CD16，可结合包被在细胞上的IgG并触发杀伤，这就是**抗体依赖细胞介导的细胞毒作用**（ADCC），它解释了利妥昔单抗等治疗性抗体的部分作用机制。NK细胞也是感染早期**γ干扰素**的主要来源，γ干扰素可激活巨噬细胞。

## 模式识别

没有抗原特异性受体，固有免疫细胞如何区分细菌和人体细胞？Charles Janeway在1989年给出的答案是：固有免疫细胞带有胚系编码的受体，识别整类微生物共有而宿主细胞没有的分子结构。

::: definition 模式识别受体 {#def-prr}
**病原体相关分子模式**（PAMPs）是保守的微生物结构，如革兰氏阴性菌的脂多糖（LPS）、细菌脂蛋白、鞭毛蛋白、未甲基化的CpG DNA和双链RNA。**损伤相关分子模式**（DAMPs）是受损或濒死细胞释放的宿主分子，如ATP、尿酸结晶、HMGB1和线粒体DNA。

**模式识别受体**（PRRs）是胚系编码、能结合PAMPs或DAMPs并触发固有应答的受体。主要家族包括：

- 位于细胞表面和内体的**Toll样受体**（TLRs）；
- 位于胞质的**NOD样受体**（NLRs），其中一些可形成炎症小体；
- 位于胞质、检测病毒RNA的**RIG-I样受体**（RLRs）；
- 检测胞质中DNA的**cGAS–STING**通路；
- 结合真菌β-葡聚糖等微生物糖类的**C型凝集素受体**（dectin-1）。
:::

每种受体的位置与其配体的位置相吻合。表面TLR检测细菌和真菌的外部结构；内体TLR和胞质感受器检测核酸，而核酸是病毒存在的主要线索。

| 受体 | 位置 | 主要配体 | 典型病原体 |
|---|---|---|---|
| TLR4 | 细胞表面 | 脂多糖 | 革兰氏阴性菌 |
| TLR2（与TLR1或TLR6） | 细胞表面 | 脂蛋白、脂磷壁酸 | 革兰氏阳性菌、分枝杆菌 |
| TLR5 | 细胞表面 | 鞭毛蛋白 | 有动力的细菌 |
| TLR3 | 内体 | 双链RNA | 病毒 |
| TLR7和TLR8 | 内体 | 单链RNA | 病毒 |
| TLR9 | 内体 | 未甲基化CpG DNA | 细菌、DNA病毒 |
| RIG-I、MDA5 | 胞质 | 病毒RNA | RNA病毒 |
| cGAS–STING | 胞质 | 胞质中的DNA | DNA病毒、胞内细菌 |
| NOD2 | 胞质 | 胞壁酰二肽（肽聚糖） | 细菌 |

### PRR被触发后发生什么

大多数TLR通过接头蛋白**MyD88**传递信号，激活转录因子**NF-κB**。NF-κB开启炎症细胞因子（TNF、IL-1、IL-6）、趋化因子和黏附分子的基因。病毒感受器（TLR3、TLR7/8/9、RIG-I和cGAS–STING）还激活**干扰素调节因子**，开启**I型干扰素**（IFN-α和IFN-β）。I型干扰素使邻近细胞进入抗病毒状态：诱导阻断病毒复制的蛋白，并增加MHC I类分子的表达。

两个人类例子说明这些通路的重要性。遗传性MyD88或IRAK-4缺陷的儿童发生严重的侵袭性化脓性细菌感染，发热和CRP常常出人意料地轻微。TLR3通路缺陷的儿童易患单纯疱疹病毒性脑炎，而对大多数其他病毒的处理正常。每一种狭窄的易感性都揭示了缺失通路的正常功能。

### 炎症小体

IL-1β作用极强，因此其释放需要两个信号。第一个信号通常来自TLR，产生无活性的前体pro-IL-1β。第二个信号组装出一种胞质蛋白复合物——**炎症小体**。最著名的炎症小体以**NLRP3**为核心，它对多种扰动起反应：钾外流、单钠尿酸盐等晶体以及受损的线粒体。炎症小体激活**胱天蛋白酶-1**，后者把pro-IL-1β和pro-IL-18切割成活性形式，同时切割gasdermin D，使其在细胞膜上形成孔道，引起一种炎症性细胞死亡，称为**细胞焦亡**。

这解释了痛风为何如此疼痛、炎症如此剧烈：尿酸盐结晶激活关节巨噬细胞中的NLRP3，产生的IL-1β驱动中性粒细胞涌入。它也解释了一组罕见的**自身炎症性疾病**，这类疾病的炎症在没有自身抗体或自身反应性T细胞的情况下发生。*NLRP3*的功能获得性变异引起冷吡啉相关周期性综合征，表现为反复发热、荨麻疹样皮疹和炎症指标升高，对IL-1阻断治疗反应显著。家族性地中海热由*MEFV*（编码另一种炎症小体感受器pyrin）变异引起，表现为反复发作的发热和浆膜炎，用秋水仙碱治疗。

:::warning
“自身免疫”和“自身炎症”不能互换。自身免疫病由适应性免疫系统识别自身抗原所驱动，通常伴有自身抗体或自身反应性T细胞。自身炎症性疾病则由没有特异性抗原、却被开启的固有免疫通路所驱动。一名反复发热、CRP升高而自身抗体阴性的患者，并没有“排除”免疫性疾病；他可能患有自身炎症性疾病。
:::

## 补体

补体系统由30多种血浆蛋白和膜蛋白组成，大多由肝脏合成。多数以无活性前体的形式循环。激活后，它们依次切割并激活彼此，因此一个小的触发会被放大为大的应答。

::: definition 补体系统 {#def-complement}
**补体**是一组血浆蛋白级联，在某一表面被激活后有三种主要效应：

1. **调理作用**：C3b包被表面，被吞噬细胞上的补体受体识别。
2. **炎症**：小片段**C3a**和**C5a**（过敏毒素）引起肥大细胞脱颗粒和血管通透性增加；C5a还是强效的中性粒细胞趋化因子。
3. **溶解**：C5b与C6、C7、C8和C9形成**攻膜复合物**（MAC），这种孔道可杀死某些细菌，尤其是奈瑟菌（*Neisseria*）。

补体还能清除血液中的**免疫复合物**，借助红细胞把它们运送到肝脏和脾脏。
:::

### 三条途径汇聚于一个中心步骤

补体可经三条途径激活，它们都汇聚于**C3**的裂解。

- **经典途径。**C1q结合附着于抗原上的抗体（IgM，或聚集在表面的IgG）。C1随后切割C4和C2，形成经典途径C3转化酶C4b2a。这条途径把补体与适应性免疫联系起来。
- **凝集素途径。****甘露糖结合凝集素**（MBL）或纤维胶凝蛋白结合微生物表面的糖模式，激活MBL相关丝氨酸蛋白酶，后者同样切割C4和C2。
- **旁路途径。**血浆中的C3会发生缓慢的自发水解（“tick-over”）。产物结合B因子，B因子被D因子切割，形成C3转化酶（C3bBb，由备解素稳定）。在宿主细胞上它很快被关闭；在微生物表面则不会，于是C3b沉积不断放大。

每种C3转化酶都把C3切割为C3a和C3b。随着更多C3b结合，转化酶变为**C5转化酶**，把C5切割为C5a和C5b，开始组装攻膜复合物。

旁路途径还是一个**放大环**：任何途径产生的C3b都能形成更多的旁路途径转化酶。因此，无论最初由哪条途径启动，微生物表面的大部分C3b最终都由旁路途径产生。

### 调节：保护自身

由于C3b几乎能与附近任何表面结合，宿主细胞需要保护。调节蛋白包括：

- **C1抑制物**（C1-INH），它灭活C1和MBL相关蛋白酶，也灭活接触系统（缓激肽系统）中的激肽释放酶和XIIa因子；
- **H因子**和**I因子**，在血浆中和宿主细胞上灭活C3b；
- 膜调节蛋白：分解转化酶的**衰变加速因子**（CD55），以及阻止攻膜复合物组装的**CD59**。

调节蛋白失效与补体成分缺失一样会致病。**阵发性睡眠性血红蛋白尿症**（PNH）中红细胞缺失CD55和CD59，暴露于补体溶解。H因子或其他旁路途径调节蛋白的变异易导致**非典型溶血尿毒综合征**，补体损伤肾脏内皮。两者均用阻断C5的抗体治疗。

::: theorem 补体缺陷可预测其感染类型 {#thm-complement-def}
补体缺陷的临床表现取决于丧失了哪种功能：

- **经典途径早期成分**（C1q、C2、C4）：免疫复合物和凋亡细胞清除不良，因此**系统性红斑狼疮**风险很高，并易发生有荚膜细菌感染；
- **C3**：丧失调理作用，因此发生严重反复的**化脓性感染**，类似抗体缺陷；
- **末端成分**（C5至C9）和**备解素**：丧失攻膜复合物，因此反复发生**奈瑟菌**感染（脑膜炎球菌病，有时为少见血清群，或播散性淋球菌感染）；
- **C1抑制物**：遗传性血管性水肿，由缓激肽而非补体本身引起。
:::

::: proof
对大多数细菌而言，C3b的调理作用和攻膜复合物的溶解作用部分重叠，因为抗体和吞噬细胞仍能清除它们。奈瑟菌是例外：对它的杀伤高度依赖攻膜复合物，因此缺失C5至C9会暴露出一种狭窄的易感性。C3位于三条途径的汇聚点，又是C3b的来源，缺失C3就失去了调理作用以及其下游的一切，结果类似抗体缺陷。经典途径早期成分负责用C4b和C3b标记免疫复合物和濒死细胞以便清除；缺少它们，核物质滞留并被提呈给适应性免疫系统，这是产生狼疮自身抗体的途径之一。
:::

同样的逻辑预示了依库珠单抗（eculizumab）和雷夫利珠单抗（ravulizumab）等**C5抑制剂**的主要风险：它们造成药物性末端补体缺陷，因此脑膜炎球菌感染是严重风险。开始使用这些药物的患者要接种脑膜炎球菌疫苗（包括B群），在英国通常还要按照产品说明书和当地指南给予抗生素预防。

### 遗传性血管性水肿

**遗传性血管性水肿**（HAE）是C1抑制物的常染色体显性缺乏或功能障碍。缺少C1-INH，接触系统失去控制，产生**缓激肽**，使血管通透性增加。HAE患者反复出现皮肤、肠壁（引起剧烈腹痛）和上气道的肿胀，常由轻微创伤、牙科操作或雌激素诱发。没有荨麻疹，也没有瘙痒。

由于肿胀由缓激肽而非组胺引起，肾上腺素、抗组胺药和糖皮质激素均无效。急性发作用C1-INH浓缩物或缓激肽B2受体拮抗剂艾替班特（icatibant）治疗，长期预防的选择包括抗激肽释放酶抗体拉那利尤单抗（lanadelumab）。最佳筛查试验是**C4水平**，由于C1持续消耗C4，C4降低；随后用C1-INH水平和功能检测确诊。ACE抑制剂引起类似的缓激肽介导的血管性水肿，因为ACE正常情况下会降解缓激肽。

::: example 对肾上腺素无反应的肿胀 {#ex-hae}
一名24岁女性在拔牙后6小时出现唇舌肿胀，来到急诊科。她没有皮疹或瘙痒。救护人员已给予肌内注射肾上腺素、氯苯那敏和氢化可的松，但无改善。她自青春期起反复出现剧烈腹痛，2至3天后自行缓解；她父亲手部曾有“过敏性”肿胀。她正在服用复方口服避孕药。可能的机制是什么？什么检查可支持诊断？治疗原则是什么？
::: solution
**机制。**无荨麻疹或瘙痒的血管性水肿、牙科诱因、对肾上腺素、抗组胺药和激素均无反应、反复腹痛以及一位受累的父母，共同指向遗传性血管性水肿：C1抑制物缺乏导致缓激肽介导的肿胀。含雌激素的避孕药是公认的加重因素。

**检查。**C4降低支持诊断；C1-INH抗原水平和功能检测可确诊（1型水平降低；2型水平正常而功能降低）。由于不涉及肥大细胞，类胰蛋白酶预计正常。

**治疗原则。**舌肿胀威胁气道：首先要尽早请高年资麻醉科和耳鼻喉科医生参与并监测气道。特异性治疗是按当地方案使用C1-INH浓缩物或艾替班特。之后她需要转诊至免疫专科，获得书面诊疗计划和按需治疗药物，今后牙科操作前进行预防性治疗，重新评估含雌激素的避孕方法，并对一级亲属进行检测。
:::
:::

## 炎症

炎症是血管和白细胞对感染或损伤的协调反应。罗马作家塞尔苏斯（Celsus）描述了四个**主要体征**：红（*rubor*）、热（*calor*）、肿（*tumor*）、痛（*dolor*）；功能障碍（*functio laesa*）是后来加上的，通常归功于菲尔绍（Virchow）。每一个体征都有免疫学解释：

- **红和热**来自小动脉扩张，由组胺、前列腺素和一氧化氮引起。
- **肿**来自血浆蛋白和液体从毛细血管后微静脉内皮细胞间隙渗出，由组胺、缓激肽、C3a、C5a和白三烯引起。
- **痛**来自缓激肽和前列腺素E2使神经末梢致敏。
- **功能障碍**源于疼痛、肿胀和组织损伤。

细胞层面的事件如上所述：内皮活化，数小时内中性粒细胞募集，随后几天单核细胞和淋巴细胞到来。大多数急性炎症通过主动过程消退：中性粒细胞凋亡，巨噬细胞清除它们并转而产生抗炎介质，组织得到修复。急性和慢性炎症的病理学见[[pathology/acute-inflammation]]。

## 细胞因子、发热与急性期反应

**细胞因子**是在细胞之间起作用的小分子信号蛋白。其中三种是固有免疫的核心：

- **TNF**激活内皮和中性粒细胞，大量时引起休克；
- **IL-1**（主要是IL-1β）引起发热并激活内皮；
- **IL-6**引起发热并驱动肝脏的急性期反应。

**发热**的发生，是IL-1、IL-6和TNF使下丘脑产生前列腺素E2，从而上调体温调定点。对乙酰氨基酚和非甾体抗炎药等退热药通过减少前列腺素合成起作用。

**急性期反应**是肝脏合成蛋白的改变，主要由IL-6驱动。肝脏增加C反应蛋白（CRP）、血清淀粉样蛋白A、纤维蛋白原、铁蛋白和铁调素的生成，减少白蛋白和转铁蛋白。铁调素把铁滞留在巨噬细胞中，是炎症性贫血的主要原因。纤维蛋白原升高使红细胞沉降率（ESR）加快。

::: definition C反应蛋白 {#def-crp}
**C反应蛋白**（CRP）是肝细胞在IL-6作用下合成的急性期蛋白。它结合细菌表面和受损细胞上的磷酸胆碱，并激活补体经典途径。血中CRP在刺激后约6小时开始升高，约48小时达峰，一旦刺激停止便以约19小时的半衰期下降。因此其水平反映了此前一两天中IL-6的产生量。
:::

这一半衰期赋予CRP一个有用的特性：感染一旦得到控制，CRP应大约每天下降一半。在恰当治疗48至72小时后CRP仍居高不下或上升，提示感染源未被控制（如未引流的脓肿），或诊断有误。

::: example CRP下降得够快吗？ {#ex-crp}
一名70岁男性阑尾穿孔伴盆腔积液。抗生素治疗第1天CRP为240 mg/L。假设治疗控制感染源后CRP生成完全停止，此后CRP以19小时的半衰期下降。(a) 57小时后CRP应为多少？(b) 他当时实际的CRP为190 mg/L，这提示什么？
::: solution
(a) 57小时是$57/19 = 3$个半衰期，因此CRP应为

$$
240 \times \left(\tfrac{1}{2}\right)^{3} = 240 \times \tfrac{1}{8} = 30\ \text{mg/L}.
$$

(b) 190 mg/L远高于预期值。求表观半衰期：$190/240 = 0.5^{57/h}$，因此$h = 57 \times \ln 0.5 / \ln(190/240) \approx 169$小时。CRP几乎没有下降，说明IL-6仍在产生。可能的解释是积液未被引流。这应促使复查影像并讨论引流，而不是简单地更换抗生素。具体数字不如这种比较重要：CRP的变化不符合感染源已被控制的情况。
:::
:::

:::warning
CRP对感染并不特异。任何驱动IL-6生成的过程都会使其升高，包括手术、创伤、胰腺炎、活动性炎性关节炎、血管炎和某些癌症。反过来，在感染早期（升高需要数小时）、严重肝病，以及使用IL-6受体抗体托珠单抗（tocilizumab，它完全阻断CRP的生成）的患者中，CRP可能出人意料地低。系统性红斑狼疮常见ESR高而CRP正常，因此狼疮患者CRP升高应促使寻找感染。
:::

## 从局部防御到全身性危险

如果固有免疫激活扩散到感染组织以外，那些在局部有益的介质就会在全身造成伤害。广泛的血管扩张和毛细血管渗漏引起低血压；内皮活化和组织因子表达导致弥散性血管内凝血；器官灌注衰竭。**脓毒症**现在定义为宿主对感染的反应失调所致的危及生命的器官功能障碍（2016年Sepsis-3定义）。这一定义把宿主反应而非微生物放在中心。脓毒症的临床识别和处理见[[infectious-diseases/fever-sepsis]]。

## 临床中的固有免疫缺陷

固有免疫缺陷罕见，但感染模式能指出缺失的成分。下表总结了本章涉及的模式；反复感染患者的完整评估方法见[[immunology/immunodeficiency]]。

| 缺失的成分 | 典型感染 | 线索 | 关键检查 |
|---|---|---|---|
| 中性粒细胞数量（中性粒细胞减少） | 细菌性脓毒症、念珠菌、曲霉 | 口腔溃疡、化疗 | 血常规 |
| 中性粒细胞黏附（LAD-1） | 皮肤、牙龈和脐部感染 | 脐带脱落延迟、无脓、中性粒细胞计数很高 | 流式细胞术检测CD18 |
| 中性粒细胞杀伤（CGD） | 金黄色葡萄球菌、曲霉、伯克霍尔德菌、沙雷菌、诺卡菌 | 深部脓肿、肉芽肿 | DHR检测 |
| C3 | 化脓性细菌 | 类似抗体缺陷 | C3水平 |
| 末端补体（C5–C9） | 奈瑟菌 | 反复或家族性脑膜炎球菌病 | CH50和AH50 |
| 经典途径早期成分（C1q、C2、C4） | 有荚膜细菌 | 狼疮样疾病 | CH50、单个成分测定 |
| C1抑制物 | （无） | 无荨麻疹的血管性水肿 | C4，然后C1-INH水平和功能 |

**CH50**和**AH50**分别是经典途径和旁路途径的功能筛查试验。每项都测定患者血清溶解靶红细胞的能力，因此该途径中任何成分的缺乏都会使结果降低或缺失。

::: example 中性粒细胞减少与发热 {#ex-neutropenic}
一名45岁女性因乳腺癌接受化疗，末次化疗后第10天体温38.4 °C。她神志清楚，心率104次/分，血压118/72 mmHg。白细胞计数$1.2 \times 10^9$/L，其中30%为中性粒细胞。计算中性粒细胞绝对计数并解释其意义。
::: solution
中性粒细胞绝对计数等于白细胞总数乘以中性粒细胞比例：

$$
1.2 \times 10^9/\text{L} \times 0.30 = 0.36 \times 10^9/\text{L}.
$$

这低于$0.5 \times 10^9$/L，即严重中性粒细胞减少的界值。中性粒细胞计数$0.5 \times 10^9$/L或更低者体温超过38 °C，即符合NICE对**中性粒细胞减少性脓毒症**的定义（NICE CG151）。由于中性粒细胞极少，脓液、实变甚至脓尿等局部感染的常见体征可能缺如，细菌感染可在数小时内进展为感染性休克。处理遵循当地中性粒细胞减少性脓毒症路径：立即评估，留取血培养，并在就诊后1小时内经验性静脉给予广谱抗生素，无需等待计数结果。
:::
:::

反复或家族性奈瑟菌感染是末端补体成分（C5至C9）或备解素缺陷的典型表现，因为奈瑟菌的杀伤依赖攻膜复合物。CH50检测经典途径和末端途径，AH50检测旁路途径和末端途径；两者结合可筛查这些缺陷。确诊缺陷者应接种脑膜炎球菌疫苗并常给予抗生素预防，其亲属也应接受检测。

::: history
1882年，动物学家梅契尼科夫（Élie Metchnikoff）把玫瑰刺插入透明的海星幼虫体内，看到能移动的细胞聚集在刺的周围。他提出，这些他称为吞噬细胞的细胞通过吞噬入侵者来保卫机体。此后二十年，他的“细胞学派”与埃尔利希（Paul Ehrlich）等人的“体液学派”争论不休，后者认为起作用的物质存在于血清中。博尔代（Jules Bordet）在19世纪90年代证明，新鲜血清杀菌除了抗体之外还需要一种不耐热的因子；埃尔利希将其命名为补体。梅契尼科夫和埃尔利希共同获得1908年诺贝尔奖，这早早承认了两种观点都是正确的。

在20世纪的大部分时间里，固有免疫被视为粗糙而非特异的。1989年，Charles Janeway提出，固有免疫细胞必定带有识别保守微生物模式的受体，而这些受体决定适应性应答是否启动。这些受体在十年内被发现。1996年，霍夫曼（Jules Hoffmann）团队与Bruno Lemaitre证明Toll蛋白控制果蝇的抗真菌防御；1997年，Ruslan Medzhitov和Janeway描述了一种能激活炎症基因的人类Toll同源物；1998年，博伊特勒（Bruce Beutler）团队证明对LPS有抵抗力的小鼠携带*Tlr4*突变，从而确定TLR4就是LPS受体。博伊特勒和霍夫曼与发现树突状细胞的斯坦曼（Ralph Steinman）共同获得2011年诺贝尔奖。
:::

::: summary
- 屏障是第一道防线，医院中的许多感染源于屏障被破坏，而非免疫细胞失灵。
- 中性粒细胞通过滚动（选择素）、牢固黏附（CD18等整合素）和跨内皮迁移离开血液，然后通过吞噬、NADPH氧化酶爆发和颗粒内容物进行杀伤。LAD-1和慢性肉芽肿病显示了黏附或杀伤失败的后果。

- 模式识别受体（TLRs、NLRs、RLRs、cGAS–STING、C型凝集素）检测保守的微生物分子和危险信号，经NF-κB和干扰素调节因子传递信号，产生炎症细胞因子和I型干扰素。
- NLRP3炎症小体激活胱天蛋白酶-1以释放IL-1β；其过度活化是痛风发作和自身炎症综合征的基础，后者不同于自身免疫病。
- 补体经经典、凝集素和旁路途径激活，汇聚于C3，发挥调理（C3b）、致炎（C3a、C5a）和溶解（C5b–9）作用。缺陷可预测感染类型：C3对应化脓性细菌，末端成分对应奈瑟菌，经典途径早期成分对应狼疮。
- 遗传性血管性水肿是C1抑制物缺乏，引起对肾上腺素或抗组胺药无反应的缓激肽介导的肿胀；C4是筛查试验。
- IL-1、IL-6和TNF引起发热和急性期反应。CRP在数小时内升高，约48小时达峰，以约19小时的半衰期下降，因此下降失败提示感染源未被控制。
:::

## 习题

::: exercise 中性粒细胞绝对计数 {level=1 check="0.68"}
一名男性白细胞计数为$3.4 \times 10^9$/L，其中中性粒细胞占20%。计算他的中性粒细胞绝对计数，单位为$10^9$/L。
::: hint
用白细胞总数乘以中性粒细胞比例。
:::
::: solution
$3.4 \times 0.20 = 0.68$，因此中性粒细胞绝对计数为$0.68 \times 10^9$/L。这属于中度中性粒细胞减少（介于0.5与$1.0 \times 10^9$/L之间）。
:::
:::

::: exercise 受体与配体配对 {level=1}
对下列每种微生物分子，说出一种能检测它的模式识别受体：(a) 脂多糖；(b) 鞭毛蛋白；(c) 内体中的病毒双链RNA；(d) 真菌β-葡聚糖；(e) 胞质中的DNA。
::: solution
(a) TLR4（与MD-2和CD14协同）。(b) TLR5。(c) TLR3。(d) Dectin-1，一种C型凝集素受体。(e) cGAS，经STING传递信号。一般规律是：表面受体检测细菌和真菌的细胞壁成分，内体和胞质受体检测核酸。
:::
:::

::: exercise 补体的功能 {level=1}
说出负责下列各项的补体产物：(a) 调理作用；(b) 中性粒细胞趋化；(c) 奈瑟菌的溶解；(d) 遗传性血管性水肿中最可能降低的筛查指标。
::: solution
(a) C3b。(b) C5a。(c) 攻膜复合物C5b–9。(d) C4，在C1抑制物缺乏时被失控的C1活性持续消耗。
:::
:::

::: exercise CRP半衰期 {level=2 check="30"}
一名肾盂肾炎女性在梗阻性输尿管结石解除时CRP为120 mg/L。假设此后CRP生成停止，并以19小时的半衰期下降，38小时后她的CRP应为多少mg/L？
::: hint
38小时是几个半衰期？
:::
::: solution
38小时是$38/19 = 2$个半衰期，因此CRP应为$120 \times (1/2)^2 = 120/4 = 30$ mg/L。接近这一数值支持感染源已充分控制；远高于此则应寻找持续存在的感染源。
:::
:::

::: exercise 为什么没有脓？ {level=2}
一名婴儿患有CD18缺陷。逐步解释为什么其血中中性粒细胞计数很高，而皮肤感染却不形成脓液。
::: solution
CD18是白细胞整合素（包括LFA-1和Mac-1）共有的β2链。缺少CD18，中性粒细胞仍能在选择素上滚动，却不能转为在ICAM-1上的牢固黏附，因此不能停下并穿越内皮。中性粒细胞于是滞留在血液中，使计数升高，感染时骨髓释放更多中性粒细胞，计数更高。脓液主要由组织中死亡的中性粒细胞构成；中性粒细胞到不了组织，感染就会坏死、扩散而不形成脓液。Mac-1（CD11b/CD18）也是一种补体受体，因此对C3b包被微生物的吞噬同样受损。
:::
:::

::: exercise 开始使用C5抑制剂之前 {level=2}
一名32岁阵发性睡眠性血红蛋白尿症女性将开始使用依库珠单抗。解释在这种疾病中她的红细胞为何被破坏、药物如何起作用，以及它带来何种感染风险及其原因。
::: solution
PNH中，一个造血干细胞获得性*PIGA*突变使GPI锚无法合成，因此由其衍生的红细胞缺少GPI锚定的补体调节蛋白CD55和CD59。补体随之沉积在这些红细胞上，攻膜复合物将其溶解，引起血管内溶血、血红蛋白尿和血栓形成。依库珠单抗结合C5并阻止其裂解，攻膜复合物无法形成，血管内溶血停止。阻断C5相当于造成末端补体缺陷，而脑膜炎奈瑟菌的杀伤依赖攻膜复合物。因此她发生脑膜炎球菌病的风险大大增加，治疗前需接种ACWY群和B群脑膜炎球菌疫苗，按当地指南给予抗生素预防，并被告知发热时要紧急就医。
:::
:::

::: exercise CRP正常的发热儿童 {level=3}
一名14个月女孩出现高热、精神萎靡和肺炎链球菌菌血症。尽管已患病24小时，她的CRP仅为18 mg/L。她6个月时曾患金黄色葡萄球菌蜂窝织炎。免疫球蛋白、补体和中性粒细胞计数均正常。提出一个能把这些感染与低CRP联系起来的解释，并说明如何检查。
::: hint
想一想细胞在细菌刺激下产生IL-6需要哪条信号通路。
:::
::: solution
经MyD88或IRAK-4的TLR信号缺陷可以同时解释这两个特点。大多数TLR（以及IL-1受体）激活NF-κB需要这些接头分子，因此患儿的固有免疫细胞在细菌刺激下几乎不产生IL-6、IL-1或TNF。IL-6低意味着CRP很少升高、常常发热也不明显，而早期炎症薄弱使化脓性细菌（尤其是肺炎链球菌和金黄色葡萄球菌）得以侵袭。这类患儿的免疫球蛋白、补体和中性粒细胞计数通常正常，因此常规筛查结果正常。检查需要专科检测：用TLR配体刺激血细胞后测定细胞因子生成，再行基因检测。认识这一模式很重要，因为此类患儿CRP正常并不能排除严重细菌感染；不过这些缺陷罕见，CRP低远更常见的原因是采样过早。这类疾病的感染风险往往随年龄增长而降低。
:::
:::

::: exercise 按成分进行反复感染的鉴别诊断 {level=3}
三名儿童因反复感染转诊。(a) 一名4岁儿童反复肺炎球菌肺炎和中耳炎，免疫球蛋白正常，CH50低，AH50低。(b) 一名16岁青少年第二次患脑膜炎球菌病，CH50正常但AH50缺失。(c) 一名9岁儿童反复金黄色葡萄球菌皮肤脓肿并患沙雷菌骨髓炎，补体和免疫球蛋白正常。分别说出最可能的缺陷和确诊检查。
::: solution
(a) CH50和AH50均降低，说明缺陷位于两条途径共有的成分：C3或某个末端成分。感染为化脓性肺炎球菌感染而非奈瑟菌感染，指向**C3缺乏**（或C3消耗，例如H因子或I因子缺乏导致继发性C3耗竭）。用C3水平、H因子和I因子水平确诊。

(b) CH50正常而AH50缺失提示缺陷局限于旁路途径，反复脑膜炎球菌病指向**备解素缺乏**（X连锁）或D因子缺乏。用备解素和D因子测定确诊。

(c) 过氧化氢酶阳性菌引起脓肿和骨髓炎，而补体和免疫球蛋白正常，指向**慢性肉芽肿病**。用DHR流式细胞术检测和基因检测确诊。
:::
