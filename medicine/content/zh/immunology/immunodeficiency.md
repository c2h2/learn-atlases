免疫缺陷是免疫学的问诊：**它的语法是感染的微生物、部位、时机与严重度、加上家族史、生长、与非感染性的线索（自身免疫、肉芽肿、肿瘤、皮疹、发育），而它的算术是哪一类缺陷让你死于哪一类微生物。**本章按这一逻辑覆盖体液与联合免疫缺陷、吞噬与补体缺陷、继发免疫缺陷的现代图谱、及免疫科的急救。

本章涵盖抗体缺陷、联合与细胞缺陷、综合征与先天错误、及继发免疫缺陷。

## 抗体缺陷

::: definition 体液免疫缺陷 {#def-antibody}

::: definition 继发与获得性免疫缺陷 {#def-secondary}

::: example 五次肺炎的幼儿 {#ex-cVID-child}
一名3岁儿童在14个月中有四次培养阴性的肺炎、及伴鼓膜置管的慢性中耳炎；有一位母系的舅舅“在婴儿期死于胸部感染”；生长已滑过百分位；IgG 1.8、IgA测不出、IgM 0.2、破伤风应答差而肺炎球菌应答极差；流式显示转换记忆B细胞低。
::: solution

::: example 用维奈克拉时的无热源发热 {#ex-neutropenic}
一名68岁慢性淋巴细胞白血病患者用维奈克拉与奥妥珠单抗、第3疗程第12天、体温38.6、寒战、无定位症状就诊；中性粒细胞0.3、C反应蛋白12、胸片正常、原位留置输液港；他没在服复方磺胺，因为“你们停掉了”。

::: example 患卡介苗淋巴结炎的婴儿 {#ex-bcg}

::: summary
- 从模式而不是单次感染怀疑免疫缺陷：不寻常的微生物、部位、严重度、频率、结局、或对静脉抗生素的需要。
- 抗体缺陷以鼻窦肺的细菌感染与疫苗应答差呈现；既测免疫球蛋白也测功能、并按年龄区间判读。
- 联合与T细胞缺陷以生长停滞、机会性微生物、及疫苗的并发症在早期呈现；重症联合免疫缺陷是一个在感染之前被发现的移植候选者。
- 如今在成人中，由药物与恶性肿瘤造成的继发免疫缺陷在数量上超过先天错误：熟悉你的激素、抗CD20、JAK抑制剂与双特异性抗体的风险表。
- 无脾与补体缺陷是等待中的脑膜炎球菌与肺炎球菌的急症；在发热之前接种并教育。
- 治疗有三条腿：感染的预防疫苗、预防、免疫球蛋白、免疫的重建移植、基因治疗、酶、及并发症的监测肺、自身免疫、恶性。
:::

一名45岁患者有慢性咳嗽、支气管扩张、贾第鞭毛虫病、及可触及的脾与淋巴结、IgG 5.2正常低值、亚群正常、肺炎球菌应答差。免疫科想要更多信息。计划接下来的6个月。
::: solution
**对灰色地带做深度表型化（[[#def-antibody]]、[[immunology/antigen-recognition]]、[[respiratory/interstitial-vascular-disease]]）：重复测量的纪律——用结合疫苗做激发、并在4-8周重复肺炎球菌多糖的应答、按年龄校正血清型的判读、以及随时间看免疫球蛋白与亚类及特异性抗体的轨迹、而不是单次数字、及排除继发原因药物与淋巴增殖及丢失蛋白性肠病及肾病及抗癫痫及狼疮邻近的丢失——[[renal/filtration]]、[[gastrointestinal/digestion-absorption]]、[[blood/lymphoma-myeloma]]；组织的问题——淋巴结与脾的特征刻画为慢性淋巴细胞白血病与淋巴瘤及结节病及IgG4及多中心型Castleman病及非干酪性肉芽肿活检、对比GATA2与单核细胞B淋巴细胞树突细胞缺陷的工作流、及为浸润与骨髓增生异常及大颗粒淋巴细胞及STAT3功能获得谱的骨髓检查伴中性粒细胞减少与脾大及关节炎的大颗粒淋巴细胞白血病三联——[[blood/leukaemia]]、[[musculoskeletal/inflammatory-arthritis]]；遗传学——当存在失调特征时做全外显子或靶向组合CTLA4与LRBA、带它们的自身免疫性血细胞减少及低丙种球蛋白血症及淋巴增殖、及STAT3功能获得、带它们的糖尿病与肠病、及PIK3CD与受体酪氨酸激酶及NFκB家族、及GATA2的分枝杆菌与人乳头瘤病毒及肺泡蛋白沉积症的邻近、带咨询与同意的框架、及家系筛查的含义——[[genetics/genetic-testing]]、[[immunology/tolerance-regulation]]；及过渡期的保护包——早期治疗的抗生素与气道清除、及肺炎球菌与流感接种、及基线的断层与肺功能、及淋巴瘤警报症状的教育、及免疫科再诊的标准新的血细胞减少或B症状或淋巴结增大记录在案、好让“观察等待”意味着真的在被观察——[[clinical-skills/records-handover]]。**
