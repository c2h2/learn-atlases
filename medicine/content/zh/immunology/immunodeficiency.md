**免疫缺陷**是免疫系统某一部分的失灵，使人异常易受感染，并常常也易发生自身免疫、炎症或癌症。大多数儿童每年有六到十次呼吸道感染，大多数反复感冒的成人免疫系统也正常。关键在于识别出少数其感染讲述着另一个故事的人。

这个故事通常由感染本身讲出来。免疫系统的每一支都在特定部位防御特定的微生物，因此在做任何检查之前，病原体、感染部位、起病年龄和家族史通常就已指向有缺陷的成分。检查随后证实病史所提示的结论。

本章先阐述这一推理，然后介绍主要的原发性免疫缺陷（抗体、联合、吞噬细胞和补体缺陷）、常见得多的继发性免疫缺陷（包括HIV感染和无脾），以及检查和处理的原则。固有免疫的缺陷已在[[immunology/innate-immunity]]中介绍。

::: definition 原发性和继发性免疫缺陷 {#def-immunodeficiency}
**原发性免疫缺陷**现在通常称为**先天性免疫缺陷**（inborn error of immunity），由免疫系统的遗传缺陷引起。已知的有数百种，由国际免疫学会联合会（IUIS）分类。许多在儿童期发病，但有些（如常见变异型免疫缺陷）通常在成人期发病。

**继发性免疫缺陷**是获得性的，由其他疾病或其治疗引起：药物、血液系统肿瘤、HIV感染、脾缺失、蛋白丢失、营养不良或年龄极端。继发性免疫缺陷远比原发性常见。
:::

## 解读感染模式

提示感染异常的线索常用英文缩写**SPUR**概括：感染**严重**（Serious）、**持续**（Persistent）、**不寻常**（Unusual，病原体或部位不寻常）或**反复**（Recurrent）。其他警示信号包括婴儿生长迟缓、需要静脉抗生素才能清除感染、免疫缺陷或不明原因早亡的家族史，以及活疫苗引起的感染。

::: theorem 感染模式指向缺陷 {#thm-pattern}
| 缺陷成分 | 典型病原体 | 典型部位和特征 | 常见起病年龄 |
|---|---|---|---|
| **抗体** | 有荚膜细菌（肺炎链球菌、流感嗜血杆菌）、贾第虫（*Giardia*）、肠道病毒 | 鼻窦炎、中耳炎、肺炎、支气管扩张；慢性腹泻 | 6个月以后（母体IgG消退时）或成人期 |
| **T细胞（联合）** | 病毒（巨细胞病毒、腺病毒、水痘病毒）、念珠菌（*Candida*）、肺孢子菌（*Pneumocystis*）、分枝杆菌、活疫苗 | 生长迟缓、慢性腹泻、持续鹅口疮、肺炎 | 出生后最初几个月 |
| **吞噬细胞** | 金黄色葡萄球菌、革兰阴性菌、曲霉（*Aspergillus*）、念珠菌 | 皮肤和深部脓肿、口腔溃疡、伤口愈合不良 | 婴儿期或儿童期 |
| **补体（终末成分）** | 奈瑟菌（*Neisseria*） | 反复脑膜炎球菌病 | 任何年龄，常在青春期 |
| **补体（经典途径早期成分）** | 有荚膜细菌 | 狼疮样疾病 | 儿童期或成人期 |
| **脾** | 有荚膜细菌、疟原虫（*Plasmodium*）、二氧化碳嗜纤维菌（*Capnocytophaga*） | 暴发性脓毒症 | 脾缺失后的任何年龄 |
:::

::: proof
这一模式源于各成分的功能。抗体和补体调理胞外细菌，尤其是抵抗吞噬的有荚膜细菌，IgA保护黏膜表面，因此抗体缺陷引起反复的鼻窦和肺部细菌感染；抗体还在肠道和血液中中和肠道病毒并控制贾第虫。T细胞是控制胞内病原体（病毒、分枝杆菌、肺孢子菌、黏膜表面的真菌）所必需的，并为抗体产生提供辅助，因此T细胞缺陷引起两类感染，也是最严重的。吞噬细胞在组织中杀灭细菌和真菌，因此其缺陷引起脓肿。攻膜复合物对奈瑟菌尤其重要。脾脏过滤血液，并产生对多糖的快速IgM应答。

起病年龄取决于母体IgG。婴儿在最初几个月受经胎盘获得的IgG保护，因此单纯抗体缺陷很少在约6个月以前发病；而T细胞缺陷不能由母体抗体代偿，在出生后最初几周或几个月就会发病。
:::

## 抗体缺陷

抗体缺陷是引起症状的最常见的原发性免疫缺陷。它们主要表现为反复的呼吸道细菌感染。不治疗的话，反复的胸部感染会导致**支气管扩张**，而大部分远期损害可以通过早期诊断来预防。

### 婴儿生理性低丙种球蛋白血症

母体IgG在妊娠晚期穿过胎盘，因此足月儿出生时的IgG水平与母亲相近。这些IgG以约3至4周的半衰期下降。婴儿自身的产生起步缓慢。结果在约3至6月龄时出现IgG的**生理性低谷**。早产儿获得的母体IgG较少，低谷更深、出现更早。

### X连锁无丙种球蛋白血症

**X连锁无丙种球蛋白血症**（XLA）由**布鲁顿酪氨酸激酶**（BTK）基因变异引起，该酶是骨髓中B细胞发育所必需的。B细胞不能发育到前B细胞阶段以后，因此血液中几乎没有B细胞，所有免疫球蛋白类别都极低。患病男孩最初几个月健康，之后发生由有荚膜细菌引起的反复中耳炎、鼻窦炎和肺炎。扁桃体和淋巴结非常小，因为它们主要由B细胞滤泡构成。肠道病毒可引起慢性、有时致命的脑膜脑炎，口服脊髓灰质炎活疫苗是危险的。T细胞免疫正常，因此大多数病毒和真菌感染能被正常应对。

### 常见变异型免疫缺陷

**常见变异型免疫缺陷**（CVID）是成人中最常见的有症状的原发性抗体缺陷。它是一组异质性疾病，大多数找不到单一的基因缺陷，其定义为：

- IgG显著降低，伴IgA和/或IgM降低；
- **疫苗抗体应答差**（例如对肺炎球菌多糖或破伤风类毒素）；
- 排除了抗体降低的其他原因，尤其是药物、淋巴瘤和蛋白丢失等继发性原因；
- 通常在4岁以后发病；大多数患者在二十至四十多岁确诊。

B细胞通常存在，但不能分化为浆细胞。除感染外，许多患者发生**非感染性并发症**：自身免疫性血细胞减少、肺、肝和淋巴结的肉芽肿性病变（肉芽肿性淋巴细胞性间质性肺病）、肠病、脾肿大以及淋巴瘤风险增加。从出现症状到确诊往往要好几年，在此期间形成支气管扩张。

### 选择性IgA缺乏症

**选择性IgA缺乏症**是最常见的原发性免疫缺陷，在欧洲血统人群中大致每500至700人中有1人患病；在东亚人群中罕见得多。大多数患者健康，因为IgM能在黏膜表面部分代偿。有些人反复发生呼吸道或胃肠道感染，该病还与自身免疫相关，尤其是乳糜泻。有两点实际意义：乳糜泻IgA血清学会假阴性（见[[immunology/autoimmunity]]）；以及完全IgA缺乏并有抗IgA抗体的人，罕见情况下对含IgA的血液制品会发生严重反应。

::: example 反复肺炎的幼儿 {#ex-xla}
一名2岁男孩自9月龄起患过四次肺炎、反复中耳炎和一次肺炎球菌菌血症。此前他一直健康。查体几乎看不到扁桃体，也摸不到淋巴结。他的舅舅3岁时死于脑膜炎。免疫球蛋白：IgG 0.6 g/L，IgA和IgM测不出。最可能的诊断是什么？如何确诊？处理原则是什么？
::: solution
**诊断。**6个月后（母体IgG消退时）开始的有荚膜细菌反复感染、全低丙种球蛋白血症、扁桃体和淋巴结缺如，加上一位可能患病的舅舅，提示**X连锁无丙种球蛋白血症**。

**确诊。**流式细胞术淋巴细胞亚群显示**CD19 B细胞缺如或几乎缺如**（少于淋巴细胞的2%），T细胞正常。单核细胞BTK蛋白表达检测和*BTK*基因测序可确诊。随后可为其母亲提供携带者检测；她的每个儿子有1/2的患病概率，每个女儿有1/2的概率成为携带者。

**处理原则。**终身**免疫球蛋白替代**，每3至4周静脉注射或每周皮下注射，调整剂量以使谷浓度IgG维持在目标范围内，更重要的是预防感染。及时用抗生素治疗感染，监测肺功能并做影像学检查以发现支气管扩张，避免可能致病的活疫苗。替代治疗期间他不需要常规疫苗，因为他不能产生抗体，而免疫球蛋白提供被动保护；有时仍接种灭活流感疫苗，因为它可能刺激T细胞应答。在良好的替代治疗下，XLA患者大体上能过正常生活。
:::
:::

## 联合免疫缺陷

### 重症联合免疫缺陷

**重症联合免疫缺陷**（SCID）是一组T细胞发育失败、伴或不伴B细胞和NK细胞发育失败的缺陷。由于B细胞需要T细胞辅助，即使B细胞存在，抗体应答也会失败。SCID是儿科急症。

::: definition 重症联合免疫缺陷 {#def-scid}
**SCID**是一组遗传性疾病，T细胞缺如或无功能，因此细胞介导应答和抗体应答都失败。患儿在出生后最初几个月出现**生长迟缓**、**慢性腹泻**、持续性**口腔念珠菌病**以及耶氏肺孢子菌、巨细胞病毒、腺病毒和副流感病毒等**机会性病原体**感染。活疫苗（BCG、轮状病毒疫苗）可引起播散性疾病。如果没有造血干细胞移植或基因治疗，大多数患儿在1至2岁内死亡。
:::

SCID按存在哪些淋巴细胞群分类，这可以指向病因：

- **T−B+NK−**：共同γ链缺陷（*IL2RG*，X连锁，最常见的类型），该链为IL-2、IL-4、IL-7、IL-9、IL-15和IL-21的受体所共用；T细胞发育需要IL-7，NK细胞需要IL-15。其信号伙伴JAK3缺乏表现相同，但为常染色体隐性遗传。
- **T−B−NK+**：V(D)J重组缺陷（*RAG1*、*RAG2*、编码Artemis的*DCLRE1C*），T细胞和B细胞不能产生受体，而不重排受体基因的NK细胞正常（见[[immunology/antigen-recognition]]）。
- **T−B−NK−**：**腺苷脱氨酶（ADA）缺乏**，有毒的嘌呤代谢物杀死所有发育中的淋巴细胞。

淋巴细胞减少是关键线索：正常婴儿的淋巴细胞计数远高于成人，因此在成人中正常的淋巴细胞计数对婴儿来说可能非常低。穿过胎盘的母体T细胞可在SCID婴儿体内植入，引起移植物抗宿主样皮疹，也会干扰T细胞计数。

SCID的**新生儿筛查**检测**T细胞受体切除环**（TREC），即TCR基因重排时切除下来的小段环状DNA，只存在于新近生成的T细胞中。出生第一周采集的干血斑中缺乏TREC提示胸腺输出不足。许多国家已常规开展筛查；在英格兰，自2021年9月起作为NHS服务内评估开展。早期诊断很重要，因为在感染前移植的生存率最好，也可以避免接种活疫苗。

根治性治疗是**造血干细胞移植**，最好来自HLA相合的同胞。部分类型（如ADA缺乏）可用经校正的患者自身干细胞进行**基因治疗**。在此之前，婴儿需要隔离防护以避免感染、肺孢子菌预防、免疫球蛋白替代、避免活疫苗，并只能输注经**辐照**且巨细胞病毒阴性的血液制品，因为未经辐照的输血中存活的供者淋巴细胞可引起致命的输血相关移植物抗宿主病。

::: example 腹泻和鹅口疮的婴儿 {#ex-scid}
一名4月龄女婴自6周龄起腹泻，口腔鹅口疮经治疗仍持续，体重增长不良；她的体重从第50百分位降至第2百分位以下。她因咳嗽、呼吸急促和低氧入院，支气管肺泡灌洗发现耶氏肺孢子菌。淋巴细胞计数为$0.9 \times 10^9$/L。她的父母是表亲，一个哥哥或姐姐在5月龄时死于“肺炎”。最可能的诊断是什么？当务之急是什么？
::: solution
**诊断。**在出生后最初几个月起病，有生长迟缓、慢性腹泻、持续性念珠菌病和肺孢子菌肺炎，且淋巴细胞计数就其年龄而言明显降低（正常婴儿计数要高出数倍），强烈提示**重症联合免疫缺陷**。父母近亲婚配和同胞死亡提示常染色体隐性类型，如RAG1/2、Artemis、JAK3或ADA缺乏。

**紧急检查。**淋巴细胞亚群（T、B和NK细胞以及初始T细胞标志物）、免疫球蛋白、T细胞增殖试验和基因检测。还要做HIV检测，因为婴儿期HIV感染可有类似表现。

**当务之急。**治疗肺孢子菌肺炎，用PCR检查病毒（巨细胞病毒、腺病毒、呼吸道病毒），并紧急转诊至跨区域儿科免疫和移植中心。保护性隔离，免疫球蛋白替代，治疗后进行肺孢子菌预防，只输注经辐照的巨细胞病毒阴性血液制品，**不接种活疫苗**（核实她是否已接种轮状病毒疫苗，以及符合条件时是否接种了BCG）。立即开始家庭成员的HLA配型，为造血干细胞移植做准备；除部分类型可做基因治疗外，这是唯一的根治性治疗。以后出生的同胞可在出生时即得到诊断。
:::
:::

### 其他联合缺陷

- **22q11.2缺失综合征**（DiGeorge综合征）源于第三和第四咽囊发育异常。特征包括圆锥动脉干心脏畸形、甲状旁腺发育不全所致的低钙血症、特征性面容、腭异常以及学习和精神方面的困难。胸腺较小，大多数患儿有轻至中度T细胞缺陷，随年龄增长而改善；少数完全没有胸腺，表现类似SCID，需要胸腺移植。在T细胞功能明确之前，血液制品应经辐照，活疫苗应推迟。
- **Wiskott–Aldrich综合征**（X连锁，*WAS*）引起湿疹、伴**小血小板**的血小板减少、反复感染、自身免疫和淋巴瘤。
- **共济失调毛细血管扩张症**（*ATM*）引起进行性小脑共济失调、眼和皮肤毛细血管扩张、抗体和T细胞缺陷、放射敏感性和淋巴系统肿瘤高风险；甲胎蛋白升高。
- CD40配体缺乏引起的**高IgM综合征**见[[immunology/adaptive-responses]]。

## 吞噬细胞和补体缺陷

这些已在[[immunology/innate-immunity]]中介绍。概括如下：

- **中性粒细胞减少**最常由化疗引起，导致细菌和真菌感染；低于$0.5 \times 10^9$/L时严重程度急剧上升。
- **慢性肉芽肿病**引起由过氧化氢酶阳性细菌和曲霉所致的脓肿和肉芽肿；DHR试验可确诊。
- **白细胞黏附缺陷**引起脐带脱落延迟和无脓的感染，血液中性粒细胞计数很高。
- **终末补体**和备解素缺乏引起反复奈瑟菌感染；C3缺乏引起化脓性感染；经典途径早期成分缺乏引起狼疮。

## 继发性免疫缺陷

医院中所见的免疫缺陷者大多是继发性的，其中许多并未被如此标注。常见原因包括：

- **药物**：糖皮质激素、化疗、抗代谢药（硫唑嘌呤、吗替麦考酚酯、甲氨蝶呤）、钙调神经磷酸酶抑制剂、JAK抑制剂和生物制剂。**利妥昔单抗**清除B细胞6至12个月，可引起长期低丙种球蛋白血症；抗TNF治疗易导致结核和其他肉芽肿性感染；
- **血液系统肿瘤**：慢性淋巴细胞白血病和骨髓瘤引起低丙种球蛋白血症和功能性抗体缺陷；白血病及其治疗引起中性粒细胞减少；
- **蛋白丢失**：肾病综合征、蛋白丢失性肠病和严重烧伤导致IgG丢失；
- **营养不良**，全球免疫缺陷最常见的原因；
- **糖尿病**、**慢性肾脏病**、**肝硬化**和**饮酒**，损害中性粒细胞功能和其他防御；
- **年龄极端**：新生儿（尤其是早产儿）和老年人（**免疫衰老**，初始T细胞减少，疫苗应答减弱）；
- **无脾**和**HIV感染**，见下文。

:::warning
在排除继发性原因之前，不要给患者贴上CVID或其他原发性抗体缺陷的标签。成人IgG降低有许多获得性解释：药物（利妥昔单抗、苯妥英和卡马西平等抗癫痫药、糖皮质激素）、经肾或肠道的蛋白丢失以及B细胞肿瘤。血清蛋白电泳、尿蛋白测定和用药史是首次评估的一部分。因为把IgG降低归因于“CVID”而漏诊淋巴瘤或骨髓瘤，是严重的错误。
:::

::: example 老年男性抗体降低 {#ex-secondary}
一名71岁男性一年内患过三次肺炎。IgG 3.5 g/L，IgA 0.3 g/L，IgM 0.2 g/L。他服用雷米普利和阿托伐他汀。血红蛋白104 g/L，钙2.75 mmol/L，肌酐轻度升高。在考虑原发性抗体缺陷之前应做什么？
::: solution
**先考虑继发性原因。**71岁新发的低丙种球蛋白血症极不可能是原发性免疫缺陷。贫血、高钙血症和肾功能损害，加上多克隆免疫球蛋白受抑，强烈提示**多发性骨髓瘤**：恶性浆细胞克隆产生单一的单克隆免疫球蛋白或游离轻链，而正常的多克隆免疫球蛋白受到抑制，造成功能性抗体缺陷。由于副蛋白的存在，总球蛋白甚至可能看起来正常。

**检查。**血清蛋白电泳加免疫固定电泳、血清游离轻链、尿本周蛋白、血涂片，并转诊血液科做骨髓检查和影像学检查。慢性淋巴细胞白血病（血常规和血涂片、淋巴细胞免疫分型）和淋巴瘤是其他主要的恶性原因；还应检查蛋白丢失（尿蛋白/肌酐比值、白蛋白）和药物。

**处理原则。**治疗原发病。及时治疗感染，接种疫苗；如果在此基础上仍反复感染，且IgG低、疫苗应答差，可按国家标准进行免疫球蛋白替代。
:::
:::

### 脾

脾脏过滤血液，清除被调理的细菌以及衰老或被寄生虫感染的红细胞，其边缘区产生对多糖抗原的快速IgM应答。**无脾或脾功能减退**见于手术切除、镰状细胞病（反复梗死在幼儿期导致“自体脾切除”）、乳糜泻和其他疾病。血涂片可见**豪–焦小体**（Howell–Jolly bodies），即通常被脾脏清除的核残余物。

没有功能性脾脏的人终身面临**脾切除后暴发性感染**的风险，主要病原体是肺炎链球菌，也包括b型流感嗜血杆菌、脑膜炎奈瑟菌、犬咬二氧化碳嗜纤维菌（*Capnocytophaga canimorsus*，来自狗咬伤）以及重症疟疾。它可在数小时内从轻微发热进展为感染性休克。英国指南（UKHSA《绿皮书》）建议接种肺炎球菌、Hib和脑膜炎球菌（ACWY和B）疫苗，每年接种流感疫苗，考虑终身抗生素预防（尤其在脾切除后最初几年和高风险患者中），备用抗生素，随身携带警示卡，并建议发热时立即就医。

### HIV感染

HIV是全球最重要的获得性免疫缺陷。病毒通过**CD4**和一个辅助受体（通常是趋化因子受体**CCR5**，感染后期也可能是CXCR4）进入细胞，因此感染CD4 T细胞、巨噬细胞和树突状细胞。感染早期的大部分CD4 T细胞丢失发生在肠道相关淋巴组织中。遗传了两个CCR5变异**Δ32**拷贝的人缺乏这一辅助受体，对使用CCR5的毒株高度抵抗；正是这一事实使少数因血液肿瘤接受CCR5 Δ32纯合供者干细胞移植的人得以治愈。

不治疗时，HIV使CD4 T细胞在数年中进行性下降。**CD4计数**可预测可能发生哪些机会性感染：

| CD4计数（细胞/µL） | 变得可能发生的感染和疾病 |
|---|---|
| 低于约500 | 带状疱疹、口腔念珠菌病、结核（可在任何计数时发生） |
| 低于200 | 肺孢子菌肺炎；在美国监测定义中这一水平也界定了艾滋病 |
| 低于100 | 脑弓形虫病、隐球菌性脑膜炎 |
| 低于50 | 巨细胞病毒视网膜炎、播散性鸟分枝杆菌复合群感染 |

有效的**抗逆转录病毒治疗**（ART）抑制病毒复制，使CD4计数恢复，早期开始时预期寿命接近正常。英国（BHIVA）和WHO指南建议所有HIV感染者都接受ART，不论CD4计数如何。接受ART并持续检测不到病毒载量的人不会通过性行为传播HIV（**检测不到=不具传染性**，U=U）。CD4计数低于200细胞/µL时给予肺孢子菌预防，直至计数恢复。在CD4计数很低的人中开始ART，可能随着免疫恢复而暴露或加重已有的感染，即**免疫重建炎症综合征**（IRIS）。HIV的临床处理见[[infectious-diseases/hiv]]。

::: example 气促的成人 {#ex-hiv}
一名41岁男性3周来进行性劳力性气促、干咳和发热。他的血氧饱和度静息时95%，步行时降至86%。胸片显示双侧肺门周围间质性阴影。他有口腔念珠菌病。淋巴细胞计数为$0.8 \times 10^9$/L，其中CD4 T细胞占9%。计算他的CD4计数，解释其意义，并概述其诊疗的免疫学原则。
::: solution
**CD4计数。**CD4绝对计数等于淋巴细胞计数乘以CD4比例：$0.8 \times 10^9/\text{L} \times 0.09 = 0.072 \times 10^9/\text{L} = 72$细胞/µL（因为$10^9$/L等于每µL $1000$个，$0.072 \times 1000 = 72$）。

**意义。**CD4计数低于200细胞/µL，伴亚急性气促、运动时血氧饱和度下降、间质性阴影和口腔鹅口疮，强烈提示**肺孢子菌肺炎**，这是晚期HIV感染的首发疾病。计数低于100还使他面临脑弓形虫病和隐球菌病的风险，因此应考虑这些疾病（例如做血清隐球菌抗原检测）。

**诊疗原则。**确诊HIV感染并测定病毒载量。确认肺孢子菌感染（诱导痰或支气管肺泡灌洗液PCR或免疫荧光）并按指南治疗，若有低氧则加用糖皮质激素辅助治疗。在专科指导下**尽早开始ART**，通常在肺孢子菌治疗的最初两周内；推迟会增加发生其他机会性感染的风险，尽管开始治疗可能诱发IRIS。在ART下CD4计数恢复到200细胞/µL以上之前，继续肺孢子菌预防。提供性伴告知和检测。他的诊断是一次错失的机会：更早的HIV检测（英国指南在许多场合建议常规检测）本可以预防这场疾病。
:::
:::

## 疑似免疫缺陷的检查

根据感染模式分阶段选择检查。

1. **一线检查**：血常规加分类和血涂片（中性粒细胞、淋巴细胞、血小板大小、豪–焦小体）；血清免疫球蛋白IgG、IgA和IgM；**HIV检测**；成人做血清蛋白电泳；尿蛋白。
2. **抗体功能**：针对疫苗抗原（破伤风、Hib、肺炎球菌血清型）的特异性IgG；若水平低，在试验性接种后4至8周复测。
3. 流式细胞术**淋巴细胞亚群**：CD3、CD4、CD8 T细胞，CD19 B细胞，NK细胞，必要时加做初始和记忆亚群。
4. **补体**：CH50和AH50。
5. **中性粒细胞功能**：DHR试验。
6. **基因检测**，通常采用基因组合或外显子组测序，越来越多地使精确的分子诊断成为可能，并为靶向治疗开辟了道路。

结果必须与**年龄特异性参考范围**比较，因为淋巴细胞计数和免疫球蛋白水平在儿童期变化很大。

::: quiz
一名30岁女性3年内患过六次肺炎，现已有早期支气管扩张。她还患有自身免疫性血小板减少症。IgG 2.1 g/L，IgA 0.1 g/L，IgM 0.2 g/L。B细胞存在。她不服用任何药物，尿中无蛋白，血清电泳未见副蛋白。她对肺炎球菌多糖试验性接种无应答。最可能的诊断是什么？
- [ ] X连锁无丙种球蛋白血症
- [x] 常见变异型免疫缺陷
- [ ] 选择性IgA缺乏症
- [ ] 慢性肉芽肿病
::: solution
IgG低伴IgA和IgM低、疫苗应答差、B细胞存在、成人起病、反复呼吸道感染伴支气管扩张、自身免疫，且已排除继发性原因，符合**常见变异型免疫缺陷**。XLA见于男孩，自婴儿期起B细胞缺如；选择性IgA缺乏不影响IgG；CGD影响中性粒细胞的杀伤功能，引起脓肿，而不是伴免疫球蛋白降低的鼻窦和肺部感染。
:::
:::

::: history
1952年，美国陆军儿科医生Ogden Bruton描述了一名反复肺炎球菌感染的8岁男孩，其血清电泳缺少丙种球蛋白带；他给男孩注射丙种球蛋白，这是第一次免疫球蛋白替代治疗。以他命名的缺陷基因*BTK*于1993年被鉴定。20世纪50年代，瑞士医生描述了婴儿的重症联合免疫缺陷；1968年，Robert Good在明尼阿波利斯的团队为一名SCID男孩实施了首例成功的骨髓移植，供者是他的姐姐。1990年，一名ADA缺乏型SCID女孩成为首批接受基因治疗的人之一。

艾滋病于1981年首次被描述，当时美国疾病控制中心报告了此前健康的年轻男性中的肺孢子菌肺炎。病毒于1983年由巴尔–西诺西（Françoise Barré-Sinoussi）和蒙塔尼（Luc Montagnier）分离，两人于2008年获诺贝尔奖。1996年引入的联合抗逆转录病毒治疗把HIV从致命疾病变成了可控的慢性病。
:::

## 后续内容

免疫功能低下者的感染处理见[[infectious-diseases/immunocompromised-host]]，HIV见[[infectious-diseases/hiv]]。造成大部分继发性免疫缺陷的移植和药物性免疫抑制见[[immunology/transplant-tumour-immunology]]，免疫功能低下者的疫苗接种见[[immunology/vaccines-immunotherapy]]。

::: summary
- 当感染严重、持续、不寻常或反复，或有生长迟缓、活疫苗感染或家族史时，应怀疑免疫缺陷。
- 病原体、部位和起病年龄指向缺陷：抗体（有荚膜细菌、鼻窦和肺部、6个月以后）、T细胞（机会性病原体、病毒、真菌、最初几个月）、吞噬细胞（脓肿、金黄色葡萄球菌、曲霉）、终末补体（奈瑟菌）、脾（暴发性肺炎球菌脓毒症）。
- 母体IgG在最初几个月提供保护；约3至6月龄时出现IgG生理性低谷。
- XLA（*BTK*）使男孩B细胞和免疫球蛋白缺如；CVID引起IgG降低伴IgA和/或IgM降低以及疫苗应答差，通常见于成人，常有自身免疫和肉芽肿性并发症；选择性IgA缺乏常见且常无症状。
- SCID在婴儿期引起生长迟缓、腹泻、念珠菌病和机会性感染；其亚型（T−B+NK−、T−B−NK+、T−B−NK−）指向致病基因。新生儿TREC筛查、辐照血液、不接种活疫苗和干细胞移植是关键。
- 继发性免疫缺陷常见得多：药物、血液系统肿瘤、蛋白丢失、营养不良、慢性病、年龄极端、无脾和HIV。诊断原发性抗体缺陷前须排除继发性原因。
- HIV经CD4和CCR5耗竭CD4 T细胞；CD4计数预测机会性感染；所有人接受ART，低于200细胞/µL时进行肺孢子菌预防，以及U=U。
:::

::: exercise 哪一支？ {level=1}
说出下列每种表现最可能缺陷的免疫系统分支：(a) 一名6周龄婴儿患肺孢子菌肺炎和慢性腹泻；(b) 一名25岁患者第三次患脑膜炎球菌性脑膜炎；(c) 一名3岁儿童患金黄色葡萄球菌肝脓肿和曲霉肺炎；(d) 一名40岁患者反复鼻窦炎和肺炎，IgG低。

(a) T细胞（联合免疫缺陷）。(b) 终末补体（或备解素）。(c) 吞噬细胞杀伤（慢性肉芽肿病）。(d) 抗体（例如CVID，需先排除继发性原因）。

::: exercise 母体IgG {level=1 check="12*0.5^(84/28)"}
一名足月儿出生时IgG为12 g/L，全部来自母体。假设半衰期为28天，84天时母体IgG为多少g/L？
::: solution
84天是$84/28 = 3$个半衰期：$12 \times (1/2)^3 = 12/8 = 1.5$ g/L。到3个月时母体IgG所剩无几，此时不能自身产生抗体的婴儿开始发生感染。
:::

::: exercise 利妥昔单抗之后 {level=2}
一名58岁女性18个月前因肉芽肿性多血管炎接受利妥昔单抗治疗，近6个月内患过三次胸部感染。她的IgG为3.8 g/L。解释其机制、还需要哪些信息以及处理原则。
::: solution
**机制。**利妥昔单抗结合B细胞上的CD20并清除B细胞。长寿浆细胞不表达CD20，因此IgG水平通常只缓慢下降；但反复疗程、与其他免疫抑制剂联用以及年龄较大可导致持续性低丙种球蛋白血症，因为浆细胞池得不到来自B细胞的补充。

**还需要的信息。**B细胞计数（CD19），看B细胞是否已恢复；IgA和IgM；针对疫苗抗原的特异性抗体水平和试验性接种的应答；其他免疫抑制药物；蛋白丢失（尿蛋白）和血清电泳；以及她在使用利妥昔单抗之前IgG是否已经偏低（原先存在的抗体缺陷）。

**处理。**及时治疗感染，评估是否还需要继续使用利妥昔单抗，接种疫苗（B细胞被清除期间应答可能较差），并考虑抗生素预防。如果IgG低、疫苗应答差且感染持续，可按国家标准进行免疫球蛋白替代。这是继发性免疫缺陷，可能随B细胞恢复而改善。
:::
:::

::: exercise XLA的遗传 {level=2 check="0.5*0.5"}
一名女性经证实携带致病性*BTK*变异。她的伴侣未患病。他们下一个孩子是患病男孩的概率是多少？
::: solution
孩子为男孩的概率是$1/2$；携带者母亲的儿子有$1/2$的概率遗传到带变异的X染色体。因此患病男孩的概率为$1/2 \times 1/2 = 1/4 = 0.25$。仅就儿子而言，风险是$1/2$；女儿有$1/2$的概率成为携带者，但不患病。
:::
:::

::: exercise 脾切除之后 {level=2}
一名35岁自行车骑手因交通事故接受了脾切除。列出他感染风险增加的免疫学原因，以及应为他提供的预防措施。
::: solution
**原因。**脾脏过滤血液，其巨噬细胞清除调理不良的细菌；肺炎链球菌、b型流感嗜血杆菌和脑膜炎奈瑟菌等有荚膜细菌抵抗调理，主要靠脾脏清除。脾脏边缘区B细胞产生对多糖抗原的快速IgM应答。脾脏还清除被寄生虫感染的红细胞，因此疟疾更严重。

**预防。**接种肺炎球菌、Hib和脑膜炎球菌（ACWY和B）疫苗，择期脾切除最好在术前至少2周、急诊脾切除在术后2周接种，并按建议加强；每年接种流感疫苗（流感后继发细菌感染是一种风险）。考虑每日抗生素预防，尤其是在最初几年，并备好在发热初起时服用的备用抗生素。携带警示卡或手环。教育他发热时紧急就医，认真对待狗咬伤（二氧化碳嗜纤维菌），旅行时非常认真地预防疟疾。这些措施遵循UKHSA《绿皮书》和当地指南。
:::
:::

三名6月龄以下婴儿疑似SCID。淋巴细胞亚群：(a) T细胞缺如，B细胞存在，NK细胞缺如，男孩；(b) T细胞缺如，B细胞缺如，NK细胞存在，父母近亲婚配；(c) T、B和NK细胞均缺如，X线显示骨骼异常。分别提出最可能的基因缺陷并说明理由。
::: solution
(a) **共同γ链（IL2RG）缺陷**，X连锁。共同γ链是T细胞发育所需的IL-7受体和NK细胞所需的IL-15受体的组成部分；B细胞能发育，但缺乏T细胞辅助（和IL-21信号）而功能不良。JAK3缺乏表型相同但为常染色体隐性遗传，所以如果女孩出现这种模式，应考虑JAK3。

(b) **V(D)J重组缺陷**：*RAG1*、*RAG2*或*DCLRE1C*（Artemis）。T细胞和B细胞不能组装受体，因此不能发育，而NK细胞不需要重排，所以正常。常染色体隐性遗传与近亲婚配相符。Artemis缺乏还导致放射敏感性，这影响移植预处理方案的选择。

(c) **腺苷脱氨酶缺乏**。蓄积的脱氧腺苷代谢物对所有发育中的淋巴细胞有毒，因此T、B和NK细胞均缺如；ADA缺乏是一种全身性代谢病，这解释了骨骼异常（肋软骨连接处杯口样改变）以及可能的神经系统和听力问题。酶替代治疗可在移植或基因治疗前稳定患儿病情。

::: exercise 无脾男性发热 {level=3}
一名62岁男性20年前因外伤接受脾切除，现发热、寒战6小时，伴压之不褪色的皮疹。血压82/50 mmHg，乳酸6.1 mmol/L。他2天前被自家的狗咬伤。脾切除后他从未接种过任何疫苗。给出致病菌的鉴别诊断，解释为什么他的病情进展如此之快，并列出关键的紧急措施。
::: solution
**鉴别诊断。**脾切除后暴发性感染，最常见的是肺炎链球菌；脑膜炎奈瑟菌（压之不褪色的皮疹）；b型流感嗜血杆菌；鉴于狗咬伤，还有***犬咬二氧化碳嗜纤维菌***，这是一种来自狗唾液的革兰阴性菌，在无脾者中引起伴紫癜和弥散性血管内凝血的暴发性脓毒症。如果他去过疟疾流行区，还需排除疟疾。

**为什么这么快。**没有脾脏，进入血液的细菌不能被有效清除；有荚膜病原体在数小时内繁殖到极高数量，大量释放内毒素或细胞壁成分，引起细胞因子风暴、DIC和休克。这种风险终身存在，而未接种疫苗使他对最常见的病原体毫无保护。

**紧急措施。**按感染性休克处理：复苏（ABCDE），在不延误治疗的前提下做血培养，按当地针对无脾患者的脓毒症指南**立即静脉给予大剂量广谱抗生素**（覆盖肺炎球菌、脑膜炎球菌和二氧化碳嗜纤维菌），补液和血管活性药物，尽早请重症医学团队参与。之后他需要接种疫苗，考虑预防性和备用抗生素，并携带警示卡。
:::
