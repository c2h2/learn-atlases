V(D)J重组随机地产生淋巴细胞受体。其中许多不可避免地会结合机体自身的分子。如果所有这些自身反应性细胞都被允许应答，每个人都会患自身免疫病。大多数人没有患病，因为免疫系统有一套清除、沉默或约束自身反应性淋巴细胞的机制，它们共同产生**免疫耐受**。

耐受不是单一机制，而是若干层次，每一层捕获从上一层逃脱的细胞。这种分层设计解释了两个临床事实。某一层的单基因缺陷会引起严重、早发且模式可辨的自身免疫。而常见的自身免疫病通常需要几处小的失败同时出现。同样的机制也保护胎儿、使肠道耐受食物和共生细菌，它们也正是肿瘤免疫治疗有意松开的“刹车”。

本章介绍胸腺和骨髓中的中枢耐受、外周耐受（失能、清除、调节性T细胞和抑制性受体）、特殊部位的耐受，以及揭示每种机制的疾病。

::: definition 免疫耐受 {#def-tolerance}
**免疫耐受**是对原本会引起应答的抗原的特异性无应答。**自身耐受**是对机体自身抗原的耐受。耐受具有**抗原特异性**：处于耐受状态的人对其他抗原仍能正常应答。它不同于**免疫抑制**，后者是应答能力的普遍降低。
:::

## 中枢耐受

::: definition 中枢耐受 {#def-central}
**中枢耐受**是在淋巴细胞仍在中枢淋巴器官中发育时清除或重编程自身反应性细胞：T细胞在**胸腺**，B细胞在**骨髓**。其机制包括**克隆清除**（凋亡死亡）、**受体编辑**（在B细胞中，通过新的轻链重排改变特异性），以及把部分自身反应性CD4 T细胞转向**调节性T细胞**。
:::

### 胸腺中的T细胞选择

未成熟T细胞（胸腺细胞）从骨髓来到胸腺，在那里重排TCR基因。每个胸腺细胞随后接受两次检验。

**阳性选择**发生在皮质。皮质胸腺上皮细胞在自身MHC上提呈自身肽。TCR能微弱结合自身MHC的胸腺细胞获得存活信号。完全不能结合自身MHC的胸腺细胞毫无用处，因为它永远无法识别机体自身细胞提呈的抗原，于是因被忽视而死亡。T细胞就是这样获得MHC限制性的。在同一阶段，细胞根据其受体结合II类还是I类分子，分别定向为CD4或CD8。

**阴性选择**主要发生在髓质。髓质胸腺上皮细胞和树突状细胞提呈自身肽。TCR能强烈结合自身肽–MHC的胸腺细胞是危险的，会通过凋亡被清除。部分具有中至高度自身反应性的CD4胸腺细胞则被转向成为**调节性T细胞**。

::: theorem 胸腺选择的亲和力模型 {#thm-selection}
胸腺细胞的命运取决于其TCR与自身肽–MHC相互作用的强度：

- **不结合或极弱结合**：因被忽视而死亡（约90%的胸腺细胞）；
- **弱至中等结合**：阳性选择，作为常规T细胞存活；
- **强结合**：阴性选择而凋亡，或转向调节性T细胞谱系。

因此成熟的受体库富含对自身MHC弱结合的受体，而这恰好是强结合自身MHC加外来肽所需要的。
:::

胸腺如何清除只针对胰腺、甲状腺或皮肤特有蛋白的T细胞？髓质胸腺上皮细胞在转录调节因子**AIRE**（自身免疫调节因子）的控制下，表达数以千计的这类**组织限制性抗原**。实际上，胸腺髓质中包含了全身每个器官的影子。

**自身免疫性多内分泌腺综合征1型**（APS-1，又称APECED）显示了AIRE失灵的后果。它通常为常染色体隐性遗传。针对多种组织抗原的T细胞逃脱清除，患者发生针对多个内分泌腺的自身免疫。经典三联征是：

- **慢性皮肤黏膜念珠菌病**，常为最早的表现，见于幼儿期；
- **甲状旁腺功能减退症**；
- **原发性肾上腺皮质功能减退症**（艾迪生病）。

念珠菌病有一个引人注目的解释：大多数患者产生针对Th17细胞因子IL-17F和IL-22的中和性自身抗体，因此在黏膜表面存在获得性抗真菌防御缺陷。

::: example 鹅口疮与手足搐搦的少女 {#ex-aps1}
一名13岁女孩自4岁起反复口腔鹅口疮并有甲营养不良。现在出现手指刺痛和手足痉挛。血钙低、血磷高，甲状旁腺激素不适当地降低。应考虑什么统一的诊断？应预见哪些其他问题？如何确诊？
::: solution
**诊断。**慢性皮肤黏膜念珠菌病加上甲状旁腺功能减退（低钙、高磷、PTH低）是**APS-1**经典三联征中的两项，由*AIRE*功能缺失性变异引起。

**机制。**没有AIRE，胸腺髓质不能表达甲状旁腺、肾上腺和其他组织限制性抗原，因此针对它们的T细胞未被清除而攻击这些腺体。念珠菌病反映了中和IL-17F和IL-22的自身抗体。

**应预见的问题。**原发性肾上腺皮质功能减退是第三个组成部分，若被漏诊可能致命，因此她需要定期监测并了解相关症状；并发疾病可诱发艾迪生危象。其他特征包括原发性卵巢功能不全、1型糖尿病、自身免疫性肝炎、恶性贫血、白癜风、脱发、牙釉质发育不良和吸收不良。

**确诊。***AIRE*变异的基因检测，以及检测抗I型干扰素自身抗体（几乎所有患者都有，且极具特征性）。应为其同胞提供检测。
:::
:::

### 骨髓中的B细胞耐受

在骨髓中，受体强烈结合自身抗原的未成熟B细胞会得到第二次机会：继续重排轻链基因以取代自身反应性受体（**受体编辑**）。若失败则死亡。弱结合自身抗原的B细胞可离开骨髓，但会变为**失能**。B细胞耐受不如T细胞耐受完全，但这关系不大，因为大多数针对蛋白质的B细胞应答需要T细胞辅助，而T细胞本身是耐受的。

## 外周耐受

中枢耐受并不完全。有些自身抗原根本不在胸腺中表达，有些表达水平太低，清除的亲和力阈值也并不完美。每个健康人的循环中都有自身反应性T细胞。**外周耐受**控制着它们。

::: definition 外周耐受 {#def-peripheral}
**外周耐受**是在成熟自身反应性淋巴细胞离开中枢淋巴器官后对其进行的控制。其机制包括：

1. **失能**：在没有共刺激的情况下识别抗原后发生的功能性失活；
2. **清除**：反复受刺激的细胞发生凋亡，主要通过**Fas**和**Fas配体**；
3. **调节性T细胞**的**抑制**；
4. **抑制性受体**，尤其是**CTLA-4**和**PD-1**，它们关闭被激活的T细胞；
5. **忽视**：抗原从未在激活性情境中被提呈给T细胞，例如因为它被隔离在屏障之后。
:::

### 失能

如[[immunology/adaptive-responses]]所述，在没有CD28共刺激的情况下识别其肽–MHC的T细胞不会被激活，反而对随后的刺激（即使有共刺激）也失去反应。自身抗原通常由表达很少CD80和CD86的静息树突状细胞提呈，因此在外周遇到其抗原的自身反应性T细胞通常会变为失能。这是感染能触发自身免疫的原因之一：微生物产物激活了同时在提呈自身肽的树突状细胞，补上了缺失的共刺激。

### Fas介导的清除

反复受刺激的T细胞同时表达Fas（CD95）和Fas配体。Fas结合后经胱天蛋白酶-8触发凋亡。这种**活化诱导的细胞死亡**清除持续应答自身抗原的T细胞，并在感染后使应答收缩。

**自身免疫性淋巴细胞增生综合征**（ALPS）大多由*FAS*的杂合变异引起。淋巴细胞因不能死亡而蓄积。患儿出现：

- 慢性、非恶性的**淋巴结肿大和脾肿大**；
- **自身免疫性血细胞减少**，尤其是溶血性贫血和血小板减少；
- 特征性的**“双阴性”T细胞**增多，这些细胞表达αβ TCR，但既不表达CD4也不表达CD8（健康时约占T细胞的1%）；
- 终身淋巴瘤风险增加。

### 调节性T细胞

::: definition 调节性T细胞 {#def-treg}
**调节性T细胞**（Treg）是表达转录因子**FOXP3**和高水平CD25（IL-2受体α链）、能抑制其他免疫细胞激活和功能的CD4 T细胞。**胸腺Treg**在胸腺中由自身反应性前体发育而来。**外周Treg**在外周由常规CD4 T细胞分化而来，尤其是在肠道中，针对食物和共生菌抗原，在TGF-β和视黄酸的影响下产生。
:::

Treg通过多种机制发挥抑制作用：

- **CTLA-4**，Treg组成性表达。CTLA-4结合树突状细胞上的CD80和CD86，并把它们从细胞表面物理性地移除，使其他T细胞得不到共刺激。
- **消耗IL-2**：其高亲和力IL-2受体吸收IL-2，使邻近的效应细胞得不到IL-2。
- 分泌抑制性细胞因子**IL-10**、**TGF-β**和IL-35。

**IPEX综合征**（X连锁免疫失调、多内分泌腺病、肠病）由*FOXP3*功能缺失性变异引起。患病男孩缺乏功能性Treg，通常在出生后最初几个月内出现伴水样腹泻的严重自身免疫性肠病、1型糖尿病、湿疹样皮炎和自身免疫性血细胞减少。不治疗则致命；造血干细胞移植可治愈。天然携带*Foxp3*突变的scurfy小鼠患有同样的疾病，该基因正是借此被鉴定的。

Treg机制的缺陷会引起相关疾病。*CTLA4*单拷贝杂合缺失（CTLA-4单倍剂量不足）以及LRBA（一种保护CTLA-4免于降解的蛋白）缺乏，都会引起伴淋巴细胞器官浸润和抗体缺陷的自身免疫。合乎逻辑的治疗是用CTLA-4–Ig融合蛋白**阿巴西普**（abatacept）替代CTLA-4的功能，常常有效。

::: example 婴儿期腹泻和糖尿病的男孩 {#ex-ipex}
一名3个月男婴大量水样腹泻，饮食调整无效，生长迟缓，有湿疹样皮疹，并新诊断糖尿病，血糖很高，抗GAD抗体阳性。他的舅舅在婴儿期死于“顽固性腹泻”。最可能的诊断是什么？什么检查支持诊断？为什么该病累及这些特定器官？
::: solution
**诊断。**男孩出现新生儿或婴儿期自身免疫性糖尿病、自身免疫性肠病和皮炎，且有受累的舅舅（提示X连锁遗传），指向由*FOXP3*变异引起的**IPEX综合征**。

**检查。**流式细胞术可能显示FOXP3阳性CD4 CD25高表达细胞减少或缺失（尽管某些变异产生数量正常但无功能的细胞）。*FOXP3*基因检测可确诊。抗肠道（抗肠上皮细胞或抗harmonin）和抗胰岛抗原的自身抗体有支持意义。血清IgE常升高。

**为什么是这些器官。**在免疫系统持续接触它必须耐受的抗原的地方，最需要Treg。肠道持续面对食物和共生细菌，正常情况下外周Treg在那里占主导。皮肤是另一个富含环境抗原的屏障。没有Treg，效应T细胞攻击肠上皮、胰岛和皮肤。这种糖尿病是真正的自身免疫性糖尿病，不同于大多数由β细胞通道或胰岛素基因缺陷引起的单基因新生儿糖尿病。

**治疗原则。**支持治疗（营养、胰岛素），用免疫抑制控制炎症，以造血干细胞移植作为根治性治疗，由免疫专科团队负责。
:::
:::

### 抑制性受体：CTLA-4和PD-1

被激活的T细胞会自行关闭。有两个受体尤为重要。

**CTLA-4**在T细胞激活后数天内被诱导表达，与CD28竞争CD80和CD86，且结合亲和力高得多。它作用较早，主要在淋巴结中，提高激活的阈值。缺乏CTLA-4的小鼠在数周内死于大量淋巴细胞增生。

**PD-1**表达于反复受刺激的T细胞。γ干扰素可在几乎任何细胞上诱导其配体**PD-L1**，包括肿瘤细胞和炎症组织。PD-1信号招募磷酸酶，减弱TCR和CD28信号。它主要作用于组织、应答的后期，在慢性刺激时限制损伤。处于持续PD-1信号下的T细胞，例如在慢性病毒感染或肿瘤中，会变得**耗竭**：它们持续存在，但细胞因子产生和杀伤能力降低。

用抗体阻断这些受体——**伊匹木单抗**（ipilimumab，抗CTLA-4）以及**帕博利珠单抗**（pembrolizumab）或**纳武利尤单抗**（nivolumab）（抗PD-1）——可恢复T细胞对肿瘤的应答。它也会解除对自身的外周耐受，因此这些药物会引起**免疫相关不良事件**：结肠炎、肝炎、肺炎、皮炎、甲状腺炎、垂体炎、肾上腺炎、1型糖尿病、心肌炎和关节炎。其处理概述于[[immunology/transplant-tumour-immunology]]。

::: example 使用帕博利珠单抗期间的甲状腺功能 {#ex-irae}
一名62岁男性因转移性非小细胞肺癌接受帕博利珠单抗治疗。开始治疗六周后，他感到焦虑、心悸；游离T4升高，TSH受抑。又过了八周，他感到疲乏、怕冷，游离T4降低，TSH升高。从免疫学角度解释事件的经过。
::: solution
甲状腺毒症之后继以甲状腺功能减退的过程，是检查点抑制所致**破坏性甲状腺炎**的典型表现。阻断PD-1解除了T细胞的一个刹车，其中包括此前被外周耐受控制的甲状腺反应性T细胞（许多此类患者原先就有抗甲状腺过氧化物酶抗体）。T细胞攻击破坏滤泡，释放储存的甲状腺激素，引起一过性**甲状腺毒症**，核素扫描摄取低（不同于由TSH受体刺激性抗体驱动的格雷夫斯病）。储存的激素耗尽、腺体受损后，随之出现**甲状腺功能减退**，且常为永久性。

**处理原则。**甲状腺毒症期通常对症处理，例如用β受体阻滞剂；抗甲状腺药物无用，因为激素合成并未增加。甲减期给予左甲状腺素。帕博利珠单抗通常可以继续使用，因为这种情况用激素替代即可轻松处理。这不同于心肌炎等更危险的免疫相关事件，后者需要停药并给予大剂量糖皮质激素。决策由肿瘤科和内分泌科按现行指南共同作出。
:::
:::

## 特殊部位的耐受

有些组织具有**免疫豁免**：放在那里的外来移植物比在其他部位存活更久。例子有眼前房、睾丸，在一定程度上还有脑。豁免不只是隔离的问题；这些组织主动表达Fas配体和PD-L1，产生TGF-β，且淋巴引流有限。

豁免可能被打破。在**交感性眼炎**中，一只眼的穿通伤释放了被隔离的眼内抗原；T细胞在区域淋巴结中被激活，随后连**未受伤**的那只眼也一起攻击。同样，输精管结扎或睾丸损伤可导致抗精子抗体。

**胎儿**是携带父源HLA的半同种异体移植物，却不被排斥。有几种机制共同起作用。胎盘滋养层不表达经典I类分子HLA-A和HLA-B，限制了母体T细胞的识别；它转而表达HLA-C和非经典的**HLA-G**，后者抑制NK细胞。针对父源抗原的母体Treg在妊娠期扩增。子宫NK细胞不杀伤，而是帮助螺旋动脉重塑。

### 口服耐受与引入食物的时机

食物是每天大量摄入的外来蛋白，正常情况下被耐受。在肠道吸收的食物抗原在有利于外周Treg的耐受性环境中被提呈。相反，炎症皮肤（如婴儿湿疹）过早接触食物蛋白，可能促进致敏和过敏。

这一认识改变了临床实践。**LEAP**试验（Learning Early About Peanut Allergy，2015年发表）把640名4至11月龄、患严重湿疹和/或鸡蛋过敏的婴儿随机分为规律食用花生组和避免花生直至5岁组。意向性分析中，5岁时花生过敏在避免组发生率为**17.2%**，在食用组为**3.2%**。对花生皮肤点刺风团较大（提示已存在过敏）的婴儿被排除在外。英国和其他地区的指南现建议从约6月龄起，以适合年龄的形式与其他食物一起引入花生和鸡蛋等致敏食物，而不是推迟；高风险婴儿可能需要先咨询专科意见。

::: example 预防一例过敏需要多少婴儿？ {#ex-leap}
利用LEAP意向性分析的数据，计算在这一高风险人群中早期引入花生的绝对危险降低、相对危险降低和需治疗人数。
::: solution
**绝对危险降低**（ARR）$= 0.172 - 0.032 = 0.140$，即14个百分点。

**相对危险**$= 0.032 / 0.172 \approx 0.186$，因此**相对危险降低**为$1 - 0.186 \approx 0.81$，约81%。

**需治疗人数**$= 1/\text{ARR} = 1/0.140 \approx 7.1$。大约需要让7名高风险婴儿早期食用花生，才能预防一例5岁时的花生过敏。

这些数字适用于所研究的高风险婴儿（严重湿疹和/或鸡蛋过敏，且无较大的花生风团）。在基线风险较低的婴儿中，同样的相对降低会带来较小的绝对降低和较大的需治疗人数。
:::
:::

:::warning
很容易把耐受看作单纯的“没有应答”。实际上它是一种主动状态。调节性T细胞、抑制性受体以及食物抗原的耐受性提呈，都需要持续的免疫活动。这就是为什么这些机制受到干扰时耐受会丧失——例如检查点抑制剂、感染提供了共刺激或Treg缺失——也是为什么有时可以有意诱导耐受，如变应原免疫治疗或早期引入食物。
:::

## 耐受如何失败

本章的单基因疾病表明每一层都很重要。[[immunology/autoimmunity]]所讲的常见自身免疫病则不同：它们源于许多微小的遗传效应，每一个都略微削弱某种耐受机制，再加上环境触发因素。其中许多相关基因正是引起罕见单基因病的那些基因。例如，略微降低*CTLA4*功能或改变*PTPN22*（一种设定TCR信号阈值的磷酸酶）的常见变异，会增加1型糖尿病、类风湿关节炎和自身免疫性甲状腺病的风险。

| 机制 | 单基因疾病 | 主要特征 |
|---|---|---|
| 胸腺表达组织抗原 | APS-1（*AIRE*） | 念珠菌病、甲状旁腺功能减退、艾迪生病 |
| 调节性T细胞 | IPEX（*FOXP3*） | 婴儿肠病、1型糖尿病、皮炎 |
| 抑制性受体 | CTLA-4单倍剂量不足；LRBA缺乏 | 淋巴细胞浸润、血细胞减少、抗体缺陷 |
| Fas介导的清除 | ALPS（*FAS*） | 淋巴结肿大、脾肿大、自身免疫性血细胞减少 |
| 凋亡细胞的清除 | C1q缺乏 | 系统性红斑狼疮 |

::: quiz
一名儿童有慢性淋巴结肿大和脾肿大、自身免疫性溶血性贫血和血小板减少，且既不表达CD4也不表达CD8的TCRαβ阳性T细胞比例增加。最可能失灵的是哪种耐受机制？
- [ ] 胸腺皮质中的阳性选择
- [ ] AIRE对组织限制性抗原的表达
- [x] Fas介导的活化淋巴细胞清除
- [ ] FOXP3依赖的调节性T细胞发育
::: solution
淋巴细胞增生、自身免疫性血细胞减少和双阴性T细胞增多是自身免疫性淋巴细胞增生综合征的特征，通常由*FAS*变异引起。本应通过活化诱导凋亡而死亡的淋巴细胞蓄积，自身反应性细胞逃脱清除。AIRE缺陷引起内分泌自身免疫和念珠菌病，FOXP3缺陷引起伴肠病和糖尿病的IPEX。
:::
:::

::: history
1945年，Ray Owen注意到共享胎盘循环的异卵双生牛终生携带对方的红细胞，却不产生针对它们的抗体。伯内特（Frank Macfarlane Burnet）和芬纳（Frank Fenner）在1949年提出，免疫系统在发育期间学习什么是“自身”。1953年，比林厄姆（Rupert Billingham）、布伦特（Leslie Brent）和梅达沃（Peter Medawar）证明了这一点：出生时注射另一品系细胞的小鼠，后来能接受该品系的皮肤移植。伯内特和梅达沃因发现获得性免疫耐受共同获得1960年诺贝尔奖。

抑制性T细胞的概念在20世纪70年代流行，后来因所提出的机制无法证实而失宠。1995年，坂口志文（Shimon Sakaguchi）证明CD4 CD25 T细胞能预防小鼠的自身免疫；2001年和2003年，几个研究组把scurfy小鼠、人类IPEX综合征与转录因子FOXP3以及这些细胞联系起来。坂口志文与Mary Brunkow、Fred Ramsdell因外周免疫耐受方面的发现获得2025年诺贝尔生理学或医学奖。
:::

## 后续内容

常见的自身免疫病以及自身抗体在诊断中的应用见[[immunology/autoimmunity]]。分别试图诱导耐受和打破耐受的移植与肿瘤免疫治疗见[[immunology/transplant-tumour-immunology]]。

::: summary
- 耐受是抗原特异性的无应答。它分层建立：发育期间的中枢耐受和之后的外周耐受。
- 在胸腺中，不能结合自身MHC的胸腺细胞因被忽视而死亡，弱结合者被阳性选择，强结合者被清除或成为调节性T细胞。AIRE使胸腺能表达组织限制性抗原；其缺失引起APS-1。
- 在骨髓中结合自身抗原的B细胞进行受体编辑、死亡或变为失能。
- 外周耐受通过失能（有抗原无共刺激）、Fas介导的清除（ALPS中丧失）、FOXP3调节性T细胞（IPEX中丧失）、抑制性受体CTLA-4和PD-1以及对被隔离抗原的忽视来实现。
- Treg通过CTLA-4介导的CD80/CD86移除、消耗IL-2以及分泌IL-10和TGF-β发挥抑制作用。
- 检查点抑制剂阻断CTLA-4或PD-1以增强抗肿瘤免疫，可预见地引起甲状腺炎和结肠炎等免疫相关不良事件。
- 免疫豁免、母胎耐受和口服耐受都是主动过程。在LEAP试验中，高风险婴儿早期引入花生使5岁时花生过敏从17.2%降至3.2%。
- 常见自身免疫病涉及许多微小的遗传效应，作用于单基因耐受疾病所揭示的同一些通路。
:::

::: exercise 绝对危险降低 {level=1 check="0.14"}
在LEAP中，5岁时花生过敏在避免组发生率为17.2%，在食用组为3.2%。以小数表示的绝对危险降低是多少？
::: solution
$0.172 - 0.032 = 0.14$。需治疗人数为$1/0.14 \approx 7.1$。
:::

::: exercise 阳性选择还是阴性选择？ {level=1}
说明下列每个胸腺细胞最可能的命运：(a) 其TCR不结合任何自身MHC分子；(b) 其TCR以弱亲和力结合自身MHC；(c) 其TCR以高亲和力结合髓质上皮细胞提呈的自身胰岛素肽；(d) 对某自身肽具有中至高亲和力的CD4胸腺细胞。
::: solution
(a) 在皮质中因被忽视而死亡。(b) 阳性选择并成熟为常规T细胞。(c) 阴性选择：在髓质中凋亡（胰岛素肽因AIRE而在那里表达）。(d) 可能转向胸腺调节性T细胞谱系（FOXP3阳性），但也可能被清除。
:::
:::

::: exercise 说出缺陷 {level=1}
说出下列各例最可能受累的基因：(a) 一名男孩婴儿期起病的肠病、糖尿病和皮炎；(b) 一名儿童慢性念珠菌病、甲状旁腺功能减退和艾迪生病；(c) 一名儿童淋巴结肿大、脾肿大和自身免疫性血细胞减少。
::: solution
(a) *FOXP3*（IPEX）。(b) *AIRE*（APS-1）。(c) *FAS*（ALPS）。
:::
:::

::: exercise 感染与自身免疫 {level=2}
一个人体内有此前处于失能或被忽视状态的自身反应性T细胞。说明病毒感染可能如何触发其自身免疫，描述两种不同的机制。
::: solution
**旁观者激活。**病毒诱导的模式识别信号激活树突状细胞，使其表达CD80、CD86和炎症细胞因子。如果这些树突状细胞同时在提呈自身肽（例如来自被病毒损伤的组织），自身反应性T细胞此时同时获得信号1和共刺激，就可能被激活而非变为失能。组织损伤还会释放此前被隔离的自身抗原（如交感性眼炎）。

**分子模拟。**病毒或细菌的肽可能与自身肽足够相似，使针对微生物激活的T细胞或抗体与自身发生交叉反应。A组链球菌感染后的风湿热是经典例子，抗链球菌M蛋白抗体与心肌肌球蛋白交叉反应。

在这两种情况下，耐受此前并非不存在；它是靠缺乏激活性情境来维持的，而感染提供了这种情境。
:::
:::

::: exercise 为什么用阿巴西普治疗CTLA-4单倍剂量不足？ {level=2}
一名22岁男性反复胸部感染，IgG低，有自身免疫性血小板减少，肺和肠道有淋巴细胞浸润。基因检测显示*CTLA4*杂合功能缺失变异。解释为什么一个正常拷贝不够，以及为什么阿巴西普是合理的治疗。
::: solution
CTLA-4通过结合CD80和CD86并把它们从抗原提呈细胞上物理性移除来发挥作用。细胞表面CTLA-4的量很关键，因此只有一个功能性拷贝时，Treg和活化T细胞的CTLA-4太少，不能有效移除共刺激配体。这就是**单倍剂量不足**。T细胞随之过度激活、浸润器官并驱动自身免疫，而紊乱的应答也损害正常的抗体产生。**阿巴西普**是可溶性CTLA-4–Ig融合蛋白，结合CD80和CD86并阻断其与CD28的相互作用，替代了缺失的CTLA-4功能。重症病例考虑造血干细胞移植。
:::
:::

::: exercise 较低风险人群中的需治疗人数 {level=2 check="1/(0.05*(1 - 0.032/0.172))"}
假设在一个不干预时花生过敏风险为5%的婴儿人群中，早期引入花生的相对危险与LEAP相同（$0.032/0.172$）。计算需治疗人数（给出未取整的值）。
::: hint
绝对危险降低等于基线风险乘以相对危险降低。
:::
::: solution
相对危险降低$= 1 - 0.032/0.172 \approx 0.814$。绝对危险降低$= 0.05 \times 0.814 \approx 0.0407$。需治疗人数$= 1/0.0407 \approx 24.6$，即约25名婴儿。相对效应与高风险人群相同，但由于基线风险较低，预防一例需要治疗更多婴儿。这是把试验结果应用于基线风险不同的人群时的一般原则。
:::
:::

::: exercise 作为移植物的妊娠 {level=3}
解释为什么表达父源HLA分子的胎儿不被母体免疫系统排斥，并描述一种母体对胎儿抗原的免疫确实造成伤害的临床情况。
::: solution
有几种机制保护胎儿。(1) 与母体血液直接接触的绒毛滋养层缺乏经典I类和II类分子，绒毛外滋养层表达HLA-C、HLA-E和非经典的HLA-G，但不表达HLA-A或HLA-B，既限制了母体T细胞的识别，又通过HLA-G和HLA-E的受体抑制NK细胞。(2) 针对父源抗原的母体调节性T细胞在妊娠期扩增。(3) 蜕膜是耐受性环境，子宫NK细胞主要支持血管重塑而非杀伤。(4) 滋养层上的补体调节蛋白保护其免受补体攻击。

当母体**抗体**穿过胎盘时就会造成伤害。在**胎儿和新生儿溶血病**中，RhD阴性母亲在前次妊娠中被胎儿RhD阳性红细胞致敏，产生抗D IgG，后者经FcRn穿过胎盘破坏胎儿红细胞。预防方法是在规定时间给RhD阴性妇女注射抗D免疫球蛋白，以防止致敏。在**新生儿同种免疫性血小板减少症**中，针对父源血小板抗原（常为HPA-1a）的母体抗体破坏胎儿血小板，可引起颅内出血。
:::
:::

::: exercise 推理一例检查点毒性 {level=3}
一名55岁黑色素瘤女性在开始伊匹木单抗联合纳武利尤单抗治疗8周后出现严重血性腹泻。结肠镜显示结肠炎。(a) 解释为什么联合治疗比单药引起更多免疫相关不良事件。(b) 概述处理原则。(c) 为什么必须先排除感染？
::: solution
(a) CTLA-4和PD-1在不同阶段、不同部位起作用。CTLA-4主要在淋巴结中限制初始T细胞的启动，并被Treg利用，因此阻断它降低了激活新的自身反应性克隆的阈值，并损害Treg的抑制。PD-1主要在组织中约束已激活的T细胞。同时阻断两者就去掉了两个独立的刹车，于是更多自身反应性T细胞被启动，到达组织的细胞也更少受约束。肠道持续接触抗原且依赖Treg控制，因此特别容易受累。

(b) 对严重程度分级。对于严重结肠炎，暂停检查点抑制剂，给予静脉补液和支持治疗，并开始大剂量糖皮质激素。若数天内无反应，加用英夫利昔单抗或维得利珠单抗进一步免疫抑制。是否恢复治疗由肿瘤团队按ESMO等现行指南决定。

(c) 感染性结肠炎，尤其是艰难梭菌和巨细胞病毒感染，可酷似免疫相关结肠炎；给未控制感染的患者使用大剂量激素或英夫利昔单抗可能是危险的。因此应在治疗前或开始时送检粪便培养和艰难梭菌检测。
:::
:::
