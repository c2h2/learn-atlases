固有免疫系统识别的是各类微生物；适应性免疫系统识别的是单个分子，所用的受体并非直接编码在基因组中，而是在每个发育中的淋巴细胞里通过切割和连接基因片段装配而成。一个人大约有$10^{12}$个淋巴细胞，它们共携带数以百万计的不同受体，其中大多数永远遇不到与之匹配的抗原。

B细胞和T细胞“看”抗原的方式根本不同。B细胞的受体——即其表面的抗体——结合分子天然折叠的形状。T细胞的受体只结合另一个细胞表面**主要组织相容性复合体**（MHC）分子沟槽中的一段短肽片段。理解这一差别，就能解释为什么T细胞需要抗原提呈细胞、为什么移植配型的关键是HLA、为什么某些药物反应可用基因检测预测，以及为什么某些细菌毒素会引起休克。

本章介绍抗原、抗体和T细胞受体的结构、受体多样性的产生、MHC分子与两条抗原加工途径，以及HLA变异的临床后果。

## 抗原与表位

::: definition 抗原、表位和半抗原 {#def-antigen}
**抗原**是能被抗体或T细胞受体特异性结合的任何分子。**免疫原**是本身也能激发免疫应答的抗原。受体实际接触的抗原那一小部分是**表位**（抗原决定簇）。

- **B细胞表位**位于天然分子的表面。许多是**构象表位**：由序列上相距很远、经折叠而靠近的氨基酸组成。
- **T细胞表位**是蛋白质在细胞内降解后产生的**线性**肽。

**半抗原**是能被抗体结合、但本身不具免疫原性的小分子。它与载体蛋白共价结合后才具有免疫原性。青霉素是经典的临床例子：它与血清蛋白和细胞表面蛋白结合，药物–蛋白复合物可激发IgE或IgG应答。
:::

蛋白质是最强的免疫原，因为它们能被提呈给T细胞，T细胞再辅助B细胞。纯多糖不能由MHC提呈，因此只引起较弱的、T细胞非依赖性抗体应答。这一差别正是结合疫苗存在的原因，见[[immunology/vaccines-immunotherapy]]。

## 抗体与B细胞受体

::: definition 免疫球蛋白结构 {#def-antibody}
**抗体**（免疫球蛋白，Ig）是一种Y形糖蛋白，由两条相同的**重链**和两条相同的**轻链**（κ或λ）通过二硫键连接而成。每条链都有一个氨基端**可变（V）结构域**和一个或多个**恒定（C）结构域**。

- 两条臂是**Fab**片段（抗原结合片段）。一条重链和一条轻链的V结构域共同构成抗原结合部位。每个V结构域内有三个高变环，即**互补决定区**（CDR1至CDR3），与抗原接触；CDR3变异最大。
- 柄部是**Fc**片段（可结晶片段）。它不结合抗原，而是通过与细胞上的Fc受体和补体成分C1q结合，决定抗体发挥何种作用。
- 重链恒定区决定**同种型**（类别）：IgM、IgD、IgG、IgA或IgE。

**B细胞受体**（BCR）是膜结合型免疫球蛋白，与信号分子Igα和Igβ（CD79a和CD79b）相连。浆细胞分泌的是同一抗体的可溶形式。
:::

这种设计把识别与作用分开。可变端决定结合什么，恒定端决定接下来发生什么。因此，同一抗原特异性可以先以IgM出现、随后以IgG或IgA出现，作用不同而识别对象不变。同种型及其功能见[[immunology/adaptive-responses]]。

### 亲和力与亲合力

一个抗原结合部位与一个表位之间的结合强度称为**亲和力**，通常用**解离常数**$K_d$表示，即一半结合部位被占据时游离抗原的浓度。$K_d$越低，结合越紧。对简单的可逆相互作用，游离抗原浓度为$[A]$时结合部位被占据的比例为

$$
\theta = \frac{[A]}{[A] + K_d}.
$$ {#eq-occupancy}

**亲合力**是带有多个结合部位的完整抗体与具有重复表位的抗原之间的总结合强度。由于所有部位必须同时松开抗体才能脱离，亲合力可远大于亲和力。IgM是有十个结合部位的五聚体，初次应答中亲和力低，但对细菌多糖等具有重复表位的抗原亲合力高。

caption: 随游离抗原浓度升高（任意单位，如nmol/L），抗原结合部位被占据的比例$\theta = [A]/([A]+K_d)$。当$[A] = K_d$时占据率为一半（虚线）。第二条曲线的亲和力低十倍。免疫应答过程中的亲和力成熟使抗体从类似第二条的曲线移向类似第一条的曲线。这是单一结合部位达到平衡时的简化模型。
:::

::: example 多少抗原能占满受体？ {#ex-occupancy}
某抗体对其抗原的$K_d = 2$ nmol/L。(a) 游离抗原浓度为2 nmol/L时，结合部位被占据的比例是多少？(b) 18 nmol/L时呢？(c) 亲和力成熟后$K_d$降至0.2 nmol/L，此时2 nmol/L下的占据率是多少？
::: solution
用$\theta = [A]/([A] + K_d)$。

(a) $\theta = 2/(2 + 2) = 0.5$。按定义，浓度等于$K_d$时一半部位被占据。

(b) $\theta = 18/(18 + 2) = 0.9$。浓度为$K_d$的九倍时，90%的部位被占据。

(c) $\theta = 2/(2 + 0.2) = 0.909$，约91%。亲和力提高十倍，在抗原浓度低十倍时即可达到同样的占据率。这就是为什么后期经过亲和力成熟的抗体能在早期抗体无能为力的浓度下中和毒素和病毒。
:::
:::

## T细胞受体

::: definition T细胞受体 {#def-tcr}
**T细胞受体**（TCR）是由**α链和β链**（在大多数T细胞中）组成的膜异二聚体，每条链有一个可变结构域和一个恒定结构域，结构上与抗体的Fab臂相似。它从不分泌，只结合**与MHC分子结合的肽**（肽–MHC）。TCR与**CD3**复合物和ζ链相连，后者把激活信号传入细胞。

**共受体**CD4和CD8结合MHC分子的非多态性部分。**CD4**结合MHC II类分子，因此CD4 T细胞识别II类分子上的肽；**CD8**结合MHC I类分子，因此CD8 T细胞识别I类分子上的肽。
:::

少数T细胞使用γδ TCR。γδ T细胞富集于上皮，不依赖经典MHC识别应激诱导抗原和非肽抗原，行为部分类似固有免疫细胞。另一些T细胞群体识别非经典分子上的非肽抗原：**CD1**上的脂类，以及**MR1**上来自细菌的维生素B代谢物（由黏膜相关恒定T细胞，即MAIT细胞识别）。

TCR识别的关键事实是**MHC限制性**：某个T细胞只有在其肽由某一特定MHC分子（通常是个体自身的MHC）提呈时才能识别它。Rolf Zinkernagel和Peter Doherty在1974年发现，小鼠的细胞毒性T细胞只杀伤与该小鼠MHC相同的病毒感染细胞，从而证明了这一点。

| 特征 | B细胞受体/抗体 | T细胞受体 |
|---|---|---|
| 链 | 两条重链、两条轻链 | α和β（或γ和δ） |
| 每个分子的结合部位 | 两个（IgM、IgA更多） | 一个 |
| 识别对象 | 天然分子：蛋白质、多糖、脂类、核酸、小分子化学物 | 与MHC结合的短肽 |
| 表位 | 常为构象表位 | 线性表位 |
| 分泌形式 | 有（抗体） | 无 |
| 应答中亲和力成熟 | 有，通过体细胞高频突变 | 无 |

## 多样性的产生

基因组中没有足够的基因来直接编码数百万种受体。每个淋巴细胞通过**V(D)J重组**构建自己的受体基因。

::: theorem 体细胞重组产生受体库 {#thm-vdj}
每条受体链的可变结构域由分开的基因片段编码：**可变（V）**、**多样性（D）**（仅重链和TCR β链有）和**连接（J）**片段。在每个发育中的淋巴细胞里，各类片段各选一个并连接在一起，连接成的V(D)J单位编码该细胞的可变结构域。多样性有四个来源：

1. **组合多样性**：V、D、J片段的选择；
2. **连接多样性**：连接不精确，核酸外切酶去除核苷酸，**末端脱氧核苷酸转移酶**（TdT）添加非模板核苷酸；由此形成CDR3；
3. **链配对**：任何重链可与任何轻链配对（任何α链可与任何β链配对）；
4. 仅在B细胞中，免疫应答期间已重排基因的**体细胞高频突变**。
:::

::: proof
重组由**RAG1和RAG2**酶完成，它们识别每个片段旁的重组信号序列并切断DNA。切断的末端由处理双链断裂的通用DNA修复机制（非同源末端连接）加工和重新连接，其中包括核酸酶**Artemis**。由于连接不精确，三分之二的尝试会产生移码和无功能的链；未能产生功能性受体的发育中细胞会死亡。一条染色体上重排成功的细胞会停止另一条染色体上的重排（**等位基因排斥**），因此每个淋巴细胞只表达一种特异性。这就是克隆选择的物质基础：每个细胞都是带有单一受体的克隆始祖。
:::

算一算就知道单靠组合选择是不够的。教科书给出的人类重链基因座数据约为40个功能性V片段、23个D片段和6个J片段；组合选择得到$40 \times 23 \times 6 = 5520$种重链。连接多样性再把这个数字乘以许多个数量级，因此潜在受体库远大于体内淋巴细胞的数量。

由此得出两个临床推论。第一，**RAG1、RAG2或Artemis缺乏**使T细胞和B细胞都无法产生受体，导致T细胞和B细胞缺失而NK细胞（不重排受体）正常的重症联合免疫缺陷；见[[immunology/immunodeficiency]]。第二，由于每个淋巴细胞的重排都是独特的，共享同一重排的一群细胞就是一个克隆。在淋巴细胞浸润灶中检测到**克隆性**免疫球蛋白或TCR重排，是淋巴瘤而非反应性炎症的证据；监测该重排可衡量治疗后的白血病残留。

随机产生受体有代价：许多受体会识别自身。这些细胞如何被清除或控制，是[[immunology/tolerance-regulation]]的主题。

## MHC分子

T细胞只能看到另一个细胞展示的肽。展示分子由**主要组织相容性复合体**编码，这是6号染色体上的一个基因簇，在人类称为**HLA**（人类白细胞抗原）区域，因为其产物最早是用输血患者和多次妊娠妇女的抗体在白细胞上发现的。

::: definition MHC I类和II类分子 {#def-mhc}
**MHC I类**分子（HLA-A、HLA-B和HLA-C）由一条多态性重链与**β2微球蛋白**配对组成。它们表达于**几乎所有有核细胞**（红细胞上没有）。其沟槽两端封闭，容纳约8至10个氨基酸的肽，这些肽通常来自细胞**内部**合成的蛋白质。它们向**CD8** T细胞提呈。

**MHC II类**分子（HLA-DR、HLA-DQ和HLA-DP）由α链和β链组成。它们只在**专职抗原提呈细胞**上组成性表达：树突状细胞、巨噬细胞和B细胞（以及胸腺上皮）；γ干扰素可在其他细胞上诱导其表达。其沟槽两端开放，容纳较长的肽，约13至25个氨基酸，通常来自从细胞**外部**摄取的蛋白质。它们向**CD4** T细胞提呈。
:::

这种分工在生物学上是合理的。任何细胞都可能被病毒感染，因此每个有核细胞都需要能向细胞毒性T细胞展示自己正在合成什么。辅助性T细胞则需要与少数已对环境取样的专门细胞相互作用，因此II类分子只限于这些细胞。

### HLA多态性与遗传

HLA基因是人类基因组中多态性最高的基因，主要基因座已知等位基因数以千计。每个等位基因结合一组不同的肽，这由沟槽中容纳特定**锚定残基**的口袋决定。人群层面的多样性使单一病原体不太可能在所有人身上都逃避提呈。

HLA等位基因是**共显性**的：每个基因座上父母双方的等位基因都表达，因此一个人通常有六种不同的I类分子（A、B、C各两种）和多种II类分子。这些基因彼此靠近，通常作为一个整体遗传，称为**单倍型**，父母各传一个。因此两个同胞共享两个单倍型的概率为$\tfrac14$，共享一个的概率为$\tfrac12$，均不共享的概率为$\tfrac14$。这是移植中寻找同胞供者的基础，见[[immunology/transplant-tumour-immunology]]。

现代HLA分型采用DNA测序，等位基因按标准命名法书写：例如**HLA-B\*57:01**表示B基因座、等位基因组57、特定蛋白01。

## 抗原加工与提呈

::: theorem 两条途径，两类T细胞 {#thm-pathways}
蛋白质在细胞内的位置决定了由哪一类MHC提呈它。

- **胞质途径（I类）。**胞质中的蛋白质，包括病毒蛋白和肿瘤蛋白，被**蛋白酶体**降解。肽由转运体**TAP**泵入内质网，装载到新合成的I类分子上，运送到细胞表面供CD8 T细胞识别。
- **内吞途径（II类）。**经内吞或吞噬摄入的蛋白质在酸化的内体中降解。II类分子在内质网中合成时，其沟槽被**恒定链**封住；它们转运到内体，在那里恒定链被切割为一个称为**CLIP**的片段。分子**HLA-DM**移除CLIP，使高亲和力肽得以结合。II类分子–肽复合物转运到细胞表面供CD4 T细胞识别。
:::

::: proof
两条途径在空间上是分开的。I类分子在内质网中获得肽，而只有胞质肽能经TAP到达那里。II类分子在内质网中被恒定链保持空载，因此无法拾取这些胞质肽，只有到了内体才变得可以接纳肽，而那里正在降解内化的蛋白质。因此，在细胞内复制的病毒被报告给能够杀伤该细胞的CD8细胞毒性T细胞，而从外部摄取的物质被报告给协调应答的CD4辅助性T细胞。
:::

这里有一个重要的例外。要针对不感染树突状细胞的病毒或针对肿瘤启动CD8应答，树突状细胞必须把**外源性**抗原装载到I类分子上。某些树突状细胞能做到这一点，这一过程称为**交叉提呈**。它解释了蛋白疫苗为何在某些情况下能激发细胞毒性T细胞，也是肿瘤免疫的核心。

只有树突状细胞能有效激活**初始**T细胞。当它们的模式识别受体检测到微生物产物时，它们迁移到引流淋巴结，提高MHC表达，并表达**共刺激**分子CD80和CD86。共刺激的必要性是下一章的主题。

这些途径的缺陷罕见但颇有启发性。在**MHC II类缺陷**（“裸淋巴细胞综合征”的一种，由CIITA等转录因子缺陷引起）中，CD4 T细胞不能发育，患儿在婴儿期即表现为重症联合免疫缺陷。在**TAP缺陷**中，I类分子表达极低；患儿CD8 T细胞很少，出现慢性细菌性鼻窦和肺部感染以及坏死性皮肤肉芽肿，而病毒感染却出人意料地轻。

:::warning
常见的错误说法是“抗体识别肽”或“T细胞识别蛋白质”。抗体识别天然抗原的三维表面，抗原可以是蛋白质、碳水化合物、脂类或核酸；这就是为什么针对折叠分子制备的抗体可能识别不了蛋白质印迹上的变性蛋白。T细胞只识别与MHC分子结合的短线性肽；它们根本看不到游离抗原。
:::

## 超抗原

某些细菌毒素绕过了正常的识别。**超抗原**在肽沟槽以外，结合MHC II类分子的外侧和TCR β链可变区的侧面。因此它会激活所有使用某些β链可变区家族的T细胞，而不论其特异性如何。常规抗原大约激活$10^4$至$10^5$个T细胞中的一个；超抗原可激活多达五分之一的T细胞。

结果是细胞因子大量释放，包括TNF、IL-2和γ干扰素，引起发热、皮疹、毛细血管渗漏、休克和多器官衰竭。**中毒性休克综合征**由中毒性休克综合征毒素-1（TSST-1）等葡萄球菌超抗原引起，链球菌中毒性休克则由链球菌致热外毒素引起。处理见[[infectious-diseases/fever-sepsis]]；从免疫学角度看，常加用克林霉素是因为它能抑制毒素生成，重症病例有时使用含中和抗体的静脉注射免疫球蛋白。

::: example 卫生棉条与皮疹 {#ex-superantigen}
一名19岁女性在月经第4天就诊，体温39.8 °C，呕吐、水样腹泻，全身弥漫性日晒样红色皮疹。血压78/40 mmHg，肌酐升高。一个卫生棉条已放置超过24小时。解释其疾病的免疫学机制，以及为何比普通局部感染严重得多。
::: solution
这一表现符合**葡萄球菌中毒性休克综合征**：发热、弥漫性红皮病、低血压和多器官受累，并与滞留的卫生棉条有关。在棉条上生长的金黄色葡萄球菌产生**TSST-1**，一种超抗原。

TSST-1被吸收后，把抗原提呈细胞上的MHC II类分子与使用特定β链可变区家族的TCR交联，而不考虑沟槽中的肽是什么。大量T细胞同时被激活，而不是普通感染中被激活的极少数抗原特异性细胞。结果是细胞因子风暴：IL-2、TNF和γ干扰素引起发热、血管扩张和毛细血管渗漏，于是出现休克和器官功能障碍。局部感染可能微不足道，致病的是免疫应答。

处理原则：取出棉条（控制感染源），复苏，并按当地指南给予抗生素，既包括针对金黄色葡萄球菌的药物，也包括能抑制毒素合成的药物。一到两周后会出现特征性的手掌和足底脱皮。
:::
:::

## HLA与疾病

由于HLA等位基因决定提呈哪些肽，它们影响对感染、自身免疫和药物反应的易感性。关联以相对危险度或比值比表示，大多数远非决定性的。

| HLA等位基因 | 相关疾病 | 说明 |
|---|---|---|
| HLA-B27 | 强直性脊柱炎和其他脊柱关节炎 | 欧洲血统的强直性脊柱炎患者大多携带，但B27阳性者中只有少数发病 |
| HLA-DQ2和HLA-DQ8 | 乳糜泻 | 几乎所有患者携带其一，因此两者均缺如时乳糜泻可能性很小 |
| HLA-DR3和HLA-DR4（伴DQ2/DQ8） | 1型糖尿病 | DR3/DR4杂合子风险最高 |
| HLA-DRB1“共享表位”等位基因 | 血清阳性类风湿关节炎 | 与侵蚀性更强的病情相关 |
| HLA-B\*57:01 | 阿巴卡韦超敏反应 | 处方前筛查 |
| HLA-B\*15:02 | 卡马西平所致Stevens–Johnson综合征/中毒性表皮坏死松解症 | 常见于汉族、泰族及其他东南亚血统人群 |
| HLA-B\*58:01 | 别嘌醇所致重症皮肤反应 | 在某些亚洲人群中较常见 |

乳糜泻的机制已被详细阐明：HLA-DQ2和DQ8特别善于结合脱酰胺的麦胶肽，并把它们提呈给肠道CD4 T细胞。在药物超敏反应中，阿巴卡韦结合在HLA-B\*57:01的沟槽内，改变其提呈的自身肽，于是T细胞把改变了的自身当作外来物而发生反应。

这些关联灵敏度高而特异度一般，因此更适合**排除**而非确立诊断。HLA-DQ2/DQ8分型是一项阴性意义的检查：两者都缺如时，乳糜泻可能性很小。HLA-B27则相反：它在健康人群中常见，因此非特异性腰背痛患者B27阳性提供的信息很少。

::: example 阿巴卡韦用药前筛查 {#ex-abacavir}
一名34岁新诊断HIV感染的男性将开始抗逆转录病毒治疗，考虑使用阿巴卡韦（abacavir）。在PREDICT-1随机试验（Mallal等，2008年）中，前瞻性HLA-B\*57:01筛查使临床诊断的阿巴卡韦超敏反应从7.8%降至3.4%，使免疫学确证（斑贴试验阳性）的超敏反应从2.7%降至0%。HLA-B\*57:01对免疫学确证超敏反应的阳性预测值约为48%，阴性预测值为100%。解释这些数字。
::: solution
**阴性预测值100%。**没有一个HLA-B\*57:01阴性的患者发生免疫学确证的超敏反应。因此筛查阴性实际上排除了真正的阿巴卡韦超敏反应。这就是HIV指南建议在开始阿巴卡韦前检测HLA-B\*57:01、且不给携带该等位基因者使用阿巴卡韦的原因。

**阳性预测值约48%。**使用阿巴卡韦的等位基因携带者中约一半发生确证的超敏反应，因此携带该等位基因是必要条件而非充分条件。包括T细胞受体库在内的其他因素影响反应是否发生。对于一项旨在避免危险反应的检测，中等的阳性预测值是可以接受的，因为在有替代药物时放弃一种药物的代价很小。

**残余的3.4%。**筛查后的患者中仍有临床诊断的反应。其中许多是被误认为超敏反应的其他情况，因为其临床表现（发热、皮疹、胃肠道症状）缺乏特异性。因此，怀疑发生反应后即停用阿巴卡韦且永不再次激发的临床警示仍然适用。
:::
:::

::: example 卡马西平与血统 {#ex-carbamazepine}
一名28岁汉族女性新诊断局灶性癫痫，正在考虑使用卡马西平（carbamazepine）。她的医生计划先检测HLA-B\*15:02。解释这项检测的免疫学基础，以及结果阳性时如何处理。
::: solution
卡马西平可引起**Stevens–Johnson综合征和中毒性表皮坏死松解症**，这是严重的T细胞介导反应，细胞毒性CD8 T细胞和NK细胞杀伤角质形成细胞，导致大面积皮肤剥脱。在汉族和其他几种东南亚血统人群中，这种反应与**HLA-B\*15:02**强相关：药物直接与这一I类分子相互作用，形成的复合物被CD8 T细胞识别为外来物。

由于该等位基因在这些人群中相对常见而反应危及生命，药品监管机构和指南建议这些人群在开始卡马西平前进行检测。如果她携带HLA-B\*15:02，就避免使用卡马西平（通常对奥卡西平和苯妥英等结构相关药物也建议谨慎），改用其他抗癫痫发作药物。阴性结果并不能完全消除风险，因此仍要告知她，在用药最初几周若出现皮疹、口腔溃疡或发热，应立即停药并就医。在欧洲血统人群中，相关的等位基因不同（HLA-A\*31:01），其检测也不那么成熟。
:::
:::

::: quiz
某病毒感染肝细胞，但不感染树突状细胞。下列哪项最能解释针对该病毒的CD8 T细胞最初是如何被激活的？
- [ ] 肝细胞迁移到淋巴结，用MHC I类分子向初始CD8 T细胞提呈病毒肽。
- [ ] 抗体结合病毒并将其提呈给CD8 T细胞。
- [x] 树突状细胞摄取感染细胞或病毒物质，在淋巴结中将病毒肽交叉提呈于MHC I类分子上，激活初始CD8 T细胞。
- [ ] CD8 T细胞识别肝细胞表面的天然病毒蛋白。
::: solution
初始T细胞只能由树突状细胞激活，后者在淋巴结中提供肽–MHC和共刺激。本身未被感染的树突状细胞必须把外源性病毒蛋白引入I类途径：这就是交叉提呈。效应CD8 T细胞一旦被激活，就离开淋巴结，杀伤在自身MHC I类分子上展示病毒肽的感染肝细胞。T细胞从不识别天然蛋白，抗体也不提呈抗原。
:::
:::

::: history
1890年，冯·贝林（Emil von Behring）和北里柴三郎（Kitasato Shibasaburō）证明，用白喉或破伤风毒素免疫过的动物血清能保护其他动物；埃尔利希（Paul Ehrlich）提出，细胞带有结合毒素的“侧链”，侧链脱落进入血液就成为抗毒素。机体怎么能制造针对几乎任何物质（包括自然界从未存在过的合成化学物）的抗体？这个难题催生了抗原塑造抗体的“指导学说”。1957年，伯内特（Frank Macfarlane Burnet）提出了相反的观点：每个淋巴细胞带有一种预先存在的受体，抗原选择并扩增与之匹配的克隆。伯内特的**克隆选择**学说至今仍是这一学科的框架。

抗体的结构由埃德尔曼（Gerald Edelman）和波特（Rodney Porter）在20世纪60年代阐明（1972年诺贝尔奖）。1976年，利根川进（Susumu Tonegawa）证明抗体基因在B细胞中发生重排，解决了多样性问题（1987年诺贝尔奖）。多塞（Jean Dausset）、贝纳塞拉夫（Baruj Benacerraf）和斯内尔（George Snell）因发现MHC及其在免疫应答中的作用于1980年获奖，Zinkernagel和Doherty 1974年关于MHC限制性的发现于1996年获奖。1987年，Pamela Bjorkman、Don Wiley及其同事发表了HLA-A2的晶体结构，显示一段肽躺在沟槽中——这幅图景让此前的一切都说得通了。
:::

## 后续内容

识别只是第一步。识别了自身肽–MHC的T细胞是被激活、被忽略还是被关闭，取决于共刺激和细胞因子，见[[immunology/adaptive-responses]]和[[immunology/tolerance-regulation]]。HLA配型以及T细胞对外来MHC的应答是[[immunology/transplant-tumour-immunology]]的核心。

::: summary
- B细胞识别任何类型分子上天然的、常为构象性的表位；T细胞识别与MHC分子结合的短线性肽。
- 抗体由两条重链和两条轻链组成；可变结构域（带有CDR环）结合抗原，Fc区决定功能。亲和力是单个部位的结合强度，以$K_d$衡量；亲合力是多个部位的综合强度。
- TCR是与CD3相连的αβ异二聚体；CD4结合MHC II类分子，CD8结合MHC I类分子。T细胞具有MHC限制性。
- 受体多样性来自RAG1/RAG2介导的V(D)J重组、连接多样性（TdT）、链配对以及B细胞中的体细胞高频突变。RAG或Artemis缺乏引起T−B−NK+重症联合免疫缺陷。
- MHC I类分子（HLA-A、B、C）存在于所有有核细胞上，经蛋白酶体和TAP把胞质肽提呈给CD8 T细胞。MHC II类分子（HLA-DR、DQ、DP）存在于抗原提呈细胞上，在移除恒定链和CLIP后把内吞的肽提呈给CD4 T细胞。树突状细胞可把外源性抗原交叉提呈于I类分子上。
- HLA基因高度多态、共显性，以单倍型遗传；同胞HLA全相同的概率为1/4。
- 超抗原在沟槽之外结合MHC II类分子和TCR Vβ，激活大部分T细胞，引起中毒性休克。
- HLA关联（B27、DQ2/DQ8、B\*57:01、B\*15:02）主要用于排除疾病或预防药物反应。
:::

## 习题

::: exercise 三倍Kd时的占据率 {level=1 check="0.75"}
某抗体与其抗原结合的$K_d = 4$ nmol/L。游离抗原浓度为12 nmol/L时，其结合部位被占据的比例是多少？以小数作答。
::: solution
$\theta = 12/(12 + 4) = 12/16 = 0.75$。浓度为$K_d$的三倍时，四分之三的部位被占据。
:::
:::

::: exercise I类还是II类？ {level=1}
对下列每种情况，说明由哪一类MHC提呈抗原、哪类T细胞应答：(a) 受感染的支气管上皮细胞内合成的流感病毒蛋白；(b) 被其受体结合破伤风类毒素的B细胞所摄取的类毒素；(c) 黑色素瘤细胞内合成的突变蛋白；(d) 巨噬细胞吞噬体内的细菌蛋白。
::: solution
(a) I类，CD8 T细胞：蛋白在普通有核细胞的胞质中合成。(b) II类，CD4 T细胞：B细胞经BCR内化类毒素，并在II类分子上提呈其肽，由此获得辅助。(c) I类，CD8 T细胞。(d) II类，CD4 T细胞：吞噬体中的蛋白进入内吞途径。
:::
:::

::: exercise 组合多样性 {level=1 check="40*23*6*(40*5 + 30*4)"}
采用教科书估计值：约40个功能性V、23个D和6个J重链片段，约40个V和5个J κ片段，约30个V和4个J λ片段。忽略连接多样性，计算仅靠组合连接和随机配对能产生多少种不同的抗体可变区。
::: hint
分别计算重链数和轻链数（κ加λ），再相乘。
:::
::: solution
重链：$40 \times 23 \times 6 = 5520$。κ轻链：$40 \times 5 = 200$；λ轻链：$30 \times 4 = 120$；轻链共$320$。配对：$5520 \times 320 = 1\,766\,400$，约$1.8 \times 10^6$。连接多样性和体细胞高频突变使实际受体库比这再增加许多个数量级。
:::
:::

::: exercise 解读阴性的HLA检测 {level=2}
一名40岁女性有缺铁性贫血和腹胀，已坚持无麸质饮食一年，因此乳糜泻血清学检查现已无参考价值。她的HLA分型显示既无HLA-DQ2也无HLA-DQ8。能得出什么结论？为什么阳性结果的用处要小得多？
::: solution
几乎所有乳糜泻患者都携带HLA-DQ2或DQ8，因为需要这些分子把脱酰胺麦胶肽提呈给肠道CD4 T细胞。因此两者都缺如时乳糜泻可能性很小，应寻找其症状和缺铁的其他原因。阳性结果的用处小得多，因为普通人群中相当一部分人携带DQ2或DQ8，其中大多数永远不会患乳糜泻；阳性结果无法把她与健康人群区分开。如果存在DQ2/DQ8，就需要进行麸质激发，随后做血清学检查和十二指肠活检。
:::
:::

::: exercise 红细胞缺乏II类分子的意义 {level=2}
红细胞既不表达MHC I类也不表达II类分子。结合一种具体感染，说明这对宿主的一个好处和一个坏处。
::: solution
**坏处。**寄生在红细胞内的病原体，如疟疾血液期的恶性疟原虫（*Plasmodium falciparum*），无法被报告给CD8 T细胞，因为没有I类分子提呈其肽。因此对血液期疟疾的防御依赖抗体（针对输出到红细胞表面的寄生虫蛋白和裂殖子）以及脾脏的吞噬。

**好处。**红细胞比其他组织更容易在人与人之间输注，因为它们不带HLA分子，不会激发同种反应性T细胞应答；输血相容性主要取决于由抗体识别的ABO和其他红细胞抗原（见[[blood/transfusion]]）。此外，在病毒感染中红细胞也不会成为细胞毒性T细胞的靶标。
:::
:::

::: exercise 没有CD4 T细胞的孩子 {level=2}
一名7个月女婴持续腹泻、生长迟缓、口腔念珠菌病，并患耶氏肺孢子菌（*Pneumocystis jirovecii*）肺炎。淋巴细胞总数正常，但CD4 T细胞很低；有CD8 T细胞和B细胞。免疫球蛋白低。流式细胞术显示她的B细胞和单核细胞不表达HLA-DR。解释其机制。
::: solution
B细胞和单核细胞上HLA-DR缺失提示**MHC II类缺陷**，通常由开启所有II类基因的转录因子之一（如CIITA或RFX复合物）缺陷引起。CD4 T细胞在胸腺中通过识别II类分子上的自身肽而被选择；没有II类分子，几乎没有CD4 T细胞发育，而在I类分子上被选择的CD8 T细胞仍然存在。没有CD4辅助，B细胞不能产生类别转换的抗体，因此尽管有B细胞，免疫球蛋白仍低。结果是伴机会性感染的联合免疫缺陷。根治方法是造血干细胞移植。
:::
:::

::: exercise HLA-B27的价值 {level=3}
设某人群中8%的人携带HLA-B27，强直性脊柱炎患病率为0.2%，患者中90%为B27阳性。(a) B27阳性者中患强直性脊柱炎的比例是多少？(b) 这对慢性腰背痛患者检测HLA-B27有何提示？
::: hint
以100 000人计算。有多少人患强直性脊柱炎且B27阳性？B27阳性者共有多少？
:::
::: solution
(a) 在100 000人中，200人患强直性脊柱炎，其中$0.9 \times 200 = 180$人B27阳性。B27阳性者共$8000$人。因此$180/8000 = 0.0225$，按这些示意数字约2.3%的B27阳性者患病。

(b) 对于非特异性腰背痛患者，单独一项HLA-B27阳性只能适度提高患病概率，因为大多数B27阳性者永远不会发生脊柱关节炎。它只有作为结构化评估的一部分才有用：腰背痛的炎性特征、骶髂关节MRI、CRP以及葡萄膜炎等其他特征。阴性结果降低了患病概率，但在本例中有10%的患者为B27阴性，因此不能排除诊断。
:::
:::

::: exercise 中毒性休克与感染性休克 {level=3}
比较葡萄球菌中毒性休克综合征与革兰氏阴性菌感染性休克的休克机制。为什么静脉注射免疫球蛋白可考虑用于重症链球菌中毒性休克，而不用于革兰氏阴性菌脓毒症？
::: solution
在革兰氏阴性菌感染性休克中，触发因素是一种病原体相关分子模式，主要是脂多糖，它激活固有免疫细胞上的TLR4，驱动TNF、IL-1和IL-6释放；应答与细菌负荷成比例，主要由固有免疫细胞介导。在中毒性休克综合征中，触发因素是超抗原，它不论肽为何，通过交联MHC II类分子和TCR Vβ激活大部分T细胞。即使局部感染很小，细胞因子风暴（IL-2、γ干扰素、TNF）也可能极为猛烈。

从数千名献血者混合制备的静脉注射免疫球蛋白含有能中和多种链球菌超抗原的抗体，因此可能减少已在循环中的毒素对T细胞的持续激活。脂多糖通过固有受体起作用，不是一种能被混合抗体制剂以有临床意义的方式可靠中和的单一毒素，因此IVIG在革兰氏阴性菌脓毒症中没有确立的作用。其在链球菌中毒性休克中的使用仍由专科医生根据当地和国家指南决定。
:::
