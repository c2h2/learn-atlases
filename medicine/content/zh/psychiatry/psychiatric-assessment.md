精神科评估与其他任何医学评估承担着相同的任务：采集病史、检查患者、考虑还有什么可以解释眼前的表现，最后得出工作诊断并制订计划。不同之处在于材料。检查主要针对患者在会谈中所说和所做的内容，病史的大部分也涉及想法、感受和人际关系，而不是器官。

本章讲授这种评估的三个部分：精神科病史、精神状况检查和风险评估。本章还介绍容易被遗忘的躯体方面，以及如何把各项发现整合为个案概念化。后续各章都假定读者已经掌握这些内容。

## 安排会谈

好的信息取决于好的会谈。一个恐惧、多疑或羞愧的人，不会向一个显得匆忙或带有评判态度的人讲述自己的体验。

::: definition 精神科会谈 {#def-interview}
**精神科会谈**是一种半结构化的交谈，目的是理解患者的问题、确立诊断并建立工作关系。会谈从**开放式问题**（“请跟我说说最近发生了什么”）过渡到检验特定症状的**聚焦式问题**（“您是否比平时醒得更早？”）。**知情人病史**（collateral history）是从熟悉患者的人（如亲属、照护者或全科医生）那里获得的信息；除非存在紧迫的安全理由，应在征得患者同意后获取。
:::

一些实际要点会带来很大差别：

- **房间。**选择安静、私密的空间。斜向而坐，不要正面相对。在急诊场合，要了解出口和报警系统的位置，并避免以一种让患者感到被困住的方式站在患者与门之间。
- **开场。**做自我介绍，说明会谈的目的和预计时长，并说明信息将如何处理。询问对方希望如何被称呼。
- **倾听。**在最初几分钟让患者不受打断地讲述。复述你听到的内容（“听起来过去这个月让您筋疲力尽”）。在适当的时候进行小结。
- **语言。**使用通俗的词语，不用术语。如果患者的母语不是英语，应使用专业口译员而不是家庭成员。亲属可能会过滤所说的内容，患者在他们面前也可能无法自由地谈论受虐待、物质使用或自杀想法。
- **文化。**询问患者及其家人如何理解这个问题。在患者所属文化或宗教群体中共有的信念不是妄想，痛苦也可能主要以躯体方式来描述。

## 精神科病史

下列标题遵循通常的书面记录格式。实际会谈中，可以根据交谈的进展在各项之间灵活切换。

| 标题 | 内容 |
|---|---|
| 主诉 | 用患者自己的话描述的问题，起病、病程、演变以及对日常生活的影响 |
| 现病史 | 症状的细节、诱因、有帮助的因素、以往的求助尝试 |
| 既往精神病史 | 以往的诊断、住院（包括依据精神卫生法的强制住院）、治疗及其效果、自伤 |
| 既往躯体病史 | 躯体疾病、头部外伤、癫痫、甲状腺疾病、近期感染 |
| 用药 | 当前及近期用药、依从性、不良反应、非处方药和草药制剂 |
| 物质使用 | 以每周单位数计的饮酒量、烟草、大麻及其他药物，使用模式及后果 |
| 家族史 | 亲属中的精神疾病、自杀、物质使用和神经系统疾病 |
| 个人史 | 出生与发育、童年逆境、教育、工作、人际关系、性生活史 |
| 司法史 | 被捕、定罪、暴力行为、正在进行的法律程序 |
| 社会状况 | 住房、经济、照护责任、需要抚养的子女、支持系统 |
| 病前人格 | 患病前的状态：兴趣、应对方式、人际关系 |

有两项需要特别强调。第一，一定要询问**需要抚养的子女**以及患者所照护的其他人，因为他们的安全可能取决于答案。第二，一定要采集**药物和饮酒史**。中毒和戒断几乎可以引起或模仿每一种精神综合征，物质使用还会改变风险。

::: example 全科诊所中的首次会谈 {#ex-first-interview}
Daniel Okafor 先生，34 岁，仓库经理，因为“脑子停不下来”就诊于全科医生。自公司宣布裁员以来，他已经睡眠不佳两个月。全科医生应如何安排接下来的十五分钟？

::: solution
**以开放式问题开始。**“请再多说说停不下来是什么感觉。”Okafor 先生描述自己躺着担心钱的问题、胸口发紧，并且对孩子容易发脾气。

**明确主要综合征。**用聚焦式问题检查抑郁（情绪低落、兴趣丧失、早醒、食欲、自责、无望感）和焦虑（难以控制的担忧、坐立不安、肌肉紧张、惊恐发作）。他报告持续的担忧和坐立不安，但仍然喜欢和儿子踢足球，周末情绪会好转。

**筛查要点。**饮酒：为了“帮助睡眠”，他已从每周约 10 个单位增加到约 30 个单位。用药：无。躯体：静息时无心悸，体重稳定。直接询问自杀想法；他说从未有过。

**背景。**他与伴侣及两个分别为 6 岁和 9 岁的孩子同住。他的父亲有“神经问题”，并且大量饮酒。

**小结并制订计划。**表现提示在工作压力背景下的广泛性焦虑，饮酒量上升，目前可能正在加重他的睡眠问题。全科医生检查甲状腺功能，就饮酒给出简短建议，解释心理治疗的选择，并安排两周后复诊。询问自杀并没有让他不安。这样的询问是常规，并不会诱发这种念头。
:::
:::

## 精神状况检查

病史描述的是过去。**精神状况检查**（mental state examination，MSE）记录的是会谈过程中观察到的和患者报告的情况。它相当于精神科的体格检查，书写时应让另一位临床医生能够想象出患者的样子，并能与日后的评估作比较。

::: definition 精神状况检查 {#def-mse}
**精神状况检查**是对患者在评估时精神功能的结构化描述，包括以下标题：外貌与行为；言语；心境与情感；思维（形式与内容）；感知；认知；自知力。每一项都记录观察所见和患者本人的报告，最好附有简短的原话引用。
:::

### 外貌与行为

描述你所见到的：自我照料、衣着、体重、躯体疾病或中毒的迹象、外伤。注意目光接触、交流关系、活动水平以及任何异常动作。**精神运动性迟滞**是思维和动作的减慢，是重度抑郁的典型表现。**精神运动性激越**是不安的、无目的的活动。注意震颤、肌张力障碍或静坐不能的不安，它们可能是药物的不良反应。

### 言语

描述语速、音量、语调和言语量。**言语迫促**是快速、难以打断的言语，是躁狂的典型表现。**言语贫乏**指自发言语很少。此处描述言语本身，其逻辑组织属于思维形式。

### 心境与情感

**心境**是持续的情绪状态，由患者本人描述（“您最近自我感觉怎么样？”）。用患者自己的话记录，必要时用 0–10 分的量表记录。**情感**是观察到的、随时变化的情绪表达。情感可以是有反应性的（变化恰当）、受限的、迟钝的或平淡的、不稳定的（变化迅速），或不协调的（与所述内容不相称，例如描述丧亲时发笑）。

### 思维形式

**思维形式**是思想之间的联系方式，根据言语来判断。**形式思维障碍**指这种联系本身受到干扰：

- **思维奔逸**：话题快速跳跃，但每次跳跃都能通过双关、押韵或联想追溯。典型见于躁狂。
- **联想松弛**（思维脱轨）：观念之间的联系丧失，听者无法跟上。典型见于精神分裂症。
- **病理性赘述**：绕很长的弯路，最终才到达要点。**思维离题**：回答逐渐偏离，再也不回到问题上。
- **思维中断**：思路突然停止。
- **语词新作**：创造新词，或以个人化的方式使用普通词语。

### 思维内容

思维内容包括先占观念、担忧、伤害自己或他人的想法以及异常信念。

::: definition 异常信念与侵入性思维 {#def-beliefs}
**妄想**是一种坚定的、错误的信念，尽管存在相反的证据仍坚信不疑，且不能用患者的文化、宗教或亚文化背景来解释。妄想按主题描述：被害、夸大、罪恶、虚无、躯体、关系、嫉妒或钟情（钟情妄想）。

**超价观念**是一种可以理解但不合理、并主导患者生活的信念，例如神经性厌食患者坚信自己超重。它不像妄想那样僵固。

**强迫观念**是一种不想要的、侵入性的想法、意象或冲动，患者承认它来自自己的头脑并试图抵抗。**强迫行为**是为减轻强迫观念引起的痛苦而进行的重复动作或心理仪式。
:::

### 感知

**幻觉**是在没有外界刺激的情况下产生的知觉，被体验为真实的，并定位于外部空间。它可以出现在任何感觉中：听觉、视觉、触觉、嗅觉或味觉。**错觉**是对真实刺激的错误感知，例如在昏暗的光线下把挂在门上的外套看成一个人。**假性幻觉**是一种类似知觉的体验，患者能认识到它来自自己的头脑。

特定类型提示特定诊断。听到以第三人称谈论自己的声音，或听到对自己进行实况评论的声音，提示精神分裂症。视幻觉在被证明为其他原因之前，应首先考虑器质性病因，如谵妄、药物中毒或路易体痴呆。入睡时（入睡前幻觉）或醒来时（醒后幻觉）出现的幻觉很常见，通常是正常的。

### 认知

记录对时间、地点和人物的定向力，注意力和集中力，以及记忆。在简短评估中，**4AT** 是经过验证的谵妄筛查工具。它对警觉性、简短精神测验（年龄、出生日期、地点、年份）、注意力（倒背月份）以及急性变化或病程波动进行评分；4 分或以上提示可能存在谵妄。怀疑痴呆时，使用较长的工具，如**蒙特利尔认知评估**（MoCA）或**Addenbrooke 认知检查**（ACE-III）。筛查分数用于支持临床判断，它们本身从不构成诊断。

### 自知力

**自知力**是患者对自身状况的理解。询问他们是否认为自己有什么不对、这是否可能是一种疾病，以及是否认为治疗可能有帮助。自知力不是全有或全无的，也不等同于决策能力：一个人可能不同意诊断，但仍能理解和权衡作出某一特定决定所需的信息。

::: warning 不要把心境记为“还好”就到此为止
一个常见错误是在简短交谈后写下“心境：还好，情感：正常”，尤其当患者安静而有礼貌时。应直接询问心境、兴趣、睡眠、食欲、无望感和自杀想法，并根据观察描述情感。许多重度抑郁患者表现得很有礼貌，许多精神病性障碍患者除非被以平静、好奇的方式询问，否则会把自己的信念藏在心里。
:::

## 躯体评估与器质性病因

精神症状常常有躯体原因。**器质性**一词仍被用于描述由可识别的脑部或全身性疾病、药物或毒物引起的精神障碍。漏诊器质性病因是精神科最严重的错误之一，因为潜在疾病可能是可治疗的，有时还很危险。

::: theorem 首先考虑器质性病因 {#thm-organic}
每一次新的精神科表现都需要与临床情况相称的躯体评估。存在以下情况时，器质性病因的可能性尤其大：急性起病、意识或注意力波动、定向障碍、视幻觉、约 40 岁以后首次发病、神经系统体征异常、近期头部外伤、新出现的躯体症状或物质使用。
:::

::: proof
精神活动依赖于正常工作的大脑，而大脑对其化学和物理环境十分敏感。感染、缺氧、低血糖、电解质紊乱、内分泌疾病、药物和戒断都会扰乱神经元功能，其结果往往首先表现为注意力、心境或感知的改变。谵妄是最常见的例子：它表现为注意力不集中和意识波动，经常被误读为激越或精神病性症状。该原则中列出的特征正反映了这一生理学基础。原发性精神障碍通常在青春期或成年早期起病，不会使意识模糊，因此急性意识混乱或晚年首次发病会使概率偏向躯体原因。
:::

对新出现的表现，合理的基线评估包括生命体征、神经系统检查，以及根据临床情况选择的血液检查：全血细胞计数、尿素和电解质、血钙、肝功能、甲状腺功能、血糖或 HbA1c，通常还包括维生素 B12 和叶酸。当病史提示时，再加做尿液药物筛查、心电图（尤其在使用抗精神病药之前）、HIV 和梅毒血清学检查，以及脑影像学检查或脑电图。

::: example 外科病房中的“精神病” {#ex-delirium-mimic}
Margaret Hughes 夫人，78 岁，髋部骨折修复术后第三天。夜间她大喊“有人从墙里穿过来”，并拔掉了静脉留置针。外科团队请精神科会诊“新发精神病”。会诊医生应该怎么做？

::: solution
**注意危险信号。**老年人急性起病、视幻觉以及身处躯体疾病诊疗环境，都指向谵妄（见[[#thm-organic]]）。

**评估注意力和波动性。**她昏昏欲睡，倒背月份无法越过十月，护士反映她昨天下午还很清醒。她的 4AT 评分为：警觉性异常（4 分），简短精神测验错两项（2 分），注意力少于 7 个月份（1 分），存在急性变化（4 分）。总分 = 11 分，远超 4 分的阈值。

**寻找病因。**核查用药记录（阿片类药物、新加的抗胆碱能药物），检查有无尿潴留和便秘，检查有无感染，并申请血液检查。她的血钠为 126 mmol/L，尿液浑浊。

**计划。**诊断是谵妄，而不是原发性精神病性障碍。治疗针对病因，并配合平静的定向引导、眼镜和助听器、良好的照明、家人探视以及正常的睡眠模式。抗精神病药仅保留用于严重痛苦或危险的情况，并且要遵循当地指南，以低剂量短期使用。谵妄在[[geriatrics-palliative/delirium-dementia-care]]中有深入介绍。
:::
:::

### 筛查测验有多好？

筛查工具有用，但其意义取决于所检测人群中该疾病的常见程度。**阳性预测值**（PPV）是检测结果阳性者真正患病的概率：

$$
\text{PPV} = \frac{\text{灵敏度} \times p}{\text{灵敏度} \times p + (1-\text{特异度})(1-p)}
$$ {#eq-ppv}

其中$p$为患病率。一项关于 4AT 的荟萃分析发现，其灵敏度和特异度均约为 0.88。在大约每 5 名患者中有 1 人患谵妄的老年内科病房，4AT 阳性结果大约三次中有两次是正确的。在谵妄罕见的门诊，大多数阳性结果将是假阳性。

::: widget bayes
mode: test
prevalence: 0.2
sensitivity: 0.88
specificity: 0.88
caption: 灵敏度和特异度均约为 0.88 的谵妄筛查，以自然频数显示（简化的示意数据）。把患病率从老年病房（约 0.2）调向门诊（0.02），观察阳性结果中真阳性所占比例如何下降。同一个测验在不同场合意味着不同的东西。
:::

::: example 计算预测值 {#ex-ppv}
设灵敏度和特异度均为 0.88，患病率为 0.2，计算 4AT 的阳性预测值。再对患病率 0.05 重复计算。

::: solution
当$p = 0.2$时：每名受筛者中真阳性$= 0.88 \times 0.2 = 0.176$。假阳性$= 0.12 \times 0.8 = 0.096$。PPV $= 0.176 / (0.176 + 0.096) = 0.176/0.272 \approx 0.647$，约 65%。

当$p = 0.05$时：真阳性$= 0.88 \times 0.05 = 0.044$；假阳性$= 0.12 \times 0.95 = 0.114$。PPV $= 0.044 / 0.158 \approx 0.278$，约 28%。

测验本身没有改变，但在谵妄少见的地方，近四分之三的阳性筛查结果是假阳性。阳性筛查结果提示需要进行临床评估，而不是诊断。
:::
:::

## 个案概念化

诊断说明一个人有哪一类问题。**个案概念化**（formulation）则解释为什么这个人此时会出现这个问题，以及什么可能有帮助。

::: definition 生物-心理-社会个案概念化 {#def-formulation}
**个案概念化**是对一个人困难的简要、个体化的解释。它通常组织为一个网格，一边是**生物**、**心理**和**社会**因素，另一边是四类原因：

- **易感**因素，使其变得脆弱（家族史、童年逆境）；
- **促发**因素，触发本次发作（丧亲、停药）；
- **维持**因素，使问题持续（饮酒、孤立、无益的信念）；
- **保护**因素，支持康复（亲密关系、就业、信仰、既往对治疗反应良好）。
:::

个案概念化与处理直接相连：每个维持因素都提示需要改变的地方，每个保护因素都是需要加强的方面。它应使用可以与患者分享的通俗语言书写。

## 风险评估

评估风险意味着理解可能发生什么伤害、为什么会发生，以及什么能降低其可能性。它是每一次精神科评估的组成部分，而不是一张需要单独填写的表格。

::: definition 临床风险评估 {#def-risk}
精神卫生领域的**风险评估**是关于可能的伤害及如何减少伤害的结构化临床判断。主要领域包括：

- 对自身的风险：自伤和自杀；
- 对他人的风险：暴力或攻击；
- 来自他人的风险：剥削、虐待、家庭暴力；
- 自我忽视，包括不进食、不饮水或不处理躯体疾病；
- 对受抚养者的风险，例如子女或患者所照护的成年人。

对每个领域，临床医生都要考虑既往史、当前状态、背景和保护因素，并商定降低风险的计划。
:::

自杀的危险因素，如既往自伤、男性、独居或近期丧失，在人群水平上是真实存在的。但它们预测某一个体将会做什么的能力非常差，因为即使在具有许多危险因素的人群中，自杀也是罕见的。因此，英国国家卫生与临床优化研究所（NICE）关于自伤的指南（NG225，2022 年）指出，不应使用风险评估工具和量表来预测未来的自杀或自伤，也不应以此决定谁接受治疗或出院。重点转而放在对需求的**心理社会评估**、与患者共同制订的**安全计划**以及及时的随访上。后续章节将详细讨论这一点（[[psychiatry/self-harm-suicide-prevention]]）。

询问自杀是一项核心技能。从一般性问题（“您是否有时觉得活着没有意义？”）逐步过渡到具体问题（“您是否有过结束自己生命的想法？是否做过任何计划？”）。没有证据表明询问会增加风险，许多人被问到时会感到如释重负。

暴力风险遵循同样的逻辑。最强的指标是既往暴力、物质滥用，以及特定的当前特征，例如伴有愤怒的被害信念，或针对某个具体人物的威胁。大多数精神疾病患者从未有过暴力行为，他们成为暴力受害者的可能性大于成为施暴者。

## 决策能力与同意

许多评估会提出这样的问题：患者能否作出某一特定决定，例如拒绝住院或治疗。在英格兰和威尔士，这由《2005年心智能力法》（Mental Capacity Act 2005）规范。决策能力是被推定存在的。它针对具体决定、具体时间。只有当心智或大脑的损害导致患者无法理解相关信息、记住信息、使用或权衡信息，或无法表达决定时，患者才对该决定缺乏决策能力。相关法律以及独立的《精神卫生法》框架在[[psychiatry/treatments-mental-health-law]]和[[medical-ethics-law/consent-capacity]]中介绍。

::: example 查房时的拒绝 {#ex-capacity-round}
Arjun Mehta 先生，52 岁，患有需胰岛素治疗的糖尿病，因足部感染收入内科病房。他拒绝静脉抗生素，说“医院的饭有毒，输液也有毒”。他五年前被诊断为妄想性障碍。内科团队询问他是否有能力拒绝治疗。

::: solution
**推定有决策能力，并针对此决定进行检验。**需要作出的决定是是否接受针对足部感染的静脉抗生素治疗。

**是否存在心智或大脑的损害？**是的：妄想性障碍，也可能存在感染导致的谵妄，必须用注意力测验加以检查。

**应用功能性测试。**他能复述自己有感染、不治疗可能扩散并导致截肢，因此他能理解并记住信息。然而，他无法权衡这些信息：每次讨论都会回到输液有毒这一坚定信念上，他无法考虑输液无毒的可能性。在这一决定上，他因妄想而缺乏决策能力。

**下一步。**可以依据《心智能力法》，以最低限制的方式，按其最佳利益给予治疗。首先应尝试争取他的同意，例如让他看着输液袋被打开，或在临床合适时改用口服抗生素。让他的家人和社区精神卫生团队参与。清楚地记录评估过程。如果治疗的主要目的是针对他的精神障碍，那么相关的框架应是《精神卫生法》。
:::
:::

::: example 使用口译员 {#ex-interpreter}
Fatima Rahimi 女士，26 岁，刚从阿富汗来到英国，在英语流利的丈夫陪同下前来急诊科。工作人员说她“不肯说话”。丈夫提出由他来翻译。评估应如何进行？

::: solution
**礼貌地谢绝这一提议。**使用专业口译员，可以现场或通过电话，并尽可能安排女性口译员，因为 Rahimi 女士可能更愿意如此。家庭成员无法保持中立，而且可能本身就是问题的一部分。

**至少在部分会谈中单独见她。**这是常规的良好做法，对于安全地询问家庭暴力至关重要。

**考虑文化和创伤因素。**询问她如何理解自己的困难。她可能将痛苦描述为头痛、睡眠差或“心里痛”。询问她在移民之前和移民过程中的经历，因为她可能经历过暴力或丧失。

**避免误解。**沉默可能反映的是恐惧、羞耻、疲惫或没有听懂，而不是精神疾病导致的缄默。全程核实她是否理解，使用短句，并记录口译员的姓名。

在口译员的帮助下，她描述了噩梦、容易受惊以及回避与她村庄遭受袭击有关的提示物。这提示创伤相关障碍，评估随后转向她当前的安全和支持。
:::
:::

::: quiz
一名 40 岁女性说，电台里的一名男子一直通过他所选的歌曲向她传递私人信息。她对此深信不疑，她姐姐说什么都无法改变她的想法。这一信念最恰当的描述是：
- [ ] 超价观念
- [x] 关系妄想
- [ ] 强迫观念
- [ ] 假性幻觉
::: solution
这一信念是坚定的、错误的，并且在存在相反证据时仍然坚持，其主题是中性事件对本人具有特殊意义：这是关系妄想。超价观念不那么僵固；强迫观念被认为是自己不想要的想法并受到抵抗；假性幻觉是一种知觉体验，而不是信念。
:::
:::

## 书写记录

评估记录应当清晰到足以让同事在凌晨 3 点据此采取行动。一份好的记录包括：

1. 一句话的概述：患者是谁、为什么接受评估。
2. 按标准标题书写的病史，并注明信息来源（患者、亲属、全科医生记录）。
3. 精神状况检查，附简短的原话引用。
4. 躯体检查发现和检查结果。
5. 个案概念化和鉴别诊断。
6. 用通俗语言书写的风险小结，并与计划相关联。
7. 计划：谁、在什么时间之前、做什么，以及情况变化时该怎么办。

避免使用“博取关注”或“操纵他人”等带有污名化的标签。它们描述的是观察者的挫败感，而不是患者本人，而且会在整个医疗系统中一直跟随患者。

::: history
通过细致观察进行评估的做法早于现代精神病学，但今天所用的结构在很大程度上得益于 20 世纪初的德语精神病学。雅斯贝尔斯（Karl Jaspers）的《普通精神病理学》（*General Psychopathology*，1913 年）区分了体验的形式与内容，并坚持从患者的角度理解体验，这是描述性精神病理学的基础。施奈德（Kurt Schneider）后来列出了他认为对精神分裂症具有特征性的“一级症状”，这些症状影响了此后数十年的会谈方式，尽管现在已知它们并非精神分裂症所特有。1977 年，恩格尔（George Engel）提出了生物-心理-社会模式，它成为个案概念化的标准框架。20 世纪下半叶出现了结构化会谈和操作性标准，始于 Feighner 标准（1972 年）和 DSM-III（1980 年），使精神科诊断更加可靠。
:::

## 后续内容

接下来的各疾病章节将始终运用这种评估：[[psychiatry/mood-disorders]]、[[psychiatry/anxiety-disorders]]和[[psychiatry/psychotic-disorders]]。一般会谈技能见[[clinical-skills/history-taking]]和[[clinical-skills/communication]]，筛查测验的解读见[[epidemiology-ebm/diagnostic-tests]]。

::: summary
- 精神科评估与任何医学评估具有相同的结构：病史、检查、辅助检查、诊断和计划。
- 按标准标题采集病史，始终包括物质使用、需要抚养的子女，并尽可能获取知情人的叙述。
- 精神状况检查记录会谈时的外貌与行为、言语、心境与情感、思维形式与内容、感知、认知和自知力。
- 妄想、超价观念、强迫观念、幻觉和错觉都有精确的含义，要谨慎使用。
- 对每一次新的表现都要寻找器质性病因，尤其是急性起病、注意力波动、视幻觉或晚年首次发病时。
- 筛查测验的预测值取决于患病率。
- 个案概念化运用易感、促发、维持和保护因素，解释为什么这个人此时会出现这个问题。
- 风险评估是与计划相关联的临床判断；NICE 建议不要使用风险量表来预测自杀或分配医疗资源。
- 决策能力是被推定存在的，针对具体决定，并用《心智能力法》的功能性测试来检验。
:::

## 习题

::: exercise 说出术语 {level=1}
写出下列各项正确的精神病理学术语：(a) 在黑暗的房间里把挂在门上的外套看成一个人；(b) 以双关语相连、在话题间跳跃的快速言语；(c) 一名男子反复洗手，以中和他自知过分的污染想法；(d) 描述母亲去世时发笑。
::: solution
(a) 错觉：对真实刺激的错误感知。(b) 思维奔逸，典型见于躁狂；很可能伴有言语迫促。(c) 强迫观念（侵入性的污染想法）伴强迫行为（洗手）。(d) 情感不协调。
:::
:::

::: exercise 病史的标题 {level=1}
列出精神科病史的主要标题，并举出两个绝不能遗漏的项目，分别说明理由。
::: solution
主诉；现病史；既往精神病史；既往躯体病史；用药；物质使用；家族史；个人史；司法史；社会状况；病前人格。绝不能遗漏的两项：物质使用，因为中毒和戒断几乎会模仿或加重每一种精神综合征，并改变风险；需要抚养的子女或患者所照护的其他人，因为他们的安全可能取决于计划。询问自杀想法是第三项。
:::
:::

::: exercise 心境还是情感？ {level=1}
解释心境与情感的区别，并说明两者各自如何记录。
::: solution
心境是一段时间内持续的情绪状态，由患者主观报告，用患者自己的话记录（例如“很平淡，好像什么都无所谓”），有时用 10 分制的自评。情感是会谈中观察到的情绪表达，由临床医生记录为有反应性的、受限的、迟钝的、平淡的、不稳定的或不协调的。两者可能不一致：一个人可能报告心境低落，却礼貌地微笑。
:::
:::

::: exercise 筛查的预测值 {level=2 check="round(100*0.9*0.1/(0.9*0.1+0.2*0.9))"}
一份简短的抑郁问卷灵敏度为 0.90，特异度为 0.80。它在一个 10% 患者患有抑郁的诊所中使用。阳性结果中真阳性占百分之多少？答案以整数百分比表示。
::: hint
用[[#eq-ppv]]，取$p = 0.1$。
:::
::: solution
每名受筛者中真阳性$= 0.9 \times 0.1 = 0.09$。假阳性$= (1 - 0.8) \times 0.9 = 0.18$。PPV $= 0.09/(0.09 + 0.18) = 0.333$，即约**33%**。三个阳性结果中有两个是假阳性，这就是为什么阳性筛查结果之后要进行临床会谈，而不是直接诊断。
:::
:::

::: exercise 书写个案概念化 {level=2}
Chloe Turner 女士，23 岁，学生，第二次抑郁发作。她的母亲患有双相障碍。她在学校曾遭受欺凌。三周前她的恋爱关系结束，此后她不再去上课，待在自己房间里，几乎每晚饮酒。她有一位每天来看望她的亲密朋友，两年前她对认知行为治疗（CBT）反应良好。请以易感、促发、维持和保护因素的网格形式写出生物-心理-社会个案概念化。
::: solution
易感：生物方面，心境障碍家族史（母亲患双相障碍，这也提出了 Chloe 是否存在双相性的问题）；心理方面，学校受欺凌后自尊低下；社会方面，未明确提及。促发：三周前恋爱关系结束。维持：生物方面，每晚饮酒，加重心境和睡眠问题；心理方面，退缩和回避，使她失去愉悦感和成就感；社会方面，孤立，学业落后。保护：一位亲密、支持她的朋友；既往对 CBT 反应良好；学业和对未来的计划。处理随之而来：评估饮酒问题，鼓励行为激活，提供心理治疗，联系学生支持服务，并鉴于家族史仔细询问既往有无轻躁狂。
:::
:::

::: exercise 器质性还是功能性？ {level=2}
对下列每个人，说明是否应积极排除器质性病因，并举出两项检查：(a) 一名 19 岁青年，听到声音并社交退缩三个月；(b) 一名 67 岁、无精神病史的女性，两周来逐渐变得多疑，并在客厅里看到“小孩子”；(c) 一名 30 岁患者，有焦虑、体重下降、震颤和心悸。
::: solution
(a) 器质性病因可能性较小，但仍需基线评估：尿液药物筛查（大麻和兴奋剂）、包括甲状腺功能在内的血液检查，以及抗精神病药治疗前的心电图；如有神经系统体征则行神经影像学检查。(b) 是的，强烈需要：晚年首次发病、亚急性病程和视幻觉提示谵妄、路易体痴呆或其他脑部疾病。检查：针对感染和代谢原因的血液检查、认知评估和脑影像学检查；并核查用药。(c) 是的：很可能是甲状腺毒症。检查：甲状腺功能检查和心电图（排查快速性心律失常）。
:::
:::

::: exercise 决策能力针对具体决定 {level=3}
一名 45 岁精神分裂症男性因胸痛入院，被发现患有心肌梗死。他相信自己正受到安全部门的监视，但同意服用阿司匹林并接受血管造影，还就风险提出了合理的问题。第二天，他拒绝让护士给他称体重，说秤会传送他的数据。一名初级医生写道：“因精神病而缺乏决策能力”。请评析这条记录。
::: solution
这条记录把决策能力当作一个人的整体属性，这在法律上和实践中都是错误的。根据《心智能力法》，决策能力是被推定存在的，并在需要作出每一项决定时分别评估。对于血管造影的决定，他理解、记住并权衡了信息，且表达了选择，因此他具有决策能力，尽管他持有妄想。对于称体重的决定，他的推理可能被妄想扭曲，但这需要专门检验。而且这一决定在临床上意义不大，还有限制更少的选择，例如估算体重或稍后再试。更好的记录应写明具体决定、是否存在损害、功能性测试的每一部分如何评估以及结果。仅凭精神分裂症的诊断，绝不能认定缺乏决策能力。
:::
:::

::: exercise 评价风险评估 {level=3}
某医院信托的审计发现，每一位自伤后就诊者都填写了一份 10 项的自杀风险量表，得分为“低风险”者出院时没有安排随访。请结合基础发生率和英国现行指南，解释这种做法为何有问题，并提出更好的方法。
::: solution
即使在高风险人群中自杀也是罕见的，因此任何灵敏度和特异度不完美的量表都会有很低的阳性预测值，并且会把许多后来死于自杀的人标记为“低风险”。对这类工具的研究一致发现，它们对个体预测而言太不准确。因此，用分数分配医疗服务会拒绝为需要随访的人提供随访，并带来虚假的安心。NICE NG225（2022 年）建议不要使用风险工具或量表来预测自杀或自伤，也不要以此决定谁接受治疗或出院。更好的方法是：对每个人进行心理社会评估，了解其处境、需求、精神状况以及这一行为的意义；共同制订安全计划；治疗潜在疾病；在患者同意的情况下让家人参与；并为所有人提供及时的随访，尤其关注出院后的最初几天。危险因素仍然为谈话提供信息，但不能取代谈话。
:::
:::
