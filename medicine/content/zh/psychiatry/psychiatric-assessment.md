精神科的检查没有化验单，它的仪器是谈话本身：**一次好的评估要同时完成四件事——建立足以说出真相的关系、把主观的体验变成可记录的语言、判断此刻的风险、并决定下一步由谁在什么时候接手。**本章覆盖会谈的设置与资料的来源、精神状态的检查（作为一份可以重复填写的表格而不是散文）、风险的判断（自杀、自伤与对他人的危害）、以及最容易造成误诊的两种伪装（谵妄与 无能力）。所有条目都可以套用于门诊、病房与急诊。

## 设置

::: definition 精神科会谈 {#def-interview}
**会谈开始前要想清楚四件事：谁在场、要问什么、什么必须今天知道、以及这个人的问题会是什么。位置与时间也要交代：安静的房间、不背对门、手机收起、留出至少三十分钟；被打断的记录会让患者学会不说重要的事。开场用开放的一句话（在“我们从哪儿说起好呢？”之后保持沉默十秒，多数人会自动补上真正的主题），随后再转向封闭的问题核实风险与症状的边界。资料的来源要写清并标注：她自己、家属或朋友（在需要她同意时）、初级照护的记录、以及既往的住院与出诊记录；只有她一个人的说法时要在病历里注明（在“无旁证”）。要特别处理三种人：沉默者（先问最不敏感的话题与躯体不适，把“你为什么不来上学”改成“我们从你早上醒来说起”）；愤怒者（承认对方有理由生气，把不满变成一个可回答的问题）；与否认者（不与幻觉争辩，改问“这些声音对你意味着什么”）。会谈的收尾同样重要：说出你的初步理解、说明下一步（在谁、什么时候、去哪里）、并直接问她最担心什么。风险的问题必须在会谈内问完：自杀、自伤、（在若干情形下的）对他人的危害、以及（在需要时的）保护的议题（在她自己家中的孩子）；如果因时间不够而未问，就要在病历里写明并安排补问的时间。要记录的还有你无法评估的部分在缺乏翻译与在（（拒绝回答的项目上的）），否则下一个人会以为你已经问过（[[clinical-skills/history-taking]]、[[clinical-skills/communication]]、[[psychiatry/self-harm-suicide-prevention]]、[[clinical-skills/records-handover]]）。**
:::

## 检查

::: definition 精神状态检查 {#def-mse}
**精神状态检查是此刻的可重复记录，它的作用是使两个人可以比较同一个人的同一个方面。九个栏目：一般观察在外表的整洁与在（目光与（在精神运动的迟滞或激越上的）；心境（她自己说的）与情感（你观察到的）要分开写，并说明情感的反应性与范围（在“情感平淡”与“情感与内容不协调”是两件事））；言语在量的多少与速度的快慢与在打断与（在沉默的等待时间上的）；思维的形式在联想的松弛与在思维的中断与在被迫的思维与（在插入上的）与内容在妄想的主题与在强迫的思维与在先占的观念与在自责与在贫穷与在（罪恶的妄想的鉴别）；知觉在幻听的内容与在评论与在命令性的与在视与在触与在（（在内感受性的幻觉上的））；认知在 定向与在记与在注意与在计算与在语言的流畅与在视空间与在（额的与顶叶的项目上的）；睡眠与食欲在早醒与在入睡的困难与在（（在嗜睡上的））；风险在自杀的意念、计划、手段、意图、既往行为、保护的因素，与在对他人的念头与在忽视与在（（保护的议题上的））；以及洞察在她如何解释自己的经历与在（（她是否愿意接受帮助上的））。常见错误有四个：用心境的形容词代替风险的具体内容；把“接触合作”当成检查的结论；在激越者身上放弃认知的项目而不记录；以及照抄上一份的原文。要写出原话（在“她称声音‘在替我数数’”）而不是分类的标签，因为原话是下一个人判断变化的依据（[[clinical-skills/physical-examination]]、[[psychiatry/psychotic-disorders]]、[[psychiatry/mood-disorders]]、[[clinical-skills/records-handover]]）。**
:::

## 风险

::: definition 自杀、自伤与对他人的危害 {#def-risk}
**风险的记录要区分“评估”与“计划”：只有评估而没有可核查的下一步，等于没有评估。自杀的风险按四条写：意念在（频率、时长、能否被别的事打断）、意图与计划在（是否选定方法、时间、是否已准备）、行为在（既往的尝试、最近的准备、把东西送人）、以及加权项在男、老年、独居、慢性疼痛与在酗酒与在既往自伤与在家族的自杀与在近期的出院与在丧亲与在债务与在（躯体的疾病上的）。要写出保护的因素，因为它们在之后的决定里同样被引用。要强调时间窗：出院后的第一个月、自伤就诊后的数月、丧亲后的第一年，风险成倍升高，而这些日子是可以预先安排的。自伤的风险不等于自杀的风险：前者需要问功能在（要感觉、要停止感觉、要惩罚、要被人看见）并给替代；后者需要问方法与时间。对他人的危害较少预测但必须处理：思维的（被指派的）内容与被害的妄想结合可及的对象与在物质与在（（不眠上的））构成风险；记录要写出你考虑过的具体对象与采取的通报义务在（在若干体系中的对有关方面的报告）以及通知谁与为何。能力的议题在风险中常同时出现：当她拒绝一个能降低风险的措施时，要评估的是能力而不是服从在（她能理解、记得、权衡、表达选择）；有能力的拒绝必须被尊重，同时把风险与替代写清楚。最后，把“你担心什么、你不担心什么、你做了什么、下一次在什么时候”四句话写进病历，因为查房与移交时需要的是这个而不是形容词（[[psychiatry/self-harm-suicide-prevention]]、[[medical-ethics-law/consent-capacity]]、[[psychiatry/treatments-mental-health-law]]、[[clinical-skills/patient-safety]]）。**
:::

::: example 第一次会谈 {#ex-first-interview}
一名24岁的男性被母亲带来，母亲在门外等候；他坐立不安、说话快、笑得不合时宜；这是他第三次因“抑郁”被开药。
::: solution
**第一次会谈的目标不是给出诊断，而是把三件事问全（[[#def-interview]]、[[#def-mse]]）。第一，既往的心境的高涨：直接问“有没有一段日子您睡得很少却特别有劲、想法特别快、做了平时不会做的事”；三次抗抑郁药无效加在不合时宜的笑与在（（言语的加快上的））提示双相的谱系，而这一条会改变用药。第二，知觉与思维的形式：请他描述那声音或那种“被看着”的感觉，记录原话；如果他答非所问，那比任何内容都重要。第三，风险与现实的功能：学业与工作与住宿与在（与家庭的冲突上的）与近三个月的失去。同时也要给他本人一次独处的时间（母亲在门外时许多话不会说），并在他同意后再与母亲谈，把她的观察作为旁证记录来源。收尾要说三句：你听到了什么、你现在的初步理解、下一步与时间；如果他要走，不要以“那你回去吃药”结束，而是给一个两周内的复诊与一张写着你担心什么的纸。要不要今天住院取决于风险与能力，而不是母亲的焦虑程度（[[psychiatry/psychotic-disorders]]、[[psychiatry/mood-disorders]]、[[clinical-skills/communication]]、[[psychiatry/treatments-mental-health-law]]）。**
:::
:::

::: example 被当作精神病的谵妄 {#ex-delirium-mimic}
一名81岁的女性在全科被诊断为“晚发的精神病”并服奥氮平一周；她夜间更糊涂、白天清楚、认不出女儿；入院后血压偏低、尿培养阳性、正在用三种抗胆碱能负担高的药。
::: solution
**这是谵妄被写成精神病，而老年新发的“精神病”在排除躯体原因之前不应被当作精神科诊断（[[#def-mse]]、[[#def-risk]]、[[geriatrics-palliative/delirium-dementia-care]]）。识别靠四个特征：注意的损害在（不能连续说出月份或数字的减法）、病程的波动在（夜重日轻）、知觉以视与在（触的幻觉为主而非评论性幻听）、以及在（意识的清晰度的改变）。要做的事按顺序：把抗胆碱能与在苯二氮与在（（阿片的药物上的））逐条减量或替换在（不要骤停成堆的药）；治感染但要问“这个尿是原因还是巧合”，因为老年人无症状的菌尿很常见而低血压与在（脱水的容量不足）可能才是主因；查钠与钙与甲与在B 族维生素与在（肾与肝的功能）与血相与炎症的标志；测体温与尿量与在（（便的潴留））。抗精神病药在这里只用于严重的激越或在（威胁进食与安全）时的小剂量在避免高效价与在（长半衰期的品种），而且要在病程记录里写明“为谵妄的短期使用”与停用的时间。还要处理已经造成的伤害：把这一周的诊断改回来并通知初级照护，因为“晚发精神病”这个标签会让她以后每次混淆都被当作精神科的问题；同时安排环境的措施在白天的光线与在熟悉的物品与在（（家属的在场））与在（活动的重启）（[[geriatrics-palliative/polypharmacy]]、[[pharmacology/adverse-reactions]]、[[clinical-skills/laboratory-tests]]、[[clinical-skills/records-handover]]）。**
:::
:::

::: example 用翻译的会谈 {#ex-interpreter}
一名40岁的女性从战乱地区抵达，三周来不听不动、不吃；她的丈夫说“她是被吓坏的”；现场只有她的儿子可以当翻译。
::: solution
**首先换掉翻译：让儿子翻译母亲的痛苦与在（可能被拘禁或侵犯的经历）会毁掉保密与准确性，也会让孩子承担不该承担的内容；应使用专业的口译服务在（若没有可用的现场口译，则用电话或视频的口译，并明确记录翻译者是谁）。准备三件事：给译员一分钟说明目的与在（可能出现的内容）并请他逐字翻译在（不要概括她的回答）；坐的位置让三方都能看到；时间要长一些，因为口译使会谈变慢。评估上，不听不动不吃要想到紧张症在（可被苯二氮缓解的急症）与重度抑郁与在（创伤后的木僵）的鉴别，而这三者的处置不同；因此要查体征与在肌张力与在（对指令的反应）与体温与在CK 与在（进出的液体）。问到创伤要按稳定的原则：先保证安全与睡眠与进食，不在第一次会谈里追问细节；但要问一次自杀，因为在刚抵达的在（（人群中））这一风险常被忽略。同时处理她的现实：住处与在（食物的获得）与在（家庭的分离）与在（申请的等待）本身就在维持她的症状，转介社区的服务与在翻译与在（文化中介的协助）常与药物同等重要。记录要写明使用口译与在（术语核对过）与在（她原话的翻译版本）（[[clinical-skills/communication]]、[[psychiatry/psychotic-disorders]]、[[public-health/global-health]]、[[psychiatry/treatments-mental-health-law]]）。**
:::

::: example 查房上的能力 {#ex-capacity-round}
一名67岁的男性因下肢坏疽被建议截肢，他反复说“我不想让他们砍我”，同时能说出自己是什么病、有什么风险、还有什么选择；他答应妻子“会考虑”，但拒绝签字。
::: solution
**“拒绝我们同意的治疗”不等于无能力（[[#def-risk]]、[[medical-ethics-law/consent-capacity]]、[[medical-ethics-law/ethical-principles]]）。能力的四项要逐条评估并记录：他能否理解信息在（用自己的话重复“腿上的血供断了，毒素会进血里”）；能否记得并前后一致；能否权衡在（他能说出“活着的代价是失去腿，而失去腿我可能不想要那样的生活”）；能否稳定地表达选择在（他不是每次给出不同的答案，而是反复给出同一个）。他通过了四项，所以这是一个有能力的拒绝，即使它通向死亡。此时要做的是把拒绝变成一个可以工作的决定：解释如果不做会怎样在镇痛的方案与在感染的口服控制与在（（在家的护理））；缩小选项以试探他的真正顾虑在（他怕的可能是（在（（（在养老院的））生活））而不是手术本身）；引入他信任的人在妻子与在（宗教的照护）并在他同意下再谈；并约定复评的时间在（“我们明天这个时候再谈一次，好吗”）。也要评估是否存在影响判断的可治因素：疼痛与在（阿片的药物）与在（感染相关的轻度谵妄）会改变波动中的能力，因此评估要在清楚的时刻做，并写下当时他的定向与注意。若他确实无能力，则按本地的框架由在被授权的代表或在（（最佳的利益的决策））作出决定，并记录你为何这样判断。查房上的表述要平实：说“他理解并拒绝，我们不推他”，不要说“他不配合”（[[medical-ethics-law/end-of-life-ethics]]、[[clinical-skills/communication]]、[[surgery/vascular-urological-surgery]]、[[clinical-skills/records-handover]]）。**
:::

::: history
**精神状态检查的来源是十九世纪欧洲的病历传统与法医学的需要。普鲁士与在（奥地利的医生在法庭上被要求说明一个人是否有能力管理自己的财产与是否能为自己的行为负责），于是标准化的检查条目从法律实务中长出；克雷丕林的病历以描述的精確著称，他把观察与在（病程的记录）写成可以比较的单元，而布洛伊勒与雅斯贝尔斯进一步发展了“理解”与“解释”的分界。雅斯贝尔斯在1913年的普通精神病理学里做了本领域最重要的一次方法学工作：他把现象学的描述在（患者经历了什么）与因果的解释在（为什么）分开，并把幻觉与妄想与思维的形式分成可以询问的项目；这一本书至今仍是“如何问出主观体验”的范本，而它诞生前精神科的病历多是症状的清单。能力与同意的概念也在同一世纪被法律塑形：十九世纪的“理性人”标准在二十世纪被逐步替换为具体的认知测验在（理解、权衡、表达），而1990年代多国的心智能力立法明确写了“推定有能力”与“以决定而非诊断判断”两条原则，把评估的焦点从“她是否精神异常”移到“她此刻能否做出这个决定”。风险的评估走了另一条路：临床直觉的可靠性在1960至1970年代被多项研究质疑，于是出现了结构化的工具与精算的模型，而二十年的比较研究给出了一个至今有效又常被误解的结论——在人群层面，工具略优于人；在个体层面，两者的预测都不强；因此工具的正确用法是组织信息并规定必须问什么，而不是给出一个可以据以放行的数字。同一时期，自杀的预防把风险从“特质”改写为“时间窗”：出院后的头几个月、自伤后的数周、丧亲后的第一年。翻译与文化精神病学对会谈的挑战在二战后的移民潮中显现，人类学与跨文化的精神病学区分了在（解释的模型）：她如何命名、归因、期待什么样的帮助；这也改变了会谈的伦理——不再假定同一种问法适用于所有人。近二十年，检查的记录方式受到信息学的影响：模板让项目齐全却催生复制粘贴，于是各国的记录标准开始要求在（风险的原文）与在（可核查的下一步）；而视频与在（远程的评估在疫情期间被大规模采用）也带来新的问题，例如在屏幕后无法察觉的在气味与在（（身体的安全））。这段历史的教训是：精神状态的检查之所以有价值，不在于它给出了标签，而在于它强迫询问那些不会被主动说出的事——只要它还保留原话与时间（[[clinical-skills/history-taking]]、[[clinical-skills/records-handover]]、[[medical-ethics-law/consent-capacity]]、[[psychiatry/self-harm-suicide-prevention]]）。**
:::
::: summary
- 会谈要设置好：谁在场、留足时间、开放开始、封闭核实、结尾说出下一步。
- 资料来源要标注；没有旁证本身就是一种需要记录的信息。
- 精神状态检查是九栏的可重复记录，写原话而不写标签；心境与她说的、情感与你观察的要分开。
- 老年新发的“精神病”在排除谵妄与躯体原因之前不是精神科诊断；注意的损害与病程的波动是识别的关键。
- 风险评估要写成意念、意图、计划、行为、加权项、保护的因素，并落到手段的移出与下一次的日期。
- 拒绝治疗不等于无能力；能力按理解、记忆、权衡、表达四项评估，并在清楚的时刻做。
:::

::: exercise 正确记录旁证 {level=1}
一名学生的病历写：“其母诉患者近月来行为异常。”请改写这段记录并说明要点。
::: solution
**要写清来源、时间、内容与你的核对：她的母亲在（她本人同意联系）于今日在诊室外单独提供的信息是：近两个月患者有四次连续三小时以上的不眠而自称不累，曾在三月的一个月内刷掉约四万元，且两次在深夜给朋友发长语音在（母亲此前不知道）。这些信息与患者本次“我只是睡得少”的说法不一致，已在会谈中向她核实，她承认花钱的事但未承认不眠。旁证要标名与在（与患者的关系）与在（是否经她同意）与在（获取的日期），因为将来读病历的人需要判断这条信息的分量；同时要记录不一致本身，它常常比一致更有诊断价值（[[#def-interview]]、[[clinical-skills/records-handover]]、[[psychiatry/mood-disorders]]）。**
:::

::: exercise 把伪装分开 {level=2}
三名患者都表现为“糊涂”：72岁的女性三天内忽清忽糊；68岁的女性三年缓慢加重而常找不到词；45岁的男性两周来答非所问并说电视在跟他说话。请各给首要的判断与两项关键检查。
::: solution
**第一位是谵妄：急起、波动、注意受损；关键是找出诱因在用她的用药清单在抗胆碱能与在苯二氮与在（（阿片类）、体温、尿、钠钙、肾肝、胸）并做注意的床旁测试，而不是一上来做头颅影像。第二位是痴呆的进程：缓慢、以语言或记忆为主、定向与在（视空间的损害逐渐累积）；关键是可治原因的筛查与在结构的影像与在（（认知的量表）），并按需评估驾驶与能力。第三位是精神病性或在（器质的）状态：答非所问提示思维的形式的障碍，而“电视说话”是幻听或在（关系观念）；关键是排除物质与在感染与在癫痫的在（（非惊厥的状态））与在（自身免疫的脑炎），后者在亚急性起病伴精神症状与在（睡眠与运动的改变）时要想到。共同的一条：注意的检查与在（时间的曲线）能在五分钟里把三者分开，比任何单项化验更有用（[[#def-mse]]、[[geriatrics-palliative/delirium-dementia-care]]、[[nervous-system/dementia-neurodegeneration]]、[[psychiatry/psychotic-disorders]]）。**

::: exercise 应对沉默的患者 {level=2}
一名26岁的女性被家人带来，全程不看人不说话，问十句答一句“嗯”；她的家人不断替她回答。请给出你接下来二十分钟的做法。
::: solution
**先把替答的人请开：向家人解释有些话只在没人替她说时才说得出，并请他们在候诊室等在（这也减少她的表现压力）；若她坚持有人陪，就尊重并让陪同者不出声。然后降低要求：不说“你为什么不来上课”，改成“我们从一个小的问题开始，你可以点头”；给她纸笔或让她在手机上一句话写下最困扰她的三点在（书写常绕过言语的阻断）；先问身体在（睡、吃、疼、月经、心悸），因为这些是最不需要信任的入口。观察要记录：目光的接触与在（回答的潜伏期）与在（是否点头多于出声）与在（运动的抑制），后者提示紧张症谱系在（可被苯二氮试验性地缓解），而抑郁与在解离与在（被胁迫的沉默）在表现上可以相似但处置完全不同。风险必须问：把纸推到她面前在（“有没有想过不再活着；有就画圈”），并记录她用哪种方式回答了。最后给一个低压的收尾：告诉她你观察到什么、下一步需要什么、以及可以不见面就能联系的方式在若干体系中的在文本与在（（网络的问诊））（[[#def-interview]]、[[clinical-skills/communication]]、[[psychiatry/mood-disorders]]、[[psychiatry/self-harm-suicide-prevention]]）。**
:::

::: exercise 改进风险的移交 {level=3}
你所在的病房每例入院都填风险评分，但半年内仍发生两次住院期间的自伤。请分析可能的问题并给出五项改动。
::: solution
**评分表本身不是预防。可能的五个问题：分数替代了内容在（填完九分就不再问方法与手段）；评估只在入院时做一次而不在变化的节点做；风险没有转成具体的动作与在（执行人与时间）；夜间的交接在（从白班到夜班的口头移交）里丢掉了细节；以及患者自己的信息没有被纳入。五项改动：一，把评分与必须问的四项绑定在（方法、准备、既往尝试、此刻的意图），缺一不许提交，并把原话填进表里。二，规定复评的触发点在（入院、病情变化、请假外出、换班、出院前）而不是每周一次。三，每次评估必须写出两条动作与责任人在（由谁在何时把家属带来的药锁进柜、由谁在何时通知家属）。四，把移交结构化：在床旁交一张写有“她在说什么、我们担心什么、今夜要看什么”的小卡在（不超过五行），而不是口头描述。五，让患者参与写她的预警信号与能起作用的办法，并把这一页放在她的床边；同时给员工一条明确的升级路径与在（无指责的复盘），否则大家会学会把分数填低以免被要求做更多。评价看的是过程指标在触发点的完成率与在（（动作的按时执行率））与在（自伤的次数与严重度），而不只是“评分覆盖率”（[[#def-risk]]、[[clinical-skills/patient-safety]]、[[clinical-skills/records-handover]]、[[psychiatry/self-harm-suicide-prevention]]）。**
:::

## 练习

:::
::: exercise 从速记写出精神状态检查 {level=1}
速记如下：低头、少动、说话慢而声小、回答前先叹气、说“没意思，都怪我”、否认想死但承认“想过睡过去别醒”、情感反应存在、注意能完成月份的倒数、定向完整。请写成规范的精神状态检查并给出两句结论。
::: solution
**一般观察：仪表整洁但少动，目光多向下，无自发的小动作。言语：量少、语速慢、音量低、回答前有明显的潜伏期与叹气。心境（她说的）：“没意思”“都怪我”。情感（你观察的）：低落但具反应性，范围略窄，与内容协调。思维形式：连贯、无松弛或中断。思维内容：自责的观念在（需注意是否已达妄想的强度）；否认自杀的意念，但承认被动的求死愿望在（“想过睡过去别醒”），未问及方法与计划，需补问。知觉：未引出幻觉，需明确记录未曾询问的部分还是阴性。认知：定向完整，注意可完成月份的倒数，未查记忆与视空间。睡眠食欲：待补。风险：存在被动求死的意念，方法与意图未评，风险等级不能定；今日须补问计划与手段与既往行为，并约定复评。洞察：部分在（她接受就诊）。结论两句：一，这是一次伴显著精神运动迟滞的抑郁状态，自责突出；二，本次风险询问不完整，“否认想死”不能被记录为低风险，必须在离开前补齐意念、计划、手段、既往尝试四项，并写下下一次接触的具体日期（[[#def-mse]]、[[#def-risk]]、[[clinical-skills/records-handover]]）。**
:::

::: exercise 给转介信分诊 {level=2}
四封转介信同时到达：写“抑郁，需住院评估”的32岁女性；写“幻听三月，未用过药”的19岁男性；写“服过量，内科已出院”的41岁女性；写“痴呆伴攻击，家属无法应对”的79岁男性的妻子。请安排优先级与首日动作。
::: solution
**分诊按“今天会不会死人”而不是按在（信件的措辞）。最高是服药过量的41岁：内科出院后的数周是自杀的高危期，需要当日或次日见面，问方法与囤药、把药交托、约固定的随访并把在（出院后72小时的电话）补上在（如尚未做过）。第二是19岁的首次精神病：未治疗的时间是可改变的因素，需要一周内的专科首诊与在（旁证的采集）与躯体与物质的筛查，并解释治疗与在（对睡眠与物质的建议）。第三是32岁的“需住院评估”：先电话了解她现在的进食、睡眠、自杀与在（照顾的负担），多数可以在一周内门诊解决，但要在电话里问全风险的四项；若她不能进食或有求死的计划，则当日处理。最后是79岁的家属：她的需要是真实的，但风险的落点常在（照护者的崩溃）与在药物的副作用与在（（谵妄的诱因））；给她一次在（不含他的）的会谈，重新审视用药与环境，并把在（居家的支持）的转介启动。共同的要求：每封信都要回一句“我们做了什么与为什么”，因为转介信的分诊质量取决于初级照护是否知道规则（[[#def-interview]]、[[psychiatry/psychotic-disorders]]、[[geriatrics-palliative/delirium-dementia-care]]、[[clinical-skills/clinical-reasoning]]）。**
:::

::: exercise 问出那个难问的问题 {level=2}
请在门诊对一名刚被诊断为精神分裂症、独居、三个月无亲友联系的青年，问出自杀相关的六个问题，并说明你如何处理他的“没有”。
::: solution
**六个问题依次是：“这三个月里有没有觉得活着没什么意思？”“有没有想过结束自己的生命？”“这样的念头最严重的时候，持续多久、一天来几次？”“有没有想过用什么办法？”“有没有为这件事做过准备，比如攒药或写东西？”“以前有没有伤过自己或试过结束生命？”每问之后留足沉默，不打断。当他说“没有”时：不要立刻写下否认，而是再具体一步在（“有没有过那种觉得自己消失了大家会轻松的念头？”），因为独居者的被动求死常不以“自杀”的语言出现；同时问保护的因素在（什么让你留在现在的生活里），它既提供资源也提供谈话的出口。要问手段的可及：他手上有多少药、谁有钥匙、家里有什么。记录要写“患者否认当前的自杀意念，曾否认既往尝试；被动求死的念头经追问为阴性；家中剩余药物已由本人同意交家属保管；两周后复诊”。要提醒团队：在精神分裂症的人群里自杀的完成率显著高于一般人群，且常在缓解早期与在羞耻与在（（失访的时期））发生，所以“没有念头”不能换成“下次再来”（[[#def-risk]]、[[psychiatry/psychotic-disorders]]、[[psychiatry/self-harm-suicide-prevention]]、[[clinical-skills/communication]]）。**
:::

::: exercise 审查一套精神状态记录系统 {level=3}
你要审查某院的电子病历模板：精神状态检查由十二个下拉菜单组成，中位填写时间四十秒。请指出问题、设计评估的方法与五项改动。
::: solution
**四十秒填完十二个菜单意味着它在记录想象中的患者而不是眼前的人（[[#def-mse]]、[[clinical-skills/patient-safety]]）。问题有四：菜单的默认值让“接触合作、无自杀意念”成为最省时的答案；没有原话的字段，因此主观体验被抹平；风险的字段不与动作绑定在（填了风险也没有下一步）；以及模板不显示上一次的差异，因此变化的信号看不见。评估方法：抽取连续二百份病历做结构化审查在（检查是否含原话、风险四项是否齐全、是否有下一次的日期、以及与上一份的复制率）；再做十份的患者与家属的访谈在（他们是否觉得被记录）；并统计住院期间的自伤与在（非计划的重入院）与记录质量的关联。五项改动：一，删到八个必填项，其余按需，让时间回到问诊而不是点击。二，强制一个“她的原话”的文本框，且系统对整段复制上一次的内容给出提示而不是允许静默通过。三，把风险的四项做成必须逐项确认而不能整体勾选。四，在评估旁边放一个“下一步与责任人”的字段，未填则不能保存。五，打开差异视图在（与上一份并排显示变化），并在每月的质量会上抽十份做无指责的复盘。指标：中位填写时间、复制率、风险四项的完整率、含原话的比例、以及在（出院后三十日内的自伤率）（[[clinical-skills/records-handover]]、[[psychiatry/self-harm-suicide-prevention]]、[[public-health/health-systems-economics]]）。**
