精神病性状态是指一个人与共同现实的接触受到干扰的状态。他们可能听到别人听不到的声音，持有别人认为不可能的信念，或者以一种难以理解的方式思考和说话。精神病性症状对患者本人和身边的人来说都很可怕，而且常常被误解。大多数精神病性障碍患者没有暴力行为，许多人恢复良好，结局在很大程度上取决于他们得到帮助的速度和质量。

本章介绍精神病性症状、精神分裂症及其他精神病性障碍、不可漏诊的病因、抗精神病药治疗背后的生物学，以及能改善结局的照护：早期干预、心理和家庭工作、审慎的处方以及对躯体健康的关注。

## 什么是精神病性状态

::: definition 精神病性状态及其症状维度 {#def-psychosis}
**精神病性状态**是一种以**幻觉**、**妄想**或**思维紊乱**为特征的综合征，通常伴有自知力下降。在精神分裂症及相关障碍中，症状分为三个维度：

- **阳性症状**：附加于正常精神活动之上的体验，如幻觉、妄想以及言语或行为紊乱。
- **阴性症状**：正常功能的丧失，如动机减退（意志减退）、言语减少（言语贫乏）、情感表达减少（情感迟钝）、愉快感减少（快感缺失）和社交退缩。
- **认知症状**：注意力、工作记忆、加工速度和计划能力方面的问题。
:::

阳性症状最引人注目，通常促使患者首次接触医疗服务。阴性症状和认知症状虽然不那么显眼，却常常对工作、学习和人际关系影响最大，而且对药物的反应最差。

精神病性状态是一种综合征，而不是诊断。它见于精神分裂症，也见于双相障碍和重度抑郁、痴呆和谵妄，以及药物所致的情况。面对任何表现，首要任务都是弄清属于哪一种。

## 精神分裂症及相关障碍

### 精神分裂症

::: definition 精神分裂症 {#def-schizophrenia}
在 ICD-11 中，**精神分裂症**要求在至少一个月的大部分时间里存在以下至少两项，其中至少一项来自前四项：

1. 持续的妄想；
2. 持续的幻觉（最常见为听幻觉）；
3. 思维紊乱（形式思维障碍）；
4. 被影响、被动或被控制体验（例如认为思维被插入或被夺走，或行为受到外力控制）；
5. 阴性症状；
6. 明显紊乱的行为；
7. 精神运动性紊乱，包括紧张症。

这些症状不能是其他健康状况的表现，也不能是某种物质或药物的作用。DSM-5-TR 要求持续存在紊乱征象至少六个月，其中包括至少一个月的活动期症状。
:::

精神分裂症通常在青春期后期或成年早期起病，男性略早于女性。终生风险略低于 1%。起病前常有数月或数年的**前驱期**，表现为社交退缩、学习或工作表现下降、古怪的想法和减弱的（较轻的）精神病性体验。

病程各不相同。有些人只有一次发作并完全康复；许多人反复复发，发作间期部分恢复；少数人尽管接受治疗，症状仍持续存在。与较好结局相关的因素包括急性起病、明显的诱因、病前功能良好、心境症状突出以及**未治疗精神病期**短。

### 其他精神病性障碍

- **分裂情感性障碍**：在同一次发病中，精神分裂症症状与心境发作（躁狂或抑郁）同时存在。
- **妄想性障碍**：一种或多种持续的妄想，常为被害、嫉妒或躯体性质，没有精神分裂症的其他特征；患者在妄想之外的功能往往保持良好。
- **急性短暂性精神病性障碍**（ICD-11）：精神病性症状突然起病，症状变化迅速，通常在数周至数月内缓解。DSM-5-TR 有类似的**短暂精神病性障碍**，持续不到一个月。
- **物质所致精神病性障碍**：由某种物质（如大麻、兴奋剂或酒精）的中毒或戒断引起的精神病性症状。
- 由躯体疾病引起的**继发性精神病性障碍**（见下文）。
- **伴精神病性症状的心境障碍**，见[[psychiatry/mood-disorders]]。

### 病因与危险因素

精神分裂症源于遗传因素和环境因素对发育中大脑的共同作用。

- **基因。**遗传度高，双生子研究中约为 80%。风险分散在许多效应微小的常见变异上，此外还有较罕见的拷贝数变异，如 22q11.2 缺失。一级亲属患精神分裂症会使终生风险增加约十倍。
- **早期发育。**产科并发症（如出生时缺氧）和孕期母亲感染与风险的小幅增加有关。
- **社会环境。**在城市中成长、移民、属于少数族裔群体（尤其是遭受歧视时）以及童年逆境都与较高的发病率有关。在英格兰，某些黑人及少数族裔群体的精神病性障碍发病率较高，这一发现指向歧视和社会不利处境等社会原因，而不是族裔本身。
- **大麻。**经常使用大麻，尤其是在青春期使用和使用高效价大麻，与较高的精神病性障碍风险有关。在一项大型欧洲研究中，与从不使用者相比，每天使用高效价大麻者患精神病性障碍的比值约高出五倍。

## 多巴胺假说与抗精神病药

::: theorem 精神病性症状的多巴胺假说 {#thm-dopamine}
阳性精神病性症状与纹状体中由中脑边缘及相关通路驱动的多巴胺过度释放有关。所有能治疗阳性症状的药物都阻断多巴胺 D2 受体，其临床效价与它们与 D2 受体结合的强度相关。增加多巴胺的药物（如苯丙胺类）可引起精神病性症状。
:::

::: proof
有三方面的证据支持这一假说。第一来自药理学：20 世纪 70 年代发现，不同抗精神病药的临床剂量与其对 D2 受体的亲和力密切相关，而与其对其他受体的作用无关。第二来自药物所致的精神病性症状：苯丙胺和可卡因增加突触间隙的多巴胺，可在健康人中引起偏执性精神病性症状，并使精神分裂症患者的症状加重。第三来自脑影像：PET 研究显示，精神分裂症患者和部分精神病高危者的纹状体多巴胺合成和释放增加。该假说也解释了抗精神病药的主要不良反应，因为同样的 D2 阻断也作用于其他多巴胺通路。阻断**黑质纹状体**通路引起运动障碍。阻断**结节漏斗**通路解除了多巴胺对催乳素释放的抑制，引起高催乳素血症。通往前额叶皮质的**中脑皮质**通路多巴胺活性降低，可能促成阴性症状和认知症状，这解释了为什么 D2 阻断对这些症状帮助甚微，甚至可能使之加重。该假说并不能解释疾病的全部：谷氨酸（NMDA 受体）功能障碍、大脑发育改变和认知变化也参与其中。
:::

### 抗精神病药

抗精神病药常被分为**第一代**（典型）药物，如氟哌啶醇（haloperidol）和氯丙嗪（chlorpromazine），以及**第二代**（非典型）药物，如奥氮平（olanzapine）、利培酮（risperidone）、喹硫平（quetiapine）、阿立哌唑（aripiprazole）、氨磺必利（amisulpride）和氯氮平（clozapine）。这种划分是粗略的。这些药物在各自的不良反应谱上的差异大于两类之间的差异，而且除氯氮平外，它们对阳性症状的疗效大体相似。

::: definition 抗精神病药的主要不良反应 {#def-antipsychotic}
- **锥体外系不良反应**（源于黑质纹状体 D2 阻断）：**急性肌张力障碍**（持续的肌肉痉挛，如动眼危象或斜颈，在数小时至数天内出现）、**帕金森综合征**（震颤、强直、动作迟缓，在数周内出现）、**静坐不能**（一种极其痛苦的内在不安），以及**迟发性运动障碍**（数月或数年后出现的口、舌和面部不自主运动，常为永久性）。
- **高催乳素血症**：月经紊乱、溢乳、性功能障碍，长期可致骨密度下降。常见于利培酮、氨磺必利和第一代药物。
- **代谢影响**：体重增加、血脂异常和 2 型糖尿病。氯氮平和奥氮平最为明显。
- **心血管影响**：QTc 间期延长（与氟哌啶醇及其他几种药物有关）、体位性低血压。
- **镇静**和**抗胆碱能**作用。
- **神经阻滞剂恶性综合征**（NMS）：一种罕见、危及生命的反应，表现为发热、严重强直、意识改变、自主神经功能不稳定和肌酸激酶极度升高。
:::

药物的选择由临床医生与患者共同决定，并考虑哪些不良反应对患者最重要。按照 NICE CG178 和当地方案，治疗前和治疗期间的监测包括：体重和腰围、血压和脉搏、空腹血糖或 HbA1c、血脂、必要时的催乳素，以及有指征时（例如存在心脏危险因素或使用延长 QT 间期的药物）的心电图。

::: warning 静坐不能容易被漏诊且危险
静坐不能看起来像焦虑或激越：患者坐不住、来回踱步、不停变换重心，感到被驱使着要动。它常被误认为精神病性症状加重，从而导致抗精神病药加量，使其更加严重。静坐不能令人非常痛苦，并与冲动性自伤有关。每当服用抗精神病药的人显得激越时，都要直接询问（“您是否感到内心不安？是否必须不停地动？”），并重新评估药物和剂量。
:::

### 氯氮平

**氯氮平**是唯一有明确证据表明对**难治性精神分裂症**疗效更优的抗精神病药。NICE 在实践中将难治性精神分裂症定义为对至少两种不同抗精神病药无效，其中至少一种是氯氮平以外的第二代药物，且每种都以足够的剂量使用了足够的时间。氯氮平还能减少自杀行为。然而，它常常被较晚才使用。

由于存在严重的不良反应，氯氮平需要仔细监测：

- **中性粒细胞减少和粒细胞缺乏症**：在英国，须通过注册的监测服务，在最初 18 周每周查一次全血细胞计数，然后到满一年前每两周一次，此后每四周一次。
- **心肌炎和心肌病**：多见于最初两个月；注意发热、心动过速、胸痛和呼吸困难。
- **便秘**，可进展为危及生命的肠梗阻，必须主动询问并积极治疗。
- **癫痫发作**（与剂量相关）、流涎、镇静、体重增加和糖尿病。
- **与吸烟的相互作用**：烟草烟雾中的化学物质诱导肝酶 CYP1A2，而该酶代谢氯氮平。如果患者戒烟，例如住进无烟病房时，氯氮平血药浓度可能急剧升高并引起中毒。尼古丁替代疗法没有这种作用。

::: example 一个“不见好转”的男性 {#ex-clozapine}
Marcus Campbell 先生，31 岁，患精神分裂症九年。他先后充分试用过利培酮和奥氮平，长效注射剂和血药浓度证实了良好的依从性。他仍然每天听到充满敌意的声音，两年内住院三次。请概述下一步措施。

::: solution
**确认难治性。**他已使用过两种抗精神病药，其中至少一种为第二代药物，剂量和疗程都足够，依从性已得到确认。物质使用和诊断也已复核。他符合难治性精神分裂症的标准。

**提供氯氮平。**氯氮平是首选治疗。借助书面资料，解释其获益（有相当大的机会获得有意义的改善，住院次数减少）和负担（血液检查、不良反应）。

**基线检查。**全血细胞计数、心电图、体重、血压、血糖或 HbA1c、血脂，并记录吸烟状况。在氯氮平监测服务处登记。

**安全起始。**从低剂量开始，缓慢加量，在最初几周监测脉搏、血压和体温，因为有低血压、心动过速和心肌炎的风险。每次复诊都询问排便情况，并预防性地开具泻药。就他戒烟时如何处理达成计划。

**继续心理社会照护。**针对精神病性症状的 CBT 可以帮助他应对残留的声音，家庭干预可以减少复发。
:::
:::

## 早期干预与首次发作

::: theorem 未治疗精神病期越短，结局越好 {#thm-dup}
较长的**未治疗精神病期**（从精神病性症状出现到开始充分治疗的时间）与较差的症状和功能结局相关。与常规照护相比，旨在快速发现和治疗首发精神病性障碍并在最初几年提供强化多学科照护的服务能够改善结局。
:::

在英格兰，**精神病早期干预**（early intervention in psychosis，EIP）服务面向首次发作的 14 至 65 岁人群。国家准入标准要求，因疑似首发精神病被转介的人中，至少 60% 在两周内开始接受 NICE 推荐的治疗。EIP 照护包括抗精神病药、**针对精神病性症状的认知行为治疗**（CBTp）、**家庭干预**、教育和就业支持（例如个体化安置与支持），以及躯体健康照护。

::: example 首次发作 {#ex-first-episode}
Aisha Bello 女士，20 岁，大学生，被室友带到全科医生处。两个月来她一直待在房间里，不再去上课，并遮住了笔记本电脑的摄像头和窗户。她说邻居在广播她的思想，还有一个声音在评论她正在做的事。她几乎每天吸大麻。应如何评估和处理？

::: solution
**识别精神病性症状。**她有被害妄想、思维被广播（一种被动体验）和对其行为进行实况评论的声音，伴社交退缩：很可能是首发精神病。

**评估风险和紧急程度。**询问自杀想法、伤害他人（尤其是邻居）的想法、自我忽视以及她的易受伤害性。询问她对情况的理解以及她认为什么会有帮助。

**寻找病因。**体格检查；血液检查，包括全血细胞计数、肾功能、肝功能、甲状腺功能、血糖和血钙；尿液药物筛查；并考虑 HIV 和梅毒血清学检查。如有神经系统体征、癫痫发作、意识混乱或表现迅速变化，则行脑影像学检查、脑电图和自身免疫性脑炎相关检查。

**紧急转诊**至精神病早期干预服务。NICE 建议，除非与精神科医生协商，全科医生不应在专科评估之前开始使用抗精神病药。

**EIP 中的处理。**完成基线躯体测量后，使用与她共同选择的口服抗精神病药，进行 CBTp，在她同意的情况下进行家庭干预，并支持她继续学业。坦诚、不带评判地讨论大麻问题：继续使用与更多的复发和更差的结局有关。
:::
:::

### 继发性（器质性）精神病性障碍

新发的精神病性症状可以由躯体疾病引起。提示继发性病因的特征包括起病年龄较大、起病迅速、意识混乱或意识波动、视幻觉或其他非听觉性幻觉、神经系统体征、癫痫发作、头痛以及治疗反应差。

病因包括谵妄、癫痫（尤其是颞叶癫痫）、脑卒中、脑肿瘤、痴呆（尤其是路易体痴呆）、亨廷顿病、自身免疫性脑炎（如抗 NMDA 受体脑炎，典型表现为年轻女性先出现精神病性症状，随后出现癫痫发作、运动障碍和自主神经功能不稳定）、HIV 和神经梅毒、系统性红斑狼疮、甲状腺疾病，以及包括糖皮质激素、左旋多巴和兴奋剂在内的药物。

## 长期照护与预防复发

首次发作后，NICE CG178 建议继续抗精神病药治疗一段时间（常为至少一到两年），并讨论停药的风险和获益。停用抗精神病药，尤其是突然停药时，复发很常见。

一项大型维持治疗试验荟萃分析（Leucht 等，2012 年）发现，在约一年的时间里，继续服用抗精神病药者有 27% 复发，而换用安慰剂者有 64% 复发。

长效注射（储库）抗精神病药可以帮助那些不愿每天服药或因不依从而复发的人。当不良反应得到认真对待、患者理解并同意治疗计划、治疗符合其目标时，依从性就会提高。

### 心理和社会照护

- **针对精神病性症状的 CBT**帮助患者理解自己的体验，减少声音和信念带来的痛苦，并发展应对策略。
- **家庭干预**可减少复发。它针对能预测复发的**情感表达**（家庭中批评、敌意或过度卷入的态度），并为照护者提供支持。
- **个体化安置与支持**帮助患者进入竞争性就业。
- **艺术治疗**可能有助于改善阴性症状。
- **住房、经济和社会交往**是治疗的一部分，而不是额外的附加。

### 躯体健康：死亡率差距

精神分裂症患者平均比一般人群早逝约 15 年。大多数额外死亡源于躯体疾病，尤其是心血管疾病、呼吸系统疾病和癌症。促成因素包括吸烟率高、抗精神病药的代谢影响、贫困、体力活动减少，以及**诊断遮蔽**，即躯体症状被错误地归因于精神疾病。年度躯体健康检查、戒烟支持以及对体重增加的早期处理（生活方式建议，某些情况下在专科指导下换用抗精神病药或加用二甲双胍）是照护的核心部分。

::: example 服用奥氮平后体重增加 {#ex-metabolic}
Daniel Wright 先生，26 岁，八个月前因首发精神病开始服用奥氮平，现在情况良好。他的体重从 82 kg 增加到 98 kg；身高 1.75 m。HbA1c 为 44 mmol/mol（正常低于 42）。计算他的 BMI 并概述应对措施。

::: solution
**BMI。**$\text{BMI} = \text{体重}/\text{身高}^2 = 98/1.75^2 = 98/3.0625 = 32.0$ kg/m²。治疗前为$82/3.0625 \approx 26.8$。他已从超重变为肥胖，HbA1c 处于提示糖尿病风险升高的范围（42–47 mmol/mol）。

**应对。**这是一种常见且重要的不良反应，最好及早处理。与他公开讨论。提供饮食和体力活动方面的生活方式项目。重新评估抗精神病药：可与专科团队一起考虑换用代谢风险较低的药物，如阿立哌唑，同时权衡复发风险。有时会在专科建议下加用二甲双胍（metformin），以限制与抗精神病药相关的体重增加。检查血脂和血压，如果他吸烟则支持他戒烟，并复查 HbA1c。治疗早期体重迅速增加预示着体重会进一步增加，因此建议在最初几周每周监测体重。
:::
:::

::: quiz
一名 24 岁男性两天前开始服用氟哌啶醇。他就诊时双眼向上凝视固定，颈部扭向一侧，非常痛苦。最可能的诊断是什么？
- [x] 急性肌张力障碍
- [ ] 迟发性运动障碍
- [ ] 神经阻滞剂恶性综合征
- [ ] 静坐不能
::: solution
在开始使用高效价第一代抗精神病药后数小时至数天内出现动眼危象和斜颈等持续的肌肉痉挛，属于急性肌张力障碍。按照当地指南给予抗胆碱能药物（如丙环定（procyclidine））后会迅速缓解。迟发性运动障碍在数月或数年后出现；NMS 包括发热、强直和意识改变；静坐不能是不安感。
:::
:::

::: example 置于背景中的声音 {#ex-voices-culture}
Olufunke Adebayo 夫人，58 岁，最近丧偶。她告诉全科医生，晚上有时会听到丈夫呼唤她的名字，偶尔还会看到他坐在他的椅子上。她知道丈夫已经去世，正在哀伤中，但其他方面功能正常。她所在的教会认为这表明丈夫已得安息。这是精神病性症状吗？

::: solution
**很可能不是。**在许多文化中，丧亲后短暂地听到或看到已故的亲人很常见，通常不是精神疾病的征象。关键特征：她知道丈夫已经去世，这些体验短暂且与她的丧失有关，她没有其他精神病性症状，功能保持良好，而且她所在的群体以一种令她感到安慰的方式理解这种体验。

**什么会改变这一判断。**坚定的错误信念（例如认为丈夫还活着，被关在某处）、充满敌意或命令性的声音、其他精神病性症状、明显的痛苦或功能损害，或重度抑郁或认知衰退的迹象。

**应对。**使这种体验正常化，支持她的哀伤，检查有无抑郁和自杀想法，并请她在情况变化时复诊。把普通的哀伤标记为精神病性症状是有害的。
:::
:::

::: history
19 世纪 90 年代，克雷佩林（Emil Kraepelin）根据病程和结局把“早发性痴呆”（*dementia praecox*）与躁狂抑郁性疾病区分开来。1911 年，布洛伊勒（Eugen Bleuler）提出了“精神分裂症”（*schizophrenia*）一词，强调精神功能的分裂，并指出并非所有患者都会衰退。施奈德（Kurt Schneider）在 20 世纪中叶描述了一级症状。1952 年，巴黎的德莱（Jean Delay）和德尼凯（Pierre Deniker）在拉博里（Henri Laborit）观察到氯丙嗪在手术中的镇静作用之后，报告了它对精神病性症状的疗效。卡尔松（Arvid Carlsson）在 20 世纪 50 年代末和 60 年代对多巴胺的研究，以及 20 世纪 70 年代西曼（Philip Seeman）和斯奈德（Solomon Snyder）团队关于抗精神病药效价与 D2 受体结合相一致的发现，奠定了多巴胺假说的基础。1988 年，凯恩（John Kane）等人证明了氯氮平在难治性精神分裂症中的优越性，在此前发生粒细胞缺乏症致死事件之后，氯氮平得以在血液监测下重新使用。早期干预服务在 20 世纪 90 年代发展起来，其中以墨尔本的麦高瑞（Patrick McGorry）的工作最为突出。
:::

## 后续内容

心境障碍中的精神病性症状见[[psychiatry/mood-disorders]]；大麻和兴奋剂所致的精神病性症状见[[psychiatry/substance-use]]；产后精神病和晚发性精神病性障碍见[[psychiatry/lifespan-psychiatry]]；依据精神卫生法的强制住院和治疗见[[psychiatry/treatments-mental-health-law]]；多巴胺通路见[[physiology/synapses]]。

::: summary
- 精神病性状态是一种由幻觉、妄想和思维紊乱构成的综合征；精神分裂症还有阴性症状和认知症状。
- 精神分裂症通常在成年早期起病；诊断要求特征性症状持续至少一个月（ICD-11）或紊乱持续六个月（DSM-5-TR），并排除其他原因。
- 风险反映了基因、早期发育、社会逆境和大麻使用。
- 所有抗精神病药都阻断 D2 受体；这既解释了它们对阳性症状的疗效，也解释了锥体外系和催乳素方面的不良反应。
- 监测体重、血糖、血脂、血压、催乳素，有指征时监测心电图；注意静坐不能，了解 NMS 的征象。
- 氯氮平是难治性精神分裂症的治疗药物；它需要血液监测，警惕心肌炎和便秘，并关注吸烟状况的变化。
- 早期干预服务缩短未治疗精神病期，并将药物、CBTp、家庭干预和职业支持结合起来。
- 继续抗精神病药治疗可大大降低复发风险；这一决定应共同作出。
- 精神分裂症患者早逝约 15 年，主要死于躯体疾病；躯体健康照护是核心治疗。
:::

## 习题

::: exercise 阳性还是阴性？ {level=1}
将下列各项分类为阳性、阴性或认知症状：(a) 听到一个声音评论自己的行为；(b) 整天躺在床上，毫无动力；(c) 难以跟上谈话、记不住指令；(d) 认为自己的思想正被一台机器夺走；(e) 说话很少。
::: solution
(a) 阳性（幻觉）。(b) 阴性（意志减退）。(c) 认知（注意力和工作记忆）。(d) 阳性（被动体验，思维被夺）。(e) 阴性（言语贫乏）。
:::
:::

::: exercise 多巴胺通路 {level=1}
说出四条主要的多巴胺通路，以及在每条通路中 D2 阻断的临床效应。
::: solution
中脑边缘通路：阳性症状减轻（治疗作用）。中脑皮质通路：阴性症状和认知症状可能加重。黑质纹状体通路：锥体外系不良反应（肌张力障碍、帕金森综合征、静坐不能、迟发性运动障碍）。结节漏斗通路：高催乳素血症，因为多巴胺通常抑制催乳素释放。
:::
:::

::: exercise 氯氮平与吸烟 {level=1}
一名服用氯氮平病情稳定的男性住进无烟病房后突然戒烟。请解释可能发生的情况以及应采取的措施。
::: solution
烟草烟雾中的多环芳烃诱导代谢氯氮平的 CYP1A2。戒烟后，该酶的活性在数天内下降，氯氮平血药浓度升高（常常是大幅升高），可能发生中毒：镇静、流涎、低血压、便秘和癫痫发作。尼古丁替代疗法不诱导 CYP1A2。治疗团队应监测中毒表现，检测氯氮平血药浓度，并按药师或专科医生的建议减量。如果他重新开始吸烟，情况则相反。
:::
:::

::: exercise 需治数 {level=2 check="3"}
在一项维持治疗荟萃分析中，服用抗精神病药者一年内有 27% 复发，服用安慰剂者有 64% 复发。计算一年内预防一次复发的需治数，向上取整为整数。
::: solution
绝对风险降低$= 0.64 - 0.27 = 0.37$。NNT $= 1/0.37 \approx 2.7$，向上取整为**3**。三人需继续服用抗精神病药一年，才能预防一次复发，这是一个很大的效应。
:::
:::

::: exercise BMI 的变化 {level=2 check="round(10*(95/1.68^2 - 78/1.68^2))/10"}
一名身高 1.68 m 的女性在服用抗精神病药期间体重从 78 kg 增加到 95 kg。她的 BMI 增加了多少？答案保留一位小数。
::: solution
身高的平方$= 1.68^2 = 2.8224$。之前的 BMI $= 78/2.8224 \approx 27.6$；之后$= 95/2.8224 \approx 33.7$。增加量$= 17/2.8224 \approx 6.02$，即约**6.0** kg/m²。
:::
:::

::: exercise 识别 NMS {level=2}
一名 40 岁女性在一周前增加了抗精神病药剂量，现在出现意识混乱，体温 39.4 °C，全身“铅管样”强直、出汗、血压不稳定，肌酸激酶 18,000 U/L。说出可能的诊断、两种鉴别诊断以及处理原则。
::: solution
神经阻滞剂恶性综合征。鉴别诊断：5-羟色胺综合征（数小时内起病，表现为阵挛和反射亢进而非铅管样强直，与 5-羟色胺能药物有关）、脓毒症或脑炎、恶性高热（麻醉后）以及致死性紧张症。处理：停用抗精神病药；转入内科或重症监护；支持治疗，包括降温、静脉补液，并监测肾功能（有横纹肌溶解风险）；苯二氮䓬类药物；重症时在专科建议下使用丹曲林（dantrolene）或溴隐亭（bromocriptine）等特异性药物。只有在完全康复后，才谨慎地考虑换用另一种药物重新使用抗精神病药。
:::
:::

::: exercise 器质性还是原发性？ {level=3}
一名 23 岁、无精神病史的女性在两周内出现偏执观念、激越和听幻觉，随后出现一次全面性癫痫发作、口部异常运动和血压波动。她接受了氟哌啶醇治疗，随后变得僵硬、反应减少。应考虑什么诊断？为什么？需要哪些检查？
::: solution
应怀疑自身免疫性脑炎，尤其是抗 NMDA 受体脑炎。线索包括：精神病性症状迅速起病，随后出现癫痫发作、口面部运动障碍、自主神经功能不稳定和意识水平下降，以及对抗精神病药耐受差（强直加重，这也可能是 NMS）。检查：血清和脑脊液 NMDA 受体抗体、腰椎穿刺（常见淋巴细胞增多）、脑电图（可能显示慢波或特征性图形）、头颅 MRI，并通过盆腔超声或 MRI 寻找卵巢畸胎瘤，因为年轻女性常伴有相关肿瘤。处理属于神经科范畴：免疫治疗，如有肿瘤则予切除，同时停用抗精神病药。早期治疗可改善结局，因此对任何不典型的首发精神病都必须考虑这一诊断。
:::
:::

::: exercise 与家庭一起制订计划 {level=3}
一名 22 岁男性经过六个月的治疗，已从首发精神分裂症中康复。由于体重增加和性功能方面的不良反应，他想停用抗精神病药。与他同住的母亲对他的“懒惰”非常挑剔。请讨论相关问题并制订计划。
::: solution
他的愿望是合理的，应当加以探讨，而不是置之不理。需要坦诚告知的事实：停药后的复发率很高，尤其是在最初几年和突然停药后，而复发可能使学业和人际关系受挫；但不良反应是真实存在的，会影响依从性和健康。选择包括：换用代谢和性功能不良反应较少的抗精神病药（例如阿立哌唑），将剂量减至最低有效水平，通过生活方式项目处理体重问题；如果在充分知情的讨论后他仍希望停药，则按照 NICE CG178 的描述，商定在密切监测下逐渐减量，书面记录复发征兆（他个人的早期预警信号），并制订危机计划。家庭氛围很重要：高情感表达（批评、敌意）预示复发。提供家庭干预，帮助他的母亲了解阴性症状（看起来可能像懒惰），改善沟通并减少复发。通过个体化安置与支持帮助他重返工作或学习。记录这一共同决策。
:::
