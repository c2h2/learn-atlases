精神病性障碍是大脑给经验赋予意义的方式发生了改变。**精神病指的是共享现实的检验能力的丧失：体验被赋予过度的显著性，于是声音成了言语、注视成了意图；它是一个症状群而不是一个疾病，有多种原因，也需要多种治疗。本章覆盖综合征与其病因（阳性与阴性与解离的症状、诊断的边界与器质性的鉴别）、治疗（抗精神病药与心理社会的治疗如何各管一段）、以及病程与其决定因素（早期的干预与抵抗的定义与预后的可改变部分）。

## 综合征与其病因

::: definition 精神病、精神分裂症与其鉴别 {#def-psychosis}
**症状的三分法仍然好用。阳性症状是新增的东西：幻觉（在言语性的与（在评论性的与（在对话性的））声音中最有意义）、妄想（在被与被与被被读心与被被植入的观念中最损害信任）、以及形式思维的障碍（在言语的松散与（在答非所问上的））。阴性症状是减少的东西：动机的减退与言语量的减少与情感的平淡与（在体验到的快乐上的）减退与（在社会上的）退缩；它们最预测长期的功能，也最不被药物改善，且最难与抑郁与药物的镇静与（在制度的萎缩上的）区分。解离的症状包括（在洞察的缺乏与（在自我与身体界限的紊乱上的））与在（（在时间感上的）的紊乱）。诊断上，精神分裂症要求症状持续相当的时间并造成功能的下降，并排除情感的与物质的与器质的原因；分裂情感性障碍处在两者之间（在满足两者的标准时），而短暂的与在感应性的与（在（文化相关的））的状态有各自的编码。真正不能省的是鉴别：起病在四十岁以后、伴在（神经的体征与（在认知的早期下降上的））的、伴在意识的波动与（在视幻觉上的）的、第一次发作、以及在免疫的与（在内分泌的）的，都要做器质性的排查。
排查的具体清单：血液在血相与在电解质与在钙与在肝与肾的功能与在甲的功能与在B 族维生素与在（HIV 与（在梅毒的筛查上的））与尿的药物与（在若干的）筛查；影像（在第一次发作与（在（有神经体征者中的））的计算机断层或磁共振）；脑电在（（在发作的可能的表现上的））；以及在亚急性与在（在（精神病的与（在记忆与（在癫痫上的）的）中的）时的）自身免疫的抗体与在（（在脑脊髓的）的）的检查。病因的模型是易感与压力的组合：遗传的易感度高但由许多微效的变异共同构成；环境的贡献包括在 城市的养育与（在移民与（在童年创伤与（在 大麻 的使用上的）的））；而在（多巴胺的合成能力的轻度升高上的）是被反复验证的生物学特征，也是抗精神病药的共同作用点。要交代给患者的一句话：精神病不是人格的失败，也不是父母的过错，它是一种可以被治疗的、常可被部分或完全缓解的、复发可以被预防性管理的大脑的状态（[[psychiatry/psychiatric-assessment]]、[[nervous-system/neuroinflammation]]、[[endocrine/thyroid]]、[[emergency-critical-care/acute-assessment]]）。**

## 治疗

::: definition 抗精神病药与心理社会的治疗 {#def-antipsychotic}
**抗精神病药主要通过阻断二型多巴胺受体减轻阳性症状，而各自的受体谱决定副作用。剂量原则是最低有效：多数人在中低剂量段已获得绝大部分效益，再加只是增加副作用；急性期可以稍高，稳定后回到维持的最低量。第一代的锥外反应常见，其中的静坐不能最容易被误认为“焦虑”或“需要更多药”，其实它是剂量过高的信号。第二代里氯氮平最有效，尤其在抵抗与治疗自杀的风险时，代价是粒细胞的监测与心肌炎与代谢的改变与（在肠的麻痹性梗阻上的）风险；奥氮平的代谢负担最重；利培酮与帕利哌酮最易升高催乳素并按剂量出现锥外反应；阿立哌唑因为部分激动而较少体重与催乳素的问题，却可能引起静坐不能与失眠；长效的针剂把“每天要不要吃药”的决定从患者身上移开，能降低复发，尤其适合讨厌每日服药的人。
副作用的管理应当是一张可以勾的清单：体重与腰围与血压与糖化的血红蛋白与血脂，在换药或加量时复查；锥外的反应用减量或（在短期的）抗胆碱能药处理，但不要把急性肌张力障碍当作癫痫；催乳素升高要问月经与泌乳与性功能与（在长期者中的）骨的健康，并考虑换用阿立哌唑或在专科下加用雌激素；QT 的延长要复核合并用药与电解质与（在若干药物上的）剂量；氯氮平的便秘要主动预防，几天不排便按急症处理，因为麻痹性梗阻会致命；镇静在夜间给药即可缓解，而（在体重增加上的）的干预（营养师与（在若干病例中的）二甲双胍）要在早期而不是晚期做。
心理社会的治疗不是附属品，它决定长期的功能。认知行为的治疗不争论幻觉与妄想的真假，而是减少它们带来的痛苦与行动；家庭的工作与心理教育降低复发并打断互相责备的循环；支持性就业（先找到工作再补齐准备）优于先训练后求职的模式；认知的矫正针对注意与工作记忆的损害；同伴的支持与恢复的叙事提供药物给不了的东西。排这些的顺序的标准只有一个：她现在最要解决什么。若她要先回到课堂，就把注意力放在睡眠与药物镇静与认知的安排上；若她最怕的是声音，就先做症状的工作；若家庭每晚都在争吵，就先做家庭的工作（[[psychiatry/psychiatric-assessment]]、[[psychiatry/treatments-mental-health-law]]、[[pharmacology/adverse-reactions]]、[[pharmacology/dosing-principles]]）。**
:::

## 病程与其决定因素

::: definition 早期干预、抵抗与预后 {#def-course}
**未治疗的时间越长，症状与功能的结局越差，因此第一次发作后的头两年是专门服务的窗口：小规模的团队、可及的危机应对、认知行为的治疗、家庭的工作与（在若干体系中的）就学与工作的保住，其效应在试验与真实世界中都被支持，但前提是转诊真的能到。临床上最常见的错误不是“没有抵抗”，而是在没有足量足疗程试用之前就换药，或把依从性的问题误判为抵抗。抵抗的定义是两种充分的药物之后仍无足够的反应，而此时氯氮平常被延迟数年，这期间发生的复发与住院与自杀风险是可避免的；把“已经试过氯氮平”作为抵抗判断的前提，是任何质量指标里最容易改善的一条。预后的可改变部分包括：继续的治疗与长效剂型的选择、睡眠的节律、物质的使用（尤其大麻与兴奋剂）、躯体共病（心血管的死亡是这类患者寿命缩短的最大原因）、戒烟与运动与（在若干体系中的）代谢的手术的讨论、以及住房与家庭与就业这些看起来“非医学”的东西。缓解的分布也应当被诚实地讲：约三分之一的人可获得很好的长期结果，三分之一在症状与功能上部分受限，三分之一需要持续的照护；任何人都无法在第一次发作时预测她属于哪一组，所以既不能用最坏的可能去规定她的生活，也不能用最好的可能去解释她的困难（[[psychiatry/psychotic-disorders]]、[[endocrine/diabetes]]、[[public-health/prevention-promotion]]、[[cardiovascular/vascular-disease]]）。**
:::

::: example 第一次发作 {#ex-first-episode}
一名21岁的男生被家人带来，六个月来逐渐不上课、把自己关在房里、说“室友在收音机里藏了话给他”；近两周彻夜不眠并给母亲打了十几个电话；他的家人要求“先别告诉他诊断，也别让他知道我们查了什么”。
::: solution
**这一次会谈的目标是安全、解释与下一步，而不是诊断的宣布。安全：评估（在自杀与在被害观念下的）风险与在（他是否会被那些声音驱使上的）与睡眠与（在酒精与大麻上的）与在（在（激越与不进食上的））的收住的指征；睡眠剥夺本身会加重观念，所以恢复睡眠是本周的具体治疗。解释：向他说人话（“你现在经历的这些联系感，是压力大时大脑把无关的东西连在一起，它是真实的体验，也是可以变轻的”），并向家人解释早期干预服务能做什么与能做到多少。同意：他不拒绝见面时可以门诊开始，他拒绝但风险不明确时用最低的强度短谈与在（（（在两三天内的））再约）与给家人一份“哪些变化要立刻打电话”的清单，而不是用强制去争一个“他必须同意”的场面。用药：第一次发作时建议一种第二代药物从小剂量起，说明起效需要数周、副作用要报告而不是忍受、以及（在若干方案中的）疗程至少一至两年；同时开始认知行为的治疗与家庭的工作，并处理他真正想回去的事在（在（课程与考试上的））的安排。对“别说诊断”的请求：承诺不越过他的同意，同时说明他将来需要知道自己的情况，并把信息的节奏交给他决定（[[psychiatry/psychiatric-assessment]]、[[psychiatry/treatments-mental-health-law]]、[[clinical-skills/communication]]、[[paediatrics/adolescent-health]]）。**
:::

::: example 被延迟的氯氮平 {#ex-clozapine}
一名34岁的男性在八年中用了五种抗精神病药（其中一种只试了两周三），反复住院与（在自伤上的）两次；他在门诊说“这些药都让我困，没用”；他从未被提供氯氮平；他的血相一直正常。
::: solution
**这一例符合治疗抵抗，而真正的可改之处是服务的流程。第一步是把过去的试药重排：每一次是足量吗、连续多久了、依从可保证吗、有没有（在物质的使用与（在诊断的重审上的））的混淆。若两药充分而无效，氯氮平应在几周内被认真提供而不是再试第三种；如果“困”是障碍，用夜间的单次剂量与缓慢的加量与（在若干病例中的）较低的目标剂量去解决，或先解决依从（长效针剂对某些人比氯氮平现实）。氯氮平的说明要具体：粒细胞的监测（在（按本地的频率上的））与感染发热时的当日处理、心肌炎在头四周内与在（（在肌钙蛋白与（在CRP 的复查上的））、镇静的与（在体位性低血压上的））的加量节奏、以及最重要也最少被谈的：便秘的每日询问与在（（乳果糖与（在聚乙二醇上的））的）主动的通便，因为肠麻痹是氯氮平可预防的死因。若他拒绝：不要用“你只有这一条路”来压，先问哪一部分不可接受抽血与镇静与（在（每天服药上的））；说明（在若干体系中的）家庭式的在护士的上门与（在抽血的上门的）的服务；同时给他现在最少伤害的方案与在在（（（在自伤风险上的））的安全网），并在病历上写下“已提供氯氮平，因某原因未接受”。质量的一层：把“从符合抵抗标准到首次氯氮平的天数”作为一个可测量的指标，因为把中位延迟从数年降到数月，是本领域最便宜的质量改进。同时筛查（在（自杀的意念上的））与抑郁共病与（在创伤后的）的问题（这些在抵抗的诊断中常被忽略），并考虑（在电休克上的）联合（尤其在（在紧张症与（在严重自杀的意念上的））时）（[[psychiatry/treatments-mental-health-law]]、[[psychiatry/self-harm-suicide-prevention]]、[[pharmacology/adverse-reactions]]、[[clinical-skills/patient-safety]]）。**

::: example 听到声音的文化 {#ex-voices-culture}
一名46岁的来访者在宗教背景中听到已故母亲的声音，说“她在提醒我做事”；她不恐惧，功能良好，家人也认为这是她的信仰；她的新全科医生在病历上写了“幻听，考虑精神分裂症”并准备开药。
::: solution
**这里最可能犯的是把文化性的体验当作病理的征候。判断的四条不是“有没有听到声音”，而是：这一体验在她自己的文化里是否被理解为异常；它是否带来痛苦；它是否让她失去对自己行为的控制；以及是否伴随其他的精神病性特征（在被与被与被与被读心的信念与（在功能上的）全面的衰退与（在（（在思维形式上的））的紊乱）。她听到的是一个熟悉的、被社群认可的声音，内容不命令她伤害谁，她不害怕，也不因此停下手头的事：这更像一种在文化框架内的体验（在丧亲后的尤其常见），不构成诊断，更不自动构成用药的指征。要处理的是即将发生的伤害：一个被写进病历的“精神分裂症”会带来真正的后果（保险与就业与（在她自己眼中的）自我理解），而一次不必要的抗精神病药会让她承担副作用与“我是精神病人”的身份。可行的做法：删除或改写那个不确定的表述，留下事实（“在与文化一致的背景下报告听到亡母的声音，不伴痛苦与其他精神病性特征，功能良好”）；向她解释在出现哪些变化时应当回来（声音变得（在命令与敌对的）、睡不好、开始疑心周围的人、不再出门）；给她一份书面的说明以便将来的医师看到；并对全科做一次同事之间的讨论（在文化与（在精神病性的鉴别上的））的问题上，最好以一次培训而不是以纠正的方式提出）。也要诚实：在若干社群里，“不被诊断”意味着得不到任何支持，因此要权衡她的实际利益，并把决定与她一起做。最后一条：不要用“你的信仰”来否认她的体验，也不要因为尊重而放弃评估；两者可以同时做到（[[psychiatry/psychiatric-assessment]]、[[clinical-skills/communication]]、[[public-health/determinants-inequalities]]、[[medical-ethics-law/ethical-principles]]）。**

::: example 产后的急症 {#ex-postpartum-psychosis}
一名30岁产妇在产后第九天不睡、说“孩子不是我的”、时而说“不要靠近她”；婴儿被外婆带着；她被家属送到门诊，说“她只是太累了”。
::: solution
**产后的精神病是产科与精神科的急症，其风险在两日内最高且不睡与妄想的组合意味着不能“观察一周”。第一优先是母婴的安全：直接问（在伤害婴儿的念头上的）与在（在声音的命令上的）与（在她对婴儿的信念上的）的危险（“她不是我的”这一类妄想可能引出保护性或攻击性的行动），并把问题的答案记录下来；不要因为她否认就停止询问，也不要因为否认就排除风险。第二是收住的层级：多数需要住进有母婴同室能力的（在若干体系中的）母子的单位，或在没有这种单位时与婴儿的照护安排一起处理；同时评估在失水与在营养与在钠与（在（产后出血与（在子痫的迟发形式上的））的）躯体因素。第三是用药与环境的处理：给一种抗精神病药并在哺乳的可行性上与儿科一起决定；用苯二氮的短期方案恢复睡眠（睡眠的恢复本身就是治疗的一部分）；若她的情绪与（在精神病性症状上的）严重或（在拒绝进食与（在紧张症上的）），把电休克作为选项提出（它起效快且在这一情境中的证据好）。同时把婴儿的安排落实谁在照顾婴儿与能否同室与母乳喂养的支持，并在病历上写明“这不是‘太累了’，而是一种可以治愈的急症”，因为这一句话决定了将来遇到她的人如何行动。第四是与家属的工作：他们害怕且常有病耻，需要具体的分工（不要让丈夫在她面前与她争辩妄想的内容）、以及一个明确的联系人；说明预后（在多数人中数周内明显改善，而在产后起病者中双相的病程常见，因此出院后需要情绪稳定的长期计划与（在再次妊娠前的）预防的安排）。第五是出院后的衔接：在四十八小时内的接触、儿科与母婴保健的知情、（在再次妊娠前的）预先的计划在（孕期的与（在产后的预防上的）），以及对她作为母亲的角色的支持（而不是把她的病与她的母亲身份对立起来）——[[obstetrics-gynaecology/postnatal-period]]、[[psychiatry/mood-disorders]]、[[obstetrics-gynaecology/pregnancy-complications]]、[[clinical-skills/communication]]。

## 通向何处

精神状态的检查与诊断见[[psychiatry/psychiatric-assessment]]；情感的与物质的共病见[[psychiatry/mood-disorders]]与[[psychiatry/substance-use]]；风险的评估见[[psychiatry/self-harm-suicide-prevention]]；法律的框架见[[psychiatry/treatments-mental-health-law]]；器质性精神病的鉴别见[[nervous-system/neuroinflammation]]与[[endocrine/thyroid]]；代谢与心血管的照护见[[endocrine/diabetes]]与[[cardiovascular/vascular-disease]]；急性期见[[emergency-critical-care/acute-assessment]]。

::: history
**精神分裂症的历史是命名与去命名的历史。十九世纪末，克雷丕林把一组起病于青年并伴功能衰退的情况归为一类，强调它的病程；1911年布洛伊勒用“精神分裂症”取代它，把重点放在联想的分裂上，并否认必然衰退。1930年代施耐德列出一组“一级的症状”，例如被强加的思想、被广播的体验与被评论的声音；这些条目后来进入操作性诊断标准，好处是提高可靠性，代价是把主观体验当作近乎生物学的标志，而它们并不如想象中特异。药物的年代始于1952年：氯丙嗪从麻醉的辅助转入精神科，试验显示它能改变病程而不只是镇静，随后的几十年里大批公立医院因此关闭，形成所谓“药物引起的去机构化”；这一进程既解放了很多人，也在社区服务没有跟上时把负担转移给了家庭、监狱与急诊。诊断的改革在1970年代展开：美国的诊断计划与英国与美国的精神病诊断标准可靠性研究证明，结构化的访谈能比医生的直觉产生更一致的结论，这直接催生了1980年之后以症状清单与病程时限为核心的分类，也把“分裂”与“情感性”与“短暂性”的边界反复重划；1993年与2013年的两版手册在亚型的存废、在（在抵抗的定义上的）与在“精神病临床高危”这一概念的取舍上持续争论。生物学的解释从胺类假说开始：利血平可以造成镇静与抑郁，而抗抑郁药的发现把去甲肾上腺素与5-羟色胺带入视野；到1970年代，多巴胺受体的阻断成为抗精神病药共同的作用，1980年代的受体亚型研究又解释了为什么不同的药有不同的副作用。近二十年最重要的转变是把注意力从“多巴胺假说”扩展到谷氨酸与免疫与（在发育的神经环路层面的）时间线，同时把预后研究的核心从症状转向功能：国际的随访研究显示长期结局的分布比19世纪的预言乐观得多，不同国家的差异提示社会与服务的因素不可忽视。这一段历史的教训对本章很实际：每一次命名的改动都会改变谁能拿到资源，而每一项药物的发明都会改变谁被关在哪里——[[psychiatry/psychiatric-assessment]]、[[psychiatry/treatments-mental-health-law]]、[[pharmacology/drug-development-prescribing]]、[[public-health/health-systems-economics]]。**
:::
::: summary
- 精神病是现实检验的丧失，其症状分为阳性、阴性与解离三组，而治疗与预后对这三组的反应完全不同。
- 第一次发作、晚发起病、伴意识波动或神经体征或早期认知下降者，必须做器质性的排查。
- 抗精神病药主要减轻阳性症状与激越；剂量按最低有效，副作用要有一张可勾的清单并主动处理。
- 阴性症状与认知的损害靠心理社会与康复的路径；把“药吃了还是不能工作”当作失败会毁掉康复的动机。
- 两种足量足疗程的药物无效即应考虑氯氮平；氯氮平的延迟是可测量的质量问题，而便秘是其可预防的死因。
- 未治疗的时间越长结局越差，因此早期干预与“不把人赶走”的服务设计与药物同等重要。
:::

::: exercise 说出这个现象 {level=1}
请命名并说明诊断意义：听到有人用她的名字骂她；确信邻居在墙上装摄像头；两周只睡三小时而自称被选中；递三次汤匙才成功并说手不听使唤；问今天星期几而答“红色”。
::: solution
**评论性幻听最提示精神病性状态，也最容易伴命令性的风险，需要直接问声音是否让她做事。被害妄想的关键在确信度与不可修正与功能的后果；同时要排除她真的被骚扰，因为被跟踪的体验在若干情形中是真实的。两周只睡三小时而自觉良好是躁狂的睡眠需要减少，“被选中”是夸大，这一条把诊断推向双相而非精神分裂症，而鉴别决定用药：此时加抗抑郁药会恶化。递三次汤匙与“手不听我的”要想到紧张症的僵住与药物的锥外反应，紧张症是急症，需要苯二氮与（在重者中的）电休克。答“红色”是联想的松弛，属于形式思维的障碍，比内容更有诊断价值，应在检查中记录原话而不是笼统写“思维障碍”——[[psychiatry/psychiatric-assessment]]、[[psychiatry/mood-disorders]]、[[emergency-critical-care/acute-assessment]]。**

::: exercise 选择急期的药物 {level=2}
一名32岁男性在急诊极度激越，怀疑家人害他，拒药并试图推门离开；他既往用氟哌啶醇后出现过严重的肌张力障碍，心电示QT 轻度延长。请给出此刻的次序。
::: solution
**先降温，再给药，最后才考虑强制。非药物的部分最有效：让开门口的通道，减少在场的人数与噪音，由他认识的人说话，并给出可以接受的选项。药物方面避免氟哌啶醇（既往的严重锥外反应与QT 的延长都是理由）；可选口服的奥氮平或（在需要肌注时的）奥氮平的针剂，或异丙嗪类的镇静；避免同时给苯二氮与肌注的抗精神病药以外的多种镇静剂，因为呼吸的抑制是主要的即刻危险。若必须肌注，需要一名医师在场监护并记录理由与时限。给完药之后要做的是重新评估激越的原因：疼痛与尿潴留与低血糖与谵妄与（在物质中毒上的）都可能在“精神病”的标签下被漏掉；同时给他一个可预期的时间表（谁在几点来看他、什么时候可以打电话），因为不可预测会维持激越。事后把这次的用药与反应写入记录，并注明“避免高效价的第一代药物”，让下一次见到他的人不必重复试探——[[emergency-critical-care/acute-assessment]]、[[pharmacology/adverse-reactions]]、[[psychiatry/treatments-mental-health-law]]。**

::: exercise 应对恐惧的家人 {level=2}
一名患者的父母在第一次发作后的家庭会谈上问三件事：“是我做错了什么吗”“他会不会一辈子这样”“我们能强制他吃药吗”。请逐条回答。
::: solution
**第一条：不是你们的错。这一句要说得具体：遗传的易感与发育中的脑的变化与压力的叠加共同致病，教养方式不造成精神分裂症；同时也要承认你们现在很累很怕，这是真实的，也需要被支持。第二条：没有人能在第一次发作时预测十年后的情形，但整体的图景比过去乐观，约三分之一的人可以有很好的一般性恢复；现在最能改变结局的是四件事——继续治疗、睡好、不碰大麻与兴奋剂、以及保住学习与工作；把这四件做好，比争论诊断更有产出。第三条：法律上，一个有能力的成年人可以拒绝治疗，而强制只在若干条件满足时可以使用；在临床上真正有效的是把药变成他能接受的安排，例如换掉让他难受的药、把服药时间并入他的一天、用长效的针剂去掉每天的争执、让他自己决定吃哪一种是次要的目标。要给他们一份可写的东西：复发的早期信号清单与谁在什么时候被联系；并约定下一次的家庭会谈（在若干周内），因为恐惧在信息不足时会被焦虑放大。不要承诺“他会完全好”，也不要暗示“这就是终点”；同时把父母自己的健康与（在（其他子女上的））的担心列入关注——[[clinical-skills/communication]]、[[psychiatry/treatments-mental-health-law]]、[[psychiatry/substance-use]]。**

::: exercise 设计一个十年的精神病服务 {level=3}
请为一个五十万人口的区域设计一条从首次发作到长期照护的精神病服务路径，并说明筹资、人员、公平与评价。
::: solution
**按时间设计而不是按机构设计。第一个五年内的关键是一整套早期干预的服务：可被自我转介的门（不经全科也能进入）、当日可及的评估与危机替代（在危机之家与（在夜间电话的团队上的）替代急诊）、专门的治疗师与认知行为与家庭的工作与就业的就学的支持，并把“从首次症状到被看到的天数”与“未治疗的时间”作为公开的指标。长期的部分是一支可分派的外展团队（对反复失访者与（在（无家者的））的主动接触）、代谢与心血管的照护（把血压与体重与糖化与血脂写成强制的年度项目，因为这部分人群的可预防的死亡最多）、以及康复的真实内容（在支持性就业与（在受保护的（在工作上的））的替代路径上的）的选项。急性期要有小而可及的病房与（在约束与（在长期住院上的））的减量的政策，并与社区团队共用同一份危机计划；长期住院的床位应被逐年替换为在（在（中途之家与（在（公寓式的））的））的过渡的住所。人员与保留是关键约束：治疗师与（在（同伴支持者的）职位与督导的时间与（在危机后的）复盘，否则三五年后只剩文件。公平要写成指标：按族群与性别与年龄与剥夺指数分层看强制使用的比例与住院时长与（在诊断的改判上的））的比率，因为过度诊断与不足诊断同时存在于同一系统。评价要包含患者报告的东西：工作与学习、住房的稳定、（在（她是否觉得自己被尊重上的））的、以及在（在五年上的）的随访——[[public-health/health-systems-economics]]、[[public-health/determinants-inequalities]]、[[psychiatry/treatments-mental-health-law]]、[[clinical-skills/patient-safety]]。**

::: exercise 把精神病分类 {level=1}
为下列四种情形各给最可能的类别与首要处置：三日前开始发热僵硬的服抗精神病药者；五天前生产的产妇说孩子不是她的；初次使用致幻剂后两日的惊恐与视物变形；尿毒症患者近日看见小人在屋里跑。
::: solution
**发热伴僵硬且正在用抗精神病药，是恶性综合征：立刻停药、请重症支持、查肌酸激酶与自主的稳定，它是可致死的诊断，最容易被误当作“病情加重”而加药。产后第五天的精神病是当日急症：评估自伤与伤害婴儿的风险，收入有母婴同室条件的单位，给抗精神病药并恢复睡眠。致幻剂后的惊恐与视物变形是中毒的急性反应：安静的环境与苯二氮即可，多在数小时消退，持续者要查新精神活性物质与水钠的紊乱。尿毒症患者的生动视幻觉伴昼夜波动是谵妄：查代谢与感染与药物的蓄积，而不是加抗精神病药的剂量；若必须用药，选镇静与QT 风险较低的方案并减量——[[emergency-critical-care/acute-assessment]]、[[obstetrics-gynaecology/postnatal-period]]、[[psychiatry/substance-use]]、[[renal/chronic-kidney-disease]]。**

::: exercise 管理代谢的账单 {level=2}
一名29岁男性用奥氮平两年后体重增加二十二公斤，腰围108厘米，糖化5.9，甘油三酯3.1，血压138/88；他说“这药让我能睡，我不想换”。请给出方案。
::: solution
**不要把它写成“换药或代谢”的两难（[[#def-antipsychotic]]、[[endocrine/diabetes]]）。第一步是把基线写成可比较的一组数：体重、腰围、血压、糖化、空腹血脂，并按年度重复，这样将来任何变化都有参照。第二步尊重他说的“我需要睡”，把睡眠当作独立的问题处理：固定的作息、夜间的单次给药、（在需要时的）褪黑素或短期的苯二氮，这样减药时不会同时失去睡眠这一支柱。第三步才是药物的调整：先试减量到最低有效，若无复发迹象再考虑换到代谢负担较轻的药（阿立哌唑或齐拉西酮），换药要缓慢并带上复发的警报计划。第四步是代谢的治疗本身：营养师的结构性的饮食安排与（在含糖饮料上的）替换、每周累计一百五十分钟的活动与（在若干病例中的）二甲双胍以减轻体重的增加、按指南处理血压与（在甘油三酯高时的）戒酒与（在重者中的）降脂。最后与她约定一个她能接受的目标数字（例如先减五公斤与腰围减四厘米），并把每一次的进步写进病历，因为这类干预的失败多数源于“没人再说起它”（[[pharmacology/adverse-reactions]]、[[public-health/prevention-promotion]]、[[clinical-skills/communication]]）。**
:::

::: exercise 写一份预防复发的计划 {level=2}
一名34岁的男性在第四次入院后同意写复发预防的计划；他每次都“在停药后的六周内犯病”。请写出这份计划的内容。
::: solution
**计划要短，且必须是他写的（[[#def-course]]、[[clinical-skills/communication]]）。第一栏是他自己的早期信号，按出现的先后排：先是睡不足与清晨的烦躁，然后是需要关上门与开始听收音机的“提示”，最后是把邻居的话当作针对他。第二栏是每一个信号对应的动作：睡不足时当晚联系护士并临时加一次镇静；开始回避时取消一次独处的周未并让母亲来吃饭（这是过去有效过的做法）。第三栏是他愿意在早期接受的治疗与剂量，以及他明确不接受的做法（例如不要再在急诊给他用氟哌啶醇）。第四栏是联系的人与顺序与电话，含夜间与周末的号码。第五栏是给家人的三句话：可以做什么、不要做什么、什么时候送医。第六栏是他自己希望被对待的方式（“不要在我解释时说我不正常，请给我两周的时间来证明”）。写完后与他逐条演练一遍，复印三份（他与家人与病历），并把“上次四次发作前都出现过哪几条”写清楚。不要写“按时服药”这一条了事：真正的计划必须回答“当他不想吃药时我们做什么”，比如长效的针剂与（在若干体系中的）预先的意愿书，以及双方同意的最低强度（每周一次电话比再次住院便宜得多）。三个月后复评，并在每次缓解后更新——[[psychiatry/treatments-mental-health-law]]、[[clinical-skills/records-handover]]、[[psychiatry/self-harm-suicide-prevention]]。**

::: exercise 就强制治疗辩论 {level=3}
一方主张：对反复停药复发的精神病应在出院时就要求长效针剂作为条件；另一方主张这违背自主并毁掉治疗关系。请陈述双方并给出你的立场。
::: solution
**支持一方的最强论证：复发本身有代价，每一次发作都可能带来脑与功能的进一步损害与（在若干研究中的）治疗反应变差；而自愿的口服依从性差是长期住院的最强预测，长效针剂在随机试验与真实世界中确实减少复发与住院；一个“出院时同意”的条件看起来比第六次入院时被迫更省伤害。反对一方的最强论证：把治疗作为出院的条件，法律上常越出强制治疗的授权范围；对许多人是“不按这个就不放我走”的胁迫，会使下一次的隐瞒与回避成为默认策略；它还把资源从真正缺的东西住房与随访与（在危机之家的替代上的）转到监控服药上；并且，把一个人反复发病的责任放在“她没吃药”上，会掩盖药物副作用与在（睡眠与物质的使用与家庭压力上的）等可改的原因。我的立场：可以做的是把“条件”换成“共同的选择”——在住院期间就开始谈长效针剂，把它作为减少争执与遗忘的工具而不是通行证，并明确拒绝它可以被接受，但要把风险与后果说清并写下来；对少数因反复停药而反复处于危险的人，法律的框架可以在社区内使用（在若干法域中的社区的命令），但要满足两个条件：有书面的、被共同理解的理由，以及配套的服务（每周的接触与可及的危机替代），否则它只是把门槛搬到门外。评价这一政策的指标应当是住院日与自伤与她的体验与被强制的比例，而不是“注射的完成率”——[[psychiatry/treatments-mental-health-law]]、[[medical-ethics-law/ethical-principles]]、[[medical-ethics-law/consent-capacity]]、[[public-health/health-systems-economics]]。**
