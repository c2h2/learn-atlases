发展精神病学把人放在时间轴上看：**同一套症状在不同的年龄有不同的意义，同一种药在不同的体重与不同的肝肾功能下有不同的暴露，同一次“异常”的行为可能是疾病也可能是阶段。**本章覆盖童年（注意与学习与语言与动作的发展性障碍如何被识别与如何与家庭和学校一起工作）、青少年（第二次发展的窗口，风险行为与首次发作的高峰与服务的过渡）、以及老年（迟发的症状与神经认知疾病的鉴别与多重用药的处理）；此外是把发展贯穿始终的治疗原则：剂量按体重与发育、心理治疗按发展阶段改写、以及披露与同意的年龄边界。

## 童年

::: definition 发育性的障碍 {#def-neurodev}
**发育性障碍的定义是“起病于发育期、损害个人与社会功能”，而不是“儿童特有的病”。注意缺陷多动障碍的核心是执行功能的困难：在需要维持注意与抑制反应与顺序安排的活动中不成地困难，并且在两个以上的场合（家庭与学校）造成损害；它是可以治疗的，但“治疗”不等于药：课堂的安排与作业的量与（在需要时的）额外时间与作息的一致同样重要；共病常常决定结局——学习与语言的障碍、抽动、焦虑、对立的行为、以及在青少年期出现的物质使用与驾驶的风险。孤独症的谱系以社会沟通的质的差异与兴趣与行为的重复与感觉的异常为特征，诊断的关键不是“有没有交朋友的愿望”，而是差异是否自幼存在并在当下的环境中造成困难；成年后被诊断的人常常报告“多年被当作焦虑或性格问题”，而延迟诊断的代价是真实的功能损失与自我叙事的混乱。具体的学习与运动障碍（在阅读与书写与计算与动作的协调）经常被误读为“不努力”；识别它们的价值不只是获得考试的额外时间，更是把“你为什么不做”的问题换成“你怎样学得更好”。语言与言语的发育迟缓要尽早处理，因为它会伪装成行为问题；而“贵人语迟”的说法在没有任何干预的情况下等来的是挫折与注意力与社交的问题。
评估的规则是“三个场合、两条信息、一份记录”：家里与学校与诊室的表现、父母的发育史与教师的量表、以及既往的检查（听力的视力与（在若干情形中的）癫痫的病史与家族的史）。诊断不是给孩子贴一个永久标签，而是为资源与理解提供理由；因此写诊断时要同时写三件事：孩子擅长什么、什么环境会让他失败、以及从现在起可以做哪三件具体的事。学校的角色不可替代：一份可执行的在校支持计划（座位与指令的方式与作业的分解与考试的安排与一个可以求助的成人）比任何一次门诊的谈话都更能改变一年。还要问的是孩子自己怎么想：许多孩子最痛苦的不是症状，而是“我是不是笨”；把诊断用他能懂的话解释清楚（“你的大脑在处理顺序这件事上比别人慢，这不是懒，我们有办法”）本身是治疗的一部分。最后，家庭需要的是可以执行的支持而不是同情的解释：亲子的行为管理的项目在品行问题上有效、睡眠的规律在若干障碍中能显著改善行为、以及家长自己的抑郁与焦虑要被识别并治疗（[[paediatrics/neurodevelopment]]、[[paediatrics/growth-development]]、[[psychiatry/anxiety-disorders]]、[[public-health/prevention-promotion]]）。**
:::

## 青春期与晚年

::: definition 青春期与发展的第二个半场 {#def-lifespan-adolescent}
**青春期是大脑第二次大规模重组的时期：前额的控制与奖赏系统的敏感度之间的发育落差，使青少年在情绪与同伴与新奇的事物面前既有最强的可塑性也有最高的风险。临床上有四件事在这十年集中出现。第一，多数精神障碍的起病高峰在青春期与二十岁之前，因此这一段是二级预防唯一真正的窗口：识别前驱的症状（社会退缩与学业的滑坡与睡眠的倒置与（在若干病例中的）短暂的精神病性体验）并用低强度而持续的干预接住他们。第二，风险行为是症状也是病因：驾驶、酒精与其他物质、无保护的性行为、（在若干人群中的）神经的发育尚未完成时的暴露，都会把一次阶段的困难变成长期的后果。第三，自伤与自杀在这个年龄既是常见的临床现象也是最容易被误读的求助：非自杀性的自伤有其自身的功能（调节情绪与惩罚自己与让痛变得可以说），把每一次自伤都当作自杀的企图会让两边都被误导。第四，服务的过渡是一个真实的临床事件：从儿童到成人的转介常发生在十六至十八岁，恰逢学业与居住与身份的变化，因而也是随访最容易断的时刻。做过渡的正确做法是“重叠而不是交接”：一次共同的会面、一份包含治疗与剂量与危机计划的转介信、一个明确的成人服务的联系人、以及在转介后两周内的第一次预约——把“你自己去联系”写进出院小结是最常见的失败——[[paediatrics/adolescent-health]]、[[psychiatry/self-harm-suicide-prevention]]、[[psychiatry/substance-use]]、[[clinical-skills/records-handover]]。**
:::
## 贯穿年龄的治疗

::: definition 贯穿年龄的发育精神药理与心理治疗 {#def-lifespan-treatment}
**儿童的药理学不是成人的一半剂量：体重与分布的容积与肝的酶与肾的清除都在变，而若干的药在儿童中的疗效与不良反应与成人不同，甚至与适应证不匹配（许多用于儿童的处方从未在该年龄做过试验，属于合法的超说明书使用，但必须向家长说明这一点与依据）。原则有四：从低剂量起并按体重加量、一次只改一种药、把目标写在处方旁边（是睡整夜还是不再打人还是能完成作业）、并且按期评估是否还需要（每三到六个月问一次“还需要这个吗”，因为在儿童中“没人停药”是常态）。兴奋剂与托莫西汀与（在若干情形中的）α的激动剂用于注意缺陷多动障碍，抗精神病药在若干的适应证中受限使用并需要监测体重与代谢与（在若干药中的）催乳素与锥外的反应；氟西汀在青少年的抑郁中有相对最好的证据，但需要与前两周的自杀风险的增加一起开具并加密随访。心理治疗要按发展阶段改写：对儿童依靠成人与游戏与具体化的规则，对青少年则必须给他们自主（让他们参与决定治疗的目标、允许他们对治疗师说“不”、并把保密的边界一开始就讲清楚——哪些内容会告诉家长、哪些不会、以及在自伤风险时如何处理），否则依从性会在最需要的时候崩塌。老年人的用药则是减法优先：起始剂量低、加量慢、避免抗胆碱能与长效的苯二氮与（在若干的）抗组胺与（在跌倒风险中的）多种药的组合；每开一药先问“有没有不用的办法”，每看一次门诊先问“哪一个可以不再用”——[[psychiatry/mood-disorders]]、[[paediatrics/adolescent-health]]、[[geriatrics-palliative/polypharmacy]]、[[pharmacology/patient-variation]]。**
:::

::: example 不认字的八岁 {#ex-dyslexia-anxiety}
一名八岁的男孩在二年级开始出现上学前腹痛与呕吐与拒绝进教室；老师说他“聪明但不专心、字迹乱、读书跳行”；家长开始怀疑是焦虑，并要求“开一点安神的药”。
::: solution
**先找原因的次序，再谈药（[[#def-neurodev]]、[[paediatrics/neurodevelopment]]）。他的表现最像未被识别的阅读障碍：跳行与字迹与朗读的困难在智力正常的孩子身上以“不专心”的面目出现，而焦虑与躯体症状（腹痛与呕吐与晨间的发作与在周末的缓解）常常是后果而不是原因——每天在教室里经历可预期的失败，八岁的孩子只能用身体表达。评估的具体动作：视力的听力的检查、标准化的阅读与拼写与（按本地的路径）教育的心理学的评估、注意的量表（在家与在学校各一份）、以及一次直接的谈话（问他“最难的是什么”，他往往能说出来）。要拒绝的是“先吃点对焦虑的药”：真正的干预是学校的（明确的与系统的与按字母与读音对应的阅读教学与练习的安排与考试的安排与一个理解他的教师），家长的（把“不是不努力”解释清楚）与（在焦虑确实独立存在且损害功能时的）认知行为取向的心理治疗；药物在这个年龄不是这一问题的答案，而把腹痛当成“装病”会让他失去唯一的求助方式。也要说明两件事：早识别可以改变轨迹（阅读障碍不会消失，但方法可以被教），以及共病很常见（约三成的儿童有注意与语言的合并困难，需要各自的处理）——[[clinical-skills/communication]]、[[public-health/prevention-promotion]]。**
:::
:::

::: example 人格改变的祖父 {#ex-frontotemporal}
一名67岁的退休教师半年来花钱失控、在超市拿别人的东西、言语变得粗俗、不再洗澡、食欲改变且偏爱甜食；他没有记忆的问题；家人带他来“看抑郁”。
::: solution
**行为为主的改变加相对保留的记忆，是行为变异型额颞叶痴呆的典型起病，而不是抑郁或“老年性格变坏”（[[#def-lifespan-treatment]]、[[nervous-system/dementia-neurodegeneration]]）。支持它的线索：早发的执行与行为与人格的改变、淡漠与去抑制、语言的改变（言语量减少与意义的丢失）、饮食的改变（甜食的偏好与暴食）、以及缺乏自知（他不认为自己有问题，这解释了为什么家人是就诊的推动者）。与阿尔茨海默型的差别在于：本型的记忆与视空间早期相对好，而晚期会出现同样的衰退；与抑郁的鉴别（在老年抑郁中也可有淡漠与不洗与不想动）要看情绪的质地与昼夜与（在抑郁中的）自责与求死的念头与（本病中缺乏的）自知。与（在若干病例中的）路易体的差别是波动与幻视与（在其中的）对抗精神病药的敏感。检查：影像（额与前颞的萎缩，MRI 优于“年龄相关改变”的读法）、认知评估（含执行的成套）、实验室（甲的低下与维生素B12 与（在若干情形中的）梅毒与人类免疫缺陷与（在慢性的酒精史中的）硫胺），以及（在有自杀风险的老年人中的）一次认真的自杀询问。诊断后要谈的是现实的问题：财务（他会被骗，而家属需要尽早建立代理与授权与（在需要时的）监护的路径）、驾驶（必须明确说明并按规定上报）、以及（在超市拿东西与（在性方面的）失态时的）法律的麻烦。治疗是环境的与行为的：结构的日程与去掉诱因与（在暴食与偷藏食物时的）安排与（在易怒与冲动时的）选择性再摄取的抑制剂与（在若干病例中的）曲唑酮与（在必要的）短时的抗精神病药；同时要给家属一条他们最需要的信息：**这不是“他故意的”**，而照护者的抑郁与分离（在额颞叶型中尤其常见，因为人还在而人已变）需要被作为病人看待——[[geriatrics-palliative/delirium-dementia-care]]、[[psychiatry/lifespan-psychiatry]]、[[medical-ethics-law/consent-capacity]]。**
:::

::: example 十七岁要求成人的治疗 {#ex-transition-edge}
一名17岁半的女生在儿童青少年精神科随访两年，因抑郁与自伤；她即将上大学，要求“现在就转到成人，不要再让父母进诊室”；她的母亲不同意转诊并称“她还太小”。
::: solution
**她的两个要求都值得认真对待，而且它们在临床上是同一件事（[[#def-lifespan-adolescent]]、[[paediatrics/adolescent-health]]）。转诊的时机：服务的年龄上限是制度而非生物学，最好的时机是“她稳定的时候”而不是“下一次崩溃的时候”，因此在她愿意并且离大学开学还有几个月的现在转，风险最低；拖延到十八岁之后由急诊接管，才是真正违背她利益的做法。同意的年龄：在若干法域中，成熟的未成年人可以对与治疗有关的事务自己同意（包括保密的限度），而家长反对本身不自动取消她的能力；需要评估她的理解与稳定与（在危机计划中的）她的参与，并把“她可以不让父母进入诊室”与“她愿意在什么时候让父母知道什么”分开谈。具体要做的事：一次三方的共同面谈（她、母亲、两位治疗者），在其中承认母亲的担心是真实的（两年前她曾吞药，母亲的警觉有依据），并给出一份她签名的危机计划（早期信号与可以打给谁与去哪个急诊与允许在何种情况下通知家人）；同时把转介做得具体（成人的团队的名字与首诊的日期与药物与剂量的清单与心理治疗的记录），并安排与成人团队的共同会面一次——“重叠而不是交接”。最后，与她的父母单独谈一次：他们仍然可以做的是（在约定的范围内）知道她是否安全，而不是掌握她的每一次会谈；把这条边界说清楚，能减少转诊后第一年的失联——[[psychiatry/mood-disorders]]、[[clinical-skills/communication]]、[[medical-ethics-law/consent-capacity]]、[[clinical-skills/records-handover]]。**
:::

::: example 淡漠的帕金森患者 {#ex-ppd-apathy}
一名72岁的帕金森病患者被家人说"变懒变没礼貌"：不主动做事、不吃药、无缘无故地发笑、体重下降；他的妻子已经筋疲力尽；照护机构要求"给他开点抗抑郁的药"。
::: solution
**帕金森病的神经精神问题要先分清五件事，因为它们的治疗互相冲突（[[#def-lifespan-treatment]]、[[nervous-system/movement-disorders]]）。淡漠：起始行为的减少与情感的平淡与对后果的漠然，是帕金森病最常见的精神症状之一，源于额叶皮层下环路的多巴胺不足；它不是抑郁，抗抑郁药的效果有限，而结构化的日程与把任务切成可以启动的小块与（在若干病例中的）胆碱酯酶的抑制更有帮助。抑郁：情绪的低落与自责与求死的念头与晨间的加重，是可以被治疗的，选择性再摄取的抑制剂在帕金森病中相对安全。药物的效应：多巴胺的受体激动剂可以引起冲动的控制障碍（病态的赌博与过度的购物与性方面的强迫与无目的的走动与为了不吃亏而超量服药的多巴胺失调），这一例的"无缘无故地发笑"可能是异动症或药物的精神病的早期；处理是逐步减停激动剂而不是加药，并告知家属这是药物引起的疾病，因为它常被家庭读成"他变坏了"。认知的下降：注意与执行与视空间的变化，需要与药物的影响分开。睡眠的障碍：快速眼动睡眠的行为障碍（在梦中喊叫与拳打）常在运动症状之前多年出现，氯硝西泮与褪黑素可以缓解。给照护者的部分与药物同样重要：这位妻子的疲惫是可以预见的，需要具体的帮助（把药分装在按时的盒子里与在启动困难时的提示的方式与白天的活动与在机构中的明确的分工与对她自己的抑郁的筛查）；而"给他开点抗抑郁药"这一要求应当被回应为一次评估，而不是被简单地满足或拒绝。最后一条：不要把淡漠当作不配合来处理，也不要为了配合而加量，因为两者都会把可治的问题变成难治的问题（[[psychiatry/mood-disorders]]、[[nervous-system/movement-disorders]]、[[geriatrics-palliative/delirium-dementia-care]]、[[clinical-skills/communication]]）。**
:::

**发展精神病学是从三件本来分开的事合成的一门学问：儿童的诊断、青春期的风险与老年的认知。儿童的评估源于学校：比奈与西蒙在1905年为法国的义务教育设计的智力测验，把“能不能跟上”变成一个可以被测量的问题，也开启了智力测验在移民与贫困人群中被滥用的阴暗一段（在一战中的军队甲乙量表与美国1920年代的移民筛查中都有记录）；而“儿童指导诊所”（1900年代末在芝加哥与伦敦出现）第一次把发育与家庭与学校放进同一份病历，使“孩子的问题”不再是道德问题。孤独症的命名来自1943年坎纳与1944年阿斯伯格的两个互不知晓的病例系列，两者在数十年间被混同、被错误地归因于父母的冷淡（贝特尔海姆的“冰箱母亲”论在1960至1970年代造成巨大的伤害，并在1970年代的翼母组织与拉波特的工作之后被经验证据推翻）；1980年的诊断手册首次把儿童孤独症列为独立诊断，随后的普查与标准的统一（在1994年与2013年的手册中的谱系化）解释了报告率的上升的大部分——这是一个诊断定义的变迁如何改变流行病学与资源分配的范例。注意缺陷多动障碍的谱系更长：1845年霍夫曼的《魔鬼的罐子》里已有形象，1902年斯蒂尔在讲座中描述了“道德控制的缺陷”，1937年布拉德利发现中枢兴奋剂可以改善行为，而1960至1970年代关于“是否是为不听话的孩子发明的诊断”的争论，直到双盲的对照与随访研究（在若干队列中显示症状持续到成年并伴随物质使用与驾驶与就业的风险）才使它成为一个被广泛接受的神经发育的障碍。青春期的临床是被自杀与服务的缺失逼出来的：1960至1970年代青少年自杀的上升与“没有专门的科室”的现实，催生了危机热线与（在1974年的）儿童之与（1990年代后）早期的精神病干预的项目；而把青春期当作一个独立的、有自身大脑生物学的发展阶段，则是1990年代后影像与队列研究的结果。老年的精神病学始于“老年精神病学”这一亚专科在1940至1950年代的建立，其动力既是床位的管理也是“可治疗的痴呆”这一概念的兴起：阿尔茨海默在1906至1907年的病例报告之后半个多世纪才被重新发现，1960至1970年代的“真实的抑郁”与“假性的痴呆”的区分与1980年代以后的抗痴呆药，使“记性差”从衰老变成了需要评估的疾病；同一时期暴露了大医院中抑郁与痴呆的老年人被忽视与被过度约束的历史，直接推动了（在英国的）老年精神病学改革与（1989年的）国家的服务标准。把这些线索合起来看，本专科反复出现的教训只有一个：把一个人放到她的时间与她的处境中去判断，否则“正常”与“疾病”这两个词都会被误用——[[psychiatry/psychiatric-assessment]]、[[paediatrics/neurodevelopment]]、[[geriatrics-palliative/delirium-dementia-care]]、[[medical-ethics-law/ethical-principles]]。**
:::
::: summary
- 发育性障碍的定义是起病于发育期并造成功能的损害，而不是“儿童的病”；诊断的价值在于解释与资源，而不在于标签。
- 儿童的躯体症状常是后果：在开始用药之前先查学校与（在阅读与注意上的）具体的困难。
- 青春期是多数精神障碍的起病高峰，也是二级预防唯一真正的窗口；服务的过渡要重叠而不是交接。
- 老年人格与行为的改变不是衰老：额颞叶型的痴呆以行为起病而记忆早期保留，需要财务与驾驶的现实安排。
- 儿童的处方从低剂量按体重起、一次只改一种药、把治疗目标写在旁边、并定期问“还需要吗”。
- 心理治疗按发展阶段改写；给青少年自主与保密的边界，是依从性的前提而不是让步。
:::

::: exercise 把正常与疾病分开 {level=1}
请判断：七岁不会系鞋带；十三岁每天与父母争执；十五岁连续两周不出房间且不吃饭；十六岁每天玩到凌晨三点而在周末补睡；十一岁在一年级时读到三年级水平而四年级时停滞。
::: solution
**“正常”是按功能与时限说的（[[#def-neurodev]]、[[#def-lifespan-adolescent]]）。七岁不会系鞋带：孤立的一项动作的落后值得看一次（在动作协调障碍中的）评估，尤其在合并写字与骑车与（在系扣子上的）困难时；若只是这一项且不影响生活，随访即可。十三岁每天争执：在青春期的常态范围内，除非合并逃学与（在若干病例中的）攻击与自伤与（在家庭之外的）功能的崩溃——那时要看的是环境是否还有可以协商的余地。十五岁两周不出房间且不吃饭：这是必须当天处理的，进食的量与（在脱水时的）身体的指标与（在自杀风险上的）询问一样重要；社交的退缩加上体重的下降在这个年龄最常见于抑郁与（在若干病例中的）精神病性的起病与（在拒食中的）危险的体重。十六岁每天玩到凌晨三点周末补睡：先看是否损害白天的功能；青春期的时相本身后移，完全的禁令通常无效，而光的暴露与早晨的光照与约定的起床时间比争论“熬夜有害”更有效；若为持续的、无法被拉回的、并伴情绪的恶化，要考虑双相的可能与睡眠的节律的障碍。十一岁的阅读原本超前而在四年级停滞：这种“从超前到停滞”的曲线最有价值，通常说明任务的要求超过了她的策略（在语言的与阅读的具体障碍中的），或说明情绪与欺凌在起作用；处理是拿回客观的数据（课程的作业与（在校的）评估）而不是给一个动机论的解释——[[psychiatry/mood-disorders]]、[[paediatrics/neurodevelopment]]、[[clinical-skills/clinical-reasoning]]。**
:::

::: exercise 给学校写一份说明 {level=2}
一名九岁被诊断为孤独症谱系与注意缺陷的学生的班主任要求家长“提供医生的说明，写明他可以得到什么照顾”；家长担心写出来会被区别对待。请写出这封信的内容与给家长的话。
::: solution
**信的功能是让学校能做事，而不是给疾病登记（[[#def-neurodev]]、[[clinical-skills/communication]]）。可以写：诊断的类别与依据、他容易失败的情境（在指令的层级与噪音与突然的变化与需要推测社交情境的任务）、支持他的措施（提前的预告与一次一条的指令与可以离开的安静角与视觉的日程与考试的安排与一个指定的成人）、以及需要避免的做法（公开的批评与“他就是不听话”的解释与在疲劳时增加要求）。应当不写：无关的既往史与家庭的细节与（在诊断之外）没有必要的推测、也不写任何会限制他未来的断言（“永远不能独立学习”）。写之前征得同意并让她看全文，说明学校看到什么与谁会看到与保存在哪里；也要说明“这份说明不降低他的期望，只是改变教学的方法”——许多学校把它当作降低要求的许可，需要正面拒绝这一误读。给家长的话要承认她担心的是真的：公开与隐蔽各有权衡（不写就得不到支持，写了可能被贴标签），而现实的做法是折中：说明学习上的需要而不写出所有诊断的细节，并按本地的规定决定诊断的名称是否出现在文件里。同时给她一份她自己可以保存的副本，并把支持措施写进学校的书面的计划（在若干体系中的个别教育计划），因为信件会被遗失而计划会被执行——[[clinical-skills/records-handover]]、[[public-health/prevention-promotion]]。**

::: exercise 给八十多岁减药 {level=2}
一名84岁的女性在服阿普唑仑十二年、阿米替林（在抑郁后）、（在“睡不着”时的）唑吡坦、以及（在轻度认知下降后的）多奈哌齐；近半年跌倒两次。请给出减药的次序与谈话的方式。
::: solution
**跌倒是这一处方的症状，不是她的运气（[[#def-lifespan-treatment]]、[[geriatrics-palliative/polypharmacy]]）。次序按“伤害最大、获益最小”排：首先是苯二氮，十二年的使用不能骤停，按每月减四分之一的速度递减并暂停在出现明显戒断的档；其次是唑吡坦（与苯二氮的部分重叠，在减掉苯二氮后常可一并撤去）；再次是阿米替林（抗胆碱能与体位的低血压与（在老年中的）QT的延长与认知的损害，用替代治疗覆盖抑郁之后减停）；多奈哌齐要单独评估：先确认是否真的诊断了痴呆并且有过客观的评估与（在若干体系中的）继续用药的条件，因为“记性差”不是适应证。每一处改动前后要有对照：血压（卧立位）、睡眠的日记、跌倒的日记、（在抑郁上的）量表；并明确一次只动一个。谈话的方式决定成败：不要说“这个药该停了”，要说“我们试六个月，看哪一样少了反而更好”，并把撤药的同意变成可撤回的试验；写下一张减量的表让她与家属拿着（每档的日期与出现什么情况要停下并联系）；同时提供替代（睡眠的限制与固定起床的时间与白天与傍晚的光照与夜间的如厕的安排与（在抑郁复发时的）心理与药物的路径与跌倒后的骨骼与肌力的训练）。要如实说明风险：减药初期睡眠会短暂变差与焦虑会上升，这不是“离不开药”的证据；也要说明不停药的风险（跌倒与髋部的骨折与（在其后的）一年的死亡风险、驾驶的受损与费用的负担）。最后，把“减药”写进病历的用药单，让每一个后来看到这张单的人都知道这是有意的决定——[[psychiatry/mood-disorders]]、[[nervous-system/dementia-neurodegeneration]]、[[geriatrics-palliative/falls]]、[[clinical-skills/communication]]。**

::: exercise 为青少年早期干预辩护 {level=3}
有人主张对16至25岁有短暂精神病性体验的青年做早期识别与干预，另一派认为这会造成标签与焦虑与对正常青春期波动的医疗化。请陈述双方的最强论证并给出你的立场。
::: solution
**支持一方的最强论证：精神病性障碍的起病高峰在此，而未治疗的时间越长，功能与症状的结局越差；早期的路径可以同时处理真正占据这十年的其他问题（抑郁与自伤与物质与失学与家庭），因此服务不会只服务于少数人；随机试验显示若干干预家庭的参与认知的治疗与低剂量的药与协调的照护能改善症状与若干功能的指标；而对“谁会成为精神病”的预测虽然绝对精度有限，却与临床的直觉同样有用，且干预的强度是可以按风险分层的（最轻的接受随访与（在需要时的）心理治疗，而不是人人给药）——[[psychiatry/psychotic-disorders]]。反对一方的最强论证：在筛查的人群中最终发病的比例低，所以多数被标记者不会发病；标签的成本由被标记的人付（自我概念的改变与家庭与学校对待方式的改变与（在若干人群中的）病耻与保险与就业的隐忧）；而服务的扩张常从治疗转向“占床”，把资源从已经病重者转走；历史上的教训是识别总是跑在证据前面。我的立场是可以辩护的中间：接受早期识别，但以三条件为界——一是把“风险的状态”与“疾病”分开写并反复解释（这是可能性，不是判决，且多数人不会发展出精神病）；二是只提供与风险成比例的干预，把心理治疗与家庭的工作支持与随访作为默认的层级，而抗精神病药留给确实达到阈值者，并说明其代谢的成本；三是在给任何标签之前先解决占首位的实际问题（安全与住所与（在缺课者中的）学业的补救与（在自伤者中的）照护），因为这是绝大多数求助者的需要；并公开监测这一群体的转诊后的诊断分布与失访率与功能指标。反对者真正的担忧应当被接受而不是被反驳：如果路径的结果是给焦虑的青年发药，那么它是失败的，而这正是需要指标而不是口号的地方——[[public-health/screening]]、[[public-health/prevention-promotion]]、[[medical-ethics-law/ethical-principles]]。**

::: exercise 先看哪个科 {level=1}
为下列四位患者判断首诊的科室：八岁在课堂攻击他人且语言发育晚；十三岁拒绝上学并呕吐；十五岁抽动的少年强迫洗手；七十岁在丧偶后“抑郁”并伴执行的失误。
::: solution
**按“最可能改变结局的问题”分诊（[[#def-neurodev]]、[[#def-lifespan-adolescent]]）。八岁的攻击加语言晚：先看发育的评估（在孤独症与语言的障碍中的）与环境的支持，攻击常是沟通失败的产物；把行为当独立问题处理会让学校与家庭都错过解释。十三岁的拒学加呕吐：躯体症状在上学的时刻出现而在周末消失，是焦虑的行为签名；先做学校的与家庭的计划（渐进的返回与（在需要时的）认知行为的治疗与学业的安排），而“先看消化科”通常只会重复同一套阴性检查；但也要排除真正的躯体原因（在晨间的头痛与呕吐要查颅内压）。十五岁的抽动加强迫：两者常并存，而强迫是这一例的功能损害来源（洗手的时间与皮肤的损伤与隐藏仪式），首诊可以是儿童精神科并安排暴露与反应预防；注意治疗抽动与强迫的路径不同（前者用α的激动剂或（在重者）抗精神病药，后者以心理治疗为核心），不要把“抑制动作”当成首要目标。七十岁的丧偶后“抑郁”伴执行的失误：这是唯一一位应先看躯体与认知的评估的，因为在老年，淡漠与执行的功能的下降可以是痴呆的早期或抑郁的假性痴呆或两者的叠加；哀伤本身不是疾病，但自杀的风险与（在老年男性中的）风险最高与是否影响进食与服药，决定了是否需要治疗；顺序是：身体的检查与实验室与认知的评估与（在若干情形中的）影像，然后再谈药（[[geriatrics-palliative/delirium-dementia-care]]、[[psychiatry/mood-disorders]]、[[nervous-system/movement-disorders]]、[[clinical-skills/clinical-reasoning]]）。**

::: exercise 在两端开药 {level=2}
请为下列两种情形说明剂量与治疗监测的原则：一名二十五公斤的九岁男孩需要氟西汀；一名86岁的女性第一次被开抗抑郁药。
::: solution
**两端的原则相同：从低开始、慢加、按体重与功能算、并把目标写清楚（[[#def-lifespan-treatment]]、[[pharmacology/patient-variation]]）。九岁、二十五公斤的抑郁：氟西汀在儿童青少年抑郁中有相对最好的证据，起始按体重给低剂量（数毫克每日），每一至两周按反应加量；关键的处方动作不是剂量而是随访：在开始与加量的头四周内加密接触（因为抗抑郁药在二十岁以下与自杀意念的早期增加有关，而这一风险集中在治疗的最初数周）、把家长与本人（在约定的保密范围内）都纳入观察、把治疗的期望说清（起效两至四周，早期可能更焦躁）；同时把心理治疗与学校的支持并列而非备选。监测的内容：情绪与睡眠与（在活动与食欲上的）改变与（在若干病例中的）转相的迹象（在双相的家族史中的）与自伤的念头、体重与身高（在生长曲线上）、以及依从与副作用；不要在有双相的可能时在无情绪稳定的保护下单给抗抑郁药。86岁的第一次处方：起始剂量约为成人的四分之一到二分之一，加量的间隔加倍；选择的依据是共病而不是疗效的差异——心脏的QT与在低钠与在跌倒与（在抗胆碱能负担中的）的（在若干药中的）风险与（在镇痛中的）血清素与阿片的相互作用与（在多病共存中的）多重用药。目标要具体（恢复晨间活动与（在睡眠上的）改善与（在体重上的）稳定）并设复评的时间，若两次足量足疗程无效则要转专科而不是继续加量；同时给一次认真的抑郁的鉴别（在痴呆中的淡漠与（在丧亲中的）哀伤与（在甲状腺功能低下中的）疲劳）。共同的一句话：在两端，药物的选择常常没有“心理与环境的干预是否到位”重要，而后者是唯一一件随年龄与体重都不变的东西——[[psychiatry/mood-disorders]]、[[geriatrics-palliative/polypharmacy]]、[[paediatrics/acute-childhood-illness]]、[[clinical-skills/communication]]。**

一名被诊断为注意缺陷多动障碍的九岁学生的学校要求家长“让医生开具药后必须提交一份在校服药的同意与副作用的说明”，并拒绝在非服药日让孩子参加某些活动。请回应。
::: solution
**学校有两件对的事与两件错的事（[[#def-neurodev]]、[[clinical-skills/communication]]）。对的是：在校给药需要书面的授权与清晰的剂量与时间（在若干体系中学校有权要求由医务室给药并有家长的同意），以及教师需要知道要看什么。错的是：把药物当作参加活动的前提（这是把治疗的决定从家庭与医生手里拿走，并可能被读作对用药的惩罚性的要求），以及暗示“服药的表现”才是入学与活动的条件。回应的方式：给学校一份说明，内容包括诊断与在校可能需要的安排（座位与指令与作业的分段与考试的安排与一个可求助的成人）、在观察上的要点（剂量起效的时间与何时最可能出问题）、以及在校给药的授权（若家长同意）与（在若干药物中的）在家服用即可——兴奋剂通常在家早晨服，学校需要知道的只是效果在上午最明显，因此把需要集中注意的科目排在后面。要正面纠正两条误解：药物不是行为的许可证，用药的孩子同样需要课堂的安排与（在若干孩子中）行为管理的项目；药物也不改善学习本身，它改善的是维持注意与抑制反应的能力，因此“吃了药就不用额外时间”是错的。同时提醒家长：学校不能强制要求诊断的细节之外的信息；如果学校继续以活动相要挟，应把争议提交到特殊教育的协调（或本地的公平与包容的机制），并在信中说明“我们可以讨论支持安排，但不能把药物作为条件”——这与治疗联盟并不矛盾：大多数这类冲突源于教师害怕承担用药的责任，一份明确的责任表与一个具体的联系人常常比一次会议更有用——[[clinical-skills/records-handover]]、[[public-health/prevention-promotion]]、[[clinical-skills/communication]]。**
:::

::: exercise 设计一条贯穿生命历程的服务 {level=3}
请为一个一百五十万人口的城市设计一条“从出生到晚年”的精神健康服务路径，覆盖发育、青春期、老年与过渡，并给出筹资、人员与评价的设计。
::: solution
**以发展作为组织的原则，而不是以年龄切分的服务拼接（[[#def-lifespan-treatment]]、[[public-health/health-systems-economics]]）。入口与筛查：把发育的监测与初级保健的育儿随访绑定（在若干的关键月龄做语言与社交与动作的筛查，阳性即转介到有明确等候时限的团队），以及入学前的视听力检查（被忽视的感觉的缺损是“行为问题”最常见的可治原因之一）。学龄期：一支跨学科的团队（发育的行为的儿科或精神科的医师与治疗师与教育心理的服务与言语治疗），负责诊断、在校的支持计划与家长的项目；这一层的成败取决于等候的时限与学校是否会执行。青春期：一个可被自我转介的门诊（不经家庭与不经全科的通道，因为它绕过了病耻）、（在若干体系中）学校内的心理卫生的人员、一个明确的精神病早期干预的路径与（在自伤上的）一次门急诊与危机团队的一致路径；这一层的筹资逻辑要算“避免的成年期的长期照护”，否则永远竞争不过急性床。过渡：不是转介信而是重叠的服务（共同的会面与两周内的首诊与一份由患者签名的危机计划与（在若干体系中的）成人与儿童团队的共同门诊），并把过渡的成功率作为一个公开的指标（转介后被看到的人数与在十二个月内的脱落）。老年：一支老年精神病的团队（含记忆的门诊与（在痴呆的行为症状上的）上门评估与（在养老机构中的）会诊的容量），把减药与跌倒与照护者的支持作为常规项目而不是研究课题；并在安宁的共同照护中有明确的位置（抑郁的可治性即使在晚期也值得处理）。人员：这一路径的主要约束不是床位而是人；需要跨学科的组合（治疗师与护士与社工与（在若干角色上的）受过培训的人员与（在同伴支持中的）有经验者），以及保留率的措施（督导的时间与（在危机事件后的）复盘与支持）——否则所有的设计都会在五年内退化为一份文件。评价：按路径而不是按科室测量（筛查阳性到被看到的天数与在校计划的执行率与十五至二十四岁人群的接触率与过渡后被看到与一年内脱落与（在养老院中的）抗精神病药的使用与（在老年中的）跌倒后的抗凝的比例与按剥夺指数与族群分层的结局差）。公平是设计的一部分而不是附加：如果最先受益的是最容易接触服务的人群，这条路径会扩大不平等，因此每一层都要有主动的外展（在社区的与在学校与在线上的与（在若干人群中的）翻译与文化上适配的材料），并用同一组分层指标检验它是否真的做到了——[[public-health/prevention-promotion]]、[[public-health/determinants-inequalities]]、[[psychiatry/self-harm-suicide-prevention]]、[[clinical-skills/records-handover]]。**
