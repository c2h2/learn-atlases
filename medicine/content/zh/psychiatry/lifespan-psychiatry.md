精神障碍在人生的不同阶段表现各异。儿童的焦虑可能表现为肚子痛和拒绝上学。新手母亲的抑郁可能隐藏在疲惫和对婴儿的担忧背后。老年人的抑郁可能表现为记忆问题或躯体不适。评估和治疗的原则相同，但必须根据发育、家庭背景、躯体健康和法律加以调整。

本章涵盖三个领域：儿童和青少年精神病学、围产期精神卫生以及老年精神病学。对于每一个领域，本章着重说明其不同之处、最常见的疾病以及最重要的安全问题。

## 儿童和青少年精神卫生

所有终生精神障碍中约有一半在十五六岁之前起病。及早识别问题，并在家庭和学校中帮助儿童，可以改变一个人的人生轨迹。

### 儿童有何不同

- **发育。**必须对照儿童年龄应有的表现来判断其行为。两岁时发脾气是正常的，十二岁时则不然；幼儿期怕黑是正常的。
- **儿童周围的系统。**儿童生活在家庭、学校和社区之中。评估需要父母或照护者、教师，常常还有社会照护机构参与。儿童身上的问题可能反映了系统中的问题，例如父母患病、冲突或忽视。
- **沟通。**年幼的儿童可能通过行为、游戏或躯体症状而不是语言来表达痛苦。
- **儿童保护。**每一次评估都要考虑儿童是否有遭受虐待或忽视的风险。儿童保护是每个人的责任。
- **同意。**年轻人可能能够自己作出决定，这取决于年龄和理解能力。

::: definition 青少年的同意与能力 {#def-lifespan-adolescent}
在英格兰和威尔士，**16 岁和 17 岁**的年轻人被推定有能力同意治疗，并且《2005年心智能力法》（Mental Capacity Act 2005）在大多数方面适用于他们。**16 岁以下**的儿童，如果具有足够的成熟度和理解力，能够充分理解所建议的治疗，就可以同意治疗；这被称为 **Gillick 能力**，源于 1985 年英国上议院的一个判例。对于缺乏这种能力的儿童，通常可以由父母代为同意。年轻人拒绝治疗会引起复杂的法律问题，常常需要专科和法律意见。
:::

### 神经发育障碍

::: definition 神经发育障碍 {#def-neurodev}
**神经发育障碍**起病于发育期，涉及大脑发育的差异，影响个人、社交、学业或职业功能。

- **注意缺陷多动障碍**（ADHD）：持续的注意缺陷和/或多动-冲动模式，在 12 岁之前出现（DSM-5-TR），见于一个以上的场合（例如家中和学校），并造成功能损害。
- **孤独症谱系障碍**（孤独症）：社交沟通和社交互动方面的持续差异，加上局限、重复的行为、兴趣或活动模式，可能包括感官敏感。孤独症是终生的，对人的影响差异很大；许多孤独症成人更喜欢“身份优先”的说法（“孤独症人士”）。
- **智力障碍**（ICD-11 称“智力发育障碍”）：智力功能和适应性行为明显受限，始于发育期。
- **抽动障碍**，包括 **Tourette 综合征**（多种运动抽动和至少一种发声抽动，持续一年以上）。
:::

神经发育障碍常常同时出现，并与焦虑、抑郁和癫痫共存。它们由专科多学科评估作出诊断，评估依据来自父母和学校的病史、观察以及标准化工具。

**ADHD 的治疗。**NICE NG87（2018 年，2019 年更新）推荐对年幼儿童首先采用家长培训和环境支持，当这些措施之后症状仍造成明显损害时再使用药物。**哌甲酯**（methylphenidate）是 5 岁及以上儿童和青少年的一线药物；**赖右苯丙胺**（lisdexamfetamine）是下一个选择。对于成人，赖右苯丙胺或哌甲酯为一线药物。兴奋剂可以降低食欲、减缓生长，并升高心率和血压，因此监测包括开始用药前及治疗期间定期测量身高、体重、脉搏和血压，并将生长情况绘制在百分位曲线图上。

**孤独症。**没有治疗孤独症本身的药物。支持的重点是沟通、调整环境、教育、帮助家庭以及治疗焦虑、睡眠问题和 ADHD 等共存疾病。抗精神病药有时用于严重的易激惹或攻击行为，但仅在其他方法无效时使用，并需仔细监测（NICE CG170）。

::: example 一个坐不住的男孩 {#ex-adhd}
Leo Martin，8 岁，因学习进步差被转介。老师说他在座位上坐不住，不停地打断别人，经常丢东西；父母描述他从学步期起在家里也是这样。他的阅读落后。他的母亲问他是不是“只是需要更多管教”。应如何评估他？需要考虑什么？

::: solution
**评估。**专科评估收集发育史、来自家庭和学校的报告（双方的评定量表）、观察结果，并进行包括听力和视力在内的体格检查。ADHD 要求症状出现在一个以上的场合、在儿童期起病并造成功能损害，这些似乎都存在。

**考虑其他可能和共存疾病。**特定学习障碍（如阅读障碍）可能解释阅读问题和挫败感；焦虑、睡眠问题（包括阻塞性睡眠呼吸暂停）、听力损失、孤独症、失神发作以及家中的不良经历都可能导致注意力不集中或坐立不安。

**回答母亲的问题。**ADHD 不是由不良的养育方式引起的，尽管养育策略会有帮助。解释这一点以减少自责。

**如果诊断为 ADHD 的计划。**家长培训、课堂调整和阅读支持。如果功能损害仍然明显，可在测量基线身高、体重、心率和血压并了解心血管病史后，提供哌甲酯等药物，并定期监测生长和心血管指标。
:::
:::

### 情绪和行为问题

**焦虑障碍**是儿童中最常见的精神障碍。它们可能表现为拒绝上学、黏人、躯体症状或回避。CBT（常有父母参与）是主要治疗。

**抑郁**在青春期后变得常见得多，尤其是在女孩中。在年轻人中，它可能表现为易激惹而不是心境低落。NICE NG134（2019 年）推荐首先采用心理治疗。对于心理治疗无效的中度至重度抑郁，在专科评估后可以在心理治疗的同时加用**氟西汀**（fluoxetine）；它是在年轻人中证据最好的抗抑郁药。所有抗抑郁药都带有年轻人在治疗早期自杀想法增加的警示，因此需要密切监测。

**品行问题**（持续的对抗、攻击、违反规则）在年幼儿童中最好通过家长培训项目处理，在青少年中则采用多模式干预。

## 围产期精神卫生

妊娠期和产后一年带来躯体、激素和社会方面的变化，是精神疾病易感性增加的时期。这一时期的精神疾病影响母亲、她与婴儿的关系以及婴儿的发育。在英国，自杀仍然是妊娠结束后一年内孕产妇死亡的主要原因之一。

::: definition 分娩后的精神疾病 {#def-perinatal}
- **产后情绪低落**（baby blues）：短暂的流泪、易激惹和情绪不稳定，在产后最初几天非常常见（常在第 3–5 天左右），约两周内无需治疗即可缓解。
- **产后抑郁**：在妊娠期或产后开始的抑郁发作，约每 10 名女性中有 1 人受影响。症状与抑郁相同，常伴有焦虑以及对婴儿或对自己是不称职母亲的担忧。
- **产后精神病**：一种严重的精神科急症，约每 1,000 名产妇中有 1–2 人发生，通常在产后最初两周内开始。特征包括快速变化的心境（躁狂、抑郁或混合状态）、意识混乱、妄想和幻觉，常常涉及婴儿。患有双相障碍或既往有过发作的女性风险要高得多。
:::

围产期焦虑障碍、强迫障碍（常伴有婴儿受到伤害的侵入性想法）以及创伤性分娩后的 PTSD 也很常见。父亲和伴侣也可能发生抑郁。

### 筛查与评估

NICE CG192（2014 年，2020 年更新）建议在首次产前接触和产后早期询问精神健康情况，包括过去或现在的严重精神疾病以及围产期精神疾病家族史。抑郁使用 **Whooley 问题**（关于心境低落和兴趣丧失的两个问题）以及一个是否需要帮助的问题；焦虑使用 **GAD-2**。**爱丁堡产后抑郁量表**（EPDS）是一份计分 0–30 的 10 项问卷，也被广泛使用。第 10 项询问自伤的想法，始终需要跟进。在一项大型个体参与者数据荟萃分析中，EPDS 以 11 分或以上为界值时，对重性抑郁的灵敏度约为 0.81，特异度约为 0.88。

Sofia Rossi 女士，31 岁，在第一个孩子出生六周后接受健康随访员的随访。她的 EPDS 各项得分为 2、1、2、3、2、1、2、2、1、0（第 10 项为自伤）。计算她的总分并说明接下来应怎么做。然后计算在患病率为 10% 时，灵敏度 0.81、特异度 0.88 的 EPDS 达到 11 分或以上的阳性预测值。

::: solution
**总分。**$2+1+2+3+2+1+2+2+1+0 = 16$，高于界值。

**下一步。**阳性筛查结果之后应进行临床评估，内容包括抑郁、焦虑、睡眠、与婴儿的情感联结、支持和安全。第 10 项为 0 分，但仍要直接询问自杀想法。许多疲惫的新手母亲得分很高，因此需要通过会谈区分抑郁与正常的适应。如果确诊抑郁，选择包括有指导的自助、CBT 或人际心理治疗，必要时使用抗抑郁药，并提供关于哺乳期用药的信息。

### 妊娠期和哺乳期用药

关于妊娠期精神药物的决策，要权衡药物对婴儿的风险与疾病未治疗或复发对母亲和婴儿的风险。发现怀孕后突然停用有效的治疗可能导致复发。关键原则：

- 尽可能在妊娠前进行规划，为任何服用精神药物且有生育可能的人提供孕前咨询。
- 使用安全性证据最好的药物的最低有效剂量，避免不必要的换药。
- 由于致畸和神经发育损害的风险很高，妊娠期不得将**丙戊酸盐**用于精神疾病。按照 MHRA 的规定（2024 年 1 月），除非两名专科医生独立认定没有替代方案，否则不应为 55 岁以下的任何人开始使用丙戊酸盐，可能怀孕者必须参加妊娠预防计划。
- 妊娠期使用**锂盐**需要专科管理，随着肾功能变化密切监测血锂水平，并对分娩作出规划。
- 具体药物的信息来自英国致畸信息服务（UK Teratology Information Service）和 BNF 等专业来源。

::: example 一位“不像她自己”的母亲 {#ex-postpartum-psychosis}
Amara Okonkwo 夫人，29 岁，八天前生下第一个孩子。她的丈夫打电话给全科医生，因为她已经三个晚上没睡觉，说话很快，认为婴儿在医院里被“调包”了，有时还显得意识混乱。她在大学时有过一次抑郁发作。可能的诊断是什么？应该怎么做？

::: solution
**诊断。**这很可能是**产后精神病**：产后两周内起病，严重失眠，言语加快，存在涉及婴儿的妄想，并伴意识混乱。她既往的抑郁可能是一种未被诊断的双相障碍的一部分。

**紧急程度。**这是一种精神科急症，因为存在自杀、伤害婴儿（通常与妄想有关，而非出于意图）以及迅速恶化的风险。需要由围产期精神卫生团队或危机团队在当天进行评估。

**排除躯体原因。**应考虑感染、子痫、甲状腺疾病、贫血、睡眠剥夺相关的谵妄以及药物作用。

**处理。**首选收入**母婴病房**，母亲和婴儿可以在那里安全地待在一起。治疗通常包括抗精神病药，有时加用心境稳定剂，并注意哺乳问题。康复通常良好，但以后妊娠时复发以及日后出现双相发作的风险很高，因此为今后的妊娠制订书面计划很重要。
:::
:::

## 老年精神病学

老年精神病学处理晚年的精神疾病，包括各种痴呆。躯体疾病、药物、感觉丧失、丧亲和社会孤立都会影响临床表现。

::: theorem 三个“D”相互重叠 {#thm-three-d}
在老年人中，**谵妄**（delirium）、**痴呆**（dementia）和**抑郁**（depression）都会引起认知、心境和行为的改变，并且常常共存。谵妄是急性的、波动的，伴注意力受损；痴呆是逐渐进展的，注意力直到晚期才受损；抑郁导致主观的记忆抱怨和努力不足，而在投入时表现常常保持正常。由于谵妄是医学急症、抑郁是可治疗的，对任何出现认知改变的老年人都必须积极寻找这两者。
:::

::: proof
这种区分源于其机制。谵妄是由急性躯体应激（感染、药物、代谢紊乱、手术）引起的全脑功能紊乱。它首先损害觉醒和注意力，因此在数小时至数天内起病，并在一天中波动。痴呆源于进行性神经变性或血管损伤。它在数月至数年中侵蚀记忆和其他认知领域，而注意力和警觉性直到晚期才受影响。晚年抑郁损害注意力集中、加工速度和动机，因此患者可能回答“不知道”并抱怨记忆差，但在鼓励下表现常常会改善。每一种疾病也会增加其他疾病的风险：痴呆是谵妄最强的危险因素，谵妄会加速认知衰退，而抑郁可能是痴呆的早期特征。因此，评估的核心包括：向知情人仔细询问起病和病程、使用 4AT 等注意力测验、评估心境以及寻找躯体原因。
:::

| 特征 | 谵妄 | 痴呆 | 抑郁 |
|---|---|---|---|
| 起病 | 急性（数小时至数天） | 隐匿（数月至数年） | 数周至数月 |
| 病程 | 波动 | 缓慢进展 | 持续，可随心境变化 |
| 注意力 | 受损 | 通常直到晚期才受损 | 注意力集中下降 |
| 意识 | 改变 | 正常 | 正常 |
| 对测验的典型回答 | 注意力不集中、杂乱无章 | 会尝试作答，虚构或掩饰 | “不知道”，努力不足 |

### 晚年抑郁

老年人的抑郁很常见，却常常被漏诊，因为它可能以躯体症状、焦虑、记忆抱怨或退缩而不是悲伤来表现。它与躯体疾病、疼痛、残疾、丧亲和孤独有关，并会增加死亡率。老年男性的自杀率很高。治疗遵循与年轻成人相同的原则，同时注意躯体健康、药物相互作用、跌倒以及 SSRI 引起的低钠血症；对于重度或伴精神病性症状的抑郁，ECT 是一种有效的选择。

### 痴呆的行为和精神症状

::: definition 痴呆的行为和精神症状 {#def-bpsd}
**痴呆的行为和精神症状**（BPSD）包括激越、攻击、游走、睡眠紊乱、淡漠、抑郁、焦虑、妄想和幻觉。其中许多反映了未被满足的需求：疼痛、便秘、感染、饥饿、口渴、无聊、恐惧或令人困惑的环境。
:::

首先应寻找并处理原因，并采用非药物措施：以人为本的照护、结构化活动、音乐、调整环境以及照护者培训。**抗精神病药**会增加痴呆患者脑卒中和死亡的风险。NICE NG97（2018 年）建议，只有当患者有伤害自己或他人的风险，或因激越、幻觉或妄想而极度痛苦时才使用抗精神病药，以最低有效剂量、最短时间使用，并定期复查。路易体痴呆或帕金森病痴呆患者可能对抗精神病药发生严重的、有时危及生命的敏感反应。

::: example 抗精神病药的代价 {#ex-nnh}
一项对痴呆患者使用非典型抗精神病药的安慰剂对照试验的汇总分析（Schneider 等，2005 年）发现，在 10–12 周内，服用抗精神病药者约 3.5% 死亡，而服用安慰剂者约 2.3% 死亡。计算绝对风险增加和需害数（NNH）。这应如何指导实践？

::: solution
**绝对风险增加。**$0.035 - 0.023 = 0.012$，即 1.2 个百分点。

**NNH。**$1/0.012 \approx 83$。每用非典型抗精神病药治疗大约 83 名痴呆患者约三个月，就多出一例死亡。

**意义。**在试验中，抗精神病药对激越的获益不大。考虑到每治疗约 80 人就多一例死亡，加上脑卒中风险增加、镇静和跌倒，抗精神病药应保留用于严重痛苦或存在风险的情况，以低剂量短期使用，并按照 NICE NG97 的建议定期复查。非药物方法优先。
:::
:::

### 晚发性精神病性障碍

60 岁以后开始的精神病性症状常与脑部疾病（痴呆，尤其是路易体痴呆、脑卒中、肿瘤）、谵妄、药物、感觉障碍（听力损失是公认的危险因素）或抑郁有关。原发性精神病性障碍也可能晚发，常见于独居的女性，表现为关于邻居或闯入者的被害妄想。评估包括认知测验、听力和视力检查，以及有指征时的神经影像学检查。

::: warning 不要认为老年人的意识混乱“只是痴呆”
老年人的思维或行为突然改变，尤其伴有嗜睡或波动时，在被证明为其他原因之前都应视为谵妄，即使他们已经患有痴呆。谵妄很常见，常被漏诊，并与高死亡率相关。用 4AT 等工具检查注意力，审查用药，并寻找感染、脱水、尿潴留、便秘、疼痛和代谢原因。
:::

::: quiz
一名女性在分娩四天后接受检查。她有时流泪、易激惹，但在婴儿睡觉时能够入睡，照顾婴儿很好，也乐于接待探视者。最可能的解释是什么？
- [x] 产后情绪低落
- [ ] 产后抑郁
- [ ] 产后精神病
- [ ] 双相障碍
::: solution
产后第 3–5 天左右出现短暂的流泪和情绪不稳定，而无持续的心境低落、功能丧失、失眠或精神病性症状，是产后情绪低落的典型表现。它在约两周内缓解。如果持续超过两周或症状加重，则应评估有无产后抑郁。
:::
:::

::: history
儿童精神病学在 20 世纪 30 年代成为一个专科，标志是坎纳（Leo Kanner）的教科书（1935 年）以及他在 1943 年对早期婴儿孤独症的描述；1944 年，阿斯伯格（Hans Asperger）在维也纳描述了一组相关的儿童。20 世纪 60 年代，拉特（Michael Rutter）的怀特岛研究首次严格估计了儿童精神障碍的患病率。1902 年，斯蒂尔（George Still）描述了如今会被称为 ADHD 的儿童。1858 年，马尔塞（Louis-Victor Marcé）发表了一部关于产褥期精神疾病的早期专著，围产期精神卫生领域的 Marcé 学会即以他命名。英国最早的母婴病房于 20 世纪 40 年代末和 50 年代开设。20 世纪 50 年代，罗斯（Martin Roth）的工作将老年人的抑郁和晚发性精神病性障碍与痴呆区分开来，奠定了现代老年精神病学的基础。1987 年，考克斯（John Cox）及其同事发表了爱丁堡产后抑郁量表。
:::

::: summary
- 一半的终生精神障碍在十五六岁之前起病；儿童评估要考虑发育、家庭、学校和儿童保护。
- 16–17 岁的年轻人被推定具有决策能力；更年幼的儿童可能具有 Gillick 能力。
- ADHD、孤独症、智力障碍和抽动障碍属于神经发育障碍；哌甲酯是儿童 ADHD 的一线药物，需监测生长、脉搏和血压。
- 心理治疗是年轻人抑郁的一线治疗；专科评估后可加用氟西汀。
- 产后情绪低落短暂而常见；产后抑郁约影响 1/10 的女性；产后精神病（每 1,000 人中 1–2 人）是急症，双相障碍者风险高。
- 在妊娠期和产后询问精神健康情况；EPDS 是一种筛查工具，第 10 项始终需要跟进。
- 妊娠期用药决策要平衡药物风险与复发风险；不得使用丙戊酸盐。
- 在老年人中，谵妄、痴呆和抑郁相互重叠；始终要寻找谵妄。
- 处理 BPSD 应先寻找原因并采用非药物方法；痴呆患者使用抗精神病药会增加脑卒中和死亡风险。
:::

## 习题

::: exercise 产后情绪低落还是抑郁？ {level=1}
列出区分产后情绪低落与产后抑郁的三个特征。
::: solution
时间和持续时间：产后情绪低落在最初几天开始，约两周内缓解；产后抑郁持续超过两周，并可能在产后第一年内较晚时开始。严重程度：产后情绪低落较轻，功能保持；抑郁则包括持续的心境低落或兴趣丧失，并伴功能受损。相关特征：抑郁包括无望感、自责、即使婴儿睡觉时也睡不好，有时还有自伤想法等症状。
:::
:::

::: exercise 谵妄、痴呆还是抑郁？ {level=1}
给出谵妄、痴呆和抑郁的典型起病、病程和注意力状态。
::: solution
谵妄：在数小时至数天内急性起病，病程波动，注意力受损，意识改变。痴呆：在数月至数年内隐匿起病，缓慢进展，注意力通常直到晚期才受损。抑郁：在数周至数月内起病，病程持续，注意力集中下降但意识正常，常回答“不知道”且努力不足。
:::
:::

::: exercise Gillick 能力 {level=1}
一名 15 岁女孩向全科医生寻求焦虑的治疗，并且不希望告诉父母。全科医生必须评估什么？
::: solution
评估她就这一决定是否具有 Gillick 能力：她是否有足够的成熟度和理解力，能理解所建议治疗的性质、目的、获益和风险以及替代方案。全科医生应鼓励她让父母参与，但如果她有能力，应尊重她的保密要求，除非存在儿童保护方面的担忧或严重伤害的风险，此时向相关机构分享信息是正当的。评估过程和理由应记录下来。
:::
:::

::: exercise EPDS 总分 {level=2 check="13"}
一名女性的 EPDS 各项得分为 1、1、2、2、1、2、1、2、1、0。计算她的总分。
::: solution
$1+1+2+2+1+2+1+2+1+0 = 13$。这高于 11 分的界值（并达到常用的 13 分阈值），因此应随后进行抑郁的临床评估。第 10 项为 0 分，但仍应询问自杀想法。
:::
:::

::: exercise 需害数 {level=2 check="1/(0.035-0.023)"}
采用 10–12 周内抗精神病药组死亡率 3.5%、安慰剂组 2.3% 的数据，计算需害数。给出$1/\text{ARI}$的精确值（不要取整）。
::: solution
ARI $= 0.035 - 0.023 = 0.012$。NNH $= 1/0.012 \approx 83.3$。习惯上报告为约 83（有些人为了对伤害保持谨慎而将 NNH 向下取整）。每治疗约 80 人三个月，就多出一例死亡。
:::
:::

::: exercise 兴奋剂的监测 {level=2}
一名 10 岁儿童开始服用哌甲酯治疗 ADHD。开始用药前和治疗期间应测量哪些指标？为什么？
::: solution
开始用药前：身高和体重并绘制在百分位曲线图上，心率和血压并绘制在百分位曲线图上，以及心血管病史（心悸、晕厥、心源性猝死家族史），如有疑虑则做心电图或请心脏科会诊。治疗期间：每六个月测量身高，定期测量体重（兴奋剂会降低食欲并可能减缓生长），每次调整剂量后及每六个月测量心率和血压（兴奋剂可使两者升高），并评估睡眠、心境、抽动和食欲。遵循 NICE NG87 和当地方案。
:::
:::

::: exercise 围产期规划 {level=3}
一名 32 岁双相 I 型障碍女性，服用锂盐病情稳定，现妊娠 8 周。她生第一个孩子后曾患产后精神病。请概述一份围产期精神卫生计划。
::: solution
紧急转介至专科围产期精神卫生服务。不要突然停用锂盐。讨论各种选择：继续使用锂盐（心脏畸形风险略有增加；由于妊娠期肾清除率升高，需每隔几周密切监测血锂水平；进行胎儿超声心动图检查；制订分娩计划，包括血锂检查和液体管理，因为产后血锂可能急剧上升），或换用妊娠期安全性数据良好的抗精神病药，同时权衡复发风险。鉴于她的病史和双相障碍，她发生产后精神病的风险非常高，因此应制订一份与助产士、产科医生、全科医生和家人共享的书面计划，内容包括：复发的早期征象、产后保护睡眠（夜间支持）、最初几周的密切联系、及时入住母婴病房，以及关于产后喂养和用药的决定。让她的伴侣参与。定期复查计划，并确保产科团队知道在分娩时联系围产期服务。
:::
:::

::: exercise 养老院中的行为改变 {level=3}
一名住在养老院的 84 岁阿尔茨海默病男性，过去一周在接受个人护理时对工作人员有攻击行为。工作人员要求开“一些让他平静下来的药”。请描述一种结构化的处理方法。
::: solution
首先寻找原因，因为新出现的行为常常提示未被满足的需求或躯体疾病：评估有无谵妄（注意力、波动性）、疼痛（例如关节炎、压疮或牙齿问题）、便秘、尿潴留或感染、新用药物、睡眠差、听力或视力问题以及抑郁。观察模式：攻击是否只在个人护理时出现？这可能反映恐惧、尴尬、活动时疼痛或误解。非药物措施：平静地接近，解释每一个步骤，由固定的照护人员护理，留出更多时间，提供选择，调整时间安排，并治疗疼痛。让他的家人参与，以了解他的经历和喜好。只有在采取这些措施后他仍极度痛苦或有伤害自己或他人的风险时，才考虑使用抗精神病药，以最低剂量、最短时间使用，事先（尽可能）与他本人及其家人讨论脑卒中和死亡风险增加的问题，并在约六周内复查。如果可能是路易体痴呆，则避免使用抗精神病药。记录决策理由。
:::
