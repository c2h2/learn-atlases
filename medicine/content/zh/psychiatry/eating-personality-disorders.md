进食障碍与人格障碍共用一套临床的语法：**关于自我与身体的痛苦，通过控制、回避与关系的动荡表达出来；两者都在长期的治疗中被改变，也都在短期的危机中被误治。本章覆盖进食障碍的综合征（神经性厌食与神经性贪食与暴食障碍与回避限制性的进食障碍与其他特定的类型）、医学的危险与再喂养（电解质与心脏与（在再喂养综合征中的）磷的变化）、以及人格障碍（尤其边缘型：其诊断的实质与其治疗，即治疗者自己作为工具的使用）。

## 进食障碍

::: definition 进食障碍的综合征 {#def-eating}
**神经性厌食：能量的摄入相对于需要明显不足，导致显著的低位体重；对增重的强烈恐惧或对成为胖的病态的执念；以及对自身体重或体形的自毁性的评估。它的自我牺牲性质决定了治疗的困难：多数人并不把“低体重”当作问题，而把节制当作成就，所以动机是需要在治疗中长出来的，而不是被要求先具备的门槛。非典型（在体重接近正常者）同样有危险，其医学的并发症可以出现在体重下降之前。神经性贪食：反复的暴食（在一段时间内摄入明显多于多数人在相似时间与相似情境下的量，并伴失控感）与补偿的行为（自我催吐与滥用泻药与利尿剂与过度的运动），其体重可以正常，而诊断的核心是自我评价过度地受体重与体形的支配；它的病程常常在正常体重下进行多年而不被发现。暴食障碍：反复的暴食而不伴规律的补偿，因而常伴体重上升与代谢的问题，并且被“我停不下来”的失控感与事后的羞耻定义；把它归入“贪吃”或“缺乏意志力”是最常见的延误。回避限制性的进食障碍：对进食的回避并非出于体形的担忧，而是源于感觉的敏感（在质地与气味与温度上的）或对后果的恐惧（在窒息与呕吐与（在过敏后的）焦虑中的），在孤独症谱系与（在若干的焦虑的障碍中）常见，也常被误诊为“挑食”。其他特定的类型（在非典型与（在夜间进食的）与（在若干人群中的）文化的综合征中）不是废纸篓：多数门诊的个案落在这里，其处理与“典型的”同类并无不同。
共病决定了结局：抑郁与焦虑与（在贪食与暴食中的）物质的使用与自伤与（在若干病例中的）冲动的问题；而人格的特质（在完美主义与（在僵化的）与（在关系中的））不稳定的会预测治疗的脱落。生物学与遗传的说明要向患者交代清楚：进食障碍的遗传度在中到高的范围，它不是父母的教养方式的产物，也不是青春期的 虚荣；这一句在治疗性会谈中常常是家属听到的最重要的话。诊断要记录的东西有具体的清单：体重与（在身高的百分位与（在下降的速率上的））曲线与（在闭经上的）月经与（在补偿行为上的）每周的次数与（在既往的）住院与（在自伤上的）风险与（在口腔与食管与（在骨上的））身体的损害与（在家庭中的）当前的压力。最后一条是治疗的门：门诊的认知行为的治疗（在贪食与暴食中最有证据）与家庭的基于证据的治疗（在青少年厌食中是首选的路径之一）与（在低位体重或（在失代偿时的））营养的康复与（在需要时的）医学的住院；“先增重再谈治疗”是一个假的选择，因为两件事必须同时发生——[[psychiatry/mood-disorders]]、[[psychiatry/anxiety-disorders]]、[[paediatrics/growth-development]]、[[gastrointestinal/oesophagus-stomach]]。**
:::

## 医学的危险与再喂养

::: definition 医学的并发症与再喂养 {#def-refeeding}
**厌食的身体是长期饥饿的身体，其并发症可以突然出现：心率过缓（在运动员中可以是生理的，在这里则是代谢率下降的表现，若低于五十次每分或伴QT的延长需要收住院）、体温过低与低血压与直立性的改变、白细胞与血小板的轻度下降（在骨髓的浆液性的萎缩中的）、以及（在重者中的）肝的转氨酶的升高（在自噬中的）。电解质中最要注意的是钾：呕吐与（在滥用中的）泻药与利尿剂会造成低钾与代谢性的碱中毒（在呕吐）或酸中毒（在泻药），而低钾与QT的延长与（在若干药物中的）尖端扭转的风险叠加。骨骼的损害在青少年最重：在骨峰值形成的年龄失去雌激素与（在若干病例中的）睾酮与胰岛素样的生长因子，会造成不完全可逆的骨密度的下降，因此“月经何时恢复”是一个真实的预后指标，而双能X 线的骨密度与（在若干方案中的）营养的康复与（在持续闭经者中的）经皮的雌二醇（注意结合的雌激素在肝的首过效应下会进一步压低胰岛素样的生长因子）是需要讨论的。再喂养综合征是本章最可预防的死亡原因：长期饥饿的细胞靠磷的储备与（在糖解中的）辅酶的依赖维持，一旦给糖与胰岛素，磷随钾与镁一起进入细胞，血磷可以在两到三日内跌至危险的低位，其后果是呼吸的肌无力与心室的衰竭与（在重者中的）溶血与抽搐与死亡。因此再喂养的规则是可写的：起始前先查磷与钾与镁与钠与（在若干体系中的）硫胺与（在低磷时先补再喂）、给量从低于需求的水平起并按耐受逐日加、在第一周加密的电解质与（在症状时的）心电的监测、液体的钠的负荷不要过量（在再喂养的水肿与（在若干病例中的）心衰的风险中）、以及在加量的同时给硫胺与（在需要时的）多种维生素。速度上，“快增重”在门诊的若干研究中并不比慢的更安全或更危险，但在低位体重（在体重指数的十至十二以下）与（在心脏的储备差时的）需要谨慎；关键不是数字而是监测是否配套。心脏的骤停也发生在（在单纯催吐者的）低钾与（在若干药物中的）QT的延长上，所以任何“催吐后乏力”都需要一次心电与电解质而不是安慰。
一个容易被忽略的并发症是牙齿与食管：反复的催吐使胃的酸接触牙的舌面，造成不可逆的釉质的溶解（在若干患者中这是最早被牙医发现的信号），以及（在剧烈的呕吐后的）Mallory-Weiss 的撕裂与（在极少数中的）食管的破裂；同时唾液腺的肿大与（在若干病例中的）手的肿胀（在水肿的再喂养中）会让患者自己害怕，需要提前解释。精神科住院的医学门槛要写清（在本地的路径中）：体重的百分比与心率与血压与体温与（在 QTc 上的）与（在钾上的）与（在意识上的）与（在自杀风险上的）与（在家庭中的）照护是否已失效；低于阈值者按门诊的密集的（在若干体系中的）日间的项目走，因为住院本身对长期的病程的改善有限，而其（在非医疗的）环境的代价（在脱离与（在污名的）与（在失去的学习与工作上的））是真实的（[[gastrointestinal/clinical-nutrition]]、[[cardiovascular/arrhythmias]]、[[endocrine/reproductive-endocrinology]]、[[renal/potassium-calcium-phosphate]]）。**
:::

## 人格障碍与作为工具的自己

::: definition 人格障碍尤其边缘型 {#def-personality}
**人格障碍是“在多个领域上持续、僵硬、并在压力时失代偿的内在经验与行为的方式”，其诊断不是终身诅咒而是一个描述：多数人在数年内明显改善，边缘型尤甚；把它当作“治不好的病”是过去三十年最有害的误解。边缘型的实质是对被抛弃的极度敏感与（在其上的）情绪的调节的困难：情绪的基线起伏大、恢复慢，因而行为的“过激”常常是可理解的应对（自伤与（在若干病例中的）物质的使用与（在关系中的）激烈的争吵）而不是操纵；共病的轴包括（在解离上的）与（在短暂的应激相关的精神病性的症状上的）与（在自我感的持续的不稳定上的）与（在慢性的空虚感上的）与（在冲动上的）。诊断需要与（在双相中的）情绪的周期区分：边缘型的情绪反应是外向的、以小时计的、并总在关系的场景中发生；而双相的发作是内源性的、以日周计的、并带着睡眠与精力与（在若干病例中的）夸大的持续改变；把两者分开会改变用药（在边缘型中心境稳定剂与抗精神病药只能针对特定的靶症状，而不是“稳定情绪”这个空的目标）。治疗的核心是专门的、有手册的、有督导的心理治疗：辩证的（在技能上的：痛苦耐受与情绪的调节与正念与人际的效率，并配合个体的会谈与电话的支持，被证明能减少自伤与住院）；基于心智化的；图式的治疗；以及（在若干体系中的）在专科门诊内的阶梯式安排。抗抑郁药不改变人格的结构，它们治疗共病（抑郁与焦虑与（在若干病例中的）冲动的症状）；苯二氮通常有害（在解离与脱抑制的风险中）；阿片类与（在若干体系中的）镇静类的处方本身就是风险。
而治疗者的自己就是工具：移情与反移情是数据（在边缘型的关系模式中，治疗者常被拉入“要么全能要么无能”的位置），因此督导与个案的讨论不是奢侈品而是安全的设备；界限（会谈的时间与（在两次之间的）可及的规则与（在危机时的）路径）是治疗的内容而不是行政的约束，被清晰执行的界限本身就是新的经验——不是“世界会抛弃我”，而是“约定可以被守住”。风险管理的现实：慢性的自伤不等于即时的自杀风险，但历史与（在最近的）升级与（在手段上的）致命性与（在年老男性中的）完成的比率，都要被同时评估；危机计划的要点是“具体的行动、具体的名字、具体的时间”。最后：不要把人格障碍当作拒绝给服务的理由，也不要把所有复杂的人归入它；反污名的最好证据是团队自己的排班表——是否给这些人安排了足够的会谈时间（[[psychiatry/mood-disorders]]、[[psychiatry/self-harm-suicide-prevention]]、[[clinical-skills/communication]]、[[psychiatry/treatments-mental-health-law]]）。**
:::

::: example 校医的转介 {#ex-school-referral}
一名13岁的女生在校医处称“最近跑两步就晕”；体重从52降到44公斤；她每天早起跑步，早餐“不吃，我在尝试轻断食”；家长说“她一直这样，学习很拼”；校医转介时问“要不要直接送急诊”。
::: solution
**这是一次需要当天完成的医学评估，而不是排期两周的门诊（[[#def-refeeding]]、[[#def-eating]]）。第一步是把体重放在发育的曲线上看：青少年“减了八公斤”可能意味着体重指数的两个点的下降与（在生长中的）预期体重的偏离，其严重度高于同样的数字在成人；先测卧立位的心率与血压与体温与（在指尖的）血糖，做一个心电（在QTc 与（在过缓上的）），并查钾与钠与磷与镁与（在碳酸氢根上的）与肾的功能与白蛋白与（在若干体系中的）淀粉酶与（在闭经史时的）甲与（在月经史时的）妊娠。第二步是判断收住院还是门诊：本地的门槛通常看体重的百分比与心率与体温与（在 QTc 上的）与（在钾上的）与（在晕厥上的）与（在家庭是否能承担喂养上的）；她的晕厥与（可能的）过缓与（在十个月内）八公斤的下降已经在边缘，多数团队会给她一个短期内（数日而非数周）的密集评估而不是等待。第三步是与她与家长各自谈：对她不要用“你需要吃”开始，而要用她能认同的目标（不晕与可以跑步与（在皮肤与头发上的）与（在学习的注意力上的）），并明确医学的安全底线不是可以谈判的；对家长要给出可以执行的具体分工（每餐的结构与（在餐后时的）陪伴与不要在桌上争论食物与热量与把运动暂时暂停的决定由医生承担，这一条能显著减轻家庭的冲突）。要说清的诊断：她的表现符合限制型的进食障碍（在轻断食与（在运动的强迫性上的）），而“学习很拼”的完美主义是预后的一个可干预的靶点；青少年的厌食首选以家庭为基础的治疗（父母的餐食的重建的角色与（在若干方案中的）单独的个体治疗），而“让她自己决定”在低位体重时不是尊重自主而是放弃责任。最后要交代的是长期的过程：体重恢复先于心理的恢复，而复发常在开学与考试与（在假期后的）时点发生，因此复诊要按学期安排而不是按“好了再来”——[[paediatrics/growth-development]]、[[cardiovascular/arrhythmias]]、[[clinical-skills/communication]]、[[gastrointestinal/clinical-nutrition]]。**

::: example 反复回来的自伤 {#ex-bpd-spiral}
一名24岁的女性在一年内因前臂的切割伤就诊急诊七次；每次都在“被分手或被解雇”之后的数小时内；她诊断为边缘型人格障碍，服四种药；她的病历第一行写着“别收她，她是寻求注意的”。
::: solution
**先改掉那行字（[[#def-personality]]、[[psychiatry/self-harm-suicide-prevention]]）。“寻求注意”是描述一个未被满足的需要，不是拒绝对她的照护的理由；把这样的句子留在病历里会造成两类伤害：下一次她在急诊被跳过，以及她学会用更重的方式求助。评估要具体：伤的深度与部位与（在神经与肌腱上的）损伤与是否曾伤及要害与最近的升级与（在酒精与（在物质上的））与（在自杀的意念上的）与计划的可行与（在她所重视的东西上的）（工作与孩子与宠物与（在宗教上的）），慢性的自伤与急性的自杀风险要同时评。治疗的路径是专门的、有手册的心理治疗（在辩证的行为治疗中的技能组与（在若干体系中的）电话的支持，能减少自伤与住院），而不是加药；她的四种药要逐一问“治哪个靶症状、有没有效、要不要减”（在边缘型中抗抑郁药不改变结构，苯二氮常有害，而多药联用常成为新的问题）。医疗的次序：每次就诊要有伤口的处理与（在破伤风与（在感染上的））与一次认真的（但不是审讯式的）的评估与一个明确的下一步（当天可以找谁与下一次的预约与（在危机时的）路径）；不要在没有替代的情况下只是“劝她回家”。给她一份她自己写的危机计划：从最早的信号（在几小时内会发生什么）到她已经用过且有效的措施（冷水的刺激与（在剧烈运动上的）与（在信任的人上的）打电话）到明确不能做什么（不与某人独处与不接触某种药物）与谁陪同去急诊；把这张纸放在她可及的地方并录入本地的电子记录。对团队要做的一件事：把她从“每次不同的医师”变成“一个负责的团队与固定的时间”，因为可预测是她最需要而最少被给到的东西；同时给治疗者安排督导（在反移情的愤怒上），否则换人会成为默认的处方。要如实记录她的进步（在间隔的延长与（在方法的改变上的））：这些信息会改变下一个见到她的人的态度——[[psychiatry/treatments-mental-health-law]]、[[clinical-skills/communication]]、[[clinical-skills/records-handover]]、[[psychiatry/mood-disorders]]。**

::: example 闭经的运动员 {#ex-female-athlete}
一名21岁的中长跑学生，体脂低，近十四个月未来月经；她的骨盆在六个月内出现两次应力性骨折；她说“跑步是我唯一的成绩”；队医给她开了口服的避孕药“调经”。
::: solution
**这是相对能量缺乏的综合征，而不是“运动员的三联症”这个旧名字下的一件事（[[#def-eating]]、[[#def-refeeding]]、[[endocrine/reproductive-endocrinology]]）。机制是能量可用性的不足压下了下丘脑的促性腺激素的脉冲，造成低雌激素的状态：它的代价是骨（在应力性骨折与（在骨密度的下降上的））与内分泌（在月经与（在若干病例中的））与（在激素的轴上的）与（在若干中的）心血管与（在女性运动员中的）月经的紊乱常常是第一个信号。两次应力性骨折加闭经加上低能量可用，已经足以诊断，不需要“她是不是厌食”这个问题作为前提：多数这类患者不符合进食障碍的完整标准，但治疗的逻辑相同——把能量的缺口补上。队医给的口服避孕药是本章最常见的错误之一：它能造成撤退出血与让人误以为“月经恢复了”，却不能修复低能量造成的骨丢失，因为它绕过了下丘脑而没有恢复内源的雌激素的脉冲与（在若干通路上的）骨的健康。真正的处方是三件事（同时、由同一个人协调）：减少消耗（训练的量的调整，需要教练在场一起谈）、增加摄入（在营养师下的结构性的能量与碳水与蛋白与钙与维生素D 的安排，并把“为了跑得好而吃”作为框架）、以及（在持续闭经者中的）经皮的雌二醇加环状的黄体酮作为骨的保护（而不是避孕药），并同时监测（在恢复的月经上的）与（在若干体系中的）骨密度与（在应力性骨折后的）回归运动的时间。与她的谈话要从她的目标进入：骨的健康是“能继续跑”的前提，而“我唯一的成绩”这一句既是她的资源（她的纪律可以被用于恢复）也是风险（身份的完全被运动占据会让受伤成为危机），因此要讨论第二身份与（在受伤或停训时的）情绪的备用；也要筛查（在低能量与（在若干人群中的））追求成绩下的催吐与（在补剂上的）滥用的物质与（在队伍文化中的）体重与体形的压力（教练的语言往往是干预的对象，而不是旁观者）。最后，她的骨的时间是不可逆的一部分：骨峰值的窗口在二十几岁之前，因此“再等一年看看”不是中性的选择（[[paediatrics/growth-development]]、[[endocrine/bone-calcium]]、[[musculoskeletal/fractures]]、[[gastrointestinal/clinical-nutrition]]）。**

::: example 两个门诊的重叠 {#ex-diabulimia}
一名19岁的一型糖尿病的女性，最近三次糖化的血红蛋白在95以上；她承认“有时候少打一点胰岛素，因为那样不会胖”；她有反复的泌尿生殖的感染与一次（在酮症酸中毒后的）住院。
::: solution
**“为了控制体重而减少胰岛素”在内分泌门诊里被叫作一个轻描淡写的名字，而它同时是进食障碍的行为与（在医学上的）危险（[[#def-eating]]、[[#def-refeeding]]、[[endocrine/diabetes]]）。它的机制要说清：胰岛素不足使葡萄糖被排出而不能利用，结果是热量的丢失与（在若干病例中的）体重下降，同时酮体升高，因此她承受的是反复的酮症酸中毒与感染与（在长期中的）微血管的并发症加速（在视网膜与肾与神经上的）——她的三次高值与反复的感染与一次住院已经不是“依从性差”。处理必须两个服务一起做，且不能彼此等待。医学的一层：把糖化的血红蛋白作为“风险”而不是“成绩”来谈（避免任何羞辱的语言，因为它会直接把行为推向隐藏）、把胰岛素方案简化到她真的能执行的形式（在若干病例中泵的与（在持续葡萄糖的监测下的））与（在若干方案中的）把剂量与实际进食量匹配的（在她同意下的）策略（注意：这不是“为了体重而调低”，而是把剂量与餐食对齐，并让护士与营养师可见）与（在酮症上的）安全网（在病中的规则与酮的试纸与一个可以打电话的号码）。进食的一层：按暴食与（在控制上的）动机评估，认知行为的治疗（在贪食的路径上）与（在低体重者中的）营养的康复与（在体形的痛苦上的）工作；不要用“你必须好好打胰岛素”作为治疗的目标句，因为它把心理的问题变成了一个服从的问题。共同的一层：一份两个门诊都能看到的计划（复诊的节奏与（在酮症酸中毒后的））住院时的精神科的联络与（在她愿意时的）家属的参与（在开车 与（在高血糖时的）操作机器上的）安全；以及明确的记录（把减少胰岛素的意图写进病历的方式要既清楚又不带评判，因为它会让下一个医师理解而不是责怪）。要告诉她的实话：年轻女性的一型糖尿病在“少打胰岛素”这一行为下的长期后果（在视网膜与（在肾的替代治疗上的）是真实且可以部分避免的，而她现在做这件事的原因（在体重与（在青春期的身体上的））也是真实的、可以被治疗的；两件事同时成立，所以两个门诊都要见到她。同时筛查抑郁与（在的））——[[endocrine/diabetes-complications]]、[[psychiatry/mood-disorders]]、[[clinical-skills/communication]]、[[gastrointestinal/clinical-nutrition]]。**

## 通向何处

进食障碍的诊断与风险的评估见[[psychiatry/psychiatric-assessment]]；情绪的与共病的治疗见[[psychiatry/mood-disorders]]与[[psychiatry/anxiety-disorders]]；自伤与自杀的风险见[[psychiatry/self-harm-suicide-prevention]]；营养与再喂养的医学见[[gastrointestinal/clinical-nutrition]]；内分泌与骨见[[endocrine/reproductive-endocrinology]]与[[endocrine/bone-calcium]]；治疗的组织与法律的边界见[[psychiatry/treatments-mental-health-law]]；儿童与青少年的服务见[[paediatrics/growth-development]]。

::: history
**进食障碍的历史同时是医学对“自愿的饥饿”的解释史。最早的清晰描述来自1689年 Morton 的“神经性的消耗”与1873至1874年 Gull 与 Lasègue 分别命名的“厌食症”（在 Gull 的笔下它是“对进食的厌恶”与一种“精神的、自我中心的、介于正常与疯狂之间的”状态；他反对当时流行的宗教解释，也反对用强制喂食）。二十世纪初的争论把它的重心移向内分泌与下丘脑（Simmonds 与 Fröhlich 的综合征的类比与（在若干病例中的）垂体的改变），而1930至1950年代的精神分析的解释（在家庭与（在母女关系上的））与（在性心理的发展上的）虽然留下了“冰箱母亲”式伤害，却也使它被承认为一种需要心理治疗而不是单纯喂食的疾病；1960至1970年代女性的身体意象与（在文化中的）理想体重的研究把它放回社会与个体的交汇处。诊断标准的演化值得记取：1980年的手册第一次列出神经性厌食与贪食（后者由 Crisp 与（在1979年的）Russell 等人争取进来，Russell 在描述“贪食症”这一综合征时特别指出它可以在正常体重者身上发生），此后每一版都在体重阈值与（在月经的必要性上的）与（在体形自我评价上的）与（在暴食的定义上的）之间摇摆，并在2013年删去了闭经这一条、纳入了暴食障碍、并把“显著低的体重”改为相对性标准——每一次改动都改变了谁被算作患者与谁能拿到资源。再喂养综合征的认识更晚：它作为临床现象在战俘与（在集中营解放后的）幸存者中被记录（1940年代的“再喂养的水肿”与（在若干病例中的）死亡），却在很长时间内被当作个案；直到1990年代对磷的代谢的机制的阐明与（在若干综述中的）病例的汇编，它才成为写进指南的预防项目——这是一个“外科与营养科的常识如何花了五十年才变成常规”的例证。人格障碍的历史同样曲折：Kraepelin 与 Schneider 把“病态人格”写进了分类，精神分析把它变成一种（在治疗的等级上的）低等的诊断（在1950至1970年代的美国，“人格障碍”常被用作拒绝治疗的理由），而 Linehan 在1970至1980年代从自己的临床失败出发（她治疗自杀的年轻女性的经验）建立了辩证的行为治疗，并在1991年的第一个随机试验中显示它能减少自伤的行为——这是本专科第一次以证据而非德性谈论边缘型，也启动了随后二十年的“心智化”与“图式”的路径与（在2000年代以后的）关于诊断去污名化（把“人格障碍”改为“复杂性创伤的应对”之类的提议）的持续讨论；英国国家卫生与临床优化研究所2009年的指南第一次明确说：不要因为它而拒绝服务。本章最后要留下的历史教训是：这两个诊断群都被“道德的语言”（在意志与（在自控上的））与（在 操控性上的）操纵上的长期统治，而每一次进展都发生在把道德换成机制与可测量的结局时——[[psychiatry/psychiatric-assessment]]、[[psychiatry/self-harm-suicide-prevention]]、[[gastrointestinal/clinical-nutrition]]、[[medical-ethics-law/ethical-principles]]。**
:::
::: summary
- 进食障碍的四个主要综合征按“行为与自我评价的支配”区分，而不是按体重；正常体重不等于低风险。
- 厌食的医学危险按时间可预期：过缓与低体温与（在再喂养中的）低磷，两者都需要客观的收住院的门槛而不是印象。
- 再喂养的法则可以写在一张卡片上：先查磷钾镁、从低于需求起、逐日加量、加密监测、给硫胺。
- 口服避孕药不能保护骨：低能量造成的骨丢失要靠恢复能量与（在持续闭经者中的）经皮的雌激素。
- 边缘型的实质是情绪的调节的困难与被抛弃的敏感，其治疗是有手册的心理治疗与清晰的界限，而不是越来越多的药。
- 缓解不等于痊愈：体重的恢复先于心理的恢复，持续的随访降低复发，因此不要以“好了”结束照护。
:::

::: exercise 读化验单 {level=1}
一名催吐为主的患者：钾3.0、钠138、氯96、碳酸氢根32、肌酐88、磷0.9、镁0.72。请解读并给出处置。
::: solution
**这是一张呕吐的化验单（[[#def-refeeding]]、[[renal/potassium-calcium-phosphate]]）。低钾伴低氯与代谢性的碱中毒（在氢离子与氯的丢失后的）是自我催吐的典型图形；磷在正常低限提示她的能量摄入不足（尚未再喂养），镁的正常低限意味着钾很难被补上去（在镁未纠正时钾的保留受损）。处置的顺序：先补镁再补钾（口服与静脉按严重度），因为单补钾常无效；查心电（在QTc 与（在U 波上的）），低钾加QT的延长会构成尖端扭转的风险，此时避免任何延长QT的药（在若干的止吐与抗精神病与抗生素中）；口服的钾在需要时可以给（在若干体系中的）每天若干毫摩尔，并按重复制查；纠正碱中毒的关键是氯与容量（在生理盐水后肾会保留钾的机制要向她解释，否则她会把输液当作“营养”）。磷要在开始加量进食之前复查，因为再喂养会把它推得更低。还要想到假象：利尿剂的滥用会给出相似的图形（在碱中毒上），而泻药的滥用更常造成代谢性的酸中毒与（在尿的钾上的）不同；若图形与病史不合，加做尿的钾与（在可疑时的）利尿剂的筛查，并（在怀疑肾上腺的异常时的）测肾素的水平（在呕吐者中肾素常升高）。最后是与她谈：这张单不是“抓到你把证据”，而是解释为什么她的乏力与心悸是真实的、可测量的、并且可以在数日内改善——把化验变成同盟而不是控诉，是这类患者愿意继续随访的原因（[[clinical-skills/laboratory-tests]]、[[clinical-skills/communication]]、[[endocrine/diabetes]]）。**

::: exercise 牙科与医学美容的信号 {level=2}
一名牙科医师报告一名31岁女性的下前牙舌面的釉质溶解与频繁的唾液腺的肿大；她本人否认“有问题”，说她“只是容易反胃”；她的全科记录里两年内开过三次抗酸药。
::: solution
**牙的舌面的酸蚀是反复呕吐的高度提示，配合唾液腺的肿大（在鼓腮时的）与（在若干病例中的）手的背侧的瘢痕（在Russell 征：牙齿的擦伤）与（在反复的）反胃与抗酸药的处方，这一组的组合足以启动一次进食障碍的评估，而不需要等到她承认（[[#def-eating]]、[[#def-refeeding]]）。谈话的技术比知识更关键：不要在门诊里对质“你在催吐”，而是描述加邀请（“我看到的是牙的里侧被酸泡过，这种情况我见过两种原因，一种是胃的反流，一种是让自己吐；我想听听你觉得像哪一种”）；给她不承认的权利，同时说明你会怎么处理（在牙科的保护与（在氟与（在修复上的））与在她同意下的复查）。要评估的：体重的曲线与（在波动上的）与饮食的规则与（在每周的次数上的）补偿与（在泻药与利尿剂上的）滥用与（在口腔的疼痛与（在进食时的）尴尬上的）功能的损害与（在自伤与（在酒精上的））与（在抑郁上的）共病；查钾与碳酸氢根与（在淀粉酶上的）与（在若干病例中的）甲（在亢进时的）（她说的“容易反胃”也可能是别的）。干预：牙科的保护（在含氟的制剂与（在夜间的）套与修复的时机——不要在仍在呕吐时做昂贵的永久修复）、把治疗的目标定为“减少次数”而不是“立刻停止”（催吐常常是她处理情绪的方式，替代需要先建立）、认知行为取向的治疗（在贪食的路径上有最好的证据）、以及在（在低体重时的）营养的康复。也要处理误读：抗酸药的处方是她被漏掉的两次机会；把“牙的酸蚀=要问一句”作为诊室常规写进本地的清单，可以让下一次不必靠牙科的转介信——[[gastrointestinal/oesophagus-stomach]]、[[psychiatry/mood-disorders]]、[[clinical-skills/communication]]、[[psychiatry/psychiatric-assessment]]。**

::: exercise 卡住的家庭 {level=2}
一名16岁的厌食患者的父母每餐都盯着她吃饭，家里因为食物每天争吵四次；她说“他们逼我我就更不吃”；家庭治疗排不上队。请给出你可以做的三件事。
::: solution
**目标是把“吃饭”从夫妻与亲子战场变成一件可以完成的任务（[[#def-eating]]、[[#def-personality]]）。第一件：把喂养的责任交给结构而不是情绪（固定的三餐加两到三次点心的时间、每餐二十至三十分钟、餐后一次固定的点心、父母在同一时间做同一件事、不在餐桌上讨论体重与热量与体形、饭后不“检查”），并把这一套写成纸，父母与孩子各一份；在青少年的厌食中，让父母在餐食上重新掌握责任是有证据的路径（在家庭为基础的治疗中），关键不是说理而是把“什么时候吃”确定下来，使冲突可以提前发生而不在餐盘前发生。第二件：教父母一句可以重复的话（“这一餐是我们家的规矩，你可以生气，我们不用谈”），并明确禁止三种反应（谈判、惩罚、恳求），因为这三种都会被学习到“再坚持一会儿就会有转机”。第三件：给她一个不属于食物的位置（她在这段治疗中想要的东西：能上学与不再怕体重秤与被允许继续跑，把它写成治疗目标，并为每个目标配一个可以做的小步）。同时要筛查父母自己的抑郁与焦虑与（在婚姻上的）耗竭，并给他们一次不带孩子的会谈，因为“卡住的家庭”常常是疲惫而不是抗拒；并说明复发是可以预期的事件而不是失败（在开学与考试与假期结束时最容易），预先写好那时的三步。若家庭治疗排不上：用可用的替代（父母的小组与（在若干体系中的）网络的项目与由护士与营养师承担的六次结构化的会谈）并在病历里记录“已提出而不可得”，这既保护他们也推动服务的改变（[[paediatrics/growth-development]]、[[clinical-skills/communication]]、[[psychiatry/treatments-mental-health-law]]）。**

::: exercise 纠正你所在服务的污名 {level=3}
你的成人门诊里，被标注“人格障碍”的患者被系统性地放在最后叫号、危机时被告知“这不是危机”、且平均门诊时间比他人短。请设计一项改变并说明如何证明它有效。
::: solution
**先把事实变成数字（[[#def-personality]]、[[clinical-skills/patient-safety]]、[[public-health/determinants-inequalities]]）。审计三件事：按诊断标签的失约与取消与未完成的比率、危机接触后四十八小时内的被看到率、以及（在自伤者中的）住院与（在急诊的）停留与（在约束上的）使用的分层。然后做四项干预。语言：把“寻求注意”与“操控性的”与“人格障碍患者”从文书中撤出，规定病历写行为与语境（“在被告知不能提前取药后用手臂划伤，随后主动找护士”），并对新来的人员做半天的培训（在病历语言与（在诊断的意义上）），因为文书是最容易被复制的污名。可及：设立“复杂的情绪调节”的开放通道（每周两次的可自我转介的短时面谈与（在危机时的）同一团队的电话），取消“必须先停止自伤才能进入项目”的条件（这条排除规则是自我矛盾的：治疗的内容就是自伤），并把“两次爽约即结案”改为“两次爽约后主动再联系”。能力：保证心理治疗的时间与督导（每周的个案讨论与（在反移情的处理上的）），因为没有人会在被要求“更有耐心”时变得更有能力；同时把每次会谈的时间与普通人一致或更长，而不是更短。政策：在服务的目标里写入“这一群体的一年内的被看到率与自伤的减少与（在急诊的）使用的减少”，并按族群与性别与年龄分层看（边缘型的诊断在不同人群中分布并不相同，把它当作纯生物学的诊断会掩盖服务如何分配）。评价的指标（在十二个月内）：被拒绝的比率与首次接触的等待天数与爽约后被再联系的比率与（在自伤上的）急诊的就诊与（在门诊时间内被完成的）治疗次数与（在患者体验调查中的）“我觉得被尊重”的比例与人员的态度量表（同一份问卷前后各做一次）。同时准备一个反直觉的结果并公开它：若干指标可能变差（更多的接触带来更早期的自伤的暴露），因此要以“严重度与住院与自伤的致命性”为主要终点而不是次数——[[psychiatry/self-harm-suicide-prevention]]、[[clinical-skills/records-handover]]、[[medical-ethics-law/ethical-principles]]。**

::: exercise 评估一次心动过缓 {level=1}
一名17岁的女性，体重指数13.4，心率46次每分，晨起时头晕；她的父母要求“先在家吃两周看看”。请说明你的判断与理由。
::: solution
**她的过缓加上头晕与体重指数的低位，已经达到多数本地路径的住院或至少当日密集评估的门槛（[[#def-refeeding]]）。要点有四：过缓在饥饿状态是代谢率下降的适应，但适应到一定程度就是失代偿的前兆，尤其在住院的第一周（在再喂养的心脏的负荷下）；晕或头晕说明心输出量已影响到脑的灌注，需要心电（在QTc 上）与（在卧立位的）血压与体温与（在钾与磷与镁上的）与（在血糖上的）；“在家先吃两周”的风险不是“没治好”，而是在低磷与（在低钾上的）心律的失常之间没有监测；而家庭喂养在低位体重时常常失败，反而加重冲突，因此应当被解释为“我们需要先让她的身体可以承受门诊的治疗”。与父母谈的要点：不是我们不相信你们，而是这个阶段的治疗需要医学的监测；并给一个明确的、有限的（在住院的时长上的）说明与出院后的接应（谁在出院后四十八小时内联系），因为“住进去就找不到人”是这类家庭最害怕的事。同时要说明住院不能治好厌食，它的目标是安全的体重恢复与（在治疗联盟上的）重新开始——[[paediatrics/growth-development]]、[[cardiovascular/arrhythmias]]、[[clinical-skills/communication]]、[[psychiatry/treatments-mental-health-law]]。**

::: exercise 把诊断分开 {level=2}
一名29岁的女性在三个月中情绪剧烈波动：与伴侣争吵后整夜不睡、次日“感觉很好”、第三周又整日卧床并称“我没用”；她在门诊承认在体重正常时也曾连续数日只喝可乐。请给出鉴别与下一步。
::: solution
**要分开的是边缘型的情绪的不稳定与双相的发作与进食障碍与（在若干中的）物质的影响（[[#def-personality]]、[[#def-eating]]、[[psychiatry/mood-disorders]]）。支持边缘型的线索：情绪的转换由关系的事件触发、以小时计、并伴自伤与（在被抛弃的恐惧上的）与自我感的不稳定；支持双相的线索是：持续的（在数日以上的）精力与睡眠需要的减少与（在若干病例中的）夸大与（在言语与（在性兴趣上的））的增加与在情绪好时的功能改善（而不是关系崩坏）——她“整夜不睡后感觉很好”这一条要追问是连续几天与是否伴活动的增多与消费与（在性冒险上的）与（在家族的史上的）。两者可以共存，共病率不低，所以治疗要按当前占主导的目标排：若她当前的风险是自伤与（在被分手时的）失控，那么专门的心理治疗是主线；若确认有双相的发作，则需心境稳定剂并在（在若干病例中的）心理治疗配合下调整。用药上要避免的是：用加药来代替对人格的治疗（在边缘型中药物只能针对靶症状）与用“人格障碍”来排除双相的诊断（这会让她失去一个可治疗的诊断）。下一步：让她记录两到四周的情绪与睡眠与（在关系事件上的）的日记（或按本地的量表）+（在家族的史上的）的采集 +（在物质与（在甲状腺上的））的排查 + 一次关于进食的独立评估（她“只喝可乐”的数日在体重正常者仍可能造成低磷与低钾）；并把结论与不确定性都告诉她（“我们现在看到的是A，B还没被排除，所以我们这样安排”）——[[psychiatry/psychiatric-assessment]]、[[psychiatry/mood-disorders]]、[[clinical-skills/communication]]。**

::: exercise 写一份真正有用的危机计划 {level=2}
一名有边缘型特质与反复自伤的患者同意写危机计划；她以前写过的计划“从来用不上”。请写出这一份的条目与写法。
::: solution
**有用的计划短、具体、由她写、并且在她平静时完成（[[#def-personality]]、[[psychiatry/self-harm-suicide-prevention]]）。六个条目：一，最早可被认出的信号（不是“我很崩溃”而是可观察的：不回消息与整夜不睡与开始翻看旧的照片与把腕带摘掉），越具体越有用。二，按次序的应对（从最轻的开始：冷水与（在剧烈运动上的）与离开现场与（在某个具体的电话上的）与（在她自己的技能清单上的）三步），并注明“哪一件在过去真的有用过”，因为这比理论上的方法更能被执行。三，可以联系的人与顺序（三个名字与电话与“什么时候可以打给母亲而什么时候不要”）。四，服务的路径（门诊的时间与（在门诊外的）电话号码与谁接与（在需要时的）急诊的地址与要带什么），并写清“如果我觉得会伤害自己，我会去这里”。五，要移走或交托的东西（药物与（在刀刃上的））与（在的）；六，她希望别人怎么对待她（“不要对我说你不该这样”与“请陪我坐十分钟”），这一条常被跳过，但它决定她下次是否求助。写法上：不超过一页、用她的词、手写也可以、复印三份（她与（在她指定的）一个人与电子病历）；把“计划本身”设为主题在下一次会谈复评（是否用过与哪一条失效与需要改哪一行）。不要用“不许伤害自己的合约”：它不具保护力，还会让她在自伤后因违约而隐藏。最后：把这份计划录进可被急诊与危机团队调阅的记录，否则她在最需要时它不在任何人的手里——[[clinical-skills/communication]]、[[clinical-skills/records-handover]]、[[psychiatry/treatments-mental-health-law]]。**

::: exercise 设定一项服务的标准 {level=3}
请为你的区域为进食障碍与人格障碍危机分别设定服务标准，并说明标准之间会怎样彼此消耗。
::: solution
**标准要写成“谁在多长时间内被谁看到”，并配套的资源（[[#def-eating]]、[[#def-personality]]、[[public-health/health-systems-economics]]）。进食障碍：所有新转介在两周内完成包含医学风险筛查的首评（在心率与血压与体温与体重曲线与钾磷镁与心电上）；达到医学门槛者在当日被内科或儿科接管，精神科在四十八小时内会诊；未达门槛者在四周内开始规范的心理治疗，青少年的以家庭为基础的治疗在八周内可及；住院有明确的人口学门槛与（在体重恢复之后的）随访（在出院后一周与（在第一年中的））每月的复评，并把“出院后三十天内的再入院”作为质量指标。人格障碍与反复自伤：危机时的接触在四小时内由本团队完成（不是“去急诊”的转介）；两周内的被看到率作为公开的指标；取消“必须先停止自伤”的准入条件；保证心理治疗的容量（辩证的行为治疗的课程每年开班若干次并公布等待），同时把药物开处的复核（在多药与（在苯二氮上的））设为季度审计。两条标准会彼此消耗的三个地方：急诊（进食障碍的医学不安全感与自伤的就诊都涌向同一批人，因此需要各自的快速通道与一个共用的医学评估区）、床位（内科的床被厌食占用与精神科的床被（在自伤后的）危机占用，而两者都可以被门诊的密集的路径替代，所以要投资于日间与（在若干体系中的）家庭的营养的康复）、以及人员（专门的治疗者的培训与保留是唯一的瓶颈，因此标准里必须包含培训的时间与督导的时间，否则只是把未受训的人员推到高风险的场合）。公平：按剥夺指数与族群与（在男性与（在五十岁以上者中的））分层看接触率，因为这两类病都被“典型人群”的想象排除（男性与（在少数族群中的））的进食障碍与（在老年人中的）自伤最常被漏，标准要写成“没有人因为不符合刻板印象而被漏掉”。最后：每年公开一次未达到的条目与原因，并把“为什么没做到”作为治理的议题而不是绩效的惩罚——那才是标准能长期存在的方式——[[psychiatry/treatments-mental-health-law]]、[[public-health/determinants-inequalities]]、[[clinical-skills/patient-safety]]。**
