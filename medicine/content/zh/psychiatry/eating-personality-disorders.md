本章介绍两类常被误解、有时还会遭到不耐烦对待的疾病。进食障碍看起来像是对食物的一种选择，但神经性厌食是所有精神障碍中死亡率最高的疾病之一。人格障碍看起来像是性格问题，但它们是长期存在的困难模式，会造成巨大的痛苦，并且在得到恰当帮助时会有所改善。

两者都要求医生将细致的躯体照护与稳定、尊重的关系结合起来。两者都会因污名而加重。本章前半部分介绍进食障碍及其医学风险；后半部分介绍人格障碍，重点是边缘型人格障碍。

## 进食障碍

::: definition 主要的进食障碍 {#def-eating}
- **神经性厌食**：相对于个人的身高、年龄和发育阶段，体重显著偏低（ICD-11 中成人 BMI 低于 18.5 kg/m²），且不能用其他疾病解释，同时存在持续的阻止体重恢复正常的行为模式（限制摄入、过度运动、清除行为），通常由对体重增加的强烈恐惧以及对体形或体重的超价关注所驱动。ICD-11 增加了**危险的低体重**这一标注（成人 BMI 低于 14 kg/m²）。
- **神经性贪食**：频繁、反复发作的**暴食**（在失控感下进食大量食物），随后反复采取**补偿行为**以防止体重增加（自我催吐、滥用泻药、禁食、过度运动），并过度关注体形或体重。体重通常在正常范围或以上。
- **暴食障碍**：反复暴食但无规律的补偿行为，引起明显痛苦。它是最常见的进食障碍，常与肥胖相关。
- **回避性/限制性摄食障碍**（ARFID）：导致体重下降、营养缺乏或功能受损的限制性进食，其驱动因素不是对体形或体重的关注，而是例如对食物的感官敏感、害怕噎住或呕吐，或对进食缺乏兴趣。
:::

进食障碍影响所有年龄、性别、族裔和体型的人。神经性厌食最常在青春期起病，在女孩和女性中诊断更多，但男孩和男性同样会患病，而且确诊更晚。少数族裔群体和体型较大者的进食障碍常因不符合刻板印象而被漏诊。

### 病因与维持因素

遗传因素起重要作用；双生子研究提示神经性厌食的遗传度为中到高。完美主义、焦虑和强迫等人格特质、不良生活事件以及追求瘦的文化压力都起一定作用。节食是常见的诱因。

一旦开始，饥饿本身就会帮助维持疾病。它会导致对食物的先占观念、刻板、情绪低落、社交退缩和思维迟缓，这些都使改变变得更难。在神经性贪食中会形成一个循环：严格节食导致饥饿和失控，然后是暴食，接着是羞耻和补偿行为，然后再次节食。

### 躯体影响

饥饿影响每一个器官系统，清除行为还会导致电解质紊乱。

| 系统 | 影响 |
|---|---|
| 心血管 | 心动过缓、低血压、体位性血压下降、心律失常、QT 间期延长、心肌质量减少 |
| 代谢 | 低血糖；清除行为时出现低钾血症和代谢性碱中毒；低磷血症和低镁血症 |
| 内分泌与骨骼 | 闭经、性激素水平低、青春期延迟、骨量减少和骨质疏松 |
| 血液 | 贫血、白细胞减少、血小板减少 |
| 胃肠道 | 胃排空延迟、便秘、肝酶升高；呕吐时出现牙齿腐蚀、腮腺肿大、食管撕裂 |
| 皮肤及其他 | 胎毛样毛发、皮肤干燥、催吐所致的指关节胼胝（Russell 征）、低体温、近端肌无力 |

即使病情严重，血液检查也可能正常，因此正常的结果绝不能排除危险。英国皇家精神科医学院的指南《进食障碍中的医学急症》（Medical Emergencies in Eating Disorders，MEED，2022 年）取代了早先的 MARSIPAN 指南，为成人和青少年制定了风险评估方法。它将多项指标（BMI 或中位数 BMI 百分比、体重下降速度、心率和血压、心电图、血液检查、体温、肌力和行为）分别评为红色、琥珀色或绿色。例如，成人 BMI 低于 13 kg/m² 被评为红色。多项琥珀色评级同时出现表明风险高。

### 儿童和青少年的 BMI

由于 BMI 在儿童期随年龄变化，因此要对照生长参考标准来解读。**中位数 BMI 百分比**（%mBMI）将青少年的 BMI 与同年龄、同性别的中位数 BMI 相比较：

$$
\%\text{mBMI} = \frac{\text{BMI}}{\text{同年龄同性别的中位数 BMI}} \times 100
$$ {#eq-mbmi}

%mBMI 低于约 70% 表明风险高。

::: example 来自学校的转介 {#ex-school-referral}
Chloe Patel，15 岁，由学校护士转介。她六个月来体重下降，月经停止，每天上学前跑步。她体重 41.5 kg，身高 1.65 m。假设她这个年龄女孩的中位数 BMI 为 20.0 kg/m²（示意值；实践中从英国生长参考标准中查得）。她卧位心率 44 次/分，立位 72 次/分。评估她的风险并概述处理。

::: solution
**BMI。**$41.5/1.65^2 = 41.5/2.7225 \approx 15.2$ kg/m²。

**%mBMI。**$15.2/20.0 \times 100 \approx 76\%$。这一数值偏低，但高于 70% 的高风险阈值。

**其他指标。**静息心率 44 次/分属于心动过缓，站立时心率上升 28 次/分是很大的体位性变化，提示心血管功能受损。闭经提示激素受抑制和骨骼风险。强迫性运动增加了风险。

**总体判断。**她很可能患有神经性厌食，并有多项令人担忧的躯体发现。她需要紧急进行心电图、血液检查（电解质、磷、镁、血糖、全血细胞计数、肝功能）、体温以及坐起/下蹲肌力测试，并在当天与儿科和进食障碍团队讨论，以决定是否需要内科住院。

**治疗。**对于儿童和青少年，NICE 推荐由社区进食障碍服务提供的**聚焦神经性厌食的家庭治疗**（FT-AN）作为一线心理治疗。她的父母在恢复营养中起核心作用。学校需要调整她的体育活动。
:::
:::

### 治疗

NICE 指南 NG69（2017 年，2020 年更新）推荐根据障碍类型和年龄量身定制的心理治疗：

- **成人神经性厌食**：个体聚焦进食障碍的 CBT（**CBT-ED**）、**Maudsley 成人神经性厌食治疗**（MANTRA）或**专科支持性临床管理**（SSCM）。儿童和青少年采用 FT-AN。
- **神经性贪食**：成人首先采用基于 CBT 的指导式自助，需要时再采用个体 CBT-ED；青少年采用聚焦神经性贪食的家庭治疗。
- **暴食障碍**：指导式自助，然后是团体或个体 CBT-ED。

药物不是神经性厌食的主要治疗。共存的抑郁、焦虑和强迫障碍很常见，应分别加以评估和治疗。恢复体重至关重要，因为神经性厌食的许多心理改变是饥饿的结果，会随营养改善而好转。

### 再喂养综合征

::: definition 再喂养综合征 {#def-refeeding}
**再喂养综合征**是在一段时间的饥饿后重新开始营养支持时可能发生的、可致命的液体和电解质转移。饥饿期间，机体利用脂肪和蛋白质供能，细胞内的磷、钾和镁被耗竭，尽管血清水平可能正常。当重新摄入碳水化合物时，胰岛素分泌将葡萄糖、磷、钾和镁驱入细胞。血清水平随之可能急剧下降，引起心律失常、心力衰竭、呼吸肌无力、意识混乱和癫痫发作。硫胺素缺乏也可能被暴露出来。
:::

预防依赖于识别高危人群、在再喂养前及期间定期测定电解质、补充硫胺素和其他维生素，以及根据需要补充磷、钾和镁。MEED 指南警告，**喂养不足**同样危险：过于谨慎地开始营养支持会延长饥饿、延缓恢复。因此，再喂养应在仔细监测和补充下进行，而不是采用极低的能量摄入。

::: example 糖尿病与体重下降 {#ex-diabulimia}
Hannah Brooks 女士，22 岁，患 1 型糖尿病。一年来她的 HbA1c 从 58 mmol/mol 升至 104 mmol/mol，两次因糖尿病酮症酸中毒住院，体重也有所下降。她的糖尿病专科护士发现她一直在漏用胰岛素。她承认自己极度害怕体重增加。应如何理解和处理？

::: solution
**理解。**为减轻体重而故意漏用胰岛素是一种补偿行为。没有胰岛素时，葡萄糖连同其热量从尿中丢失，因此体重下降。这种模式有时被称为“糖尿病贪食症”（diabulimia），并不是一个独立的诊断；它可能是神经性贪食等进食障碍或其他特定的进食障碍的一部分。

**风险。**它大大增加糖尿病酮症酸中毒、早发微血管并发症（视网膜病变、神经病变、肾病）和死亡的风险。

**处理。**由糖尿病团队和进食障碍服务共同照护。以同情的态度对待她，因为羞耻感很常见。避免迅速严格控制血糖，因为这可能加重视网膜病变并引发快速的液体转移；商定逐步、现实的胰岛素目标。提供聚焦进食障碍的心理治疗。筛查抑郁和自杀想法。NICE NG69 和糖尿病指南建议，1 型糖尿病青年患者出现无法解释的高 HbA1c 或反复发生 DKA 时，应询问有无进食障碍和漏用胰岛素。
:::
:::

### 筛查

**SCOFF** 问卷包括五个问题：您是否因为饱得难受而让自己呕吐（**S**ick）？您是否担心自己对进食量失去了控制（**C**ontrol）？您最近三个月是否体重下降超过一英石（**O**ne stone，6.35 kg）？当别人说您太瘦时，您是否仍认为自己胖（**F**at）？您是否会说食物（**F**ood）主宰了您的生活？两个或更多“是”的回答提示可能存在进食障碍。一项荟萃分析发现，其合并灵敏度和特异度分别约为 0.86 和 0.83。

::: warning 体重正常不等于风险低
临床医生常常因为 BMI 在正常或偏高范围而放心。但神经性贪食患者通常体重正常，而从较高起始体重迅速减重的人，即使 BMI“正常”，也可能出现严重的躯体并发症。应根据体重下降速度、清除行为、电解质、心血管体征和心电图来评估风险，而不能只看 BMI。绝不要对疑似进食障碍的人说他们“还不够瘦”，不可能患病。
:::

## 人格障碍

每个人都有人格：一种独特的思考、感受和与他人相处的方式。当这些模式变得僵化并造成持续的问题时，就存在人格障碍。

::: definition 人格障碍 {#def-personality}
**人格障碍**（ICD-11）是一个人在体验和理解自我、他人和世界的方式上的长期紊乱，表现为**自我功能**（身份认同、自我价值、自我导向）和**人际功能**（建立和维持亲密、双方满意的关系，处理冲突）方面的问题。这种紊乱表现为在许多情境中适应不良的情绪、思维和行为模式，已持续很长时间（通常两年或以上），并引起痛苦或功能损害。

ICD-11 对**严重程度**进行评定：人格困难（不属于障碍），以及轻度、中度或重度人格障碍。然后描述突出的**特质维度**：负性情感、疏离、社交紊乱（dissociality）、脱抑制和强迫性（anankastia，完美主义和刻板），以及可选的**边缘模式**标注。

DSM-5-TR 保留了分为三个群的十种分类性人格障碍：**A 群**（古怪或离奇：偏执型、分裂样、分裂型）、**B 群**（戏剧化或反复无常：反社会型、边缘型、表演型、自恋型）和 **C 群**（焦虑或恐惧：回避型、依赖型、强迫型）。
:::

人格障碍通常在青春期或成年早期显现，许多人会随着时间推移而改善，尤其是在接受治疗时。约每 20 名成人中就有 1 人可能符合某种人格障碍的标准，在精神卫生服务机构和监狱中这一比例要高得多。人格障碍常与抑郁、焦虑、进食障碍和物质使用共存。

### 边缘型人格障碍

**边缘型人格障碍**（BPD），又称情绪不稳定型人格障碍，是临床服务中最常见的人格障碍。其特征包括：

- 强烈地害怕被抛弃，并竭力避免被抛弃；
- 不稳定而强烈的人际关系，在理想化和贬低之间交替；
- 不稳定的自我感；
- 在消费、性、物质或进食等方面的冲动性；
- 反复的自伤和自杀行为；
- 明显的情绪不稳定，心境快速变化，持续数小时；
- 长期的空虚感；
- 难以控制的强烈愤怒；
- 与应激相关的一过性偏执观念或解离。

病因包括易产生强烈情绪反应的气质倾向，加上破坏情绪发展的经历，例如童年期虐待、忽视或情绪被漠视的环境。并非每个 BPD 患者都有创伤史。

BPD 患者的自杀风险很高。他们的痛苦是真实的，绝不能用这一标签来漠视它。

::: theorem 结构和一致性有帮助，药物不能治疗核心症状 {#thm-bpd}
边缘型人格障碍的核心特征对在一致、可靠的关系中提供的结构化、长期心理治疗反应最好。没有任何药物被批准或被 NICE 推荐用于边缘型人格障碍的核心特征，而多药联用会造成伤害。
:::

::: proof
BPD 中的许多困难出现在人际关系中：害怕被抛弃、难以信任，以及在他人似乎疏远时出现的情绪风暴。一种提供可预测框架的治疗（明确的目标、规律的会谈、商定的危机计划、相互沟通的团队）可以减少危机的触发因素，并提供一个可以学习新的相处方式的环境。有效的治疗都具有这种结构。**辩证行为治疗**（DBT）教授耐受痛苦、调节情绪、正念和处理人际关系的技能，并将个体治疗、技能小组和电话指导结合起来。**心智化治疗**（MBT）帮助人们理解自己和他人的心理状态，从而减少对互动的误读。试验表明，这些治疗可以减少自伤并改善功能。相比之下，针对核心特征的药物试验规模小、结果不一致。在危机中，药物常常被一种接一种地添加，导致镇静、体重增加以及家中存放危险数量的药物。因此，NICE CG78（2009 年）建议不要对 BPD 本身进行药物治疗，但允许在危机中短期使用镇静药物（不超过约一周），并对抑郁等共存疾病分别进行治疗。
:::

::: example 一位频繁就诊者 {#ex-bpd-spiral}
Kayla Morgan 女士，24 岁，两个月内在与伴侣争吵后割伤手臂或服药过量，八次到急诊科就诊。工作人员说她“操纵他人”。她正在服用四种在不同危机期间开始使用的精神药物。应如何改善她的照护？

::: solution
**改变用语。**“操纵他人”是一种带有污名的评判。她的自伤是应对压倒性情绪的一种方式；它带有真实的风险，值得以同情的方式回应。

**每次就诊。**妥善处理她的伤口，给予与其他任何人相同的照护和镇痛。按照 NICE NG225 的建议，每次都提供心理社会评估，而不是假定什么都没有改变。

**重新审视诊断和计划。**如果 BPD 是工作诊断，要确保她已被告知并有机会讨论。转介至社区精神卫生团队或人格障碍专科服务，接受 DBT 或 MBT 等结构化心理治疗。

**危机计划。**与她共同制订一份书面危机计划，并与急诊科、全科医生和危机团队共享，说明触发因素、什么有帮助以及应联系谁。

**药物。**审查全部四种药物，目标是减少用药；检查有无过量时危险的药物，并限制供应量。对任何共存的抑郁按其本身情况进行治疗。

**一致性。**一名指定的照护协调员、不依赖于危机的定期预约以及各服务之间的良好沟通，可以减少反复就诊的循环。
:::
:::

### 反社会型人格障碍

**反社会型人格障碍**的特征是持续地漠视和侵犯他人的权利：欺骗、冲动、易激惹和攻击性、鲁莽、不负责任以及缺乏悔恨。DSM-5-TR 要求有 15 岁之前品行障碍的证据。它在监狱中很常见，并与物质滥用密切相关。NICE CG77 推荐针对违法行为的团体认知和行为干预，并指出不应因该诊断或违法史而将人们排除在医疗或社会照护之外。

::: example 女运动员 {#ex-female-athlete}
Zara Ahmed 女士，19 岁，大学运动员，因胫骨应力性骨折就诊。她已八个月没有月经，每天训练两次，饮食“干净”。她的 BMI 为 19.0 kg/m²。她否认对自己的体重有任何担忧。请讨论。

::: solution
**识别模式。**闭经、应力性骨折和高训练负荷提示**运动中的相对能量缺乏**（RED-S）：能量摄入相对于训练需求过低，导致激素受抑制和骨密度下降。她的 BMI 正常，但这并不能排除低能量可用性或进食障碍。

**评估。**仔细询问进食情况、体重变化、训练之外的运动、补偿行为以及对体形和体重的想法。筛查进食障碍。检查心率、血压和电解质，并针对闭经安排骨密度测定和内分泌评估。

**处理。**在运动营养师的帮助下增加能量摄入，与教练和医疗团队一起调整训练，并监测月经恢复和骨骼健康。如果存在进食障碍，则转介至进食障碍服务。解释青少年后期和二十多岁时建立的骨量会影响一生的骨折风险。
:::
:::

::: quiz
一名 27 岁神经性厌食女性（BMI 12.5 kg/m²）入院并开始鼻胃管喂养。第 3 天，她出现呼吸困难、意识混乱和新发心律失常。哪一项血液检查结果最可能解释这些表现？
- [ ] 血钠升高
- [x] 血磷降低
- [ ] 血钙升高
- [ ] 白蛋白降低
::: solution
这是再喂养综合征。重新摄入碳水化合物后释放的胰岛素将磷（连同钾和镁）驱入细胞。严重低磷血症导致呼吸肌和心肌无力、心律失常和意识混乱。必须在再喂养前及期间定期测定并补充电解质。
:::
:::

::: history
1689 年，莫顿（Richard Morton）描述了一例“神经性消耗病”。1873 年，伦敦的格尔（William Gull）和巴黎的拉塞格（Charles Lasègue）分别独立描述了神经性厌食；格尔为其命名。1979 年，拉塞尔（Gerald Russell）描述了神经性贪食，指关节征也以他的名字命名。20 世纪 70 年代，布鲁赫（Hilde Bruch）的工作塑造了将神经性厌食理解为自我感和控制感障碍的观点。针对青少年神经性厌食的家庭治疗于 20 世纪 80 年代在 Maudsley 医院发展起来。在人格障碍方面，斯特恩（Adolph Stern）于 1938 年提出了“边缘”一词。莱恩汉（Marsha Linehan）在 20 世纪 80 年代发展了辩证行为治疗，并于 1993 年出版了治疗手册；贝特曼（Anthony Bateman）和福纳吉（Peter Fonagy）在 20 世纪 90 年代末发展了心智化治疗。2003 年，英格兰卫生部的政策文件《人格障碍：不再是排斥性诊断》（*Personality Disorder: No Longer a Diagnosis of Exclusion*）挑战了拒绝为这一诊断的患者提供照护的做法。
:::

## 后续内容

营养与再喂养见[[gastrointestinal/clinical-nutrition]]；青少年健康见[[paediatrics/adolescent-health]]；自伤见[[psychiatry/self-harm-suicide-prevention]]；心理治疗见[[psychiatry/treatments-mental-health-law]]。

::: summary
- 神经性厌食是显著低体重加上阻止体重恢复的行为；神经性贪食是暴食加补偿行为；暴食障碍是最常见的进食障碍；ARFID 是不伴体形关注的限制进食。
- 进食障碍影响所有性别、年龄、族裔和体型的人。
- 饥饿和清除行为影响每个器官；尽管风险高，血液检查也可能正常。使用 MEED 的红-琥珀-绿框架。
- 对于青少年，将 BMI 解读为同年龄同性别中位数的百分比。
- 再喂养综合征源于胰岛素驱动的磷、钾和镁转移；通过监测和补充加以预防，同时避免喂养不足。
- 心理治疗处于核心地位：青少年用 FT-AN；成人用 CBT-ED、MANTRA 或 SSCM；神经性贪食和暴食障碍首先采用指导式自助。
- 人格障碍是自我和人际功能的长期紊乱；ICD-11 评定严重程度和特质维度。
- 边缘型人格障碍包括情绪不稳定、害怕被抛弃、冲动和自伤；DBT 和 MBT 有帮助；没有药物能治疗其核心特征。
- 避免带有污名的用语；提供一致、结构化的照护和危机计划。
:::

## 习题

::: exercise BMI {level=1 check="round(10*36/1.6^2)/10"}
计算一名体重 36 kg、身高 1.60 m 女性的 BMI，保留一位小数，并说明它是否处于 ICD-11 成人危险低体重范围内。
::: solution
BMI $= 36/1.60^2 = 36/2.56 = 14.0625$，即**14.1** kg/m²。这刚好高于 ICD-11 危险低体重的阈值（BMI 低于 14 kg/m²），但仍然非常低，提示医学风险高；MEED 框架会将其评为琥珀色，还必须评估其他指标。
:::
:::

::: exercise 贪食与血钾 {level=1}
解释为什么反复自我催吐会引起低钾血症和代谢性碱中毒。
::: solution
呕吐使胃中的盐酸丢失，导致代谢性碱中毒。液体丢失引起容量不足，激活肾素-血管紧张素-醛固酮系统；醛固酮增加肾脏对钠的重吸收和对钾的排泄。碱中毒还使钾转移入细胞，并增加肾脏钾丢失。呕吐物中直接丢失的钾也起一小部分作用。其结果是低钾血症，可引起心律失常和肌无力。
:::
:::

::: exercise 群与维度 {level=1}
说出 DSM-5-TR 的三个人格障碍群并各举一例，并列出 ICD-11 的五个特质维度。
::: solution
A 群（古怪或离奇）：偏执型、分裂样或分裂型。B 群（戏剧化或反复无常）：反社会型、边缘型、表演型或自恋型。C 群（焦虑或恐惧）：回避型、依赖型或强迫型。ICD-11 特质维度：负性情感、疏离、社交紊乱、脱抑制和强迫性。
:::
:::

::: exercise 中位数 BMI 百分比 {level=2 check="round(100*14.2/18.6)"}
一名 12 岁男孩的 BMI 为 14.2 kg/m²。假设他这个年龄和性别的中位数 BMI 为 18.6 kg/m²（示意值）。计算他的 %mBMI（取整数）并加以评论。
::: solution
%mBMI $= 14.2/18.6 \times 100 \approx 76.3$，即**76%**。这属于明显体重不足。它高于约 70% 的高风险阈值，但风险还取决于体重下降速度、心血管体征、血液检查和行为，这些都必须评估。
:::
:::

::: exercise 筛查的检出 {level=2 check="round(100*0.86*0.05/(0.86*0.05+0.17*0.95))"}
以 SCOFF 的灵敏度 0.86 和特异度 0.83 计算，患病率为 5% 时的阳性预测值是多少？答案以整数百分比表示。
::: solution
真阳性$= 0.86 \times 0.05 = 0.043$。假阳性$= 0.17 \times 0.95 = 0.1615$。PPV $= 0.043/(0.043+0.1615) = 0.043/0.2045 \approx 0.210$，即**21%**。
:::
:::

::: exercise 再喂养风险 {level=2}
列出四项提示再喂养综合征高风险的特征，并概述预防原则。
::: solution
高风险特征包括 BMI 极低、近期体重显著下降、许多天几乎没有或完全没有营养摄入、喂养前血钾、血磷或血镁偏低，以及酗酒史或使用胰岛素、化疗药物、抗酸药或利尿剂等药物。预防：喂养前测定电解质、血糖并做心电图；给予硫胺素和复合维生素；在适当监测下开始营养支持，而不是采用极低的摄入量（以避免喂养不足）；起初每天检查磷、钾、镁和血糖，并根据需要补充；监测液体平衡、心率和水肿；按照 MEED 和当地方案，让营养师和内科团队参与。
:::
:::

::: exercise 有争议的诊断 {level=3}
一名 30 岁男性在十年间被给予了四种不同的诊断：抑郁症、双相 II 型障碍、ADHD 和边缘型人格障碍。他有由被拒绝触发、持续数小时的快速心境变化，长期空虚感，冲动消费和反复自伤。请讨论如何区分双相障碍与边缘型人格障碍，以及为什么这很重要。
::: solution
关键区别在于心境变化的模式。在双相障碍中，心境发作持续数天至数周（轻躁狂至少四天），是相对于患者平常状态的改变，并伴有睡眠需求和精力的持续变化。在 BPD 中，心境变化迅速，持续数小时，通常由被感知到的拒绝等人际事件触发，背景是长期的空虚感和不稳定的身份认同。他的特征更符合 BPD，但两者可以共存，ADHD 也可能促成冲动，需要单独评估。这很重要，因为治疗不同：双相障碍用心境稳定剂治疗，而 BPD 的核心特征对结构化心理治疗有反应，不恰当地使用心境稳定剂或抗精神病药会使他承受不良反应却没有获益。仔细的纵向病史、知情人信息和心境记录都有帮助。无论作出哪种诊断，都应与他公开讨论。
:::
:::

::: exercise 一个服务设计问题 {level=3}
某进食障碍服务的等候名单长达六个月，并且只接受 BMI 低于 15 kg/m² 的成人转介。请运用本章原则和英国现行指南评析这一政策。
::: solution
BMI 阈值把神经性贪食、暴食障碍和 ARFID 患者，以及体重较高或体重迅速下降的神经性厌食患者排除在外，而他们中的许多人都面临严重的医学和精神风险。单凭 BMI 并不能很好地反映风险；MEED 强调综合评估体重下降、心血管体征、血液检查和行为。漫长的等待会使疾病变得根深蒂固，而早期干预可以改善结局；英格兰的国家项目推动了青少年快速获得治疗以及针对新发进食障碍的青年早期干预。NICE NG69 指出，不应仅根据 BMI 将人们排除在治疗之外。更好的政策是：按临床需要接受转介，使用 MEED 框架按风险分诊，提供早期干预，在等待期间为神经性贪食和暴食障碍患者提供指导式自助，并与基层医疗就躯体监测建立明确的共同照护安排。
:::
