焦虑是一种正常而有用的情绪。它让身体做好应对危险的准备，使注意力更敏锐，并促使人采取行动。当焦虑与真实的威胁不相称、持续存在并引起痛苦或妨碍日常生活时，就存在焦虑障碍。总体而言，焦虑及应激相关障碍是最常见的精神障碍之一。它们也是最可治疗的精神障碍之一，因此识别它们非常值得。

本章解释正常的恐惧如何变成障碍，介绍主要的焦虑障碍、强迫障碍和创伤相关障碍，并阐述治疗原则。本章还介绍可能看起来像焦虑的躯体疾病，因为漏诊这些疾病是真实存在的危险。

## 从正常恐惧到障碍

::: definition 威胁反应 {#def-threat}
**威胁反应**是大脑和身体对所感知危险的协调反应。**杏仁核**探测到威胁，并通过下丘脑和脑干激活**交感神经系统**和**下丘脑-垂体-肾上腺轴**。其结果是心率加快、呼吸急促、肌肉紧张、出汗、口干和警觉性提高，即“战斗或逃跑”反应。**前额叶皮质**通常会对威胁进行评估，并在危险过去后抑制这一反应。
:::

惊恐发作的每一种症状都是这一反应的一部分。快速呼吸降低了血液中的二氧化碳，引起手指和口周麻刺感、头晕和胸闷。理解这一点有助于患者把可怕的感觉重新解读为无害的。

是什么把恐惧变成了障碍？易感性起一定作用：焦虑障碍有家族聚集性，部分通过基因，部分通过学习；童年逆境也会增加风险。但治疗的关键在于焦虑一旦开始后是什么在**维持**它。

::: theorem 回避维持焦虑 {#thm-avoidance}
焦虑障碍是由人们用来保护自己免受所恐惧结果的行为维持的。**回避**（远离所恐惧的情境）、**逃离**（提前离开）和**安全行为**（为防止灾难而采取的行动，例如抓住扶手或“以防万一”随身带药）在短期内能缓解焦虑，但使患者无法认识到所恐惧的结果并不会发生，或者是可以应对的。因此，有效的治疗包括在不采取这些行为的情况下面对所恐惧的情境。
:::

::: proof
这一解释来自学习理论。恐惧可以通过联结习得，例如在公交车上的一次惊恐发作使公交车变得可怕（经典条件反射）。随后回避公交车带来即刻的解脱，而解脱又奖励了回避，于是回避变得更强（负强化）。由于患者从未在公交车上停留足够长的时间让焦虑自然下降，“如果我没下车，我就会晕倒”这一信念从未得到检验。安全行为的作用方式相同：如果一个人每次发作时都抓住扶手而从未晕倒，他会把功劳归于扶手，而不是得出惊恐不会导致晕倒的结论。暴露治疗打破了这一循环。在没有逃离或安全行为的情况下，反复、持续地接触所恐惧的情境，就能产生新的学习：这个情境是安全的，焦虑会自行上升、达到高峰然后下降。
:::

## 主要障碍

::: definition 焦虑及恐惧相关障碍 {#def-anx-disorders}
- **广泛性焦虑障碍**（GAD）：在至少数月（DSM-5-TR 为六个月）的大多数日子里，对许多日常事务（健康、金钱、工作、家庭）过度且难以控制的担忧，伴有坐立不安、疲乏、注意力差、易激惹、肌肉紧张和睡眠紊乱等症状。
- **惊恐障碍**：反复出现意外的**惊恐发作**（强烈恐惧突然涌现，在数分钟内达到高峰，伴躯体症状），随后持续担心再次发作，或为避免发作而改变行为。
- **广场恐惧症**：害怕并回避一旦惊恐发作时可能难以逃离或得不到帮助的情境，如人群、公共交通、排队或独自离家。
- **社交焦虑障碍**：因担心被负面评价、尴尬或受辱，而对社交或表现情境产生明显恐惧。
- **特定恐惧症**：对特定物体或情境的明显恐惧，例如高处、蜘蛛、注射或乘飞机。
:::

在 ICD-11 中，强迫障碍和应激相关障碍是单独的类别，但它们与焦虑障碍有共同的机制和治疗，因此在此一并介绍。

**强迫障碍**（OCD）以强迫观念、强迫行为或（通常）两者兼有为特征（定义见[[psychiatry/psychiatric-assessment]]）。常见主题有污染与清洗、伤害与检查、对称与排序，以及不想要的性、宗教或暴力想法。强迫行为耗费时间（常常每天超过一小时），或引起痛苦或功能损害。自知力程度不一；大多数人承认自己的恐惧是过分的。相关障碍包括**躯体变形障碍**（对自己外貌中想象的缺陷的先占观念）和**囤积障碍**。

**应激相关障碍**发生于一个可识别的事件之后：

- **急性应激反应**是对异常应激事件的正常、短暂的反应，在数天内平息。
- **创伤后应激障碍**（PTSD）发生于暴露于极端威胁性或恐怖的事件之后。ICD-11 要求三组症状：在当下**再体验**该事件（生动的侵入性记忆、闪回或噩梦，伴恐惧或惊恐）；**回避**作为提示物的想法、记忆、活动或情境；以及持续的**当前威胁**感（过度警觉或惊跳反应增强）。症状持续至少数周（DSM-5-TR 为一个月以上），并引起显著的功能损害。
- **复杂性 PTSD**（ICD-11 诊断）是 PTSD 加上情绪调节、对自己的负面看法（羞耻、内疚、无价值感）以及维持人际关系方面的持续问题。它通常发生于难以逃离的长期或反复创伤之后，例如童年期虐待、酷刑或家庭暴力。
- **适应障碍**是对应激源（如离婚或失业）的反应，表现为先占观念和适应失败，通常在六个月内缓解。

## 类似焦虑的躯体疾病

焦虑症状大多是躯体性的，因此躯体疾病可能看起来像焦虑障碍。新出现的表现，特别是在约 40 岁以上或无既往病史的人中，需要进行躯体评估。

| 病因 | 线索 |
|---|---|
| 甲状腺功能亢进症 | 体重下降、怕热、震颤、心动过速、甲状腺肿 |
| 心律失常（如室上性心动过速、心房颤动） | 心悸突发突止、脉搏不规则、心电图改变 |
| 低血糖 | 发作与空腹或胰岛素及磺脲类药物有关，进食后缓解 |
| 哮喘、肺栓塞 | 呼吸困难伴喘鸣、低氧、血栓形成危险因素 |
| 嗜铬细胞瘤（罕见） | 阵发性头痛、出汗、心悸和高血压 |
| 物质 | 咖啡因、兴奋剂、大麻；酒精或苯二氮䓬类药物戒断 |
| 药物 | 沙丁胺醇、左甲状腺素过量、糖皮质激素、某些减充血剂 |

焦虑在躯体疾病中也很常见，已知患有焦虑障碍的人仍然可能发生心脏或呼吸系统急症。

::: example 夜间胸痛 {#ex-panic-cardio}
Priya Desai 女士，29 岁，凌晨 2 点因突然胸闷、心悸、手指麻刺感和一种自己快要死了的感觉来到急诊科。症状在十分钟内达到高峰，现在正在缓解。这是她两个月内第四次就诊。她的心电图、肌钙蛋白和体格检查均正常。应如何处理？

::: solution
**首先按比例排除危险病因。**对于心电图正常、肌钙蛋白正常、血氧饱和度正常且无危险因素的年轻女性，急性冠脉综合征和肺栓塞的可能性很小；评估中仍应考虑这些疾病，并检查有无心律失常（症状发作时的心电图很有价值）和甲状腺功能亢进症。

**识别模式。**强烈恐惧伴躯体症状突然涌现，在数分钟内达到高峰，意外地反复发生，并反复求医，提示**惊恐障碍**。询问发作间期的担忧和回避：她现在回避健身房和地铁，因为“我的心脏可能会撑不住”。

**清楚地解释。**描述威胁反应，以及快速呼吸如何引起麻刺感和胸闷。确认检查显示她的心脏是健康的，这些症状是真实的，但并不危险。

**计划。**除非出现新的特征，否则建议不要反复检查。通过基层医疗或英国国家医疗服务体系心理治疗服务（NHS Talking Therapies）转介接受针对惊恐障碍的 CBT。建议减少咖啡因。如果无法获得心理治疗或患者更偏好药物，可选择选择性 5-羟色胺再摄取抑制剂（SSRI）。不推荐对惊恐障碍使用苯二氮䓬类药物，因为它们与较差的长期结局相关。
:::
:::

## 评估与测量

病史要探究患者害怕什么、身体和头脑中发生了什么、回避什么、使用了哪些安全行为，以及生活受到怎样的影响。始终要询问心境低落、饮酒和药物使用（常被用来应对焦虑）以及自杀想法。抑郁和焦虑经常同时出现。

**GAD-7** 问卷对过去两周内广泛性焦虑的七项症状评分，每项 0–3 分，总分 0–21 分。5、10 和 15 分分别标志着轻度、中度和重度焦虑。前两项构成 **GAD-2**，用于快速筛查；通常以 3 分或以上为界值。在最初的基层医疗验证研究中，GAD-2 达到 3 分或以上对 GAD 的灵敏度约为 0.86，特异度约为 0.83。

::: example GAD-7 及其后续 {#ex-gad7}
Luis Fernández 先生，45 岁，完成 GAD-7，各项得分为 3、2、2、1、2、3、1。计算他的得分和严重程度。然后计算在 20% 的人患 GAD 的人群中，GAD-2 达到 3 分或以上（灵敏度 0.86，特异度 0.83）的阳性预测值，并加以评论。

::: solution
**GAD-7 总分。**$3+2+2+1+2+3+1 = 14$，属于中度（10–14 分）。

**GAD-2。**他前两项合计$3+2 = 5$，高于界值。

**患病率 20% 时的 PPV。**真阳性$= 0.86 \times 0.2 = 0.172$。假阳性$= 0.17 \times 0.8 = 0.136$。PPV $= 0.172/(0.172 + 0.136) = 0.172/0.308 \approx 0.558$，约 56%。

**评论。**即使在高患病率人群中，近一半的阳性筛查结果也是假阳性。问卷用于确定谁需要临床评估，并为衡量进展提供基线；诊断来自会谈。
:::
:::

## 治疗

英国的治疗遵循 NICE 指南：GAD 和惊恐障碍为 CG113（2011 年），社交焦虑障碍为 CG159（2013 年），强迫障碍和躯体变形障碍为 CG31（2005 年），PTSD 为 NG116（2018 年）。截至 2026 年，这些仍是现行指南。它们共用**阶梯式照护**模式：从强度最低的有效治疗开始，如无帮助则逐级提高。

::: definition 焦虑障碍的治疗方法 {#def-anx-treatment}
- **心理教育**：解释威胁反应和回避循环。
- **低强度干预**：基于 CBT 的指导式自助、计算机化 CBT 和心理教育小组。
- **认知行为治疗**（CBT）：识别并检验令人恐惧的预测，减少安全行为，以及对所恐惧情境的分级**暴露**。针对特定障碍的形式包括针对惊恐的 CBT、针对社交焦虑的 Clark 和 Wells 模型，以及针对强迫障碍的**暴露与反应预防**（ERP），即患者面对触发因素并克制强迫行为。
- 针对 PTSD 的**聚焦创伤的治疗**：**聚焦创伤的 CBT** 和**眼动脱敏与再加工**（EMDR）。
- **药物**：SSRI 是大多数焦虑障碍和强迫障碍的一线药物。NICE 推荐舍曲林（sertraline）作为 GAD 的首选。替代选择包括另一种 SSRI、SNRI（文拉法辛（venlafaxine）、度洛西汀（duloxetine））或普瑞巴林（pregabalin）。
:::

药物治疗的重要原则：

- **早期加重。**SSRI 可能在最初一两周使焦虑加重。从小剂量开始并解释这一点可以提高依从性。
- **起效时间。**获益在数周内逐步显现，强迫障碍可能需要十二周或更长时间，且所需剂量常高于治疗抑郁（剂量决定遵循 BNF 和专科意见）。
- **苯二氮䓬类药物。**这类药物起效快，但会导致耐受、依赖、镇静、跌倒和驾驶能力受损，戒断反应也可能很严重。NICE 建议不要将其用于 GAD 和惊恐障碍，作为短期危机处理时除外。普瑞巴林也有被滥用和产生依赖的可能，自 2019 年起在英国被列为管制药物。
- **不做事后疏泄。**对于 PTSD，不推荐在创伤后立即进行单次心理疏泄（debriefing），因为它不能预防 PTSD，还可能使之增加。更可取的是早期支持、实际帮助和观察等待，对发生 PTSD 者给予聚焦创伤的治疗。

::: example 停用长期使用的苯二氮䓬类药物 {#ex-benzo-taper}
Joan Fraser 夫人，71 岁，15 年前因丧亲后的焦虑开始服用地西泮（diazepam），此后每晚服用。今年她跌倒了两次，女儿担心她的记忆力。她对停药感到焦虑。请概述处理方法。

::: solution
**为何要改变。**老年人长期使用苯二氮䓬类药物会增加跌倒、骨折、认知损害和道路交通事故的风险，而且最初的适应证已经过去。

**共同决策。**温和地解释原因，承认她并没有做错什么，并商定一个由她掌控的计划。长期用药后突然停药是危险的：戒断可引起反跳性焦虑、失眠，罕见情况下可引起癫痫发作。

**逐渐减量。**缓慢减量，通常每两到四周小幅减少一次，接近结束时进一步放慢，戒断症状令人困扰时暂停减量，并遵循 BNF 和当地指南。地西泮的半衰期长，本身就适合用于逐渐减量。

**支持。**为焦虑和失眠提供心理帮助（针对失眠的 CBT），评估其他镇静药物，并检查有无抑郁。定期复查。许多人发现停药后睡眠和思维比以前更好。
:::
:::

::: example 停不下来的检查 {#ex-checking-son}
Ahmed Hassan 先生，35 岁，每天早上要花两个小时才能出门，因为他要检查炉灶是否关闭、门是否锁好，常常检查 30 次。他知道这样做过分，但如果停止检查，他会感到难以忍受的焦虑，担心家人会死于火灾。自儿子出生以来，他还出现了伤害婴儿的侵入性画面，这令他十分恐惧，于是他回避给孩子洗澡。诊断是什么？应如何理解关于婴儿的侵入性想法？

::: solution
**诊断。**强迫障碍：关于伤害的强迫观念（火灾、伤害婴儿）、强迫行为（反复检查）、耗费时间（每天超过一小时）和功能损害，自知力良好。

**侵入性画面。**不想要的伤害婴儿的想法在强迫障碍中很常见，尤其是在新手父母中。它们是**自我不协调的**：患者觉得这些想法可憎，会抵抗它们，并回避引发它们的情境。它们不是意图或欲望。没有证据表明强迫障碍患者会把这类想法付诸行动。认识到这一点很重要：把他当作对孩子有风险的人来对待，会加重他的羞耻和回避，并可能使他不敢求助。

**仔细鉴别。**评估仍应全面，就像任何临床医生在提到伤害儿童时都必须做的那样。会引起担忧的特征包括：想法被体验为可以接受或想要的、精神病性症状、中毒或暴力史。这些都不存在。

**治疗。**采用暴露与反应预防的 CBT：分级练习，例如只检查一次就出门、给儿子洗澡，同时不执行强迫行为。如果症状严重或进展缓慢，可加用 SSRI。
:::
:::

::: warning 安慰可能变成强迫行为
家人和临床医生常常以反复安慰来回应焦虑：“门锁好了”“你的心脏没问题”。安慰能短暂缓解焦虑，但它的作用就像安全行为或强迫行为一样，会使问题持续下去（见[[#thm-avoidance]]）。更好的做法是清楚地提供一次信息，然后支持患者耐受不确定性。为安慰健康焦虑患者而反复做检查也有同样的效果。
:::

::: example 一种不容忽视的针头恐惧 {#ex-adult-phobia}
Grace Adeyemi 女士，32 岁，一年前被诊断为 1 型糖尿病。她错过了几次预约，HbA1c 升高。她承认自己一看到针头就晕倒，并回避抽血检查。请描述这种恐惧症的类型，以及其治疗与其他恐惧症有何不同。

::: solution
**类型。****血液-注射-损伤**型特定恐惧症。与其他恐惧症不同，它常常产生双相反应：先是心率和血压升高，随后突然下降（血管迷走反应），可导致晕厥。

**治疗。**分级暴露，从看针头的图片开始，逐步过渡到抽血和自我注射。由于有晕厥的风险，治疗师会教授**应用性紧张**：在暴露过程中绷紧手臂、腿部和躯干的大肌肉，以升高血压、防止晕厥。

**更广泛的照护。**与糖尿病团队合作，使操作更容易进行：躺着抽血、使用局部麻醉药，以及使用小针头的胰岛素笔。她的恐惧症是获得医疗照护的障碍，值得治疗。
:::

::: quiz
一名惊恐障碍男性总是随身带一瓶水，开会时总坐在出口附近，“以防我感到不舒服”。根据认知行为模型，这些行为的主要作用是什么？
- [ ] 它们通过习惯化逐渐减轻他的焦虑。
- [x] 它们使他无法认识到惊恐并不危险，从而使障碍持续下去。
- [ ] 它们是无害的习惯，可以忽略。
- [ ] 它们表明他的惊恐是由躯体疾病引起的。
::: solution
这些是安全行为。它们带来短期的缓解，但意味着每次他没有晕倒时，他都把功劳归于那瓶水或出口，而没有认识到惊恐不会导致晕倒。治疗包括在有计划的暴露中放弃这些行为。
:::
:::

::: history
对非理性恐惧的描述自古就有，希波克拉底曾描述过一个夜间无法从吹笛人身边走过的男子。1871 年，韦斯特法尔（Carl Westphal）描述了“广场恐惧症”（*Agoraphobie*）；1895 年，弗洛伊德（Sigmund Freud）将“焦虑性神经症”从神经衰弱中分离出来。20 世纪中叶，学习理论改变了治疗方式：沃尔普（Joseph Wolpe）在 20 世纪 50 年代发展了系统脱敏法，马克斯（Isaac Marks）等人在 20 世纪六七十年代于伦敦证明暴露才是起作用的关键成分。1966 年，迈耶（Victor Meyer）描述了针对强迫障碍的暴露与反应预防。克拉克（David Clark）的惊恐认知模型（1986 年）将惊恐发作解释为对躯体感觉的灾难化误解。在越战老兵和临床医生的推动下，创伤后应激障碍的诊断于 1980 年被纳入 DSM-III，为早先被称为“炮弹休克”和“战斗疲劳”的反应提供了名称。2019 年通过的 ICD-11 增加了复杂性 PTSD。
:::

## 后续内容

威胁反应的自主神经基础见[[physiology/autonomic-nervous-system]]；与抑郁的重叠见[[psychiatry/mood-disorders]]；苯二氮䓬类药物依赖见[[psychiatry/substance-use]]；心理治疗的更多细节见[[psychiatry/treatments-mental-health-law]]。

::: summary
- 焦虑是一种正常的威胁反应；障碍是指与危险不相称、持续存在并造成损害的焦虑。
- 回避、逃离和安全行为在短期内缓解焦虑，但会维持障碍。
- 主要障碍包括 GAD、惊恐障碍、广场恐惧症、社交焦虑障碍和特定恐惧症；强迫障碍和应激相关障碍（PTSD、复杂性 PTSD、适应障碍）与之密切相关。
- 排除躯体原因，尤其是甲状腺疾病、心律失常、低血糖和物质，并寻找共存的抑郁和饮酒问题。
- GAD-7 衡量严重程度；GAD-2 是一种快速筛查，其预测值取决于患病率。
- 治疗采用阶梯式：先是心理教育和指导式自助，然后是带暴露的 CBT（强迫障碍用 ERP，PTSD 用聚焦创伤的 CBT 或 EMDR）。
- SSRI 是一线药物，GAD 首选舍曲林；应解释早期加重和延迟获益。
- 避免长期使用苯二氮䓬类药物；创伤后不提供单次心理疏泄。
- 强迫障碍中伤害他人的侵入性想法是不想要的、受到抵抗的，并不表明存在将其付诸行动的风险。
:::

## 习题

::: exercise 说出障碍名称 {level=1}
说出最可能的诊断：(a) 一名女性一年来回避超市和公交车，因为她害怕在无法离开的地方发生惊恐发作；(b) 一名男性八个月来几乎每天担心自己的健康、工作和孩子，伴睡眠差和肌肉紧张；(c) 一名学生无法在研讨课上作报告，因为她害怕脸红并被认为愚蠢。
::: solution
(a) 广场恐惧症（可能伴惊恐障碍）。(b) 广泛性焦虑障碍。(c) 社交焦虑障碍。
:::

::: exercise 惊恐发作的生理学 {level=1}
解释为什么惊恐发作时的过度通气会引起手指和嘴唇的麻刺感。
::: solution
快速呼吸呼出二氧化碳，使动脉$P_{\text{CO}_2}$下降，造成呼吸性碱中毒。碱中毒增加钙与白蛋白的结合，使离子钙降低，从而增加周围神经的兴奋性，引起口周和手指的麻刺感。低$P_{\text{CO}_2}$还会引起脑血管收缩，导致头晕。
:::
:::

::: exercise PTSD 的症状组 {level=1}
列出 ICD-11 中 PTSD 的三组核心症状，以及复杂性 PTSD 的三项附加特征。
::: solution
PTSD：在当下再体验创伤（侵入性记忆、闪回、噩梦）；回避提示物；以及持续的当前威胁感（过度警觉、惊跳反应增强）。复杂性 PTSD 另外包括：情绪调节问题；持续负面的自我概念（羞耻、内疚、无价值感）；以及维持人际关系的困难。
:::

::: exercise 筛查计算 {level=2 check="round(100*0.86*0.06/(0.86*0.06+0.17*0.94))"}
以 GAD-2 的灵敏度 0.86、特异度 0.83 计算，在 6% 的人患 GAD 的基层医疗人群中，阳性预测值是多少？答案以整数百分比表示。
::: solution
真阳性$= 0.86 \times 0.06 = 0.0516$。假阳性$= 0.17 \times 0.94 = 0.1598$。PPV $= 0.0516/(0.0516+0.1598) = 0.0516/0.2114 \approx 0.244$，即约**24%**。四分之三的阳性筛查结果是假阳性，因此 GAD-2 阳性之后需要进一步评估。
:::

::: exercise 设计暴露等级 {level=2}
一名 40 岁广场恐惧症男性已两年未乘坐公共交通。请设计一个六级的分级暴露等级，并说明实施暴露的两条规则。
::: solution
等级示例，从最不害怕到最害怕：(1) 在公交车站站 15 分钟；(2) 在同伴陪同下乘坐人少的公交车坐一站；(3) 独自坐一站；(4) 在人少的时段独自坐五站；(5) 在高峰时段坐五站；(6) 独自乘坐 30 分钟的火车。规则：留在情境中，直到焦虑明显下降，或者停留足够长的时间来检验所恐惧的预测，而不要在焦虑高峰时逃离；放弃安全行为（坐在门边、携带不需要的药物）；每一级定期重复，直到变得容易后再进入下一级；记录预测和实际发生的情况。
:::

::: exercise 只是“担心过度”吗？ {level=2}
一名有 GAD 病史的 55 岁女性，一个月来出现焦虑、心悸、体重下降 4 kg、震颤和腹泻。她的全科医生增加了舍曲林的剂量。这种处理有什么问题？应该怎么做？
::: solution
已知患有焦虑障碍的人出现新的症状模式，仍然需要躯体评估。体重下降、震颤、腹泻和心悸强烈提示甲状腺功能亢进症；还必须排除心房颤动。评估应包括脉率和节律、甲状腺疾病的体征、甲状腺功能检查和心电图。把新出现的躯体症状归因于已知的精神科诊断称为诊断遮蔽，是精神障碍患者疾病漏诊的常见原因。
:::
:::

::: exercise 车祸之后 {level=3}
一场严重的高速公路车祸导致一位朋友死亡，三周后，一名 24 岁女性做噩梦、无法开车并且容易受惊。她的雇主在车祸次日安排了一次单次疏泄。她的母亲问她现在是否患有 PTSD，以及是否应该开始服用抗抑郁药。请讨论。
::: solution
在事件发生三周后，这些症状很常见，许多人无需特殊治疗即可恢复。ICD-11 的 PTSD 要求症状持续至少数周并伴有显著的功能损害，DSM-5-TR 要求超过一个月，因此现在诊断 PTSD 为时尚早，尽管这些症状可能是一种会发展为 PTSD 的急性应激反应。NICE NG116 建议积极监测和实际支持，并在约一个月内重新评估；如果发生 PTSD（或现在症状已很严重），则提供聚焦创伤的 CBT；对于有临床意义症状的人，在第一个月内即可提供个体聚焦创伤的 CBT。不推荐单次疏泄，因为它不能预防 PTSD，还可能使其加重。药物治疗不是预防或治疗 PTSD 的一线方法；对于偏好药物或无法参与心理治疗的成人，日后可考虑 SSRI 或文拉法辛。还要检查有无抑郁、饮酒和自杀想法，并通过分级暴露支持她恢复驾驶。失去朋友的哀伤也需要空间。
:::
:::

::: exercise 一个复杂的病例 {level=3}
一名 38 岁女性童年期反复遭受虐待，现在有噩梦和闪回，用酒精帮助入睡，与伴侣频繁激烈争吵，并形容自己“毫无价值、令人恶心”。在痛苦时她曾以割伤的方式自伤。请讨论鉴别诊断和治疗的优先事项。
::: solution
鉴别诊断包括复杂性 PTSD（PTSD 症状加上情绪调节、负面自我概念和人际关系方面的问题）、PTSD 共病抑郁、边缘型人格障碍（与之有大量重叠，也可能共存）以及酒精使用障碍。仔细评估可以区分它们：在复杂性 PTSD 中，自我概念稳定地负面，核心是创伤症状；而在边缘型人格障碍中，自我形象不稳定，害怕被抛弃很突出。优先事项：首先是安全（自伤、饮酒、当前来自他人的风险，包括施虐者是否仍构成威胁）；稳定的治疗关系；减少会干扰治疗的饮酒；学习应对痛苦和自伤的稳定化技能；然后按照 NICE NG116 的建议，进行针对复杂性 PTSD 加以调整且常常延长的聚焦创伤治疗。药物可能有助于共存的抑郁或睡眠问题，但不是主要治疗。鉴于饮酒和自伤，避免使用苯二氮䓬类药物。
:::
