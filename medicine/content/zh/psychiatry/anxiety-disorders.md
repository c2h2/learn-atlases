焦虑障碍是门诊里最大的一类，也是最容易被两种相反的方式处理错误的一类：**要么被当作心脏与胃的疾病反复检查，要么被当作“人人都会紧张”而不予治疗。正确的看法介于两者之间：焦虑是防御系统的过度动员，它可以被理解、被测量、被暴露、被药物改变，而它最常见的维持机制恰恰是好心的安慰与回避。**本章覆盖恐惧与焦虑的神经经济学、各障碍的鉴别（惊恐、广泛性焦虑、恐惧症、强迫谱与创伤后）、以及治疗的三条腿（解释与暴露与药物）与其常见失败。

## 核心问题

::: definition 恐惧、焦虑与防御系统 {#def-threat}
**恐惧是对当下可识别的威胁的反应：心跳加快、呼吸加快、肌肉紧张、注意收窄，其价值在于行动。焦虑是对尚未到来或不明确的威胁的持续动员，它没有可以逃跑的对象，因此变成慢性的消耗：失眠、肌肉的疼痛、胃肠的症状、以及“必须查清楚”的探查行为。恐惧与焦虑的学习有三条通路，而治疗要逐条打乱：第一条是直接的经历（被狗咬过一次）；第二条是被告知（母亲说水很危险）；第三条是观察（父亲见蛇时的脸色）。回避是维持的核心，它在短时间里显著减轻痛苦，因此被强烈地负性强化，而它同时剥夺了“不逃避会怎样”的新经验，于是恐惧的记忆没有被更新，只被证实。安全感与安慰也有同样的双重作用：一次急诊的“心脏没问题”能让她今天好过，但若服务反复提供这种确认，它就成了检查与复诊的燃料；因此治疗焦虑时要写出“我们要减少哪一句安慰”，这是与开药同等重要的处方。躯体的感觉在这里成为触发：心跳、头晕、手麻这些正常的波动被解读为危险的信号，解读本身放大了感觉，形成惊恐的循环；因此解释要具体到在生理的过度换气与在二氧化碳的下降与在手麻与在（濒死感的联系）。诊断之外要评估的还有共病（抑郁在焦虑人群中的比例极高，且两者同时治疗优于先后）、物质（咖啡因、能量饮料、（在若干的）减肥与提神的产品、酒精的自我治疗、大麻在若干人中的焦虑加重）、以及生活的维持因素夜班、在（育儿的负荷）、在（工作的不安全感）。要把焦虑与躯体疾病的关系说清而不是掩盖：甲状腺与心律失常与哮喘与在贫血与在（（癫痫的部分发作））确实可以模仿，因此首次的发作样事件需要有限的检查而不是无限的检查；检查的限度本身也是治疗的一部分（[[psychiatry/psychiatric-assessment]]、[[clinical-skills/clinical-reasoning]]、[[cardiovascular/arrhythmias]]、[[endocrine/thyroid]]）。**
:::

## 各种障碍

::: definition 惊恐、广泛性焦虑、恐惧症与强迫谱 {#def-anx-disorders}
**惊恐发作是数分钟内到达高峰的恐惧伴躯体症状（心悸、胸闷、气短、手麻、头晕、濒死感）；发作本身不危险，而它的可怕之处在于被解释为心脏病。当发作之后出现“担心下一次”的持续预期与回避（尤其在无人帮助或难以离开的场合），即为惊恐障碍伴（或不伴）广场恐惧；此时她可能已经看过五次急诊。广泛性焦虑的核心不是担心什么，而是“担心”这个动作本身占据了大部分清醒时间，伴肌肉紧张与易怒与睡眠的浅；它的功能常是被默认的（“不担心就等于不重视”），而这句信念是治疗要处理的对象。恐惧症是特定对象或情境触发的即刻的焦虑与可预期的回避，其诊断容易，其治疗几乎完全依赖分级暴露；血液-注射-损伤型的独特之处是血管迷走的血压下降与短暂的意识丧失，因此暴露时必须配合在升高血压与在（（四肢的紧张上的））的技术，且要在能躺下的房间里做。创伤后应激障碍要有暴露史与三类症状：重现在噩梦与在闪回与在（被声音与气味触发的躯体反应）、回避与在麻木与在（负性的信念）、以及高唤起在惊醒与在易怒与在（注意的困难）；症状在一个月后仍持续并影响功能才成立，急性的应激反应多数会自行缓解，因此过早的“一次心理清创”并不被推荐。强迫症要单独说：它的核心是侵入性的想法在伤害与在污染与在（（性与宗教的内容））引起痛苦，与在（为了消除痛苦而做的仪式），包括外在的清洗检查与内在的反复回想与求证；治疗是在暴露与在（反应阻止）而不是泛泛的支持性谈话，而谈话中允许她向医生求证一次，就等于替她做了一次仪式。还要识别几个近邻：疑病在（疾病焦虑）与躯体形式的问题常在门诊里更像“内科病”，而焦虑障碍的躯体面具在老年与在（若干文化中）尤其常见——把疼痛与在（“虫子在皮肤下”）与在（心脏的空落）当作主诉（[[psychiatry/psychotic-disorders]]、[[psychiatry/mood-disorders]]、[[clinical-skills/communication]]、[[psychiatry/self-harm-suicide-prevention]]）。**
:::

## 治疗

::: definition 治疗焦虑 {#def-anx-treatment}
**第一条是解释，且要具体到能改变行为：把惊恐讲成“防御系统被误触发＋过度换气的放大＋回避的维持”，并在解释结束时约定一件本周要做的事在不查脉搏与在（（走五十米））。第二条是暴露，它是多数焦虑障碍最有效的一步：分级的情境在（从最容易的开始，每一步留在里面直到焦虑下降一半而非逃出来）；对强迫则是暴露之后不做强迫行为在（摸门把手而不洗手，不向家人求证）；剂量要足够，“两周一次的心理门诊谈话”不是暴露治疗，而服务的常见失败恰恰是名义上有心理治疗而实际没有暴露。第三条是药物：选择性血清素再摄取抑制剂或（在若干的）血清素与去甲肾上腺素再摄取抑制剂对惊恐与广泛性焦虑与强迫均有效，但要交代两件事——起效要四到六周、最初的两周可能更焦虑所以从半量起在（在惊恐中尤为重要）；强迫常需要更高的剂量与更长的时间在（十二周才判断疗效）。苯二氮类的地位要讲清：它有效、快、并且在恐惧症前的短期使用或在（严重的失眠的几天）里合理，但它损害暴露学习在（在药里完成的暴露不会留下新的记忆）并造成依赖与在（停药时的反跳），因此不能既是唯一的药又是长期的药；戒断要在稳定期以每二至四周减十分之一的速度进行，并在减到后半段放慢。第四条是生理与生活的调整：把咖啡因与能量饮料降下来在（这一条常在两周内产生可测量的差别）、规律的睡眠与活动、以及在（酒精的自我治疗的解除）。第五条是服务的形态：多数轻中度病例可以在初级照护内以在书写的或在基于网络的认知行为课程与在（（护士的随访））完成；重者与在有自杀与在（物质共病）者进专科；而“等待十二周后再谈”的中间安排最糟，因为它把治疗的时间变成了症状固化的时间。最后要有一张可测量的表在（焦虑的量表每二周一次），因为焦虑的治疗在“感觉差不多”时最容易被悄悄中断，而中断的时机决定了复发（[[pharmacology/dosing-principles]]、[[pharmacology/adverse-reactions]]、[[psychiatry/mood-disorders]]、[[public-health/prevention-promotion]]）。**
:::

::: example 心内科的旋转门 {#ex-panic-cardio}
一名35岁的女性在半年内做了两次冠脉造影与三次动态心电，全部正常；她仍每天摸脉搏数十次，不敢独自去超市；她的医生准备“再约一次核磁”。
::: solution
**她已经得了两次病：惊恐障碍，以及被检查维持的健康焦虑（[[#def-threat]]、[[#def-anx-treatment]]）。要做的第一步不是加检查而是停止加检查，并由同一个人把这句话说清楚：冠状动脉与心电与核磁的结果一起把危险的可能性压到极低，而每天摸脉搏会让她的心跳成为注意的对象，从而制造更多的心跳不齐的主观体验。要写一份共同的计划：一位负责的医生在（避免多头问诊）、一份“不再做的检查”清单、以及一个明确的替代动作在（不摸脉搏，改测步数）。第二步是治疗本身：把过度换气的循环讲给她，并让她在现场故意做出头晕在（快呼吸三十秒）以取得对症状的控制感；开始分级暴露在（先在超市门口站五分钟，再进到有人的通道）；同时给选择性血清素再摄取抑制剂并交代最初两周可能更慌。第三步是安排随访的节律在（两周一次，配一张焦虑表），并在每次随访时删掉一项回避而不是问“今天感觉如何”。要处理她的信念在（“万一这次是真的呢”）：不是辩论，而是把不确定性变成可以带着走的东西在（“我们可以带着百分之三的可能继续生活，你已经在做了”）。最后写一封给初级照护的信，明确“若再有胸痛，除非伴在持续与在冷汗与在（晕厥），不再重复影像”，这条规则能保护她（[[clinical-skills/clinical-reasoning]]、[[cardiovascular/coronary-artery-disease]]、[[clinical-skills/communication]]、[[clinical-skills/records-handover]]）。**
:::

::: example 失效的药片 {#ex-benzo-taper}
一名52岁的女性服阿普唑仑0.5毫克每日三次已六年，最近“药效过了”、要求在睡前加一片；她有抑郁在治，近期丧偶；她的全科不敢直接谈停药。
::: solution
**这不是病情恶化到需要加量，而是耐受的表现：同一剂量能覆盖的时间变短、剂量之间出现戒断的焦虑，被误读为“焦虑复发”（[[#def-anx-treatment]]、[[pharmacology/dosing-principles]]）。要谈的次序：先承认这六年她的功能确实靠它维持、不指责开药的她或他；再解释耐受与依赖不是成瘾的道德问题而是生理适应；最后给出一个由她选时间的计划，而不是“今天开始减”。计划要具体：把不规律剂量固定成时间表在（等分的三次），必要时换成半衰期更长的品种在（地西泮的等效换算）以抹掉剂量的谷底；随后每二至四周减十分之一，在最后四分之一段放慢到每四周减一点；把减药的日子避开已知的压力事件在（丧亲的周年纪念）。同时把能替代疗效的东西补上：暴露的练习与在失眠的在（（行为的处理））与在（抗抑郁药的剂量复核），因为在减药期出现焦虑时，如果没有任何可加的东西，她只能回到药片。要提前告知反跳的症状在失眠与在触电感与在（（对光的敏感））并区分它与复发在（反跳在减量的第二天出现、几天内缓解），给她一份书写的日程表与一个可以随时联系的电话。若在某一档停滞数月，把它当作新的基线而不是失败；而若她最终决定只减到某一低剂量长期停不下来，也应被坦率地讨论而不是暗中加量或 突然停药，因为突然停用苯二氮类可以引起癫痫（[[psychiatry/mood-disorders]]、[[pharmacology/adverse-reactions]]、[[geriatrics-palliative/polypharmacy]]、[[clinical-skills/communication]]）。**
:::

::: example 家人要求做的影像 {#ex-checking-son}
一名27岁的男性的父母坚持要给他做头颅核磁，因为他“这两个月总说头里不舒服、想事情想不停”；他的检查与神经系统体格正常；他自己在场，说“你们查吧，我无所谓”。
::: solution
**先分别听两个人说话，因为他们的诉求不同（[[#def-threat]]、[[#def-anx-treatment]]、[[clinical-skills/communication]]）。他所谓的“头里不舒服”多半是紧张性头痛与颈部的僵硬与失眠的描述，而“想事情想不停”是广泛性焦虑的核心；他的“我无所谓”是放弃争取的表达，不是安心。父母的诉求常被两件东西驱动：害怕“如果有东西没查出来”，以及需要证明儿子的病是真的在（“你看，不是他懒”）。处理方式是给一次真正的神经系统的检查在眼底与在颅神经与在（（病理反射））并当场告知正常，然后说明为什么这次的核磁可能有害在（偶发的无意义的发现会制造新的焦虑与更深的探查），并把“如果……我们就查”写成明确的红旗在清晨加重的头痛与呕吐与在新发的癫痫与在肢体的无力与在（视力的下降）。随后给他一次单独会谈：直接问情绪与在（自杀）与睡眠与在（工作的压力）与在（物质的使用），因为在被父母代言的年轻人中，真正的痛苦常在最后一分钟才被说出口。治疗上从行为入手在睡眠的规律与在（（活动的增加）），并把父母纳入一次会谈，交给他们一件有用的任务在（不再问“你今天头疼吗”，改为约他每周一起走两次路）——因为家人的反复询问就是检查的一种形式。最后写下复评的时间在（四周）而不是“有事再来”（[[psychiatry/psychiatric-assessment]]、[[nervous-system/headache-pain]]、[[public-health/screening]]、[[clinical-skills/patient-safety]]）。**
:::

::: example 怕蛇的兽医 {#ex-adult-phobia}
一名34岁的爬行动物兽医因怕蛇而无法工作，两年前在一次展览中被缠手腕的蛇吓到；她现在连看照片都要出汗，且反复要求同事“先检查笼子里有没有”。
::: solution
**特定恐惧症在成人中并不少见，且对治疗的反应很好，问题在于她这类对象往往一辈子不被识别为可以治（[[#def-anx-disorders]]、[[#def-anx-treatment]]）。她的工作依赖她回避的东西，因此治疗的目标要现实：不是“爱上蛇”，而是能在被要求时完成一次装笼与转运。做法是密集的分级暴露，最好在几天到一两周内完成在（若干体系中的单日疗法）而不是每周一次拖上半年：从看黑白的小图与在（不引发回避的距离上的）活体开始，每一步停留到主观的焦虑下降一半以上才进入下一步，并且每一步都由她自己发起而不是被推着做在（被迫的暴露会巩固恐惧）；关键是禁止安全性行为在（不看同事的脸色、不攥着手机、不隔着玻璃），否则新的学习不会发生。认知的一条要处理：“一旦心跳快起来我就控制不了”——用一次故意的过度换气与在（原地三十次的深蹲）来证明心跳快不会导致失控。药物在这里不是治疗，除非用于在（一次不可推迟的操作前的短期）；而苯二氮若在暴露前服用会使那次暴露失去意义，这一点必须讲清。还要处理她同事的配合在（他们每次替她检查笼子，就是一次集体维持的回避）：把计划告诉团队并请他们改为“陪她做而不是替她做”。安排两次随访以确认她没有退回原样在（回避的回升常在数周内悄悄发生）（[[psychiatry/psychiatric-assessment]]、[[clinical-skills/communication]]、[[pharmacology/adverse-reactions]]、[[public-health/environmental-occupational]]）。**

**焦虑的历史很长，但它作为一门可治疗的疾病却相当年轻。十九世纪的医生描述过一种叫做“心脏神经症”的病，见于铁路职员与电报员，表现为心悸与气短与不敢独自出门；同期的“神经衰弱”被用来命名一切以疲劳与焦虑为主的城市病，美国医生比尔德在1869年把它写成一种文明的产物。1871年，一位英国医生在报告里第一次描述了后来被称为惊恐发作的发作性事件；而真正把惊恐从心脏神经症里分离出来的，是二十世纪的两次工作：一次是1960年代在伦敦用乳酸钠诱发惊恐发作的实验——给惊恐患者输注乳酸钠会在数分钟内重现一次发作，而在其他人身上不会，这使惊恐第一次成为可以在实验室里研究的对象；一次是1980年诊断手册把“广场恐惧伴惊恐发作”写成独立的条目，从此它的流行病学与治疗试验有了共同的语言。行为疗法的出现改变了治疗的方向：1920年代，一位美国的研究者用逐步接近与食物的奖励让一个十一岁的男孩不再害怕兔子与狗，这一案例确立了系统脱敏的原理，而南非的一位精神科医生在1960年代把它发展为暴露在诊室内的现场进行，并证明对强迫症的清洗仪式，让患者接触污物而不许洗手的效果优于任何谈话。这些工作汇成了今天所有焦虑障碍治疗的核心：暴露加反应阻止。认知模型在1980年代补上了另一半：一位加拿大的临床研究者提出惊恐的关键不是心跳本身，而是对心跳的灾难性解读，于是治疗加入了针对解读的工作与故意的内感受暴露——让患者在诊室里转椅子与快呼吸，把“我以为我要死了”的感觉变成可以练习的东西。药物的历史充满了意外：苯二氮类在1950年代末被合成，因其罕见的肌肉松弛与抗焦虑作用迅速成为世界上最常开的药之一，到1970年代关于依赖的报道使各国收紧处方；抗抑郁药在1980年代末成为一线，一部分原因是它们的过量安全性优于三环类，而不是因为它们更有效；此后各国指南把心理治疗与药物并列为同等的一线，而真实世界里的服务供给差距巨大。创伤的部分走得最慢：从十九世纪的“弹震症”到越战后1980年创伤后应激障碍进入手册，其间的关键是退伍军人与（在性暴力的幸存者）的倡导让“正常的反应在不正常的情境中”被承认。1990年代之后，创伤聚焦的认知行为治疗与眼动脱敏与再处理被反复检验，前者在多数指南中被列为一线，而“所有人在急性期都应该做一次心理清创”的说法被证据推翻，这成为精神卫生领域少见的、明确纠正了善意做法的例子。最近的争论集中在两个方向：一是数字化的课程与在（基于手机的干预）能否解决等待名单的问题，试验显示对轻中度有效而对重者不足；二是在（迷幻药辅助治疗）在创伤后与终末期痛苦中的复兴，其早期的结果令人注意，但试验设计上的困难——受试者几乎不可能被设盲——让疗效的估计仍不确定。这一段历史对本章的意义是一个提醒：焦虑障碍最有效的治疗方法是被实验室与诊室里的观察而不是被理论发现的，而它至今仍然常常没有被人用上。**
:::
::: summary
- 焦虑是防御系统对未定威胁的持续动员；回避与安慰在短期有效、长期维持症状。
- 惊恐的解释要具体到过度换气的循环，并且必须配一件本周要做的行为。
- 暴露是多数焦虑障碍的核心，剂量要足；在服用苯二氮之后完成的暴露不产生新的学习。
- 抗抑郁药四到六周才见效，最初两周可能更焦虑，因此从半量起并事先说明。
- 六年的苯二氮类“失效”是耐受而不是病情恶化；减量以每二至四周十分之一，后半段放慢。
- 反复的检查是健康焦虑的治疗对象之一；写下“不再做什么”与“出现什么才查”两份清单。
:::

::: exercise 追问心悸 {level=1}
一名31岁的男性反复心悸，每次三到八分钟，伴手麻与“要死了”的感觉；四次急诊心电正常；他说“我就是怕下一次”。请给出诊断与四条处置。
::: solution
**这是惊恐发作伴预期的焦虑，“怕下一次”正是从发作到障碍的那一步。四条处置：一，用一次现场的诱发证明心跳可以被他主动加快而不危险在（原地三十次深蹲或快呼吸三十秒），把症状从“发作”改写成“反应”；二，讲清过度换气的机制，把手麻归到二氧化碳的下降，并练缓慢的鼻吸与在（延长上的）呼气；三，停止反复的自行测脉搏与在（再查一次的安排），改为一份红旗清单在与运动相关的晕厥与在家族中的猝死与在（（持续数小时的心动过速））；四，给暴露的作业与在（每周两次的记录），并按严重度决定是否加药在（选择性血清素再摄取抑制剂半量起）（[[#def-anx-disorders]]、[[#def-anx-treatment]]、[[cardiovascular/arrhythmias]]）。**

::: exercise 处理创伤后的披露 {level=2}
一名患者在第五次会谈中第一次说出生殖器的暴力经历并出现解离、说不出话；她随后要求取消后续预约。请写出你的处理。
::: solution
**不要把披露当作治疗的开始点，而要把“她现在能否安全地待在这里”当作唯一的目标。当下：停止追问，把注意力放回身体与环境在说出地点与日期与在（（让她描述房间里的三样东西）），用她能接受的语调说明“我们不需要再谈细节，今天已经够了”。随后：允许取消，但要留下一个可及的联系方式与一个具体的日子在（两周后，哪怕只谈十分钟），因为创伤后障碍的脱落常发生在披露之后的一周内。要做的评估：自杀的风险与在（当下的安全，包括她是否与施暴者同住）与在饮酒与在（睡眠）。要说明治疗的形式与她的选择权：创伤聚焦的治疗有效但需要她准备，稳定睡眠与在（对触发物的应对）可以在先；不在她未同意时反复邀请她谈细节。记录要写她自己的话与在（她希望的下一步），并写明保密的例外在（若家中有其他儿童需要保护）。转介到有能力的服务，并把你的角色说清楚：不是替代创伤的治疗，而是维持安全与可及（[[#def-anx-disorders]]、[[psychiatry/self-harm-suicide-prevention]]、[[medical-ethics-law/confidentiality]]、[[clinical-skills/communication]]）。**

::: exercise 安排强迫症的治疗 {level=2}
一名29岁的男性有污染与反复清洗，每天三小时，皮肤破损；他曾在门诊接受“心理支持”两年无改善；他希望“先吃药，暴露以后再说”。请给出方案与谈话要点。
::: solution
**先纠正一个误会：他接受的不是焦虑障碍的治疗，因为没有暴露的支持性谈话对强迫症基本无效（[[#def-anx-disorders]]、[[#def-anx-treatment]]）。谈话要点：强迫的维持机制是仪式带来的短期缓解，所以治疗的关键不是想通污染是否真实，而是“接触之后不洗”这段时间里焦虑会自己下降的经验；药能降低焦虑的强度但不能替她做这件事，而单用药物缓解的比例明显低于药物加暴露。方案：把剂量写清楚在（选择性血清素再摄取抑制剂加到常规剂量的上限甚至更高，并在十二周时才判断疗效），因为低剂量的处方是强迫症治疗失败最常见的原因之一；同时安排每周一次、连续十二次以上的暴露与反应阻止，作业要可核查在（摸门把手后延迟一小时再洗，并记录焦虑的起止）；皮肤按外科与皮肤科处理在温和的清洁剂与在（润肤剂的规律使用），并约定洗手以外的皮肤护理不再成为仪式的一部分。要明确一条医生的纪律：不接受他的求证在（“这个真的脏吗”），而是把问题回给他在（“我们把它当作不确定来对待”），因为医生的确认是症状的一部分。最后约定一个可测量的复评在（量表每四周一次）与升级的门槛在（两次足量足疗程无效时转专科）（[[pharmacology/dosing-principles]]、[[clinical-skills/communication]]、[[psychiatry/treatments-mental-health-law]]）。**

::: exercise 评价迷幻药辅助治疗的浪潮 {level=3}
某机构准备开设“赛洛西宾辅助治疗”的门诊，面向难治的抑郁与创伤后障碍。请评价证据、风险与治理。
::: solution
**证据的一面：小样本的随机试验显示，在受过训练的支持环境中单次或两次的赛洛西宾可带来数周的症状改善，尤其在抑郁与在（终末期患者的存在性痛苦）；机制上的解释涉及在血清素2A的受体与在（（网络的灵活性）），而“心理体验的放大”与在（暗示性提高）可能是疗效的一部分而不是副作用。因此不能简单说它无效。不确定的一面：试验的设盲几乎不可能实现，导致期望效应难以剔除；样本量小、退出率的报告不一致、随访短于六个月；真正的复发与在（功能的指标）少被报告；而多项试验由少数团队完成，外部效度未知[[epidemiology-ebm/critical-appraisal]]。风险的一面：急性期的血压升高与在恐慌与在（解离）；有个人或在（强家族史的）精神病性障碍与在（双相）的人可能被诱发；自杀的风险在治疗前后都要评估；而“支持”本身是干预的核心成分，把它复制到商业门诊时最先被牺牲的恰是这一部分。治理上应要求的清单：严格的排除标准与在（药物相互作用的审查）、每次给药的在两名受训的人员与在（一整天的监护）、公开的在（不良事件的登记）与在（至少十二个月的随访）、以及在（不向未获批准的情形提供）的边界与在（转介研究的路径）。我的立场：把它放在研究或有严格许可的项目内，并在开设之前先说明“若两年后不能报告完成率与不良事件与功能结局，本门诊不应继续扩张”；对个体则不应让一个未定疗效的新疗法替代已有证据的治疗在暴露与在创伤聚焦的治疗与在（（药物的优化））（[[pharmacology/drug-development-prescribing]]、[[epidemiology-ebm/randomised-trials]]、[[medical-ethics-law/research-ethics]]、[[psychiatry/mood-disorders]]）。**

::: exercise 说出这个模式 {level=1}
为下列四种表现各给最可能的类别与首选治疗：连续三个月对一切事情担心且颈部僵硬；只在演讲前发作、平时正常；每天洗手四十次；地震后两个月反复噩梦且绕路避开原地址。
::: solution
**广泛性焦虑：核心的动作是“担心本身”，首选是解释加在基于认知行为课程的或在（（药物的选择）），并处理睡眠与咖啡因。特定恐惧症（演讲）：只在可预期的情境中即刻发作、其余时间正常，首选是技能的练习与在（分级暴露）与在若干情形中的在（表演前的短期药物），而不是长期的药。强迫症：仪式占去时间与消耗生活，首选是暴露与反应阻止加足量的血清素再摄取抑制剂，并判断要等到十二周。创伤后应激障碍：暴露史加在（重现与回避与高唤起）且超过一个月，首选创伤聚焦的治疗，而不是单纯的支持性谈话。共同的一点：这四种病的首选治疗都不是“先吃点镇静药看看”（[[#def-anx-disorders]]、[[#def-anx-treatment]]、[[psychiatry/self-harm-suicide-prevention]]）。**

::: exercise 开出第一张处方 {level=2}
一名38岁的女性首次诊断惊恐障碍，症状每周三次，未用药物，合并轻度哮喘，希望“别让我发胖、别让我上瘾”。请写出你的处方与交代。
::: solution
**处方：选择性血清素再摄取抑制剂在（舍曲林或艾司西酞普兰），从常规起始剂量的一半开始，一周后加到全量，四到六周判断疗效；同时说明她的三个顾虑分别对应什么——体重：这两种药的体重影响在多数人中有限，若明显增加可换在（安非他酮以外）的方案再议；成瘾：它们不产生渴求与觅药行为，但突然停用会有撤药的不适，因此减药要按计划在稳定期缓慢做；“别让我更慌”：最初的十到十四天可能短暂加重，这是已知的、可预期的、不危险的，必要时可在这两周内限量给一次苯二氮在（不超过七天）或在（按需要的普萘洛尔），并说明哮喘 者用普萘洛尔需谨慎。交代时间表：两周首次复诊在不看疗效，只看副作用与在（（有没有回避的回升））、六周复评严重度、缓解后维持至少十二个月。最后配一件行为的作业在每周两次把心率提起来的运动与在（一次超市的短时暴露），并明确“药让暴露更容易被完成，不能替它”（[[#def-anx-treatment]]、[[respiratory/asthma-copd]]、[[pharmacology/dosing-principles]]、[[pharmacology/adverse-reactions]]）。**

::: exercise 应对反复求安慰的人 {level=2}
一名健康焦虑的患者每天给你与护士打五到八个电话，问同一个症状；团队疲惫，有人主张“给她约一次检查把她安抚下来”。你怎么处理？
::: solution
**约检查会让她的焦虑今天下降，并让电话在明天变多，因为求证被奖励了（[[#def-threat]]、[[#def-anx-treatment]]、[[clinical-skills/patient-safety]]）。要做的是把“确认没有病”换成“确认有安排”：指定一名负责的医护在（一个名字而不是一个科）；把电话改为每周两次的固定时间在（每次十五分钟）；给一份书写的红旗清单，说明出现哪些情况要立刻联系而其余一律等到固定时间；把“今天要不要检查”从每次通话的内容里移除。这一步一定会让她的焦虑短期上升，这属于治疗的一部分，需要在第一次就把话说清在（“前两周会更难受，因为我们在撤掉一个暂时有效的东西”）。团队层面：统一口径在（任何人不得回答关于是否得病的问题，只回答“我们周五谈这个”），并把疲惫写进交接而不是私下抱怨，因为不一致的回应是最强的强化程序；给团队十分钟的复盘在（每两周一次）以维持这一纪律。同时治疗焦虑本身在解释的重复与在（（暴露于身体的感觉））并筛查抑郁与在（自杀）。若她出现新的、性质不同的症状，按红旗处理并做检查在（该查就查），因为纪律不等于忽视（[[clinical-skills/communication]]、[[clinical-skills/records-handover]]、[[public-health/screening]]）。**

::: exercise 批评这套服务 {level=3}
某地的焦虑障碍服务只提供“每周一次、共十二次的谈话治疗”，平均等待十九周；重度者以苯二氮类维持。请批评并给出改革方案。
::: solution
**三个结构性缺陷（[[#def-anx-treatment]]、[[public-health/health-systems-economics]]、[[clinical-skills/patient-safety]]）。第一，名义上有心理治疗而实际没有暴露：每周六十分钟的谈话不产生新的学习，而证据要求的是一次接一次的现场暴露与作业，因此完成率与效果都很差；改革是把课程的形态改成“密集、短程、可核查”，包括若干体系中的单日恐惧症门诊与在（以暴露为核心的五到八次短程治疗）。第二，十九周的等待把可治的早期变成慢化的晚期：中间用在书写的或在（（基于网络的课程））覆盖轻中度，并把第一次接触做成“解释＋一件作业＋时间表”的一次门诊，这一步能显著降低随后的治疗需求。第三，把苯二氮当作重度者的维持方案是反向的选择：它阻碍暴露并制造依赖，尤其对未接受任何治疗的人；改革是给出减药的路径与并行的行为治疗，并且把“没有替代就减药”列为禁止的做法。测量的指标应为：暴露是否在记录中被写明、症状量表在第十二次的改变、等待的实际天数、苯二氮的新开率与在（减药的成功率）、以及完成率而不是预约率。资金上，密集短程的单价看似高，但按“每一例缓解的成本”计算通常优于长程低强度在（这也是英国心理治疗普及项目在评价方法上的贡献）。最后要保留一条：重度与共病者需要专科，改革不能把所有人都推向自助（[[psychiatry/self-harm-suicide-prevention]]、[[pharmacology/adverse-reactions]]、[[public-health/prevention-promotion]]）。**
