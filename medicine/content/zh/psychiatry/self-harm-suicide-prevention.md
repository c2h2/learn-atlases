自杀与自伤的预防是精神科里唯一“问一句就能改变结局”的领域：**风险的窗口是短而可以预期的，而服务常常把力气花在窗口之外；有效的做法并不神秘——直接地问、按行为的严重度而不是按勇气分级、在离开的当下就安排好下一次的接触、并把手段的可及性降下来。**本章覆盖风险的询问与判断、自伤作为独立的对象（其功能与管理与制度周围的误区）、以及跨越时间与人群的预防（高危期与学习、以及人群层面的手段限制）。

## 询问与判断

::: definition 自杀风险的评估 {#def-assessment}
**风险评估的产出不是分数而是行动。要问的清单要直接：是否想过结束自己（频率与强度与持续的时长）；是否有过计划（时间地点与方法）；是否有过准备与尝试（在几个月内的）；是否已经选定并保留手段；是否有自伤的历史（最强的单一预测之一）；最近的失去与在羞耻与（在债务与（在急性疼痛上的））；是否独睡与是否刚出院与是否刚停止饮酒；精神科的诊断与（在家族中的）自杀；以及保护的因素（孩子与信仰与对方法的顾虑与愿意谈）。问“想死”不会把念头放进一个人脑中，这一点已被反复证明；不说出口的假设才会造成漏诊。要把“意念”与“意图”与“计划”与“行为”分开记录，并写下你据以行动的原话。风险的时间性最关键：住院后的一周与出院后的一至三个月、自伤就诊后的数月、丧亲后的第一年、以及诊断告知后的短期，都是倍数升高的窗口；因此“她今天说不想”不能替代“两周后谁见她”。也要用行为分级：一次在高致命的地点的尝试与一次在冲动下的过量，含义不同；反复的自伤不等于高风险的自杀，但两者常共存。评估之后必须落到三件可核查的事：把手段移出在药与（在枪与（在若干的农药上的）并说明由谁保管）、把下一次接触定到具体的日子与时间、把危机联系方式写成一张她带得走的纸（[[psychiatry/psychiatric-assessment]]、[[psychiatry/mood-disorders]]、[[emergency-critical-care/poisoning]]、[[psychiatry/treatments-mental-health-law]]）。**
:::

## 自伤作为独立的对象

::: definition 自伤的功能、处理与制度 {#def-selfharm}
**自伤是故意的、自己不打算致死的对自身身体的伤害，它在青少年与年轻成人中的终身比例可达一成上下，且多数不寻求死亡。它的功能是可被问出来的：把情绪的痛苦换成身体的痛、停止解离或麻木、惩罚自己、让内在的混乱有一个可见的形状、或让说不出口的事被看见。理解功能决定了替代：为“要感觉”的人提供冷水的强烈感觉与（在剧烈运动上的）替换，为“要停止感觉”的人提供接地与规律的作息，为“要惩罚自己”的人提供自我同情的工作，为“要让人看见”的人提供可以求助的渠道与不惩罚的回应。管理的原则有五条：一是不要用愤怒或羞辱回应（一次“你又来了”会让下一次的求助变成更重的一次伤害）；二是不要在急诊制造不必要的住院（对多数人，短时间的、有明确计划的、由同一个人接手的路径更好）；三是把伤口的处理规范化在缝合与（在破伤风与（在抗生素的滥用上的）的节制）；四是把治疗的门打开在辩证的行为取向的技能与（在（情绪的调节的工作上的））；五是筛查被隐藏的经历在性方面的暴力与在忽视与（在欺凌上的），因为披露往往发生在治疗关系的第三或第四次而不是第一次。制度周围的误区也要说清：把自伤当作“人格障碍的特征”而拒绝服务；用“不能缝，缝了会强化行为”的说法让患者带着可以处理的伤口离开（这一说法没有依据）；用两次爽约即结案的政策排除最需要连续性的人；以及在病历里写下评判性的句子。自伤最强的可改变预测是既往的自伤，因此每一次就诊都是干预的窗口，而不是需要被忍耐的成本（[[psychiatry/psychiatric-assessment]]、[[psychiatry/eating-personality-disorders]]、[[clinical-skills/communication]]、[[paediatrics/adolescent-health]]）。**
:::

## 跨越时间与人群

::: definition 跨时间与人群的预防 {#def-prevention}
**预防有三层时间。个人的时间：识别高危期并在其中加密接触（出院当日与第一周与第一个月），把手段的可及性降低在药量的小包装发放与在枪的安全保管与（在农药的替代上的），并在每一次接触中给一份具体的下一步。服务的时间：把“离开”设计成有名字有电话的时间点而不是一个信封（在若干体系中，出院后的七十二小时内的电话能把后续的就诊率显著提高到九成以上）；把重复自伤者交给同一支团队而不是每次不同的人。人群的时间：多数自杀发生在精神科的门诊之外，因此初级照护与学校与急诊与在（（在农村的）的劳动与农业的服务）都要有可执行的筛查与转介；同时限制方法与地点的危险在桥梁的屏障与在煤矿气的去除与在若干的（在镇痛药的包装上的），这是本领域唯一“不需要患者配合也有效”的干预，其在若干国家的长期效果可以在总死亡率上看到。还要处理学习效应：同一社群内的模仿性自杀是真实的，因此媒体报道与学校的回应要按指南在不写方法与细节与在不美化与（在（给出求助的渠道上的））；而对因自杀失去亲人的人，他们的自杀风险升高数倍且持续数年，因此丧亲的支持不是安慰而是预防。污名仍然是核心障碍：它让求助延后，让家属隐藏病史，让服务把力气花在证明“她不是真的想”上；减少污名的最有效方式不是海报，而是让每一个见到她的人在病历上写下她说的话并给出下一次的时间（[[public-health/prevention-promotion]]、[[public-health/determinants-inequalities]]、[[psychiatry/treatments-mental-health-law]]、[[emergency-critical-care/resuscitation]]）。**
:::

::: example 本应不同的出院 {#ex-discharge-window}
一名29岁的女性在服过量后住院三天，情绪好转、说“我再也不会这样”，家属签字接她回家；出院小结写着“不适时随诊”；她的柜子里还有前两次处方剩下的药。
::: solution
**出院后的第一周与第一个月是自杀的最高危期，而“看起来好了”在这段时间里最不可靠。要改的三件事：第一，把手段拿走——直接问柜子里有什么、有多少、由谁保管，并把剩下的药收走或换成小包装的发放，这一条比任何安慰都有效。第二，把下一次接触定到具体的日子与时间（在若干体系中的四十八至七十二小时内的电话与七天内的面谈），并在小结上写下联系人的名字，让门诊不必从零开始认识她。第三，让接她的人知道要看什么（睡眠的恢复与回避的减少与把东西送人这类信号，以及“她说好了很多”并不等于安全）。还要处理她自己的计划：一份她写的恶化计划（早期信号与对应的动作与可以联系的人）与一份危机时的联系方式，两份都要她带走并录进病历。最后，把这次住院的原因与她未来的风险用平实的语言写给初级照护，而不是只写“情绪障碍”，因为下一个在深夜面对她的人需要知道她上次用了什么方法（[[#def-assessment]]、[[#def-prevention]]、[[clinical-skills/records-handover]]、[[psychiatry/mood-disorders]]）。**
:::
:::

::: example 青少年的短信 {#ex-adolescent-selfharm}
一名15岁女生的母亲拿到女儿与同学的聊天记录，里面有切割的照片与“下次一起”的话；女孩否认想死，只说“大家都这样”；校方向导建议“通知全班做筛查”。
::: solution
**先分清三件事：她的风险、同伴的风险、以及学校的反应是否安全。对她：自伤在青少年中常见且多为情绪的调节，但“一起”的话意味着群体的功能，需要单独会谈（不带母亲）与直接的询问与（对伤口的）处理与一次关于求助渠道的约定；不要把她的否认当作低风险的全部证据，也不要因为她说“大家都这样”就把它正常化。对同伴：照片里的另一名学生必须被联系，因为她可能风险更高；联系的方式要经过她（除非有紧迫的危险），否则会摧毁仅有的信任；随后由学校的心理人员按个案处理而不是集体审判。对学校：“全班筛查”在没有配套支持时通常弊大于利（它会制造标签与模仿，并让被筛出问题的人无处可去）；替代的做法是给教师一份“如何回应与如何转介”的简短培训、把可用的联系方式贴出来、并对班级做一次按指南的、不写方法的讨论（在若干体系中的“不渲染”原则）。对家长：他们害怕且可能没收她的所有东西与日夜守着，这需要引导在把刀与药收好这件事上是对的，在（在（彻夜盯守与（在搜查手机上的））上会造成对抗）；也要问家里是否有其他兄弟姐妹需要关注。最后把两周内的复诊与（在需要时的）儿童精神科的转诊落实，并把“下一次她想在夜里找人时可以打给谁”写成一行字（[[paediatrics/adolescent-health]]、[[#def-selfharm]]、[[public-health/prevention-promotion]]、[[clinical-skills/communication]]）。**
:::
:::

::: example 好转中的人并不安全 {#ex-early-improvement}
一名48岁的男性在重度抑郁治疗四周后回诊，说自己“轻松多了，不想麻烦你们再来”；他上周围绕了病房送自己的书；他的睡眠刚恢复；他在两年前有过一次高致命的尝试。
::: solution
**这是本章最危险的一种情形：精力先于心境恢复。抗抑郁治疗起效时，动作与计划的恢复常早于绝望感的消退，因此“他开始做事、送东西、说不再麻烦别人”可以是决定已经做好的迹象，而不是好转的证据。要做的事：不要接受“我好了”作为结束，用同一份量表复评并把过去的尝试与家族的自杀明确列入判断；直接问现在是否想过、是否有计划、是否已经选定了方法与时间（问这些不会植入念头）；把手段再一次移走并让家属在场时说明由谁保管；把随访的间隔缩短（在若干体系中的每周一次，持续数周）而不是拉长；并解释清楚为什么“感觉好一些”时恰恰需要继续来，用他能接受的话（在睡眠的恢复与体力的恢复会先于心情的稳定上的）。如果他拒绝进一步的接触：说明担心的具体内容与你可以提供的最低强度，并保留再次接触的路径与（在必要时）为他的安全做的评估；不要让他觉得被扣留。同时给他一次“活着的支持”的工作：债务与婚姻与在（工作失去上的）这些维持绝望的现实问题，往往比再增加一种药更能改变结局（[[#def-assessment]]、[[psychiatry/mood-disorders]]、[[psychiatry/treatments-mental-health-law]]、[[clinical-skills/communication]]）。**
:::
:::

::: example 年老农民的决断 {#ex-older-male}
一名76岁的果农在妻子去世后两年不出门、“不麻烦孩子”、把农具与药整理好送人；他因胸痛被送来，检查正常；他否认心情不好，说“我没什么，就是想睡”。
::: solution
**这一组细节——独居的老年男性、丧亲、慢性躯体病、把东西送人、拒绝求助、否认情绪——构成高致命风险而不是低风险，因为在这些人中自杀常是长期计划后的单次行动，且在医院里几乎不表达念头。做法有五条。第一，用躯体与功能的语言进入：谈胸痛与睡眠与（在疼痛与（在便秘上的））与“最近能不能上楼”，比问“您是否抑郁”更能得到答案；同时仍要问一次自杀，直接而尊重。第二，把身体的检查做完：老年抑郁的假性认知下降与在甲的低与（在钠的紊乱与（在药物上的））都可能是原因之一。第三，把手段拿开：家中有农药与（在若干体系中的）枪枝时，要具体到“这一周内由谁把这些带走”，并说明这是暂时的（在若干研究中，暂时移出与延长获取的距离是可测量的保护因素）。第四，让家人参与并取得她的同意：他的“不麻烦孩子”是文化性的克制，可以请女儿来一次门诊在（（在她能听到的范围内））而不是被排除在沟通之外。第五，安排可见的接触：出院后的三日内电话、一周内初级照护的访视、（在若干体系中的）社区的照护与农业服务的介入与在（在（白天的活动上的））的重建；并给他一个具体的小任务（在若干项目中的“每日一次的电话”由护士或同伴完成）。要说的一句实话：他这个年龄段的男性完成自杀的比例最高，而“他没说什么”从来不是安全的证据（[[geriatrics-palliative/ageing-frailty]]、[[#def-prevention]]、[[endocrine/thyroid]]、[[clinical-skills/communication]]）。**

::: history
**自杀的预防史是一部“该由谁负责”的历史。十九世纪的道德与法律把自杀未遂者当作罪犯对待，尸体解剖与财产没收的残余在若干国家持续到二十世纪中叶，直到教会的立场与法律的改革使其去罪化；同一时期，涂尔干的社会学把自杀写成社会整合的产物，把解释从个人道德移到了人群的结构，这一视角至今仍是预防工作的地基。医学接管的过程从二十世纪的流行病学开始：自杀被作为可以分类、可以随访、可以干预的结局来研究，而1960年代英国的几项研究确立了此后最重要的两条经验事实：一是自伤后的数年内再次自杀的风险显著升高，二是这一风险在最近的数月最为集中；这直接催生了自伤的门急诊随访门诊与专门团队。危机干预的兴起与 电话相伴：1958年伦敦的萨马利滕中心与（在若干国家的）同类志愿机构把“随时可打的电话”变成一项制度，其证据基础在几十年间一直薄弱，但其在真实世界里的作用在后续的国际综述中得到支持，并成为各国策略的标配。方法的限制是被偶然发现的：英国在1950至1960年代把家用煤气的一氧化碳含量大幅降低，随后自杀总数下降，而被限制的这一方法的自杀几乎完全消失且没有明显的替代；类似的发现后来在若干岛屿与国家的农药的禁用与在（在跳楼地点的屏障与（在药品包装的小份化上的））上重复，使“限制手段”成为预防中证据最强、争议最小的一条。媒体的角色在1980年代后被认识：模仿性的自杀与“维特效应”被反复记录，于是世界卫生组织与各国的记者协会制定了报道的指南——不写方法、不渲染、给出求助渠道——并在若干国家与在线平台的算法管理结合。去污名的运动与幸存者组织在英国的丧亲者协会与（在其他国家的同类组织上的）让家属从被责备的旁观者变成预防的参与者，也揭示了丧亲者自身升高的风险。最近二十年，公共卫生的框架与高危个体的临床管理并置：各国的国家策略把数据监测与方法的限制与初级照护的培训与学校的课程与在（在农村人群上的）的农业安全写在一起；而临床侧的新工具在若干数字的电话与短信的随访与（在电子的预警的评分上的）在试验中效果参差，提醒人们：真正起作用的常常不是新技术，而是有人在具体的日子打来了具体的电话。这一段历史中反复出现的结论只有一个：自杀多数发生在冲动与可得性的交汇点上，而预防就是把这两者分开一点（[[public-health/prevention-promotion]]、[[emergency-critical-care/poisoning]]、[[psychiatry/mood-disorders]]、[[medical-ethics-law/ethical-principles]]）。**
:::
::: summary
- 风险评估的产出是行动而不是分数：手段、下一次接触的时间、与一张她带得走的联系方式。
- 询问自杀不会植入念头；不直接问才是漏诊的主要原因，而意念、意图、计划、行为要分开记录。
- 风险是时间性的：出院后早期、自伤就诊后数月、丧亲后第一年，按窗口配置资源。
- 自伤有可被问出的功能，替代要对着功能给；羞辱与“两次爽约即结案”会直接抬高下一次的严重度。
- 好转的早期不安全：精力先于心境恢复，送东西与突然的平静需要当天重新评估。
- 限制手段是少数不需要患者配合就有效的干预，包括药量的小包装与家中危险品被暂时移走。
:::

::: exercise 按致命性而不是勇气分级 {level=1}
为下列三次就诊各评风险的高低并给出即刻的处置：吞下自家所有药并被邻居发现；在高处犹豫后被路人拉住；反复在前臂切割以求“让脑子停一下”。
::: solution
**第一例：高。方法已选定并囤积、被动中断（在“被发现才停下”的含义上）意味着意图明确，需要当天的精神科评估与收住的考虑与在（把家中剩余药物移出上的）的落实。第二例：高。地点的选择与未遂的犹豫同样是行动，路人的干预只是运气；需要询问计划的细节与时间的选定与在（是否有告别的举动上的），并把随访加密。第三例：中低但不可忽略。功能是调节而非求死，风险在“方法升级”与在（共病的抑郁与酒精上的）；处置是伤口的规范处理、一次不带评判的功能询问、在（技能替代上的）的转介与两周内的复诊，而不是住院或加药。共同的记录要求：写下她说的原话与你的判断与做了什么，并说明下一次接触的时间（[[#def-assessment]]、[[#def-selfharm]]、[[clinical-skills/records-handover]]）。**
:::
:::

::: exercise 建立安全计划 {level=2}
一名有自杀史的患者同意写安全计划。请写出六个层级并说明它与“不许伤害自己的合约”的区别。
::: solution
**六个层级：一，她自己的警告信号（可观察的：不接电话与凌晨醒与开始整理东西）；二，可以自己做的应对冷水与出门与在（（给某个人发消息上的））；三，可以联系以分散注意力的两个人与电话；四，可以求助的两个专业渠道（含夜间）；五，把手段交托或移走的具体安排与由谁执行；六，她认为值得活的一件事（人名或事，不是抽象的“要坚强”）。区别在于：书面“合约”（承诺不伤害自己）既不能预测风险也不能降低风险，还会让患者在违约后隐藏念头；安全计划是给她与团队的一份动作清单，且假定念头会来。写完后要演练一遍，复印三份，并把“下一次复评的时间”写在同一页（[[#def-assessment]]、[[clinical-skills/communication]]、[[psychiatry/self-harm-suicide-prevention]]）。**
:::

::: exercise 处理受虐的披露 {level=2}
一名十九岁的女生自伤后在第三次会谈中透露幼年遭到亲属的性侵害；她要求“不要告诉任何人，包括我母亲”。
::: solution
**先接住再决定：感谢她说出来、明确这不是她的错、说明你会遵守保密但在何种情况下必须突破（对她现在的安全风险与对其他儿童的风险），并把这一整套规则一次性讲清，因为她很可能在过去被告知“别声张”。然后评估当下：侵害者现在是否仍能接触到她或家中有无其他儿童（在这类情形中常有需要保护的其他孩子，这可能构成保密的例外）；她目前的风险（披露后自伤常短暂加重）；以及她的现实安排（居住与经济）。转介：按本地的路径联系性暴力的支持服务与（在需要时的）儿童保护或成人保护的程序，并把“是否报案”的选择权留在她手上，但要说明各选项与她能得到的支持；不要在她未同意时突然替她报案，除非有迫切的危险。治疗上：创伤的工作在她稳定且有支持之后再开始，早期以稳定与睡眠与在（解离上的）的处理为主。记录要写她自己的话在（可能的范围内）并说明你告知她的保密例外（[[#def-selfharm]]、[[medical-ethics-law/confidentiality]]、[[clinical-skills/communication]]、[[paediatrics/safeguarding]]）。**
:::

::: exercise 把调查变成预防 {level=3}
本地区一年内发生六起自杀死亡并有多起严重自伤，验尸与调查提出了若干建议。请设计一套“把调查变成预防”的机制。
::: solution
**机制要有四个部件。一，中央的台账：每一起死亡与每一宗调查建议被录入同一处，标明责任方与时限，并由一个季度会议跟踪是否完成；多数地区的失败不是没有建议，而是没有人在半年后核查。二，分类与规律：把方法、地点、时间窗、接触服务的经历、在（是否被强制治疗上的）与族群与年龄做成可分析的表，因为预防的靶点通常在模式里而不是个案里。三，个案的回顾：对每一起死亡做一次不指责任何人的系统回顾在（在哪些环节本可提供另一种接触），并把结论写成可执行的一两条改变在（出院后72小时的电话与手段的移出上的）。四，反馈给一线与家属：把学到的东西写成一页纸发到全科与急诊与学校，并让丧亲的家庭参与审阅，因为他们最常指出服务里“没人想到”的地方。评价：建议的按期完成率与在（方法特异性的自杀率上的）与在（高危窗口内的接触率上的）；同时公开尚未完成的部分，因为一个只报告成功的机制会失去信任（[[#def-prevention]]、[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]）。**
:::

## 练习

::: exercise 问出该问的问题 {level=1}
请写出你在门诊问自杀的六句话，按顺序，并说明每句的意图。
::: solution
**一，“最近有没有觉得活着没什么意思？”给退出通道，让否认可以不说谎。二，“有没有想过结束自己的生命？”直接命名，不绕。三，“这样的念头多久来一次、一次持续多久？”频率与时长比有无更能预测行为。四，“有没有想过用什么办法、什么时候？”方法与时间是意图的证据。五，“有没有为这件事做过准备，比如留信或安排东西？”准备是风险的强指标。六，“以前有没有伤过自己或尝试过？”既往行为是最强的预测之一。每句之后要问保护的因素（她在乎谁、她对方法有何顾虑）；最后用一句共同的语言收尾（“我会把这些写下来，因为它们在关键时刻能帮我们决定怎么帮你”）。这套问题不能替代判断，但能保证不会漏掉最重要的信息（[[#def-assessment]]、[[clinical-skills/communication]]）。**
:::

::: exercise 处理一次吞服 {level=2}
一名34岁女性在家中服下对乙酰氨基酚与（在若干的）阿司匹林与在（普萘洛尔上的）约两小时被送来，清醒、血压正常、化验刚开始。请给出即刻与随后二十四小时的要点。
::: solution
**三件事同时做：分期、测浓度、防迟发。对乙酰氨基酚：按服药后的时间与血浓度落在治疗的曲线上决定是否用解毒在（N-乙酰半胱氨酸上的），剂量不明或时间不明时按最坏情形处理并在四小时后复测；同时查肝功与凝血与在（酸中毒上的）。阿司匹林：早期血气可能被误读为正常，需要看酸碱与阴离子隙与在（水杨酸浓度的重复测定上的），注意在碱化尿液与在（（血液净化的指征上的））与体温的升高。普萘洛尔：即使在稳定的现在，也可能在两到四小时后出现在（心动过缓与低血压与低血糖上的）在儿童与在（（大剂量的缓释剂型上的）），所以需要监护与在胰高血糖素与在（（脂肪乳的准备上的））的可及；缓释制剂要想到在（迟发吸收与全肠灌洗的考虑上的）。全身：查在血气与血糖与钾与在（（肌酸激酶上的））与在（妊娠试验上的），观察在气道与在（（意识的可能下降上的））。精神科的一层：在她身体稳定后由同一名人员完成风险的评估与在（手段的移出上的）的安排与在（出院后72小时内的电话与七日内的面谈上的）；不要把她的这次就诊写成“情绪问题，已安慰离院”（[[emergency-critical-care/poisoning]]、[[#def-assessment]]、[[clinical-skills/records-handover]]）。**
:::

::: exercise 支持被留下的人 {level=2}
一名父亲在儿子自杀去世后第四个月被转到你的门诊：失眠、自责、“我该发现的”，并说自己也想过一了百了。
::: solution
**丧亲者自身的自杀风险升高数倍并持续数年，而他现在的表现是三件事的叠加：哀伤、创伤后的侵入与回忆、以及可治疗的抑郁与升高的风险。要做的是：一，直接评估他的自杀在他自己的计划与手段与在（（是否也开始安排事情上的）），不要把他的“想跟他去”当作正常的哀伤而略过。二，把睡眠当作急症处理在短时的药物与固定的作息与在（（白天的活动上的）），因为不眠会同时加重侵入与自杀的意念。三，处理自责的认知：不是辩论“这不是你的错”，而是把“我该发现的”改写成具体的问题在（当时你能知道什么与谁在那个时刻能帮上），并引入丧亲者的团体在（与同样经历的人说话的效果常好于与专业人士的单独会谈）。四，处理事务性的压力：休假与在保险与在（（关于死亡证明上的））与家庭内部的分歧在（常被忽略的冲突源），给他一份可以照着做的清单。五，把随访排成时间而不是条件：三周与三个月与在（周年与生日上的）这些日期前主动联系，因为“有事再来”在这类人身上从不起作用。也要照顾团队：接诊自杀逝者的家属会影响 医护人员 的判断与情绪，一次督导性的讨论是应有的配置（[[#def-prevention]]、[[psychiatry/mood-disorders]]、[[geriatrics-palliative/palliative-care]]、[[clinical-skills/communication]]）。**
:::

::: exercise 撰写一份预防策略 {level=3}
请为一个地区撰写自杀预防策略的纲要，覆盖人群、高危群体、服务与学习，并说明如何避免“文件存在而结局不变”。
::: solution
**四部分加一个学习环（[[#def-prevention]]、[[public-health/prevention-promotion]]、[[public-health/health-systems-economics]]）。人群：限制手段在药品的小份包装与家中农药与在（（枪的安全保管上的））、地点的安全改造在桥梁与在（（高危的居住楼层上的））、媒体的报道指南与在（在线平台的内容管理上的）、以及反污名的持续工作在以故事与在（求助渠道的可信性上的）而不是标语。高危群体：出院后的窗口在72小时内的电话与七日内的面谈与在（（手段的移出写入出院医嘱上的））、自伤就诊后在（交给固定的团队而非每次不同的人）、监狱与在（拘留后的第一周）、丧亲者在（主动的联系与团体的支持）、在性少数与在（跨性别的青少年上的）的青少年在学校的成人与在（可及的心理治疗）。服务：可及的危机渠道在夜间的电话与在危机的住宅替代与在（（急诊的精神科联络））、按严重度的分层治疗在（而不是所有人都收住院或所有人都回家）、以及员工的方法学培训在（如何问与如何记录与如何收尾）。学习：把每一起死亡变成台账上的一条待办在（有责任人、有期限、有公开状态），并按季度复核完成率而不是复述建议。避免“文件存在而结局不变”的三个办法：指标写的是动作在（72小时内的电话完成率）而不只是意愿；每一条目有预算与负责人；每年公布未完成的条目与原因，并把丧亲者与使用者放进评审的桌边——因为策略通常不是在专业上失败，而是在无人负责上失败（[[psychiatry/treatments-mental-health-law]]、[[clinical-skills/patient-safety]]、[[public-health/determinants-inequalities]]）。**
