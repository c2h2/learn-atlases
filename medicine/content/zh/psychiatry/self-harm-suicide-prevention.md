每一位医生都会遇到伤害过自己或正在考虑自杀的人，在急诊科、病房、全科诊所以及每一个专科都会遇到。在这些接触中他们受到怎样的对待很重要。富有同情心、不慌不忙的回应能让一个人更有可能再次求助；轻视的回应则会使其可能性降低。

本章介绍自伤和自杀是什么、有多常见、为什么个体预测如此困难、如何评估和支持处于危机中的人，以及在服务和人群层面上哪些措施能预防自杀。按照安全报道指南，本章不描述方式及其致死性。

如果本章的话题让您感到困扰，可以获得支持。在英国和爱尔兰，可随时免费拨打 116 123 联系撒玛利亚会（Samaritans）。在其他地方，当地的危机热线和急救服务可以提供帮助。

## 定义与用语

::: definition 自伤与自杀 {#def-selfharm}
- **自伤**：按 NICE 指南的用法，指故意的自我中毒或自我伤害，**无论其表面目的或动机如何**。它包括有自杀意图和无自杀意图的行为。
- **自杀意念**：结束自己生命的想法，从被动地希望不再醒来，到主动的想法和计划。
- **自杀未遂**：至少带有一定死亡意图的自伤行为。
- **自杀**：由带有死亡意图的自我伤害行为导致的死亡。
:::

NICE 有意采用宽泛的自伤定义。行为背后的意图往往是复杂的，可能随时间变化，也很难从外部判断。一个人可能通过伤害自己来应对压倒性的情绪、惩罚自己、表达痛苦或逃离难以忍受的处境，许多人会说出不止一个原因。因为某些行为看似缺乏自杀意图就视其为“不严重”是不安全的：任何形式的自伤都是日后自杀已知最强的危险因素。

用语很重要。说“死于自杀”，而不是暗含犯罪意味的“犯下自杀”。避免说“自杀未遂失败”或“自杀成功”。避免使用“博取关注”或“操纵他人”等标签，它们反映的是挫败感而不是理解，并可能导致人们得不到照护。

## 自伤和自杀有多常见？

世界卫生组织估计，2021 年全世界约有 727,000 人死于自杀。自杀是 15–29 岁人群的第三大死因，大多数自杀发生在低收入和中等收入国家。

在英格兰和威尔士，2024 年登记的自杀为 6,190 例，率为每 10 万人 11.4 例。约四分之三为男性；男性自杀率为每 10 万人 17.6 例，女性为 5.7 例。在英国，中年人的自杀率最高。自伤远比自杀常见，尤其是在年轻人中，特别是年轻女性。大多数自伤不会导致到医院就诊。

在自伤后到医院就诊的人中，日后自杀的风险大大升高。一项随访研究的荟萃分析发现，约 1.6% 的人在一年内死于自杀，是一般人群自杀率的许多倍。

## 为什么风险难以预测

在人群水平上，许多因素与自杀相关：

- 既往自伤，尤其是近期自伤；
- 精神疾病，尤其是抑郁症、双相障碍、精神分裂症、人格障碍和物质使用障碍；
- 男性、中年、离婚、丧偶或独居；
- 失业、债务和其他经济困难；
- 躯体疾病，尤其是慢性疼痛和影响独立生活能力的疾病；
- 近期的丧失、关系破裂、丧亲（包括因自杀而丧亲）、法律问题；
- 无望感，以及能够获得自杀手段；
- 童年逆境，遭受虐待或暴力；
- 某些职业和群体：例如与刑事司法系统有接触的人，以及一些遭受歧视的少数群体。

保护因素包括牢固的人际关系、对子女的责任、目标感、关于自杀的宗教或文化信念、良好的解决问题的技能，以及能获得有效的照护。

::: theorem 低基础发生率使个体预测失效 {#thm-base-rate}
由于自杀是罕见的，即使在具有多个危险因素的人群中也是如此，任何将个体划分为“高风险”或“低风险”的测验或量表的阳性预测值都很低：大多数被划为高风险的人不会死于自杀，而在确实死于自杀的人中，有相当一部分曾被划为低风险。危险因素描述的是群体；它们无法可靠地说明某一个人将会做什么。
:::

::: proof
任何分类的阳性预测值既取决于灵敏度和特异度，也取决于患病率：

$$
\text{PPV} = \frac{\text{灵敏度} \times p}{\text{灵敏度} \times p + (1-\text{特异度})(1-p)}
$$ {#eq-ppv-suicide}

假设在自伤后就诊的人中，约$p = 0.016$（1.6%）的人在一年内死于自杀，某风险量表的灵敏度为 0.8、特异度为 0.6，这对此类工具来说已是很好的表现。每筛查 1,000 人，约有 16 人将死于自杀；量表将其中$0.8 \times 16 = 12.8$人标记为高风险，漏掉约 3 人。在不会死亡的 984 人中，量表将$0.4 \times 984 = 393.6$人标记为高风险。因此 PPV 为$12.8/(12.8 + 393.6) \approx 0.031$，约 3%。每 100 名被标记为高风险的人中，有 97 人在那一年不会死于自杀；而在确实死于自杀的人中，约五分之一曾被标记为低风险。对真实风险量表的系统评价发现，其表现与此相当或更差。一个分数无法承担决定谁获得照护的重任。
:::

正因如此，NICE 关于自伤的指南（NG225，2022 年）指出，不应使用风险评估工具和量表来预测未来的自杀或自伤复发，也不应以此决定谁接受治疗或谁出院。它还建议不要依赖把风险笼统地分为低、中、高等级的做法。重点转而放在理解患者的需求以及保障其安全的计划上。

## 自伤后对患者的评估与支持

::: definition 心理社会评估与安全计划 {#def-assessment}
**心理社会评估**是由受过训练的专业人员进行的一次协作式谈话，探讨患者的处境、需求和精神健康、自伤的意义和背景、当前关于自杀的想法、使情况变糟或变好的因素，以及他们想要什么帮助。NICE NG225 建议，每一位自伤后就诊的人都应获得一次心理社会评估。

**安全计划**是与患者共同制订的一份简短、个人化的书面计划。它通常列出：危机可能正在形成的预警信号；患者可以自助的事情；能提供分散注意力或支持的人和场所；可以求助的人；专业服务和危机联系方式；以及使周围环境更安全的方法。
:::

良好实践的关键要素：

- **尊重与尊严。**以对待任何其他损伤时同样的照护、同意程序和镇痛来处理躯体损伤。解释正在进行的处理。
- **必要时先进行躯体治疗。**自我中毒或损伤的医学治疗遵循标准的急诊处理，并参考中毒信息服务的建议；绝不能因为伤害是自己造成的就延误或拒绝治疗。
- **决策能力。**如果患者拒绝针对自伤的治疗，应评估其就该决定的决策能力。有决策能力的人可以拒绝；缺乏决策能力的人可以依据《心智能力法》按其最佳利益接受治疗。可能需要紧急的上级和法律意见。
- **询问自杀。**直接而平静地询问。探讨当前的想法、计划、准备、到目前为止是什么阻止了他们，以及他们认为接下来会发生什么。询问不会增加风险。
- **让他人参与。**在患者同意的情况下，让家人、朋友或照护者参与，他们常常掌握重要信息，自身也需要支持。当存在严重风险而患者拒绝时，可以按照职业指南打破保密，但应加以讨论并记录。
- **随访。**商定接下来的计划：谁来随访、何时随访，以及患者在危机中如何获得帮助。将计划告知全科医生。

::: example 自伤后的青少年 {#ex-adolescent-selfharm}
Maya Thompson，15 岁，割伤前臂后由母亲陪同到急诊科就诊。伤口很浅。她说自己已经自伤六个月了，“为了让那些感受停下来”，并不是想死。她的母亲很生气，说她“是为了博取关注”。评估应如何进行？

::: solution
**妥善处理伤口。**在局部麻醉下清洁并闭合伤口，解释每一个步骤。

**部分评估时单独见她。**青少年在父母面前可能不会透露欺凌、虐待、性取向、物质使用或网络伤害。解释保密原则及其限度。

**心理社会评估。**探讨她想让哪些感受停下来、家里、学校和网上发生了什么、她的心境、睡眠、进食，以及现在或过去有无自杀想法。询问有无需要保护的问题。询问什么对她有帮助。

**支持她的母亲。**母亲的愤怒很可能反映了恐惧和无助。解释自伤通常是应对强烈痛苦的一种方式，而不是“博取关注”，这是 Maya 需要帮助的信号。向她提供如何回应以及在哪里获得支持的信息。

**计划。**与 Maya 共同制订安全计划，转介至儿童和青少年精神卫生服务进行随访，告知全科医生，并在征得同意后告知学校的学生关怀团队。NICE NG225 建议，自伤的儿童和青少年应由受过相应训练的专业人员评估，并且不应因为伤口看起来轻微而低估自伤复发的风险。
:::
:::

::: warning 不要根据伤情的严重程度判断意图的严重程度
轻微的损伤可能伴随强烈的自杀意图，严重的损伤也可能发生在一次很少计划的冲动行为之后。人们还常常误判自己所做之事的医学危险性。要通过询问患者在行为之前、期间和之后的想法来评估意图，绝不能根据自伤的躯体严重程度来决定某人不需要心理社会评估或随访。
:::

## 高风险时期与群体

某些时期的风险特别高，服务机构可以围绕这些时期进行规划。

::: example 出院后的那一周 {#ex-discharge-window}
Ian Gallagher 先生，46 岁，在失业和与妻子分居后因重度抑郁发作住院三周。他正在好转，计划于周五出院，独自住在一套公寓里。应做好哪些安排？

::: solution
**认识风险。**英国全国精神卫生自杀与安全保密调查（NCISH）一贯发现，自杀风险在精神科住院出院后的最初几周最高，尤其是最初一到两周。他还有若干附加因素：男性、中年、新近分居和失业，并且独自回家。

**规划出院。**尽可能避免在没有周末支持的情况下于周五出院，或安排专门的周末联系。确保已预约随访：在英格兰，标准是出院后 72 小时内联系。商定书面安全计划，包括危机联系方式。讨论实际问题（钱、住房、工作），并为他联系支持资源。在他同意的情况下，让他的家人或朋友参与。

**药物。**以适当的数量提供药物，并评估是否有任何药物在过量时特别危险。

**沟通。**在出院前或出院当天将出院小结发给全科医生和社区团队，并确保每个人都知道谁负责第一次联系。
:::
:::

其他高风险时期包括首次诊断为严重躯体或精神疾病之后、丧亲之后、法律或经济危机时期以及出狱后。在英国，风险特别高的群体包括中年男性、接受精神卫生服务的人、自伤者、物质滥用者、某些职业群体以及因自杀而丧亲的人。

::: example 早期的好转 {#ex-early-improvement}
Lucy Evans 女士，33 岁，三周前因重度抑郁开始服用抗抑郁药。复诊时她似乎更平静、更开朗、更有精力，并说自己已经“做了一个决定”，感到“很平静”。她的姐姐提到 Lucy 一直在把一些物品送人。医生应如何回应？

::: solution
**不要被虚假的好转所安慰。**在心境好转之前精力先恢复、作出决定后突然平静以及把物品送人，都可能表明一个人已决定结束自己的生命。在抗抑郁药治疗早期，精力可能在无望感消退之前恢复。

**直接而亲切地询问。**“你说你已经做了一个决定。能跟我多说说吗？你是否一直在想结束自己的生命？”

**根据她的回答作出回应。**如果她透露了自杀计划，就需要紧急行动：当天由精神卫生危机团队评估，考虑安排安全场所，在征得同意后让她的姐姐参与，使周围环境更安全，并为接下来的几小时和几天制订明确的计划。如果她缺乏决策能力或面临严重风险并拒绝帮助，可以考虑依据精神卫生法律处理。

**经验。**抗抑郁药带有关于年轻人在治疗早期自杀想法增加的警示，对所有人都建议在最初几周密切复诊。家庭成员提供的信息往往至关重要。
:::
:::

::: example 全科诊所里的一位老年男性 {#ex-older-male}
Gerald Price 先生，78 岁，最近丧偶，到全科医生处续开骨关节炎止痛药。他话不多，但提到自己“再也看不出做任何事有什么意义”，并且“不会成为任何人的负担”。全科医生应如何回应？

::: solution
**认真对待。**老年男性的自杀率很高，许多人在死亡前几周看过全科医生，常常以躯体不适就诊。丧亲、慢性疼痛、丧失独立性以及觉得自己是负担都很重要。

**询问。**温和而直接地问：“您说不会成为负担，您是否有过结束自己生命的想法？”探讨抑郁、孤独、疼痛控制、饮酒和认知情况。

**采取行动。**如存在抑郁则予以治疗（心理治疗，适当时使用药物），改善疼痛管理，为他联系丧亲支持和社区团体以减少孤立，并在征得同意后让家人参与。评估家中所备药物的数量，尤其是过量时危险的药物。安排早期随访。如果他有主动的计划，应寻求紧急精神卫生评估。
:::
:::

## 人群层面的预防

::: definition 自杀预防 {#def-prevention}
**自杀预防**结合了面向全人群（普遍性）、面向高风险群体（选择性）以及面向已出现自杀行为的个人（指征性）的措施。有效的组成部分包括限制获得自杀手段、负责任的媒体报道、改善精神疾病的识别和治疗、自伤后和出院后的随访、对危机中的人的支持，以及对因自杀而丧亲者的支持（**事后干预**）。
:::

人群措施中证据最强的是**限制手段**。当一种常用方式变得不易获得时，总体自杀率常常下降，因为自杀危机往往很短暂，许多人不会转而采用其他方式。例子包括 20 世纪六七十年代英国家用燃气的去毒化、几个亚洲国家对高毒农药的限制、英国 1998 年限制一种常用非处方止痛药包装规格的立法，以及在已知地点设置安全屏障。

**媒体报道**影响自杀率。详细报道方式，或耸人听闻、浪漫化的报道，与模仿行为有关；而讲述人们如何应对危机的故事则可能有保护作用。撒玛利亚会和世界卫生组织的指南规定了安全报道的做法，本章也遵循这些做法。

在英格兰，**自杀预防战略**（2023–2028 年）确定了重点群体，包括中年男性、曾经自伤的人、儿童和青少年以及与精神卫生服务有接触的人，并确定了重点行动，如应对网络伤害、改善对因自杀而丧亲者的支持以及减少获得手段的机会。

**事后干预**很重要，因为因自杀而丧亲的人，包括家人、朋友、同事和临床医生，自身的自杀风险也会增加，并常常感到孤立、内疚或被污名化。英国的 Support After Suicide 等服务提供实际和情感上的支持。

### 关心工作人员

失去一名死于自杀的患者的临床医生常常经历哀伤、内疚和害怕被指责。机构应提供支持、受保护的反思时间，以及以学习而非指责为重点的回顾。在某些群体中，医生本身的自杀风险也较高，现有专门为他们提供的保密支持服务。

::: history
几个世纪以来，许多国家都把自杀视为犯罪或罪孽。在英格兰和威尔士，根据《1961年自杀法》（Suicide Act 1961），自杀不再是犯罪，而协助自杀则被定为犯罪。涂尔干（Émile Durkheim）的《自杀论》（*Le Suicide*，1897 年）表明自杀率随社会整合和社会规范程度而变化，使自杀成为社会科学的研究对象。美国的施奈德曼（Edwin Shneidman）发展了自杀学，并提出了“心理痛苦”（psychache）即难以忍受的心理痛苦这一概念。1953 年，瓦拉（Chad Varah）在伦敦创立了撒玛利亚会，为考虑自杀的人提供电话服务。爱丁堡的克赖特曼（Norman Kreitman）研究自伤，并与同事在 1976 年表明，用无毒燃气替代有毒的家用燃气后自杀率随之下降。自 1996 年以来，英国全国精神卫生自杀与安全保密调查一直在收集与服务机构有接触者的自杀数据。2012 年，斯坦利（Barbara Stanley）和布朗（Gregory Brown）发表了如今被广泛使用的安全计划干预方法。
:::

## 后续内容

作为精神科评估一部分的风险评估见[[psychiatry/psychiatric-assessment]]；抑郁症和双相障碍见[[psychiatry/mood-disorders]]；中毒的医学处理见[[emergency-critical-care/poisoning]]；决策能力与同意见[[medical-ethics-law/consent-capacity]]；预测值的解读见[[epidemiology-ebm/diagnostic-tests]]。

::: summary
- 自伤是故意的自我中毒或自我伤害，无论动机如何；它是日后自杀最强的危险因素。
- 使用不带污名的用语：“死于自杀”；绝不说“博取关注”。
- 2021 年全世界约有 727,000 人死于自杀；2024 年英格兰和威尔士登记自杀 6,190 例，其中四分之三为男性。
- 危险因素描述的是群体；由于自杀罕见，风险量表的阳性预测值很低，NICE NG225 建议不要用它们来预测自杀或分配照护。
- 每一位自伤后就诊的人都应获得心理社会评估、共同制订的安全计划和随访。
- 对损伤给予完整的照护；如果患者拒绝治疗，应评估其决策能力。
- 不要根据自伤的躯体严重程度判断意图。
- 高风险时期包括出院后数周、自伤后、丧亲后和出狱后；出院后 72 小时内随访。
- 限制手段、安全的媒体报道和事后干预是关键的人群措施。
- 可以获得支持：在英国和爱尔兰，拨打 116 123 联系撒玛利亚会。
:::

## 习题

::: exercise 定义 {level=1}
给出 NICE 所使用的自伤定义，并解释为什么这一定义不取决于意图。
::: solution
自伤是故意的自我中毒或自我伤害，无论其表面目的或动机如何。意图往往是复杂的，会随时间变化，并且难以从外部判断；没有自杀意图的自伤仍会大大增加日后自杀的风险；把某些行为界定为“不算真正的”自伤，会导致人们得不到评估和帮助。
:::
:::

::: exercise 用语 {level=1}
用不带污名的语言改写以下说法：(a)“犯下自杀”；(b)“博取关注的过量服药”；(c)“自杀未遂失败”。
::: solution
(a)“死于自杀”或“结束了自己的生命”。(b)“自我中毒”或“作为应对痛苦方式的过量服药”；描述发生了什么，而不是给动机贴标签。(c)“自杀未遂”或“在一次自杀尝试中幸存”。
:::
:::

::: exercise 安全计划的组成部分 {level=1}
列出安全计划的六个组成部分。
::: solution
危机正在形成的预警信号；患者可以独自使用的内在应对策略；能够分散注意力的人和社交场所；患者可以求助的人；专业服务和危机联系方式（包括撒玛利亚会和当地危机团队等服务）；以及使周围环境更安全的方法。许多计划还包括活下去的理由。
:::
:::

::: exercise 预测值 {level=2 check="round(1000*0.75*0.01/(0.75*0.01+0.3*0.99))/10"}
某自杀风险量表的灵敏度为 0.75，特异度为 0.70。在随访期内 1% 的人将死于自杀的人群中，被划为高风险的人中有百分之多少会死于自杀？答案保留一位小数。
::: hint
用[[#eq-ppv-suicide]]，取$p = 0.01$。
:::
::: solution
真阳性$= 0.75 \times 0.01 = 0.0075$。假阳性$= 0.30 \times 0.99 = 0.297$。PPV $= 0.0075/(0.0075 + 0.297) = 0.0075/0.3045 \approx 0.0246$，即**2.5%**。每 100 名被标记为高风险的人中，约有 97 或 98 人在该期间不会死于自杀。
:::
:::

::: exercise 被量表漏掉的人 {level=2 check="2.5"}
使用与上一题相同的量表和人群，每筛查 1,000 人，有多少人尽管被划为低风险仍会死于自杀？答案保留一位小数。
::: solution
每 1,000 人中有$1000 \times 0.01 = 10$人将死于自杀。量表漏掉其中的$1 - 0.75 = 0.25$，因此每 1,000 人中有$10 \times 0.25 = $**2.5**名死者曾被划为低风险。这就是为什么“低风险”分数绝不能成为拒绝为某人提供随访的理由。
:::
:::

::: exercise 拒绝治疗 {level=2}
一名 28 岁女性自我中毒后到急诊科就诊，拒绝抽血和治疗，说她想离开。概述医生应采取的步骤。
::: solution
保持冷静，尝试理解她的理由；提供私密的空间和时间。用清楚的语言解释医学危险和治疗。评估她就拒绝治疗这一具体决定的决策能力：她能否理解、记住和权衡信息并表达决定？考虑中毒、精神障碍或过量本身是否损害了这种能力。如果她有决策能力，必须尊重她的拒绝，但应鼓励她留下，提供心理社会评估，告诉她如何再来就诊，并仔细记录；请上级同事参与，并在征得同意后让她的家人参与。如果她缺乏决策能力，可以依据《心智能力法》以限制最少的方式按其最佳利益进行治疗，并有上级参与和清楚的记录。紧急寻求上级、精神科以及必要时的法律意见；遵循当地政策。
:::
:::

::: exercise 一次服务审计 {level=3}
某精神卫生信托发现，其患者自杀中有 40% 发生在出院后三个月内，许多患者在周五出院且没有预约随访。提出五项改进措施，并说明每项的理由。
::: solution
(1) 确保每个人出院后 72 小时内得到随访，因为风险在最初几天和几周最高。(2) 避免在没有周末安排的情况下于周五出院，或建立主动的周末联系，因为周末的服务较少。(3) 出院前共同制订书面安全计划，并与全科医生和危机团队共享，使患者和其他人都知道危机出现时该怎么做。(4) 在征得同意后让家人和照护者参与出院规划，因为他们常常最先注意到病情恶化。(5) 在出院前后处理实际的压力源（住房、经济、就业、物质滥用），因为它们会引发出院后的危机。还可考虑：评估所提供的药物，确保出院小结及时送达，以不指责的方式监测并从每一例死亡中学习，以及培训工作人员进行富有同情心、以需求为基础的评估，而不是风险评分。
:::
:::

::: exercise 人群策略 {level=3}
某卫生部门请求就地方自杀预防计划提出建议。请描述主要组成部分，举出有循证依据的措施，并解释为什么减少获得手段的机会可以降低总体自杀率。
::: solution
组成部分：监测地方数据（谁、在哪里、何时）以便有针对性地采取行动；普遍性措施（限制手段、安全的媒体报道、学校和工作场所的精神健康项目、减少酒精危害）；针对高风险群体的选择性措施（中年男性、与刑事司法系统有接触的人、物质滥用者、因自杀而丧亲的人）；以及针对曾经自伤或处于危机中的人的指征性措施（及时的心理社会评估、安全计划、出院后随访、危机服务）。对因自杀而丧亲者的事后干预必不可少。有循证依据的措施包括限制获得常用手段、在已识别的地点设置物理屏障、自伤后和出院后的随访联系，以及与媒体合作遵循安全报道指南。限制手段之所以有效，是因为自杀危机往往短暂且矛盾；如果眼前的手段无法获得或更难使用，危机可能就会过去，而许多人不会改用其他方式。家用燃气去毒化和限制高毒农药等国家层面的例子之后，总体自杀率都出现了下降。
:::
