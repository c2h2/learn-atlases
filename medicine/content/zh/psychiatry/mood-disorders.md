每个人都会有情绪低落的日子，大多数人也会有精力异常充沛的时期。心境障碍则不同。心境的改变更严重、持续更久，伴随一组其他症状，并且干扰生活。抑郁症是全世界致残的主要原因之一；双相障碍虽然较少见，但自杀风险高，发作期间也容易造成伤害。

本章介绍如何识别抑郁发作和躁狂发作，如何区分单相抑郁与双相障碍，需要考虑的主要病因，以及治疗原则，包括锂盐的安全使用。本章假定读者已掌握[[psychiatry/psychiatric-assessment]]中的评估技能。

## 抑郁

### 抑郁发作

::: definition 抑郁发作 {#def-depression}
**抑郁发作**是指至少两周的时间里，患者在一天中的大部分时间、几乎每天都存在**心境低落**或**兴趣或愉快感丧失**（快感缺失），并伴有其他症状。ICD-11 和 DSM-5-TR 都要求从以下列表中总共至少有五项症状：

- 心境低落；
- 兴趣或愉快感丧失；
- 注意力差或犹豫不决；
- 无价值感或过度自责；
- 无望感（ICD-11 列入）；
- 反复出现死亡或自杀的想法；
- 睡眠改变（失眠，常伴早醒；或睡眠过多）；
- 食欲或体重改变；
- 精神运动性激越或迟滞；
- 疲乏或精力下降。

这些症状必须引起痛苦或损害功能，并且不能用某种物质或其他躯体疾病更好地解释。
:::

严重程度根据症状的数量和强度以及功能损害程度分为**轻度**、**中度**或**重度**。有几种模式值得识别，因为它们会改变处理方式：

- **伴精神病性症状。**存在妄想或幻觉，通常与低落的心境相一致：罪恶妄想、贫穷妄想、疾病妄想，或认为身体正在腐烂（虚无妄想）。这是一种严重的疾病，需要抗抑郁药与抗精神病药联合治疗或电休克治疗（ECT）。
- **忧郁型。**明显的快感缺失、晨重暮轻、早醒、明显的精神运动性改变和体重下降。
- **伴非典型特征。**心境可因好事而好转、睡眠和食欲增加、对拒绝敏感。
- **季节性模式。**发作在每年的同一时间反复出现，通常在秋冬季。
- **围产期起病。**在妊娠期或产后起病，在[[psychiatry/lifespan-psychiatry]]中讨论。

**持续性抑郁障碍**（恶劣心境）是一种较轻但慢性的心境低落，持续至少两年。

单次抑郁发作称为**抑郁障碍，单次发作**；再次发作则为**复发性**。抑郁常常复发：一次发作后，约一半的人会再次发作，且每多一次发作风险就更高。

### 抑郁的病因是什么？

没有单一的病因。有用的思考方式是分层次：

- **遗传易感性。**双生子研究提示遗传度约为 30%–40%。风险分散在许多效应微小的基因上。早期有人声称单个基因变异（例如 5-羟色胺转运体基因中的变异）与应激相互作用导致抑郁，但这一结论在大型研究中未能成立。
- **应激与逆境。**童年期虐待和忽视、丧亲、关系破裂、贫困和慢性疾病都会增加风险。应激会激活下丘脑-垂体-肾上腺（HPA）轴，许多抑郁患者的皮质醇升高。
- **心理模式。**贝克（Aaron Beck）描述了**负性认知三联征**：对自我、世界和未来的负性看法。这些模式使抑郁持续，也是认知治疗的目标。
- **治疗的生物学。****单胺假说**提出抑郁是由 5-羟色胺或去甲肾上腺素过少引起的，因为最早的抗抑郁药会增加这些递质。抗抑郁药在数小时内就会提高单胺水平，但改善却需要数周。因此，目前的解释强调神经可塑性、应激激素和情绪加工方面较慢的变化。简单的“化学失衡”说法已不再被接受。

### 排除其他原因

心境低落是许多疾病的特征，细致的病史可以保证诊断的准确。

| 类别 | 举例 |
|---|---|
| 双相障碍 | 曾有过躁狂或轻躁狂者的抑郁发作 |
| 正常反应 | 丧亲后的哀伤；应激事件后的适应障碍 |
| 内分泌 | 甲状腺功能减退症、库欣综合征、艾迪生病、高钙血症 |
| 神经系统 | 脑卒中、帕金森病、多发性硬化、痴呆、脑肿瘤 |
| 其他躯体疾病 | 贫血、维生素 B12 缺乏、阻塞性睡眠呼吸暂停、癌症（尤其是胰腺癌） |
| 物质 | 酒精、兴奋剂戒断、大麻 |
| 药物 | 糖皮质激素、干扰素、某些 β 受体阻滞剂、左乙拉西坦、激素类治疗 |

用于重度痤疮的异维A酸（isotretinoin）值得专门说明。抑郁、焦虑以及罕见的自杀想法被列为其不良反应，但关于因果联系的观察性研究结果并不一致。2023 年，英国药品和保健品监管局（MHRA）引入了额外的保障措施：在治疗前和治疗期间评估精神健康和性功能；对于 18 岁以下者，须由两名处方者同意才能开始治疗。服用异维A酸者新出现心境低落时应予以重视，并与处方者讨论。

::: example 不是每个疲乏的患者都患抑郁 {#ex-not-depression}
Siobhan Kelly 夫人，56 岁，告诉她的全科医生自己感到“没劲、疲惫不堪”，对园艺失去了兴趣，六个月来体重增加了 5 kg。她怕冷，皮肤干燥。她要求开抗抑郁药。全科医生应如何处理？

::: solution
**评估心境综合征。**她有数月的心境低落、兴趣丧失和疲乏，可能符合抑郁发作的标准。

**寻找躯体线索。**体重增加伴怕冷、皮肤干燥和疲乏，提示甲状腺功能减退症。询问有无便秘和月经改变，检查有无反射迟缓和甲状腺肿。

**检查。**甲状腺功能显示 TSH 升高、游离 T4 降低：原发性甲状腺功能减退症。

**计划。**治疗甲状腺功能减退症，在甲状腺功能恢复正常后（通常数周之后）复查心境。如果心境低落仍然存在，再将其作为抑郁本身进行评估和治疗。如果先开始使用抗抑郁药，就会延误正确的治疗。
:::
:::

### 衡量严重程度：PHQ-9

**患者健康问卷-9**（PHQ-9）询问过去两周内 DSM 的九项症状。每项按 0（完全没有）到 3（几乎每天）计分，总分 0–27。常用的分级为：0–4 分极轻，5–9 分轻度，10–14 分中度，15–19 分中重度，20–27 分重度。NICE 指南 NG222（2022 年）在选择治疗时把抑郁分为**较轻**（大致为 PHQ-9 低于 16 分）和**较重**（16 分或以上）。第 9 项询问死亡或自伤的想法，无论总分多少，都必须随后进行一次谈话。

一项大型个体参与者数据荟萃分析发现，PHQ-9 以 10 分或以上为界值时，对重性抑郁的灵敏度约为 0.88，特异度约为 0.85。与任何筛查一样，其预测值取决于患病率。

Kwame Mensah 先生，41 岁，完成 PHQ-9，各项得分为 2、3、1、2、3、2、1、0、1（第 9 项是认为自己死了更好或想伤害自己的想法）。计算他的总分，给出常用的严重程度分级和 NICE NG222 的分组，并说明第 9 项需要怎样处理。

::: solution
**总分。**$2+3+1+2+3+2+1+0+1 = 15$。

**分级。**15 分属于 15–19 分段，即“中重度”。

**NICE 分组。**15 分刚好低于 16 分，因此属于“较轻”的抑郁。这个界值是参考，而不是规则：临床医生还要考虑功能、病程和患者的病史。

**第 9 项。**得 1 分（“有几天”）意味着他曾有过死亡或自伤的想法。这需要一次细致、直接的谈话，了解自杀想法、计划、保护因素和支持，必要时制订安全计划。问卷永远不能取代这样的谈话。
:::
:::

## 抑郁的治疗

治疗由临床医生与患者共同选择，需考虑严重程度、既往疗效、个人偏好和其他疾病。截至 2026 年，英格兰的主要框架是 NICE NG222（2022 年）。

::: definition 抑郁的治疗选择 {#def-treatments}
- **心理治疗。**基于认知行为治疗的指导式自助、团体或个体**认知行为治疗**（CBT）、**行为激活**（安排有回报和有目的的活动）、**人际心理治疗**（IPT）、咨询、短程心理动力学治疗，以及针对较轻抑郁的团体运动或正念项目。
- **抗抑郁药。**选择性 5-羟色胺再摄取抑制剂（**SSRI**，如舍曲林（sertraline）、西酞普兰（citalopram）、氟西汀（fluoxetine））、5-羟色胺和去甲肾上腺素再摄取抑制剂（**SNRI**，如文拉法辛（venlafaxine）、度洛西汀（duloxetine））、米氮平（mirtazapine）、三环类抗抑郁药和单胺氧化酶抑制剂。
- 个体 CBT 与抗抑郁药**联合**，NICE 将其列为较重抑郁的首选。
- 针对严重或难治性疾病的**物理治疗**：电休克治疗（ECT），以及在部分机构中使用的重复经颅磁刺激。
:::

对于**较轻**的抑郁，除非患者本人偏好，NICE 不推荐常规将抗抑郁药作为一线治疗；首先采用低强度心理干预。对于**较重**的抑郁，个体 CBT 与抗抑郁药联合是列出的第一个选择，单独的个体 CBT、行为激活或单用抗抑郁药为替代方案。

### 抗抑郁药的使用

有几条原则适用于所有抗抑郁药：

- **起效。**部分获益常在头两周出现，但完全起效需要四到六周或更长时间。不良反应通常先出现，因此患者需要知道会发生什么。
- **复诊。**NICE 建议在开始用药后两周内复诊（25 岁以下或自杀风险增加者在一周内复诊），因为年轻人在治疗早期自杀想法会有小幅增加。
- **巩固。**缓解后，抗抑郁药通常应继续使用至少六个月，以降低复发风险。反复发作者可能受益于更长时间的维持治疗。
- **停药。**抗抑郁药应逐渐减量。突然停药可引起**撤药症状**：头晕、“电击样”感觉、焦虑、易激惹、睡眠紊乱和流感样症状。对部分人而言，这些症状可能严重且持久，NICE（2022 年）建议以与药物和个人相匹配的速度逐渐减量。

SSRI 的主要不良反应包括恶心、胃肠道不适、性功能障碍、治疗早期的激越、**低钠血症**（尤其见于老年人）、**出血风险**增加（尤其与非甾体抗炎药、阿司匹林或抗凝药合用时），以及西酞普兰和艾司西酞普兰引起的 **QT 间期延长**。任何 5-羟色胺能药物与其他 5-羟色胺能药物（如曲马多、曲普坦类、利奈唑胺或单胺氧化酶抑制剂）合用时，都可能促成 **5-羟色胺综合征**（激越、震颤、阵挛、高热）。剂量和相互作用必须在英国国家处方集（BNF）或当地处方集中核对。

::: example SSRI 与血钠 {#ex-hyponatraemia}
Edith Clarke 夫人，84 岁，三周前开始服用舍曲林治疗抑郁。她还因高血压服用苄氟噻嗪（bendroflumethiazide）。她的女儿反映她变得意识混乱、步态不稳。她的血钠为 121 mmol/L（正常 135–145）。请解释发生了什么，并概述处理措施。

::: solution
**机制。**SSRI 可引起抗利尿激素分泌失调综合征，导致水潴留和稀释性低钠血症。风险在治疗的最初几周、老年人、女性以及合用其他降低血钠的药物（如噻嗪类利尿剂）时最高。

**评估。**意识混乱和步态不稳伴血钠 121 mmol/L 属于中重度低钠血症，需要紧急的医学评估，包括液体状态、其他病因以及癫痫发作或跌倒的风险。

**处理。**停用舍曲林，并与内科团队一起评估噻嗪类药物；按照当地指南处理低钠血症，血钠纠正速度不得超过推荐值。她康复后，抑郁仍需治疗：可选择心理治疗，或低钠血症风险较低的抗抑郁药（如米氮平），并早期检查血钠。老年人开始使用 SSRI 时，尤其存在其他危险因素时，建议检测基线和随访血钠。
:::
:::

### 抑郁无效时

**难治性抑郁**通常指对两种以足够剂量、足够疗程使用的抗抑郁药反应不足。在称抑郁为难治性之前，要先核查基本问题：诊断是否正确（双相抑郁、器质性病因、物质使用）？患者是否一直在服药？是否存在治疗无法解决的持续应激？

接下来的步骤包括增加或更换心理治疗、换用不同类别的抗抑郁药，或**增效治疗**：加用锂盐或抗精神病药，如阿立哌唑（aripiprazole）或喹硫平（quetiapine）。**ECT** 是治疗重度抑郁最有效的方法，尤其适用于伴精神病性症状、拒绝进食和饮水危及生命或木僵的情况。

::: example 维持治疗的需治数 {#ex-nnt}
一项被频繁引用的抗抑郁药巩固治疗试验荟萃分析（Geddes 等，2003 年）发现，在随访期间，继续服用抗抑郁药者约 18% 复发，而换用安慰剂者约 41% 复发。计算绝对风险降低和预防一次复发的需治数（NNT）。

::: solution
**绝对风险降低。**$0.41 - 0.18 = 0.23$。

**NNT。**$1/0.23 \approx 4.35$。按照惯例，NNT 向上取整，因此约**5**人需要继续治疗才能使一人避免复发。

**解读。**以医学的标准来看，这是一个很大的效应。它支持康复后继续使用抗抑郁药的建议。但这一决定仍然是个体化的：需要权衡患者的复发史、不良反应和本人的偏好。
:::
:::

## 双相障碍

::: definition 躁狂、轻躁狂与双相障碍 {#def-bipolar}
**躁狂发作**是一段明显的心境高涨、膨胀或易激惹的时期，伴活动或精力增加，持续至少一周（如需住院则不论时长）。它伴有睡眠需求减少、言语迫促、思维奔逸或观念飘忽、夸大、注意力易分散和冒险行为（消费、性行为、驾驶）等症状。它导致明显的功能损害，并可能伴有精神病性症状。

**轻躁狂发作**的症状类似但较轻，DSM-5-TR 规定持续至少四天（ICD-11 表述为“数天”），且不引起明显的功能损害或精神病性症状。

- **双相 I 型障碍**：至少一次躁狂发作，通常也有抑郁发作。
- **双相 II 型障碍**：至少一次轻躁狂发作和至少一次抑郁发作，且无躁狂发作。
- **环性心境障碍**：至少两年的心境波动，有多次未达到完全标准的轻躁狂症状期和抑郁症状期。
:::

双相障碍的终生患病率约为 1%–2%，通常在青春期后期或成年早期起病。遗传度高，双生子研究中约为 60%–80%。大多数患者处于抑郁的时间远多于躁狂，首次发作常为抑郁。因此，双相障碍常常首先被诊断为单相抑郁。

::: warning 治疗抑郁之前一定要询问轻躁狂
开始使用抗抑郁药之前，要直接询问既往有无精力异常充沛、睡眠减少却不觉得累、异常自信、大量消费或冒险的时期。患者常把这些时期记为“好日子”，因此询问亲属会有帮助。提示双相性的线索包括抑郁起病早、多次短暂发作、产后起病、伴精神病性症状以及双相障碍家族史。单用抗抑郁药治疗双相抑郁可能诱发躁狂或快速循环。
:::

### 急性躁狂的处理

躁狂对患者的财务、人际关系、躯体健康和安全来说都是一种紧急情况。处理原则如下：

1. **安全与环境。**评估风险，考虑住院，减少刺激。如果患者缺乏自知力且面临严重风险，可能需要依据精神卫生法律处理。
2. **停用抗抑郁药。**
3. **抗躁狂药物。**NICE CG185 推荐首选抗精神病药（氟哌啶醇（haloperidol）、奥氮平（olanzapine）、喹硫平或利培酮（risperidone））。如无效，则换用列表中的另一种抗精神病药，并可加用锂盐。短期使用苯二氮䓬类药物可能有助于缓解激越和改善睡眠。
4. **躯体健康。**检查有无器质性病因（甲状腺疾病、糖皮质激素或兴奋剂等药物），确保足够的饮食、液体和睡眠。

### 长期治疗与锂盐

躁狂发作后，长期治疗可降低复发风险。在 NICE 指南中，**锂盐**是一线长期治疗。它是预防复发最有效的心境稳定剂，也是唯一有一致证据表明能降低自杀的心境稳定剂。

::: theorem 锂盐的治疗指数窄 {#thm-lithium}
能预防复发的血清锂浓度与引起中毒的浓度十分接近。维持治疗时，血锂水平通常以 0.6–0.8 mmol/L 为目标，在末次服药后 12 小时测定（部分患者可用更高水平，最高达 1.0 mmol/L）。高于约 1.2–1.5 mmol/L 时，中毒的可能性越来越大。任何降低锂排泄的因素都会使血锂升高。
:::

::: proof
锂不经代谢，几乎完全经肾脏排泄。它在肾小球滤过，大部分在近端小管随钠一起被重吸收。当机体缺钠或缺水时（呕吐、腹泻、发热、炎热、摄入减少），近端小管重吸收更多的钠，锂也随之被重吸收，因此血锂升高。噻嗪类利尿剂引起钠丢失，也导致同样的代偿性重吸收。非甾体抗炎药减少肾血流量和肾小球滤过，血管紧张素转化酶抑制剂和血管紧张素受体阻滞剂也会降低锂清除率。由于有效浓度与中毒浓度之间的余地很小，以上任何一种因素都可能使原本稳定的患者发生中毒。
:::

根据 NICE CG185 和 BNF 总结的锂盐监测包括：

| 项目 | 原因 | 时间（一般情况） |
|---|---|---|
| 血清锂（服药后 12 小时） | 疗效与中毒 | 开始用药或调整剂量后每周一次，直至稳定；第一年每 3 个月一次；此后每 6 个月一次，高风险人群每 3 个月一次 |
| 肾功能（eGFR） | 长期有慢性肾脏病风险 | 每 6 个月 |
| 甲状腺功能 | 锂盐可引起甲状腺功能减退症 | 每 6 个月 |
| 血钙 | 锂盐可引起甲状旁腺功能亢进 | 基线及定期检测 |
| 体重；有心脏风险者基线心电图 | 体重增加；罕见的传导影响 | 按需 |

常见不良反应有细微震颤、口渴和尿量增多（锂盐可引起**肾性尿崩症**）、体重增加和甲状腺功能减退症。**中毒**的体征包括粗大震颤、呕吐和腹泻、步态不稳、言语含糊、意识混乱，严重时出现癫痫发作和意识水平下降。锂盐有致畸性，妊娠期必须在专科指导下处理。

::: example 锂盐遇上非甾体抗炎药 {#ex-lithium-interface}
Tomasz Nowak 先生，48 岁，患双相 I 型障碍，服用锂盐病情稳定已六年，血锂水平为 0.6–0.7 mmol/L。一次运动损伤后，他服用布洛芬（ibuprofen）十天。热浪期间他出现了腹泻。现在他出现粗大震颤、呕吐和步态不稳。血锂为 2.1 mmol/L，肌酐从 85 µmol/L 升至 160 µmol/L。请解释发生了什么，并概述处理。

::: solution
**解释。**有两种机制使他的血锂升高。布洛芬降低了锂的肾清除率；腹泻加上炎热导致钠和水的丢失，使近端小管对锂的重吸收增加（见[[#thm-lithium]]）。肌酐升高表明发生了急性肾损伤，进一步减少了锂的排泄。

**严重程度。**血锂 2.1 mmol/L 伴神经系统体征属于明显中毒，是医学急症。

**处理。**停用锂盐和布洛芬。紧急寻求内科和毒理学意见；静脉补液以纠正脱水、恢复肾功能；监测血锂、电解质、肾功能和神经系统状态。严重中毒时，尤其伴肾功能受损或严重神经系统表现时，考虑血液透析，并遵循当地指南和中毒信息服务的建议。

**预防。**服用锂盐的患者及其家属应了解中毒的早期征象，知道自行购买的非甾体抗炎药可能很危险，并在呕吐或腹泻时就补液以及是否暂停锂盐寻求建议。是否重新开始用药以及目标血锂水平，由精神科团队决定。
:::
:::

### 其他心境稳定剂

- **丙戊酸盐**（valproate）对躁狂和维持治疗有效，但具有很强的致畸性：在宫内暴露的儿童会出现严重畸形和神经发育障碍。自 2024 年 1 月起，MHRA 要求，除非两名专科医生独立记录没有其他有效或可耐受的治疗适合该患者，否则不得为 55 岁以下的任何人开始使用丙戊酸盐；对任何可能怀孕者须实施**妊娠预防计划**。
- **拉莫三嗪**（lamotrigine）预防抑郁复发的作用大于预防躁狂复发。由于存在严重皮肤反应（包括史-约综合征）的风险，必须缓慢加量。
- **抗精神病药**如喹硫平、奥氮平和阿立哌唑用于急性发作和维持治疗。它们的代谢影响需要监测。

对于**双相抑郁**，NICE CG185 推荐氟西汀联合奥氮平，或单用喹硫平，单用奥氮平或拉莫三嗪为替代方案。不在没有抗躁狂药的情况下使用抗抑郁药。

心理治疗同样重要：心理教育、学习识别复发的早期预警信号、保持规律的睡眠和日常作息以及家庭参与，都能减少复发。

::: example 一位疲惫的老年男性 {#ex-late-life-mood}
Harold Bennett 先生，74 岁，退休教师，妻子去世后三个月来逐渐变得退缩。他吃得很少，体重下降了 6 kg，凌晨 4 点醒来，并告诉全科医生他的肠子“已经不动了，因为我的内脏正在腐烂”，还说自己没有照顾好妻子，罪该一死。可能的诊断是什么？为什么情况紧急？

::: solution
**诊断。**这是伴精神病性症状的重度抑郁发作。虚无妄想（内脏正在腐烂）和罪恶妄想是与心境一致的精神病性症状。单纯的哀伤不会引起这样的妄想、明显的体重下降和弥漫的自责。

**为什么紧急。**他是一位新近丧偶的老年男性，有无望感、自责和精神病性症状，而且进食很少。其中每一项都增加了对自杀和躯体状况恶化的担忧。要以直接而富有同情心的方式询问自杀想法。

**评估。**排除体重下降和便秘的躯体原因，包括癌症、高钙血症和甲状腺功能减退症。检查他的认知功能。

**处理。**紧急转诊专科。治疗选择为抗抑郁药联合抗精神病药，或 ECT；ECT 对老年人的精神病性抑郁效果良好，如果他停止进食和饮水尤其要考虑。为了安全和营养，可能需要住院。
:::
:::

::: quiz
一名 27 岁女性正在接受第三次抑郁发作的治疗。下列哪一项病史最应改变治疗计划？
- [ ] 她以前对舍曲林反应良好。
- [x] 她的姐姐描述，去年有一周她几乎不睡觉，花光了积蓄，还创办了三家新公司。
- [ ] 她有失眠和食欲差。
- [ ] 她的母亲曾患产后抑郁。
::: solution
姐姐的叙述提示既往有躁狂或轻躁狂发作，这会把诊断改为双相障碍。治疗随之以心境稳定剂或抗精神病药为中心，并避免单用抗抑郁药。其他特征在单相抑郁中很常见。
:::
:::

::: history
希波克拉底学派的著作中就描述过忧郁症，古代的卡帕多西亚的阿雷提乌斯（Aretaeus of Cappadocia）也注意到忧郁与躁狂的交替。1854 年，法尔雷（Jean-Pierre Falret）描述了“循环性精神病”（*folie circulaire*）；1899 年，克雷佩林（Emil Kraepelin）将复发性心境障碍归为躁狂抑郁性精神病，并根据病程将其与早发性痴呆（精神分裂症）区分开来。1949 年，墨尔本的凯德（John Cade）报告锂盐能使躁狂患者平静下来；20 世纪五六十年代，丹麦的肖乌（Mogens Schou）的试验确立了锂盐的应用。最早的抗抑郁药是在 20 世纪 50 年代偶然发现的：抗结核药异烟酰异丙肼（iproniazid）能提升心境，库恩（Roland Kuhn）于 1957 年报告了丙米嗪（imipramine）的抗抑郁作用。第一种被广泛使用的 SSRI 氟西汀于 1987 年在美国获批。与此同时，贝克在 20 世纪六七十年代发展了针对抑郁的认知治疗。
:::

::: summary
- 抑郁发作是至少两周的心境低落或兴趣丧失，并伴有其他症状，总共五项，引起痛苦或功能损害。
- 严重程度、精神病性症状以及发作模式（忧郁型、非典型、季节性、围产期）指导治疗。
- 始终考虑躯体原因、药物和物质，并始终询问既往有无轻躁狂或躁狂。
- PHQ-9 等筛查问卷用于衡量严重程度并辅助临床评估，但不能取代临床评估；第 9 项始终需要一次谈话。
- NICE NG222（2022 年）用较轻和较重抑郁来指导治疗选择；在每一个层级，心理治疗都处于核心地位。
- 抗抑郁药需要数周才能起效，需要早期复诊（尤其是 25 岁以下者），缓解后应继续至少六个月，停药时应逐渐减量。
- 躁狂首先用抗精神病药治疗；锂盐是双相障碍的一线长期治疗。
- 锂盐的治疗指数窄：脱水、非甾体抗炎药、血管紧张素转化酶抑制剂和噻嗪类会升高血锂；需监测血锂、肾功能、甲状腺功能和血钙。
- 未经两名专科医生同意，不得为 55 岁以下者开始使用丙戊酸盐（MHRA 2024 年），对可能怀孕者绝不能在没有妊娠预防的情况下使用。
:::

## 习题

::: exercise 标准简述 {level=1}
列出抑郁发作的核心症状和最短病程，并举出四项计入诊断的其他症状。
::: solution
核心症状：心境低落，以及兴趣或愉快感丧失（至少需要其一）。病程：至少两周，一天中大部分时间、几乎每天。其他症状（任举四项）：注意力差或犹豫不决；无价值感或自责；无望感；反复出现死亡或自杀的想法；睡眠改变；食欲或体重改变；精神运动性激越或迟滞；疲乏。总共至少五项症状，并伴有痛苦或功能损害。
:::
:::

::: exercise 躁狂还是轻躁狂？ {level=1}
举出区分躁狂发作与轻躁狂发作的两个特征，并说明双相 I 型与双相 II 型障碍的区别。
::: solution
躁狂持续至少一周（如需住院则不论时长），而 DSM-5-TR 中轻躁狂持续至少四天。躁狂引起明显的功能损害，可能需要住院，并可能伴有精神病性症状；轻躁狂不引起明显的功能损害或精神病性症状。双相 I 型要求至少一次躁狂发作；双相 II 型要求至少一次轻躁狂发作和一次抑郁发作，且无躁狂发作。
:::
:::

::: exercise 锂盐及其相互作用 {level=1}
说出三种会升高血清锂的药物或情况，以及四种锂中毒的体征。
::: solution
升高血锂：非甾体抗炎药、血管紧张素转化酶抑制剂或血管紧张素受体阻滞剂、噻嗪类利尿剂，以及脱水（呕吐、腹泻、发热、炎热、摄入不足）；肾功能下降也会升高血锂。中毒体征：粗大震颤、呕吐和腹泻、共济失调、言语含糊、意识混乱，严重时出现癫痫发作和意识水平下降。
:::
:::

::: exercise PHQ-9 总分 {level=2 check="16"}
一名女性的 PHQ-9 各项得分为 3、2、2、3、1、2、2、1、0。她的总分是多少？属于 NICE NG222 的哪一组？
::: solution
$3+2+2+3+1+2+2+1+0 = 16$。16 分属于 NICE NG222 的“较重”组（16 分或以上），在常用分级中属于“中重度”（15–19 分）。第 9 项为 0 分，但在会谈中仍应询问自杀想法。
:::
:::

::: exercise 需治数 {level=2 check="5"}
在一项双相障碍维持治疗试验中，两年内服用锂盐者 30% 复发，服用安慰剂者 50% 复发（示意数据）。两年内预防一次复发的需治数是多少？向上取整为整数。
::: solution
绝对风险降低$= 0.50 - 0.30 = 0.20$。NNT $= 1/0.20 = 5$。五人需服用锂盐两年，才能预防一次复发。
:::
:::

::: exercise 第一种抗抑郁药 {level=2}
一名 35 岁男性，首次出现较重的抑郁发作，既往无躁狂症状，希望在心理治疗的同时使用药物。他还因背痛规律服用萘普生（naproxen）。请讨论抗抑郁药类别的选择，以及开始用药时应告诉他什么。
::: solution
SSRI（如舍曲林）因其耐受性和安全性，是常见的首选，并按照 NICE 对较重抑郁列出的首选方案联合个体 CBT。萘普生很重要：SSRI 与非甾体抗炎药合用会增加胃肠道出血的风险，因此应重新评估是否需要萘普生，并根据 BNF 考虑使用质子泵抑制剂保护胃黏膜。应告诉他：恶心或坐立不安等不良反应常常先出现，通常会逐渐消退；获益在数周内逐步显现；约两周内会复诊；如果出现自杀想法或感觉更糟，要尽早求助；治疗通常在康复后继续至少六个月；停药应逐渐、有计划地进行，以避免撤药症状。
:::
:::

::: exercise 双相障碍与妊娠计划 {level=3}
一名 29 岁的双相 I 型障碍女性，使用丙戊酸盐病情稳定已三年，该药是在现行限制出台之前、她 22 岁时开始使用的。她现在计划怀孕。请概述相关问题以及应如何处理。
::: solution
妊娠期使用丙戊酸盐会使胎儿发生严重先天畸形和儿童神经发育障碍的风险很高，因此不应在妊娠期用于治疗双相障碍。按照 MHRA 的规定，她本应已加入妊娠预防计划，并每年接受专科复查。计划应在受孕前开始，由她的精神科医生参与，最好还有围产期精神卫生服务。选择包括换用妊娠期数据更令人放心的抗精神病药，或换用锂盐；锂盐的致畸风险比过去认为的更小、更低，但在妊娠期和分娩前后需要密切监测血锂。换药应逐步进行，换药后的阶段要监测有无复发。她需要知道，产后阶段复发和产后精神病的风险很高，因此书面的围产期计划和产后的密切支持至关重要。建议补充叶酸。不应突然停用丙戊酸盐，因为快速撤药有复发风险。
:::
:::

::: exercise 这种抑郁是难治性的吗？ {level=3}
一名 52 岁女性患抑郁 18 个月。她先后试用西酞普兰和舍曲林，各四周，均无效。她每周饮酒约 40 个单位，并长期上夜班。她的全科医生将她的抑郁描述为“难治性”，并询问能否加用锂盐增效。请回应。
::: solution
她尚不符合难治性抑郁的合理定义。四周太短，不足以判断一种抗抑郁药的疗效；充分的试验通常至少需要以足够剂量使用四到六周，并确认依从性。先后使用两种 SSRI 也没有检验不同的作用机制。更重要的是，每周 40 个单位的酒精足以引起并维持抑郁，并干扰治疗；它也使锂盐的使用更不安全。夜班工作扰乱睡眠和昼夜节律。其他需核查的方面：诊断（既往轻躁狂、甲状腺功能减退症或贫血等躯体原因），以及她是否接受过心理治疗。合理的计划是：在支持下处理饮酒问题，提供 CBT 或行为激活，以足够的剂量和疗程优化一种抗抑郁药的试验，并评估工作安排。只有在这些步骤之后抑郁仍然持续时，才在专科意见下考虑增效治疗。
:::
:::
