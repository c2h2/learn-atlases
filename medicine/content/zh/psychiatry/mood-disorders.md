心境障碍是精神科门诊的主体，也是最容易被两头误诊的一类：**抑郁不只是悲伤，躁狂不只是高兴；它们是可以被分级、被测量、被治疗复发的疾病，而其治疗的风险常常来自“没有问的那一句”——是否有过一次躁狂，是否此刻想死，是否正在服着会要命的药。**本章覆盖单相抑郁（其分级与躯体表现与共病）、双相及其雷区（低起的误诊、抗抑郁药诱发转相、锂盐的地位）、以及治疗的工具箱（抗抑郁药的选择与起效的时间、心理治疗、复发的预防）。

## 抑郁

::: definition 单相抑郁 {#def-depression}
**抑郁发作的核心是持续两周以上的情绪低落或兴趣与愉快感的丧失，并伴若干附加症状：睡眠的改变（早醒更提示内源性的型）、食欲与体重的变化、精神运动的迟滞或激越、疲乏与无力、注意与决定的困难、无价值与过度的自责、以及死的念头与自杀的计划。分级按症状的数目与强度与功能的损害：轻度的发作仍可维持工作而很痛苦，重度的可以完全不进食不起床，伴精神病性的抑郁则以自责与贫穷与罪恶的妄想为特征，是自杀风险最高的一类。有两组表现常被漏掉。第一是躯体化的面具：在老年与若干文化中，主诉是疼与累与“心脏不舒服”而不是心情，而在老年人中抑郁常表现为遗忘与执行功能的下降，被当作痴呆（在抑郁的假性痴呆中，回答常是“不知道”而非错误的答案，且起病与主观的抱怨重于客观的检查）。第二是激越与焦虑的面具：坐立不安与反复求助与（在若干药物上的）不耐受，其最危险的形式是伴焦虑的抑郁，因为它兼有冲动与痛苦。非典型的特征值得识别：情绪可以被好事短暂改善、嗜睡与食欲增加、四肢发沉与（在人际关系中的）被拒绝的敏感；它们提示双相的可能并要求在用药上更谨慎。诊断要同时记录的还有：既往的发作次数（次数越多，将来复发的概率越高，第四次之后通常需要长期治疗）、家族史与（在家族中的）自杀与双相、当前的风险在念头与计划与手段与（在保护的因素上的）与共病在甲状腺与在贫血与在疼痛与（在酒精上的）、以及近三个月的重大生活事件。要交代的一句话：抑郁不是软弱的同义词，它是一种可治疗的疾病，其治疗的目标是恢复到病前的功能与（在若干方案中的）维持治疗以防止复发，而不是“撑过去”（[[psychiatry/psychiatric-assessment]]、[[endocrine/thyroid]]、[[psychiatry/self-harm-suicide-prevention]]、[[geriatrics-palliative/delirium-dementia-care]]）。**
:::

## 双相与其雷区

::: definition 双相障碍 {#def-bipolar}
**双相一型要求至少一次躁狂：一周以上的高涨或易怒的心境，伴精力与活动的增加，同时有睡眠需要的减少、言语与联想的加快、夸大或自信的增加、注意的分散、活动的增多与冒险（在消费与（在性上的））与（在投资的生意上的）；重者出现精神病性的症状并被周围人一眼认出。双相二型要求一次轻躁狂（明确的改变但功能未崩坏、无需住院）加一次重性抑郁；其人的痛苦主要在抑郁的一端，因此常常只在抑郁时被诊断。环性以多年波动为特征。雷区有四。第一，躁狂被误认为“状态好”：患者喜欢那段时期，家人记得的是花钱与吵架，而医师只记录了现在的失眠与无力；因此筛查必须直接问“是否有一段时间您睡得很少却精力特别足、想法特别快、做了平时不会做的事”，问三四个具体的问题可以筛出多数病例。第二，抗抑郁药把双相的抑郁推成躁狂或混合的状态，并可能造成快速循环；一旦双相的诊断成立，治疗的主线是心境稳定剂与（在若干的）第二代抗精神病药，而不是抗抑郁药，且抗抑郁药只在专科的监督下与情绪稳定剂同用。第三，混合的状态最危险：抑郁的心境与躁狂的动力同时存在不眠与（在激越与（在冲动上的）），自杀的行为在这里最可能发生，而它常被当作“抗抑郁药不够”而加量。第四，双相共病注意缺陷与物质使用与边界特质的比例高，任何一个被单独治疗都会失败。也要说明维持治疗的价值：锂盐不仅稳定心境，还降低自杀的风险；而停药后的复发率高，尤其在前几个月，因此减药要慢并带上预警的计划（[[psychiatry/psychiatric-assessment]]、[[psychiatry/psychotic-disorders]]、[[psychiatry/substance-use]]、[[pharmacology/dosing-principles]]）。**
:::

## 治疗的工具箱

::: definition 抗抑郁药与心理治疗 {#def-treatments}
**开始一次抗抑郁治疗前先确认三件事：有没有一次未识别的躁狂、有没有需要立刻处理的自杀风险、以及是否有躯体原因在甲状腺与在贫血与在药物与（在酒精上的）。选择药物的依据是副作用与相互作用与既往的反应与患者的偏好，而不是疗效的差异：选择性血清素再摄取抑制剂最常作为起点在胃肠道与（在性功能的与（在血清素综合征的风险上的）；米氮平在失眠与消瘦者方便（在镇静与体重增加上的））；安非他酮对性功能的负担小并有助于戒烟（在癫痫与（在饮酒者中的）的禁忌）；三环类有效但危险，在心脏病与（在过量的致命性上的）使其不适合作为第一线。剂量的原则是按目标加量并等到足够的时间：有效的判断通常在足量四至六周之后，而两周时看到的常常只是副作用。要提前交代的时间线： 睡眠 与食欲与焦虑可能在第一周改善，心情与兴趣在第到六周，而自杀的意念在二十至二十五岁之间需要加密的随访（在开始的两周内）。心理治疗与药物同等有效于轻中度的发作，且对复发的预防有独立的价值：认知的行为的治疗、人际的治疗、行为激活在（安排活动与（在规律上的））与（在慢性与（在难治的抑郁中的））的图式与在（基于心智化的与（在行为伴侣的治疗上的）。联合治疗在中重度的病例中优于任一单独。复发预防的规则可以背下来：一次发作后维持至少六至十二个月；两次以上发作或（在重度的发作与（在家族史与（在早发起病上的）者考虑长期；不要“感觉好了就停”，因为第一年内停药后的复发率显著更高，而减药要在稳定期缓慢进行并带上复发的预警计划。工具之外还有：运动与光照（在季节性的））与睡眠节律的重建与（在酒精上的））的减少）；以及在若干情形中被证明有效的分级运动方案与在重度的与在精神病性的与在难治的（在电休克上的）的物理治疗（[[psychiatry/psychiatric-assessment]]、[[pharmacology/dosing-principles]]、[[pharmacology/adverse-reactions]]、[[psychiatry/self-harm-suicide-prevention]]）。**
:::

::: example 那封不是抑郁的全科来信 {#ex-not-depression}
一封转介信写着“62岁女性，抑郁半年，抗抑郁药三种无效，请求专科评估”；她体重下降八公斤、便秘、皮肤干、声音低沉、动作慢；她在甲减确诊后曾停药；血钙偏高。
::: solution
**在把“抗抑郁药无效”记为抵抗之前，先问她的抑郁是不是躯体病造成的（[[#def-depression]]、[[endocrine/thyroid]]）。她有三条线索指向可治的原因：甲减（在停药后复发的）可以完全模仿迟滞与在便秘与在皮肤干与（在声音的改变与（在认知变慢上的），而血钙升高本身会造成情绪低落与多尿与口渴与便秘与（在重者中的）意识改变，需要查甲状旁腺激素与（在若干病例中的）肿瘤的筛查。要做的事：重新查甲的功能与血钙与白蛋白校正与（在肾与钠与（在维生素D上的））与血相与炎症的标志与（在B 族维生素与（在HIV 与梅毒的筛查上的）；把甲减重新治疗并按需要缓慢加量（在老年与（在心脏的病史上的））从低剂量起），并解释为什么“情绪的药”在甲状腺没纠正之前不会有反应；高钙按严重度给补液与（在若干的）双膦酸盐与（在甲状旁腺的手术的评估上的））。也要处理抑郁本身：躯体病与抑郁可以同时存在，所以纠正之后仍然按发作的严重度与风险来治疗；同时说明她的体重下降一半可能是病而非“没胃口”。这一类转介的教训是程序性的：抗抑郁药换到第三种之前，应当有一份写清楚“已经排除了什么”的清单在甲与钙与贫血与在药物与（在酒精与（在睡眠的呼吸暂停上的）），并且把这一份清单作为转介信的一部分（[[clinical-skills/laboratory-tests]]、[[clinical-skills/clinical-reasoning]]、[[endocrine/adrenal]]、[[renal/potassium-calcium-phosphate]]）。**

::: example 锂盐在学科的交界 {#ex-lithium-interface}
一名45岁的双相患者在服锂盐（在浓度0.7上的）三年稳定；他因腹泻脱水来到急诊，肌酐从90升到160，浓度1.6，手抖与说话含糊；内科准备“继续原药并观察”。
::: solution
**这是锂中毒的早期，需要当天处理而不是观察（[[#def-treatments]]、[[renal/chronic-kidney-disease]]、[[emergency-critical-care/poisoning]]）。机制要说清：锂全部经肾清除，容量不足与（在若干的）利尿剂与（在血管紧张素转换酶抑制剂与非甾体的抗炎药上的）都会升高浓度，而腹泻与进食少的组合是最常见的诱因；浓度与中毒的严重度并不完全平行，慢性的中毒在较低浓度也可以有神经的表现。处置按步骤：立刻停锂（在急诊的记录上写明时间与浓度上的）；给生理盐水恢复容量并按小时复查浓度与肌酐与钠；查神经的表现在震颤与（在构音与（在共济失调与（在反射与（在意识上的）；血液净化的指征是重度的神经表现或（在浓度很高且肾的功能差上的））或（在长期的蓄积者中的））的持续升高，按本地的毒理与肾科的途径决定，不要等“到某个数字”才请会诊。恢复之后有三件事：把这次的诱因写进病历（在腹泻时的停药规则上的）），给她一张“病中规则”的卡片在（呕吐腹泻或发热时的暂停与（在饮水的量的上的））；重新审视合并用药（在氢氯噻嗪与（在布洛芬与（在血管紧张素转换酶抑制剂的））的），并在不得不用时加密浓度；以及长期随访的肾功能与甲与钙在锂相关的多尿与在甲的低与在甲状旁腺的升高与（在肾的慢性下降上的）。最后要替她争的一点：锂是她稳定三年的药，不该因为一次可预防的中毒而被永久停用；停用的决定要在她稳定时、连同替代的方案一起讨论（[[renal/potassium-calcium-phosphate]]、[[pharmacology/metabolism-excretion]]、[[endocrine/thyroid]]、[[clinical-skills/records-handover]]）。**

::: example 疲惫的老人 {#ex-late-life-mood}
一名78岁的男性在妻子去世后一年“没意思”，近三个月消瘦、不洗澡、把助听器摘掉说“吵”；他的女儿说他“记性差了很多”；他服三种降压药与（在阿托伐他汀与（在阿司匹林上的））。
::: solution
**老年抑郁常以“像痴呆”与“像老了”出现，而它的可治性不因年龄减少（[[#def-depression]]、[[#def-treatments]]、[[geriatrics-palliative/polypharmacy]]）。评估要具体：哀伤与抑郁的区分（在哀伤中自我的价值与愉快的能力保留，且念头是“想见到她”而不是“我是负担”）；认知的主诉要用行为验证（在抑郁的假性痴呆中他答“不知道”，在痴呆中他编答案，且抑郁的起病常有明确的时间）；听力与视力必须处理，因为被摘掉的助听器本身会制造退缩与“记性差”的假象，而把它装回去可能就改变一半的表现。躯体与药物的审查同样重要：三种降压药加他汀可以造成乏力的主诉，甲的低下与贫血与维生素的缺乏要查；跌倒的风险决定用药的选择。风险要直接问：老年男性自杀的完成率高，且常用在枪与（在碳与（在跳下的）的）致命方式；他的独居与丧偶与慢性疼痛与（在（酒上的））都是加权项；问“有没有想过自己不在了更好”，并问手段与计划与在（是否把东西送人上的）。治疗上：舍曲林或（在若干体系中的）米氮平在低剂量起始（在钠与（在出血与（在抗胆碱能负担上的））的顾虑），与女儿约定的两周的复评，并把心理治疗与（在哀伤上的）的工作与活动的安排同时启动；对不洗澡与不吃这两件事，直接给护理的可执行清单在（固定的洗澡的日子与（在一人陪同的进餐上的）），比任何药物都见效快。同时要给她女儿一次不带他的会谈，因为照护者的崩溃是老人被送进医院的常见原因（[[geriatrics-palliative/ageing-frailty]]、[[nervous-system/dementia-neurodegeneration]]、[[clinical-skills/communication]]、[[pharmacology/patient-variation]]）。**

::: example 血清素药与钠 {#ex-hyponatraemia}
一名74岁的女性因抑郁开始舍曲林，第十三周因跌倒与意识模糊被送来；钠122、血浆渗透压低、尿钠高、钾正常、皮质醇与甲正常；她同时服吲达帕胺。
::: solution
**这是抗利尿激素分泌不当的低钠，最可能的贡献者是噻嗪类的利尿剂与选择性血清素再摄取抑制剂，两者都是可停的原因（[[#def-treatments]]、[[renal/water-sodium]]、[[pharmacology/adverse-reactions]]）。要点是次序：先停可疑的药（在吲达帕胺与舍曲林两者都要停，并记录时间）；限液（在若干的五十至一毫升每公斤的范围内）并按小时复查钠；纠正的速度不能快（在二十四小时内的上升不超过若干毫摩尔，以避免渗透性脱髓鞘），如果有抽搐或严重的意识障碍则用高渗盐水按体重的小剂量并更密的监测；同时查原因的清单在肺的与中枢的病变与在疼痛与在恶心与在再喂养与（在阿片的药物上的）。老年女性是这一并发症的高危人群，风险在开始的头几周内最高，所以更合理的做法是开药时就定复查钠的时间在基线与在两周与（在剂量变化后的），并把“乏力与意识模糊与跌倒”写进给家属的说明里，因为这几个字常是唯一的报警。抑郁的治疗不能因此终止：可以在钠纠正后换用低风险的药（在米氮平与（在安非他酮上的））并在两周后复查钠；也要说明“曾经低钠”不等于终身不能再用这一类药，但再次使用时必须有更早的监测。最后把这件事写进她的过敏与不良反应的字段，并注明是“不良反应”而不是“药物过敏”，因为后者会让以后的医生避开整类并不需要避开的药（[[renal/acid-base-disorders]]、[[cardiovascular/hypertension]]、[[clinical-skills/patient-safety]]、[[clinical-skills/records-handover]]）。**

**抗抑郁治疗的历史有几个决定性的偶然。1950年代，异烟肼类的抗结核药与中枢降压药在病人身上产生了明显的情绪提升，促使精神药理学第一次从镇静转向抗抑郁；1957年，作为结核药合成的异卡波肼被注意到能让抑郁的病人“说话变多、下床活动”，而同一年代末，抗精神病药的发现者之一在研究氯丙嗪类似物时合成出了丙咪嗪，它没有镇静作用却改变了抑郁的病程，成为三环类的起点。这两件事共同确立了胺类假说：1960年代，Schildkraut 提出抑郁与脑内单胺的不足有关，而这一过于简洁的模型统治了四十年的教学与研究，也塑造了公众对“化学失衡”的理解。1970至1980年代，诊断被改革：Feighner 的标准与美国英国的研究把发作的时限与症状清单写进规则，1980年的手册由此可以区分抑郁发作与神经症与人格的困难，而双相与单相的分界第一次变得可以研究，这直接使锂盐的预防作用在1968年的双盲试验中得以被证明。1980年代末，氟西汀的上市带来选择性血清素再摄取抑制剂的时代：它们没有三环类的心脏毒性与过量的致命性，使门诊的大量处方成为可能，也带来关于广告与（在若干国家中的）直接面向患者的处方与“是否过度用药”的争论。1990年代后，证据的重心转向三个问题：疗效与安慰剂的差别是否被夸大，回答是差别随严重度增大而在轻度发作中很小；儿童青少年与二十多岁人群在开始治疗的初期是否有自杀意念的增加，回答是有小幅的增加，因而有了各国的黑框与监测的建议与（在若干体系中的）“首月加密随访”的制度；停药时的撤药综合征是否被误认为复发或依赖，回答是它有自己的时间与症状并需要缓慢减停。同一时期，心理治疗的地位被反复确认：英国的国家服务在2008年后为焦虑与抑郁大规模提供循证的心理治疗，成为“谈话治疗也可被制度化供给”的范例，也暴露了等待名单与完成率的问题。近二十年，难治性抑郁的治疗重新变得多样：氯胺酮与其类似物以小时计的抗抑郁作用打开了谷氨酸的通路，而它也带来了关于疗效持续时间与滥用与商业化门诊的担忧；经颅的磁刺激与（在若干体系中的）深部脑刺激的探索让“物理的治疗”回到台面；与此同时，关于“抑郁症是不是一个被过度扩张的类别”的争论在学界持续，其核心是分类的边界与（在社会的因上的）的权重。这些争论对门诊的实际影响只有一个：把发作诊断、严重度、风险、躯体原因与患者的偏好都摆在台面上，再谈药；历史反复证明，跳过任何一项的处方都会在某个具体的人身上付出代价。**
:::
::: summary
- 抑郁发作按症状的数目与强度与功能分级，而老年与若干文化中它以躯体与认知与激越的面具出现。
- 开始治疗前必须筛一次躁狂：一次未识别的轻躁狂会把整个治疗路径从抗抑郁药改向心境稳定剂。
- 抗抑郁药的疗效判断在足量四至六周之后；第一周看到的常常只是副作用，这一时间线必须事先说清。
- 二十岁以下与年轻成人在开始治疗的初期需要加密随访，因为自杀意念可能先于疗效被观察到。
- 锂盐仍需被当作有治疗窗的药：容量不足与常见的合并用药会把它推向中毒，而“病中规则”的卡片能预防多数事件。
- 缓解不是治疗的结束：首次发作后维持六至十二个月，多次发作者考虑长期，减药要慢并带上复发预警的计划。
:::

**第一句：“有没有一段时间，家人觉得您比平时更兴奋或更爱发脾气，同时睡得很少却精力充沛？”抓的是躁狂或轻躁狂的核心（睡眠需要的减少加心境或精力的改变）。第二句：“那段时间有没有想法特别快、说话多到别人插不上？”抓联想加快与言语增多。第三句：“有没有做过平时不会做的花钱或投资或性的决定，后来觉得不像自己？”抓判断的损害与冒险。第四句：“家里人有没有得过双相或吃过锂盐？”抓家族史，其权重高于任何单项症状。任何一句阳性都要追问持续时间与是否住院与是否伴抑郁的交替与（在若干病例中的）抗抑郁药下的转相；阳性不等于诊断双相，但足以改变处置：把抗抑郁药降到必要的最低或不用、优先选心境稳定剂的路径、并把“上次的兴奋”写进病历的显著位置，因为下一个见到她的人只看到抑郁。阴性也要记录，因为它支持此后的用药（[[#def-bipolar]]、[[psychiatry/psychiatric-assessment]]、[[pharmacology/adverse-reactions]]）。**

::: exercise 执行恶化计划 {level=2}
一名37岁的抑郁患者在稳定期自愿参与制定“恶化计划”；请写出计划应包括的条目，并说明它与危机计划的区别。
::: solution
**恶化计划针对的是“正在滑回去”的几周，而不是今晚的危机（[[#def-depression]]、[[clinical-skills/communication]]）。条目有六：她自己的早期信号并按出现的顺序（先是不再回消息与凌晨三点醒，然后是不洗澡与不上班）；每一步对应的动作与由谁提醒（在两周不运动时约一次面谈）；她愿意在早期接受的治疗调整（在若干方案中的临时加量或恢复原来的剂量），并预先取得她对具体数字的同意，以免在最没力气决策时重新谈判；她明确不愿意的做法（不要在她面前把话交给家属）；可联系的人与电话（含夜间与周末）；以及升级的界限（在出现何种情形时她同意被送医）。与危机计划的区别在于对象与时间：危机计划回答“现在想伤害自己怎么办”，恶化计划回答“如何在两周内把它拦住”；两份都要写，且都要放在她能找到的地方。还要给她一份可以拿给家人读的一页纸（三句话：她可能需要什么、不要做什么、什么时候打电话），并约定每季度用五分钟复评一次；这类计划的价值在真实世界的数据显示，多数复发如果被本人早期识别，可以在门诊被接住（[[psychiatry/self-harm-suicide-prevention]]、[[clinical-skills/records-handover]]、[[psychiatry/treatments-mental-health-law]]）。**

有人说“抗抑郁药不过是昂贵的糖丸，抑郁只是大脑的化学失衡被发明出来的故事”。请就两部分分别评价。
::: solution
**关于“化学失衡”：这一说法作为对公众的解释已经被证据削弱，动物与人的研究并不能证明抑郁是某个胺的不足，而2022年关于血清素的一篇广泛引用的综述也明确否定了“简单失衡”的模型；承认这一点很重要，因为它曾被用来让患者觉得自己“坏了个零件”而被动等待药物。但它不等于治疗无效：抗抑郁药在随机试验中优于安慰剂，效应在重度发作中最大、在轻度中最小，且安慰剂本身在抑郁试验中占比很大，这部分源于自然缓解与试验的期待效应。关于“昂贵的糖丸”：把平均效应小误读为没有效应是常见的统计错误；更准确的表述是——对轻度抑郁，心理治疗与运动与等待的差别不大而首选应是非药物的；对中重度，药物能可靠地缩短发作并降低复发的概率，其最重要的证据其实在维持期，因为停药后的高复发率恰恰说明药在起作用而不是在演戏。同时必须承认这一叙事的伤害：把社会的因（在贫困与暴力与孤独与失能的工作上）写成脑内的问题，会转移政策的责任；药企的选择性发表确实发生过，这让公众的怀疑有依据。因此我的立场是：不用“化学失衡”解释抑郁，但承认药物是有效的工具之一；把治疗按严重度分层，把心理治疗与生活的改变放在轻度的一线；把处方与随访与量表与（在六周时的）复评绑定，并如实告诉患者药能做什么与不能做什么——既不神化也不否定（[[#def-treatments]]、[[epidemiology-ebm/critical-appraisal]]、[[public-health/determinants-inequalities]]、[[pharmacology/drug-development-prescribing]]）。**
