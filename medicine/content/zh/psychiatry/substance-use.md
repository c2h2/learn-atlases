酒精、烟草和其他药物在全世界的疾病和过早死亡中占很大比例。仅酒精就与肝病、癌症、损伤、暴力和自杀有关，而烟草仍然是最大的单一可预防死因。物质使用问题在各个医学专科所见的患者中也很常见，却常常未被识别。

本章解释物质使用如何变成障碍、如何进行评估、如何安全地处理中毒和戒断，以及预防复发、替代治疗和减少伤害如何起作用。重点是酒精和阿片类物质，其他物质篇幅较短。全章都要注意用语：说“使用药物的人”，而不是“瘾君子”或“吸毒者”。污名会阻止人们寻求帮助。

## 关键概念

::: definition 物质使用的模式 {#def-dependence}
- **中毒**：由某种物质引起的暂时状态，伴有意识、认知、感知、心境或行为的紊乱，随着物质被清除而消退。
- **有害使用**（ICD-11 称“有害使用模式”）：已对躯体或精神健康造成损害或对他人造成伤害、但不伴依赖的使用模式。
- **依赖**（ICD-11）：一种物质使用调节障碍，表现为以下至少两项：(1) 对使用的控制受损（开始、用量、停止）；(2) 使用逐渐优先于其他活动和责任，并且不顾伤害继续使用；(3) 生理特征：**耐受**（需要更多的量才能达到同样效果）、停止或减量时出现**戒断**症状，或为避免戒断而使用。这些特征通常至少存在 12 个月；如果是持续使用，则为一个月。
- DSM-5-TR 使用单一类别——**物质使用障碍**，根据存在的标准数（共 11 条）分为轻度、中度或重度。
:::

### 为什么使用会变成强迫性的

所有能引起依赖的药物都会增加**中脑边缘奖赏通路**（从腹侧被盖区到伏隔核）中的多巴胺释放。这一系统通常发出信号，表明某事是有回报的、值得重复。

::: theorem 神经适应驱动依赖 {#thm-neuroadaptation}
反复接触某种物质会在大脑中产生与其作用相反的适应性改变。这些改变在药物存在时导致**耐受**，在药物撤除时导致**戒断**，使动机从寻求愉快转向回避痛苦，并强化线索与使用之间的习得性联结。其结果是不顾伤害持续存在的强迫性使用。
:::

::: proof
大脑会以相反方向的调整来应对持续的药物作用。例如，酒精增强抑制性的 GABA-A 受体功能，并抑制兴奋性的 NMDA 谷氨酸受体。长期饮酒后，GABA-A 受体敏感性降低，NMDA 受体上调。当酒精突然撤除时，大脑处于过度兴奋状态：震颤、焦虑、出汗、心动过速，最严重时出现癫痫发作和谵妄。阿片类物质同样抑制去甲肾上腺素能的蓝斑核，蓝斑核通过提高其活性来适应，因此停用阿片类物质会产生去甲肾上腺素激增，出现激越、出汗、腹泻和瞳孔散大。与此同时，与药物使用相关的线索（场所、人、用具）通过奖赏环路及调节它的前额叶皮质中的学习，开始触发多巴胺释放和渴求。随着时间推移，使用越来越少地由愉快驱动，而越来越多地由缓解戒断和渴求驱动。这解释了为什么在戒断结束很久之后复发仍很常见，以及为什么治疗不仅要处理躯体依赖，还必须处理线索、应对方式和患者的处境。
:::

## 酒精

### 酒精的计量：单位

在英国，一个**单位**是 10 mL（约 8 g）纯乙醇。一份饮品中的单位数为：

$$
\text{单位数} = \frac{\text{容量 (mL)} \times \text{ABV (\%)}}{1000}
$$ {#eq-units}

其中 ABV 是酒精的体积百分比。一品脱（568 mL）5% 的啤酒含$568 \times 5/1000 = 2.84$个单位；一瓶 750 mL、13% 的葡萄酒含 9.75 个单位。

英国首席医疗官的低风险饮酒指南（2016 年）建议，为保持较低的健康风险，男性和女性都不应经常每周饮酒超过 **14 个单位**，并应分散在三天或更多天内，且有若干天不饮酒。不存在完全安全的饮酒量。

::: example 采集饮酒史 {#ex-units}
Patrick Doyle 先生，49 岁，说自己“只是喝几杯”。经询问，他每个工作日晚上喝四品脱 5% 的拉格啤酒，周六和周日各喝一瓶 750 mL、13% 的葡萄酒。计算他每周的单位数并加以评论。

::: solution
**工作日。**每品脱 2.84 个单位，四品脱为$4 \times 2.84 = 11.36$个单位；五天共$5 \times 11.36 = 56.8$个单位。

**周末。**每瓶葡萄酒 9.75 个单位；两瓶为 19.5 个单位。

**合计。**$56.8 + 19.5 = 76.3$个单位/周，超过 14 个单位低风险指南的五倍。

**评论。**“喝几杯”是一种常见的低估，通常并非有意。询问饮品的种类、容量和酒精度，以及典型一周的饮酒模式，就能得到准确的数字。在这一水平上，他发生肝病、高血压、心房颤动、多种癌症和依赖的风险很高。下一步是用 AUDIT 以及关于戒断症状和晨饮的问题筛查依赖和危害。
:::
:::

### 筛查与简短干预

**AUDIT**（酒精使用障碍识别测验）是世界卫生组织的 10 项问卷，计分 0–40。在英国的实践中，8–15 分提示风险增加，16–19 分为较高风险，20 分或以上提示可能存在依赖。前三项构成 **AUDIT-C**，是一种快速筛查，计分 0–12，通常 5 分或以上时再进行完整的 AUDIT。

对于饮酒超过低风险水平但无依赖的人，在基层医疗或医院进行五到十分钟的**简短干预**（反馈风险、提供建议、支持其设定目标）可以减少饮酒。有依赖的人需要专科评估。

### 酒精戒断

在已形成依赖的人中，停止饮酒或大幅减少饮酒量会引起戒断。其时间进程对安全照护很重要。

| 距末次饮酒时间 | 典型特征 |
|---|---|
| 6–12 小时 | 震颤、出汗、焦虑、恶心、心动过速、失眠、渴求 |
| 12–48 小时 | 可能出现戒断性癫痫发作（全面性）；一过性幻觉，常为视幻觉 |
| 48–72 小时（可更晚） | **震颤谵妄**：意识混乱、定向障碍、生动的幻觉、严重的自主神经功能亢进（发热、心动过速、高血压），可致命 |

戒断需要医学处理。**苯二氮䓬类药物**（例如氯氮䓬（chlordiazepoxide））是主要治疗；它们作用于同样的 GABA-A 受体，可预防癫痫发作和谵妄。在医院中，NICE 指南（CG100）支持**症状触发**方案，即根据结构化量表（如 **CIWA-Ar**，修订版临床研究所酒精戒断评估量表）的评分给药，而不是按固定时间表给药；在其他场合则使用固定递减方案。剂量和方案遵循当地方案和 BNF。

有计划的社区戒断适合许多人。对于风险较高者建议住院：既往有戒断性癫痫发作或震颤谵妄、饮酒量极大、有严重躯体或精神疾病、缺乏支持，或年轻人和老年人。

::: theorem 在损害发生之前补充硫胺素 {#thm-thiamine}
大量饮酒者由于饮食差、吸收减少和储存受损，有**硫胺素**（维生素 B1）缺乏的风险。硫胺素缺乏引起 **Wernicke 脑病**，这是一种急性的、可能可逆的急症，可进展为基本不可逆的 **Korsakoff 综合征**。意识混乱、眼肌麻痹或眼球震颤以及共济失调这一经典三联征仅见于少数病例，因此必须积极怀疑这一诊断，并以大剂量胃肠外硫胺素治疗。
:::

Korsakoff 综合征导致严重的新记忆形成障碍，常伴虚构（以编造的叙述填补记忆空白，并无欺骗意图）。给硫胺素缺乏者输注含葡萄糖的液体可诱发 Wernicke 脑病，因此应及时给予硫胺素，但绝不能因此延误低血糖的治疗。

::: example 一位被发现意识混乱的老年女性 {#ex-alcohol-older}
Irene Walsh 夫人，72 岁，被邻居发现在家中意识混乱，送至急诊科。她步态不稳，侧视时有眼球震颤，身体消瘦。邻居说，自两年前丈夫去世后，她每天喝“一瓶雪利酒”，三天前酒喝完后就停止了饮酒。她的脉搏 118 次/分，体温 37.9 °C，正在摸弄床单，说上面有虫子。发生了什么？优先事项是什么？

::: solution
**两种急症。**她有 **Wernicke 脑病**的特征（营养不良的大量饮酒者出现意识混乱、眼球震颤、共济失调），也有**震颤谵妄**的特征（停止饮酒三天后出现意识混乱、视幻觉、心动过速和发热）。

**优先事项。**
1. 气道、呼吸、循环；立即检测血糖，如有低血糖则予以治疗。
2. 按照当地方案，立即给予大剂量**胃肠外硫胺素**，作为维生素 B 和 C 制剂的一部分。
3. 在密切监测下用苯二氮䓬类药物治疗戒断，同时认识到老年人对镇静更敏感；请上级医生参与。
4. 寻找发热和意识混乱的其他原因：感染（例如吸入性肺炎）、跌倒所致头部外伤、肝性脑病、电解质紊乱（钠、钾、镁、磷）和低血糖。
5. 恢复营养时监测再喂养综合征。

**之后。**康复后评估认知以排查 Korsakoff 综合征；处理丧亲和抑郁问题；并提供专科酒精治疗。老年人的酒精问题常常因为没有被询问而被漏诊。
:::
:::

### 戒断后的预防复发

戒断本身并不是治疗。如果没有进一步的支持，大多数人会重新饮酒。NICE 指南 CG115（2011 年）推荐心理干预（如基于 CBT 的方法、行为伴侣治疗以及匿名戒酒会或 SMART Recovery 等互助团体），对于中度和重度依赖，在戒断后使用药物：

- **阿坎酸**（acamprosate）：被认为可调节谷氨酸传递；降低复饮风险。
- **纳曲酮**（naltrexone）：阿片受体拮抗剂，减弱酒精的奖赏效应和渴求。不得用于正在使用或需要阿片类药物的人。
- **双硫仑**（disulfiram）：阻断乙醛脱氢酶，因此饮酒会导致乙醛蓄积，出现面部潮红、恶心、心悸和低血压。它起威慑作用，需要监督和患者的决心；反应可能很严重。
- **纳美芬**（nalmefene）可用于帮助无需立即戒断的依赖者减少饮酒量（NICE TA325）。

## 阿片类物质

阿片类物质包括海洛因（二醋吗啡）、处方药物（如吗啡、羟考酮、可待因和曲马多），以及合成阿片类物质（如芬太尼及其类似物），后者在某些国家越来越多地混入非法供应中。

- **中毒和过量**：嗜睡、针尖样瞳孔和呼吸抑制，即过量的典型三联征。耐受下降时（出狱、出院或脱毒后）以及与酒精、苯二氮䓬类或加巴喷丁类药物合用时，风险上升。
- **戒断**：渴求、焦虑、打哈欠、出汗、流涕流泪、瞳孔散大、起鸡皮疙瘩、腹部绞痛、腹泻和肌肉酸痛。海洛因戒断约在 6–12 小时内开始，2–3 天达到高峰，约一周内消退。它非常难受，但与酒精戒断不同，在其他方面健康的成人中很少有危险，尽管脱水和耐受丧失是真实存在的风险。

### 治疗

::: definition 阿片类物质替代治疗与减少伤害 {#def-substances}
**阿片类物质替代治疗**（OST，又称阿片类激动剂治疗）以一种处方的长效阿片类药物取代非法阿片类物质的使用，起初在监督下服用：**美沙酮**（methadone，一种完全激动剂，每日口服液）或**丁丙诺啡**（buprenorphine，一种部分激动剂，每日舌下含服，或每周、每月一次的缓释注射）。OST 减少非法阿片类物质使用、过量致死、血源性病毒传播和犯罪，并使人们留在治疗中。

**减少伤害**是在不要求完全戒断的情况下减少药物使用所造成的损害：针具交换项目，乙型肝炎、丙型肝炎和 HIV 的检测及乙型肝炎疫苗接种，以及向使用阿片类物质者及其家人提供**带回家的纳洛酮**（naloxone），以便逆转过量。
:::

OST 按照专科方案开具处方，其重要的安全要点如下：

- **美沙酮**的半衰期长且变异大，因此在最初几天会蓄积；死亡集中在诱导期。它会延长 QT 间期，并与许多药物相互作用。
- **丁丙诺啡**作为一种受体亲和力高的部分激动剂，对呼吸抑制有封顶效应，因此过量时较安全。如果在完全激动剂仍然存在时开始使用，它可以将其置换出来而引起**催促戒断**，因此应在患者已出现轻度戒断时开始使用。
- 离开治疗是一个高风险时期。耐受迅速下降，因此恢复以前的非法阿片类物质用量可能致命。

::: example 急诊科的过量病例 {#ex-opioid-ed}
Jamal Hussain 先生，38 岁，被发现无反应后送来。他的呼吸频率为 6 次/分，瞳孔呈针尖样，血氧饱和度 84%。一位朋友说他昨天刚出狱。请概述处理。

::: solution
**立即处理。**开放气道、给氧，用球囊面罩通气支持呼吸。按照当地方案给予**纳洛酮**，静脉滴定或肌内注射，目标是恢复足够的呼吸，而不是完全清醒（后者可能诱发严重戒断和激越）。

**观察。**纳洛酮的作用时间比许多阿片类物质短，因此呼吸抑制可能复现；要观察他，必要时重复给药或持续输注。美沙酮等长效阿片类物质需要更长时间的观察。

**寻找其他问题。**检测血糖，寻找同时摄入的药物（对乙酰氨基酚血药浓度、酒精、苯二氮䓬类），检查有无误吸、低体温，以及长时间静卧导致的骨筋膜室综合征或横纹肌溶解。

**理解风险。**出狱是一个过量风险极高的时期，因为耐受已经下降。

**离开前。**提供转介至药物治疗服务（最好能快速获得 OST）、为他和他的朋友提供带回家的纳洛酮及培训、血源性病毒检测以及减少伤害的建议。尊重地对待他；不带评判的态度会让他更有可能再来。
:::
:::

## 其他物质

| 物质 | 主要作用和风险 | 处理原则 |
|---|---|---|
| 大麻 | 放松、感知改变；焦虑和偏执；大量使用高效价大麻时出现精神病性症状和依赖；大麻素剧吐综合征 | 心理社会支持；治疗精神病性症状和共病 |
| 兴奋剂（可卡因、苯丙胺类） | 欣快、精力充沛、焦虑、偏执、精神病性症状；高血压、脑卒中、心肌梗死、心律失常；使用后情绪低落和疲惫 | 中毒时支持治疗；激越时用苯二氮䓬类；无获批的替代药物；心理社会治疗 |
| 苯二氮䓬类、Z 类药物 | 镇静、记忆损害、跌倒；依赖；与阿片类和酒精合用危险 | 戒断可引起癫痫发作；在监督下缓慢减量 |
| 加巴喷丁类（普瑞巴林、加巴喷丁） | 镇静，高剂量时欣快；与阿片类合用时呼吸抑制 | 自 2019 年起在英国为管制药物；逐渐减量 |
| GHB / GBL | 迅速镇静、昏迷；严重且危险的戒断 | 戒断属于医学急症，需要专科照护 |
| 合成大麻素受体激动剂 | 作用不可预测且强烈；激越、精神病性症状、癫痫发作、心脏影响 | 支持治疗 |
| 烟草（尼古丁） | 依赖；危害主要来自烟雾 | 行为支持加伐尼克兰、尼古丁替代疗法、金雀花碱或电子烟 |

关于烟草，NICE 指南（NG209，2021 年）支持将含尼古丁的电子烟作为希望戒烟的成人的一种选择，并说明其危害远小于吸烟，但并非没有风险。伐尼克兰（varenicline）在 2021 年因杂质问题撤出后，于 2024 年重新回到英格兰 NHS 戒烟服务中。药物与行为支持相结合，戒烟成功的机会最大。

::: example 一个关于大麻的问题 {#ex-cannabis-psychosis}
Liam O'Connor 先生，17 岁，每天吸食高效价大麻已两年。他的父母带他来看全科医生，因为他变得多疑，认为社交媒体上的人在议论他。他问：“大麻不是天然的、安全的吗？”全科医生应如何回应？

::: solution
**评估。**探究这些信念（是否坚定？有无幻觉？）、心境、自杀想法和功能。经常使用大麻者的偏执观念可能是一过性的中毒效应，也可能是精神病性障碍的开始。疑似首发精神病需要紧急转诊至精神病早期干预服务。

**诚实地回答。**天然并不意味着安全。经常使用高效价大麻，尤其是从青春期开始，与精神病性障碍风险增加有关，精神病性发作后继续使用与更多的复发有关。大麻依赖确实存在，戒断症状有易激惹、睡眠差和食欲下降。

**引导参与，而不是说教。**使用动机式方法：询问他从大麻中得到了什么、他担心什么；尊重他的自主权；通过青少年药物服务为他减少或停止使用提供支持。在他同意的情况下让父母参与，并商定尽快复诊。
:::
:::

## 共病情况

::: definition 精神疾病与物质使用共病 {#def-comorbidity}
**共病情况**（有时称为双重诊断）是指同一个人同时患有精神障碍和物质使用障碍。两者的关系是双向的：物质可以引起或加重精神症状（酒精与抑郁、兴奋剂与精神病性症状），而精神障碍又使人们借助物质来应对（用酒精应对焦虑，用大麻应对痛苦）。两者应由相互协作的服务机构同时治疗，而不是一个机构等待另一个问题先解决。
:::

共病者的自杀、躯体疾病、无家可归以及与刑事司法系统接触的比例更高。NICE 指南（NG58，2016 年）强调，不应因为物质使用而将人们排除在精神卫生服务之外。

::: example 变成问题的止痛药 {#ex-gabapentinoid}
Rachel Green 女士，44 岁，患慢性背痛，服用处方的普瑞巴林和可待因，最近还服用从网上购买的地西泮。她要求全科医生提前开药，因为她“吃完了”。她看起来昏昏欲睡。有哪些担忧？全科医生应如何处理？

::: solution
**担忧。**加巴喷丁类药物、阿片类药物和苯二氮䓬类药物合用会大大增加致命性呼吸抑制的风险。提前要求开药、嗜睡以及网上购药提示存在问题性使用和可能的依赖。非法购买的“地西泮”可能是假药，含有效力更强的苯二氮䓬类物质。

**处理方式。**坦诚、不带责备地与她交谈。评估她的疼痛、心境、睡眠和自杀想法，询问所有物质，包括酒精。不要突然停用所有药物，因为苯二氮䓬类或加巴喷丁类药物的戒断可引起癫痫发作。

**计划。**约定只由一名处方者开药、只在一家药房取药，每次供应量更少、更频繁；以安全为先，计划逐步减少这些药物的联合使用；提供带回家的纳洛酮；转介至疼痛服务，制订不以药物为中心的计划（体力活动、心理方法）；如确认依赖，则让药物服务参与。定期复查。清楚地记录有关管制药物的决定。
:::
:::

### 酒精清除的时钟

与大多数药物不同，一旦血液中的浓度达到中等水平，乙醇就以大致恒定的速率被清除，因为乙醇脱氢酶已经饱和（零级动力学）。典型的速率约为每小时 15 mg/100 mL，但个体差异很大，许多大量饮酒者的清除更快。这解释了为什么一个人在大量饮酒后的第二天早上仍可能超过法定驾驶限值。

::: widget plot
f: c - 15*x
x: 0, 20
y: 0, 300
sliders: c=200:50:300:10
hlines: 80
labels: \text{血液酒精浓度（mg/100 mL）}
caption: 一个简化的零级清除模型：血液酒精浓度每小时下降约 15 mg/100 mL（示意性平均值；实际速率差异很大）。水平线表示 80 mg/100 mL，即英格兰和威尔士的法定驾驶限值（苏格兰的限值更低，为 50）。如果午夜时为 200 mg/100 mL，要到早上 8 点左右才会降到 80 以下。睡觉、喝咖啡和洗澡都不能加快这一过程。
:::

::: warning 不要给正在使用阿片类药物的人开纳曲酮
纳曲酮阻断阿片受体。在阿片类物质依赖者中，它会诱发突然的严重戒断，还会阻断阿片类止痛药的作用。在为酒精依赖开具纳曲酮之前，要仔细核查有无任何阿片类物质使用，包括处方的可待因或曲马多以及 OST，并告诉患者服用期间阿片类止痛药将无效。同样，停用纳曲酮后，对阿片类物质的敏感性可能增加。
:::

::: quiz
一名每天喝一瓶伏特加的男性入院接受择期手术，在入院前一晚最后一次饮酒。大约 36 小时后，他出现了一次全面性癫痫发作。下列哪项说法正确？
- [ ] 戒断性癫痫发作只在五天后出现，因此更可能是其他原因。
- [x] 癫痫发作通常在末次饮酒后 12–48 小时出现，这一模式符合酒精戒断。
- [ ] 预防酒精戒断的最佳方法是给他少量饮酒。
- [ ] 由于有依赖风险，苯二氮䓬类药物属于禁忌。
::: solution
戒断性癫痫发作通常在末次饮酒后 12–48 小时出现。仍须排除其他原因（头部外伤、低血糖、电解质紊乱）。苯二氮䓬类药物是预防和治疗戒断的首选药物，每一位入院的大量饮酒者都应筛查依赖，以便预见戒断。
:::
:::

::: history
大约在 1800 年，美国的拉什（Benjamin Rush）和英国的特罗特（Thomas Trotter）提出酗酒是一种疾病的观点。1881 年，韦尼克（Carl Wernicke）描述了以他名字命名的脑病；19 世纪 80 年代末，科尔萨科夫（Sergei Korsakoff）描述了遗忘综合征。1935 年，比尔·威尔逊（Bill Wilson）和鲍勃·史密斯（Bob Smith）创立了匿名戒酒会。多尔（Richard Doll）和希尔（Austin Bradford Hill）在 20 世纪 50 年代的研究确立了吸烟是肺癌的病因。1965 年，纽约的多尔（Vincent Dole）和奈斯旺德（Marie Nyswander）报告了针对海洛因依赖的美沙酮维持治疗。1976 年，爱德华兹（Griffith Edwards）和格罗斯（Milton Gross）描述了**酒精依赖综合征**，这是现代 ICD 标准的基础。20 世纪 80 年代英国对 HIV 的应对带来了针具交换，并使减少伤害成为公共卫生政策。
:::

## 后续内容

酒精相关性肝病见[[gastrointestinal/liver-disease]]；中毒和过量见[[emergency-critical-care/poisoning]]；药物依赖和不良反应见[[pharmacology/adverse-reactions]]；酒精和烟草政策见[[public-health/prevention-promotion]]。

::: summary
- 依赖包括控制受损、不顾伤害而使用的优先性上升，以及生理特征（耐受、戒断）；有害使用造成损害但不伴依赖。
- 所有成瘾性药物都增加中脑边缘多巴胺；神经适应产生耐受和戒断，并使使用转向缓解痛苦。
- 一个英国单位是 10 mL 乙醇；单位数 = 容量（mL）× ABV / 1000；低风险指南为每周 14 个单位。
- AUDIT 和 AUDIT-C 筛查危险饮酒；简短干预对无依赖的饮酒者有效。
- 酒精戒断可引起癫痫发作（12–48 小时）和震颤谵妄（48–72 小时）；苯二氮䓬类药物是治疗药物，在医院中最好采用症状触发方案。
- 要积极怀疑 Wernicke 脑病，并给予胃肠外硫胺素。
- 戒断后，心理支持加阿坎酸、纳曲酮或双硫仑可减少复发。
- 阿片类物质过量引起昏迷、针尖样瞳孔和呼吸抑制；纳洛酮可逆转，但其作用可能先于阿片类物质消退。
- 美沙酮和丁丙诺啡替代治疗、针具交换和带回家的纳洛酮能挽救生命；出狱或离开治疗是高风险时期。
- 同时治疗共病的精神疾病和物质使用，不要将人们排除在照护之外。
:::

## 习题

::: exercise 一瓶酒中的单位数 {level=1 check="28"}
一瓶 700 mL、40% 的伏特加含有多少个英国单位？
::: solution
单位数$= 700 \times 40/1000 = 28$。每天一瓶即每周 196 个单位，是低风险指南的十四倍。
:::
:::

::: exercise 依赖还是有害使用？ {level=1}
一名 25 岁男性每个周六晚上喝 30 个单位的酒，因打架两次被警方警告，但一周其余时间滴酒不沾，没有戒断症状，想停就能停。请对他的饮酒模式进行分类并说明理由。
::: solution
有害使用模式（或危险饮酒）：他的饮酒已对自己和他人造成伤害（暴力、警方介入），但缺乏依赖的特征：没有控制受损，饮酒不优先于其他活动，没有耐受或戒断。他会从简短干预以及关于狂饮风险的讨论中获益。
:::
:::

::: exercise 戒断的时间 {level=1}
描述酒精戒断的典型时间进程，并给出戒断性癫痫发作和震颤谵妄出现的时间。
::: solution
症状在末次饮酒后 6–12 小时开始，表现为震颤、出汗、焦虑、恶心和心动过速。癫痫发作通常在末次饮酒后 12–48 小时出现。震颤谵妄伴意识混乱、幻觉和严重的自主神经功能亢进，通常在末次饮酒后 48–72 小时开始，也可能更晚出现。
:::
:::

::: exercise 每周总量 {level=2 check="round(10*(3*750*12/1000 + 4*440*4.5/1000))/10"}
一名女性每周喝三瓶 750 mL、12% 的葡萄酒和四罐 440 mL、4.5% 的苹果酒。计算她每周的单位数，保留一位小数。
::: solution
葡萄酒：$3 \times 750 \times 12/1000 = 27$个单位。苹果酒：$4 \times 440 \times 4.5/1000 = 7.92$个单位。合计$= 34.92$，即每周**34.9**个单位，约为低风险指南的两倍半。
:::
:::

::: exercise 第二天早上 {level=2 check="(180-80)/15"}
采用血液酒精浓度每小时下降 15 mg/100 mL 的简化模型，180 mg/100 mL 的浓度需要多少小时才能降到 80 mg/100 mL 的驾驶限值？
::: solution
需要下降$180 - 80 = 100$ mg/100 mL。按每小时 15 mg/100 mL 计算，需要$100/15 \approx 6.67$小时，约 6 小时 40 分钟。实际清除速率各不相同，因此唯一安全的建议是：前一晚大量饮酒后不要开车。
:::
:::

::: exercise 选择预防复发的药物 {level=2}
一名 52 岁男性已完成酒精戒断。他因膝骨关节炎规律服用复方可待因对乙酰氨基酚（co-codamol），并患有中度慢性肾脏病。请讨论在阿坎酸、纳曲酮和双硫仑之间如何选择。
::: solution
在他服用可待因期间，纳曲酮不适用，因为它阻断阿片受体，会诱发戒断或使镇痛失效；首先需要改变他的疼痛管理方案。阿坎酸经肾脏排泄，在肾功能受损时根据严重程度属于禁忌或需慎用，因此必须对照 BNF 核查他的 eGFR。双硫仑需要患者的决心和监督，并有心血管和肝脏方面的风险；一般为二线选择。选择取决于他的肾功能和疼痛方案，任何药物在配合心理支持时效果最好。合理的做法是先重新评估他的镇痛方案（例如适合其肾功能的非阿片类选择和物理治疗），如果能停用阿片类药物则考虑纳曲酮，如果肾功能允许则考虑阿坎酸。
:::
:::

::: exercise 美沙酮诱导期 {level=3}
解释为什么美沙酮治疗中的死亡集中在治疗的最初两周，并列出降低这一风险的三项措施。
::: solution
美沙酮的半衰期长且变异大（常为 24 小时或更长，但个体间差异很大）。每日重复给药时，它会蓄积直到达到稳态，这可能需要约五个半衰期，因此在第一天看似耐受良好的剂量之后，血药浓度仍会持续上升数天。如果加量过快，或患者同时使用海洛因、酒精、苯二氮䓬类或加巴喷丁类药物，就可能发生呼吸抑制，常常发生在睡眠中。耐受程度也可能被高估。措施：按照专科方案从低剂量开始并缓慢加量；早期数周内每日在监督下服药；频繁复查有无镇静；提醒患者和家属不要合用其他物质；提供带回家的纳洛酮；有指征时检查心电图和相互作用的药物。
:::
:::

::: exercise 一个住院病例 {level=3}
一名 60 岁男性因肺炎入院。第 2 天，他变得激越、出汗、震颤，脉搏 125 次/分，并拔掉了静脉留置针。团队怀疑是脓毒症所致的谵妄。还应考虑什么替代性或附加的诊断？什么信息可以证实它？应如何处理？
::: solution
在考虑脓毒症相关谵妄的同时，还应考虑酒精戒断，并可能进展为震颤谵妄；两者可能并存。信息：从家人或全科医生处获取知情人饮酒史、AUDIT、既往住院或戒断史、血液检查（MCV、GGT 升高，血小板减少）以及时间（在入院即停止饮酒后约 36–48 小时起病）。处理：治疗肺炎；用结构化量表评估戒断，并按照当地方案给予苯二氮䓬类药物；针对可能的 Wernicke 脑病给予胃肠外硫胺素；纠正电解质，包括镁、钾和磷；在安静、光线充足的环境中护理；避免单用抗精神病药，因为它们会降低癫痫发作阈值，且不能治疗戒断。每一位入院的成人都应被询问饮酒情况，以便预见戒断，而不是很晚才识别出来。
:::
:::
