成瘾的照护是精神科里最被低估的一门临床：**物质使用几乎总是与共病、污名、反复的失约与系统的排斥同行，而它的有效治疗并不复杂：稳定的关系、按阶段的目标、可以执行的药物与不把人赶走的制度。**本章覆盖依赖与戒断与治疗的框架（诊断的实质与其维度、戒断的危险与药物治疗的位置）、主要物质（酒精与阿片与兴奋剂与 大麻 与尼古丁各自的病程与治疗）、以及横贯的问题（共病与妊娠与服务的组织）。

## 一般的装置

::: definition 依赖、戒断与治疗的框架 {#def-dependence}
**依赖的旧概念是“耐受与戒断”，现在的描述更贴近临床：对物质的渴求与控制的失败与不顾后果的继续与时间的让位，按严重度分轻中重三级。它的要点是把诊断落在行为上而不是落在“是不是一天多少”上：一个每天喝四酒单位但无法在说“不喝”之后做到的人，与一个偶尔大量饮酒但能控制的人，前者才是问题。戒断的危险按物质分：酒精与苯二氮的戒断可以致命（在抽搐与（在谵妄的），其风险随既往的戒断的严重度与（在（ 同时使用的）与（在肝病上的）而升高，所以“最后一次饮酒的时间”是病史中必须问的一项；阿片的戒断极不舒服但通常不致命（在脱水与（在心脏病者中的））的）），而它的可怕之处是复吸后的过量（在耐受的下降上），这才是真正的死亡机制；兴奋剂与 大麻 与尼古丁的戒断不危及生命但会摧毁当天在睡眠与在食欲与（在（情绪上的））。治疗的框架有四根柱子。第一根是评估而非说教：把她的目标（可以是减量，可以是安全，可以是保住孩子或工作）作为治疗的目标，否则第一次会谈就结束了。第二根是动机的工作：不争论，而是反映矛盾（她既想继续也想停下，两个都是真的），并把差别说出来（“上周有一次你觉得不必喝，那次有什么不同”）。第三根是药物：阿片的激动治疗（在美沙酮与丁丙诺啡之间选择，前者需要每日的服药与QT的关注，后者可以可以在门诊起始并有封顶的安全性）能把死亡与在犯罪与（在HIV上的）显著降低，是任何服务的第一优先；酒精的用阿坎酸 与纳曲酮与（在若干病例中的）双硫仑与（在戒断后的）的减重药（在若干证据下的）；尼古丁的替换与伐尼克兰是最被低估的救命处方。第四根是连续性：包括在最不愿意见到的那个人身上；每一次“这次我们没办法”都是下一次过量。
服务层面要问四个问题：出院与急诊离开的当天有没有人接手；镇痛与（在（牙科上的））与（在妊娠中的）的照护会不会因为她的用药史而被拒绝；类药物是否可在门诊获得；以及她的记录里是否只有“不配合”而没有“为什么”。诚实的一点：完全戒断是许多人的目标，但不是唯一的目标；把“复发”重新定义为病程的一部分而不是道德的失败，会改变团队的行为——从“ 她又犯了所以结案”变成“她这次需要什么”（[[psychiatry/mood-disorders]]、[[emergency-critical-care/poisoning]]、[[pharmacology/adverse-reactions]]、[[public-health/health-systems-economics]]）。**

## 主要的物质

::: definition 酒精、阿片、兴奋剂、大麻与尼古丁 {#def-substances}
**酒精：筛查用两条问题或AUDIT，用意在“值得谈一次”而不是定罪；风险的沟通要用绝对数与她的处境肝的纤维化的程度与血压与（在睡眠上的）与（在抑郁上的），而不是“每天三杯会死”。戒断的处理按风险分层：门诊的在既往无抽搐与谵妄者与（在当日饮酒量下的）苯二氮的递减的方案（在若干体系中用氯氮䓬与（在肝病时用劳拉西泮））与社区的照护与硫胺素（在给糖之前）；住院的（在谵妄与（在抽搐史上的）需要按评分给药的方案（在症状的指导下优于固定的剂量）与（在低钾低镁时的）纠正与（在定向与（在灯光与（在熟悉的人上的）的环境上的））。长期的治疗：纳曲酮（在肝病与（在阿片使用者中的）禁忌）与阿坎酸（在肾功能不全时减量）与（在若干体系中的）双硫仑（在明确的监督下与（在酒精-双硫仑反应的风险上的）），加上任何能被使用的心理的与互助的项目（在动机式的访谈与（在认知的行为的治疗与（在十二步的互助中的））；最重要的常常不是药而是“她的晚上变成什么样”。阿片：激动治疗是预后最好的干预；剂量要足（在美沙酮与丁丙诺啡下的过量的死亡大幅减少），并提供纳洛酮的携带与（在使用者中的）教育（在被目击时的））与（在不与酒精或苯二氮同用时上的））；同时治疗疼痛（在她不再被当作“寻求药物的人”时，疼痛是可以被评估的）与（在牙科与（在手术后的））的镇痛的路径要事先写下。兴奋剂：没有可靠的替代激动剂；有效的是结构化的权变强化在阳性的尿与在（奖励的存取上的）与在群组与在（运动与（在住房上的）的）行为的治疗与（在（睡眠与（在进食上的）的）恢复）；戒断后的抑郁与（在自杀意念上的）需要一周内的复评。大麻：多数使用者不会到障碍，但对每日使用与（在青少年起病与（在家族的精神病史者中的））的精神病的风险要说清，且“没有解药”不等于“没有办法”：停用的尝试与在（睡眠与（在焦虑上的）的）处理与在（动机的工作上的）的几次会谈常能改变轨迹。尼古丁：每一次住院与在（每个门诊的）处方都是戒烟的机会；联合的替换（在贴片加上（在急用时的）含片或胶）与伐尼克兰在精神科的病史与（在监测下的）与（在（电子烟作为减害的过渡与（在其后的停用它上的）的））是本章效果最大的成本效益之一。
**要提醒的一条是：把兴奋剂与大麻的“治疗”完全交给刑事或行政的系统，会让最需要帮助的人永远到不了门诊。**

## 横贯的问题

::: definition 共病、妊娠与服务 {#def-comorbidity}
**共病是常态而非例外：多数成瘾的就诊者同时有情绪的或焦虑的或创伤相关的问题，或注意的障碍或人格的困难。原则是同时治疗、由同一团队治疗：把她的饮酒“等她的情绪好了再说”或“先把抑郁治好她就不喝了”，都会让她在两个门之间掉下去。自伤与（在自杀意念上的）的风险在（在酒精的中毒期与（在兴奋剂的崩溃期上的））都升高，所以每一次危机接触都要包括物质的病史与（在（把药冲走的能力上的））。妊娠：酒精没有已知的安全剂量，问询要用具体的问题（在最后一次饮酒的周数与（在量与频率上的））而不是标签；治疗的核心不是断言风险而是帮她减少（在她的伴侣与家庭的参与下）与在（产科与新生儿与（在社工的）的共同计划）；苯二氮的戒断的处理在妊娠中同样需要（未治疗的戒断与（在抽搐与（在胎儿的缺氧上的）的风险更高），并优先用长一点的递减与（在若干体系中的）专科的）监护；阿片的激动治疗在妊娠中是标准在（在监督下的）分娩期的继续与在（（在新生儿戒断后的）儿的照护），而突然的停用与在胎儿的窘迫与（在早产上的）相关。服务的设计要按这条人群的现实：门诊的“两次爽约即结案”是最常见的排除机制；预约的时间要避开工班与照护；尿的检查只能用于治疗的调整而不能成为信任的前提；镇痛与在牙科与（在手术后的）的可及应当被写在政策里。最后要问的是污名的位置：多数伤害不是在戒断时发生，而是在她被认为不值得被治的时候发生（[[psychiatry/mood-disorders]]、[[psychiatry/self-harm-suicide-prevention]]、[[obstetrics-gynaecology/pregnancy-complications]]、[[public-health/health-systems-economics]]）。**

::: example 本可以不一样的急诊出院 {#ex-opioid-ed}
一名28岁的男性因海洛因的两次过量被同一急诊救治，第二次用了纳洛酮；他清醒后要求出院，说“我朋友能给我弄到药”；急诊给了他一份戒毒热线的单子，他在十一天后第三次过量死亡。
::: solution
**这一例的每一处都是可改的（[[#def-dependence]]、[[#def-substances]]、[[emergency-critical-care/poisoning]]）。第一处：他把纳洛酮的逆转当作“最后一次”，这是过量幸存者的典型心理，因此清醒后的三十分钟是最有产出的三十分钟，需要有人坐在他旁边谈，而不是递一张单子。第二处：出院计划里没有替代治疗的可及性。阿片的激动治疗应当在那次就诊内被启动：急诊或观察病房内即可给丁丙诺啡（在戒断评分达到一定水平后起始，或在若干方案中的低剂量法），并在出院前预约门诊的第一次服药；把“你去找戒断中心”当成计划等于没有计划。第三处：他和他的同伴没有被给纳洛酮。所有过量幸存者的同伴与家属都应当拿到一套纳洛酮并学会用（在（不呼吸时的）），因为多数致命的过量发生在有人在场时；把 纳洛酮 放在急诊的药柜之外、按不需要处方的方式给，是把死亡前移的最便宜的措施。第四处：没有人记录他的用药史与镇痛的需要，因此下一次他来的时候，所有人看到的仍是“那个过量的人”。第五处：出院后的两周是死亡风险最高的时段之一；如果那次出院时已联系好门诊并在四十八小时内有一次电话或面对面的接触，第三次可能不会发生。系统要做的三件事：把“过量之后”设为一条有专人负责的路径（启动激动治疗、给纳洛酮、四十八小时内联系、三日内见到人）；在培训里说明拒绝激动治疗的启动是不当的做法；以及把这一类死亡纳入与当地防自杀同等级的审查，因为它通常被归为“他选择不接受治疗”，而这种归因会让同样的错误重复出现（[[clinical-skills/patient-safety]]、[[emergency-critical-care/acute-assessment]]、[[public-health/health-systems-economics]]）。**

::: example 每天晚上的那杯酒 {#ex-alcohol-older}
一名71岁的退休工程师，妻子两年前去世后每天晚饭后喝半瓶到一瓶威士忌，“睡前再来两片劳拉西泮”；他否认其他问题；钠131、γ-谷氨酰转移酶升高、近三个月两次跌倒、一次轻微的碰撞后脑出血已吸收。
::: solution
**老年饮酒是被漏得最多的一类，因为它常常“从不闹事”（[[#def-substances]]、[[#def-comorbidity]]、[[geriatrics-palliative/polypharmacy]]）。要点有六。第一，筛查要用适合年龄的话：不是“你是不是酒鬼”，而是“一天里什么时候喝、多少、什么时候不喝”；他说的量要按标准单位换算（半瓶到一瓶威士忌相当于每日数十克以上的纯酒精，在老年女性与男性都已进入危险的区间）。第二，先想它是后果也是原因：丧偶的哀伤与失眠与（在退休后的）生活的空洞与（在轻度认知下降时的）去抑制都靠这杯酒处理，所以单给“少喝点”的处方不会改变晚间的结构。第三，劳拉西泮与酒精的叠加是他跌倒与脑出血的最可能解释，也是记忆的主诉的常见原因；苯二氮在老年本身就应避免，与酒精同用会增加呼吸的抑制与在（夜间时的）的混乱。第四，减药与减酒不能同时骤停：苯二氮的递减要慢（数周到数月的计划，一次只减一档），而酒精的减量要评估既往的戒断（抽搐与谵妄的病史与晨间的出汗与手抖）；如果他真的依赖，递减可以在门诊完成，但必须给硫胺素与（在低钠时的）复查与家属的说明。第五，低钠要按酒性多饮与（在啤酒与（在（利尿剂使用）上的）的机制考虑，同时查甲与（在（皮质醇上的））的（在若干病例中的））其他原因。第六，最被低估的治疗是白天与晚上的安排：把晚饭后的时间填满在散步与在（在社区中的）、把酒移出可及的地方、让他的女儿或朋友参加一次门诊、治疗失眠的非药物部分、以及（在抑郁确实存在时）抗抑郁的治疗；对若干人，阿坎酸或纳曲酮可以降低渴求（在肝病与（在肾功能上的））注意与（在（疼痛科的阿片同用时的）纳曲酮的禁忌）。要说的那句实话：他再这样喝两年，一次跌倒或一次出血就可能结束他的独立生活，而现在减量，多数损害可以恢复——[[geriatrics-palliative/falls]]、[[psychiatry/mood-disorders]]、[[clinical-skills/communication]]、[[renal/potassium-calcium-phosphate]]。**

::: example 加巴喷丁的阶梯 {#ex-gabapentinoid}
一名46岁的女性因慢性疼痛与焦虑在三年中被加上加巴喷丁，目前每日3600毫克；她想停药，但每次减两百毫克就“浑身不对”；她的全科担心“成瘾”，神经科认为“她需要它”。
::: solution
**加巴喷丁类的滥用与依赖是过去十年新增的问题，而它常常由两个好意的处方叠加而成：疼痛与焦虑，两个科室各加一点，谁也没有计划怎么减（[[#def-dependence]]、[[pharmacology/adverse-reactions]]、[[geriatrics-palliative/symptom-control]]）。先承认两件事：她的“浑身不对”是真的戒断（在焦虑与失眠与出汗与恶心与（在重者中的）抽搐样的表现），而她的疼痛与焦虑也是真的；把“成瘾”与“依赖”与“需要”分开，才能决定做什么。诊断的线索：为了追求放松或欣快而加量、提不出疼痛的变化却要求更多、与其他的中枢抑制药同用、在拿不到药时出现异常的寻找行为；这些行为可以出现在完全合规的患者身上，因为剂量本身已经很高。做法：先定一个共同的目标（在两个科室都同意的书面的计划下减到可耐受的低剂量或停），一次只减一档并按她的耐受调速度（常见的做法是每二至四周减总量的一成，在低剂量段更慢）；同时给替代（疼痛的非药物的路径与（在睡眠上的））的行为的处理与（在焦虑上的）心理治疗与（在抑郁时的）抗抑郁的选择（在度洛西汀与（在米洛西林的））的适应证下的。不要用突然停药来“证明她没有依赖”，也不要在她减不下去时加回原来的剂量了事；每一次尝试之间留出数周的稳定期并把已经做到的部分记录下来，因为她的自动想法常是“我永远离不开”。若她出现欣快与（在剂量自我增加上的）与其他抑制药的合并，则需要成瘾专科的参与，并把处方的方式改为短期与固定的时间（避免“补开”的窗口），同时向她解释这不是惩罚而是安全的设计。也要处理她正在经历的：长期疼痛本身的可治性有限，而“减掉这一片”的谈话容易让她感到被放弃，所以每一步都要与“我们能为你做什么”一起给（[[musculoskeletal/back-pain]]、[[psychiatry/anxiety-disorders]]、[[clinical-skills/communication]]、[[surgery/anaesthesia-pain]]）。**

::: example 大麻与精神病的疑问 {#ex-cannabis-psychosis}
一名19岁的男生在两年几乎每天使用高效价的大麻后出现被监视的观念与听不见的声音；他的父母要求“给他做脑的核磁并把他送进戒断中心”；他本人说“是他们在害我”。
::: solution
**这里有两个都可真实的原因，而且它们常常同时存在（[[#def-substances]]、[[#def-comorbidity]]、[[psychiatry/psychotic-disorders]]）。大麻与精神病的关系是剂量与频率与起病年龄依赖的：每日使用与高四氢大麻酚的产品与（在青少年期开始的）与（在有家族史的）会把首次发作精神病与转换到持续的精神病的风险提高若干倍；但同时，多数大麻使用者不会患精神病，所以“是大麻引起的”这一判断既不能靠时间关系确立，也不能靠否认排除。临床的处理是：先按一次精神病性的状态处理（风险的评估与（在激越与不进食与不睡上的））的收住的考虑与（在若干病例中的）抗精神病药的短期使用，并说明“无论起因是什么，现在这些体验对你都是真实的、可以治疗的”；对父母则给出可核查的计划而不是道德的判定。检查的重点在身体与共病：物质的筛查（在合成的大麻的制品与（在兴奋剂与（在致幻剂上的）的）假阴性与假阳性要知道）与（在甲与（在维生素与（在感染与（在自身免疫的脑炎上的）的））的筛查与（在神经的体征与（在头部的外伤史上的））时的）影像，“常规做核磁”在没有指征时收益低而延误治疗。关键的时间实验：在停用的数周内复评。若症状随停用与睡眠的恢复明显消退，则物质诱发的可能性大；若在停用四至六周后仍持续，则应按精神病性的障碍治疗并进入早期的干预的路径。要交代给全家的：继续使用的年轻人复发与转换的风险更高，所以减少使用是治疗的一部分，但不是道德的考试；以及早期的睡眠与学业与工作的恢复比争论“病因”更能改善结局。最后一条是父母的角色：把“他必须去戒断中心”变成“他愿意接受的最低强度的帮助”，因为拒绝之后被送去的地方通常不能提供他需要的（[[paediatrics/adolescent-health]]、[[psychiatry/psychotic-disorders]]、[[nervous-system/neuroinflammation]]、[[clinical-skills/communication]]）。**

## 通向何处

诊断与风险的评估见[[psychiatry/psychiatric-assessment]]；共病的情绪与焦虑的问题见[[psychiatry/mood-disorders]]与[[psychiatry/anxiety-disorders]]；自伤与自杀见[[psychiatry/self-harm-suicide-prevention]]；中毒的急救见[[emergency-critical-care/poisoning]]；妊娠与新生儿见[[obstetrics-gynaecology/pregnancy-complications]]与[[paediatrics/newborn]]；药物的相互作用与不良反应见[[pharmacology/metabolism-excretion]]与[[pharmacology/adverse-reactions]]；服务的组织见[[public-health/health-systems-economics]]。

::: history
**成瘾的治疗史在很大程度是一部“谁负责”的历史。十八世纪以前的欧洲把醉酒当作道德的失败与穷人的习惯；十九世纪的禁酒运动把它变成社会问题，而1904年的瑞典与（在若干美国州的）禁令证明法律的禁令可以压制销售却压不住需求，并催生了非法的供应。“作为疾病的成瘾”这一框架由美国的医师协会与（在1950年代的）Rush 的酒瘾委员会与（在酒精的匿名者会的）十二步的运动共同推广：后者在1935年由一位商人与一位医生建立，其互助的模式在世界范围内比任何机构都更持久，尽管其随机对照的证据直到2020年前后才被比较认真地积累。医学的一翼从1950年代的双硫仑开始，随后是1965年 Dole 与 Nyswander 的美沙酮维持：他们用一项长期 的研究证明海洛因的成瘾者可以在口服的美沙酮上稳定地生活与工作，从而把“戒断是唯一出路”的教条打开了一个缺口；此后六十年的证据一再重复这个结论：维持治疗降低死亡、犯罪与（在HIV上的）传播，而强制的、以完全戒断为唯一目标的机构，其后的过量死亡风险反而升高。戒断的医学来自两个方向：一是苯二氮把酒精的戒断从一种高死亡率的急症变成了可以在门诊处理的问题（1960年代以后），二是1990年代对磷与硫胺素的再喂养的认识（见本章另一处）。纳洛酮的故事最有实践意义：它1960年被合成，长期只用于医院，1990年代后被改造为可自行使用的制剂并在各地改为无需处方的分发；在若干城市的评估显示，把它交给使用者与其同伴之后，被目击的过量可以在现场被逆转——这是从药理到公共卫生最短的一条路径。政策的转折出现在2001年的葡萄牙：把个人使用的持有非罪化，同时把资源投入卫生与社会的（在劝导的委员会与（在治疗的接入上的），其后的评估显示高风险的使用与（在HIV的传染上的））下降而没有出现使用率的上升；与之相对的是把成瘾交给刑事系统的代价，在若干国家的阿片危机中被证明是致命的。最近二十年有三件事改变了本专科的面貌：纳曲酮与丁丙诺啡的复方与（在长效的注射剂型上的）出现，使“每天到门诊”不再是唯一可行的方案；减害的语言在安全的使用的教育的与在（针具的交换与（在过量后的救援上的））从边缘进入指南；以及对“脑病”这一模型的批评在里希滕斯坦与（在的）——它提醒我们，脑的改变是真实的，但把它当作“疾病的全部”会削弱社会环境与意义在治疗中的地位，也会被用来为强制的、缺乏同意的治疗辩护。本章的立场是把两者都当作真的：物质改变了脑，因此药物可以救人；人活在关系与处境里，因此羞辱会杀人——[[pharmacology/drug-development-prescribing]]、[[public-health/health-systems-economics]]、[[emergency-critical-care/poisoning]]、[[medical-ethics-law/ethical-principles]]。**
:::
::: summary
- 依赖的诊断落在行为上：渴求、控制失败、不顾后果、时间让位，而不是“每天多少”。
- 酒精与苯二氮的戒断可以致命，危险最强 预测因素是既往戒断的严重度；阿片戒断不难受致死，真正死于复吸后的过量。
- 阿片的激动治疗降低死亡与（在犯罪与（在HIV上的）），应作为第一优先；纳洛酮要交到同伴手里才有效。
- 老年饮酒几乎总被漏掉，因为它不闹事；与苯二氮的同用是跌倒与出血的可治原因。
- 共病要同时治疗、同一团队治疗；把物质问题“等情绪好了再说”等于把她推到两个门的中间。
- 妊娠中没有安全的酒精剂量；阿片的激动治疗是标准，突然停用有害。
- 污名是临床变量：被拒绝的一次就诊，常常就是最后一次过量前的最后一次接触。
:::

**支持的一方：反复的用药确实改变脑，尤其在突触的可塑性与在（前额的控制与（在纹状体的奖赏预测上的））的学习回路上，这解释了耐受的加深与渴求的持久与在戒断数月后仍会被线索触发的复发；把它称作“病”移走了道德的责备，使药物与保险与（在（早期干预上的））的介入有了正当性，并在实践中显著减少了 医师说“这是她自己选的”的频率（[[#def-dependence]]、[[pharmacology/drug-development-prescribing]]）。反对的一方：任何“学习与动机的持久改变”都可以被说成脑病，这个定义因此过宽，几乎不可反驳；把复发的原因放在个体脑内会淡化真正的病因在贫困与在创伤与在疼痛的可得性与（在住房与（在社会的孤立上的），并已经在若干场合被用来为强制的治疗与（在工作场所的）的筛查辩护；同时，“慢性病”的框架容易让人以为治疗必须终身、且以完全戒断为唯一目标，而现实是多数成瘾者最终自然缓解且恢复的轨迹多样。我的立场与服务的含义：把它当作“脑被改变的、由处境驱动的、可以治疗的”三类陈述同时成立。含义有四：一，用药物治疗（尤其阿片的激动治疗）而不是只讲意志；二，把资源放在她的处境（住房与工作与疼痛与（在创伤后的））的治疗）而不是只放在说教；三，用慢病的语言安排随访（复诊与复发的调整），而不是“三次爽约即结案”；四，不用这个说法剥夺她的自主（同意的能力与（在（治疗目标上的）的选择）——因为脑被改变并不等于不能决定。评价一项政策的唯一可靠问题始终是：它是否减少了过量与（在与污名上的）的就诊与（在治疗的可及上的））的距离——[[public-health/health-systems-economics]]、[[public-health/determinants-inequalities]]、[[medical-ethics-law/ethical-principles]]。**

下列五种急性情形按“最可能立即致命”排序并给出处置：吸了兴奋剂后胸痛；一次阿片的过量伴呼吸八次；一次苯二氮的戒断的抽搐；饮酒者停饮后第二天的心悸出汗；一次大麻使用后的心慌与恐惧。

**排序按“呼吸与循环与抽搐”三条通路（[[#def-dependence]]、[[emergency-critical-care/poisoning]]）。第一是阿片的过量：呼吸八次意味着通气不足，先给气道的支持与纳洛酮（按滴定给，避免一次把成瘾者推到剧烈的戒断与激越），并观察再镇静（在长效与（在若干的芬太尼的类似物上的）需要更久）。第二是苯二氮的戒断的抽搐：它可能继续发作并演变为谵妄，按酒精的戒断处理（苯二氮的静脉给药与硫胺素与（在血糖与电解质上的）纠正）。第三是兴奋剂的胸痛：冠状动脉的痉挛与（在心动过速与（在高血压上的）的缺血与（在若干病例中的）主动脉的夹层与（在重者中的））的高温与横纹肌溶解；给苯二氮与硝酸类与（在需要时的）的降温，避免单用β受体阻滞剂（在α的效应未被阻断时的）的争议性做法，并按胸痛的路径查肌钙蛋白与心电。第四是停饮后的自主症状：它是戒断的早期，需要在抽搐与谵妄之前按计划给药与评估既往的严重度。第五是大麻后的心慌与恐惧：多数在安静的环境与（在若干病例中的）少量的苯二氮后缓解，但必须先排除在心律失常与（在（其他物质的同用上的））与在自伤与（在胸痛上的），并且不要在排除之前把她的胸痛归因于“抽了大麻”。共同的一条：把“物质的使用”当作分诊的资料而不是分诊的结果（[[infectious-diseases/fever-sepsis]]、[[cardiovascular/coronary-artery-disease]]、[[geriatrics-palliative/delirium-dementia-care]]）。**

::: exercise 在妊娠中开药 {level=2}
一名九周的孕妇有海洛因的每日使用与两次过量史；她说“我不想用药，为了孩子”。请给出你的建议与依据。
::: solution
**建议是：不要在妊娠期停用阿片的激动治疗，而是尽快开始或维持丁丙诺啡或美沙酮，并与产科与新生儿一起计划（[[#def-comorbidity]]、[[obstetrics-gynaecology/pregnancy-complications]]、[[paediatrics/newborn]]）。依据有四点：每一次过量的风险（在缺氧与胎死宫内）远高于维持治疗的已知风险；反复的中毒与戒断的循环（在胎儿的暴露上）比稳定的血药浓度更有害；突然的停用与（在早产与（在胎儿的窘迫上的））相关，并在真实世界中极难维持，复吸率高；而维持治疗能提高产检的依从与营养与（在成瘾服务中的）连续性。要跟她讲清的两件事：新生儿会出现戒断的综合征，但这是可预期、可评估与可治疗的，并且比“孩子在宫内经历过量”更安全；哺乳在稳定的、没有大量镇静药同用的情况下通常是允许的并有助于新生儿的症状。具体安排：丁丙诺啡（在若干体系中优于美沙酮，因为新生儿的症状较轻且住院较短）并按需调整剂量（在妊娠的血容量与代谢的改变下可能需要加量而不是减量）、叶酸与其他维生素、（在与其他药物的相互作用上的）的复核（在苯二氮与（在酒精上的）的）同用时的与分娩期的继续用药与新生儿的评分的工具与（在产后六周上的）的随访，因为产后是过量的高风险时段。最后一条是把她的动机（“为了孩子”）变成两周内的三个具体动作，而不是用来要求她立刻完全停用——[[psychiatry/substance-use]]、[[obstetrics-gynaecology/postnatal-period]]、[[clinical-skills/communication]]。**

::: exercise 处理一名受损的同行 {level=2}
你发现一名外科顾问在连续两台手术后手抖、说话含糊、办公室有酒味；他是一位“受人尊敬”的教师；护士已经私下议论但没人上报。请写出你作为同事与作为医师的两步。
::: solution
**这一步不是告发，而是防止下一台手术伤人（[[#def-dependence]]、[[medical-ethics-law/professionalism-regulation]]、[[clinical-skills/patient-safety]]）。第一步是当日的、面对人的、明确的行动：与他本人谈话（不带羞辱，讲事实与观察到的时间与场合，说明你担心他的病人与他自己），同时确保今天与明天他不再负责临床（暂停手术与（在（（在值班上的））的排班），并把这一决定通知科室的负责人与（在需要时的）医院的治理；不要接受“我明天就好了”的承诺来替代一个当晚生效的安排，也不要让护士承担这一决定的后果。第二步是按本地产的程序上报与转介：多数体系有对受损医护人员的专门的路径（在治疗与（在工作的调整上的））上的）的评估，它的目的首先是治疗与安全，而不是惩罚；在等待评估期间安排（在（复核的））的监督。要同时处理三件事：病历与在（（近两周他主刀的手术上的））的回顾，看是否有可以发现的损害（这是最容易因“他是谁”而跳过的一步）；对团队的一次说明（在不泄露诊断的前提下承认“有人提出了关切并已处理”），因为沉默会毁掉报告文化的信任；以及对报告者的保护，因为第一个开口的人最容易被孤立，而受损的同行常常让团队自发给“酒”找理由在（（他的压力与他的资历上的））。关于他自己的部分：他的问题更可能是疾病而不是品行（在酒精依赖的隐匿与（在被发现的羞耻上的）的高风险中），所以路径应同时包含治疗与（在恢复后的）受监督的复岗，包括对复发的明确的处理；把他“赶走”通常只会把风险移到别处，并让他失去求助的动机（[[psychiatry/treatments-mental-health-law]]、[[public-health/health-systems-economics]]、[[clinical-skills/communication]]）。**

::: exercise 为减害政策辩护 {level=3}
你的城市拟设一处监督的注射点与阿片的激动治疗的门诊的扩展；反对者说这会“传递错误的信息”并增加社区的失序。请为决策提供一份评估。
::: solution
**评估要按四条问题组织，并且每条都写清证据的强度与本地的可检验指标（[[#def-dependence]]、[[public-health/health-systems-economics]]、[[public-health/determinants-inequalities]]）。第一，死亡：在已有的评估中，监督的注射设施内没有报告的死亡，过量在被目击时可被当场逆转；若把本地每年的过量死亡作为分母，哪怕只避免若干例，其绝对收益也超过了多数公共卫生干预。第二，使用率与“错误的信息”：系统综述一致显示减害设施不提高社区的药物使用率，也不提高注射的起始；真正影响使用率的是可获得性、贫困与疼痛治疗的可得与在（在治疗的可及上的）的 stigma，而不是建筑的外观。第三，社区的成本：需要如实面对“街面的失序”的报告，并用可测量的方式回应周边的犯罪与公开的注射与丢弃的针具与（在（（在设施的排队上的）的设计），这些通过选址与运营与（在社工的介入上的））是可控的；把服务放在离人远的地方会牺牲它最主要的功能在（（把最易死亡的人接进来））。第四，费用：一个针具与纳洛酮的发放点的成本远低于一次重症监护的住院或一次在（在HIV的终身治疗上的）；而激动治疗的扩展在多个体系中被证明能降低在（在与药物有关的犯罪与（在住院上的））的总成本。要提出的条件：把服务与真正的治疗入口连在一起当日即可启动的激动治疗与在（（在镇痛与牙科与住房上的）的转介），而不是只做注射的现场；把纳洛酮同时发给使用者与警察与在邮政与在（在社区的药房上的）；设立公开的评价在（每十二个月的）与社区的代表会议，因为反对的声音多数是关于安全与秩序，而不是抽象的道德。最后的诚实：减害不是“放弃戒断”，它是把死亡与在（在治疗之间的）的伤害降到最低，同时保住她与系统之间的联系；把两者对立起来的政策，通常两者都做不到（[[emergency-critical-care/poisoning]]、[[infectious-diseases/healthcare-infections]]、[[medical-ethics-law/ethical-principles]]）。**
