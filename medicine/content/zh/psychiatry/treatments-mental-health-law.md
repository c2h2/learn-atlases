法律是精神科把伦理挂上去的骨架。**精神卫生法之所以存在，是因为人可能因疾病而对自己或他人危险，可能失去决定的能力，也可能在有余力时拒绝对自己有益的治疗；法律授权干预，同时也设定干预的边界、时限、复核与申诉的渠道。本章覆盖治疗的种类与其递送（心理、社会与社区的治疗如何被组织，以及可及性如何决定疗效）、强制及其限度（拘留的条款、强制治疗的适用范围、法庭与第二意见、社区治疗令）、以及能力与知情同意（能力的定义与其决策特定性、最佳利益的路径、预先的意愿与代理的决策）。

## 治疗与其递送

::: definition 心理、社会与社区的治疗 {#def-therapies}
**药物只是精神科治疗的一小部分，而它的效果常常依赖于另外几件事同时成立。心理治疗按机制分：行为的路径利用学习的规律（暴露与反应预防治疗强迫，分级暴露治疗恐惧）；认知的路径针对信念与解释的样式（在抑郁中处理负性的三联与自动化思维，在精神病性症状中把信念当作可检验的假设而不是荒谬的断言）；第三波的路径把目标从改变内容转向改变与内容的关系（正念与接纳与认知的解离与价值的澄清，用于慢性的疼痛与抑郁的复发与边缘的人格）。每一类都有被证明的适应证与不适当的场景，而转介的关键不是流派而是四个问题：这个诊断有被支持的疗法吗、患者愿意并能够参与吗、治疗师的胜任与督导可保证吗、以及治疗期间的风险由谁监测。心理治疗可以被损害的因素也很具体：认知的损害与活跃的成瘾与（在急性期的）严重的症状与语言的障碍与（在被动安排下的）缺乏自主性；一次“被法院或家属要求”的治疗，其效果往往不如其过程本身有意义。
社会与社区的治疗决定多数人的功能：住房（稳定的住所是抗精神病药之外最强的预后因素，而“先给房”的路径在反复入住的群体中有效）；工作与教育（支持性就业即“先求职再准备”的模式在随机试验中优于先训练后求职）；家庭的工作（情感表达的水平，也就是批评与过度卷入的程度，能预测复发，因此家庭干预的价值在于把指责翻译成可以执行的具体约定）；日常的节律（睡眠的时相与活动的安排与酒精的可用性与（在躁狂的易感者中的）夜间的工作）；以及危机之外的连续性（一个可及的负责团队、一个被写下来的危机计划、一个患者愿意在早期使用的信号清单）。评估一个服务的优劣，可以只问四件事：等待的时长有多长；被拒绝的人后来怎样；出院后两星期的接触是否落实；以及是否有可以自行联系的渠道。这四项决定了“以人为中心”是口号还是排班表——[[psychiatry/psychiatric-assessment]]、[[psychiatry/substance-use]]、[[psychiatry/self-harm-suicide-prevention]]、[[public-health/health-systems-economics]]。**
:::

## 强制及其限度

::: definition 精神卫生法的框架 {#def-mha}
**以英格兰与威尔士为例，法律的结构在其他法域大同小异地存在：拘留的依据、时限、复核与强制治疗的边界。评估通常由两人完成，需要满足三个条件：存在精神障碍；出于患者健康或安全或他人安全的需要而拘留是适当的；以及没有其他可以替代的措施。短期拘留可以随时被医院撤销，并可延展到法定的上限；超过该时限后继续住院需要官方的复核；而无限期的条文适用于最严重且治疗反应慢的情形，并附带更强的复核保障。第二意见的制度让患者在若干情形下可以要求一位独立医师审查诊断与是否适合继续，且在某些阶段这一要求不可被拒绝。强制治疗的核心限制是那条常被误解的规则：为“精神障碍”的治疗可以在最初的数周内不经同意而实施；超过之后，除非患者有决策能力却拒绝（此时在多数体系内不能强迫一个有能力的成年人接受治疗），治疗必须建立在同意或法定的例外之上。牙科与身体其他部位的非精神科的治疗不在此授权之内，除非该治疗是精神障碍本身的治疗的一部分。
法庭提供法律的复核：在法定的时限内自动被召集，也可以由患者或其代表申请；代表人可以调阅病历、传唤证人并要求记录理由。法庭的意义不只是“释放”，更在于它逼出清楚的理由与更好的解释；对许多患者，第一次知道“我有权见法庭与我有权要一名律师”就改变了整个住院的体验。社区的命令（社区治疗令）把若干条件写进出院：居住与服药与会谈与（在违反时的）召回；它的证据是温和的（可能减少再入院，但没有可靠地减少暴力或改善社会功能），而它的临床代价是真实的时间与信任——把每天的服药变成法律义务，会推迟患者与治疗者之间关于“你从药里得到什么”的诚实讨论。因此使用它的正当理由应是：一个具体的、可被指出的、曾经导致伤害的模式；并且应当有书面的、被共同理解的、并含“若我不配合会怎样”的解释。数据的另一面也要说明：强制住院的比例在不同族群与不同社区之间差异巨大，其中精神病的诊断差异、警力的介入、无家与物质使用与服务的可及都参与其中；减少强制的努力因此既是伦理的要求也是质量的指标（[[medical-ethics-law/ethical-principles]]、[[clinical-skills/patient-safety]]、[[psychiatry/psychotic-disorders]]、[[public-health/determinants-inequalities]]）。**
:::

## 能力与知情同意

::: definition 精神能力与治疗的同意 {#def-capacity}
**能力不是“我同意你的看法”，而是一套可以逐项检验的过程：能否理解与病情与选择与后果有关的信息；能否把这些信息保持住以便思考；能否权衡它们（把风险与好处与自己重视的东西放在一起）；以及能否表达自己的决定。四个要点决定了它在临床上如何使用。第一，决策特定：一个人可以有同意打针的能力而没有同意截肢的能力，也有能力决定今天的安排而没有能力管理财务；“没有能力”永远要说“对什么”。第二，时间的特定：能力会随谵妄与代谢与药物的时段起伏，所以评估必须写明时间。第三， 能力的推定：成年人被推定为有能力，除非被证明否则没有，而这与年龄与诊断与决定的“明智程度”无关——一个令人不安的决定不构成没有能力的证据。第四，不以结果论：帮助一个人获得能力是第一步，用最不损害选择的替代方案（在需要时有陪同与（在必要时）与（在一天中他最清醒的时段）与以他习惯的语言与书面或图片的辅助）是义务，而不是可选的礼貌。
当一个决定被认定为无能力者所作，治疗的路径转为最佳利益：这不只是医学的最佳，还包括患者过去的与现在的意愿与信念与价值观、以及凡是可行的咨询对象（家属与朋友与照护者与前期的预先的意愿与（在若干体系中的）指定的持久授权的代表）；并且在两个同样合理的方案之间，选择对患者的权利与自主限制最少的那个。预前的意愿（拒绝若干或全部精神科治疗）在若干法域有法定的地位，在其余法域则作为意愿的证据被纳入最佳利益的判断——临床上最重要的动作是现在就把它记录下来并让它可以被找到，因为在危机时没有人在你口袋里找一份从未写过的文件。对有能力的拒绝，法律的界限很清楚：有能力的成年人可以拒绝甚至致命的治疗，精神科的诊断不改变这一点；此时医生的工作是确保安全网（解释与（在二十四小时内的）复谈与（在可能的）次优方案与（对家属的）说明与（对团队交班的）记录），而不是找一个“她其实没有能力”的理由。评估的记录要用行为而不是结论：写“当我问她药是做什么的，她答‘让我睡得着，别的我不知道’；问及停药的后果，她答‘不知道’”，然后写你据此对四个能力项目的判断（[[medical-ethics-law/consent-capacity]]、[[medical-ethics-law/ethical-principles]]、[[clinical-skills/communication]]、[[geriatrics-palliative/delirium-dementia-care]]）。**
:::

::: example 名为自愿的住院 {#ex-borbic-official}
一名孤独症的老年男性在急性精神运动性激动后被人护送入急诊；他从未说过同意，也未说过不同意；护士在他的腕带写了“自愿”，因为他“没有反对”。他在病房被约束三次。
::: solution
**“没有反对”不是同意，这是这一例的全部。一个缺乏决策能力的成年人、在一个他被持续控制且不被允许离开的处境中，事实上正在被拘禁，无论病历上写着什么；欧洲的人权法院与各国的判例都因此确立了这样的原则：事实的拘禁需要法律的依据、记录、复核与申诉的渠道，否则构成对自由权的侵犯。正确的动作是当场把处境变成法律：评估他的能力（对“留院与治疗”这一决定）；若无能力且符合拘禁的条件，则按本地区的程序拘留并给出理由；若不需要拘禁，则按最佳利益以最少限制的替代安排（一名熟悉的人员与低刺激的房间与家属的陪同与按需要的短期口服药物）而不是靠“自愿”这个标签回避责任。约束与限制必须是最后的手段、最短的时间、有医嘱或政策的依据、有人观察、有实时的记录、并有当日的复核；每一次约束之后都应当有一次针对“为什么走到这一步”的团队回顾，而不是仅仅记录生命体征。对这位患者还有具体的一层：孤独症与智力障碍的人在急性应激下常表现为激动，而最常见的原因常常是可以被找到的（疼痛与尿潴留与便秘与感染与环境的过度刺激与沟通的失败），因此“抗精神病药加约束”的路径常常只是掩盖了未做的体检与未问的照护者。事后要做的事包括：向他的亲属或 辩护人 解释发生了什么与依据是什么、审查“自愿”这一记录的更正、把这一例作为一起未遂的伤害上报、并在病房里放一份“如何判断自愿是否真实”的一页纸——因为这类错误来自习惯而不是恶意——[[emergency-critical-care/acute-assessment]]、[[medical-ethics-law/consent-capacity]]、[[psychiatry/psychiatric-assessment]]、[[clinical-skills/patient-safety]]。**
:::

::: example 社区命令的召回难题 {#ex-cto-recall}
一名双相的患者在社区治疗令下出院，条件是每周服药；第四周他没有来，电话说“我觉得很好，不想吃药”；他的母亲说他两年前曾在停药后住院并有暴力行为。
::: solution
**这里有两个决定要分开：他今天是否需要被召回，以及这份命令是否仍在为他服务。召回的标准是风险的显著性与紧迫性，而不是“没有来”这一条本身；他说“我觉得很好”不等于没有能力，也不等于会复发，因此正确的第一步是把面谈约成一次真正的评估而不是执行一次程序。评估的内容要具体：睡眠与活动的变化与（在躁狂前驱期最有价值的）几天的自我感觉与（在既往史中的）同样的前驱征兆与酒精与其他物质与最近的应激与（她是否已经与她的治疗师谈过减药的可能）。若他愿意来，可以今天完成；若他拒绝而风险升高，团队应当使用可以使用的合法工具（复核的能力与风险的可操作性），同时说明“我担心的是你像两年前那样”而不是“你有义务服从”。召回之后的第一件事不是恢复原来的剂量了事，而是把命令本身重新谈判：母亲的恐惧与患者的愿望之间需要一个能落地的折中（长效的针剂换掉每天的争执、把服药以外的预警信号写进计划、把随访的密度提高而把条件的数量减少）。命令的目标从来不是服从，而是让出院可以安全；如果它的存在只是让团队感觉负责，而实际上使治疗关系变成执法关系，那么它已经偏离了自己存在的理由。最后一条常被人忽略：无论这次结果如何，都要向患者书面说明她被记录的条件、她要做什么、以及如何申请法庭或提出申诉——记住自己“被如何对待”的能力，会影响这个人将来是否愿意再次求助——[[psychiatry/mood-disorders]]、[[medical-ethics-law/ethical-principles]]、[[clinical-skills/communication]]、[[psychiatry/treatments-mental-health-law]]。**

::: example 电休克的同意会谈 {#ex-ect-consent}
一名68岁的女性在重度抑郁伴拒食与木僵的状态中，体重下降八公斤、脱水、卧姿不动；她的儿子说她“一向很反对打针”，而她此前从未讨论过电休克；她无法回答问题。
::: solution
**第一步是判断能力，而不是判断她会不会同意。她现在的状态（木僵与拒食）常常本身就是无能力的理由：无法理解、无法保持、无法权衡、无法表达；能力评估必须逐项写明并记录她说过的话。第二步是走最佳利益而不是找一位“能签字的家属”：在多数法域中亲属并不自动拥有替代决定医疗的权利，儿子说的是“她一向反对打针”——这是对具体情境的推测，而不是关于电休克在抑郁中的预后的预前意愿；要把这两者区分清楚，同时认真地把她的价值观纳入判断（她重视什么、她以前面对痛苦时的选择、她信任谁、她害怕什么）。第三步是选择限制最少的可行方案：在拒食与脱水的情形中，身体的风险本身很急，需要同时给液体的补充与营养与（在木僵中）苯二氮的试验与治疗抑郁的药物，并明确“电休克在这些措施无效或不可等待时是解除病情的手段”；对伴木僵与拒食的重度抑郁，电休克的起效速度与证据强度使它在最佳利益的讨论中占据重要位置。第四是把程序做扎实：麻醉的评估与心电与牙齿与既往的病史、两位医师的独立审查与（在若干法域中的）法庭或第二意见的路径、以及一份说明认知副作用与疗程与“每一次治疗前都可撤回同意”的记录。对她的家属要讲两件事：认知的影响是真实的（在疗程中最常见的是对近事的遗忘，多数在数月内改善，但少数人对疗程中的若干时段永久失记），而“我们凭什么现在替她决定”这个问题应该被正面回答而不是被回避。最后：她恢复之后，把当时如何决定与为什么这样决定告诉她——这一步常被省略，却是保住治疗关系的关键——[[psychiatry/mood-disorders]]、[[medical-ethics-law/consent-capacity]]、[[surgery/anaesthesia-pain]]、[[clinical-skills/communication]]。**
:::

::: example 谈话治疗的等候名单 {#ex-therapy-access}
你的地区把认知治疗的等候时间从中位六周延长到二十七周；抑郁的初级照护的转介量不变；两名治疗师离职；同时自伤急诊的就诊量上升。
::: solution
**把等待当作治疗的一部分来管理，而不是当作行政的副产品。第一层是分流而不是分类：把等候中的人按风险与严重度与功能损害分层，并为每一层配置“在此期间做什么”（自杀风险的高危者不能被放进队列；中度者在等待期间接受初级照护内的行为激活与睡眠与酒精的处理与规律的接触）；队列本身需要一个明确的复核节奏，因为“进入队列后无人再评估”是最常见的失败。第二层是效率：单次会谈的利用中有多少被用于第一次评估而无人再回来、未完成的比例有多高（把“来了两次不再来”作为一个可改进的指标）、以及阶梯式的递送（自助的材料与（在督导下的）引导的自我帮助与小组的与个别的与（在难治者的）专科的心理治疗），阶梯式的路径可以在同样的资源下覆盖更多人而不降低平均的效果，但绝不能被用来“把所有人都推到最低强度”。第三层是可及的门槛：语言与残障与 托儿 与夜间的时段与交通的补贴与（在若干人群中的）病耻；同一名患者在不同条件下完成率差别很大，这是“公平即有效性”的直接例子。第四层是数字与远程的选项：有证据支持的程序化的项目可以填补等待，但必须包含安全的边界（风险时如何升级）与可及性（数字素养与设备）以免把最需要的人排除在外。要测量的东西：等候时间的分布与第90百分位、等待期间的自伤与失访、第一次会谈前的撤回率、以及按族群与剥夺指数分层的效果差；同时把“等待期内的最低服务包”（一次说明风险与应对的信、一个可以打电话的号码、一次两周内的复核）写进政策，否则名单只是把风险转给最沉默的人——[[psychiatry/anxiety-disorders]]、[[psychiatry/self-harm-suicide-prevention]]、[[public-health/health-systems-economics]]、[[public-health/determinants-inequalities]]。**

## 通向何处

精神科的评估与诊断见[[psychiatry/psychiatric-assessment]]；各病的药物治疗见[[psychiatry/mood-disorders]]与[[psychiatry/psychotic-disorders]]与[[psychiatry/anxiety-disorders]]；成瘾的治疗见[[psychiatry/substance-use]]；自杀风险的评估与安全网见[[psychiatry/self-harm-suicide-prevention]]；同意与能力与伦理的通则见[[medical-ethics-law/consent-capacity]]与[[medical-ethics-law/ethical-principles]]；服务的组织与筹资见[[public-health/health-systems-economics]]与[[public-health/prevention-promotion]]。

::: history
**精神卫生法的历史是一部把“关起来”改写成“依法处置”的历史。十八世纪末的改革（Pinel 在比塞特医院解开锁链的传说与 Tuke 在约克的收容所）把道德治疗引入疯人院，但真正的转折是十九世纪初的立法：英格兰1808年的收容所法与1845年的郡立疯人院法把公立的收容纳入国家与地方的责任，同年成立的专员制度第一次给住院以第三方的巡查；1890年的证书制度让拘留依赖两份签署的文件，其代价是形式压过了判断，这一教训在四十年后被复验。1930年的法引入了“自愿住院”的概念，1959年的法把它扩大并试图取消“监护令”式的司法处置，同时开始把治疗而非收容写进目标——但“没有大门”的制度仍留下了事实上的拘禁，因为被送进来的人常常既未同意也未被赋予离开的权利。这个缺口在1982年的法中只被部分修补，直到欧洲人权法院在2004年的 Stone 案与之前的HL 案（即“事实拘禁”的判决）确认：没有法律依据的持续控制即是违法；其后果是2007年的修法与随后关于“剥夺自由”的持续立法争论，也是本章第一个病例的由来。去机构化的进程同样充满误读：1950至1960年代大医院的关闭在很多国家由三股力量推动（新型药物的出现与新的社区照护的理论与对住院的批判与财政），其结果在各国差异巨大；读过的评估显示：多数住院者被安全地转到了社区，真正“流浪”的比例远小于政治话语中的数字，但社区服务的强度决定了结局，而监狱与看守所成了若干法域中精神病人最多的“机构”。复核的制度从专员与法庭（1983年的法确立的精神病复核法庭）到“患者的建议与介入服务”，其逻辑是把判断从治疗者手中分出去；而第二意见、法律援助与代表人的普及，使法律从文件变成可及的程序。强制治疗的上限（若干周之后不得强迫）与社区治疗令与（在若干法域中的）预先的意愿，代表了此后二十年的争论焦点：如何在可以强制的范围之内保留尽可能多的自主。减量的运动把注意力转向住院内部：约束与隔离的过度使用在1990年代的调查与（2010年代后的）多起死亡个案之后被公开，各国陆续制定“减少约束”的策略与培训的标准化与数据的公开；这使本章最后一个问题变得具体：法律写在纸上之后，是否被护士在夜里两点钟执行（[[medical-ethics-law/ethical-principles]]、[[medical-ethics-law/professionalism-regulation]]、[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]）。**
:::
::: summary
- 治疗的效果大部分在药片之外：住房、工作、家庭的沟通方式与危机之外的连续性，都是可以被处方的干预。
- 强制需要法律依据、时限、独立的复核与申诉的渠道；“没有反对”不等于同意，事实上的拘禁同样受法律约束。
- 强制治疗有明确的窗口与边界；对有能力的拒绝，诊断不改变“可以拒绝”这一原则。
- 能力是决策特定且时间特定的，被推定为存在，并且不因决定的内容令人不安而被否定。
- 最佳利益要纳入患者过去的意愿与价值观与可以咨询的人，并选择限制最少的可行方案。
- 服务的可及性是疗效的变量：等候的时间、拒绝之后的去处、出院后两周的接触与能否自行联系，决定“以人为中心”是真是假。
:::

::: exercise 入院第一天的权利 {level=1}
一名24岁的男性在第一日被拘留，他不识字、不用母语、愤怒并要求“让我走”。请在24小时内列出他应当被告知的内容与实际的落实方式。
::: solution
**清单要短、要重复、要用他能用的形式（[[#def-mha]]、[[clinical-skills/communication]]）。他需要知道六件事：为什么被留下（依据的条款与理由，用具体的话而不是法律术语的引用）、最长到什么时候、谁能复核（自动的法庭与申请的时间、可以要求一名律师、可以要求独立的第二意见的情形）、可以向谁投诉与如何联系辩护人、他在治疗上的地位（哪些治疗可以在最初数周内不经同意实施，超过之后呢）、以及探视与电话与抽烟与财物与（在需要时的）宗教与饮食的安排。落实的方式：口头的解释加上书面或图示的版本、由一名经过培训的人员在当天完成并在病历上记录“以何种方式告知与谁在场与他问了什么”；请口译（不要用同病房的患者做翻译，也不要在没有口译的情况下把复杂的权利说成“你有权申诉”）；对不识字的患者用语音或图示的材料；在他愤怒时先处理能处理的（睡眠与疼痛与烟与一次给家属的电话），然后在第二或第三小时再讲一次——第一天的重复比第一天的完整更重要。要记录的是他的问题与你的回答而不是“已告知”这三个字；并主动问他希望我们如何联系他的家人与他是否愿意让他们参与——这些细节在事后的投诉与法庭上都比病程记录更有分量——[[psychiatry/psychiatric-assessment]]、[[clinical-skills/records-handover]]。**

::: exercise 划一条保住治疗的界限 {level=2}
一名边缘人格的患者在你的门诊两年，多次在深夜打电话并要求加急会面；本周她在你休假时威胁自伤；你想减少接触，又怕“抛弃”会伤害她。请设计界限。
::: solution
**界限的目的不是拒绝她，而是让这段关系可以持续（[[#def-therapies]]、[[psychiatry/eating-personality-disorders]]）。三条原则：可预测、可解释、可执行。可预测：把可以接触与不可以接触写清楚（固定的门诊时间与两次门诊之间可以做的与（在危机时）应当去的地方与一个明确的夜间渠道），并把这一份“合约”给她一份书面，让她在愤怒时不必依赖记忆或运气。可解释：解释背后的理由与限制（不是“我们人手不够”这种防御的话，也不是“这是为你好”，而是“我们的模式在门诊内有效；深夜的电话会让门诊的关系变成危机动员，而这两件事我不能同时做”）。可执行：越界时按事先说的执行，且不带惩罚的语气——一次未约的加急要求，回应是“按我们的约定，我会在周四的门诊谈这件事”，然后不再解释第二遍；同时把危机渠道畅通（急诊的路径与（在需要时的）团队的替班），使界限不等于遗弃。技术上的要点：治疗的框架要写下来并定期重审（每一次危机后一次简短的回顾：发生了什么、按约定做了吗、约定需要改什么），因为界限被讨论时会被内化，被宣布时只会被测试。对治疗师自己的两层：一是识别反移情（内疚与愤怒与想“再多做一点”的冲动都是数据，需要督导而不是行动）；二是承认在若干研究中“更多的门诊接触”并不总带来更好的结果，对若干患者，减少危机的“回报”本身就是治疗的一部分。最后：不要因为她威胁自伤就放弃评估风险；威胁的内容与方式与可及的手段与既往的自伤与（在最近的）失去与酒精，仍然要被认真评估，界限与评估是两件事（[[psychiatry/self-harm-suicide-prevention]]、[[clinical-skills/communication]]）。**

::: exercise 处理一个有能力的“不” {level=2}
一名37岁的男性在精神分裂症的缓解期有能力地拒绝继续口服药，他说“我宁愿复发三次也不想再尝那种僵硬”；他有两次住院史；他的母亲请求你“说服他”。请说明你怎么办。
::: solution
**先确认这不是症状：他说的理由与他的既往经历一致、他能说出药物的利弊、他能在数日内保持同一立场、他理解不吃的后果并能说出来——这四条成立时，这就是一个有能力的拒绝，不能靠“他不肯吃就是有病”推翻（[[#def-capacity]]、[[medical-ethics-law/consent-capacity]]）。然后是三个可以合法且合乎伦理地追求的目标：把伤害降低、把选择保留、把关系保住。降低伤害：把他的具体抱怨当作可治疗的问题（那次僵硬是急性的肌张力障碍还是静坐不能还是帕金森样的反应，各自有不同的处理），提出换药或减量或加用抗胆碱能的路径，并把“长效针剂”作为“每天服药的争执”的替代（在若干患者中，每月一针把自主性交还给他，因为它把服药从每日的服从变成每月的决定）。保留关系：与他约定复发的早期信号清单与他愿意在早期使用的措施（睡眠的处理与减少刺激与一个可以由他指定的人在早期介入），并把这份清单交给他的母亲而不是交给家属一份“监督方案”。同时明确他拒绝的边界：若他将来无能力且符合强制的条件，法律可以覆盖他的意愿；这不是威胁，而是他应当知道的后果，应该在平静时讲而不是在冲突中讲。对母亲的请求要诚实：你会与他一起工作，但不会代替他与儿子作战；给他一份“什么话有用与什么话让他更抗拒”的简短建议（避免以依从为话题的争吵，改为睡眠与压力的谈话）。记录：他拒绝时的原话、能力的四项判断、你提出的替代方案与他的选择；这类记录在将来被重新评估时是不可替代的——[[psychiatry/psychotic-disorders]]、[[clinical-skills/communication]]、[[medical-ethics-law/ethical-principles]]。**

::: exercise 为你避免的强制算账 {level=3}
你的病房推行“减少约束”的一年后，约束的次数下降四成，而员工报告的“差点受伤”的事件上升；管理层问你是否应该回到旧的做法。请给出评估与答复。
::: solution
**这个问题需要三组数据而不是一个观点（[[#def-mha]]、[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]）。第一组是伤害：患者的伤害（约束相关的皮肤与循环与（在极端情形中的）死亡与（更常见的）羞耻与创伤的记忆）、员工的伤害（在徒手控制中的肌肉骨骼与被打）、以及约束期间与之后两小时的总伤害；把“差点受伤”的报告单独看是错的，因为它的增长可能只是上报文化改善的信号——先查上报率本身是否变化，再比较严重度分级后的事件。第二组是过程：约束的时机分布（是否从夜间转移到人手较多的时段）、被约束的人群是否变化（若干改革会把约束集中到更少数的人身上，从而掩盖总问题）、是否有可比的替代措施被使用（低刺激的房间、按比例的人员、口头降级、按需要的药物、家属或辩护人的到场）、以及培训与督导的覆盖率与事后回顾的完成率。第三组是患者的体验与后果：住院满意度、对治疗的评价、投诉与法庭申诉的数量、以及再入院与（在若干体系中的）住院时长。答复的结构应当是：不回到旧做法，但也不接受“次数下降”作为唯一的成功标准；把指标改为“每床日的严重伤害率与每床日的隔离时长与患者体验与员工的损伤”；同时承诺做旧做法从未做过的事——把每一次约束当作一次系统的失效来查，因为绝大多数约束的根源在于排班与床位与等待与（在急诊的）滞留，而不是在于某个护士的判断。经济上要算全账：一次严重伤害的赔付与投诉处理与员工的工伤与离职的成本，通常高于一到两名额外人员的成本；这一点在预算的讨论里比伦理的论证更有效。最后一层是诚实：改革期间确实可能出现一段风险的波动，隐瞒它会让团队不再相信指标；应当把波动的数据公开地与团队一起读，并把“我们不靠把人绑起来解决没人手的问题”表述为一项可被检验的承诺而不是口号——[[psychiatry/psychiatric-assessment]]、[[clinical-skills/records-handover]]、[[medical-ethics-law/professionalism-regulation]]。**

::: exercise 选择法律的框架 {level=1}
为下列情形各选择正确的框架：一名谵妄的老年住院患者拔除输液管并要求回家；一名17岁的青少年拒绝住院；一名被拘留的患者拒绝牙科的治疗；一名有能力的患者拒绝抗精神病药。
::: solution
**四个情形属于不同的轨道（[[#def-mha]]、[[#def-capacity]]、[[medical-ethics-law/consent-capacity]]）。谵妄的老年患者：先按能力评估处理并治疗谵妄的病因，通常用最佳利益的框架与最少限制的措施（一名熟悉的照护者与视力的辅助与白天的光线与（在必须时）短时的口服药物），只有在法定的条件满足时才使用精神科的拘留；同时核查是否存在不合理的限制，因为“为便利的约束”在多数法域中是违法的。17岁的青少年：在若干法域中未成年人有自己的规则与家长同意的路径，而拒绝的效力取决于年龄与成熟度与决定的严重性；成熟青少年的拒绝不能简单地被父母的同意覆盖，而争议时应寻求法院的宣告而不是靠劝说；无论用哪个框架，都要记录她的观点并让她有独立的代表。被拘留者拒绝牙科的治疗：精神卫生法的强制治疗授权不覆盖与精神障碍无关的躯体治疗，牙科属于另一套同意的规则——他有能力的拒绝就是拒绝，无能力则按最佳利益；这条界限在病房里常被混淆，因为“已住院”容易被读成“一切均可代替决定”。有能力的拒绝：不治疗，但要确保安全网（解释与随访与（在可行的）次优选择与（对家属的）说明与对团队的交班），并记录能力的四项判断。共同的一条是：先问“这个决定是否需要在法律之下被覆盖”，再问“有没有一种不需要覆盖也能做到的做法”——[[psychiatry/psychiatric-assessment]]、[[geriatrics-palliative/delirium-dementia-care]]、[[paediatrics/adolescent-health]]、[[surgery/anaesthesia-pain]]。**

::: exercise 完成一次能力的评估 {level=2}
一名54岁的男性在抑郁伴 精神病性的症状中被建议住院；他说“我知道你们说我病得很重，但我要回去上班，我不上班就会失去工作”。请写出你的评估与记录。
::: solution
**评估要围绕四个能力项目逐项展开，并留下他的原话（[[#def-capacity]]、[[clinical-skills/communication]]）。理解：请他解释医生认为的问题与他自己的看法；他能说出“你们说我病得很重”说明他能理解他人主张的内容，还要问他对治疗与不住院的后果各自的理解。保持：请他在几分钟后重复要点；注意症状（在重度抑郁中的注意力与（在精神病性症状中的）被观念占据）会真实地损害这一项。权衡：问他“如果住院，你担心失去什么与得到什么；如果不去，最坏会怎样”——他给出了一个清晰的价值排序（工作对他是首要的），这本身是能力的证据而不是缺陷。表达：他明确表达了选择。到这里，他的决定是有能力的：为了工作而接受恶化的风险，是一个令人不安但完全可以由有能力的成年人做出的选择。接下来的工作不是推翻决定而是重构选择：找出可以两全的安排（部分住院与日间的项目与（在若干体系中）在家属陪同下的门诊强化与把抗抑郁的治疗立即开始并说明起效的时间与（在自杀风险的评估后）具体的安全计划）、把“失去工作”的风险与可能的证明与休假的路径解决掉（一份说明病情的信与（在需要时的）职业健康与社会保障的介入）、约定复谈的时间（“我们今晚不谈要不要住院，我们谈谈怎样让你在上班的同时不被这个病拖下去”）。记录要写：评估的时间与情境、四项的行为证据（引原话）、你的结论与理由、你提供的替代方案、风险的具体评估与缓解、以及复谈的时间；不要用“患者无洞察力”代替评估，因为洞察力不是法律的标准——[[psychiatry/mood-disorders]]、[[medical-ethics-law/consent-capacity]]、[[clinical-skills/records-handover]]。**

::: exercise 处理一次隔离事件 {level=2}
夜间一名患者因激越被隔离四十分钟，事后病历只写了“为安全需要而隔离”；患者抱怨“没人告诉我为什么”；家属投诉；夜班说“当时只有三个人当班”。
::: solution
**把这一例当作三件事来处理：这一次是否正当、这位患者是否被公正对待、以及这个系统是否会把下一次变得更糟（[[#def-mha]]、[[clinical-skills/patient-safety]]）。这一次：隔离只有在没有其他更少限制的选择且时间短时才可接受；“三个人当班”不是理由，但它是重要的数据（人员比例决定了口头降级与陪伴的可行性）。要补的记录是事实性的：开始与结束的时间与期间的观察与生命体征与尝试过的替代（谈话与（在需要时的）药物与家属或辩护人的电话与环境的调整与让患者离开的条件）与当时的解释。是否“告诉了他为什么”是核心：隔离必须伴随持续的解释与让他知道如何结束的途径，否则它只是惩罚的一种形式。对患者的答复：由一名资深人员在两天内当面向他说明发生了什么与依据与记录与可以如何申诉，并听取他当时的体验（“没人告诉我为什么”这种体验常常比四十分钟本身更令人受伤，也常常是下一次不信任的来源）。对家属：同样的信息加上病房的政策与他可以参与的改进。对系统：把这次纳入当周的回顾，问三个可执行的问题——夜间的人员与（在急诊的）等待是否制造了这次激越、是否有可用的低刺激房间与（在需要时）一名陪伴的人员、以及隔离的记录模板是否强制填写替代措施与解释；并把隔离率按原因与时段与人群分层公开。指标上不要只看次数：每床日的隔离时长与重复隔离的个体数量与（在隔离期间的）伤害与（在之后的）投诉，才能显示是否真的在减少——[[psychiatry/psychiatric-assessment]]、[[clinical-skills/records-handover]]、[[medical-ethics-law/professionalism-regulation]]。**

::: exercise 起草一份减少约束的策略 {level=3}
请为你的机构起草一份减少约束与隔离的策略，包含治理、预防、现场与事后的部分，并说明如何避免“指标达标而体验变差”。
::: solution
**四个部分（[[#def-mha]]、[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]）。治理：高层的一份声明（约束只作为最后的手段、最短的时间、有依据、有观察、有记录、有回顾），一名对指标负责的管理者与季度的公开报告；对政策的一致性做一次审查，因为不同病房的标准不一致会把患者转移到最容易受限的地方；培训（语言的降级与（在需要时）安全的徒手控制）与人员的配置被视为策略的一部分而不是它的补充。预防：把可预期的诱因变成排班与流程的问题（等待与拥挤与疼痛与便秘与睡眠的剥夺与咖啡因与（在戒断中的）未处理的与（在谵妄中的）未识别的），建立可选择的替代（低刺激的房间与一名受过训练的陪伴与（在若干患者中）家属或辩护人的到场与预先的意愿与（在早期信号时的）药物的调整），并为每位被记录为“有暴力风险”的患者写一份可被任何人执行的个人计划（什么信号意味着什么与先做什么与什么不该做）。现场：授权一线在约束之前使用“停一下”的工具（换人说话与（在可能的）移动到另一个空间与一次给主管的电话），并把“没有解释就约束”定义为不可接受而不是可原谅。事后：每一次都在二十四小时内做一次结构化的回顾（患者与人员都参与，条件允许时），并给患者一份书面的说明与申诉的渠道；把重复被约束的少数人拉出来做个案的审查。指标：每百名住院日的约束次数与时长与伤害率与患者的体验与投诉与再入院的间隔；关键是把“次数下降”与“患者的体验改善”同时设为目标，因为最容易的达标方式是“该约束时不记录”或“把约束换成未被定义的其他控制”——所以要同时监测未被记录的控制（长期的锁门与（在若干病房中的）“不让离开”的口头指令）与员工的报告文化。最后的诚实：如果机构愿意接受约束的下降，就必须愿意接受与之相伴的人员与场地的成本；把改革交给临床团队而没有资源，结果通常是指标的修饰而不是伤害的减少——[[clinical-skills/communication]]、[[medical-ethics-law/professionalism-regulation]]、[[public-health/health-systems-economics]]。**
