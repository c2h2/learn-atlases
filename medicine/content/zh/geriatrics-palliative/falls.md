跌倒是老年综合征的典型代表：常见、昂贵、多数可预防、而一贯地被检查不足、因为没有人会把一次跌倒带到医院、直到它摔断了什么。**本章涵盖作为一带鉴别症状的跌倒（机械性滑倒、晕厥性黑矇、边际累积的多因素倒塌）、真正能找到病因的评估（从看见的人那里取的故事、直立血压、药柜、足、眼与计时步行）、后果级联（损伤、骨折、抗凝下的头颅出血、以及对跌倒的恐惧本身变成闭门-去适应-跌倒）、有真实证据的治疗（肌力与平衡运动作为最好的单一防跌倒药、针对性的药物削减、白内障手术、为正确心律装起搏器、高风险住宅的居家危险处理）、及把它串起来的服务（从急诊或全科到一间有名字的、多因素跌倒门诊的整合路径）。本章的论点是：“她摔了一跤不是一个诊断、而老膝盖不是一个计划。**

## 症状与其病因

::: definition 作为老年综合征的跌倒 {#def-causes}
**先说数字、因为它们足以证明这份专门兴趣值得：社区居住的65岁以上成人约三分之一每年跌倒、其中一半会再跌；跌倒许多国家老年成人损伤死亡的首位原因、也是65岁以上者急诊就诊最常见的原因；髋部骨折带来20-30%的一年死亡率；而经济负担超过许多营销得好得多的疾病。驱动检查程序的分类：机械性跌倒（一个边际大致正常的人真正滑了一跤或绊了一下——这类事存在、但“我滑了一下”这个标签值得与无法解释的倒塌同等的审视、因为一个健康的30岁者在同一片湿地上滑倒并不会跌倒）；晕厥性跌倒短暂脑灌注不足——体位性的、心脏心律失常的、颈动脉窦与咳嗽及排尿综合征、主动脉瓣与血红蛋白、并把晕厥一章的黑矇对跌倒之辨反向应用：在老年人中晕厥常以无法解释的跌倒呈现、而跌倒的检查程序必须问之前那几秒；及多因素跌倒（常见的故事、其中五个部分原因——轻度近端肌无力与一个白内障与一个小血管步态与两片降压药与拖鞋——越过阈值后相加）。内在风险目录：年龄相关步态与平衡及视力与本体感觉及反应时的下降、正常而在程度上可改变、疾病相关帕金森综合征与卒中及痴呆及周围神经病及关节病及急迫性失禁、及把慢性步态变成急性跌倒的谵妄与感染、及治疗相关精神药物负荷——镇静剂、抗抑郁药、抗精神病药；降压药尤其在起始与剂量改变时；多种用药作为四种以上药物本身就成为一个跌倒风险因素；这使得跌倒门诊是一家穿着运动服的去处方门诊。外在层：地毯与楼梯及夜间的膀胱之旅与鞋与不合适的镜、及无取暖的浴室、真实而修复便宜、但要带诚实的证据脚注：居家危险干预在住宅确实危险而跌倒确实机械起源的人中最有效、这就是“无效”与“高危亚组有效”的试验所指的东西。要在问起之前就预料到的后果：损伤腕、肱骨头、骨盆、髋、及头部撞击的下巴压痛征、颅内出血带其抗凝倍增与其延迟的硬膜下呈现、及“我三周前摔了一跤、现在意识混乱”这个句子级的紧迫；跌倒后综合征对跌倒的恐惧缩小了世界——活动停止、肌肉流失、更多跌倒跟随、而抑郁与入住安老院常常是真正的结局、而不是任何骨折；及全科称为螺旋的呈现表型起不再被报告的跌倒、因为她不再被问起、直到骨折让病史成为必须。组织一切的临床规则：老年成人的任何跌倒都要找一个原因发生了什么、不只是什么受伤、做一次损伤搜寻包括令她难堪的那部分检查、做一次药物核查、及一个计划——而计划必须包含肌力、因为跌倒本身现在是下一次跌倒的风险因素、而时间就是肌肉——[[geriatrics-palliative/ageing-frailty]]、[[cardiovascular/arrhythmias]]、[[geriatrics-palliative/polypharmacy]]。**
:::

## 评估

::: definition 跌倒的评估：故事、系统、步幅 {#def-assessment}
**病史是收益最高的检验、而通常被跳过：跌倒之前的五个问题你在做什么；是否分阶段发生；有无先兆——说明体位性的头昏、说明心律失常的心悸与无先兆、说明前庭的视物旋转、胸痛、及不带黑矇的突然倒地即“跌倒发作”而不是晕厥、意识的数秒尽可能有目击者、因为“她像一棵树一样倒下”与“她瘫软下去”是不同的句子、及之后（意识混乱持续时间、它说明脑震荡或癫痫发作后或低血糖；及她在地面上躺了多久、因为躺卧正是横纹肌溶解与急性肾损伤与低体温藏身之处、而没有人发现她本身就是一个社会急症）；以及从照护员或看见的邻居取的旁证、因为老年跌倒者会轻描淡写（“我只是赶紧跪下去看一样东西”）而目击者也说不准细节、所以两份病史都要取。检查的躯体套装：带正规技术并读出脉搏应答的卧立位血压定义体位性低血压的下降——20/10、带自主神经对药物对脱水的解读、及帕金森的红旗：卧位高血压伴立位低血压的模式是自主神经衰竭、而这位患者的卧位高血压绝不可被追到地上、心脏检查带杂音与颈动脉脉搏性质、神经系统带帕金森征与上扬的足底反射及振动与本体感觉及串联步态及Romberg及拉试验其异常命名了导致她向后跌倒与贴墙行走习惯的向后推进、足趾甲与畸形及脉搏及鞋垫及无后跟支撑的拖鞋、视力视力表与白内障及上下双光镜与楼梯之问及新配眼镜的适应期、及认知与情绪、因为对运动计划的依从要经过它们。表现测试让步态自己说话：起立行走计时超过12秒标记高跌倒风险、它同时测量她的康复进展、4米步速、五次起坐、及简单而展示策略与恐惧的“从地上爬起来”观察。针对性的检查、而不是撒网：心电图心律失常线索与PR与QT及起搏心律及缺血之问、按病史指征的跌倒相关血液体位症状——全血细胞与铁蛋白及糖化血红蛋白及维生素B12及甲状腺功能及钙及葡萄糖；无法解释的跌倒伴长时间躺卧——肌酸激酶与肾功能及尿、仅在病史说明时做脑影像新发定位征、伴抗凝的头部外伤与延迟硬膜下规则——每一位“她从三周前那次跌倒之后就不是她自己了”今天都需要一次扫描、及原因未明的晕厥在计算机断层上少有收益、及为无法解释的黑矇做动态心电图或埋藏式记录器的心律失常搜寻、带心脏停搏间期的起搏阈值——[[clinical-skills/history-taking]]、[[cardiovascular/arrhythmias]]、[[nervous-system/sensory-systems]]。**
:::

## 治疗与路径

::: definition 跌倒预防与整合路径 {#def-prevention}
**什么有效、及其大致强度：运动是首选药物——Otago类型与团体平衡与肌力及太极规划的荟萃分析显示有意义的跌倒率下降（约五分之一到四分之一）、效应集中于带足够剂量交付的、对平衡与功能有挑战的渐进规划、这就是为何“我会用拐杖”与“她能照传单上的做操”不是干预、而物理治疗师与社区健身房及舞蹈及带跌倒资格的武术、及依从问题本身就是服务设计——加上那种因为简短并系在水壶旁而真的被做的家庭练习。药物：针对镇静催眠与抗胆碱能及致体位性及血压过度治疗的定向去处方（邻近STOPP与Beers的清单、及跌倒门诊的证据：由有处方权的药师或老年病医师做药物复审能减少多重用药者的跌倒）、给缺乏者与护理院邻近者的维生素D而不是年度大剂量冲击（把冲击剂量拉下王座的试验文献）、及一句诚实的话：维生素D是缺乏时的补充、不是所有人的防跌倒药。感官与结构：白内障手术按试验标准减少跌倒（第二只眼的效应）、新配镜与双光镜的谨慎、足病与鞋、及髋部保护具在机构内与现实世界之间的证据。心脏修复：为已记录的心脏抑制型颈动脉窦综合征装起搏器、及时抓住的心律失常病因（这就是为何78岁无先兆的无法解释跌倒值得心律捕捉、而不只是一张髋部保护具传单）、体位性低血压管理阶梯（缓慢改变体位与水与盐及相容时的加压、及邻近氟氢可的松与屈昔多巴与米多君的处方、带卧位高血压的腾挪——需要一个常做这件事的临床医师）、及衰弱者中被过度治疗的高血压关于获益对跌倒的坦率与个体化目标的谈话、及骨折之后的去处方之问。环境：高风险住宅的危险处理（指南规定的多因素评估、包括“上一次跌倒发生在哪里、一臂之内有什么”）、由能看见真实住宅的职业治疗师完成的扶手与淋浴及照明及移除地毯、及远程照护与挂坠报警器的安装是因为她躺了九个小时、而不是因为它能预防跌倒它预防的是躺卧的后果、这是一个被如此命名的正当目标。服务架构：整合跌倒服务指南推荐的模型——急诊与全科与病房的转诊进入同一门诊、尽可能在同一预约日内包含医师与物理治疗师与职业治疗师及药物复审、带风险分层与复能及转诊即运动、及骨折联络附设、使她在腕部时已符合资格的骨质疏松治疗真的送达、医院侧入院时的跌倒风险评估与跌倒后清单及簇分析——这是一间病房看出它的淋浴与凌晨两点的降压药查房才是问题、而不是宣布患者不可预防的方式、及文化那一块——每一次院内跌倒后无责怪的诚实询问、因为替代方案是被隐藏的跌倒与一个假的安全单元。最后的证据脚注：多因素干预在高风险者中胜过单一干预、而整章就是这句话的延伸：门诊不是一次一个原因地修理跌倒、它在五个领域叠加小幅下降、直到她的风险曲线回到她的生活之下——[[geriatrics-palliative/ageing-frailty]]、[[geriatrics-palliative/polypharmacy]]、[[endocrine/bone-calcium]]。**
:::

::: example “就是倒下去了”的79岁患者 {#ex-syncopal}
5个月内三次跌倒、全部无先兆、一次伴下巴伤口而无骨折；两份急诊记录写“机械性”；服氨氯地平与吲达帕胺、且上月起又加坦索罗辛用于尿频；门诊心电图示一度房室传导阻滞、而卧立位下降为34/16。
::: solution
**把跌倒当回事而找到的两个原因（[[#def-causes]]、[[#def-assessment]]）：解读——”无先兆的跌倒在证明否则之前是晕厥（心律失常之问的紧迫方式与髋部之问不同）、但她的故事也指名体位性低血压（在站立时把血压打下来的三药组合：利尿剂加钙通道阻滞剂加用于排尿的α阻滞剂——每一味都开始得合理、总和不可辩护）与传导线索（PR异常伴无先兆跌倒要求心律捕捉——24小时动态可能漏、7-14天贴片或埋藏式记录器是现代答案、而在监护床上做颈动脉窦按摩以应对转头触发的黑矇、是她六十多岁时就该做的最古老检查）“；计划——”先做药物手术吲达帕胺复审、坦索罗辛的适应证被质疑——尿频可能是利尿剂的时点或膀胱脱垂或糖尿病或习惯、所以要用膀胱病史取代α阻滞剂、而不是反过来、现实的盐与水而不是一通说教、若与她的动脉相容则合身的加压袜、及今天就预约动态监测、若贴片阴性则埋藏式记录器、因为她本可能因心脏阻滞死在人行道上而我们称之为笨拙；及安全网——“关于反复晕厥的驾驶与驾照机构谈话、要正规进行并记录、因为这是没人喜欢而人人都必须进行的会诊、及她带回家的清晰书面计划警示征、立即坐下的规则、及何时打给谁。她会向朋友引述的那句教训：“有两位医师写下机械性、之后才有人数了我的药片并量了我站着的脉搏。”**

::: example 撞了头并在服华法林的82岁患者 {#ex-subdural}
一名因房颤抗凝（华法林）的82岁患者在跌倒时把头撞到浴室柜；不知有无意识丧失；国际标准化比值3.2；她看起来没事并拒绝入院；两周后她女儿打电话：“她一直健忘、头痛、现在说话很奇怪。”
::: solution
**延迟硬膜下与抗凝的双重困境（[[#def-causes]]、[[#def-prevention]]、[[blood/haemostasis-bleeding]]）：规则——”抗凝者的任何头部外伤都要当日评估并对影像取低阈值、而延迟硬膜下需要一个安全网、写明打给谁与看什么征、用家属记得住的语言、因为她看起来没事是硬膜下的序曲、而她现在的说话异常是今天的急诊计算机断层、不是下周的全科复审“；急性处理——”扫描跨越骨缝的新月形、与卒中及神经外科团队一起做逆转决定（危及生命的出血用凝血酶原复合物与维生素K、带血栓风险的诚实——她现在不再防卒中、及何时重启之问没有整齐答案、需要一个记录在案的多学科决定、及重复影像与从钻孔到骨窗开颅处理需要处理机化膜的外科路径）；之后——“本应在数周前完成的跌倒检查程序、用她自己的数字讨论她的卒中风险与出血评分之后再做抗凝决定左心耳封堵转诊在这场确切的谈话中已是一个真实选项、华法林对直接口服抗凝药的复审带肾算术与依从现实、及浴室扶手与淋浴椅与防滑垫与夜灯、及那位去过她真实住宅的职业治疗师、因为打开她颅骨的那个柜子已经在那儿二十年了。系统注记：她拒绝入院需要一个记录在案的能力谈话、一个具名的安全网联系人、与一个已预约的复审——那种保护不了任何人的“她拒绝了”、通常是写下了字却没有做功课的记录。**

::: example “跌倒发作”的84岁患者 {#ex-dropattack}
一年内四次“我的腿突然一软”、两次在楼梯上、一次造成腕部骨折；从无意识丧失、无头晕；神经系统检查正常包括肌力；她被告知是她的膝盖、并被给了一个助行架；更细的病史显示发作持续数秒、在颈部旋转后开始（倒车、床上翻身）、一次在紧领口之后。
::: solution
**颈动脉窦高敏与“腿一软”传说（[[#def-causes]]、[[#def-assessment]]）：改变诊断的病史——”体位触发的、意识保留数秒的脑灌注不足是颈动脉窦综合征的模式转头与领口及倒车入车库、而我的腿软了是许多老年人描述全脑灌注不足的方式、因为由颈部机械触发的无意识丧失倒地是大脑而不是脊髓的、膝盖从来不是罪魁“；检查——”监护下的颈动脉窦按摩只能在一个准备好起搏除颤的临床医师在场时做、绝不双侧、并把近期短暂脑缺血发作或血管杂音列为禁忌：超过3秒的心脏停搏应答或50毫米汞柱的降压值命名这个综合征、带心电图对应的记录、及床边检查不明确时的晕厥单元转诊、及如果图像指向神经介导型则倾斜台的角色“；治疗——”心脏抑制型变异起搏的证据、是与心脏科医师真正的谈话、而不是塞给她的那个助行架、加教育转头的意识与反复晕厥的驾照规则要正规说明、及松开领口与倒车课程、听起来像笑话、直到你见过由此而来的第五次骨折“；及元教训——”腿一软的病史是一道戴着她无力戴得更像的伪装的晕厥问题：在老年成人中、无头部损伤模式的反复无法解释跌倒要接受与晕厥相同的检查程序、因为它们中的许多就是晕厥、而膝盖与笨拙与只是老了是审计中大多数被漏掉的起搏病例之前的三个标签。**

::: example 白内障手术让跌倒减半的71岁患者 {#ex-cataract}

## 通向何处

晕厥鉴别在[[cardiovascular/arrhythmias]]与[[cardiovascular/circulation-blood-pressure]]、骨级联在[[endocrine/bone-calcium]]与[[geriatrics-palliative/ageing-frailty]]、卒中与帕金森综合征病因在[[nervous-system/motor-systems]]与[[nervous-system/movement-disorders]]、去处方机制在[[geriatrics-palliative/polypharmacy]]。

::: history
**在人口学迫使这个问题之前、跌倒是医学研究最少的杀手：18世纪讣告里体面的“衰老跌倒”、19世纪心理学者对老年步态的兴趣、及20世纪初的认识（Marjory Warren时代的英国工作、与1940-50年代的美国老年学）——跌倒聚集在被机构化的老年人中、并预测当时人人正在学会计数的骨折。现代科学始于1970-80年代的流行病学转向：马萨诸塞与奥克兰及澳大利亚队列研究产生了“三分之一”这个数字（一个如此违反直觉、以致被重新测量四次才被相信的数字）、Campbell与Robertson及Otago1997年的试验使运动成为一个跌倒干预而不是一句空话、而Tinetti与Guralnik及多族裔布鲁克林老年研究时代把“意外”这个概念拆解为步态与平衡与恐惧。生理机制随后跟上：Lord与墨尔本跌倒兴趣组关于反应时间与下肢肌力的工作、及Morris与Ian Campbell相关的β阻滞剂与跌倒安心研究、及把跌倒命名为触发项而把骨强度命名为髋部骨折之弹药的骨质疏松性骨折流行病学“跌倒是事件、骨质疏松是疾病”这个骨章继承的框架、及解释“她站起来就头晕”是一个诊断而不是借口的感觉与前庭医学工作。黑矇文献提供了内科那一半：Wieling与Kenny及Sheldon与各晕厥指南时代、逐步把无法解释的跌倒移入晕厥检查程序、以及1990-2000年代颈动脉窦综合征心脏起搏试验与埋藏式记录器革命、不断找到老的胸部检查找不到的心律失常、其令人尴尬的推论是几十年被标为“跌倒发作”与“笨拙”的老年人一直在发生间歇性心脏阻滞。服务时代完成整合：指南跌倒指导及其更新、从处方跨越到跌倒结局的药物复审证据、关于跌倒后级联的系统质量指标工作、及Gillespie主导的Cochrane综述给出的结论：运动有效、居家危险处理主要在真有危险处有效、而多因素干预在高风险人群中有效——一支证据基础被此后的指南稀释成“把这些都做一遍”的一句话。阴暗面的历史是安老院与医院跌倒产业：1990-2010年代的床报警器与腕带与约束带及把床推进墙角的强制时代、它减少了一些跌倒、却产出了被约束、被报警、被孤立的住民文献、及如今监管框架所命名的尊严与自由损害（“跌倒不是患者安全问题、未预防的伤害性跌倒与限制性反应合起来才是”的转变、及限制性实践减少规划、及最重要的、2010-2020年代从床报警器转向如厕协助与可见性及活动——这是跌倒医学关于行为与轮转的通则教训：技术从来不是干预、投入的人力与判断才是）。当前这一章是整合路径的经济学：指南实施后的差异与2020年代整合跌倒服务的评价文献、及旁边的骨折联络与老年骨科证据、和公平框架：跌倒风险跟随贫困与族群、最可能跌倒与最不可能被提供运动班的是同一个人、所以这条路径真正的干预是一张公交车票与一个会回电话的人。——[[geriatrics-palliative/ageing-frailty]]、[[cardiovascular/arrhythmias]]、[[geriatrics-palliative/polypharmacy]]。**
:::

::: summary
- 跌倒是一个症状：把它分为机械性、晕厥性或多因素性；无先兆的无法解释跌倒在证明否则之前是晕厥、需要心律与体位评估。
- 收益最高的检验是免费的：有目击者的故事、带脉搏应答的卧立位血压、药柜、足、眼、起立行走试验。
- 带足够剂量的运动是首选的防跌倒药；针对性的去处方、白内障手术、及为正确心律起搏是其他几个大效应量。
- 抗凝者的头部外伤意味着当日评估与一个家属真能使用的延迟硬膜下安全网；长时间躺卧是医学急症横纹肌溶解、急性肾损伤、低体温。
- 对跌倒的恐惧是一个有其自身患病率、可治疗的后遗症：计划必须买回信心、而不只是预防下一次撞击。
- 多因素服务在高风险者中胜过零散的单一干预；路径的成功指标是一个在家有功能的人、不是一份填写完整的清单。
:::

**一条动脉上的两种病（[[#def-assessment]]、[[#def-prevention]]、[[nervous-system/movement-disorders]]）：识别——”卧位高血压伴立位低血压是自主神经衰竭（正在出现的帕金森提示由突触核蛋白病在做这件事）、而治疗任何一个数字都会加重另一个：这是医学中真正的杂耍会诊之一、而正确的第一步是减法减少或停用降压药、尤其是晚间剂量与长效制剂、因为站立血压才是送她进医院的东西、而在跌倒者中近期内卧位数字是较小的敌人；非药物阶梯——“缓慢改变体位与先坐后站规则、成次的饮水500毫升快速饮用的升压效应是真实的生理、若心脏允许则加盐、及神经源性体位性低血压用腰部加压或腹带优于腿袜、床头抬高以应对夜间钠排泄与晨间低谷、及少量多餐应对餐后下降及饭后散步而不是午睡“；药物最后而小量——”米多君用于最糟的时段而不是全天下午5-6点后不给剂量以保护卧位血压、及氟氢可的松带卧立位监测与卧位高血压观察、及在获批准地区的屈昔多巴、及夜间高血压若处理则用短效药在睡前——是让两个数字都活着的反向处方“；及大局——”自主神经转诊与帕金森进展的讨论、及她及照护者需要的体位性低血压教育、因为她的疾病会改变这场杂耍、而今天优雅的计划会在每次复审时被重新争论——这就是跟随一个诊断的含义。**

::: exercise 审计院内跌倒 {level=2}
你的病房：12个月34次跌倒、6次伴损伤；所有不良事件都写“无人目击、发现于地面”；所有跌倒风险评估都已完成并“高风险”；凌晨两点的给药轮包含降压药与镇静药。像一位老年病医师与一位人因专家那样审计它。
::: solution
**簇分析（[[#def-prevention]]）：解读——”医院里无人目击的跌倒是一次目击失败、不是患者的属性：人们会因为去厕所、走向出口、及凌晨两点找水喝而跌倒、而你真正拥有的数据是一个穿着患者责怪外衣的凌晨两点模式；诚实的类别：如厕之旅、自行服药的游荡、排尿后体位性首次下床、查房后疲惫的活动、及因按钮位置或上次她按下时员工说不要而未被使用的呼叫铃；能推动数字的修补：把药物对齐到身体把降压药移到不在她夜尿中间的时点、质疑镇静药因为它正在造成那起夜间意识混乱的起床本身、如厕时间表与床边坐便椅及触手可及的男式尿壶——因为尿壶是有尊严的医学而不是失败、未固定的车轮与低床、及为那个无论如何都会滚下来的人放在床旁地上的床垫、及真的能被听见的地板报警器、及她可以问我任何事的文化、用她试图做什么的真相取代发现于地面这句话、及每日短时团队会读跌倒风险评分然后做评分告诉我们的事（一个什么都不改变的评分只是一份法律文书、而谵妄者不会替你签它）。重新审计的指标：伤害性跌倒率与限制性应对率放在一起、因为一个靠绑住患者来“解决”跌倒的病房偷走了结局、而这两个数字应同在一只仪表盘上、让偷窃的风险可见。**

::: exercise 设计跌倒服务 {level=3}
你的地区：没有统一的跌倒路径；急诊每年做出“机械性跌倒”出院3000次而无随访；唯一的跌倒门诊每周开4个时段面对700份转诊；社区运动容量有26周等待；骨折联络服务只存在于一所医院。构建模型、其容量规划、其公平措施与其指标。
::: solution
**跌倒系统设计（[[#def-prevention]]、[[geriatrics-palliative/ageing-frailty]]）：对现状的诊断——“3000个未经检查的机械性标签是一支未匹配的下一跌倒与下一骨折队列、这是该服务最大的隐匿患病：急诊的标签把一个症状变成一个已关闭的事件、而同一个人六个月后带着髋部再来；每周4个时段的门诊是为担忧的健康者准备的检伤剧场、而无骨折的反复跌倒者从不被看到因为他们从不就诊；而26周的运动等待、是在为一个证据基础要求剂量与近期性的药物开一张传单——是一支有真实候补名单的假干预“；模型——”在每一个交接点捕捉筛查：急诊与救护车与全科及骨折门诊都触发同一个一问加起立行走最低项的评估、高风险者自动转入多因素门诊、及为红旗征保留快速通道无先兆晕厥在本月而不是今年得到心律捕捉；门诊被重新设计成一个枢纽、带执业护士与药师及物理治疗与职业治疗、同一日的药物与直立血压与步态与环境评估、计划对着转诊理由而不是对着空气写；运动容量被建成服务的核心投资证据对容量之比：每一笔投入防跌倒运动的钱都买回骨折住院、使跌倒服务在财政部文件中的辩护自行写成、其采购模型为完成课程的剂量付费而不是为转诊付费、及社区健身房与舞蹈及武术及以大礼堂为场所的规划带交通方案、及“她没来”的一个电话规程——因为出勤是剂量的一部分；公平层——”跌倒率与骨折率与服务触达都跟随贫困与族群与乡村、所以采购任务书点名队列、外展通过人已经去的地方进行、信息用本地区的语言与格式、并按五分位报告指标、因为一支只服务热心与富裕者的跌倒服务只是一个带转诊代码的运动班；及问责——“地区报告未经评估的反复跌倒者数字那3000的分母、从跌落到干预的时间、运动课程完成率、每家单元骨折后的骨质疏松治疗率、每家安老院的伤害性跌倒率、及一年髋部骨折死亡率、带具名负责人、及一个把空缺名额与钱放在一起看的董事会。**
