65岁及以上的居家老人中，每年约有三分之一发生跌倒；80岁及以上者约有一半。大多数跌倒不造成严重损伤，但跌倒是老年人损伤相关死亡的最常见原因，导致了大多数髋部骨折，而且常常标志着走向依赖的开始。跌倒同时也是一个症状：它是心脏、大脑、肌肉、眼睛、药物和居家环境中各种问题的可见终点。

本章介绍跌倒如何分类、为什么会发生、如何评估一位跌倒过的老人，以及哪些干预能预防再次跌倒。本章以[[geriatrics-palliative/ageing-frailty]]中储备和衰弱的概念为基础。

## 什么是跌倒，为什么会跌倒 {#sec-causes}

::: definition 跌倒 {#def-fall}
**跌倒**是指一个人非故意地倒在地面、地板或其他较低平面上的事件。这个定义不涉及原因：晕厥、绊倒或癫痫发作引起的都是跌倒，而评估的任务就是弄清楚是哪一种。
:::

把跌倒大致分为三类是有帮助的，因为每一类引出的评估不同。

- **机械性（意外）跌倒**：平衡和肌力通常足以应付的人发生了绊倒或滑倒。健康人的真正意外跌倒，除了处理损伤外几乎不需要别的。但“机械性跌倒”这个说法被滥用了：一个健康的30岁成人脚趾勾到地毯时很少会摔倒，所以一位因此摔倒的老人可能存在腿部无力、视力差或反应迟缓。
- **晕厥性跌倒**：由脑血流减少引起的短暂意识丧失，例如直立性低血压、心律失常、颈动脉窦过敏或主动脉瓣狭窄。老年人往往不记得自己失去过意识，因此晕厥常常以“原因不明的跌倒”出现。
- **多因素跌倒**：衰弱者中最常见的模式，几个程度不重的危险因素叠加，越过了跌倒的阈值。

::: definition 跌倒的危险因素 {#def-causes}
**内在危险因素**属于个人本身：既往跌倒、高龄、肌肉无力、步态和平衡障碍、视力损害、认知障碍和痴呆、帕金森病、卒中、周围神经病变、关节炎、足部问题、尿急和尿失禁、抑郁、直立性低血压，以及对跌倒的恐惧。**外在危险因素**属于环境和治疗：药物（尤其是镇静药和降压药）、照明不足、松动的地毯、楼梯、不合适的鞋，以及在楼梯上佩戴双光或渐进多焦点眼镜。**情境因素**描述当时正在做的事：夜间起床排尿、匆忙行动，或拿着东西上下楼梯。
:::

::: theorem 跌倒风险随危险因素数目增加而升高 {#thm-multifactorial}
跌倒的风险随一个人所具有的危险因素数目急剧上升。在一项针对75岁及以上居家老人的经典队列研究中（Tinetti等，1988），一年内跌倒的比例从没有危险因素者的8%上升到有四个或更多危险因素者的78%。
:::

::: proof
平衡是一个控制系统。大脑整合来自眼睛、内耳以及关节和皮肤（本体感觉）的信息，并通过肌肉校正姿势。每一个危险因素都削弱了这个系统的一个部分：白内障削弱视觉，神经病变削弱本体感觉，镇静药减慢信息处理，股四头肌无力限制了校正能力。健康的系统有冗余，一个薄弱环节可由其他环节代偿。当几个环节同时薄弱时，就没有余力了，一次普通的扰动（转身、绊一下、快速站起）便无法纠正。这正是[[geriatrics-palliative/ageing-frailty#thm-threshold]]中的阈值原则在平衡上的应用，它也解释了为什么即使只去除一两个危险因素也能带来有意义的改变。
:::

### 导致跌倒的药物

药物是最容易改变的原因之一。主要类别（常称为**增加跌倒风险的药物**）包括：

- **精神活性药物**：苯二氮䓬类和“Z类药物”（佐匹克隆（zopiclone）、唑吡坦（zolpidem））、抗抑郁药、抗精神病药，以及有镇静作用的抗组胺药。
- **降低血压的药物**：降压药、利尿剂、用于前列腺症状的α受体阻滞剂（坦索罗辛（tamsulosin）、多沙唑嗪（doxazosin））、硝酸酯类，以及治疗帕金森病的药物。
- **影响大脑或平衡的药物**：阿片类、加巴喷丁类、抗胆碱能药物，以及某些抗癫痫药。
- **可导致低血糖的药物**：胰岛素和磺脲类。

服用多种药物本身也会独立地增加风险，与药物种类无关，这也是跌倒评估总要包括用药评估的原因之一（[[geriatrics-palliative/polypharmacy]]）。

### 跌倒的后果

损伤从瘀伤到腕部、肱骨、骨盆和髋部骨折，以及头部损伤不等。服用抗凝药的老年人尤其容易发生颅内出血，包括**慢性硬膜下血肿**，它可在一次轻微头部外伤后数天或数周出现，表现为意识混乱、头痛、嗜睡或行为的逐渐改变。

**长时间倒地**（通常定义为在地上躺一小时或更久）可导致压力性损伤、脱水、低体温、横纹肌溶解和急性肾损伤，并预示不良结局。无法自行站起本身就是肌无力的信号，需要处理。

**害怕跌倒**在跌倒后很常见，有时在跌倒前就已存在。它使人限制活动，导致更多的肌肉流失、更差的平衡和更多的跌倒，即**跌倒后综合征**。治疗它（通过运动、建立信心以及制定跌倒时的应对计划）是跌倒照护的一部分。

::: warning 不要止步于损伤
一个常见错误是处理了骨折或缝合了伤口，就让患者出院，而没有问她为什么会跌倒。老年人的每一次跌倒都需要回答两个问题：造成了什么损伤，以及是什么导致了跌倒。跌倒是未来跌倒的强预测因素，所以首次就诊时的评估是预防下一次跌倒的最好机会。
:::

## 评估 {#sec-assessment}

跌倒非常常见，不可能每一位跌倒者都接受全面的专科评估。英国国家卫生与临床优化研究所（NICE）的NG249指南（2025年，取代了2013年的CG161）建议：应询问65岁及以上的人（以及50–64岁的高风险者）是否跌倒过；对过去一年内跌倒过，并且存在衰弱、受伤需要医疗处理、失去意识、无法在无人帮助下站起，或过去一年跌倒两次或以上的人，应提供全面的多因素跌倒评估。跌倒过但没有这些特征的人，应评估其步态和平衡，如有受损，则提供预防跌倒的运动项目。NG249还建议不要用跌倒风险预测工具来估计个人的风险：病史和评估能更好地完成这项工作。

::: definition 多因素跌倒评估 {#def-assessment}
**多因素跌倒评估**旨在找出每一个可治疗的跌倒促成因素。其主要组成部分为：

1. **跌倒的经过**：当时在做什么、有无先兆症状、有无意识丧失、在地上躺了多久，以及目击者的描述。
2. **既往跌倒史和对跌倒的恐惧。**
3. **用药评估**，重点是增加跌倒风险的药物。
4. **心血管评估**：脉搏、心音（主动脉瓣狭窄）、卧立位血压和心电图。
5. **步态、平衡、肌力和活动能力**，例如用起立-行走计时测试或步速。
6. **神经系统检查**：帕金森病、卒中、神经病变和小脑疾病的体征。
7. **视力**、认知、情绪、排尿控制、足部和鞋。
8. **骨骼健康和骨折风险**（例如FRAX），因为今天没有骨折的跌倒，明天可能导致骨折。
9. **居家危险因素和活动**，通常由作业治疗师评估。
:::

### 病史

病史是评估中最有用的部分。要问跌倒之前、之中和之后发生了什么。站起时头晕等先兆提示直立性低血压；心悸或完全没有先兆提示心律失常；旋转感提示前庭问题。转头时或衣领过紧时跌倒提示颈动脉窦过敏。询问目击者：患者是否脸色苍白、是否失去意识、是否有抽动，以及恢复有多快；事后长时间的意识混乱提示癫痫发作、头部外伤或低血糖。老年人常常少报跌倒或为其找理由（“我只是绊了一下”），因此家属或照护者的描述很有价值。

### 卧立位血压

::: definition 直立性低血压 {#def-oh}
**直立性（体位性）低血压**是指从卧位站起（或头高位倾斜）后3分钟内，收缩压持续下降至少20 mmHg，或舒张压下降至少10 mmHg。测量时患者先平卧至少5分钟，在站起后约1分钟和3分钟时测量；测试中出现的症状应予记录。
:::

病因包括脱水、降压药、糖尿病和帕金森病所致的自主神经功能衰竭，以及长期卧床。脉搏反应有帮助：站立时心率明显上升提示血容量不足，而心率几乎不升提示自主神经功能衰竭或β受体阻滞。部分自主神经功能衰竭患者平卧时血压高（**卧位高血压**）而站立时血压低；对他们的治疗需要专科处理。

### 步态与平衡测试

在**起立-行走计时测试（TUG）**中，受试者从一把标准椅子上站起，以正常速度走3米，转身，走回并坐下。用时超过约12–15秒提示活动能力受损，跌倒风险较高；《世界跌倒指南》（2022）以TUG超过15秒或步速低于0.8 m/s来识别需要进一步评估的人。观察测试过程与计时同样有用：需要用手臂撑起提示股四头肌无力，小碎步拖行提示帕金森病或脑血管病，转身不稳提示平衡差。

### 辅助检查

辅助检查依病史而定。心电图是常规。血液检查通常包括全血细胞计数、肾功能和电解质、血糖，以及在相关时的维生素B12和甲状腺功能。长时间倒地后应检查肌酸激酶和肾功能。如果跌倒原因不明或提示晕厥，可能需要较长时间的心律监测（动态心电图、体外贴片或植入式心电记录器），并可由受过培训的人员在心电和血压监测下进行颈动脉窦按摩。脑部影像不是常规：其指征是按头部外伤指南需要检查的头部外伤、新出现的局灶性神经体征，或提示硬膜下血肿的症状。

::: example 两次“机械性”跌倒与一个传导阻滞 {#ex-syncopal}
Joyce Adeyemi夫人79岁，五个月内跌倒三次，均无先兆。两份急诊记录写着“机械性跌倒”。她因高血压服用氨氯地平（amlodipine）和吲达帕胺（indapamide），上个月又因尿频开始服用坦索罗辛。心电图示窦性心律伴一度房室传导阻滞（PR间期260 ms）。卧位血压152/84 mmHg；站立3分钟时为118/68 mmHg，并感到头晕。请解读这些发现并概述计划。
::: solution
**解读。**老年人无先兆的跌倒，在被证明不是之前，都应视为可能的晕厥。她的收缩压下降$152 - 118 = 34$ mmHg，舒张压下降$84 - 68 = 16$ mmHg，并伴有症状，符合直立性低血压的定义（[[#def-oh]]）。三种药物起了作用：钙通道阻滞剂、噻嗪样利尿剂和α受体阻滞剂。每一种都是出于合理的理由开始的，但合在一起降低了她的站立血压。一度房室传导阻滞本身不会引起跌倒，但对于无先兆、原因不明跌倒的患者，它提示可能存在间歇性的更高度传导阻滞。

**计划。**

1. 评估用药。坦索罗辛是最新加用的药物，最可能是罪魁；考虑停用，并重新评估她的尿频（尿频可能由利尿剂引起）。评估她的血压目标是否合适，在适当时减少或停用降压药。
2. 安排较长时间的心电监测，因为尚未排除间歇性心律失常。如果症状复发而监测无阳性发现，可考虑植入式心电记录器。
3. 指导她缓慢站起、补充液体，以及感到要晕倒时该怎么做。
4. 告知她驾驶方面的要求：她必须遵守驾照管理机构关于不明原因意识丧失的规定，这一建议应记录在案。
5. 提供肌力与平衡训练项目，并评估骨骼健康。
:::
:::

## 预防与管理 {#sec-prevention}

::: definition 多因素跌倒预防 {#def-prevention}
**跌倒预防**是针对个人已识别的危险因素组合采用的干预措施。证据最充分的干预包括：渐进性的肌力与平衡训练；用药评估，停用或减少增加跌倒风险的药物；由作业治疗师为高风险者进行居家危险因素评估和改造；治疗视力问题，尤其是白内障手术；处理直立性低血压；为部分缓慢性心律失常或心脏抑制型颈动脉窦过敏患者植入起搏器；以及治疗骨质疏松，以降低一旦跌倒时发生骨折的风险。
:::

**运动**是最有效的单项干预。2019年一项关于居家老年人运动的Cochrane系统评价（Sherrington等）发现，运动使跌倒发生率降低约23%（率比0.77）。以挑战平衡和功能为主的项目，如Otago项目或跌倒管理运动（FaME）项目，效果良好；平衡训练与抗阻训练相结合的项目似乎效果最好。运动要想有效，必须循序渐进、持续数月，并且强度足以挑战平衡；一份没有随访的运动传单是不够的。太极拳也能减少跌倒。单纯步行则不能。

**用药评估**减少导致跌倒的药物负担。停用或逐渐减量精神活性药物尤其值得，但必须缓慢进行以避免撤药反应（见[[geriatrics-palliative/polypharmacy]]）。

**居家危险因素改造**由上门的作业治疗师评估，主要在高风险者中减少跌倒，如近期住过院或视力差的人。常见的改造包括安装扶手、改善照明、清除绊倒隐患，以及把床挪得离厕所近一些。

**视力。**为白内障患者尽早进行第一只眼的白内障手术可减少跌倒。应提醒人们：新眼镜，尤其是多焦点镜片，在适应期间可能增加跌倒风险；外出步行和上下楼梯时，单焦点的远用眼镜可能更安全。

**维生素D。**维生素D补充剂可纠正缺乏，是骨骼健康治疗的一部分，但大型试验显示，它不能预防非缺乏者的跌倒。一项每年一次给予极大剂量（每年一次500,000单位）的试验，反而增加了跌倒和骨折（Sanders等，2010）。因此，应把维生素D视为对缺乏的治疗，而不是预防跌倒的药物。

**髋部保护器**（带衬垫的衣物）在照护机构中可能减少髋部骨折，因为那里能坚持穿戴；但在社区中作用甚微，主要是因为人们不穿。

**报警器和远程照护**不能预防跌倒，但呼叫挂坠可以缩短倒地时间，这对独居者本身就是一个值得追求的目标。

::: example 抗凝治疗中的头部外伤 {#ex-subdural}
Irene Kowalczyk夫人82岁，因心房颤动服用华法林（warfarin）。她在浴室跌倒，头撞到浴缸边缘。她不确定是否失去过意识。她的INR为3.2。她感觉良好，拒绝住院。两周后她的女儿打来电话：母亲变得健忘、头痛，而且“说话怪怪的”。首次就诊时应该怎样处理？现在又该怎样处理？
::: solution
**首次就诊时。**NICE头部外伤指南（NG232，2023）建议，服用抗凝药的人发生头部外伤后，即使没有其他危险因素，也应在8小时内进行头颅CT检查。如果扫描正常，她和家人应得到清晰的口头和书面建议，说明警示症状（头痛加重、意识混乱、嗜睡、呕吐、肢体无力）以及应联系谁，因为硬膜下血肿可能延迟出现。如果她对该决定有决策能力，她拒绝住院的意愿应受到尊重，并记录决策能力评估、所提供的信息和安全保障计划。

**现在。**服用华法林者头部外伤两周后出现新的意识混乱、头痛和言语改变，强烈提示**慢性硬膜下血肿**。她需要紧急评估，并在今天进行CT检查。如果发现血肿，应紧急逆转华法林（按当地方案使用凝血酶原复合物和静脉维生素K），并请神经外科会诊；有症状的慢性硬膜下血肿常经颅骨钻孔引流。

**之后。**是否重新开始抗凝，需在她本人、她的心内科或内科医生以及神经外科医生共同参与下，权衡她的卒中风险和出血风险。第一次跌倒后就应该进行全面的跌倒评估，现在必须进行：她为什么在浴室跌倒，有哪些可以改变（扶手、淋浴椅、照明、用药评估）？单纯跌倒本身并不是对获益者停用抗凝的理由；对跌倒的治疗就是跌倒评估。
:::
:::

::: example “我的腿一下子就软了” {#ex-dropattack}
Ada Lindqvist夫人84岁，一年中有四次“腿一下子就软了”，其中一次导致腕部骨折。她没有注意到失去意识，也没有头晕。神经系统检查，包括下肢肌力，均正常。她被告知是膝盖无力，并得到一个助行架。详细询问后发现，有两次发生在她转头倒车时，一次发生在她穿着高领紧口衬衫时。应考虑什么诊断？如何确诊？
::: solution
由转头或颈部受压诱发的发作提示**颈动脉窦综合征**：对颈动脉窦压力感受器刺激的过度反射反应，引起心动过缓（**心脏抑制型**）、血压下降（**血管抑制型**）或二者兼有。老年人常不记得短暂的意识丧失，所以“腿软了”可能是在描述晕厥。下肢肌力正常不支持膝盖是原因。

颈动脉窦按摩由受过培训的人员在持续心电和血压监测下进行，先平卧，再直立（在倾斜床上），每次只按摩一侧，绝不双侧同时进行。近期有卒中或短暂性脑缺血发作者应避免；有颈动脉杂音者，除非已排除颈动脉疾病，也应避免。心室停搏超过3秒或收缩压下降超过50 mmHg为异常（欧洲心脏病学会晕厥指南，2018）；诊断颈动脉窦综合征需要该检查在符合的病史背景下重现她的症状。

如果证实为心脏抑制型，双腔起搏可减少发作，应与心内科医生讨论。还应建议她避免穿紧领衣服，尽可能整个身体转动而不是只转头，并遵守驾照管理机构关于晕厥后驾驶的规定。腕部骨折后需要评估她的骨骼健康。
:::
:::

::: example 看清楼梯 {#ex-cataract}
Patience Owusu夫人71岁，两年来反复跌倒。三次转介去运动班她都没有完成。由于白内障，她双眼视力为6/24。她两次拒绝转诊眼科，说：“我在家里应付得很好，我知道东西都在哪儿。”你会如何处理？
::: solution
**证据。**为白内障患者做第一只眼的手术可减少跌倒；视力差是可改变的危险因素，但人们常常少报，因为在熟悉的环境中他们能代偿。“我知道东西都在哪儿”描述的正是一个已经学会在视力不佳时应付的人；她的跌倒发生在环境不那么可预测的时候。

**谈话。**之前的建议可能只从视力的角度提出。把手术与她自己的目标（少跌倒、保持独立、安全外出）联系起来，并解决实际障碍（交通、有人陪同、术后怎么办），可能改变她的决定。这是她的选择；如果她仍然拒绝，应予尊重并记录。

**计划的其余部分。**视力只是一个促成因素。要问清运动转介为什么失败（交通、时间、疼痛、情绪低落），并提供她能参加的方案，例如物理治疗师提供的居家运动项目。评估她的用药和血压，改善照明并标记台阶边缘，评估她的骨骼健康。治疗白内障可能是最大的单项获益，但多因素计划能带来最好的总体效果。
:::
:::

::: example 计算预防的跌倒次数 {#ex-rate}
某社区跌倒服务为200人开展肌力与平衡训练项目，这些人的平均跌倒率为每人每年2.0次。假设该项目使跌倒率降低Cochrane系统评价中所见的23%（率比0.77），一年可预防多少次跌倒？
::: solution
没有该项目时：$200 \times 2.0 = 400$次跌倒/年。有该项目时：$400 \times 0.77 = 308$次跌倒/年。预防的跌倒：$400 - 308 = 92$次/年。

有两点需要解读。第一，率比作用于跌倒的次数，所以结果表示为预防的跌倒次数，而不是受保护的人数：有些人会多次跌倒，而该项目既减少首次跌倒，也减少反复跌倒。第二，只有当项目与试验中实施的内容相符（循序渐进、挑战平衡、持续数月的运动）且人们坚持参加时，试验中的效应才适用。
:::
:::

### 医院内跌倒

跌倒是医院中最常报告的不良事件之一。住院患者风险高，原因包括急性疾病、谵妄、陌生环境、新加的药物以及急于去厕所。良好的做法包括：对每位老年住院患者进行多因素评估（而不是风险评分）、测量卧立位血压、评估镇静类药物、预防谵妄、确保能拿到助行器和呼叫铃、定时协助如厕，以及穿合适的鞋。任何院内跌倒后，应在移动患者之前检查有无损伤；如果可能有髋部骨折或脊柱损伤，应使用安全的搬运设备；还应由医生评估，如果不能排除头部外伤，应进行神经系统观察。床栏和约束可能造成伤害，不能替代个体化评估。

::: quiz
对于居家老年人，哪项干预降低跌倒发生率的随机证据最强？
- [ ] 每位70岁以上老人每年一次大剂量维生素D
- [x] 持续数月的渐进性肌力与平衡训练项目
- [ ] 为每位跌倒者配备髋部保护器
- [ ] 每次全科就诊时进行跌倒风险预测评分
::: solution
渐进性、挑战平衡的运动使跌倒发生率降低约四分之一。维生素D不能预防非缺乏者的跌倒，而极大剂量的年度给药在一项试验中反而增加了跌倒。髋部保护器在照护机构中可能减少髋部骨折，但不能预防跌倒。NICE建议不要用跌倒风险预测工具来估计个人的风险（[[#def-prevention]]）。
:::
:::

## 后续内容

晕厥和心律失常见[[cardiovascular/arrhythmias]]，血压调控见[[cardiovascular/circulation-blood-pressure]]。骨质疏松和骨折预防见[[endocrine/bone-calcium]]。帕金森病及其他运动障碍见[[nervous-system/movement-disorders]]。在本课程中，跌倒与衰弱（[[geriatrics-palliative/ageing-frailty]]）、谵妄（[[geriatrics-palliative/delirium-dementia-care]]）和用药评估（[[geriatrics-palliative/polypharmacy]]）相互关联。

::: history
在20世纪的大部分时间里，老年人跌倒被视为意外或衰老不可避免的一部分。1986年，Bernard Isaacs等描述了“起立行走”测试，这是一种在床旁观察起身、行走和转身的简单方法；1991年，Diane Podsiadlo和Sandra Richardson加上了秒表，形成了起立-行走计时测试。1988年，Mary Tinetti等对康涅狄格州纽黑文的336名75岁及以上老人随访一年，表明跌倒可以由少数危险因素预测，而且风险随危险因素的累积急剧上升。Tinetti后来的试验（1994）表明，针对这些危险因素的多因素干预可以减少跌倒。在新西兰，A. John Campbell、M. Clare Robertson等在20世纪90年代后期开发并检验了一项居家肌力与平衡训练项目，即后来的Otago运动项目。2001年，Rose Anne Kenny等在纽卡斯尔证明，起搏可减少心脏抑制型颈动脉窦过敏老年人的跌倒，这有助于确立许多“原因不明”的跌倒源于心血管。
:::

::: summary
- 跌倒是一个症状。把它分为机械性、晕厥性或多因素，并记住老年人常常不记得自己失去过意识。
- 风险随危险因素数目急剧上升；即使只去除几个也有帮助。
- 评估是多因素的：病史和目击者描述、用药评估、卧立位血压、心电图、步态与平衡、神经系统、视力、认知、排尿控制、足部、骨骼健康和居家环境。
- 直立性低血压是指站立后3分钟内收缩压下降至少20 mmHg或舒张压下降至少10 mmHg。
- 持续数月、挑战平衡和肌力的运动是最有效的干预。用药评估、白内障手术、对高风险者的居家危险因素改造，以及为合适的缓慢性心律失常植入起搏器，可进一步增加获益。
- 维生素D治疗缺乏，但不能预防非缺乏者的跌倒。
- 服用抗凝药者发生头部外伤后需要及时进行CT检查，并建立应对迟发性硬膜下血肿的安全保障。
- 长时间倒地和害怕跌倒本身就是危害。
:::

## 习题

::: exercise 为跌倒分类 {level=1}
把以下每次跌倒归为主要是机械性、晕厥性还是多因素，并为每例指出一项进一步的评估：(a)一位热爱步行的68岁女性在冰面上滑倒，摔断了手腕；(b)一位80岁男性坐在桌旁时无先兆地倒下，醒来时躺在地上；(c)一位87岁女性，患黄斑变性、膝骨关节炎、尿急，新近开始服用一种抗抑郁药，夜间去厕所途中跌倒。
::: solution
(a)机械性：冰面滑倒是真正的危险，能让健康人摔倒。她仍需要评估骨骼健康，因为站立高度跌倒导致腕部骨折提示骨质疏松。(b)晕厥性：坐位时无先兆地失去意识，提示心律失常。他需要心电图和较长时间的心律监测，并接受驾驶方面的建议。(c)多因素：视力差、膝痛、夜间尿急和新加的精神活性药物叠加在一起。她需要用药评估（抗抑郁药）、排尿控制评估、夜间照明，以及肌力与平衡训练项目。
:::
:::

::: exercise 解读卧立位血压 {level=1}
一位76岁男性平卧5分钟后血压为138/76 mmHg，站立1分钟时为124/70 mmHg，站立3分钟时为112/66 mmHg；脉搏从64次/分升至68次/分。他有直立性低血压吗？脉搏反应提示什么？
::: solution
3分钟时收缩压下降了$138 - 112 = 26$ mmHg，符合定义（3分钟内收缩压至少下降20 mmHg或舒张压至少下降10 mmHg）。舒张压下降10 mmHg，也符合定义。心率仅上升4次/分，这是一种迟钝的反应，提示自主神经功能衰竭（例如糖尿病或帕金森病所致）或β受体阻滞剂等减慢心率的药物，而不是单纯的血容量不足，后者通常引起更大的心率上升。
:::
:::

::: exercise 运动项目预防的跌倒 {level=1 check="0.23*150"}
某照护机构有50名住户，平均跌倒率为每人每年3次。如果一项运动项目使跌倒率降低23%，一年可预防多少次跌倒？
::: solution
基线跌倒：$50 \times 3 = 150$次/年。预防的跌倒：$150 \times 0.23 = 34.5$次/年，约34或35次。注意，照护机构中的试验结果不如社区试验一致，因此这一估计偏乐观。
:::
:::

::: exercise 一年不跌倒的机会 {level=2 check="round(1000*(1-exp(-0.8*0.77)))/10"}
采用图中的简单模型，一位女性以平均每年0.8次的速率随机跌倒。她一年内至少跌倒一次的概率为$1 - e^{-0.8}$。如果她完成一项率比为0.77的运动项目，计算她一年内至少跌倒一次的概率，以百分数表示，保留一位小数。
::: hint
先把速率乘以率比，再用$1 - e^{-\text{速率}}$。
:::
::: solution
不运动时：$1 - e^{-0.8} = 0.551$，即55.1%。运动后速率变为$0.8 \times 0.77 = 0.616$次/年，至少跌倒一次的概率为$1 - e^{-0.616} = 0.4599$，即**46.0%**。“根本不跌倒”的机会的绝对改善（约9个百分点）小于跌倒次数23%的减少，这就是为什么试验同时报告这两个结局，也说明两个数字不应混淆。
:::
:::

::: exercise 跌倒后的用药评估 {level=2}
一位跌倒过两次的83岁女性服用：睡前阿米替林（amitriptyline）25 mg用于“睡眠差”、睡前佐匹克隆7.5 mg、雷米普利（ramipril）、苄氟噻嗪（bendroflumethiazide）、多沙唑嗪、用于尿急的奥昔布宁（oxybutynin），以及对乙酰氨基酚（paracetamol）。她站立时收缩压下降28 mmHg。指出可能起作用的药物，并说明你会如何调整。
::: solution
起作用的药物：阿米替林（镇静、抗胆碱能、引起直立性低血压）、佐匹克隆（镇静催眠药）、奥昔布宁（抗胆碱能；可加重认知损害），以及三种降压药（雷米普利、苄氟噻嗪和多沙唑嗪），而她有症状性直立性低血压。做法：与她讨论什么对她重要，商定优先顺序。首先停用或减量多沙唑嗪（α受体阻滞剂是直立性低血压的常见原因），并根据她目前的血压重新评估其他药物的必要性。逐渐减停佐匹克隆和阿米替林，同时给予睡眠建议，并处理睡眠差的原因（例如夜尿或疼痛）。考虑尿急的非药物处理（膀胱训练、定时排尿）并停用奥昔布宁。每次只做一两项改变，复查卧立位血压，并安排随访。剂量和减量方案依据现行指南和BNF。
:::
:::

::: exercise 服用直接口服抗凝药者跌倒后扫描正常 {level=2}
一位因心房颤动服用阿哌沙班（apixaban）的80岁男性跌倒并碰到了头。8小时内的CT扫描正常，他意识清醒。家属问他是否应该停用抗凝药，“因为他老是跌倒”。你如何回答？
::: solution
解释扫描显示目前没有出血，并给予关于迟发性出血症状（头痛加重、意识混乱、嗜睡、呕吐、肢体无力）以及应联系谁的书面建议。关于抗凝药：在心房颤动中，抗凝所预防的卒中风险通常超过跌倒带来的额外出血风险，分析提示一个人每年需要跌倒非常多次，这一平衡才会逆转。因此单纯跌倒通常不是停药的理由。决定是个体化的：核对适应证、肾功能和剂量，评估任何增加出血风险的药物（例如非甾体抗炎药或抗血小板药），最重要的是通过多因素评估治疗跌倒。记录这次讨论和他本人的意见。
:::
:::

::: exercise 他应该植入起搏器吗？ {level=3}
一位77岁男性有五次原因不明的跌倒，伴面部外伤。直立倾斜位下进行右侧颈动脉窦按摩，出现6秒的停搏，并重现了他的头晕。他的血压下降30 mmHg。他有轻度认知障碍，与妻子同住。讨论支持和反对起搏的理由，以及还需要做什么。
::: solution
支持起搏：症状被重现，停搏超过3秒，加上反复原因不明的跌倒伴外伤，符合心脏抑制型颈动脉窦综合征，双腔起搏可减少晕厥和跌倒。外伤表明这些发作是危险的。反对或需注意之处：血压下降30 mmHg提示同时存在血管抑制成分，起搏对其无效，因此跌倒可能不会完全停止；起搏有操作风险（感染、电极问题）；而且起搏预防老年人跌倒的证据并不一致。其他跌倒原因也必须处理。还需要做的：与他和妻子讨论各种选择，包括他自己的优先考虑，并评估他知情同意的决策能力；评估降低血压或减慢心率的药物；提供肌力与平衡训练和居家评估；给予驾驶建议；评估骨骼健康和骨折风险。最终决定与心内科医生共同作出。
:::
:::

::: exercise 设计跌倒管理路径 {level=3}
你被要求为一个6万人口、其中约11,000人为65岁及以上的城镇设计跌倒管理路径。按每年三分之一的人跌倒计算，估计每年有多少老人跌倒，并说明该路径应如何识别和帮助他们。
::: solution
每年约有$11{,}000 / 3 \approx 3{,}700$名老人跌倒，远远超出一个专科门诊的接诊能力。因此路径需要分层。(1)发现病例：在常规接触中询问跌倒情况（全科随访、药房、急诊、救护车出诊、社会照护），并利用救护车和急诊数据识别跌倒但未送医院的人。(2)按NICE NG249标准分流：存在衰弱、受伤、意识丧失、无法自行站起或跌倒两次及以上的人，转给跌倒服务进行多因素评估；其他人进行步态与平衡检查并提供运动项目。(3)有证据的干预：便于参加的肌力与平衡项目（社区课程和居家方案，并提供交通）、由药师或医生进行的用药评估、为高风险者提供作业治疗师上门、白内障手术快速通道、与心内科衔接处理晕厥，以及负责骨骼健康的骨折联络服务。(4)公平：贫困地区跌倒风险更高，因此服务必须覆盖居家不出、不说英语或承担照护职责的人。(5)评价指标：跌倒、致伤性跌倒、髋部骨折、运动项目的参与率和完成率，以及人们自己的目标。
:::
