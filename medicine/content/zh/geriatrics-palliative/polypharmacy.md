药物是医学中最有力的工具之一，而老年人服用的药物最多。在英格兰，许多75岁以上的人规律服用五种或更多药物，相当一部分人服用十种或更多。每一种药物可能都是出于充分的理由、由不同的处方者、按照针对单一疾病的指南开出的。合在一起，它们可能导致跌倒、意识混乱、肾损伤、出血和住院。英国一项针对默西赛德郡两家医院入院情况的经典研究（Pirmohamed等，2004）发现，约6.5%的入院与药物不良反应有关，服用多种药物的老年人受影响最大。

本章解释老年人为何更容易发生不良反应、有害的处方模式如何产生、用于评估用药的工具，以及如何安全地停药。药理学背景见[[pharmacology/patient-variation]]和[[pharmacology/adverse-reactions]]。

## 多重用药及其重要性 {#sec-problem}

::: definition 多重用药 {#def-problem}
**多重用药**是指一个人同时使用多种药物，通常定义为规律服用五种或更多药物。多重用药可以是**恰当的**——每一种药物都有适应证、有效且为本人所接受，并且药物组合已经优化；也可以是**有问题的**——药物处方不当或未能实现预期获益，或者治疗的总体负担超过了对本人的获益。
:::

数目本身不是问题。一个同时患有心力衰竭、糖尿病和慢性肾脏病的人，服用八种药物可能完全合理。问题在于未经评估的累积：不再需要的药物、随着年龄增长风险变大的药物，以及用来治疗其他药物副作用的药物。

### 老年人为何更易受损

::: theorem 低剂量起始，缓慢加量 {#thm-startlow}
由于老年人生理储备较小、药物消除较慢、对许多药物作用更敏感，相同剂量在老年人中产生的效应更大、持续更久。因此，药物应从低剂量开始，缓慢加量，并在每一步评估效果。
:::

::: proof
**药代动力学变化。**肾清除率下降，因此经肾排泄的药物和活性代谢物会蓄积（例如地高辛、锂盐、加巴喷丁、直接口服抗凝药以及吗啡的代谢物）。体脂增加、体液减少，因此脂溶性药物（如地西泮）的分布容积增大、半衰期延长，而水溶性药物达到更高的浓度。肝血流量和首过代谢可能下降。这些变化见[[geriatrics-palliative/ageing-frailty#eq-halflife]]。

**药效学变化。**衰老的大脑对镇静药、阿片类和抗胆碱能药物更敏感，因此在较低剂量时就会出现意识混乱和跌倒。压力感受器反射减慢，使降压药更易引起直立性低血压。口渴感和肾脏浓缩能力下降，使利尿剂更易引起脱水和低钠血症。抗凝药和抗血小板药的出血风险随年龄增加。

**相互作用。**可能的药物两两组合数比药物数增长得更快：$n$种药物有$n(n-1)/2$个药物对。五种药物有10个可能的药物对；十种药物有45个。并非每一对都会发生相互作用，但相互作用的机会成倍增加。
:::

### 处方级联

::: definition 处方级联 {#def-cascade}
**处方级联**是指一种药物的不良反应被误认为一种新的疾病，于是又开了第二种药物来治疗它。第二种药物可能引起更多的不良反应，级联可以继续下去。
:::

一些常见的级联：

| 第一种药物 | 不良反应 | 第二种药物 |
|---|---|---|
| 钙通道阻滞剂（氨氯地平） | 踝部水肿 | 袢利尿剂 |
| 胆碱酯酶抑制剂（多奈哌齐） | 尿失禁 | 膀胱抗毒蕈碱药（奥昔布宁） |
| 非甾体抗炎药 | 血压升高 | 降压药 |
| 甲氧氯普胺或抗精神病药 | 帕金森综合征 | 左旋多巴 |
| 噻嗪类利尿剂 | 痛风 | 别嘌醇或秋水仙碱 |
| 血管紧张素转换酶抑制剂 | 咳嗽 | 镇咳药或抗生素 |

胆碱酯酶抑制剂级联的危害尤其大：抗胆碱能的膀胱用药与治疗痴呆的药物作用相反，可能加重认知损害。

::: example 脚踝、利尿片与跌倒 {#ex-cascade}
Hannah Levi夫人81岁，因高血压开始服用氨氯地平（amlodipine）。两个月后她出现踝部肿胀，于是加用了呋塞米（furosemide）。现在她有尿急和尿失禁，两次因急着去厕所而跌倒，血钠为131 mmol/L。她坐位血压118/66 mmHg，站立时100/60 mmHg。请解释发生了什么，并提出计划。
::: solution
这是一个处方级联（[[#def-cascade]]）。氨氯地平通过扩张毛细血管前小动脉、升高毛细血管压力而引起踝部水肿。这种水肿不是由液体过多引起的，因此利尿剂对它作用不大，但呋塞米却导致了尿急、急着去厕所时跌倒、轻度低钠血症和直立性低血压。按她的年龄和衰弱程度，她目前的血压偏低。

计划：停用呋塞米（她没有心力衰竭等其他适应证；需核实这一点）。重新评估她的血压；如果仍需治疗，可以减少氨氯地平的剂量，或换用其他类别（例如血管紧张素转换酶抑制剂或血管紧张素受体阻滞剂，并监测肾功能）。调整后复查血钠和卧立位血压，评估跌倒情况，并把“氨氯地平引起踝部水肿”记录为药物不良反应，以免级联重演。
:::
:::

## 用药评估的工具 {#sec-tools}

::: definition 用药评估及其工具 {#def-tools}
**结构化用药评估**是对一个人所服用的每一种药物进行有计划、以人为本的评估，目的是就每种药物的用途、是否仍然有效且仍被需要、是否造成伤害达成一致。明确的标准可以为评估提供支持：**STOPP/START**（第3版，2023）列出了65岁及以上人群中133种潜在不当处方情形（STOPP）和57种潜在处方遗漏（START）；**美国老年医学会Beers标准**（最近一次更新于2023年）列出了老年人应避免或慎用的药物；**抗胆碱能负荷量表**按药物的抗胆碱能活性评分。
:::

明确的标准是有用的提示，但被STOPP标记的药物对某个具体的人仍可能是正确的，而START提示的遗漏对预期寿命短的人可能是错误的。评估必须从本人的目标出发。

### 抗胆碱能负荷

许多药物具有抗胆碱能活性，其中包括一些通常不被认为是抗胆碱能药的药物。它们的作用会叠加：口干、便秘、尿潴留、视物模糊、心动过速、意识混乱、谵妄和跌倒。在**抗胆碱能认知负荷（ACB）量表**中，每种药物计1分（可能有抗胆碱能作用）至3分（明确且有临床意义），各药分数相加。较高的总分与老年人的认知下降、跌倒和死亡相关；总分3分或以上通常被认为有临床意义。强抗胆碱能药物包括三环类抗抑郁药（阿米替林）、膀胱抗毒蕈碱药（奥昔布宁、托特罗定、索利那新）、镇静性抗组胺药（氯苯那敏、异丙嗪）、帕罗西汀以及某些抗精神病药。不同的已发表量表给出的分数略有差异，因此应注明所用的量表。

::: example 计算抗胆碱能负荷 {#ex-acb}
Victor Okoro先生79岁，有轻度认知障碍，睡前服用阿米替林（amitriptyline）治疗神经病理性疼痛，服用奥昔布宁（oxybutynin）治疗尿急，服用氯苯那敏（chlorphenamine）治疗瘙痒，服用呋塞米治疗心力衰竭。按以下ACB分值：阿米替林3分、奥昔布宁3分、氯苯那敏3分、呋塞米1分，计算他的总分并提出调整建议。
::: solution
ACB总分$= 3 + 3 + 3 + 1 = 10$，对一位有认知障碍的男性来说负荷非常高。调整应在征得他同意并加以监测的情况下逐项进行：停用氯苯那敏，治疗瘙痒（润肤剂，寻找原因）；对尿急，尝试膀胱训练，并考虑抗胆碱能作用很小（如血压允许，例如米拉贝隆（mirabegron））或没有抗胆碱能作用的药物；对神经病理性疼痛，考虑抗胆碱能作用较小的替代药物（例如度洛西汀（duloxetine）或加巴喷丁类，它们有各自的不良反应，加巴喷丁类还需按肾功能调整剂量）。呋塞米是心力衰竭所需，贡献很小。负荷降低后重新评估他的认知。
:::
:::

### 获益时间

每一种预防性药物都有一个**获益时间**：从开始用药到一个人可能从中获益之间的延迟。例如，用于一级预防的他汀类药物和治疗骨质疏松的药物需要数月到数年才能预防事件。当预期寿命短于获益时间时，人们承担了药物的负担和风险，却几乎没有机会从中获益。这是在衰弱者或生命末期评估预防性药物最有力的理由之一。

## 去处方 {#sec-deprescribing}

::: definition 去处方 {#def-deprescribing}
**去处方**是对可能造成伤害或已不再带来获益的药物进行有计划、有监督的减量或停用的过程，目的是管理多重用药并改善结局。它是良好处方的一部分，而不是另一项独立的活动，决定由医患共同作出。
:::

典型的去处方过程有五个步骤：

1. **列出所有药物**，包括非处方药和草药制剂，并弄清本人实际如何服用（用药重整）。
2. **评估药物伤害的总体风险**：药物数目、高风险药物、衰弱、认知和肾功能。
3. **评估每一种药物**的适应证、获益与危害，以及它在本人目标中的位置。
4. **确定优先停用的药物**：危害最大而获益最小的、最容易停用的，以及本人希望停用的。
5. **实施与监测**：尽可能一次只停一种药；对会引起撤药反应的药物逐渐减量（苯二氮䓬类、Z类药物、抗抑郁药、阿片类、加巴喷丁类、糖皮质激素、β受体阻滞剂、质子泵抑制剂）；商定需要观察什么以及何时复查。

苏格兰政府的多重用药指南（《现实处方》（*Realistic Prescribing*），第3版，2018）把类似的过程组织为七个步骤，第一步是“对患者来说什么是重要的”。NICE关于药物优化（NG5，2015）和多病共存（NG56，2016）的指南支持为多病共存并多重用药的人进行结构化用药评估；在英格兰，初级医疗为风险较高的人提供结构化用药评估，通常由临床药师完成。

::: warning 停药也可能造成伤害
去处方并不是“全部停掉”。有些药物突然停用是危险的：苯二氮䓬类（反跳性焦虑、失眠、癫痫发作）、β受体阻滞剂（反跳性心绞痛或心动过速）、糖皮质激素（肾上腺皮质功能不全）、抗癫痫药、抗帕金森病药和抗抑郁药（停药症状）。另外，有些药物在老年人中使用不足：心房颤动的抗凝药、脆性骨折后的抗骨质疏松治疗，以及充分的镇痛。良好的评估既停药，也开药。
:::

::: example 跌倒与被停掉的抗凝药 {#ex-anticoag}
Albert Novak先生84岁，患心房颤动、高血压和糖尿病，两年前有过一次轻型卒中。过去一年他跌倒过两次，均未受伤。他的全科医生“因为跌倒风险”停用了他的阿哌沙班（apixaban）。这个决定正确吗？
::: solution
很可能不正确。既往卒中、年龄、高血压和糖尿病使他每年再发卒中的风险很高，而抗凝治疗能大幅降低这一风险。跌倒确实增加出血风险，尤其是硬膜下血肿，但模型研究提示，一个接受抗凝治疗的人每年需要跌倒非常多次，跌倒带来的出血风险才会超过预防卒中的获益。因此，单纯跌倒通常不是停用抗凝药的理由。

更好的做法：(1)与他共同讨论后重新开始抗凝，并根据他的年龄、体重和肾功能（Cockcroft–Gault肌酐清除率）核对正确剂量；(2)停用不必要的抗血小板药和非甾体抗炎药并控制血压，以降低出血风险；(3)通过多因素评估治疗跌倒（[[geriatrics-palliative/falls]]）；(4)告知头部外伤的注意事项以及何时需要紧急就医。如果他在了解利弊后仍然不愿服用抗凝药，应尊重并记录他的知情选择。
:::
:::

::: example 夜间低血糖 {#ex-insulin}
Grace Thompson夫人86岁，住在照护机构，患中度痴呆，CFS 7。她每天两次服用格列齐特（gliclazide），每天一次注射基础胰岛素。她的HbA1c为48 mmol/mol（6.5%）。夜班工作人员两次发现她出汗、意识混乱，指尖血糖分别为2.8和3.1 mmol/L。她的糖尿病治疗应如何调整？
::: solution
对衰弱的老年人，糖尿病治疗的主要目的是预防低血糖和症状性高血糖，而不是实现严格的长期控制；在预期寿命较短的情况下，严格控制获益甚微，却会导致低血糖、跌倒、意识混乱和心脏事件。HbA1c为48 mmol/mol且出现低血糖，说明她治疗过度。美国糖尿病协会等的指南建议，对健康状况复杂的人放宽目标，对健康状况很差的人避免依赖HbA1c；英国的指导意见同样建议对衰弱者采用个体化的宽松目标。

计划：首先停用格列齐特（一种磺脲类药物，在肾功能减退的老年人中发生持续性低血糖的风险很高）。评估是否仍需要胰岛素：减少剂量，如果血糖保持在可接受范围，可考虑在监测下停用。与照护机构商定一个避免症状的血糖范围（例如没有低于约6 mmol/L的读数，也没有持续高到引起口渴、多尿或感染的读数）、一个监测计划，以及读数超出范围时的处理方法。评估她的肾功能和其他用药。
:::
:::

::: example “不依从”的吸入剂使用者 {#ex-adherence}
Samuel Wright先生80岁，患慢性阻塞性肺疾病，两年来因症状“控制不佳”先后被开了三种不同的吸入剂，又因不规律取药而被贴上“不依从”的标签。他双手有关节炎，并有轻度认知障碍。应该评估什么？
::: solution
**不依从**往往是非故意的。观察他使用每一种装置，评估吸入技术：关节炎的手可能按不动定量吸入器，或无法让按压与吸气协调；认知障碍会让几种不同的装置令人困惑。问他认为每种吸入剂是做什么用的，是否注意到副作用或有费用问题。

解决办法包括：统一使用一种装置、使用储雾罐或呼吸驱动装置、每日一次的方案、书面说明，以及药师或家人的帮助。不检查吸入技术就以“控制不佳”为由升级治疗，是导致多重用药的常见原因。多格分药盒不能解决吸入剂的问题，对片剂也不建议常规使用：它们适合部分人，但可能引入差错并降低灵活性，因此应在个体评估后再使用。
:::
:::

## 处方之外的体系 {#sec-system}

::: definition 照护体系中的药物优化 {#def-system}
**药物优化**是一种以人为本、安全有效地使用药物的方法，使人们从药物中获得尽可能好的结局。关键流程包括：**用药重整**（每次照护转接时都有一份准确的现用药物清单，NICE NG5建议在入院后24小时内完成）、定期的结构化用药评估、出院时清楚地说明用药改变及其理由、监测高风险药物，以及报告可疑的药物不良反应（在英国通过MHRA的黄卡计划（Yellow Card scheme））。
:::

照护转接是最危险的时刻。住院期间停用的药物可能因旧的重复处方而被误开；因临时原因开始使用的新药（例如质子泵抑制剂或安眠药）可能一用多年。一份好的出院信应说明改变了什么、为什么改变，以及应在何时复查什么。

::: quiz
一位患痴呆的85岁女性正在服用多奈哌齐，新出现了尿失禁。最恰当的处理是什么？
- [ ] 加用奥昔布宁治疗尿失禁
- [x] 考虑多奈哌齐是可能的原因，在加用任何药物之前先评估尿失禁
- [ ] 立即永久停用多奈哌齐
- [ ] 插入长期留置导尿管
::: solution
胆碱酯酶抑制剂可引起尿失禁。加用抗胆碱能的膀胱用药会启动一个与痴呆治疗作用相反、并可能加重意识混乱的处方级联（[[#def-cascade]]）。第一步是评估尿失禁（感染、尿潴留、便秘、活动能力、如厕的便利性），并考虑是否由多奈哌齐引起；然后再与她及其家属讨论任何调整。
:::
:::

## 后续内容

药代动力学和药物不良反应的一般原理见[[pharmacology/patient-variation]]和[[pharmacology/adverse-reactions]]。导致跌倒和谵妄的药物见[[geriatrics-palliative/falls]]和[[geriatrics-palliative/delirium-dementia-care]]。在生命末期，停用预防性药物成为[[geriatrics-palliative/palliative-care]]规划的一部分。

::: history
“处方级联”一词由Paula Rochon和Jerry Gurwitz于1997年在《英国医学杂志》（*BMJ*）的一篇文章中提出；2005年，Sudeep Gill等在一个大型加拿大队列中发现，开始服用胆碱酯酶抑制剂的老年痴呆患者更可能被开具膀胱抗毒蕈碱药。不当处方的明确标准始于1991年Mark Beers等的工作，最初针对美国养老院的住户；现在由美国老年医学会维护。在爱尔兰，Denis O'Mahony、Paul Gallagher等于2008年发表了STOPP/START标准，它是围绕欧洲的处方实践设计的，既包括过度用药，也包括遗漏用药。“去处方”（deprescribing）一词在21世纪头十年开始普遍使用；2015年，Ian Scott等在《美国医学会杂志·内科学》（*JAMA Internal Medicine*）上发表的文章提出了一个被广泛采用的分步方案。
:::

::: summary
- 多重用药（五种或以上药物）可以是恰当的，也可以是有问题的；目标是用对的药，而不是用最少的药。
- 老年人更易受损，原因是清除减慢、分布改变以及敏感性增加，尤其是大脑和循环系统：低剂量起始，缓慢加量。
- 当不良反应被当作新疾病治疗时，就产生了处方级联；要识别并逆转它。
- STOPP/START、Beers标准和抗胆碱能负荷量表是评估的提示，而不是规则；本人的目标优先。
- 预防性药物有获益时间；当预期寿命更短时，其价值下降。
- 一次停用一种药物，对有撤药反应的药物逐渐减量，并进行监测和复查。有些药物使用不足，需要开始使用。
- 照护转接时的用药重整和清晰沟通能防止许多差错。
:::

## 习题

::: exercise 识别处方级联 {level=1}
对每个过程，指出最初的不良反应，并提出更好的做法：(a)一位男性开始服用雷米普利（ramipril）后出现干咳，先后被开了两个疗程的抗生素和一种止咳糖浆；(b)一位女性因恶心服用甲氧氯普胺（metoclopramide）数月后，出现震颤和动作迟缓，被转诊以排除帕金森病。
::: solution
(a)血管紧张素转换酶抑制剂引起的咳嗽。停用抗生素和止咳糖浆；如果仍有适应证，把雷米普利换成血管紧张素受体阻滞剂。(b)甲氧氯普胺（一种多巴胺拮抗剂）引起的药源性帕金森综合征。停用甲氧氯普胺，寻找恶心的原因，并在数周至数月后重新评估震颤；药源性帕金森综合征可能需要一段时间才能消退。开始使用左旋多巴会使级联延续下去。
:::
:::

::: exercise 计算可能的药物对数 {level=1 check="12*11/2"}
一位女性规律服用12种药物。共有多少个不同的药物对？
::: solution
$n(n-1)/2 = 12 \times 11 / 2 = 66$对。每一对都是一个可能的相互作用（大多数不会相互作用，但软件核查和药师评估必须把它们全部考虑在内）。
:::
:::

::: exercise 抗胆碱能负荷 {level=1 check="3+1+1"}
按以下ACB分值：奥昔布宁3分、华法林1分、地高辛1分，计算一位服用奥昔布宁、华法林、地高辛和对乙酰氨基酚（0分）的男性的ACB总分。这一负荷有临床意义吗？
::: solution
总分$= 3 + 1 + 1 + 0 = 5$。总分3分或以上通常被认为有临床意义。贡献最大的是奥昔布宁，它也是最容易替换或停用的。
:::
:::

::: exercise 应用STOPP和START {level=2}
Rita Sandhu夫人78岁，患骨质疏松且有过椎体骨折，还有高血压和胃食管反流病。她服用氨氯地平、6年未经评估的奥美拉唑（omeprazole）每日40 mg、连续3年每晚服用的佐匹克隆，以及治疗背痛的布洛芬（ibuprofen）。她没有接受任何抗骨质疏松治疗。指出可能的STOPP和START问题。
::: solution
STOPP类问题：长期大剂量质子泵抑制剂未经评估（考虑减至最低有效剂量或停用，因为长期使用与骨折、艰难梭菌感染和低镁血症相关）；长期使用催眠药（佐匹克隆：跌倒、骨折、意识混乱；在睡眠建议的配合下逐渐减量）；老年高血压患者使用非甾体抗炎药（血压升高、肾脏和胃肠道损害；改用对乙酰氨基酚、外用非甾体抗炎药或物理治疗等替代方案）。START类遗漏：脆性骨折后的抗骨质疏松治疗（例如双膦酸盐，在核查肾功能、血钙、维生素D和口腔健康之后使用）。这些调整应与她讨论，并逐项实施。
:::
:::

::: exercise 苯二氮䓬类药物的减量 {level=2}
一位79岁男性每晚服用替马西泮（temazepam）已有10年。他跌倒过两次，愿意尝试停药。概述安全减量的原则。
::: solution
原则：商定计划和他的目标；解释可能出现的撤药症状（反跳性失眠、焦虑），并说明它们通常会缓解；逐渐减量，例如每二至四周减少约10–25%，如果症状明显则放慢速度（具体方案依据当地指南和BNF，长期使用者可能需要数月）；提供支持和失眠的认知行为方法（睡眠卫生、刺激控制、固定的起床时间）；避免换用另一种催眠药；定期复查。长期使用后突然停药有出现严重撤药症状（包括癫痫发作）的风险，应予避免。
:::
:::

::: exercise 换算HbA1c目标 {level=2 check="round(10*(64/10.929+2.15))/10"}
以mmol/mol（IFCC单位）表示的HbA1c，可用公式$\% = \text{mmol/mol} / 10.929 + 2.15$换算为旧的百分比单位（DCCT/NGSP）。为一位衰弱的老年女性商定了64 mmol/mol的宽松目标。这相当于多少百分比单位？保留一位小数。
::: solution
$64 / 10.929 + 2.15 = 5.856 + 2.15 = 8.006$，即**8.0%**。对于有复杂健康问题的人，ADA建议的目标大致在这一水平（低于8.0%，即64 mmol/mol）；对于健康状况很差的人，则建议完全不依赖HbA1c，而把重点放在预防低血糖和症状性高血糖上。
:::
:::

::: exercise 获益时间 {level=3 check="round(1/(0.06-0.045))"}
在一项示意性的一级预防试验中，一种药物把5年心血管事件风险从6.0%降至4.5%，头两年几乎看不到获益。计算治疗5年预防一次事件所需的治疗人数（取整）。然后讨论是否应在一位CFS 7、估计预期寿命约1至2年的89岁女性中继续使用该药。
::: solution
绝对风险降低$= 0.060 - 0.045 = 0.015$。需治疗人数$= 1/0.015 \approx 66.7$，即约**67**人治疗5年预防一次事件。对这位女性而言：她的预期生存期短于大部分获益累积所需的时间，因此她获益的机会很小，却要承担日常的负担（服药、监测）和不良反应的风险。在与她和家属讨论后停药是合理的，并解释这一改变反映的是该药现在价值有限，而不是放弃照护。这里的数字是示意性的；对真实药物，获益时间的估计来自试验数据。
:::
:::

::: exercise “他们在停她的药” {level=3}
一次用药评估后，91岁的Patricia Owen夫人停用了他汀、阿司匹林（用于一级预防）和双膦酸盐（已服用8年）。她的儿子很生气：“你们是在放弃她。”你会如何回应？是什么让这次去处方是安全的？
::: solution
首先倾听，承认他的担忧，并用浅显的语言解释理由：每一种药物都根据它现在还能为她做什么进行了评估。在她这个年龄，用于一级预防的阿司匹林获益很小，而出血风险是真实存在的。他汀的预防获益需要数年才能累积，而且她一直有肌肉酸痛。双膦酸盐治疗5到10年后进行评估是标准做法，由于药物会在骨中留存，对许多人来说“药物假期”是合理的；她的骨折风险将会重新评估。要强调哪些照护在继续：对她的症状和疾病的治疗，以及对她进行监测的计划。安全的保障在于：这一决定是与她共同作出的（如果她缺乏决策能力，则在家属参与下按她的最佳利益作出），一次只改变一项，每项停药都有记录在案的理由，有监测和复查计划，并与她的全科医生和照护团队进行了清晰的沟通。主动提出与他再谈一次，表明这次评估是积极照护的一部分。
:::
