谵妄是在一具患病身体之上、心智发生的短路；而痴呆照护是当心智的衰退是背景而不是事件时医学所做的事；在医院里、两者被一起处理得很糟的情形、多于任何单独被处理得很好的情形。**本章涵盖谵妄（机制、易感-诱发算术、被漏掉的活动减退亚型、4AT、病因搜寻、非药物的核心、及少数激越者诚实的药理学）、内科病房上的痴呆（会交流的行为、抗精神病药的证据及其路易体与卒中及死亡率警诫、随之而来的去处方）、及老年病房生活于其中的法律伦理层（能力、约束、精神能力法的机制、及每个系统都会处理不好的痴呆基础上谵妄患者）。本章的两句话：“她只是累了是谵妄的墓志铭、而痴呆中的每一个行为症状都是一个病房已停止尝试阅读语言写成的句子。**

## 谵妄

::: definition 谵妄：机制、检出与病因搜寻 {#def-delirium}
**值得一教的机制一段：一具急性患病的身体产生一个易损脑综合征——神经递质的故事（胆碱能缺陷对着多巴胺能与炎症噪声）与网络的故事（额顶与丘脑系统的注意与觉知网络一起离线）解释了临床卡片：急性起病、波动病程、注意缺损与思维紊乱或觉知改变——这就是4AT的四项与CAM的四条特征、也是为何谵妄是一个没有任何血液检验能替代的床旁诊断。应当令人震惊的流行病学：住院老年患者三分之一到一半发生谵妄（在重症监护、髋部骨折、心脏手术后更高）、四分之一以上在入院时已存在而其中多数被漏掉、且它与真正重要的结局独立相关：住院更长、功能与认知下降其中部分永不恢复、机构化、死亡；以及与痴呆的双向通道痴呆的脑谵妄容易十倍、而一次谵妄发作揭示或加速痴呆是医学中真正未定的预后问题之一。算术：谵妄=易感性×诱发性——衰弱、痴呆、失聪的高龄女性会因为一个便盆与一次髋部骨折而谵妄、而健朗的70岁者带着同样的脓毒症头脑清楚、这就是为何预防文献识别高风险入院、移除三个诱因、活动、定向、补液、戴上眼镜产生了试验级的下降而几乎不花钱、却仍是医院医学中最有名无实被实施的包裹。检出的失败模式：活动减退亚型一半以上病例、那个“安静的乖孩子”与脸上传单式的记录、在被漏掉的同时、活动过度者得到了会把一切加重的劳拉西泮、在下午茶时分来访而在晨间查房被记录为“清醒、定向四方面全”的波动、基线不明所以没人能把这个变化称为改变这就是为何家人的“她不是她自己”是一件病房应视作检验结果的诊断工具、及命名问题被写成“脓毒症”或“尿路感染”或“社会性”或“只是累了”的意识混乱——诊断在不被命名时就被漏掉、而在被命名时结局改善。作为固定套路的病因搜寻：低氧与低血压及低血糖与低钠及高钙及尿毒症及肝性脑病、及感染搜寻尿与胸及伤口及口腔及艰难拟梭菌及导管、及作为自我实现经典的那个“感染其实是导管”的导管感染、药物抗胆碱能与阿片及苯二氮䓬及激素负荷、及戒断状态——带5天规则的酒精及可乐定与巴氯芬及苯二氮䓬的反跳反应、及骤停激动剂包括帕金森药与巴氯芬、其戒断本身就是急症、潴留与嵌塞膀胱扫描与直肠指检——医学所拥有的最低技术最高收益的检验、疼痛未被治疗的疼痛会致谵妄、而定时对乙酰氨基酚是谵妄医学的证据、感觉剥夺为做扫描而摘下、再没戴上的眼镜与助听器、颅内事件当病史或体征说明时的硬膜下与卒中及癫痫及脑炎、带一句诚实的注：多数谵妄从不需要扫描、而少数需要的病例因今天就做而获益。处理就是病因清单减去诱因加上不可妥协项液体与营养及睡眠结构及活动及再定向及那个她认识的固定面孔、而抗精神病药被降级到它的证据位置：不预防、不常规、仅在因痛苦或危险时短期小剂量、带心脏与癫痫及路易体的安全检查及躯体健康监测及停止日期、因为病房的“她正在安静下来”是一个停药而不是续药的理由。**
:::

## 内科病房上的痴呆

::: definition 一般场景中的痴呆照护：行为与抗精神病药之问 {#def-dementia-care}
**前提：多数痴呆照护不是神经病学——它是在由从未大规模地困惑过与恐惧过的人设计的环境里、管理一个人剩余的交流。类型属于神经系统与精神科各章阿尔茨病与血管性与路易体及额颞叶、及其下方注明的独特谵妄药物陷阱；本章添加的是病房语法。作为句子来读的痴呆行为与心理症状：抗拒照护其实是疼痛或便秘或对水的恐惧以“她很难搞”呈现、直到有人正规检查她并开对乙酰氨基酚的尿路感染与骨折与牙痛、踱步其实是对着黑暗走廊的午后黄昏综合征、“偷窃”指控其实是对话与物体恒存感丧失、攻击其实是一个无法编辑应答的人被淹没的阈值、及退缩其实是抑郁或谵妄或悲伤、并按病可治的方式可治。真正重要的评估工具是ABC或同等工具前因-行为-后果、及一个被给予时间填写它的护士、因为痴呆行为症状的干预研究不断给出同一个答案：环境与员工培训及个体化活动规划有效、而精神药物多半无效关于痴呆症状的证据显示精神药物在群体层面对痴呆行为症状的获益小到没有、而真实世界的危害恰好集中在这个人群。诚实记录的抗精神病药台账：它们短期减少某些攻击与痛苦；它们带有脑血管事件与死亡率类别警诫来自痴呆汇总试验的小绝对风险上升、让每条指南都说“仅在有害于自己或他人时、在非药物选项之后、数周内复审”、卒中风险真实但数值上不大、而死亡率信号约为每年绝对1-2%超过安慰剂——这是她或她的代理人应用她的数字而不是传单的数字进行的一场谈话、胆碱酯酶抑制剂与美金刚的证据不大且依疾病而异、不能取代社会处方、苯二氮䓬陷阱通过加重疾病来“镇静”的去抑制与跌倒及谵妄、在膀胱与过敏及抗抑郁处方中悄悄累积的抗胆碱能负荷、及有真实成就的去处方运动美国的质量指标与英国的停用精神科多重用药运动及审计、及在同群比较反馈真实之处安老院下降的抗精神病药处方曲线——这是本章床旁信息的公共健康版本。路易体的警诫在任何属于它的地方都值得自己一句：路易体痴呆的神经阻滞剂敏感可以是灾难性的典型与某些非典型药物导致帕金森与意识严重恶化、所以那个抗精神病药初治的痴呆患者伴波动认知与视幻觉及跌倒史、就是你开药之前要核对的那个人、而帕金森精神病相关的药物问题属于专科。照护架构：有实际试验或类试验支持的痴呆友好病房特征单人间与自然的可见性及痴呆专科护士、及那个展示了每周五十小时无结构单调是什么模样的痴呆照护映射观察工具、再定向与认可而不与她无法保持的时间地点争辩、进餐时间作为干预手把手与有色餐盘及陪她坐的证据、一名员工一项任务的连续性让一个恐惧的人能重新预测世界、及照护者作为病房最少被使用的诊断与治疗资源——那个知道她历来睡在椅子里的配偶、及那位能在四十秒内平息恐慌而整个团队花一小时失败的女儿。最后是交界清单：驾驶当诊断造成损害时的驾照通报义务、披露与能力的顺序谁听到诊断以及如何听到、在伦理章覆盖、尽早的预先规划在她仍能回答时的“什么对你重要”、及保住病房收益的门诊落实社区痴呆团队与支持护士及日间服务、及照护者自身的健康、因为痴呆是一个两患者的诊断。**

## 法律与伦理机制

::: definition 能力、约束与谵妄痴呆交界 {#def-capacity}
**精神能力法的四条原则是病房的家具、不是考试的填充：能力是针对具体决定与具体时间的同一位患者有能力拒绝查血、而今晚没有能力管理胰岛素；推定能力并有支持它的义务眼镜与助听器与安静的房间与女儿及一次只问一个问题、能把许多“无能力”的记录变回有能力的决定；结论不明智不等于无能力在84岁安全地失败的权利是真实的、并在凌晨两点被反复重新争论；及最佳利益程序带其限制最少选项要求及其预先决定及其持久授权、而临床医师在行动之前必须真正去找它们。在本章病房上的应用：拔掉输液的谵妄患者（约束阶梯——重新安置与分散注意力与一对一及熟悉的面孔、及移除那条本不必在那儿的管路；及使用约束时要有一份文件、一次复审停止的约定、一个名字、及同一天告知家属；及剥夺自由保障的时代及其替代、带来医院最终必须在有意义的文书上回答的那个问题：“她不能自由离开、也无法同意留下”）；隐匿给药之问把抗精神病药放进果汁、该法直接处理了这一情形、而痴呆照护中多数伦理失败都出于好意犯了它；拒绝那根真正需要的留置针针对那个时刻那个决定的能力评估、按该法自身的语法记录——理解、保持、权衡、传达——并列明所使用的支持；及交界案例：签了安老院移居文书的早期痴呆患者究竟有无能力、波动能力患者的预先决定、及把撤除与不予的法律界线放在其法律位置（离医院传说放置的位置很远）的判例。痴呆基础上的谵妄患者完成了本章的伦理、因为她正是每个系统同时失败之处：没有人记录的基线所以谵妄未被诊断、没有人重新审视的同意因为“她从来就没有能力”成了一句病房口号、掩盖了去年有能力的拒绝与今年可治的病因、没有人规划的出院因为“她不能回到那里”带着社工的耸肩到来、而不是一个家属可以尝试的复能计划、及没有人说明的预后因为痴呆轨迹与谵妄轨迹真正纠缠在一起、而那句诚实的话——“这场病可能让她失去的功能多于归还的、这是我们会做的、这是我们会不做的”——需要一个有时间的临床医师。本章的伦理立场：可治的病因即使在重度痴呆中也要治疗胸部感染与粪嵌塞及疼痛的骨折是最佳利益问题、答案显而易见、而不可治的轨迹要早早在患者自己的话语中规划照护上限谈话与心肺复苏在疾病轨迹中的讨论、属于一个阳光下午的门诊、而不属于凌晨三点的骤停、而这两句话要一起说、因为只说其中一句的系统、正是家属与死因研讯不断描述的那个系统。**
:::

::: example 带着“激越”与一个标签的76岁患者 {#ex-dlb}

::: example 变成再入院的出院 {#ex-dsd}
一名81岁血管性痴呆患者、原本带着照护包独居、因脓毒症与谵妄住院11天；现在“医学上适合出院”、但仍需要她在之前并不需要的进餐与节制帮助；病房说“她还不能回去”；家属说“她之前很好”并拒绝入住安老院；第19天她在走廊的推车上。
::: solution
**痴呆基础上谵妄的出院陷阱（[[#def-capacity]]、[[#def-delirium]]、[[geriatrics-palliative/ageing-frailty]]）：诚实的框架——“谵妄已部分清除、而痴呆与去适应占据了一部分阵地；医学上适合出院描述的是血液、不是这个人、而还不能回去是一句伪装成预后的系统话语——功能仍可能在数周或数月内改善、而机构居留越久、能回来的就越少；这位女性需要的计划而不是一张推车——一个位置正确的临时床位中间照护或复能单元、或指明强度的家庭病床、由职业治疗主导、把入院前功能记录下来并用作基准的目标书写、带着女儿能接受的真实时数的居家复能包试用、及她现在已作为一个人认识过的社区团队关键工作者、在她之前到达的辅具、为新的能力书写的节制与营养及给药方案、及为家属的恐惧引入社区痴呆团队与支持护士——那种恐惧是正当而有传染性的；及能力与程序层——”如果她对居住决定无能力、则走最佳利益程序、征询家属、并通过真正尝试居家照护包而不是断言它行不通来检验限制最少选项、仅在康复现实的试用之后才启动安老院安置程序、并写下复审日期让还不行变成到什么时候；及系统的记账——“走廊上的19天是一个带医学标签的社会照护失败、而这个确切的模式独居者的谵妄伴残余功能丧失正是出院以评估与复能路径存在的原因、也是它们的缺席应与床位数并列放入董事会风险登记册的原因。**

::: exercise 抓住戒断性谵妄 {level=1}

::: solution
**医源性戒断性谵妄（[[#def-delirium]]）：诊断——”第3-5天的时点与自主神经体征及错认、符合苯二氮䓬戒断性谵妄、这是一个穿着精神科外衣的用药错误病例；酒精之问要用同样的方式问旁证病史永远不到场、就是这两个诊断在医院藏身的方式；规程——“以一个正规的减量方案恢复用能抑制戒断的剂量重新负荷苯二氮䓬、然后按她的神经系统设定的速度减量、在用之处采用症状触发的给药、硫胺素与电解质及黑暗安静的房间、而抗精神病药只作为谨慎的附加、因为它降低了它现在正冒险的癫痫阈值、并不治疗戒断本身；及系统修补——”把入院时的药物对账作为一个安全流程、去取安老院的给药记录、并让护士打电话而不是想当然、及全院安全警示，因为长期的苯二氮䓬与巴氯芬及可乐定及帕金森药戒断、是老年病房上反复发生的可避免伤害——这也是2020年代去处方时代的一个反讽：我们现在知道会造成入院的药、正是同一批运动正确地试图停止为新患者处方的那个药。“

::: exercise 安全地处理激越性谵妄 {level=2}

::: solution
**有理由的激越（[[#def-delirium]]）：顺序——”第一是疼痛骨折是诊断、而未充分治疗是谵妄：定时对乙酰氨基酚、神经阻滞、或真正能覆盖活动的阿片剂量并附上肠道与恶心计划、第二是移除曲马多与阿米替林的抗胆碱能与低钠及镇静贡献、及拒绝劳拉西泮之请、因为除戒断与紧张症外苯二氮䓬会加重谵妄、而矛盾性去抑制就在你说好的后面、第三是人床边的女儿、定向、窗边的椅子、眼镜、助听器、日光、一名护士一项任务、改造的厕所而不是便盆、及先给镇痛再由物理治疗师轻柔地移动那条腿；然后才是药——“如果他对他的修复或他自己仍是危险、则低剂量抗精神病药带心电图与QT及路易体筛查及癫痫与心脏病史、停止日期以天而不是周计、及当天复审疼痛方案是否起效、因为它通常已经起效。温和说出的劳拉西泮答案：那个药会把手术日的意识混乱变成一个星期——我们先修疼痛与人、把药用于这两者的失败、而不是在它们之前。”

## 通向何处

痴呆亚型及其神经病学在[[nervous-system/dementia-neurodegeneration]]、精神科鉴别在[[psychiatry/lifespan-psychiatry]]、能力法律在[[medical-ethics-law/consent-capacity]]、衰弱模型在[[geriatrics-palliative/ageing-frailty]]、去处方科学在[[geriatrics-palliative/polypharmacy]]。

::: history
**谵妄的历史是一个失而复得的故事：希波克拉底的躁狂与脑炎、17世纪作为内科病房发热症状的“谵妄”、然后是精神科对意识混乱的殖民（19世纪收容所文献、与20世纪中叶把每一位激越的老人称为“老年性意识混乱”、并用当十年的镇静剂治疗他们的习惯）——直到1970-80年代把它作为可诊断的医学综合征重新确立：诊断手册的注意缺损正式化、及波士顿团队创造了意识混乱评估方法、及1990-2000年代的纵向结局研究证明谵妄预测痴呆、机构化与死亡、且关键在于它可以被预防多成分的医院老年项目与Cochrane综述时代的包裹、以眼镜与助行器与家人相处的价格减少了三分之一的病例。检出的失败本身被作为一门科学来研究经典系列中未诊断谵妄的发生率高达一半到三分之二、活动减退亚型的隐形、及护士识别对医师识别的差距、使“问护士”成为一句临床格言。精神药理学沿着证据倒着走：出于信念为谵妄引入的抗精神病药、被一个又一个试验证明不能缩短发作或改善结局2010-2020年代的谵妄试验发现氟哌啶醇或利培酮相对于安慰剂在时长或严重度上无获益、及非典型药物自身的安全尾巴、而苯二氮䓬的作用被缩减到戒断状态与特定适应证、同时右美托咪定与褪黑素及雷美替胺的文献成熟为一场有意思的辅助之争——历史的总结是：病房学会了不再把患者摇醒、而开始移除病因。痴呆照护的历史从看管走向以人为本：1960-70年代的机构贮存批评、Maudsley的Roth与Isaacs及Blessed学派、恰当地命名了各类痴呆、并证明护理院的“老年性痴呆”常常漏掉可治的疾病与抑郁、Tom Kitwood 1990年代照护心理治疗带来的以人为本革命把“恶性社会心理学”作为机构的诊断、2000年代的痴呆照护映射审计让服务部门羞愧的“每周四十六分钟活动”这个数字、及痴呆行为与心理症状的命名、及巨大的政策时代自2009年起的国家痴呆战略与首相峰会、以及“痴呆友好”的一切、包括超市。其中抗精神病药的一章最富教益：2004-06年的类别警诫汇总试验中约1.6-1.7倍的死亡率信号与卒中风险、及随之而来的分类警告、那个从未真正完成的处方下降由委托质量与创新给付及停用精神科多重用药运动推动的英格兰安老院31%下降、及丹麦与澳大利亚登记库显示同一杠杆有效、这证明公开的处方率同群比较是一种有力的临床干预、隐匿给药与约束丑闻及其调查2012年的Winterbourne View报告与后续审查及转型照护规划——其发现在于、每个国家的记录无论挂什么旗、同一个开精神药物过量的系统都在给替代品配置人手不足、及路易体痴呆的神经阻滞剂敏感文献标准的制定与灾难性反应的病例系列——那张写着“这不是阿尔茨病”的卡片能救命。法律架构是最后的一层：2005年精神能力法及其英爱与苏格兰及英联邦表亲最佳利益对替代判断之争仍在判例文献中运行、及把“最佳利益”变成“意愿与偏好”再变回来的联合国公约解释——这就是整章哲学在慢动作中的样子。当前的前沿是预后与诚实：从谵妄到痴呆的轨迹研究、沟通试验开始测量的“接下来会发生什么”谈话、及认识到本世纪大多数痴呆患者将死于我们仍在书写其谵妄检测包裹的机构——这就是为何本章不断重复那两句话：安静的那个患者有最响的综合征、而行为就是生命体征。——[[nervous-system/dementia-neurodegeneration]]、[[medical-ethics-law/consent-capacity]]、[[psychiatry/lifespan-psychiatry]]。**
:::

::: summary
- 谵妄是易损脑的急性、波动的注意缺损综合征；它是一个床旁诊断4AT或意识混乱评估方法、在活动减退时常常被漏、并独立预测死亡、痴呆进展与机构化。
- 治疗是移除病因加包裹活动、定向、补液、眼镜与助听器、睡眠、家人、停用肇事药；抗精神病药仅用于严重痛苦或危险、带监测、停止日期与路易体的警觉。
- 预防有效多成分包裹约减少三分之一的病例、而几乎不花钱、这使它的未实施成为一个治理事实。
- 痴呆行为与心理症状就是交流：疼痛、便秘、感染、无聊与恐惧打扮成攻击；环境与员工培训干预胜过精神药物、后者的获益很小而其危害卒中、死亡率、镇静跌倒是类别性的。
- 能力是针对具体决定的并需要支持；约束与隐匿给药是带名字与复审的法律程序、不是病房习惯。
- 痴呆基础上的谵妄是对系统的压力测试：记录基线、治疗可治的、早早规划轨迹、并把真相的两半一起告诉家属。
:::

**4AT（[[#def-delirium]]）：条目——警觉正常（0）、简短精神状态检查失败或不确定（1）、倒说月份的加速试验异常2、注意条目、急性变化或波动加上夜间行为、并注意“未记录”是一个系统缺口而护士的旁证就是阳性发现2：合计5分、即“可能的谵妄——检查”4分或以上是可行动的阈值、9分以上为很可能。行动——“谵妄病因搜寻规程生命体征带氧与尿量及药物负荷及膀胱扫描及肠道及伤口及血钠与血糖、作为医嘱写下的非药物包裹、给家人打电话、及病历里的意识混乱流程图带复审时间、因为4AT的第二份工作是有序列的：恢复正常的评分就是结局、而下午茶时分上升的评分就是晨间查房漏掉的波动。**

::: exercise 对抗精神病药做决定 {level=2}
一名中度阿尔茨病的安老院住民在洗浴时打了照护者两次；该院要求喹硫平“让照护成为可能”。非药物复审：髋部活动时有疼痛、便秘、清晨7点由两名匆忙的员工洗浴、此前从未尝试改变流程。给处方者建议。
::: solution
**一张作为人员配置问题的处方（[[#def-dementia-care]]、[[#def-capacity]]）：顺序——”抗精神病药不是下一步、前因-行为-后果公式才是：打人发生在洗浴时前因、在她最僵硬髋痛与最胀满便秘的时候、配上她无法预测也无法拒绝的流程清晨7点的两个忙碌的人；干预自己会写出来：带洗浴前对乙酰氨基酚的镇痛时间表与通便、时间与人员改变一位熟悉的照护者、不匆忙的十分钟、如果那是她的清醒窗口就改为下午洗浴、毛巾与无摄像头的房间、及用她仍保留的语言提供选择、及照护者培训方法在有培训的地方护士教育者会教的认可与分散注意力及手把手洗浴法“；药物谈话——”如果在这一切之后打人仍持续而伤害迫近、一次短期而明确的抗精神病药试用是正当的、带她的精神能力法与能力程序记录在案、谁为她同意、以及什么会让我们停药——喹硫平与许可及死亡率警告及4周内复审及计划中的停止日期正是在这里真正发生；及给安老院的诚实框定：如果要求这个药是为了让清晨能照现有排班运转、我们治疗的是排班、而这场谈话我们会谈、因为那是她如果能说话自己会谈的谈话。落实——“今天处理疼痛与肠道、本周改变流程、由该院保留事件日志、及与处方者及家属在同一天的复审预约——因为这个病例的另一部历史、就是那个变成诊断的喹硫平、正是上一个案例的开篇句。**

::: exercise 进行一次能力评估 {level=2}
一名84岁在活动过度性谵妄中的急诊患者拒绝静脉抗生素治疗肺炎、并想回家“喂鸟”。记录能力的推理、以及若该拒绝站不住时的合法选项。
::: solution
**用它自己语法写的评估（[[#def-capacity]]、[[medical-ethics-law/consent-capacity]]）：针对此刻这个决定的功能测试——”她是否理解与该决定相关的信息感染、拟议的治疗、包括口服路径与回家风险在内的替代方案、保持它足够长的时间、权衡它谵妄恰恰是一台权衡机器的故障——注意缺损与波动、并传达决定；先给支持：安静的房间与女儿与眼镜、及把你的胸部感染了、输液是最快的治疗方式压缩成一句一句的版本、因为没有支持的能力评估不是该法意义上的评估“；谵妄的法律分量——”一个急性意识混乱状态通常但不总是使复杂决定的能力失效、而这里的拒绝与疾病不可分离、喂鸟的念想说明权衡并未发生：这是一个此刻未通过测试的决定、不是一个不明智但有能力的拒绝“；合法路径——”对谵妄而无能力的患者按最佳利益治疗、带紧急性分析无适当成人时的独立心理疾病倡导者、若存在则征询代理人、限制最少的选项、及真正被比较过的口服抗生素加家庭访视选项、因为那正是病房跳过的天平、如果她将被违背意愿留住则走剥夺自由的程序紧急授权路径带具名的时钟负责人与复审——这是法律要求的、而只是把她留住的病房违反了它；及本轮下班前必须存在的记录：四项能力本身的评估、尝试过的支持及其失败、决定及其理由、家属与代理人的参与、使用或未使用约束及其理由、及复审时间、因为该法文书的意义在于下一位临床医师继承的是推理、而不只是结论。**

::: exercise 设计谵妄服务 {level=3}
你的地区综合医院：普通病房不筛查谵妄、复审显示一半病例存在而被漏、抗精神病药使用是同群中位数的3倍、40%的谵妄发作从未被记录、家属报告“没人解释任何事”、而痴呆病房没有联络模型。构建这个改进规划及其测量计划。
::: solution
**作为一门服务的谵妄（[[#def-delirium]]、[[#def-dementia-care]]、[[clinical-skills/patient-safety]]）：对系统的诊断——“这家医院把意识混乱当作一项护理观察与一次精神科会诊、而不是一个带路径的医学综合征、而这三个数字漏掉的病例、处方、未记录的发作是同一个失败被数了两遍；规划——”4AT与观察表的实施、每一位护士都被培训并被授权触发复审、并带上靠近紧急医学呼叫的反射、因为筛查只有接到行动上才有效、那个作为带负责人清单的谵妄规程液体、带药师参加的谵妄日查房药物审计、膀胱与肠道时间表、按名字的责任活动、床边袋子里的感觉辅助、晚9点的睡眠保护巡视带茶与熄灯及噪音审计、加上老年精神科联络模式中每天出现在两个最差病房的那张面孔、及有时间而不只是头衔的痴呆联络护士；处方那一半——“按病房每周的抗精神病药仪表盘带同群线、及有权打电话给处方者的药师、停止日期规则最近100例入院中没有一个抗精神病药是在缺少复审日期的情况下开始的、并对每一例审计路易体核查、苯二氮䓬限于戒断与紧张症邻近的例外、及能替代一半按需呼叫的定时对乙酰氨基酚与肠道及膀胱处方、及对让镇静成为最后手段真正落地的沟通技能培训认可与一人一任务及痴呆护理技能、并配替补时数、因为技能需要的时间超过病房给过的；家属——”当天的信息传单、及那个在情绪变化时给家属打电话的具名的人、及这就是谵妄、它这样影响睡眠与食欲、而她今天不是真正认识你的谈话、这是家属评价最高而服务提供最少的那个干预；测量——“用同一方法每月审计的时点患病率、及记录率与抗精神病药率、及伤害性约束与剥夺自由转诊率、及家属调查、及每年的混合方法、因为没人投诉是现存关于痴呆照护质量最弱的证据。**
