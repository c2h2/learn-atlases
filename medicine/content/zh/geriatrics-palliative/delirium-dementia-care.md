谵妄和痴呆是老年人意识混乱最常见的两个原因，而且常常同时存在。谵妄是一种急性脑功能衰竭，通常由躯体疾病或药物引起，属于医疗急症。痴呆是一种慢性、进行性的认知下降，它改变了一个人对疾病、医院和治疗的体验。住院老年人中多达四分之一患有谵妄，患痴呆的比例与此相近；许多人两者兼有。

本章介绍如何识别谵妄、谵妄为何发生、如何预防和处理谵妄，以及如何在普通医疗环境中照护痴呆患者。最后介绍当一个人缺乏决策能力时作出决定的法律框架。引起痴呆的疾病见[[nervous-system/dementia-neurodegeneration]]。

## 谵妄 {#sec-delirium}

::: definition 谵妄 {#def-delirium}
**谵妄**是一种在数小时至数天内发生的注意和意识的急性紊乱，在一天中往往有波动，并伴有其他认知紊乱（如记忆、定向、语言或知觉）。有证据表明，它是某种躯体疾病、药物或撤药，或几种原因共同作用的直接生理后果。（此处概括的是DSM-5-TR标准；ICD-11与之相似。）
:::

注意力不集中是核心特征。谵妄患者无法保持专注：谈话时跟不上思路，不能倒背一年中的月份，很容易分心。其他特征包括思维紊乱、意识水平改变、睡眠-觉醒周期紊乱、幻觉（通常是视幻觉）、妄想，以及恐惧或易激惹等情绪改变。

谵妄有三种**运动亚型**：

- **活动亢进型谵妄**：激越、坐立不安、游走、喊叫、拉扯管线。它因为打扰他人而容易被注意到。
- **活动低下型谵妄**：嗜睡、退缩、迟缓、饮食减少。这是老年人中最常见的亚型，也是最常被漏诊的，因为患者看起来只是“安静”或“累了”。它的预后也最差。
- **混合型谵妄**：在两者之间波动。

谵妄之所以重要，是因为它常见而且危险。它与住院时间延长、跌倒、压力性损伤、新入住照护机构、痴呆患者认知下降加快以及死亡率升高相关。许多人回忆起谵妄时都觉得非常可怕。

::: theorem 谵妄源于易感性与打击的相互作用 {#thm-model}
谵妄的风险取决于两组相互作用的因素：**易感因素**（个人的易损性）和**诱发因素**（疾病过程中的打击）。高度易感的人在轻微打击后即可发生谵妄，例如新用一种镇静药或在陌生病房度过一夜；而身体强健的人则需要重大打击，如严重脓毒症或大手术。（这一模型由Inouye和Charpentier于1996年提出。）
:::

::: proof
易感因素包括高龄、痴呆或其他认知障碍、衰弱、重症疾病、视力和听力障碍以及酗酒。每一项都降低了大脑的储备（[[geriatrics-palliative/ageing-frailty#thm-threshold]]）。诱发因素随后导致脑功能衰竭的机制尚未完全阐明，但包括神经递质失衡（胆碱能不足和相对的多巴胺过剩，这解释了为什么抗胆碱能药物会引起谵妄，而多巴胺拮抗剂能减轻激越）、炎症从身体蔓延到大脑，以及缺氧、低血糖和低灌注时大脑能量供应受损。由于阈值取决于储备，最易感的患者往往有好几个小的诱因，每一个都必须找到并处理。
:::

### 病因

谵妄通常不止一个原因。查找应当系统化：

- **感染**：胸部、泌尿系统、皮肤和软组织以及其他部位。
- **药物**：抗胆碱能药物、阿片类、苯二氮䓬类和Z类药物、糖皮质激素、抗帕金森病药物以及许多其他药物；还有酒精、苯二氮䓬类或抗抑郁药的**撤药**。
- **代谢**：低钠血症、高钙血症、低血糖和高血糖、脱水、急性肾损伤、肝衰竭、甲状腺疾病。
- **缺氧和低灌注**：肺炎、心力衰竭、心肌梗死、肺栓塞、贫血。
- **脑部**：卒中、硬膜下血肿、癫痫发作（包括非惊厥性癫痫持续状态）。
- **潴留和疼痛**：尿潴留、便秘以及未经治疗的疼痛。
- **环境**：陌生环境、转换病房、睡眠剥夺、没有眼镜或助听器、身体约束和导尿管。

### 识别

如果工作人员仅凭非正式的印象，约有一半的谵妄会被漏诊。在老年人入院时以及发现变化时进行常规筛查，可以提高识别率。在英国，**4AT**被广泛使用，并为苏格兰校际指南网络（SIGN）第157号指南（2019）所推荐。它大约需要两分钟，不需要专门培训。

::: definition 4AT {#def-4at}
**4AT**包括四个项目：

1. **警觉性**：正常（0分），或明显异常，例如嗜睡或激越（4分）。
2. **AMT4**：年龄、出生日期、所在地点、当前年份：没有错误（0分），一处错误（1分），两处或以上错误或无法测试（2分）。
3. **注意力**：从十二月开始倒背月份：正确七个或以上（0分），开始了但正确不足七个或拒绝（1分），因病重、嗜睡或注意力不集中而无法测试（2分）。
4. **急性改变或病程波动**：过去两周内警觉性、认知或其他精神功能出现改变，且在过去24小时内仍然存在：否（0分），是（4分）。

总分**4分或以上**提示可能存在谵妄，伴或不伴认知障碍。1–3分提示可能存在认知障碍。0分提示谵妄或严重认知障碍的可能性不大，但如果第4项的信息不完整，仍有可能存在谵妄。
:::

在一项针对老年人研究的荟萃分析中（Tieges等，2021），4AT的合并灵敏度和特异度均约为88%。由Inouye于1990年制定的**意识模糊评估法（CAM）**是另一种选择，它要求存在急性起病和病程波动、注意力不集中，以及思维紊乱或意识改变二者之一。筛查工具是辅助手段：结果阳性时需要进行临床评估，而且从亲属或照护者那里了解患者的平常状态必不可少。

::: example “只是累了”的女士 {#ex-hypoactive}
Lin Zhou夫人82岁，三天前因跌倒导致耻骨支骨折入院。护士报告说她“一点也不麻烦”：她白天大部分时间在睡觉，吃得很少。她的儿子说，入院前她每天早上都做填字游戏。她嗜睡但可唤醒，说错了自己的年龄，但出生日期、年份和医院名称都答对了；倒背月份时说到十一月就无法继续。她正在规律服用可待因（codeine）。请计算4AT评分并概述下一步处理。
::: solution
**4AT。**警觉性：嗜睡，明显异常（4分）。AMT4：一处错误（1分）。倒背月份：开始了但正确不足七个（1分）。急性改变：儿子描述了与基线相比的明显变化（4分）。总分$4 + 1 + 1 + 4 = 10$，提示很可能为谵妄。这是**活动低下型谵妄**，很容易被误认为疲倦。

**下一步。**寻找病因（[[#thm-model]]）：可待因（便秘、尿潴留和直接镇静）、脱水和摄入不足、骨折疼痛、感染、低钠血症和其他代谢紊乱，以及缺氧。为她查体，检查膀胱容量和排便情况，并送检包括钠、钙、血糖和肾功能在内的血液检查。用耐受性更好的镇痛方案替代可待因（例如规律服用对乙酰氨基酚，仅在需要时加用小剂量阿片类，并配合缓泻剂）。鼓励进食饮水，在物理治疗协助下让她下床活动，确保她戴上眼镜和助听器，让她的儿子参与，并每天用4AT复评。告诉家属什么是谵妄，以及病因得到治疗后谵妄通常会好转，但恢复可能需要数天到数周。
:::
:::

### 预防与处理

医院中约三分之一的谵妄是可以预防的。NICE CG103指南（最近一次更新于2023年）建议在入院时评估有风险的人，并由熟悉的团队提供针对其危险因素的**多组分干预**，同时避免不必要的病房转换。

::: definition 多组分谵妄预防 {#def-prevention}
**多组分谵妄预防**针对每一个可改变的危险因素：定向（时钟、日历、向患者解释身在何处以及为什么）和认知刺激；避免脱水和便秘；评估有无缺氧；寻找并治疗感染；早期活动；评估和治疗疼痛；评估用药；良好的营养，并戴好义齿；用眼镜和助听器纠正感官障碍；以及通过减少噪音、避免夜间操作和夜间发药来促进良好睡眠。
:::

这一方法的范本是**医院老年生活项目（HELP）**。在一项纳入852名老年内科住院患者的对照试验中（Inouye等，1999），干预组有9.9%发生谵妄，常规照护组为15.0%。

已发生谵妄的**处理**包括三部分：

1. **找出并治疗病因。**这是唯一针对问题本身的治疗。
2. **支持性照护。**采用与预防相同的措施；让家属参与；尽可能在不使用约束的情况下保障患者安全；解释正在发生的事情。
3. **处理痛苦。**如果患者非常痛苦，或有伤害自己或他人的风险，而交谈和其他非药物措施无效，NICE建议使用短疗程（通常不超过一周）、最低有效剂量的氟哌啶醇（haloperidol），并按当地指南谨慎调整剂量。抗精神病药并不治疗谵妄本身，只能减轻严重的激越。对帕金森病或路易体痴呆患者必须避免使用，或只能在专科意见下使用。苯二氮䓬类可加重谵妄，仅保留用于特定情况，如酒精或苯二氮䓬类撤药，或抗精神病药禁忌时。

::: warning 镇静不是诊断
一个常见错误是给激越、意识混乱的老人使用镇静药，却不去寻找原因。镇静可以掩盖缺氧、尿潴留、疼痛或膀胱充盈，还可能把活动亢进型谵妄变成活动低下型谵妄，并导致误吸和跌倒。首先要问：这个人的身体、用药或环境发生了什么变化？
:::

## 普通医疗中的痴呆 {#sec-dementia}

::: definition 痴呆 {#def-dementia}
**痴呆**（DSM-5-TR中称为重度神经认知障碍）是一种获得性的、通常为进行性的认知下降，累及一个或多个认知领域（记忆、执行功能、语言、视空间能力、注意或社会认知），严重到影响日常活动的独立性，且不能用谵妄或其他精神障碍解释。
:::

据估计，英国有近一百万人患有痴呆，而且随着人口老龄化，这一数字还在增加。最常见的原因是阿尔茨海默病、血管性痴呆、阿尔茨海默病与血管病变的混合型、路易体痴呆和额颞叶痴呆（[[nervous-system/dementia-neurodegeneration]]）。

### 谵妄、痴呆还是抑郁？

这三者容易混淆，而且常常并存。

| | 谵妄 | 痴呆 | 抑郁 |
|---|---|---|---|
| 起病 | 急性（数小时至数天） | 隐匿（数月至数年） | 数周至数月 |
| 病程 | 波动 | 缓慢进展 | 持续情绪低落 |
| 注意力 | 受损：核心特征 | 直到晚期通常正常 | 注意力集中下降，但努力时能够集中 |
| 意识 | 常有改变 | 正常 | 正常 |
| 测试时的典型回答 | 注意力不集中、容易分心 | 努力回答但想不起来 | “我不知道”；不愿用力 |

痴呆是谵妄最强的危险因素，而谵妄又加速痴呆的进展。在谵妄发作期间不应诊断痴呆。

### 痴呆的治疗

NICE（NG97，2018）推荐**乙酰胆碱酯酶抑制剂**多奈哌齐（donepezil）、加兰他敏（galantamine）和卡巴拉汀（rivastigmine）用于轻至中度阿尔茨海默病，以及路易体痴呆和帕金森病痴呆。**美金刚**（memantine）是一种NMDA受体拮抗剂，用于中至重度阿尔茨海默病，或不能耐受胆碱酯酶抑制剂时。它们对认知和功能的获益有限；副作用包括恶心、心动过缓和晕厥（胆碱酯酶抑制剂），以及头晕和嗜睡（美金刚）。

抗淀粉样蛋白抗体仑卡奈单抗（lecanemab）和多奈单抗（donanemab）能适度延缓经淀粉样蛋白检测证实的早期阿尔茨海默病的进展。它们于2024年获得MHRA批准，但有引起脑水肿和出血的风险（淀粉样蛋白相关影像学异常），需要密切监测。2025年，NICE基于成本效果未推荐其在NHS中使用；2026年上诉获得支持后，相关评估正在重新审议。它们的地位仍在变化，阅读时应核实最新情况。

### 行为与痛苦

痴呆患者常出现行为改变，如激越、攻击、游走、叫喊、抗拒照料、淡漠或精神病性症状。这些常被称为**痴呆的行为和精神症状（BPSD）**。更有用的理解方式是：这是一个已无法用语言表达的人在传达痛苦或未被满足的需要。

::: definition 痴呆痛苦行为的处理 {#def-dementia-care}
痴呆痛苦行为的处理始于系统地查找原因，然后是非药物方法，最后才是药物。需要寻找的原因包括疼痛、便秘、尿潴留、感染、谵妄、饥饿、口渴、需要如厕、过热或过冷、听力或视力问题、恐惧、无聊、抑郁、药物副作用，以及照护的实施方式。以人为本的照护利用对这个人的了解（经历、日常习惯、喜好）来减轻痛苦。只有在其他方法无效、出现严重痛苦或伤害风险时，才考虑使用抗精神病药。
:::

痴呆患者使用抗精神病药会增加卒中和死亡的风险（汇总试验数据显示约为1.6至1.7倍，这在21世纪头十年中期引发了监管警告），而其对激越的获益很小。在英国，利培酮（risperidone）是唯一获准用于此用途的抗精神病药：用于中至重度阿尔茨海默病中存在伤害风险的持续性攻击行为的短期治疗（不超过6周）。任何抗精神病药都应从低剂量开始，定期评估其效果，不再需要时即停用。路易体痴呆患者可对抗精神病药出现严重、有时致命的敏感反应。

医院可以通过以下方式让痴呆患者的照护更安全：记录个人信息（例如阿尔茨海默病协会的“这就是我”（This is me）表格）、欢迎照护者陪伴患者（John's Campaign）、安排熟悉的工作人员、避免夜间转换病房，以及提供有意义的活动。

::: example 有“激越”和视幻觉的男士 {#ex-dlb}
Desmond Hughes先生76岁，因肺炎入院。他的妻子描述他两年来意识混乱时好时坏，看见花园里有并不存在的孩子，经常跌倒，夜里会把梦境演出来。入院第二晚他出现激越，被给予了氟哌啶醇。第二天早上他全身僵硬、嗜睡、不能吞咽。可能的基础诊断是什么？哪里出了问题？
::: solution
认知波动、反复出现的形象生动的视幻觉、快速眼动睡眠行为障碍和跌倒（现在还出现了明显的帕金森综合征）是**路易体痴呆（DLB）**的核心特征。路易体痴呆患者对抗精神病药非常敏感：氟哌啶醇可引起严重的肌强直、镇静、跌倒，以及一种类似神经阻滞剂恶性综合征的疾病，并曾与死亡相关。

出问题的地方：他妻子提供了路易体痴呆的病史，却没有被利用；对激越使用了抗精神病药，而没有先寻找原因（肺炎、缺氧、疼痛、膀胱充盈或便秘、夜间的陌生病房）。现在：停用氟哌啶醇，给予支持治疗（补液、吞咽评估、营养、检查肌酸激酶和体温），治疗肺炎，并寻求专科意见。今后出现激越时，应处理病因并采用非药物措施；如果必须用药，需要专科意见。他的病历中应明确标注对抗精神病药敏感的警示。
:::
:::

::: example “每月一次的尿路感染” {#ex-recurrent-uti}
Bridget Murphy夫人88岁，住在照护机构，患中度阿尔茨海默病。六个月里她因“尿路感染”接受了六个疗程的抗生素，每次都是在一次激越加重和尿试纸阳性之后开始的。她已经发生了两次艰难梭菌（*Clostridioides difficile*）腹泻。应如何改变她的照护？
::: solution
在65岁以上的人群中，尤其是照护机构的住户，没有感染的尿中带菌（**无症状菌尿**）很常见，因此尿试纸阳性并不能说明膀胱是她行为改变的原因。英国的指导意见建议不要用试纸诊断65岁以上人群的尿路感染；诊断依据是新出现的泌尿系统症状或体征，如排尿困难、新发的尿频或尿急、新发尿失禁、耻骨上疼痛、发热或寒战。反复不必要的抗生素已经导致了艰难梭菌感染，并有利于耐药菌的产生。

对每次激越发作更好的做法是：评估有无谵妄（4AT），寻找疼痛（例如对无法自述的人使用结构化疼痛评估工具）、便秘、尿潴留、脱水、其他感染，以及她的日常安排或照护方式的变化。与工作人员和家属商定一份照护机构计划，说明何时适合、何时不适合进行尿液检测和使用抗生素。评估她用药的抗胆碱能负荷。抗生素只保留用于有明确感染征象时。
:::
:::

::: example 变成再入院的出院 {#ex-dsd}
Pradeep Shah先生84岁，患轻度血管性痴呆，因肺炎所致谵妄入院。第5天他的病情已稳定，但夜间仍糊里糊涂，晚上7点被独自送回家，带着新药，没有安排随访。两天后他因被发现在街上游荡而再次入院。指出其中的失误，并描述一次更安全的出院。
::: solution
失误：叠加在痴呆之上的谵妄往往需要数天到数周才能缓解，而他出院时仍处于谵妄状态；晚上把他送回空无一人的家，去掉了所有的保障；没有解释或分药盒的新药很可能被错误服用；没有随访，很可能也没有与他的全科医生或家人沟通。

更安全的出院：出院前评估他的功能和认知（由作业治疗师评估他能否在家应付）；与他和家人讨论谵妄及其预期的恢复过程；考虑一段时间的中间照护或居家功能恢复服务；与药师一起规划用药（尽量少改动、清晰的用药清单、服药协助）；白天出院，家中有人；发出出院小结，把谵妄列为诊断，说明应在几周后重新评估他的认知，并请全科医生复查；给家属一个联系电话。谵妄是日后痴呆进展的危险因素，因此认知的随访本身就是必要的。
:::
:::

## 决策能力与最佳利益 {#sec-capacity}

谵妄和痴呆常常影响一个人作决定的能力。在英格兰和威尔士，《2005年精神能力法》（Mental Capacity Act 2005）提供了相关框架；苏格兰适用《2000年无行为能力成年人（苏格兰）法》（Adults with Incapacity (Scotland) Act 2000），北爱尔兰适用《2016年精神能力法（北爱尔兰）》（Mental Capacity Act (Northern Ireland) 2016）。

::: definition 决策能力（英格兰和威尔士） {#def-capacity}
根据《2005年精神能力法》，如果一个人由于心智或大脑的损害或功能紊乱而无法就某一特定事项在特定时间作出决定，即为缺乏该决定的**决策能力**。一个人如果不能做到以下一项或多项，就属于无法作出决定：**理解**与该决定相关的信息；**记住**这些信息足够长的时间以作出决定；在作决定的过程中**运用或权衡**这些信息；或以任何方式**表达**其决定。决策能力针对具体的决定和具体的时间。
:::

该法规定了五项原则：

1. 除非已确定一个人缺乏决策能力，否则必须推定其具有决策能力。
2. 除非已采取一切可行的步骤帮助其作决定而未获成功，否则不得认为其无法作出决定。
3. 不得仅因为一个人作出了不明智的决定，就认为其无法作出决定。
4. 代表缺乏决策能力者作出的决定，必须符合其**最佳利益**。
5. 在采取行动之前，应考虑能否以对其权利和自由限制更少的方式达到目的。

最佳利益决定要考虑这个人过去和现在的意愿、感受、信念和价值观，以及家属、照护者和任何持有持久授权书者的意见。有效的健康与福利**持久授权书**，或有效且适用的**预先拒绝治疗决定**，在其范围内必须遵从。对于缺乏决策能力、又没有合适的人可以咨询的人，在作出重大医疗决定或改变居住安排时，应转介给**独立精神能力倡导人**（Independent Mental Capacity Advocate）。

约束（包括身体控制、床栏以及用于控制的镇静）只有在为防止对本人造成伤害所必需且属于相称的回应时，才符合该法。如果一个缺乏同意能力的人处于持续的监督和控制之下，且不能自由离开医院或照护机构，这可能构成**剥夺自由**，必须依据《剥夺自由保障措施》（Deprivation of Liberty Safeguards）获得授权（计划中的替代方案《自由保护保障措施》（Liberty Protection Safeguards）自2023年起已被无限期推迟）。

在谵妄中，决策能力常有波动。可以等待的决定应等到患者好转后再作。

::: quiz
一位患谵妄的80岁男性想离开病房回家。他的注意力时好时坏。下列哪项说法正确？
- [ ] 他患有谵妄，因此缺乏决策能力
- [ ] 他能清楚地说出自己的意愿，因此具有决策能力
- [x] 在采取步骤帮助他作决定之后，必须用功能性测试评估他就这一决定的决策能力
- [ ] 只有在要约束他时才需要评估决策能力
::: solution
诊断并不决定决策能力。功能性测试（他能否理解、记住、运用或权衡相关信息并表达决定？）适用于此时此刻的这一具体决定，并且要在帮助他之后进行（例如选择他最清醒的时候，用简单的话解释）。如果他缺乏决策能力，就按最佳利益作出决定，并采用限制最少的方案（[[#def-capacity]]）。
:::
:::

## 后续内容

引起痴呆的疾病及其病理和诊断见[[nervous-system/dementia-neurodegeneration]]。引起谵妄的药物见[[geriatrics-palliative/polypharmacy]]。生命末期可能不可逆的谵妄在[[geriatrics-palliative/symptom-control]]和[[geriatrics-palliative/end-of-life-care]]中讨论。关于决策能力和知情同意的法律在[[medical-ethics-law]]中进一步展开。

::: history
“谵妄”（delirium）一词源于拉丁语*de lira*，意为“偏离犁沟”；希波克拉底的著作中已描述了发热时急性意识混乱的临床表现。在20世纪的大部分时间里，它有许多名称（急性意识模糊状态、中毒性精神病、ICU精神病），这阻碍了研究。1906年，Alois Alzheimer报告了Auguste Deter的病例，这位五十多岁的女性有进行性记忆丧失和行为改变，其大脑中出现了如今以他的名字命名的斑块和缠结；他的同事Emil Kraepelin于1910年在其教科书中用他的名字命名了这一疾病。1990年，Sharon Inouye等发表了意识模糊评估法，使谵妄能够在日常实践中被测量；1999年，她的团队关于医院老年生活项目的试验表明谵妄是可以预防的。在英国，Alasdair MacLullich等开发了4AT（2014年完成验证），其设计目标是让任何工作人员都能快速使用。
:::

::: summary
- 谵妄是由疾病、药物或撤药引起的注意和意识的急性、波动性紊乱。它常见、常被漏诊（尤其是活动低下型），而且危险。
- 风险取决于易感性和诱发打击；易感者只需一个小的诱因，而且通常不止一个原因。
- 用4AT筛查（4分或以上提示谵妄），经临床确认，并采集旁证病史。
- 医院中约三分之一的谵妄可通过多组分干预预防。
- 治疗病因；采用非药物照护；短期小剂量氟哌啶醇仅保留用于严重痛苦或有风险时，帕金森病和路易体痴呆患者应避免使用抗精神病药。
- 在痴呆中，痛苦行为通常提示未被满足的需要：在考虑药物之前，先寻找疼痛、便秘、谵妄和环境原因。抗精神病药增加卒中和死亡风险。
- 决策能力针对具体决定和具体时间。使用功能性测试，帮助患者作决定；如果患者缺乏决策能力，以限制最少的方式按其最佳利益行事。
:::

## 习题

::: exercise 计算4AT评分 {level=1 check="6"}
一位86岁男性意识清醒。他正确说出了自己的年龄、出生日期和医院名称，但说现在是1998年。他说出“十二月、十一月、十月、九月”后就停下了。他的女儿说他直到昨天还很好。计算他的4AT评分。
::: solution
警觉性正常：0分。AMT4：一处错误（年份），1分。倒背月份：开始了但正确不足七个，1分。急性改变：是，4分。总分$0 + 1 + 1 + 4 = 6$，达到4分或以上，提示可能存在谵妄（[[#def-4at]]）。下一步是临床评估和寻找病因。
:::
:::

::: exercise 谵妄、痴呆还是抑郁？ {level=1}
说出每个人最可能的诊断：(a)一位80岁女性，女儿反映她两年来记忆力逐渐变差、开车时迷路、忘记缴账单，测试时注意力正常；(b)一位78岁男性，开始服用一种膀胱用药后两天内变得嗜睡、跟不上谈话、不停地抓扯被单；(c)一位74岁的鳏夫说他“什么都提不起劲”，对大多数问题回答“我不知道”，妻子去世后体重下降。
::: solution
(a)痴呆：数年来隐匿起病，影响日常功能，注意力保留。(b)谵妄：急性起病、注意力不集中、意识改变，很可能由抗胆碱能药物（例如奥昔布宁（oxybutynin））引起。(c)抑郁：丧亲后出现情绪低落、淡漠、“不知道”式回答和体重下降。抑郁可以类似痴呆，应予治疗；情绪改善后再重复认知测试。
:::
:::

::: exercise 撤药性谵妄 {level=1}
一位70岁男性接受择期髋关节置换术。术后第三天，他出现激越、出汗、震颤，心率115次/分，并有视幻觉。首先应考虑什么原因？什么病史可以证实？
::: solution
酒精戒断，典型表现是末次饮酒后二至四天出现谵妄（震颤谵妄），伴震颤、出汗、心动过速和幻觉。应仔细询问饮酒史，最好经家属或全科病历证实，并询问苯二氮䓬类药物的使用情况，因为突然停用苯二氮䓬类会出现类似表现。处理遵循当地的酒精戒断方案，使用苯二氮䓬类和维生素B1（thiamine）。仍需寻找其他原因（感染、缺氧、疼痛、肺栓塞、尿潴留）。
:::
:::

::: exercise 4AT阳性的预测值 {level=2 check="round(1000*0.2*0.88/(0.2*0.88+0.8*0.12))/10"}
在一个急诊内科病房，20%的老年患者患有谵妄。4AT的灵敏度和特异度均为88%。4AT阳性的患者中，实际患有谵妄的比例是多少？以百分数表示，保留一位小数。
::: hint
设想1,000名患者，分别计算真阳性和假阳性的人数。
:::
::: solution
1,000名患者中，200人患谵妄，800人没有。真阳性：$200 \times 0.88 = 176$。假阳性：$800 \times 0.12 = 96$。阳性预测值$= 176 / (176 + 96) = 176/272 = 0.647$，即**64.7%**。约三分之一的筛查阳性是假阳性（其中许多是患痴呆但无谵妄的人），因此4AT阳性后必须进行临床评估。阴性预测值很高（约97%），所以只要关于急性改变的信息完整，筛查阴性是令人放心的。
:::
:::

::: exercise 预防谵妄的需治疗人数 {level=2 check="round(1/(0.150-0.099))"}
在HELP试验中，接受常规照护的患者有15.0%发生谵妄，接受干预者有9.9%。计算绝对风险降低，以及预防一例谵妄所需的治疗人数（取整）。
::: solution
绝对风险降低$= 0.150 - 0.099 = 0.051$（5.1个百分点）。需治疗人数$= 1/0.051 \approx 19.6$，即约**20**。相对风险降低为$0.051 / 0.150 = 34\%$。该干预主要投入的是志愿者和工作人员的时间（定向、活动、睡眠、补水、眼镜和助听器），几乎没有危害，因此需治疗人数为20是非常有利的。
:::
:::

::: exercise 评估照护机构中的抗精神病药 {level=2}
Ellen Baxter夫人89岁，患重度阿尔茨海默病，已服用利培酮14个月。利培酮是在她住院期间因谵妄并打工作人员而开始使用的。她现在很平静，白天大部分时间在睡觉，已经跌倒两次。应该怎么办？
::: solution
利培酮仅获准用于阿尔茨海默病持续性攻击行为的短期治疗（不超过6周），而当初的适应证（谵妄期间的激越）已经消失。它增加了她卒中、死亡、跌倒和镇静的风险。计划：与她的家属和照护机构讨论后，逐渐减量并停用利培酮，同时监测痛苦是否复现。针对可能的复发制定以人为本的计划（寻找疼痛、便秘、感染和环境诱因；采用非药物方法）。评估她的其他用药和跌倒情况。记录这一决定和复查日期。
:::
:::

::: exercise 评估出院决定的决策能力 {level=3}
Agnes Wright夫人87岁，患中度痴呆，因跌倒入院后想回家。她独居，今年已跌倒四次。团队认为照护机构会更安全。描述你会如何评估她就这一决定的决策能力，以及她有决策能力和缺乏决策能力时分别会怎样。
::: solution
决策能力评估：一开始推定她有决策能力。确定相关信息：各种选择（有支持地回家、无支持地回家、照护机构）、每种选择的主要风险（跌倒、长时间倒地、无法管理用药或饮食），以及可获得的支持。帮助她作决定：安静的房间、她状态最好的时段、简单的语言，或许可以与作业治疗师一起去她家看看，让她展示自己如何应付。然后测试她能否理解、记住、运用和权衡这些信息，并表达选择。“运用和权衡”是痴呆中最常受影响的部分：她是否认识到自己的跌倒及其后果，并能把它们与家对她的意义进行权衡？记录所提的问题和她的回答。

如果她有决策能力：即使团队认为她回家的选择不明智，也必须尊重。团队的任务是降低风险：护理员、呼叫挂坠、居家改造、跌倒预防项目、用药评估。如果她缺乏决策能力：最佳利益决定要考虑她的意愿和价值观（她想住在家里）、家属和任何受托人的意见，以及限制最少的方案。在有充分照护支持的情况下先尝试回家，往往是正确的第一步。如果没有家人或朋友可以咨询，在涉及改变居住安排的决定中必须有独立精神能力倡导人参与。
:::
:::

::: exercise 与早期痴呆患者一起提前规划 {level=3}
Joseph Mbeki先生72岁，刚被诊断为阿尔茨海默病。他有决策能力，与妻子同住。概述未来一年中应向他提供的预先规划谈话，以及时机为何重要。
::: solution
时机之所以重要，是因为对复杂事项的决策能力会下降，而早期进行的谈话能让他自己作决定。话题包括：(1)对他最重要的是什么、他想怎样生活，记录在预先声明中；(2)趁他还能理解时，办理财产和财务事务以及健康和福利两方面的持久授权书；(3)将来是否有他想拒绝的治疗（预先拒绝治疗决定，必须书面、签名并有见证人，如果拒绝的是维持生命的治疗，还必须声明即使危及生命也适用）；(4)驾驶：他必须告知驾照管理机构和保险公司；(5)工作、财务和遗嘱；(6)未来的照护意愿，包括希望在哪里接受照护，以及之后对住院、人工喂养和心肺复苏的看法；(7)为作为照护者的妻子提供支持，包括照护者评估。随着情况变化应重新讨论，并把文件与他的全科医生共享，以便在紧急情况下可以获取。
:::
