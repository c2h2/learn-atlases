衰老不是疾病，但它改变了每一种疾病的表现和每一种治疗的作用方式。一位85岁的肺炎患者可能既不发热也不咳嗽，只是新出现意识混乱并跌倒了一次。适合40岁成人的药物剂量，在老年人体内可能蓄积数日。卧床一周可能让人失去一个月的独立生活能力。老年医学就是围绕这些事实建立起来的专科。

本章介绍衰老的生物学和生理储备的概念、称为衰弱的临床状态及其测量方法、肌少症与营养不良，以及本专科的核心方法——老年综合评估（comprehensive geriatric assessment，CGA）。后续各章将把这些概念应用于跌倒（[[geriatrics-palliative/falls]]）、谵妄（[[geriatrics-palliative/delirium-dementia-care]]）和处方（[[geriatrics-palliative/polypharmacy]]）。

## 衰老的生物学 {#sec-biology}

### 为什么年龄越大越容易出问题

生物学家把衰老描述为机体无法再完全修复的分子和细胞损伤的逐渐累积。一个被广泛引用的框架是“衰老的标志”（López-Otín等，2013年首次发表，2023年更新），它把相关过程归为几类：DNA损伤和端粒缩短、基因调控的改变（表观遗传漂移）、蛋白质质量控制失效、线粒体功能障碍、细胞衰老、干细胞耗竭，以及细胞间通讯的改变，其中包括有时被称为“炎性衰老”的低度慢性炎症。

对临床医生来说，更有用的概括要简单得多。直到高龄，各器官在静息状态下仍能正常工作，但静息功能与其最大能力之间的余量在缩小。这个余量就是**生理储备**。

::: definition 生理储备与稳态狭窄 {#def-biology}
**生理储备**是指一个器官系统的正常工作水平与其在应激下所能达到的最大水平之间的差值。**稳态狭窄**（homeostenosis）是指这一储备随年龄增长而逐渐缩小，以致较小的应激就足以使系统越过失代偿点而出现症状。
:::

几乎每个系统的储备都会下降。以下几个例子在床旁尤为重要：

- **心脏与循环。**心室变得僵硬，最大心率下降（粗略估计约为220减去年龄），压力感受器反射变慢。老年人对脱水、失血和降压药的耐受性较差，更容易发生直立性低血压。
- **肾脏。**肾小球滤过率（GFR）往往随年龄下降，但血清肌酐常保持“正常”，因为肌酐的来源——肌肉量——也在减少。一位瘦小的老年女性，肌酐正常却可能掩盖着仅30 mL/min的GFR。
- **大脑。**认知储备下降，在任何急性疾病、药物调整或转到陌生环境时，大脑都容易发生谵妄。
- **肌肉与骨骼。**肌肉量和肌力从中年开始下降（见[[#def-sarcopenia]]）；骨密度下降，女性绝经后尤为明显。
- **体温调节、口渴与免疫。**老年人口渴感减弱，脓毒症时可能不发热，对某些疫苗的应答也较弱。

::: theorem 阈值原则 {#thm-threshold}
当作用于某一系统的应激超过该系统剩余的储备时，临床问题就会出现。老年人的储备较小，因此：(1)轻微的应激可以导致严重的功能衰竭；(2)发生衰竭的往往不是受到直接打击的系统，而是储备最少的系统；(3)几个单独都不足以越过阈值的小缺陷，叠加后可以越过阈值。
:::

::: proof
把大脑看作一个储备随年龄和既有痴呆而下降的系统。尿路感染会引起发热、脱水、睡眠不足和炎症细胞因子释放。对30岁的人来说，这些应激远在大脑的储备范围之内，所以症状只来自膀胱。对一位患轻度痴呆的88岁老人来说，同样的应激超过了剩余的储备，大脑首先衰竭：临床表现是谵妄，而膀胱症状轻微甚至缺如。同样的道理也解释了为什么跌倒可能是肺炎的首发表现（平衡和肌肉的储备最少），以及为什么几个单独都能耐受的轻度问题（白内障、轻度周围神经病变、新加的一片降压药）叠加起来会导致跌倒。
:::

这一原则解释了**老年综合征**：跌倒、谵妄、尿失禁、活动障碍和压力性损伤。每一种都是多种促成因素的最终共同通路。这就是为什么教科书中“寻找单一诊断”的经典建议在老年人中常常行不通。老年医学的做法是列出每一个促成因素，并尽可能多地加以纠正。

### 不典型表现

由于最薄弱的系统最先衰竭，老年人常以非特异性的功能下降就诊：“腿没劲了”“不像她自己了”、意识混乱、跌倒、进食差或新出现的尿失禁。这些表现有时被轻率地称为“应对不能”（acopia）或“社会性入院”。这两个标签都应避免。它们描述的是患者应对失败，而更有用的问题是：是什么新的疾病把患者推过了她的阈值？

::: warning “社会性入院”是排除性诊断
一个常见错误是认为一位“在家里应付不过来”的老人没有医学问题。脓毒症、无胸痛的心肌梗死、低钠血症、高钙血症、药物中毒、尿潴留、便秘和硬膜下血肿都可以这样表现。功能的突然丧失总是有原因的，而向亲属或照护者了解改变了什么、何时改变，是找到原因的第一步。
:::

### 衰老与药物

衰老既改变机体对药物的处置（药代动力学），也改变药物对机体的作用（药效学）。这些变化在[[geriatrics-palliative/polypharmacy]]和[[pharmacology/patient-variation]]中有完整介绍，但有两点现在就值得了解。

第一，身体组成发生变化：脂肪比例上升，总体液量下降。因此，地西泮（diazepam）等脂溶性药物的分布容积增大，而地高辛（digoxin）或锂盐等水溶性药物在相同剂量下达到更高的浓度。第二，肾清除率下降。消除半衰期同时取决于这两者：

$$
t_{1/2} = \frac{0.693 \times V_d}{CL}
$$ {#eq-halflife}

其中$V_d$为分布容积，$CL$为清除率。$V_d$增大和$CL$减小都会延长半衰期，而且两者的效应相乘。

对于经肾清除的药物，英国国家处方集（BNF）和药品生产商通常以**Cockcroft–Gault公式**估算的肌酐清除率给出剂量调整建议，该公式包含年龄和体重。血清肌酐以µmol/L为单位时：

$$
\text{CrCl (mL/min)} = \frac{(140 - \text{年龄}) \times \text{体重 (kg)} \times F}{\text{血清肌酐 } (\mu\text{mol/L})}
$$ {#eq-cg}

男性$F = 1.23$，女性$F = 1.04$。实验室报告的eGFR（英国采用CKD-EPI公式计算）已按1.73 m²体表面积标准化，不包含体重，因此对瘦小的老年人可能高估与药物剂量相关的清除率。英国的指导意见（英国药品和保健品管理局MHRA及BNF）建议：对治疗窗窄的药物、体重处于极端的人群以及直接口服抗凝药，使用按实际体重计算的Cockcroft–Gault公式。

::: example 肌酐“正常”的88岁患者 {#ex-renal}
Edith Clarke夫人88岁，体重48 kg，因胸部感染和新发心房颤动入院。她的血清肌酐为90 µmol/L，在实验室参考范围内，实验室报告的eGFR约为50 mL/min/1.73 m²。一位低年资医生准备开始抗凝治疗，询问是否需要考虑肾功能。请估算她的肌酐清除率。
::: solution
按[[#eq-cg]]计算，女性取$F = 1.04$：

$$
\text{CrCl} = \frac{(140 - 88) \times 48 \times 1.04}{90} = \frac{2595.8}{90} \approx 28.8 \text{ mL/min}
$$

她的肌酐清除率约为29 mL/min，远低于“正常”肌酐和eGFR所提示的水平。肌酐看起来正常，是因为她产生肌酐的肌肉很少。许多药物的剂量阈值在30或50 mL/min附近（包括直接口服抗凝药、某些抗生素、加巴喷丁类药物和二甲双胍），因此按eGFR选择的剂量可能是错误的。处方者应查阅现行BNF或药品说明书，在指南要求时采用Cockcroft–Gault值，并在急性疾病期间复查肾功能，因为它可能迅速变化。
:::
:::

## 衰弱 {#sec-frailty}

大多数80岁以上的人并不衰弱，而有些60多岁的人却已衰弱。单凭年龄很难判断一个人能否耐受疾病或治疗。衰弱这一概念正是用来刻画这种差别的。

::: definition 衰弱 {#def-frailty}
**衰弱**是一种可在临床上识别的易损性增高状态，源于多个生理系统与年龄相关的储备和功能下降，使机体应对日常或急性应激的能力受损。与同龄的非衰弱者相比，衰弱者在遭遇同样的疾病或治疗后，发生跌倒、谵妄、失能、住院、入住照护机构和死亡的风险更高。
:::

研究和实践中有两种主要模型。

**衰弱表型**（Fried等，2001年，基于心血管健康研究）用五项标准定义衰弱：

1. 非意愿性体重下降（过去一年约4.5 kg或体重的5%）；
2. 自述疲乏；
3. 握力下降；
4. 步速减慢；
5. 体力活动少。

符合三项或以上为衰弱；符合一至两项为**衰弱前期**。表型模型把衰弱看作一种以能量低下和肌肉衰竭为特征的特定综合征。

**缺陷累积模型**（Rockwood和Mitnitski）把衰弱看作一个人所具有的健康缺陷占可能缺陷的比例。**衰弱指数**的计算方法是统计缺陷（症状、体征、疾病、失能、检查异常）的数目，再除以纳入考虑的缺陷总数：

$$
\text{衰弱指数} = \frac{\text{存在的缺陷数}}{\text{纳入考虑的缺陷数}}
$$ {#eq-fi}

该指数是介于0与1之间的连续数值。它随年龄上升，而在任何年龄，指数越高，死亡和失能的风险越高。在英格兰，全科医疗系统根据初级医疗记录中编码的36项缺陷计算**电子衰弱指数（eFI）**。最初的eFI分为四档：健康（0–0.12）、轻度衰弱（>0.12–0.24）、中度衰弱（>0.24–0.36）和重度衰弱（>0.36）。改进版eFI2按各项缺陷对结局的预测强度进行加权，已经开发完成并正在推广；无论哪个版本，电子评分都是提示进行临床评估的信号，而不是诊断。

### 临床衰弱量表

床旁最常用的工具是**临床衰弱量表（CFS）**，由Rockwood等制定，2020年修订为2.0版。临床医生根据病史作出判断，对患者在本次疾病之前约两周的状态进行分级：

| CFS | 描述（概要） |
|---|---|
| 1 | 非常健壮：强健、活跃、精力充沛 |
| 2 | 健康：无活动性疾病症状，但不如第1级健壮 |
| 3 | 维持良好：疾病控制良好，除步行外不常规锻炼 |
| 4 | 极轻度衰弱：不依赖他人，但症状限制活动；“变慢了” |
| 5 | 轻度衰弱：在较高层次的活动（理财、出行、繁重家务）上需要帮助 |
| 6 | 中度衰弱：外出活动和料理家务需要帮助；洗澡可能需要帮助 |
| 7 | 重度衰弱：个人生活照料完全依赖他人，但病情稳定 |
| 8 | 极重度衰弱：完全依赖他人，接近生命终点 |
| 9 | 终末期疾病：预期寿命不足约6个月，但除此之外并无明显衰弱 |

CFS在65岁及以上人群中验证。对于较年轻的人或有稳定单一残疾的人（例如学习障碍或脊髓损伤），不应单独使用该量表，因为它衡量的将是残疾而不是衰弱。

::: example 根据病史评定衰弱等级 {#ex-ftt}
Kwame Mensah先生78岁，以“生长停滞”（failure to thrive）入院。他的女儿说，两周前他独居，能自己洗漱穿衣，拄拐步行去街角商店；但大约一年前，因为他“很容易累”，女儿接手了他的购物、银行事务和繁重的清洁工作。过去十天他吃得很少，一直坐在椅子上，上厕所需要帮助。他的临床衰弱量表评分是多少？评分的时间点为什么重要？
::: solution
CFS依据的是本次急性疾病前约两周的基线状态，而不是今天的状态。基线时他个人生活能自理，但在较高层次的活动（购物、理财、繁重家务）上需要帮助，即**CFS 5，轻度衰弱**。

如果按今天的状态评分（如厕依赖他人、整天坐在椅子上），他看起来是CFS 7。这会错误地提示一种长期的重度依赖，并可能导致治疗不够积极。这十天的功能下降是一个需要找出原因的新问题：感染、脱水、便秘、抑郁、药物调整，或潜在的癌症。称之为“生长停滞”只是给症状命名，并没有解释它。正确的记录应写明基线CFS 5，以及正在查找原因的急性功能下降。
:::
:::

### 衰弱评分的用途

衰弱评分只有在改变下一步做法时才有用。恰当的用途包括：提示进行老年综合评估，为共同讨论手术或化疗的风险提供信息，有针对性地开展跌倒或用药评估，以及开启关于未来照护的谈话。衰弱也有一定的可逆性，尤其是较轻的衰弱：运动、营养和治疗相关疾病可以让一个人的等级下降。

衰弱评分绝不能单独用来拒绝治疗。CFS能预测群体的结局，却无法判断某一位84岁的患者能否从重症监护中获益。这一判断需要完整的临床情况和患者本人的目标。在新冠疫情期间，NICE曾在其重症监护指南中短暂推荐使用CFS，随后因担心其被不公平地应用，在几天内修订指南，指出它不应用于较年轻者、有稳定长期残疾者、学习障碍者或孤独症患者。

::: quiz
某衰弱指数由36项可能的缺陷计算。一位79岁女性有9项缺陷记录在案。下列哪项说法正确？
- [ ] 她的衰弱指数为9，属于很高
- [x] 她的衰弱指数为0.25，属于原始eFI的中度衰弱档
- [ ] 不知道她的年龄就无法解释该指数
- [ ] 指数0.25表示她今年有25%的死亡概率
::: solution
指数为9/36 = 0.25（[[#eq-fi]]）。在原始eFI分档中，“>0.24–0.36”为中度衰弱。该指数是缺陷所占的比例，不是死亡概率；在任何年龄其解释方式相同（尽管老年人往往数值较高）。
:::
:::

## 肌少症、营养不良与活动障碍 {#sec-sarcopenia}

::: definition 肌少症 {#def-sarcopenia}
**肌少症**是一种进行性、全身性的骨骼肌疾病，表现为肌力和肌肉量的加速丧失。欧洲老年人肌少症工作组（EWGSOP2，2019）的定义是：肌力低下（例如握力低或反复起坐测试缓慢）为**可能的肌少症**；同时证实肌肉数量或质量下降为**确诊的肌少症**；若还存在躯体功能差（例如步速慢）则为**严重肌少症**。
:::

肌力比肌肉量更重要。腿部无力使人难以从椅子上站起、上楼梯或在绊倒时恢复平衡，这把肌少症与跌倒、骨折和丧失独立直接联系起来。肌少症与衰弱有重叠但并不相同：肌少症是肌肉的疾病，而衰弱是一种常常包含肌少症的多系统状态。

**营养不良**在居家老年人中常见，在住院老年人中非常常见。原因包括食欲差、牙齿问题、吞咽困难、抑郁、痴呆、贫困、孤独，以及使能量需求增加的疾病。在英国，营养不良通用筛查工具（MUST）综合了体重指数、非计划性体重下降和急性疾病对进食的影响。老年人每千克体重通常需要比年轻人更多的蛋白质来维持肌肉；PROT-AGE研究组（2013）和欧洲临床营养与代谢学会（ESPEN）等专家组建议，健康老年人每天至少摄入1.0–1.2 g/kg蛋白质，患病时更多，除非肾脏疾病限制了摄入。

**活动障碍**本身也有危害。卧床会使老年人肌力迅速丧失，同时伴随直立性低血压、压力性损伤、便秘、尿潴留、静脉血栓栓塞和信心丧失。许多医院现在开展让患者在住院的每一天都起床、穿衣和活动的项目，因为住院期间的“去适应”可以把一个独立生活的人变成依赖他人的人。

## 老年综合评估 {#sec-cga}

::: definition 老年综合评估 {#def-cga}
**老年综合评估（CGA）**是一个多维度、跨学科的诊断过程，用以识别衰弱老年人在医疗、心理、功能和社会方面的需求，并随后制定和实施一个协调、整合的治疗与随访计划。计划及其由团队执行是定义的组成部分：只有评估而没有计划的不是CGA。
:::

CGA的领域通常归纳如下。

| 领域 | 典型内容 |
|---|---|
| 医疗 | 问题清单（包括未诊断的问题）；用药评估；营养；排尿排便控制；视力和听力；口腔健康 |
| 心理健康 | 认知（例如用4AT筛查谵妄，排除谵妄后进行认知筛查）、情绪、焦虑 |
| 功能 | 基本日常生活活动（洗漱、穿衣、如厕、转移、进食）和工具性日常生活活动（购物、做饭、理财、服药）；步态与平衡 |
| 社会 | 居住状况、照护者及其负担、经济状况、支持服务、对本人重要的事 |
| 环境 | 住宅布局与危险因素、交通和社区资源的可及性 |
| 未来规划 | 目标、意愿、预立医疗照护计划、持久授权书 |

团队通常包括医生、护士、物理治疗师、作业治疗师、药师和社会工作者，必要时还有营养师、言语和语言治疗师及精神科医生。CGA的力量来自把这些视角汇聚在一起：物理治疗师注意到患者不借助手臂就站不起来，药师发现了两种抗胆碱能药物，社会工作者了解到她的丈夫——她的照护者——自己也身体欠佳。

::: theorem CGA改善衰弱老年住院患者的结局 {#thm-cga}
一项随机试验的Cochrane系统评价（Ellis等，2017）发现，与常规照护相比，急诊入院并接受CGA的老年人在3–12个月后仍然存活并住在自己家中的可能性更大（风险比约1.06），入住照护机构的可能性更小（风险比约0.80）。当CGA由专科团队在专门病房实施时，获益最为明确。
:::

::: proof
CGA之所以有效，是因为衰弱者的问题相互作用。只治疗肺炎，会让患者虚弱、意识混乱并用药过多。一个团队如果同时治疗谵妄、每天让她走动、停用导致直立性低血压的药物、解决营养问题，并与家人一起规划出院，就处理了她可能丧失独立的那些原因。对单一结局而言，效应量不大，但它适用于一个庞大且不断增长的人群，而且这一结局（“存活并住在家中”）正是大多数老年人认为最重要的。
:::

::: example 并不简单的“单纯尿路感染” {#ex-uti}
Rosa Bianchi夫人84岁，被发现倒在家中地板上后由救护车送来。她意识混乱，尿试纸检测显示白细胞和亚硝酸盐阳性。入院记录写着“尿路感染，开始抗生素，好转后出院”。她独居，患有高血压和骨关节炎，服用氨氯地平（amlodipine）、苄氟噻嗪（bendroflumethiazide）、每日四次的复方可待因对乙酰氨基酚（co-codamol 30/500），以及睡前服用的佐匹克隆（zopiclone）。请运用阈值原则，找出还必须评估哪些问题。
::: solution
在老年女性中，尿试纸阳性在没有感染时也很常见（无症状菌尿），英国的指导意见（英国卫生安全局UKHSA和NICE）建议不要用试纸诊断65岁以上人群的尿路感染。因此第一个问题是到底有没有尿路感染。要寻找泌尿系统症状、发热、炎症指标升高和其他感染灶；如果仍怀疑感染，应送尿培养。

阈值原则（[[#thm-threshold]]）提示有几个缺陷叠加在一起。需要评估的清单：

- **谵妄。**意识混乱伴跌倒提示谵妄；用4AT筛查，并寻找每一个诱因（[[geriatrics-palliative/delirium-dementia-care]]）。
- **跌倒。**她在地上躺了多久？检查肌酸激酶和肾功能（横纹肌溶解、急性肾损伤）、体温（低体温）、受压部位和外伤。
- **药物。**可待因可引起便秘、尿潴留和意识混乱；佐匹克隆导致镇静和跌倒；噻嗪类可能引起低钠血症，并与氨氯地平共同导致直立性低血压。检查血钠和卧立位血压。
- **膀胱与肠道。**检查有无尿潴留（膀胱扫描）和便秘。
- **功能与居家情况。**她之前是怎样生活的？现在谁能帮忙？

于是计划就成了一次CGA：治疗任何已证实的感染，纠正诱因，评估用药，早期活动，并与团队一起规划出院。
:::
:::

::: example 髋部骨折之后 {#ex-hip}
Harold Price先生76岁，在家中跌倒导致左股骨颈骨折。他患有帕金森病、2型糖尿病和轻度认知障碍，每天五次定时服用卡比多巴-左旋多巴（co-careldopa）。请概述良好的老年骨科照护的要素。
::: solution
在英国，髋部骨折由骨科医生和老年骨科医生共同管理（NICE CG124；结局由国家髋部骨折数据库进行审计）。关键要素如下：

1. **在入院当天或次日手术**，在不造成不必要延误的前提下优化可逆的问题。术前用神经阻滞（例如髂筋膜阻滞）和规律镇痛控制疼痛。
2. **按时服用帕金森病药物。**漏服左旋多巴可引起严重的肌强直、吞咽困难，少数情况下出现一种类似神经阻滞剂恶性综合征的危险状态。如果他不能吞咽，需要专科意见选择替代方案（例如罗替高汀（rotigotine）贴剂）。必须避免使用甲氧氯普胺（metoclopramide）等多巴胺阻断类止吐药和大多数抗精神病药。
3. **预防谵妄**，因为他的认知障碍和手术使谵妄很可能发生。
4. **术后第一天即下床活动**，除非有明确的禁忌，并且每天接受物理治疗。
5. **骨骼健康与跌倒。**骨折后开始抗骨质疏松治疗（见[[endocrine/bone-calcium]]），并评估他为何跌倒（[[geriatrics-palliative/falls]]）：帕金森病或其治疗引起的直立性低血压很可能是促成因素。
6. 把**营养、压力性损伤护理、血糖控制和出院规划**纳入CGA。

髋部骨折的死亡率很高：大约四分之一的患者在一年内死亡，主要死于那些使跌倒和骨折容易发生的衰弱和疾病。这就是为什么老年骨科模式治疗的是整个人，而不只是髋部。
:::
:::

## 后续内容

储备背后的生理学见[[physiology/integrative-physiology]]，年龄相关的药理学见[[pharmacology/patient-variation]]。在本课程中，衰弱和CGA是[[geriatrics-palliative/falls]]、[[geriatrics-palliative/delirium-dementia-care]]和[[geriatrics-palliative/polypharmacy]]的基础，而衰弱往往也是通向[[geriatrics-palliative/palliative-care]]的疾病轨迹。

::: history
在20世纪以前，大多数无法独立生活的老人在济贫院的病房中度过余生，几乎得不到医疗照顾。1909年，纽约医生Ignatz Nascher创造了“geriatrics”（老年医学）一词，主张老年应当有自己的医学。现代老年医学专科于1935年在英国起步：这一年，Marjory Warren接管了西米德尔塞克斯医院的慢性病房。她逐一评估了数百名“慢性病人”，治疗他们的疾病，让他们下床并进行康复，使许多被认为需要终身照护的人得以出院。她的评估、分类、康复和专门团队的方法，正是老年综合评估的直接前身。1963年，Sidney Katz等发表了日常生活活动指数，为临床医生提供了记录功能的标准方法。衰弱的测量在世纪之交随之而来：Kenneth Rockwood和Arnold Mitnitski的缺陷累积指数（2001）、Linda Fried的衰弱表型（2001），以及2005年的临床衰弱量表。
:::

::: summary
- 衰老使生理储备变窄（稳态狭窄）。当应激超过剩余储备时疾病就会显现，因此最薄弱的系统往往最先衰竭，表现常不典型。
- 老年综合征（跌倒、谵妄、活动障碍、尿失禁）有多种促成因素；做法是尽可能多地找出并纠正它们。
- 在瘦小的老年人中，“正常”的肌酐可能掩盖低清除率；在药物指南要求时使用Cockcroft–Gault公式。
- 衰弱是一种易损性增高的状态。表型模型计数五项特征；衰弱指数是存在缺陷的比例。临床衰弱量表评定的是疾病前两周的基线功能。
- 衰弱评分用于提示评估和支持共同决策，绝不能取代个体化判断。
- 肌少症（肌力和肌肉量低下）和营养不良很常见，与跌倒和依赖相关，并且部分可逆。
- 老年综合评估是以计划为终点的团队过程；对衰弱的老年住院患者，它提高了存活并住在家中的机会。
:::

## 习题

::: exercise 计算衰弱指数 {level=1 check="round(100*11/36)/100"}
一位82岁男性的全科医疗记录中，列出了原始电子衰弱指数所用36项缺陷中的11项。计算他的衰弱指数（保留2位小数），并指出他属于哪一档。
::: hint
用存在的缺陷数除以纳入考虑的缺陷数（[[#eq-fi]]）。
:::
::: solution
衰弱指数$= 11/36 = 0.3056$，保留2位小数为**0.31**。它大于0.24且不大于0.36，属于原始eFI的**中度衰弱**档。该评分提示需要对他进行临床评估（例如使用临床衰弱量表，并评估跌倒风险和用药），而不是诊断。
:::
:::

::: exercise 男性的肌酐清除率 {level=1 check="round((140-79)*82*1.23/110)"}
一位79岁男性，体重82 kg，血清肌酐110 µmol/L。用Cockcroft–Gault公式估算他的肌酐清除率，结果取整到mL/min。
::: solution
$$
\text{CrCl} = \frac{(140 - 79) \times 82 \times 1.23}{110} = \frac{6152.5}{110} \approx 55.9
$$
他的肌酐清除率约为**56 mL/min**。男性系数为1.23，是因为肌酐以µmol/L报告。对较重的男性，结果高于肌酐相同的瘦小女性，因为更多的肌肉产生更多的肌酐。
:::
:::

::: exercise 评定临床衰弱量表 {level=1}
评定以下每个人的基线临床衰弱量表等级：(a)一位72岁女性，每周游泳三次，高血压控制良好；(b)一位86岁男性，能自己洗漱穿衣，但购物、做饭和银行事务由儿子负责；(c)一位90岁女性，所有个人生活照料都需要两名护理员协助，但一年来病情稳定。
::: solution
(a)她很活跃，所患疾病控制良好。她属于健康（CFS 2）；如果她是同龄人中最活跃的一类，则为非常健壮（CFS 1）。(b)他在较高层次的活动上需要帮助，但个人生活能自理：**CFS 5，轻度衰弱**。(c)个人生活照料完全依赖他人，但病情稳定，且未接近生命终点：**CFS 7，重度衰弱**。每种情况下，评定描述的都是基线，而不是急性疾病期间的状态。
:::
:::

::: exercise 康复期的蛋白质需要量 {level=2 check="66"}
一位80岁、体重55 kg的女性正从肺炎中康复，肾功能正常。按每千克体重每天1.2 g蛋白质的目标，她每天需要多少克蛋白质？请提出两种帮助她在医院达到这一目标的实用方法。
::: solution
$55 \times 1.2 = 66$ g蛋白质/天。实用措施：记录她的进食量并定期称重；在两餐之间提供富含蛋白质的点心和口服营养补充剂；确保她戴好义齿、眼镜，并帮她打开包装；保护用餐时间不被打扰；如果MUST评分提示有风险，请营养师参与。配合物理治疗进行运动也很重要：肌肉在使用时，蛋白质才能最好地支持肌肉。
:::
:::

::: exercise 半衰期与年龄 {level=2 check="round(0.693*112/1.2)"}
以下是一种脂溶性苯二氮䓬类药物的示意性数值。年轻成人：$V_d = 77$ L，$CL = 1.6$ L/h。85岁老人：$V_d = 112$ L，$CL = 1.2$ L/h。计算老年人的半衰期（取整到小时），与年轻成人比较，并解释其临床后果。
::: hint
使用[[#eq-halflife]]。药物大约需要几个半衰期才能达到稳态？
:::
::: solution
年轻成人：$t_{1/2} = 0.693 \times 77 / 1.6 \approx 33$ h。老年人：$t_{1/2} = 0.693 \times 112 / 1.2 \approx 64.7$ h，即约**65小时**，大约翻了一倍。分布容积增大（脂肪更多）和清除率下降都延长了半衰期。达到稳态约需四到五个半衰期，因此老年人开始规律服药后，药物会在11–13天内持续蓄积，镇静、跌倒和意识混乱可能在开处方一周甚至更久之后才出现。这些数值仅为示意；实际剂量和药代动力学参数以处方集为准。
:::
:::

::: exercise 为谵妄的衰弱男性规划住院管理 {level=2}
Kwame Mensah先生（[[#ex-ftt]]）被发现有900 mL尿潴留、便秘和血钠126 mmol/L，并且处于谵妄状态。请按CGA的领域写出问题清单，以及你会邀请参与的团队成员。
::: solution
医疗：谵妄及其诱因（尿潴留、便秘、低钠血症、可能的感染）；评估可引起尿潴留或低钠血症的药物（例如抗胆碱能药、阿片类、噻嗪类、选择性5-羟色胺再摄取抑制剂）；营养（进食差已十天）；跌倒风险。心理健康：目前为谵妄；谵妄缓解后筛查认知和情绪。功能：基线CFS 5；目前活动和如厕需要帮助；每天物理治疗以防去适应。社会：独居；女儿帮助购物和理财；询问她能否多提供帮助，以及他是否愿意接受护理员上门。未来：讨论目标，如果他愿意，在他仍能作出这一决定时办理持久授权书。团队：医生、护士（导尿管护理、肠道护理、谵妄护理）、物理治疗师、作业治疗师、药师、营养师，出院前还需社会照护人员参与。计划应写明谁在何时之前做什么。
:::
:::

::: exercise 解读CGA的证据 {level=3 check="round(1/(0.6*0.06))"}
在某医院，接受常规照护的老年急诊入院患者中，60%在六个月后仍存活并住在家中。假设CGA使这一比例相对增加6%（风险比1.06，如[[#thm-cga]]所述）。计算绝对增加量，以及使额外一人存活并住在家中所需的治疗人数（取整）。并评论这一效应是否值得。
::: solution
接受CGA时，$0.60 \times 1.06 = 0.636$，即63.6%存活并住在家中。绝对增加量为$0.636 - 0.600 = 0.036$（3.6个百分点）。需治疗人数为$1/0.036 \approx 27.8$，即约**28**。每评估28位衰弱老人，就有额外一人存活并住在自己家中，这是一个值得的效应：该干预主要投入的是人员时间，危害很少，还能减少入住照护机构。这一计算假设试验结果适用于该医院的人群，而这取决于是否按照试验的方式实施CGA。
:::
:::

::: exercise 重症监护门口的衰弱评分 {level=3}
一位74岁女性患重症肺炎，正在考虑是否转入重症监护。一位同事说：“她的CFS是6，所以不进ICU。”请讨论这种推理的对错，以及应该如何作出决定。
::: solution
正确之处：衰弱预示危重症后的结局较差，CFS 6意味着她很可能康复过程漫长而艰难，死亡概率更高，因此追问重症监护能否帮到她是合理的。错误之处：评分概括的是群体，而不是个体。决策必须考虑：CFS的评定是否正确（依据两周前的基线，而不是今天的状态）；急性疾病是否可能逆转；她的其他疾病；最重要的是她本人的意愿，包括任何预先拒绝治疗的决定，或家属对她意愿的看法。有些CFS 6的患者会选择并受益于限定时间的强化治疗试验；另一些人则更愿意在普通病房接受以舒适为重点的照护。公平的程序是：由高年资医生与患者或了解其意愿的人共同作出临床决定，记录理由，而且绝不能仅凭评分作出决定。
:::
:::
