衰老不是一种疾病、但它的物理并不留情面：稳态储备变窄、同样的打击产生不同的临床图像、而微小的应激会级联放大。**本章涵盖衰老的生物学（标志性特征、生理储备的丧失、及为何75岁的尿路感染患者以跌倒与一次意识混乱呈现而不是排尿困难）、衰弱作为一个可测量的临床状态（表型与缺陷累积模型、筛查及其诚实的使用与误用）、肌少症与营养不良及制动螺旋、全面老年评估作为老年医学独特的技术、及那个要么支持要么拆毁脆弱者的系统：夜间医院文化、把安老院当作患者、照护交接、康复、以及在治疗中期的同时为尽头做规划。组织性的那句话来自老年病医师：“治疗床上的那个人、而不是那个人里的床。”——听起来软弱、直到你看着一个运转良好的老年病房预防掉一个零散的、按器官分科的入院会产生谵妄、跌倒、压疮、不适当的喂养管与葬礼。**

## 生物学与测量

::: definition 衰老的生理学与储备 {#def-biology}
**解释框架：衰老的标志性特征（基因组不稳定与端粒损耗与表观遗传漂移与蛋白稳态丧失与线粒体功能障碍与细胞衰老、伴衰老细胞分泌表型的炎性衰老背景、及失能的营养感知与干细胞耗竭及细胞间通讯改变）——这是实验室生物学对“为何一切临床事件的概率随年代指数上升”的真正描述尝试、及其诚实的转化：标志解释了机体层面储备下降的事实、而你实际治疗的就是储备下降——同一个细菌、药物、髋部或禁食、在30岁产生发热的地方产生了谵妄、而老年综合征（跌倒、谵妄、失禁、压力性损伤、衰弱）是多系统边际丧失的临床签名、不是单一器官疾病。边际的生理学：心血管僵硬的心室与迟钝的压力感受器反射及传导系统纤维化、使心动过速与低血压及β阻滞与容量转移都不那么可宽容、肾隐藏在正常肌酐里的肾小球滤过率下降、因为产生肌酐的肌肉质量也在下降——胱抑素C与Cockcroft-Gault对CKD-EPI的处方含义、这就是为何老年药物剂量是一道肾算术、而此人30年前那对肾脏已经不在、体温调节脓毒症就诊时的低体温与无取暖住宅中的跌倒、免疫免疫衰老带其感染呈现与疫苗应答及带状疱疹再激活逻辑、肌肉骨骼每年1-2%的骨与1%的肌肉丢失、带肌少症性肥胖及维生素D及蛋白摄入之问、及感觉认知被误标为意识或情绪低落的视力与听力丧失、而事实上是可干预的孤立与谵妄风险贡献项、眼镜与助听器就是老年医学而不是慈善。内分泌代谢的边际：每公斤的甲状腺素剂量与地高辛及锂及苯二氮䓬类的敏感——这是一句话处方清单版的药代与药效衰老、在多重用药一章完整覆盖。生物学的临床产出在床旁是有限的衰老细胞清除剂与雷帕霉素及TAME与DOGMA邻近的长寿试验-二甲双胍、治不了你那位81岁正在跌倒的患者、但在框定上是巨大的：衰老是系统没有备用零件的时候、所以预防与温和的对待 就是治疗、而“她住在哪里、和谁一起、这周之前她能做什么”这个问题与血液检验同样是生理学、因为一位安老院住民与一位同年龄同髋部骨折的富裕业余帆船手是两个不同轨迹里的两个不同患者——这正是为何实际年龄的预测力不如功能、也为何本章每一个评估工具测的是功能而不是岁数——[[physiology/homeostasis-body-fluids]]、[[immunology/innate-immunity]]、[[renal/filtration]]。**
:::

::: definition 衰弱：综合征、工具与用途 {#def-frailty}
**两个可用的模型与一个警告。表型Fried五项：非自愿体重下降、自述耗竭、活动少、步速慢、握力低——三项及以上是衰弱、一或两项是衰弱前期与缺陷累积指数Rockwood衰弱指数：把症状、体征、残疾与异常检验对着“本可以计数的东西”计数；比值本身就是衰弱、而其惊人的性质是近乎线性的死亡率与失能关系、及约0.67缺陷这个与生命不相容的理论上限。你会真正遇到的临床工具：电子衰弱量表Rockwood的1到9、从非常健康到终末期、带其易记的图片及其正当的分诊与研究用途、PRISMA-7与G8及两问筛查（“你会不会很快感到疲惫、你认为自己需要帮助吗？”、及在诊室里多看一秒做出的临床衰弱判断——优秀临床医师不自觉地就做）、及诚实的批评：工具不是人格测验、它们测量失能与依赖的程度不亚于生物学、所以它们可能把年龄歧视与阶级歧视及性别规范偷运进“客观”评分、而筛查规划时代的风波就是教训（英格兰人群衰弱筛查试点、给80岁以上者寄信、因一场公众与学术运动而被取消——主题是被人寄来一个数字却没有一个计划的体验——因为一个没有干预的评分就是一个标签、而一个没有同意的标签就是伤害）。正当的用途：预测谁在手术或入院周围需要老年病医师（外科衰弱项目数据、及在紧急髋部之前而不是重症监护第9天之后进行预康复与照护目标谈话）、谁需要跌倒与康复及药物复审服务衰弱作为一个转诊而不是一个命运、及谁希望现在就进行那场严肃的谈话而他们还仍能选择从量表健康一端做出的预先照护规划与研究参与及居住地点决定、比在疾病一端做同样的谈话更有价值。测量的真相一句话：衰弱最好被用作通向全面评估与支持的大门、绝不作为拒绝治疗的理由——年龄不等于衰弱、衰弱不等于无益这条规则、每条指南都写明、而每个深夜的急性评估会诊仍然在检验它。**
:::

## 老年综合征与评估

::: definition 肌少症、营养不良与制动螺旋 {#def-sarcopenia}
**肌肉很重要：肌少症（AWGS-2与EWGSOP2标准时代的定义：先以肌力低作为触发——用测力计测握力——然后用肌肉量或质量低确认、重度肌少症再加上功能低）是衰弱呈现的生理引擎、并有三个可治的驱动因素：不活动与卧床住院老年患者每周10%的股四头肌丢失——这是我们任何人将经历的最快衰退、也是“让她动、第一天、计划上写名字”成为老年医学第一戒律的原因、营养不足（随疾病、衰老与炎症上升到每日每公斤1.2克的蛋白需求、带吞咽困难与牙齿及抑郁及独处及药物改变悄悄削减摄入的因素、及入院时的MUST筛查、及一位营养师用一张食物强化建议表能比一张口服营养补充处方做更多）；及缺乏与内分泌背景（维生素D对跌倒与骨折的不大但真实的数字、对令人失望的大剂量冲击试验——这就是每日而不是超大剂量的教训——及消耗患者的甲状腺与睾丸酮及激素性肌病及炎性肌病的鉴别、不只是“老了”）。要预防的螺旋：跌倒→骨折→入院→谵妄→卧床→去适应→“生长失败”→安老院→衰退；那条链里每一支箭头都有一个循证断路器（髋部骨折路径与老年骨科联合服务及早期活动及谵妄包裹及骨保护——因为三分之一跌倒的人会骨折一根骨头、而骨折联络服务仍然错过最开始的80%——本章的工作就是知道你在哪位患者身上切断哪些箭头）。吞咽与营养的边缘情形：误吸性肺炎与吞咽治疗评估、及质地与稀液体的重思“增稠液反而让肺炎更糟因为没人愿意喝”的文献、及作为误吸预防的口腔护理、以及牙齿的保护作用被处方不足、痴呆中喂养管的伦理与证据（随机试验显示不能预防误吸或死亡或压疮、而代之以生命尽头的舒适喂食、及围绕撤除或不予的法律与家庭过程——属于精神能力法与姑息各章、但在此说明因为那根管子是在凌晨3点的病房被提供的、而病房需要唾手可得的证据）、及非自愿体重下降的检查边界（筛查癌与抑郁及甲状腺及糖尿病及痴呆及牙齿与社会原因、同时接受最年长者的消耗常是多因素的、而计划是功能与尊严及谁来看望、不是再做一个计算机断层）。**
:::

::: definition 全面老年评估与老年医学服务 {#def-cga}
**全面老年评估本身就是干预：一个多维度、跨学科的诊断过程（医学-心理-社会-功能）最终形成一个协调的计划、由一个训练有素的团队在一个有入院限制并主动老年医学共管评估与康复单元上交付——而它的证据是一般医学最强的服务事实之一：Stuck与Ellis及Kalra与Forsyth试验及其Cochrane综合、及老年骨科与卒中单元的类似研究、显示活着回家且功能改善且长期住院减少的可能性提高、而效应量来自模式而不是场所（跨学科每周查房、带一个具名团队与每天一个目标、及从第一天开始的出院规划、可转移到任何病房——这就是为何老年友好卫生系统把全面老年评估提取为“上移”指导与4M框架：什么重要、药物、心智、活动——在每一例老年入院的每一天被问起）。考试会问而病房会忘的条目：包含抗胆碱能与镇静负荷的药物复审（见多重用药章）、在日常观察表上而不是应要求才做的认知筛查带谵妄CAM或4AT、情绪（老年抑郁量表与“这周她和谁说过话”之问及丧偶史）、跌倒（带直立血压与鞋、及晕厥对机械对多因素的归因、及起立行走试验与10米步行及握力作为老年医学真正使用的体格检查）、节制（“哪个先来、急迫还是不能活动”及尿垫对常识判断）、营养（诊室墙上的体重曲线像血压一样）、皮肤（Waterlow或Braden与泡沫床垫及翻身及那份伪装成营养的伤口照护）、感觉（擦亮的眼镜与装了电池的助听器——这就是为何床边有一盒备用助听器与报纸大小的信息）、及社会（照护者自身的健康作为一项生命体征、及住房与取暖与财务、及“当你不能再独居时由谁决定、我们如何让那是一个选择而不是一场伏击”）。服务架构：收入评估与治疗单元对联络服务、对带社区团队的病房查房、对家庭病床、及两小时衰弱长者门诊、及日间医院康复、及中间照护与复能、及一条至为重要的注记：服务资金不足而碎片化、因为老年医学是医学中最暴露于不平等的专科（健康的活动家80岁在75岁就被看到、而衰弱独处的79岁得到的是跌倒、骨折、护理院、系列入院——而抗精神病药使用有40倍差异的安老院、是一个发生在无法投诉人身上的公共健康失败）。这个模型的一个弱点：全面老年评估的收益要求系统兑现评估所做下的承诺——永远没到的辅助器具与排进长队的社区职业治疗转诊、及那个“她不能再回到那里”的入院其实是一个带医学标签的社会照护失败——这就是为何本章以整合而不是以工具结尾。**
:::

::: example 84岁患者的“简单尿路感染” {#ex-uti}
从急诊以“尿路感染与意识混乱”收入；病房计划：静脉抗生素、继续本次入院新开的利培酮“用于激越”、卧床“直到能活动”、留置导尿“用于监测尿量”、400英里外的女儿未被告知病房电话。第3天：不下床、不吃、新出现失禁、“不是她自己了”。
::: solution
**病房现在就是疾病（[[#def-cga]]、[[#def-frailty]]）：复审——“这是医源性老年综合征的流水线：谵妄的误吸与低钠及低氧及低血糖及药物原因都已查（那个尿路感染本身需要一个中段尿标本与一个理由、而不是一根尿试纸的细菌——是无症状菌尿、恰恰在这个人群中过度治疗极其严重）、而无精神病的谵妄中新开抗精神病药违反指南、及抗胆碱能与阿片及苯二氮䓬清单及减量决定“；导尿管在里面（感染与束缚及隐私丧失）；卧床（来自肌少症节的去适应算术——这就是为何”活动就是治疗”写在白板上）；早餐11点的7点给药轮与未摆好的餐盘、眼镜摘下、助听器取出：病房的时间表是一种致谵妄暴露、而修补不新奇、它被命名并被排程：8点戴上眼镜、在吃饭的时候给饭、灯光与噪音及定向、以及如果你把病房电话给他们、家属就是团队的一部分。重写：“停利培酮并与药师复审每一种药、移除导尿管或写下它拔除的那天、在抗生素用完之前让她坐到椅子上、请女儿把鞋与照片与病史带来、营养师给强化食物而不是默认的营养补充、理疗与职业治疗目标按名字写、谵妄监测记录在观察表上、及现在开始出院规划谈话——因为第3天的不是她自己是一个康复预后之问、答案是6周、以及她以前住在哪里、她在那里会接受帮助吗。”最后是治理那句话：这种入院模式正是患者安全与老年友好工作存在的原因；没有人有恶意、而一切都是默认设置——而默认正是一个运转良好的病房一次一个习惯所替换掉的东西。**

::: example 78岁的“生长失败” {#ex-ftt}
安老院住民；6个月体重下降7公斤；反复“太不适”而不能住院；现在卧床伴双侧压力性损伤、服11种药、间断意识混乱但安老院说是“基线”；员工说“她只是一直在衰退”；家人问“这是临死还是可治的？”
::: solution
**这个需要评估而不是意见的问题（[[#def-frailty]]、[[#def-sarcopenia]]）：诚实的框架——“老年成人的非自愿体重下降与衰退是一个要调查的诊断、不是一个要接受的处置安排、而只是老了与她要死了两种叙事都终止了本不该终止的谈话；家属的问题是正确的问题、这就是为何答案是结构化复审而不是安慰“；复审——”在安老院由一位优秀护士完成的那份全面老年评估、即可治贡献项审计：抑郁（在这个人群中以淡漠与拒食呈现的可治抑郁）、甲状腺与糖尿病及维生素B12与维生素D及感染（牙脓肿、及作为原因而不是结果的隐匿尿路感染、及上次入院抗生素后的艰难拟梭菌）、癌（如果改变处理就接受扫描、并拒绝不改变处理的那一个、尽可能依她已知的价值判断并记录）、药物（抗胆碱能与镇静及非甾体抗炎药及地高辛、及三种降压药伴夜间低血压与跌倒、及以便秘粪嵌塞呈现为意识混乱——这是一份12种药物清单审计会给出的结果）、口腔与牙齿及吞咽评估、及带食物强化的蛋白摄入、及盘子收走之前她是否被问过要不要再来一份、压力性损伤作为一个营养与活动及翻身的计划而不只是敷料、疼痛时间表、眼镜与助听器、及4AT与给女儿的一次病史电话在一个下午就能在床边完成的抑郁对痴呆对谵妄的拆解“；及那场大谈话——”这是进行预期照护规划的时刻、带相当于照护上限建议的文件、不是心脏骤停之后才填的表格：如果她今晚心脏停了、她希望怎样？在椅子上回答、不是在抢救推车的恐慌中；这与我们会治疗她的胸部感染、处理她的嵌塞、并请伤口团队来完全兼容、因为问题从来不是全或无、而太不适不能住院的模式常常是太不适进一家无益的医院——这就是为何家庭病床与安老院外展团队及与老年医学的线上会诊路径存在、也是为何家属值得听到我们会查清是什么在驱动这个、以及谁在何时做什么、这句话用计划取代了系列性衰退。**

::: example “肌酐正常”的81岁患者 {#ex-renal}
一名81岁女性、48公斤体重、丧偶、每周三天有一位照护员同住；跌倒后以意识混乱入院；肌酐88微摩尔每升“正常”；替班团队因尿路感染开始标准剂量呋喃妥因、因髋痛开始布洛芬；两天后她更加意识混乱并且少尿。
::: solution
**肾、肌肉与处方（[[#def-biology]]、[[#def-cga]]）：生理——”一名48公斤体重81岁女性的肌酐88不是正常的肾功能——它是一个几乎没有肌肉来产生它的人的肌酐、而此处估算肾小球滤过率约为40-45、这使得呋喃妥因既对尿液无效又可能中毒（指南把估算滤过率低于45视为禁用、低于30视为危险）、而布洛芬是灌注不足肾脏与脱水及非甾体抗炎药的三方碰撞；少尿与加深的意识混乱就是把那份处方清单读回给你听“；即刻的工作——”药物负荷审计（家用的苯二氮䓬、可待因、抗胆碱能抗抑郁药也计入——数抗胆碱能与镇静负荷）、液体与电解质重新评估带膀胱扫描查尿潴留及粪嵌塞检查、感染重新评估（尿路感染是真的吗、还有别的来源吗、呋喃妥因是不是根本没在治疗一个全身感染）、及被意识混乱分散掉的跌倒检查程序“；及修补——”停布洛芬、把肾算术真正做完之后换抗生素（与药师一起做剂量调整的替代）、按有监测的计划补液、并把胱抑素C或计算的肌酐清除率写进病历、让下一位替班医师继承的是肾脏而不是那个数字；及不再重复本次入院的出院给全科的信以毫升每分写明肾功能、不含非甾体抗炎药而对乙酰氨基酚与外用及理疗阶梯的镇痛计划、及药物复审转诊、因为这次入院是一个穿着医学外衣的处方不良事件——它是可报告、可学习的、也正处于多重用药一章的核心地带。**

::: exercise 计算这个肾处方 {level=1}
为上面那位81岁、48公斤、肌酐88微摩尔每升的女性估算肌酐清除率（Cockcroft-Gault）、并说明它改变她两份新处方中的哪两份、如何改变。
::: solution
**算术（[[#def-biology]]）：把88微摩尔每升换算为约0.99毫克每分升；肌酐清除率=（(140-81)×48×0.85)/(72×0.99）、约为32-34毫升每分或用微摩尔版本：1.23×(140-81)×48×0.85/88、同样答案。后果：呋喃妥因——在这个清除率下它既不能在尿中充分浓集、也不能从血浆中安全清除；指南说低于45毫升每分避免使用（低于30禁用）；换成按培养结果治疗实际感染部位的药；及布洛芬——肾前列腺素是她不适时唯一能让灌注不足的肾脏保持灌注的东西、所以停用它、用对乙酰氨基酚与外用及定期复审阶梯；并注意第三个——如果她在用经肾清除的阿片（吗啡的代谢物）或直接口服抗凝药或地高辛或锂、同样的算术决定剂量。教学要点：”肌酐是正常的是一句杀死过衰弱者的话；是肌肉造出了那个数字、是肾造出了那个患者——而每一位衰弱老年患者的每一个处方决定都应对着估算清除率做出、电子病历本应主动提供、而药师本应把它视为第二个签名——[[geriatrics-palliative/polypharmacy]]。**

## 通向何处

谵妄与痴呆照护是自成一章（[[geriatrics-palliative/delirium-dementia-care]]）、药物科学在[[geriatrics-palliative/polypharmacy]]、跌倒一章补全综合征集合（[[geriatrics-palliative/falls]]）、而伦理机制在[[medical-ethics-law/consent-capacity]]与[[geriatrics-palliative/end-of-life-care]]。

::: history
**老年医学因时势所需被发明了两次、而只被命名一次：除Charcot学派及邻近的先行者之外、现代专科始于Ignatz Nascher在1909年创造“老年医学”一词、并坚持这个领域是临床的而不是看管的、然后是两次世界历史性的时刻——Marjory Warren自1931年起在米德尔塞克斯医院的工作：她走遍伦敦济贫院医疗系统的“慢性病”病房、发现数千名本可以活得不同的老年患者（“他们并不老、他们是被忽视、并因长年坐在床上而挛缩”这个观察）、并建立了第一个带跨学科团队与早期活动及以家庭为单位的老年评估与康复服务——这就是全面老年评估在实践中的奠基论文。战争与国民健康服务随后使它专业化：Isaacs与Brooke与Brocklehurst及Kane一代人建立了大学学系、随后的试验者把Marjory Warren的直觉变成证据（一个以服务为基础的学科那句经典的“我们早就对了、现在我们能证明”）、而1948年后英国的老年医学委员会使它成为世界上制度化程度最高的专科之一、而其美国对应物仍是学术少数、全球版本跟随人口学而不是规划。概念史很有教益：“医疗慢性病患者”变成“衰弱老人”再变成“作为可测综合征的衰弱”（Clegg与Young与Rockwood、及2001-2010年表型对缺陷累积之争、及加拿大团队的电子衰弱量表）、以及让这门科学变得迫切的平行社会史：安老院产业的曝光与严重事件审查时代、以及首推2020-21年安老院大流行死亡率——英国历史上冲突之外最集中的死亡——暴露了这个专科未完成的事业：当“社区”是一栋有一个经理的建筑时、社区医学的边界在哪里。药理学很晚才跟上：1991年来自美国内科普通科医师的Beers标准、及2015、2019、2023年美国老年医学会更新、及爱尔兰O'Mahony高韦团队的STOPP-START标准、及2013与2018年的国家用药复审指南、及2020年代抗胆碱能负荷级联与苯二氮䓬及质子泵抑制剂及选择性血清素再摄取抑制剂的去处方试验——它们共同把药物复审变成一个有数字的临床干预、而不是一场闲聊。当前这一章是人口与经济的：2020年代的超级老龄化、与85岁以上人口超过400万的预测、及人力紧缺、因为没有国家培养了足够的老年病医师、所以老年病医师分发的是一个模型而不是在做一个负荷、及整合议程（更好的照护基金与照护系统、及安老院持续照护、及“为老年人一次做对”、及家庭病床与虚拟病房的证据、在2020年代成为一支像样的试验文献）。历史的语气是防守与自豪各半：老年医学花了几十年成为其他专科寄来问题的专科、并在最近二十年证明它的方法——多维度评估、把功能作为结局、团队高于单器官的肿瘤董事会模型——是将来所有医学不得不为何人、在何处、多快变成的预演。Marjory Warren的洞见仍是这个领域最新的东西：许多不可治愈的依赖者、是被收容他们的系统造成这样的。——[[physiology/integrative-physiology]]、[[geriatrics-palliative/polypharmacy]]、[[public-health/health-systems-economics]]。**
:::

::: summary
- 衰老收窄生理边际；老年综合征（跌倒、谵妄、失禁、压力性损伤）是多系统边际丧失、所以单一器官推理会误读它们。
- 衰弱可以测量（表型、缺陷累积、电子衰弱量表）、对预测与转诊有用——而当它被用作没有支持的标签或拒绝治疗的许可时会造成伤害。
- 肌少症与营养不良很快形成螺旋；活动、蛋白、及摄入减少的可预防原因就是治疗、而床本身就是一种临床暴露。
- 在限制入院的评估单元做全面老年评估、是医学中证据最好的服务干预之一——其条目可移植到每一所接收老年患者的病房。
- 衰退是一个要调查的诊断：体重下降与“生长失败”值得先做一次药物与抑郁感染营养口腔的审计、然后才是一个叙事。
- 提前规划（能力、复苏、照护地点）是主动老年照护的一部分、最好早做、用患者自己的话、写在全系统都能看见的纸面上。
:::

使用临床（电子）衰弱量表、分类：(a) 健壮而活跃的79岁者；(b) 缓慢、用助行架、上楼梯需休息、不需要帮助洗澡；(c) 所有个人照护都需要帮助、节制受损、在帮助下可活动；(d) 卧床而持续患病。每一级在外科入院中改变什么？
::: solution
**各级及其用途（[[#def-frailty]]）：(a) 非常健康到健康（约1-2）、(b) 轻度衰弱约4：“易受伤害”——不依赖但缓慢、(c) 中到重度衰弱约6-7、(d) 重度衰弱到终末（约8-9）。在外科入院中、级别改变谈话与围手术期计划：健康者走标准路径；轻度衰弱者需要老年医学共管与在紧急情况之前而不是之中进行的目标谈话、跌倒筛查与药物复审及谵妄预防包裹作为默认而不是恩惠；中重度衰弱者需要“在我这样的人身上这个手术的结果是什么”用功能术语回答、带该操作专属的衰弱数据、因为在这个级别“生存”是错误的货币、而“之后我会不会住进护理院”可能是与决策相关的风险；而在8-9级、问题变成这个手术究竟是不是合适的治疗、还是带明确重评触发的最优保守处理——不是扣住照护、而是匹配照护。每一次使用量表都应带的诚实警诫：这一级描述的是患者当前的轨迹、不是她的价值也不是她的上限——电子衰弱量表自己的作者们说该工具用于标记需要评估、支持与预测的人、不用于决定谁值得治疗——而一个9分仍然是你面前一个有具体问题的人、那个问题按其自身的是非仍然可治。**

::: exercise 做出谵妄加衰弱的入院计划 {level=2}
为一名83岁独居者（痴呆“轻度”、拄拐行走）、因肺炎入院、在病房急性意识混乱、不吃、无探视者、写出头24小时计划。按心智、药物、活动、什么重要来组织。
::: solution
**4M入院计划（[[#def-cga]]）：心智——”现在做4AT或CAM、此后每班一次、谵妄检查程序作为一个限时的清单（低氧、脓毒症来源、低血糖、低体温或高热、尿潴留与粪嵌塞、疼痛、药物清单、及包括钙钠镁及需要时甲状腺功能在内的血液）、并在第一天给全科与女儿打病史电话、因为轻度基线认知损害是一个风险因素、不是一个可以对照记录的基线、及把谵妄环境包裹写成医嘱（眼镜、戴上助听器、昼夜的灯光与噪音、定向板、与理疗一起活动、家庭照片、那位认识她的固定护士）；药物——“与药师复审整份药物清单（苯二氮䓬与Z药及阿片及抗胆碱能清点、及可以等待的他汀、及自2016年未复审过的质子泵抑制剂）、带肾算术的抗生素选择与剂量、静脉血栓预防与缓泻及镇痛按时间表而不是按需——因为疼痛与便秘是致谵妄的、而抗精神病药不为黄昏综合征单独给予、只在痛苦或风险要求时给予、带一个复审停止日期、并筛查路易体痴呆的禁忌；活动——”在氧允许时午餐前坐到椅子上、理疗与职业治疗与营养、带手指食物与强化菜单、及在意识混乱缓解后或之前核查吞咽、导尿管不插入或在黎明拔除改用膀胱扫描、压疮区域已查并配适当的床垫、及其实与活动计划相同的跌倒计划；什么重要——“在谵妄允许时用她自己的话、在有记录时用她以往的话（预先声明、持久授权、及我绝不希望这样活着的谈话、现在就该问女儿而不是凌晨两点）、把病房电话给女儿并邀请她参与照护、及两行记录在案的预后句子带一个复审日期——这就是我们在治疗肺炎的同时保护她的心与身如何变成一个可执行的计划而不是一句口号。**

::: exercise 建设安老院药物规划 {level=2}
你的地方照护机构：240家安老院、抗精神病药处方有40倍差异、无标准的专业人员可及、夜间唯一的医学接触是救护车呼叫、60%的住民死在医院、而多数人在别处记录的意愿并非如此。设计这个规划及其指标。
::: solution
**安老院医学（[[#def-frailty]]、[[#def-cga]]、[[geriatrics-palliative/polypharmacy]]）：模型——”每家安老院有一位具名全科医师、带安老院挂牌与定期巡诊职责、而不是一个我们是他们全科的形式；一个嵌入或待命的老年医学与高级实践护士服务、带电子药物复审与床边的溃疡伤口门诊、及取代夜间急诊的直接收入评估单元的通路——因为太不适不能住院常常是对一家对她毫无办法的医院太不适；及针对抗精神病药差异的药师断路器（带去处方路径的年度复审、及用于按需文化的教育与行为支持团队、及减少精神科多重用药与描述-评估-实施-监测框架、带本地把每家与同群对比后反馈的审计——正是在认真推行的地区让40%降到个位数、而不是在只报告不推行的地区）；在家中死亡的能力——“在健康时的预期照护规划、带预先选择与相当于照护上限的预期药物及院外时间安排、及被记录并被执行的偏好照护地点、及快速可及的姑息照护团队、因为说过要在家的人死在医院是一个系统选择、不是住民的偏好“；及指标——”按安老院的抗精神病药处方率带同群比较、非预期住院率、这位住民在最后一年是否有医师或处方护士看过、救护车呼叫后的院外医院转移率、及家属调查项她的意愿是否被知道并被尊重、因为这个问题是验尸官与儿子都会问的那一个。**

::: exercise 为老年医学辩护 {level=3}
一份财政部文件提议关闭“低价值”的老年评估服务、把钱投向急性容量、指出该专科“把死者治得慢、把衰弱者治得贵”。就证据、经济与公平写一份反驳、并承认其中真实的部分。
::: solution
**为老年医学辩护（[[#def-cga]]、[[#def-frailty]]）：承认——”粗率的批评有真实的边缘：全面老年评估的单个效应量确实不大、当后续服务不存在时其收益会消失（一个没有复能与辅具与社区护士的模型只是一场会议）、而老年医学不擅长测量和宣传它预防了什么（一次被避免的谵妄或一次被推迟的安老院入住出现在别人的预算里、不在任何人的成功案例里）；反驳的证据——“评估单元与老年骨科及卒中单元的限制入院与主动共管、在死亡与机构化及住院时长上都有随机或强观察性结局数据、经济随之而来——痴呆基础上的谵妄与跌倒后的去适应及生长失败的再入院、是急性医学中最昂贵而满意度最低的事件之一、而老年共管的替代不是更短的住院、而是别处更长的住院与更差的结局；经济部分——”髋部骨折的老年骨科模式在多数被检验过的地点节省成本、而每一项关于复能与综合门诊照护及家庭病床的质量调整生命年研究都显示便宜的床日论证是幼稚的、因为床日会与更糟的商品交换位置（护理院永久入住是昂贵的选项、延迟出院是可预见的选项、而带骨折级联的反复跌倒则是难以言说地昂贵、且它始于没有提供那个肌力与平衡规划）；公平部分——“老年患者是照护最受社会资本决定的群体：同样的骨折与同样的衰弱、依家庭倡导力与邮政编码、产出一家私人康复机构或一趟走廊推车、所以一个被采购的服务就是平衡器、而效率节省会作为不公落下、因为患者不运动、不投诉、也不用私人金钱投票、而这个专科自身的人力报酬低且多为女性——这是一个线索、说明社会认为谁的衰老值得付钱“；诉求——”为模型的承诺出资、不只是为它的会议：有人力配置的评估单元、有容量的社区落实、有具名临床医师的安老院与护理交界、附设的跌倒与骨及药物服务、及把活着且在家且有功能算作结局的报告（正是患者报告他们想要的、也是整章一直在讲的东西）——并且只在明显未按模型运作的地方关闭低价值服务、并在新的地方用一个称职运作的模型取代它们。**
