晚期疾病患者常常同时有几种症状：疼痛、气促、恶心、便秘、疲乏、食欲差、情绪低落、焦虑和瘙痒。良好的症状控制并不依赖罕见的技巧。它依赖于仔细的评估、对每个症状背后机制的理解、向患者解释清楚的计划，以及频繁的复评。本章介绍症状控制的原则和最常见症状的处理，包括阿片类药物处方的算术。

本章中所有药物信息描述的都是英国实践中的原则和典型做法。具体患者的剂量以现行BNF、《姑息治疗处方集》（*Palliative Care Formulary*）和当地姑息治疗指南为准；症状难以控制时应寻求专科意见。

## 原则 {#sec-principles}

::: theorem 症状控制的原则 {#thm-principles}
有效的症状控制遵循五个步骤：(1)**评估**每个症状、其严重程度、对患者的影响及其可能的原因和机制；(2)向患者和家属**解释**原因和计划；(3)在符合本人目标和负担可接受的前提下，**治疗可逆的原因**；(4)选择针对其机制的非药物和药物措施进行**处理**；(5)频繁**复评**效果并加以调整。
:::

::: proof
晚期疾病中的大多数症状有不止一个原因，而治疗取决于原因。便秘引起的恶心需要缓泻剂，而不是止吐药；胸腔积液引起的气促可能通过引流缓解；阿片类中毒引起的意识混乱需要减量，而不是镇静药。解释可以减轻恐惧，而恐惧会放大许多症状（Saunders所说的“全人疼痛”）。是否治疗可逆的原因取决于负担与获益：如果患者能活到从中获益，引流积液是值得的；而在生命最后几天输血则可能不值得。晚期疾病的症状变化很快，上周有效的计划今天可能就不对了：频繁复评本身就是治疗的一部分。
:::

## 疼痛 {#sec-pain}

::: definition 晚期疾病中的疼痛 {#def-pain}
疼痛按机制分类。**伤害感受性疼痛**由组织损伤引起：**躯体痛**（骨、皮肤、肌肉）通常定位明确，呈酸痛；**内脏痛**（器官、包膜、空腔脏器）定位不清、位置深在，可呈绞痛或牵涉痛。**神经病理性疼痛**由神经系统损伤引起，常呈烧灼样、射击样或电击样，并伴有沿神经或皮节分布的感觉改变（麻木、痛觉超敏）。许多癌症患者的疼痛是混合性的。评估应记录部位、性质、严重程度、时间规律、加重和缓解因素、对功能和睡眠的影响、患者的理解和恐惧，以及对既往治疗的反应。
:::

### 镇痛阶梯及其后续发展

1986年发表的**世卫组织镇痛阶梯**为癌痛引入了一个简单的阶梯式方法：第一阶梯，非阿片类药物（对乙酰氨基酚、非甾体抗炎药）；第二阶梯，弱阿片类药物（可待因、曲马多（tramadol））加非阿片类药物；第三阶梯，强阿片类药物（吗啡及其替代药物）加非阿片类药物；每一阶梯都可加用**辅助药物**。其配套原则是“口服给药、按时给药、按阶梯给药、个体化给药、注意细节”。镇痛阶梯使口服吗啡在全世界得以普及。世卫组织2018年的癌痛指南转向了更加个体化的框架；在实践中，许多中至重度疼痛的患者直接使用小剂量强阿片类药物，跳过弱阿片类药物，因为后者增益不多且代谢难以预测（可待因是一种前体药物，经CYP2D6转化为吗啡，而CYP2D6的活性因人而异）。

### 强阿片类药物

NICE关于姑息治疗中强阿片类药物的指南（CG140）推荐口服吗啡作为大多数晚期疾病患者的一线强阿片类药物。关键原则：

- **起始**：对于肾功能正常、未使用过阿片类药物的患者，典型的起始方案是每天口服吗啡20–30 mg，可用缓释制剂（每日两次）或速释制剂（每4小时一次），并备有速释剂量用于爆发痛。衰弱的老年人和肾功能损害者使用更低的剂量。
- **爆发痛剂量**：在规律镇痛基础上为“突破”的疼痛给予的一剂速释阿片类药物。英国实践中，爆发痛剂量通常为同一药物每日总剂量的十分之一至六分之一。
- **剂量调整**：通常每天根据所需爆发痛剂量的总和以及副作用调整规律剂量。
- **预防副作用**：所有规律使用阿片类药物的人都应开具缓泻剂；备好止吐药；解释嗜睡和恶心常在数天内缓解，但便秘不会。
- **警惕中毒**：嗜睡、意识混乱、幻觉、肌阵挛、针尖样瞳孔，严重时呼吸抑制。中毒常发生在肾功能下降之后。

::: definition 每日总剂量与爆发痛剂量 {#def-tdd}
阿片类药物的**每日总剂量**（TDD）是24小时内所有规律剂量与爆发痛剂量之和。**爆发痛剂量**是同一阿片类药物TDD的一个分数，通常为六分之一：

$$
\text{爆发痛剂量} \approx \frac{\text{TDD}}{6}
$$ {#eq-btp}

为了比较或转换阿片类药物，每种药物都用换算比例表示为**口服吗啡当量**。英国实践中常用的近似比例为：口服吗啡换算为皮下吗啡，除以2；口服吗啡换算为皮下二醋吗啡，除以3；口服吗啡换算为口服羟考酮，除以1.5至2（各换算表不同）；口服羟考酮换算为皮下羟考酮，约除以2。所有换算比例都是近似的，应遵循当地指南。
:::

**肾功能损害。**吗啡代谢为吗啡-3-葡萄糖醛酸苷和吗啡-6-葡萄糖醛酸苷，它们经肾排泄，肾功能下降时会蓄积，导致嗜睡、意识混乱和肌阵挛。在中至重度肾功能损害时，宜选择对肾脏依赖较少的阿片类药物：中度损害时可减量使用羟考酮（oxycodone），重度损害时在专科意见下使用阿芬太尼（alfentanil）或芬太尼（fentanyl）等。

**透皮贴剂**（芬太尼、丁丙诺啡（buprenorphine））在口服困难时有用，但需要许多小时才能达到稳定的效果，撤除后作用也要许多小时才消失，因此适用于稳定的疼痛，而不适合快速调整剂量。

**阿片类药物转换**（轮换）用于副作用无法耐受，或尽管加量疼痛仍未控制的情况。由于对一种阿片类药物的耐受并不完全适用于另一种（不完全交叉耐受），新药的计算等效剂量通常减少25–50%，因中毒而转换时尤其如此。

::: example 阿片类中毒与药物转换 {#ex-rotation}
Thomas Ward先生72岁，患前列腺癌伴骨转移。他每天两次服用缓释吗啡60 mg，每天还需要四次速释吗啡10 mg的爆发痛剂量。两天来他变得嗜睡，四肢出现抽动，并看见墙上有虫子。由于脱水，他的eGFR从55降到25 mL/min/1.73 m²。请计算他的口服吗啡TDD，并按口服吗啡与口服羟考酮2:1的比例、转换时减量25%，概述一个安全的调整方案。
::: solution
**评估。**肾功能下降时出现嗜睡、肌阵挛和幻觉，提示吗啡代谢物蓄积导致的**阿片类中毒**。可逆因素：脱水（给予补液，如合适可考虑皮下或静脉补液），以及急性肾损伤的任何其他原因，如非甾体抗炎药或尿路梗阻（前列腺癌的风险之一）。

**TDD。**规律剂量：$60 \times 2 = 120$ mg。爆发痛剂量：$4 \times 10 = 40$ mg。TDD $= 160$ mg口服吗啡/天。

**转换为羟考酮。**等效剂量：$160 / 2 = 80$ mg口服羟考酮/天。由于中毒和不完全交叉耐受减量25%：$80 \times 0.75 = 60$ mg/天，例如缓释羟考酮30 mg每日两次。爆发痛剂量（[[#eq-btp]]）：需要时速释羟考酮约$60 / 6 = 10$ mg。

**监测。**在最初24小时内，可在保证疼痛得到控制的前提下暂停规律剂量，直至中毒征象改善。至少每天评估疼痛和中毒情况，并复查肾功能。如果肾功能进一步恶化，需要专科意见以选择阿芬太尼等替代药物。这里的剂量用于说明计算方法；实际处方遵循当地指南。
:::
:::

### 辅助镇痛药

有些疼痛单用阿片类药物效果不佳：

- **神经病理性疼痛**：阿米替林、度洛西汀、加巴喷丁或普瑞巴林（pregabalin）（NICE CG173）。加巴喷丁类在肾功能损害时需要减量，并可引起嗜睡和头晕；三环类药物的抗胆碱能作用限制了其在老年人中的使用。
- **骨痛**：非甾体抗炎药（配合胃黏膜保护，肾功能损害和心力衰竭时慎用）；**姑息性放疗**，常为单次分割，能缓解大多数患者骨转移灶引起的疼痛；双膦酸盐或地舒单抗（denosumab）以减少骨相关事件。
- **神经受压、肝包膜痛和颅内压增高**：糖皮质激素（地塞米松（dexamethasone））减轻肿瘤周围水肿。
- **肠梗阻引起的绞痛**：解痉药，如丁溴东莨菪碱（hyoscine butylbromide）。
- **操作性治疗**：神经阻滞（例如胰腺癌疼痛的腹腔神经丛阻滞），以及在选定病例中的椎管内镇痛。

::: example 需要三种治疗的骨痛 {#ex-bone}
Ngozi Eze夫人67岁，患乳腺癌伴右股骨转移。她大腿持续酸痛，行走时加重。吗啡只部分缓解了疼痛，而且让她嗜睡。还应该做什么？
::: solution
**评估骨骼。**股骨转移灶负重时疼痛，提示可能即将发生病理性骨折。需要X线检查和骨科意见：可能需要预防性内固定，随后进行放疗。

**骨痛的治疗**：股骨姑息性放疗（单次分割治疗常用且有效）；如果肾功能和其他风险允许，使用非甾体抗炎药并配合质子泵抑制剂；按肿瘤科医生的建议继续使用骨靶向药物（双膦酸盐或地舒单抗）；把阿片类药物调整到最低有效剂量以减轻嗜睡。

**检查并发症**：恶性高钙血症（口渴、便秘、意识混乱、恶心、嗜睡；检查校正血钙），它可能解释她的嗜睡；如果出现背痛或神经症状，还要考虑转移性脊髓压迫。

骨痛常常需要多种方法联合；单纯增加阿片类药物往往会增加副作用，却控制不了与活动相关的疼痛。
:::
:::

::: warning 转移性脊髓压迫
癌症患者新出现的背痛，尤其是胸背痛、平卧时加重或呈束带样分布的疼痛，可能是**转移性脊髓压迫（MSCC）**的首发表现。不要等到出现肢体无力、感觉丧失或括约肌功能障碍，那时功能往往已经永久丧失。NICE指南（NG234，2023）建议紧急评估并进行全脊柱MRI检查（如有神经症状或体征，在24小时内完成；某些情况下更快），对有神经功能缺损者使用糖皮质激素，并以放疗或手术作为确定性治疗。
:::

## 气促、咳嗽与分泌物 {#sec-breathlessness}

::: definition 晚期疾病中的气促 {#def-dyspnoea}
**气促**是对呼吸不适的主观体验。它与血氧饱和度或呼吸频率的相关性并不密切：一个人可能在血氧饱和度正常时也非常气促。在晚期疾病中，气促源于疾病本身（肿瘤、积液、心力衰竭、慢性阻塞性肺疾病、神经肌肉无力）、并发症（感染、贫血、肺栓塞），以及它所引发的焦虑和惊恐，而焦虑和惊恐又会加重气促（呼吸—思维—功能循环）。
:::

在适当时**治疗可逆的原因**：引流胸腔积液，治疗感染或心力衰竭，对有症状的贫血输血，对肿瘤所致气道梗阻考虑放置支架。

**非药物措施**对慢性气促的证据最好：对着面部吹的**手持风扇**（面部感受到凉风可减轻气促感）、呼吸技巧、体位、合理安排活动节奏、在可能时进行肺康复，以及应对气促危机的书面计划。专门的气促服务把这些措施结合在一起。

**药物**：

- **阿片类药物**小剂量广泛用于晚期疾病的气促，尤其是静息时的气促和生命最后几周。证据并不一致：早期的小型试验提示有益，但近期较大规模的试验，包括慢性阻塞性肺疾病中的BEAMS试验（Ekström等，2022），在主要结局上并未显示规律小剂量缓释吗啡对慢性气促有益。因此，使用应个体化并加以复评。
- **苯二氮䓬类药物**（例如舌下劳拉西泮（lorazepam）或咪达唑仑（midazolam））在焦虑和惊恐突出时可能有帮助，但不是气促本身的一线治疗。
- **氧疗**对低氧血症患者有帮助。对于气促但无低氧血症的人，一项随机试验（Abernethy等，2010）发现，经鼻导管给氧并不优于给予医用空气；风扇更简单。

**咳嗽**可能通过治疗病因、单纯止咳糖浆或小剂量吗啡、可待因等阿片类药物缓解。生命末期**有声的呼吸道分泌物**见[[geriatrics-palliative/end-of-life-care]]。

## 恶心、便秘及其他症状 {#sec-other}

::: definition 按机制选择止吐药 {#def-other}
晚期疾病中的恶心和呕吐，处理方法是识别可能的**机制**，并选择作用于相应受体的止吐药：

| 机制 | 典型原因 | 一线止吐药（举例） |
|---|---|---|
| 化学性（化学感受器触发区） | 阿片类、高钙血症、肾衰竭、其他药物 | 氟哌啶醇（多巴胺D2拮抗剂） |
| 胃潴留 | 阿片类、肝大、腹水、自主神经功能衰竭 | 甲氧氯普胺或多潘立酮（促动力药） |
| 前庭性或与运动相关 | 运动、小脑或前庭疾病 | 赛克力嗪（cyclizine，抗组胺药） |
| 颅内压增高 | 脑肿瘤或脑转移 | 地塞米松加赛克力嗪 |
| 肠梗阻 | 腹部或盆腔癌症 | 见下文；完全梗阻伴绞痛时避免使用促动力药 |
| 焦虑 | 预期性恶心 | 处理恐惧；必要时用苯二氮䓬类 |

当原因不明或涉及多种机制时，常使用左美丙嗪（levomepromazine）等广谱止吐药。同时治疗可逆的原因（便秘、高钙血症、药物、感染、颅内压增高）。
:::

甲氧氯普胺和氟哌啶醇是多巴胺拮抗剂，帕金森病和路易体痴呆患者应避免使用；有时改用较难通过血脑屏障的多潘立酮（domperidone），但需注意其心脏风险。

**便秘**在使用阿片类药物时几乎普遍存在，因为对这一作用不会产生耐受。从一开始就应规律使用缓泻剂：通常是刺激性泻药（番泻叶、比沙可啶），加或不加软化剂或渗透性泻药（多库酯钠、聚乙二醇）。如果使用缓泻剂后便秘仍持续，在排除肠梗阻的前提下，可使用**外周作用的μ阿片受体拮抗剂**（PAMORA），如纳洛西醇（naloxegol，口服）或甲基纳曲酮（methylnaltrexone，皮下注射）。直肠指检，必要时使用栓剂或灌肠，可处理粪便嵌塞。

::: example 恶性肠梗阻 {#ex-mbo}
Julia Bennett夫人69岁，患晚期卵巢癌伴腹膜病变。她有腹部绞痛、腹胀，每天一到两次大量呕吐。她已五天没有排便。CT扫描显示小肠多处梗阻。经判断无法手术。请概述她的处理。
::: solution
多处梗阻的恶性肠梗阻很少适合手术。处理的目标是缓解疼痛、恶心和呕吐，同时如果她愿意，允许她少量饮水和进食。

- **给药途径**：口服吸收不可靠，因此通过皮下持续输注泵进行**持续皮下输注**给药，并在需要时追加皮下剂量。
- **疼痛**：持续性疼痛使用皮下阿片类药物；绞痛使用**丁溴东莨菪碱**（一种不通过血脑屏障的抗毒蕈碱药），它还能减少胃肠道分泌。
- **恶心和呕吐**：氟哌啶醇或左美丙嗪。有绞痛和完全梗阻时避免使用甲氧氯普胺等促动力药，因为它们会加重绞痛。
- **分泌物**：丁溴东莨菪碱；如果呕吐量仍大，加用**奥曲肽**（octreotide）进一步减少分泌。
- **糖皮质激素**：试用地塞米松可减轻梗阻部位的水肿，在部分患者中有助于梗阻缓解；如约一周内无效则停用。
- **减压**：可短期使用鼻胃管；对于持续大量呕吐，减压性胃造瘘是一种选择。
- **液体和营养**：口腔护理必不可少；如果她愿意，可少量啜饮，并为享受而进食。是否给予胃肠外补液或营养，根据她的预后和意愿个体化讨论。

解释如果恶心得到控制，每天呕吐一两次可能是可以接受的结果，并与她商定目标。
:::
:::

### 其他症状

- **厌食和恶病质**：癌症恶病质所致的体重下降由炎症和代谢改变驱动，单靠进食无法逆转。处理的重点是本人和家属的痛苦：少食多餐、为享受而进食、治疗可逆的原因（口腔问题、恶心、便秘、抑郁）。糖皮质激素可短暂刺激食欲。
- **疲乏**：非常常见。治疗可逆的促成因素（贫血、高钙血症、抑郁、失眠、药物），合理安排活动节奏，在生命末期可考虑短期试用糖皮质激素。
- **瘙痒**：取决于病因。所有人都使用润肤剂。**胆汁淤积性瘙痒**，如有可能应解除胆道梗阻（放置支架）；所用药物包括舍曲林（sertraline）、利福平（rifampicin）和纳曲酮（naltrexone），需在专科意见下使用。**尿毒症性瘙痒**，常用小剂量并按肾功能调整的加巴喷丁；地法链菲（difelikefalin）获准用于血液透析患者。抗组胺药在这两种情况下帮助都不大。
- **焦虑和抑郁**：常见且可治疗，可给予心理支持，在适当时使用抗抑郁药（注意起效时间）或短效抗焦虑药。
- **口腔护理**：口干或口腔疼痛（由药物、氧疗或念珠菌病引起）造成相当大的痛苦，而且容易治疗。
- **恶性高钙血症**（急症）：静脉补液并静脉给予双膦酸盐，前提是确认治疗符合本人的目标。

::: example 抗组胺药无效的瘙痒 {#ex-pruritus}
Ibrahim Saleh先生84岁，患慢性肾脏病5期，选择了保守性肾脏管理。他全身瘙痒，夜不能寐。皮肤干燥，有搔抓痕迹。他一直在服用氯苯那敏，这让他嗜睡，却没有止痒。你会怎么做？
::: solution
这很可能是**尿毒症性（慢性肾脏病相关）瘙痒**，它主要不是由组胺介导的，因此抗组胺药帮助不大。氯苯那敏还具有很强的抗胆碱能作用和镇静作用，会增加这位老年男性跌倒和意识混乱的风险：停用它。

处理：规律、充分地涂抹**润肤剂**，避免热水浴和肥皂；剪短指甲；检查并纠正促成因素（皮肤干燥、血磷升高、缺铁、其他药物、疥疮等皮肤病）。如果瘙痒持续，常用小剂量**加巴喷丁**，并按他极低的肾功能调整剂量，同时监测嗜睡和头晕。地法链菲获准用于血液透析患者，因此对他不适用。评估他的睡眠和情绪，瘙痒会影响两者。目标是舒适，与他所选择的保守治疗路径相一致。
:::
:::

一位因癌痛规律口服吗啡的女性出现了恶心。她已五天没有排便。最恰当的第一步是什么？
- [ ] 加用赛克力嗪
- [ ] 换用芬太尼贴剂
- [x] 评估并治疗便秘，复查缓泻剂方案

便秘是使用阿片类药物者恶心的常见可逆原因。进行评估（包括腹部检查，如适当还包括直肠指检），治疗便秘，并确保开具规律的缓泻剂。治疗原因先于加用止吐药（[[#thm-principles]]、[[#def-other]]）。
:::

## 探索：为什么剂量调整要等待稳态

::: widget plot
f: 1-exp(-0.693*x/h)
sliders: h=3:2:24:0.5
x: 0, 72
y: 0, 1.05
hlines: 0.94
labels: \text{稳态水平的分数}
caption: 规律给药时，药物（或其活性代谢物）的水平按曲线$1 - e^{-0.693t/t_{1/2}}$趋近稳态，经过四个半衰期达到约94%（虚线）。滑块设定以小时为单位的半衰期。半衰期约3小时时，一天之内即可达到稳态，这就是口服吗啡剂量通常每天调整一次的原因。肾功能下降时，吗啡代谢物的半衰期延长，肾衰竭后中毒可在数天内逐渐累积。这是一个教学模型，不是剂量计算工具。
:::

## 后续内容

阿片类药物的药理学见[[pharmacology/drug-receptor]]和[[pharmacology/dosing-principles]]。生命最后几天的照护，包括皮下持续输注泵和预期处方，见[[geriatrics-palliative/end-of-life-care]]。谵妄在[[geriatrics-palliative/delirium-dementia-care]]中讨论，肾功能损害时的处方在[[geriatrics-palliative/polypharmacy]]中讨论。

::: history
19世纪初，德国药剂师Friedrich Sertürner从鸦片中分离出吗啡，但由于担心成瘾和缩短生命，它在临终患者疼痛中的应用长期受到限制。20世纪50至60年代，Cicely Saunders及其同事证明，在疼痛复发之前规律给予口服吗啡，可以控制大多数患者的癌痛，而不会导致剂量不断升级或成瘾；20世纪70年代，Robert Twycross在圣克里斯托弗安宁院研究了口服吗啡和二醋吗啡，表明两者口服时同样有效。1986年，世界卫生组织出版了《癌痛缓解》（*Cancer Pain Relief*），提出了三阶梯镇痛法，帮助口服吗啡成为全世界的基本药物。获得机会仍然极不平等：许多中低收入国家至今仍难以获得口服吗啡。
:::

::: summary
- 评估每个症状及其机制，加以解释，在适当时治疗可逆的原因，采用基于机制的措施进行处理，并频繁复评。
- 把疼痛分为伤害感受性（躯体性、内脏性）和神经病理性；大多数癌痛是混合性的。
- 口服吗啡通常是首选的强阿片类药物。开具规律剂量和爆发痛剂量（常为每日总剂量的六分之一）、缓泻剂，以及必要时的止吐药。
- 肾功能损害时吗啡代谢物蓄积；警惕嗜睡、肌阵挛和幻觉，并换用对肾脏依赖较少的阿片类药物。
- 换算比例是近似的：口服吗啡换算为皮下吗啡除以2；换算为皮下二醋吗啡除以3；口服吗啡换算为羟考酮除以1.5–2。因中毒而转换时减量25–50%。
- 对神经病理性疼痛和骨痛使用辅助药物；新发背痛要想到MSCC，嗜睡要想到高钙血症。
- 对于气促，风扇和非药物措施优先；仅对低氧血症给予氧疗；阿片类药物个体化使用，证据并不一致。
- 按机制选择止吐药；帕金森病患者避免使用多巴胺拮抗剂；完全梗阻时避免使用促动力药。
:::

## 习题

::: exercise 每日总剂量与爆发痛剂量 {level=1 check="90/6"}
一位女性每天两次服用缓释吗啡30 mg，过去24小时内需要三次速释吗啡10 mg的爆发痛剂量。计算她的每日总剂量，并按TDD的六分之一计算新的爆发痛剂量（单位mg）。
::: solution
TDD $= 30 \times 2 + 3 \times 10 = 60 + 30 = 90$ mg口服吗啡。爆发痛剂量$= 90 / 6 = 15$ mg。如果在这些剂量下她的疼痛得到控制且没有副作用，可按当地指南把规律剂量增加到与TDD相符的水平，例如45 mg每日两次。
:::
:::

::: exercise 口服吗啡换算为皮下吗啡 {level=1 check="90/2"}
一位每天口服90 mg吗啡的男性已不能吞咽。按2:1的比例，皮下持续输注泵24小时应输注多少皮下吗啡？
::: solution
$90 / 2 = 45$ mg皮下吗啡/24小时。皮下爆发痛剂量约为其六分之一，即$45 / 6 = 7.5$ mg。具体处方取决于当地指南和可用的药物规格。
:::
:::

::: exercise 选择止吐药 {level=1}
为以下每种情况推荐一线止吐药：(a)一位男性患高钙血症，在纠正血钙期间出现恶心；(b)一位肝转移女性有早饱感，饭后呕吐未消化的食物；(c)一位脑转移男性有晨起头痛和呕吐。
::: solution
(a)化学性原因：氟哌啶醇，同时治疗高钙血症。(b)胃潴留（胃受压）：如果没有完全梗阻，用甲氧氯普胺等促动力药。(c)颅内压增高：地塞米松减轻脑水肿，配合赛克力嗪。
:::
:::

::: exercise 口服吗啡换算为皮下二醋吗啡 {level=2 check="120/3"}
一位每天口服120 mg吗啡的女性改为皮下二醋吗啡（diamorphine）输注。按口服吗啡与皮下二醋吗啡3:1的比例，24小时二醋吗啡剂量是多少（mg）？按六分之一计算，皮下爆发痛剂量是多少？
::: solution
$120 / 3 = 40$ mg二醋吗啡/24小时。爆发痛剂量为$40 / 6 \approx 6.7$ mg，实践中按当地指南取整为便于抽取的剂量。二醋吗啡溶解度很高，因此在需要以小体积给予大剂量时很有用。
:::
:::

::: exercise 吗啡换算为羟考酮 {level=2 check="90/1.5"}
一位每天口服90 mg吗啡的男性因吗啡引起的瘙痒和恶心难以忍受，改用口服羟考酮。按吗啡与羟考酮1.5:1的比例，不减量（疼痛已控制，没有中毒征象），他每天的羟考酮总剂量是多少mg？
::: solution
$90 / 1.5 = 60$ mg口服羟考酮/天，例如缓释制剂30 mg每日两次，速释爆发痛剂量约$60/6 = 10$ mg。有些指南采用2:1的比例，那样每天为45 mg；所用比例应遵循当地政策，而因中毒而转换时还要进一步减量。
:::
:::

::: exercise 处理气促 {level=2}
Dorothy Hill夫人78岁，患晚期慢性阻塞性肺疾病。她静息时气促，非常害怕，吸空气时血氧饱和度为93%。她要求吸氧。概述你的处理思路。
::: solution
评估可逆的原因（急性加重、感染、心力衰竭、贫血、气胸），并确保吸入治疗和吸入技术已达最优。她的血氧饱和度并不提示吸氧能缓解气促：氧疗对低氧血症患者有帮助，而对无低氧血症者，它并不优于空气。解释这一点，并提供手持风扇、体位、呼吸技巧和应对惊恐的气促计划。肺康复或气促服务可能有帮助。如果气促仍然严重，可以在密切复评下考虑试用小剂量阿片类药物，并解释证据并不一致；短效苯二氮䓬类药物可能有助于缓解惊恐。讨论她的目标和未来的照护。
:::
:::

::: exercise 终末期躁动还是可逆的问题？ {level=3}
Patrick Doyle先生70岁，患转移性肺癌，已躁动24小时，喊叫并试图下床。他正在使用皮下持续输注泵，24小时内输注吗啡30 mg和咪达唑仑10 mg。他的家属要求“用点更强的药”。列出必须检查的内容，以及应如何作出关于镇静的决定。
::: solution
在增加镇静之前先检查可逆的原因：尿潴留（触诊或扫描膀胱）、便秘或粪便嵌塞、疼痛（包括受压部位和体位）、阿片类中毒（肌阵挛、肾功能）、高钙血症、缺氧、感染、药物或酒精或尼古丁戒断，以及恐惧或灵性痛苦。检查输注泵是否正常运行、穿刺部位有无炎症。如果他正处于濒死期，在处理原因后躁动仍令人痛苦，那么增加咪达唑仑或加用抗精神病药（例如左美丙嗪）是恰当的，目标是能缓解痛苦的最低剂量。向家属解释正在发生的事情以及治疗的目的。在生命末期为缓解难治性痛苦而进行的相称镇静是合法且合乎伦理的；它的目的是舒适，而不是缩短生命；应记录决定、理由和复评情况，必要时寻求专科姑息治疗意见。
:::
:::

::: exercise 癌症男性新发背痛 {level=3}
Michael Turner先生66岁，患前列腺癌，已知有骨转移。他诉一周来背部中段出现新的疼痛，平卧时加重，并呈束带样向胸部扩散。他感觉双腿“有点沉”。他的血钙正常。最可能的诊断是什么？有多紧急？应该怎么做？
::: solution
骨转移患者出现新发胸背痛、平卧加重、束带样放射，并有主观的下肢沉重感，提示**转移性脊髓压迫**，并可能已有早期神经受累。这是肿瘤急症。步骤：立即与当地MSCC协调员或急性肿瘤团队讨论；全面的神经系统检查（肌力、感觉平面、反射、膀胱和肠道功能）；紧急全脊柱MRI（鉴于有神经症状，按NICE NG234在24小时内完成，如病情恶化则更快）；在等待确定性治疗期间按当地方案使用糖皮质激素（地塞米松）；镇痛；如存在机械性不稳定，采取脊柱保护措施。确定性治疗通常是放疗，部分选定患者采用手术。结局主要取决于治疗时他的行走能力，这就是为什么等到无力明显才处理是严重的错误。
:::
:::
