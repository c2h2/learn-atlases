症状控制是姑息医学的药理学：让一剂吗啡可被处方的是同一套阿片受体科学、而解释它的便秘与恶心及肌阵挛、及靠轮换获得的解救也是同一套；而同样的评估语法（这个症状在对这个人做什么、什么在驱动它、已经试过什么）比任何单一药物做的工作都多。**本章涵盖疼痛（机制的判读——伤害性、骨性、内脏性、神经病性——镇痛阶梯的现代形式、带转化与轮换及不良反应管理的阿片处方手艺、辅助药与干预），呼吸困难与咳嗽及分泌物、按机制选择的恶心呕吐药理学、作为“没有人在故意杀死患者、而患者却因它而死”的那个症状的便秘、带着它诚实上限的恶病质与厌食、及包括被正确执行的姑息镇静程序在内的谵妄与难治症状。它的方法那句话：治疗机制、命名期望、并带着一个数字复审——“好一些了”不是一个剂量；“疼痛3/10、走到花园、睡了五小时”才是。**

## 疼痛

::: definition 疼痛：机制、阶梯与阿片手艺 {#def-pain}
**决定处方的那个评估：世界卫生组织传统的阶梯从一步的非阿片到三步的强阿片、伴随2020年代对其慢性非癌用途的重新思考、而在癌与终末疼痛上大体完整保留、及2022年世界卫生组织更新对其他情境的非阿片强调、加上真正挑选药物的机制判读：躯体伤害性对乙酰氨基酚与非甾体及阿片按比例应答的酸痛、骨痛转移灶的运动诱发痛——单次放疗的证据、弥漫成骨病变的放射性核素、即将发生的病理性骨折的骨科稳定、及双膦酸盐与地舒单抗这层骨保护药是伪装成镇痛药的药、及快速减轻骨膜水肿的地塞米松、内脏性阵发、牵涉、带自主神经成分——腹腔神经丛阻滞用于胰胆疼痛那类介入名单、及解痉药之问、神经病性烧灼、电击、异常性疼痛、对单用阿片应答差、而阶梯二层的邻居比三层更重要（阿米替林与去甲替林及度洛西汀及加巴喷丁普瑞巴林邻近的证据、带着它们在老年人中的镇静与跌倒及滴定现实、及用于局限区域的外用利多卡因与辣椒素）、及混合与总痛层肌痉挛与压迫与恐惧放大、及“这疼痛是我的身体在告诉我我正在死去”这层镇痛药碰不到的意义、而心理建构可以碰。本专科教授的阿片手艺：定时给药加突破剂量的结构背景加解救原则——突破剂量约为每日背景量的十二分之一到六分之一、及解救剂量被反复使用时的加量算术：把背景量提高突破剂量所消耗的总量、因为这一句话就是整个滴定的算法、口服优先皮下其次的路径每个姑息药师都背得出的输注泵配伍与禁忌表、及肌肉注射作为酷刑应避免、转化表与它们的谦逊吗啡对羟考酮与芬太尼透皮及美沙酮的比例、这就是为何美沙酮的转化表彼此不同、为何轮换在计算之后要为交叉耐受打折并重新滴定、及为何当驱动因素是神经毒性或无效时轮换是一次重新开始而不是一个交换、被主动而不是被动管理的不良反应账本下面在自己定义里讲的那个永不耐受的便秘、通常在数日内随一个止吐药与更慢的滴定而缓解的恶心、及通常会上去的镇静除非剂量跑到了需求前面、肾功能受损时毒性阿片蓄积的肌阵挛与异常性疼痛及痛觉过敏、带着它的代谢物化学吗啡-3-葡萄糖醛酸与-6-葡萄糖醛酸、及其他药物的去甲代谢物、及为何芬太尼与美沙酮及丁丙诺啡是肾更安全名单——这是医学中收益最高的姑息事实之一、及各自的检查流程尿潴留与出汗与瘙痒、因为不是所有阿片瘙痒都是阿片引起的；及最后的处方文化要点：持续性疼痛要定时而不是按需给药、因为给药计划就是依从性科学、而持续性疼痛中的按需镇痛是一个恐慌协议例外是真正的那触发性疼痛、预先进给药就是为了换药与走路与洗澡、泻药与第一剂阿片一起开、而不是第四天之后、及在有指征的骨与包膜及神经压迫的炎症中第一剂就给激素、及另一端的停与减规则当放疗起效时的降级、因为疼痛轨迹是一个像肌酐一样的处方输入。介入与放射层作为转诊时机的能力腹腔与上腹下及半月神经节阻滞、及鞘内泵及神经松解、用于继续加量只会带来镇静的疼痛、及“我们还能请谁”的反射、因为2020年代的姑息医学不是口服治疗加听天由命、而多数医师至今仍这么以为。**

## 呼吸困难与分泌物

::: definition 呼吸困难、咳嗽与分泌物 {#def-dyspnoea}
**晚期疾病中的呼吸困难：评估把值得治疗的可逆贡献因素可引流的积液与可阻塞的气道与为症状而不是数字输血纠正的贫血、及感染与心衰、及埋在癌病史里的那颗豌豆大的栓子、及药物副作用清单分开于那个终末的器质性通气需求状态、而那里的治疗就是症状医学与诚实；药理学：带系统综述与考科蓝支持的低位剂量全身阿片用于终末的难治呼吸困难阿片初治者从小的口服或皮下吗啡开始、并滴定到症状而不是呼吸频率——这正是家属与低年资医师都需一起听到的那个恐惧的答案：“这个剂量治疗那种空气饥饿、并且不会加速她的死亡”、若干按所述滴定的姑息给药研究支持这一点、作为二线或三线而不是一线的苯二氮䓬用于那条焦虑回路证据有限、而空气饥饿恐慌中的现实作用显著、时机是一种可教的技术、真正适应证是低氧的氧疗试验显示在非低氧的癌呼吸困难中、姑息氧疗相对于室内空气没有症状获益、及吹向面部的风扇带其出人意料地强的证据、及手持风扇成了安宁院自己水壶的东西、体位与呼吸控制与缩唇呼吸及节能、及早于终末生命医学数月就是呼吸困难医学的肺康复、及难治呼吸困难中的镇静作为对等的最后选项、包括姑息照护与伦理各章讨论过的器械与无创通气决定。咳嗽阶梯：病因优先清单血管紧张素转换酶抑制剂与鼻后滴漏及反流及可治感染及积液及气道支架时机、终末咳嗽的阿片抑制、讲清便秘与嗜睡、及那层润喉与蜂蜜与含片不是安慰剂医学、并如此声明、及带咳血预期计划的咳嗽“给我看看血”的规则与平静的陪伴、及快速镇静包裹、及深色毛巾、是本章病态的民间智慧被转成一个协议、因为它有效。分泌物：一个词穿着的两个不同问题充血性吵闹的终末分泌物、不痛、却是家属记住为溺水的那个声音、而抗毒蕈碱药丁溴东莨菪碱或格隆溴铵只能适度减少它、真正的治疗是重新摆放体位与解释——“她没有窒息、这只是累到无法吞咽的声音”——及神经病患者的唾液处理格隆溴铵与阿托品滴舌及异丙托溴铵喷雾邻近、及腮腺肉毒毒素注射、及吸引、其定位是家属培训而不是临床医师的治疗、及关于分泌物没人印在传单上的诚实一句：正在死去的人通常听得见、并被平静的声音安慰、即使无反应、这就是为何抗毒蕈碱药要与解释一起给、而不是取代它。**

**恶心与呕吐是受体地图：按通路选择止吐药——攻击多巴胺与5羟色胺2及组胺与毒蕈碱的广谱药左美丙嗪带着它的镇静与体位性低血压代价、及它在安宁院的主力地位、用于化疗与肾及颅内压升高成分的5羟色胺3类昂丹司琼格拉司琼、用于胃潴留与阿片恶心带其多巴胺激动副作用张力障碍与帕金森综合征、及输注泵里配伍禁忌的促动力药甲氧氯普胺、化疗止吐方案纳入时的神经激肽1拮抗剂、带其真实的化疗恶心试验证据及其镇静与代谢代价的奥氮平、用于痉挛性绞痛与机械成分的茶苯海明与莨菪类、并带肠梗阻陷阱对机械性梗阻用促动力药就是绞痛与呕吐、及恶性肠梗阻用奥曲肽加抑制分泌加激素加镇痛、伴或不带减压胃造口的内科处理、及本身就是一个预后决定的外科意见——这是姑息医学标志性的管理难题之一、值得下面一个完整的例子、带其广泛的恶性恶心及包膜及肝及脑转移角色、早上给、并带上胃保护与胰岛素意识之问的地塞米松、及苯二氮䓬是正确药物应对正确情况的那个预期条件性恶心。便秘：肠道里那个永不适应的阿片受体以刺激药为基础的泻药——番泻叶或比沙可啶——加上一个渗透性聚乙二醇或乳果糖、作为与阿片处方同时的标准、而不是事后补救、及必须先于每一个“她恶心又意识混乱”的入院故事的指检与溢出性失禁、及阿片之外的原因清单高钙血症与止吐药与抗毒蕈碱药与铁剂及液体不足与不动及肿瘤及脊髓及甲状腺功能减退及多发性骨髓瘤肾、及“她不吃了所以不饿了”的级联、及外周阿片拮抗剂的难治景观、及姑息专科医师每天做的泻药决定：肠道方案是一项常设医嘱、并随它所服务阿片的每一次剂量变化而复审。厌食-恶病质：本学科的诚实一章使“多吃点”成为一个残忍指令的细胞因子与代谢重编程、恶病质指数在若干癌中的预后权重、糖皮质激素与孕激素有真实的短期食欲与幸福感作用及其真实的短持续时间、而药用水麻酮的证据对恶病质不可靠、及营养支持——它是一种针对缺乏的治疗、也可以是一种针对愉悦的治疗、而应该与她一起决定、不是与一本饮食日志、及另一端舒适喂食的反向纪律：家属那句“她在饿死”需要这个解释——正在死去的身体不想要食物、而强喂就是误吸——而她愿意的话提供她最喜欢的味道、就是科学允许的那份照护；及本章末尾的谵妄与难治痛苦块：舒适允许时的可逆贡献因素搜寻阿片与激素与抗毒蕈碱药本身、及潴留与感染与高钙血症与低氧、及那个地塞米松与预后谈话属于一起的脑转移、以左美丙嗪或咪达唑仑按协议与家属同意滴定到痛苦而不是滴定到镇静目标的对症管理、终末激越的膀胱与肠道与疼痛与体位与恐惧的鉴别、及姑息镇静作为真正难治痛苦的具名程序对等剂量的逻辑、患者或代理的知情同意、并行的常规照护、及两只手都张开保持的与安乐死的区别——是伦理各章的分析、而本章是它的协议。**

一名68岁前列腺癌转移至腰椎：静息时深部酸痛4/10（吗啡已优化），尽管用了突破剂量而活动时仍9/10；站立困难；尚无肌力下降或感觉缺失；一张低年资记录写着地塞米松“算不上姑息”。

**按机制的多模式骨痛医学（[[#def-pain]]）：判读——”一个承重转移灶上、背景酸痛之上的运动诱发痛、是经典的机械加骨膜组合、单用阿片只会把它变成镇静、而今天没有神经体征并不是明天没有脊髓之问——全脊柱评估与稳定性影像属于紧急、不属于可选“；这套包——”疼痛部位单次外照射放疗与分次方案在止痛上等效的试验、带着诚实的再照射与骨折风险的警诫、及第一周内疼痛反跳的解释与预先给激素与剂量调整计划、骨保护药双膦酸盐或地舒单抗这层、带牙科与肾及低钙与维生素D的核查——药预防骨骼事件并降低疼痛轨迹、这就是为何它们在本章而不只在肿瘤那一章、带明确适应证与复审的地塞米松疗程骨膜与神经水肿成分、早上给、必要时胃保护与血糖监测、及当放疗接管时计划好的减停——那位低年资医师的轻视是文化中过时的那一半：当有时限并瞄准明确时、激素是正当的辅助、机械成分的骨科脊柱外科或放疗稳定化的意见一个疼痛而不稳定的病灶是一个管道问题、而重建可以胜过这里每一片药、及环绕这一切的镇痛算术背景加抗炎加如果是神经根性神经病的组合、活动与康复之前的预先给药、常设的泻药与止吐计划、及当放疗起效时向下重新滴定——因为疼痛轨迹是一个像肌酐一样的处方输入“；及谈话——”这疼痛是不是癌在长之问的诚实回答常常是的、这就是为何这个计划同时是一份请肿瘤团队重新评估全身控制的请求、及写下来的功能目标（站起来泡茶；和孙辈坐一会儿）作为结局来复审、而不是作为乐观。**

::: example 发痒的肾 {#ex-pruritus}
一名79岁拒绝透析（保守肾脏管理）的患者、滤过率8、因全身瘙痒无法入睡、皮肤干燥带抓痕、因疼痛在服口服吗啡；女儿在凌晨两点上网搜“肝功能衰竭瘙痒”。
::: solution
**把晚期肾病的瘙痒做对（[[#def-other]]、[[renal/chronic-kidney-disease]]）：机制核查——“尿毒症瘙痒不是一件事干燥皮肤与矿物骨及组胺及κ阿片邻近通路、及药物贡献因素、而可逆清单值得一次正规的过润肤剂作为药物而不是化妆品、肾团队仍可作为症状目标的磷控制、及阿片复审——吗啡自身的瘙痒与其在肾衰竭中的神经毒性、使转换为芬太尼或丁丙诺啡成为姑息肾脏学中收益最高的动作之一、及女儿搜索找到一半的鉴别：胆汁淤积与药物、及疥疮与干燥重叠的病因、值得排除一次“；治疗阶梯——”润肤剂与短时温水淋浴及白软化石蜡家族、及薄荷脑水剂这个老而可靠的药、及局限区域的外用辣椒素、及服务提供时的窄波紫外线B对难治尿毒症瘙痒有真实证据、主要为了睡眠而不是为了止痒的抗组胺药、因为尿毒症瘙痒不是单纯的组胺、而镇静本身就是对痛苦的一种镇痛、并就此说一句诚实的话、及米氮平与加巴喷丁普瑞巴林邻近的全身选项、带着让它们成为专科启动而非病房启动的肾剂量与镇静与跌倒的警诫、及那个真正需要在κ激动剂的胆汁淤积瘙痒对尿毒症证据之间洗清的严重问题、女儿会读到它、而应该先从你这里听到“；及姑息的框架——”这类症状会终结居家者的睡眠与耐心、而在一个好的保守肾脏照护门诊里它被当作疼痛一样认真地治疗：写在同一份急救药物文件里的瘙痒计划、被示范了润肤方案的社区护士以便它继续下去、设好的复审日期、及用一页纸的解释预先回答那次凌晨两点的搜索、因为在姑息医学里、家属的搜索引擎是一个合并症。**

::: exercise 书写输注泵处方 {level=1}
一名在家临终的患者已无法吞咽、口服吗啡每日总量60毫升为有效镇痛、而左美丙嗪已控制住她的恶心。转化并处方一个24小时皮下输注、加上按需药物、及你必须问的那个配伍之问。
::: solution
**输注泵处方基础（[[#def-pain]]、[[#def-other]]）：转化——”按本地指导做口服对皮下吗啡（或等效）的转化英国一个常见的比例是吗啡口服对皮下2:1——含X毫克的60毫升口服溶液按此转化——而比例表与分子选择因国家与肾功能而异、这就是为何姑息药师或本地姑息处方集是这张处方的共同签署人、而这个计算要像胰岛素一样被双人核对；混合——“吗啡或等效药加左美丙嗪或等效止吐药、若激越或肌阵挛是个问题则加减咪达唑仑、在具名的输注泵中配制并做配伍核查经典的配伍禁忌、及为何丁溴东莨菪碱与丙氯拉嗪及苯妥英及地西泮被排除在外、安宁院药房赖以为生的配伍图表在一通电话里回答、部位侧胸或大腿的细管留置针、若输注持续则轮换、及已知晓的快速输注速率设置“；按需层——”皮下突破剂量通常为24小时总量的十二分之一到六分之一用于疼痛与呼吸困难、用于严重激越的咪达唑仑、及以防万一的出血与癫痫剂量、按真实剂量处方、而不是写如危机则讨论这几个字、并给家访护士关于谁打给谁的书面指示“；及复查——”由任何到场者每日两次复审输注、因为输注泵是一份缓慢执行的处方、而它的剂量必须随着她的症状移动——最常见的现实错误是那台活过了自己适应证的泵、以及那个因没人调整它而学会不信任它的家属。**
:::

::: exercise 进行阿片边界谈话 {level=2}
一名45岁复发淋巴瘤伴复杂社会史（因既往阿片使用障碍、目前在美沙酮维持上稳定）因严重肿瘤疼痛入院。住院医师写道：“她的耐受是行为性的；为了安全，给她低于常规剂量的药。”纠正这个计划与这个想法。
::: solution
**阿片耐受是生理，不是品格（[[#def-pain]]、[[medical-ethics-law/professionalism-regulation]]、[[psychiatry/substance-use]]）：纠正——”美沙酮维持占据的正是镇痛需要的受体：她是交叉耐受的、因此她需要高于常规的阿片剂量才能获得镇痛、而给她不足剂量不是谨慎、是一件披着道德外衣的忽视；而维持治疗本身必须继续与处方服务核实、绝不能作为疏漏被停掉、因为在一个耐受患者身上的戒断本身就是急症、并带上被尊重的成瘾科单独计划；实操建设——“以能耐受的镇痛剂量定时给强阿片常常是常规起始需求的1.5-2倍、宽松的突破剂量并把消耗量作为它本就是的滴定数据来追踪、联合镇痛药与辅助药与介入选项、因为减轻阿片负荷胜过争论它、尿药物与药片计数监测（若要做）应作为临床支持而不是监控警察——疼痛医学的共识声明对此很明确、及一个具名的处方者跨团队拥有这个方案、因为断裂的续方正是每个人那个困难患者被制造出来的方式“；及这个想法——”耐受是行为性的这句话应该触发与在姑息病历上写下觅药行为同样的警报：有物质使用史的人的疼痛被治疗不足两次——一次被疾病、一次被临床医师的不适——而本章全部的历史就正是对此的抗议；美沙酮专特的药理学QT与代谢交互、及当美沙酮同时成为镇痛药时不完全交叉耐受的转化、是一张专科处方使姑息与成瘾医学的联合意见成为对他们两个都正确的升级。**
:::

::: exercise 处理终末谵妄 {level=2}
一名70岁胆管癌致终末期肝衰竭患者在晚8点突然激越：拉扯管路、恐惧天花板、认不出她的丈夫；生命体征稳定、无发热；在家服乳果糖与利福昔明、四天未排便；家属受惊、而病房想要“氟哌啶醇并约束”。
::: solution
**最后几日肝病的谵妄（[[#def-other]]、[[geriatrics-palliative/delirium-dementia-care]]）：与目标相配的那一次可逆性过筛——”肝性脑病中四天未排便就是一个治疗目标、而直肠冲洗或灌肠及各种路径给的乳果糖、及停掉任何致便秘或镇静的贡献因素、及膀胱扫描与低血糖及感染及低氧及低钠及出血的迅速核查、全都仍然有指征、因为它们治疗的是痛苦、不是日子“；环境——”带着一个计划在房间里的家属告诉丈夫这是什么、该做什么：平静的声音、熟悉的物品、灯留着因为黑暗更糟、他能持续做的重新定向、及会持续允许他这样做的护理人员、一位护士一项任务的连续性、及移除今晚不要紧的管路“；药物——”抗精神病药（氟哌啶醇或左美丙嗪低起始剂量）针对痛苦滴定、路径由肠道决定、并阅读而不是无视QT与肝的警诫肝衰竭的给药现实、及苯二氮䓬的双重角色：一般而言在谵妄中有害、对酒精戒断谵妄有用、并作为抗精神病药失败时的第二剂、而肝性终末激越常常需要它、用于难治痛苦的咪达唑仑输注、带与下面姑息镇静相同的伦理与同意流程、及拒绝约束：拉扯管路用藏起管子和陪着她来回答、而不是绑住她——这既更仁慈、而且按谵妄文献也更可能有效“；及家属那份治恐惧的药——”这个症状最常把一个好的死亡变成一段坏的回忆、所以解释肝与毒素与可逆且可处理的那个版本、对什么可修什么不可修诚实、留下来的许可、如果他睡不着，也给他一点安神药的提议、及10点前会有具名医师到场、都属于处方单的一部分。**

::: exercise 审计治疗不足 {level=3}
你的安宁院的转诊患者到来时带有：60%的持续疼痛病例仅有按需镇痛、40%的阿片使用者无肠道方案、22%在没有痛苦适应证的情况下启动了抗精神病药、35%的非低氧呼吸困难在生命尽头使用氧气、而一半的居家死亡缺少“以防万一”的药物。设计这个质量改进规划。
::: solution
**作为临床医学的处方质量（[[#def-pain]]、[[#def-other]]、[[clinical-skills/patient-safety]]）：诚实的定框——“这五个数字其实是一个数字：用习惯而不是机制治疗症状、而质量改进的设计遵循本章教的同一逻辑让正确的事成为默认、让错误的事可见“；干预——”入院用药对账工具、在屏幕上标记这五种模式、并给处方者发一行带理由的提示更少而瞄准更好的警报胜过警报风暴——多重用药各章的教训复用、带默认肠道方案与定时镇痛及附带按需剂的医嘱集针对那40与60%数字的选择架构、因为教育熬不过夜班、呼吸困难路径卡、让风扇与阿片成为容易的路径、而氧气成为一个需要理由的记录偏离非低氧给氧之问是一个系统温和度的测试：设备路径就是处方路径、在注册时而不是危机时的预期处方规则、并让社区护士与院外服务自动收到清单一半没有急救药物的居家死亡是一个戴着临床面具的传真与电子邮件问题、及带命运追踪的抗精神病药审计：每一例启动的抗精神病药都有一个适应证、一次复审与一个停止日期、而那22%每月带同行这一行重新报告、因为处方率透明度是唯一被证明能移动曲线的干预借自安老院文献；而每一例的路易体核查仍是安全关键“；测量与方法——”在标准化样本上每季度用评估者间信度重新计数这五个指标、加上作为过程结局的家属体验与护士信心调查、及加一个对偏离的年度混合方法复审这个女人为何在做氧疗图表行由临床医师在死亡病例讨论式会议上当众读给临床医师听、因为那是能在不损害人的自尊的情况下改变处方的格式“；及报告——”费率连同目标与差距及修补负责人一起公布在安宁院自己的质量页上、因为这个专科的创始人建立它的命题就是：未被治疗的痛苦是一个系统事实——这使得仪表盘是一份道德文件、而不只是一份管理文件。**

**症状控制的历史是医学最有效的药物被恐惧、被重新发现、并最终被正确给药的故事：十九世纪末的吗啡专利药与止咳糖浆时代、及随之而来的成瘾恐慌、这让1914年哈里森法案之后的美国处方变得令人望而却步、并给了二十世纪疼痛治疗不足一个长长的起跑优势、英国医用麻醉品使用的衰落圣克里斯托弗早期的病例名单本身就是一份记录、及Cicely Saunders的病历记录下癌痛如何未经检查也未经治疗；及现代的解救、它同时从两个方向到来：1970-80年代的内源性阿片受体科学Hughes与Kosterlitz的脑啡肽工作、及使理性轮换与副作用预测成为可能的受体药理学与公共的那一半1980年代显示癌痛一贯不被治疗的审计、反对阿片恐惧“最残忍的神话”的期刊社论、及后来把止痛框定为一项人权的说法、及1986年世界卫生组织癌痛阶梯、它因简单而被普遍抄写、却在全球被误读为一个加量保证、而不是一个机制与辅助药的菜单——本章一直在纠正这一点、及基本药物与全球可及性文献——一个高收入国家集团消耗世界吗啡的绝大部分、而人类多数从未能获得基本止痛药、及本章药物所依赖的模型清单与各洲姑息处方集工作。辅助药科学是按专科到来的加巴喷丁的带状疱疹后神经痛试验、及随后的抗抑郁与抗惊厥试验、被考科蓝疼痛组以让神经病镇痛成为药理学中被审计最严的角落之一的规律性逐药编目、止吐药的受体测绘把呕吐中枢生理转化为昂丹司琼的5羟色胺3受体工作、及肿瘤各章借用的神经激肽1拮抗剂与奥氮平止吐试验时代、呼吸困难证据——姑息氧疗试验、 床旁风扇研究与确立阿片用于难治呼吸困难、并对非低氧症状用氧持怀疑态度的考科蓝综述——是一个非药物装置（一个对着脸的电池盒）在一个适应证上击败一种药物姑息氧疗的罕见案例、以及尽管如此仍在被教授的证据。阴暗面的历史也在这里：阿片流行病自身的姑息邻近性普渡与萨克勒的故事、及那句播下“给阿片的患者中成瘾很罕见”的恶名昭彰的两句话短信——及由此产生的美国危机如何在可及性运动在国外取胜的确切十年里让临床医师对正当的癌痛处方退缩、2022年疾病控制中心指南修订与姑息照护学会的批评向公众重述了这次鞭梢般的反转；“对阿片的恐惧杀死的患者比阿片更多”如今可以作为一支文献而不是一句格言被引用；及姑息镇静与安乐死的邻近争论关于镇静与安乐死的注册库文献、伦理各章给它自己的一段。对一个学生的历史形状：本章几乎每一条“显然的”规则与阿片同开的泻药、呼吸困难用的风扇、梗阻用的奥曲肽、神经毒性用的轮换、骨痛用的激素之所以存在、是因为有人审计了治疗不足、有人做了试验、而当证据追上时、伦敦或休斯顿或班加罗尔或内罗毕某家安宁院里已经有人在手工做它了。——[[pharmacology/autonomic-drugs]]、[[medical-ethics-law/end-of-life-ethics]]、[[public-health/global-health]]。**

::: summary
- 先判读疼痛机制躯体、骨、内脏、神经病、总痛：阶梯决定强度、而机制决定药物组合与辅助药清单。
- 阿片手艺是算术加预期：定时的背景加按比例解救剂量、转化后减量再重新滴定、对肠道与恶心与镇静及神经毒性的主动管理、及按肾功能知情的药物选择。
- 呼吸困难用阿片治疗难治症状、用风扇、只在低氧时用氧、并用平静的解释；终末分泌物需要重新摆放体位、一个抑制分泌药、而解释胜过吸引。
- 止吐药按通路选择促动力、化学感受器触发板、抑制分泌、中枢、而对机械性梗阻用促动力药是一个有名字的处方错误：恶性肠梗阻是奥曲肽与抑制分泌与激素与镇痛与排气、不是甲氧氯普胺。
- 便秘永不耐受：以刺激性药为基础的方案与第一剂阿片同时开始、而难治病例需要一次检查与一次原因审计、不是第四种泻药。
- 恶病质有中度的短期药物而没有解药；舒适喂食就是照护；难治痛苦由带同意的、与常规照护并行的对等姑息镇静管理。
:::

## 练习

::: exercise 计算轮换 {level=1}
一名患者用口服吗啡60毫克缓释每日两次加10毫克可溶突破剂量每日四次、因神经毒性转换为口服羟考酮本地比例为口服吗啡对羟考酮每日总量1:1.5、并为不完全交叉耐受减少33%。算出起始的每日羟考酮总量与一个合理的背景加解救分配。
::: solution
**把算术展示出来（[[#def-pain]]）：24小时吗啡=120+40=160毫克；羟考酮等效=160/1.5这里的比例是对每日总量写成吗啡对羟考酮=1:1.5、即羟考酮剂量=160/1.5……明确写出你所用的约定——这才是技能≈107毫克/日；交叉耐受的减少33%给出约70毫克/日；实操的转化：缓释羟考酮30毫克每日两次背景60/日加10毫克可溶突破剂量约为每日背景量的六分之一、每一至两小时按需、带日记；及两个已不再给分而临床医师需要的要点：写出所用的约定比例应用于每日总量；在另一种约定中羟考酮是更强的分子所以它的数字更小——表格彼此不同、而读错一张是一个真实的过量机制、及在24-48小时带着解救剂消耗量重新给背景剂量复审。**
:::

::: exercise 选择止吐药 {level=2}
配对并说明理由：(a) 吗啡第2天的阿片恶心；(b) 糖尿病姑息患者的胃潴留模式；(c) 已知腹膜癌病的绞痛性呕吐；(d) 脑转移伴颅内压升高的晨起喷射性呕吐；(e) 每个化疗周期前的预期性恶心。
::: solution
**通路配对（[[#def-other]]）：(a) 促动力的5羟色胺4与多巴胺拮抗剂甲氧氯普胺阿片性胃潴留的机制、常随滴定与耐受而缓解、并注明张力障碍警告与输注泵配伍禁忌；(b) 甲氧氯普胺或多潘立酮作为促动力药、带QT警诫、并提及红霉素选项、因为姑息药师会建议它；(c) 停用促动力药、按肠梗阻处理：奥曲肽加丁溴东莨菪碱或格隆溴铵加地塞米松加左美丙嗪或氟哌啶醇、加上思考过的排气计划与记录在案的外科意见——这是本章的例子压缩成一张处方；d) 以5羟色胺3与地塞米松为主的方案昂丹司琼加上早上给的激素、及为全貌做的紧急影像与肿瘤复审、而这个恶心的时间规律诊断已经把它命名了；及e) 苯二氮䓬——唯一一个能治疗条件化反应的药物——加上为下一周期收紧的止吐方案按化疗致吐风险表纳入神经激肽1与奥氮平、因为预期性恶心是一个用学习理论与劳拉西泮治疗的学习问题、这在考试里是一句值得记住的话。**
:::

::: exercise 处理呼吸困难 {level=2}
一名74岁终末期慢性阻塞性肺病合并肺癌患者、因低氧在家吸氧、诉“空气饥饿在傍晚更糟、而我害怕吗啡让我上瘾或让我的呼吸停下来”。构建完整的计划。
::: solution
**作为整体症状的呼吸困难（[[#def-dyspnoea]]）：先搜寻可逆因素——”重新问积液之问、带其引流或留置导管选项胸膜各章的那一个、贫血与感染及心脏及栓子的贡献对着目标核查哪项检查会改变症状计划是唯一的指征、吸入剂与激素方案重新检查、并注意到激素肌病与肾上腺之问、因为慢性阻塞性肺病患者会同时被过度治疗与治疗不足“；用她的两种语言回答阿片谈话——”依赖：在剂量与这个症状上、躯体依赖是可预期的、而不是她上瘾这个词所背负的那个灾难终末疾病的慢性阿片文献不支持成瘾在这个人群中是一个有意义的风险、及滴定协议低位起始、例如阿片初治者用2.5毫克口服吗啡溶液、按书面计划滴定到症状、血氧饱和度与意识对着计划而不是对着她朋友的恐怖故事来监测、及它会让我停止呼吸用研究来回答正规滴定的阿片用于难治呼吸困难不加速死亡并改善空气饥饿——这就是为何处方与解释作为同一个干预一起发出“；及这套包的其余部分——”床旁风扇与打开的窗证据比本章多数药物更好、物理治疗师教的体位与缩唇与呼吸控制训练、她能控制的傍晚结构在最糟的那一小时之前预先给药、留给惊恐成分的苯二氮䓬她可以要求、但不作为默认、氧的核查既然癌已进展、她现在的饱和度、及便携钢瓶对床头浓缩器用于夜间、及诚实的非低氧只用空气的警诫——而她自己的氧正满足这一条、所以她该听听自己为何继续用、及若尚未转诊就转诊姑息照护、因为这个症状的管理是一个服务、而不是一张处方。**
:::

::: exercise 设计症状控制教学 {level=3}
你的综合医院的姑息联络团队在病房之间反复发现同样五个处方错误。为以下情形设计系统修补不是讲座：有阿片无泻药、持续性疼痛仅按需、梗阻中使用甲氧氯普胺、非低氧呼吸困难给氧、及害怕呼吸频率的咪达唑仑剂量。包括你的测量计划。
::: solution
**系统、不是讲座（[[#def-other]]、[[clinical-skills/patient-safety]]、[[geriatrics-palliative/polypharmacy]]）：有阿片无泻药——“电子处方的硬性停止、带覆盖与理由代码、及若干卫生系统测量到的成功、阿片医嘱集上预印的肠道方案而不是一张贴纸提醒人类要像人类、及药师在病房查房时依常设协议直接加药的权限、审计把该费率作为一类感染率式指标报告因为它表现像一个可预防伤害指标：基线、运动、持续列示；持续性疼痛仅按需——”默认缓释或定时镇痛并附带按需剂的医嘱集那个假设人类会遵循默认的选择架构、因为他们确实会、这是同一个戏法、而比教学环节有更强的证据、加上护理评估触发24小时内4次以上突破剂量促使那次重新滴定的电话——那张挂在床旁的升级协议就是对床旁的同一个戏法；已知梗阻中使用甲氧氯普胺——“对着诊断代码的处方核查一个带清楚理由的交互警报、因为这是那种人人都会接受的罕见警报、也是警报疲劳的答案：更少的警报、瞄准更好、及把正确组合放进病房冰箱与应用程序的恶性肠梗阻路径传单；非低氧呼吸困难给氧——”询问适应证的设备申请单、并把风扇与阿片选项并列列出、因为设备申请就是伪装成行为的处方行为这个人群中氧的真实伤害：绊线与虚假的安心、及对风扇的延误、及由呼吸治疗师主导的呼吸困难门诊作为通往良好症状医学的更容易的路径；害怕呼吸频率的咪达唑仑剂量——“由顾问医师提前签署的滴定指导与预印的以防万一协议、因为终末激越是由护士在接下来的10分钟管理的、不是由医师在接下来的40分钟协议驱动的症状滴定不缩短生存的证据基础、正是那个剂量必须携带的安心：把这个剂量治疗痛苦而不加速死亡这句话写进指南正文、而不是脚注、及一个带模拟日的人员能力与信心调查；测量——”逐病房每季度计数这五个指标、并做一次混合方法的年度复审费率与家属体验项、因为系统医学与愧疚之间的区别在于：系统版本可以被重新审计并改进、而愧疚版本会被那个理应受责的人忘掉。**
