姑息照护是在治愈不再是计划时治疗这个人的学科：总痛（Cicely Saunders的短语、仍是这个领域最好的诊断工具）、让那个短语可操作的跨学科团队、及把它重新组织起来的时机论证——姑息应当从诊断起就陪在治疗旁边、而不是在治疗结束之后。**本章涵盖哲学及其机制（整体评估、跨学科团队、各种场所及其筹资）、作为本专科真正操作技术的沟通技能集（不确定之下的预后诚实、照护目标与预先照护规划、希望的重新校准而不是希望的移除）、及现代姑息的按病实践：癌、带其晚期转诊丑闻的器官衰竭轨迹、保守肾脏管理、神经科门诊、处在分类系统尽头的痴呆与衰弱、及如今服务人数已超过传统住院模式的门诊姑息模式。它的两句统治性话语：“总痛是真实的、并在它的每一个成分上都可治疗”、及“预后之问从来不是全或无；它是接下来会发生什么、以及什么对你重要、在同一个谈话里被问起。”**

## 这门学科与它的机制

::: definition 姑息照护：哲学、团队与场所 {#def-discipline}
**基础是一个有临床后果的道德观察：将死之人同时在一个以上的维度上受苦——Cicely Saunders的总痛（躯体与心理、社会与灵性作为一个主诉一起到来：那个同时也是“怕成为负担”的骨痛、与兄弟那场未完成的争吵、及失去那份曾经就是自我的工作），她那一代人把它从一个牧师的洞见转换成一个评估模板；及圣克里斯托弗与现代安宁运动的第二个洞见：这个评估是一项团队运动、而团队需要一栋楼或一个家访模式或两者都要。团队的组成就是它的证据：受过症状科学训练的医学与护理人员、把困难谈话作为其主要工作的专科人员、药师（预期性处方与注射泵、及与难供应药物的沟通文献）、物理治疗师与职业治疗师（决定家中死亡是否可能的那套节能设备与浴室几何）、心理学家与咨询师、牧师与灵性关怀工作者（灵性病史工具——FICA与FOLEY及那个“你从哪里获得力量”之问、它对自述无神论者与对牧师一样能开启对话）、社会工作者（没有别人会开的福利与债务及住房及移民身份医学）、治疗师音乐与艺术及回忆工作、不是娱乐、及志愿者陪伴与照护者喘息、金斯基金与国家终末生命文件把它算作一项干预、因为研究支持它。场所及其诚实的地理：安宁院住院部（用于症状真正无法处理的那一小部分——别处做不了的专业症状控制、及预防照护者崩溃的短期托管、而它本身就是给照护者的预防死亡服务）、作为多数人首选的家（社区护士与安宁院居家及快速通道入院路径及院外时间的药物、及“凌晨三点我打给谁”这个比任何政策传单都更能决定死亡地点的问题）、医院联络与门诊（在多数服务中已占联系的大多数——早期姑息整合模式与晚期癌专业姑息照护的综述、显示症状负荷与生活质量、有时还有生存信号、及让姑息坐在化疗旁边而不是之后的同步照护模式）、护理院与痴呆轨迹（姑息照护是方法不是场所之争、这是当前专业文献的中心论点：安宁哲学随患者走进每一张床）、及各国记录的可及性不平等：非癌疾病转诊过晚或从不、少数族裔与乡村及多元性别及无家可归及学习障碍及监狱群体服务不足、儿童姑息医学作为一门自身学科、及使死亡地点成为一个邮政编码统计的筹资彩票——这就是为何本章把采购当作一个临床主题。时机证据一段：早期整合试验肿瘤门诊随机研究显示生活质量与情绪改善、并若干显示生存信号、及现在建议在晚期诊断而不是治疗耗尽时转诊的指导；实操的时机工具惊讶提问——“如果这位患者在一年内去世我会惊讶吗”——一个筛查提示而不是判决、下面的疾病轨迹识别、医院里用来标记生命最后一年复审谈话的触发工具、及邻近衰弱指数与骨折及器官衰竭预后医学的那片整本书的领域、之所以抵达这里是因为姑息转诊决定就是一个带电话号码的预后决定；及临床医师应当知道因为它决定计划的政策层持续照护资助的评估战场与个人预算相邻的自付、及一份资助复审与一份照护计划之间的区别、及家属不该被迫去学读的种种规则——这就是为何有时间的专科护士往往就是有尊严的几周与残酷的几周之间的差别。**

## 谈话

::: definition 目标、预后与预先照护规划 {#def-conversation}

## 反过来看的疾病

::: definition 跨疾病轨迹的姑息 {#def-trajectories}

::: example “没有床”的安宁院床位 {#ex-notavailable}
一名66岁胶质母细胞瘤患者、与丈夫及社区护士在家、夜间出现难以控制的呕吐与激越；社区护士三次致电安宁院入院部：“没有床、由全科处理、更差再打来”；她在凌晨4点死在救护车里。丈夫以书面提出严重事件审查的问题。
::: solution
**入院系统就是临床照护（[[#def-discipline]]、[[clinical-skills/patient-safety]]）：诚实的审查回答——“安宁院的首要功能是那部凌晨三点的电话、以及当家无法承受的症状危机到来时会出现的那张床；对一个正在死去患者的难控呕吐与激越、三次来电升级成更差再打来、无论床位统计是多少都是一次服务失败、而凌晨4点死在救护车上正是入院流程存在要预防的那个结局；一晚本应发生的事——”值班医师与专科护士用一份成文分类共同做电话评估（使好、想办法变得容易的不可处理症状标准：家庭静脉或皮下输注泵带咪达唑仑包裹与甲氧氯普胺、及院外药房发药、社区护士额外访视或安宁院日间护士与志愿者陪伴服务、带姑息投入的社区医院或普通内科病房作为桥梁、因为没有安宁院床位绝不能等于没有人管、及在危机结束之前就预约好的次日晨入院）；审查应当产出的系统修补——“由被授权开放床位并可处方的人员值班的24小时专业分诊电话床位管理者模式、记录在案的升级规则两次家庭处理失败来电=专家到场、不是第四通电话、安宁院之间的互助协议区域溢出、单个单元的忠诚文化抵制它、而每一起严重事件又重新推荐它、容量报告、显示那张总是满的床是否是正确日子里的正确那张床（短期托管对终末的构成及住院时长政策、及由中央解决的快速通道福利与收费规则、因为筹资恐慌常常才是真正的床位管理者）；及丈夫的信按医学希望被回答的方式回答——”事实、该道歉之处的道歉、具名的改变、及审查的副本、因为这个专科的创始人建立它的命题就是：一个正在死去的人绝不是一个床位管理问题、而严重事件审查就是这个命题被执行的方式。**

::: exercise 主持照护目标会议 {level=2}

## 通向何处

症状药理学是下一章（[[geriatrics-palliative/symptom-control]]）、拒绝与不予的法律架构在[[medical-ethics-law/end-of-life-ethics]]与[[medical-ethics-law/consent-capacity]]、濒死期的生理在[[geriatrics-palliative/end-of-life-care]]、而按疾病的细节从[[gastrointestinal/gi-bleeding-cancer]]、[[cardiovascular/heart-failure]]与[[renal/chronic-kidney-disease]]链接过来。

::: history
**姑息照护的历史先是一部传记、才是一门学科：Cicely Saunders那位在1950-60年代于圣约翰与圣若瑟安宁院工作的护士、社会工作者后来的医师、把现代安宁院理念——住院症状控制加家庭加志愿者加研究——与“总痛”这个词结合起来的人、她的通信与临床笔记使它可操作、并迫使英国医学注意到死亡是一门临床专科、终点是她创立的1967年开张的圣克里斯托弗安宁院、及随后跟随她在五大洲讲座而生的国际安宁居家照护的衍生网络；美国分支史由她1963年的讲座激发的家庭照护规划、与Elisabeth Kübler-Ross 1969年的《论死亡与临终》、本书被错误地冻结成五阶段、如今领域里每个人都把它当作关于简化的警告来教、而她实际的讲座讲的是倾听、1970年代的家庭安宁运动、及1983年的安宁给付立法、在一次立法打击中让美国这个领域的筹资结构化、也让资格争议化。第二阶段是科学的：1980-90年代的症状科学时代——阿片轮换与受体药理学的工作、及相关学会的期刊与教科书让症状证据可被引用、1990-2000年代的死亡质量测量时代、把大量医院与护理院的死亡命名为系统失败的医学研究所报告、及显示终末生命强度是邮政编码现象而非患者偏好现象的地理学图谱、及那个名字至今仍是代名词的支持研究“意愿通常被知道却很少被记录；不做心肺复苏的医嘱来得太晚；疼痛未被充分治疗；重症监护室的死亡缺乏尊严”发现触发了整整一代预先照护规划政策、而它2016年的重新分析承认干预未达预期——一个异常诚实地研究自身失败领域的诚实记录。早期整合的转向是当前这一章：肺癌与支持性照护的门诊试验、及把专业姑息从最后手段移到并行的标准、学术中心的支持姑息照护部门改名、及2010-2020年代的保守肾脏管理随机与队列规划、证明“透析或不透析”之问是一个虚假的两难、及仍在为资格争论而人口学反驳的“痴呆与衰弱的姑息照护”文献。阴暗的那条线、放在它该在的位置：被遗漏者的地图关于安老院与监狱及机构中死去者的“看不见就不在意”报告、及部分国家三分之一的人在死前没有任何姑息接触的审计发现、及卷入移民拘留与“敌对环境”政策将死者的报告、这把可及性之问用这个专科无法外包的政治语言表达出来。历史的轨迹：从伦敦南部的一栋房子、到一门与肿瘤科和肾内科及心内科就时机争论的医学学科、仍在为Saunders曾经争取的同一件事奋斗——死得糟糕通常是一次系统失败、而把它如此命名就是一个临床动作。——[[medical-ethics-law/end-of-life-ethics]]、[[public-health/health-systems-economics]]、[[geriatrics-palliative/end-of-life-care]]。**
:::

::: summary
- 总痛——躯体、心理、社会、灵性——是评估模板；跨学科团队带药学、治疗、灵性关怀、社会工作与志愿者就是治疗。
- 与疾病导向照护的早期整合改善症状、情绪、有时还有生存；晚期转诊是器官衰竭、肾、痴呆与衰弱队列中的主导失败。
- 预后诚实是区间、轨迹与具名不确定的手艺；价值谈话与计划属于一起、而人工物（预先决定、急救照护计划、代理人）必须能被必须遵守它的系统找到。
- 希望是被重新校准而不是被移除、而讲真话是与家属协商、不是强加给他们；“困难”的患者通常就是总痛。
- 按疾病的姑息现已是一门子专科：癌急症、器官衰竭危机、保守肾脏管理、运动神经元病门诊模式与痴呆方法、各有自己的脚本与证据。
- 死亡地点是一个系统输出：预期药物、具名的凌晨三点联系人、筹资导航与尽早的首选地点谈话、比床位更能决定它。
:::

在一个南亚家庭中、成年的子女们在走廊里找到你：“请不要告诉我们母亲癌症复发了；她会失去希望、死得更快。”她已经两次问你是否“一切干净”。你怎么做？
::: solution
**协商的真话（[[#def-conversation]]）：避免的第一个错误——“同意撒谎会毁掉三方都需要的唯一一样东西她对你的信任、以及他们对你的信任、以及你记录一次真实谈话的能力、而在走廊里断然拒绝会把一个悲恸中的家庭变成一个对手；文献与判例的答案是协商之路“；技术——”与家人一起的评估面谈：他们具体害怕什么、到目前为止告诉过她什么、她自己的过往记录是什么（那个问了两次的女人正在告诉她想获得信息——但要私下与她确认：你处境中的有人喜欢完整的细节、有人喜欢大致的图景——你是哪一种、谁应该在场的？）以尊重与隐私、及常常用一个不是家人的口译进行；然后是约定——“与家人商定的分阶段、跟着患者节奏的计划联合会议中诚实而有节制的语言、正是她日后会描述为”他们按我自己的速度告诉我“的东西、及被”这个计划保护她的希望而不是刺破它“这一事实争取过来的家人”；及记录——”谈话被记录在案、她陈述的信息偏好为凌晨两点的医师记录下来、以及她可以撤回或改变这一事实——计划是一个过程、而这个过程就是姑息；及那层元意识：她会失去希望的恐惧并不愚蠢：预后的披露在某些患者中确实带着真实的反安慰与痛苦风险、这正是节度存在的理由、也是为什么替代方案全家人共同保守、而她假装着死去的秘密是更差的医学。**

::: exercise 处理运动神经元病门诊的访视 {level=2}
一名57岁运动神经元病患者、功能下降、正在讨论无创通气、说“当我再也无法呼吸时、我想像父亲一样死在家里、而不是被绑在机器上”。这句话产生什么、到什么时候、在哪些文件里？
::: solution
**主动的预先照护规划门诊（[[#def-trajectories]]、[[#def-conversation]]、[[nervous-system/neuromuscular]]）：答案的组件——“她这句话是一份请求被书写出来的治疗计划：(1) 现在、在门诊、而不是在危机时进行通气机谈话无创通气的获益与负担、及升级会是什么样子、包括运动神经元病中的气管切开之问、在那里证据有限而这个选择真的让患者分流、我们可以开始也可以停止的规则移除了那台没有出口机器的陷阱、及她的答案被记录；(2) 预期症状包裹呼吸困难与疼痛及分泌物及焦虑的药物提前规划、带注射路径与输注泵的熟悉、及在急诊之前的安宁居家注册；(3) 预先决定她可能想做出的具体拒绝——插管、气管切开、在某阶段喂养管——以当前的能力评估书写、并在法律或门诊倾向之处由第二医师见证、及沟通路径计划眼控设备与辅助沟通板、现在就做、因为她表达意愿的能力是一种正在减少的资源——这是这种疾病最残酷的交互；(4) 实际事务带院外电话与家中药物及知晓计划的登记让救护车班组也知道的避免住院计划、及孩子们及葬礼及遗产的谈话、由专科护士在她还能参与时主持——及进度表：所有在这次访视中都是常规、因为运动神经元病门诊模式的定义性美德就是谈话在危机使它们不可能的数月之前发生、这就是姑息章节整个时机论证落在一种疾病上的样子。**

::: exercise 审计一个服务的公平性 {level=3}
审计请求：你的安宁院符合姑息照护资格的人群只覆盖41%的逝者；非癌疾病、安老院住民、少数族裔与无家可归患者代表性不足；住院部总是满的；居家护理的候补名单真实存在。撰写发现备忘录与干预集、每行标明负责人与指标。
::: solution
**作为临床工作的公平审计（[[#def-discipline]]、[[public-health/screening]]、[[clinical-skills/patient-safety]]）：发现的框架——”41%、且偏向恰好是系统一直知道如何服务的队列、这是一个服务设计的结果、不是一个偏好的发现、而床位统计的分母证明了我们看见哪些将死者、遗漏了哪些；必须与数字同做的访谈安老院的“我们不知道你们会来家里”、全科诊所的“我以为她已经归你们管了”、无家可归队列的“没人会从夜间收容所预约安宁院”、及家属们的晚期转诊故事、它们全都包含同样三句话中的一句：转诊路径不为人知、资格被假定、或信任从未建立“；带负责人与指标的干预——”自动标记路径急诊与内科病房标记惊讶提问阳性者、及骨折联络与肾及心衰门诊共同制定转诊触发、由联络团队负责；指标：从最后一年标记到转诊的时机、按诊断组、安老院与街头模式每个安老院群组一名具名联络护士、带抗精神病药与预期药物的门诊——也是谵妄痴呆各章的请求——及与药物酒精服务的伙伴关系、并带监狱与移民拘留倡导者为之奋斗的那同样的记录弹性；指标：安老院与露宿者的首选地点死亡率、语言与信任层社区组织与宗教团体伙伴关系、带付薪的社区引导员而不是六种语言的传单、及作为默认而非恩惠的口译预约系统、及关于家庭披露模式的人员培训；指标：分组报告的家庭调查公平项、容量的再平衡（住院部“总是满”的状态被审计：它是在服务不可处理的症状需求、还是在充当一扇本不该充当的前门；对快速通道入院与七天全天候护理的居家优先投资、因为容量规划在家属开口之前就写下了死亡地点曲线）；及问责——“带逝者队列分母与非癌代表性百分比的季度公平报告、向董事会内部并向服务的报告外部公布、因为这个专科的历史就是一个女人坚持的一件事：谁死得糟糕是一个系统事实、而审计就是一个现代服务证明它听见了她的方式。**
