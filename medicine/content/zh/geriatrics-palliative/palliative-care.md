每个人都会死亡，而在高收入国家，大多数人是在经历一段疾病之后去世的，而不是突然死亡。姑息治疗（安宁疗护）是医学中关注如何在无法治愈的疾病中尽可能好地生活、以及如何善终的部分。它不只用于最后几天，不只用于癌症，也不是积极治疗的对立面：它可以与化疗、透析或心力衰竭治疗同时进行，在某些情况下既改善生活质量，也延长生存期。

本章介绍什么是姑息治疗及由谁提供、人们走向生命终点的几种不同方式、如何识别可能处于生命最后一年的人，以及帮助人们获得他们所希望的照护的谈话和预立医疗照护计划。症状控制见[[geriatrics-palliative/symptom-control]]，生命最后几天的照护见[[geriatrics-palliative/end-of-life-care]]。

## 什么是姑息治疗 {#sec-discipline}

::: definition 姑息治疗 {#def-discipline}
世界卫生组织（2002）将**姑息治疗**定义为一种方法，它通过早期识别、对疼痛及其他躯体、心理社会和灵性问题进行无懈可击的评估和治疗，来预防和减轻痛苦，从而改善面临威胁生命的疾病相关问题的患者及其家属的生活质量。姑息治疗肯定生命，把死亡视为一个正常过程；既不加速也不推迟死亡；提供一个支持系统，帮助患者尽可能积极地生活直至死亡，并帮助家属应对患者患病期间和居丧期的困难；它适用于疾病的早期，可与其他旨在延长生命的治疗同时进行。
:::

这个定义中有三点值得强调。第一，照护的对象是患者**及其家属**。第二，痛苦有**多个维度**：Cicely Saunders称之为**全人疼痛**（total pain），意思是躯体疼痛会被心理痛苦（恐惧、抑郁）、社会问题（经济、家庭冲突、角色丧失）以及灵性或存在性痛苦（意义、内疚、死后会怎样）所塑造和加重。第三，姑息治疗在疾病**早期**就适用。

### 由谁提供

大多数姑息治疗是**通科**照护，由原本就在照顾这个人的专业人员提供：全科医生、社区护士、医院团队、照护机构工作人员，以及患者所患疾病的专科医生。**专科姑息治疗**团队（姑息医学顾问医师、临床专科护士及相关专业人员）为他们提供支持，并在医院、社区和安宁疗护院中诊治需求复杂的人；安宁疗护院提供住院床位、日间服务和居家安宁疗护。

在英格兰，国家框架《姑息与临终照护的愿景》（*Ambitions for Palliative and End of Life Care*，2021–2026）提出了六项愿景：把每个人视为独立的个体；每个人都能公平地获得照护；最大程度地提高舒适和福祉；照护是协调的；所有工作人员都做好照护的准备；每个社区都做好提供帮助的准备。自《2022年健康与照护法》（Health and Care Act 2022）起，英格兰的整合照护委员会依法有责任委托提供姑息治疗服务。英国大多数安宁疗护院是慈善机构，部分经费来自NHS。

::: theorem 早期姑息治疗改善结局 {#thm-early}
在严重疾病的早期，把专科姑息治疗与针对疾病的治疗结合起来，可以改善生活质量和情绪，减少生命末期的过度治疗，而不缩短生存期。在一项纳入151名新诊断的转移性非小细胞肺癌患者的随机试验中（Temel等，2010），接受早期姑息治疗的患者比仅接受标准肿瘤治疗的患者生活质量更好、抑郁症状更少、生命末期的治疗也不那么激进；其中位生存期也更长（11.6个月对8.9个月）。
:::

::: proof
早期姑息治疗同时改变了几件事。症状得到更充分的评估和治疗。患者和家属反复进行关于预后和目标的谈话，这帮助他们理解自己的疾病，并作出反映其优先考虑的治疗决定。在Temel试验中，早期姑息治疗组的患者在生命最后几周接受化疗的可能性更小，转介到安宁疗护的时间更早。生存期的差异是一个次要发现，其机制尚不确定；它可能反映了晚期激进治疗相关并发症的减少，以及对抑郁和症状更好的处理。随后在多种癌症以及某些非癌症疾病中进行的试验，也支持其在生活质量和情绪方面的获益。
:::

::: example 诊断时即转介 {#ex-early}
David Kim先生63岁，刚被诊断为伴肝转移的胰腺癌，正准备开始姑息性化疗。他有上腹痛和背痛，体重下降了8 kg，妻子说他睡不好。肿瘤科医生犹豫现在转介姑息治疗是否“太早”，因为他还在接受治疗。你的看法是什么？
::: solution
并不太早。转移性胰腺癌预后差，而他已经有疼痛、体重下降和痛苦。在化疗的同时开展早期姑息治疗有试验证据支持（[[#thm-early]]）。转介应被表述为额外的支持，而不是放弃治疗。

姑息治疗现在可以提供的：评估和治疗疼痛（胰腺癌疼痛常因腹腔神经丛受累而带有神经病理性成分；腹腔神经丛阻滞可能有帮助）、评估体重下降（胰腺外分泌功能不全很常见，可用胰酶替代治疗）、睡眠和情绪，以及对他妻子的支持。它还为逐步展开以下谈话提供了空间：什么对他最重要、他对自己疾病的理解，以及他对未来的意愿，从而使疾病后期的决定能以这些为依据。
:::
:::

## 临终的轨迹 {#sec-trajectories}

::: definition 疾病轨迹 {#def-trajectories}
关于生命最后几个月功能如何变化的研究（Lynn和Adamson，2003；Murray等，2005）描述了三种典型的**疾病轨迹**：

1. **短期明显衰退**，典型见于癌症：功能长期得以维持，随后在数周至数月内出现相当可预测的衰退。
2. **长期受限伴间歇性严重发作**，典型见于器官衰竭（心力衰竭、慢性阻塞性肺疾病、慢性肾脏病、肝病）：逐渐衰退，其间穿插急性加重，任何一次都可能致命，每次之后部分恢复。
3. **长期缓慢衰弱**，典型见于衰弱和痴呆：一开始功能就低，在数年中缓慢下降，死亡常在一次胸部感染或骨折等小事件之后发生。
:::

轨迹之所以重要，是因为它们决定了谈话的时机以及死亡的可预测性。在癌症中，衰退通常可以识别。在器官衰竭中，很难知道哪一次加重会是最后一次，患者常常在医院接受强化治疗时去世，却从未讨论过自己的意愿。在衰弱和痴呆中，生命末期可能长达数年，而且常常根本没有被认识到。

非癌症患者历来较少获得专科姑息治疗，尽管其症状负担与癌症患者相似甚至更重。获得照护的机会也因贫困程度、族裔和居住地而不平等，《愿景》框架把这列为优先事项。

### 识别生命的最后一年

临床医生对一个人还能活多久的估计并不准确。在一项针对转介到芝加哥安宁疗护项目的终末期患者的研究中（Christakis和Lamont，2000），医生的预测只有约20%落在实际生存期的三分之一误差范围之内，平均而言把生存期高估了约五倍。由于精确预测并不可靠，实践的重点是识别**可能**处于生命最后一年的人，以便规划照护。

提示这一识别的工具包括：

- **意外问题**：“如果这位患者在未来12个月内去世，我会感到意外吗？”如果答案是“不会”，就启动对目标和需求的评估。在一项荟萃分析中（Downar等，2017），它预测6至18个月内死亡的合并灵敏度约为67%，特异度约为80%；它是一个提示，而不是准确的预测工具。
- **一般性和疾病特异性指标**，如“支持与姑息治疗指标工具”（SPICT）和“金标准框架”（Gold Standards Framework）主动识别指南中的指标：体能状态下降、计划外住院、体重下降、最佳治疗下症状仍持续，以及疾病特异性标志（例如尽管治疗已最优化，心力衰竭患者静息时仍有症状；或慢性阻塞性肺疾病伴严重气流受限和频繁急性加重）。
- **体能状态量表**，如姑息体能量表（Palliative Performance Scale），它对功能进行分级，并在群体水平上与生存期相关。

一旦识别出来，就可以把这些人纳入初级医疗的姑息治疗登记，评估其需求，提供预立医疗照护计划，并与非工作时间服务共享其信息。

::: warning 等待确定性
一个常见错误是把姑息治疗的谈话推迟到死亡已经确定之时，而那时患者可能已病重到无法参与。不确定性是器官衰竭和衰弱的常态。谈话可以承认这种不确定性（“我希望你能在很长一段时间里保持良好，但我担心你的病可能会加重，我觉得我们也应该为此做些打算”），并在情况变化时重新讨论。
:::

::: example 心力衰竭：一边治疗一边规划 {#ex-hf}
Margaret O'Brien夫人81岁，患射血分数降低的心力衰竭和慢性肾脏病，植入了心律转复除颤器（ICD）。六个月内她因液体负荷过多住院三次，走过一个房间就气促，体重也在下降。她正在服用所有能耐受的心力衰竭药物。她的心内科医生请你和她讨论未来的照护。应涵盖哪些话题？
::: solution
她符合生命最后一年的指标：反复住院、尽管治疗已最优化但静息或轻微活动时仍有症状、体重下降和肾脏疾病。话题包括：

1. **她的理解和优先考虑**：她对自己心脏病的了解，以及对她最重要的是什么（例如待在家里、避免住院、某个家庭活动）。
2. **继续心力衰竭治疗**：只要利尿剂和其他药物有助于缓解她的症状，就继续使用；这既是疾病治疗，也是姑息治疗。
3. **ICD**：在她临近死亡时，ICD可能会释放痛苦的电击。应在她还能作决定时讨论关闭电击功能——这不会导致死亡，也不影响起搏功能。英国心脏基金会和英国复苏委员会的指导支持开展这类谈话。
4. **治疗升级和复苏**：她是否希望再次住院、接受强化治疗或心肺复苏；在晚期心力衰竭中，心肺复苏不太可能成功。把她的意愿记录下来，例如记录在ReSPECT表格上，可以帮助急救团队。
5. **她希望在哪里接受照护**，以及实现这一点所需的支持（社区心力衰竭护士、社区护士、部分服务可在家中给予胃肠外利尿剂）。
6. **症状控制**：气促、疲乏、情绪低落。

这些谈话通常分几次进行，如果她愿意，可以让家人参与，并记录下来与她的全科医生和非工作时间服务共享。
:::
:::

## 谈话与预立医疗照护计划 {#sec-conversation}

::: definition 预立医疗照护计划 {#def-conversation}
**预立医疗照护计划（ACP）**是一个人与其照护提供者、通常还有其亲近的人之间，就其价值观、目标和对未来照护的意愿进行讨论的自愿过程，以便在其日后丧失决策能力或无法交流时，照护能以这些意愿为指导。其成果可包括：关于意愿和偏好的**预先声明**（没有法律约束力，但在最佳利益决定中必须予以考虑）、**预先拒绝治疗决定**（有效且适用时具有法律约束力）、指定健康与福利方面的**持久授权书**受托人，以及急诊照护和治疗计划，如**ReSPECT**。
:::

根据《2005年精神能力法》（英格兰和威尔士），**预先拒绝治疗决定**（ADRT）必须由年满18岁且有决策能力的人作出，必须明确所拒绝的治疗；如果拒绝的是维持生命的治疗，还必须书面形式、签名并有见证人，并包含即使危及生命也适用的声明。一个人不能用预先决定来要求某种特定治疗。

**ReSPECT**（急诊照护和治疗推荐摘要计划）由英国复苏委员会及合作方于2016年推出，记录一个人对急诊照护的意愿和临床建议，包括（但不限于）心肺复苏。**不尝试心肺复苏（DNACPR）**决定是一个认为不应尝试心肺复苏的临床决定。在英格兰和威尔士，上诉法院于2014年（Tracey案）裁定，除非会造成身体或心理伤害，否则有义务让患者参与这一决定；意见分歧并不使医生有义务提供不会奏效的心肺复苏，但应告知患者，并为其提供第二意见。

### 如何进行谈话

有几个框架可以帮助组织困难的谈话。**SPIKES**（Baile等，2000）描述了告知坏消息的六个步骤：

1. **环境**（Setting）：隐私、坐下来、有时间、合适的人在场、不被打扰。
2. **认知**（Perception）：询问对方已经了解了什么（“关于这次扫描，别人是怎么跟你说的？”）。
3. **邀请**（Invitation）：询问对方想知道多少信息、希望以什么方式获得。
4. **告知**（Knowledge）：先预告坏消息要来了，再用浅显的语言分小段给出信息，并核实对方是否理解。
5. **情绪**（Emotions）：以共情回应情绪；允许沉默；说出对方的情绪（“我能看出这让你很震惊”）。
6. **策略与总结**（Strategy and summary）：商定计划和下一步。

其他有用的技巧包括**询问—告知—询问**（了解对方知道什么，告诉他们，再核实他们理解了什么），以及一边期望最好的结果、一边为最坏的情况做准备的方法。讨论预后时，鼓励临床医生诚实地说明不确定性，给出范围（“几周到几个月”，而不是“三个月”），并探询对方的希望和恐惧。

有些患者不想知道详细信息，有些家属要求对患者隐瞒信息。患者本人对信息的意愿优先；临床医生可以直接询问患者希望知道多少、希望谁参与，而不是凭一方的意见作出假设。

::: example 拒绝透析 {#ex-conservative-kidney}
Ernest Walker先生80岁，患慢性肾脏病5期（eGFR 9 mL/min/1.73 m²）、糖尿病和心力衰竭，CFS 6。医生建议他进行血液透析，但他说不想“在机器上度过最后几年”。他的女儿希望他接受透析。团队应如何回应？
::: solution
**决策能力与信息。**除非有理由怀疑，否则推定他具有决策能力；即使别人不同意，一个人也可以拒绝治疗。要确保他的决定是知情的：解释透析包括什么、对他这样年龄和衰弱程度的人可能的获益和负担（对有明显合并症的老年人的研究提示，透析带来的生存获益可能很小，而花在透析和住院上的时间相当多），以及替代方案包括什么。

**保守性肾脏管理**是一条积极的治疗路径，而不是“不治疗”：它包括贫血、液体平衡、血钾和酸中毒的管理，症状控制（瘙痒、疲乏、气促、恶心、不安腿），预立医疗照护计划以及对家属的支持，由肾脏科和姑息治疗团队共同提供。

**家属。**倾听他女儿的担忧；她可能担心父亲在放弃，或者不了解保守治疗能提供什么。在征得他同意后，让她参与讨论。决定权仍在他本人。记录讨论内容、他的决定和计划，并明确告诉他可以改变主意。
:::
:::

::: example “没有床位”的安宁疗护院 {#ex-notavailable}
Fatima Hassan夫人74岁，患转移性乳腺癌。她因日渐虚弱住院，被认为处于生命的最后几周。她希望在家中去世，但出院被耽搁了，因为当地安宁疗护院没有床位，工作人员便认为她只能留在医院。还有什么办法能实现她的愿望？
::: solution
安宁疗护院的住院病房只是几条途径之一。可选方案：(1)通过NHS持续健康照护的**快速通道**（Fast Track Pathway）安排居家照护，该通道允许为病情迅速恶化、可能进入终末期的人快速提供照护经费；(2)居家安宁疗护或社区专科姑息治疗护士；(3)通过共享照护记录告知社区护士、全科医生和非工作时间服务；(4)出院前把设备（医用床、减压床垫、坐便椅）送到家中；(5)开具并把预期用药配送到家中（[[geriatrics-palliative/end-of-life-care]]）；(6)填写ReSPECT或同等表格，让救护车人员知道她的意愿。

出院前，要确认她和家人想要什么、能应付什么，以及她的丈夫和子女在有支持的情况下是否觉得能够照顾她。障碍是一种假设，而不是缺少选择：在许多地区，一两天内就能安排快速出院回家。
:::
:::

## 后续内容

晚期疾病的症状控制见[[geriatrics-palliative/symptom-control]]，最后几天及死亡后的照护见[[geriatrics-palliative/end-of-life-care]]。关于决策能力、知情同意和治疗决定的法律在[[medical-ethics-law]]中进一步展开。作为一种轨迹的衰弱见[[geriatrics-palliative/ageing-frailty]]。

::: history
现代安宁疗护运动始于Cicely Saunders，她先后接受过护士、医务社工和医生的训练。20世纪50年代后期，她在哈克尼的圣约瑟夫安宁院工作时证明，按时规律口服吗啡控制临终患者的疼痛，远优于等疼痛复发时才给药；她还提出了全人疼痛的概念。1967年，她在伦敦南部的锡德纳姆创办了圣克里斯托弗安宁院，将临床照护、教学和研究结合在一起。1974年，Florence Wald在康涅狄格州创办了美国第一家安宁疗护机构；加拿大外科医生Balfour Mount为他于1975年在蒙特利尔皇家维多利亚医院开设的服务创造了“姑息治疗”（palliative care）一词，选择这个词是因为在讲法语的魁北克，“hospice”一词带有宗教色彩。1987年，姑息医学在英国被认定为一个医学专科。
:::

::: summary
- 姑息治疗通过预防和减轻各个维度的痛苦（全人疼痛），改善威胁生命的疾病患者及其家属的生活质量。
- 它在早期即适用，可与针对疾病的治疗同时进行，适用于所有限制生命的疾病，而不仅仅是癌症。早期专科姑息治疗可改善生活质量和情绪。
- 大多数姑息治疗是通科照护；专科团队为复杂病例提供支持。
- 三种轨迹（癌症、器官衰竭、衰弱和痴呆）决定了何时以及如何进行规划。
- 临床医生会高估生存期；意外问题和SPICT等工具可识别可能处于生命最后一年的人，以便规划照护。
- 预立医疗照护计划记录价值观和意愿；拒绝维持生命治疗的ADRT必须书面形式、签名、有见证人，并声明即使危及生命也适用。
- 结构化的沟通（SPIKES、询问—告知—询问）有助于告知坏消息，并诚实地讨论不确定性。
:::

## 习题

::: exercise 回答“我还有多久”的问题 {level=1}
一位晚期肺癌男性问你：“我还有多长时间？”描述你会如何回应。
::: solution
首先探究这个问题：询问是什么促使他问这个问题、他已经了解了什么，以及他是想要一个数字还是别的什么（例如他能否赶上某个家庭活动）。如果他想要一个估计，就以“几周到几个月”这样的时间单位给出诚实的范围，而不是一个单一的数字；解释你无法精确预测，有些人活得更长，有些人更短；并解释哪些迹象可能提示时间更短。回应他的情绪，允许沉默，并询问在接下来的时间里什么对他最重要。主动提出可以再谈，如果他愿意，可以让家人参与。
:::
:::

::: exercise 识别姑息治疗需求 {level=1}
列出提示慢性阻塞性肺疾病患者可能处于生命最后一年的四个指标，以及识别后应采取的两项行动。
::: solution
指标（任选四项）：严重气流受限，静息或轻微活动时即气促；频繁急性加重或住院；需要长期氧疗；体重下降或体重指数低；体能状态下降、依赖增加；右心衰竭；对意外问题的回答是“不会”。行动：把此人纳入初级医疗姑息治疗登记并协调照护；提供预立医疗照护计划，包括对住院、机械通气和复苏的意愿；评估症状控制（气促、焦虑）；与非工作时间服务共享信息。
:::
:::

::: exercise 怎样的ADRT才有效？ {level=1}
一位运动神经元病女性希望将来拒绝有创通气，即使不用它会死亡。在英格兰和威尔士，她的预先决定必须包括什么才有效且适用？
::: solution
她作出决定时必须年满18岁并具有决策能力。决定必须明确所拒绝的治疗（有创通气），也可以注明适用情形。由于拒绝的是维持生命的治疗，它必须是书面形式，由她本人签名（或由他人在她面前并按她的指示代签），由一名见证人签名，并包含即使危及生命也适用的声明。如果她之后撤回、设立了涵盖同一决定的持久授权书，或行为明显与之不一致，则该决定无效；如果出现了她未曾预料到的情形，则不适用。她应把副本交给她的全科医生、神经科医生和家人。
:::
:::

::: exercise 意外问题的预测值 {level=2 check="round(100*0.2*0.67/(0.2*0.67+0.8*(1-0.802)))"}
在一个普通内科门诊，20%的患者将在12个月内死亡。意外问题的灵敏度为67%，特异度为80.2%。对于临床医生回答“不会，我不会感到意外”的患者，有百分之多少会在12个月内死亡？以整数百分数作答。
::: hint
以1,000名患者计算：统计死亡且被标记的人数，以及存活但被标记的人数。
:::
::: solution
1,000名患者中，200人死亡，800人存活。被标记且死亡：$200 \times 0.67 = 134$。被标记但存活：$800 \times (1 - 0.802) = 800 \times 0.198 = 158.4$。阳性预测值$= 134 / (134 + 158.4) = 134 / 292.4 = 0.458$，约**46%**。被标记的患者中不到一半在一年内死亡，而死亡者中有三分之一没有被标记。这个问题可以用来启动规划——这对任何患严重疾病的人都有帮助——但绝不能用它来告诉一个人还能活多久。
:::
:::

::: exercise 回应家属隐瞒信息的请求 {level=2}
一位儿子请求你不要告诉他有决策能力的母亲她的癌症已经扩散：“这会要了她的命。在我们的文化里我们不谈这个。”你如何回应？
::: solution
倾听并认可他的爱和担忧；询问他担心告诉母亲后会发生什么，以及他对母亲意愿的了解。解释你不会强行把信息塞给她，但你不能对她撒谎，而且她有权知道她想知道的一切。商定由你敏感地询问她希望知道多少、希望谁参与关于她疾病的讨论：有些患者更愿意让家人获知信息，如果这是她自己的选择，那就是正当的。如果她直接提问，就按她设定的节奏诚实回答。文化背景影响信息分享的方式，但不能凌驾于她本人的意愿之上。记录这些谈话。
:::
:::

::: exercise 运动神经元病的照护规划 {level=2}
Neil Fraser先生58岁，患运动神经元病，延髓肌和呼吸肌日渐无力。他仍能交流，但有些困难。列出应及早讨论的决定，以及时机为何重要。
::: solution
决定包括：胃造瘘喂养（最好在呼吸功能下降过多之前进行，以保证操作安全）；无创通气（可以改善症状和生存期）以及他将来是否希望撤除、在什么情况下撤除；经气管切开的有创通气；对住院和复苏的意愿；希望的照护地点和死亡地点；沟通辅助工具和声音储存（在丧失说话能力之前）；健康与福利方面的持久授权书；如果他希望拒绝某些特定治疗，还有预先决定。时机之所以重要，是因为说话、吞咽和呼吸功能可能迅速下降，而这些谈话需要在他还能表达时听到他本人的声音。由包括姑息治疗在内的运动神经元病专科多学科团队协调这些工作。
:::
:::

::: exercise 设计有效的转介 {level=3}
某医院的专科姑息治疗团队收到的转介大多发生在患者生命的最后72小时内，而器官衰竭患者的转介很少。提出使转介更早、更公平的改进措施，并说明你将如何衡量效果。
::: solution
改进措施：(1)基于需求而不是诊断的约定转介触发条件（症状未控制、家庭或决策需求复杂、反复住院、意外问题回答为“不会”）；(2)与心内科、呼吸科、肾脏科和老年医学团队开展联合门诊或联合查房；(3)对通科团队进行识别姑息需求和开展谈话的培训，使通科团队承担更多工作，只转介复杂病例；(4)为全科姑息治疗登记中的患者设置电子标记，并共享ReSPECT表格；(5)与社区和宗教团体合作，主动接触在转介中代表性不足的群体（按贫困程度和族裔）。衡量指标：从转介到死亡的时间（中位数及分布）；非癌症诊断转介所占比例；医院内死亡者生前有记录在案的预立医疗照护计划的比例；症状评分以及患者和家属的体验；以及转介人群与当地人口构成的比较。
:::

::: exercise 处理关于复苏的分歧 {level=3}
Leonard Gray先生88岁，患晚期痴呆和反复吸入性肺炎，再次入院。医疗团队认为心肺复苏不会成功，还会造成伤害。他的妻子坚持“必须全力抢救”。他缺乏决策能力。应如何作出并沟通这一决定？
::: solution
当心肺复苏不会成功时，DNACPR决定是一项临床判断，但正如Tracey案（2014）和Winspear案（2015）所确立的，除非会造成伤害，否则有义务让患者参与（此处由于他缺乏决策能力，通过他亲近的人参与）。步骤：由一位高年资医生在私密的环境中与他的妻子会面；了解她的理解、她丈夫的价值观以及他以前表达过的意愿；诚实地解释心肺复苏包括什么，以及为什么它不太可能让他的心脏重新跳动或让他恢复到以前的状态；说明哪些照护会继续（如适当则治疗肺炎、症状控制、舒适、营养和口腔护理），以免“不做心肺复苏”被理解为“不再照护”。如果她不同意，团队没有义务提供其判断不会成功的心肺复苏，但应提供第二意见，并记录讨论过程、理由和她的意见。如果有健康与福利方面的持久授权书，必须征询受托人的意见；如果问题确实是最佳利益问题（心肺复苏可能成功但未必是他想要的），则按照《精神能力法》的最佳利益程序作出决定。
:::
