一个人如何离世，会伴随其家人的余生。生命最后几天的照护是每一位医生、每一个专科都要提供的，而其中大部分并不复杂：识别出患者正在走向死亡，与患者及其家人坦诚交谈，缓解症状，停止不再有益的措施，并在死亡后照料遗体和居丧者。当这种照护出问题时，通常不是技术不足，而是识别和沟通的失败。

本章介绍如何识别濒死、生命最后几天和最后几小时的照护、英国关于临终决定的法律和伦理框架、死亡后要做的事，以及居丧。本章建立在[[geriatrics-palliative/palliative-care]]和[[geriatrics-palliative/symptom-control]]的基础之上。

## 识别濒死 {#sec-recognition}

::: definition 识别一个人可能正在走向死亡 {#def-recognition}
当以下几种变化同时出现，且不能用可逆的原因解释时，一个人可能正在进入生命的最后几天：日益虚弱和疲乏，大部分或全部时间卧床；饮食减少、吞咽困难；嗜睡加重或意识水平下降；躁动或意识混乱；呼吸方式改变（包括潮式呼吸和有声的呼吸道分泌物）；四肢末梢发凉、出现花斑。NICE指南NG31（2015）建议，识别濒死是一项判断，其依据是收集并记录这些征象、考虑它们是否可能可逆、在不确定时向更有经验的同事寻求意见，并至少每24小时复评一次。
:::

不确定是正常的。有些看起来正在走向死亡的人会好转，尤其是在感染、高钙血症、脱水、阿片类中毒或低血糖等可逆原因得到治疗之后。目标不是确定无疑，而是制定一个符合最可能病程的计划，并随着情况变化进行复评。应向家属解释这种不确定性本身（“我认为他可能正在走向死亡，可能就在接下来的几天里，但我不能确定；我们每天都会再来看他”）。

### 利物浦照护路径的教训

利物浦照护路径（Liverpool Care Pathway）是一种针对临终者的整合照护路径，21世纪头十年在英国医院中广泛使用。由Julia Neuberger男爵夫人主持的独立评审（《多些照护，少些路径》（*More Care, Less Pathway*），2013）发现，尽管该路径能够支持良好的照护，但它常被当作勾选式的规程来执行：患者未经讨论就被纳入路径，补液未作解释就被撤除，家属感到被排斥在外。该路径于2014年逐步停用。取而代之的是，临终者照护领导联盟（《只有一次做对的机会》（*One Chance to Get It Right*），2014）提出了**临终者照护的五项优先事项**：

1. 认识到这个人可能在接下来的几天或几小时内死亡，并清楚地加以沟通；根据本人的需要和意愿作出决定、采取行动，并定期复评和修订（**识别**）。
2. 工作人员与临终者及其认为重要的人之间进行敏感的**沟通**。
3. 在临终者希望的程度内，让临终者及其认为重要的人**参与**关于治疗和照护的决定。
4. 积极了解、尊重并尽可能满足家属和临终者认为重要的其他人的需要（**支持**）。
5. 商定、协调并以同情心实施一份**个体化计划**，内容包括饮食、症状控制以及心理、社会和灵性支持。

::: example 最后一次入院 {#ex-lastdays}
George Ellis先生89岁，患晚期痴呆和心力衰竭，住在照护机构。五天来他已不再进食，只啜饮少量液体，大部分时间在睡觉，现在因血压低和胸部感染入院。他的女儿说他不会希望“靠机器维持下去”。描述他的照护步骤。
::: solution
**识别。**在晚期痴呆和心力衰竭的基础上，他数天来持续衰退，伴摄入差、嗜睡和可能的感染，提示他可能正在走向死亡。考虑可逆因素，以及治疗它们是否符合他的意愿、是否可能有帮助：如果胸部感染的抗生素可能缓解症状或可能促使康复，使用抗生素是合理的，但强化治疗不符合他的意愿。

**沟通与参与。**与他的女儿（以及任何受托人）交谈：解释他可能正在走向死亡、这一点并不确定、哪些会做以及哪些不会做。询问他的价值观、任何预立医疗照护计划、ReSPECT表格或预先决定，以及灵性或文化方面的需要。

**个体化计划**（[[#def-dying]]）：停用非必需的药物以及常规的血液检查和观察；以有效的途径继续使用缓解症状的药物；开具预期用药；口腔护理；如果能安全吞咽，提供少量啜饮；个体化地决定是否进行临床辅助补液；记录DNACPR决定和治疗升级计划；如果他的家人认为这是他想要的，并且能够迅速安排，考虑让他回到熟悉他的照护机构。至少每天复评一次。
:::
:::

## 最后几天和最后几小时的照护 {#sec-dying}

::: definition 生命最后几天的个体化照护计划 {#def-dying}
临终者的**个体化照护计划**包括：评估并**停用**不再使患者获益的药物和干预（例如他汀类、降压药、常规血液检查和频繁的观察），同时继续使用缓解症状的药物；针对生命最后几天的常见症状（疼痛、气促、躁动、恶心和呕吐，以及有声的呼吸道分泌物），预先开具**预期用药**，通常经皮下途径给药；个体化地决定**补液和营养**，包括在本人愿意且能安全饮水时支持其饮水，以及频繁的口腔护理；定期评估症状和舒适度；关注本人及其家属的心理、社会、灵性和文化需要。
:::

### 预期用药

人在临近死亡时通常会丧失吞咽能力，而症状可能在夜间或周末出现。**预期处方**是在需要之前，就把药物备在家中、照护机构或病房里，使护士能够及时给药。常见的类别有：

| 症状 | 典型药物类别（举例） |
|---|---|
| 疼痛和气促 | 阿片类（吗啡；肾功能损害时可选用羟考酮或阿芬太尼等） |
| 躁动、焦虑和痛苦 | 苯二氮䓬类（咪达唑仑） |
| 恶心和呕吐 | 止吐药（氟哌啶醇、左美丙嗪或赛克力嗪） |
| 有声的呼吸道分泌物 | 抗毒蕈碱药（丁溴东莨菪碱或格隆溴铵（glycopyrronium）） |

剂量取决于本人目前的用药、肾功能和衰弱程度，并遵循当地指南。如果症状反复出现，24小时内需要数次给药，就应安装**皮下持续输注泵**（24小时持续皮下输注），24小时剂量依据已使用的剂量确定，同时仍备有爆发剂量。

::: example 安装皮下持续输注泵 {#ex-syringe}
Ruth Abrams夫人76岁，患转移性肺癌，正在家中走向死亡。本周之前她没有规律使用阿片类药物。过去24小时内，社区护士为缓解疼痛和气促给了她五次皮下吗啡2.5 mg，为缓解躁动给了两次皮下咪达唑仑2.5 mg，每次效果都很好。请建议24小时输注泵的内容和爆发剂量。
::: solution
**吗啡。**总用量：$5 \times 2.5 = 12.5$ mg/24小时。24小时输注约10–15 mg皮下吗啡可以反映她的用量；对于未使用过阿片类药物的衰弱者，许多临床医生会选择10 mg，并保留爆发剂量。爆发剂量仍为2.5 mg（约为15 mg的六分之一，或10 mg的四分之一；在低剂量时，爆发剂量通常定为最小的可操作剂量）。

**咪达唑仑。**总用量：$2 \times 2.5 = 5$ mg；24小时输注5–10 mg，爆发剂量2.5 mg。

**实际要点。**吗啡和咪达唑仑用注射用水配制时可在同一输注泵中配伍。达到稳态需要数小时，因此如果启动输注泵时她感到不适，应同时给一次爆发剂量（见下图）。每天以及在任何爆发剂量之后复评剂量。这些数字用于说明推理过程；剂量遵循当地指南。
:::
:::

### 补液与营养

临终者通常喝得和吃得都越来越少，家属常担心本人在“挨饿”或“渴死”。在最后几天，摄入减少是死亡过程的一部分，而不是死亡的原因。口干是口渴的主要来源，可通过频繁的口腔护理以及在能吞咽时少量啜饮来缓解。NICE NG31建议：在本人愿意且能够时支持其饮水，每天评估水合状态，并与本人及其认为重要的人讨论**临床辅助补液**（例如皮下补液）的风险和获益。在某些情况下，试用辅助补液可能是合适的，例如口渴或谵妄可能与脱水有关时，并至少每12小时复评一次；而在另一些情况下，补液可能导致液体过多、水肿或分泌物增多而毫无益处。临床辅助补液和营养属于医疗措施，相关决定按本人的最佳利益作出。

### 最后几小时的变化

应让家属对常见的变化有所准备：

- **呼吸**可能变得不规则，出现暂停（呼吸暂停）后又有较深的呼吸（潮式呼吸），或变得浅表，临近死亡时偶有叹息样呼吸。
- **有声的呼吸道分泌物**（“临终喉鸣”）出现在本人已无法清除咽喉分泌物时。它可能不会让失去意识的人感到痛苦，但会让家属不安。调整体位有帮助；常给予抗毒蕈碱药，尽管其减轻声响的证据有限。吸引很少有帮助，还可能造成痛苦。
- **皮肤**变凉并出现花斑，尤其是膝部和足部。
- **意识**逐渐消失；听觉可能仍然存在，可以鼓励家属与本人说话。

::: warning 不要什么都不停，也不要停止交谈
有两种相反的错误很常见。一种是继续那些不再有益的常规观察、血液检查和药物，这会造成不适，并分散对真正重要之事的注意力。另一种是不经讨论就“全部停掉”，连口腔护理、对症状的关注以及与家属的交谈也一并停了。识别濒死改变的是照护的目标，而不是照护的多少。
:::

### 临终的伦理与法律

根据英国法律和专业指南：

- 对于不符合本人最佳利益、或有决策能力者拒绝的延长生命治疗，**不予或撤除**是合法的（*Airedale NHS Trust v Bland*，1993）。临床辅助营养和补液属于此意义上的治疗。自*An NHS Trust v Y*案（最高法院，2018）起，对于缺乏决策能力的人，只要遵循《精神能力法》和专业指南、并且各方对最佳利益意见一致，撤除辅助营养和补液就不需要法院批准。
- 为缓解痛苦而按需调整的适当剂量阿片类药物和镇静药进行**症状缓解**是合法的，即使理论上存在缩短生命的风险（双重效应原则）。实践中，研究提示在姑息治疗中审慎使用的阿片类药物和镇静药并不缩短生存期。
- **姑息性镇静**是指在生命末期为缓解难治性痛苦而相称地使用镇静药；当其意图是缓解痛苦、剂量相称，并且经过讨论、记录和复评（最好有专科姑息治疗的意见）时，它是合法且合乎伦理的。
- **安乐死**（医生蓄意结束患者的生命）是违法的；在英格兰和威尔士，协助或鼓励自杀是《1961年自杀法》（Suicide Act 1961）规定的犯罪。
- 英国各地都曾就**协助死亡立法**展开辩论。在英格兰和威尔士，一项私人议员法案（《终末期成年人（生命终结）法案》（Terminally Ill Adults (End of Life) Bill））于2025年在下议院获得通过，但于2026年4月在上议院因议会时间耗尽而失效，一项类似的法案于2026年晚些时候再次提交下议院；在苏格兰，苏格兰议会于2026年3月否决了一项协助死亡法案。截至撰写本文时（2026年底），协助死亡在英国任何地方都不合法，读者应核实最新情况。

当患者请求医生结束其生命时，这一请求值得认真而富有同情心的回应：探究其背后的原因（未控制的症状、对死亡过程的恐惧、抑郁、觉得自己是负担、失去控制感），处理能够处理的问题，并清楚地说明医生能做什么、不能做什么。

## 死亡之后 {#sec-after}

::: definition 死亡的核验与证明 {#def-after}
**死亡核验**是确认一个人已经死亡。按照英国皇家医学院学会（Academy of Medical Royal Colleges）的实践规范（2008），心肺骤停后，应至少观察**五分钟**以确定发生了不可逆的心肺骤停：触诊无大动脉搏动、听诊无心音（在医院中，如条件允许，可辅以连续心电图显示心脏停搏、动脉内监测无搏动性血流，或超声心动图显示无收缩活动）。在此期间如有任何自主心跳或呼吸恢复，应重新开始观察。五分钟后，确认瞳孔对光反射消失、角膜反射消失，以及对眶上压迫无任何运动反应。死亡时间记录为满足这些标准的时间。**死亡证明**是填写死因医学证明书（MCCD），写明死因，以便进行死亡登记。
:::

在许多场合，除医生外，受过适当培训的注册护士或急救医护人员也可按当地政策进行死亡核验。居家的预期死亡由社区护士或全科医生核验。

**英格兰和威尔士的死亡证明。**自2024年9月9日起，英格兰和威尔士的每一例死亡，在登记之前都必须经过**医学审查员**（一位独立的高年资医生）的审查，或由验尸官调查。在死者生前诊治过死者的注册医师可以填写MCCD；以前要求医生在死亡前28天内或死亡后见过患者的规定已不再适用。医学审查员办公室还会与居丧家属交谈，家属可以就照护提出任何疑虑。苏格兰和北爱尔兰有各自的制度。

**转交验尸官**（在苏格兰为地方检察官）适用于可能属于非自然死亡或死因不明的情况，包括由暴力、创伤或损伤（包括跌倒）、中毒、自伤、疏于照顾、职业病或职业因素、医疗操作引起的死亡，以及在羁押或国家拘禁中的死亡。医生如有任何疑问，应与医学审查员或验尸官办公室讨论。

**死后照护**遵循本人和家属的意愿、文化和宗教习俗，以及国家关于死后照护的指南。内容包括：让遗体平躺，闭合眼睑和嘴，除非死亡需要转交验尸官，否则拔除管线和装置，确认身份，并有尊严地处理遗体。火化前必须取出心脏起搏器和某些其他植入装置。家属可能希望陪伴遗体一段时间，并参与清洗或穿衣。

::: example 凌晨3点的死亡 {#ex-nightdeath}
凌晨3点，护士给低年资医生打电话：92岁的Iris Bell夫人停止了呼吸。她的死亡是预期中的，已有DNACPR决定和个体化照护计划。她的儿子在她身边。医生应该怎么做？
::: solution
立即前往病房，与护士和她的儿子交谈，表达哀悼。核验死亡（[[#def-after]]）：至少观察五分钟，确认无大动脉搏动、无心音、无呼吸；然后确认瞳孔对光反射、角膜反射和对眶上压迫的运动反应均消失。记录检查结果、死亡时间（确认满足标准的时间）以及在场人员。检查是否有转交验尸官的理由（例如近期跌倒或骨折、外伤，或与某项操作有关的死亡）；如有，管线和导管应保留原位。询问她的儿子是否有文化或宗教方面的意愿，以及是否需要联系其他家人。解释接下来的程序（MCCD、医学审查员的审查，以及居丧办公室将如何与他联系）。确保早上通知全科医生，并给她的儿子关于实际事务和居丧支持的书面信息。
:::
:::

::: example 清洗遗体与尽快下葬 {#ex-ghusl}
Yusuf Rahman先生67岁，因转移性结肠癌在医院去世。他的家人是穆斯林，希望为他清洗遗体（ghusl），并在24小时内下葬。今天是星期六。医院能提供什么帮助？
::: solution
许多宗教，包括伊斯兰教和犹太教，都希望在死后尽快下葬。英格兰和威尔士的医学审查员制度规定了遗体的**紧急放行**：主治医生及时填写MCCD，在有当地安排的情况下，医学审查员办公室和登记官可以在非工作时间完成审查和登记。尽早联系值班医学审查员、居丧办公室和太平间。如果死亡必须转交验尸官，应把这一请求告知验尸官办公室；验尸官会尽可能照顾宗教需要。

关于清洗：征得家属同意后，工作人员应尽量少地接触遗体，保持遗体覆盖，并避免家属不希望的操作，例如家属希望自己清洗时，工作人员就不要清洗。许多医院设有供家属清洗遗体的设施，或与当地清真寺和殡葬服务机构合作。如果死者患有法定传染病，适用感染控制建议。在生前的预立医疗照护计划中记录并尊重这些意愿，会让这一过程更顺利。
:::
:::

## 居丧 {#sec-bereavement}

**悲伤**是对丧失的正常反应。它不是一系列固定的阶段，在不同的人和不同的文化之间差异很大。许多居丧者在专注于丧失和恢复日常生活之间来回摆动（Stroebe和Schut的双过程模型）。大多数人在家人、朋友和社区的支持下，随着时间推移逐渐适应。

有些人会发展为**延长哀伤障碍**，表现为对逝者强烈的思念或沉浸，伴有情感痛苦，其持续时间超出其文化中的预期，并损害功能。ICD-11要求在死亡后持续至少六个月；DSM-5-TR要求成人至少持续十二个月。危险因素包括突然或创伤性的死亡、非常亲密或依赖的关系、既往精神健康问题、缺乏社会支持，以及死亡前后的困难处境。居丧还与在世配偶的躯体疾病和死亡率增加相关。

英国的居丧支持通常分为三个层级：为所有居丧者提供关于悲伤和可获得支持的信息；为需要更多帮助的人提供训练有素的志愿者或社区服务的支持；为有复杂需要的人提供专科心理支持。其中很大一部分由安宁疗护院提供。医生可以通过以下方式提供帮助：承认这一死亡，主动提出一次后续谈话（例如解释发生了什么，或回答关于疾病的问题），以及识别居丧患者何时需要更多帮助。

::: example 曾是照护者的女儿 {#ex-bereaved}
Carol Simmons女士58岁，照顾患痴呆的母亲七年，直到母亲八个月前去世。她辞去了工作，独自生活。她告诉全科医生，她无法停止想念母亲，吃饭时仍然摆两副碗筷，回避朋友，觉得生活失去了意义。她睡眠差，体重下降。她的全科医生应如何回应？
::: solution
八个月时她的悲伤仍然强烈而持续，并损害了日常生活。应同时考虑可能的延长哀伤障碍（按ICD-11标准，要求至少六个月）和抑郁：询问情绪、快感缺失、无望感和自杀念头，并敏感地评估风险。失去所照顾之人的照护者，往往同时失去了日常角色、收入和社会联系，这增加了风险。

回应：倾听，承认她的丧失和多年的照护付出；解释强烈的悲伤是可以得到帮助的。提供转介至居丧支持（例如当地安宁疗护院或居丧慈善机构）或心理治疗，如存在抑郁则予以治疗。在经济、工作和社会联系方面提供实际帮助（照护者组织常为曾经的照护者提供支持）也是照护的一部分。安排随访。如果她表达了自杀念头，应遵循当地的安全和危机处理指南，并告诉她可获得的支持服务，例如撒玛利亚会（Samaritans，英国电话116 123）。
:::
:::

::: quiz
一家人问，为什么他们已不能吞咽的临终父亲没有“打点滴”。哪种回答最准确？
- [ ] 在生命最后几天总是停止补液
- [ ] 在生命最后几天总是给予补液，因为口渴难以忍受
- [x] 口干是口渴的主要原因，可以通过口腔护理缓解；辅助补液可能帮助一些人，也可能伤害另一些人，因此决定是个体化的，并需复评
- [ ] 一旦被识别为濒死，补液就是违法的
::: solution
NICE NG31建议个体化地决定是否进行临床辅助补液，为所有人提供频繁的口腔护理，与家属讨论，并定期复评（[[#def-dying]]）。
:::

## 后续内容

晚期疾病的症状控制见[[geriatrics-palliative/symptom-control]]。临终决定、决策能力和知情同意的伦理与法律在[[medical-ethics-law]]中进一步展开。沟通和预立医疗照护计划见[[geriatrics-palliative/palliative-care]]，决策能力见[[geriatrics-palliative/delirium-dementia-care]]。

::: history
1969年，瑞士裔美国精神科医生Elisabeth Kübler-Ross出版了《论死亡与临终》（*On Death and Dying*），该书基于她在芝加哥对临终患者的访谈。书中的五个“阶段”（否认、愤怒、讨价还价、抑郁、接受）本意并非固定的顺序，后来的研究也不支持把它们当作固定顺序，但这本书说服了医生去与临终者交谈，而不是绕开他们交谈。1993年，上议院在*Airedale NHS Trust v Bland*案中的判决在英格兰法律中确立：当延长生命的治疗（包括人工营养和补液）不符合患者的最佳利益时，撤除这些治疗可以是合法的。1999年，Margaret Stroebe和Henk Schut发表了悲伤的双过程模型。在英国，利物浦照护路径由利物浦皇家大学医院和利物浦玛丽·居里安宁院于20世纪90年代后期制定，曾广泛推广，直到2013年的Neuberger评审导致其被撤销，并由基于临终者照护五项优先事项的个体化照护所取代。
:::

::: summary
- 识别濒死是一项临床判断，依据是几种征象同时出现，并在考虑可逆原因之后作出；不确定是正常的，应与家属分享；至少每24小时复评一次。
- 照护的五项优先事项：识别、沟通、参与、支持，以及个体化照护计划。
- 停止不再有益的措施；为疼痛、气促、躁动、恶心和分泌物开具预期用药；需要多次给药时使用皮下持续输注泵。
- 口腔护理缓解口渴；是否辅助补液需个体化决定并复评。
- 撤除无益的治疗以及相称的症状缓解（包括姑息性镇静）是合法的；截至撰写本文时，安乐死和协助自杀在英国是违法的。
- 观察心肺骤停至少五分钟后核验死亡，再确认瞳孔、角膜和运动反应消失。
- 在英格兰和威尔士，每一例死亡都要经医学审查员或验尸官审查；非自然死亡（包括跌倒和外伤后的死亡）转交验尸官。
- 悲伤是正常的；延长哀伤障碍和抑郁需要识别和支持。
:::

## 习题

::: exercise 开具预期处方 {level=1}
列出预期用药通常涵盖的五种症状，以及每种症状所用的药物类别。
::: solution
疼痛和气促：阿片类。躁动和焦虑：苯二氮䓬类（咪达唑仑）。恶心和呕吐：止吐药（例如氟哌啶醇、左美丙嗪或赛克力嗪）。有声的呼吸道分泌物：抗毒蕈碱药（丁溴东莨菪碱或格隆溴铵）。剂量取决于本人目前的用药、肾功能和衰弱程度，并遵循当地指南；处方还应写明给药途径（通常为皮下）、剂量范围和最大给药频率。
:::
:::

::: exercise 核验死亡 {level=1}
按照2008年的实践规范，列出心肺骤停后核验死亡的步骤。
::: solution
至少观察五分钟，以确定发生了不可逆的心肺骤停：触诊无大动脉搏动、听诊无心音、无呼吸。如有任何自主心跳或呼吸恢复，重新开始五分钟的观察。然后确认瞳孔对光反射消失、角膜反射消失，以及对眶上压迫无任何运动反应。把满足这些标准的时间记录为死亡时间，并记录检查结果。
:::
:::

::: exercise 解释呼吸中的声响 {level=1}
一位临终男性的妻子因丈夫喉中咕噜作响的呼吸声而非常难过。你会告诉她什么？能做些什么？
::: solution
温和地解释，这种声音是由于他太虚弱，无法咳出或咽下唾液和分泌物，使其积聚在咽喉所致；这在临近死亡时很常见，他很可能察觉不到，也不会因此感到痛苦。让他侧卧往往能减轻声响。可以给予抗毒蕈碱药以减少新的分泌物，尽管不一定总是有效。吸引很少有帮助，还可能让他难受。如果她愿意，鼓励她陪在他身边，和他说话，握着他的手。
:::
:::

::: exercise 输注泵中的吗啡 {level=2 check="5*2.5"}
一位从未使用过阿片类药物的临终女性，在24小时内因疼痛需要了五次皮下吗啡2.5 mg。她总共接受了多少皮下吗啡（mg）？
::: solution
$5 \times 2.5 = 12.5$ mg/24小时。这一总量是确定24小时输注泵剂量的依据（例如10–15 mg，取决于她的衰弱程度、肾功能和当地指南），同时仍备有爆发剂量。
:::
:::

::: exercise 从口服吗啡改为皮下吗啡 {level=2 check="80/2"}
一位男性每天两次服用缓释吗啡40 mg，未曾需要爆发剂量。他现在不能吞咽了。按口服与皮下2:1的比例，输注泵中24小时皮下吗啡的剂量应为多少（mg）？
::: solution
口服TDD $= 40 \times 2 = 80$ mg。皮下剂量$= 80 / 2 = 40$ mg/24小时。皮下爆发剂量约为$40/6 \approx 6.7$ mg，按当地指南取整为可操作的剂量。输注泵在下一次口服剂量本应服用的时间启动。
:::
:::

::: exercise 回答关于补液的问题 {level=2}
一位临终胰腺癌女性的儿子要求给她静脉输液，因为“她脱水了，会渴死的”。她嗜睡、口干，能少量啜饮。你如何回应并作出决定？
::: solution
倾听他的担忧，并解释饮水减少是死亡过程的正常部分，而口干——口渴的主要来源——可以通过频繁的口腔护理（湿润口腔、润唇膏）缓解，他也可以帮忙做。然后作出个体化决定（[[#def-dying]]）：如果脱水可能加重痛苦或谵妄，而补液不太可能造成伤害（例如没有明显的水肿、腹水或呼吸道分泌物），试用皮下补液是合理的，并明确复评标准，至少每12小时复评一次。如果补液可能造成伤害而没有获益，则解释为什么不建议补液。记录讨论内容和决定，情况变化时重新讨论。
:::
:::

::: exercise 请求结束生命 {level=3}
Gwen Pritchard夫人79岁，患转移性癌症并有严重气促。她对医生说：“我想让你给我点什么来结束这一切。”医生应如何回应？
::: solution
以开放的态度回应，而不是终止谈话：承认这一请求，并询问是什么让她提出这个请求。全方位地探究痛苦：未控制的气促或其他症状、对死亡过程的恐惧（例如害怕窒息）、抑郁、觉得自己是负担、失去控制感或尊严、家庭或灵性方面的痛苦。评估有无抑郁和自杀念头。处理能够处理的问题：更好地处理气促（风扇、阿片类药物、焦虑管理），解释死于她这种疾病的过程通常可以做到舒适，提供专科姑息治疗，并让她放心：她可以拒绝不想要的治疗，生命末期的痛苦可以得到缓解，必要时包括使用镇静。坦诚地说明医生不能合法地结束她的生命或帮助她结束生命，因为截至撰写本文时，安乐死和协助自杀在英国是违法的。记录这次谈话，让团队参与，并继续去看她：这一请求往往是痛苦的信号，而痛苦会对照护产生反应。
:::
:::

::: exercise 医学审查员还是验尸官？ {level=3}
Frank Holloway先生86岁，在家中跌倒导致髋部骨折并接受了手术。他随后发生肺炎，十天后去世。病房医生拟定死因为“1a 肺炎，2 痴呆”，并打算填写MCCD。这样做正确吗？
::: solution
不正确。这一死亡发生在一次损伤（跌倒导致的髋部骨折）之后，事件链是：跌倒、股骨颈骨折、手术、制动和肺炎、死亡。由损伤导致或促成的死亡不是纯粹的自然死亡，必须转交验尸官。更准确的死因应类似于“1a 支气管肺炎，1b 股骨颈骨折术后制动，1c 跌倒”，如果痴呆和其他疾病起了促成作用，则列于第2部分。医生应与医学审查员讨论此病例，由其就转交验尸官提供意见；验尸官可能决定需要进行死因审讯，也可能允许医生在记录损伤的情况下签发MCCD。应告诉家属为什么要转交。准确的死亡证明对家属、对公共卫生统计以及从死亡中吸取教训都很重要。
:::
:::
