生命的最后几日是医学的技术与道德词汇必须在实时中彼此嵌合的地方：认出死亡已经开始、撤回不再服务的东西、治疗造成痛苦的东西、用家属能存活下来的句子告诉他们真相、然后在死亡之后——以同样的能力照护遗体、文书、亲属与人员。**本章涵盖活跃濒死期的识别与它要求的反转（液体、喂养、目标、药片、抗生素）、濒死者症状与家属在场的全天候管理、死亡的识别与证明及遗体的照护（包括文化与宗教的必需）、在医院里与死亡相交的验尸官与器官捐献交界面、及决定下一个家庭能否得到一个好死亡的居丧与人员后续。它的照护标准是一句话：任何人都不应恐惧地、疼痛地、违背自己意愿地孤独地、或在其文化未被咨询的情况下去世——而这四种失败中的每一种都是一个系统属性、今晚就可以测量。**

## 认出死亡已经开始

::: definition 最后几日：识别与反转 {#def-recognition}
**识别难题：以日计的预后比以月计的更难、而最后一周的体征是在没人教的病房里学会的：不断加重的衰竭与一天中大部分时间在睡眠、她没有显得受苦却失去了食欲与口渴、血压下降与四肢发凉及沿着膝盖往上爬的花斑、潮式或失调的呼吸及新的分泌物声音、或那种一些家属读作“她在道别”而一些研究提示它本身就是一种现象的安静地从交谈中离开、及让这一切讲得通的轨迹背景一个已停止应答的晚期癌、那个上一次住院恢复得不如前一次的器官衰竭患者、第二次误吸或新骨折或不愈合压力区的衰弱痴呆患者——“最后几日生命”的识别标准与预后体征文献中终末生命识别工具集群、其诚实的判决是它们单个有限、合起来尚可、而若不被行动就毫无用处；惊讶提问的失败模式多数老年住院患者都可以被说成“可能在死去”、这就是为何好的服务把识别转换成一份具名文件——有自己的表格与自己的预期药物讨论的最后几日照护计划——而不是走廊里的一种情绪。识别所要求的反转、每一个都带着自己的谈话：液体皮下盐水可能加重分泌物与充血与水肿、而口腔护理治疗的是口渴感、因为濒死大脑的口渴是嘴而不是容量、及“终末生命补液”之辩的证据基础——它真的有争议、而应该与家属讨论而不是向他们引经据典、营养最后几日中人工营养的问题由生理解答——正在关闭的身体无法利用营养液、而误吸与水肿及再喂养伤害是干预的风险、及舒适喂食代替管子的原则延伸开来：一勺冰淇淋在此阶段就是药——饥饿性谵妄或一个可逆原因可能在驱动事情的例外案例、正是识别为一项临床任务而不是一个公式的理由、反向的去处方级联停掉他汀与双膦酸盐与可能正在让她恶心地高辛、而糖尿病胰岛素朝向避免低血糖而不是血糖正统来减少滑移量表而非奴役量表的原则、及在无监护的居家死亡中停止血糖监测、抗高血压药随血压一起脱落、及锂与左旋多巴及激素的微管理、它们是停药的例外、带着在多重用药与精神科各章命名的自身反跳与戒断药理学、抗生素之问“为舒适还是为生命治疗胸部感染”的决定、家属体验为“你们要放弃了吗”、而它有时确实是一种作为桥的希望——一次门诊、一场婚礼、有时确实只是更多的腹泻——决定连同其理由与停止点记录在案、因为最后几周口服对静脉对都不用的之问是照护目标医学、而答案在两个病情完全相同的患者之间是不同的、及监测与干预审计一个有目的的生命体征表之问与凌晨4点血糖之问及在濒死者身上抽血之问、每一个都回答“这会不会改变今晚在她身上发生什么”——反转清单就是把去处方各章以最大斜率应用。**
:::

## 濒死期

::: definition 最后数小时：症状与在场管理 {#def-dying}
**照护包的现实：濒死的患者需要更少的干预与更多的到场——躯体处理是简短的为舒适与压力区重新摆放体位、及那个在濒死照护中最被忽视而最有效的治疗口腔护理计划口渴感与干裂的口唇及被治疗念珠菌、及棉签蘸水比在给一个会呛咳的患者的几口水更诚实地被提供、轻轻闭合眼睑、膀胱与肠道计划（濒死者的潴留仍然是一个可逆的激越原因、值得一次检查、而失禁用垫子与尊严及一份换过用词的清单管理），而药物处理是预期性的而不是反应性的：以防万一综合征对已滴定的阿片应答的疼痛与呼吸困难、用于恶心与痛苦的左美丙嗪或等效药、用于急性激越或癫痫的咪达唑仑、以同样被教授并被自信执行的剂量滴定、因为濒死中的激越是被当作医学来管理的恐惧、绝不用约束、及用于吵闹呼吸的抑制分泌药、带下面的解释；分泌物之问再次出现、因为它是家属最难听的声音：死亡咕噜声不痛、不是溺水、并不总是能修好、而它对应重新摆放体位与停止人工液体的反应、比对加大抗毒蕈碱药的反应更大——解释是首要的治疗、而抗毒蕈碱药在与校准到其有限效果的希望一起提供及诚实的一句：有些传统与有些家属希望那个声音在发生之前就被大声命名出来、这是一位有时间的护士能有的谈话、而一位同时有三位其他患者的护士不能有、这就是人员配置作为死亡地点的决定因素；呼吸模式的谈话潮式呼吸的间歇让家属打来“她走了吗”——作为模式而不是危机来解释、呼吸暂停的间歇是濒死的一部分而不是一个复苏事件、及终末不安与低活动型谵妄的区别决定了是治疗还是仅仅坐着陪；作为临床材料的在场家属在场的许可“你们可以碰她、她很可能听得见你们——听觉被认为是最后消失的感觉”、这未经证明而 普遍地安慰人、并且足够真实、被分配的角色一面有用的手持镜：润湿口唇、放音乐、讲故事、轮流坐班的排班表、好的姑息单元就靠它把无助的家属转换成照护团队、按儿童参与姑息家庭照护的文献用诚实的话把的孩子与孙辈包括进来、及疏远的家人与“她想见谁”的核查现在就做、因为濒死者的人际关系不是由那个接电话的人以礼让之名代为管理的；及环境与后勤的能力家中床位对安宁院对病房的决定对着夜里需要什么重新核查、当家在四楼带一台周日就坏的提升机时诚实地回答“她能死在家里吗”、今晚实际在房里的设备与药物、因为一张明天才到的处方是不该让家属去下的赌注、那个还不需要但被告知现在几点而不是时间何时到的殡仪馆、及作为同一小时内安排的牧师与文化请求牧师、伊玛目、拉比、彩虹家庭、祝福或沉默——灵性关怀团队在此阶段是一个快速反应服务、而病房谁也不问的默认是每一种信仰的审查都会发现的那个失败。最后、房间的生命体征：人员自己的行为要么是一剂镇痛药要么是一个应激源、而“坐下来解释的团队”是家属报告最多的干预——濒死者被家属比被图表更准确地监测、而承认这一点的病房在这整个定义里事事都变好。**
:::

## 死亡之后

::: definition 死亡：识别、文书、遗体与居丧 {#def-after}
**死亡的识别：临床检查在有监护的环境中或用听诊能力持续十分钟听不到心音、及呼吸音消失及瞳孔固定散大及早期尸僵与尸斑的皮肤变色、这是学会标准时代对神经背景之外死亡的重新确认、它以讲得道理的平实生理学取代了两位医师的心脏呼吸脑干形式、并结束了“60秒无心搏”辩论的诉讼时代——而器官捐献交界面在某些司法辖区与场合添加自己的辅助检查、更多是移植医学的主题而不是床旁的、计时与通报职责亲属是在识别之前还是之后到来的之问、用文化与时机而不是习惯来回答、因为有些家庭需要曾在场、而有些传统在亲属到达之前不会洗身、这就是为何死亡识别同时是一项操作与一件社会工作、及诚实的边缘案例无亲属的无人陪伴的医院死亡——与第二人一起清点并翻查遗物、及安葬贫困者的职责、是一项没人拍照的公共健康职能；证明层从病历与实际顺序写出的死亡证明：第一部分从直接死因向下到基础疾病、带间隔那一行、第二部分是有贡献的合并症而不是购物清单、“我不能排除”的措辞会把案件交给验尸官、及死亡证明改革辩论所围绕的“起始不确定”问题、及医学检查官对验尸官的模式设想及各国的范例、及当死亡是暴力、非自然或无人陪伴时医师的法律义务、在那里验尸官转诊规则与警方及殡仪的编舞绝不允许把家属拖延到法律最低限之外数日；器官与组织捐献交界面医院内死亡具捐献可能的顺序：尽早转诊给专科团队、因为窗口是以分钟到小时计、及脑干与循环死亡捐献路径、带着它们自身保护生理的重症监护阶段是免疫学移植各章的细节、现已在多国运行的默认退出同意系统、及当请求时机糟糕或死亡属于太平间而不属于临床医师时仍会发生的家属如临大敌的谈话、及组织捐献的时间表（眼与皮肤与骨）及适用时验尸官的异议——这是一次专科谈话、而全科医师至少不该搞砸它；遗体的照护及其文化医学其遗漏会变成投诉的尊重协议：核对遗体并以名讳与帘幕的尊严擦洗、及假牙与首饰、及“我们要不要盖住脸”之问按宗教而不是病房习惯回答在穆斯林与犹太实践中、洗身与裹殓是家庭与信仰社区的义务、而时间与遗体处理的要求是临床医师基本能力的一部分、而与信仰洗身者的合作就是那个干预、不是医院自己的清洗、带家属房间与安静路径的太平间、及一些丧子家庭提出的遗照——是围产期居丧协议教会所有人的、及用平实语言解释的尸检请求及其法律机制、及居丧与后续医学在家属中识别“有复杂居丧的风险”——突然与暴力与被污名化、及因自杀及因孩子及曾是秘密家庭的配偶照护者的居丧、及写进出院文件里而可能被读也可能不被读的居丧服务与全科及慈善及信仰社区支持、及第二周那位护士的电话、证据说那是价值最高的部分、及本专科发明的后续讨论文化、因为一周经历四次死亡而没有语言会变成一项人员危害、及应该在十年之内被召见的、及死亡与不良结局审查应该像“给对了吗”一样认真地问“她与她的家属被怎样对待”、因为对最后一周的审计正是一家医院最应该为不及格而感到羞愧的审计。**
:::

::: example 一次其实是回家的入院 {#ex-lastdays}
一名74岁终末期心衰患者“为了优化”入院；她整天睡、什么都不吃、血压82/50、肌酐上升、病房里已经发生过两次家庭危机；心内科团队想要“在我们决定之前再做一次超声”；女儿说“我母亲一直在问我们是不是在等什么”。
::: solution
**命名最后几日、然后清场（[[#def-recognition]]、[[#def-dying]]）：识别与诚实的动作——“女儿那句话就是诊断：患者已经知道几周来团队没有说出的事、而为一个没人能优化的射血分数做优化是治疗计划的委婉语；接下来24小时应当包含一次由顾问医师主导、他们两人在场的谈话描述轨迹、用她被问起时同样的语域回答“我们到了吗——在死去吗”、及就医院仍能做什么做决定（是症状控制与她女儿的椅子、不是正性肌力药、除非姑息与心内科团队确信它们服务于一个具名的目标、比如回家）而超声不是下一个动作；被明显地执行的反转清单——”一张逐条解释的停药清单他汀、如果没有近期支架则阿司匹林、可能就是那个厌食元凶的地高辛、朝向舒适减少并对着她的呼吸困难而不是她的体重复审的利尿剂、退役的血糖与血压目标、削减到能改变今晚照护的频率、及如果她下周得胸部感染怎么办的谈话、抗生素两个方向都诚实；作为治疗的后勤——“回家去世不是一次出院、而是一次带着包的照护移交：社区护士带输注泵与预期药物与24小时电话、前屋里的一张医用床、若低氧则带氧、及夜里照亮的马桶路径、预约好的安宁居家访视、及在此刻确实是临床药物的葬礼与财务及孙辈上学的后勤、及一个被守住的承诺：救护车班组能读到这份计划；及用本章的语言在四周后重新问女儿那句话：你需要我们做到而没做到的——因为家庭会议里那个趁她还能回答的问题、就是可获得的最后一个临床动作。**
:::

::: example 被审查的凌晨三点病房死亡 {#ex-nightdeath}
一名86岁安老院住民、晚期痴呆、在03:40独自死在一间急性外科病房的侧室、因激越两次给予按需劳拉西泮而镇静、约束带“为了她的安全”系着；家属05:20到达；记录写“安静、平和”；儿子是警察、要求查看病历。
::: solution
**严重事件早已写在病历里（[[#def-after]]、[[#def-dying]]、[[geriatrics-palliative/delirium-dementia-care]]）：按顺序的审查发现——”死亡是可预期的、而濒死未被识别没有最后几日计划、没有预期药物、从未记录过首选照护地点的谈话、这把一条可预期的轨迹变成了一次急诊；当晚的处理是濒死照护的反面对未分化的激越给按需劳拉西泮而没有原因搜寻——膀胱与肠道与疼痛与低氧、没有内科复审的反复加量、及那条约束带、它从来不是一个舒适措施、而对一个无法同意的人来说是一个法律事件；及最糟的部分是文书：在第二次给药后无人检查她、家属被延迟电话通知时写下安静、平和、这份记录会把一个坏的死亡变成一起索赔、而更糟的是它很可能是假的；儿子将触发的流程——“坦诚职责的运作验尸官通报规则的核查、带审计轨迹说明的原样保全病历、由顾问医师与当班护士及风险团队与家属一起的会议并回答他们真正的问题而不是律师的语言、及范围包括儿子在问的问题而不是机构偏好问题的严重事件审查“；不是”更多培训“的修补——”包含约束与按需精神活性药审计触发的濒死者观察记录、安老院联络与最后几日标记、好让一位住民的最后一次入院不是外科病房的一场意外、可能今天就走的姑息反射、及安老院与病房里积极使用的预期处方、及一路触达她本该在这里吗的跌倒后与激越后复审、及那场03:40的人员后续讨论、因为夜班团队记住这场死亡会比本次审查里任何人都久、而后续讨论就是一个服务留住做这项工作的人员的方式“；及家属自己的后续——”从记录与那位住在附近的女儿及她在院里唱过的那首赞美诗重建她的意愿、及在儿子要求时让他在场为遗体清洗、因为儿子在病历之后的第一个问题是她受苦了吗、而唯一诚实的回答要来自一个因他问了而变得更好的服务。**
:::

::: example 家属必须洗身的遗体 {#ex-ghusl}
一名68岁穆斯林男性在23:00死于呼吸病房。住院医师打电话给太平间要求“立即转运”；一小时之内到达的家属请工作人员离开、好让他们为他洗身；一位护士已经开始标准的死亡后护理、搬运工在楼上等着、而居丧团队下班直到早晨。

::: exercise 教家属听懂濒死的声音 {level=1}

::: solution
**六十秒内的咕噜声谈话（[[#def-dying]]）：三句话——”先讲她身体语言里的事实：那个声音是唾液积在她喉咙后部、因为她实在太放松、太疲惫、吞不下去——它不痛、也不是窒息；她并不像您那样意识到它。然后是动作：我们可以改变她躺着的方式、这常常有帮助、还有一种药能在部分时间把它收干——它不完美、但如果这个声音让您担心的程度超过让她担心的程度、我们就会用它。第三是许可与真相：您可以坐在她身边、跟她说话、握她的手——听觉被认为是最后消失的感觉之一、即使这是一种民间说法、它也是那种不造成伤害的。如果您希望我们为不安给她用点药、请说出来；您永远不是在打扰我们。“手艺的标记：没有行话、没有虚假的确定、那个声音被命名、家属的角色被包括、及在凌晨两点的惊慌来电之前作出提议——是同一场谈话、音量是十倍。**

::: exercise 书写死亡证明 {level=2}

**作为法律与临床文件的证明（[[#def-after]]）：第一部分——(a) 支气管肺炎右下叶、有细菌培养记录或有引用的胸部临床记录做出的临床诊断——到死亡的间隔三天是诚实的最后事件数字；基础链条——(b) 血管性或多发性梗死或阿尔茨海默型痴呆、并写明吞咽困难与反复误吸这一环、因为“痴呆导致误吸、误吸导致肺炎”正是验尸官与临床医师都想明确看到的因果句；(c) 2型糖尿病与4期慢性肾病作为第二部分而不是第一部分的贡献因素、因为合并症属于那里、而第一部分是一个序列不是一个清单；由规则而不是由感觉回答的方式之问——”一位衰弱女性胸部感染前三天跌倒、而影像没有伤害、通常不构成验尸官转诊应用暴力或非自然之测与无人陪伴之测、不是应用迫害妄想之测、但若跌倒造成一次无人看见的髋部或头部伤害而使轨迹复杂化、那么转诊就是法律义务、而更好的证明正是验尸官能读懂的那一份“；及让医师陷入麻烦的空——”从病历估计并记录为估计的间隔、删去我不能排除的语言、改用来证据支持的最可能序列起始不确定与诊断不确定的相关规则、由死亡证明改革以检查医师模式而不是靠含糊的证明来处理、及亲身经历要求：如果你不认识她也从未见过她、那么你要不就把病历熟读到能诚实地证明、要么这个病例属于改革辩论正为那一缺口而发明的验尸官路径。**

::: summary
- 识别最后几日是一项背后有一份清单的临床动作：轨迹、睡眠、摄入、循环与呼吸模式、合在一起阅读并转换成一份具名计划、因为以日计的预后从不确定、而这是主张规划的理由、不是主张推迟的理由。
- 识别触发反转：液体与喂养与目标及多数药片被逐一重新考虑、抗生素作为一个目标决定来讨论、监测只在能改变今晚的地方保留。
- 濒死期以在场多于操作来治疗：口腔护理、重新摆放体位、预期药物、对一个咕噜声的抗毒蕈碱药加一次解释、及把角色交给家属。
- 死亡的识别是一项被教授的操作；证明是一份从记录写出的临床文件；验尸官与捐献路径有医学必须尊重的钟。
- 遗体的照护是文化医学：信仰家庭要求的清洗与时间与处理属于临床能力级别的知识、而安静的路径与家属房间是基础设施、不是奢侈品。
- 后续是死亡的一部分：对家属的坦诚、保全的记录、接受了后续讨论的人员、及用同一个声音问“她被怎样对待”的审查。
:::

## 练习

::: exercise 书写最后几日计划 {level=1}
在病房查房时你判断一名转移性乳腺癌患者处于最后几日。列出计划的各行：要停的药、要开始的药、监测、家属、信仰、后勤。
::: solution
**一页纸上的计划（[[#def-recognition]]、[[#def-dying]]）：带理由的停药清单他汀、双膦酸盐、非必需的抗高血压药、对照仍在使用阿片复审的泻药、朝向“无低血糖”目标减少的胰岛素、而继续使用的是治疗她实际拥有症状的药（阿片、止吐药、用于她的脑转移的抗癫痫药、激素继续然后复审）；开始清单（预期的皮下套装——镇痛、用于痛苦的止吐与镇静、抑制分泌、用于激越或癫痫的咪达唑仑——按剂量与路径处方、放在护士凌晨3点能取到的地方、及作为护理医嘱写下的口腔护理与皮肤与体位方案）；监测（与计划匹配的观察频率、随停药清单一起停止的血液检查、及带复审时间的一句预后（“在死去——12小时复审、若有痛苦则更早”）及那份默认不是心肺复苏的升级计划、按适用情况以有法律效力的紧急照护与治疗计划写下）；家属在房间里用家属会对自己孩子用的话说出“她可能今天或今夜离世”、探视弹性与过夜在场的许可、提供的角色（润唇、音乐、轮流坐班的排班、印在纸上的电话号码）；信仰（点名提供牧师与她自己的神职人员、而不是依据多年前勾选的宗教栏来假定、带时间计的礼仪请求、现在就记录的清洗偏好、因为一小时后所有人都忘掉一切时就会被问到）；及后勤床位朝向与窗户与安静病房的请求、像它很重要一样给出的殡仪与居丧假期信息、因为它确实重要、及如果她敢想要回家那份具名的照护包与回家计划。一页纸、一个负责人、抄送给病历与全科及家属的手机相机——一个好死亡就是这样被配置人员的。**

::: exercise 回答补液之问 {level=2}
一名濒死女性的家属坚持“给她挂个滴、她渴”：她有分泌物与踝水肿、半昏迷。真正地说服他们、或找到那个折中。
::: solution
**口渴在嘴里（[[#def-recognition]]）：用他们的语言讲生理——“在尽头、身体无法利用水：一滴注会加进她已经呼哧作响的分泌物、以及她无法抱怨的肿胀、而口渴的感觉住在干燥的嘴里、这是我们能够治疗的——常常治疗得更好——用安宁运动四十年磨出来的棉签与喷雾与海绵及安全时的冰块而在这里你要示范、不是描述：口腔护理就在他们面前做、好让他们看见它的技术“；两个方向都诚实——”皮下液体有时能帮助一个可逆的成分（邻近谵妄的脱水与药物清除的恶心、及她似乎在一袋之后醒过来的日子）、这就是为何存在一个带复审规则的试用版本：一次有定义的小量输注、一个我们正在看具体东西的名字、若它没有买到它看上去要买的东西就停止——这个计划是在家属帮助下问出的一个问题、不是向他们下达的一次拒绝“；及请求之下的悲恸——”滴注往往是他们觉得自己还能做的最后一件事、这就是为何替代方案必须是一个动作（口腔护理排班与这个你可以做的交接）、也是为何我们什么都没做在这个房间里从不真实、而应该列出我们改在做什么并大声说出来”。折中的回答：一次有时限、目标具名的液体试用、带明确的停止标准、或当分泌物已经在告诉你它会往哪边走时的以同情代液体的版本；两者都站得住、而不说出口的拒绝站不住。**

::: exercise 处理捐献谈话 {level=2}
一名34岁患者发生灾难性脑出血、正朝脑干死亡检测推进、而她的父母最近亲属说“她是车祸、她不会成为捐献者、请别再问了”。移植协调员已打过两次电话。现在怎么办？
::: solution
**一场极其严肃谈话中的捐献医学（[[#def-after]]、[[immunology/transplant-tumour-immunology]]、[[nervous-system/stroke]]）：即时的规则——“捐献的请求由受训的专科护士提出、在合适的时间与地点、在预后被理解之后——不是靠电话施压两次、也绝不是在复苏室的最初几分钟、而那句别再问了被回答一次、并且答得 properly：我会停下；如果在某个时点你们想知道成为捐献者意味着什么、我可以请人解释一次、而只要你们说不、答案就一直是说不——因为关于家属拒绝的文献（关于请求时机与专门请求者模式、及一个记录充分的：时机不当或带施舍姿态的请求会即使在愿意捐献的家庭里也硬化拒绝）讲的是把它做对、不是施压“；无论如何继续的平行职责——”脑干死亡检测与捐献是分开的谈话与分开的决定捐献之问不触碰检测之问、而父母需要那堵墙被明确说出来、因为医师会为了她的器官而停止救治并宣布她死亡这个恐惧、正是与拒绝同样杀死捐献的恐惧、而它用检测团队独立性的透明、及她可能受也可能不受其约束的法律框架（默认退出的同意架构、及各构成国不同且必须准确陈述的家属协商对家属否决的区别、及对她本人记录在案意愿的核查——捐献登记册、及她对朋友说过的、父母可能不知道的话）来回答“；答案保持不的路径——”这是正当且被尊重的、句号——终末照护按父母的时间表推进、告知协调员、而她其余器官的可能性绝不再次在家属面前被提及、因为对拒绝的尊严是赢得下一个家庭的一部分“；及他们再次问起的路径——”相当多的悲恸家庭会在一周之内这样做、这就是为何专科护士有耐心、为何重症监护保持生理支持的能力循环死亡后捐献的路径中循环停止的窗口是分钟而不是小时、这就是为何我们不再问了绝不能变成我们不再准备回答了。**

::: exercise 审计你所在单元的最后一周 {level=3}
为你的病房设计一次死亡审计：样本、数据来源、问题、阅读他人死亡现场的伦理、及值得向董事会报告的修补。
::: solution
**死亡与尊严审计（[[#def-after]]、[[clinical-skills/patient-safety]]、[[geriatrics-palliative/palliative-care]]）：样本与来源——”一个团队能真正复审的期间内每一例住院死亡单元层面是一个季度、带病历与护理及姑息记录、全科与安老院文件、用药表的审计轨迹、及那个使它不同于死亡病例讨论的部分：由另一个独立的人去接触并访谈家属、因为记录里装着人员的版本、而家属携带剩下的部分；按令人不适的顺序排列的问题——“她被识别为濒死了吗何时、由谁、是否记录、预期药物是否在首次需要时被处方并可获得、疼痛与痛苦是否在治疗后被评估（按需阶梯作为一条证据轨迹、不是一份菜单、约束与精神活性药的审计轨迹是否干净、家属是否被告知她可能死去及何时及用了什么话、她想去哪里而她为何不在那里、遗体及其文化要求是否被妥善处理、及证明：死亡证明上的死因是否与病历相符、验尸官转诊规则是否被遵守——所有这些都能从病历得到答案、而所有通常只被部分回答）；方法的伦理——”被访谈的家属是悲恸者、不是研究对象：访谈的邀请在点名支持服务的情况下提出、而人员被告知这次审计是有公开回应计划的学习、不是一次搜捕、而严重的失守另外走正常的保障与监管路径并且要快、不走审计日历、因为一个儿子报告一个坏的死亡值得几天之内的一通电话、并在审计报告里给出一个原因“；及董事会层——”能让董事会行动的指标：死亡地点对记录偏好的差距、有完成的最后几日计划及有预期药物可获得的死亡比例、独自死在侧室的院外时间死亡数字那个凌晨3点而没人告诉她儿子去的指标、每家医院都恨它、而它是本章最诚实的单一指标、死亡前后的按需精神活性药与约束费率、及每季度由做过护理观察的那个人朗读一份死亡的两段叙述、这就是这次审计如何保持为一项临床审计、而不是一次带命案杀人的行政练习。**
