病毒是一组被蛋白质包裹、有时还被一层膜包裹的基因，只能在活细胞内增殖。在细胞外，病毒颗粒什么也不做：它没有代谢，不产生能量，也不合成蛋白质。进入细胞后，它接管宿主的细胞机器来复制自己，往往复制成千上万次。

对宿主的依赖给医学带来两个后果。第一，药物可作用的靶点比细菌少，因为病毒复制的大多数步骤使用的是人体的酶。有用的抗病毒药物作用于病毒用自身蛋白完成的少数步骤。第二，病毒的复制方式解释了它在患者身上的表现：它如何传播，能否潜伏几十年，进化有多快，以及能否致癌。

本章介绍病毒颗粒的结构，巴尔的摩分类，复制周期及以其为靶点的药物，包括潜伏感染在内的各种感染结局，病毒的进化，宿主应答，以及致癌病毒。

## 病毒颗粒 {#virion}

::: definition 病毒体 {#def-virion}
**病毒体**是细胞外完整的病毒颗粒。它包括：

- **基因组**，为DNA或RNA，二者不会兼有；可以是单链或双链、线状或环状，可以是一整段或分为数个节段；
- **衣壳**，由重复亚单位构成的蛋白质外壳，保护基因组；大多数衣壳为**二十面体对称**（有20个面、大致呈球形）或**螺旋对称**（围绕核酸呈螺旋状）；
- 许多病毒还有**包膜**：病毒出芽时从宿主细胞获得的脂质膜，上面镶嵌着病毒**糖蛋白**，用于结合下一个细胞上的受体。
:::

病毒体非常小：从细小病毒的约20 nm到痘病毒的约300 nm。大多数只能用电子显微镜看到。

病毒有无包膜是一个很实用的事实。包膜是脂质膜，会被干燥、去污剂、肥皂和乙醇破坏。**有包膜病毒**，如流感病毒、麻疹病毒、疱疹病毒、HIV和SARS-CoV-2，通常需要密切接触、呼吸道分泌物、血液或性接触才能传播。**无包膜病毒**，如诺如病毒、轮状病毒、腺病毒、肠道病毒和人乳头瘤病毒，在物体表面存活的时间长得多，能耐受胃酸和胆汁，常经粪—口途径传播。诺如病毒对含醇手消毒剂相对耐受，因此暴发时要用肥皂和水洗手，并用含氯制剂清洁。

## 按基因组对病毒分类 {#baltimore}

病毒按结构和基因组序列分为不同的科。对于理解复制，更有用的分类是戴维·巴尔的摩（David Baltimore）于1971年提出的。它从一个事实出发：每种病毒都必须产生宿主核糖体能读取的**信使RNA**（mRNA）。基因组的类型决定了通向mRNA的途径。

::: definition 巴尔的摩分类 {#def-baltimore}
| 组 | 基因组 | 通向mRNA的途径 | 有医学意义的例子 |
|---|---|---|---|
| Ⅰ | 双链DNA | 宿主或病毒的RNA聚合酶转录DNA | 疱疹病毒、腺病毒、乳头瘤病毒、痘病毒 |
| Ⅱ | 单链DNA | 先转变为双链DNA | 细小病毒B19 |
| Ⅲ | 双链RNA | 病毒RNA聚合酶转录其中一条链 | 轮状病毒 |
| Ⅳ | 正链单链RNA | 基因组本身即可作为mRNA | 肠道病毒、诺如病毒、丙型肝炎病毒、黄病毒、冠状病毒 |
| Ⅴ | 负链单链RNA | 病毒RNA聚合酶把基因组复制成mRNA | 流感病毒、麻疹病毒、腮腺炎病毒、呼吸道合胞病毒、狂犬病毒、埃博拉病毒 |
| Ⅵ | 带逆转录酶的单链RNA | RNA被复制成DNA，DNA整合入宿主基因组 | HIV、HTLV-1 |
| Ⅶ | 带逆转录酶的部分双链DNA | 通过RNA中间体复制 | 乙型肝炎病毒 |
:::

每一组都有其特定的需要。人体细胞没有以RNA为模板复制RNA的酶，因此所有RNA病毒都必须编码**依赖RNA的RNA聚合酶**。正链基因组一进入细胞就能被翻译，所以聚合酶由它产生。负链基因组不能被直接读取，因此病毒体必须把聚合酶分子带入细胞。逆转录病毒和乙型肝炎病毒编码**逆转录酶**，这是一种把RNA复制成DNA的酶。这些病毒酶在人体内没有对应物，是抗病毒药物的主要靶点。

## 复制周期 {#replication}

::: theorem 病毒复制的步骤，以及每一步为何都是药物靶点 {#thm-cycle}
每种病毒都要完成同样的一系列步骤：

1. 病毒蛋白与宿主细胞上的受体**吸附**；
2. 通过包膜与细胞膜融合或通过内吞作用**穿入**；
3. **脱壳**，基因组从衣壳中释放出来；
4. **基因组表达和复制**，合成病毒蛋白和新的基因组；
5. 新病毒体的**装配**；
6. 通过膜出芽或细胞裂解而**释放**，有时随后还要**成熟**。

依赖于一种在人体中没有对应物的病毒蛋白的步骤，就是选择性药物的潜在靶点。
:::

::: proof
选择性毒性要求病毒与宿主之间存在差异。只使用宿主机器的步骤，如在宿主核糖体上的翻译，无法在不伤害细胞的情况下被阻断。使用病毒酶或病毒表面蛋白的步骤则可以。

- **吸附和穿入。**HIV先结合CD4，再结合辅助受体CCR5或CXCR4。马拉韦罗（maraviroc）阻断CCR5，恩夫韦肽（enfuvirtide）阻断融合。
- **脱壳。**甲型流感病毒需要M2离子通道才能脱壳。金刚烷胺（amantadine）曾能阻断它，但目前几乎所有流行株都已耐药，所以不再用于流感。
- **基因组复制。**这是最丰富的靶点。阿昔洛韦（aciclovir）等**核苷类似物**被病毒聚合酶掺入病毒DNA，使链延伸终止。HIV逆转录酶可被核苷类和非核苷类抑制剂阻断。丙型肝炎病毒聚合酶可被索磷布韦（sofosbuvir）阻断。把病毒DNA插入宿主染色体的HIV**整合酶**可被多替拉韦（dolutegravir）等整合酶抑制剂阻断。
- **装配和成熟。**HIV和丙型肝炎病毒先合成长的多聚蛋白，再由病毒**蛋白酶**切割成有功能的部分；蛋白酶抑制剂阻止这一过程。
- **释放。**流感病毒**神经氨酸酶**切割唾液酸，使新病毒体得以离开细胞；奥司他韦（oseltamivir）和扎那米韦（zanamivir）抑制这种酶。
:::

受体决定**嗜性**，即病毒所感染的细胞和组织范围。流感病毒血凝素结合呼吸道上皮上的唾液酸。SARS-CoV-2结合ACE2。EB病毒结合B细胞上的CD21。HIV感染带有CD4的细胞，主要是辅助性T细胞和巨噬细胞。受体使用的改变可以改变疾病：禽流感病毒偏好人肺深部的一种唾液酸形式，这是它们难以在人与人之间传播、但一旦感染又会引起严重肺炎的原因之一。

在同步感染的实验室培养中，有感染性的病毒体数量起初会下降，因为进入的颗粒已经脱壳、不再具有感染性。在新病毒体出现之前的这段空白称为**隐蔽期**。随后，当细胞释放子代病毒时，感染性滴度急剧上升。一个细胞释放的新病毒体数量称为**裂解量**，可达数百乃至数千。

## 感染的结局 {#outcomes}

病毒感染可以有几种不同的进程，取决于病毒和宿主。

- **急性感染**：病毒复制，免疫应答将其清除，宿主获得免疫。例如流感、麻疹、轮状病毒感染和甲型肝炎。
- **慢性（持续性）感染**：由于免疫应答未能清除病毒，病毒持续复制数月或数年。例如乙型肝炎、丙型肝炎和HIV感染。
- **潜伏感染**：病毒以休眠形式存在，很少或不产生病毒体，以后可以再激活。
- **转化**：病毒改变所感染细胞的生长调控，有时导致癌症。

::: definition 潜伏感染 {#def-latency}
**潜伏感染**是指病毒基因组存在于细胞中而不产生感染性病毒的状态。只有少数病毒基因表达，因此被感染的细胞几乎不被免疫系统察觉。当免疫控制减弱，或在应激、发热、紫外线等诱因作用下，可发生向增殖性感染的**再激活**。

所有人类疱疹病毒都能建立潜伏感染：

- **单纯疱疹病毒**1型和2型潜伏于感觉神经节，再激活时表现为唇疱疹或生殖器疱疹；
- **水痘-带状疱疹病毒**潜伏于背根神经节和脑神经节，再激活时表现为带状疱疹；
- **EB病毒**潜伏于记忆B细胞；
- **巨细胞病毒**潜伏于髓系细胞，在器官移植受者和晚期HIV感染者中再激活。
:::

潜伏感染解释了疱疹病毒感染为何终身存在。抗病毒药物作用于正在复制的病毒，因此能缩短再激活的病程，但不能清除潜伏的基因组。HIV有一个类似的储存库：静止的记忆T细胞中整合的前病毒DNA在有效治疗下依然存在，这就是抗逆转录病毒治疗必须终身进行的原因。

::: example 局限于一个皮节的痛性皮疹 {#ex-shingles}
一名74岁的南亚裔女性左侧胸部烧灼样疼痛三天，随后出现一条由红色丘疹和水疱组成的带状皮疹，止于中线。她小时候出过水痘。请解释其病毒学机制以及早期抗病毒治疗的道理。
::: solution
这是**带状疱疹**。她儿时患水痘后，水痘-带状疱疹病毒沿感觉神经上行，潜伏于支配该皮节的背根神经节。随着年龄增长，针对该病毒的T细胞免疫下降。病毒再激活，在神经节中复制引起疼痛，并沿神经下行到皮肤，在一个皮节内引起皮疹。在肤色较深的皮肤上，发红可能不太明显，水疱和皮节分布是更可靠的体征。

阿昔洛韦或伐昔洛韦（valaciclovir）等抗病毒药物通常在皮疹出现后72小时内开始使用，遵循当地指南。它们抑制病毒DNA复制，能缩短再激活的病程并可能减轻急性疼痛。它们不能清除潜伏的病毒。老年人发生**带状疱疹后神经痛**的风险更高，即皮疹愈合后仍持续的疼痛。英国为老年人和免疫功能低下者提供带状疱疹疫苗；目前的接种对象见《绿皮书》（Green Book）。
:::
:::

## 病毒的进化 {#evolution}

RNA病毒进化迅速。它们的聚合酶缺乏DNA聚合酶的校对功能，每复制10,000～100,000个核苷酸大约出错一次。由于基因组约有10,000个核苷酸，复制次数又极多，几乎每个新基因组都与其亲代不同。因此，感染者体内携带着一群彼此相关的变异株，有时称为**准种**。能抵抗药物或逃避抗体的变异株会被迅速选择出来。

这就是为什么HIV总是用多种药物联合治疗。单一药物在数周内就会选择出耐药突变株，而病毒需要同时出现几个突变才能逃脱三种药物，这种可能性极小。

::: definition 抗原漂移与抗原转换 {#def-drift-shift}
流感病毒以两种方式改变其表面抗原**血凝素**（H）和**神经氨酸酶**（N）。

- **抗原漂移**：H和N基因中点突变的逐渐积累。针对去年病毒产生的抗体与今年病毒的结合减弱。漂移引起季节性流行，也是疫苗每年都要更新的原因。
- **抗原转换**：整个H或N基因被一个新基因替换，新基因通常来自动物流感病毒。流感病毒基因组有八个独立的RNA节段，当两种不同的病毒感染同一个细胞时，它们的节段可以混合（**重配**）。带有新血凝素的病毒遇到几乎没有免疫力的人群，就可能引起**大流行**。抗原转换只发生在甲型流感病毒，它在鸟类和猪中有动物宿主。
:::

::: example 漂移还是转换？ {#ex-influenza}
报告了两种情况。(a) 在一个普通的冬季，流行的H3N2株与疫苗株相比，血凝素有几处氨基酸改变，疫苗效力低于往常。(b) 人群中出现了一种新的甲型流感病毒，其血凝素基因来自一种禽流感病毒，其他基因来自人和猪的流感病毒；它迅速在全世界传播。请对每种情况分类，并解释其公共卫生后果。
::: solution
(a) 是**抗原漂移**。病毒亚型不变，但点突变改变了血凝素上的抗体结合位点。许多人有部分免疫力，因此结果是一次季节性流行，与疫苗株的不匹配降低了保护作用。应对措施是每年更新疫苗株，依据由世界卫生组织协调的全球监测。

(b) 是**抗原转换**。重配使病毒获得了一种大多数人没有抗体的血凝素。这可以引起各年龄组罹患率都很高的大流行。与新的甲型流感病毒相关的大流行例子有1957年（H2N2）、1968年（H3N2）和2009年（H1N1）。应对措施包括大流行防范计划、迅速研制匹配的疫苗，以及按国家指南使用神经氨酸酶抑制剂。
:::
:::

## 宿主应答 {#host-response}

病毒生活在细胞内，因此免疫系统要么在病毒进入之前将其阻挡，要么杀死藏匿病毒的细胞。

- **干扰素。**被感染的细胞察觉到病毒核酸后释放**Ⅰ型干扰素**（干扰素-α和干扰素-β）。它们与邻近细胞结合，诱导**抗病毒状态**：一旦病毒进入，就有降解RNA和停止蛋白质合成的酶发挥作用。病毒性疾病的发热、肌痛和乏力也有很大一部分由干扰素引起。
- **自然杀伤细胞**杀伤失去MHCⅠ类分子的细胞；许多病毒从细胞表面去除这些分子，以躲避T细胞。
- **细胞毒性T细胞**识别MHCⅠ类分子上的病毒肽并杀死被感染的细胞。它们对于清除已建立的感染和控制潜伏的疱疹病毒必不可少。
- **抗体**通过阻断吸附或穿入来中和游离的病毒体，是大多数疫苗提供的主要保护。

有些疾病由这种应答而不是由病毒本身引起。在急性乙型肝炎中，肝损伤在很大程度上由T细胞杀伤被感染的肝细胞所致。这些机制的细节见[[immunology/innate-immunity]]和[[immunology/adaptive-responses]]。

::: example 衡量治疗反应 {#ex-viral-load}
一名新诊断HIV感染的34岁男性，血浆病毒载量为100,000拷贝/mL。开始抗逆转录病毒治疗后，在第一阶段的下降中，病毒载量以约1.5天的半衰期下降。假设这一半衰期保持不变，估算15天后的病毒载量，并用对数下降值表示这一下降。
::: solution
15天是$15/1.5 = 10$个半衰期。病毒载量为

$$
100{,}000 \times 2^{-10} = \frac{100{,}000}{1{,}024} \approx 98 \text{ 拷贝/mL}
$$

下降倍数为$1{,}024$，因此**对数下降值**为$\log_{10} 1{,}024 \approx 3.0$，约下降一千倍。

实际上，第一阶段之后下降会减慢，因为寿命较长的被感染细胞仍在持续释放病毒。病毒载量通常在开始治疗后几个月内降至检测不到。快速的第一阶段表明，大部分血浆病毒来自寿命短、正在活跃感染的细胞，它也提供了一个可测量的早期信号，说明药物正在起作用。病毒载量用对数尺度报告，因为它跨越多个数量级，变化小于约0.5个对数通常被视为正常波动范围之内。
:::
:::

## 病毒与癌症 {#oncogenic}

全世界大约八分之一的癌症归因于感染。其中许多由细菌幽门螺杆菌（*Helicobacter pylori*）引起，其余大部分由病毒引起。能致癌的病毒称为**致癌病毒**。

::: definition 致癌病毒 {#def-oncovirus}
**致癌病毒**通过改变细胞生长的调控而促成癌症。主要的人类例子有：

| 病毒 | 主要癌症 |
|---|---|
| 人乳头瘤病毒，尤其是16型和18型 | 宫颈癌、肛门癌、口咽癌、外阴癌、阴道癌和阴茎癌 |
| EB病毒 | 伯基特淋巴瘤、鼻咽癌、部分霍奇金淋巴瘤、移植后淋巴组织增生性疾病 |
| 乙型和丙型肝炎病毒 | 肝细胞癌 |
| 人类疱疹病毒8型 | 卡波西肉瘤、原发性渗出性淋巴瘤 |
| HTLV-1 | 成人T细胞白血病/淋巴瘤 |
| 默克尔细胞多瘤病毒 | 默克尔细胞癌 |
:::

机制各不相同。高危型HPV产生两种蛋白质，**E6**和**E7**。E6促进抑癌蛋白**p53**的降解，E7使视网膜母细胞瘤蛋白**Rb**失活。细胞失去了DNA损伤后停止分裂的检查机制，突变不断积累。乙型和丙型肝炎主要通过数十年的炎症、肝细胞死亡和再生致癌，常在肝硬化形成之后，不过乙型肝炎病毒DNA也可以整合到宿主基因组中。

在每种情况下，感染都是必要的而不是充分的：大多数感染者从未发生癌症。还需要其他突变、免疫抑制和时间。这就是病毒所致癌症可以预防的原因：接种HPV和乙型肝炎疫苗，治疗乙型和丙型肝炎，以及筛查癌前病变。

::: example HPV检测阳性 {#ex-hpv}
一名31岁女性在英格兰参加宫颈筛查。她的标本高危型HPV检测阳性，细胞学显示低级别病变。请解释这些结果的意义，以及为什么筛查从HPV检测开始。
::: solution
高危型HPV在年轻成人中非常常见，大多数人在一至两年内由免疫系统清除。癌症的发生需要高危型的持续感染。在持续感染的细胞中，病毒基因组可能整合到宿主DNA中，E6和E7的持续表达在许多年里推动细胞走向癌变。

英格兰采用**HPV初筛**：标本先检测高危型HPV，只对HPV阳性的标本做细胞学检查。HPV检测阴性意味着此后数年发生宫颈癌的风险极低，这就是为什么截至2026年，英格兰25～49岁检测阴性者的复查间隔为五年。像本例这样HPV阳性且细胞学异常，需转诊做**阴道镜检查**以寻找癌前病变，遵循国家筛查规程。

在青春期、暴露之前接种HPV疫苗，能预防疫苗所覆盖型别的感染，预计将在未来几十年中大幅减少宫颈癌。
:::
:::

::: warning 朊粒不是病毒
**朊粒**引起克-雅病等传染性海绵状脑病。它们有时与病毒放在一起讲授，但不含核酸。朊粒是一种正常宿主蛋白PrP的错误折叠形式，它能把正常蛋白转变为错误折叠的形式。朊粒不引起免疫应答，也不能被常规灭菌方法破坏，因此用于高危组织的手术器械需要特殊处理。抗病毒药物和针对病毒的常规实验室方法对它们都不适用。
:::

::: quiz
为什么流感病毒需要在病毒体内携带RNA聚合酶，而脊髓灰质炎病毒不需要？
- [ ] 流感病毒在细胞质中复制，而脊髓灰质炎病毒在细胞核中复制
- [x] 流感病毒是负链基因组，核糖体不能读取，而脊髓灰质炎病毒的基因组可以直接作为mRNA
- [ ] 脊髓灰质炎病毒利用宿主的依赖RNA的RNA聚合酶
- [ ] 流感病毒是DNA病毒
::: solution
脊髓灰质炎病毒是**正链**RNA基因组，一进入细胞就被核糖体翻译，产生病毒聚合酶。流感病毒是**负链**基因组，即mRNA的互补链，不能被翻译。如果病毒体内没有包装聚合酶，就无法产生病毒mRNA。人体细胞没有依赖RNA的RNA聚合酶，而且流感病毒是少见的在细胞核内复制的RNA病毒。
:::
:::

::: history
1892年，德米特里·伊万诺夫斯基（Dmitri Ivanovsky）证明烟草花叶病的病原体能通过截留细菌的滤器。1898年，马丁努斯·贝杰林克（Martinus Beijerinck）认为它是一种只在活细胞中增殖的新型传染因子；同年，弗里德里希·吕夫勒（Friedrich Loeffler）和保罗·弗罗施（Paul Frosch）证明牛的口蹄疫由一种可滤过的病原体引起。1901年，沃尔特·里德（Walter Reed）领导的委员会证明黄热病由蚊子传播、由可滤过的病原体引起，这是第一种被归因于病毒的人类疾病。

20世纪30年代末，人们第一次用电子显微镜看到了病毒。1949年，约翰·恩德斯（John Enders）、托马斯·韦勒（Thomas Weller）和弗雷德里克·罗宾斯（Frederick Robbins）在非神经组织的人体组织培养中培养出脊髓灰质炎病毒，使脊髓灰质炎疫苗成为可能，并因此获得1954年诺贝尔奖。1970年，霍华德·特明（Howard Temin）和戴维·巴尔的摩各自独立发现了逆转录酶，1971年巴尔的摩提出了他的分类法。哈拉尔德·楚尔·豪森（Harald zur Hausen）在20世纪80年代初在宫颈癌中鉴定出HPV 16型和18型，这项工作于2008年获得诺贝尔奖。
:::

## 后续内容

抗病毒的免疫机制见[[immunology/innate-immunity]]和[[immunology/adaptive-responses]]，疫苗见[[immunology/vaccines-immunotherapy]]。抗病毒药物与其他抗微生物药物一起在[[microbiology/antimicrobials]]中讨论，从PCR到血清学的病毒实验室检测见[[microbiology/laboratory-diagnosis]]。主要的临床病毒感染见[[infectious-diseases/hiv]]、[[respiratory/respiratory-infections]]和[[gastrointestinal/liver-disease]]。

::: summary
- 病毒体是装在蛋白质衣壳中的DNA或RNA基因组，有时有脂质包膜。有包膜病毒脆弱；无包膜病毒能在物体表面存活并耐受乙醇。
- 巴尔的摩分类按病毒产生mRNA的方式分组。RNA病毒需要自己的依赖RNA的RNA聚合酶；逆转录病毒和乙型肝炎病毒需要逆转录酶。
- 复制经历吸附、穿入、脱壳、基因组复制、装配和释放。药物作用于使用病毒蛋白的步骤：穿入、聚合酶、整合酶、蛋白酶和神经氨酸酶。
- 感染可以是急性、慢性、潜伏或转化性的。疱疹病毒形成潜伏感染并再激活；抗病毒药物不能清除潜伏的基因组。
- RNA病毒突变迅速。流感病毒的漂移引起季节性流行；通过重配发生的转换可引起大流行。
- 干扰素、自然杀伤细胞、细胞毒性T细胞和中和抗体控制病毒感染，而免疫应答本身也造成部分疾病。
- HPV、EB病毒、乙型和丙型肝炎病毒、HHV-8、HTLV-1和默克尔细胞多瘤病毒促成癌症；疫苗接种、治疗和筛查能预防其中的大部分。
:::

## 习题

::: exercise 对基因组分类 {level=1}
把每种病毒归入其巴尔的摩分组：(a) 甲型流感病毒，(b) HIV，(c) 乙型肝炎病毒，(d) 诺如病毒，(e) 单纯疱疹病毒。
::: hint
问一问基因组由什么构成、是什么极性，以及是否涉及逆转录。
:::
::: solution
(a) Ⅴ组，负链单链RNA。(b) Ⅵ组，带逆转录酶的单链RNA。(c) Ⅶ组，部分双链DNA，通过逆转录经RNA复制。(d) Ⅳ组，正链单链RNA。(e) Ⅰ组，双链DNA。
:::
:::

::: exercise 对数下降值 {level=1 check="3.7"}
一名患者在治疗期间丙型肝炎病毒载量从250,000 IU/mL降至50 IU/mL。对数下降值是多少？保留一位小数。
::: hint
对数下降值$= \log_{10}(\text{治疗前}/\text{治疗后})$。
:::
::: solution
比值为$250{,}000/50 = 5{,}000$，$\log_{10} 5{,}000 \approx 3.70$。对数下降值为**3.7**。
:::
:::

::: exercise 包膜与手卫生 {level=1}
解释为什么含醇手消毒剂对流感病毒有效，而对诺如病毒不太可靠。
::: hint
包膜由什么构成？
:::
::: solution
流感病毒有脂质**包膜**，乙醇能溶解它；失去包膜糖蛋白后，病毒无法吸附或进入细胞。诺如病毒没有包膜。它的蛋白质衣壳对乙醇更耐受，因此在诺如病毒暴发期间，工作人员要用肥皂和水洗手，通过机械作用去除病毒，物体表面用含氯制剂清洁。
:::
:::

::: exercise 阿昔洛韦为何具有选择性 {level=2}
阿昔洛韦能抑制单纯疱疹病毒，而对未感染细胞毒性很小，但它不能治愈感染。请解释这两个事实。
::: hint
最先使阿昔洛韦磷酸化的是哪种酶？病毒聚合酶在感染的哪种状态下是活跃的？
:::
::: solution
阿昔洛韦是核苷类似物。它必须磷酸化才能起效，而第一个磷酸基团只有**病毒胸苷激酶**能高效地加上，因此药物主要在被感染的细胞中被激活。其余的磷酸基团由宿主酶加上。三磷酸阿昔洛韦随后优先被**病毒DNA聚合酶**利用，一旦掺入病毒DNA就终止链的延伸。

它不能治愈，是因为在**潜伏**状态下，病毒并不在神经节神经元中复制其DNA。只作用于DNA合成的药物对潜伏的基因组没有影响，因此停药后仍可再激活。耐药通常由病毒胸苷激酶的突变引起。
:::
:::

::: exercise 估算半衰期 {level=2 check="1.5"}
开始治疗后，病毒载量在6天内从80,000降至5,000拷贝/mL，呈单一指数下降。半衰期是多少天？
::: hint
病毒载量减半了多少次？
:::
::: solution
$80{,}000/5{,}000 = 16 = 2^4$，所以6天内经过了四个半衰期。半衰期为$6/4 = 1.5$天。
:::
:::

::: exercise 每年接种的疫苗 {level=2}
流感疫苗每年都要更新，而童年接种的麻疹疫苗能保护几十年。两者都是聚合酶易出错的RNA病毒。请解释这一差别。
::: hint
想一想每种病毒对其表面蛋白改变的耐受程度，以及重配。
:::
::: solution
两种病毒的突变率相近。差别在于突变能带来什么。流感病毒血凝素的抗体结合位点能容忍许多改变而仍保持功能，因此每年都会出现并传播逃避抗体的变异株：即**抗原漂移**。甲型流感病毒还能通过重配获得一种全新的血凝素。

麻疹病毒的表面蛋白受到的约束大得多。中和抗体所针对位点的改变往往会损害其功能，因此该病毒基本上一直只有一个血清型。疫苗诱导的抗体因而能持续中和流行株，两剂接种可提供持久的保护。
:::
:::

::: exercise 移植后的巨细胞病毒感染 {level=3}
一名52岁男性接受了巨细胞病毒（CMV）血清阳性供者的肾脏；他本人血清阴性。移植后六周，在强化免疫抑制期间，他出现发热、白细胞减少和肝功能异常。请解释他为何风险很高、如何监测CMV，以及预防的思路。
::: hint
考虑供者器官中的潜伏感染、受者缺乏免疫力，以及T细胞的作用。
:::
::: solution
CMV是一种疱疹病毒，**潜伏**在供者肾脏的细胞中。受者以前没有免疫力，因此当病毒在移植器官中再激活时，不会遇到记忆T细胞或抗体。他使用的免疫抑制剂旨在阻断针对移植物的T细胞应答，也同时阻断了控制CMV所需的T细胞。供者阳性、受者阴性的移植发生CMV病的风险最高。

CMV通过血液**定量PCR**监测。病毒载量上升能在症状出现之前或出现时发现病毒复制。

预防采用移植指南规定的两种策略之一：**预防性用药**，即移植后在一定时期内给所有高危受者使用抗病毒药物；或**抢先治疗**，即定期监测PCR，在病毒载量超过阈值时开始治疗。他的病情应立即进行PCR检测并接受专科治疗。
:::
:::

::: exercise 家禽工人感染新型流感病毒 {level=3}
一名家禽养殖场工人在扑杀感染了高致病性禽流感A(H5N1)的禽类后出现结膜炎和发热。PCR确认为H5感染。请解释为什么即使这名工人康复了，这个病例对公共卫生仍然很重要，以及哪些病毒学事件会使之成为大流行威胁。
::: hint
考虑受体结合、重配以及人传人。
:::
::: solution
人感染禽H5病毒说明病毒能够跨越物种屏障。大多数人没有针对H5血凝素的抗体，因此一种能在人与人之间高效传播的变体可能引起大流行。

两种病毒学变化会加大威胁。**受体适应**：禽流感病毒偏好人肺深部而非上呼吸道的一种唾液酸形式，这限制了通过咳嗽和打喷嚏排出病毒；把偏好转向上呼吸道受体的突变会促进传播。**重配**：如果这名工人或一头猪同时感染了人季节性流感病毒，八个RNA节段可以混合，产生一种具有H5表面、而内部基因已适应人类的病毒。

公共卫生应对遵循国家指南：报告、隔离、抗病毒治疗，对接触者进行检测和抗病毒预防，为工人提供防护装备，并对病毒测序以寻找适应哺乳动物的变化。这名工人没有继续传播是令人放心的，但监测仍在继续。
:::
:::
