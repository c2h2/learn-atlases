病毒学奖励一种“结构式”的思考：**基因组的类型决定复制的策略、复制的策略决定可用的药物、而宿主对一个被感染的细胞的反应决定了大多数的症状——这就是为什么“病毒性”的病有它那种感觉、以及为什么在数百种人类病毒中只有少数几种有治疗。**本章通过你真正会处理的感染来讲病毒的生物学。

本章涵盖病毒的结构与复制、抗病毒的原则、呼吸道与全身性的RNA病毒、疱疹与DNA病毒、肝炎病毒、以及HIV与麻疹及新发病毒特殊的情况。

## 通向何处

检测的方法在[[microbiology/laboratory-diagnosis]]；抗病毒的药理学在[[microbiology/antimicrobials]]；与免疫缺陷的交叉在[[immunology/immunodeficiency]]；规划与暴发的控制在[[public-health/communicable-disease-control]]与[[paediatrics/immunisation]]；HIV的医学在[[infectious-diseases/hiv]]。

::: history
**病毒学始于一个“可以过滤的幽灵”：伊万诺夫斯基1892年的烟草花叶病的滤液、与贝杰林克把它命名为“活的、有生命的流体”（以及他拒绝称之为细菌）、以及1897年洛夫勒与弗洛施对口蹄疫滤液的确认、以及里德与卡罗尔及阿加蒙特1900年对黄热的“蚊子传播”的证明伴其人—蚊—人的实验——其中一些以志愿者丧命为代价、在教授研究伦理时值得记住——[[medical-ethics-law/research-ethics]]；噬菌体与结构的年代——1917年埃勒曼与特沃特对噬菌体的发现、以及温德尔·斯坦利把烟草花叶病毒结晶、证明病毒是“有生物学的化学品”、以及超速离心与电子显微镜的“计数”的年代、以及那一系列传代造就了17D的黄热及沙宾与索尔克的脊髓灰质炎疫苗、及泰勒的诺贝尔奖——[[public-health/global-health]]；肿瘤病毒学这条线——1911年劳斯的“鸡的肿瘤的滤液”及其被冷落四十年、然后是杜尔贝科及特明及巴尔的摩用反转录酶把它翻转过来诺贝尔奖、与 src 这一癌基因的由来、以及楚尔·豪森确立人乳头瘤病毒致癌、以及随之而来的疫苗、以及EB病毒与伯基特的“非洲的地方性圈”那张淋巴瘤的分布图、与“猿不吃香蕉”的论证、以及埃普特与阿琼的EB病毒的培养、以及困扰病毒学海拉细胞的交叉污染——[[pathology/cancer-biology]]、[[genetics/cancer-genetics]]；肝炎检测的年代——麦卡洛姆1947年的“传染性血清的肝炎”、以及布隆伯格的“澳大利亚抗原”取自一组原住民的血清、以及他的血友病的队列研究揭示了经肠外的传播、以及该生物技术团队的克隆出乙肝疫苗——第一剂“癌症的疫苗”、经由重组的表面抗原、以及1989年霍顿与朱等人克隆并发现丙肝、以及随后几代的检测在数年之内净化了血液的供应——[[blood/transfusion]]、[[gastrointestinal/liver-disease]]；以及基因组的监测的年代——新冠病毒基因组的快速发布、与变体命名的政治、与“把测序当作常规的公共卫生服务”这场转型——[[public-health/communicable-disease-control]]。**
:::

::: summary
- 基因组的类型就是命运：复制的策略决定趋向性、突变的速率、持续存在的模式、以及“哪些药物类别可能存在”。
- 症状大多是免疫：急性的病毒性疾病是干扰素与正在死亡的上皮、这就是为什么抗病毒药的时机在峰值之前决定一切。
- 潜伏改写了自然史——疱疹病毒保证终身的暴露；免疫抑制决定了“哪一种病毒再激活、以及在哪里”。
- 漂移对转变解释了流感“每年对偶尔大流行”的行为；分节段的基因组的重配就是转变的机制。
- 征服大多数人类病毒的是疫苗、不是药物；在有药物的地方乙肝、丙肝、HIV、疱疹、流感、新冠病毒、它们反映的是由结构生物学发现特异的病毒酶。
- 诊断由实验室完成——聚合酶链的组合检测、抗原的检测、血清学的时机、以及测序——而验前概率与标本的选择是临床的技能。
:::

**病毒学检测的选择（[[#def-respiratory]]、[[#def-herpes]]、[[#def-bloodborne]]、[[microbiology/laboratory-diagnosis]]）：急性的HIV——第四代的“抗原抗体联合”检测及其窗口、以及在临床怀疑时查核糖核酸血清转换病的鉴别、以及EB病毒、以及“不要用只测抗体的检测”——[[infectious-diseases/hiv]]；单核细胞增多症——嗜异性抗体在年轻人中敏感性的限度、以及EB病毒的衣壳免疫球蛋白G与免疫球蛋白M及核抗原的判读的方格既往对原发对再激活、以及异型淋巴细胞与肝功能的辅助——[[blood/haematopoiesis]]；妊娠的流感——呼吸道组合检测的周转与“尽早治疗”的论证、以及“不要等检测才治疗”孕妇住院风险的数字——[[obstetrics-gynaecology/pregnancy-complications]]；麻疹的免疫——定性的免疫球蛋白G的酶免疫、以及“疫苗接种史胜过血清学”之问、以及为接触者在暴发中测滴度；以及新生儿的巨细胞病毒——出生21天之内的尿或唾液的聚合酶链21天之后的污染的问题、以及“出生后晚期的宫内感染”的干血斑筛查敏感性的问题——[[paediatrics/newborn]]；以及那几条总括的规则——窗口的咨询、单份血清对成对血清的逻辑、以及“测序用于暴发、不用于常规诊断”的经济学——[[clinical-skills/laboratory-tests]]。**

::: exercise 为带状疹开处方 {level=1}
一名68岁的肾移植的受者肾小球滤过率32、用他克莫司与麦考酚酯在胸段三个皮节的皮疹出现60小时后就诊；疼痛8/10；无眼也无播散。请写出完整的方案。
::: solution
**免疫抑制宿主中的带状疹（[[#def-herpes]]、[[immunology/transplant-tumour-immunology]]、[[nervous-system/headache-pain]]）：抗病毒——伐昔洛韦或大剂的阿昔洛韦、并按肾调整剂量“调整不足的神经毒性与意识模糊的风险”要诚实地写进记录、以及“播散或中枢或眼或内脏的疾病”用静脉阿昔洛韦的阈值三个皮节的表现正与之擦边、以及“延长疗程对加大剂量”这一实践上的变异、以及怀疑耐药的信号不典型的慢性的出血的病灶并转介膦甲酸钠；疼痛——神经病理性优先加巴喷丁类的“按肾的剂量与镇静及驾驶的咨询”、以及三环类的告诫与选择性的血清素再摄取的替代、以及局部的利多卡因贴剂的邻近、以及阿片的避开、以及“激素”之问回答为不用试验显示对疱疹后神经痛没有获益、而在免疫抑制者中增加风险——[[renal/potassium-calcium-phosphate]]、[[clinical-skills/patient-safety]]；感染控制与接触的规则——播散者用空气与接触、局限且病灶被遮盖者用标准预防、以及“易感的孕妇与新生儿及免疫受损的接触者”的建议带免疫球蛋白的窗口、以及停工之问移植患者作为产科病房的访客——[[obstetrics-gynaecology/pregnancy-complications]]、[[paediatrics/newborn]]；以及预防的重写——重组的带状疹疫苗用于免疫抑制的成人“非活的平台”的安全论证、以及与免疫抑制强度的时机、以及规划的扩展、以及疱疹后神经痛早期转介的路径、以及V1分布者“当天看眼科”的阈值——[[immunology/vaccines-immunotherapy]]、[[nervous-system/sensory-systems]]。**

::: exercise 处理一次针刺伤 {level=2}
一名医学生被一枚空心针的针头刺伤、来源患者后来被发现HIV阳性而病毒负荷不明、丙肝抗体阳性、而乙肝表面抗原阴性且表面抗体阳性。请规划接下来的72小时与6个月。
::: solution
**暴露后的医学（[[#def-antivirals]]、[[#def-bloodborne]]、[[infectious-diseases/hiv]]、[[clinical-skills/patient-safety]]）：即刻——用肥皂与水而不是腐蚀剂处理伤口、以及报告与事件的编号、以及职业健康与感染科值班对来源与暴露的分级审查空心与深度及可见的血及“末端的针头”风险的权重、以及为“检测来源”的同意与保密的架构对一个不愿被检测的来源进行检测的法律与伦理、以及被暴露的工作者自己记录的保密——[[medical-ethics-law/confidentiality]]、[[medical-ethics-law/consent-capacity]]；HIV的决定——“3小时为佳、24小时为上限、72小时仍应考虑”这条规则、28天的替诺福韦恩曲他滨加多替拉韦或拉替拉韦的方案配妊娠与肾及肝的检查、以及对副作用的安抚能提高完成率、以及基线及第6周及第12周有时6个月的检测时间表、连同第四代检测窗口的算术、以及职业健康随访的归属；乙肝与丙肝这两根线——“表面抗体已保护、不需要加强”或无应答者用加速的疫苗程序、以及丙肝“没有预防”的现实：第3到6周查聚合酶链、第12周查抗体、以及“若持续则早期治疗”的方案、以及“急性丙肝现在就治疗”的论证、以及经皮的传播率丙肝约千分之二、HIV约千分之三、而接种疫苗后的乙肝约千分之一要说清；以及人的系统——急性焦虑的处理、该告诉谁、工作的状态、同伴的支持、以及72小时与2周时的依从检查、以及针具的审计与安全的工程设计的教训、因为“该预防的那一次是下一次”——[[public-health/communicable-disease-control]]、[[public-health/environmental-occupational]]。**

::: exercise 设计一次病毒暴发的应对 {level=3}
一波诺如病毒让你的病房每天关闭、而同时一例麻疹到了急诊、那里有百分之三十的工作人员没有记录的免疫。请为两者写出7天的控制计划。
::: solution
**两种病原菌、两本手册（[[#def-respiratory]]、[[public-health/communicable-disease-control]]、[[infectious-diseases/healthcare-infections]]）：诺如——用肥皂与水洗手、以及含酒精的手消毒剂的局限、以及次氯酸钠的表面浓度、以及呕吐物的处理包及其处置的路径、以及病房关闭的阈值“工作人员在症状之后48小时”的规则、患者的同组安置、入院构成的管理、以及内镜与透析单元的专门规则——镇静期间气溶胶化的呕吐物这一课、以及用粪便的聚合酶链确认带告诫、以及分型测序、以及被算过成本病房周转的后果——[[gastrointestinal/bowel-disease]]、[[emergency-critical-care/acute-assessment]]；麻疹——立即空气传播的隔离与工作人员的防护口罩、以及暴露窗口的测绘、以及工作人员免疫的分诊“有记录的两剂、或1970年以前出生？”的本地政策、以及对不确定者“测滴度对立即接种”的决定、以及接触的预防72小时内的联合疫苗、以及在6天之内给免疫受损者与孕妇及婴儿用免疫球蛋白、以及公共卫生通报的时钟、以及候诊区与救护车的去污的后勤、以及“与医院的传播团队一起写的声明”、因为麻疹会成为社区的新闻；以及共享的治理——每日的发病的例会与下降的图表、以及易感患者的保护移植与肿瘤病房的“屏蔽”的规则、以及社交活动取消的阈值、以及“这两种疾病都追踪接种不足与服务不足的群体”这一公平的意识、以及把暴发的报告喂回一份预防的计划、好让下一次从第0周、而不是第2周开始——[[public-health/determinants-inequalities]]、[[clinical-skills/patient-safety]]。**
