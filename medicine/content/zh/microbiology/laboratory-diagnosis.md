临床微生物学有百分之二十是微生物的知识、百分之八十是标本的知识：**实验室只能查出你送给它的东西、你送的方式与你送的时机决定着你读到的几乎每一个结果、而最新的技术让“标本的选择与结果的判读”——而不是培养——成为稀缺的临床技能。**本章教从申请到报告的整条工作流：恰当地开单、各种方法及其限度、以及如何对每一类结果采取行动。

本章涵盖标本的选择与运送、显微镜与培养、抗原与分子的方法含测序、血清学及其时机的陷阱、以及抗菌的敏感性的报告。

## 拿到标本

::: definition 标本的选择与申请单 {#def-specimen}
**第一条规则——微生物学始于解剖（那张“无菌对已被定植”的地图：血与脑脊液及关节及胸腔及深部组织“通常是无菌的”、而痰对支气管肺泡灌洗对气管内吸出物构成“下呼吸道代表性”的一个谱以及尿的采集方法及其污染的梯度、以及“伤口的拭子对深部组织对骨活检”这个会改变处理的论证、以及那条“绝不要浅表地拭子一处慢性的伤口、然后治疗长出来的东西”的纪律——糖尿病足的拭子之争见[[microbiology/bacteria]]、导管的取样规则见[[renal/urinary-tract]]）；时机的规则尽可能“在抗生素之前留培养”、以及“休克时不要延误抗生素”这一例外、以及成对的血培养并保证足够的量成人每瓶10毫升、以及“第二套从另一个部位采”以区分污染者、以及疟疾的涂片与寄生虫的时机、以及心内膜炎“拉开间隔的几套对紧急的几套”的争论、以及血清学“急性期与恢复期成对”的逻辑、以及聚合酶链排毒的窗口（呼吸道在第1到3天、不是第10天、以及脑脊液的肠道病毒的聚合酶链对血清）；运送与后勤厌氧的运送培养基、到实验室的时间、以及温度的规则——脑膜炎球菌会死在冰箱里：怀疑脑膜炎球菌时血培养放在室温、而脑脊液绝不冷藏、以及要即刻处理、以及寄生虫的粪便的固定剂、以及病毒运送培养基的冷链——那个决定“阳性率”的“患者、部位、时机、容器”的四方对话、比任何仪器都更能决定产出；以及“申请单作为一份临床的文书”那些会改变实验室处理的危险因素的问题——为寄生虫的专业能力而问的旅行、为扩展的真菌与病毒的组合检测而问的免疫抑制、为生物膜的超声处理而问的器械——[[infectious-diseases/immunocompromised-host]]——以及那句“问临床医师到底在找什么”的对话、它是这个科室里产出最高的沟通——[[clinical-skills/records-handover]]。**

::: example 瓶长出“污染者”的血培养 {#ex-contaminant}
一名带人工髋的60岁患者有6周的发热与疼痛；两套血培养都在第5天长出痤疮丙酸杆菌；值班医生说污染；全科医师说那个髋“有点温”。
::: solution
**污染对人工关节感染的医学（[[#def-specimen]]、[[#def-methods]]、[[musculoskeletal/inflammatory-arthritis]]）：微生物的逻辑——丙酸杆菌既是皮肤的常住者、又是被承认的人工器械的病原“晚发的、低度的肩与髋的人工关节感染”的表型：疼痛与僵硬、全身体征极轻、C反应蛋白正常或轻度、以及“第5天阳性”符合一种慢的微生物、而不是一蹴而就的假象、以及“两套都阳性且形态不同”这个论证、以及从深部标本得到同一种微生物是决定性的；检查——髋的穿刺液查“α-防御素与乳酸及细胞计数”、培养延长孵育、以及“若翻修则对取出的部件做超声破碎”、以及带“金属伪影抑制”的磁共振或CT、及核医学的标记白细胞的扫描、以及在安全时“为培养而停用抗生素的窗口”、以及含骨科与微生物与风湿与感染科的多学科团队——[[surgery/orthopaedics]]；若确诊的治疗方案——“清创并保留”对“一期交换”对“二期交换”按微生物与软组织及“部件可否更换”的逻辑、以及长节的定向的抗生素口服降级的“试验证据的时代”、以及丙酸杆菌用青霉素对替代、以及“保留的假体要不要加利福平”这一生物膜之问诚实地讨论；以及那则元教训——绝不在不了解临床背景的情况下否定一个结果按流程贴上“污染”的标签、而不去病房看一眼、会让人漏掉“两次翻修那么多”的诊断、以及血培养的判读的操作规程当微生物与器械相关时要共同审查、以及值得保护的“实验室与临床医师通电话”的文化——[[clinical-skills/clinical-reasoning]]、[[clinical-skills/communication]]。**

::: example 找不到微生物脑膜炎的脑脊液 {#ex-csf-negative}
一名30岁有发热、头痛与颈项强直；脑脊液400个中性粒细胞、蛋白1.5、糖低；在症状30小时后革兰染色阴性；血培养长出肺炎链球菌；团队在争论“是否继续阿昔洛韦”以及“是否覆盖李斯特菌”。
::: solution
**信息不全时的脑脊液的判读（[[#def-specimen]]、[[#def-methods]]、[[nervous-system/neuroinflammation]]）：生理的判读——“低糖而以中性粒细胞为主的脑脊液，在被证明是别的之前就是细菌性的”、而革兰染色的敏感性只有百分之五十到九十在早期或低负荷时更低、以及肺炎链球菌的脑膜炎中脑脊液的培养晚于血、以及脑脊液与尿的肺炎链球菌的抗原与聚合酶链的辅助、以及“脑膜炎的组合检测”的阳性与阴性连同既往抗生素的影响；治疗的决定——继续苄青霉素加头孢曲松、药敏已知后按药敏调整、并加上李斯特菌的覆盖按年龄或酒精或妊娠或免疫抑制或细胞免疫缺陷加氨苄西林的规则、而“革兰染色阴性”提高了李斯特菌的相对份额、以及阿昔洛韦之问——单纯疱疹“典型是淋巴细胞为主、而早期可以是中性粒细胞为主”头24小时的例外、以及“任何有脑表现的画面都要持续用阿昔洛韦直到聚合酶链阴性”这条规则、以及肺炎链球菌的地塞米松的获益的窗口、以及“不要因为部分治疗过就不给”、以及李斯特菌不给地塞米松这一细微、以及对无反应者重复腰穿连同脑室炎与积脓及脑积水的影像的时机——[[emergency-critical-care/acute-assessment]]；监测与预防的尾巴——血清型与疫苗史的复查、以及提供HIV的检测、以及“若反复发作则查免疫球蛋白”、以及“密切接触者的预防”这个问题“对脑膜炎球菌、而不是对肺炎链球菌”诚实地回答肺炎链球菌的家庭化学预防并非常规、除特殊情形、以及“没有明显诱因的肺炎链球菌脑膜炎”时搜寻胸与鼻窦与耳的源头；以及记录——封最终诊断的信“肺炎链球菌的脑膜炎、聚合酶链与培养的证据”、好让下一位临床医师不必重启一段“病毒性脑膜炎”的故事——[[clinical-skills/records-handover]]、[[public-health/vaccination-programmes]]。**

::: example 过度诊断的粪便组合检测 {#ex-cdiff-overcall}
一名用泻药的84岁的失禁患者有三次稀便；病房送了艰难梭菌的检测；聚合酶链阳性、而实验室的流程加了毒素的免疫测定为阴性。团队开始口服万古霉素并隔离了患者。

::: example 发热与那份回来的血清学 {#ex-serology-timing}
一名26岁在病程的第5天有发热、咽痛与淋巴结肿大；嗜异性抗体的检测阴性、而EB病毒衣壳的免疫球蛋白G阳性、衣壳的免疫球蛋白M阴性、核抗原阴性第7天。她的同住者在3周前确诊了EB病毒。请安慰、还是检查？
::: solution
**读血清学的窗口（[[#def-serology]]、[[#def-methods]]、[[infectious-diseases/hiv]]）：这个模式——“衣壳的免疫球蛋白G阳性而无免疫球蛋白M、核抗原阴性”，要么是非常早期的血清转换次序是：免疫球蛋白M先出现、然后免疫球蛋白G持续、核抗原在3到6个月出现、所以核抗原阴性意味着“数月之内的感染”、要么是既往感染伴核抗体的消退；以及嗜异性抗体在第一周百分之二十五到五十、而在年长的青少年与成人中总体百分之四十到六十敏感性的问题“嗜异性抗体阴性的EB病毒”存在、而“非嗜异性的传染性单核细胞增多症”自有一份鉴别、以及“重复查、还是做聚合酶链”的决定早期原发感染查血的EB病毒的DNA、以及异型淋巴细胞的涂膜与肝功能的辅助；按暴露信息行动——那位同住者提高了验前的概率、以及“第14天的修补”：重复的血清学显示滴度升高或核抗原的血清转换、以及“若很重现在就查EB病毒的聚合酶链”、以及“不要凭一次早期的组合下诊断”这条规则温和地写；绝不可漏掉的那份鉴别——提供急性HIV的检测那种“像单核细胞增多症的血清转换病”、以及“第四代加核糖核酸”的窗口期的方案、以及以保密为前提的性健康的路径——[[medical-ethics-law/confidentiality]]、以及巨细胞病毒与弓形虫及人类疱疹病毒6及链球菌、以及淋巴瘤与白血病的危险信号持续与B的症状及脾大及涂膜的异常，触发下一层的检查——[[blood/leukaemia]]；以及后续——脾大与“停止接触性运动”的咨询的时机三周与“按症状”的实践变异、以及如何在不说吓人的话的前提下说、以及“不需要追踪接触者”的解释、以及“疲劳会比病毒本身更长”的安心、配上复发的计划、以及“若表现不典型就再查”的标准被写进记录——[[clinical-skills/communication]]。**

## 通向何处

结果如何改变处理，在[[infectious-diseases/fever-sepsis]]与[[infectious-diseases/immunocompromised-host]]中被演练；耐药的机制活在[[microbiology/antimicrobials]]；暴发测序的应用在[[microbiology/infection-control]]；血清学的免疫学在[[immunology/antigen-recognition]]。

::: history
**实验室的微生物学是一部“你把针扎到哪里”的历史：科赫年代的固体培养基的革命洛夫勒的血清斜面、以及佩特里的平皿——经由范妮·赫塞的“琼脂的厨房”与科赫研究所的工作坊、以及1884年的革兰染色与1882年的齐尔-尼森、以及“墨汁查脑脊液”的年代1912年古德纳用墨汁诊断隐球菌——[[microbiology/bacteria]]；“会思考的琼脂”的年代——1900到1930年代那场培养基的竞赛麦康凯1905年那台“乳糖发酵的流行病学工具”、以及伤寒与痢疾的粪便培养基的军备竞赛、以及为结核服务的罗氏培养基的那一世纪、以及1977年“加缓冲的活性炭酵母浸膏与半胱氨酸”的培养基——它让麦克德对“美国军团大会的暴发”的重新分析得以命名军团菌——[[respiratory/respiratory-infections]]；抗体检测的革命——1896年的肥达试验、与它那一整个世纪的判读之争、以及1910到1920年代“非密螺旋体”的试验带着它们给自身免疫上的那课、以及1941年库恩斯荧光抗体的技术、以及亚洛与伯森放免的年代它让抗原与抗体变得可以定量、以及那份驯服了假阳性的嗜异性吸收的工作——[[immunology/antigen-recognition]]；聚合酶链的转折——1983年的穆利斯与1990年代诊断的采纳、以及HIV的核糖核酸“把窗口关闭”的几代抗原抗体的联合检测、以及1995年起对献血的核酸检测、以及结核的“两小时”分子检测的时代把结核的诊断从数周变成两小时、以及世界卫生组织推荐所致政策的转变、以及呼吸道组合检测的试验与“恰当使用”的争论、以及“培养阴性的脑炎”的脑脊液的宏基因组的病例系列”被救回来的戊肝与钩端螺旋体与阿米巴、以及把感染当作液体活检的那个愿景；以及鉴定与耐药的将来——2000与2010年代那个把“到鉴定的时间”减半质谱的时代、以及全基因组测序的常规化结核传播的簇、以及李斯特菌暴发的检出、以及淋病的药敏的预测，以及随之而来的“临床微生物学家必须会读生物信息学”这一新的责任。**
:::

::: summary
- 标本就是检测：部位、时机、容量、容器与运送决定阳性率的程度超过仪器本身、而申请单应当承载那个临床的问题。
- 革兰染色加细胞计数是“第一小时的诊断”；培养在许多部位仍是敏感性的金标准、但要花数天；分子的检测用“定植的噪声”换取敏感性。
- 血清学是一次“时钟的练习”：哪一种抗体、哪一周、哪一种检测、以及交叉反应与既往的接种会对判读做什么。
- 阴性结果有它的属性：治疗之前、负荷低、标本错、“排出与清除”的时机，在罕见的微生物之前解释了大多数的假阴性。
- 把药敏的报告当作处方来读——内在的耐药、尿中的浓缩、可诱导的基因、以及报告哲学，都会改变一个“敏感”的含义。
- 多重与测序的结果只在临床的背景中才是诊断；实验室的职责是“判读的伙伴”、临床医师的职责是“要对东西”。
:::

::: exercise 判读一份阳性的呼吸道组合检测 {level=1}

::: solution
**组合检测的阳性与验前的概率（[[#def-methods]]、[[respiratory/respiratory-infections]]）：这个检测能与不能说什么——“检出不等于有活性、更不等于病因”鼻病毒会持续数周、偏肺病毒在年长与免疫受损者中“是疾病还是携带”、以及携带者正是大多数人体内的肺炎链球菌的DNA、是上气道常住菌清单上的一员、以及组合检测不会问的那个“痰的质量”的问题鳞状上皮细胞的计数、以及血与尿的培养及尿抗原作为“侵袭性疾病”的证据——[[clinical-skills/laboratory-tests]]；临床的综合——实变加发热，“在被另行证明之前就是肺炎链球菌的肺炎”、而鼻病毒常常是同行的旅伴与诱因病毒与细菌的协同的文献，所以：按严重度治疗细菌性的肺炎、不要因为病毒的阳性而不给抗生素、并考虑“份没有临床医师主导评述组合报告的模板，是否正把居民变成未被治疗的患者”；以及病房的后果——针对鼻病毒的飞沫预防“并不现实”、而免疫受损者的偏肺病毒需要它自己同组安置的思考在移植病房它会走向肺炎——[[infectious-diseases/healthcare-infections]]、[[infectious-diseases/immunocompromised-host]]；以及报告的伦理——组合检测需要评述那些没人读的“检测限与临床相关性”的样板、对“实验室与临床医师的讨论”、以及本地的组合检测阳性的基线，好让“一簇”真的是一簇——[[clinical-skills/communication]]。**
