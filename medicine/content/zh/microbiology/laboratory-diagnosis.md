一份微生物学结果是一条长链的终点。有人选择了标本，采集、标记，填写了申请单并送到实验室。实验室选择了要做的检查，再由某人阅读报告并判断其含义。链条上任何一处出错，都会产生误导性的答案，而许多最常见的错误发生在标本到达实验室之前。

本章追踪标本从床旁到报告的全过程。目的是帮助你选择正确的检查，采集有用的标本并解释结果，包括准确的检查仍给出误导性答案的情况。

本章介绍标本采集，显微镜检查，培养和鉴定，抗微生物药物敏感性试验，抗原检测和分子检测，血清学，以及检验结果解释的原则，包括预测值。

## 标本 {#specimen}

::: definition 合格的标本 {#def-specimen}
有用的标本应当：

- **取自正确的部位**：即感染部位，并尽可能避开正常菌群，例如取脓液或组织而不是表面拭子；
- **在正确的时间采集**：只要不危险地延误治疗，就在使用抗生素之前采集，并在疾病的适当阶段采集；
- **装在正确的容器中**：无菌，并使用正确的运送培养基、防腐剂或血培养瓶；
- **量足够**：量少会漏检数量少的微生物；
- **及时**在适当温度下**运送**；
- **附有清楚的申请**：临床资料、相关的旅行史和暴露史、已使用的抗生素，以及特别关注的病原体或检查。
:::

由这些原则可以推出几种常见错误。伤口的干燥表面拭子主要培养出其表面的皮肤和环境微生物。在室温下放置的尿液标本使细菌增殖，因此未感染者的标本也可能显示高菌数。大部分是唾液的痰标本培养出的是口腔菌群。使用几次抗生素之后采集的标本，即使感染确由细菌引起，也常常无细菌生长。

申请单是标本的一部分。实验室根据申请单上所写的内容处理每一份标本。如果没有提到“近期去过巴基斯坦”，粪便标本就不会检查旅行史所提示的病原体；如果没有怀疑危险病原体，实验室也不会安全地处理标本。

### 血培养 {#blood-cultures}

**血培养**是脓毒症最重要的微生物学检查。血液被接种到装有肉汤的培养瓶中，通常一个需氧瓶和一个厌氧瓶构成**一套**。培养瓶在自动化系统中孵育，系统检测到细菌生长时即报告该瓶阳性。

菌血症常为低水平，成人每毫升血液中细菌往往少于一个，因此**血量**是灵敏度的主要决定因素。英国标准建议成人每瓶约8～10 mL，怀疑菌血症或心内膜炎时，至少经不同的静脉穿刺采集两套。大多数有临床意义的细菌在48小时内生长，培养瓶通常孵育五天后才报告阴性。

皮肤微生物可能在采血时进入培养瓶。仔细的皮肤消毒、消毒瓶口，以及除非怀疑导管感染否则不经现有导管采血，都能减少污染。当培养瓶报阳时，培养出同一细菌的套数有助于区分污染和真正的感染。

::: example 四瓶中有一瓶阳性 {#ex-contaminant}
一名47岁肾盂肾炎女性在使用抗生素前采集了两套血培养。40小时后，四瓶中有一个需氧瓶报阳，培养出凝固酶阴性葡萄球菌。她没有血管内器械，针对尿液中培养出的大肠埃希菌（*E. coli*）的治疗正在起效。这个细菌有意义吗？
::: solution
很可能没有。有几个特点提示**污染**：

- 该细菌是常见的皮肤共生菌；
- 它只在四瓶中的一瓶生长，来自两次静脉穿刺中的一次；
- 它生长所需的时间相对较长；
- 她没有人工植入物或导管，而凝固酶阴性葡萄球菌引起真正感染正是在这些情况下；
- 她的病另有解释，且治疗有效。

治疗它会让她不必要地接触万古霉素（vancomycin）等抗生素。如果同一细菌出现在多套血培养中，而患者有中心静脉导管或人工心脏瓣膜，解释就会不同。血培养污染相当常见，因此许多医院把污染率作为采血技术的衡量指标加以审核。
:::
:::

## 显微镜检查与培养 {#methods}

::: definition 实验室的核心方法 {#def-methods}
**显微镜检查**提供快速、低成本的初步观察：

- **革兰染色**显示革兰阳性菌和革兰阴性菌及其形态，也显示炎症细胞，后者表明标本是否来自感染部位；
- **抗酸染色**（齐-内染色，或更灵敏的荧光**金胺**染色）显示分枝杆菌；
- **真菌染色**和湿片显示酵母、菌丝、原虫和蠕虫卵。

**培养**在固体培养基（琼脂平板）或液体肉汤中培养微生物。培养基可以是**营养丰富的**，以支持苛养菌生长，如用于嗜血杆菌属（*Haemophilus*）和奈瑟菌属（*Neisseria*）的巧克力琼脂；也可以是**选择性的**，以抑制不需要的菌群，如麦康凯琼脂，主要允许革兰阴性杆菌生长。平板根据预期的微生物在空气中、二氧化碳中或无氧条件下孵育。

菌落的**鉴定**现在通常采用**MALDI-TOF质谱**，它把菌落的蛋白质图谱与参考数据库比较，在几分钟内鉴定出大多数细菌和酵母。生化试验对某些微生物仍然有用。
:::

培养有两大优势：它证明存在有活力的微生物，并提供药敏试验和分型所需的分离株。它的弱点是时间和灵敏度。大多数细菌需要过夜孵育，分枝杆菌需要数周，已被抗生素损伤的微生物可能根本不生长。有些微生物，如梅毒螺旋体（*Treponema pallidum*），不能常规培养。

## 药敏试验 {#susceptibility}

::: definition MIC与折点 {#def-mic}
**最低抑菌浓度**（MIC）是在标准实验室条件下能阻止某种微生物可见生长的抗微生物药物的最低浓度。它用一系列**倍比稀释**来测定，例如0.25、0.5、1、2和4 mg/L。

**临床折点**是用于对微生物进行分类的MIC（或纸片扩散法中相应的抑菌圈直径）。在英国采用的欧洲（EUCAST）体系中，分类为：

- **S，标准剂量方案下敏感**：在标准剂量下成功的可能性高；
- **I，增加暴露下敏感**：如果通过加大剂量或因药物在该部位浓集而增加感染部位的暴露，可能有效；
- **R，耐药**：即使增加暴露，失败的可能性也很高。
:::

MIC通过在肉汤或琼脂中稀释来测定，或用**纸片扩散法**估计：把含药的纸片放在接种了细菌的平板上，药物向外扩散，将无生长区的直径与折点比较。也使用自动化系统和梯度试条。

折点综合了几类数据：没有耐药机制的野生型菌株的MIC分布，药物在标准剂量和高剂量下在患者体内达到的浓度，以及临床结局数据。EUCAST每年更新折点。由于折点取决于药物的药理学特点，不同药物之间的MIC值不能直接比较：1 mg/L的MIC对一种抗生素可能很低，对另一种抗生素可能已经太高。

快速检测现在可以直接检出某些耐药机制，而不必等待完整的MIC结果。*mecA*基因的PCR可鉴定MRSA，侧向层析试验可在几分钟内检出常见的碳青霉烯酶。这些内容在[[microbiology/antimicrobials]]中描述。

::: warning “I”并不意味着“中介，应避免使用”
2019年以前，许多报告用“I”表示中介：一个最好避免使用该药的灰色区域。EUCAST把它重新定义为**增加暴露下敏感**。报告为对某药“I”的微生物，如果使用更高的剂量，或者药物在感染部位浓集（许多药物在尿液中就是如此），就可以用该药治疗。把“I”当作“耐药”会导致不必要地使用更广谱的药物。要查看报告所附的剂量建议，如有疑问应与微生物科讨论。
:::

::: example 阅读MIC报告 {#ex-mic}
从一名机械通气患者的支气管吸出物中分离出的铜绿假单胞菌（*Pseudomonas aeruginosa*），报告哌拉西林—他唑巴坦（piperacillin–tazobactam）MIC为8 mg/L，类别为“I”。现行折点表中的折点为S ≤ 0.001 mg/L、R > 16 mg/L。这是什么意思？
::: solution
对于铜绿假单胞菌，EUCAST把某些药物的S折点设在一个人为的低值上，使野生型分离株在标准剂量下永远不会报告为S。这是一个信号，表明针对这种细菌**应始终使用高剂量方案**。

MIC为8 mg/L，高于S折点，但不高于16 mg/L的R折点，因此该分离株为**I：增加暴露下敏感**。如果按折点表所列的高剂量方案给药（常采用延长输注），并与微生物科和药剂科共同决定，哌拉西林—他唑巴坦是合理的选择。报告并不意味着细菌耐药。这里引用的折点仅作说明；务必查阅现行的EUCAST折点表和本地报告。
:::
:::

## 抗原检测与分子检测 {#molecular}

**抗原检测**检出微生物的某种成分，通常利用抗体。例如肺炎链球菌（*Streptococcus pneumoniae*）和嗜肺军团菌（*Legionella pneumophila*）血清群1的尿抗原检测，血液或脑脊液中的隐球菌抗原，疟疾抗原检测，以及呼吸道病毒的侧向层析检测。它们快速，常可在床旁使用。其灵敏度一般低于核酸检测，有些只检出一个菌种的一部分：军团菌尿抗原阴性不能排除其他血清群的感染。

**核酸扩增试验**（NAAT），其中最常见的是**聚合酶链反应**（PCR），把一段短的DNA或RNA靶序列复制数百万次。它们灵敏度和特异度极高，能检出不能培养或已被抗生素损伤的微生物，数小时内即可出结果。多重检测板可同时检测许多呼吸道、肠道或中枢神经系统病原体。

在**实时荧光PCR**中，每个循环都测量产物的量。**循环阈值**（Ct）是信号越过设定水平时的循环数。靶标多的样本越过得早，因此**Ct越低，靶标越多**。如果每个循环使产物加倍，起始量相差十倍相当于约$\log_2 10 \approx 3.3$个循环。

$$
\text{倍数差异} = 2^{\Delta \text{Ct}}
$$ {#eq-ct}

分子检测也有局限。它们检出的是核酸而不是有活力的微生物，因此在感染消退后数周仍可能阳性。它们只检出设计时针对的靶标。不同平台的Ct值不同，且未标准化，因此只应在同一检测方法内比较。

**测序**扩展了分子诊断。16S rRNA基因的PCR和测序可以在来自正常无菌部位的培养阴性标本中鉴定细菌，例如在使用抗生素后切除的心脏瓣膜。**全基因组测序**用于预测结核分枝杆菌（*Mycobacterium tuberculosis*）的耐药性，并在暴发调查中比较分离株，基因组之间只有少数几个单核苷酸差异时提示近期传播。

::: example Ct的变化意味着什么？ {#ex-ct}
一名在重症监护病房的63岁流感男性，入院时鼻咽PCR的Ct为22。五天后，用同一种检测方法，Ct为27。样本中的病毒RNA量大约下降了多少？
::: solution
Ct升高了5个循环。假设每个循环使产物加倍，

$$
2^{5} = 32
$$

样本中的病毒RNA量下降了约**32倍**，比每3.3个循环下降十倍略多一些。

解释时要谨慎。拭子采集的材料量不确定，因此Ct值随采样技术而变化。较晚的Ct值也不能说明剩余的RNA是否来自有感染性的病毒。同一种检测方法上的变化趋势比单个数值更有用。
:::
:::

## 血清学 {#serology}

::: definition 血清学 {#def-serology}
**血清学**检测宿主针对某种微生物的抗体应答，有时也检测血液中微生物的抗原。当微生物难以培养或取样时，用于诊断既往感染以及评估免疫状态。

- **IgM**最先出现，在初次感染后一至两周内，通常在数周至数月内下降。IgM阳性提示近期感染，但它可能持续存在、在再激活时再次出现，或因交叉反应而假阳性。
- **IgG**上升较慢，常终身存在。单次IgG阳性表明既往感染或疫苗接种。
- **血清转换**，即由阴性转为阳性，或急性期标本与10～14天后采集的恢复期标本之间抗体滴度**升高四倍或以上**，表明近期感染。
- **IgG亲和力**衡量抗体结合的紧密程度。感染后数月内亲和力逐渐增高，因此低亲和力提示近期感染。例如，它用于判断孕期弓形虫或巨细胞病毒感染的时间。
- **窗口期**是感染后检测仍为阴性的那段时间。
:::

窗口期决定了检测如何提供。第四代HIV检测同时检测抗体和病毒的p24抗原。大多数感染在暴露后四周内可被检出，英国指南（BHIVA、BASHH和BIA，2020年）指出，最后一次暴露45天后第四代检测阴性可以可靠地排除感染。较早检测的人应被告知复查。

乙型肝炎血清学显示了一组标志物如何组合在一起解释。

| HBsAg | 抗-HBc（总） | IgM抗-HBc | 抗-HBs | 解释 |
|---|---|---|---|---|
| − | − | − | − | 从未感染，无免疫力 |
| − | − | − | + | 通过疫苗接种获得免疫 |
| − | + | − | + | 既往感染，已痊愈，有免疫力 |
| + | + | + | − | 急性感染 |
| + | + | − | − | 慢性感染（HBsAg存在超过六个月） |

**HBsAg**即表面抗原，表明当前感染。**抗-HBc**即针对核心蛋白的抗体，表明曾经发生过感染，因为疫苗只含表面抗原。**抗-HBs**即针对表面抗原的抗体，表明有免疫力。病毒DNA载量和HBeAg用于评估慢性感染的活动性。

::: example 一份乙型肝炎结果 {#ex-hbv}
一名从越南移居英国的38岁女性在孕期接受筛查。结果为HBsAg阳性、总抗-HBc阳性、IgM抗-HBc阴性、抗-HBs阴性。十年前献血时她曾被告知患有“乙肝”。请解释这些结果及其对婴儿的意义。
::: solution
HBsAg阳性意味着**当前感染**。总抗-HBc阳性而IgM抗-HBc阴性，加上十年前的病史，说明感染是**慢性**而不是急性的。抗-HBs阴性，与预期一致，因为她尚未清除病毒。

主要的意义在于她的婴儿。若不加干预，分娩时母婴传播很常见，而婴儿期感染通常会转为慢性。她的婴儿应在出生后不久接种乙型肝炎疫苗，如果母亲的传染性标志物水平高，还应同时注射乙型肝炎免疫球蛋白，并完成全程疫苗接种，遵循英国《绿皮书》。她本人的诊疗包括转诊至肝病专科，检测HBV DNA和HBeAg，并评估肝脏疾病；如果病毒载量高，可在孕晚期提供抗病毒治疗。家庭成员和性伴侣应接受检测和疫苗接种。
:::
:::

## 解释检验结果 {#interpretation}

检验结果改变的是一个人患病的概率，而不是给出确定的答案。改变的程度取决于检验本身，以及检验前患病的可能性有多大。

::: theorem 预测值取决于患病率 {#thm-ppv}
对于**灵敏度**为$\text{Se}$（患病者中检测阳性的比例）、**特异度**为$\text{Sp}$（未患病者中检测阴性的比例）的检验，在验前概率为$p$的人群中应用时：

$$
\text{PPV} = \frac{\text{Se}\cdot p}{\text{Se}\cdot p + (1-\text{Sp})(1-p)}
\qquad
\text{NPV} = \frac{\text{Sp}\,(1-p)}{\text{Sp}\,(1-p) + (1-\text{Se})\,p}
$$ {#eq-ppv}

**阳性预测值**（PPV）随验前概率降低而降低，**阴性预测值**（NPV）随验前概率升高而降低。
:::

::: proof
设想检测10,000人。验前概率为$p$时，有$10{,}000p$人患病，其中比例为$\text{Se}$的人检测阳性：这些是真阳性。其余$10{,}000(1-p)$人未患病，其中比例为$1-\text{Sp}$的人也检测阳性：这些是假阳性。PPV是真阳性除以全部阳性，约去10,000后即得到公式。

当$p$很小时，即使很低的假阳性率，作用于庞大的未患病人群，产生的假阳性也会多于真阳性。检验本身没有变，变的是人群。这就是床旁所用形式的贝叶斯定理。
:::

::: widget bayes
mode: test
prevalence: 0.01
sensitivity: 0.95
specificity: 0.98
caption: 一项灵敏度95%、特异度98%的检验，以自然频数表示。验前概率为1%时，约三分之二的阳性结果是假阳性。把患病率调到30%，即在有典型症状的人中使用同一检验时，几乎所有阳性结果都变成真阳性。这就是为什么检验应当出于临床理由申请，而不是对所有人进行筛查。
:::

::: example 同一检验用于两种场合 {#ex-ppv}
一项快速抗原检测的灵敏度为95%，特异度为98%。计算其阳性预测值：(a) 在一个受检者中30%患有该感染的门诊；(b) 在一个1%的人患有该感染的筛查项目中。
::: solution
(a) $p = 0.30$时：

$$
\text{PPV} = \frac{0.95 \times 0.30}{0.95 \times 0.30 + 0.02 \times 0.70} = \frac{0.285}{0.299} \approx 0.95
$$

(b) $p = 0.01$时：

$$
\text{PPV} = \frac{0.95 \times 0.01}{0.95 \times 0.01 + 0.02 \times 0.99} = \frac{0.0095}{0.0293} \approx 0.32
$$

在门诊，95%的阳性结果是真阳性。在筛查中，只有约三分之一是真阳性；每三个阳性者中有两个并没有感染。因此筛查阳性结果在作出诊断之前要用另一种不同的检验来确认。
:::
:::

结果的其他特点也很重要。来自正常**无菌部位**（如血液、脑脊液或关节液）的阳性结果，比来自有正常菌群部位的阳性结果分量更重。对于尿液等某些标本，**数量**很重要。而且，在没有问一问检验结果是否符合临床表现之前，不应据此采取行动。

::: quiz
一项呼吸道感染的快速检测用于两组人：在暴发期间因典型症状入院的人，以及在常规手术前接受筛查的健康人。该检测在两组中的灵敏度和特异度相同。哪一种说法正确？
- [ ] 两组的阳性预测值相同
- [x] 有症状组的阳性预测值更高
- [ ] 有症状组的阴性预测值更高
- [ ] 筛查组的特异度更低
::: solution
灵敏度和特异度是检验本身的属性，而预测值取决于验前概率。在暴发期间有症状的人中，验前概率高，因此**PPV更高**。在健康人中验前概率低，因此假阳性更多，而NPV更高。
:::
:::

::: history
19世纪80年代，罗伯特·科赫（Robert Koch）的实验室把固体培养基、纯培养和染色确立为细菌学的标准工具，汉斯·克里斯蒂安·革兰（Hans Christian Gram）1884年的染色法至今仍是大多数阳性培养物的第一项检查。血清学始于1896年用于伤寒的肥达凝集试验，1906年奥古斯特·冯·瓦色曼（August von Wassermann）提出了梅毒的补体结合试验。

实验室药敏试验随抗生素本身一起发展。1966年，阿尔弗雷德·鲍尔（Alfred Bauer）、威廉·柯比（William Kirby）及其同事使纸片扩散法标准化。1983年，凯利·穆利斯（Kary Mullis）发明了聚合酶链反应，使不经培养就检出微生物成为可能；他分享了1993年诺贝尔化学奖。MALDI-TOF质谱于2010年前后进入常规临床实验室，把鉴定从以天计变为以分钟计。随后出现了细菌全基因组测序，它现在已成为英格兰结核病常规诊断的一部分。
:::

## 后续内容

这些检查背后的微生物见[[microbiology/bacteria]]、[[microbiology/viruses]]和[[microbiology/fungi-parasites]]。药敏结果如何指导治疗是[[microbiology/antimicrobials]]的一部分，测序如何帮助追踪暴发见[[microbiology/infection-control]]。诊断试验评价的一般原则在[[epidemiology-ebm/diagnostic-tests]]和[[clinical-skills/laboratory-tests]]中展开。

::: summary
- 大多数错误发生在实验室之前：选择正确的部位，在安全时于使用抗生素前采样，及时送检足量标本，并写清楚申请。
- 血培养的灵敏度取决于血量；至少采集两套。多瓶中只有一瓶出现皮肤微生物，通常是污染。
- 显微镜检查快速；培养证明活力并提供用于药敏试验的分离株；MALDI-TOF在几分钟内鉴定菌落。
- MIC是抑制生长的最低浓度。EUCAST折点把分离株分为S、I（增加暴露下敏感）或R；不同药物之间的MIC不能直接比较。
- 抗原检测快速；核酸扩增试验非常灵敏，但检出的是核酸而不是活力。在实时荧光PCR中，Ct越低靶标越多，约3.3个循环的差异相当于十倍。
- 血清学利用IgM、IgG、血清转换、四倍升高和亲和力；窗口期限制了早期检测。乙型肝炎标志物要放在一起解读。
- 预测值取决于验前概率：同一检验在疾病罕见时会产生许多假阳性。
:::

## 习题

::: exercise 最佳标本 {level=1}
对下列每种情况，说出一种比所提议的标本更好的标本：(a) 用慢性腿部溃疡的表面拭子诊断其下的骨髓炎；(b) 大部分是唾液的痰标本；(c) 经两天前插入的外周静脉留置针采集的血培养。
::: hint
瞄准感染部位，避开定植菌群的来源。
:::
::: solution
(a) **骨活检**，手术或影像引导下获取，最好在使用抗生素之前；表面拭子培养出的是定植菌，与骨培养的相关性差。(b) 咳嗽后的**深部痰**标本，必要时用诱导痰或支气管镜标本。(c) 皮肤消毒后经**新的静脉穿刺**采集的血培养；现有的留置针常已被定植。
:::
:::

::: exercise Ct与倍数变化 {level=1 check="32"}
两份样本用同一种实时荧光PCR检测。样本A的Ct为20，样本B的Ct为25。假设每个循环产物加倍，样本A所含的靶标是样本B的多少倍？
::: hint
用$2^{\Delta \text{Ct}}$。
:::
::: solution
$\Delta \text{Ct} = 5$，所以样本A所含的靶标是样本B的$2^5 = 32$倍。
:::
:::

::: exercise 解读乙型肝炎标志物 {level=1}
一名医务人员的结果如下：HBsAg阴性，抗-HBc阴性，抗-HBs 250 IU/L。请加以解释。
::: hint
哪种标志物可由疫苗产生，哪种只能由感染产生？
:::
::: solution
她有**通过疫苗接种获得的免疫力**。抗-HBs表明有免疫力。抗-HBc阴性，因此她从未被感染：疫苗只含表面抗原，不诱导抗-HBc。HBsAg阴性确认没有当前感染。
:::
:::

::: exercise 计算预测值 {level=2 check="2/3"}
一项检验的灵敏度为90%，特异度为95%。它在一个10%的人患有该病的人群中使用。其阳性预测值是多少？以分数给出精确值。
::: hint
以1,000人计算：数出真阳性和假阳性。
:::
::: solution
1,000人中，100人患病，其中90人检测阳性。900名未患病者中，5%检测阳性，即45人。PPV为$90/(90 + 45) = 90/135 = 2/3$。三个阳性结果中有一个是假阳性。
:::
:::

::: exercise 四倍升高 {level=2}
一名50岁男性患非典型肺炎。针对某种病原体的抗体滴度入院时为1:32，两周后为1:256，两份标本在同一批次中平行检测。滴度升高了几个倍比稀释度？这一变化说明什么？
::: hint
数一数从32到256加倍了几次。
:::
::: solution
从1:32到1:256是8倍，即**三个倍比稀释度**。这超过了四倍升高，表明近期感染了该病原体。双份血清要一起检测，因为不同批次的结果可能相差一个稀释度。这种血清学通常是事后确认诊断，因此治疗决策依据临床表现以及PCR或尿抗原等更快速的检查。
:::
:::

::: exercise 为什么阴性结果有误导性 {level=2}
一名女性与新伴侣发生无保护性行为，十天后出现咽痛和发热，次日做了第四代HIV检测，结果阴性。三周后发现该伴侣感染了HIV。请解释她第一次检测为何可能是阴性，以及她需要做哪些检测。
::: hint
想一想窗口期以及第四代检测检测的是什么。
:::
::: solution
她的症状可能是**原发性HIV感染**。第四代检测检测p24抗原和抗体。暴露后第十一天，她很可能还处于**窗口期**，两者都还检测不到。阴性结果不能排除感染。

她现在需要复查，英国指南指出，最后一次暴露45天后第四代检测阴性可以排除感染。由于她有症状，也可以用HIV RNA检测来检出很早期的感染。她应接受专科性健康服务，包括讨论其他性传播感染。暴露后预防只能在暴露后72小时内使用。
:::
:::

::: exercise 用检验排除疾病 {level=3 check="round(0.98*0.95/(0.98*0.95+0.05*0.05)*1000)/1000"}
一项脑膜炎球菌病快速检测的灵敏度为95%，特异度为98%。一名发热伴瘀点皮疹的儿童，临床医生估计其患脑膜炎球菌病的验前概率为5%。计算阴性预测值，保留三位小数。然后解释为什么检测结果不应使这名儿童停止治疗。
::: hint
用[[#eq-ppv]]中的NPV公式。
:::
::: solution
$$
\text{NPV} = \frac{0.98 \times 0.95}{0.98 \times 0.95 + 0.05 \times 0.05} = \frac{0.931}{0.9335} \approx 0.997
$$

NPV约为**0.997**：阴性结果之后仍有约0.3%的残余概率。这听起来很小，但脑膜炎球菌病可在数小时内致死，而治疗安全有效，因此治疗的阈值非常低。对于发热伴瘀点皮疹的儿童，阴性检测结果不能成为不使用抗生素的理由。决策既取决于概率，也取决于漏诊的后果。
:::
:::

::: exercise 培养阴性的心内膜炎 {level=3}
一名有人工主动脉瓣的58岁男性，因“胸部感染”从全科医生处服用了几天口服抗生素。他因发热、新出现的杂音和超声心动图发现赘生物而入院。三套血培养均为阴性。列出培养阴性的可能原因，以及能够查明病因的检查。
::: hint
考虑之前使用的抗生素、苛养菌和不能培养的微生物。
:::
::: solution
可能的原因：

- **之前使用的抗生素**，这是最常见的原因，抑制了链球菌等普通细菌的生长；
- 生长缓慢或需要特殊条件的**苛养菌**，如HACEK组细菌；
- **常规血培养无法培养的微生物**，如贝纳柯克斯体（*Coxiella burnetii*，Q热）、巴尔通体属（*Bartonella*）和惠普尔养障体（*Tropheryma whipplei*）；
- **真菌**，可能需要特定的方法；
- **非感染性原因**，如消耗性或自身免疫性心内膜炎。

有用的检查：如果可以安全地短暂停用抗生素，再做血培养并延长孵育时间；针对柯克斯体和巴尔通体的**血清学**；如果进行手术，对瓣膜组织做**PCR和16S rRNA基因测序**，并做组织病理学检查；以及β-D-葡聚糖等真菌检查。给实验室的申请必须说明临床问题，因为这些检查不是常规进行的。
:::
:::
