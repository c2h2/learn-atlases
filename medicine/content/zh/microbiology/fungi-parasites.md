真菌和寄生虫与我们一样是**真核生物**。它们的细胞有细胞核、线粒体和80S核糖体，因此与我们共享大部分生物化学。这使它们比细菌更难治疗：病原体有而人体细胞没有的靶点更少，抗真菌药和抗寄生虫药往往有更多的副作用和相互作用。

这两类微生物还教给我们一种不同的感染思维方式。严重的真菌病主要是**宿主**的疾病：所涉及的真菌在环境或正常菌群中很常见，当某一种特定的免疫防御失效时，它们就引起侵袭性疾病。寄生虫病主要是**地点和行为**的疾病：这些生物需要特定的媒介、动物宿主、水或土壤，因此旅行和暴露史是诊断的关键。

本章介绍真菌的生物学及其所致疾病，免疫缺陷与真菌感染之间的联系，原虫，蠕虫，以及这些病原体的诊断方法。

## 真菌生物学 {#fungi}

::: definition 真菌 {#def-fungal}
**真菌**是真核生物，具有由**几丁质**、**β-葡聚糖**和甘露糖蛋白构成的坚硬细胞壁。其细胞膜含**麦角固醇**，而不是人体细胞的胆固醇。它们从周围环境中摄取营养，而不进行光合作用。

有医学意义的真菌以三种形式生长：

- **酵母菌**：圆形或卵圆形的单细胞，以出芽方式繁殖，如念珠菌属（*Candida*）和隐球菌属（*Cryptococcus*）；
- **霉菌**：称为**菌丝**的分枝丝状体，形成菌丝体并释放可经空气传播的孢子（分生孢子），如曲霉属（*Aspergillus*）和毛霉目真菌；
- **双相真菌**：在约25 °C的环境中以霉菌形式生长，在37 °C的组织中以酵母形式生长，如组织胞浆菌属（*Histoplasma*）和篮状菌属（*Talaromyces*）。
:::

真菌细胞与人体细胞之间的差异就是抗真菌药物的靶点。**唑类**，如氟康唑（fluconazole）和伏立康唑（voriconazole），阻断合成麦角固醇所需的一种真菌酶。**多烯类**，如两性霉素B（amphotericin B），结合麦角固醇并在膜上打孔；由于它们也会少量结合胆固醇，因此对肾脏有毒性。**棘白菌素类**阻断细胞壁中β-葡聚糖的合成，这一结构在人体中没有对应物。这些药物在[[microbiology/antimicrobials]]中进一步讨论。

### 按深度划分的真菌病 {#fungal-depth}

真菌感染常按其侵犯的深度分组。

- **浅部和皮肤感染**累及皮肤、毛发和指（趾）甲。**皮肤癣菌**（毛癣菌属（*Trichophyton*）、小孢子菌属（*Microsporum*）和表皮癣菌属（*Epidermophyton*））能消化角蛋白，引起癣。需要脂质的马拉色菌属（*Malassezia*）酵母引起花斑糠疹，并参与脂溢性皮炎的发生。念珠菌引起口腔念珠菌病（鹅口疮）、外阴阴道念珠菌病和尿布皮炎。
- **皮下感染**在真菌经皮肤植入后发生，例如被刺扎伤。孢子丝菌属（*Sporothrix*）引起沿淋巴管扩散的结节。
- **系统性或侵袭性感染**累及内脏器官或血液。在健康人中少见，但在免疫功能受损者中可引起严重疾病。

浅部感染常见，很少危险。侵袭性真菌感染较少见，但常常致命，其发病率随着化疗、器官移植和重症监护的每一次进步而上升。

::: example 儿童头皮瘙痒 {#ex-tinea-capitis}
一名6岁的加勒比黑人男孩头皮斑片状脱发伴脱屑两个月。几乎没有发红，按“头皮干燥”开的润肤剂无效。他的妹妹也开始挠头皮。最可能的诊断是什么？为什么治疗与体癣不同？
::: solution
最可能的诊断是**头癣**，即皮肤癣菌感染头皮和发干。在英国，最常见的病原体是断发毛癣菌（*Trichophyton tonsurans*），它通过密切接触以及共用梳子或帽子在儿童之间传播，在非洲和加勒比裔儿童中尤其常见。在深色皮肤上，发红往往不易看出，脱屑、断发和斑片状脱发可能是主要体征，因此容易被误认为皮肤干燥或脂溢性皮炎。

诊断通过对毛发和头皮刮屑进行显微镜检查和培养来确认。治疗需要**口服**抗真菌药，按当地指南选择，因为真菌生活在毛囊和发干内，外用药物到达不了那里。有时会让患儿和家人使用抗真菌洗发剂，以减少传播。家庭成员应接受检查，因为未治疗的接触者是再感染的常见原因。
:::
:::

## 侵袭性真菌感染 {#invasive}

::: definition 主要的侵袭性真菌 {#def-invasive}
- **念珠菌属**是肠道和皮肤正常菌群的组成部分。它们在留置中心静脉导管、使用广谱抗生素、接受腹部手术、肠外营养、重症监护或中性粒细胞减少的人中引起**念珠菌血症**和深部器官感染。耳念珠菌（*Candida auris*），最近被重新归类为耳念珠菌属的*Candidozyma auris*，常对几类抗真菌药耐药，能在皮肤和物体表面存活，并在重症监护病房引起暴发。
- **曲霉**，主要是烟曲霉（*A. fumigatus*），产生人人都会吸入的孢子。它在长期中性粒细胞减少者或干细胞移植后引起**侵袭性曲霉病**，在哮喘和囊性纤维化患者中引起**变应性支气管肺曲霉病**，在陈旧性肺空洞中引起**曲霉球**和慢性肺曲霉病。
- **新生隐球菌**（*Cryptococcus neoformans*）是存在于土壤和鸟粪中的有荚膜酵母。它经吸入感染，在晚期HIV感染者和其他T细胞缺陷者中引起**脑膜炎**。
- **耶氏肺孢子菌**（*Pneumocystis jirovecii*）不能培养。它在晚期HIV感染者、使用大剂量糖皮质激素者以及器官移植或化疗后的人中引起**肺孢子菌肺炎**。
- **毛霉目**真菌（如根霉属（*Rhizopus*））引起**毛霉病**，这是一种侵犯鼻窦、眼眶、脑或肺的快速侵袭性感染。菌丝侵入血管，引起组织坏死。危险因素包括糖尿病酮症酸中毒、中性粒细胞减少和铁过载。
- **地方性双相真菌**，如组织胞浆菌属、球孢子菌属（*Coccidioides*）、芽生菌属（*Blastomyces*）和马尔尼菲篮状菌（*Talaromyces marneffei*），生活在特定地区的土壤中。它们在健康人中引起肺部感染，在免疫功能受损者中引起播散性疾病。
:::

2022年，世界卫生组织发布了第一份真菌重点病原体清单。新生隐球菌、耳念珠菌、烟曲霉和白念珠菌（*Candida albicans*）被列入最高优先级组，反映了它们的疾病负担、死亡率和耐药性。

::: theorem 何种免疫缺陷预示何种真菌 {#thm-fungal-host}
免疫系统的不同分支防御不同的真菌。

- **中性粒细胞**杀伤菌丝和侵袭的酵母。长期**中性粒细胞减少**易发生侵袭性曲霉病、毛霉病和侵袭性念珠菌病。
- **T细胞**，尤其是CD4辅助性T细胞，指导巨噬细胞对付胞内和有荚膜的真菌，并保护黏膜表面。**T细胞缺陷**易发生肺孢子菌肺炎、隐球菌脑膜炎、播散性地方性真菌病和皮肤黏膜念珠菌病。
- **屏障**阻止共生的念珠菌进入血液。中心静脉导管、手术以及化疗造成的黏膜损伤为念珠菌血症打开了通路。
:::

::: proof
霉菌以吸入孢子的形式进入，孢子出芽成菌丝，菌丝大得远非单个吞噬细胞所能吞下。中性粒细胞聚集在菌丝周围，用氧化剂和酶损伤它们，因此中性粒细胞的数量和功能是关键的防御。这就是为什么侵袭性曲霉病的风险随中性粒细胞减少持续时间的延长而急剧上升。

隐球菌等酵母和肺孢子菌等真菌小到足以被巨噬细胞吞入，但除非巨噬细胞被T细胞产生的细胞因子（尤其是干扰素-γ）激活，否则它们能抵抗杀伤。在晚期HIV感染中，CD4计数低于约200个/µL时开始有肺孢子菌肺炎的风险，低于约100个/µL时有隐球菌脑膜炎的风险。黏膜念珠菌由Th17细胞控制，因此口腔念珠菌病是T细胞功能下降的早期征象。

这一原理反过来同样适用。在没有已知病因的人身上发生隐球菌脑膜炎或肺孢子菌肺炎，应进行HIV检测并寻找其他T细胞缺陷。
:::

::: example 不能缓解的头痛 {#ex-crypto}
一名来自津巴布韦、现居英国的36岁男性，头痛、发热和恶心逐渐加重两周。他体重下降，从未做过HIV检测。腰椎穿刺显示初压35 cmH₂O，淋巴细胞轻度增多，葡萄糖降低。请解释最可能的诊断，以及如何确诊和处理。
::: solution
最可能的诊断是**隐球菌脑膜炎**，很可能是晚期HIV感染的首发表现。新生隐球菌经吸入感染，引起的肺部疾病很轻，然后在T细胞免疫严重降低时播散到脑。头痛常缓慢发展，颈项强直可能不明显。

脑脊液或血液**隐球菌抗原**检测灵敏度和特异度都很高，是主要的诊断检查。脑脊液墨汁染色可见有荚膜的酵母，但灵敏度较低。培养可确认病原体。他还需要做HIV检测和CD4计数。

初压升高很重要。病原体及其荚膜阻碍脑脊液的重吸收，颅内压升高造成了很大一部分头痛、视力丧失和死亡。因此，处理除抗真菌治疗外还包括**反复腰椎穿刺**以降低压力。治疗包括使用两性霉素B和氟胞嘧啶（flucytosine）的诱导期，随后是使用氟康唑的巩固期和维持期，遵循世界卫生组织和国家指南。抗逆转录病毒治疗通常在抗真菌治疗数周后开始，因为试验显示立即开始会增加死亡率，可能是由于脑内的免疫重建炎症。
:::
:::

## 原虫 {#protozoa}

寄生虫是生活在宿主体表或体内、以损害宿主为代价获益的生物。在医学上，这一术语包括两类：单细胞的**原虫**和多细胞的**蠕虫**。虱和疥螨等体外寄生虫也包括在内。

::: definition 原虫及其宿主 {#def-protozoa}
**原虫**是单细胞真核生物。许多原虫有一个活动的摄食形式（**滋养体**）和一个能在宿主体外存活的抵抗形式（**包囊**或**卵囊**）。由于它们在宿主体内增殖，少量的接种就可能导致压倒性的感染。

寄生虫的生活史涉及几类宿主：

- **终宿主**，寄生虫在其体内进行有性生殖或发育为成虫；
- **中间宿主**，寄生虫在其体内进行无性生殖或幼虫发育；
- **媒介**，通常是昆虫，在宿主之间传递寄生虫，它本身也可能是上述宿主之一。

主要的人体原虫有：

| 病原体 | 传播方式 | 主要疾病 |
|---|---|---|
| 疟原虫属（*Plasmodium*）各种 | 雌性按蚊叮咬 | 疟疾 |
| 刚地弓形虫（*Toxoplasma gondii*） | 猫粪、未煮熟的肉、经胎盘 | 先天性弓形虫病；晚期HIV感染者的脑部病变 |
| 十二指肠贾第虫（*Giardia duodenalis*） | 水中的包囊，粪—口途径 | 腹泻、腹胀、吸收不良 |
| 溶组织内阿米巴（*Entamoeba histolytica*） | 食物或水中的包囊 | 阿米巴痢疾、肝脓肿 |
| 隐孢子虫属（*Cryptosporidium*） | 水、游泳池、动物中的卵囊 | 腹泻；严重免疫抑制时呈慢性 |
| 利什曼原虫属（*Leishmania*） | 白蛉叮咬 | 皮肤和内脏利什曼病 |
| 锥虫属（*Trypanosoma*） | 采采蝇（非洲）或锥蝽（拉丁美洲） | 睡眠病；恰加斯病 |
| 阴道毛滴虫（*Trichomonas vaginalis*） | 性接触 | 阴道炎和尿道炎 |
:::

### 疟疾 {#malaria}

疟疾是世界上最重要的寄生虫病，也是从热带地区返回英国的旅行者发热最重要的病因。感染人的有五种疟原虫：恶性疟原虫（*P. falciparum*）、间日疟原虫（*P. vivax*）、卵形疟原虫（*P. ovale*）、三日疟原虫（*P. malariae*）和诺氏疟原虫（*P. knowlesi*）。

生活史解释了临床特点：

1. 受感染的蚊子注入**子孢子**，子孢子到达肝脏并在肝细胞内增殖。这一阶段没有症状，至少持续约一周。
2. 每个被感染的肝细胞向血液中释放数千个**裂殖子**，裂殖子侵入红细胞。
3. 在红细胞内，寄生虫从**环状体**发育为滋养体和**裂殖体**，裂殖体破裂释放新的裂殖子。恶性疟原虫、间日疟原虫和卵形疟原虫的周期约为48小时，三日疟原虫为72小时，诺氏疟原虫为24小时。发热随每次破裂出现，不过恶性疟的发热常不规则。
4. 部分寄生虫发育为**配子体**，被吸血的蚊子摄入后完成有性周期。

间日疟原虫和卵形疟原虫还会在肝内留下休眠形式即**休眠子**，可在数月或数年后引起复发。清除休眠子需要另一种药物，如伯氨喹（primaquine）或他非诺喹（tafenoquine），它们可在G6PD缺乏者中引起溶血，因此要先检测G6PD状态。

几乎所有死亡病例都由恶性疟原虫引起。被感染的红细胞表达一种寄生虫蛋白，使其黏附于小血管壁。滞留的细胞阻塞脑、肾和其他器官的微循环，导致脑型疟、急性肾损伤、酸中毒和死亡。在没有免疫力的旅行者中，恶性疟可在数小时内进展。

诊断依靠血涂片和快速抗原检测。**厚血涂片**浓缩血液，用于检出疟原虫；**薄血涂片**显示虫种，并可计数**原虫血症**，即被感染红细胞的百分比。单次阴性结果不能排除疟疾：英国的做法是重复检测，在48～72小时内检查三份标本后才排除疟疾。

::: example 探亲归来后发热 {#ex-malaria}
一名42岁女性12天前从尼日利亚探亲归来。她没有服用抗疟预防药。她有发热、头痛和呕吐，但意识清醒。薄血涂片在所计数的2,000个红细胞中有60个见到恶性疟原虫环状体。她的红细胞计数为$4.5 \times 10^{12}$/L。计算以百分比和每微升原虫数表示的原虫血症，并解释结果。
::: solution
**原虫血症**$= 60/2000 \times 100 = 3\%$。

红细胞计数$4.5 \times 10^{12}$/L即每微升$4.5 \times 10^6$个细胞，因为1 L等于$10^6$ µL。假设每个被感染的细胞含一个原虫，

$$
0.03 \times 4.5 \times 10^6 = 135{,}000 \text{ 个原虫每}\mu\text{L}
$$

英国指南把原虫血症超过2%的恶性疟视为重症或高危，即使患者看起来情况尚好也需要静脉治疗，因为原虫血症可能迅速上升，并发症可在数小时内出现。应评估她是否有重症疟疾的其他特征，如意识障碍、酸中毒、低血糖、贫血和肾损伤，并在专科指导下处理。静脉注射**青蒿琥酯**（artesunate）是世界卫生组织推荐的重症疟疾一线治疗，病情好转后改为完整的口服疗程，遵循现行国家指南。

在疟疾流行国家长大、现居英国的人是输入性疟疾最大的群体。离开流行区后免疫力会减弱，因此“探亲访友”的旅行者面临真实的风险，并能从出行前的咨询中获益。
:::
:::

## 蠕虫 {#helminths}

::: definition 蠕虫 {#def-helminths}
**蠕虫**是多细胞的虫体。引起人类疾病的有三类：

- **线虫**：蛔虫属（*Ascaris*）、钩虫、蛲虫属（*Enterobius*）、鞭虫属（*Trichuris*）、类圆线虫属（*Strongyloides*）、弓蛔虫属（*Toxocara*）和丝虫；
- **绦虫**：牛带绦虫（*Taenia saginata*）和猪带绦虫（*Taenia solium*），以及引起包虫病的棘球绦虫属（*Echinococcus*）；
- **吸虫**：血吸虫属（*Schistosoma*）、片形吸虫属（*Fasciola*）以及华支睾吸虫属（*Clonorchis*）等肝吸虫。

与原虫不同，大多数蠕虫**不在人体内增殖**。每条成虫都来自一个单独的感染性虫卵或幼虫，因此虫负荷以及疾病的严重程度反映了暴露的强度。类圆线虫是重要的例外。
:::

在组织中移行的蠕虫引起辅助性T细胞2型应答，伴有**嗜酸性粒细胞增多**和IgE升高。在热带地区生活或旅行过的人出现原因不明的嗜酸性粒细胞增多时，应寻找蠕虫，尤其是类圆线虫和血吸虫。只生活在肠腔中的蠕虫可能只引起很轻的嗜酸性粒细胞增多。

有几种感染途径值得记住：

- **吞入虫卵**：蛔虫、鞭虫、蛲虫和弓蛔虫，以及猪带绦虫的虫卵，后者引起**囊尾蚴病**，即肌肉和脑中的幼虫囊肿。在流行地区，脑囊尾蚴病是获得性癫痫的主要病因之一；
- **未煮熟的肉中的幼虫**：来自牛肉的牛带绦虫和来自猪肉的猪带绦虫，引起肠绦虫病；
- **幼虫经皮肤侵入**：来自土壤的钩虫和类圆线虫，以及来自含有受感染螺类的淡水的血吸虫；
- **来自狗粪的虫卵**：细粒棘球绦虫（*Echinococcus granulosus*），在肝和肺中形成包虫囊。人是偶然的中间宿主。

钩虫在小肠中吸血，是全世界缺铁性贫血的重要原因。埃及血吸虫（*Schistosoma haematobium*）生活在膀胱周围的静脉中；其虫卵引起血尿、纤维化，多年后可导致膀胱鳞状细胞癌。曼氏血吸虫（*Schistosoma mansoni*）的虫卵沉积于肝脏，引起门静脉周围纤维化和门静脉高压。

::: example 来自热带地区的男性准备使用激素 {#ex-strongyloides}
一名58岁男性在牙买加农村长大，30年前移居英国，因新诊断的血管炎即将开始大剂量糖皮质激素治疗。他的血常规显示轻度嗜酸性粒细胞增多。为什么即使他几十年前就离开了热带地区，也应先检测粪类圆线虫？
::: solution
粪类圆线虫（*Strongyloides stercoralis*）在常见的人体蠕虫中独一无二，因为它能在一个宿主体内完成生活史。在肠道中孵出的幼虫可以经肠壁或肛周皮肤重新进入体内，这一过程称为**自体感染**。因此，感染可以在离开流行区后持续数十年，常常没有症状，嗜酸性粒细胞增多也只是轻度或间歇性的。

糖皮质激素和其他免疫抑制剂解除了T细胞对虫体的控制，可引发**过度感染**：大量自体感染，幼虫穿过肺和其他器官移行。幼虫携带肠道细菌一同移行，因此过度感染常伴有革兰阴性菌菌血症或脑膜炎，死亡率很高。

他应在免疫抑制前做类圆线虫血清学检查，条件允许时做粪便检查。如为阳性，按当地指南用伊维菌素（ivermectin）治疗可预防过度感染。如果检测会延误高危者的紧急免疫抑制治疗，许多中心会进行经验性治疗。
:::
:::

::: warning 嗜酸性粒细胞计数正常不能排除蠕虫感染
嗜酸性粒细胞增多是一条有用的线索，但没有增多并不能排除蠕虫。在慢性类圆线虫感染、成虫局限于肠腔，以及使用会抑制嗜酸性粒细胞的糖皮质激素的人中，嗜酸性粒细胞计数可能正常。当暴露史相符、漏诊后果严重时，例如在免疫抑制之前，应直接用血清学和粪便检查进行检测。
:::

## 诊断 {#diagnosis}

患者体内存在的生活史阶段决定了应做的检查。

- **血涂片**用于疟疾，以及在某些丝虫的微丝蚴进入循环时检测微丝蚴，需按其出现时间采血。
- **快速抗原检测**：疟疾抗原检测、隐球菌抗原，以及贾第虫和隐孢子虫的粪便抗原。
- **粪便显微镜检查**查找虫卵、包囊和寄生虫，通常检查不同日期的三份标本，因为排出是间歇性的。在许多实验室，多重PCR现已取代显微镜检查用于常见的肠道原虫。
- **血清学**用于难以取样的组织寄生虫，如类圆线虫、血吸虫、弓蛔虫、棘球绦虫和弓形虫。抗体在暴露后数周才出现，阳性结果可能反映既往感染。
- 真菌：对皮肤、毛发、指（趾）甲和组织进行**显微镜检查和培养**；血清**半乳甘露聚糖**用于侵袭性曲霉病；**β-D-葡聚糖**是许多真菌（包括肺孢子菌，但不包括毛霉目真菌和隐球菌）的细胞壁成分；**组织病理学**显示组织侵袭，是侵袭性霉菌感染的确切证据。

影像学支持诊断。中性粒细胞减少患者的胸部CT可见周围有一圈磨玻璃影的结节，提示侵袭性霉菌感染。

::: quiz
一名45岁女性因急性髓系白血病化疗后中性粒细胞减少已进入第三周。尽管使用了广谱抗生素，她仍持续发热，CT扫描显示数个周围有晕圈的肺结节。最可能的病原体是哪一种？
- [ ] 耶氏肺孢子菌
- [ ] 新生隐球菌
- [x] 烟曲霉
- [ ] 十二指肠贾第虫
::: solution
长期中性粒细胞减少是**侵袭性曲霉病**的主要危险因素，伴晕征的结节是其典型的早期CT表现。菌丝侵入血管，在梗死的肺组织周围造成小范围出血。肺孢子菌和隐球菌主要是T细胞缺陷的风险，贾第虫不引起肺部疾病。血清半乳甘露聚糖和支气管镜检查有助于确诊，而伏立康唑等抗霉菌唑类的治疗应在得到证实之前就开始，遵循当地指南。
:::
:::

::: history
1880年，在阿尔及利亚工作的法国军医阿方斯·拉韦朗（Alphonse Laveran）在患者血液中看到了疟原虫。1897年，在印度工作的罗纳德·罗斯（Ronald Ross）证明蚊子传播鸟类的疟原虫，不久之后乔瓦尼·巴蒂斯塔·格拉西（Giovanni Battista Grassi）及其意大利同事证明按蚊传播人类疟疾。罗斯于1902年、拉韦朗于1907年获得诺贝尔奖。

常被称为热带医学之父的帕特里克·曼森（Patrick Manson）在1877—1878年证明蚊子会摄入丝虫的微丝蚴，这是首次证明昆虫能携带人体寄生虫。在医学真菌学方面，雷蒙·萨布罗（Raymond Sabouraud）在19世纪90年代对皮肤癣菌的研究，使他的名字留在了至今仍用于真菌培养的培养基上。侵袭性真菌感染的增多则出现得晚得多，因为化疗、器官移植和HIV流行造就了大量免疫功能受损的人群。
:::

## 后续内容

抗真菌药和抗寄生虫药在[[microbiology/antimicrobials]]中介绍，实验室检查见[[microbiology/laboratory-diagnosis]]。返回旅行者、疟疾和热带感染的临床处理见[[infectious-diseases/tropical-infections]]。免疫功能受损者的感染，包括侵袭性真菌病，见[[infectious-diseases/immunocompromised-host]]和[[infectious-diseases/hiv]]。

::: summary
- 真菌是真核生物，有几丁质和β-葡聚糖构成的细胞壁，其膜中含麦角固醇；这些是主要的抗真菌靶点。
- 真菌以酵母、霉菌或双相形式生长。感染可以是浅部、皮下或侵袭性的。
- 免疫缺陷预示真菌感染：中性粒细胞减少导致曲霉、毛霉目真菌和侵袭性念珠菌感染；T细胞缺陷导致肺孢子菌、隐球菌和地方性真菌病；中心静脉导管导致念珠菌血症。
- 原虫是单细胞生物，在宿主体内增殖。疟疾的生活史解释了其发热、复发（间日疟和卵形疟的休眠子）以及恶性疟的严重性。
- 返回旅行者疑似疟疾属于急症；在英国指南中，原虫血症超过2%的恶性疟按重症处理。
- 大多数蠕虫不在人体内增殖，因此疾病反映暴露程度；在组织中移行的蠕虫引起嗜酸性粒细胞增多。类圆线虫可持续存在数十年，免疫抑制时引起过度感染。
- 检查取决于体内存在的生活史阶段：血涂片、抗原检测、粪便显微镜检查或PCR、血清学以及组织病理学。
:::

## 习题

::: exercise 计算原虫血症 {level=1 check="3"}
在一张薄血涂片上，1,500个红细胞中有45个含有恶性疟原虫。原虫血症的百分比是多少？
::: hint
原虫血症等于被感染细胞数除以计数细胞数，再乘以100。
:::
::: solution
$45/1500 \times 100 = 3\%$。在恶性疟中，这超过了英国指南视为重症或高危疾病的2%阈值。
:::
:::

::: exercise 宿主与媒介 {level=1}
对于刚地弓形虫，说出其终宿主，并解释人是如何感染的。人是终宿主还是中间宿主？
::: hint
寄生虫在哪种动物体内进行有性生殖？
:::
::: solution
**猫**及其他猫科动物是终宿主：有性生殖在猫的肠道中进行，卵囊随粪便排出。人通过吞入猫粪中的卵囊（存在于土壤、猫砂或未洗净的蔬菜中），或食用未煮熟的肉中的组织包囊而感染。孕期的初次感染可通过胎盘。人是**中间宿主**：寄生虫在肌肉和脑中形成组织包囊，但不进行有性生殖。
:::
:::

::: exercise 真菌细胞中的靶点 {level=1}
说出真菌的三种作为抗真菌药物靶点的结构或分子，以及作用于每种靶点的药物类别。
::: hint
想一想膜固醇、它的合成以及细胞壁。
:::
::: solution
膜中的**麦角固醇**被两性霉素B等**多烯类**结合。**麦角固醇合成途径**，具体为羊毛固醇14α-脱甲基酶，被**唑类**阻断。细胞壁中**β-葡聚糖**的合成被**棘白菌素类**阻断。氟胞嘧啶在真菌细胞内转化为干扰核酸合成的药物，是第四种选择。
:::
:::

::: exercise 每微升原虫数 {level=2 check="80000"}
一名患者的恶性疟原虫血症为2%，红细胞计数为$4.0 \times 10^{12}$/L。每微升血液中有多少个被寄生的红细胞？
::: hint
先把红细胞计数换算成每微升细胞数。1升等于$10^6$ µL。
:::
::: solution
$4.0 \times 10^{12}$/L$= 4.0 \times 10^6$/µL。则$0.02 \times 4.0 \times 10^6 = 80{,}000$个被寄生的细胞每微升。
:::
:::

::: exercise 旅行六个月后发热 {level=2}
一名27岁男性在印度农村工作六个月后回国。他没有服用预防药。回国六个月后，他出现隔日发热，血涂片见间日疟原虫。他在国外曾接受过疟疾治疗。请解释为什么他离开那么久之后还会患疟疾，以及他还需要什么额外的治疗。
::: hint
哪些虫种会在肝脏中留下休眠形式？
:::
::: solution
间日疟原虫（以及卵形疟原虫）可以形成**休眠子**，即肝细胞中的休眠原虫。它们可在数周到数月、偶尔数年后激活，向血液中释放裂殖子，引起**复发**。他在国外很可能只接受了针对血液期的治疗，这不能清除休眠子。

他需要针对血液期感染的治疗，然后再用一种杀灭休眠子的药物，如伯氨喹或他非诺喹。两者都可在**G6PD缺乏**者中引起严重溶血，因此必须先测定G6PD活性，遵循国家指南。
:::
:::

::: exercise 中性粒细胞减少与晕征 {level=2}
解释为什么侵袭性曲霉病是长期中性粒细胞减少的疾病，而肺孢子菌肺炎是CD4计数低下的疾病。
::: hint
比较组织中真菌形态的大小与吞噬细胞的大小，并问一问杀灭它们各需要哪些细胞。
:::
::: solution
曲霉以孢子形式进入肺，孢子出芽成**菌丝**，菌丝太大，单个吞噬细胞无法吞噬。**中性粒细胞**用氧化剂和酶从外部攻击菌丝。没有中性粒细胞时，菌丝自由生长并侵入血管，因此风险随中性粒细胞减少的程度和持续时间而上升。

肺孢子菌生活在肺泡中，由经CD4 T细胞辅助而活化的**肺泡巨噬细胞**控制。CD4计数降至约200个/µL以下时，巨噬细胞就不能再清除它。单纯中性粒细胞减少通常不引起肺孢子菌肺炎，单纯CD4计数低下通常也不引起侵袭性曲霉病。
:::
:::

::: exercise 湖中游泳后嗜酸性粒细胞增多 {level=3}
一名23岁学生在马拉维待了三个月后回国，期间曾在马拉维湖游泳。最后一次游泳四周后，她出现发热、咳嗽、荨麻疹，嗜酸性粒细胞计数为$3.2 \times 10^9$/L。和她一起游泳的朋友身体健康。最可能的诊断是什么？为什么第一次血清学检查可能为阴性？两名旅行者应如何处理？
::: hint
哪种蠕虫在淡水中经皮肤侵入？抗体需要多长时间才能产生？
:::
::: solution
最可能的诊断是**急性血吸虫病**（片山综合征）。受感染的淡水螺释放的尾蚴经皮肤侵入；当幼虫成熟并开始产卵时，超敏反应引起发热、咳嗽、荨麻疹和明显的嗜酸性粒细胞增多，通常在暴露后数周出现。

此时血清学可能为**阴性**，因为抗体需要数周才能产生，尿液或粪便中也可能尚未出现虫卵。通常在最后一次暴露后约三个月复查。

处理由专科进行。**吡喹酮**（praziquantel）主要作用于成虫，因此通常在虫体成熟后给药或重复给药，严重的急性症状可使用糖皮质激素。健康的朋友有相同的暴露，也应在适当间隔后进行血清学筛查，阳性时予以治疗，因为未治疗的感染可对膀胱、肠道或肝脏造成长期损害。
:::
:::

::: exercise 旅行者的肝脏病变 {level=3}
一名35岁男性在墨西哥待了六个月后回国，发热、右上腹痛三周。超声显示肝右叶一个7 cm的单发空腔。他旅行期间曾有短暂腹泻。请给出鉴别诊断，解释最可能的病因及其确诊方法。
::: hint
想一想引起肝内空腔的细菌、原虫和蠕虫病因。
:::
::: solution
鉴别诊断包括**细菌性肝脓肿**（常源于胆道或肠道，病原为克雷伯菌、大肠埃希菌、链球菌或厌氧菌）、**阿米巴肝脓肿**和继发感染的**包虫囊肿**。中央坏死的肿瘤也有可能。

最可能的病因是**阿米巴肝脓肿**。溶组织内阿米巴包囊随被污染的食物或水被吞入。滋养体侵入结肠壁，经门静脉到达肝脏，在那里破坏组织形成脓肿。它在年轻男性中最常见，只有少数人当时有腹泻。

诊断依靠**阿米巴血清学**（肝脓肿时通常为阳性）结合影像学。此阶段粪便显微镜检查常为阴性。不常规进行穿刺，只用于诊断有疑问、脓肿很大或治疗无效时。治疗用甲硝唑（metronidazole），随后用肠腔内药物清除肠道中的包囊，遵循专科指南。如果怀疑包虫囊肿，在任何穿刺之前都要检查棘球绦虫血清学和影像学特征，因为囊肿破裂可引起严重过敏反应和播散。
:::
:::
