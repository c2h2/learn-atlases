真菌学与寄生虫学共享同一堂临床的课：**微生物通常比你最初的鉴别所承认的更慢、更奇怪、也更依赖地理、所以诊断要靠“在看涂片之前先想暴露与免疫状态”、以及靠知道“哪几种真菌与寄生虫的病会快得足以要求经验性的治疗”。**

## 寄生虫

::: definition 原虫 {#def-protozoa}

## 通向何处

宿主风险表的映射在[[infectious-diseases/immunocompromised-host]]与[[immunology/immunodeficiency]]；抗真菌与抗原虫的药理学在[[microbiology/antimicrobials]]；包括显微镜与血清学的实验室方法在[[microbiology/laboratory-diagnosis]]；热带的综合征在[[infectious-diseases/tropical-infections]]；皮肤与甲的疾病在[[musculoskeletal/skin]]。

::: history
**医学的真菌学等待着染色与抗生素：早期皮肤癣菌的年代肖恩莱因、阿诺德与格鲁比关于“癣的病因”的家谱——格鲁比1841年对真菌成分的展示、以及戴维纳那条“炭疽的杆菌”的平行、以及1840年代对人类放线菌病的首批描述、以及维勒曼在1729年米歇利的属名这块“史前”之后、因那把“灯刷状的霉”而命名了曲霉病；念珠菌与外科的年代——1950年代对抗生素时代之后的葡萄球菌与念珠菌的“重叠感染”的认识、以及两性霉素去氧胆酸盐的故事1950年代那次前往一份菲律宾土壤样本的考察、是抗真菌历史上“奠基的那一铲”、以及此前的制霉菌素、以及5-氟胞嘧啶的偶然、以及为隐球菌疾病“联合用药”的理由——[[infectious-diseases/hiv]]；地方性真菌病的地图——达令1906年在危地马拉的组织学的捕捉、以及卡斯泰拉尼与阿尔瓦雷斯及德赫苏斯对拉丁美洲的澄清场“这不是网状内皮系统的增生、这是一种真菌”的争论、同时也产出了“蝙蝠与鸟的粪便在洞穴与鸡舍里”的流行病学、以及1914到1930年代圣金谷地的球孢子菌病的流行病学那个最初的病例、陆军的机场与扬尘施工的几波、以及“峡谷的热”的命名的政治——[[respiratory/interstitial-vascular-disease]]；寄生虫学的黄金时代——拉韦朗1880年在君士坦丁“在一名士兵的血里观察到疟疾的色素”、以及罗斯与戈尔基的媒介与生活史的工作、以及格拉西与费莱蒂“让感染的蚊子叮自己”的自身实验、以及他们后来关于“谁证明了传播”的争论、以及曼森关于“龙线虫的水蚤与丝虫的媒介”的规划1877年他在卡拉巴尔的监狱里得出的、“蚊子携带丝虫”的洞见、当时他在尼日利亚工作、以及河盲症控制的故事——从媒介控制的方案、到伊维菌素捐赠的规划是公共卫生史上最伟大的决定之一——[[public-health/global-health]]；以及现代——艾滋病定义性的隐球菌与篮状青霉及微孢子虫与等孢的识别、奠定了机遇性真菌学、以及免疫受损宿主的整章、以及“由全球卫生基金支撑蠕虫的群体给药”的时代。**
:::

::: summary
- 真菌的疾病按宿主分裂：表面的疾病很常见、范围“从影响外观到极其痛苦”、而侵袭性的疾病是“免疫状态特异的”、并且以小时计进展。
- 风险表胜过反射式的检查：中性粒细胞减少与霉、酮症酸中毒与毛霉目、导管与念珠菌、T细胞的衰竭与肺孢子菌及隐球菌。
- 抗真菌的毒性与相互作用是“期末考试”级别的药理学：两性霉素的肾与电解质、唑类那片细胞色素P450的混乱与QTc、棘白菌素相对的宽厚。
- 寄生虫的疾病第一位是暴露的病史、第二位才是涂片：先想再开单、并知道“哪些检查血清学、聚合酶链、浓缩的粪便、厚血膜”回答哪个问题。
- “激素之前先想类圆线虫”是一条“带着死亡率”的患者安全的规则；任何种的疟疾都是一小时内要确诊的病。
- 在阿米巴与真菌的病灶里、影像滞后于临床的反应；判断早期的成功时治疗的是“发热与炎症标志物的轨迹”、不是那张图。
:::

**归国者无症状的嗜酸细胞增多（[[#def-protozoa]]、[[#def-helminths]]、[[infectious-diseases/tropical-infections]]）：一份“减少暴露”的病史——淡水的洗浴血吸虫与蠕虫的移行、赤足走土钩虫与类圆线虫、未煮熟的鱼肝吸虫与阔节裂头绦虫与颚口动物、猪肉与牛肉带绦虫与旋毛虫、去过罗阿罗阿流行的中非这是一个“治疗的安全”的问题、以及时长与“乡村对城市”；有针对性的检查——按时间粪便的虫卵与寄生虫与“培养类圆线虫”、以及血吸虫的血清学与尿及粪的聚合酶链、以及弓首蛔虫与丝虫按地理选班氏或罗阿或河盲的血清学、以及在有指征时“按微丝蚴的周期性取血的涂片”、以及类圆线虫血清学交叉反应的说明、以及在“有游走浸润的哮喘患者”中考虑曲霉的致敏与变应性的支气管肺曲霉病的检查；那个“过度治疗”之问的答案——嗜酸细胞增多的程度与“持续的检查、对推定地用吡喹酮或伊维菌素的算法、对转诊旅行医学门诊”那种“什么都治”的进路、带着它虚假的安心与罗阿罗阿的安全风险、以及“疟疾与巴贝虫不算在嗜酸细胞增多里”这个提示它们不造成嗜酸细胞增多——一个有用的阴性——[[blood/haematopoiesis]]；以及随访——封“判读并安心”的信、3个月复查计数恢复正常意味着暴露的反应已经平息、为下一次派驻做的“再暴露的咨询”、以及“血吸虫的再感染、要治疗整个社区、而不只是旅行者”这个现实——[[public-health/global-health]]、[[clinical-skills/communication]]。**

::: exercise 处理一份阳性的β-D-葡聚糖 {level=2}

**假阳性的国度、以及该怎么办（[[#def-invasive]]、[[microbiology/laboratory-diagnosis]]、[[emergency-critical-care/critical-care]]）：这个检测的真相——它能查出肺孢子菌与念珠菌及曲霉查不出毛霉目或隐球菌、但有记录在案的假阳性：某些透析滤器的膜、纱布与织物的接触、某些β内酰胺哌拉西林他布坦与阿莫西林克拉维酸“制剂的历史”、静脉的免疫球蛋白与白蛋白及某些血液制品、以及含葡甘露聚糖的食物——所以患者的透析回路与所用的抗生素以及阳性的阈值都很重要；临床的判读——验前概率的重构一名在用广谱抗生素、未做预防的重症监护患者、其“侵袭性疾病”的阳性预测值不算高、但也不是零、而“缺氧轻微的肺孢子菌绝不能被漏掉：要问为什么没做预防”、以及配对的CT与半乳甘露聚糖及呼吸道病毒的组合检测、以及“诱导的痰对支气管肺泡灌洗”的决定、以及“立刻查HIV”这场谈话、以及按轨迹在“经验性地治疗”与“紧急的支气管镜”之间的取舍；行动——重复并确认、而不是对一个数字起反应、并按临床的轨迹而非单凭检测来治疗、以及抗真菌的管理经验性的棘白菌素对不用、以及在72小时按培养及半乳甘露聚糖及灌洗的结果降级、以及“以葡聚糖指导停药”的试验按你们的人群看它们显示了什么；以及系统——报告里的“检测的限度”一条评述可以为“纱布造成的假象”省下三天的卡泊芬净、重症监护抗真菌处方的审计、以及关于新的透析膜的“实验室与临床医师的反馈环路”——[[infectious-diseases/stewardship-outbreaks]]、[[pharmacology/adverse-reactions]]。**

::: exercise 为一名归国的发热者运行一套热带感染的分诊 {level=3}
为你们急诊设计一套“热带之后发热”的7×24小时的算法、包括疟疾与登革及高后果的病原体的筛查、以及它的治理。
::: solution
**“热带之后的发热”是一个系统（[[#def-protozoa]]、[[#def-invasive]]、[[emergency-critical-care/acute-assessment]]、[[public-health/communicable-disease-control]]）：前门——分诊生命体征里的“旅行之问”（目的地与日期及预防用药、发热的起病、配潜伏期的表的决策支持：7天以内的登革与基孔肯雅及寨卡及伤寒及急性的疟疾可能；超过6周恶性疟仍可能、间日疟的复发与肠热及肝炎及急性的HIV；数月或数年的“在持续头痛的疟疾”？）、以及“非免疫者的重症表现”的危险信号、以及同一小时的疟疾检测“只查恶性疟抗原的快速检测”会漏掉非恶性疟这个陷阱、以及厚与薄的吉姆萨涂片并配专家的确认、以及重症疾病中寄生虫的计数、以及“临床上很重就不要等结果——按重症的标准经验性地静脉用青蒿琥酯”——[[microbiology/laboratory-diagnosis]]；按病种的第一小时的规则——登革“第4到6天的血浆渗漏期”的数日子、不用非甾体的、血小板不做预防性的输注、以及“以血细胞比容的走势管理液体（而血红蛋白的下降意味着出血）”；肠热的“在抗生素之前采血培养”、以及玫瑰疹与穿孔的识别；脑型疟的意识与气道及低血糖的监测青蒿琥酯更安全这一点——[[emergency-critical-care/shock-fluids]]、[[infectious-diseases/tropical-infections]]；高后果病原体的那一层——“旅行加接触加出血的暴露”的筛查、以及“立刻安置在单人间、不要送常规标本、打电话给感染医师与公共卫生机构及参考实验室的路径”、以及标本包装的合法性与工作人员的支持及去污、以及“在不确定之下的安全的决定”把“检测与治疗及隔离与升级”的平衡记录下来——[[public-health/communicable-disease-control]]、[[clinical-skills/patient-safety]]；以及治理——急诊疟疾检测的周转与阳性的确认的操作规程配一个可随时到岗的显微镜人员名册、旅行史数据质量的审计、脓毒症与热带疾病的“双路径”脓毒症的六个指标仍然适用、公平的审查谁会去“探望亲友”的旅行、谁漏掉了预防用药、以及旅行门诊的语言与费用的障碍、以及每年一次的模拟演练。**
