毒力是把一个细菌变成一种疾病的东西：**附着、侵袭、逃逸、损伤与传播是五个演化的问题、而每一个都有分子层面的解答——黏附素、分泌系统、荚膜、毒素与生物膜——它们解释了你所见的临床综合征、并启发了你所开的诊断与药物。**本章是上一“微生物目录”之下那一层机制。

本章涵盖黏附与定植、侵袭与分泌系统、免疫逃逸、毒素介导的损伤、生物膜与持续存在、以及传播与耐药的演化动力学。

## 进来并留下来

::: definition 黏附与定植 {#def-adhesion}
**受体的逻辑菌毛与带末端黏附素的纤毛、结合特定的糖脂或糖蛋白的受体——致病性大肠埃希菌的FimH对尿溶血素、以及肾盂肾炎菌株与P血型相关的黏附“血型与严重程度之间存在遗传关联”这一奇事、百日咳博德特菌那“气管的细胞毒素与丝状血凝素”的一对（使麻痹并使黏附、支原体的附着器、以及幽门螺杆菌的血型抗原及中性粒细胞激活蛋白的黏附素——由宿主多态的受体来解释——[[gastrointestinal/oesophagus-stomach]]、[[renal/urinary-tract]]、[[respiratory/respiratory-infections]]）；作为“分子的拖船”与抽搐式运动的IV型菌毛奈瑟菌与假单胞菌的收缩马达、以及在极部的装配、以及表面锚定非纤毛的黏附素识别基质的微生物表面组分——葡萄球菌的结合纤连蛋白的蛋白解释了器械与伤口的趋向、以及“侵袭素与A蛋白”的两面性；作为定位工具的动机与趋化鞭毛的计数与“集团对浮游”的逻辑、幽门螺杆菌经黏液的“感知pH的螺旋”、以及变形菌在导管上的群游——驱动鞭毛的质子动力见[[cell-biochemistry/membranes-transport]]；以及为生态位的竞争细菌素、以及经VI型分泌系统递送抗细菌的毒素——假单胞菌与不动杆菌的竞争生物学——以及菌群的“作为病原体排斥的定植抵抗”、带着它被抗生素打破、又被粪移植恢复的逻辑——见[[microbiology/microbiota]]与[[gastrointestinal/bowel-disease]]。**
:::

::: definition 侵袭与免疫逃逸 {#def-invasion}
**分泌系统的工具箱从I型到VI型的注射器、带着它们转运效应物的“针的复合体”——III型注射器注入“扰乱肌动蛋白聚合”的分子以进入（沙门菌的Sip与Sop效应物触发那把细菌吞进去的膜皱褶、以及志贺菌由侵袭质粒介导的侵袭与M细胞的取样、以及由III型注入的“转位蛋白打孔造成的炎症性腹泻”、以及肠致病性大肠埃希菌经Tir与“聚集素intimin”的“脚座的形成”造成的黏附与消除的病变——[[gastrointestinal/digestion-absorption]]、[[gastrointestinal/bowel-disease]]）；作为毒力与沟通的注射系统抗真核与抗细菌的、可收缩的“噬菌体尾样”的VI型注射器、以及“接合与效应物的混合体”IV型（嗜肺军团菌用它Dot-Icm的分泌装置从内质网的囊泡建造它的复制液泡——巨噬细胞内寄生的大师课见[[infectious-diseases/immunocompromised-host]]）；“拉链与雪球”这两种侵袭策略李斯特菌用内化素A与B拉链式地进入上皮、然后用肌动蛋白的火箭穿过细胞质、并在细胞之间扩散而不暴露于细胞外；以及耶尔森菌与葡萄球菌的侵袭素、以及沙门菌经M细胞摄入后在修饰过的囊泡内复制；以及细胞内的生态位（结核分枝杆菌经ESX-1与毒力因子阻断吞噬体与溶酶体的融合、以及中和吞噬体的酸化、以及作为“谈判出来的免疫学停战”的肉芽肿——见[[infectious-diseases/tuberculosis]]）；以及免疫逃逸的柜子荚膜——C组链球菌透明质酸的分子模拟、以及唾液酸化了的奈瑟菌与补体H因子的招募、以及肺炎链球菌的溶血素与荚膜的一对——[[immunology/innate-immunity]]；避开IgG与补体的蛋白——A蛋白与IgA蛋白酶、以及M蛋白与Fc结合的那套、以及白细胞毒素——杀白细胞素的成孔蛋白杀死中性粒细胞、以及它的坏死性肺炎与皮肤的表型、以及α毒素七聚体的孔；以及抗原变异的引擎——奈瑟菌的菌毛靠“链的错配滑动”与基因转换发生的抗原与相的变异、以及疏螺旋体表面抗原的洗牌与复发性发热、以及锥虫的抗原变异的平行——[[immunology/adaptive-responses]]。**

## 损伤与持续存在

::: definition 毒素、生物膜与持续存在 {#def-toxins}
**那张映射到综合征外毒素的分类表A-B型的毒素——腺苷二磷酸核糖基化的酶（霍乱毒素锁定Gs、升高环腺苷酸造成分泌、百日咳毒素废掉Gi、带来淋巴细胞增多与“致咳激素”的效应、以及白喉毒素及铜绿假单胞菌的A外毒素以延伸因子2为靶、让蛋白合成死亡——[[gastrointestinal/digestion-absorption]]、[[respiratory/respiratory-infections]]）；成孔的那一类——α毒素与杀白细胞素与α溶血素、以及链球菌溶血素O站在“抗链球菌溶血素O试验”背后那个对氧不稳定的溶血素与链球菌溶血素S、以及磷脂酶产气荚膜梭菌的α毒素/卵磷脂酶——组织的液化与产气、以及炭疽那对“水肿因子与致死因子”；以及超抗原——在沟槽之外交联主要组织相容性复合体二类与Vβ、把百分之二十的所有T细胞在一场细胞因子的风暴中激活（中毒性休克综合征毒素1、以及葡萄球菌的肠毒素与链球菌的热病外毒素、带着它们的皮疹与休克与脱皮、以及主要组织相容性复合体二类的多态性对它们的影响——细胞因子的生物学见[[immunology/adaptive-responses]]与[[immunology/innate-immunity]]）；内毒素与“病原相关分子模式”的逻辑脂质A对TLR4与CD14与MD2、鞭毛蛋白对TLR5、未甲基化的二核苷酸对TLR9、以及感知肽聚糖与DNA的胞质感受器（NOD与cGAS-STING、带着它们发热与低血压与弥散性血管内凝血及呼吸窘迫的表型——[[immunology/innate-immunity]]、[[emergency-critical-care/shock-fluids]]）；生物膜（“附着—成熟—扩散”的架构、带着它们的胞外多糖与DNA及菌毛及水的通道、以及10到1000倍的抗生素的耐受、以及“并不是耐药”的持续细胞表型、以及器械感染的临床现实——葡萄球菌与肺炎链球菌及假单胞菌及念珠菌的器械综合征、以及针对葡萄球菌生物膜联合利福平的逻辑、以及抗生素的封管治疗、以及“取出对保留”的决定——[[microbiology/antimicrobials]]、[[surgery/wounds-surgical-infection]]、人工关节见[[musculoskeletal/inflammatory-arthritis]]）；以及持续存在与休眠严谨的反应与静止期的通用应激反应、囊性纤维化慢性葡萄球菌感染中的小菌落变异、“可存活但不可培养”状态之争、毒素抗毒素的持续细胞、以及细胞内持续存在的储存库巨噬细胞里的沙门菌让治愈重新变得困难、以及生物膜脱落造成的复发——这就是“为什么疗程是以周而不是以天计”的生物学基础。**
:::

::: definition 病床边的传播与演化 {#def-evolution}
**作为临床问题的传播途径粪口途径伴感染剂量的分层——从志贺菌与隐孢子虫的很小、到霍乱的很大、以及呼吸道飞沫与气溶胶之间那条决定防护装备政策的界线（麻疹与结核与流感及冠状病毒的证据层级——[[public-health/communicable-disease-control]]、[[infectious-diseases/healthcare-infections]]）；媒介与储存库的逻辑（家畜与禽类及爬行类及蜱及洪水动物源的问题、只有暴露史能解开——[[infectious-diseases/tropical-infections]]）；性传播与垂直传播（母婴的名单与产时的处理——见[[obstetrics-gynaecology/labour-birth]]与[[paediatrics/newborn]]）；医疗相关的途径（手与器械与环境、以及抗生素选择的生态系统——[[microbiology/infection-control]]）；以及医师们制造的演化动力学选择窗与突变预防浓度、以及“耐药即自然选择、而治疗即选择压力”——高负荷部位心内膜炎与肺炎与结核的空洞内宿主的耐药演化驱动了联合治疗的逻辑（结核、HIV与肝炎的方案）；水平基因转移的载体——质粒与转座子及整合子及噬菌体耐药岛与质粒的流行病学——广谱酶与碳青霉烯酶及新德里金属酶的传播地图、以及接合的机器——见[[microbiology/antimicrobials]]；以及毒力与耐药的权衡、以及它们被打破之处耐甲氧西林的适合度代价与补偿的突变、以及带杀白细胞素株在社区的成功、以及社区相关的耐甲氧西林流行病学的循环——群体遗传学的语言见[[genetics/common-disease-genetics]]。**

::: example 旅行者的毒素 {#ex-cholera-vs-etec}

::: solution
**两种毒素、同一类机制、不同的急症（[[#def-toxins]]、[[gastrointestinal/digestion-absorption]]、[[infectious-diseases/tropical-infections]]）：共享的生理——由肠毒素驱动的分泌性腹泻、粪便等渗且无白细胞霍乱毒素那不可逆的Gs与环腺苷酸的锁定、对肠致病性大肠埃希菌的耐热毒素“同样的把戏”加上耐热肠毒素经环鸟苷酸、以及为什么止泻药在炎症性肠道疾病里既是姑息又有风险、而在这个病里则诚实地另当别论；不同的处理——以补液为中心口服补液盐、它经钠糖共转运的理由、是一种“由毒力机制推导出的治疗”——很漂亮、霍乱对那百分之十的重者用静脉的乳酸林格或生理盐水加钾与碳酸氢盐、多西环素或阿周红作为减少排菌的辅助、儿童的锌、以及通报及在硫代硫酸盐蔗糖琼脂上的粪便培养及聚合酶链、以及公共卫生及霍乱疫苗之谈——而肠致病性大肠埃希菌是自限的过程、只对重症给单剂的抗生素、以及洛哌丁胺的正当性；以及预防的教学——水与冰及沙拉及煮熟的热食规则、以及它们真实有效性的读数、及铋剂、及益生菌那薄弱的证据、以及正在形成的疫苗管道；暴发的角度——口被淹的水管井触发了国家的警报、而“病死率完全取决于补液的获取”治疗下的百分之一、对不治疗下的两位数、以及口服霍乱疫苗的运动、以及终结流行的“水、环境卫生与个人卫生”的干预——[[public-health/environmental-occupational]]、[[public-health/global-health]]；以及考试的箴言——痛性痉挛反映的是电解质的丢失、以及营养不良的儿童再喂养的风险——[[gastrointestinal/clinical-nutrition]]。**

## 通向何处

分子所瞄准的固有感受器在[[immunology/innate-immunity]]；应用机制的“微生物目录”在[[microbiology/bacteria]]；组织的后果在[[pathology/acute-inflammation]]；耐药的药理学在[[microbiology/antimicrobials]]；与微生物组的相互作用在[[microbiology/microbiota]]。

::: history
**毒力因子的生物学是“应用了的科赫”：白喉毒素发现的年代贝林与北里1888年的过滤实验证明无细胞的滤液会造成麻痹与死亡、从而证明存在一种可溶的毒物、以及费弗尔更早的霍乱与伤寒的滤液的工作、以及博尔代对百日咳毒素的解剖、以及1940年代伯内特关于相变异的工作它证明疫苗的组成很重要——[[respiratory/respiratory-infections]]、[[infectious-diseases/immunocompromised-host]]；毒素纯化的那一世纪——斯坦利与帕彭海默对炭疽致死毒素的重建、1970年代霍乱毒素的结构与腺苷二磷酸核糖基化的酶学、以及1980年代把猩红热的热病外毒素重新理解为T细胞的丝裂原、以及那个确立了“多克隆的T细胞激活”的与卫生棉及中毒性休克综合征毒素1相关的流行病学——[[immunology/adaptive-responses]]；分子发病学的革命——侵袭素的克隆、泰里奥特与蒂尔尼对李斯特菌肌动蛋白彗尾的工作、以及桑松内的志贺菌的细胞生物学规划、以及“病原菌通过针状的接触机器注射效应物”这一源自植物病理学的发现、以及“黏附与消除”的那对蛋白构成脚座的工作、以及2010年代把VI型分泌系统重新理解为“细菌之间竞争的武器”；以及现代的持续存在的年代——科斯特顿慢性感染的模型与马什的牙菌斑的生态学奠基了生物膜的领域、伴随器械感染负担的统计、以及哈罗德·刘易斯那句“耐药是遗传学、而持续存在是生理学”的主张、及严谨的反应与毒素抗毒素的分子基础、以及“用恢复粪群的定植抵抗作为疗法”把本章前半的逻辑变成了一种获批的治疗——[[microbiology/microbiota]]、[[gastrointestinal/bowel-disease]]。**
:::

::: summary
- 毒力是分幕的：先黏附、然后侵袭或回避、然后损伤、然后传播——而每一幕都有值得在临床上认出的、有名字的分子机器。
- 毒素的综合征遵循酶的逻辑：腺苷二磷酸核糖基化霍乱、百日咳、白喉、成孔杀白细胞素、链球菌溶血素、超抗原中毒性休克——定义临床时钟的正是酶。
- 细胞内的生活分枝菌、李斯特菌、沙门菌、军团菌、衣原体决定了免疫依赖T细胞、药物的选择细胞内的穿透与疫苗的困难。
- 荚膜、抗原的变异与免疫逃逸的蛋白解释了疫苗的“血清型的生态学”与再感染；T细胞非依赖的多糖抗原正是结合疫苗被发明的原因。
- 生物膜与持续细胞解释了器械感染、复发、与疗程的逻辑——源头控制不是抗生素的替代、而是它们能起效的原因。
- 抗生素的使用就是演化：耐药的突变体被选择、质粒把它转移、而病房变成了生态系统——处方的那一章就写在这里。
:::

**由机制指导的管理（[[#def-evolution]]、[[#def-toxins]]、[[microbiology/antimicrobials]]、[[infectious-diseases/stewardship-outbreaks]]）：耐药出现的物理学——突变的预防浓度与接种量的效应、解释了为什么高负荷的部位需要联合与源头控制心内膜炎与骨与结核的空洞例子、附带损害的动理学微生物组的耗竭、以及由碳青霉烯及氟喹诺酮及广谱头孢暴露研究记录的艰难梭菌与耐药阴性菌及肠球菌的选择、以及疗程缩短的证据革兰阴性菌血症与肺炎及“心内膜炎的邻近”的在研短期疗程的试验、连同它们的人群一起读——[[epidemiology-ebm/randomised-trials]]；处方集的杠杆——受限对不受限而“必须复查”由电子的强制功能执行的48到72小时的停药与复查、以及带生物利用度表的静脉转口服、以及每日一次给药与“让门诊静脉治疗成为可能”的选择、作为管理的诊断（下呼吸道感染降钙素原的边界、快速血培养的组合检测 的影响研究及其降级的发现、质谱与药敏的速度、以及“用鼻腔聚合酶链的阴性预测值来停用万古霉素”）、以及作为“活的文件的本地药敏图”、带每季度的按处方者的反馈；以及文化与治理的那一层——兽医与农业的“同一健康”的连接黏菌素政策的平行——[[public-health/environmental-occupational]]、[[public-health/global-health]]；生态学的审计病房层面的消耗对耐药的走势的图、以及反馈给制造自己耐药菌群的单元；以及给处方者诚实的框架——“政策保护的是你未来的患者的选择权、这是你自己的处方足迹”、“只培养、不是每例发热都培养”的规则、配安全网的指导有期限的抗生素与复查的日期、作为一种处方的结构、以及真正重要的结局指标没有被过度治疗的死亡率、以及艰难梭菌与耐药及再入院——[[clinical-skills/patient-safety]]。**
