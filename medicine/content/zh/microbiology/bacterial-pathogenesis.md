接触人体的细菌大多数并不造成伤害。它们被冲走，被固有防御杀灭，或者定居下来成为正常菌群中无害的成员。**病原体**是能够引起疾病的微生物，而要做到这一点，它必须解决一系列问题：到达宿主，附着于表面，增殖，躲避或抵抗免疫应答，并损伤组织。每一种解决办法都是一个**毒力因子**，而每一个毒力因子都是理解临床表现的线索。

按步骤思考也能解释治疗。有些疾病由在组织中生长的细菌引起，杀灭细菌就能治愈。另一些疾病由已经起完作用的毒素引起，此时抗生素帮助不大。有些感染在植入的器械上持续存在，因为细菌生活在药物无法清除的生物膜中。

本章介绍致病性和毒力，把微生物与疾病联系起来的证据，黏附和侵袭，免疫逃逸，细菌毒素，生物膜，以及决定谁会发病的宿主因素。

## 致病性、毒力与剂量 {#virulence}

::: definition 致病性与毒力 {#def-virulence}
**致病性**是微生物引起疾病的能力。它是一个菌种或菌株“有或无”的属性。

**毒力**是致病性的程度：微生物引起疾病的难易和严重程度。例如可用**半数感染量**（ID50，即使一半暴露宿主发生感染的剂量）或**半数致死量**（LD50，即使一半宿主死亡的剂量）来衡量。

**原发病原体**能使健康人致病。**机会致病菌**主要在宿主防御受损时致病，例如中性粒细胞减少、留置中心静脉导管或烧伤时。
:::

感染剂量差异极大。志贺菌属（*Shigella*）和产志贺毒素的大肠埃希菌（*Escherichia coli*）可能在摄入10～100个菌后就引起疾病，这就是它们容易在托儿所的儿童之间传播的原因。对于胃酸正常的人，霍乱弧菌（*Vibrio cholerae*）需要大得多的剂量，因为胃酸能杀死大部分摄入的弧菌。服用质子泵抑制剂或因其他原因胃酸减少的人，较低剂量的多种肠道病原体即可使其感染。

一个简单的模型使这些数字更便于应用。假设一个剂量中的每个微生物各自独立地以很小的概率$r$引起感染。那么剂量$D$使宿主感染的概率为

$$
P(D) = 1 - e^{-rD}
$$ {#eq-dose}

令$P = 0.5$可得$\text{ID}_{50} = \ln 2 / r$，因此同一模型可以写成$P(D) = 1 - 2^{-D/\text{ID}_{50}}$。每增加一个ID50的暴露，逃脱感染的机会就减半。

::: widget plot
f: 1 - 2^(-x/m)
x: 0, 1000
y: 0, 1.05
sliders: m=100:10:1000:10
labels: \text{感染概率}
caption: 指数剂量—反应模型$P = 1 - 2^{-D/\text{ID}_{50}}$，横轴为剂量$D$（微生物个数）。滑块设定ID50。ID50低时，如志贺菌，即使很小的暴露也很危险；ID50高时曲线平缓。真实的剂量—反应曲线还取决于宿主、媒介（食物、水、手）和菌株；这是一个简化模型。
:::

::: example 一次暴露后感染的可能性有多大？ {#ex-dose}
在一个简化模型中，某种肠道病原体的ID50为100个菌。一名儿童从被污染的玩具上吞下了约300个菌。用指数剂量—反应模型计算感染概率。如果剂量是10个菌，概率又是多少？
::: solution
用$P(D) = 1 - 2^{-D/\text{ID}_{50}}$。

$D = 300$时：$D/\text{ID}_{50} = 3$，所以

$$
P = 1 - 2^{-3} = 1 - \tfrac{1}{8} = 0.875
$$

$D = 10$时：$P = 1 - 2^{-0.1} \approx 0.067$，约7%。

即使剂量只有ID50的十分之一，也有真实的风险。这就是为什么洗手，以及让腹泻儿童在症状消失48小时后才返回托儿所，是英国标准的公共卫生建议：这些措施降低的是剂量，而不仅仅是暴露的次数。
:::
:::

## 把微生物与疾病联系起来 {#causation}

在病人身上发现某种微生物，并不能证明它导致了疾病。它可能是无害的定植菌或污染菌。医学微生物学有判断因果关系的正式标准。

::: theorem 科赫法则及其分子版本 {#thm-koch}
**科赫法则**认为，一种微生物导致一种疾病，需要满足：

1. 在该病的每一个病例中都能找到它；
2. 能把它分离出来并进行纯培养；
3. 把纯培养物接种到易感宿主时能引起该病；
4. 能从该宿主中再次分离出同一微生物。

**分子科赫法则**由斯坦利·法尔科（Stanley Falkow）于1988年提出，把同样的逻辑应用于毒力基因：

1. 该基因存在于致病菌株中，而通常不存在于非致病菌株中；
2. 灭活该基因会降低毒力；
3. 恢复该基因会恢复毒力。
:::

::: proof
经典法则在几种常见情况下不成立，了解这些失败之处与了解规则本身同样有用。

- **带菌者。**健康人可以携带脑膜炎奈瑟菌（*Neisseria meningitidis*）、肺炎链球菌（*Streptococcus pneumoniae*）和金黄色葡萄球菌（*Staphylococcus aureus*），因此有该微生物却没有疾病。
- **无法培养的微生物。**麻风分枝杆菌（*Mycobacterium leprae*）和梅毒螺旋体（*Treponema pallidum*）不能在实验室培养基上生长。
- **没有动物模型。**有些人类病原体在动物身上不引起类似的疾病，而故意使人感染通常是不道德的。
- **多种微生物共同致病。**脓肿和牙周病涉及几种微生物的共同作用。

分子版本检验的是一个特定的基因而不是整个微生物，因而避开了其中一些问题。现代证据还来自组织中的DNA检测、免疫应答、流行病学以及治疗或疫苗接种的效果。针对某一种微生物的疫苗推广后疾病随之消失，就是该微生物导致该病的有力证据。
:::

## 黏附与定植 {#adhesion}

人体表面受到流动的保护：唾液、尿液、由纤毛推动的黏液以及肠蠕动。不能牢牢附着的细菌就会被冲走。

::: definition 黏附 {#def-adhesion}
**黏附**是细菌与宿主表面的特异性结合。它由**黏附素**介导，黏附素是与宿主细胞或细胞外基质上的受体结合的细菌分子。许多黏附素位于**菌毛**的顶端；另一些是锚定在细胞壁上的蛋白质。

由于每种黏附素结合一种特定的受体，黏附有助于解释**组织嗜性**：为什么一种微生物感染某种组织而不感染另一种。
:::

一些例子显示了这种特异性可以有多高。

- **尿路致病性大肠埃希菌。**Ⅰ型菌毛结合膀胱中含甘露糖的受体，引起膀胱炎。**P菌毛**结合肾脏中的糖脂受体，与肾盂肾炎相关。
- ***淋病奈瑟菌***（*Neisseria gonorrhoeae*）利用Ⅳ型菌毛附着于尿道和宫颈上皮。它能转换菌毛蛋白基因，改变菌毛抗原。
- ***化脓性链球菌***（*Streptococcus pyogenes*）通过表面蛋白结合咽部细胞上的纤连蛋白。
- ***金黄色葡萄球菌***有能结合纤维蛋白原和纤连蛋白的表面蛋白。植入的器械很快会被这些宿主蛋白包被，这就给了葡萄球菌一个附着点。
- ***霍乱弧菌***通过一种菌毛附着于小肠黏膜，使自己靠近其毒素作用的细胞。

黏附是预防的靶点。感染或接种疫苗后产生的抗黏附素抗体能阻止定植。包括无细胞百日咳疫苗在内的一些疫苗就含有黏附素作为抗原。

## 侵袭与免疫逃逸 {#invasion}

有些病原体停留在表面，通过毒素起作用。另一些则进入组织或生活在细胞内，在那里它们受到保护，免受抗体和许多抗生素的作用。

::: definition 侵袭与免疫逃逸 {#def-invasion}
**侵袭**是细菌进入宿主细胞或组织。细菌通过以下方式侵袭：

- **诱导自身被摄取**：沙门菌属（*Salmonella*）和志贺菌属通过针状的**Ⅲ型分泌系统**把蛋白质注入肠上皮细胞，使细胞把它们吞入；
- **结合进入受体**：单核细胞增生李斯特菌（*Listeria monocytogenes*）利用一种称为内化素的表面蛋白结合E-钙黏蛋白；
- **分解组织**：透明质酸酶和链激酶等酶帮助化脓性链球菌沿组织间隙扩散。

**免疫逃逸**包括使细菌在宿主应答中存活的任何机制：

- **荚膜**，使菌体表面躲开补体和抗体，并阻止吞噬；
- 金黄色葡萄球菌的**A蛋白**，以错误的方向结合IgG的Fc段；
- 奈瑟菌属、流感嗜血杆菌（*Haemophilus influenzae*）和肺炎链球菌的**IgA蛋白酶**，切割黏膜IgA；
- **抗原变异**，改变表面抗原的速度快于抗体跟进的速度；
- **杀白细胞素**，杀伤白细胞的毒素；
- **胞内存活**：结核分枝杆菌（*Mycobacterium tuberculosis*）阻止吞噬体与溶酶体融合，李斯特菌则从吞噬体逃逸到细胞质中。
:::

胞内菌改变了控制它们的免疫应答。抗体无法到达它们，因此控制依赖于**T细胞**和活化的巨噬细胞。这就是为什么HIV感染者、使用糖皮质激素或TNF抑制剂的人以及器官移植受者容易受到结核分枝杆菌、李斯特菌和沙门菌的威胁。这也解释了肉芽肿：肉芽肿是巨噬细胞和T细胞有组织的聚集，把它们无法杀灭的微生物围隔起来。

李斯特菌和志贺菌更进一步。在细胞内，它们把宿主的肌动蛋白聚合成一条尾巴，把自己推入相邻细胞。它们在细胞之间扩散，从不暴露于细胞外空间。

## 毒素 {#toxins}

::: definition 外毒素与内毒素 {#def-toxins}
**外毒素**是细菌产生并释放、能损伤宿主细胞的蛋白质。革兰阳性菌和革兰阴性菌都能产生外毒素，它们往往毒性极强、作用特异，通常可被加热灭活。许多外毒素可以转化为无害但仍能诱导抗体的**类毒素**，这是破伤风和白喉疫苗的基础。

**内毒素**是革兰阴性菌外膜中脂多糖的脂质A部分。它不是以这种形式分泌的，而是在细菌生长或死亡时释放。它耐热，通过触发宿主的炎症反应而不是直接损伤细胞起作用，不能制成类毒素。
:::

许多外毒素具有共同的**A–B结构**。**B**（结合）部分附着于靶细胞上的受体，把毒素带入细胞。**A**（活性）部分是一种改变细胞成分的酶。由于A部分是酶，几个分子就能影响整个细胞。

| 毒素 | 细菌 | 作用 | 结果 |
|---|---|---|---|
| 霍乱毒素 | 霍乱弧菌 | 使G蛋白Gs发生ADP-核糖基化，腺苷酸环化酶持续处于激活状态 | cAMP升高；氯离子和水分泌；大量水样腹泻 |
| 不耐热肠毒素 | 产肠毒素大肠埃希菌 | 与霍乱毒素类似 | 旅行者腹泻 |
| 白喉毒素 | 白喉棒状杆菌（*Corynebacterium diphtheriae*） | 使延伸因子2发生ADP-核糖基化 | 蛋白质合成停止；咽部假膜、心肌炎、神经病变 |
| 志贺毒素 | 1型痢疾志贺菌、产志贺毒素大肠埃希菌 | 切割核糖体RNA | 蛋白质合成停止；血性腹泻、溶血性尿毒症综合征 |
| 百日咳毒素 | 百日咳鲍特菌（*Bordetella pertussis*） | 使抑制性G蛋白Gi发生ADP-核糖基化 | cAMP升高；淋巴细胞增多、免疫细胞功能受损 |
| 破伤风毒素 | 破伤风梭菌（*Clostridium tetani*） | 到达脊髓，切割抑制性神经元中的一种SNARE蛋白 | 失去抑制；痉挛和强直 |
| 肉毒毒素 | 肉毒梭菌（*C. botulinum*） | 在胆碱能神经末梢切割SNARE蛋白 | 乙酰胆碱不能释放；弛缓性瘫痪 |

另一些外毒素直接破坏细胞膜。例如产气荚膜梭菌（*C. perfringens*）的α毒素，是一种在气性坏疽中破坏肌肉的磷脂酶；还有链球菌溶血素O和杀白细胞素（Panton–Valentine杀白细胞素）等成孔毒素。

::: theorem 超抗原绕过抗原特异性 {#thm-superantigen}
**超抗原**是一种毒素，它结合抗原提呈细胞上MHCⅡ类分子的外侧以及T细胞受体的可变β区，无需经过加工，也不在肽结合槽中提呈。因此，它激活所有带有匹配β区的T细胞，这可以占全部T细胞的很大比例，而不是对普通抗原发生应答的极小部分。
:::

::: proof
普通抗原被切成肽段，只有受体恰好匹配某一种肽—MHC组合的T细胞才会应答。这部分细胞非常少。

超抗原从侧面把MHCⅡ类分子与T细胞受体夹在一起。任何受体具有相容β区的T细胞都会被激活，而不论其受体其余部分识别什么。T细胞大规模的同时激活释放大量IL-2、TNF和干扰素-γ等细胞因子。

细胞因子的洪流引起发热、弥漫性红色皮疹、毛细血管渗漏、低血压和多器官衰竭：即**中毒性休克综合征**。例子包括金黄色葡萄球菌的中毒性休克综合征毒素1（TSST-1）和肠毒素，以及化脓性链球菌的致热外毒素。
:::

### 内毒素与感染性休克 {#endotoxin}

内毒素通过固有免疫系统起作用。血液中的脂质A与**脂多糖结合蛋白**结合，后者把它交给**CD14**，再交给巨噬细胞和内皮细胞上的受体**TLR4**及其伴侣分子MD-2。TLR4信号激活转录因子NF-κB，并释放TNF、IL-1和IL-6。

少量时这种反应是有益的：它引起发热并募集中性粒细胞。大量时则引起血管扩张、毛细血管渗漏、凝血激活伴弥散性血管内凝血以及休克。脑膜炎球菌败血症出现紫癜和迅速的循环衰竭，展示了内毒素最剧烈的作用。革兰阳性菌通过脂磷壁酸和肽聚糖碎片等其他成分引发类似的反应，这就是为什么感染性休克并不局限于革兰阴性菌感染。

::: warning 抗生素不能中和已经产生的毒素
当疾病由预先形成的毒素引起时，杀灭细菌并不能逆转损伤。在肉毒中毒和破伤风中，**抗毒素**中和尚未与神经结合的毒素，而从已结合毒素的作用中恢复需要数周。在葡萄球菌食物中毒中，毒素已经存在于食物里，抗生素没有作用。

相反的错误也会发生。在产志贺毒素大肠埃希菌感染中，某些抗生素可能增加濒死细菌释放毒素，出于对溶血性尿毒症综合征的担忧，英国指南建议不要常规使用抗生素。始终要问：疾病是由生长的细菌引起的，还是由毒素引起的，或者两者兼有？
:::

::: example 旅行后的水样腹泻 {#ex-cholera-vs-etec}
一名28岁的援助工作者从霍乱暴发地区回国，突然出现无痛性、大量的水样腹泻。她没有发热，粪便中无血。脉搏每分钟120次，站立时感到头晕。请解释其机制，以及口服补液盐为何有效。
::: solution
这一表现符合**霍乱**，或由产肠毒素大肠埃希菌引起的类似但较轻的疾病。这两种细菌都停留在小肠表面而不侵袭，因此没有发热、炎症或便血。

霍乱毒素通过其B亚基与肠细胞结合。A亚基使腺苷酸环化酶持续激活。cAMP升高打开CFTR氯离子通道，于是氯离子、随后钠和水大量涌入肠腔。每天可丢失数升液体，死亡由脱水和电解质丢失引起，而不是由组织损伤引起。

口服补液盐之所以有效，是因为毒素不影响**钠—葡萄糖同向转运体**（SGLT1）。葡萄糖和钠一同被吸收，把水拉回体内。补液是主要的治疗，轻者口服，重者静脉输注。抗生素能缩短病程、减少排菌，但相对于补液是次要的。
:::
:::

::: example 年轻女性发热、皮疹和休克 {#ex-toxic-shock}
一名24岁女性出现高热、呕吐、腹泻和类似晒伤的弥漫性红色皮疹。血压82/45 mmHg，肌酐升高。她在经期使用卫生棉条。之后的血培养无细菌生长。请解释其发病机制和处理原则。
::: solution
这很可能是**葡萄球菌中毒性休克综合征**。定植于阴道的金黄色葡萄球菌在卫生棉条造成的条件下生长，产生超抗原**TSST-1**。毒素被吸收，引起T细胞大规模激活和细胞因子释放，这就解释了皮疹、休克和器官衰竭。葡萄球菌中毒性休克时血培养通常为阴性，因为致病的是毒素而不是菌血症。手掌和足底的皮肤通常在一至两周后脱屑。

处理原则是去除感染源（卫生棉条），复苏和器官支持，以及使用覆盖金黄色葡萄球菌的抗生素。指南通常加用克林霉素（clindamycin）等蛋白质合成抑制剂，因为它能减少细菌产生毒素。静脉注射免疫球蛋白含有抗超抗原的抗体，有时用于重症病例，尤其是链球菌中毒性休克，需遵循专科意见和当地指南。
:::
:::

## 生物膜与持续感染 {#biofilm}

::: definition 生物膜 {#def-biofilm}
**生物膜**是附着于表面、包裹在细菌自身产生的基质中的细菌群落，基质由多糖、蛋白质和DNA构成。生物膜中的细菌生长缓慢，能躲开吞噬细胞和抗体，对抗生素的耐受性也远高于自由生长的同种细菌。
:::

生物膜可在死骨、心脏瓣膜、牙齿上形成，尤其是在植入材料上：中心静脉导管、导尿管、人工关节、人工心脏瓣膜和起搏器。凝固酶阴性葡萄球菌、金黄色葡萄球菌和铜绿假单胞菌（*Pseudomonas aeruginosa*）是典型的生物膜细菌。在囊性纤维化中，铜绿假单胞菌在黏稠的气道黏液中形成生物膜，一旦形成几乎不可能根除。

几个特点解释了对抗生素的耐受。基质减慢了某些药物的渗透。生物膜中的许多细胞分裂缓慢或根本不分裂，而大多数抗生素作用于生长中的细胞。一小部分处于休眠状态的**持留菌**在治疗中存活，治疗结束后重新生长。实验室药敏试验是在自由生长的细菌上进行的，因此一种细菌可能报告为敏感，却仍能在生物膜中存活。

生物膜中的细菌还通过**群体感应**协调其行为。每个细胞释放小的信号分子；当菌群密集时，信号浓度超过阈值，开启毒素、基质产生或扩散相关的基因。金黄色葡萄球菌的**agr**系统就以这种方式调控毒素的产生。

::: example 人工髋关节疼痛 {#ex-biofilm-joint}
一名71岁男性18个月前做了髋关节置换术。近六个月来髋部疼痛逐渐加重，无发热。X线片显示假体松动。关节穿刺液培养出对多种抗生素耐药的表皮葡萄球菌（*Staphylococcus epidermidis*）。请解释为什么这是生物膜感染，以及为什么单用抗生素不太可能治愈。
::: solution
凝固酶阴性葡萄球菌引起的人工关节迟发性低度感染是典型的生物膜感染。来自皮肤的表皮葡萄球菌很可能在手术时污染了植入物，并在其表面形成了生物膜。缓慢的病程、无发热和假体松动反映的是慢性低度炎症，而不是急性侵袭性感染。

由于表皮葡萄球菌也栖居于皮肤，单次阳性培养可能是污染。因此诊断依赖于多份标本：指南建议手术时采集多份组织标本，两份或更多份培养出同一种细菌时，感染的可能性大。

抗生素能抑制感染，但很少能清除它，因为生物膜庇护了生长缓慢的细胞和持留菌。治愈通常需要手术去除生物膜，常为一期或二期更换假体，之后在专科指导下进行较长疗程的抗生素治疗。
:::
:::

## 宿主因素 {#host}

暴露是否导致疾病，取决于宿主的程度不亚于取决于微生物。特定的防御缺陷预示特定的感染，这在两个方向上都有用：已知的缺陷告诉你该担心什么，而少见的感染则提示可能存在隐匿的缺陷。

- **无脾。**脾脏清除被抗体和补体包被的细菌，并产生针对荚膜多糖的抗体。没有功能性脾脏的人，包括镰状细胞病患者，有发生有荚膜细菌暴发性感染的危险：肺炎链球菌、b型流感嗜血杆菌和脑膜炎奈瑟菌。
- **终末补体缺陷**（C5–C9）阻止膜攻击复合物的形成，易发生反复的奈瑟菌感染。阻断C5的药物，如依库珠单抗（eculizumab），带来同样的风险，因此患者在治疗前要接种疫苗，并常需服用抗生素预防。
- **中性粒细胞减少**易发生革兰阴性菌菌血症、金黄色葡萄球菌感染和侵袭性真菌感染。
- **T细胞缺陷**易发生胞内菌、分枝杆菌、真菌和病毒感染。
- **屏障破坏**为微生物打开入口：烧伤（铜绿假单胞菌）、静脉导管（葡萄球菌）、导尿管（肠道细菌）和手术伤口。

::: quiz
哪一种机制解释了中毒性休克综合征中大量细胞因子的释放？
- [ ] 脂质A与巨噬细胞上的Toll样受体4结合
- [x] 毒素在肽结合槽之外把MHCⅡ类分子与T细胞受体连接起来
- [ ] 毒素使延伸因子2发生ADP-核糖基化
- [ ] 抗体结合荚膜并激活补体
::: solution
中毒性休克的毒素是**超抗原**。它们在正常抗原结合位点之外结合MHCⅡ类分子和T细胞受体β区，因此一次激活很大比例的T细胞。脂质A经TLR4传递信号是革兰阴性菌感染性休克中内毒素的机制。使延伸因子2发生ADP-核糖基化是白喉毒素的作用。
:::
:::

::: history
1884年，弗里德里希·吕夫勒（Friedrich Loeffler）培养出白喉杆菌，并注意到细菌停留在咽部，而损害却出现在心脏和神经。他怀疑存在一种循环中的毒物。1888年，埃米尔·鲁（Émile Roux）和亚历山大·耶尔森（Alexandre Yersin）证明，白喉培养物的无菌滤液能在动物身上复制出这种疾病，从而证明细菌毒素本身就能致病。1890年，埃米尔·冯·贝林（Emil von Behring）和北里柴三郎（Kitasato Shibasaburō）证明，免疫动物的血清能中和白喉毒素和破伤风毒素，由此产生了抗毒素疗法，冯·贝林也因此获得1901年首届诺贝尔生理学或医学奖。

罗伯特·科赫（Robert Koch）判断因果关系的标准是在19世纪80年代他关于结核病的研究中提出的，现在称为科赫法则。一个世纪之后，1988年，随着分子遗传学使开启和关闭单个细菌基因成为可能，斯坦利·法尔科提出了针对毒力基因的分子科赫法则。
:::

## 后续内容

毒力背后的结构在[[microbiology/bacteria]]中介绍，病原体所逃避的固有和适应性免疫应答见[[immunology/innate-immunity]]和[[immunology/adaptive-responses]]。作为临床综合征的脓毒症是[[infectious-diseases/fever-sepsis]]的主题，器械相关感染见[[infectious-diseases/healthcare-infections]]。生物膜和毒素如何影响抗生素的选择，在[[microbiology/antimicrobials]]中解释。

::: summary
- 致病性是引起疾病的能力；毒力是其程度，用ID50或LD50衡量。在指数模型中$P = 1 - 2^{-D/\text{ID}_{50}}$。
- 科赫法则把微生物与疾病联系起来，但对带菌者、无法培养的微生物和多菌感染不适用；分子科赫法则检验单个毒力基因。
- 菌毛上的黏附素和表面蛋白结合特异性受体，解释了组织嗜性。
- 侵袭性细菌诱导自身被摄取或结合进入受体；荚膜、A蛋白、IgA蛋白酶、抗原变异和胞内存活帮助逃避免疫。
- 外毒素是蛋白质，常为A–B结构的酶，可以制成类毒素；内毒素是脂质A，通过TLR4触发炎症。超抗原一次激活大量T细胞，引起中毒性休克。
- 器械上的生物膜耐受抗生素，通常需要去除器械。
- 宿主缺陷预示感染：无脾与有荚膜细菌，终末补体缺陷与奈瑟菌，T细胞缺陷与胞内微生物。
:::

## 习题

::: exercise 把毒素与其机制配对 {level=1}
把每种毒素与其机制配对：(a) 霍乱毒素，(b) 白喉毒素，(c) 破伤风毒素，(d) TSST-1。机制：(1) 超抗原，(2) 使延伸因子2发生ADP-核糖基化，(3) 切割抑制性神经元中的一种SNARE蛋白，(4) 使腺苷酸环化酶持续激活。
::: hint
其中两种毒素通过加上ADP-核糖影响信号转导或蛋白质合成；只有一种作用于神经系统。
:::
::: solution
(a)–(4)，(b)–(2)，(c)–(3)，(d)–(1)。霍乱毒素使Gs保持激活并升高cAMP。白喉毒素使延伸因子2失活，停止蛋白质合成。破伤风毒素阻断脊髓中抑制性递质的释放。TSST-1是超抗原。
:::
:::

::: exercise 剂量与概率 {level=1 check="0.875"}
在指数剂量—反应模型中，某种微生物的ID50为100个。剂量为300个时感染概率是多少？给出精确的小数。
::: hint
用$P = 1 - 2^{-D/\text{ID}_{50}}$。
:::
::: solution
$D/\text{ID}_{50} = 3$，所以$P = 1 - 2^{-3} = 1 - 0.125 = 0.875$。
:::
:::

::: exercise 脾脏与荚膜 {level=1}
为什么没有功能性脾脏的人特别容易受到肺炎链球菌的威胁？
::: hint
想一想荚膜对吞噬作用的影响，以及脾脏的贡献。
:::
::: solution
肺炎链球菌有多糖**荚膜**，除非细菌被抗体和补体包被，否则它能抵抗吞噬。脾脏过滤血液，清除调理不充分的细菌，其边缘区B细胞产生针对多糖抗原的抗体。没有脾脏时，有荚膜的细菌在血液中增殖，可在数小时内引起暴发性脓毒症。因此无脾者要接种针对有荚膜细菌的疫苗，可能需要抗生素预防，并被告知发热时要紧急就医，均遵循国家指南。
:::
:::

::: exercise 类毒素与否 {level=2}
破伤风可以通过接种类毒素来预防，但没有针对内毒素的疫苗。请从两种分子的性质解释这一差别。
::: hint
比较一种蛋白质与一种作为膜成分的脂质。
:::
::: solution
破伤风毒素是**蛋白质**。用甲醛处理能破坏其毒性，但保留足够的结构，使免疫系统产生中和抗体，从而阻断真正的毒素。内毒素是**脂质A**，是嵌在所有革兰阴性菌外膜中的糖脂。它免疫原性差，在许多菌种之间相似，也不是作为独立的毒素分泌的，因此没有能防御它的类毒素。针对多变的O抗原的抗体只能防御特定的菌株。
:::
:::

::: exercise 科赫法则的实际应用 {level=2}
解释为什么麻风分枝杆菌和幽门螺杆菌（*Helicobacter pylori*）各自至少不符合科赫法则中的一条，以及还有哪些证据把它们与疾病联系起来。
::: hint
想一想培养，以及有多少感染者一直保持健康。
:::
::: solution
***麻风分枝杆菌***不能在人工培养基上生长，因此不符合第2条。把它与麻风联系起来的证据是它存在于病变中、能在犰狳和小鼠足垫中生长、免疫应答以及治疗的效果。

***幽门螺杆菌***可以培养，但许多感染者从未发生溃疡，因此严格意义上的第1条不成立。证据来自巴里·马歇尔（Barry Marshall）亲自吞服细菌的实验（引起了胃炎）、流行病学，最重要的是根除该菌能大大减少溃疡复发这一事实。
:::
:::

::: exercise 高罹患率所需的剂量 {level=2 check="332"}
用ID50为100个的指数剂量—反应模型，多大剂量能使感染概率达到90%？取整到个位。
::: hint
由$0.9 = 1 - 2^{-D/100}$解出$D$。
:::
::: solution
$2^{-D/100} = 0.1$，所以$D/100 = \log_2 10 \approx 3.32$，$D \approx 332$个。使逃脱感染的机会降低到十分之一，大约需要3.3个ID50。
:::
:::

::: exercise 儿童血性腹泻 {level=3}
一名4岁男孩在参观农场三天后出现血性腹泻。粪便PCR检出志贺毒素基因，培养出大肠埃希菌O157。六天后他面色苍白，尿量减少，血小板计数低，血涂片见破碎红细胞。请解释其发病机制，以及为什么不常规使用抗生素。
::: hint
志贺毒素结合在哪里？细菌被杀死时毒素会怎样？
:::
::: solution
这是产志贺毒素大肠埃希菌感染后的**溶血性尿毒症综合征**。细菌定植于结肠，释放**志贺毒素**，毒素被吸收入血。其B亚基结合糖脂Gb3，后者在肾小球内皮上含量丰富。A亚基停止蛋白质合成，损伤内皮细胞。受损的血管激活血小板并形成微血栓，消耗血小板（血小板减少），剪切红细胞（破碎红细胞和溶血），并阻塞肾小球（急性肾损伤）。

一般避免使用抗生素，因为某些抗生素通过应激或杀死细菌，可能增加毒素的产生或释放，观察性研究也把它们与较高的溶血性尿毒症综合征风险联系起来。处理以支持治疗为主，仔细管理液体平衡，必要时透析，在专科医生指导下进行。该病为法定报告疾病，公共卫生团队调查感染来源，并按英国指南让受感染的儿童在清除细菌之前不返回托儿所。
:::
:::

::: exercise 反复发生的脑膜炎球菌病 {level=3}
一名27岁男性三年内第二次发生脑膜炎球菌感染，两次都是少见的血清群。应怀疑什么宿主缺陷？如何检查？对他和他的家人有什么意义？
::: hint
免疫系统的哪一部分在血液中直接杀灭奈瑟菌？
:::
::: solution
反复或少见血清群的奈瑟菌感染提示**补体**系统缺陷，尤其是形成膜攻击复合物的终末成分C5–C9，或备解素缺陷。奈瑟菌的清除格外依赖补体介导的溶菌作用。

检查从补体功能试验开始（经典途径和旁路途径活性，即CH50和AP50），然后测定单个补体成分。还应考虑狼疮等引起补体消耗或丢失的其他原因。

意义：他应接种脑膜炎球菌疫苗，可能需要抗生素预防，并应备有发热时紧急治疗的方案，均遵循专科意见。遗传性缺陷有家族性，因此其兄弟姐妹可以接受检测。同样的推理适用于使用依库珠单抗等C5抑制剂的人，他们在开始治疗前要接种疫苗。
:::
:::
