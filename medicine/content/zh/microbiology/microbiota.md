每个人的皮肤、口腔、肠道、上呼吸道和阴道中都携带着大量微生物。其中大多数是细菌，也有病毒、真菌和古菌。一项严谨的估计表明，人体内细菌细胞的数量与人体细胞的数量处于同一数量级，其中大部分在结肠。

这些微生物并不是过客。它们消化我们无法消化的食物，合成维生素，训练免疫系统，最重要的是占据了本来会被病原体占据的空间。它们也是医院内大多数感染的来源：当患者自身的菌群到达不该到的地方时，就会引起感染。抗生素会改变这个群落，有时改变很长时间，而艰难梭菌（*Clostridioides difficile*）感染是由此造成危害的最清楚的例子。

本章介绍微生物群的基本术语，它在身体不同部位的组成，它的发育和功能，研究它的方法，抗生素如何扰乱它，艰难梭菌感染和粪菌移植，以及定植与感染的区别。

## 基本术语 {#vocabulary}

::: definition 微生物群与微生物组 {#def-microbiota}
**微生物群**是生活在某一特定环境（如人体肠道）中的微生物群落。严格地说，**微生物组**是它们基因的总和，不过这两个词常被混用。

微生物群的成员按其与宿主的关系来描述：

- **共生菌**（共栖菌）生活在宿主身上而不造成伤害；
- **互利共生菌**在自身获益的同时也使宿主获益；
- **致病共生菌**通常无害，但在条件改变时（例如使用抗生素后或免疫功能受损时）可以致病。

同一种微生物可以扮演几种角色。大肠埃希菌（*Escherichia coli*）在结肠中是无害的共生菌，也是尿路感染最常见的病原体。
:::

::: definition 定植、感染与污染 {#def-colonisation}
**定植**是指微生物在身体某一部位存在并增殖，但没有组织侵袭，也没有引起疾病的宿主反应。

**感染**是指微生物侵入组织，伴有宿主反应，通常有疾病的症状或体征。

**污染**是指标本中存在的微生物是在采集或处理过程中带入的，并不存在于所采样的部位。

这一区分决定治疗。定植通常不需要抗生素，感染通常需要，而污染需要一份更好的标本。
:::

单凭一次阳性培养无法区分这三者。从鼻拭子中培养出金黄色葡萄球菌（*Staphylococcus aureus*），从腿部溃疡中培养出铜绿假单胞菌（*Pseudomonas aeruginosa*），从痰中培养出念珠菌属（*Candida*），从无症状老年女性的尿液中培养出大肠埃希菌，通常都是定植。结果的意义由临床表现决定。

## 微生物群栖居的部位 {#sites}

身体的每个部位都有其特有的湿度、氧气、营养和酸度条件，因而有其特有的群落。

| 部位 | 典型微生物 | 临床意义 |
|---|---|---|
| 皮肤 | 凝固酶阴性葡萄球菌、痤疮丙酸杆菌（*Cutibacterium acnes*）、棒状杆菌；潮湿部位有金黄色葡萄球菌 | 血培养污染菌以及导管和假体感染的来源 |
| 鼻腔 | 凝固酶阴性葡萄球菌、棒状杆菌；相当一部分人有金黄色葡萄球菌 | 鼻腔金黄色葡萄球菌携带者发生手术部位感染的风险较高 |
| 口腔 | 草绿色链球菌、多种厌氧菌 | 龋齿、牙周炎、心内膜炎、吸入性肺炎 |
| 上呼吸道 | 链球菌、嗜血杆菌属、奈瑟菌属；有时有肺炎链球菌和脑膜炎奈瑟菌 | 携带先于侵袭性疾病和向他人传播 |
| 胃 | 由于胃酸，微生物很少；许多人有幽门螺杆菌（*Helicobacter pylori*） | 胃酸减少使细菌过度生长，并降低肠道感染所需的剂量 |
| 结肠 | 非常密集，主要是拟杆菌属（*Bacteroides*）、粪杆菌属（*Faecalibacterium*）和其他厚壁菌门细菌等厌氧菌；大肠埃希菌和肠球菌数量较少 | 发酵、定植抵抗，腹腔和尿路感染的来源 |
| 阴道（育龄期） | 乳杆菌属（*Lactobacillus*）占优势 | 酸性pH防御病原体；乳杆菌减少导致细菌性阴道病 |

结肠中的菌群数量远远最多，每克内容物约有$10^{11}$个细菌。每个人体内有数百个菌种，而且不同人之间具体组成的差异，大于同一个人在不同时间的差异。

下呼吸道和膀胱等过去认为无菌的部位，含有少量可被测序检出的微生物。其意义仍有争议，在实践中，常规的尿培养或下呼吸道标本培养仍按该部位通常无菌来解释。

## 发育与功能 {#functions}

微生物群在出生时及出生后获得。经阴道分娩的婴儿最先被来自母亲阴道和肠道的微生物定植；剖宫产出生的婴儿起初获得更多的皮肤和环境微生物。母乳中含有婴儿不能消化的复杂糖类，但它们能滋养双歧杆菌属（*Bifidobacterium*），后者在母乳喂养婴儿的肠道中占优势。饮食、兄弟姐妹、宠物和抗生素在婴儿期塑造这个群落，到大约三岁时，它就与成人的相似了。在成人中，它相当稳定，但会对饮食、药物、疾病和年龄作出反应。

微生物群的功能分为三类。

- **代谢。**结肠细菌发酵人体酶无法消化的膳食纤维，产生乙酸、丙酸和丁酸等**短链脂肪酸**。丁酸是结肠上皮细胞的主要能量来源。细菌还合成维生素K2和某些B族维生素，并转化胆汁酸和药物。
- **免疫发育。**在完全没有微生物的条件下饲养的动物，即所谓无菌动物，其肠道淋巴组织发育不良，免疫应答异常。微生物产物帮助诱导调节性T细胞和IgA，使对共生菌的应答保持平衡。
- **定植抵抗**，这是临床微生物学中最重要的功能。

::: theorem 定植抵抗 {#thm-colonisation-resistance}
完整的微生物群保护宿主免受外来病原体的定植和感染。破坏微生物群（最常见的是抗生素）会去除这种保护，使病原体或耐药微生物得以立足。
:::

::: proof
几种机制共同起作用。

- **争夺营养和空间。**常驻细菌消耗新来者所需的糖、氨基酸和铁，并占据黏膜上的附着位点。
- **抑制性产物。**短链脂肪酸降低pH并抑制某些肠杆菌目细菌。许多细菌释放**细菌素**，即杀灭近缘细菌的蛋白质。
- **胆汁酸转化。**肝脏分泌**初级胆汁酸**。结肠细菌把它们转化为**次级胆汁酸**。某些初级胆汁酸促进艰难梭菌芽孢的出芽，而次级胆汁酸抑制其生长。
- **刺激宿主防御。**共生菌诱导肠壁分泌黏液、抗菌肽和IgA。

当抗生素杀死群落的大部分时，营养变得可用，次级胆汁酸减少而初级胆汁酸增加。此时到来的病原体，或已经少量存在的耐药菌，就能扩增。这解释了抗生素之后的艰难梭菌感染、住院治疗期间多重耐药肠杆菌目细菌在肠道的定植，以及一个抗生素疗程后的阴道念珠菌病。
:::

## 如何研究微生物群 {#methods}

大多数肠道细菌是难以在实验室培养的严格厌氧菌，因此单靠培养只能得到很不完整的图景。现代研究采用DNA测序。

- **16S rRNA基因测序**扩增所有细菌都有的一个基因的一部分，并把序列归类为不同的分类单元。它成本低廉，能显示存在哪些细菌及其比例，通常可到属的水平。
- **鸟枪法宏基因组测序**对样本中的全部DNA进行测序。它能鉴定菌种和菌株，并显示存在哪些基因，包括耐药基因和代谢通路。
- **代谢组学**测定短链脂肪酸和胆汁酸等化学产物，把组成与功能联系起来。

结果用**多样性**指标来概括。一个群落所含微生物的种类越多（丰富度），各类的数量越均衡（均匀度），多样性就越高。**香农指数**兼顾二者：

$$
H = -\sum_{i} p_i \ln p_i
$$ {#eq-shannon}

其中$p_i$是属于分类单元$i$的群落比例。对于$S$个丰度相等的分类单元，$H = \ln S$，为可能的最大值。

::: example 抗生素治疗前后的多样性 {#ex-shannon}
一个简化的肠道群落含有四个分类单元，比例分别为0.4、0.3、0.2和0.1。使用广谱抗生素一周后，只检出三个分类单元，比例分别为0.85、0.10和0.05。计算治疗前后的香农指数，保留两位小数。
::: solution
治疗前：

$$
H = -(0.4\ln 0.4 + 0.3\ln 0.3 + 0.2\ln 0.2 + 0.1\ln 0.1) \approx 1.28
$$

四个分类单元可能的最大值为$\ln 4 \approx 1.39$，因此这个群落相当均衡。

治疗后：

$$
H = -(0.85\ln 0.85 + 0.10\ln 0.10 + 0.05\ln 0.05) \approx 0.52
$$

多样性下降了一半以上。一个分类单元消失了，另一个现在占据主导。真实的群落有数百个分类单元，但模式相同：广谱抗生素同时降低丰富度和均匀度。恢复需要数周到数月，有些分类单元可能不再回来。
:::
:::

::: warning 相关不等于因果
从肥胖和糖尿病到抑郁症和孤独症，已有数百种疾病被发现与肠道微生物群的差异相关。这些发现大多是来自横断面研究的相关性。不同的微生物群可能是疾病的原因，也可能是疾病的结果，或者是伴随疾病的饮食、药物和生活方式的结果。例如，二甲双胍、质子泵抑制剂和抗生素都会改变微生物群。对于“微生物组的差异导致某种疾病”或“某种益生菌能治疗它”的说法，要像对待任何其他说法一样严格审视，并寻找以临床结局为终点的随机试验。
:::

## 抗生素与艰难梭菌 {#cdiff}

::: definition 艰难梭菌感染 {#def-cdiff}
艰难梭菌是一种形成芽孢的厌氧革兰阳性杆菌。**艰难梭菌感染**（CDI）是由产毒株引起的腹泻或结肠炎。其特点是：

- 通过芽孢**传播**，芽孢能在物体表面和手上长期存活，并能耐受乙醇；
- 当微生物群被破坏时，尤其是初级胆汁酸多、次级胆汁酸少时，芽孢在肠道内**出芽**；
- **毒素A和毒素B**使调控结肠细胞肌动蛋白细胞骨架的信号蛋白失活，细胞变圆、死亡，结肠发生炎症；
- 疾病谱从轻度腹泻到**假膜性结肠炎**、中毒性巨结肠、穿孔和死亡。

主要危险因素是近期使用抗生素、高龄、住院或入住养老院以及重病。克林霉素、头孢菌素类、氟喹诺酮类以及与β-内酰胺酶抑制剂合用的广谱青霉素风险最高。质子泵抑制剂与较高的风险相关。
:::

首次发作接受治疗的人中约有五分之一会**复发**，而且每发作一次，风险都会升高。复发是因为芽孢仍留在肠道内，而微生物群尚未恢复，因此导致首次发作的条件依然存在。

许多人，尤其是住院患者，携带艰难梭菌而没有症状。因此只对有腹泻且无其他明显原因的人进行检测，英国实验室采用两步法：先做一项灵敏的筛查试验，如谷氨酸脱氢酶（GDH）抗原或毒素基因PCR，再检测游离毒素。毒素检测阳性提示疾病；有细菌而未检出毒素提示带菌或毒素水平低，需结合临床表现解释结果。

::: example 使用抗生素后腹泻 {#ex-cdiff}
一名住在养老院的81岁女性因胸部感染接受了头孢菌素治疗。十天后，她每天出现六次水样腹泻，伴腹痛和发热。白细胞计数为$16 \times 10^9$/L，肌酐升高。粪便检测GDH阳性、毒素阳性。请解释其发病机制和处理原则。
::: solution
这是**艰难梭菌感染**。头孢菌素杀死了她结肠微生物群的大部分，去除了定植抵抗。从养老院环境中获得、或原本就少量存在的艰难梭菌芽孢，在改变了的胆汁酸环境中出芽并增殖。毒素A和毒素B损伤结肠上皮，引起腹泻、炎症、发热和白细胞升高。肌酐升高反映了液体丢失。

处理原则，遵循英国指南：

- 尽可能**停用或重新评估致病的抗生素**，并重新评估质子泵抑制剂和泻药等其他药物；
- 将她**隔离**在带独立卫生间的单人间，使用手套和围裙，用肥皂和水洗手，并用杀芽孢产品清洁；
- 根据白细胞计数、体温、肌酐和结肠炎体征**评估严重程度**，并监测液体；
- 给予**对艰难梭菌有效的口服抗生素**：截至2026年，NICE推荐首次发作口服万古霉素（vancomycin），非达霉素（fidaxomicin）作为替代，早期复发时用非达霉素；
- 如有危及生命的结肠炎征象，紧急请外科和专科会诊。

用另一种抗生素来治疗抗生素相关的感染，这种讽刺是真实存在的。之所以使用万古霉素和非达霉素，是因为它们留在肠道内并作用于艰难梭菌；非达霉素的抗菌谱更窄，对正常菌群的损害更小，这在一定程度上解释了它较低的复发率。
:::
:::

### 粪菌移植 {#fmt}

**粪菌移植**（FMT）是把经过筛查的健康供者的粪便，通过结肠镜、灌肠、鼻胃管或胶囊移入患者的肠道。其目的是恢复一个多样化的群落，并随之恢复定植抵抗和次级胆汁酸代谢。

粪菌移植是微生物群能防御感染的最清楚的临床证明。在2013年发表的一项随机试验中，范诺德（van Nood）及其同事发现，粪菌移植治愈复发性艰难梭菌感染的比例远高于单用万古霉素，试验因此提前终止。截至2026年，NICE建议对既往已有两次或更多次发作的复发性艰难梭菌感染成人考虑粪菌移植。

供者需经过仔细筛查，包括筛查多重耐药菌，因为经粪菌移植传播耐药菌曾引起严重感染。将其用于炎症性肠病或代谢性疾病等其他疾病仍属试验性质。

**益生菌**是为带来健康益处而给予的活微生物。用益生菌预防抗生素相关性腹泻和艰难梭菌感染的试验结果不一致，各种产品差异很大，它们也不是英国预防或治疗艰难梭菌感染的标准指南的组成部分。在重症和免疫功能低下者中，曾发生过由益生菌微生物引起的罕见血流感染。

## 当菌群引起感染时 {#endogenous}

住院患者的大多数细菌感染是**内源性**的：由患者自身的菌群到达无菌部位引起。

- 大肠埃希菌等肠道细菌沿尿道上行引起尿路感染，沿导尿管更容易上行。
- 皮肤细菌经静脉导管和手术伤口进入。鼻腔携带金黄色葡萄球菌的人发生由自身菌株引起的手术部位感染的风险较高，这就是为什么一些外科单位会筛查携带者，并在术前提供去定植。
- 肠穿孔或手术使厌氧菌和肠杆菌目细菌的混合物进入腹腔。
- 吸入肺内的口腔菌群引起吸入性肺炎和肺脓肿。

这就是感染预防如此关注器械和操作的原因：它们在定植部位与无菌部位之间开辟了通路。

::: example 无症状的尿培养阳性 {#ex-asb}
一名长期留置导尿管的78岁男性，常规送检了一份“用于筛查”的尿液标本，培养出大于$10^5$ CFU/mL的大肠埃希菌。他没有发热，没有新出现的意识模糊，也没有疼痛。应该治疗吗？
::: solution
不应该。几乎所有长期留置导尿管的人在数周内尿中都会有细菌，因为来自皮肤和肠道的微生物定植于导管并形成生物膜。这是**无症状菌尿**，属于定植的一种形式。治疗它并不能预防有症状的感染，反而会选择出耐药菌、扰乱肠道微生物群，并增加艰难梭菌感染的风险。

英国指南建议不要对无症状的导尿患者送检尿液标本，也不要治疗这一人群的无症状菌尿。尿试纸在导尿患者和老年人中也不可靠。如果他出现感染症状，如发热、寒战、腰痛或没有其他原因的新发谵妄，应从新插入的导尿管中采集标本，最好在更换旧导管之后，并按当地指南进行治疗。
:::
:::

::: example 有鱼腥味的阴道分泌物 {#ex-bv}
一名29岁女性有稀薄的灰白色阴道分泌物，伴鱼腥味，无瘙痒或疼痛。阴道pH为5.5。显微镜检查见上皮细胞表面覆盖着小细菌，乳杆菌很少。请解释其微生物学机制。
::: solution
这是**细菌性阴道病**，是阴道微生物群的改变，而不是被某一种新的微生物感染。正常情况下乳杆菌占优势，产生乳酸，使pH保持在约4.5或以下，并抑制其他微生物。在细菌性阴道病中，乳杆菌大部分被厌氧菌和加德纳菌属（*Gardnerella*）组成的混合群落取代。pH升高，细菌产生的胺类引起鱼腥味，加碱后尤为明显（“胺试验”）。

表面覆盖细菌的上皮细胞是**线索细胞**。诊断采用**阿姆塞尔标准**（以下四项中至少三项：稀薄均匀的分泌物、pH高于4.5、胺试验阳性和线索细胞）或**纽金特评分**等革兰染色评分。治疗遵循国家指南，复发很常见，因为微生物群往往会回到同样的状态。
:::
:::

::: quiz
使用一个疗程的克林霉素后，哪一种变化最直接地使艰难梭菌芽孢得以在结肠中出芽和生长？
- [ ] 共生菌产生的次级胆汁酸增加
- [x] 把初级胆汁酸转化为次级胆汁酸的共生菌丧失
- [ ] 短链脂肪酸产生增加
- [ ] 胃酸增加
::: solution
共生菌把**初级**胆汁酸（其中一些促进艰难梭菌芽孢出芽）转化为抑制其生长的**次级**胆汁酸。克林霉素杀死了许多这类共生菌，于是初级胆汁酸积累，次级胆汁酸减少。使用广谱抗生素后，短链脂肪酸的产生也是减少而不是增加。
:::
:::

::: history
1885年，特奥多尔·埃舍里希（Theodor Escherich）描述了婴儿粪便中的细菌，其中包括后来被命名为大肠埃希菌的细菌。20世纪初，埃利·梅契尼可夫（Élie Metchnikoff）提出，发酵乳中的乳酸菌可能通过取代有害的肠道微生物而促进健康，这是益生菌理念的早期版本。1958年，本·艾斯曼（Ben Eiseman）及其在丹佛的同事报告用粪便灌肠治疗假膜性结肠炎。

1935年，伊万·霍尔（Ivan Hall）和伊丽莎白·奥图尔（Elizabeth O'Toole）在健康新生儿的粪便中描述了艰难梭菌；它的名字反映了培养它有多么困难。直到20世纪70年代末，它才被确定为抗生素相关性假膜性结肠炎的病因。21世纪初，一种高毒力菌株在北美和英国引起大规模暴发，包括白金汉郡几家医院的死亡病例，这促成了强制性监测和英格兰抗生素处方的重大改变。人类微生物组计划于2007年启动，2012年发表了健康人体微生物群的参考目录，所用的是DNA测序而不是培养。
:::

## 后续内容

微生物群中各种微生物的结构和生长见[[microbiology/bacteria]]。如何选择抗生素以减少对微生物群的损害是[[microbiology/antimicrobials]]中抗菌药物管理的一部分，病房中艰难梭菌的控制见[[microbiology/infection-control]]。结肠炎本身以及其他与微生物群相关的肠道疾病见[[gastrointestinal/bowel-disease]]，使共生菌得以与我们共存的免疫耐受见[[immunology/tolerance-regulation]]。

::: summary
- 微生物群是生活在体表和体内的微生物群落；细菌细胞的数量与人体细胞大致相当，大部分在结肠。
- 定植是存在而无疾病，感染是伴有宿主反应的侵袭，污染是在采样时带入的。单凭阳性培养无法区分它们。
- 每个部位都有自己的菌群。乳杆菌使阴道pH保持在低水平；结肠厌氧菌把纤维发酵为短链脂肪酸，并把初级胆汁酸转化为次级胆汁酸。
- 定植抵抗通过竞争、抑制性产物、胆汁酸转化和刺激宿主防御来防御病原体。抗生素会去除它。
- 微生物群用16S测序、鸟枪法宏基因组测序和代谢组学研究；多样性用$H = -\sum p_i \ln p_i$等指数衡量。
- 艰难梭菌感染发生在抗生素破坏之后：芽孢出芽，毒素A和毒素B损伤结肠，复发常见。粪菌移植在复发性疾病中恢复定植抵抗。
- 大多数医院感染是内源性的；无症状菌尿，尤其是导尿患者的无症状菌尿，不应治疗。
:::

## 习题

::: exercise 定植还是感染？ {level=1}
将下列情况分别归为定植、感染或污染：(a) 一名健康男性术前鼻腔筛查拭子培养出MRSA；(b) 从一处发热、扩散的蜂窝织炎中培养出化脓性链球菌（*Streptococcus pyogenes*）；(c) 一名没有留置导管、患尿路感染的女性，四瓶血培养中有一瓶培养出凝固酶阴性葡萄球菌。
::: hint
问一问是否有伴宿主反应的组织侵袭，以及微生物可能如何进入标本。
:::
::: solution
(a) **定植**：MRSA携带于鼻腔而不致病。它仍然重要，因为它增加手术部位感染的风险，是去定植的理由。(b) **感染**：微生物正在侵袭组织并引起炎症。(c) 很可能是**污染**：一种皮肤微生物只出现在多瓶中的一瓶，患者没有器械，且有另一个明确的致病原因，最可能是在静脉穿刺时从皮肤带入的。
:::
:::

::: exercise 两个等量菌种的多样性 {level=1 check="0.69"}
一个群落含有比例相等的两个分类单元。计算其香农指数，保留两位小数。
::: hint
用[[#eq-shannon]]，$p_1 = p_2 = 0.5$。
:::
::: solution
$H = -(0.5\ln 0.5 + 0.5\ln 0.5) = -\ln 0.5 = \ln 2 \approx 0.69$。
:::
:::

::: exercise 酸性的阴道 {level=1}
解释乳杆菌如何防御阴道感染，以及雌激素为何重要。
::: hint
想一想乳杆菌产生什么，以及它们以什么为食。
:::
::: solution
乳杆菌把阴道上皮中的糖原发酵为**乳酸**，使pH保持在约4.5或以下。酸抑制许多病原体以及与细菌性阴道病相关的厌氧菌；有些菌株还产生其他抑制性物质。糖原的沉积依赖于**雌激素**，因此乳杆菌占优势是育龄期的特点。青春期前和绝经后，pH较高，菌群也更混杂。
:::
:::

::: exercise 三个分类单元的群落 {level=2 check="1.04"}
一个群落含有三个分类单元，比例分别为0.5、0.25和0.25。计算其香农指数，保留两位小数，并与三个分类单元可能的最大值比较。
::: hint
$\ln 0.25 = 2\ln 0.5$。
:::
::: solution
$H = -(0.5\ln 0.5 + 0.25\ln 0.25 + 0.25\ln 0.25) = 0.5\ln 2 + 0.5\ln 4 = 1.5\ln 2 \approx 1.04$。

三个分类单元的最大值为$\ln 3 \approx 1.10$，在三者相等时达到。这个群落略不均衡。
:::
:::

::: exercise 为什么有些抗生素风险更高 {level=2}
克林霉素和广谱头孢菌素类发生艰难梭菌感染的风险很高，而短疗程的呋喃妥因风险很小。请解释这一差别。
::: hint
每种药物在体内哪里达到高浓度？它杀灭哪些细菌？
:::
::: solution
克林霉素对肠道**厌氧菌**活性很强，而厌氧菌构成了结肠微生物群的大部分，其中包括许多产生次级胆汁酸的细菌。广谱头孢菌素类也能到达肠道并杀灭多种共生菌，而艰难梭菌本身对它们耐药。因此两者都去除了定植抵抗，使艰难梭菌得以自由生长。

呋喃妥因被吸收后浓集于**尿液**，在结肠中活性很低，且疗程短。它几乎不扰乱肠道微生物群，这是它成为单纯性膀胱炎一线药物的原因之一。
:::
:::

::: exercise 心脏手术前的鼻腔携带 {level=2}
一名准备做冠状动脉旁路移植术的66岁男性被发现鼻腔携带甲氧西林敏感金黄色葡萄球菌。请解释这为什么重要，以及可以采取哪些措施。
::: hint
金黄色葡萄球菌引起的手术部位感染大多来自哪里？
:::
::: solution
金黄色葡萄球菌引起的手术部位感染大多由患者**自身的菌株**引起，这些菌株携带于鼻腔和皮肤。因此携带者术后发生胸骨伤口感染和菌血症的风险较高。

许多单位在高危手术前提供**去定植**，通常是连续数天使用鼻腔抗菌软膏和抗菌沐浴液，遵循当地方案。其目的是减少手术时的细菌数量，而不是永久清除携带状态。外科抗生素预防也选择覆盖金黄色葡萄球菌的药物。过度使用去定植药物会选择出耐药性，这就是为什么相关方案只针对明确的高危人群。
:::
:::

::: exercise 解读艰难梭菌检测结果 {level=3}
一名55岁住院女性在开始肠内管饲后出现腹泻。两周前她用过抗生素。她的粪便检测GDH阳性、毒素阴性。应如何解释这一结果？接下来应怎么做？
::: hint
英国两步法检测的每一步各检测什么？
:::
::: solution
GDH检测的是**细菌**，不论其是否产毒；毒素检测的是粪便中的**游离毒素**。GDH阳性、毒素阴性意味着有艰难梭菌存在，但未检出游离毒素。她可能是**携带者**，腹泻另有原因，如肠内营养；也可能患有毒素水平低于检测下限的艰难梭菌感染。许多实验室会加做毒素基因PCR，以显示该菌株是否能产生毒素。

由临床评估作出决定。应排查管饲、泻药和其他药物等原因。由于她可能传播艰难梭菌，在腹泻期间应采取肠道隔离预防。如果临床表现强烈提示艰难梭菌感染，如发热、白细胞升高或影像学显示结肠炎，可在与微生物科讨论后根据临床判断开始治疗，遵循当地指南。
:::
:::

::: exercise 评价一项微生物组的说法 {level=3}
一项横断面研究发现，2型糖尿病患者的肠道微生物多样性低于非糖尿病者。一家报纸报道称“肠道细菌导致糖尿病”，并推荐一种益生菌。请指出对这一发现的三种其他解释，并描述一种能够检验因果关系的研究设计。
::: hint
想一想反向因果、药物和饮食造成的混杂，以及干预研究能显示什么。
:::
::: solution
其他解释：

- **反向因果**：糖尿病本身可能通过高血糖、肠道动力改变或胆汁酸变化而改变微生物群。
- **治疗造成的混杂**：大多数2型糖尿病患者服用的**二甲双胍**会显著改变肠道微生物群。他汀类、质子泵抑制剂和近期使用的抗生素也会。
- **饮食和生活方式造成的混杂**：低纤维饮食、肥胖和缺乏体力活动既与糖尿病相关，也与较低的多样性相关。

更好的证据来自在糖尿病发生之前测定微生物群并校正饮食和药物的**前瞻性队列研究**，来自无菌动物的**移植实验**，最重要的是来自以HbA1c等临床结局为终点、针对某种明确的微生物干预（如粪菌移植或某种特定益生菌）的**随机对照试验**。只有当这类试验显示有益时，才应推荐益生菌；报纸的说法远远超出了证据。
:::
