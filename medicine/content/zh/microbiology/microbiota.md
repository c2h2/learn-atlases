人类的菌群是你借来的一个器官：**大约约一百万亿个微生物、提供代谢的、屏障的与免疫的服务、而它的紊乱与“几乎多到可疑”的一批疾病相关——同时，针对它急性崩溃的那一种被证明的、可重复的、基于机制的治疗（粪的菌群移植），仍是这个领域最惊人的成功、也是它被吹得最过的承诺。**

本章涵盖常驻的菌群及其功能、“菌群失调”的观念、艰难梭菌的感染、基于菌群的疗法、以及饮食与益生菌及粪移植的证据基础。

## 那个常驻的器官

::: definition 正常的菌群及其功能 {#def-normal}
**生物地理（皮肤与口腔与肠道与阴道与肺、以及“胎盘是否有菌”之争的地图、密度沿肠道向远端递增、以及胃的酸的把关、与小肠“计数低而转运快”、以及结肠“已知的最密集的群落”——以厌氧菌为主的、兼性需氧的、分层的架构、黏膜黏附的群落对管腔的群落、以及“噬菌体组”在我们称为细菌生态的东西上叠加了一层病毒学——[[gastrointestinal/digestion-absorption]]）；服务把抗性的淀粉发酵成短链的脂肪酸——丁酸作为结肠细胞的燃料、以及丙酸与乙酸的全身效应——与维生素K及叶酸及B12的营养的邻近、以及“塑造药物代谢与艰难梭菌的萌发”的胆汁酸的转化、以及“经生态位的竞争与细菌素排斥病原体”的定植的抵抗、以及酸的屏障与黏液及“支持性的分泌型免疫球蛋白A的角色”——[[gastrointestinal/clinical-nutrition]]、分泌型免疫球蛋白A与调节性T细胞的诱导见[[immunology/tolerance-regulation]]、以及药物代谢的交叉（含依立替康与柳氮磺吡啶及地高辛的菌群的药理学见[[pharmacology/metabolism-excretion]]）；以及发育与免疫的伙伴分娩方式与抗生素及城市化及宠物及同胞及哺乳决定因素的那片文献、连同它在“效应的量级”上的诚实、以及在无菌小鼠中“分段丝状菌与梭菌厚的壁菌门教育调节性T细胞与Th17”的实验、以及卫生与多样性的假说、以及“菌群与小胶质细胞及肠脑轴”的临床前的兴奋对人类的证据的缺口——[[paediatrics/newborn]]、[[immunology/tolerance-regulation]]、[[physiology/integrative-physiology]]。**

## 艰难梭菌与菌群的治疗

::: definition 艰难梭菌的感染 {#def-cdiff}

## 通向何处

扰乱这个生态系统的药物在[[microbiology/antimicrobials]]；结肠炎的处理与外科的阈值在[[gastrointestinal/bowel-disease]]与[[surgery/acute-abdomen]]；黏膜的免疫在[[immunology/tolerance-regulation]]；实验室的算法在[[microbiology/laboratory-diagnosis]]；感染控制的职责在[[microbiology/infection-control]]。

::: history
**菌群被发现过两次、而在中间被遗忘了：1676年列文虎克在自己牙垢与湖水里观察到的“微小动物”、以及随后持续两个世纪的中断；粪的治疗在十九世纪的那条血脉中国的“黄龙汤”的粪悬液的传说、以及十七世纪意大利与奥地利“为食物中毒”的报告、以及1958年艾塞曼那一组“用健康供者的粪灌肠治疗的假膜性结肠炎”的病例系列、显示了惊人的改善——是现代时代的奠基报告、而且是在艰难梭菌被命名之前；抗生素时代的悖论——1930与1940年代对“广谱治疗之后的葡萄球菌与梭菌的肠炎”的认识、1970年代与克林霉素的关联、以及仓鼠模型中毒素的发现、以及A与B两种毒素的纯化、以及2000年代“二元毒素与027型”的分子流行病学的年代北美医院的流行、以及英国医院感染的激增、带着它们的国家报告与“杀芽孢的清洁”的教训——[[infectious-diseases/healthcare-infections]]、[[clinical-skills/patient-safety]]；测序的革命——多样性的“系统发育标签”的方法、以及2012年的人类微生物组规划参照的地图、以及宏基因组与代谢组学、以及公众科学的多样性推进份“代表性不足的人群”的数据库的偏倚是一则关于数据公平的警示、以及“16S对鸟枪法对培养组学”的方法之争——[[microbiology/laboratory-diagnosis]]；移植的转折——2013年那两项并行的试验证明“粪的输注胜过万古霉素治疗复发的艰难梭菌”、以及粪库的创立、以及2019到2022年活的生物治疗制品的批准“粪便的药物化”：纯化的厌氧菌与基于芽孢的联合菌群、以及广泛的供者筛查的标准、以及艰难梭菌之外的适应证的扩张与它的治理的争论。**
:::

::: summary
- 菌群是一个代谢的与免疫的器官；抗生素是它最常见的外界的打击、而生态的代价可以在数周到数年内被测量。
- 菌群失调的关联要分级：艰难梭菌与炎症性肠病及肝性脑病有治疗的证据；而大多数关于脑、免疫与代谢的主张仍是关联性的。
- 艰难梭菌按“复发的连续过程”来处理——严重度的分期、非达霉素或万古霉素的策略、抗毒素B的单克隆抗体、以及在复发序列的早期就恢复菌群。
- 绝不为“治愈”做检测、绝不治疗无症状的携带、并把“粪便阴性的肠麻痹”当重症治疗；止泻药会加重结肠炎。
- 粪的菌群移植证明了“恢复一个生态系统能治好一种疾病”这个原理；它同时也是一则“未受监管的交付与感染的传播”的警示故事。
- 益生菌是“按菌株的药”、不是保健食品：在很窄的生态位里被证明、在脆弱的患者身上可能有害、而且永远不如它所对标的抗菌药物管理。
:::

::: solution
**对菌群友好的处方（[[#def-dysbiosis]]、[[microbiology/antimicrobials]]、[[infectious-diseases/stewardship-outbreaks]]）：复发艰难梭菌者的尿路感染——最短的有效疗程、避开氟喹诺酮与克林霉素与广谱头孢当呋喃妥因或甲氧苄啶或匹美西林或磷霉素符合敏感性与部位时、并在病历里写下“未来的感染”的备注、并在处方系统里加一个“艰难梭菌的风险”的警示标志——[[renal/urinary-tract]]、[[gastrointestinal/bowel-disease]]；牙的脓肿——针对性的青霉素V、或短疗程的阿莫西林而不是7到10天、以及在有艰难梭菌病史的患者中避开克林霉素、以及局部与镇痛及转诊牙科的路径“不引流的话抗生素治不好一个脓肿”这一课对微生物组同样适用——[[anatomy/head-neck]]；哮喘儿童的轻型肺炎——阿莫西林为先、学龄期的非典型用多西环素、以及“大环内酯与哮喘的邻近”要诚实、以及“多数是病毒性的、发热的曲线指导复查”、以及带复查日期的“有限期的处方”、以及“用哮喘的行动计划、而不是为喘息与发热开抗生素”——[[respiratory/respiratory-infections]]、[[respiratory/asthma-copd]]；以及一般的规则——“把第一剂与疗程的决定做好”胜过任何益生菌的救援、以及避开“抗生素之后的卫生”的神话一小时一杯活菌酸奶的戏、以及“未来的任何一次疗程都会再次提高艰难梭菌的风险”这一框架——它比传单更能改变家庭的行为——[[public-health/prevention-promotion]]。**

::: exercise 评价一篇微生物组的论文 {level=3}
“来自瘦供者的粪便改善了肥胖者的胰岛素敏感性：一项随机试验”——而它的新闻稿承诺“很快就有减肥的药丸”。请评价并沟通。
::: solution
**微生物组论文的评价（[[#def-dysbiosis]]、[[epidemiology-ebm/critical-appraisal]]、[[public-health/prevention-promotion]]）：对设计的质询——小样本的交叉或平行设计、以“高胰岛素-正葡萄糖钳夹或稳态模型”为终点把一个替代的终点外推到体重与糖尿病、以及“供者的异质性就是干预的变异”多位供者对超级供者这一问题——“对最好的那位供者的反应”是这个领域那道不体面的未解之问、以及“抗生素的预处理与饮食的标准化与盲法的现实”气味与盲法的问题——[[epidemiology-ebm/randomised-trials]]；因果的推理——无菌动物的转移实验真正的强处、以及它们转化的限度、以及人类的移植试验“其中菌群效应是一种治疗、不是机制的证明”、以及菌群与饮食的相互作用脱离了饮食、这个表型还能被转移吗、以及“中介的分析”及其相关性的地位；以及沟通的伦理——“一个生态系统的药丸”这个框架对研究实际的发现用平实的语言说清效应的量级与持久、以及“炒作的循环”的伤害——从放弃有证据治疗的患者、到资助的摇摆、以及“批评新闻稿”这个教学的瞬间论文自己讨论部分的诚实、对标题、以及“把重复验证解释为正常的科学、而不是丑闻”、以及给你自己患者临床的底线——生活方式的证据仍是一线、而微生物组正是“让我们对简单的解释保持谦逊”的理由——[[gastrointestinal/clinical-nutrition]]、[[clinical-skills/communication]]。**
