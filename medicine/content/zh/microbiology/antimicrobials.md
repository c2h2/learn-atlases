抗微生物药物是医学中最有效的治疗手段之一，也是最常被滥用的药物之一。对脑膜炎球菌脓毒症及时给予抗生素能挽救生命；同一种药物用于病毒性感冒，对患者毫无益处，反而可能造成伤害，并选择出会影响他人的耐药菌。因此，合理处方需要两方面的知识：药物如何起作用，以及耐药如何产生。

本章的原则是当地抗生素指南中各种选择背后的理由。它们解释了为什么一种药物对某种感染是一线用药、对另一种感染却毫无用处，为什么有些药物每天给药一次而另一些要持续输注，以及为什么处方应在两三天后复核。

本章介绍抗微生物作用的原则，按靶点分组的主要抗菌药物类别，抗病毒、抗真菌和抗寄生虫药物，药效学，耐药的机制和传播，以及抗菌药物管理。本章不给出剂量和给药方案：它们来自《英国国家处方集》（BNF）和当地针对每位患者的指南。

## 原则 {#principles}

抗微生物药物对微生物的伤害必须大于对宿主的伤害。这种**选择性毒性**取决于微生物有而宿主没有的靶点，或者在二者之间差异足够大的靶点。细菌肽聚糖在人体中没有对应物，所以青霉素类非常安全；真菌和人体细胞都是真核细胞，所以抗真菌药往往毒性更大。

有几个术语描述药物的作用以及作用于哪些微生物。

- **抗菌谱**是药物作用的微生物范围。**窄谱**药物，如氟氯西林（flucloxacillin），作用于有限的一组细菌；**广谱**药物，如美罗培南（meropenem），作用于许多革兰阳性菌、革兰阴性菌和厌氧菌。
- **杀菌**药物杀死细菌；**抑菌**药物阻止细菌生长，依靠宿主防御来清除它们。这一区分在宿主防御薄弱时最为重要，如心内膜炎、脑膜炎和中性粒细胞减少，此时首选杀菌药物。
- **经验性**治疗在病原体明确之前开始，依据该综合征的可能病因和当地耐药情况。**目标性**治疗在有了培养和药敏结果之后选择，通常应更窄谱。

## 按靶点分类的抗菌药物 {#targets}

::: definition 作用于细胞壁和细胞膜的药物 {#def-cellwall}
**β-内酰胺类**结合并灭活**青霉素结合蛋白**（PBP），即交联肽聚糖的酶。细胞壁被削弱而破裂，生长中的细菌溶解。这一类包括：

- **青霉素类**：青霉素G（benzylpenicillin）、阿莫西林（amoxicillin）、氟氯西林（对葡萄球菌β-内酰胺酶稳定）和哌拉西林（piperacillin）；
- **头孢菌素类**，其抗革兰阴性菌活性一般从早期到后期各代逐渐增强；除头孢洛林（ceftaroline）和头孢吡普（ceftobiprole）对MRSA有效外，没有一种对肠球菌、李斯特菌或MRSA有活性；
- **碳青霉烯类**，如美罗培南，是这一类中抗菌谱最广的；
- **单环β-内酰胺类**（氨曲南（aztreonam）），只对革兰阴性菌有活性。

**β-内酰胺酶抑制剂**，如克拉维酸（clavulanic acid）、他唑巴坦（tazobactam）和阿维巴坦（avibactam），与β-内酰胺类联用，保护后者免受某些β-内酰胺酶的破坏。

**糖肽类**（万古霉素（vancomycin）和替考拉宁（teicoplanin））结合肽聚糖构建单元的末端，阻止其掺入。它们是不能穿过革兰阴性菌外膜的大分子，因此只作用于包括MRSA在内的革兰阳性菌。

作用于细胞膜的药物有**达托霉素**（daptomycin），它使革兰阳性菌的细胞膜去极化；以及**多黏菌素类**（黏菌素（colistin）），它破坏革兰阴性菌的外膜，是对付高度耐药革兰阴性菌的最后手段。
:::

β-内酰胺类的主要不良反应是**超敏反应**，从轻度皮疹到严重过敏反应不等。青霉素类还可引起艰难梭菌（*Clostridioides difficile*）感染，在大剂量或肾衰竭时可引起癫痫发作。万古霉素有肾毒性，因此要监测其血药浓度。

::: definition 作用于蛋白质合成和核酸的药物 {#def-proteinsynthesis}
细菌的**70S核糖体**与人体的80S核糖体不同，这使选择性抑制成为可能。

- **30S亚基**：**氨基糖苷类**（庆大霉素（gentamicin）、阿米卡星（amikacin）），对革兰阴性杆菌有杀菌作用；**四环素类**（多西环素（doxycycline）），抑菌、广谱，包括胞内菌。
- **50S亚基**：**大环内酯类**（克拉霉素（clarithromycin）、阿奇霉素（azithromycin））、**林可酰胺类**（克林霉素（clindamycin））、**噁唑烷酮类**（利奈唑胺（linezolid））和氯霉素（chloramphenicol）。大环内酯类和四环素类对支原体、衣原体和军团菌有活性。

作用于**核酸**和**叶酸**的药物：

- **氟喹诺酮类**（环丙沙星（ciprofloxacin）、左氧氟沙星（levofloxacin））抑制DNA旋转酶和拓扑异构酶Ⅳ；
- **利福霉素类**（利福平（rifampicin））抑制细菌RNA聚合酶；它们是结核病治疗的核心，由于耐药会迅速出现，从不单独使用；
- **硝基咪唑类**（甲硝唑（metronidazole））在厌氧菌内被激活，损伤DNA；
- **甲氧苄啶**（trimethoprim）和**磺胺类**阻断细菌叶酸合成的相继步骤，二者联用即复方磺胺甲噁唑；
- **呋喃妥因**（nitrofurantoin）浓集于尿液，损伤细菌DNA和蛋白质，因此只用于下尿路感染。
:::

每类药物都有处方者必须了解的特征性不良反应和相互作用：

| 类别 | 主要不良反应和相互作用 |
|---|---|
| 氨基糖苷类 | 肾损伤、听力和平衡功能丧失；需监测血药浓度 |
| 大环内酯类 | QT间期延长；克拉霉素和红霉素抑制CYP3A4，升高某些他汀类及其他药物的浓度 |
| 氟喹诺酮类 | 肌腱断裂、主动脉瘤、中枢神经系统反应、QT间期延长；英国药品和保健品管理局（MHRA）的建议限制了其使用 |
| 四环素类 | 在儿童和孕期引起牙齿变色和骨骼影响；光敏反应 |
| 克林霉素 | 艰难梭菌感染的风险高 |
| 利奈唑胺 | 长期使用引起骨髓抑制和神经损伤；与某些抗抑郁药合用引起5-羟色胺综合征 |
| 利福平 | 强效酶诱导剂，降低许多药物的浓度，包括激素类避孕药和抗凝药；体液呈橙色 |
| 甲氧苄啶 | 血钾升高；拮抗叶酸，孕早期避免使用 |
| 甲硝唑 | 金属味，长疗程引起周围神经病变；建议避免饮酒 |

### 针对病毒、真菌和寄生虫的药物 {#other-agents}

::: definition 抗病毒药、抗真菌药和抗寄生虫药 {#def-otheragents}
**抗病毒药**作用于使用病毒蛋白的复制步骤：

- **核苷类似物**，如阿昔洛韦（aciclovir），由单纯疱疹病毒和水痘-带状疱疹病毒的胸苷激酶激活，然后阻断病毒DNA聚合酶；更昔洛韦（ganciclovir）以类似方式作用于巨细胞病毒；
- **神经氨酸酶抑制剂**（奥司他韦（oseltamivir）、扎那米韦（zanamivir）），阻止流感病毒体的释放；
- 用于HIV的**抗逆转录病毒药物**，分属几类：核苷类和非核苷类逆转录酶抑制剂、整合酶抑制剂、蛋白酶抑制剂和进入抑制剂，总是联合使用；
- 用于丙型肝炎的**直接抗病毒药物**，阻断病毒蛋白酶和聚合酶，能治愈大多数感染；
- **核苷和核苷酸类似物**，如替诺福韦（tenofovir）和恩替卡韦（entecavir），能抑制乙型肝炎病毒，但很少能治愈。

**抗真菌药**作用于真菌的细胞膜和细胞壁：**唑类**抑制麦角固醇合成，并通过细胞色素P450与许多药物相互作用；**多烯类**（两性霉素B（amphotericin B））结合麦角固醇，有肾毒性；**棘白菌素类**阻断β-葡聚糖合成；**氟胞嘧啶**（flucytosine）干扰核酸合成，与两性霉素联用治疗隐球菌脑膜炎。

**抗寄生虫药**包括青蒿素衍生物和其他抗疟药，用于肝内休眠子的伯氨喹（primaquine）和他非诺喹（tafenoquine），用于多种原虫的甲硝唑，用于类圆线虫和其他一些线虫的伊维菌素（ivermectin），用于多种蠕虫的阿苯达唑（albendazole），以及用于血吸虫和绦虫的吡喹酮（praziquantel）。
:::

## 药效学 {#pkpd}

**药代动力学**描述机体对药物做了什么：吸收、分布、代谢和排泄。**药效学**描述药物对微生物做了什么。对于抗微生物药物，二者之间的联系是药物浓度随时间的变化与微生物MIC之间的关系。

::: theorem 三种杀菌模式 {#thm-pkpd}
抗菌药物的杀菌活性与以下三种指标之一相关性最好，每种指标都把游离（未结合）药物浓度与MIC联系起来：

- **时间依赖性**杀菌，以游离浓度高于MIC的时间占给药间隔的百分比$f T_{>\text{MIC}}$衡量。适用于**β-内酰胺类**。
- **浓度依赖性**杀菌，以峰浓度与MIC之比$C_{\max}/\text{MIC}$衡量。适用于**氨基糖苷类**。
- **暴露依赖性**杀菌，以24小时浓度—时间曲线下面积与MIC之比$\text{AUC}_{24}/\text{MIC}$衡量。适用于**氟喹诺酮类**和**万古霉素**。
:::

::: proof
β-内酰胺类的杀菌速率在浓度达到MIC的几倍之后变化不大。进一步提高峰浓度增益甚微；重要的是细菌暴露的时间有多长。当浓度降到MIC以下时，存活的细菌几乎立即恢复生长。因此，增加给药频次、延长输注或持续输注能提高其疗效，尤其是对敏感性较低的微生物。$f T_{>\text{MIC}}$的大致目标是给药间隔的40%～70%，取决于β-内酰胺类的亚类。

氨基糖苷类在浓度越高时杀菌越快，而且在浓度降到MIC以下后其作用仍持续数小时：即**抗生素后效应**。每天一次大剂量给药可达到高峰浓度，而较长的无药期使浓度降得足够低，从而减少肾脏和内耳细胞对药物的摄取。这是每日一次氨基糖苷类给药并监测血药浓度的基础。

对于万古霉素和氟喹诺酮类，一天内的总暴露量能预测疗效，对万古霉素来说还能预测毒性，因此根据血药浓度把剂量调整到目标AUC。
:::

对于以一级动力学消除的药物，单次静脉给药后浓度呈指数下降：

$$
C(t) = C_0 \cdot 2^{-t/t_{1/2}}
$$ {#eq-decay}

浓度保持在MIC以上的时间，可以由从$C_0$降到MIC所需的半衰期数$\log_2(C_0/\text{MIC})$求得。

::: widget plot

caption: 单次静脉给予一种β-内酰胺类药物后的简化浓度—时间曲线，起始浓度32 mg/L，示意性半衰期为$h$小时，某微生物的MIC为$m$。曲线保持在MIC线以上的时间即$T_{>\text{MIC}}$。半衰期越短或MIC越高，这段时间就越短，这就是为什么对敏感性较低的微生物采用更频繁的给药或更长时间的输注，而不是更大的单次剂量。这些数值仅作示意，不描述任何具体药物或患者。
:::

::: example 药物在MIC以上的时间有多长？ {#ex-pkpd}
在一个示意性模型中，某β-内酰胺类药物静脉推注后游离峰浓度为32 mg/L，半衰期为1小时，每8小时给药一次。微生物的MIC为2 mg/L。$f T_{>\text{MIC}}$是多少？如果它太低，可以怎么做？
::: solution
从32降到2 mg/L所需的半衰期数为

$$
\log_2\!\left(\frac{32}{2}\right) = \log_2 16 = 4
$$

半衰期为1小时，所以浓度在MIC以上维持4小时。给药间隔为8小时，因此$f T_{>\text{MIC}} = 4/8 = 50\%$。

如果这类药物的目标更高，把同样的日总量分成更频繁的较小剂量，或采用**延长输注或持续输注**，能使浓度更长时间保持在MIC以上。把单次剂量加倍只能在MIC以上多维持一个半衰期，即1小时。这就是为什么在重症监护中，对于铜绿假单胞菌（*Pseudomonas aeruginosa*）等敏感性较低的微生物，采用哌拉西林—他唑巴坦或美罗培南的延长输注。实际给药取决于患者的肾功能和病情，并遵循当地指南。
:::
:::

## 耐药性 {#resistance}

::: definition 耐药机制 {#def-resistance}
**天然耐药**是整个菌种的属性。例如：革兰阴性菌与糖肽类（外膜将其排除在外），肠球菌与头孢菌素类，支原体与β-内酰胺类（没有细胞壁），以及厌氧菌与氨基糖苷类（摄取需要依赖氧的转运）。

**获得性耐药**出现在原本敏感的菌株中，由突变或获得基因引起。主要有四种机制：

1. 药物的**酶促灭活**，如β-内酰胺酶和氨基糖苷修饰酶；
2. **靶点改变**，如新的青霉素结合蛋白或突变的DNA旋转酶；
3. **摄入减少**，由外膜孔蛋白缺失引起；
4. **主动外排**，由把药物泵出的膜泵完成。

几种机制常常同时存在，一个质粒可以携带对几类药物的耐药基因。
:::

重要的耐药菌体现了每一种机制。

- **MRSA**携带*mecA*基因，编码**PBP2a**，这是一种与几乎所有β-内酰胺类亲和力都很低的青霉素结合蛋白。因此MRSA对氟氯西林和大多数其他β-内酰胺类耐药，需根据感染部位和药敏结果用糖肽类、利奈唑胺、达托霉素或其他药物治疗。
- **耐万古霉素肠球菌**（VRE）携带的基因，最常见的是*vanA*，改变了肽聚糖前体的末端，使万古霉素难以结合。
- **超广谱β-内酰胺酶**（ESBL）常见于大肠埃希菌（*E. coli*）和克雷伯菌属（*Klebsiella*），能水解青霉素类和头孢菌素类，包括第三代头孢菌素。碳青霉烯类仍然有效。
- **AmpC β-内酰胺酶**由阴沟肠杆菌（*Enterobacter cloacae*）等细菌的染色体编码，在使用某些头孢菌素治疗期间可被诱导表达，因此耐药可能在治疗过程中出现。
- **碳青霉烯酶**水解碳青霉烯类和大多数其他β-内酰胺类。主要家族有**KPC**、**OXA-48样**以及金属β-内酰胺酶**NDM**、**VIM**和**IMP**。它们主要见于肠杆菌目细菌、假单胞菌和不动杆菌，通常由质粒携带。头孢他啶—阿维巴坦等新的复方制剂对其中一些酶有效，但对金属β-内酰胺酶无效，因此实验室要鉴定酶的家族以指导治疗。
- **氟喹诺酮耐药**由DNA旋转酶和拓扑异构酶基因的突变引起，常与外排相结合。
- **耐药结核病**由染色体突变引起，如利福平耐药的*rpoB*突变，异烟肼耐药的*katG*或*inhA*突变。对二者均耐药即为**耐多药结核病**（MDR-TB）。

耐药通过两种方式传播。**克隆传播**是成功的耐药菌株在人与人之间传播，经手、器械以及在社区中传播。**水平基因转移**在菌株和菌种之间转移耐药基因，主要通过质粒，如[[microbiology/bacteria]]所述。抗生素的使用推动了这两种方式，因为每个疗程都会在感染部位以及患者自身的微生物群中选择出耐药菌。动物中的抗生素使用和环境中的耐药基因是同一系统的组成部分，这就是为什么耐药被称为一个**“同一健康”**问题。

::: example 解读一株耐药尿液分离株 {#ex-esbl}
一名67岁女性有膀胱炎症状，但无发热或腰痛。尿培养出的大肠埃希菌报告为“产ESBL”，对阿莫西林、阿莫西林—克拉维酸、头孢氨苄、甲氧苄啶和环丙沙星耐药，对呋喃妥因、磷霉素、匹美西林和美罗培南敏感。她的eGFR为70 mL/min/1.73 m²。哪些选择是合理的？为什么应避免使用美罗培南？
::: solution
该细菌产生**ESBL**，能破坏青霉素类和头孢菌素类，而且它还获得了对甲氧苄啶和环丙沙星的耐药，产ESBL菌株常常如此。她患的是下尿路感染，没有上尿路或全身感染的征象。

合理的口服选择，按当地指南，包括**呋喃妥因**（浓集于尿液，适合她的肾功能）、**匹美西林**（pivmecillinam）和**磷霉素**（fosfomycin）。它们在膀胱中达到高浓度，对身体其他部位的菌群影响很小。

美罗培南有效，但应避免使用。它需静脉给药，抗菌谱广，是治疗严重耐药革兰阴性菌感染最后几种可靠的药物之一。把它用于膀胱炎会使她承受不必要的风险，并选择出碳青霉烯耐药，从而使她和其他人失去这一选择。ESBL标记对她以后的诊疗也很重要：如果她发生源于尿路的脓毒症，经验性方案应覆盖产ESBL细菌。
:::
:::

::: warning 没有感染就不要治疗阳性培养结果
阳性培养表明存在某种微生物，而不是说明需要治疗。治疗定植、污染或无症状菌尿没有益处，只会增加危害：不良反应、艰难梭菌感染，以及在患者菌群中选择出耐药菌。典型的例子是无泌尿系症状的老年人尿培养阳性。英国指南建议，除孕期和破坏黏膜的泌尿外科操作之前外，不要治疗无症状菌尿。始终要问：这一结果是否符合临床感染？
:::

::: example 髋关节手术前尿培养阳性 {#ex-asb}
一名准备做择期髋关节置换术的74岁男性，常规尿液标本培养出大于$10^5$ CFU/mL的大肠埃希菌。他没有泌尿系症状，也没有发热。外科团队询问是否应推迟手术先用一个疗程的抗生素。
::: solution
这是**无症状菌尿**。在关节置换手术中，术前治疗无症状菌尿并未被证明能减少人工关节感染，而且日后关节感染的病原体通常与尿中的不同。治疗会使他承受抗生素的副作用，并在术前选择出耐药菌。除非当地指南另有规定，手术可以照常进行，不必治疗菌尿，并采用常规的外科抗生素预防。

正因为如此，不提倡对无症状者常规做尿培养：它产生的结果诱使人进行没有益处的治疗。
:::
:::

## 抗菌药物管理 {#stewardship}

::: definition 抗微生物药物管理 {#def-stewardship}
**抗微生物药物管理**是一套协调一致的措施，旨在促进抗微生物药物的合理使用，以改善患者结局，同时减少不良反应和耐药。

在英格兰的医院中，其框架是**“明智开始，然后聚焦”**（Start Smart then Focus），由现在的英国卫生安全局发布，最近一次更新在2023年：

- **明智开始**：没有细菌感染的临床证据时不开始使用抗生素；尽可能在开始前留取培养；在危及生命的感染中及时开始有效治疗，对有高危特征的疑似脓毒症要在一小时内开始；遵循当地指南；记录过敏状态、适应证、药物、给药途径以及复核或停药日期。
- **然后聚焦**：在**48～72小时**结合培养结果复核诊断和处方，并作出明确的决定：**停用**，从静脉**转为**口服，**更换**为更窄谱或在必要时更广谱的药物，**继续**并设定新的复核日期，或转为**门诊肠外抗微生物治疗**。

在国际上，世界卫生组织的**AWaRe**分类把抗生素分为**可及类**（常见感染的一线和二线药物，耐药潜力较低）、**慎用类**（耐药潜力较高，需监测）和**限用类**（用于多重耐药感染的最后手段药物）。2024年联合国的一项政治宣言设定目标：到2030年，全世界人用抗生素中至少70%应为可及类抗生素。
:::

抗菌药物管理的其他部分同样实用。对许多常见感染，短疗程与长疗程同样有效，NICE指南现在建议许多社区获得性肺炎病例用五天，女性单纯性膀胱炎用三天。一旦患者好转并能吸收口服药物，就从静脉治疗转为口服，可以缩短住院时间并避免导管感染。监测血药浓度可以防止毒性。

**青霉素过敏标签**值得特别一提。大约十分之一的住院患者带有这种标签，但在经过正式评估的人中，约90%可以安全使用青霉素。许多标签记录的是恶心等副作用，或童年病毒感染期间出现的皮疹。标签导致使用更广谱或疗效较差的药物，导致更多的艰难梭菌感染和更多的耐药菌感染。仔细采集过敏史，并在适当时通过检测或监督下激发试验**去除标签**，是抗菌药物管理的一部分。

::: example 葡萄球菌菌血症中的青霉素过敏标签 {#ex-sab-allergy}
一名61岁的非洲黑人男性因膝关节化脓性关节炎发生金黄色葡萄球菌（*Staphylococcus aureus*）菌血症。该菌为甲氧西林敏感金黄色葡萄球菌（MSSA）。他的病历中写着“青霉素过敏”，已开始使用万古霉素。为什么这个标签很重要？应该怎么做？
::: solution
对于MSSA菌血症，抗葡萄球菌的**β-内酰胺类**，如氟氯西林或头孢唑林（cefazolin），比万古霉素更有效。观察性研究显示，在MSSA菌血症中使用万古霉素与较高的治疗失败率和死亡率相关。因此，这个标签不是一个小细节：它可能正把他引向对一种严重感染疗效较差的治疗。

第一步是仔细采集**过敏史**：发生了什么，什么时候，用药后多久出现，如何处理的，以及此后是否用过任何青霉素类或头孢菌素类。如果反应是腹泻等副作用，或是很久以前的轻度皮疹，许多医院有直接口服激发或使用交叉反应性低的头孢菌素的方案。有严重过敏反应或严重皮肤反应史者，在使用任何β-内酰胺类之前都需要过敏专科意见。

决策应有感染科和过敏科参与，并遵循当地方案。如果证实标签有误，应从所有记录中删除，并向患者解释，以免错误重复发生。
:::
:::

::: quiz
一名30岁女性因肾盂肾炎入院，开始静脉使用抗生素。第3天，她已退热，能进食饮水，尿培养出对几种口服药物敏感的大肠埃希菌。最恰当的抗菌药物管理措施是什么？
- [ ] 继续静脉使用抗生素14天
- [ ] 加用第二种静脉抗生素以覆盖耐药
- [x] 根据药敏结果改用一种口服抗生素，并确定总疗程
- [ ] 因为已退热，停用所有抗生素
::: solution
这是48～72小时的**“然后聚焦”**复核。她正在好转，能口服药物，药敏结果允许作出有针对性的选择。改用一种合适的口服药物，并按当地指南设定停药日期，既能有效完成治疗，又能避免继续静脉治疗的风险。完全停药会使肾盂肾炎治疗不足。
:::
:::

::: history
1910年，保罗·埃尔利希（Paul Ehrlich）推出了用于梅毒的胂凡纳明（洒尔佛散），这是系统寻找一种能杀灭微生物而不伤害宿主的“魔弹”的成果。1935年，格哈德·多马克（Gerhard Domagk）报告染料百浪多息能治愈小鼠的链球菌感染，磺胺类成为第一批被广泛使用的抗菌药物。亚历山大·弗莱明（Alexander Fleming）于1928年发现了青霉素，霍华德·弗洛里（Howard Florey）、恩斯特·钱恩（Ernst Chain）及其牛津同事在1940—1941年使之成为药物。弗莱明在1945年的诺贝尔演讲中警告说，剂量不足会使细菌产生耐药。

每一类新药之后都出现了耐药。到20世纪40年代末，产青霉素酶的葡萄球菌在医院中已很常见。甲氧西林于1959年问世，1961年英国报告了MRSA。1988年报告了耐万古霉素肠球菌，2009年报告了NDM-1碳青霉烯酶。2015年，在中国发现了质粒携带的黏菌素耐药基因*mcr-1*。2016年由吉姆·奥尼尔（Jim O'Neill）主持的英国政府抗微生物药物耐药性评估报告，使这一问题受到广泛的政治关注。
:::

## 后续内容

抗生素所作用的细菌结构见[[microbiology/bacteria]]，报告敏感性的实验室检查，包括MIC和折点，见[[microbiology/laboratory-diagnosis]]。药物作用、药代动力学和不良反应的一般原则见[[pharmacology/dosing-principles]]和[[pharmacology/adverse-reactions]]。临床抗菌药物管理项目和暴发控制见[[infectious-diseases/stewardship-outbreaks]]，结核病和HIV的治疗见[[infectious-diseases/tuberculosis]]和[[infectious-diseases/hiv]]。

::: summary
- 选择性毒性取决于微生物有而宿主没有的靶点：肽聚糖、70S核糖体、细菌酶、病毒聚合酶和蛋白酶、真菌麦角固醇。
- β-内酰胺类和糖肽类作用于细胞壁；氨基糖苷类、四环素类、大环内酯类、克林霉素和利奈唑胺作用于核糖体；氟喹诺酮类、利福平、甲硝唑和叶酸拮抗剂作用于核酸合成。
- β-内酰胺类表现为时间依赖性杀菌（$fT_{>\text{MIC}}$），氨基糖苷类为浓度依赖性杀菌（$C_{\max}/\text{MIC}$），万古霉素和氟喹诺酮类为暴露依赖性杀菌（$\text{AUC}/\text{MIC}$）。给药方式由此而来。
- 耐药分为天然耐药和获得性耐药，通过灭活酶、靶点改变、摄入减少和外排实现。MRSA（PBP2a）、VRE（*vanA*）、ESBL和碳青霉烯酶（KPC、OXA-48、NDM、VIM、IMP）是关键例子。
- 耐药通过克隆和质粒传播，每个抗生素疗程都会在患者自身的菌群中选择出耐药菌。
- 抗菌药物管理意味着明智开始，在48～72小时复核，以最短的有效疗程使用最窄谱的有效药物，尽早转为口服，并纠正错误的青霉素过敏标签。
:::

::: exercise 把药物与其靶点配对 {level=1}
说出每种药物的靶点：(a) 庆大霉素，(b) 环丙沙星，(c) 万古霉素，(d) 克拉霉素，(e) 甲氧苄啶。
::: hint
细胞壁、核糖体（哪个亚基？）、DNA复制还是叶酸合成。

(a) 30S核糖体亚基。(b) DNA旋转酶和拓扑异构酶Ⅳ。(c) 肽聚糖前体末端的D-丙氨酰-D-丙氨酸，阻断细胞壁合成。(d) 50S核糖体亚基。(e) 细菌叶酸途径中的二氢叶酸还原酶。

::: exercise 高于MIC的时间 {level=1 check="75"}
在一个示意性模型中，某β-内酰胺类药物的游离峰浓度为40 mg/L，半衰期为1.5小时，每6小时给药一次。对于MIC为5 mg/L的微生物，$f T_{>\text{MIC}}$占给药间隔的百分比是多少？
::: hint
数一数从40降到5 mg/L需要几个半衰期。
:::
::: solution
$\log_2(40/5) = \log_2 8 = 3$个半衰期，即$3 \times 1.5 = 4.5$小时。$4.5/6 = 0.75$，所以$f T_{>\text{MIC}} = 75\%$。
:::
:::

::: exercise 天然耐药 {level=1}
解释下列每种组合为什么无效：(a) 用头孢曲松治疗粪肠球菌（*Enterococcus faecalis*）心内膜炎；(b) 用万古霉素治疗大肠埃希菌菌血症；(c) 用阿莫西林治疗肺炎支原体（*Mycoplasma pneumoniae*）肺炎。
::: hint
每一种都是菌种的属性，而不是某个特定菌株的属性。
:::
::: solution
(a) 肠球菌的青霉素结合蛋白与头孢菌素类亲和力低，因此所有头孢菌素都无效。(b) 万古霉素分子太大，不能通过孔蛋白穿过革兰阴性菌的外膜。(c) 支原体没有细胞壁，因此β-内酰胺类没有作用靶点。
:::

::: exercise 每日一次庆大霉素 {level=2}
解释为什么庆大霉素通常每日给药一次，而不是分成三次较小的剂量，以及为什么要测定血药浓度。
::: hint
考虑浓度依赖性杀菌、抗生素后效应和毒性。
:::
::: solution
庆大霉素以**浓度依赖**的方式杀菌，因此单次大剂量能获得高的$C_{\max}/\text{MIC}$比值和快速杀菌。其**抗生素后效应**在浓度降到MIC以下后仍能抑制细菌再生长数小时，因此两次给药之间的较长间隔不会让细菌再生长。对肾脏和内耳的毒性取决于持续的暴露，而这些组织对药物的摄取是可饱和的，因此每天有一段较长的低浓度时间能减少毒性。之所以测定血药浓度，是因为其消除取决于肾功能：谷浓度高意味着药物在蓄积，必须按当地的列线图调整剂量或给药间隔。
:::
:::

::: exercise 产ESBL细菌尿路感染的口服选择 {level=2}
一名45岁女性患产ESBL大肠埃希菌引起的单纯性膀胱炎。解释为什么阿莫西林—克拉维酸和头孢氨苄不太可能有效，以及为什么呋喃妥因、磷霉素和匹美西林常常仍然有效。
::: hint
ESBL水解什么？其他三种药物在结构或机制上有何不同？
:::
::: solution
ESBL水解青霉素类和头孢菌素类，包括头孢氨苄。克拉维酸在实验室中能抑制许多ESBL，但产ESBL菌株常携带其他β-内酰胺酶和耐药机制，因此阿莫西林—克拉维酸常常失败。呋喃妥因和磷霉素不是β-内酰胺类，作用于不同的靶点，因此ESBL对它们没有影响。匹美西林是β-内酰胺类，但对许多ESBL相对稳定，并能在尿液中达到高浓度。这三种药物都浓集于尿液，适合下尿路感染，对其他部位的影响有限。最终的选择取决于药敏报告和当地指南。
:::
:::

::: exercise 危险的相互作用 {level=2}
一名服用辛伐他汀的70岁男性因胸部感染被处方克拉霉素。一周后他出现肌肉疼痛和尿色变深。请解释其机制，以及本来可以如何避免。
::: hint
哪种酶代谢辛伐他汀？克拉霉素对这种酶有什么作用？
:::
::: solution
辛伐他汀由**CYP3A4**代谢。克拉霉素强烈抑制CYP3A4，使辛伐他汀浓度升高，引起**肌病**，严重时引起**横纹肌溶解**，肌红蛋白使尿色变深，并有发生肾损伤的风险。本可以通过检查相互作用来避免：BNF建议避免这一组合，例如在疗程期间暂停他汀，或者在适合该感染的情况下选择不抑制CYP3A4的抗生素，如多西环素。
:::
:::

::: exercise 为什么结核病需要联合治疗 {level=3 check="10"}
一个结核空洞内约有$10^9$个杆菌。导致利福平耐药的自发突变约每$10^8$个杆菌发生1个，异烟肼耐药约每$10^6$个发生1个，二者相互独立。治疗前空洞内预计有多少个利福平耐药杆菌？然后用计算说明为什么联合治疗能防止耐药。
::: hint
用菌群数量乘以突变频率；对于两种药物，把频率相乘。
:::
::: solution
预计的利福平耐药杆菌数：$10^9 \times 10^{-8} = 10$。单用利福平会杀死占多数的敏感菌，留下这10个杆菌长成一个耐药菌群，这就是单药治疗造成耐药结核病的方式。

通过独立突变对两种药物都耐药的杆菌，频率约为$10^{-8} \times 10^{-6} = 10^{-14}$，因此空洞内的预计数量为$10^9 \times 10^{-14} = 10^{-5}$：几乎肯定一个也没有。每种药物都能杀死对另一种药物耐药的杆菌。这就是为什么结核病在初始阶段用几种药物治疗，为什么依从性很重要，以及为什么在诊断时使用快速分子检测检测利福平耐药。同样的原理也解释了HIV的联合治疗。
:::
:::

::: exercise 第四天的复核 {level=3}
一名52岁小腿蜂窝织炎男性入院时因“看起来病得很重”开始静脉使用哌拉西林—他唑巴坦。第4天，他已退热，红肿已退到入院时所画的笔线以内，炎症指标在下降，血培养阴性。请应用“然后聚焦”复核，并说明每项决定的理由。
::: hint
考虑蜂窝织炎的可能病原体、当前药物的抗菌谱、给药途径和疗程。
:::
::: solution
**诊断**：蜂窝织炎通常由化脓性链球菌（*Streptococcus pyogenes*）或金黄色葡萄球菌引起；血培养阴性很常见，不能排除这一诊断。他的治疗有效。

**药物**：哌拉西林—他唑巴坦是一种慎用类广谱抗生素，具有他不需要的抗假单胞菌和抗厌氧菌活性。它增加了艰难梭菌感染和耐药的风险。恰当的做法是**换用覆盖链球菌和葡萄球菌的窄谱药物**，如氟氯西林，过敏者用替代药物，遵循当地指南。

**给药途径**：他正在好转，能口服药物，因此符合**转为口服**治疗的标准。

**疗程**：设定**停药日期**。NICE蜂窝织炎指南建议短疗程，通常总共5～7天，只有在感染未好转时才延长。

**记录**：在病历和用药单上记录复核情况、理由和计划。决定是**更换药物、转为口服并设定停药日期**，这在不降低疗效的同时减少了危害。
