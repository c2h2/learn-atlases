在医疗过程中获得的感染，伤害的是因为别的原因前来就医的患者。一个因髋关节置换入院的人可能带着手术部位感染出院；一个脑卒中患者可能发生肺炎、导尿管相关尿路感染或艰难梭菌（*Clostridioides difficile*）腹泻。在任何时候，医院住院患者中都有百分之几的人患有在医院获得的感染，其中许多是可以预防的。

**感染预防与控制**（IPC）是阻止微生物从一个人或一个地方传到另一个人或地方的一整套做法。其中大部分很简单：清洁双手，使用合适的防护装备，保持设备和环境清洁，谨慎处理各种器械。它的成功取决于每一次都做到这些事情，这就是为什么感染预防与控制既是关于个人行为的学科，也是关于系统的学科。

本章介绍感染链和传播途径，标准预防和基于传播途径的预防，去污和灭菌，医疗相关感染和集束化措施，监测和暴发处理，再生数和群体免疫的计算，以及医务人员的防护。截至2026年，英格兰的做法遵循英国国民医疗服务体系英格兰（NHS England）发布的**《国家感染预防与控制手册》**（NIPCM）。

## 感染链 {#chain}

::: definition 感染链 {#def-transmission}
感染的传播需要六个环节：

1. **病原体**；
2. 病原体生存和增殖的**储存宿主**：人、动物或环境；
3. 离开储存宿主的**排出门户**，如呼吸道、肠道、皮肤或血液；
4. **传播方式**；
5. 进入新宿主的**侵入门户**，如伤口、黏膜或器械；
6. **易感宿主**。

打断任何一个环节都能阻止传播。感染预防与控制措施可以按它们所打断的环节来分组。
:::

主要的**传播方式**有：

- **接触传播**：直接接触，在人与人之间，通常经手；或间接接触，经被污染的设备或物体表面。这是医院中最常见的途径，见于MRSA、产碳青霉烯酶肠杆菌目细菌、艰难梭菌和诺如病毒等；
- **飞沫传播**：较大的呼吸道颗粒在落下之前只飞行一小段距离，通常不超过约一米，见于许多呼吸道病毒和脑膜炎奈瑟菌（*Neisseria meningitidis*）；
- **空气传播**：小颗粒悬浮在空气中，在一定距离以外或在传染源离开之后仍可被吸入，见于结核分枝杆菌（*Mycobacterium tuberculosis*）、麻疹病毒和水痘-带状疱疹病毒；
- **共同媒介传播**：被污染的食物、水、药物或血液制品；
- **媒介生物传播**：蚊和蜱等昆虫及节肢动物；在英国医院中罕见。

飞沫传播与空气传播之间的区别并不像这些分类所显示的那样截然分明。人呼出的颗粒大小是连续分布的，COVID-19大流行表明，呼吸道病毒可以在近距离以及在通风不良的房间中通过吸入小颗粒而传播。在实践中，这些分类对选择预防措施仍然有用，而通风现在被公认为控制的重要组成部分。

## 标准预防 {#standard}

::: definition 标准感染控制预防措施 {#def-standard}
**标准感染控制预防措施**（SICP）由所有工作人员在任何时候对所有患者使用，不论是否已知或怀疑有感染。在《国家感染预防与控制手册》中，它们包括：

- 评估每位患者的感染风险，并安排合适的床位；
- **手卫生**；
- 呼吸卫生和咳嗽礼仪；
- 根据操作选择的**个人防护装备**（PPE）；
- 诊疗设备的安全管理；
- 诊疗环境的安全管理；
- 布草的安全管理；
- 血液和体液溅洒的安全处理；
- 废物（包括锐器）的安全处置；
- 预防职业暴露，包括锐器伤。
:::

之所以要有标准预防，是因为大多数携带可传播微生物的人并不知道自己携带。对每个人采取同样的基本措施，就能防范未知的风险。

**手卫生**是最重要的单项措施。手把微生物从一个患者带到另一个患者，从被污染的物体表面带到患者身上，并从患者的定植部位带到导管等易感部位。世界卫生组织描述了手卫生的**五个时刻**：

1. 接触患者之前；
2. 进行清洁或无菌操作之前；
3. 接触体液之后；
4. 接触患者之后；
5. 接触患者周围环境之后。

对于没有肉眼可见污物的手，**含乙醇的手消毒剂**是首选方法。它快速，能杀灭大多数细菌和有包膜病毒，对皮肤的损伤也小于反复洗手。当手有肉眼可见的污物时，在护理腹泻或呕吐患者之后，以及在艰难梭菌或诺如病毒暴发期间，需要用**肥皂和水**洗手，因为乙醇不能杀灭芽孢，对无包膜病毒效果也较差。手套不能代替手卫生；摘下手套时手会被污染。

## 基于传播途径的预防 {#precautions}

::: definition 基于传播途径的预防措施 {#def-precautions}
当已知或怀疑患者患有通过某种特定途径传播的感染时，在标准预防的基础上加用**基于传播途径的预防措施**（TBP）。

- **接触预防**：单人间，或与携带同一种微生物的患者集中安置；接触患者或其周围环境时戴手套、穿围裙或隔离衣；专用设备；强化清洁。用于MRSA、产碳青霉烯酶微生物、艰难梭菌和诺如病毒。
- **飞沫预防**：单人间或集中安置；近距离接触时戴防液体的外科口罩。用于流感、许多其他呼吸道病毒，以及治疗最初24小时内的脑膜炎球菌病。
- **空气预防**：单人间，最好是负压隔离病房；佩戴经过**适合性测试**的**呼吸防护器**（在英国为FFP3）；在相关情况下只安排有免疫力的工作人员。用于有传染性的肺结核、麻疹、水痘或播散性带状疱疹，以及对某些呼吸道感染患者进行产生气溶胶的操作时。
:::

隔离是一种权衡。在一些研究中，住单人间的患者被查看的次数较少，可能感到孤独和焦虑，跌倒和压力性损伤也更多。因此，预防措施应在需要时及时开始，在不再有必要时按当地政策停止。

::: example 急诊科的麻疹 {#ex-measles-ed}
一名未接种疫苗的24岁男性因发热、咳嗽、结膜炎和新出现的斑丘疹，在繁忙的急诊科候诊了三个小时。后来PCR确诊为麻疹。在候诊期间，他与约40名患者和工作人员同处一室。请解释为什么这是一次严重的暴露，并概述应对措施。
::: solution
麻疹是传染性最强的人类感染之一。它经**空气**途径传播；患者离开后，病毒在房间空气中可存留长达约两小时。从出疹前约四天到出疹后四天都有传染性，因此他在整个就诊期间都有传染性。

应对由感染预防团队和当地卫生防护团队主导，遵循英国卫生安全局（UKHSA）的指南：

- 向当地卫生防护团队**报告**病例，因为麻疹是法定报告疾病；
- **确定暴露者**：在他就诊期间及其后一段时间内曾在候诊区的所有人；
- **评估他们的免疫状况**：有记录的两剂MMR疫苗接种，或麻疹IgG阳性，可作为有保护的证据；
- 为易感接触者**提供暴露后保护**：对符合条件者在暴露后72小时内接种MMR疫苗；对不能接种活疫苗的高危者，如易感孕妇、严重免疫抑制者和小婴儿，在六天内给予人正常免疫球蛋白；
- 没有免疫证据的暴露工作人员，从首次暴露后第5天到最后一次暴露后第21天**停止工作**。

这一事件也暴露了系统的失误。发热伴皮疹的人应在到达时就被识别出来并转入单间，这就是为什么许多急诊科在分诊时筛查皮疹和发热。
:::
:::

## 去污 {#decontamination}

::: definition 清洁、消毒与灭菌 {#def-decontamination}
**去污**是清除或杀灭微生物，使物品能够安全使用的过程。它分为三个层次：

- **清洁**通常用洗涤剂和水，物理性地清除污物、有机物和许多微生物；它必须最先进行，因为有机物会保护微生物免受消毒剂和灭菌剂的作用；
- **消毒**杀灭或灭活大多数微生物，但不一定能杀灭细菌芽孢；
- **灭菌**杀灭所有微生物，包括芽孢。

**斯波尔丁分类**使去污层次与风险相匹配：

| 类别 | 用途 | 所需处理 | 例子 |
|---|---|---|---|
| 高度危险 | 进入无菌组织或血管系统 | 灭菌 | 手术器械、植入物 |
| 中度危险 | 接触黏膜或不完整的皮肤 | 高水平消毒或灭菌 | 软式内镜、喉镜片 |
| 低度危险 | 只接触完整的皮肤 | 清洁，必要时低水平消毒 | 血压计袖带、听诊器 |
:::

在英国的消毒供应中心，手术器械通常在高压灭菌器中用**压力蒸汽**灭菌。英格兰现行指南规定，对多孔负载，温度为134～137 °C，至少维持3分钟。不耐热的物品用其他方法灭菌，如低温过氧化氢。软式内镜不能高压灭菌，需在自动化清洗消毒机中清洗和消毒，这就是为什么内镜再处理的差错是反复出现的事故原因。

不同微生物的抵抗力不同。**朊病毒**抵抗力最强，其次是细菌芽孢、分枝杆菌、无包膜病毒和真菌，繁殖体细菌和有包膜病毒最容易被杀灭。标准灭菌不能可靠地灭活朊病毒，因此，对有克-雅病风险者的高风险组织使用过的器械，要按特定的国家指南处理，有时需隔离存放或销毁。

## 医疗相关感染 {#hai}

::: definition 医疗相关感染与集束化措施 {#def-hai}
**医疗相关感染**（HAI）是在医院或其他医疗场所由于医疗而发生的感染。主要类型有：

- **血流感染**，尤其是与中心静脉导管相关的血流感染；
- **导尿管相关尿路感染**；
- **手术部位感染**；
- **医院获得性肺炎和呼吸机相关肺炎**；
- **艰难梭菌感染**，以及MRSA和产碳青霉烯酶细菌等耐药微生物引起的感染。

**集束化措施**是针对某一操作的一小组循证做法，通常三到五项，每次都一起执行。依从性按“全或无”计算：只有每一项都做到，这次集束化措施才算完成。
:::

集束化措施之所以有效，是因为器械相关感染遵循可预测的途径。对于中心静脉导管，皮肤上的微生物沿导管外壁移行，手上的微生物经接头进入。因此，典型的**置管集束化措施**包括手卫生、最大无菌屏障、用含2%氯己定的70%乙醇进行皮肤准备、选择最合适的部位以及无菌敷料。**维护集束化措施**再加上每日评估是否仍需要导管、使用前消毒接头以及敷料护理。2006年，彼得·普罗诺沃斯特（Peter Pronovost）及其同事报告，在密歇根州100多个重症监护病房开展的、围绕这样一份核查表建立的项目，大幅降低了导管相关血流感染，并使降低得以持续。

对任何器械来说，最有效的单项措施往往是**拔除它**。导尿管或静脉导管每多留置一天，风险就增加一分，这就是为什么集束化措施包括每日评估是否仍需要。

监测按每单位暴露量报告感染率，以便对规模和病例构成不同的单位进行跨时间的比较：

$$
\text{每1,000器械日感染率} = \frac{\text{感染数}}{\text{总器械日数}} \times 1000
$$ {#eq-rate}

::: example 重症监护病房的导管感染 {#ex-clabsi}
一个重症监护病房一年中记录了6例中心静脉导管相关血流感染。其患者的中心静脉导管共留置2,400个导管日。计算每1,000导管日的感染率，并解释为什么使用这一指标，而不是每位患者的感染数。
::: solution
$$
\frac{6}{2400} \times 1000 = 2.5 \text{ 每1,000导管日}
$$

导管感染的风险取决于导管留置的时间，因此按每位患者计算感染数，会使患者住院时间更长或病情更重的单位处于不利地位。用导管日作分母衡量的是每一天暴露的风险。病房就可以追踪自身感染率随时间的变化，并与全国监测数据比较。感染率上升会促使对置管和维护做法以及导管留置时间进行审查。
:::
:::

## 监测与暴发 {#outbreaks}

::: definition 监测与暴发 {#def-outbreak}
**监测**是对感染数据进行持续、系统的收集、分析和解释，并反馈给能据此采取行动的人。在英格兰，医疗机构通过强制性监测报告MRSA、MSSA和革兰阴性菌菌血症以及艰难梭菌感染，临床医生在临床怀疑某些传染病时就必须向当地卫生防护团队报告。

**暴发**是在时间和地点上相关联的两例或以上同一种感染，或病例数超过通常的预期数。暴发处理遵循一个共同的顺序：

1. 确认诊断，并确认病例确实增加；
2. 制定**病例定义**（人、地点、时间以及临床或实验室标准）；
3. 搜索病例并绘制**流行曲线**；
4. 对来源和途径形成假设并加以验证，例如对分离株进行分型或测序；
5. 尽早实施**控制措施**，不等待证据；
6. 与工作人员、患者和公众沟通；
7. 宣布暴发结束并记录经验教训。
:::

::: example 病房中的艰难梭菌聚集 {#ex-cdiff-cluster}
一个有28张床位的老年内科病房在三周内记录了四例新发艰难梭菌感染；所有病例都发生在入院三天以后。通常的发病率约为每两个月一例。感染预防团队应采取哪些步骤？
::: solution
同一病房在28天内出现两例或以上新的医院起病病例，符合英国通常所说的**发病率升高期**的定义，因此团队不等证实暴发就开始调查。

- **控制措施**立即开始：对病例进行隔离并采取接触预防，用肥皂和水洗手，用杀芽孢剂强化清洁，并检查便椅和其他共用设备，它们是常见的储存宿主。
- **分型**：将分离株送去做核糖体分型或测序。几名患者为同一型别提示病房内传播；型别不同提示病例是独立发生的，往往反映了抗生素的使用。
- **抗生素复核**：团队审核病房的处方，尤其是头孢菌素类、克林霉素、氟喹诺酮类和阿莫西林—克拉维酸等高风险药物，并复核质子泵抑制剂的使用。
- **审核**：审核手卫生和清洁情况，并向工作人员反馈。

如果分型显示为共同菌株，则宣布暴发，并可能采取进一步措施，如病房停止收治。每个病例都应复盘，找出本可以采取的不同做法。
:::
:::

::: example 来自水槽的产碳青霉烯酶细菌 {#ex-sink-cluster}
在八个月内，一个血液科病房在九名患者中发现了产碳青霉烯酶的肺炎克雷伯菌（*Klebsiella pneumoniae*），尽管手卫生审核良好，也采取了接触预防。测序显示患者的分离株亲缘关系很近，环境采样在几个洗手池的下水口中发现了同一种细菌。请解释其来源和控制措施。
::: solution
**水槽下水口**是革兰阴性菌（包括产碳青霉烯酶细菌）公认的储存宿主。微生物在下水口和存水弯中形成**生物膜**，能抵抗常规清洁。水龙头流出的水冲击下水口，把微生物溅到水槽、周围物体表面、手以及放在附近的物品上；当水槽被用来倾倒为生物膜提供养分的液体或营养物时，问题更加严重。

控制措施包括停止在洗手池倾倒液体，使患者物品远离水槽，清洁和处理下水口，更换被污染的管道，以及重新设计水槽，使水不直接流入下水口。一些病房已把水槽完全移出病房，改用乙醇手消毒剂。对患者的筛查和持续监测能显示这些措施是否有效。这一案例说明，当标准措施失败时，必须考虑环境，而不仅仅是人。
:::
:::

## 再生数与群体免疫 {#herd}

一种感染在人群中的传播，可以用每个病例引起的新感染数来概括。

::: theorem 再生数与群体免疫阈值 {#thm-herd}
**基本再生数**$R_0$是在完全易感的人群中，一个有传染性的人平均引起的继发病例数。**有效再生数**$R_e$是在部分人有免疫力的实际人群中的平均数。如果人群中易感者的比例为$s$，且混合是随机的，

$$
R_e = R_0 \cdot s
$$ {#eq-re}

当$R_e > 1$时暴发扩大，当$R_e < 1$时暴发减弱。**群体免疫阈值**，即使$R_e = 1$的免疫人群比例，为

$$
H = 1 - \frac{1}{R_0}
$$ {#eq-hit}

如果一种疫苗能在比例为$E$的接种者中预防感染，所需的疫苗接种率为$V_c = H/E$。
:::

::: proof
如果所有接触者都易感，每个有传染性的人所接触的人足以感染$R_0$个人。如果只有比例为$s$的人易感，就只有这一比例的接触会导致感染，从而得到$R_e = R_0 s$。

当每个病例被不到一个新病例所取代时，即$R_0 s < 1$，因而$s < 1/R_0$时，传播减弱。因此免疫人群的比例必须超过$1 - 1/R_0$。

如果接种率为$V$，疫苗保护比例为$E$，则免疫比例为$VE$。令$VE = 1 - 1/R_0$，得到$V_c = (1 - 1/R_0)/E$。当$V_c$超过1时，无论接种率多高，单靠疫苗接种都不能阻断传播。该模型假设随机混合；未接种者的聚集，如接种率低的学校或社区，即使在全国接种率高于阈值时也能维持暴发。
:::

::: widget plot
f: 1 - 1/x; (1 - 1/x)/e
x: 1, 20
y: 0, 1.1
sliders: e=0.95:0.5:1:0.01
labels: H = 1 - 1/R_0; V_c = H/E
caption: 群体免疫阈值$H$（下方曲线）和使用有效率为$E$的疫苗时所需的接种率$V_c$（上方曲线），横轴为$R_0$。季节性流感的$R_0$只略高于1，只需要不大的免疫比例；麻疹的$R_0$通常引用为12～18，需要超过90%。用滑块降低疫苗有效率，可以看到对于传染性很强的感染，所需接种率超过100%。该模型假设随机混合。
:::

对于$R_0 = 15$的麻疹，$H = 1 - 1/15 \approx 0.93$，因此约93%的人群必须有免疫力。两剂MMR疫苗能保护约97%的接种者，所需接种率为$0.933/0.97 \approx 0.96$，即96%。这就是为什么世界卫生组织的麻疹目标是两剂接种率达到95%，也是为什么接种率的小幅下降之后就会出现暴发。

## 保护医务人员 {#staff}

医务人员既面临风险，也是风险来源。职业健康服务提供乙型肝炎和流感疫苗接种，必要时提供麻疹、腮腺炎、风疹和水痘疫苗接种，并在入职时筛查结核病。

**锐器伤**和血液溅洒可以传播血源性病毒。英国指南常引用的、被感染源污染的针刺伤后的大致传播风险为：乙型肝炎约三分之一（来自高传染性的感染源，暴露者无免疫力），丙型肝炎约三十分之一，HIV约三百分之一。空心针、深部损伤以及可见血液时风险更高。安全的做法能预防大多数损伤：绝不回套针帽，使用安全装置，并在使用地点处置锐器。

::: example 针刺伤 {#ex-needlestick}
一名26岁的低年资医生在为患者抽血后被空心针深深刺伤。后来发现该患者感染HIV且病毒载量可测出，乙型肝炎表面抗原阴性，丙型肝炎抗体阴性。这名医生已完成乙型肝炎疫苗全程接种，有记录显示产生了应答。概述应立即采取的措施及其理由。
::: solution
**立即急救**：让伤口轻轻出血，用肥皂和流动的水冲洗，不要擦洗或吸吮伤口。用敷料覆盖。

立即向职业健康部门**报告**，下班时间则向急诊科报告，因为某些干预措施有时间限制。

**评估风险**：被装有血液、来自HIV病毒载量可测出的感染源的空心针深深刺伤，属于严重暴露。推荐HIV**暴露后预防**（PEP），应尽快开始，最好在数小时内，最迟不超过72小时，并按国家指南持续28天。如果感染源在治疗下病毒载量持续检测不到，则不需要暴露后预防。

**乙型肝炎**：这名医生有记录证明的免疫力，且感染源HBsAg阴性，因此不需要进一步处理。**丙型肝炎**：感染源抗体阴性，因此风险很低；无论如何，丙型肝炎都没有暴露后预防，如果感染源阳性，会提供随访检测。

**随访**：基线血液检测，窗口期后检测HIV，提供支持，并在排除HIV感染之前给予安全性行为的建议。还应复盘这一事件，以防再次发生。
:::
:::

::: warning 手套不等于手卫生
手套保护佩戴者免受污染，但人们常常戴得太久。戴手套的手接触一名患者，然后接触床栏，再接触电脑键盘，再接触第二名患者，一路都携带着微生物。手套应针对特定的操作戴上，操作后立即摘下，随后进行手卫生。不建议在常规接触完整皮肤时戴手套，这样做与较差的手卫生相关。
:::

::: quiz
一名40岁男性因咳嗽三周、体重下降入院，胸片见空洞。痰涂片见抗酸杆菌。在评估他不再有传染性之前，需要采取哪种预防措施？
- [ ] 只需标准预防
- [ ] 接触预防，戴手套、穿围裙
- [ ] 飞沫预防，工作人员戴外科口罩
- [x] 空气预防：单人间，最好是负压病房，在规定情况下工作人员佩戴经过适合性测试的FFP3呼吸防护器
::: solution
涂片阳性的肺结核经**空气**途径传播：携带结核分枝杆菌的小颗粒悬浮在空气中，可在一定距离外被吸入。他需要关门的单人间，最好是负压病房；工作人员需按当地政策佩戴经过适合性测试的呼吸防护器，尤其是在可能为耐药结核病或进行产生气溶胶的操作时。接触者由结核病服务机构追踪。
:::
:::

::: history
1847年，伊格纳茨·塞麦尔维斯（Ignaz Semmelweis）在维也纳证明，由刚做完尸体解剖的医生和医学生负责的产科病房，产褥热死亡率远高于由助产士负责的病房。用含氯石灰溶液洗手使死亡人数急剧下降。他的观点在他生前基本上被拒绝。19世纪50年代，弗洛伦斯·南丁格尔（Florence Nightingale）利用克里米亚战争的死亡统计数据，倡导卫生、通风和清洁的医院。1867年，约瑟夫·李斯特（Joseph Lister）引入了使用石炭酸的抗菌外科。

1927年，威廉·克马克（William Kermack）和安德森·麦肯德里克（Anderson McKendrick）发表了流行病的数学模型，再生数和群体免疫阈值正是由此推导出来的。1968年，厄尔·斯波尔丁（Earle Spaulding）描述了按感染风险对医疗器械进行分类的方法，至今仍指导着去污工作。以感染控制护士、监测和集束化措施为特征的现代感染控制，从20世纪60年代起逐步发展，并在英格兰因21世纪初的MRSA和艰难梭菌流行以及COVID-19大流行而加速。
:::

## 后续内容

医疗相关感染背后的微生物见[[microbiology/bacteria]]和[[microbiology/microbiota]]，用于调查暴发的测序和分型见[[microbiology/laboratory-diagnosis]]。医疗相关感染和暴发的临床处理见[[infectious-diseases/healthcare-infections]]和[[infectious-diseases/stewardship-outbreaks]]。法定报告、接触者追踪以及传播的人群层面见[[public-health/communicable-disease-control]]和[[public-health/vaccination-programmes]]。

::: summary
- 传播需要病原体、储存宿主、排出门户、传播方式、侵入门户和易感宿主；打断任何一个环节都能阻止传播。
- 在医院中，接触传播（主要经手）占主导。飞沫传播和空气传播是一个连续谱，通风很重要。
- 标准预防适用于每一位患者、每一次操作。在世界卫生组织的五个时刻进行手卫生是最重要的措施；对芽孢和诺如病毒用肥皂和水。
- 基于传播途径的预防措施增加了接触、飞沫或空气预防；空气预防需要经过适合性测试的FFP3呼吸防护器，最好使用负压病房。
- 清洁先于消毒和灭菌。斯波尔丁分类把高度危险、中度危险和低度危险物品分别对应于灭菌、高水平消毒和清洁。
- 集束化措施和尽早拔除器械可预防导管、导尿管和手术相关感染；感染率按每1,000器械日报告。
- $R_e = R_0 s$，群体免疫阈值为$1 - 1/R_0$，所需接种率为$(1 - 1/R_0)/E$；麻疹需要约95%的两剂接种率。
- 锐器伤通过安全的做法来预防，发生后及时处理，有指征时进行HIV暴露后预防。
:::

## 习题

::: exercise 选择预防措施 {level=1}
下列患者分别需要哪种基于传播途径的预防措施：(a) 诺如病毒感染者；(b) 流感患者；(c) 水痘患者；(d) MRSA定植者？
::: hint
想一想每种微生物的主要传播途径。
:::
::: solution
(a) **接触**预防，用肥皂和水洗手并强化清洁；呕吐也会产生有传染性的气溶胶，因此当地可能加用口罩。(b) **飞沫**预防，进行产生气溶胶的操作时采取空气预防。(c) **空气**预防加接触预防，由对水痘有免疫力的工作人员护理。(d) 按当地政策采取**接触**预防，常同时进行去定植。
:::
:::

::: exercise 群体免疫阈值 {level=1 check="0.75"}
某种感染的$R_0 = 4$。假设随机混合，人群中必须有多大比例的人有免疫力才能阻止持续传播？给出精确的小数。
::: hint
用$H = 1 - 1/R_0$。
:::
::: solution
$H = 1 - 1/4 = 0.75$。四分之三的人群必须有免疫力。
:::
:::

::: exercise 对设备进行分类 {level=1}
用斯波尔丁分类，说出下列物品的类别以及所需的去污层次：(a) 手术室中使用的手术刀柄，(b) 软式胃镜，(c) 便椅。
::: hint
问一问每件物品接触什么组织。
:::
::: solution
(a) **高度危险**：它进入无菌组织，因此必须**灭菌**。(b) **中度危险**：它接触黏膜，因此至少需要**高水平消毒**，在实践中由自动化内镜清洗消毒机完成。(c) **低度危险**：它接触完整的皮肤，因此需要**清洁**并消毒；在有艰难梭菌或诺如病毒的情况下，使用含氯消毒剂或其他杀芽孢产品。
:::
:::

::: exercise 有效再生数 {level=2 check="1.8"}
某种感染的$R_0 = 6$。在一个社区中，70%的人有免疫力。$R_e$是多少？暴发会扩大吗？
::: hint
易感比例为$s = 1 - 0.7$。
:::
::: solution
$s = 0.3$，所以$R_e = 6 \times 0.3 = 1.8$。由于$R_e > 1$，暴发会扩大。这种感染的群体免疫阈值为$1 - 1/6 \approx 0.83$，因此免疫比例需要提高约13个百分点。
:::
:::

::: exercise 手卫生审核 {level=2 check="80"}
一名观察员在病房记录了85次手卫生时机，其中68次执行正确。计算以百分比表示的依从率，并指出这项审核的两个局限性。
::: hint
依从率等于正确执行次数除以时机数。
:::
::: solution
$68/85 = 0.80$，所以依从率为**80%**。局限性包括**霍桑效应**，即工作人员在被观察时往往表现更好；样本量小，可能不能反映夜班或繁忙时段；不同观察员之间可能存在差异；以及依从率不衡量手法，例如是否覆盖了手的所有表面。把结果反馈给工作人员，并辅以培训和方便取用的手消毒剂，比数字本身更有用。
:::
:::

::: exercise 麻疹疫苗接种率 {level=2 check="96"}
麻疹的$R_0$约为15，两剂MMR疫苗能保护约97%的接种者。计算达到群体免疫阈值所需的两剂接种率。以百分比给出答案，四舍五入到整数。
::: hint
先求$H = 1 - 1/R_0$，再除以$E$。
:::
::: solution
$H = 1 - 1/15 \approx 0.933$。$V_c = 0.933/0.97 \approx 0.962$，所以需要约**96%**的两剂接种率。接种率低于这一水平，哪怕只低几个百分点，麻疹都能传播，尤其是在未接种的儿童集中于同一学校和社区的地方。
:::
:::

::: exercise 内镜事件 {level=3}
一家医院发现，由于一台内镜清洗消毒机的故障，有三周时间某一消毒步骤没有完成。在此期间有140名患者做了胃镜检查。存在哪些风险？医院应该怎么做？
::: hint
考虑内镜的斯波尔丁类别、可能传播的微生物以及坦诚告知义务。
:::
::: solution
胃镜是**中度危险**器械，接触黏膜，常被血液和分泌物污染。消毒不完全可能导致细菌传播，包括耐药革兰阴性菌和假单胞菌，理论上也可能传播乙型肝炎、丙型肝炎和HIV等血源性病毒。对每位患者的绝对风险通常很低，但不是零。

医院应停用该设备并调查故障；召集包括感染预防、微生物学和卫生防护人员在内的事件处理小组；通过核查哪些内镜和患者受到影响来评估风险；并开展**回溯调查**。联系患者，告诉他们发生了什么，在适当的时间间隔为他们提供血源性病毒检测，并给出联系人。公开透明是法律和职业上的坦诚告知义务。分享经验教训，并加强对清洗消毒机的验证和监测。
:::
:::

::: exercise 养老院的诺如病毒 {level=3}
两天内，一家养老院40名住户中有12名、以及5名工作人员突然出现呕吐和腹泻。请解释为什么诺如病毒是最可能的原因，并概述控制措施，包括何时可以宣布暴发结束。
::: hint
考虑潜伏期、病毒的特点及其传播方式。
:::
::: solution
**诺如病毒**是养老院和医院中呕吐腹泻暴发最常见的原因。其潜伏期短，为12～48小时，呕吐突出，在住户和工作人员中迅速传播，病程短，这些都符合。它经粪—口途径、被污染的物体表面以及呕吐产生的气溶胶传播。感染剂量极低、对乙醇有抵抗力以及能在环境中存活，使暴发难以阻止。

控制措施遵循英国卫生安全局和当地指南：

- 通知当地卫生防护团队，并送粪便标本做PCR确诊；
- 让患病住户留在自己的房间，尽可能使用专用卫生间；
- 患病工作人员在症状停止后48小时内不得上班；
- 用**肥皂和水**进行手卫生，用**含氯消毒剂**进行清洁；
- 戴手套、穿围裙，及时处理呕吐物和粪便；
- 限制收住、转院和探视，并告知接收医院有暴发；
- 给予额外的液体，监测体弱住户是否脱水。

通常在一段规定时间内没有新病例，一般是最后一例症状消失后48～72小时，并完成**终末清洁**后，才宣布暴发结束。
:::
