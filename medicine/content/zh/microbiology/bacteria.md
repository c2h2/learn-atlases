细菌是没有细胞核的单细胞生物。它们大多无害，许多还有益，只有少数会致病，却造成了医院中所见的大部分细菌性疾病。要对这少数细菌进行推理，临床医生需要掌握每种细菌的几项基本事实：细胞的形态、对革兰染色的反应、是否需要氧气、是否形成芽孢，以及如何与其他细菌交换基因。

这些事实并非琐碎的知识。革兰染色反应告诉你哪些抗生素能够到达细菌。需氧情况告诉你细菌在体内的栖居部位，以及哪种标本能培养出它。芽孢的形成解释了为什么有些感染能在含醇手消毒剂下存活，而基因转移解释了耐药性为何能在不同菌种之间如此迅速地传播。

本章介绍细菌细胞的结构，革兰染色和主要的细胞被膜类型，细菌的生长与芽孢，细菌遗传学，以及引起人类疾病的细菌的实用分类。

## 细菌细胞 {#structure}

细菌是**原核生物**：其DNA游离于细胞质中，而不是被包裹在核膜内。细菌比人体细胞小得多。典型的杆菌宽约1 µm、长2～3 µm，大致与人的血小板相当。

::: definition 细菌细胞 {#def-structure}
每种细菌都具有相同的核心结构：

- **细胞质膜**，为不含固醇的磷脂双层（支原体是例外）；
- **拟核**：一条不被膜包裹的环状染色体；
- **70S核糖体**，由30S和50S亚基组成，不同于人体的80S核糖体；
- 几乎所有菌种都有由**肽聚糖**构成的**细胞壁**，肽聚糖是由短肽交联的糖链网状结构。

许多细菌还有一些非必需结构：

- **质粒**：能自主复制的小型环状DNA，常携带耐药基因或毒素基因；
- **荚膜**：一层疏松的外层，通常为多糖，可抵抗吞噬；
- **鞭毛**用于运动，**菌毛**用于黏附于物体表面或其他细菌；
- **芽孢**：少数菌属形成的休眠、抵抗力极强的形式。
:::

这些结构中的每一种都是药物的靶点或屏障。70S核糖体使氨基糖苷类、大环内酯类和四环素类能够阻断细菌的蛋白质合成，而对人体细胞影响有限。肽聚糖只存在于细菌，因此阻断其合成的药物，如青霉素类，是我们所拥有的最安全的抗生素之一。荚膜则解释了为什么脾功能缺失的人容易受到肺炎链球菌（*Streptococcus pneumoniae*）等有荚膜细菌的威胁。

### 两类细胞被膜 {#envelopes}

细胞质膜以外的各层称为**细胞被膜**。有医学意义的细菌具有两种设计中的一种，而革兰染色可以把它们区分开来。

::: definition 革兰阳性菌与革兰阴性菌的细胞被膜 {#def-envelope}
**革兰阳性菌**的细胞被膜由细胞质膜和覆盖其上的一层厚肽聚糖组成，厚度约20～80 nm。其中贯穿着**磷壁酸**和**脂磷壁酸**。没有外膜。

**革兰阴性菌**的细胞被膜由细胞质膜、仅几纳米厚的一薄层肽聚糖以及其外的第二层膜即**外膜**组成。两层膜之间的空间称为**周质间隙**。外膜的外叶由**脂多糖**（LPS）构成，小分子通过称为**孔蛋白**的蛋白通道穿过外膜。
:::

脂多糖由三部分组成。**脂质A**把它锚定在膜上，是其有毒成分，常称为**内毒素**。核心寡糖把脂质A与**O抗原**相连，O抗原是一条长而多变的糖链，用于菌株分型（例如大肠埃希菌（*Escherichia coli*）O157）。

外膜在临床上有三方面的意义。它是一道屏障：万古霉素等大分子无法穿过外膜，所以万古霉素对革兰阴性菌没有实用的活性。周质间隙中含有β-内酰胺酶等酶，恰好位于进入的β-内酰胺类抗生素抵达的位置。革兰阴性菌释放的脂质A是炎症和感染性休克的强烈诱因，[[microbiology/bacterial-pathogenesis]]对此有详细解释。

### 革兰染色的原理 {#gram}

::: theorem 革兰染色区分两类细胞被膜 {#thm-gram}
革兰染色时，先用**结晶紫**染色，再用**碘液**处理，然后用**乙醇或丙酮**脱色，最后用**沙黄**或中性红复染。具有厚肽聚糖细胞壁的细菌保留紫色，称为**革兰阳性菌**。细胞壁薄而有外膜的细菌失去紫色，被复染成红色，称为**革兰阴性菌**。
:::

::: proof
结晶紫进入所有细胞。碘与之结合，在细胞内形成大的染料—碘复合物。

脱色是决定性的步骤。在革兰阳性菌中，乙醇使厚的肽聚糖网脱水收缩，把大复合物困在细胞内。在革兰阴性菌中，乙醇溶解了富含脂质的外膜的大部分，薄的肽聚糖层无法留住复合物，紫色因此被洗脱。

随后复染剂把所有细胞都染成红色，但在革兰阳性菌中，红色被更深的紫色掩盖。结果是两种颜色报告了一个结构上的差异。
:::

革兰染色会以可以预见的方式出错。脱色过度会使革兰阳性菌看起来像革兰阴性菌。陈旧培养物和受抗生素损伤的细菌可能着色不均。有些细菌几乎不着色，这些例外值得作为一组来记忆。

::: warning 革兰染色看不到的细菌
革兰染色未见细菌并不能排除细菌感染。有几类重要细菌着色很差或根本不着色：

- **分枝杆菌**，其富含**分枝菌酸**的蜡质细胞壁不易被染料穿透；需要抗酸染色（齐-内染色或金胺染色）；
- **支原体**，完全没有细胞壁；
- **衣原体**和**立克次体**，生活在人体细胞内；
- **军团菌**，着色很淡；
- **螺旋体**，如梅毒螺旋体（*Treponema pallidum*），太细，普通光学显微镜下看不到。

怀疑这些病原体时，检验申请必须注明，因为实验室会采用不同的染色、培养方法、抗原检测或PCR。
:::

### 形态、排列与需氧情况 {#classification}

除革兰染色反应外，微生物学家接下来报告的是**形态**和**排列**。圆形细胞是**球菌**，杆状细胞是**杆菌**，弯曲或螺旋形的包括弧菌和螺旋体。在一个平面上分裂的球菌形成成对或**链状**排列（链球菌）；在多个平面上分裂的球菌形成**葡萄串状**排列（葡萄球菌）。

::: definition 需氧情况 {#def-oxygen}
细菌按其利用氧的方式分组：

- **专性需氧菌**需要氧（铜绿假单胞菌（*Pseudomonas aeruginosa*）、结核分枝杆菌（*Mycobacterium tuberculosis*））；
- **兼性厌氧菌**有氧无氧均能生长（大肠埃希菌、金黄色葡萄球菌（*Staphylococcus aureus*））；大多数常见病原菌属于此类；
- **专性厌氧菌**受氧损害，只能在无氧条件下生长（脆弱拟杆菌（*Bacteroides fragilis*）、梭菌属（*Clostridium*）各菌种）；
- **微需氧菌**需要低浓度的氧（弯曲菌属（*Campylobacter*）、幽门螺杆菌（*Helicobacter pylori*））。
:::

需氧情况可以预测细菌的栖居部位和致病部位。专性厌氧菌在结肠以及牙齿与牙龈之间的缝隙中占优势。当组织失去血供或肠内容物外漏时，它们引起感染，因此常见于脓肿、肠穿孔、吸入性肺炎和坏死性伤口。厌氧菌感染常有恶臭，送检厌氧菌的标本必须是脓液或组织，而不是干拭子。

## 生长与芽孢 {#growth}

细菌通过**二分裂**繁殖：一个细胞复制其染色体、长大，然后分裂为两个相同的子细胞。菌群数量加倍所需的时间称为**代时**或倍增时间。

::: definition 代时与生长曲线 {#def-growth}
若菌群起始时有$N_0$个细胞，每$g$分钟加倍一次，则经过$t$分钟后细胞数为

$$
N = N_0 \cdot 2^{t/g}
$$ {#eq-growth}

世代数为$n = t/g = \log_2(N/N_0)$。

在封闭培养中，生长分为四个时期：

1. **迟缓期**，细胞适应新培养基，尚未分裂；
2. **指数期（对数期）**，生长遵循[[#eq-growth]]；
3. **稳定期**，营养耗尽、代谢废物积累，分裂与死亡达到平衡；
4. **衰亡期**，活菌数下降。
:::

不同细菌的代时差别很大。大肠埃希菌在营养丰富的肉汤中约20分钟即可倍增一次。结核分枝杆菌约需15～20小时，麻风分枝杆菌（*Mycobacterium leprae*）约需两周。代时解释了临床实践中的许多现象。大肠埃希菌血培养通常在一天内报阳。分枝杆菌培养要保留六周或更久才能报告阴性。生长缓慢的细菌也难以杀灭：结核病的治疗持续数月，部分原因是抗生素对正在分裂的细胞作用最强。

体内的代时比在肉汤中长，因为营养有限，而且免疫系统会在细菌生长的同时杀灭它们。尽管如此，这个公式仍可用来估计未经治疗的感染扩展得有多快，以及为什么脓毒症的治疗延误一小时也很重要。

:::

::: example 三小时后有多少细胞？ {#ex-growth}
一份每毫升含$10^3$个大肠埃希菌的尿液标本，在温暖的实验台上放置了三小时才放入冰箱。假设代时为20分钟，且没有迟缓期。每毫升将有多少细菌？这为什么重要？
::: solution
世代数为$n = 180/20 = 9$。

$$
N = 10^3 \times 2^9 = 10^3 \times 512 = 5.12 \times 10^5 \text{ 每毫升}
$$

一份来自未感染者的标本，现在看起来就像来自重度感染者，因为传统上以每毫升超过$10^5$个细菌提示尿路感染。这就是为什么尿液必须尽快送到实验室或冷藏保存，或者收集在含有硼酸等防腐剂的容器中。这里的错误结果属于分析前误差：实验室的测量是准确的，但标本在送达之前已经发生了变化。
:::
:::

### 芽孢 {#spores}

::: definition 芽孢 {#def-spore}
**芽孢**是细菌在营养缺乏时于细胞内形成的休眠体。它有一个脱水的核心、一层厚的保护性皮质和坚韧的蛋白质外壳。芽孢没有可测得的代谢，能存活多年。

有医学意义的形成芽孢的细菌分为两组：

- **需氧**芽孢菌：芽孢杆菌属（*Bacillus*）（炭疽芽孢杆菌（*B. anthracis*）、蜡样芽孢杆菌（*B. cereus*））；
- **厌氧**芽孢菌：梭菌属（破伤风梭菌（*C. tetani*）、肉毒梭菌（*C. botulinum*）、产气荚膜梭菌（*C. perfringens*））以及艰难梭菌（*Clostridioides difficile*）。
:::

芽孢能耐受高温、干燥、辐射和包括乙醇在内的许多消毒剂。条件改善时，它们**出芽**重新成为生长的细胞。这些特性直接关系到临床：

- 艰难梭菌芽孢可在病房物体表面以及仅用含醇手消毒剂清洁过的手上存活，因此暴发期间要用肥皂和流动水洗手，并用含氯制剂清洁；
- 土壤中的破伤风梭菌芽孢进入伤口，在组织坏死、氧气缺乏的部位出芽；
- 肉毒梭菌芽孢能在加热不充分的腌制或罐装食品中存活；
- 熟米饭中的蜡样芽孢杆菌芽孢能耐受煮沸，若米饭保温存放，芽孢会出芽并产生毒素。

灭菌方法，如高压蒸汽灭菌器中的加压蒸汽，就是为杀灭芽孢而设计和验证的。芽孢是医疗灭菌的基准，[[microbiology/infection-control]]对此有所介绍。

::: example 吃了自制罐装食品后出现瘫痪 {#ex-botulism}
一名46岁女性在食用自己在家装瓶保存的蔬菜24小时后出现复视、眼睑下垂和吞咽困难。次日无力扩展到双臂。她意识清醒，无发热，感觉正常。与她同吃这顿饭的丈夫也出现了类似症状。请解释其微生物学机制。
::: solution
这是**食源性肉毒中毒**的表现：从脑神经开始的对称性、下行性弛缓性瘫痪，意识和感觉正常，发生在共同进餐的两个人身上。

事件链取决于芽孢。来自土壤的肉毒梭菌芽孢污染了蔬菜。家庭装瓶的低酸食品加热程度足以杀死竞争性微生物，却不足以破坏芽孢。密封的瓶内处于厌氧状态，于是芽孢出芽，细菌产生了**肉毒神经毒素**。引起疾病的是毒素而不是感染：毒素阻断神经末梢释放乙酰胆碱，而且在食物被吃下时毒素就已经存在了。

处理遵循国家指南。肉毒中毒是公共卫生紧急事件，疑似病例要立即报告，以查找食物来源和其他可能受累的人。治疗包括支持治疗，密切监测呼吸（因为可能发生呼吸衰竭），以及尽早使用**抗毒素**。抗毒素能中和循环中的毒素，但不能逆转已经与神经结合的毒素，这就是早期治疗重要的原因。恢复需要长出新的神经末梢，可能需要数周到数月。
:::
:::

## 细菌遗传学 {#genetics}

细菌是单倍体且分裂迅速，因此一个新的突变如果带来生长优势，可以在数小时内在菌群中扩散。单靠突变就能解释某些耐药，例如结核分枝杆菌对单个药物的逐步耐药。但细菌的大部分进化是通过获得其他细菌中已有的基因来实现的。

::: definition 水平基因转移 {#def-hgt}
**水平基因转移**是指DNA在细菌之间的转移，而不是从亲代细胞传给子代细胞。有三种机制：

- **转化**：细菌从周围环境中摄取死亡细胞释放的游离DNA。肺炎链球菌和奈瑟菌属（*Neisseria*）能自然地进行转化。
- **转导**：**噬菌体**（感染细菌的病毒）把细菌DNA从一个细胞带到另一个细胞。
- **接合**：两个细菌通过性菌毛接触，一方把质粒的拷贝传给另一方。接合性质粒可以在不同菌种之间转移。

可移动遗传元件使这些转移更为高效。**转座子**可以在染色体和质粒之间跳跃。**整合子**以基因盒的形式捕获耐药基因并把它们排列起来加以表达。
:::

噬菌体介导的转移解释了为什么有些细菌只有携带某种特定病毒时才是危险的。**白喉毒素**的基因由噬菌体携带；没有这种噬菌体的白喉棒状杆菌（*Corynebacterium diphtheriae*）菌株不产生毒素。大肠埃希菌O157的**志贺毒素**基因和霍乱弧菌（*Vibrio cholerae*）的**霍乱毒素**基因也由噬菌体携带。噬菌体整合到细菌染色体上并以这种方式改变宿主菌特性的现象称为**溶原性转换**。

接合解释了现代抗生素耐药为什么扩散得如此之快。一个质粒可以同时携带对几类抗生素的耐药基因。使用其中任何一种抗生素都会选择出整个质粒。携带超广谱β-内酰胺酶（ESBL）或碳青霉烯酶基因的质粒，可以在同一名患者的肠道内从大肠埃希菌转移到肺炎克雷伯菌（*Klebsiella pneumoniae*），[[microbiology/antimicrobials]]对此有所描述。

::: example 外科病房中的耐药质粒 {#ex-plasmid}
三个月内，一个外科病房从五名患者中分离出耐碳青霉烯类的细菌。其中两例为肺炎克雷伯菌，两例为大肠埃希菌，一例为阴沟肠杆菌（*Enterobacter cloacae*）。分型显示这些细菌是互不相关的菌株，但都在同一个质粒上携带相同的碳青霉烯酶基因。这是怎么回事？为什么这会改变调查的方向？
::: solution
不同菌种、互不相关的菌株却携带相同的质粒，提示这是一次**质粒暴发**：耐药基因是通过接合在细菌之间传播的，而不是一个克隆在患者之间传播。

这改变了感染控制团队的调查方向。克隆性暴发提示同一种细菌在患者之间传播，常经手或器械传播。质粒暴发还可能涉及共同的环境储存库，例如水槽下水道，许多菌种在那里的生物膜中相遇并交换质粒。团队会筛查接触者，检查手卫生和清洁情况，并对水槽和下水道采样。揭示这种模式的工具是质粒分型，现在通常用全基因组测序完成；仅靠菌种鉴定会漏掉这一点。
:::
:::

## 致病的细菌 {#pathogens}

实用的分类从革兰染色和形态开始，再加上需氧情况和几项简单试验。在现代实验室中，最终鉴定通常采用**MALDI-TOF质谱**，它根据细菌蛋白质的图谱识别菌种，但传统的分组仍然是组织临床思维的框架。下面列出医学生应当认识的病原菌。

::: definition 革兰阳性球菌 {#def-cocci}
**葡萄球菌**呈葡萄串状排列，**触酶阳性**。

- 金黄色葡萄球菌**凝固酶阳性**。它引起皮肤软组织感染、脓肿、菌血症、心内膜炎、骨与关节感染，以及毒素性疾病（食物中毒、中毒性休克综合征、葡萄球菌烫伤样皮肤综合征）。耐甲氧西林的菌株称为**MRSA**。
- **凝固酶阴性葡萄球菌**，如表皮葡萄球菌（*S. epidermidis*），栖居于皮肤。它们感染人工植入物和血管内导管，是血培养中最常见的污染菌。腐生葡萄球菌（*S. saprophyticus*）引起年轻女性的尿路感染。

**链球菌**呈成对或链状排列，**触酶阴性**。按血琼脂上的溶血类型和兰斯菲尔德表面抗原分组。

- **β溶血**（完全溶血）：化脓性链球菌（*S. pyogenes*，A群）引起咽炎、蜂窝织炎、坏死性筋膜炎和猩红热，其后可发生风湿热和肾小球肾炎等免疫性并发症；无乳链球菌（*S. agalactiae*，B群）引起新生儿脓毒症和脑膜炎。
- **α溶血**（不完全的绿色溶血）：肺炎链球菌呈矛头状双球菌，引起肺炎、中耳炎、鼻窦炎和脑膜炎；口腔中的**草绿色链球菌**引起心内膜炎。
- **肠球菌**（粪肠球菌（*E. faecalis*）、屎肠球菌（*E. faecium*））栖居于肠道，引起尿路、胆道和导管相关感染。它们对头孢菌素类天然耐药。
:::

::: definition 革兰阳性杆菌 {#def-gprods}
- **形成芽孢的厌氧菌**：破伤风梭菌（破伤风）、肉毒梭菌（肉毒中毒）、产气荚膜梭菌（气性坏疽和食物中毒）以及艰难梭菌（抗生素相关性结肠炎）。
- **形成芽孢的需氧菌**：炭疽芽孢杆菌（炭疽）和蜡样芽孢杆菌（食物中毒）。
- 单核细胞增生李斯特菌（*Listeria monocytogenes*）：一种经食物传播的胞内菌，可在孕妇、新生儿、老年人以及细胞免疫受损者中引起脓毒症和脑膜炎。与肠球菌一样，它对头孢菌素类天然耐药。
- 白喉棒状杆菌：通过噬菌体编码的毒素引起白喉。
- **分枝状杆菌**：诺卡菌属（*Nocardia*）（在免疫功能低下者中引起肺、脑和皮肤感染）和放线菌属（*Actinomyces*）（引起伴窦道的慢性脓肿）。
:::

::: definition 革兰阴性菌 {#def-gneg}
**球菌**：脑膜炎奈瑟菌（*Neisseria meningitidis*）（脑膜炎和败血症）、淋病奈瑟菌（*N. gonorrhoeae*）（淋病）和卡他莫拉菌（*Moraxella catarrhalis*）（中耳炎、慢阻肺急性加重）。奈瑟菌呈肾形双球菌。

**杆菌**分为几组：

- **肠杆菌目**，肠道中的兼性厌氧菌：大肠埃希菌、克雷伯菌属、肠杆菌属、变形杆菌属、沙雷菌属、沙门菌属、志贺菌属和耶尔森菌属。它们引起尿路感染、腹腔感染、菌血症和胃肠炎，是ESBL和碳青霉烯酶基因的主要携带者。
- **非发酵菌**，存在于水和医院环境中的需氧菌：铜绿假单胞菌和鲍曼不动杆菌（*Acinetobacter baumannii*）。它们对许多抗生素天然耐药。
- **苛养的呼吸道杆菌**：流感嗜血杆菌（*Haemophilus influenzae*）、百日咳鲍特菌（*Bordetella pertussis*）（百日咳）和嗜肺军团菌（*Legionella pneumophila*）（军团病）。
- **弯曲的杆菌**：弯曲菌属（英国细菌性胃肠炎最常见的病因）、幽门螺杆菌（胃炎和消化性溃疡）和霍乱弧菌。
- **厌氧菌**：脆弱拟杆菌，腹腔脓肿中最主要的厌氧菌。
:::

::: definition 革兰染色体系之外的细菌 {#def-odd}
- **分枝杆菌**：细胞壁含分枝菌酸的抗酸杆菌。结核分枝杆菌引起结核病，麻风分枝杆菌引起麻风，**非结核分枝杆菌**在有结构性肺病的人中引起肺部疾病，在晚期HIV感染者中引起感染。
- **支原体**：最小的能独立生活的细菌，没有细胞壁。肺炎支原体（*M. pneumoniae*）引起非典型肺炎，不受β-内酰胺类影响。
- **专性胞内菌**：沙眼衣原体（*Chlamydia trachomatis*）（生殖道感染和沙眼）、鹦鹉热衣原体（*Chlamydia psittaci*）、立克次体属（*Rickettsia*）（斑疹伤寒和斑点热）以及贝纳柯克斯体（*Coxiella burnetii*）（Q热）。
- **螺旋体**：细长、螺旋形、能运动的细菌。梅毒螺旋体引起梅毒，伯氏疏螺旋体（*Borrelia burgdorferi*）引起莱姆病，钩端螺旋体属（*Leptospira*）引起钩端螺旋体病。
:::

::: example 血培养中的革兰阳性球菌 {#ex-staph-bacteraemia}
一名63岁男性，经隧道式中心静脉导管进行血液透析，出现发热和寒战。抽取了两套血培养。十四小时后两套均报阳，革兰染色显示**葡萄串状排列的革兰阳性球菌**。这说明了什么？接下来该怎么做？
::: solution
葡萄串状排列的革兰阳性球菌是**葡萄球菌**。两种可能是金黄色葡萄球菌和凝固酶阴性葡萄球菌。

有三个特点提示是真正的感染而不是污染：两套均为阳性，报阳迅速，而且中心静脉导管是一个明显的感染源。在菌种明确之前，团队按可能的金黄色葡萄球菌菌血症处理，并按当地指南进行经验性治疗。

随后实验室鉴定细菌，通常用MALDI-TOF在数小时内完成，并做药敏试验，包括是否为MRSA。如果是金黄色葡萄球菌，处理原则是控制感染源（拔除导管），复查血培养以证实菌血症已清除，超声心动图检查以寻找心内膜炎，查找迁徙性感染灶，并请感染专科会诊。金黄色葡萄球菌菌血症死亡率高，因此大多数医院按规范流程处理。

如果凝固酶阴性葡萄球菌只在多套中的一套里生长，那更可能是皮肤污染菌。革兰染色提供了第一条线索；阳性套数和临床表现决定其意义。
:::
:::

::: example 脑脊液中的革兰阴性双球菌 {#ex-meningococcus}
一名19岁学生因发热、头痛、颈项强直和压之不褪色的紫癜样皮疹入院，立即给予抗生素。随后在安全时进行的腰椎穿刺显示大量中性粒细胞，革兰染色见**革兰阴性双球菌**。请解释这一结果，并说明公共卫生应对措施。
::: solution
年轻成人出现紫癜样皮疹，脑脊液中见革兰阴性双球菌，几乎可以肯定是***脑膜炎奈瑟菌***。

微生物学解释了临床过程。脑膜炎奈瑟菌有一层抗吞噬的多糖**荚膜**，其外膜释放大量内毒素，导致感染性休克以及由血管损伤引起的皮疹。由于在腰椎穿刺之前已用抗生素，培养可能为阴性；血液或脑脊液的**PCR**仍能确诊并鉴定荚膜群。

在英国，脑膜炎球菌病是法定报告疾病。公共卫生团队识别密切接触者，主要是家庭成员以及在发病前七天内有类似密切接触的其他人，并为他们提供抗生素预防以清除带菌状态。如果荚膜群属于疫苗覆盖的类型，还可为接触者提供疫苗接种。抗生素的选择遵循国家指南。
:::
:::

::: quiz
一名22岁女性有干咳、低热，胸部X线片显示斑片状改变。服用阿莫西林一周后咳嗽未见好转。哪种病原体最能解释β-内酰胺类药物为何无效？
- [ ] 肺炎链球菌，因为其荚膜阻挡了青霉素
- [x] 肺炎支原体，因为它没有细胞壁
- [ ] 流感嗜血杆菌，因为它是革兰阴性菌
- [ ] 金黄色葡萄球菌，因为它呈葡萄串状排列
::: solution
β-内酰胺类通过阻断肽聚糖合成发挥作用。支原体没有细胞壁，因此在它身上没有作用靶点。支原体是年轻成人非典型肺炎的常见病因，需用作用于蛋白质合成或DNA的抗生素治疗，按当地指南选择。肺炎链球菌的荚膜能抵抗吞噬，但不能抵抗青霉素；许多流感嗜血杆菌和金黄色葡萄球菌菌株只有在产生β-内酰胺酶时才耐药。
:::
:::

::: history
丹麦医生汉斯·克里斯蒂安·革兰（Hans Christian Gram）在柏林工作时于1884年发表了他的染色方法。他当时试图让死于肺炎者的肺组织切片中的细菌更清楚地显现出来，并谦逊地指出有些细菌不保留染料。这一观察成了细菌学中应用最广的检验。

对细菌基因的研究来得更晚。1928年，弗雷德里克·格里菲斯（Frederick Griffith）证明，无害的肺炎球菌菌株可以被死亡的有毒力细菌中的物质“转化”为有荚膜的致死菌株。1944年，奥斯瓦尔德·埃弗里（Oswald Avery）、科林·麦克劳德（Colin MacLeod）和麦克林·麦卡蒂（Maclyn McCarty）确定这种物质是DNA。约书亚·莱德伯格（Joshua Lederberg）和爱德华·塔特姆（Edward Tatum）于1946年描述了接合，诺顿·津德（Norton Zinder）和莱德伯格于1952年描述了转导。

1977年，卡尔·乌斯（Carl Woese）和乔治·福克斯（George Fox）比较了核糖体RNA序列，证明原核生物由两个截然不同的类群组成，即现在所称的细菌和古菌。16S核糖体RNA基因测序成为细菌分类以及鉴定无法培养的微生物的标准方法。
:::

## 后续内容

细菌如何黏附、侵袭和损伤组织，是[[microbiology/bacterial-pathogenesis]]的主题。正常细菌菌群见[[microbiology/microbiota]]，本章提到的从革兰染色到MALDI-TOF和测序的实验室方法在[[microbiology/laboratory-diagnosis]]中讲解。抗生素的靶点和耐药性在[[microbiology/antimicrobials]]中介绍。宿主对细菌的应答见[[immunology/innate-immunity]]，临床综合征见[[infectious-diseases/fever-sepsis]]和[[infectious-diseases/tuberculosis]]。

::: summary
- 细菌是原核生物，有70S核糖体，几乎所有菌种都有肽聚糖细胞壁；两者都是人体细胞所没有的抗生素靶点。
- 革兰阳性菌有厚的肽聚糖细胞壁而无外膜。革兰阴性菌细胞壁薄，并有含脂多糖的外膜，其脂质A即内毒素。
- 革兰染色的原理是厚的细胞壁在脱色时把结晶紫—碘复合物留在细胞内。分枝杆菌、支原体、胞内菌和螺旋体不能可靠地显示。
- 形态、排列和需氧情况能缩小范围：葡萄串状提示葡萄球菌，链状提示链球菌，恶臭的脓液提示厌氧菌。
- 指数生长时$N = N_0 \cdot 2^{t/g}$。代时解释了为什么有些培养只需数小时，而有些需要数周。
- 芽孢杆菌属、梭菌属和艰难梭菌的芽孢能耐受高温、干燥和乙醇，这决定了手卫生、清洁和食品安全的做法。
- 转化、转导和接合在细菌之间转移基因。噬菌体携带几种主要的毒素基因，质粒在菌种之间传播耐药性。
:::

## 习题

::: exercise 判读革兰染色 {level=1}
一名有脓性分泌物的男性，其尿道拭子显示许多中性粒细胞，细胞内含有革兰阴性双球菌。最可能的病原体是什么？为什么这一发现如此有用？
::: hint
哪些革兰阴性球菌成对排列？其中哪一种经性传播？
:::
::: solution
最可能的病原体是***淋病奈瑟菌***。在有症状男性的尿道标本中，中性粒细胞内见革兰阴性双球菌对淋病有很高的特异性，因此镜检可以使治疗在当天开始。仍需培养以做药敏试验，因为淋球菌耐药很常见；在多数情况下，核酸扩增试验用于诊断，也用于咽部和直肠等部位。
:::
:::

::: exercise 计算世代数 {level=1 check="3"}
在指数生长期，一份培养物从每毫升200个细胞增长到1600个细胞。经过了多少代？
::: hint
用$n = \log_2(N/N_0)$。
:::
::: solution
$N/N_0 = 1600/200 = 8$，$\log_2 8 = 3$。经过了三代。
:::
:::

::: exercise 芽孢与手卫生 {level=1}
解释为什么在有数例艰难梭菌（*Clostridioides difficile*）感染的病房里，要求工作人员用肥皂和水洗手，而不是使用含醇手消毒剂。
::: hint
想一想乙醇对芽孢有什么作用，而洗手的作用又是什么。
:::
::: solution
艰难梭菌通过**芽孢**传播，而芽孢能耐受乙醇。含醇手消毒剂能杀灭许多繁殖体细菌和有包膜病毒，但会让芽孢在手上存活下来。肥皂和流动水是通过机械作用起效的：摩擦和冲洗能把芽孢从皮肤上去除，尽管并不能杀死它们。出于同样的原因，暴发期间的环境清洁使用含氯制剂或其他杀芽孢产品。
:::
:::

::: exercise 估算倍增时间 {level=2 check="30"}
在指数生长期，一份培养物在5小时内从每毫升$10^4$个细胞增长到$10^7$个。估算以分钟计的代时，取整到分钟。
::: hint
先根据一千倍的增长求出世代数，再用经过的时间除以世代数。
:::
::: solution
增长了1000倍，所以世代数为$n = \log_2 1000 \approx 9.97$。经过的时间为300分钟，因此

$$
g = \frac{300}{9.97} \approx 30.1 \text{ 分钟}
$$

代时约为**30分钟**。一个实用的捷径是：倍增十次约等于增长1000倍。
:::
:::

::: exercise 万古霉素与β-内酰胺类为何不同 {level=2}
万古霉素对金黄色葡萄球菌有效，但对大肠埃希菌无效。阿莫西林对这两种菌的许多菌株都有效。请用细胞被膜的结构解释这一差别。
::: hint
比较两种药物的分子大小，以及它们各自到达肽聚糖必须经过的路径。
:::
::: solution
两种药物都作用于肽聚糖的合成，而肽聚糖合成发生在细胞质膜的外侧面。在金黄色葡萄球菌等革兰阳性菌中，肽聚糖暴露在表面，两种药物都能到达。

在大肠埃希菌等革兰阴性菌中，肽聚糖位于**外膜**之下。阿莫西林这样的亲水性小分子能通过**孔蛋白**进入周质间隙。万古霉素是一种大分子糖肽，不能通过孔蛋白，因此永远到达不了它的靶点。革兰阴性菌对阿莫西林的耐药通常来自周质间隙中的β-内酰胺酶，它在药物穿过外膜之后将其破坏。
:::
:::

::: exercise 获得了毒素的菌株 {level=2}
从一份咽拭子中分离出一株不产毒的白喉棒状杆菌（*Corynebacterium diphtheriae*）。一位同事说可以不予理会，因为“它永远不可能引起白喉”。这种说法正确吗？
::: hint
白喉毒素基因由什么携带？
:::
::: solution
不完全正确。**白喉毒素基因**由噬菌体携带。不产毒的菌株如果被这种噬菌体感染、噬菌体整合到其染色体上，就可能变成产毒菌株，这就是**溶原性转换**。不产毒的菌株仍可引起咽痛，偶尔引起侵袭性感染，但不会引起毒素介导的疾病。这就是为什么参比实验室要用PCR检测分离株的毒素基因并确认毒素的产生，也是为什么公共卫生应对取决于分离株是否产毒，并遵循国家指南。
:::

::: exercise 结核培养需要多长时间？ {level=3 check="17"}
假设一个液体培养系统在含有约$10^7$个细菌时报告阳性，而一份痰标本带入了10个活的结核分枝杆菌。代时为20小时、没有迟缓期时，需要多少天才能报阳？答案取整到天，然后评论这对临床医生意味着什么。
::: hint
增长了一百万倍。求出世代数，乘以20小时，再换算成天。
:::
::: solution
增长倍数为$10^7/10 = 10^6$，所以世代数为$n = \log_2 10^6 \approx 19.9$。

$$
t = 19.9 \times 20 \approx 399 \text{ 小时} \approx 16.6 \text{ 天}
$$

取整约为**17天**。这个模型是简化的：真实的培养有迟缓期，标本中的许多杆菌可能并无活力，因此实际观察到的时间往往更长。实践中，涂片阳性的标本可能在两周左右报阳，而菌量少的标本可能需要更久，培养要保留约六周才能报告阴性。

对临床医生来说，等待培养结果太慢，无法指导最初的决策。治疗常常根据临床表现、显微镜检查和快速分子检测开始，后者可在数小时内检出结核分枝杆菌DNA和关键的耐药突变。培养对于完整的药敏试验仍然必不可少。
:::
:::

::: exercise 新生儿脑膜炎的革兰染色 {level=3}
一名出生10天的婴儿出现发热和前囟膨隆，脑脊液中性粒细胞计数升高。列出这一年龄段细菌性脑膜炎的三种经典病原体及各自的革兰染色表现，并解释为什么其中一种会影响经验性抗生素的选择。
::: hint
想一想分娩时从母亲生殖道和肠道菌群中获得的细菌，以及对头孢菌素类的天然耐药。
:::
::: solution
出生后最初几周的三种经典病原体是：

- **B群链球菌**（无乳链球菌（*Streptococcus agalactiae*））：成对和链状排列的革兰阳性球菌；
- ***大肠埃希菌***，尤其是带K1荚膜的菌株：革兰阴性杆菌；
- ***单核细胞增生李斯特菌***：短小的革兰阳性杆菌，有时被误认为类白喉杆菌或球菌。

李斯特菌对头孢菌素类天然耐药。单用头孢菌素可以覆盖B群链球菌和大多数大肠埃希菌，却会漏掉李斯特菌，因此小婴儿脑膜炎的经验性方案要加用阿莫西林（amoxicillin）等药物，遵循国家和当地指南。革兰染色如果见到细菌，就可以在等待培养和药敏结果期间缩窄治疗范围。
:::
