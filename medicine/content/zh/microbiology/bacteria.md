细菌学最好被当作一部“形态、染色与策略”的目录来学：**革兰的反应、对氧的偏好、加上几手毒力的花招、就能预测多数临床综合征、正确的标本、经验性的药物、以及隔离的预防措施。**本章走过有医学重要性的细菌、按形态与染色组织、并带着决定谁伤害谁、以及如何被发现的结构。
本章涵盖细菌的结构与分类、革兰阳性的球菌与杆菌、革兰阴性的诸科、非典型与螺旋体、以及由每一分组随之而来的抗菌治疗的含义。

## 结构与分类

::: definition 细菌的身体方案 {#def-structure}
**被膜决定了大部分的事（革兰阳性那厚厚的肽聚糖、带磷壁酸、无外膜、这就是为什么它们保留结晶紫、以及为什么万古霉素与β内酰胺对它们如此有效；而革兰阴性有内膜、薄的肽聚糖、以及带脂多糖、孔蛋白、以及“β内酰胺酶潜伏的周质空间”的外膜——这就是为什么它们的药物清单更短、而它们的内毒素休克更重——TLR4与CD14与MD2的生物学见[[immunology/innate-immunity]]、通透性与外排作为耐药机制见[[microbiology/antimicrobials]]）；表面的武器以及它们造成的病（抗吞噬并定义了“有荚膜的微生物”的荚膜——肺炎链球菌与b型流感嗜血杆菌与脑膜炎球菌、以及无脾患者的噩梦——[[immunology/innate-immunity]]、[[blood/haematopoiesis]]；A蛋白与M蛋白与IgA蛋白酶、以及器械与心瓣及关节上的生物膜——器械的生物学见[[infectious-diseases/healthcare-infections]]、人工关节见[[musculoskeletal/inflammatory-arthritis]]）；作为“病程的作者”的毒素（带A-B结构的外毒素——破伤风与肉毒的神经毒素作用于相反的突触、白喉与志贺毒素以不同的切口让核糖体停摆、霍乱毒素锁死腺苷酸环化酶——以及超抗原——中毒性休克综合征毒素1与葡萄球菌的肠毒素及链球菌的热病外毒素、在沟槽之外交联主要组织相容性复合体二类、造成中毒性休克的皮疹与休克——[[infectious-diseases/fever-sepsis]]；以及与细胞壁相邻的炎症——脂质A的内毒素、胞壁肽、革兰阳性的脂磷壁酸、以及为什么细菌性脑膜炎的脑脊液在微生物死掉之后仍会伤害海马、这就是为什么指南里要有地塞米松）；以及分类的捷径形态与排列、氧与生长的要求、氧化发酵与凝固酶及触酶及尿素酶及吲哚的试验——如今部分被质谱取代、见[[microbiology/laboratory-diagnosis]]——以及为无法培养成员准备的16S核糖体RNA测序。**
:::

## 革兰阳性的微生物

::: definition 葡萄球菌与链球菌 {#def-cocci}
**金黄色葡萄球菌作为那个“典范的病原菌”凝固酶阳性、A蛋白、以及“凝聚因子”这套毒力的工具箱、以及皮肤与软组织的统治——从毛囊炎到坏死性筋膜炎——[[musculoskeletal/skin]]、[[surgery/wounds-surgical-infection]]；深在的综合征——菌血症伴其向骨、关节、心瓣与肾的转移性种植、以及那条“找到源头”的戒律（导管、心、骨、脓肿、以及医院与社区的菌株的耐甲氧西林的流行病学、伴杀白细胞素相关的坏死性肺炎；以及毒素的综合征——由预先形成的肠毒素造成的食物中毒、其潜伏期很短、婴儿的烫伤样皮肤的剥脱毒素、以及那段与卫生棉及伤口相关的中毒性休克的病史——金黄色葡萄球菌的控制对中性粒细胞的依赖见[[immunology/innate-immunity]]、湿疹与冷脓肿的关联见[[immunology/immunodeficiency]]）；凝固酶阴性的葡萄球菌（人工关节、心瓣、起搏器与导管上的生物膜大师、带着它们多重耐药的习性、以及那条判读的规则：培养出一次阳性的表皮葡萄球菌通常意味着皮肤的污染、除非图景吻合——一句既防止漏掉器械感染、又防止十天无谓万古霉素临床推理的箴言——[[clinical-skills/clinical-reasoning]]、[[microbiology/laboratory-diagnosis]]）；以及按兰斯菲尔德分群的链球菌A组的化脓性链球菌——咽炎与其非化脓性的后遗症：风湿热与感染后肾小球肾炎、以及化脓性的蜂窝组织炎、坏死性筋膜炎与产褥的脓毒症、加上风湿性心脏炎的分子模拟（[[cardiovascular/valve-congenital-disease]]）与产褥的病史（[[obstetrics-gynaecology/labour-birth]]；B组的无乳链球菌的早发对晚发的新生儿疾病、以及产时筛查与预防的规划——[[paediatrics/newborn]]、[[obstetrics-gynaecology/labour-birth]]；草绿色链球菌群带着它们的牙生物膜与培养阴性的心内膜炎、及中性粒细胞减少的菌血症与黏膜炎的关联——[[infectious-diseases/immunocompromised-host]]；肠球菌带着它们胆盐七叶苷的阳性、它们院内的尿路与胆道及外科的习性、它们内在的头孢菌素耐药、以及它们的万古霉素耐药与利奈唑胺耐药的年代——耐药见[[microbiology/antimicrobials]]与[[infectious-diseases/healthcare-infections]]；以及肺炎链球菌——枚矛枪形的、有荚膜的双球菌、造成中耳炎、鼻窦炎、社区获得性肺炎、脑膜炎、以及在脾缺失者身上那场暴发性脓毒症）。**
:::

::: definition 革兰阳性的杆菌与产芽孢的那一类 {#def-gprods}
**“用毒素制造自己疾病”的厌氧产芽孢菌（艰难梭菌——被抗生素扰乱菌群伴其A与B两种肠毒素与细胞毒素的结肠炎、以及易复发的迁延病程、完整内容见[[gastrointestinal/bowel-disease]]与[[microbiology/microbiota]]；破伤风——其逆行运输的破伤风痉挛毒素阻断抑制性中间神经元的胞吐、以及牙关紧闭与苦笑及角弓反张的痉挛、脏伤口与疫苗接种状态之问、免疫球蛋白与甲硝唑及苯二氮与呼吸机的管理、以及“每一个发生在可接种者身上的病例”桩公共卫生的耻辱——[[public-health/vaccination-programmes]]；肉毒——其由胆碱能接头处突触前的可溶性N乙基马来酰亚胺敏感的神经因子附着蛋白被切割所造成的下行性麻痹、家庭罐装与蜂蜜及伤口及婴儿形式、球脑与呼吸的衰竭而感觉与神志保留、以及抗毒素要在麻痹完成之前给；气性坏疽——α毒素的肌坏死与捻发音、以及“外科清创压倒一切”这条规则——[[surgery/trauma]]、骨髓炎的邻近见[[musculoskeletal/bones-joints]]）；需氧的那一排白喉棒状杆菌——其由β噬菌体编码的毒素、道可以造成梗阻的假膜、以及心肌病与神经病的后遗症、类毒素疫苗的凯旋、以及“输入的病例让问题重新醒来”之问——[[public-health/vaccination-programmes]]；单核细胞增多性李斯特菌作为那个食源的、细胞内的寄生虫、侵袭妊娠、新生儿、65岁以上者、以及细胞免疫受损者、带着它的脑膜炎与菱脑炎、以及“革兰染色阴性、弯曲菌阳性”这类冷知识、以及它的氨苄西林的治疗与“头孢菌素内在耐药”这个陷阱——[[obstetrics-gynaecology/pregnancy-complications]]、[[infectious-diseases/immunocompromised-host]]、[[microbiology/antimicrobials]]；炭疽芽孢杆菌——其吸入型的纵隔经典、以及毒素的“水肿因子与致死因子”的生物学、及生物恐怖的编排——[[respiratory/respiratory-infections]]；以及环境的机遇者诺卡——弱抗酸的、分支的土壤细菌、在移植患者中造成肺、中枢与皮肤的疾病、用复方磺胺治疗数月——[[infectious-diseases/immunocompromised-host]]、脑脓肿见[[nervous-system/neuroinflammation]]。**
:::

## 革兰阴性与非典型

::: definition 革兰阴性的诸科 {#def-gneg}
**肠杆菌（大肠埃希菌作为分子生物学的工作场所、以及尿、血流、新生儿脑膜炎与腹泻性疾病的头名、带着它从肠毒性型“旅行者的腹泻”到产志贺毒素的O157出血性大肠炎伴溶血尿毒综合征——[[renal/acute-kidney-injury]]——再到肠致病性与肠聚集性型的各病原型、以及它超广谱酶与AmpC及“黏菌素耐药的碳青霉烯酶”的那场流行——[[microbiology/antimicrobials]]；肺炎克雷伯菌那荚膜沉重的肺炎与肝脓肿及器械的习性、以及它作为碳青霉烯酶震中的身份；肠杆菌属与沙雷菌属伴可诱导的AmpC；伤寒沙门菌带着它的肠热与慢性的胆囊携带、及Vi多糖的疫苗、以及非伤寒沙门菌的食源胃肠炎伴其与HIV及营养不良相关的侵袭型——[[infectious-diseases/hiv]]；志贺菌那10个微生物的感染剂量与杆菌性的痢疾、及溶血尿毒综合征的邻近；变形菌的鸟粪石结石；以及小肠结肠炎耶尔森菌的假阑尾炎——[[gastrointestinal/bowel-disease]]）；那些不发酵乳糖的怪客（铜绿假单胞菌带着它的绿脓菌素色素、它的生物膜、以及它囊性纤维化气道的适应——[[respiratory/asthma-copd]]：它的热水池毛囊炎、糖尿病者的恶性外耳道炎、烧伤与中性粒细胞减少的脓毒症、以及它那张内在耐药的清单；鲍曼与嗜麦芽窄食单胞菌作为重症监护病房物体表面的常住者——[[emergency-critical-care/critical-care]]、[[infectious-diseases/healthcare-infections]]）；奈瑟菌（脑膜炎奈瑟菌带着它的飞沫传播与群体的休眠、它的淤点性脓毒症伴沃特豪斯-弗里德里克森综合征、以及与补体末端通路缺陷的关联——[[immunology/innate-immunity]]、[[endocrine/adrenal]]；淋病奈瑟菌见[[infectious-diseases/sexually-transmitted-infections]]）；b型流感嗜血杆菌与不可分型的气道疾病、带着那个疫苗成功的故事——[[respiratory/asthma-copd]]、[[public-health/vaccination-programmes]]；百日咳博德特菌带着它麻痹气道纤毛的毒素、百日咳、以及婴儿的呼吸暂停的致死性、及青少年母亲免疫消退与“包茧”的政策之争——[[paediatrics/immunisation]]；以及空肠弯曲菌（格林-巴利与反应性关节炎的触发者——[[nervous-system/motor-systems]]、[[musculoskeletal/inflammatory-arthritis]]）与幽门螺杆菌（连同它的酸生态与癌症的归因见[[gastrointestinal/oesophagus-stomach]]）。**
:::

::: definition 分枝杆菌、非典型与螺旋体 {#def-odd}
**结核分枝杆菌与它的朋友们（那层拒绝革兰染色、在罗氏培养基上长数周蜡样的分枝菌酸被膜、以及驱动着整个结核的临床与公共卫生的机器——见[[infectious-diseases/tuberculosis]]；以及非结核的分枝杆菌——晚期HIV中的鸟胞内复合群、带“温德米尔夫人”的支气管扩张表型、以及伤口与导管的快速生长者——[[respiratory/interstitial-vascular-disease]]、[[infectious-diseases/hiv]]）；专性细胞内与无细胞壁的沙眼衣原体的“原体”的双相生活、以及沙眼与性病性淋巴肉芽肿及新生儿肺炎、以及作为两端反应性关节炎、带着成对治疗的公共卫生的衣原体见[[infectious-diseases/sexually-transmitted-infections]]；肺炎嗜衣原体的轻度非典型肺炎；肺炎支原体带着它“无细胞壁”的生物学（对青霉素免疫、它的冷凝集素的溶血、以及皮疹与脑炎的关联、及它在学校里社区暴发的生态学——[[respiratory/respiratory-infections]]、[[blood/anaemia]]；立克次体与柯克斯体带着它们“亲血管”的内皮感染、以及斑点热、以及Q热与心内膜炎的关联——[[infectious-diseases/tropical-infections]]、培养阴性的心内膜炎见[[cardiovascular/valve-congenital-disease]]）；以及螺旋体（梅毒螺旋体那个暗视野的经典、与它那个定义了一个世纪的分期——[[infectious-diseases/sexually-transmitted-infections]]；伯氏疏螺旋体与莱姆病那多系统的行军、伴其面瘫、心脏阻滞、关节炎、以及“蜱的感染时间”的逻辑——[[nervous-system/neuroinflammation]]、[[cardiovascular/arrhythmias]]；以及钩端螺旋体那鼠尿的洪水与Weil病的黄疸、肾、肺的出血——[[infectious-diseases/tropical-infections]]、[[renal/acute-kidney-injury]]）。**
:::

::: example 导管、心瓣与第三组血培养 {#ex-staph-bacteraemia}
一名57岁经隧道式导管的血液透析患者出现金黄色葡萄球菌的菌血症；第3天的血培养仍阳性；超声心动正常；她有背痛与一个肿胀的膝。
::: solution
**金黄色葡萄球菌的菌血症——一种“按方案处理”的病（[[#def-cocci]]、[[infectious-diseases/healthcare-infections]]、[[cardiovascular/valve-congenital-disease]]）：这样的规则存在自有其原因——源头控制优先移除或更换导管并培养尖端、并以“对背痛做脊柱的CT与MRI”的低阈值搜寻未引流的积聚——椎体的骨髓炎与硬膜外脓肿这个陷阱、以及反复培养直到清除、第3天的阳性定义了复杂的与延长的治疗及感染科的会诊、基本上对每一位患者做超声心动经食管的、因为经胸会漏掉人工瓣膜与小的赘生物、以及按药敏在抗葡萄球菌的β内酰胺与万古霉素或达托霉素之间选择、以及骨与关节感染口服降级近年试验的微妙——[[musculoskeletal/bones-joints]]、透析的给药见[[renal/chronic-kidney-disease]]；转移性的清点——膝的穿刺找化脓性关节炎血培养阳性时绝不做“反应性”的假定、脊柱的MRI、皮肤与眼及尿的巡查、以及脾肾微脓肿的CT之问；以及治理——导管包的重新审计敷料与接头及夹闭及“刷洗那个终点”的技术、透析单元的传播筛查、耐甲氧西林隔离政策的落实、以及那项“菌血症仍带着百分之二十死亡率”的死亡审计——这个数字正当化了从14天到6周的方案的僵性、以及复发随访——[[clinical-skills/patient-safety]]、[[microbiology/laboratory-diagnosis]]。**
:::

::: example 出皮疹与颈项强直的大学生 {#ex-meningococcus}
一名19岁的大学生被送来时意识混乱、伴不褪色的紫癜性皮疹、血压70/40、皮肤斑驳、乳酸9；全科医师当天上午因“病毒性”的症状看过她。
::: solution
**脑膜炎球菌的脓毒症——几分钟与接触者（[[#def-gneg]]、[[immunology/innate-immunity]]、[[emergency-critical-care/shock-fluids]]）：第一个小时——识别与肾上腺素与液体与抗生素“同时看”如果能建立静脉通路、甚至在转运之前立即静脉给苄青霉素或头孢曲松、以及在血流动力学不稳定时“不要为CT而延误腰穿”、以及血小板与凝血纠正及重症监护通气及肾脏替代的规划、以及C蛋白消耗紫癜暴发的机制、以及早期截肢与植皮的康复谈话——[[emergency-critical-care/critical-care]]、[[blood/haemostasis-bleeding]]；检查——血培养与聚合酶链“不要等结果”、以及在安全时脑脊液混浊的脑脊液伴中性粒细胞、低糖、高糖的经典、以及“咽拭子没有用”、以及为回答“是否成簇”之问的分群与分型——[[microbiology/laboratory-diagnosis]]；数小时之内的公共卫生机器——隔离飞沫直到用了24小时的抗生素、以及通报、以及密切接触者的名单家庭、同宿舍者、任何暴露于呼吸道分泌物的人、被插管的人员、立即用利福平或环丙沙星或头孢曲松的预防、以及为这一簇考虑的B或C或W疫苗之谈、以及那份在诚实与恐慌之间取得平衡的学校与大学的通告；以及后续——对不寻常或复发的病例做补体的筛查末端通路与备解素的缺陷、以及依库珠单医源的风险、以及无脾与肾上腺出血的氢化可的松之问[[endocrine/adrenal]]、以及那封关于“那个病毒性的上午”的全科医师的信、它教的是“不褪色的皮疹”这个教学要点——[[clinical-skills/patient-safety]]。**

::: example 上眼睑下垂的厨师 {#ex-botulism}

## 通向何处

微生物如何造成组织损伤、与炎症一起放在[[pathology/acute-inflammation]]；标本的选择与检测在[[microbiology/laboratory-diagnosis]]；药物的选择与耐药在[[microbiology/antimicrobials]]；与宿主缺陷的关联在[[immunology/immunodeficiency]]与[[infectious-diseases/immunocompromised-host]]；公共卫生的应对在[[infectious-diseases/healthcare-infections]]。

::: history
**医学细菌学是一个关于染料与肉汤及其后果的故事：革兰在1884年的结晶紫与碘的技术（他对魏格特染色的一次 modest 的改进、以及他承认自己不确定它为什么有效）、科赫1876年用炭疽证明纯培养、以及他的法则、以及那场固体培养基的革命（佩特里的平皿、以及赫塞的太太范妮贡献的琼脂）、以及1883至1884年洛夫勒与北里制备的白喉与破伤风的培养、以及1890年贝林与北里的白喉抗毒素、以及贝林的诺贝尔奖、以及那个血清治疗的年代——它同时也教会了人们什么是过敏（一战中马血清的破伤风预防造成的死亡、以及里奇与波捷的豚鼠过敏的工作、以及主动免疫的兴起）；治疗的黎明——艾利希治疗梅毒的“606号药物”与“魔法子弹”这句话、以及多马克1935年在女儿的手被感染之后展示的百浪多息、以及鲁与弗莱明这条青霉素的谱系（1928年那个霉菌与被忽视的十年、以及弗洛里与钱恩的提纯、以及深层发酵的罐子迁往皮奥里亚、以及战时的大规模生产）——[[pharmacology/drug-development-prescribing]]；耐药的序章——在病房暴发的1940年代的耐药葡萄球菌、以及在美西林引入后一年之内就检测到耐药（1961年的那个报告）、以及1977年青霉素耐药肺炎链球菌的报告、以及糖肽与利奈唑胺及达托霉素及头孢洛林年代的那场追逐、以及2000年代由克雷伯菌的欧洲克隆引起的碳青霉烯酶的流行——[[infectious-diseases/stewardship-outbreaks]]；分子重分类的年代——卡尔·乌斯“用核糖体RNA的系统发育推翻按形态的分类”、以及质谱与16S及全基因组测序的流行病学（结核的传播网、以及用单核苷酸多态计数解决的点源暴发）——[[microbiology/laboratory-diagnosis]]；以及“被遗忘的微生物”的提醒——被忽视疾病的管道政治里的麻风与查加斯与内脏利什曼、以及卡介苗那段“从花园棚屋里对一株牛型菌连续13年的减毒”、以及结核疫苗那个至今不完美的一世纪——[[infectious-diseases/tuberculosis]]、[[public-health/global-health]]。**

::: summary
- 革兰染色、对氧的需求、加上一小份毒力的词汇表就能预测综合征：无脾宿主中“有荚膜三剑客”的荚膜、梭菌诸综合征的毒素、器械上的生物膜。
- 金黄色葡萄球菌的菌血症是方案医学——源头控制、反复培养、超声心动、感染科的意见、以及由清除的那天决定的固定疗程。
- 脑膜炎球菌的疾病是一桩“通报与接触者”的急症：抗生素精确到分钟、对家庭的预防要在数小时之内。
- 认识内在耐药的陷阱：肠球菌与头孢菌素、李斯特菌与头孢菌素、支原体与所有作用于细胞壁的药、铜绿假单胞菌与半个货架。
- 毒素介导的疾病（破伤风、肉毒、白喉、中毒性休克）的进展独立于细菌的负荷——抗毒素与疫苗状态及支持治疗排在抗生素之前。
- 杀死革兰阴性的微生物会释放内毒素；预期并支持第一剂、而不是把它误读成治疗的失败。

预测微生物与经验性的治疗：(a) 糖尿病足的脓、成簇的革兰阳性球菌；(b) 脑脊液、革兰阴性的双球菌；(c) 痰、矛枪形的革兰阳性双球菌；(d) 胆汁、带丝状形态革兰阴性的杆菌。

**从染色到处方的医学（[[#def-cocci]]、[[#def-gneg]]、[[microbiology/antimicrobials]]）：(a) 金黄色葡萄球菌、包括按本地的流行率与医疗暴露判断耐甲氧西林的风险——相应地覆盖并降级、以及糖尿病足“探到骨与磁共振”的那个多种微生物的现实——[[endocrine/diabetes-complications]]、[[musculoskeletal/bones-joints]]；(b) 脑膜炎奈瑟菌——头孢曲松加上“预防与通报”的公共卫生包——[[emergency-critical-care/acute-assessment]]；(c) 肺炎链球菌——带着严重程度评分的社区获得性肺炎的路径——[[respiratory/respiratory-infections]]；(d) 胆道的肠道混合（大肠埃希菌、克雷伯菌、厌氧菌、以及梭菌属）、带着“哌拉西林他唑巴坦、或头孢曲松加甲硝唑”的逻辑、以及“梗阻要不要引流”之问——[[gastrointestinal/pancreas-biliary]]、反复胆道操作者加覆念珠菌见[[microbiology/fungi-parasites]]；以及那条普适的规则——染色指导第一小时的治疗、而培养与敏感性及临床病程指导第三天——[[clinical-skills/clinical-reasoning]]。**

::: exercise 选择经验性的治疗 {level=1}
写出第一小时的抗生素：需要重症监护的社区获得性肺炎；伴肛周疼痛的中性粒细胞减少的脓毒症；伴休克的产褥热；以及透析导管的脓毒症。
::: solution
**按综合征的经验治疗（[[#def-cocci]]、[[#def-gneg]]、[[microbiology/antimicrobials]]、[[infectious-diseases/fever-sepsis]]）：重症的社区获得性肺炎——β内酰胺加大环内酯或呼吸氟喹诺酮，覆盖肺炎链球菌与非典型及军团菌的理由、流感后空洞型的加覆耐甲氧西林、以及铜绿的风险分层——[[respiratory/respiratory-infections]]；中性粒细胞减少——哌拉西林他唑巴坦或头孢他啶这条抗铜绿的骨架、导管或皮肤或低血压时加万古霉素、而肛周疼痛需要紧急的磁共振与外科会诊来覆盖厌氧与革兰阴性、因为中性粒细胞减少的脓毒症会藏着一个外科的源头——[[infectious-diseases/immunocompromised-host]]；产褥——克林霉素加庆大霉素加氨苄西林覆盖A组链球菌与李斯特菌及肠道阴性杆菌及厌氧菌、并搜寻残留的妊娠产物与子宫内膜炎及盆腔的感染性血栓——[[obstetrics-gynaecology/labour-birth]]；导管脓毒症——万古霉素或替考拉宁、按严重程度加革兰阴性的覆盖、按微生物与囊袋感染决定导管的移除、以及在试图保留时使用抗生素的封管——[[renal/chronic-kidney-disease]]、采集培养的时机见[[microbiology/laboratory-diagnosis]]；以及管理的那层包装——尽可能先培养、在48到72小时依据敏感性报告与本地的药敏图降级——[[infectious-diseases/stewardship-outbreaks]]。**

::: exercise 处理那处慢性的伤口 {level=2}
一名62岁的糖尿病足溃疡在6周内的两次拭子都长出铜绿假单胞菌；病房希望给6周的静脉抗生素、“因为它长出来了”。请推理。
::: solution
**定植对感染的医学（[[#def-gneg]]、[[endocrine/diabetes-complications]]、[[microbiology/antimicrobials]]）：判读——浅表拭子反映的是生物膜的定居者、而深部的组织与骨定义了感染探到骨、以及磁共振与骨活检的培养这个金标准、以及“从慢性伤口的一份拭子里得到单一微生物”这个证据问题、以及多种微生物的现实；治疗的决定——支柱优先：清创与减压与灌注及血糖的控制、以及抗生素针对临床感染的严重程度与深度口服的环丙沙星这一抗铜绿的选项、以及它的肌腱与大血管及QTc及耐药的代价、以及骨髓炎的疗程的比较讨论、以及高压氧与局部制剂的证据分级——[[cardiovascular/vascular-disease]]、神经病变的足见[[nervous-system/sensory-systems]]；耐药的责任——抗铜绿的选择压在局部筛选出耐药把病房的铜绿的敏感性趋势作为共同的指标、以及“绝不用静脉给药去压制一处定植的伤口”这个反射、以及带照片与测量的伤口门诊的路径、好让轨迹看得见；以及关于截断的诚实——感染而缺血的肢体决定树、防止截肢的多学科团队、以及康复与义肢及五年死亡率的那个背景——[[surgery/vascular-urological-surgery]]、有时随这个问题一起来的治疗目标谈话见[[geriatrics-palliative/palliative-care]]。**

::: exercise 预防那场暴发 {level=2}
一个月里同一病房有3名患者长出产碳青霉烯酶的大肠埃希菌；一名死亡。你在72小时内做什么？
::: solution
**暴发控制的医学（[[#def-gneg]]、[[infectious-diseases/stewardship-outbreaks]]、[[microbiology/infection-control]]）：0到24小时——病例的发现对接触者做现况的直肠与伤口的筛查、并配本地实验室能力的规划、基于传播途径的预防单人间或同组安置、隔离衣手套与围裙、专用的设备、以及固定点的护理编班、以及用合适或杀芽孢制剂的环境深度清洁、以及水池与排水口及水龙头的调查、以及抗生素的停用与审计同一天内对碳青霉烯处方者的反馈；24到72小时——基因流行病学送检分离株做全基因组测序、以区分共享来源的一簇与并行的演化——那个“相差0到10个单核苷酸多态”的论证、以及源头的复查内镜与十二指肠镜、制冰机、手卫生依从的观察、以及病房流向与人员连续性的审查、以及对家属的沟通与死亡回顾的安排、以及政策的那一行去定植有限的现实、筛查退出的标准、转运的限制、以及接收医院的通报职责——区域网络的义务——[[clinical-skills/patient-safety]]、[[public-health/communicable-disease-control]]；以及事后——管理的干预碳青霉烯的受限与“必须审查”、以及肠道阴性杆菌菌血症口服降级的证据、与新发邻近的预防规划对高危转运史的入院筛查、以及带时间线的事件学习报告、以及对筛查依从的审计、因为这类控制是后勤加上诚实——[[microbiology/antimicrobials]]、[[infectious-diseases/healthcare-infections]]。**
