你体内的每一个细胞都携带一部32亿字母文本的两份拷贝，分装成长短极不均衡的46卷，折叠进直径六微米的细胞核。绝大多数折叠是正确的。本课程讨论的疾病来自文本与卷册出错的方式：一个字母被替换、一段被删除、整卷增减、一章在卷与卷之间互换，或者一卷沿单一亲代被复制两次、又因来源亲本而被沉默。

本章是地图与机器：基因组由什么构成、如何包装、细胞分裂与受孕时如何分配，以及错误为何并非随机分布，而是跟随染色体的几何学与卵子的生物学。

## 基因组及其包装

人核基因组约$3.2 \times 10^{9}$ bp，组织为23对染色体：22对常染色体与1对性染色体。单倍数$n = 23$；体细胞为二倍体，$2n = 46$。一个典型的二倍体细胞核因此把约6米长的DNA压缩进直径6 µm的球体，压缩约一万倍。

::: definition 染色体结构与显带 {#def-chromosome}
中期染色体由两条姐妹染色单体在**着丝粒**处相连构成；短臂记作**p**（petit），长臂记作**q**。显带经染色（G显带）产生，自着丝粒向外编号，故11p15.5指11号染色体短臂1区15带的第5亚带——一个精确的地址，也是细胞遗传学报告描述缺失的方式。**端粒**以TTAGGG重复与shelterin蛋白封闭末端；**近端着丝粒染色体**（13、14、15、21、22）在短柄上携带随体与rRNA基因，是彼此可以融合的染色体。
:::

染色体内容极不均衡。基因密度在19号与17号染色体富含基因、富含GC的条带最高，而在4号染色体大片富含AT的长臂最低；Y染色体基因稀少，其男性特异区含决定睾丸发生与精子生成的基因，缺失导致不育。仅约1–2%的基因组编码蛋白；其余是调控序列、结构序列（着丝粒卫星、端粒重复），以及——按总量计的——**重复DNA**，其临床意义远大于其名：

- **转座元件**：LINE-1与*Alu*序列占基因组很大比例。它们并非惰性。一个LINE-1元件的插入在一位携带者母亲的儿子中引起了B型血友病，*Alu*插入也造成了其他少数疾病。元件在基因组不同位置的拷贝之间发生**不平衡交换**，是许多复发性微缺失的机制。
- **拷贝数变异（CNV）**：从一千碱基对到数百万碱基对的片段缺失、重复与插入。有些常见而无害；有些致病。报告中“意义未明的CNV”陈述的是人群数据不足，而非此发现不重要。
- **节段重复**：几乎完全相同的区块，常含旁系同源基因与假基因。凡基因组携带同一序列的两个高度相似拷贝之处，减数分裂配对就可能滑移。

::: definition 基因组病与NAHR {#def-genomic}
**基因组病**指染色体片段拷贝数改变引起的疾病，通常源于**非等位同源重组（NAHR）**：减数分裂中两条染色体在节段重复块处错位配对，错配构型中的交换使一条染色单体缺失一段、另一条重复一段。推论有二。其一，同一复发性缺失在不同家庭反复出现、大小与断点完全相同，这就是Williams、DiGeorge（22q11.2）与Prader-Willi/Angelman等综合征共享区间的原因。其二，携带互补重复的亲本可能传递、或自身表现出相关而不同的表型。
:::

## 两种分裂方式

::: definition 有丝分裂与减数分裂 {#def-division}
**有丝分裂**产生两个彼此相同、也与母细胞相同的二倍体子细胞：DNA复制一次、分离一次，后期姐妹染色单体分开。
**减数分裂**经**一次**复制后的**两次**分裂，由一个二倍体细胞产生单倍体配子。前期Ⅰ中同源染色体沿全长配对成二价体，形成联会复合体，非姐妹染色单体之间的**交换**形成交叉——互换的可见证据，遗传重组的物理基础。后期Ⅰ分开的是*同源染色体*（姐妹保持在一起）；减数分裂Ⅱ分开姐妹。故单倍体配子携带每对染色体中的一条，每条都是其来源两条的嵌合马赛克。
:::

重组并不均匀。着丝粒处与近端粒处受抑制，在主要由*PRDM9*编码的锌指蛋白结合位点定义的“热点”升高，且性别有别——女性图谱交换更少、更靠近端粒，这也有助于解释母源不分离率更高（见[[#thm-nondisjunction]]）。平均每个二价体约一至两次交换，每次减数分裂全基因组约35次，使$2^{23}$种可能配子各自再增添变异。

遗传图距由重组定义：1厘摩（cM）是平均观察到1%重组的距离。由于双重交换恢复亲本构型，观察重组分数$r$低估真实距离并在0.5处饱和——这就是不连锁位点与相距极远的连锁位点都给出$r = 0.5$的实际原因。

::: widget plot
f: 50*(1-exp(-x/50)); 0.5*x
x: 0, 200
y: 0, 55
labels: \text{观察重组率}; \text{图距（线性）}
caption: 重组分数$r$（百分数）对以厘摩计的真实图距。距离小（直线，$r \approx d/2$）时连锁几乎可直接测量；距离增大时，双重交换及更高阶交换掩盖了互换，$r$趋近50%——与不连锁位点无从区分。两个坐标轴在临床上都有意义：距疾病基因5 cM的标记在约2.5%的减数分裂中“出错”，这正是使用连锁检测（而非突变检测）时必须向家系说明的残留风险。
:::

::: theorem 不分离与母龄 {#thm-nondisjunction}
染色体不分离的频率随母龄急剧上升，主要原因是卵母细胞在减数分裂开始后数十年才完成分裂；父龄对非整倍体贡献甚微，却确实增加新的点突变。
:::

::: proof
初级卵母细胞进入减数分裂后停滞于前期Ⅰ，出生前即已如此，直至排卵才继续——对一位40岁女性而言是停滞约四十年。维系姐妹染色单体臂的连合蛋白在胎儿期复制时装载，停滞期间不被更换；其缓慢流失削弱了维持二价体正确双定向的物理联系，抵抗同源染色体过早分离的交叉也被逐步解除。卵母细胞的纺锤体组装检查点也比体细胞更宽容，故错误定向的二价体仍可被放行。因此错误率随停滞时长上升，且多发生于减数分裂Ⅰ（产生含两条同源体的配子），多于减数分裂Ⅱ。相比之下，精原细胞在成年期持续分裂；每次分裂都有复制错误之险，而具增值优势突变的自更新干细胞会克隆扩张——这就是软骨发育不全（*FGFR3*）与多发性内分泌肿瘤2B型（*RET*）等新发显性点突变病随父龄升高，而三体不随父龄升高的原因。
:::

受精时若发生过不分离，合子该对染色体有三条（**三体**）或没有（**nullisomy，零体**）。此类孕绝大多数流产：三体在自然流产中占比很大，而能活产三体却限于少数染色体——21、18、13与性染色体——因为更大的染色体携带太多基因、无法耐受三剂量。若错误发生在受精后最初几次有丝分裂，结果是**嵌合体**：一个个体两种以上细胞系，其比例因组织而异，从而决定表型之轻重。三体系也可被清除——**三体拯救**——若余下两条恰好来自同一亲本，结果即**单亲二体**（UPD）：除非该染色体有印记、或双亲的两条同源体携带同一隐性变异，否则悄无声息。

::: example 复发流产与健康的母亲 {#ex-translocation}
一对夫妇四次妊娠丢失、一个健康儿子。流产产物核型示非均衡染色体组成；母亲核型46,XX,t(4;12)(q21;q23)——平衡相互易位。请解释流产，并说明选项。
::: solution
易位携带者减数分裂时，两条正常染色体与两条衍生染色体会联成**四价体**。分离可为*交替式*——正常加平衡易位，两者均存活——或*邻近式*，产生对一段部分三体、对另一段部分单体的配子。交替式分离恰是最少见的结局，这就是多数孕流产的原因；而活产染色体非均衡孩子的风险仍真实存在（经验上相互易位约自几个百分点至20%，视染色体与断点而定，个别易位风险异常高）。可讨论的选项：自然受孕加早期介入性产前诊断（11–13周绒毛取样或羊水穿刺，胎儿标本核型/微阵列）；试管婴儿加染色体结构重排的植入前检测——选出均衡（或正常）组成的胚胎，降低但不消除丢失之险，且须注意部分结果报告“嵌合”而信息不全；配子捐赠；或收养。还要注意儿子核型将告诉你什么：他或是完全正常，或是像母亲一样的平衡携带者，只有后者有生育风险。家中谁应被提供检测，由遗传科决定，而非实验室报告。
:::
:::

::: example 一根在家族中传递的额外染色体 {#ex-robertsonian}
一名3岁Down综合征患儿有46条染色体：一条正常21号、一条正常14号，以及一条由14q与21q相连构成的染色体。其母健康。诊断是什么？什么决定再发风险？
::: solution
患儿患**易位型Down综合征**，源于14与21的罗伯逊（整臂）融合：他有21q关键区三个拷贝——表型由此而来——却只有46条染色体。决定性问题在于该融合是新发还是遗传自携带亲本。若母亲核型为45,XX,der(14;21)，即她为平衡罗伯逊携带者：她的每个卵母细胞要么得到衍生染色体、要么得到正常21号（以及正常或缺失的14号），而21零体不能存活这一事实主导了理论概率，故母源携带者生育Down综合征活产儿的实际风险约10–15%（父源携带者较低，仅几个百分点）。若母亲核型正常，则融合发生于某一亲本的生殖细胞或早期合子，再发风险低（约1%，已计入性腺嵌合）。同一诊室还应谈两点：21q21融合（21;21易位）致风险孕100%，因为所有可存活孕都继承衍生染色体——这正是超声与血清筛查“正常”后仍应提供胎儿核型的原因；以及未来妊娠可行产前诊断这一事实，决定了Down综合征患儿急需的是核型而非临床印象。
:::

## 为发现命名

遗传报告使用一种紧凑的语言，误读会造成实际伤害：

| 术语 | 含义 | 临床陷阱 |
|---|---|---|
| 位点、等位基因、变异 | 一个位置；该处发现的一种序列；一个具体的序列差异 | “变异”是一项发现，不是诊断 |
| 纯合／复合杂合 | 同一改变的两次拷贝／同一基因的两个不同致病改变 | 单个杂合改变不能解释隐性病，除非第二个等位基因已被交代 |
| 半合子 | 仅一个拷贝，如男性X染色体基因或缺失区 | X连锁隐性病男性被误报“携带者”；他实为半合子且受累 |
| 嵌合 | 两种以上细胞系 | 血液检测阴性会漏掉受累组织中的嵌合变异 |
| 新发 | 先证者新发、双亲均无 | 再发风险低但非零，因性腺嵌合存在 |
| 外显率、表达度 | 表型是否出现／出现多重 | “未受累”亲代可能是未外显携带者；家族史可假性安心 |
| 46,XX与46,XY | 核型公式，可加写47,XX,+21或del(5p) | “正常”核型报告的是分辨率，不是无病 |

::: warning 正常核型不能排除遗传病，正常微阵列也不能排除平衡重排
每种检测只看见其分辨率允许之物。G显带核型检出约5–10 Mb的改变，是疑平衡易位、低比例嵌合或性染色体异常时的首选；它会整个漏掉单基因病。染色体微阵列检出低数十至数百kb的拷贝数改变——是未明发育迟缓、孤独症与多发先天异常的一线检测——却对平衡重排、多数单基因病与重复扩增病、以及常见的低水平嵌合是盲的。测序发现序列变异，但不作专门分析就看不到拷贝数、甲基化或重复长度。所以开单前要问的不是“结果正常吗”，而是“这个检测的分辨率排除了什么，我的具体假设是什么”。
:::

::: example 双亲非近亲且健康的孩子患了隐性病——却只找到一个突变等位基因 {#ex-upd}
一名β地中海贫血男孩检测出一个明确的致病*HBB*变异。其母携带此变异；其父不携带。全基因测序未见第二个变异。给出两种解释及鉴别方法。
::: solution
两种解释都关乎父源等位基因的**丢失**而非突变。(i) **11号染色体单亲二体**：经三体拯救或配子修复机制，孩子继承了两条母源11号（或11p区），使母源隐性变异功能性纯合——这是单一携带亲本家庭出现貌似显性隐性疾病的标准解释。用亲本标记或基于SNP的拷贝数/杂合性分析检测：拷贝数正常而节段性或整条染色体杂合性丢失提示UPD，若该区有印记，甲基化研究可确证。(ii) **另一等位基因缺失**：父源染色体全基因或部分*HBB*缺失只会留下一个可测变异，且对默认两份拷贝的测序是隐形的；剂量分析（MLPA或测序数据读深）可定谳。另需除外：深部内含子或调控区变异，以及罕见地——改变表达的第二、静默的*HBB*等位基因。这一教训适用于一切只找到一个突变的“隐性”病：追问第二次打击是缺失、UPD，还是检测看不见的变异。
:::
:::

## 错误从何而来，为何有些反复出现

三种机制产生多数结构性疾病，分清是哪一种在起作用即可谈论再发：

- **减数分裂不平衡交换（NAHR）**发生在错位的重复序列之间，产生复发性的、完全相同的重排——从而存在检测亲本、发现平衡携带者的可能。
- **双链断裂修复错误**——非同源末端连接及其亲戚——产生的断点无重复序列同源性，通常为一个家庭所独有，基本不复发， 断点处常有小插入或“疤痕”。
- **复制叉停滞与重启**可在一个区域内产生多断点的复杂重排（染色体碎裂与染色体合成），解释了孩子看似继承正常基因组、却有一条局部粉碎染色体的病例。

全基因组来看，每代每碱基对约$1 \times 10^{-8}$的突变率意味着一个健康新生儿相对其父母携带约60–70个新发单核苷酸改变，其中一至两个落在编码序列，零点几个百分点被预测影响蛋白功能。多数无关宏旨；少数引起显性疾病，属新发突变而非遗传风险。

::: example 一个改变咨询的数字 {#ex-hw}
某北欧裔人群囊性纤维化活产发病率约2500分之一。估计该人群携带者频率、一对无已知家族史夫妇的风险；若其中一人做了能检出88%致病*CFTR*变异的阴性检测，此估计如何改变。
::: solution
罕见常染色体隐性病发病率$q^2 = 1/2500 = 0.0004$，故等位基因频率$q = 0.02$，携带者频率$2pq \approx 2q = 0.04$——25分之一。该人群两个无亲缘个体生育患病孩子的风险$1/25 \times 1/25 \times 1/4 \approx 1/2500$，即人群发病率，理当如此。阴性检测不能把风险降为零：残留风险为此人恰是那12%检测遗漏变异之携带者的概率，即$0.04 \times 0.12$除以阴性检测的概率（约$1 - 0.04 = 0.96$），约200分之一而非25分之一。把这个数乘进夫妇的算术，所报风险改变约二十倍——这就是筛查结果须以“残留风险”报告的原因，也是不同族裔人群（变异谱与携带者频率皆不同）筛查表现更差、必须区别咨询的原因。
:::

::: quiz
一名女性携带平衡相互易位。其子发育迟缓，微阵列示微重复/微缺失模式。最能解释孩子结果的机制是？
- [ ] 节段重复之间的NAHR。
- [x] 减数分裂四价体的邻近式分离，产生染色体组成非均衡的配子。
- [ ] 减数分裂Ⅱ不分离。
- [ ] 三体拯救。
::: solution
易位携带者的四价体可以按把一条正常染色体与一条衍生染色体送入同一配子的方式分离；受精后孕体对涉及的区段部分三体、部分单体，微阵列报告为一处增加、另一处缺失。NAHR是重复序列之间*复发性*微缺失的机制；不分离改变整条染色体数目；三体拯救产生单亲二体而非节段不平衡。
:::

::: history
染色体学说很早就确立了：Sutton与Boveri在1902–1903年各自独立论证减数分裂中染色体的行为解释了Mendel定律；Morgan于1910年发现第一个X连锁突变；Sturtevant于1913年绘出第一张连锁图。此后细胞遗传学须等待技术。1956年Tjio与Levan确立人类有46条染色体；1959年Lejeune组以及独立地Jacobs与Strong鉴定出21三体；1960年Nowell与Hungerford在慢性髓系白血病中描述了一根异常小的染色体——费城染色体——1973年Rowley证明其为9号与22号染色体间的易位，最终成为伊马替尼的靶点。Caspersson与Zech在1970年代初发展的显带方法使每条染色体逐带可辨，缺失、倒位与标记染色体因此可以诊断，并且关键地可以追溯到亲本。1980年代对复发性微缺失综合征的认识，伴随荧光原位杂交的发展，产生了以分子诊断取代临床描述的检测；始于1977年的测序在1990年代进入常规诊断；2010年前后起，单细胞与二代方法使胚胎就单基因病可检，并使许多染色体“看似正常”的孩子得到诊断。
:::

## 通向何处

染色体疾病及其临床面目见[[genetics/chromosomal-disorders]]；家系中的模式见[[genetics/mendelian-inheritance]]；模式的例外见[[genetics/non-mendelian-inheritance]]；实验室如何回答问题见[[genetics/genetic-testing]]。转录与变异分类的机器见[[cell-biochemistry/gene-expression]]。

::: summary
- 基因组为3.2 Gb、23对染色体；p/q臂与条带命名给每个发现一个地址；基因密度极不均衡。
- 重复序列不是垃圾：节段重复与转座元件是NAHR的底物，从而是复发性基因组病的底物；它们的存在决定一个重排是否会在家系中复发。
- 有丝分裂制造拷贝；减数分裂一次复制两次分裂，经交换把亲本染色体打成马赛克，并使基因组减半。
- 重组分数在50%饱和，故图距与观察重组不是一回事；连锁标记从来不是突变的完美替身。
- 不分离随母龄上升，因卵母细胞在前期Ⅰ等待数十年；父龄增加的是新点突变病而非非整倍体。
- 合子后错误产生嵌合体，三体拯救可产生单亲二体——这是单一携带亲本家庭“隐性”病的一种解释。
- 每种检测只见其分辨率允许之物：核型、微阵列与测序回答不同问题；先有问题，后有检测。
:::

## 练习

::: exercise 读核型 {level=1}
写出下列核型记号：(a) 21三体女性；(b) X单体男性；(c) 5号染色体短臂末端缺失女性；(d) Klinefelter综合征男性。
::: solution
(a) 47,XX,+21。(b) 45,X。(c) 46,XX,del(5p)——“猫叫综合征”的缺失多为新发，需较高分辨率或微阵列检出。(d) 47,XXY。注意记号如何记录数目、性染色体、再记重排，以及其中缺失了多少临床细节：47,XX,+21并不说明额外染色体源于减数分裂Ⅰ还是Ⅱ，也不说明是否为易位型。
:::
:::

::: exercise 两次分裂 {level=1}
写出减数分裂后期Ⅰ与后期Ⅱ各分开什么；并说明14;21罗伯逊易位携带者的减数分裂Ⅰ错误为何可产生完全不含21号物质的配子。
::: solution
后期Ⅰ分开同源染色体（二价体），随交叉解除而分离；后期Ⅱ分开姐妹染色单体。14;21携带者的减数分裂Ⅰ分离使每个次级卵母细胞要么得衍生染色体、要么得正常21号（以及正常或阙如的14号）；若衍生染色体走向一极而正常21号（连同正常14号）走向另一极，则未得衍生染色体的配子含21号物质，而得衍生染色体、无正常21号的配子与正常配子受精后含两份21q——21三体——完全不含21号物质的配子受精后为21单体，不能存活。正是这种不对称使携带者母亲的经验风险远离理论上的四分之一。
:::

::: exercise 重组与图距 {level=1 check=“10”}
一个大谱系中两个标记的重组分数为0.10。图距多大？对连锁检测意味着什么？
::: solution
小距离下，1%重组按定义为1 cM，故两标记相距约10 cM。连锁检测中，距疾病等位基因10 cM的标记在约10%的信息性减数分裂中与其发生重组：基于该标记的结果在约十分之一的传递中出错，故报给家系的残留风险须相应调整（如50%的先验风险按单体型与相期调至约45%或55%）。这就是诊断实验室宁可找到致病变异本身、而不依赖追踪标记的原因。
:::

::: exercise 携带者算术 {level=1 check=“0.025”}
某人群中一常染色体隐性病发病率为6400分之一。设Hardy–Weinberg平衡，估计携带者频率。
::: solution
$q^{2} = 1/6400 = 0.00015625$，故$q = 0.0125$，携带者频率$2pq \approx 2q = 0.025$——40分之一。注意假设：随机婚配、无选择、无奠基效应、无近亲。若近亲婚配，风险根本不受$2pq$限制，因为夫妇可共享血缘同源一致的等位基因——这就是表兄妹婚配后代隐性病率远高于人群数字的原因，也是认真采集家族史、而非依赖人群数字的价值所在。
:::

::: exercise 为何是这条染色体，不是那条 {level=2}
活产儿童中最常见的常染色体三体系21三体，而多数其他染色体的三体只见于流产或死胎。请解释，并说明这对产前筛查的敏感性意味着什么。
::: solution
额外基因剂量的耐受程度取决于所载基因的数量与内容：21号是最小的常染色体、基因相对稀少，故21三体能发育至足月，而16三体（流产中最常见的三体）不能。这对筛查有直接影响。无细胞DNA检测测量的是母血中的胎盘DNA，当存在胎盘局限性嵌合或双胎消失之一时，非整倍体21号来源的信号被稀释；而16与22三体既如此频繁地流产，其检出既无必要亦不可行。因此筛查性能总是针对其目标病种（21、18、13与性染色体）报告，低风险结果并非胎儿无染色体异常的声明。
:::
:::

::: exercise 是否嵌合 {level=2}
一名24岁女性因不孕检查，血液20%计数细胞为45,X细胞系，但身材正常、无Turner综合征表现。请解释，并说明咨询前应再查什么。
::: solution
这是X单体嵌合，可在血液中静默却在卵巢中有意义：45,X/46,XX嵌合与原发性卵巢功能不全相关，而血液45,X比例与性腺表型相关性差。咨询前应：复检或扩大检查（第二组织如皮肤成纤维细胞，或增加计数细胞数，因血液低比例嵌合系可能是培养伪象或淋巴细胞年龄相关性染色体丢失），以及——至关重要的——查找Y染色体物质，因为隐匿Y序列的45,X系（如mos 45,X/46,XY或标记染色体）有性腺母细胞瘤风险，处理要改为性腺影像与可能的性腺切除。辅助生殖妊娠的胎儿核型还可能揭示胎盘局限性嵌合，故产前结果须就绒毛、胎儿与新生儿之别进行咨询。
:::

::: exercise 设计检测 {level=3}
一名9岁儿童全面发育迟缓、头颅MRI正常、有一次惊厥、无畸形面容；父母非亲缘，家族史无提示。按顺序列出诊断策略，并以各步能查到与查不到什么作为依据。
::: solution
一线：染色体微阵列（多数中心按表现与性别同时行脆性X检测），因为拷贝数改变可解释有分量的少数未明发育迟缓，结果改变再发风险（新发CNV：低；遗传自平衡或外显可变亲本的CNV：可能高），并可指向需监测的综合征。二线：微阵列阴性则行 核心家系（trio）外显子组或基因组测序，诊断率显著提高；外显子组阴性不能排除疾病——重复扩增、深部内含子与调控变异、甲基化缺陷、低于检测限的嵌合、被流程滤除区域的拷贝数、以及功能未知的新基因，皆仍可能。三线：结果导向的靶向检测——表型提示印记病则行甲基化研究，或特定重复长度检测。全程：一两年后重新分析阴性结果、保存原始数据，并记住“意义未明变异”是一场持续的对话而非一个结果。还有一条：永不让分子诊断取代临床诊断——孩子的管理方案依据表型书写，不依据报告。
:::

::: exercise 父龄 {level=3}
一名52岁男性与其28岁的伴侣读到“高父龄父亲突变更多”，询问年龄对子女风险的影响。给出你会使用的数字并给出咨询。
::: solution
父亲每增一岁，精子约多两轮细胞分裂的复制风险，子代新发单核苷酸负荷约每父龄一岁增加两个突变，故52岁男子之子比20岁男子之子多带约八十个新发点突变。对那一小批由特定功能获得改变引起、且赋予精原干细胞增殖优势的病——软骨发育不全（*FGFR3*）、Apert综合征（*FGFR2*）、致死性发育不良、MEN2B与I型神经纤维瘤病（*RET*、*NF1*）——风险随父龄区间升高数倍，但任一具体疾病的绝对风险仍低（如软骨发育不全自约十万分之一升至每十万几例）。相比之下，三体风险由母龄驱动，故两人合并的画像由其母龄相关非整倍体风险与其父龄相关突变风险主导；对“该检测吗”的回答是：超声与测序均不能可靠发现显性新发突变，而非整倍体问题可按常规指征以无细胞DNA或介入性取样解决。诚实的咨询还包括效应量的含义：对多数此类夫妇，严重疾病的绝对风险增量很小，父龄本身不是介入性产前诊断的指征。
:::
