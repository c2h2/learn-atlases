癌症是一种体细胞遗传病，却有着胚系后果。当一个细胞获得足够多的可遗传改变、摆脱对其谱系的约束时，肿瘤便发生，继而演化——其子代竞争空间、养分，并最终与治疗对抗。这一过程中几乎每条重要通路之所以被发现，都是因为某个家族、某个儿童肿瘤或某条白血病特异染色体告诉某人该往哪里看。

本章讲述体细胞突变如何产生癌、胚系变异如何增加对癌的易感性，以及两者如何用于实践：该给哪位患者做检查、开什么单、结果对亲属意味着什么，以及肿瘤的测序结果如今如何指导治疗。

## 从突变到肿瘤

::: definition 驱动、乘客与克隆演化 {#def-drivers}
**驱动**突变赋予生长或存活优势、在肿瘤发生中被选择；**乘客**功能中性、只是被携带。一个肿瘤是一个**克隆**及其亚克隆：一个细胞获得最初优势，其子代积累更多驱动，肿瘤遂成为一个群体——这就是单次活检可能低估最终引起耐药变异的原因。**肿瘤突变负荷**（每Mb突变数）衡量肿瘤被突变的程度，可预测免疫检查点阻断的反应：错配修复缺陷与聚合酶ε超突变肿瘤携带数千新抗原。
:::

::: definition 癌基因与抑癌基因 {#def-onc-tsg}
**原癌基因**经功能*获得*成为**癌基因**——点突变、扩增、易位，或使其处于强增强子之下的启动子重排。细胞水平上一个改变的等位基因即已足够，故癌基因激活呈显性行为。典型例子：*KRAS*密码子12/13/61、*BRAF* V600E、*PIK3CA* H1047R、*ERBB2*（HER2）扩增、*MYCN*扩增、*BCR-ABL1*融合、*PML-RARA*、*ALK*融合，以及TERT启动子突变。
**抑癌基因**经两个等位基因的功能*丢失*而失活——Knudson的**两次打击**——方式为突变加缺失、杂合性丢失、有丝分裂重组，或一个等位基因表观沉默加另一个突变（经典例子：散发性微卫星不稳定结直肠癌的*MLH1*启动子甲基化，对比Lynch综合征的胚系错配修复突变）。有些以单倍剂量不足起效（*PTEN*、*RB1*部分如此），有些突变蛋白获得新的致癌属性（*TP53*功能获得型突变体）。
:::

功能分类——“hallmarks（ hallmark 特征）”——是有用的骨架，因为每一类都含有可成药靶点：持续的增殖信号（受体酪氨酸激酶、RAS–MAPK、PI3K–AKT–mTOR）；对生长抑制的抵抗（RB–E2F、p16^INK4A^、周期蛋白D）；死亡抵抗（滤泡性淋巴瘤t(14;18)中的BCL-2）；衰老与复制极限的丧失（TERT、*CDKN2A*，以及替代性端粒延长表型）；侵袭与转移（E-钙黏蛋白/*CDH1*、EMT程序、趋化因子受体）；肿瘤血管生成（VHL丢失与HIF驱动的VEGF）；免疫逃逸（PD-L1上调、β2-微球蛋白与HLA丢失——也是检查点抑制剂在某些克隆失败的原因）；基因组不稳定与突变（错配修复、同源重组、聚合酶校对、有丝分裂检查点）；代谢失调；以及促癌炎症。

::: theorem 体细胞突变随年龄与限步事件数积累 {#thm-multistage}
癌症发病率近似随年龄的幂次上升，指数反映细胞必须积累的限速事件数；因此一个组织的癌风险取决于其干细胞分裂次数与暴露于致突变物之多少；而提供了一个“首次打击”的遗传综合征抬高发病率却不改变年龄曲线的形状。
:::

::: proof
若恶性表型需要$k$个序贯限速改变，每个在干细胞谱系中单位时间以小恒定概率发生，则风险率表现为$t^{k-1}$——这就是多阶段模型，解释上皮癌为何随年龄剧增，也解释视网膜母细胞瘤：当第一击为遗传所得、所需步骤少一步，遂在婴儿期起病。两个推论在临床上都是承重的。其一，组织间风险不同部分缘于终身干细胞分裂次数——这就是高更新上皮（结肠、皮肤、育产史作用下的乳腺）比左心室更常患癌的原因——尽管致突变暴露（烟草、紫外线、黄曲霉毒素、马兜铃酸、慢性炎症）能压倒该项，这也是移民研究显示人群癌症差异多为环境性的原因。其二，抑癌基因的胚系致病变异（“每个细胞已带一击”）把曲线向左上方推移——更早发病、更多肿瘤、成对器官双侧——这正是家族史中要找的流行病学签名，也是早发本身就是转诊指征的原因。其推论是Peto悖论：大象的细胞与分裂次数远超小鼠，癌却不多得多；比较基因组学把它归于大象额外的功能性*TP53*拷贝及相关重复，以及其他大型长寿物种增强的抑癌网络。
:::

## 遗传性肿瘤综合征

约5–10%的癌症发生于携带高或中等外显率胚系变异之人；另一层家族聚集则反映共同环境加多基因背景。临床触发点从来不是单一诊断而是**模式**：年轻、多原发、成对器官双侧、综合征典型肿瘤、特殊组织学，以及同种或相关肿瘤跨代出现。

::: example 34岁的盲肠癌患者 {#ex-lynch}
一名34岁男性患盲肠腺癌Ⅱ期。其母48岁患子宫内膜癌，舅父39岁患结直肠癌。肿瘤检测示免疫组化MSH2与MSH6着色缺失、高度微卫星不稳定。
::: solution
这一模式即Lynch综合征：右半早发结直肠癌、一级亲属子宫内膜癌、MSH2/MSH6缺失伴MSH6继发缺失（MSH6随MSH2失稳而降解）、微卫星不稳定。免疫组化与不稳定性结果告诉你机制；只有胚系检测（*MSH2*测序加缺失/重复分析，并考虑顺式沉默*MSH2*的*EPCAM*缺失）才能告诉这个家庭。先确证再行动，因为散发性*MLH1*甲基化伴*BRAF* V600E才是错配修复缺陷结直肠癌最常见原因，追它的胚系就追错了。一旦找到胚系变异：每位一级亲属各有2分之1可能携带，级联检测是最有价值的一步；患者本人处理即刻改变（鉴于异时癌风险，全结肠切除而非节段切除是合理选择，确诊后每年结肠镜，妇科监测并在完成生育后讨论降险子宫切除，尿液与皮肤检查，以及Lynch研究中阿司匹林化学预防的考虑）；并且因其错配修复缺陷预测疗效，未来任何晚期病变使用免疫检查点抑制即成为正当选项。注意其子女的风险取决于他的携带状态与配偶的遗传，而亲属的阴性症状前检测只对家系变异有信息量。
:::
:::

::: example 乳腺诊室的胚系结果 {#ex-brca}
一名38岁女性患3级三阴性乳腺癌、无家族史，胚系检测：*BRCA1*致病变异，肿瘤显示野生型等位基因丢失。她问这对她、她42岁的妹妹、她14岁的儿子各意味着什么。
::: solution
对她：该变异预示残留乳腺显著升高的终生乳腺癌风险以及卵巢、输卵管与腹膜癌风险（数字在各指南引用的区间内）；也预示对铂类化疗与PARP抑制的敏感（在相应场合），两者均已进入高危遗传病的辅助治疗。处理是一场讨论：对侧乳腺切除对比强化MRI监测；降险输卵管卵巢切除——诚实的陈述是卵巢癌筛查未被证明降低死亡率，故生育完成后提供的手术才是有效选项，其后果包括立即的外科绝经、骨与心血管考量，以及子宫去留下个体化的激素替代决定。对她的妹妹：针对已知家系变异的症状前检测可得、低廉，应在咨询后提供而非一封书信索要——对*该*变异的阴性结果确属安心，阳性则改变处理。对14岁的儿子：**不要**对健康未成年人检测成年起病之病；现在记录家系变异的理由，是让他成年后能被提供检测（并且重要的是，使其未来子女有生育选项），走同样的咨询路径。清楚讲一遍：阳性结果不是诊断；风险数字是把人群数字套在修饰基因与生活史未知的个体上；他姨妈的病程不是他的宿命。
:::

## 修复基因、合成致死与治疗

细胞在双链断裂修复于同源重组与非同源末端连接之间择路；同源重组需要完整的*BRCA1*–*BRCA2*–PALB2–*FANCD2*–*RAD51*轴。失去该通路的细胞依赖备份修复与PARP介导的单链断裂修复。**PARP抑制剂**把PARP困在单链断裂处，在同源重组缺陷的细胞中断裂使复制叉崩塌——肿瘤死亡，而同源重组正常的组织得以恢复。这就是临床上实现的**合成致死**，用于携*BRCA1/2*或相关改变的卵巢、乳腺、胰腺与前列腺癌；同一逻辑解释肿瘤对铂类与电离辐射的敏感，及其耐药机制：回复突变恢复读框、53BP1或SHLD1/2依赖的末端保护丢失、药物外排、复制叉恢复。

另有三种治疗耐药模式因其属遗传学而应入本课程：**靶点突变**（*BCR-ABL1* T315I与三代抑制剂、*EGFR* T790M继而C797S、*PIK3CA*与通路再激活、*KIT*继发突变）；**旁路信号**（MET扩增、RAS–MAPK再激活、*RB1*/*TP53*缺失肺癌在EGFR抑制下的小细胞谱系转换、前列腺癌的神经内分泌转化）；以及**免疫逃逸**（HLA或β2-微球蛋白丢失，消除干扰素信号的JAK1/2突变——这就是检查点阻断初治有效后仍会失效的原因）。

::: example 一次并不关于肿瘤的肿瘤检测 {#ex-chip}
一名71岁转移性胰腺癌患者液体活检报告*TP53*突变加*DNMT3A*变异（变异等位基因比例24%）；胚系panel报告*ATM*致病变异。治疗团队问：*DNMT3A*是不是靶点？他的家人需要查*ATM*吗？
::: solution
*DNMT3A*变异几乎可以肯定是**意义未明的克隆性造血**（CHIP）：释放入血浆的白细胞来源DNA携带*DNMT3A*、*TET2*、*ASXL1*、*JAK2*与*PPM1D*的体细胞突变，其频率随年龄陡增，血浆cfDNA检测无法把它们与肿瘤来源变异区分。三个推论：它不是该胰腺癌的治疗靶点；它是血浆检测“肿瘤”假阳性、以及仅测肿瘤的血标本得出虚假胚系报告的常见原因（配对的正常组织测序才能分辨）；且高变异比例时，该发现预示心血管风险与治疗相关血细胞减少，若血象异常值得告知血液科。*ATM*结果则须另作处理：单个等位基因*ATM*变异属中等风险乳腺癌基因，关系到其家族的监测；纯合或双等位**ATM**失活即毛细血管扩张性共济失调，若有亲属出现神经症状应查两个等位基因；*ATM*改变的肿瘤可能对DNA损伤药物与PARP抑制更敏感——这是活跃试验证据而非常规实践。通则：肿瘤或血浆结果的解读离不开配对正常样本、变异等位基因比例与患者年龄；胚系结果作为家庭事务而非肿瘤事务来咨询。
:::
:::

::: warning 肿瘤panel阴性不能排除遗传易感，意义未明的胚系变异什么都解释不了
两个错误反复出现。其一，体细胞肿瘤panel只测其设计所及的基因与改变，阴性结果对胚系综合征一无所知——多数易感基因不在肿瘤panel内；胚系检测需要配对正常样本与按规范分类报告胚系变异的实验室。其二，易感基因的意义未明变异（VUS）绝不能驱动处理：基于VUS做降险手术、或据此把某亲属排除在检测之外，就是伤害；正确做法是寻求共分离与功能证据，或当作未发现变异、按个人与家族史管理。当胚系与体细胞同步测序时，还要记住反向陷阱：仅在血液中20%比例的“胚系”变异可能是CHIP，血与肿瘤皆有的变异可能是无人证实其致病的基因中的良性多态。
:::

::: example 九个月大的双侧视网膜母细胞瘤 {#ex-rb}
一名9月龄婴儿因白瞳就诊；检查见双侧多灶视网膜肿瘤。父母健康、非亲缘，无家族史。血液与肿瘤检测：血中可测得致病*RB1*变异，肿瘤中第二个等位基因丢失。
::: solution
血中可测出*RB1*变异意味着**可遗传性视网膜母细胞瘤**，即使无家族史：约40%病例可遗传，其中多数来自新的胚系变异，通常父源，且在父母血中常以低水平存在（性腺嵌合）。由于每个细胞已带第一击，第二击发生于众多视网膜细胞——这就是疾病双侧、多灶、婴儿期起病的原因（见[[#thm-multistage]]）。三个推论也就是胚系检测要在诊断时而非日后做的理由。**第二原发：**生存者的骨肉瘤、软组织肉瘤、松果体母细胞瘤（三侧型）及日后黑色素瘤终生风险显著升高，放疗放大该风险——故治疗计划只要可行便偏向动脉内或玻璃体腔化疗、局部治疗与眼球摘除而避开外照射；长期随访包括以减少辐射为要的监测影像。**同胞：**即使父母血检阴性，同胞风险亦非可忽略，因为有性腺嵌合可能；实际答案是婴儿期麻醉下眼底检查，并考虑针对家系变异的靶向检测。**父母的未来：**若孩子是家系首例，父母自身风险接近背景，但其同胞的子女风险取决于某一亲本是否嵌合；而孩子若存活，其每个孩子2分之1概率继承该变异——这就是把结果与家系变异记录成他成年后可获取形式的原因。注意仅测肿瘤的panel会漏掉什么：没有配对血样本，胚系第一击便不可见，家庭就丢掉了这个病例中最具行动价值的信息。
:::

::: quiz
下列哪项最能解释PARP抑制剂杀死*BRCA1*双等位失活的细胞却不伤正常组织？
- [ ] 肿瘤细胞中PARP更丰富。
- [x] *BRCA1*两个等位基因丢失使同源重组消失，细胞无法修复PARP抑制造成的复制相关断裂；正常细胞保留一个功能等位基因而能修复。
- [ ] PARP抑制剂被肿瘤特异激酶激活。
- [ ] *BRCA1*缺陷细胞完全不能进行非同源末端连接。
::: solution
合成致死要求单一损伤不致死而两者并存才致死。杂合的正常细胞保留同源重组而得以恢复；双等位失活的肿瘤细胞不能，留下被困的PARP与崩塌的复制叉。这也解释复发时所见的耐药机制：胚系型损伤的回复、同源重组恢复（如53BP1依赖末端保护丢失或*BRCA*继发回复突变）、以及药物外排。

::: history
Boveri于1914年提出异常染色体可使细胞无制分裂、癌起源于细胞——此后八十年逐点被证实。Knudson1971年对视网膜母细胞瘤的统计分析，用年龄分布与双侧性推断出两次打击、并在基因未明之前区分遗传性与散发性；*RB1*cDNA于1986年被三个组克隆，其产物及对E2F的控制在其后十年阐明。Bishop与Varmus发现Rous肉瘤病毒癌基因*src*存在正常细胞同源物（1970年发现、1976年解释），确立了原癌基因概念并获1989年诺贝尔奖。Vogelstein组于1987–1991年界定腺瘤-癌序列与*APC*；Lynch综合征的错配修复基因1993年随之；*BRCA1*与*BRCA2*于1994与1995年由包括Mary-Claire King团队与冰岛、冰岛-澳大利亚各组在内的协作克隆。染色体易位定义了血液系统恶性肿瘤——1960年的费城染色体与1976年的t(14;18)——靶向治疗随之：伊马替尼因Druker组在慢性髓系白血病显示持久细胞遗传学反应，2001年获批。Hanahan与Weinberg2001年的“特征”综给全领域以语言；2005年证明PARP抑制对同源重组缺陷细胞致死，把一条DNA修复通路变成一个药物类别；2011年伊匹木单抗获批开启检查点抑制；2014年测序时代附带发现的克隆性造血，使“血液里一个突变”的解读成为日常临床问题。
:::

## 通向何处

细胞周期调控、凋亡及其检查点见[[cell-biochemistry/signalling-cell-cycle]]；DNA修复通路见[[cell-biochemistry/gene-expression]]；肿瘤病理与分期见[[pathology/cancer-biology]]；基于风险知情的筛查与治疗见各器官系统课程；症状前检测的伦理见[[genetics/genetic-testing]]与[[medical-ethics-law/consent-capacity]]。

::: summary
- 癌症是体细胞演化：驱动突变被选择，乘客被积累，由此形成的亚克隆结构解释了混合反应与必然的耐药。
- 癌基因以显性方式激活（突变、扩增、融合、增强子劫持）；抑癌基因经两次打击丢失，含表观沉默——Knudson以统计学推断出的细胞机制。
- 发病率随年龄呈幂次上升，因为需要数个限速事件；胚系一击免除一步，产生早发、双侧与多发——遗传综合征的流行病学签名。
- 以模式识别综合征（年龄、多发、成对器官双侧、组织学、家系），以正确的检测确证（结直肠与子宫内膜肿瘤的普遍MMR检测能发现家族史漏掉者），并以监测加（证据支持时）降险手术管理。
- DNA修复缺陷是治疗机会：同源重组缺陷与错配修复缺陷分别预示铂类、PARP抑制剂与检查点抑制的敏感，其耐药机制是遗传性的。
- 解读肿瘤与血浆测序须配正常样本并看变异等位基因比例：克隆性造血制造假阳性，胚系发现是需要咨询的家庭信息。
- 不为成年起病的易感性检测健康未成年人；要为已知家系变异提供级联检测；绝不在意义未明变异上采取行动。
:::

## 练习

::: exercise 用语言说两次打击 {level=1}
解释为何遗传的*RB1*变异在婴儿期致癌，而散发性视网膜母细胞瘤需要同一细胞两次体细胞事件、发病较晚。
::: solution
遗传的致病等位基因意味着每个视网膜细胞已带一击，只需一次体细胞事件——突变、有丝分裂重组或缺失——即失活剩余等位基因；靶细胞多、单细胞概率小，于是肿瘤在一两岁内出现、常多灶双侧，且个体其他组织终生风险升高。散发肿瘤需同一细胞两次独立体细胞事件，其概率随时间陡增，故单侧、晚发。同一逻辑解释遗传性*TP53*、*VHL*或*APC*综合征为何更早、更多发地起病，以及“第二次打击”如何使常染色体显性易感在细胞水平呈隐性。
:::
:::

::: exercise 给改变分类 {level=1}
就下列发现指出癌基因或抑癌基因及其机制：(a) ERBB2拷贝数12；(b) *CDKN2A*纯合缺失；(c) t(9;22)；(d) *VHL*双等位体细胞突变；(e) TERT启动子−124C>T。
::: solution
(a) 癌基因，经扩增（配体非依赖的HER2信号）。(b) 抑癌基因，经缺失——p16^INK4a^丢失释放CDK4/6，使RB高磷酸化。(c) 癌基因，经融合：BCR-ABL1提供组成性酪氨酸激酶活性（伊马替尼及其后继者之靶）。(d) 抑癌基因，经两次体细胞打击，导致HIF稳定与VEGF/PDGF驱动的血管生成。(e) 癌基因，经启动子突变制造ETS结合位点、重新激活端粒酶——胶质瘤、黑色素瘤与膀胱癌的早期事件。
:::
:::

::: exercise 转诊算术 {level=1}
下列患者哪些应转诊临床遗传科评估肿瘤易感，为什么：(a) 46岁乳腺癌、其姨母60岁乳腺癌；(b) 35岁乳腺癌；(c) 60岁子宫内膜癌，肿瘤MMR缺陷、孤立性MSH6丢失、无家族史；(d) 5岁单侧视网膜母细胞瘤。
::: solution
(a) 仅凭此一般不需胚系检测——该模式与多基因加共同环境的家族聚集相容，但完整家系谱（含卵巢、胰腺、前列腺癌与男性乳腺癌）可能改变评估。(b) 是：仅诊断年龄即达到多数机构的标准。(c) 是：肿瘤检测发现孤立MMR蛋白丢失即应评估胚系，即使无家族史——Lynch综合征可无信息量家系（尤其外显率较低的*MSH6*与*PMS2*；且家族史可因偶然、收养或小家庭而偏短）。(d) 是：任何视网膜母细胞瘤（含单侧）都应评估胚系*RB1*变异，因为一部分单侧病例可遗传，牵涉患儿第二肿瘤风险、同胞，以及避免放疗。
:::

::: exercise 机制与处理 {level=2}
一名40岁女性经商检panel发现*BRCA2*致病变异。她本人与家族均无癌史。她的风险多大？应提供什么？
::: solution
*BRCA2*致病变异使女性乳腺癌终生风险显著升高（自三十多岁起上升），另有卵巢、输卵管与腹膜、胰腺、前列腺（男性亲属）与黑色素瘤风险升高。应提供：按当地方案年龄启动的结构化高危乳腺监测（通常近三十岁起每年MRI并加用乳腺X线），并明确讨论“监测发现而不预防”；作为选项的降险乳腺切除（量化收益及其身体意象与性健康后果）；生育完成后的降险双侧输卵管卵巢切除（*BRCA1*通常四十出头、*BRCA2*略晚），讨论外科绝经、无乳腺癌者选择性激素替代，以及术后腹膜癌风险仍在的事实；带诚实数字的生活方式建议（酒精、体重、体力活动）；亲属级联检测。还须谈生育学含义——若夫妇想要这份信息，伴侣的携带状态关乎未来子女——并记录所谈内容，使方案能随年龄被重新讨论。
:::

::: exercise 预言治疗 {level=2}
一肿瘤报告：微卫星不稳定，免疫组化错配修复缺陷（MLH1与PMS2丢失），*BRAF* V600E野生型。两种可能的解释是什么？用哪个检测区分？若为转移性，MSI状态支持什么治疗？
::: solution
MLH1丢失伴PMS2继发丢失，或源于胚系*MLH1*变异（Lynch综合征），或源于体细胞/表观的*MLH1*启动子高甲基化——后者在散发结直肠癌通常属CpG岛甲基化表型并与*BRAF* V600E相关。鉴别检测为肿瘤的*MLH1*启动子甲基化（阳性强烈支持散发性），若阴性或临界，则行*MLH1*与*EPCAM*胚系测序加缺失/重复分析；此处*BRAF*野生使散发甲基化可能性下降，提高胚系检测的优先度。转移性病变中，错配修复缺陷预测PD-1方向免疫检查点抑制的反应——这是获批的组织非依赖适应证，可产生持久缓解；胚系结果另指导家族监测与级联检测，并支持讨论阿司匹林化学预防及Lynch综合征所述手术选项。
:::

::: exercise 家族史不够用 {level=3}
一名29岁男性双侧听神经瘤并新发脑膜瘤，胚系*NF2*致病变异。其父母与两个同胞检测阴性。其伴侣已妊娠。解释遗传方式，说明你如何交代这次妊娠与他本人的肿瘤学未来。
::: solution
*NF2*为外显率很高的常染色体显性病；双亲检测阴性且无相关家族史，意味着变异在他体内*新发*（或罕见地位于一方亲本的生殖系——那对其同胞只是应告知的小残留风险）。他们的妊娠风险因此按他本人的状态而非家族史计算：每个孩子2分之1——这是他们需要的数字。可讨论的选项：不检测；针对已知家系变异的介入性产前诊断（因变异已知而可得、可靠）；少数中心可做的针对已知家系变异的无创产前诊断；若考虑经IVF再生育，植入前遗传学检测；以及不检测的选项。他的肿瘤学未来需要专科团队：以听力保全为要的系列影像，快速进展型病例选择性使用贝伐珠单抗，权衡听力与面神经风险的手术或放疗选项；另有脑膜瘤、室管膜瘤与周围神经鞘瘤的监测、眼科随访，以及对威胁成年早期听力与平衡之疾病的社会心理负担的管理。
:::

::: exercise 设计监测方案 {level=3}
一名26岁女性被发现携带*PTEN*致病变异（Cowden综合征谱）。列出其监测方案及每项的理由，并说明对其30岁弟弟如何处理。
::: solution
*PTEN*错构瘤肿瘤综合征升高乳腺、甲状腺（滤泡细胞）、子宫内膜与肾癌风险，伴巨头、皮肤黏膜损害、胃肠道息肉与血管畸形，罕见Lhermitte-Duclos病。监测循风险并言明理由：按当地方案自三十余岁或更早开始每年乳腺MRI监测——其终生风险接近*BRCA*相关疾病；每年甲状腺超声——甲状腺癌常见且常早期，以细胞学而非预防性甲状腺切除指导手术（不同于*RET*，后者才做预防切除）；子宫内膜监测并对异常出血放低取样门槛、生育完成后讨论子宫切除；定期肾影像——双侧早发肾肿瘤是死亡的主要贡献；皮肤复查与胃肠息肉的关注。对其弟弟：现在就提供针对已知家系变异的级联检测——阴性可使其脱离终生项目，阳性则启动之；若他有巨头与多发毛根鞘瘤，阴性结果不能解释症状，此时应查第二个等位基因或另选基因。记录每次讨论，并把方案写成患者可随身携带的形式，以免换一家医院便一切归零。
:::

::: exercise 伦理与证据 {level=3}
一名健康22岁无症状男性的父亲41岁死于Li-Fraumeni综合征相关的*TP53*肾上腺皮质癌。他要求检测。你如何做？若他12岁又有何不同？
::: solution
他是有行为能力的成人，且知晓有监测收益，检测是恰当的：从父亲病历或保存标本确证家系变异；事先咨询阳性（终生全身MRI监测、尽量避开放疗、生育含义、心理冲击、无立法保护区的保险与就业）与不确定结果的可能；取得书面同意；当面告知；无论结果如何安排随访与支持。若是12岁：默认不因成年起病易感性检测健康儿童——童年无收益时检测剥夺其未来自主权、在一些地方影响可保性、并可能拖累家庭关系——但Li-Fraumeni是少数推荐儿童期监测的成年起病综合征之一，故决定确有争议：应与家庭共同作出，对具备Gillick能力的孩子纳入其本人意见，并可推迟至青少年期；记录理由。注意两种要避免的错误：拒绝一个有行为能力、收益明确成人的检测请求；以及因父母想要确定性而反射性地检测儿童。
:::
