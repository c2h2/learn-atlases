染色体异常比多数学生想象的多发，也比教科书示意图上的更古怪。若把性染色体非整倍体计入，约150个活产中就有1例染色体异常；约一半孕早期流产携带染色体异常；而绝大多数非整倍体孕根本无法到达足月。从合子到门诊之间横着一道“致死剂量失衡”的过滤器——这就是为什么能存活的三体都是小的那几条，为什么不平衡易位可以表现为反复流产而不是一个孩子，以及为什么低危孕妇的“高风险”筛查结果更可能是错的而非对的。

本章讨论数目与结构染色体异常：它们的模样、由来、检测能与不能说什么，以及患者与家庭接下来面对什么。

## 先看数字

::: definition 非整倍体与多倍体 {#def-aneuploidy}
**非整倍体**指个别染色体数目异常：**三体**（三个拷贝，如47,XX,+21）、**单体**（一个拷贝，如45,X）。**多倍体**指整套额外染色体——三倍体69,XXX/XXY/YYY与四倍体92,XXXX——通常源于两个精子进入一个卵子或一次分裂失败；三倍体在流产中常见，孕若继续则致死或近致死，额外染色体组来自父方时表现为部分性葡萄胎表型。
:::

以下近似频率值得记住，因为它们驱动咨询：Down综合征总出生率约700分之一（随母龄升高：25岁约1,000分之一，35岁约350分之一，42岁约30分之一）；18三体约5,000分之一；13三体约12,000分之一；性染色体非整倍体合计约500分之一。核型上21号染色体除自由三体外还可见其他异常者不足21三体和新生儿的1%——其余为易位型或嵌合型。

::: theorem 剂量决定存活 {#thm-dosage}
一个非整倍体能否到达足月，取决于额外或缺失基因的数量与内容，而非染色体的名分：小的、基因贫乏的染色体三体可活产，大的、基因富集的三体不能，而性染色体非整倍体是所有情形中最能耐受者。
:::

::: proof
每条染色体都携带其产物必须保持演化所定比例之基因；多一个拷贝会使该染色体上每个剂量敏感基因的表达升高约一半，而这类产物中许多参与复合体工作、位于膜上或作为调控RNA，失衡本身即有害（“基因平衡”约束：化学计量与数量同等要紧）。21号是人类最小的常染色体、基因相对贫乏，13与18号居中——这就是这三条、也是常染色体中仅有的这三条能不时在足月被见到，而16三体（流产中最常见三体）在孕早期结束前即致死的原因。单体更糟，因为没有第二份缓冲损失；常染色体单体在活产儿中几乎从不见。性染色体从中幸免大半：额外的X被失活（形成巴尔小体），只有假常染色体区与逃逸基因被超量，这就是47,XXX、47,XXY与47,XYY表型轻微而多变的原因，也是Turner表型取决于第二条性染色体之**缺失**——即本应逃逸失活的基因之单倍剂量不足——的原因。同一逻辑解释了为什么部分三体可在整条三体不能时相容于生命，以及微缺失与微重复综合征本质上就是对少数几个基因剂量所做的受控实验。
:::

## 21三体（Down综合征）

表型可辨但多变：新生儿肌张力低下与关节松弛，面中部扁平伴眼裂上斜，通贯掌，足趾间隙宽，Brushfield斑，身材矮与短头。约半数有先心病——完全性房室间隔缺损最具特征，室间隔缺损与法洛四联症也常见。还有：十二指肠闭锁（“双泡征”，有时伴环状胰腺）、Hirschsprung病、食管与十二指肠闭锁、甲状腺功能减退与乳糜泻、白内障与屈光不正、寰枢椎不稳定（麻醉与运动前须考虑）、阻塞性睡眠呼吸暂停、听力下降、以反复肺部感染为主要表现的原发性免疫功能缺陷，儿童期白血病风险显著升高（急性巨核细胞白血病，新生儿期由一过性髓系异常 preceding），以及中年期伴淀粉样血管病的Alzheimer病风险升高——21号染色体上多出的*APP*基因不过是在做这个基因做的事。

认知跨度很大，且儿童之间的差异大于完全三体与嵌合三体之间的差异；早期干预、听力视力矫正、甲状腺监测与心脏修补改变的是结局本身。高收入国家的预期寿命已达六旬，衰老相关的失能——尤其是Alzheimer病——正成为主导的临床问题。

90–95%病例的机制是母源减数分裂不分离，母龄相关正由此而来；3–4%为父源或合子后；3–4%源于罗伯逊易位；1–2%为嵌合型。

::: example 一位32岁孕妇的高风险筛查结果 {#ex-cri}
一位孕12⁺²周、无家族史的女性超声貌似正常，无细胞DNA报告“21三体高风险”。她问：孩子有Down综合征吗？
::: solution
不能这么说——而答案是一道算术，不是一句安慰。无细胞DNA对21三体的敏感性超过99%、假阳性率约0.05–0.1%，但其**阳性预测值取决于患病率**。32岁的先验风险约300分之一（0.33%），则“高风险”结果的后验概率约为$0.99 \times 0.0033 / (0.99 \times 0.0033 + 0.001 \times 0.9967) \approx 77\%$；若为40岁、先验相当，则超过99%。所以该结果大幅度移动了概率，却未确立诊断，且它出错的原因是生物学的而非技术的：胎盘局限性嵌合（测的是滋养层DNA而非胎儿）、消失或受累的同孕双胎、母亲的拷贝数改变或母亲自身的局限性嵌合、母亲肿瘤，以及低胎儿分数导致的检测失败（是失败而非假阳性）。下一步是诊断性检测——11周起绒毛取样或15周后羊膜腔穿刺——同时做培养与非培养细胞的定量荧光或微阵列，因为快速检测能查出常见非整倍体，而低水平嵌合须计数细胞后才可见，也只有细胞遗传学或微阵列能识别罗伯逊易位——父母的自身风险恰取决于此。绝不凭筛查结果终止妊娠；同样的话也要反着咨询，因为无细胞DNA“低风险”不等于核型正常。
:::

## 18三体与13三体

两者均严重；且如今都作为继续妊娠被遇到，因为筛查是可选项，也因为重症监护决策是与父母共同作出而非单方面决定。

**18三体（Edwards综合征）**：生长受限、枕部突出、小颌、握拳伴示指压小指、摇椅足、手指弯曲、脉络丛囊肿、食管与脐部异常，多数有复杂心脏畸形。中位生存数日至数周；约5–10%存活超过一岁且伴严重残疾。**13三体（Patau综合征）**：全前脑及其谱系（从无叶型全前脑到孤立性眼距过近）、唇腭裂、小眼与视网膜脉络膜缺损、轴后多指、头皮缺损（先天性皮肤发育不全）、肾畸形、心脏畸形与外生殖器模糊；生存期同样有限。

其临床含义在于：诊断改变的是管理计划——分娩地点、是否提供心脏手术、安宁与新生儿路径、喂养与呼吸支持、居丧与遗传随访——而这些是与父母提前、依据具体发现（哪个器官、哪种畸形、哪个诊断）而非仅凭染色体作出的决定。胎动减少、水肿与严重心脏病可能使提前分娩合适；反之，嵌合18三体的头心正常可相容于更长生存，仅绒毛取样检出的嵌合需要羊水穿刺来解读。

## 性染色体非整倍体

它们是出生时最常见的染色体异常，也是成人中最少被诊断的，因为表型常细微，核型有时数年后才被报告。

::: example 没有月经、个子不高的女孩 {#ex-turner}
一名15岁少女，身高自童年即在第3百分位，未来月经。查体见宽胸、乳头间距宽、后发际低、肘外翻与双侧非凹陷性踝水肿。骨龄落后；FSH与LH升高，雌二醇低。
::: solution
这是Turner综合征，源于完全性或嵌合性X单体；淋巴水肿反映胎儿期淋巴管发育异常；卵巢功能衰竭（高促性腺激素性性腺功能减退）导致无青春期发动与矮小，后者主要因假常染色体区*SHOX*单倍剂量不足——这就是生长激素要早开始、雌-孕激素替代要用于青春期发育与骨健康的原因。在相关病变出现之前先查它们：超声心动与心脏大血管MRI查二叶主动脉瓣与主动脉缩窄（成年有主动脉夹层风险，故妊娠风险可观、需专科评估）、肾超声查马蹄肾、甲功与乳糜泻血清学、听力与眼科检查。**查找Y染色体物质**：若有男性化表现、任何Y来源标记染色体或45,X/46,XY嵌合，应以PCR或FISH确认——性腺母细胞瘤风险此时构成性腺切除的理由。借赠卵或可生育；软骨与听力问题、糖尿病与高血压需终生关注。若产前发现45,X细胞系，胎儿45,X、嵌合45,X/46,XX与45,X/46,XY性发育差异男性之间意义迥异，且单凭绒毛取样无法分辨。
:::
:::

**47,XXY（Klinefelter综合征）**约600名男性中1例，常迟至生育评估才诊断：身材高、四肢长、睾丸小硬、男性乳房发育、体毛稀少、男性化不足、无精子症（多数可经显微取精获取精子并行卵胞质内单精子注射），乳腺癌、代谢综合征、2型糖尿病、骨质疏松、静脉血栓栓塞、自身免疫病与焦虑或语言性学习困难风险升高。睾酮替代改善男性化、情绪与骨密度但不改善生育；这一诊断之所以重要，在于它改变监测方案，并使男子免去多年不明原因的疲惫与羞耻。**47,XYY**（约1,000男性中1例）与**47,XXX**（1,000女性中1例）常不被诊断；文献描述了高大身材、学习困难（尤其言语语言）、肌张力低下以及孤独症谱系与行为问题风险增高，而XYY与犯罪的过时联系源于在收容机构的取样偏倚，若被提起应就此点名澄清。性染色体非整倍体的产前诊断是咨询最常跑在证据前面的场合，这也是许多机构现在建议：无细胞DNA的偶然性染色体发现若未获孕妇要求可不报告。

## 结构异常

::: definition 结构改变的类型 {#def-structural}
**缺失**：臂内（间隙性）或末端；小的称**微缺失**，仅微阵列或靶向检测可查出。
**重复**：常为造成同胞缺失的同一次减数分裂不平衡交换的另一产物。
**倒位**：臂内型或臂间型（含着丝粒）；表型通常均衡，但携带者可因倒位段内的交换产生含缺失与重复的配子，且一个断点即可打断一个基因。
**易位**：相互易位（非同源染色体间互换）或罗伯逊易位（两条近端着丝粒染色体整臂融合，如45,XX,der(14;21)）。
**环状染色体**：两端断裂后融合，有丝分裂中不稳定——这就是环状染色体可致嵌合、且表型重于缺失片段所能预测的原因（20环伴顽固癫痫是常见的例子）。
**等臂染色体**：一臂丢失、另一臂重复，如Xq等臂染色体——伴矮小与性腺衰竭的Turner表现的常见原因。
**标记（额外）染色体**：一条额外的结构异常染色体；双随体inv(15)标记染色体引起inv(15)重复综合征，表现肌张力低下、癫痫与孤独症。
:::

**缺失综合征**之所以可辨，是因为关键区内少数几个基因的剂量就足够：5p−（猫叫综合征：猫叫样哭声、小头、重度学习困难）；4p−（Wolf–Hirschhorn：“希腊头盔”面容、唇裂、癫痫）；1p36缺失（最常见末端缺失——重度发育迟缓、心肌病、视听丧失）；7q11.23（**Williams综合征**，含*ELN*：主动脉与肺动脉瓣上狭窄、婴儿期高钙血症、言语能力强而视空间困难的过分友善性格、结缔组织表现）；22q11.2（**22q11.2缺失综合征**，见下）；11p13（WAGR：*WT1*/*PAX6*，有Wilms瘤风险——所以要触发监测的是缺失而非仅基因）；15q24、1q21.1、16p12.1以及许多表达度可变的复发区间。

::: example 抽搐与低钙的婴儿 {#ex-22q11}
足月儿，生后第2天，全身性惊厥；血钙1.5 mmol/L（游离钙0.68 mmol/L）伴甲状旁腺素低；新生儿查体闻及短的圆锥动脉干杂音。此后发现喂哺困难伴经鼻返流，内镜见轻微腭部异常。
::: solution
甲状旁腺发育不良所致低钙、圆锥动脉干心脏畸形与腭功能异常这三联征，应促使检测22q11.2缺失（DiGeorge/腭-心-面综合征，关键基因含*TBX1*）——用微阵列或靶向FISH，因该缺失多数病例低于常规核型分辨率。这一综合征是表达度可变与“还应找什么”的经典示范：胸腺发育不良伴T细胞减少（接种活疫苗前、输注非照射血制品前查淋巴细胞亚群）、肾畸形、学习困难（算术尤著）、青少年与成年期精神疾病（约四分之一成人患精神分裂症）、腭部手术需求、言语与喂哺支持、麻醉气道注意事项。遗传方式通常为常染色体显性且多数为新发；若发现某一亲本携带缺失——约十分之一病例有一方亲本受累、常为轻型——再发风险即为50%，故需检测父母，任何受累的成年亲属也需要其可能从未有过的心脏、精神与代谢随访。
:::
:::

**亲本易位的非均衡产物**通常产生“发育迟缓+局灶结构改变”的孩子：小头或大头、生长停滞、畸形面容，以及依获得/丢失片段而异的心、肾与脑畸形。同一片段的部分三体可无结构异常而以重度智力障碍起病——缺失表型通常（并非总是）比相应重复更重，因为后者至少还有一份拷贝在。

**平衡重排**在携带者通常无害，有三个例外值得记住：断点打断基因（X染色体断点打断*DMD*与*RS1*的经典例子，以及“暴露”另一条染色体上的隐性等位基因）；位置效应使基因离开其调控环境；以及[[genetics/genome-chromosomes]]所述四价体分离的生育后果。

## 机制决定再发

| 发现 | 通常机制 | 确为新发后的再发风险 |
|---|---|---|
| 自由21三体 | 母源减数分裂不分离 | 约1%（计入性腺嵌合），并按母龄校正 |
| 遗传自母亲的der(14;21)所致21三体 | 罗伯逊携带者 | 约10–15%（父方携带者：几个百分点） |
| t(21;21)所致21三体 | 21q21q融合携带者 | 可存活孕100%受累 |
| 22q11.2、Williams、1p36缺失 | 通常新发NAHR或修复错误 | 确系新发且已检性腺者约1%；亲本携带者50% |
| 平衡相互易位 | 家族性或新发 | 流产与不平衡子代风险高（几个至约20%） |
| 患儿嵌合三体 | 合子后有丝分裂错误 | 低，但表型不可预测 |
| 性染色体非整倍体 | 不分离，XXY常为父源减数分裂Ⅰ | 一般低 |

::: example 核型“正常”而微阵列发现缺失 {#ex-microarray}
一名4岁儿童全面发育迟缓、行为问题、反复中耳炎、室间隔缺损已修补；核型正常。微阵列报告22q11.2有1.8 Mb缺失，双亲检测均正常。你能告诉这个家庭什么？
::: solution
该缺失为*新发*，故父母再发风险低——约1%，涵盖性腺嵌合可能——但并非零，正是这个数字让“还会再来一次吗”的谈话诚实而非廉价安慰。它也回答了家里的其他疑问：即使同一家庭内表型也多变，故姐姐的轻度言语困难与父母本人的细微发现（如有）应当被刻意查找而非归于偶然；这一诊断附带监测义务（心脏与腭部评估、活疫苗前免疫亚群、甲状腺与血钙、肾影像、发育与精神随访直至青春期、以及听力）；它也不该被用来预言这个孩子的能力。要用家庭日后仍能听懂的话解释清楚：拷贝数结果是一项其含义随时间变化的发现，对同一数据的重新分析可能上调或下调解读——是实验室在谨慎，而不是犯了错。
:::

::: warning 无细胞DNA筛查与它引发的决定
无细胞DNA是筛查试验：阴性预测值高，阳性预测值取决于患者先验风险；它不是诊断试验；当胎盘嵌合时它测的不是胎儿；也未被证实适用于人们希望它覆盖的所有病种。任何不可逆的决定——尤其终止妊娠——都不应仅凭筛查结果作出；需要的是诊断性标本加细胞遗传学或微阵列研究，以及点名说明可致结果不符情形的咨询。同一纪律适用于其推论：无细胞DNA低风险不排除染色体异常、微缺失或单基因病，绝不可向孕妇描述为“孩子染色体正常”。
:::

::: quiz
一名女孩有Turner综合征表现；核型46,X,i(Xq)。机制是？
- [ ] 母源减数分裂Ⅰ不分离。
- [x] 着丝粒横裂（或断裂-融合），留下同一条X的两条长臂、丢失短臂。
- [ ] 罗伯逊易位。
- [ ] 合子后有丝分裂不分离。
::: solution
等臂染色体形成于着丝粒横向而非纵向分裂，子细胞继承一臂的两份拷贝、另一臂的零份；46,X,i(Xq)因短臂基因（含*SHOX*——矮小、Turner体态）单倍剂量不足而仅存一份长臂。生育罕见，但赠卵妊娠或有可能；心血管风险与Turner综合征相同，故适用同样的监测。
:::
:::

::: history
1959年，在Tjio与Levan确立人类染色体数目三个月后，Lejeune、Michaux与Turpin报告了Down综合征的21三体；几乎同时，爱丁堡的Jacobs与Strong报告Klinefelter综合征多一条X、Turner综合征少一条X；两年内13与18三体相继被描述；显带使每条染色体逐一可辨之后，缺失综合征接踵而来。1980年代的DNA研究显示，多数45,X孕中那条唯一的X来自母亲——性染色体自父源配子丢失；对不分离与单亲二体的研究开始解释单一携带亲本家庭中的罕见隐性病。微缺失时代自1980年代高分辨显带开启，而荧光原位杂交、继而1992年报道的比较基因组杂交及其微阵列形式，在“细微”综合征变为可检测之后弥合了描述与机制之间的鸿沟；2010年专家共识推荐染色体微阵列作为未明发育迟缓与多发先天异常的一线检测。1997年卢煜明（Dennis Lo）报告母血中的胎儿DNA；至2011年，常见非整倍体的无创产前检测已进入临床——这一进步改善了筛查，同时将使不符结果的解读成为产前遗传咨询的核心技能。
:::

## 通向何处

发现背后的机制——不分离、NAHR、UPD、嵌合——见[[genetics/genome-chromosomes]]；印记与重复病见[[genetics/non-mendelian-inheritance]]；遗传模式与再发算术见[[genetics/mendelian-inheritance]]；实验室检测之别见[[genetics/genetic-testing]]；儿童期的综合征面目见[[paediatrics/congenital-genetic]]。

::: summary
- 非整倍体在受孕层面常见而多为致死：能存活的三体是基因含量最少者；这道过滤器正是产前风险须以概率而非确定性表述的原因。
- 21三体表型可辨而多变，累及心、胃肠、内分泌、血液、免疫、气道，晚期还有神经退行性变；其管理是监测，其机制决定再发风险。
- 18与13三体通常仅能相容于短暂生存；产前诊断改变照护计划，须与父母商议而非代其决定。
- 性染色体非整倍体最常见也最常被漏诊：Turner综合征需心、肾、内分泌、听力与性腺监测并查找Y物质；Klinefelter综合征是成年期值得作出的诊断。
- 结构异常包括缺失、重复、倒位、易位、环、等臂染色体与标记染色体；亲本的平衡改变可解释反复流产与不平衡子女。
- 再发风险取决于机制——自由三体约1%；母源罗伯逊携带者10–15%；t(21;21)100%；遗传性微缺失50%——驱动咨询的是机制而非标签。
- 核型、微阵列与测序分辨率不同；无细胞DNA只是筛查；每个结果都连同其残留不确定性一起告知患者。
:::

## 练习

::: exercise 为发现命名 {level=1}
解读：(a) 47,XX,+18；(b) 46,XX,del(4p16.3)；(c) 46,XX,der(14;21)(q10;q10),+21；(d) 46,XY,inv(9)(p12q13)。
::: solution
(a) 18三体（Edwards综合征）。(b) 4p末端区缺失，即Wolf–Hirschhorn综合征。(c) 46条染色体、核型貌似正常，但一条14;21衍生染色体取代了一条14号，另加一条额外21号：易位型Down综合征。衍生染色体为14q与21q着丝粒处融合，故患儿有21q三个拷贝——衍生染色体本身即第三个拷贝——且必须检测父母，因为同样的融合若存在于母亲（45,XX,der(14;21)）即为平衡携带状态，再发风险10–15%。(d) 9号染色体臂间倒位，一种常见的多态变异、视为良性，报告它是为了避免被误当作就诊原因——一个有用的提醒：染色体报告必须结合表型阅读。
:::
:::

::: exercise 母龄风险 {level=1}
解释为何孕早期联合筛查（颈项透明层加生化标志物）加母龄优于单用母龄，而无细胞DNA对21三体又优于两者。
::: solution
单用母龄在5%筛查阳性率下约30%检出率：风险梯度真实，但对单次妊娠而言很弱。颈项透明层、游离β-hCG与PAPP-A各自携带关于胎儿的独立信息，与母龄先验合并可得约85–90%检出率、5%假阳性率。无细胞DNA直接读取胎儿（胎盘）来源的DNA序列，对21三体检出率>99%、假阳性率<0.1%——因此其似然比高下立判、在筛查人群中的阳性预测值也更高——但它仍是筛查试验；对13、18三体与性染色体较弱；可因低胎儿分数而失败；受胎盘嵌合、消失双胎与母源拷贝数改变干扰；也不检测颈项透明层与超声可能发现的结构性与单基因疾病。
:::
:::

::: exercise 阳性预测值 {level=1 check=“0.5”}
某筛查试验敏感性99%、特异性98%。在患病率100分之一的人群中，阳性结果里真阳性占比多少？
::: solution
取10,000人：患病者100人、检出99人；未患病9,900人，其中2%（198人）阳性。阳性预测值$= 99/(99 + 198) = 0.5$——阳性结果一半为假。本题要点：患病率低时主导阳性预测值的是特异性而非敏感性——这就是用于低患病率人群的筛查试验需要远高于98%的特异性的原因，也是回复给患者的数字必须纳入其本人先验风险的原因。
:::
:::

::: exercise 先做哪个检测？ {level=1}
在核型、FISH/快速PCR、染色体微阵列与测序之间为下列情形作出选择：(a) 疑似染色体病且结构心脏病明确的新生儿；(b) 未明学习困难与孤独的6岁儿童；(c) 孕16周颈项透明层5 mm而无细胞DNA正常；(d) 反复感染伴圆锥动脉干畸形。
::: solution
(a) 核型（临床紧急时加快速非整倍体检测），因为数目或大结构改变可能性大，且为父母计必须识别易位。(b) 一线染色体微阵列，有指征时加脆性X检测；微阵列无诊断价值则行外显子组/基因组测序。(c) 诊断性取样（绒毛或羊水）加微阵列：颈项透明层增厚而无细胞DNA正常提示拷贝数改变、单基因或综合征病因，且越来越多地指向测序panel，故微阵列正常时应考虑测序。(d) 靶向22q11.2检测（微阵列或FISH），因为临床问题具体，而该缺失低于常规核型分辨率。
:::

::: exercise 产前标本中的嵌合 {level=2}
因无细胞DNA高风险于孕13周行绒毛取样，仅直接制备（细胞滋养层）示21三体嵌合，培养正常。你如何建议？为什么？
::: solution
两种制备取的是不同细胞群体：直接制备反映细胞滋养层（来自外绒毛/内细胞团谱系），培养细胞反映中胚层核心，故一嵌合一正常恰是**胎盘局限性嵌合**的模式——16号最多见，21号亦有充分描述，后者还可解释无细胞DNA假阳性。由于该标本无法确定胎儿染色体组成，应建议羊膜腔穿刺（羊膜细胞源于胎儿），计数足够细胞以排除低水平嵌合；若发现持续，再考虑脐带血取样与分娩时胎盘检查。与操作同等重要的是两条咨询：本次取样的起因本是筛查结果，故筛查假阳性与胎盘嵌合的可能性早应在预期之内；而Ⅲ型胎盘局限性嵌合伴颈项透明层增厚或生长受限时，即使羊膜细胞正常，受累胎儿的风险仍真实存在，故生长监测必须继续。
:::

::: exercise 再发算术 {level=2}
一对夫妇育有一名Down综合征孩子。就下列每种情形说明再发风险与理由：(a) 患儿47,XX,+21，母亲34岁；(b) 患儿46,XX,+21,der(14;21)mat；(c) 母亲45,XX,der(21;21)；(d) 患儿46,XX/47,XX,+21，血液10%嵌合细胞。
::: solution
(a) 在母龄基线之上约1%：三体由不分离（多为母源减数分裂Ⅰ）而来，性腺嵌合是罕见再发的残留解释；无论如何应提供产前诊断。(b) 母源罗伯逊携带者：经验上生育Down综合征活产儿风险约10–15%，另有不平衡孕的丢失；若为父方携带者则仅几个百分点。(c) 可存活孕100%受累，因为每个可存活孕体必须继承21q21q衍生染色体加一条正常21号；选项为配子捐赠或植入前检测。(d) 低且不可预测：合子后有丝分裂错误不会重演，但患儿表型取决于哪些组织携带该细胞系，无法由血液10%推算。
:::

::: exercise 印记入画 {level=2}
两个孩子均为15号染色体父源单亲二体——一个整条，一个仅15q11-q13区。预测各自的表型，并解释为何母源同区缺失导致另一种疾病。
::: solution
两孩均缺乏15q11-q13的母源贡献而有两份父源活性拷贝，故均患**Prader-Willi综合征**（新生儿肌张力低下与喂哺困难，随后多食与肥胖、性腺功能减退、学习困难、行为特征）；而15q11-q13的母源缺失导致**Angelman综合征**，因为该区既含母源表达基因（尤其神经元中的*UBE3A*），也含父源表达基因（*SNRPN*、SNORD116簇）。两种病即从相反亲本看同一区间——这就是检测始于甲基化研究（两者皆异常）的原因，也是必须继而确立机制（缺失、单亲二体或印记中心缺陷）的原因：只有缺失带实质性再发风险，只有印记缺陷提示反式作用的表观遗传机器基因的可能。
:::

::: exercise 带标记染色体的少年 {level=3}
一名12岁儿童肌张力低下、3岁起癫痫、孤独症与脊柱侧弯；所有细胞中可见一条额外的小型近端着丝粒样染色体，鉴定为源于15q11-q13的双随体标记，位于父源染色体。解释表型、机制与再发风险。
::: solution
这是**异双中心15号染色体/inv dup(15)综合征**：一个额外标记染色体在两条正常同源染色体之外再携带两份15q11-q13，使关键区实际存在四至五个拷贝。该区（含*UBE3A*簇与印记基因）的剂量驱动表型：婴儿期起病癫痫（常难控制）、肌张力低下、语言缺失或极少、孤独症特征与行为障碍；严重程度随拷贝数与亲源递增——父源（如此例）意味着印记的、表达之额外拷贝无对手，而母源额外拷贝部分被沉默。机制通常是亲本（多不受累）减数分裂不平衡交换或断裂-融合-桥事件，或在孩子体内新发；由于多数病例为新发，父母再发风险低，但若某一亲本携带平衡的15号重排（或标记遗传自嵌合亲本），风险显著升高，故必须做父母核型与微阵列。治疗对症且多学科——抗癫痫药（注意有报道某些药物加重行为问题）、发育支持、脊柱侧弯与睡眠管理——并应告诉家庭：预测结局的是标记的大小与内容，而不是“多了一条染色体”这几个字。
:::

::: exercise 与父母共同决定 {level=3}
一对夫妇孕21周被告知胎儿18三体伴大型房室间隔缺损与马蹄肾。他们问你的建议。请组织你的回答，并列出未来数周需要作出的决定。
::: solution
先确保诊断确凿而完整：诊断性核型或微阵列（选择性病例加外显子组测序，因少数貌似“18三体”表型的胎儿另有改变预后的发现）、详细结构筛查与胎儿超声心动图，并转诊有该病经验的胎儿医学与新生儿/安宁团队。然后诚实地给出统计——以区间而非判词的形式：多数患病孕流产或死产；活产婴儿中位生存数日至数周，极少数存活超过一岁且多伴重度多重残疾；病程由心脏病、喂养与气道问题决定，具体检出的畸形很重要。不带诱导地陈列选项：继续妊娠并计划以舒适为主的新生儿照护；继续妊娠并请求包括心脏手术在内的积极处理（部分中心可提供，也确实产生过长期生存者，但多数伴重度残疾）；终止妊娠——每一个选项都应有谈话的时间，并可联系围产安宁团队与其他家庭。须提前决定并写入病历的事项包括分娩地点与方式、出生时复苏与重症、喂养（是否提供管饲）、手术的门槛、病情恶化时的复苏状态；此外还有父母的检查（未做者查父母核型以寻找易位）、居丧与同胞支持，以及产后关于再发与未来妊娠的遗传咨询。
:::
