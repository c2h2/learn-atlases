医生见到的多数疾病并不是孟德尔式的。冠心病、2型糖尿病、精神分裂症、哮喘、炎症性肠病、乳腺癌、慢性肾病与抑郁都在家族中聚集，但并不按孟德尔方式分离：儿子继承的是风险，而非诊断。解释这一模式、测量它、又不过度宣称地使用它，就是本章的内容——在这里遗传学与你将在[[epidemiology-ebm/observational-studies]]重逢的流行病学相接。

四个问题组织起这门学科：人群中有多少变异来自遗传（遗传度）？哪些变异负责，我们如何找到它们（连锁、关联、测序）？携带它们的个体风险有多大（多基因评分、家族史）？对此能做什么（风险分层、预防，以及预测的伦理）？

## 易患性、阈值与家族风险之形

::: definition 多基因遗传与易患性-阈值模型 {#def-liability}
**多因子**疾病源于许多效应微小的遗传与环境的影响。**易患性-阈值模型**假设存在一个连续的潜在易患性——在很大程度上（但并非完全）可加——当易患性超过阈值$\tau$时疾病发生。由于人群患病率$K$是阈值以上的尾部面积，先证者的亲属——其平均易患性向上平移——在疾病罕见时其相对风险远超$K$。该模型同时解释三项观察：再发风险随亲缘关系疏远而急剧下降；对发病率较低的性别，其亲属风险更高（先天性肥厚性幽门狭窄男孩多见，其亲属再发也更多；先证者属于低发性别的多发性硬化）；以及随患病亲属数目增多风险升高。
:::

::: theorem Edwards平方根法则 {#thm-edwards}
对罕见多因子疾病，患者同胞的风险约为$\sqrt{K}$（$K$为人群患病率）——故同胞相对风险$\lambda_{s}$约为$1/\sqrt{K}$，疾病越罕见其值越高。
:::

::: proof
在许多微效位点存在时，同胞平均共享一半的分离遗传变异，故同胞的易患性约向先证者亲属超额平均易患性的一半平移。对正态分布，尾部概率以超指数速度下降，故均数的固定平移使尾部面积呈乘积式放大；当$K$很小时该放大接近平方根：把同胞风险写为$K \approx c\sqrt{K}$（$c$为1量级常数），即可再现经验规律$\lambda_s = K/K \approx 1/\sqrt{K}$——$K \approx 0.1$的疾病约为3倍，$K \approx 0.005$约14倍，$K$接近$10^{-3}$时超过30倍。该法则在其应当失效处失效：单个大效应等位基因（*BRCA1*变异所给风险远高于$\sqrt{K}$）、共同环境抬高的同胞相似性、以及选择性婚配。其临床价值在于提供一个即时的合理性检验：若一个家庭所报“同病风险”远离$\sqrt{K}$，应寻找孟德尔病因、共同暴露或过度报告。
:::

## 遗传度

::: definition 遗传度 {#def-heritability}
**遗传度**指表型**变异**中可归因于遗传变异的比例。**广义**遗传度$H^{2}$包括显性与上位效应；**狭义**遗传度$h^{2}$只计加性效应，是对选择发生反应、且多基因评分能够捕捉的量。它是对某一时期、一定环境范围内人群定义的：它对个体什么也不说，对宿命什么也不说，且环境改变时其值改变。
:::

经典估计来自双生子与养子研究。在等同环境假设下，Falconer公式给出

$$
h^{2} \approx 2\,(r_{\text{MZ}} - r_{\text{DZ}}),
$$ {#eq-falconer}

其中$r$为对内相关（对二分类疾病，为由一致率导出的易患性相关）。方法至关重要：家系回归、双生子模型、领养设计、基于SNP的GREML（对芯片常见变异的限制最大似然），以及在GWAS汇总统计上做的LD分数回归——它们回答的问题略有不同；对许多常见病，易患性尺度的SNP遗传度约在0.1–0.4之间，即使基于家系的遗传度更高——这就是历史上的“遗传缺失”之谜，现今多归因于早期GWAS无法检出的微效变异，加上罕见变异、结构变异与基因–环境结构。

::: example 从双生子对到遗传度 {#ex-h2}
40对同卵双生对精神分裂症一致率0.48，80对双卵双生一致率0.17。估计遗传度，并列出可能使该数字出错的因素。
::: solution
把易患性尺度的一致率当作相关，Falconer法则给出$h^{2} \approx 2(0.48 - 0.17) = 0.62$。有意思的是假设部分：同卵双生共享的宫内与产后环境多于双卵（绒毛膜、相似对待、相同外貌），故同卵相关中的“环境”项被抬高、$h^{2}$偏向上；精神分裂症中的选择性婚配同时提高两类双生对的遗传相似性；双生子注册库样本不能代表人群；一致率由本身不稳定的诊断边界定义，“一致”的一对可能轻重不同，故易患性的测量带有误差；且仅120对样本时0.62的置信区间很宽。领养与同胞研究以及基于SNP的估计都提示精神分裂症遗传度相当高（约0.5–0.8），因此即便算术粗糙，结论的方向是稳健的。应记住的教训是：引用单一遗传度数字必须连同其设计与假设，绝不可说成“他的精神分裂症六成是遗传的”。
:::
:::

::: warning 高遗传度不等于不可改变，低遗传度不等于不重要
遗传度是人群方差的属性，随环境移动。成年身高在多数被研究中的人群狭义遗传度约80%，然而北欧人平均身高一个世纪内增高约10 cm——完全由环境造成，等位基因频率未变。近视遗传度高，其患病率却随近距离用眼与户外活动减少在一代内增至三倍。反之，肺癌的遗传度中等，但吸烟——一项暴露而非一个变异——造成其大部分；极少数遗传极高风险个体（如快N-乙酰转移酶型与膀胱癌致癌物交互，或从不吸烟者肺腺癌的胚系*EGFR*变异）并不改变吸烟的人群归因分数。引用遗传度必须连同其测量所及的环境，且绝不可作为对患者个人命运的断言。
:::

## 寻找变异

::: definition 连锁与关联 {#def-linkage-association}
**连锁**研究追踪染色体片段与疾病在家系中的共传递；它对大效应、罕见变异有效，对模型假设要求少，但因果区段只能定位到数十Mb。**关联**（候选基因以及决定性的全基因组关联）比较无关病例与对照间的等位基因频率；由于多代重组留下短共享单体型，关联可定位至数千碱基之内——但仅对两组中均能观察到的常见等位基因有效，且须严格控制多重检验与群体结构。
:::

全基因组关联研究（GWAS）对数十万常见变异分型，用参考面板插补至数百万；进行质控（样本检出率、亲缘关系、杂合度、性别核对、板效应）；用主成分校正祖先结构；逐个变异检验（通常为加性logistic或线性回归，跨队列meta分析）；并以约$p < 5 \times 10^{-8}$——对百万个近似独立检验的Bonferroni阈值——宣布全基因组显著。发现必须在独立样本中重复；效应量对二分类性状以比值比、对数量性状以每等位基因beta报告。

GWAS的发现出乎意料。多数关联变异位于非编码DNA；它们聚集于在相关细胞类型中活跃的增强子与启动子区；因果基因未必是最近的基因；一个变异可与多种表面无关的疾病相关（免疫疾病间的*IL23R*、*HLA*与*LPP*多效性，冠心病间脂代谢位点的多效性）；一位点的多数信号其实来自数个不同等位基因——这就是以统计可信集精细定位、并在相关细胞中以功能学（eQTL共定位、CRISPR扰动）跟进自成一门学问的原因。

::: example 读一个全基因组结果 {#ex-gwas}
一项6万例、12万对照的GWAS报告一个常见内含子变异（次要等位基因频率24%）与冠心病相关，每拷贝OR 1.06，$p = 3 \times 10^{-14}$。记者写道：“科学家找到了致病基因。”什么对，什么错，此变异要临床有用还缺什么？
::: solution
对：该关联统计上确凿——远超全基因组显著性，样本量充分，方向与量级都符合已知影响冠心病风险的众多常见变异。错在：“致病”与“基因”。OR 1.06是每拷贝6%的相对增加——对10年风险5%的人，杂合约5.3%、纯合约5.6%——单凭这一差异不改变任何处理决定；变异位于内含子，可能只是标记而非中介邻近基因的信号；估计适用于所研究的人群与时代，带着其自身的混杂结构与环境分布；研究无法证明干预该通路能降低风险。任何临床使用之前需要：独立队列（含其他族裔）的重复、精细定位到可信的因果变异与基因、该基因功能位于疾病通路的证据、在目标人群中的校准（中年欧洲队列的OR不可直接搬运），以及——决定性的——证明按结果行动能改变结局，因为风险信息唯有改变预防才有用。诚实的总结是：这是真实的生物学，但对个体的预测力可以忽略——这正是多基因评分要把成百上千个此类变异聚合起来的原因。
:::
:::

## 多基因评分及其限度

**多基因风险评分**把个体所携风险等位基因按GWAS效应量加权求和：$G = \sum_j \beta_j x_j$，$x_j$为等位基因剂量。评分通常以人群分布的百分位报告。制作良好的冠心病评分可区分分布上、下半区约3倍的风险差；冠心病多基因评分前8%者的风险与单个中等效应变异携带者相当——这推动了用多基因评分富集预防性治疗人群的研究。类似评分现见于2型糖尿病、若干癌症与部分精神疾病；在人群筛查中回传冠心病与乳腺癌多基因评分的试验正在进行。

其限度同样重要，临床使用前必须言明：

- **族裔可迁移性。** 欧洲裔GWAS导出的评分在非洲、东亚、南亚及混血人群中精度大部分丧失，因连锁结构、等位基因频率、效应量与未建模环境皆不同。这是当前数据的属性而非人类生物学的属性；部署不可迁移的评分只会扩大医学正试图缩小的不公。
- **环境与群体结构的混杂。** 由于亲属共享基因与环境，评分可能经养育、社会经济地位或医疗可及性差异而貌似“预测”结局；家系内分析已使若干此类效应缩水。
- **校准与基线率。** 评分必须结合人群发病率换算为绝对风险；对千里之一患病率的疾病，“高分子评分”不是诊断；任何筛查项目都须知道其在被筛人群中的阳性预测值。
- **临床效用与有效性之别。** 分析有效性、预测有效性与效用是三个不同的命题，唯有最后一个能证成筛查项目；多数机构的过渡立场是：家族史加传统危险因素仍是标准，多基因评分作为研究中的辅助。
- **决定论与披露。** 评分是概率性的，随GWAS扩大重算而变，可能被储存、出售并以当事人未同意的方式使用。遗传信息是家庭信息，多基因信息也不能豁免论证。

::: example 诊室里的多基因评分 {#ex-prs}
一名52岁男性，不吸烟，血压128/78，LDL 3.4 mmol/L，无糖尿病，其父64岁心梗；他做了消费端多基因评分，冠心病居第88百分位，问如何解读。
::: solution
首先把该数字放进真正主导其处理的风险模型：其QRISK或SCORE2类方程的10年风险，由年龄、性别、血压、血脂、吸烟、糖尿病、贫困度与家族史驱动（一级亲属早发——男60岁前——通常是家族史额外计险的阈值；其父64岁心梗恰在边界）。他的评分落在证据所示“至多增加有限鉴别度、且无经验证的治疗阈值”的区间；在多数人群与服务机构，它不应改变任何决定。其次，把该发现当作教育与动员的契机——这正是此类结果最有用的场合：他无症状、LDL 3.4 mmol/L、有家族史，可操作的谈话内容是血压、血脂、体力活动、体重，而若风险不确定——冠脉钙化评分——测的是疾病本身而非易感性，且确实改变分类处理。第三，明确限度：评分多导自欧洲裔队列、不随GWAS扩大再校准、这也是他全家的信息、而“第88百分位”不是诊断。若他想正式细化风险，路径是经验证的临床工具加血脂血压测量，而不是基因报告。
:::
:::

## 基因与环境

::: definition 基因–环境交互与相关 {#def-ge}
**基因–环境交互**指暴露的效应随基因型而异（乘积尺度或加和尺度——须指明用哪个）。**基因–环境相关**指基因型影响暴露，故貌似遗传的效应可能部分是环境的；它在教育、行为与精神遗传学中是大问题：父母的基因型可造成基因–环境相关（遗传养育），孩子的气质也可唤起特定环境。
:::

有临床内容的实例：**苯丙酮尿症**是表型完全依赖环境的遗传病典范——认知损害来自膳食苯丙氨酸，配方可防，这正是新生儿筛查存在的理由；同一问题以母源性苯丙酮尿症的形式延续到下一代。**酒精**——东亚常见的*ALDH2* Glu504Lys变异使乙醛蓄积、发红，强有力地防止酒精依赖，却使仍饮酒者的食管癌风险倍增——这是见到发红患者时应认识的交互。**氨基糖苷类耳聋**与线粒体m.1555A>G变异：一个后果对一个家庭具有毁灭性的药物遗传学交互，也是某些机构在长程氨基糖苷治疗前筛查该变异的原因。**日晒**与*MC1R*变异及黑色素瘤：日晒的人群归因分数远超基因型效应，而基因型仍修饰之。**吸烟**与*CHRNA5*相关位点（尼古丁依赖），以及携带α1-抗胰蛋白酶*SERPINA1* Z等位基因者吸烟则早发肺气肿。

发育与表观遗传效应也属此处：荷兰饥饿冬天的队列显示，孕早期饥荒暴露与子代*IGF2*甲基化改变及日后代谢与心血管结局风险升高相关；发现对机制是提示性的，引用时应连同人类表观遗传关联研究的限度（组织特异、反向因果、甲基化是原因还是结果）。

## 从统计到诊室

临床医生实际要做的是：

1. **规范地采集三代家族史**，包括发病年龄、族裔、近亲婚配与结局；这是最廉价的“遗传检测”，可识别需要更早或额外监测之人（记录见[[clinical-skills/records-handover]]，开单见[[genetics/genetic-testing]]）。
2. **识别“常见”病表现得像孟德尔病的情形**——连续两代50岁前的乳腺或卵巢癌、45岁前右半结肠癌伴多原发、同样情形子宫内膜癌、年轻亲属的心肌病或主动脉病伴猝死——并转诊，因为单基因病因会以致病方式改变亲属的管理，这是多基因评分做不到的。
3. **诚实地使用风险工具**：说明风险是概率性的、可改变因素通常占主导、风险信息的意义在于行动。
4. **在语言上避免基因决定论**，尤其对精神与行为疾病；并抵制为“检测”检测后无任何行动可循之病的请求。
5. **在给家庭建议时掌握人群数据**：多因子病的再发风险来自易患性模型而非25%这个数字；对多因子病套用孟德尔模式会造成真实的痛苦与错误的决定。

::: example 一份既非孟德尔、亦不可忽略的家族史 {#ex-t1d}
一名28岁健康女性询问未来子女患1型糖尿病的风险：其30岁的弟弟11岁确诊，父母均未患病且非亲缘。她读到该病“有遗传性”，想知道是否该给伴侣做检测。
::: solution
1型糖尿病为多因子病，有很大的免疫介导环境成分，故其算术属易患性模型而非25%。她本人风险约15–25分之一（在欧洲裔人群中人群患病率约300–500分之一时，同胞相对风险约15–25倍；在患病率更低的人群则更低），其子女的风险主要取决于**另一位**亲本：人群背景风险，再按伴侣一侧的家族史修正。文献数字：父亲患病时子女风险约6–8%，母亲患病约2–4%——这一亲源差异机制未明（部分是患病母亲的宫内环境，可能还有HLA区类印记效应）；而患病舅舅的情形两者都不适用，其外孙辈仅略高于人群风险。给伴侣做检测没有指征：1型糖尿病的多基因背景没有临床检测；HLA分型用于研究与某些预测研究，不用于生育决定，而且结果也不会改变处理。值得做的是准确而适度的建议：她子女的绝对风险低，至多百分之几；家族史不支持任何特别的产前或新生儿安排；家庭了解症状是合理恰当的；若她想要一个数字，基于家族史的数字及其不确定范围就是诚实的答案。注意两种诱惑：比证据允许的更精确，以及其镜像错误——因该病“只是”多因子而打发掉这份家族史。
:::

::: quiz
某人群身高的狭义遗传度估计为0.8。哪项说法正确？
- [ ] 个体身高的80%由其基因决定。
- [x] 在该人群、该环境范围内，身高方差的80%可归因于加性遗传变异。
- [ ] 若营养改善，身高的遗传度必然升高。
- [ ] 高个子父母的孩子将高于人群中80%的人。
::: solution
遗传度是人群层面的方差比：它不分解个体的表型；环境改善时它反而可能下降（营养改善使环境方差增大，即使均值身高上升$h^{2}$也可能下降）。回归均值同样适用，故高个父母的孩子预期偏高、但比父母中值更接近人群均数。
:::
:::

::: history
Galton的生物测量学提出了问题——能力遗传吗？——留下了统计装置也留下了优生学的耻辱。Fisher 1918年的论文《基于孟德尔遗传假设下亲属间的相关》把孟德尔颗粒式遗传与连续变异调和，创建了数量遗传学；Wright的路径分析以及Castle与Nilsson-Ehle关于多基因的工作提供了模型；Falconer 1960年的教科书给出了至今沿用的双生子与同胞公式。Doll与Hill对“一种暴露引起一种常见病”的证明（1950年起）确立了方程的环境之半。Botstein、Lathrop等在1980年代后期把连锁分析变成了全基因组扫描方法；Risch在1990年代初为复杂疾病形式化了同胞相对风险与病例对照设计；Wellcome Trust病例对照联盟2007年报告14,000例、3,000对照、50万变异，显示了未重复候选基因发现的局限，而2005年补体因子H与年龄相关性黄斑变性的关联开启了GWAS时代。Yang、Visscher等的复杂性状的基因组限制最大似然分析，与Bulik-Sullivan等的LD分数回归，使基因型遗传度成为常规；Khera等证明冠心病多基因评分前几个百分点者的风险与单基因脂代谢病相当——把问题从发现推进到了临床使用。
:::

## 通向何处

设计、偏倚与混杂见[[epidemiology-ebm/observational-studies]]与[[epidemiology-ebm/bias-confounding]]；单基因风险算术见[[genetics/mendelian-inheritance]]；变异如何实际测量见[[genetics/genetic-testing]]；药物遗传学与基因组数据的临床应用见[[genetics/genomic-medicine]]；遗传性肿瘤风险见[[genetics/cancer-genetics]]。

::: summary
- 常见病是多因子的：易患性-阈值模型解释了同胞相对风险的梯度、性别与严重程度效应，以及罕见家族性病为何给出巨大相对风险。
- Edwards的$\sqrt{K}$法则是任何家族风险数字的即时检验；严重失配时怀疑孟德尔病因、共同环境或报告偏倚。
- 遗传度是人群方差比，依赖设计、依赖环境；Falconer公式是起点不是事实；高遗传度对可改性什么也不说。
- 连锁在家系中找大的罕见效应；关联在人群中找小的常见效应，阈值$p < 5 \times 10^{-8}$、要求重复；多数GWAS变异非编码，因果基因常非最近者。
- 多基因评分聚合微效、可作风险分层，但跨族裔迁移差、受共享环境混杂，筛查前须证明临床效用。
- 对可改暴露，基因–环境交互是常态（苯丙酮尿症、酒精、日晒、吸烟、氨基糖苷）；基因–环境相关是行为遗传推断的头号威胁。
- 在诊室：认真采集家族史；当常见病表现得像孟德尔病时转诊；使用概率化、可行动的风险语言。
:::

## 练习

::: exercise 同胞相对风险 {level=1 check=“1/70”}
某病人群患病率5,000分之一。用Edwards法则估计患者同胞的风险。
::: solution
$\sqrt{K} = \sqrt{1/5000} \approx 1/70$。故同胞相对风险约$5000/70 \approx 71$：罕见的多因子病给亲属带来大相对风险——这就是乳糜泻（患病率约百分之一，故一级亲属风险约十分之一、相对风险近10）阳性家族史背后的算术，也是它在高血压中几乎缺席的原因。
:::
:::

::: exercise Falconer公式 {level=1 check=“0.7”}
某性状同卵双生一致率0.65，双卵0.30。估计狭义遗传度。
::: solution
$h^{2} \approx 2(0.65 - 0.30) = 0.70$。引用时附上假设：等同环境、无选择性婚配、无基因–环境相关、可靠的病例定义，以及把一致率当作易患性相关的替代。
:::
:::

::: exercise 从比值比到个人 {level=1}
某变异对一疾病的OR为1.20；一名50岁女性该病10年发病率2%。估计她携带一个拷贝时的10年风险，并说明该近似掩盖了什么。
::: solution
按比值尺度乘积放大，10年风险约$2\% \times 1.2 \approx 2.4\%$（严格地把2%化为比值、乘1.2、再化回，也是2.4%）。近似掩盖之处：OR在特定人群、特定年龄段、族裔与暴露分布中估计，不可迁移至他人或其他族裔；在这种效应量下置信区间要紧；绝对增加0.4个百分点本身不改变任何处理——这就是风险预测使用多因素模型的原因。
:::
:::

::: exercise 阈值为何如此定 {level=2}
解释GWAS为何用$p < 5 \times 10^{-8}$而非$p < 0.05$；若研究报告$p = 2 \times 10^{-7}$的“全基因组提示性”关联，应如何表述其发现？
::: solution
在约百万个半独立常见变异的检验中，0.05的阈值保证数以万计的假阳性；$0.05/10^{6} = 5 \times 10^{-8}$把族系错误率控制在5%附近。单个研究中$2 \times 10^{-7}$的“提示性”结果，更可能是噪声或未达阈的小真实效应而非经验证的关联；历史上多数未经独立重复的提示性结果未能幸存。正确的表述是该位点值得在独立样本中检验，原数据与重复数据的meta分析才是应报告的结果。
:::
:::

::: exercise 遗传度与环境 {level=2}
同一批基因，某表型在普遍营养不良的人群遗传度0.6，在营养良好人群0.35。解释这为何不相矛盾。
::: solution
$h^{2} = V_G/(V_G + V_E + 2\text{Cov} + \dots)$。营养差异大时环境方差$V_E$大，遗传度低；营养普遍良好时$V_E$缩小，同样的遗传方差占据更大份额，遗传度升高。均值也会上升——身高正是如此。基因型–表型映射什么都没变，变的只是环境分布。这也是遗传度估计不能跨人群比较的原因，以及低遗传度不意味着个体遗传效应小（暴露可主导人群方差，而单个高外显变异可主导个体风险）的原因。
:::
:::

::: exercise 缺失的遗传度 {level=2}
家系研究估计精神分裂症易患性遗传度约0.7；10万人基于SNP的GREML约0.25。列出差距的解释，以及哪些部分已被弥合。
::: solution
SNP遗传度只捕捉常见芯片与插补变异及其加性效应，因而错过效应较大的罕见变异（外显子组与基因组测序补此）、结构变异与拷贝数改变（需分别测量；22q11.2、1q21.1等大缺失贡献可观）、非加性效应与上位，以及抬高家系估计的基因–环境结构（选择性婚配、共享环境、基因–环境相关、宫内效应）。另一方面，大规模GWAS的LD分数回归与GREML显示易患性SNP遗传度随样本量与插补质量上升；以数百万变异构建的多基因评分已捕捉可观的遗传信号份额——故“缺失”的大部分是统计功效而非生物学。真正仍缺的主要是罕见与结构变异——这正是大队列外显子组测序开始增添关联的原因。
:::
:::

::: exercise 设计一项研究 {level=3}
你想知道多基因评分能否在南亚人群中为2型糖尿病的传统危险因素增添有用信息。概述设计、确立价值的分析，以及可能使答案为否的三件事。
::: solution
设计：目标人群中的前瞻性队列或类试验分析，基线分型，测量危险因素（BMI、腰围、血脂、血糖、家族史、社会经济与生活方式），结局为核实的新发糖尿病；评分必须源自（或至少验证并重加权于）南亚GWAS而非仅有欧洲GWAS。分析：增量鉴别（C统计量，且最好用净重分类/决策曲线而非单看C）、各评分百分位组的校准、固定阈值下的绝对风险，以及——真正的问题——按评分行动是否改变行为或结局；敏感性分析可用家系内设计或阳性对照以探测群体结构伪象，并按祖先比例分层。使答案为否的三件事：评分的族裔迁移失败（极常见）；混杂——该人群中基因型频率与糖尿病风险同时随迁移、城市化与膳食变化；以及——最重要的——天花板效应，因为BMI与血糖已捕捉多数可操作风险，真实的遗传信号对已充分知情的决策增添有限。
:::

::: exercise 边缘处的伦理 {level=3}
一家公司向雇主推销职场健康项目：员工自愿加测心脏代谢疾病多基因评分，参与后续预防路径者保费降低。指出问题与双方论据。
::: solution
支持方：参与自愿；该信息对常见病确有预测力；预防是当前遗传学增添伤害最少、收益最大之处；若评分用于给予而非削减福利，可以是公平的。反对方：当雇主是发起者时同意很少是自由的，“自愿”带有强制的分量；遗传信息是家庭信息，无法完全去标识；预测效度依族裔不同，基于欧洲裔评分的项目会不均地分配福利并固化既有差距；保费结构是许多司法区立法禁止的基因歧视的软版本，会把成本转嫁给无法改变特征的个体；数据的二级使用（保险人、执法、研究、出售）几乎从不在参与者的合理预期内。可辩护的版本要求：仅在使用能改变管理之处使用；永不设经济惩罚（给予，不扣减）；在每一个部署人群证明表现公平；数据治理设独立保管人与日落条款；“不知晓权”受保护且无惩罚。注意本案例倚赖的不对称：遗传学目前长于分配风险信息、短于分配有效干预；只做前者不做后者的项目是保费优惠计划，不是卫生干预。
:::
