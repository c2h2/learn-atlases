孟德尔规律描述的是这样一类核等位基因：它们干净利落地分离，无论来自母亲还是父亲行为完全相同，而且永不改变长度。真实的家庭会在为数不多的几种方式上打破规律，每一种例外都有自己的机制、自己的检测，以及由机制——而非由家系形态——决定的再发风险。

本章涵盖实践中会遇到的例外：线粒体遗传、基因组印记、伴早现的重复序列扩增病，以及体细胞与生殖系两种形式的嵌合体，连同单亲二体和家系“不守规矩”的非遗传原因。

## 线粒体遗传

::: definition 线粒体DNA与异质性 {#def-mt}
线粒体携带自身的环状DNA，长16,569 bp，编码13个呼吸链亚基、2个核糖体RNA与22个转运RNA；其余约1,300种线粒体蛋白由核基因编码。一个细胞含有数百个线粒体、数千份mtDNA拷贝，因此一个人可以同时携带野生型与突变基因组的混合物——**异质性**。当突变比例在某组织中超过**阈值**时疾病出现，这正是同一变异在一人可以无症状、在其同胞却可以是毁灭性的原因。由于线粒体经卵母细胞传递，mtDNA变异表现为**母系遗传**：患病男性不向其子女传递任何东西。
:::

两种现象使家系难以预测。卵子发生过程中mtDNA的**瓶颈效应**意味着女性卵母细胞所接受的线粒体来自一个大幅缩小的池，故她本人血液中的突变负荷几乎不能预言任何一个子女的负荷——后者可能是5%，也可能是80%。而伴有选择的**有丝分裂分离**意味着一个组织的负荷随时间改变、组织之间也各不相同：单一大片段缺失（Kearns–Sayre、Pearson、慢性进展性外眼肌麻痹）在血液中出了名地低、在终末分裂后组织里更高，这正是疑似单一大片段缺失综合征要做尿沉渣或肌肉检测、而不是抽血检测的原因。

::: theorem 阈值与组织决定表型 {#thm-threshold-mt}
对给定的mtDNA变异，当某组织的突变负荷超过该组织满足其ATP与氧化还原需求所能容忍的水平时疾病显现；由于负荷因组织而异、随年龄而变，“无症状”携带者日后可能发病，且其子女的负荷可能与她本人完全不同。
:::

::: proof
以m.3243A>G转运RNA变异为例。负荷20–40%时，一个人可以仅有偏头痛，或耳聋，或什么症状都没有；当肌肉与脑内负荷达60–80%，同一变异便产生卒中样发作、癫痫、乳酸酸中毒与身材矮小的MELAS；而该变异的母系传递可以解释这样一个家庭：一位女性糖尿病加耳聋，她的儿子童年“卒中”而血管正常，她的姐妹死于心源性猝死性心肌病，她的兄弟却完全健康。负荷并非固定：终末分裂后组织会不均匀地积累或丢失突变基因组；而在血液中，携有大片段缺失或严重tRNA变异的细胞在有丝分裂中被淘汰，故实测负荷随年龄下降。这对咨询的意义既是生物学规则也是实践守则：引用观察到的家系模式与组织特异性负荷，而不是单一风险数字；当负荷之测量会改变处理时在多个组织中测定；并记住轻症母亲可以生出重症孩子，而患病孩子的“完全健康”的母亲本人也可能是会传递的低水平携带者。
:::

需要掌握的临床模式：**LHON**（Leber遗传性视神经病变，经典为m.11778G>A，青年成人无痛性先后视力丧失且男性居多，其原因并非X连锁传递）、**MELAS**、伴肌阵挛与脂肪瘤的**MERRF**、**Kearns–Sayre综合征**（进展性外眼肌麻痹、色素性视网膜病变、20岁前心脏传导阻滞——起搏器可能比其他表现早好几年就需要）、**Pearson综合征**（婴幼儿铁粒幼细胞贫血伴胰腺外分泌功能不全）、Leigh综合征（可为mtDNA型，但更多为核基因型），以及核基因影响核苷酸池所致的mtDNA耗竭综合征。由于多数儿童线粒体病由**核**基因引起，其遗传往往是常染色体隐性、再发风险4分之1——这是就“线粒体病”为一个家庭做咨询之前最重要的一个区分。

生育咨询：绒毛或羊水的产前检测技术上可行，但对异质性变异一般不提供，因为被取样的组织不能预言孩子；植入前检测同样受此限制，还受可用DNA量之限。**线粒体移植（mitochondrial donation）**——在雄原核或纺锤体阶段用供者卵胞质替换母亲的缺陷线粒体——自2015年监管决定起已获英国批准用于临床，所生孩子体内仅存母源mtDNA的极小比例（有回复报道），并引发种系与身份认同等应纳入知情同意讨论的问题。

::: example 一位母亲的提问 {#ex-mt-counsel}
一名29岁女性携带m.3243A>G变异（异质性，血液38%，有偏头痛与感音神经性耳聋；其母41岁死于MELAS）询问：未来子女风险多大？孕期能否做检测？
::: solution
她的所有孩子都会继承她的mtDNA，因为父亲不传递线粒体，所以没有一个孩子能靠“遗传运气”避开该变异；变化的是负荷，而由于卵母细胞瓶颈，负荷变化无法预测。她本人较轻的病程提供不了可靠信息：携带同一变异的母亲死于重型。不推荐产前检测，因为绒毛或羊水的异质性与孩子任何组织的相关性都很差；植入前检测亦然，甚至可能依据不可靠的标准挑选胚胎。可以提供的是：一个测量基线（第二组织如尿上皮细胞的负荷，作为背景而非预测）、一次包含卵子捐赠以及合法获批可行的线粒体移植的生育讨论、孕前对她本人糖尿病、心脏、听力与神经状态的评估（妊娠可能首次暴露线粒体病），以及婴儿期的早期儿科参与。坦率地说“我们给不出一个数字”，并说明理由；家属通常比接受一个日后被证明错误数字更容易接受坦率的不确定性。
:::
:::

## 印记：亲源来源很重要

::: definition 基因组印记 {#def-imprinting}
在印记位点，两个等位基因中哪一个表达、哪一个沉默取决于**它来自父亲还是母亲**，其机制是配子中建立、受精后维持的差异性DNA甲基化，通常覆盖含多个基因与非编码RNA的一个结构域。推论：印记染色体的单亲二体并非中性；缺失的表型取决于它继承自哪一亲本；印记障碍可由缺失、单亲二体、印记中心缺陷，或反式作用表观遗传基因突变（如瞬时性新生儿糖尿病中的*ZFP57*）引起。
:::

临床原型是15q11-q13的互补一对：**父源**转录本（*SNRPN*、SNORD116簇）缺失导致**Prader-Willi综合征**，而神经元中**母源**表达的*UBE3A*缺失导致**Angelman综合征**——同一区间、相反亲本、相反疾病。在11p15，父源促生长模式获得（IC1高甲基化、IC2低甲基化或父源单亲二体）导致伴胚胎性肿瘤风险的**Beckwith-Wiedemann谱系**，而*IGF2*活性降低（IC1低甲基化）导致生长受限的**Silver-Russell综合征**；其他印记病包括**瞬时性新生儿糖尿病**（6q24父源）、**假性甲状旁腺功能减退1a型**（母源遗传的*GNAS*失活伴Albright骨发育不良，而同一突变若来自父亲则大体只表现为激素抵抗）、Kagami-Ogata与**Temple综合征**（14q32），以及同时具有多个印记表型儿童的**多印记位点障碍**。

印记也是肿瘤机制——视网膜母细胞瘤与Wilms瘤中正常等位基因按亲源丢失拷贝——并解释为何“母系效应”的家族史可以在不存在线粒体传递的情况下出现在门诊。

::: example 不是一个诊断的甲基化结果 {#ex-pws}
一名出生5天的男婴喂哺困难、肌张力低下、隐睾，15q11-q13甲基化检测异常。父母问：“哪个基因”出了问题？再生一个患病孩子的机会多大？
::: solution
甲基化检测显示父源甲基化模式丢失——符合Prader-Willi综合征，在引起该病的全部四种机制中此检测均异常——因此它确立了疾病而未确立机制，而决定再发风险的恰是机制。后续检测包括亲本缺失分析（FISH或微阵列，约70%病例可发现父源15q11-q13缺失），以及母源单亲二体检测（基于SNP），若均阴性再查印记中心缺陷。再发风险：父亲若携带父源缺失，其每个子女风险50%；新发缺失（多数病例，发生于他本人受孕时的父源染色体）风险低；单亲二体几乎总是偶发事件，再发风险可忽略；印记中心微缺失风险50%；反式作用缺陷（*ZFP57*）为隐性，风险4分之1。对父母的说法应是：“您儿子患Prader-Willi综合征，我们还需要一项检测才能告诉您关于未来妊娠的事。”同时说明：同样的甲基化结果若出现在有Angelman表现的女孩身上，意味着涉及的是一条相反亲源的染色体。
:::
:::

## 重复序列扩增与早现

已有四十余种神经与发育障碍由短串联重复的扩增引起，主要有五类：产生多聚谷氨酰胺蛋白的三核苷酸CAG/CAA编码区重复（脊髓小脑性共济失调、Huntington病、脊髓延髓肌萎缩症、齿状核红核苍白球路易体萎缩）、非编码区重复（*DMPK* 3′UTR的CTG——强直性肌营养不良；*FMR1* 5′UTR的CGG——脆性X；*FXN*内含子1的GAA——Friedreich共济失调；*C9orf72*的GGGGCC——额颞叶痴呆与肌萎缩侧索硬化），以及四核苷酸与五核苷酸型。

::: definition 早现与不稳定性 {#def-anticipation}
**早现**指逐代发病更早或病情更重。其机制是重复序列的**减数分裂不稳定性**：中间长度或前突变长度的等位基因在传递时倾向扩增，子女的等位基因比亲代的更长、发病更早。不稳定性的方向受传递亲本性别影响——Huntington病的扩增主要发生于父系传递，而脆性X的全突变几乎完全经母系传递，先天性强直性肌营养不良几乎只经母亲发生。
:::

脆性X既说明了机制，也说明了检测的伦理。正常*FMR1*携带约5–44个CGG重复；45–54为中间“灰区”；55–200为**前突变**，其转录为过量mRNA并引起一种不同于全突变的疾病——年长携带者（多为男性）的**脆性X相关震颤/共济失调综合征**，以及约五分之一女性携带者的**原发性卵巢功能不全**；超过200时启动子甲基化、基因沉默，产生**脆性X综合征**：最常见的遗传性智力障碍原因，面容狭长、耳大、睾丸大、焦虑与孤独症谱系特征、二尖瓣脱垂。由于表型取决于扩增长度，同一家庭里可能有震颤的外祖父、学习困难的孙女、卵巢早衰的携带者母亲，和一位重复长度未知而无症状的女性。因此检测必须按长度测定、以一个附带解读的数字报告；对扩展家庭成员的级联检测才是临床价值所在。

::: example 三代人，三种病 {#ex-fxr}
一名7岁男孩有学习困难、焦虑、拍手、耳大与睾丸大。其62岁母系外祖父有进行性动作性震颤、步态共济失调与记忆力减退；其34岁的母亲39岁时因“卵巢早衰”切除子宫。男孩检测示*FMR1* 420个CGG重复伴甲基化。
::: solution
男孩患**脆性X综合征**，源于经母系传递、完全甲基化的扩增：其母亲为前突变携带者（据推断：她或其兄弟的重复数需测定），而扩增为全突变发生在母系传递中，全突变风险随母亲重复数急剧上升（母源等位基因超过约90个重复时几乎必然扩增至200以上）。外祖父的震颤与共济失调是**脆性X相关震颤/共济失调综合征**，由前突变的RNA功能获得引起；母亲的卵巢早衰是**前突变相关的原发性卵巢功能不全**——同一位点在三种重复长度上产生三种机制不同的疾病。处理随机制而来：测定其母亲的重复数与甲基化状态；检测其母亲的同胞与外祖母（外祖母若为中间或前突变等位基因，即可识别更多风险妊娠）；为其母亲的姐妹及其亲属提供关于卵巢储备与生育患病子女风险的咨询；说明全突变男性的姐妹可为轻型受累携带者；并注意这个男孩的管理需要教育支持、针对焦虑与孤独症谱系特征的行为治疗、心脏与骨科随访，而不是疾病修饰药物。由于检测结果牵涉三代人，结果披露应征得家庭同意及父母代儿童作出的同意，报告既写给临床医生，也写给这个家庭。
:::
:::

## 嵌合体

::: definition 嵌合体 {#def-mosaicism}
**嵌合体**指同一个体内存在两个以上遗传上不同的细胞系。**体细胞嵌合**源于合子后突变，其范围取决于发生突变的发育阶段与谱系；**生殖系（性腺）嵌合**全部或主要局限于生殖细胞，因此一个外周血基因组两次都正常的父母可以有多个患病孩子；**合子后性腺嵌合**两者兼有。嵌合个体的表型可限于受累谱系：沿Blaschko线分布的节段性皮肤损害、单侧白内障、孤立性半身肥大，或一侧半球的大脑畸形。
:::

有三种临床形式重要。**RAS病与PIK3CA相关过度生长**，以及**McCune-Albright综合征**（合子后*GNAS*激活突变：多骨性纤维异常增殖症、边界呈“缅因海岸”样锯齿且不越过中线牛奶咖啡斑、性早熟与其他内分泌功能亢进）必然是嵌合的，因为同一突变若见于生殖系即致死。**貌似新发的显性变异之后再现**——父母均正常却有两个患病子女的成骨不全与软骨发育不全家庭——是生殖系嵌合，这也是为什么“低于1%”的再发风险应当连同机制一起以区间形式给出的原因。**检出**取决于组织与测序深度：皮肤成纤维细胞中8%的变异在血液中可能测不到，因此对受累组织做靶向深度测序（就拷贝数而言则用更高密度微阵列或显微镜）是诊断步骤而非最后手段；血液“阴性”绝不应作为排除嵌合报告给家庭。

::: example 沿一条线分布的皮疹 {#ex-mosaic}
一名6岁儿童自婴儿期起左小腿有沿Blaschko线分布的线状疣状皮损，现患癫痫，MRI示左额叶局灶性皮质发育不良。腹部外观正常皮肤的活检在常规测序中未见变异。
::: solution
两处病变均符合合子后生长信号基因激活——即表皮痣综合征的模式，如嵌合性*PIK3CA*、*HRAS*、*AKT3*或*KRAS*所致者：同一变异存在于脑与皮肤，但等位基因比例低，且血液中永不出现。远端皮肤的常规检测阴性不能排除诊断；正确的标本是受累组织（皮损处皮肤，或如行手术则切除的脑组织），正确的方法是能检出百分之几序列读段的深度靶向测序。处理是对症与预见性的：控制发作，若发育不良可切除且与发作学一致则转诊癫痫外科；发育支持；皮肤科与骨科随访；以及相关综合征伴随表现（部分包括肿瘤风险）的监测。其父母的再发风险可忽略；患儿本人的生育风险低且取决于谱系——这是一个诚实的答案，但它要求说出机制，而不是读家系。
:::
:::

::: warning 血液检测阴性不能排除嵌合体、单亲二体或印记缺陷
造成假性安心“正常”结果的最常见三个原因全都是取样问题。嵌合变异可以在皮肤为5%而在白细胞中测不到，常规Sanger或外显子组流程会丢弃低比例调用。单亲二体不改变拷贝数，除非平台报告杂合性丢失或分析特意寻找，否则微阵列看不见它；节段性UPD会伪装成缺失所致杂合性丢失。只检测一个位点的甲基化可能漏掉印记缺陷，且在嵌合性印记病中甲基化结果可以部分正常。所以开单之前的问题是：哪个组织、哪种机制、这个检测能否在我需要的水平上看到它？
:::

- [ ] 她无症状，说明其重复不可能扩增，其子女没有风险。
- [x] 她可能携带正常或中间等位基因，或一个可在母系传递中扩增、导致子女先天型或早发型的扩展等位基因。
- [ ] 她的风险是2分之1发病，但其子女没有风险。
- [ ] 强直性肌营养不良的早现只经父亲发生。
::: solution
强直性肌营养不良是伴早现的常染色体显性病，先天型几乎完全经母亲传递显著扩增的等位基因所致。一名无症状的35岁女性，其重复数可在正常范围、在可变中间范围，或少见的、尚无症状的低水平扩展；重复长度测定（而非panel或外显子组）可以回答此问题；若她为携带者，还需讨论其卵母细胞中的扩增风险。检测其父系一侧同样重要，因其兄弟的扩增可能来自父母任何一方，其他亲属也可能有风险。
:::
:::

::: history
个体可以是遗传嵌合体的思想可追溯至20世纪初的波韦里（Theodor Boveri）。线粒体遗传于1988年进入医学：华莱士（Ian Wallace）等鉴定出Leber遗传性视神经病变的m.11778G>A变异，证明母系传递的线粒体DNA突变可致人类疾病；tRNA综合征MELAS与MERRF随后被发现，异质性与卵母细胞瓶颈在1990年代被阐明。基因组印记于1980–1990年代由韦斯（Marion Weiss）、苏拉尼（Azim Surani）、索尔特（Davor Solter）等的小鼠工作确立，其人类对应证据见于Ledbetter与Matalon两组的单亲二体报道，以及1989–1993年间证明15q11-q13缺失依亲源不同导致Prader-Willi或Angelman综合征——为Prader、Labhart与Willi（1956）及Angelman（1965）早已描述的两种临床实体给出了解释。重复序列扩增时代由1991年脆性X的CGG重复、1992年强直性肌营养不良的CTG与1993年Huntington病的CAG开启；自1920年代起在被累及家庭中观察到的早现现象，被解释为DNA聚合酶滑移与修复的一个分子属性。
:::

## 通向何处

例外背后的机器见[[cell-biochemistry/gene-expression]]（复制滑移、DNA甲基化、染色质）与[[cell-biochemistry/signalling-cell-cycle]]（生长通路嵌合体）。基于家系的风险算术见[[genetics/mendelian-inheritance]]；诊断的实验室路径见[[genetics/genetic-testing]]；UPD与印记的肿瘤后果见[[genetics/cancer-genetics]]。

::: summary
- 线粒体DNA母系遗传、异质、依阈值而起作用；卵母细胞瓶颈使负荷（从而病情轻重）在亲属间不可预测，外周血负荷是终末分裂后组织的糟糕替代。
- 多数儿童线粒体病为核基因编码，故为常染色体隐性、再发风险4分之1——咨询前先确定这个家庭属于哪一型。
- 印记位点按亲源表达，故单亲二体、缺失的亲源侧别与印记中心缺陷都会致病；Prader-Willi与Angelman是从相反亲本看同一区间。
- 重复扩增引起早现，扩增在传递性别上有亲源偏倚；同一位点在不同重复长度产生不同疾病（前突变、全突变）。
- 嵌合体解释“散发”显性病的再发、节段性皮肤与脑病，以及表型与血检之间的多数落差；在受累组织上用深度检测作出诊断。
- 早现、印记与嵌合并非奇闻：它们每一个都会改变所报的再发风险、所开的检测和所送检的组织。
:::

## 练习

::: exercise 一个线粒体病的家系 {level=1}
一名携带m.3243A>G变异的男性患者与一位健康女性育有三名子女。其子女或孙辈患病的风险多大？为什么？
::: solution
他的子女都不从他继承mtDNA，因为线粒体来自卵母细胞；他们的孩子经这一系也因此没有风险。他的姐妹若携带该变异则可能传递，其母系家族需要追查。这是家系图能给出干净结论的极少数情形之一，值得就用这几句话告诉家属。
:::
:::

::: exercise 母亲的检测为何失败 {level=1}
一名临床Kearns-Sayre综合征的女孩血mtDNA分析正常。请解释，并说明下一步。
::: solution
单一大片段mtDNA缺失通常在白细胞中水平极低或测不到，因为携带大缺失的细胞在有丝分裂中被淘汰，而终末分裂后组织保留之。检测尿上皮标本（常规做“颊黏膜—尿沉渣”配对DNA），若仍阴性则查肌肉，用长片段PCR或Southern印迹查缺失；肌活检还可见破碎红纤维与COX阴性纤维。大多数单一缺失为散发，母亲未来子女的再发风险低——这个答案同时回答了生育问题。
:::
:::

::: exercise 重复长度与风险 {level=2}
一名男性*HTT*有41个CAG重复；其父60岁发病Huntington病。41个重复意味着什么？其子女风险多大？
::: solution
正常*HTT*等位基因不超过约26个重复，27–35为中间型（不致病但父系传递中不稳定），36–39为外显率降低型，40次及以上为完全外显。41个重复，只要他活得足够久就会发病，预期起病在成年晚期；每个孩子有2分之1概率继承该等位基因，且精子发生中更易扩增，故继承其等位基因的孩子可能有更长的重复和更早的发病。对未成年者就成年起病疾病做症状前检测不予提供；讨论的对象是他本人，包括生育选项——产前诊断、在风险亲本不愿知晓自身状态时采用排除策略的植入前遗传学检测，以及不检测的选择——并为每种选择提供咨询与支持。
:::
:::

::: exercise 实践中的嵌合 {level=2}
一名临床诊断I型神经纤维瘤病的男孩，牛奶咖啡斑、皱褶处雀斑与丛状神经纤维瘤局限于一个肢体，无家族史；血液常规测序未见*NF1*变异。如何解释？如何检测与咨询？
::: solution
节段性（V型）神经纤维瘤病由局限于受累谱系的合子后体细胞*NF1*突变引起，故白细胞DNA阴性，诊断为临床诊断；只有在深入测序皮损或神经纤维瘤时才可获得分子确证。其子女的再发风险不是经典型NF1的2分之1，但也不是零，因为可能合并性腺受累；实际建议是个位数的低风险；检查其父母与同胞以发现提示遗传性变异的轻型表现；并转诊继续部分需要的监测（血压、眼科，以及对受累区域出现NF1肿瘤的警觉）。
:::
:::

::: exercise 两种机制，同一结果 {level=3}
一名Angelman综合征女孩甲基化检测异常，微阵列未见缺失，双亲DNA检测示15q11-q13有两个母源等位基因、无父源等位基因。写出机制、再发风险，以及仍需核查的两件事。
::: solution
机制是**15号染色体母源单亲二体**（或节段性UPD）：她该区有两个母源拷贝，因而不存在表达*UBE3A*的父源染色体、父源转录本缺失，产生Angelman综合征。单亲二体后的再发风险很低，因为机制是偶发的三体自救或单体自救事件；但必须在父母核型中排除罗伯逊易位或活跃的减数分裂错误，并用第二种方法（基于SNP的拷贝中性杂合性丢失或微卫星分析）确证机制，因为只看甲基化时，小缺失或印记中心缺陷可伪装成UPD。表型与机制相关——缺失通常最重、UPD略轻——这正是“她将来会怎样”的回答取决于你确立的机制的原因。
:::
:::

::: exercise 表观遗传与一个家庭 {level=3}
一名儿童患瞬时性新生儿糖尿病，伴高甘油三酯血症与巨舌；甲基化检测示6q24 PLAGL1/HYMAI印记调控区母源甲基化丢失。其母30岁诊断2型糖尿病，且有巨大儿生育史。解释这一家庭图景与生育学意义。
::: solution
瞬时性新生儿糖尿病源于父源表达的*PLAGL1*/*HYMAI*位点过表达，一种机制是印记调控区母源低甲基化，使母源等位基因按父源模式表达。母源*ZFP57*变异——早期胚胎维持印记所需的转录因子——可引起同样的低甲基化，且因其隐性，同胞再发风险4分之1；*ZFP57*女性携带者本身亦有妊娠期糖尿病与巨大儿倾向，与其母的病史吻合；*ZFP57*相关病例常在多个印记位点出现低甲基化。因此应：全基因组检测印记位点（多印记位点障碍）、对*ZFP57*测序、检查父亲的甲基化，若模式符合，则向父母提供基于携带状态的咨询——再发风险取决于这是*ZFP57*隐性效应、印记中心缺陷，还是偶发表观突变。
:::
:::

::: exercise 设计一项研究 {level=3}
一名10岁儿童患偏侧巨脑畸形与顽固性癫痫，MRI证实单侧畸形；血液外显子组无诊断性发现；手术标本可获得。请描述检测方案及其解释的限度。
::: solution
对切除组织、如可能再对受累侧皮肤成纤维细胞做深度测序（组织的靶向panel或全外显子组），并与血液比较等位基因比例，以区分合子后嵌合与胚系变异；同时查找拷贝数改变及机制靶通路（mTOR通路基因：*PIK3CA*、*AKT3*、*PTEN*、*MTOR*、*DEPDC5*），测序阴性时以通路激活的免疫组化作为支持证据。解释限度：纯度低的标本会漏掉百分之几的变异；高比例变异可能反映标本内的选择而非致病事件；脑内发现的变异只有在为已知或可信致病的功能获得型改变、且其嵌合表型相符的基因中才具有因果意义，需要功能或数据库支持，理想时还在显微切割的病变组织中加以证实。而结果的临床用途是真实的：mTOR通路嵌合可改变手术与药物治疗决策（mTOR抑制剂已用于结节性硬化及相关表现），并能确立这个家庭的再发风险可忽略而非25%。
:::
:::

::: exercise 核基因还是线粒体？ {level=2}
同一家庭的姐弟二人均罹患Leigh样综合征，伴乳酸酸中毒与基底节改变；其母健康，父母为一级姑表兄妹。血mtDNA测序未见致病变异。最可能的遗传方式是什么？对父母意味着什么？应做什么检测？
::: solution
两个不同性别的患病同胞、健康父母加上近亲婚配，指向**常染色体隐性核基因**性线粒体病；mtDNA测序阴性符合而非意外，因为多数儿童线粒体病是核基因编码的——复合体Ⅰ、Ⅱ、Ⅲ、Ⅳ、Ⅴ的装配与翻译因子（如伴细胞色素c氧化酶缺乏的Leigh综合征之*SURF1*）、CoQ10与硫辛酸通路、mtDNA维持与耗竭综合征（*TK2*、*DGUOK*、*POLG*），以及丙酮酸脱氢酶复合体基因——其中*PDHA1*为X连锁，可貌似线粒体遗传。这对夫妇未来每次妊娠风险4分之1，扩展家庭需同样咨询。检测：肌肉与成纤维细胞呼吸链酶活性、mtDNA拷贝数与缺失分析、核基因测序——鉴于近亲婚配，优先选择线粒体基因靶向panel或外显子组/基因组测序加同源区作图——测序无果时行肌活检。确定基因之所以要紧，是因为其中少数可治（核黄素反应性复合体Ⅰ缺乏、CoQ10、生物素对全羧化酶合成酶缺乏、生酮饮食加硫胺对PDH缺乏），也因为在选择性耗竭综合征中已有肝移植等治疗先例。
:::
