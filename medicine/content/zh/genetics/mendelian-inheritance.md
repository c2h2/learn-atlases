家系图是一件有其自身逻辑的证据。连续三代表面健康、夫妇来自同一村庄，却育有一男一女两名患病子女，提示隐性机制；每一代都有患病男性、但其儿子均不患病，提示X连锁；一个成年起病的家系中每一代都不“跳过”，提示伴年龄依赖性外显率的显性传递。正确读出这一逻辑，将改变对亲属提供的检查、向家属告知的风险数字，以及一次阴性检测的意义。

本章讲清单基因遗传的三种模式——常染色体显性、常染色体隐性、X连锁——以及它们偏离期望时所用的词汇，和遗传咨询门诊中实际使用的概率运算。

## 单基因的词汇

::: definition 基本概念 {#def-terms}
**基因型**指一个位点上一对等位基因的组成；**表型**是可观察的结果。携带两个相同致病等位基因的个体为**纯合子**；同一位点携带两个不同致病等位基因者为**复合杂合子**——近亲婚配所生隐性病患的常见情形，也是病情轻重可随等位基因组合而异的原因。X染色体上携带某变异的男性（或携带缺失的细胞）为**半合子**。**携带者**指携带致病等位基因而不发病者——这一术语严格来说只适用于隐性遗传，在X连锁或显性病中滥用会误导家属。**近亲婚配**指双方有共同祖先：**近婚系数**$F$是子代某个位点上两个等位基因同源一致的概率，一级姑表/姨表兄妹（first cousins）子女的$F = 1/16$。**表型模仿**（phenocopy）指环境因素造成的、与遗传性表型无法区分的表现（氨基糖苷类或连接蛋白变异所致的耳聋；药物或*KCNQ1*突变所致的QT间期延长）。
:::

单个突变等位基因产生显性表型有三种机制，分清是哪一种即可解释表型与治疗：**单倍剂量不足**（50%的产物不够——*PAX6*、*TBX1*，*LMNA*部分如此）；**显性负效应**（突变产物破坏多聚体——胶原三股螺旋、p53、连接蛋白）；以及**功能获得**（新的或失调控的活性——软骨发育不全中的*FGFR3*、MEN2中的*RET*、高钾型周期性瘫痪中的钠通道*SCN4A*）。相比之下，隐性病通常是酶或转运体的功能丧失，而50%的活性尚高于阈值——即[[cell-biochemistry/gene-expression]]中叙述的阈值效应。

## 常染色体显性遗传

::: definition 常染色体显性遗传 {#def-ad}
表型在杂合子中显现。典型特征：性状每代均出现（垂直传递）；男女均等受累且均能传递；患病的杂合者将疾病传给一半子女，儿女人人机会均等；而由于*新生*变异、不完全外显、轻型病例未被识别，或——在历史上——患者育前早逝，家族史可以完全为阴性。
:::

以下实例各取其说明要点：**马凡综合征**（*FBN1*，表达度可变：主动脉根部病变、晶状体向上方外方脱位、骨骼表现；主动脉夹层风险主导整个管理方案）;**I型神经纤维瘤病**（基因多效性：牛奶咖啡斑、神经纤维瘤、视路胶质瘤、骨与血管病变、学习困难；诊断为临床诊断，同一变异在同胞间可轻可重）;**软骨发育不全**（*FGFR3*功能获得；约80%为新发突变，与父龄相关；纯合型致死）;**成人型多囊肾病**（*PKD1*/*PKD2*；晚发，故年轻亲属需影像检查，或更佳者，在遗传咨询后进行症状前检测）;**I型强直性肌营养不良**（CTG扩增伴早现现象，先天型仅经母系传递，多系统受累——见[[genetics/non-mendelian-inheritance]]）;**遗传性非息肉病性结直肠癌/Lynch综合征**（传递的是一种*易感性*的显性遗传，细胞水平则是隐性失活——Knudson的两次打击）;**家族性高胆固醇血症**（LDL表型呈显性，也是级联筛查的典范）。

两点特征主导咨询。**晚发**意味着亲属在未有人发病前即处于风险之中，这正是症状前检测必须按流程进行的原因——先咨询、留考虑间隔、针对已知家系变异的确证检测、商定结果告知安排并随访——也是阴性结果既带来解脱又可能带来幸存者内疚的原因。**不完全外显与表达度可变**意味着表面正常的亲代仍可能携带变异，故孙辈的再发风险并非为零，“健康”的家族史不能排除诊断。

## 常染色体隐性遗传

::: definition 常染色体隐性遗传 {#def-ar}
需要两个致病等位基因。典型特征：先证者往往是同胞中唯一的患者（水平分布）；男女受累机会均等；双亲均为携带者时，每个子女有4分之1的患病风险、2分之1的可能是携带者、4分之1的可能是两者皆非；父母通常健康，若该病罕见，父母可能彼此相关。患者的子女皆为携带者，只有当配偶也是携带者时才发病（**假显性**，见于隐性病在人群中相当常见的情况）。
:::

隐性病不成比例地集中于**酶病与转运体病**，其临床格局随之而来：囊性纤维化、血红蛋白病、苯丙酮尿症及其他氨基酸病、糖原病与溶酶体贮积症、先天性肾上腺皮质增生症、肝豆状核变性、白化病、脊髓性肌萎缩以及各类感音神经性耳聋。有两点概率推论在门诊中很重要。其一，患儿的健康同胞是携带者的概率为3分之2（在“未患病”条件下的2分之1×修正：正是学生常漏掉的条件概率计算），此人子女的风险为$2/3 \times 1/2 \times$（其配偶的人群携带者频率）。其二，近亲婚配使罕见隐性等位基因同时出现在双方家族的概率升高：一级姑表兄妹子女$F = 1/16$，故因共同祖先带来的额外风险约为该罕见隐性病的$1/16$——经验上，严重常染色体隐性或多基因病的风险从基线的约2–3%升至约4–6%，围产儿死亡率另有小幅升高；应当引用的是这一对夫妇自己的家族史，而不是笼统的数字。

## X连锁遗传

::: definition X连锁遗传 {#def-xl}
**X连锁隐性**：半合子男性发病；不存在父传子（父亲只把X传给女儿）；变异经女性携带者进入家系；男患者的姐妹各有2分之1可能是携带者，其女儿则为必然携带者。**X连锁显性**：男女均可受累，男性有时更重或宫内致死（如色素失禁症，*IKBKG*）；男患者的女儿全部受累、儿子全不受累——此即与常染色体显性相区别的模式。**症状性杂合子**：出现症状的女性携带者，因X失活偏向正常等位基因一侧，或因X结构异常、Turner嵌合所致。
:::

X连锁疾病的携带者检测是概率必须明确的经典场合。若一名女性的兄弟患Duchenne型肌营养不良、其母为必然携带者，则该女性的先验风险为2分之1；每一健康儿子使其乘以2分之1，正常的肌酸激酶或正常的抗肌营养不良蛋白检测结果再进一步修正——数字必须合并而非互相取代，同一张家系图上不同家庭的结果也各不相同。女性携带者同样需要临床关注，因为*DMD*基因女性携带者中相当比例的少数会发生心肌病，无论有无肌力下降均需监测；血友病携带者可能出血，这影响手术、分娩与麻醉的计划。

::: example 给携带概率一个数字 {#ex-carrier}
一名女性的兄弟患X连锁重症联合免疫缺陷；其父母均未患病，她本人有两个健康儿子。问：她为携带者的风险多大？其儿子患病的风险多大？
::: solution
依家系结构把母亲视为必然携带者或可能携带者；在母亲确为携带者的标准情形下，该女性的先验风险为$1/2$。每个健康儿子使其减半，因为携带者的儿子有$1/2$概率患病，而非携带者的儿子不会患病：两个儿子之后后验风险为$\dfrac{0.5 \times 0.5^{2}}{0.5 \times 0.5^{2} + 0.5} = 1/5$。其儿子患病的风险于是为$1/5 \times 1/2 \approx 1/10$——而不是家属记忆中初次咨询时的那个4分之1。反过来，若母亲本人的携带状态尚不确定，或先证者的变异为新发，则必须把新突变率纳入先验，算法随之改变；这正是遗传科医生需要确切的变异、确切受检的亲属和一张呈现在屏幕上的家系图，而不是一句“我们觉得这病是随女辈传的”的原因。
:::
:::

## 为什么真实家系会“不守规矩”

| 现象 | 含义 | 对家系图的影响 |
|---|---|---|
| 外显率降低 | 部分携带者终生不发病 | 看似跳代；风险无法凭临床排除 |
| 表达度可变 | 同一变异，轻重不同 | 与重症患儿同持一致变异的“轻型”亲代 |
| 早现现象 | 逐代发病更早或更重 | 重复序列扩增：强直性肌营养不良、Huntington病、脆性X |
| 位点异质性 | 不同基因的变异引起同一表型 | 单一基因检测阴性不能排除疾病（视网膜色素变性、非综合征性耳聋、遗传性乳腺癌） |
| 等位基因异质性 | 同一基因的不同变异表型不同 | 基因型–表型相关；以及人群特异的奠基者等位基因 |
| 基因多效性 | 一个基因，多个器官系统 | 神经纤维瘤病、Marfan、*PKD1* |
| 表型模仿 | 环境模仿基因型 | 药物性耳聋或QT延长；高外显家系中的“散发”病例 |
| 单亲二体、嵌合体、生殖腺嵌合 | 非孟德尔式传递 | 看似*新发*诊断后的再发；若存在性腺嵌合，再发风险高于所报数字 |
| 假显性 | 隐性等位基因很常见 | 患者的父母之一亦患病，貌似显性（某些人群中的地中海贫血） |

还有两点措辞上的讲究可避免门诊中大多数错误。**再发风险以每次妊娠计**：一对夫妇已有两个患病孩子，并不改变下一胎4分之1的风险；“到咱们这一代总算断了”这类安慰是换上白大褂的赌徒谬误。以及**阴性不等于清白**：对一个从未证明存在于家系中的变异的阴性检测、对存在位点异质性基因的panel阴性、或在酶本就不表达的组织中做的正常酶学检测，回答的都不是所问的那个问题。

::: example 矮个子父亲与高高的孕肚 {#ex-achondroplasia}
一名孕妇孕26周因股骨偏短转诊。父亲患软骨发育不全；母亲身材正常，无家族史。超声示股骨长度低于第3百分位，无羊水过多。
::: solution
软骨发育不全是功能获得性*FGFR3*变异所致的常染色体显性病，而纯合子——本对夫妇不可能有，因母亲不带变异——围产期致死。故先验风险为2分之1，超声所见又显著提高后验概率，因此处理原则是确证而非假定：对羊水细胞或绒毛膜绒毛细胞做父源家系变异的靶向检测（快速，且答的是真正的问题），详细的胎儿结构筛查（含头颅形态与胸围），并咨询告知：预期的表型即其父亲的表型——连同随之而来的风险：婴儿期枕骨大孔狭窄与颈髓压迫、中耳疾病与听力下降、胸腰椎后凸、阻塞性睡眠呼吸暂停，以及生长、神经与骨科随访和特殊的麻醉注意事项。若胎儿股骨正常，则超声所见需另有解释（体质性、胎盘性、染色体性，或另一种遗传方式的骨发育不良），故应继续生长监测，而这对夫妇的再发风险未必是当初承诺的那个低值。不了解家系变异、仅凭“超声看着偏短”就去做检测，正是答非所问的典型。
:::
:::

::: example 近亲婚配与一次“阴性”检测 {#ex-consanguinity}
一名孕妇的父母为一级姑表兄妹；其侄儿患脊髓性肌萎缩症。她本人的SMN1缺失检测报阴性。她问：孩子有风险吗？
::: solution
两个独立的计算。其一，检测阴性之下她仍为携带者的风险：95–98%的脊髓性肌萎缩症患者为*SMN1*外显子7纯合缺失，故基于缺失的携带者检测会漏掉另外2–5%第二个等位基因为点突变的携带者，“阴性”结果残留的风险约为三十分之一到五十分之一的先验超越概率——正确的表述是“这个结果使可能性小多了，数字在这里”。其二，家系结构：侄儿的患病亲代是她的同胞或其配偶的同胞，其配偶可能共享同一位祖先。夫妇双方应采用能检出点突变的方法（*SMN1*测序加拷贝数检测）复检携带状态；若双方均携带致病等位基因，胎儿风险即为4分之1，与先前的阴性报告无关。同时，姑表婚配带来的基线风险仍适用于本次妊娠——严重隐性或多基因病额外增加2–3%——此事应在家族史的语境中提及一次，而不应像诊断一样反复强调。
:::
:::

::: example 两个健康父母，两个病孩：一次“新发”显性变异之后的再发 {#ex-mosaicism}
一对夫妇第一胎死产，骨骼改变符合致死型（Ⅱ型）成骨不全；父母双方骨骼正常、无骨脆性、家族史阴性，且外周血检测未见*COL1A1*或*COL1A2*变异。第二胎正常。第三胎孕10周，他们来问风险。
::: solution
胶原的显性负效应突变按预期在纯合状态——对结构型等位基因而言甚至在杂合状态——即致死，故此类病例多为新发突变。但该夫妇下一胎的风险**并非**人群突变率：只存在于亲代一方一部分生殖细胞、而不在其血液中的变异——性腺或生殖系嵌合——是血检查不出的；经验上，第一胎患病而双亲检测阴性的夫妇中约5–10%会有第二个患病孩子。因此正确的咨询是给出一个区间（百分之几的量级，多数中心对致死型成骨不全报5–10%，因为确有再发病例报告），计划在孕早期超声监测，并在本次妊娠中对绒毛或羊水细胞检测先证儿已鉴定的家系变异——这也是为什么在考虑再次妊娠之前值得找回并复检第一胎保存的DNA（或皮肤成纤维细胞培养物）。若无法获得该变异，检测仍可有参考价值但须谨慎，且应告知夫妇：“低风险”的估计同样背着性腺嵌合这个前提。同一逻辑——双亲检测阴性买不来零风险——适用于软骨发育不全、母亲可能为嵌合体的X连锁疾病，以及大量“散发”病例之后再见于文献的病种。
:::
:::

::: quiz
一名30岁男性患常染色体显性多囊肾病，*PKD1*变异已知。其父母均健在，62岁的父亲从未做过超声。关于父亲的携带状态，最佳估计是？
- [ ] 他肯定未受累，因为患者的外祖父没有肾病。
- [x] 他可能携带该变异而外显随年龄未全；其本人患病的可能并非零，唯有超声或基因检测可以分辨。
- [ ] 他必然携带，因为*PKD1*是显性基因。
- [ ] 他的状态与其其他子女无关。
::: solution
成人型多囊肾病具有年龄依赖性外显：许多携带者在二十余岁尚无可检出的囊肿，故62岁无病降低了但不能排除这种可能，而患者本人新发变异同样可能。这一区分有临床意义：若他确实携带，其其他子女（患者的伯/叔/姑/舅/姨）各有2分之1的风险，可自筛查与血压管理中获益；而患者同胞的风险也取决于变异来自哪一方亲代。
:::
:::

孟德尔（Mendel）1866年的论文给出了比例，但医学模式来自加罗德（Garrod）：他在1902年对尿黑酸尿症的论述明确论证该病为隐性、近亲婚配的父母比例过高、且“化学个体性”在家族中传递；其1908年的Croonian讲座把这一思想推广为一整类疾病。贝特森（William Bateson）于1905年将孟德尔学说引入人类医学，加罗德（Archibald Garrod）等描述了“先天性代谢错误”，Hutchison、Suter等人开始积累耳聋、共济失调与失明家系。霍尔丹（J. B. S. Haldane）1935年关于X连锁致死基因突变率的论文指出，X连锁病的频率是突变与选择之间的平衡，并推导出X连锁致死病（如Duchenne型肌营养不良）约三分之一的病例源于新突变——这正是此类家系中三分之一母亲并非携带者的原因。奥尔巴赫（Charlotte Auerbach）关于突变的研究，以及1960年代起麦克西克（Victor McKusick）的《医学遗传学》与后来成为OMIM的汇编，给了这门学科教科书与目录。莱昂（Mary Lyon）1961年的假说解释了女性携带者，莫图尔茨基（Arno Motulsky）、斯克里文（Charles Scriver）与同代人建立了生化与咨询实践，使临床遗传学成为有自身伦理的专科：信息、非指令化，以及以家庭而非单个患者为照护单位。
:::

## 通向何处

例外与复杂情况——线粒体遗传、基因组印记、重复序列扩增、嵌合体——见[[genetics/non-mendelian-inheritance]]；如何对家系提示的问题选择检测见[[genetics/genetic-testing]]；染色体层面的模式见[[genetics/chromosomal-disorders]]；常见病的多基因算术见[[genetics/common-disease-genetics]]。

::: summary
- 常染色体显性：垂直传递、男女均等、每胎2分之1；因新突变、晚发或外显不全，可以完全没有与本病相符的家族史。
- 常染色体隐性：水平分布、见于同胞、每胎4分之1，多为酶病；健康同胞的携带者风险为3分之2；近亲婚配经血缘同源一致性提高风险（一级姑表兄妹子女$F = 1/16$）。
- X连锁隐性：男性发病、女性携带、无父传子；携带者风险是一个贝叶斯量，随每位受检亲属而变；女性携带者需要心脏与出血监测。
- 显性的机制是单倍剂量不足、显性负效应或功能获得；隐性病是低于阈值的功能丧失——机制既预言家系形态，也预言治疗方向。
- 家系偏离孟德尔期望的原因有外显率、表达度、早现、异质性、基因多效性、表型模仿、嵌合体与单亲二体；临床医生的任务是在报出风险数字之前先辨明是其中哪一种。
- 再发风险以每次妊娠计；阴性检测只等于检测本身能看到的：针对家系变异的检测与位点异质性，是假性安心结论的两个最常见来源。
:::

## 练习

::: exercise 近亲系数计算 {level=1 check=“0.0625”}
一级姑表兄妹（first cousins）所生子女的近婚系数$F$是多少？
::: solution
$F = 1/16 = 0.0625$：传递路径在每一侧各经过两代、每代一次减数分裂，每位共同祖先是$(1/2)^{5}$，两位共同祖父母（外祖父母）加倍。路径自两位共同祖先中每一位向下经亲代达子代——共五次减数分裂，每位祖先得$(1/2)^{5}$，两位相乘加倍——故约6.25%的位点预期为血缘同源纯合，这正是罕见隐性病风险升高的原因。
:::
:::

::: exercise 3分之2规则 {level=1}
一对夫妇均为某隐性病的携带者。他们的女儿未患病。她是携带者的概率多大？若她的配偶是同一人群的携带者，其第一胎患病的风险多大？
::: solution
在“未患病”条件下，她为携带者（概率$2/3$）或两者皆非（1/3），故携带概率为$2/3$。若其配偶*确为*携带者，第一胎风险为$2/3 \times 1/4 = 1/6$；若配偶本人的携带概率为$p$，则风险为$2/3 \times p \times 1/4$。把两个因子分开保留，才能在配偶的检测结果出来后更新这个数字。
:::
:::

::: exercise 不完全外显下的风险 {level=1 check=“1/15”}
一名男性的母亲确诊患外显率为80%的常染色体显性病；他25岁且未发病。其子女患病的概率多大？以分数作答。
::: solution
他携带变异的先验风险为1/2；25岁未病按贝叶斯将其降为$\dfrac{0.5 \times 0.2}{0.5 \times 0.2 + 0.5 \times 1} = 1/6$。其子女继承变异的概率为$1/6 \times 1/2 = 1/12$，发病概率为$1/12 \times 0.8 \approx 0.067$——约15分之1。注意两个问题（“他携带吗？”“携带会发病吗？”）是分开回答的，而整个计算的大部分功夫只是别把两者混为一谈。
:::
:::

::: exercise 模式识别 {level=2}
对下列每种家系描述，指出最可能的遗传方式：(a) 一同胞群中男患者，其母系舅舅皆患病，未发病女性不传递给其儿子；(b) 男患者的每个女儿均患病，每个儿子均正常；(c) 一小型社区中健康夫妇育有患病的一男一女两个孩子；(d) 亲代轻症、子女重症，呈早现模式，且先天型仅经母亲传递。
::: solution
(a) X连锁隐性（男性发病、经女性携带者传递，其儿子——即母系舅舅——患病）。(b) X连锁显性，因男患者把X传给所有女儿而不传儿子。(c) 常染色体隐性，可能存在奠基者等位基因。(d) 重复序列扩增所致常染色体显性，伴早现、母系传递时出现重症先天型——I型强直性肌营养不良即其典范。
:::
:::

::: exercise 新突变还是遗传？ {level=2}
一名患软骨发育不全的男孩父母身材均正常，夫妇正考虑再生育。再发风险多大？依据什么推理？
::: solution
约80%的软骨发育不全为新的显性突变，多位于父源等位基因并与父龄相关；若证实胎儿的*FGFR3*变异不存在于双亲血液中，则再发风险低但并非可忽略——因为一小部分此类家庭存在性腺（生殖系）嵌合，也因为非父子关系属于应由咨询处理而非归咎实验室的事由。故夫妇其他子女的风险在1%以内量级，应以区间并说明理由的方式告知，并提供未来妊娠早期超声测股骨长的选项。其机制为功能获得性变异、纯合致死——这对夫妇若双方均患病会问及生育问题时，这一点就很要紧。
:::
:::

::: exercise 出错的携带者检测 {level=3}
一名女性的表姑母死于囊性纤维化。实验室报告她的囊性纤维化靶向突变panel检测“阴性”。其配偶的panel亦为阴性。请向这对夫妇解释，为何其残留风险并非零——给出三个彼此独立的理由。
::: solution
第一，panel不是基因：靶向panel只检出其所含变异（通常覆盖目标人群70–90%的致病等位基因），故阴性结果仍留有罕见或全新*CFTR*变异的可能，残留携带风险是一个可计算的数字，通常是人群风险的某个分数而非零。第二，族裔要紧：为北欧裔变异设计的panel在非洲、亚洲或中东裔中表现更差，报出结果数字之前应先记录夫妇的族裔背景。第三，表型谱：*CFTR*变异谱从经典型疾病一直到孤立的先天性双侧输精管缺如或胰腺炎，故亲属身上的“轻型”变异可能不在panel之列，某些基因型甚至不引起汗氯升高。然后说明后续：若追求最小残留风险，可做全基因分析（或外显子组/基因组测序）；一旦两个等位基因均已明确，即可选择产前或植入前检测；或按现有数字继续妊娠。
:::
:::

::: exercise 症状性携带者 {level=3}
一名19岁女性进行性近端肌无力，肌酸激酶1,800 U/L；其外甥患Duchenne型肌营养不良。基因检测证实她携带家系*DMD*缺失。请解释女性携带者为何可以发病，还应检查什么。
::: solution
由于Lyon所描述的随机X失活，女性携带者本身是嵌合体；若失活偏向于沉默携带正常等位基因的那条X——可能出于偶然，也可能因X结构异常，或对表达正常X的细胞存在选择——她就会表达表型，可仅表现为心肌病，也可伴肢体带型肌无力。应做的检查：不论有无症状均行心脏评估（心电图、超声心动图或心脏MRI），因携带者相关扩张型心肌病可先于骨骼肌无力出现；肌无力明显者评估呼吸功能；复查CK并完善肌病评估（MRI模式；诊断存疑时行肌活检加抗肌营养不良蛋白染色）；除外肾性等其他CK升高原因；就其本人子女（2分之1概率传递变异，儿子患病、女儿为携带者）及其余家庭成员进行遗传咨询；并在其病历中显著标注，使产科、麻醉与手术团队在有创操作前知晓她患肌营养不良蛋白病——届时需要呼吸与心脏评估，并应避免司可林（琥珀胆碱）与吸入麻醉药。
:::

::: exercise 设计一次咨询 {level=3}
一名24岁无症状男性的父亲刚被基因确诊为Huntington病。他前来要求检测。请陈述你的处理步骤及每步的意义。
::: solution
不要当场检测。先完整采集病史（情绪、酒精与物质使用、亲密关系、工作、子女与生育计划），说明阳性结果无法撤回，并伴随抑郁、幸存者内疚、关系变化，以及在没有反歧视立法辖区内的保险与职业影响等风险，也说明阴性结果同样有心理后坐力。确认患病亲属的家系变异已有记录；与临床遗传团队、最好再与患者支持组织安排一次检测前咨询，并问明家庭中谁会被告知。提供冷静期与第二次门诊；只在接受者书面同意、由有症状前检测经验的实验室检测，结果当面告知并安排随访（含心理健康支持）。讨论他可能未考虑过的替代方案：不透露父代状态的排除性产前诊断（结果不揭示祖辈是否携带）、带不披露流程的植入前遗传学检测，以及不检测的生育规划。记录其决定能力、自愿性与告知方案。若他决定检测且阳性，虽无预防性疗法，也应规划监测与支持，并讨论驾驶、枪支（依当地）、保险与家庭告知；若阴性，结束随访，并处理家系变异方面任何残留的不确定性。
:::
