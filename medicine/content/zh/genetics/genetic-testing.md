遗传检测是中间夹着一个分子的假设检验。在任何标本离开诊室之前，四个问题值得先有答案：临床问题是什么、哪种机制可能解释它、哪种技术能在哪种组织中看到那种机制、以及你和患者将如何对待每一种可能的回答。先问问题再开单，报告便是工具；先开单再问，报告便成为新不确定性的来源——一个没人说得清意义的变异、一个属于整个家族的结果、一个谁也没同意讨论的偶然发现。

本章讲授实验方法及其分辨率、报告的语言、各类检测及其适用场景——携带者、症状前、产前、新生儿——以及把结果转化为计划的咨询实践。

## 选择技术

::: definition 主要技术，按能看到什么划分 {#def-tech}
**核型分析**培养活细胞，在显带分辨率下拍摄染色体：约5–10 Mb。它是唯一能常规看到平衡重排、整条染色体低水平嵌合以及完整性染色体图景的项目。
**FISH**（荧光原位杂交）用标记探针询问一个命名序列，可作于固定或活细胞；它回答“这个位点在此标本中缺失/重复/有几个拷贝”，当临床问题具体时（如22q11.2）即是快速检测。
**染色体微阵列（CMA）**把DNA杂交到全基因组探针上，拷贝数分辨率可低至数十kb；SNP阵列还能报告同源区段（揭示近亲或单亲二体）与低水平嵌合。它看不到平衡重排、甲基化或重复长度。
**靶向单基因与panel检测**（Sanger测序、扩增子或捕获式二代测序）读取指定基因：适合序列变异与小的插入缺失；拷贝数与深部内含子改变需附加分析。
**外显子组测序**靶向约2万个基因的编码外显子；**基因组测序**读全基因组，另可及内含子、重复（需专门分析）、结构变异与线粒体DNA，且无需重跑实验即可重新分析。
**甲基化/印记检测**（如MS-MLPA）看到特定亲源的甲基化——Prader-Willi/Angelman与Beckwith-Wiedemann/Silver-Russell的检测，其机制对测序不可见。**重复长度检测**（PCR与Southern印迹，或重复引物PCR）测定扩增长度。**酶学与功能检测**测量基因产生的表型；**RNA研究**（活检组织转录组）在DNA结果含混时检测异常剪接。
:::

| 诊室中的问题 | 一线检测 | 为何不用其他 |
|---|---|---|
| 未明的发育迟缓、孤独症或多发先天异常 | CMA（±脆性X长度检测） | 核型漏掉亚显微CNV；多数机构外显子组列为二线 |
| 疑似非整倍体或复发性流产伴平衡易位 | 核型 | CMA不能判断平衡；FISH只答一个问题 |
| 复发经典型综合征（如临床疑22q11.2缺失） | 靶向CMA或FISH | 问题只有一个位点时全基因组方法是过度检查 |
| 早发或高度提示的单基因病 | 基因panel或核心家系外显子组/基因组 | 仅当鉴别诊断由单一基因主导时单基因检测才高效 |
| 病因不明的急性肝/神经/代谢恶化 | 紧急基因组测序（科研/急件通道） | panel漏掉位点异质性；时间要紧 |
| 超声发现胎儿畸形 | 羊水/绒毛核型+CMA | CMA无诊断价值时外显子组正被（试验支持的）逐步加入 |
| 已知家系变异（症状前、产前、携带者） | 针对该变异的靶向检测 | 其余都不提供信息；全基因组检测替代不了一个靶向问题 |

::: theorem 检测必须能看到机制 {#thm-resolution}
阴性检测只排除其设计所覆盖之物：变异的类别（序列、拷贝数、甲基化、重复、重排）、其测量的基因组区域、病变可能存在的组织，以及其检出限以上的等位基因比例。令人放心与假性安心之间，隔着的就是这一条原则。
:::

::: proof
每种技术都有各自的盲区，且盲区并不整齐重叠。捕获式panel深读外显子，却对启动子缺失、深部内含子剪接变异、重复扩增是盲的——并且由于多数流程将其压制——除非拷贝数调用程序针对数据验证过，大结构事件也是盲的。CMA测全基因组拷贝数，却对一切不改变剂量之物是盲的：平衡插入、点突变、印记缺陷、扩增。甲基化检测只看探针清单上的位点。Sanger测序一个有高相似假基因的基因，可能把假基因序列当作基因本身报告。嵌合是比例问题：10%等位基因比例的变异深测可可靠检出、Sanger漏检，若所涉谱系非造血系统甚至可完全不在血中。检出率是检测在项目人群上的属性，不是它在你患者身上的属性：即便外显子组测序也有天花板，由致病基因已知且变异可被检出的孟德尔病比例决定——这就是未确诊罕见病中外显子组诚实的产出率约三分之一到一半的原因，也是阴性结果应排入“重新分析”而非结案的缘故。
:::

::: example 放错地方的正确标本 {#ex-tissue}
一名12岁儿童右腿节段性过度生长伴血管畸形，大腿可见毛细血管性斑片，MRI有局灶所见。两次血标本，先送血管基因panel、后送外显子组，均报告正常。
::: solution
伴血管畸形的节段性过度生长通常由PI3K–AKT–mTOR通路（*PIK3CA*、*KCNK3*、*TEK*、*MAP3K3*等）的合子后激活变异引起，等位基因比例低，存在于受累组织，常在白细胞中测不到。正确的标本是受累组织——皮损、切除的血管标本或受累脂肪——以能检出1–5%等位基因比例的深度靶向测序检查，最好配对照的正常组织。血外显子组不算错的检测，而是这个机制下错的标本（嵌合体见[[genetics/non-mendelian-inheritance]]）：结果以变异栖居之地为界。报告规范也随发现而来：变异比例、组织、达到的测序深度都是解读的一部分；收到“血检阴性”的临床团队在安心之前应问一句“——那么是什么组织？多深？”
:::
:::

## 报告的语言

::: definition 变异分类 {#def-classification}
序列变异按五级报告：**致病、可能致病、意义未明变异（VUS）、可能良性、良性**。分类权衡人群频率（在对照中足够常见的变异不可能引起罕见隐性病）、计算与功能预测、家系共分离、基因的属性（已知机制：功能丧失、功能获得、特定错义热点）与病例层面证据——即ACMG/AMP框架。分类是带日期、带实验室的判断：随证据积累，同一变异可被上调或下调，这就是保存数据要被重新分析、“重新分类”通知会在多年后寄到的原因。
:::

报告中的三种表述需要专门的使用能力。**“符合常染色体隐性遗传，双亲各携带一个变异”**意味着假定两个变异*反式*排列；相位要紧时（一人同一基因两个变异），要靠亲本检测证明。**“无信息阴性”**——或“仅对所检变异而言未检出”——意味着该亲属只被检测了一个家系变异，结果对其他机制什么也不说；经典的隐患是一个家属对疾病放了心，而检测其实从未回答疾病的问题。**“二次/偶然发现”**——与检查指征无关但有医学行动价值的结果——只应出现在患者选择接收之处（成人方案；儿童仅在与就诊表型相关时）。

::: warning VUS是调查的开始而非结束，且永远不是处理决定的依据
对意义未明变异采取行动——降险手术、把某亲属排除在筛查之外、给孩子的癫痫贴上“遗传性”标签——是把实验室的模糊转成临床的伤害。正确的回应是寻求更多证据：亲本相位、扩展家系共分离、RNA或功能数据、表型与基因已知机制的匹配，以及一两年后的重新分析。而对家属的正确表述也就是这一句：“我们还不知道；什么能告诉我们；我们何时再问。”
:::

::: example 一个意义未明的缺失 {#ex-vus}
一名7岁儿童有学习困难与轻微异常体征，CMA示某基因贫乏位点220 kb拷贝数缺失；实验室判为VUS。其母携带同一缺失并有轻度学习困难；其父未受累，且无其他亲属受检。
::: solution
这个家系所能提供的分类证据不多但真实：缺失按母系遗传模式与轻度表型共分离、区域基因内容可能包含单倍剂量不足基因、人群数据库中可能有若干未完整描述表型的携带者。这能换来的不是诊断，而是计划：带着这个具体表型重新检查母亲及其母系亲属（她当年是不是“学得慢”？有无受累的母系男性亲属？缺失内究竟有哪些基因、其中有没有已确立的剂量敏感基因？）；向实验室提交共分离数据申请重新评估；并且——关键地——无论这个缺失何意，都按表型管理这个孩子，因为他需要语言治疗、教育支持和心肾影像，VUS既不创造也不取消需要。真正被改变的是家庭的决策，此时“对不确定性的诚实”就是干预：母亲的再发风险推理、未来的产前请求、夫妇自身检测的问题，全系于最终分类的重定——所以必须书面告知这个家庭：这是一道有复查日期的开放题，既不可夸大，也不可轻慢。
:::
:::

## 检测的类别，各有各的规矩

::: definition 检测的分类学 {#def-categories}
**诊断性检测**回答“这位患者为何有表现？”。**症状前检测**给有风险成人检测已知家系变异，通常是晚发病（Huntington病、*BRCA*、肥厚型心肌病基因）。**携带者检测**在健康人中寻找隐性变异，可单人或作为婚检/孕前筛查。**产前诊断**对胎儿作出诊断（11周起绒毛取样、15周起羊膜腔穿刺），与仅作风险分层的**产前筛查**（联合筛查、无细胞DNA）相区别。**新生儿筛查**对每名婴儿检测早期治疗可防害的疾病。**药物遗传学检测**预测药物处置（见[[genetics/genomic-medicine]]）。
:::

::: theorem 筛查与诊断；以及由谁同意 {#thm-screening}
筛查试验把人群分为风险组，唯有当疾病重要、试验可接受、确有早期使用有效的治疗、且质量有保障的诊断与治疗可及时才成立；诊断试验回答关于一个人的问题。筛查背后永远需要诊断的可能性；症状前与产前检测尤其承担非指令性义务：实验室提供事实，服务提供理解，决定属于患者。
:::

::: proof
经典Wilson–Jungner意义上好筛查项目的每条属性，都会转化为运营要求。疾病必须在临床上重要——这就是新生儿筛查panel以治疗而非以检测通量划界的原因：“我们能测什么”绝不能跑在“我们能早期做什么且有效”前面。试验的敏感性与特异性决定两类不同的伤害——漏诊与虚惊——在低患病率人群中虚惊一侧占优：患病率5,000分之一、特异性99.9%时，约一半筛查阳性为假，项目因此必须为确证能力与咨询师时间留预算，而非只留试纸和读数仪。早期治疗必须有效：苯丙酮尿症合格，因为饮食能预防残疾；无公认早期干预的病种被家长压力加入又在证据失败后撤除，已反复上演。而诊断臂必须能兑现：筛查阳性孩子的代谢病转诊要等数周，会把收益转成伤害。同一逻辑约束产前筛查：序贯模式（高风险筛查→提供诊断性取样）只在诊断性服务与非指令性咨询有资源处成立；没有它们，筛查项目本身即伤害。
:::

## 产前与植入前路径

时间表在临床与伦理上都要紧。**孕早期联合筛查**（颈项透明层加生化标志物，11–14周）合并母龄对21三体检出率约85–90%、假阳性率5%。**无细胞DNA**（10周起）读取母血浆中胎盘DNA：对21三体检出>99%、假阳性<0.1%；对18、13与性染色体较弱；依赖胎儿分数；受胎盘局限性嵌合、消失双胎及母源拷贝数改变或肿瘤干扰。两者皆为筛查。**诊断性检测**——绒毛取样（11–13⁺⁶周）与羊膜腔穿刺（15周起）——在有经验中心的操作相关丢失风险约1–3/1,000，产出胎儿细胞供核型、快速非整倍体检测与CMA，畸形病例选择性加做外显子组。**植入前遗传学检测**（单基因病PGT-M、重排PGT-SR、非整倍体PGT-A）在IVF周期中对Day-5胚胎的滋养外胚层细胞活检；其限度——嵌合报告、等位基因脱扣、以及须预先知晓家系变异——应写入同意讨论。

::: example 序贯结果 {#ex-nipt}
一名33岁孕妇12周无细胞DNA返回“21三体高风险”。12周超声正常。她想预约终止妊娠。
::: solution
第一，不要把筛查当诊断——尤其这一项：33岁先验风险约400分之一，即使99%敏感、99.9%特异的试验，该患病率下阳性预测值也只在八成出头；正常超声降低但不抹去概率。第二，解释结果为何“没有出错也会错”——胎盘局限性嵌合、早早消失的同孕双胎、母源拷贝数变异——以及下一步：羊膜腔穿刺（此处优于复取绒毛，因为培养羊膜细胞问的是胎儿而非滋养层），核型加微阵列，数日至两周出结果。第三，决定留在她手里：若胎儿受累，她面对完整的选项——继续妊娠并做产前产后规划、继续妊娠并以舒适为主、或终止妊娠——法律时限与服务路径的时间此刻就要谈，而非诊断结果出来之后。第四，处理筛查本身：无论结果如何，她离开时应清楚无细胞DNA从未说过孩子有Down综合征；筛查的存在是扩大知情选择，不是提前做决定。记录咨询；预约诊断取样；若结果正常，请认真对待假阳性筛查之苦有多常见——是项目的成本，不是例外。
:::
:::

::: example 家属要求“先做外显子组再决定” {#ex-exome-prenatal}
孕20周，针对性超声示双肾囊性发育不良与羊水过少。父母问外显子组测序能否“告诉我们一切”。
::: solution
它能告诉的有限但真实。CMA无诊断价值后的胎儿外显子组在约四分之一到三分之一的畸形胎儿中增加分子诊断，产率最高者正是此处所见组合（骨骼、肾、多系统类似纤毛病的模式提示单基因病因，如*PKD1/PKD2*、纤毛病基因；而孤立囊性肾——*HNF1C*——的缺失在CMA而非外显子组上可检出）。诚实划界：周转以周计，有时超出继续妊娠的决策窗；VUS在产前场景常见且少有可行动性；阴性外显子组既不排除遗传病因也不预言轻重；而在无出生后表型的胎儿中解读一个新发显性变异本质上不确定。伦理形态也须在留样前谈：他们要什么结果、以何周转、由谁解读、VUS怎么办。胎儿医学、临床遗传——以及路径涉及新生儿或安宁时——新生儿与安宁团队都应在谈话中在场；无论测序走向哪边，决定留在父母手中。
:::
:::

## 作为临床技能的咨询

::: definition 非指令性及其实践 {#def-nondirective}
遗传咨询是以技术为核心的沟通过程，帮助个人或家庭：(1)理解医学事实包括可能的结局范围；(2)理解遗传如何贡献以及亲属的风险；(3)理解处理与生育的选项；(4)**在其自身价值的语境下**选择其认为正确的选项；(5)按选择行动。非指令性指咨询者的价值不被代置于患者的价值之上——而非隐瞒事实、把风险说含糊，或咨询师对处理没有专业意见。
:::

::: proof
为Huntington病症状前检测发展出的规程——并推广至其他成年起病疾病——正是把上述五个目标应用于“说出去收不回”的结果之心理风险的直接产物。检测前咨询确认动机、个人与家族精神病史、对“阳性结果目前无预防性治疗”的理解、告知谁及如何告知的安排、所在辖区的保险与职业处境；留样前的间隔允许反悔；结果当面告知、有支持者在场、并预约随访；而阴性结果同样被当作心理事件处理（幸存者内疚；当家庭叙事围绕疾病组织时，阴性反而撕裂家庭认同）。每一步的存在都因早期门诊学到了失败模式：首诊即检测、电话告知、不随访、以及把“阴性即轻松”当作默认。实践中该规程也是基因组时代同意书的模板：它强制讨论“什么想知道、什么不想知道”，而这正是外显子组与基因组测序的设计问题——报什么、报给谁、何时报。
:::

::: history
这门学科的用词很年轻。“遗传咨询”由Davenport圈子在1900年代命名——带着其一生都在与之脱钩的优生学底色；Reed 1947年的论文与英美最早的一批诊所开启了非指令性、以患者为中心的实践；美国遗传咨询委员会的首批考试在1980年代中期。McKusick的教科书与他自1966年起在Johns Hopkins的遗传门诊教会了医学把家系接到处理上。检测的现代时代起自细胞遗传学（1956年确定人类染色体数目）、显带，到1970年代末1980年代初第一批基于DNA的产前诊断——培养羊膜细胞的限制性片段研究；胎儿DNA自母血中检出则晚得多——检测小到实验室手工完成，其验证因此以十年计——直到多重基因panel、外显子组与基因组把瓶颈明白无误地从化学移到了解读与咨询。
:::

::: quiz
一名健康25岁男性的母系舅舅死于A型血友病；家系*F8*变异已知。其母已检测并非携带者；他要求检测“以求安心”。恰当的回应是？
- [ ] 给他做*F8*测序——完全排除最安全。
- [x] 解释：母亲非携带且家系变异已知，其先验风险已经极低（仅剩人群残留与母方生殖腺嵌合的可能）；针对家系变异的检测无指征，而测序只会生出更多问题。
- [ ] 用另一种方法复检其母。
- [ ] 只在他有症状时检测。
::: solution
症状前检测只对家族所传的变异有信息量。其母对已知家系*F8*变异的阴性结果把他的先验风险压到背景水平外加性腺嵌合的小小余量——此时给他的*F8*测序答不了真正的问题，只会生产一个他终生携带的VUS。门诊谈话应以数字重述残留风险、记录在案，并在新家族信息出现时（新发患病亲属、或其母家族史改变）再议。为一个正确的情绪给一个已经解决的家系做全基因测序，是“错误检测”的标本。
:::

## 通向何处

各技术如何回答具体综合征见[[genetics/chromosomal-disorders]]与[[genetics/mendelian-inheritance]]；嵌合与组织选择见[[genetics/non-mendelian-inheritance]]；分类框架在肿瘤的应用见[[genetics/cancer-genetics]]；症状前检测的伦理框架见[[medical-ethics-law/consent-capacity]]；筛查数字背后的统计见[[epidemiology-ebm/diagnostic-tests]]。下一章[[genetics/genomic-medicine]]把结果带进治疗——并带进基因组作为公共产品的伦理。

::: summary
- 技术须匹配机制：核型看数目与平衡，微阵列看拷贝数，测序看序列，甲基化检测看印记，重复检测看扩增，功能检测看基因的作为——而组织须匹配疾病栖居的谱系。
- 没有检测能排除其分辨率之外之物：变异类别、覆盖区域、被检组织、可检出的等位基因比例。“阴性”永远意味着“对本检测所见范围内阴性”。
- 五级分类是有日期的判断而非事实；VUS是一次排了日程的重新分析、绝非处理决定；无信息阴性须被认出为无信息。
- 筛查分拣人群，诊断回答个人问题；筛查项目的评判标准是阳性结果背后的路径，而非实验室里的试验。
- 症状前检测遵循源于Huntington病的规程——多次咨询、反思间隔、当面告知、阳性与阴性均随访——因为结果不可逆且属于全家。
- 咨询在设计上非指令：事实是服务方的供给，价值由患者应用；关于“想知道什么”的同意谈话是技术的一部分，而非其障碍。
:::

## 练习

::: exercise 选择检测 {level=1}
为下列情形选择首选检测：(a) 16周胎儿左心室单发强光点、其余全部正常、无细胞DNA低风险；(b) 4岁发育迟缓、查体正常；(c) 已知家系*LDLR*变异的成人求评估；(d) 发作性肌无力伴肌无力表型的儿童。
::: solution
(a) 不做介入检测：低风险女性、常规筛查连续的孤立强光点什么也不改变——路径按常规结构筛查继续，焦虑以咨询而非羊穿处理。(b) 染色体微阵列（按表型与性别适应时加脆性X检测）；CMA无诊断价值则外显子组。(c) 针对已知家系*LDLR*变异的靶向检测——其余一切都不回答该问题。(d) 临床优先是生理诊断（抗体、重复电刺激、单纤维肌电图）；若血清学阴性且有家族史或婴儿期起病，再做先天性肌无力综合征基因靶向测序（或外显子组）——基因检测在机制（突触前、突触、突触后）定位之后选择。
:::

::: exercise 读懂报告上的数字 {level=1}
实验室报告“检出率99.5%，失败率2%”。某机构年筛查40,000名新生儿，该病患病率8,000分之一，敏感性99.5%、特异性99.95%。估计假阳性数与每发现一例真病例对应的阳性总数，并说明项目必须为什么留预算。
::: solution
40,000人中约5人患病；检出约4.98例。39,995名未患病者产生$39{,}995 \times 0.0005 \approx 20$例假阳性；2%失败率另有约800份标本需重新采集。每发现一真病例对应阳性数$\approx (20 + 5)/5 \approx 5$——五分之四的筛查阳性是假的。项目必须预算：失败标本的紧急重采能力；每年约25例阳性所需的生化与临床确证能力；每年向20家父母宣告“您的健康孩子没有事”的沟通队伍规模；以及结局追踪，以使假阴性（每年预期0.02例漏诊——若失败或召回流程有漏洞则更多）能在临床上被发现时被发现。一个筛查数字是伪装成数字的工作量预测。
:::
:::

::: exercise 阴性后的残留风险 {level=1 check=“0.0016”}
某罕见隐性病下，一名女性的人群携带者风险为40分之一。靶向检测在其人群可检出96%的携带者等位基因。若她检测阴性，其大致残留携带风险为多少？
::: solution
残留风险$= \dfrac{0.025 \times 0.04}{0.025 \times 0.04 + 0.975} \approx 0.001$，即约千分之一——形式化：先验比$1/39$，乘以携带者出现阴性检测的概率（$1 - 0.96 = 0.04$），后验比约$1/1560$；简单表述：风险从40分之一降到约千分之几。该计算可泛化：阴性检测把风险除以检测的检出率——对小先验减去几乎nothing，对大先验减去很多——这正是当夫妇问“panel阴性是否让携带者筛查失去意义”时应引用的算法。
:::
:::

::: exercise 不是阴性的阴性 {level=2}
一名30岁男性的父亲携带肥厚型心肌病*MYH7*致病变异。他本人针对该家系变异检测阴性，并对全科医生说“基因学已经替我洗清了——我可以不再看心脏科了”。什么是对的？病历应写什么？
::: solution
对的是：对已知家系*MYH7*变异阴性意味着他没有遗传它（留出实验室误差与生殖系嵌合的小概率——以及关键前提：所测变异确为该家的致病原因，而实验室若对边界致病的分类有更新可能会回访）。HCM阴性症状前检测后解除监测是标准做法，附两个条件：家系变异确为致病者（确认分类未被修订），且结果须连同“这移除的是你的*遗传*风险、不是人群心脏病的风险”一并告知。病历应写明所测变异、实验室、日期、当时的分类与处置建议——“因家系变异阴性解除心脏科监测，症状出现时再诊”。防止“替我洗清”式误读的门诊记录，只比制造误读的那份多一句话。
:::
:::

::: exercise 何时提供外显子组 {level=2}
一名2岁全面发育迟缓伴癫痫与婴儿期起病共济失调的患儿父母问：已经两项单基因检测阴性，为何还拒绝“全基因检测”。请说明两边的道理并陈述现代立场。
::: solution
反对先做外显子组（旧的纪律）：临床图像提示一小套机制，单基因检测更便宜、更快、更易解读；外显子组成倍增加VUS与二次发现，需要为父母可能不想知道的信息取得同意，且需要一个能据结果行动的团队。支持（这是2026年多数指南与随机试验、国家项目支持的立场）：当鉴别诊断横跨数十个基因——癫痫性脑病伴共济失调正是如此——外显子组/基因组测序的产率高于序贯panel，每个诊断的成本更低，能在可治病因被错过之前出结果，并终结以试验性治疗与焦虑计价的诊断流浪。诚实的综合是：表现跨基因边界时外显子组已成一线；表型为单一常见病因的综合征时靶向检测仍是正解；无论哪条路，开单都要求同意覆盖二次发现、保存与重新分析，且团队能就结果进行咨询。父母的问题本身指出答案：他们已经历了序贯检测；系统的职责是说明外显子组增加什么、又不能承诺什么。
:::
:::

::: exercise 分类 {level=2}
实验室在某基因为功能丧失机制的位点发现杂合截短变异；人群对照频率0/280,000；患儿受累；父母各携带“同一个”罕见良性改变的一份拷贝；实验室软件预测无功能影响，因为该变异可逃避无义介导的mRNA衰减。请分类并说明哪项检测最可能改变分类。
::: solution
证据指向致病或可能致病，但有一处要紧的模糊：功能丧失基因的截短变异带强证据（PVS1），而当截断逃避无义介导的衰减（末外显子或逃逸变异）时PVS1要降级，因为蛋白可能近乎正常。对照中缺席支持致病；软件对NMD逃逸的预测恰恰是那种不能独自左右分类的*in silico*主张。报告中相位未定——“父母各携带同一罕见改变”更可疑的是该位置为良性假象而非疾病。最有信息量的一步：RNA研究（血或相关活检），看转录本是否真实产生、蛋白是否被截短——功能与RNA证据能决定预测决定不了的事。在此之前，若患儿表型并不特异对应该基因的综合征，该变异大概率是VUS——一次排了日程的重新分析，不是一个诊断。
:::

::: exercise 起草同意书 {level=3}
你在为儿科基因组测序服务起草同意书。列出这份同意书必须真正向父母提出的问题——而非签字栏——并说明每个问题若被默认掉会出什么事。
::: solution
核心问题，各自对应一种有记录的失败模式。(1)孩子病情之外可能发现什么——二次/偶然发现：选择接收、不接收或按儿童适用清单（ACMG二次发现基因清单式）；默认覆盖的结局是父母在数月后得知你早知道“关乎他们自身健康”的事而他们从未同意。(2)当变异遗传自父母时，可否向*父母*报告其结果：孩子检测带出的父母携带状态与成年起病风险属于他们自己的同意决定。(3)保存与重新分析：数据是否保存、知识更新时是否重跑、孩子成年时由谁同意——默认的“否”会放弃测序的主要优势。(4)数据共享：实验室伙伴、科研库、发表、去标识化的限度（基因组只是化名而已）。(5)保险与披露语境：结果在本地辖区是否影响保险、以及向亲属披露的义务。(6)VUS的操作含义——家庭对确定性的期待，否则重新分类的电话听来像背叛。(7)不知情权与撤回：撤回能够与不能够撤回什么。一份只作签字栏、不作这七个问题菜单的同意书，会把一切可预见的伤害以“意外”的形式转嫁给家庭——与这门学科非指令性传统的正相反。
:::

::: exercise 微缩的一节咨询 {level=3}
一名34岁女性，其兄28岁死于*TGFBR2*相关主动脉夹层，来求症状前检测。家系变异有记录。她焦虑，妊娠7个月，其伴侣希望“若她有风险就直接测胎儿”。请组织你的处理并指出决策点。
::: solution
第一步，把她的检测按症状前而非产科急事处理：检测前咨询涵盖她对疾病的理解（血管管理、监测、手术阈值——因为与Huntington病不同，这里*有*预防路径）、阳性结果在妊娠期的心理分量、告知安排（亡兄的父母与同胞的状态）、保险影响；留样前留间隔；当面告知并安排随访。她的焦虑与妊娠使其适合“快，但按正确的顺序”——一周内出结果却不咨询，是应避免的错误。第二步，关于胎儿：对妊娠仍在继续的胎儿，就一种晚发、可知晓后即可管理的疾病做产前检测并非自动有指征，且只有在她结果出来之后才谈得上伦理：她若阴性，胎儿检测没有目的；她若阳性，胎儿检测可辩护之处主要在于会改变妊娠期或产后的处理——而*TGFBR2*一般不改变（患儿自儿童期监测治疗，知之于出生并不改变新生儿处理）。谈话因此应区分“先测我，若我携带再谈孩子”与伴侣跳步的愿望；并点出服务必须避免的滑坡——主要指南对成年起病疾病的胎儿检测一律保留给在夫妇自身处理中有医学理由的情形。第三步，无论结果如何都要落实的实际事项：她的心血管评估可以在妊娠期启动（β受体阻滞剂决定是与产科-心脏的谈话）、新生儿查体与家族级联图可以预备，而孩子本人的检测推迟到能行动的年龄——并在儿童病历中把这一点记录为一个决定，而非疏漏。
:::
