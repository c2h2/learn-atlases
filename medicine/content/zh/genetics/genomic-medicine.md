基因组大约在2010年前后离开了遗传科诊室，进入普通医学，而多数临床医生尚未更新“这意味着什么”的模型。 承载它的是四件事：依据患者药物代谢基因型开药；增加、沉默或重写基因的治疗；作为科研基础设施与公共产品的基因组；以及三者随之而来的伦理问题——对能预测亲属风险之材料的同意、数百万美元治疗的公平可及、以及可遗传修饰的第一个实际问题。

本章是这门课程的应用端：药物遗传学作为临床药理学，基因与细胞治疗作为已经在治疗患者的机制，编辑作为立在门口的技术，伦理作为让其余一切保持诚实的学科。

## 药物遗传学

::: definition 药物遗传学与药物基因组学 {#def-pgx}
**药物遗传学（pharmacogenetics）**研究药物反应的遗传变异，经典地限于一个基因与一个药；**药物基因组学（pharmacogenomics）**研究全基因组图景。临床可行动的变异分两族：**药代动力学**——决定暴露量的基因（CYP2D6、CYP2C19、CYP2C9、TPMT、NUDT15、UGT1A1、DPYD、SLCO1B1的激活型、失活型或拷贝数变异）——与**药效动力学**——决定靶标或通路的基因（HLA风险等位基因，如阿巴卡韦之*HLA-B\*57:01*、卡马西平之*HLA-B\*15:02*；华法林敏感性之*VKORC1*；丙肝应答之*IFNL3/IL28B*；降低氯吡格雷活化的*CYP2C19*缺失等位基因）。检测的结果是一个表型标签——慢、中间、正常（快）、迅速或超快代谢者——而非原始基因型，处方指导附于标签之上。
:::

基因型已知，药与剂量就会改变；其推理是把[[pharmacology/metabolism-excretion]]的药理学应用于遗传变异。

| 基因 | 受影响药物 | 机制 | “错误”基因型的临床后果 |
|---|---|---|---|
| *TPMT* / *NUDT15* | 硫嘌呤（硫唑嘌呤、6-巯基嘌呤） | 灭活减少→细胞毒核苷酸蓄积 | 致命性骨髓抑制；按基因型减量或回避 |
| *DPYD* | 氟嘧啶类（5-FU、卡培他滨） | 分解代谢减少 | 重度口腔炎、腹泻、中性粒细胞减少；减量起始或回避 |
| *UGT1A1*（启动子*28等位基因） | 伊立替康 | 活性代谢物葡萄糖醛酸化减少 | 中性粒细胞减少；高剂量时调整剂量 |
| *CYP2C19* | 氯吡格雷（前药）、质子泵抑制剂、部分SSRI | 缺失等位基因活化失败；增益等位基因加速 | 置入支架后抗血小板效应下降；改用替代药（普拉格雷、替格瑞洛） |
| *CYP2D6* | 可待因/曲马多（前药活化）、他莫昔芬、许多抗抑郁与抗精神病药 | 拷贝数与功能谱从无到超快 | 可待因超快代谢者中毒（呼吸抑制；哺乳期慎用）；慢代谢者镇痛失败 |
| *CYP2C9* / *VKORC1* | 华法林 | 清除率与靶标的剂量需求 | 维持剂量差异巨大；药物遗传学给药在一些试验减少INR失控时间 |
| *HLA-B\*57:01* | 阿巴卡韦 | 免疫介导超敏 | 回避——一个可预防的、可致命的反应 |
| *HLA-B\*15:02 / -A\*31:01* | 卡马西平、奥卡西平、苯妥英 | SJS/TEN与DRESS风险因等位基因而异 | 有风险血统者开药前检测；选择替代药 |
| *SLCO1B1* | 辛伐他汀 | 肝脏摄取减少 | 肌病风险；封顶剂量或换他汀 |
| *G6PD*缺乏（X连锁） | 伯氨喹、拉布立酶、氨苯砜、呋喃妥因 | NADPH减少、氧化性溶血 | 急性溶血；有风险人群用氧化性药物前检测 |

::: theorem 可行动的药物遗传学要求一个行动 {#thm-pgx}
药物遗传学检测只有当结果在首剂之前可得、表型-剂量规则写入病历与处方系统、实验室结果保存在未来每一次用药都能被找到的地方时，才改变结局。已实施药物基因组学的主导失败模式不是解读而是调阅：一个*CYP2D6*表型，在医生写下可待因的那一刻无人看得见。
:::

::: proof
实施科学已经把有用的检测与仅仅预测得好的检测分开。华法林给药说明差别：药物遗传学算法（CYP2C9、VKORC1、临床因素）在多数但非全部大型试验缩短达标时间，而结局获益取决于人群基因型频率与INR监测本来的好坏——各国指导因此不同，诚实的总结是“监测不完美处有用，而非监测的替代”。可待因演示相反的情形——有行动价值却无良好的历史信号可循：CYP2D6拷贝数扩增经典型超快代谢把可待因迅速转为吗啡，足以在儿童与乳儿中引起呼吸抑制，尸检病例报告先于说明书修订；行动是在人群回避可待因，现已是多辖区的指导。使用检测的通用设计规则是：(1)读表型而非等位基因；(2)查证据等级（1A级药-基因对要行动，较弱者仅供参考）；(3)把表型记录一次，写入问题列表或可互操作字段；(4)把“正常代谢者”结果当作许可而非保护——该检测排除的是异常反应的遗传原因，不是一切原因。
:::

::: example 药师的一通电话 {#ex-thiopurine}
一名19岁炎症性肠病患者即将开始硫唑嘌呤。医院药物遗传学服务报告*TPMT*活性中间（一个无功能等位基因）、*NUDT15*野生型。处方医生问是否“照旧”在用药后监测TPMT水平。
::: solution
把顺序反过来：*TPMT*表型已知中间时，指南（如基于CPIC者）支持以减量起始（约标准剂量的三分之一到三分之二），而非标准剂量日后再修正；血常规监测仍属必要，因为减量限制但不消除骨髓抑制风险，也因为表型标签不能完整刻画硫嘌呤代谢物处置（查*NUDT15*正是因为它独立于TPMT、主导东亚与西班牙裔人群的风险）。解释其所以然：硫嘌呤由TPMT灭活；一个工作等位基因留下的储备更少，标准剂量会蓄积细胞毒的硫鸟嘌呤核苷酸。病历需要的是表型、日期与所适用的规则，使任何未来处方者（同一患者某天可能因白血病接受6-巯基嘌呤）继承的是推理，而不仅是数字。
:::
:::

::: example 支架与前药 {#ex-clopidogrel}
一名58岁中国男性因急性冠脉综合征置入药物洗脱支架，予以氯吡格雷负荷。药房服务报告入院前的药物遗传学结果：*CYP2C19* \*2/\*3——慢代谢者。
::: solution
氯吡格雷是需要CYP2C19介导活化的前药；两个功能缺失等位基因意味着活性代谢物显著减少、治疗中血小板反应性偏高、PCI后支架血栓与缺血事件增多被一致报道——这就是CPIC建议支架后置入且两个功能缺失等位基因携带者（如无禁忌）改用替代P2Y12抑制剂的原因。行动是换用普拉格雷或替格瑞洛（而非氯吡格雷加倍剂量——克服代谢阻断的作用并不稳定），把表型记录在所有未来处方者看得见之处，并注意本例教导的不对称：同一基因型让氯吡格雷失灵，也让某些质子泵抑制剂与部分抗抑郁药表现不同，因为CYP2C19触及多条通路。它同时精确地给出否定的一面：正常代谢者的结果并不能保护他免于支架血栓的常见原因——剂量不足、依从性差、自行停药——所以药物遗传学结果是警惕的一个输入，而非警惕的替代。
:::
:::

## 增加、沉默与编辑基因

::: definition 基因治疗的模态 {#def-gene-therapy}
**基因添加（gene addition）**递送一个功能拷贝，通常经腺相关病毒（AAV）入肝、视网膜、肌肉或中枢神经，或离体**慢病毒转导**患者自身的造血或淋巴细胞后回输。它是*游离体（episomal）*的——基因平行于基因组存在——且不纠正原突变，因此生长中的儿童需要重复给药，而通常不能重复（中和抗体）。**基因编辑**——CRISPR–Cas9以向导RNA造成双链断裂，经非同源末端连接修复（敲除）或以外源供体模板修复（敲入）——改变序列；碱基编辑与先导编辑作更小、更干净的编辑。**RNA层面治疗**——降解RNA或调节剪接的反义寡核苷酸（ASO，诺西那生调节SMA之*SMN2*剪接）、siRNA（patisiran、givosiran、inclisiran）与适配体——作用短暂、可重复给药、不触DNA。
:::

截至2026年的临床现实是：每种模态各有几种被治得不错的病，另有一长串疾病在试验中。已批准的例子包括：*RPE65*相关视网膜营养不良的AAV基因添加（视网膜下注射）；乙型血友病（肝启动子下的因子IX变异体）与甲型血友病（因子VIII构建体；表达持久但受既存免疫、肝毒性事件以及分裂肝脏中游离体丢失问题的限制）；β-地中海贫血与镰状细胞病的慢病毒基因添加（清髓的自体CD34+细胞——首个CRISPR编辑疗法**exagamglogene autotemcel**即在此框架下，通过破坏*BCL11A*红系增强子重建胎儿血红蛋白）；诺西那生以ASO剪接调节治疗SMA、eterplirsen类药物外显子跳跃治疗Duchenne肌营养不良；以及siRNA治疗遗传性转甲状腺素蛋白淀粉样变性与急性肝卟啉病。共性定义了这一领域：超罕见适应证、以百万计的单价单次输注、其毒性（烷化剂暴露、清髓、早期慢病毒系列的插入致癌信号）如今要与持久获益相权量的预处理方案，以及复杂到“一批失败即一次临床事件”的生产。
::: example 两兄弟与一台泵 {#ex-smadri}
一名5岁重型甲型血友病（*F8*无义变异）患儿尚无抑制物。他的血液科团队在新上市产品的语境下讨论AAV基因添加的试验结果。
::: solution
按机制与其限度解释该疗法。单次静脉输注携带肝特异性启动子下*F8*转基因的AAV5载体，可使多数患者内源性因子VIII产量从（<1%）升至持续20–50%等效区间，把重型甲型血友病从每周预防变成近乎常人的日子——试验中测得的效果是年化出血率下降>95%、多数患者脱离预防用药。但是：游离体转基因随肝细胞分裂被稀释（儿童生长、以及任何未来的肝再生或损伤），两三年时测得的表达是一个脆弱的承诺；既存或诱导的衣壳免疫排除部分患者、并可威胁终生再给药的可能；转氨酶升高需要激素救援；存在小的理论性插入与肝细胞癌信号，需注册研究随访多年；而肝脏恰是那类无法轻易“撤销治疗”的器官。对这个5岁孩子，成人许可产品目前至多是超说明书或试验选项；负责任的表述不是“还不能，永远不能”，而是“他需要的获益——免去几十年的预防治疗——是真实的，而我们尚不能回答的持久性问题，正是本领域把他作为儿童研究对象的原因”。
:::
:::

## 编辑，以及可遗传的界线

::: definition 体细胞编辑与生殖系编辑 {#def-editing}
**体细胞编辑**改变患者的细胞、不遗传：造血干细胞（上文镰状细胞病疗法）或T细胞（CAR-T）的离体编辑，以及体内编辑（脂质纳米颗粒或AAV递送编辑工具，在转甲状腺素蛋白淀粉样变性等试验中）。**生殖系编辑**改变精子、卵子或胚胎，改变可传给后代——可遗传的人类基因组编辑。2018年广州CRISPR编辑的双女婴事件宣布之后，研究与临床共识（美国国家医学院2020；WHO专家咨询委员会2021）是：在缺乏充分安全性与必要性时，以生殖为目的的生殖系编辑不可接受；多数国家与欧洲委员会的强硬立场是予以禁止。
:::

::: theorem 可遗传界线的伦理 {#thm-heritable}
三个论证支撑着生殖系辩论，且分开即失真：安全（脱靶与胚胎的在靶嵌合；未知的跨代效应）；同意（被编辑者及其后代无法同意）；正义（富人的可遗传修饰将成为世袭优势的新机制，与治疗在类上不同）。各自的逻辑终点不同——技术、禁令与政策——所以“编辑行还是不行”是一个混乱的问题。
:::

::: proof
安全论证是经验性的、可能被侵蚀：人类胚胎*MYBPC3*奠基者品系纠正（Mitalipov组，2017）显示高效率、所用检测方法未检出脱靶，但检测方法本身——少数细胞的全基因组测序——会漏检大的缺失、染色质碎裂样事件与嵌合；小鼠工作表明胚胎的修复通路选择不同于体细胞（p53非依赖机制造成大片缺失插入与杂合性丢失），故“未检出脱靶”不等于“无脱靶”。同意论证对称地适用于选择（PGT本就在胚胎间挑选），但在类上不对称：编辑为某个体的所有后代固定一个选择，关闭而非打开选项——修复一个孩子骨髓的镰状细胞疗法，与在一个胚胎里made的、该血统任何孩子都将携带的编辑，区别在此。正义是最不随技术转移的论证：单次100–300万美元的基因疗法已经难坏为其配给的系统（疗效合同、年金支付、人群返利），而可遗传的一次性“增强”市场将以任何治疗都不及的方式跨代复利优势——这正是Nuffield与WHO报告把公平问题折进许可问题、而非事后分配问题的原因。
:::

::: warning 治理即治疗
本章每种模态的约束条件都不是科学性的：可及性（在还要买病房用药的预算里，谁得到一次160–300万英镑的治疗）、写进试验方案与注册研究的长期随访义务、作为患者安全问题的生产与质量、以及将带着一个游离体生活六十年儿童的同意。一个“治愈”若在上市前没有决定其获取规则，就会以审批的速度复制不公。讨论疗法时请把价格说出口；假装它是别人的伦理学，是基因组医学谈话中最常见的失败。
:::

## 基因组作为公共产品；遗传信息作为家庭信息

::: definition 遗传信息的伦理框架 {#def-ethics-frame}
驱动伦理的是遗传数据的四种属性：**预测性**（疾病之前的风险）、**家族性**（一个变异是全家共有之物，一个患者的结果改变亲属的信息）、**身份性**（基因组是持久的标识符；“去标识化”只是弱化了的匿名）、以及**双刃性**（同一序列可支持治疗也可支持歧视）。传统给出的配重——自主、保密、不伤害、正义——因此以罕见的张力运行：自主延伸到不知情权，对儿童则延伸到向未来开放的权利；保密撞上警告义务——当亲属的医学决定将因之改变时（经典者遗传性癌症综合征），一些辖区以允许“有保障措施的披露”的规范调节；正义关切可及性、歧视（GINA式保护各国不一，人寿与长期护理保险多在其外）以及人群数据集的归属与再利用。
:::

::: example 对素未谋面的亲属的义务 {#ex-duty-warn}
一名Huntington病患者拒绝告知他持有地址的同父异母妹妹，并要求团队对其家族史保密。职业规范与道德论证允许什么？
::: solution
从几乎所有规范共享的框架出发。关于他的遗传信息是他的；该信息对妹妹的涵义是她的——悬而未决的是她的生育与职业决定——对一个成年起病、无预防性治疗的疾病。永远先试的第一步：以支持劝导（提出陪她就诊遗传门诊，让服务发一封泛化的“您可能受益于遗传咨询”的信，探询他的恐惧——病耻、内疚、家庭冲突）。仅当劝导失败、且职业规范与当地法律提供依据时，才可考虑未经同意的披露，且须以窄的形式：给能够行动的人以最低信息——有亲属处于风险、应寻求咨询——而非他的诊断或他的基因；在多次尝试留痕之后、并把理由记录在案。注意临床遗传服务在这里有一项替代技术：可以*邀请*亲属来咨询而不透露患者任何情况——这是化解多数此类病例的实际机制，在级联体系中发出邀请即是标准处理。道德的剩余部分：无论走哪条路，都要记录，并继续照顾这位患者——对保密请求的惩罚性处理会教会患者隐藏家族史，从而伤害下一个人的级联图。
:::
:::

::: history
治疗的弧线很短。第一次人体基因添加是1990年NIH的实验：一名腺苷脱氨酶（ADA）缺乏症儿童接受了基因标记的淋巴细胞——一项只能标记、不能治疗的研究，也是对随后之事的一记警示：1999年Jesse Gelsinger在尿素循环试验中死亡、2002–03年X-SCID试验的白血病（γ逆转录病毒载体在*LMO2*启动子旁插入）、以及十年的缄默。领域以更安全的设计重建：2005年起的自失活启动子慢病毒载体产出了β-地中海贫血与脑腺苷脱氨酶缺乏症的结果；luxturna（*RPE65*）于2017年获批；首批AAV血友病试验于2017–2020年报告持久表达；2023年末，首个CRISPR编辑疗法（镰状细胞病与输血依赖型β-地中海贫血）在英国与美国上市，走完了从Doudna与Charpentier 2012年的生物化学到病床的距离。与此同时，人群测序从人类基因组计划2003年完成走向十万基因组与国家项目，使基因组成为医院基础设施——也使本章后半部分的问题成为病房日常，而非会议哲学。
:::

::: quiz
一名重型镰状细胞病儿童被提供exagamglogene autotemcel。哪项陈述抓住了家庭必须理解的取舍？
- [ ] 编辑会遗传给他们未来的孩子，因此必须讨论绝育。
- [x] 编辑留在患者自己的骨髓中，需要带有自身风险（包括生育力丧失）的清髓预处理，且是一次性干预，获益持久但尚未证明持续终生。
- [ ] 由于被编辑的细胞会被替换，该疗法每年需要重复。
- [ ] 该疗法编辑成熟红细胞，因此只在输血期间有效。
::: solution
Exagamglogene autotemcel采集患者CD34+干细胞，以CRISPR破坏*BCL11A*红系增强子，在白消安样清髓后回输；被编辑的干细胞自我更新，故效应不是年度性的而是长期的——但清髓带口腔黏膜炎、感染与不育风险，植活失败可能发生，最大队列也仍在随访。体细胞编辑不遗传；被编辑的红细胞来自被编辑的干细胞；设计上也无需年度重复给药。生育问题才是每天面对的伦理：清髓是性腺毒性的，所以生育力保存必须在一个“先经清髓预处理才能救命”的疗法之前讨论。
:::

## 通向何处

本章预设的药理学见[[pharmacology/metabolism-excretion]]与[[pharmacology/patient-variation]]；载体与表达生物学见[[cell-biochemistry/gene-expression]]；检测路径见[[genetics/genetic-testing]]；家族保密的判例见[[medical-ethics-law/confidentiality]]；资源伦理见[[medical-ethics-law/justice-resources]]；正被编辑的血红蛋白病见[[blood/haemoglobin-disorders]]。

::: summary
- 药物遗传学是带表型标签与行动的药物处置遗传变异；只有当结果在首剂前被调出、并为未来每一张处方保存时它才起作用。
- 基因添加、RNA疗法与编辑此刻就在治疗真实的疾病——视网膜营养不良、SMA、血友病、血红蛋白病、淀粉样变性——每种模态各有其固定成本：免疫、能否重复给药、预处理毒性、持久性、价格。
- 体细胞编辑是医学；可遗传的生殖系编辑目前被禁止或处于暂缓，其理由——安全、同意、正义——环环相扣、指向不同的补救，不可混为一谈。
- 遗传数据是预测的、家族的、身份性的、双刃的；职业实践是级联邀请、对二次发现的同意、以及在亲属可预防伤害面前——最小限度且依程序地——让路的保密。
- 可及与治理是治疗的一部分；只送达能为其预算买单之人的基因组医学，无论作为生物技术成就如何，作为医学已经失败。
:::

## 练习

::: exercise 读一个表型标签 {level=1}
报告写道：“CYP2D6：一个功能等位基因与一个无功能等位基因；预测中间代谢者；活性评分1.0。”这位患者能安全使用可待因吗？
::: solution
中间代谢者本身不是禁忌——向吗啡的转化发生，但容量是降低而非升高，所以更需担心的是镇痛不足而非毒性。安全性的回答是：在多数场景，可待因处方本就不单独取决于基因型：真正要紧的指导（儿童、哺乳母亲与已知超快代谢者避免可待因；其余按常规镇痛原则）无论结果如何都适用，而“中间”标签既不警告也不豁免任何临床判断本已管辖之事。实际操作是：记下表型、预期CYP2D6激活药物的疗效下降、镇痛失败时选择替代——而若患者是超快或慢代谢者——则按CPIC规则行动，对可待因即回避/减量。
:::
:::

::: exercise 药与基因的配对 {level=1}
开下列药物前各应具备哪种药物遗传学检测：(a) 阿巴卡韦；(b) 硫唑嘌呤；(c) 东南亚血统患者的卡马西平；(d) 地中海血统患者的伯氨喹；(e) 氟嘧啶类化疗？
::: solution
(a) *HLA-B\*57:01*——阳性即永不处方；回避即可预防超敏。(b) *TPMT*（活性或基因型）与*NUDT15*——功能减低基因型需减量或换药。(c) *HLA-B\*15:02*（±*-A\*31:01*）——SJS/TEN风险。(d) G6PD活性——氧化性溶血；伯氨喹前对缺乏范围结果作定量检测，重度缺乏请血液科会诊。(e) *DPYD*——功能减低变异决定起始减量或回避，但需注意常见错义变异阳性预测值低，故指导是剂量式而非二分的。
:::

::: exercise 游离体算术 {level=1}
某AAV肝脏基因治疗在第2年表达为正常的25%。设转基因随每次肝细胞分裂丢失，肝细胞更新使表达被稀释：成人约每十年降6%，儿童早期生长时快一倍。估计4岁接受治疗的患者到多大年龄可能重新需要预防治疗，并说明该计算的限度。
::: solution
简单指数：成人更新为25% × 0.94^n，头二十年生长期为25% × 0.88^m。把重型血友病阈值定在约5%，仅生长期就约需14年把25%降到5%（0.88^14 ≈ 0.17，25% × 0.17 ≈ 4%），即十八九岁；成人期丢失更慢，数字更晚更缓。限度才是要点：真实数据显示丢失是可变且非指数的、个体间游离体拷贝数不同、携转基因肝细胞的选择（随时间抬高水平、可抵消稀释）、以及数十年尺度上根本没有人类数据。这个数字的存在是让一句临床陈述变得精确：第3年看似永久的纠正，并未证明到第30年仍是永久的，随访义务据此设计。
:::
:::

::: exercise 载体选择 {level=2}
为各靶标选择载体/模态并辩护：(a) 乙型血友病，肝，永久性；(b) 婴儿期起病的运动神经元病SMA；(c) 可通过重建骨髓治愈的镰状细胞病；(d) 需要等位基因特异性沉默的显性功能获得等位基因。
::: solution
(a) AAV——不分裂的肝细胞维系游离体；嗜肝血清型；永久表达是目标，整合风险可接受。(b) ASO（诺西那生）或AAV9基因添加（*SMN1*）：问题在中枢与剪接——ASO在脑脊液以RNA层面作用、需重复给药但无免疫永久性之忧；AAV9入神经元、一次但不可重复。两者皆有；可辩护的答案按年龄与可重复性取舍。(c) 慢病毒转导或CRISPR离体编辑自体CD34+细胞加清髓——骨髓是可自我更新的靶标、预处理可存活，这正是首批获批编辑疗法的设计。(d) 等位基因特异性ASO或siRNA，或变异特异性向导的CRISPR——敲低需要区分突变型与野生型转录本，RNA层面模态以序列做到这一点，而AAV过表达做不到。
:::

::: exercise 筛查panel之争 {level=2}
某国家项目拟在现行生化panel之外，对新生儿增加基于测序的、针对有行动价值的成年起病风险（*BRCA1/2*、家族性高胆固醇血症变异）的筛查。请给出两边各两个最强论证，以及多数伦理学家会接受它的程序条件。
::: solution
支持：预防价值真实但时间错位——二十几岁起始的他汀预防FH的事件、*BRCA*监测能救命；新生儿取样提供成人随访永远达不到的覆盖率（公平论证：儿童期取样筛查所有人，成人级联检测筛查有表达能力者）；样本保存使日后重新分析便宜。反对：获益在成年兑现，比可能给予同意或认可晚了几十年；父母的决定权被用于未来一个人的信息，其保险与家庭关系后果是孩子无法撤销的；panel设计邀请任务蔓延——从有行动价值滑向仅仅有趣。多数伦理学家接受的程序条件：结果在儿童期不得*披露*——样本在治理下保存、保留不知情权，披露推迟到可同意年龄并允许退出，项目以下游监测依从率而非检测人次为评价指标。注意每个反对意见真正攻击的是哪一边：科学不在争议之列；争议在于为一个未获同意的未来之人做决定的权威。
:::

::: exercise 正义与价格 {level=2}
一次定价250万美元的基因疗法可治愈一种终生每位患者耗费卫生系统120万美元的疾病。解释为什么“它自己付得起自己”是错误的框架，并说出三种实际被提出的筹资机制。
::: solution
框架错了三个理由：货币的时间价值使即时成本最重地砸在付款的部门，而节省发生在别处（患者流、社会照护、未来预算——“错口袋”问题）；反事实终生成本假设该疗法对每位接受治疗者、且持续数十年有效，而没有任何试验支持这一点；且成本中性不等于正义——一个疗法可以自负盈亏，仍被配给给熬过申请队列的人。实际提出的机制：年金/抵押式支付（付款方分年支付、仅当获益持续）；基于结局的返利（无效即退款）；以及在地方购买之外持有超罕见疗法预算的人群风险池或独立国家准入基金，把决定与一家医院的现金流脱钩。诚实的临床后果是：准入标准——哪些基因型、哪些合并症、哪些年龄——成为配给文件，临床医生应当明说，而不是把标准包装成纯粹的医学。
:::

::: exercise 设计一份同意书 {level=3}
你在起草一项体内CRISPR试验（脂质纳米颗粒靶向肝脏）的同意书。列出严谨同意必须覆盖的十个要素，区分科学上的不确定与价值上的取舍。
::: solution
须申明的科学不确定：(1)脱靶谱及检测方法的不可见处（大缺失、嵌合）；(2)持久性及编辑在肝更新中不持久的可能；(3)对Cas蛋白的免疫原性限制重复给药；(4)长期未知——载体与编辑的组合没有数十年人类经验；(5)剂量爬坡状态与受试者个人在试验剂量区间中的位置之不确定。须指出的价值取舍：(6)生殖系暴露——纳米颗粒可测到低水平的性腺组织附带编辑；受试者对假想传递的价值判断要紧，必须被引出而非默认排除；(7)生育与生育时机；(8)一个持久、可身份关联结果的隐私与未来可保性；(9)若厂家撤出，受试者怎么办（产品半衰期、随访义务由谁接）；(10)在检测质量参差的试验点，选择不了解在靶效应的权利。同意书应当说明：哪些是未知的、哪些是不可知的、哪些是受试者自己的决定——2018年广州事件把这种区分变成了国际准则。
:::

::: exercise 最后的问题 {level=3}
一名22岁青年，无个人及家族病史，要求做全基因组测序“规划我的人生”：饮食、运动、职业风险、保险、伴侣筛查。你怎么说？
::: solution
分三层回答。基因组能给的：对未来处方有用的药物遗传学标签；少数经确认、若有则引出监测的单基因风险（遗传性肿瘤与心脏panel按*家族史*提供——他没有）；与未来伴侣生育规划相关的祖源与携带者状态。基因组不能给的：行为、职业或多数复杂疾病的多基因评分——效应量小到无法指导个人、跨群体转移差到无法可靠预测；超出证据兜售的饮食与运动“基因处方”；以及可保性——多数辖区里保险公司拿不到的数据不影响承保，但他可能自愿披露而后悔。伦理核心在他最后一条：伴侣筛查只有当双方的携带者状态与意愿都在场时才是生殖医学；单独一人被筛，就把一个共同决定变成一场市场，并可能制造污名；正确的转诊是*与伴侣一道*去遗传服务，或使用正当提供的孕前携带者筛查。最后告诉他真正该带走的：把临床病历做扎实、让药物遗传学结果可被调阅、把家系图画准确，把钱花在会改变他和医生所作所为的检测上——而对一个没有家族史的人，今日基因组恰是这件事做得最少的。
:::
