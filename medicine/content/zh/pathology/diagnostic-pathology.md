大多数患者从未见过病理医师，然而他们医疗中许多最重要的决定都依赖于病理医师。一个肿块是不是癌，是哪一种癌，是否已被完整切除，可能对哪些药物有反应，这些问题都要通过检查组织和细胞来回答。本章追踪一份标本，从它离开患者的那一刻起，直到它的报告在多学科会议上被讨论。随后介绍尸检、保障这一流程安全的质量体系，以及数字病理的到来。

报告所表达的概念，如分级、分期和预测性标志物，在[[pathology/cancer-diagnosis]]中定义。本章讲的是病理医师如何得出这些结果，以及临床医生应当如何阅读它们。

## 细胞病理学的分支

**组织病理学**是根据组织诊断疾病，组织中保留了结构（细胞如何排列）。**细胞病理学**是根据单个细胞或小细胞团诊断疾病，没有组织结构。两者与**尸检**一起构成**细胞病理学**这一大的专业。其他病理学分支，如临床生物化学、血液学和微生物学，分析的是体液和病原体（[[clinical-skills/laboratory-tests]]，[[microbiology/laboratory-diagnosis]]）。

## 标本与申请

这一流程从临床医生开始。每份标本必须至少标有患者的全名、出生日期和一个唯一标识符（如NHS号码），并与一张**申请单**相匹配，申请单上写有相同的标识符、标本部位、临床问题和相关病史。临床信息会改变诊断思路：“服用NSAIDs者的胃溃疡”和“伴体重下降和贫血的溃疡”会引导病理医师寻找不同的东西。

标本有几种类型：

- **活检**取少量组织用于诊断。**空芯针活检**用中空的针取出一条圆柱形组织，常在超声或CT引导下进行；**内镜活检**取黏膜小块；**环钻活检**取一个皮肤圆柱；**切取活检**切除病变的一部分；**切除活检**切除整个病变。
- **切除标本**切除一个器官或其一部分，通常用于治疗已知的疾病，如乳房切除术或结肠切除术。
- **细胞学**标本由细胞组成：体液、刷片、刮片和穿刺物。

## 固定与处理

::: definition 固定 {#def-fixation}
**固定**是对组织进行处理，通过阻止自溶（细胞自身酶的自我消化）和腐败（细菌引起的分解），使其结构尽可能保持生活时的状态。标准固定液是**10%中性缓冲福尔马林**，即约4%的甲醛溶液，它在蛋白质之间形成交联（亚甲基桥）。
:::

良好的固定取决于三点。标本必须迅速接触固定液，因为血供一断，自溶就开始了；从离体到固定的时间称为**冷缺血时间**，乳腺癌标本应控制在约一小时以内，因为延迟会使用于指导治疗的受体降解。固定液的体积至少应为组织体积的十倍。固定时间必须足够长：福尔马林渗透组织很慢，交联所需的时间更长。

固定液的渗透深度随时间的平方根增加：

$$
d = K\sqrt{t}
$$ {#eq-penetration}

其中$d$是以毫米计的深度，$t$是以小时计的时间，$K$是取决于固定液和组织的系数。对于福尔马林，$K$约为每小时平方根0.75 mm（文献值不一），因此福尔马林在24小时内约渗透3.7 mm。这就是为什么大标本在浸入固定液之前必须剖开或切片。

::: example 标本为什么要切片 {#ex-fixation}
外科医生切下一个含有肿瘤的肾，把它整个放入福尔马林中。假设$K = 0.75$ mm每小时平方根。福尔马林到达10 mm厚组织块中心和4 mm厚切片中心各需多长时间？如果肾保持完整，位于包膜下3 cm的肿瘤会怎样？
::: solution
1. 10 mm组织块的中心距每个表面5 mm：$t = (5/0.75)^2 \approx 44$小时。
2. 4 mm切片的中心深2 mm：$t = (2/0.75)^2 \approx 7.1$小时。
3. 距表面30 mm的肿瘤需要$(30/0.75)^2 = 1600$小时，超过两个月。远在此之前它就已自溶。
4. 自溶的组织失去细胞核细节和抗原，可能使分级、免疫组织化学和分子检测变得不可靠。这就是为什么大标本要在实验室中及时剖开或切片（或按当地安排送新鲜标本），也是为什么固定规程同时规定了最短和最长固定时间。
:::
:::

固定后，病理医师（或经过培训的生物医学科学家）进行**大体检查**，又称“取材”。描述、测量标本，必要时拍照，并用彩色墨水涂染手术切缘，以便在显微镜下辨认。代表性组织块被放入塑料包埋盒。然后对组织进行**处理**：用浓度递增的乙醇脱水，用二甲苯等透明剂替换乙醇，再用熔化的石蜡浸透组织并包埋成块。切片机切出3至4 µm厚的切片，漂浮后贴附于载玻片上。

常规染色是**苏木精-伊红**（H&E）染色。苏木精把细胞核染成蓝紫色，因为它与DNA等酸性结构结合（它们是“嗜碱性”的）。伊红把胞质、胶原和肌肉染成不同程度的粉红色（它们是“嗜酸性”的）。大多数诊断仅凭H&E即可作出。

常规处理需要一天或更长时间。骨和钙化组织需要先在酸性或螯合溶液中**脱钙**，这可能需要数天至数周，并会损伤DNA。英国皇家病理学家学院（RCPath）提出的关键绩效指标是：80%的组织病理学病例在标本采集后7个日历日内发出报告，90%在10日内发出报告。

### 冰冻切片

当外科医生在手术中需要答案时，可以把组织快速冷冻，在冷冻切片机（恒冷箱切片机）中切片。**冰冻切片**约20分钟即可给出诊断。它用于在大范围切除前确认病变为恶性，检查手术切缘是否干净，或确认活检含有可供诊断的组织。冷冻会使组织变形，脂肪组织难以切片，而且有些诊断，如淋巴瘤或某些甲状腺滤泡性病变的鉴别，无法可靠地作出。因此每一次冰冻切片之后，都要对同一组织进行常规处理后的检查。

## 细胞病理学

::: definition 细胞学标本 {#def-cytology}
- **脱落细胞学**检查自然脱落或从表面刮取的细胞：尿液、痰、胸腔积液和腹腔积液，以及宫颈样本。
- **细针穿刺**（FNA）用细针从肿块中吸取细胞，如甲状腺结节、淋巴结、乳腺病变，或经超声内镜穿刺纵隔淋巴结或胰腺。
- **液基细胞学**把样本置于保存液中，从中制备出薄而均匀的细胞层，可在同一样本上进行HPV检测等附加检查。
- **细胞块**是把液体或穿刺物离心沉淀，像组织一样处理沉淀物，以便进行免疫组织化学和分子检测。
:::

细胞学快速、廉价且创伤小，细针穿刺常可在数小时内出报告。其主要局限是只见细胞而不见结构。它能显示细胞是恶性的，但往往不能判断肿瘤是否浸润；有些诊断，如甲状腺滤泡癌，依赖于包膜或血管的侵犯，而细胞学看不到这些。因此结果以类别报告，既表达诊断，也表达其确定程度；例如英国甲状腺细胞学使用Thy1（不能诊断）到Thy5（恶性）的类别。在**快速现场评估**中，细胞病理医师或科学家在操作过程中检查是否已获得足够的诊断材料。

## 特殊染色

在抗体问世之前，病理医师开发了显示特定物质的化学染色。其中许多至今仍在日常使用。

| 染色 | 显示的物质 | 典型用途 |
|---|---|---|
| 过碘酸希夫（PAS） | 糖原、黏液、真菌壁、基底膜 | 真菌、糖原贮积、分泌黏液的癌 |
| 抗酸染色（Ziehl-Neelsen） | 抗酸杆菌（红色） | 肉芽肿中的分枝杆菌 |
| Grocott六胺银 | 真菌壁（黑色） | 肺孢子菌、曲霉 |
| 刚果红 | 淀粉样物质（偏振光下苹果绿色双折光） | 淀粉样变 |
| 普鲁士蓝（Perls） | 三价铁（蓝色） | 含铁血黄素、铁过载 |
| 网状纤维染色 | 网状纤维（黑色） | 肝结构、骨髓纤维化 |
| Masson三色染色 | 胶原（蓝色或绿色） | 肝和肾的纤维化 |
| 革兰染色 | 细菌（阳性紫色，阴性红色） | 组织中的细菌 |

## 免疫组织化学

::: definition 免疫组织化学 {#def-ihc}
**免疫组织化学**（IHC）用抗体检测组织切片中的特定蛋白质。结合的抗体通过一种酶（通常是过氧化物酶）显色，该酶把二氨基联苯胺等显色剂转化为位于蛋白质所在部位的棕色沉淀。评估染色的模式（核、胞质或膜）、强度以及着色细胞的比例。
:::

IHC回答两类问题。**诊断性**IHC确定肿瘤的**谱系**：是癌、淋巴瘤、黑色素瘤还是肉瘤；对于癌，还要判断其可能的器官来源。**预测性**IHC测定指导治疗的蛋白质。

| 标志物 | 典型阳性 |
|---|---|
| 广谱细胞角蛋白 | 癌（上皮细胞） |
| CD45 | 淋巴瘤和其他白细胞 |
| S100、SOX10 | 黑色素瘤、神经鞘肿瘤 |
| 结蛋白（desmin） | 平滑肌和骨骼肌肿瘤 |
| CK7 / CK20 | CK7+ CK20−：肺、乳腺及许多其他部位；CK7− CK20+：结直肠；CK7+ CK20+：尿路上皮、部分胰腺和胃 |
| TTF-1 | 肺腺癌、甲状腺 |
| CDX2 | 肠型腺癌 |
| GATA3 | 乳腺癌和尿路上皮癌 |
| PAX8 | 肾、卵巢（浆液性）、子宫内膜和甲状腺肿瘤 |
| WT1、钙视网膜蛋白 | 间皮瘤（WT1也见于浆液性卵巢癌） |

::: theorem 免疫组织化学要作为一组来解读 {#thm-panel}
没有任何单一的免疫组织化学标志物对某一肿瘤类型是完全特异或完全敏感的。谱系要根据一组标志物的模式来判定，标志物的选择要考虑形态学和临床情境，并且既包括预期阳性的标志物，也包括预期阴性的标志物。
:::

::: proof
用作标志物的蛋白质反映的是分化程序，而肿瘤可以异常表达它们，在去分化时丢失它们，或在不同器官间共享它们。TTF-1在肺和甲状腺肿瘤中都着色；GATA3在乳腺癌和尿路上皮癌中都着色；某些低分化癌丢失细胞角蛋白；某些黑色素瘤丢失S100。固定不良或脱钙等技术因素会使染色减弱。一组标志物把几个不完美的检测变成一种模式，其特异性远高于任何单一结果，而预期阴性的标志物可以防止误判。最终的解读总要整合H&E表现和临床情况。
:::

::: example 来源不明的肝转移灶 {#ex-cup}
一名68岁男性肝内有多个肿块。空芯针活检显示腺癌。IHC：CK7阴性，CK20阳性，CDX2阳性，TTF-1阴性。最可能的原发部位是哪里？下一步应当做什么？
::: solution
1. CK7−/CK20+模式加CDX2阳性，是**结直肠腺癌**的典型表现。
2. TTF-1阴性不支持肺腺癌，后者是这一年龄组肝转移灶的另一个常见来源。
3. 病理医师报告为转移性腺癌，免疫表型符合结直肠来源，团队安排结肠镜和CT寻找原发灶。
4. 同一份活检可用于预测性检测：用IHC检测错配修复蛋白，用分子检测确定*RAS*和*BRAF*状态，因为这些会影响转移性结直肠癌的治疗。因此组织要谨慎使用，只申请能回答问题的检测。
:::
:::

### 预测性免疫组织化学

- 乳腺癌中的**雌激素受体和孕激素受体**是核蛋白，按着色细胞核的比例和强度评分（例如用Allred评分）。阳性肿瘤可能对内分泌治疗有反应。
- 乳腺癌和胃癌中的**HER2**是膜蛋白，评为0、1+、2+或3+。3+为阳性；2+为不确定，需用原位杂交检测基因扩增来判定；0和1+对经典的HER2靶向治疗为阴性，但1+或2+而无扩增的肿瘤（“HER2低表达”）现在可能适用一种较新的抗体偶联药物。
- **PD-L1**按肿瘤细胞的百分比（肿瘤比例评分）或肿瘤细胞加免疫细胞的百分比（联合阳性评分）评分，帮助选择适合免疫检查点抑制剂的患者。
- **错配修复蛋白**（MLH1、PMS2、MSH2、MSH6）是核蛋白；其中一对缺失提示错配修复缺陷，可用于筛查林奇综合征，并预测对检查点抑制剂的反应（[[pathology/cancer-biology]]）。

## 分子病理学

现在许多治疗依赖于检测肿瘤中的特定遗传改变。

- **聚合酶链反应**（PCR）扩增目标序列，可检测已知突变，如肺癌中的*EGFR*突变或结直肠癌中的*KRAS*突变。
- **原位杂交**在组织切片上使用标记的DNA探针。使用荧光探针（**FISH**）时，病理医师计数每个细胞核中的信号，例如检测*HER2*扩增，或用“分离”探针检测肺癌中*ALK*的重排。
- **二代测序**（NGS）同时对许多基因乃至整个基因组测序，检测突变、融合和扩增，并测定肿瘤突变负荷和微卫星不稳定性。
- **液体活检**检测循环肿瘤DNA（ctDNA），即肿瘤细胞释放入血的DNA。在无法获得组织时，它可以发现可靶向的突变并监测耐药；但阴性结果不能排除突变，因为有些肿瘤释放的DNA很少。

在英格兰，基因组检测通过NHS基因组医学服务组织实施，该服务发布国家基因组检测目录，规定哪些检测可用于哪些癌症和遗传病（[[genetics/genomic-medicine]]）。

::: example HER2原位杂交结果 {#ex-her2}
一例乳腺癌IHC评分HER2 2+。双探针原位杂交计数20个细胞核，平均每个细胞核有6.4个*HER2*信号和2.0个17号染色体着丝粒（CEP17）信号。该肿瘤有HER2扩增吗？
::: solution
1. 比值 $= 6.4/2.0 = 3.2$。
2. 按照英国采用的国际（ASCO/CAP）标准，*HER2*/CEP17比值为2.0或以上，且平均每个细胞*HER2*拷贝数为4.0或以上，提示**扩增**。
3. 两个条件都满足（比值3.2，拷贝数6.4），因此该肿瘤为**HER2阳性**。
4. 这使她有资格按照多学科团队的建议接受HER2靶向治疗。不确定的IHC结果通过直接测定基因得到了判定，这就是两种技术要结合使用的原因。
:::
:::

::: example 检测能看到这个突变吗？ {#ex-vaf}
一份肺腺癌活检送检NGS。病理医师估计样本中30%的有核细胞是肿瘤细胞，其余是炎症细胞和间质细胞。如果肿瘤细胞携带杂合性*EGFR*突变，预期的变异等位基因频率（VAF）是多少？如果该检测能可靠检出低至5%的变异，在肿瘤含量最低为多少时能检出这一突变？
::: solution
1. 每个肿瘤细胞有两个*EGFR*拷贝，其中一个突变，因此肿瘤等位基因的一半带有突变。正常细胞没有。
2. 预期VAF $= 0.30 \times 0.5 = 0.15$，即15%（假设拷贝数没有改变）。
3. 要达到5%的检测下限：肿瘤比例 $\times 0.5 = 0.05$，所以肿瘤比例 $= 0.10$，即10%。
4. 肿瘤含量低于约10%时，真实存在的突变可能被漏掉，而报告为“未检出”。这就是病理医师要选择肿瘤最丰富的区域、有时从切片上把它刮取下来（宏观切割），并在申请单上记录肿瘤含量的原因，也是为什么肿瘤很少的样本的阴性结果要附带这一说明。
:::
:::

## 阅读病理报告

组织病理学报告通常有四个部分：提供的临床资料；**大体描述**（标本的外观、大小和重量、病变大小以及所取的组织块）；**镜下描述**；以及**结论**或诊断，常附有诊断编码。对于癌的切除标本，英国皇家病理学家学院发布**数据集**，规定必须报告的项目。许多报告以结构化（**大纲式**）格式呈现这些项目。在国际上，国际癌症报告合作组织负责协调这些数据集。

对于癌的切除标本，报告通常记录：

- **肿瘤类型**和**分级**；
- **大小**和浸润**范围**，由此得出pT类别；
- **淋巴管血管侵犯**（淋巴管或血管内有肿瘤）和**神经周围侵犯**；
- **切缘**：肿瘤是否累及切缘，若未累及，到最近切缘的距离（毫米）；
- **淋巴结**：检查的数目和受累的数目，以及肿瘤是否突破淋巴结包膜，由此得出pN类别；
- **病理分期**（pTNM，注明所用TNM版本）；
- **生物标志物**结果，可能在补充报告中给出。

::: definition 切缘与前哨淋巴结 {#def-margins}
- **手术切缘**是标本的切割面。如果切缘处有肿瘤，则切缘**受累**（阳性），提示肿瘤可能残留在患者体内。切除的完整性概括为**R0**（无残留肿瘤）、**R1**（镜下残留肿瘤）或**R2**（肉眼残留肿瘤）。怎样算切缘干净因肿瘤类型而异：有的指墨染处无肿瘤，有的要求达到最小距离。
- **前哨淋巴结**是最先接受肿瘤淋巴引流的一个或几个淋巴结，通过在肿瘤附近注射放射性示踪剂、染料或磁性颗粒来识别。如果前哨淋巴结无肿瘤，其他淋巴结受累的可能性很小，因此可以避免全面淋巴结清扫及其淋巴水肿的风险。它是早期乳腺癌和黑色素瘤的标准做法。
:::

::: example 阅读一份乳腺癌报告 {#ex-report}
一名57岁女性接受了局部扩大切除和前哨淋巴结活检。报告写道：“非特殊型浸润性癌，2级，18 mm。未见淋巴管血管侵犯。浸润性癌最近切缘3 mm（下切缘）。前哨淋巴结：0/2受累。ER阳性（Allred 8/8），HER2阴性（IHC 1+）。pT1c pN0(sn)。”解释其含义。
::: solution
1. **非特殊型浸润性癌**是最常见的乳腺癌，以前称为浸润性导管癌。
2. **2级**为中等分化（Nottingham评分6或7）。
3. **18 mm**使肿瘤归为pT1c（大于10 mm且不超过20 mm）。
4. **无淋巴管血管侵犯**以及**两枚阴性前哨淋巴结**（pN0(sn)）表明扩散到淋巴结的可能性小，因此不需要进一步的腋窝手术。
5. **3 mm的切缘**表明肿瘤已被完整切除；英国乳腺外科协会的共识指南认为保乳手术后至少1 mm的放射状切缘即为足够，因此不需要再次切除。
6. **ER阳性**且Allred评分最高，预测内分泌治疗获益。**HER2 1+**对经典的HER2靶向治疗为阴性。
7. 多学科团队会综合这些因素推荐辅助治疗，通常是保乳手术后的乳腺放疗和内分泌治疗，并根据估计的获益考虑化疗（[[surgery/breast-endocrine-surgery]]）。
:::
:::

::: warning 阴性活检的价值取决于样本
活检只显示被取到的组织。对于影像学上看似恶性的病变，小样本的良性结果可能反映**取样误差**：针没有取到肿瘤。病理医师无法知道没有被取到的是什么。因此结果必须与临床和影像学所见相互印证；这在乳腺肿块的“三联评估”（临床检查、影像学和活检）中得到了规范化。当三者不一致时，要在多学科会议上讨论这一不一致，通常需要重复活检。同样的逻辑也适用于报告为“不能诊断”的细胞学，它意味着材料不足，而不是结果正常。
:::

## 多学科团队

在英国，每一例新诊断的癌症都要由**多学科团队**（MDT）讨论，成员包括外科医生、肿瘤科医生、放射科医生、病理医师、专科护士等。病理医师介绍诊断、分级和分期、切缘和生物标志物，并指出不确定之处。讨论常会发现临床、影像和病理所见之间的不一致，从而促使复查切片或进行进一步检测。随后与患者讨论团队的建议，患者的意愿决定最终的决策。

## 质量与安全

实验室流程有很多步骤，每一步都可能出错：标签错误、处理过程中混入另一患者的组织碎片（“漂浮物”）、判读错误、漏掉小的癌灶，或报告没有送达临床医生。保障措施包括：

- 每一步都进行**患者身份确认**，标本和切片使用条形码；
- 染色的**室内质量控制**，每张IHC切片都附有对照组织；
- **室间质量评价**项目，如UK NEQAS，把同样的材料发给许多实验室并比较结果；
- 由英国认可服务机构（UKAS）按照国际标准ISO 15189对实验室进行**认可**；
- 对疑难或高风险病例进行**会诊**和双人报告，并在MDT会议上复核；
- 确保重要的和意外的结果直接传达给负责的临床医生的制度。

发现错误时，要修改报告，通知临床医生，并按照职业坦诚义务对事件进行调查并向患者告知（[[clinical-skills/patient-safety]]）。

## 尸检

**尸检**（死后检查）是对死者遗体进行的系统性体表和体内检查，并根据需要取样进行组织学、微生物学和毒理学检查。在英格兰和威尔士有两种尸检：

- **医院（经同意的）尸检**由临床医生申请，经近亲属同意，用于了解疾病、核查诊断的准确性、评估治疗效果，以及用于教学和研究。组织的摘取和保留受《2004年人体组织法》（在苏格兰为《2006年人体组织（苏格兰）法》）管辖，该法是在发现器官未经同意被保留之后出台的，尸检场所由人体组织管理局颁发许可。
- **验尸官尸检**由验尸官（一名独立的司法官员）下令进行，适用于死亡突然且原因不明、暴力或非自然死亡、在国家羁押中死亡或符合其他标准的情况。不需要家属同意，但会尊重他们的意见。

自2024年9月9日起，英格兰和威尔士所有未报告给验尸官的死亡，都必须由独立的**医学审查员**进行审查。医学审查员是一名资深医生，在死亡登记之前审查病历，与主治医生和死者家属交谈，并确定死因。这一制度是在对全科医生哈罗德·希普曼（Harold Shipman）所犯谋杀案等事件的调查之后引入的，这些调查显示了以往死亡证明制度的薄弱。

在许多国家，医院尸检率已急剧下降。然而，尸检研究不断发现，相当比例的死亡存在生前漏诊或误诊的重大诊断。在家属不接受完整尸检时，越来越多地采用创伤较小的方法，即死后CT或MRI加靶向活检。

## 数字病理与人工智能

在**数字病理**中，玻璃切片被高分辨率扫描，生成全切片图像，由病理医师在屏幕上阅片。这使远程报告、更快的会诊和更便利的教学成为可能，许多NHS实验室已经采用。数字图像也使**人工智能**算法的应用成为可能，例如在前列腺活检中标出可能的癌、计数核分裂象或对生物标志物评分。一些此类工具已获得监管批准，作为病理医师的辅助工具。要安全使用它们，需要在本地病例上进行验证，认识到算法在与其训练数据不同的人群或染色方法上可能表现更差，并且由病理医师对诊断负责。

::: quiz
淋巴结中的一例转移性癌CK7阳性、CK20阴性、TTF-1阳性、GATA3阴性。最可能的原发部位是哪里？
- [ ] 结直肠
- [x] 肺
- [ ] 乳腺
- [ ] 膀胱
::: solution
CK7阳性、CK20阴性符合肺、乳腺和若干其他部位。TTF-1阳性指向肺腺癌（或甲状腺），GATA3阴性不支持乳腺癌和尿路上皮癌。结直肠癌通常CK7阴性、CK20阳性。
:::

::: history
缪勒（Johannes Müller）于1838年发表了对肿瘤的显微镜研究，他的学生菲尔绍（Rudolf Virchow）使显微镜成为病理学的核心工具。1905年，梅奥诊所的威尔逊（Louis B. Wilson）引入了一种快速冰冻切片方法，使外科医生能在手术中得到诊断。1941年，孔斯（Albert Coons）及其同事用荧光染料标记抗体，用以在组织中定位抗原，这是免疫组织化学的开端；在普通显微镜下可见的酶标记方法于20世纪60和70年代相继出现。穆利斯（Kary Mullis）于1983年发明了聚合酶链反应，并因此分享了1993年诺贝尔化学奖；它使在小活检标本上进行分子病理检测成为可能。在英格兰和威尔士，法定的医学审查员制度于2024年9月9日开始实施。
:::

::: summary
- 组织病理学检查保留结构的组织；细胞病理学检查没有结构的细胞。两者都依赖于正确的标签和临床信息。
- 福尔马林固定使蛋白质交联并阻止自溶。渗透深度随时间的平方根增加，因此大标本必须切片；冷缺血时间必须短。
- 组织经处理制成石蜡块，切成3至4 µm的切片，进行H&E染色。冰冻切片约20分钟即可在术中给出答案，但可靠性较低。
- 细胞学（脱落细胞学、细针穿刺、液基细胞学、细胞块）快速、创伤小，但常不能评估浸润。
- 特殊染色显示病原体、黏液、淀粉样物质、铁和纤维化。
- 免疫组织化学确定谱系（作为一组来解读）和预测性标志物（ER、PR、HER2、PD-L1、错配修复蛋白）。
- 分子病理学（PCR、FISH、NGS、ctDNA）检测可靶向的改变；足够的肿瘤含量至关重要。
- 癌的报告给出类型、分级、大小、浸润、淋巴管血管侵犯、切缘、淋巴结、pTNM和生物标志物，常采用RCPath数据集。前哨淋巴结活检避免了不必要的淋巴结清扫。
- 结果在多学科团队会议上整合。质量依赖于身份识别、室间质评、ISO 15189认可和会诊。
- 尸检分为经同意的医院尸检和验尸官尸检；自2024年9月9日起，英格兰和威尔士所有非验尸官案件的死亡均由医学审查员审查。

在双探针原位杂交中，平均每个细胞核*HER2*信号为4.8个，CEP17为2.0个。计算*HER2*/CEP17比值。给出精确值。

::: solution

::: exercise 冰冻切片：何时用，何时不用 {level=2}
对下列每种情况，说明冰冻切片是否合适及原因：(a) 先前无法活检的肺结节，在肺叶切除前确认为癌；(b) 诊断肿大淋巴结中疑似的淋巴瘤；(c) 胰腺切除术中检查胆管切缘；(d) 一个疑为黑色素瘤的3 mm皮肤病变。
::: solution
(a) 合适：恶性诊断可以支持在同一次手术中进行肺叶切除。(b) 不适合作出明确诊断：淋巴瘤分类需要固定良好的组织、免疫组织化学，常还需要分子检测；冰冻切片可以确认已取得可供诊断的组织，并可送新鲜组织。(c) 合适：切缘阳性可能使外科医生切除更多胆管。(d) 不合适：冷冻小的黑素细胞病变会使其变形，并可能耗尽精确测量厚度所需的组织，而厚度决定分期。
:::

::: exercise 同意与验尸官 {level=2}
一名45岁男性在家中猝死，无已知疾病。他的家属不希望进行尸检。一名82岁女性在医院死于已知的转移性肺癌，她的主治医生想知道她是否也有肺栓塞。分别解释由谁决定是否进行尸检。
::: solution
该男性的猝死原因不明，必须报告给**验尸官**，由验尸官决定是否需要尸检以确定死因；不需要家属同意，但验尸官会考虑他们的意见，也可能采用创伤较小的方法。该女性的死亡有已知的自然原因，因此由**医学审查员**审查，通常不报告给验尸官。为回答主治医生的问题而进行的尸检属于**医院尸检**，根据《2004年人体组织法》需要近亲属同意。如果他们拒绝，就不能进行。
:::
:::

::: exercise 不一致的活检 {level=3}
一名49岁女性有一个2 cm的乳腺肿块，质硬、边界不规则。乳腺X线摄影和超声显示一个高度可疑为癌的毛刺状病变。超声引导下空芯针活检显示良性纤维组织和脂肪。解释如何解读这一结果以及下一步该怎么做。
::: hint
想一想三联评估。
:::
::: solution
这是**三联评估不一致**：临床和影像学所见高度可疑，但活检为良性。最可能的解释是取样误差，即针取到的是病变附近的组织而不是病变本身；有些癌，尤其是小叶癌，细胞成分也很少，难以取到。在这种情况下不能接受良性结果。应在乳腺多学科会议上讨论此病例，复查影像和活检位置，并重复活检，例如多取几条组织或采用真空辅助活检，或切除病变以明确诊断。一般原则是：病理医师只能报告样本中有什么，与临床和影像学所见相互印证是解读每一份活检的一部分。
:::
:::

::: exercise 肿瘤太少 {level=3}
一份小的支气管镜肺腺癌活检约含8%的肿瘤细胞。NGS报告“未检出*EGFR*突变”。肿瘤科医生问能否认为患者是*EGFR*野生型。用变异等位基因频率解释答案，并提出可以怎么做。
::: solution
肿瘤细胞占8%、突变为杂合时，预期的变异等位基因频率为$0.08 \times 0.5 = 0.04$，即4%，低于约5%的典型检测下限。因此真实存在的突变可能被漏掉，结果应解读为“在肿瘤含量低的样本中未检出”，而不是已确认的野生型。可选的做法包括：在肿瘤更丰富的组织块或区域经宏观切割后重新检测，采用更敏感的靶向PCR检测，检测血液中的循环肿瘤DNA（阳性结果可据以治疗，但阴性结果不能排除突变），或重新取活检。这一决定很重要，因为*EGFR*突变型肺癌使用靶向药物治疗，作为一线选择比化疗或免疫治疗更有效。
:::
:::
