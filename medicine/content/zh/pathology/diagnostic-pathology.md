诊断病理学是“看、取、说”的专科：**冷冻切片与细胞学筛查与免疫组化的组合与分子的检测，都只是回答三个问题的工具——是不是癌、哪一种、有多少——而病理医师的答复塑造了此后每一句临床的话；因此本专科的核心技术与其说是显微镜，不如说是取样、语言与不确定性的管理。**本章覆盖从标本到报告的工作流（申请单与固定与取材与切片与诊断与报告的写法）、作为诊断系统的实验室（分析前与分析中与分析后的错误分布与检验项目的选择与解释）、以及质量、误差与数字化（内外部的质量评价与关键差异的会议与重复阅片与人工智能辅助与远程诊断）。

## 从标本到报告

::: definition 诊断的工作流 {#def-workflow}
**病理的每个结论都始于一个不由病理医师控制的决定：取哪块组织。取样的代表性是诊断的上限（一个针吸的细胞学不能给乳腺的原位与浸润的分层与间质的反应，因此不能分类；一个内镜的活检可能只取到溃疡的边缘；一个前列腺的穿刺可以完全错过背侧与前外的病灶）；所以细胞学与组织学不是“粗细”之分，而是问题的种类不同——细胞学看细胞，组织学看结构与关系。分析前的环节最脆弱：申请单的信息（部位与侧别与影像与既往的标本与临床的问题，缺一则诊断的假设空间无法被缩小）、固定的开始与时长与缓冲液（缺血时间的长短直接改变若干标志物的可测性，使术前治疗后的评估与研究的可比性依赖于此）、包埋与切片的层面（一张切片的厚度与选取的块数决定了能否看到一处微小的高度不典型区域）、以及切片的编号与标记（这是“标本混淆”这一最可怕的病理误差的所在）。诊断的语言是被设计的：完整的报告包含标本的描述（接受与切开与取材的块数与肿瘤的大小与外观与切缘与淋巴结的取样）、镜下的描述（分级与组织学与浸润的模式与淋巴血管与神经与周围的改变）、结论（诊断的措辞按可被行动的程度分级，从描述性的“不足以判断”到明确的诊断，再到需要附加检测的“提示性”）、附加的检测（免疫组化与分子，及其结果如何被写入诊断）、以及补注（分期与推荐与既往标本的比较）。补注这一段最能区分好的报告与够用的报告：分期需要的要素（浸润的深度与范围与脉管与切缘与淋巴结的数目与转移的数目与远处沉积）如果缺失，临床只能在报告中猜测或再次取组织；而把不确定的部分写成“我建议做某某检查”比把它藏进沉默更负责任——[[pathology/cancer-diagnosis]]、[[clinical-skills/records-handover]]、[[surgery/perioperative-care]]。**
:::

::: definition 作为诊断系统的实验室 {#def-lab}
**检验医学的诊断误差绝大多数在分析之前与之后，而不在仪器里：患者的状态（空服与昼夜与月经与体位与运动的近期改变与输液侧的采血）、采集的次序与真空管的添加物（依地酸盐污染使钙假性极低、柠檬酸盐管的不足充盈使凝血时间假性延长、含锂的管使钾假性升高）、标注与身份（这是最危险的失败，也是唯一完全可预防的一类，需要两名核对与条形码与患者的确认）、运输的温度与时间（钾从细胞漏出与血气在室温的继续代谢与氨的升高与乳酸的降解使“放了一会儿”成为独立的变量）、以及生理节律与参考区间的适用性（把一个实验室的“参考范围”套在另一人群上会产生错误的正常）。解释的项目有固定的算法：一个孤立的自身抗体阳性（抗核抗体的低滴度在健康人群中的流行率相当高，因此在低验前概率的人群中一个阳性的结果最可能是假阳性，并会启动一个以“排他”为主、以焦虑为代价的检查级联）、一项肿瘤标志的升高（器官而非肿瘤的标志与良性的原因，与它作为随访而非诊断工具的用途）、一次轻度的肝功异常（药物与酒精与脂肪肝与溶血与运动与炎症的时程，以及“是否重复与是否加做自身与病毒与影像”的路径）、以及一次异常的凝血筛查（采集的质量与抗凝药的存在与稀释的假象，先重复再升级）。“更多检查”与“更准的诊断”之间的曲线在阈值之前迅速变平：这就是为何检验的适当性（检验的适当性管理）是一项临床能力，也是为何每一项检验申请都应该回答“这个结果会不会改变我的处置”（不会则不做）。而实验室侧的能力建设同样重要：把“未标注与凝固与溶血”的拒收标准写清并公布、把关键的危急值（钾与钙与血小板与凝血与血气与心肌的标志）做成有时限的双向闭环、把重复的申请与“套餐”式的组合审视为可改进的模式、以及把解释性注释写入报告（把结果与配套的下一步一起给，被证明能减少误读与重复开单——尤其在肾功能与药物浓度与凝血的项目上）——[[clinical-skills/laboratory-tests]]、[[renal/filtration]]、[[pharmacology/dosing-principles]]。**
:::
::: definition 质量、误差与数字化病理 {#def-quality}
**病理的质量体系由若干被测量的环节支撑：内部的质量控制（同一张切片的不同层面与同一实验室不同时间的判读一致性）、室间的质量评价（外部机构发的切片与盲法的比对与“是否达到共识”的分级）、关键的差异分析（当病理的诊断改变了治疗或被临床推翻时的回顾，这是本专科最有价值的学习来源，因为它把“误差”归到流程而不是归到人）、双重阅片（在筛查的细胞学与乳腺癌的分级与切缘与淋巴结的微转移中，二次阅片显著提高灵敏度而代价是可承受的延迟）、以及参数的监测（固定与切片与染色的合格率和脱钙的时间与免疫组化的对照与抗体克隆与批号的追溯，因为染色失败与内部对照缺失会使一个阴性的结果不可解释）。误差的类型是可预期的：标本的混淆（历史上最严重的一类，多源于容器与标记与包埋盒与切片之间的错位，因此需要“同一时间只处理一例”与开盖时的再核对与条形码与随机抽检的比对）、识别的错误（把标签贴在错误的玻片上、或把外院的切片当作本科的）、以及解释的变异（在若干诊断上观察者间的差异确实大：不典型增生与原位与浸润的边界与若干软组织肿瘤的分类与前列腺与乳腺与子宫内膜的分级与消化道扁平病变的不典型判读，以及“临界类”的病变——这正是第二意见在病理中是常规而非冒犯的理由）；以及一个更隐蔽的来源：确认偏误（当申请单写着“癌”时，切片更容易被读成癌，这既是申请单信息重要的原因，也是“临床信息会引导（也可能误导）判读”的双刃）。数字化与人工智能改变了传播而非判断：切片扫描使远程的会诊与第二意见与归档与科研成为可能（并暴露了扫描的质量与对焦与颜色的差异与网络的瓶颈与授权的许可问题），而算法现在能做的是“计数与定位”（有丝分裂与细胞的密度与受体的量化与淋巴结转移的筛查与前列腺的分级）而非最终的诊断；采用的正确姿势是把它们当作“不会疲劳的第一道阅片”，并要求可解释的输出、验证的数据来源（切片染色与扫描仪的分布与人群）、性能退化的监测、责任的界定与对训练数据偏倚的意识；同时保存原件的可用性与可追溯的存储，因为在法律上“切片”仍是那份原始材料——[[pathology/cancer-diagnosis]]、[[clinical-skills/medical-imaging]]、[[clinical-skills/patient-safety]]。**
:::

::: example 冷冻切片的分歧 {#ex-frozen}
术中甲状腺的冷冻切片报“滤泡性病变，不能区分腺瘤与癌”；外科医师在台上要求“那就切掉一侧”；家属在门外等着一个答复；病理科与外科的既往合作愉快。
::: solution
**接受性差是病理学最诚实的一句话（[[#def-workflow]]、[[#def-quality]]、[[endocrine/thyroid]]）：解释为什么不能定：滤泡性肿瘤的分类依据是被膜与血管的侵犯，而这需要把被膜完整地、多层次地取样并在永久切片上看——冷冻的人工产物会掩盖核的细节与结构的边界，细胞学同样不能区分（这就是“提示滤泡性病变”的标本的标准结局，而不是病理医师的退缩）；因此术中的正确行为有两种：只取一侧并把最终的分类交给永久切片（术前与术后共同决定的补做取决于结果），或者（在临床与超声与细胞学高度可疑时）按可疑处理——但绝不能从一张冷冻切片上得到“癌”或“不是癌”的话。沟通的次序：先在电话里说清“我的报告能说什么、不能说什么、以及为什么”（电话是这一环节的正确工具，因为它允许提问，而报告纸上的“不能确定”会被读成无能），再确认外科的决定与患者术前同意书的范围（把扩大的切除在术中未经同意地实施，是伦理与法律的双重问题），并在正式报告中把术中咨询的记录写进去（谁、何时、说了什么）。患者的答复要由主刀给，且要与最终报告一致：用“这块标本的类型必须把整个包膜看完才能定性，这需要几天；大多数这类病变最后是良性的，但若显示侵犯，可能需要第二次手术，而我们已经把这一点纳入计划”这样的语言（绝对的比例要给本地的数字）。系统的一层：把这一类反复出现的“术中要求更多”的情形写成科室间的共识（哪些标本在冷冻上原则上不能定类：甲状腺与滤泡性乳腺病变与若干软组织的边界病变与骨与唾液腺与前列腺的分层），把它放在术前的同意与多学科的计划里，而不是留给一位在台上等待的医师临场判断；并把最终报告与术中咨询的差异作为质量指标记录——[[clinical-skills/communication]]、[[medical-ethics-law/consent-capacity]]、[[surgery/perioperative-care]]。**
:::

::: example 低危患者中阳性的抗核抗体 {#ex-ana}
一名34岁女性因“乏力三个月”被开了抗核抗体，结果1:160 斑点型；她无任何体征，血相与肾功能与尿与炎症标志正常；她在网上查到“红斑狼疮”并预约了风湿科。
::: solution
**验前概率与级联（[[#def-lab]]、[[#def-workflow]]、[[immunology/autoimmunity]]）：这个结果的数学：低滴度的抗核抗体在健康人群中相当常见（百分之若干至十几，取决于方法与人群的界值），因此在没有滑膜与皮肤与肾脏与血液学线索的情况下，一个1:160 的阳性更可能是一个假阳性（按贝叶斯：验前概率低时，即便特异度95%的试验，其阳性预测值也很低）；而一旦阳性，检查的级联（抗体谱与补体与尿与血与（有时）影像）几乎总能找到“轻微的异常”，把一次良性的乏力变成一个需要长期随访的“未分化”的标签，并带来氢氯喹与激素与产科与保险的实际后果——[[clinical-skills/laboratory-tests]]、[[epidemiology-ebm/diagnostic-tests]]。该做什么：一，向患者解释（这是这一步最重要也最常被跳过的部分）：用具体的比例说明“在没有其他证据时这个结果不能诊断也不能排除任何病”，并说明“为什么当初不该查”而不指责开单的同事（否则她会学到“医生的话不可信”而不是“检查有适应证”）；二，重新评估而不是继续排他（乏力的鉴别里，睡眠与情绪与甲状腺与铁与贫血与睡眠呼吸暂停与药物与酒精与血糖与妊娠与感染后状态与（少见的）自身免疫的阳性线索，比抗体滴度更有产出——把这些查一遍并按时间给出计划）；三，安全网（写出“哪些新症状值得回来：关节炎样的晨僵与光敏的皮疹与口腔溃疡与脱发的成片与雷诺与血栓与尿的泡沫与水肿”，并说明复查的条件而不是定期“看看滴度”，因为抗体的滴度在没有活动病时不预测什么）；四，取消级联（把已经预约的专科门诊取消或改为一次说明性的门诊，这在检验适当性的文献中被证明是有效且省钱的干预）——[[psychiatry/mood-disorders]]、[[musculoskeletal/connective-tissue-vasculitis]]。系统的做法：在检验申请的路径里加“适应证提示”（把抗核抗体的低滴度报告自动附上解释性的注释——多数实验室已能做，且注释能显著减少不必要的后续），并把“没有指征的自身抗体检测”作为可审计的指标在检验与初级照护的联合会议上讨论（针对模式而非个人）——[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]。**
:::

::: example 到达时被改过的报告 {#ex-report-change}
一份乳腺的病理报告在患者已被告知“良性”后，被修正为“原位癌”；修正是因为在免疫组化加做与重新取材后发现了原先未在取材层面的病变；外科与患者服务与病历都需处理。
::: solution
**报告的更正是一项临床操作（[[#def-workflow]]、[[#def-quality]]、[[clinical-skills/patient-safety]]）：第一步是保证正确的信息到达做决定的人：直接打电话给提出检查的医师并确认其理解（不是发一份新的电子文件等对方打开），同时确保患者通过一条明确的渠道被联系（谁打、何时打、由谁打、以及她需要什么样的支持：陪同的人与下一次门诊的时间与写下来的解释——“更正”这个词容易被听成“我们弄错了”，所以要说明“发现了更多”而不是掩盖“最初不知道”）；同时保留原来的报告与修正的记录并写明理由（这是审计所需，也是对患者诚实）。第二步是行动的清单：是否需要补的手术与前哨的评估（在原位癌的背景下按本地多学科的路径处理，且要考虑她已被告知的“良性”是否已经造成了延误）、是否需要补充影像与门诊的复评、是否已按本地程序进行多学科讨论（未讨论的病例是这类事件最常见的第二重失败）、以及后续的随访是否被登记。第三步是学习而不是追责：把这一例交给关键差异的会议（这是病理质量系统的核心仪式），并按误差的类型分析（是取样的代表性——未取到的层面、还是判读的变异——初次阅片被看成反应性的改变、还是报告的沟通——“提示性”的语言被读成“良性”）；同时检查相关的系统因素（取材的规范是否要求在同一标本上重复包埋与是否所有“良性”的诊断在特定部位都需二次阅片、报告的“结论”字段是否足够明确、以及免疫组化的加做是否被制度化）。第四是制度性义务：对患者的告知义务（在多数体系内，重要的诊断修正需要主动、及时、书面并附解释，且要记录已告知）、对本院的治理与（按严重度）对外的报告、以及对同行的通报（当误差的原因是可以共享的技术因素时，比如同一批抗体的失效）；把“没人因为这次修正而被惩罚”作为文化的一部分公开说明，否则下次修正会被延迟——而延迟的修正是这一环节中最危险的并发症——[[pathology/cancer-diagnosis]]、[[medical-ethics-law/professionalism-regulation]]、[[surgery/breast-endocrine-surgery]]。**
:::

::: example 没有背景的转诊单 {#ex-boring-form}
一份转诊的活检：申请单上写“胃黏膜，鉴别胃炎”；镜下见固有的腺体的减少与肠化的病灶与一处零星的、核浆比增高的上皮细胞；患者的年龄与用药与家族史与内镜所见与既往标本均未提供。
::: solution
**没有语境的标本是危险的标本（[[#def-workflow]]、[[#def-quality]]、[[gastrointestinal/gi-bleeding-cancer]]）：这份报告在缺信息时会朝两个错误的方向走：过度（把再生的与反应性的核增大误判为不典型，从而启动一个根除与监测与焦虑的程序）与不足（把一处真正的不典型增生读成“炎症相关”，因为它在没有语境时不可解释）——同样的组织在不同问题下会有不同的措辞，这就是申请单是生命线的原因。立刻要做的三件事：打电话给内镜的医师（一句话常常胜过一份表格：病变的部位与外观与为什么取这一块、有无既往的不典型、以及是否在同一部位重复取材），调阅既往的标本（同一名患者的既往切片是病理诊断中价值最高的单一资源，“与两年前相比无变化”是许多争议的答案，而这一资源在没有申请单信息时往往无法被检索），以及（在不典型确实存在但难定时）使用注释性的语言并给出下一步（“不足以诊断不典型增生；建议重新取材并在六周内复查胃镜”，或者要求加做与随访，并把理由写清），而不是含糊其辞地把决定丢给临床。报告的技术内容：肠化的分型与范围与幽门螺杆菌的可视化与（按本地做法）加做的染色与 OLGA 与 OLGIM 的分期，以及不典型增生的分级与其可重复性的坦白（胃的不典型增生的观察者间差异大，因此在若干体系内，“高度”的诊断需要第二阅片，而“临界”的病变最好在抗炎与治疗幽门螺杆菌之后重新取材再判——因为炎症本身使判读不可靠，这一步既减少过度诊断也减少漏诊）——[[gastrointestinal/bowel-disease]]、[[infectious-diseases/tuberculosis]]。系统的修复：把申请单的最低要求标准化（部位、侧别、内镜或影像所见、既往的同部位标本、临床的问题、以及月经与妊娠与用药的状态在特定器官的必要性），并在电子系统里做“信息不足则不予处理”的软性把关；建立“与既往标本的比较”作为报告的固定字段；把“因申请单信息不足而需要补充”的次数作为一种可改进的指标统计（它不是投诉，而是流程的输出）；以及为转诊的医师写一份“如何在标本上提出正确的问题”的说明（把“鉴别胃炎”换成“胃体的不规则溃疡，幽门螺杆菌阴性，需排除肿瘤性病变”，会让同一张切片给出完全不同的报告）——[[clinical-skills/records-handover]]、[[clinical-skills/communication]]、[[pathology/diagnostic-pathology]]。**

## 通向何处

肿瘤的诊断与分级分期见[[pathology/cancer-diagnosis]]与[[pathology/cancer-biology]]；检验项目的解读见[[clinical-skills/laboratory-tests]]；影像与病理的关系见[[clinical-skills/medical-imaging]]；分子与遗传的检测见[[genetics/genetic-testing]]与[[genetics/genomic-medicine]]；误差与学习系统见[[clinical-skills/patient-safety]]与[[clinical-skills/records-handover]]。

::: history
**诊断病理学的历史是“看得见”的技术史与“可信任”的制度史的合流。显微镜的改进使组织成为客体：施莱登与施旺的细胞学说（1838至1839年）与菲尔绍的《细胞病理学》（1858年）把疾病定位到细胞，并把“体液”的语言赶出诊室；同一位作者描述了炎症的白细胞游出与栓子与淀粉样与胶质瘤与白血病，几乎以一己之力奠定了若干亚专科。技术的三件套依次到位：石蜡的包埋与切片（1860年代以后）、苏木精与伊红染色（1870至1880年代，使组织的分区可辨）、以及诊断命名法的形成（癌的分级与分期从斯托克的乳腺分型到贝吉特的分类、再到肿瘤分期手册的国际语言）。细胞学的诞生是一步“从细胞而非结构判断”的赌博：巴氏的宫颈癌筛查（其1928年的早期报告被冷落了十余年，直到1941至1952年的美国全国性试验证明了死亡率下降），其后果是本领域第一次以人群为单位组织阅片，也第一次出现“筛查的假阴性”这类系统性误差。免疫与分子的一翼从科尔与库恩斯的凝集与沉淀与1941年Coons 的荧光标记的抗体开始，到酶标的免疫组化（1960至1970年代）与抗体的商品化与自动化（1990年代）与（1985年之后的）原位与荧光杂交与聚合酶链与测序，把诊断的问题从“是什么”扩展到“有没有可被靶向的改变”；这一转向也把本领域变成了治疗的守门人（受体的状态与基因的重排与错配的修复与微卫星与遗传的筛查与治疗相关），以及把“检测的性能”变成了监管的对象（体外的诊断的法规与实验室的认证与室间的评估）。最近的十年是数字与算法：切片的扫描（2010年代后在若干国家被国家服务采用）、人工智能的辅助（在有丝分裂的计数与转移的筛查与受体的量化与分级上被验证，并暴露了泛化与偏倚与责任的问题），以及由此而来的组织学之外的学科（数据的治理与软件的版本与性能的持续监测），其共同的问题是同一个古老的问题：这个结果能不能被信任到足以据此对一个人采取行动——[[pathology/cancer-diagnosis]]、[[genetics/genomic-medicine]]、[[clinical-skills/patient-safety]]。**
:::

::: summary
- 诊断的上限由取样决定：细胞学看细胞、组织学看结构，而“不能定类”往往是标本的性质而不是医师的能力。
- 申请单的临床问题是报告的一部分：没有语境的不典型既可能被过度诊断也可能被当作反应性而漏掉。
- 检验的诊断误差集中在分析前后：身份与采集与运输与转抄，而不是仪器；因此核对与拒收的规则是临床安全的一部分。
- 低验前概率的检查会产生假阳性的级联：申请前问“结果会改变处置吗”是最有效的质量管理。
- 关键差异的分析与二次阅片与参数的监测是病理质量的地基；把误差按类型而不是按人归类，才会带来改进。
- 数字化与人工智能改变的是传播与计数，而不是责任：可解释的算法、验证过的数据、原件的可及与法律的追溯缺一不可。
:::

## 练习

::: exercise 选择特殊染色 {level=1}
为下列五个问题各选一组染色并说明预期：肺的肉芽肿；不明原因的肝的铁沉积；疑似 Whipple 病的小肠；肾活检的基底膜与系膜；黑色素瘤与未分化癌的鉴别。
::: solution
**染色与问题的配对（[[#def-workflow]]、[[infectious-diseases/fever-sepsis]]、[[renal/tubular-function]]）：肉芽肿：抗酸（或荧光霉素类）与六胺银（或过碘酸雪夫加淀粉酶），因为结核与真菌必须在肉芽肿的解释之前被排除，且“干酪与不干酪”只说明形态不说明病因；同时留出组织做分子与培养（切片的敏感性有限，“阴性不能排除”要在报告里写明）。铁：普鲁士蓝（含铁血黄素的蓝色定量与分布：肝细胞与库普弗细胞与（遗传性血色病时的）门管区的模式），并解释“血红蛋白与输血与炎症”的不同分布，必要时接上铁的定量与遗传的检测。Whipple 病：过碘酸雪夫染色巨噬细胞中的阳性颗粒且耐淀粉酶，并结合聚合酶链的确认与鉴别（与鸟分枝杆菌在免疫抑制者中的相似，其抗酸阳性而雪夫阴性），并同时考虑其他引起泡沫巨噬细胞的病因。肾：六胺银或过碘酸雪夫看基底膜（钉突与双轨与厚的膜性病变）与马松三色看细胞与基质与系膜的增生与刚果红（偏振光下的苹果绿双折射）在怀疑淀粉样时，并配合免疫荧光（免疫球蛋白与补体与轻链的沉积模式，是狼疮与抗基底膜与IgA与轻链沉积病的分类基础）。黑色素对未分化癌：黑色素（S100 与 SOX10 与 HMB45 与 Melan-A，注意S100 的宽泛与 desmoplastic 变异中部分标志的丢失）对上角蛋白（广谱与低分子量）与上皮膜抗原与淋巴细胞共同抗原与肌源性标志与淋巴的标志，且原则是“用一个组合而不是单个抗体”，因为未分化肿瘤的表型可以异常表达；并保留足够的组织做分子（在真正未分化的肿瘤中用于定位来源）——[[pathology/cancer-diagnosis]]、[[pathology/cancer-biology]]、[[musculoskeletal/skin-cancer]]。**
:::

::: exercise 读一份骨髓的报告 {level=2}
一份报告：“增生活跃，红系与粒系比例倒置，可见小的巨核细胞簇与淋幼细胞增多（12%），未见明确的纤维组织增多。”临床怀疑骨髓增生异常综合征。请说明你还需要什么。
::: solution
**从描述到分类（[[#def-workflow]]、[[blood/haematopoiesis]]、[[blood/leukaemia]]）：形态是入口而不是答案。需要的是：一，计数的原始数据（有核细胞的比例与各类细胞的百分数与原始细胞的确切百分数，因为20%这一阈值决定急性白血病与骨髓增生异常的分界，而“未见明确”这样的措辞无法用于分类）；二，发育异常的定位与程度（一系还是多系与病态的具体形态，并明确排除可逆的原因：维生素B12 与叶酸与铜的缺乏与病毒与药物与酒精与最近的生长因子，这些都能模拟病态造血）；三，免疫分型（流式的细胞表面标志以量化原始细胞并判断其表型，并识别异常的成熟模式与浆样树突的增多）；四，遗传学（常规核型与荧光原位杂交的常见缺失与易位，以及染色体的核型质量与细胞数；并加做髓系的基因面板，因为其中的若干突变改变预后与治疗的选择并影响移植与去甲基化治疗的时机）；五，纤维化的分级（网状纤维与胶原的染色与（必要时）活检的切片方向，因为“未见明确增多”若来自一张方向不理想的切片则不足以分级）；六，与既往的标本与外周血对比（病程的方向比单次切片更有解释力）；以及报告的语言（把骨髓增生异常与“待排”的分层写清，说明需要什么资料才能分类，并把不确定的部分写成建议而不是沉默）——[[blood/haematopoiesis]]。临床的一层：把报告的局限性告诉转诊者（若临床仍不放心，重复的活检与血液科的随访与分子的结果一起看比一次“不典型”的活检更有价值），并解释为什么这份报告不是“正常”（“增生活跃”在贫血的背景下本身是线索）——[[clinical-skills/communication]]、[[clinical-skills/records-handover]]。**
:::

::: exercise 审计一个周转时间的问题 {level=2}
细胞学的常规报告的周转从中位4天恶化到11天；积压集中在下午采集的标本；两名细胞学技师休产假；病理医师的空闲阅片时间被会议占满。请审计并给出改进的顺序。
::: solution
**把周转当作系统的输出（[[#def-quality]]、[[#def-workflow]]、[[public-health/screening]]）：诊断的分解：瓶颈在制片与初筛（下午的标本在次日晨才制片，说明制片的班次与接收的时间不匹配，而不是“人不够”这么简单），以及在人员缺位时没有替代的产能（休产假是可预期的事件，因此“可预期的缺位”应当被设计进流程而不是被临时应对）。改进按有效性与可逆性排：一，削掉不产生诊断价值的步骤（把“正常的”阴性筛查从双读改为基于风险的双读、把重复的取材与制片的环节合并、并让“拒收”的标准更清楚以减少重做），这一条常被忽略，因为它要求承认某些惯例是为过去而存在；二，重新排班以匹配到达（下午的接收窗口加一名制片员或把制片自动化到与接收同一时间，以及把细胞学的制片放到内镜中心与门诊当场完成，被证明能显著缩短周转并提高质量）；三，保护阅片的时间（把病理医师从非必要的会议与行政中释放出来，按“每小时可读的例数与需要的例数”排一个可见的产能表，因为积压是产能问题而不是动机问题）；四，用外部与技术的冗余（远程的阅片与第二线的签约与扫描后的分派，使积压被“转移”而不是“等待”，并要求远程的切片质量的可验证）；五，人工智能的第一道筛查（把明显阴性的切片优先排序，让人的时间集中在可疑者，但要以经过本地验证为前提并保留人的最终判断）。监测的指标：周转的分布与尾部（第90与第95百分位，而不是平均数）、不满意标本的比例、复检后的诊断改变率、以及（在筛查中）间期癌的比率——因为周转的改善若以质量下降为代价，会以另一种形式回来；同时向申请端公开周转与积压，使“何时能拿到结果”成为可预期的信息而不是靠打电话催——[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]。**
:::

::: exercise 就面向消费者的肿瘤风险基因检测给出建议 {level=3}
一名52岁、无肿瘤家族史的女性做了一家公司的唾液检测，报告显示 BRCA1 的一个“意义未明的变异”以及“多基因风险评分在她所在的百分位的第78”；她要求做预防性的双侧乳腺切除。
::: solution
**消费级基因结果的正确处理（[[#def-lab]]、[[#def-quality]]、[[genetics/genetic-testing]]）：先把两条信息的证据分量说清。意义未明的变异不是风险因素：它在人群中的出现率使多数此类变异最终被重分类为良性，而商业实验室的分类常基于有限的家系与缺乏功能的证据；临床的规则是“不因意义未明的变异改变处置”（这是国际的共识），且不应据它以手术或加强筛查。多基因风险评分是群体层面的分布而非个体的诊断：它在训练的人群（以欧洲祖先为主）中最有判别力，在其他祖先中的效度较低，且在临床上目前不改变指南的筛查建议；把它当作“她属于中上风险”的确定信息来沟通是错误的。此外，消费级的平台常为测序的补全与验证而把样本转给临床实验室，但位点的覆盖与验证的标准与遗传咨询的缺失意味着：阳性的、可行动的结果必须在一个有资质的临床实验室中被确认后才可用于医疗决定（这是一个具体、可执行的建议，也保护她不被一个假阳性推向手术）——[[clinical-skills/clinical-reasoning]]。对她的做法：一，把她真正关心的问题取出来（她怕的是什么？家族中没有肿瘤史却被检查驱动，说明动机多半是焦虑而非流行病学），并给出与她的实际风险相称的答案（用她的年龄与乳腺的密度与生育与激素史与体重的常规风险评估，并明确她的筛查应该做什么）。二，把这份报告的每一条按其证据等级重新解释（不用行话，不用“这只是研究性的”这种被听成“不重要”的词；给出绝对的风险而不是百分位）。三，把“预防性切除”这一请求当作一次需要评估与时间的决定而不是一个可以立即满足或拒绝的申请：明确在她的情况下手术的证据不足（手术的收益需要致病的生殖系变异或极强的家族史），并提供替代的焦虑的处理路径（遗传咨询的一次门诊与乳腺的专科评估与风险的重新沟通与心理的支持）。四，解释隐私与数据（她的数据在什么条件下可能被出售或用于研究与保险与雇佣的歧视在不同法域下的保护不同，且“删除数据”不等于从已共享的下游消失），以及她可能希望知道的“次要发现”的取舍（若她希望知道可干预的变异，应在咨询下由临床的服务做，而不是靠消费级平台的默认）。五，把这件事放进公平的语境：这类服务的营销让许多人以为自己“知道了风险”，而真正的遗传风险评估的等待很长，这种不对等会持续制造临床的负担——[[genetics/genetic-testing]]、[[medical-ethics-law/confidentiality]]、[[public-health/determinants-inequalities]]。**

::: exercise 决定冷冻切片怎么办 {level=1}
就下列四种情形各给出“做或不做冷冻”的决定并说明理由：乳腺的可疑肿块；肺的孤立结节；卵巢的肿物伴腹腔的结节；以及一处骨的溶骨病变。
::: solution
**冷冻的适应证由“术中能改变什么”决定（[[#def-workflow]]、[[pathology/cancer-diagnosis]]、[[surgery/perioperative-care]]）：乳腺的可疑肿块：可以做，但要说清其局限（良性者无需扩大；恶性者常常需要术后的完整信息以决定前哨与切除的范围，因此阳性时的处置应事先与患者约定）；对以影像为线索的微小病变，若未做定位则冷冻可能取不到病灶；细胞学的“滤泡性病变”与“不能定类”要提前告知不能定性。肺的孤立结节：有价值（决定是楔形切除后等待永久切片还是直接解剖性切除与淋巴结的取样、并确认切缘与（在多发结节时）是否同源），但需要标本的质量与时间，且磨玻璃的病变在冷冻上的判读不可靠（浸润成分的判断应留给永久的全面取材），因此术前与治疗后的评估都要按“浸润成分需全面取材”来沟通。卵巢的肿物伴腹腔的结节：这是冷冻最有价值的场景之一（决定是减瘤的探查还是先活检并按分期处理、并区分生殖细胞的与上皮的与转移的病变、以及黏液性病变的来源），因此需要有经验的人员在场与足够取材的时间与（必要时）免疫组化的加做；同时要说清假阴性与“不能定类”的可能（腹膜的黏液病变与边界性的肿瘤与淋巴瘤不适合在冷冻上分型）。骨的溶骨病变：通常不做（分类需要脱钙与（常有的）分子与形态学的组合，而冷冻会消耗有限的组织并因脱钙的缺失而使判读失真），正确的做法是足够的活检组织与（在怀疑淋巴瘤与感染时的新鲜留样与培养与流式）与术前与放射与骨科的共同规划（穿刺道的路径必须由将做手术的团队设计，因为一个位置不当的穿刺道会改变截肢的平面）——[[musculoskeletal/bones-joints]]、[[musculoskeletal/fractures]]、[[obstetrics-gynaecology/gynaecological-cancer]]。**

::: exercise 解读一组肿瘤标志 {level=1}
一名健康男性在体检中查到前列腺特异性抗原5.8、癌胚抗原轻度升高、甲胎蛋白正常、糖类抗原19-9 轻度升高。请解释每一项并给出处置。
::: solution
**器官的标志而非肿瘤的标志（[[#def-lab]]、[[pathology/cancer-diagnosis]]、[[gastrointestinal/liver-function]]）：前列腺特异性抗原由前列腺的上皮（含良性增生与前列腺炎）产生，5.8 在此年龄最常见的解释是增生，且操作与射精与尿潴留与感染都会升高；处置是复查（避开上述因素并在抗炎后）并结合直肠与体积与（现代的）影像与（在专科路径下）先行磁共振再决定活检，而不是把一次的值当作诊断——[[clinical-skills/physical-examination]]。癌胚抗原对结直肠与其他腺癌是随访的工具而非诊断的工具：吸烟与肝炎与炎症性肠病与肾功能不全与良性肝胆病都能轻度升高，且在没有已知肿瘤的人群中一个轻度的升高不应引向“全身搜索”（其产出的偶然发现的害处大于收益）；处置是按症状的评估（便血与排便习惯与体重与贫血的筛查）与结直肠筛查的资格，而不是影像套餐。糖类抗原19-9 与胰腺与胆道相关，但在胆汁淤积与胆管炎与囊肿与（少见的）良性肺病中显著升高，且在 Lewis 抗原阴性的人中假性偏低；因此若有黄疸与腹痛与体重下降则做胰腺与胆道的影像，若无症状则复查并解释；同时把“胆红素与碱性磷酸酶”的图形先读出来（有梗阻的证据与没有是两回事）。甲胎蛋白正常不排除肝细胞癌（约三分之一的病例不升高），因此对肝硬化的人群筛查靠超声而不是标志——[[gastrointestinal/liver-disease]]。总原则：这三类检查的合理用途都是“已确诊者的随访”或“高危人群的特定筛查”，而不是无症状人群的普查；把它们解释给患者的语言是“这三项不能告诉我你有没有癌，但有两项需要按症状复查”——[[public-health/screening]]、[[clinical-skills/communication]]。**

::: exercise 主持一次不一致的会议 {level=2}
一次临床与病理的对照发现：内镜诊断为“高度可疑恶性”的溃疡活检三次为“炎症与肉芽”；手术切除的标本最终显示浸润性癌伴明显的间质反应。请主持会议并输出行动。
::: solution
**不一致会议的目的不是找责任人（[[#def-quality]]、[[#def-workflow]]、[[gastrointestinal/gi-bleeding-cancer]]）：先把事实按时间排列（每次活检的部位与块数与内镜的照片与固定的质量与取材是否覆盖溃疡的底部与边缘与镜下的描述），再问可被改进的问题而不是“是否漏诊”：取样是否代表了病变（溃疡型胃癌可以在边缘而不显示浸润、而表浅的活检只到黏膜的炎症带）；取材的方案是否要求“每一处溃疡的活检全部包埋并多层面切片”；判读时是否使用了加做的染色与是否考虑了“在炎症背景中的印戒细胞（其可以几乎没有核的非典型与细胞角蛋白的免疫组化才暴露）”；临床的怀疑是否被传递到申请单上（“高度可疑恶性”的申请单会让病理医师加做与多切，而“鉴别胃炎”则不会——这就是为什么这类会议的产出常常是申请单的标准而不是判读的技术）。同时把这一类病变的共同点整理出来（溃疡型的胃癌与硬性乳腺癌与炎症型乳腺癌与前列腺与膀胱的原位与浅表的肌层浸润与皮肤转移性黑色素瘤与结直肠的（在炎症性肠病背景中的）不典型，其共同的机制是“有限的取样加背景的重叠”，并因此需要共同的防护：可疑的溃疡全部取材、必要时加做细胞角蛋白、以及在临床与病理不一致时立刻重新取材而不是“随访”）——[[clinical-skills/clinical-reasoning]]。输出的行动要具体到人与时限：修改取材的方案（写明哪些部位与哪些形态要求多层面与加做）、修订内镜的记录（照片与取材的编号的对应，使“取哪块”能被追溯）、约定“临床高度可疑而病理阴性”时的强制的复议路径（由内镜与病理共同复阅并立即决定重复取材，而不是让患者在六周后自己回来）、把这一例写成科内的教学并在网络的范围内共享（同类设备的漏诊常常不止一处）、以及六周后回顾这些行动是否发生并统计再发的次数。会议的语言要一致地指向系统：“我们没有让这张切片有机会被看到”比“他没有看到”更能带来改变——[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]。**

::: exercise 引入一台病理的人工智能助手 {level=3}
你的实验室拟引入一个用于前列腺穿刺的算法助手（自动的分级与病灶的定位与优先排序）。请给出引入的方案：证据、验证、流程、法律、伦理与退出。
::: solution
**人工智能在病理中的引入（[[#def-quality]]、[[#def-workflow]]、[[clinical-skills/patient-safety]]）：证据的一层：要求供应商提供前瞻性的、多中心的、以及在你们自己要用的染色与扫描仪与人群上的性能（灵敏度与特异度与分级的加权一致性与按病灶大小与位置的分布），并接受“在公开数据集上的性能”不能外推这一事实（切片的染色强度与扫描仪的色差与人群的构成都会改变结果）；并规定性能的监测计划（每季度的抽样复核与分层的性能与漂移的报警的阈值），因为算法会因上游的改变而退化——[[epidemiology-ebm/critical-appraisal]]。流程的一层：明确它是“第一道的排序与提示”而不是判读者（诊断的责任在医师，因此工作流上不得出现“算法未标记即不看”的空间）；对前列腺的分级采用双读（在有癌的切片上的分级的一致性是临床决策的核心，而算法之间的分级差异可以改变治疗），并把“算法的提示被医师否决”的情况记录下来（这是最有价值的学习数据，也是性能的实地指标）。法律与治理的一层：软件的分类与版本的控制与变更的验证与网络安全（扫描的图像属于患者，且需要完整的数据保护的影响评估与合法的加工基础与对数据主体权利的响应）；责任的界定（供应商与院方与医师的合同边界，以及在发生不良事件时的调查的可及性）；以及对训练数据与偏倚的声明与可解释性（输出附带病灶的位置与置信度而不是一个黑箱的分数，使“为什么它这么认为”可被核查）。伦理与知情的一层：是否在报告中提及算法的参与（多数共识倾向于向患者说明有软件辅助而不隐藏），以及如果算法改变了分级，患者是否应该被告知（这与任何辅助工具一样：改变结论者必须可追溯）；同时避免“自动化的偏见”（年轻与健康焦虑的患者可能被过度筛查，而依赖算法的低资源单位可能漏掉不典型的形态）。退出与失败预案：定义在什么情况下停用（性能低于阈值或上游设备改变或数据出现漂移）、停用后如何维持产能（人工的双读会立即成为瓶颈，需要在引入时就规划人力）、以及保留原始的数字切片与决策的日志（使事后的复盘可能）。最后一条是最容易被忽略的：把引入的成本算全（扫描与存储与网络的投入与技师的时间与持续的验证与许可的费用），并把它与“周转时间与漏诊率”的实际改善一起提交给决策者；因为一台只做排序而没人有权改的算法，其价值主要是让医师更快——[[public-health/health-systems-economics]]、[[medical-ethics-law/confidentiality]]、[[clinical-skills/medical-imaging]]。**
