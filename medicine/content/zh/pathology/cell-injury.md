细胞损伤是每一章疾病的第一页：**细胞对压力的反应只有很少几种命运——适应、可逆的损伤、以凋亡或坏死的死亡、或安静的沉积——而临床所见的症状与体征与化验的异常，几乎都是这些命运在组织尺度上的投影。**本章覆盖损伤的通路（三磷酸腺苷的耗竭与线粒体与钙与氧自由基与膜与蛋白的稳态与（作为最终共同通路的）线粒体的通透性）、死亡的形态（凋亡与坏死与（在若干类型中的）坏死性凋亡与铁死亡与（在感染中的）细胞焦亡与自噬的相关死亡）、以及适应与沉积（肥大与增生与化生与发育不全与（在内含物与色素与若干蛋白与脂质与钙与尿酸盐与（在输血依赖者的）铁）与它们的临床后果）。

## 细胞为何生病

::: definition 损伤的级联 {#def-injury}
**缺氧与缺血是所有损伤中最普遍的起点，其通路是可背诵的因果链：氧的不足使氧化磷酸化减慢，三磷酸腺苷下降，钠钾泵的效率降低，细胞内积钠与积水（细胞的水变性，在显微镜下是胞浆的淡染与肿胀与（在重者）膜的空泡化），核糖体从内质网脱落使蛋白的合成减少，无氧的糖酵解被代偿性上调但产生乳酸使胞内的酸碱度下降；同时钙从内质网漏出并进入胞浆，激活若干的酶（磷脂酶破坏膜、蛋白酶消化蛋白、内切酶切开脱氧核糖核酸），而线粒体的膜在损伤与钙与酸碱度的组合下形成非特异性的通透孔（其蛋白的组分即通透性转换孔），使膜电位崩溃并释放细胞色素C（这是凋亡的启动步骤之一）——而这一孔道的形成常是“不可逆”的分界（[[pathology/acute-inflammation]]、[[cardiovascular/coronary-artery-disease]]）。自由基的一面：氧的不完全还原与铁的催化（芬顿反应）产生羟基，攻击膜的磷脂（发生过氧化链式反应并破坏膜的完整性）、蛋白（使巯基氧化并错误折叠）与脱氧核糖核酸（单链的断裂与碱基的改变，包括8-羟基脱氧鸟苷这一被用作氧化损伤标志的产物）；防御是酶与非酶的一组（超氧化物歧化酶把超氧转成过氧化氢并被过氧化氢酶与谷胱甘肽的过氧化物酶清除，而还原型的谷胱甘肽与维生素E与维生素C与（在膜上中断链式反应的）类胡萝卜素提供化学的缓冲），而谷胱甘肽的耗竭（在乙酰氨基酚的中毒中被亲代谢物耗光，或在营养不良与脓毒症中被耗尽）是对氧与药物毒性易感的共同机制（[[pharmacology/metabolism-excretion]]、[[emergency-critical-care/poisoning]]）。蛋白的稳态是第三个战场：错误折叠的蛋白被分子伴侣识别并被泛素的系统降解或被自噬清除，而当合成的速率与（在内质网的）折叠的能力与清除的通路失配时，未折叠的蛋白反应被激活（其短期目的是减少翻译与增加伴侣与增加降解，而持续的激活转向凋亡），这一机制解释了若干沉积性疾病（淀粉样与若干的神经退行的疾病与（在肾小管的）轻链的病与（在肝的）α1 抗胰蛋白酶的缺失的聚合）与若干药物的细胞毒性——[[pathology/cancer-biology]]、[[nervous-system/dementia-neurodegeneration]]、[[renal/tubular-function]]。**
:::
::: definition 死亡的形态学 {#def-death}
**凋亡与坏死的区别在膜的行为与后果：凋亡是程序化的、耗能的、“把自己收好”的过程（细胞皱缩与胞浆的嗜酸与染色质的边集与（由半胱天冬酶切割的）胞骨架的解构与膜的出泡与（被磷脂酰丝氨酸外翻标记的）凋亡小体被邻近的细胞与巨噬细胞以胞葬作用吞噬，因此内容物不外泄，故几乎没有炎症）；它的两条上游通路（死亡的受体的通路（肿瘤的坏死因子与Fas 与其配体）与线粒体的通路（细胞色素C 与Apaf-1 与半胱天冬酶-9 的复合体））汇聚于效应的一半胱天冬酶，而其调控（Bcl-2 家族的促凋亡与抗凋亡成员的平衡）是若干疾病与药物（在若干血液肿瘤中被靶向）的靶点；凋亡在生理上是常态（胚胎的塑形与月经周期的退化与（在淋巴的）选择的排除自身反应者与（在若干组织中的）每天的数量），其异常增多见于（在获得性免疫缺陷与若干衰竭状态中的）丢失与（在肿瘤中的）受抑——[[immunology/adaptive-responses]]、[[pathology/cancer-biology]]。坏死是被动的、不耗能的、“泄漏”的过程：肿胀与膜的破裂与内容物的释放与（因此）炎症；它的形态按机制与组织而不同（凝固性（在缺血的大多数实质器官中，结构的轮廓被保留数日）与液化性（在脑与（在化脓性感染的）脓）与干酪样（在结核与若干真菌的）与脂肪的（在胰腺的与（在创伤的）皮下）与纤维素样的（在血管壁与（在重症的）免疫复合物）），并且“坏死的凋亡样”与（在若干发育与肿瘤中的）混合的形态存在。第三类被分子定义：坏死性凋亡（由相互作用蛋白的激酶3 与（在效应端的）混合谱系的激酶结构域样蛋白执行，是在 caspase-8 被抑制时细胞对坏死因子的一种“备份”死亡，与若干的缺血与炎症与感染的疾病有关）、铁死亡（由铁的依赖的脂质过氧化驱动，且被谷胱甘肽的过氧化物酶4 限制，在肾的缺血与若干肿瘤的脆弱性中被注意到）、细胞焦亡（由炎症小体的半胱天冬酶-1 与gasdermin 的孔道执行，伴随白细胞介素1 与18 的释放，是有强烈炎症后果的死亡，在感染与（在若干的晶体与代谢的）炎症中重要）与自噬相关的死亡（自噬在小量时是保护，在过度时与若干的药物与饥饿的状态中可能致死）——[[immunology/innate-immunity]]、[[renal/acute-kidney-injury]]、[[pathology/acute-inflammation]]。临床的意义在“以什么顺序发生”与“能恢复吗”：凋亡通常不引起炎症因而无体征，而坏死必然引起炎症（这就是为何“细胞的死亡”有时发热有时安静）；而不可逆的判定（膜的功能的完全丧失与线粒体的不能恢复与脱氧核糖核酸的降解）意味着任何之后的“治疗”只能作用于边缘的、仍在可逆与不可逆之间的组织，即临床上的危险区——[[cardiovascular/coronary-artery-disease]]、[[nervous-system/stroke]]、[[emergency-critical-care/resuscitation]]。**
:::

## 适应与沉积

::: definition 从肥大到含铁血黄素 {#def-adaptation}
**适应是细胞在持续的压力下改变体积、数量、类型或内容物以求生存：肥大（体积增大，靠蛋白的合成增加，在不能分裂的细胞如心肌是唯一的方式，其机制是机械的感应与生长因子的通路与胚胎基因程序的重启；生理性的在骨骼肌与妊娠的子宫，病理性的在压力（高血压与瓣膜的狭窄）与（少见的）容量的负荷，其结局取决于是否伴随血供与间质的匹配——向心性肥厚的缺血与（在若干心肌病中的）纤维化与（在失代偿后的）扩张与心衰）与增生数量增多，靠干细胞的与已分化细胞的分裂，生理性的在激素依赖的（乳腺与子宫内膜）与代偿性的（肝的部分切除后的再生与（在溶血时的）红系的增生与（在缺氧时的）红系的生成），其病理的一面是在生长因子与内分泌的驱动下的过多（子宫内膜的增生与（在若干的）息肉与（在皮肤的）疣与（在内分泌的）增生），并且必须区分对生理性刺激的反应与肿瘤性的克隆增殖，因为若干的增生状态确实是不典型与癌的通道——[[endocrine/hypothalamus-pituitary]]、[[pathology/cancer-biology]]。化生是一种已分化的细胞类型被另一种替换（在组织上更耐受该压力但功能上更“降级”），几乎总是发生在柱状或立方上皮的慢性刺激下：呼吸道的鳞状化生（吸烟与慢性刺激，且有脱氧核糖核酸甲基化与若干通路的改变，因此在戒烟后可以部分逆转，但在持续者是癌前病变的第一步）、巴雷特（食管的鳞状对柱状与杯状细胞的替换，是酸与胆汁与（在若干的）幽门螺杆菌的产物的结果并有腺癌的风险）、（在胃的）肠化（与尾型同源盒转录因子2 与黏液表型的转换）、（在胰与（在胆道的）与（在膀胱的）鳞状与腺性的化生与（在结缔组织的）骨化性化生（在我的骨性发育不全与（在创伤后的）骨化）与（在关节的）软骨的）；化生本身不是癌，而是“同一种压力同时造成了可逆的适应与不可逆的突变”的共存证据——[[gastrointestinal/oesophagus-stomach]]、[[respiratory/asthma-copd]]。萎缩（体积与数量的减少，靠自噬与蛋白的降解与干细胞的耗竭）与（在其原因被去除后的）可逆性与（在若干情形中的）化生与癌变的风险相关（胃体的萎缩与肠化与（在雌激素缺乏后的）子宫内膜与（在失神经与制动后的）骨骼肌与（在绝经后的）乳腺与（在慢性胰的）胰腺）；而沉积是“适应失败或负荷超限”的语言：细胞的水变性（钠与水的急性积聚）与脂肪的变性（在肝最常见，机制是极低的密度脂蛋白的分泌障碍与脂肪酸的氧化减少与（在酒精的）氧化还原的改变与（在若干药物与营养不良与肠外的营养与（在肥胖与糖尿病中的）胰岛素的抵抗）的脂肪的流入增加，其可逆性依赖于原因，而其临床的严重性在于“单纯脂肪肝与脂肪性肝炎与纤维化”的分界）与糖原与（在若干的代谢贮积病中的）黏多糖与鞘脂与（在肾小管的）蛋白的重新吸收的小滴与（在内分泌的）胶样的小滴与（在肝的）透明的小滴（酒精的透明小体是角蛋白的聚合与（在α1 抗胰蛋白酶缺乏中的）错折叠的聚合）与胆固醇的结晶与（在关节与肾与皮下的）尿酸盐；色素的沉积包括含铁血黄素铁的去铁蛋白的聚合，在输血依赖的地中海贫血与（在慢性溶血与反复出血的）与（在若干的肝与心与内分泌的铁过载的疾病中的），其危害在于铁催化的自由基反应导致器官的纤维化与（在内分泌的）功能的减退与（在心的）心肌病，而铁的螯合治疗是“沉积本身可被治疗”的少数疾病之一——[[blood/haemoglobin-disorders]]、[[gastrointestinal/liver-disease]]、[[pharmacology/adverse-reactions]]。**
:::

::: example 肌钙蛋白与波峰 {#ex-infarct-timeline}
一名胸痛五小时的患者，肌钙蛋白明显升高并在第三小时到峰值；急诊给了溶栓；问：从组织学看，“再通”在挽救什么？
::: solution
**危险区的算术（[[#def-death]]、[[#def-injury]]、[[cardiovascular/coronary-artery-disease]]）：心肌在完全的缺血下约二十至四十分钟开始不可逆的坏死，且坏死从心内膜下（此处室的壁内压最高、灌注梯度最大）向心外膜呈“波峰”式推进，因此在数小时内同一块心肌存在三个区域：已坏死的中心、仍在可逆与不可逆之间的危险区（其被再灌注挽救的比例几乎完全决定最终的射血分数与心衰与死亡）、以及远端的缺血但存活的肌。溶栓与（更好的）急诊的介入治疗的价值不在于让“已经坏死的”恢复，而在于在波峰到达心外膜之前中断它——这就是“时间就是心肌”的解剖学含义，也是为什么症状到球囊的分钟数被用作质量的指标（[[emergency-critical-care/resuscitation]]、[[cardiovascular/coronary-artery-disease]]）。肌钙蛋白的曲线要说清两件事：它是膜失败的下游（肌钙蛋白的释放需要数小时才升到可测，因此过早的采样不能排除；而其峰值与曲线下面积与坏死的体积相关但不精确到足以替代影像与临床），并且它的时相解释了形态学的时间表（六小时内的改变轻微，四至十二小时可见水肿与早期的凝固与（在若干纤维的）波浪状的心肌纤维，十二至二十四小时最清楚，一到三日凝坏的边缘带炎症，三至七日边缘的肉芽，数周后瘢痕——而“七日”之所以重要，是因为此时的心壁最软，是（在梗死的边缘的）破裂与（在心室游离壁与室间隔与乳头肌的）机械并发症与（在抗凝与（在旧时的）溶栓后的）心脏压塞的时段）——[[surgery/acute-abdomen]]。临床的推论：再灌注后不必因酶高而恐慌（酶峰是再灌注的证据之一），但要监测再灌注的心律与（在若干病例中的）无复流（微血管的损伤与（在其中的）中性粒与（在其中的）氧自由基的爆发是再灌注损伤的本质，这也是为什么“再通晚了”可能弊大于利的争议存在，且为什么铁的依赖的反应在动物中可被抑制而临床上尚无成熟的药物）；同时记住危险区是可被后期挽救的：存活的但顿抑与冬眠的心肌在血运重建后可以恢复，这正是（在慢性的心衰与（在有存活心肌的证据时的）血运重建的）影像评估的意义（超声的负荷与磁共振的活性与（在若干中心的）正电子的代谢）——[[clinical-skills/medical-imaging]]、[[cardiovascular/valve-congenital-disease]]。**
:::

::: example 吸烟者的支气管 {#ex-metaplasia}
一名58岁吸烟者（四十年每日二十支）因咯血做支气管镜，活检见假复层的纤毛柱状上皮被鳞状上皮取代，伴有基底细胞的增生与轻度的核的非典型，无浸润。
::: solution
**把化生与不典型增生放在同一条压力曲线上（[[#def-adaptation]]、[[#def-death]]、[[respiratory/lung-cancer-pleura]]）：鳞状化生是适应：柱状上皮在焦油与（在烟气中的）氧化剂与（在其中的）颗粒的持续刺激下，被更耐受但功能更差的鳞状上皮替换（后果本身即症状的来源：纤毛的清除丧失使黏液滞留与（在晨间的）咳嗽与感染的易感，而杯状细胞的化生与黏液的分泌增加参与慢性支气管炎的表型）。真正改变风险的不是化生而是伴随的分子事件：吸烟使基底细胞与（在支气管的）分泌细胞累积脱氧核糖核酸的加合物与（若干通路的）突变（肿瘤蛋白53 与（若干的）癌基因与去甲基化的改变），而“轻度的核的非典型与基底细胞的增生”处在可逆的适应与癌前病变的边界上，因此需要按分级报告（不典型增生的分级与原位与浸润的分界在呼吸道的判读依赖结构的完整，故支气管的活检常不足以定级，需要（在咯血的背景下）重复的定位的活检与（在若干体系中的）自体荧光与窄带的成像）。要向她解释的两件事：一，“这不是癌，但它说明你的气道已经为了耐受烟气而改变了结构”；二，戒烟的实际意义是可测量的（化生的部分可以在数月至数年的戒烟后逆转，不典型增生的低级别者亦然，而风险按戒烟的年数衰减但不会归零——这一句要说得诚实：不戒烟则风险按每年累积，戒烟则前十年的收益最大）。临床的下一步：咯血本身需要按病因查（支气管的癌与（在吸烟者中的）结核与（在慢性感染后的）支气管扩张与（在若干药物与凝血障碍的）出血，且“影像正常加镜下化生”不等于排除了远处的病灶），并做肺功能的评估与（按本地的标准）低剂量的计算机断层筛查的资格——[[respiratory/respiratory-infections]]、[[respiratory/control-breathing-tests]]、[[public-health/screening]]。系统的收获：这个病例是“一级与二级预防同时适用”的范例（戒烟是病因的治疗，筛查是早期发现的路径，而两者都由同一次门诊可以同时启动），也说明为何病理的语言（化生与不典型增生与原位与浸润）应当被翻译成患者能行动的话（“哪一步是可逆的、哪一步不可逆、以及现在做什么能改变轨迹”）——[[clinical-skills/communication]]、[[public-health/prevention-promotion]]。**
:::

::: example 长期饮酒者的肝 {#ex-steatosis}
一名44岁每日饮白酒者，天冬氨酸的氨基转移酶92与丙氨酸的氨基转移酶45（比例大于2）与γ-谷氨酰转移酶升高与平均的红细胞体积升高；超声见回声增强；体重指数29；乙肝的表面抗原阴性。
::: solution
**脂肪变性的机制与它的两个岔路（[[#def-adaptation]]、[[#def-injury]]、[[gastrointestinal/liver-disease]]）：为什么是脂肪：乙醇的氧化改变肝细胞的氧化还原比（还原型的烟酰胺腺嘌呤二核苷酸增多），抑制脂肪酸的氧化并促进其合成，同时（在乙醇的诱导下）细胞色素P450 2E1 产生氧自由基并使细胞的信号转向炎症；加上（在饮酒者中的）外周的脂肪的动员与（在营养不良与（在肥胖与糖尿病中的）胰岛素抵抗时的）脂肪的流入，结果是甘油三酯在胞浆形成大小不等的空泡（在重者把核挤到一边，形似“印戒”但要与黏液的区分）。为什么这两个酶这样比：酒精性时天冬氨酸的氨基转移酶常高于丙氨酸（因丙氨酸的底物在饮酒者中不足与（在线粒体的）天冬氨酸酶的释放与（在若干病例中的）吡哆醇的缺乏），而γ-谷氨酰转移酶与平均的红细胞体积是乙醇暴露的两条间接线索（都不特异，也都不敏感，且都可被其他原因解释——因此它们适合做监测而不是诊断）。关键的岔路：多数脂肪变性是可逆的（戒酒数周内脂肪的沉积明显减少），但若干比例者进入脂肪性肝炎（炎症与（在肝细胞周围的）纤维与（在若干的） Mallory-Denk 的小体与（在重者）胆红素与白蛋白与凝血酶原时间的失代偿的指标），并可到肝硬化；而“酒精加（在肥胖与糖尿病中的）代谢的因素”是相加的（这是今日最常见的组合：她的体重指数29 提示两者并存，而治疗两者比治疗任一个都重要）——[[endocrine/diabetes]]、[[gastrointestinal/liver-function]]。要做的检查与要给的：按本地的路径计算纤维化的程度（天冬氨酸对丙氨酸的比值与（在若干体系中的）血小板与（现代的）瞬时的弹性成像与（在有指征时的）肝的活检查）与（在重症的酒精性肝炎中的）评分与（在糖皮质激素的适应证中的）感染的排除与（在上消化道出血的背景中的）内镜的静脉的评估；治疗的核心是戒酒（并给（在住院期间与（在出院后的）随访中）可被使用的支持：硫胺素在补充葡萄糖之前、苯二氮的递减的方案与（在若干中心的）加巴喷丁与（在维持期的）纳曲酮与阿坎酸与心理与社会的（这是唯一被证明能同时改善肝与生存与癌与心血管的干预）与营养（热量与蛋白与（在酗酒者中）多种维生素的补充）与（在肥胖与糖尿病并存时的）代谢的治疗）——[[psychiatry/substance-use]]、[[gastrointestinal/clinical-nutrition]]。一条常被忽略的：把脂肪变性解释给她的正确方式是“这是可逆的”（恐惧常使人就医，但希望才使人戒酒），并同时说明不可逆的那一步长什么样（纤维化与硬化的形态），使她在窗口内行动——[[clinical-skills/communication]]。**

::: example 输血依赖的地中海贫血患者 {#ex-iron}
一名22岁重型地中海贫血患者，自婴儿期规律输血（每年约十个单位），未规律服用铁的螯合；心脏的磁共振的T2星为8毫秒（正常大于20）；空腹血糖开始异常。
::: solution
**铁的沉积是一种可治疗的原发病（[[#def-adaptation]]、[[#def-injury]]、[[blood/haemoglobin-disorders]]）：机制：人体没有排铁的通路，每单位的红细胞含约二百毫克铁；慢性输血（以及（在无效造血的驱动下的）肠道吸收的增加）使铁以含铁血黄素与（在不溶的）含铁微砾的形式沉积在肝与心与内分泌（胰腺与垂体与甲状旁腺与性腺）与关节与皮肤；游离的二价铁通过芬顿反应催化羟自由基，把“沉积”变成“氧化损伤与纤维化”，因此铁过载的临床表现就是这些器官的纤维化的表现：肝（纤维化与（在与病毒性肝炎协同时的）肝硬化）、心（心肌病与心律失常——在过去这是首位的死因）、内分泌（糖尿病与性腺的功能减退与生长与青春期的落后与甲状腺功能低下与（在若干病例中的）骨密度的问题）、以及感染的易感（若干细菌（如小肠结肠炎耶尔森与某些弧菌）在富铁的环境中生长更好）。T2星8毫秒意味着心肌的铁显著（这是决定治疗强度的客观指标，其价值在于比血清铁蛋白更能反映心的铁），因此“未规律螯合”这一行为本身就是需要处理的临床问题。治疗：一个规则且可被使用的螯合方案按年龄与器官的选择与联合（若干病例中的去铁酮与（在心的铁过载中的）它的核心地位），并注意各自的毒性（听与视的（在去铁胺的）与（在去铁酮的）粒细胞缺乏与（在若干口服药的）胃肠与肝与（共同的）依从的问题），并把铁的负荷的监测制度化（肝的与心的的磁共振的定期与血清铁蛋白的趋势与（在若干中心的）内分泌的筛查（糖与甲状腺与（在青春期的）性腺与骨），使治疗按器官而非按单一化验调整）——[[endocrine/thyroid]]、[[cardiovascular/valve-congenital-disease]]。血糖异常的处理要按这个人群的特殊性：这不是二型糖尿病（是铁的胰腺的损伤与（在若干病例中的）胰岛素分泌的不足与（在肝病背景下的）抵抗的组合），因此治疗常需要胰岛素与（在若干病例中的）按肝功能选择的口服药，并同时考虑（在年轻女性中的）妊娠与（在铁过载未控制时的）生育与（在若干法域中的）心脏的与内分泌的联合随访与（在有移植可能时的）造血干细胞的移植的评估（她是22岁，需要重新讨论治愈性路径的风险与收益，包括（在有合适的供者时的）减低强度的移植）——[[endocrine/diabetes-complications]]、[[blood/transfusion]]、[[obstetrics-gynaecology/pregnancy-complications]]。最后一条是沟通：一个从婴儿期开始每天输血的年轻人对“你为什么不喝药”这一问法的反应是可预期的需要的是把方案的负担拆开（泵的时长与口服的次数与（在依从性差时的）长效的口服方案与（在学校与工作的）隐私与（在成年过渡期的）责任的交接），并让她参与选择——依从的干预在铁过载中是唯一被反复证明“改变剂量不如改变可行性”的领域——[[clinical-skills/communication]]、[[paediatrics/growth-development]]。**

## 通向何处

缺血与再灌注与血栓的循环障碍见[[pathology/haemodynamics]]；炎症对损伤的反应见[[pathology/acute-inflammation]]与[[pathology/chronic-inflammation-repair]]；细胞的异常增殖与逃避死亡见[[pathology/cancer-biology]]；损伤的分子检测与活检的形态学见[[pathology/diagnostic-pathology]]；器官的特异性缺血见[[cardiovascular/coronary-artery-disease]]与[[nervous-system/stroke]]与[[renal/acute-kidney-injury]]。

::: history
**细胞病理学始于一个断言：疾病是细胞的状态而不是体液的失衡。菲尔绍在1858年的《细胞病理学》把当时的显微技术（消色差的物镜与（在1840年代后的）苯胺的染料与（1860年代的）苏木精）与细胞学说的哲学（施莱登与施旺与（1855年的）魏尔啸的“一切细胞来自细胞”）合成一门诊断的实践，并把炎症的白细胞游出与栓子与淀粉样与白血病与（若干的）肿瘤的分类归入同一门语言；他的学生与同代（孔海姆的炎症的血管与化学趋化的先声与（1880年代的）科恩海姆把白细胞移出血管的行为学化与（1890年代的）梅奇尼科夫的吞噬）把视野从“细胞的病变”扩展到“细胞之间的反应”。损伤的生物化学属于二十世纪的仪器：从希尔与迈尔霍夫的能量代谢与（1941年的） Lipmann 的辅酶A 与（1940年代的）三磷酸腺苷，到（1950年代的）膜泵与（1960年代的）自由基的酶学（超氧化物歧化酶的发现使“氧的毒性”从悖论成为通路）与（1970年代的）钙的信号与（1980年代的）线粒体的通透性转换与（2000年代的）铁死亡与坏死性凋亡与焦亡的分子识别。程序性细胞死亡的历史是一次范式的翻转：1972年克尔与威利斯与柯里在形态学上命名“凋亡”时几乎无人问津；1980年代在线虫中通过基因的筛选找到的“死亡的基因”（ced 与（其哺乳类的同源）Bcl-2 与（1990年代的）半胱天冬酶的家族）使霍维茨与（2002年的）苏尔斯顿与布雷纳尔获得诺贝尔奖，并让“细胞主动自杀”成为生理与发育与癌症治疗的语言；而“细胞的死亡方式是被分类的”这一观念（凋亡与坏死性凋亡与焦亡与铁死亡）则是2010年代之后才稳固的。适应与沉积的观察更早：从（十九世纪的）含铁血黄素的命名与（在输血出现后）铁过载的疾病化，到巴雷特与（在1950年代后的）化生与癌变的连续（流行病学在吸烟者中确立，分子在吸烟者的气道的样本中确立）；而“蛋白的稳态”分子伴侣的发现（1987年，拉斯卡与（1990年代的）热休克的研究）、泛素的降解（1980年代的赫尔与（2004年的诺贝尔奖））、与内质网的未折叠反应（1990年代末到2000年代）共同构成了今日理解沉积与神经退行与代谢性肝病的框架。这一切的临床后果是同一个：今天读一张切片与读一份肌钙蛋白，用的仍是同一套关于细胞如何生病、如何死、以及在何处还能被救回的知识——[[pathology/cancer-biology]]、[[pharmacology/drug-development-prescribing]]、[[clinical-skills/laboratory-tests]]。**
:::

::: summary
- 三磷酸腺苷的耗竭是可逆与不可逆之间的主轴：泵失效与细胞肿胀与（在持续时）线粒体的通透孔。
- 自由基的损伤由铁的催化放大，其防御（超氧化物歧化酶与谷胱甘肽）的耗竭解释了若干药物与营养与脓毒症状态下的易感。
- 凋亡不泄漏故无炎症，坏死泄漏故必炎症；第三、四类死亡（坏死性凋亡与焦亡与铁死亡）由特定的分子执行并有各自的炎症后果。
- 适应（肥大与增生与化生与萎缩）与沉积（脂与蛋白与糖与色素与盐）不是无关的形态，而是同一压力在不同时限与强度上的产物。
- 化生是可逆的适应，但它与癌共享同一种压力与同一批突变——这是筛查与戒烟的生物学理由。
- 缺血的时钟按细胞类型不同，而标志物的曲线滞后于损伤；“挽救危险区”是再灌注治疗的全部逻辑。
:::

## 练习

::: exercise 把沉积与其后果配对 {level=1}
为下列沉积各说出机制与最有临床意义的后果：肝的甘油三酯；肾小管上皮的重吸收小滴；心肌的含铁血黄素；胃黏膜的淀粉样；关节的尿酸盐；肺泡内的含铁血黄素的巨噬细胞。
::: solution
**沉积的六种结局（[[#def-adaptation]]、[[#def-injury]]、[[gastrointestinal/liver-disease]]）：肝的甘油三酯（脂肪变性）：可逆，但若干比例经炎症与纤维化到硬化，其后果取决于病因是否被去除（酒精与代谢的因素与药物与病毒的与（在妊娠急性脂肪肝与（在Reye综合征中的）线粒体的毒性是急性的类型））。肾小管的重吸收小滴：蛋白的负荷（在肾病综合征与（在多发的骨髓瘤的）轻链与（在若干的）小管的损伤时），其后果是（在轻链时的）小管的堵塞与（在其中的）炎症与（在慢性时的）萎缩与间质的纤维，与“小管的蛋白管理的过载”这一共同机制——[[renal/tubular-function]]、[[blood/lymphoma-myeloma]]。心肌的含铁血黄素：铁的催化自由基，后果是扩张型的心肌病与（在传导系统的）心律失常与（在未经螯合者的）死亡，是“沉积即可治疗”的典型（也是输血依赖的患者的第一位可预防的死因，历史上）——[[blood/transfusion]]、[[cardiovascular/valve-congenital-disease]]。胃黏膜的淀粉样：错误折叠的蛋白的细胞外的沉积（按前体的分型：免疫球蛋白的轻链与（在慢性炎症中的）A 型与（在老年与（在长期透析的）β2 微球蛋白的）与（在内分泌的肿瘤中的）激素的前体），其后果可以是沉积的部位的功能障碍（胃的沉积可致出血与（在肠的）假性梗阻与吸收不良与（在心的）限制性的心肌病与（在神经的）自主的病），而活组织的刚果红与（在分型可用时的）质谱是分型的关键——[[pathology/diagnostic-pathology]]、[[renal/tubular-function]]。关节的尿酸盐：单钠的尿酸盐的晶体在滑膜与（在慢性的）骨与软组织形成沉积，激活炎症小体与（在多次发作后的）侵蚀与（在肾的）结石与（在髓质的）间质的病，其后果可被降尿酸的长期治疗改变（并把晶体作为慢性炎症的模型）——[[musculoskeletal/inflammatory-arthritis]]、[[renal/urinary-tract]]。肺泡内的含铁血黄素的巨噬细胞：提示肺泡的出血（在血管炎与（在肺肾综合征的）抗体的病与（在二尖瓣的狭窄的）高压与（在凝血障碍与弥散的出血的）），其后果是（在反复出血后的）含铁血黄素的沉积与（在若干病例中的）纤维，而其诊断价值在于“ BAL 里的 hemosiderin-laden macrophage = 至少数日前的出血”——[[respiratory/interstitial-vascular-disease]]、[[immunology/autoimmunity]]。**

**两套话术（[[#def-adaptation]]、[[#def-death]]、[[clinical-skills/communication]]）：对吸烟者：要点是“这是气道为了活下来而换了材料，换材料本身可逆，但让它换的那个东西也在同时造成不可逆的改变”；具体说：“你的气管表面的细毛被更硬的皮替换了，所以咳嗽与清痰与感染变多；这一改变在戒烟后可以部分恢复；报告里的“轻度不典型”表示一些细胞的核开始不对劲，多数会停住甚至回去，但吸烟继续会让它继续走的概率升高”。下一步：一次结构化的戒烟（药物的联合（在适合者的伐尼克兰与（或）替换与（或）安非他酮的）与行为的与（在若干体系中的）处方内的支持），一个明确的复诊（咯血的追踪与（按本地的标准）低剂量的计算机断层的筛查资格）与（在慢性的咳嗽与气促时的）肺功能——[[respiratory/control-breathing-tests]]、[[public-health/prevention-promotion]]。对巴雷特：要点是“下端的食管因为长期接触酸而换成了肠型的上皮，这本身不是癌，但它所在的段有较低的癌变风险，我们需要定期看它”；具体说：解释“肠化”是胃或肠型的上皮，“特殊型”意思是含杯状细胞（这是诊断的定义，不是严重度的分级——这一句几乎每位患者都需要，因为报告上的字眼像分级），并给绝对的风险而不是相对的词（每年千分之若干的量级），说明质子泵的控制症状而不消除风险（抗酸的目的是炎症与症状，癌变风险的降低证据有限），以及内镜监测的方案（按肠化的长度与不典型的有无分层，并在有不典型时按（在若干病例中的）消融的路径）与在体重与（在夜间症状的）体位与（在若干食物与（在吸烟饮酒的）刺激物的）生活方式的建议与（在难治的返流中的）抗反流手术的讨论——[[gastrointestinal/oesophagus-stomach]]、[[pathology/cancer-diagnosis]]。共同的沟通的技术：把“不是癌”与“需要随访”同时说清（只说前者导致失访，只说后者导致恐慌）；把风险用绝对数与分母说；给她写下来（书面的下一步与复发的报警症状使依从显著提高）；并说明“改变可以起效的窗口在哪里”（这是让患者行动的最有效的一个句子）——[[clinical-skills/patient-safety]]。**

::: exercise 把蛋白稳态当作治疗靶点 {level=3}
一种小分子计划通过激活热休克因子1 或增强自噬来清除错误折叠的蛋白（靶病为一种遗传的淀粉样变性）。请设计从机制到临床的验证路径与其主要的失败风险。
::: solution
**蛋白稳态的治疗设计（[[#def-injury]]、[[#def-adaptation]]、[[pathology/cancer-diagnosis]]）：机制的假设可被拆成三个可测的环节：增加伴侣（热休克因子1 的激活上调热休克的蛋白网络）、增加清除自噬的诱导（在雷帕霉素的依赖的与（在非依赖的路径上的）通路与溶酶体的功能的恢复）、以及减少来源（反义的寡核苷酸与小的干扰核糖核酸与（在若干的）CRISPR 的编辑与（在若干的）稳定天然构象的小分子）；而遗传的淀粉样变（在转甲状腺蛋白与（在若干的）纤维蛋白原与载脂蛋白与前白蛋白的变异）提供了一个罕见的优势：致病的前体由一个可定位的器官（肝）产生，且有一个可测的血液的替代物。设计的通路：一，建立可被用于人体药效的标志（血浆的前体的浓度与（在组织中的）刚果红的面积的定量与（在若干病例中的）质谱的分型与（在心的限制性的病变中的）心脏的磁共振与（在神经的）电生理的评分），否则试验只能测“安全的”。二，先在“减少来源”上取得人体证据（反义的路径已有若干范例），并用它作为工具药来验证“降低前体的浓度能否改变器官的结局”这一因果假设（这是本领域最重要的未决问题：若干疾病的器官的损伤在沉积之前已经发生，或沉积只在其后部分可逆）。三，再测试伴侣与自噬的路径（它们的效应是间接的、可能需要在疾病早期干预，且全身的热休克因子的激活有发热与（在肿瘤风险上的）顾虑）。四，设计能识别亚型的分层（同一表型的不同变异与（在若干的）器官的偏好会使混合的人群稀释效应）。五，在终点上接受“器官的替代物加功能的复合终点”并要求较长的随访（淀粉样的清除以年计）——[[epidemiology-ebm/randomised-trials]]、[[genetics/genomic-medicine]]。失败的风险要预先说出：脱靶（全身的热休克与自噬的激活影响免疫与（在肿瘤监测上的）与（在若干的）代谢）与“清除已有的沉积”的实际困难（已形成的纤维的骨架可能不被有效地清除，故时机重于强度）与（在自噬时的）双面性（自噬在若干情境中是细胞的存活机制，抑制肿瘤而促进存活的应激）与补偿（伴侣的上调可能同时稳定突变的蛋白）与（在血液的标志与器官的负担不一致时的）解释的困难；以及一个概念的风险：把“清除蛋白”等同于“治愈疾病”，而在若干的神经退行的疾病中已反复出现“标志物改善而结局不变”——[[nervous-system/dementia-neurodegeneration]]、[[pharmacology/drug-development-prescribing]]。**

::: exercise 说出坏死的类型 {level=1}
为下列标本各说出坏死的类型与理由：脑的动脉血栓后的皮质；结核的肺的上叶；急性胰腺炎的胰周脂肪；下肢的糖尿病足发黑干燥；一个脓腔的中心；子痫患者的肝的门管区周围；以及（在恶性高血压中的）肾的小动脉壁。
::: solution
**形态是机制的影子（[[#def-death]]、[[#def-injury]]、[[pathology/haemodynamics]]）：脑的动脉血栓后：液化性坏死（脑的富含的脂质与缺乏的支架使坏死的组织被小胶质细胞清除成腔，数周后留下囊性的空洞与胶质瘢痕，且缺血六至十二小时即可见“红色的神经元”与（在二十四至四十八小时的）中性粒的浸润）——[[nervous-system/stroke]]。结核的上叶：干酪性坏死（结构的完全消失而成均质的嗜酸的碎片，周围为肉芽肿与（在若干的）郎汉斯的巨细胞与（在边缘的）纤维），其“奶酪样”的质地源于脂类（在其中的分枝杆菌的细胞壁的脂质）与坏死的混合，并因低氧与酸的环境限制（但不消除）细菌的繁殖——[[infectious-diseases/tuberculosis]]、[[pathology/chronic-inflammation-repair]]。胰周脂肪：脂肪的坏死被溢出的脂酶分解的脂肪细胞形成甘油与（与钙结合的）脂肪酸的钙皂，眼观为白色的斑与（在镜下的）嗜碱的钙化，其后果是低钙（在重症的与（在若干病例中造成）的手足搐搦）——[[gastrointestinal/pancreas-biliary]]。糖尿病足发黑干燥：凝固性的坏疽（缺血的蛋白的变性保留了结构的轮廓）与（在感染与潮湿时的）湿性（叠加的腐败菌与（在其中的）蜂窝织炎与脓毒症），两者的区别在临床上是“干燥稳定与湿性需急处理”——[[surgery/vascular-urological-surgery]]、[[endocrine/diabetes-complications]]。脓腔的中心：液化性坏死伴中性粒的溶解（脓即死去的与存活的白细胞与坏死的碎片与细菌），需要引流——[[pathology/acute-inflammation]]、[[surgery/wounds-surgical-infection]]。子痫的门管区周围：出血性坏死（在血管痉挛与（在血管内的）纤维的沉积的机制下，门周区的肝细胞坏死伴出血，可与肝的被膜下的血肿与（在若干的）破裂相关，是产科的急症）——[[obstetrics-gynaecology/pregnancy-complications]]、[[gastrointestinal/liver-disease]]。恶性高血压的小动脉：纤维素样坏死（血浆的蛋白（含纤维的蛋白）渗入坏死的血管壁而成红染的、似纤维素的物质，见于免疫的血管炎与（在结节性多动脉炎中的）与（在恶性高血压中的）小动脉与（在胃与十二指肠溃疡底的）血管壁）——[[renal/acid-base-disorders]]、[[immunology/hypersensitivity]]。**

::: exercise 解释再灌注损伤 {level=1}
一名患者的冠状动脉在闭塞两小时后被开通；开通后心律出现加速性的室性心律与（在若干病例中的）再灌注后的心肌的顿抑与（在实验中的）更大的损伤。请用通路解释并说明临床上能做什么。
::: solution
**再灌注的双面（[[#def-injury]]、[[#def-death]]、[[cardiovascular/coronary-artery-disease]]）：缺血造成的钠与钙的积聚与三磷酸腺苷的匮乏与（在细胞内的）酸中毒在血流恢复的瞬间产生几个后果：氧突然进入含有游离铁与（在细胞色素的）泄漏的电子链的细胞，产生爆发性的自由基；钙的过载打开线粒体的通透孔（在再灌注的那一刻打开，故“孔的开闭”在再灌注时成为决定性的事件）；酸中毒的突然纠正（通过钠氢交换与（在其中的）钠钙交换的反转）本身也促进孔的开放；加上被恢复的血流带入的中性粒（其在内皮的黏附与（在微血管的）堵塞产生无复流）与补体的激活与（在其中的）炎症的放大——后果是四类：可被挽救的心肌的额外损伤、微血管的损伤与无复流、再灌注的心律失常（多为短暂且通常不增加最终梗死的体积）、以及顿抑（存活但收缩功能暂时低下，可数日至数周恢复——临床上的“血流通了但室壁仍不动”多是这个而非坏死）——[[pathology/acute-inflammation]]、[[cardiovascular/cardiac-cycle]]。临床可做的：缩短缺血的时间是唯一被反复证明的（时间的收益远大于任何药物）；控制再灌注的“条件”（在介入的路径中避免在开通瞬间的高压与高钙的灌注液与（在若干中心的）碱性的与低钙的与富钾的诱导液（在手术的心脏停搏液中被使用并有实验的支持），并纠正低钾与低镁）；处理无复流（在导管室内的腺苷与（在若干的）钙拮抗剂与（在选择病例中的）抽吸的争议）；药物的二级预防（他汀的（在术前负荷剂量的）与（在若干的）抗血小板的与（在若干病例中的）远端的缺血的后处理仍在试验中）；以及顿抑的正确解读（不要因为室壁不动而过早判定预后，用（数日至数周后的）复查与（在有存活心肌的证据时的）血运重建的评估来决定，同时避免过度与不足的抗凝与（在心室功能低下者的）器械的考虑）——[[surgery/perioperative-care]]、[[pharmacology/adverse-reactions]]。**

::: exercise 解读一份有不典型的巴氏涂片 {level=2}
一名29岁女性的筛查细胞学报告为“不典型鳞状细胞，意义不明”；她的人乳头状病毒的检测为16/18 型阳性；她非常焦虑并要求“把病灶切掉”。
::: solution
**细胞学的语言与其下一步（[[#def-adaptation]]、[[#def-death]]、[[obstetrics-gynaecology/gynaecological-cancer]]）：先把术语翻译：“意义不明的不典型鳞状细胞”是一句关于标本的陈述而非关于病变的陈述——它的意思是“这些细胞不够正常也不足以称为病变”，其中最常见的原因是反应性的（炎症与（在激素影响的）萎缩与（在放线菌与（在若干的药物中的））修复），而在有16/18 型病毒时其“背后有高级别病变”的概率显著上升，因此正确的动作不是切除也不是重复涂片，而是按路径做阴道的镜检（并可同时在（在若干路径中的）一年内复检的病毒以覆盖“一过性”的情形，具体取决于本地的指南）。要给出的绝对数（用本地的数据）：这一类别中最终发现高级别病变的比例约在若干个百分之几，而16/18 阳性者明显更高（这是把她的焦虑变成“一次可安排的检查”的最有效的数字）——[[public-health/screening]]。关于“切掉”：在没有组织学的高级别病变之前做切除（锥切）会付出真实的代价（出血与宫颈的狭窄与（在将来的妊娠中的）宫颈的机能不全与早产的风险），因此次序是先细胞学与病毒与阴道镜与（有指征的）活检，再决定是否需要诊断性的切除（其适应证是细胞学与组织学不一致与阴道镜不满意与（在若干的）腺性的病变，而不是患者的焦虑）；同时解释病毒本身（多数在两年内被清除，且疫苗与治疗性疫苗的角色与（在伴侣中的）传播的误解与（在若干人群中的）病耻），并说明随访为什么比一次“彻底的处理”更安全——[[infectious-diseases/sexually-transmitted-infections]]、[[clinical-skills/communication]]。要补的一层：把她的焦虑当作临床资料而不是干扰（询问她的既往筛查与家族的史与（在若干人群中的）对子宫的切除的文化含义与她的生育的计划），把随访的时间表写下来（并说明“若失守会怎样”），给出可及的联系渠道（“结果出来后谁打电话给你”），并处理病耻的语言（病毒的性传播的说明要在尊重的前提下给，并明确“这不代表任何人的行为不检”）——[[medical-ethics-law/consent-capacity]]、[[public-health/screening]]。**

::: exercise 给组织讲清区别 {level=2}
你要给一组一年级学生讲“凋亡、坏死、焦亡、自噬”。请给一个能在两次课内讲清并留下可应用的鉴别要点的教学方案。
::: solution
**教学的设计（[[#def-death]]、[[#def-injury]]、[[pathology/acute-inflammation]]）：用两个轴组织全部内容：膜是否完整（决定炎症有无）与是否耗能（决定形态是否“整齐”）；然后按四个原型讲：凋亡（收好自己：皱缩与出泡与凋亡小体与胞葬，无炎症；举例：指蹼的退化与（在淋巴的选择中的）自身反应者的清除与（在肿瘤治疗中的）期望的结局）；坏死（泄漏：肿胀与破裂与炎症；举例：梗死的中心与（在其中的）凝固与（在脑的）液化）；焦亡（有程序的泄漏：炎症小体与半胱天冬酶-1 与成孔的蛋白与白细胞介素1 与18 的释放；举例：若干的胞内菌与（在晶体与（在若干的）淀粉样的）无菌的炎症）；自噬（先讲清它是存活机制：细胞吃掉自己的部分以度过饥饿并清除受损的线粒体与蛋白的聚集体，其过度才与死亡相关；举例：（在饥饿与运动后的）生理的上调与（在若干的肌与神经的）疾病中的清除不足）；每个原型配一张电镜的图与一句临床的话（“为什么这个病人的炎症标志不升高”（在凋亡为主的病）与“为什么这个病人的高热与白细胞介素1 的通路是治疗靶点”（在焦亡与炎症小体的病））——[[immunology/innate-immunity]]、[[immunology/hypersensitivity]]。可应用的四条要点：一，看炎症就能猜死亡的方式；二，“程序的”不等于“好的”（焦亡与坏死性凋亡是程序但促炎）；三，“自噬”不是死亡的同义词而是代谢的通路，故“诱导自噬以治疗”需要谨慎的理由；四，标志物的层次（膜的完整的丧失可被染料测，半胱天冬酶的激活可被测，磷脂酰丝氨酸的外翻可被测，而“坏死性凋亡与焦亡”需要在实验中被证明，因此临床报告里几乎只出现凋亡与坏死的语言）——[[clinical-skills/laboratory-tests]]、[[pathology/diagnostic-pathology]]。评估的学习效果用病例：给三份材料（一个化疗后的淋巴瘤的活检与一个梗死的心肌与一名全身炎症反应综合征的患者的皮肤），要求学生对号并预测（炎症的标志、以及（若可用）干预的靶点在通路的哪一步）——[[clinical-skills/clinical-reasoning]]。**

一名患者的四肢的创面存在坏死、定植的细菌与（在创面的渗液中持续的）炎症与（在无血供的基底上的）不愈合。请从细胞损伤的角度设计一个能支持愈合的创面床。
::: solution
**创面床的病理学（[[#def-death]]、[[#def-injury]]、[[pathology/chronic-inflammation-repair]]）：为什么不愈合：慢性创面停在炎症期——渗液里的蛋白酶持续降解基质，生物膜使中性粒无法清除细菌，血供不足使每一次氧的需求都成为损伤，反复的机械压力与渗液对周围皮肤的化学刺激加重炎症；结果是成纤维细胞被消耗、基质的降解大于合成、新生血管不成熟，这正是"炎症未终止"在一个器官上的表现。设计分四层。第一层，去掉不可逆的部分：清创把坏死变成能愈合的边缘；对被生物膜覆盖的创面，机械、化学与酶的方法并用，而对血供可疑者采取"少量多次"以避免一次清得太深。第二层，改变氧的供需：纠正贫血、戒烟、维持灌注压、必要时先做血运重建——顺序很重要，先评估血管再清创，否则更彻底的清创只会造成更大的不愈。第三层，控制细菌与炎症而不伤肉芽：按本地路径使用含银或含碘的敷料并设使用时限，只在有全身感染证据时给系统的抗生素，并区分定植与感染（局部杀菌剂在高浓度下对成纤维细胞同样有毒，这是"外用药也有药理学"的一课）。第四层，给创面力学与生物的环境：负压引流、减压的方案（压疮的翻身计划与足部的减压鞋具）、必要时植皮或生物的皮肤替代物。测量与终点：以三维记录随访面积与深度（比照片可靠），描述肉芽的质量与渗液的量与疼痛的评分；若四周无改善则回到病因重新查——血供、非典型感染、血管炎、恶性变（慢性创面上的鳞状细胞癌）与营养不良，而不是更换敷料——[[surgery/wounds-surgical-infection]]、[[surgery/vascular-urological-surgery]]、[[endocrine/diabetes-complications]]、[[geriatrics-palliative/falls]]。**
