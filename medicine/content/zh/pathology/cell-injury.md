每一种疾病，无论累及哪个器官，都始于承受应激的细胞。细胞的反应方式只有寥寥几种。它可以发生适应，改变自身的大小、数量或类型，以应对新的需求；它可以受到损伤而后恢复；它也可以死亡，而死亡的方式决定了组织随后的形态，以及机体下一步的反应。本章讲授这一有限的反应谱、每种反应背后的机制，以及病理医师如何在显微镜下识别它们。

本章的概念贯穿此后的每一章。急性炎症是机体对死亡细胞和受损细胞的反应。梗死是动脉阻塞引起的细胞死亡。癌起源于经历过适应和异型增生的组织。理解了心肌细胞为何在失去血供二十分钟后死亡的读者，也就理解了临床医学的很大一部分。

## 细胞损伤的原因

损伤细胞的因素种类有限：

- **缺氧。** *低氧*（hypoxia）指氧供不足。*缺血*（ischaemia）指血流不足，组织因此既失去氧和营养物质，又无法清除代谢废物。缺血是临床实践中最常见的细胞损伤原因。
- **物理因素**：创伤、高温和低温、电流以及电离辐射。
- **化学物质和药物**：一氧化碳等毒物，以及过量使用的普通药物，如过量服用对乙酰氨基酚（paracetamol）。酒精是肝损伤最常见的化学性原因。
- **病原体**：病毒、细菌、真菌和寄生虫，通过直接损害或通过宿主的免疫反应造成损伤。
- **免疫反应**：自身免疫病和超敏反应，即机体自身的防御损伤自身的组织。
- **遗传缺陷**：例如细胞无法清除的错误折叠蛋白。
- **营养失衡**：缺乏（蛋白质、维生素）和过剩（肥胖，使细胞内脂质堆积）。

某一损伤因素引起的是适应、可逆性损伤还是死亡，取决于其**严重程度**、**持续时间**以及**细胞类型**。神经元只能耐受几分钟的完全缺血，心肌细胞约二十至三十分钟，骨骼肌和成纤维细胞则可耐受数小时。细胞的状态同样重要：已经消耗了大部分氧供的肥大心肌细胞，比正常心肌细胞更容易受损。

## 细胞的适应

当应激轻微或进展缓慢时，细胞会调整其结构或功能，而不是受到损伤。去除应激后，这些适应通常是可逆的。

::: definition 细胞的适应 {#def-adaptation}
- **肥大**（hypertrophy）是细胞体积增大，进而器官增大，而细胞数量不增加。见于分裂能力很弱的细胞，如心肌和骨骼肌。
- **增生**（hyperplasia）是细胞数量增多，来源于已分化细胞或干细胞的增殖。只发生于细胞能够分裂的组织。
- **萎缩**（atrophy）是由于细胞物质丢失导致的细胞体积缩小，常伴细胞数量减少。
- **化生**（metaplasia）是一种已分化的细胞类型被另一种更能耐受应激的已分化细胞类型可逆性取代。
- **异型增生**（dysplasia）是生长紊乱，细胞失去大小、形态和排列方向的一致性。严格说来它不是一种适应，而是一种可能进展为癌的前驱病变。
:::

**肥大**可以是生理性的，也可以是病理性的。妊娠时子宫在雌激素驱动下，通过平滑肌的肥大和增生而增大。举重运动员的骨骼肌发生肥大。长期高血压患者的心脏出现左心室肥大：每个心肌细胞合成更多的收缩蛋白，使心室壁能够产生额外的压力。机械牵张和生长因子激活信号通路，开启这些基因。这种适应有其限度。肥大的心脏心室壁更厚，但每个细胞所对应的毛细血管并未增多，因此其细胞发生缺血的风险更高，最终心肌衰竭（[[cardiovascular/heart-failure]]）。

**增生**常由激素引起。青春期和哺乳期乳腺上皮增殖。部分肝切除后，肝通过增生再生。病理性增生源于过度刺激。未被孕激素拮抗的雌激素引起的子宫内膜增生是一个重要例子，因为它增加子宫内膜癌的风险。由雄激素驱动的良性前列腺增生则不增加癌的风险。增生仍是受控的生长：撤去激素后它会消退。正是这种控制将它与癌区别开来，但分裂更多的组织也是更容易积累突变的组织。

**萎缩**的原因很多：失用（打石膏的腿）、失去神经支配、血供减少（慢性缺血时的脑）、营养不良、失去激素刺激（绝经后的子宫内膜）以及压迫（肿瘤压迫邻近组织）。细胞通过泛素-蛋白酶体系统降解自身蛋白质，并通过**自噬**（autophagy）消化自身的细胞器：部分胞质被包入一个空泡，再与溶酶体融合。部分未被消化的物质残留为**脂褐素**（lipofuscin），这是一种褐色的“磨损”色素。

**化生**是一种交换。吸烟者的支气管中，正常的纤毛柱状上皮被复层鳞状上皮取代。鳞状细胞更能耐受烟雾，但它们不分泌黏液，也没有纤毛，因此肺失去了部分清除机制。长期胃酸反流者的食管下段，鳞状上皮被胃型或肠型柱状上皮取代：这就是**巴雷特食管**（Barrett's oesophagus）。化生是通过干细胞的重新编程发生的，而不是一个成熟细胞变成另一个成熟细胞。其重要性在于，化生上皮是异型增生和癌常常发生的土壤：支气管鳞状细胞癌、食管腺癌。

**异型增生**描述的是形态异常的细胞：核增大深染，核质比增高，基底层以上出现核分裂象，以及从基底到表面有序成熟的消失。它分为低级别和高级别。在宫颈称为宫颈上皮内瘤变（CIN），分为1至3级。当异型增生累及上皮全层但尚未穿过基底膜时，称为**原位癌**（carcinoma in situ）。异型增生可以消退，尤其是低级别异型增生；但高级别异型增生进展为浸润性癌的风险相当大，因此需要治疗或密切观察。这些病变与癌的联系在[[pathology/cancer-biology]]中展开。

::: example 长期反流的男性 {#ex-barrett}
一名61岁男性多年来有烧心症状。内镜检查见其食管下段4 cm呈橙红色而非灰白色。活检显示含杯状细胞的柱状上皮，无异型增生。解释这一发现及其意义。
::: solution
1. 慢性胃酸和胆汁反流损伤了食管正常的复层鳞状上皮内衬。
2. 内衬的干细胞的反应是产生更耐酸的柱状上皮。杯状细胞表明它属于肠型。这就是**化生**，该病为巴雷特食管。
3. 新的上皮是更好的耐酸屏障，但它并不稳定。巴雷特食管患者中有一小部分会发生异型增生，继而发生腺癌。
4. 无异型增生意味着他每年患癌的风险很低。处理遵循现行指南（在英国为英国胃肠病学会指南）：控制反流，并按病变段长度及有无异型增生决定内镜监测的间隔。
:::
:::

## 可逆性损伤

如果损伤因素强到无法适应，细胞就会受损。起初损伤是可逆的：去除原因后，细胞可以完全恢复。

大多数可逆性损伤，尤其是低氧损伤的核心事件是**ATP生成障碍**。没有氧，线粒体的氧化磷酸化停止。细胞转向无氧糖酵解，后者产生的ATP少得多，并产生乳酸。ATP缺乏导致以下几种后果：

- **钠钾泵**（Na⁺/K⁺-ATP酶）减慢。钠在细胞内蓄积，水随之渗透进入。细胞及其细胞器肿胀。
- 乳酸降低细胞内pH，染色质凝集。
- 核糖体从粗面内质网上脱落，蛋白质合成减少。
- 在处理脂肪的细胞（如肝细胞）中，脂质以小空泡的形式蓄积。

光镜下，可逆性损伤主要表现为两种改变。**细胞水肿**（也称水样变性）使胞质淡染、呈空泡状。**脂肪变**（steatosis）是甘油三酯滴的蓄积，最常见于酒精滥用、肥胖和糖尿病时的肝。电镜下可见质膜出泡、微绒毛消失、线粒体肿胀和内质网扩张。

::: example 用数字看细胞水肿 {#ex-swelling}
一个表现为理想渗透计的细胞，体积为2.0 pL。钠泵衰竭使其具有渗透活性的溶质含量增加15%，而细胞外渗透压保持不变。估算细胞的新体积。
::: solution
1. 水分移动，直到细胞内渗透压等于细胞外渗透压。渗透压等于溶质除以水的体积。
2. 如果溶质含量增加到1.15倍，而渗透压必须回到原来的数值，那么水的体积也必须增加到1.15倍。
3. 把整个细胞体积都当作具有渗透活性的水：新体积 $= 2.0 \times 1.15 = 2.3$ pL。
4. 实际上细胞体积中有一部分是固体成分，所以真实的增加略小。要点在于，细胞内钠的适度增加就会引起明显的肿胀，这正是细胞水肿成为受损细胞最早出现的改变的原因。水在各体液间隙之间移动的生理学见[[physiology/homeostasis-body-fluids]]。
:::
:::

## 不可逆性损伤与不可逆转点

如果损伤因素持续存在，细胞就会越过一个点，此后即使恢复血流也无法复原。有两个特征始终标志着这个点：

1. **线粒体无法恢复功能**，因而无法再生ATP。
2. **膜严重受损**：质膜渗漏，溶酶体膜将消化酶释放入胞质。

::: theorem 不可逆性细胞损伤的机制 {#thm-injury}
四种相互关联的机制使细胞从可逆性损伤走向死亡：

1. **线粒体损伤**，伴线粒体通透性转换孔开放、膜电位丧失和ATP合成障碍。
2. **钙内流**，钙从细胞外以及细胞内储存处进入胞质。
3. **活性氧**（自由基）**蓄积**，损伤脂质、蛋白质和DNA。
4. **膜损伤**，包括质膜和溶酶体膜。

每种机制都会加重其他机制，因此损伤一旦越过阈值便会加速。
:::

::: proof
依赖ATP的泵使胞质中的钙浓度通常比细胞外低约一万倍。ATP下降时，钙进入胞质，并从内质网和线粒体中释放。胞质钙激活损伤细胞的酶：磷脂酶攻击膜，蛋白酶分解细胞骨架，核酸内切酶使DNA断裂，ATP酶消耗所剩的ATP。钙还使线粒体通透性转换孔开放，导致线粒体膜电位崩溃，于是即使氧恢复，线粒体也无法再产生ATP。

受损的线粒体使电子从呼吸链漏给氧，形成**活性氧**：超氧阴离子、过氧化氢，以及由游离铁催化过氧化氢产生的极活泼的羟自由基（芬顿反应）。这些物质氧化膜脂、交联蛋白质并使DNA断裂。细胞的防御系统，如超氧化物歧化酶、过氧化氢酶和谷胱甘肽过氧化物酶，依赖于受损细胞正在丧失的还原力。

膜损伤使这一循环闭合。渗漏的质膜让更多的钙进入，也让细胞内容物流出。渗漏的溶酶体释放酸性水解酶，消化细胞。到了这一阶段，细胞无法恢复离子梯度和能量供应，死亡随之而来。
:::

细胞内容物漏入血液有实际用途。属于特定细胞内部的蛋白质，在这些细胞死亡时出现在血浆中。心肌梗死时的**心肌肌钙蛋白**、肝损伤时的丙氨酸转氨酶、肌肉损伤时的肌酸激酶，都是出于这一原因而测定的。它们的升高是细胞死亡的证据，而不仅仅是可逆性应激的证据。

2. 当$k = 0.07$时：$t = 1.386/0.07 \approx 19.8$分钟。
3. 严重缺血时，心肌约在20至30分钟后开始死亡。这里选取的示意性$k$值是为了显示这一数量级，而不是由测量得出的。
4. 这个模型的启示在于曲线的形状：耐受时间由能量消耗速率决定。降温使代谢减慢，从而延长到达阈值的时间。这就是供体器官要低温保存的原因。

### 缺血-再灌注损伤

恢复缺血组织的血流是挽救它的唯一途径，然而再灌注本身也可能加重损伤。当氧回到线粒体已受损的细胞时，会产生一阵活性氧的爆发。钙大量涌入泵功能已减弱的细胞。中性粒细胞和补体随血液到来，攻击受损的细胞。这种**再灌注损伤**参与了开通阻塞的冠状动脉之后、器官移植之后以及心脏骤停之后的损害。它并不意味着应当放弃再灌注；它解释了为什么结局取决于血流恢复之前组织缺血了多长时间。

## 坏死

细胞死亡有两条主要途径。**坏死**（necrosis）是严重损伤后的死亡，细胞肿胀，膜破裂，内容物外漏，引起炎症。**凋亡**（apoptosis）是一种受调控的程序，细胞以有序的方式自我拆解，内容物不外漏。

::: definition 坏死及其形态学类型 {#def-necrosis}
**坏死**是活体组织中细胞死亡后发生的一系列改变，由细胞的酶解消化和蛋白质变性引起。细胞核皱缩、致密（**核固缩**），碎裂成碎片（**核碎裂**），最后消失（**核溶解**）。在苏木精-伊红染色中，胞质嗜酸性增强（更红）。组织中所见的类型取决于原因和器官：

- **凝固性坏死**：死亡细胞的轮廓可保留数日，因为蛋白质（包括本会消化它们的酶）发生了变性。是除脑以外实质器官梗死的典型类型。
- **液化性坏死**：死亡组织被消化成液态团块。见于细菌和真菌感染（脓）以及脑梗死。
- **干酪样坏死**：一种干酪样、白色、易碎的团块，没有细胞轮廓，周围有肉芽肿性炎症。是结核病的典型表现。
- **脂肪坏死**：受损胰腺释放的脂肪酶破坏脂肪组织，或乳腺等富含脂肪的组织受创伤后发生。释放的脂肪酸与钙结合，形成白垩样的白色沉积。
- **纤维素样坏死**：免疫复合物和纤维蛋白沉积于血管壁，呈鲜红色、模糊的外观。见于血管炎和恶性高血压。
- **坏疽**（gangrene）是用于肢体或肠坏死的临床术语。*干性坏疽*以凝固性坏死为主。*湿性坏疽*是伴有细菌感染和液化的坏死。
:::

为什么其他器官发生凝固而脑却发生液化？脑组织支持性结缔组织很少，脂质含量高，其自身的溶酶体酶和进入的小胶质细胞的酶能迅速将其消化。脑梗死在数周内变成充满液体的腔。相反，肾或心脏的梗死保持为质地坚实的苍白区，其中死亡的细胞保留轮廓，直到炎症细胞将其清除、瘢痕组织将其取代。

::: example 心肌梗死的时间进程 {#ex-infarct}
一名70岁女性在突发压榨性胸痛五天后死亡。尸检见左心室前壁有一黄色、质软的区域，周边有一圈红边。显微镜下会看到什么？她生前心肌肌钙蛋白为什么升高？
::: solution
1. 左前降支冠状动脉闭塞导致前壁缺血。约20至30分钟后，心肌细胞越过了不可逆转点。
2. 死亡的细胞表现为**凝固性坏死**：轮廓保留，胞质强嗜酸性，细胞核消失。
3. 死亡细胞吸引中性粒细胞，其高峰约在第一至第三天。到第三至第七天，巨噬细胞正在清除死亡组织，所以第五天时梗死灶质软、呈黄色。红边是边缘的早期肉芽组织。此后数周内瘢痕取代梗死灶。
4. 肌钙蛋白是心肌的结构蛋白。濒死细胞的质膜失效后，肌钙蛋白漏入血液。因此肌钙蛋白升高是心肌细胞死亡的证据。
5. 第三至第七天软化的心室壁在力学上很薄弱，这也是心室壁破裂最可能发生的时期。临床内容见[[cardiovascular/coronary-artery-disease]]。
:::
:::

## 凋亡

**凋亡**是程序性细胞死亡：细胞激活能以有序方式降解自身DNA和蛋白质的酶。它在健康状态下发生，以清除不再需要的细胞；也在疾病中发生，以清除损伤到无法修复的细胞。

生理性的例子包括胚胎发育时指（趾）间细胞的消失、子宫内膜的脱落、胸腺中自身反应性淋巴细胞的清除，以及炎症反应结束时中性粒细胞的死亡。病理性的例子包括DNA损伤无法修复的细胞、被病毒感染的细胞（由细胞毒性T细胞杀伤），以及导管阻塞后器官的萎缩。

::: definition 凋亡及其两条途径 {#def-apoptosis}
**凋亡**是一种受调控的细胞死亡形式，由胱天蛋白酶（caspase，一类半胱氨酸蛋白酶）拆解细胞。细胞皱缩，染色质凝集于核膜下，细胞核碎裂，细胞裂解为有膜包裹的**凋亡小体**，被巨噬细胞吞噬。质膜保持完整，因此不引起炎症。

- **内源性（线粒体）途径**由DNA损伤、错误折叠蛋白或生长因子缺失等内部应激触发。BCL-2家族的感受蛋白（仅含BH3结构域的蛋白）激活**BAX**和**BAK**，后者在线粒体外膜上形成孔道。细胞色素*c*逸入胞质，与APAF-1结合形成凋亡体，激活**caspase-9**。抗凋亡蛋白**BCL-2**和BCL-XL对抗这一步骤。
- **外源性（死亡受体）途径**由配体与细胞表面的死亡受体结合触发：细胞毒性T细胞上的Fas配体与Fas结合，或TNF与TNF受体1结合。受体募集接头蛋白并激活**caspase-8**。
- 两条途径汇聚于**执行性caspase**，即caspase-3和caspase-7。
:::

凋亡细胞将磷脂酰丝氨酸翻转到质膜外层。它充当“吃掉我”的信号，使巨噬细胞在细胞内容物漏出之前将其清除。这就是凋亡在免疫学上“安静”的原因，也是组织可以通过凋亡失去许多细胞而几乎不出现可见反应的原因。

存活与死亡之间的平衡既是疾病的作用点，也是治疗的靶点。许多癌过度表达BCL-2或失去p53（感知DNA损伤并触发内源性途径的蛋白）；这些细胞在本应致死的损伤下存活下来（[[pathology/cancer-biology]]）。滤泡性淋巴瘤由一种使*BCL2*受免疫球蛋白基因调控的易位所驱动。一类抑制BCL-2的药物现已用于某些白血病。凋亡过度参与了神经退行性疾病以及HIV感染中CD4 T细胞的丢失。

::: warning 凋亡不是温和的坏死
一个常见错误是把凋亡当作较轻的坏死。两者在性质上不同。坏死时细胞肿胀，膜破裂，内容物外漏，随后发生炎症；它总是提示病理状态。凋亡时细胞皱缩，膜保持完整，碎片被吞噬而不引起炎症，这一过程可能完全是正常的。同一种刺激可以引起其中任何一种：轻微的损伤可能触发凋亡，而对同一细胞的严重损伤则引起坏死，因为已没有ATP来运行凋亡程序。
:::

| 特征 | 坏死 | 凋亡 |
|---|---|---|
| 细胞大小 | 增大（肿胀） | 缩小（皱缩） |
| 细胞核 | 核固缩、核碎裂、核溶解 | 凝集，碎裂成规整的碎片 |
| 质膜 | 破坏 | 完整 |
| 细胞内容物 | 外漏，被酶解消化 | 保留在凋亡小体内 |
| 炎症 | 通常存在 | 不存在 |
| 意义 | 总是病理性的 | 常为生理性的，也可为病理性的 |

### 其他形式的受调控细胞死亡

过去二十年的研究表明，一些看起来像坏死的死亡实际上受特定通路控制。**坏死性凋亡**（necroptosis）可由例如caspase-8被阻断时的TNF触发；激酶RIPK1和RIPK3激活蛋白MLKL，后者在质膜上穿孔。**细胞焦亡**（pyroptosis）发生于被微生物感染的巨噬细胞：炎症小体激活caspase-1，后者切割gasdermin D形成膜孔，并释放白细胞介素-1β。**铁死亡**（ferroptosis）是谷胱甘肽过氧化物酶4失效时由脂质过氧化引起的铁依赖性死亡。这些形式都以膜破裂和炎症告终，在感染、缺血和药物研发中具有重要意义，但在诊断组织学中它们看起来就像坏死。其炎症后果在[[pathology/acute-inflammation]]中讨论。

::: quiz
一份淋巴结活检显示散在的单个皱缩细胞，核致密、碎裂，每个细胞周围有透明晕，周围无中性粒细胞。最可能的过程是什么？
- [ ] 凝固性坏死
- [x] 凋亡
- [ ] 液化性坏死
- [ ] 脂肪坏死
::: solution
孤立地逐个死亡、细胞皱缩、染色质凝集碎裂且无炎症，是凋亡的特征。坏死累及成群的细胞，引起肿胀并激发炎症反应。淋巴结生发中心正常就含有许多凋亡的B细胞，被巨噬细胞吞噬。
:::
:::

## 细胞内蓄积

当细胞产生某种物质过多、无法将其分解，或摄取了无法处理的物质时，就可能发生蓄积。蓄积既可以是无害的标志，也可以是疾病的直接原因。

- **脂质。** 甘油三酯在**脂肪变**时蓄积，最常见于肝。原因包括酒精、肥胖和胰岛素抵抗（代谢功能障碍相关脂肪性肝病）以及某些药物。动脉粥样硬化时，胆固醇蓄积在动脉壁的巨噬细胞中，这些充满脂质的细胞称为泡沫细胞。
- **蛋白质。** 过多的蛋白质表现为粉红色小滴。在肾，近端小管细胞重吸收从受损肾小球漏出的蛋白质。大量合成免疫球蛋白的浆细胞可含有称为Russell小体的圆形包涵体。错误折叠的蛋白质可以杀死细胞，如α1-抗胰蛋白酶缺乏症中异常蛋白在肝细胞内蓄积。
- **糖原**蓄积见于糖原贮积病，以及控制不佳的糖尿病时的肾小管。
- **色素。** *脂褐素*是衰老细胞和萎缩细胞中被消化的膜所留下的褐色残渣，无害。*含铁血黄素*是一种金褐色的储铁色素，出现在红细胞崩解的部位（陈旧性瘀伤），或机体铁负荷过多时（血色病、反复输血）。普鲁士蓝（Perls）染色将其显示为蓝色。*黑色素*由黑素细胞产生。来自污染空气或烟雾的*炭末*被肺泡巨噬细胞吞噬并运至淋巴结，使其变黑（炭末沉着症）。

::: example 输血患者的肝 {#ex-iron}
一名24岁女性患重型β地中海贫血，自幼每隔几周输注一次红细胞。肝活检显示肝细胞和库普弗细胞内有金褐色颗粒，普鲁士蓝染色呈蓝色，并有纤维化。解释这些发现。
::: solution
1. 每单位红细胞都含有铁，而机体没有受调控的排铁途径。因此反复输血导致**铁过载**。
2. 过多的铁以铁蛋白及其聚集的不溶性形式**含铁血黄素**储存，后者就是那种金褐色色素。普鲁士蓝染色检测三价铁，并将其染成蓝色。
3. 游离铁通过芬顿反应催化产生羟自由基。由此造成的氧化损伤破坏肝细胞，反复的损伤和修复导致纤维化，最终导致肝硬化。心脏和内分泌腺也会受损。
4. 这就是接受定期输血者需要接受铁螯合治疗并监测铁负荷的原因，遵循专科指导（[[blood/haemoglobin-disorders]]）。
:::
:::

## 病理性钙化

钙盐可能异常地沉积于组织中。病理性钙化有两种，区别在于血钙。

::: definition 营养不良性钙化与转移性钙化 {#def-calcification}
- **营养不良性钙化**是指在血清钙和磷**正常**的情况下，钙盐沉积于死亡或变性的组织中。例如动脉粥样硬化斑块、受损和老化的心瓣膜（钙化性主动脉瓣狭窄）、陈旧性结核的干酪样坏死，以及某些肿瘤（如甲状腺乳头状癌）中所见的同心圆状**砂粒体**。
- **转移性钙化**是指由于血清钙或磷升高，钙盐沉积于**正常**组织中。原因包括原发性甲状旁腺功能亢进症、伴磷潴留和继发性甲状旁腺功能亢进的慢性肾脏病、维生素D中毒，以及肿瘤破坏骨质。它累及排酸而使内部环境偏碱性的组织：肺、肾（肾钙质沉着症）、胃黏膜和动脉壁。
:::

这里的“转移性”与癌毫无关系：它指钙从其正常所在之处（骨）被转移到了其他组织。

::: example 慢性肾脏病中的钙和磷 {#ex-caxp}
一名55岁男性患5期慢性肾脏病，血清钙2.40 mmol/L，血清磷2.10 mmol/L。计算钙磷乘积，并解释他的动脉为何有风险。
::: solution
1. 乘积 $= 2.40 \times 2.10 = 5.04$ mmol²/L²。
2. 传统的经验法则认为，乘积超过约4.4 mmol²/L²（常规单位为55 mg²/dL²）时，磷酸钙在软组织中沉淀的风险增加。他的数值高于此值。
3. 肾不能排泄磷，磷因此升高。暴露于高磷的血管平滑肌细胞改变其行为，主动沉积矿物质，因此晚期肾病中动脉中膜钙化很常见。
4. 现行指南（KDIGO）建议分别管理钙和磷，而不是依赖乘积，因为乘积掩盖了哪一项异常。不过这一计算仍说明了控制血磷的重要性（[[renal/chronic-kidney-disease]]）。
:::
:::

## 细胞衰老

细胞随时间积累损伤。端粒是染色体末端的重复序列，在大多数体细胞中每分裂一次就缩短一些；当端粒缩短到临界长度时，细胞停止分裂（**复制性衰老**）。DNA损伤不断积累，错误折叠的蛋白质清除效率下降，线粒体产生更多的活性氧。衰老细胞分泌炎症细胞因子和蛋白酶，这一特征将衰老与低度慢性炎症联系起来（[[pathology/chronic-inflammation-repair]]）。整个人的衰老见[[geriatrics-palliative/ageing-frailty]]。

::: history
菲尔绍（Rudolf Virchow）的《细胞病理学》（*Die Cellularpathologie*，1858年）提出，疾病是细胞生命活动的紊乱，每个细胞都来自先前存在的细胞。这取代了疾病源于体液失衡的旧观念，使细胞成为病理学的基本单位。**凋亡**一词由克尔（John Kerr）、怀利（Andrew Wyllie）和柯里（Alastair Currie）于1972年提出，他们描述了一种形态独特的细胞死亡形式，并认为它是与细胞分裂互补的受控过程。程序性细胞死亡的遗传基础是在线虫*Caenorhabditis elegans*中阐明的，该线虫在发育过程中恰好有131个细胞死亡；布伦纳（Sydney Brenner）、霍维茨（H. Robert Horvitz）和苏尔斯顿（John Sulston）因这项工作分享了2002年诺贝尔生理学或医学奖。
:::

## 后续内容

细胞死亡引发机体的反应。坏死组织释放信号，募集中性粒细胞，启动**急性炎症**，即[[pathology/acute-inflammation]]的主题。死亡组织随后被清除，并由再生或瘢痕取代（[[pathology/chronic-inflammation-repair]]）。整片组织的缺血性细胞死亡即**梗死**，见[[pathology/haemodynamics]]。从化生到异型增生再到癌的进展是[[pathology/cancer-biology]]的主题。

::: summary
- 细胞对应激的反应是适应、可逆性损伤或死亡。结局取决于损伤的严重程度和持续时间，以及细胞的类型和状态。
- 适应：肥大（细胞增大）、增生（细胞增多）、萎缩（细胞缩小）、化生（另一种成熟细胞类型）。异型增生是生长紊乱，是癌的前驱病变。
- 可逆性损伤主要由ATP耗竭驱动：泵衰竭、细胞水肿和脂肪变。
- 不可逆性损伤以线粒体衰竭和膜损伤为标志，由钙内流和活性氧驱动。细胞蛋白（肌钙蛋白、转氨酶）漏出是细胞死亡的临床标志。
- 坏死类型：凝固性（梗死）、液化性（脓肿、脑）、干酪样（结核）、脂肪坏死、纤维素样坏死；坏疽是临床术语。
- 凋亡是受调控的、由caspase介导的、不引起炎症的死亡，经内源性途径（BCL-2家族、细胞色素*c*、caspase-9）或外源性途径（死亡受体、caspase-8）发生。
- 营养不良性钙化发生于血钙正常的受损组织；转移性钙化发生于钙或磷升高时的正常组织。
:::

::: exercise 可逆还是不可逆？ {level=2}
说出以下各项发现提示可逆性损伤还是不可逆性损伤，并加以解释：(a) 胞质淡染的细胞水肿；(b) 肝细胞脂肪变；(c) 细胞核消失（核溶解）；(d) 血清肌钙蛋白升高；(e) 线粒体肿胀并含有大的无定形致密物。

::: exercise 解释钙化 {level=2}
一名78岁男性血清钙正常，其主动脉瓣严重钙化并狭窄。一名45岁女性患原发性甲状旁腺功能亢进症，双肾有钙沉积。对两者分别分类，并解释机制上的差别。
::: solution
男性为**营养不良性**钙化：数十年的机械应力损伤了瓣叶，钙沉积于受损组织中，而血清钙正常。女性为**转移性**钙化（肾钙质沉着症）：过多的甲状旁腺激素使血清钙升高，钙盐沉淀于正常组织中，尤其是偏碱性的肾间质。前者由局部组织损伤驱动，后者由异常的血液化学驱动。
:::
:::

::: exercise 两种速度的死亡 {level=3}
暴露于低浓度某种毒物的肝细胞逐个死亡，表现为皱缩，无炎症。在高浓度下，成片的肝细胞死亡并肿胀，中性粒细胞聚集。解释同一种毒物为何能产生这两种图像，以及哪项血液检查结果会有不同。
::: hint
凋亡程序需要能量。
:::
::: solution
在低浓度下，细胞受损但保留了足够的ATP来运行凋亡程序。DNA或线粒体损伤激活内源性途径，caspase拆解每个细胞，碎片被巨噬细胞清除而不引起炎症。在高浓度下，ATP崩溃，钙大量涌入，膜在凋亡程序得以运行之前就已破裂，于是细胞发生坏死。其内容物漏出并募集中性粒细胞。第二种情况下血清丙氨酸转氨酶的升高会大得多，因为坏死将细胞内容物释放入血。（凋亡细胞也会释放一些酶，但少得多。）
:::

::: exercise 心脏大而气促的男性 {level=3}
一名66岁男性高血压控制不佳已二十年，现出现气促。超声心动图显示左心室壁增厚、收缩功能减弱。从细胞水平解释一种适应是如何变成疾病的，包括他的心脏为何更易发生缺血。
::: solution
压力超负荷通过牵张和生长因子信号刺激心肌细胞合成更多的收缩蛋白，于是细胞增大（肥大），心室壁增厚。起初这维持了心输出量。然而毛细血管的数量并未相应增加，因此氧需要弥散的距离增大，每个增大的细胞单位质量所得到的血流减少。更厚的心室壁还增加了氧需求。反复发生的相对缺血通过凋亡和坏死导致细胞丢失，丢失的细胞被纤维组织取代，使心室变僵硬。存活的细胞转向效率较低的胎儿型基因表达。这种适应到达了极限，变成了心力衰竭。降低血压可以使肥大部分逆转，这是治疗高血压的理由之一。
