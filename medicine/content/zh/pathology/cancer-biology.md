癌不是一种疾病，而是数百种疾病，但它们遵循共同的逻辑。在每一种癌中，都有一个细胞的DNA发生了改变，使它摆脱了把正常细胞约束在其位置上的控制。它的后代在不该分裂时分裂，在该死亡时存活，侵入本应尊重的组织，并扩散到远处器官。本章解释这是如何发生的：哪些基因发生了改变，改变后的细胞如何表现，是什么导致了这些改变，以及这些知识如何产生了针对肿瘤特定缺陷的治疗。

本章着重于机制。肿瘤如何分类、分级、分期和诊断见[[pathology/cancer-diagnosis]]，遗传性肿瘤综合征的深入讨论见[[genetics/cancer-genetics]]。

## 什么是肿瘤

::: definition 肿瘤 {#def-neoplasm}
**肿瘤**（neoplasm，字面意思是“新生物”）是一种异常的组织团块，其生长超过正常组织且与之不协调，并且在引起它的刺激停止后，仍以同样过度的方式持续生长。**瘤**（tumour）一词原指任何肿块，现在用作肿瘤的同义词。**癌**（cancer）是**恶性**肿瘤的通称，即能够浸润和扩散的肿瘤；**良性**肿瘤则保持局限。
:::

这一定义包含了它与增生（[[pathology/cell-injury]]）的关键区别。增生的组织因刺激而生长，撤除刺激后停止生长。肿瘤是自主的：它持续生长，因为它自身的基因已经改变。

几乎所有肿瘤都是**克隆性**的：每个细胞都来自同一个原始细胞。在女性的肿瘤中，可以通过检查X染色体上的基因来证明这一点。女性的每个细胞在发育早期随机失活一条X染色体，因此正常组织是母源X或父源X处于活性状态的细胞的混合。而肿瘤的所有细胞失活的都是同一条X染色体，因为它们来自同一个细胞。在淋巴组织肿瘤中，克隆性表现为每个细胞都带有相同的免疫球蛋白或T细胞受体基因重排。

## 癌是体细胞的遗传性疾病

::: theorem 癌的发生是克隆演化的多步骤过程 {#thm-multistep}
癌是在一个细胞谱系中积累多种遗传学和表观遗传学改变而发生的。每一个赋予细胞生长或存活优势的改变，都使其后代超过邻近细胞。赋予优势的改变是**驱动**突变；随之携带而没有作用的许多其他突变是**乘客**突变。临床上显现的癌通常含有少数几个驱动突变，是在数年或数十年中获得的。
:::

::: proof
证据来自几个方面。大多数癌的发病率随年龄急剧上升，大致与年龄的某次幂成正比，这正是若干独立的限速事件必须发生在同一个细胞中时所预期的。病理医师可以看到中间阶段：在结肠中，小的良性腺瘤长成大的腺瘤，出现高级别异型增生，然后成为浸润性癌。对这些阶段进行测序显示，它们以典型的顺序积累突变。第一步通常是*APC*基因失活，使腺瘤得以形成；*KRAS*的激活突变使腺瘤生长；*TP53*的丢失伴随向癌的转变。这一**腺瘤-癌序列**由Fearon和Vogelstein于1990年描述。在一个肿瘤内部，细胞不断获得新的突变，因此肿瘤成为相关亚克隆的混合体（**肿瘤内异质性**）。治疗选择出耐药的亚克隆，这解释了为什么起初有效的癌常常复发。
:::

涉及的基因分为三组：促进生长的**癌基因**，限制生长的**抑癌基因**，以及维持基因组完整性的基因，后者的失效会加速前两类改变的积累。

## 癌基因

::: definition 原癌基因与癌基因 {#def-oncogene}
**原癌基因**是其产物促进细胞生长或存活的正常基因。**癌基因**是原癌基因的突变形式或过度表达形式，其产物在不该有活性时具有活性。癌基因以**显性**方式起作用：两个拷贝中的一个发生改变就足以产生效应。
:::

原癌基因编码生长信号到达细胞核的通路中的每一个环节：

- **生长因子**，如PDGF。
- **生长因子受体**，如表皮生长因子受体（*EGFR*）和*HER2*（又称*ERBB2*）。
- **信号转导分子**，如*RAS*和*BRAF*。RAS是一个分子开关，结合GTP时处于“开”的状态，通过把GTP水解为GDP而自行关闭。突变的RAS不能水解GTP，因此一直处于“开”的状态。*KRAS*突变见于大多数胰腺癌以及许多结直肠癌和肺癌。*BRAF* V600E突变常见于黑色素瘤。
- **转录因子**，如*MYC*，它开启生长所需的许多基因。
- **细胞周期调节因子**，如细胞周期蛋白D1和细胞周期蛋白依赖性激酶CDK4。

原癌基因通过三种主要方式变成癌基因：

1. **点突变**，改变蛋白质的结构，使其持续活化（*RAS*、*BRAF*、*EGFR*）。
2. **基因扩增**，产生基因的许多拷贝，从而产生过多的正常蛋白。约15%至20%的乳腺癌有*HER2*扩增，某些神经母细胞瘤有*MYCN*扩增。
3. **染色体易位**，或者把一个基因置于强启动子的控制之下（伯基特淋巴瘤中，t(8;14)易位把*MYC*置于免疫球蛋白基因旁），或者把两个基因融合产生一种新蛋白（慢性髓细胞性白血病中，t(9;22)易位产生费城染色体和*BCR::ABL1*融合基因）。

::: example 白细胞计数升高 {#ex-cml}
一名52岁女性乏力，左肋下不适。白细胞计数$180 \times 10^9$/L，可见各个成熟阶段的中性粒细胞和中幼粒细胞，脾肿大。细胞遗传学显示t(9;22)(q34;q11)。解释其分子基础及治疗方法。
::: solution
1. 该易位把22号染色体上*BCR*基因的一部分与9号染色体上的*ABL1*基因连接起来。缩短的22号染色体就是**费城染色体**。
2. 融合基因*BCR::ABL1*编码一种持续活化的酪氨酸激酶。它驱动髓系细胞增殖，并保护它们免于凋亡。这就是**慢性髓细胞性白血病**。
3. 由于该病由单一的致癌激酶驱动，抑制它非常有效。**伊马替尼**（imatinib）是针对BCR::ABL1设计的酪氨酸激酶抑制剂，是第一个此类药物；随后出现了更新的药物。
4. 有了这些药物，大多数慢性期CML患者现在的预期寿命接近正常。通过测定血液中*BCR::ABL1*转录本来监测疗效。激酶结构域的突变可导致耐药，这是耐药亚克隆被选择的一个例子（[[blood/leukaemia]]）。
:::
:::

## 抑癌基因

::: definition 抑癌基因 {#def-tsg}
**抑癌基因**是其产物限制细胞生长或促进受损细胞死亡的基因。癌源于**功能丧失**，这通常需要细胞中该基因的**两个**拷贝都失活。
:::

::: theorem Knudson二次打击假说 {#thm-two-hit}
对于抑癌基因，需要两次“打击”（失活事件），每个等位基因各一次，细胞才会失去控制。在遗传性肿瘤综合征中，第一次打击遗传而来，存在于每个细胞中，只需获得第二次打击，因此肿瘤出现得更早，常为多发，并可能为双侧。在散发性癌中，两次打击必须在同一个细胞中获得，因此肿瘤出现得较晚，且通常为单发。
:::

克努森（Alfred Knudson）于1971年根据**视网膜母细胞瘤**（一种幼儿眼部肿瘤）的统计学资料提出了这一假说。遗传型患儿发病更早，且常累及双眼。其基因*RB1*后来被鉴定出来。一个常见的推论是，抑癌基因的遗传性突变在家系中表现为**显性遗传**，因为第二次打击几乎必然会在某个细胞中发生，但在每个细胞中却以**隐性**方式起作用。第二次打击常常是包含正常等位基因的整个区域的丢失，称为**杂合性丢失**。

最重要的抑癌基因有：

- ***RB1***基因的蛋白产物**RB**控制细胞周期从G1期到S期的转换。其活性形式结合转录因子E2F，阻止细胞进入S期。生长信号激活细胞周期蛋白D和CDK4/6，后者使RB磷酸化并释放E2F。几乎每一种癌都以某种方式使这一检查点失效：丢失RB、过表达细胞周期蛋白D或CDK4，或丢失CDK抑制因子p16。CDK4/6抑制剂用于激素受体阳性的乳腺癌。
- ***TP53***的产物**p53**是“基因组的守护者”。它通常被MDM2维持在低水平，MDM2使其被降解。DNA损伤、癌基因活性和缺氧使p53稳定。随后它使细胞周期停止（通过CDK抑制因子p21）以便修复；如果损伤无法修复，它就触发凋亡或永久性衰老。*TP53*是人类癌症中突变最频繁的基因。遗传性突变引起**Li-Fraumeni综合征**，在年轻时发生肉瘤、乳腺癌、脑肿瘤和其他癌。
- **APC**通过促进β-连环蛋白的降解来控制WNT信号通路。APC丢失时，β-连环蛋白蓄积，进入细胞核并开启生长基因。遗传性突变引起**家族性腺瘤性息肉病**，结肠有数百至数千个腺瘤，若不切除结肠，几乎必然发生结直肠癌。
- 其他还包括*BRCA1*和*BRCA2*（DNA修复）、*PTEN*（拮抗PI3K-AKT生长通路）、*NF1*（关闭RAS）、*VHL*（控制对缺氧的反应；在透明细胞肾细胞癌中丢失）以及*CDKN2A*（编码p16）。

::: warning 家系中显性，细胞中隐性
学生常常推断，既然家族性肿瘤综合征以常染色体显性方式遗传，那么突变的抑癌基因必定以显性方式起作用。并非如此。一个正常拷贝就足以控制细胞。遗传下来的是一种大大增加的概率：在数十亿个细胞中，至少有一个细胞会丢失剩余的那个拷贝。这就是为什么携带相同遗传突变的人发生癌的年龄差别很大，也是为什么胚系检测结果描述的是风险而不是必然（[[genetics/cancer-genetics]]）。
:::

::: quiz
一名8个月大的患儿双眼发生视网膜母细胞瘤。哪一项最能解释其双侧、早发的疾病？
- [ ] 两个*RB1*拷贝都以突变形式遗传。
- [x] 每个细胞都遗传了一个突变的*RB1*拷贝，因此每个肿瘤只需要再发生一次体细胞打击。
- [ ] *RB1*是癌基因，因此一次突变就足够了。
- [ ] 患儿在妊娠期暴露于致癌物。
::: solution
在遗传性视网膜母细胞瘤中，每个视网膜细胞都已带有第一次打击。数百万个视网膜细胞中任何一个再发生一次体细胞事件就足够了，因此肿瘤出现早，且常累及双眼。两个突变拷贝都遗传通常与生命不相容，*RB1*是抑癌基因，而且不需要环境原因。
:::
:::

## 基因组不稳定性与表观遗传改变

当细胞修复DNA的系统失效时，突变积累得更快。因此**基因组不稳定性**被称为癌的一种*促成*特征：它本身不使细胞恶变，但加快了获得那些致恶变改变的速度。

- **错配修复**纠正DNA复制时产生的错误。当它失效时，错误不断积累，尤其是在称为微卫星的短重复序列中，其长度发生改变：即**微卫星不稳定性**（MSI）。错配修复基因的遗传性缺陷引起**林奇综合征**（Lynch syndrome，结直肠癌、子宫内膜癌及其他癌）。在散发性肿瘤中，最常见的原因是*MLH1*基因因甲基化而沉默。
- **同源重组**以姐妹染色单体为模板准确修复双链断裂。它需要BRCA1和BRCA2。缺乏同源重组的细胞依赖其他易出错的通路，对**PARP抑制剂**高度敏感，这一原理称为合成致死。
- **核苷酸切除修复**清除紫外线引起的损伤。它在**着色性干皮病**中的遗传性失效导致年轻时发生多发性皮肤癌。
- **染色体不稳定性**，即整条染色体或大片段的获得和丢失，在大多数癌中很常见。

**表观遗传**改变改变基因表达而不改变DNA序列。抑癌基因可因其启动子甲基化而沉默，如*MLH1*和*CDKN2A*。修饰染色质的酶的突变在癌中很常见。代谢酶异柠檬酸脱氢酶（IDH）的突变形式见于某些胶质瘤和白血病，它产生2-羟戊二酸，后者阻断去除DNA和组蛋白甲基的酶。由于表观遗传改变是可逆的，抑制DNA甲基化或突变型IDH的药物已用于某些癌。

::: example 年轻女性的结直肠癌 {#ex-msi}
一名38岁女性患右半结肠癌。她的母亲48岁时患子宫内膜癌。肿瘤的免疫组织化学显示错配修复蛋白MSH2和MSH6缺失，肿瘤呈微卫星不稳定。解释这些发现及其意义。
::: solution
1. MSH2和MSH6（二者成对发挥作用）缺失意味着错配修复失效，由此导致的微卫星内错误积累解释了不稳定性。
2. 她的年轻发病和母亲的子宫内膜癌提示遗传性缺陷：**林奇综合征**，即胚系*MSH2*突变加上肿瘤中的第二次打击。与MLH1缺失不同，MSH2缺失很少由甲基化引起。
3. 应转诊她接受遗传咨询和胚系检测。如果发现突变，可以检测亲属，并为其提供结肠镜监测和降低风险的措施。在英国，NICE正是出于这一原因，建议对所有结直肠癌和子宫内膜癌检测错配修复缺陷。
4. MSI-高的肿瘤携带大量突变，产生免疫系统能够识别的异常蛋白（**新抗原**）。这就是此类肿瘤在晚期时对免疫检查点抑制剂反应良好的原因。
:::
:::

## 癌的特征

2000年，哈纳汉（Douglas Hanahan）和温伯格（Robert Weinberg）提出，种类繁多的癌可以通过每一种癌都必须获得的少数几种能力来理解。他们的框架在2011年和2022年得到扩展。

::: theorem 癌的特征 {#thm-hallmarks}
细胞要成为恶性肿瘤，需要获得一组功能性能力：

1. **维持增殖信号**：癌基因使生长通路保持开启。
2. **逃避生长抑制**：丢失RB、p53和其他“刹车”。
3. **抵抗细胞死亡**：丢失p53，过表达BCL-2。
4. **实现复制永生**：重新激活端粒酶。
5. **诱导血管生成**：募集新生血管。
6. **激活浸润和转移**。
7. **重编程细胞代谢**（2011年增补）。
8. **逃避免疫摧毁**（2011年增补）。

两项**促成特征**使这些能力得以获得：**基因组不稳定性与突变**，以及**促进肿瘤的炎症**。2022年的更新提出了更多候选特征，包括表型可塑性的解锁、衰老细胞、非突变性表观遗传重编程以及微生物组的影响。
:::

这一框架的价值在于，每一种特征都是潜在的治疗靶点：

| 特征 | 靶向治疗举例 |
|---|---|
| 增殖信号 | 针对HER2的曲妥珠单抗；*EGFR*突变肺癌的EGFR抑制剂；黑色素瘤的BRAF抑制剂 |
| 逃避生长抑制 | 激素受体阳性乳腺癌的CDK4/6抑制剂 |
| 抵抗细胞死亡 | 慢性淋巴细胞白血病的BCL-2抑制剂 |
| 血管生成 | 抗VEGF抗体（贝伐珠单抗） |
| 逃避免疫摧毁 | 抗PD-1、PD-L1或CTLA-4抗体 |
| 基因组不稳定性 | *BRCA*突变癌的PARP抑制剂 |

### 无限复制

正常人体细胞只能分裂有限的次数，因为端粒随每次分裂而缩短，直到细胞进入衰老（[[pathology/cell-injury]]）。大多数癌重新激活**端粒酶**（重建端粒的酶），少数采用一种替代性的重组机制。否则，一个克隆在达到有意义的大小之前很早就会停止生长。

### 代谢改变

即使在氧充足时，癌细胞也大量摄取葡萄糖，并把其中大部分转化为乳酸。这种**有氧糖酵解**（瓦博格效应）看似浪费，但它为分裂中的细胞提供了合成新膜、蛋白质和核酸所需的碳骨架。葡萄糖的高摄取是**FDG-PET**成像的基础，它使用一种放射性葡萄糖类似物来显示肿瘤及其转移灶。

### 血管生成

没有自己的血供，肿瘤的直径无法超过约1至2 mm，因为氧只能弥散很短的距离。缺氧使转录因子**HIF-1α**稳定，后者开启**VEGF**和其他促血管生成因子。由此形成的血管渗漏、迂曲且排列紊乱。在透明细胞肾细胞癌中，*VHL*基因丢失使HIF即使在正常氧浓度下也保持稳定，这就是这类肿瘤血管极其丰富的原因。

## 浸润与转移

**转移**，即肿瘤扩散到远处部位，是癌症死亡的主要原因。它需要一系列步骤，而能完成每一步的细胞都很少。

1. **黏附性丧失。** 癌细胞通常通过**E-钙黏着蛋白**彼此黏附。E-钙黏着蛋白丢失使细胞得以脱离。许多癌细胞部分地获得间充质细胞的特征（**上皮-间质转化**），变得更具运动性。
2. **侵袭基底膜和间质。** 肿瘤细胞及其周围的间质细胞分泌**基质金属蛋白酶**等蛋白酶，降解细胞外基质。穿过基底膜正是浸润性癌与原位癌的分界。
3. **侵入脉管。** 细胞进入淋巴管或血管。
4. **在循环中存活。** 大多数循环肿瘤细胞死亡。存活者部分依靠以血小板包裹自身而得到保护。
5. **逸出血管与定植。** 细胞在远处器官离开血管，然后必须在那里生长。许多细胞在生长前休眠多年，这解释了晚期复发，例如乳腺癌。

肿瘤通过三种主要途径扩散：

- **淋巴道转移**，是癌的典型途径，首先到达区域淋巴结。最先接受引流的淋巴结是**前哨淋巴结**，在乳腺癌和黑色素瘤中进行取样。
- **血道转移**，是肉瘤的典型途径，但在癌中也很常见。静脉比动脉更容易被侵犯。经门静脉引流的肿瘤（来自胃肠道）首先转移到肝；经体静脉引流的肿瘤转移到肺。
- **种植性转移**，跨越体腔播散，如卵巢癌在腹膜上种植。

转移的分布模式不能仅用血流来解释。佩吉特（Stephen Paget）于1889年提出，肿瘤细胞（“种子”）只在相容的器官（“土壤”）中生长。例如前列腺癌偏好骨，这种偏好取决于肿瘤细胞与局部环境之间的相互作用。

### 逃避免疫系统

免疫系统能够识别癌细胞，因为突变的蛋白质会产生新的抗原。临床上显现的癌已经逃脱了这种监视。一个关键机制是利用**免疫检查点**，即正常情况下防止T细胞损伤机体的“关闭开关”。肿瘤细胞可表达**PD-L1**，后者与T细胞上的PD-1结合，使其失活。阻断PD-1、PD-L1或CTLA-4的抗体解除了这一刹车，彻底改变了黑色素瘤、肺癌、MSI-高癌及其他癌的治疗（[[immunology/transplant-tumour-immunology]]）。由于它们普遍解除了对免疫的制约，几乎可以在任何器官引起自身免疫性副作用。

## 肿瘤生长

肿瘤生长常用其**倍增时间**来描述。一个从单个细胞开始的肿瘤，需要约30次倍增才能含有$10^9$个细胞，约相当于1 cm、重1 g的肿块，这是通常能在临床上发现的最小尺寸。再倍增10次，就会有$10^{12}$个细胞，约1 kg，这样的肿块常常是致命的。因此，肿瘤生命史的大部分在被发现之前就已过去，从被发现到死亡只隔着为数不多的几次倍增。

::: example 这个肺结节长得多快？ {#ex-vdt}
一名64岁吸烟女性的CT显示一个直径8 mm的实性肺结节。三个月（90天）后它为10 mm。假设它是一个呈指数生长的球体，计算其体积倍增时间。
::: solution
1. 体积与直径的立方成正比，所以$V_2/V_1 = (10/8)^3 = 1.953$。
2. 对于指数生长，体积倍增时间为$\text{VDT} = \dfrac{t \ln 2}{\ln(V_2/V_1)}$。
3. $\text{VDT} = \dfrac{90 \times 0.693}{3 \ln 1.25} = \dfrac{62.4}{0.669} \approx 93$天。
4. 在英国胸科学会的肺结节指南中，体积倍增时间小于约400天是恶性的特征，93天完全落在这一范围内。极短的倍增时间（数周）则提示感染或炎症。这个结节需要进行肺癌检查（[[respiratory/lung-cancer-pleura]]）。
5. 注意测量的敏感性：直径2 mm的变化相当于体积几乎加倍，因此小的测量误差也很重要。更推荐使用容积测量软件。
:::
:::

## 癌的病因

驱动癌的突变有三个来源：DNA复制过程中的随机错误，随细胞分裂次数增加而增多；遗传变异；以及环境暴露。许多常见癌与可以避免的暴露密切相关。

**化学致癌物。** 化学致癌分两个阶段。**启动**是由诱变剂引起的DNA永久性改变。**促进**是由本身不是诱变剂的物质（如激素或慢性刺激）刺激已启动细胞的增殖。有些致癌物直接起作用，如化疗所用的烷化剂，可在日后引起白血病。大多数需要被肝脏或组织中的酶活化：烟草烟雾中的苯并[a]芘、**黄曲霉毒素B1**（来自储存谷物和坚果上的霉菌，是非洲和亚洲部分地区肝癌的主要原因，引起一种特征性的*TP53*突变），以及引起染料和橡胶工人膀胱癌的芳香胺。烟草和酒精见[[pathology/environmental-pathology]]。

**辐射。** 中波紫外线（UVB）在DNA中引起嘧啶二聚体，导致皮肤癌（[[musculoskeletal/skin-cancer]]）。电离辐射引起双链断裂和染色体重排；原子弹幸存者白血病和实体癌增加，切尔诺贝利事故后暴露于放射性碘的儿童发生了甲状腺乳头状癌。

**感染因子。**

| 病原体 | 癌 | 机制简述 |
|---|---|---|
| 高危型人乳头瘤病毒（HPV 16、18及其他） | 宫颈癌、肛门癌、口咽癌及其他癌 | 病毒E6蛋白降解p53；E7结合并使RB失活 |
| EB病毒 | 伯基特淋巴瘤、鼻咽癌、部分霍奇金淋巴瘤 | 病毒蛋白驱动B细胞增殖和存活 |
| 乙型和丙型肝炎病毒 | 肝细胞癌 | 主要是慢性炎症、细胞死亡和再生，通常伴肝硬化 |
| HTLV-1 | 成人T细胞白血病/淋巴瘤 | 病毒Tax蛋白激活生长基因 |
| 人类疱疹病毒8型 | 卡波西肉瘤，尤其在免疫抑制时 | 病毒蛋白促进增殖和血管生成 |
| 幽门螺杆菌 | 胃腺癌、胃MALT淋巴瘤 | 慢性炎症；根除后淋巴瘤可消退 |
| 埃及血吸虫 | 膀胱鳞状细胞癌 | 慢性炎症 |

::: example HPV为何引起宫颈癌 {#ex-hpv}
一名34岁女性的宫颈筛查样本高危型HPV阳性，细胞学显示高级别核异质。阴道镜活检证实为CIN 3。解释病毒如何引起癌，以及为什么大多数HPV感染不会。
::: solution
1. 高危型HPV感染宫颈上皮的基底细胞。在大多数人中，免疫系统在一到两年内清除感染，因此大多数感染从不致病。
2. 在持续感染中，病毒DNA可能整合进宿主基因组。这常常破坏正常情况下抑制癌基因**E6**和**E7**表达的病毒基因，于是它们大量产生。
3. E6促进**p53**的降解，于是细胞在DNA损伤时不再停滞或死亡。E7结合**RB**并释放E2F，于是细胞在没有生长信号时进入S期。两个关键的抑癌基因同时失效。
4. 随之出现遗传不稳定，更多突变积累。结果先是异型增生（CIN），经过数年后成为浸润性癌。
5. CIN 3需要治疗，通常是切除转化区，以预防浸润性癌。英国的HPV疫苗接种计划和以HPV为初筛的筛查旨在预防这些改变；筛查见[[pathology/cancer-diagnosis]]。
:::
:::

::: history
1775年，伦敦外科医生波特（Percivall Pott）把扫烟囱工人的阴囊癌与他们接触烟灰联系起来，这是对职业性癌的首次描述。1889年，佩吉特（Stephen Paget）研究乳腺癌转移灶的分布后，提出了转移的“种子与土壤”学说。1911年，劳斯（Peyton Rous）用无细胞滤液在鸡之间传播肉瘤，证明病毒能够致癌；他于1966年获得诺贝尔奖。1915年，山极胜三郎（Katsusaburo Yamagiwa）和市川厚一（Koichi Ichikawa）在兔耳上涂抹煤焦油诱发皮肤癌，这是首次实验性化学致癌。1976年，毕晓普（J. Michael Bishop）和瓦默斯（Harold Varmus）证明劳斯肉瘤病毒的致癌基因是被病毒捕获的一个正常细胞基因，从而确立了原癌基因的概念；他们于1989年获得诺贝尔奖。克努森（Alfred Knudson）的二次打击假说（1971年）以及哈纳汉和温伯格的癌的特征（2000年）为这一领域提供了组织性的思想。
:::

## 后续内容

同样的机制在每个器官中重现：结直肠癌见[[gastrointestinal/gi-bleeding-cancer]]，肺癌见[[respiratory/lung-cancer-pleura]]，白血病和淋巴瘤见[[blood/leukaemia]]和[[blood/lymphoma-myeloma]]。肿瘤如何命名、分级、分期和筛查是[[pathology/cancer-diagnosis]]的主题，病理医师如何在组织中检测癌基因和修复缺陷见[[pathology/diagnostic-pathology]]。

::: summary
- 肿瘤是一种自主的克隆性生长，刺激去除后仍持续存在；恶性肿瘤浸润和转移。
- 癌通过一个细胞谱系中驱动突变的积累（克隆演化）而发生，如腺瘤-癌序列：先是*APC*，然后是*KRAS*，再是*TP53*。
- 癌基因是被激活的原癌基因，以显性方式起作用，激活方式包括点突变（*RAS*、*BRAF*）、扩增（*HER2*）或易位（*BCR::ABL1*、*MYC*）。
- 抑癌基因需要两次打击。RB控制G1/S检查点，p53对DNA损伤作出反应，APC控制β-连环蛋白。
- DNA修复（错配修复、同源重组）失效和表观遗传沉默加速癌的发生，并产生治疗靶点。
- 癌的特征包括持续增殖、逃避生长抑制和细胞死亡、永生化、血管生成、浸润和转移、代谢改变以及免疫逃逸，由基因组不稳定性和炎症促成。
- 转移需要黏附性丧失、侵袭、进入脉管、存活和定植；扩散途径为淋巴道、血道或种植性。
- 约30次倍增产生可被发现的1 cm肿瘤；肿瘤生命的大部分是看不见的。
- 致癌因素包括化学物质、辐射以及HPV、EBV、乙型和丙型肝炎病毒和幽门螺杆菌等感染因子。
:::

::: exercise 癌基因还是抑癌基因？ {level=1}
将下列基因分为癌基因或抑癌基因，并说明它在癌中通常如何改变：(a) *KRAS*；(b) *TP53*；(c) *HER2*；(d) *APC*；(e) 伯基特淋巴瘤中的*MYC*。
::: solution
(a) 癌基因，激活性点突变。(b) 抑癌基因，两个等位基因均失活（常为一个突变加另一个等位基因丢失）。(c) 癌基因，扩增。(d) 抑癌基因，两个等位基因均失活。(e) 癌基因，t(8;14)易位使其受免疫球蛋白启动子控制。
:::

从单个细胞开始，需要多少次倍增才能达到$10^9$个细胞？四舍五入到整数。
::: solution
$\log_2(10^9) = 29.9$，所以约30次倍增。

::: exercise 扩散途径 {level=1}
给出下列肿瘤远处扩散的典型首发部位及原因：(a) 结肠癌；(b) 大腿肉瘤；(c) 卵巢癌。
::: solution
(a) 肝，因为结肠经门静脉引流（通常先累及淋巴结）。(b) 肺，因为肉瘤经血道扩散，而体静脉回流到肺。(c) 腹膜，经腹腔种植性播散。

::: exercise 体积倍增时间 {level=2 check="round(60*log(2)/(3*log(1.2)))"}
一个肺结节在60天内直径从10 mm长到12 mm。假设它是一个呈指数生长的球体，计算其体积倍增时间（天），四舍五入到整数天。
::: hint
$\text{VDT} = \dfrac{t \ln 2}{3 \ln(d_2/d_1)}$。
:::
::: solution
$\text{VDT} = \dfrac{60 \times 0.693}{3 \ln 1.2} = \dfrac{41.6}{0.547} \approx 76$天，符合恶性。

::: exercise 两种病毒蛋白 {level=2}
解释HPV蛋白E6和E7各自如何使细胞的一个主要抑癌基因失效，以及为什么两者同时失效比任何一个单独失效更危险。
::: solution
E6使p53被降解，于是细胞在DNA损伤时不再停滞或凋亡。E7结合RB并释放E2F，于是细胞在没有生长信号时进入S期。两者结合，细胞被驱动分裂（由于RB丢失），却在由此产生DNA损伤时无法停止或死亡（由于p53丢失）。任何一个单独作用都会触发另一个的防御：非计划性增殖通常会激活p53，从而杀死细胞。当两者都失效时，受损细胞持续分裂，并积累更多突变。
:::
:::

::: exercise 把治疗与特征相匹配 {level=2}
说出下列每种治疗所针对的特征及其起效的分子原因：(a) 胚系*BRCA1*突变的卵巢癌使用PARP抑制剂；(b) MSI-高的结直肠癌使用PD-1抗体；(c) 雌激素受体阳性的乳腺癌使用CDK4/6抑制剂。
::: solution
(a) 基因组不稳定性：缺乏BRCA1的肿瘤细胞不能通过同源重组修复双链断裂，阻断PARP使它们无法修复DNA损伤，因而死亡（合成致死），而有一个正常*BRCA1*拷贝的正常细胞得以存活。(b) 逃避免疫摧毁：MSI-高肿瘤有许多新抗原，阻断PD-1使T细胞得以攻击它们。(c) 逃避生长抑制：CDK4/6抑制剂使RB保持活性，E2F保持结合状态，细胞无法通过G1/S检查点。
:::

::: exercise 解读时间进程 {level=3}
一名60岁男性的肺结节在一次扫描中为6 mm，12个月后再次扫描仍为6 mm。一位同事说：“它没有长大，所以是良性的。”利用体积倍增时间和测量误差的概念，讨论这种说法是否合理。
::: hint
计算体积倍增时间为400天时，一年内直径会变化多少。
:::
::: solution
若体积倍增时间为400天，365天后体积将为原来的$2^{365/400} \approx 1.88$倍，相当于直径增大到$1.88^{1/3} \approx 1.23$倍，即从6 mm增至约7.4 mm。生长更慢的癌，倍增时间为600天，会长到约6.9 mm，变化不到1 mm，接近人工测量的误差。因此，对于小结节，直径稳定令人放心，但并不能下定论：某些腺癌，尤其是部分实性的腺癌，生长非常缓慢。这就是指南使用容积测量、按结节类型设定随访间隔的原因，也是“没有生长”要在一个最短期限内来定义的原因。
:::
:::

::: exercise 两名患者，同一个基因 {level=3}
两名女性的乳腺癌都有*TP53*突变。一名62岁，无家族史；另一名29岁，她的弟弟15岁时患骨肉瘤，母亲40岁时患脑肿瘤。解释同一个基因为何能在两者中都起作用，第二例提示什么，以及这一区别为什么对治疗和家庭很重要。
::: solution
对于62岁的女性，两次*TP53*打击最可能都是体细胞性的，是在数十年间乳腺细胞的普通克隆演化中获得的；*TP53*是癌中最常突变的基因。对于29岁的女性，年轻发病以及肉瘤和脑肿瘤的家族模式提示**Li-Fraumeni综合征**：胚系*TP53*突变，任何细胞只需再发生一次打击。这一区别很重要，因为胚系检测可以确诊并使亲属得以接受级联检测；Li-Fraumeni综合征患者会接受强化监测，常包括全身MRI；而且由于他们的细胞对辐射诱发的癌敏感，会尽可能减少放疗和CT暴露，这可能影响手术选择，例如选择乳房切除术而不是保乳手术加放疗。决策遵循专科遗传学和肿瘤学的指导。
:::
