癌症生物学研究的是体细胞如何变成一种疾病：一个由突变、选择与适应构成的演化过程，被装进一个由组织、血管、免疫与基质构成的生态系统，并在被诊断之后的多年里继续演化。**本章覆盖体细胞演化（驱动对搭乘、突变景观与突变的原因）、生长控制的电路（原癌基因与抑癌基因与它们的剂量与通路）、以及“特征”的清单（获得增殖的信号与逃避生长抑制与抵抗死亡与 无限的复制潜力与血管生成与侵袭与转移与免疫逃逸与代谢的重编程与基因组的不稳定与肿瘤微环境）。**

## 体细胞演化

::: definition 驱动、搭乘与突变景观 {#def-somatic}
**肿瘤是一个演化的群体：每一个癌症都始于一个获得了某种生长优势的细胞，其后代在突变的产生、选择的压力与随机的漂变之间继续多样化。驱动突变是那些给予选择优势并被扩大的改变（在一个基因的通路上反复出现、并有功能实验支持），而搭乘突变只是搭车者——它们很多但不成因；区分二者靠统计学（在数千例中某基因的突变频率高于背景的期望）与机制（通路的收敛与功能的效应）。突变景观的内容有明确的来源：自发的脱氨基与复制的错误与吸烟的加合物与紫外线与芳香胺与马兜铃酸与错配修复缺陷与同源重组缺陷与载脂蛋白B编辑与天冬氨酸的脱氨与化疗（尤其是烷化剂与后来的治疗相关的骨髓肿瘤）与APOBEC在膀胱癌中的成簇——一份突变标本的“特征”因而可以回溯病因，这是分子病理最惊人的能力之一，也把流行病学变成了可在切片上读的东西。突变负荷本身有临床含义：高负荷（错配修复缺陷与人乳头状病毒相关者与吸烟者的癌）通常意味着更多的新抗原，因而对免疫检查点的抑制更可能响应——这是“突变的数量”变成治疗决定的一个例子——[[genetics/cancer-genetics]]、[[immunology/transplant-tumour-immunology]]、[[pharmacology/patient-variation]]。 克努德森 的两击假说把这一切连到年龄与遗传：多数癌症需要数次的事件累积，因此发病率随年龄呈幂律上升；而当第一次事件由生殖细胞带来（遗传的视网膜母细胞瘤与 林奇综合征与 BRCA1），曲线整体左移且早发，且同一个体的多发与双侧病变变得常见——[[genetics/chromosomal-disorders]]。**
:::

::: definition 生长的控制电路 {#def-circuitry}
**癌基因是正常基因的获得性功能版本（原癌基因变成癌基因：点突变与扩增与重排与启动子的改变），其逻辑是“踩住的油门”：RAS 家族在三分之一的人类癌症中被激活（且不同亚型的密码子偏好不同，因此 KRAS 的G12C 共价抑制剂是药物化学的一个胜利）、RAF 与 MAP 通路的组成性激活、以及受体酪氨酸激酶的过度表达或配体自分泌（HER2 与 EGFR 与 ALK 与 NTRK 的融合）。抑癌基因是失去功能的一翼，遵循“两个等位基因都要失守”的隐性规则（杂合性丢失与启动子的甲基化与无义介导的衰变），其清单由细胞周期的检查点（RB1 与 E2F 的轴与细胞周期蛋白的依赖激酶的抑制药如 CDKN2A）、基因组的守卫（TP53 在半数以上的人类癌症中被改变，且其突变的类型决定了显性负性与获得功能的表型）、DNA 的修复（错配修复的 MLH1 与 MSH2 与 BRCA1 与 BRCA2；它们失守时产生可被利用的“合成致死”窗口——聚ADP核糖聚合酶抑制药在同源重组缺陷中的机制）、以及细胞黏附与抑癌的信号（APC 与 WNT 通路在结直肠的“起始”作用，与 SMAD4 与 PTEN 与 VHL 在不同器官的门户角色）——[[genetics/mendelian-inheritance]]、[[pathology/cancer-diagnosis]]。剂量与时机同样关键：同一个通路在胚胎与成人与肿瘤中的后果不同（某些通路的激活引起不可逆的衰老而非增殖，这解释了为何单纯抑制一个节点常常不够）；而“通路冗余与反馈”是耐药的一般原因（抑制 MAPK 会导致上游受体的再激活，因此联合与顺序的策略在生物学上是必然的而非经验主义）——[[pharmacology/drug-receptor]]。**
:::

## 特征在行动

::: definition 血管生成、侵袭、代谢与免疫逃逸 {#def-hallmarks}
**实体瘤在数毫米内会撞上扩散的极限，于是获得血管：缺氧诱导因子稳定后驱动血管内皮生长因子与其他因子的表达，新生的血管形态异常而渗漏（这也是抗血管生成药物使血管“正常化”从而短期改善给药与缺氧的悖论性机制）；临床的实现包括贝伐珠单抗与雷珠单抗在眼科的不同用途与受体酪氨酸激酶抑制药与甲状腺与肾的富血管肿瘤的处理——[[gastrointestinal/liver-disease]]、[[nervous-system/sensory-systems]]。侵袭与转移是效率极低的过程（进入血管的肿瘤细胞绝大多数死亡），它需要上皮的-间质的程序（E-钙黏蛋白的丢失与 蜗牛家族转录因子 与 TWIST 与 ZEB、以及基质金属蛋白酶对基底的降解）与“种子与土壤”的匹配（转移的器官偏好由趋化因子受体与整合素与器官的微环境决定：乳腺到骨与肺与肝与脑、前列腺到骨、结直肠到肝、肺到肾上腺与脑与骨），以及转移前灶的准备（肿瘤来源的囊泡与髓系的细胞先改造目标器官）；骨转移的溶骨与成骨混合与“种子与土壤”在临床上表现为疼痛与病理骨折与高钙与脊髓的压迫——[[musculoskeletal/skin-cancer]]、[[nervous-system/motor-systems]]。代谢的重编程（有氧糖酵解与“瓦尔堡效应”与谷氨酰胺与脂质与乳酸的使用）既是生物量与能量的需要，也是被癌基因与抑癌基因的通路塑造的结果，并构成了正电子发射断层成像的显像原理；而免疫的编辑（清除与平衡与逃逸）解释了为何肿瘤会下调人类白细胞抗原与上调配体的程序（程序性死亡配体1与2）并募集调节性的细胞与髓系的抑制细胞——这一环被检查点的抑制药转化为治疗（以及它带来的自身免疫样不良反应与“并非人人有效”的生物标志物困境）——[[immunology/transplant-tumour-immunology]]、[[clinical-skills/medical-imaging]]、[[endocrine/adrenal]]。**
:::

::: example 遗传性癌症的线索 {#ex-lyynch}
一名44岁的结直肠癌患者，肿瘤显示错配修复蛋白的缺失与高度的微卫星不稳定；他的父亲五十多岁死于子宫内膜癌，一位叔叔死于输尿管癌。
::: solution
**从切片到家族（[[#def-somatic]]、[[#def-circuitry]]、[[genetics/cancer-genetics]]）：这不是巧合：错配修复的缺失加微卫星不稳定加家族中结直肠与子宫内膜与上尿路的肿瘤，构成林奇综合征的典型图案（常染色体显性的生殖系突变，附加的体细胞失守，以及“可被免疫识别的”高突变肿瘤）；筛查的路径是先前的免疫组化与分子（微卫星不稳定性或突变或甲基化的组合），并用它把有限的遗传检测能力用在最可能阳性的人身上（这就是为什么“对所有确诊的结直肠癌做错配修复的筛查”在多数国家已成为常规，而它同时是治疗决策与遗传诊断的入口）——[[pathology/cancer-diagnosis]]、[[gastrointestinal/gi-bleeding-cancer]]。对这位患者当下的意义有两层：一，微卫星高度不稳定的II期结直肠癌的预后较好且不从5-氟尿嘧啶单药的辅助治疗获益，而转移期的它对程序性死亡受体的抑制敏感——即同一个标志同时改变了分期与治疗；二，风险降低的手术问题（更大范围的结肠切除与是否需要同时切除子宫与卵巢）应当在术前被讨论而不是在并发症之后（这是遗传性肿瘤外科最容易做错的一次谈话，因为它同时涉及癌症的预防与生育与性的功能与身体的形象）——[[obstetrics-gynaecology/gynaecological-cancer]]、[[surgery/gastrointestinal-surgery]]。家族的一层：把谱系画到三代并写明年龄与部位；转介到遗传服务（先证者的检测最经济，其阴性结果的意义要在家族史背景下解释）；并给出亲属的方案（从二十至二十五岁开始的结肠镜与间隔与妇科的筛查与教育性的症状报告，以及这些筛查已被证明降低死亡）；同时处理“为什么我们早就该知道”的疑问（这一例中家族内的肿瘤被当作不相关的事件，这是最常见的延误，也正是常规筛查肿瘤标本的价值）——[[genetics/genetic-testing]]、[[clinical-skills/communication]]。**
:::

::: example 靶向药与它的逃逸 {#ex-osimertinib}
一名从不吸烟的肺腺癌女性携带表皮生长因子受体的敏感突变，对第一代抑制剂响应十个月后影像学进展；再活检显示T790M；她问“是不是药失效了，还有别的办法吗”。
::: solution
**演化在治疗之中（[[#def-somatic]]、[[#def-circuitry]]、[[respiratory/lung-cancer-pleura]]）：她的进展不是失败而是选择：药物把敏感克隆压下去，一个预先存在的或新获得的耐药亚克隆扩张——这解释了为何“对然后耐药”是靶向治疗的常态而非例外，也解释了为何再活检与再测序有价值（T790M 是第三代表皮生长因子受体抑制剂的靶点，而另一些机制（MET 的扩增与小的细胞转化与融合的获得与下游的丝裂原通路的激活）需要完全不同的对策）——[[pharmacology/metabolism-excretion]]、[[pathology/cancer-diagnosis]]。对她的解释要包含三件事：一，“肿瘤细胞在演化”这一比喻能让她理解为什么治疗要按结果改变而不是“用完一种就没有了”；二，治疗的顺序在转移期是关于生活品质的时间管理（每种药物的无进展时间与不良反应与口服对住院的差别与脑转移的中枢穿透性——第三代药物在这一点上更好）；三，还有别的路径（后续的化疗与抗血管与联合的策略与在耐药机制明确后的组合与再挑战以及临床试验，包括双特异抗体与抗体偶联药物这类把药物“送到靶上”的设计）——[[respiratory/respiratory-infections]]。临床的注意：不要仅凭一次血液的循环肿瘤脱氧核糖核酸阴性就放弃组织（灵敏度有限），也不要忽略假性进展与非肿瘤的原因（感染与栓塞与治疗的炎症）；把症状与体能状态与患者的目标纳入排序（这是靶向治疗时代最常见的可改善的照护：在有效口服药与生活质量之间做明确的权衡），并把姑息照护早期接入而不是留到最后——[[geriatrics-palliative/palliative-care]]、[[clinical-skills/clinical-reasoning]]。**
:::

::: example 双侧肿瘤的孩子 {#ex-rb}
一名十四个月的幼儿因白瞳症就诊，双眼的视网膜母细胞瘤，父亲幼时曾“一只眼睛视力不好”。
::: solution
**第一次事件在生殖细胞里（[[#def-somatic]]、[[#def-circuitry]]、[[genetics/chromosomal-disorders]]）：这是克努德森两击假说的原型：遗传型的孩子从父母之一带来一个失守的 RB1 等位基因，因此在视网膜的每一个细胞中都只差一次事件，结果是多灶、双侧与早发；父亲的“一只眼视力不好”很可能是未诊断的同一病种（或是未外显的其他表现）——[[nervous-system/sensory-systems]]。即刻的处理是保住生命、眼球与视力这个次序：分期与影像（眶与颅的磁共振与脑脊液的选择）与在麻醉下的检查与局部治疗（激光与冷冻与斑块与动脉内化疗）与全身的化学减量与外眼手术的时机（保眼失败的判断与假眼的告知）；同时避免不必要的放射（在遗传型中它会显著增加第二肿瘤的风险，这是一个“今天的治疗决定二十年后的癌”的活例子）——[[pathology/cancer-diagnosis]]、[[clinical-skills/medical-imaging]]。遗传与家庭的一层：RB1 的生殖系检测（先证者）并据此给父母与未来的兄弟姐妹与父亲再做检测；并说明遗传型的风险传递（常染色体显性、外显率高但不是百分之百）与可选的路径（生育的选择与产前与着床前的诊断，以及“我们不打算知道”也是一种可接受的选择）；把随访做成终身的：第二肿瘤（骨肉瘤与软组织与放疗野内的肉瘤与放疗后的白血病）与需要向成年过渡的病历摘要——[[paediatrics/congenital-genetic]]、[[genetics/genetic-testing]]。伦理的一层：把孩子的“生存质量”与“保眼”的取舍与父母的自主与儿童未来的自主同时摆出来（一些决定不可逆，所以决定要按“最不利于未来自主的那个”来谨慎）；并为家庭提供长期支持（视觉障碍的教育与遗传的咨询与兄弟姐妹的筛查）——[[medical-ethics-law/beginning-of-life]]、[[obstetrics-gynaecology/contraception-fertility]]。**
:::

::: example 被预防掉的那个病毒相关癌症 {#ex-hpv}
一名29岁女性因宫颈的原位腺癌接受了手术；她的接种史不详；她的社区在讨论“疫苗是否让筛查变得不必要”；她问“我还需要筛查吗”。
::: solution
**三级预防的接缝（[[#def-hallmarks]]、[[#def-somatic]]、[[public-health/vaccination-programmes]]）：先答她的问题：需要，而且她的情况使筛查更重要而非更不必要——已经存在的病变与治疗后的复发风险使她需要按“治疗后”的路径随访（细胞学与人类乳头状病毒的联合与阴道的细胞学，因为治疗改变了宫颈的解剖与取材的敏感性）；治疗也不能预防其他型别与新的暴露与感染，而疫苗在治疗后仍可能被推荐（虽不治疗现有的感染）——[[obstetrics-gynaecology/gynaecological-cancer]]、[[pathology/cancer-diagnosis]]。机制要讲清，因为它是“癌症可以被预防”的最好例子：持续的高危型人乳头状病毒的E6 与 E7 表达分别失守 TP53 与 RB1 的功能，从而绕过凋亡与检查点（这一分子逻辑解释了为何它需要“持续”而非一次接触，以及为何筛查以病毒为起点更有效）；而腺型的病变更常在颈管、可以跳跃、并且疫苗对腺癌的保护不及鳞癌（这是筛查在疫苗时代仍不可取消的技术理由）——[[genetics/cancer-genetics]]、[[public-health/screening]]。对社区的问题给一个诚实的回答：疫苗会让筛查的未来更“轻”（间隔更长、起始更晚、以病毒检测为主），但只有在覆盖足够高且持续多年之后；如果因为疫苗成功而放弃筛查，最先受害的是那些从未被覆盖的人，而且这正是消除规划最常见的自毁方式（成功的消失带来风险的消失，进而带来覆盖的下降）——[[public-health/determinants-inequalities]]、[[public-health/screening]]。临床医师的份额：把接种的谈话当作癌症预防的谈话（以“未来不得癌症”为语言而不是“性生活”）；对已感染者不施加道德；并把男性与免疫抑制者与无家者与性工作者与低收入群体的可及性一起争取，因为人类乳头状病毒相关癌症的负担高度集中在这些人群——[[immunology/vaccines-immunotherapy]]、[[clinical-skills/communication]]。**

**癌症生物学的每一次跃进都来自“能不能测量”的改变。19世纪末的显微镜病理把癌与肉瘤分开，并给出转移的解剖学；1900年代初鲁克斯与墨比厄斯以鸡的白血病证明其传染性、埃利希与后来的移植排斥研究为免疫监视埋下伏笔；1910至1915年野口欧吉与月田的焦油致癌实验把癌症变成可被人为诱导、因而可被实验研究的对象。二十世纪前半属于病毒与基因：劳斯肉瘤病毒的逆转录机制与宿主癌基因的发现（把“病毒的基因”变成“我们自己的基因被改变”）、以及1970年代与1980年代以重组技术克隆癌基因与抑癌基因的时代（RAS 于1982年、MYC、ABL 于慢性髓系病的费城染色体、RB1 于1986至1987年、TP53 于1989年、BRCA1 于1994年、BRCA2 于1995年）。第三阶段是“通路”的时代：从基因到电路（生长信号与检查点与凋亡与血管生成与侵袭），以及1990至2000年代“特征”清单的成形（哈纳汉与温伯格 的两篇论文，其后的增补把免疫与代谢与微环境纳入）。治疗的一侧由同一批分子决定：格列卫把 BCR-ABL 从一个细胞遗传学的发现变成一种口服药（并确立了“抑制一个驱动”的范式与耐药的问题）、曲妥珠单抗与 HER2 与内分泌治疗与表皮生长因子受体的抑制剂与免疫检查点的抑制（其临床证据在2010年代把黑色素瘤与肺癌与肾癌与霍奇金的结局改写，并带来免疫相关不良反应这门新学科）。测序与生物信息则把“个体化”从口号变成流程（肿瘤的多基因面板与治疗性突变与微卫星不稳定性与突变负荷与最小残留病灶的循环脱氧核核酸监测，以及2010年代的组织不可知的适应性许可设计——按分子而非按器官批准药物）——[[genetics/genomic-medicine]]、[[pharmacology/drug-development-prescribing]]、[[clinical-skills/laboratory-tests]]。**
:::

::: summary
- 癌症是体细胞的演化疾病：驱动与被选择的亚克隆决定了诊断时的组成、治疗中的适应与最终的耐药。
- 癌基因是获得性功能的“卡住的油门”，抑癌基因是失去功能的刹车（需两次失守）；通路的冗余与反馈使单点抑制常不足。
- 特征不是清单而是过程：血管生成、侵袭与转移、免疫的编辑与代谢的重编程都受同一批通路的调度并受微环境的塑造。
- 第一击可以来自生殖细胞：遗传综合征使发病更早、多发、双侧，并把临床问题扩展到家系与预防性手术与生育的选择。
- 年龄是最强的危险因素，多步突变的乘积逻辑解释了它；而可避免的暴露与感染占了可相当大的一部分。
- 临床的含义：按分子选择治疗、按演化预期耐药、按家系识别遗传、并按“三级预防”把病毒与遗传与环境接在一起。
:::

::: exercise 把靶向药对上靶点 {level=1}
把下列药物与靶点配对并说明其临床场景：伊马替尼、曲妥珠单抗、维莫非尼、奥拉帕利、帕博利珠单抗。
::: solution
**药物—靶点—场景（[[#def-circuitry]]、[[#def-hallmarks]]、[[pharmacology/drug-receptor]]）：伊马替尼对应 BCR-ABL 的融合酪氨酸激酶（慢性髓系病的口服革命，以及胃肠间质肿瘤的 KIT 与血小板来源生长因子受体，两者都是“抑制一个驱动”的范例，而其耐药由激酶域的二次突变引起）；曲妥珠单抗对应 HER2 的过度表达（乳腺癌与胃癌，需注意心脏的毒性且与蒽环类叠加的风险，以及抗体偶联药物把细胞毒药物“送进”HER2 阳性的细胞这一后来的发展）；维莫非尼对应 BRAF 的V600E 突变（黑色素瘤，且因通路反馈必须与 MEK 抑制剂合用，否则 反常的鳞癌会增多）；奥拉帕利对应聚ADP核糖聚合酶在同源重组缺陷肿瘤中的合成致死（BRCA1/2 遗传型的乳腺、卵巢、胰腺与前列腺，以及它带来的骨髓与二次肿瘤与耐药的复发问题）；帕博利珠单抗对应程序性死亡受体1（黑色素瘤与肺与肾与错配修复缺陷者的多种癌，伴随免疫相关的内分泌与肠与肺与皮肤的毒性以及“需要时间才起效”的假性进展问题）——[[endocrine/thyroid]]、[[blood/leukaemia]]、[[musculoskeletal/skin-cancer]]。**

::: exercise 解释癌症为何难治 {level=1}
用最少的技术词汇向一名患者解释“为什么癌症比感染难治”。
::: solution
**四个理由（[[#def-somatic]]、[[#def-hallmarks]]、[[pharmacology/adverse-reactions]]）：一，它是你自己的细胞：细菌与我们不同，而癌细胞是我们自己的细胞变了样，所以能杀它的东西往往也杀我们（这就是治疗窗窄的根源，也是靶向与免疫治疗试图扩大这个窗的两种办法）；二，它是许多种细胞：一个肿瘤里有不同的亚克隆，治了一种就剩下另一种（所以我们看到“先有效后耐药”，所以需要联合而不是单药、需要再活检而不是猜）；三，它会变：药物本身就是一道选择的压力，会把耐药的细胞挑出来；四，它懂得利用我们自己的机制：血管与免疫细胞与修复与生长因子都被征用，所以“切断供应”与“松开免疫的刹车”成为治疗，而它们的副作用也来自这些机制（高血压与蛋白尿与自身免疫样的炎症）。要说清的希望：这些认识已经使一部分癌症成为可以长期带病生存的疾病，使一部分（若干白血病与睾丸与霍奇金与部分的儿童肿瘤）可被治愈，并把治疗的选择变成一个按分子与按家系的决定——[[blood/leukaemia]]、[[paediatrics/acute-childhood-illness]]。**
:::

::: exercise 读一份肿瘤的突变报告 {level=2}
转移性肺腺癌的报告：KRAS G12C 阳性、PD-L1 60%、微卫星稳定、肿瘤突变负荷10、TP53 与 STK11 共突变。请解释每项与你的治疗思路。
::: solution
**逐项解读（[[#def-somatic]]、[[#def-circuitry]]、[[respiratory/lung-cancer-pleura]]）：KRAS 的G12C 曾经“不可成药”，如今有共价的抑制剂（在二线被证实，且与化疗与免疫的次序与联合仍在确定）；PD-L1 高表达提示免疫治疗可能获益（但它是连续的、不完美的标志，且与 KRAS 的共突变状态相关）；微卫星稳定加突变负荷中等说明免疫的“新抗原”论证并不强；STK11 的共突变在文献中与免疫治疗反应较差与预后较差相关（这提醒不要把 PD-L1 当成单独的裁决），而 KEAP1 的共突变更是负面的信号（且与放疗的抵抗有关）；TP53 是非特异的背景。治疗思路因此不是“有靶点就吃靶向药”一条线：把驱动抑制与免疫与化疗与中枢的控制与局部的巩固与症状的姑息按患者的目标与体能与脑与骨的情况排序，并预设再活检或在进展时做血液的测序以寻找可操作的新机制（MET 的扩增与小细胞转化与融合的获得与下游的激活）——[[pharmacology/patient-variation]]、[[pathology/cancer-diagnosis]]。沟通的要点：把报告的每一项翻译成“能做什么”（患者要的不是分子的名字而是下一步与概率与代价），并解释为何“没有靶点”不等于“没有治疗”，以及为何临床试验值得被讨论而不是最后才被提起——[[clinical-skills/communication]]、[[medical-ethics-law/research-ethics]]。**

::: exercise 就降低风险的手术给出建议 {level=3}
一名35岁、BRCA1 致病变异、已完成生育、母亲与姨妈均患乳腺癌与姨妈患卵巢癌的女性，被建议做预防性的双侧乳腺切除与输卵管卵巢切除。请给出你的建议过程。
::: solution
**风险降低的决策（[[#def-somatic]]、[[#def-circuitry]]、[[genetics/genetic-testing]]）：先把数字给准（在 BRCA1 携带者中终生乳腺癌与卵巢癌的风险区间、以及卵巢癌筛查的无效性——这一点决定了“切除输卵管与卵巢”是唯一被证明降低死亡的措施；以及乳腺的磁共振筛查作为替代策略的存在与它的局限）；同时说明风险的异质性（家族的修饰与其他变异使“平均风险”只是起点）。二，把选择摆全而不是给一个答案：加强筛查、药物预防、乳腺的切除、卵巢与输卵管切除的时点（通常在完成生育后、且按型别在四十岁左右，因为卵巢癌筛查不奏效而时机重要）、以及“先做输卵管而延迟卵巢”这一正在研究的路径与它对绝经的影响。三，把代价说清：手术与麻醉与重建的并发症与感觉的改变与身体的形象与性的功能与亲密关系；而卵巢切除意味着即刻的绝经（激素替代的取舍在 BRCA 携带者中并不像大众想象的那样禁忌、但要个体化，尤其在没有乳腺癌病史时）与骨骼与心血管与泌尿与情绪与生育的问题——[[endocrine/reproductive-endocrinology]]、[[endocrine/bone-calcium]]、[[obstetrics-gynaecology/menopause]]。四，程序的质量：多学科（遗传与乳腺与妇科肿瘤与整形与心理与外科）与至少两次的谈话与一位“决策辅导”的角色、书面绝对数字与图形、以及“现在不做也是一种决定、并可以在任何时候重新讨论”；并处理家族的压力与伴侣的意见（这些决定常被家庭成员的恐惧推着走）。五，公平与可及：重建与心理与遗传咨询的可用性以及不要让“能不能请假与付得起”决定她的选择——[[public-health/determinants-inequalities]]、[[medical-ethics-law/consent-capacity]]。**

## 练习

::: exercise 给基因分类 {level=1}
把 APC、KRAS、TP53、RB1、BRCA2、MYC、ERBB2、VHL 按原癌基因与抑癌基因与修复基因分类，并说出一个“最能体现剂量效应”的例子。
::: solution
**分类与剂量（[[#def-circuitry]]、[[#def-somatic]]、[[genetics/cancer-genetics]]）：获得性功能的原癌基因：KRAS 与 MYC 与 ERBB2（HER2）——它们的致病方式是“被激活”，因此一个等位基因的改变（点突变或扩增或重排）即起作用；失去功能的抑癌基因：APC 与 TP53 与 RB1 与 VHL——它们需要两个等位基因都失守（ 克努德森的隐性规则，通过第二个等位基因的突变或缺失或甲基化实现），因此体细胞的杂合性丢失在切片上可以看到；修复基因：BRCA2（以及 BRCA1 与错配修复的家族）既是“看管者”（维持基因组稳定，失守时提高全基因组的突变率并造成可被利用的同源重组缺陷），也与特定的组织易感相关。最能体现剂量效应的是 RB1：一次生殖细胞的击打使双眼早发的多灶视网膜瘤成为常态，而体细胞的两次击打则是散发的单侧迟发；另一个剂量现象是 HER2 的扩增水平（基因拷贝数决定抗体的选择与疗效，因此”3+“与”2+且原位杂交阳性“不是同一种病）——[[nervous-system/sensory-systems]]、[[pathology/cancer-diagnosis]]。**

::: exercise 解释致癌物 {level=1}
就下列各项解释其暴露—反应与机制与预防的层次：烟草、紫外线、人乳头状病毒、马兜铃酸、以及氡。
::: solution
**五种致癌物的比较（[[#def-somatic]]、[[pathology/environmental-pathology]]）：烟草：多环芳烃与亚硝胺的加合物形成嘧啶与加合物的特征突变签名，剂量—反应在多数器官呈平方或立方关系（因此”少吸“的收益不如”不吸“，而戒烟后风险随时间下降）；预防在人群端最有效（税与禁广告与无烟场所）。紫外线：嘧啶二聚体与C到T的特征突变并在着色性干皮病（核苷酸切除修复缺陷）中放大成数百倍的风险，剂量—反应的形态是间歇性灼伤而非持续低量，因此防晒与晒床的管制是可操作的预防。人乳头状病毒：E6 与 E7 分别失守 TP53 与 RB1，需要持续感染，且被疫苗几乎完全预防——这是”把癌症变成可预防感染“的样板。马兜铃酸：与 APOBEC 无关的特征性T到A的突变并有阈值之争，其教训是”天然不等于安全“与草药的监管。氡：α粒子的短程高线性能量沉积导致肺的基底与鳞状的上皮的突变，且与吸烟强烈相乘（因此戒烟与降氡要同时做）；预防在住房与职业层，剂量—反应在低暴露处的不确定性最大——[[respiratory/lung-cancer-pleura]]、[[pathology/environmental-pathology]]、[[public-health/prevention-promotion]]。**

::: exercise 解读肿瘤的异质性 {level=2}
同一患者的三个转移灶分别显示：一个有表皮生长因子受体的敏感突变、一个有 MET 的扩增、一个有小的细胞转化；血清的循环脱氧核糖核酸也检出多种变异。请解释并提出策略。
::: solution
**异质性的解读与对策（[[#def-somatic]]、[[#def-hallmarks]]、[[pathology/diagnostic-pathology]]）：解释是分支式的演化：在药物压力下，不同病灶独立地找到出路（同一患者对不同部位反应不同——即”混合反应“，在影像上表现为有的病灶缩小而另一个长大，这常被误读为”药无效“或”药有效“）。循环脱氧核糖核酸同时检出多种变异与组织学一致，且其浓度可作负荷与反应的定量；但要清楚其灵敏度低（脑与腹膜与黏液型的病变常常假阴性），所以”血液里没找到“不能替代组织。策略：继续对存在驱动突变的克隆加压、同时为其他克隆留出选项（按部位分层决定局部治疗——例如对孤立的进展灶做放疗或手术而全身治疗不变，这是把”演化“限制在可管理的范围）；考虑通路性的联合（上皮间质的通路的MET 扩增与表皮生长因子受体抑制剂的联合策略在试验中被检验；小的细胞转化则意味着含铂与依托普替的化疗方案）；以及在治疗间隙允许”药物假期“以让敏感克隆竞争（这一”适应性治疗“思路在临床研究中减少了毒性并延长了控制，但尚未成为标准）——[[pharmacology/drug-receptor]]、[[clinical-skills/clinical-reasoning]]。伦理与照护：当每一轮治疗都在制造新的耐药时，明确患者的目标并让姑息照护与治疗并行成为默认，并把”不再升级“写成可以讨论而不是一堵墙——[[geriatrics-palliative/palliative-care]]。**

::: exercise 就一份”癌症筛查面板“的建议给出意见 {level=3}
一家公司向健康人群出售包含一百多个基因的遗传性肿瘤面板（含许多证据等级低的中外显率变异），附带”根据结果安排更密集的筛查“；你的门诊有患者拿着结果来问。
::: solution
**基因面板的临床回应（[[#def-circuitry]]、[[#def-somatic]]、[[genetics/genetic-testing]]）：先说明这类商业面板的问题：意义未明的变异的率随检测的宽度上升（多数人在大面板上会得到至少一个不能解释的结果），中外显率的变异的分类常被后来的数据推翻（尤其那些基于单一家系与缺乏功能证据者）、而”根据结果做更密的筛查“常常超出证据（可能导致过度诊断与不必要的手术与保险与心理的后果）。对患者的处理：把结果分类（明确致病的、可能致病的、意义未明的、良性的）并只对前两类行动，且要复核实验室的证据与数据库与家系；对意义未明的变异明确说”这个结果不能指导你的照护，也不改变你的筛查计划“；把知情同意讲清（谁保留了数据、是否会被重分类并回告、以及在商业实验室的检测是否等同于临床诊断路径）；同时提供被证明有效的路径——按家族史做规范的遗传评估（结构化的风险问卷与经认证实验室的靶向检测）与按指南的筛查与生活方式的风险降低——[[public-health/screening]]、[[clinical-skills/clinical-reasoning]]。对系统的建议：把直接面向消费者的遗传检测纳入咨询的通道（否则结果落在无人的信箱里）、要求实验室公开其分类的证据与方法（这是公平的问题：数据库的祖先构成使某些族群更容易得到不确定或错误的结论）、以及对广告的可执行规则（不得用”基因检测“暗示”医学上必要“）——[[genetics/genomic-medicine]]、[[medical-ethics-law/confidentiality]]、[[public-health/determinants-inequalities]]。**
