慢性炎症是“刺激物不肯离开”时发生的事：**持续的微生物、不能被消化的颗粒、自身的免疫反应或持续的暴露使炎症的舞台一直开着，只是演员换了——中性粒被单核的细胞与淋巴细胞与浆细胞替换，纤维的增生开始与损伤同时发生，而组织在“试图修复”与“持续被损伤”之间形成一种新的、常常致残的稳定。**本章覆盖慢性炎症的细胞与它得以持续的机制（巨噬细胞的极化与淋巴的环路与其维持反馈）、肉芽肿（其结构、形成它的通路、以及按形态与部位排列的鉴别）、以及修复与替换（再生与瘢痕与纤维化及其调控、创面愈合的时相与其失败的两种形式）。

## 单核的演员

::: definition 巨噬细胞、淋巴细胞与持续性 {#def-chronic}
**慢性炎症的定义性特征是三个过程的重叠：持续的损伤、同时的修复、以及被重新塑造的组织。浸润的细胞是单核的（巨噬细胞与其来源的单核细胞与组织固有的巨噬细胞）与淋巴细胞与浆细胞与（在若干类型中的）嗜酸或嗜碱的细胞与（在长期者）肥大细胞与成纤维的细胞；而“慢性”不是“时间长的急性”，而是被新的调控所维持的状态。巨噬细胞是这场戏的主角，因为它的表型是被环境写出来的：在干扰的γ与（在微生物产物驱动的） Toll 样受体与（在死亡的细胞的）清理信号下转向促炎的一极（产生肿瘤坏死因子与白细胞介素6 与12 与活性的一氧化氮与氧的自由基，并呈递抗原），在（在白细胞介素4 与13 与10 与肿瘤的与糖皮质激素驱动的）信号下转向另一极（产生精氨酸酶与转化生长因子β 与血小板衍生与血管的内皮生长因子，负责纤维化与血管的生成与（在若干情形中的）免疫的抑制）；这一“极化”在体内不是一个二分的开关而是一个连续的、按位置的谱（在创面的不同时相与（在肉芽肿的）不同环带与（在肿瘤的）不同的区域），而它的临床后果是同一个细胞既能清除感染也能制造硬化——[[immunology/innate-immunity]]、[[pathology/acute-inflammation]]、[[gastrointestinal/liver-disease]]。淋巴的持续靠三个环路：抗原的持续（不能被清除的微生物，如结核与若干真菌与布鲁菌与乙肝病毒；不能被消化的颗粒；持续的自身抗原与移植的抗原），淋巴与巨噬细胞的相互喂养（T 细胞产生干扰的γ 激活巨噬细胞，巨噬细胞产生白细胞介素12 与6 与23 维持 T 亚群（在17 型的通路上尤甚，这是银屑病与若干脊柱关节病的机制），形成不需要外来的刺激也能自持的闭环），以及淋巴的组织结构（在若干慢性炎症中形成三级淋巴的器官样聚集，使抗原的呈递与淋巴的活化在炎症局部即可完成，见于类风湿的滑膜与干燥的唾液腺与哮喘与慢性移植的排斥）——[[immunology/adaptive-responses]]、[[musculoskeletal/inflammatory-arthritis]]。为什么全身的反应在这里“变安静”：慢性的病灶释放的介质较少进入血循环，而肝脏的急相反应在持续的低度刺激下会被重新调定（白蛋白下降，而若干标志在数周后部分回落），这就是为何“炎症标志不高”从未排除过慢性炎症（结核与（在结节病中的）与（在若干的）血管炎可以有基本正常的 C 反应蛋白），而贫血与低白蛋白与体重下降与儿童的生长落后与慢性的肌肉减少是更敏感的提示——[[clinical-skills/laboratory-tests]]、[[geriatrics-palliative/ageing-frailty]]、[[blood/anaemia]]。**
:::

::: definition 肉芽肿 {#def-granuloma}
**肉芽肿是被围起来的、不能被消灭的炎症：由激活的上皮样的巨噬细胞与其转化的多核巨细胞组成，外周一圈淋巴细胞与纤维，中央或有坏死。形成它的条件是细胞内的病原体或颗粒既不能被清除又不能被杀死，再加上T 细胞与巨噬细胞之间的正反馈（干扰素γ、肿瘤坏死因子、白细胞介素12、17、23 的通路）；这解释了为何抗肿瘤坏死因子的治疗会使既有的结核肉芽肿解体并播散——结构的炎症被药物拆掉的教科书后果，也是用药前筛查潜伏结核的理由。分类的第一步是有坏死还是没有。伴坏死（干酪样）者首先想感染：结核、若干真菌、猫抓病与性病性淋巴肉芽肿的杆菌、布鲁菌、梅毒、若干非结核分枝杆菌；也要想到肉芽肿性血管炎、类风湿结节与若干药物反应的坏死性肉芽肿。不伴坏死者包括：结节病（形态“干净”，巨细胞内可见层状小体与星状小体与双折射的颗粒，但诊断必须先排除外源颗粒与感染）、过敏性肺泡炎（疏松、间质、伴细胞性纤维化的灶）、药物反应、克罗恩病的肠壁肉芽肿、原发性胆汁性胆管炎的门管肉芽肿、以及异物型（缝线与滑膜磨损的颗粒与锆与铍）。部位常常胜过形态：双侧肺门的淋巴结肿大指向结节病；上叶的分布指向结核；沿淋巴管的分布指向真菌与孢子丝菌；肝的门管、肠的全层、腮腺与泪腺、肾的间质各提示不同的病因。该做的检查：暴露的病史（职业与爱好与旅行与动物的接触与饮水与装修的粉尘）、感染的筛查（结核的皮试或血液的干扰素释放试验与真菌与病毒与性传播的病原）、血清学（血管紧张素转化酶的灵敏度与特异度都不足以单独定论；同时查钙与肝酶）、影像的模式、以及必要部位的足够大的活检（经支气管的冷冻活检与皮肤与肝）。要点是“看到肉芽肿只是描述，为什么有肉芽肿才是诊断”；在贴上结节病这个标签之前必须主动排除感染，在免疫抑制者尤其如此——把一个真菌病当结节病给激素是可以致命的错误——[[respiratory/interstitial-vascular-disease]]、[[infectious-diseases/tropical-infections]]、[[clinical-skills/medical-imaging]]、[[immunology/adaptive-responses]]。**
:::

## 修复与替换

::: definition 再生、瘢痕与纤维化 {#def-repair}
**修复有两种结局。再生由同种细胞重建原有结构，前提是支架、干细胞与生长信号完好：肝的代偿性再生、造血系统的持续更新、肾小管上皮的恢复、骨的愈合都属此类。瘢痕则由肉芽组织填入并成熟为胶原的基质，永久改变结构与功能。再生的能力按细胞分三类：持续更新的（被覆上皮、造血、生殖）、有储备的（肝、肾小管、内分泌腺）与几乎不能的（心肌、骨骼肌（卫星细胞除外）、神经元的胞体）；这一分层解释了心梗与脊髓损伤后的结局为何与肝部分切除后的恢复截然不同。肉芽组织是修复的工作面：毛细血管在内皮生长因子与成纤维生长因子与缺氧诱导因子的驱动下由已有血管出芽，向缺氧区生长；成纤维细胞先分泌第三型的胶原与蛋白聚糖的基质，并在转化生长因子β与机械张力下转为肌成纤维细胞（兼具收缩与合成），负责创面收缩；随后毛细血管退化、成纤维细胞凋亡、第三型胶原被第一型替换并交联（赖氨酰氧化酶的铜依赖的交联，维生素C 是其辅助因子，这也是坏血病时创面裂开的原因）——因此瘢痕的抗拉强度只回到原有约七成，永不更高。纤维化是把修复的开关卡在“开”：持续的巨噬细胞与第二型的辅助T 细胞的细胞因子（转化生长因子β与白细胞介素4 与13）与血小板衍生与结缔组织的生长因子的通路激活肌成纤维细胞，并使部分上皮与内皮转分化为间叶的成纤维细胞；基质沉积并交联，微血管被压迫，实质被隔断。在肝即肝硬化（肝星细胞激活，门周纤维向桥接的间隔发展）；在肺为间质纤维化（蜂窝与限制性通气障碍与弥散能力下降）；在心为舒张功能障碍与心律失常的基质；在肾为间质纤维与肾小管的萎缩（慢性移植肾病与梗阻与反流的肾病）。可干预的点存在但有限：去除持续的刺激仍是唯一被反复证实能改变轨迹的措施；而肺纤维化的两种药与若干肝病病因治疗后纤维程度回退的观测，说明纤维化并非总不可逆。创面愈合按时相推进且可测量：炎症期数日，增殖期（肉芽与上皮的爬行）数日数周，重塑期数月至一年；抗拉强度在第三周左右约达一半并缓慢平台——所以拆线时机与举重与腹部手术后的活动限制不是保守的习惯，而是胶原的动力学；瘢痕在十个月内继续成熟，而老化的瘢痕终生仍在被塑型（这也是瘢痕会随年龄与体重与（在妊娠中的）拉伸而改变的原因）——[[surgery/wounds-surgical-infection]]、[[gastrointestinal/liver-disease]]、[[respiratory/interstitial-vascular-disease]]、[[renal/chronic-kidney-disease]]、[[pathology/acute-inflammation]]。**
:::

::: example 钙化的上叶 {#ex-granuloma-read}
一名34岁的女性入职胸片发现右上叶一个致密的结节伴钙化与肺门的钙化的淋巴结；她无症状，既往在乡下住过并有结核的接触史；干扰素释放试验阳性；她问“我是不是有结核”。
::: solution
**旧病灶的读法：一个致密的、部分钙化的结节伴钙化的淋巴结，在一个无症状者身上，最可能是已经愈合的原发感染（结核的原发复合体的遗迹或组织胞浆菌的类似病灶）。钙化本身是修复的产物：干酪的坏死灶被纤维包裹并沉积钙盐（营养不良性的钙化，在血钙正常时发生），这是慢性炎症结局的物理证据。阳性结果要说清含义：结核的血液试验阳性说明“感染过”（T 细胞记住），不能区分潜伏与活动，也不会因为治愈而转阴；她需要的是活动的评估：症状的追问（咳嗽超过两周与夜汗与体重下降与（在咯血中的）痰的改变），影像的对比（调阅任何旧的片子；若这个结节在两年前大小形态完全相同，活动基本可排除），痰或诱导痰的检查（在影像可疑或有症状时），以及结核病的鉴别（新近的活动结核、肿瘤的钙化模式（爆米花样与层状，见于错构瘤与类癌的淋巴结转移）、陈旧的真菌、以及其他肉芽肿病）。处理分两条线：若为陈旧已愈（多数），不需要治疗，但要说明未来再激活的少数风险（免疫抑制的治疗与肿瘤坏死因子的抑制剂与长期激素与透析与硅肺与糖尿病的暴露会增加它，因此她在未来接受这些治疗之前应被告知“当年胸片上有钙化的旧结核”，这一句话可能救她一命）；若评估为潜伏感染（阳性试验且无活动），可按本地的方案给预防的治疗（数月的方案在依从上远优于长程，并解释“治的是一个未来可能发生的病”，并说明肝毒性与随访的必要性）。她的顾虑还包括保险与职业（在若干体系中潜伏结核的记录影响入职与移民的体检，应给她书面的说明：影像所见与试验的意义与“非活动、不传染”）——[[infectious-diseases/tuberculosis]]、[[respiratory/lung-cancer-pleura]]、[[pathology/environmental-pathology]]。**
:::

::: example 肝硬化的轨迹 {#ex-fibrosis}
一名52岁的酒精性肝病患者已经出现脾大与血小板98与白蛋白30与轻度的蜘蛛痣；他问“如果我现在戒酒，我的肝能好吗”。
::: solution
**纤维化可逆到什么程度？答案是部分可以，而且戒酒的收益出现得比想象早。机制的一面：胶原的沉积在早期（门周与窦周的纤维化）主要由可被解除的刺激驱动，戒酒与减重与病毒的抑制可以减轻；而一旦形成交联的间隔与再生的结节与窦的毛细血管化与血管的重建，逆转会慢得多且不完全（基质被“修饰”成抵抗降解的形式，且血管的构型已被改写）。不过人体的证据是乐观的：在长期戒酒者中有硬化的程度减轻与门脉压力下降的报道；在乙肝与丙肝的病毒被抑制后，纤维化评分常在数年内在组织学上下降；在非酒精的脂肪性肝病中体重下降10%以上可以有相当比例的纤维化改善。因此对他的答复要分成时间轴：数周内是水肿与控制腹水与凝血与注意力的改善；数月内是炎症指标与胆红素与（在若干病例中的）白蛋白的改善与戒断与营养（硫胺素与蛋白与维生素的）的重新安排；数年则是纤维化的可能回退与肝癌的风险仍在（硬化者的监测不因改善而停止——这一点必须说清楚，否则他会把“好转”理解为“痊愈”）。同时把“门脉高压在不在”讲清：脾大与血小板低说明已经有门脉高压（脾的扣押与（在其中的）血小板生成素的减少），所以他需要胃镜筛查食管胃底静脉的（并按风险给非选择性β受体拮抗剂），需要接种（甲肝乙肝与流感与肺炎的），需要（在戒断的风险与（在肝性脑病的风险中的））用药的调整（避免苯二氮的长效制剂与（在若干的）阿片），以及戒酒的帮助（药物与心理与社会的支持与（在依赖的评估中）住院的戒断的方案）与（在失代偿时）移植的评估（戒酒的时间与（在若干中心中的）社会的评估与（在酒精相关的肝病中的）移植的预后——这些问题在早期讨论比在危重时讨论更有帮助）——[[gastrointestinal/liver-disease]]、[[psychiatry/substance-use]]、[[pathology/cancer-biology]]、[[surgery/gastrointestinal-surgery]]。**

::: example 采石工的肺 {#ex-silicosis}
一名61岁的采石工（三十五年干式钻孔与爆破，无防护），进行性气促与咳嗽；胸片见双上叶的多个小结节并融合成大的对称的肿块；他做过四次“结核病的治疗”，最后一次三年前。
::: solution
**职业暴露、慢性炎症与一个被误治的结局。硅的病理：吸入的二氧化硅的颗粒被肺泡巨噬细胞吞噬，颗粒在细胞内破坏溶酶体的膜并导致巨噬细胞的死亡，释放的内容物再被下一批巨噬细胞吞噬，形成自我维持的循环，同时释放转化生长因子与炎性的细胞因子，最终产生两种病变：境界清楚的硅结节（同心排列的胶原）与（在进展的）大块纤维化（融合的肿块，常在上叶，可有空洞与（在其中的）缺血性的坏死）。他的临床有四个必须处理的问题。第一，结核的易感是成倍升高的（硅肺患者结核的终生风险显著高，且影像的结节与空洞与硅的病变无法区分），这解释了他被反复治疗的历史：影像“像结核”而治疗“没有改变”；正确的做法是把微生物的证据摆在前面（痰的涂片与培养与分子检测，并在有空洞时多次），把“影像像而培养阴性”记录为诊断的过程而不是失败。第二，剂量与暴露的确认（三十五年无防护的干式钻凿足以致病；要问具体的工种与其他同类的暴露（磨料与喷砂与石材的切割与半导体与水处理的其他粉尘）与同事的患病情况——这既支持诊断也是职业病申报的核心），并同时申报（职业病的认定与（在若干法域中的）赔偿与治疗的路径与劳动保护的介入，让同车间其他人也得到防护）。第三，其他并存的病因（硅与结核与其他分枝杆菌与类风湿的Caplan 综合征肺的结节与（在慢性炎症中的）肺癌的风险与（在上叶的肿块与（在肺癌的）的鉴别）——一个融合的上叶肿块在硅肺患者中不能默认是纤维化，需要活检或至少系统的影像与（在选择中的）正电子，尽管硅的病变本身可有摄取）。第四，处理与预防：戒烟与肺的康复与（在低氧者中的）氧与疫苗与（在进展与呼吸衰竭者中的）移植的评估（终末期硅肺可移植，且在结核已治愈的前提下可行）与（最重要的）源头控制——湿式的作业与局部的抽风与呼吸防护的适配与（在若干体系中的）替代的磨料；“给工人戴口罩”不是控制，工程与工艺的改造才是，这一课对每一个接触粉尘的行业都成立（[[public-health/environmental-occupational]]、[[respiratory/interstitial-vascular-disease]]、[[infectious-diseases/tuberculosis]]、[[public-health/communicable-disease-control]]）。**
:::

::: example 从未急性的溃疡 {#ex-chronic-ulcer}
一名78岁、独居、有二型糖尿病与外周动脉病变的患者，小腿有一个存在十四个月的溃疡；边缘增厚隆起、基底苍白、渗液不多、疼痛在夜间平卧时加重；他曾因“感染”住院三次并反复用外用抗生素。
::: solution

急性炎症的介质与细胞的募集见[[pathology/acute-inflammation]]；肉芽肿性感染的病原与治疗见[[infectious-diseases/tuberculosis]]与[[infectious-diseases/tropical-infections]]；纤维化在器官层面的表现见[[gastrointestinal/liver-disease]]与[[respiratory/interstitial-vascular-disease]]与[[renal/chronic-kidney-disease]]；慢性炎症与癌变见[[pathology/cancer-biology]]与[[pathology/cancer-diagnosis]]；慢性创面的外科处理见[[surgery/wounds-surgical-infection]]；炎症性疾病的免疫治疗见[[immunology/vaccines-immunotherapy]]与[[pharmacology/adverse-reactions]]。

::: history
**慢性炎症的观念是从“结核”这一原型长出来的。1882年科赫培养出结核的病原并把科赫的结节（在皮试后出现的））与肉芽肿的形态与该病固定在一起，也带来一个反讽的1890年的治疗失败（结核的提取物导致重症者恶化，成为免疫的病理学的起点）。肉芽肿的结构在此之前已被拉埃内克在尸检与（在显微镜普及前的））描述中被辨认；而（在1880年代的））菲尔绍学派与（在梅奇尼科夫的））吞噬的学派为“为什么炎症不结束”给出了两种互补的答案：组织的损伤与细胞的反应。职业性慢性肺病的历史与工业化同步：从硅肺在采矿的记载（在古代的））到二十世纪初的（在采石与（在隧道与（在磨料与（在陶瓷与（在喷砂的））的爆发与大流行的诉讼与（在英国的）的硅肺委员会（1910至1918年）与美国的（在1930至1940年代的））的立法与（在源头控制的））的工程；这一历程第一次把“暴露的剂量”作为诊断与预防的单位，也奠定了职业病申报与（在工作场所的）的监测。修复与瘢痕的现代认识来自两门战争医学：创伤的感染与（在输注血浆与（在磺胺与青霉素的）的临床与（在（（在1942年的）的（在维氏与伊克尔的））的创面愈合的分期研究，明确了炎症、增殖与重塑的时相与胶原的代谢；（在1950年代的）的胶原的生化与（在1960年代的）的成纤维细胞与肌成纤维细胞（在电镜下的））的识别与（在1970至1980年代的）的生长因子（在转化生长因子的））的纯化，把“瘢痕”从组织的宿命变成可被追问的通路。巨噬细胞的极化（在1980至2000年代的）的第一与第二型的命名，与（在（（在2010年代后的的单细胞的重绘一起，把“慢性炎症”从一个形态学的词变成一组可以被干预的调控节点——而它留下的临床问题仍是同一个：那个不走的刺激是什么，它能不能被拿走（[[pathology/acute-inflammation]]、[[public-health/environmental-occupational]]、[[immunology/innate-immunity]]。**

::: summary
- 慢性炎症是持续损伤与同时修复的重叠，其细胞演员是巨噬细胞与淋巴细胞与浆细胞，而非中性粒。
- 巨噬细胞的表型由局部环境写成，因此同一个细胞既能清除感染也能制造硬化；极化是谱而不是开关。
- 肉芽肿意味着“清除不了又杀不死”，其形成依赖T 细胞与巨噬细胞的正反馈——这也解释了抗肿瘤坏死因子治疗后的播散。
- 有无坏死与分布的部位是肉芽肿鉴别的第一步；在诊断结节病之前必须主动排除感染。
- 再生取决于细胞类型与支架；瘢痕的抗拉强度上限约为七成因交联的I 型胶原的替换有期限。
- 纤维化是被卡住的修复，去除持续刺激仍是唯一确证的干预；创面的时间常数决定了活动限制与拆线的时机。
:::

::: exercise 给肉芽肿的鉴别排序 {level=1}
下列四种情形各给出最可能的方向与第一个要排除的诊断：双肺门淋巴结伴皮肤结节；回肠全层炎伴肉芽肿；肝门管的界板肉芽肿；上叶空洞伴钙化的淋巴结。
::: solution
**按部位与形态排序（[[#def-granuloma]]、[[#def-chronic]]）。双肺门淋巴结伴皮肤结节，最像结节病；第一个要排除的是结核与真菌，做法是问暴露史、做血液的干扰素释放试验与痰的检查，同时记住淋巴瘤也可以有肺门的淋巴结与发热。回肠全层炎伴肉芽肿，最像克罗恩病；第一个要排除的是肠结核，因为在流行区两者的治疗完全不同，而给激素会让结核恶化，依据是肺的影像、分子检测、组织的抗酸与培养。肝门管的界板肉芽肿，最像原发性胆汁性胆管炎；先排除药物与感染，再查线粒体的抗体与免疫球蛋白M 与胆管的影像。上叶空洞伴钙化的淋巴结，最像结核；先排除肿瘤（按钙化的模式差别与痰的检查，必要时活检）——共同的顺序是把感染放在免疫之前。**

::: exercise 给烧伤创面计时 {level=2}

::: exercise 把炎症与癌变的风险连起来 {level=2}

::: exercise 设计一个抗纤维化的一级预防规划 {level=3}
器官的纤维化是许多慢性炎症疾病共同的致残终点。请在人群与医院的层面设计一个减少纤维化负担的规划，并说明如何评价。

**出发点：纤维化早期几乎没有症状，等到器官失代偿，干预的窗口已经过去，所以一级预防的价值高于任何后来的抗纤维化药（[[#def-repair]]、[[public-health/prevention-promotion]]）。第一条线是把可控的刺激去掉：饮酒（初级照护的筛查与简短的介入与依赖的治疗）、代谢的因素（体重与血糖与血脂，并把肝纤维化的无创评估纳入糖尿病与肥胖的常规）、烟草、职业与环境的粉尘（石棉与硅与木尘的申报与工程的控制）、慢性感染（乙肝与丙肝的筛查与治疗、结核的规范治疗、在若干人群中的血吸虫）。这五条在任何人群中都改变纤维化的轨迹，而且成本远低于任何抗纤维化的药物。第二条线是把已有的炎症控制达标：哮喘与炎症性肠病与类风湿与慢性肾病的达标治疗，并把依从性当作临床问题（药费与复诊的距离与方案的复杂度都是纤维化的决定因素）。第三条线是早发现的工具：无创的血与影像的评分（血小板与转氨酶与年龄的组合与瞬时的弹性成像），把它们放进已有的门诊路径而不是新建一条路径；筛查必须与清晰的转诊界线写在一起（异常即转诊、病因的检查清单、酒精与代谢的介入同时开始），否则筛查只是制造焦虑。第四条线是把已确诊者纳入随访的结构（按分期与器官的功能定时复查、并发症的筛查、移植的早期讨论、以及戒烟与营养与运动的一致建议）。评价的指标要提前定：人群的可控刺激的暴露率、无创评估的完成率与异常者的后续完成率、终末期器官病的年发病数与不同十分位之间的差别（因为规划最容易在依从性最好的人群中先见效而扩大不平等）、以及每一例的成本与失访的比例。同时说明证据的限度：一级预防的效应需要多年的观察，因此要用中间的指标与严格的对照与公开的假设，避免把“筛查的参与率上升”当作“纤维化减少”的证据（[[public-health/screening]]、[[gastrointestinal/liver-disease]]、[[public-health/environmental-occupational]]、[[public-health/determinants-inequalities]]、[[renal/chronic-kidney-disease]]）。**

一名患者的淋巴结活检报告“不伴坏死的肉芽肿”；请给出一套完整的检查（含病史的问题）并说明各自的目的。
::: solution
**目标是回答“为什么有肉芽肿”（[[#def-granuloma]]、[[#def-chronic]]）。病史问五组：一是呼吸与全身的症状（咳嗽与气促与眼红与面部的皮疹与关节的痛与腮腺的肿）；二是暴露，包括鸟与加湿器与霉变的干草与木材与猫与生食与饮水与装修的粉尘与爱好中的打磨石材；三是感染的可能（结核的接触与（在流行区的）旅行与（在性传播的）的病史与（在猫抓后的））；四是用药（在若干药物可以引起肉芽肿的药理性的反应）；五是既往的肿瘤与自身免疫的病史。检查的次序：血液（血相与肝的酶与钙与（在必要时））的肾的）与感染的筛查（结核的血液的试验与（在按暴露的））真菌的（在血清学与（在培养中的））与病毒的与性传播的病原的）与（在怀疑血管炎者））的抗中性的细胞的胞浆的抗体；影像（胸的计算机断层按（在上叶与（在沿淋巴管与（在肺门对称的）的分布来读）；组织的复检（要求补做抗酸与六胺银的染色与（在必要时）的分子与培养，因为“肉芽肿”的诊断在染色做完之前是不完整的）。最后是诊断的逻辑：结节病是排除性的诊断，它的成立条件是形态符合、部位符合、感染被排除、且有（在若干体系中的）血清与影像的支持；在免疫抑制的患者中要更保守，因为真菌与分枝杆菌可以给出几乎相同的图像（[[respiratory/interstitial-vascular-disease]]、[[infectious-diseases/tuberculosis]]、[[clinical-skills/medical-imaging]]。**

## 练习

::: exercise 处理一个不愈合的创面 {level=2}
一名糖尿病患者的足底溃疡已十周，边缘胼胝、基底可见腱、探及骨、渗液不多但血糖控制差；他拒绝住院。请在门诊设计处理的方案并说明风险。
::: solution
**先说清这例的三个急迫问题（[[#def-repair]]、[[#def-chronic]]、[[endocrine/diabetes-complications]]、[[surgery/wounds-surgical-infection]]）。第一，探及骨意味着骨髓炎的可能很高，这在糖尿病足中是一个很实用的体征（探针能碰到骨，阳性的预测价值在患病率高的场景中相当有用）；需要深部组织的培养（而不是表面的拭子）与影像（磁共振对骨髓炎的敏感性最好）与血液的炎症标志与血相与血流的评估。第二，边缘的胼胝与足底的位置意味着压力是持续存在的病因：不清除胼胝、不做减压（在特定的鞋具与（在必要时）不可承重的支具与（在卧床依从性差者的）暂时性的石膏的固定），任何敷料都不会成功。第三，血流的评估先于激进的处理：趾臂的指数与（在异常者的）血管的超声与（在选择者的）造影；若在缺血的情况下做广泛的清创，结果是更大的创面。骨髓炎成立时的治疗是长的疗程（在若干方案中六周，静脉与口服的转换在若干研究中是可接受的）并按培养与本地的耐药选择，同时保留“手术的清创与（在有限的 bone 的受累者的）部分骨切除”的可能性，因为单靠抗生素在缺血与死骨存在时经常失败。血糖与营养与疼痛与（在感觉缺失者的）教育同样重要： 他拒绝住院是可以被部分接受的立场，前提是门诊的路径可以承担（每天的换药与随访的频率与培养与影像与血管的评估可在门诊完成）；要向他说明拒绝的是什么（不是“住院”这个形式，而是减压与静脉的抗生素与血管的介入的组合）；并给出可被实现的次优方案（每天到门诊换药与口服的按培养的抗生素与（在依从的血糖监测下的）药物的调整与（在必要时）足科的门诊的胼胝清除）。报警的界限要写清楚（发热与红肿的扩展与恶臭与脓与血糖的失控与意识的改变即刻回来）；并预约骨与血管与内分泌与足病与慢性疼痛与抑郁方面心理的共同随访。若骨髓炎进展或血供无法重建，讨论的部分是截肢的平面与（在术后的）康复与假肢的评估与（在流行区）——把“不住院”变成一个有时间表与责任人的计划，比说服他住院更能保住这只脚（[[geriatrics-palliative/symptom-control]]、[[clinical-skills/communication]]、[[public-health/health-systems-economics]]）。**

::: exercise 评价抗纤维化的治疗 {level=3}
一种新药在特发性肺纤维化的二期试验中把十二周时的用力肺活量的下降速率从每年240毫升改为每年160毫升；请评价这一证据并说明你会如何在临床中使用它。
::: solution
**评价分四层（[[#def-repair]]、[[epidemiology-ebm/critical-appraisal]]、[[respiratory/interstitial-vascular-disease]]）。第一层是终点：用力肺活量的年下降率是替代终点，它与死亡与急性加重与生活质量相关，但只是部分相关。已获批的两种药正是在这一终点上取得效应，所以方向一致；要问的是效应的大小是否达到临床意义：八十毫升的差别落在最小重要差别的边缘，个体患者在十二周内几乎察觉不到。第二层是设计：二期的样本量小、随访短；需要检查是否按基线的功能与弥散能力与影像的纤维化范围分层，是否预设了统计的规则，以及退出与死亡与急性加重在各组之间是否平衡——在肺纤维化的试验里，不对称的退出常常本身就是结局的信号。第三层是外推：试验排除的患者在门诊很常见，例如合并肺动脉高压与肺气肿与结缔组织病相关的纤维化与药物或放疗后的纤维化；同时还要问诊断是否可靠，“特发性”意味着已排除其他原因，而试验通常要求多学科的病例确认，实际临床常常省略这一步，结果是把可治疗的病当特例治了。第四层是风险与代价：抗纤维化的药有胃肠的副作用与光敏与肝酶的监测的需要与相互作用的考虑，并可能延误移植的讨论或（在少数人中）加速衰退；因此真正的决定不是“用不用一个药”，而是“何时开始、按什么监测、何时停”。我的用法：只有在诊断经多学科确认、基线的功能与影像与症状被记录、并已向患者说明这不是治愈而是可能减慢下降之后才使用；把替代终点的改善讲成概率而不是承诺；并安排随访的时点（三至六个月的肺功能与症状与副作用的评估与（在恶化者）重新讨论诊断与移植的评估与缓和照护的并行）（[[respiratory/gas-exchange]]、[[clinical-skills/communication]]、[[medical-ethics-law/consent-capacity]]、[[geriatrics-palliative/palliative-care]]）。**
