急性炎症的设计初衷是短暂的。它清除损伤的原因，然后自行关闭。当病因无法清除，或者关闭机制失灵时，炎症就会持续数周、数月乃至数年。细胞组成发生变化，组织被本应保护它的反应所损伤，修复与破坏同时进行。这就是**慢性炎症**，它是许多成人重大疾病的基础：结核病、类风湿关节炎、炎症性肠病、肝硬化，以及以较隐匿形式存在的动脉粥样硬化。

本章后半部分讲述**修复**：损伤后组织如何通过原有细胞的再生或结缔组织瘢痕得到恢复。这两个主题是相互关联的，因为驱动慢性炎症的细胞也驱动瘢痕形成，而且过度修复（纤维化）本身就是器官衰竭的主要原因。

## 什么是慢性炎症

::: definition 慢性炎症 {#def-chronic}
**慢性炎症**是持续时间长（数周至数年）的炎症，其中活动性炎症、组织破坏和修复尝试同时进行。其特征是：

- **单个核细胞**浸润：巨噬细胞、淋巴细胞和浆细胞；
- **组织破坏**，主要由这些细胞的产物引起；
- **愈合尝试**，表现为新生血管形成（血管生成）和纤维化。
:::

慢性炎症可以继发于未能消退的急性炎症，例如脓肿未引流时。更常见的是隐匿起病，没有急性期。主要原因有：

- 能抵抗杀伤的病原体引起的**持续感染**：结核分枝杆菌、梅毒螺旋体、某些病毒、真菌和寄生虫。它们常激发一种称为迟发型超敏反应的T细胞反应。
- **长期接触有害物质**，可来自外部（吸入的无法被消化的二氧化硅），也可来自内部（动脉壁中的脂质）。
- **免疫介导的炎症性疾病**：类风湿关节炎等自身免疫病，即免疫系统对机体自身组织发生反应；以及哮喘等过敏性疾病。

## 慢性炎症的细胞

### 巨噬细胞

**巨噬细胞**是慢性炎症的核心细胞。血液单核细胞按急性炎症中描述的方式进入组织，成熟为巨噬细胞，可存活数月。许多器官还含有出生前就定居于此的常驻巨噬细胞：肝的库普弗细胞、脑的小胶质细胞、肺的肺泡巨噬细胞。

巨噬细胞对其周围环境作出反应，可以通过两种大致的方式被活化。这种二分法是对一个连续谱的简化，但很有用。

- **经典活化**（有时称为M1）由微生物产物和T细胞产生的干扰素-γ（IFN-γ）诱导。这些巨噬细胞能有效杀死微生物，产生活性氧、一氧化氮和溶酶体酶，并分泌TNF、IL-1和IL-12等炎症细胞因子。它们也损伤组织。
- **替代活化**（有时称为M2）由IL-4和IL-13诱导。这些巨噬细胞杀伤微生物的能力差，但促进修复：它们分泌TGF-β和PDGF等生长因子，刺激血管生成、成纤维细胞增殖和胶原合成。

在愈合中的伤口里，巨噬细胞群从前一种类型转向后一种类型。在慢性炎症中，两者可能同时存在，因此组织在同一部位既被破坏又形成瘢痕。

### 淋巴细胞、浆细胞及其他细胞

**T淋巴细胞**既对巨噬细胞作出反应，又驱动巨噬细胞。不同类型的CD4辅助性T细胞产生不同的细胞因子：Th1细胞产生IFN-γ，使巨噬细胞经典活化；Th2细胞产生IL-4、IL-5和IL-13，活化嗜酸性粒细胞和替代型巨噬细胞；Th17细胞产生IL-17，募集中性粒细胞。**B淋巴细胞**分化为分泌抗体的**浆细胞**。在某些长期炎症中，如类风湿滑膜，淋巴细胞组织成类似淋巴结滤泡的结构。这些细胞的免疫学在[[immunology/adaptive-responses]]中展开。

**嗜酸性粒细胞**是过敏性炎症和寄生虫感染的特征。其颗粒含有主要碱性蛋白，对寄生虫有毒性，也损伤上皮。**肥大细胞**遍布全身的结缔组织，参与急性和慢性过敏反应。

::: theorem 巨噬细胞-淋巴细胞环路 {#thm-loop}
慢性炎症能够自我维持，是因为巨噬细胞和T淋巴细胞相互刺激。巨噬细胞向T细胞呈递抗原并分泌IL-12，促进Th1分化。活化的T细胞分泌IFN-γ，活化更多的巨噬细胞。活化的巨噬细胞释放细胞因子，募集更多的单核细胞和淋巴细胞。只要抗原持续存在，这一环路就会继续运转。
:::

这解释了慢性炎症为何难以关闭，也解释了慢性炎症性疾病的治疗为何在环路的不同节点上发挥作用：糖皮质激素作用广泛，甲氨蝶呤和其他免疫抑制剂，以及针对TNF、IL-12/23或T细胞共刺激的生物制剂。

## 肉芽肿性炎

**肉芽肿**是慢性炎症的一种独特形式，当机体无法消灭某种持续存在的物质时就会采用它：不是消灭，而是把它围起来。

::: definition 肉芽肿 {#def-granuloma}
**肉芽肿**是由活化的巨噬细胞组成的紧密、有组织的聚集，常含多核巨细胞，周围环绕一圈淋巴细胞。活化的巨噬细胞称为**上皮样细胞**，因为它们胞质丰富、呈粉红色，彼此紧密排列如同上皮。**巨细胞**由巨噬细胞融合而成；**朗汉斯巨细胞**（Langhans giant cell）的细胞核在细胞边缘排列成马蹄形，**异物巨细胞**的细胞核则散在分布。

含有中心干酪样坏死的肉芽肿称为**干酪样肉芽肿**（结核病的典型表现），没有的称为**非干酪样肉芽肿**（结节病和克罗恩病的典型表现）。
:::

肉芽肿在两种情况下形成。持续存在的抗原驱动T细胞反应时，形成**免疫性肉芽肿**，如结核病。惰性物质太大而无法被吞噬时，在其周围形成**异物肉芽肿**，如缝线材料、滑石粉或破裂囊肿中的角蛋白；它不需要特异性免疫反应。

| 疾病 | 病因 | 典型肉芽肿 |
|---|---|---|
| 结核病 | 结核分枝杆菌 | 干酪样，伴朗汉斯巨细胞；抗酸染色（Ziehl-Neelsen）见抗酸杆菌 |
| 麻风 | 麻风分枝杆菌 | 位于皮肤和神经；菌量多少取决于宿主反应 |
| 梅毒（三期） | 梅毒螺旋体 | 树胶肿：坏死中心，浆细胞显著 |
| 真菌感染 | 组织胞浆菌、隐球菌等 | 常有坏死；特殊染色可见病原体 |
| 猫抓病 | 汉赛巴尔通体 | 淋巴结内星状肉芽肿，中心有中性粒细胞 |
| 结节病 | 不明 | 非干酪样，见于淋巴结、肺、皮肤和眼 |
| 克罗恩病 | 对肠内容物的免疫反应 | 非干酪样，位于肠壁 |
| 异物 | 缝线、滑石粉、晶体 | 异物巨细胞；可见异物，有时需偏振光 |

::: proof
结核病为什么会引起肉芽肿？结核分枝杆菌被巨噬细胞吞入，但它通过阻止吞噬体与溶酶体融合而在细胞内存活。被感染的巨噬细胞向CD4 T细胞呈递分枝杆菌抗原并分泌IL-12。T细胞分化为Th1细胞并分泌IFN-γ，后者活化巨噬细胞，使其能够杀死或至少遏制杆菌。活化的巨噬细胞变成上皮样细胞，部分融合成巨细胞。巨噬细胞和T细胞产生的**TNF**维持这一结构，并不断募集细胞。在中心，细胞的活动和氧供不足导致干酪样坏死。因此，肉芽肿以局部组织破坏为代价遏制了感染。如果T细胞反应失败，如在晚期HIV感染中，肉芽肿形成不良，杆菌就会播散。
:::

::: example 咳嗽与空洞 {#ex-tb}
一名32岁男性从结核病高发国家移居英国，咳嗽、盗汗和体重下降已三个月。胸片显示右上叶有一空洞。经支气管镜活检见伴中心干酪样坏死和朗汉斯巨细胞的肉芽肿。解释其病理，以及病理医师下一步会做什么。
::: solution
1. 肺内伴干酪样坏死和朗汉斯巨细胞的肉芽肿强烈提示**结核病**，尽管真菌感染可以有相似表现。
2. 干酪样物质液化并经支气管咳出后形成空洞。空洞壁含有大量杆菌，因此患者很可能具有传染性。
3. 病理医师会申请**抗酸染色**（Ziehl-Neelsen染色）查找抗酸杆菌，标本应送分枝杆菌培养和分子检测，后者能比培养更快地检出病原体和耐药突变。
4. 盗汗和体重下降等全身症状由细胞因子引起，尤其是TNF。
5. 治疗、接触者追踪和公共卫生报告遵循国家指南（[[infectious-diseases/tuberculosis]]）。
:::
:::

::: example 结节病中的高钙血症 {#ex-sarcoid}
一名41岁黑人女性双侧肺门淋巴结肿大，双胫前有触痛的红色结节，血清钙2.85 mmol/L（参考范围约2.2至2.6）。淋巴结活检见紧密的非干酪样肉芽肿；分枝杆菌和真菌的染色和培养均为阴性。解释她的血钙为何升高。
::: solution
1. 病原体染色阴性的非干酪样肉芽肿，加上双侧肺门淋巴结肿大和结节性红斑的典型表现，指向**结节病**。这是一个排除性诊断，因为结核病、真菌感染和淋巴瘤可以产生相似的表现。
2. 肉芽肿中活化的巨噬细胞表达**1α-羟化酶**，该酶将25-羟维生素D转化为活性激素1,25-二羟维生素D（骨化三醇）。
3. 与肾脏的该酶不同，巨噬细胞的这种酶不受甲状旁腺激素调控，因此骨化三醇过量生成。它增加肠道对钙的吸收，血清钙升高，而甲状旁腺激素被抑制。
4. 日光照射增加维生素D的生成，可加重高钙血症。同样的机制也见于某些淋巴瘤和结核病。
:::
:::

## 慢性炎症的全身影响

慢性炎症通过循环中的细胞因子影响全身。

- **慢性病贫血。** IL-6使肝脏产生更多的铁调素，后者把铁滞留在巨噬细胞和肠黏膜中。体内有铁，但无法用于生成红细胞（[[blood/anaemia]]）。
- **恶病质。** TNF等细胞因子引起食欲减退以及肌肉和脂肪的分解。
- **反应性（AA型）淀粉样变。** 急性期蛋白血清淀粉样蛋白A长期处于高水平，可导致其片段以不溶性淀粉样纤维的形式沉积于肾、肝和脾。它是长期未经治疗的类风湿关节炎、慢性感染和家族性发热综合征的并发症，通常表现为蛋白尿。淀粉样物质经刚果红染色后在偏振光下呈苹果绿色双折光。

没有典型表现的低度慢性炎症也参与常见病的发生。在**动脉粥样硬化**中，滞留于动脉壁的脂蛋白被氧化，巨噬细胞将其摄取变成泡沫细胞，斑块表现为一种慢性炎症病变（[[cardiovascular/coronary-artery-disease]]）。CANTOS试验（2017年）支持了其临床意义：在既往心肌梗死且CRP升高的人群中，一种抗IL-1β抗体减少了心血管事件的复发，但增加了致死性感染，至今尚未进入常规使用。**肥胖**伴有脂肪组织的巨噬细胞浸润和胰岛素抵抗。低度炎症随年龄增长而增加，有时称为“炎性衰老”。

## 再生

损伤后，组织以两种方式之一得到恢复。**再生**以同类型的细胞替代受损细胞，恢复正常的结构和功能。**结缔组织修复**则以瘢痕替代它们。发生哪一种，取决于细胞的分裂能力以及组织的支持框架是否保存。

::: definition 组织的增殖能力 {#def-cell-types}
- **不稳定组织**（labile tissue）所含细胞终生持续分裂，以替代丢失的细胞：皮肤、口腔、肠道和泌尿道的表面上皮，以及骨髓。
- **稳定组织**（stable tissue）所含细胞通常处于静止状态，但在损伤后能够分裂：肝细胞、肾小管细胞、成纤维细胞、内皮细胞和平滑肌细胞。
- **永久性组织**（permanent tissue）所含细胞在成年后基本不能分裂：神经元和心肌细胞。它们受损后由瘢痕（心脏）或胶质瘢痕（脑）修复。骨骼肌可通过卫星细胞有限地再生。
:::

再生还需要**细胞外基质**得以保存。基底膜和结缔组织框架引导再生的细胞形成正确的排列。肝脏说明了这一点。健康肝脏部分切除后，剩余的肝细胞分裂，数周内肝脏恢复原有体积，活体肝移植正是利用了这一特性。但当肝细胞反复被破坏、框架塌陷并被纤维组织取代时，再生产生的是紊乱的结节而不是正常的小叶。这就是**肝硬化**。

## 瘢痕修复

当无法再生或损伤范围广泛时，机体会沉积结缔组织。这一过程分为相互重叠的几个阶段。

1. **炎症与清除。** 形成血凝块，中性粒细胞继而巨噬细胞清除死亡组织和碎屑。巨噬细胞对后续过程至关重要。
2. **肉芽组织。** 三至五天内，该区域被**肉芽组织**填充：新生的薄壁毛细血管、增殖的成纤维细胞和疏松水肿的基质。其名称来自表面红色颗粒状的外观，每一颗粒是一个毛细血管袢。它很容易出血。
3. **胶原沉积与瘢痕形成。** 成纤维细胞沉积胶原，先是III型，随后主要是I型。血管退化。组织变得苍白而坚实。
4. **改建。** 在数月中，胶原由**基质金属蛋白酶**和成纤维细胞分解并重建，发生交联，沿应力方向排列，瘢痕逐渐成熟。

::: theorem 生长因子驱动修复 {#thm-repair}
瘢痕修复主要由巨噬细胞和血小板释放的生长因子协调：

- **VEGF**（血管内皮生长因子）驱动**血管生成**，即新血管从已有血管出芽；
- **PDGF**和**FGF**刺激成纤维细胞迁移和增殖；
- **TGF-β**（转化生长因子β）是最重要的**致纤维化**因子：它刺激胶原合成，抑制基质降解，并使成纤维细胞转变为能够收缩的**肌成纤维细胞**。

TGF-β持续活化是许多器官纤维化的共同通路。
:::

### 皮肤伤口的愈合

皮肤伤口经历相同的阶段，其愈合按伤口边缘如何对合进行分类。

**一期愈合**（primary union）见于用缝线对合边缘的清洁切口。组织丢失很少，因此肉芽组织少，瘢痕细。典型的时间进程如下：

| 时间 | 事件 |
|---|---|
| 24小时 | 血凝块填充切口；边缘有中性粒细胞；表皮开始向切口生长 |
| 3天 | 巨噬细胞取代中性粒细胞；肉芽组织开始填充裂隙 |
| 5天 | 肉芽组织填满间隙；新生血管最丰富；胶原桥接切口 |
| 2周 | 胶原积累，血管退化，瘢痕变白 |
| 1个月及以后 | 由完整表皮覆盖的结缔组织瘢痕；改建持续数月 |

**二期愈合**（secondary union）见于大的或开放的伤口，如溃疡、大的脓腔或感染伤口。形成的肉芽组织多得多，炎症更明显，肌成纤维细胞引起的**伤口收缩**缩小缺损的面积，有时可缩小其大部分。瘢痕较大。

### 抗张强度

愈合中的伤口在数周内都很薄弱。约一周拆除皮肤缝线时，伤口只有未受伤皮肤强度的约10%。此后一个月内，随着胶原积累和交联，强度迅速增加，约三个月时达到正常的70%至80%的平台期，永远不会恢复到100%。

2. 第6周：$e^{-(6-4)/1.5} = e^{-1.333} \approx 0.264$，所以$S = 80/1.264 \approx 63.3\%$。
3. 在第二周到第六周之间，伤口强度迅速增加，但即使到第六周，仍远低于正常皮肤。
4. 这就是腹部手术后的患者被建议数周内避免提重物的原因，也是伤口在早期受力时可能裂开（伤口裂开）的原因，尤其是在愈合延迟时。这些数字是示意性的；实际建议以手术团队为准。
:::
:::

### 妨碍愈合的因素

局部和全身因素都会减慢或阻止愈合。

- **局部因素**：感染，这是导致愈合延迟最重要的单一原因；血供不良（外周动脉疾病、静脉疾病）；缝线或碎片等异物；机械应力或活动；既往放疗；压迫，如压疮。
- **全身因素**：糖尿病，损害白细胞功能和微循环；营养不良，尤其是蛋白质缺乏和**维生素C缺乏**（胶原中脯氨酸的羟化需要维生素C）；**糖皮质激素**，抑制炎症和TGF-β的产生，从而削弱瘢痕；吸烟；高龄。

::: warning 不要把肉芽组织误认为肉芽肿
两者名称相似，但结构毫不相关。**肉芽组织**是正常愈合中富含血管和成纤维细胞的组织，见于每一个正在修复的伤口。**肉芽肿**是一种特定类型的慢性炎症所产生的活化巨噬细胞聚集，常提示结核病、结节病或异物。溃疡活检报告“肉芽组织”是意料之中的；报告“肉芽肿”则引出一系列鉴别诊断。
:::

## 异常修复与纤维化

修复可能在三个方向上出错。

- **瘢痕形成不足**导致**伤口裂开**（伤口重新张开）或慢性溃疡，如静脉性腿部溃疡和糖尿病足溃疡。
- **瘢痕形成过度。** **增生性瘢痕**隆起但局限于原伤口范围内，常随时间消退。**瘢痕疙瘩**（keloid）超出原伤口的边界生长且不消退；瘢痕疙瘩在非洲裔和亚洲裔人群中以及耳垂、胸部和肩部更为常见。高出皮肤、妨碍上皮化的过度生长的肉芽组织称为“赘肉”（proud flesh）。
- **挛缩。** 瘢痕过度收缩，尤其是跨关节的烧伤后，可将肢体固定在畸形的位置。

内脏器官的**纤维化**是不停止的修复。当损伤持续存在时，如慢性病毒性肝炎、酒精相关性肝病、代谢功能障碍相关脂肪性肝病或特发性肺纤维化，修复信号也持续存在。在肝脏，**肝星状细胞**对TGF-β发生反应，转变为肌成纤维细胞并沉积胶原。在肺，肺泡壁中的成纤维细胞也是如此。正常组织被瘢痕取代，器官衰竭。减缓纤维化的药物现已用于特发性肺纤维化（吡非尼酮和尼达尼布），还有更多药物在研究中（[[respiratory/interstitial-vascular-disease]]）。

由于纤维化是慢性肝病预后的主要决定因素，人们采用无创方法对其进行评估。一个广泛使用的评分是**FIB-4**：

$$
\text{FIB-4} = \frac{\text{年龄（岁）} \times \text{AST（U/L）}}{\text{血小板 }(10^9/\text{L}) \times \sqrt{\text{ALT（U/L）}}}
$$ {#eq-fib4}

数值低于1.3提示进展期纤维化可能性小，高于2.67提示可能性大；介于两者之间的需要进一步检查，如增强肝纤维化（ELF）血液检测或弹性成像。这些阈值主要在35至65岁人群中得到验证。

::: example 纤维化评分 {#ex-fib4}
一名58岁女性患2型糖尿病，超声示脂肪肝，AST 45 U/L，ALT 50 U/L，血小板$160 \times 10^9$/L。计算她的FIB-4并说明其意义。
::: solution
1. 分子：$58 \times 45 = 2610$。
2. 分母：$160 \times \sqrt{50} = 160 \times 7.071 \approx 1131$。
3. FIB-4 $\approx 2610/1131 \approx 2.31$。
4. 该值介于1.3和2.67之间，因此为**不确定**：进展期纤维化既未被排除，也未被证实。
5. 在英国许多诊疗路径中，下一步是ELF检测或瞬时弹性成像。这个评分之所以有效，是因为纤维化使血小板计数降低（通过门静脉高压和血小板生成素减少），并且随着肝脏瘢痕化，AST相对于ALT升高。纳入年龄是因为纤维化随时间累积（[[gastrointestinal/liver-disease]]）。
:::
:::

::: example 不愈合的溃疡 {#ex-ulcer}
一名74岁男性患2型糖尿病，足底溃疡已三个月。双足感觉减退，足部动脉搏动弱。溃疡边缘活检见慢性炎症、血管稀少的肉芽组织，无恶性病变。解释溃疡为何不愈合。
::: solution
1. **神经病变**使他感觉不到压力或损伤，因此溃疡在行走时反复受创。
2. 外周动脉疾病导致的**缺血**限制了氧和营养物质的供应，因此肉芽组织形成不良；活检显示血管稀少。
3. **高血糖**损害中性粒细胞的趋化和杀伤功能，糖尿病伤口常发生感染，使炎症迁延。
4. 糖尿病还妨碍巨噬细胞从炎症状态向修复状态的转换，生长因子信号也减弱。
5. 活检排除了恶变，长期溃疡偶尔会发生恶变。按照国家指南，处理需要多学科足部护理团队：减轻压力、治疗感染、尽可能恢复血流以及控制血糖（[[endocrine/diabetes-complications]]）。
:::
:::

::: quiz
外科医生询问为什么长期服用大剂量泼尼松龙的患者腹部瘢痕薄弱。哪一种解释最好？
- [ ] 糖皮质激素增加TGF-β，引起过度纤维化。
- [x] 糖皮质激素抑制炎症，减少TGF-β和胶原合成，因此沉积的胶原较少。
- [ ] 糖皮质激素直接破坏成纤维细胞。
- [ ] 糖皮质激素引起维生素C缺乏。
::: solution
糖皮质激素减弱炎症阶段，包括驱动修复的巨噬细胞，并降低TGF-β的产生和胶原的合成。瘢痕中的胶原较少，抗张强度较低。它们不会引起过度纤维化，不会直接破坏成纤维细胞，也不会引起坏血病。
:::
:::

::: history
1868年，德国病理学家朗汉斯（Theodor Langhans）描述了结核肉芽肿中细胞核位于周边的多核巨细胞，这种细胞后来以他的名字命名。1882年，科赫（Robert Koch）确定结核分枝杆菌是结核病的病因，把肉芽肿与特定微生物联系起来。梅奇尼科夫（Élie Metchnikoff）在19世纪80年代关于吞噬细胞的研究，使巨噬细胞成为炎症和防御的中心。1971年，加比亚尼（Giulio Gabbiani）和马伊诺（Guido Majno）在肉芽组织中发现了**肌成纤维细胞**：一种含有收缩丝的成纤维细胞，从而解释了伤口如何收缩。同年，福克曼（Judah Folkman）提出肿瘤依赖于血管生成，这一概念也改变了对肉芽组织和修复的研究。
:::

## 后续内容

慢性炎症和纤维化出现在各个器官系统中：肝脏（[[gastrointestinal/liver-disease]]）、肺（[[respiratory/interstitial-vascular-disease]]）、关节（[[musculoskeletal/inflammatory-arthritis]]）和肾脏（[[renal/chronic-kidney-disease]]）。其免疫机制在[[immunology/autoimmunity]]和[[immunology/hypersensitivity]]中展开。手术和创伤后受损组织的修复见[[surgery/wounds-surgical-infection]]。慢性炎症也是癌的危险因素，见[[pathology/cancer-biology]]。

::: summary
- 慢性炎症是持续时间长的炎症，其中炎症、组织破坏和修复同时发生，有巨噬细胞、淋巴细胞和浆细胞参与。
- 原因：持续感染、长期接触有害物质，以及自身免疫病和过敏性疾病。
- 巨噬细胞可经典活化（杀伤、组织损伤）或替代活化（修复、纤维化）。巨噬细胞和T细胞通过IL-12和IFN-γ相互维持。
- 肉芽肿是由上皮样巨噬细胞、巨细胞和淋巴细胞组成的有组织聚集；干酪样肉芽肿提示结核病，非干酪样肉芽肿提示结节病、克罗恩病或异物。TNF维持肉芽肿。
- 全身影响：慢性病贫血、恶病质、AA型淀粉样变；低度炎症参与动脉粥样硬化。
- 组织分为不稳定、稳定和永久性三类。再生既需要能分裂的细胞，也需要完整的基质框架。
- 瘢痕形成：血凝块与炎症、肉芽组织、胶原沉积、改建。VEGF驱动血管生成，TGF-β驱动纤维化。
- 伤口通过一期或二期愈合；一周时强度约为10%，三个月时约为70%至80%。
- 感染、缺血、糖尿病、营养不良、维生素C缺乏和糖皮质激素妨碍愈合。异常修复包括伤口裂开、瘢痕疙瘩、挛缩和器官纤维化。
:::

::: exercise 描述肉芽肿 {level=1}
描述结核肉芽肿的显微结构，说出每个组成部分，以及用于寻找病原体的染色方法。
::: solution
中心为干酪样坏死：无定形、粉红色、颗粒状的碎屑，没有细胞轮廓。其周围是胞质丰富、粉红色的上皮样巨噬细胞，以及细胞核在周边排列成马蹄形的多核朗汉斯巨细胞。肉芽肿外周环绕一圈淋巴细胞，陈旧病灶中有成纤维细胞和纤维化。抗酸染色（Ziehl-Neelsen染色）将抗酸杆菌显示为红色杆状。
:::

::: exercise 计算FIB-4 {level=1 check="1.25"}
计算一名50岁男性的FIB-4：AST 40 U/L，ALT 64 U/L，血小板$200 \times 10^9$/L。给出精确值。
::: solution
$\dfrac{50 \times 40}{200 \times \sqrt{64}} = \dfrac{2000}{1600} = 1.25$。该值低于1.3，因此进展期纤维化可能性小。
:::

::: exercise 一期还是二期 {level=2}
从以下方面比较一期愈合和二期愈合：肉芽组织的量、伤口收缩的作用、最终瘢痕的大小以及典型例子。
::: solution
一期愈合：肉芽组织少，收缩少，形成细线状瘢痕；典型的是清洁的缝合手术切口。二期愈合：大量肉芽组织填充大的缺损，肌成纤维细胞引起明显收缩（可使伤口面积大幅缩小），瘢痕较大；典型的是开放伤口、溃疡、感染伤口和引流后的脓腔。
:::

用$S(t) = \dfrac{80}{1 + e^{-(t-4)/1.5}}$计算第3周时伤口强度占未受伤皮肤的百分比。保留一位小数。
::: solution
$e^{-(3-4)/1.5} = e^{0.667} \approx 1.948$，所以$S = 80/2.948 \approx 27.1\%$。

::: exercise 抗TNF与结核 {level=2}
类风湿关节炎患者在开始使用抗TNF药物之前要筛查潜伏性结核。用肉芽肿的生物学解释原因。
::: solution
潜伏性结核中，少量活的杆菌被遏制在肉芽肿内。TNF是形成和维持肉芽肿所必需的：它募集并活化巨噬细胞，维持其有组织的结构。阻断TNF可使肉芽肿瓦解，释放杆菌并导致复燃，后者常表现为播散性或肺外病变。筛查能识别潜伏感染者，使他们在使用生物制剂之前或同时接受治疗，遵循国家指南。
:::
:::

::: exercise 不断长大的瘢痕 {level=3}
一名19岁尼日利亚裔女性打了耳洞。一年后，一侧耳垂上长出一个坚硬、发亮的结节，远远超出耳洞范围。曾切除一次，复发后更大。说出这一病变的名称，解释它与增生性瘢痕的区别，并说明它为何复发。
::: hint
把病变的边界与原伤口相比较。
:::
::: solution
这是**瘢痕疙瘩**：致密胶原的过度生长，超出原伤口边界且不消退。增生性瘢痕隆起但局限于原伤口内，常在一两年内变平。瘢痕疙瘩在非洲裔和亚洲裔人群中以及耳垂和胸部等部位更为常见，提示存在遗传易感性。瘢痕疙瘩中的成纤维细胞对TGF-β反应过度，产生异常大量的胶原。切除本身就是一个新的伤口，会触发同样的异常反应，因此除非在切除的同时联合其他措施（如由专科医生选择的激素注射、加压或放疗），瘢痕疙瘩常会复发。
:::
:::

::: exercise 肠道中的肉芽肿 {level=3}
一名23岁男性腹泻、体重下降。结肠镜见斑片状溃疡，溃疡之间肠段正常；活检见透壁性慢性炎症伴非干酪样肉芽肿。给出肠道肉芽肿的鉴别诊断、可以区分它们的检查，并解释炎症为何是慢性的。
::: solution
鉴别诊断包括**克罗恩病**（鉴于跳跃性病变和透壁性炎症，可能性最大）、肠**结核**（尤其是有相关旅行史或来自高发地区者；肉芽肿常较大、融合并有干酪样坏死）、耶尔森菌等其他感染、结节病（胃肠道罕见），以及对肠内容物的异物反应。可资鉴别的检查包括活检组织的抗酸染色、分枝杆菌培养和PCR，用于结核的胸片和干扰素-γ释放试验，粪便培养，以及影像学和内镜检查的整体表现。克罗恩病的炎症是慢性的，因为对肠道自身微生物内容物的免疫反应无法消退：抗原始终存在，由IL-12/23、IFN-γ和TNF维持的巨噬细胞-淋巴细胞环路持续运转。这就是使用针对TNF或IL-12/23的生物制剂的原因（[[gastrointestinal/bowel-disease]]）。
:::
