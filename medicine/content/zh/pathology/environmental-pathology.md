许多人类疾病不是由微生物或缺陷基因引起的，而是由人们呼吸、进食、饮用的东西以及在工作和家中接触的东西引起的。烟草、酒精、肥胖和空气污染是全球疾病和早逝的最大原因之一，而它们在原则上都是可以预防的。本章把[[pathology/cell-injury]]中的细胞损伤机制应用于这些环境和营养性病因。内容包括烟草、酒精、药物损伤、污染物和职业暴露、包括辐射在内的物理因素、营养不良和维生素缺乏，以及肥胖。

政策和预防等人群层面的内容见[[public-health/environmental-occupational]]和[[public-health/prevention-promotion]]。这里关注的是这些因素对细胞和组织做了什么。

## 环境损伤的原理

::: definition 剂量、暴露与易感性 {#def-exposure}
环境因素的作用取决于：

- 到达靶组织的**剂量**，它取决于浓度、暴露持续时间和途径（吸入、摄入、皮肤）；
- **代谢**：许多化学物质在被酶（常为肝脏的细胞色素P450酶）转化为活性产物之前是无害的（**生物活化**），而另一些则通过结合反应被解毒并排出；
- 个体的**易感性**：年龄、性别、代谢酶的遗传变异、营养状态以及并存疾病。

因此，同样的暴露可能伤害一个人而放过另一个人。
:::

本章反复出现两种一般机制。**活性代谢物**与蛋白质和DNA共价结合，损伤细胞或引起突变。**氧化应激**来自活性氧，当它压倒细胞的抗氧化防御（尤其是谷胱甘肽）时，就会损伤膜、蛋白质和DNA。

## 烟草

吸烟是英国最大的单一可预防死因，也是全世界最大的可预防死因之一。WHO估计烟草每年导致700多万人死亡。长期吸烟者中约一半（在某些研究中更多）死于吸烟引起的疾病。

香烟烟雾含有数千种化学物质。最重要的几类是：

- **尼古丁**，作用于脑内的烟碱型乙酰胆碱受体，引起依赖。它本身不是癌症或肺病的主要原因。
- 颗粒相“焦油”中的**致癌物**，包括多环芳烃（如苯并[a]芘）和烟草特有亚硝胺。它们被生物活化为能与DNA结合并引起突变的化合物，例如肺癌中的*TP53*和*KRAS*突变。
- **氧化剂和刺激物**，损伤气道，募集中性粒细胞和巨噬细胞，并使抗蛋白酶失活。
- **一氧化碳**，降低血液的携氧能力。

吸烟引起的疾病包括：

- **肺癌**，绝大多数病例由吸烟引起；以及口腔、喉、食管、胃、胰腺、肾、膀胱和宫颈的癌，以及急性髓系白血病；
- **慢性阻塞性肺疾病**（COPD）：慢性支气管炎和肺气肿，炎症细胞释放的蛋白酶破坏肺泡壁（[[respiratory/asthma-copd]]）；
- **心血管疾病**：冠心病、卒中、外周动脉疾病和主动脉瘤，机制是内皮损伤、凝血倾向增加和动脉粥样硬化加速；
- **妊娠**中：低出生体重、早产和死产；以及暴露于二手烟的儿童发生婴儿猝死和呼吸道感染。

累积暴露量用**包年**表示：每天吸20支装香烟的包数乘以吸烟年数。肺癌风险随包年数增加而升高，戒烟后下降，但多年内仍高于从不吸烟者。

::: example 吸烟史 {#ex-packyears}
一名63岁女性自23岁起每天吸15支烟。她现在咳嗽已六周。计算她的包年数，并解释她的吸烟史为何重要。
::: solution
1. 每天15支即每天$15/20 = 0.75$包。
2. 她已吸烟$63 - 23 = 40$年。
3. 包年 $= 0.75 \times 40 = 30$。
4. 30包年的吸烟史使她成为肺癌和COPD的高风险者。根据NICE关于疑似癌症的指南，40岁或以上、曾经吸烟且有不明原因咳嗽的人，应接受紧急胸片检查。按年龄和吸烟史，她也符合肺癌筛查的条件。
5. 任何年龄戒烟都能降低进一步受害的风险，戒烟支持是有效的（[[public-health/non-communicable-disease]]）。
:::
:::

**电子烟**以气溶胶形式输送尼古丁而不燃烧烟草。英国公共卫生机构认为，对于完全转用电子烟的成年人，它们比吸烟的危害小得多，并能帮助人们戒烟。它们并非没有风险，其长期影响仍在研究中，不推荐不吸烟者使用，尤其是年轻人。

## 酒精

酒精是肝病最常见的化学性原因，还参与许多其他疾病、伤害和社会危害。

::: definition 酒精单位 {#def-units}
在英国，一个酒精**单位**是10 mL（约8 g）纯乙醇。一杯饮料所含的单位数为

$$
\text{单位数} = \frac{\text{体积（mL）} \times \text{ABV（\%）}}{1000}
$$ {#eq-units}

其中ABV是酒精体积分数。英国首席医疗官的低风险指南（2016年）建议，为使健康风险保持在低水平，男性和女性每周规律饮酒都不应超过**14个单位**，并分散在三天或以上。
:::

### 代谢

大多数乙醇在肝脏中被氧化。**乙醇脱氢酶**把它转化为**乙醛**，**乙醛脱氢酶**把乙醛转化为乙酸。较小部分由细胞色素P450酶CYP2E1代谢，该酶被规律饮酒诱导，并产生活性氧。两个主要反应都产生NADH。这些事实解释了大部分损害：

- **过多的NADH**使肝脏代谢转向合成脂肪、远离脂肪分解，引起脂肪肝。
- **乙醛**有毒且致癌：它与蛋白质和DNA结合。乙醛脱氢酶（*ALDH2*）无活性变异在东亚人群中很常见，携带者乙醛蓄积，饮酒后面部潮红，并且若饮酒则食管癌风险升高。
- 来自CYP2E1的**氧化应激**损伤肝细胞。CYP2E1被诱导也解释了为什么规律饮酒者对某些药物毒性（包括对乙酰氨基酚）更敏感。

### 对肝脏和其他器官的影响

酒精相关性肝病经历三个相互重叠的阶段：

1. **脂肪变**（脂肪肝）：肝细胞内出现脂滴。它见于大多数大量饮酒者，戒酒后可逆。
2. **酒精性肝炎**：肝细胞肿胀（气球样变）并死亡，含有凝集的细胞骨架蛋白（**Mallory-Denk小体**），周围有中性粒细胞。它可以急性起病，表现为黄疸，严重者短期死亡率高。
3. **肝硬化**：肝脏被纤维带和再生结节取代（[[pathology/chronic-inflammation-repair]]），导致门静脉高压和肝衰竭（[[gastrointestinal/liver-disease]]）。

酒精还引起急性和慢性胰腺炎、扩张型心肌病、高血压、心房颤动、胃炎、周围神经病、包括Wernicke-Korsakoff综合征在内的脑损害（通过硫胺素缺乏），以及口腔、咽、喉、食管、肝、肠和乳腺的癌。在妊娠期，酒精通过胎盘，可引起**胎儿酒精谱系障碍**，表现为生长受限、特征性面容以及终生的学习和行为问题。英国的指导意见是，妊娠期最安全的做法是完全不饮酒。

::: example 计算单位 {#ex-units}
一名47岁男性说他“大多数晚上喝一瓶葡萄酒”。一瓶为750 mL，ABV 13%，他每周六个晚上各喝一瓶。计算他每周的摄入量，并与指南相比较。
::: solution
1. 每瓶单位数 $= 750 \times 13/1000 = 9.75$个单位。
2. 每周摄入量 $= 9.75 \times 6 = 58.5$个单位。
3. 这是每周14个单位低风险指南的四倍多。
4. 在这一水平，他发生酒精相关性肝病、高血压、心房颤动和几种癌的风险相当大。评估包括AUDIT等结构化问卷、肝功能检查，并视结果进行肝纤维化检测。
5. 长期每天大量饮酒后突然停饮可引起戒断，而戒断可能有危险，因此减量要在专业支持下有计划地进行（[[psychiatry/substance-use]]）。
:::
:::

## 药物损伤

药物是组织损伤的常见原因。**药物不良反应**常分为两类：一类可由药物的药理作用预测且与剂量相关（A型），如抗凝药引起的出血；另一类不可预测且与剂量无关（B型），如严重的过敏或特异质反应。不良反应的分类和报告见[[pharmacology/adverse-reactions]]。

**对乙酰氨基酚**肝毒性是活性代谢物损伤的经典例子。在治疗剂量下，大多数对乙酰氨基酚与葡萄糖醛酸或硫酸结合后排出。一小部分被细胞色素P450酶（主要是CYP2E1）氧化为一种高度活泼的化合物**NAPQI**（N-乙酰对苯醌亚胺），后者立即通过与**谷胱甘肽**结合而被中和。

::: theorem 活性代谢物引起的毒性 {#thm-napqi}
当产生的活性代谢物的量超过细胞的解毒能力时，过多的部分与细胞蛋白共价结合，引起细胞死亡。对于对乙酰氨基酚，这发生在谷胱甘肽耗竭时。损伤在中央静脉周围（3区）的肝细胞中最重，那里活化酶的浓度最高，氧分压最低。
:::

::: proof
过量服用时，结合途径饱和，于是更大比例的药物被转化为NAPQI。谷胱甘肽消耗的速度超过其再合成的速度。一旦谷胱甘肽降到临界水平以下，NAPQI就与蛋白质（尤其是线粒体中的蛋白质）的半胱氨酸基团结合。随之出现线粒体功能障碍和氧化应激，ATP下降，肝细胞发生坏死（[[pathology/cell-injury]]）。任何增加CYP2E1活性（长期大量饮酒、某些药物）或减少谷胱甘肽储备（饥饿、营养不良）的因素都会增加易感性。解毒剂**乙酰半胱氨酸**通过补充谷胱甘肽起作用，在NAPQI与蛋白质结合造成不可逆损伤之前尽早使用效果最好。
:::

::: example 过量服药后的黄疸 {#ex-paracetamol}
一名19岁女性在过量服用对乙酰氨基酚两天后被送到急诊科。她现在有黄疸、嗜睡。ALT为6800 U/L，凝血酶原时间延长。解释其机制以及血液检查的意义。
::: solution
1. 过量服药使正常的结合途径饱和，于是更多的对乙酰氨基酚被转化为NAPQI，后者耗竭了谷胱甘肽并与肝细胞蛋白结合。
2. 中央静脉周围的肝细胞发生坏死。ALT极高反映这种酶从死亡细胞中漏出。
3. 凝血酶原时间延长表明肝脏已不能充分合成凝血因子：它是**急性肝衰竭**严重程度的标志。嗜睡可能提示肝性脑病。
4. 就诊延迟降低了乙酰半胱氨酸的获益，但仍要使用。她需要按国家指南紧急处理，并尽早与专科肝病中心讨论，因为可能需要考虑肝移植。
5. 一旦身体条件允许，她还需要接受富有同情心的心理社会评估，因为过量服药可能反映自伤；这绝不应被视为不如医学治疗重要。在英国，可随时拨打116 123联系撒玛利亚会（Samaritans）（[[psychiatry/self-harm-suicide-prevention]]）。
:::
:::

## 污染物与职业暴露

**室外空气污染**是气体（二氧化氮、臭氧、二氧化硫）和颗粒物的混合物。**细颗粒物**（PM₂.₅，直径小于2.5 µm的颗粒）可深入肺部，最小的颗粒可能进入血液。它在气道和血管中引起炎症和氧化应激，增加心血管疾病、呼吸系统疾病和肺癌的死亡。WHO 2021年空气质量指南规定PM₂.₅年平均浓度为5 µg/m³，世界上大多数城市都超过这一水平。用固体燃料做饭造成的**室内空气污染**是低收入国家疾病的主要原因。

**一氧化碳**是不完全燃烧产生的无色无味气体，来源如有故障的燃气设备、汽车尾气和火灾。它与血红蛋白的亲和力约为氧的200至250倍，形成碳氧血红蛋白，降低氧的运输，并使氧解离曲线左移，使剩余的氧更难释放给组织。它还损害线粒体呼吸。需氧量高的脑和心脏受影响最大。脉搏血氧仪不能区分碳氧血红蛋白和氧合血红蛋白，因此饱和度读数可能看起来正常。

::: example 全家头痛 {#ex-co}
冬季，一名36岁女性和她的两个孩子都出现头痛、恶心和头晕，离开家后症状改善。该女性的脉搏血氧饱和度为98%，但用碳氧血红蛋白测定仪进行血气分析显示碳氧血红蛋白为18%。解释这些发现。
::: solution
1. 同一家庭中数人出现头痛和恶心，离家后改善，强烈提示**一氧化碳中毒**，很可能来自有故障的锅炉或取暖器。
2. 一氧化碳与血红蛋白的结合远比氧紧密，形成碳氧血红蛋白；她18%的血红蛋白不能携带氧。
3. 脉搏血氧仪把碳氧血红蛋白当作氧合血红蛋白读出，因此98%的饱和度是虚假的安慰。碳氧血红蛋白测定仪直接测定碳氧血红蛋白。
4. 治疗是高流量吸氧，它缩短碳氧血红蛋白的半衰期，家中每个人都需要评估。必须消除污染源，并按当地程序上报事件。可能出现迟发性神经系统损害（[[emergency-critical-care/poisoning]]）。
:::
:::

**铅**曾广泛存在于油漆、汽油和水管中。它抑制血红素合成的酶（δ-氨基乙酰丙酸脱水酶和亚铁螯合酶），引起伴红细胞嗜碱性点彩的小细胞性贫血，并损害发育中的脑，因此儿童最易受害。成人可出现周围神经病、腹痛和肾损害。

**职业性肺病**由吸入粉尘引起。**石棉**纤维，尤其是青石棉等闪石类，细长，能深入肺外周和胸膜，并抵抗清除。石棉引起胸膜斑（通常无害）、弥漫性胸膜增厚、**石棉肺**（间质纤维化）、**间皮瘤**和肺癌。石棉与吸烟共同作用引起的肺癌风险远大于两者单独作用。间皮瘤通常在暴露后20至50年出现，因此在英国禁止石棉（1999年全面禁止）多年之后仍有病例发生。**二氧化硅**引起矽肺并增加结核病风险；煤尘引起煤工尘肺（[[respiratory/interstitial-vascular-disease]]）。

## 物理性损伤

**热烧伤**按深度分类。**浅表**烧伤只累及表皮，发红、疼痛。**部分皮层**烧伤延伸到真皮，起水疱。**全层**烧伤破坏整个真皮，包括神经末梢，因此可以无痛，且仅靠边缘无法愈合，需要植皮。大面积烧伤引起经受损毛细血管的大量液体丢失、高代谢状态、感染，吸入烟雾后还有气道和肺损伤。烧伤范围以占体表总面积的百分比估算，“九分法”可快速近似估算成人的烧伤面积。

**低体温**指核心体温低于35 °C。随着体温下降，代谢减慢，意识水平降低，心脏易发生心律失常。局部冻伤（冻疮）由冰晶形成以及小血管的收缩和血栓形成引起。**热射病**指核心体温高于约40 °C并伴中枢神经系统功能障碍，引起广泛的细胞损伤、横纹肌溶解和DIC。

**电损伤**取决于电压、电流和路径。低压交流电可引起心室颤动。高压电流沿其穿过组织的路径产生热量，造成深部烧伤和肌肉坏死，范围可能远远超出小小的入口和出口伤所提示的程度。

## 电离辐射

电离辐射，如X射线、γ射线和粒子，携带足以从原子中击出电子的能量。它通过使DNA断裂直接损伤细胞，也通过电离水产生自由基间接损伤细胞。

::: definition 辐射剂量及其效应 {#def-radiation}
- **吸收剂量**是每千克组织沉积的能量，单位为**戈瑞**（Gy；1 Gy = 1 J/kg）。
- **有效剂量**是对全身总体风险的加权度量，考虑了辐射类型和受照器官的敏感性，单位为**希沃特**（Sv），通常用毫希沃特（mSv）。
- **确定性效应**（组织反应）发生在阈剂量以上，其严重程度随剂量增加：皮肤红斑、脱发、白内障、不育、骨髓衰竭和急性放射综合征。
- **随机性效应**没有已知的阈值：随剂量增加的是发生概率，而不是严重程度。它们是癌症和遗传效应。在辐射防护中，即使在低剂量下，也假定风险与剂量成正比地增加。
:::

不同细胞的放射敏感性不同。快速分裂的细胞最敏感：骨髓、肠上皮、皮肤和性腺。神经元等不分裂的细胞抵抗力较强。这一原理是放射治疗的基础，放疗利用了癌细胞修复DNA损伤能力较差这一点；它也解释了放疗的副作用，如黏膜炎和腹泻。

全身剂量超过约1 Gy引起**急性放射综合征**。其类型反映受损的组织：较低剂量时骨髓在数周内衰竭，出现感染和出血；较高剂量时肠上皮在数天内丧失，出现腹泻和液体丢失；剂量很高时神经系统和循环在数小时内衰竭。照射的晚期效应包括纤维化、小血管闭塞和第二原发癌。

英国人均每年接受的各种来源的辐射剂量约为2.7 mSv，其中约一半来自氡气。医学影像是最大的人工辐射源。剂量差异很大：一次胸片约0.02 mSv，而腹部CT为几毫希沃特，某些扫描方案约为10 mSv。

::: example 正确看待CT剂量 {#ex-radiation}
一名30岁女性询问她接受腹部和盆腔CT扫描会受到多少辐射，在她所在的医院这一检查约为10 mSv。将其与天然本底辐射以及约0.017 mSv的胸片相比较。
::: solution
1. 英国的本底辐射约为每年2.7 mSv。
2. $10/2.7 \approx 3.7$，所以这次CT大约相当于3.7年的本底辐射剂量。
3. 一次胸片相当于$0.017/2.7 \times 365 \approx 2.3$天的本底辐射，因此CT约为胸片的600倍。
4. 据估计，10 mSv引起未来癌症的风险很小，对成人而言约为两千分之一的量级，并假定与剂量成正比增加。如果扫描能回答一个重要的临床问题，它就是合理的；英国（根据IR(ME)R法规）的原则是每次照射都必须正当化，并保持在合理可行的最低水平。儿童对辐射更敏感，余生更长，因此同样的剂量对他们风险更大（[[clinical-skills/medical-imaging]]）。
:::
:::

## 营养不良与维生素缺乏

**营养不良**（malnutrition）既包括营养不足，也包括营养过剩。营养不足仍是低收入国家幼儿死亡的主要原因，常与感染并存；在高收入国家的医院中也很常见，见于老年人、慢性病患者和进食障碍患者。

儿童**重度急性营养不良**有两种经典类型。**消瘦型**（marasmus）源于严重的能量缺乏：患儿极度消瘦，肌肉和脂肪消耗，但无水肿，机体分解自身组织以求生存。**水肿型**（kwashiorkor，恶性营养不良）的特征是**水肿**、脂肪浸润的增大肝脏、伴片状脱屑的皮肤病变以及毛发改变。过去它被简单地解释为能量充足而蛋白质缺乏，但现在认为其机制除饮食外还涉及感染、氧化应激和肠道微生物的改变。两种类型的免疫功能都受损，感染很常见。

**再喂养综合征**发生于严重营养不良者开始进食或接受人工喂养时。碳水化合物引起胰岛素释放，驱使磷、钾和镁进入细胞，对硫胺素的需求也突然增加。严重低磷血症可引起心力衰竭、呼吸衰竭、意识混乱和死亡。高风险者用NICE营养支持指南中的标准等来识别，喂养要谨慎开始，并进行监测和补充（[[gastrointestinal/clinical-nutrition]]）。

| 维生素 | 主要作用 | 缺乏的影响 |
|---|---|---|
| A | 视觉（视紫红质），维持上皮 | 夜盲、干眼症和角膜损害、鳞状上皮化生、感染增加 |
| D | 钙和磷的吸收，骨矿化 | 儿童佝偻病，成人骨软化症 |
| 硫胺素（B1） | 碳水化合物代谢的辅酶 | 脚气病（神经病变、心力衰竭）；Wernicke脑病和Korsakoff综合征 |
| 叶酸和B12 | DNA合成；B12还维持髓鞘 | 巨幼细胞贫血；B12缺乏还引起脊髓亚急性联合变性 |
| C | 胶原中脯氨酸和赖氨酸的羟化；抗氧化 | 坏血病：牙龈出血、毛囊周围出血、伤口愈合不良 |
| 烟酸 | 合成NAD和NADP | 糙皮病：皮炎、腹泻、痴呆 |

::: warning 对高危者先给硫胺素再给葡萄糖
对于有硫胺素缺乏风险的人，如大量饮酒者或严重营养不良者，给予葡萄糖会增加硫胺素需求，可诱发或加重**Wernicke脑病**。经典三联征（意识混乱、眼球运动异常和共济失调）只见于少数患者，因此诊断很容易漏掉。原则是按当地指南及时给所有高危者补充硫胺素，而不是等待三联征齐全。未经治疗的Wernicke脑病可进展为永久性记忆丧失（Korsakoff综合征）或死亡。
:::

## 肥胖

::: definition 体重指数与肥胖 {#def-bmi}
**体重指数**（BMI）是以千克为单位的体重除以以米为单位的身高的平方：

$$
\text{BMI} = \frac{\text{体重（kg）}}{\text{身高（m）}^2}
$$ {#eq-bmi}

对于成人，WHO和NICE的分类为：健康体重18.5至24.9 kg/m²，超重25至29.9 kg/m²，肥胖30 kg/m²或以上。NICE对南亚、华人、其他亚洲、中东、非洲黑人或非洲-加勒比背景的人推荐较低的阈值，因为他们在较低的BMI就会发生心血管代谢疾病：23 kg/m²起为超重，27.5 kg/m²起为肥胖。腰围身高比为0.5或以上提示中心性脂肪增多。
:::

BMI是一个简单的人群指标。它不能区分脂肪和肌肉，因此会把一些肌肉发达的人误分类，也不能显示脂肪储存在哪里。腹腔内的脂肪（内脏脂肪）比皮下脂肪带来更大的代谢风险，这就是要加测腰围的原因。

::: widget plot
f: x/h^2
x: 40, 150
y: 10, 55
sliders: h=1.7:1.5:2:0.01
hlines: 18.5; 25; 30
labels: \text{BMI（kg/m}^2\text{）}
caption: 身高为$h$米的人的体重指数随体重（千克）的变化。水平线标出18.5、25和30 kg/m²，即一般成人的阈值；对于NICE所列的族群，适用23和27.5 kg/m²的较低阈值。移动身高滑块，可以看到每个阈值对应的体重如何随身高的平方而变化。
:::

脂肪组织是一个活跃的内分泌器官。肥胖时，增大的脂肪细胞处于应激和缺氧状态，巨噬细胞在其周围聚集。它们释放脂肪酸和TNF、IL-6等炎症细胞因子，而改善胰岛素敏感性的激素**脂联素**减少。正常情况下传递饱腹信号的**瘦素**水平升高，但脑对其产生抵抗。结果是**胰岛素抵抗**和低度慢性炎症。

肥胖增加以下疾病的风险：2型糖尿病、高血压、血脂异常、冠心病和卒中；代谢功能障碍相关脂肪性肝病；阻塞性睡眠呼吸暂停；负重关节的骨关节炎；胆石症；多囊卵巢综合征和生育力下降；以及几种癌，包括子宫内膜癌、食管（腺）癌、结肠癌、肾癌和绝经后乳腺癌。脂肪组织产生的过多雌激素解释了子宫内膜癌和乳腺癌风险的一部分。

::: example 采用较低阈值的BMI {#ex-bmi}
一名52岁孟加拉裔男性体重70 kg，身高1.68 m。他的空腹血糖处于临界水平。计算他的BMI并加以解读。
::: solution
1. BMI $= 70/1.68^2 = 70/2.822 \approx 24.8$ kg/m²。
2. 按一般阈值，他被归为健康体重，刚好低于25。
3. 作为南亚背景的人，适用NICE的较低阈值：24.8 kg/m²高于23，因此他被归为**超重**。
4. 南亚裔人群在相同BMI下倾向于在腹部和肝脏储存更多脂肪，并在较低的BMI发生2型糖尿病。他临界的血糖与此相符。测量腰围身高比可以提供更多信息，应为他提供糖尿病和心血管风险评估（[[endocrine/diabetes]]）。
:::
:::

::: quiz
一名大量饮酒的45岁男性被发现平均红细胞体积升高，超声示脂肪肝，并出现意识混乱、步态不稳和眼球运动异常。哪种维生素缺乏最能解释其神经系统表现？
- [ ] 维生素A
- [x] 硫胺素（维生素B1）
- [ ] 维生素C
- [ ] 维生素D
::: solution
大量饮酒者出现意识混乱、共济失调和眼肌麻痹，构成由硫胺素缺乏引起的Wernicke脑病三联征。酒精减少硫胺素的摄入、吸收和储存。平均红细胞体积升高反映酒精对骨髓的直接作用或伴随的叶酸缺乏。
:::
:::

::: history
1700年，意大利医生拉马齐尼（Bernardino Ramazzini）出版了《论手工业者的疾病》（*De Morbis Artificum Diatriba*），系统论述了工人的疾病，奠定了职业医学的基础。1747年，海军外科医生林德（James Lind）比较了治疗水手坏血病的六种方法，发现柑橘类水果能治愈坏血病，这是最早的对照临床试验之一。19世纪90年代，艾克曼（Christiaan Eijkman）证明鸡的脚气病是由精米饮食引起的，这项工作导致了维生素的发现，他于1929年分享了诺贝尔奖。1950年，多尔（Richard Doll）和希尔（Austin Bradford Hill）发表了一项把吸烟与肺癌联系起来的病例对照研究，随后进行了英国医生队列研究，确立了吸烟是一个主要死因。1927年，穆勒（Hermann Muller）证明X射线能引起果蝇突变，确立了辐射是一种诱变剂。
:::

## 后续内容

烟草和酒精将在肺、肝、心脏和癌的各章中再次出现；职业和环境卫生政策见[[public-health/environmental-occupational]]；临床实践中的营养见[[gastrointestinal/clinical-nutrition]]；中毒见[[emergency-critical-care/poisoning]]。病理医师如何在组织中识别这些损伤，以及尸检在确定环境性死因中的作用，见[[pathology/diagnostic-pathology]]。

::: summary
- 环境因素的作用取决于剂量、代谢（生物活化或解毒）和个体易感性。活性代谢物和氧化应激是常见机制。
- 烟草烟雾含有尼古丁、致癌物、氧化剂和一氧化碳；它引起癌、COPD、心血管疾病和妊娠危害。暴露量以包年计量。
- 一个英国单位是10 mL（8 g）乙醇；低风险指南为每周不超过14个单位。酒精被代谢为乙醛，产生NADH和氧化应激，引起脂肪变、酒精性肝炎和肝硬化以及许多其他疾病。
- 对乙酰氨基酚毒性源于谷胱甘肽耗竭时的活性代谢物NAPQI，引起3区肝坏死；乙酰半胱氨酸补充谷胱甘肽。
- 细颗粒物、一氧化碳、铅和石棉是重要的污染物。脉搏血氧测定会漏诊一氧化碳中毒。
- 烧伤、低体温、热射病和电损伤通过热、冷和电流引起细胞损伤。
- 电离辐射以戈瑞（吸收剂量）和希沃特（有效剂量）计量。确定性效应有阈值；随机性效应（癌症）没有。分裂中的细胞放射敏感性最高。
- 营养不足包括消瘦型和水肿型；再喂养综合征由磷、钾和镁的转移引起。维生素缺乏有特征性的病理表现；对Wernicke脑病高危者应补充硫胺素。
- 肥胖（BMI 30 kg/m²或以上；按NICE指南某些族群为27.5 kg/m²或以上）引起胰岛素抵抗和慢性炎症，增加糖尿病、心血管疾病、肝病和几种癌的风险。
:::

::: exercise 为什么是3区？ {level=2}
解释为什么对乙酰氨基酚过量首先损伤中央静脉周围的肝细胞，以及为什么长期大量饮酒且饮食不良的人可能更易受害。
::: solution
3区肝细胞位于中央静脉周围，含有浓度最高的、把对乙酰氨基酚转化为NAPQI的细胞色素P450酶，并接受含氧最少的血液。当谷胱甘肽耗尽时，NAPQI首先在那里与蛋白质结合。长期大量饮酒诱导CYP2E1，因此形成更多的NAPQI；饮食不良减少谷胱甘肽储备，因此可用于解毒的谷胱甘肽更少。两者都使平衡向毒性一方倾斜。
:::

::: exercise 一位老船厂工人 {level=3}
一名74岁男性在20世纪60和70年代曾在船厂工作，吸烟30年，于1990年戒烟。他现在气促，有单侧胸腔积液。CT显示结节状胸膜增厚包绕肺，以及双侧钙化胸膜斑。讨论可能的诊断、石棉和吸烟的作用以及潜伏期的意义。
::: hint
把石棉引起的胸膜疾病与吸烟也起作用的疾病区分开。
:::
::: solution
造船业涉及大量石棉暴露。钙化胸膜斑是既往暴露的标志，通常无害。伴胸腔积液的结节状包绕性胸膜增厚强烈提示**恶性间皮瘤**，需要组织诊断（胸膜活检加免疫组织化学）。石棉纤维，尤其是闪石类，到达胸膜并持续存在，引起慢性炎症、氧化性DNA损伤和间皮细胞突变。间皮瘤不是由吸烟引起的。然而，吸烟使石棉暴露者的**肺癌**风险成倍增加，因此肺癌是另一个重要诊断。20至50年的潜伏期解释了为什么在暴露结束和英国禁令实施数十年后仍在诊断出间皮瘤。职业暴露引起的间皮瘤有法律意义：患者可能有权获得赔偿，在英格兰和威尔士，因其死亡的病例必须报告给验尸官。
:::
:::

::: exercise 重新开始进食 {level=3}
一名24岁神经性厌食症女性BMI为13 kg/m²，入院治疗。喂养第三天，她出现气促和意识混乱，血清磷为0.3 mmol/L（参考值约0.8至1.5）。解释其机制，以及本应指导她喂养的原则。
::: solution
这是**再喂养综合征**。在饥饿期间，体内总磷、钾和镁已经耗竭，尽管血清水平可能正常。开始喂养后，碳水化合物刺激胰岛素分泌，后者驱使葡萄糖、磷、钾和镁进入细胞，用于糖酵解和蛋白质合成，于是血清水平急剧下降。ATP和2,3-二磷酸甘油酸都需要磷；严重低磷血症损害心肌和呼吸肌的收缩，引起意识混乱、抽搐和溶血。对硫胺素的需求也增加。原则是识别高风险者（BMI极低、数日几乎未进食、喂养前电解质偏低），谨慎开始喂养并逐渐增加，在喂养前和喂养期间补充硫胺素和其他维生素，监测并补充磷、钾和镁，遵循国家指南并有专科参与（[[psychiatry/eating-personality-disorders]]）。
:::
:::
