环境与职业病理研究的是外部世界如何把损伤写进组织：粉尘被吸入后肺部如何反应，能量形式如何按剂量与时序造成伤害，以及金属、溶剂、化学品与污染空气如何在数十年间累积出可归因的疾病。**本章覆盖职业性肺病（暴露的性质、剂量与个体的反应决定纤维化、胸膜斑、肉芽肿或肿瘤）、物理的损伤（电离辐射与温度与电与气压）、中毒学（铅、汞、砷、溶剂、农药与工业化学品，各自的靶器官、生物监测与螯合）、以及空气、水与土壤的人群污染——再加上本领域最难的一课：证据、法律与预防的时限之间从不一致。**

## 会致瘢痕的粉尘

::: definition 尘肺与反应的肺 {#def-dust}
**吸入的颗粒被肺以四种方式回应，取决于颗粒的大小、形状、可溶性与致病力：可溶的颗粒被清除而不留痕；不溶的细小颗粒到达肺泡并被巨噬细胞吞噬，若该颗粒能活化炎症通路，就进入一个“巨噬细胞死亡与酶释放与纤维化”的循环（矽肺与石棉肺的机制），并可累及淋巴结；惰性的颗粒留在肺内形成粉尘灶（煤工尘肺的煤斑）；而耐久纤维则造成胸膜的反应与极少见的恶性间皮瘤。** 决定结局的是剂量与纤维的类型：石棉是一类矿物纤维的商品名，角闪石类的直而脆的纤维比蛇纹石类的卷曲纤维更难被清除且致癌性更强；直径与长度决定“可吸入性”，而吸烟不引起石棉肺却与肺癌相乘（这是职业医学最常被引用的相乘例子，也是为何戒烟咨询在职业人群中是救命而非礼节）。疾病的清单各有其形态与流行病学：矽肺（上叶的结节性纤维化与蛋壳样钙化的淋巴结与并发的结核易感与随后描述的自身免疫关联）、煤工尘肺（煤斑与大块纤维化）、石棉肺（下叶为主的间质纤维化加胸膜斑）、铍（非干酪性的肉芽肿并可与结节病混淆、且有遗传的易感标志）、由机器加工粮食与木料与金属磨削与硬质合金与焊接烟尘造成的各类肺部疾病（其中的金属烟热与有机粉尘的中毒综合征是“今天暴露、今天发热”的少见例外）；以及一个反复出现的教训：新的暴露会不断出现（陶瓷纤维与碳纳米管与3D打印的超细颗粒），而监管永远滞后于病例，“石棉的教训”因此是关于时间而不是关于某一种矿物——[[respiratory/interstitial-vascular-disease]]、[[public-health/environmental-occupational]]、[[pathology/chronic-inflammation-repair]]。**
:::

## 能量与分子

::: definition 辐射、温度与电 {#def-energy}
**电离辐射的损伤按“直接打击脱氧核糖核酸与间接的自由基与氧的增强”两条路发生，其后果取决于剂量与剂量率与分次与组织的更新率与个体的年龄：确定性效应有阈值且严重度随剂量上升（红斑与脱毛与白内障与不育与骨髓与胃肠与中枢的急性综合征），随机性效应无阈值而概率随剂量上升（白血病与甲状腺与乳腺与肺的实体瘤，其潜伏期为数年至数十年）。分次的四个“R”（修复与再增殖与再分布与再氧合）解释了为何放疗的分次方案与急性暴露的间歇都重要；而淋巴细胞的动力学与呕吐出现的时间，可在事故后作为剂量的生物估算（染色体的畸变与双着丝粒的计数是剂量计）——[[blood/haematopoiesis]]、[[clinical-skills/medical-imaging]]。中暑是外周血管扩张与出汗不足共同失败的结果：核心的温度超过约40至42度时直接造成细胞的损伤（横纹肌溶解与急性肾损伤与肝的缺血与弥散性血管内凝血与脑），而“劳力性”与“非劳力性”两型在人群与机制上都不同（后者的多数是可预防的居家热伤害：热浪期间独居的老人与没有空调的顶层公寓与利尿剂与抗胆碱药与β阻滞剂与精神疾病的药物清单——[[geriatrics-palliative/ageing-frailty]]）。冻伤是冰晶与血管收缩与血栓的联合，其处理是快速复温而不摩擦并保留完整的水疱与判断是否可用前列环素类似物；电击最危险的是交流电穿过躯干时的心室纤颤与延迟的深部坏死（入口与出口的伤口远小于肌肉的损害，所以筋膜切开与肌红蛋白与肾的保护是重点，而“看着没事”不能排除内部）。气压的变化则制造另一类气体依赖的疾病：减压病与动脉的气体栓塞与中耳与鼻窦的损伤与肺的气压伤，以及高压氧治疗的适应证与有限的地位——[[emergency-critical-care/critical-care]]、[[cardiovascular/arrhythmias]]。**
:::
::: definition 金属、化学品与污染 {#def-toxins}
**金属的共同特性是累积、亲某些组织、且生物监测比血浓度更可靠：铅（儿童的神经发育与成人的高血压与肾病与周围神经与牙龈的线与点彩的红细胞与卟啉的通路，其剂量—反应在低处没有阈值，所以“允许的水平”是被不断下调的公共卫生史；以及骨铅作为长期储库使血铅在暴露停止后仍能持续数月）、汞（元素汞的蒸气造成中枢与意向性震颤与牙龈口腔的症状、甲基汞经胎盘的选择性损伤与对鱼的生物富集、无机汞的肾）、砷（皮肤的色素改变与过度的角化与掌跖的线状皮纹与肺与膀胱与皮肤以及肝血管内皮瘤，其污染同时是职业与地方性的饮用水问题）、镉（肾小管的病与骨痛病以及吸烟者的肺气肿）、以及铬的六价与镍与铍与铊（脱发与周围神经）与锰（锥体外系，且其帕金森综合征对左旋多巴反应差）。溶剂与化学品各有其靶：四氯化碳与对乙酰氨基酚的肝与氯仿，三氯乙烯与致敏与皮炎与可能的淋巴瘤，正己烷与二硫化碳与周围神经与锥体系，苯与骨髓（白血病与再生障碍）与甲苯的滥用（白质的病与心脏的猝死），有机磷与氨基甲酸酯的胆碱能危象与百草枯（剂量依赖的、不可逆的肺纤维化）、以及一氧化碳与氰化物与硫化氢这三个“细胞与血红蛋白缺氧”的杀手（每个都有特征的暴露现场与各自的解毒策略）。人群的空气污染把职业暴露的算术搬到城市的尺度：细颗粒物与二氧化氮与臭氧与多环芳烃，其对心肺的死亡率与儿童的肺生长与低出生体重与痴呆的关联（对数线性且无已证明的安全水平），以及室内空气（固体的燃料与氡与霉菌）；治疗这些暴露的少数具体手段是螯合（铅的钙二钠依地酸与琥珀酸二巯基丙磺、汞与砷的巯基供体）与“移除与源头治理”——后者几乎总是比任何药物都重要，因为持续暴露下的治疗注定失败——[[renal/tubular-function]]、[[nervous-system/sensory-systems]]、[[gastrointestinal/liver-disease]]、[[public-health/environmental-occupational]]。**
:::

::: example 气短的建筑工人 {#ex-asbestosis}
一名67岁的退役拆船工渐进气短与干咳三年；双下肺爆裂音；胸片示胸膜斑与下叶的网状影；肺功能为限制性伴弥散量下降；他不吸烟已二十年。
::: solution
**把影像读成暴露档案（[[#def-dust]]、[[#def-toxins]]、[[respiratory/interstitial-vascular-disease]]）：石棉肺的诊断是三件事的合取：明确的暴露（职业与年限与纤维类型与当时有无防护）、潜伏期足够长（纤维化的出现通常在首次暴露二十年以上，故“退休”绝不是风险的结束）、以及排除其他原因（吸烟与治疗与结缔组织病与家用暴露与既往的放疗）；形态与分布有提示价值（下叶为主并伴胸膜斑者倾向石棉肺，而特发的肺纤维化多在无胸膜斑的上叶与胸膜下分布并有其影像与病理的模式）。检查：高分辨的计算机断层（纤维化的分布与胸膜的改变与有无肿块或积液）、肺功能的系列（与肺癌与间质病的一般评估）、以及在怀疑恶性时的组织（胸腔镜的活检与免疫组化；细胞学对间皮瘤的诊断价值有限）——[[pathology/diagnostic-pathology]]、[[clinical-skills/medical-imaging]]。治疗与预后：无逆转的办法，所以三件事最重要：戒断进一步的暴露（并评估家中的“携带纤维的衣物”这一被低估的途径与同住的家人）、肺康复与疫苗与氧与呼吸困难的症状控制、以及在合适时点的抗纤维化药物（在进展的纤维化表型中被使用的尼达尼布与吡非尼酮，其证据来自特发的肺纤维化与其他纤维化的扩展，需要肝与胃肠的监测）——[[geriatrics-palliative/symptom-control]]、[[respiratory/mechanics-breathing]]。法理与告知：这是职业病报告与赔偿的典型（暴露史要具体到材料、年限、每周小时、防护、以及工友是否同样发病），而“暴露—影像—疾病”的区别要向他讲清（有胸膜斑不等于有石棉肺，也不必然是赔偿意义上的病，但意味着需持续观察）；并给出需立即返诊的红旗（新发胸痛、积液的增长、咯血、体重下降——肺癌与间皮瘤的监测不是规划化的筛查，而是有症状时的快速响应与对可疑征象的低阈值）——[[public-health/environmental-occupational]]、[[clinical-skills/communication]]。**

::: example 工厂的聚集 {#ex-cluster}
一家家具厂的八名木工在五周内出现咳嗽、发热、寒战与乏力，多在周一或连续工作数日后加重；胸片与肺功能大致正常；两名被诊断为“反复的病毒”；车间的旧除尘系统坏了两个月。
::: solution
**聚集即流行病学（[[#def-dust]]、[[#def-energy]]、[[public-health/environmental-occupational]]）：这个模式（多人、同一暴露、按工作日波动、离开周末好转、影像可正常）首先提示有机的粉尘引起的呼吸道反应：农民肺型的外源性过敏性肺泡炎（热的暴露与抗体的介导与淋巴细胞性的肺泡炎）或金属烟热（新金属烟尘的吸入，当日发热并在数小时内自解）或聚合物烟雾热，以及刺激性粉尘引起的气道反应——鉴别的关键不是化验而是“时间与地点的结构”：症状与上班日与车间与除尘的失效是否吻合、下班与假期是否缓解、以及不在车间的人是否有症状（把“我们车间的人都这样”当作诊断性证据）——[[respiratory/interstitial-vascular-disease]]。要做的检查：外周血的白细胞与炎症标志（在金属烟热可升高而在肺泡炎常有淋巴细胞减少）、肺功能与弥散量的系列、以及在诊断不明或严重时计算机断层与支气管肺泡灌洗（淋巴细胞性肺泡炎与中性粒的肺泡炎与嗜酸细胞性肺病的区别，以及“沉淀的抗体”只在配合暴露解释时才有意义——它证明接触而非疾病）——[[clinical-skills/laboratory-tests]]。处置的顺序：立刻的工程控制（修除尘与通风并降低暴露的浓度，这是控制层级的顶端），移除继续暴露者（带薪的，否则没人会主动离开岗位），个体防护只是最后的手段而不是策略；并对重症的肺泡炎短期使用糖皮质激素；同时启动报告的义务（职业卫生与检查机构与法定的职业病报告），因为这是“群体识别”的责任而不是可选的利他——[[medical-ethics-law/professionalism-regulation]]。要避免的两个错误：把这八个人当作八次独立的感染分别治疗（这是本领域最常见的照护失败，代价是持续暴露与不可逆的纤维化），以及在证据尚不足时否认（可以先控制、后证明——比例性原则在这里意味着宁可先保护）；随访要包括肺功能的复查与“再次进入车间是否复发”的受控评估（只在有医学监督与客观测量的条件下进行），并把这次事件写进厂方的整改与再发的预防——[[public-health/health-systems-economics]]。**

::: example 热浪期间的病房巡查 {#ex-heatwave}
热浪第五天，夜间最低温29度：一名84岁独居女性在晕倒后被送来，核心温度41.2度、意识模糊、血压低、肌酸激酶高、肌酐从70升到210；她的药单上有氢氯噻嗪、阿米替林、奥氮平与氯苯那敏；她住在顶楼且没有空调。
::: solution
**经典型中暑在真实的一周内（[[#def-energy]]、[[#def-toxins]]、[[geriatrics-palliative/ageing-frailty]]）：这是非劳力性（经典型）中暑：散热机制在“环境热＋药物＋行为受限”的三重作用下失效——出汗需要容量（噻嗪使她在热到来之前已处于低容量）、皮肤血管扩张需要自主神经的反应（抗胆碱药与阿米替林与奥氮平的抗毒蕈碱作用阻止出汗并干扰下丘脑的调节，而抗精神病药还损害体温调节的中枢与行为的主动性），而“能呼救”本身也是一种生理能力（独居、行动受限、怕开窗的安全顾虑、以及不认为自己需要求助）。处置的关键在最初的三十分钟：降温优先于一切检查（冷水浸泡是金标准，若无则蒸发降温加风扇并持续的核心温度监测，以40度为停止点；不要用非甾体抗炎药（无效且加重肾与凝血）；镇静或寒战会产热，可用苯二氮控制），同时按需要补液并按弥散性血管内凝血与横纹肌溶解与肝与肾的轨迹逐小时复查——[[emergency-critical-care/shock-fluids]]、[[renal/acute-kidney-injury]]、[[nervous-system/stroke]]。并发症的时间表要写在病程里：早期的脑（谵妄与少见的梗死）、肾与肝与凝血、以及数日后的迟发肝衰竭；而肌红蛋白的峰值常滞后于肌酸激酶，所以“第一天的肌酐”不代表结局——[[gastrointestinal/liver-disease]]、[[blood/haemostasis-bleeding]]。预防的清单要具体且属于同一次出院：调整的药（在热季减少或停用抗胆碱与噻嗪并写下“温度超过某值时的规则”，即把病假日规则扩展成热假日规则）、被装到家的降温与饮水与检查的探访（以及邻里与社区组织与药房与邮差的联络网）、把名单从“高危人群”变成“谁在何时敲门”的行动（发预警容易、按预警行动难——这是热浪评估反复的结论）、以及建筑层面的政策（遮阳与绿化与“可降温的公共房间”与对租户的降温义务）——[[public-health/environmental-occupational]]、[[public-health/health-systems-economics]]。**

::: example 发育迟缓的孩子与那栋老房子 {#ex-child-lead}
一名两岁半的男孩说话少、注意力差、反复腹痛与便秘、血红蛋白98伴点彩红细胞；他的母亲在翻新一九四零年代的房屋；血铅被报为28微克每分升。
::: solution
**没有安全水平（[[#def-toxins]]、[[#def-dust]]、[[paediatrics/growth-development]]）：先解释这个数（28微克每分升在儿童已属明显升高：与认知与注意与行为的关联在此水平以下即可测出，且无阈值，故“等等看”不是中性的选择；贫血的点彩与嗜碱性点彩 与卟啉的通路支持显著暴露，但缺铁本身会升高血铅的吸收，所以两者都要查）——[[blood/anaemia]]。即刻的三件事：一，找到并切断来源（翻新的含铅油漆的粉尘是最可能的解释，其次是水与含铅的香料与化妆品与玩具与家长的职业衣物与土壤与装修的废渣；“停止干磨与干刮”并做专业的清除，并检查兄弟与同住的孩子与孕妇）；二，重复的检测与评估（静脉的确认而非指尖、全血计数与铁与血清铁与铁蛋白与饮食与营养的评估、以及发育的筛查与早期的干预转介——语言的干预在此刻就能开始，不必等神经心理的报告）；三，医学的驱铅（螯合在儿童用于更高的水平或有症状者，此例以移除与营养与随访为主，若超过某阈值或用二巯基丁二酸；绝不用依地酸钙钠在未评估锌与铜与肾功能的情况下、且“没换环境就用药”是无效且有害的）——[[renal/tubular-function]]、[[emergency-critical-care/poisoning]]。要同时处理的：腹疼与便秘与异食癖（补铁与纠正锌与饮食的结构常能减轻症状，并把异食本身作为需要行为干预的暴露源）；以及家与制度的一层（把房屋登记入油漆的安全改造的名单，向公共卫生与环境部门报告——这是可被追踪与干预的环境暴露；对房东与施工方的义务的说明；以及向家长清楚说明“这不是你的错，但只有你能切断它”）；随访发育与血铅下降的曲线，并预期血铅下降是缓慢的（骨铅的储库会持续释放数月）——[[public-health/environmental-occupational]]、[[clinical-skills/communication]]。**

## 通向何处

肺对粉尘与烟雾的反应见[[respiratory/interstitial-vascular-disease]]与[[respiratory/asthma-copd]]；毒物的代谢与排泄见[[pharmacology/metabolism-excretion]]与[[renal/tubular-function]]；急性的中毒处置见[[emergency-critical-care/poisoning]]；热的循环与肾脏后果见[[renal/water-sodium]]与[[cardiovascular/circulation-blood-pressure]]；人群层面的措施见[[public-health/environmental-occupational]]与[[public-health/prevention-promotion]]。

::: history
**职业与环境病理的历史是一部“先有病例、后有法律”的史。十八世纪的工厂与矿山给出了最初的病理学：拉马齐尼《论手工业者的疾病》（1700年）把职业按病种整理；波特的烟囱清扫工的阴囊癌（1775年）第一次把一种癌归给一种暴露，并最终指向焦油与多环芳烃，也催生了“洗不掉的东西能致癌”的公共卫生观念；十九世纪的磷颌坏死（火柴女工的下颌坏死）与后来的磷与镭的替代品选择确立了“替代品往往同样危险”的警诫；砷与帽匠的疯与汞的震颤与硝酸工的牙与肺是同一时代的图谱。二十世纪的三场大课塑造了本领域：石棉（从1920年代的尸检描述与1930至1950年代的流行病学与1955至1960年代的吸烟交互与间皮瘤的确认，到禁令与赔偿与数十年的诉讼，其教训被后来的苯与氯乙烯的肝血管内皮瘤与二氧化硅与矽肺的工会斗争反复引用）；辐射（X射线的早期操作者的白内障与再生障碍与白血病、镭表盘女工的颌骨坏死、广岛与长崎的生命效应研究与其线性无阈的外推之争、以及切尔诺贝利与福岛之后的甲状腺与心理与迁移的健康后果）；铅（从1920年代的汽油与涂料到1960至1970年代对儿童神经毒性的重新发现，再到1970年代起各国逐步禁铅、以及血铅参考值的连续下调；这是本领域唯一一次“没有阈值的证据”最终压倒了产业的拖延）；最近的一章是细颗粒物与室内空气（1930年的伦敦烟雾事件与1948年的多诺拉与美国清洁空气法与队列研究的兴起，以及固体燃料的炉灶革命）；方法论上，从“病例的聚集”到队列与生物监测与暴露组学（生物标志与暴露的重建），本领域始终在潜伏期与因果推断与法律时限的张力中工作——[[public-health/environmental-occupational]]、[[epidemiology-ebm/observational-studies]]。**
:::

::: summary
- 肺对吸入物的反应取决于颗粒的大小、形状、溶解度与致病力，而非暴露的名字；同一剂量的不同纤维造成不同的病。
- 职业病的特征是潜伏期：疾病在暴露后数十年出现，所以病史要覆盖整个工作生涯与家庭暴露，退休不是风险的结束。
- 辐射的效应分确定性（有阈值、严重度随剂量）与随机性（无阈值、概率随剂量）；四个“R”与分次的逻辑同样适用于事故。
- 金属与溶剂各有可预测的靶器官，且“切断来源”几乎总排在螯合之前；儿童的发育毒物没有安全水平。
- 中暑与冻伤与电击与气压伤都是“物理剂量的病理”，其结局取决于最初的三十分钟与药物与年龄与独居这些放大器。
- 聚集的病例是流行病学的信号：多名同事的同一症状比任何单项检查更早给出诊断，也是法定报告与工程控制的触发器。
:::

::: exercise 由综合征反推暴露 {level=1}
为下列五个“综合征—最可能的暴露”配对给出理由：周围神经病伴贫血与腹痛；意向性震颤与牙龈炎与肾功能异常；帕金森综合征伴反应差；非干酪性肉芽肿的肺病；膀胱的肿瘤与芳香胺的气味。
::: solution
**五个反推（[[#def-toxins]]、[[#def-dust]]、[[nervous-system/sensory-systems]]）：一，铅：运动为主的周围神经病（垂腕）加腹痛与便秘加小细胞或正细胞的贫血伴点彩与嗜碱性点彩，再加牙龈的铅线与卟啉通路的生化；确认用静脉的血铅，并同时找来源（装修与电池回收与进口香料与水）。二，汞（元素的蒸气）：意向性震颤与易兴奋与口腔牙龈炎与肾小管的病，职业史在牙科与氯碱与金矿与仪表；甲基汞则以上行性的感觉障碍与视野与听力为主并有胎盘的富集；砷的鉴别靠尿的形态分型（同时有皮肤的改变与测量末梢毛发的砷）。三，锰：锥体外的帕金森综合征（姿势不稳与步态与肌张力增高）且左旋多巴反应差，见于焊接与采矿与吸入滥用；其磁共振在苍白球有高信号——与特发的帕金森病的鉴别在病史而非影像。四，铍：与结节病几乎不可区分的非干肉芽肿（需要暴露史与铍的淋巴细胞增殖试验），以及结核与感染与肿瘤的排除。五，芳香胺：膀胱的尿路上皮癌（染料与橡胶与铝的冶炼与理发与印刷与头发染料的长期暴露），其职业归因的成立依赖“多人同病＋潜伏期＋岗位对应”，处理时同时考虑尿液细胞学与膀胱镜的路径与同岗位人群的筛查——[[pathology/cancer-biology]]、[[pathology/cancer-diagnosis]]。**
:::

::: exercise 向一名怀孕的女工给出建议 {level=2}
一名妊娠九周的实验室技术员每天接触甲醛与有机溶剂并偶尔操作低水平的放射性核素；她担心“要不要马上辞职”。
::: solution
**建议的结构（[[#def-toxins]]、[[#def-energy]]、[[obstetrics-gynaecology/pregnancy-complications]]）：先给框架而不是答案：多数职业暴露的水平低于造成胎儿损害的水平；风险取决于具体的浓度、时长、途径与是否可避免，因此“立即辞职”通常是过度的、且会带来收入与保险的伤害。做法是分层：一，量化（索取安全数据表与岗位的暴露监测记录并问雇主与职业卫生服务有无既往的超限，并识别高峰的短时暴露：开箱的甲醛与通风橱的使用与离心与倾倒与污染的台面与手套）。二，控制层级（把她的操作移出、由他人代做、或减少频率；改善通风与局部排风；使用密闭的容器与更安全的替代试剂（例如把某些固定与染色流程改为低毒的替代）与更严格的个人防护；把她的工作站与通道远离排放与共享的通风口）。三，辐射遵循既定的孕期剂量限值与胚胎的监测与胎儿剂量的评估；把核素的操作暂停或调整，并说明“诊断剂量的影像不构成终止妊娠的理由”，而高剂量的治疗性照射则是另一回事——[[clinical-skills/medical-imaging]]、[[pathology/diagnostic-pathology]]。四，其他可被忽略的风险长时间站立与轮班与夜班与昼夜节律被打乱与工作相关的心理社会风险（这些与低出生体重与早产的关联可能比化学物更大）与 lifting 的姿势与锐器与感染的暴露（血液与细胞培养与病原体的分类与操作的规则）。五，法律与程序（把风险评估写入文件并让雇主履行义务、给出书面调整的选项、以及“不因怀孕而受罚”的保障）；随访时记录症状与暴露的日志（“我改了什么、之后如何”），因为这份记录在赔偿与将来类似案例中都重要——[[public-health/environmental-occupational]]、[[medical-ethics-law/justice-resources]]。**

::: exercise 设计清洁空气的干预 {level=3}
你所在城市的细颗粒物年均值为22微克每立方米（世界卫生组织的年指导值为5）；交通与冬季的家庭固体燃料取暖与一个燃煤的调峰电厂并存。请设计一个五年的干预与评估方案。
::: solution
**干预的设计（[[#def-energy]]、[[#def-toxins]]、[[public-health/environmental-occupational]]）：先做来源解析，因为措施的排序必须由组分与来源决定（交通与居民燃煤与工业与扬尘与区域输送的相对份额，以及黑碳与超细颗粒与臭氧的前体在何处富集）：不看来源的“低排放区”可能把黑碳问题换成一氧化碳问题。五年的组合按成本—收益与可执行性排：一，居民燃料的替代（对最贫困家庭全额补贴的清洁取暖与房屋的保温与锅炉的淘汰与禁止散煤的销售；这是短期内对冬季峰值最有效的一项，并同时降低燃料贫困与室内的暴露与火灾与一氧化碳的风险）；二，交通（公交与自行车与步行的基础设施、货运的绕行、低速与学校周边的禁怠速、以及车辆的分级收费——其健康收益的主体来自流量的减少而非车型的更换）；三，工业（对调峰电厂设运行的限制（其每年只运行几十小时却贡献不成比例的峰值，这是最容易的一项）与排放的连续监测公开）；四，室内与个体（把学校的教室与养老与医院先做机械通风与过滤，把可负担的空气净化器在污染日发给高危的患者——作为“最后一层”而不是替代上游）；五，监测与沟通（城市网格的传感器与实时的公开指数与在指数超标日的学校与养老与工地的行动规则，以及对“哪一天该做什么”的通俗指引）。评估：暴露的监测（颗粒物与黑碳与二氧化氮与臭氧的分布而非只有均值）与健康的近端指标（学校的肺功能与哮喘急诊与心血管事件的急诊与全因死亡的超额），加上公平的层次（最贫困社区是否受益最多——它们通常既是暴露的最大承受者又是替代措施支付能力最弱者）与意外的后果（清洁取暖的燃料选择：电力与热泵优于生物质；把煤换成木屑会加重室内与区域的颗粒与森林的压力）；并预先说明“达标不等于安全”（在浓度—反应无阈值的情形下，5微克只是可行的里程碑）与政策需要随科学更新而重新收紧——[[public-health/health-systems-economics]]、[[cardiovascular/vascular-disease]]。**

::: exercise 为一次辐射事故分诊 {level=2}
一次工业源的事故后有六名接触者：甲在十分钟内呕吐并伴局部的手部溃疡；乙在五十分钟后呕吐；丙仅焦虑而无呕吐；丁为孕妇且在源旁停留最久；戊已在外院被给予普鲁士蓝；己不明原因的全血细胞下降。请分诊并说明依据。
::: solution
**分诊的依据（[[#def-energy]]、[[#def-toxins]]、[[emergency-critical-care/major-incidents]]）：呕吐出现的时间是最早且最有用的剂量指标（越早越高），配合淋巴细胞的系列动力学（在二十四与四十八小时的绝对淋巴细胞计数曲线是最实用的生物剂量计，双着丝粒的染色体分析在数日内给出更精确的剂量）；局部的手部的溃疡提示近距离与高剂量的局部照射（需要按放射损伤的外科原则处理：保功能的清创与血管的评价与分期，而不是立即的截肢；并追踪剂量的测绘与皮肤的迟发效应与晶状体的随访）。分层的处置：甲（疑似急性辐射综合征的造血与胃肠型，立即转入有隔离与输血与生长因子与层流条件的中心，按分期的方案给予细胞因子并在有指征时用干细胞输注）；乙（观察与系列的计数，可能在数日内出现造血的抑制）；丙（焦虑是真实的伤害：给以信息与随访而不要用检查强化其信念，并说明没有呕吐与无剂量证据的含义，同时不要承诺“绝对没事”）；丁（胎儿的风险按孕周与剂量：早期的高剂量可致流产与中枢的损害，而低剂量则远低风险；处理是准确的剂量估算与清晰的解释与延续妊娠的支持性照护，而不是任何“自动”的建议）；戊（普鲁士蓝用于铯与铊的内污染，说明这是内污染的路线，需要继续的粪便与全身计数器与甲状腺的评估）；己（全血细胞下降者按急性辐射综合征的造血型处理，并排除其他的原因：合并的化学品与病毒与药物）——[[blood/haematopoiesis]]、[[obstetrics-gynaecology/pregnancy-complications]]。共同的三件事：污染的去污（衣物与皮肤的清洗与伤口的处理并保护救治者——二次污染是本院伤亡的主要来源）；剂量重建（把每个人的位置与时间与源的几何记录下来，供数月后的判断与赔偿）；以及沟通（对公众讲“外照射不会让你变成放射源，而污染会被洗掉”，这一句话能减少大多数的恐慌；并按法定的报告与国际的通报）——[[emergency-critical-care/major-incidents]]、[[clinical-skills/communication]]。**

::: exercise 辨认粉尘 {level=1}
把下列病理与影像的描述与粉尘配对：上叶的结节与蛋壳样的淋巴结；下叶的纤维化与胸膜斑；非干酪性的肉芽肿；煤的黑色斑与大块纤维化；双折射的颗粒与同心圆的玻璃样结节。
::: solution
**形态对应暴露（[[#def-dust]]、[[pathology/diagnostic-pathology]]）：上叶的结节性纤维化与蛋壳样钙化的淋巴结——二氧化硅（矽肺，并警惕并发的结核与随后出现的自身免疫的关联，其结节呈同心圆的胶原）；下叶的间质纤维化合并胸膜斑——石棉（胸膜斑提示暴露而非疾病本身，且不引起明显的限制性障碍，除非弥漫且厚）；非干酪性的肉芽肿——铍（与结节病难分，需暴露史与淋巴细胞增殖的证据并排除感染与肿瘤与药物）；黑色的煤斑与大块纤维化——煤（并发二氧化硅时进展更快，即混合性的尘肺）；同心圆玻璃样结节伴双折射的颗粒——矽或混合的粉尘（在偏振光下可辨结晶的硅）。四条通用的读片原则：分布（上叶与下叶与淋巴道）、胸膜是否受累、淋巴结的形态、以及是否有进行性的块状纤维化；以及一句更硬的提醒：病理只说明“这是什么反应”，而病因来自病史——同一张切片可以来自矿山、喷砂的车间、拆船的舱室、牙科与石艺的工作台、或者陶瓷与玻璃的厂房——[[respiratory/interstitial-vascular-disease]]、[[public-health/environmental-occupational]]。**

::: exercise 处理升高的血铅 {level=2}
一名汽车维修工的血铅被报为52微克每分升，他无症状、有四岁的孩子、并仍在做含铅部件的切割。请写出你的处理与随访计划。
::: solution
**成人的铅（[[#def-toxins]]、[[public-health/environmental-occupational]]、[[renal/tubular-function]]）：即刻的动作有四：一，停止继续的暴露（在切断来源之前任何药物都只会把铅重新分布；干切与打磨与焊枪产生的烟尘是主要的途径，湿法与局部抽气与更换工艺才是解法，并检查他的衣物与鞋子是否被带回住宅——这是儿童暴露常被忽略的一环）；二，确认与评估（静脉的血铅复查、全血计数与铁状态与肌酐与血压与尿酸与周围神经的症状与口腔与腹部的体征；锌与原卟啉或血的涂片在判断慢性暴露的时长上有用；同时为他的孩子安排检测，因为儿童的血铅在本例中属于“必须排除的紧急情形”）；三，职业卫生与法定的程序（雇主与监管的责任与岗位的调整与带薪的脱离暴露、以及向公共卫生与职业部门报告的义务，并做同岗位人群的筛查）；四，驱铅（在此水平且有持续暴露的成人口服螯合常被使用，但只有在切断来源的前提下才有意义，并需监测肾功能与微量元素的丢失与药物的不良反应）。随访：起始后的数周内复查血铅（观察是否继续下降）、随后数月一次（骨铅的释放造成的“反跳”是预期内的，不是新的暴露）、以及血铅与血压与肾功能的长期观察与生殖的咨询（铅对生育与精子的影响与经胎盘与经乳汁的传递——[[obstetrics-gynaecology/pregnancy-complications]]、[[endocrine/reproductive-endocrinology]]）；记录与教育（洗手与不在工作处进食与更衣与淋浴，以及对家庭暴露路径的一一排查），并把“回到什么岗位、什么时候”以书面形式固定，因为多数复发的原因是没人真正改变工作方式——[[clinical-skills/records-handover]]。**

::: exercise 在一次辐射事件后给出建议 {level=2}
一次医院的放射治疗装置的故障使三名患者在治疗中接受了超出计划的剂量；事件已被内部发现并尚未对外公布。请给出你的建议。
::: solution
**过量照射后的义务（[[#def-energy]]、[[medical-ethics-law/professionalism-regulation]]、[[clinical-skills/patient-safety]]）：这是一起必须“立刻告知”的事件，理由不仅是伦理（诚实与自主）也是实用（他们后续的症状会被归因于原发癌而非照射，从而被错误地处理），并且国际上此类事件有强制的报告框架。临床的一层：请放射生物与肿瘤物理的专家重建每个人实际接受的剂量与分次与受照的体积与器官（皮肤与脊髓与肠与肺与肾与骨），并按此重新估计收益与风险的平衡——对某些人会改变后续的治疗计划（是否继续、是否调整、是否改为姑息），对某些人增加随访（皮肤的溃疡与纤维化与黏膜与吞咽与肠与膀胱的迟发反应与继发肿瘤的风险——注意后者在晚期癌症患者身上常常不再是主要问题，这一点要诚实说出）；并给出书面的症状清单与明确的联系人（“出现什么情况立即打这个电话”）。沟通的一层：不要用“没有伤害”开头，而要说“我们造成了一个错误，这是我们知道的事实、我们还不知道的、以及我们打算怎么做”；提供他们在场时的第二次谈话与一位独立的支持者（家属或 维权组织）；并承诺时间表并如期更新。系统的一层：向监管机构与国家与（如适用）国际的报告；原因的调查（设备的联锁与验收与周期性的检测与剂量计的维护与人员的配置与“为什么检测没发现”），实施整改并验证；以及把这次事件作为对其他单位的通报（这类事件中，同一型号的装置常常在多处以同样的方式使用，行业层面的告警能防止更多受害者）——[[pathology/diagnostic-pathology]]、[[public-health/health-systems-economics]]。最后：治疗团队的道德创伤要处理（他们中的多数人并非过失者，事件通常是系统的联锁失效），而对患者的补偿路径应尽早透明而不是留给律师——[[geriatrics-palliative/palliative-care]]。**

::: exercise 就低剂量之争陈述意见 {level=3}
有人主张“低剂量的电离辐射无害，因此线性无阈模型是被高估的恐惧”。请以流行病学与生物学的证据与之辩论，并说明政策应如何对待不确定性。
::: solution
**低剂量的争论（[[#def-energy]]、[[epidemiology-ebm/observational-studies]]、[[public-health/environmental-occupational]]）：先承认对方对的部分：在数十毫希沃特以下的直接流行病学证据确实弱（置信区间跨过零或依赖于难以控制的选择与混杂），而“适应性反应”与修复与凋亡的机制在低剂量确实存在，且高剂量的数据向外推在生物学上并不自动正确。再说证据的另一面：第一，最有力的队列（寿命研究的原子弹幸存者）在低剂量段虽不显著但点估计持续为正，并与职业照射（核工业工人与放射技师与早期放射医师的白内障与肿瘤死亡与白血病）与医疗照射（儿童的CT与CT后的白血病与脑瘤、放疗后的继发癌、以及职业与环境的队列，如氡与粉笔厂与天然高本底地区的混杂结果）方向一致；第二，机制上，双链的断裂与其错接在单个粒子的径迹上即可发生，且儿童的细胞分裂更活跃（同样的剂量在儿童有更高的当量风险），因此把“低剂量”外推给成人当作安全等级，是把不确定当作无害；第三，“适应性反应”的群体效应从未被证明能降低癌症的发生，而“ 激素效应的说法 ”的主张也从未在任何随机化的健康终点上被证实——[[clinical-skills/medical-imaging]]。政策的正确立场是：把线性无阈当作保守的规划假设而非精确的风险方程（这正是国际放射防护委员会的立场：它承认不确定性，并用它来防止把不确定性变成对他人的伤害）；同时严格遵守正当性与最优化两个原则（每一次照射必须有明确的收益，且在最合理的可达到的水平之下，不得作为常规）；以及对儿童与孕妇使用更强的措施（剂量与适应证的双重审查与设备的儿科方案）。最后要说清一点：争论的实际影响不在哲学而在分配——低剂量的假设决定了谁住在核设施附近、谁在夜班操作透视设备、谁的孩子做全身计算机断层、以及事故后的疏散线画在哪里。在这种分配问题上把不确定当作无害，等于把举证责任转嫁给最无力拒绝的人——[[medical-ethics-law/justice-resources]]、[[public-health/prevention-promotion]]。**
