一个发现肿块的人需要一连串问题的答案。它到底是不是肿瘤？如果是，是良性还是恶性？它起源于哪种组织？它的细胞看起来有多异常，扩散到了多远？它会对某种特定治疗有反应吗？本章解释用于回答这些问题的概念：区分良性和恶性肿瘤的特征，肿瘤如何命名，如何分级和分期，预后因素和预测因素如何指导治疗，肿瘤标志物和筛查试验应当和不应当如何使用，以及癌如何在远离肿瘤本身的地方产生影响。

病理医师获取这些信息所用的实验室技术，包括活检、免疫组织化学和分子检测，见[[pathology/diagnostic-pathology]]。肿瘤为何如此表现的生物学原理见[[pathology/cancer-biology]]。

## 良性肿瘤与恶性肿瘤

::: definition 良性肿瘤与恶性肿瘤 {#def-benign-malignant}
**良性**肿瘤局限于其起源部位，不浸润周围组织，也不扩散到远处。它通常可以手术切除，患者得以存活。**恶性**肿瘤浸润并破坏邻近组织，并可扩散到远处部位（**转移**）。两者的区分基于四个特征：分化、生长速度、局部浸润和转移。
:::

| 特征 | 良性 | 恶性 |
|---|---|---|
| 分化 | 分化好；与起源组织相似 | 从分化好到未分化（间变）不等 |
| 生长速度 | 通常缓慢 | 通常较快；可能不规则 |
| 局部浸润 | 膨胀性生长，常有纤维包膜；不浸润 | 浸润性生长，侵袭并破坏周围组织 |
| 转移 | 无 | 常见；体积大、分化差的肿瘤更易转移 |

**分化**描述肿瘤细胞在结构和功能上与其起源的正常细胞的相似程度。高分化结肠腺癌仍形成腺体并分泌黏液。低分化腺癌则形成片状细胞，腺体很少或没有。**间变**指完全缺乏分化，是恶性的标志。间变细胞表现为：

- **多形性**：细胞和细胞核的大小与形态不一；
- **核深染**：细胞核着色深，染色质粗；
- 核质比增高，核仁大；
- 核分裂象多且有**病理性核分裂**，例如三极核分裂；
- 失去**极性**，细胞失去正常的排列方向；
- 有时出现瘤巨细胞。

恶性最好的单一标准是**浸润**，唯一的绝对标准是**转移**。少数肿瘤不完全符合这一划分。皮肤基底细胞癌局部浸润和破坏，但几乎从不转移。良性脑膜瘤可以因压迫脑而致死，内分泌腺的良性肿瘤可以因其分泌的激素而致死，嗜铬细胞瘤就可以通过儿茶酚胺致死。

**原位癌**是尚未浸润穿过基底膜的上皮性恶性肿瘤。其细胞看起来是恶性的，但不能转移，因为上皮内没有淋巴管和血管。完全切除即可治愈。一旦肿瘤穿过基底膜，就成为浸润性的。

## 肿瘤的命名

::: definition 肿瘤的命名 {#def-nomenclature}
肿瘤根据其细胞或组织来源以及生物学行为命名。

- **良性**肿瘤通常在细胞类型后加后缀*-oma*（中文为“瘤”）：*腺瘤*（形成腺体的良性上皮性肿瘤）、*乳头状瘤*（呈指状突起的良性上皮性肿瘤）、*脂肪瘤*（脂肪）、*平滑肌瘤*（平滑肌）、*软骨瘤*（软骨）。
- **上皮**来源的恶性肿瘤称为**癌**（carcinoma）：*腺癌*（腺性）、*鳞状细胞癌*、*尿路上皮癌*。
- **间叶**组织（结缔组织、肌肉、骨、脂肪）来源的恶性肿瘤称为**肉瘤**：*脂肪肉瘤*、*平滑肌肉瘤*、*骨肉瘤*。
- 造血细胞的恶性肿瘤是**白血病**和**淋巴瘤**。
:::

有几个名称不符合这些规则，必须专门记住：

- **淋巴瘤**、**黑色素瘤**、**间皮瘤**和**精原细胞瘤**都是恶性的，尽管以*-oma*（“瘤”）结尾。*肝细胞瘤*（hepatoma）是肝细胞癌的旧称。
- **畸胎瘤**含有来自一个以上胚层的组织，起源于生殖细胞。卵巢成熟性囊性畸胎瘤（皮样囊肿）是良性的；成人睾丸畸胎瘤是恶性的。
- **混合瘤**含有来自同一胚层的一种以上细胞类型，如涎腺多形性腺瘤。
- **错构瘤**是由该部位固有组织紊乱构成的肿块，如肺内的软骨和支气管上皮。**迷离瘤**是位置异常的正常组织，如胃壁中的一个胰腺组织结节。两者都不表现为恶性肿瘤的行为。
- 儿童胚胎性组织的肿瘤称为**母细胞瘤**：神经母细胞瘤、肾母细胞瘤（Wilms瘤）、视网膜母细胞瘤。它们是恶性的。

权威的国际分类是世界卫生组织肿瘤分类，按器官系统分册出版，目前为第五版。

::: quiz

::: solution

## 分级与分期

两个问题决定了癌的大部分预后和治疗：它的细胞看起来有多异常，以及它扩散到了多远？

::: definition 分级与分期 {#def-grade-stage}
- **分级**是根据显微镜下表现对肿瘤侵袭性的评估，依据其分化程度，在许多分级系统中还依据其核分裂活性。级别通常从1级（高分化，低级别）到3级（低分化，高级别）编号。
- **分期**是对肿瘤解剖范围的评估：原发肿瘤的大小或浸润深度、区域淋巴结的扩散以及有无远处转移。
:::

::: theorem 分期通常比分级更能预测结局 {#thm-stage}
对于大多数实体瘤，分期比分级更能预测生存，因为分期衡量的是已经发生的事情（扩散），而分级衡量的是一种倾向。两者与其他因素一起用于选择治疗。
:::

**分级系统**因器官而异。两个重要的例子：

- **乳腺癌（Nottingham分级）。** 三项特征各评1至3分：腺管形成、核多形性和核分裂计数。总分（3至9）给出1级（3至5分）、2级（6或7分）或3级（8或9分）。
- **前列腺癌（Gleason评分和ISUP分级分组）。** 病理医师为最常见的结构和其余最高级别的结构各给出3、4或5的Gleason分级，然后相加。评分再归入五个**分级分组**：分级分组1为Gleason 3+3=6，分级分组2为3+4=7，分级分组3为4+3=7，分级分组4为评分8，分级分组5为评分9或10。

**分期**采用国际抗癌联盟（UICC）的**TNM系统**，其第九版自2026年1月1日起在英国生效。

- **T**描述原发肿瘤：其大小或浸润深度（T1至T4），Tis表示原位癌。
- **N**描述区域淋巴结：N0表示无受累；N1至N3表示受累程度递增。
- **M**描述远处转移：M0（无）或M1（有）。

前缀记录分期的获得方式：**c**表示临床分期（体格检查和影像学），**p**表示病理分期（切除标本检查之后），**y**表示新辅助治疗后，**r**表示复发。T、N、M类别组合成I至IV的**分期组**，用于预后判断和治疗决策。每个器官的具体类别不同，且随版本而变化，因此总是要查阅而不是靠记忆。

::: example 结肠癌的分期 {#ex-tnm}
一名67岁男性因盲肠癌接受右半结肠切除术。病理报告：中分化腺癌，浸润穿过固有肌层进入结肠周围脂肪；23枚淋巴结中2枚有转移癌；CT未见远处转移。用TNM和分期组表达这一结果，并解释其对治疗的意义。
::: solution
1. **T**：浸润穿过固有肌层进入结直肠周围组织，对结直肠癌而言为**pT3**。（T1为浸润黏膜下层，T2为浸润固有肌层，T4为浸润脏层腹膜或其他器官。）
2. **N**：2枚区域淋巴结转移为**pN1**（N1包括1至3枚受累淋巴结；N2为4枚或以上）。
3. **M**：无远处转移为**cM0**，因为它是由影像学评估的。
4. 任何有区域淋巴结受累而无远处转移的肿瘤都是**III期**结肠癌。
5. 淋巴结受累表明癌已扩散到肠外，因此术后恢复后通常考虑辅助化疗，由多学科团队与患者共同决定。**分级**（中分化）会被报告，但对处理的影响不如分期大。推荐至少检查12枚淋巴结，因为检出数量过少有分期不足的风险（[[gastrointestinal/gi-bleeding-cancer]]）。
:::
:::

::: example Nottingham分级 {#ex-grade}
一例乳腺癌腺管形成少（3分），核多形性中等（2分），核分裂计数高（3分）。它的Nottingham分级是多少？仅凭分级能决定治疗吗？
::: solution
1. 总分 $= 3 + 2 + 3 = 8$。
2. 总分8或9为**3级**，即低分化、高级别癌。
3. 分级只是几种预后因素之一。治疗还取决于肿瘤大小、淋巴结状态以及**预测性**标志物雌激素受体、孕激素受体和HER2。有一些工具把这些因素结合起来，估计治疗的获益（[[surgery/breast-endocrine-surgery]]）。
:::
:::

## 预后因素与预测因素

::: definition 预后因素与预测因素 {#def-predictive}
- **预后因素**提供有关疾病可能结局的信息，与治疗无关。例如：分期、分级、淋巴管血管侵犯。
- **预测因素**提供有关某种特定治疗可能获益的信息。例如：乳腺癌雌激素受体表达预测内分泌治疗获益；*HER2*扩增预测HER2靶向药物获益；结直肠癌的*KRAS*或*NRAS*突变预测抗EGFR抗体**无**获益。
:::

有些因素兼具两者。*HER2*扩增曾预示预后不良，但现在它也预测靶向治疗的获益，这大大改善了HER2阳性乳腺癌患者的结局。

## 肿瘤标志物

::: definition 肿瘤标志物 {#def-marker}
**肿瘤标志物**是由肿瘤产生、或由机体对肿瘤作出反应而产生、可在血液、尿液或组织中测定的物质。血清肿瘤标志物主要用于**监测**已知癌症的治疗和发现复发，以及在特定情况下支持诊断。除少数例外，它们缺乏用于筛查或单独用于诊断所需的灵敏度和特异度。
:::

| 标志物 | 主要肿瘤 | 引起升高的其他原因 |
|---|---|---|
| PSA（前列腺特异性抗原） | 前列腺癌 | 良性前列腺增生、前列腺炎、尿路感染、近期射精或剧烈运动、导尿管 |
| CA-125 | 卵巢上皮性癌 | 月经、妊娠、子宫内膜异位症、盆腔炎、任何腹膜刺激、肝病、心力衰竭 |
| AFP（甲胎蛋白） | 肝细胞癌；卵黄囊瘤 | 妊娠、慢性肝炎和肝硬化 |
| hCG（人绒毛膜促性腺激素） | 绒毛膜癌；妊娠滋养细胞疾病；某些生殖细胞肿瘤 | 妊娠 |
| CEA（癌胚抗原） | 结直肠癌（监测） | 吸烟、炎症性肠病、肝病 |
| CA 19-9 | 胰腺癌和胆道癌 | 梗阻性黄疸、胰腺炎；缺乏Lewis血型抗原者不产生 |

当已知肿瘤会产生某种标志物时，该标志物的价值最大。睾丸生殖细胞肿瘤就是一个例子：在诊断时测定AFP、hCG和LDH，它们参与分期（“S”类别），并用于发现复发。在英国，NICE建议对持续存在提示卵巢癌症状（如腹胀、早饱和盆腔疼痛）的女性测定CA-125；水平为35 IU/mL或以上时，进行腹部和盆腔超声检查。

::: example CA-125升高 {#ex-ca125}
一名34岁女性已知患子宫内膜异位症，有盆腔疼痛。全科医生测定CA-125为88 IU/mL（参考值低于35）。她非常担心自己患了卵巢癌。解读这一结果。
::: solution
1. CA-125是一种糖蛋白，由体腔上皮来源的组织表达，包括腹膜、胸膜和子宫内膜。
2. **子宫内膜异位症**常使CA-125升高，月经和其他腹膜刺激也是如此。绝经前患子宫内膜异位症的女性CA-125升高，更可能反映的是这一情况而不是癌。
3. 卵巢上皮性癌在34岁时少见，绝经后则常见得多，因此验前概率很低。
4. 这一结果仍需适当随访：做超声检查，若卵巢表现异常则进一步评估。妇科采用结合CA-125、超声特征和绝经状态的评分系统（如恶性风险指数）。
5. 这个例子说明了为什么CA-125不用于一般人群的筛查：假阳性很常见，而在早期卵巢癌中CA-125常常正常（[[obstetrics-gynaecology/gynaecological-cancer]]）。
:::
:::

::: warning 标志物正常不能排除癌，升高也不能证明癌
血清肿瘤标志物在早期癌中常常是正常的，而此时发现癌最为重要；约一半早期卵巢癌的CA-125正常，某些侵袭性前列腺癌的PSA仅轻度升高。标志物也会因良性疾病而升高。为症状含糊的人送检一组“肿瘤标志物”而没有明确的问题，会带来虚假的安慰和虚惊，并导致更多不必要的检查。申请标志物应当是为了回答一个明确的问题，通常针对已知或高度怀疑患有会产生该标志物类型肿瘤的人。
:::

## 筛查

**筛查**是对没有症状的人进行检测，以便足够早地发现疾病或其前驱病变，从而改善结局。它不同于诊断：大多数接受筛查的人是健康的，筛查的危害落在他们身上。

::: theorem 筛查的原则 {#thm-screening}
只有当所针对的疾病是重要的健康问题、有可识别的早期阶段，存在可接受的准确检测方法，早期治疗能改善结局，并且总体获益大于危害、成本合理时，筛查项目才是合理的。这些原则由Wilson和Jungner于1968年为世界卫生组织提出，在英国由英国国家筛查委员会采用。
:::

三种偏倚使筛查看起来比实际更有效，因此只有以死亡率为结局的随机试验才能证明真正的获益。

- **领先时间偏倚。** 筛查更早地发现癌，因此即使死亡时间相同，从诊断起算的生存期也更长。
- **病程长度偏倚。** 生长缓慢的肿瘤在可检出的症状前期停留更久，因此筛查更容易发现它们。而它们本来就预后较好。
- **过度诊断。** 筛查发现一些在患者一生中都不会引起症状或死亡的癌。治疗这些癌只带来危害而无获益。这在前列腺癌、乳腺癌和甲状腺癌中尤其是个问题。

::: example 领先时间 {#ex-leadtime}
某男性的结直肠癌本应在66岁时出现症状，若没有任何有效治疗，他将在70岁时死亡。筛查在62岁时发现了同一个癌，但假设早期治疗并未改变病程，他仍在70岁时死亡。计算两种情况下从诊断起算的生存期，并解释其中的错误。
::: solution
1. 无筛查：66岁诊断，70岁死亡，生存期 $= 4$年。
2. 有筛查：62岁诊断，70岁死亡，生存期 $= 8$年。
3. 从诊断起算的生存期翻了一倍，但他一天也没有多活。多出的四年是**领先时间**：他只是更早地知道了自己的癌。
4. 这就是为什么必须在随机试验中比较筛查组和未筛查组的**死亡率**（人群中的死亡数），而不是比较从诊断起算的生存期，来判断筛查的获益。肠癌筛查通过了这一检验：粪便隐血试验的随机试验降低了结直肠癌死亡率（[[public-health/screening]]）。
:::
:::

截至2026年，英格兰的癌症筛查项目如下：

| 项目 | 邀请对象 | 检测 |
|---|---|---|
| 肠癌 | 50至74岁，每2年一次 | 居家粪便免疫化学试验（FIT）；阳性者行结肠镜检查 |
| 乳腺癌 | 50至71岁女性，每3年一次 | 乳腺X线摄影 |
| 宫颈癌 | 25至64岁 | 以HPV检测为初筛，发现HPV者加做细胞学；HPV阴性后每5年一次（自2025年7月起25至49岁者也是如此，与50至64岁相同） |
| 肺癌 | 有吸烟史的55至74岁人群，正在全国推行 | 风险评估，然后对高风险者行低剂量CT |

前列腺癌没有人群筛查。2026年5月，英国国家筛查委员会建议不对一般人群进行筛查，仅建议对携带*BRCA2*变异且有相关家族史的45至61岁男性进行针对性筛查；其实施取决于政府的决定。希望接受PSA检测的男性在充分了解获益和危害后可以申请检测。苏格兰、威尔士和北爱尔兰的项目在一些细节上有所不同。

caption: 一个示意性的筛查试验，灵敏度87%，特异度90%，用于每1000人中有8人患癌的人群。大多数阳性结果是假阳性，因为健康的大多数人产生了大量假阳性。提高患病率（如在有症状的门诊中），阳性预测值随之上升。这些是教学用数值，不代表任何具体项目的性能。
:::

::: example 阳性结果意味着什么？ {#ex-ppv}
某筛查试验灵敏度为87%，特异度为90%，用于每1000人中有8人患癌的人群。在10000名受检者中，真阳性和假阳性各有多少？阳性预测值是多少？
::: solution
1. 患癌者：$10{,}000 \times 0.008 = 80$。真阳性：$80 \times 0.87 = 69.6 \approx 70$。
2. 未患癌者：$9{,}920$。假阳性：$9{,}920 \times 0.10 = 992$。
3. 阳性预测值 $= \dfrac{69.6}{69.6 + 992} \approx 0.066$，约6.6%。
4. 每16名阳性者中约有15人并未患癌。这就是为什么阳性筛查结果引出的是进一步的诊断性检查（结肠镜、活检）而不是治疗，也是为什么向受邀筛查者提供的信息必须解释假阳性。这一计算在[[epidemiology-ebm/diagnostic-tests]]中展开。
:::
:::

## 副肿瘤综合征

::: definition 副肿瘤综合征 {#def-paraneoplastic}
**副肿瘤综合征**是癌症患者身上一组无法用肿瘤的局部或转移性扩散、也无法用起源组织正常产生的激素来解释的症状和体征。它由肿瘤分泌的物质（激素、细胞因子）或针对肿瘤与正常组织共有抗原的免疫反应引起。
:::

副肿瘤综合征之所以重要，是因为它可能是隐匿性癌的首发表现，本身可能严重甚至致命，并可用于监测肿瘤。

| 综合征 | 机制 | 典型肿瘤 |
|---|---|---|
| 高钙血症 | 甲状旁腺激素相关蛋白（PTHrP） | 鳞状细胞癌（肺、头颈部）、肾癌、乳腺癌 |
| 库欣综合征 | 异位ACTH | 小细胞肺癌、神经内分泌肿瘤 |
| 低钠血症（SIADH） | 异位抗利尿激素 | 小细胞肺癌 |
| 红细胞增多症 | 促红细胞生成素 | 肾细胞癌、肝细胞癌、小脑血管母细胞瘤 |
| Lambert-Eaton肌无力综合征 | 抗电压门控钙通道抗体 | 小细胞肺癌 |
| 小脑变性 | 抗浦肯野细胞抗原抗体（如抗Yo） | 卵巢癌和乳腺癌 |
| 重症肌无力 | 抗乙酰胆碱受体抗体 | 胸腺瘤 |
| 游走性血栓性静脉炎（Trousseau征） | 组织因子和黏液等促凝物质 | 胰腺癌和其他腺癌 |
| 肥大性骨关节病和杵状指 | 不明 | 肺癌 |
| 黑棘皮病、皮肌炎 | 不明；免疫性 | 胃癌和其他癌 |

癌症中的高钙血症并不都是副肿瘤性的：它也可能由转移灶破坏骨质引起，这在乳腺癌和骨髓瘤中很常见。

::: example 意识混乱的吸烟者 {#ex-paraneoplastic}
一名吸烟45年的66岁男性在两周内出现意识混乱和便秘。校正血清钙3.4 mmol/L，甲状旁腺激素被抑制，胸片显示右肺门肿块。骨扫描未见转移。解释其高钙血症。
::: solution
1. 高钙伴甲状旁腺激素**被抑制**，排除了原发性甲状旁腺功能亢进症，后者的PTH会升高或不适当地正常。
2. 没有骨转移，局部骨破坏不太可能是原因。
3. 最可能的解释是肺鳞状细胞癌分泌**甲状旁腺激素相关蛋白**（PTHrP）。PTHrP作用于骨和肾的PTH受体，增加骨吸收和肾脏对钙的重吸收，但PTH检测测不到它。
4. 这是**恶性肿瘤体液性高钙血症**，属于副肿瘤综合征。它需要按当地指南紧急治疗，肿瘤也需要诊断和分期（[[respiratory/lung-cancer-pleura]]，[[endocrine/bone-calcium]]）。
:::
:::

## 癌症负担

癌症是全球主要死因之一。国际癌症研究机构（IARC）估计，2022年约有2000万新发病例和970万死亡。在英国，最常见的癌是乳腺癌、前列腺癌、肺癌和肠癌，肺癌造成的死亡最多。年龄是最强的危险因素，因为突变随时间积累。发病率和结局还受贫困、吸烟、肥胖、酒精以及获得诊断的机会影响，因此癌症统计显示出社会群体之间的巨大不平等（[[public-health/non-communicable-disease]]）。

::: history
1932年，英国病理学家杜克斯（Cuthbert Dukes）发表了基于浸润深度和淋巴结受累的直肠癌分期系统；杜克斯分期沿用了数十年，并表明扩散范围能预测生存。1943年至1952年间，法国外科医生德努瓦（Pierre Denoix）创建了TNM系统，后被UICC采纳。1943年，帕帕尼科拉乌（George Papanicolaou）和特劳特（Herbert Traut）证明宫颈癌及其前驱病变可以在阴道涂片中发现，这是宫颈细胞学筛查的基础。格里森（Donald Gleason）于1966年描述了他的前列腺癌分级系统，1968年威尔逊（James Wilson）和容格纳（Gunnar Jungner）为世界卫生组织发表了他们的筛查原则。
:::

## 后续内容

这些概念被逐个器官地应用：乳腺癌见[[surgery/breast-endocrine-surgery]]，结直肠癌见[[gastrointestinal/gi-bleeding-cancer]]，肺癌见[[respiratory/lung-cancer-pleura]]，妇科肿瘤见[[obstetrics-gynaecology/gynaecological-cancer]]。病理医师如何从标本中得出分级、分期和预测性标志物见[[pathology/diagnostic-pathology]]，筛查项目的原则见[[public-health/screening]]。

::: summary
- 良性肿瘤分化好、生长慢、膨胀性生长且不转移；恶性肿瘤分化程度不一，浸润并转移。浸润是最好的标准，转移是决定性的标准。
- 间变表现为多形性、核深染、核质比增高、病理性核分裂和极性丧失。原位癌尚未穿过基底膜。
- 良性肿瘤以“瘤”（*-oma*）命名；上皮来源的恶性肿瘤是癌，间叶来源的是肉瘤。淋巴瘤、黑色素瘤、间皮瘤和精原细胞瘤是恶性的。
- 分级描述镜下的侵袭性（Nottingham分级、Gleason/ISUP分级分组）；分期描述解剖范围（TNM，英国自2026年起采用UICC第九版）。分期通常更能预测结局。
- 预后因素预测结局；预测因素预测特定治疗的获益（ER、HER2、*RAS*）。
- 肿瘤标志物（PSA、CA-125、AFP、hCG、CEA、CA 19-9）用于监测和回答特定的诊断问题，不用于一般筛查。
- 由于领先时间偏倚、病程长度偏倚和过度诊断，筛查要用随机试验中的死亡率来评判。患病率低时，筛查试验的阳性预测值低。
- 副肿瘤综合征源于肿瘤产物或交叉反应性免疫：PTHrP引起的高钙血症、异位ACTH和ADH、Lambert-Eaton综合征等。
:::

::: exercise 阳性预测值 {level=2 check="round(100*0.018/(0.018+0.049))"}
一项灵敏度90%、特异度95%的检测用于患病率为2%的人群。阳性结果中真阳性占百分之几？四舍五入到整数百分比。
::: hint
以1000人来计算。
:::
::: solution
1000人中有20人患病，其中18人检测阳性。980名未患病者中有5%（49人）检测阳性。PPV $= 18/(18 + 49) = 0.269$，约27%。
:::

::: exercise 领先时间的数字 {level=2 check="5"}
某癌本应在64岁时因症状被诊断，69岁时导致死亡。筛查在59岁时发现了它，但死亡日期不变。从诊断起算的生存期看起来改善了多少年？
::: solution
无筛查时生存期为$69 - 64 = 5$年；有筛查时为$69 - 59 = 10$年。看似改善的5年完全是领先时间。
:::

::: exercise 用哪个标志物，为什么？ {level=2}
对下列每种情况，说明肿瘤标志物是否合适以及用哪一个：(a) 非精原细胞性生殖细胞肿瘤睾丸切除术后监测；(b) 为一名担心患癌的健康45岁女性做“筛查”；(c) 结直肠癌切除术后随访；(d) 肝硬化男性的肝癌监测。
::: solution
(a) 合适：AFP和hCG（加LDH），治疗成功后下降，复发时升高。(b) 不合适：没有任何标志物适合作为一般人群的筛查试验，假阳性会造成伤害；应为她提供她有资格参加的国家筛查项目。(c) 合适：CEA，结合CT，作为随访的一部分。(d) 超声是主要的监测检查；某些方案中可同时使用AFP，但它单独使用灵敏度不够。
:::
:::

::: exercise 血钠118 {level=3}
一名吸烟的61岁女性血清钠118 mmol/L，血浆渗透压低，尿液浓缩，无脱水或水肿体征。此后数周内她出现近端肌无力，反复用力后可短暂改善。CT显示中央型肺部肿块伴纵隔淋巴结明显肿大。给出最可能的肿瘤类型，解释两种综合征，并说明识别它们为什么重要。
::: solution
最可能的肿瘤是**小细胞肺癌**，这是一种与吸烟密切相关且常伴副肿瘤综合征的神经内分泌肿瘤。低钠血症伴尿液浓缩和容量状态正常，符合**抗利尿激素分泌失调综合征**：肿瘤分泌ADH，肾脏潴留水分，钠被稀释。用力后短暂改善的肌无力符合**Lambert-Eaton肌无力综合征**：针对肿瘤电压门控钙通道产生的抗体与运动神经末梢上的钙通道发生交叉反应，减少乙酰胆碱释放；反复用力短暂地增加钙内流和递质释放。识别它们很重要，因为它们可能是癌的首发表现，严重低钠血症可引起抽搐且必须谨慎纠正，而且治疗肿瘤常能改善这些综合征（[[respiratory/lung-cancer-pleura]]）。
:::
:::

::: exercise 我们应该筛查吗？ {level=3}
一位同事建议用一种灵敏度80%、特异度90%的血液检测为所有50岁以上成人筛查胰腺癌。在这一人群中，胰腺癌在任一时点的患病率大约为千分之一。利用筛查原则和预测值的计算，给出有理有据的回应。
::: hint
计算每1000名受检者的阳性预测值。
:::
::: solution
每1000人中约1人患癌，0.8人检测阳性；999名未患癌者中约100人检测阳性。PPV为$0.8/(0.8 + 99.9) \approx 0.8\%$：每100个阳性中超过99个是假阳性，每一个都需要CT或超声内镜等进一步检查，带来费用、焦虑和并发症。该检测还会漏掉五分之一的癌。对照Wilson和Jungner原则，它在几个方面都不合格：对于一种罕见病，检测不够准确；可检出的症状前期短且界定不清；也没有随机试验证据表明早期发现能降低死亡率。目前仅在研究情境中考虑为遗传风险极高的人群筛查胰腺癌，在这些人群中患病率高得多，预测值也相应更好。
:::
:::
