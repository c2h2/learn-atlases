诊断癌症是一串关于标本、名称与分期的决定：**从一处病灶被取下的那一刻（细胞学、粗针、切除、液体）到病理医师的分类（其免疫组化与分子检测的组合）与分级与分期，再到“有没有可被靶向的改变”与“遗传的综合征在不在场”的问题——每一步都是一个可能被行动的程度不同的断言，而链条的最薄弱环节决定了癌症诊断的质量。**本章覆盖取样的选择（细胞学与粗针与切除与内镜与液体活检的能与不能）、命名与测量（分类与分级与分期与其各自的用途与失败）、以及预测与预后与遗传的标志物（受体与通路与突变负荷与可遗传的变异与报告这些结果时的伦理）。

## 取样的方式

::: definition 取样、细胞学与 adequacy {#def-sampling}
**每一种取样方式都回答一类问题，选错方式的错误无法靠阅片弥补。细胞学（细针的抽吸与刷片与灌洗与体液的离心）看的是细胞：它能高置信地说“这是癌的细胞”与“这是反应性的”与“这是不能定类的滤泡性病变”，但不能可靠地说出结构与侵犯，因此不能用于需要架构的诊断（乳腺与甲状腺与唾液腺的滤泡性病变与前列腺的分层与肺的原位与浸润与消化道扁平病变的不典型）；它的最大价值在无法或不宜取组织之处（胰腺后方经超声引导的穿刺与深部的淋巴结与腹腔的积液与脑脊液与（在呼吸科的）经支气管的灌洗）与在快速的术中判断（是否已有沉积的病变）。粗针活检（核心针）看的是组织的条：足以做分级与免疫组化与（常有的）分型与分子的检测，是多数可触及与影像可见病灶的首选，且优于细胞学之处在于它能显示间质的关系（浸润与原位与侵犯被膜）；其局限是阴性不能排除（取材的偏差），故影像与病理不一致时的态度是重复取样而不是“符合临床”。切除与切取（在皮肤与内镜与口腔与外阴的部位）用于需要整体结构的病变（是否侵破基底膜与切缘的评估），而“先切下来再说”在可被完整切除的小病灶上是合理的路径，但必须先想清楚切缘与再次切除的代价（一次不当的活检可能使后续的分期与手术的计划复杂化）。液体活检（循环的脱氧核糖核酸与循环的肿瘤细胞与外泌体）目前的正当用途有限而增长（在若干血液与肺与肠的方案中的基因的分型、在治疗中按突变的动态监测、以及在若干癌种中的术后微小残留病灶的检测——其灵敏度与特异度的组合意味着“阳性提示、阴性不排除”，所以任何基于血液的结论都要在临床的语境与（必要时）组织的确认下解读）；“够不够”这个概念因此贯穿一切：一份标本要么能回答问题，要么不能，而病理医师说”不足以判断“是一种保护性的、需要被感谢的回答，因为它阻止一个不成立的结论被写进病历并驱动此后数月的处置。取样的现场还有几个可预防的错误：部位与侧别的标注（同一器官的多处病灶必须在申请单上区分）、抗凝与固定（骨髓与淋巴的标本需要新鲜与部分做涂片与流式与冷冻，而 福尔马林会毁掉这些）、以及感染与放射与冷冻的特殊处理（怀疑分枝杆菌与朊蛋白与嗜铬细胞瘤时的取样方式不同）——[[clinical-skills/medical-imaging]]、[[pathology/diagnostic-pathology]]、[[surgery/perioperative-care]]。**
:::

## 命名与测量

::: definition 分类、分级与分期 {#def-classify}
**三个词，三种用途，不可互换。分类回答”这是什么“（组织起源与形态的类型与分子的定义），决定治疗的门类的选择（乳腺癌与肺腺癌与结直肠癌与卵巢癌与淋巴癌的方案完全不同），并且在若干实体中已按分子重排（中枢的肿瘤现在按脱氧核糖核酸的特征分类与胃肠道间质的按突变与白血病与淋巴瘤按遗传的异常与若干软组织肿瘤按融合）。分级回答”它有多像它本该是的样子“（分层的异型与分裂与结构的形成的组合），是肿瘤生物学在切片上的粗略投影，其价值在于同一分期内的预后区分与在部分肿瘤中的治疗门槛，但它的可重复性有限（在前列腺与乳腺与子宫内膜与肾与软组织中分级者间的差异不小，因此在若干体系内高度依赖关键病变的第二阅片）——[[pathology/diagnostic-pathology]]。分期回答”它在身体里到了哪里“：解剖学的分期（原发灶的范围与区域的淋巴结与远处）仍是以手术与治疗计划为核心的语言；而预后分期（把分级与标志物与影像与治疗反应加进来）是决策的语言；两者的差异在若干癌种中已成惯例（淋巴的分期加用大肿块的与全身症状的分层与妇科的手术分期与肝的分期把肝功能纳入与甲状腺的按年龄与危险分组）；”分期漂移“（筛查与影像使更多早期病例被发现而使”存活率“改善的现象）与”分期迁移“（同一患者在治疗后分期被重新定义）是解读存活率数据时最常见的两个陷阱，也是为何分期必须写明是临床的还是病理的（前者的错误来自影像的不足，后者的错误来自淋巴结取样不足：若一份结肠切除只报了六枚淋巴结，那么”淋巴结阴性“这句话是取材的产物而非生物学）。分期的报告要包含分期所需的全部要素（原发灶浸润的深度与范围与脉管与神经与切缘的状态与最近的切缘距离与淋巴结的总数与转移的数目与最大转移灶与（在若干部位）沉积的病灶），并在缺失时说明为什么（”未做“与”未见“是不同的话）——[[pathology/cancer-biology]]、[[public-health/screening]]、[[surgery/gastrointestinal-surgery]]。**
:::
::: definition 预测性标志与分子诊断 {#def-biomarkers}
**标志物分四类，混用它们是临床的常见错误：诊断的（确立肿瘤的存在）、预后性的（预测结局而不特别指向某种治疗）、预测性的（预测对某治疗的反应）、以及药效动力学性的（反映靶点被击中）。经典的实现：乳腺与胃的HER2（被扩增者的抗HER2治疗，其检测的判读与（临界值）的复检与前处理的一致性要求使实验室的资质在此成为治疗资格的一部分）与激素的受体（阳性的内分泌治疗，且”低阳性“的分界与治疗强度相关）与肺的驱动通路（上皮的生长因子受体的突变与间变性淋巴瘤激酶与ROS与RET与NTRK与代谢通路与KRAS 的特定改变与MET与HER2 的插入，每一个都有其抑制剂与其耐药的模式）与结直肠与子宫内膜与胃的错配修复与微卫星（预测免疫检查点的抑制并提示林奇综合征的筛查）与卵巢与乳腺与胰腺与前列腺的BRCA与其他同源重组的缺陷（预测聚腺苷二磷酸核糖聚合酶抑制剂的效应并给出遗传的咨询）以及（在血液与若干实体中）按突变的肿瘤负荷与（新兴的）按循环的脱氧核糖核酸的残留病灶。方法的选择决定结果能否被相信：测序的范围与覆盖的深度与已知变异的数据库与克隆性造血造成的假阳性（年龄相关的白细胞的突变会出现在血液的测序中，若不用配对的正常样本对照就会把非肿瘤的变异报给肿瘤的治疗）与（在若干平台上的）拷贝数与融合的漏检（脱氧核糖核酸的测序对重排与表达的改变不敏感，故 RNA 与免疫组化有时是唯一的路径）；因此报告的措辞必须与方法的限度一起给（”未在本方法覆盖的基因中检出“不等于”没有可靶向的改变“）。意义的分级把不确定制度化（一类的致病到四类的良性与三类的意义不明），并且随之带来责任的转移：分类会随证据改变，而实验室是否承诺重分类与回告（以及谁能接触原始数据）应当写入知情同意；而”次要发现“（在为一个成年患者的肿瘤做测序时发现的遗传的乳腺癌易感变异，或一个致病的早发疾病）的处理需要事先约定的政策，因为它涉及家族中的其他人——[[genetics/genetic-testing]]、[[genetics/genomic-medicine]]、[[pharmacology/patient-variation]]。**
:::

::: example 乳腺的结果会议 {#ex-breast-mdt}
乳腺的多学科会上有一份粗针活检：”浸润性癌，非特殊类型，二级，淋血管侵犯未见，雌激素与孕激素受体阳性（90%与80%），HER2 阴性（1+），Ki-67 25%“；影像提示一个22毫米的病灶与一枚形态可疑的腋窝淋巴结（细针穿刺阴性）；患者72岁并有轻度认知损害。
::: solution
**把报告的每一项变成决定（[[#def-biomarkers]]、[[#def-classify]]、[[surgery/breast-endocrine-surgery]]）：分期未定：淋巴结的细针阴性不能排除侵犯（假阴性率不可忽略，尤其当形态可疑），所以外科仍会做前哨的活检；而22毫米加可疑淋巴结意味着术前的腋窝的超声与（必要时）重复的穿刺与术后的分期可能改变放射与全身治疗的强度。生物学决定了门类的选择：激素受体阳性、HER2 阴性意味着以内分泌治疗为主干，是否加化疗取决于（在绝经后且淋巴结有限负担的病例中）多基因的检测结果，因此若她可能拒绝化疗，就不必做该检测（这是一个必须事先约定的实用判断，因为检测的价值完全在于结果会改变处置）——[[endocrine/reproductive-endocrinology]]。Ki-67 的25%是一个跨实验室可重复性有限的指标，不应单独作为治疗强度的依据（它的取样与判读的差异大，且已被多基因检测在部分场景中取代）。她的年龄与认知状态要写在治疗的设计里而非事后考虑：每日口服的方案与依从的支持与（芳香化酶抑制剂的）骨与关节的副作用的管理与髋部的骨密度与（在72岁以上者中）心与肾的共病的评估与（在轻度认知损害者中）决策的辅助与同意能力的评估与照护者的参与——一次”谁替她决定“的澄清比任何标志物更能影响她能否完成治疗——[[geriatrics-palliative/ageing-frailty]]、[[medical-ethics-law/consent-capacity]]。病理与外科的接口：受体的判读与前处理的时间相关（缺血与固定的时长会改变结果的可靠性，故一份”1+“要在合格的实验室才可信）；若术后标本与粗针的受体或HER2 不一致，应按术后为准并重新评估治疗；同时应确认是否已按要求做了（在新辅助治疗后的）病理完全缓解的评估与（在保乳时）切缘的要求——[[pathology/diagnostic-pathology]]、[[clinical-skills/communication]]。会议的产出要写成一句人能执行的话（”先行手术与前哨，术后按分期与多基因的结果决定内分泌与是否化疗与放疗；在术前完成骨与认知与营养的评估“）与一个复核的日期，并把未决的问题（腋窝）明确标出——否则会议记录只是记录——[[clinical-skills/records-handover]]。**
:::

::: example 不确定意义的分子结果 {#ex-vus}
一名41岁、母亲与外祖母均在五十岁前患乳腺癌的女性做了遗传的检测，报告返回 BRCA2 的一个”意义未明的变异“；她的肿瘤未做检测；她问”我该不该切除“”我的女儿要不要查“。
::: solution
**如何回应一个”不知道“（[[#def-biomarkers]]、[[#def-classify]]、[[genetics/genetic-testing]]）：先纠正两个误解：意义未明的变异不是致病突变，也几乎从不是（按人群频率与计算与公共数据库的重新分类）；把临床决策建在它上面是错的（不应据此做降低风险的手术，也不应据此改变筛查的强度）。给她的正确解释：”这个变异目前不能告诉我们风险；大多数人拿到的这类结果最终被证明是良性的；我们不能靠它做决定，但我们也不会因此放弃你真正的风险来源——你的家族史。“这句话要具体到她下一步能做什么：按家族史而非按这一结果做风险评估（用经过验证的模型与家族的完整谱系与发病年龄与双侧与卵巢与胰腺与前列腺的肿瘤），并按结果决定筛查或药物预防或（在她愿意的前提下）研究性的路径；同时把她母亲的肿瘤作为最有价值的资源（若母亲已故但有组织留存，检测肿瘤的体细胞变异与（若合适）该位点的共分离，可以把这个变异向良性或致病的一侧移动——这是家系的变异被重分类的主要途径）——[[pathology/cancer-diagnosis]]。关于女儿：不在”意义未明“的状态下给未成年人做检测（这是明确的伦理与专业共识：只在可能提供医疗益处的成年期检测），同时说明”若日后被重分类为致病，我们会按约定的渠道回告“，并把回告的前提（她同意保留联系与同意的范围与由谁告知）现在就写清。关于她自己的两个实际问题：保险与雇用的歧视在不同法域的保护不同（她可能担心检测的历史影响她，这是真实的顾虑，应被回答而不是被否认），以及心理的负担（”不确定“常常比”坏消息“更难承受；提供遗传咨询的再次面谈与支持的团体，并把”我们现在能做什么“写在纸上带走）——[[clinical-skills/communication]]、[[medical-ethics-law/confidentiality]]。系统的一层：把变异的重分类与回告做成可运行的流程（谁负责在数据库更新后找出受影响的人、用什么措辞、多久一次、以及在原始实验室已消失时的责任归属）；并规定检测前咨询的最低内容（可能的结果的四类与其含义与家族的影响与数据的去向），否则这类谈话会在诊室里被重复上百次而每次都不一致——[[genetics/genetic-testing]]、[[clinical-skills/records-handover]]。**
:::

::: example 不是转移癌的淋巴结 {#ex-echo}
一名有宫颈的鳞状细胞癌病史的女性因颈部淋巴结肿大做切除活检，病理见淋巴结被膜下的鳞状上皮样细胞簇，免疫组化p40 与细胞角蛋白5/6 阳性；她被告知”转移癌“；两位资深医师在复阅时意见不一。
::: solution
**良性异位与转移的鉴别（[[#def-sampling]]、[[#def-classify]]、[[pathology/diagnostic-pathology]]）：这是病理判读中经典的两难：淋巴结内的良性上皮的异位（在宫颈的缪勒管与鳞状的残余与（在腋窝的）乳腺的组织与（在腹腔的）脾内的上皮与（在盆腔淋巴结的）苗勒管的植入，常在被膜下并伴有内膜样或纤毛的类型与（重要的）良性形态与囊性的改变）对上低体积的转移其核的非典型与促结缔组织增生的间质反应与坏死的碎片与（在淋巴结的实质内而非仅在包膜下）与（在有已知原发灶者）与形态与免疫表型的相符。支持良性的证据有：小的、孤立的、包膜下的、无异型的、缺乏间质反应、伴随腺体与纤毛、以及（在若干部位）与既往手术或内膜异位相关的历史；而支持转移的是：大于若干毫米、核仁明显、有丝分裂、坏死的碎片、位于实质、并伴淋巴结的其他反应性改变缺失。关键的第三个证据是分子与共定位：在低体积的病变上，克隆性的检测（若可行）与（在宫颈的原发者的）人类乳头状病毒的检测（在转移灶中检出病毒的信号是强力的联系证据），以及p16 的强弥漫阳性在人类乳头状病毒相关病变中的提示价值——[[obstetrics-gynaecology/gynaecological-cancer]]、[[infectious-diseases/sexually-transmitted-infections]]。做法：不要在同一份报告里独断（这样的病变应当在提交前有第二与第三阅片与免疫组化的组合与（必要时）原发灶的切片的比对与（若有既往的宫颈的锥切）同一病变的人类乳头状病毒的比较）；如果仍不确定，用分层的语言（”符合低体积的鳞状上皮，性质不能确定；建议结合影像与临床并考虑重复取材“）并安排一次多学科的讨论而不是让这句话进入分期——分期被一份不确定的报告改变，是这类事件最大的伤害（把一位患者从”局限“变成”播散“会改变治疗与保险与她的生活）——[[clinical-skills/communication]]。对患者的沟通：在结论改变之前不要给”转移“这一词（一旦说出就难撤回），而是说”两位专家对这一处组织的性质有不同意见，我们正在用附加的检测来判断，并把这一步放在决定治疗之前“；同时给出时间表与负责的人；并把这一例提交关键差异的讨论，评估是否需要修订本实验室的这类病变的报告规范（例如要求此类诊断必须附带”低体积病变的性质“的说明与第二阅片）——[[clinical-skills/patient-safety]]、[[pathology/diagnostic-pathology]]。**
:::

::: example 需要结构的淋巴瘤 {#ex-lymph-node}
一名26岁男性颈部淋巴结肿大，外院的细针穿刺报”反应性增生“；但他有夜间盗汗与饮酒后淋巴结疼痛与体重下降，超声见多个融合的淋巴结；你的团队只有一次粗针的标本可用。
::: solution
**淋巴瘤的诊断为什么需要结构（[[#def-sampling]]、[[#def-biomarkers]]、[[blood/lymphoma-myeloma]]）：细针的细胞学在淋巴瘤上的三个限度：霍奇金的诊断性细胞稀少并藏在反应的背景里、结节的亚型依赖结构（结节性的与弥漫的与滤泡的）与（在若干病例中）需要整个淋巴结才能区分（反应性的滤泡增生对滤泡性淋巴瘤、以及不典型淋巴细胞增生对边缘区的淋巴瘤）。因此临床高度怀疑时的标准是切除活检（保留架构），而粗针只在其不可行或已确诊者的疗效评估时使用；本例若只能做粗针，就必须把能做的都做（多根、多部位、新鲜留样的一部分）并同时送：组织学（结构与人造血窦和间质与（霍奇金的）陷窝样细胞的形态）、免疫组化的组合（T与B与生发中心的标志与（在怀疑霍奇金时的）CD30 与CD15 与PAX5 的弱阳性与上皮膜抗原与（在需要时的）EBV 的原位杂交）、流式（克隆性的免疫球蛋白轻链的限制与异常的T细胞表型）、以及遗传学（选择性易位的荧光原位杂交与（若干体系中的）免疫球蛋白与T细胞受体的基因重排的克隆性——后者在形态不足以定论时提供”是淋巴增殖性“的客观支持）。若这些仍不能定性：不要用一个”反应性“结束（那会让临床延误数月），而是明写”不符合/不能排除某类淋巴瘤，建议切除活检“并亲自与临床联系——一个明确的下一步远胜于一个含糊的诊断。临床的一层：饮酒后的疼痛与盗汗与年轻男性纵隔的病变是霍奇金的经典提示，所以影像（胸腹盆的计算机断层或（在现代路径中）正电子发射的断层）与治疗前分期应在诊断的确立同步准备（并有生育的保存的讨论，在化疗与（可能的）放疗之前——这一条经常被漏掉，而其后果是终身的）；同时排除模拟的情形（结节病与结核与病毒性的淋巴结病与猫抓病与系统性红斑狼疮与血管免疫母细胞的淋巴结病与药物反应与噬血的综合征）——[[infectious-diseases/tuberculosis]]、[[immunology/immunodeficiency]]。流程的教训：把”临床高度怀疑而细胞学阴性“定义为需要复议的触发条件（而不是接受阴性），并在网络内约定淋巴的标本的处理规范（新鲜与冷冻与固定的分配与流式的时限与谁负责打电话告知需要重复取样）；并让一次跨院标本的第二意见成为常规而不是例外——[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]。**

## 通向何处

取样的组织学与分子技术见[[pathology/diagnostic-pathology]]；癌症的生物学与演化（耐药的来源）见[[pathology/cancer-biology]]；遗传的综合征与检测的咨询见[[genetics/cancer-genetics]]与[[genetics/genetic-testing]]；影像在分期与引导取样中的作用见[[clinical-skills/medical-imaging]]；治疗的按标志选择见[[pharmacology/drug-receptor]]与[[pharmacology/patient-variation]]。

::: history
**癌症诊断的历史是三种能力依次到位的历史：看见细胞、给出名字、测量范围。显微镜与染色使细胞可见（十九世纪中叶的病理学把”癌的细胞“与”炎的细胞“分开，并为淋巴与结缔组织命名），而细胞的来源学说的确立使”上皮的 vs 间叶的“成为可能的分类；命名的系统化在十九世纪末与二十世纪初成型：从莫尔森与斯托克斯与贝吉特的分类的尝试，到按器官与形态与（后来）按免疫表型与遗传的异常的分类；世卫组织的分类系列（自1960年代起）把命名变成国际协议，而其最近的版本把分子的特征写进定义（中枢的肿瘤与淋巴与软组织的分型由此改变）。分级从形态的直觉走向可测量的指标（乳腺与前列腺与子宫内膜的分层与（在软件辅助下的）分裂的计数与（在若干部位）按公式计算的分级），同时其可重复性被系统性地量化（观察者间一致性的研究发现若干诊断的分歧大到必须改变常规）；分期则从外科的经验变成有明确定义的语言：从肿瘤分期手册（其分期被写进每一版指南）到淋巴结取样的最低数目的规定（因为分期在淋巴结未被找到的患者中不可能可靠）与（在直肠癌与新辅助治疗后的）治疗后分期的规则与（在病理学中的）残留病灶的评估的定义。免疫组化从1941年以荧光标记抗体的组织定位开始，经1960至1970年代的酶标技术与1970年代的杂交瘤与抗体商品化进入日常（使”未分化“这一诊断变得罕见），并在1990年代之后被分子（从染色体的核型与荧光原位杂交到1990年代的聚合酶链与2000年代后的高通量测序）所补充：2005年前后的乳腺癌与结直肠癌与肺癌的治疗决策开始由实验室的标志决定，这使病理成为治疗的守门人；而”按分子而非按器官“的审批（若干药物的组织不可知许可）与（循环的脱氧核糖核酸的）残留病灶监测把这条路径推到今天——而这段历史反复出现的教训是：诊断的技术进步先于其验证，而每一次”我们能看到更多“都带来”我们如何解释更多“的新伦理——[[pathology/diagnostic-pathology]]、[[genetics/genomic-medicine]]、[[pharmacology/drug-development-prescribing]]。**
:::

::: summary
- 取样方式决定问题的种类：细胞学说细胞、粗针说结构与关系、切除说侵犯与切缘、液体活检说”提示但不能排除“。
- 分类决定治疗门类、分级决定同一分期内的区分、分期决定范围；三者不可互换，且分期必须写明是临床的还是病理的。
- 标本的”够不够“与”能不能定类“是保护性的回答；把不能定类的写成确定，代价由患者付。
- 标志物分四类（诊断、预后、预测、药效），而测序的深度与配对的正常样本与方法的覆盖决定了报告能说什么。
- 意义未明的变异不是风险因素：不因它改变处置，但要承诺重分类与回告，并把家族史作为真正的风险来源。
- 淋巴瘤与若干转移性病变的诊断需要架构与新鲜留样；”反应性“这三个字在临床高度怀疑时必须被复议。
:::

## 练习

::: exercise 为不明的原发灶选标志 {level=1}
一名男性颈部淋巴结内有腺癌的转移，影像未见明确的原发；请给出一组免疫组化的顺序与各自的意义。
::: solution
**按可能性递减的顺序（[[#def-biomarkers]]、[[#def-classify]]、[[pathology/diagnostic-pathology]]）：先确认上皮的（广谱细胞角蛋白与上皮膜抗原）并排除三个”伪装者“（淋巴（CD45 与其他淋巴的标志）、黑色素（S100 与SOX10 与（必要时）HMB45）、以及（在颈部者）鼻咽与唾液腺与甲状腺与甲状旁腺与（在低位的）肺与消化道的来源）。然后定位在颈部淋巴结的腺癌：甲状腺的转录因子与甲状腺球蛋白与（在怀疑时）降钙素，因为甲状腺的乳头状癌可以以淋巴结为首发；上呼吸道的腺样囊性与嗅神经母细胞瘤的形态；肺的来源用甲状腺转录因子1 与细胞角蛋白7 的组合（并注意甲状腺转录因子1 亦见于甲状腺）与（在腺癌中）细胞角蛋白7 阳性而细胞角蛋白20 阴性的模式；消化道上皮用尾型同源盒转录因子2 与细胞角蛋白20 与CDX2（结直肠）与（在上消化道与胰腺胆道的）细胞角蛋白7 与（在胰腺胆道者）糖类抗原19-9 与（在前列腺者）同源框蛋白与前列腺特异的抗原（配合影像与前列腺特异的抗原的水平）；以及女性要考虑乳腺与妇科（此例为男性故略）；肾与肾上腺与（少见的）生殖细胞的标志（精原与甲胎蛋白与人绒毛膜促性腺激素，在年轻男性中一定要考虑，因为它可被治愈）。原则：用一组而不是一个抗体；阳性结果要与形态一致，否则加做与咨询而不是勉强解释；并保留组织做分子（在真正的来源不明时，表达的谱的分类可提供有限的提示，但其证据等级与临床用途要如实说明）。临床的配合：鼻咽镜与（在颈部者）耳鼻喉的评估与甲状腺的超声与（在男性）睾丸的检查与超声与（在结肠的标志者）内镜与（在计划治疗前）按部位的治疗（因为”来源不明的癌“的治疗方案与按部位治疗的差别是可存活的差别）——[[pathology/cancer-biology]]、[[clinical-skills/medical-imaging]]、[[surgery/gastrointestinal-surgery]]。**

::: exercise 从数字判断一个筛查规划 {level=2}
某宫颈癌筛查规划把起始年龄从25岁推迟到30岁、间隔从三年改为五年，理由是引入人类乳头状病毒的检测；五年后发病率在30至34岁组上升12%而25至29岁组下降。请评估。
::: solution
**怎么读这组数（[[#def-biomarkers]]、[[#def-sampling]]、[[public-health/screening]]）：先看设计的可预测后果：推迟起始与延长间隔会在被”少筛“的年龄组造成发病率的上升（既可能来自真实的风险增加，也可能来自累积的病变到较晚才被发现），所以30至34岁组的上升是这一政策的预期信号而非意外——因此关键的终点不是发病率而是浸润癌与死亡的绝对率与其时间轨迹（发病率上升而死亡不升，是”延后但安全“；两者同升，是政策过头）。要看的数据：按年龄与五年的出生队列的筛查参与（覆盖率是否在每个十分位都保持在阈值之上，因为间隔延长后一次未参与等于五年无保护，而依从的不平等会被放大）、病变的分期与分级分布（发现的病变更为进展的证据：更深的浸润与更多的淋巴结与更大的高级别病变比例）、间期癌（两次筛查之间的癌症，是”间隔太长“的最敏感的哨点）、异常结果的处置的时间（在延长间隔的规划中，被漏掉的与延迟的病例的占比会上升）、以及”未被筛查者“的画像（最贫困与少数族群与移民与新迁入者的参与率）。还要看方法学的混淆：筛查的转换会改变检测方法（细胞学对人类乳头状病毒），使两年的发病率不可直接比较（同一个人群的阳性率因方法的灵敏度不同而不同），因此必须做同一队列的前后与用同期未转换的对照。政策的答复：若浸润癌与死亡率未升而30至34岁的病变增加，则应在该年龄组加一次筛查或缩短间隔（这是可校正的设计缺陷），并加强对最难触达人群的招募；若死亡率上升，这是可归因的伤害，需要公开的数据、政策的回调与对患者的说明——[[public-health/determinants-inequalities]]、[[obstetrics-gynaecology/gynaecological-cancer]]、[[epidemiology-ebm/measuring-disease]]。**

你的医院在一年内发生了九起病理分析前的误差（标本被混放与容器未标注与侧别不明与固定液用错与”未做“的项目）；无患者伤害但有三例导致重复手术。请设计方案。
::: solution
**分析前的安全方案（[[pathology/diagnostic-pathology]]、[[#def-sampling]]、[[clinical-skills/patient-safety]]）：先按发生的类型与地点分类（手术间与门诊的内镜与病房与穿刺的介入与检验的接收与实验室的内部），并做九例的根本原因分析（每一例都问：屏障为何失效、为何没有被下游发现、以及”若同一天再多两例会发生什么“）。技术性的强制功能（按有效性排）：单一患者一个时间段的原则（同一时间只处理一位患者的标本，包括手术间与门诊），开盖前的再核对（患者与部位与侧别与容器由两名人员用三个来源（口述的姓名、腕带、申请单）确认），预打印的标签（在打印之前不得离开房间，且”手写“被禁止），条形码的扫描闭环（从床旁到接收，每一步都记录，未扫描即无法进入系统），部位与侧别的下拉菜单与强制的字段（”未标注“与”未指定“不能作为可选值），固定液的错误预先放置两种固定液并以视觉与语言的提示（10%的缓冲福尔马林与（在怀疑特定病变时的）特殊介质与（在需要新鲜时）一个明确的留样的通知），以及标本袋与容器与病理单上的部位的图示（在乳腺与前列腺与子宫内膜与四肢与双侧器官上使用”画出来“的部位图）。人的因素：短时与临时的人员在接收与取材时的误差率高，因此把这些岗位纳入培训与能力的清单与（在有疲劳的夜班）做流程的加固；并鼓励未遂事件的上报（把上报的数量当作健康的指标，因为未遂是即将发生的错误的预报）。系统的一层：把重复手术与”标本丢失“作为可上报的事件并纳入院级的指标；用”接收即扫描“的时间戳与”从离体到固定“的间隔做监控（后者同时是质量与安全的指标）；在年度回顾时把九例的整改是否发生与是否有效一起评估（例如”手写标签“是否真的消失了），并把同类事件的再发率作为唯一有意义的结果。文化的条件：公开说明”没有人因这份报告而被处罚，但我们会追踪流程是否改变“，并把发生的事件变成教学材料（用匿名化的时间线在科室内讲，因为分析前的错误几乎所有人都可能犯——它的可预防性靠屏障而不是靠细心）——[[pathology/diagnostic-pathology]]、[[clinical-skills/patient-safety]]、[[surgery/perioperative-care]]。**

::: exercise 选择检查 {level=1}
为下列五种情形选择首选的检查：甲状腺结节的影像可疑、肺的3毫米磨玻璃、可疑乳腺癌但穿刺三次不典型、肝的表面结节在肝硬化背景下、以及可疑的骨转移但骨扫描阴性。
::: solution
**按”回答什么问题“来选（[[#def-sampling]]、[[#def-classify]]、[[clinical-skills/medical-imaging]]）：甲状腺的可疑结节：超声引导的细针穿刺（按影像的分层决定穿刺的阈值与（在极小者）主动监测的替代），而细胞学不能区分滤泡性肿瘤，这一局限要在同意时说明（本例若为可疑的乳头状则细胞学足够）。3毫米的磨玻璃结节：不穿刺（技术上的困难与假阴性与对低风险病变的过度诊断），而是按指南的复查间隔做薄层的计算机断层，把”稳定即良性可能大“当作主要工具（对生长者再定位处理）——[[respiratory/lung-cancer-pleura]]。可疑乳腺而穿刺不典型：不升级为切除是错的也不对，正确的路径是按不典型的类型决定（某些不典型（如导管的不典型增生与不典型乳头状病变与小叶的原位）在粗针后需要切除以排除相邻的病变，而其他则可以随访），并复核影像与病理的一致性（不一致时重新穿刺而不是手术），以及加做与（在若干体系中）免疫组化的组合与多学科的决定——[[surgery/breast-endocrine-surgery]]。肝硬化背景下的肝结节：诊断可以靠影像的动态强化（动脉期的充盈与门脉或延迟期的廓清）而通常不需要穿刺（穿刺有播散的争议与出血与阴性不能排除），因此选择增强磁共振或增强超声并按本地的分期标准处理（肝细胞癌的影像诊断能力是这些肿瘤中特有的）——[[gastrointestinal/liver-disease]]。可疑骨转移而骨扫描阴性：按症状与部位选（脊柱与承重骨与（在骨髓的病变与多发的骨髓瘤与（在若干溶骨的病变中）骨扫描可假阴性），改用计算机断层或磁共振（磁共振对骨髓的敏感性高，并对脊髓的压迫是首选）与（在怀疑骨髓瘤时的）低剂量的全身计算机断层或全身磁共振的路径），并同时看实验室（钙与碱性的磷酸酶与蛋白的电泳与游离的轻链），因为”影像阴性加生化与症状提示“需要重复而不是安慰——[[musculoskeletal/bones-joints]]、[[blood/lymphoma-myeloma]]。**

::: exercise 解析一份TNM {level=2}
一份结肠的病理报告：”T3、N1b、切缘阴性、取检12枚淋巴结其中2枚转移、有淋血管侵犯、分化差、无沉积、送检的近端切缘距肿瘤6厘米。“请解析并指出需要澄清之处。
::: solution
**解析与追问（[[#def-classify]]、[[pathology/diagnostic-pathology]]、[[gastrointestinal/gi-bleeding-cancer]]）：T3（穿透肌层到浆膜下的结缔组织或在无腹膜覆盖的周围组织中长入）意味着超出肌层但未穿破脏层腹膜（后者是T4a）；N1b（2枚区域淋巴结转移，1至3枚为N1）；两者加M0（此处未提及远处，需明确）构成第三期的可能，具体亚期按T与N的组合；切缘阴性（并要区分环周切缘与最近的切缘与”6厘米“是有用的但不是最关键的那个数字——真正决定复发风险的是最近切缘的距离（以毫米计）与在结肠手术中是否为整块切除）；12枚淋巴结是最低要求（不足会使分期不足并影响是否加化疗的判断，此处达标，但要报告每个淋巴结的大小与（在新辅助治疗后）是否已无残留）；淋血管侵犯与分化差是第三期中”高危“的特征，影响辅助化疗的方案与强度；”无沉积“是有价值的阴性；而报告的缺项也要指出：是否做了错配修复与微卫星的免疫组化（既是林奇的筛查又影响第三期的预后与治疗的选择：错配修复缺陷的II期预后较好且从单氟的化疗获益少），是否明确肠梗阻与穿孔的状态（影响分期与治疗），以及是否明确是右半还是左半（影响预后与治疗），是否检查了原发灶的近远切缘与是否切除并检查了肠系膜根部的完整性与是否（在中低位直肠）做了全肠系膜的切除（此处为结肠故不适用）。分期要写成明确的组别第几期，按哪一版的分期手册与是病理的还是临床的（pT 与 cT 的差别），以及是否达到足够淋巴结取样的标准（不足的取样使分期偏低，这是分期漂移的原因之一）；最后的临床决策（是否辅助化疗与（在若干情形中的）免疫治疗）应结合错配修复的分期与（在高危者）循环的脱氧核糖核酸的残留病灶的监测（其价值正在被前瞻性地检验，且”升高不等于复发“的解释必须与影像结合）——[[public-health/screening]]、[[clinical-skills/records-handover]]。**

::: exercise 处理一个偶发的遗传发现 {level=2}
为转移性前列腺癌做体细胞的测序在血液（未配对的正常样本）中报告了 BRCA2 的生殖系致病变异，患者75岁、有三个成年儿子、从未做过遗传咨询；报告由肿瘤科医师在门诊看到。
::: solution
**偶发发现的正确通路（[[#def-biomarkers]]、[[#def-sampling]]、[[genetics/genetic-testing]]）：先判断这件事的性质：体细胞的 panel 常常无意识地测到了生殖系的变异（在没有配对正常的情况下，血液的 DNA 被一并测序），而报告里的”生殖系“三个字会改变他的治疗（聚腺苷二磷酸核糖聚合酶的抑制剂的适用与铂类的敏感与（在若干情形）内分泌治疗的策略）与他的家族（每个儿子有50%的概率携带，而携带者可能有前列腺与乳腺与胰腺与卵巢的筛查与预防的意义）。正确的做法是不要在门诊里”顺口告知“，也不要因为报告来自体细胞的检测就把它当作不重要：一，确认（在一个有资质的实验室做专门的生殖系的检测，因为这是所有后续决定的前提，且需要知情同意（包括对家族的影响）与（若有需要）遗传的咨询），二，同时不延误治疗（他的治疗可以按”提示同源重组缺陷“的结果先走，确认的结果用于其后的调整），三，安排一次有时间与隐私的谈话（不要在家属在场时突然宣布一个影响三代人的消息；先问她想不想知道与想知道多少，并尊重她拒绝部分信息的权利），四，为家族留出路径如何告知与谁告知由他决定，但要事先约定；并提供书面材料（包括具体给儿子的解释与转介的路径），把”如何告诉家人“变成可以被支持的行动——[[clinical-skills/communication]]、[[medical-ethics-law/confidentiality]]。要避免的错误：把结果当作”研究性“而不告知（这是最常见且最不可辩护的失败）；在没有咨询与确认的情况下让治疗发生大的改变；在没有配对的正常样本的情况下把克隆性造血的变异当作肿瘤的驱动；以及在没有回告机制的情况下把患者的名字留在”若将来重分类则无处联系“的名单上。制度的一层：为体细胞检测制定”哪些生殖系的发现会被回告、由谁告知、如何记录同意“的政策，并与遗传的服务约定接口（谁负责家系的追溯与对亲属的告知路径）；以及在报告中把”本检测非遗传诊断“的字样放在显著位置——否则临床医师会不自觉地把一个筛查性的结果当作确定的结论——[[genetics/genetic-testing]]、[[clinical-skills/patient-safety]]。**

::: exercise 为一个肿瘤网络设计病理服务 {level=3}
你要为一个覆盖五家医院、每年两万例肿瘤切除的网络设计病理服务。给出组织、亚专科、周转、质量、数字化与公平的方案。
::: solution
**网络的病理设计（[[pathology/diagnostic-pathology]]、[[pathology/acute-inflammation]]、[[public-health/health-systems-economics]]）：组织的原则是”集中读片、分散取样“：标本在患者所在处被正确取到（因此取样与固定的培训要在内镜与手术与门诊的单位做，并把固定的合规率作为跨单位的指标），而复杂的判读（分子与少见肿瘤与（在新辅助治疗后的）残留病灶的评估与需要双重阅片的筛查）集中在有亚专科专长的中心；亚专科的覆盖按”病例数乘以判读的困难度“设（乳腺与消化与呼吸与泌尿与妇科与血液与淋巴与软组织的骨与皮肤与（在有儿童肿瘤的网络里）儿童的肿瘤），并规定哪些诊断必须有亚专科的复核（分期的关键项与”不能定类“的与（在罕见部位的）首例——这一条把有限的专家用在刀刃上）。周转要按临床的需求分层：筛查与术前与术中与（新辅助治疗后的）手术后的评估各有不同的时限，且必须承诺”哪一类在多少个工作日“的公开标准（并要求临床在预约上按此安排，因为把”所有报告都紧急“的文化和”等两周“的文化同时存在会摧毁两者）。质量的架构：室间的质量评价与关键差异的分析（临床与病理的对照在本网络内是常设的议程）与双重阅片的规则（在筛查、乳腺癌的切缘与（在若干癌种中）分期的关键项与所有”未见到癌“的手术标本）与参数的监测（固定与切片与染色的合格率与免疫组化的对照与批号的追溯）与分期的完整性（每季度抽查报告是否包含分期所需的全部要素——这是最容易改善也最少被测量的质量指标）。数字化：扫描加网络内的分派（使积压与专长可以跨单位流动），并要求扫描仪与染色的可验证性与原件的保留（在法律上切片仍是那份原始材料）；人工智能的辅助用于筛查的排序与（在若干场景中）受体的量化与分裂的计数，且要求本地验证与性能的监测与（关键的）可解释的输出。公平与可及：远程诊断必须包含”到最偏远的单位也能拿到及时的第二意见“，并把语言的与文化的沟通纳入（一份无法被患者理解的报告是不完整的报告）；同时监测按单位的周转与复检率与分期完整率与（在筛查中）参与率，因为网络化的风险是把资源集中到中心而使边缘的单位更弱——那正是最需要网络的地方——[[clinical-skills/patient-safety]]、[[pathology/diagnostic-pathology]]。**
