炎症是机体对感染和组织损伤的反应。它把血浆蛋白和白细胞从循环中带到需要它们的地方，使它们能够消灭微生物、稀释毒素并清除死亡细胞。没有炎症，伤口永远不会愈合，轻微的感染也会致命。然而炎症也是许多疾病的原因：脓毒症患者、哮喘气道或发炎关节中的损害，很大程度上是由反应本身而非最初的诱因造成的。

本章讲述**急性炎症**，即在数分钟至数小时内发生、持续数天的快速反应。本章按顺序追踪这一反应：是什么启动了它，血管发生了什么，白细胞如何离开血液，哪些化学介质协调它，它在组织中和整个患者身上表现如何，以及它如何结束。较慢、较长的反应是[[pathology/chronic-inflammation-repair]]的主题。

## 炎症的启动

::: definition 炎症及其主要表现 {#def-inflammation}
**炎症**是有血管的组织对感染或损伤的一种保护性反应，其中液体、血浆蛋白和白细胞从血液进入组织。**急性炎症**起病快、持续时间短，有液体和蛋白质渗出，以中性粒细胞为主。

经典的**主要表现**（cardinal signs）是红（*rubor*）、肿（*tumor*）、热（*calor*）、痛（*dolor*），由塞尔苏斯（Celsus）描述，后来又加上了功能障碍（*functio laesa*）。
:::

每一种主要表现都有其机制。红和热来自扩张的小动脉输送了更多的血液。肿来自漏入组织的液体和蛋白质。痛来自缓激肽和前列腺素等介质作用于神经末梢，以及肿胀造成的压力。功能障碍由疼痛和肿胀共同导致。

诱因有以下几类：

- **感染**：细菌、病毒、真菌和寄生虫，以及它们产生的毒素。
- 任何原因引起的**组织坏死**，包括缺血、创伤、烧伤和化学损伤。死亡细胞释放通常隐藏在细胞内的分子，如尿酸、ATP和DNA。
- **异物**：木刺、缝线，以及痛风中的尿酸盐等晶体。
- **免疫反应**，如过敏和自身免疫病，其诱因是无害物质或机体自身的组织。

细胞通过固有免疫系统的受体识别这些诱因。巨噬细胞、树突状细胞和上皮细胞上的**Toll样受体**识别微生物特有的分子，称为病原体相关分子模式。受损细胞释放的分子称为损伤相关分子模式。一种称为**炎症小体**的胞质复合物感知细胞损伤和晶体，激活caspase-1，后者产生白细胞介素-1β的活性形式。这些受体受刺激后，细胞释放细胞因子和其他介质，启动反应。受体生物学见[[immunology/innate-immunity]]。

## 血管反应

最早的改变发生在小血管。其目的是把血液带到受损区域，并让血浆蛋白和白细胞离开血管。

1. **血管扩张。** 小动脉扩张，主要由组胺和一氧化氮介导。血流增加，引起红和热。有时之前会有短暂的收缩。
2. **通透性增加。** 毛细血管后微静脉的内皮变得渗漏，富含蛋白质的液体逸入组织。这是肿胀的主要原因。
3. **血流淤滞。** 随着液体外渗，小血管中的红细胞浓缩，血流减慢。缓慢的血流使白细胞得以移向血管壁。

通透性增加有几种机制。最常见的是微静脉**内皮细胞收缩**，使细胞之间出现裂隙。组胺、缓激肽和白三烯可在数秒内引起这种改变，且持续时间短，为15至30分钟。TNF和IL-1等细胞因子引起细胞连接较慢而较持久的改变。在烧伤和严重感染中，内皮受到**直接损伤**，渗漏可持续数小时乃至数天。黏附于内皮的白细胞本身也能损伤内皮。

液体跨毛细血管壁的移动遵循Starling原理（[[physiology/homeostasis-body-fluids]]）。积聚的液体性质取决于哪一种力发生了改变，这一区别具有重要的诊断价值。

::: definition 渗出液与漏出液 {#def-exudate}
- **渗出液**（exudate）是蛋白质含量高、常含细胞的血管外液体，在血管通透性增加时形成。它提示炎症（或肿瘤，肿瘤也使血管渗漏）。
- **漏出液**（transudate）是蛋白质含量低、细胞很少的血管外液体，由正常血管壁两侧静水压或胶体渗透压失衡所形成，见于心力衰竭或血浆白蛋白降低。
- **水肿**是组织间隙或体腔内液体过多，无论是渗出液还是漏出液。**脓液**是富含中性粒细胞、死亡细胞且常含微生物的化脓性渗出液。
:::

对于胸腔积液，用**Light标准**进行区分。只要满足以下至少一项，积液即为渗出液：胸腔积液蛋白与血清蛋白之比大于0.5；胸腔积液乳酸脱氢酶（LDH）与血清LDH之比大于0.6；或胸腔积液LDH大于血清LDH正常上限的三分之二。

::: example 胸腔积液 {#ex-light}
一名67岁女性有右侧胸腔积液。胸腔积液：蛋白42 g/L，LDH 310 U/L。血清：蛋白68 g/L，LDH 220 U/L。实验室血清LDH正常上限为250 U/L。这是渗出液还是漏出液？意味着什么？
::: solution
1. 蛋白比值 $= 42/68 \approx 0.62$，大于0.5。
2. LDH比值 $= 310/220 \approx 1.41$，大于0.6。
3. 正常上限的三分之二为$\tfrac{2}{3} \times 250 \approx 167$ U/L；积液LDH 310 U/L超过此值。
4. 三项标准全部满足，因此积液为**渗出液**。其原因是血管通透性增加，而非压力失衡。
5. 渗出液最常见的原因是肺炎（肺炎旁积液）和癌。漏出液则提示心力衰竭、肝硬化或低白蛋白血症。随后要对积液做进一步检查，包括微生物学和细胞学检查（[[respiratory/lung-cancer-pleura]]）。
:::
:::

淋巴管也参与其中。淋巴流量增加以引流水肿液，淋巴管把微生物和碎屑运往淋巴结。淋巴管的炎症（**淋巴管炎**）表现为沿肢体分布的红色条纹，区域淋巴结肿大并有压痛（**淋巴结炎**）。若扩散超出淋巴结，可引起菌血症。

## 细胞反应

炎症的主要目的是把白细胞送到损伤部位。急性炎症中的白细胞主要是**中性粒细胞**，它们最先到达，在最初6至24小时内占优势。随后**单核细胞**到达，在组织中成为巨噬细胞；24至48小时后巨噬细胞占优势，因为中性粒细胞寿命短，通过凋亡死亡，而巨噬细胞能存活并增殖。这一模式有变化：病毒感染时淋巴细胞可能最先到达，过敏反应中嗜酸性粒细胞突出。

::: theorem 白细胞黏附级联 {#thm-adhesion}
白细胞经毛细血管后微静脉壁离开循环，按一系列步骤进行，每一步由不同家族的黏附分子介导：

1. **边集**：血流减慢，把白细胞推向血流的边缘。
2. **滚动**：白细胞与活化内皮上表达的**选择素**（E-选择素和P-选择素）发生微弱、短暂的结合。
3. **牢固黏附**：内皮表面的趋化因子激活白细胞的**整合素**（如LFA-1），后者与内皮配体（如ICAM-1）紧密结合。
4. **穿出**（游出）：白细胞在PECAM-1（CD31）的协助下从内皮细胞之间挤出，并穿过基底膜。
5. **趋化**：白细胞沿趋化物质的浓度梯度向损伤部位移动。
:::

::: proof
每一步都依赖于前一步，每一步所用的分子都由炎症刺激开启。组胺和凝血酶在数分钟内把储存在内皮颗粒中的P-选择素转移到细胞表面。巨噬细胞产生的TNF和IL-1在一至两小时内诱导E-选择素、ICAM-1和VCAM-1的表达。选择素键形成和断裂都很快，因此它们使白细胞减速而不使之停止：白细胞沿血管壁滚动。滚动时，白细胞遇到结合在内皮表面的趋化因子。趋化因子使白细胞的整合素构象转变为高亲和力形式，滚动的细胞随之停下。然后它爬行到内皮细胞之间的连接处并穿过去。由于损伤组织的信号同样开启了黏附分子，白细胞只在需要它们的地方离开血液。

趋化物质包括细菌产物（以N-甲酰甲硫氨酸开头的肽）、补体片段C5a、白三烯B4，以及CXCL8（白细胞介素-8）等趋化因子。白细胞感知其自身长度范围内的浓度差，通过聚合肌动蛋白伸出前缘，向浓度较高的方向移动。
:::

### 吞噬与杀伤

在损伤部位，中性粒细胞和巨噬细胞吞噬并消灭微生物和死亡组织。**吞噬作用**分三步进行。

1. **识别和附着。** 吞噬细胞通过甘露糖受体等受体直接识别微生物，而当微生物被**调理素**（IgG类抗体和补体片段C3b）包被时，识别效率要高得多。
2. **吞入。** 细胞伸出伪足包围颗粒，将其封入吞噬体，吞噬体再与溶酶体融合形成吞噬溶酶体。
3. **杀伤和降解。** **NADPH氧化酶**（吞噬细胞氧化酶）在吞噬体膜上组装，将氧转化为超氧阴离子：这就是**呼吸爆发**。超氧阴离子转变为过氧化氢，中性粒细胞颗粒中的**髓过氧化物酶**将过氧化氢和氯离子转化为次氯酸，一种强氧化剂。溶酶体酶、防御素和其他颗粒蛋白进一步参与杀伤。

中性粒细胞还能释放**中性粒细胞胞外诱捕网**：由DNA和颗粒蛋白组成的网，在细胞外捕获并杀死微生物。

杀灭微生物的武器也会损伤宿主。酶和氧化剂从活化的中性粒细胞中漏出，尤其是当中性粒细胞遇到太大而无法吞入的目标，或试图吞噬附着在组织上的物质时。这种**白细胞介导的损伤**是许多疾病中损害的主要机制，包括急性呼吸窘迫综合征、肾小球肾炎、痛风以及哮喘时的气道。

### 白细胞功能缺陷

每一步的缺陷都显示了这一步的正常作用。有这些缺陷的人反复发生细菌和真菌感染。

- **白细胞黏附缺陷1型**由β2整合素（CD18）突变引起。中性粒细胞不能黏附并离开血液，因此血中性粒细胞计数高，而感染部位几乎没有脓。
- **慢性肉芽肿病**由NADPH氧化酶某一组分的突变引起，最常见的是X连锁型。吞噬细胞能吞入微生物，但不能杀死过氧化氢酶阳性菌，如金黄色葡萄球菌和曲霉。持续存在的微生物激发肉芽肿。
- 获得性缺陷要常见得多：化疗后的中性粒细胞减少、控制不佳的糖尿病（趋化和杀伤受损），以及糖皮质激素治疗。遗传性疾病详见[[immunology/immunodeficiency]]。

::: example 反复脓肿的男孩 {#ex-cgd}
一名6岁男孩曾患金黄色葡萄球菌引起的肝脓肿，以及曲霉引起的肺部感染。他的血中性粒细胞计数正常。淋巴结活检见肉芽肿。呼吸爆发试验（二氢罗丹明流式细胞术）显示其中性粒细胞无氧化活性。解释这些发现。
::: solution
1. 数量正常的中性粒细胞到达了感染部位，因此黏附和趋化功能正常。
2. 氧化试验失败表明NADPH氧化酶不起作用。这就是**慢性肉芽肿病**。
3. 没有超氧阴离子及其产物，中性粒细胞无法杀死过氧化氢酶阳性菌。（过氧化氢酶阴性的细菌会自己产生过氧化氢，中性粒细胞的髓过氧化物酶可以利用它。）金黄色葡萄球菌和曲霉是典型病原体。
4. 在吞噬细胞内持续存在的微生物成为慢性刺激，巨噬细胞和淋巴细胞聚集在其周围形成**肉芽肿**。
5. 最常见的类型是X连锁型，符合男孩的情况。在专科医疗下，处理包括长期抗微生物预防，造血干细胞移植可以治愈。
:::
:::

## 化学介质

血管反应和细胞反应由化学**介质**协调。有些储存在细胞中，在数秒内释放；有些按需合成。有些以无活性的前体形式在血浆中循环，经蛋白水解而激活。

::: definition 炎症介质 {#def-mediators}
**炎症介质**是在损伤部位由细胞释放或由血浆蛋白产生、引起一种或多种炎症事件的物质。主要介质及其主要作用如下：

| 介质 | 主要来源 | 主要作用 |
|---|---|---|
| 组胺 | 肥大细胞、嗜碱性粒细胞 | 小动脉扩张，微静脉通透性增加 |
| 前列腺素（PGE₂、PGI₂） | 多种细胞，经环氧合酶 | 血管扩张、疼痛、发热 |
| 白三烯B₄ | 白细胞，经5-脂氧合酶 | 中性粒细胞趋化 |
| 白三烯C₄、D₄、E₄ | 肥大细胞、白细胞 | 通透性增加，支气管收缩 |
| TNF和IL-1 | 巨噬细胞、肥大细胞、内皮 | 内皮活化、发热、急性期反应 |
| 趋化因子（如CXCL8） | 巨噬细胞、内皮 | 白细胞募集和活化 |
| 补体C3a、C5a | 血浆 | 肥大细胞脱颗粒（过敏毒素）；C5a有趋化作用 |
| 补体C3b | 血浆 | 调理作用 |
| 缓激肽 | 血浆（激肽系统） | 通透性增加、疼痛 |
| 一氧化氮 | 内皮、巨噬细胞 | 血管扩张、杀伤微生物 |
:::

这些介质大多寿命很短。它们在数分钟内被降解，或者只在刺激持续存在时才产生。这解释了炎症的一个重要特性：病因去除后，炎症就会消退。

许多药物作用于这些通路，它们表明了哪些介质在临床上起作用（[[pharmacology/drug-receptor]]）：

- **非甾体抗炎药**（NSAIDs）抑制环氧合酶（COX-1和COX-2），从而减少前列腺素。它们缓解疼痛和发热，但不阻止白细胞募集。阿司匹林不可逆地抑制环氧合酶；它对血小板血栓素的作用是其用于心血管疾病的基础。
- **糖皮质激素**作用广泛。它们减少多种细胞因子、黏附分子以及产生前列腺素和白三烯的酶的转录。
- **抗组胺药**阻断H1受体，对以组胺为主的荨麻疹和花粉症有效，但对白三烯更为重要的哮喘无效。**白三烯受体拮抗剂**用于哮喘。
- 针对TNF或IL-6受体的**生物制剂**用于类风湿关节炎等慢性炎症性疾病。

::: example 服用新药后嘴唇肿胀 {#ex-angioedema}
一名58岁黑人男性三周前开始服用血管紧张素转换酶（ACE）抑制剂治疗高血压。他出现嘴唇和舌肿胀，无荨麻疹或瘙痒。抗组胺药无效。解释其机制。
::: solution
1. 面部深层组织肿胀而无荨麻疹，即**血管性水肿**。
2. ACE（激肽酶II）正常情况下降解**缓激肽**。ACE被抑制后，缓激肽蓄积。
3. 缓激肽增加微静脉通透性，于是液体漏入嘴唇、舌和气道的疏松组织。
4. 介质不是组胺，所以没有风团，抗组胺药也无效。
5. ACE抑制剂相关的血管性水肿在非洲裔或非洲-加勒比裔人群中更常见。它可能危及气道，因此属于急症；应停用该药且不再使用。处理遵循现行指南（[[emergency-critical-care/anaphylaxis]]）。
:::
:::

## 形态学类型

急性炎症的表现取决于产生多少液体、蛋白质和脓液，以及在何处产生。

- **浆液性炎**：水样、细胞少的渗出液。例如烫伤后皮肤水疱中的液体，以及体腔的病毒性积液。
- **纤维素性炎**：通透性更高，纤维蛋白原得以逸出并形成纤维蛋白。在心包等浆膜表面，纤维蛋白形成粗糙的绒毛状层，引起摩擦音。纤维蛋白可被巨噬细胞清除，也可机化成瘢痕，造成粘连。
- **化脓性炎**：产生大量脓液，是葡萄球菌等化脓菌的典型表现。**脓肿**是组织内局限性的脓液积聚，中心是液化的组织，周围是一圈中性粒细胞，之后形成肉芽组织和纤维化的壁。
- **溃疡**：炎症组织坏死脱落造成的上皮表面局部缺损，如胃消化性溃疡。

::: example 手掌内的积脓 {#ex-abscess}
一名34岁女性五天前在园艺劳动时割伤了手掌。该处发热、发红、肿胀，中心有压痛并有波动感。体温38.4 °C。她已口服抗生素两天，没有好转。解释抗生素为何无效，以及需要怎么做。
::: solution
1. 穿刺伤后出现有压痛的波动性肿胀，提示**脓肿**：化脓性炎形成的局限性脓液积聚，最常由金黄色葡萄球菌或链球菌引起。
2. 脓肿中心是没有血供的液化坏死组织。抗生素很难到达那里，而且酸性、富含蛋白质的脓液会降低某些药物的活性。
3. 脓腔内的中性粒细胞已经死亡或濒临死亡，无法清除细菌。
4. 需要引流：必须手术排出脓液，使脓腔通过肉芽组织愈合。抗生素只是辅助，按当地指南和培养结果选用。手部感染可沿腱鞘扩散，因此需要及时的外科评估（[[surgery/wounds-surgical-infection]]）。
:::
:::

## 全身反应

炎症在全身产生影响，统称为**急性期反应**。它们主要由细胞因子TNF、IL-1和IL-6驱动。

- **发热。** 细胞因子作用于下丘脑，在那里诱导环氧合酶-2并产生前列腺素E₂。PGE₂上调体温调定点。这就是NSAIDs能退热的原因。
- **急性期蛋白。** IL-6刺激肝脏合成更多的**C反应蛋白**（CRP）、纤维蛋白原和血清淀粉样蛋白A，合成较少的白蛋白。CRP结合于微生物表面，起调理素作用。纤维蛋白原使红细胞叠连（缗钱状排列），沉降加快，所以**红细胞沉降率**（ESR）升高。肝脏还产生更多的**铁调素**，阻止铁从储存中释放；这导致慢性炎症性贫血。
- **白细胞增多。** 细胞因子使骨髓释放细胞，白细胞计数因而升高。细菌感染通常引起**中性粒细胞增多**，常伴未成熟细胞（“核左移”）。病毒感染引起淋巴细胞增多，寄生虫感染和过敏引起嗜酸性粒细胞增多。某些感染，如伤寒和一些病毒感染，会使计数降低。
- **其他影响**：心率增快和血压改变、寒战、食欲减退、嗜睡和全身不适。

严重感染时，大量细胞因子和其他介质进入循环。可随之出现广泛的血管扩张、血管渗漏、心肌抑制和弥散性凝血。**脓毒症**的定义（Sepsis-3，2016年）为宿主对感染的反应失调所致的危及生命的器官功能障碍。其识别和处理见[[infectious-diseases/fever-sepsis]]和[[emergency-critical-care/shock-fluids]]。

CRP在刺激后约六小时内升高，约两天达高峰。其血浆半衰期约19小时且基本恒定，因此CRP下降的速度几乎完全取决于肝脏是否仍在被指令合成它。因此CRP下降是炎症刺激正在得到控制的良好迹象。

::: example CRP应该下降多快？ {#ex-crp}
一名45岁男性患肺炎，入院时CRP为200 mg/L。假设抗生素使刺激立即停止，CRP以19小时的半衰期下降。48小时后CRP是多少？降到10 mg/L需要多长时间？
::: solution
1. 经过时间$t$后：$\text{CRP}(t) = 200 \times 2^{-t/19}$。
2. 48小时时：$200 \times 2^{-48/19} = 200 \times 0.174 \approx 35$ mg/L。
3. 降到10 mg/L：$2^{-t/19} = 10/200 = 0.05$，所以$t = 19 \log_2 20 \approx 82$小时，约三天半。
4. 真实患者的下降更慢，因为合成是逐渐减少而不是立即停止的。尽管如此，治疗两三天后CRP完全没有下降，提示存在持续的病灶，如脓胸或耐药菌，应重新评估。
:::
:::

::: warning 早期CRP正常与激素治疗下的高计数
有两个常见错误。第一，CRP需要数小时才会升高，所以病程最初几小时内CRP正常并不能排除严重感染；临床表现是第一位的。CRP也是非特异性的：它在创伤、手术后、梗死和炎症性疾病中都会升高，不仅限于感染。第二，糖皮质激素在没有感染时也会使中性粒细胞计数升高，因为它们使原本黏附在血管壁上的中性粒细胞释放出来（脱边集），并减慢其进入组织。服用激素者计数升高需要解读，而不是自动使用抗生素。
:::

## 结局与消退

急性炎症可以有四种结局。

1. **完全消退。** 当损伤有限且组织能够再生时，介质被降解，液体经淋巴管引流，中性粒细胞通过凋亡死亡并被巨噬细胞吞噬，组织恢复正常。既往健康成人的大叶性肺炎通常以这种方式消退。
2. **瘢痕愈合**（纤维化）。当组织不能再生，或破坏严重、纤维蛋白很多时，该区域被结缔组织取代。
3. 在化脓菌感染时**形成脓肿**。
4. 当刺激持续存在或反应无法清除它时，**进展为慢性炎症**。

::: theorem 消退是一个主动过程 {#thm-resolution}
急性炎症并不是简单地自行耗尽。它的结束是由启动它的同一反应主动开启的：介质寿命短，需要持续的刺激；花生四烯酸通路从产生白三烯转向产生**脂氧素**和**消退素**等促消退介质；吞噬了凋亡中性粒细胞的巨噬细胞释放抗炎细胞因子（IL-10和TGF-β）；中性粒细胞经历凋亡而不是坏死。
:::

这一原理有实际意义。持续的炎症并不总是由持续的刺激引起；它也可能反映向消退转换的失败。关于促消退介质的研究旨在促进消退，而不是阻断炎症。

::: quiz
中性粒细胞与活化内皮之间最初的、短暂的“滚动”接触由哪一对分子介导？
- [x] 内皮上的选择素与白细胞上的糖类配体结合
- [ ] 白细胞上的整合素与内皮上的ICAM-1结合
- [ ] 两种细胞上的PECAM-1
- [ ] C5a与白细胞上的受体结合
::: solution
滚动依赖于选择素（内皮上的E-选择素和P-选择素），其键形成和断裂都很快。整合素与ICAM-1结合产生牢固黏附，PECAM-1协助穿出，C5a是趋化物质。
:::
:::

::: history
古罗马作家塞尔苏斯（Aulus Cornelius Celsus）在公元1世纪将红、肿、热、痛列为炎症的表现。1867年，科恩海姆（Julius Cohnheim）在显微镜下观察活青蛙的肠系膜，看到白细胞黏附在小静脉壁上并穿过管壁，证明脓细胞来自血液。1882年，梅奇尼科夫（Élie Metchnikoff）看到透明海星幼虫体内的游走细胞聚集在他插入的一根刺周围，提出炎症的目的是把吞噬细胞带到损伤部位；他与埃尔利希（Paul Ehrlich）分享了1908年诺贝尔生理学或医学奖。1927年，刘易斯（Thomas Lewis）描述了皮肤受到用力划压后的“三联反应”（红线、潮红和风团），并将其归因于组织中释放的一种组胺样物质。
:::

## 后续内容

当刺激持续存在时，细胞群从中性粒细胞转变为巨噬细胞和淋巴细胞，纤维化修复在持续损伤的同时开始：这就是慢性炎症，见[[pathology/chronic-inflammation-repair]]。维持慢性炎症的免疫机制在[[immunology/adaptive-responses]]中展开，严重感染的临床处理见[[infectious-diseases/fever-sepsis]]。

::: summary
- 急性炎症是一种快速、短暂的反应，把液体、蛋白质和中性粒细胞带到感染或损伤部位。其主要表现是红、热、肿、痛和功能障碍。
- 诱因由Toll样受体和炎症小体等固有免疫受体识别。
- 血管反应：血管扩张、微静脉通透性增加和血流淤滞。渗出液（高蛋白）提示通透性增加；漏出液（低蛋白）提示压力失衡。Light标准用于区分胸腔积液的性质。
- 白细胞通过边集、选择素介导的滚动、整合素介导的黏附、穿出和趋化离开血液，然后通过吞噬和呼吸爆发杀死微生物。
- 介质包括组胺、前列腺素、白三烯、细胞因子（TNF、IL-1、IL-6）、补体、激肽和一氧化氮。大多数寿命很短，许多是药物靶点。
- 类型：浆液性、纤维素性、化脓性（脓肿）和溃疡。脓肿需要引流。
- 全身反应：经PGE₂引起的发热、急性期蛋白（CRP、纤维蛋白原、铁调素）、ESR升高和白细胞增多。
- 结局：消退（一个主动过程）、瘢痕、脓肿或慢性炎症。
:::

## 习题

::: exercise 解释主要表现 {level=1}
对急性炎症的每一种主要表现，说明其基本机制和一种相关介质。
::: solution
红和热：小动脉扩张，由组胺、一氧化氮和前列腺素介导。肿：微静脉通透性增加，富含蛋白质的液体外漏，由组胺、缓激肽和白三烯C₄、D₄、E₄介导。痛：缓激肽和前列腺素E₂使神经末梢致敏并受刺激，以及肿胀造成的压力。功能障碍：疼痛和肿胀的共同作用。
:::
:::

::: exercise 中性粒细胞绝对计数 {level=1 check="9.6"}
全血细胞计数显示白细胞$12.0 \times 10^9$/L，中性粒细胞占80%。中性粒细胞绝对计数是多少$10^9$/L？给出精确值。
::: solution
$12.0 \times 0.80 = 9.6 \times 10^9$/L，属于中性粒细胞增多（通常上限约为$7.5 \times 10^9$/L，因实验室而异）。
:::
:::

::: exercise 说出类型 {level=1}
说出炎症的形态学类型：(a) 烫伤后的水疱；(b) 心肌梗死后伴摩擦音的心包；(c) 颈部的疖；(d) 胃黏膜的缺损。
::: solution
(a) 浆液性炎。(b) 纤维素性炎。(c) 化脓性炎，形成脓肿。(d) 溃疡。
:::
:::

::: exercise Light标准 {level=2 check="round(25/70*100)/100"}
某胸腔积液蛋白25 g/L，LDH 90 U/L；血清蛋白70 g/L，LDH 200 U/L，LDH正常上限为250 U/L。计算蛋白比值（保留两位小数），并判断积液是渗出液还是漏出液。
::: hint
检验Light标准的全部三项。
:::
::: solution
蛋白比值 $= 25/70 = 0.357\ldots$，四舍五入为0.36（不大于0.5）。LDH比值 $= 90/200 = 0.45$（不大于0.6）。250的三分之二约为167，90低于此值。没有一项标准满足，因此积液为**漏出液**，提示心力衰竭、肝硬化或低白蛋白血症，而非炎症。
:::
:::

::: exercise CRP半衰期 {level=2 check="round(19*log2(160/10))"}
脓肿引流后，患者CRP为160 mg/L。假设合成立即停止，半衰期为19小时，CRP降到10 mg/L需要多少小时？四舍五入到整数小时。
::: solution
从160降到10是下降16倍，即$\log_2 16 = 4$个半衰期。$4 \times 19 = 76$小时。
:::
:::

::: exercise 没有脓的孩子 {level=2}
一名9个月大的男孩脐带脱落延迟，现在反复发生不形成脓液的皮肤感染。他的中性粒细胞计数持续很高。最可能是哪种缺陷？为什么血中计数高而组织中中性粒细胞很少？
::: solution
**白细胞黏附缺陷1型**，由β2整合素CD18缺陷引起。中性粒细胞不能牢固黏附于内皮，也不能游出血管，因此留在血液中（计数高），无法到达组织，组织中脓液就很少。脐带脱落延迟是典型的早期表现，因为脐带脱落需要中性粒细胞参与。
:::
:::

::: exercise 肿胀的关节 {level=3}
一名62岁男性醒来时第一跖趾关节红、热、肿。体温37.9 °C，白细胞$13 \times 10^9$/L，CRP 85 mg/L。关节液中有大量中性粒细胞和负性双折光的针状晶体。解释晶体如何引起急性炎症，以及为什么全身指标不能把它与化脓性关节炎区分开。
::: hint
想想炎症小体。
:::
::: solution
晶体是单钠尿酸盐，因此诊断为痛风。尿酸盐晶体被关节内的巨噬细胞吞噬，激活**NLRP3炎症小体**，后者激活caspase-1并释放IL-1β。IL-1β活化内皮、募集中性粒细胞并引起局部表现。吞入晶体的中性粒细胞释放酶和氧化剂，加重损伤。全身表现，即体温升高、中性粒细胞增多和CRP升高，无论诱因为何都由IL-1、TNF和IL-6驱动，所以在痛风和化脓性关节炎中是一样的。这就是为什么必须进行关节穿刺，做显微镜检查、晶体检查和培养：两者甚至可以同时存在。这一机制也是IL-1阻断剂用于某些对标准治疗无效的痛风的原因。
:::
:::

::: exercise 为什么发热？ {level=3}
一名学生认为发热只是感染的有害副产物，应当一律治疗。利用发热的机制和相关介质的作用，给出一个平衡的回答。
::: solution
发热是有意产生的：IL-1、TNF和IL-6在下丘脑诱导COX-2，PGE₂上调体温调定点，于是机体保存并产生热量，直到达到新的调定点。体温升高会减慢某些微生物的生长，并增强某些免疫功能，提示它有保护作用。另一方面，发热提高代谢率和耗氧量，可能损害心肺疾病患者，引起不适，在幼儿中可诱发热性惊厥。用对乙酰氨基酚或NSAID治疗发热可降低调定点、改善舒适度，但不治疗病因。平衡的观点是：发热是一种受调控的反应，而不是功能失常；按指南为舒适和特定高危人群而治疗它，并始终寻找其病因。
:::
