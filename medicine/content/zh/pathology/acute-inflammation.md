急性炎症是身体最快的协调反应：**少数几种化学介质把一个看不见的有害触发转化为一场有真实解剖学后果的血管与细胞反应——红、肿、热、痛与功能丧失——由中性粒细胞在数分钟内执行，并在没有造成更大伤害的前提下被主动地终止（消退不是被动的消退，而是一套被编程的程序）。**本章覆盖血管的时相（血流与通透性与介质与它们的时序）、细胞的时相（中性粒的募集次序与黏附的级联与吞噬与杀菌与中性粒的胞外陷阱）、全身的反应（发热的细胞因子与白细胞增多与急相的反应物与炎症的非特异全身表现）、结局（完全消退与化脓与慢性与纤维化），以及临床的四种情形（看似蜂窝织炎而非蜂窝织炎、痛风、脓性的手指、以及类固醇被用于哮喘）。

## 血管的时相

::: definition 血流、通透性与介质 {#def-vascular}
**损伤一旦被感知，两条通路同时启动。血管的运动：局部的毛细血管前的括约肌松弛使毛细血管网开放（发红与热，即动脉性的充血），随后静脉的扩张与通透性的增加使富蛋白的液体进入间质（肿胀与疼痛与功能丧失）；通透性增加的次序有解剖与时间的规律——细静脉的内皮收缩（组胺与缓激肽与白三烯与血小板活化因子作用的速发、短暂的窗口，主要在小静脉）、随后是细胞骨架的重新塑形与内皮的损伤（后者在严重的烧伤与化学损伤中持久且广泛）、以及新生血管的持续渗漏（血管内皮生长因子与不完整的基底膜，这是肿瘤与肉芽组织渗漏的基础）。介质的网络按时间分工：储存在颗粒里的组胺与5-羟色胺在数分钟内达峰（肥大细胞与血小板，经由补体的过敏毒素与神经反射与物理损伤释放）；新合成的类花生酸（环合酶产物前列腺素与前列环素与血栓素与脂合酶产物白三烯与脂氧素）在数十分钟至数小时维持血管的扩张与疼痛与趋化（前列腺素不引起通透性增加本身却放大它对其他介质的效应，这解释了非甾体抗炎药为什么减轻疼痛与肿胀却不阻断炎症的其他表现）；而细胞因子（肿瘤坏死因子与白细胞介素1与白细胞介素17与干扰素通路的产物）在数小时内开始改变基因表达，诱导黏附分子与化学因子与肝脏的急相蛋白（C反应蛋白与血清淀粉样A与纤维蛋白原与铁调素），并制造发热（前列腺素E2在下丘脑的作用）与白细胞增多（骨髓的储备释放与粒细胞刺激因子的驱动）——[[immunology/innate-immunity]]、[[pharmacology/drug-receptor]]、[[clinical-skills/laboratory-tests]]。液体进入间质不只是肿胀：纤维蛋白原变成纤维蛋白的网络局限微生物并为随后的成纤维细胞提供支架，而水肿分离组织与升高间质的压力（在封闭的筋膜室内即成为临床急症），并且稀释毒素；渗出液对淋巴的引流把抗原与抗原呈递细胞带到引流淋巴结，这是先天与适应性免疫之间最重要的接头——[[pathology/chronic-inflammation-repair]]、[[immunology/adaptive-responses]]。**
:::

## 细胞的时相

::: definition 中性粒按次序到达 {#def-cells}
**中性粒细胞是急性炎症的执行细胞，其募集是一场按顺序的分子交通管理：选择素介导的滚动（P-选择素从威贝尔-帕拉德小体与颗粒中迅速被动员到内皮表面，E-选择素由细胞因子诱导，其配体是唾液酸化与岩藻糖基化的糖基如适配蛋白-1）；随后由趋化因子在内皮表面呈现所激活的整合素（β2 的家族：LFA-1 与 Mac-1 与 gp150,95）牢固地黏附（这是白细胞黏附缺陷I型的原因：缺失整合素的共同β链，患儿表现为脐带脱落延迟与反复的无脓的感染）；接着变形穿过内皮（白细胞介导的游走，沿补体C5a与白三烯B4与细菌的甲酰肽与化学因子的梯度）；最后在局部被调理（抗体与补体C3b与它们的组合是最有效的）并经吞噬受体的“拉链式”包裹内吞 进入吞噬体。杀菌是氧化与不氧化的两把刀：烟酰胺腺嘌呤二核苷酸磷酸氧化酶的组装产生呼吸爆发（超氧化物与随后经髓过氧化物酶产生的次氯酸盐；慢性肉芽肿病是这一复合体的遗传缺陷，表现为过氧化氢酶阳性菌与真菌的反复的、包裹性而非消解的感染，其诊断靠二氢罗丹明的流式或硝基蓝四氮唑试验——[[immunology/immunodeficiency]]），以及颗粒的内容（防御素与溶菌酶与乳铁蛋白剥夺铁与酸性水解酶与一氧化氮通路与中性粒的胞外陷阱：被释放的染色质被修饰并被颗粒蛋白包被，用于捕捉胞外的微生物但也构成自身抗原与血栓的支架——[[immunology/autoimmunity]]）。时间的规律有临床价值：六至二十四小时以中性粒为主，两日后单核与巨噬细胞接管并清除凋亡的中性粒（这一“胞葬作用”的转换由脂氧素与消退素与保护素与巨噬细胞的表型改变驱动，若失败则进入慢性的炎症），而脓是死亡的中性粒与液化坏死与纤维蛋白的混合物——其存在意味着需要引流而不是抗生素单独治疗——[[pathology/chronic-inflammation-repair]]、[[surgery/wounds-surgical-infection]]。**
:::

## 全身也参与反应

::: definition 全身效应与结局 {#def-systemic}
**当局部反应溢出或细胞因子进入循环，就出现全身的反应：发热的机制与临床的双面性（前列腺素介导的调定点上移增加了肝的产热与肌肉的战栗并减少了散热，而发热本身改善淋巴与中性粒的功能并限制铁的可用性与某些病原的复制，却也增加心肌与呼吸的负担与谵妄的风险，故“退热”在多数成人是舒适而非病程的改变——而对有心脏病与癫痫与高热者则有明确的理由）；白细胞计数的两个方向的解释力（中性粒的增多与左移与中毒的颗粒与杜德勒小体提示细菌感染与类固醇与β激动剂与吸烟与应激与坏死的边缘，而白细胞的减少伴杆状核增多在脓毒症中是危险的信号，且新生儿与老年人与免疫抑制者可能不升高）；以及急相的反应物：C反应蛋白与血清淀粉样A与纤维蛋白原与铁调素（慢性病的贫血的机制）与白蛋白与转铁蛋白的下降（阴性急相物使营养与水肿的评估复杂化）。急性时相反应的时程决定了它如何被使用：C反应蛋白在损伤后六至八小时开始升、并在四十八小时左右达峰（故“发病三小时且C反应蛋白正常”既不能排除感染也不能延迟复查与再评估），而降钙素原在细菌性脓毒症中由多种组织产生、在病毒性干扰素的背景下被抑制，因此它在下呼吸道感染的抗生素决策中比C反应蛋白更有用——尽管它不是“要不要用抗生素”的开关，而是结合临床的证据之一——[[clinical-skills/laboratory-tests]]、[[infectious-diseases/fever-sepsis]]。结局有五种：完全消退（病原被清除与介质被灭活与凋亡的中性粒被胞葬清除与组织的结构复原，肝与肾小管的上皮最能再生）、清除不彻底而进入慢性（巨噬细胞与淋巴与浆细胞与纤维化）、化脓与脓肿形成（局部的液化与需要引流与破溃后的窦道）、以及纤维性修复与机化（在胸膜与心包与肺的渗出被纤维组织取代而遗留功能限制）；还有第四种被低估的结局：炎症未消退而成为慢性的“低度”活动（肥胖的脂肪组织的炎症与动脉粥样硬化与代谢综合征与慢性阻塞性肺病与衰老相关的慢性炎症），把急性炎症的分子与慢病流行病连成一条线——[[endocrine/diabetes]]、[[cardiovascular/vascular-disease]]、[[geriatrics-palliative/ageing-frailty]]。**
:::

::: example 不是蜂窝织炎的蜂窝织炎 {#ex-pseudo-cellulitis}
一名78岁女性因“双小腿红肿热痛伴发热”被收入院并给了静脉抗生素；她有心衰与慢性静脉高压；白细胞与C反应蛋白轻度升高；入院三天后仍“没好转”。
::: solution
**类蜂窝织炎的鉴别（[[#def-vascular]]、[[#def-systemic]]、[[musculoskeletal/skin]]）：最重要的线索是“双侧”：真正的蜂窝织炎几乎总是单侧，而双小腿的红肿热痛在老年人中最常见的解释是郁积性皮炎与慢性静脉高压的急性加重（含铁血黄素与湿疹与硬结与疼痛的灼热而非边界清楚的红斑）加上依赖性的水肿；其他常被误诊者包括：接触性皮炎（新的外用与弹力绷带的染料与绷带上的粘贴剂）、痛风与假性痛风、深静脉血栓（双侧则考虑近端阻塞与全身原因）、脂膜炎与结节性红斑、类风湿的中性与自身炎症的皮肤表现、淋巴瘤与卡波西、淋巴水肿后的改变、以及甲状腺功能低下黏液性水肿——[[nervous-system/motor-systems]]。检查能做什么与不能做什么：白细胞与C反应蛋白在非感染的炎症中同样升高（因此它们不能把“红”变成“感染”），超声对深静脉血栓与对“皮下鹅卵石样改变”的敏感性有限且不特异（蜂窝织炎在超声下也有其特征，但它无法把郁积性皮炎排除），而血培养在蜂窝织炎中的阳性率极低（不推荐常规）——[[clinical-skills/laboratory-tests]]、[[clinical-skills/physical-examination]]。支持诊断的四个特征：单侧、边界与进展、发热与寒战的全身起病、以及门户（足癣的裂口与伤口与溃疡与趾间与外伤与水疱与昆虫叮咬）；治疗上真正的蜂窝织炎需要覆盖β溶血性链球菌与金黄的抗生素并处理足癣与水肿与抬高患肢与预防复发（反复发作与淋巴损害会形成恶性循环）；而被误诊者的“治疗失败”其实是治疗错误：需要的是抬高与压缩与外用激素与利尿与心衰的管理，而不是升级抗生素——[[pharmacology/adverse-reactions]]、[[microbiology/antimicrobials]]。这一例的教训是程序性的：入院时要说明“什么支持感染”与“若不改善我们要重新考虑什么”，并把复评的时间写在医嘱里；同时把误诊作为一个可学习的类错误上报（类蜂窝织炎是最常见的过度使用抗生素的原因之一，也是抗菌药物管理最有回报的靶点——被误诊者平均多住院两天以上并承担难辨梭菌与跌倒与压床的风险）——[[clinical-skills/clinical-reasoning]]、[[infectious-diseases/stewardship-outbreaks]]。**
:::

::: example 痛风的那只踝 {#ex-gout}
一名58岁男性在夜间被第一跖趾关节的剧痛痛醒，关节红肿到不能碰床单；他有高血压用氢氯噻嗪、慢性肾病三期、并饮啤酒每日；这次是他“第一次”，之前被当作感染开了抗生素无效。
::: solution
**晶体的炎症是急性炎症的教科书（[[#def-vascular]]、[[#def-cells]]、[[musculoskeletal/osteoarthritis]]）：机制的要点：单钠的尿酸盐的针状晶体在关节内被巨噬细胞与滑膜细胞识别，通过NLRP3 的炎症小体激活半胱天冬酶-1并产生白细胞介素1β，同时晶体在补体与游离膜的结合下驱动中性粒的募集——这是一条“先天免疫的受体被内部分子危险激活”的通路，解释了为何发作如此剧烈而无微生物参与（也因此抗生素必然“无效”，这一病史线索本身就是诊断信息）。诊断的确认：关节的穿刺在偏振光下见负性双折射的针状晶体（并送培养以排除化脓性关节炎——两者可并存，故凡“红、热、痛、不能动、伴发热”的单关节都必须先排除感染）；尿酸的值在急性期可以正常甚至偏低（不要在发作期用一个正常的尿酸来排除诊断，也不要在急性期凭一个升高的尿酸就确诊）；超声的双轨征与双能计算机断层在疑难时可用——[[clinical-skills/medical-imaging]]、[[clinical-skills/physical-examination]]。治疗按共病选：非甾体抗炎药（在慢性肾病三期与老年人的肾与胃肠与心血管风险，故需最低有效剂量与最短疗程并考虑质子泵的保护）、或关节内或口服的糖皮质激素（对少关节的发作尤其合适，且需注意类固醇后的血糖与白细胞的升高与随后的血尿酸波动）、或秋水仙碱（低剂量方案，注意肾功能与与大环内酯类与他汀与非二氢吡啶类钙拮抗剂的相互作用导致的中毒——腹泻与肌病与骨髓抑制）；难治者可用白介素1的拮抗剂（在诊断明确且常规治疗禁忌时）——[[pharmacology/metabolism-excretion]]、[[renal/chronic-kidney-disease]]。长期的一层：发作后启动降尿酸（别嘌醇在肾功能不全时按肾功能起始并缓慢加量至目标尿酸，注意重症药物反应综合征的遗传易感与在东亚与某些族群中的人类白细胞抗原等位基因的筛查；非布司他的心血管信号需要按个体权衡；苯溴马隆类促排药在肾结石与尿量少者禁忌），并在起始降尿酸的头数月用低剂量的抗炎预防（因尿酸的快速波动本身会触发发作，这是最常见的“药反而让病情加重”的误解来源）；同时处理诱因（噻嗪可换为氯沙坦或钙拮抗剂、酒精尤其是啤酒与烈酒、高果糖的饮料、以及急性病与手术与脱水与禁食），并解释“这是可以被控制的晶体病，不是终身发作的宿命”——[[cardiovascular/hypertension]]、[[pharmacology/patient-variation]]。**

::: example 发展为脓的手 {#ex-abscess}
一名34岁男性在四天前被猫咬伤的手背如今红肿、波动感明显、手指呈半屈位并在被动伸展时剧痛，发热38.6度；他给了破伤风的处置但口服抗生素未见效。
::: solution
**化脓性感染的处理次序（[[#def-cells]]、[[#def-systemic]]、[[surgery/wounds-surgical-infection]]）：两个诊断必须同时被识别：一是脓（波动感意味着需要切开引流——抗生素对包裹的脓腔穿透有限，“引流的脓”这一临床格言在此是解剖学的必然；脓液送革兰染色与培养以指导后续）；二是屈肌腱鞘的化脓感染（手指半屈与被动伸展剧痛与沿腱鞘的肿胀压痛与张力增高，是Kanavel 的四个体征，属于外科急症，因为它在数小时内破坏腱的滑膜与血供）。处理：立即请手外科会诊并准备手术的清创与腱鞘的冲洗（并评估是否需要反复的灌洗）；同时给覆盖猫的口腔菌群（多杀巴斯德菌与链球菌与葡萄球菌与厌氧菌）的抗生素——阿莫西林克拉维酸是首选，青霉素过敏者用多西他赛或复方磺胺加甲硝唑或按本地的耐药选择（并理解一代的头孢与氟喹诺酮对巴斯德菌与厌氧菌的覆盖不足是“口服两天无好转”的常见原因）；住院的静脉给药并抬高患肢与夹板的舒适位与术后的早期活动（手部的僵硬是最常见的后遗症，物理治疗与肿胀的控制要在手术当天就开始讨论，而不是在出院时）——[[microbiology/antimicrobials]]、[[musculoskeletal/fractures]]。追加的一层：伤口的性质（咬伤属于污染伤：初期缝合仅在面部且已清创时考虑，其余二期愈合）、神经血管与肌腱功能的记录与拍照（既是照护也是法证的记录）、破伤风与狂犬与猫抓病与罕见的兔热病与分枝杆菌（海与淡水暴露的嗜水与溃疡分枝杆菌）的考虑、以及免疫抑制与糖尿病与脾切除的状态（它们把“局部感染”变成“全身急症”，并使进展速度成为分诊的指标）；若出现脓毒的表现，按脓毒症的集束化处理——[[emergency-critical-care/shock-fluids]]、[[immunology/immunodeficiency]]。最后：向患者解释“为什么切开比输液更重要”（否则引流会被当作治疗的失败），并预约复诊（伤口的检查与引流的必要性与功能的康复与是否需要考虑手部的防护与职业的影响）——[[clinical-skills/communication]]。**

::: example 未用过激素的哮喘发作 {#ex-steroids}
一名26岁女性哮喘急性发作，呼气峰流速为个人的50%，说话断句；你决定给予全身的糖皮质激素；她担心“激素会让人发胖与骨头变脆”，并问能不能只用雾化。
::: solution
**激素在急性炎症中的双面（[[#def-vascular]]、[[#def-cells]]、[[respiratory/asthma-copd]]）：为什么必须给：哮喘的急性发作是气道的炎症与水肿与黏液的分泌与平滑肌的反应，β激动剂只松解平滑肌；糖皮质激素通过抑制多种炎症基因的转录（核因子κB与激活蛋白1的通路与多种细胞因子与黏附分子与诱导型一氧化氮合酶与环合酶-2）与增加β受体的表达，降低晚发反应与住院与复发；其效应在数小时后才出现（这解释了为何“给了激素还要继续雾化”与为何不能因为“没有立刻好转”就判定无效），且短疗程（五天的口服泼尼松龙在多数发作中足够）优于延长（并不显著缩短恢复而增加不良反应）。她的顾虑要具体回答：短期疗程的常见反应是失眠与情绪的波动与胃的不适与血糖与血压的短暂升高与面部的潮红与食欲增加；而“满月脸与骨质疏松与皮肤变薄与白内障与生长抑制”属于反复或长期暴露的累积效应（每年超过若干疗程就应重新审视她的控制方案并转介哮喘的专科评估，因为“经常需要激素”意味着维持治疗不足，而正确的解法是吸入的激素的剂量与技术与依从与触发因素与生物制剂的路径而不是每年几次口服）——[[immunology/tolerance-regulation]]、[[pharmacology/adverse-reactions]]。给她的解释要点：一次短疗程的激素不改变她的骨与体重，而“不用激素”的风险是住院与重症监护与死亡；同时明确的其他配套（氧的滴定与雾化与硫酸镁与（少数）静脉的镁与氨茶碱的地位与无创通气与插管的判断，以及出院时的吸入技术的教学与书面的行动计画与随访的时间与“何时再来”的标准），并把全身激素的记录写入她的病历与用药单（在需要长期使用者中还要考虑骨与眼与血糖与肾上腺的抑制与“随身激素卡”）——[[emergency-critical-care/airway-ventilation]]、[[clinical-skills/communication]]、[[endocrine/adrenal]]。**

## 通向何处

先天免疫的受体与补体见[[immunology/innate-immunity]]；从急性到慢性与修复见[[pathology/chronic-inflammation-repair]]；化脓与外科感染见[[surgery/wounds-surgical-infection]]与[[emergency-critical-care/shock-fluids]]；介质的药理靶点见[[pharmacology/drug-receptor]]与[[pharmacology/adverse-reactions]]；炎症标志的解读见[[clinical-skills/laboratory-tests]]；全身炎症反应见[[infectious-diseases/fever-sepsis]]。

::: history
**急性炎症的五个征候（红、肿、热、痛与功能丧失）是古代外科的遗产：塞尔苏斯写下前四者，菲尔希诺加入了第五者；而“炎症是有用的损伤反应”这一现代观念要等到循环被理解之后。列文虎克在1690年代用自制的显微镜描述了血与脓中的小体；亨特对血管与修复与炎症的比较解剖学研究把炎症从“脓的体质”转成局部的事件；菲尔绍在十九世纪中叶描述了白细胞的游出与炎症的局部血液变化，并提出了渗出与变质的分类；而“化学趋化”的概念由梅奇尼科夫在1880年代用幼虫与蔷薇刺的实验建立（他因此成为细胞病理与先天免疫之父，并与艾利希的体液学派构成一段著名的对立与最终的和解）。二十世纪的介质时代：埃尔利希的补体与受体的思路、达尔文与亨利与后来的西肖特与马雷沙尔对组胺与其他自体活性物质的分离、以及“自花的毒素”（1930年代达尔文与斯特列尔与1970年代的本格特·萨米尔松对前列腺素与白三烯的纯化，后者以极少的羊水与牛的精液完成了关键的一步，并在1982年获诺贝尔奖）；郑（约翰·文）在1971年提出前列腺素介导了阿司匹林的作用，为环合酶作为药物靶点奠基。细胞因子的时代从1950年代的干扰素与1980年代的白细胞介素1与肿瘤坏死因子与1990年代的信号转导与转录因子的通路开始，“全身炎症反应综合征”的定义（1991年）既统一了语言也制造了过度的诊断，随后被脓毒症的定义（序贯性器官衰竭的评估）取代；而“消退是被编程的”这一发现（2000年代的脂氧素与消退素与保护素与胞葬作用的受体）把一个被动的过程变成治疗的新靶点，也使本章与慢病（动脉粥样硬化与代谢综合征与衰老的慢性炎症）连成一线——[[immunology/innate-immunity]]、[[pharmacology/drug-development-prescribing]]。**
:::

::: summary
- 急性炎症是被介质编排的血管与细胞事件：血流改变与通透性增加与中性粒的按次序募集，各自有其解剖与时限。
- 介质的时间分工决定临床的时间窗：组胺在分钟、类花生酸在小时、细胞因子在数小时并启动肝脏的急相反应。
- 中性粒的杀菌依赖氧化爆发与颗粒内容；这两条通路的遗传缺陷以特定的感染模式呈现（无脓的感染与过氧化氢酶阳性的脓肿）。
- 全身反应（发热与白细胞增多与急相蛋白）既是宿主防御也是诊断的工具，但其时程要求按时间解读：“早期正常”不等于排除。
- 结局取决于清除是否完成：完全消退、化脓与引流、慢性与纤维化、或未终止的低度炎症把急性炎症接进慢病。
- 临床的四课：双侧的红肿要怀疑非感染；晶体性炎症对抗生素必然无效；波动感意味着引流；短疗程激素的安全问题要按累积暴露而非单次来谈。
:::


::: exercise 给炎症介质排序 {level=1}
把下列按其在炎症中出现的时间与主要作用归类：组胺、血栓素A2、白三烯B4、C反应蛋白、白细胞介素1、缓激肽、转化生长因子β、一氧化氮。
::: solution
**按时间与作用的归类（[[#def-vascular]]、[[#def-cells]]、[[#def-systemic]]）：数分钟（储存的介质）：组胺（细静脉的内皮收缩与通透性增加与血管扩张）与缓激肽（通透性与疼痛与血管扩张，并被肽酶降解）。数十分钟至数小时（新合成的脂类）：血栓素A2（血小板的聚集与血管收缩）、白三烯B4（强效的中性粒趋化与黏附的激活）、白三烯C4-D4-E4（支气管的收缩与黏液与通透性）、前列腺素E2（血管扩张与疼痛与发热）与前列环素（血管扩张与血小板的抑制）。数小时（细胞因子与基因的表达）：白细胞介素1（与肿瘤坏死因子共同诱导内皮的黏附分子与化学因子与肝脏的急相蛋白与发热）；随后（一日至数日）：C反应蛋白（由肝脏在白细胞介素6驱动下产生、结合磷酸胆碱与调理并激活经典补体通路，其值的时间窗决定了“早期正常”的解释）；以及消退与修复期：转化生长因子β（抑制淋巴与促进纤维化与修复，是把炎症转向瘢痕的开关）与一氧化氮（诱导型的合酶在炎症中产生大量一氧化氮，兼有杀菌与血管扩张与免疫调节的双面作用，其抑制在动物模型中加重而过度产生导致休克时的低血压）。把这张表用来读临床的时间线：为何伤后第一天的肿胀对非甾体抗炎药反应好、第四天的肿胀更依赖细胞的因素、而“炎症的疼痛”部分是介质对末梢神经的致敏——[[pathology/chronic-inflammation-repair]]、[[pharmacology/drug-receptor]]。**

::: exercise 解释一份激素后的血常规 {level=2}
一名哮喘患者在口服泼尼松龙第四天：白细胞14.5、中性粒92%、淋巴细胞8%（绝对值0.6）、无杆状核增多、无中毒颗粒；她无症状。如何解释？
::: solution
**类固醇的白细胞图案（[[#def-cells]]、[[#def-systemic]]、[[respiratory/asthma-copd]]）：机制的四条同时作用：骨髓的储备释放增加与中性粒从血管边缘的“脱落”减少（黏附分子的下调使循环内数量上升）与凋亡的延迟（中性粒的寿命被延长）与淋巴与嗜酸与单核的重新分布（淋巴与嗜酸细胞减少是类固醇的特征，也是为什么“用了激素后嗜酸细胞仍高”提示剂量不足或另有原因）；因此这份报告的模式是“高中性粒、无左移、无中毒颗粒、淋巴与嗜酸低”，与细菌感染的“高中性粒伴左移与中毒颗粒与杆状核增多与（常有的）淋巴的相对保留”不同——[[clinical-skills/laboratory-tests]]。临床的推论：不要用白细胞来诊断她“有感染”（这会推动不必要的抗生素与检查），也不要因为白细胞高而延迟出院；反之，若她出现发热的症状或左移或中毒颗粒或临床的恶化，则要考虑感染（在激素的背景下炎症的体征被钝化，故发热的阈值与检查的阈值都要降低）。同类需要解释的还有：分娩与剧烈运动与癫痫发作与手术与吸烟与应激的内源性儿茶酚胺与皮质醇的效应与β激动剂后的白细胞升高，以及慢性骨髓增殖性疾病与白血病中的“高白细胞”；一条实用的规则是：把白细胞当作“分布”的指标而非“生产”的指标，并按时间与用药与临床背景解读——[[blood/haematopoiesis]]、[[pharmacology/adverse-reactions]]。**

::: exercise 诊断发热的来源 {level=2}
一名腹部手术第六天的患者发热38.9度、心率112、白细胞16伴左移；切口外观良好、肺与尿无明显症状。请给出你的思路与查体的次序。
::: solution
**术后发热的时相与它之外的事物（[[#def-systemic]]、[[pathology/chronic-inflammation-repair]]、[[surgery/wounds-surgical-infection]]）：把“风与水与伤口与Walk与药物”的传统助记当作提示而非法则（肺不张被高估、导管与药物热与静脉血栓在第六天同样常见），更重要的是“漏掉的解剖”：腹腔的吻合口漏与脓肿（第六天的发热伴心率快与肠功能的停滞与白细胞的左移，最需要一个增强扫描而非等待）、深部的切口与筋膜的感染（表面的外观正常不等于深部清洁，注意疼痛的比例与伤口的浆液性与坏死性的渗出与皮下的张力）、胸腔的积液与肺炎与（插管过久者的）气管支气管的感染、导管的血流感染（发热的时段与导管的入口与拔管的培养）、泌尿（尤其在导尿后）与（下肢的）深静脉血栓与肺栓塞、以及非感染的原因（输血与药物的热与酒精的戒断与心梗后与肺的栓塞与肿瘤与炎症性肠病的发作、与类固醇的停用）。查体的次序有讲究：先看病人（呼吸的功与意识与尿量与血压的趋势比单个温度重要），再看伤口与腔道（引流液的性状与引流管的旁漏）与腹部（压痛的定位与腹膜的体征在老年人可缺失），再回顾“任何留在体内的东西”（导管的日期与静脉的外周炎与牙齿与鼻窦与眼睛与压疮与骶尾）。检查要按假设定向：血培养两套与尿与痰的选择性送检与C反应蛋白与降钙素原的系列（比单次更有意义）与腹盆的增强扫描与超声的胸腔与（有指征时）下肢的超声；治疗不要等全部结果：若怀疑腹腔的污染或脓毒症则按本地的方案经验性用药并在数小时内取得源控制（因为“抗生素对未引流的脓无效”是本领域最古老也最有效的教条），同时复查与再评估的时间写进医嘱——[[emergency-critical-care/critical-care]]、[[clinical-skills/clinical-reasoning]]。**

::: exercise 设计一项“促消退”的试验 {level=3}
一种合成的消退素类似物在动物模型中加速了炎症的消退并减少纤维化；你要为“急性呼吸窘迫综合征”设计一期与二期的路径。
::: solution
**把消退当作靶点的试验设计（[[#def-cells]]、[[#def-systemic]]、[[respiratory/respiratory-failure]]）：概念的问题：在急性窘迫综合征中，炎症既驱动损伤也参与宿主防御与修复；“促进消退”意味着加快清除凋亡的中性粒与恢复肺泡上皮的离子转运与减少纤维化的增殖，因此主要终点不应是“炎症标志的下降”（那可能同时意味着免疫抑制）而是“炎症的终止而不牺牲防御”。一期的设计：在健康志愿者与在轻度肺损伤的患者中测剂量爬坡与安全（关键的担忧是继发感染与伤口愈合的延迟与药物对肿瘤免疫的潜在影响）；用药效动力学的替代指标取得“证据 of 机制”：支气管肺泡灌洗液的中性粒与凋亡细胞的比值与巨噬细胞的胞葬能力与（可被诱导时）外周血的中性粒的凋亡与噬菌的实验性指标，配合血浆的蛋白与炎症标志与肺的顺应性——[[clinical-skills/laboratory-tests]]、[[immunology/innate-immunity]]。二期的设计：以分层与适应性随机化与预设的干预效应的中间指标（无呼吸机天数与无器官衰竭天数与生物标志的分层）与一个明确的“终止规则”，同时把亚型的富集作为设计的一部分（在“低炎症”与“高炎症”的表型中，同一药物的效应方向可能相反，这类试验失败的最常见原因是把异质的人群当作同质——这也是过去二十年急性窘迫综合征的所有药物试验的共同教训）——[[epidemiology-ebm/randomised-trials]]、[[epidemiology-ebm/critical-appraisal]]。伦理与公平的一层：重症的知情同意的能力（代理同意的路径与事后的同意与延迟的招募），以及在资源有限的环境中“促消退”是否可被使用（若药物需要在无机械通气的低资源环境中使用，其价值的论证方式完全不同）；以及阴性结果的发表（一项促消退药在生物标志上有变化而临床终点上无变化的结果，对理解消退的生物学同样重要）——[[medical-ethics-law/research-ethics]]、[[public-health/global-health]]。**

一名患者的胸腔穿刺液：蛋白34克每升而血白蛋白32、乳酸脱氢酶620而血乳酸脱氢酶180、细胞以中性粒为主、葡萄糖2.1、pH 7.05。请按渗出与漏出与后续行动解读。
::: solution
**用规则与用临床（[[#def-vascular]]、[[pathology/chronic-inflammation-repair]]、[[respiratory/lung-cancer-pleura]]）：Light 的标准：胸液对血的蛋白比值（34/32 大于0.5）与胸液对血的乳酸脱氢酶比值（620/180 大于0.6）与胸液的乳酸脱氢酶大于血上限的三分之二，任一满足即为渗出液（三条都满足，故明确是渗出）。中性粒为主提示急性的过程：肺炎旁的积液或（更早的）食管破裂与肺的栓塞与外伤与结核的早期；葡萄糖低（小于3）与pH 低（小于7.2）在肺炎旁的积液中意味着复杂的、需要引流的脓胸（细菌与细胞的代谢耗糖与二氧化碳的堆积），并在其他背景下提示类风湿与结核与恶性与狼疮；因此下一步不是“观察”而是：立即重复的影像（超声看分隔与locules）、送革兰染色与培养（含厌氧与结核）与细胞学（在成人中恶性也要考虑）、以及胸外科的会诊决定是胸腔管的引流还是（分隔的）纤维溶解或胸腔镜的清创；同时给抗生素并按是否脓性决定疗程——[[microbiology/laboratory-diagnosis]]、[[clinical-skills/physical-examination]]。要提醒的陷阱：在利尿治疗中的“假性渗出”（血与胸液的乳酸脱氢酶梯度可以帮到判断，而蛋白的浓度差是更好的指标）与乳糜的胸液（甘油三酯高与乳白色，与胸导管的损伤与淋巴瘤）与血性的（外伤与恶性与肺的栓塞）与嗜酸细胞为主的（空气与药物与寄生虫与血管炎）——每种都需要不同的下一步——[[pathology/cancer-diagnosis]]。**

::: exercise 围绕级联开药 {level=1}
为下列情形选择并解释：急性踝的扭伤（无禁忌）；慢性肾病四期的痛风发作；服用华法林者的肌肉痛；炎症性肠病的活动期；以及一名哮喘患者对非甾体抗炎药曾出现支气管收缩。
::: solution
**在级联的不同点上介入（[[#def-vascular]]、[[pharmacology/drug-receptor]]、[[pharmacology/adverse-reactions]]）：急性扭伤：非甾体抗炎药短期（阻断环合酶从而减少前列腺素的疼痛与肿胀，注意对骨的愈合与胃与肾的顾虑，且证据显示对功能结局的改善有限，故与冷敷与抬高与压缩与早期的活动一起用，后者才是恢复的主力）。慢性肾病四期的痛风：避免非甾体抗炎药（肾的前列腺素依赖的灌注与容量与肾小管的间质的三重风险），用低剂量的秋水仙碱（按肾功能减量并避开与其相互作用的药物，否则出现骨髓与肌肉的中毒）或短疗程的糖皮质激素或关节内的注射（并监测血糖），难治者在专科下用白介素1的拮抗剂；同时不要在急性期突然改变降尿酸的方案——[[renal/chronic-kidney-disease]]。服用华法林的肌痛：避免非甾体抗炎药（胃肠的出血与血小板的功能与蛋白结合的置换与对肠道菌群的间接影响使国际标准化比值升高），首选外用（双氯芬酸的凝胶在局部的肌肉与关节有效且全身暴露低）与乙酰氨基酚（大剂量仍会增强华法林的作用，故按不超过某日剂量并加强监测）与运动治疗与（在肌筋膜痛时）热与非药物的路径；避免曲马多作为“安全的替代”（跌倒与便秘与嗜睡与血清素综合征与依赖）——[[blood/thrombosis-anticoagulation]]、[[musculoskeletal/back-pain]]。炎症性肠病的活动期：非甾体抗炎药可诱发加重（环氧合酶通路的转向与局部的前列腺素减少与黏膜的通透性增加），故用糖皮质激素诱导缓解与免疫调节与生物制剂维持，并把镇痛按阶梯（对乙酰氨基酚与（谨慎）弱阿片与解痉），并说明“止泻药在肠炎活动期要谨慎”——[[gastrointestinal/bowel-disease]]。哮喘对非甾体抗炎药曾出现支气管收缩：这是脂合酶通路的转向（环合酶被阻断使花生四烯酸流向白三烯）在部分哮喘与鼻息肉与阿司匹林加重的呼吸道疾病中；处理是避免非选择性的环合酶抑制剂并（若必须用抗炎药）在专科评估与（选择性环合酶-2抑制剂的）激发试验后使用，并用乙酰氨基酚的低剂量替代，同时把这一事件写入过敏与不良反应的字段——[[respiratory/asthma-copd]]。**

::: exercise 解释一次正常的C反应蛋白 {level=2}
一名发热两日的老人C反应蛋白为4；她精神差、心率快、血压偏低。请解释这个结果并给出下一步。
::: solution
**时程与宿主（[[#def-systemic]]、[[clinical-skills/laboratory-tests]]、[[infectious-diseases/fever-sepsis]]）：这个结果几乎不提供排除的信息：C反应蛋白由肝脏在白细胞介素6驱动下合成，在损伤或感染后约六至八小时才开始升、并在约四十八小时达峰；因此“发热两日”可能仍处于上升前的窗口（且两日的定义常不可靠）。宿主的一面使解释更弱：老年人可以反应迟钝，而“精神差加心率快加血压偏低”是生理学的报警（在老年与体弱人群中，意识与循环的改变远比炎症标志更早、更可靠），而已经使用糖皮质激素与免疫抑制与肥胖（白蛋白与稀释与营养状态）与严重肝病与某些人群的遗传背景都会压低C反应蛋白——[[geriatrics-palliative/ageing-frailty]]。下一步：按“疑似脓毒症”处理（一套血培养与尿与胸片与乳酸与血气与肾与凝血与血常规的复查、静脉的抗生素与按体重与肾功能的液体、并复评乳酸与灌注而不是复评体温），并在六至十二小时后复查炎症标志（趋势比单点有用）与在有指征时查降钙素原（其在细菌感染中上升快于C反应蛋白且不受激素影响，但仍不能替代临床）；同时考虑非感染的原因（在心衰与肺的栓塞与心梗与出血与肠缺血与胰腺炎与药物热与关节炎的发作中，C反应蛋白也可以正常而临床“看起来像感染”），并把“什么会改变我的想法”写进交班——[[emergency-critical-care/acute-assessment]]、[[clinical-skills/records-handover]]。**

::: exercise 就“消退”作为药物靶点辩论 {level=3}
一方主张：促进炎症的消退可以治疗慢病而不造成广泛的免疫抑制；另一方主张：抑制未终止的炎症才是正路。请陈述双方的最强论证与你的结论。
::: solution
**消退作为靶点（[[#def-cells]]、[[#def-systemic]]、[[pharmacology/drug-receptor]]）：促进消退一方的最强论证：消退是主动的程序（脂氧素与消退素与保护素与巨噬细胞的表型转换与凋亡中性粒的胞葬作用与离子通路的恢复与淋巴管的引流），因此增强它可以在终止炎症的同时保留识别病原的能力（胞葬作用本身诱导转化生长因子β与抗炎的表型，形成“清理即安抚”的正反馈）；这也解释了为何长期抗炎（非甾体抗炎药与糖皮质激素）在慢病中有效却代价高，以及为何现有的抑制性生物制剂在若干疾病中使感染与肿瘤的风险上升；此外在急性损伤（心肌与肾与脊髓）中，未终止的中性粒反应是残疾的主要来源，而动物模型中促进消退的分子明显减小了梗死与纤维化——[[immunology/tolerance-regulation]]。抑制炎症一方的最强论证：许多慢病的炎症是抗原持续驱动的（自身抗体与持续的微生物与晶体与淀粉样与代谢的信号），此时“促进消退”等于给一个仍在被激活的系统加上刹车而发动机还在踩（例如类风湿的滑膜与银屑病的皮肤需要上游通路的阻断）；而且消退的增强可能损害宿主的防御（在需要中性粒的反应中增加感染，且理论上损害肿瘤的免疫监测），并且内源介质在体内的半衰期与作用范围意味着“外源给一个脂质介质”很难得到局部的效应——[[immunology/autoimmunity]]、[[pathology/cancer-biology]]。结论是可辩护的中间立场：把“消退”看作分型的策略而非单一的药物类别（哪些患者处于“炎症未终止”的表型、哪些处于“抗原持续驱动”，这需要生物标志与影像与细胞的功能检测）、在抗原可清除的疾病中优先清除（感染与晶体与淀粉样与肥胖与吸烟与牙周）并在这些情形下测试促消退的分子（因为它们最接近模型中的情形）、以及在急性与自限的场景（围手术期与缺血与再灌注与急性的肺损伤）中首先试验（时间窗明确且暴露短，安全性可评估）。无论哪一方，都必须承认：过去二十年里最可靠的“抗炎”进步来自上游通路的靶向（生物制剂）与危险因素的去除，而“促消退”仍待临床证明——所以临床医生今天能做的是终止那些本可以被终止的炎症（移除刺激物、引流脓、停用致病药物、处理肥胖与牙周与吸烟），这也是一种促进消退——[[public-health/prevention-promotion]]、[[surgery/wounds-surgical-infection]]。**
