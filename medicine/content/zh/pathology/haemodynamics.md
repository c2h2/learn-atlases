血流动力学的紊乱是“血流的问题被写成组织的损伤”：**压力的负荷使心室增厚或扩张，血流的阻断使其后的器官梗死，血栓在错误的地方形成并脱落，液体被压进或漏进不该去的腔隙，而休克则是循环的输送能力无法满足代谢的需求。**本章覆盖液体的错位（水肿与积液与星力的账本与其四个变量）、异常位置的凝血（血栓形成的三要素与其诱因与静脉血栓与动脉血栓的不同逻辑）、以及栓塞与梗死与休克（栓子的去向与梗死的形态与休克的四型与其器官的后果）。

## 液体的错位

::: definition 水肿、积液与星力的账本 {#def-oedema}
**组织液的生成与回流是一本四栏的账：毛细血管的静水压把液体推出，血浆的胶体渗透压把液体拉回，间质的静水压与胶体渗透压修正两侧，而淋巴负责把剩下的蛋白与水分运走。水肿是这本账失衡的结果，而病因可以按四栏来归类。静水压升高：心衰与（在静脉的）狭窄与（在妊娠与久坐时的）依赖与（在肝硬变时的）门脉的高压；胶体渗透压下降：白蛋白低于约25至30克每升时出现（肾病综合征与肝病与营养不良与蛋白丢失的肠病）；通透性升高：炎症与脓毒症与烧伤与（在药物与蛇毒时的）内皮的损伤，此时液体是渗出液并伴白蛋白的漏出；淋巴的回流受阻：癌性的淋巴阻塞与术后的清扫与放射与（在丝虫病时的）寄生虫与（在反复的蜂窝织炎后的）淋巴的破坏，其液体富含蛋白，故按之不易凹陷且对外用利尿剂无反应。区分水肿的类别靠几个具体的问题：是全身还是局部、是凹陷还是不凹陷、是晨轻暮重还是持续不变、有没有气促与端卧呼吸与体重的骤变。全身性水肿的三个大原因是心、肝、肾。单侧的局部水肿首先要排除深静脉血栓，其次想腹股沟的肿块压迫与盆腔术后的淋巴损伤。双侧的下肢水肿最常见于静脉高压与依赖，其次是药物，尤其是钙拮抗剂、非甾体的抗炎药、噻唑烷二酮、糖皮质激素、加巴喷丁与若干抗抑郁药；这一类在减量或换药后可消，故在开始利尿剂之前应先核对用药单。不凹陷的水肿提示淋巴的阻塞与甲的低下：皮肤厚而皱、趾的钝圆、Stemmer 征阳性（在第二趾的基部捏不起皮褶）；此处利尿剂无效，治疗是压缩与抬高的物理治疗与皮肤的护理与反复感染的预防。积液的命名按腔隙：胸腔的（漏出与渗出的分界见 Light 的标准）、腹腔的（在肝硬变时为漏出，其感染需要按中性粒的计数诊断）、心包的（其快速积聚导致填塞）与（在儿童的）水与（在肾病的）皮下。水肿的临床价值在于它是全身状态的读数：突然的体重增加是最敏感的早期指标，比体检的凹陷更早；而对利尿剂的反应不佳常常说明病因判断错了（如淋巴阻塞与（在钙拮抗剂引起的）外周的液体重新分布），而不是剂量不够——[[cardiovascular/heart-failure]]、[[renal/water-sodium]]、[[gastrointestinal/liver-disease]]、[[pathology/acute-inflammation]]。**
:::

## 在错误位置凝血

::: definition 血栓形成及其疾病 {#def-thrombosis}
**Virchow 的三要素仍是最好的框架：血流、血管壁与血液的成分。静脉血栓以血流淤滞为主角：制动、术后、妊娠、心衰、房颤、瘫痪与长途旅行。动脉血栓以血管壁的病变为主角：斑块破裂使组织的因子与胶原暴露，血小板黏附聚集，形成所谓的白血栓，因此表现为心、脑与外周的缺血。用药的逻辑由此分野，而非出于习惯：静脉血栓是纤维与红细胞构成的红血栓，由凝血级联驱动，抗凝有效；动脉血栓由血小板活化启动，故以抗血小板为核心，抗凝只在房颤与机械瓣与急性冠脉综合征后的短期联合时使用。
血栓的结局有四种：被自身的纤溶部分溶解、蔓延、机化并与静脉壁粘连从而破坏瓣膜形成血栓后的病变、或脱落成为栓子。遗传的易感包括抗凝血酶、蛋白C 与蛋白S 的缺乏，以及因子V Leiden 与凝血酶原的基因变异。获得的高凝最需注意肿瘤，尤其是胰腺、胃、卵巢与肺。无诱因、反复发生或伴游走性皮肤血栓的静脉血栓，应按年龄与症状做有针对性的肿瘤筛查，而不是全身乱查。抗磷脂综合征以动静脉血栓、反复的流产与重症时的多脏器血栓为表现，诊断需要间隔十二周以上的两次抗体阳性，而它的长期治疗偏向华法林而非直接口服抗凝药。
评估的实用原则是：检查只在结果会改变疗程或亲属的咨询时才有意义。急性期的抗凝会干扰多数项目的判读，妊娠与口服抗凝药同样如此，所以“在血栓后立刻查全套”常常既花钱又误导。妊娠相关的血栓还要按生理的改变解释：凝血因子的升高与静脉的受压使产后六周的风险最高，而直接口服抗凝药在此不适用（[[blood/thrombosis-anticoagulation]]、[[cardiovascular/vascular-disease]]、[[obstetrics-gynaecology/pregnancy-complications]]、[[pathology/diagnostic-pathology]]）。**
:::

::: definition 栓塞、梗死与休克 {#def-embolism}
**栓子随血流停在管径与它相当之处，因此去向由来源决定：左心的栓子到脑、肾、脾与下肢；静脉的栓子到肺；门静脉的栓子到肝。例外是反常的栓塞：在卵圆孔未闭与房间隔的缺损时，静脉的栓子进入体循环，从而在年轻且无房颤的患者中造成卒中。栓子的种类包括血栓、脂肪（在长骨骨折之后）、空气与气体（在手术与中心静脉的导管与潜水之后）、羊水、肿瘤的细胞团、感染性心内膜炎的赘生物，以及动脉粥样硬化斑块被破坏后释出的胆固醇结晶。
梗死属于凝固性坏死，其形态由两个因素决定：解剖的血供与组织的性质。有双重血供或吻合网的器官（肺、肠、肝）发生出血性梗死，而终末动脉供血的肾、脾与心发生贫血性梗死；睾丸与肠可因静脉的扭转而呈出血性；再灌注、溶栓与手术后的梗死常带出血。脑的梗死是液化性坏死，数周后留下囊腔与胶质瘢痕。旧梗死的读法是：苍白软化 在二十四至四十八小时最清楚，一至三日有中性粒，一至四周有巨噬细胞与（在脑的）格子细胞，数月后为胶质瘢痕与空腔；因此法医与临床都能从时限的形态推断事件发生的时间，而CT 与MRI 的扩散加权成像早已把这一部分变成了影像的问题。
休克的四型仍是床边的第一分诊：低容量、心源性、梗阻性与分布性。它们的治法互相排斥，而体征常常混合，因此要按“每搏量的来源”来问三个问题：回心血量够不够（病史、腔的大小、被动抬腿）、泵行不行（室壁的运动与瓣与心律）、血管的张力对不对（温度与血压与脓毒的背景与过敏的暴露）。乳酸是组织灌注的读数而不是诊断，它的下降比它的绝对值更有意义；血压正常不等于不休克（在代偿期的年轻患者可以血压正常而乳酸升高）；而对补液的反应是分类的工具，不是治疗的目标。休克最后的共同通路是微循环的衰竭与细胞的氧利用障碍与（在多脏器功能障碍中的）器官的顺序性失代偿，所以治疗的时间比药物的选择更重要（[[emergency-critical-care/shock-fluids]]、[[cardiovascular/circulation-blood-pressure]]、[[infectious-diseases/fever-sepsis]]、[[pathology/acute-inflammation]]）。**
:::

::: example 长途飞行后的腿 {#ex-dvt-pe}
一名29岁的女性在十四小时的航班后第二天出现左小腿的肿胀与疼痛，D-二聚体在社区的检测中升高；她有口服的避孕药史；她的母亲“年轻时得过血栓”。
::: solution
**验前概率决定路径。按 Wells 的评分把临床的可能性量化（肿胀的程度与沿深静脉的压痛与双侧的差别与癌与制动与既往的血栓与年龄），然后二选一：可能性低时做高灵敏的D-二聚体（阴性可以安全地排除，无需影像）；可能性高时直接做加压的超声。不要跳过这一步去做血栓的“筛查项目”：D-二聚体在妊娠与手术与炎症与肿瘤与高龄时都升高，特异性很差，它的价值在于阴性排除而不是阳性诊断。关于她母亲的病史：只在结果会改变疗程的长短或亲属的咨询时才做遗传的检测，并且要避开急性期与抗凝的干扰。治疗按本地的路径：直接口服抗凝药的单药起始或先给低分子肝素再衔接，剂量的选择看体重与肾功能与相互作用的药物与依从性；口服避孕药立即停用，并在疗程内改用不含雌激素的方法（在妊娠与哺乳时改用低分子肝素，因为华法林与直接口服抗凝药不适用）。疗程是三个层面的决定：诱发的因素（在飞行与制动这类短暂因素之后的首次近端血栓多为三个月）、遗传与肿瘤的发现（可能延长）、以及复发与（在抗凝下的）继续血栓。她的顾虑还包括飞行与妊娠：教会她长途旅行时的活动与补水、避免紧束的膝上袜带与在将来妊娠时按家族史与个人史做预防的评估。同时告诉她复查的必要性：若出现胸痛与气促与晕厥与咯血需即刻就诊，因为肺的栓塞可以在腿的症状很轻时已经很重（[[blood/thrombosis-anticoagulation]]、[[clinical-skills/laboratory-tests]]、[[obstetrics-gynaecology/contraception-fertility]]、[[respiratory/respiratory-failure]]）。

::: example 癌症解释的两条腿肿 {#ex-lymph-oedema}
一名68岁的女性因宫颈癌在六年前做了根治性的手术与术后的放射，近两年双下肢逐渐肿胀，按之不易凹陷，皮肤增厚并有反复的蜂窝织炎；白蛋白与心与肾的检查正常。
::: solution
**这是淋巴的阻塞而不是静水压的负荷，几个特征可以确定：按之不易凹陷、皮肤的增厚与皱褶、趾端钝圆、Stemmer 征阳性、抬高后改善不明显、利尿剂无效、并且有明确的原因（盆腔的清扫加上放射会使淋巴的通路纤维化，而肿瘤的复发必须被排除）。机制上是含蛋白的液体滞留在间质，长期的刺激引发炎症与脂肪的增生与纤维化，于是组织变硬并失去弹性；富蛋白的环境又使皮肤成为链球菌的入口，形成“蜂窝织炎—淋巴进一步破坏—更肿”的循环。检查的重点：先做盆腔与腹部的影像排除复发与（在髂静脉受压时的）静脉的阻塞；同时看是否合并静脉的高压（这两种病因常并存，且压缩的治疗不同）。处理的核心不是排水而是维持：由受过训练的物理治疗做完整的消肿治疗（手法引流与多层低弹性的压缩与皮肤与趾甲的护理与运动），日间使用压力袜（按周径与压力等级定制）、夜间可继续、每年评估压力的适配；反复的蜂窝织炎（一年两到三次以上）是长期预防性抗生素的指征，并把皮肤裂口与足癣与趾甲的治疗当作治疗的一部分而不是附带。要明确告诉她的事：利尿剂在此无效且会造成电解质与容量的问题；按摩与“排毒”与（在若干广告中的）气压的器具在没有压缩的情况下会让肢体更肿；放疗与手术后的淋巴损害是终身的，但可以通过每日的护理把发作的次数与肢体的围度控制住。最后一层是随访：体重的变化与新发的疼痛与（在破溃不愈时的）皮肤肿瘤（在慢性的淋巴水肿与瘢痕上的血管肉瘤罕见但存在）都需要被记录（[[surgery/wounds-surgical-infection]]、[[obstetrics-gynaecology/gynaecological-cancer]]、[[infectious-diseases/healthcare-infections]]、[[geriatrics-palliative/symptom-control]]）。**

::: example 导管术当天的足 {#ex-atheroembolism}
一名72岁的男性在冠状动脉的造影后五天出现足趾的发紫与疼痛，双足的脉搏存在；皮肤见网状的青斑，肾的肌酐从90升到180，血与尿的嗜酸细胞升高，补体偏低。
::: solution
**这是胆固醇的结晶栓塞，而不是新的血栓或动脉的栓塞。机制：导管的机械的摩擦使主动脉的斑块碎裂，大量的微小结晶随血流进入小动脉，在弓形的动脉内形成阻塞并引发异物样的内膜反应；因此它的三联是：近期有血管的操作或抗凝、足趾发紫但脉搏存在（因为阻塞在小动脉而非大动脉）、以及多系统的表现（肾的损伤与肠的缺血与眼底的 Hollenhorst 斑与（在肌肉的）疼痛与嗜酸细胞升高与低补体与（在数周内的）进行性的肾功能不全）。诊断很少需要活检（皮肤的破溃处与肾的活检可以看到特征性的梭形的空隙），更多是靠“操作之后、脉搏存在、多系统、且抗凝之后不好转”的组合；血管的重建在这里没有帮助，因为病变是弥漫的小动脉。处理是支持性的：停掉可能加重的手法（在必要之外的再次介入与（在肾损伤时的）造影剂）、按肾功能调整药物、疼痛与破溃的护理、以及是否继续抗凝的两难（若因支架必须继续，则与出血与皮肤的坏死一并权衡，并把“结晶栓塞”写进病历的显著位置，让将来的医生不再重复同样的操作）。预后要说实话：肾功能的恢复取决于打击的程度，不少患者的肌酐停留在新的基线；复发可以发生但通常较前轻；同时他需要的是斑块稳定（他汀与血压与（在糖尿病者的）血糖与（在吸烟者的）戒烟），而不是更强效的抗凝。把这一例教给年轻医师的三条是：脉搏存在不排除缺血、“新的心衰”可以是结晶栓塞后的肾与（在其中的）高血压、以及操作之后两周内的多系统表现要问一遍操作史（[[cardiovascular/vascular-disease]]、[[renal/acute-kidney-injury]]、[[clinical-skills/clinical-reasoning]]、[[cardiovascular/coronary-artery-disease]]）。**

::: example 产后的气促 {#ex-peripartum}
一名33岁初产的产妇在产后第九天出现端坐呼吸与夜间气促与下肢水肿；产程长并曾有产后的出血与输血；血压146/94，尿蛋白阴性，心率112，床旁的超声见左室的射血分数35%。
::: solution
**产后的气促的鉴别有固定的四条，按危险排序：心源性（围产期的心肌病与（在若干病例中的）原有的心肌病在妊娠的负荷下失代偿）、血栓（肺的栓塞，在产后六周内风险最高）、感染（在子宫内膜炎与脓毒症时的）分布性的休克与羊水相关的肺的损伤、以及非心非肺的原因（贫血与（在子痫前期的时的）液体潴留与（在失血输血后的）循环的负荷）。她的超声把答案定在心肌病：妊娠最后一个月至产后五个月内出现的射血分数下降、没有其他的解释、并常有先兆子痫与多胎与年龄偏大与产时出血输血的病史，其机制与（在若干病例中的）血管紧张素转换酶的通路与泌乳素的片段有关（这解释了一个实践中重要、在动物实验中有力的问题：她的治疗与（在若干中心中的）断奶）。治疗按心衰的指南但按妊娠改写：利尿剂缓解充血；β受体拮抗剂在充血稳定后小剂量加起；血管紧张素的转换酶抑制剂只在她不再哺乳时给（哺乳期的替代是肼苯达嗪与硝酸酯与（在若干体系中）卡托普利的个案经验）；螺内酯可以（在哺乳数据有限的情况下慎用）；抗凝只在射血分数极低或有血栓的证据时；并处理贫血与（在产后抑郁与（在婴儿照护中的）睡眠剥夺时的）现实的困难。她的风险要交代：再次妊娠的心衰风险显著，故避孕与（在未来妊娠前的）孕前咨询是治疗的一部分，而若射血分数在数月后仍不恢复，需要按扩张型心肌病的路径考虑器械与专科的转诊。也要提醒她的是“恢复的可能性”：相当比例者的射血分数在六个月内明显改善，因此不要在产后几周就定终身，同时不要在症状缓解后自行停药。她的婴儿照护的支持（谁夜间喂奶与是否能按时服药与随访的交通）必须被写进计划，否则依从性会成为她出院后再入院的原因（[[cardiovascular/heart-failure]]、[[obstetrics-gynaecology/postnatal-period]]、[[obstetrics-gynaecology/pregnancy-complications]]、[[blood/thrombosis-anticoagulation]]）。**

## 通向何处

静脉血栓的诊断与治疗与抗凝的药物学见[[blood/thrombosis-anticoagulation]]；休克的分型与液体与血管活性药见[[emergency-critical-care/shock-fluids]]；缺血与再灌注的细胞损伤见[[pathology/cell-injury]]；炎症与内皮的关系见[[pathology/acute-inflammation]]；心衰的血流动力学见[[cardiovascular/heart-failure]]；水肿与钠水平衡的生理见[[renal/water-sodium]]与[[physiology/homeostasis-body-fluids]]；围产期的并发症见[[obstetrics-gynaecology/pregnancy-complications]]。

::: history
**血流动力学的病理学是把物理学搬进诊室的过程。星力的方程出自1896年星力的跨毛细血管的液体交换的研究，他把植物的渗透与动物的循环连成一个可算的模型，也使“水肿”从体质名词变成压力差的结果；“积水与水肿”的分类在此之前早已是病理学的基本词汇（在孟希尼科夫与菲尔绍的体系中，渗出与漏出的区别就是炎症是否在场）。血栓的一端是形态学：从（在十七世纪）Hunter 与 Hewson 对死后凝血与活体血栓的区分，到十九世纪中叶 Walshe 与 Mackenzie 的临床统计，再到1856至1863年 Rudolf Virchow 在兔的实验中把静脉炎的三要素写清；Virchow 的学生与同代（Zenker 与 Eberth 与 Shimmin 的接种实验、Bizzozero 在1868年用显微镜看到血小板在损伤血管处的聚积）把“血小板与纤维”变成了血栓的核心。凝血的生化属于二十世纪：从 Quick 的凝血酶原时间与（1930年代）Warburg 的抗凝血酶，到1916年 McLean 在 Johns Hopkins 找到肝素的抗凝作用、1918年 Howell 命名它、1930年代 Scott 与链球菌的培养液使肝素可被大量制备，肝素由此从实验室试剂成为病房里的药。香豆林的故事来自兽医：1920年代北美牛的产后出血无法解释，Link 在1939至1941年从腐败的甜三叶草中分离出双香豆素，这才有了华法林（1950年代作为抗凝药进入临床，并在同年因几位王室患者的使用而广为人知）；“从鼠药到药”是转化医学最常被引用的一例。纤溶的时代从1930年代的血栓的溶解的尝试开始，1940至1950年代链激酶的发现与（1958年的）纤维蛋白溶酶原的结构使“把血栓溶掉”成为可能，1979至1980年代的三项临床试验确立了溶栓在心肌梗死中的价值，并把“时间就是心肌”变成急诊的组织形式。休克的现代定义来自战争：一战中关于失血性休克的生理研究（Wiggers 的狗模型）与二战的血浆与全血的输送与朝鲜战场上的输血体系，奠定了“容量—泵—张力”的分诊框架；1960年代以后肺动脉的导管与（1970年代的）重症监护的普及使“分型治疗”成为可能，也带来“治疗目标值”的争论（在1990年代的超容量与超氧的试验被否定后，节制成为主流）。最近的三十年是抗凝的去实验室化：低分子肝素（1980年代）、磺达肝癲钠、口服的直接凝血酶与Xa 因子的抑制剂（2008年之后）让数千万人不必再监测国际标准化比值，而特指的拮抗剂（依达赛珠单抗与（在若干体系中的） Andexanet）把“没有解药的抗凝”变成过去；同时抗磷脂综合征的识别（1980年代以后）与肿瘤相关血栓的机制提醒我们：Virchow 的三要素至今仍是这门学问最简洁的语言（[[blood/thrombosis-anticoagulation]]、[[cardiovascular/circulation-blood-pressure]]、[[emergency-critical-care/shock-fluids]]、[[pharmacology/drug-development-prescribing]]）。**
:::
::: summary
- 水肿是星力账本的失衡：静水压、胶体渗透压、通透性与淋巴四栏各有其临床的指纹。
- 不凹陷、皮肤增厚、抬高无效、利尿剂无效——这四条一起指向淋巴而不是心肾。
- 静脉血栓的核心是淤滞，抗凝有效；动脉血栓的核心是斑块破裂，抗血小板为核心。
- 血栓的四种结局中，机化会破坏瓣膜；早期抗凝防止蔓延与栓塞，但不保证不留下血栓后的病变。
- 梗死的形态由血供决定：终末动脉的器官为贫血性，双重血供者出血性，脑为液化性。
- 休克按“回心血量、泵、血管张力”三问分诊，四型的治法互相排斥，而乳酸的趋势比数值更有用。
:::

::: exercise 给休克分型 {level=1}
为下列四位患者各判断休克的类型与第一步的处理：消化道出血的四小时；心肌梗死后两小时伴肺水肿；瓣膜置换术后突然气促伴颈静脉的充盈；脓性胆管炎伴降温时的血压下降。
::: solution
**四位分别代表四型（[[#def-embolism]]、[[emergency-critical-care/shock-fluids]]）。消化道出血：低容量性，第一步是压迫来源与配血的准备与按反应的液体复苏（在止血之前不把血压“补满”，避免稀释与凝血因子的进一步丢失与（在门脉高压时的）压力的反跳）；随即内镜与（在失败时的）介入或外科。心梗后伴肺水肿：心源性，第一步是减轻前负荷（在血压允许时给利尿剂与硝酸酯）与早期的血运重建与（在需要时）机械的循环支持，而不是补液；床旁的超声看室壁的运动与（在下腔的）宽度可避免误判。瓣膜置换后突然气促伴颈静脉的充盈：梗阻性，先想心包的填塞与张力性气胸与（在远处的）肺的栓塞，第一步是针对可被立即解除的机械问题（穿刺减压与（在填塞时的）开胸的准备），而不是加大血管活性药。胆管炎的分布性休克：第一步是宽的抗菌覆盖与容量的复苏与（关键的）源头的解除（在数小时内的胆道引流），因为在这里“抗生素与引流”的时序决定结局。共同的判断技巧是三问加一个反应：回心血量、泵、张力；然后看对第一步干预的反应（补液后乳酸与灌注与尿量的改变），并把“混合”的可能留在心里（脓毒症常同时有低容量与心肌的抑制与（在胆红素与（在肾功能不全时的））药物的影响）。**
:::

::: exercise 解读一份易栓症的检查 {level=2}
一名41岁的男性在近端深静脉血栓发生后的第五天（已用低分子肝素）被查出：蛋白S 偏低、抗凝血酶偏低、狼疮抗凝物的筛选阳性、因子V Leiden 阴性；他要求“查清是不是遗传”。
::: solution
**这份检查几乎没有可解释的部分（[[#def-thrombosis]]、[[clinical-skills/laboratory-tests]]）。逐项说明：急性血栓与急性的炎症会消耗蛋白S 与抗凝血酶，使两者假性偏低；低分子肝素会升高抗凝血酶的测定值而在部分方法中造成偏差（不同试剂对药物的敏感性不同），华法林则会降低蛋白C 与S 并使若干项目无法判读；狼疮的抗凝物的筛选在急性的炎症与抗凝治疗中可以假阳性，而且它的确认与（在抗磷脂抗体中的）重复必须间隔十二周以上。正确的做法是：先治血栓（按他的诱因与影像的范围定疗程），不在急性期下“遗传”的结论；若有指征（无诱因的复发、家族史、年轻的病例、抗磷脂的可能），在停抗凝后至少一个月与不在急性事件与不在妊娠时复查（选可被本地实验室规范的方法组合）；并把“结果会改变什么”预先说清（多数静脉血栓的疗程由临床而不是由遗传的结果决定，改变治疗的是抗磷脂的存在与（在少数情形中的）肿瘤的发现）。给他的一段话：现在查的项目会因血栓本身与药物而失真，所以现在做等于花钱买一个不能被解释的数字；三个月后我们按需要复查，而这期间最重要的是按疗程抗凝与压缩与活动。另外要说的是：即便真的存在蛋白C 或S 或抗凝血酶的缺乏，多数情况下它的含义也是“更容易再发”而不是“必须终身”，除非他有过复发或有多个缺陷或（在抗磷脂综合征时）有动脉的事件。**
:::

::: exercise 诊断肿胀的阴囊 {level=2}
一名64岁的男性单侧阴囊逐渐肿大三年，不透光、触不到正常的睾丸、平卧不缩小；他有腹股沟的修补史与心衰的病史。请给出鉴别与下一步。
::: solution
**先分清三个腔（[[#def-oedema]]、[[surgery/vascular-urological-surgery]]）。睾丸鞘膜的积液：阴囊的透光试验阳性（在暗室里用手筒可透红光），触不到睾丸是因为积液把它包住，平卧不缩小（与疝不同）；而腹股沟的斜疝可以进入阴囊、咳嗽有冲击感、平卧可回纳、透光的阴性（在肠管含气时不透光），且存在被嵌顿的风险。精索与附睾的病变（在囊肿与（在精索的静脉曲张时的））：静脉曲张立位时呈“一包虫”并在Valsalva 时增大，卧位消退，是年轻男性不育的常见原因之一。肿瘤：睾丸的肿块是硬的、不透明、沉重感、透光的阴性，且不能与附睾分开——任何“透不过光的阴囊肿物”都要按肿瘤处理（超声与（在阳性时的）肿瘤标志与经腹股沟的根治性切除，绝不做经阴囊的活检，因为会改变引流的淋巴与（在分期中的））局部复发的模式。他的鉴别里还有全身的因素：心衰与肝硬变与低白蛋白可以造成阴囊的水肿（双侧、凹陷、皮肤薄亮），而丝虫病与放疗与术后的淋巴损害造成不凹陷的肿胀。下一步很简单：做超声（区分积液与实质与腹股沟疝与疝的内容），并在超声之前不要穿刺放液。要提醒的两点：放液会复发并可能引入感染，若为睾丸的肿瘤则可能造成种植；正确的治疗是按病因（反复的有症状的积液做鞘膜的翻转或切除与（在疝时的）修补与（在肿瘤时的）手术），并在心衰者的阴囊水肿时治疗心衰而不是抽液。最后一条关于老年患者的沟通：阴囊的病变常常让患者羞于描述，医生需要用一句正常化的问话（“我需要看并检查这个部位，这是常规的”）与一位陪同的人员与足够的时间，否则这类可以治愈的病变会被拖延。**

为下列四位患者各选择抗凝的策略并说明理由：74岁非瓣膜性房颤且既往有卒中；机械的主动脉瓣置换后；妊娠二十周发生近端深静脉血栓；以及活动期胃癌合并下肢深静脉血栓。
::: solution
**四种情形对应四种答案（[[#def-thrombosis]]、[[blood/thrombosis-anticoagulation]]、[[pharmacology/patient-variation]]）。非瓣膜性的房颤且既往卒中：直接的口服抗凝药（按肾功能与年龄与体重选择剂量），因为它的颅内出血的风险低于华法林且无需监测；若有机械瓣或中重度的二尖瓣狭窄则不能用此类药。机械的主动脉瓣：华法林加（在若干方案中的）小剂量的阿司匹林，按瓣的类型与位置设定目标国际标准化比值并保持时间在治疗范围内的比例，因为直接的口服抗凝药在此被证明不足且有害（在试验中的）瓣的血栓更多；同时讲清妊娠时华法林的禁用与（在机械瓣的孕妇中的）低分子肝素与华法林的艰难权衡（需要专科的中心与共同的决策）。妊娠二十周的血栓：低分子肝素（按体重的调整与（在抗Xa的监测的）的个别考虑），全程用至产后至少六周且总疗程不少于十二周；不用华法林（在若干孕周的致畸与胎儿的出血）与不用直接的口服抗凝药（缺乏人类的数据）。活动期胃癌合并深静脉血栓：低分子肝素（在胃肠肿瘤中的）直接的口服抗凝药的出血与复发的权衡偏向肝素，而在（在肾的或肝的功能的障碍与（在血小板低的化疗周期中的））时按血相与（在化疗引起的）血小板的最低点调整剂量与（在必要时）暂停；并且要把“是否已知的脑的转移与（在需要内镜的处理的）病灶”作为选择的前提，因为这两者会显著改变出血的风险。共同的一句话：抗凝的选择从来不是“哪一种更好”，而是“在这个人的肾功能与肿瘤与瓣与妊娠与（在依从与费用的）现实之间，哪一种能安全地用满疗程”。**

::: exercise 读一张梗死的图 {level=2}
请为下列尸检或影像所见各推断受累的血管与时间：左室前壁与心尖变软；楔形的贫血性病灶在肾；一侧的中脑动脉区的软化伴脑疝；结肠脾曲的节段性坏死。
::: solution
**形态能同时告诉我们血管与时间（[[#def-embolism]]、[[pathology/cell-injury]]）。左室前壁与心尖：左前降支，且心尖受累提示闭塞在间隔支之后不远；时间上若呈灰白变软并有边缘的充血带，多为三至七日（此期最易发生心脏破裂与（在乳突肌的）断裂）；若已为灰白的瘢痕，则是数周至数月之前。肾的楔形贫血性梗死：肾动脉的分支的阻塞，尖端朝向皮质、底部在包膜下；来源常在左心（房颤与（在感染性心内膜炎的赘生物与（在心梗后的））室壁的血栓），若是多发且双侧要考虑心源与（在血管炎与（在的）；而“梗死加血尿加乳酸脱氢酶升高”在房颤患者中是常见的三联。中脑动脉区的大面积软化：同侧中脑动脉，恶性水肿在一至五日达峰，可致脑疝与死亡；去骨瓣减压的时机在四十八小时内（在六十万岁以内者的））的证据最强；而“脑疝”这一结局正是本节所说的肿胀与颅腔的容积的关系。结肠脾曲的节段性坏死：非阻塞性的肠系膜的缺血，发生在肠系膜上与下动脉供血的交界，诱因是低灌注在重症与在透析与（在大手术的后的）；而脾曲的梗死常伴腹痛与（在便血后的）的肠壁积气的影像。共同的一课是：梗死不是“血管堵了”这一件事，而是“血管堵了加上侧支与代谢的需求与时间”的乘积（[[cardiovascular/coronary-artery-disease]]、[[nervous-system/stroke]]、[[gastrointestinal/bowel-disease]]、[[renal/acute-kidney-injury]]）。**

::: exercise 设计一个静脉血栓栓塞的预防策略 {level=3}
请为一个每年两万台手术、含内科病房与（在急诊的）创伤与（在产科的）病房的医院设计一套静脉血栓栓塞的预防策略，并说明如何避免“为评分而评分”。
::: solution
**策略要回答四个问题，缺一不可（[[#def-thrombosis]]、[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]）。谁有风险：把风险评估嵌进入院的流程（在入院、术后、病情变化与转出时各评估一次），内科用经过验证的模型在（的）与外科用按手术与病人的分层在（（的），而不是凭印象。给什么预防：机械的（在早期活动的与（在抗凝禁忌时的）逐级加压的装置与（在若干手术中的））足底的泵）与药物的（按手术的类型与出血的风险选择低分子肝素或（在若干方案中的）小剂量的普通肝素或磺达肝癲钠，并把给药的时间与椎管内麻醉的时窗写进医嘱的模板）；产科按危险因素的组合而不是按单一因素。给多久：按风险持续在大手术的与在肿瘤的与（在脊髓的损伤后的）的延长预防是有效的，并把“出院后是否继续”写在出院用药的单据上，因为绝大多数可预防的血栓发生在出院之后。如何不被滥用：把评分变成“评分加动作加时限”，否则只是文书；对每一条被拒绝的预防记录理由在出血的风险与（在病人的拒绝中的）；对每一条高危而预防不足的情况给床旁的提示；并让护士的评估成为触发而非抄写。评价的指标要既有过程又有结局：评估的完成率与高危者的预防率与机械预防的皮肤损伤与（在出血事件的）与在（（在出院后的）三十天内的）的症状性血栓与（在已知的）可避免的死亡；同时把“筛查出来的无症状血栓”的数量单列，因为把影像的偶然发现当作品质的提升是最常见的自欺。公平与教育的一条：把患者的书面与口头的教育（症状与何时就医）纳入路径，因为多数再入院的血栓不是因为没给预防，而是因为症状被忽略了（[[surgery/perioperative-care]]、[[obstetrics-gynaecology/postnatal-period]]、[[emergency-critical-care/critical-care]]、[[public-health/screening]]）。**
