每个细胞的健康都依赖于稳定的血液供应。血液必须在血管内保持液态，不能过多地漏出血管，又必须在血管破裂时迅速凝固。本章讨论这些条件失败时会发生什么：液体逸入组织（**水肿**），血液淤积在器官中（**充血**），血液从血管逸出（**出血**），血液在不该凝固的地方凝固（**血栓形成**），物质随血流运行并阻塞远处的血管（**栓塞**），组织因失去血供而死亡（**梗死**），以及整个循环衰竭（**休克**）。

这些疾病造成了发达国家的大部分死亡和残疾。心肌梗死、卒中和肺栓塞，归根结底都是血栓形成和栓塞的问题。本章背后的生理学见[[physiology/homeostasis-body-fluids]]和[[cardiovascular/circulation-blood-pressure]]；临床处理见各器官系统课程。

## 水肿

成人瘦体重的约60%是水。其中约三分之二在细胞内；在细胞外的三分之一中，大部分位于细胞之间的组织间隙，较少部分在血浆中。液体不断地经毛细血管和微静脉壁在血浆和组织间液之间移动。

::: theorem Starling原理 {#thm-starling}
液体跨毛细血管壁的净滤过量为

$$
J_v = K_f\big[(P_c - P_i) - \sigma(\pi_c - \pi_i)\big]
$$ {#eq-starling}

其中$P_c$和$P_i$分别是毛细血管内和组织间隙的静水压，$\pi_c$和$\pi_i$分别是血浆和组织间液中蛋白质产生的胶体渗透压，$\sigma$是管壁对蛋白质的反射系数（管壁对蛋白质不通透时为1，完全通透时为0），$K_f$是滤过系数，反映管壁的面积和通透性。
:::

::: proof
静水压把水推出血管。血浆蛋白（主要是白蛋白）不易穿过管壁，因此通过渗透作用把水保留在血管内。这些力的平衡决定了净流量。传统教学认为，液体在静水压高的毛细血管动脉端滤出，在静水压较低的静脉端被重吸收。现代研究表明，在大多数组织中几乎没有稳定的重吸收，因为起作用的胶体渗透压是内皮糖萼下方的胶体渗透压，而不是整个组织间液的胶体渗透压。无论哪种观点，少量的净滤过液都由**淋巴管**送回循环。当滤过超过淋巴引流能力时，就会形成水肿。
:::

::: definition 水肿及其四种机制 {#def-oedema}
**水肿**是液体在组织间隙或体腔内的异常积聚。体腔内的液体称为**积液**（胸腔积液、心包积液）或**腹水**（腹腔）。广泛的严重水肿称为**全身水肿**（anasarca）。水肿由以下一种或多种机制引起：

1. **静水压升高**：心力衰竭、静脉阻塞（深静脉血栓形成），以及肾脏的钠水潴留。
2. 低白蛋白引起的**血浆胶体渗透压降低**：肾病综合征（从尿中丢失）、肝硬化（合成减少）、严重营养不良和蛋白丢失性胃肠病。
3. **淋巴管阻塞**（淋巴水肿）：淋巴结切除或放疗、肿瘤侵犯，以及丝虫感染。
4. **血管通透性增加**：炎症、烧伤和过敏反应。

前三种产生蛋白质含量少的**漏出液**。第四种产生富含蛋白质的**渗出液**（[[pathology/acute-inflammation]]）。
:::

水肿的影响取决于其部位。腿部水肿令人不适，但很少危险。按压时会留下缓慢恢复的凹陷（**凹陷性水肿**）；淋巴水肿富含蛋白质，后期发生纤维化，不易出现凹陷。**肺水肿**使肺泡充满液体，妨碍气体交换，因此可以致命。**脑水肿**发生在坚硬的颅腔内，使颅内压升高，可能把脑组织推入枕骨大孔（脑疝）。

1. 正常，动脉端：$(35 - 0) - (25 - 3) = 35 - 22 = 13$ mmHg，向外。
2. 正常，静脉端：$(15 - 0) - (25 - 3) = 15 - 22 = -7$ mmHg，即向内7 mmHg。
3. 低白蛋白，动脉端：$(35 - 0) - (15 - 3) = 35 - 12 = 23$ mmHg，向外。
4. 低白蛋白，静脉端：$(15 - 0) - (15 - 3) = 3$ mmHg，此时变为向外。
5. 血浆胶体渗透压降低时，液体沿毛细血管全长滤出。当这超过淋巴引流能力时，就形成水肿。实际上，随着滤出的液体增多，组织间液的胶体渗透压也会下降，从而限制了这一效应，因此低白蛋白血症引起的水肿通常只在白蛋白非常低时才出现。
:::
:::

::: example 眼睑肿胀的孩子 {#ex-nephrotic}
一名4岁男孩每天早晨眼周肿胀，现在双腿肿胀、腹部膨隆。他的尿液起泡沫。尿蛋白很高，血清白蛋白14 g/L（参考值约35至50 g/L），胆固醇升高。解释其水肿。
::: solution
1. 大量蛋白尿、低白蛋白血症、水肿和高脂血症构成**肾病综合征**。幼儿最常见的病因是微小病变病。
2. 白蛋白从尿中丢失使血浆胶体渗透压降低，于是液体沿毛细血管全长滤入组织间隙。
3. 水肿聚集在组织压低的部位：夜间平卧后的眼周，以及直立时的双腿、阴囊，并形成腹水。
4. 肾病综合征时肾脏也潴留钠，这也起了作用。两种机制产生的都是漏出液。肾脏病理见[[renal/filtration]]。
:::
:::

## 充血与淤血

两个术语都指组织内血量增加，但机制不同。

- **充血**（hyperaemia）是一个*主动*过程：小动脉扩张，流入的血液增多。组织发红、发热。见于运动中的肌肉、脸红和急性炎症。
- **淤血**（congestion）是一个*被动*过程：血液不能流出，积聚在静脉和毛细血管中。由于淤滞的血液缺氧，组织呈暗红蓝色（发绀）。见于心力衰竭和静脉阻塞。

长期淤血会损伤组织，因为灌注不良的组织处于缺氧状态。右心衰竭引起的**慢性肝淤血**中，肝小叶中央静脉扩张，其周围的肝细胞萎缩或死亡，而门管区附近氧合较好的肝细胞发生脂肪变。肝切面呈中央暗、周边淡的图案，形似槟榔（“槟榔肝”）。左心衰竭引起的**慢性肺淤血**中，红细胞漏入肺泡并被巨噬细胞分解，后者因而含有含铁血黄素；这些细胞称为“心力衰竭细胞”（[[cardiovascular/heart-failure]]）。

## 出血

**出血**是血液从血管逸出。按大小描述如下：

- **瘀点**：皮肤或黏膜的微小（1至2 mm）出血，是血小板减少或血小板功能缺陷的典型表现。
- **紫癜**：稍大（约3 mm至1 cm）的出血，见于血小板疾病、血管炎和血管脆性增加。
- **瘀斑**：较大（超过1至2 cm）的皮下出血，随着血红蛋白转变为胆红素和含铁血黄素而变色。
- **血肿**：组织内的血液积聚，可以无关紧要，在脑内则可以致命。

出血的后果取决于出血量、速度和部位。迅速丢失约五分之一的血容量即可引起休克，而同样的量在数周内缓慢丢失可能只引起缺铁性贫血。脑干的少量出血可以致死，而同样的量在大腿则无害。

## 正常止血

止血是在血管损伤部位止住出血、同时保持其他部位血液流动的过程。它分四个相互重叠的步骤进行，详见[[blood/haemostasis-bleeding]]。

1. **血管收缩**：受损血管短暂收窄。
2. **初期止血**：血小板通过**血管性血友病因子**黏附于暴露的胶原，被活化，释放其颗粒内容物（包括ADP和血栓素A₂），并通过糖蛋白IIb/IIIa受体聚集形成血小板栓子。
3. **二期止血**：损伤部位暴露的**组织因子**启动凝血级联反应，产生**凝血酶**。凝血酶把纤维蛋白原转变为**纤维蛋白**，加固血小板栓子。
4. **血凝块稳定与吸收**：纤维蛋白交联，栓子收缩。**纤维蛋白溶解**开始：纤溶酶原转变为纤溶酶，后者分解纤维蛋白。其碎片中包括**D-二聚体**。

正常内皮主动防止凝血。它覆盖其下方的胶原，产生抑制血小板的前列环素和一氧化氮，携带激活**抗凝血酶**的肝素样分子，表达使凝血酶转而激活**蛋白C**的血栓调节蛋白（蛋白C与蛋白S一起破坏因子Va和VIIIa），并分泌组织型纤溶酶原激活物。内皮损伤或活化使其转向促凝。

## 血栓形成

::: definition 血栓形成 {#def-thrombosis}
**血栓形成**是活体的心脏或完整血管内由血液成分形成固体团块（**血栓**）的过程。它不同于血**凝块**，后者在血管外或死后形成。
:::

::: theorem 菲尔绍三联征 {#thm-virchow}
三组因素易导致血栓形成：

1. **内皮损伤**或功能障碍；
2. **血流异常**：淤滞或湍流；
3. 血液**高凝状态**。

任何一项都可能足以导致血栓形成，但血栓通常是几种因素共同作用的结果。
:::

::: proof
内皮损伤暴露胶原和组织因子，内皮抗凝功能的丧失又解除了对血小板和凝血酶的制约。它在血流快速的心脏和动脉中起主导作用：血栓形成于溃疡的动脉粥样硬化斑块、心肌梗死区上方的心内膜以及受损的瓣膜。

正常血流是层流：细胞在血流中央运行，与内皮之间隔着一层血浆。湍流（见于动脉分叉处、动脉瘤内和斑块表面）损伤内皮，并形成使血小板接触血管壁的涡流。淤滞（见于不能活动者的腿部静脉或颤动的左心房）使血小板接触内皮，妨碍活化凝血因子的稀释，并减慢抑制物的流入。淤滞在静脉中起主导作用。

高凝状态是血液中任何有利于凝血的改变。遗传性因素包括凝血因子V Leiden突变（因子V对蛋白C抵抗）、凝血酶原G20210A变异，以及抗凝血酶、蛋白C和蛋白S缺乏。获得性因素要常见得多：癌、妊娠及产后数周、含雌激素的避孕药和激素替代治疗、大手术和创伤、抗磷脂综合征、肝素诱导的血小板减少症，以及肥胖。
:::

### 动脉血栓与静脉血栓

血栓因形成部位而不同。

- **动脉血栓**形成于快速流动的血液中，通常位于受损的表面，如破裂的动脉粥样硬化斑块。它们富含血小板，颜色苍白，倾向于从附着点逆向生长。它们阻塞冠状动脉、脑动脉和下肢动脉。
- **静脉血栓**形成于缓慢流动的血液中，通常位于下肢深静脉。它们富含被纤维蛋白网罗的红细胞，呈暗红色，沿血流方向朝心脏生长。其危险在于栓塞到肺。
- **附壁血栓**附着于心腔壁或主动脉壁，如梗死区上方或动脉瘤内。
- **赘生物**是心瓣膜上的血栓，可以是感染性的（感染性心内膜炎），也可以是无菌性的。

在流动血液中形成的血栓可见**Zahn线**：由血小板和纤维蛋白组成的浅色层与红细胞组成的暗色层交替排列。这些线条表明血栓是在生前形成的。死后形成的凝块柔软、呈胶冻状、暗红色，上部为红细胞沉降后留下的黄色“鸡脂样”部分；它不附着于血管壁，也没有Zahn线。

### 血栓的结局

未使患者死亡的血栓有四种结局：

1. **蔓延**：血栓增大，添加更多的血小板和纤维蛋白，并可能阻塞血管。
2. **栓塞**：血栓部分或全部脱落，随血液运行。
3. **溶解**：纤维蛋白溶解将其清除。这在新鲜血栓中最有可能发生，这就是溶栓药物只在最初几小时内有效的原因。
4. **机化和再通**：较陈旧的血栓被肉芽组织长入，成为血管壁的一部分，并可能形成部分恢复血流的新管道。

::: example 长时间手术后的小腿疼痛 {#ex-dvt}
一名66岁女性六天前接受了髋关节置换术，此后大部分时间卧床。她的左小腿现在肿胀、发热、有压痛。用菲尔绍三联征解释她为何有静脉血栓形成的风险，并概述如何评估深静脉血栓形成。
::: solution
1. **淤滞**：不能活动使小腿肌肉泵失去作用，血液淤积在下肢深静脉中。
2. **内皮损伤**：髋关节手术中的操作和体位可能损伤股静脉。
3. **高凝状态**：大手术释放组织因子，作为急性期反应的一部分，纤维蛋白原和因子VIII升高。
4. 三项因素同时存在，因此骨科手术有很高的静脉血栓栓塞风险，这就是患者在风险评估后接受血栓预防的原因。
5. 在英国，NICE指南（NG158）使用结构化的临床可能性评分（两级Wells评分）。若深静脉血栓形成可能性大，行近端下肢静脉超声检查；若可能性小，先做D-二聚体检测，D-二聚体正常则血栓形成的可能性很小。处理见[[blood/thrombosis-anticoagulation]]。
:::
:::

::: warning D-二聚体用于排除，而不是用于确诊
只要纤维蛋白被分解，就会产生D-二聚体。它在血栓形成时升高，但在手术后、感染、癌、妊娠和高龄时也会升高。在临床可能性低的人中，D-二聚体正常使血栓形成的可能性很小。刚做完手术的人D-二聚体升高几乎说明不了什么。该检测不应用于“筛查”临床可能性高的人，他们无论D-二聚体结果如何都需要影像学检查。为减少老年人的假阳性，NICE建议对50岁以上者考虑采用年龄校正的阈值。
:::

::: example 年龄校正的D-二聚体 {#ex-ddimer}
一名72岁男性的两级Wells评分提示肺栓塞可能性小。他的D-二聚体为640 µg/L FEU，实验室的标准临界值为500 µg/L FEU。对50岁以上者常用的年龄校正阈值为年龄×10 µg/L FEU。解读这一结果。
::: solution
1. 年龄校正阈值：$72 \times 10 = 720$ µg/L FEU。
2. 他的结果640 µg/L FEU高于标准临界值，但低于年龄校正阈值。
3. 在采用这种方法的诊疗路径中，临床可能性低且D-二聚体低于年龄校正阈值，即视为排除了肺栓塞，从而避免了不必要的CT肺动脉造影。
4. 这种校正之所以有效，是因为健康人的D-二聚体也随年龄升高，固定的临界值在老年人中特异性降低。当地方案必须明确检测的单位，因为有些实验室以不同的单位报告D-二聚体。
:::
:::

## 栓塞

::: definition 栓塞 {#def-embolism}
**栓子**是从其起源处脱落、随血液运行到远处、并在那里嵌塞且可能阻塞血管的固体、液体或气体团块。最常见的栓子是血栓碎片（**血栓栓塞**）。其他栓子包括脂肪、空气、羊水、动脉粥样硬化碎屑、肿瘤细胞和感染性物质。
:::

### 肺栓塞

大多数肺栓子来自下肢深静脉血栓，尤其是膝以上的静脉。栓子经过右心进入肺动脉。其影响取决于栓子的大小和循环的状态。

- 大的栓子嵌塞于肺动脉干分叉处（**骑跨性栓子**）或阻塞大部分肺循环，引起急性右心衰竭，可导致猝死。
- 中等大小的栓子阻塞中等动脉。由于肺有来自肺动脉和支气管动脉的双重血供，只有少数引起**梗死**，主要发生在循环已经受损的人，如心力衰竭患者。梗死引起胸膜性胸痛和咯血。
- 长期反复发生的许多小栓子可导致慢性血栓栓塞性肺动脉高压。

### 体循环血栓栓塞

动脉循环中的栓子通常起源于心脏：心房颤动时的左心耳、心肌梗死区上方的附壁血栓，或瓣膜赘生物。较少数来自主动脉和颈动脉的动脉粥样硬化斑块。它们嵌塞于脑（引起卒中）、下肢、肠、肾和脾。静脉血栓可以经过左右心之间的通道（如卵圆孔未闭）进入体循环：即**反常栓塞**。心房颤动作为卒中的原因见[[cardiovascular/arrhythmias]]。

### 其他栓子

- **脂肪栓塞**：股骨等长骨骨折或广泛软组织损伤后，脂肪滴进入循环。大多数病例无症状。少数人在伤后1至3天出现**脂肪栓塞综合征**，表现为气促和低氧血症、意识混乱以及上半身瘀点状皮疹。脂肪滴阻塞小血管，释放的脂肪酸损伤内皮。
- **空气栓塞**：空气经开放的静脉进入循环，例如在置入或拔除中心静脉导管时。大量空气（约100 mL量级）可在右心形成泡沫状阻塞。**减压病**发生于潜水员上浮过快时：高压下溶解在组织中的氮气析出形成气泡。
- **羊水栓塞**是分娩时罕见且常致命的并发症。羊水和胎儿细胞进入母体循环，引起突然的心肺衰竭和弥散性血管内凝血。
- **动脉粥样硬化栓塞**：常在动脉导管操作时脱落的粥样斑块碎片，嵌塞于肾、皮肤和肠的小动脉；胆固醇结晶在血管中留下针形裂隙。

::: example 股骨骨折后的意识混乱 {#ex-fat}
一名22岁男性在摩托车事故中股骨骨折。48小时后，在手术固定之前，他出现气促和意识混乱，未吸氧时血氧饱和度88%，胸部和结膜出现少量瘀点。解释可能的诊断。
::: solution
1. 发病时间（长骨骨折后一至三天）以及呼吸窘迫、神经系统改变和瘀点三联征，提示**脂肪栓塞综合征**。
2. 骨髓脂肪在骨折处进入撕裂的静脉，运行至肺，脂肪滴阻塞毛细血管。部分脂肪滴穿过肺循环或经卵圆孔未闭到达脑和皮肤。
3. 脂肪酶从脂肪中释放的游离脂肪酸损伤内皮，造成肺血管渗漏和低氧血症。瘀点反映毛细血管受损和血小板消耗。
4. 处理以支持治疗为主，长骨骨折早期固定可降低风险。也必须考虑肺血栓栓塞，但后者不太可能引起瘀点状皮疹。
:::
:::

## 梗死

::: definition 梗死 {#def-infarction}
**梗死**是由于组织的动脉供血阻塞（较少见的是静脉回流阻塞）引起的缺血性坏死区。几乎所有梗死都由血栓形成或栓塞引起。
:::

梗死按颜色分类。

- **白色（贫血性）梗死**发生于动脉阻塞且器官为单一**终末动脉**供血的实质器官：心、肾和脾。进入死亡区域的血液很少，该区域变得苍白而坚实。这类器官的梗死常呈楔形，尖端指向阻塞的血管，底部朝向器官表面。
- **红色（出血性）梗死**发生于血液持续进入死亡组织的情况：静脉阻塞后（睾丸或卵巢扭转）、能使血液积聚的疏松组织、有**双重循环**的器官（肺、肝）、先前已淤血的组织，以及血流恢复到死亡区域时。嵌顿疝中的肠梗死是红色的。

大多数器官中梗死的镜下表现为**凝固性坏死**，随后发生炎症并被瘢痕取代。在脑中，梗死产生液化性坏死（[[pathology/cell-injury]]）。

血管阻塞是否引起梗死取决于四个因素：

1. **血供的解剖**：有替代血供的器官（肺、肝、有两条动脉的手）能抵抗梗死；终末动脉供血的器官则不能。
2. **阻塞的速度**：缓慢狭窄的动脉使侧支血管得以发育，而突然阻塞则来不及。
3. **组织对缺氧的易损性**：神经元几分钟后死亡，心肌二十至三十分钟后死亡，成纤维细胞可存活数小时。
4. **血液的含氧量**：贫血或低氧血症使同等程度的阻塞更易引起梗死。

::: quiz
尸检时在肺动脉内发现一团块。它坚实、干燥，附着于血管壁，可见浅色层与暗色层交替排列。这说明什么？
- [ ] 死后形成的凝块
- [x] 生前在流动血液中形成的血栓或血栓栓子
- [ ] 脂肪栓子
- [ ] 肿瘤栓子
::: solution
血小板与纤维蛋白层和红细胞层交替排列即**Zahn线**，只在流动的血液中形成。死后凝块柔软、呈胶冻状、不附着，常有红细胞沉降后形成的黄色上层。在肺动脉中，分层的团块最可能是来自下肢静脉血栓的栓子。
:::
:::

## 弥散性血管内凝血

::: definition 弥散性血管内凝血 {#def-dic}
**弥散性血管内凝血**（DIC）是一种获得性综合征，凝血系统的广泛激活在整个微循环中形成小血栓。血小板和凝血因子被消耗，纤维蛋白溶解被激活，因此患者既有血栓形成又有出血。
:::

DIC本身不是一种疾病，而是严重基础疾病的并发症。最常见的诱因是**脓毒症**、严重**创伤**和烧伤、**产科并发症**（胎盘早剥、羊水栓塞、死胎滞留），以及**癌**，尤其是急性早幼粒细胞白血病和分泌黏液的腺癌。共同机制是组织因子或其他促凝物质释放入血，或广泛的内皮损伤。

其结果是肾、肺、脑和肾上腺中的微血栓造成器官损害，以及伤口、静脉穿刺部位和黏膜的出血。实验室检查通常显示血小板计数低，凝血酶原时间和活化部分凝血活酶时间延长，纤维蛋白原降低，D-二聚体升高，血涂片见红细胞碎片。治疗针对病因，必要时输注血液成分予以支持（[[blood/haemostasis-bleeding]]）。

## 休克

::: definition 休克 {#def-shock}
**休克**是导致组织氧输送或氧利用不足、进而引起细胞缺氧的循环衰竭。它通常但并不总是伴有低血压。按机制分类如下：

- **低血容量性休克**：失血或失液（出血、呕吐、腹泻、烧伤）。
- **心源性休克**：心脏泵功能衰竭（大面积心肌梗死、心律失常、心肌炎）。
- **梗阻性休克**：心脏充盈或射血受阻（大面积肺栓塞、张力性气胸、心脏压塞）。
- **分布性休克**：广泛的血管扩张和血管渗漏，使血容量“分布”到扩大的血管床中。原因包括**感染性休克**、**严重过敏反应**以及脊髓损伤后的**神经源性休克**。
:::

休克经历三个阶段。在**代偿期**，反射维持重要器官的灌注：交感神经系统加快心率，收缩皮肤和肠道的血管，肾脏通过肾素-血管紧张素-醛固酮系统潴留盐和水。皮肤湿冷、苍白（早期感染性休克除外，此时皮肤可能温暖）。在**进展期**，组织缺氧导致无氧代谢和**乳酸酸中毒**。酸中毒使小动脉扩张，血液淤积在微循环中，并发生内皮损伤和DIC。在**不可逆期**，细胞损伤如此广泛，以至于恢复血压也无法阻止死亡。

病理医师在许多器官中看到其后果：肾的急性肾小管损伤，肺的弥漫性肺泡损伤（急性呼吸窘迫综合征的“休克肺”），肠、脑和心的缺血性损伤，以及肾上腺出血，后者是脑膜炎球菌脓毒症的典型表现。

两个简单的床旁数值有助于识别休克。**平均动脉压**（MAP）是推动血液进入器官的平均压力，可近似为

$$
\text{MAP} \approx \text{DBP} + \tfrac{1}{3}(\text{SBP} - \text{DBP})
$$ {#eq-map}

其中SBP和DBP分别为收缩压和舒张压。**休克指数**是心率除以收缩压；大于约1的值提示明显的休克。按照Sepsis-3的定义，感染性休克需要使用血管加压药才能使MAP维持在65 mmHg或以上，且充分液体复苏后血清乳酸仍高于2 mmol/L。

::: example 被汽车撞倒的男性 {#ex-shock}
一名40岁男性被汽车撞倒后送入医院。心率128次/分，血压86/58 mmHg。他面色苍白、皮肤湿冷、意识混乱，腹部膨隆。计算MAP和休克指数，并解释其生理学。
::: solution
1. MAP $\approx 58 + \tfrac{1}{3}(86 - 58) = 58 + 9.3 \approx 67$ mmHg。
2. 休克指数 $= 128/86 \approx 1.49$，远大于1。
3. 可能的机制是内出血（很可能在腹腔内）引起的**低血容量性休克**。
4. 心率快、皮肤湿冷苍白显示交感代偿：机体正把血液从皮肤和肠道转移到脑和心脏。低血压意味着代偿正在失败，意识混乱表明脑灌注不足。
5. 接近65 mmHg的MAP看起来似乎可以接受，但在心率很快的年轻人中，它掩盖了大量失血。处理遵循创伤救治方案，以控制出血为首要任务（[[surgery/trauma]]，[[emergency-critical-care/shock-fluids]]）。
:::
:::

::: history
哈维（William Harvey）于1628年描述了血液循环。菲尔绍（Rudolf Virchow）在19世纪50年代研究肺动脉阻塞时表明，肺内的血凝块通常来自其他部位的静脉，并提出了*血栓形成*和*栓塞*这两个术语；他所考虑的三项因素后来被归纳为“菲尔绍三联征”。1875年，察恩（Friedrich Wilhelm Zahn）描述了在流动血液中形成的血栓的分层结构。1896年，斯塔林（Ernest Starling）证明跨毛细血管的液体交换取决于静水压与血浆蛋白渗透压之间的平衡。
:::

## 后续内容

本章所述的疾病在整个临床医学中反复出现。冠状动脉血栓形成和心肌梗死见[[cardiovascular/coronary-artery-disease]]，卒中见[[nervous-system/stroke]]，静脉血栓栓塞和抗凝治疗见[[blood/thrombosis-anticoagulation]]，休克的识别和治疗见[[emergency-critical-care/shock-fluids]]。

::: summary
- 跨毛细血管的液体交换遵循Starling原理。水肿由静水压升高、血浆胶体渗透压降低、淋巴管阻塞或通透性增加引起；只有最后一种产生渗出液。
- 充血是主动的（小动脉扩张）；淤血是被动的（静脉回流受阻），如右心衰竭时的槟榔肝。
- 止血包括血管收缩、血小板栓子、纤维蛋白形成和纤维蛋白溶解；正常内皮具有抗凝作用。
- 菲尔绍三联征：内皮损伤、血流异常和高凝状态。动脉血栓富含血小板，形成于受损内皮；静脉血栓富含红细胞，形成于淤滞处。
- Zahn线表明血栓是生前在流动血液中形成的。血栓可蔓延、栓塞、溶解或机化。
- 大多数栓子是血栓栓子；其他有脂肪、空气、羊水和粥样物质。下肢静脉血栓栓塞到肺；心脏血栓栓塞到脑和四肢。
- 终末动脉供血的实质器官发生白色梗死；双重血供的器官、静脉阻塞后和再灌注后发生红色梗死。
- DIC是广泛的微血栓消耗血小板和凝血因子，同时引起血栓形成和出血。
- 休克分为低血容量性、心源性、梗阻性和分布性，经历代偿期、进展期和不可逆期。
:::

用$\text{DBP} + \tfrac{1}{3}(\text{SBP} - \text{DBP})$估算血压90/60 mmHg时的平均动脉压（mmHg）。给出精确值。
::: solution
$60 + \tfrac{1}{3}(90 - 60) = 60 + 10 = 70$ mmHg。

::: exercise 说出水肿的机制 {level=1}
给出以下各项水肿的主要Starling机制：(a) 腋窝淋巴结清扫后的手臂肿胀；(b) 右心衰竭时的踝部水肿；(c) 肝硬化时的腹水；(d) 扭伤后肿胀的踝关节。
::: solution
(a) 淋巴管阻塞。(b) 静脉压升高引起的毛细血管静水压升高，加上肾脏钠潴留。(c) 主要是白蛋白合成减少引起的血浆胶体渗透压降低，同时有门静脉压升高和钠潴留。(d) 炎症引起的血管通透性增加。

对以下休克进行分类：(a) 张力性气胸的男性；(b) 对蜂蜇发生严重反应的女性；(c) 大面积前壁心肌梗死的男性；(d) 胃肠炎致严重脱水的儿童；(e) 患肺炎、补液后血压仍下降的女性。

::: exercise 休克指数 {level=2 check="round(115/92*100)/100"}
一名产妇产后两小时心率115次/分，血压92/60 mmHg。计算她的休克指数（保留两位小数）并加以解读。
::: solution
$115/92 = 1.25$。休克指数大于约1提示明显失血。在产后，这应促使立即评估产后出血，因为年轻女性代偿能力强，血压可能很晚才下降。
:::

::: exercise 静脉端的Starling力 {level=2 check="-2"}
在毛细血管静脉端，$P_c = 18$ mmHg，$P_i = 0$，$\pi_c = 23$ mmHg，$\pi_i = 3$ mmHg，$\sigma = 1$。计算净滤过压（mmHg，正值表示向外）。给出精确值。
::: solution
$(18 - 0) - (23 - 3) = 18 - 20 = -2$ mmHg：一个小的向内压力。

::: exercise 红色还是白色？ {level=2}
预测以下梗死是红色还是白色，并解释：(a) 心内膜炎栓子引起的脾梗死；(b) 心力衰竭患者的肺梗死；(c) 嵌顿疝中的小肠；(d) 心房颤动栓子引起的肾梗死。
::: solution
(a) 白色：终末动脉供血的实质器官。(b) 红色：肺有双重循环且处于淤血状态，因此支气管动脉的血液流入死亡区域。(c) 红色：嵌顿时静脉回流首先受阻，而且肠是有侧支供血的疏松组织。(d) 白色：肾由终末动脉供血。
:::

::: exercise 年轻女性反复血栓形成 {level=3}
一名29岁女性曾患深静脉血栓形成，两次在妊娠10周后流产，现在又发生短暂性脑缺血发作。她的血小板计数轻度降低，APTT延长。提出最可能的诊断，解释一个容易形成血栓的人凝血时间反而延长这一矛盾，并说明哪些检查可以确诊。
::: hint
想一想伴有抗体的获得性高凝状态。
:::
::: solution
可能的诊断是**抗磷脂综合征**：伴有持续抗磷脂抗体的静脉和动脉血栓形成及病理妊娠。这些抗体（狼疮抗凝物、抗心磷脂抗体和抗β2糖蛋白I抗体）与磷脂-蛋白复合物结合。在试管中，它们干扰凝血反应赖以组装的磷脂，因此APTT延长；这就是该抗体被称为狼疮*抗凝物*的原因。相反，在体内它们活化内皮、血小板和补体，促进血栓形成。确诊需要间隔至少12周的两次检测均为阳性。它可单独发生，也可伴发于系统性红斑狼疮。处理由专科进行，包括抗凝治疗，妊娠期需特别注意。
:::
:::

::: exercise 长途旅行后的晕倒 {level=3}
一名54岁男性曾接受结肠癌治疗，在经过12小时的飞行后于机场晕倒。他气促，心率124次/分，血压80/50 mmHg，颈静脉怒张。从菲尔绍三联征到休克，解释最可能的事件序列，并说出休克的类型。
::: solution
长时间坐着造成下肢静脉**淤滞**；**癌**通过组织因子等肿瘤促凝物质使血液处于高凝状态；长途飞行中的脱水也可能起作用。下肢形成深静脉血栓，其一部分脱落成为栓子。栓子经过右心，嵌塞于肺动脉主干，阻塞了大部分肺循环。右心室无法对抗这一阻塞而泵血，于是扩张并衰竭，颈静脉怒张，左心室充盈减少，心输出量崩溃。这是大面积肺栓塞引起的**梗阻性休克**。这是一种医疗急症，按照现行指南清除或溶解血栓的治疗可能挽救生命。
:::
:::
