胸腔是装在盒子里的两只气球加一台泵，其临床要点几乎全部来自三个事实：肺对抗着一个并非由它自己产生的压力做功；心坐在两肺之间、有自己防水的隔间；而这个盒子的壁、底和盖是以让遗忘者上当的方式与腹、颈和上肢共享的。胸膜液让肺得以滑动；肋膈隐窝是液体积聚之处；纵隔是一张各有其急症的分区清单；膈的三个裂孔则是全身最常考的三组关系。

本章讲授胸壁与胸膜腔、肺及其肺段、纵隔、心与心包、大血管与膈——并全程应用[[anatomy/anatomical-language]]中的影像约定。

## 胸壁与胸膜腔

::: definition 胸壁 {#def-wall}
胸壁即胸廓（12肋、胸骨、胸椎）、其**三层**肋间肌——肋间外肌（纤维行向前下，“手插口袋”）、肋间内肌（行向后下）、最内层（胸横肌与肋间最内肌）——**胸内筋膜**与**壁胸膜**，其外为血管神经平面。每个肋间隙在**上位肋下缘的肋沟**内走行**静脉、动脉与神经**（VAN，自上而下），另有一较小的分支沿下位肋的上缘行走。肋间隙前方经胸骨后动脉（乳房内动脉）引流至胸骨软骨后方，后方经奇静脉系统引流——这一关系使胸骨后动脉成为胸部最危险的出血源，也是冠脉外科最有用的桥血管。
:::

壁胸膜由肋间神经（周边部）与膈神经（膈中央部及纵隔胸膜）密集支配；脏胸膜与肺实质无痛觉纤维，这就是为什么活检肺组织边缘毫无感觉而胸膜剥离却疼痛剧烈，为什么胸膜性疼痛尖锐而局限——而当膈中央部受累时——经膈神经**牵涉至C3–5皮节的肩部**（Kehr征，与膈下脓肿或脾破裂的牵涉相同，由膈下的同一根神经达成）。

::: definition 胸膜反折与隐窝 {#def-pleura}
**肋胸膜**贴胸壁，**纵隔胸膜**贴纵隔，**膈胸膜**贴膈；反折是两个壁部区域相遇之处。肺缘达不到胸膜反折线，其间的间隙——**肋膈隐窝**——正常时只含潜在腔隙与一薄层润滑液，是直立患者游离液体最先积聚之处。经典的体表投影线（锁骨中线、腋中线、脊柱旁线）：**肺下缘**分别平对第8、10、12肋；**胸膜反折**平第6肋（内侧平剑胸结合高度）、8与10肋——全程比肺低**两肋**，这就是“听诊胸部干燥”与“隐窝空虚”是两个不同陈述的原因。胸骨后的**肋纵隔隐窝**对气体和少量积液起着同样的作用。
:::

::: example 安全的胸腔穿刺 {#ex-thoracentesis}
拟在内科病房引流一2 L右侧胸腔积液。
::: solution
解剖学会替你写出核查清单。让患者坐起并身体前倾——液体落入**低位的肋膈隐窝**。找到**肋骨的上缘**，而不是上位肋骨间隙的下缘：肋间神经、动脉与静脉走在**上位肋下缘**的肋沟内，因此贴着肋上缘进针是从血管神经束的下方通过，而非穿过它（下位肋上缘的分支细小多变——接受这份剩余风险）。瞄准**后腋线或肩胛线的第7–9肋间**，超声确认：超声既能选定液袋又能测量液深，英国胸科学会的实践是不成像不穿刺，因为对基底部积液盲穿有**经抬高的膈穿入肝或脾**的危险——患侧膈可以高到乳头水平。缓慢抽吸，遇疼痛、咳嗽或测压表到底即停：一次抽液超过1.5 L后的**复张性肺水肿**，正是指南限定抽液量的原因，也是患者的咳嗽成为有用体征的原因。进针路径由外向内即本课的教学大纲：皮肤→浅筋膜→前锯肌/外来肌层→三层肋间肌→胸内筋膜→壁胸膜→胸膜腔——恰在该肋上缘、且仅在处——避开血管神经束穿过肋间隙。
:::
:::

::: history
脓胸是最古老的外科疾病之一：希波克拉底文集记述了胸部积液的对口引流与排出，而军事外科在穿透性胸部损伤几乎必死于感染的几个世纪里延续了胸腔引流。现代的规则——肋上缘、低位隐窝、超声引导、限量抽液——条条都有代价：肋间引流在创伤外科的地位由两次世界大战的胸科单位奠定；从盲穿到超声引导胸膜操作的转变则由1990—2000年代的对照系列研究推动，它们显示了有多少“安全”标志下面藏着抬高的膈或萎陷的肺。
:::

## 肺、气道与支气管肺段

::: definition 肺及其气道 {#def-lungs}
**右主支气管**比左侧更粗、更短、更垂直——这是误吸物偏好右侧的原因，也是右肺通气味略更多的原因。气管在**胸骨角（T4/5）**分为两侧；右支气管在入肺门前于肺动脉上方发出**动脉上（上叶）支气管**——“artery上”即其定义，而左上位叶支气管位于其动脉的下方（动脉下）。各主支气管再分为**支气管肺段**——右侧10段，左侧8–10段（多对肺段共干）——为各具肺段支气管、肺段动脉与结缔组织隔的锥形单位，段**间无动脉吻合**；静脉则相反，行于**段间平面**，每条引流两个肺段。肺实质本身是一棵不断分支的上皮树——传导气道至终末细支气管（无气体交换），呼吸细支气管与肺泡管至约3亿个肺泡——其血供、神经支配与淋巴引流见[[respiratory/mechanics-breathing]]。
:::

肺段结构是胸外科医生能切除恶性肿瘤所在肺段而保留其余部分的原因：**肺段切除术**沿段间平面进行——先结扎肺段支气管后膨胀肺（病变段保持萎陷，形成“膨胀-萎陷线”），以标志边界的段间静脉定位。这也是感染倾向于尊重肺段界限的原因，以及胸片上的后基底实变可以对应到一个具名肺段与一个具名支气管、值得在支气管镜下追查的原因。

::: example 误吸的花生 {#ex-aspiration}
一名两岁幼儿吞食花生呛咳20分钟后送来；间断咳嗽，右侧呼吸音减低，以右下胸最响的哮鸣。胸片报告“正常；呼气未见空气潴留”。
::: solution
X线不能排除诊断；解剖预示该在哪里找，生理说明为什么早期片可以正常。花生极可能已通过右主支气管，停在**右中间支气管或下叶肺段支气管**：幼儿气道足够细，一颗花生可阻塞一个肺叶支气管，而梗阻又可起**活瓣**作用——吸气时跨肺压为正，空气挤过花生进入，呼气则被阻挡——这种过度充气出现在呼气相或侧位片上，而不是吸气相的正位片上。幼儿持续的单侧过度充气或对支气管扩张剂无反应的固定哮鸣，属于**硬管或软管支气管镜**的领地：必须取出（植物性异物——花生的油分数日内引起剧烈的化学性支气管炎，使取出更难、肺段损伤更重）。教训：误吸是病史加解剖的诊断，“X线正常”回答的是一个没人问过的问题。
:::
:::

## 纵隔及其分区

::: definition 纵隔的分区与内容 {#def-mediastinum}
**纵隔**是两胸膜囊之间自胸骨至椎前的间隙，在**胸骨角平面（胸骨角至T4/5椎间盘）**分为**上纵隔**（上：大血管、气管、食管、胸导管、胸腺残迹）与**下纵隔**；后者以心包再分为**前**（疏松组织、残迹、淋巴——经典“4T”之地：胸腺瘤、畸胎瘤/生殖细胞瘤、“可怕的”淋巴瘤、甲状腺）、**中**（心、心包、肺根、膈神经）与**后纵隔**（降主动脉、奇静脉与半奇静脉系统、食管、胸导管、迷走神经、交感干）。此平面绝非纸上谈兵：主动脉弓在此起始，气管在此分叉，胸导管在此左跨，奇静脉静脉在此弓过右肺根注入上腔静脉。
:::

肺**根**由与纵隔胸膜连续的反折固定；其内容排列是考试点名常客，也是外科方位学：**右侧**支气管在后，肺动脉在前，肺静脉在下前方（**RALS**：**R**ight侧肺**A**rtery在支气管之**A**nterior；**L**eft侧则在其**S**uperior）；肺门结构被**支气管肺淋巴结**环绕，这就是结核与结节病使其增大、以及此处癌肿在转移途中必经纵隔淋巴结分站的原因。

::: example 心尖？不，肺尖的肿瘤 {#ex-pancoast}
一名62岁吸烟者右肩与肩胛痛3个月，右手小肌肉萎缩，右眼睑下垂伴瞳孔缩小，声音嘶哑。
::: solution
每个体征定位到一个纵隔-肢体界面，而合起来定位到一平方厘米——肺尖的**上沟瘤（Pancoast瘤）**。**Horner综合征**（上睑下垂、瞳孔缩小、无汗）是**星状神经节/颈交感链**在C8–T1水平被后内侧侵犯；**C8–T1疼痛与手内在肌萎缩**是越过第1肋颈的**臂丛下干**；**声嘶**是**右喉返神经**在锁骨后方绕锁骨下动脉的沟内受累（左侧神经在主动脉弓下折返，故左侧声带麻痹要想到主动脉与纵隔病因——主肺动脉窗的病变）。除非证实否则即为肺尖癌，其分期逻辑是纵隔的：淋巴结分站与大血管决定外科医生能切到哪里。Pancoast瘤以同步放化疗处理，可切除时行连同胸壁、偶及椎体的扩大切除——所以解剖学上的三个名字（交感链、下干、喉返神经）同时就是预后：眼睑与瞳孔可以切除；瘫痪的手与嘶哑的声带是根治手术的边界。
:::
:::

::: warning 胸导管与乳糜胸
**胸导管**起自**乳糜池**（L2水平，膈脚后方），经主动脉裂孔（在主动脉与奇静脉之间）进入后纵隔，右侧上行，约在T5交叉至左，注入**左颈内静脉与左锁骨下静脉汇合处**。损伤致胸腔内出现**乳糜**——白色、富含甘油三酯、免疫学代价高昂——经典见于食管切除或胸部创伤之后，积液侧别随胸导管的交叉而定（T5以下在右，以上在左）。识别它是一道液体分析题（胸液甘油三酯），处理它则是外科手术：胸导管结扎术，术前解剖是示意图上的一条线，术野即上文所述的后纵隔。
:::

## 心、心包与听诊区

::: definition 胸腔中的心 {#def-heart}
心位于**中纵隔**，旋转到这样一副姿态：**右心室构成大部分前面（胸肋面）**，**左心室构成左缘与心尖**（左侧第5肋间、锁骨中线——心尖搏动），**左心房构成后面**（紧挨食管前方，故巨大左房可致吞咽困难，也故有经食管超声心动图的视角），**右心房构成右缘**。**心底**（后上，主要为左房）接受肺静脉；**心尖**即心室尖。四个瓣膜同处一个朝前偏右的平面，但血流沿来流方向通过它们，因此其**听诊区**在水流抵达胸壁之处——主动脉区右第2肋间（升主动脉的血流线），**肺动脉区**左第2肋间，**三尖瓣区**胸骨体左下缘，**二尖瓣区**心尖。
:::

::: theorem 听其下游，不听其门 {#thm-downstream}
瓣膜音沿其产生的射流方向传导，因此瓣膜的体表投影（其解剖环在胸骨后被投射的位置）与其听诊区（血流中的下游）不同。主动脉瓣位于胸骨中部后方、约平第3肋软骨；主动脉瓣狭窄在右第2肋间听诊最响并向颈动脉传导，因为收缩期射流正朝那个方向去。
:::

::: proof
取两个极端。**二尖瓣**环在卧位患者约投射于T7–8胸骨后；但其病变却在**心尖**判断，因为关闭不全的反流束被心室收缩推向后外——而在**腋下与背部**听到，是因为后叶连枷时射流指向前、冲入左房腔并经其出口冲出，股湍流恰在腋下与肩胛间区可闻。**主动脉瓣狭窄**沿颈动脉向上放射——同样是这一物理事实，使超声医生在心窗不佳时把多普勒取样放进颈部——而肥厚型心肌病的收缩期杂音沿左室流出道向基底部产生、又因晚期的动态梗阻而变异，在其间听到，并随减少前负荷的动作而增强。换言之，体表解剖就是一股射流投射到胸壁上的物理学。唯一真正的规则是听诊者的地图：主动脉右第2肋间，肺动脉左第2肋间，三尖瓣左第4–5肋胸骨旁，二尖瓣左第5肋锁骨中线——而每个名字之所以坐落在那里，靠的是这条定理，而非瓣膜的地理。
:::

::: definition 心包 {#def-pericardium}
**纤维心包**是不易扩张的囊，下方与膈中心腱连续，上方与大血管外膜连续，内衬**浆膜心包**——壁层（与纤维层相贴）与脏层（**心外膜**，贴于心表面）——其间潜在腔隙含10–50 mL液体。其不可扩张性就是填塞生理的全部：液体**快速**积聚（创伤后积血、游离破裂、夹层破入心包）使心包内压陡升，右房右室舒张充盈失败，**Beck三联征**——低血压、心音遥远、颈静脉压升高——描述了这种崩溃；液体**缓慢**积聚（肿瘤、尿毒症、甲减）可容数升而仅有呼吸困难，最早的电学征象（低电压、心在液体囊中摆动产生的**电交替**）先于血流动力学改变。疼痛来自**膈神经支配的壁层心包**，这就是急性心包炎向斜方肌嵴放射的原因——具诊断特异性，因为只有膈神经的牵涉才能到达C3–5的那片皮肤。
:::

::: example 颈静脉说“不是气胸” {#ex-tamponade}
道路交通事故，胸部闭合性损伤，收缩压80 mmHg，心率130次/分，双侧呼吸音等清，颈静脉怒张，心音遥远。
::: solution
这是**伴填塞三联征的梗阻性休克**，解剖决定即刻处置。呼吸音等清排除了张力性气胸（另一种梗阻性休克急症——同样低血压、颈静脉怒张，但患侧**呼吸音消失、气管移位**）；无血胸的浊音；心音遥远凑齐三联征。处理是**心包减压**——针吸心包穿刺术（剑突下进针、朝向左肩，针经中心腱到达右心室前面，避开两肺前缘与胸骨后血管）作为桥梁；若心搏骤停则行**开胸或复苏性正中切开**，因为伴填塞的钝性或穿透伤通常意味着一个需要缝合而非引流的出血腔。与此相关的外科事实：心脏前面可在不进入任何一侧胸膜的情况下到达（心包在胸骨下段后方裸出——正是这块“裸区”使剑突下与腋前外侧开胸路径成为可能），而胸骨正下方的心腔首先是右心室——针与外科医生手指到达的正是那里。
:::
:::

心自身的血供沿沟走行：**右冠状动脉**在右房室沟内，85%发出**下（后）降支**（右优势型），约60%供血**窦房结**、约90%供血**房室结**——这是**下壁心肌梗死**以心动过缓与房室传导阻滞发病的解剖学原因；沿前室间沟下行的**左前降支**供应室间隔大部（其闭塞导致伴束支传导阻滞与心尖室壁瘤的前壁梗死）；在左房室沟内的**左回旋支**供应侧壁（其闭塞即“电学安静”的侧壁梗死）。静脉回流主要经后房室沟内的**冠状窦**入右心房——左侧起搏电极与心脏停搏液插管的目标。

## 大血管、淋巴与膈

**主动脉弓**（T4/5平面，自右头臂静脉形成处至动脉韧带处的降主动脉）依次发出**头臂干、左颈总动脉、左锁骨下动脉**；其分支与邻接关系解释了主动脉瘤的压迫症状目录——上腔静脉阻塞、吞咽困难（食管）、声嘶（左喉返神经）、肋骨侵蚀。**胸主动脉**在正中左侧下行，至T12跨回中线，发出肋间后动脉（其扩张的侧支在主动脉缩窄时造成肋切迹）、支气管支、食管支与心包支。成人型主动脉缩窄多位于动脉韧带附近**峡部**或其稍远处——由此才有使肋间动脉扩张的侧支，以及桡-股动脉延迟与桡-桡比较：摸到的脉搏对比对比，字面上就是主动脉弓的分支与其降部延续的对比。

::: definition 膈及其裂孔 {#def-hiatus}
肌性膈有**中心腱**（未来的腱来自横膈膜隔）、**胸骨部、肋骨部与腰部**（腰部纤维在腰大肌与腰方肌上方形成**内、中、外弓状韧带**），由**膈神经（C3–5）**支配，中央面感觉亦归膈神经、周边部归肋间神经。三个大裂孔：

| 裂孔 | 平面 | 通过结构 |
|---|---|---|
| **腔静脉孔（中心腱）** | **T8** | 下腔静脉、右膈神经 |
| **食管裂孔（右膈脚）** | **T10** | 食管、迷走神经干 |
| **主动脉裂孔（内弓状韧带后方）** | **T12** | 主动脉；胸导管与奇静脉经韧带后方通过，并非“穿过”裂孔 |

记忆法：**腔静脉**（vena cava，8个字母）在**T8**，**食管**（oesophagus，10个字母）在**T10**，**主动脉裂孔**（aortic hiatus，12个字母）在**T12**——但要记住主动脉并非真正“穿过”肌肉，这就是膈肌脚水平主动脉损伤属腹膜后/纵隔之事、胸导管与奇静脉在韧带后方与主动脉同行原因。
:::

::: example 肩痛与放错位置的洞 {#ex-hiatus}
一名70岁患者慢性餐后胸骨后烧灼与反流，钡餐见膈上有胃皱襞；另一名患者钝性外伤后40年，出现胸腔内肠鸣音。
::: solution
第一例是**裂孔疝**，其两型就是食管裂孔本身的解剖：**滑动型**（95%）食管胃连接部经松弛的膈食管膜上移，贲门随之而上——抗反流装置（左膈脚的袢、His锐角、腹内段）被废用，反流随之而来；**食管旁型**连接部原位不动而胃底从其旁疝入——危险不是反流而是**胃扭转与绞窄**，这就是有症状的大食管旁疝要修补、无症状的滑动型可不修的原因。第二例那位陈旧机动车事故后“胸腔内肠鸣音”的患者是**膈疝（膈破裂）**，多位于左侧（右侧有肝保护），初次受伤时漏诊——破口在肌肉上，超声与平片都不是好的追问者——多年后腹腔脏器疝入胸腔并绞窄才暴露真容：一张见胃管在膈上盘曲的胸片即可终结争论，而修补需要经腹或经胸，不是内镜。两例都系于T10食管裂孔的设计：一个肌性环，只有当它的膈脚、其膜与其压力协同工作时才是称职的。
:::

::: quiz
后前位胸片上，心左缘下份主要由哪个结构构成？
- [ ] 左心耳
- [x] 左心室
- [ ] 右心室
- [ ] 肺动脉干

正位片心左缘自上而下：**主动脉结、肺动脉干、左心耳（小）、左心室**——心室独占其下2/3，心尖是其最低点。**右缘**为**右心房**（下半）与上腔静脉（上部），这就是正位片心影增大意味着“左房向右推挤”（双房影）或心室延续左缘的原因；也是右心室——前面最大的部分——在**心缘上根本看不到**、只能在侧位片上以胸骨后间隙填塞表现的原因。听诊规则在影像上再次适用：表面轮廓是心腔贴肺之处，而非心腔所在之处。

## 通向何处

通气力学与胸膜压在[[respiratory/mechanics-breathing]]；心动周期与压力曲线在[[cardiovascular/cardiac-cycle]]；传导系统的外科邻接在[[cardiovascular/electrophysiology-ecg]]；食管行程在[[gastrointestinal/oesophagus-stomach]]；乳腺（一个有其自身淋巴地理的胸壁结构）在[[surgery/breast-endocrine-surgery]]。

::: summary
- 肋间束走在上位肋下缘的肋沟内：贴下位肋的上缘进针即可避开——安全引流与神经阻滞的基础。
- 胸膜反折全程比肺低两肋：隐窝是真实的空间，液体先积于此，而膈的高度使“安全”线没有超声就不安全。
- 气道解剖是误吸（右、垂直、粗）与手术（各有支气管与动脉的肺段、静脉行于其间）的命运；支气管镜与肺段切除是应用化的肺段解剖。
- 纵隔是一张分区清单，其综合征是压迫效应：肺尖的Pancoast、主肺动脉窗的喉返神经、胸导管交叉处的乳糜胸、食管后左房增大致的吞咽困难。
- 心的表面、心腔、听诊区与心影轮廓，都是同一个旋转了的心从不同方向的所见；听下游，看贴肺的那条缘，按神经牵涉（膈神经→肩，T1→前臂，肋间→带状）。
- 膈：T8腔静脉在其腱内，T10食管在右膈脚，T12主动脉在内弓状韧带之后——裂孔的设计同时解释了反流与绞窄性食管旁疝。
:::

## 练习

::: exercise 神经的行程 {level=1}
自核至喉描绘左喉返神经的行程，并列出使左声带麻痹的三种病变。
::: solution
核在延髓的**疑核**→迷走神经经颈静脉孔出颅→在颈动脉鞘内下行→在**动脉韧带后方**跨过主动脉弓，在此绕弓折返、沿气管食管沟上行→支配除环甲肌（喉上神经）以外的全部喉内肌→声门裂以下感觉。三种左侧声带病变：**主动脉弓动脉瘤或夹层**（韧带处）、主肺动脉窗的**肺尖/纵隔肺或淋巴结恶性肿瘤**、以及**甲状腺手术**（神经在Berry韧带旁的沟内关系——内分泌解剖上最著名的外科关系）。单侧麻痹表现为声嘶与咳嗽无力；双侧麻痹是气道急症，声带居中间位。
:::

::: exercise 胸片的边缘 {level=1}
说出增大后产生以下影像的结构：(a)心右缘双密度影；(b)左肺门“肺动脉结”影突出；(c)侧位片右侧气管角消失伴胸骨后密度增高；(d)气管隆突增角。
::: solution
(a)**左心房**——食管后方的心腔向右突出成双房影（二尖瓣狭窄时其耳部使左缘中段膨隆）；以侧位/钡餐见食管受压确认。(b)**主肺动脉或左肺动脉**扩张（肺动脉高压、左向右分流）。(c)**右心室增大**在侧位片填塞胸骨后间隙；(d)气管隆突增角（>100°）再次指向**左房增大**——隆突正居左房“屋顶”之上——或隆突下淋巴结（结核、淋巴瘤、转移）。每个答案都是经由其肺界面读出的一个心腔或血管：X线看见的是表面，而本章的心腔地理学把表面还原为体积。
:::

::: exercise 管子会到哪里？ {level=1}
在右第5肋间、腋前线、“贴肋”置入胸腔引流管。单纯积液时此处对气与液皆可接受；描述你管路穿经的结构，以及过低时危险的两个结构、过高时危险的一个结构。
::: solution
路径：皮肤→浅筋膜→背阔肌/前锯肌所在的胸壁→肋间外、内、最内肌→胸内筋膜→壁胸膜→胸膜腔，贴着**下位肋的上缘**以避开VAN束。过低（低于穹顶，呼吸窘迫患者的穹顶在腋中线可达第5肋间）：右侧为**肝**，左侧为**脾**；过高过前：当管子被插入实变或粘连的肺而非游离腔隙时，**肺实质**即危险——故有指检先行原则（检查手指能区分肺表面、粘连与空腔）与影像原则（穹顶在膈肌所在之处，不在教科书所说之处）。同一个答案也点出了下位肋上缘分支的剩余风险：一根小血管、一位凝血障碍患者更大的血肿，以及为何在有时间的情况下肋间引流要先纠正凝血。
:::

::: exercise 供血区与节律 {level=2}
一起下壁ST段抬高心肌梗死（II、III、aVF抬高）出现2:1房室传导阻滞伴交界性逸搏45次/分。涉及哪支动脉？阻滞的解剖学解释是什么？
::: solution
**右冠状动脉**（在约85%的右优势型供血区，下壁；且约90%的**房室结动脉**起于十字交叉处）。房室结由后降支/后房室沟区的房室结支供血，故下壁梗死造成**结缺血、阻滞在结**——窄QRS、交界性或低位心房逸搏，多为一过性、阿托平有反应，常伴迷走张力增高（Bezold-Jarisch反射）。对照：前壁梗死伴新发右束支传导阻滞意味着**希氏束以下**损害（间隔穿支）、宽QRS逸搏、预后不良需起搏——同一个节律标签（“房室阻滞”）两副解剖故事，这就是为何决定处理的是心电图的QRS宽度与梗死供血区，而非阻滞比例。
:::
:::

::: exercise 增宽的纵隔 {level=2}
一张钝性创伤的胸片显示上纵隔增宽。列出解剖学上成立的鉴别诊断（五条），并说出使创伤性主动脉损伤成为第一个必须排除项的那个解剖事实。
::: solution
鉴别：**峡部的主动脉损伤**；胸骨/肋骨骨折或脊柱损伤所致纵隔血肿；大静脉扩张（仰卧、紧张患者——体位性假性增宽）；胸腺（幼儿）；淋巴结增大（偶见）；食管破裂伴纵隔气体。那个解剖事实：主动脉被**动脉韧带**与膈固定，减速伤使剪切力集中于峡部——创伤性破裂的经典部位——其被包裹的纵隔血肿是游离破入胸腔致死之前唯一的影像学征象。处理循解剖而行：CT血管成像（弓内对比剂，动脉期追峡部）；一旦确诊，在腔内修复之前先控制血压（降低dP/dt）——而弓的分支清单决定覆膜支架如何着陆、左锁骨下动脉是否需被覆盖或血运重建。
:::

::: exercise 无脉的胸 {level=2}
一名30岁患者上肢血压190/100 mmHg，下肢收缩压120 mmHg，桡-股动脉延迟，向左肩胛间区的收缩期杂音；胸片示第6–8肋下缘切迹。各用一句话解释每条所见。
::: solution
这是**主动脉缩窄**，典型位置在左锁骨下动脉之后不久的峡部：(1)上肢高血压是狭窄迫使左心室产生的上游压力；(2)下肢相对低血压是下游压力；(3)桡-股延迟是脉搏经侧支与窄段到达的时间差；(4)肩胛间区杂音是流经缩窄处及其侧支的血流，在主动脉走行处被听到；(5)肋切迹是**扩张、搏动的肋间后动脉**（经胸骨内动脉→肋间前动脉→肋间后动脉绕过梗阻的主动脉-主动脉通路）侵蚀肋骨下缘——X线对侧支解剖的自拍，也是患者开胸时为何出血如注、外科医生的术前地图为何是本章所画那段肋间故事的原因。
:::

::: exercise 按神经定位疼痛 {level=2}
指出神经与节段解释下列牵涉痛：(a)膈中央部受刺激→肩尖；(b)心肌缺血→左上臂内侧；(c)肺下叶胸膜炎→上腹；(d)Pancoast瘤→臂内侧。
::: solution
(a)**膈神经，C3–5**——肩上部锁骨上区皮肤为C3–4（锁骨上神经），同一节段，故有Kehr征（脾破裂、膈下脓肿、心包炎）。(b)心脏传入经**T1–T5**（主要T1–4，经交感链与颈中/下神经节至星状神经节），与上臂内侧**T1/肋臂神经、臂内侧皮神经（T1–2）**区重叠——疼痛越至尺侧前臂与小指，因皮节共享脊髓节段。(c)下胸部肋部壁胸膜由**肋间神经下部（T7–12）**支配，节段同时支配腹壁，皮层将其与内脏痛混淆——第6肋以上的胸膜炎鲜少牵涉至上腹（上位肋间神经留在胸段皮节），这是要记住的鉴别界线。(d)肿瘤侵犯**臂丛下干（C8–T1）**，其分布区为前臂与手的尺侧——与心脏牵涉同一组节段，但**肌萎缩、Horner征与可触及的肺尖病变**把它标记为外科而非内脏问题。
:::

::: exercise 为操作做解剖规划 {level=3}
一名18岁原发自发性气胸（30%）患者先抽气，失败后改行胸腔闭式引流与胸膜固定术。为每一步论证其解剖：穿刺点、置管点、胸膜固定的前提，以及替代方案（胸腔镜肺大疱切除）的两大远期解剖风险。
::: solution
抽气：**第2肋间、锁骨中线**——直立患者的心尖游离气体，而肺前缘贴胸骨缘，过低或过内的针会进入肋纵隔隐窝而非胸膜腔，胸骨后血管正位于胸骨缘外侧一横指（留在其外）。置管：**第5肋间、腋前至腋中线、“安全三角”内**（前为胸大肌外侧缘，后为背阔肌外侧缘，顶在乳头连线——男性平第4肋间，女乳房下）——此区胸壁的肋间动脉前支缺如、无腋尾之虞，即使仰卧引流管也居于胸膜腔引流气体的依赖区。胸膜固定只有在**肺完全复张**使脏壁两层胸膜贴合时才有效——必须先消灭间隙，滑石才能让两个面发炎粘连——故有引流管位置与负压之设，以及复张失败（“肺锁”）迫令剥脱术。同一解剖框架内的手术风险：胸腔镜切除肺尖肺大疱，后方危险**星状神经节与交感链（Horner征）**，内侧危险**胸骨后血管**；术后沿引流管路径或穿刺孔的肋间神经痛，是这一入镜的已知代价——一根具名的神经，在一个具名的间隙，遵循本章每一根针都遵循的同一规则：识束、贴肋、敬膈。
:::
