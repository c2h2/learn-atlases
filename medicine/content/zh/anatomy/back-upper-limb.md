背部与上肢是一个功能单位：一根直立传重的柱、一副把抓握终端摆位到各处的肌吊带，以及一张绷在其间、每个具名驿站都可能受伤的神经丛。临床上这一对按三个故事教：脊柱与其椎间盘（背痛、根性病变、今天必须减压的马尾）、臂丛及其终末神经（每条各有一处骨折、一处卡压与一张签名手），以及手的间隙（感染与肿胀在这里服从筋膜几何，而夹板与手术之别就在这里的解剖判读）。

本章讲授脊柱与背肌、肩与肩胛区、臂丛与四肢的神经、臂与前臂的间隙区，以及手。

## 脊柱与背部

::: definition 脊柱 {#def-spine}
脊柱由33块椎骨——**7颈、12胸、5腰、5块融合的骶椎、4块尾椎**——借**椎间盘**（髓核为脊索残余，位于纤维环内；椎间盘占脊柱长度的25%，在腰部前方较厚，这是腰前凸的成因之一）、后方的**关节突（椎弓根）关节**以及**前、后纵韧带**相连而成。成人弯曲——胸与骶的**后凸**（原发、胎儿期形成）与颈、腰的**前凸**（继发、随抬头与行走获得）——使脊柱成为一根承载能力超出各部分之和的弹簧。**脊髓**在成人止于**L1/2**（婴儿更低——故婴儿腰椎穿刺选择更低平面），末端为**脊髓圆锥**，**马尾**与**终丝**在**腰池**（蛛网膜下隙至S2）内延续，这就是L3/4以下进针取脑脊液而不触脊髓的原因。
:::

::: definition 背部的肌肉 {#def-back-muscles}
背部按层排列。**浅层**（动肢）：斜方肌（副神经）、肩胛提肌、菱形肌，以及——演化上动肢而功能上呼吸——背阔肌与后锯肌。**中层**（体壁轴向衍生物）：呼吸性的躯干竖肌床与**胸腰（腰）筋膜**，其中、后层包绕**竖脊肌**（外侧的肋突髂肋肌、长肌、内侧的棘肌），前层衬于腰方肌；经此筋膜传递的腹内压，正是腹部“后壁是肌肉”而非仅有腹肌前壁的原因。**深层（固有肌）**：作为长支撑带的竖脊肌、**横棘突肌群**（半棘肌、多裂肌——节段性、本体感觉性，在慢性腰痛中最先抑制、最后恢复），以及最靠近关节的**棘间肌与回旋肌**。固有肌由**脊神经后支**支配，肢带与体壁肌由前支支配——这条划分决定哪根神经的损伤造成什么。
:::

::: theorem 椎间盘向后外侧突出，行走的神经根买单 {#thm-disc}
后纵韧带中央宽而强、向侧方变窄；纤维环以后外侧最弱。因此突出在腰椎通常压迫的不是该节段出口（在上方椎间孔内、受保护）的神经根，而是**走向下方椎间孔的行走根**：**L4/5旁中央突出压迫L5根**，L5/S1突出压迫S1根。下位的中央型突出威胁马尾——是急症。相反，**极外侧**突出抓住出口根（L4/5极外侧：L4根），这就是运动缺损的平面必须对照突出位置而非只对照其高度来读的原因。
:::

::: proof
皮节与肌节的后果随这条规则而来。**L5**（L4/5旁中央）：𧿹伸（𧿹长伸肌）与髋外展无力，小腿外侧与足背麻木，膝反射正常或减低，其张力试验是**直腿抬高**（伸直抬腿使L4–S1在椎间盘上被牵张）。**S1**（L5/S1）：跖屈与足跟行走无力，踝反射消失，足外侧与小趾麻木，交叉直腿抬高阳性特异性更高。**马尾综合征**是后内侧椎间盘的灾难——双侧坐骨神经痛、**鞍区麻木（S3–5）**、膀胱肠道功能障碍（先为充溢性尿潴留，无痛且晚），运动无力形式多变；病变是圆锥以下的那一袋神经根，手术是**24–48小时内**减压，因为膀胱功能恢复随延误陡降：本章最讲时间的诊断，也是解剖使其可定义的（鞍区皮节与无痛性潴留是十个红旗里的那两个）。同一根脊柱也解释牵涉痛：来自骨膜、关节突与纤维环后部（脊膜返神经，即脊神经前支的返支）的**躯体性**痛在背部局限；**根性**痛沿患者能描出的线放电至膝以下；而椎间盘痛本身——髓核酸性物质与炎性介质作用于神经根的“化学性椎间盘炎”——正是影像上压缩很轻却可有根性痛的原因，这个事实保护患者免受对图片开刀。
:::

::: example 腰椎穿刺，逐层而言 {#ex-lp}
一名疑诊脑膜炎的24岁患者需要脑脊液。你选择L3/4（或L4/5）间隙，侧卧，屈膝抱腹。
::: solution
针的路径就是背部的层次清单：**皮肤、浅筋膜、棘上韧带、棘间韧带、黄韧带**（第一次“落空感”，密封椎管的弹性膜，亦是目标：错过它，针就谎报夹在两椎板之间）、**硬膜外隙**（脂肪与无瓣膜的椎内静脉丛，凝血障碍时易出血）、**硬膜**（第二次落空感）、**蛛网膜**，以及**蛛网膜下池**，其中的马尾根在针尖旁漂开——这就是该操作在L3/4以下安全的理由：马尾会动，脊髓不会。入路可经正中（屈曲把水平的腰椎棘突像书页一样打开）或经旁正中。远期风险：脑脊液漏所致的**穿刺后头痛**，其发生率随笔尖式针头、以及针尖斜面平行于硬膜纤维方向而下降。婴儿脊髓终点更低，故在**L4/5或更低**进入蛛网膜下隙，以髂嵴连线（**Tuffier线**，平L4棘突或L4/5间隙）定位——摆放体位时最先摸到的全身通用标志。
:::
:::


## 肩带与肩袖

::: definition 肩复合体 {#def-shoulder}
**上肢带（肩带）**——锁骨（全长皮下，是把肢架离躯干的支柱；最早骨化、内侧最晚融合（25岁）的骨）与肩胛骨（浮于肌肉之上，其**关节盂**是一个由纤维软骨**盂唇**加深的浅窝）——以稳定换取活动度。稳定性由**肩袖**（四块肌的腱与关节囊融合：**冈上肌**——启动外展，最常撕裂的腱——**冈下肌**与**小圆肌**（外旋），**肩胛下肌**（内旋），分别由肩胛上神经（冈上、冈下肌）、肩胛下神经上下支（肩胛下肌）与腋神经（小圆肌）支配）、**肱二头肌长头**及其结节间沟（肱骨头下压器与弱屈肌）、盂肱韧带与负压，以及上方的**喙肩弓**（肩袖撞击其下的屋顶，中间隔以**肩峰下滑囊**）提供。**四边间隙**（上方小圆肌，前方肩胛下肌/关节囊，下方大圆肌，外侧肱骨）传送**旋肱后动脉与腋神经**——该束在四边间隙综合征中被压，在后脱位中处于险境。
:::

::: example 回不去的胳膊 {#ex-shoulder}
一名22岁橄榄球运动员被擒抱后手臂处于外展外旋位；他用另一只手托着肘；肩部视之“方形”，且“团徽区”麻木。
::: solution
这是**前（喙突下）脱位**——占肩关节脱位95%，机制恰是那个外展、后伸、外旋的姿势——方形轮廓是空的关节盂，肱骨头在喙突下可触及。**“团徽区”麻木**（三角肌下份那片皮肤）标志着绕行外科颈的**腋神经**（C5–6）损伤：复位之前记录感觉、复位之后再记录一次（复位后新发而未曾记录的麻痹会变成投诉）。复位（足跟抵腋的牵引-反牵引——希波克拉底文集的方法——或现代外旋技术）把肱骨头放回盂唇之下；年轻运动员的复发率反映**Bankart损伤**（前下盂唇连同骨或骨膜撕脱），并推动手术修复。两个附注：40岁以上患者常在同一瞬间撕裂**肩袖**；而未经复位的**后脱位**（癫痫、电击、内收位跌倒）在标准正位片上被漏诊——固定内旋位的“灯泡征”是线索。
:::
:::

## 臂丛与四肢的神经

::: definition 臂丛 {#def-plexus}
臂丛即**C5–T1**的脊神经前支，排列为**根→干（上、中、下）→股（前、后）→束（外侧、内侧、后——依其与腋动脉的关系命名）→分支**，其经典终末五条及其根：**肌皮神经（C5–7）**——臂前间隙肌与前臂外侧皮神经；**腋神经（C5–6）**——三角肌、小圆肌、团徽区皮肤；**正中神经（C5–T1）**——前臂大部分屈肌、鱼际肌与桡侧三个半指掌面皮肤；**尺神经（C8–T1）**——尺侧腕屈肌、指深屈肌内侧半、大部分手内在肌与小指加无名指的一半；**桡神经（C5–T1）**——全部伸肌、经其浅支支配手背桡侧、经其皮支支配臂与前臂后面。根与干由**Erb（上干，C5–6：“侍者tip（行李员手）”——内收、内旋、旋前位；产瘫与头颈侧屈伤）**与**Klumpke（下干，C8–T1：内在肌麻痹、爪形，且——因交感干与锁骨下动脉同行——同侧Horner征；上肢被猛力上牵的损伤）**两型来检查。**胸长神经（C5–7）**沿胸壁深面、经肢带肌深面下行至前锯肌，其损伤产生**翼状肩胛**——也是腋窝淋巴结清扫术中处于险境的那根；**胸背神经**（背阔肌，后方腋窝入路）与**肩胛上神经**（肩胛上切迹）是外科解剖上具名的同门。
:::

::: example 折臂与垂腕 {#ex-radial}
一名30岁患者跌倒碰到肘；X线示肱骨干中1/3与远1/3交界处横行骨折。复诊时他不能伸腕与伸掌指关节，第一背侧虎口区麻木。
::: solution
**桡神经**伤在**桡神经沟（螺旋沟）**，此处它贴骨走行于肱三头肌内外侧头之间——这一关系给了肱骨干中段骨折10–18%的神经损伤率，也产生“星期六夜麻痹”（沟内受压）——而拐杖麻痹在腋窝受压、连同肱三头肌一并麻痹成更完全的垂腕。模式从解剖直接读出：垂腕伴**掌指关节水平手指下垂而指间关节伸展保留**（蚓状肌与骨间肌伸指间关节，由**尺神经**支配）、**鱼际垫感觉正常**（该区属肌皮神经）、**第一背侧虎口**麻木（桡神经浅支）。闭合性骨折麻痹多为神经失用：腕托观察三个月，毫无恢复则计划肌腱转位；开放性或穿透伤、或复位后新出现的麻痹则手术探查——神经的命运跟着骨损伤的机制走。
:::
:::

::: quiz
哪一个单一病损导致手指内收外展丧失、无名指与小指在用力握拳时加重的爪形，而手背感觉正常？
- [ ] 臂丛下干
- [x] 腕部尺神经深支（钩骨钩/Guyon管，运动支）
- [ ] 骨间后神经
- [ ] C8神经根病
::: solution
手指的内收与外展是**骨间肌（尺神经深支）**的功能；无名指与小指爪形**在握拳时加深**是经典的尺神经爪形（内侧两条蚓状肌与骨间肌失去后，掌指关节在试图屈指时过伸——“尺神经悖论”指出**高位**病变反而爪形更重，因为长屈肌同时瘫痪；**低位**病变静止时爪形较轻但内在肌丧失；而腕部深支病变恰好只丢内在肌）。手背感觉保留，因为**尺神经手背支在腕上（Guyon管近端）分出**——运动性爪形伴感觉保留把病变定位于管的深终支，同一事实也把它与C8根或下干病变区分开（后者感觉、以及常累及正中神经支配的鱼际肌也会受累）。

## 间隙区：臂、前臂与压力法则

**臂**分为**前间隙区**（肌皮神经：肱二头肌、肱肌、喙肱肌——屈肘与强力的旋后；其残余感觉为前臂外侧皮神经）与**后间隙区**（桡神经：肱三头肌、肘肌——伸），由内外侧肌间隔分隔；**肱动脉**走行于内侧肱二头肌沟，正中神经居其深面，内有臂内侧皮神经，是肱动脉搏动触诊与肘窝静脉穿刺深邻之处；**肱二头肌腱膜**是一柄双刃剑：它保护动脉，而在髁上损伤中，它是移位的近折段与被绞锁的血管神经束受损的靠垫。

::: definition 前臂与骨筋膜室综合征 {#def-compartment}
前臂分为**前（掌侧；浅层——起自内上髁的屈肌旋前肌群，深层——指深屈肌、拇长屈肌、旋前方肌；除尺侧腕屈肌与指深屈肌内侧半属尺神经外均由正中神经支配；其纯运动支为骨间前神经）**与**后（伸肌；桡神经/骨间后神经）**间隙区，由骨间膜分隔，外侧为**桡侧移动组**（肱桡肌与桡侧腕长、短伸肌——由桡神经支配的屈腕肌）。肌、动脉与神经行走在**不扩张的骨筋膜鞘**内。**骨筋膜室综合征**——室内出血或肿胀，经典见于髁上骨折、前臂挤压伤、过紧的石膏或血管修复后再灌注——使室内压升高至毛细血管灌注失效，数小时内肌肉梗死并纤维化为**Volkmann缺血性挛缩**（十九世纪命名里那爪形而无功能的前臂）。临床经典句：**疼痛与体征不成比例、被动牵拉室内肌肉剧痛、穿行其内的神经感觉异常**（掌侧为正中或骨间前神经），无脉出现极晚——这句必须烂熟，因为等无脉会把四小时的筋膜切开拖成四天的挛缩。
:::

::: example 肘伸直的孩子 {#ex-supra}
一名五岁儿童从秋千上以半伸肘位跌落；肘肿胀、保持轻屈位，桡动脉搏动存在，但孩子不敢动手并诉指尖发麻。
::: solution
除非X线证明否则即为**髁上骨折**——儿童最常见的肘部骨折，伸直型：肱骨干经薄弱的髁上皮质向前冲出。危险的解剖：**肱动脉与正中神经**正压在近折段的行进路径上，**肱肌**被挤在骨折段与骨膜之间——于是或见**脉搏存在而前臂缺血的肢体**（侧支维持脉搏而肌肉灌注已失效），或见**无脉而仍存活的肢体**（动脉痉挛加上由尺侧上、下副动脉与骨间返动脉构成的丰富髁上吻合）。处理随之：尽快转诊复位（经皮克氏针，让尺神经避开——钉由外向内或分叉进针以避开内侧血管束），复位后要问的永远不是“有脉搏吗”，而是**“被动伸指导致疼痛吗？”**——掌侧间隙的诚实报告。这一病史里的指尖发麻是数小时内归骨科、而非急诊过夜笔记里一句带过的神经损伤或压迫征。
:::
:::

## 手与其间隙

::: definition 手的间隙与弓 {#def-hand}
手以筋膜划分为**鱼际间隙区**（拇短展肌、拇短屈肌浅头、对掌肌——**正中神经返支**，C8–T1）、**小鱼际间隙区**（掌短肌——该区唯一的皮肌、尺神经完整性的标志；小指展屈肌、对掌肌——尺神经深支）、**中间间隙区**（屈肌腱、蚓状肌I–II正中神经与III–IV尺神经支配、**掌浅、掌深间隙**，二者被自第三掌骨至背侧筋膜的**掌中隔**分开）与**拇收肌**（尺神经深支；鼻烟窝的底，其虎口萎缩是最早可见的尺神经征）。动脉弓：**掌浅弓**（以尺动脉为主，在钩骨水平发出指总掌侧动脉）与**掌深弓**（以桡动脉为主，位于掌骨与骨间肌上），加上**双血管供血原则**（桡、尺动脉经两弓，及腕背网），支撑着手外科的每一测试——**Allen试验**在取桡动脉做冠脉搭桥或前臂皮瓣之前阻断一侧、观察掌经另一侧的再充盈。
:::

::: example 吞笔帽与鼻烟窝 {#ex-snuffbox}
一名19岁骑自行车摔倒、腕背伸位手掌撑地；一小时后鼻烟窝肿胀压痛，沿拇指纵轴挤压痛；首诊X线正常。
::: solution
除非证实否则即为**舟骨**损伤——其**结节就在鼻烟窝的底**（窝的边界为外展拇长肌与伸拇短肌在外、伸拇长在内）， 手掌撑地后的舟骨骨折在最初X线常不可见（可达无移位骨折的一半；骨影重叠与骨小梁线中断是征象）。此骨折之所以要紧在**血供**：桡动脉的分支**自远端进入、逆行走行**，故**腰部或近极**骨折使近侧骨段缺血，结局是**缺血性坏死与骨不连**及早期关节炎——“X线正常、鼻烟窝压痛”即按舟骨骨折处理（拇指人字石膏固定，两周复查影像，或在现代单位用当场定论的MRI）的原因。同一解剖也回答了另一个舟骨问题——为何远极可随意切除而近端骨折要螺钉固定、有时还要植骨——并陈述了通则：**动脉逆行之处，以离心脏最远的骨段判断骨折**（股骨颈是髋部的同一句话）。
:::
:::

::: example 纽扣脓肿与手掌深间隙 {#ex-hand-space}
一名静脉吸毒者在掌侧腕部注射；五天后鱼际区出现压痛、波动性肿胀，拇指保持外展位，而掌弓正位于针道区域。
::: solution
感染有两条路，间隙界定这两条。掌侧腕部的浅层穿透伤可播种**掌浅间隙或鱼际间隙**（后者与拇指屈肌腱鞘相延续，并沿拇长屈肌进入**前臂Parona筋膜间隙**——这就是拇指尖或腱鞘感染可以表现为前臂远端肿胀的原因；小指腱鞘同样延续为尺侧囊，终于掌中间区——该指腱鞘脓毒症于是表现为掌中间肿胀）。**纽扣脓疡**——脓经掌腱膜的纤维隔同时向掌侧与背侧溃出——是脓液沿垂直隔寻找阻力的最小沙漏形通道，这就是掌侧肿胀看似骗人地小的原因：皮下的间隙比皮肤更深。处理是外科解剖学：切口避开桡侧的**桡神经浅支**与走在每个指蹼中线的**指总、指固有掌侧神经**，各间隙分别引流加对口切开，且——因为动脉弓在掌部位置表浅（横跨掌部的切割伤是尺动脉损伤经典机制的原因之一）——须在上止血带、放大镜下、并清楚针道穿过了哪条具名血管的条件下进行。屈肌腱鞘脓毒症是同一课最急迫的版本：数小时内冲洗，因为鞘内高压绞窄的正是肌腱自己的血供——伴腱纽行走的指动脉鞘内分支。
:::

::: history
四肢的外科是从它的神经长出来的。Bell定律（1811年）在猪脊髓上区分了前后根功能；十九世纪的臂丛描述与尺、正中神经的战伤外科确立了经典的手部损伤；Charles Bell爵士本人的手保存在爱丁堡——一件带着临床历史的遗物：一种至今仍在争论病因的畸形。舟骨的血管教训来自铁路损伤与早期骨科的碰撞；Dupuytren（1832年）描述了以他命名的掌筋膜挛缩；Paget关于神经损伤后神经营养改变的观察仍留在教科书里。骨筋膜室综合征的现代命名属于第一次世界大战——被压砸的、包扎过紧的肢体——而早期筋膜切开之争由再植时代的压力计裁定。
:::

## 通向何处

根性病变与脊髓综合征续于[[anatomy/neuroanatomy]]；周围神经损伤的临床在内[[nervous-system/stroke]]与[[nervous-system/neuromuscular]]；骨折分类与手术固定见[[surgery/orthopaedics]]；背痛的红旗医学见[[musculoskeletal/back-pain]]；骨筋膜室压力测定见[[emergency-critical-care/acute-assessment]]与[[surgery/trauma]]。

::: summary
- 脊柱的工程学是间盘、弯曲与后支支配的肌肉；间盘向后外侧突出压及行走根（L4/5间盘→L5根），而马尾处的后内侧突出是今天的手术。
- 臂丛是一张五站地图——根、干、股、束、支——每一个具名病变（Erb、Klumpke、螺旋沟、肘、腕、管）都是一个驿站配一块骨、一个机制、一张签名手。
- 桡神经贴着骨走（螺旋沟），正中神经伴肱动脉穿过肘部的危险区，尺神经绕内上髁之后——三条神经、三处骨折、三种夹板。
- 筋膜造出间隙，间隙造出压力综合征：被动牵拉痛、感觉异常，然后是挛缩；脉搏是最后消失的，也是最不该等的。
- 手的间隙——鱼际、掌中、腱鞘延续、Parona——感染在这里靠几何诊断、靠具名切口引流；其血供由设计而双重，由Allen检验。
- 在肢体的远侧骨段——舟骨、股骨颈——动脉逆行，骨折问题永远是离心脏最远那块骨的灌注。
:::

## 练习

::: exercise 以反射定根 {level=1}
给出下列各例的神经根、神经与反射：(a)肱二头肌反射消失；(b)踝反射消失；(c)垂腕无力而肱三头肌反射正常；(d)大腿外侧麻木而无无力。
::: solution
(a)**C5–6，肌皮神经**（肱二头肌与旋后肌反射——若屈肘旋后亦无力，则为上干/肌皮神经根性病变）。(b)**S1，胫神经**（踝反射是该根的深腱反射；若足底反射亦消失、足外侧麻木，则S1根病或胫/腓肠感觉模式）。(c)**桡神经在螺旋沟或以下**——肱三头肌支（高位桡/腋/后束水平）保留，腕与指伸肌瘫痪：经典的中段病变；C7根病变通常累及肱三头肌及其反射。(d)**股外侧皮神经（L2–3），感觉异常性股痛**——髂前上棘附近经腹股沟韧带深面的纯感觉卡压；L2–3根病会加上髋屈/内收无力与股四头肌反射改变。要记住的答题模式是：**深腱反射定位到节段，无力定位到神经，麻木定位到皮节，三者合参把根、干与周围神经区分开。**
:::
:::

::: exercise 追踪臂丛 {level=1}
肿瘤破坏了右侧臂丛下干。预测运动丧失（按具名肌群）、感觉丧失与自主神经体征——并说出哪两条具名神经被豁免，及其诊断意义。
::: solution
**运动：全部手内在肌**（鱼际、小鱼际、蚓状肌、骨间肌——经两神经的终末支）→平坦萎缩的手、四指全爪形；加上**尺侧腕屈肌与指深屈肌内侧半**（尺神经支配的C8–T1成分屈指肌）与C8支配的腕指屈肌力弱。**感觉：臂与前臂内侧（内侧皮神经，T1）与尺侧一个半指（尺神经）加正中神经掌区——整个C8–T1的带状区。**自主神经：**Horner征**（上睑下垂、瞳孔缩小、无汗、面部干燥），因T1白交通支供养星状神经节、交感干与锁骨下动脉同行——该体征把干/根病变与更远端病变区分开，且在吸烟者指向Pancoast瘤（见[[anatomy/thorax]]）。**豁免：胸长、肩胛上、腋与肌皮神经（C5–6，上干及其分支）——肩肘功能接近正常。**这种豁免正是对替代定位的诊断性回答：同样的内在肌萎缩若伴C5–6受累提示外侧束或高位病变；内在肌全瘫伴Horner征而肩关节正常提示**下干或T1根**，在影像上就是肺尖或胸廓入口的问题。
:::

::: exercise 读懂爪形手 {level=2}
两名患者都表现为无名指与小指爪形：(a)肘部尺神经病变；(b)T1根性撕脱。用一个爪形特征加一个附加所见来鉴别。
::: solution
这里的枢纽是**尺神经悖论**。悖论如此展开：**高位（肘部）病变爪形反而较轻**，因其瘫痪的指深屈肌不能屈指间关节、驱动不了爪形；而**低位（腕部）病变爪形最重**——指深屈肌完好、对着去神经的蚓状肌屈指间关节。T1根撕脱的表现像一个**极高位**病变，加上关键的**臂、前臂内侧皮神经（T1——近端、根水平的神经）丧失**，而肘部病变将其豁免；且根撕脱是**神经节前置性**的，**背根神经节及其神经保持完整**——临床上感觉丧失而电诊断的神经动作电位（NAP）保留，这是区分根撕脱与丛断裂的经典试验，而神经节前的病变告诉外科医生颈部无法缝合神经（需神经移位）。所以两个鉴别点：**感觉丧失向上延伸及臂内侧（根，T1）而局限于手与前臂（肘部尺神经）**，加上悖论的严重度梯度与电诊断。考试式的答案通常是：“正中-尺混合型爪形=下干（两神经），纯尺侧爪形=尺神经；爪形越重=病变越低。”
:::

::: exercise 过紧的石膏 {level=2}
前臂骨折石膏固定后两晚，儿童疼痛加剧需要阿片类，被动伸指导痛，手指肿胀发紧。写出鉴别诊断、你绝不会依赖的那一项检查、以及两步处理。
::: solution
鉴别：**石膏下不断升高的间隙压力**（最常见、可处置的原因——疼痛与体征不成比例、阿片需求攀升、被动牵拉室内肌肉痛、张力性肿胀、早期中正/骨间前神经感觉异常），对比单纯的敷料过紧、复位不良骨折段扭曲动脉，或（更晚）感染。绝不会依赖的检查：**桡动脉搏动**——脉搏在早已使肌肉梗死的压力下依然存在，因为收缩压超过间隙压直到极晚；同一真理的反面（无脉的手可经侧支灌注）已在本章髁上骨折一节陈述。两步：(1)**立即拆开石膏夹板并剪开所有敷料至皮肤**——一半的压力下降来自释放环形外壳；二十分钟后复评。(2)若疼痛与牵拉征持续，**测间隙压力**（常用阈值为舒张压减间隙压之差小于30 mmHg），继而行受累间隙的**筋膜切开**，方案须保护神经与浅静脉、创面敞开、二期覆盖。防止医疗诉讼的那句话是带时间戳的记录：恶化被记录，石膏在某一确知时刻被打开，打开无效时外科医生被叫到。
:::

::: exercise 在肘部定位神经 {level=2}
一名患者示指远节指骨屈曲无力、拇指指间关节屈曲无力，而感觉正常、腕部正中神经主干神经传导正常。是哪条分支？在哪里？感染后继发综合征的具名变异叫什么？
::: solution
这一模式属于**骨间前神经（AIN）**——正中神经在肘下方发出的纯运动支，支配拇长屈肌、指深屈肌外侧半与旋前方肌：**纯运动**麻痹（“OK征”变成指尖伸直位的捏），**感觉正常**（AIN不携带皮肤分布区——其关节支至腕与腕骨间关节），以及因主干完好而正常的常规腕部神经传导。近端卡压（Struther韧带、肱二头肌腱膜、指浅屈肌两头）与感染后/疫苗接种后的**Parsonage-Turner（臂丛神经痛性肌萎缩）**——经典为急发肩臂痛、数日后出现选择性AIN或其他斑片状麻痹——是两类病因。本题有用的部分是方法：**具名神经分布区内纯运动缺损、感觉与主干传导正常，病变就在该神经的具名分支而非主干**——同一逻辑也能识别上文的骨间后神经与尺神经深支模式。
:::

::: exercise 翼与钢丝 {level=2}
一名乳腺癌改良根治加腋清除术后患者推墙时肩胛骨翼状；另一名锁骨中段骨折患者仅在过头外展时出现翼状。分别说出神经名称，并按机制解释为什么第二个不是第一个。
::: solution
第一：**胸长神经（C5–7，前锯肌）**——腋清除术的经典医源性损伤（神经沿胸壁行于清除野上缘）；前锯肌把肩胛骨锚于胸廓并上旋关节盂，故**对抗阻力前推时内侧缘翼状**。第二：锁骨骨折后仅过头位的翼状提示**斜方肌（副神经，XI）**无力——该神经位于颈后三角，颈清扫与后三角淋巴结活检时处于险境——其翼状为**外侧性**（下角远离脊柱），**外展**时最重，因为斜方肌靠上旋关节盂完成过头上举的最后60°；肩部还会下垂、以耸肩姿态代偿而酸痛。鉴别在方向与动作：**前锯肌——前推、内侧翼；斜方肌——过头外展、外侧翼**，再挂上第三个名字（菱形肌，肩胛背神经）则产生轻度外侧翼状与肩胛内侧痛——三条神经、三个动作、三个临床征；三者都靠让患者做那块肌肉的动作、观察肩胛骨作答来检查——这是作为纯粹解剖学的体格检查。
:::

::: exercise 被割开的手掌 {level=2}
一刀横过掌侧腕横纹远侧、偏尺侧。列出该侧由浅入深的危险结构，并说出最决定手功能的两个损伤。
::: solution
由浅入深：皮肤与掌腱膜；**尺神经掌皮支**（在腕上发出，支配手掌小鱼际底（掌短肌区）——在腕管病变中豁免，而在此处遇险）；**Guyon管内的尺神经与尺动脉**并行（入口处神经在动脉浅而偏内，随后绕钩骨钩分为浅/感觉与深/运动支）；**掌浅弓**及其指总动脉与正中神经支配的蚓状肌；更深为屈肌腱、绕钩骨钩与掌深弓同行于掌骨与骨间肌上的**尺神经深支**，以及掌中间隔。最主导功能的两个损伤：**尺神经深（运动）支**——全部内侧与大部分外侧内在肌丧失、最重的爪形、捏与握力瘫痪（没有单一肌腱转位能良好重建，故早期探查、无张力缝合或移植）——以及**尺动脉及其弓**，因为弓供应指总血管：动脉加两指缺血的模式需要血管修复，而其缺如会使任何未来的桡动脉获取或手部皮瓣计划都要先做Allen（见弓原则）。本课末句是操作性的：手掌切割伤应在手术室、止血带、放大镜与写着上述解剖的屏幕前探查——不在病床旁的敷料下。
:::

::: exercise 抬起箱子 {level=3}
一名L4/5旁中央椎间盘突出的仓库搬运工接受保守治疗。请用解剖学术语解释：(a)当神经根是问题时为什么痛在腿而不在背；(b)为什么坐比站更痛；(c)时间起作用的生理学论证；(d)终结保守治疗争论的四条所见。
::: solution
(a)疼痛发生器是**神经根**而非间盘：髓核的酸性环境与细胞因子加上机械压迫使**背根神经节与行走根的鞘**发炎，而大脑把根痛读进皮节——腿——正如把心痛读进手臂；间盘自己的纤维环后部（脊膜返神经）产生局限的深部背痛成分，两者之比就是临床病史。(b)**坐位与站立时的椎间盘与椎旁负荷比站立更高**（经典Nachemson测量：坐位前屈使腰椎间盘压力比较站高约40–90%，站立高于卧位），因为躯干重力线移到脊柱前方，伸肌——通过本章脊柱赖以建成的那根杠杆——必须产生压缩节段的对抗力矩；同样的生物力学使一次弯腰搬起在L4/5变成一百牛米的剪切。(c)时间起作用是因为**髓核脱水萎缩**（随年龄发生的蛋白多糖丢失是同一过程的慢放），炎症成分平息；多数根性病变6–12周改善，这就是指南答案为镇痛、 力所能及的活动与理疗、而后才请教外科医生。(d)手术清单：**马尾综合征**（一袋神经根内全部骶根受压——鞍区麻木、无痛性潴留——以小时计）；**进行性加重的重度运动缺损**（不断恶化的足下垂）；**药物无效的剧痛**；以及**结构与症状相符、六至十二周仍存在缺损**。每一条都是关于正在失去什么、能够挽回什么的解剖学陈述——这就是外科与内科对指征一致而对时机分歧的原因。
:::
