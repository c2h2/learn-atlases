下肢为两件事而生，是上肢从没有的：承重与推进。它的全部解剖都由此而来——深而斜的髋，其血供穿经关节囊；膝关节是旋转平台上的一副铰链、韧带在内部交叉；小腿部骨筋膜鞘包裹对抗重力的肌肉；足的弓由韧带弹承、由肌腱维系；还有静脉，必须把血从低垂位泵回高处，因而靠泵与瓣膜为生——也毁于它们。它的临床医学相应地是机械学的：中断具名血供的骨折、以具名手法为检查的韧带，以及在袜套区皮肤上写下自己失败的静脉。

本章讲授臀区与髋、股三角与大腿、膝与腘窝、小腿的动脉、间隙与静脉，以及足与踝。

## 臀区与髋

::: definition 臀区与坐骨切迹 {#def-gluteal}
臀肌是外展肌群（臀中肌与臀小肌，经转子，由**臀上神经**支配）与伸-旋肌群（臀大肌——**臀下神经**，肌内注射“外上象限”之所，避开自梨状肌下缘走行至大腿中部的**坐骨神经**；梨状肌、闭孔内肌与上下孖肌——短外旋肌，各由S1–S2丛的自有神经支配）。**坐骨大孔**在梨状肌上缘传送臀上血管与神经，在其下方传送臀下血管与神经、**坐骨神经**、股后皮神经以及闭孔内肌与孖肌神经；**坐骨小孔**在骶棘韧带正下方，传送**阴部神经**与阴部内血管，绕坐骨棘重新进入会阴——即[[anatomy/pelvis-perineum]]所述阻滞的标志。**坐骨神经**（L4–S3）是全身最大的神经：其**胫神经部**携带腘绳肌（股二头肌短头除外，归**腓总神经部**）与膝下全部肌肉；其**腓总神经部**是受压最易伤、神经本身病变中最先失效的纤维——这就是髋部坐骨神经损伤可表现为**足下垂重于腘绳肌无力**的原因，也是单一病变后两部分恢复不均的原因。
:::

::: definition 髋关节及其血供 {#def-hip}
**髋**是球窝滑膜关节：髋臼由纤维软骨**盂唇**加深、由**髋臼横韧带**封口，接受股骨头；股骨头的圆韧带（**凹动脉**，闭孔动脉经髋臼切迹的分支）在成人是可变而通常次要的血供。**关节囊**前方附于转子间线、后方沿颈走行，故**股骨颈位于囊内**而转子间区不是——这一个事实统辖骨折的处理。股骨头血供主要来自**旋股内侧动脉**经支持带血管沿颈后面上行（旋股外侧动脉前方参与），加凹动脉；支持带血管在囊内**由远端走向近端**，故囊内骨折的移位会撕裂它们。其神经支配（前为股神经与闭孔神经，后为股方肌神经）就是髋病牵涉至**腹股沟——并经闭孔神经的关节支至膝**的原因：膝痛而膝正常的小儿，在查髋之前是髋。
:::

::: theorem 囊内股骨颈骨折使股骨头缺血——处理跟着血管走 {#thm-neck}
老年患者的**移位囊内（头下型）骨折**通常撕裂支持带血管，内固定因此双重失败：头发生**缺血性坏死**，而无血供的骨固定后不愈合。指南的逻辑由此而来——**机能较好的老年患者移位囊内骨折行关节置换（半髋或全髋），无移位骨折与年轻患者行内固定**（年轻者任何保头尝试都值得冒坏死风险），而**囊外（转子间、转子下）骨折——血供完整、松质骨面出血且能愈合——固定而不置换。**
:::

::: proof
细节即证明。支持带血管自后上进入颈部，这就是**后上粉碎最差**的原因，也是无移位或嵌插骨折血供可保的原因——“外翻嵌插”的年轻患者颈骨折原位两枚螺钉固定并观察的依据。凹动脉只在支持带血供完好而患者年轻时才要紧——吻合真实但细小，年轻患者移位骨折后坏死率仍高，这就是该人群复位是急诊（以小时计，不以天计）的原因：不是因为软骨先死，而是骨内残存通道被填塞过久即血栓。**移位颈骨折缺血性坏死10–30%**，这就是每一例固定后的颈骨折都要影像学随访至愈合与存活终点的原因，也是“已愈合”骨折18个月后髋痛要开MRI的原因。置换解剖完成论证：置换清除死骨、恢复长度与偏心距，且须尊重骨折未破坏的东西——后方的**坐骨神经**（为何后方入路髋关节向后脱位、为何要修复短外旋肌）与**外展装置**，其剥离正是手术绝不该造成的跛行。
:::

::: example 说出神经名字的跛行 {#ex-trendelenburg}
一名54岁女性无痛性跛行；当她右腿站立时骨盆向左掉。
::: solution
这是**Trendelenburg征**阳性：**外展肌（臀中肌、臀小肌，臀上神经）**不能维持骨盆水平，骨盆向**对侧**下坠——该征以站立侧给病变命名。鉴别在机制的三个点：**神经**（臀上神经麻痹——注射后或术后；或L5根，此时其他L5肌肉同入画面）、**腱**（外侧入路髋术后外展肌腱撕脱），或**力学**（髋内翻或复位不良时大转子高位使力臂变短；而任何疼痛的髋给出的是避痛步态而非真正的Trendelenburg）。力臂解释了它：外展肌把髂骨拉过固定的股骨下行以使骨盆水平，而颈与转子的每一台手术，多年后都按这个滑轮是否还在工作来评判。
:::
:::

## 股三角、大腿与股管

::: definition 股三角与股鞘 {#def-femoral}
**股三角**——上为腹股沟韧带，外为缝匠肌，内为长收肌——是腹、会阴与下肢之间的门户。内容**由外向内**为**NAVEL：神经（股神经）、动脉、静脉、空（股管）、淋巴**——**股鞘**包绕动脉、静脉与股管但**不含股神经**，分为外（动脉）、中（静脉）、内（**股管**，内含Rosenmüller淋巴结环）三格。股管上方由**股环**封闭——边界为腹股沟韧带、腔隙韧带、耻骨梳韧带与腹直肌鞘缘：这个狭窄硬性的环使股疝成为[[anatomy/pelvis-perineum]]所述之绞窄者。**大隐静脉**在耻骨结节外下方3–4 cm经**隐静脉裂孔（卵圆窝）**注入股静脉，附近有腹壁浅静脉、旋髂浅静脉与阴部外浅静脉及腹股沟浅淋巴结——血管外科与肿瘤分期的腹股沟十字路口：肛门生殖区皮肤与下肢引流至此，黑色素瘤标测由此开始。
:::

::: definition 大腿间隙与收肌管 {#def-thigh}
**前侧（股神经）：**股四头肌、缝匠肌、髂腰肌（屈髋肌，其腱构成三角的底）与髂肌——屈髋与伸膝；**隐神经**——股神经的终末皮支——与股血管同经**收肌（Hunter）管**——该管是腱膜性隧道（外为股内侧肌，内为长收肌与大收肌，上为收肌裂孔），股动脉出此成为膝后的**腘动脉**；隐神经随后伴大隐静脉行至膝下，是小腿手术中被牺牲或取走的神经，也是收肌管病变内侧腿痛的来源。**内侧（闭孔神经）：**收肌群、股薄肌、闭孔外肌——及其至髋与膝的关节支（即上文牵涉那句话）。**后侧（坐骨神经胫部，股二头肌短头为腓总例外）：**腘绳肌——伸髋屈膝；坐骨结节是其起点与“坐骨”，运动员的近端腘绳肌撕脱是同一地理的另一版本。动脉方面，大腿靠**股动脉**及其**深动脉**（穿支越收肌）与髌周**膝吻合网**而生——这条旁路使小腿能在腘动脉缓慢闭塞中存活，也使前移植时代的医生得以结扎股动脉。
:::

::: example 心导管术后的搏动性肿物 {#ex-fa}
股动脉冠脉造影六周后，患者腹股沟出现压痛、膨胀性肿物伴杂音；穿刺记录为“偏低”。
::: solution
**股动脉假性动脉瘤**——动脉壁的一个洞出血入被包裹的瘤腔，穿刺**低于股鞘覆盖范围或低于腹壁下动脉起始**的经典后果：此处动脉贴骨、无可压迫的软组织隧道，穿刺孔无法闭合；安全区是**股骨头之上的股总动脉**（腹股沟中点，以腹股沟韧带线为上限，以分叉为界——股鞘与股骨头软骨帽使其可以压迫）。诊断靠双功超声（瘤颈“来回血流”），处理按解剖分级——超声引导凝血酶注射（绝不可入自体动脉——故瘤颈解剖即治疗的风险）或压迫；感染、膨胀或缺血的瘤腔手术。两个毗邻并发症补全股三角的临床清单：**动静脉瘘**（对穿内倾走行的静脉与动脉——连续性杂音的模仿者）与**腹膜后血肿**（腹股沟韧带上穿刺，血管针道开向腹腔——“干净”的腹股沟后背痛伴低血压的患者）——一条皮肤线造成的三种并发症，这就是术者在下针之前先标出韧带的原因。
:::
:::

## 膝与腘窝

::: definition 膝及其检查 {#def-knee}
膝是两个关节——**胫股**（髁对平台，以纤维软骨**半月板**相隔：内侧C形并连于**胫侧副韧带**，外侧圆形、活动、被腘肌腱分开）与**髌股**。静态稳定靠**侧副韧带**（内侧——至胫骨的浅束、与内侧半月板相融的深束；外侧——索状**腓侧副韧带**，不与半月板及绕过它的股二头肌腱粘连）、**关节囊与后外侧角**，以及内部的交叉韧带：**前交叉韧带**（前内胫骨止点至后内股骨起点，伸膝位紧张；抵抗胫骨前移与旋转——**Lachman**与轴移试验即其查体）与**后交叉**（更强；后坠征与后抽屉）。移位半月板撕裂机械性**交锁**——桶柄卡入铰链——而半月板的血**从周边向内**（红-红、红-白、白-白区），故周边撕裂缝合、中央退变者修剪——又是舟骨的血管逻辑。滑囊自成一门门诊：髌前（女仆膝）、髌下（跳跃膝——髌腱端点病）、鹅足（缝匠-股薄-半腱联合止点，常见的“膝内侧痛”），以及**腘窝（Baker）囊肿**——腓肠肌-半膜肌滑囊经关节单向活瓣充盈，表现为酷似深静脉血栓的小腿肿胀，破裂则给出踝下新月征。
:::

::: definition 腘窝 {#def-popliteal}
膝后的菱形间隙——外上为股二头肌，内上为半腱半膜肌，下方为腓肠肌两头——内容**由浅入深：胫神经、腘静脉、腘动脉**，埋于脂肪与淋巴结中；**腓总神经**沿股二头肌内缘逃向**腓骨颈**（在此浅表易伤——见[[anatomy/anatomical-language]]的石膏）。腘动脉被其膝降支与比目鱼肌弓**固定**，这就是膝关节脱位会撕裂或牵拉它的——也是该伤规则为系列脉搏**加**踝肱指数、对入院时有力而现在变弱的脉搏做血管造影的原因：内膜瓣今天保脉搏，今晚就闭塞。
:::

::: example 打软的膝与肿起的小腿 {#ex-acl}
24岁足球运动员膝“打了软”，数小时内肿胀，转身时不稳；三天后小腿肿痛。
::: solution
扭转伤后**数小时内**的血肿伴Lachman阳性即**前交叉韧带撕裂**（积液来自韧带胫骨止点撕脱与滑膜血管；“啪、肿、软”的病史在MRI之前即诊断——MRI在此的意义是找它的同伴：**外侧半月板是ACL急性撕裂的搭档**——与旧的O'Donoghue“不幸三联”（内侧半月板）教学相反——外翻机制时还有内侧副韧带）。第三天的肿痛小腿是**Baker囊肿破裂与深静脉血栓**的鉴别——超声一石二鸟：加压探头查血栓，灰阶见腓肠肌与半膜肌间液体沿筋膜面下流——即囊肿破裂的假性血栓性静脉炎。处理是外科解剖学：急性ACL不缝合而重建——常用**髌腱骨-髌腱-骨**或**腘绳肌腱**经按原生足印定位的骨道（隧道要放在韧带原来在的地方，而不是顺手的地方）——9–12个月回场，**未达肌力标准就回场的年轻运动员再撕裂率最高**。
:::
:::

## 小腿：动脉、间隙、静脉

腘动脉在腘肌下缘分为**胫前动脉**——穿骨间膜至伸肌间隙，在踝部浅出为**足背动脉**（拇长伸肌腱外侧可及；少数人先天性缺如）——与**胫后动脉**：较大的干，与**胫神经**同行于比目鱼肌深面，发出**腓动脉**至腓骨间隙，终于**内踝后方**（胫后动脉搏动，邻**踝管**）。深系统的伴行静脉接受浅系统——**大隐静脉**（内踝前方；切开与搭桥的桥静脉，终于隐股交界）与**小隐静脉**（外踝后方入腘静脉）——经**穿通静脉**相连，而**肌泵**与其单向瓣膜完成爬升。

::: theorem 站立时的静脉压是一根柱，行走是其治疗 {#thm-venous}
患者静止站立时，从右房至踝的静脉是一根连续的液柱：踝部约**90 mmHg**（约20–30 mmHg的**动态静脉压**是正常行走所达到的——小腿泵在瓣膜关闭下排空液柱、踝部穿通支使深系统充盈）。**静脉高压**——源于瓣膜失效（原发性静脉曲张、DVT后血栓破坏，或穿通支关闭不全）——产生临床阶梯：水肿、**小腿袜套区**的含铁血黄素沉着与脂性硬皮病，终至**静脉性溃疡**——加上静脉曲张本身。溃疡的四诊鉴别即本章的一句话：**静脉性**（袜套区、浅、不规则、渗出，皮肤色素改变，加压治愈）、**动脉性**（趾、足、外踝，凿孔样、结构外露、痛、冷、无脉——加压会毁肢）、**神经性**（�胝下的足底受压点、无痛——糖尿病足）与**混合性**（老人的多数）：区分它们的查体是包扎之前的脉搏、毛细血管再充盈与ABPI。
:::

::: proof
这个阶梯是把流体力学写在皮肤上：站立的90–100 mmHg液柱正常随每一步被卸载至20–30 mmHg；瓣膜失效时足部整天处于高压，毛细血管床漏出纤维蛋白原与生长因子，**纤维蛋白套与白细胞扣押**过程产生硬结、色素沉着的脂性硬皮病，轻微外伤敞开一个无法愈合的溃疡，因为组织的转运机制已病。**穿通静脉**是外科靶点：最大的交通静脉位于小腿的环形筋膜带——袜套区的祸首地带——其结扎加隐干消融（热消融试验时代）与加压，把复发率压下来。血栓后肢体经另一条路到达同一皮肤：机化的血栓摧毁瓣膜叶本身，这就是DVT预防即中年溃疡预防的原因——也是**血栓后**肢体的浅静脉手术须谨慎的原因：浅系统可能是仅存的去路，取掉它反而加重肿胀。
:::

::: warning 小腿的四间隙，再次
骨筋膜室综合征定义于[[anatomy/back-upper-limb]]；小腿是经典肢体，因为其筋膜紧、四个间隙是各有名字的小盒子：**前侧**（胫骨前肌、伸肌群、**腓深神经**——最先失效的神经，给出**第一趾蹼麻木**这一最早的感觉征，足趾被动跖屈痛）、**外侧**（腓骨肌群、腓浅神经）、**浅后**（腓肠-比目鱼肌、腓肠神经）、**深后**（胫骨后肌、屈肌、胫神经与胫后血管——“血管修复后疼痛的小腿”之爪形与胫神经征即此间隙的压力所致）。**血管外科医生在股腘重建或腘动脉栓塞后盯住的是前侧与深后间隙——再灌注使它们肿胀；脉搏仍在，足毁于内部的压力而非踝部的无脉。**
:::

::: example 抬不起来的足 {#ex-drop}
一名48岁患者在外科病房别扭的病床体位躺两天后出现无痛性右足下垂；查体踝背屈**与**外翻无力，内翻与跖屈正常，小腿前外侧与整个足背感觉减退。
::: solution
这一模式可分足下垂的两个病因。**腓总神经于腓骨颈**：背屈无力（腓深——胫前肌）**加外翻无力**（腓浅——腓骨长短肌），**内翻正常**（胫神经——胫骨后肌），感觉缺失在**小腿前外侧（腓肠外侧皮神经）与足背**（腓浅），无腰痛——此处为床挡或截石位带在腓骨头处的压迫。**L5根**病变同样有胫前肌无力，但加上**内翻与髋外展受累**（不属腓总支配的L5肌：胫骨后肌经胫神经受L4–5），常有腰痛与张力征阳性——且严重时双向均无力，除腘绳肌内侧头外反射正常。图不典型时电诊断以腓骨颈传导阻滞与胫神经支配的L5肌肉豁免来定位。两种情况处理相同：解除压迫、**踝足矫形器**防足尖拖地、对抗跖屈挛缩的牵伸——三个月无恢复则胫后肌腱转位把行走的足还回来：一条胫神经支配的肌改道去干腓总的活，一根肌腱的应用解剖学。
:::
:::

## 足与踝

::: definition 足弓与踝 {#def-foot}
足的**内侧纵弓**——弹簧——由形状（距骨楔入跟骨、舟骨与楔骨构成的拱顶）、**足底（长、短）韧带与足底腱膜**（使**足底筋膜炎**成为其跟骨起点牵张过用的弓弦——晨起第一步最痛、内侧结节压痛）与肌腱维系——**胫骨后肌**（动态钥匙：其失效即成人获得性扁平足，弓消失、后足外翻、从后方看“趾过多”征）、胫骨前肌、腓骨长肌至第一跖骨底，以及缩短会加重一切畸形的小腿三头肌。**外侧纵弓**低而静态。**踝（距小腿）关节**是嵌入两踝之间的铰链；其**外侧韧带**（距腓前、跟腓、距腓后）就是内翻损伤的序列——先ATFL（背伸90°位前抽屉试验查它），继以跟腓（中立位距骨倾斜），而三角（内侧）韧带是一张强韧的整片，其损伤伴随**双踝与三踝骨折**与后踝Volkmann碎片——Weber分型（A联合韧带下方、B在其处、C在其上方常伴联合与内侧损伤）就是关于哪些韧带失效、进而哪些骨折不稳定需手术的陈述。足底是足的外科地层学——皮肤以纤维隔连于足底腱膜（足底肿胀为何如此疼痛、切口为何须顺隔而非横断隔），三层肌，**腓肠与足底内外侧神经**（胫神经终支，其在内踝后**踝管**内卡压——“足的腕管”——给出灼痛足底伴Tinel阳性），以及骨间肌、蚓状肌与内收肌层和跖骨头、**Morton神经瘤**——第三趾蹼神经的神经周纤维化，第三、四跖骨头间的点击。
:::

::: example 反复崴的踝 {#ex-ankle}
篮球运动员落在别人脚上；踝强力内翻；外踝前下方肿胀淤青数分钟出现；她能走四步但痛。
::: solution
Ottawa规则决定要不要拍片（踝区压痛、不能负重四步——本例影像非强制），解剖决定撕裂了什么：**足跖屈位的内翻先牵拉距腓前韧带**——最常见的踝扭伤，压痛轨迹自外踝至骰骨线——**跟腓韧带**在更大暴力时加入（中立位距骨倾斜，当腓骨肌腱的连线使CFL成为缰绳）；**联合韧带**在足着地时的外旋中损伤（高位腓骨骨折、挤压试验、外旋试验，与重力应力位踝穴增宽——韧带功能的影像学陈述），而支持带上束撕裂时**腓骨肌腱**在外踝后方脱位向浅出。处理按同一解剖分级：I–II度ATFL撕裂用功能支具、早期活动与本体重训练（韧带的机械感受器随它去了；平衡训练取而代之），而充分康复后仍有前抽屉阳性的反复“打软”踝是手术候选人——Broström修复把韧带缝回骨上，恰是最初损伤本该缝合的地方。
:::
:::

::: quiz
一溃疡位于第一跖骨头，深，周围一圈胼胝，无痛；足温暖、脉搏有力。诊断为：
- [ ] 静脉性溃疡
- [x] 受压点神经性（糖尿病）溃疡
- [ ] 动脉性溃疡
- [ ] Marjolin溃疡
::: solution
受压点（跖骨头——转移负重的胼胝）、**胼胝环、无痛与良好的循环**合起来就是**神经性溃疡**：感觉缺失取消了本应迫使减载的疼痛，运动神经病的爪形把压力移到了跖骨头。静脉性溃疡在袜套区、渗出、伴皮肤改变；动脉性在远端（趾、甲褶、踝），凿孔样、缺血且**痛**；Marjolin是慢性瘢痕或溃疡的癌。危险足按定理规定的查法检查——脉搏、毛细血管再充盈、单丝感觉、鞋的内衬压力图与畸形——而治疗（减载）遵循同一解剖：全接触石膏靠把压力从溃疡移到整个足而起作用。
:::

::: history
下肢的现代解剖是外科医生与工程师的合作。Hunter的收肌管解剖与十九世纪股、腘动脉结扎术使深血管变得可以接近；1950–60年代大隐静脉进入动脉搭桥与血管外科黄金年代的股腘搭桥把浅表解剖改造来治深部疾病。髋的血管教训——股骨颈的缺血性坏死——在1950年代的骨折病房学到，并在Thompson与Charnley1950–60年代的人工关节中得到回答（低摩擦关节成形，其承重面仍依他的测量）。Trendelenburg试验（1884年）与Lachman及轴移的世纪中叶工作把查体变成物理科学；半月板的分区与ACL的足印在1980年代由关节镜外科与解剖学家敲定；而Nachemson的压力测量与动态静脉压革命（里昂与Chalmers学派的工作）给了本章所引站立肢体的物理学。
:::

## 通向何处

DVT与其预防见[[cardiovascular/vascular-disease]]；动脉疾病的处理见[[cardiovascular/vascular-disease]]与[[surgery/vascular-urological-surgery]]；糖尿病足见[[endocrine/diabetes]]与[[endocrine/diabetes-complications]]；骨折见[[surgery/orthopaedics]]；静脉曲张手术见[[surgery/vascular-urological-surgery]]；踝的放射学见[[clinical-skills/medical-imaging]]。

::: summary
- 股骨颈的血管在囊内、由远及近：这一个事实把髋部骨折分成置换与固定两组，并预测决定随访的坏死。
- NAVEL与股鞘组织起腹股沟的十字路口：鞘含血管与股管、不含神经；穿刺的高度决定假性动脉瘤、瘘与腹膜后出血。
- 膝外有韧带、间有半月板、内有交叉韧带；检查（Lachman、抽屉、倾斜）是韧带的方向，半月板的血决定缝合还是修剪。
- 小腿的静脉是一根静水柱加一台泵；静脉高压是袜套溃疡的病理生理，而“先ABPI后包扎”是动脉疾病的一票否决。
- 四个间隙、四条神经、四种压力：有脉搏的小腿痛仍可能是筋膜切开，而第一趾蹼麻木是前间隙的早期警报。
- 足的弓是韧带-肌腱复合体，其肌腱失效给畸形命名（胫骨后肌→扁平外翻足），其踝的损伤是韧带序列，Weber分型将其分为稳定与手术。
:::

## 练习

::: exercise 牵涉到哪里？ {level=1}
按神经解释牵涉：(a)髋病感觉在膝；(b)闭孔疝伸髋时大腿内侧痛；(c)L4根痛在小腿内侧面与足。
::: solution
(a)**闭孔神经至髋的关节支与其至膝的关节支**（Hilton定律：营养某关节的神经也营养相邻的肌与关节）：皮层把共同节段（L2–4）读成膝。(b)**Howship-Romberg征**——闭孔疝在其管内压迫闭孔神经，疼痛沿闭孔分布（大腿内侧至膝），伸髋内旋使管内更紧；消瘦老人伴此征的肠梗阻即诊断，而管的解剖（闭孔膜、闭孔内肌、神经在血管上下方分支）解释了为什么在那里发生。(c)**隐神经**——股神经的皮支——即小腿内侧与足内侧的皮肤——L4皮节与之同行——这就是收肌管操作后膝下隐神经感觉缺失、与L4根的小腿内侧痛落在同一条带上的原因。
:::
:::

::: exercise 逐个脉搏 {level=1}
说出搏动点、动脉及其自主动脉弓/髂顺序的起点：(a)内踝后方；(b)足背；(c)收肌管内；(d)髂前上棘尖端连线至耻骨联合的中点。
::: solution
(a)**胫后动脉**——内踝后方、拇长屈肌与指深屈肌腱之间（腘动脉较大的终支）。(b)**足背动脉**——胫前动脉的延续，拇长伸肌外侧、第一跖骨间隙（麻醉科与血管查体的足部脉搏）。(c)**收肌管内的股动脉**，贴大收肌腱——旧外科中大腿截肢止血的压迫点，也是股浅动脉远段病变的入路。(d)**腹股沟中点的股动脉搏动**——股骨头上的股总动脉（髂前上棘与耻骨联合之间：三角的中线）——下肢出血的压迫点、导管的门户，也是急诊医生、麻醉科与介入医生从不同房间共用的标志。
:::

::: exercise 固定还是置换？ {level=1}
逐例选择并给出血管学理由：(a)82岁，头下型移位股骨颈骨折；(b)26岁，头下型移位骨折；(c)79岁，转子间骨折；(d)70岁，无移位头下型骨折。
::: solution
(a)**半髋置换（机能好、活跃、认知完好者全髋）**——支持带血管已撕裂，这个年龄的头不会再血管化；置换一台手术同时解决骨折与其坏死。(b)**急诊开放复位内固定**——此后还有40年的负重，任何保头尝试都正当，延误就是血栓的机会。(c)**内固定（动力髋螺钉/头髓钉）**——囊外骨折血供完整、骨会愈合；手术的差事是力学。(d)**内固定（螺钉）并随访股骨头活性**——无移位意味着支持带血管很可能完好，风险是医源性移位，这就是“观察不治”不是无移位之答案的原因。
:::

::: exercise 膝后的神经 {level=2}
膝后脱位（高能量仪表板伤）后足底与足背均麻木、踝以下全部运动瘫痪；脉搏存在。哪些结构？血管陷阱是什么？
::: solution
**胫神经加腓总神经**麻痹——坐骨神经的两分部、或两神经本身在腘窝内被移位的胫骨牵张；足底属胫神经，足背属腓总，两系的运动瘫即腘窝的完整清单。**血管陷阱**：腘动脉被膝降支与比目鱼肌弓固定，脱位可将其牵张至**内膜撕裂而脉搏保留**——数小时内血栓跟进，截肢率随每一小时上升。处理是骨科规则：先复位脱位，然后**复位前后**查脉搏加ABI，对CT血管造影或联合血管组探查保持低阈值——有脉搏的那个病变，就是即将没有脉搏的那个。
:::

::: exercise 取静脉之后 {level=2}
一名患者的隐静脉被取作冠脉搭桥；此后小腿内侧至内踝麻木，站立时足肿。各作解释，说出神经名称与取静脉术野的解剖。
::: solution
麻木源于**隐神经**：它与大隐静脉下段密切伴行——膝下在缝匠肌与股薄肌之间、内踝前方贴静脉旁——故在取腱隧道中其分支不可避免地受压或被切断：这是术野固有的以神经换桥血管、值得写入同意的取舍。肿胀源于取材本身：浅干被取走后，下垂的肢体依赖深系统，踝部水肿就是小腿泵如今必须重新分配的负荷——用搭桥病人形影不离的弹力袜处理，腔镜取材可减轻；而卵圆窝处的腹股沟解剖（属支与淋巴结）仍是这台手术最危险的一厘米。
:::
:::

::: exercise 先包扎后提问 {level=2}
一名袜套区溃疡由按静脉路径行事的护士予高压迫包扎。两天后患者足部出现静息痛。规程漏掉了什么？绷带的按解剖分级规则是什么？
::: solution
规程跳过了**ABPI**：对缺血肢体（“混合性”溃疡——静脉的皮肤、动脉的入血）施高压迫，把本来边缘化的灌注压降到组织存活线以下，造成缺血性静息痛——一条好规则未核查便使用之危。分级规则（压迫性溃疡护理共识）：**ABPI 0.8–1.3全量压迫（40 mmHg）；0.5–0.8改良/减量压迫；<0.5禁止压迫、转诊血管科；不可压迫的血管（糖尿病钙化的中膜病变、ABPI假性升高）用趾压与体积描记**——永远先测，因为腿的两套系统可以同时失效，而治愈静脉溃疡的绷带，划得清动脉病变维持着的坏死界线。
:::

::: exercise 哪种扭伤是哪个 {level=2}
说出受伤结构与检查：(a)内翻损伤后第五跖骨基底疼痛水肿；(b)内踝后疼痛伴Tinel阳性；(c)中年男性第一跖趾关节肿胀；(d)两踝尖之间压痛、外旋痛、挤压试验阳性。
::: solution
(a)**腓骨短肌撕脱（假Jones）第五跖骨基底（茎突）骨折**——内翻时腓骨短肌与足底腱膜外侧带把粗隆拉下——对比真正的**Jones骨折**：远端1.5–2 cm、干骺端-骨干交界处，处好发应力、血供差、外科医生打钉的区域。(b)**踝管（胫后神经）卡压**，鉴别有内侧诸腱的腱炎——管内自前内至后（内踝后方）的顺序：**胫骨后肌、指长屈肌、胫后动静脉、胫神经、拇长屈肌**（“Tom, Dick And Very Nervous Harry”）——神经最浅、最好扎的目标。(c)**第一跖趾关节痛风（podagra）**——最下垂、最凉的那个关节，尿酸的最爱——鉴别为第一跖趾关节的𧿹僵直与第二跖骨头的Freiberg病。(d)**高位（联合韧带）踝损伤/Weber B-C骨折型**——骨间与胫腓韧带；挤压（压中段小腿、联合韧带处痛）与外旋试验是其查体，应力位内侧间隙清晰区增宽是其影像学裁决：需要固定的不稳定踝穴。
:::

::: exercise 设计神经阻滞 {level=3}
描绘踝部阻滞的五条神经、它们在踝部的位置，以及该操作的三个解剖学危险。
::: solution
**五个点。****隐神经**（伴大隐静脉，内踝前方）——足内侧皮肤。**腓肠神经**（外踝后方伴小隐静脉）——足外缘与小趾。**腓浅神经**（踝前方浅表、支持带外侧）——大部分足背。**腓深神经**（拇长伸肌与趾长伸肌之间、足背动脉外侧；**第一趾蹼是其领地**，故趾蹼阻滞收尾）。**胫神经**（内踝后方、拇长屈肌浅面、血管外侧——全足的主力阻滞，须抽吸、缓注、小量）。危险：**血管内注射**（胫后血管与伴行静脉——每一站都抽吸）；**神经内注射**（紧密的胫神经鞘意味着：遇阻即停；止血带还会把压迫麻痹加进鉴别）；以及**外踝处的交叉解剖**（腓肠神经与小隐静脉恰在已麻醉患者无法提醒你的地方）。实践中，一记好的胫神经阻滞加腓浅的区域浸润即可覆盖前足手术，而无须坐骨神经阻滞的运动瘫痪——踝只有五根神经之宽，但你不必全阻。
:::
