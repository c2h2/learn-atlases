解剖学语言是医学生学到的第一项临床技术，也是此后每一页病历都会用到的唯一一项技术。外科医生写下“左乳外上象限一3 cm肿块，距乳头4 cm”，放射科医生写下“右肾盂输尿管交界处一8 mm结石”，理疗师写下“肩关节外展受限至90°，伴疼痛弧”——三人做的是同一件事：用一套共享的、精确到足以让另一栋楼、另一个专业、另一个大洲的人都能找到目标的约定，在空间中为一个东西定位。这套约定是被发明出来的——而不是被发现出来的——出自一个曾多次因含糊其辞的提问而付出流血代价的职业。值得把它当作一个被设计出来的系统来学习：它的原语很少——一种体位、三个平面、一组表示方位关系的词汇、一组表示运动的词汇，以及一套坦率地规定“身体与教科书不符时该怎么办”的规则。

本课确立原语、它们在临床中的误用，以及这套语言向影像学延伸的现代部分——阅片室的约定继承自解剖台，只是应用的对象从尸体变成了图像。

## 参照体位

::: definition 解剖学姿势 {#def-anatomical-position}
**解剖学姿势**是人体解剖学的参照框架：身体直立，头与眼平视，双足并拢或微微分开、脚尖朝前，上肢垂于体侧，**掌心朝前**，拇指指向远离身体的一侧。每一个方位术语的含义都是“在解剖学姿势下”，与患者当前的实际姿势无关。拇指的外旋是前臂得以旋转的原因：在解剖学姿势下桡骨与尺骨互相平行，旋前时桡骨跨过尺骨——因此“掌心朝前”的规则并非出于美观，而是记录了肢体旋转的胚胎学。
:::

“所有术语均指解剖学姿势而非患者当前姿势”这条规则，恰好解决了它当初被制定时想要消除的歧义。仰卧患者的“前面”依然是前面，即使此时它是朝向天花板的那一面；足的“内侧缘”依然是内侧，即使当踝关节交叉时它朝向外侧。经常逃出这条规则的结构家族只有一个，就是头，因为成人头部相对胚胎时期的排列在躯干上弯折了近直角：在头部，**垂直面**与**水平面**是相对耳眦平面（眶下缘至外耳道上缘的连线）定义的，而不是相对地面；脑内的“上方”对直立者而言意味着“朝向颅顶”——这就是脑干自身的中轴需要另一套名称（沿神经轴的嘴侧/尾侧）的原因。

::: definition 方位关系术语 {#def-relational}
- **上/下**（颅侧/尾侧）：朝向身体中轴的头端/尾端。
- **前/后**（腹侧/背侧）：朝向身体的前面/后面——在四肢，对应的术语是**近侧/远侧**（朝向/远离附肢附着点）；在手与前臂，“前”被**掌侧（跖侧）/背侧**取代，在足则为**足底侧/足背侧**。
- **内/外**：朝向/远离正中面。
- **浅（外部）/深（内部）**：朝向/远离体表。
- **同侧/对侧**：位于身体的同一侧/对侧。
- 就四肢而言，**桡侧/尺侧**（拇指侧/小指侧）与**胫侧/腓侧**在旋转使内/外易于混淆时取代内/外——腕可以处于旋后、旋前或两者之间，但桡骨永远是桡骨。
:::

::: theorem 离开参照框架，任何术语都没有意义 {#thm-frame}
每一个正确的解剖方位陈述都隐含着量化条件：“在解剖学姿势下，在这一侧，相对于这两个被命名的标志。”一份报告、一项查体所见或一段手术记录，若省略了这三个坐标之一，并不是做出了一个可能错误的陈述，而是根本没有做出陈述——读者必须暗中补上一个参照框架，而不同的读者会补上不同的框架。
:::

::: proof
这一失效模式以最字面、也最有外科审计意味的方式被记录下来。在体位与影像标准约定出现之前的时代，弹头或结石的“水平”可以相对于乳头、脐，或某节椎骨棘突来报告——而那椎骨是在端坐、平卧或侧转的患者身上触到的——于是同一句描述在不同读者手中会指向不同的结构。这门学科选定的固定点是：椎骨，从枢椎（C2）向下编号，颈部最可触及的棘突作为临床标志（C7，隆椎——你摸得到的那根棘突，T1的更低也常常更深）；肋骨，从第二肋向下数，其软骨与胸骨角相接（Louis角，你摸得到的那个平面，平对T4/T5椎间盘、气管分叉与主动脉弓——这就是每一本体格检查手册都出现“从胸骨角向下数肋”的原因）；以及脐——它并不可靠（会随膨隆与体型移动）——这就是放射科医生以命名的椎骨而非以瘢痕定位的原因。注意连标志本身也服从这条定理：胸骨角之所以可用，正因为它由其与某节椎骨的关系被*定义*，从而闭合了触诊与影像之间的环。还要注意编号约定中内含的认识论卫生——“L3/4椎间盘水平”无论患者是否站立扫描都成立，而“脐的水平”则随姿势改变含义：这套语言编码了哪些陈述能经受变化、哪些不能。
:::

## 平面、切面与运动轴

::: definition 平面 {#def-planes}
**平面**是穿过身体的平面；起主导作用的有三族。**正中（正矢状）面**左右等分身体；任何与其平行的面均为**矢状面**（旁正中矢状面）。**冠状（额）面**分前与后；穿过身体重心附近的那个面在随口说话时也被称为**斜切面**——但规范用法只把“斜”留给有意取斜角的面，如斜位体层成像。**横断（轴、水平）面**分上与下。**切面**是一次切割的结果：**横断（轴）切面**是横断面内所见结构的呈现，而一个器官的横断面形状是关于该器官的一个事实——肝、心、子宫的轴位轮廓，正是它们在如今比尸体讲授更多解剖的CT与MRI上的样子。
:::

运动围绕垂直于其发生平面的**轴**进行——屈/伸在矢状面内绕冠状轴扫动，外展/内收在冠状面内绕前后轴扫动，旋转在横断面内绕垂直轴进行。**环转**是前三种运动在髁状关节或球窝关节处的合成，描出一个顶点位于关节内的圆锥。

::: definition 运动：按临床医生被要求记录的术语 {#def-movements}
**屈曲**与**伸展**减小并增大相关关节骨之间的角度（膝关节例外：屈膝是小腿的后旋，越过中立位的“伸膝”是过伸）。**外展**与**内收**使肢体远离与朝向正中面；**侧屈**使躯干或颈部侧向倾斜。绕长轴的旋转分为**内旋/外旋**；**旋后**与**旋前**旋转前臂使掌心向上或向下；**背屈**与**跖屈**使足尖抬起与下压，**内翻**与**外翻**使足底转向内侧与外侧。专门的运动有自己的名称，因为它们常见：**前伸/后缩**（下颌、肩带），**上提/下降**（肩、下颌骨），拇指的**对掌**（鞍状关节屈曲、内旋与外展的合成，使拇指掌侧与小指掌侧相贴——其丧失是正中神经麻痹中的临床事件），以及足部复合的**旋后/旋前**（对距下关节而言大致分别是外翻兼外展、内翻兼内收的并集——一个值得记住的命名陷阱，因为足病医生的“过度旋前”指的不是前臂的运动）。
:::

::: example 规范描述的腕关节 {#ex-wrist}
一名患者跌倒时手掌撑地，此后主诉“往下弯手腕”困难。查体：手保持轻度屈曲位，腕近端背侧隆起（侧位呈“餐叉样”外观），被动活动诱发疼痛。
::: solution
手掌撑地跌倒加“餐叉样”畸形是经典的**Colles骨折**——桡骨远端向背侧移位。现在来看看病历必须以语言而非图像记录的内容：腕关节主动**背伸**丧失、**屈曲**部分保留；移位本身应描述为远折端的**背侧（后侧）倾斜与成角**并**桡侧（外侧）短缩**——这正是手看起来向拇指侧偏移的原因。对于一位掌心朝大腿的患者，“往下弯手腕”实际上是屈曲加旋前的复合动作，而简单重复这句话的理疗转诊单开的是一道歧义。这个教训具有一般性：每一条运动所见都应写明关节、运动的平面/轴与侧别——“左腕：背伸0°（正常70°），屈曲60°（正常80°），被动旋后诱发疼痛”才是一条另一位临床医生可以核查的陈述。
:::
:::

## 分区、象限、体腔与躯干内部

::: definition 身体及其体腔的划分 {#def-regions}
身体分为**头、颈、躯干与四肢**；躯干被**膈**分为**胸廓（部）**与**腹（部）**，腹之下为**骨盆（部）**，经骨盆上口与腹相延续。**背侧体腔**（颅腔加椎管）与大得多的**腹侧体腔**内衬浆膜：腹侧体腔的胸部部分内衬**壁胸膜**（胸壁），在肺表面反折为**脏胸膜**，两处不同表面的壁胸膜相遇而肺不存在的部位形成**肋膈隐窝**——隐窝的存在说明了液体可以积聚而肺并非“被覆盖”；腹部的内衬是**壁腹膜**与**脏腹膜**，其间有**大腹膜腔与网膜囊**，盆腔的腹膜反折决定了发炎的阑尾定位于何处、游离液体为何流向直肠子宫陷凹（Douglas窝）。内衬的**间皮**分泌恰好足以润滑滑行的浆液——当Starling力失衡时，这一事实就以腹水或积液的形式变得可见。
:::

腹部的临床地理学存在于两套相互竞争的体系之中。**四分法**（以脐的平面划分左右上下四个象限）快捷且适合定位疼痛；**九分法**——左右髂区（腹股沟区）、左右腰（腹）区、左右腹上（季肋）区，加中间的腹上区、脐区与腹下（耻）区——把疼痛与肿物映射到器官上，仍是多数诊断学教材查腹时使用的方法。

::: example 两次阑尾炎定位 {#ex-appendix}
一名19岁患者自晨6时起脐周正中疼痛，现定位至右下腹，伴食欲不振及疼痛开始后呕吐一次。
::: solution
两种描述都正确，各自的细节都来自胚胎学。**脐周**痛是**内脏痛**：盲肠与阑尾是中肠衍生物，由肠系膜上动脉及其内脏传入神经支配，传入纤维约在T10水平进入脊髓，把疼痛投射到脐周相应的皮节——位于中线、定位模糊，因为传入纤维双侧进入而大脑皮层无法区分左右。后来的**右下腹**痛是**躯体（壁层）痛**：发炎的阑尾此刻刺激覆盖其上的壁腹膜，其感觉神经为节段的肋间神经与腰神经，产生尖锐、局限、偏侧的疼痛。同一事件，用象限语言与用神经语言各描述一遍，就成了临床推理：中肠区域的内脏痛→躯体痛序列，除非证实否则即为阑尾炎；而压痛最明显点接近发炎器官（故有McBurney点——自髂前上棘至脐连线的内1/3与外2/3交点——这是个命名法上的人名，但有用，因为它命名的是几何而非人物）。
:::
:::

::: warning 悄悄误导人的词
三类术语造成的伤害与其数量不成比例。**“Flank”（腰部/侧腹）**指侧胸腹壁，但肾绞痛被描述为“腰部向腹股沟放射”，而胸膜炎是“胸膜性、向肩部放射”——病人三个词都用；务必让患者用自己的话、用指尖重新表述一遍。**“Perforated”（穿孔）、“ruptured”（破裂）与“hernia”（疝）**：穿孔是空腔脏器壁的洞，破裂是实质器官或动脉瘤的迸破，疝是穿过壁层的突出；把肠梗阻说成“肠穿孔”不是同一解剖中的同一种急症。**人名命名的间隙与三角**（McBurney点、Calot三角、Petit三角）对没有背下它们的人不含任何几何信息；解剖学当前的编辑风格——“先说边界，再说内容”——恰恰因为人名术语在最需要精确的时刻（手术台上、法律文书里）失效。
:::

## 影像学：语言继承了参照框架

::: definition 断面影像的阅片约定 {#def-imaging}
CT与MRI图像按惯例以**横断面显示，仿佛自患者足端向上观察**：患者的**右侧在阅片者的左侧**，前在上，后在下；图像堆叠中的“上”是**头侧**。**胸部X线片则仿佛面对患者显示**——同样是患者右侧在阅片者左侧；侧位胸片显示患者面向阅片者左侧，并以标记注明左右。对比惯例：在CT上骨为**高密度**（白），气为**低密度**（黑）；在MRI上信号称为**高信号/低信号**；由于T1加权与T2加权序列使脂与液的表现互为颠倒，MRI报告中的颜色词在不知道序列时毫无意义——这是约定胜过直觉的一次小巧而纯粹的胜利。
:::

::: example 以正确框架读一份报告 {#ex-imaging}
要求阅读T10水平的轴位CT层面。“我该在哪里找下腔静脉与主动脉？什么告诉我这一层面在T10？”
::: solution
先用框架，再用局部解剖。框架：图像为轴位、自下向上看——患者右侧在你的左侧，前方在上，因此结构的前部（右室流出道、升主动脉的延续）位于屏幕上方。T10处椎体是中后方的圆形结节；**主动脉**位于椎体稍偏左前；**下腔静脉**在主动脉的前右侧，紧贴肝后缘，因中心静脉压低而被压成椭圆形或缝隙状——两个事实，位置与形状，让你一眼区分二者，即使两者都是灰色。判断层面在T10，是因为食管在此处穿膈（伴迷走神经干），主动脉则在其后方于T12经主动脉裂孔；也因为T10处可见双侧肺而其间的中心结构已由膈脚取代心脏。读断面解剖就是如此：定位框架，定位一个层面标记结构，再推导其余。下一章里每个器官的位置都遵循同样的两步。
:::
:::

## 变异、命名与诚实问题

::: definition 解剖变异 {#def-variation}
**解剖变异**是偏离标准描述、但仍处于健康人群所见于范围内的差异：不是畸形（畸形损害功能），也（通常）不是疾病。变异是以数目计的常态，而非例外：**肝动脉**约五分之一的人起自肠系膜上动脉或腹主动脉；**左位下腔静脉**见于千分之几；**副左肝静脉**、肺**奇叶**、**掌长肌**缺失10%–15%、**甲状腺最下动脉**——每个区域都有这样的清单，因为“标准解剖”是一个统计学摘要，外科医生头脑中的模型必须携带关于结构的概率分布，而不是单张示意图。
:::

::: proof
变异为何有临床意义，可从变异的发生方式推出：曾经可行并一直可行的胚胎学备选方案。起自肠系膜上动脉的迷走肝动脉是一条按错误的相对顺序生长的胚胎血管持久存在；它重要，是因为它走行于肝总管附近，可能在胆囊切除时被钳夹——所以胆囊切除手术的语言是一套以*关系*而非以大小和位置识别结构的语言（由此才有“关键安全视图”：只有两条、且仅有两条结构进入肝脏，即胆囊管与胆囊动脉，并将胆囊上1/3自胆囊床剥离）。命名体系编码的是同一哲学。国际标准**Terminologia Anatomica**（1998年及其后续修订）规定拉丁文形式并附英文对应词，在有描述性术语处废止人名术语，并正式区分“变异”与“异常”；其对临床病历的实际影响是一条构成规则：结构以其关系与内容命名（直肠子宫陷凹、侧脑室前角、颞浅动脉的一级分支），这是从未听说过那个人名术语的读者也能使用的信息。
:::

::: example 肌肉缺席，后果在场 {#ex-variation}
一名手外科医生为正中神经麻痹患者计划掌长肌腱转位；术前检查发现双侧均无掌长肌腱。
::: solution
掌长肌缺失是最常见的“变异”之一（在许多人群中10%–15%缺失，某些人群更高），完全无害，而在此处具有决定性：预定的移植或转位必须在进手术室之前重新规划，而不是在术中才发现——这正是术前检查变异存在的全部理由。同样的思路支撑着活体捐献手术的语言（肝左叶或右叶、一个肾：血管的变异决定谁可以捐献），也解释了为何解剖学诚实的语域说“通常”、“约70%的病例起于”、“可重复”，而临床后果要求确定：解决之道在于*被命名的结构由跨越变异而持续存在的关系来定义*——胆囊动脉就是沿Calot三角走向胆囊的那条血管，无论在本例中恰好是哪条血管扮演这一角色。
:::
:::

::: history
这门语言比大多数机构都古老。亚历山大的Herodotus（约公元前300年）创造了沿用至今的术语——以肠管十二指之长命名的*duodenum*（十二指肠）、以及mamma（乳）一词；Galen公元2世纪的拉丁文与希腊文命名法，靠翻译与权威而非解剖，在大学中统治了一千余年。Andreas **Vesalius**以*De humani corporis fabrica*（《人体的构造》，1543年）恢复了手术刀的地位，按所见命名结构，并在上千页中悄然纠正Galen；Fabricus、Varolius、Falloppio、Eustachius与Arantius增添了至今仍刻在骨与管上的人名；William **Croone**以及18世纪的莱顿与爱丁堡学派出于动脉与神经教授解剖。**Gray's Anatomy**（1858年）固定了英语学生的词汇；1895–1935年的**巴塞尔、伦敦与波恩**约定试图统一拉丁文命名，成功了一半；**Terminologia Anatomica**（1998年）在国际解剖学协会联合会的领导下完成了这一尝试。影像学的约定来得最晚也最快：先是横断面，随后自1972年（Hounsfield的CT）起决定自足端向上显示——这个选择与“掌心朝前”规则同样任意，也同样必要，并且同样承担着患者安全的重量。
:::

::: quiz
一处伤口“位于腕上3 cm，前臂尺侧，穿透皮肤并经过屈指肌腱的深面，桡动脉搏动完好”。所列四条推断中哪一条是安全的？
- [ ] 断裂的肌腱是桡侧腕屈肌。
- [x] 所描述的肌腱位于小指侧，指浅、指深屈肌经此——桡侧腕屈肌本会被描述为桡侧；而桡动脉搏动完好对尺动脉不作任何说明。
- [ ] 桡神经损伤。
- [ ] 患者不能屈手指。
::: solution
这是一道翻译测试题，也是整套词汇的全部意义所在：**尺侧**指小指侧；**桡侧**指拇指侧，尺侧的伤口伴桡动脉搏动完好，对尺侧一无所排除——尺动脉恰恰是此处危险的血管，这就是病历写明脉搏、而手部必须以Allen试验或指端灌注来评估的原因。被命名的深部结构位于尺侧，因此不可能是桡侧腕屈肌（桡侧）；“屈肌经其深面”这一关于伤口底的陈述定位的是深度而非神经——腕部正中神经居中而非尺侧；“屈指南深面完好”告诉我们该腱*完整*或未受累，而非断裂，故手指屈曲可能保留。阅读解剖描述，是一门注意语言中什么*被*定位、什么*未*被定位的学问——在手术刀或扫描之前。
:::

::: summary
- 所有解剖陈述都在掌心朝前的解剖学姿势下做出；患者的实际姿势从不改变结构的方位术语。
- 三个平面、一个框架（右侧在阅片者左侧）、以椎骨与肋骨为锚的标志，把触诊与影像变成同一个坐标系；脐不在标志之列。
- 运动名称关节与平面、轴配对；精确记录写明关节、平面与侧别——而四肢专用术语（桡侧/尺侧、胫侧/腓侧）的存在，是因为旋转会让内/外说谎。
- 内脏痛居中而模糊，躯体痛偏侧而尖锐；四分法与九分法同一地理的两种方言，选择哪种方言记录了所指疼痛的种类。
- 影像学约定是继承自解剖台的约定应用于图像；MRI信号名离开序列毫无意义，CT密度名离开对比状态毫无意义。
- 变异在界定范围内是常态；以关系与内容而非位置或大小命名结构，并写下有什么、没什么、以及对下一个经手者意味着什么——用规范术语，在任何人动刀之前。
:::

## 练习

::: exercise 方位翻译 {level=1}
用标准术语重述：(a)“胆囊底，相对于肝脏面”；(b)“阑尾根部，相对于盲肠”；(c)“心，相对于食管与胸壁”；(d)“腓总神经，相对于膝关节线与腓骨颈”。
::: solution
(a) 胆囊底通常在肝**下面（脏面）**沟的中1/3与外1/3交界处突出，而相对于肝这个器官它在**下方与前**，因其达腹壁处正当第9肋软骨尖。(b) 三条结肠带汇聚于根部，根部在盲肠的**后内侧**、盲肠中1/3与后1/3交界处——这是蚓突是盲肠后内侧壁附属物的几何原因，也是其尖端游移的原因（盆位30%，盲肠后位65%——具外科重要性的百分比）。(c) 心位于食管**前方**、胸壁**后方**（在胸骨体与第3–6左侧肋软骨之后，这正是听诊器需要的答案）、胸膜腔**内侧**。(d) 腓总神经**在浅表、沿外侧（腓侧）**绕**腓骨颈，约在关节线下方一横指**——这一关系经受膝关节的任何旋转而不改变，也是石膏在腓骨颈处过紧导致足下垂的原因。
:::
:::

::: exercise 数出节段 {level=1}
一份病历写道：“左侧自肺尖至第6肋水平，叩诊呈鼓实音（绝对浊音）伴支气管呼吸音。”累及哪个体腔？提示多大的积液？“从胸骨角向下数”能确认什么？
::: solution
“绝对浊音（石样浊音）”是浆膜腔积液的体征——**左侧胸膜腔**，因为肺被压缩避让，胸壁传导积液上方实变/不张肺的声音，在其上界处产生支气管呼吸音。前方至第6肋大致意味着积液占据左胸腔上半——大量积液（数百毫升至数升；仅肋膈隐窝在背部胸片显影之前便可容纳300–500 mL）。从胸骨角（平对T4/5椎间盘与第2肋软骨的平面）向下数，确认第6肋*究竟是哪一根*，从而确认积液上界位于胸腔中部——也排除了最常见的错误：从第一个可触及的隆起开始数（常常是锁骨或T1棘突，取决于你在身体的哪一端）。
:::
:::

::: exercise 脊柱的平面 {level=1}
一枚椎间盘突出被描述为“L4/5后外侧”。画出经过椎间盘的三个平面，说出该描述预测的运动与神经根。
::: solution
横断面把椎间盘分为上下两半；矢状面（脊柱影像惯例中的冠状位，可同时显示两侧椎弓根——“南北”视图）分左右；后外侧这一描述词把两者结合：突出在椎间盘中心的后方（向后——突入椎管的侧隐窝/椎间区）且偏于一侧（外）。危险的神经根是**L5**：在每个腰段，出口根位于相应椎弓根下方的椎间孔内，被中央型/旁中央型后外侧突出所放过，后者捕获的恰是下一节段的**行走根**——脊柱解剖中最常被考查的关系，且纯属关系语言：“行走根对出口根”，而非大小，决定缺损。预测的运动是**屈曲**加重疼痛（把髓核向后挤压）、直腿抬高沿神经根走行复制疼痛——这就是查体像其他一切一样，被描述为运动与神经之间的关系。
:::

::: exercise 体表投影 {level=2}
标出并给出以标志定义的边界：(a) McBurney点；(b) 妊娠34周孕妇阑尾的体表投影；(c) 输精管触诊部位；(d) 右心室增大患者的心尖搏动。
::: solution
(a) 自**髂前上棘至脐**连线的内1/3与外2/3交点，位于右下（髂）区——一个“线加比例”的定义，而非空间中的一个点。(b) 根部（盲肠交界处）大致仍在耻骨结节连线的侧方交界处，但妊娠子宫把阑尾推向**外上方**：至妊娠晚期压痛最明显点向右腰或肋缘下移动——一个可变的关系，也是妊娠期阑尾炎表现不典型且就诊偏晚的原因之一。(c) 在精索后份、**皮下环处或其在腹股沟管内的上方**，一根坚韧的索状结构，可在皮下滚动——之所以可触及，是因为它是一根肌壁厚、没有同样触感的邻近重要邻居的管子，这也是输精管结扎术解剖学的基础。(d) 心尖搏动是**心搏动的最外下点**；右心室增大时心旋转并移位——心尖变靠前且可能触不到，而胸骨左缘活动增强；应记住的短语是“单纯右心室增大时胸骨左缘抬举感，心尖向外移位而不下移”，因为该描述说的是移位的*方向*——把躯干框架的语言应用于一个变化的器官。
:::

::: exercise 读一份MRI报告 {level=2}
一份MRI报告写道：“右侧脑室前角一12 mm病灶，T2高信号，T1低信号，无弥散受限。”解释每个坐标与每个信号词的贡献，以及没有增强图像这句话不能说什么。
::: solution
坐标：**右侧**与**前角**把病灶定位于侧脑室具名腔室与分部——而“侧脑室的”已把它置于额叶白膜深面，因为脑室是大脑内的间隙。信号词：**T2高信号**伴**T1低信号**是游离水（单纯液体——囊肿、水肿、脑脊液）的特征信号，因此该信号模式提示但不能证明病灶含液；**无弥散受限**不利于厚细胞成分/脓/急性梗死。没有增强，报告便不能说是否存在**强化的实性成分**——区分良性蛛网膜/室管膜囊肿与囊性肿瘤的那个特征；且脱离序列谈信号不能识别组织，只能反映其含水量与屏障。本题的要义：这套语言是组合性的——框架+腔室+序列+行为——读者的功力在于检查一句话把四个坐标中的哪一个留了空。
:::

::: exercise 手术室里的变异 {level=2}
腹腔镜胆囊切除中，术者注意到“一根动脉口径的血管自肝固有动脉区域走向肝IV/VII段肝门，位于预期胆囊动脉的内侧”。鉴别诊断中有哪些变异？“关键安全视图”以关系解剖的语言说究竟确立了什么？
::: solution
肝胆囊三角内动脉血管的鉴别诊断包括**替代右肝动脉**（起自肠系膜上动脉，走行于胆总管后外方）、**副右肝动脉**、起自左支或右支的**肝中动脉**，以及——这一内侧走行的描述所提示的——横跨向旁正中区域的动脉变异。关键安全视图是关系定义的术中形式：清除肝胆囊三角内的脂肪与纤维组织，把胆囊下1/3的浆膜自胆囊床剥离，确认**进入胆囊的恰好两条、且仅有两条结构**——胆囊管与胆囊动脉。该视图“确立”的并非解剖标准，而是：无论存在哪些血管，属于胆囊的只有这两条，其余属于肝并须保留。以*走向何处、供养何物*而非以名称来命名结构，是唯一对变异稳健的命名法——定理的实践形态。
:::

::: exercise 写出查体所见 {level=3}
把以下三条所见改写为精确的解剖学记录，各按要求写明关节/平面/侧别或框架/标志/节段：(a) 第一掌指关节肿胀；(b) 腹部搏动性肿物；(c) 头向右转时疼痛。
::: solution
(a)“右手第一掌指关节：肿胀、皮温高、被动屈伸压痛（活动度0–40°，对侧0–90°）；静息位无偏斜；第一背侧骨间肌萎缩”——写明关节、侧别、所查运动平面、同侧/对侧对照。(b)“上腹部与脐区搏动性、膨胀性肿物，宽约7 cm，自脐上约2 cm向剑突延伸，无压痛，双侧股动脉搏动可及”——分区名称（上腹/脐区）、一行之内给出大小、以标志表述节段，以及远端脉搏的陈述，这本身就是解剖学推理（动脉瘤会栓塞；无脉即定位）。(c)“颈椎向右旋转诱发右侧颈旁区疼痛并向右枕部放射，于C2/3旋转时最重；右侧Spurling试验复制出根性痛”——运动、侧别、方向、节段，以及局部痛与放射/根性痛的区分，这正是神经病变的解剖学语言。要记住的模式：**结构、侧别、关系、诱发运动**——每条查体所见都是这四个名词的集合。
:::

::: exercise 设计更好的报告 {level=3}
某放射科提议把腹部报告中所有区域描述替换为椎体水平坐标（“肿物位于L2，中线左4 cm，左肾前方2 cm”）。列出该提议的得与失，并说明各自在什么场合才是正确的体系。
::: solution
得：坐标体系**与姿势无关**（L2无论仰卧或站立都是L2，不像“脐的水平”），可被机器读取，与CT、MRI实际显示人体的方式一致；摆脱对检查者触诊与体型的依赖（肥胖、腹水、妊娠会使体表标志说谎）。失：外科医生经体表手术——转换血管内修复入路需要腹主动脉分叉的*体表投影*（正中线、约骶骨岬水平，是可触及的——坐标被翻译回触诊），放疗医师每日摆位需要体表标记，而查体的临床医生以分区思考，因为其信息来自体表（压痛、肿物、反射）。正确答案，也是较好的报告的通行做法，是**双重编码**：同时写明内部坐标（椎体水平、具名关系）与体表翻译（分区、象限、可触标志），使同一结构既可被手也可被机器找到。一套原语可被两种独立方法核查的语言，正是病历存在的目的——这不过是解剖学姿势规则在更高一层的重演。
