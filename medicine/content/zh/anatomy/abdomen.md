腹部是一个主要仅凭压力就留住内容物的容器：一条管道（肠）以双层浆膜（肠系膜）悬挂于脊柱（主动脉、静脉、肾）之上，外包一层其设计决定肠在何处疝出的肌筋膜壁，内衬一个其隐窝与沟决定感染去向的浆膜囊。关于它的一切临床——急腹症、疝、门静脉高压者的出血、结石游走性的绞痛、恰好发生在某一个弯曲的缺血性结肠炎——都从这套架构推出。

本章讲授腹膜腔及其交通、腹壁与腹股沟区，然后逐区讲器官：前肠、脾-肝-胆、中肠与后肠、腹膜后隙及其尿路，以及大血管。

## 腹膜及其交通

::: definition 腹膜、网膜与肠系膜 {#def-peritoneum}
**腹膜**是衬于腹壁（**壁腹膜**——敏感、节段性、能定位）并包被脏器（**脏腹膜**——自主神经、定位差）的浆膜，两者间为潜在腔隙。腹膜反折自身处形成膜片：**大网膜**（“腹腔的警察”，自胃大弯悬垂，其两层围成胃后方的**网膜囊**，经**Winslow网膜孔**进入——这是唯一的天然交通，其前界含**肝门三联结构**，下壁为下腔静脉）；**小网膜**（肝胃韧带与肝十二指肠韧带，携**左、右胃血管**，其游离缘内有肝动脉、胆总管与门静脉）；以及**小肠系膜**（自十二指肠空肠曲至右髂窝的扇形）、**横结肠系膜**、**乙状结肠系膜**与支撑脾的**膈结肠韧带**。十二指肠（除D1）、升结肠与降结肠、胰、肾、输尿管与主动脉为**腹膜外位（腹膜后）**；升、降结肠为继腹膜外位，经**Toldt筋膜**贴于后壁——正是这个外科平面让人可以通过“拆开”发育所粘连的结构而游离结肠。
:::

**结肠旁沟**——结肠外侧缘与腹壁之间的通道——随膈肌运动与体位输送液体：从膈下间隙下行至髂窝（一个表现得像胆囊炎的阑尾炎，反之亦然：盆腔感染向上蔓延），并经系膜根部跨中线由右盆至左盆。横结肠以上的**结肠上区**（膈下与肝下间隙）与其下的**结肠下区**（成对的结肠旁沟与盆腔）构成空腔脏器穿孔的脓肿地图；网膜囊是其隐藏的房间，经Winslow孔流入、经大网膜腔引流。

::: example 胰腺炎的后门 {#ex-lesser-sac}
一名重症胆源性胰腺炎一周后出现早饱、上腹可触及的饱满与持续发热；CT示胃后一大片液体积聚。
::: solution
积液在**网膜囊**，解剖同时解释了病程与治疗。胰腺横跨网膜囊的囊底、位于腹膜外；发炎腺体的渗出在前侧突破腹膜面进入囊内，其上方为胃（早饱——胃自后方被压），下方为横结肠系膜（液体可经此被推入大腹膜腔），与腹腔其余部分仅经**Winslow孔**相通（这就是此类积液能局限为**假性囊肿**而不弥散的原因）。成熟且有症状的假性囊肿**经胃或十二指肠引流（经胃、内镜或手术）**——这个手术之所以存在，正因为囊壁紧贴胃后壁，正是这一关系使其产生症状。而此孔的临床另一面：经Winslow孔的内疝（肠管疝入肝门三联结构后方）是“闭袢性梗阻而其余肠管外观正常”的经典，也是青年与老年缺血的具名原因。
:::
:::

## 腹壁与腹股沟区

::: definition 腹壁的层次与腹直肌鞘 {#def-wall}
自皮肤向内：**皮肤、浅筋膜（Camper脂肪层与Scarpa膜层）、腹外斜肌、腹内斜肌、腹横肌、腹横筋膜、腹膜外脂肪、壁腹膜**。三块扁肌的腱膜在**腹直肌鞘**内包绕**腹直肌**：在**弓状线**（约脐与耻骨结节连线中点）以上，三层分别经肌的前、后方；在其下，三层均走**前方**，只留腹横筋膜贴于肌后——这个薄弱点有时使下腹正中切口裂开，或使腹直肌鞘血肿沿之下潜。鞘的内容（腹壁上、下动脉，肋间神经终支）决定了：**白线**为何**血管稀少**（外科入路所在），侧缘为何是血管出血之处（血肿，以及神经卡压的腹直肌鞘综合征）。
:::

::: definition 腹股沟管与肌耻骨孔 {#def-inguinal}
**腹股沟管**是下腹前壁的一处潜在通道，自腹横筋膜内的**腹股沟管深（内）环**（腹股沟中点、腹股沟韧带上方1.25 cm）至腹外斜肌腱膜内的**浅（外）环**（耻骨结节上方）；男性通过**精索**（输精管、睾丸/提睾动脉、蔓状静脉丛、淋巴、生殖股神经生殖支），女性通过**子宫圆韧带**，另有**髂腹股沟神经**（L1）——说它“通过”并不确切——手术是有意打开它的。**腹股沟（Hesselbach）三角**——外侧为腹壁下血管，内侧为腹直肌缘，下方为腹股沟韧带——是腹横筋膜的薄弱区。Fruchaud的**肌耻骨孔**统一了疝的解剖：腹前壁下方由髂耻束、髂前上棘、耻骨结节与联合腱围成、仅以腹横筋膜覆盖的单一区域，是直疝、斜疝与股疝的共同部位；补片修补（Lichtenstein与腹膜前入路）即针对此孔对腹压的有意加固。
:::

::: theorem 疝以其与血管的关系定义 {#thm-hernia}
腹壁下血管是解剖学家的标志，也是外科医生的：**腹股沟斜疝**在其**外侧**进入深环（未闭的腹膜鞘突——其不闭合即先天性的鞘膜积液）；**腹股沟直疝**在其**内侧**经Hesselbach三角突出（后天性腹横筋膜薄弱）；**股疝**则在腹股沟韧带**下方**经股环通过（前为韧带，后为耻骨梳韧带，外侧为股静脉，内侧为腔隙韧带），出现于腹股沟韧带下方，常较小，常见于经产妇，并**早期绞窄**，因为股环坚硬不让。
:::

::: proof
这条规则在三个方面证明自身价值。**诊断**：耻骨结节上内方出现咳嗽冲击感为腹股沟疝；韧带下方、耻骨结节外侧为股疝——结节与韧带正是血管规则的实体形式，因为深环在其稍上方，股管在其稍下外方。**风险**：股环坚硬的四边界（腔隙韧带、耻骨梳韧带、腹股沟韧带、股静脉）解释了为什么“老年瘦弱女性腹股沟区小包块伴肠梗阻”除非证明否则即为股疝，也解释其梗阻诊断为何偏晚（Richter疝——仅对系膜侧肠壁被嵌顿，肠腔尚通，绞窄隐蔽）。**修补**：一切腹股沟疝修补术或者关闭或缺损桥接并解除会再次开放的张力——Shouldice以缝合将腹横膜固定于腹股沟韧带，Lichtenstein以补片铺过肌耻骨孔，腹膜前修补（Stoppa、腹腔镜TAPP/TEP）让腹压本身把补片压向腹壁——这就是“自后向前”的入路以同一平面处理直疝、斜疝与股疝的原因，定理的外科形态。神经地理（髂腹下、髂腹股沟、生殖股神经生殖支，以及腹腔镜套管所涉的股外侧皮神经）是疝修补术后慢性腹股沟疼痛存在的原因，也是补片须避开精索结构外侧“疼痛三角”的原因。
:::

## 前肠：胃、十二指肠及其动脉

**胃**居上腹与左季肋部：贲门、胃底、胃体、胃窦、幽门——幽门平**经幽门面（L1）**，位于胸骨上切迹与耻骨联合连线的中点，是腹部解剖最有用的水平面（它同时通过十二指肠空肠曲、胰颈、肾门，稍下方还有脊髓圆锥与主动脉分叉）。其血供——**胃左动脉**（腹腔干）、**胃右动脉**（肝动脉）、**胃网膜弓**（脾动脉/胃十二指肠动脉）、**胃短动脉**（脾动脉）——走行于大小弯，这就是胃切除术是一场沿具名血管线的解剖、而胃短血管是分离大网膜时脾门之险的原因。**十二指肠球后壁**是经典的出血性溃疡部位，因为**胃十二指肠动脉**恰在其后方：侵蚀造成**呕血与黑便**，而前壁溃疡穿孔入腹膜腔（膈下游离气体）。十二指肠除最初2 cm外均为腹膜外位，其第三部在腹主动脉与肠系膜上动脉之间被**肠系膜上血管自前方横跨**——主动脉肠系膜角在极度消瘦时变窄，使D3梗阻（**肠系膜上动脉综合征**，其呕吐是腹腔动脉压迫综合征同一几何的变异型）。

## 肝、胆道与脾

::: definition 肝的叶、段与肝门三联 {#def-liver}
肝真正的解剖划分不是镰状韧带那两叶表面的划分，而是自**胆囊窝至下腔静脉的功能线（Cantlie线）**：按**门静脉血管流域**划分左右半肝，再按门静脉分支细分为**八个Couinaud肝段**——肝切除、活体肝捐献与肿瘤报告的语言。**肝门三联**（门静脉、肝固有动脉、胆总管）在小网膜游离缘内走行（前方），**下腔静脉在其后**——**Pringle手法**（阻断肝十二指肠韧带）即在控制肝动脉与门静脉入肝血流的两结构之间。**门静脉**在胰颈后方由**肠系膜上静脉与脾静脉**合成，下行至肝门；因其**无瓣膜**且其压力等于右房加压差，门静脉高压在**门体静脉吻合处**宣告自身存在：食管与胃底静脉曲张（**胃左静脉→奇静脉**）、**海蛇头**（附脐静脉→腹壁上下动脉）、直肠（直肠上→直肠中/下）、腹膜后（Retzius静脉、结肠），以及肝裸区（膈）。**镰状韧带**（含**肝圆韧带**，即闭锁的脐静脉）与冠状韧带、三角韧带固定肝并界定膈下与肝下间隙。
:::

::: example 血沿着门铃的线路流 {#ex-varices}
一名52岁酒精性肝硬化患者大呕血；内镜下见食管静脉曲张。
::: solution
出血途径是一个吻合：**门静脉（胃左/冠状静脉）→食管黏膜下静脉→奇静脉→上腔静脉**，正常时以低压开放，窦阻力增高时怒张成黏膜下柱——曲张静脉在**食管胃结合部与食管下段**出血，位置在黏膜下（故套扎有效、硬化剂能形成瘢痕），其上覆以菲薄的黏膜——食物或呕吐的创伤造成那经典的临终性大出血。同样的门脉高压重新开放**附脐静脉（海蛇头——以脐为中心放射状，与腔静脉阻塞时垂直走的腹壁浅静脉不同：血流方向可资鉴别）**，并使直肠静脉丛扩张（痔常见但非门脉所特有）。复苏按解剖的缩影展开：即刻要务是气道与粗孔留置针（曲张静脉出血是静脉压性出血——**Sengstaken-Blakemore三腔二囊管**压迫：胃囊在胃底、食管囊沿食管下段，是门-奇静脉地图的物理学应用），然后是缩血管治疗（特利加压素减少门静脉入流），然后套扎，再然后——难治者——**TIPS**（经颈静脉肝内门体分流：经肝实质自**肝右静脉至门静脉右支**的人工通道，影像科医生的Couinaud肝段与肝静脉解剖，以分流氨绕过肝、用肝性脑病换出血）。长期靠移植评估，而其急性期病死率正是为什么病史里写的是那个吻合口而非肝硬化。
:::
:::

**胆囊**躺在脏面的胆囊窝内，胆囊底在第9肋软骨尖（胆囊炎时可触及的一点，Murphy征的手指之处），胆囊漏斗（Hartmann袋——颈部的外突，在结石嵌顿时压迫肝总管），胆囊体，以及延续为胆囊管的胆囊颈；**胆囊动脉**在**Calot三角**（胆囊管、肝总管、肝——外科医生的关键视野，见[[anatomy/anatomical-language]]）内起自肝右动脉。**胆管**——左右肝管→肝总管，＋胆囊管→胆总管——下行于**十二指肠第一部后方、胰头内或后方**，在**肝胰壶腹（Oddi壶腹）**处与胰管汇合，开口于D2后内侧的大十二指肠乳头：这就是胰头癌或嵌石同时梗阻两股水流的原因——**无痛性梗阻性黄疸伴可触及无痛的胆囊（Courvoisier定律）**是胆囊管汇入处以下胆总管的梗阻、发生在一个从未纤维化的胆囊；也是“胆总管结石＋胰腺炎”这一组合之所以存在的原因。

**脾**居左季肋部，贴第9–11肋，长轴沿第10肋，**脏面的脾门**邻胃、左肾、胰尾与结肠左曲。**脾动脉**沿胰上缘迂曲走行（腹膜外位），胃短与左胃网膜血管是胃脾韧带与脾肾韧带的内容物——外科医生切断这两条韧带以游离脾，脾肾韧带内的胰尾即险。脾组织植入、副脾（10–20%，脾门与韧带沿行）与**脾切除后凶险感染**风险（有荚膜菌——肺炎链球菌、脑膜炎球菌、流感嗜血杆菌——故急诊脾切除时或术后两周内接种疫苗，以及终身“发热即急诊”卡片）——这就是脾的全部临床解剖。

## 中肠、后肠与血管边界

**中肠**——自胆管汇入处以远的十二指肠至横结肠近端2/3——悬挂于**肠系膜上动脉**（12–15条空、回肠支，回结肠、右结肠、中结肠动脉），淋巴沿系膜根放射至腹腔干邻位的淋巴结（为何中肠癌手术是高位的血管结扎）。**空肠**居左上，壁厚、血管丰富，直小血管长而血管弓少；**回肠**居盆腔与右髂窝，壁薄，集合淋巴滤泡聚集，直小血管短而血管弓多——差别之于吻合的外科医生与小肠造影的放射科医生都很要紧。**阑尾**可靠地沿盲肠的**三条结肠带**汇聚于根部找到；**尖端**游荡（盲肠后约65%，盆位约30%），症状随之而变——盲肠后位阑尾炎缺乏前腹壁压痛而**腰大肌征**阳性；盆腔位者有耻骨上或尿路症状（输尿管与膀胱受刺激）而腹软，诊断偏晚，尤其儿童、老人、孕妇（盲肠被顶上——[[anatomy/embryology]]）与用激素者。

::: definition 结肠的血管边界 {#def-colon-vessels}
**后肠**（横结肠远端至肛管上段）由**肠系膜下动脉**供血——左结肠、乙状支、直肠上动脉。**Drummond边缘动脉**（与迂回的**Riolan弓**）连接肠系膜上、下动脉的流域；在中结肠与左结肠动脉流域之间的**脾曲（Griffiths点）**，以及在乙状结肠最下一支与直肠上动脉之间的**直肠乙状结肠交界（Sudeck点）**，血管弓稀疏——这些就是**“分水岭”区**，低灌注状态在那里造成**缺血性结肠炎**（节段性，平片“拇指影”，血管病患者左侧腹痛伴血便），也是血管外科的主动脉阻断钳威胁降结肠/乙状结肠之处（为何开放修复时要再植或保留肠系膜下动脉）。
:::

::: example 分水岭梗死 {#ex-ischaemic-colitis}
一名透析的78岁患者透析中低血压发作；12小时后出现左侧腹痛伴排便带血。CT示降结肠至脾曲增厚；乙状结肠镜见节段性发绀黏膜而直肠豁免。
::: solution
这是**Griffiths分水岭区的非闭塞性缺血性结肠炎**：低流量，而非血栓，在肠系膜上、下动脉流域的边界带——故**节段分布止于脾曲、直肠豁免**（直肠由直肠上、中、下三重供血而受保护，这正是把缺血性结肠炎与溃疡性结肠炎分开的解剖学陈述——后者直肠炎从肛缘开始连续上行）。处理遵循解剖的两个裁决：多数无坏死者经肠道休息、抗生素与纠正灌注而愈；不愈者（腹膜炎、持续出血、狭窄形成）随访造影见**拇指影或单发狭窄**需切除——即急性事件所预告的左半结肠切除。本例暗含的诊断答案：“数小时结肠低流量的患者，阵发性左侧腹痛＋血便”首先考虑缺血性结肠炎，感染性与炎性鉴别其次。
:::
:::

## 腹膜后隙、肾与输尿管

::: definition 肾、输尿管及其险境 {#def-urinary}
**肾**位于腰大肌与腰方肌上，自T12至L3，左肾较高；肾门朝向前内（故后方入路遇到的是肾后面，而下极穿刺活检避开节段血管的无血管线Brödel线）。邻接：右——肝、十二指肠D2、结肠肝曲；左——胃、脾、胰尾、空肠袢、结肠脾曲；双侧——内上方为肾上腺，上方为膈与胸膜（故肋缘下切口的胸膜危险，以及酷似肾痛的下叶肺炎）。**输尿管**沿腰大肌前面下行，在**髂总动脉分叉**处跨过骨盆缘，女性在子宫阔韧带基底部经**子宫动脉下方**（“桥下流水”——子宫切除术中结扎之处），然后斜穿膀胱壁（其抗反流机制在儿童失效即致膀胱输尿管反流与瘢痕）。三处生理性狭窄——**肾盂输尿管连接处、骨盆缘（血管跨过处）、膀胱输尿管连接处**——即三处结石滞留点，各处按其皮节给出疼痛：上段输尿管绞痛为睾丸/阴唇区（L1–2，与生殖股共享），下段为尿频尿急（S2–4，与膀胱共享）。
:::

::: example 三颗结石，三种表现 {#ex-stones}
三位患者：(a)30岁，突发腰至腹股沟绞痛，辗转不安，镜下血尿；(b)60岁，同样的疼痛但伴发热寒战；(c)45岁，偶然发现骨盆缘12 mm结石，无症状。
::: solution
(a)**梗阻性输尿管结石**——疼痛的迁移就是结石沿输尿管的迁移，其牵涉随之下变（L1→S2-4皮节）；肾绞痛**只有名字是“绞”**——输尿管对梗阻蠕动产生近乎持续的痛伴不安的波峰；患者辗转反侧（对比安静不动的腹膜炎患者）。CT平扫泌尿系成像（CT KUB）现为诊断金标准（无论透不透X线——尿酸结石平片透光，而所有结石CT皆显影）。(b)**梗阻合并感染尿液是泌尿外科急症**：梗阻的感染肾单靠抗生素不能引流——**数小时内减压**（逆行输尿管支架或经皮肾造瘘），之后再行确定性取石——这是腔隙内积脓的解剖学转化为唯一两个能救肾的操作。(c)**一颗在狭窄处嵌顿数月的12 mm结石是沉默的肾杀手**（无症状梗阻在数周至数月内毁掉肾功能），其大小（>5–6 mm难以自排）与嵌顿使干预（输尿管镜、支架）成为正确答案——“偶然”发现的肾积水从不偶然，就是这个原因。左睾丸静脉以直角注入左肾静脉——对比右侧直接入下腔静脉——也归入本例：这就是**左侧精索静脉曲张**常见的原因，也是老年患者新发左侧精索静脉曲张要问肾静脉内肾细胞癌癌栓的原因（变异见[[anatomy/anatomical-language]]）。
:::
:::

## 大血管与间隙

**腹主动脉**在T12经内弓状韧带后方进入，发出腹腔干（T12）、肠系膜上动脉（L1，主动脉肠系膜角——上文的D3压迫）、肾动脉（L1/2，左支较长，经肾静脉后方；右支在下腔静脉前方）、生殖腺动脉（L2），并在**L4**分为左右髂总动脉，恰在左髂总静脉跨越处旁（主动脉分叉对左髂静脉的压迫——盆腔外科医生的May-Thurner解剖）。**肾下**是动脉瘤修复之处，因为可在肾动脉下方阻断主动脉；动脉瘤经典的临床解剖是**疼痛三足架**（背、腰、腿）与**破入腹膜后隙**的暂时局限（一位晕厥、可触及搏动性肿物而“恢复”的患者——局限破裂的清明间歇），对比自由破入腹膜腔者不能恢复。**下腔静脉**在**L5**由髂总静脉合成，在主动脉右侧上行，接受肾静脉与肝右（中）静脉，在**T8**穿膈；**左肾静脉**在肠系膜上动脉与主动脉之间跨过主动脉前方——被压迫即胡桃夹综合征，造成左侧精索静脉曲张与血尿，是与著名表亲肠系膜上动脉综合征同一几何的练习。

::: history
腹部解剖学由三个职业建成。大战的外科医生以他们的脓肿地图教会了人们腹膜的隐窝与沟；钡剂时代的放射科医生在活人身上固定了十二指肠空肠曲与盲肠的变异；1960–80年代的移植与肝胆外科医生——Lortat-Jacob的肝血管解剖、法国学派的肝段切除、Starzl的门奇静脉断流——把尸体的动脉变成了活体的外科平面。腹股沟区的故事自成一部专科史：1887–1953年的Bassini、McVay与Shouldice修补逐步认清腹前壁真实拥有的层次；Usher与Lichtenstein的补片时代（1958；1986）与腹腔镜腹膜前修补（1990年代）汇聚于Fruchaud的单一肌耻骨孔——一门两千年历史的手术，因为一位解剖学家画出了正确的地图而进步，是罕见的例证。
:::

## 通向何处

腹膜液与脓肿路径续于[[anatomy/pelvis-perineum]]；肠道的外科在[[surgery/acute-abdomen]]与[[gastrointestinal/bowel-disease]]；肝的生理在[[gastrointestinal/liver-function]]与[[gastrointestinal/liver-disease]]；肾的在[[renal/filtration]]与[[renal/urinary-tract]]；疝的处理在[[surgery/gastrointestinal-surgery]]。

::: summary
- 腹膜是一组以具名路线（Winslow孔、结肠旁沟）相连的间隙——而路线就是脓肿地图、腹膜炎地图与内疝地图。
- 腹壁的弓状线与腹股沟的肌耻骨孔是两个薄弱点；疝与腹壁下血管的关系为其命名，而股环的坚硬使其危险。
- 经幽门面组织上腹；十二指肠后壁溃疡出血（胃十二指肠动脉），前壁穿孔（游离气体），胃小弯的动脉是胃左动脉。
- 门静脉高压是一堂以静脉曲张为教材的解剖课：食管下段、脐、直肠、腹膜后——其治疗（套扎、气囊、特利加压素、TIPS、移植）是以其他手段执行的门体静脉地图。
- 结肠的分水岭点（Griffiths、Sudeck）是低流量致缺血之处；阑尾的结肠带汇聚是混乱终结之处；输尿管的三处狭窄是结石停驻之处，其三种牵涉模式为之定位。
- 主动脉T12–L4及其五条具名分支的平面，下腔静脉L5–T8；左肾静脉的跨主动脉走行解释了胡桃夹与左侧精索静脉曲张；腹膜后局限破裂解释了动脉瘤的清明间歇。
:::

::: exercise 两次内脏到躯体 {level=1}
用神经语言描述a)十二指肠溃疡穿孔与b)急性阑尾炎的疼痛顺序与偏侧化。
::: solution
(a)十二指肠周围/上腹**内脏性**疼痛（T7–10，经腹腔干与肠系膜上神经丛，中线），数小时内当胃内容物沿**右结肠旁沟**流下、刺激壁腹膜与右髂区时转为**右侧或泛化的躯体性**疼痛——阑尾炎的模仿者（反之亦然：阑尾炎的高位盲肠后炎症沿同一沟模仿胆囊炎）。酸引起的化学性腹膜炎最初以**上腹与右侧**最重，随后泛化。(b)如[[anatomy/anatomical-language]]所述：T10脐周内脏性→右髂窝躯体性——但此处要加上变异：盲肠后位（腰痛、腰大肌征、前腹壁腹膜刺激征少）、盆腔位（耻骨上、尿路症状、定位差），以及网膜与免疫反应使其泛化或不能局限的婴幼儿与老人。沟与神经，讲了两次。
:::

::: exercise 鞘与出血 {level=1}
一名抗凝的哮喘患者剧烈咳嗽后出现脐旁疼痛性包块，不越过中线，当她绷紧腹壁时压痛更甚（Carnett征阳性）。发生了什么？为什么它不在腹腔内？
::: solution
**腹直肌鞘血肿**，鞘内**腹壁下动脉或其分支或外侧穿支**破裂所致——弓状线以下腹直肌后面只有腹横筋膜，故出血可沿之下潜、量大而不破腹膜。解剖给出的临床规则：包块与压痛**在壁内**（Carnett征阳性：绷紧肌肉时压痛增加或不变；腹腔内疼痛则减轻），而鞘的中线融合（白线）使其**不越过中线**。处理：纠正抗凝、影像（CT显示平面与有无活动性造影剂外溢；持续出血者血管栓塞），并认识到低位鞘内出血在填塞前可以巨大，因为弓状线以下没有任何东西限制它。鉴别：半月线的嵌闭疝（Spigelian疝），同样在壁内但边界不同——在需要开腹之前，两者都不需要开腹。
:::
:::

::: exercise 沿着精索走 {level=1}
说出精索的结构、各层被膜来自腹壁的哪一层，并解释提睾反射的径路及其临床用途。
::: solution
精索内容：**输精管**、**睾丸动脉**（起自腹主动脉）、**输精管动脉与提睾动脉**（起自腹壁下/髂内系统）、**蔓状静脉丛**（左侧入肾静脉，右侧入下腔静脉）、淋巴、生殖股神经生殖支与交感纤维。被膜来自腹壁层次：**精索外筋膜**（腹外斜肌腱膜）、**提睾肌及其纤维**（腹内斜肌——故提睾反射：划大腿上内侧L1–2，提睾肌收缩上提睾丸；**睾丸扭转**时消失——不可靠但经典——在急性痛性阴囊的鉴别中有用）、**精索内筋膜**（腹横筋膜在深环处随精索外突——这就是先天性斜疝位于精索被膜之内、而直疝自后壁内侧突出、不在一个预成环筋膜内的原因）。腹膜鞘突——其近端未闭即斜疝，远端未闭即鞘膜积液——补全清单。睾丸动脉的长度与静脉直角汇入左侧肾静脉，解释了扭转为何是血管急症与精索静脉曲张的不对称。
:::

::: exercise 哪个吻合在出血？ {level=2}
对于每一例：说出门体静脉吻合及门静脉血流方向：(a)曲张静脉呕血；(b)海蛇头；(c)门脉高压性直肠出血；(d)肾切除术中有意义的腹膜后途径。
::: solution
(a)**胃左（冠状）静脉（门静脉系）↔食管静脉→奇静脉（体循环/腔静脉系）**：血流**离肝**，经胃短/冠状路径上行入低压的奇静脉。(b)**附脐静脉（门静脉系，走行于肝圆韧带内）↔腹壁浅静脉（体循环）**：经典鉴别是血流方向——门脉高压时以脐为中心向四周放射、脐上血流朝向头侧；腔静脉阻塞时脐下垂直血流仍**向上**、以胸腹壁外侧静脉为主。(c)**直肠上静脉（门静脉系，经肠系膜下）↔直肠中、下静脉（体循环，髂内/阴部内）**：肛直肠丛怒张。(d)**肾与腰/腹水的腹膜后静脉（门静脉系的包膜与十二指肠支↔肾、腰、膈静脉）**——腹膜后炎症形成的粘连或“腹膜后静脉曲张”野，在肾切除与肝手术分离时出血。血流方向这一点回答了治疗问题：**TIPS有效是因为它降低门静脉压力、把血流转向肝的流出道**而非背离——且经颈静脉入路无需开放解剖。
:::

::: exercise 定位梗阻 {level=2}
一名既往三次开腹的70岁患者阵发性脐周痛、呕吐、完全停止排气排便；腹膨隆、鼓音、肠鸣音高调；X线示中腹部小肠袢扩张、环状襞横跨全腔且不见结肠。请用解剖学回答：梗阻平面，结合病史最可能的两个原因，以及“绞窄性”梗阻从全身宣告自身的解剖学理由。
::: solution
**小肠梗阻**：环状襞（plica circulares）横跨整个肠腔，以此区别于结肠的结肠带；中腹部分布而无结肠积气定位于小肠；呕吐出现越早、越显著，梗阻越高（高位——胆汁性、早；低位——粪样、晚）。本例原因依次：**粘连束带**（既往开腹——网膜与创面腹膜的纤维桥，最常见于既往切口附近与回肠）与**内疝或束带压迫**（或所施手术疾病的复发；消瘦老人的股疝或闭孔疝是漏诊项）。绞窄宣告自身，是因为**被嵌闭袢的系膜静脉先在颈部受压**（壁薄、低压），袢充血、膨胀、成为**闭袢**（两端均不能减压），继而动脉入流失效、肠壁梗死——细菌移位与内毒素吸收造成发热、心动过速、酸中毒、持续性（非阵发性）疼痛与腹膜刺激征：解剖学序列“先静脉后动脉，先闭袢后单纯”，这就是发热、压痛、持续痛的小肠梗阻需要手术而非输液的原因。
:::

::: exercise 搏动性肿物 {level=2}
一名80岁吸烟者突发剧烈背痛与腰痛，到院前曾虚脱、大汗，其间一度有短暂反应。事件是什么？“短暂反应”的解剖学是什么？为什么“压痛性搏动性肿物”既是查体所见又是手术指征？
::: solution
**腹主动脉瘤渗漏或破裂**，多位于肾下。清明间歇的解剖：**腹膜后局限破裂**，血肿与体壁的填塞暂时稳住破口——“反应”是血栓撑住的血压；再次虚脱是血栓第一次滑脱。查体的价值：可触及的**肾下主动脉**正常在脐上、偏左于中线，以**宽度**而非搏动计约2 cm（消瘦者）——虚脱患者该轮廓上出现**压痛、膨胀性**肿物，不是等待来确认的所见：它是立即请血管外科到场、且只在患者稳定到能活过CT室三十分钟时才做复苏性CT的指征。手术解剖（肾下阻断、左肾静脉、跨过主动脉第四部的十二指肠、L5处髂总静脉的汇合、外侧的输尿管）解释了为什么修复是主动脉阻断加人工血管——也解释了同一套解剖为什么带来肾衰、缺血性结肠（肠系膜下动脉）与阻断钳解除冲洗后的酸中毒性心搏骤停的风险。
:::

::: exercise 描绘脓肿 {level=2}
胃溃疡左侧穿孔后的膈下脓肿：从腹膜路径解释其定位，为什么患者有呃逆、左肩痛与基底积液，以及为什么引流路径是经肋或经前腹壁，其依据是膈的淋巴做什么。
::: solution
定位：胃后下面穿孔的自由液体经**左膈下（脾周）间隙**流动——上为膈，下为脾与胃，下界为膈结肠韧带所限——呼吸时胸腔内负压把感染的液体向上泵入**膈下间隙**，其裸区相关的淋巴吸收液体与细菌（老外科医生的“膈会吸”——腹膜液经膈的孔口出口至纵隔淋巴，这就是膈下积液引起纵隔与胸膜炎症、膈旁引流必须是闭式系统的原因）。牵涉表现源于**左膈神经**（C3–5）：膈受刺激的呃逆，肩尖痛（锁骨上神经C3–4），以及**左侧基底反应性积液与呼吸受限**伴酷似胸部原发疾病的基底体征——经典的“以胸部感染示人的腹部脓毒症”，也是提醒：膈是一个带胸段神经的腹腔器官。引流在影像引导下沿避开胸膜的路径（后部反折至第8肋，外侧第10，前部第6），除非积液高在后方，膈下间隙的引流首选肋缘前下经路而不穿胸腔。

::: exercise 设计手术的平面 {level=3}
用一页纸教授右半结肠切除术。给出手术的解剖：血管结扎点、游离平面、吻合的血供与张力测试，以及处于危险中的两处输尿管交叉区。
::: solution
**血管结扎**：回结肠动、静脉于其起自肠系膜上动脉处结扎（带淋巴结的脂肪随标本切除——肿瘤学标本就是系膜的淋巴扇，所以结扎要高、近胰颈，这就是本手术对**中结肠血管蒂**的危险，在右侧还有系膜根后方的**第三部十二指肠与胰头**）；右结肠动脉（常缺如或共干）与中结肠动脉右支；**回结肠血管蒂与十二指肠的关系**是为什么分离自内侧向外侧进行、先辨认十二指肠。**游离**：沿Toldt白线切开后，在血管少的**Toldt平面**（胚胎融合筋膜）内侧翻转结肠，游离肝曲（肝结肠韧带——前上方小心胆囊与十二指肠），把**右侧生殖腺血管与输尿管向后方扫开**。

**吻合**：回肠横结肠或回肠结肠；游离回肠系膜做到无张力；以钳测试边缘弓——**蠕动、切缘出血、可触及的搏动、无张力**——两端分别是小肠（壁厚、单一血管弓）与横结肠（结肠带、脂肪垂）。**输尿管危险区**：其跨髂总动脉分叉的骨盆缘处（被生殖腺血管撑起、呈“叉中”所见），与高位结扎时向十二指肠/胰头侧的偏内（右输尿管全程在升结肠游离平面的后方——它是带教老师指给你看、而住院医结扎的那个结构）。整页纸就是本章论点的同义转述：手术在发育留下的间隙里进行，而损伤发生在术者忘记了那个间隙里本该有什么神经、血管或导管的地方。
