胚胎学是时间维度上的解剖学。本课程描述的每一个结构——由一根管道来的四个腔、绕着自己的血管旋转的肠管、横穿腹部抵达阴囊的睾丸——都是一个大致运行八周过程的停滞或完成阶段，而这个过程出错的方式各有各的专名与再发风险。约每33名儿童中有1名出生时患有临床意义的先天异常；又有一分成人的疾病（剖宫产时偶然发现的双角子宫、影像上发现的重复集合系统、中年发现的心脏分隔缺陷）其实是迟到的胚胎学发现。产科医生、小儿外科医生、遗传学家与畸形学家说的都是同一门语言：“器官发生”、“神经嵴”、“第六周”。

本课按临床顺序走一遍这个过程：胚层、折叠与管闭合、咽器、最常以错误示人的器官、分娩时的胎儿-胎盘循环，以及决定“什么在什么时候伤害胚胎”的规则。

## 从受精卵到植入：头两周

::: definition 从受精到植入 {#def-fertilisation}
**受精**——配子的融合——通常发生在**输卵管壶腹部**。合子在3–4天进入子宫的途中卵裂（桑葚胚，16个细胞），液体进入形成**胚泡**：外层的**滋养层**（未来的胎盘）与内细胞团的**胚胎内胚**（未来的胚胎）及一个原始腔。胚泡于**第6–7天**着床于子宫底或体，滋养层分化为细胞滋养层与合体滋养层，后者侵蚀子宫内膜毛细血管并分泌**hCG**，拯救黄体及其孕酮输出——这是所有妊娠试验的生化基础，也是黄体功能维持至约第8–10周胎盘接管的基础。到第14天，双胚盘（上胚层、下胚层）就位，胚胎期——而非胎儿期——正式开始。
:::

::: example 双胎，以及为什么它是一个产科急症问题 {#ex-twins}
一名孕妇12周超声报告“双绒毛膜双羊膜囊双胎”。26周另一名患者的不同超声报告“单绒毛膜双羊膜囊双胎”，团队随即开始每两周一次的监测。
::: solution
绒毛膜数——几个胎盘——由**分裂的时机**决定，而它决定此后的一切。受精后72小时内（滋养层形成之前）的分裂产生**双绒毛膜双羊膜囊**双胎：各自胎盘（或融合但各自独立），各有各的羊膜囊；这也是多胎减胎问题以及“共胎盘而实不共”情形所属的模式。第4–8天的分裂，在滋养层形成之后、羊膜形成之前，产生**单绒毛膜双羊膜囊**双胎——一个共享胎盘，95%以上病例内有血管吻合——这正是**双胎输血综合征**（动静脉分流失衡：供血儿血容量不足、少尿伴羊水过少；受血儿容量超负荷伴羊水过多）与选择性生长受限赖以发生的土壤，而每两周的监测正是为了捕捉它们。第8天以后的分裂产生单羊膜囊双胎（罕见，脐带缠绕危险），第13天以后的分裂则不完全——联体双胎。两点实际推论：**绒毛膜数必须在14周前确定**（此后超声无法可靠区分融合胎盘，而凭厚lambda峰读出的“双绒毛膜”标签即是整个妊娠的监测方案）；而在法学的意义上**单卵不等于同一**——单绒毛膜双胎共享DNA却在表观遗传上不同、可以表型不同，当“同卵”双胎在某个畸形上不一致时，这是咨询中重要的一点。
:::
:::

## 原肠胚形成与三胚层宪法

::: definition 原肠胚形成 {#def-gastrulation}
**第3周**初，上胚层细胞经双胚层盘表面的**原条**迁移，排挤并取代下胚层，形成**三个初级胚层**：**外胚层**（表面与神经系统）、**中胚层**（肌、骨、结缔组织、血与内皮、肾与生殖腺基质）与**内胚层**（消化管上皮及其腺性突——呼吸、肝、胰、甲状腺）。原条头端增厚为**脊索突**，其尖端——**口咽板（prechordal plate）**——标记未来的口，其旁神经板被诱导形成神经系统：**诱导**，一个组织的信号决定另一个组织的命运，本领域的中心概念（Spemann与Mangold1924年的经典移植实验所证明）。
:::

::: theorem 胚层命运解释成人病变 {#thm-germlayers}
病变的组织构成与位置会出卖它的起源胚层：畸胎瘤含三个胚层的衍生物（它源于全能细胞）；Meckel憩室含异位胃黏膜，因为它是卵黄管的遗迹，而卵黄管是一根内胚层管；鳃裂囊肿衬于颈部，因为咽器是内胚层与外胚层相遇之处；癌发于上皮（内胚层或外胚层）而肉瘤发于中胚层。当病理学看似无视解剖学时，问一问这份组织在第四周在做什么。
:::

::: proof
这条规则可以当作诊断发生器来用。一个随吞咽与伸舌移动的颈部中线肿物是**甲状舌管囊肿**，因为甲状腺自舌盲孔经甲状舌管降至颈下部、拖着它的附着；同一条胚胎学陈述解释了为什么手术（Sistrunk术）要切除舌骨中段——导管与它同行。一个含毛发、牙齿与上皮的青年前纵隔肿物是**畸胎瘤**，因为全能细胞（来自原条区域或迁移的生殖细胞）能把三个胚层组织成恰好那样的混乱。一个胸锁乳突肌前缘、在成人上呼吸道感染后发现的囊肿是**鳃裂囊肿**——第二咽沟被掩埋的口袋，其正常命运是被第二弓覆盖并消失；它在成年期显现恰成教科书，因为它的胚胎学是一场倒计时的消失。而**畸胎瘤组织的分布**遵循原始生殖细胞的迁移路线（中线结构：骶尾、纵隔、松果体），这一观察把一个奇谈变成了一张细胞迁移地图。推断没有一个需要教科书的插图；每一条都由三胚层宪法加上本课其余部分列出的迁移路线推出。
:::

## 神经胚形成、胚体折叠与管缺陷

::: definition 神经胚形成与胚体折叠 {#def-neurulation}
在脊索的诱导下，背侧外胚层增厚为**神经板**，其沟升起、靠拢、拉链般闭合——起自未来的颈段、向两端推进——到**第4周**末形成**神经管**；从折叠边缘掐断的嵴细胞形成**神经嵴**，其衍生物（周围神经节与Schwann细胞、黑色素细胞、颅面间充质包括成牙本质细胞与大部分面颅、**心输出道分隔**、主肺动脉隔与经咽器而来的甲状旁腺与C细胞、肾上腺髓质、肠神经丛）是医学里最短却仍须背诵的清单。与此同时，扁平的胚盘在两个平面上折叠——头尾方向把口咽膜带到头端、把泄殖腔带到尾端；左右方向把内胚层包入的卵黄囊卷成**管状肠**，由闭合的腹壁围住。
:::

头端失败产生**无脑畸形**（不能存活；母血与羊水AFP升高，超声颅盖缺失）；尾端失败产生闭合型（隐性脊柱裂——毛发小凹，常见、良性）与开放型的**脊柱裂**（**脑膜膨出、脊髓脊膜膨出**——脊髓脊膜膨出的病变决定随后瘫痪的平面与膀胱/肠道模式：腰段病变保留髋屈曲，骶段病变下肢可动而膀胱去神经）。**受孕前后叶酸（400 µg/日，孕前开始至第4周）**的保护作用——试验证据中再发风险降低约三分之二，食品强化后人群数据中初发风险显著降低——使其成为最可预防的结构缺陷类别，也是胚胎学事实（第28天闭合）跑在多数孕妇意识到自己怀孕之前的那一个。

::: example 中线上的缺陷与它的算术 {#ex-ntd}
一位既往妊娠患过脊髓脊膜膨出的女性，在本次妊娠5周时询问该怎么办、风险多大。
::: solution
两个数字一个期限。经验上**一次患儿妊娠后的再发风险为3–5%**（人群风险约0.1%；某些人群与更多患病亲属中更高——引用遗传咨询的数字，而非背景数字）。干预是**叶酸5 mg每日**，尽可能孕前开始——她已5周，故今日开始、服满孕早期，同时要明白神经管在受孕后第25–28天闭合，约当月经刚错过之时：药物瞄准的窗口恰是患者几乎总错过的那一个，这正是该建议应属于每一次孕前谈话、而不只属于这一次的原因。监测：**16–18周AFP**（开放缺陷把甲胎蛋白漏入母血与羊水）加**系统超声**，现代影像可检出多数开放型与不少闭合型缺陷。更深的咨询要点：多数神经管缺陷是多因素而非单基因——再发风险数字而非孟德尔比例才是诚实的货币；而关于强化面粉的人群数据也应在回答里，因为它能让她看到自己正在管理的风险一部分是环境性的。
:::
:::

::: warning 日期问题
产科的孕周从**末次月经**（LMP：孕周“4周”的胚胎其实是受精后2周）算起；胚胎学事件则从**受精**算起。孕“6周”时的致畸原暴露，在你不知道用的是哪个钟之前毫无意义——在LMP算法下6周服用的药，在发育上是4周，正值原肠形成与神经胚形成，同样剂量同样的分子能造成它在8周时再也造不出的损害。咨询之前先换算时钟：LMP减两周就是胚胎学时间。
:::

## 咽器：头部的分节

::: definition 咽弓 {#def-pharyngeal}
第4周出现五个弓（第1、2、3、4、6弓——第2弓暂时过度生长覆盖第3、4弓，把它们埋入**颈窦**）；每个弓各有其**动脉**、**软骨/骨组**、**神经**与肌组。各弓及其神经：

| 弓 | 神经 | 骨骼/肌肉衍生物 | 动脉 |
|---|---|---|---|
| 1（下颌弓） | 三叉神经（V3） | Meckel软骨→锤骨、砧骨、下颌骨、上颌骨；咀嚼肌、下颌舌骨肌、二腹肌前腹、鼓膜张肌 | 上颌动脉区 |
| 2（舌弓） | 面神经（VII） | 镫骨、茎突、舌骨小角；表情肌、镫骨肌 | 镫骨动脉 |
| 3 | 舌咽神经（IX） | 舌骨大角；茎咽肌 | 颈总/颈内动脉区 |
| 4 | 迷走神经（喉上） | 甲状软骨与大部分环状软骨、咽缩肌 | 主动脉弓（左） |
| 6 | 迷走神经（喉返） | 环状软骨、杓状软骨；除环甲肌外的全部喉内肌 | 肺动脉、动脉导管 |

弓之间的**沟**为外胚层（第一沟形成外耳道），内的**囊**为内胚层：囊1→中耳腔与咽鼓管；囊2→腭扁桃体；囊3→**下甲状旁腺与胸腺**；囊4→**上甲状旁腺**与滤泡旁C细胞。位置看起来更高的第3囊产生下甲状旁腺、最终却位于第4囊来源者之下，这个事实有外科后果：胸腺从颈部降入纵隔并拖着它的甲状旁腺一起走，因此异位的下甲状旁腺可以位于下颌角至纵隔之间的任何地方——甲状旁腺手术之所以是一场胚胎学考试的原因。
:::

::: example 当第四咽囊失败 {#ex-diGeorge}
新生儿科医生见到一名足月儿：低钙惊厥、圆锥动脉干心脏畸形（永存动脉干）、腭裂。
::: solution
三联征指向同一个胚胎学单元——**咽囊3、4与心输出道**，全部由**神经嵴细胞**填充——并指向同一项检查：染色体微阵列或FISH查**22q11.2缺失**（**DiGeorge/腭面-心面部综合征**：胸腺与甲状旁腺发育不全/不发育、圆锥动脉干异常、腭功能不良、学习与精神风险）。推理就是这条定理的实战：低钙是甲状旁腺缺如（囊4），动脉干是输出道分隔失败（心神经嵴），而嵴迁移是把它们捆在一起的一个过程。即刻处理是补钙与维生素D，并且——因为胸腺是第3弓衍生物——在接种任何活疫苗前检查T细胞功能，如需输血使用照射去白细胞的血液；长期处理是该综合征的成人文献（腭修补、心脏随访，以及应写进青少年咨询的精神分裂症风险）。本题的要义在于习惯：**综合征是一片胚胎学野缺陷**，认出这片野（此处：嵴→第3/4囊→输出道）就是把一列所见变成一个诊断的方法。
:::
:::

## 器官及其特征性错误

**心。** 一根管道——第3周管形化的中胚层板，约**第22天**开始搏动——向右袢曲（右袢；当纤毛侧化失败时失败即**反位心伴内脏反位**，Kartagener谱系），并在第5–7周分隔：房室垫、**第一房间隔与第二房间隔**及让右房血液绕过充满液体之肺的**卵圆孔**，以及**主肺动脉隔**——螺旋的，这就是为什么主动脉最终落在肺动脉干的后右侧，也是为什么对位不良产生法洛/共干型解剖。临床上最重要的常见缺陷类别：**室间隔缺损**（总体最常见，小者可自闭）、**继发孔型房间隔缺损**（固定分裂的S2）、**动脉导管未闭**（本该在出生时收缩的那根血管）、**法洛四联症**（漏斗部隔前上移位：室缺、主动脉骑跨、肺动脉狭窄、右室肥厚——运动后蹲踞的“紫绀”生理）。

**肠。** 中肠在第6周疝入脐带，绕肠系膜上动脉逆时针旋转270°，退回后把盲肠固定在右髂窝低位；任何一期失败都产生畸形：**脐膨出**（中线、有膜覆盖）、**腹裂**（右侧、无膜、肠管泡在羊水中）、**不旋转伴中肠扭转**（新生儿胆汁性呕吐的外科急症——Ladd术）、**盲肠位置异常**。卵黄（卵黄-脐）管遗迹产生符合**“2的法则”**的Meckel憩室：人群2%，距回盲瓣2英尺，长2英寸，2种常见异位组织（胃、胰腺），2岁前发病、并发症男性2倍——来自异位胃黏膜对侧正常回肠被酸溃疡的无痛性便血，由锝-99m高锝酸盐扫描诊断——它使胃黏膜在任何地方都显影。后肠的异常产生**先天性巨结肠**——远端结肠**肠神经节**缺如（又是神经嵴），因为嵴细胞头到尾迁移而直肠最后到达：一种没有抑制的张力，近端扩张（“Hirschsprung”就是从松弛不下来的直肠乙状段），直肠活检确诊，拖出术治疗。

**泌尿生殖系统。** 三个肾依次出现（前肾、中肾、后肾）；后肾发生体从盆腔升至腰部并旋转，失败产生**盆腔肾或马蹄肾**（峡部卡在肠系膜下动脉起始处——对一切主动脉手术都是事实）与**重复集合系统**，上极引流偏内下（Weigert-Meyer定律：上极梗阻、下极反流）。**间介中胚层**建造两种性别的管道——副中肾（Müller）管形成子宫、输卵管与阴道上段；中肾（Wolff）管形成男性的附睾与输精管——而在无Y染色体与Sry时性腺默认发育为女性，这才是那句陈话的真正含义。睾丸的下降拖着它的血管、它的腹膜鞘（**睾丸鞘突**，其不闭合即未闭鞘突→斜疝或鞘膜积液）与它的神经的走行假象一起走；失败即**隐睾**，附带其癌症与生育的赌注；以及可触及但从未入管的异位睾丸。

::: example 两岁儿童的无痛性出血 {#ex-meckel}
一名2岁男孩三次无痛的酱红色大便；血红蛋白78 g/L；腹部查体与凝血筛查正常；结肠镜无收获；小儿外科医生考虑锝扫描。
::: solution
“2的法则”一句话做出诊断：两岁以下儿童无痛的大量便血、上下内镜均阴性，除非高锝酸盐扫描（在异位**胃黏膜**浓聚）否则即为**出血性Meckel憩室**，儿童敏感性约85%。注意出血的解剖同样是胚胎学的：憩室内胃黏膜分泌的酸溃疡**相邻的正常回肠黏膜**，所以“病灶”在憩室对侧的肠壁上而不在憩室内——手术是连同溃疡区的段切除，而非简单的憩室切除。这项检查之所以成立，是因为它显影的是胚胎组织而非解剖：本章世界的提醒——诊断常常就是对一个发育错误的直接显影。
:::
:::

::: example 出生第二天的胆汁性呕吐 {#ex-volvulus}
一名既往健康的出生两天新生儿，吃奶后突然呕吐绿色液体；腹部变胀、压痛；婴儿苍白、心动过速。
::: solution
**新生儿的胆汁性呕吐，除非上消化道造影证明否则即为肠旋转不良伴中肠扭转**，其胚胎学就是临床推理。未完成旋转的中肠悬挂在狭小的**肠系膜上动脉**蒂上，异常的**Ladd束**横跨十二指肠；肠管绕蒂扭转，而扭转就是整个中肠的动脉闭塞——苍白、休克、酸中毒的婴儿不是“胃肠炎”，而是缺血性肠。时间以肠的分钟计，不以小时计：必须在缺血窗内急诊开腹复位并行Ladd术，因为从乳头到横结肠中段的全部小肠都系在这一根动脉上。要记住的短语是胚胎学的那句——**中肠扭转是单血管灾难**——因为它解释了为什么“新生儿呕吐物发绿＋便血＋休克”的外科急迫性等同于成人动脉瘤破裂，也解释了为什么上消化道造影（十二指肠空肠曲相对Treitz韧带位置异常）是在患儿稳定时唯一值得做的检查。
:::
:::

## 胎儿循环与出生时的转变

::: definition 胎儿循环的捷径 {#def-fetal-circ}
胎儿不通风其肺，其循环按此布线。含氧的胎盘血经**静脉导管**回流，把最含氧的血流经**卵圆孔**导入左房、进而供应冠脉与脑循环（右向左的房间分流是绕过未负荷之肺的*正常*捷径）；下腔静脉的其余血液与全部上腔静脉血液绕过右室进入肺动脉干，再经**动脉导管**（第6弓衍生物，低氧张力与胎盘/前列腺素E₂使其开放）流入降主动脉，其中大部分经**脐动脉**（两条，在脐带内）回到胎盘。脐**静脉**只有一条。出生时：肺膨胀使肺血管阻力骤降，肺血流增加，左房压超过右房，**卵圆孔功能性关闭**（其解剖闭合约25%不完全——卵圆孔未闭，常见且多无害）；动脉血氧升高与PGE₂下降使**导管**收缩（1–3个月解剖闭合）；脐血管纤维化为**脐内侧韧带**与镰状韧带游离缘内的**肝圆韧带/静脉韧带**——对肝胆与移植外科医生要紧的标志。
:::

::: theorem 有些病变是导管依赖的 {#thm-duct}
在一组危重型先天性心脏病中，度过出生后头几天的生存依赖动脉导管保持开放，否则循环中断或肺血流归零：**导管依赖肺血流**（肺动脉闭锁、重症法洛）、**导管依赖体循环血流**（重症主动脉缩窄、主动脉弓离断、左心发育不良）、以及**需要混合的并联环路**（完全性大动脉转位）。维持生命靠药物——前列腺素E₁（alprostadil）输注，接受其呼吸暂停与发热的代价——而在导管闭合前作出诊断是新生儿脉搏血氧筛查的目的。
:::

::: proof
这套生理是一个带开关的双环路系统的回路分析。取**左心发育不良**：左室无法支撑体循环，体循环输出依赖右室输出跨过导管进入降主动脉，冠脉与脑循环依赖房间水平的混合与弓的逆向灌注——当导管在第2–3天收缩，体循环灌注崩溃，婴儿以休克起病。同样的算术换一组体征就是**大动脉转位**：右室发主动脉、左室发肺动脉构成两个并联环路，若无房间或导管交通根本不成循环，故即刻干预是球囊房间隔造口（Rashkind）以扩大混合病变，数周内行根治（动脉调带）。取**主动脉缩窄**：导管植入处的狭窄意味着宫内下半身经导管灌注；导管闭合后左室后负荷骤升，下肢变苍白而头部保留灌注——差异性发绀与桡-股延迟，也是婴儿型缩窄是急症、成人型缩窄是侧支病（扩张的肋间动脉侵蚀肋骨下缘，“肋切迹”，一条胎儿从不需要、慢性旁路的教科书征象）的原因。这定理是一条推论：*新生儿的导管是病变大多唯一没烧掉的桥*——这就是“先给PGE₁，别等超声”作为急诊指令的原因，也是导管依赖病变成为儿科最有力论据的原因：对药能在手术机会之前买到一段命。
:::

::: quiz
患者在妊娠“第5–6周”（按LMP记）服用一种药物，相当于哪个胚胎学危险期？
- [ ] 仅肢芽与心的早期器官发生
- [x] 原肠形成/神经胚形成窗口——重大结构致畸最敏感的时期，心与神经管结构在此期易损
- [ ] 胎儿生长早期

::: solution
减两周。LMP第5–6周即受精后第3–4周：原肠形成至神经管闭合——其干扰产生神经管缺陷、心分隔错误与早期面、肢野损害，正是经典畸形学的定义期。“着床前全或无”说的是头两周；（发育周）8周以后是胎儿期，致畸原此时更多造成生长受限与功能或轻微结构缺陷，而非重大畸形。知识在于换算，不在清单：致畸原效应读的是胚胎走的钟，不是日历走的钟。

## 致畸原与时间的规则

::: definition 关键期 {#def-teratogen}
**致畸原**在暴露落入某器官的**关键期**时致畸——器官发生期（发育第3–8周）为大体结构缺陷；胎儿期则为生长、功能与中枢神经系统效应。除头两周（足够损害即致死，存活者结构正常：“全或无”法则）外，剂量-反应很少全或无。值得烂熟于心的清单：**感染**（TORCH组：弓形虫、风疹、巨细胞病毒、单纯疱疹；B19微小病毒胎儿水肿；寨卡）；**药物**（沙利度胺——1957–61年的灾难催生了现代畸形学监管，约4–7天窗口内的肢体减少性缺陷；异维A酸——颅面、心、中枢神经，强制妊娠预防计划之因；华法林——鼻发育不良与点状骨骺；丙戊酸等抗癫痫药——神经管与认知；孕晚期的ACE抑制剂与NSAID——胎儿肾；酒精——最常见的可预防智力障碍原因，无确立安全剂量）；**母源疾病**（孕前糖尿病——尾侧回归缺陷与心脏畸形，风险随孕早期血糖走；未经治疗的苯丙酮尿症；系统性红斑狼疮——抗Ro/La新生儿心脏传导阻滞）。
:::

::: history
观念比解剖学年轻。William Harvey的胚胎学论著（1651年）把发育表述为渐成论；von Baer定律（1828年）把胚层与“先一般后特殊”的发育次序带入生物学；Weismann的种质学说（1892年）把遗传系与体细胞分开。临床时代由1961–65年风疹流行开启（Gregg1941年提出母体风疹与白内障、耳聋之关联得到证实），而本学科的监管是用**沙利度胺**付账的——1957年上市，1961–62年撤出，是一切现代致畸原测试要求、妊娠标签规则与药物警戒体系的直接祖先；1988年异维A酸时代的妊娠预防计划与2016–17年寨卡应急写下了现在的篇章。胚胎学本身是在模式生物上测绘的——Spemann与Mangold的胚组织移植（1924年）、Nüsslein-Volhard与Wieschaus的*Drosophila*筛选（1980年），以及其后的敲除小鼠时代，“同源异型密码”由此解释了脊柱的分节、咽弓与肠的管辖区为什么彼此押韵。
:::

## 通向何处

器官层面的细节延续到后面每一章：咽器在[[anatomy/head-neck]]，心的错误在[[cardiovascular/valve-congenital-disease]]，肠旋转在[[anatomy/abdomen]]与[[gastrointestinal/bowel-disease]]，泌尿生殖道在[[anatomy/pelvis-perineum]]与[[renal/urinary-tract]]，循环转变在[[paediatrics/newborn]]与[[cardiovascular/valve-congenital-disease]]。处方实践中的致畸风险见[[clinical-skills/patient-safety]]，畸形披露的伦理见[[medical-ethics-law/beginning-of-life]]。

::: summary
- 胚层是宪法：外胚层主神经与表面，中胚层主肌肉-骨骼-液体管线，内胚层主肠与腺；病变位置、构成与综合征归类遵循胚层与迁移路线。
- 时钟要紧两次：神经管第28天闭合（孕前叶酸因此有效），LMP与受精算法的差使每一次致畸原谈话改变两周。
- 双胎按绒毛膜分类而不按脸蛋：绒毛膜性由胚胎分裂的日子决定，单绒毛膜胎盘正是整个监测体系围绕的风险。
- 咽器是一张分节地图，它的失败是“野”而不是清单：22q11是嵴与囊；甲状旁腺手术与心分隔是它的临床科目。
- 心、肠、肾与性腺各有一小把特征性运动；畸形就是被中止、过度或误导的那个运动——扭转、Meckel、马蹄肾、隐睾。
- 胎儿循环的三个分流按时刻关闭，而危重先心病通常或者需要其中一个别关、或者需要另一个快关：前列腺素与脉搏血氧筛查就是这句话的两个现代答案。
:::

## 练习

::: exercise 换算时钟 {level=1}
一名患者在“怀孕4周”（按LMP）服用了一种非处方药。给出那一刻的发育阶段，并说出重大结构的器官发生是否正在进行。
::: solution
LMP4周≈受精后约2周：胚泡正在着床或刚刚着床，双胚盘正在形成——原肠形成之前。这是字面意义上的**全或无期**：明显的打击倾向于终止妊娠或完全不致畸，因为器官发生尚未开始；该药极不可能造成结构缺陷。咨询仍须仔细采集病史（有些“4周”的算法不同；排卵时间有变异；少数致畸窗口——如神经板——在数日内即开启），并且安慰应用患者日后能自己复用的两周换算法来表达。
:::

::: exercise 说出遗迹 {level=1}
指出下列结构的胚胎来源：(a)甲状舌管囊肿；(b)脐部开放的尿囊；(c)具胃黏膜的回肠憩室；(d)随感冒增大的颈后三角囊肿；(e)动脉韧带。
::: solution
(a)甲状腺自舌盲孔降至颈下部的降路（导管遗迹；随吞咽/伸舌移动）。(b)**尿囊/尿生殖窦**交通——自膀胱尖走至脐的尿囊；尿囊未闭则脐部漏尿；其中间遗迹即脐正中韧带。(c)**卵黄（卵黄-脐）管**遗迹——Meckel憩室（2的法则）。(d)**第二鳃（沟）囊肿**——经典位于胸锁乳突肌前缘；后三角的非典型变异仍起自掩埋的沟上皮，壁内淋巴组织对感染起反应时增大。(e)闭合的**动脉导管**，左第6主动脉弓的远端遗迹——一个其存留是病变、其闭合是生理事件的结构（见[[anatomy/thorax]]）。
:::

::: exercise 再发风险的算术 {level=1 check=“0.05”}
在本诊所服务的人群中（未预防），一次患儿妊娠后神经管缺陷的再发风险为5%。若受孕前后大剂量叶酸使再发风险降低三分之二，治疗后的再发风险是多少？
::: solution
$0.05 \times (1 - 2/3) \approx 0.017$，约1.7%——相对于未治疗的二十分之一约为六十分之一。这笔算术属于咨询，理由有二：它小到足以安慰惊恐的夫妇，又大到来论证监测（系统超声与AFP）与每日一片的必要；它也演示了本学科诚实的语法——风险按乘法下降，预防效应是一个分数而不是零。（有本诊所审计数据时应引用自己的数字；人群数字随地区与强化政策而异。）
:::

::: exercise 野的诊断 {level=2}
为每一组综合征候群命名其胚胎学野：(a)唇裂＋牙缺失＋耳赘；(b)沿胸锁乳突肌前缘开口的鳃瘘；(c)右位主动脉弓＋永存动脉干＋低钙血症；(d)双肾缺如伴Potter序列。
::: solution
(a)**第一弓/第一、二弓野**，主要为神经嵴衍生物（鼻额突与上颌突）——口面-嵴综合征。(b)**第二咽沟/囊**径路——颈窦未闭锁，产生沿肌前缘的经典沟-皮瘘（深面关系：颈内、外动脉之间，这就是外科解剖）。(c)**心神经嵴/圆锥动脉干与咽囊野**——想到22q11.2缺失（DiGeorge谱系）：输出道分隔、囊衍生物、弓的侧化都是嵴。(d)**间介中胚层输尿管芽诱导失败**：无输尿管芽即无集合系统亦无羊水（胎儿尿是妊娠后半羊水的大部），羊水过少即Potter序列——肢体压迫、肺发育不全——双肾缺如不能宫外存活，因为没有液体肺就长不起来。
:::

::: exercise 是否导管依赖 {level=2}
一名出生第2天的新生儿，发绀，软收缩期杂音，空气下SpO₂ 84%。在任何影像之前开始前列腺素输注。请用一句生理学语言为这个决定辩护，并说出使PGE₁而非单纯吸氧成为正确药物的两个所见。
::: solution
生理学那句话：若肺血流或体循环输出依赖导管，则导管的闭合就是病变本身，再通它是唯一治疗病理生理的药；这个决定不花钱而买到小时。两个所见：**导管前后血氧差**并非必需（在转位这类并联环路病变中，因混合在房间水平，双臂可以同样低氧），而支持导管依赖的特异组合是**吸100%氧几乎不改善的低氧**（固定右向左分流或肺血流受限——高氧打不开闭锁的东西）加上**易休克或虚脱伴酸中毒**（跨导管的体循环血流）。在这种语境下高氧试验是拖延，超声心动图是预约而不是治疗；按临床印象开始前列腺素并转往儿科心脏中心是标准治疗，其呼吸暂停风险是“在监护条件下开始”的理由，不是不给的理由。
:::

::: exercise 显影组织而非器官的扫描 {level=2}
一名不明原因出血的小儿，锝-99m高锝酸盐扫描右下腹阳性。解释诊断、假阴性原因，以及为什么血管造影可能是替代。
::: solution
诊断：**Meckel憩室内的异位胃黏膜**——高锝酸盐被胃型黏膜摄取，所以扫描显影的是胚胎组织而非解剖（见[[anatomy/abdomen]]）。假阴性：胃黏膜太少或被出血损伤/脱落、快速冲刷、以及成人患者（幼儿期外阳性率下降）。当出血迅猛而扫描阴性或不可及，替代方案是**标记红细胞扫描**（数小时内检出较慢的出血）或**血管造影**（更快的出血、更精确、有治疗潜力）；若出血量大，外科或内镜决定必须越过影像——这就是为什么这个问题从一开始就属于小儿外科病房。教学要点：基于胚胎学的影像之所以强，正因为它基于机制，也恰在机制缺失处失效——这就是第二个检查应改攻解剖与血流的原因。
:::

::: exercise 规划甲状旁腺搜寻 {level=2}
因原发性甲状旁腺功能亢进探颈时，找到三个外观正常的腺体，但钙与PTH仍高。接下来去哪里找？什么胚胎学论证了这个搜寻顺序？
::: solution
沿**第3囊的下降径路找第四个腺**：自下颌角沿颈动脉鞘向下，进入上、前纵隔（胸腺舌——翻出胸腺检查），甲状腺内或后，气管食管沟，以及颈动脉鞘与甲状腺实质。这个顺序的论证在于**下甲状旁腺与胸腺同起自第3囊**，因而旅程最远、异位最常见；上腺（第4囊）更恒定，位于上极后方环甲关节附近。副腺（10–15%）与罕见的双下腺是本野的例外——手术以生化解释完毕而终止、而非以看过四个部位终止，就是这个原因；若四个都正常，想异位或（罕见）第五个腺，并考虑影像，下次还有放射科的精确定位——本身就是一张同一胚胎学的地图。
:::
