骨盆是一只骨漏斗、一层肌底，加三根管道——泌尿、后肠与生殖——在其中紧密相伴地穿过，这就是它的疾病以混合物就诊的原因：既梗阻膀胱又侵犯勃起神经的前列腺、撕裂括约肌的分娩、直肠与阴道之间的瘘，以及从肛管走进坐骨肛门脂肪的脓肿。本区解剖因此按三个问题教授：骨与筋膜的建筑是什么，管道在哪里与神经血管交叉，每一处破裂时什么漏到哪里。

本章讲授骨盆骨与盆底、筋膜间隙与自主神经丛、膀胱与尿道、直肠与肛管、前列腺与内生殖器、女性骨盆与会阴体，以及会阴间隙与外生殖器。

## 骨盆骨、入口、出口与盆底

::: definition 骨骨盆与肌性盆底 {#def-bone}
**骨骨盆**由两块髋骨（髂、坐、耻）、**骶骨**（五节融合，骶孔传送S1–S4前支）与**尾骨**。**骨盆上口（终线）**——骶骨岬、翼、髂耻线与耻骨嵴及联合——把承载腹腔脏器的**大（假）骨盆**与产科重要的**小（真）骨盆**（其入口、骨腔与出口）分开；入口平面的结合径中，**产科结合径**（骶骨岬至联合内面，约10 cm）是胎头必须通过的一条。**骨盆出口**是耻骨联合、坐耻支、坐骨结节、骶结节韧带与尾骨之间的菱形，被两结节连线分为前方的**尿生殖三角**与后方的**肛门三角**。**盆膈**——**肛提肌**（起自耻骨体的耻骨直肠肌构成肛直肠悬带、耻骨尾骨肌、起自腱弓的髂骨尾骨肌，加**坐骨尾骨肌**）及其筋膜被膜——构成肌性盆底；其前、中、后三区缺损恰对应膀胱膨出、子宫阴道脱垂与直肠膨出。**阴部神经（S2–4）**出坐骨大切迹于梨状肌下方，绕**坐骨棘**与骶棘韧带（产科医生与麻醉医生的标志——**阴部神经阻滞**即打在棘的周围），在坐骨肛门窝外侧壁闭孔筋膜的**阴部（Alcock）管**内行至会阴分支。**髂内动脉**及其静脉丛贴盆侧壁腹膜之后——盆腔出血的血管控制点，也是每一台髂淋巴清扫的危险。
:::

::: example 摸得到而看不见的棘 {#ex-spine}
一名第二产程产妇枕后位，宫缩无效、胎头卡在上口之上；住院总考虑器械助产，先做骨盆内评估判断骨盆是否相称。
::: solution
住院总需要的每个数字都是经软组织触诊的骨解剖。**骶骨岬**够不到（若够得到，对角结合径就短，真实结合径——对角减约1.5 cm——不相称）；**坐骨棘**在中骨盆摸到，其突出度与**耻骨弓角**及**坐骨大切迹**描述骨腔与出口；**骶骨弯曲**与**尾骨**定出口后矢状径。正是产钳与胎吸围绕设计的标志：器械的弯曲顺骨盆弯曲——胎头以斜径下降过入口、在耻骨弓下转至枕前、在联合下俯屈——而扁平后段的枕后位卡住的胎头转不了，这就是“评估骨盆而不只看宫缩”背后的机械故事。先排空膀胱（其被腹膜覆盖的底部随充盈升出骨盆——胀大的膀胱既堵入口又挡在任何子宫切口路上），联合下方的尿道与耻骨弓是娩出胎头压迫的结构——产后尿潴留与压力性尿失禁是盆底而非膀胱疾病的原因。
:::
:::

## 筋膜间隙与自主神经丛

盆腔脏器悬于盆内筋膜：**浅（腹膜下）层**浓缩为支持韧带（**耻骨膀胱、耻骨前列腺、主（横宫颈/Mackenroth）韧带与骶子宫韧带**）与**膀胱-、直肠-阴道隔**，**髂内鞘**包绕血管神经。脏器与盆壁之间是含脂的间隙——**耻骨后（Retzius）**、**膀胱后（男为直肠膀胱，女为直肠子宫——Douglas窝）**，以及肛提肌下方成对的**坐骨肛门窝**——它们是感染与液体的通路、外科的界面。**上腹下丛**（主动脉丛的延续，左右**腹下神经**沿髂内血管内面下行）与直肠、前列腺、阴道旁的**下（盆部）腹下丛**携带交感（T11–L2：排放、血管收缩）与副交感（S2–4：勃起、膀胱收缩、直肠动力）纤维。其地形是**全直肠系膜切除**在直肠系膜筋膜表面保护腹下神经与盆丛的原因（直肠癌术后的泌尿与性功能是关于界面是否正确的报告），也是根治性子宫切除与前列腺切除带着各自功能代价的原因——在前列腺5点与7点位后外侧走行的**神经血管束（海绵体神经）**即保神经技术的靶。

## 膀胱与尿道

::: definition 膀胱及其颈 {#def-bladder}
**膀胱**在腹膜外，其底部（三角区——光滑，在两侧输尿管口与膀胱内口之间，来自被吸收的中肾管）经直肠膀胱/直肠子宫隔与直肠（男）或阴道（女）相邻，其**顶被腹膜覆盖**：膨胀的膀胱把自己的腹膜被膜向上带走，这就是**耻骨上穿刺**可腹膜外入膀胱的原因——前提是充分膨胀且腹膜已被推开，也是安全的耻骨上路径取旁正中且必须真正胀满的原因。**输尿管**沿盆侧壁下行（跨髂总分叉，在腰大肌与闭孔内肌内侧），转而向前至膀胱底，在女性**从子宫动脉下方**穿过（“桥下流水”——子宫切除时随子宫血管结扎的那里），在男性于膀胱底被输精管从内侧跨过（“先认清输尿管再断输精管”）。三角区输尿管斜行壁内部构成抗反流机制；小儿其失效给出**膀胱输尿管反流**与肾瘢痕。膀胱**动脉**——髂内的膀胱上与下——与其**静脉丛**解释了前列腺/膀胱手术的出血；其**淋巴**行至髂外链；其**感觉**纤维随交感（胀满）与副交感（膨胀、疼痛、S2–4排尿反射弧）两套走行。
:::

::: definition 男性尿道与外渗地图 {#def-urethra}
男性尿道分**前列腺部**（内括约机制、精阜与射精管）、**膜部**（穿过深会阴间隙与**尿道外括约肌**——狭窄、伸展性最小，骨盆骨折撕裂的经典部位）、**球部与阴茎（海绵体）部**（在海绵体内，球部是骑跨伤撕裂的常见部位），开口于阴茎头窝。**女性尿道**长3–4 cm，紧贴阴道前方（共壁），**尿道旁（Skene）腺**与外括约肌是膀胱颈以下主要的控尿机制——生育、雌激素流失与盆部手术各有其特征性尿失禁模式、而上行尿路感染压倒性地多见于女性的原因。
:::

::: theorem 外渗遵循筋膜被囊 {#thm-extravasation}
**膜部**尿道损伤（骨盆骨折）：尿漏入**深会阴间隙与耻骨后间隙**，直肠指检前列腺高位，经尿道插管危险。**Buck筋膜完整**的**球部**尿道损伤：肿胀限于阴茎。Buck**破裂**：尿入**浅会阴间隙**，其后界为会阴膜——故不能后退入肛门三角——但前方与阴囊浅筋膜（肉膜）及腹壁浅筋膜深层连续，因为浅筋膜膜样层（**Colles膜**）在下方附于阔筋膜、在上方附于白线的浅层，故外渗积聚于阴囊、会阴与前腹壁而**不进大腿、不后退入坐骨肛门窝**——伴腹部扩展的“蝴蝶形”会阴肿胀，就是这三个附着的示意图。
:::

::: proof
定理是照着筋膜读出的三条边界。浅会阴间隙是一只袋：底为Colles膜（膜样浅筋膜）、顶为会阴膜，只向前开口：后方Colles与会阴膜后缘融合；两侧附于坐耻支；下方续为阴囊肉膜与腹壁Scarpa膜。膜上方的尿道外括约肌与尿道压迫肌，以及膀胱颈的延续，解释了为什么球膜交界是重建的分水岭：骨盆骨折牵张性断离后，两端隔着深间隙瘢痕分离，修复（渐进会阴入路）就是穿过曾限制尿液界面的解剖。女性尿道的短、直与阴道相邻是十几条临床事实的解剖之句——性交后膀胱炎、尿道阴道反射带、脱垂修复时折弯或去神经的危险，以及尿道憩室以压之溢尿的阴道前壁压痛肿胀就诊。地图同样适用于感染：浅间隙积液（破裂的球部尿道或感染的尿道旁腺）按引导切口的同一规则扩散——经所累间隙的低位对抗引流，而不是穿过下一个间隙。
:::

## 直肠、肛管与齿状线

::: definition 直肠与肛管 {#def-rectum}
**直肠**（12–15 cm）上1/3的前面与两侧被腹膜覆盖、中1/3仅前面、下1/3完全无——决定手术入路（经腹前、经后、经肛）与高位前切除“腹膜内穿孔”危险的序列。其三个**Houston瓣**与两个弯曲（骶曲、会阴曲）在内镜与产科上重要。**肛管**（3–4 cm，从肛直肠环到肛缘）被**齿状（肛皮）线**——肛瓣线与后肠黏膜的最后部分——分为两段。线上：**柱状/内脏内胚层**上皮、**内脏传入（不痛）**、动脉来自**直肠上动脉（肠系膜下）**、静脉经**直肠上静脉→肠系膜下静脉→脾静脉→门脉**、淋巴至**髂内**结、静脉丛即**内痔**。线下：**改造的鳞状（外胚层）**上皮、**躯体性的肛下神经（痛）**、**直肠下动脉（阴部内）**、**直肠下与中静脉入体循环**、淋巴至**腹股沟浅**结，以及**外痔**与皮肤。**内括约肌**（环形肌延续、自主）与**外括约肌**（随意、肛下神经）加**耻骨直肠肌**构成**肛直肠环**，切断它即翻转控便机制。
:::

::: example 做成马蹄形的脓肿 {#ex-fistula}
一名患者肛周痛两周；左侧肛门波动性肿胀作为肛周脓肿切开，数周后仍持续流液；再次入院发现对侧坐骨肛门窝肿物。
::: solution
自然史就是解剖。大多数肛直肠脓毒起自齿状线的**肛腺**梗阻感染；脓沿筋膜界面找最小阻力：**肛周**（最常见，在肛缘）、或经内括约肌的薄弱处入**括约肌间**界面、或入**坐骨肛门窝**（大而充满脂肪、间隔少——故积液量大）、或向上入**肛提肌上**间隙。**切开后不愈=少数患者的肛瘘**——从齿状线同一内口的上皮化管道；而后正中路径经**肛尾深间隙**连通两坐骨肛门窝，使单侧积液在数周后于对侧宣示——**马蹄形脓肿**，以Hanley手术引流（后正中内口切开加两臂对抗引流），正因管道走在那个具名间隙里。外科医生的规则是本章的缩影：**Goodsall规则**（横贯肛门线之前的外口放射状追踪、之后的弯向中线）是括约肌纤维方向的地图，而每一次切开的危险在**肛直肠环与括约肌总量**——能引流而不切割的挂线之所以存在，控便是手术的另一个成功标准。
:::
:::

痔遵循同一条线的经济学：**内痔**是肛管上段的血管垫（右前、右后、左外——反映主要回流支的经典三位），不痛而脱垂（I–IV分级），以套扎治疗（其起效正因齿状线以上的血管垫是无感觉的内脏组织）或以越过齿状线的肛皮剥离切除；**外痔**是下段血管垫与肛周静脉，血栓形成而急性疼痛（躯体神经供应），而直肠丛的**门-体吻合**（见[[anatomy/abdomen]]）正是肝硬化患者的直肠静脉曲张与痔混淆却互不相同的原因。

## 前列腺、精囊与男性生殖道

::: definition 前列腺及其带区 {#def-prostate}
**前列腺**（纤维肌性，约20 mL）位于膀胱颈下方，被**前列腺尿道**与**射精管**穿过，**输尿管**跨过其上外侧面（开放式前列腺切除术中外科医生的“幕布”）。**McNeal带区解剖**是临床地图：**周围带**（直肠指检可及，约70%癌症起源之处、后外侧——故指感之硬与活检之靶）、**移行带**（内部腺体，其良性增生产生梗阻性的中叶与侧叶）、射精管周围的**中央带**，以及**前纤维肌性残端**。毗邻：**肛提肌与后外侧的神经血管束**（勃起）、前方的**耻骨前列腺韧带与背侧静脉复合体**（Santorini丛，控制它即前列腺切除的开场），后方以**直肠膀胱（Denonvilliers）筋膜**分隔直肠——直肠癌手术前侧解剖与罕见的尿直肠瘘的界面。**前列腺静脉丛**与**椎静脉（Batson）丛**交通，这就是前列腺癌以成骨性脊椎转移（腰、盆、股）先于泌尿症状就诊的路线。**精囊**位于膀胱后上方、输精管壶腹在其间；**射精管**穿过前列腺至精阜。
:::

::: example 向内长的腺体 {#ex-bph}
一名74岁男性尿线细、排尿踌躇、夜尿、终末滴沥；指检腺体光滑、对称增大、无结节；PSA 4.8 ng/mL；尿流率高残余尿。
::: solution
生理是带区的解剖：**良性前列腺增生起于包绕尿道的移行带**，故腺体向内生长早期即梗阻（相比之下，造成多数死亡率的周围带癌从腺体可触及的表面向外长、晚期才梗阻）。下尿路症状谱把储尿（逼尿肌对出口梗阻的反应——尿频、夜尿、急迫）与排尿（梗阻本身——踌躇、线细、中断）分开；升高的残余尿是失代偿泵的迹象，也是膀胱小梁、憩室与这条路径终末的高压双侧膀胱输尿管反流与肾功能损害的原因（梗阻后肾见[[renal/acute-kidney-injury]]）。对称光滑的腺体与轻度升高的PSA（随体积、潴留/器械/感染上升——故在指检按摩前或等待后测量）指向非癌；而**静脉丛-椎体路线**属于鉴别诊断谈话的内容，因为它解释了危险的病为何晚发。处理——α阻滞、大腺体用5α还原酶抑制、手术（经尿道电切、大腺体剜除、经包膜的简单前列腺切除或尿道悬吊）——是对解剖的直接阅读：哪块组织梗阻、哪条路径到达它；而电切后逆行射精（膀胱颈被切除敞开）就是本章一句话的知情同意。
:::
:::

**睾丸与阴囊**：睾丸从尿生殖襻经腹股沟管下降（见[[anatomy/abdomen]]）并带其被膜；阴囊内**肉膜**（平滑肌、温度）与精索外、提睾、精索内筋膜各层是壁之解剖，**睾丸鞘膜**（腹膜鞘突远端残余）包绕睾丸、仅后方例外——血管与输精管到达的外科“裸区”固定附睾，也是鞘膜积液向前就诊的原因。**附睾**（头在上、尾在下、输精管在睾丸内侧缘延续）、**精索**及其动静脉安排（蔓状丛降温、精索静脉曲张左侧占优）是阴囊内容的地理：扭转是睾丸在鞘膜腔内的旋转（精索高位结扎，而“铃铛畸形”是易感的横位），提睾反射消失（见[[anatomy/anatomical-language]]）是病史急性时把少年送进手术室而非超声室的体征。

## 女性骨盆、会阴体与分娩

::: definition 子宫、支持结构与会阴体 {#def-uterus}
未孕**子宫**在膀胱上前倾前屈；其**底部**被腹膜覆盖，从中走出**阔韧带**（腹膜襻，载输卵管、圆韧带、卵巢与子宫血管，及其基部的输尿管）、**圆韧带**（经腹股沟管至大阴唇——妊娠腹股沟痛的疼痛线）、**卵巢子宫**、**主（横宫颈）**与**骶子宫**韧带：**主韧带与骶子宫韧带加肛提肌是宫颈与阴道上段真正的支持**（子宫切除时必须重新附着、否则脱垂随之而来的层面），子宫**动脉**沿阔韧带基部上行、**跨过输尿管上方**，静脉丛与淋巴（至髂外、髂内与腹主动脉旁链——宫颈与子宫内膜癌的分期地图）随行。**宫颈**突入阴道（周围为穹窿——后穹更深，是经阴道后穹穿刺与Douglas窝低位点的途径），转化区（柱状-鳞状交界，多数癌症起源处）在宫颈阴道部。**阴道**向后下行，前壁邻膀胱底/尿道（故膀胱膨出及其缺损：中央性或阴道旁——耻骨宫颈筋膜从盆筋膜腱弓“白线”撕脱），后壁邻直肠（直肠膨出，以及**会阴体**——阴道与肛管之间的纤维肌性结节，球海绵体肌、外括约肌与会阴横肌在其间交错——产科撕裂或侧切所切断的结构）。
:::

::: example 三度撕裂 {#ex-sphincter}
一名枕先露手术助产加会阴正中侧切后，子宫收缩良好仍出血；麻醉下检查发现侧切延入肛门括约肌复合体、达但未穿肛管上皮。
::: solution
按标准分类这是**3b/3c–4°会阴撕裂**3a：外括约肌（EAS断裂>50%；3b：<50% EAS；3c：EAS加内括约肌（IAS）；4°：穿肛管上皮——分类就是解剖：两个括约肌加上皮是被分级的三个结构），修复是其倒放。辨认回缩的括约肌断端（EAS向侧方缩到横肌之后——必须找到尖端的理由）、**EAS端端或重叠对接**、IAS单独修复、阴道与会阴黏膜关闭、抗生素与缓泻剂（第一次排便是手术的考验），以及关于**肛门失禁率**（相当比例的排气失禁、更小但真实的被动失禁）与将来分娩（择期剖宫产或助产以避免复发是指南答案；修补部的会阴超声是下一次谈话的开始）的咨询。预防解剖同样标准：**会阴后侧斜切开**在有指征时特意偏离中线，正因中线之后下一个结构就是刚描述的那个括约肌；而会阴体的纤维交错构型，就是“不伤括约肌的那一刀”是角度而非仅是技巧的陈述。

## 会阴间隙与外生殖器

**会阴膜**（旧用法中的尿生殖膈下筋膜；现代教材保留膜而弃“膈”）分隔**深会阴间隙**（**尿道括约肌（尿道外括约肌）**加尿道压迫肌——女性为尿道阴道括约肌——膜部尿道、**阴部内血管**，及男性**尿道球（Cowper）腺**）与**浅会阴间隙**（**外生殖器根部**：阴茎球与脚及其球海绵体肌与坐骨海绵体肌、女性的**前庭大（Bartholin）腺**——男性尿道球腺的同源物，后者反居深间隙——及会阴浅横肌）。外生殖器依次同源：阴茎头/阴蒂头、尿道海绵体/前庭球、海绵体脚/阴蒂脚、阴囊/大阴唇、阴茎皮/阴唇阴囊褶；神经支配即是会阴地图：**阴部（肛下、会阴、阴蒂/阴茎背神经）**加**髂腹股沟（L1，阴唇/阴囊前部）**与**生殖股**覆盖根部皮肤。**Bartholin腺**经处女膜与小阴唇之间的导管开口于阴道口后外侧——梗阻即经典的单侧、“5点或7点位”肿胀：无论感染与否，切开不可把它当作简单切开的脓肿（Word导管袋形缝合是标准，因单纯切开必复发）。

::: quiz
一名外阴癌位于后联合；外科医生规划腹股沟淋巴结手术。哪项解剖支持该决定，例外是什么？

- [x] 外阴淋巴引流至腹股沟浅、然后深、然后髂外淋巴结——除阴蒂沿阴部内轴走行、流向髂内淋巴结，这是与前方病变相关的例外
- [ ] 全部会阴结构无例外地引流至腹股沟浅淋巴结
- [ ] 齿状线把外阴引流改向门脉系统
::: solution
齿状/肛皮线以下的外阴与会阴皮肤是**外胚层、躯体性的，引流至腹股沟结的水平组再垂直组**（浅→深→髂外），这就是外阴癌处理是腹股沟股淋巴结手术的原因（其并发症——淋巴水肿、切口裂开——就是这张地图的代价）。**阴蒂**随尿生殖窦发育、带着阴茎深静脉/淋巴管随阴部内轴走行，可引流至**髂内（髂下）**淋巴结——影响前方病变规划的例外；齿状线以上的肛管向内至髂内（齿状规则的淋巴应用），这就是高位肛管与低位直肠癌按盆结分期、而低位肛缘肿瘤按腹股沟分期的原因。

::: history
会阴解剖是由在其中工作的泌尿外科与产科医生定稿的。十八九世纪的产科流派（Smellie、Chamberlen兄弟及其产钳、Simpson在氯仿时代的改良）把骨盆平面与分娩机制固定为外科事实；阴部神经阻滞（两次世界大战之间Kieth与Östergren的岁月）使该神经绕坐骨棘成为日常工作标志。尿道与阴茎球外渗的“蝶形”地图来自导尿管让骑跨伤在文献中变得罕见的年代；Colles——Astley Cooper的学生，其1818年筋膜层描述仍带他名字——写下了经典论述。肛周脓毒一章的规则——Goodsall（1900）、坐骨肛门间隙的马蹄形引流（Hanley，1978）、现代保括约肌挂线与瘘管栓时代——由St Mark's医院及其流派汇总；McNeal的前列腺带区解剖（1968–72，在全器官切片上完成）在一次职业生涯内重写了泌尿外科教材关于“叶”的那一页。
:::

## 通向何处

肛管手术见[[gastrointestinal/bowel-disease]]与[[surgery/gastrointestinal-surgery]]；前列腺与膀胱生理见[[renal/urinary-tract]]与[[renal/filtration]]；妊娠的骨盆变化见[[obstetrics-gynaecology/pregnancy-antenatal]]、分娩见[[obstetrics-gynaecology/labour-birth]]；盆底与脱垂见[[obstetrics-gynaecology/menstrual-pelvic-disorders]]、妇科肿瘤分期逻辑见[[obstetrics-gynaecology/gynaecological-cancer]]；阴部与产科麻醉见[[surgery/anaesthesia-pain]]。

::: summary
- 骨盆是上口—骨腔—出口的漏斗，有肛提肌的肌底与自主神经布线（腹下丛），每台盆腔根治手术要么保护要么牺牲它；坐骨棘是这一切的标志。
- 外渗——尿、脓、血——遵循筋膜被囊：向前从Colles到肉膜到Scarpa，向后是会阴膜，两侧是坐骨肛门窝的间隔；读出肿胀就读出撕裂。
- 齿状线是肛管的两半：线上不痛/内脏/门脉/髂内，线下痛/躯体/体循环/腹股沟；痔、脓肿、瘘与癌都坐在它的一边。
- 前列腺的带区预告疾病与其并发症：移行带梗阻（BPH）、周围带癌（静脉丛把它们送进脊柱）；5点与7点的神经血管束决定勃起功能。
- 女性骨盆在肛提肌与主骶子宫复合体上分三区支持；脱垂与产科损伤是分区失效，而会阴体的撕裂按其穿过的括约肌分级。
- 外生殖器同源，间隙以会阴膜定义，会阴神经（阴部S2–4、髂腹股沟L1）解释了它的阻滞与其牵涉模式。
:::

::: exercise 照解剖插管 {level=1}
用解剖学解释：(a)为什么男性导尿会在两个点上遇到女性没有的阻力；(b)在阴茎球部强行插管的危险；(c)为什么前列腺患者的导管可能需要探条或弯头。
::: solution
(a)男性尿道的两个生理性狭窄及其弯曲：**膜部尿道**（外括约肌、伸展性最小、在尿生殖膈处）与**外部尿道口**——加上女性3–4 cm直尿道所无的固定弯曲（耻骨下）。(b)球部尿道贴会阴膜下面；此处用力有**假道穿入浅会阴间隙**的危险——正常患者是尿道口周围出血的小伤，而狭窄或感染的尿道则是沿Buck/Colles界面外渗的灾难（上述定理）。规则：轻轻牵引、阴茎成直角（拉直耻骨下弯曲）通过，绝不逆痉挛。(c)增生的**中叶或侧叶**抬高膀胱颈、造成一条前上方的高道，直头导管卡在其上；**弯头（coude）导管**朝前滑过抬高的腺底，失败则耻骨上造瘘或膀胱镜导丝——都是腺体带区几何的应用。

::: exercise 分级与保护 {level=1}
各说出结构与界面：(a)指检在前列腺后外侧摸到的结节及其所在带区；(b)会阴（前列腺）穿刺过深进入的间隙；(c)保神经根治性前列腺切除保护哪束神经、走在何处。
::: solution
(a)**周围带结节**——手指隔着直肠膀胱筋膜摸到周围带后面；硬结、固定指向癌，并驱动经直肠超声引导的模板（就是这张可触表面的地图）。(b)过深或偏后穿直肠壁：针尖进入**直肠系膜/直肠膀胱（Denonvilliers）间隙**，危险直肠系膜血管，感染腺体则危险盆丛界面——这就是标准模板计数针数并以可触/可见腺体为中心的原因。(c)**沿前列腺后外侧（5与7点位）在肛提肌筋膜下、包膜外走行的海绵体神经（勃起神经）与盆丛支**所在的神经血管束——保护它们的解剖在前列腺侧韧带外侧的无血管界面直视下完成，而功能结局正是本章的论证：决定勃起功能 的是解剖，不是癌。

::: exercise 肿物的地图 {level=1}
骑跨伤造成阴囊与会阴肿胀瘀斑、尿道口出血、不能排尿；腹部开始膨隆。用筋膜附着追踪尿液，并说明为什么大腿幸免。
::: solution
球部尿道破裂且Buck撕裂→尿与血进入**浅会阴间隙**→向前入阴囊（肉膜）、上行阴茎（Buck被膜已破）、再入**Scarpa膜深面的前腹壁**；腹部膨隆是外渗的腹壁扩展，不是腹膜内尿液（会给出腹膜刺激与板状静腹）。**大腿幸免，因为Colles膜在腹股沟韧带下方紧附阔筋膜**；肛门三角幸免，因为Colles在后方与会阴膜后缘融合。处理：转流（耻骨上造瘘）与影像（先逆行尿道造影），因为诊断的全部内容是那个界面——而盲插经尿道导管可把部分撕裂变成完全断裂。

::: exercise 坐骨肛门窝还是肛周？ {level=2}
在临床与外科上区分坐骨肛门窝脓肿与肛周脓肿，并给出坐骨肛门窝型更大、更毒、更可能需要麻醉下检查的解剖学原因。
::: solution
肛周：在肛缘，明显、局限，常可安全切开（旧规则：局限处切开——但那只适用于肛周积液）。坐骨肛门窝：在**大而充满脂肪的坐骨肛门窝**，楔在闭孔内肌（外侧有阴部/Alcock管）与肛提肌及其下筋膜（内侧）之间，尖在肛提肌与闭孔筋膜会合处上方，底在会阴皮肤——一个脂肪疏松、间隔少的间隙，脓可追踪数百毫升并向上（朝肛提肌）、向内（朝直肠/阴道），造成会阴饱满、全身脓毒而外表不惊人：故需**麻醉下检查、经低位偏外侧切口沿间隙以手指扫过引流，切口足够宽以防桥接再积，向前方或经肛尾间隙的马蹄形扩展做对抗引流，并警惕窝外侧壁内容（Alcock管内的阴部神经与阴部内血管——盲目高位钳夹能伤到的两个结构）**。

::: exercise 按分区说脱垂 {level=2}
一名68岁女性主诉肿物与“下坠”；Valsalva阳性见阴道前壁下降伴尿道口张开、独立的后壁膨出、宫颈缘下降。说出每个缺损、其筋膜/肌肉失效，以及检查遵循的分区逻辑。
::: solution
**前区（膀胱膨出）：膀胱与阴道之间耻骨宫颈筋膜的缺损**——中央性（两侧盆筋膜腱弓“白线”之间）或阴道旁（耻骨宫颈筋膜自该白线撕脱）；用窥器叶片推回并分级（II/III）——其极端是尿道膨出-膀胱膨出，膀胱底在尿道旁下降，这就是它可与压力性尿失禁共存（或巨大时折弯尿道而掩盖它）的原因。**后区（直肠膨出/肠疝）：直肠阴道隔（直肠膨出），或Douglas窝携小肠下降（肠疝）——缺损在高处**，这就是肠疝与子宫切除后阴道穹隆脱垂共存的原因（穹隆是新宫颈，主骶子宫复合体必须重建）。**心尖区：宫颈/残端的主-骶子宫支持失效**（真正的“盆底”层面；肛提肌与肌性膈是它的吊床）。检查的逻辑就是总结中的分区规则：前、心尖、后，最后站位Valsalva，因为脱垂只在重力对抗下才降到最大。

::: exercise 淋巴结与线条 {level=2}
从胚胎线预测淋巴引流区并解释：(a)肛缘鳞癌；(b)阴囊基底细胞或鳞癌；(c)直肠上段腺癌；(d)胃癌的Krukenberg卵巢转移。
::: solution
(a)**腹股沟浅然后深→髂外**——齿状/肛皮线以下的外胚层皮肤（齿状规则的淋巴应用）。(b)**腹股沟浅（水平组）**——阴囊皮肤，又是躯体外胚层，经典即阴囊壁的扫烟囱工癌及其腹股沟结（第一个被描述的职业癌，其引流至今仍是考试最爱）。(c)**沿直肠上→肠系膜下淋巴结**——后肠的动脉之路（淋巴随动脉：这就是直肠癌分期与高位结扎是同一台手术的原因），直肠下段引流髂内。(d)**经腹腔与胃黏膜下丛的淋巴**——Krukenberg瘤经腹膜或横结肠系膜淋巴至卵巢蒂到达卵巢，这就是年轻女性的卵巢肿物要查胃的路线。每个答案都是本章淋巴语法的一句话：**躯体外胚流向腹股沟，肠与盆腔脏器流向其具名动脉旁的淋巴结，腹膜无处不在。**

::: exercise 疼痛线 {level=2}
追踪解释以下现象的疼痛与反射路径：(a)T10脊髓损伤与b)骶髓损伤患者胀膀胱的尿意与漏尿；以及c)为什么完全性脊髓损伤患者局部麻醉下导尿无痛。
::: solution
(a)胀满感与排尿反射弧住在**S2–4**（经盆内脏神经与下腹下丛的副交感传入）。**T10损伤保留骶弧完好**——反射膀胱充盈、逼尿肌在反射控制下收缩（上运动神经元/反射亢进膀胱），反射克服出口阻力即漏尿，协同失调加上高压储尿；T6以上膨胀可触发**自主神经反射亢进**（高血压、出汗、潮红，是本解剖的急症）。(b)**骶/圆锥/马尾病变摧毁反射弧**——感觉（无胀满感知）与运动（无收缩）支皆失：**无痛、过度膨胀、无反射（下运动神经元）膀胱**伴溢出性失禁与高残余，以清洁间歇导尿处理，正因不能要求膀胱排空。(c)骶段以上的完全损伤意味着**会阴与膀胱颈对痛麻木但自主反射仍在**：故导尿无痛，同时必须记住疼痛等同刺激（导管牵引、结石嵌塞）仍诱发反射亢进——损伤的感觉平面从不意味着“忽略自主神经那条线”，这是同样三句话的实践教训。

::: exercise 设计解剖 {level=3}
用一页教宫颈癌盆腔淋巴清扫：髂外包的边界、由外至内顺序的危险结构、闭孔窝的神经，以及宫旁解剖中输尿管的两个危险点。
::: solution
**边界**：髂外包——外侧腰大肌（其上表面有生殖股神经）、血管外膜本身、上方的旋髂深静脉与淋巴支（结扎，否则等着淋巴囊肿/淋巴漏）、下方的腔隙区；**闭孔窝**——闭孔内肌及其筋膜内走行的**闭孔神经**（可能重复或分裂；清扫前先辨认）、内侧髂外血管、后方髂内系统，以及横穿术野的**副闭孔/异常闭孔动脉**（起自腹壁下或髂外，多达五分之一）——经典意外出血点。**侧壁与宫旁的危险结构由外至内**：腰大肌上的生殖股神经；髂外静脉（牵开，别抓——其损伤把干净解剖变成填塞的术野）；髂内的动脉分支与静脉丛；**输尿管两处**——跨髂总分叉处（在侧壁辨认、跟踪至骨盆缘、保持视野）与**阔韧带基部子宫动脉下方的隧道**（须在夹闭动脉前自主韧带中骨骼化——“桥下流水”是对桥上外科医生的警告），以及前侧解剖中膀胱侧壁/子宫膀胱反折处；最后内侧是**阴蒂…阴道与宫颈后外侧的下腹下丛及其海绵体神经**，其保留是本手术的功能结局。一页的道德，本章一如既往：肿瘤边界以动脉划，功能边界以神经划，而输尿管被要求在两者之中都安全。
:::
