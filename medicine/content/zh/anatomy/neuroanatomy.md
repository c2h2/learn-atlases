神经系统的解剖是唯一一种临床医生在检查病人之前就用它回答问题的局部解剖：病灶在哪里。神经病学课程的每一个症状——偏瘫、感觉平面、核间性眼肌麻痹、帕金森样震颤——都是本章结构语法里的句子：传导束及其交叉、核团及其节段、半球及其动脉，以及颅骨这只固定的盒子，其内容只能以别人的代价肿胀。

本章讲授脊髓及其传导束与综合征、脑干与颅神经核、小脑与基底节与丘脑、大脑半球及其动脉、脑室与脑脊液与脑疝，以及脑膜。颅神经的周围行程在[[anatomy/head-neck]]；疾病的内科学在[[nervous-system/stroke]]及各姊妹章节。

## 脊髓：传导束与综合征

::: definition 脊髓的上行与下行系统 {#def-tracts}
脊髓是围绕中央管的灰质蝴蝶（前、后角，胸段侧角——交感核），外包白质柱。三个系统支配临床检查。**后柱（薄束与楔束）**：大纤维有髓、**同侧**上行至延髓（薄束核、楔束核），弓形内纤维交叉，升为内侧丘系——携带振动、关节位置与精细触觉，及其丧失后的感觉性共济失调（Romberg阳性、踏地步态）。**外侧脊髓丘脑束**：小纤维入髓、在Lissauer束上行一两个节段、换元、**在一两个节段内经白质前连合交叉**，然后对侧上行——携带痛温；交叉解释了为什么**髓内**病变（空洞）在该节段破坏交叉纤维、给出**披风样、节段性、双侧痛温丧失而后柱触觉保留**，也为什么**髓外**压迫只有在横切纤维板的层面上生长时才产生**骶部豁免、上行性**的感觉缺失（骶纤维最外）。**外侧皮质脊髓束**：延髓锥体交叉（约85%），故交叉**以上**的病变麻痹**对侧**躯体、脊髓病变**同侧**麻痹——束内自身纤维板层（颈内、骶外）解释髓外压迫 又先累及双腿。**前角与根**：下运动神经元——松软、萎缩、束颤、反射消失；**脊髓小脑束**在侧索走肢体的不自主本体感觉，而**脊髓自己的血供**（一条脊髓前动脉、两条后外侧，T8–L1关键分水岭受主动脉手术威胁）自成一套血管解剖。
:::

::: theorem Brown-Séquard：半条脊髓，两次交叉，一个诊断 {#thm-sequard}
比方说T10右侧的半脊髓病变产生：病变以下**同侧**上运动神经元性瘫痪（未交叉的皮质脊髓束）、**同侧**振动与位置觉丧失（未交叉的后柱）、该节段**节段性**下运动神经元与后柱体征（T10的角与根），以及自病变**下方一两个节段开始**的**对侧**痛温丧失（脊髓丘脑束携带的是在进入节段经连合交叉的纤维）——伴该节段一条窄的同侧全模态缺失带（后根）。这一图形就是在一名患者身上试验的脊髓接线图；现实最常见的病因不是匕首而是椎间盘、肿瘤与脱髓鞘。
:::

::: proof
综合征的每个元素都是被放到空间里的一次交叉。瘫痪同侧，因为皮质脊髓纤维在**延髓**就交叉了，比脊髓节段高出一整段计数；感觉性共济失调同侧，因为后柱要到**延髓**的核才交叉——两个缺失共享一边，因为脊髓还没有接到那次交叉。痛温丧失**对侧且起自病变下方**，因为脊髓丘脑束是一列**已经交叉**的二阶纤维；在病变节段进入的纤维此刻仍在白质前连合里交叉，这就是对侧脊髓丘脑缺失始于解剖病变**下方**一两节段、而病变自身节段**双侧**失去痛觉的原因（两侧交叉的纤维都被切断——这条“节段性”带若累及肢体节段的双侧中央部，即**空洞性披风**）。现实中的Brown-Séquard患者——经典的椎间盘碎块、肿瘤或多发性硬化——呈现混合而不完整的图形，因为真实病变不读教科书的矢状切面；但不完整的图形仍按同一语法解读：**哪边瘫、哪边不觉得针刺、带在哪里**——三个答案在任何影像之前把脊髓病变定位到一侧一个节段。
:::

::: example 踏地的糖尿病足与暗中笨拙的手 {#ex-sacd}
一名68岁二甲双胍使用者三个月步态不稳、踏地，闭眼淋浴时加重，手指麻木笨拙，舌炎；血红蛋白96 g/L，MCV 112 fL。
::: solution
图形是**亚急性联合变性**——维生素B12缺乏损害**后柱**（感觉性共济失调、Romberg、暗处与湿地加重——闭眼即失效的视觉代偿）与**外侧皮质脊髓束**（“联合”：加上痉挛、膝踝反射亢进伴Babinski阳性——晚期前角受累使下肢混合性松软）。血液象是同一病变的另一半——B12的甲硫氨酸合酶角色所防止的叶酸循环阻滞产生的巨幼变——而病因重要：二甲双胍相关吸收不良、恶性贫血、胃切除手术、不补充的素食。确证：血清B12（与甲基丙二酸和同型半胱氨酸，缺乏时皆升高）、抗内因子与抗壁细胞抗体，以及脊髓MRI后柱T2信号——解剖制造影像学。治疗是B12补充，加上对患者要紧的神经病规则：**治疗停止进军而缺失只部分恢复**，这就是神经上限要早评估、而无论血红蛋白数字、神经症状都是胃肠外补充指征的原因。
:::
:::

## 脑干：“四”的规则与交叉性综合征

::: definition 脑干的布局 {#def-brainstem}
脑干是把脑干的核团围绕脑室排列成的**纵列**：**内侧**——躯体运动柱（III、IV、XII的核与其附近的泌涎/泪腺一般内脏传出）、皮质脊髓束（大脑脚底、脑桥基、锥体）、内侧丘系与中央被盖束；**外侧**——感觉柱（脊髓丘脑束、三叉神经脊束核与脊束、蜗核与前庭核、随行的交感纤维）与小脑脚。**“四”的规则**组织各层面：四个横断面（中脑、脑桥、尾侧脑桥、延髓）各有一个**四个中线结构**（该层颅神经的运动核、内侧丘系、皮质脊髓束，尾侧层的IV核）与**四个外侧结构**（脊髓丘脑束、三叉神经核与脊束、交感纤维、前庭/蜗核与脚）按可预测的组合失效。因为各层颅神经位于皮质脊髓束交叉**之上或同级**，单一脑干病变产生**交叉（交替）性缺失：病变侧颅神经体征，对侧躯体征**——把脑干与半球分开的签名，也是“交叉体征”一词应先把临床医生的心思送到脑干而非皮层的原因。
:::

::: example 构音障碍笨拙却不是典型卒中的手 {#ex-lateral-medullary}
一名61岁高血压患者晨起眩晕呕吐、声音嘶哑、吞咽困难伴呛咳，左半面痛温丧失、右半身痛温丧失，左睑下垂伴瞳孔缩小，左侧肢体不协调。肢体肌力正常。
::: solution
这是**延髓背外侧（Wallenberg）综合征**——小脑后下动脉（或椎动脉）供血区，“四”规则的外侧组加邻近的疑核：**前庭核**（眩晕、呕吐、眼震）、**小脑下脚**（同侧共济失调）、**脊髓丘脑束**（对侧半身痛温丧失）、**三叉神经脊束核与脊束**（同侧面部痛温丧失——脑干名片式的交叉感觉图形）、**下行交感纤维**（同侧Horner）、**疑核**（同侧腭喉麻痹——声嘶鼻音、吞咽呛咳、呕吐反射消失），而**皮质脊髓束与内侧丘系豁免**，因为它们在内侧——故肌力正常、振动觉保留。误吸是即刻的护理问题（吞咽评估是第一项检查），眩晕症状控制是第二，卒中检查——闭塞的椎动脉、颈部影像、按年龄的血栓倾向、血管危险因素阶梯——是预防。要记住的定位之句：**交叉性痛温丧失（同侧面、对侧身）伴球部体征与Horner而肌力保留，就是延髓背外侧**，没有别的结构给出这一组合。
:::
:::

脑干的其他经典读同一批纵列。**延髓内侧综合征**（脊髓前动脉/椎动脉支）：对侧偏瘫（锥体）、对侧位置与振动丧失（内侧丘系）、**舌向病变侧同侧偏斜**（XII）——“交替性舌下神经偏瘫”。**中脑—Weber**（大脑后动脉支）：同侧**III麻痹**（下外斜眼、睑下垂、固定散大瞳孔——瞳孔规则见[[anatomy/head-neck]]）伴**对侧偏瘫**（大脑脚）；内侧纵束受损给出**核间性眼肌麻痹**——侧视时同侧眼不能内收伴对侧眼外展位粗大眼震，年轻患者双侧INO是多发性硬化直到证明否则。**脑桥—Millard-Gubler与脑桥背外侧综合征**：面神经核或其束加入皮质脊髓束，给出**交替性面瘫伴对侧偏瘫**，而小脑中脚、三叉神经核与外展神经核（后者摧毁全部同侧水平注视——PPRF的邻居）填满该层的体征。**网状结构及其上行投射**（去甲肾上腺素的蓝斑、5-羟色胺的中缝、组胺的结节乳头顶、胆碱的脚桥-背外侧被盖）是意识的解剖，而双侧被盖功能障碍——或其弥散的代谢抑制——是[[nervous-system/stroke]]中昏迷的结构对应物。

## 小脑、基底节、丘脑

::: definition 小脑及其体征 {#def-cerebellum}
小脑**同侧**调节运动（其输出交叉两次——小脑上脚交叉至对侧红核与丘脑，再下行投射——故半球病变在同侧签名）。其病变产生**肌张力低下、意向性震颤、快速轮替动作障碍、钟摆样反射、分解与辨距过度运动、爆发性或扫描样语言与眼震**，肢体体征来自半球，**躯干性共济失调与步态共济失调来自蚓部与绒球小结叶（前庭小脑，其病变给出下击性眼震与头部Titubation）**；小儿中线肿瘤（髓母细胞瘤、第四脑室室管膜瘤）以共济失调加导水管或第四脑室梗阻的颅内高压就诊——小脑临床对子的两半：协调，与后颅窝的空间算术。
:::

**基底节**——纹状体（尾状核与壳）、外/内苍白球、底丘脑核、黑质致密部与网状部——构成选择并增益调节皮层运动程序的环路；其病变是**少动-强直型（帕金森综合征的黑质纹状体多巴胺缺失——静止性震颤、强直、运动迟缓、姿势不稳；见[[nervous-system/movement-disorders]]）**或**多动型（底丘脑核病变→对侧偏侧-投掷样舞蹈症；纹状体补丁与卒中→舞蹈症、肌张力障碍，及运动障碍全部多巴胺平衡的药理学）**。**丘脑**是皮层的门户——**VPL**（来自躯体的内侧丘系与脊髓丘脑输入）与**VPM**（三叉）、丘脑枕与后核（联合）、前核与外侧核（边缘与小脑环路）、髓板内核群（觉醒，及模拟意识障碍的战略梗死部位）；其病变给出**全模态对侧感觉丧失**（内侧丘系与脊髓丘脑束在中脑已经会合）与**丘脑痛综合征**——卒中后中枢痛，这个去传入的烧伤教会我们痛除了感受器还有皮层。

## 大脑：皮层、优势、动脉

::: definition 半球及其表面 {#def-cortex}
**初级运动皮层**（中央前回，面部代表区在外下方，腿部在内侧的旁中央小叶）与**初级感觉皮层**（中央后回，同一小人）在顶部由**大脑前动脉**（腿与排尿中枢）、在外侧面由**大脑中动脉**供血（面与臂，优势半球下额回的Broca区与颞上回的Wernicke区——其血管与功能分离即失语综合征的解剖）。**枕叶**（距状皮层，黄斑代表在后——枕叶梗死伴黄斑豁免的原因）属**大脑后**；颞叶上表面是听放射之地与Meyer袢的绕行（颞叶的“天上馅饼”——对侧同向上象限盲），对照顶叶视放射的“地上馅饼”。
:::

::: theorem 每条动脉的卒中是一个综合征，因为皮层的地理是功能的 {#thm-arteries}
**ACA**：对侧下肢瘫与感觉缺失、淡漠与抓握反射、尿失禁——内侧条带。**MCA（上干）**：对侧面臂瘫、凝视**偏向**病灶（额叶眼区把眼推向对侧视野，破坏性病灶让眼转向病侧），优势半球——Broca失语。**MCA（下干）**：Wernicke失语伴上象限盲，或——非优势——**偏侧忽略**、无自知、穿衣失用。**MCA（主干/近端）**：全部加上偏盲与 致密偏瘫。**PCA**：对侧同向偏盲伴黄斑豁免，及——优势侧——胼胝体压部并入左枕故事时的失读伴失写，深支受累时的丘脑与中脑体征。**分水岭（ACA–MCA–PCA之间的交界带梗死）**：双侧肩髋“桶中人”无力与低灌注的认知-视觉断连——低血压自己的解剖。
:::

::: proof
综合征的逻辑是两张地图叠合：小人与纤维束。**眼偏斜**遵循额叶眼区的交叉投射：右半球梗死摧毁把眼转向左的驱动，故凝视停在病灶侧（远离瘫痪侧）——而**脑桥**病变（PPRF或外展神经核，水平注视的最后公共通路，已在交叉之后）把眼转向**病灶对侧、偏瘫侧**——同一征象机制在两个层面读出，这就是脑干综合征里的“反向凝视”是定位线索而非谜团的原因。**忽略**是右侧顶叶（及其额叶与扣带回网络）的疾病——患者不注意左侧、否认缺失、把钟面的数字画在右边；**无自知**与虚构是它的亲属而非心理学意义的否认，这个区分属于查房。**失语**定位遵循优势颞额语言区：Broca为非流利、费力、无文法而理解相对保留（常伴右侧面与臂的邻近皮层体征——经典失语伴偏瘫由此而来）；Wernicke为流利、空洞、错语而理解受损且无瘫痪（病灶在外下、运动区豁免）；传导性失语——复述不成比例地丧失——是两者之间的弓状束。左PCA区的**失读无失写**是断连论证的临床化：文字到达右枕皮层、过不了梗死的压部、永远到不了左半球的语言区——而书写保留，因为语言输出区完好。每个发现都是同一读两遍的定理：脑是一张地图，而动脉把地图分块。
:::

::: example 不是偏头痛的头痛 {#ex-uncus}
一名24岁男性右颞被打，短暂迷惘后正常交谈两小时；随后呕吐、意识模糊，右瞳散大固定，左上肢左下肢渐无力。
::: solution
这是**伴小脑幕切迹疝的硬膜外血肿**——脑膜中动脉在**翼点**（颅骨最薄点，平片经典显示骨折线跨过其沟）被颞骨撕破，血块膨胀使颅内压越过阈值前一到六小时的**中间清醒期**，然后是脑疝三联：**同侧固定散大瞳孔**（海马钩回把III压在天幕缘——副交感表面纤维先受累，又是瞳孔规则）、**对侧偏瘫**（大脑脚受压——有时**同侧**，当对侧大脑脚被碾在天幕上，Kernohan切迹，这个假定位体征使偏瘫侧不可靠），与中脑网状结构失去上行驱动的**进行性意识迟钝**。处理就是时钟：立即CT、立即神经外科清除（开颅并电凝该动脉，如今慢性硬膜下的表亲常用脑膜中动脉栓塞），途中气道与渗透压控制。给急诊室的本章要点：**颞部打击伴任何意识丧失与任何瞳孔改变是一次扫描，不是偏头痛或醉酒的诊断**——硬膜外血肿杀死一小时前还在说话的年轻人，而翼点与动眼神经的解剖就是原因。
:::
:::

::: example 七岁儿童的晨起头痛 {#ex-posterior-fossa}
一名儿童三周清晨头痛、正午前缓解，两天呕吐，新发步态不稳；查体歪头坐位、宽基底步态、左侧辨距不良与视乳头水肿。
::: solution
在MRI证明否则之前这一组合就是**后颅窝肿物**，而综合征的两半都是本章解剖。**蚓部与小脑半球**给出躯干与肢体共济失调及辨距不良；毫米之远的**第四脑室**被压或被侵（髓母细胞瘤起自蚓部菱形唇，室管膜瘤起自脑室底），受阻的脑脊液通路给出**颅内高压**——晨起头痛（夜间低通气升高CO₂与脑血流，Monro-Kellie曲线的每日预演）、呕吐、视乳头水肿，与来来去去的第六神经麻痹（该神经长的颅内行程使它成为压力的假定位者）。儿童歪头该被核查后颅窝肿瘤而不是贴上斜颈标签；任何腰穿之前必须查眼底——扁桃体疝规则。处理是儿科神经外科：MRI（髓母细胞瘤经第四脑室出口与椎管蛛网膜下腔 滴状转移需全神经轴）、激素与不用乙酰唑胺的手术桥梁，以及后颅窝自己的外科解剖——乙状窦、蚓部中线静脉、外展神经核与绕行的面神经居住的面丘这一脑室底，及上方的导水管——术后记录清点损伤的正是结构。
:::
:::

## 脑室、脑脊液与颅骨的算术

::: definition 脑脊液系统与脑积水 {#def-csf}
脑脊液由**脉络丛**分泌（侧脑室、第三脑室顶、第四脑室）——每天约500 mL、存留约150 mL、每天周转三次——流经**侧脑室→Monro孔→第三脑室→大脑导水管→第四脑室→Luschka孔（外侧）与Magendie孔（正中）→蛛网膜下腔**，并经**蛛网膜颗粒汇入上矢状窦**。任何一点的梗阻都产生上游的**梗阻性（非交通性）脑积水**——导水管狭窄（婴儿的头围增大；后颅窝肿瘤的第四脑室）、Monro孔（胶样囊肿——体位性头痛与猝死）、第四脑室出口（髓母细胞瘤）；吸收障碍产生**交通性脑积水**（出血后与脑膜炎后的颗粒纤维化；**正常压力脑积水**——步态失用先于痴呆先于失禁，其顺序要紧的三联，“湿、晃、疯”是最后也最特异的助记）。颅骨是近固定的盒子，以**Monro-Kellie**平衡装着脑、血与脑脊液——脑脊液与血的代偿性移位买到约10–15%的体积，此后压力沿颅内顺应性曲线陡升，内容开始移动：**大脑镰下（扣带）疝**在镰下压迫ACA（下肢为主的梗死）、**钩回（天幕切迹）疝**如硬膜外示例、**中央下行疝**伴意识丧失的头尾分级与定位层面的呼吸与瞳孔改变，与经枕骨大孔的**小脑扁桃体疝**——延髓闭塞器受压、呼吸停止、本章第一诫的终局：**局灶体征、意识抑制或后颅窝综合征的患者，在影像之前不要腰穿**，因为针制造的压力差可能恰是脑疝所需的最后一毫升。
:::

**脑膜及其出血**结束外科的清单：**硬膜外**（动脉性、脑膜中、双凸镜形、限于骨缝）；**硬膜下**（横跨硬膜下腔的**桥静脉**撕裂——婴儿的减速伤、酒精中毒者的跌倒、老年脑萎缩皮层把静脉拉紧；新月形、跨桥静脉，老华法林患者的慢性硬膜下以其模糊的困惑与最终的单侧偏瘫就诊、结果是一侧积液）；**蛛网膜下腔**（Willis环分叉处的动脉瘤——后交通、大脑中、前交通及其额叶与腿野与记忆后遗症——霹雳样头痛、CT第一小时的敏感度、其后的腰穿黄变）；与**脑内**（高血压出血偏爱的深部位置：壳、丘脑、脑桥、小脑——后两者邻近脑书写下的外科紧急）。

::: quiz

::: history
这套系统的解剖是靠缺陷论证建起来的。Gall与颅相学的时代让位于Broca 1861年的切除实验与尸检（下额言语区）与Wernicke 1874年的中枢概念；Brown-Séquard 1850年代在犬的半切实验与他本人临床描述的脊髓讲述了交叉的故事；反射弧与神经元学说（Sherrington、His、Ramón y Cajal）固定了突触语法。脑干的交叉性综合征在1850–1920年的维也纳与爱丁堡诊所命名；小脑与锥体外系的临床流派（Marie、Dejerine、Wilson与Kinnier Wilson）填满了皮层下各章。Moniz的额叶白质切断术（1935）及其废止教给了额叶的代价；Penfield在蒙特利尔的皮层刺激地图从清醒患者绘出小人；而脑室与脑脊液随着Quincke 1891年的腰穿与脑室引流时代成为生理学——压力，而不只是结构，从此可治。
:::

## 通向何处

卒中内科学与影像见[[nervous-system/stroke]]；颅神经周围行程见[[anatomy/head-neck]]；自主与疼痛药理学见[[pharmacology/autonomic-drugs]]与[[nervous-system/headache-pain]]；脊髓节段的椎管内麻醉见[[surgery/anaesthesia-pain]]；昏迷的代谢解剖见[[nervous-system/dementia-neurodegeneration]]与[[emergency-critical-care/critical-care]]。

::: summary
- 脊髓是三次交叉：后柱在延髓交叉、皮质脊髓在延髓（锥体）、脊髓丘脑在进入脊髓时交叉——每一个感觉平面与每一个半切问题都是这三句话。
- 脑干是围绕脑室的纵列加“四”的规则；其签名是交叉综合征——颅神经在病变侧，长束在另一侧。
- 小脑在同侧签名，丘脑是所有人的门户而谁的朋友都不是，基底节在少动与多动之间做选择。
- 每条大脑动脉是一个综合征，因为它供应功能地图上具名的一块——ACA腿、MCA面臂与语言或忽略、PCA视觉、分水岭肩带。
- 颅骨服从Monro-Kellie：代偿、曲线拐点、然后按具名模式脑疝——瞳孔-钩回、腿-ACA-镰下、呼吸停止-扁桃体；先影像再穿刺。
- 出血各有解剖：动脉-硬膜外-翼点、静脉桥-硬膜下、环-动脉瘤-蛛网膜下腔、深穿支-脑内。
:::

## 练习

::: exercise 节段与侧别 {level=1}
为下列各给出病灶（侧别与层面）：(a)左偏瘫、左位置觉丧失、伸舌右偏；(b)披风分布双侧痛温丧失而双手触觉振动保留；(c)左睑下垂、左瞳固定散大、右偏瘫；(d)眩晕、左Horner、左面部麻木、右侧身麻木、声嘶、肌力正常。
::: solution
(a)的答案是**右侧延髓内侧病变（延髓内侧综合征）**：锥体（交叉以上的左偏瘫）、内侧丘系（左位置与振动丧失），与**右侧舌下神经根丝或核——舌偏向病变侧**，本综合征中唯一指向自身脑干层面的颅神经。每项的方法相同：列出每一侧每一模态，问每条束在哪里交叉，然后才选层面与侧别——三条交叉束、三个问题、一个答案。(b)**脊髓空洞——C2–T1双侧中央管周围**，交叉的连合纤维被毁（披风）、后柱保留（触、振）、皮质脊髓束保留或后期受累（空洞累及前角时的手部萎缩）。(c)**左中脑（Weber）**——III束与大脑脚。(d)**左延髓背外侧（Wallenberg）**——前庭、三叉、交感、疑核与脊髓丘脑纵列而锥体豁免。
:::
:::

::: exercise 同向还是异向 {level=1}
一名患者双眼视野左半均看不见；瞳孔光反射正常；眼无病。通路病灶在哪里，哪些发现能分开视束与枕叶皮层？
::: solution
**左侧同向偏盲**定位在视交叉之后——右侧视束、右侧外侧膝状体及其放射，或右侧视皮层。**视束**病变常显示相对性瞳孔传入障碍（视束的瞳动纤维前往顶盖前区）并随时间出现盘弓凹陷（逆行跨触突萎缩轻但真实），偏盲依部位而同心或非同心：**放射**携带颞叶（上方，Meyer袢——“天上馅饼”）与顶叶（下方，“地上馅饼”）两半，非同心且常带各自脑叶的其他体征（顶叶伴忽略，颞叶切除不慎时视野缺损更重）；**枕叶皮层**给出最同心的缺损、**黄斑豁免**（枕极的PCA-MCA双重供血）与正常瞳孔，因为瞳孔纤维在膝状体之前已离开。检查者用视野的同心性、瞳孔与脑叶的同伴把视束、放射与皮层分开——又是通路的地理。
:::
:::

::: exercise 步态失用 {level=2}
一名76岁患者三年渐进的宽基底、磁性、拖曳步态、尿频、思维迟钝伴淡漠；MRI示脑室增大超过脑沟萎缩的程度。这是什么综合征，为什么步态先出现，放液试验预测什么？
::: solution
**特发性正常压力脑积水**——其交通性脑积水的三联按**出现与对治疗反应的顺序**是“晃、湿、疯”：步态最先也最好，因为脑室周围**额叶的放射冠旁纤维与旁中央区的下行腿纤维被扩大的脑室拉伸**（腿纤维走得最贴近脑室——与ACA腿野同一身体分区），失禁随额叶排尿中枢的断连而来，痴呆——皮层下性、淡漠、迟缓——最后也最难逆。放液试验（大量腰穿前后测步态）帮助筛选分流候选人，统计学要诚实：好的放液试验预测反应，差的不排除；分流的改善步态最大、认知最小，这就是手术主要为步态提供的原因。绝不能漏的鉴别是每一个模仿者——帕金森综合征、颈椎病性脊髓病、ACA自己的腿、周围性前庭病——因为诊断靠图形而非图片。
:::
:::

::: exercise 两种核间性眼肌麻痹 {level=2}
一名年轻女性向右注视时双眼水平双影：左眼不能内收，右眼外展伴眼震；集合正常。说出传导束与侧别；然后解释为什么同样的眼征出现在一位突发起病的74岁高血压患者意味着完全不同的事。
::: solution
病灶在**左侧内侧纵束（MLF）**。向右注视时右外展神经核激发右外直肌，同时中间神经元纤维立即交叉并在**左MLF**上行至左动眼神经核的内直肌亚核；故左MLF病变取消右注视时的左内收而右眼外展伴粗大眼震——**左INO**，按未能内收的那只眼命名。集合正常因为内直肌运动神经元及其核上性集合输入（中脑而非MLF）完好——把INO与内直肌麻痹分开的体征。年轻的单侧或双侧INO是多发性硬化（MLF致密的髓鞘与长束的长度使它成为脱髓鞘靶）；老年血管病患者的同签名是**脑桥腔隙性梗死**，而昏迷伴固定瞳孔的患者脑干病变是结构性且紧急的——规则是INO在任何年龄都定位到MLF，而**病因**随人群翻转，这就是“一个INO，什么年纪？”就是一整间门诊的原因。
:::
:::

::: exercise 分水岭 {level=2}
心搏骤停伴长时间低血压后，患者能活动手臂与面，却不能抬肩、腿部几乎不能动；运动与面孔的视觉受损；记忆严重受损。用血管供血区解释每一项。
::: solution
**交界带。**高凸面沿腿区（ACA）与面臂区（MCA）之间走行的**ACA–MCA皮层交界带**：其“桶中人”综合征是肩与近端臂无力（小人的躯干与肩条带正在交界）而面手相对保留，更深的ACA主干区也受累时腿更重。**MCA–PCA交界带**在颞顶枕交界处 产生视觉联合缺损——双侧顶枕交界梗死的**脑性视觉障碍（运动与面孔）与Balint样综合征**（视空间注意受损与视神经性共济失调）。而**海马——Sommer角——是全局缺血选择易感灰质之最**，故遗忘综合征叠在皮层交界带走的一切之上：经典教学是低灌注的记忆伤在海马（最深的打击则有板层皮层坏死与分水岭的内部——纹状体——交界）。此处的解剖不是一条血管而是两个供血区的共享边缘——大脑自己的低流量地理图。
:::
:::

::: exercise 脊髓的卒中 {level=2}
血管内主动脉修复一小时后患者弛缓性截瘫、躯干以下痛温丧失而双腿振动与本体感觉保留。说出综合征、动脉与机制。
::: solution
**脊髓前动脉（脊髓前部）综合征**——前2/3（皮质脊髓与脊髓丘脑束及角）梗死而**由脊髓后动脉供血的后柱豁免**；弛缓是脊髓休克头几小时，之后为痉挛性截瘫。主动脉修复后的机制：**Adamkiewicz大根动脉**——大的根髓供血支，通常左侧、T8–L2之间入椎——在移植物中被覆盖、栓塞或低灌注，脊髓自己的分水岭（中胸段脆弱的供血）是这一噩梦并发症的原因；预防就是方案（远端灌注、脑脊液引流降低脊髓外在压力、运动诱发电位监测），治疗是同样几个杠杆反向转动（提升平均动脉压、引流脑脊液以提高脊髓灌注压），以MRI脊髓水肿与弥散受限确证。临床规则是本章最后的血管一课：**脊髓和脑一样有动脉供血区，而主动脉手术是脊髓卒中手术风险最高的房间。**
:::

::: exercise 床旁失语 {level=2}
分类并给出病灶：(a)流利、空洞、迂回、错语；不能复述；不能命名；理解受损；无瘫痪。(b)非流利、费力、电报样；理解好；复述差；右偏瘫。(c)除不能复述外一切流利良好——患者纠正你的错误却说不出一句话。
::: solution
(a)**Wernicke（接受性/后部）失语**——优势颞上回后部（理解皮层的Wernicke区），MCA下干，常带Meyer袢近邻的上象限盲而**无瘫痪**，因为运动区豁免。(b)**Broca（表达性/前部）失语**——优势下额回（面臂运动皮层的邻居——故偏瘫），MCA上干；理解保留，费力与无文法是病变签名。(c)**传导性失语**——两个语言区之间的**弓状束**（或其缘上回的入口）：自发语言与理解近乎正常、患者懊恼地知情，而复述失败——这个断连综合征证明了（仍在证明）经典语言模型的架构，胜过任何病灶地图。值得保持的临床习惯：**先测复述再测命名**，因为复述保留对复述受损的分裂是失语算法的第一个岔路——纤维解剖在做诊断的工作。
:::

一名昏迷患者：右瞳6 mm固定、左瞳3 mm有反应；疼痛刺激左上肢左下肢伸直姿势；不规则、周期（Cheyne-Stokes）呼吸；向右转头时无头眼（玩偶眼）反射。组织定位与决策。
::: solution
**伴右瞳固定散大的参差瞳**是右侧**小脑幕切迹（钩回）疝**压迫同侧III——瞳孔先于运动束，因为副交感纤维走行表浅（[[#thm-arteries]]与瞳孔规则的逻辑）。**左侧伸直姿势**是红核水平或以上皮质脊髓束的失效（去大脑强直——中脑/脑桥上段），同一压迫的运动账本（记住Kernohan切迹的假定位：偏瘫侧并非万无一失）。**Cheyne-Stokes呼吸**把呼吸生成器的控制放在仍属前脑/上脑干（是半球与间脑昏迷的图形；共济失调性、喘息样呼吸才说延髓与终末）。**头眼反射消失**意味着脑干弧——前庭核、MLF、动眼与外展神经核——在脑桥中脑交界或其以下失效；该手法要求颈椎已清，鼓膜允许时冰水变温试验完成算术。决策一段说完：在证明否则之前这是**外科性肿物**——立即保护气道、甘露醇或高渗盐、过度通气只作短暂桥梁、几分钟内推到CT台上，因为硬膜外或大脑半球巨大肿胀所致固定瞳孔在第一小时仍可逆、第三小时就不，也因为其他昏迷（代谢、中毒）不会不对称地散瞳：**不对称就是外科指针**——整章解剖就是为这条规则而写。
