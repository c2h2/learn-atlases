头颈每平方厘米挤进的重要地皮多过全身任何区域：气道及其返行的神经；颈内静脉与颈总动脉输送脑的血；交感干趴在椎骨槽上；唾液腺的导管与其支配面部运动的神经并行；咽则被气、食与感染共用。外科的颈是一组三角与鞘；内科的颈是一组神经与间隙；本区的急症——气道梗阻、深间隙感染、颈动脉出血——全是这套解剖的急症。

本章讲授颈椎与颈部三角、颈动脉鞘与颈根、咽与喉及其神经、甲状腺与唾液腺、面部、头皮与海绵窦，以及眶。

## 颈椎与颈部区域

::: definition 颈椎及其运动 {#def-cspine}
**寰枕关节**（枕髁坐落在C1即**寰椎**的侧块上；寰椎前弓与C2即**枢椎**的**齿突**相关节，由**横韧带**及其翼状、覆膜副韧带束缚）是点头关节；**C1–2**是摇头的枢轴，两者合供颈部一半的旋转与屈伸。**椎动脉**在横突孔内上行（通常于C6入孔），绕寰椎侧块后方、穿硬膜入颅。下颈椎携**钩椎（Luschka）关节**，其骨赘压迫出口根——与腰椎同一椎间孔逻辑（[[anatomy/back-upper-limb]]）。椎前肌与**颈深筋膜**（封层、气管前层、椎前层，交汇处形成**颈动脉鞘**）围成颈部，筋膜附着决定感染去向。
:::

::: definition 三角 {#def-triangles}
**胸锁乳突肌**把每侧分为**颈前三角**与**颈后三角**。后三角（**斜方肌、胸锁乳突肌、锁骨**；顶为皮肤与位置浅表易伤的**副神经**——非正规淋巴结活检的经典牺牲品，也是后三角淋巴结只有在先辨认神经后才可动刀的原因；**颈外静脉**横过；底下为**臂丛干**——肌间沟阻滞的靶；以及**淋巴链**，其锁骨上端藏着**Virchow淋巴结**——腹部恶性肿瘤左侧的哨兵，其路径即胸导管）。前三角被二腹肌与肩胛舌骨肌切成四份：**颏下**（唇尖与口底淋巴——“路德维希”地域的牙源性来源）、**下颌下**（腺体、舌神经与舌下神经、导管）、**颈动脉**（鞘与C4分叉，下述神经关系）与**肌**（甲状腺、甲状旁腺、气管、食管、喉）。锁骨后的**颈根**自内向外塞着大静脉与动脉、左侧弯弓注入锁骨下-颈内静脉交界的**胸导管**、第一肋颈上的**交感干**，与**肺尖**——Pancoast瘤（见[[anatomy/thorax]]）或颈肋所累及的四个结构。
:::

::: example 让肩膀塌下来的淋巴结活检 {#ex-spinal accessory}
一名40岁患者在右颈后三角“局麻下切除了淋巴结”；数周后肩痛，手臂不能外展过水平，无法梳头。
::: solution
**副神经（CN XI）**在锁骨上约两横指处、贴颈内静脉表面于颈后三角的皮下横行，是该野非正规淋巴结活检的经典牺牲品；切断或瘢痕卡压使**斜方肌**瘫痪（肩**塌**下，外展过90°失败——斜方肌上旋关节盂——见[[anatomy/back-upper-limb]]翼状肩练习），其肩胛骨翼状为**外侧性**且外展时加重，可与前锯肌麻痹鉴别。预防就是规则：后三角的淋巴结活检意味着开放入路并辨认神经，而非局麻下掏取。治疗须转专科——新鲜损伤行神经移植或转位；理疗方案（肩胛支具与提肩胛、菱形肌强化）至少在发现过晚时部分恢复功能。法医学解剖就是本病例写下的那句话：神经浅表、恒定、正在术野里；损伤本身即“没有去找它”的陈述。
:::
:::

## 颈动脉鞘、交感干与深间隙

**颈总动脉**在**C4**（甲状软骨上缘）分为**颈内动脉**——**在颈部无分支**，经颈动脉管入颅——与**颈外动脉**，其八条分支（甲状腺上、咽升、舌、面、枕、耳后、上颌、颞浅）绘成面与口的动脉地图。分叉处的**颈动脉体**是外周化学感受器（[[cardiovascular/circulation-blood-pressure]]）；颈内动脉起始处的**颈动脉窦**是压力感受器，按摩它使心率减慢，而肿瘤或衣领刺激它致晕。**颈内静脉**位于后外方，**迷走神经**在其后之间，同在一条鞘内；鞘的筋膜沿大血管与心包膜相融——颈静脉搏动因此而来，被切断的颈静脉能吸气也因此而来。**颈交感干**在鞘后的头长肌上；其**星状神经节**（C7–T1，第一肋颈上方）携带中断后产生**Horner综合征**（上睑下垂、瞳孔缩小、面部无汗、眼球凹陷外观）的纤维。**颈深间隙**——咽后、“危险”间隙（颈动脉鞘与椎前筋膜之间，颅底至膈）、扁桃体周围、咽旁、下颌下——是颈部脓毒的高速公路，而其出口是胸腔：一颗磨牙引发的下行性坏死性纵隔炎，就是这套解剖的ICU入院通知书。

::: example 口底蜂窝织炎 {#ex-ludwig}
一名糖尿病男性在下颌磨牙感染后三天口底疼痛、木板样抬高；舌被向上向后推挤，言语含糊，流涎而焦虑。
::: solution
**Ludwig咽峡炎**是**下颌下、舌下与颏下间隙**的双侧蜂窝织炎——下磨牙根尖位于下颌舌骨肌附着下方，引流进下颌下间隙，感染在舌下疏松组织内越过中线。它杀人靠**气道梗阻**而非脓毒症：舌被推向咽后壁，而肿胀是不波动、不局限的，因为是蜂窝织炎而非脓肿——“切开”毫无帮助，延误才是敌人。处理按解剖的优先级：**先保气道**（清醒纤支镜插管；面部与颈部解剖不允许时行外科气道——下述气管切开/环甲膜切开决策）；再**覆盖口腔厌氧菌的广谱抗生素**；然后在积液成脓后**引流牙齿与已成形的脓腔**，下颌下切口沿皮纹、避开**面神经下颌缘支**（个别患者它在下颌角下方绕弯——切口应低于下颌骨两横指）以及口底内的下颌下导管与舌神经。一句话总结：口底坚硬、舌体抬高，就是有牙科病史的气道急症，糖尿病与免疫抑制者来得最快。
:::
:::

## 咽、喉及其神经

::: definition 咽与腭 {#def-pharynx}
**咽**自颅底至C6（环状软骨下缘，续为食管）：**鼻咽**（鼻腔后方，顶有**咽（腺样）扁桃体**，**咽鼓管（Eustachian）口**及其圆枕——小儿梗阻之所）、**口咽**（口腔后方，**腭扁桃体**居于舌腭弓与咽腭弓之间，其囊贴于上缩肌——扁桃体周围脓肿的界面）与**下咽**（空气与食物的共用腔，喉入口两侧的**梨状窝**——鱼刺卡住、异物必须寻找之处——以及隐窝续为食管的喉咽）。缩肌由**咽丛（迷走）**支配，**茎咽肌（IX）**除外；腭也如此，除**张腭帆肌（V3）**——“咽肌皆迷走、茎咽除外归舌咽；腭肌皆迷走、张腭除外归三叉”。**扁桃体窝的动脉是面动脉的扁桃体支**，其感觉线解释了**经Jacobson神经（IX）的牵涉性耳痛**。
:::

::: definition 喉 {#def-larynx}
喉是气道的守卫括约肌：软骨——**甲状**、**环状**（唯一完整环，故环甲膜是急症之门；也故过紧气管插管致后板坏死与声门下狭窄）、坐落环状软骨上缘的**杓状**、入口前方的**会厌**——带**喉室**及其**前庭（假）襞与声（真）襞**的**声门裂**；小儿气道最窄处是**环状软骨环**（故儿科插管必须在20–25 cmH₂O有漏气——紧的是环状软骨而非声带）。肌肉：**环甲肌**——声带张肌，由**喉上神经外支**（随甲状腺上动脉走行——外科医生的第二根神经）支配；**其余全部喉内肌**由**喉返神经**支配；**后环杓肌是唯一外展肌**，故双侧喉返麻痹时声带居正中位、危险的是气道而非声音。感觉：声带以上**喉内（内支）**（咳嗽反射的传入），声带以下**喉返**。淋巴：声带以上至**颈二腹肌/颈深**链，以下至**气管旁**——喉癌分期的边界。**环甲膜**——皮下、中线、仅被细小的环甲吻合支横过——是外科气道，因为其中无重要结构，而两块软骨使它隔着血与肥胖也能摸到。
:::

::: example 甲状腺术后的两种声嘶 {#ex-thyroid-nerves}
全甲状腺切除后，A患者发不出高音、打电话久了声音发累；B患者声嘶而带气声。第三位在完成性甲状腺切除后一激动即喘鸣。
::: solution
A：**喉上神经外支**麻痹——环甲肌瘫痪、声带不能拉紧，失去的是音高与投射而非发声本身（该神经随甲状腺上动脉走行；损伤发生在靠近起点结扎该血管时）。B：**喉返神经**麻痹——声带瘫痪致气息样弱声（神经位于气管食管沟，与甲状腺下动脉及Berry韧带相邻，多数损伤在此；外科医生在下颈部辨认它并跟踪至韧带）。C：**双侧喉返损伤**——声带居正中、气道狭窄，第一次危机是活动或情绪时的喘鸣：急症。这也是完成性切除或一侧术后初现声嘶时须与外科医生讨论双侧麻痹的原因（标准做法是中止、分期）。甲状腺术前的谈话按功能点出两根神经：“高音区改变，和声音嘶哑”就是解剖学的知情同意句；病历上“双侧喉返神经已辨认并保留”也因此而写。
:::
:::

**甲状腺**自甲状舌骨向下包裹气管至第五气管环，**峡部**跨过2–4环；其**甲状腺上动脉**（颈外动脉第一分支）、**甲状腺下动脉**（甲状颈干——外科医生的后方危险），以及**最下甲状腺动脉**（数个百分点，起自头臂干/主动脉弓——气管前的出血源）。静脉回流——甲状腺上、中、下静脉——使下静脉成为到头臂静脉的短而宽的通道，胸骨后甲状腺肿拖出时其撕裂是该手术具名的危险，正如**头臂动脉与胸膜顶**是胸骨后延伸粘连到的地方。甲状旁腺位于腺叶后方囊与鞘之间的界面；寻找与保留它们遵循[[anatomy/embryology]]的下降路线。

## 唾液腺与面部

::: definition 腮腺与下颌下区 {#def-salivary}
**腮腺**填满下颌后窝，自深至浅被**颈外动脉**、**下颌后静脉**与**面神经丛**贯穿，面神经五终支（颞、颧、颊、下颌缘、颈）在其上扇开；**耳颞神经（V3）**携带其分泌神经纤维（耳神经节，舌咽来源），是Frey综合征的神经。**Stensen导管**横咬肌、在**上第二磨牙**对面穿颊肌——颊与导管损伤后检查唾液的视点。**下颌下腺**绕下颌舌骨肌后缘进口底；**Wharton导管**沿口底肌表面前行，**舌神经自外内侧从其下方绕过**（在乳头处清理导管结石的外科医生必须记住这个袢），开口于舌系带旁的**舌下乳头**。**舌下腺**是舌黏膜下小而纯黏液的腺体，多条小导管口于口底——舌下腺囊肿（ranula）的来源（黏液外渗囊肿把口底吹起，治疗是摘腺体而非揭囊肿顶）。
:::

::: example 腺门的结石 {#ex-duct}
一名55岁女性“每次进食”下颌下疼痛性肿胀；餐后一小时内消肿。
::: solution
这是**唾液绞痛**——导管梗阻使腺体对着送不出去的唾液肿胀——而九成发生在**下颌下腺**：其导管长、逆重力、把碱性、黏稠、富钙的唾液送进乳头处的低位弯道；故多数结石**双手触诊可及**、X线可见（80%钙化足够）。处理即应用解剖：小远端结石用水化与按摩，可触及的导管结石行口内取出（记住舌神经在导管下方的袢），近端活动结石用**唾液内镜**。绝不能漏的鉴别是**腺门肿瘤**——硬、不绞痛、持续的肿块——须影像与腮腺式手术规划，因为面神经下颌缘支与舌神经、舌下神经就在腺体深面，且它共享颈清扫的地盘。预防之句写给复发病人：水化；而使唾液变稠的抗胆碱药是这病的帮凶。
:::
:::

面神经的**颞骨内**行程带着自己的定位地理——岩大神经（泪液）、镫骨肌神经（听觉过敏）与鼓索（舌前2/3味觉、下颌下与舌下分泌）依次发出，缺损的模式即说出病变在颞骨何处；Bell麻痹的内科学在[[nervous-system/sensory-systems]]。**三叉神经**三支——眼支（V1）经眶上裂至额、角膜与眼；上颌支（V2）经圆孔，其眶下神经出面“犬齿窝”，及上牙槽后支/翼腭神经节的腭与上牙领地；下颌支（V3）经卵圆孔，咀嚼肌、耳颞神经、下牙槽神经及其颏孔处的颏支（牙科麻醉标志，下唇麻木永远该拍第三磨牙与下颌体X线）——是口、面与前头皮的感觉地图；其运动支的肌肉即咬肌反射与张口的下颌**偏向瘫痪侧**（翼肌无力、对侧推力无对抗）一章。

## 头皮、面部与海绵窦

::: definition 头皮与面部的危险 {#def-scalp}
**头皮**五层——**皮肤、致密皮下组织（血管走在脂肪小室里，故头皮出血裂开而不自塞、动脉回缩而又再出血）、帽状腱膜（枕额肌的腱——把创缘拉开、必须修补的一层）、疏松腱膜下组织（“帽状腱膜下隙”——危险层：导血管所在，也是头皮撕脱的界面，婴儿此处出血可大到失血性休克）与骨膜**（随颅瓣一起剥离的一层）。**面部**经**面静脉入眼静脉与海绵窦**的无瓣膜通路回流——“面部危险三角”句话的全文：口至眼连线以上挤一颗痘可把脓毒性血栓性静脉炎向内播种（更常见的是鼻窦与牙根）。淋巴地图：额与前颞至**腮腺前/腮腺**结，下睑、鼻与内颊至**下颌下**，唇与颏至**颏下**，耳区至**耳前/耳后与颈深上**——故头皮病灶分期要摸颈，故硬的颈淋巴结要派人去看头皮。
:::

::: definition 海绵窦与眶尖 {#def-cavernous}
**海绵窦**是蝶鞍两侧的成对硬膜通道，接受**眼静脉**、大脑中（Sylvian）静脉与垂体静脉血，经**岩窦**引流至**乙状窦与颈内静脉**。其外侧壁自上而下走**III、IV、V1、V2**；其血窦内走**颈内动脉，VI在其下外方**——颈动脉海绵窦瘘或窦内动脉瘤**最先失去VI**的原因。其临床面孔：**脓毒性血栓**（来自面、鼻、鼻窦——球结膜水肿、眼球突出、同侧然后双侧眼肌麻痹伴发热；影像、抗凝与数周抗生素的急症）；**颈动脉海绵窦瘘**（搏动性突眼、杂音、动脉化的结膜血管）；以及**眶上裂对眶尖综合征**——眶上裂病变豁免II，眶尖病变拿走视神经——分开两者的那句话。
:::

::: example 感冒后的淤血眼 {#ex-cavernous}
一名少女患额窦炎第三天，右眼肿胀闭合、视物双影、体温39.2°C，左眼也开始发红。
::: solution
在影像证明之前这就是**海绵窦血栓**，而第二只眼的受累是其签名——两窦经翼静脉环状窦交通，故单侧眶淤血在数小时至数天内变成双侧颅神经麻痹。传入路径正是解剖警告的那条无瓣之路：额/筛窦→眼静脉→眼上静脉（故小儿筛窦炎所致眶蜂窝织炎是当天收住院、当天耳鼻喉/眼科决定引流的事）。检查是增强CT或MR静脉造影（眼上静脉血栓、窦充盈缺损）、血培养、寻找原发灶（鼻窦、面、牙）；治疗是立即广谱抗菌（金葡、链球菌、鼻窦厌氧菌）、无颅内出血时抗凝（观察性证据，多数中心在颅神经进行性受损时使用），以及原发灶引流。死亡率今为20–30%；治愈后遗留的颅神经与视物损害才是这病的真实代价。
:::
:::

## 眶

::: definition 眶及其肌肉 {#def-orbit}
**眶腔**——四壁金字塔，尖在视神经管与眶上裂——内容眼球、六条眼外肌、上睑提肌、泪腺、脂肪与神经。四条**直肌**起自尖部总腱环（外直肌**VI**，其余**III**），例外是**上斜肌——IV**——在滑车处拐弯，内旋并下视已内收的眼（在内收位检查的那条肌；其颅内行程之长使它成为头颅外伤的牺牲品）；**下斜肌**（III）自眶底升起。规则：**外直肌归VI、上斜肌归IV、其余皆归III**——头位随麻痹而定：IV使头歪向病变对侧（失去的内旋），III给出“下外斜”伴上睑下垂与散大瞳孔（副交感纤维走在神经表面——见下述瞳孔规则），VI使脸转向斜视侧，因为眼不能外展。
:::

::: quiz
一位患者右侧角膜反射的感觉消失、张口时下颌偏向右侧、右上唇麻木——没有听力丧失，也没有面肌无力。病灶在：
- [ ] 海绵窦
- [x] 右侧的三叉（半月）神经节与神经——含运动根，而不累及面神经
- [ ] 内听道内的右侧面神经
- [ ] 右侧眶下裂
::: solution
**所见都是三叉的：角膜的感觉是V1，下颌偏向无力的一侧（V3运动根到翼肌），上唇是V2（眶下）——所以是三叉的主干或神经节的病灶。海绵窦（侧壁有III、IV、V1、V2）会保留V3的运动与下颌神经（它在海绵窦之前经卵圆孔出颅）；面神经不支配面部感觉，其病灶以运动为主，而那里的角膜反射消失是运动臂（不眨而感觉存在）——同一个反射在两条神经上的临床区别正是考官的最爱。眶下裂走的是V2的终支，不是V3。**
:::

::: history
颈部的外科是一座为开刀而绘制地图的解剖学家之林：Astley Cooper的腺体专著（1830年代）、Theodor Kocher在伯尔尼的甲状腺切除——其系列死亡率降到1%以下，他归功于他教外科医生寻找的结扎线、包膜与神经（1909年诺贝尔奖）——以及Crile的根治性颈清扫（1906年）：把淋巴结、颈内静脉、胸锁乳突肌与副神经整块切除，直到后一世纪的“改良”与选择性清扫把死亡率不再要求的结构还给病人。喉科的神经解剖归功于十九世纪临床医生的叉舌实验并在手术中得到证实；环甲膜切开在军队与麻醉学说中的地位由几个世纪“切不开脖子就失去病人”的病例固定，而该路径无血管的描述就是其证据。海绵窦与危险三角的感染学说是青霉素时代临床病理文献在1930–50年代解剖台上写成的——抗生素之前，该综合征是近乎普遍的死亡，而它留下的解剖正是面部的三角至今作为外科地理教授的原因。
:::

## 通向何处

颅神经核及其中枢病变见[[anatomy/neuroanatomy]]；Bell麻痹与三叉神经痛的内科学见[[nervous-system/sensory-systems]]与[[nervous-system/headache-pain]]；甲状腺手术及其并发症处理见[[surgery/breast-endocrine-surgery]]与[[endocrine/thyroid]]；气道梗阻的内科学见[[emergency-critical-care/airway-ventilation]]；颈部脓毒的牙源性来源见[[infectious-diseases/fever-sepsis]]；耳的解剖见[[nervous-system/sensory-systems]]。

::: summary
- 颈是三角与鞘：后三角的神经（XI）、颈动脉鞘的内容、颈根的四个结构，与把脓运到纵隔的筋膜间隙。
- 咽与腭服从颅神经规则（皆X除茎咽IX；皆X除张腭V3），喉服从两根神经：喉上外支拉紧、喉返运动——而后环杓肌独占外展。
- 甲状腺手术是神经与血管的地理：喉返在沟里与Berry韧带、喉上外支在上极、胸骨后甲状腺肿路径上的甲状腺下静脉与头臂动脉。
- 唾液腺的临床解剖是导管的物理（下颌下结石）与神经的邻近（腮腺内的面神经支、Wharton下方的舌神经袢）。
- 头皮的第五层与面部的无瓣静脉是出血与感染的教训；海绵窦是青春痘与鼻窦炎会产生颅神经后果的原因。
- 眶是三根神经与一条规则（外直肌VI、上斜肌IV、其余III），加上“累及瞳孔的动眼神经麻痹=动脉瘤直到证明否则”。
:::

## 练习

::: exercise 追踪牵涉的耳 {level=1}
列出耳外疾病引起耳痛的四条神经通路，各给一个病变。
::: solution
**V3（耳颞神经）**——颞下颌关节与牙病、耳廓前方；**IX（鼓室支，Jacobson神经）**——舌根、扁桃体、咽（扁桃体炎与下咽肿瘤）；**X（耳支，Arnold神经）**——喉、下咽、食管，以及经迷走的肺尖（耳检正常的吸烟者耳痛是全喉镜检查的指征）；**C2–3（枕小神经与耳大神经）**——上颈椎与后颅窝硬膜。共同点是耳与整条上呼吸消化道的感觉供应共享，而耳镜检查正常、耳痛持续者，在纤维喉镜与影像说否则之前就是头颈癌——成人单侧浆液性积液伴耳道正常，是同一规则的耳科表达（鼻咽肿块堵塞咽鼓管）。
:::

::: exercise 颏孔 {level=1}
牙医的下牙槽神经阻滞未能麻醉下唇；第二位患者在第三磨牙拔除后三周下唇麻木。各是什么解剖，第二位患者需要什么？
::: solution
阻滞的靶是**下牙槽神经**在下颌孔软组织内、入管之前；失败通常是位置（针尖在孔前方，或把下颌小舌误认）或副支配（下颌舌骨神经交叉，阻滞良好但颏部皮肤幸免）。拔牙后麻木是**下牙槽或舌神经损伤**——牙根与下颌管相邻（下第三磨牙牙根在全景片上常钩住下颌管；横过牙根的“黑线”是警告）——患者需要**记录（画出麻木区、两点辨别）、部位影像、6–8周无恢复即转微血管神经组**，以及诚实的陈述：晚期发现的完全Waller变性病变，预后差于同一神经的早期探查。无牙科原因的“麻木颏”是另一句话：下颌骨或颅底病变所致颏/下牙槽神经病变直到证明否则——牙科的红旗，医学书上则是下颌骨或颅底恶性肿瘤的“麻木颏综合征”。
:::
:::

::: exercise 定位Horner {level=1}
发现Horner综合征。给出两个床旁试验与三个节段定位，各配一个病变。
::: solution
床旁试验：**可卡因或羟苯丙胺滴眼**（节后第三级神经元储备不能释放去甲肾上腺素——第一/二级对第三级的药理学定位），以及**苯福林/溴莫尼定**变体；加上病史中的节段性问诊。三节段：**一级（下丘脑至C8-T2）**——脑干卒中、脱髓鞘；**二级（C8-T2经交感干与肺尖）**——Pancoast瘤（与下干症状和Horner同现：见[[anatomy/thorax]]）、颈肋、颈部手术、颈动脉鞘；**三级（沿颈内动脉至眼）**——**颈内动脉夹层**（颈外伤后或自发的疼痛性Horner，伴头痛或脑缺血——三联征中的急诊）、海绵窦病变（伴VI）。无汗的分布区分它们：颈动脉分叉以上的二级病变失去面部出汗（交感缩汗纤维随颈外动脉走行），而节后病变出汗正常（汗腺纤维在下方加入颈动脉丛）。
:::

::: exercise 急症气道 {level=2}
一名外伤患者既不能插管也不能给氧（“不能插管、不能氧合”）；团队拿起手术刀指向环甲膜。从解剖上论证该部位，然后列出该操作比示意图困难的三个原因，以及预防并发症的后续处理。
::: solution
部位：**环甲膜皮下、中线、可在两软骨之间辨认、相对无血管**（小的环甲出动静脉吻合横过其上1/3——切口取水平中线、上缘小心的原因），其开口进入的气道在声门上梗阻风险之下、在隆突无用之上。三个现实困难：**肥胖、水肿或儿童的颈**，标志摸不到（有时间就用超声，并知道膜比瘦成人更低更深）；**喉骨折或肿瘤气道的变形甲状舌骨解剖**（环状软骨不在气管在的地方）；以及**已在创伤性凝血病的患者术野中甲状腺或静脉丛的出血**。垂直中线皮肤切口配水平膜切口、保留探条或引导器、放气后固定导管是技术答案。后续就是并发症：高位气管切开或套囊压力所致**声门下/气管狭窄**，这就是计划确定性气道转换（经2–4环的正式气管切开，或放囊后拔管评估）的原因，也是手术记录写下囊压与置管时间的理由。
:::

::: exercise 腺与神经 {level=2}
计划为多形性腺瘤行腮腺浅叶切除。说出面神经主干出茎乳突孔时夹在其间的结构、解剖的标记规则，以及该手术两个特有的并发症。
::: solution
主干出茎乳突孔时位于**二腹肌后腹上方**，在**下颌后静脉与颈外动脉之间**入腺（分支在静脉外侧）；操作规则是在其恒定处找主干——耳屏指针、鼓乳突缝、二腹肌缘——再从主干追踪分支。两个特有并发症：**面瘫**——大部临时、源于牵拉，分支切断则永久（眼需贴胶与润滑；可移植的断神经即刻修复），而下颌缘支——个别患者在下颌角下方绕弯、低于下颌两横指的切口可避开——是一侧口角下垂的原因；以及**Frey（味觉性出汗）综合征**——耳颞神经副交感纤维异常再生到皮肤汗腺，进食时面颊潮红出汗，通过在瘤床插入屏障（SMAS瓣）预防/治疗。第三线问题是**复发**瘤更高的面神经风险：第一次不彻底切除时囊膜破裂，就是多形性腺瘤不能剜出的原因。
:::

::: exercise 颈部肿块 {level=2}
为下列各给出鉴别诊断及其解剖线索：(a)婴儿颈后三角软、透光肿块；(b)60岁左锁骨上窝硬、无痛、固定淋巴结；(c)下颌角肿块随进食增大；(d)中线肿块伸舌时上升。
::: solution
(a)**囊状水瘤（淋巴管畸形）**——透光是线索（充盈淋巴液）、后三角是常见部位，气道与纵隔延伸是危险、MRI是其地图。(b)**Virchow淋巴结（Troisier征）**——左锁骨上淋巴结意味着胸导管的地盘：腹部（胃、胰、肾）恶性肿瘤直到证明否则，而穿刺规划要当作原发灶将由CT去寻找。(c)**唾液结石或腺体肿胀**——进食时增大是梗阻性绞痛（Wharton与下颌下腺的十分之九），腺体本身可慢性感染而无分泌。(d)**甲状舌管囊肿**——管道的胚胎学（[[anatomy/embryology]]）使伸舌上升成为诊断体征，而Sistrunk手术（管道加舌骨中段加至盲孔的组织袖）是预防单纯切除必然复发的术式。

::: exercise 颈动脉手术野 {level=2}
颈动脉内膜剥脱中，标准切口与暴露有哪些具名神经危险，各司何损伤后留下什么？
::: solution
标准高颈暴露横过或牵开**VII下颌缘支**（口唇不对称——切口须按两指规则与下颌角保持距离、拉钩不得向上抻它）、**舌下神经**（舌偏向患侧、构音与吞咽困难；它在术野顶部勾绕舌动脉与面动脉）、鞘内后方的**迷走**及其上游的**喉返**（声嘶；在颈内动脉远端解剖中是恒久的危险）、**喉上**（声音易累与音高——外支随甲状腺上/舌干走行）、**副神经**（高位解剖）与**交感干**（Horner——在头长肌上后内方）；外加**颈袢**（无害），以及作为出血结构的**面动脉、舌动脉与下颌后静脉**。每个具名结构都在鞘壁上或术野顶上——这就是知情同意按功能点神经、而阻断时灌注与窦神经浸润属于麻醉医生那半个同一解剖的原因。

::: exercise 瞳孔规则 {level=2}
用血管与纤维解剖解释动眼神经麻痹的“累及瞳孔”规则及其例外。
::: solution
**副交感缩瞳纤维走在动眼神经的表面**（表浅、束的周边、随软膜血管），而眼外肌的躯体纤维在中央。**外在压迫性病变**（后交通动脉瘤、钩回）先取表面纤维→**散大固定瞳孔伴上睑下垂与“下外斜”眼**；**内科/缺血性病变**（糖尿病神经滋养血管的微血管病）打击核心而通常**豁免瞳孔**，因为软膜供血的表面纤维幸存。故规则：疼痛性、累及瞳孔的动眼神经麻痹是血管造影的问题（必须紧急排除动脉瘤——蛛网膜下腔出血的动眼神经麻痹自带死亡率）。瞳孔救不了的例外：**部分或早期压迫性病变可不完全豁免瞳孔**，约10–20%压迫性麻痹以瞳孔豁免起病——所以规则是紧急程度的阈值而非出院证明，而“糖尿病性动眼神经麻痹”仍是需要随访、血压与血糖关注的诊断。
:::

::: exercise 规划引流 {level=3}
一名45岁未治疗的牙源性脓毒患者左下颌下区肿、热、波动，牙关紧闭、吞咽困难与发热；CT见左下颌下间隙积液沿咽侧壁延伸至纵隔上界。规划手术入路并说出决定它的结构。
::: solution
诊断是**下行性深间隙感染伴早期下行性坏死性纵隔炎**——[[anatomy/head-neck]]筋膜一段的咽旁→“危险”间隙/内脏间隔路径——方案是气道、引流与纵隔控制同时。**气道**：牙关紧闭不许口内入路时清醒纤支镜插管或局麻气管切开（牙关紧闭是翼肌炎症，口底变形时的假道风险是Ludwig的教训）。**颈部引流**：沿下颌下缘切口（其下两横指，下颌缘支规则），切开颈阔肌、掀起肌瓣，辨认保护**面动静脉、舌下神经、舌神经与下颌下导管**，进入下颌下间隙并沿**茎舌肌/下颌舌骨肌界面**向内追踪积脓至咽旁间隙，经第二个**颈（颈切开）入路沿颈动脉鞘**经胸廓入口到达纵隔延伸。**纵隔控制**：决定依CT并外科化——积液在隆突以上，经颈广泛引流加清创或可奏效；隆突以下（经典“过气管分叉就开胸”规则）须**开胸或VATS清创**请胸外科。全部病例：广谱抗菌、ICU、该病要求的24–48小时二次清创，患者稳定后清除牙源。决定一切的解剖之句：脓在哪个间隙、是否已过胸廓入口、气道是否还在肿胀之上。
:::
