在气道与血管之间坐着间质，而它也有一棵自己的血管树。本章把两个临床病理的世界连接：**间质的肺病（肺泡壁与间质的炎症与纤维化——限制的通气、低的弥散能力与运动时的去饱和这三联的生理），以及肺的循环（肺栓塞与肺高压）[[respiratory/gas-exchange]]、[[respiratory/mechanics-breathing]]。**

本章涵盖纤维化与炎症的间质肺病、结节病与尘肺，以及肺栓塞与肺高压。

## 间质

::: definition 纤维化的级联与特发的肺纤维化 {#def-ipf}
**在易感的个体中，上皮的反复损伤与成纤维细胞的激活会造成肌成纤维细胞灶与细胞的基质的沉积；瘢痕一旦建立就不会退回。它的临床的对应就是普通型间质肺炎：网格与蜂窝与牵拉的扩张，主要在胸膜下与基部[[pathology/chronic-inflammation-repair]]、[[clinical-skills/medical-imaging]]。生理：一个限制图形，伴低的弥散能力与运动时的去饱和；症状是干咳与进行性的呼吸困难和Velcro样的爆裂音[[respiratory/control-breathing-tests]]、[[respiratory/gas-exchange]]。管理：把原因与共病移除（药物与暴露与反流和胃食管），以及抗纤维化（吡非尼酮与尼达尼布会减慢用力肺活量的下降）；在选中的中的移植[[immunology/transplant-tumour-immunology]]；以及姑息的支持与肺的康复[[geriatrics-palliative/palliative-care]]、[[public-health/prevention-promotion]]。急性的加重是一个急诊，需要排除感染与栓塞[[respiratory/respiratory-failure]]、[[#def-pe]]。**
:::

::: definition 间质肺病的鉴别：暴露、药物、系统疾病、肉芽肿与囊肿 {#def-ild-list}
**按线索整理这张清单。职业与环境的暴露造成尘肺：硅与石棉及煤（石棉还与间皮瘤相关），以及农民肺与饲鸟肺这类过敏性肺泡炎，其纤维化期可酷似纤维化性肺病[[public-health/environmental-occupational]]、[[immunology/hypersensitivity]]。药物与治疗：胺碘酮与硝呋太尔类、甲氨蝶呤、抗肿瘤药以及放疗的边界[[pharmacology/adverse-reactions]]、[[pathology/cancer-biology]]。系统性自身免疫病，特别是硬皮病与类风湿及混合性结缔组织病，会带来自己的间质模式[[musculoskeletal/connective-tissue-vasculitis]]、[[immunology/autoimmunity]]。肉芽肿性的疾病包括结节病与肉芽肿性多血管炎[[immunology/hypersensitivity]]、[[musculoskeletal/connective-tissue-vasculitis]]。囊肿性包括肺的朗格汉斯细胞组织细胞增生症与淋巴管肌瘤病[[blood/lymphoma-myeloma]]、[[obstetrics-gynaecology/menopause]]。还有与纤维化并存的炎症表型以及吸烟相关的[[respiratory/asthma-copd]]。**
:::

::: example 被误诊为慢阻肺的患者 {#ex-ipf}
一位68岁被当作慢阻肺并用吸入剂治疗三年的人，仍呼吸困难且咳嗽；体检两下肺有爆裂音而无哮鸣；肺功能比率0.78、用力肺活量为预测值的62%、弥散能力为45%。
::: solution
**这是一部限制的病史，不是阻塞：比率正常而肺活量与弥散能力都下降，加上基部的爆裂音，就该怀疑间质肺病[[respiratory/control-breathing-tests]]、[[#def-ipf]]。下一步是高分辨率CT与暴露及用药史和自身免疫的血清学；若图形符合普通型间质肺炎则无需活检[[clinical-skills/medical-imaging]]、[[immunology/autoimmunity]]。常见的错误包括：把纤维化误标为哮喘或慢阻肺、继续无效吸入剂、以及延误抗纤维化与移植评估[[respiratory/asthma-copd]]、[[immunology/transplant-tumour-immunology]]。同时处理共病：胃食管反流与肺动脉高压和肺癌风险，并把戒烟与疫苗及康复列入[[gastrointestinal/oesophagus-stomach]]、[[public-health/vaccination-programmes]]、[[public-health/prevention-promotion]]。**
:::
:::

## 肺的循环

::: definition 肺栓塞：把死腔变成临床 {#def-pe}
**血栓来自深静脉（腿与骨盆，少见于手臂），堵塞肺动脉，形成被通气而无灌注的肺泡：死腔增加、二氧化碳的梯度扩大，而低氧来自这些不匹配与分流及心输出量下降。经典的三联（胸痛的呼吸困难与咯血）少见，而最常见的就是不明的原因的心动过速与呼吸急促和晕厥前兆[[respiratory/gas-exchange]]、[[cardiovascular/arrhythmias]]。风险：手术与制动与恶性肿瘤和妊娠及雌激素与既往的血栓[[surgery/perioperative-care]]、[[obstetrics-gynaecology/pregnancy-complications]]、[[blood/thrombosis-anticoagulation]]、[[obstetrics-gynaecology/contraception-fertility]]。诊断：预测的评分（分级的概率），然后D-二聚体或影像；CT肺动脉造影是主力，而V/Q在年轻的女性与肾的和造影剂的问题中占优势[[clinical-skills/medical-imaging]]。危险分层（血压与右心的标志及肌钙蛋白）决定治疗[[cardiovascular/heart-failure]]。**
:::

::: definition 肺高压：五组 {#def-ph}
**右心的后负荷升高来自三种机制：血管被堵塞、血管壁重塑、或血容量与压力被动升高。超声估测三尖瓣反流的压差与右心的大小及室间隔的形态是筛查；右心的导管测量是确诊[[cardiovascular/valve-congenital-disease]]、[[clinical-skills/medical-imaging]]。分组：左心疾病（最常见）；肺病与缺氧（把低氧的血管收缩推向重塑）[[cardiovascular/heart-failure]]、[[respiratory/asthma-copd]]；慢性血栓栓塞（可手术）[[#ex-cteph]]；发育与遗传的动脉病及药物与结缔组织病[[genetics/mendelian-inheritance]]、[[musculoskeletal/connective-tissue-vasculitis]]；以及机制未明的。治疗：针对病因（左心与肺与缺氧），在动脉性高压中专用的血管扩张药（内皮通路的三类）与在这些可切除的中的手术或球囊的肺动脉成形[[immunology/transplant-tumour-immunology]]、[[cardiovascular/valve-congenital-disease]]。**
:::

::: example 飞行之后的呼吸困难 {#ex-pe}
一位41岁在长途飞行后两天出现胸膜性胸痛与呼吸急促；心率104，饱和94%，腿痛；D-二聚体显著升高。
::: solution
**一个中低危肺栓塞的图形：先做影像确认（CT肺动脉造影），并同时评估危险分层；在等待时给治疗剂量的抗凝（除非禁忌）[[clinical-skills/medical-imaging]]、[[blood/thrombosis-anticoagulation]]。治疗：直接的口服抗凝药为主，或在特殊情形（癌与妊娠与抗磷脂的）中选择其他[[obstetrics-gynaecology/pregnancy-complications]]、[[blood/thrombosis-anticoagulation]]；住院的标准是低血压与右心的衰竭与严重的低氧[[emergency-critical-care/shock-fluids]]。随访：疗程按触发（短暂的与长期的）与复发及癌症的筛查的谨慎[[pathology/cancer-diagnosis]]。预防：制动的措施与旅行的建议与雌激素的风险[[obstetrics-gynaecology/contraception-fertility]]、[[surgery/perioperative-care]]。**
:::

::: example 心脏的传导与肺门的阴影 {#ex-sarcoid}
一位32岁的非裔女性有踝的肿痛与结节性红斑及双侧肺门的淋巴结增大；接下来出现晕厥前兆与心动过缓。
::: solution
**这是急性结节病（关节与皮肤与淋巴结的经典组合）合并心脏受累——一个急诊[[immunology/hypersensitivity]]、[[musculoskeletal/inflammatory-arthritis]]、[[cardiovascular/arrhythmias]]。诊断：活检显示非坏死的肉芽肿，并排除分枝杆菌与真菌及淋巴瘤[[pathology/diagnostic-pathology]]、[[infectious-diseases/tuberculosis]]、[[blood/lymphoma-myeloma]]；血钙与血管紧张素转换酶与眼及心脏的检查（心电图与监护与心脏的磁共振）[[renal/potassium-calcium-phosphate]]、[[nervous-system/sensory-systems]]。心脏或神经或眼的严重受累要用大剂量激素和其他免疫抑制[[endocrine/adrenal]]、[[immunology/tolerance-regulation]]；高度房室阻滞需要起搏的评估[[cardiovascular/arrhythmias]]。急性的形式常常自行缓解，而慢性的会纤维化[[#def-ild-list]]。**
:::
:::

::: example 没有溶解的血凝块 {#ex-cteph}
一位58岁在规范抗凝六个月后仍呼吸困难；超声显示右心扩大与高的三尖瓣压差；核素的通气灌注扫描显示出固定的灌注缺损。
::: solution
**慢性血栓栓塞性肺高压，直到被证明别的：抗凝之后栓子没有吸收，而是被机化的组织替代，造成血管的狭窄与阻力升高[[#def-ph]]、[[blood/thrombosis-anticoagulation]]。评估需要右心导管与专门的影像（CT与灌注的分布）以及在有经验中心的手术可行性判断[[clinical-skills/medical-imaging]]、[[cardiovascular/valve-congenital-disease]]。治疗：终身的抗凝与专门的评估——外科的肺动脉血栓内膜剥脱以及在这些不可手术中的球囊的肺动脉成形与药物[[surgery/perioperative-care]]、[[immunology/transplant-tumour-immunology]]。识别的意义在于这是可治的：把它当作不可逆的动脉性高压会夺走一个这些可能治愈的机会[[respiratory/respiratory-failure]]。**
:::
:::

::: quiz
一位在妊娠晚期的疑似肺栓塞患者在下肢超声阴性之后，常常优先选择通气灌注扫描而不是CT肺动脉造影，因为：
- [ ] 对中央的鞍状栓子更敏感
- [x] 在胸片正常时它能保持好的鉴别力，而母亲的乳腺剂量更低
- [ ] 它完全避免胎儿辐射而CT做不到
- [ ] 它还能评估右心的扩大
::: solution
**两种扫描对胎儿的剂量都很低；差异在母体的乳腺：在胸片正常时通气灌注的判读可靠，因此常作为首选[[obstetrics-gynaecology/pregnancy-complications]]、[[clinical-skills/medical-imaging]]、[[respiratory/gas-exchange]]。右心的评估要靠超声[[cardiovascular/valve-congenital-disease]]。**
:::

::: history
间质与血管的呼吸病学来自门诊的合并：X线把肺门的淋巴结与弥漫的影子带入诊断，于是结节病与尘肺在矿工与城市中被描述[[public-health/environmental-occupational]]、[[clinical-skills/medical-imaging]]；肺的循环从尸检的血栓与右心的导管被认识，而后是通气灌注扫描与CT血管造影把诊断变成日常的影像[[cardiovascular/valve-congenital-disease]]；抗凝从战时的毒鼠药衍生而来，而后是低分子的肝素与直接的口服药[[blood/thrombosis-anticoagulation]]；肺高压从先天性的心脏的分流被理解，再到动脉病的靶向药物[[cardiovascular/valve-congenital-disease]]、[[immunology/transplant-tumour-immunology]]；而抗纤维化药物把一个无法治疗的病变成了一个可以减慢的病[[pharmacology/drug-development-prescribing]]。
:::

## 通向何处

生理的三联与弥散及运动气体在[[respiratory/gas-exchange]]与[[respiratory/control-breathing-tests]]；限制与流量在[[respiratory/mechanics-breathing]]；免疫的机制在[[immunology/hypersensitivity]]与[[immunology/autoimmunity]]；急性的低氧与支持在[[respiratory/respiratory-failure]]；恶性的与胸膜的在[[respiratory/lung-cancer-pleura]]；抗凝在[[blood/thrombosis-anticoagulation]]；以及职业与环境的控制在[[public-health/environmental-occupational]]。

::: summary
- 间质肺病是肺泡壁的炎症与纤维化：生理上是限制、弥散能力下降与运动时去饱和；诊断靠高分辨CT的模式与暴露、药物和自身免疫的线索。
- 特发肺纤维化代表不可逆的瘢痕；抗纤维化治疗减慢用力肺活量的下降，而移植评估与姑息支持要早谈。
- 肺栓塞是把死腔变成临床：先用预测概率分层，再用D-二聚体或影像确认；右心与血压的危险分层决定是否再灌注。
- 肺高压按五组来想：左心与肺病缺氧最常见，慢性血栓型可以手术，而动脉型有靶向药。
- 结节病与尘肺说明同一件事：肉芽肿与暴露会在肺留下图形，读出图形需要病史、影像与活检，并排除感染与肿瘤。
:::

## 练习

::: exercise 读生理 {level=1}
比率0.88，用力肺活量62%，第一秒60%，弥散能力44%，体积描记的容积全面降低。是限制吗，而弥散能力能区分什么？
::: solution
比率高而肺活量与容积都低，这是典型的限制[[respiratory/control-breathing-tests]]、[[respiratory/mechanics-breathing]]。弥散能力是关键的岔路：它降低提示肺的实质或血管的病变（纤维化、肺高压、贫血）；若正常，要想胸壁、神经与肥胖，那里肺本身完好[[#def-ipf]]、[[#def-ph]]、[[blood/anaemia]]。再问：气体交换是否受累（静息与运动去饱和、肺泡-动脉梯度）会决定严重程度与治疗[[respiratory/gas-exchange]]。
:::
:::

::: exercise 把模式对到疾病 {level=1}
为每一个高分辨CT的模式给出两层的诊断：(a) 基部胸膜下蜂窝；(b) 上区淋巴道结节与双侧肺门淋巴结；(c) 马赛克衰减与中央小叶结节及上区纤维化；(d) 弥漫磨玻璃。
::: solution
(a) 普通型间质肺炎：特发或结缔组织病相关[[#def-ipf]]、[[musculoskeletal/connective-tissue-vasculitis]]；(b) 结节病，其次硅尘与淋巴管癌病和淋巴瘤[[#ex-sarcoid]]、[[pathology/cancer-diagnosis]]、[[blood/lymphoma-myeloma]]；(c) 过敏性肺泡炎（纤维化期）或气道疾病，需要暴露史[[#def-ild-list]]、[[public-health/environmental-occupational]]；(d) 肺泡出血或肺囊虫肺炎及药物与心源性的水肿[[respiratory/gas-exchange]]、[[infectious-diseases/immunocompromised-host]]、[[cardiovascular/heart-failure]]。模式加病史加血清学（必要时活检）才是诊断[[clinical-skills/medical-imaging]]、[[pathology/diagnostic-pathology]]。
:::
:::

::: exercise 钙的提问 {level=2}
一位结节病患者血钙3.1而肌酐140伴多尿。解释机制与处理，并命名另两个肉芽肿性的原因。
::: solution
肉芽肿内的巨噬细胞会把维生素D活化而不受反馈控制，于是肠的钙吸收与骨的吸收都增加，造成高钙与肾的损害及多尿（肾源性的机制与钙的沉积）[[renal/potassium-calcium-phosphate]]、[[endocrine/bone-calcium]]、[[renal/acute-kidney-injury]]。处理：停止钙与维生素D的补充，用盐水扩容与袢的利尿（在容量充足后），用激素抑制肉芽肿，并在严重时用双膦酸盐或降钙素[[endocrine/bone-calcium]]、[[renal/water-sodium]]。另两个原因：结核与其他分枝杆菌（包括非结核的）及真菌（组织胞浆菌）和滑肉芽肿的病[[infectious-diseases/tuberculosis]]、[[microbiology/fungi-parasites]]。
:::
:::

::: exercise 纤维化的养鸟人 {level=2}
一位58岁的虎皮鹦鹉饲养者有三年进行性的呼吸困难；高分辨CT显示上区为主的纤维化伴牵拉的支气管扩张、中央小叶结节，而在呼气序列上明显的马赛克衰减。为什么这个病例引人入胜？
::: solution
因为它同时具备纤维化性气道/血管的小病与空气 trapping 的征象，而这正是慢性过敏性肺泡炎的样子，而不是特发肺纤维化[[#def-ild-list]]、[[immunology/hypersensitivity]]、[[respiratory/mechanics-breathing]]。区别的意义：移除抗原可以延缓甚至改变病程，而把它当作特发纤维化会让暴露继续[[public-health/environmental-occupational]]、[[geriatrics-palliative/polypharmacy]]。做法：详细的暴露史（家养与爱好和工作）与 precipitins/特异抗体（辅助而非决定）、洗液的淋巴细胞（支持）与 多学科 讨论[[clinical-skills/medical-imaging]]、[[pathology/diagnostic-pathology]]。抗纤维化在进展的纤维化表型中仍可考虑[[#def-ipf]]。
:::
:::

::: exercise 评分并决定 {level=2}
用简化的Wells评分为下述计算：既往深静脉血栓、心率116、两周前手术，其他项均无。给出概率与下一步。
::: solution
1.5加1.5加1.5等于4.5分：属于非低概率（临床中/高度可能），因此不能只靠D-二聚体，应该直接CT肺动脉造影（或在胸片正常且考虑适合时通气灌注）[[#def-pe]]、[[clinical-skills/medical-imaging]]。同时要评估危险分层（血压与超声右心与肌钙蛋白）并在无禁忌时给抗凝[[cardiovascular/valve-congenital-disease]]、[[blood/thrombosis-anticoagulation]]。评分的价值在于把检查的阈值与资源的顺序排好[[emergency-critical-care/acute-assessment]]、[[clinical-skills/clinical-reasoning]]。
:::
:::

::: exercise 溶栓的阈值 {level=2}
一个大面积肺栓塞的患者在复苏室停搏，在用肾上腺素四分钟后恢复循环。给出溶栓的决定、方案、心肺复苏的注意与补救的选项。
::: solution
在停搏中若肺栓塞是最可能的原因，指南支持全身溶栓（组织型纤溶酶原激活剂的方案），并且可以在继续心肺复苏时给药；循环恢复后常需要肝素与重症的床位[[#def-pe]]、[[emergency-critical-care/resuscitation]]、[[blood/thrombosis-anticoagulation]]。注意：最近的手术与创伤和颅内的事件会提高出血的风险，而长的复苏要谨慎[[surgery/perioperative-care]]、[[nervous-system/stroke]]。补救与替代：导管取栓与外科取栓、体外膜肺氧合的桥接，以及在失败后的血栓内膜剥脱[[emergency-critical-care/critical-care]]、[[surgery/vascular-urological-surgery]]、[[#ex-cteph]]。
:::

::: exercise 血管扩张药的逻辑 {level=2}
一位弥漫皮肤型硬皮病的男性（与肺动脉高压相关的血清学）渐进呼吸困难；超声提示高度可能的肺高压。给出评估、反应性试验的逻辑，与三类药物轴的原理。
::: solution
评估要按顺序：先排除更常见的原因（左心疾病与肺病和慢性血栓），包括超声与肺功能与弥散能力及CT和通气灌注，然后右心导管确诊并测压力与心输出量[[#def-ph]]、[[musculoskeletal/connective-tissue-vasculitis]]、[[clinical-skills/medical-imaging]]。反应性试验只在少数特发的病例中做（钙通道阻滞剂只在阳性者中有益）；结缔组织病的肺动脉高压几乎总是阴性，所以不必冒险[[cardiovascular/valve-congenital-disease]]。药物按三条轴（一氧化氮与内皮素及前列环素）联合或序贯，同时管理贫血与心包和肾[[renal/potassium-calcium-phosphate]]、[[immunology/transplant-tumour-immunology]]。也要筛查吸收不良与心律失常和指端溃疡[[gastrointestinal/bowel-disease]]、[[cardiovascular/arrhythmias]]。
:::

::: exercise 设计间质与栓塞的服务 {level=3}
设计一个把间质肺病与肺血管疾病连接起来的区域服务：门诊、诊断、多学科架构、升级路径，以及公平与试验的议程。
::: solution
门诊：一个共同的呼吸生理通道（肺功能与弥散及运动气体）与专门的间质和肺血管门诊，配备护士与影像和病理的读片会[[respiratory/control-breathing-tests]]、[[pathology/diagnostic-pathology]]。诊断：一个标准的高分辨CT与通气灌注协议与自体血清学的一组，以及由有经验中心做的右心导管和活检[[clinical-skills/medical-imaging]]、[[cardiovascular/valve-congenital-disease]]。多学科：放射与病理与呼吸和风湿及外科一起决定，特别是当模式与暴露冲突时[[immunology/hypersensitivity]]。升级：一个急性的肺栓塞与高危标志的路径[[emergency-critical-care/shock-fluids]]、进展纤维化的移植与姑息的并行讨论[[immunology/transplant-tumour-immunology]]、[[geriatrics-palliative/end-of-life-care]]。公平与试验：暴露职业者的早期转诊与少数群体的延迟诊断[[public-health/determinants-inequalities]]、试验的登记与抗纤维化和肺高压的治疗的可及[[public-health/health-systems-economics]]、[[pharmacology/drug-development-prescribing]]。
