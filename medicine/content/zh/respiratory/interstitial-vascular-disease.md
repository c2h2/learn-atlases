由于哮喘和慢阻肺很常见，呼吸医学的注意力大多集中在气道上。本章讨论肺的另外两个组成部分：**间质**，即肺泡壁中薄薄的支持组织；以及**肺循环**。间质疾病使肺泡壁增厚并形成瘢痕，使肺变硬并阻碍气体转移。肺血管疾病阻塞或狭窄肺循环，造成通气浪费并加重右心室负荷。

这两类疾病有共同的生理特征：劳力性气短、气体转移下降、运动时加重的低氧血症，晚期出现肺动脉高压和右心衰竭。它们还有一个共同的诊断陷阱：早期病变时胸片和肺量计可能看起来正常。本章先讨论间质性肺疾病，包括特发性肺纤维化和结节病，然后是肺栓塞，最后是肺动脉高压。

## 间质性肺疾病 {#sec-ild}

::: definition 间质性肺疾病 {#def-ild}
**间质性肺疾病**（ILD，又称弥漫性实质性肺疾病）是一组200多种疾病，引起肺泡壁及其周围组织的炎症和/或纤维化。分组如下：

- **有已知病因或相关因素的ILD**：结缔组织病（系统性硬化症、类风湿关节炎、炎性肌病）、药物、职业和环境暴露（石棉、二氧化硅、过敏性肺炎中的有机抗原）以及放射。
- **肉芽肿性ILD**，主要是结节病。
- **特发性间质性肺炎**，其中**特发性肺纤维化**最常见、也最重要。
- **少见类型**，如淋巴管平滑肌瘤病和肺朗格汉斯细胞组织细胞增生症。
:::

其生理改变可由[[respiratory/mechanics-breathing]]和[[respiratory/gas-exchange]]推出。纤维化使肺变硬，因此肺容积下降（限制性模式，FEV₁/FVC比值正常或升高），呼吸变得浅快。肺泡壁增厚和毛细血管丧失使气体转移（TLCO）下降。静息时血氧饱和度可能正常，但活动时下降，因为毛细血管通过时间缩短。典型表现为干咳、进行性劳力性气短、肺底细小的"爆裂音"（velcro啰音），某些疾病还有杵状指。

**高分辨率CT**（HRCT）是关键检查，因为异常的模式和分布常常指向特定疾病。诊断由呼吸科医师、放射科医师和病理科医师组成的**多学科团队**作出，综合临床病史（暴露、药物、结缔组织病症状）、自身抗体、HRCT，必要时还有支气管肺泡灌洗或肺活检。

### 特发性肺纤维化

::: definition 特发性肺纤维化 {#def-ipf}
**特发性肺纤维化**（IPF）是一种病因不明的慢性进行性纤维化性肺疾病，主要发生于60岁以上的人，具有**普通型间质性肺炎**（UIP）的影像学和/或组织学模式。在HRCT上，UIP表现为**胸膜下和基底部为主**的网格影和**蜂窝影**（成簇的囊状气腔），伴牵拉性支气管扩张。诊断要求排除已知病因的ILD。
:::

一般认为IPF源于衰老的肺泡上皮反复受损后的异常修复：成纤维细胞和肌成纤维细胞沉积过多胶原，而不是恢复正常结构。危险因素包括高龄、男性、吸烟、某些职业粉尘和遗传变异（包括*MUC5B*启动子和端粒相关基因的变异）。男性更为常见。

病程呈进行性，但差异很大。未经治疗时，据报道从诊断起的中位生存期约为三到五年，比许多癌症还差。有些患者会发生**急性加重**，即突然恶化并出现新的双侧磨玻璃影，死亡率很高。

自2014年以来，治疗发生了很大变化。两种**抗纤维化药物**，**吡非尼酮**和**尼达尼布**（一种酪氨酸激酶抑制剂），在临床试验中各使用力肺活量的下降减缓约一半。两者都不能恢复已丧失的肺功能，也不能治愈疾病。NICE技术评估根据FVC占预计值的百分比，规定了哪些患者可在NHS中使用。2025年10月，美国食品药品监督管理局根据FIBRONEER-IPF试验批准了第三种药物**奈兰司特**（nerandomilast，一种优先抑制磷酸二酯酶4B的抑制剂）；它在其他地区的可及性取决于各国监管机构和评估。支持治疗同样重要：肺康复、低氧血症时氧疗、治疗咳嗽和反流、戒烟、接种疫苗、针对气短的姑息治疗，以及少数合适患者的肺移植。

::: warning 不要用免疫抑制治疗IPF
由于许多间质性疾病对糖皮质激素和免疫抑制剂有反应，过去曾以同样方法治疗IPF。PANTHER-IPF试验（2012年发表）提前终止了其三联治疗组（泼尼松龙、硫唑嘌呤和N-乙酰半胱氨酸），因为接受该治疗的患者死亡和住院比安慰剂组更多。IPF是纤维化性疾病，而非炎症性疾病。这就是准确的多学科诊断如此重要的原因：同样的HRCT表现可能是IPF、纤维化性过敏性肺炎或结缔组织病，而治疗截然不同。
:::

::: example 消不掉的爆裂音 {#ex-ipf}
一名72岁退休木工干咳、气短缓慢加重18个月。他有杵状指，双肺底可闻及细小的吸气末爆裂音。他没有关节、皮肤或肌肉症状，不规律服用任何药物，不养鸟，也没有明显的石棉暴露。肺量计：FEV₁ 2.2 L，FVC 2.6 L（预计值的68%），FEV₁/FVC 0.85；TLCO为预计值的45%。六分钟步行时血氧饱和度从95%降至86%。HRCT显示胸膜下、基底部为主的网格影伴蜂窝影和牵拉性支气管扩张。可能的诊断是什么？如何证实和处理？
::: solution
限制性肺量计（比值高、FVC降低）、TLCO显著降低和运动时血氧下降，提示纤维化性ILD。结合杵状指、肺底爆裂音、年龄和HRCT上明确的UIP模式，且无已知病因的证据，可能的诊断是**特发性肺纤维化**。诊断由ILD多学科团队作出；在典型UIP模式且无其他病因时，通常不需要肺活检。检查自身抗体以寻找未被识别的结缔组织病，并仔细复核他的暴露史。

处理：坦诚地讨论诊断和预后；考虑抗纤维化药物，因为他的FVC在NICE指南支持治疗的范围内；提供肺康复；鉴于他运动时血氧下降，评估便携式氧疗；接种疫苗；规划症状控制和预立医疗照护计划。72岁时不太可能适合肺移植，但需个体化评估。
:::
:::

### 进行性肺纤维化

IPF以外的许多ILD也可发展为进行性纤维化，包括纤维化性过敏性肺炎、结缔组织病相关ILD和无法分类的ILD。一项国际指南（ATS/ERS/JRS/ALAT，2022年）把IPF以外ILD患者的**进行性肺纤维化**定义为：在过去一年内、无其他解释的情况下，出现以下至少两项：症状加重；生理学进展（FVC绝对值下降达到或超过预计值的5%，或TLCO绝对值下降达到或超过预计值的10%）；影像学进展。尼达尼布在这一人群中同样能减缓FVC下降。

### 过敏性肺炎

**过敏性肺炎**是小气道和肺泡对吸入抗原（通常为有机物）的免疫反应：鸟类蛋白（来自鸽子、虎皮鹦鹉、羽绒被）、霉菌（存在于潮湿住所、干草、堆肥、热水浴缸中）和某些化学物质。它分为**非纤维化性**和**纤维化性**。非纤维化性疾病可在暴露后数小时反复出现发热、咳嗽和气短。纤维化性疾病起病隐匿，可与IPF相似。线索包括暴露史、HRCT上以中上肺区为主并伴马赛克征和气体陷闭，以及支气管肺泡灌洗液淋巴细胞增多。最重要的治疗是**找出并去除抗原**；部分患者使用糖皮质激素和其他免疫抑制剂。

### 结节病

::: definition 结节病 {#def-sarcoid}
**结节病**是一种病因不明的多系统疾病，特征是受累器官中出现**非干酪样肉芽肿**。最常累及肺和胸内淋巴结，但也可累及皮肤、眼、心脏、神经系统、肝、肾和骨。诊断需要相符的临床表现、非干酪样肉芽肿的证据（勒夫格伦综合征等典型表现除外），并排除其他肉芽肿病因，尤其是结核病和真菌感染。
:::

结节病典型地在20至50岁之间发病。在非洲–加勒比裔人群中更常见，病情往往也更重；在北欧人中也常见。许多人是在胸片上偶然发现**双侧肺门淋巴结肿大**的。胸片表现按Scadding分期描述：0期正常；Ⅰ期仅肺门淋巴结肿大；Ⅱ期淋巴结肿大伴肺部浸润影；Ⅲ期有浸润影而无淋巴结肿大；Ⅳ期纤维化。

**勒夫格伦综合征**（Löfgren syndrome）是一种急性表现，包括双侧肺门淋巴结肿大、**结节性红斑**（胫前有压痛的红色结节）、关节炎或关节周围炎（尤其是踝部）和发热。通常在数月内自行缓解，预后良好。

肺外结节病很重要，因为某些器官受累是危险的：

- **眼**：前葡萄膜炎或后葡萄膜炎；所有患者都需要眼科评估。
- **心脏**：心肌中的肉芽肿可引起心脏传导阻滞、室性心律失常、猝死和心力衰竭。心悸、晕厥或心电图异常需要用心脏MRI或PET检查。
- **钙**：肉芽肿中的巨噬细胞表达1α-羟化酶，把维生素D转化为活性形式，可引起高钙尿症、高钙血症和肾结石。
- **皮肤**：结节性红斑，以及慢性病例中的冻疮样狼疮（鼻部和面颊的紫红色斑块）。
- **神经系统**：脑神经麻痹（尤其是面神经）、脑膜炎、垂体受累。

血清血管紧张素转换酶常升高，但其灵敏度和特异度都不足以诊断结节病。从最容易获取的部位取组织，常用**支气管内超声引导下纵隔淋巴结针吸活检**。许多患者不需要治疗，因为疾病常可自行缓解。糖皮质激素用于危及器官的疾病（心脏、眼、神经系统、高钙血症）以及有症状的进行性肺部疾病，甲氨蝶呤和其他药物作为减少激素用量的选择。

::: example 疼痛的胫前和一片阴影 {#ex-sarcoid}
一名29岁女性三周来双侧胫前出现疼痛、发红、有压痛的结节，双踝肿痛，伴低热。她有轻度干咳。胸片显示双侧肺门淋巴结肿大。血钙正常，心电图正常。可能的诊断是什么？她需要活检吗？
::: solution
结节性红斑、踝关节周围炎、发热和双侧肺门淋巴结肿大的组合是**勒夫格伦综合征**，一种急性结节病。这种表现非常有特征性，若表现典型且其他病因（如结核病、淋巴瘤或引起结节性红斑的链球菌感染）被认为不太可能，通常不需要活检。治疗为对症处理，使用NSAID并休息。她应做眼科检查和肺功能检查作为基线，并随访以确认缓解，缓解通常在六个月至两年内发生。症状持续、体重下降或盗汗等不典型特征应促使进行组织取样。
:::
:::

### 职业性和药物性ILD

- **石棉肺**是吸入石棉纤维引起的纤维化，通常在数十年前于造船、建筑、绝缘或管道包覆工作中有大量暴露。病变位于肺底，与IPF相似。**胸膜斑**（壁层胸膜良性钙化增厚）是暴露的标志。石棉还引起间皮瘤并增加肺癌风险，吸烟者尤甚（[[respiratory/lung-cancer-pleura]]）。
- **硅沉着病**由采石、喷砂、石材加工以及切割人造石厨房台面时吸入结晶二氧化硅引起；后者已在多个国家的年轻工人中造成严重疾病。病变累及上肺区，形成结节和肺门淋巴结"蛋壳样"钙化，并增加结核病风险。
- **煤工尘肺**由煤尘引起。
- 可引起ILD的**药物**包括胺碘酮、甲氨蝶呤、呋喃妥因、博来霉素等化疗药物，以及免疫检查点抑制剂（肺炎）。用药史至关重要，第一步是停用该药（[[pharmacology/adverse-reactions]]）。

在英国，某些职业性肺病可获得工伤致残津贴，因此详尽的职业史对患者的意义不仅在于诊断（[[public-health/environmental-occupational]]）。

## 肺栓塞 {#sec-pe}

::: definition 静脉血栓栓塞症与肺栓塞 {#def-pe}
**静脉血栓栓塞症**（VTE）包括深静脉血栓形成（DVT）和肺栓塞（PE）。**肺栓塞**是肺动脉树的阻塞，几乎总是由在下肢或盆腔深静脉中形成并经右心转移而来的血栓引起。
:::

::: theorem 菲尔绍三联征 {#thm-virchow}
血栓形成源于三种因素的组合：血流**淤滞**、**血管壁损伤**（内皮损伤）和血液**高凝状态**。
:::

危险因素与三联征相对应：制动、长途旅行、手术（尤其是骨科、盆腔和腹部手术）、住院、创伤、活动性癌症及其治疗、妊娠和产褥期、含雌激素的避孕药和激素替代治疗、肥胖、既往VTE，以及因子V Leiden和抗磷脂综合征等遗传性或获得性易栓症（[[blood/thrombosis-anticoagulation]]、[[pathology/haemodynamics]]）。

### 肺和心脏中发生了什么

栓子阻断部分肺的血流，形成**肺泡无效腔**：有通气而无灌注。血流转向其余的肺，后者相对其通气而言灌注过多，造成V/Q失调和低氧血症。患者过度通气，因此$P_{aCO_2}$通常偏低。如果栓子到达外周，可引起**肺梗死**，伴胸膜炎性疼痛和咯血。

血流动力学影响取决于循环被阻塞的程度以及患者的心肺储备。大块栓子使右心室后负荷骤增，而右心室壁薄，不适合承受高压。右心室扩张，室壁张力和耗氧量增加，室间隔向左心室膨出，使左心室充盈和心输出量减少。这可导致梗阻性休克和心搏骤停。

### 临床表现与诊断

典型症状为突发气短、胸膜炎性胸痛、咯血、晕厥和DVT的表现。体征包括心动过速、呼吸急促、低氧血症，大块PE时还有低血压、颈静脉压升高和右心室抬举样搏动。许多表现并不典型，老年人尤其如此。

诊断策略取决于临床可能性，用经过验证的评分评估，如NICE指南NG158中使用的两级**Wells评分**。

::: definition 肺栓塞的两级Wells评分 {#def-wells}
计分：DVT的临床症状和体征（3）；其他诊断的可能性小于PE（3）；心率高于100次/分（1.5）；制动3天或以上，或过去4周内手术（1.5）；既往DVT或PE（1.5）；咯血（1）；活动性癌症，即过去6个月内接受治疗或处于姑息阶段（1）。评分**高于4**分表示PE**可能**；4分或以下表示PE**不太可能**。
:::

NG158的概要：如果PE**可能**，安排CT肺动脉造影（CTPA），若不能立即进行则先给予临时抗凝。如果PE**不太可能**，进行**D-二聚体**检测；结果阴性则PE可能性极小，应考虑其他诊断；结果阳性则行CTPA。NG158允许对50岁以上者考虑采用年龄校正的D-二聚体阈值。D-二聚体是交联纤维蛋白的降解产物，灵敏但不特异：感染、癌症、妊娠、手术和高龄都会使其升高，因此只在临床可能性低的人中用于排除PE。通气/灌注（V/Q）显像是CTPA的替代方法，例如在肾功能受损、造影剂过敏或（常常是）妊娠时。

其他检查起辅助作用。心电图最常见的是窦性心动过速；经典的S1Q3T3模式并不常见。胸片常正常，有助于排除其他诊断。确诊PE后，肌钙蛋白、利钠肽以及右心室影像学检查（CT或超声心动图）有助于评估严重程度。

::: example 为气短女性评分 {#ex-wells}
一名38岁女性在关节镜手术后10天出现气短和胸膜炎性胸痛，术后她卧床一周。心率108次/分，$S_pO_2$ 94%，无DVT体征。她正在服用复方口服避孕药。查体、心电图和胸片均无其他诊断的特征。计算她的Wells评分，并概述下一步。
::: solution
DVT体征：无（0）。其他诊断的可能性小于PE：是（3）。心率高于100：是（1.5）。4周内手术/制动：是（1.5）。既往VTE：无。咯血：无。癌症：无。合计**6分：PE可能**。

她应做CTPA。若不能尽快进行，在无禁忌证的前提下，等待期间开始临时抗凝。D-二聚体检测在此无用，因为对于评分为"可能"的人，阴性结果并不能可靠地排除PE。她的口服避孕药是一个额外的（未计分的）危险因素；若确诊PE应停用并安排替代避孕措施，因为DOAC和华法林等抗凝药对胎儿有害。
:::
:::

### 严重程度与治疗

欧洲心脏病学会指南（2019年）按早期死亡风险对PE进行分层。**高危**PE引起血流动力学不稳定（心搏骤停、梗阻性休克或持续低血压）。**中危**PE无不稳定，但有不良临床特征（例如简化肺栓塞严重程度指数升高），伴或不伴右心室功能障碍和肌钙蛋白升高。**低危**PE没有上述任何特征，部分患者可在门诊治疗。

治疗原则：

- **抗凝**是几乎所有PE的治疗。它防止血栓延展和复发，同时由机体的纤溶系统溶解已有的血栓。NICE（NG158）推荐直接口服抗凝药**阿哌沙班或利伐沙班**作为大多数成人的首选，替代方案包括低分子量肝素序贯达比加群、依度沙班或维生素K拮抗剂。在某些情况下避免使用DOAC，包括抗磷脂综合征（尤其是三抗体阳性）、妊娠和严重肾功能受损。
- **溶栓**（例如阿替普酶）用于伴血流动力学不稳定的高危PE，除非有禁忌证。它迅速溶解血栓、减轻右心室负荷，代价是相当大的大出血风险，包括颅内出血。溶栓禁忌或失败时，可选择外科或经导管取栓。
- **疗程**：至少3个月。由手术等重大一过性危险因素诱发的PE，通常在3个月时停药。对于无诱因的PE，考虑长期抗凝，权衡复发风险与出血风险。

有些人在PE后持续气短。少数人发展为**慢性血栓栓塞性肺动脉高压**（CTEPH），未溶解的机化血栓阻塞肺动脉。抗凝三个月后仍持续气短者应筛查CTEPH。

::: example 病房走廊里的晕倒 {#ex-pe-shock}
一名63岁男性因癌症行结肠切除术后第5天，行走时晕倒。他面色苍白、湿冷，血压78/50 mmHg，心率128次/分，高流量吸氧下$S_pO_2$ 84%，颈静脉怒张。床旁超声心动图显示右心室扩张、运动减弱，左心室小而充盈不足。可能的诊断是什么？治疗上有哪些考虑？
::: solution
术后突然晕倒、低氧血症、梗阻性休克和急性右心室扩张强烈提示**高危（大块）肺栓塞**。在无法安全进行CTPA的不稳定患者中，床旁超声心动图显示右心室负荷过重的证据即足以支持再灌注治疗。

标准的再灌注治疗是全身溶栓。但他五天前做过腹部大手术，由于严重出血风险，这是一个重要的禁忌证。上级医师必须迅速作出决定，权衡PE导致即刻死亡的风险与出血风险。如果条件允许，可选择外科取栓或经导管治疗。同时，他需要用普通肝素抗凝（可迅速停用或逆转）、给氧、谨慎补液（液体过多会加重右心室扩张）以及血管升压药支持，并让重症监护团队参与。
:::
:::

## 肺动脉高压 {#sec-ph}

::: definition 肺动脉高压 {#def-ph}
2022年ESC/ERS指南把**肺动脉高压**（PH）定义为静息时经右心导管测得的**平均肺动脉压高于20 mmHg**。**毛细血管前性**PH还要求肺动脉楔压（PAWP，左心房压的估计值）为15 mmHg或以下，且肺血管阻力（PVR）高于2 Wood单位。**毛细血管后性**PH的PAWP高于15 mmHg，反映来自左心的压力升高。
:::

肺循环正常时是一个低压、低阻系统，能够接受全部心输出量而压力只轻度升高，因为未使用的血管会被募集和扩张。肺血管阻力的计算公式为：

$$
\text{PVR} = \frac{\text{mPAP} - \text{PAWP}}{\text{CO}}
$$ {#eq-pvr}

压力以mmHg计，心输出量以L/min计，得出Wood单位。（乘以80换算为dyn·s·cm⁻⁵。）

::: definition 肺动脉高压的临床分类 {#def-ph-groups}
1. **动脉性肺动脉高压**（PAH）：特发性；遗传性（例如*BMPR2*变异）；药物和毒物所致；与结缔组织病（尤其是系统性硬化症）、HIV、门静脉高压或先天性心脏病相关。
2. **左心疾病相关的PH**：总体上最常见的病因（心力衰竭、二尖瓣和主动脉瓣疾病）。
3. **肺部疾病和/或缺氧相关的PH**：慢阻肺、ILD、睡眠呼吸障碍、高原。
4. **肺动脉阻塞相关的PH**：主要是**慢性血栓栓塞性PH**（CTEPH）。
5. **机制不明和/或多因素的PH**：例如血液系统疾病、结节病和代谢性疾病。
:::

在PAH中，小肺动脉发生重构：平滑肌细胞和内皮细胞增殖，血管壁增厚，形成丛状病变。三条信号通路发生紊乱：一氧化氮和前列环素（血管扩张剂和增殖抑制剂）过少，内皮素（血管收缩剂和促有丝分裂因子）过多。这些通路是现有药物的靶点。

PH的首发症状不具特异性：劳力性气短、乏力、劳力性胸痛和晕厥，晚期出现踝部水肿。这导致诊断通常延误一年或更久。体征包括第二心音肺动脉瓣成分亢进、右心室抬举样搏动、三尖瓣反流、颈静脉压升高和水肿。**超声心动图**根据三尖瓣反流峰速和右心室劳损征象估计PH的可能性；**右心导管检查**确诊并测定血流动力学。检查还要寻找病因：肺功能、HRCT、V/Q显像（CTEPH的最佳筛查检查）、睡眠监测、自身免疫血清学以及HIV和肝脏检查。

治疗取决于分组。在第2组和第3组中，治疗基础心脏或肺部疾病，氧疗纠正低氧性血管收缩。CTEPH以终身抗凝治疗，并尽可能行**肺动脉内膜剥脱术**，这是一种有可能根治的手术；不能手术者可选择球囊肺动脉成形术和可溶性鸟苷酸环化酶激动剂利奥西呱。PAH在专科中心（在英国为指定的国家肺动脉高压中心）管理，药物包括：

- **内皮素受体拮抗剂**（安立生坦、波生坦、马昔腾坦）。
- **一氧化氮通路药物**：磷酸二酯酶-5抑制剂（西地那非、他达拉非）和利奥西呱。
- **前列环素通路药物**：依前列醇（持续静脉输注）、伊洛前列素、曲前列尼尔和司来帕格。
- **索特西普**（sotatercept），一种激活素信号抑制剂，2024年获批用于成人PAH，针对生长信号的失衡。
- **钙通道阻滞剂**，大剂量，仅用于急性血管反应试验阳性的少数特发性PAH患者。

联合治疗现已很常见。对最大剂量治疗下仍恶化的患者考虑肺移植。

::: example 计算血管阻力 {#ex-pvr}
一名52岁系统性硬化症女性接受右心导管检查：平均肺动脉压38 mmHg，PAWP 10 mmHg，心输出量3.5 L/min。计算她的PVR并对其PH分类。
::: solution
$\text{PVR} = (38 - 10)/3.5 = 28/3.5 = 8$ Wood单位。

她的mPAP高于20 mmHg，PAWP为15 mmHg或以下，PVR高于2 Wood单位，因此为**毛细血管前性肺动脉高压**。在无明显ILD的系统性硬化症中，最可能是**动脉性肺动脉高压**（第1组）。她的心输出量低，这是右心室功能障碍的标志和不良预后征象。她应在肺动脉高压专科中心管理，通常采用联合治疗。
:::
:::

::: quiz
一名34岁女性突发胸膜炎性胸痛，两级Wells评分为1.5分（只有心率高于100）。按照NICE NG158，最合适的下一步是什么？
- [ ] 立即行CT肺动脉造影
- [x] D-二聚体检测
- [ ] 开始抗凝并安排V/Q显像
- [ ] 因评分低而不做检查直接离院
::: solution
4分或以下表示PE不太可能，因此下一步是D-二聚体检测（[[#def-wells]]）。若阴性，PE基本被排除，考虑其他诊断；若阳性，则行CTPA。对每个人都做影像学检查，会使许多人不必要地接受辐射和造影剂；而在考虑PE时不做任何检查就离院也不合适。
:::
:::

::: history
19世纪40至50年代在柏林工作的鲁道夫·菲尔绍（Rudolf Virchow）创造了"血栓形成"和"栓塞"这两个术语，并证明肺中的血块来自静脉。现在称为菲尔绍三联征的三种因素，是由他的工作和后来作者的工作汇集而成的。1960年，戴维·巴里特（David Barritt）和西蒙·乔丹（Simon Jordan）发表了最早的抗凝随机对照试验之一，证明肝素序贯口服抗凝药可降低PE死亡。结节病由乔纳森·哈钦森（Jonathan Hutchinson，皮肤病变，1877年）、凯撒·伯克（Caesar Boeck，1899年命名为sarcoid）和约恩·绍曼（Jörgen Schaumann）描述；斯文·勒夫格伦（Sven Löfgren）于1953年描述了伴结节性红斑和肺门淋巴结肿大的急性综合征。始于1981年的美国国立卫生研究院原发性肺动脉高压登记研究记录了其不良预后，并促成了第一种靶向药物——静脉用依前列醇——于1995年获批。
:::

::: summary
- ILD引起限制性模式、TLCO降低和运动时血氧下降；诊断依靠HRCT和多学科讨论。
- IPF：老年人中病因不明的进行性纤维化，呈UIP模式（胸膜下、基底部蜂窝影）。抗纤维化药物（吡非尼酮、尼达尼布）使FVC下降减缓约一半；免疫抑制有害。
- 过敏性肺炎由吸入抗原驱动；去除抗原是核心。
- 结节病：非干酪样肉芽肿、双侧肺门淋巴结肿大、勒夫格伦综合征；注意眼、心脏和钙的受累。
- PE源于菲尔绍三联征；它形成无效腔和V/Q失调，大块PE引起右心室衰竭和休克。
- NG158：Wells > 4分，行CTPA；≤ 4分，先查D-二聚体。大多数患者用DOAC抗凝；伴不稳定的高危PE行溶栓。
- PH：mPAP > 20 mmHg。毛细血管前性：PAWP ≤ 15 mmHg且PVR > 2 Wood单位。分为五组；左心疾病是最常见的病因。PAH在专科中心以针对内皮素、一氧化氮和前列环素通路的药物治疗。
:::

## 习题

::: exercise Wells评分 {level=1 check="3.5"}
一名正在接受结肠癌化疗的70岁男性出现气短和咯血。心率106次/分。无DVT体征，近期无手术或制动，无既往VTE，肺炎被认为与PE可能性相当。计算他的两级Wells评分，并说明按NG158的下一步。
::: solution
DVT体征0；其他诊断的可能性小于PE：否，因为肺炎被认为可能性相当（0）；心率高于100（1.5）；手术或制动0；既往VTE 0；咯血（1）；活动性癌症（1）。合计$1.5 + 1 + 1 = 3.5$：**PE不太可能**。下一步是D-二聚体检测，阳性则行CTPA。实践中，活动性癌症患者的D-二聚体常升高，因此许多此类患者最终仍要做影像学检查。
:::
:::

::: exercise 肺血管阻力 {level=1 check="(30-12)/4.5"}
一名患者mPAP 30 mmHg，PAWP 12 mmHg，心输出量4.5 L/min。计算以Wood单位表示的PVR。
::: solution
$\text{PVR} = (30 - 12)/4.5 = 18/4.5 = 4$ Wood单位。mPAP高于20、PAWP为15或以下且PVR高于2，这是毛细血管前性PH。
:::
:::

::: exercise HRCT上的模式 {level=1}
把每种模式与最可能的诊断配对：(a) 一名74岁男性胸膜下基底部蜂窝影伴牵拉性支气管扩张；(b) 一名31岁女性双侧肺门淋巴结肿大伴淋巴管周围结节；(c) 一名石匠上肺区结节伴肺门淋巴结蛋壳样钙化；(d) 一名养鸽人中上肺区磨玻璃影伴马赛克征和气体陷闭。
::: solution
(a) 普通型间质性肺炎，最可能是IPF（排除已知病因后）。(b) 结节病。(c) 硅沉着病。(d) 过敏性肺炎（饲鸟者肺）。
:::
:::

::: exercise 为什么PaCO2偏低？ {level=2}
一名急性PE患者呼吸空气时$P_{aO_2}$ 8.2 kPa，$P_{aCO_2}$ 3.9 kPa。解释这两个数值，并计算A–a梯度（取$P_{IO_2}$ 20.0 kPa，$R$ 0.8）。
::: solution
$P_{aO_2}$降低主要源于V/Q失调：从被阻塞血管转移来的血流使其余的肺相对其通气而言灌注过多；心输出量下降导致混合静脉血饱和度下降，也加重了低氧。$P_{aCO_2}$偏低反映过度通气，由肺感受器受刺激、低氧血症和焦虑驱动，足以抵消栓子造成的无效腔还有余。$P_{AO_2} = 20.0 - 3.9/0.8 = 15.1$ kPa；梯度$= 15.1 - 8.2 = 6.9$ kPa，明显升高，符合肺部疾病而非通气不足。
:::
:::

::: exercise 高钙血症 {level=2}
一名已知肺结节病的42岁男性出现口渴、多尿和意识模糊。校正血钙3.2 mmol/L，甲状旁腺激素被抑制。解释其机制和处理原则。
::: solution
结节病肉芽肿中的活化巨噬细胞表达1α-羟化酶，不依赖甲状旁腺激素地把25-羟维生素D转化为1,25-二羟维生素D（骨化三醇）。骨化三醇增加肠道钙吸收和骨吸收，引起高钙血症，进而抑制PTH。原则：静脉补液纠正脱水，避免维生素D和钙补充剂并减少日晒，使用糖皮质激素抑制肉芽肿活性和骨化三醇的产生。寻找肾结石和肾功能损害（[[endocrine/bone-calcium]]）。
:::
:::

::: exercise 为什么不查D-二聚体？ {level=2}
解释为什么D-二聚体检测对一名Wells评分低的25岁人排除PE有用，而对一名正从肺炎中恢复的85岁住院患者用处小得多。
::: solution
D-二聚体灵敏度高而特异度低。在验前概率低时（如评分低的年轻门诊患者），阴性结果可有效排除PE。D-二聚体随年龄、感染、炎症、癌症和住院而升高，因此在患肺炎的老年住院患者中，无论病因如何都可能阳性；阳性结果几乎没有信息量，大多数此类患者仍需影像学检查。年龄校正阈值可在一定程度上提高老年人中的特异度。若临床可能性高，则根本不应用D-二聚体来排除PE。
:::
:::

::: exercise 有雷诺现象的气短女性 {level=3}
一名56岁局限皮肤型系统性硬化症女性一年来气短日益加重。肺量计和肺容积正常，但TLCO为预计值的42%。她的六分钟步行距离缩短，血氧降至88%。NT-proBNP升高。讨论鉴别诊断、检查，以及检查顺序为何重要。
::: hint
系统性硬化症可引起ILD和PAH两者，肺功能模式可能有助于在两者之间作出选择。
:::
::: solution
主要可能是**动脉性肺动脉高压**和**ILD**，两者在系统性硬化症中都很常见，且可并存。肺容积正常而TLCO孤立性显著下降，加上利钠肽升高，更支持PAH。早期ILD也可在容积下降之前使TLCO降低，左心疾病（舒张功能障碍、心肌受累）则可引起毛细血管后性PH。

检查：超声心动图估计PH的可能性并评估两个心室；HRCT寻找ILD；V/Q显像排除CTEPH；**右心导管检查**确诊PH、测定PAWP并计算PVR，以区分毛细血管前性和毛细血管后性PH。顺序之所以重要，是因为治疗完全不同：PAH靶向药物对第1组PH有益，在第3组PH中可能使氧合恶化（因解除了通气不良肺区的低氧性血管收缩），对第2组PH则不合适。应让肺动脉高压专科中心参与。
:::
:::

::: exercise 试用激素？ {level=3}

在明确UIP模式且无已知病因时，可能的诊断是IPF。在IPF中，糖皮质激素（以及其他免疫抑制）不能改善结局，而在PANTHER试验中与硫唑嘌呤和N-乙酰半胱氨酸联用还增加了死亡和住院。泼尼松龙还会引起高血糖、骨质疏松、肌病、感染风险和体重增加。他应转诊至ILD多学科团队以证实诊断（并再次寻找可能对免疫抑制有反应的过敏性肺炎或结缔组织病），若确诊IPF，则考虑抗纤维化治疗和支持治疗。由于存在肾上腺抑制的风险，激素应在监督下复核并逐渐减量，而不是突然停用。
