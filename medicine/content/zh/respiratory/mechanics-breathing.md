每一次呼吸都是一小段物理过程。呼吸肌改变胸腔的容积，容积的变化改变肺泡内的压力，空气便顺着口腔与肺泡之间的压力差流动。有两样东西阻碍这种流动：肺和胸壁的弹性回缩力，它抵抗扩张；以及气道阻力，它抵抗气体的移动。几乎所有呼吸系统的临床表现都可以用这两种阻力之一的改变来解释。肺纤维化使肺变硬；肺气肿使肺变松软；哮喘使气道变窄；气胸则把肺和胸壁完全分离开来。

本章从基础开始搭建这一框架。先讲驱动通气的压力，再讲肺容积及其测定，然后是顺应性和表面张力，接着是气道阻力和呼气流量的上限，最后是呼吸功。最后一节说明肺量计测量的是什么，以及阻塞和限制这两大模式如何由力学产生。

## 推动空气的压力 {#sec-pressures}

空气从高压处流向低压处。在一次平静呼气末，声门开放、没有气流时，肺泡内压等于大气压。吸气时，肺泡内压必须低于大气压；呼气时，则必须高于大气压。按照惯例，呼吸相关压力以相对于大气压的数值表示，单位为厘米水柱（1 cmH₂O ≈ 0.098 kPa），因此大气压记为"零"。

::: definition 呼吸相关压力 {#def-pressures}
- **肺泡内压**（$P_A$）是肺泡内气体的压力。
- **胸膜腔内压**（$P_{pl}$）是脏层胸膜与壁层胸膜之间那层薄液膜中的压力。静息时约为−5 cmH₂O。
- **跨肺压**（$P_{tp} = P_A - P_{pl}$）是肺内外的压力差，是使肺保持扩张的压力。
- **跨呼吸系统压**（$P_{rs} = P_A - P_{atm}$）是肺泡与口腔之间的压力差，它驱动气流。
:::

胸膜腔内压之所以为负，是因为肺和胸壁朝相反方向牵拉。肺若任其自然，会塌陷到很小的容积：它富含弹性纤维，表面还衬着一层液膜，液膜的表面张力向内牵拉。胸壁若任其自然，则会向外弹开到更大的容积。胸膜腔液把两者耦合在一起，就像一层水膜把两块玻片粘在一起。两股相反的牵拉力在胸膜腔内形成轻度负压。

平静吸气时，膈肌收缩下降，肋间外肌上提肋骨。胸廓扩大，胸膜腔内压从约−5 cmH₂O降到约−8 cmH₂O，跨肺压增大，肺随胸廓一同扩张。根据玻意耳定律（温度不变时，压力与容积的乘积恒定），肺泡容积增大时肺泡内压下降约1 cmH₂O，空气随之流入。呼吸肌松弛时，肺的弹性回缩力使肺泡内压略高于大气压，空气流出。因此平静呼气是被动的。用力呼气时会动用腹肌和肋间内肌，它们使胸膜腔内压升高，有时远高于大气压。

::: example 胸部刺伤 {#ex-pneumo}
一名23岁男性右侧胸部被刺伤。他呼吸困难，右侧胸廓活动度小于左侧，右侧呼吸音消失。请解释其力学机制。
::: solution
伤口使胸膜腔与大气相通（或破损的肺向胸膜腔漏气）。由于胸膜腔内压低于大气压，空气进入胸膜腔。一旦胸膜腔内压升至大气压，原先使右肺保持扩张的跨肺压便降为零。肺的弹性回缩力不再受到对抗，肺便向其自身的静息容积塌陷，而右侧胸壁则稍向外弹开。这就是**气胸**。呼吸音消失，是因为贴近胸壁处已没有含气的肺组织来传导声音；该侧胸廓活动度减小，是因为胸廓扩张已不能再使肺充气。气胸的处理见[[respiratory/lung-cancer-pleura]]。
:::
:::

## 肺容积与肺容量 {#sec-volumes}

肺量计记录吸入和呼出的气体容积。标准分区由四个参照点确定：平静呼气末、平静吸气末、最大吸气末和最大呼气末。

::: definition 肺容积与肺容量 {#def-volumes}
四种**容积**互不重叠：

- **潮气量**（VT）：一次平静呼吸的气量，成人静息时约0.5 L。
- **补吸气量**（IRV）：平静吸气末还能再吸入的气量。
- **补呼气量**（ERV）：平静呼气末还能再呼出的气量。
- **残气量**（RV）：最大呼气后仍留在肺内的气量。

**容量**是容积之和：

- **肺总量** TLC = IRV + VT + ERV + RV，青年男性约6 L。
- **肺活量** VC = IRV + VT + ERV，即最大吸气后所能呼出的最大气量。
- **功能残气量** FRC = ERV + RV，即平静呼气末肺内的气量，约2.5–3 L。
- **深吸气量** IC = VT + IRV。
:::

这些数值取决于身高、年龄和性别，其他因素的影响较小，因此测量值要与参考方程比较，而不是与固定数值比较（见[[respiratory/control-breathing-tests]]）。

FRC并非随意的数值。它是肺向内的回缩力恰好与胸壁向外的回弹力相平衡时的容积，因此维持这一容积不需要任何肌肉用力。任何改变这两种回缩力之一的因素都会使FRC移动。僵硬的纤维化肺牵拉力更强，FRC下降。肺气肿时肺失去回缩力，FRC升高。平卧时腹腔内容物把膈肌推高，FRC可下降数百毫升；肥胖和妊娠也有类似作用。FRC降低有临床意义，因为一些小气道在低肺容积时会闭合，导致部分肺区有血流灌注却通气不良。

RV（因而还有FRC和TLC）不能用肺量计测定，因为受检者无法呼出残气量。常用三种方法：

- **氦稀释法**：受检者从一个含已知浓度氦气的密闭回路中反复呼吸，直至回路与肺内的浓度达到平衡。氦是一种几乎不进入血液的惰性气体。
- **氮冲洗法**：受检者吸入100%氧，收集并测定从肺内冲洗出来的全部氮气。
- **体积描记法**（"体箱"）：受检者在密闭箱内对着关闭的阀门浅快呼吸，利用玻意耳定律计算胸腔内气体的容积。

稀释法只能测得与气道相通的气体。体积描记法则测得胸腔内的全部气体，包括被闭合气道阻隔或存在于肺大疱中的气体。因此，体箱测得的容积明显大于氦稀释法测得的容积，提示存在气体陷闭。

::: example 用氦稀释法测定FRC {#ex-helium}
平静呼气末，将患者连接到一个装有9.0 L气体、含10%氦的肺量计上。反复呼吸数分钟后，氦浓度降至7.5%。FRC是多少？
::: solution
氦不被吸收，因此氦的总量守恒：$C_1 V_1 = C_2 (V_1 + \text{FRC})$。

$$
\text{FRC} = V_1 \cdot \frac{C_1 - C_2}{C_2} = 9.0 \times \frac{10 - 7.5}{7.5} = 3.0 \text{ L}
$$

FRC为3.0 L，对中等身高的成年男性而言在正常范围内。在气体陷闭严重的慢阻肺中，氦稀释法的估计值可能低于真实的胸腔气体容积，因为在测试期间氦到达不了交通不良的区域。
:::
:::

## 顺应性与弹性回缩 {#sec-compliance}

肺的行为像一个气球：充得越多，回缩的拉力越大。它的可扩张性用顺应性来描述。

::: definition 顺应性 {#def-compliance}
**顺应性**是单位扩张压变化所引起的容积变化：

$$
C = \frac{\Delta V}{\Delta P}
$$ {#eq-compliance}

对肺而言，扩张压是跨肺压。正常肺顺应性约为200 mL/cmH₂O；肺和胸壁合在一起约为其一半，大约100 mL/cmH₂O。**弹性阻力**（elastance）是顺应性的倒数。僵硬的肺顺应性低、弹性阻力高。
:::

顺应性并非恒定。肺的压力–容积曲线呈S形：在中段顺应性最高，在很高容积时下降（弹性纤维和胶原纤维达到极限），在很低容积时也下降（肺泡塌陷，必须重新打开）。正常呼吸发生在曲线陡峭、效率高的那一段。

肺纤维化、肺水肿、肺炎和急性呼吸窘迫综合征时顺应性下降，这些疾病都使肺增厚或被液体充填。肺气肿时顺应性升高，因为肺泡壁破坏使弹性组织丧失。顺应性高听起来是好事，其实不然：肺失去了在呼气时撑开小气道并把气体驱出的回缩力。

::: example 肺纤维化时的顺应性 {#ex-compliance}
健康成人吸入500 mL气体需要跨肺压升高2.5 cmH₂O。一名特发性肺纤维化女性吸入同样的500 mL需要升高10 cmH₂O。计算两者的顺应性，并解释她可能采取的呼吸方式。
::: solution
健康肺：$C = 500/2.5 = 200$ mL/cmH₂O。纤维化肺：$C = 500/10 = 50$ mL/cmH₂O，为正常的四分之一。

现在每一次正常大小的呼吸需要四倍的吸气压力，因此深呼吸的弹性功很高。肺僵硬的人通过小而快的呼吸来降低这一代价，这就是纤维化典型的浅快呼吸模式。由于肺的回缩力强，FRC、TLC和肺活量都下降，这就是本章末尾所述的限制性模式。
:::
:::

### 表面张力与表面活性物质

肺弹性回缩力的约三分之二并非来自组织，而是来自衬于肺泡表面的气–液界面的表面张力。库尔特·冯·尼尔加德（Kurt von Neergaard）在1929年证明了这一点：充满生理盐水（因而消除了气–液界面）的肺，其充盈所需压力远低于充满空气的肺。

::: theorem 球面的拉普拉斯定律 {#thm-laplace}
对于只有一个气–液界面的球形气泡，使其保持开放所需的压力为

$$
P = \frac{2T}{r}
$$ {#eq-laplace}

其中$T$为表面张力，$r$为半径。表面张力相同时，越小的气泡需要越高的压力。
:::

如果每个肺泡的表面张力都与纯水相同，就会出现两个问题：使肺充盈所需的压力很大；而且小肺泡所需压力高于大肺泡，会把气体排入较大的邻近肺泡而塌陷。肺通过**表面活性物质**避免了这两个问题。

::: proof
表面活性物质是磷脂（主要是二棕榈酰磷脂酰胆碱）与特异性蛋白质的混合物，由Ⅱ型肺泡上皮细胞分泌。其分子位于气–液界面，使表面张力远低于水。肺泡缩小时，表面活性物质分子排列得更紧密，表面张力进一步下降。$T$的下降抵消了[[#eq-laplace]]中$r$的下降，因此小肺泡并不比大肺泡需要更高的压力，也不会向大肺泡排空。表面活性物质因此有三项作用：增加顺应性从而减少呼吸功；使大小不同的肺泡保持稳定；并通过减小对肺泡壁的向内牵拉，帮助肺泡保持干燥。
:::

表面活性物质在妊娠后半期开始产生，成熟较晚。极早产儿可能产生不足，从而发生**新生儿呼吸窘迫综合征**：出生后不久出现肺僵硬、肺泡塌陷、呻吟和需氧量不断增加。产前给母亲使用糖皮质激素可加速表面活性物质的产生，也可经气管直接给新生儿注入表面活性物质（[[paediatrics/newborn]]）。在成人，急性呼吸窘迫综合征的炎症会损伤表面活性物质，这是该病肺僵硬的原因之一（[[respiratory/respiratory-failure]]）。

## 气道阻力与气流 {#sec-resistance}

阻碍呼吸的第二种力是气道阻力。对管道中的流动而言，阻力是驱动压除以流量，$R = \Delta P / \dot V$。

::: theorem 泊肃叶定律 {#thm-poiseuille}
流体在半径为$r$、长度为$l$的直管中作平滑（层流）流动时，阻力为

$$
R = \frac{8 \eta l}{\pi r^4}
$$ {#eq-poiseuille}

其中$\eta$为流体黏度。阻力与半径的四次方成反比：半径减半，阻力增至16倍。
:::

四次方关系解释了为什么气道口径的微小变化影响如此之大。哮喘时的支气管收缩、黏膜水肿和黏液各使气道略微变窄，合在一起就能使阻力成倍增加。

气流并非总是层流。在流速高的气管和大支气管中，以及在任何狭窄处，气流会变为湍流。湍流时所需压力大致随流量的平方增加，阻力取决于气体的密度而非黏度。这就是在某些上气道梗阻中使用氦氧混合气（比空气密度低的氦–氧混合物）的依据。

最细的气道对总阻力的贡献最小，这似乎令人意外。每一根细支气管都很细，但并联的数量极多，其总横截面积非常大。大部分阻力位于中等大小的支气管，大约第4至第8级。其后果是，小气道疾病可能已经很广泛，总阻力的变化却还不足以在常规检查中显示出来。小气道因此被称为肺的"静默区"。

气道阻力还取决于肺容积。肺充盈时，周围组织牵拉气道壁（径向牵引），使气道变宽。哮喘或慢阻肺患者发作时往往在较高的肺容积下呼吸，部分原因就在于此。

### 呼气流量的上限 {#sec-epp}

如果从最大吸气位尽最大力气呼气，流量会迅速升到峰值，然后随着肺的排空逐渐下降。值得注意的是，一旦呼出少量气体之后，再用更大的力气也完全不能增加流量。在肺活量的大部分范围内，呼气流量是**用力非依赖性**的。

::: definition 气道动态压缩与等压点 {#def-epp}
用力呼气时，胸膜腔内压变为正值，同时挤压肺泡和胸内气道。由于阻力的存在，气道内压力从肺泡向口腔方向逐渐下降。沿着气道总有一点，气道内的压力等于气道外的胸膜腔内压，这一点就是**等压点**。在其下游（朝向口腔一侧），气道外的压力超过气道内的压力，气道受到压缩。这就是**气道动态压缩**。
:::

::: proof
肺泡内压等于胸膜腔内压与肺弹性回缩压之和：$P_A = P_{pl} + P_{el}$。在等压点，气道内压等于$P_{pl}$，因此从肺泡到该点的压力降恰好等于$P_{el}$。上游段的气流仅由弹性回缩压驱动，而与胸膜腔内压无关。用更大力气会升高$P_{pl}$，但这使肺泡内压和下游气道所受的压缩压升高同样的幅度，因此流量不会增加。最大呼气流量由肺的弹性回缩力和等压点上游气道的阻力决定。
:::

这解释了大量临床生理现象。肺气肿时弹性回缩力低，最大流量的驱动压低，松软的气道容易塌陷：最大流量下降，气体陷闭。哮喘时上游阻力高，等压点向肺泡方向移动，那里的气道更容易被压缩。两种情况下呼气流量都受限，呼气时间延长；如果下一次吸气在呼气完成之前就开始，肺容积就会逐次递增。这就是**动态肺过度充气**。它使膈肌处于力学劣势，膈肌变平、肌纤维缩短，是慢阻肺患者活动时呼吸困难的主要原因之一。

许多慢阻肺患者会自己摸索出缩唇呼吸。缩唇在口腔处增加了阻力，使呼气时气道内压升高，等压点向口腔方向移动，从而减少气道塌陷。

### 时间常数

一个肺区充盈和排空有多快？阻力为$R$、顺应性为$C$的肺区按指数规律充盈和排空，其**时间常数**为$\tau = RC$。经过一个时间常数，约完成63%的容积变化；经过三个，约完成95%。

$$
V(t) = V_0 \left(1 - e^{-t/\tau}\right)
$$ {#eq-tau}

健康肺的$\tau$很短，只有几分之一秒，因此即使呼吸频率很快，两次呼吸之间肺也能完全排空。阻力升高（如慢阻肺）时$\tau$延长；若顺应性也升高（如肺气肿），$\tau$会更长。时间常数长的肺单位在可用的时间内无法排空，尤其在运动或焦虑使呼吸频率加快时。时间常数不同的各区域充盈也不均匀，这会使通气与血流的匹配恶化（[[respiratory/gas-exchange]]）。

::: example 半径减半 {#ex-resistance}
一名30岁哮喘女性发作时，中等支气管变窄，其半径降至正常的一半。假设为层流，这些气道的阻力升高多少倍？在相同驱动压下气流会怎样？
::: solution
根据[[#eq-poiseuille]]，$R \propto 1/r^4$。半径减半时，$R_{new}/R_{old} = 1/(0.5)^4 = 16$。在相同驱动压下，流量降至十六分之一。为维持通气，她必须产生大得多的压力波动，因此动用辅助呼吸肌。四次方定律说明了为什么轻度的支气管痉挛、水肿和黏液栓合在一起就能造成严重发作，也说明了为什么一种只使气道略微扩张的支气管舒张剂能显著缓解症状。
:::
:::

## 呼吸功 {#sec-work}

呼吸肌克服两种负荷做功：**弹性**负荷，取决于顺应性和潮气量；**阻力性**负荷，取决于气道阻力和流速。静息时呼吸肌只消耗机体耗氧量的百分之几。在严重肺病中，这一比例可增加许多倍，呼吸肌可能疲劳。

两种负荷有利于不同的呼吸模式。小潮气量可减少弹性功，因此肺僵硬的人呼吸浅而快。低流速可减少阻力功，因此气道阻塞的人倾向于呼吸较慢而深。每个人都会不自觉地选择大致使总功最小的模式。因此，呼吸模式本身就是一个临床体征。

::: definition 呼吸困难 {#def-dyspnoea}
**呼吸困难**是呼吸不适的主观体验。它是一种症状，而不是一项测量值。当脑干产生、并被大脑皮层感知的呼吸驱动与呼吸肌所能实现的通气不相称时，就会出现呼吸困难。负荷增加（肺僵硬、气道狭窄）、呼吸肌无力、过度充气和呼吸驱动增强（低氧血症、高碳酸血症、酸中毒、焦虑）都可引起呼吸困难。
:::

临床上用量表对呼吸困难分级，例如**英国医学研究理事会（MRC）呼吸困难量表**，从1级（只在剧烈运动时气短）到5级（气短到无法出门，或穿衣时即气短）。在慢阻肺中，该量表用于决定哪些人应转诊接受肺康复（[[respiratory/asthma-copd]]）。

::: warning 感觉气短不等于缺氧
呼吸困难和低氧常常同时出现，但它们是两回事。气胸或哮喘发作的患者可能非常气短而血氧饱和度正常；慢性低氧血症患者，或因阿片类药物而呼吸驱动受抑制的患者，可能血氧饱和度很低却没有什么痛苦表现。应根据全貌判断呼吸问题的严重程度：呼吸频率、呼吸做功、说话能力、精神状态、血氧饱和度，必要时还有血气。不要仅凭血氧饱和度就让人放心。
:::

::: example 爬楼梯时的动态过度充气 {#ex-copd-mechanics}
一名68岁重度慢阻肺男性能在平地上行走，但爬一段楼梯走到一半就必须停下。静息时他的FRC为预计值的140%。胸片显示膈肌低平。请解释他为何爬楼梯如此困难。
::: solution
弹性回缩力丧失和小气道狭窄限制了他的呼气流量。静息时他刚好有足够的时间呼气到一个升高了的FRC。爬楼梯时呼吸频率加快，呼气时间缩短，下一次吸气开始前他无法排空肺内气体。呼气末容积逐次升高：这就是动态过度充气。他现在在压力–容积曲线的顶部附近呼吸，那里顺应性低，每次呼吸都更费力。低平的膈肌被缩短，处于力学劣势。他的深吸气量（留给潮气呼吸的空间）缩小，因此无法增加潮气量来满足需求，只好停下。长效支气管舒张剂可减轻过度充气、改善运动耐量，肺康复则训练他调整呼吸节奏（[[respiratory/asthma-copd]]）。
:::
:::

## 肺量计检查：阻塞与限制 {#sec-spirometry}

肺量计测定一个人能呼出多少气体以及呼得多快。关键动作是**用力呼气**：最大吸气后，尽可能用力、尽可能长时间地呼气。

::: definition 肺量计指标与模式 {#def-spiro}
- **FVC**（用力肺活量）：用力呼气时呼出的总气量。
- **FEV₁**（第一秒用力呼气容积）：第一秒内呼出的气量。
- **FEV₁/FVC比值**：青年人通常约为0.75–0.85，随年龄下降。
- **阻塞性模式**：FEV₁/FVC低于正常下限。由于气流受限，FEV₁比FVC下降得更多。
- **限制性模式**：FVC降低，FEV₁/FVC正常或升高。由于肺或胸壁不能扩张，两种容积一同下降，而给定容积下的流量保持不变甚至升高。真正的限制须由肺总量降低来证实。
:::

这两种模式直接来自力学。阻塞时，气流受气道狭窄或回缩力丧失的限制，第一秒内排出的容积比例变小。纤维化所致的限制中，僵硬的肺回缩有力，把气道牢牢撑开，肺排空很快，因此比值正常甚至升高，但总容积小。限制也可来自肺外：胸壁畸形（脊柱后侧凸）、肥胖、胸膜增厚或呼吸肌无力。

**流量–容积环**描绘用力呼气和用力吸气时流量与容积的关系。阻塞时，呼气支呈凹陷（下凹）形，因为流量在峰值后迅速下降。限制时，环变窄但形状正常。气管或喉部的固定性阻塞使两支都变平；可变性阻塞只使其中一支变平，取决于病变位于胸内还是胸外。

判读时使用参考方程，根据年龄、身高和性别预测正常值。现行国际建议（ATS/ERS，2022年）以**正常下限**（LLN，第5百分位数，相当于z分数−1.645）而非固定百分比来定义异常。实践中，包括GOLD和NICE慢阻肺指南在内的许多指南仍以支气管舒张后FEV₁/FVC低于0.70这一固定值来定义阻塞。详见[[respiratory/control-breathing-tests]]。

::: example 两份肺量计结果 {#ex-spiro}
两名年龄、身高和性别相同的人接受肺量计检查。两人的FVC预计值均为4.0 L，FEV₁/FVC的LLN为0.70。

甲：FEV₁ 1.6 L，FVC 3.6 L。乙：FEV₁ 2.2 L，FVC 2.5 L。

分别判断其模式，并提出有助于进一步诊断的检查。
::: solution
甲：FEV₁/FVC = 1.6/3.6 = 0.44，远低于0.70。这是**阻塞**。FVC为预计值的90%，接近正常。下一步是支气管舒张试验（反应大提示哮喘），若怀疑肺气肿，还应测定弥散功能和肺容积。

乙：FEV₁/FVC = 2.2/2.5 = 0.88，正常或偏高。FVC为2.5/4.0 = 预计值的62.5%，明显降低。这是肺量计上的**限制性模式**。仅凭肺量计不能证实限制，因为气体陷闭时FVC也会降低。下一步是测定肺总量（体积描记法或氦稀释法）和弥散功能。TLC低伴弥散因子低提示间质性肺疾病（[[respiratory/interstitial-vascular-disease]]）；TLC低而转移系数正常则提示肺外原因，如肥胖、胸壁疾病或肌无力。
:::
:::

::: quiz
为什么用力呼气的前一段过去之后，再加大用力也不能使最大呼气流量增加？
- [ ] 呼气肌在第一秒内就疲劳了
- [x] 用力增大会升高胸膜腔内压，它对等压点下游气道的压缩与它对驱动压的升高同样多
- [ ] 低肺容积时表面活性物质耗尽
- [ ] 用力呼气时声门反射性关闭
::: solution
用力增大会升高胸膜腔内压。这升高了肺泡内压，但也使挤压等压点下游气道的压力升高同样的幅度。上游段的气流只由肺的弹性回缩压驱动（[[#def-epp]]）。这就是为什么最大呼气流量反映的是肺和气道的特性而不是受检者的力气，也是肺量计检查可重复的原因。
:::
:::

::: history
伦敦医生约翰·哈钦森（John Hutchinson）制作了一台水封式肺量计，并于1846年发表了约2000人的测量结果。他命名了**肺活量**，证明它随身高增加，并注意到它在疾病（包括结核病）中下降。1929年，库尔特·冯·尼尔加德（Kurt von Neergaard）比较了充气肺和充盐水肺，得出结论：表面张力提供了肺回缩力的大部分；他的工作此后约25年基本无人问津。20世纪50年代，研究肺泡泡沫的理查德·帕特尔（Richard Pattle）和测定肺提取物表面张力的约翰·克莱门茨（John Clements）证明，肺泡内衬含有一种降低表面张力的物质。1959年，玛丽·埃伦·艾弗里（Mary Ellen Avery）和杰尔·米德（Jere Mead）报告，死于透明膜病的婴儿的肺缺乏这种物质。第一秒用力呼气容积于1947年由法国的罗贝尔·蒂弗诺（Robert Tiffeneau）和安德烈·皮内利（André Pinelli）提出，不久之后美国的爱德华·根斯勒（Edward Gaensler）也独立提出。等压点的概念由米德等人于1967年阐述。
:::

## 后续内容

通气把空气送到肺泡。接下来发生的事情——氧和二氧化碳穿过肺泡壁并在血液中运输——是[[respiratory/gas-exchange]]的主题。呼吸的调控和各类肺功能检查见[[respiratory/control-breathing-tests]]。本章的力学会在每一个临床章节中再次出现：[[respiratory/asthma-copd]]中的气流受限，[[respiratory/interstitial-vascular-disease]]中的肺僵硬，以及[[respiratory/respiratory-failure]]中的呼吸机设置。胸廓、胸膜和膈肌的解剖见[[anatomy/thorax]]。

::: summary
- 空气顺着呼吸肌产生的压力梯度流动。平静呼气是被动的，由弹性回缩力驱动。
- 胸膜腔内压通常为负，因为肺向内牵拉而胸壁向外牵拉。FRC是这两种回缩力达到平衡时的容积。
- 残气量、FRC和TLC需要用氦稀释法、氮冲洗法或体积描记法测定；肺量计无法测定。
- 顺应性$C = \Delta V/\Delta P$在纤维化和水肿时降低，在肺气肿时升高。表面活性物质降低表面张力，使小肺泡稳定并增加顺应性。
- 气道阻力随$1/r^4$变化，主要集中于中等支气管。小气道疾病可能已很广泛而常规检查仍无变化。
- 由于等压点之后的动态压缩，用力呼气流量与用力无关。回缩力低或上游阻力高都会限制气流，引起气体陷闭和动态过度充气。
- 阻塞：FEV₁/FVC降低。限制：FVC降低而比值正常或升高，须由TLC降低证实。
:::

## 习题

::: exercise 说出容积名称 {level=1}
平静呼气末，肺内还剩哪两种容积？它们构成哪一种容量？其中哪一种可以用简单肺量计测定？
::: solution
剩下补呼气量和残气量，两者合为功能残气量。肺量计可以测定补呼气量（让受检者从FRC位尽量呼气），但不能测定残气量，因为残气量从不离开肺。因此FRC、RV和TLC需要氦稀释法、氮冲洗法或体积描记法。
:::
:::

::: exercise 计算顺应性 {level=1 check="200"}
一次平静呼吸中，肺容积增加600 mL，跨肺压从5 cmH₂O升至8 cmH₂O。肺顺应性是多少mL/cmH₂O？
::: solution
$C = \Delta V / \Delta P = 600 / (8 - 5) = 200$ mL/cmH₂O，属正常值。
:::
:::

::: exercise 氦稀释法 {level=1 check="2.4"}
肺量计内有8.0 L气体，含10%氦。从FRC位与患者肺内达到平衡后，氦浓度为7.69%。用$C_1V_1 = C_2(V_1 + \text{FRC})$计算FRC（单位L，保留一位小数）。
::: hint
整理为$\text{FRC} = V_1 (C_1 - C_2)/C_2$。
:::
::: solution
$\text{FRC} = 8.0 \times (10 - 7.69)/7.69 = 8.0 \times 0.3004 = 2.40$ L，保留一位小数为2.4 L。
:::
:::

::: exercise 变窄的气道 {level=2 check="round(1/0.6^4)"}
黏膜水肿使一根支气管的半径降至正常的60%。假设为层流，其阻力增加多少倍？答案取最接近的整数。
::: solution
$R \propto 1/r^4$，因此倍数为$1/0.6^4 = 1/0.1296 = 7.72$，取整为8。半径减少40%，阻力几乎增加到8倍。
:::
:::

::: exercise 慢肺单位的排空 {level=2 check="round(100*(1-exp(-2)))"}
某肺区的时间常数为0.5 s。根据[[#eq-tau]]，1秒后其容积变化完成了百分之几？答案取最接近的整数百分比。
::: solution
$t = 1$ s时，$t/\tau = 2$，故比例为$1 - e^{-2} = 1 - 0.135 = 0.865$，即86%。如果疾病使时间常数加倍到1 s，同样时间内只能排空$1 - e^{-1} = 63\%$，在呼吸频率快时该区域会发生气体陷闭。
:::
:::

::: exercise 表面活性物质与小肺泡 {level=2}
用拉普拉斯定律解释：没有表面活性物质时，与大肺泡相通的小肺泡为什么会倾向于向大肺泡排空？表面活性物质如何防止这种情况？
::: solution
表面张力相同时，$P = 2T/r$意味着小肺泡（$r$较小）的内压较高，因此气体从小肺泡流入大肺泡，大肺泡随之增大而小肺泡塌陷。表面活性物质降低表面张力，而且表面积缩小时降得更多，因为其分子排列更密集。在小肺泡中，$T$随$r$同步下降，因此两者压力相等，都能保持开放。表面活性物质还能增加顺应性，并帮助肺泡保持干燥。
:::
:::

::: exercise 解读一次用力呼气 {level=2}
一名45岁女性FEV₁ 2.8 L（预计值2.9 L），FVC 3.4 L（预计值3.5 L），FEV₁/FVC 0.82。她诉活动时呼吸有杂音，流量–容积环显示吸气支和呼气支均变平。这提示什么？
::: solution
她的FEV₁、FVC和比值都正常，因此没有胸内气道阻塞，也没有限制。流量–容积环两支均变平提示**中央气道固定性阻塞**，如插管后气管狭窄、甲状腺肿压迫气管或肿瘤。大气道阻塞在严重之前可能几乎不改变FEV₁，因此环的形状才是线索。她需要气管影像学检查并转诊；固定性上气道病变可发展为喘鸣和危险气道。
:::
:::

::: exercise 胸壁僵硬还是肺僵硬？ {level=3}
三名患者FVC均降低而FEV₁/FVC正常：(a) 一名70岁男性，双肺底湿啰音，杵状指；(b) 一名35岁女性，BMI为48；(c) 一名55岁运动神经元病男性。预测每人的肺总量、残气量和转移系数（KCO），并解释这些检查如何区分他们。
::: hint
想一想限制来自哪里：肺本身、胸壁和腹部，还是肌肉。KCO是每升可及肺容积的气体转移量。
:::
::: solution
(a) 提示**肺纤维化**，即肺本身的疾病。TLC降低，RV降低，由于肺泡–毛细血管膜增厚、毛细血管床丧失，气体转移下降；KCO通常降低或正常，而不升高。

(b) **肥胖**加重胸壁负荷并把膈肌推高。FRC和ERV下降最明显；TLC正常或轻度降低；RV通常保留。肺本身健康，因此KCO正常甚至升高，因为同样的毛细血管床被压缩在较小的容积中。

(c) **呼吸肌无力**使TLC降低（无法充分吸气），并使RV升高（无法充分呼气），因此VC从两端同时减小。KCO正常或升高。线索包括平卧时肺活量下降（膈肌无力）以及口腔压降低。连续测定肺活量用于监测神经肌肉疾病并把握通气支持的时机（[[respiratory/respiratory-failure]]）。

要点是："限制性"肺量计模式只是一种描述，而不是诊断。肺容积和弥散功能才能定位问题所在。
:::
:::
