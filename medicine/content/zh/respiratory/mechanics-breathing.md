通气就是被应用的物理学：由肌肉产生一个压力的梯度，被弹性（肺加胸壁）、阻力（气道）和惯性（气体和组织的质量）对抗，把潮气量输送到由表面活性物质保持开放、并悬挂在一个通常是低于大气压而且通常是空的胸膜腔里的约三亿个肺泡的泡沫。呼吸系统的每一个临床的体征（呼气流量曲线的形状与扁平的膈肌）都来自变量。

本章涵盖容积与顺应性、流量与阻力、呼吸的功，以及呼吸困难的机制。

## 容积与顺应性及静息的平衡

::: definition 肺活量与体积描记的清单 {#def-volumes}
**容积与容量：潮气（约500毫升）与补气的/补气的量、残气（不能被呼出）与功能残气（平静呼气后的肺的气体：弹性的向内与胸壁的向外的力的平衡）；测得的肺的容量（潮气+补呼气+残气）与总和（肺活量与总量的肺）：残气无法被呼出，所以它需要氦的稀释或身体对气体的稀释的定律的体积描记[[respiratory/control-breathing-tests]]。这个被测量的与这个被计算的功能残气的差距（氦对照体积描记）就是被陷闭的空间：在气肿与发作中的气体的陷闭的上升（[[#ex-copd-mechanics]]、[[respiratory/asthma-copd]]）。顺应性就是容积的改变除以压力的改变：肺的（跨肺的压力）与胸壁的与合起来，而曲线的形状重要（肺的顺应性在高的容积时下降；纤维化曲线陡度的丧失，和阻塞的过度膨胀把呼吸推到扁平的不顺应性的部分[[respiratory/interstitial-vascular-disease]]）。表面活性物质（二棕榈酰的卵磷脂与蛋白）会降低表面的张力，按面积被调节，防止小肺泡的塌陷（拉普拉斯）并维持肺泡的干燥；它的缺乏或失活（早产儿呼吸的窘迫与成人窘迫蛋白的失活）会造成塌陷与僵硬和分流[[#ex-rds]]与[[respiratory/respiratory-failure]]。胸膜压：低于大气压，在肺向上回缩与胸壁向外的地方之间；它的改变（用食管的气囊来估计）会解释静脉的回流与心包（[[cardiovascular/cardiac-cycle]]）以及气胸的体征[[#ex-pneumo]]。所有这些就是为什么一个呼吸的生理学者会说：容积就是平衡，而流量就是限制[[respiratory/gas-exchange]]。**
:::

::: example 过早的呼吸 {#ex-rds}
在28周出生的一个婴儿在出生后立即出现呼吸的急促与回缩和鼻翼的扇动；气体显示出低氧与二氧化碳的正常，以及胸片显示出弥漫的网点与支气管的空气的征象。
::: solution
**表面活性物质的缺乏（早产儿呼吸的窘迫）（[[#def-volumes]]）：没有被调节的表面的张力，小的肺泡会塌陷（拉普拉斯），所以顺应性会下降（僵硬的小肺），功能残气会崩溃，通气会被不均一地分布，而分流会造成低氧；上皮与内皮的损伤会渗出纤维性的膜（玻璃样质的膜）。体征就是这个力学：回缩（一个低顺应性的肺需要大胸内的压力）与鼻翼的扇动与呻吟（一个被部分关闭的声门会把呼气末的正压维持在闭合的容量之上，把功能残气保留[[#ex-rds]]）。管理：产前的类固醇（二型细胞的成熟）；外源性的表面活性物质与温和的压力的通气（鼻的持续的压与需要插管病例肺保护的策略[[respiratory/respiratory-failure]]、[[paediatrics/newborn]]）；以及支持与体温与葡萄糖[[paediatrics/acute-childhood-illness]]。同一个的物理学会以一个失活的形式在成人窘迫中回来（蛋白的失活与水肿的液体）[[respiratory/respiratory-failure]]。**
:::
:::

## 流量与阻力及呼气的限度

::: definition 气道与驱动的压力及动态的压缩 {#def-flow}
**流量等于压力的差除以阻力。阻力取决于气道的半径的四次方（泊肃叶）：在层流的段，阻力与气体的粘度成正比；而在快速的上游的和狭窄的段接近湍流（密度的依赖）——这就是为什么氦（低密度）在大气道的梗阻中有用而在小的气道的疾病中没有用[[#ex-asthma-mechanics]]。气道：在段到段的总横截面积上升，所以大部分阻力在上气道与段的支气管；小的气道是沉默的区域（早期阻塞的病变只在流量的末端部分显现[[respiratory/control-breathing-tests]]）。张力会减少阻力（肺的牵张会使气道张开），而这也就是为什么功能残气会高时气流会更快，而患者的呼气末的唇会把压力保持。呼气是力学的把戏：用力呼气会升高胸膜的压力，这会推动气道，而在一个相等压的点下游，跨壁的压力会转为负，气道会压缩，流量成为努力独立（这个呼气峰流量就是弹性回缩与气道的特性的一个函数，而不是肌肉的功率）。这就是为什么阻塞会在流量-容量的曲线上读出来（呼气的支的凹陷）与为什么FEV1对FVC的比率会下降[[#ex-asthma-mechanics]]、[[respiratory/asthma-copd]]；而动态的压缩也是气体的陷闭的机制：在严重的发作与慢阻肺中，提前的气道关闭会留下空气（内在呼气末的正压[[#ex-copd-mechanics]]、[[respiratory/respiratory-failure]]）。咳嗽就是同一个的物理学被利用：一个深的吸气、声门的关闭和用力的呼气对着一个被关闭的声门，然后爆炸性的开放（流量会取决于气道的顺应性与分泌物：扩张的支气管与纤毛的运动障碍会损害这一部分[[respiratory/respiratory-infections ]]）。**
:::

::: example 哮鸣与矛盾的体征 {#ex-asthma-mechanics}
一位哮喘的人在恶化后坐着不动并呼气时嘴唇被撅起；呼吸的音几乎听不见，而哮鸣已经停止；脉搏为110，而峰值流量是无法测量的。
::: solution
**一个接近沉默的胸就是危险的体征：当一个气流变得如此之少以致无法产生湍流的声音时，阻塞会加重（[[#def-flow]]、[[respiratory/asthma-copd]]、[[emergency-critical-care/acute-assessment]]）。机制：宽的平滑肌与水肿和黏液的栓子会降低半径（阻力与四次方），而动态的压缩会把小的气道提早关闭；嘴唇被撅起会通过把下游的压力提高来对抗（一个生理性呼气末的正压），而辅助的肌肉和一个前倾的姿势会增加压力并稳定胸壁。急的行动：氧气、吸入的β二激动剂（重复的或连续的雾化与定量吸入器的多个剂量）、全身激素（起效的小时，所以要早期）、异丙托溴铵在严重的病例中、静脉的镁；以及气体（二氧化碳的正常在窘迫的人中是警告，而不是安慰）[[respiratory/respiratory-failure]]。升级：无创的/插管带专家（一个被阻塞的患者的通气的策略：低的频率与长的呼气的时间来避免气压和动态的陷闭[[emergency-critical-care/airway-ventilation ]]）；张力性气胸与其他的原因的排除。随后的：被写的计划与控制被重新检查[[respiratory/asthma-copd]]。**
:::
:::

::: definition 功、呼吸的模式与呼吸困难 {#def-work}
**呼吸的功被分成弹性的（把肺与胸壁拉伸；在限制性的疾病与肥胖和中高的分钟通气量时会上升）、阻力的（把气流推动；在阻塞中上升），以及阈值的（肌肉负荷的启动；在过度的充气中上升，因为膈肌在一个被缩短的位置上运作）。一个经典的优化Otis)：在弹性的负荷与阻力负荷之间最小化功的呼吸的频率与深度：纤维化（高弹性）会选择快速的浅的呼吸，而阻塞（高阻力）慢的深的（[[#ex-copd-mechanics]]和练习）。膈肌是主要的吸气：它在一个扁平的位置（过度的充气）和在腹部的内容物（肥胖与腹胀[[gastrointestinal/clinical-nutrition ]]） 与在神经肌肉的疾病（[[nervous-system/neuromuscular]]、[[nervous-system/motor-systems]]）中会处于不利；辅助的（胸锁乳突肌与斜角肌与肋间的）会加入，而它们的使用就是临床的体征。呼气在休息时是被动的；在用力时它是腹肌（这些会损害上气道的引流并会升高胸内的压力[[cardiovascular/circulation-blood-pressure]]）。呼吸困难就是感知：呼吸的努力（来自运动中枢的拷贝）与传入的反馈（肺的牵张与胸壁与化学的）之间的不匹配（伴随放电）；这就是为什么相同的一个数字会感觉不同（焦虑与训练和阿片类[[nervous-system/headache-pain ]]），以及为什么治疗会既有机械的（姿势与风扇的气流与呼吸的策略、氧气在低氧中的）又有情感的/认知的（呼吸的管理与姑息的阿片类在难治的呼吸困难[[geriatrics-palliative/symptom-control]]、[[psychiatry/anxiety-disorders ]]）。急的图形：肺栓塞（死腔与快速的呼吸）与气胸[[#ex-pneumo]]与心衰（间质的感受器）[[cardiovascular/heart-failure]]；慢性的：疾病本身与肌肉和去适应[[respiratory/interstitial-vascular-disease]]、[[respiratory/respiratory-failure]]。**
:::

::: example 在楼梯上的喘不过气的吸烟者 {#ex-copd-mechanics}
一位有慢阻肺的68岁的人在平地上尚可，而在楼梯上会呼吸急促并撅起嘴唇；唇与呼吸的频率高；体检显示出过度的膨胀与减弱的气流音。
::: solution
**一个动态过度充气的演示（[[#def-flow]]、[[respiratory/asthma-copd]]）：在运动中，呼吸会加快而呼气的时间会缩短；一个被损害的气道会提前关闭，所以每个呼吸会留下更多的空气——功能残气会上升到接近总量的容量，膈肌会扁平（一个机械的劣势）、弹性的负荷会上升，而相同的分钟通气会需要多得多的努力（呼吸困难）。嘴唇被撅起会产生下游的压力，把气道撑开并会减少陷闭；撅唇的呼吸是被教的策略之一。管理：支气管扩张剂（抗胆碱与β激动剂；在反应时的剂量和装置的训练[[respiratory/asthma-copd]]、[[pharmacology/autonomic-drugs ]]）、肺的康复（最有力的症状的干预，尽管数字会不动[[public-health/prevention-promotion]]）、急性加重的计划（激素与抗生素与无创的通气[[respiratory/respiratory-failure ]]）、氧气的规则（在危险的二氧化碳潴留者中的可控的目标[[respiratory/respiratory-failure]]）以及手术的/容量减少的选择在选中的；以及戒烟（最重要的一个[[public-health/prevention-promotion]]）。图形会显示过度充气的容积（残气与比率升高）与氦对照体积描记的差距（气体的陷闭[[#def-volumes ]]）。**
:::
:::

::: example 突然的疼痛与消失的气流音 {#ex-pneumo}
一位高而瘦的22岁的人在咳嗽的之后突然出现右侧胸痛与呼吸困难；右侧的气流音消失，而气管被居中；在呼吸时胸部的运动减少。
::: solution
**一个自发的气胸直到被证明别的（[[#def-volumes]]、[[respiratory/lung-cancer-pleura]]）：胸膜腔的气体会把负压消除，所以肺会向内塌陷，而胸壁不再被耦合（消失的气流音与鼓音和减少的运动；一个张力性的气胸会把气管推开并会造成低血压[[emergency-critical-care/acute-assessment]]、[[emergency-critical-care/airway-ventilation ]]）。管理按大小与生理：观察（一个小的、稳定的）；抽吸（一个第一个的发作与症状）；或胸管（失败/复发/双侧或机械通气；一个张力性的气胸就是立即的减压紧急）[[emergency-critical-care/airway-ventilation]]、[[surgery/wounds-surgical-infection]]。鉴别：肺栓塞与气道的异物和气道的阻塞[[respiratory/interstitial-vascular-disease]]。提醒：胸片会低估大小（在呼气时的胶片与侧位的）与CT在复杂的中；复发是常见的（手术的建议：胸膜的固定与肺大疱的切除[[surgery/vascular-urological-surgery ]]）；以及在康复期间飞行的规则与驾驶[[public-health/environmental-occupational]]。**
:::

::: quiz
最大的呼气流量会成为努力独立的，因为：
- [ ] 呼气的肌肉会以可预测的率疲劳
- [x] 下游的气道会在相等的压的点经历动态的压缩，所以额外的努力会把驱动与压缩的压力等量地升高
- [ ] 膈肌在呼气时不能收缩
- [ ] 气道的阻力在所有容积时都是恒定的
::: solution
**在相等的压的点之后，进一步的努力会把下游的气道压得更闭，所以压力会升高而流量不会：这就是为什么流量-容量曲线的呼气支是努力独立的平台，以及为什么努力依赖的部分是吸气的（[[#def-flow]]、[[respiratory/control-breathing-tests]]）。**
:::

**机器的实验与一个世纪的支持肌肉驱动吸气的辩论；风箱的复苏与呼出的空气的化学（氧与二氧化碳的记账）；泊肃叶管流的定律与气道的四次方；球体的定律（1805）被应用于肺泡，以及表面活性物质发现的时代（1929年的表面张力的提议与1954年及1957年的低张力的证明，以及缺失它的婴儿）；身体的体积描记把 trapped 的气体变得可测量（氦与压力的方法）；努力独立流量的发现与水力学的模型（动态的压缩与相等的压的点）；以及呼吸模式的功的最小化与呼吸困难作为感知的现代工作（伴随放电与传入的不匹配）[[respiratory/control-breathing-tests]]、[[respiratory/respiratory-failure]]。**

## 通向何处

气体与它们的交换在[[respiratory/gas-exchange]]；测量与图形在[[respiratory/control-breathing-tests]]；阻塞的疾病在[[respiratory/asthma-copd]]；限制的在[[respiratory/interstitial-vascular-disease]]；急的图形在[[emergency-critical-care/acute-assessment]]与[[respiratory/respiratory-failure]]；胸膜在[[respiratory/lung-cancer-pleura]]；肌肉与神经在[[nervous-system/neuromuscular]]；以及高原的环境在[[public-health/environmental-occupational]]。

::: summary
- 肺的容积与顺应性就是平衡与这些能量的测量；功能残气会设定气体的缓冲与肌肉的运作的长度，而氦对体积描记气体陷闭的差距会把气体的陷闭量化。
- 表面活性物质会使得低压力及拉普拉斯稳定的肺；它的缺乏（早产与失活）会把表面的物理学变成塌陷与僵硬的肺及分流。
- 最大的呼气流量是努力独立的：回缩驱动它，动态的压缩限制它，而流量的环与比率读取它——哮鸣与氦氧及撅唇与内在的呼气末的正压全都是密度与瀑布的现象。
- 呼吸的模式就是功的最小化，由一个肌肉的层级执行，而它们的劣势（过度的充气与肥胖和疲劳）是呼吸困难一个主要的产生者。
- 呼吸困难是一种从伴随的放电对照传入的反馈的感知：被机械驱动、被情感调节，并可以在这两个轴上被治疗。
:::

::: exercise 两个功能残气 {level=1}
氦稀释的功能残气2.1升，而体积描记的功能残气在慢阻肺患者中为4.4升。解释这个差距与它的临床的用途。
::: solution
**氦（或氮的冲洗）只能通过被通气的空间来平衡，而体积描记会测量所有被压缩的气体：一个上升的差距意味着被通气的与被测量的空间之间的差异——气体的陷闭（[[#def-volumes]]、[[respiratory/asthma-copd]]）。用途：量化过度充气（肺容量的减少与手术的/容量减少的决定）；追踪发作（一个在哮喘的恶化时上升的陷闭[[respiratory/asthma-copd]]）；并解释症状（一个被陷闭的患者的呼吸困难，尽管气体交换尚可）。陷阱：漏与长的平衡的时间会误导氦；而一个孤立的大的差距会在肺大疱中[[respiratory/lung-cancer-pleura]]。**
:::

::: exercise 为什么快速而浅，为什么慢而深 {level=2}
用功的分解与这个最优化的论证，解释为什么间质的纤维化与哮喘会推动相反呼吸的模式，以及为什么每个模式会在它的极端处失败。
::: solution
**功会把弹性的（把僵硬的肺拉伸）与阻力的（推动气流）分开，而个体（在频率与深度之间）会最小化总和的功（[[#def-work]]）。纤维化（高弹性、低顺应性、快速回缩）：因为每次大的呼吸会花费太多弹性的功，模式会变成快速而浅；在极端时，死腔的 ventilation 会上升，而气体交换会恶化并肌肉会疲劳。哮喘（高阻力、时间依赖的充气）：深的慢的呼吸会改善在狭窄气道中的填充并会允许完全的呼气；在极端时，动态的过度充气与内在的呼气末的正压会造成肌肉的不利及危险[[#ex-copd-mechanics]]、[[respiratory/asthma-copd]]。提醒：快速的浅的图形也会出现在肥胖与肌肉的无力中（一个机械的而不是弹性的原因）[[nervous-system/neuromuscular]]。**
:::

::: exercise 读环 {level=2}
描述流量对容量的环的形状：(a) 固定气管的狭窄，(b) 可变的胸外的梗阻，(c) 严重的驼背侧弯，以及每一个的一个原因。
::: solution
**（a）吸气的与呼气的平台的都被削平（一个固定的限制）：瘢痕的狭窄与插管后的[[respiratory/lung-cancer-pleura]]、[[surgery/anaesthesia-pain]]；（b）只在吸气时削平（胸外的气道在吸气时塌陷）：声带的运动障碍与喉的软化[[paediatrics/newborn]]、[[nervous-system/motor-systems]]；发作与喘鸣被误认为哮喘[[respiratory/asthma-copd]]；（c）一个缩小环伴保留的形状（一个外部的限制）：胸壁的疾病[[#def-work]]。实践：环的形态会引导检查（胸外的疾病会需要喉的评估与流量的环的重复）[[respiratory/control-breathing-tests]]。**
:::

::: exercise 不会膨胀的胸 {level=2}
一位被通气的哮喘患者的平台压为44，而呼气末的阻断显示出12的内在呼气末的正压。分离出高压力中的顺应性与阻力及过度充气的成分，以及呼吸机与患者的动作各自会应对什么。
::: solution
**峰压减去平台压就是阻力（狭窄的气道与分泌的和管道的局限）；而平台压减去内在呼气末的正压就是弹性的（一个被过度充气的胸与肺会使其上升，而气胸会[[#ex-pneumo]]）。所以：把支气管扩张剂与吸气的时间（阻力）、过度的充气（把呼吸的频率降低以允许呼气，并把外在的呼气末的正压上调以触发被触发的呼吸）以及真实的顺应性（潮气量更小与胸壁的问题）分开[[respiratory/respiratory-failure]]、[[emergency-critical-care/airway-ventilation]]。动作：更低的频率与更长的呼气与更小的呼出的流量、支气管扩张剂与激素、深度镇静/肌松（在这些不能被同步的人中），以及在气体陷闭时有控制的过度通气（允许的高的二氧化碳）；以及气胸的排除（突然上升的压力与这些不对称的音）[[emergency-critical-care/airway-ventilation]]。目标：一个低于30的平台压与血流动力学，而不是正常的数字[[respiratory/respiratory-failure]]。**
:::

::: exercise 量化呻吟 {level=2}
把一个婴儿的呻吟与点的头以及锯式的呼吸解释为力学的体征，并说明每一个会暗示什么失败的成分。
::: solution
**呻吟就是呼气时的声门的部分关闭：一个婴儿自发呼气末的正压，会把功能残气保持在闭合的容量之上（在表面活性物质缺乏中塌陷的失败[[#ex-rds ]]）。头点动就是当一个膈肌无法克服弹性的负荷时辅助肌肉的绝望（颈部肌肉以头部作为支点在点头：一个功率对负荷的失败[[#def-work]]）；以及锯式的（胸腹的）呼吸就是膈肌的反转的运动：它会把胸廓向内拉，因为它的长度与张力已不足以把把膈肌下压（一个膈肌的失败，如在严重的过度充气或肌病中）[[nervous-system/neuromuscular]]。含义：这些是即将失败力学的体征（不是呼吸的频率）：它们要求在分钟内的升级与专家（[[paediatrics/acute-childhood-illness]]、[[emergency-critical-care/airway-ventilation]]）以及把原因（表面活性物质与气道和肌肉）针对的治疗[[paediatrics/newborn]]。**
:::

::: exercise 密度、高原与氦的问题 {level=2}
氦氧（70:30）会在a) 严重的哮喘、(b) 固定气管的狭窄、以及c) 气肿的小气道疾病中改善流量，但是不平等的。按获益排序，并用两个流量的定律与密度与粘度的物理学为之辩护。
::: solution
**排序：（b）最大（一个大的、湍流的梗阻：流量会随密度的平方根，所以把密度降低会直接增加它）；(a) 中等（混合的段与湍流的狭窄，加上分泌的廓清和功的获益）；（c）最小（小的气道泊肃叶的流动取决于粘度，而氦会提高一点粘度，几乎无益）[[#def-flow]]、[[#ex-asthma-mechanics]]。实际的：混合的70:30（低的氧气的分数在低氧危险的患者中要避免）与高流量的需求；上气道的病变是最被受益的（肿瘤与狭窄[[respiratory/lung-cancer-pleura]]）；证据是温和的，所以这是一个桥梁的治疗[[emergency-critical-care/airway-ventilation]]。高原：更低的密度与更低的分压两者都会改变流量与氧合（[[public-health/environmental-occupational]]与[[public-health/global-health]]）。**

::: exercise 设计呼吸困难的门诊 {level=3}
为一个慢性的呼吸困难构建一个诊断与管理的路径，尊重本章的力学与感知的双重性：测量的层次、模式识别的步骤、对症与疾病特异的轴，以及伦理的防护。
::: solution
**层次：（1）常见的（血气与胸片和肺功能与环和血液的[[respiratory/control-breathing-tests]]）；（2）机制的（完整的容积与弥散与激发/舒张与心肺的运动测试，它会把心脏与肺与肌肉/循环分开[[respiratory/gas-exchange]]、[[cardiovascular/heart-failure]]、[[blood/anaemia]]）；（3）感知的（呼吸困难量表与焦虑与抑郁[[psychiatry/anxiety-disorders]]、功能与睡眠[[respiratory/respiratory-failure ]]）。模式：阻塞与限制与血管和代谢的（贫血与甲状腺[[endocrine/thyroid]]）以及心（钠尿的肽[[cardiovascular/heart-failure ]]）。轴：疾病特异的（吸入的和系统的）加上症状的：肺的康复与呼吸的策略、姿势和风扇、氧气的在低氧中、阿片类在难治的（[[geriatrics-palliative/symptom-control]]、[[respiratory/respiratory-failure]]）、焦虑的认知；以及高级的照护的计划与目标[[geriatrics-palliative/end-of-life-care]]。伦理：不要在低氧时拿走氧气，而在非低氧时不要给出一个获益的神话；公平的访问（设备的训练与翻译[[public-health/determinants-inequalities]]）；以及审计（症状量表的变化与住院）。**
