通气是回应两个主人的自主系统：脑干代谢的控制器（一个调节脑脊液与动脉的氢离子的负反馈的环，主要通过二氧化碳，而外周的氧的感受器作为紧急的输入），以及皮层（它会唱歌与说话并屏住呼吸并恐慌并逆着意志呼吸）。几乎每一个异常呼吸的模式就是这个环的参数被看见，或被测试暴露[[physiology/integrative-physiology]]。

本章涵盖节律的产生、化学感受器的弧与它们的相互作用、控制临床的检查，以及睡眠的呼吸的疾病。

## 发生器与它们的反馈

::: definition 节律的产生与行为的覆盖 {#def-rhythm}
**节律来自脑干的网络：前包踢的复合体（抑制网络的爆发）与腹侧呼吸的群的吸气与呼气的神经元，被递质（血清素与去甲肾上腺素及肽）调节，把膈肌与肋间和喉的驱动把输出[[physiology/membrane-potentials]]、[[physiology/synapses]]。行为的双重的路径：皮层（运动的纤维会绕过节律的网络：这就是为什么这些会说患者会呼吸，即使在双侧脑干的损伤中——以及为什么我们会自愿地过度通气或屏气，而一个被自愿停止的呼吸会以二氧化碳驱动自动的恢复结束[[nervous-system/motor-systems ]]）；以及边缘与情感的输入（疼痛与焦虑和恐慌会驱动通气[[psychiatry/anxiety-disorders ]]）。反射会塑造模式：肺的牵张的（在大的容积时被迷走的传入阻断吸气——在正常的成人中作用小），刺激的（上气道会保护气道：咳嗽与吞咽及喉的关闭[[surgery/anaesthesia-pain ]]），以及本体感受的（在运动时的肢体会驱动通气）。临床的综合征：先天性中枢肺泡的低通气（肽的基因突变：一个在睡眠中的化学感受器的失败[[paediatrics/newborn]]、[[genetics/mendelian-inheritance ]]）；脑干的卒中与畸形（[[nervous-system/stroke]]、[[nervous-system/sensory-systems]]）以及晚期的神经肌肉的疾病中睡眠先兆的下降[[nervous-system/neuromuscular]]。**
:::

::: definition 化学感受器的弧 {#def-chemo}
**中枢的化学感受器（在延髓的表面）会被氢离子刺激，而氢离子来自二氧化碳会跨过血脑屏障扩散：这就是为什么动脉的二氧化碳是通气的主要的调节器（在这个环内几乎线性的，在阈值之上），以及为什么氢离子本身不会跨过（所以代谢的酸中毒会通过动脉的变化被感觉到，而脑脊液会缓慢地跟随，通过碳酸氢盐的排泄[[renal/acid-base-disorders ]]）。外周的（颈动脉体，通过窦的神经；主动脉的）是氧气（低氧的敏感器）以及急性酸碱变化唯一的感受器：它们会在动脉氧气低于约60毫米汞柱/8千帕时驱动通气，并且是慢性低氧的适应（高原与肺疾病的红细胞增多[[blood/anaemia]]、[[public-health/environmental-occupational]]）与急性对氧气反应的基础[[respiratory/gas-exchange]]。二氧化碳的曲线：高碳酸会把通气的驱动成倍升高（上方的曲线）；而低碳酸（焦虑的过度通气和医源性的）会把呼吸的驱动降到在意识丧失之下的水平（自愿过度通气的晕厥[[psychiatry/anxiety-disorders]]、[[nervous-system/stroke ]]）。状态依赖：在睡眠中，行为性的输入会消失，而呼吸会被代谢的控制所统治：这就是为什么环的缺陷（肥胖与阿片类和先天性）会在睡眠中变得明显，而呼吸的事件会首先在那里出现[[respiratory/respiratory-failure]]。阿片类会把弧的增益降低（μ受体在网络中），这是呼吸的抑制的机制，被纳洛酮所逆转[[emergency-critical-care/poisoning]]、[[surgery/anaesthesia-pain]]。**
:::

::: example 渐强渐弱的呼吸 {#ex-cs}
一个有心衰的人会在睡眠中交替出现逐渐加深又变浅的呼吸与十二秒的暂停，而白天二氧化碳为4.0千帕；气体显示出低碳酸血症。
::: solution
**潮式呼吸（中枢睡眠呼吸的事件）（[[#def-chemo]]、[[#def-rhythm]]）：在环的延迟（一个被延长的循环的时间）与化学感受器的增益上升以及低于阈值的二氧化碳时，肺泡的二氧化碳会在过度通气的峰值之后越过阈值，产生周期性的振荡；在心输出量低的人中时间会延长（中枢循环的时间）[[cardiovascular/heart-failure]]。线索：二氧化碳低（不是潴留者的图形）与被配偶报告的暂停、觉醒和白天疲劳；在卒中与肾的衰竭及阿片类（混合中枢的图形）中[[nervous-system/stroke]]、[[renal/chronic-kidney-disease]]、[[emergency-critical-care/poisoning]]。含义：在心衰中它标记着不良的结局；治疗就是这个基础（利尿与设备的调整和药物的最优化）与呼吸的事件的治疗：正压（自适应伺服的谨慎在高驱动的图形中）与氧气在低氧中，带在二氧化碳上升者的谨慎[[respiratory/respiratory-failure]]。驾驶规则与阿片类的审查[[geriatrics-palliative/polypharmacy]]。**
:::

::: example 会停止呼吸的婴儿 {#ex-ondi}
一个足月的新生儿在监测上有两次伴去饱和且没有努力呼吸的暂停；在两次之间他会正常吃奶和哭，而发作会在睡眠中复发；母亲回忆说他从出生后睡着时就没有正常呼吸过。
::: solution
**一个先天性中枢肺泡的低通气（呼吸节律的基因突变——呼吸节律的化学感受器的缺陷）（[[#def-rhythm]]、[[#def-chemo]]）：在睡眠中，行为性的通气消失，而代谢的控制失败，而暂停没有努力（中枢的，而不是阻塞的[[paediatrics/newborn]]、[[genetics/mendelian-inheritance ]]）。检查：在睡眠中的监测与气体/经皮的二氧化碳（在清醒时正常婴儿中高的二氧化碳）、其他的原因（代谢的与神经肌肉的：脊髓性肌萎缩症[[nervous-system/neuromuscular]]、脑干的畸形[[nervous-system/sensory-systems]]、感染[[infectious-diseases/tropical-infections ]]），以及基因的检测。管理：呼吸的支持（在睡眠中膈神经的刺激或压力通气，随着变化）与家庭的监测与急救的计划[[paediatrics/acute-childhood-illness]]、[[respiratory/respiratory-failure]]。提醒：被报告的发作在睡眠中需要客观的评估；以及兄弟姐妹的筛查和遗传的咨询[[medical-ethics-law/consent-capacity]]。**
:::
:::

::: definition 测试控制器与睡眠的气道 {#def-tests}
**静息的气体（一个正常的二氧化碳不排除一个被损害的控制器：它只是这个环的当前的输出；要看储备就要挑战它[[#ex-normal-co2 ]]）、经皮/呼气的二氧化碳（在睡眠呼吸的疾病与在儿科的在趋势中的连续）；化学感受器的反应（二氧化碳的曲线：这个斜率与阈值，在研究和特殊的诊断中；低氧的反应[[respiratory/gas-exchange]]）；呼吸的 efforts 与气流（在中枢对阻塞的事件中呼吸的努力带胸腹的绑带与气流的传感器的波形）；以及睡眠的研究（家庭的多导睡眠监测：气流与努力及饱和，在简单的气道疾病中足够；被记录的多导睡眠监测：脑电与眼动与肌电会捕捉 arousals 与周期性的肢体运动[[respiratory/respiratory-failure ]]）。评分：呼吸暂停与低通气的每小时事件（5/15/30与饱和的下降和 arousals 的等级）；睡眠相关低通气的综合征（在睡眠中的高的二氧化碳而无事件：肥胖、神经肌肉病与基因性的低通气[[nervous-system/neuromuscular]]、[[renal/chronic-kidney-disease ]]）。辅助（ sniff 的压与膈肌的超声与运动神经对膈肌的研究、最大 pressures 与经皮的胃的二氧化碳）会评估泵而不是控制器[[nervous-system/neuromuscular]]、[[respiratory/control-breathing-tests]]。**
:::

::: example 驾驶员的女儿 {#ex-blackout}
一位21岁的人在自由潜水时浅水的昏厥之后被带来；她的同伴说她每次潜水前都会做二十次快速的呼吸；她在水面上一分钟内恢复，而现在意识混乱。
::: solution
**一个被自愿过度通气造成低氧的昏厥：快速的呼吸会把二氧化碳（呼吸暂停阈值）降到很低而氧气几乎不增加（血红蛋白已经接近饱和[[respiratory/gas-exchange]]），所以低氧会在水下、在二氧化碳会强制呼吸之前到达意识的丧失——一个被人为地把警报移除传感器的问题（[[#def-chemo]]、[[#def-rhythm]]）。后果：溺水/缺氧的损伤与癫痫样的动作（不要在水下救人时把当作癫痫[[nervous-system/epilepsy]]）以及第二次潜水时的淹溺。管理：气道与氧气和气体、神经的评估与并发症（吸入的肺炎[[respiratory/respiratory-infections]]、气压伤[[respiratory/mechanics-breathing]]）与观察（一个被恢复的昏迷需要专家）[[emergency-critical-care/acute-assessment]]。预防：不要过度通气，要有伙伴，以及被认证的课程——被教授的警告。**
:::
:::

::: example 正常的二氧化碳 {#ex-normal-co2}
一个重症哮喘的人已呼吸困难14小时；呼吸32，脉搏的反常 20，在高流量的氧气上饱和91%；气体：酸碱度7.38，二氧化碳5.3，氧气9.8。
::: solution
**在一个严重的、长时间努力通气的哮喘中一个正常的二氧化碳就是衰竭的体征，不是安慰：患者应该带着呼吸的急促而低碳酸，所以一个正常值意味着肌肉的疲劳与即将的停止（[[respiratory/asthma-copd]]与[[#def-chemo]]）。行动：把重症的哮喘的治疗（重复的β激动剂与激素和镁）强化，并把插管的标准被决定，带专家在场[[emergency-critical-care/airway-ventilation]]、[[respiratory/respiratory-failure]]；一个上升的二氧化碳或酸中毒的加重（这里酸碱度7.38与一个相对高的二氧化碳）会迫使决定。陷阱：一个看起来交谈的患者与一个被测量的正常的数字会推迟升级；一个疲劳的患者不会发出声音[[emergency-critical-care/acute-assessment]]。**
:::

::: history
**十九世纪延髓切片呼吸的准备与二十年代把呼吸的中枢按顺序排列的实验；反射（1868）与它们的二十世纪临床的解剖；颈动脉体的生理学（1938年的诺贝尔奖）与单个的化学感受器单位的记录（六十年代），以及球的细胞的氧的感受通道的生物学（九十年代与时代的实验室）；中枢的化学感受器与二氧化碳/氢离子的通道（对气体敏感的通道）；睡眠呼吸的疾病从被报告的严重的打鼾的综合征到被评分的研究、正压的治疗以及一个药物治疗的新的时代[[respiratory/respiratory-failure]]；以及先天性的低通气的综合征的基因（肽的基因与通道的疾病）把控制变成分子[[genetics/mendelian-inheritance]]、[[paediatrics/newborn]]。**
:::

## 通向何处

气体的后果与交换的算术在[[respiratory/gas-exchange]]；肌肉与泵在[[respiratory/mechanics-breathing]]与[[nervous-system/neuromuscular]]；疾病与气体在[[respiratory/asthma-copd]]与[[respiratory/respiratory-failure]]；药物对弧的抑制在[[surgery/anaesthesia-pain]]与[[emergency-critical-care/poisoning]]；心脏的循环在潮式呼吸中在[[cardiovascular/heart-failure]]；肥胖的代谢在[[endocrine/diabetes]]；而高原在[[public-health/environmental-occupational]]。

::: summary
- 节律的产生是脑干的模式的发生器的产物（爆发的网络），被脑桥与状态及情感和自愿的覆盖所塑造——这就是为什么呼吸的暂停会在睡眠中生活，而歌曲会在清醒中生活。
- 二氧化碳（通过脑脊液的氢离子）是被调节的主要的变量；外周的颈动脉体是唯一的有意义的氧的感受器，并与二氧化碳的反应相乘地相互作用；环的阈值与增益就是每一个疾病和药物会移动的变量。
- 周期性的呼吸（潮式的与高原的及过度通气之后的）就是同一个高增益、延迟反馈的环，而它们的治疗会跟随环的参数。
- 睡眠呼吸的疾病是一个在睡眠中解剖的疾病，带有全身交感的与心脏的后果；诊断就是被评分的研究，而治疗跨越体重与设备以及新的药物。
- 控制器是可检查的（气体与二氧化碳的曲线、睡眠的研究，以及肌肉的辅助）也是可被操作的——通过药物与高原及训练，而自由潜水的被操作的传感器的昏厥就是警示的故事。
:::

## 练习

::: exercise 读气体 {level=1}
酸碱度7.31，二氧化碳9.2，碳酸氢盐34，碱的剩余正9，氧气7.5，在空气中。完整地解读并命名两个最可能的慢性的设置。
::: solution
**一个高碳酸呼吸性的酸中毒伴一个代谢的（肾的）补偿（一个上升的碳酸氢盐与一个接近但不正常的酸碱度：慢性的或急性在慢性上的潴留[[renal/acid-base-disorders]]、[[respiratory/respiratory-failure]]），加上低氧。设置：一个慢阻肺的潴留者[[respiratory/asthma-copd]]；以及一个肥胖低通气的综合征/一个睡眠呼吸的疾病[[#def-tests]]或一个神经肌肉的（[[nervous-system/neuromuscular]]）。行动：不要仅凭一个正常的酸碱度放心；治疗会避免把氧气推到会移除低氧驱动的水平（滴定[[respiratory/respiratory-failure]]）、寻找这些可逆的加重（感染与痰[[respiratory/respiratory-infections]]）、以及考虑通气的支持在酸血症时[[emergency-critical-care/airway-ventilation]]。**
:::

::: exercise 反射的弧 {level=1}
陈述肺牵张的反射与颈动脉的化学感受器低氧反射的感受器与传入和效应，以及每一个会占主导的一个临床的情形。
::: solution
**肺的牵张：感受器在支气管与肺泡的平滑肌中，迷走的传入，效应就是吸气的抑制（在大容积时的刹车）：在正常的成人中弱，而在小的肺的新生儿/在高气道压力的通气中更有意义[[respiratory/mechanics-breathing]]、[[paediatrics/newborn]]；在呼吸的调节中它更多在动物的模型里而不是在床边。低氧的反射：球（颈动脉体）通过窦的神经到呼吸的网络，效应就是通气增加与交感的输出及心率的变化[[#def-chemo]]：在急性低氧与高原和低氧的发作（睡眠事件与早产的呼吸的暂停）中占主导[[#ex-ondi]]、[[public-health/environmental-occupational]]；而在慢性低氧中反应会被调节（习服）。**
:::

::: exercise 环的参数 {level=2}
对于每一个（阿片类的过量与心衰的潮式呼吸、妊娠、以及肥胖的低通气）命名被移动的参数（阈值与增益及斜率、受影响的对象）与被预测的二氧化碳的曲线的转移。
::: solution
**阿片类：这个阈值被升高，而斜率/增益被降低（曲线向右下方[[#def-chemo]]）：患者在正常二氧化碳下会通气不足并在睡眠中会停止[[emergency-critical-care/poisoning]]。心衰的潮式呼吸：增益与延迟（循环的时间）上升（一个被陡峭化的线，被振荡）[[cardiovascular/heart-failure]]、[[#ex-cs]]。妊娠：孕激素会提高对二氧化碳的敏感性（斜率上升、阈值下降）：低碳酸血症的正常与对变化的储备更浅[[obstetrics-gynaecology/pregnancy-antenatal]]。肥胖的低通气：一个正常的中枢被负荷（胸壁的力学）与被钝化的反应所覆盖（在部分人中瘦素的抵抗）：曲线的斜率会低，而睡眠的事件会与高的二氧化碳并存[[#def-tests]]、[[endocrine/diabetes]]。**
:::

::: exercise 为研究评分 {level=2}
家庭的多导睡眠监测：事件每小时24次，最低的饱和82%，没有脑电。同一个患者在一次六小时的被记录的研究中显示出每小时41次伴微觉醒。解释差距的机制以及它会改变什么。
::: solution
**家庭的设备会检测气流与努力（有时还有饱和），而在没有脑电时会漏掉微觉醒、周期性肢体的运动与睡眠的结构，并会低估混合的/中枢的事件和在REM中的事件（少的时间）：所以数字会低，尤其在以微觉醒 为主的患者中[[#def-tests]]。它会改变什么：严重度的分级会改变治疗的门槛与处方的紧迫；而临床的终点（白天嗜睡与风险）会指导，而不是这个数字；在持续的症状或合并症（高血压与心律）中，一次被记录的或治疗的研究就是路径[[respiratory/respiratory-failure]]、[[cardiovascular/hypertension]]、[[cardiovascular/arrhythmias]]。提醒：在设备的失败与依从性之后（被下载的数据），诊断会被重新检查[[clinical-skills/patient-safety]]。**

::: exercise 手术后的暂停 {level=2}
一个在手术病房上用吗啡的人呼吸率为7，二氧化碳的轨迹显示出上升呼气末端慢规则的波形，而易于被唤醒。解释为什么脉搏的氧计会保持正常，以及为什么可被唤醒不是安全。
::: solution
**因为氧气与二氧化碳被不同的机制调节：慢的通气会允许氮气被排出而氧气被补充的高的吸入的分数加载，所以饱和会保持正常，同时二氧化碳会积累（钝化的弧[[#def-chemo]]，一个延迟的警报[[emergency-critical-care/poisoning]]）。可被唤醒不是安全：一个被唤醒的患者会通气，然后会再次睡着——包括在监测的间隙——而二氧化碳会上升；而氧合的正常的数字会鼓励停止监测的决定[[clinical-skills/patient-safety]]。行动：持续的二氧化碳/经皮的监测或至少定期把唤醒并记录呼吸的率与镇静评分，带升级的阈值；纳洛酮的备用与被滴定重复的剂量（避开疼痛的危机与交感的激增[[surgery/anaesthesia-pain]]）；以及风险的政策（睡眠呼吸的疾病与阿片类的负荷与肾的功能[[pharmacology/dosing-principles]]、[[#ex-ondi]]）。**
:::

::: exercise 深大的呼吸与感受器 {level=2}
一个酮症酸中毒的一型糖尿病患者以32呼吸而无低氧。解释气体饥饿的算术、被预期的气体的图形（带呼吸代偿的上限）以及插管的危险。
::: solution
**代谢的酸中毒会通过动脉的氢离子（外周的感受器[[#def-chemo]]）刺激通气：呼吸是深而有力的（酸被二氧化碳被排出所缓冲），所以被预期的气体：一个低的酸碱度与一个低的碳酸氢盐和一个被恰当降低的二氧化碳（代偿的规则；一个不能下降的二氧化碳意味着肌肉的疲劳或一个叠加的肺的过程）[[renal/acid-base-disorders]]、[[endocrine/diabetes-complications]]。插管的危险：诱导会移除驱动，而患者会在插管的尝试期间无法维持分钟通气（酸会恶化），而在通气后不可能匹配补偿的二氧化碳（会需要高的分钟通气的设置）；此外容量与钾[[renal/potassium-calcium-phosphate]]。结论：酮症酸中毒的大部分会被液体与胰岛素治疗，而插管会被避免或带着对酸中毒的补偿被计划的最有经验的操作者[[emergency-critical-care/airway-ventilation]]、[[emergency-critical-care/critical-care]]。**
:::

::: exercise 设计保护控制器的镇痛 {level=2}
为一个接受大腹部手术的睡眠呼吸暂停的人写下围手术呼吸风险的计划：术前的评估与术中及镇痛的策略和监测，每一个都用本章为之辩护。
::: solution
**术前：识别与严重度/治疗（设备的继续使用在术前的夜晚与术后的夜晚[[#def-tests ]]）、肺功能与气体在怀疑的潴留者[[#ex-normal-co2]]、气道与肥胖的评估、以及计划（区域的技术与风险被讨论[[surgery/anaesthesia-pain ]]）。术中：避免长阿片类的负荷与残余的神经肌肉的阻滞（上气道会塌陷和反应会被钝化）、监测气道与唤醒（逆转移）[[emergency-critical-care/airway-ventilation]]。镇痛：把阿片类最小化的多模式（区域的硬膜外/平面的阻滞对胸段的会保留通气而控制咳嗽[[surgery/anaesthesia-pain]]、[[respiratory/mechanics-breathing]]）加对乙酰氨基酚和非甾体（在在肾的风险被允许时[[renal/acute-kidney-injury]]）。监测：在氧计之外二氧化碳和连续的监测在高风险者中、睡眠的位置（侧卧/头被抬高的）与设备、以及升级的规则[[clinical-skills/patient-safety]]、[[respiratory/respiratory-failure]]。**

::: exercise 喘不过气而检查正常 {level=3}
一位34岁的教师有18个月的对空气的饥饿与叹息及胸的紧束；带可逆性的肺活量与弥散及气体和血液、心电与超声和胸片的影像都正常；在症状期间二氧化碳的图显示出锯齿的图形。诊断并解释这个环，并给出治疗的计划与它的证据，包括转诊的安全。
::: solution
**功能性的呼吸的障碍（呼吸的功能性的障碍/过度通气的综合征）：二氧化碳图上锯齿的图形反映在叹息与波动的通气中的变化的模式；低二氧化碳与阈值下降的环的（焦虑与习惯）会造成空气饥饿与胸痛，而它们会在肺正常时被感觉到[[#def-chemo]]、[[psychiatry/anxiety-disorders]]、[[respiratory/mechanics-breathing]]。做法：命名（一个真实的、被理解的模式的障碍——不是想象的）、避免进一步的检查除非新的标志（贫血与心脏的[[blood/anaemia]]、[[cardiovascular/arrhythmias ]]）、以及治疗：呼吸的再训练（控制的呼吸与鼻的呼吸、横膈的技术与呼吸的模式的练习）带物理治疗、认知行为的技术对触发、以及合并症（哮喘会共存：不要移除吸入剂而不测试[[respiratory/asthma-copd]]）。转诊：呼吸生理的/言语治疗的项目与心理的服务；紧急的规则（真正的胸痛与晕厥[[emergency-critical-care/acute-assessment]]）。**
