呼吸是唯一一种终生自动运行、却又能随时由意志接管的生命功能。你可以屏气、唱歌或说话，一停下来，自动控制器就恢复工作。这个控制器在睡眠、运动和疾病中都能把动脉血二氧化碳维持在设定值上下零点几千帕之内。一旦它失灵，或被药物抑制，后果来得快而严重。

本章前半部分解释呼吸如何被调控：脑干的节律发生器、化学感受器和各种反射，以及阿片类药物中毒、氧疗所致高碳酸血症和睡眠呼吸障碍中出了什么问题。后半部分介绍用于测定呼吸功能的各项检查，从肺量计和弥散功能到血气和睡眠监测，以及如何判读。

## 呼吸控制器 {#sec-controller}

::: definition 呼吸调控系统的组成 {#def-control}
- **中枢模式发生器**：延髓中产生呼吸节律的神经元群。关键的节律发生部位是腹侧呼吸组中的**前包钦格复合体**（preBötzinger complex）。孤束核内的**背侧呼吸组**接收感觉传入。脑桥呼吸中枢使吸气与呼气之间的转换平稳。
- **感受器**：中枢化学感受器、外周化学感受器，以及肺和胸壁中的感受器。
- **效应器**：呼吸肌，主要是膈肌（膈神经，C3–C5）、肋间肌，用力时还有辅助呼吸肌和腹肌。
- **皮层控制**：随意呼吸（说话、屏气）由运动皮层直接投射到呼吸运动神经元，绕过脑干。
:::

自主通路与随意通路的分离在临床上是真实存在的。脑干的小卒中可以消除自主呼吸而保留随意呼吸，患者清醒时能呼吸，睡着后却停止呼吸。皮层病变则可产生相反的情况。

### 化学感受器

::: definition 中枢与外周化学感受器 {#def-chemo}
- **中枢化学感受器**位于延髓腹侧表面附近，对周围脑细胞外液的氢离子浓度起反应。二氧化碳可自由通过血–脑屏障，在那里生成氢离子；碳酸氢根和氢离子则通过缓慢。因此中枢化学感受器对动脉$P_{CO_2}$起反应，提供了正常呼吸驱动的大部分。
- **外周化学感受器**是**颈动脉体**（位于颈总动脉分叉处，传入纤维走行于舌咽神经）和作用较小的主动脉体（迷走神经）。它们对动脉$P_{O_2}$下降反应迅速，尤其是低于约8 kPa（60 mmHg）时，也对$P_{CO_2}$和氢离子浓度升高起反应。它们是唯一能感知低氧血症的感受器。
:::

两种反应相互作用。$P_{aCO_2}$超过某一阈值后，通气大致呈直线上升，这条直线的斜率（**高碳酸通气反应**）在同时缺氧时更陡。低氧反应在$P_{aO_2}$降到约8 kPa以下之前很小，之后急剧上升，与氧解离曲线的形状相呼应。因此，在海平面的健康人中，时时刻刻控制呼吸的是二氧化碳；只有在高原或疾病中，氧才成为主要刺激。

当$P_{aCO_2}$持续升高数天，如在重度慢阻肺或肥胖低通气中，肾脏潴留碳酸氢盐，脑脊液中的碳酸氢盐也随之升高。此时中枢化学感受器在较高的$P_{CO_2}$下感受到的是接近正常的氢离子浓度，其反应变得迟钝。控制器被重新设定了。

### 肺和胸壁感受器

- **肺牵张感受器**位于气道平滑肌中，经迷走神经传递肺扩张的信号。在动物中它们终止吸气（黑–伯反射，Hering–Breuer反射）；在成人中，该反射在正常潮气量下很弱。
- **刺激感受器**位于气道上皮，对烟雾、粉尘和冷空气起反应，引起咳嗽、支气管收缩和呼吸加快。
- **肺毛细血管旁（J）感受器**位于肺泡壁内，对间质水肿和充血起反应，参与肺水肿和肺纤维化时的浅快呼吸和呼吸困难。
- **肌肉和关节感受器**参与运动开始时、血气尚未改变之前的通气增加。

## 调控失灵时 {#sec-control-fail}

### 阿片类药物与镇静药

阿片类药物作用于前包钦格复合体及其他脑干部位的μ阿片受体。它们减慢呼吸频率，降低对二氧化碳和缺氧的反应，并可引起呼吸暂停。苯二氮䓬类、酒精和加巴喷丁类药物会加重这一作用。典型患者呼吸缓慢，看上去是嗜睡而不是痛苦，瞳孔呈针尖样，$P_{aCO_2}$不断升高。

::: example 外科病房里安静的患者 {#ex-opioid}
一名71岁女性剖腹手术后第1天。她使用吗啡患者自控镇痛泵，夜间还口服了羟考酮。早上6点，她很难被唤醒，呼吸频率7次/分，瞳孔缩小。吸氧4 L/min时血氧饱和度95%。动脉血气：pH 7.21，$P_{aCO_2}$ 9.8 kPa，$P_{aO_2}$ 10.5 kPa，碳酸氢盐27 mmol/L。请判读。
::: solution
她有阿片类药物所致通气不足引起的**急性呼吸性酸中毒**。pH低，$P_{aCO_2}$高；碳酸氢盐只轻度升高，与急性升高相符。她的血氧饱和度令人放心，只是因为她在吸氧，吸氧提高了肺泡$P_{O_2}$并掩盖了通气不足：这正是吸氧时血氧饱和度正常不能排除呼吸衰竭的原因。呼吸频率低和镇静才是需要处理的体征。处理按当地指南：停用阿片类药物，支持气道和通气，并给予阿片受体拮抗剂纳洛酮，逐步滴定至恢复足够的呼吸而不完全消除镇痛。由于纳洛酮的作用时间短于许多阿片类药物，她需要持续监测。需要考虑的促成因素包括她的年龄、肾功能（肾功能受损时吗啡代谢产物蓄积）以及两种阿片类药物合用（[[surgery/anaesthesia-pain]]）。
:::
:::

### 氧疗所致高碳酸血症

在少数慢性高碳酸性呼吸衰竭患者中（多为重度慢阻肺），给予高浓度氧会使$P_{aCO_2}$进一步升高，有时可达酸中毒和昏迷的程度。传统的解释是失去了"低氧驱动"。这确有一定作用，但不是主要机制。

::: theorem 氧疗所致高碳酸血症的机制 {#thm-o2-co2}
慢性高碳酸血症患者接受不受控的高浓度氧时，$P_{aCO_2}$升高的主要原因是：

1. **V/Q匹配恶化**：氧解除了通气不良区域的低氧性肺血管收缩，使其灌注增加，并使其余肺的肺泡无效腔增大。
2. **霍尔丹效应**：氧合血红蛋白增多后携带的二氧化碳减少，将其释放入血浆。
3. **通气轻度下降**：颈动脉体的低氧刺激被解除。
:::

无论哪种机制占主导，实际结论相同：对于有高碳酸性呼吸衰竭风险的人，应按英国胸科学会（BTS）氧疗指南的建议，以受控方式给氧，目标血氧饱和度为88–92%。塔斯马尼亚的一项随机试验（Austin等，2010年）发现，对疑似慢阻肺急性加重的患者，救护人员把氧滴定至88–92%，比给予高流量氧的死亡率更低。低氧血症仍须纠正：目的是既避免低氧血症又避免不必要的高氧，而不是不给氧。

::: example 氧给得太多 {#ex-o2-copd}
一名69岁重度慢阻肺男性因急性加重被救护车送来。途中经储氧面罩给予了15 L/min的氧。到达时他昏昏欲睡。血氧饱和度99%。血气：pH 7.22，$P_{aCO_2}$ 10.4 kPa，$P_{aO_2}$ 28 kPa，碳酸氢盐33 mmol/L。发生了什么？立即应采取什么措施？
::: solution
他有**慢性基础上急性加重的呼吸性酸中毒**。碳酸氢盐升高说明他的$P_{aCO_2}$长期偏高（代谢代偿需要数天）；pH低说明其上叠加了急性升高。28 kPa的$P_{aO_2}$远高于他的需要。不受控的氧使他的V/Q匹配恶化并释放了二氧化碳（霍尔丹效应），他的嗜睡反映了二氧化碳麻醉。立即措施不是突然撤氧——由于高$P_{aCO_2}$降低了肺泡$P_{O_2}$，突然撤氧可引起突发严重低氧血症——而是把氧降到受控装置（如28%文丘里面罩），目标88–92%，复查血气，并治疗急性加重。如果经最佳药物治疗后酸中毒仍持续，则有无创通气指征（[[respiratory/respiratory-failure]]）。
:::
:::

### 周期性呼吸

任何具有延迟和高增益的反馈系统都可能振荡。**潮式呼吸**（Cheyne–Stokes呼吸）是渐强–渐弱的呼吸与呼吸暂停交替出现的模式。它常见于重度心力衰竭（从肺到颈动脉体的循环时间延长，且控制器往往过度敏感）以及卒中后。健康人在高原睡眠时也会出现周期性呼吸。

### 睡眠呼吸障碍

睡眠时，上气道肌肉松弛，呼吸驱动减弱。

::: definition 阻塞性睡眠呼吸暂停 {#def-osa}
**阻塞性睡眠呼吸暂停**（OSA）是睡眠中咽部气道反复塌陷，尽管呼吸努力持续存在，仍导致**呼吸暂停**（气流停止至少10秒）和**低通气**（气流减少并伴血氧下降或觉醒）。**呼吸暂停低通气指数**（AHI）是每小时睡眠中这类事件的次数。在成人中，AHI 5–14通常为轻度，15–29为中度，30及以上为重度。**阻塞性睡眠呼吸暂停综合征**是伴有症状（最常见为日间过度嗜睡）的OSA。
:::

危险因素包括肥胖、颈围大、下颌后缩、扁桃体肿大、男性、年龄较大、饮酒和镇静药。典型症状为鼾声响亮、他人目睹的呼吸暂停、睡后不解乏和日间嗜睡，常用爱泼沃斯嗜睡量表（Epworth Sleepiness Scale）评估（得分0–24；高于10提示过度嗜睡）。OSA与高血压、心房颤动和道路交通事故相关。

诊断依靠睡眠监测：在英国通常采用家庭呼吸多导监测（气流、呼吸努力、血氧），复杂病例采用完整的多导睡眠图（增加脑电图睡眠分期）。NICE指南NG202（2021年）建议对中度或重度OSA，以及症状影响生活质量的轻度OSA，使用持续气道正压通气（CPAP），以撑开咽腔。减重、限酒和下颌前移装置也有帮助。在英国，因OSA而过度嗜睡者必须停止驾驶，并告知驾驶员和车辆许可局（DVLA），直到症状得到控制。

**中枢性睡眠呼吸暂停**（无呼吸努力）见于心力衰竭、使用阿片类药物和脑干疾病。**肥胖低通气综合征**是肥胖者在无其他原因时出现的日间高碳酸血症（$P_{aCO_2}$高于6 kPa）；它常与OSA并存，用气道正压治疗（[[respiratory/respiratory-failure]]）。

::: example 计算事件数 {#ex-osa}
一名52岁货车司机，衣领尺码46 cm，接受了家庭睡眠监测。他的伴侣反映他鼾声很大并有呼吸停顿。6.2小时的记录中有124次呼吸暂停和62次低通气。他的爱泼沃斯评分为15分。计算他的AHI并对其OSA分级。
::: solution
事件总数$= 124 + 62 = 186$。AHI $= 186/6.2 = 30$次/小时。这是**重度OSA**（AHI ≥ 30），爱泼沃斯评分15分提示日间过度嗜睡，因此他患有OSA综合征。应为他提供CPAP，并支持其减重。由于他是有过度嗜睡的职业司机，在症状得到控制之前不得驾驶，并须告知DVLA；在英国，职业司机恢复驾驶前需要有充分控制和坚持治疗的证据。（严格地说，家庭监测计算的是每小时记录时间而非每小时睡眠时间的事件数，可能低估真实的AHI。）
:::
:::

## 肺功能检查 {#sec-tests}

肺功能检查回答一些具体问题：有无气流阻塞，是否可逆？肺是否变小？气体转移是否受损？问题在肺、胸壁还是肌肉？每项检查只能回答其中一部分。

### 肺量计检查及其判读

肺量计检查已在[[respiratory/mechanics-breathing#def-spiro]]中介绍。只有操作良好，结果才有效。国际标准（ATS/ERS，2019年）要求至少三次可接受的用力呼气，其中最大的两个FEV₁值和两个FVC值相差均不超过150 mL。用力不足、起始缓慢、咳嗽或提前终止都会产生误导性结果。

::: definition 参考值、z分数与正常下限 {#def-lln}
测量值要与根据**参考方程**预测的、同年龄、性别和身高健康人的数值比较，最常用的是全球肺功能倡议（GLI）方程。**z分数**是测量值偏离预计值的标准差个数：

$$
z = \frac{\text{测量值} - \text{预计值}}{\text{SD}}
$$ {#eq-z}

**正常下限**（LLN）是第5百分位数，即z分数−1.645。ATS/ERS关于判读的指南（2022年）把低于LLN而非低于固定百分比定义为异常。
:::

FEV₁/FVC比值通常随年龄下降。因此，GOLD和NICE用于定义慢阻肺阻塞的固定界值0.70，会把许多健康老年人判为阻塞，并漏掉一些确有阻塞的年轻人。LLN方法避免了这一问题，代价是计算更复杂。两者都在使用，报告应说明采用的是哪一种。

参考方程过去包含按族群的校正，其前提是某些人群肺功能较低属于正常。2023年，美国胸科学会建议改用不区分种族的方程（GLI Global）。实践正在变化，临床医生应了解所在实验室使用的是哪种方程。

::: example 这是阻塞吗？ {#ex-lln}
一名81岁女性，终生不吸烟，上坡时轻度气短。支气管舒张后肺量计：FEV₁/FVC 0.67。按她的年龄、性别和身高，比值预计值为0.75，LLN为0.63。FEV₁为预计值的92%。她有气流阻塞吗？
::: solution
按固定比值定义（低于0.70），她会被判为阻塞。按LLN定义，她的比值（0.67）高于LLN（0.63），对她的年龄而言在正常范围内。她FEV₁正常、无吸烟史、症状轻微，很可能没有慢阻肺；固定比值在老年人中会过度诊断阻塞。她的气短应作更广泛的检查（例如心力衰竭、贫血、体能下降）。在青年人中则会出现相反的错误：0.72的比值可能远低于其LLN。
:::
:::

### 可逆性与变异性

- **支气管舒张反应**：吸入短效β₂受体激动剂15–20分钟后复查肺量计。2024年NICE/BTS/SIGN哮喘指南（NG245）把成人FEV₁增加12%及以上且200 mL及以上视为支持哮喘的阳性结果。ATS/ERS 2022年判读标准则把FEV₁或FVC的增加超过其预计值的10%定义为显著反应。许多慢阻肺患者也有一定反应，因此仅凭可逆性不能区分哮喘和慢阻肺。
- **呼气峰流量（PEF）**是用力呼气开始时的最大流量，用廉价的手持式峰流速仪测定。连续两周每天测两次可显示**变异性**；在NG245中，平均日变异幅度20%及以上支持哮喘。在工作期间和离开工作时连续测定，有助于诊断职业性哮喘。
- **支气管激发试验**测定气道高反应性：使FEV₁下降20%所需的吸入乙酰甲胆碱剂量（甘露醇则采用下降15%）。有当前症状者乙酰甲胆碱试验阴性，则哮喘可能性小。
- **呼出气一氧化氮分数（FeNO）**测定呼出气中的一氧化氮，是2型（嗜酸性粒细胞性）气道炎症的标志。在NG245中，成人FeNO达到或超过50 ppb（5–16岁儿童达到或超过35 ppb）支持哮喘诊断。吸烟和吸入糖皮质激素会降低FeNO。

这些检查在哮喘诊断中如何组合，见[[respiratory/asthma-copd]]。

### 肺容积与弥散功能

静态肺容积（TLC、RV、FRC）用体积描记法或气体稀释法测定（[[respiratory/mechanics-breathing#sec-volumes]]）。它们可证实限制（TLC降低），并显示过度充气和气体陷闭（RV及RV/TLC比值升高）。

弥散功能（TLCO和KCO，[[respiratory/gas-exchange#def-tlco]]）与肺容积结合使用时最有价值。

| 模式 | TLC | TLCO | KCO | 典型病因 |
|---|---|---|---|---|
| 肺气肿 | 正常或升高 | 降低 | 降低 | 肺泡壁和毛细血管丧失 |
| 间质性肺疾病 | 降低 | 降低 | 降低或正常 | 膜增厚、毛细血管丧失 |
| 肺血管疾病 | 正常 | 降低 | 降低 | 肺栓塞、肺动脉高压 |
| 肺外限制 | 降低 | 降低或正常 | 升高 | 肥胖、胸壁疾病、肌无力、全肺切除术后 |
| 肺泡内血液增多 | 正常 | 升高 | 升高 | 肺泡出血、红细胞增多症 |

肺量计和肺容积正常而TLCO降低，应寻找肺血管疾病或早期间质性疾病。贫血会降低TLCO，因此结果要按血红蛋白校正。

::: example 肺量计正常的气短 {#ex-tlco}
一名44岁系统性硬化症女性气短日益加重。肺量计和肺容积正常。TLCO为预计值的48%，KCO为预计值的52%。血红蛋白正常。应怀疑什么？
::: solution
肺容积正常排除了明显的间质纤维化，肺量计正常排除了阻塞。孤立而显著的气体转移下降伴KCO降低，意味着参与气体交换的毛细血管床减少。在系统性硬化症中，首要原因是**肺动脉高压**，它使小肺动脉狭窄和闭塞。她需要做超声心动图并转诊评估，可能包括右心导管检查（[[respiratory/interstitial-vascular-disease]]）。系统性硬化症患者每年做一次包括TLCO在内的肺功能检查，用于筛查这两种并发症。
:::
:::

### 呼吸肌功能检查

疑有神经肌肉无力时，有用的检查包括坐位和卧位肺活量（卧位下降超过约20%提示膈肌无力）、最大吸气和呼气口腔压，以及鼻吸气压（sniff nasal inspiratory pressure）。在吉兰–巴雷综合征和肌无力危象中，用床旁连续测定FVC来发现即将发生的呼吸衰竭。

### 运动试验

步行试验简便地测定功能储备。**六分钟步行试验**记录在平直走廊上行走的距离，并同时监测血氧；**递增往返步行试验**用音频信号控制步行速度。它们用于间质性肺疾病和肺动脉高压的预后评估、肺康复前的评估，以及发现运动时血氧下降。**心肺运动试验**（CPET）在递增运动中测定摄氧量、二氧化碳排出量和通气量。它能判断运动受限是由于心脏、肺、肌肉还是体能下降，并在大手术前评估手术风险。

## 动脉血气 {#sec-abg}

动脉血气样本直接测定pH、$P_{aO_2}$和$P_{aCO_2}$，并计算碳酸氢盐和碱剩余。许多分析仪还测定乳酸、电解质和各种血红蛋白。

::: definition 判读血气的系统方法 {#def-abg}
1. **氧合**：对于所吸入的氧浓度而言，$P_{aO_2}$是否偏低？呼吸空气时计算A–a梯度（[[respiratory/gas-exchange#def-aa]]）；吸氧时使用P/F比值。
2. **pH**：酸血症（低于7.35）还是碱血症（高于7.45）？
3. **呼吸成分**：$P_{aCO_2}$升高（呼吸性酸中毒）还是降低（呼吸性碱中毒）？
4. **代谢成分**：碳酸氢盐或碱剩余升高（代谢性碱中毒）还是降低（代谢性酸中毒）？
5. **原发紊乱与代偿**：哪一种改变解释了pH？另一种改变是适当的代偿，还是另一个紊乱？
:::

对于呼吸性酸碱紊乱，代偿遵循可预测的规律（以传统单位表示）。在**急性**呼吸性酸中毒中，$P_{aCO_2}$每升高10 mmHg（1.33 kPa），碳酸氢盐经缓冲作用约升高1 mmol/L。在**慢性**呼吸性酸中毒中，数天后肾脏潴留碳酸氢盐，使其每10 mmHg升高约3.5–4 mmol/L。酸碱紊乱的完整论述，包括代谢性紊乱和阴离子间隙，见[[physiology/acid-base]]和[[renal/acid-base-disorders]]。

::: example 急性、慢性还是两者兼有？ {#ex-abg}
一名已知患慢阻肺的66岁男性咳绿色脓痰三天，pH 7.27，$P_{aCO_2}$ 9.3 kPa（70 mmHg），碳酸氢盐31 mmol/L。取正常$P_{aCO_2}$为40 mmHg、正常碳酸氢盐为24 mmol/L，判断这是急性、慢性还是慢性基础上急性加重的呼吸性酸中毒。
::: solution
$P_{aCO_2}$比正常高30 mmHg。

若为单纯急性，碳酸氢盐应约为$24 + 3 \times 1 = 27$ mmol/L。

若为单纯慢性，碳酸氢盐应约为$24 + 3 \times 3.5 = 34.5$ mmol/L。

他的碳酸氢盐31介于两者之间，pH 7.27也低于完全慢性代偿所能允许的水平。这是**慢性基础上急性加重的呼吸性酸中毒**：他原有一定程度的慢性二氧化碳潴留，急性加重使$P_{aCO_2}$进一步升高，肾脏来不及代偿。用亨德森方程核算：$[\text{H}^+] = 24 \times 70/31 \approx 54$ nmol/L，对应的pH约为7.27。
:::
:::

::: warning 吸氧时血氧饱和度正常不代表通气充分
脉搏血氧测定反映的是氧合，而不是通气。吸氧的患者可以在$P_{aCO_2}$升至危险水平时仍保持正常的血氧饱和度，因为额外吸入的氧维持了肺泡$P_{O_2}$。对于嗜睡的患者、使用阿片类药物的患者，或患有慢阻肺或神经肌肉疾病的患者，要检查呼吸频率和精神状态，并测定血气。静脉血气可合理地筛查$P_{CO_2}$和pH（静脉$P_{CO_2}$正常时动脉高碳酸血症的可能性很小），但不能评估氧合。
:::

::: quiz
动脉$P_{O_2}$下降时，通气增加由哪种感受器负责？
- [ ] 延髓的中枢化学感受器
- [x] 外周化学感受器，主要是颈动脉体
- [ ] 肺牵张感受器
- [ ] 肺毛细血管旁（J）感受器
::: solution
只有外周化学感受器（主要是颈动脉体）能感知动脉低氧血症（[[#def-chemo]]）。中枢化学感受器对脑细胞外液的氢离子浓度起反应，因此主要感受$P_{CO_2}$；严重缺氧实际上会抑制它们。双侧颈动脉体被切除或损伤的人（例如双侧颈动脉手术后）会丧失大部分低氧通气反应。
:::
:::

::: history
1868年，埃瓦尔德·黑林（Ewald Hering）和约瑟夫·布罗伊尔（Josef Breuer）描述了以他们命名的肺扩张反射。1905年，约翰·斯科特·霍尔丹（John Scott Haldane）和约翰·吉利斯·普里斯特利（John Gillies Priestley）证明，通气受肺泡二氧化碳极其精确的调节。在根特工作的科内耶·海曼斯（Corneille Heymans）证明了颈动脉窦和主动脉体在呼吸和循环反射调节中的作用，并于1938年获得诺贝尔奖。约翰·切恩（John Cheyne）于1818年、威廉·斯托克斯（William Stokes）于1854年描述了以他们命名的周期性呼吸。1991年，杰克·费尔德曼（Jack Feldman）、杰弗里·史密斯（Jeffrey Smith）等人确认前包钦格复合体是呼吸节律的核心。阻塞性睡眠呼吸暂停在20世纪60至70年代得到阐明，1981年悉尼的科林·沙利文（Colin Sullivan）引入经鼻CPAP作为其治疗方法。
:::

## 后续内容

本章介绍的检查是后续每一个临床章节的工具。肺量计、可逆性、PEF变异性和FeNO用于诊断和监测[[respiratory/asthma-copd]]。弥散功能和步行试验用于[[respiratory/interstitial-vascular-disease]]的分期。肺功能决定[[respiratory/lung-cancer-pleura]]中的手术耐受性。血气和呼吸调控是[[respiratory/respiratory-failure]]的核心。

::: summary
- 节律起源于延髓的前包钦格复合体；随意呼吸使用一条独立的皮层通路。
- 中枢化学感受器（经脑内氢离子）对$P_{CO_2}$起反应，提供静息驱动的大部分。只有颈动脉体能感知低氧血症，主要在约8 kPa以下。
- 慢性高碳酸血症使中枢化学感受器重新设定。氧疗所致高碳酸血症主要源于V/Q匹配恶化和霍尔丹效应；有风险者目标为88–92%。
- 阿片类药物抑制呼吸频率和对二氧化碳的反应。吸氧可在血氧饱和度上掩盖通气不足。
- OSA：AHI 5–14为轻度，15–29为中度，≥30为重度；中重度或有症状者使用CPAP。
- 依据参考方程判读肺功能，最好使用LLN；固定的FEV₁/FVC 0.70会在老年人中过度诊断阻塞。
- 结合肺量计、肺容积和弥散功能定位疾病；用PEF、可逆性、FeNO和激发试验诊断哮喘。
- 系统地判读血气，用代偿规律区分急性和慢性呼吸性酸中毒。
:::

## 习题

::: exercise 两种化学感受器 {level=1}
列出两种主要经中枢化学感受器起作用的刺激，以及两种经外周化学感受器起作用的刺激。颈动脉体的传入纤维走行于哪条神经？
::: solution
中枢：$P_{aCO_2}$升高（通过脑内氢离子），以及脑细胞外液pH的改变。外周：$P_{aO_2}$下降（尤其低于约8 kPa），以及动脉氢离子浓度升高（如代谢性酸中毒）；它们对$P_{CO_2}$也反应迅速。颈动脉体传入纤维走行于舌咽神经（经颈动脉窦神经）。
:::
:::

::: exercise z分数 {level=1 check="-2.25"}
一名50岁男性FEV₁为2.1 L。他的FEV₁预计值为3.0 L，标准差为0.4 L。计算他的z分数。
::: solution
$z = (2.1 - 3.0)/0.4 = -0.9/0.4 = -2.25$。低于−1.645，因此他的FEV₁低于正常下限。
:::
:::

::: exercise 呼吸暂停低通气指数 {level=1 check="17.5"}
一次睡眠监测记录了6小时睡眠，期间有63次呼吸暂停和42次低通气。计算AHI（次/小时）并判断严重程度。
::: solution
AHI $= (63 + 42)/6 = 105/6 = 17.5$次/小时：中度OSA（15–29）。
:::
:::

::: exercise 按NG245判断可逆性 {level=2}
一名28岁女性有发作性喘息，支气管舒张前FEV₁为2.50 L，舒张后为2.78 L。这是否达到NG245中支气管舒张试验阳性的标准？
::: solution
增加量为$2.78 - 2.50 = 0.28$ L（280 mL），占基线的百分比为$0.28/2.50 = 11.2\%$。容积标准（200 mL及以上）满足，但百分比标准（12%及以上）未满足，因此不符合NG245对阳性试验的定义。这并不排除哮喘：可逆性试验敏感性低，尤其在发作间期肺量计正常时。如果FeNO和嗜酸性粒细胞尚未确诊，指南路径的下一步包括PEF变异性或支气管激发试验。
:::
:::

::: exercise 判读一种模式 {level=2}
一名64岁已戒烟者FEV₁/FVC 0.52，TLC为预计值的125%，RV为预计值的180%，TLCO为41%，KCO为预计值的45%。描述这一模式及最可能的诊断。
::: solution
阻塞（比值低）、过度充气（TLC高）和气体陷闭（RV很高），伴气体转移和转移系数显著降低。这是**肺气肿**的典型模式：肺泡壁破坏同时去除了弹性回缩力（导致气流受限和气体陷闭）和毛细血管床（TLCO和KCO降低）。相比之下，慢性哮喘的气体转移通常正常甚至升高。
:::
:::

::: exercise 已代偿的患者 {level=2}
一名58岁严重脊柱后侧凸女性呼吸空气时pH 7.38，$P_{aCO_2}$ 7.6 kPa，碳酸氢盐33 mmol/L，$P_{aO_2}$ 8.1 kPa。判读这份血气，并解释如果给予她高流量氧，她的呼吸驱动为何重要。
::: solution
她有**慢性代偿性呼吸性酸中毒**伴低氧血症：pH正常，$P_{aCO_2}$升高，碳酸氢盐经长期肾代偿而升高。她呼吸空气时的A–a梯度为$20.0 - 7.6/0.8 - 8.1 = 2.4$ kPa，接近正常，因此主要问题是胸壁畸形所致的通气不足。她的中枢化学感受器已重新设定于较高的$P_{CO_2}$。高浓度氧可使她的$P_{aCO_2}$进一步升高并导致酸中毒，因此应把氧滴定至88–92%。她适合接受家庭无创通气评估，无创通气在胸壁疾病中非常有效（[[respiratory/respiratory-failure]]）。
:::
:::

::: exercise 聚会后昏睡的男子 {level=3}
一名23岁男性在聚会后被送到急诊科。他昏昏欲睡，呼吸频率8次/分。呼吸空气时血氧饱和度91%。呼吸空气时动脉血气：pH 7.24，$P_{aCO_2}$ 8.6 kPa，$P_{aO_2}$ 7.4 kPa，碳酸氢盐25 mmol/L。请判读，计算A–a梯度（取$P_{IO_2}$ 20.0 kPa），并概述鉴别诊断和紧急处理重点。
::: solution
急性呼吸性酸中毒（pH低，$P_{aCO_2}$高，碳酸氢盐几乎未变）。$P_{AO_2} = 20.0 - 8.6/0.8 = 9.25$ kPa；梯度$= 9.25 - 7.4 = 1.85$ kPa，正常。低氧血症可由通气不足解释；目前尚无明显误吸或肺损伤的证据。

鉴别诊断：阿片类药物中毒（查看瞳孔，寻找针眼，考虑纳洛酮）、其他镇静物质（苯二氮䓬类、γ-羟基丁酸、酒精）、头部外伤或颅内事件，在此情境下可能性较小的还有神经肌肉原因。紧急处理按ABCDE方法：气道（体位、辅助装置）、通气支持（必要时用球囊面罩）、给氧、测血糖、若可能为阿片类中毒则给纳洛酮，并复查血气。之后若A–a梯度增大，提示吸入性肺炎（[[emergency-critical-care/poisoning]]）。
:::
:::

::: exercise 规划睡眠评估 {level=3}
一名47岁女性，BMI 41，高血压难以控制，晨起头痛，爱泼沃斯评分9分。常规静脉血样本中碳酸氢盐为32 mmol/L。请解释为什么她需要的不只是简单的血氧监测，以及你要区分哪些情况。
::: solution
她的症状提示睡眠呼吸障碍，但爱泼沃斯评分在正常范围并不能排除；女性和难治性高血压患者常常较少报告嗜睡。晨起头痛和碳酸氢盐升高提示**慢性高碳酸血症**，除OSA外还提示**肥胖低通气综合征**的可能。单纯血氧监测无法测定二氧化碳，也无法区分阻塞性和中枢性事件。她需要动脉（或毛细血管）血气以证实日间高碳酸血症，并做呼吸多导监测，最好同时整夜监测经皮二氧化碳。如果她患有肥胖低通气，在OSA严重时CPAP可能已足够，但有些患者需要无创通气。体重管理是两种情况治疗的一部分。
:::
:::
