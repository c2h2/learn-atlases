呼吸衰竭是指呼吸系统已不能把动脉血氧和二氧化碳维持在安全范围之内。它不是一种疾病，而是一条最终共同通路，可由肺炎、慢阻肺、哮喘、肺水肿、神经肌肉疾病、药物过量以及许多其他疾病引起。及早识别、弄清系统中哪一部分发生了衰竭、选择合适的支持手段，是急诊内科最重要的技能之一。

本章把前面各章的生理学串联起来。它先定义两种类型的呼吸衰竭，解释各自如何发生，然后介绍治疗手段：氧疗、持续气道正压、无创通气和有创机械通气，包括急性呼吸窘迫综合征的肺保护性策略。英国实践遵循英国胸科学会（BTS）氧疗指南（2017年）和BTS/英国重症监护学会关于无创通气的指南；所有管理内容都是原则，实践中通过当地方案和上级医师决策来执行。

## 两种类型的衰竭 {#sec-types}

::: definition 1型和2型呼吸衰竭 {#def-resp-failure}
- **1型（低氧性）呼吸衰竭**：$P_{aO_2}$低于8 kPa（60 mmHg），$P_{aCO_2}$正常或偏低。这是肺**气体交换**的衰竭。
- **2型（高碳酸性）呼吸衰竭**：$P_{aCO_2}$高于约6.0 kPa（45 mmHg），通常同时伴有低氧血症。这是**通气**的衰竭："泵"不能推动足够的空气。

每一型都可以是**急性**（数分钟至数小时内发生，来不及代偿）、**慢性**（数天至数年内发生，pH有肾脏代偿）或**慢性基础上急性加重**。
:::

这一区分告诉你问题在哪里、什么能起作用。在1型衰竭中，问题在肺：液体、脓液、肺不张或血管阻塞使氧无法进入血液。患者通常呼吸用力，因此$P_{aCO_2}$偏低。治疗目标是提高吸入氧浓度并重新打开塌陷的肺泡。在2型衰竭中，问题是进出肺泡的空气不够。氧可以纠正低氧血症，却对二氧化碳毫无作用；治疗必须增加通气。

### 二氧化碳为何升高

::: theorem 肺泡通气方程 {#thm-va}
在稳态下，动脉$P_{CO_2}$与二氧化碳生成速率成正比，与肺泡通气量成反比：

$$
P_{aCO_2} \propto \frac{\dot V_{CO_2}}{\dot V_A}, \qquad \dot V_A = (V_T - V_D) \times f
$$ {#eq-va}

其中$\dot V_{CO_2}$为二氧化碳生成量，$\dot V_A$为肺泡通气量，$V_T$为潮气量，$V_D$为无效腔，$f$为呼吸频率。肺泡通气量减半，$P_{aCO_2}$加倍。
:::

::: proof
组织产生的二氧化碳必须通过肺泡通气排出。在稳态下，每分钟呼出量等于生成量。呼出量等于肺泡通气量乘以肺泡内二氧化碳浓度，而后者与其分压成正比。因此$\dot V_{CO_2} \propto \dot V_A \times P_{ACO_2}$，而肺泡与动脉$P_{CO_2}$几乎相等。整理即得此方程。无效腔通气没有帮助，因为无效腔中的气体永远到不了有灌注的肺泡：每次呼吸中只有超出无效腔的部分才起作用。
:::

:::

该方程揭示了2型衰竭的病因，可沿从脑到肺泡的链条分组：

- **驱动减弱**：阿片类药物、镇静药、脑干卒中、颅脑损伤、中枢性低通气。
- **神经和神经肌肉接头**：高位脊髓损伤、吉兰–巴雷综合征、运动神经元病、重症肌无力。
- **肌肉**：肌病、肌营养不良、严重低钾血症或低磷血症、呼吸肌疲劳。
- **胸壁和胸膜**：脊柱后侧凸、连枷胸、肥胖、大量胸腔积液。
- **气道和肺**：慢阻肺和重症哮喘，此时呼吸肌负荷超过其能力，浅快呼吸使无效腔比例增加。

1型衰竭由[[respiratory/gas-exchange#def-hypox]]中所述的低氧血症机制引起：主要是肺炎、肺水肿、ARDS、肺栓塞、ILD、肺不张和急性哮喘造成的V/Q失调和分流。

::: example 浅快呼吸 {#ex-rapid-shallow}
一名66岁重度慢阻肺急性加重女性正在疲劳。她的呼吸从频率12次/分、潮气量500 mL变为频率30次/分、潮气量250 mL。她的无效腔为150 mL。急性加重前她的$P_{aCO_2}$为5.3 kPa。假设二氧化碳生成量不变，估计她新的$P_{aCO_2}$。
::: solution
之前：$\dot V_A = (0.50 - 0.15) \times 12 = 0.35 \times 12 = 4.2$ L/min。

现在：$\dot V_A = (0.25 - 0.15) \times 30 = 0.10 \times 30 = 3.0$ L/min。

她的总分钟通气量实际上升高了（从6.0升至7.5 L/min），但肺泡通气量下降了，因为每一次小的呼吸大部分都是无效腔。根据[[#eq-va]]，新的$P_{aCO_2} = 5.3 \times 4.2/3.0 = 7.4$ kPa。这就是为什么呼吸频率快并不意味着通气充足，也是为什么疲劳患者出现浅快呼吸模式是警示信号。无创通气通过增加她的潮气量起作用。
:::
:::

### 识别呼吸衰竭

呼吸窘迫的临床征象包括呼吸频率增快（常是最早出现异常的生命体征）、动用辅助呼吸肌、不能说完整句子、心动过速、出汗和烦躁。低氧血症可引起发绀（不可靠的体征，在贫血和深色皮肤者中尤甚）、意识模糊和心律失常。高碳酸血症引起头痛、洪脉、四肢温暖、扑翼样震颤、嗜睡，最终昏迷。呼吸频率下降、腹部矛盾运动和意识水平下降等衰竭征象，提示即将发生呼吸停止。

英国国家早期预警评分2（NEWS2）等早期预警评分包含呼吸频率和血氧饱和度，NEWS2还为目标饱和度设定为88–92%的患者提供了单独的饱和度量表。动脉血气是关键检查，按[[respiratory/control-breathing-tests#def-abg]]中的方法解读。

## 氧疗 {#sec-oxygen}

氧是一种药物。开具时应注明**目标饱和度范围**，用合适的装置给予，监测并调整，不再需要时停用。氧太少会导致组织缺氧；太多则无益处，并可能造成伤害，尤其对有高碳酸血症风险的人。

::: definition 目标饱和度（BTS 2017） {#def-targets}
- 大多数急症成人为**94–98%**。
- 有高碳酸性呼吸衰竭风险者为**88–92%**：慢阻肺，以及其他疾病如严重胸壁疾病、神经肌肉疾病、肥胖低通气和囊性纤维化，在血气结果出来之前均如此。
- 危重症（如心搏骤停、休克、严重创伤）开始时给予高浓度氧，患者稳定后再调整到目标范围。
:::

有风险者的目标是个体化的：若血气显示没有二氧化碳潴留，目标可提高到94–98%。氧不是治疗非低氧血症者气短的手段。

::: definition 给氧装置 {#def-devices}
- **鼻导管**：1–6 L/min。舒适，可以进食和说话；实际给予的浓度随患者呼吸而变化。
- **普通面罩**：5–10 L/min。浓度可变；流量低于5 L/min有重复吸入二氧化碳的风险。
- **文丘里（固定性能）面罩**：通过经校准的侧孔卷入室内空气，给予设定的浓度（24%、28%、31%、35%、40%或60%）。需要精确控制时（如有高碳酸血症风险者）的首选装置。
- **储氧（"非重复呼吸"）面罩**：15 L/min，给予高浓度（约60–90%）。用于危重患者的初始治疗。
- **经鼻高流量氧疗**（HFNO）：加温加湿的气体，流量可达60 L/min，氧浓度可设定至1.0。高流量满足患者的吸气峰流量需求，冲洗上气道无效腔中的二氧化碳，并提供少量气道正压。
:::

普通面罩等"可变性能"装置给予的吸入浓度会随患者自身流量增加而下降，因为卷入的室内空气更多。一个呼吸又深又快的气短患者得到的氧可能远少于预期。固定性能装置（文丘里面罩、HFNO）可避免这一问题。

::: warning 高碳酸血症患者不要突然停氧
当一名给氧过多的患者出现$P_{aCO_2}$升高时，本能反应可能是撤掉氧气。但高$P_{aCO_2}$本身就会降低肺泡$P_{O_2}$（[[respiratory/gas-exchange#eq-age]]），而二氧化碳储备需要时间才能清除，因此停氧可导致突发的严重低氧血症。正确的做法是把氧降到能达到88–92%的最低浓度（通常用文丘里面罩），若酸中毒持续则考虑无创通气。
:::

## 不插管的气道正压 {#sec-niv}

::: definition CPAP与NIV {#def-cpap-niv}
- **持续气道正压**（CPAP）通过紧密贴合的面罩或头罩，在整个呼吸周期中施加相同的正压。它不辅助呼吸动作本身。它提高平均气道压，撑开塌陷的肺泡，增加功能残气量并改善V/Q匹配。它用于治疗**1型衰竭**（以及阻塞性睡眠呼吸暂停）。
- **无创通气**（NIV，双水平气道正压）在吸气时施加较高的压力（IPAP），在呼气时施加较低的压力（EPAP）。两者之差辅助每一次呼吸，增加潮气量和肺泡通气量。它用于治疗**2型衰竭**。
:::

CPAP对急性心源性肺水肿有效，在那里它还能降低左心室后负荷和静脉回心血量；COVID-19的低氧性呼吸衰竭中也曾广泛使用。HFNO是1型衰竭的另一种选择，一项法国试验（FLORALI，2015年）提示，在部分急性低氧性呼吸衰竭患者中，它优于标准氧疗。

NIV在**慢阻肺所致急性高碳酸性呼吸衰竭**中有充分证据：它降低死亡率、插管需要和住院时间。在BTS/ICS指南中，经最佳药物治疗后呼吸性酸中毒（pH低于7.35且$P_{aCO_2}$高于6.5 kPa）仍持续时，即有NIV指征。它也用于胸壁疾病、神经肌肉疾病和肥胖低通气的急性高碳酸性衰竭，这些患者常在家中继续使用。在运动神经元病中，对没有严重延髓无力的患者，家庭NIV可改善生存和生活质量。

开始NIV之前，团队要商定并记录NIV失败时的计划：患者是否适合插管，还是NIV就是治疗上限。只要可能，就要与患者本人讨论（[[medical-ethics-law/end-of-life-ethics]]）。某些情况下不宜使用NIV，例如患者不能保护气道、正在呕吐、有未引流的气胸、面部损伤或近期上消化道手术。1–2小时内复查血气；若pH和$P_{aCO_2}$未改善，应调整参数和面罩贴合，适当时升级为有创通气。

::: example 粉红色泡沫痰 {#ex-cpap}
一名78岁缺血性心脏病男性夜间因急性气短醒来，端坐呼吸，咳粉红色泡沫痰。双肺广泛湿啰音。呼吸空气时$S_pO_2$ 82%，储氧面罩15 L/min时89%。吸氧时血气：pH 7.31，$P_{aCO_2}$ 5.8 kPa，$P_{aO_2}$ 7.9 kPa，乳酸2.8 mmol/L。血压170/96 mmHg。这是哪一型呼吸衰竭？什么支持手段合适？
::: solution
这是**急性心源性肺水肿**导致的**1型呼吸衰竭**：肺泡被液体淹没，造成分流和V/Q失调，尽管吸入高浓度氧，他的$P_{aO_2}$仍低于8 kPa。pH轻度降低主要是组织低灌注引起的乳酸酸中毒；他的$P_{aCO_2}$目前正常，但随着疲劳可能升高。在治疗病因的同时（血压高时用硝酸酯类，容量过负荷时用袢利尿剂，并检查有无急性冠脉综合征或心律失常：[[cardiovascular/heart-failure]]），若他仍有低氧血症，**CPAP**是合适的：它重新打开被淹没的肺泡，改善氧合，减少呼吸做功，并降低左心室后负荷。必须密切监测，病情恶化时升级治疗。
:::
:::

## 有创机械通气 {#sec-imv}

当无创方法失败或不适用时，患者可能需要在重症监护中进行**气管插管**和机械通气。常见原因有：

- 不能保护气道（意识水平下降，例如格拉斯哥昏迷评分8分或以下，或气道反射丧失）；
- 用创伤较小的手段无法纠正的低氧血症；
- 尽管使用NIV仍在恶化、或NIV禁忌的高碳酸性衰竭；
- 衰竭或即将发生呼吸停止；
- 需要深度镇静或手术。

插管的决定是临床性的，既要考虑数值，也要考虑变化趋势、基础疾病的可逆性以及患者的意愿。插管本身有风险，尤其在低氧血症患者中，应由经验丰富的临床医生实施，并备好困难气道预案（[[emergency-critical-care/airway-ventilation]]）。

正压通气的生理影响不限于肺。胸腔内压升高减少静脉回心血量，因此开始通气后常出现低血压，在血容量不足的患者中尤甚。并发症包括呼吸机相关性肺炎、气压伤（气胸）、呼吸机所致肺损伤、镇静的影响、谵妄以及ICU获得性肌无力。

### 急性呼吸窘迫综合征

::: definition 急性呼吸窘迫综合征 {#def-ards}
**急性呼吸窘迫综合征**（ARDS）是急性、弥漫性、炎症性肺损伤，导致肺泡–毛细血管膜通透性增加，肺泡被富含蛋白的液体淹没，并出现严重低氧血症。**柏林定义**（2012年）要求：在已知损伤或新出现/加重的呼吸道症状后一周内起病；胸部影像显示双侧阴影，不能完全用积液、肺不张或结节解释；呼吸衰竭不能完全用心力衰竭或液体过负荷解释；氧合受损，在PEEP至少5 cmH₂O时分级为**轻度**（$P_{aO_2}$/$F_{IO_2}$ 200–300 mmHg）、**中度**（100–200 mmHg）或**重度**（100 mmHg或以下）。
:::

2023年提出的**全球定义**扩展了柏林标准，使ARDS能在更广泛的场合得到识别：它纳入了接受30 L/min或以上经鼻高流量氧疗的患者，允许用$S_pO_2$/$F_{IO_2}$比值315或以下（在$S_pO_2$为97%或以下时）代替动脉血气，并在没有X线或CT时接受肺部超声作为影像学依据。

ARDS可继发于**直接**肺损伤（肺炎，包括COVID-19；胃内容物误吸；烟雾吸入；溺水未遂）或**间接**损伤（脓毒症、严重创伤、胰腺炎、大量输血）。病理改变是**弥漫性肺泡损伤**：中性粒细胞驱动的损伤、衬于肺泡表面的透明膜、表面活性物质丧失，部分患者后期出现纤维化。肺变得僵硬、沉重且受累不均：低垂部位塌陷并被液体淹没，其他区域仍保持通气。有功能的肺很小，有时被称为"婴儿肺"。

治疗以支持为主，同时治疗病因。关键原则是避免呼吸机造成进一步伤害。

::: theorem 肺保护性通气 {#thm-lpv}
在ARDS中，与传统的较大潮气量相比，采用**小潮气量**（约6 mL/kg预计体重）和**平台压30 cmH₂O或以下**进行通气可降低死亡率。预计体重由身高和性别计算：

$$
\text{PBW（男性）} = 50 + 0.91 \times (\text{身高（cm）} - 152.4), \qquad \text{PBW（女性）} = 45.5 + 0.91 \times (\text{身高（cm）} - 152.4)
$$ {#eq-pbw}
:::

::: proof
由于ARDS肺的大部分已塌陷或被淹没，"正常"潮气量会全部送入那一小部分有通气的肺并使其过度牵张（**容积伤**）。随每次呼吸开闭的肺泡受到剪切力损伤（**肺萎陷伤**）。两者都释放炎症介质，损害肺和其他器官（**生物伤**）。限制潮气量和平台压可减少过度扩张；足够的呼气末正压（PEEP）使可复张的肺泡保持开放，减少周期性塌陷。之所以用预计体重而不是实际体重，是因为肺的大小取决于身高和性别，而与体脂无关。在ARDS Network试验（2000年）中，与12 mL/kg相比，6 mL/kg使死亡率从约40%降至31%。一个相关指标**驱动压**（平台压减PEEP）反映潮气量相对于有功能肺大小的比例，与预后相关。
:::

在中重度ARDS中有证据支持的其他措施包括：每天长时间的**俯卧位通气**（PROSEVA试验，2013年，发现在$P_{aO_2}$/$F_{IO_2}$低于150 mmHg的患者中，每天至少俯卧16小时可降低死亡率）；休克纠正后采取限制性液体策略；以及在专科中心对重症患者使用体外膜肺氧合（ECMO）。俯卧位使接受大部分血流的背侧肺重新打开，使通气和灌注更均匀，从而改善氧合。糖皮质激素在某些病因（如COVID-19）中有一定作用。

::: example 计算氧合比值 {#ex-pf}
一名45岁女性患肺炎球菌肺炎和脓毒症，已行气管插管。在$F_{IO_2}$ 0.6、PEEP 10 cmH₂O时，她的$P_{aO_2}$为9.0 kPa。胸片显示双侧阴影，超声心动图显示左心室功能正常。计算她的$P_{aO_2}$/$F_{IO_2}$比值并对ARDS分级。
::: solution
把$P_{aO_2}$换算为mmHg：$9.0 \times 7.5 = 67.5$ mmHg。

比值：$67.5/0.6 = 112.5$ mmHg（15 kPa）。

她符合柏林标准（急性起病、双侧阴影、不能用心力衰竭解释、PEEP ≥ 5），比值在100到200 mmHg之间：**中度ARDS**。处理包括肺保护性通气（潮气量约6 mL/kg预计体重，平台压30 cmH₂O或以下）、合适的PEEP，若比值低于150 mmHg则考虑俯卧位（她已经低于此值）。同时治疗肺炎和脓毒症，并谨慎管理液体。
:::
:::

::: example 设定潮气量 {#ex-pbw}
一名身高178 cm、体重120 kg的男性因ARDS接受机械通气。6 mL/kg预计体重对应的潮气量是多少？为什么不应使用他的实际体重？
::: solution
PBW $= 50 + 0.91 \times (178 - 152.4) = 50 + 0.91 \times 25.6 = 50 + 23.3 = 73.3$ kg。

潮气量$= 6 \times 73.3 \approx 440$ mL。

用他的实际体重（120 kg）计算会得到720 mL，对他肺中那一小部分有通气的区域而言是造成损伤的容积。他的肺大小与其身高和性别相符；额外的体重并不会让肺变大。肥胖确实使胸壁更僵硬，这会影响对平台压的解读，但并不能成为使用更大潮气量的理由。
:::
:::

## 神经肌肉性呼吸衰竭 {#sec-neuromuscular}

神经肌肉疾病引起的呼吸衰竭很容易被漏诊，因为患者可能看起来并不窘迫，血氧饱和度直到晚期仍正常。呼吸肌无力，肺活量下降，咳嗽变弱，分泌物积聚，发生肺不张。延髓无力又增加了误吸风险。一旦发生衰竭，可以非常突然。

在**吉兰–巴雷综合征**和**肌无力危象**等疾病中，应在床旁连续测定用力肺活量（急性期每天数次）。肺活量持续下降，尤其是降至约20 mL/kg附近，或成人肺活量低于约1 L，并伴咳嗽无力、延髓功能障碍或$P_{aCO_2}$升高时，应请重症监护会诊，并考虑在危象发生之前择期插管。峰流量在此不是有用的指标，因为它取决于用力程度和气道口径，而非吸气肌力量（[[nervous-system/neuromuscular]]）。

::: example 无力却不气短 {#ex-gbs}
一名36岁男性在一次腹泻性疾病后出现上行性无力和腱反射消失，入院诊断为吉兰–巴雷综合征。他体重80 kg。入院时FVC 3.2 L。24小时内降至2.1 L，随后降至1.5 L。他呼吸空气时$S_pO_2$ 97%，自称"没事"。你该怎么做？
::: solution
他的FVC在一天内从40 mL/kg（$3.2/80$）降至约19 mL/kg（$1.5/80$），迅速降到20 mL/kg以下。他正常的血氧饱和度是一种虚假的安慰：低氧血症是神经肌肉性衰竭的晚期征象。他需要紧急**重症监护会诊**，并应考虑在失代偿之前择期插管和通气。还要寻找延髓无力（吞咽困难、咳嗽无力、鼻音），它会增加误吸风险；以及自主神经不稳定（心律失常、血压波动），这在吉兰–巴雷综合征中很常见。同时给予针对疾病的治疗（静脉注射免疫球蛋白或血浆置换）。
:::
:::

## 慢性呼吸衰竭与长期支持 {#sec-chronic}

有些患者存在长期的低氧血症或高碳酸血症。慢阻肺慢性低氧血症的长期氧疗见[[respiratory/asthma-copd]]。家庭NIV用于胸壁疾病、神经肌肉疾病和肥胖低通气所致的慢性高碳酸性衰竭，以及急性加重后仍有高碳酸血症的部分慢阻肺患者：在英国HOT-HMV试验（2017年）中，对这类患者在家庭氧疗基础上加用家庭NIV，延长了再入院或死亡前的时间。关于长期通气的决定，尤其是在运动神经元病等进行性疾病中，需要仔细讨论患者的目标，并在通气不再有帮助或患者不再希望继续时为生命末期做好规划（[[geriatrics-palliative/end-of-life-care]]）。

::: quiz
一名54岁肌无力危象男性FVC 1.1 L（体重85 kg），咳嗽无力，呼吸空气时$S_pO_2$ 96%。哪项陈述正确？
- [ ] 他的血氧饱和度表明通气充足
- [ ] 峰流量是监测他的最佳指标
- [x] 他需要紧急重症监护会诊，因为他的肺活量约为13 mL/kg
- [ ] 高流量吸氧可以预防呼吸衰竭
::: solution
他的FVC为$1.1/85 \approx 13$ mL/kg，远低于约20 mL/kg，且咳嗽无力：他有突发通气衰竭的高风险，需要紧急重症监护评估（[[#sec-neuromuscular]]）。在神经肌肉性衰竭中，血氧饱和度正常是晚期且不可靠的征象。峰流量取决于用力程度和气道口径，不能很好地反映吸气肌力量。氧对通气毫无作用，还可能掩盖低通气。
:::
:::

::: history
1952年哥本哈根脊髓灰质炎流行期间，布莱格丹医院被呼吸麻痹患者挤满，延髓型脊髓灰质炎患者的死亡率极高。麻醉医生比约恩·易卜生（Bjørn Ibsen）提出行气管切开并进行人工正压通气，由医学生轮班昼夜不停地用橡皮气囊手动通气；死亡率随之大幅下降。这次流行催生了最早的重症监护病房。1967年，戴维·阿什博（David Ashbaugh）、托马斯·佩蒂（Thomas Petty）及其同事描述了一种成人急性呼吸窘迫综合征，后来称为ARDS。2000年，ARDS Network试验证明小潮气量通气能挽救生命。20世纪90年代的随机试验确立了无创通气在慢阻肺急性加重中的地位，其中包括普兰特（Plant）、欧文（Owen）和埃利奥特（Elliott）在英国开展的一项多中心普通病房试验（2000年）。
:::

## 后续内容

本章是课程的最后一章。它所依赖的生理学见[[respiratory/mechanics-breathing]]、[[respiratory/gas-exchange]]和[[respiratory/control-breathing-tests]]，呼吸衰竭的常见病因见[[respiratory/asthma-copd]]、[[respiratory/respiratory-infections]]和[[respiratory/interstitial-vascular-disease]]。气道管理、复苏和重症监护中的器官支持在[[emergency-critical-care/airway-ventilation]]和[[emergency-critical-care/critical-care]]中进一步展开，急症患者的评估见[[emergency-critical-care/acute-assessment]]。

::: summary
- 1型：$P_{aO_2}$ < 8 kPa，$P_{aCO_2}$正常或偏低（气体交换衰竭）。2型：$P_{aCO_2}$ > 约6 kPa（通气衰竭）。每一型都可以是急性、慢性或慢性基础上急性加重。
- $P_{aCO_2}$与$\dot V_{CO_2}/\dot V_A$成正比；浅快呼吸即使使分钟通气量增加，也会减少肺泡通气量。
- 按目标开具氧疗：大多数人94–98%，有高碳酸血症风险者88–92%。需要精确时使用固定性能装置。高碳酸血症时不要突然停氧。
- CPAP治疗1型衰竭（如心源性肺水肿）；NIV治疗2型衰竭，尤其是伴持续呼吸性酸中毒（pH < 7.35，$P_{aCO_2}$ > 6.5 kPa）的慢阻肺。先商定治疗上限。
- 插管指征：气道保护、难治性低氧血症、NIV失败或衰竭。
- ARDS：双侧阴影和低氧血症，不能用心力衰竭解释；柏林定义按$P_{aO_2}$/$F_{IO_2}$分级。采用6 mL/kg预计体重、平台压 ≤ 30 cmH₂O、PEEP，中重度患者俯卧位通气。
- 神经肌肉疾病中监测FVC；血氧饱和度是晚期征象。
:::

## 习题

::: exercise 哪一型？ {level=1}
对下列每份血气（呼吸空气）分类：(a) $P_{aO_2}$ 7.1 kPa，$P_{aCO_2}$ 4.1 kPa，pH 7.47；(b) $P_{aO_2}$ 7.6 kPa，$P_{aCO_2}$ 8.9 kPa，pH 7.24，碳酸氢盐28 mmol/L；(c) $P_{aO_2}$ 7.4 kPa，$P_{aCO_2}$ 7.9 kPa，pH 7.38，碳酸氢盐35 mmol/L。
::: solution
(a) 1型呼吸衰竭，伴过度通气引起的呼吸性碱中毒。(b) 2型，急性：pH降低，碳酸氢盐几乎未升高。(c) 2型，慢性且已代偿：pH正常，碳酸氢盐因肾脏潴留而升高。
:::
:::

::: exercise 预计体重 {level=1 check="round(6*(45.5+0.91*(165-152.4)))"}
计算一名身高165 cm的女性按6 mL/kg预计体重的潮气量（mL，取最接近的整数）。
::: solution
PBW $= 45.5 + 0.91 \times (165 - 152.4) = 45.5 + 11.47 = 56.97$ kg。潮气量$= 6 \times 56.97 = 341.8$，取整为342 mL。
:::
:::

::: exercise 氧合比值 {level=1 check="150"}
一名机械通气患者在$F_{IO_2}$ 0.4时$P_{aO_2}$为8.0 kPa。计算以mmHg表示的$P_{aO_2}$/$F_{IO_2}$比值（1 kPa = 7.5 mmHg）。
::: solution
$8.0 \times 7.5 = 60$ mmHg；$60/0.4 = 150$ mmHg。若在PEEP至少5 cmH₂O时满足柏林定义的其他标准，则为中度ARDS。
:::
:::

::: exercise 通气量减半 {level=2 check="2*5.2"}
一名患者阿片类药物过量后肺泡通气量从4.0降至2.0 L/min，二氧化碳生成量不变。他原来的$P_{aCO_2}$为5.2 kPa。估计他新的稳态$P_{aCO_2}$（kPa）。
::: solution
$P_{aCO_2} \propto 1/\dot V_A$，因此肺泡通气量减半，$P_{aCO_2}$加倍：$5.2 \times 4.0/2.0 = 10.4$ kPa。根据肺泡气体方程，他的肺泡$P_{O_2}$将下降约$5.2/0.8 = 6.5$ kPa，引起A–a梯度正常的低氧血症。
:::
:::

::: exercise 选择装置 {level=2}
为下列患者建议合适的初始给氧装置和目标：(a) 一名25岁肺炎患者，呼吸空气时$S_pO_2$ 91%；(b) 一名70岁已知慢阻肺患者，既往有高碳酸性衰竭，$S_pO_2$ 84%；(c) 一名50岁心搏骤停患者。
::: solution
(a) 鼻导管（若需要更多则用普通面罩），目标94–98%。(b) 文丘里面罩24%或28%，目标88–92%，并查动脉血气了解有无高碳酸血症。(c) 尽可能高的浓度，复苏期间经带储氧袋的球囊–活瓣–面罩给予，自主循环恢复后再调整到目标范围。
:::
:::

::: exercise CPAP还是NIV？ {level=2}
为每位患者选择CPAP或NIV并说明理由：(a) 一名75岁慢阻肺患者，经一小时最佳治疗后pH 7.29，$P_{aCO_2}$ 8.4 kPa；(b) 一名60岁COVID-19肺炎患者，吸入60%氧时$S_pO_2$ 90%，$P_{aCO_2}$ 4.3 kPa；(c) 一名67岁运动神经元病患者，晨起头痛，日间$P_{aCO_2}$ 7.1 kPa。
::: solution
(a) **NIV**：慢阻肺急性加重中持续的高碳酸性酸中毒；吸气压力支持可增加肺泡通气量。(b) **CPAP**（或HFNO）：1型衰竭；正压使塌陷的肺泡复张并改善氧合；问题不在于通气支持。(c) **NIV**（家庭双水平通气）：呼吸肌无力所致的慢性高碳酸性衰竭；它在MND中改善症状和生存，同时要做尊重他对未来意愿的规划。
:::
:::

::: exercise NIV下病情恶化的患者 {level=3}
一名72岁慢阻肺女性因急性加重使用NIV已2小时，初始pH 7.26，$P_{aCO_2}$ 9.1 kPa。复查血气为pH 7.22，$P_{aCO_2}$ 10.2 kPa。她昏昏欲睡。可能出了什么问题？需要作出哪些决定？
::: hint
从患者、面罩、机器和计划几方面考虑。
:::
::: solution
她的NIV正在失败。检查：**面罩和管路**（漏气、贴合不良、接口不合适）；**参数**（吸气压力可能太低，不足以提供足够潮气量；检查EPAP是否足够、患者与呼吸机是否同步）；**氧**（血氧饱和度是否在88–92%内，还是混入的氧过多？）；**患者**（分泌物、新发气胸、肺炎加重、镇静或衰竭）；以及**诊断**（PE或心力衰竭等其他病因）。嗜睡加重伴酸中毒恶化，意味着她可能需要有创通气。这正是事先商定的**治疗上限**发挥作用的时候：若已判断插管合适，现在就应让重症监护参与；若已商定NIV为上限，重点可能转向舒适照护，并与她和家人坦诚沟通。
:::
:::

::: exercise 坠落后的低氧血症 {level=3}
一名30岁男性从高处坠落后入院，有多发肋骨骨折和股骨骨折。第2天他气短日益加重。经储氧面罩15 L/min吸氧时$S_pO_2$ 88%，$P_{aO_2}$ 7.6 kPa。胸片显示新出现的双侧斑片状阴影，超声心动图正常。给出鉴别诊断并概述管理原则。
::: solution
严重创伤后出现伴双侧阴影的低氧性（1型）衰竭。鉴别诊断包括**ARDS**（由创伤、肺挫伤、输血或脓毒症引起）、**肺挫伤**、**脂肪栓塞综合征**（长骨骨折后；寻找瘀点和意识模糊）、**误吸**、因肋骨疼痛咳嗽无力导致的**肺炎**，以及输血相关性肺损伤。创伤后也可能发生肺栓塞。必须排除气胸。

管理：上级医师和重症监护会诊；高流量吸氧，适当时改用CPAP或HFNO，并随时准备插管；一旦机械通气，采用肺保护性通气（约6 mL/kg预计体重，平台压 ≤ 30 cmH₂O，足够的PEEP），若$P_{aO_2}$/$F_{IO_2}$比值低于150 mmHg则俯卧位；良好镇痛（包括针对肋骨骨折的区域阻滞技术），以便咳嗽和深呼吸；血流动力学稳定后采取限制性液体管理；早期骨折固定；以及在出血风险允许时进行血栓预防。
:::
