呼吸衰竭要么是不能氧合，要么是不能排出二氧化碳；两者的诊断靠气体，而两者的治疗都在于找到失败的机制并支持它，直到可逆。本章涵盖这两种衰竭、急性呼吸的窘迫综合征与肺保护的通气、无创与体外的支持、脱机与慢性的家庭通气[[respiratory/gas-exchange]]、[[respiratory/mechanics-breathing]]。

本章涵盖两型的分类、机制与气体、支持与脱机，以及家庭的路径。

## 两种类型

::: definition 一型与二型的呼吸衰竭 {#def-types}
**一型（低氧的）：氧气下降而二氧化碳正常或低，机制是通气血流的不匹配与分流及少见的弥散的限制；肺泡-动脉的梯度会增宽，而反应对氧气的程度会提示分流[[respiratory/gas-exchange]]、[[respiratory/gas-exchange]]。二型（高碳酸的）：二氧化碳升高伴低氧，机制是泵或驱动的失败（中枢与神经肌肉的、胸壁与肌肉）或负荷超过了这些能力（严重的阻塞与呼吸的功）[[respiratory/control-breathing-tests]]、[[nervous-system/neuromuscular]]。急与慢很重要：急的高碳酸会把酸碱度急剧地降低（致命的酸中毒），而慢性的会允许肾的碳酸氢盐的补偿，所以一个二氧化碳很高而酸碱度接近正常的患者是慢性的或急性在慢性上[[renal/acid-base-disorders]]、[[respiratory/respiratory-failure]]。评估：气体的模式与代偿的规则（[[renal/acid-base-disorders]]）、肺功能与影像、驱动与肌肉的测试，以及病因的分类（气道与肺泡与间质及血管；泵与中枢）[[emergency-critical-care/acute-assessment]]。**
:::

::: example 四个气体，四张床 {#ex-types}
四位患者：(a) 肺炎，氧7.9而二氧化碳4.1；(b) 阿片类过量，氧6.2而二氧化碳10.5，酸碱度7.20；(c) 已知慢阻肺，氧8.0而二氧化碳11.8，酸碱度7.36、碳酸氢盐40；(d) 肌萎缩侧索硬化，夜间氧低而二氧化碳6.4，白天气体接近正常。
::: solution
(a) 一型（通气血流不匹配为主）：治疗原因与氧气，注意梯度[[respiratory/gas-exchange]]、[[respiratory/respiratory-infections]]。(b) 急的二型（驱动失败）：逆转药物并支持通气，因为酸碱度急降最危险[[emergency-critical-care/poisoning]]、[[respiratory/control-breathing-tests]]。(c) 慢性二型伴肾的补偿（碳酸氢盐高）：不要把氧气提高太快，按目标滴定并考虑无创的通气[[respiratory/asthma-copd]]、[[#def-support]]。(d) 早期睡眠相关的泵失败：白天的气体可以正常而睡眠先去失代偿，需要睡眠的监测与无创的支持[[#ex-home-niv]]、[[nervous-system/neuromuscular]]。四张床（呼吸、急诊、重症与神经）共享同一套解读的规则[[renal/acid-base-disorders]]、[[emergency-critical-care/acute-assessment]]。
:::
:::

## 急性呼吸的窘迫综合征与被保护的肺

::: definition 急性呼吸的窘迫综合征：受损的屏障与它的通气 {#def-ards}
**肺泡-毛细血管的屏障受损（肺炎与脓毒症及创伤和误吸及其他）导致通透性水肿与表面活性物质的失活、肺泡塌陷与肺的僵硬度上升：分流与不匹配，所以低氧对氧气的反应差[[respiratory/mechanics-breathing]]、[[immunology/innate-immunity]]、[[pathology/acute-inflammation]]。诊断（柏林的标准）：急性的起病与双影，并用心源性的水肿与积液做鉴别（超声与心指标）[[cardiovascular/heart-failure]]、[[clinical-skills/medical-imaging]]；按氧气的比值分层严重度，重度者死亡风险高[[#def-support]]。通气：小的按预测体重的潮气量与限制平台的压力（肺保护）、把呼气末的正压滴定、在重度时俯卧位与神经肌肉阻滞的谨慎选择；避免过度的二氧化碳与容量负荷[[renal/water-sodium]]。病因的治疗与支持同样重要；在难治中体外的支持转诊中心[[#def-support]]、[[emergency-critical-care/critical-care]]。**
:::

::: example 胰腺的肺 {#ex-ards}
一位重症胰腺炎的人在第二天出现呼吸急促与低氧；氧气的比值降到130；胸片双侧的阴影；超声显示B线不多而下腔静脉饱满。
::: solution
**一个由全身炎症引起的急性呼吸窘迫综合征（胰腺炎是经典的肺外病因）：氧合差、依从性低、而液体平衡很关键[[#def-ards]]、[[gastrointestinal/pancreas-biliary]]、[[immunology/innate-immunity]]。做法：肺保护的通气（小的按预测体重的潮气量与压力上限）、滴定呼气末的正压与氧气、在难治的重度病例中俯卧位[[#def-support]]、[[emergency-critical-care/critical-care]]；在休克复苏之后转向保守的液体策略以减轻肺的水肿[[emergency-critical-care/shock-fluids]]、[[renal/water-sodium]]；治疗胰腺炎与感染[[gastrointestinal/pancreas-biliary]]、[[infectious-diseases/fever-sepsis]]。避免：把压力与容量调得太高造成肺的二次损伤[[#def-ards]]、[[respiratory/mechanics-breathing]]。监测：气体与顺应性与超声及乳酸，并按趋势而非单个数字决策[[clinical-skills/laboratory-tests]]。
:::
:::

::: example 无力的呼吸 {#ex-myonum}
一位重症肌无力的人在第两天肌无力危象后出现潮气量小、咳嗽无力、二氧化碳6.8且酸碱度7.28，而饱和仍为95%。
::: solution
**一个二型的衰竭，因为泵失败：饱和会保持到最后，所以数字中的氧气是虚假的安慰[[nervous-system/neuromuscular]]、[[#def-types]]。评估：用力的容量与咳嗽的峰流速、二氧化碳的轨迹与临床的标志（吞咽与颈部的无力）[[nervous-system/motor-systems]]、[[respiratory/control-breathing-tests]]。升级：及早的干预（无创的支持在选定的病例中，但常常需要插管以保护气道与通气）；同时治疗危象（血浆的交换或免疫球蛋白与激素的调整）与寻找触发（感染与药物的调整）[[immunology/hypersensitivity]]、[[infectious-diseases/fever-sepsis]]、[[endocrine/adrenal]]。注意：胆碱能的危象与药物的相互作用会混淆[[pharmacology/autonomic-drugs]]、[[pharmacology/adverse-reactions]]。长期：有些患者需要间歇的家庭通气[[#ex-home-niv]]、[[nervous-system/neuromuscular]]。**
:::
:::

## 支持、脱机与家庭

::: definition 氧气设备与无创通气及高流量和体外的阶梯 {#def-support}
**氧气：从鼻管与面罩到非重吸入和高流量的鼻（提供一部分的压力与被控制的分数）；在潴留者中目标88%到92%[[respiratory/asthma-copd]]、[[respiratory/asthma-copd]]。无创的正压：把压力用于二型（慢阻肺的酸中毒与过度通气综合征和神经肌肉的）与部分的一型；成功依赖界面与漏气和容忍度，而失败的标准是气体和临床没有改善[[emergency-critical-care/airway-ventilation]]、[[respiratory/asthma-copd]]。插管与肺保护的通气：小的潮气量与压力上限与滴定[[#def-ards]]、[[emergency-critical-care/airway-ventilation]]；俯卧位、肌松与吸入的肺扩张剂用于重度[[#def-ards]]。体外（静脉-静脉的氧合与泵）用于难治的低氧或二氧化碳，作为桥接，并需要中心的转诊与抗凝[[emergency-critical-care/critical-care]]。脱机：每天的自主呼吸试验与风险的评估，把拔管的时间与再插管的预防（咳嗽的辅助与无创的桥接）；缓慢的脱机路径用于长期的通气者[[geriatrics-palliative/ageing-frailty]]。家庭的通气：在慢性的二型与神经肌肉的疾病及成功的缓慢脱机后的方案与随访[[#ex-home-niv]]、[[public-health/health-systems-economics]]。**
:::

::: example 夜班病房嗜睡的人 {#ex-home-niv}
一位58岁在慢阻肺稳定期仍白天二氧化碳8.9与碳酸氢盐36的人在用了无创通气八周后夜间二氧化碳下降、白天嗜睡改善；体重指数34并打鼾。
::: solution
**这是慢性的二型衰竭，重叠睡眠呼吸暂停在推动潴留：治疗要同时针对气道与夜间压力[[#def-types]]、[[respiratory/asthma-copd]]、[[respiratory/control-breathing-tests]]。评估：依从性的下载与漏气和界面与压力的设置；把二氧化碳在数周至三个月内逐步降低（不要过度纠正到正常的二氧化碳，因为会失同步）[[#def-support]]。并存：减重与代谢的因素及心[[endocrine/diabetes]]、[[cardiovascular/heart-failure]]；疫苗与急性加重的计划[[immunology/vaccines-immunotherapy]]、[[respiratory/asthma-copd]]。随访：气体与症状和住院的次数；若失败，讨论长期通气的目标与生活的计划（电池的备用与旅行的规则）[[geriatrics-palliative/palliative-care]]、[[public-health/health-systems-economics]]。**
:::
:::

::: quiz
保护性的潮气量按预测（而不是实际）的体重计算，因为：
- [ ] 脂肪组织耗氧少，所以肺需要更少的通气
- [x] 通气的肺的大小随身高与性别，而不随肥胖——肥胖者的肺并不更大
- [ ] 回路由理想体重校准
- [ ] 平台压会随实际体重下降
::: solution
**潮气量是把肺按每千克的通气的肺组织来设定；用实际的体重会给一个肥胖的人一个会过度膨胀其肺的容量[[#def-ards]]、[[respiratory/mechanics-breathing]]。伤害：容积伤与气压伤及剪切[[emergency-critical-care/critical-care]]。**
:::
:::

::: history
呼吸的支持史是生理与机器的历史：铁肺与负压的通气在脊髓灰质炎的病房中，然后是被改写的正压的技术与气管切开[[emergency-critical-care/critical-care]]、[[public-health/communicable-disease-control]]；气体的分析让衰竭可测量[[clinical-skills/laboratory-tests]]；急性呼吸窘迫综合征被描述并于后来被重命名，而小的潮气量的试验把肺保护变成一个标准，俯卧位与肌松成为重度的选项[[pathology/acute-inflammation]]；无创的通气把二氧化碳的衰竭（急性的与慢性的）变成了可以不经插管来治疗；而体外的氧合在最近的呼吸的疫情期间成为中心的桥接[[public-health/global-health]]。慢性与家庭的支持（包括设备的供应与随访）则把重症的技能变成了长期的照护[[public-health/health-systems-economics]]、[[geriatrics-palliative/ageing-frailty]]。
:::

## 通向何处

交换与梯度在[[respiratory/gas-exchange]]；压力与容积在[[respiratory/mechanics-breathing]]；驱动与肌肉在[[respiratory/control-breathing-tests]]与[[nervous-system/neuromuscular]]；气道与感染在[[respiratory/asthma-copd]]与[[respiratory/respiratory-infections]]；急的路径在[[emergency-critical-care/acute-assessment]]与[[emergency-critical-care/airway-ventilation]]；肾脏的替代与酸碱在[[renal/acid-base-disorders]]与[[renal/chronic-kidney-disease]]；而长期通气的决定在[[geriatrics-palliative/end-of-life-care]]。

::: summary
- 一型是氧合的失败（不匹配与分流），二型是通气的失败（驱动、泵或负荷）；气体与代偿会区分急与慢。
- 急性呼吸窘迫综合征是通透性水肿与塌陷的肺：氧合差、顺应性低，治疗是肺保护的通气与病因的管理和液体的纪律[[#def-ards]]。
- 支持是一个阶梯：被滴定的氧气、无创的正压、插管带小的潮气量与压力上限，然后俯卧位、肌松与体外的桥接[[#def-support]]。
- 肥胖者的潮气量按预测体重；平台压与驱动，而不是数字的漂亮，是目标[[#def-ards]]。
- 脱机与慢性支持要按测量来推进：每天的自主试验、拔管后的桥接，以及在慢性二型衰竭中的家庭通气与依从性的下载[[#ex-home-niv]]。
:::

## 练习

::: exercise 给气体分类 {level=1}
一位在用28%面罩而饱和89%的60岁患者：氧气7.1、二氧化碳5.0。估算肺泡-动脉梯度，分类衰竭并命名三个最可能的原因。
::: solution
肺泡的氧气约等于吸入减去二氧化碳除以0.8，用近似的数字得到梯度升高（远超年龄预期的范围），而二氧化碳正常：这是一个单纯一型的呼吸衰竭[[respiratory/gas-exchange]]、[[#def-types]]。三个原因：肺泡的实变（感染）与间质的或心源性的水肿，以及血管的（肺栓塞）[[respiratory/respiratory-infections]]、[[cardiovascular/heart-failure]]、[[respiratory/interstitial-vascular-disease]]。下一步：胸片与超声与CT按线索[[clinical-skills/medical-imaging]]。
:::
:::

::: exercise 计算设置 {level=1}
一位182厘米的男性有急性呼吸窘迫综合征：给出预测体重与每公斤6毫升的潮气量，以及平台压的上限。
::: solution
按性别的公式，男性的预测体重约等于身高（厘米）减100，约82千克，所以潮气量约490毫升（常从每千克6毫升并向下调整），平台压在试验中被限制在约30厘米水柱[[#def-ards]]、[[emergency-critical-care/airway-ventilation]]。若压力超限，把潮气量向下到每千克4-6毫升并提高频率以处理二氧化碳（允许的高碳酸）；监测驱动与顺应性[[respiratory/mechanics-breathing]]、[[renal/acid-base-disorders]]。切记：设置是给肺的处方，按通气的肺的大小，而不是按称出的体重[[#def-support]]。
:::
:::

::: exercise 俯卧的数字 {level=2}
哪些急性呼吸窘迫综合征的患者从俯卧位最获益，通过哪些机制，而俯卧的一天在后勤上是什么样子？
::: solution
获益最大的是重度的（氧气的比值很低）早期阶段；机制是把通气血流重新分布、减少依赖区的塌陷与剪切，并改善分泌的引流[[#def-ards]]、[[respiratory/gas-exchange]]。后勤：每天长的时段（试验支持较长的时数）、一个被训练的团队、气道与管路与压力的保护和眼与面部的皮肤和喂养与神经的监测[[emergency-critical-care/critical-care]]、[[clinical-skills/patient-safety]]。同时保持肺保护的设置并按气体决定时长与疗程[[#def-support]]。
:::
:::

::: exercise 开始与失败无创通气 {level=2}
给出在急性加重的慢阻肺中启动无创通气的标准、一到两小时的成功核查，以及过早停止与换用的理由。
::: solution
启动：在优化医学治疗后仍酸碱度低于7.35且二氧化碳升高，伴严重的症状或恶化[[respiratory/asthma-copd]]、[[respiratory/asthma-copd]]。核查在一到两小时：酸碱度与二氧化碳的改善和呼吸率与辅助肌及意识[[emergency-critical-care/acute-assessment]]。早停与换用的理由：不能耐受（界面与幽闭感）、呕吐与气道风险、血流动力学不稳定、意识下降或气体的恶化——这些都需要插管而不是再等[[emergency-critical-care/airway-ventilation]]、[[emergency-critical-care/critical-care]]。陷阱：把目标氧气设置过高，或在没有酸中毒的慢性潴留中常规使用[[#def-support]]。
:::
:::

::: exercise 按数字脱机 {level=2}
定义自主呼吸试验与拔管的风险指数，并为失败的患者写出鉴别。
::: solution
试验是用一个低的支持（管路的补偿或一个低的压力支持）在30到120分钟内观察频率与潮气量与临床；常用指数是频率除以潮气量（过高提示失败）[[emergency-critical-care/airway-ventilation]]、[[respiratory/mechanics-breathing]]。失败的鉴别：心（容量与缺血）[[cardiovascular/heart-failure]]、气道（慢阻肺与分泌物）[[respiratory/asthma-copd]]、肌肉与神经（重症的肌病与药物）[[nervous-system/neuromuscular]]、负荷（感染与高分钟通气）[[infectious-diseases/fever-sepsis]]，以及中枢与焦虑[[psychiatry/anxiety-disorders]]、[[nervous-system/stroke]]。管理是找到这个原因，然后缓慢的脱机与拔管后的无创/高流量的桥接[[#def-support]]、[[geriatrics-palliative/ageing-frailty]]。
:::
:::

::: exercise 呼吸机自己的损伤 {level=2}
列出呼吸机相关肺损伤的机制与对应的保护的动作，包括在正常的肺中。
::: solution
机制：容积伤（过度的膨胀）、气压伤（高的压力与漏气的气胸）、这些不张伤（周期的开闭）、生物伤（炎症的释放）与干燥与黏液的滞留[[#def-ards]]、[[pathology/acute-inflammation]]。保护：小的按预测体重的潮气量与压力上限、被滴定的呼气末正压、在选定的中的招募与俯卧位、避免长的纯氧气暴露与容量过负荷，以及镇静的最小化与自主的试验[[#def-support]]、[[emergency-critical-care/critical-care]]。在正常的肺中（手术与神经的）同样要避免过度的膨胀与高氧气：呼吸机的设置是处方，要有适应证[[surgery/perioperative-care]]、[[surgery/anaesthesia-pain]]。
:::
:::

::: exercise 慢性支持的决定 {level=2}
哪些慢性的疾病值得长期的通气（家庭的无创或气管切开），按什么标准？
::: solution
高碳酸慢阻肺的表型（在急性加重之后仍潴留）、重叠的睡眠呼吸暂停、神经肌肉的疾病（肌萎缩侧索硬化与肌病及膈肌的瘫痪）、胸壁与脊柱的畸形、肥胖的低通气，以及在缓慢脱机后长期的通气依赖[[respiratory/asthma-copd]]、[[nervous-system/neuromuscular]]、[[musculoskeletal/back-pain]]。标准：二氧化碳的阈值与症状、反复的住院与急性加重的失败、夜间监测的证据、以及依从性与目标和照护的能力[[#ex-home-niv]]、[[geriatrics-palliative/falls]]。决定要包含预后的不确定与意愿（气管切开与撤下设备的讨论）[[medical-ethics-law/end-of-life-ethics]]、[[clinical-skills/communication]]；服务的负担（设备的供应与随访）也要考虑[[public-health/health-systems-economics]]。
:::
:::

::: exercise 设计呼吸衰竭的路径 {level=3}
为全院构建一条从病房的低氧到重症再回来的路径：识别的触发、氧气的管理、升级与上限的架构、重症后的随访，带生理的理由。
::: solution
识别：把氧气评分（饱和与呼吸率与意识）与升级的阈值自动化，加上二氧化碳红旗在潴留者[[emergency-critical-care/acute-assessment]]、[[clinical-skills/patient-safety]]。氧气管理：被滴定的目标（88-92在风险，其他94-98）与对自由流动处方的审核，避免伤害也避免遗漏[[#def-support]]、[[respiratory/asthma-copd]]。升级：明确呼叫的标准与无创和高流量的路径及重症的床位[[emergency-critical-care/airway-ventilation]]、[[emergency-critical-care/critical-care]]；治疗上限与偏好在一个被记录的计划中（心肺的复苏与通气的界限）[[medical-ethics-law/end-of-life-ethics]]、[[clinical-skills/records-handover]]。脱出：脱机的协议与拔管后的桥接，然后重症后的随访（肺功能与肌肉与认知和家属）[[geriatrics-palliative/ageing-frailty]]、[[psychiatry/mood-disorders]]、[[respiratory/control-breathing-tests]]。
