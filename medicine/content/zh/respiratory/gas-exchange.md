肺的存在就是为了让血液和空气彼此靠近。每分钟约5升血液流经肺毛细血管，铺展成一层只有一个红细胞厚的薄层，覆盖约70平方米的肺泡表面，与空气之间隔着一层不到1微米厚的屏障。静息时，机体每分钟通过这层屏障摄取约250 mL氧，排出约200 mL二氧化碳。

气体交换失败的结果是低氧血症、高碳酸血症或两者兼有。它只有五种失败方式，而少数几个方程就能在床旁把它们区分开来。本章介绍这些方程：分压与肺泡气方程、弥散、通气与血流的匹配，以及氧和二氧化碳在血液中的运输。

## 分压 {#sec-partial}

气体通过弥散从分压高处移向分压低处。混合气体中某种气体的分压等于其所占分数乘以总压（道尔顿定律）。溶解于液体中的气体，其分压等于与该液体处于平衡的气相中该气体的分压。

::: definition 吸入气与肺泡气分压 {#def-partial}
- **吸入气氧分压**（$P_{IO_2}$）是空气在上气道中被加温至体温并被水蒸气饱和后的氧分压：
  $P_{IO_2} = F_{IO_2} \times (P_B - P_{H_2O})$，其中$F_{IO_2}$为氧所占分数（空气为0.21），$P_B$为大气压，$P_{H_2O}$为37 °C时的水蒸气压（6.3 kPa，47 mmHg）。
- **肺泡气氧分压**（$P_{AO_2}$）是肺泡气中的氧分压。它低于$P_{IO_2}$，因为氧不断被血液带走，并被二氧化碳替代。
- **动脉血分压**（$P_{aO_2}$、$P_{aCO_2}$）通过动脉血气样本测定。在海平面呼吸空气时的典型值：$P_{aO_2}$ 11–13 kPa（80–100 mmHg），$P_{aCO_2}$ 4.7–6.0 kPa（35–45 mmHg）。
:::

在海平面，$P_B$ = 101.3 kPa，$P_{IO_2} = 0.21 \times (101.3 - 6.3) \approx 20.0$ kPa（150 mmHg）。

### 肺泡气方程

要知道肺转运氧的效率如何，需要知道肺泡$P_{O_2}$是多少。它无法直接取样，但可以计算。

::: theorem 肺泡气方程 {#thm-age}
在稳态下，肺泡气氧分压近似为

$$
P_{AO_2} = P_{IO_2} - \frac{P_{aCO_2}}{R}
$$ {#eq-age}

其中$R$为呼吸交换率（二氧化碳产生量除以氧消耗量），在一般混合膳食下取0.8。由于动脉$P_{CO_2}$与肺泡$P_{CO_2}$几乎相同，用前者代替后者。
:::

::: proof
每一升肺泡通气都以吸入气分压带入氧。氧从肺泡进入血液，二氧化碳则从血液进入肺泡。如果机体每消耗一个氧分子就产生一个二氧化碳分子（$R = 1$），肺泡$P_{O_2}$低于吸入气的幅度就等于肺泡$P_{CO_2}$高于吸入气（接近零）的幅度。由于$R$通常小于1，带走的氧多于加入的二氧化碳，$P_{O_2}$的下降更大：为$P_{CO_2}/R$。这个方程揭示了临床应用的要点：$P_{aCO_2}$升高（通气不足）或吸入氧降低（高原）时，肺泡$P_{O_2}$下降。
:::

在海平面呼吸空气、$P_{aCO_2}$正常为5.3 kPa时：$P_{AO_2} = 20.0 - 5.3/0.8 \approx 13.3$ kPa。

::: definition 肺泡–动脉血氧分压差 {#def-aa}
**A–a梯度**是差值$P_{AO_2} - P_{aO_2}$，衡量氧从肺泡气进入动脉血的效率。健康青年人呼吸空气时低于约2 kPa（15 mmHg）；它随年龄增大（以mmHg计的大致上限为年龄/4 + 4）。梯度升高意味着肺本身有问题：通气/血流失调、分流，较少见的是弥散受限。
:::

梯度在呼吸空气时最有用。吸氧时正常梯度会大得多，也更难预测，因此对吸氧时算出的梯度应谨慎解读；重症医学中改用$P_{aO_2}$与$F_{IO_2}$之比（P/F比值）（[[respiratory/respiratory-failure]]）。

::: example 两名低氧血症患者 {#ex-a-a}
两人均在海平面呼吸空气。分别计算A–a梯度并说明其意义。

(a) 一名74岁女性，髋关节置换术后第3天突然气短：$P_{aO_2}$ 8.5 kPa，$P_{aCO_2}$ 3.8 kPa。

(b) 一名26岁男性，被发现时昏昏欲睡，此前使用了不明剂量的海洛因：$P_{aO_2}$ 7.8 kPa，$P_{aCO_2}$ 9.0 kPa。
::: solution
(a) $P_{AO_2} = 20.0 - 3.8/0.8 = 20.0 - 4.75 = 15.2$ kPa。梯度$= 15.2 - 8.5 = 6.7$ kPa，明显升高。她在过度通气（$P_{aCO_2}$低），这本应使$P_{aO_2}$升高，但$P_{aO_2}$却很低。肺未能正常转运氧。在这种情况下首先要考虑肺栓塞（[[respiratory/interstitial-vascular-disease]]）；肺炎和肺不张是其他可能。

(b) $P_{AO_2} = 20.0 - 9.0/0.8 = 20.0 - 11.25 = 8.75$ kPa。梯度$= 8.75 - 7.8 \approx 0.9$ kPa，正常。他的肺功能正常；问题在于他呼吸不够。阿片类药物所致通气不足使肺泡$P_{CO_2}$升高，挤占了氧的位置。治疗是逆转病因并支持通气，而不只是给氧。低氧血症伴梯度正常，总是指向通气不足或吸入氧过低。（如果他同时发生了误吸，梯度就会升高。）
:::
:::

## 跨膜弥散 {#sec-diffusion}

氧和二氧化碳以被动弥散的方式穿过肺泡–毛细血管屏障。该屏障由肺泡上皮、融合的基底膜、毛细血管内皮、一薄层血浆和红细胞膜构成。

::: theorem 菲克弥散定律 {#thm-fick}
气体穿过一层组织的转运速率为

$$
\dot V_{gas} = \frac{A \cdot D \cdot (P_1 - P_2)}{T}
$$ {#eq-fick}

其中$A$为面积，$T$为厚度，$P_1 - P_2$为分压差，$D$为弥散常数，与气体的溶解度成正比，与其分子量的平方根成反比。
:::

二氧化碳的溶解度约为氧的20倍，因此在相同压力差下其弥散速度约快20倍。实际上，弥散受限几乎从不引起二氧化碳潴留：$P_{aCO_2}$升高是通气的问题。

静息时，血液在肺毛细血管中停留约0.75秒，而血液中的氧分压只需约三分之一的时间就能达到肺泡水平，安全余量很大。在这种条件下，氧的摄取是**灌注限制性**的：要摄取更多氧，需要更多血流，而不是更快的弥散。当屏障增厚（纤维化）、面积减少（肺气肿、毛细血管丧失）、通过时间缩短（剧烈运动）或驱动压低（高原）时，弥散就成为限制因素。这些因素会叠加。肺纤维化患者静息时$P_{aO_2}$可能正常，步行时却明显降低，因为血流加快缩短了通过时间。

::: definition 一氧化碳弥散量 {#def-tlco}
**一氧化碳转移因子**（TLCO，北美称DLCO）的测定方法是：吸入少量、安全浓度的一氧化碳和一种惰性示踪气体，屏气约10秒，然后测定一氧化碳被摄取了多少。之所以用一氧化碳，是因为它与血红蛋白结合极其牢固，血液中的一氧化碳分压始终接近零，因此其摄取量反映的是膜和毛细血管血容量。**转移系数**（KCO）是TLCO除以测试中测得的肺泡容积。
:::

TLCO在肺气肿、间质性肺疾病、肺血管疾病和贫血时降低，在红细胞增多症和肺泡出血时升高（肺泡内额外的血红蛋白会摄取一氧化碳）。TLCO和KCO的模式如何应用，见[[respiratory/control-breathing-tests]]。

## 通气与血流 {#sec-vq}

气体交换要正常进行，每个肺泡都需要空气和血液，而且比例合适。总体而言，肺泡通气量约为4 L/min，肺血流量约为5 L/min，比值约为0.8。但这一比值并不均一。

::: definition 通气/血流比值、无效腔与分流 {#def-vq}
- 一个肺单位的**通气/血流比值**（$\dot V/\dot Q$）是其肺泡通气量除以其血流量。
- **无效腔**是不参与气体交换的通气（$\dot V/\dot Q = \infty$）。**解剖无效腔**是传导气道，成人约150 mL（约2 mL/kg）。**肺泡无效腔**是有通气而无血流灌注的肺泡。两者合为**生理无效腔**。
- **分流**是未经过有通气肺泡就进入动脉循环的血液（$\dot V/\dot Q = 0$）。少量生理性分流来自支气管静脉和心最小静脉。病理性分流来自完全塌陷或被液体充填的肺泡，或来自心脏或肺内的解剖性右向左通道。
- **通气/血流失调**是指存在一系列介于上述两个极端之间的比值的肺单位。
:::

在直立位的肺中，由于重力作用，通气和血流都从肺尖向肺底增加，但血流增加得更陡。因此肺尖$\dot V/\dot Q$比值高，肺底比值低。约翰·韦斯特（John West）根据肺泡压、动脉压和静脉压之间的关系，把肺划分为若干区；在只在疾病或正压通气时才存在的1区，肺泡压超过动脉压，毛细血管被压闭。

### 为什么低V/Q肺单位引起低氧血症而通常不引起高碳酸血症

离开低$\dot V/\dot Q$肺单位的血液$P_{O_2}$低、$P_{CO_2}$高。离开高$\dot V/\dot Q$肺单位的血液$P_{O_2}$高、$P_{CO_2}$低。由于氧解离曲线的形状（见下文），二者在肺静脉中混合后，氧并不会被平均化：来自通气良好单位的血液已接近完全饱和，对其过度通气几乎不能增加氧。来自通气不良单位的低饱和度血液主导了混合结果。

二氧化碳则不同。它的解离曲线在生理范围内几乎呈直线，因此对健康单位过度通气可以排出额外的二氧化碳，弥补通气不足的单位。脑干感受到$P_{aCO_2}$升高后会增加通气来做到这一点。这就是为什么大多数肺炎、肺栓塞或哮喘患者在低氧血症的同时$P_{aCO_2}$偏低或正常。$P_{aCO_2}$升高意味着总通气已跟不上，是疲劳或病情严重的征象。

::: definition 低氧血症的五种原因 {#def-hypox}
1. **吸入氧过低**（高原）：A–a梯度正常。
2. **通气不足**：$P_{aCO_2}$升高，A–a梯度正常。
3. **弥散受限**：梯度升高，主要在运动时。
4. **通气/血流失调**：梯度升高；吸氧后改善良好。
5. **分流**：梯度升高；吸氧后改善不佳。
:::

最后一点区分在床旁很有用。在V/Q失调中，即使通气不良的单位也能得到一些新鲜气体；提高吸入氧浓度会提高这些单位的肺泡$P_{O_2}$，血氧饱和度随之改善。在真正的分流中，分流的血液根本接触不到增加的氧，而流经有通气肺泡的血液已接近饱和，无法再多携带。因此大量分流引起的低氧血症对高流量吸氧几乎没有反应。

::: theorem 低氧性肺血管收缩 {#thm-hpv}
肺小动脉在其周围肺泡$P_{O_2}$下降时收缩。这使血流从通气不良的区域转向通气较好的区域，改善$\dot V/\dot Q$匹配。
:::

低氧性肺血管收缩由乌尔夫·冯·奥伊勒（Ulf von Euler）和约兰·利耶斯特兰德（Göran Liljestrand）于1946年描述。它与体循环血管相反，后者在缺氧时扩张。当病变局限于一个区域时，如大叶性肺炎，它的效果很好。当全肺缺氧时，如在高原或重度慢阻肺中，广泛的血管收缩使肺动脉压升高，若持续存在，会促成肺动脉高压和右心衰竭（肺源性心脏病）。在胎儿期，它使肺血流保持在低水平，直到出生后最初几次呼吸。

::: example 吸氧也纠正不了的低氧血症 {#ex-shunt}
一名52岁男性患重症肺炎，累及两肺下叶，呼吸空气时血氧饱和度86%。经文丘里面罩吸入60%氧，血氧饱和度只升至89%；改用非重复吸入面罩后为90%。这种反应提示什么？
::: solution
大幅提高吸入氧浓度而反应不佳，提示存在大量**分流**：血液流经完全被炎性渗出物充填的肺泡。这些血液根本接触不到增加的氧。流经其余有通气肺泡的血液已接近完全饱和，提高其肺泡$P_{O_2}$几乎无济于事。低氧性血管收缩未能把足够的血流从实变的肺转移开。生理上的解决办法不是更多的氧，而是重新打开被液体充填的肺泡，这就是呼气末正压（CPAP或机械通气）以及重症时俯卧位的依据（[[respiratory/respiratory-failure]]）。
:::
:::

### 无效腔的测定

玻尔方程可估计每次呼吸中被浪费的部分。呼出气中的二氧化碳只来自有血流灌注的肺泡；无效腔贡献的是不含二氧化碳的气体，并将其稀释。

$$
\frac{V_D}{V_T} = \frac{P_{aCO_2} - P_{\bar E CO_2}}{P_{aCO_2}}
$$ {#eq-bohr}

其中$P_{\bar E CO_2}$为混合呼出气中的二氧化碳分压。正常值约为0.3。它在肺栓塞、肺气肿以及浅快呼吸时升高，因为解剖无效腔是从每次呼吸中扣除的固定容积。一个人以500 mL潮气量呼吸、无效腔为150 mL时，每次呼吸浪费30%；同一个人以250 mL潮气量呼吸时则浪费60%。

## 氧的运输 {#sec-o2}

氧在血浆中溶解度很低：每分升血液每kPa仅约0.023 mL（每mmHg 0.003 mL/dL）。在正常$P_{aO_2}$下仅约0.3 mL/dL，远不足以供应组织。几乎所有的氧都与血红蛋白结合运输。

::: definition 氧含量与氧输送 {#def-content}
动脉血**氧含量**（mL/dL）为

$$
C_{aO_2} = 1.34 \times [\text{Hb}] \times S_{aO_2} + 0.023 \times P_{aO_2}
$$ {#eq-content}

其中血红蛋白[Hb]单位为g/dL，饱和度$S_{aO_2}$以分数表示，$P_{aO_2}$单位为kPa。1.34是1 g完全饱和的血红蛋白所携带的氧量（mL）。**氧输送量**为$D_{O_2} = \text{心输出量} \times C_{aO_2}$，静息时约1000 mL/min。（英国实验室以g/L报告血红蛋白，除以10即得g/dL。）
:::

这个方程显示了氧输送减少的三条途径：饱和度低（肺衰竭）、血红蛋白低（贫血）和心输出量低（心力衰竭、休克）。严重贫血者可能血氧饱和度完美、$P_{aO_2}$正常，但氧含量只有正常的一半。

### 氧解离曲线

血红蛋白有四个血红素基团，一个基团结合氧后，其他基团更容易结合氧（协同结合）。由此得到的饱和度对$P_{O_2}$曲线呈S形。

:::

曲线形状有两个特点具有临床意义。

- **平坦的上段。** 在约8 kPa（60 mmHg）以上，饱和度超过90%，变化很小。肺内氧的装载因此不怕肺泡$P_{O_2}$的中度下降。但这也意味着脉搏血氧仪读数98%无法区分$P_{aO_2}$是13 kPa还是40 kPa：血氧饱和度监测掩盖了高氧，也掩盖了正在接受高流量吸氧的患者的病情恶化，直到$P_{aO_2}$已下降很多。
- **陡峭的下段。** 在约2–6 kPa之间，$P_{O_2}$稍有下降就释放大量氧。在$P_{O_2}$低的组织中，氧容易卸载。这也意味着一旦患者$P_{aO_2}$降到8 kPa以下，饱和度会迅速下降。

::: definition P50与曲线移位 {#def-p50}
**P50**是血红蛋白50%饱和时的$P_{O_2}$，正常约3.5 kPa（26–27 mmHg）。**右移**（P50升高）意味着亲和力降低、更易卸氧，由氢离子浓度和$P_{CO_2}$升高（**玻尔效应**）、体温升高和2,3-二磷酸甘油酸（2,3-BPG）升高引起。**左移**（P50降低）意味着亲和力升高、卸氧困难，由相反的变化以及胎儿血红蛋白、一氧化碳和高铁血红蛋白引起。
:::

玻尔效应非常符合生理需要：在温暖、酸性、富含二氧化碳的运动肌肉中，血红蛋白更容易释放氧。胎儿血红蛋白与2,3-BPG结合较弱，因此其曲线位于母体曲线左侧，有利于氧通过胎盘。

::: example 出租屋里的头痛 {#ex-co}
一个冬天的早晨，一名34岁女性和她的室友都出现头痛、恶心和嗜睡。她们的脉搏血氧仪读数为99%。经碳氧血红蛋白测定仪测定，静脉血气显示碳氧血红蛋白为28%。请解释为什么脉搏血氧仪的读数令人放心却是错误的，以及她为什么在组织水平缺氧。
::: solution
一氧化碳与血红蛋白的亲和力约为氧的200–250倍。碳氧血红蛋白为28%时，她超过四分之一的血红蛋白不能携氧，因此尽管$P_{aO_2}$正常，氧含量大约按这一比例减少。更糟的是，一氧化碳结合在部分血红素基团上，会增加其余基团对氧的亲和力，使曲线左移，因此所携带的氧在组织中更难释放。标准脉搏血氧仪使用两种波长的光，无法区分碳氧血红蛋白和氧合血红蛋白，因此读数假性正常。诊断需要碳氧血红蛋白测定（多波长血氧测定），它能测定多种血红蛋白。治疗是高浓度吸氧（缩短碳氧血红蛋白的半衰期），同时找到并去除来源（此例很可能是锅炉故障）。同一住所内多人出现相似症状是典型线索（[[emergency-critical-care/poisoning]]）。
:::
:::

### 脉搏血氧测定

脉搏血氧仪让红光和红外光穿过手指或耳垂。氧合血红蛋白和脱氧血红蛋白对这两种波长的吸收不同，仪器只分析信号中的搏动部分，以此估算动脉血氧饱和度（$S_pO_2$）。它快速、无痛、可连续监测，但有局限：

- 无法发现一氧化碳中毒或高铁血红蛋白血症。
- 灌注不良（肢端冰冷、休克）、肢体活动和某些指甲油会使其不可靠。
- 它不反映通气：吸氧患者可能血氧饱和度正常而$P_{aCO_2}$已危险地升高。
- 在低饱和度时准确性较差。
- **在皮肤色素较深的人中，它会高估饱和度。** 比较脉搏血氧测定与动脉血样本的研究，包括2020年发表的一项美国大型分析发现，隐匿性低氧血症（真实动脉血氧饱和度低于88%而血氧仪读数为92–96%）在黑人患者中的发生率约为白人患者的三倍。英国医疗器械公平性独立审查（2024年）建议就此采取行动。实践中，临床医生应了解这种偏差，关注趋势和全面的临床情况，在决策关键时使用动脉血气。

## 二氧化碳的运输 {#sec-co2}

二氧化碳以三种形式运输。在组织中进入血液的二氧化碳，约60%以碳酸氢盐形式运输，约30%以氨基甲酰化合物形式运输（与氨基结合，主要在血红蛋白上），约10%以溶解形式运输。

碳酸氢盐在红细胞内生成，碳酸酐酶加速反应$\text{CO}_2 + \text{H}_2\text{O} \rightleftharpoons \text{H}_2\text{CO}_3 \rightleftharpoons \text{H}^+ + \text{HCO}_3^-$。碳酸氢根与氯离子交换离开细胞（**氯转移**），氢离子则由血红蛋白缓冲。脱氧血红蛋白比氧合血红蛋白是更好的缓冲剂，也更容易形成氨基甲酰化合物，因此在相同$P_{CO_2}$下静脉血能携带更多二氧化碳。这就是**霍尔丹效应**。在肺内，血红蛋白氧合后释放二氧化碳，有助于其排出。

霍尔丹效应也有其临床一面。慢性高碳酸血症患者吸入高浓度氧时，血红蛋白氧合增加，将二氧化碳释放到血液中，这是其$P_{aCO_2}$可能升高的原因之一（[[respiratory/control-breathing-tests]]）。

二氧化碳与pH之间的联系（亨德森–哈塞尔巴尔赫关系）使通气成为机体最快的酸碱调节器。这一主题见[[physiology/acid-base]]。

::: example 高原上的登山者 {#ex-altitude}
一名健康的29岁登山者到达海拔4000 m的山屋，那里的大气压约为61.6 kPa。她呼吸急促，$P_{aCO_2}$为4.0 kPa。估算她的肺泡$P_{O_2}$，并解释过度通气如何帮助她。
::: solution
$P_{IO_2} = 0.21 \times (61.6 - 6.3) = 0.21 \times 55.3 = 11.6$ kPa。

$P_{AO_2} = 11.6 - 4.0/0.8 = 11.6 - 5.0 = 6.6$ kPa。

她的肺泡$P_{O_2}$约为海平面值的一半。空气中氧所占的分数不变，变的是总压。她的颈动脉体感受到$P_{aO_2}$降低，驱动通气增加（低氧通气反应）。根据[[#eq-age]]，把$P_{aCO_2}$从5.3降到4.0 kPa可使肺泡$P_{O_2}$升高约1.6 kPa，而在解离曲线的陡峭段，这能带来很大差别。她的A–a梯度正常；她的低氧血症完全来自吸入$P_{O_2}$过低。几天之内，肾脏排出碳酸氢盐以纠正呼吸性碱中毒，使通气得以进一步增加（习服）。
:::
:::

::: example 贫血与氧含量 {#ex-content}
一名61岁男性因结肠肿瘤出血，血红蛋白75 g/L，$S_aO_2$ 98%，$P_{aO_2}$ 13.3 kPa。将他的动脉血氧含量与一名血红蛋白150 g/L、饱和度和$P_{aO_2}$相同的人比较。
::: solution
将血红蛋白换算为g/dL：7.5和15。

正常：$C_{aO_2} = 1.34 \times 15 \times 0.98 + 0.023 \times 13.3 = 19.70 + 0.31 \approx 20.0$ mL/dL。

贫血：$C_{aO_2} = 1.34 \times 7.5 \times 0.98 + 0.31 = 9.85 + 0.31 \approx 10.2$ mL/dL。

尽管他的饱和度和$P_{aO_2}$都完美，氧含量却约为正常的一半。他通过增加心输出量（心动过速）以及在组织中提高氧摄取来代偿，红细胞2,3-BPG的升高也有帮助。给他补充氧几乎没有增益，因为他的血红蛋白已经饱和；治疗是止血和恢复血红蛋白，有临床指征时输血（[[blood/transfusion]]）。
:::
:::

::: quiz
一名呼吸空气的低氧血症患者A–a梯度正常。下列哪项是最可能的原因？
- [ ] 大叶性肺炎
- [ ] 肺栓塞
- [x] 阿片类药物过量所致通气不足
- [ ] 特发性肺纤维化
::: solution
低氧血症伴梯度正常，意味着肺转运氧的功能正常，问题在于到达肺泡的氧：通气不足（如本例，伴$P_{aCO_2}$升高）或吸入氧过低（如在高原）。肺炎（分流和V/Q失调）、肺栓塞（V/Q失调）和肺纤维化（V/Q失调和弥散受限）都会使梯度增大（[[#def-hypox]]）。
:::
:::

::: history
19世纪后期，克里斯蒂安·玻尔（Christian Bohr）和约翰·斯科特·霍尔丹（John Scott Haldane）都认为肺会主动向血液分泌氧。奥古斯特·克罗格（August Krogh）与其妻子玛丽·克罗格（Marie Krogh）合作，于1910年以精细的测量证明仅靠弥散就足以解释氧的摄取，平息了这一争论。约瑟夫·巴克罗夫特（Joseph Barcroft）在20世纪初描述了解离曲线及其移位；玻尔、哈塞尔巴尔赫（Hasselbalch）和克罗格已于1904年描述了二氧化碳对曲线的影响。1949年，理查德·莱利（Richard Riley）和安德烈·库尔南（André Cournand）提出了肺的三室模型（理想肺泡、无效腔和分流），临床医生至今仍用它来推理血气。乌尔夫·冯·奥伊勒（Ulf von Euler）和约兰·利耶斯特兰德（Göran Liljestrand）于1946年描述了低氧性肺血管收缩。20世纪60年代，约翰·韦斯特（John West）用放射性气体显示了直立位肺中通气和血流的区域差异。1972年，日本工程师青柳卓雄（Takuo Aoyagi）提出了现代脉搏血氧仪所依据的双波长原理。
:::

## 后续内容

调节通气使这些气体维持在设定值的调控系统，以及测定它们的检查方法，见[[respiratory/control-breathing-tests]]。A–a梯度和分流将在[[respiratory/interstitial-vascular-disease]]（肺栓塞和肺纤维化）以及[[respiratory/respiratory-failure]]中再次出现，后者根据气体交换的具体失败环节选择氧疗和通气。二氧化碳的酸碱方面见[[physiology/acid-base]]，血红蛋白本身见[[blood/haemoglobin-disorders]]。

::: summary
- $P_{IO_2} = F_{IO_2}(P_B - 6.3)$ kPa；在海平面呼吸空气时约20 kPa。
- 利用肺泡气方程$P_{AO_2} = P_{IO_2} - P_{aCO_2}/0.8$可计算A–a梯度。低氧血症伴梯度正常意味着通气不足或吸入氧过低；梯度升高意味着肺部疾病。
- 弥散遵循菲克定律。二氧化碳的弥散约比氧快20倍。TLCO反映气体交换面。
- 低氧血症有五种原因：$P_{IO_2}$过低、通气不足、弥散受限、V/Q失调和分流。分流对吸氧反应差。
- 低氧性肺血管收缩使血流离开通气不良的肺；全肺性收缩会引起肺动脉高压。
- 氧含量取决于血红蛋白、饱和度和（少量）$P_{aO_2}$。S形解离曲线保护氧的装载并有利于卸载；其P50在酸、$P_{CO_2}$、热和2,3-BPG升高时右移。
- 脉搏血氧测定发现不了一氧化碳，不反映$P_{aCO_2}$，并在皮肤色素较深的人中高估饱和度。
- 二氧化碳主要以碳酸氢盐形式运输；霍尔丹效应把其运输与氧合联系起来。
:::

## 习题

::: exercise 吸入气氧分压 {level=1 check="0.21*(101.3-6.3)"}
计算在大气压101.3 kPa下呼吸空气（$F_{IO_2}$ 0.21）者的吸入气$P_{O_2}$（kPa），水蒸气压取6.3 kPa。
::: solution
$P_{IO_2} = 0.21 \times (101.3 - 6.3) = 0.21 \times 95.0 = 19.95$ kPa，通常取整为20 kPa。
:::
:::

::: exercise 计算梯度 {level=1 check="(19.95-4.8/0.8)-9.2"}
一名45岁女性在海平面呼吸空气，$P_{aO_2}$ 9.2 kPa，$P_{aCO_2}$ 4.8 kPa。取$P_{IO_2}$ = 19.95 kPa、$R$ = 0.8，计算A–a梯度（kPa，给出精确值，保留两位小数）。是否正常？
::: solution
$P_{AO_2} = 19.95 - 4.8/0.8 = 19.95 - 6.0 = 13.95$ kPa。梯度$= 13.95 - 9.2 = 4.75$ kPa。这已升高（她这个年龄的正常值低于约2 kPa），说明她肺内存在气体交换问题，如V/Q失调。
:::
:::

::: exercise 为什么二氧化碳不受影响 {level=1}
用两三句话解释：为什么广泛V/Q失调的患者通常$P_{aCO_2}$偏低或正常，而$P_{aO_2}$降低。
::: solution
二氧化碳解离曲线近乎直线，因此增加较健康肺单位的通气可排出额外的二氧化碳，弥补通气不良的单位；化学感受器驱动了这部分额外通气。氧解离曲线顶部平坦，因此对健康单位过度通气几乎不能给已接近饱和的血液增加氧，而来自低V/Q单位的低饱和度血液仍会降低混合动脉血的饱和度。
:::
:::

::: exercise 分流分数 {level=2 check="1/3"}
一名机械通气患者的氧含量如下：肺毛细血管末端（理想）21 mL/dL，动脉血19 mL/dL，混合静脉血15 mL/dL。用$Q_s/Q_t = (C_{cO_2} - C_{aO_2})/(C_{cO_2} - C_{vO_2})$计算分流分数（以分数而非百分比表示）。
::: solution
$Q_s/Q_t = (21 - 19)/(21 - 15) = 2/6 = 1/3$，即约33%的心输出量被分流。正常值低于5%。如此大的分流对吸氧反应差，需要使塌陷的肺泡复张。
:::
:::

::: exercise 无效腔 {level=2 check="0.6"}
一名患者$P_{aCO_2}$为6.0 kPa，混合呼出气$P_{CO_2}$为2.4 kPa。用玻尔方程计算$V_D/V_T$，并提出所得数值的两个原因。
::: solution
$V_D/V_T = (6.0 - 2.4)/6.0 = 0.6$。正常约为0.3。原因包括浅快呼吸（固定的解剖无效腔在每次小潮气量中占的比例变大）、肺栓塞（肺泡无效腔）、毛细血管破坏的肺气肿，以及低心输出量（使上肺区灌注减少）。
:::
:::

::: exercise 氧含量 {level=2 check="round(10*(1.34*12*0.9+0.023*8))/10"}
计算血红蛋白120 g/L、$S_aO_2$ 90%、$P_{aO_2}$ 8 kPa时的动脉血氧含量（mL/dL，保留一位小数）。
::: solution
$C_{aO_2} = 1.34 \times 12 \times 0.90 + 0.023 \times 8 = 14.47 + 0.18 = 14.66$，保留一位小数为14.7 mL/dL。几乎全部与血红蛋白结合。
:::
:::

::: exercise 运动时血氧下降 {level=2}
一名66岁间质性肺疾病女性静息时血氧饱和度95%，步行三分钟后降至85%。她静息时$P_{aCO_2}$为4.6 kPa。请解释饱和度下降的原因。
::: solution
她的肺泡–毛细血管膜增厚、毛细血管床减少，因此氧弥散变慢。静息时红细胞约0.75 s的通过时间仍允许接近平衡。运动时心输出量增加，通过时间缩短，混合静脉血回流时饱和度更低，因此血液在达到平衡之前就离开了毛细血管。同时存在的V/Q失调也会加重。她的$P_{aCO_2}$偏低，是因为她的通气增加而二氧化碳容易弥散。运动时血氧下降是纤维化严重程度和预后的重要标志，可用步行试验正式测定（[[respiratory/control-breathing-tests]]）。
:::
:::

::: exercise 推断机制 {level=3}
三名在海平面呼吸空气的患者血气如下。分别计算A–a梯度（取$P_{IO_2}$ = 20.0 kPa，$R$ = 0.8），判断低氧血症的主要机制，并提出一个合理的临床病因。

(a) $P_{aO_2}$ 7.5 kPa，$P_{aCO_2}$ 9.5 kPa。
(b) $P_{aO_2}$ 7.0 kPa，$P_{aCO_2}$ 4.0 kPa；吸入28%氧后饱和度从86%升至97%。
(c) $P_{aO_2}$ 6.5 kPa，$P_{aCO_2}$ 4.2 kPa；经非重复吸入面罩以15 L/min吸氧后饱和度仅从82%升至85%。
::: hint
先计算$P_{AO_2}$。然后用梯度区分通气不足与肺部疾病，用对吸氧的反应区分V/Q失调与分流。
:::
::: solution
(a) $P_{AO_2} = 20.0 - 9.5/0.8 = 8.1$ kPa；梯度$\approx 0.6$ kPa，正常。**通气不足**：例如阿片类或镇静药过量、吉兰–巴雷综合征等神经肌肉无力，或肥胖低通气。

(b) $P_{AO_2} = 20.0 - 4.0/0.8 = 15.0$ kPa；梯度8.0 kPa，升高。对低浓度吸氧反应良好。**V/Q失调**：例如哮喘急性发作、无广泛实变的肺炎或肺栓塞。

(c) $P_{AO_2} = 20.0 - 4.2/0.8 = 14.75$ kPa；梯度约8.3 kPa，升高。对高浓度吸氧反应很差。**分流**：例如广泛实变、急性呼吸窘迫综合征、肺水肿，或心内、肺内动静脉右向左分流。

实际上各种机制常相互重叠；梯度和对吸氧的反应告诉你哪一种占主导。
:::
