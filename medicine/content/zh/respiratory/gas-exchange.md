氧会从气压走到线粒体，通过四个串联的步骤：通气、弥散、带着血红蛋白装载算术血管的运输，以及毛细血管到细胞的递送——而每一步在血气与弥散的能力和对氧气的反应上都会有它自己失败的签名。二氧化碳会以不同的化学（碳酸氢盐的缓冲与血红蛋白的缓冲和氯的转移）走相反的道路[[physiology/homeostasis-body-fluids]]。

本章涵盖弥散与弥散能力、通气血流的分布与分区、低氧肺泡动脉的算术，以及这两种气体的运输的化学。

## 跨过膜

::: definition 弥散与弥散的能力 {#def-diffusion}
**弥散遵循膜的定律：面积与梯度会推动它，而厚度会反对；一氧化碳（试验）会被血红蛋白如此之快地结合以至于它是被弥散限制，而测定的一氧化碳的摄取（单次呼吸的）会给出一个转运的因子，被肺泡的容积标准化[[respiratory/control-breathing-tests]]。下降的转运因子：膜厚了（间质的疾病[[respiratory/interstitial-vascular-disease]]）；面积少了（切除与气肿的间隔的丢失[[respiratory/asthma-copd]]）；血液少了（贫血）；或毛细血管的血液被这些不工作的单位拿走血管炎与高压的重塑（血管内的病变会特别地下降它）。上升的：肺泡的血增多（早期左心衰的）与哮喘和运动。反应方程：氧气与一氧化碳不同（氧气的结合是有限速的）与它会被容积和血红蛋白被校正（一个低的血红蛋白会人为地降低数字，所以一个被血红蛋白校正的数值会把贫血分开）。氧的交换的解剖学：一个0.6微米合胞的上皮加内皮与融合的基底膜，会跨过广泛毛细血管的网；在健康肺里静息的氧气是被弥散、被灌注或被通气血流匹配所限制，而在疾病中（纤维化与运动）弥散的限制会变得明显（运动时的下降梯度与饱和[[#ex-shunt ]]）。弥散的能力是一个血管与膜的测试：它是一个影像无法给的东西——一个功能的数字（[[clinical-skills/medical-imaging]]对比[[respiratory/control-breathing-tests ]]）。**
:::

::: definition 通气血流的匹配与分区及死腔与分流 {#def-vaq}
**一个匹配的这两个被独立的管道供给的结构会工作：气道会把气体带来，而血管会带来血液，而这两个分布会被重力与反射匹配。分区West): 在肺的顶部，肺泡的压力会超过动脉的（区域被压缩）与血流（第一区与被压缩的毛细血管）：一个高的通气血流（被浪费的通气: 死腔）；在底部，血管的压力会超过肺泡的（第三区开放的血管）：一个低的通气血流（被灌注的、未被通气的单位: 分流样的）；而中部是匹配的（第二区）。通气血流比例的异常会破坏交换的方式：低的比例（被灌注而未被通气：黏液与塌陷和积液）会消耗储备，造成低氧伴二氧化碳正常（因为二氧化碳比例的曲线会被高的代偿）；而高的比例（通气而未被灌注：栓塞与低血压[[respiratory/interstitial-vascular-disease]]）会增加死腔并会迫使通气。极端：分流（没有通气：先天的与肺炎的实变和动静脉的畸形）不会对氧气反应，因为血液会通过这些不通风的肺泡[[#ex-shunt]]；而死腔（没有血流）会升高二氧化碳。调节机制会匹配：低氧血管的收缩会把血流从未通气的区域转移（机制被麻醉和肺高压损害[[surgery/anaesthesia-pain]]、[[respiratory/interstitial-vascular-disease ]]），而通气会通过二氧化碳与表面的张力被调节[[respiratory/mechanics-breathing]]。测量：被计算的肺泡的氧与动脉的（肺泡动脉的差距；低氧的分类[[#ex-a-a ]]）、分割的通气/灌注的扫描与CT（[[clinical-skills/medical-imaging]]）和二氧化碳的呼气末与动脉的差距（死腔）。一个正常的差距伴低氧会指向一个低通气或一个低的吸入的氧气（高原[[#ex-altitude]]、[[emergency-critical-care/poisoning]]）。**
:::

::: example 这个差距会决定 {#ex-a-a}
一个被带来时的饱和为84%的昏迷的人：在空气中二氧化碳为11.5，而氧气为6.5千帕；一个面罩的氧气之后氧气为20，而二氧化碳为10。
::: solution
**一个高的二氧化碳伴一个低肺泡的氧气意味着一个肺泡的低通气：检查这个差距（二氧化碳上升会取代肺泡的氧气，所以这个差距会被计算的）：这里氧气在空气上低，而差距接近正常（数字符合一个纯粹肺泡的低通气），而在氧气上的反应（6.5到20）证明肺基本正常[[#def-vaq]]。原因：呼吸的驱动降低（阿片类与其他镇静[[emergency-critical-care/poisoning]]、[[respiratory/control-breathing-tests]]）、神经肌肉的失效（[[nervous-system/neuromuscular]]、[[nervous-system/stroke]]），以及胸壁的异常。这与肺的的区别：肺炎与栓塞与纤维化会升高这个差距并对氧气反应不同[[#ex-shunt]]。行动：逆转（纳洛酮谨慎的滴定[[emergency-critical-care/poisoning]]）、通气与原因的支持、以及气体以监测二氧化碳（在二氧化碳麻醉之后不要只是移除氧气[[respiratory/respiratory-failure]]）。**
:::
:::

::: example 山的头痛 {#ex-altitude}
一个在3800米的徒步者在第二天出现头痛与恶心和呼吸的急促；在休息时饱和为78%，而二氧化碳为3.5千帕；胸部听诊清晰。
::: solution
**一个低吸入的氧气分压：气压下降会把肺泡的氧气降低，所以动脉与饱和会下降，而一个正常肺泡动脉的差距（低通气是反应）[[#def-vaq]]、[[#ex-a-a]]。生理：颈动脉体的感受器会驱动通气（呼吸的急促与低碳酸血症和呼吸性的碱中毒[[renal/acid-base-disorders ]]）；肾的代偿（碳酸氢盐的利尿）需要数日，这就是为什么适应是时间的函数[[renal/water-sodium]]；以及低氧的血管收缩会把肺动脉的压力升高（易感者高原的肺高压[[respiratory/interstitial-vascular-disease]]）。危险的形式：脑的（头痛与共济失调和意识改变）与肺的（咳嗽与粉红痰和爆裂的音）——两者都需要下降与氧气；药物的预防/治疗（乙酰唑胺会加速适应[[renal/acid-base-disorders]]，以及磷酸二酯酶的抑制剂/钙的通道阻断剂在易感的肺高压中）[[public-health/global-health]]。关键：在一个低氧的、差距正常的、低碳酸血症的旅客中，阿片类是危险；而氧气的反应是迅速的（[[#ex-a-a]]对[[#ex-shunt]]的对比）。**
:::

## 运输、测量与错误的数字

::: definition 含量、运输与脉搏的氧计 {#def-transport}
**含量与分压不同：氧气几乎全部被携带与血红蛋白（1.34毫升每克乘饱和度加溶解的毫升），所以贫血会把含量摧毁而保留分压与饱和[[blood/haemoglobin-disorders]]、[[blood/anaemia]]。解离曲线的转移（见上方的组件）：右移（发热与酸中毒及运动的代谢物与二磷酸甘油酸）会帮助卸载；左移（碱中毒与低温及胎儿/碳氧的血红蛋白）会损害它。二氧化碳以三种的形式被运输（溶解、碳酸氢盐——在红细胞酶作用下的氯的转移，以及血红蛋白氨基甲酰的），而曲线效应（在氧合时酸性的释放）与通气血流的分布会塑造动脉二氧化碳；高碳酸血症代谢的补偿是肾的碳酸氢盐的保留（数天[[renal/acid-base-disorders]]、[[renal/tubular-function ]]）。脉搏的血氧测定：两个波长的吸收在氧合与还原的血红蛋白之间被比值，在一个被选择的搏动的部分上；陷阱：碳氧会被读为正常的（一个中毒的正常饱和）、染料的（美蓝与氰化物）和严重的贫血与血管收缩与动作会失败；以及静脉的搏动会过高地估计[[clinical-skills/laboratory-tests]]、[[emergency-critical-care/acute-assessment]]。正常的饱和不能排除一氧化碳的中毒或一个被移位的曲线；测定的分数（共氧的血氧测定）才是真相[[#ex-co]]。血气：采集的错误（气泡与延迟会改变分压）与温度/酸碱度的处理[[clinical-skills/laboratory-tests]]。**
:::

::: example 陪同者的头痛 {#ex-co}
两个家庭成员在清晨因头痛与恶心被带来；一个脉搏的饱和为99%，而炉子的检查显示出一氧化碳；一个患者的血气在电极上的氧气正常。
::: solution
**一氧化碳的中毒：血红蛋白的结合（亲和力数百倍）会把运载减少并把曲线左移（在组织中更少的卸载）；分压与饱和会保持正常，而脉搏的氧计无法把碳氧血红蛋白区分开，读数会正常（[[#def-transport]]、[[blood/haemoglobin-disorders]]）。线索：暴露的季节与聚集；头痛/眩晕/呕吐和意识改变与心脏的缺血[[cardiovascular/coronary-artery-disease]]；以及一个被测量的分数（一个共氧血氧测定的碳氧血红蛋白水平）与乳酸[[emergency-critical-care/poisoning]]。治疗：高流量的100%的氧气（会把半衰从数小时缩短到约一小时）直到症状和水平下降；高压的氧气在严重的病例中（意识失去与心脏的与神经的征象以及高的水平），带转移的考虑[[emergency-critical-care/critical-care]]；以及来源被固定和报警器的预防[[public-health/environmental-occupational]]、[[public-health/prevention-promotion]]。警告：一个正常的饱和在呼吸的窘迫中不是排除；以及迟发的神经精神的后遗症需要随访[[nervous-system/dementia-neurodegeneration]]。**
:::
:::

::: example 氧气无法纠正的分流 {#ex-shunt}
一个重症肺炎的患者在面罩的氧气15升下饱和为82%；二氧化碳为4.4；胸片显示出广泛的实变；而对100%的氧气的反应只是动脉的氧气从8升到11千帕。
::: solution
**一个大的分流：被灌注但未被通气的肺泡（实变与塌陷）会加入静脉血到动脉的血，而氧气无法达到它们（[[#def-vaq]]、[[#ex-a-a]]）。标志：一个高的差距与一个对氧气的低的反应（一个纯粹通气血流的不匹配会显著地反应，而分流不会）与二氧化碳被正常（剩余的单位会清除它）。行动：通过把招募的肺泡来减少分流（氧气与阳的压力的水平的滴定[[respiratory/respiratory-failure]]、[[emergency-critical-care/airway-ventilation]]）、体位（健康在上的侧卧位在单侧的疾病中[[emergency-critical-care/critical-care]]）、液体与心（避免水肿的肺加重交换[[cardiovascular/heart-failure]]）、以及治疗原因（抗生素与痰的清除）[[respiratory/respiratory-infections]]。升级：高流量的鼻、无创的，或插管带着肺的保护的策略[[respiratory/respiratory-failure]]；难治的：俯卧位与专家（体外的膜的氧合[[emergency-critical-care/critical-care ]]）。陷阱：在分流中把氧气升高会移除对通气的驱动而在潴留者的（[[respiratory/respiratory-failure]]）。**
:::
:::

::: quiz
带低氧升高肺泡动脉的氧气差距会在所有中被发现，除了：
- [ ] 肺炎
- [ ] 肺的栓塞
- [x] 在海平面的阿片类诱导纯粹的低通气
- [ ] 间质的纤维化
::: solution
**一个纯粹肺泡的低通气会在正常的一个差距上造成低氧（肺工作，而肺泡的二氧化碳会取代氧气）：二氧化碳会上升。其他的会损害交换（[[#def-vaq]]、[[#ex-a-a]]）。**
:::

::: history
**级联从气体的定律（分压与溶解的）与第一次的动脉的血液的采集（外周动脉的技术）开始；从肺泡的气体方程与肺泡动脉的差距把低氧分类（一个在临床上可使用的算术）；从弥散的能力的测定（一氧化碳的摄取）把膜与血管分开；从同位素稀释与指示剂的技术把分流与这些不匹配量化；以及从分区模型（重力与区域的解剖）与低氧的血管收缩的发现[[respiratory/interstitial-vascular-disease]]。测量的时代还包括氧合血红蛋白的曲线与转移、脉搏氧计双波长的原理（以及它们被揭穿的失败：一氧化碳和染料），以及肺栓塞的死腔的生理被通气血流的不匹配的概念取代[[respiratory/interstitial-vascular-disease]]。**
:::

## 通向何处

通气与容积在驱动之上在[[respiratory/mechanics-breathing]]；控制与通气的分布在[[respiratory/control-breathing-tests]]；气体与设备在[[respiratory/respiratory-failure]]；疾病的签名在[[respiratory/asthma-copd]]与[[respiratory/interstitial-vascular-disease]]与[[respiratory/respiratory-infections]]；血红蛋白的疾病在[[blood/haemoglobin-disorders]]；高原的环境在[[public-health/environmental-occupational]]；以及急的评估在[[emergency-critical-care/acute-assessment]]。

::: summary
- 弥散会被面积与厚度及梯度与血红蛋白决定；一个低的弥散能力会把膜与血管的疾病与贫血分开，并在影像之前把气体的交换标记出来。
- 交换就是通气血流的匹配：低的比例会消耗储备并会造成对氧气反应的低氧，高的会创造死腔，而极端的分流对氧气是不反应的。
- 肺泡动脉的差距会把低氧分类：正常（低通气与低的吸入的分压）对升高的（肺与血管的），而对100%的氧气的反应会估计分流。
- 含量与分压不同：血红蛋白会携带氧气，所以贫血与碳氧和高铁的血红蛋白会摧毁递送而保留饱和的数字——测量必须与化学一起被读。
- 二氧化碳的运输与缓冲（碳酸氢盐与血红蛋白及氯的转移）以及转移会决定动脉的数字与对治疗的反应。
:::

## 练习

::: exercise 计算这个差距 {level=1}
在海平面室内空气中：动脉氧气10.5千帕，二氧化碳5.3，年龄64。计算肺泡动脉的差距并判断它。
::: solution
**肺泡的氧气约等于吸入的氧气（约100千帕）减去二氧化碳除以0.8：100减6.6约93.4；差距约93.4减10.5约83——不对：以千帕计数字，正常的差距约在15到20以下；这里肺泡的氧气约等于100×0.21的分数……)：用简单的规则，一个64岁的人的预期差距约年龄/4)+4约十几。结论：一个接近正常的差距伴一个低的氧气与正常的二氧化碳，符合低通气或一个低的吸入（[[#def-vaq]]、[[#ex-a-a]]）；检查药物与通气[[emergency-critical-care/poisoning]]、[[respiratory/control-breathing-tests]]。**
:::
:::

::: exercise 弥散为什么会下降 {level=1}
从气肿与纤维化及贫血、和一个左到右的分流，各给一个弥散的能力下降的机制，以及一个会让它上升的。
::: solution
**气肿：间隔与毛细血管床被移除（面积丢失[[respiratory/asthma-copd ]]）；纤维化：膜增厚与毛细血管被瘢痕替代[[respiratory/interstitial-vascular-disease]]；贫血：可用于结合的血红蛋白更少（一个被血红蛋白校正的数值会把患者分开[[blood/anaemia ]]）；左到右的分流/高血压：血液被这些不均一地通气的区域拿走。会上升的：肺泡的血增多（早期的左心衰把毛细血管的血液增加，会提高摄取的速率，并会在早期的阶段被误读为良好[[cardiovascular/heart-failure]]）。提醒：胸片正常与一个低的弥散会指向血管或早期的间质的疾病[[clinical-skills/medical-imaging]]。**
:::
:::

::: exercise 分流算术 {level=2}
在吸入的氧气1.0时：动脉氧气12千帕，血红蛋白150，饱和98%，混合静脉的6.8与68%；被计算的含量的差距提示约20%的分流。解释为什么在计算前给100%的氧气，以及吸收的塌陷的告诫是什么。
::: solution
**高分数会把可被纠正的不匹配（低的比例）消除，让剩下的低氧（差距）成为真正的分流：一个对氧气的反应不佳就是分流；一个正常的差距在1.0时会排除它[[#def-vaq]]、[[#ex-shunt]]。步骤会需要混合静脉的标本与含量（血红蛋白！[[blood/haemoglobin-disorders ]]）。告诫：吸入的高的氧气会把氮气冲走并会造成吸收的塌陷（被氧气填充的肺泡会塌陷，会人为地提高分流并会加重低氧），尤其在高的压力时；所以测试会带监测与谨慎，并会被现代的策略（滴定）取代，除了在被定义的情形中[[respiratory/respiratory-failure]]、[[emergency-critical-care/airway-ventilation]]。**
:::

::: exercise 氧计的物理学 {level=2}
给出一个脉搏的氧计会误读的四个原因，以及每一个应该触发的临床的反射。
::: solution
**碳氧（一个正常在中毒中的读数：测定的分数和暴露[[#ex-co]]）；高铁/染料（一个约85%的平台与发绀对氧气的不反应：氰化物的治疗与美蓝[[emergency-critical-care/poisoning]]）；低的灌注/贫血/静脉的搏动（波动会失败：检查部位与设备，用一个动脉的标本[[clinical-skills/laboratory-tests]]）；以及指甲的染料与环境的光（一个位置错误：一个替代的部位）[[respiratory/respiratory-failure]]。共同的反射：在生理与数字不一致时，测气体并寻找色素；一个氧计是一台饱和的监测器，不是一个中毒的探测器。**

::: exercise 氧气的高碳酸 {level=2}
解释在慢阻肺中氧气诱导高碳酸的现代多机制的生理，并从中推导出目标的饱和的政策。
::: solution
**不只是驱动：（1）被解除的低氧的血管收缩会增加这些不匹配和分流样单位[[#def-vaq]]；（2）通气血流的转移会把死腔增加（二氧化碳的清除会恶化）；（3）波尔的效应（氧合的血红蛋白会释放氢离子，会提高二氧化碳）；（4）在储备低的人中一个小通气的下降[[respiratory/asthma-copd]]、[[respiratory/respiratory-failure]]。政策：在有风险者中把目标控制在88%到92%（一个被滴定面罩/高流量的设置与血气在30到60分钟）而不是自由流动的氧气；以及不要在二氧化碳上升时完全移除氧气——而是降低到目标并使用通气的支持[[emergency-critical-care/airway-ventilation]]。教育：患者与家庭成员必须知道为什么氧气会被测量，而不是习惯[[geriatrics-palliative/polypharmacy]]、[[public-health/prevention-promotion]]。**
:::

::: exercise 高压的算术 {level=2}
计算在三个大气压下呼吸100%的氧气时的氧气含量（血红蛋白150，饱和100%，动脉氧气约1900毫米汞柱），与正常的动脉的含量比较，并指出治疗的逻辑与这两个毒性。
::: solution
**被结合的：1.34乘150约20毫升每100毫升（正常动脉的含量约20）；被溶解的：0.003乘1900约5.7，所以总约26对照约20)：溶解的部分会单独满足在休息时的需求，而无论血红蛋白[[blood/haemoglobin-disorders]]。逻辑：在血红蛋白被一氧化碳阻塞（碳氧的半衰被缩短）与气泡（减压的疾病）、缺氧的组织（移植的皮瓣与放射性坏死、难治的感染）、以及气体在眼内被栓塞中[[emergency-critical-care/poisoning]]、[[surgery/wounds-surgical-infection]]。毒性：中枢的氧（癫痫发作，在高的分压时；被碳酸的水平调节）与肺（一个弥散的损伤与吸收的塌陷在长时间的暴露后），加上耳与气压伤[[respiratory/mechanics-breathing]]、[[nervous-system/epilepsy]]。实际：被定义适应证与转诊（一个中心的可用性）[[public-health/health-systems-economics]]。**

::: exercise 运动时的去饱和 {level=2}
一个纤维化的患者在静息时饱和97%，而在步行的第六分钟为86%。用弥散与通气血流的储备来解释与通过时间的概念，以及为什么去饱和会短暂地持续到恢复。
::: solution
**一个弥散受限的肺会在静息时完成交换（通过时间与储备）但在运动中，心率与容积会缩短毛细血管的通过时间、纤维化的膜会把氧气限制，而梯度会崩溃（弥散的限制）；叠加的不匹配与被摧毁的血管床会把差距推得更宽[[#def-diffusion]]、[[respiratory/interstitial-vascular-disease]]。恢复：动脉的分压会恢复快，而混合静脉的氧气下降与持续的高的心输出量会把饱和度延迟（一个延迟的最低点），而运动后通气仍会高（功与感受器）。用途：六分钟的步行与运动的气体（升高的差距与二氧化碳的异常）会把失能量化并监测治疗；以及氧气的处方（在运动中保持饱和的目标）[[respiratory/respiratory-failure]]、[[public-health/prevention-promotion]]。**

::: exercise 设计低氧的方案 {level=3}
一个地区的医院要求一个成人急性低氧升级的方案：从本章的生理写评估的步骤、氧气输送的设备按流量与实际分数、升级的触发、这些不要错过的机制，以及安全。
::: solution
**评估：饱和与气体带着吸入的分数被记录！)、二氧化碳（潴留者）与差距[[#ex-a-a]]、临床的图形（气道与呼吸的功和灌注）[[emergency-critical-care/acute-assessment]]。设备：鼻管与面罩（中等的分数与漏气）与非重吸入的面罩（高的）与高流量的鼻（被控制的与温和的压力[[respiratory/respiratory-failure]]）；记住分数依赖于流量与呼吸的模式[[#def-transport]]。政策：88%到92%在有风险者，其他94%到98%，带着滴定与重新的评估[[respiratory/respiratory-failure]]。触发：对滴定的氧气的失败与上升的二氧化碳或功，在到达专家之前升级[[emergency-critical-care/airway-ventilation]]。这些不要错过：一氧化碳（一个正常的氧计[[#ex-co ]]）、分流/畸形（不反应[[#ex-shunt ]]）、肺栓塞（死腔与正常胸片[[respiratory/interstitial-vascular-disease]]）、以及低通气（正常的差距[[#ex-a-a]]）。安全：燃烧的与皮肤及设备的训练；以及审计与教学（差距与曲线的案例）[[clinical-skills/patient-safety]]。**
