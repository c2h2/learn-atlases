肺癌是全世界最常被诊断的癌症，也是癌症死亡的首要原因。据国际癌症研究机构统计，2022年约有250万新发病例和180万例死亡。在英国，它是癌症死亡最常见的原因。它大多是可以预防的：绝大多数病例由吸烟引起。结局在很大程度上取决于诊断时的分期。早期发现的癌症常可通过手术或放疗治愈，但大多数人就诊时仍已是晚期，这就是筛查和及时检查症状如此重要的原因。

胸膜是衬于肺表面和胸壁内面的膜，常被肺癌累及，但胸膜疾病还有许多其他原因。本章后半部分讨论胸腔积液（包括如何区分漏出液和渗出液）、胸膜感染、恶性积液、间皮瘤和气胸。管理内容遵循英国现行指南，包括NICE肺癌指南和英国胸科学会（BTS）胸膜疾病指南（2023年），以原则的形式阐述。

## 肺癌 {#sec-cancer}

### 病因

吸烟引起大多数肺癌。风险随吸烟量增加，更随吸烟年限增加；戒烟后风险逐渐下降，但永远不会完全降到从不吸烟者的水平。烟草烟雾含有许多致癌物，如多环芳烃和亚硝胺，可引起*TP53*和*KRAS*等基因突变（[[pathology/cancer-biology]]）。其他病因包括二手烟、氡气（在某些地区从地下渗入住宅）、石棉（使吸烟的风险成倍增加）、空气污染、其他职业性致癌物以及既往胸部放疗。越来越多的肺癌（尤其是腺癌）发生在从不吸烟者中，这类肿瘤更常由*EGFR*等特定突变驱动。

### 类型

::: definition 肺癌的主要类型 {#def-lc-types}
- **非小细胞肺癌**（NSCLC），约占85%：
  - **腺癌**：最常见的类型，通常位于外周，是从不吸烟者和女性中最常见的类型。常带有可靶向的驱动突变（*EGFR*、*ALK*、*ROS1*、*KRAS* G12C等）。
  - **鳞状细胞癌**：与吸烟密切相关，常位于中央，可形成空洞，与甲状旁腺激素相关肽引起的高钙血症相关。
  - **大细胞癌**：排除性诊断，由于免疫组织化学能对大多数肿瘤分类，现已少见。
- **小细胞肺癌**（SCLC），约占10–15%：一种神经内分泌肿瘤，几乎都发生于吸烟者，通常位于中央，生长快，早期即扩散。最初对化疗和放疗有反应，但通常复发。与副肿瘤综合征相关。
- **类癌**是低级别神经内分泌肿瘤，典型地发生于较年轻者，与吸烟无关。
:::

肺也是其他癌症（如乳腺癌、结直肠癌、肾癌和肉瘤）的常见转移部位。

### 临床表现

症状来自原发肿瘤、胸内扩散、远处转移或肿瘤分泌的物质。

- **原发肿瘤**：持续咳嗽或慢性咳嗽性质改变、咯血、气短、胸痛、反复或吸收缓慢的肺炎（由支气管阻塞引起）以及肺叶不张。
- **胸内扩散**：声音嘶哑（左喉返神经，它绕过主动脉弓下方）、膈肌抬高（膈神经）、胸腔积液、心包积液、吞咽困难以及**上腔静脉阻塞**（SVCO），后者引起面部肿胀、头痛、颈部和胸壁静脉怒张以及气短。
- **肺上沟瘤**（Pancoast瘤）：肺尖部肿瘤侵犯臂丛（肩臂痛，C8/T1受累引起手部小肌无力）和交感干（**霍纳综合征**：同侧上睑下垂、瞳孔缩小和无汗）。
- **转移**：至骨（疼痛、骨折、高钙血症）、脑（头痛、癫痫发作、局灶体征）、肝和肾上腺。
- **全身性**：体重下降、乏力、杵状指和肥大性肺性骨关节病。

::: definition 副肿瘤综合征 {#def-paraneoplastic}
**副肿瘤综合征**是癌症的远隔效应，由激素或抗体引起，而非直接侵犯。在肺癌中重要的有：

- **抗利尿激素分泌失调综合征**（SIADH），引起低钠血症；最常见于SCLC。
- **异位ACTH分泌**，引起伴低钾血症的库欣综合征；主要见于SCLC。
- 甲状旁腺激素相关肽引起的**高钙血症**；主要见于鳞状细胞癌。
- **兰伯特–伊顿肌无力综合征**，由针对突触前电压门控钙通道的抗体引起，表现为近端肌无力，反复用力后改善；主要见于SCLC。
- 其他神经系统综合征，如小脑变性和脑炎，常由抗体介导。
:::

在英国，NICE可疑癌症指南NG12建议：40岁及以上有两项或以上不明原因症状（如咳嗽、乏力、气短、胸痛、体重下降或食欲下降）者（若曾吸烟则一项即可），应紧急行胸片检查；若胸片提示肺癌，或40岁及以上者出现不明原因咯血，应通过可疑癌症路径紧急转诊。胸片正常不能排除肺癌，因此症状持续者需要进一步评估。

::: example 意识模糊与低钠 {#ex-paraneoplastic}
一名每天吸烟30支的64岁女性因意识模糊一周被女儿送来。血钠118 mmol/L。她临床上血容量正常，血清渗透压252 mOsm/kg，尿渗透压480 mOsm/kg，尿钠45 mmol/L。甲状腺和肾上腺功能正常，未服用利尿剂。胸片显示右肺门肿块。可以统一解释的诊断是什么？
::: solution
低钠血症伴血清低渗透压、尿液不适当浓缩（尿渗透压高于血清）、持续尿钠排泄和血容量正常，且甲状腺和肾上腺功能正常、未用利尿剂，符合**SIADH**的标准。在有中央型肺门肿块的重度吸烟者中，最可能的病因是分泌抗利尿激素的**小细胞肺癌**。严重的症状性低钠血症需要在医院中谨慎纠正，避免血钠升高过快，否则有渗透性脱髓鞘的风险（[[renal/water-sodium]]）。她需要紧急分期和组织学诊断，通常通过CT以及支气管镜或支气管内超声。治疗癌症常可纠正SIADH。
:::
:::

### 检查与分期

目的是确诊、确定类型和分子特征、确定分期，并评估患者对治疗的耐受能力。检查的顺序应以尽可能少的操作获得尽可能多的信息，理想情况下应对能确立最高分期的部位取样。

- **胸部、肝脏和肾上腺增强CT**是第一项分期检查。
- **PET-CT**（氟代脱氧葡萄糖正电子发射断层扫描）在考虑根治性治疗的患者中发现代谢活跃的纵隔淋巴结和远处转移。
- **组织取样**：中央型肿瘤行支气管镜检查，纵隔淋巴结行**支气管内超声引导下经支气管针吸活检**（EBUS-TBNA），外周病灶行CT引导下活检，胸液细胞学检查，或对转移灶活检。
- NSCLC进行驱动突变和**PD-L1表达**的**分子检测**，以决定是否适合靶向治疗和免疫治疗。
- 对考虑根治性治疗的较晚期患者或有神经系统症状者，行**脑部MRI**。

肺癌按TNM系统分期。第九版（IASLC/UICC）自2025年1月起使用，按大小和对邻近结构的侵犯描述肿瘤（T）；淋巴结（N）分为无、同侧肺门（N1）、同侧纵隔或隆突下（N2，现分为单站N2a和多站N2b）以及对侧或锁骨上（N3）；转移（M）分为胸内转移（M1a：胸腔或心包积液或结节，或对侧肺结节）、单个胸外转移（M1b）或多个胸外转移（M1c，现分为单一器官系统的M1c1和多个器官系统的M1c2）。组合后得出Ⅰ至Ⅳ期。

### 治疗

治疗由肺癌多学科团队制定，取决于类型、分期、分子特征以及患者的身体状况和意愿。

- **早期NSCLC（Ⅰ–Ⅱ期及部分Ⅲ期）**：**手术**，通常为肺叶切除加淋巴结取样，多采用电视辅助或机器人胸腔镜手术。对于不适合或不愿手术的人，**立体定向消融放疗**（SABR）在少数几次分割中给予高剂量、高度聚焦的放射。手术前后可给予化疗、免疫治疗或靶向治疗以减少复发，例如*EGFR*突变肿瘤切除后使用奥希替尼。
- **局部晚期、不可切除的NSCLC（Ⅲ期）**：同步**放化疗**，之后通常用度伐利尤单抗巩固免疫治疗（*EGFR*突变肿瘤则用奥希替尼）。
- **晚期NSCLC（Ⅳ期）**：有驱动突变的肿瘤用**靶向药物**治疗，如针对EGFR（奥希替尼）或ALK（阿来替尼、劳拉替尼）的酪氨酸激酶抑制剂。没有可靶向驱动突变的肿瘤用**免疫检查点抑制剂**（抗PD-1或抗PD-L1抗体）治疗，PD-L1高表达时可单用，否则联合化疗。这些治疗显著改善了许多晚期患者的生存。
- **SCLC**：局限期行同步放化疗；广泛期行化疗联合免疫检查点抑制剂。可考虑预防性全脑照射。
- 从诊断起即整合**姑息治疗**：症状控制（气短、疼痛、咳嗽）、针对骨痛或咯血的姑息性放疗、针对SVCO或气道阻塞的支架置入，以及对患者和家属的支持（[[geriatrics-palliative/palliative-care]]）。

### 手术耐受性

肺切除术前，团队要估计术后还能保留多少肺功能。一种简单的方法是计数支气管肺段。共有19个：右侧10个（上叶3、中叶2、下叶5），左侧9个（上叶含舌段5、下叶4）。

$$
\text{ppo值} = \text{术前值} \times \frac{19 - \text{切除的肺段数}}{19}
$$ {#eq-ppo}

其中"ppo"表示术后预计值。此方法用于FEV₁和TLCO（以占预计值的百分比表示）。若某些肺段已被肿瘤阻塞而不起作用，计算需作相应调整。在BTS指南中，术后预计FEV₁和TLCO均高于40%的患者，术后气短的风险可以接受；数值较低者需要进一步评估，通常做运动试验。还要评估心血管风险和患者自身的意愿。

::: example 他能做肺叶切除吗？ {#ex-ppo}
一名68岁慢阻肺男性右下叶有一个2.8 cm的腺癌，PET-CT未见淋巴结或远处转移。他的FEV₁为预计值的65%，TLCO为预计值的58%。估计右下叶切除后他的术后预计FEV₁和TLCO。
::: solution
右下叶有5个肺段，切除后剩19个中的14个。

ppoFEV₁ $= 65 \times 14/19 = 47.9\%$，约48%。

ppoTLCO $= 58 \times 14/19 = 42.7\%$，约43%。

两者都高于40%，因此按BTS标准，他术后气短的风险可以接受；若心脏风险可接受且他本人愿意，肺叶切除是合理的选择。若其中任一数值低于40%，下一步是正式的运动试验，SABR将是另一种根治性治疗。应支持他在术前戒烟，这可减少并发症。
:::
:::

### 筛查

两项大型随机试验表明，用**低剂量CT**筛查高危人群可减少肺癌死亡。美国国家肺癌筛查试验（2011年）发现，与胸片相比肺癌死亡率降低20%；荷兰–比利时NELSON试验（2020年）发现，与不筛查相比，男性在十年时死亡率降低约四分之一。危害包括假阳性结果及随之而来的检查、辐射暴露、对缓慢生长癌症的过度诊断以及偶然发现。在英格兰，**NHS肺癌筛查项目**（由"靶向肺部健康检查"试点发展而来）邀请55至74岁有吸烟史的人进行风险评估，高风险者再行低剂量CT。该项目正在全国推广，计划于2029/30年度实现全覆盖。筛查与戒烟支持相结合时效果最好。

筛查和常规CT会发现许多小的**肺结节**，其中大多数是良性的。在BTS指南（2015年）中，非常小的实性结节（小于5 mm，或小于80 mm³）无需随访。较大的结节根据复查CT上的生长情况（测量体积）和Brock模型等风险模型进行评估，风险较高者再行PET-CT并使用Herder模型。

## 胸膜疾病 {#sec-pleura}

### 胸腔积液

每侧约10–20 mL的少量胸膜液润滑肺与胸壁之间的运动。它由壁层胸膜的体循环毛细血管滤出，经壁层胸膜淋巴管吸收。当滤出超过吸收时就形成**积液**，原因可以是静水压升高、胶体渗透压降低、毛细血管通透性增加或淋巴引流受阻（[[pathology/haemodynamics]]）。

临床上，积液引起气短、胸廓扩张减弱、叩诊**实音**、呼吸音减弱和语音共振减弱。胸片显示肋膈角变钝（正位片需要约200 mL），量较大时出现弧形上缘。超声更为敏感，能显示分隔，并用于引导每一项胸膜操作。

::: theorem Light标准 {#thm-light}
胸腔积液满足以下至少一项即为**渗出液**：

1. 胸液蛋白/血清蛋白 > 0.5；
2. 胸液LDH/血清LDH > 0.6；
3. 胸液LDH > 血清LDH正常值上限的三分之二。

若一项都不满足，则为**漏出液**。
:::

::: proof
漏出液形成于静水压与胶体渗透压的平衡被改变而胸膜完整之时，因此液体是血浆的超滤液，蛋白和LDH都很少。渗出液产生于胸膜发生炎症或被侵犯、或淋巴引流受阻之时，因此蛋白和细胞漏入胸膜腔，炎症细胞或恶性细胞释放LDH。将胸液值与血清值比较，可校正患者自身的血浆水平。该标准对渗出液高度敏感，但会把部分漏出液误判为渗出液，尤其是用利尿剂治疗的心力衰竭患者，因为利尿剂会使胸液浓缩。在这种情况下，血清–胸液白蛋白梯度高于12 g/L支持漏出液。
:::

**漏出液**通常为双侧，由心力衰竭（所有积液中最常见的原因）、肝硬化、肾病综合征、低白蛋白血症、甲状腺功能减退症和腹膜透析引起。已知心力衰竭患者出现典型的双侧积液时，除非有发热、胸膜炎性疼痛或一侧明显较大等不典型特征，否则不需要穿刺。**渗出液**由肺炎（肺炎旁胸腔积液和脓胸）、恶性肿瘤（肺癌、乳腺癌、淋巴瘤、间皮瘤、其他转移瘤）、结核病、肺栓塞、类风湿关节炎和其他自身免疫病、胰腺炎以及药物引起。

在超声引导下进行诊断性胸腔穿刺，送检胸液做蛋白、LDH、葡萄糖和pH、细胞学、革兰氏染色和培养，疑诊时还做抗酸杆菌检查。外观有帮助：脓液提示脓胸；明显血性提示恶性肿瘤、创伤或PE；乳糜样液体提示乳糜胸。葡萄糖降低见于感染、类风湿病、恶性肿瘤和结核病。胸液细胞学只能在约一半的恶性积液中检出恶性肿瘤，因此常需要胸膜活检（在CT或超声引导下，或经胸腔镜）。

::: example 漏出液还是渗出液？ {#ex-light}
一名72岁女性有单侧右侧胸腔积液。结果：胸液蛋白32 g/L，血清蛋白68 g/L；胸液LDH 260 U/L，血清LDH 210 U/L。实验室血清LDH正常值上限为250 U/L。应用Light标准。
::: solution
蛋白比值：$32/68 = 0.47$，不高于0.5。

LDH比值：$260/210 = 1.24$，高于0.6。

胸液LDH与正常值上限的三分之二比较：$\tfrac{2}{3} \times 250 = 167$；260高于此值。

满足两项标准，因此为**渗出液**。老年女性的单侧渗出液令人担心恶性肿瘤、胸膜感染、结核病和PE。下一步：胸液细胞学和微生物学检查、胸部增强CT（最好在积液完全引流之前进行，以便评估胸膜），若细胞学阴性而仍怀疑恶性肿瘤，则行胸膜活检。
:::
:::

### 胸膜感染

胸膜感染通常是肺炎的并发症（[[respiratory/respiratory-infections#def-empyema]]）。BTS指南建议，对于肉眼脓液或浑浊液体、革兰氏染色或培养阳性，或疑有感染的患者**胸液pH低于7.2**者，除抗生素外还应胸腔引流。引流管在超声引导下置入。若引流不完全，可考虑胸膜腔内注入组织型纤溶酶原激活物联合DNA酶（MIST2试验显示可改善引流）或胸外科手术。胸膜感染导致相当高的发病率和死亡率，老年人尤甚，尽早与呼吸团队讨论可改善结局。

### 恶性胸腔积液与间皮瘤

对大多数癌症而言，**恶性胸腔积液**意味着疾病已无法治愈，治疗的目的是以尽可能少的操作和住院天数缓解气短。选择包括治疗性穿刺抽液、**滑石粉胸膜固定术**（经引流管或在胸腔镜下注入滑石粉，使两层胸膜粘连）以及**留置胸膜导管**（一种可在家中引流的隧道式引流管）。选择取决于患者的意愿、预后以及引流后肺能否复张。当增厚的脏层胸膜使肺不能复张时（"陷闭肺"），胸膜固定术会失败，宜选择留置导管。

**间皮瘤**是胸膜（较少见为腹膜）的癌症，由石棉暴露引起，通常在诊断前30至40年或更早。石棉在英国被禁用之前曾广泛使用，英国是世界上间皮瘤发病率最高的国家之一。它表现为气短、胸痛（常为持续性钝痛）和胸腔积液，进而包裹整个肺。诊断需要胸膜活检的组织学。治疗主要是姑息性的，不过免疫治疗联合方案已改善了部分患者的生存。在英国，间皮瘤患者及其家属有权获得赔偿和津贴，因此详细的职业史很重要（[[public-health/environmental-occupational]]）。

### 气胸

::: definition 气胸 {#def-pneumothorax}
**气胸**是胸膜腔内有空气。**原发性自发性气胸**发生于没有已知肺部疾病的人，典型地见于瘦高的年轻男性；吸烟（包括大麻）大大增加风险，常存在肺尖部小肺大疱。**继发性自发性气胸**发生于有基础肺病者，如慢阻肺、囊性纤维化、ILD或肺炎。**创伤性**气胸发生于外伤或医疗操作之后。**张力性气胸**是指每次呼吸都有空气进入胸膜腔却不能排出，导致压力升高、纵隔移位、静脉回心血量下降。
:::

原发性自发性气胸通常引起突发胸膜炎性胸痛和气短。患侧体征包括胸廓扩张减弱、叩诊过清音和呼吸音减弱。继发性气胸相对其大小而言症状更重，因为患者的呼吸储备更少。

2023年BTS指南不再主要依据胸片上气胸的大小决定治疗。现在的处理主要基于**症状、生理功能受损程度和患者意愿**：

- 对于**症状轻微**且无生理功能受损的原发性气胸，无论大小，**保守治疗**（观察并随访）都是一种选择。
- 对于需要干预者，选择包括**门诊引流装置**（带单向活瓣的小引流管，在具备相应经验的中心可在家中处理）、**针吸**或**胸腔引流管**。
- 继发性气胸通常需要住院，多数情况下需要引流，并尽早让呼吸专科参与。
- 第二次发作后、持续漏气时以及高风险职业者，考虑手术（如胸腔镜下肺大疱切除和胸膜固定术）以防复发。

应建议患者戒烟，在气胸完全吸收之前避免乘飞机，除非做过根治性手术，否则永久避免潜水。

::: example 年轻男性的突发疼痛 {#ex-pneumothorax}
一名吸烟的21岁男性左侧胸痛和轻度气短六小时。他静息时舒适，心率88次/分，呼吸频率18次/分，血压124/76 mmHg，呼吸空气时$S_pO_2$ 98%。胸片显示左侧气胸，肺门水平气带宽3 cm。他没有既往肺部疾病。按照2023年BTS指南，可如何处理？
::: solution
这是**原发性自发性气胸**。按照旧的（2010年）以大小为依据的方法，气带超过2 cm就要干预。按照2023年指南，决定主要基于症状和生理功能受损程度。他症状轻微、生理状态稳定，因此尽管气胸较大，**保守治疗**仍是一种选择，前提是他理解这一方案，并有明确的安全提示和随访安排。若他倾向干预，或症状令他困扰，可与他讨论后采用针吸或门诊引流装置。应强烈鼓励他戒烟（复发的主要可改变危险因素），建议在确认吸收之前不要乘飞机，并告知除非做过根治性手术，否则永远不要潜水。
:::
:::

::: warning 张力性气胸是临床诊断
张力性气胸患者可有严重呼吸窘迫、低氧血症、心动过速、低血压、颈静脉怒张，晚期还有气管向健侧偏移。它最常见于创伤和接受正压通气的患者。不要等胸片：治疗是**立即减压**，用针头或开放（手指）胸廓造口，随后置入胸腔引流管。现行成人创伤指南倾向于选择腋中线稍前方的第4或第5肋间，因为那里的胸壁比传统的锁骨中线第2肋间更薄（[[surgery/trauma]]）。
:::

哪种肺癌类型与甲状旁腺激素相关肽引起的高钙血症关系最密切？
- [ ] 小细胞癌
- [ ] 腺癌
- [x] 鳞状细胞癌
- [ ] 类癌
::: solution
鳞状细胞癌最常分泌甲状旁腺激素相关肽（[[#def-paraneoplastic]]）。肺癌中的高钙血症也可来自骨转移。SIADH、异位ACTH和兰伯特–伊顿综合征是小细胞癌的特征。
:::

::: history
1950年，两项病例对照研究——理查德·多尔（Richard Doll）和奥斯汀·布拉德福德·希尔（Austin Bradford Hill）发表于《英国医学杂志》的研究，以及恩斯特·温德（Ernst Wynder）和埃瓦茨·格雷厄姆（Evarts Graham）发表于《美国医学会杂志》的研究——显示吸烟与肺癌之间存在强关联。多尔和希尔随后从1951年起随访约40000名英国医生；英国医生研究证实了这一关联，并显示了戒烟的益处。格雷厄姆本人在1933年完成了首例成功的一期全肺切除术治疗肺癌；他于1957年死于肺癌。1960年，克里斯托弗·瓦格纳（Christopher Wagner）及其同事把间皮瘤与南非的青石棉开采联系起来。理查德·莱特（Richard Light）及其同事于1972年发表了区分渗出液和漏出液的标准。2004年，三个研究组报告了能预测对酪氨酸激酶抑制剂产生显著反应的*EGFR*突变，开启了肺癌靶向治疗的时代。
:::

胸膜腔的力学以及气胸为何使肺塌陷，见[[respiratory/mechanics-breathing]]。作为肺炎并发症的胸膜感染见[[respiratory/respiratory-infections]]。癌症生物学、分期和诊断的一般原则见[[pathology/cancer-biology]]和[[pathology/cancer-diagnosis]]，肿瘤免疫学见[[immunology/transplant-tumour-immunology]]，晚期患者的照护见[[geriatrics-palliative/palliative-care]]。控烟和筛查政策在[[public-health/prevention-promotion]]和[[public-health/screening]]中讨论。

::: summary
- 肺癌是癌症死亡的首要原因；大多数病例由吸烟引起，其他病因有氡、石棉和空气污染。
- NSCLC（腺癌、鳞癌、大细胞癌）约占85%；SCLC约占10–15%，早期扩散并有副肿瘤综合征。
- 记住局部扩散（SVCO、伴霍纳综合征的肺上沟瘤、喉返神经和膈神经麻痹）和副肿瘤综合征（SCLC的SIADH、异位ACTH和兰伯特–伊顿综合征；鳞癌的PTHrP高钙血症）。
- 分期使用CT、PET-CT、EBUS和TNM第九版（2025年）。分子检测和PD-L1指导晚期NSCLC的治疗。
- 早期疾病：手术或SABR；ppo FEV₁和TLCO高于40%表示风险可接受。Ⅲ期：放化疗后免疫治疗。Ⅳ期：靶向治疗或免疫治疗。
- 对高危人群进行低剂量CT筛查可减少肺癌死亡；英格兰正在为55–74岁有吸烟史者推广全国性项目。
- Light标准区分渗出液和漏出液。胸膜感染且pH低于7.2需要引流。
- 恶性积液：与患者共同选择滑石粉胸膜固定术或留置胸膜导管。间皮瘤发生于数十年前的石棉暴露之后。
- 气胸的处理（BTS 2023）主要基于症状和生理状况而非仅凭大小；张力性气胸需要立即减压。
:::

## 习题

::: exercise 计数肺段 {level=1 check="60*16/19"}
一名术前FEV₁为预计值60%的女性接受右上叶切除（3个肺段）评估。用简单肺段计数法计算她的术后预计FEV₁（占预计值的百分比）。
::: solution
$60 \times (19 - 3)/19 = 60 \times 16/19 = 50.5\%$。高于40%。
:::
:::

::: exercise Light标准 {level=1}
某胸液样本蛋白22 g/L（血清70 g/L），LDH 90 U/L（血清200 U/L；正常值上限250 U/L）。是漏出液还是渗出液？
::: solution
蛋白比值$22/70 = 0.31$（不 > 0.5）；LDH比值$90/200 = 0.45$（不 > 0.6）；胸液LDH 90低于$\tfrac{2}{3} \times 250 = 167$。一项标准都不满足：**漏出液**。寻找心力衰竭、肝硬化、肾病综合征或低白蛋白血症。
:::
:::

::: exercise 霍纳征与肩痛 {level=1}
一名59岁吸烟者右肩疼痛并向上臂内侧放射，右手小肌萎缩，右侧上睑下垂、瞳孔缩小。病变在哪里？累及哪些结构？
::: solution
右肺尖部的**肺上沟瘤（Pancoast瘤）**。它侵犯下臂丛（C8和T1神经根，引起沿上臂内侧的疼痛以及手内在肌无力和萎缩）和颈交感干（引起同侧**霍纳综合征**：上睑下垂、瞳孔缩小和无汗）。
:::
:::

::: exercise 胸液pH {level=2}
一名肺炎患者有中等量积液。抽出的液体清亮，pH 7.12，葡萄糖2.8 mmol/L；革兰氏染色阴性。她需要胸腔引流吗？请解释。
::: solution
需要。在疑有胸膜感染时，胸液pH低于7.2提示**复杂性肺炎旁胸腔积液**，即使液体清亮、革兰氏染色阴性，单用抗生素也不太可能吸收。低pH和低葡萄糖反映细菌和中性粒细胞的代谢。她需要在超声引导下置入胸腔引流管并使用合适的抗生素。pH必须用血气分析仪测定，且不能接触空气或局麻药，否则会改变结果。
:::
:::

::: exercise 哪种类型？ {level=2}
说出每种情形最可能的肺癌类型：(a) 一名从不吸烟的45岁女性，外周肿块，*EGFR* 19号外显子缺失；(b) 一名70岁重度吸烟者，中央型肿块，就诊时有低钠血症和肝转移；(c) 一名66岁吸烟者，中央型空洞性肿块，血钙3.1 mmol/L；(d) 一名32岁患者同一肺叶反复肺炎，有一个边界清楚的支气管内病变。
::: solution
(a) 腺癌。(b) 小细胞癌。(c) 鳞状细胞癌。(d) 类癌。
:::
:::

::: exercise 慢阻肺患者的气胸 {level=2}
一名73岁重度慢阻肺男性突然气短加重。$S_pO_2$ 86%，胸片显示右肺尖1.5 cm的气胸。为什么其处理不同于年轻人大小相似的原发性气胸？
::: solution
这是**继发性自发性气胸**。他的肺功能本已很差，即使是小气胸也会引起明显的低氧血症和窘迫；死亡风险更高；由于病肺持续漏气，气胸不太可能自行吸收；复发很常见。他需要住院、受控氧疗（若有高碳酸血症风险，目标88–92%），多数情况下需要引流，并尽早请呼吸专科参与。常考虑通过手术或内科胸膜固定术预防复发。须注意不要把大的肺大疱误认为气胸；有疑问时CT有帮助。
:::
:::

::: exercise 哪种积液？ {level=3}
一名78岁退休水管工有大量左侧胸腔积液、体重下降和持续胸部钝痛。CT显示结节状胸膜增厚包裹左肺，并有钙化的胸膜斑。胸液为渗出液，两次细胞学检查均阴性。讨论可能的诊断、细胞学为何可能阴性以及下一步应怎么做。
::: solution
可能的诊断是**恶性胸膜间皮瘤**：水管工可能接触过石棉（管道包覆、绝缘材料），胸膜斑证实了暴露，结节状环周胸膜增厚伴持续疼痛是典型表现。鉴别诊断包括肺转移性腺癌和其他癌症。细胞学对间皮瘤不敏感，因为肿瘤细胞可能不脱落到液体中，且难以与反应性间皮细胞区分。下一步是**胸膜活检**，在影像引导下或经胸腔镜（同时可行滑石粉胸膜固定术），并做免疫组织化学。处理包括控制积液（滑石粉或留置胸膜导管）、评估全身治疗、姑息治疗，以及关于赔偿的建议和关于作为工业疾病须依法向验尸官（或苏格兰的地方检察官）报告死亡的说明。
:::
:::

::: exercise 他应该筛查吗？ {level=3}
一名60岁男性询问是否应该做肺癌CT筛查。他从18岁到48岁每天吸烟20支。计算他的包年数，并像向他本人解释那样讨论筛查可能的益处和危害。
::: solution
包年$= (20/20) \times 30 = 30$。他在年龄范围内（55–74岁）且有相当的吸烟史，因此在英格兰他有资格参加NHS肺癌筛查项目的风险评估，由计算出的风险决定是否为他提供低剂量CT。**益处**：筛查能在较早期发现癌症，此时手术或放疗可以治愈，在试验中使肺癌死亡减少约五分之一到四分之一。**危害**：许多人会发现最终证明是良性的结节，这可能带来焦虑和重复扫描；少数人会因良性疾病接受活检或手术；发现的某些癌症本来永远不会造成伤害（过度诊断）；有少量辐射；偶然发现（如冠状动脉钙化或肺气肿）可能导致进一步检查。决定由他本人在清晰信息的支持下作出。戒烟（他已经做到）仍是降低风险最大的措施。
:::
