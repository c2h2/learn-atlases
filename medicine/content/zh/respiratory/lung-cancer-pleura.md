肺癌是癌死亡的首位原因之一，而它的结局取决于分期与生理的储备；胸膜的疾病则是内科门诊最常见的呼吸的急症之一。本章涵盖肺癌的流行病学与分类及分期和治疗、它的全身的表现，以及胸膜的肿瘤与积液[[pathology/cancer-biology]]、[[public-health/prevention-promotion]]。

本章涵盖肿瘤的发生与分类及分期、按分期的治疗、副肿瘤的表现，以及胸膜的疾病。

## 肿瘤

::: definition 癌变、分类与分期 {#def-cancer-class}
**暴露与突变：烟草承担了多数病例，其剂量按包年累积，而石棉与氡及职业的暴露和家族的易感会叠加[[public-health/environmental-occupational]]、[[genetics/common-disease-genetics]]；慢性炎症与瘢痕会把腺癌的风险提高[[pathology/chronic-inflammation-repair]]。分类：非小细胞（腺癌与鳞状及大细胞的）与小细胞，两者的生物学与治疗完全不同[[pathology/cancer-diagnosis]]、[[immunology/tolerance-regulation]]；如今分子的靶点（上皮的生长因子的受体与激酶的融合及检查点的表达）决定治疗[[pharmacology/drug-development-prescribing]]。分期TNM把肿瘤的大小与位置、淋巴结的站与转移的侧别组合；检查包括增强的CT与正电子的扫描和头的磁共振以及纵隔的取样[[clinical-skills/medical-imaging]]、[[pathology/diagnostic-pathology]]。表现：咳嗽与咯血与胸痛和气促及反复的同一部位的肺炎；全身（消瘦与骨的痛）；局部侵犯（声带的麻痹与上腔静脉的阻塞及膈神经和Horner[[#ex-svc]]、[[nervous-system/sensory-systems]]）；以及副肿瘤的（钠与钙与神经肌肉的）[[renal/potassium-calcium-phosphate]]、[[endocrine/hypothalamus-pituitary]]。**
:::

::: example 一个肿块与一个钠的问题 {#ex-lungca}
一位66岁的吸烟者有咳嗽与消瘦；钠124而血浆渗透低，尿的钠高；胸片显示左肺门的肿块。
::: solution
**低钠伴尿钠排出提示抗利尿激素的不当分泌，而在一个中央的肺部肿块中，最可能是小细胞肺癌的副肿瘤表现[[endocrine/hypothalamus-pituitary]]、[[renal/water-sodium]]。评估要同时朝两个方向：确诊与分期（支气管镜与活检、CT与正电子及头的磁共振和钠的其他原因：甲状腺与肾上腺[[endocrine/thyroid]]、[[endocrine/adrenal]]）；以及治疗症状（液体的限制与口服的盐，必要时增高的药与受体拮抗剂的谨慎）[[renal/water-sodium]]。治疗这个肿瘤常会改善钠：化疗与免疫治疗在小细胞中会把激素的驱动减少[[pharmacology/drug-development-prescribing]]。这个图形也提醒我们：在低钠的评估中，一个胸片可以看到病因[[clinical-skills/medical-imaging]]。**
:::

## 治疗、表现与胸膜

::: definition 按分期与生物学的治疗 {#def-treatment}
**可手术的早期非小细胞肺癌：切除（肺叶与段的策略）配合系统的淋巴结取样与术前的心肺的适应评估[[surgery/perioperative-care]]、[[respiratory/control-breathing-tests]]；辅助的治疗（含铂的与靶向的和检查点的）按结果把复发的风险降低[[pharmacology/drug-development-prescribing]]、[[immunology/vaccines-immunotherapy]]。局部晚期的：同步的放化疗，然后是巩固的免疫治疗；这些不能耐受较大治疗的：根治的或姑息的放疗与消融[[pathology/cancer-biology]]。广泛期或转移性的：以全身治疗为主（化疗与检查点的抑制剂、靶向药在有驱动的中），以及早期的姑息与症状的控制[[geriatrics-palliative/symptom-control]]、[[geriatrics-palliative/palliative-care]]。小细胞：局限期的同步化放疗与广泛期的全身治疗[[pathology/cancer-diagnosis]]。贯穿其中的是共同决策：获益与毒性，以及目标与时间的规划[[medical-ethics-law/end-of-life-ethics]]、[[clinical-skills/communication]]。**
:::

::: definition 全身的表现与胸膜 {#def-parapleur}
**副肿瘤的内分泌与神经：抗利尿激素的不当分泌与异位激素（促肾上腺的激素造成库欣）及高钙（相关的肽与骨的转移和维生素D的生成）[[endocrine/adrenal]]、[[renal/potassium-calcium-phosphate]]；神经肌肉的重叠肌病与肌无力样综合征和感觉神经病[[nervous-system/neuromuscular]]、[[nervous-system/sensory-systems]]；皮肤与骨（杵状指与骨关节病）与血液（血栓性静脉炎与白细胞增多）[[musculoskeletal/bones-joints]]、[[blood/thrombosis-anticoagulation]]、[[blood/leukaemia]]。胸膜的恶性疾病：恶性积液（呼吸的困难与消失的呼吸音与浊音；超声与抽液）与原发的胸膜的间皮瘤（石棉的潜伏期与胸壁的痛和结节）[[public-health/environmental-occupational]]、[[pathology/cancer-diagnosis]]、[[immunology/tolerance-regulation]]。气胸与恶性的胸膜固定[[#ex-pleura]]、[[surgery/wounds-surgical-infection]]。**
:::

::: example 被 trapped 的肺与滑石的决定 {#ex-pleura}
一位恶性间皮瘤的人在抽液后一周积液复发，而胸片显示肺没有复张；症状在抽液时缓解。
::: solution
**肺被陷闭（脏层胸膜被肿瘤或纤维板束缚）时，滑石的胸膜固定会失败，因为两层胸膜无法贴住[[#def-parapleur]]、[[respiratory/mechanics-breathing]]。更合适的是留置的胸膜导管：它让门诊的间歇引流，症状可控，并可能引起自发的固定[[surgery/wounds-surgical-infection]]、[[geriatrics-palliative/symptom-control]]。是否用手术（剥离与胸膜的切除）要按预后与目标与生理一起决定，并在多学科中讨论[[medical-ethics-law/end-of-life-ethics]]、[[clinical-skills/communication]]。同时优化：阿片的镇咳与呼吸困难的处理、营养与家属的支持[[geriatrics-palliative/palliative-care]]。**
:::
:::

::: example 11毫米的结节 {#ex-nodule}
一位61岁的吸烟者在一次外伤的CT上被发现一个11毫米的磨玻璃与实性混合的结节，边缘有毛刺；没有症状。
::: solution
**这是一个需要按概率管理的结节，不是可以忽略的偶然发现：形态（毛刺与混合的成分）与大小与吸烟史把恶性概率升高[[clinical-skills/medical-imaging]]、[[#def-cancer-class]]。路径按公开的算法：比较旧的影像、分期重复CT的时间或PET-CT、以及组织学（经皮的活检或支气管镜）或直接切除在高度怀疑且生理允许时[[surgery/perioperative-care]]、[[pathology/diagnostic-pathology]]。沟通很重要：说明概率与步骤，避免无计划的追逐，也避免虚假的安心，并记录随访的责任[[clinical-skills/communication]]、[[clinical-skills/records-handover]]。筛查的语境：在高风险的人群中低剂量的CT会把死亡下降，这改变了偶然发现的基线[[public-health/screening]]、[[public-health/prevention-promotion]]。**
:::
:::

::: example 肿胀的面部 {#ex-svc}
一位右侧肺门肿瘤的人有面与颈的肿胀与头痛和胸壁的静脉扩张，在弯腰时加重。
::: solution
**上腔静脉的综合征：肿瘤的压迫或血栓阻塞回流[[#def-cancer-class]]、[[cardiovascular/vascular-disease]]。急迫性取决于气道与神经的症状：严重的（喉的水肿与意识改变）需要即刻的处理（类固醇在淋巴瘤中、支架与放疗）；温和的可以按诊断的进度安排[[emergency-critical-care/airway-ventilation]]、[[pathology/cancer-diagnosis]]。要问血栓的成分（导管相关的）与抗凝的角色[[blood/thrombosis-anticoagulation]]。治疗以针对肿瘤为主（化疗在小细胞与淋巴瘤中有效且快），而支架在急迫时提供即刻的缓解[[pharmacology/drug-development-prescribing]]、[[surgery/vascular-urological-surgery]]。支持：把头部抬高与症状的控制并说明病程[[geriatrics-palliative/symptom-control]]、[[clinical-skills/communication]]。**
:::
:::

::: quiz
一次抽液后恶性积液复发，而肺没有复张（被陷闭的肺）。最好的下一步是：
- [ ] 用更大剂量的滑石重复胸膜固定
- [x] 一个被建立的留置胸膜导管
- [ ] 不论预后都做剥离手术
- [ ] 持续吸引的胸管
::: solution
**肺无法复张时，胸膜固定没有可以贴住的两层；留置导管可以门诊引流并缓解症状，并可能自发固定[[#ex-pleura]]、[[#def-parapleur]]、[[geriatrics-palliative/symptom-control]]。**
:::

::: history
肺癌的世纪是流行病学的证明与预防的胜利：病例对照的研究确立了烟草的因果，而戒烟与烟草的控制使男性的发病下降[[public-health/prevention-promotion]]、[[public-health/non-communicable-disease]]；X线与痰的细胞学与外科的扩展改变发现，而后是低剂量CT的筛查试验把死亡下降[[public-health/screening]]、[[clinical-skills/medical-imaging]]；分类与治疗从手术到放化疗，再到驱动的突变与检查点，把肺癌逐渐变成一个按分子被治疗的疾病[[pharmacology/drug-development-prescribing]]、[[immunology/vaccines-immunotherapy]]；胸膜的医学从开放的活检变成胸腔镜与留置的导管[[surgery/wounds-surgical-infection]]；而石棉的流行与赔偿把职业医学写进了这一章[[public-health/environmental-occupational]]、[[medical-ethics-law/justice-resources]]。
:::

## 通向何处

吸烟的干预与筛查在[[public-health/prevention-promotion]]与[[public-health/screening]]；病理与分子在[[pathology/cancer-biology]]与[[pathology/cancer-diagnosis]]；全身的表现与内分泌在[[endocrine/endocrine-emergencies]]与[[renal/potassium-calcium-phosphate]]；神经的副肿瘤在[[nervous-system/neuromuscular]]；手术与生理的评估在[[surgery/perioperative-care]]；胸膜的操作在[[surgery/wounds-surgical-infection]]；以及症状与目标的对话在[[geriatrics-palliative/palliative-care]]与[[clinical-skills/communication]]。

::: exercise 副肿瘤还是进展？{level=2}
一位在用含免疫检查点抑制剂方案治疗的小细胞肺癌患者出现四周的近端肌无力与口干和视物模糊；反射消失而知觉正常。机制是什么，并命名三个模仿者。
::: solution
**这是Lambert-Eaton的重叠肌病：电压门钙通道的抗体在神经末梢减少乙酰胆碱的释放，反射减弱而口干明显，常与小细胞相关[[nervous-system/neuromuscular]]、[[immunology/autoimmunity]]。三个模仿者：肌无力（眼与延髓的症状与乙酰胆碱受体的抗体）、炎症的肌病与检查点相关的（肌酸激酶升高与皮疹）[[musculoskeletal/connective-tissue-vasculitis]]、以及电解质与药物（低钾与激素的肌病和他汀）[[renal/potassium-calcium-phosphate]]、[[pharmacology/adverse-reactions]]。治疗：钾通道开放剂的药与原因的治疗，以及若为检查点相关的则按分级用激素[[immunology/tolerance-regulation]]、[[geriatrics-palliative/symptom-control]]。自主的症状（口干与便秘）会帮助定位到突触前[[gastrointestinal/bowel-disease]]。**
:::
:::

::: summary
- 肺癌的分类与治疗按生物学走：非小细胞与小细胞、驱动的突变与检查点，而分期与生理的储备决定方式。
- 预防与筛查是两条最有效的轴：戒烟会使超额风险减半并继续下降，而低剂量CT在高风险人群中降低死亡[[public-health/screening]]。
- 副肿瘤的表现可以是首发线索：钠与钙与神经肌肉的综合征会指向肿瘤并需要同期的评估。
- 恶性积液与陷闭的肺要按机制选择：胸膜固定需要复张，而留置导管在不能复张时更合适[[#ex-pleura]]。
- 急迫的肿瘤相关急症（上腔静脉的综合征与高钙与气道的压迫）需要同时处理诊断与症状[[endocrine/endocrine-emergencies]]、[[emergency-critical-care/airway-ventilation]]。
:::

## 练习

::: exercise 给组织分类 {level=1}
把每一个配到最可能的类型：(a) 中央肿块，钙3.4而PTH低；(b) 从不吸烟的44岁多发结节与脑转移；(c) 肺门肿块，钠124伴用力后改善的近端肌无力。
::: solution
(a) 鳞状细胞癌（相关肽介导的高钙）[[renal/potassium-calcium-phosphate]]、[[pathology/cancer-diagnosis]]；(b) 腺癌（在从不吸烟者与年轻患者中的驱动突变常见，脑转移倾向高）[[#def-cancer-class]]、[[clinical-skills/medical-imaging]]；(c) 小细胞癌伴Lambert-Eaton的重叠肌病与抗利尿激素的不当分泌[[nervous-system/neuromuscular]]、[[endocrine/hypothalamus-pituitary]]。组织学与分子一起决定治疗，因此取材的量与染色都很关键[[pathology/diagnostic-pathology]]、[[pharmacology/drug-development-prescribing]]。
:::
:::

::: exercise 为它分期 {level=1}
一个3厘米的周围腺癌伴同侧肺门淋巴结，无纵隔淋巴结与远处病变，而对侧一叶一个8毫米的结节经PET与活检为良性。给出T与N及分期的组别和方式。
::: solution
小的周围肿瘤属于T1–T2的范围，同侧肺门（N1）而无N2或M1：对侧结节被证明良性，因此不是M1a[[#def-cancer-class]]、[[clinical-skills/medical-imaging]]。分期的组别属于可手术的局部（II期的范围），方式就是切除加系统的淋巴结取样与辅助的治疗按结果[[surgery/perioperative-care]]、[[pharmacology/drug-development-prescribing]]。教学：在分期中一个被取样的可疑病灶胜过一个被假设的转移，因为后者会夺走治愈的机会[[pathology/diagnostic-pathology]]、[[medical-ethics-law/consent-capacity]]。
:::
:::

::: exercise 开胸的适应性 {level=2}
术前的肺活量与弥散：如何计算术后的预测值，而运动的测试在哪里进入？
::: solution
先算预测的术后功能（按将被切除的功能单位校正肺的灌注或节段），然后把第一秒与弥散能力的预测值与阈值（约30%到40%以下属于高风险）比较[[respiratory/control-breathing-tests]]、[[surgery/perioperative-care]]。当数字处在边界或症状不成比例时，运动测试（最大的摄氧量与无氧的阈值和蹬车的功率）会把风险分层并揭示心与肌肉的限制[[cardiovascular/heart-failure]]、[[respiratory/gas-exchange]]。替代：在这些不适合开胸者中立体定向的放疗与消融及支气管镜的技术[[pathology/cancer-biology]]、[[clinical-skills/medical-imaging]]。共同决策包括生理的现实与目标[[clinical-skills/communication]]、[[medical-ethics-law/end-of-life-ethics]]。
:::
:::

::: exercise 脑的提问 {level=2}
哪些肺癌患者需要脑的影像，哪些需要预防性的颅的照射，而什么改变了这个实践？
::: solution
小细胞与有神经症状或广泛病变的非小细胞需要头的影像（首选磁共振）[[clinical-skills/medical-imaging]]、[[nervous-system/stroke]]。预防性的颅的照射曾是小细胞对治疗反应后的标准，因为它减少脑的复发；如今在MRI的监测被常规进行时，它不再被自动推荐，尤其在女性与老年者中，因为生存的获益不明确而认知毒性真实[[pathology/cancer-biology]]、[[geriatrics-palliative/end-of-life-care]]。实践的变化：把影像与随访的MRI作为默认，把照射留给个体化的决定，并在讨论中说明认知与生活质量的权衡[[clinical-skills/communication]]。脑的转移的症状（头痛与癫痫和局灶的缺陷）需要急的评价[[nervous-system/epilepsy]]、[[emergency-critical-care/acute-assessment]]。
:::
:::

::: exercise 抽液并决定 {level=2}
一位58岁前船厂工人新发单侧积液：给出诊断性抽液生化的预期、第一轮的鉴别，以及在两次细胞学阴性之后的下一步取材。
::: solution
渗出液的标准（蛋白与LDH的比值超过阈值）指向恶性的与感染及其他[[#def-parapleur]]、[[respiratory/respiratory-infections]]。在这个暴露史中，间皮瘤与支气管的癌与良性的石棉相关的积液都要考虑[[public-health/environmental-occupational]]、[[pathology/cancer-diagnosis]]。第一次抽液细胞学的敏感性有限，两到三次会提高它；阴性时下一步是胸腔镜的直视活检（同时可以处理胸膜固定或导管）[[surgery/wounds-surgical-infection]]、[[clinical-skills/medical-imaging]]。同时评估心源性与肾的原因，避免只在漏诊后才回看[[cardiovascular/heart-failure]]、[[renal/chronic-kidney-disease]]。
:::
:::

::: exercise 高钙，机制在先 {level=2}
两位肺癌患者钙都是3.3：一位鳞癌PTH低而相关的肽高；另一位广泛溶解性的沉积而PTH被抑制、活性的维生素D低正常。解释每一种机制与共同的急性处理。
::: solution
第一位是体液性的高钙：肿瘤分泌相关的肽，把骨吸收与肾的钙回吸收增加[[renal/potassium-calcium-phosphate]]、[[endocrine/bone-calcium]]。第二位是局部骨的溶解：骨的病灶直接被破骨细胞激活破坏[[pathology/cancer-biology]]、[[musculoskeletal/bones-joints]]。共同的急性处理：等张的盐水纠正脱水并增加钙的排出，然后双膦酸盐（或单克隆的抗体）抑制破骨细胞[[renal/water-sodium]]、[[endocrine/bone-calcium]]；停止噻嗪与钙的补充并监测钾与镁及肾功能[[geriatrics-palliative/polypharmacy]]；治疗肿瘤本身（这会决定复发）；而在严重的病例中考虑降钙素与肾的替代[[renal/acute-kidney-injury]]、[[emergency-critical-care/critical-care]]。症状（多尿与意识改变与便秘和心律失常）会决定紧急[[nervous-system/dementia-neurodegeneration]]、[[cardiovascular/arrhythmias]]。
:::
:::

::: exercise 设计肺癌的路径 {level=3}
从症状到生存：建一条国家的快速通道，带目标、公平的核查与研究的议程。
::: solution
入口与目标：两星期的转诊标准与呼吸急促/咯血直接通道的时限；从转诊到组织学与到治疗开始的被测量的天数[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]。诊断：一个CT与取样的路径（支气管镜与经皮的与纵隔的取样）、PET与头的磁共振，以及被标准化的分子与检查点的检测[[clinical-skills/medical-imaging]]、[[pathology/diagnostic-pathology]]。治疗：多学科肿瘤板、手术的与放疗与内科的容量，以及试验的访问[[surgery/perioperative-care]]、[[pharmacology/drug-development-prescribing]]。支持：从诊断之日起的姑息与症状的管理与目标的对话和家属的支持[[geriatrics-palliative/palliative-care]]、[[medical-ethics-law/end-of-life-ethics]]。公平与生存：被剥夺群体与农村者的延迟与结果（把转诊的时限按人群分层）[[public-health/determinants-inequalities]]；戒烟与疫苗与肺的康复[[public-health/prevention-promotion]]；以及生存的随访与复发的路径和第二次原发[[respiratory/asthma-copd]]。
