呼吸的感染就是肺的医学的日常，也是[[immunology/innate-immunity]]的宿主防御的梯子在其中一环失败持续的演示：声门与咳嗽，黏液纤毛的电梯，肺泡的巨噬细胞与中性粒细胞的轴，以及分泌的免疫球蛋白A与T细胞免疫适应的臂[[immunology/adaptive-responses]]、[[immunology/tolerance-regulation]]。

本章涵盖宿主的防御与社区的获得及医院的获得肺炎、流感与其他的病毒，以及结核的原发与潜伏及复发的和肺外的形式。

## 宿主的防御与它们的失败

::: definition 气道的防御与感染进入的位置 {#def-defence}
**防御按区域被分层：上气道与声门（这些会防止吸入胃和口的内容；一个被损害的咳嗽/吞咽会破坏它[[nervous-system/stroke]]、[[geriatrics-palliative/delirium-dementia-care]]）；黏液纤毛电梯（这些会被吸烟与先天性的纤毛的运动障碍及囊性的纤维化损害，产生支气管扩张与反复的感染[[respiratory/respiratory-infections]]、[[genetics/mendelian-inheritance ]]）；肺泡（表面活性蛋白与防御素、巨噬细胞，以及被干扰素与自然杀伤细胞辅助的中性粒细胞[[immunology/innate-immunity]]）；以及适应的（分泌的免疫球蛋白A与T细胞的反应[[immunology/tolerance-regulation]]）。失败会塑造综合征：酒精与药物和手术的麻醉剂及卒中（吸入的风险[[surgery/anaesthesia-pain]]、[[emergency-critical-care/poisoning]]）；吸烟与慢阻肺（黏液与上皮的损害[[respiratory/asthma-copd]]）；脾切除（荚膜的生物[[blood/anaemia]]、[[immunology/immunodeficiency]]）；激素/抑制（肺囊虫与真菌[[infectious-diseases/immunocompromised-host]]、[[microbiology/fungi-parasites]]）；支气管的阻塞（肿瘤后反复同一叶的肺炎[[respiratory/lung-cancer-pleura]]）；以及器械（插管与呼吸机[[infectious-diseases/healthcare-infections]]）。微生物学会按环境与宿主来引导：社区的（肺炎链球菌与嗜血杆菌及非典型和病毒[[microbiology/bacteria]]、[[microbiology/viruses]]）；医院的（耐甲氧西林的葡萄球菌与肠杆菌科及假单胞菌[[microbiology/antimicrobials]]）；暴露的（鸟与军团菌和牛[[microbiology/fungi-parasites]]、[[public-health/environmental-occupational]]）。检查：培养与抗原与核酸的扩增、血清学，以及在选中的病例中的支气管镜与洗液[[microbiology/laboratory-diagnosis]]；而胸片/CT会定位图形[[clinical-skills/medical-imaging]]。**
:::

## 肺炎：综合征、严重度与来源

::: definition 社区的获得的肺炎 {#def-cap}
**一个终末空间感染的综合征：咳嗽与痰及呼吸困难与胸痛和发热，常常在老年人中以意识改变和跌倒呈现；体征（支气管的呼吸音与爆裂的和浊音）与胸片（实变）；老年人会呈现不典型（低体温与低血压和谵妄[[geriatrics-palliative/delirium-dementia-care]]）。严重度会决定安置：评分（意识与尿素与呼吸与年龄/血压）会估计死亡的风险并会指导门诊对病房对重症的[[emergency-critical-care/acute-assessment]]；以及危险的标志（高呼吸率与低血压和低氧/需要升高的支持、多叶、意识、合并症、失败的治疗）。微生物学：肺炎链球菌与嗜血杆菌、病毒（流感与新冠）与非典型（支原体与衣原体及军团菌[[#ex-legionella]]），在选中的中金黄色葡萄球菌和革兰氏的阴性[[microbiology/bacteria]]、[[microbiology/viruses]]。检查按严重度：气体的与血液的培养和尿的抗原（链球菌与军团菌）与病毒测试在季节/重症中；在严重或未反应的中的痰与支气管[[microbiology/laboratory-diagnosis]]。治疗：社区的经验（一个β-内酰胺类±一个大环内酯/多西环素，按重症与当地的数据；在重病例中的组合），在24到72小时内被结果降级；疗程缩短（三天在好临床的反应中，被当地的指南指导）[[microbiology/antimicrobials]]、[[infectious-diseases/stewardship-outbreaks]]；以及支持（氧气与液体和镇痛和肺扩张与咳嗽的技术[[respiratory/respiratory-failure ]]）。并发症：积液（一个超声；复杂的与脓胸需要引流[[respiratory/lung-cancer-pleura]]）、脓肿、失败（肿瘤阻塞？错误的诊断：栓塞和血管炎[[respiratory/interstitial-vascular-disease]]）；以及复发（一个在同一个部位的肺炎需要支气管的评估[[respiratory/lung-cancer-pleura]]）。预防：疫苗与戒烟和口腔的卫生及吞咽在卒中后[[immunology/vaccines-immunotherapy]]、[[public-health/prevention-promotion]]、[[nervous-system/stroke]]。**
:::

::: example 叔父混乱的周末 {#ex-cap-empyema}
一位74岁在三天被当作病毒在家治疗的人被带来：意识混乱与呼吸30及钠低；胸片显示出一侧的大的阴影，而在超声上有分隔的液体；在抗生素开始的60小时后仍然发热。
::: solution
**一个伴积液/脓胸的肺炎：持续的发热与升高的炎症的标志和分隔的液体会提示复杂的积液（脓性的或酸/葡萄糖/酶的异常），它们需要引流[[#def-cap]]、[[respiratory/lung-cancer-pleura]]。步骤：抽吸液体的分析（培养与生化和细胞学）与把胸管放置（小的导管可以；分隔的可能需要纤维蛋白溶解的策略或外科的[[surgery/wounds-surgical-infection]]、[[respiratory/lung-cancer-pleura]]）；继续覆盖需氧/厌氧与葡萄球菌（口腔的）[[microbiology/antimicrobials]]；以及寻找原因（吸入与肿瘤/食管[[surgery/acute-abdomen]]、[[respiratory/lung-cancer-pleura]]）。提醒：一个老年人以意识混乱呈现的肺炎是常见的；在低钠和腹泻中的重症要检查军团菌[[#ex-legionella]]；以及一个失败的肺炎会需要影像和支气管在治疗后[[clinical-skills/medical-imaging]]。**
:::
:::

::: definition 医院的获得与吸入及器械的感染 {#def-hap}
**医院的获得的肺炎与相关的呼吸机（在入院48小时后，或在插管后新的浸润伴脓性的征象与氧气的需要上升）：微生物学会转向耐药的生物（葡萄球菌与肠杆菌科及假单胞菌），带着本地的耐药的模式[[microbiology/antimicrobials]]、[[infectious-diseases/healthcare-infections]]。方法：本地的经验方案按风险；培养在开始前（下呼吸道定量的标本）；以及降阶梯和短的疗程，作为约束的标准的一部分[[infectious-diseases/stewardship-outbreaks]]。预防的套（这些会减少呼吸机的肺炎）：头被抬高的与口腔的卫生及声门下的吸引和每天苏醒与拔管的试验，以及避免再插管[[emergency-critical-care/airway-ventilation]]、[[clinical-skills/patient-safety]]。吸入的肺炎：胃与口的内容会进入依赖的段（下叶与后段）在卒中后与麻醉、癫痫及食管疾病之后[[nervous-system/stroke]]、[[surgery/anaesthesia-pain]]、[[nervous-system/epilepsy]]；化学的肺炎对细菌的感染会不同（早期的支持性照护常常就够），而预防就是吞咽的评估与位置的策略和口腔的照护[[geriatrics-palliative/delirium-dementia-care]]。免疫受损的宿主（宿主）：综合征（急性间质的肺炎与结节和空腔）会引导微生物学（病毒与肺囊虫与曲霉和分枝杆菌）和宿主[[infectious-diseases/immunocompromised-host]]、[[microbiology/fungi-parasites]]、[[infectious-diseases/tuberculosis]]。**
:::

## 病毒与肉芽肿

::: definition 流感与呼吸的病毒 {#def-viruses}
**流感：分节的核糖核酸病毒（血凝素与神经氨酸酶的亚型）会通过抗原的漂移（点突变会驱动每年的疫苗重新配制）与转移（在混合宿主中节段的重配）而变化，造成流行与大流行[[microbiology/viruses]]。临床：突发的高热与肌肉疼痛及头痛和咳嗽。并发症：原发病毒的肺炎、继发细菌的（链球菌与葡萄球菌）及心肌炎与脑病[[cardiovascular/valve-congenital-disease]]、[[nervous-system/neuroinflammation]]。风险更高在年老者、妊娠、慢的疾病与免疫受损中[[obstetrics-gynaecology/pregnancy-complications]]、[[infectious-diseases/immunocompromised-host]]。检查：咽拭子的核酸测试；其他病毒：呼吸道合胞与新冠及腺病毒和人偏肺病毒[[microbiology/viruses]]、[[infectious-diseases/tropical-infections]]。治疗：神经氨酸酶的抑制剂在重症与高风险中早期给予，加上支持与氧气[[respiratory/respiratory-failure]]；预防：疫苗与卫生措施及暴露后的药物[[public-health/vaccination-programmes]]、[[public-health/prevention-promotion]]、[[infectious-diseases/stewardship-outbreaks]]。**
:::

::: definition 结核：肉芽肿的两幕 {#def-tb}
**结核分枝杆菌是抗酸、生长缓慢的需氧菌。它被吸入肺泡后由巨噬细胞吞噬，其结局取决于第一型免疫与干扰素-γ所构成的肉芽肿能否把它封闭[[immunology/adaptive-responses]]、[[pathology/chronic-inflammation-repair]]、[[microbiology/bacterial-pathogenesis]]。第一幕是原发感染：多数人没有症状，或只有轻热与肺门淋巴结增大；少数（幼儿与免疫受损者）进展为广泛肺炎或血行播散[[paediatrics/immunisation]]、[[infectious-diseases/immunocompromised-host]]。第二幕是复发：被封闭的菌在数年至数十年后重新增殖，多在肺尖，形成空洞并排菌——这就是咳嗽与夜间盗汗、消瘦及咯血的模式[[infectious-diseases/tuberculosis]]。肺外结核可累及淋巴结、胸膜、脊柱、泌尿道与中枢[[musculoskeletal/back-pain]]、[[nervous-system/neuroinflammation]]、[[renal/urinary-tract]]。诊断靠胸片与涂片及培养、核酸扩增（含耐药标记）与免疫学的试验；潜伏感染的治疗与全程的四联方案是控制传播的两翼[[public-health/vaccination-programmes]]、[[public-health/communicable-disease-control]]。**
:::

::: example 夜间的盗汗与肺尖 {#ex-tb}
一位36岁，四年前从高发病的国家来到此地；咳嗽八周、夜间大汗、体重下降六公斤且痰中带血；胸片显示右肺上叶空洞；常规痰培养在48小时尚未生长。
::: solution
**一个典型的复发（成人型）的肺结核，而常规培养不会提示：需要抗酸的涂片与培养及核酸的扩增（含耐药的标记），以及把患者安置在空气传播的防护下[[infectious-diseases/tuberculosis]]、[[microbiology/laboratory-diagnosis]]、[[microbiology/infection-control]]。步骤还包括：人类免疫缺陷与其他免疫状态的检查、胸片空洞的鉴别（真菌与肿瘤及血管炎）[[infectious-diseases/hiv]]、[[microbiology/fungi-parasites]]、[[respiratory/lung-cancer-pleura]]；以及报告的义务与接触的追溯[[public-health/communicable-disease-control]]。治疗：四联的强化期然后继续期（按耐药），带着直接观察与肝的与眼的监测[[microbiology/antimicrobials]]、[[endocrine/adrenal]]。
:::

::: example 导游的肺炎 {#ex-legionella}
一位62岁在带团旅行的两周后出现高热与干咳及腹泻和意识混乱；钠为126，肝的酶升高，而胸片显示一侧的实变；痰的革兰氏染色显示出中性粒细胞而没有菌。
::: solution
**一个非典型的、细胞的病原体：军团菌（水的系统与旅行；胃肠道与神经的症状与低钠及培养阴性的痰）[[microbiology/bacteria]]、[[public-health/environmental-occupational]]、[[geriatrics-palliative/delirium-dementia-care]]。诊断依据尿抗原（血清群1）、核酸检测和培养的特殊培养基；治疗是大环内酯或喹诺酮，并报告公共卫生以调查水源[[microbiology/antimicrobials]]、[[public-health/communicable-disease-control]]。低钠与腹泻及意识混乱都要想到它，尤其在旅行、温泉与年老吸烟者中[[public-health/environmental-occupational]]。
:::
:::

::: example 用吸入激素哮喘患者的干咳 {#ex-pneumocystis}
一位34岁在长期的大剂量吸入激素与数月的口服激素上有渐进的气促与干咳；饱和在室内为90%，而步行时降到82%；胸片仅示双周的网状；乳酸脱氢酶升高。
::: solution
**肺囊虫的肺炎，直到被证明别的：亚急性的气促伴低氧与相对温和的影像，血气上肺泡-动脉梯度增宽、LDH升高，在细胞免疫缺陷中（此例为激素所致）[[infectious-diseases/immunocompromised-host]]、[[immunology/immunodeficiency]]、[[microbiology/fungi-parasites]]。检查：HIV 的检测与CD4计数、核酸的 PCR（诱导痰或支气管肺泡灌洗）以及CT（毛玻璃）[[infectious-diseases/hiv]]、[[clinical-skills/medical-imaging]]。治疗：在重症中 TMP-SMX 大剂量加激素（在低氧时，会减少死亡）[[microbiology/antimicrobials]]、[[respiratory/respiratory-failure]]，同时把吸入/口服激素减量并规划预防[[pharmacology/adverse-reactions]]。教训：免疫抑制可以来自肺部处方本身。
:::

::: history
胸片的引入使肺炎可以在床旁被定位，并把大叶肺炎与支气管肺炎分开[[clinical-skills/medical-imaging]]；肺炎球菌的分型与Avery的转化实验把细菌学与分子生物学连接[[microbiology/bacteria]]、[[genetics/genomic-medicine]]；青霉素与随后的磺胺和半合成的青霉素改变了结局，也开启了耐药的时代[[microbiology/antimicrobials]]；结核的控制靠疗养院、公共卫生的立法，然后是异烟肼与利福平的四联方案与直接观察的治疗[[public-health/communicable-disease-control]]、[[infectious-diseases/tuberculosis]]；疫苗的时代把肺炎球菌与流感及儿童病原的负担下降[[public-health/vaccination-programmes]]；而重症医学与呼吸机的预防包减少了医院获得的感染[[infectious-diseases/healthcare-infections]]。
:::

## 通向何处

防御的层次在[[immunology/innate-immunity]]与[[immunology/adaptive-responses]]；病原的生物学在[[microbiology/bacteria]]与[[microbiology/viruses]]及[[microbiology/fungi-parasites]]；治疗的原则在[[microbiology/antimicrobials]]与[[infectious-diseases/stewardship-outbreaks]]；重症的支持在[[respiratory/respiratory-failure]]与[[emergency-critical-care/critical-care]]；胸膜的并发症在[[respiratory/lung-cancer-pleura]]；基础的疾病在[[respiratory/asthma-copd]]；而人群的措施在[[public-health/communicable-disease-control]]与[[public-health/vaccination-programmes]]。

::: summary
- 呼吸的感染总能在防御梯子的某一步被解释：咳嗽与吞咽、黏液纤毛的清除、肺泡的巨噬细胞与中性粒细胞，以及黏膜与T细胞的免疫。
- 社区获得性肺炎的管理是三件事：严重度评分决定安置，微生物学（培养、尿抗原、病毒检测）指导用药，而影像追踪并发症（积液、脓胸、脓肿）。
- 医院获得与呼吸机相关的肺炎需要本地的经验方案、治疗前的培养，以及降阶梯与短疗程作为管理的一部分；预防是一套操作而非单味药。
- 流感与其他病毒可以本身致病，也可以为细菌的继发感染铺路；风险人群的界定决定抗病毒与疫苗政策。
- 结核有两幕（原发与复发）与两阶段治疗：强化期降低负荷并防耐药，继续期清除残存菌；诊断需要抗酸涂片、培养与核酸扩增，控制依赖报告、接触追溯与直接观察。
:::

胸液的蛋白42（血清61），LDH 900（血清210），pH 7.05，葡萄糖1.2，外观如脓；涂片见中性粒细胞而无细菌。应用标准并给出引流规则。
::: solution
蛋白与LDH的比值都超过阈值：一个渗出的液体；而pH低于7.2、葡萄糖低、脓的外观把它归为复杂的积液/脓胸，需要管引流（加上纤维蛋白溶解的策略或外科在分隔时）[[#ex-cap-empyema]]、[[respiratory/lung-cancer-pleura]]、[[surgery/wounds-surgical-infection]]。涂片阴性不排除：厌氧与经治的病例常常如此，所以培养要在床边注入[[microbiology/laboratory-diagnosis]]。
:::

::: exercise 无脾的胸 {level=2}
一位28岁在交通事故后切脾的人在六小时前发热与寒战；这是什么综合征、病原、即刻的行动，以及他的出院信里本应有什么？
::: solution
暴发性脓毒症（荚膜的细菌：肺炎球菌与嗜血杆菌及脑膜炎球菌；还有巴贝虫与犬咬的细菌）[[immunology/immunodeficiency]]、[[infectious-diseases/fever-sepsis]]、[[blood/transfusion]]。即刻：把发热视为急症——培养后立刻给静脉抗生素，进行液体与乳酸的路径[[emergency-critical-care/shock-fluids]]。出院信应有：疫苗（肺炎球菌与流感嗜血杆菌及脑膜炎球菌、流感）[[public-health/vaccination-programmes]]、备用抗生素与一个佩戴的警报，以及关于动物咬伤与发热的教育[[geriatrics-palliative/polypharmacy]]。

::: exercise 检查并解读 {level=2}
给出结核菌素的皮肤试验与血液的IGRA的机制、它们的假阳性与假阴性，以及每一个会回答的两个临床问题。
::: solution
皮肤试验测量迟发的T细胞的反应（需要回访，并会被以前的BCG与非结核的分枝杆菌影响）；IGRA测量干扰素-γ的释放（特异抗原，不受BCG影响，需要实验室）[[immunology/adaptive-responses]]、[[microbiology/laboratory-diagnosis]]。假阳性：BCG（皮肤试验）与环境的分枝杆菌；假阴性：免疫抑制与年龄小及播散的疾病[[infectious-diseases/hiv]]、[[immunology/immunodeficiency]]。它们会问的是：（1）有没有被感染（潜伏）——用于接触的追踪与高风险的筛查[[public-health/communicable-disease-control]]；（2）在开始生物制剂或激素之前是否需要预防[[endocrine/adrenal]]、[[musculoskeletal/connective-tissue-vasculitis]]。它们不会区分潜伏与活动[[infectious-diseases/tuberculosis]]。

::: exercise 未免疫婴儿的咳嗽 {level=2}
一位七周龄的婴儿有四天的卡他，随后出现成阵的咳嗽、咳后呕吐以及发作间期的面色发青，无热，也听不到典型的回声；父母安好。给出诊断、危险征象、管理与预防。
::: solution
这是百日咳，因为年龄太小尚未完成基础免疫：阵发性咳嗽伴咳后呕吐与面色发青而无明显发热，是最可靠的床旁图形[[microbiology/bacteria]]、[[paediatrics/acute-childhood-illness]]。需要住院的危险征象：年龄小于三个月、呼吸暂停、喂养失败、心动过缓、肺炎与惊厥[[paediatrics/newborn]]、[[nervous-system/epilepsy]]。管理：大环内酯（早期以阻断传播）、支持、对呼吸暂停的持续监测，重症时升级[[respiratory/respiratory-failure]]。预防：报告与接触者的预防用药、把家庭的疫苗按时补种，以及孕期的免疫[[public-health/vaccination-programmes]]、[[obstetrics-gynaecology/pregnancy-antenatal]]、[[public-health/communicable-disease-control]]。

::: exercise 利福平的账本 {level=1}
命名利福平的四项监测与安全的义务，以及三个最重要的相互作用及其机制。

::: exercise 随机的阴影 {level=2}
一位HIV阳性的男性有发热与消瘦，胸片呈粟粒样，钠为127，而听诊大致正常。给出鉴别、两个最快的有用检查，以及关于皮质醇的问题。
::: solution

::: exercise 设计呼吸感染的程序 {level=3}
为一个结核发病高、冬季肺炎压力大的地区设计双轨的程序：病毒与肺炎球菌的预防及急性的路径，以及结核消除的轨迹，并为每一条线给出生理与流行病学的逻辑。
::: solution
第一条线：把疫苗（肺炎球菌与流感及儿童程序）覆盖到风险人群，把急性路径标准化（氧气的目标与严重度评分和及时的抗生素，按本地的耐药）[[respiratory/respiratory-failure]]、[[emergency-critical-care/acute-assessment]]、[[microbiology/antimicrobials]]；加上通风与咳嗽的卫生社区的信息[[public-health/prevention-promotion]]。第二条线：主动病例发现（在风险群体中的筛查与对咳嗽的路径）与快速的核酸、接触者的追踪与潜伏感染的治疗、直接观察的治疗与登记，把耐药视为一个质量的信号[[public-health/communicable-disease-control]]、[[infectious-diseases/tuberculosis]]。
