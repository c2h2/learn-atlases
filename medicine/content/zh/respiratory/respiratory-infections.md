肺随每一次呼吸暴露于外界：每天约10000升空气，其中携带着粉尘、飞沫和微生物。大多数时候，呼吸道使下气道保持近乎无菌。当这些防御被压垮，或某种毒力特别强的病原体突破防线时，就会发生下呼吸道感染。肺炎仍是最常见的住院原因之一，也是全球主要的感染性死因之一，在年龄两端的人群中尤为突出。

本章先讲肺的防御，然后讨论肺炎：如何分类、由哪些病原体引起、如何评估严重程度以及如何选择抗生素。接着讲主要的病毒感染——流感、COVID-19和呼吸道合胞病毒——最后讲结核病，其更深入的内容见[[infectious-diseases/tuberculosis]]。抗生素建议按英国现行指南（NICE NG250，2025年；以及NICE NG138）的原则阐述；实践中的选择遵循反映当地耐药情况的当地指南。

## 呼吸道的防御 {#sec-defences}

::: definition 肺的防御 {#def-defences}
- **机械性**：鼻毛和鼻甲滤除大颗粒；咳嗽反射和声门关闭防止误吸。
- **黏液纤毛清除系统**：一层黏液捕获颗粒和微生物，气道上皮上的纤毛摆动，把黏液向上推送到咽部，然后被吞下。
- **体液性**：分泌型IgA、表面活性蛋白A和D（结合并调理微生物）、溶菌酶、乳铁蛋白和抗菌肽。
- **细胞性**：肺泡巨噬细胞吞噬到达肺泡的颗粒和微生物，在其不堪重负时募集中性粒细胞。
:::

几乎每一个肺炎危险因素都是上述某一环节的失灵。吸烟使纤毛瘫痪并损伤巨噬细胞。流感等病毒感染剥脱上皮，为细菌打开通道。意识水平下降（酒精、镇静药、卒中、癫痫发作）和吞咽障碍导致误吸。囊性纤维化和原发性纤毛运动障碍损害黏液清除。免疫抑制——无论来自HIV、化疗、移植药物还是糖皮质激素——削弱细胞性和体液性防御（[[immunology/immunodeficiency]]）。

## 肺炎 {#sec-pneumonia}

::: definition 肺炎及其发病场所 {#def-pneumonia}
**肺炎**是肺实质的感染，炎性渗出物充填肺泡。通常依据下呼吸道感染的症状和体征，加上胸片上新出现的、无其他解释的阴影来诊断。按获得场所分类：

- **社区获得性肺炎**（CAP）：在医院外获得。
- **医院获得性肺炎**（HAP）：入院48小时或以后发生，且入院时不在潜伏期。
- **呼吸机相关性肺炎**（VAP）：气管插管48小时或以后发生。
- **吸入性肺炎**：吸入口咽或胃内容物后发生。
- **免疫功能低下宿主的肺炎**：须考虑耶氏肺孢子菌、真菌和巨细胞病毒等少见病原体。
:::

这种区分很重要，因为可能的病原体不同。社区获得的肺炎通常由定植于健康上气道的病原体引起。在医院获得的肺炎，经过数天抗生素治疗和有创装置之后，更常由革兰氏阴性杆菌和耐药菌引起。

肺炎必须与**急性支气管炎**区分，后者是气道的感染（通常为病毒性），有咳嗽但无实变。其他方面健康的成人急性支气管炎通常不用抗生素即可好转，咳嗽可持续三周。

### 社区获得性肺炎的病因

- **肺炎链球菌**（肺炎球菌）在所有年龄段都是最常见的已明确细菌病因。典型表现为大叶性肺炎，起病急骤，高热、寒战、胸膜炎性胸痛和铁锈色痰。
- **流感嗜血杆菌**在慢阻肺患者中常见。
- **肺炎支原体**累及青年人和儿童，常每隔几年流行一次。起病缓慢，有头痛和干咳，有时出现肺外表现，如溶血性贫血（冷凝集素）、皮疹和神经系统并发症。
- **嗜肺军团菌**通过吸入受污染水系统（冷却塔、淋浴、水疗池）产生的气溶胶而获得，不在人与人之间传播。它可引起伴意识模糊、腹泻、低钠血症和肝功能紊乱的重症肺炎。
- **金黄色葡萄球菌**引起重症、有时形成空洞的肺炎，典型地发生在流感之后。产杀白细胞素（Panton–Valentine leukocidin，PVL）的菌株可在既往健康的年轻人中引起迅速致死的坏死性肺炎。
- **肺炎克雷伯菌**和其他革兰氏阴性杆菌在酒精依赖、糖尿病和衰弱者中较常见。
- **鹦鹉热衣原体**（鹦鹉热）从鸟类获得。
- **病毒**，包括流感病毒、SARS-CoV-2和呼吸道合胞病毒，单独或与细菌一起引起相当比例的肺炎。

支原体、军团菌和衣原体常被称为"非典型"病原体。这一术语在临床上有用，因为它们缺乏常规细胞壁或寄生于细胞内，对阿莫西林等β-内酰胺类抗生素无反应；需要大环内酯类、四环素类或氟喹诺酮类。实践中，临床表现很难指示病原体，约一半病例始终找不到病原体。

### 病理与临床表现

在大叶性肺炎中，未经治疗的患者经典地经历以下阶段：充血水肿期（血管充血和水肿）、红色肝样变期（肺泡内充满中性粒细胞、红细胞和纤维素，肺看起来像肝）、灰色肝样变期（红细胞崩解，纤维素持续存在）和溶解消散期（巨噬细胞清除渗出物，肺结构恢复正常）。**支气管肺炎**是以细支气管为中心的斑片状实变，常累及两肺下叶，多见于衰弱和老年人（[[pathology/acute-inflammation]]）。

典型患者有发热、咳嗽、咳痰、气短和胸膜炎性胸痛。查体可见呼吸急促、患侧胸廓扩张减弱、叩诊浊音、支气管呼吸音和湿啰音。老年人可能只表现为意识模糊、跌倒或活动能力下降，且可能不发热。脓毒症征象（低血压、呼吸频率很快、意识模糊、乳酸升高）提示病情严重（[[infectious-diseases/fever-sepsis]]）。

### 检查

- **胸片**：证实实变并发现并发症（积液、空洞）。在初级保健中，常在没有胸片的情况下作出临床诊断。影像学改变落后于临床恢复，有时达数周。
- **脉搏血氧测定，若饱和度低或患者病情重，则做动脉血气。**
- **血液检查**：全血细胞计数、尿素和电解质（尿素是严重程度评分的一部分；低钠血症提示军团菌）、肝功能和C反应蛋白。诊断不确定时，床旁CRP检测有助于初级保健中决定是否使用抗生素。
- **微生物学检查**（中度或高度严重者）：血培养、痰培养、肺炎球菌和军团菌尿抗原检测（军团菌检测只能检出血清1型），以及呼吸道病毒的PCR，疑诊时还包括非典型病原体的PCR。

### 严重程度评估

决定患者在家还是在医院治疗、以及治疗强度，依靠临床判断，并以经过验证的评分为辅助。

::: definition CRB65与CURB65 {#def-curb65}
以下每项计1分：

- **意识模糊**（Confusion）：新出现的对人物、地点或时间定向障碍，或简易智力测验评分8分或以下；
- **尿素**（Urea）高于7 mmol/L（仅CURB65，在医院中使用）；
- **呼吸频率**（Respiratory rate）每分钟30次或以上；
- **血压**（Blood pressure）：收缩压低于90 mmHg或舒张压60 mmHg或以下；
- 年龄**65**岁或以上。

在医院中，**CURB65** 0–1分为低度严重，2分为中度，3–5分为高度严重。在社区中使用**CRB65**（不含尿素）：在NICE NG250中，0分通常为低度严重，1–2分为中度，3–4分为高度，2分或以上应考虑转诊住院。
:::

死亡率随评分急剧上升：在推导出CURB65的研究中（Lim等，2003年），0–1分者低于3%，4–5分者约40%或更高。评分辅助而不取代判断。评分没有考虑低氧血症（其本身就可能需要住院），也没有考虑妊娠、衰弱、社会状况、不能口服药物或严重合并症。

::: example 评分与决策 {#ex-curb}
一名77岁男性因咳嗽和发热三天被送到急诊科。他神志清楚、定向力正常。呼吸频率26次/分，血压102/58 mmHg，呼吸空气时$S_pO_2$ 93%。尿素9.4 mmol/L。胸片显示右下叶实变。计算他的CURB65评分并阐述管理原则。
::: solution
意识模糊：无（0）。尿素9.4 > 7（1）。呼吸频率26，低于30（0）。舒张压58 ≤ 60（1）。年龄77 ≥ 65（1）。**CURB65 = 3：高度严重肺炎。**

他应在医院治疗，评估脓毒症，病情恶化时考虑请重症监护会诊。及时开始抗生素；对于高度严重的CAP，NICE指南列出的是广谱β-内酰胺类联合大环内酯类（例如阿莫西林克拉维酸联合克拉霉素），若病情很重则先静脉给药，并根据过敏情况和当地指南调整。送检血培养和痰培养、肺炎球菌和军团菌尿抗原检测以及呼吸道病毒PCR。除非有高碳酸血症风险，给氧目标为94–98%。48小时时复评抗生素，好转后改为口服；NICE建议大多数CAP患者总疗程为5天，只有在临床需要时才延长。
:::
:::

### 治疗原则

诊断确立后应尽快开始抗生素，若有伴高危标准的脓毒症特征，应在一小时内开始。NICE指南中成人CAP的选择概要为：**低度严重**，阿莫西林（青霉素过敏时可选多西环素或克拉霉素）；**中度严重**，阿莫西林，若怀疑非典型病原体则加用大环内酯类；**高度严重**，阿莫西林克拉维酸等β-内酰胺类加大环内酯类。剂量、给药途径和替代药物以指南和处方集为准。

支持治疗与抗生素同样重要：氧、补液、血栓预防、营养和早期活动。应告知患者发热通常在一周内消退，但咳嗽和乏力可持续数周。

如果患者没有好转，依次考虑各种可能：抗生素不对应病原体（非典型病原体、耐药、金黄色葡萄球菌）；出现并发症（脓胸、肺脓肿）；诊断不同（肺栓塞、心力衰竭、阻塞支气管的肺癌、机化性肺炎、血管炎）；或宿主的问题（免疫抑制、误吸）。随访胸片不作为常规，但对症状持续者以及潜在癌症风险较高者（如50岁以上吸烟者）应予考虑。

### 并发症

::: definition 肺炎旁胸腔积液与脓胸 {#def-empyema}
**肺炎旁胸腔积液**是与肺炎相关的胸腔积液。大多数为无菌性，用抗生素即可吸收。**复杂性**肺炎旁胸腔积液已有细菌侵入，典型表现为pH低（低于7.2）、葡萄糖低、乳酸脱氢酶高。**脓胸**是胸膜腔内有脓液。复杂性积液和脓胸除抗生素外还需要引流。
:::

经治疗后发热持续、CRP不降或胸膜炎性疼痛持续时，应怀疑胸膜感染。按英国胸科学会胸膜疾病指南（2023年），通过超声引导下胸腔穿刺进行检查和处理，详见[[respiratory/lung-cancer-pleura]]。

**肺脓肿**是含脓液的空洞，通常发生在误吸之后（混合厌氧菌），或由金黄色葡萄球菌或克雷伯菌引起。表现为弛张热、体重下降和恶臭痰，胸片显示带气液平面的空洞。通常对较长疗程的抗生素有效。鉴别诊断包括空洞性肺癌、结核病和肉芽肿性多血管炎。

其他并发症包括脓毒症和感染性休克、急性呼吸窘迫综合征（[[respiratory/respiratory-failure]]），以及老年人中的急性冠状动脉事件和心力衰竭加重。

::: example 不退的发热 {#ex-empyema}
一名49岁女性患大叶性肺炎，用阿莫西林治疗。第6天她仍发热，右侧胸膜炎性疼痛，CRP从180升至240 mg/L。超声显示中等量积液并有分隔。胸腔穿刺抽出浑浊液体，pH 7.05，葡萄糖1.4 mmol/L。诊断是什么？处理原则是什么？
::: solution
她有正在进展为脓胸的**复杂性肺炎旁胸腔积液**：液体浑浊、呈酸性（pH低于7.2）、葡萄糖很低，反映细菌和中性粒细胞的代谢；分隔提示正在形成包裹。单用抗生素无法清除。她需要在超声引导下**置入胸腔引流管**，扩大抗生素覆盖范围以涵盖厌氧菌和引起胸膜感染的病原体，根据胸液培养和当地指南选择，并尽早与呼吸团队讨论。若引流不完全，可考虑胸膜腔内注入组织型纤溶酶原激活物联合DNA酶，或手术。
:::
:::

### 吸入性肺炎与医院获得性肺炎

**吸入性肺损伤**（化学性肺炎，aspiration pneumonitis）是吸入胃酸造成的化学性损伤，常见于意识水平下降者，可能不需要抗生素。**吸入性肺炎**（aspiration pneumonia）是吸入有细菌定植的口咽物质后发生的细菌感染，多见于吞咽困难者（卒中后、帕金森病或痴呆）和口腔卫生差者。它典型地累及低垂部位的肺段：直立时为右下叶，平卧时为上叶后段和下叶背段，这是由于右主支气管比左主支气管更宽、更陡直（[[anatomy/thorax]]）。

**医院获得性肺炎**是一种主要的医疗相关感染。革兰氏阴性杆菌（包括铜绿假单胞菌、克雷伯菌、大肠埃希菌）、金黄色葡萄球菌（包括MRSA）和耐药菌更为常见，尤其在近期用过抗生素或住院时间较长者中。抗生素的选择取决于严重程度、入院后的时间、耐药风险和当地指南。预防措施包括良好的口腔护理、让患者坐起、早期活动、认真评估吞咽，以及对机械通气患者实施一整套预防措施（[[infectious-diseases/healthcare-infections]]）。

## 病毒性呼吸道感染 {#sec-viral}

### 流感

::: definition 流感病毒与抗原变异 {#def-influenza}
**甲型和乙型流感**病毒是有包膜的RNA病毒（正黏病毒），基因组分节段。其表面有**血凝素**（H），与呼吸道上皮的唾液酸受体结合；以及**神经氨酸酶**（N），释放新的病毒颗粒。**抗原漂移**是H和N的点突变逐渐积累，产生新的季节性毒株，因此每年需要更新疫苗。**抗原转变**只发生于甲型流感：人类与动物（如禽类或猪）病毒之间基因组节段的重配，产生带有新H或N亚型的病毒，人群对其几乎没有免疫力，可导致**大流行**。
:::

大流行发生于1918年（H1N1，估计死亡数千万人）、1957年（H2N2）、1968年（H3N2）和2009年（H1N1）。季节性流感引起突发高热、肌痛、头痛、咽痛和干咳。大多数健康成人在一两周内康复。重症和死亡主要见于老年人，慢性心、肺、肾、肝或神经系统疾病患者，免疫抑制者，孕妇和幼儿。并发症包括原发性病毒性肺炎、继发性细菌性肺炎（尤其是肺炎链球菌和金黄色葡萄球菌）、哮喘和慢阻肺加重、心肌炎和脑炎。

对于有并发症高风险的人，在社区中有流感流行时，按照NICE技术评估指南和英国卫生安全局（UKHSA）的建议，使用**神经氨酸酶抑制剂**（奥司他韦或扎那米韦）治疗，最好在症状出现后48小时内开始。这些药物能适度缩短病程，并可能减少高风险人群的并发症。在英国，每年为老年人、慢性病患者、孕妇、医疗和社会照护工作者以及儿童接种疫苗（[[public-health/vaccination-programmes]]）。

::: example 流感后的肺炎 {#ex-flu}
一名既往健康的32岁男性患流感样疾病。五天后，在初步好转之后，他突然病情加重，出现高热、咯血和低血压。胸片显示双侧实变并有早期空洞。应怀疑什么病原体，为什么？
::: solution
先好转、后突然严重恶化的模式提示流感后**继发性细菌性肺炎**。流感损伤呼吸道上皮，削弱中性粒细胞和巨噬细胞功能，使细菌得以进入肺。年轻人出现空洞、咯血和感染性休克，指向**金黄色葡萄球菌**，可能是引起坏死性肺炎的产PVL菌株。他需要紧急重症监护评估、血培养和痰培养，以及包括抗金黄色葡萄球菌活性在内的广谱抗生素覆盖（若有危险因素或当地流行率高，还要覆盖MRSA），遵循当地指南和专科建议。若证实为产PVL金黄色葡萄球菌，可能需要公共卫生和微生物团队参与。
:::
:::

### COVID-19

COVID-19由严重急性呼吸综合征冠状病毒2（SARS-CoV-2）引起，该病毒通过血管紧张素转换酶2（ACE2）受体进入细胞。它于2019年底出现，世界卫生组织于2020年3月宣布其为大流行。感染从无症状到轻度上呼吸道疾病，到伴低氧血症的肺炎，再到急性呼吸窘迫综合征和多器官衰竭。重症与高龄、男性、肥胖、糖尿病、免疫抑制和其他慢性疾病相关，也与社会贫困和职业暴露相关。大流行早期的一个显著特征是"沉默性"低氧血症：一些患者血氧饱和度极低却几乎没有气短。

治疗由大型随机试验塑造，尤其是英国的RECOVERY平台试验。RECOVERY在2020年证明，**地塞米松**降低了需要吸氧或机械通气的住院患者的死亡率，但对不需要吸氧者无效；因此糖皮质激素用于有低氧血症的住院患者，而不用于轻症者。后来的试验显示，在部分有低氧血症和全身炎症的患者中阻断白细胞介素-6（托珠单抗）有益。抗病毒治疗（例如奈玛特韦联合利托那韦）在感染早期提供给重症风险最高的人；利托那韦有许多重要的药物相互作用。CPAP或高流量鼻导管氧疗等呼吸支持以及俯卧位见[[respiratory/respiratory-failure]]。疫苗接种大大减少了重症和死亡。有些人在感染后数月仍有持续症状（COVID-19后状况，或称"长新冠"）。

### 呼吸道合胞病毒

呼吸道合胞病毒（RSV）是婴儿毛细支气管炎最常见的病因，典型地发生在出生后第一年，表现为流涕、咳嗽、喘息、湿啰音和喂养困难（[[paediatrics/acute-childhood-illness]]）。它也在老年人和慢性心肺疾病患者中引起重要疾病。2024年9月，英国开始为老年人（最初为75–79岁）和孕妇接种RSV疫苗，后者通过转移抗体保护其婴儿。

## 结核病 {#sec-tb}

::: definition 结核病 {#def-tb}
**结核病**（TB）是结核分枝杆菌感染。结核分枝杆菌是一种生长缓慢的抗酸杆菌，由传染性肺结核患者通过空气中的飞沫核传播。**结核感染**（以前称"潜伏性结核"）是被免疫系统控制、无症状也无影像学病变的感染，不具传染性。**结核病**（活动性结核）引起症状，若累及肺或喉则可传播。
:::

据世界卫生组织统计，2023年约有1080万人患结核病，约125万人死亡，使其再次成为全球单一感染性病原体中的首要死因。在英国，大多数病例发生在出生于高发病率国家的人中，并与社会贫困、无家可归、监禁以及药物和酒精依赖密切相关。

吸入后，杆菌被肺泡巨噬细胞吞噬，并能在其中存活。在大多数人中，由γ干扰素驱动的T细胞应答把感染局限在**肉芽肿**内：肉芽肿由活化的巨噬细胞、上皮样细胞和多核巨细胞围绕中央的**干酪样坏死**构成（[[pathology/chronic-inflammation-repair]]）。初始病灶及受累的肺门淋巴结构成**原发综合征（Ghon综合征）**。免疫功能正常的感染者中约5–10%在一生中发病，其中约一半在最初两年内。HIV感染、免疫抑制药物（包括抗TNF药物和长期糖皮质激素）、糖尿病、慢性肾脏病、硅沉着病、营养不良以及幼儿中，风险要高得多。

继发性肺结核典型地累及上叶尖段和后段，这些部位通气/血流比值高，因而氧分压高。它引起持续三周以上的咳嗽、咯血、发热、盗汗和体重下降，胸片显示上肺区实变和空洞。结核病还可累及淋巴结、胸膜、骨和脊柱、脑膜、肾以及几乎任何器官。

诊断依靠微生物学。至少送三份痰标本做抗酸杆菌**涂片镜检**和**培养**；培养需要数周，但仍是金标准，并可进行完整的药物敏感性试验。**核酸扩增检测**（例如同时检测利福平耐药的检测）可快速出结果。结核感染用**γ干扰素释放试验**（IGRA）或结核菌素皮肤试验检测，两者都不能区分感染与活动性疾病。

::: widget bayes

prevalence: 0.02

caption: 用γ干扰素释放试验在低风险人群中筛查结核感染的示意模型（患病率2%，灵敏度80%，特异度97%；数值为教学所选）。即使特异度很高，在此患病率下每三个阳性结果中约有两个是假阳性。提高患病率——如检测传染性结核患者的密切家庭接触者，或新近从高发病率国家来的人——阳性预测值随之升高。这就是筛查针对高风险人群的原因。
:::

药物敏感结核病的治疗是六个月方案：**利福平、异烟肼、吡嗪酰胺和乙胺丁醇**两个月（强化期），然后**利福平和异烟肼**四个月（继续期）。多药联用是因为对任何单一药物都容易产生耐药。重要的不良反应包括肝毒性（利福平、异烟肼、吡嗪酰胺），尿液和泪液呈橙色、强效诱导肝酶并与许多药物（包括激素避孕药）相互作用（利福平），周围神经病变（异烟肼，用维生素B6预防）以及视神经炎（乙胺丁醇）。通过病例管理支持依从性，必要时采用直接督导下治疗。在英国结核病是法定报告疾病，需追踪和筛查接触者。耐药结核病、肺外结核和结核病控制规划见[[infectious-diseases/tuberculosis]]。

::: example 咳嗽六周 {#ex-tb}
一名34岁男性三年前从一个结核病高发国家来到英国，咳嗽六周、盗汗、体重下降6 kg。他与另外五人合住。胸片显示右上叶空洞。下一步应怎么做？
::: solution
在证实为其他疾病之前，这是**疑似肺结核**；空洞提示他可能具有高度传染性。若收住院，应安置在单人间并实行呼吸道隔离。送三份痰标本（最好包括一份晨痰）做抗酸涂片、培养和同时检测利福平耐药的快速核酸扩增检测。应像对所有结核病患者一样为他提供HIV检测，并检查有无糖尿病。若结果支持结核病，开始标准四联治疗，治疗前检查肝功能和视力，并向当地卫生防护团队报告病例，由其追踪和筛查他的家庭接触者。上叶空洞的鉴别诊断包括肺癌（尤其是鳞状细胞癌）、肺脓肿、非结核分枝杆菌感染和肉芽肿性多血管炎。
:::
:::

::: warning 可能为结核病时，不要用氟喹诺酮类"试验性抗感染"
左氧氟沙星和莫西沙星等氟喹诺酮类对结核分枝杆菌有活性。对实际上患有结核病的患者，按推定的细菌性肺炎给予这类药物，可能带来暂时好转，延误诊断，降低痰培养阳性率，并筛选出氟喹诺酮耐药——从而失去治疗耐药结核病的关键药物之一。当结核病确有可能时，先留取痰标本，若需要抗生素则选择非喹诺酮类。
:::

## 预防 {#sec-prevention}

在人群层面预防呼吸道感染的主要措施包括：不吸烟；减少固体燃料造成的室内空气污染；按国家免疫规划接种疫苗（肺炎球菌、流感、COVID-19、RSV、百日咳、b型流感嗜血杆菌，以及对有结核风险者接种卡介苗）；医疗机构中良好的感染预防（手卫生、呼吸道隔离、通风）；以及早期诊断和治疗结核病以阻断传播（[[public-health/communicable-disease-control]]）。

::: quiz
一名45岁男性在国外住酒店后回国，出现高热、意识模糊、腹泻和右下叶实变。血钠126 mmol/L。哪项检查能最快支持可能的诊断？
- [ ] 痰抗酸杆菌涂片
- [x] 军团菌尿抗原
- [ ] γ干扰素释放试验
- [ ] 支原体冷凝集素
::: solution
旅行住酒店（水系统）、伴意识模糊和腹泻的重症肺炎以及低钠血症，提示**军团病**。尿抗原检测可快速检出最常见的嗜肺军团菌血清1型；阴性不能排除其他血清型，因此还要送呼吸道标本做培养和PCR。在英国军团病是法定报告疾病，公共卫生团队会调查可能的来源。治疗需要对细胞内病原体有活性的抗生素，如大环内酯类或氟喹诺酮类。
:::
:::

::: history
1882年3月24日，罗伯特·科赫（Robert Koch）在柏林宣布发现了结核杆菌，这一天现已定为世界防治结核病日。1881年，路易·巴斯德（Louis Pasteur）和乔治·斯滕伯格（George Sternberg）各自独立分离出肺炎球菌，1886年阿尔伯特·弗伦克尔（Albert Fraenkel）确立了它是大叶性肺炎的主要病因。1943年在塞尔曼·瓦克斯曼（Selman Waksman）实验室发现的链霉素，在1948年英国医学研究理事会的试验中得到检验，这是最早的随机对照试验之一。该试验及其后续试验表明，单药治疗很快出现耐药，从而确立了联合治疗作为结核病治疗的基础。1976年在费城美国退伍军人协会大会参会者中暴发疫情之后，军团病得到认识。2020年3月在英国启动的RECOVERY试验，在约100天内报告了地塞米松对COVID-19的死亡率获益。
:::

## 习题

::: exercise CURB65 {level=1 check="2"}
一名68岁肺炎女性神志清楚，呼吸频率24次/分，血压118/72 mmHg，尿素8.1 mmol/L。她的CURB65评分是多少？
::: solution
意识模糊0，尿素高于7（1），呼吸频率低于30（0），血压正常（0），年龄65岁或以上（1）。CURB65 = 2，中度严重。适合在医院评估，处理还要参考她的血氧饱和度和临床情况。
:::
:::

::: exercise 典型与非典型 {level=1}
为什么阿莫西林治疗不了肺炎支原体？说出两类有效的抗生素。
::: solution
阿莫西林等β-内酰胺类通过结合青霉素结合蛋白作用于细菌细胞壁；支原体没有细胞壁。大环内酯类（克拉霉素、阿奇霉素）和四环素类（多西环素）有效，氟喹诺酮类也有效。
:::
:::

::: exercise 漂移还是转变？ {level=1}
解释抗原漂移与抗原转变的区别，并说明哪一种可发生于乙型流感。
::: solution
漂移是血凝素和神经氨酸酶基因点突变的逐渐积累，每个季节产生新的变异株，需要每年更新疫苗；甲型和乙型流感都会发生。转变是新的H或N亚型的突然出现，通常由人类与动物甲型流感病毒之间基因组节段重配引起；它可导致大流行，只发生于甲型流感，因为乙型流感没有重要的动物宿主。
:::
:::

::: exercise 阳性预测值 {level=2 check="round(100*0.08/(0.08+0.027))"}
用灵敏度80%、特异度97%的IGRA检测一名涂片阳性结核病患者的家庭接触者，这些人中结核感染的患病率为10%。阳性结果的阳性预测值是多少（以百分比表示，取最接近的整数）？
::: hint
在1000名接触者中，分别数出真阳性和假阳性。
:::
::: solution
1000名接触者中，100人感染，900人未感染。真阳性：$0.80 \times 100 = 80$。假阳性：$0.03 \times 900 = 27$。PPV $= 80/(80 + 27) = 0.748$，即75%。对比本章中患病率2%的低风险人群约35%的数值：同样的检测在先验概率高的人群中提供的信息要多得多。
:::
:::

::: exercise 抗结核治疗的副作用 {level=2}
一名接受标准抗结核治疗的女性诉足部刺痛，一个月后又出现视物模糊、难以分辨红绿色。她还询问复方口服避孕药是否仍然有效。分别是哪些药物引起的？应给予什么建议？
::: solution
足部刺痛提示**异烟肼**引起的周围神经病变，由维生素B6缺乏所致；可给予维生素B6预防，尤其是对高风险者。视物模糊和红绿色觉丧失提示**乙胺丁醇**视神经炎；应停用该药并让她紧急就诊眼科。**利福平**强效诱导肝酶，降低激素避孕药的效果；她应使用可靠的替代方法，如含铜宫内节育器，并检查她的其他药物有无相互作用。
:::
:::

::: exercise 误吸到了哪里？ {level=2}
一名79岁帕金森病男性跌倒后在地板上躺了一夜，随后发生肺炎。最可能累及哪些肺段，为什么？
::: solution
仰卧时，误吸物在重力作用下流入低垂部位的肺段：**上叶后段**和**下叶背段（上段）**，右侧更常见，因为右主支气管更短、更宽、更陡直。站立或坐位时，误吸多累及下叶，尤其是右下叶。病原体通常是包括厌氧菌在内的口腔细菌混合。他的帕金森病通过吞咽困难增加了风险；吞咽评估是处理的一部分。
:::
:::

::: exercise 不见好转的肺炎 {level=3}
一名61岁吸烟者患右下叶肺炎，CURB65为1分，已用阿莫西林治疗5天。他仍有咳嗽和低热。复查胸片显示右下叶阴影持续存在并有一定程度的容积减少。给出有条理的鉴别诊断和关键检查。
::: solution
考虑四类情况。**病原体或药物不对**：阿莫西林未覆盖的非典型病原体、耐药菌，或结核病。**并发症**：肺炎旁胸腔积液或脓胸（若有积液则行超声和胸腔穿刺），或肺脓肿。**诊断错误或另有诊断**：在一名有容积减少的61岁吸烟者中，**阻塞支气管的肿瘤**（阻塞性肺炎）是严重的担忧；还有肺栓塞伴梗死、机化性肺炎或异物吸入。**宿主因素**：免疫抑制或反复误吸。

检查：痰培养和抗酸杆菌、尿抗原、炎症标志物、胸部超声查积液，以及**胸部CT**，若CT提示支气管内病变再行**支气管镜检查**。50岁以上吸烟者持续的肺叶阴影伴容积减少，在排除癌症之前不应归因于吸收缓慢（[[respiratory/lung-cancer-pleura]]）。
:::
:::

::: exercise 成簇出现的肺炎 {level=3}
两周内，同一家医院收治了五名重症肺炎成人。其中三人在同一栋写字楼工作，楼顶有一座冷却塔。两人有低钠血症，一人肝功能紊乱。可能的病因是什么？如何证实？随后应采取什么公共卫生行动？
::: solution
这提示一次来自共同环境来源（可能是冷却塔）的**军团病**暴发。军团菌通过受污染水的气溶胶传播，不在人与人之间传播。证实方法：尿抗原检测（血清1型），以及呼吸道标本培养或PCR，以便对病原体分型，把患者分离株与冷却塔的环境样本进行匹配。公共卫生行动：报告卫生防护团队，成立暴发控制小组，检查并采样潜在来源，对冷却塔消毒，在其他暴露者中搜寻病例，并提醒临床医生对与该区域相关的肺炎患者进行检测。患者需要对军团菌有活性的抗生素（大环内酯类或氟喹诺酮类）。
:::
:::
