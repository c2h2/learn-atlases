哮喘和慢性阻塞性肺疾病（慢阻肺）是气流阻塞的两大常见原因。两者在英国共累及数百万人，在全世界累及数亿人，并占急诊入院的很大一部分，冬季尤甚。两者都使气道变窄，都引起喘息、咳嗽和气短，但它们在病因、机制、随时间的演变以及治疗上各不相同。

简而言之：**哮喘**是由气道炎症驱动的**可变性**气流受限疾病；它常始于儿童期，可以得到良好控制，发作间期肺功能可能正常。**慢阻肺**是**持续性**、通常进行性的气流受限疾病，主要由长期接触有害颗粒（首先是烟草烟雾）引起；它始于中年或更晚，肺损伤大多不可逆。许多患者并不能干净利落地归入其中一类，有些人兼具两者的特征。

本章依次讨论两种疾病：出了什么问题、如何诊断、稳定期如何管理、急性加重如何治疗。治疗遵循英国现行指南（2024年NICE/BTS/SIGN哮喘指南NG245和NICE慢阻肺指南NG115）以及国际GINA和GOLD报告，以原则的形式阐述，而非针对个别患者的指示。

## 哮喘 {#sec-asthma}

::: definition 哮喘 {#def-asthma}
**哮喘**是一种气道慢性炎症性疾病，特征是**可变的呼吸道症状**（喘息、气短、胸闷和咳嗽，其出现时间和强度均有变化）并伴有**可变的呼气气流受限**。气道呈**高反应性**：对健康气道几乎没有影响的刺激，会使其过度收缩。
:::

### 气道内发生了什么

在大多数哮喘患者中，尤其是儿童期起病者，炎症呈**2型**模式。屋尘螨、花粉或动物皮屑等吸入性变应原被树突状细胞摄取，提呈给辅助性T细胞2（Th2）。这些细胞和气道的固有淋巴样细胞释放各有分工的细胞因子：白细胞介素-4驱动B细胞产生免疫球蛋白E（IgE），白细胞介素-5募集并维持嗜酸性粒细胞，白细胞介素-13增加黏液分泌和气道高反应性。受损的气道上皮释放胸腺基质淋巴细胞生成素（TSLP）等"警报素"信号，放大这一反应（[[immunology/hypersensitivity]]）。

已致敏者再次吸入变应原时，肥大细胞上的IgE发生交联，肥大细胞在数分钟内释放组胺、白三烯和前列腺素。平滑肌收缩、黏膜肿胀：这是**速发型哮喘反应**。数小时后，被募集的嗜酸性粒细胞和淋巴细胞引起**迟发型反应**，气道进一步变窄，高反应性增加。经年累月，反复炎症可使气道壁增厚、平滑肌增多，并在上皮下沉积胶原。这种**气道重塑**可能使部分气流受限变为固定性。

并非所有哮喘都是2型。一些成人——常为晚发、肥胖或有吸烟史者——嗜酸性粒细胞炎症很少；这种"2型低"哮喘对糖皮质激素反应较差。实践中测定的2型炎症标志物是**血嗜酸性粒细胞计数**和**FeNO**（[[respiratory/control-breathing-tests]]）。

常见诱因包括病毒性呼吸道感染（儿童发作的最常见原因）、变应原、冷空气、运动、烟雾和污染，以及面粉、异氰酸酯和乳胶等职业性致敏物。某些药物会诱发发作：**β受体阻滞剂**（包括滴眼液）可引起严重支气管痉挛；在少数伴鼻息肉的成人哮喘患者中，**阿司匹林和其他NSAID**通过使花生四烯酸代谢转向白三烯而诱发发作。

### 诊断

哮喘没有单一的金标准检查。诊断依靠典型病史，并以可变性气流阻塞或2型炎症的客观证据为支持。客观检查很重要：多个国家的研究发现，被贴上哮喘标签的成人中，相当一部分在检查后并无哮喘。

2024年NICE/BTS/SIGN指南（NG245）为病史提示哮喘的成人列出了一套检查顺序。概要如下：

1. 测定**血嗜酸性粒细胞计数**或**FeNO**。嗜酸性粒细胞计数升高（高于实验室参考范围）或FeNO达到或超过50 ppb即可确诊。
2. 否则，进行**肺量计及支气管舒张试验**。FEV₁增加12%及以上且200 mL及以上即可确诊哮喘。
3. 若仍未确诊，或无法进行肺量计检查，则连续两周每天两次测定**峰流量变异性**；平均变异幅度达到或超过20%即可确诊。
4. 若诊断仍未证实，则转诊做**支气管激发试验**。

5至16岁儿童遵循类似路径，FeNO阈值较低（35 ppb）。5岁以下通常无法进行客观检查，治疗依据症状和体征，待孩子年龄足够大时再检查复核。

::: example 每年冬天都会复发的咳嗽 {#ex-asthma-dx}
一名24岁女性一年来反复出现喘息和夜间咳嗽，感冒后和接触猫时加重。她儿时患过湿疹。发作间期查体正常。她的FeNO为62 ppb。如何诊断？NG245建议什么治疗？
::: solution
病史很典型：发作性、可变的症状，夜间咳嗽，可识别的诱因，以及个人特应性病史。按照NG245，有提示性病史的成人FeNO达到或超过50 ppb即可**确诊哮喘**，无需进一步检查（肺量计作为基线仍然有用）。FeNO升高还预示她对吸入糖皮质激素反应良好。

对于新诊断的成人，NG245建议从**按需使用低剂量ICS/福莫特罗**开始（一种吸入器中合并了吸入糖皮质激素和起效迅速的长效β₂受体激动剂福莫特罗），用于缓解症状，即"抗炎缓解治疗"（AIR）。每次使用缓解药物都同时给予一剂糖皮质激素。如果她就诊时症状频繁或夜间憋醒，指南建议直接开始低剂量MART（见下文）。她还需要一份个人书面行动计划、吸入技术培训和关于诱因的建议。
:::
:::

### 稳定期哮喘的管理

目标是**控制**：无症状或症状极少、无发作、活动不受限、肺功能正常或接近正常，同时副作用最少。哮喘未控制通常通过询问症状、缓解药物使用和夜间憋醒来评估，有时借助经过验证的问卷，并记录需要口服糖皮质激素的发作。

::: definition 哮喘的吸入治疗 {#def-asthma-drugs}
- **吸入糖皮质激素**（ICS；如布地奈德、倍氯米松、氟替卡松）减轻气道炎症和高反应性，降低发作风险，是哮喘治疗的基础。
- **β₂受体激动剂**使气道平滑肌松弛。短效药物（SABA；沙丁胺醇、特布他林）数分钟内起效，持续4–6小时。长效药物（LABA；沙美特罗、福莫特罗、维兰特罗）作用持续12–24小时。福莫特罗起效快，因此也可作为缓解药物使用。
- **MART**（维持和缓解治疗）使用同一种ICS/福莫特罗吸入器，既作规律维持治疗，又按需缓解症状。
- 其他附加治疗包括**白三烯受体拮抗剂**（孟鲁司特）、**长效毒蕈碱受体拮抗剂**（LAMA；噻托溴铵），以及在重症哮喘中针对2型通路的**生物制剂**。
:::

对于12岁及以上的成人和青少年，NG245列出了阶梯式路径。概要如下：从按需使用低剂量ICS/福莫特罗（AIR）开始；若哮喘未控制，改为低剂量MART；然后是中剂量MART。若仍未控制，检查FeNO和血嗜酸性粒细胞：任一升高则转诊至哮喘专科；若均未升高，可考虑试用一段时间的附加白三烯受体拮抗剂或LAMA，若仍未控制则转诊。5–11岁儿童遵循相应的路径，从儿童低剂量ICS开始。确切剂量、装置和许可范围以指南和现行处方集为准。GINA策略（每年更新）推荐类似的以ICS/福莫特罗为基础的方案作为其首选路径。

升级治疗之前要先检查基础问题：患者吸入方法是否正确、是否规律用药、是否避免诱因（包括吸烟）？诊断是否正确？鼻炎、肥胖、反流或呼吸模式紊乱等合并症是否在起作用？

::: warning 切勿单用短效缓解药物治疗哮喘
不配合吸入糖皮质激素而规律或频繁使用短效β₂受体激动剂，只能缓解症状而使炎症得不到治疗，而且大量使用SABA本身就是风险标志。英国全国哮喘死亡审查（2014年）发现，许多死者被开具了大量缓解吸入器，而预防性药物很少。现行指南（NG245和GINA）已不再推荐成人和青少年单用SABA治疗。一个领取大量缓解吸入器的患者需要紧急复诊，而不是再开一张重复处方。
:::

**重症哮喘**是指在高剂量治疗和处理好基础问题后仍未控制，或需要这种治疗才能保持控制的哮喘。它在专科中心管理。生物制剂靶向2型炎症：**奥马珠单抗**（抗IgE）、**美泊利珠单抗**和**瑞利珠单抗**（抗白细胞介素-5）、**贝那利珠单抗**（针对白细胞介素-5受体，清除嗜酸性粒细胞）、**度普利尤单抗**（针对白细胞介素-4受体α，阻断白细胞介素-4和-13信号）以及**特泽鲁单抗**（抗TSLP）。它们减少发作和口服糖皮质激素的需要，而长期口服糖皮质激素的危害包括骨质疏松、糖尿病、白内障和肾上腺抑制。

### 急性哮喘

哮喘急性发作是急症，可以致命，包括既往病情轻微的年轻人。严重程度用简单的床旁指标判断。英国实践中使用的BTS/SIGN标准概要如下。

::: definition 成人急性哮喘的严重程度 {#def-acute-asthma}
- **中度**：症状加重；PEF高于最佳值或预计值的50–75%；无急性重度哮喘的特征。
- **急性重度**：具有以下任一项：PEF为最佳值或预计值的33–50%；呼吸频率≥25次/分；心率≥110次/分；不能一口气说完整句话。
- **危及生命**：重度哮喘患者具有以下任一项：PEF低于最佳值或预计值的33%；$S_pO_2$低于92%；$P_{aO_2}$低于8 kPa；$P_{aCO_2}$"正常"（4.6–6.0 kPa）；沉默肺；发绀；呼吸努力减弱；心律失常；衰竭；意识水平改变；低血压。
- **濒死**：$P_{aCO_2}$升高，或需要以升高的充气压力进行机械通气。
:::

急性哮喘中$P_{aCO_2}$正常是危险信号。发作中的患者应当在过度通气，$P_{aCO_2}$应当偏低；正常或正在升高意味着他们正在疲劳，已无法维持那样的通气。

医院内治疗遵循指南和当地方案。原则是：给氧，目标血氧饱和度94–98%；大剂量吸入短效β₂受体激动剂，重度发作时用氧气驱动雾化反复或持续给药；重度或危及生命的发作加用雾化异丙托溴铵；所有需要医院评估的发作都给予全身性糖皮质激素（英国实践中通常口服泼尼松龙至少五天）；若反应不佳，单次静脉给予硫酸镁。有危及生命或濒死特征，或病情恶化的患者，需要尽早让上级医师和重症监护团队参与。出院前要复核吸入技术、预防性治疗和书面行动计划，并在初级保健中随访。

::: example 发作的分级 {#ex-acute-asthma}
一名19岁哮喘学生在感冒后出现气短。她两次呼吸之间只能说几个字。呼吸频率30次/分，心率124次/分，PEF 160 L/min（她的最佳值为450 L/min），呼吸空气时$S_pO_2$ 93%。血气：$P_{aO_2}$ 9.1 kPa，$P_{aCO_2}$ 4.2 kPa。对严重程度分级。
::: solution
PEF占最佳值的百分比：$160/450 = 0.356$，约36%，处于33–50%区间。呼吸频率高于25、心率高于110以及不能说完整句子，都是**急性重度哮喘**的特征。没有危及生命的特征：PEF高于33%，$S_pO_2$高于92%，$P_{aO_2}$高于8 kPa，$P_{aCO_2}$偏低（正应如此）。她需要在医院立即治疗：受控给氧、雾化沙丁胺醇、全身性糖皮质激素并密切复评。如果她的PEF降到33%以下，或$P_{aCO_2}$升到正常范围，就已进入危及生命的类别。
:::
:::

## 慢阻肺 {#sec-copd}

::: definition 慢阻肺 {#def-copd}
**慢性阻塞性肺疾病**（慢阻肺）是一种异质性肺部疾病，其慢性呼吸道症状（气短、咳嗽、咳痰、急性加重）源于气道（支气管炎、细支气管炎）和/或肺泡（肺气肿）的异常，这些异常导致**持续性、通常进行性的气流阻塞**（GOLD定义）。实践中，诊断要求在有相应症状和危险因素的人中，**支气管舒张后FEV₁/FVC低于0.70**。
:::

慢阻肺是全球主要死因之一；世界卫生组织将其列为第四位，2021年约有350万人因此死亡。在英国，主要病因是吸烟。在全世界，烹饪和取暖时燃烧木柴、粪便和农作物秸秆产生的烟雾（生物质燃料）、职业粉尘和烟雾以及室外空气污染也很重要，这就是为什么在许多低收入和中等收入国家，从不吸烟的女性也常患慢阻肺。限制早年肺发育的因素，如早产、儿童期感染和母亲吸烟，也会增加风险，因为一个从未达到正常肺功能峰值的人，能损失的余地更小。

**α1-抗胰蛋白酶缺乏症**是一种遗传性病因。肝脏合成的α1-抗胰蛋白酶保护肺免受中性粒细胞弹性蛋白酶的损伤。Z等位基因纯合子（PiZZ）者水平极低，较早发生肺气肿，典型地累及下叶，吸烟者尤甚；部分人还发生肝病（[[genetics/mendelian-inheritance]]）。对于年轻发病或吸烟史很少的慢阻肺患者，建议进行检测。

### 出了什么问题

烟草烟雾和其他刺激物引起以中性粒细胞、巨噬细胞和CD8 T细胞为主的慢性炎症。随之出现三种过程，在不同人中比例各异：

- **慢性支气管炎**：黏液腺和杯状细胞肥大，引起咳嗽和咳痰。临床上定义为连续两年、每年至少三个月的大多数日子有咳痰。
- **小气道病变**：小气道的炎症、纤维化和丧失。这是气流阻塞的主要部位，其中大部分在出现症状之前就已发生。
- **肺气肿**：终末细支气管以远的气腔永久性扩大并伴有其壁的破坏。**小叶中央型**肺气肿是吸烟者的典型类型，累及上肺区的呼吸性细支气管；**全小叶型**肺气肿是α1-抗胰蛋白酶缺乏症的典型类型，累及整个腺泡，主要在下肺区。蛋白酶（来自中性粒细胞和巨噬细胞的弹性蛋白酶）与抗蛋白酶之间的失衡，加上氧化应激，驱动了这种破坏。

其力学后果已在[[respiratory/mechanics-breathing]]中阐述：弹性回缩力丧失和小气道狭窄限制呼气流量，导致气体陷闭和动态过度充气。肺泡壁丧失使气体转移下降。V/Q失调引起低氧血症；在晚期疾病中，可继而出现高碳酸血症、肺动脉高压和右心衰竭（**肺源性心脏病**）。慢阻肺也是一种全身性疾病，与肌肉萎缩、体重下降、骨质疏松、心血管疾病、焦虑和抑郁以及肺癌相关。

### 诊断与评估

任何35岁以上、有危险因素（通常为吸烟）并有劳力性气短、慢性咳嗽、经常咳痰、冬季频繁"支气管炎"或喘息的人，都应考虑慢阻肺。诊断需要**支气管舒张后肺量计**显示FEV₁/FVC低于0.70。NICE指南中的其他初始检查包括胸片（排除其他诊断，如肺癌）、全血细胞计数（贫血、红细胞增多症）和体重指数计算。吸烟史以**包年**量化：每天吸烟的包数（每包20支）乘以吸烟年数。

::: definition 慢阻肺严重程度评估 {#def-gold}
- **气流阻塞的严重程度**（GOLD分级，以支气管舒张后FEV₁占预计值的百分比计，适用于FEV₁/FVC < 0.70者）：GOLD 1轻度，≥80%；GOLD 2中度，50–79%；GOLD 3重度，30–49%；GOLD 4极重度，<30%。
- **症状**：改良MRC（mMRC）呼吸困难量表或慢阻肺评估测试（CAT）。
- 过去一年的**急性加重史**。
- GOLD将症状与急性加重结合，分为**A**组（症状少，风险低）、**B**组（症状多，风险低）和**E**组（两次或以上中度急性加重，或一次或以上导致住院的急性加重）。
:::

FEV₁本身与症状和结局的相关性较弱。气短、急性加重频率、运动能力和体重都能提供额外的预后信息。

::: example 他吸了多少烟？ {#ex-pack-years}
一名62岁男性16岁开始吸烟。40岁以前每天30支，此后每天15支。计算他的包年数。
::: solution
16岁到40岁共24年，每天30支：$24 \times 30/20 = 36$包年。

40岁到62岁共22年，每天15支：$22 \times 15/20 = 16.5$包年。

合计：$36 + 16.5 = 52.5$包年。这是重度暴露，使他处于慢阻肺、肺癌和心血管疾病的高风险之中；在英格兰，他符合肺癌筛查项目的条件（[[respiratory/lung-cancer-pleura]]）。现在戒烟仍是针对所有这些风险最有效的一项干预。
:::
:::

### 稳定期慢阻肺的管理

NICE指南NG115的原则按优先顺序为：

1. **戒烟。** 戒烟是唯一被证明能减缓肺功能下降的干预措施。行为支持结合药物治疗（尼古丁替代疗法、伐尼克兰或安非他酮），戒烟成功率约为单凭意志力的二到三倍（[[public-health/prevention-promotion]]）。
2. **接种疫苗**：每年接种流感疫苗，接种肺炎球菌疫苗，以及现行国家免疫规划推荐的其他呼吸道疫苗。
3. **肺康复**：适用于因气短而活动受限的人（在NICE指南中，通常为MRC 3级及以上）。这是一项至少六周、在指导下进行的运动训练和教育计划。它改善运动能力和生活质量的效果超过任何吸入药物，住院后进行还可减少再入院。
4. **自我管理与优化**：个体化的急性加重应对计划、正确的吸入技术、合并症的治疗、营养和心理支持。
5. **吸入治疗**，以缓解气短并减少急性加重。

::: definition 慢阻肺的吸入治疗 {#def-copd-drugs}
- **短效支气管舒张剂**（SABA或短效毒蕈碱受体拮抗剂SAMA），气短时按需使用。
- **LAMA + LABA**：用于气短仍限制活动或有急性加重、且没有哮喘特征的人。长效毒蕈碱受体拮抗剂（噻托溴铵、乌美溴铵、格隆溴铵、阿地溴铵）阻断气道平滑肌上的M3受体。
- **LABA + ICS**：在NICE指南中考虑用于**有哮喘特征或提示对糖皮质激素有反应的特征**者：既往哮喘或特应性诊断、血嗜酸性粒细胞计数较高、FEV₁随时间的显著变化（至少400 mL）或峰流量显著的昼夜变异（至少20%）。
- **三联疗法**（LAMA + LABA + ICS）：用于双联治疗下仍有急性加重或症状困扰者。
:::

GOLD（2025年报告）推荐LAMA + LABA作为B组和E组的常规初始治疗，在E组血嗜酸性粒细胞计数≥300个/µL时考虑三联治疗。血嗜酸性粒细胞可预测吸入糖皮质激素的获益。ICS会增加慢阻肺患者发生肺炎的风险，因此没有指征时不使用。

针对特定患者的其他治疗包括：**长期阿奇霉素**以减少急性加重（由专科启动，需先检查心电图QT间期延长并排除非结核分枝杆菌）、**罗氟司特**（磷酸二酯酶-4抑制剂）和黏液溶解剂。近年GOLD报告中的新选择包括用于急性加重频繁且嗜酸性粒细胞升高者的**度普利尤单抗**，以及吸入性磷酸二酯酶3/4抑制剂**恩司芬群**（ensifentrine）；可及性因国家而异。对于选定的重度肺气肿伴过度充气患者，**肺减容**（手术，或经支气管镜放置单向支气管内活瓣）可改善气短和运动能力，少数患者可选择肺移植。

**长期氧疗**（LTOT）可延长慢性低氧血症慢阻肺患者的生存。这是由1980年前后的两项试验证明的：英国医学研究理事会试验和美国夜间氧疗试验。在NICE指南中，LTOT用于不吸烟者：稳定期$P_{aO_2}$低于7.3 kPa，或低于8 kPa并伴继发性红细胞增多症、外周水肿或肺动脉高压，且两次测定至少间隔三周；每天至少使用15小时。氧不是治疗非低氧血症者气短的手段，而在氧气附近吸烟有严重的火灾风险，因此吸烟是不开具氧疗的有力理由。

::: example 稳定期慢阻肺的管理方案 {#ex-copd-stable}
一名67岁女性，吸烟史40包年，按自己的步速在平地行走即感气短（mMRC 2，CAT 18）。支气管舒张后FEV₁/FVC为0.55，FEV₁为预计值的58%。去年有一次在家治疗的急性加重。血嗜酸性粒细胞计数为0.1 × 10⁹/L，无哮喘病史。她仍每天吸烟10支。对她的慢阻肺进行分类并概述管理原则。
::: solution
比值低于0.70，证实存在阻塞。FEV₁ 58%为**GOLD 2级**（中度）。她症状明显（mMRC 2，CAT ≥10），仅有一次中度急性加重，因此属于**GOLD B组**。

优先事项：以行为支持和药物治疗帮助她戒烟；接种流感、肺炎球菌及其他推荐疫苗；因她受气短限制，转诊肺康复；制定自我管理计划；检查合并症（心血管疾病、焦虑、抑郁、骨质疏松）。吸入治疗：按需使用短效支气管舒张剂；由于她有气短、无哮喘特征且嗜酸性粒细胞计数低，使用**LAMA + LABA**联合制剂。目前没有使用ICS的指征。每次复诊都应检查吸入技术。
:::
:::

### 慢阻肺急性加重

::: definition 慢阻肺急性加重 {#def-aecopd}
**急性加重**是指症状（气短、咳嗽、痰量或脓性）持续恶化，超出日常的正常波动，急性起病，需要改变治疗。大多数由呼吸道病毒或细菌（流感嗜血杆菌、卡他莫拉菌、肺炎链球菌）或空气污染诱发；有些找不到原因。
:::

急性加重很重要：它们加速肺功能下降、降低生活质量，需要住院的急性加重在随后一年内死亡风险相当高。对于急性气短的慢阻肺患者，必须考虑其他原因，如肺炎、气胸、肺栓塞、心力衰竭和心律失常。

管理原则遵循NICE指南和当地方案：

- 增加短效支气管舒张剂的使用。
- **口服糖皮质激素**：英国实践中通常为泼尼松龙每天30 mg，共5天。它可缩短恢复时间，减少治疗失败。
- 痰液呈脓性或有感染征象时使用**抗生素**，按当地指南（NICE NG114）和既往痰培养结果选择。
- 在医院中，若患者有高碳酸性衰竭风险，给予**受控氧疗**，目标血氧饱和度88–92%，并查血气核实。
- **无创通气**（NIV）用于经最佳初始药物治疗后仍持续存在的急性高碳酸性呼吸衰竭：在BTS/ICS指南中，即pH低于7.35且$P_{aCO_2}$高于6.5 kPa。NIV可降低死亡率和插管需要（[[respiratory/respiratory-failure]]）。
- 发作之后：复核吸入治疗、吸入技术和吸烟情况，并提供肺康复（最好在出院后四周内开始）。

::: example 血气与酸中毒 {#ex-aecopd}
一名已知慢阻肺（GOLD 3）的71岁男性因气短加重和咳绿痰三天入院。经28%文丘里面罩吸氧，$S_pO_2$为90%。第一次血气：pH 7.30，$P_{aCO_2}$ 8.1 kPa，碳酸氢盐30 mmol/L。经雾化支气管舒张剂、泼尼松龙、抗生素和一小时受控氧疗后，复查血气为pH 7.28，$P_{aCO_2}$ 8.6 kPa。下一步是什么？
::: solution
他有**慢性基础上急性加重的高碳酸性呼吸性酸中毒**：碳酸氢盐升高提示慢性潴留，pH低显示有急性成分。他的血氧饱和度在目标范围（88–92%）内，因此问题不是氧引起的；酸中毒在最佳药物治疗下仍持续，并略有加重。pH低于7.35且$P_{aCO_2}$高于6.5 kPa，他符合**NIV**的标准。开始之前，要作出并记录NIV失败时的决定——考虑到他的意愿和病情，有创通气是否合适——并查看胸片排除气胸。开始NIV后1–2小时内复查血气；若未改善，按既定计划升级。
:::
:::

## 哮喘还是慢阻肺？ {#sec-distinguish}

区分两者很重要，因为治疗不同：ICS是哮喘治疗的基础，却可能对某些慢阻肺患者有害；而不含ICS的长效支气管舒张剂是慢阻肺的一线治疗，在哮喘中单用却很危险。

| 特征 | 哮喘 | 慢阻肺 |
|---|---|---|
| 起病年龄 | 常为儿童或青年期 | 通常在35岁以上 |
| 吸烟或暴露 | 不是必要条件 | 几乎总是存在 |
| 症状 | 可变、夜间、有诱因 | 持续、进行性 |
| 特应性 | 常见 | 不典型 |
| 发作间期肺功能 | 常正常 | 持续异常 |
| 支气管舒张反应大、FeNO升高 | 支持 | 少见 |
| 气体转移 | 通常正常 | 常降低（肺气肿） |

有些人兼具两者的特征，尤其是长期哮喘的吸烟者。这类患者的治疗方案中须包含吸入糖皮质激素，其预后通常比单患其中一种疾病者差。

::: quiz
一名无哮喘特征的慢阻肺患者，在按需使用短效支气管舒张剂后仍感气短。NICE和GOLD指南首先推荐哪种维持治疗？
- [ ] 单用吸入糖皮质激素
- [ ] 长效β₂受体激动剂加吸入糖皮质激素
- [x] 长效毒蕈碱受体拮抗剂加长效β₂受体激动剂
- [ ] 长期氧疗
::: solution
对于没有哮喘特征或糖皮质激素反应性特征的人，推荐双联长效支气管舒张（LAMA + LABA）（[[#def-copd-drugs]]）。慢阻肺中不单用ICS，LABA + ICS留给有哮喘特征者。氧疗用于慢性低氧血症，而不是单纯的气短。
:::
:::

::: history
伦敦医生亨利·海德·索尔特（Henry Hyde Salter）本人患有哮喘，他在1860年把哮喘描述为一种支气管肌肉的疾病，并认识到猫之类的诱因。查尔斯·弗莱彻（Charles Fletcher）和理查德·佩托（Richard Peto）随访伦敦的在职男性八年，于1977年描述了现以他们命名的模式：只有易感的吸烟者肺功能迅速丧失，而戒烟可使下降速度回到接近正常。1963年，卡尔–贝蒂尔·劳雷尔（Carl-Bertil Laurell）和斯滕·埃里克松（Sten Eriksson）从血清电泳上缺失的一条带发现了α1-抗胰蛋白酶缺乏症。美国夜间氧疗试验（1980年）和英国医学研究理事会试验（1981年）证明长期氧疗可延长低氧血症慢阻肺患者的生命。随后出现了国际策略：全球哮喘防治创议（GINA）于1993年启动，1995年发布首份报告；全球慢性阻塞性肺疾病创议（GOLD）于2001年发布。2014年，英国全国哮喘死亡审查表明许多死亡本可预防，最常见的原因是预防药物使用不足和过度依赖缓解药物。
:::

## 后续内容

诱发许多急性加重的感染见[[respiratory/respiratory-infections]]。急性加重导致高碳酸性呼吸衰竭时，氧疗和NIV的使用在[[respiratory/respiratory-failure]]中展开。慢阻肺和肺癌病因相同且常并存（[[respiratory/lung-cancer-pleura]]）。β₂受体激动剂和毒蕈碱受体拮抗剂的药理学见[[pharmacology/autonomic-drugs]]，哮喘的2型免疫学见[[immunology/hypersensitivity]]。

::: summary
- 哮喘：气道慢性炎症，症状可变、气流受限可变；常为2型（嗜酸性粒细胞、IgE、FeNO升高）。
- NG245（2024年）：成人先用嗜酸性粒细胞或FeNO（≥50 ppb）诊断，然后是支气管舒张试验（≥12%且≥200 mL），然后是PEF变异性（≥20%），然后是支气管激发试验。
- 哮喘治疗以ICS为基础。NG245让成人从按需ICS/福莫特罗（AIR）开始，然后是低剂量和中剂量MART。不再推荐单用SABA治疗。
- 急性重度哮喘：PEF 33–50%，呼吸频率≥25，心率≥110，不能说完整句子。$P_{aCO_2}$正常是危及生命的征象。
- 慢阻肺：由吸烟和其他暴露引起的持续性气流阻塞（支气管舒张后FEV₁/FVC < 0.70）；包括小气道病变、肺气肿和慢性支气管炎。
- 稳定期慢阻肺：戒烟、接种疫苗、肺康复、自我管理，然后LAMA + LABA；仅在有哮喘特征或嗜酸性粒细胞升高时用ICS；慢性低氧血症（$P_{aO_2}$ < 7.3 kPa，或伴并发症时 < 8 kPa）用LTOT。
- 急性加重：支气管舒张剂、泼尼松龙、感染时用抗生素、受控氧疗（88–92%），持续呼吸性酸中毒时用NIV。
:::

## 习题

::: exercise 包年 {level=1 check="30"}
一名55岁女性每天吸烟15支，共40年。她的吸烟量是多少包年？
::: solution
包年$= (15/20) \times 40 = 0.75 \times 40 = 30$。
:::
:::

::: exercise 峰流量百分比 {level=1 check="round(100*190/520)"}
一名哮喘发作男性的PEF为190 L/min，他的最佳值为520 L/min。这是其最佳值的百分之几（取最接近的整数）？仅按PEF属于哪个严重程度区间？
::: solution
$190/520 = 0.365$，取最接近的整数为37%。处于33–50%区间，符合**急性重度**哮喘；还必须评估其他特征（呼吸频率、脉搏、言语、血氧饱和度、血气）以发现危及生命的征象。
:::
:::

::: exercise GOLD分级 {level=1}
一名70岁男性支气管舒张后FEV₁/FVC为0.48，FEV₁为预计值的34%。他属于GOLD几级？选择治疗还需要哪些信息？
::: solution
比值低于0.70时FEV₁为预计值的30–49%，属**GOLD 3级（重度）**。选择治疗还需要他的症状负担（mMRC或CAT）、过去一年的急性加重史、血嗜酸性粒细胞计数、是否有哮喘特征、吸烟状况、血氧饱和度（以考虑是否评估LTOT）以及合并症。
:::
:::

::: exercise 为什么是福莫特罗？ {level=2}
解释为什么ICS/福莫特罗可在哮喘中作为缓解药物使用，而ICS/沙美特罗不能。
::: solution
福莫特罗既作用持久又起效迅速（数分钟内产生支气管舒张），因此能快速缓解症状；把复方吸入器作为缓解药物使用，还能在每次症状加重时给予一剂ICS，在炎症加重时加以治疗。沙美特罗起效慢，不能快速缓解，因此不作为缓解药物使用。
:::
:::

::: exercise 是否危及生命？ {level=2}
一名33岁急性哮喘男性呼吸频率18次/分，昏昏欲睡，听诊胸部呼吸音很弱，呼吸空气时$S_pO_2$ 91%，$P_{aCO_2}$ 5.6 kPa。一位低年资同事说他看上去"平静多了"，呼吸频率也正常。你如何回应？
::: solution
这是**危及生命的哮喘**，甚至可能是濒死哮喘。呼吸音微弱（沉默肺）、嗜睡（意识水平改变）、血氧饱和度低于92%和$P_{aCO_2}$正常，都是危及生命的特征。在这种情况下呼吸频率下降意味着衰竭而不是好转：他已无法过度通气，$P_{aCO_2}$正常就说明了这一点。他需要立即给予大剂量支气管舒张剂、氧、全身性糖皮质激素、静脉镁剂，并紧急请上级医师和重症监护团队评估，因为可能需要气管插管。
:::
:::

::: exercise LTOT标准 {level=2}
一名74岁慢阻肺女性五年前已戒烟，两次稳定期呼吸空气的动脉血气相隔四周：$P_{aO_2}$分别为7.6和7.7 kPa。她有踝部水肿，超声心动图提示肺动脉高压。她是否符合NICE长期氧疗标准？
::: solution
她的$P_{aO_2}$高于7.3 kPa，因此不符合第一条标准。但低于8 kPa，且有外周水肿和肺动脉高压的证据，因此符合第二条标准。她不吸烟。应为她提供每天至少15小时的LTOT，并评估家庭安全和她使用设备的能力。目的是减轻驱动其肺动脉高压的肺血管收缩，并改善生存。
:::
:::

::: exercise 哮喘还是慢阻肺？ {level=3}
一名58岁男性有25包年吸烟史，10年前已戒烟，现有气短和喘息。他儿时有"胸部毛病"。支气管舒张后FEV₁/FVC为0.63；吸入沙丁胺醇后FEV₁增加450 mL（22%）。FeNO为48 ppb，血嗜酸性粒细胞0.45 × 10⁹/L。TLCO正常。讨论可能的诊断及其对治疗的影响。
::: hint
逐一对照[[#sec-distinguish]]表中的每一项特征，考虑它指向哪一方。
:::
::: solution
慢阻肺的特征：年龄、相当的吸烟史和支气管舒张后持续阻塞（比值0.63）。哮喘的特征：儿童期呼吸道症状、很大的支气管舒张反应（450 mL，22%）、FeNO升高、血嗜酸性粒细胞升高，以及气体转移正常（使明显肺气肿的可能性小）。他很可能是**伴固定性气流阻塞的哮喘**，或许还有吸烟所致的慢阻肺成分。实际的后果是，他的治疗中必须包含**吸入糖皮质激素**。若存在哮喘，不含ICS的LABA是不安全的。按NICE慢阻肺的说法，他有明确的"哮喘特征"，因此LABA + ICS（或三联治疗）是合适的，转诊专科复核也合理。

::: exercise 选择氧疗目标 {level=3}
对下列每位患者，说明其住院时的目标血氧饱和度并给出理由：(a) 一名30岁急性重度哮喘女性；(b) 一名69岁慢阻肺男性，既往有高碳酸性呼吸衰竭，入院时碳酸氢盐升高；(c) 一名64岁慢阻肺女性，因肺炎入院，入院血气显示$P_{aCO_2}$ 4.6 kPa、碳酸氢盐正常。
::: solution
(a) **94–98%。** 她没有高碳酸性衰竭的风险；哮喘中的低氧血症很危险，应予纠正。

(b) **88–92%。** 他有记录在案的慢性高碳酸血症和既往高碳酸性衰竭，不受控的氧有加重其酸中毒的风险（[[respiratory/control-breathing-tests#thm-o2-co2]]）。

(c) 起初为**88–92%**，因为她患慢阻肺，属于风险人群；但她的血气没有显示高碳酸血症，碳酸氢盐正常，因此按照BTS指南，若后续血气证实她没有二氧化碳潴留，目标可调整为94–98%。目标是个体化并需复核的，而不是由诊断固定的。
