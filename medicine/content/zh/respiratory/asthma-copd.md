哮喘与慢性的阻塞的肺的疾病是从同一台肺活量计的两端被读出的这两个慢性的气道疾病：哮喘（变量的、炎症的、通常可逆的气流的受限带气道的过度反应，一个T2免疫与平滑肌的疾病）以及慢阻肺（进展的、大部分固定的受限，来自小气道的纤维化与实质的破坏（气肿），一个先天免疫与蛋白酶的疾病）[[respiratory/mechanics-breathing]]。

本章涵盖哮喘的免疫学与管理、慢阻肺的病理生理与它的长期的项目，以及急性的发作。

## 哮喘：T2的气道

::: definition 哮喘：机制与表型及诊断 {#def-asthma}
**机制：在一个易感的气道中，上皮与2型的免疫（辅助的T细胞2与先天2型的淋巴细胞与嗜酸性细胞，在白细胞介素5与4和13的细胞因子下）会产生炎症与平滑肌的反应性及黏液和重塑[[immunology/adaptive-responses]]、[[immunology/hypersensitivity]]；触发（变应原与病毒和刺激物与运动、冷空气及药物（阿司匹林疾病与β阻滞剂）[[pharmacology/adverse-reactions]]）会把发作点燃。表型：过敏性的（早发的与变应原的阳性及共病[[immunology/hypersensitivity]]）、非过敏性的（晚发的、嗜酸性的或中性的）、迟发的伴阿司匹林疾病与息肉[[paediatrics/newborn]]、以及重型/难治的[[#def-asthma-rx]]。诊断：症状变化的模式（波动与夜间和触发）加客观的可变的气流受限：呼气的流量对活量的比率与反应性（一个被吸入的β激动剂之后的上升）、峰值流量的日记与变异、以及在困难中的激发试验（高渗的盐/乙酰甲胆碱）[[respiratory/control-breathing-tests]]。支持：呼出的一氧化氮与血液/痰的嗜酸性细胞和变应原的测试；鉴别：慢阻肺与功能性的呼吸的障碍（[[#ex-asthma-dx]]）与支气管扩张和声带运动障碍[[respiratory/respiratory-infections]]、[[nervous-system/motor-systems]]。合并症与加重者：鼻炎与息肉和反流及肥胖、焦虑与吸入的技术和依从性[[geriatrics-palliative/polypharmacy]]、[[gastrointestinal/oesophagus-stomach]]。**
:::

::: definition 哮喘的管理：阶梯、缓解剂与生物制剂 {#def-asthma-rx}
**原则：症状与发作的这两个目标被控制，而风险被降低（药物与损失的天）；始终审查技术与依从性和触发，以及一个被书写的计划[[respiratory/respiratory-failure]]。药物：吸入的糖皮质激素（基础：风险的下降与死亡）加缓解（以前短效的β激动剂单独，如今被避免：含激素复合的缓解剂（长效的β激动剂的复合）会把严重的发作降低[[pharmacology/autonomic-drugs ]]）；阶梯（低到高剂量的复合、添加：长效毒蕈碱的拮抗剂与白三烯的调节剂，以及在选择的病例中口服长效的β激动剂）；急性的治疗（雾化/计量吸入器多个剂量的β激动剂与异丙托溴铵和全身激素，以及在重症中的镁[[emergency-critical-care/airway-ventilation]]、[[respiratory/mechanics-breathing]]）；以及口服的激素（短的疗程被使用，而它们的伤害被管理：骨与血糖和眼的[[endocrine/adrenal]]、[[musculoskeletal/bones-joints]]）。生物制剂（在专门的转诊中按表型）：抗免疫球蛋白E与抗白细胞介素5/4/13的路径与抗胸腺基质淋巴素的药，会减少发作与口服激素（选择者试验的证据）[[immunology/vaccines-immunotherapy]]、[[medical-ethics-law/justice-resources]]。其他：变应原的免疫治疗（鼻炎/哮喘的蜂毒）、支气管的热成型在选中的严重病例中、以及职业的暴露的移除[[public-health/environmental-occupational]]；疫苗与戒烟[[public-health/vaccination-programmes]]；以及在孕期中继续吸入的激素[[obstetrics-gynaecology/pregnancy-antenatal]]。**
:::

::: example 夜班护士的哮鸣 {#ex-asthma-dx}
一位42岁在三年前更换了清洁剂的症状后出现症状的人：夜间醒来与早晨的紧束，在周末会好转；肺活量显示比率0.68与一个第一秒的量上升15%；在空气中的饱和正常。
::: solution
**一个典型哮喘的诊断：波动的症状带夜间与触发，加上一个可逆的气流受限（一个被升高的反应性与一个显著的反应[[respiratory/control-breathing-tests]]、[[#def-asthma]]）。额外的检查：变应原的测试与血液的嗜酸性细胞（表型）与呼出的一氧化氮；职业的联系（这个时间表与周末的模式）需要高峰流量的日记在工作与假期的对照与转诊到职业的服务[[public-health/environmental-occupational]]——一个暴露被移除的诊断，如果它被说出来，会改变结局。管理：吸入的激素与一个被商定的缓解剂，一个被写的计划与复核（技术与依从性）；驾驶的规则与设备的审查；以及在反应不佳时重新考虑这个诊断[[respiratory/control-breathing-tests]]。**
:::
:::

## 慢阻肺：进展的气道

::: definition 慢阻肺：暴露、先天免疫与这两个表型 {#def-copd}
**暴露：烟草（大多数的病例）与生物的燃料和职业的粉尘（[[public-health/environmental-occupational]]、[[public-health/global-health]]）会在易感的个体中驱动炎症（先天免疫的细胞与蛋白酶：弹性蛋白酶对抗抗弹性蛋白酶的失衡[[immunology/innate-immunity]]、[[genetics/mendelian-inheritance]]的α1的缺乏[[#ex-a1at]]），产生两种重叠的图形：小的气道疾病（纤维化的狭窄与黏液：慢性支气管炎的表型）与实质的破坏（气肿），两者都会造成气流受限和气体的陷闭与交换的损害[[respiratory/mechanics-breathing]]、[[respiratory/gas-exchange]]。后果：急性的加重（病毒与细菌的）会加速下降并会标记结局；全身的伴随（肌肉与骨质疏松及心血管的疾病和焦虑/抑郁、肺癌的风险）会定义疾病[[respiratory/respiratory-infections]]、[[respiratory/lung-cancer-pleura]]、[[cardiovascular/coronary-artery-disease]]。诊断：暴露与症状（进展的呼吸困难与咳嗽/痰和加重）加上一个在使用支气管扩张剂后固定的比率（0.7以下；年龄调整避免过度诊断）[[respiratory/control-breathing-tests]]；检查会分层气体与弥散和影像（表型与 bullae[[respiratory/lung-cancer-pleura]]）；血液（红细胞增多与α1在早发的/非吸烟者中[[blood/anaemia ]]）。分期会结合症状（呼吸困难量表与加重的历史）与风险（[[public-health/screening]]的语言）。**
:::

::: example 包年的建造者 {#ex-copd-stable}
一位67岁（四十包年）在呼吸困难与跌倒和每年三次的加重，第一秒为预测的45%；仍在吸烟；饱和为93%；心脏的共病。
::: solution
**一个需要阶梯与风险的稳定期慢阻肺（[[#def-copd]]）：药物：长效的支气管扩张剂（毒蕈碱与β的复合），而在加重者中带三联（添加吸入的激素，带着肺炎与血糖的权衡[[pharmacology/autonomic-drugs]]、[[musculoskeletal/bones-joints]]）；急救（一个被写的加重的计划：激素与抗生素）；疫苗（呼吸道的与流感/肺炎球菌）[[immunology/vaccines-immunotherapy]]、[[public-health/vaccination-programmes]]；肺的康复（一个最强的干预在症状与住院上[[public-health/prevention-promotion ]]）；戒烟（最重要的，带着药物与支持[[public-health/prevention-promotion]]）；以及共病（心脏与骨与情绪[[cardiovascular/hypertension]]、[[psychiatry/mood-disorders]]）。氧气：不是在这个饱和度上（长期的氧气在静息的重度低氧中有死亡的数据[[#ex-aecopd]]）；以及在选中的病例中高级的干预（容量的减少与移植[[respiratory/lung-cancer-pleura]]）。随访：加重与症状与技术以及计划的复核[[geriatrics-palliative/polypharmacy]]。**
:::

::: example 气体与酸 {#ex-aecopd}
一位慢阻肺人在四天的咳嗽与痰后被带来；呼吸28；饱和85%而在空气中；气体：酸碱度7.19、二氧化碳10.5、氧气7.2、碳酸氢盐29。
::: solution
**一个急性加重呼吸衰竭的发作伴部分补偿呼吸性的酸中毒（一个高的二氧化碳与一个被上升的碳酸氢盐提示在急性之上的慢性的潴留）[[renal/acid-base-disorders]]、[[respiratory/respiratory-failure]]。包：可控的氧气（88%到92%以避免被增加的死腔与分流效应[[respiratory/respiratory-failure]]）、支气管扩张剂（短效的毒蕈碱与β）、全身激素（五天）、抗生素在脓性的痰中[[respiratory/respiratory-infections]]，以及早期的无创的通气：一个在医学的治疗后持续的酸碱度低于7.35伴高的二氧化碳是无创的通气的适应证——它会减少插管与死亡；复查气体在一个到两小时[[emergency-critical-care/airway-ventilation]]。陷阱：高流量的氧气会升高二氧化碳；镇静会移除驱动（[[respiratory/control-breathing-tests]]）；以及一个恶化或意识丧失或无法保护气道会转入插管的标准（带着对哮喘样的人的陷阱[[respiratory/control-breathing-tests]]）。后续的：吸入的阶梯与疫苗与康复以及一个被写的计划[[#def-copd]]。**
:::
:::

::: example 38岁的小叶基底型的改变 {#ex-a1at}
一位38岁的非吸烟的人在胸片上出现下叶的肺气肿，并有一个第一秒的显著下降与一个低的弥散；他的父亲在五十多岁开始着氧气。
::: solution
**α1-抗胰蛋白酶的缺乏直到被证明别的：一个在年轻时、在下叶、在没有吸烟暴露中的气肿，伴家族的线索，就是这个肝源性蛋白酶保护的基因的纯合子的状态[[genetics/mendelian-inheritance]]、[[respiratory/mechanics-breathing]]、[[gastrointestinal/liver-disease]]。检查：血清的水平与表型（在边缘中的功能性的测试）与家族的咨询和筛查[[medical-ethics-law/beginning-of-life]]。管理：支气管扩张剂与康复和疫苗与急性的加重的计划的常规（[[#ex-aecopd]]）；把吸烟（包括被接触的）移除；在缺乏患者替代的治疗（提升血浆的水平与静脉的方案，带输注的负担）[[blood/transfusion]]；肝/肺的移植在选中的病例中[[immunology/transplant-tumour-immunology]]；以及遗传的咨询与保险的告诫。陷阱：一个慢阻肺的标签会隐藏一个家族的诊断（兄弟姐妹与孩子），以及一个被误分类的哮喘会延迟正确的路径[[#def-asthma]]。**
:::

::: history
**古代短呼吸的名称与早期的学派；十九世纪中风死亡的病理解剖（收缩的肌肉与黏液堵塞的支气管）与痰的结晶的遗留；二十世纪过敏的计划（把哮喘与鼻炎及湿疹连接）；肺活量对流量的测量与流行病学的曲线（下降的轨迹与吸烟的因果的证明[[public-health/non-communicable-disease]]）；吸入的激素与β激动剂的时代，然后是复合与阶梯与书写的计划[[public-health/health-systems-economics]]；T2的免疫学把表型变成靶点，以及生物制剂和试验；以及急性发作照护的试验（全身激素与无创的通气会把插管与死亡减少）和氧气的规则（在潴留者中的可控的目标[[respiratory/respiratory-failure]]）。**
:::

## 通向何处

力学的基础在[[respiratory/mechanics-breathing]]；交换与气体在[[respiratory/gas-exchange]]；检查与图形在[[respiratory/control-breathing-tests]]；急性的衰竭与通气在[[respiratory/respiratory-failure]]与[[emergency-critical-care/airway-ventilation]]；感染在加重中在[[respiratory/respiratory-infections]]；血管与间质在[[respiratory/interstitial-vascular-disease]]；肿瘤与胸膜在[[respiratory/lung-cancer-pleura]]；药物在[[pharmacology/autonomic-drugs]]；以及预防与暴露在[[public-health/prevention-promotion]]与[[public-health/environmental-occupational]]。

::: summary
- 哮喘就是T2炎症与平滑肌的一个变量的、通常可逆的气道疾病：用症状与客观的可变的气流受限来诊断，并按吸入激素与缓解的复合被阶梯化治疗，生物制剂会改变重型。
- 慢阻肺就是暴露驱动的、小的气道的纤维化与实质的破坏：一个固定的气流受限伴气体的陷闭与交换损害，并带有加重的急性。
- 轨迹会重要：正常的老化会把第一秒缓慢地下降，而在易感的暴露上会更快——这就是为什么戒烟与暴露的移除是疾病修饰的干预。
- 发作被支气管扩张剂与激素和抗生素（在脓性的痰中）与可控的氧气治疗；在慢阻肺酸中毒性的高碳酸中早期无创的通气会减少插管与死亡。
- 氧气在重度静息的低氧中会挽救生命，而在潴留者中过高会给害：规则就是目标在急性的（88-92%）与长期的标准。
:::

## 练习

::: exercise 判断这些可逆性 {level=1}
前：第一秒2.1，活量3.4；在使用支气管扩张剂后：第一秒2.4，活量3.5。计算改变并说明它是否符合标准以及它证明与不证明什么。
::: solution
**绝对的变化为300毫升，而百分比约14%：同时满足标准（上升超过200毫升并且超过12%），所以显著的可逆[[respiratory/control-breathing-tests]]、[[#def-asthma]]。它证明：气流受限会改变（哮喘在支持之中）。它不证明：哮喘的唯一（慢阻肺与哮喘-慢阻肺的重叠也会有反应[[#def-copd]]），也不排除（一个阴性的反应不会排除一个缓解期的哮喘——所以要检查变异与激发）。实践：与治疗前后一起报告，并避免在激素的试验后把试验中断治疗[[clinical-skills/clinical-reasoning]]。**
:::

**局部：念珠病与嘶哑及咳嗽（spacer与漱口和吐掉的技术会减少它们[[pharmacology/autonomic-drugs ]]）；全身（在高的剂量/长期的）：骨（[[musculoskeletal/bones-joints]]）、眼的（白内障与青光眼[[nervous-system/sensory-systems]]）、皮肤薄与瘀斑、在儿童中的生长（被监测）以及肾上腺的抑制（[[endocrine/adrenal ]]）。需要额外的情形：在手术中压力的剂量在长期的抑制中[[surgery/perioperative-care]]、在疾病中计划的升高、以及在口服激素被撤回时的谨慎的减 Slow（肾上腺的恢复）[[endocrine/adrenal]]。缓解：最低有效的剂量与复核与疫苗/骨的保护[[public-health/vaccination-programmes]]。**

::: exercise 开生物制剂 {level=2}
把每一个重型哮喘的患者与它的生物制剂的类别与它的生物标记物匹配：(a) 19岁，对草的皮试阳性，免疫球蛋白E为240，在高的激素复合上有发作；(b) 45岁伴嗜酸性细胞1.2与晚发的疾病；(c) 一个有共病的哮喘……
::: solution
**（a）抗免疫球蛋白E（过敏性的表型：阳性的变应原与一个在范围内的免疫球蛋白E）[[immunology/hypersensitivity]]；（b）抗白细胞介素5/受体的药（嗜酸性的高的表型，晚发的疾病）或抗白细胞介素4/13（在特应性的/激素依赖的中带数字）[[immunology/adaptive-responses]]；（c）取决于这个组合（抗白细胞介素4/13会覆盖特应性皮炎的共病；抗胸腺基质的会覆盖一个低的T2的图形[[#def-asthma ]]）。实践的规则：专门的资格（阶梯被完成与技术和依从性和口服激素被撤回）、生物标记物在开始时（这些会指导选择）与结果（发作与口服激素的减少）；以及转诊的公平与支付[[medical-ethics-law/justice-resources]]、[[public-health/health-systems-economics]]。**

陈述长期氧气的标准与死亡的数据，以及急性发作目标范围的规则与它的机制，调和氧气会拯救与会伤害。
::: solution
**会拯救：在静息重度的低氧中（在稳定的患者中，在两次测量中动脉的氧气或饱和低于阈值），每天至少15小时会改善在选中人群中的生存；在中度的以及在运动/夜间的中，数据更弱[[#def-copd]]。会伤害：在急性的发作中高流量的氧气会升高二氧化碳（被解除的低氧的血管收缩与死腔与波尔的效应[[respiratory/gas-exchange]]、[[respiratory/control-breathing-tests]]），以及在有风险者中自由流动的氧气与死亡相关——所以目标88%到92%并滴定与气体[[#ex-aecopd]]、[[respiratory/respiratory-failure]]。调和：氧气是一个药物，有剂量与适应证；会拯救的是慢的、重的低氧，而会伤害的是在一个被损害的环中的过度治疗[[respiratory/control-breathing-tests]]。**
:::
:::

::: exercise 读无创通气的气体 {level=2}
为每一个发作的气体决定：开始无创的通气；尝试药物的治疗并重新检查气体；或插管——(a) 酸碱度7.36、二氧化碳8.6；(b) 在雾化的治疗与28%的氧气四十分钟后酸碱度7.22、二氧化碳11.2；(c) 酸碱度7.08、昏迷的评分9、呕吐、面部外伤的病史。
::: solution
**（a）一个在代偿中慢性的高碳酸，没有酸血症：继续药物治疗并复查，而不是常规机器（酸血症是适应证[[respiratory/respiratory-failure]]、[[emergency-critical-care/airway-ventilation ]]）。（b）在最初的治疗后持续酸中毒的呼吸衰竭：现在就启动无创的通气（这些会减少插管与死亡）并重复气体[[#ex-aecopd]]。（c）插管：一个严重的酸血症伴意识的损害与呕吐（吸入的风险）和面部的外伤（面罩的禁忌）——带着对潴留者的谨慎的氧气目标与一个专家的计划[[emergency-critical-care/airway-ventilation]]。共同的规则：气体、临床图形与设备的适合性一起决定。**
:::

::: exercise 不是哮喘的哮鸣 {level=2}
给出五个哮喘的模仿者与把每一个与哮喘分开的鉴别者。
::: solution
**慢阻肺（一个吸烟的暴露与固定的气流及一个年龄；影像[[#def-copd ]]）；功能性的呼吸的障碍（叹息与四肢的麻刺及一个正常的检查与激发试验阴性[[respiratory/control-breathing-tests]]）；声带的运动障碍（在吸气上的喘鸣与流量的环和喉的评估[[nervous-system/motor-systems]]）；心衰（端坐呼吸与钠尿肽和胸片[[cardiovascular/heart-failure]]）；支气管扩张/异物/肿瘤（痰与局部发现和CT[[respiratory/respiratory-infections]]、[[respiratory/lung-cancer-pleura]]）；以及变应性的支气管肺的曲霉病（浸润与曲霉的血清学[[immunology/hypersensitivity]]、[[microbiology/fungi-parasites]]）。鉴别线索：没有对吸入激素的反应与一个正常的在发作之间的检查、异常胸片、气体、一个非阻塞的图形[[respiratory/control-breathing-tests]]。**
:::

::: exercise 下降的门诊 {level=2}
一位55岁被诊断为在三联吸入上慢阻肺的人，今年在依从性下已有三次发作，仍每日吸10支，不参加康复，并且有一个会放弃的持续正压的睡眠呼吸暂停：写下接下来的六个月。
::: solution
**这是一个干预的失败，而不是药物的：（1）戒烟（最高的回报：药物与行为[[public-health/prevention-promotion ]]）；（2）肺的康复（如果没有它，一个住院减少的获益不存在[[public-health/prevention-promotion ]]）；（3）复核技术与依从性，以及吸入器是否合适（[[pharmacology/autonomic-drugs]]）；（4）一个被写的加重的计划和疫苗[[immunology/vaccines-immunotherapy]]；（5）持续正压的重新参与（界面的调整与依从性的下载或替代的设备[[respiratory/control-breathing-tests]]）；（6）共病与风险的筛查（心脏与骨和情绪与肺癌[[cardiovascular/hypertension]]、[[musculoskeletal/bones-joints]]、[[psychiatry/mood-disorders]]、[[respiratory/lung-cancer-pleura]]）；（7）肺减容/移植的考虑如果症状持续[[respiratory/lung-cancer-pleura]]；（8）被安排的随访（症状与发作）以及一个审查的诊断（这个哮喘的成分？支气管扩张？[[#def-asthma]]）。**
:::

::: exercise 设计气道服务 {level=3}
为一个哮喘与慢阻肺负担高的地区设计一个从社区到重症的服务：诊断的路径、药理学公平的架构、发作与急的照护的系统、康复，以及人口的健康的轴。
::: solution
**诊断：一个肺活量测定的标准（被训练的操作与参考的方程）在所有的风险者中，以及避免标签的复核；在困难中的激发/变异与转诊[[respiratory/control-breathing-tests]]。药物：一个被资助的阶梯（复合与缓解的规则，避开单独短效的β激动剂），吸入器的训练与技术的审查，以及生物制剂中心的访问（公平的门槛[[medical-ethics-law/justice-resources]]、[[pharmacology/autonomic-drugs ]]）。发作：一个当日/急性发作的路径（氧气目标与药物与无创的通气在酸中毒中，以及升级的标准[[#ex-aecopd]]、[[emergency-critical-care/airway-ventilation]]）与出院后的随访（一个复核与一个被写的计划，减少复发[[clinical-skills/records-handover ]]）。康复：一个可达的项目与维持的策略[[public-health/prevention-promotion]]。人口的轴：戒烟与干净的燃料与职业的暴露和疫苗[[public-health/environmental-occupational]]、[[public-health/vaccination-programmes]]；学校的与工作的计划[[paediatrics/immunisation]]；以及审计（急性发作与住院和死亡与这些不平等的差距[[public-health/determinants-inequalities]]）。**
