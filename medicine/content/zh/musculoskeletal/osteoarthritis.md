骨关节炎是关节对“一个没人礼貌地问过的问题”的回答：**当软骨与骨及滑膜与肌肉及神经系统，都在负荷之下一起变老时，会发生什么？**那个旧的“磨损”的标签错了两次——它暗示了不可避免，也暗示了只有软骨。现代的实践把骨关节炎当作一种“全关节的疾病”来对待：它的疼痛的发起者可以住在骨里、滑膜里、滑囊里、肌肉里或脊髓里；而它那架处理的梯子的最初几级不是药、而且永远不会是药。

本章涵盖关节为什么退变、骨关节炎如何表现与如何诊断、以及从教育与运动到置换及其“余波”的那座处理的金字塔。

## 关节为什么会退变

::: definition 衰竭关节的病理生理 {#def-pathophysiology}
**先说软骨（透明软骨是无血管的、无神经的、“抗压黏弹的轴承”，其中软骨细胞 被安置在“被锁住水的蛋白聚糖的凝胶”里、被II型胶原的笼子约束着，而软骨细胞通过整合素与初级纤毛感受负荷、并维持着一套“以地质年代计的时间在更新”的基质——失效的模式是从“合成代谢的维持”转向“分解代谢的、降解基质的酶的优势”：聚集蛋白聚糖被剪切、胶原的网被破坏、出现纤维化，而有限的自我修复让缺损无人填补——[[cell-biochemistry/proteins-enzymes]]、负荷的那几行见[[physiology/muscle]]）；全关节的演员表（软骨下的骨——硬化与囊肿、“对改变的负荷的重建的反应”、以及“骨髓的病变与疼痛”的关联；滑膜——“由机械驱动低级别的炎症”，伴积液与那次急性发作的生物学；关节囊与韧带——松弛与僵硬同时存在；半月板与盂唇——“在最小的扭转之上的退变的裂隙与桶柄样的撕裂”、以及那堂被艰难地学会的“膝关节镜的课”；关节周围的滑囊与肌腱——被归咎于软骨的“关节周围”的疼痛的发起者；以及肌肉——股四头肌与髋的外展的无力既是原因也是结果、并带着那个“由疼痛引起反射性的萎缩”要去打破——[[physiology/muscle]]、[[musculoskeletal/bones-joints]]）；以及疼痛的发起者之问题（来自骨与滑膜及滑囊的伤害性的疼痛、牵涉关节囊的模式、以及那种“解释了为什么X线的严重度与疼痛常常不一致”的伤害性的可塑性的放大——与慢性疼痛的重叠见[[musculoskeletal/back-pain]]与[[psychiatry/anxiety-disorders]]）。病因——原发对继发（年龄与多基因的遗传与女性及绝经及族裔的负荷的模式；肥胖作为“可修改的全身性的机械炎症性的暴露”——脂肪的机械传导与脂肪因子、以及“体重对膝的负荷”的剂量反应——[[gastrointestinal/clinical-nutrition]]、[[endocrine/diabetes]]；关节形态的失败——髋的发育性的发育不良、股骨髋臼的撞击、以及半月板切除或骨折之后的力线不良——[[paediatrics/congenital-genetic]]、[[musculoskeletal/fractures]]；韧带丢失的韧带损伤之后的“创伤后的骨关节炎”、以及年轻的膝盖与“转体的运动”之间那场漫长的争论——[[physiology/muscle]]；以及内分泌与骨骼的疾病——血色病与焦磷酸钙及甲状旁腺——见[[musculoskeletal/inflammatory-arthritis]]与[[endocrine/bone-calcium]]。）**
:::

## 识别它

::: definition 临床的特征与诊断 {#def-diagnosis}
**那个能“说出关节名字”的病史与活动相关的疼痛、在一整天中加重、上下楼梯与下蹲与起身与转移时明显；短暂的“起步的僵硬”晨起少于30分钟、休息后的“启动”的发僵；夜间的疼痛作为“急性发作或进展的标志、而不是常规”；那个“打软与绞锁”（带着游离体或半月板的含义、以及晚期的关节的“僵硬与畸形”的轨迹；以及真正会改变转诊的功能之问——楼梯与购物与洗澡与驾驶及工作与睡眠——[[clinical-skills/history-taking]]、[[musculoskeletal/bones-joints]]）；检查逐关节的算法——手的骨的增大与捻发音及“关节囊型的被动活动丧失”、以及赫伯登与布夏尔的结节、以及“远端指间与腕掌及第一跖趾为先”的分布；髋的“腹股沟的痛与内旋的丧失”、以及那个“膝的牵涉的陷阱”；膝的内翻或外翻的力线不良与积液及股四头肌的消瘦、以及“内侧关节线的压痛对髌股的挤压的体征”；以及足的“第一跖趾的僵硬（拇僵症与中跗——[[clinical-skills/physical-examination]]、[[anatomy/lower-limb]]、[[anatomy/back-upper-limb]]）；以及影像与化验——“通常没有必要”的纪律当平片会改变处理时才拍、带着那四联的经典——关节间隙的丢失与软骨下的硬化及囊肿及骨赘——以及那句诚实的免责声明：“影像的严重度与症状的相关很差”、这就是为什么在一份不寻常的表现里影像不能诊断临床的骨关节炎；用于排除模仿者的化验——当“真的怀疑炎症的疾病”时才查炎症的标志、以及尿酸与钙与甲状腺作为背景——[[clinical-skills/laboratory-tests]]；磁共振真正的适应证——诊断的两难、“年轻的、化脓的或绞锁的膝”这一疑问、疑似的功能不全的骨折与缺血性坏死、以及那台“它不应该成为的试验的诊室”——[[clinical-skills/medical-imaging]]、应力的那几行见[[musculoskeletal/fractures]]；以及当诊断真的不确定时、用于积液与“手的模式”的超声[[musculoskeletal/bones-joints]]。**
:::

::: example 并不“只是老了”的膝 {#ex-mimic}
一名58岁被说成“双膝骨关节炎”已3年、报告晨僵75分钟、大多数清晨有明显的大量积液、C反应蛋白34、并疲劳；既往的X线“有一点间隙变窄”。
::: solution
**这是一例“以骨关节炎面目出现的炎症”、而揭穿它的是C反应蛋白与僵硬的时间（[[#def-diagnosis]]、[[musculoskeletal/inflammatory-arthritis]]）：重构——长时间的晨僵加积液加全身性炎症加C反应蛋白升高，“在被排除之前就是滑膜炎”、而骨关节炎与类风湿在同一位60岁的膝盖里常常共存（[[immunology/autoimmunity]]）；检查——抗环瓜肽抗体与类风湿因子及血沉与C反应蛋白、以及为滑膜炎与侵蚀做超声、以及对“手与足的关节的清点”、以及任何穿刺的液体都要查晶体（[[clinical-skills/laboratory-tests]]、[[musculoskeletal/inflammatory-arthritis]]）；那个真正重要处理的岔路——为类风湿做“改善病情的药与治疗达标”的转诊、对一条骨关节炎的路径、以及那句“不要反复把激素打进一个尚未诊断的肿的关节”的告诫（[[musculoskeletal/inflammatory-arthritis]]、[[pharmacology/dosing-principles]]）；安全网——那种“比X线所预期的更糟”的反应，每次都该触发一次“模仿者的再清扫”：晶体与夏科及缺血性坏死、功能不全的骨折、以及关节附近的恶性——[[#def-pathophysiology]]、[[musculoskeletal/fractures]]、[[pathology/cancer-diagnosis]]；以及“转向”的沟通——“检查与化验改变了这个标签、这对你意味着改变”的诚实、以及写在纸上修订后的计划——[[clinical-skills/communication]]、[[clinical-skills/records-handover]]。**
:::
:::

::: example 那位膝片正常而病在髋的患者 {#ex-hip-referral}
一名71岁因右侧膝痛4个月就诊、除了“倾向于积液”之外膝的检查几乎无发现、膝的全范围的活动度伴疼痛；髋没有被检查，因为“痛的是膝”；膝的X线显示轻度的骨关节炎；她现在拄拐行走、而疼痛会把她痛醒。
::: solution
**在髋被检查之前，它都是被牵涉的髋的病变（[[#def-diagnosis]]）：闭孔神经共享的皮区解释了为什么髋的病变会“在腹股沟、大腿与膝上宣布自己”、而“不检查症状之上的那个关节”是肌肉骨骼医学最古老的陷阱之一——检查髋、找内旋的丧失与腹股沟的痛、以及明显的肢体长度与外展的情况（[[clinical-skills/physical-examination]]、[[anatomy/lower-limb]]）；检查——髋的正位与蛙式位、以及当平片正常而疼痛与夜间症状持续时保持低的磁共振阈值——缺血性坏死、功能不全的骨折、炎症的髋、以及“在超声引导下把关节内的注射当作一项诊断的试验”（[[clinical-skills/medical-imaging]]、[[musculoskeletal/fractures]]、缺血性坏死那一行见[[#def-pathophysiology]]）；正确标签带来的处理后果——核心的与外展的训练与负荷的策略、以及为“伴她真实症状晚期的髋骨关节炎”尽早讨论关节置换、对比“对膝下手却毫无作用”的治疗（[[#def-management-pyramid]]、[[surgery/orthopaedics]]）；以及可以推广的一般化的教训——髋的疾病可以表现为大腿或膝的痛、腰的疾病可以表现为髋或膝的痛、而当脊柱与髋都不正常时，“由诊断性麻醉的阻滞来转诊”是一位高年资的决定、不是一张磁共振的申请——[[musculoskeletal/back-pain]]。**
:::
:::

::: example 那位44岁的髋 {#ex-young-hip}
一名44岁的健身教练因“髋紧”的康复没有效果、在18个月里右侧腹股沟疼痛；深蹲与久坐时痛、“在内旋的终末处有个卡住”；骨盆平片显示浅的髋臼、以及股骨头颈交界处突出的“凸轮”；关节间隙仍然保留。
::: solution
**这是“关节形态的失败、正在发生的骨关节炎”，不是过度使用的肌腱病（[[#def-pathophysiology]]）：发育不良与凸轮及“钳形”的形态，通过把接触的压力集中起来而缩短了软骨与盂唇的寿命、而那个“保住原生髋”的决定窗口恰恰就是这个“关节间隙仍保留”的时刻——[[#def-diagnosis]]、[[surgery/orthopaedics]]；检查——承重骨盆的投照与站立位的髋的影像及“中心边缘角与α角”的测量、以及在考虑手术时的“静脉造影或磁共振的造影”、以及那杯“脊柱与髋的活动度的混合”与模仿者的清扫——跑步者的应力骨折与缺血性坏死及炎症的髋及“弹响的髋”及被牵涉的腰部（[[clinical-skills/medical-imaging]]、应力的那几行见[[musculoskeletal/fractures]]、[[musculoskeletal/back-pain]]）；处理的分支——针对活动度与肌力的物理治疗并配合“回避负荷的教练”、对“骨盆周围的或股骨的截骨”、对“关节镜凸轮的切除与盂唇的修补”，带着它们各自证据的分级、以及“当它们在发育不良而不稳定的髋上被施行时”的失败模式（[[#def-surgery-below]]、[[epidemiology-ebm/observational-studies]]）；以及那份“长远眼光”的咨询——活动的调整而不是停止、场“未来做关节置换的概率”的谈话不要渲染灾难、对侧髋的检查、以及“对子女与家族的知晓”的分寸、以及那份与“既懂保髋又懂凸轮的手术误行”的人共同商定重返教学的计划——[[clinical-skills/communication]]、[[physiology/muscle]]。**
:::

## 处理的金字塔

::: definition 处理：运动、体重、药物、手术 {#def-management-pyramid}
**人人共有的基础（教育与期望——“骨关节炎不只是侵蚀；疼痛在每一个阶段都可治”这个框架、以及诚实的自然史、以及自我管理的技能——目标的设定与配速及急性发作的处理、以及那些可以放量的数字化的项目——[[clinical-skills/communication]]、[[public-health/prevention-promotion]]）；作为“改变疾病的干预”的运动（渐进的肌力训练、包括股四头肌与髋的外展；按关节与身体区域选择的“有氧与水中与太极与自行车”的选项；那条剂量的规则——“运动中疼、但次日就平息是安全的、尖锐而持续的加重是一个调整负荷的信号”；关节置换前的预康复、带着它与结局的关联的证据；以及把“乐趣与社交的背景及可步行的地方”工程化以形成长期的依从——[[physiology/muscle]]、[[public-health/prevention-promotion]]、负荷的逻辑见[[musculoskeletal/back-pain]]）；体重（体重下降对膝的负荷与症状的剂量反应——即便是适度而持续的下降也能带来“有临床意义的改善”、以及它与“手术转诊的阈值”的纠缠、以及那份“不带污名”的体重谈话的交付——[[gastrointestinal/clinical-nutrition]]、[[#def-surgery-below]]）；辅具与支具与鞋根“拿在对侧的手里”的手杖的教学要点、用于内侧间室的膝骨关节炎的鞋垫与卸载的支具（诚实的效应量、用于拇僵症的“第一跖趾的硬底鞋垫”、以及那份“与跌倒重叠”的居家与交通的职业治疗的评估——[[geriatrics-palliative/falls]]）；药物外用非甾的用于表浅的关节优先省下胃与肾、口服非甾的要做“心血管与肾与胃肠与虚弱与多重用药的风险”的账、并算上胃的保护、以及乙酰氨基酚被降级为“中度镇痛的辅助”、度洛西汀在“伴中枢特征的慢性疼痛”里的那一小块地、以及曲马多只留给短程连同跌倒与意识模糊及低钠及癫痫及5羟色胺与药物的相互作用那份清单——[[pharmacology/adverse-reactions]]、慢性疼痛的辅助那一行见[[psychiatry/mood-disorders]]、多重用药见[[geriatrics-palliative/polypharmacy]]；关节内的激素用于短期的急性发作的缓解（带着“最大的间隔”的诚实、注射后血糖的小幅波动、以及“罕见化脓的关节”的安全网、以及玻璃酸那“在对照试验中塌方的效应量”——见下面的图形。）**
:::

::: definition 外科：何时、哪一种、以及之后 {#def-surgery-below}
**把关节置换的适应证当作一场明确的谈话（终末期的关节加显著的症状加“保守的选项已经失败”加知情的期望——触发的是疼痛与功能、不是X线；以及“把总体上是更好的手术拖延掉的”“太年轻、太胖、体能太差”的迷思“；以及现实的数字：疼痛缓解的幅度与”达到最大获益的时机”与再手术的时钟、以及15年的生存率——[[surgery/orthopaedics]]）；逐关节的菜单髋用全髋带着入路与摩擦界面的选择及“脱位预防的文化”、单髁置换那一小块地（带着进展与翻修的取舍、膝置换的“髌股与前交叉的状态”的规划与康复的预测的设定、肩与踝与肘、以及足部“融合对置换”的争论；在“年轻而单一的间室且力线不良”的患者中做截骨、在“稳定胜过活动”处做关节融合、以及在感染之后做“切除的成形”作为挽救——[[surgery/orthopaedics]]）；以及围手术期的系统（预康复与优化——贫血与铁与糖化的血红蛋白与吸烟与营养及用药的复查、以及“麻醉的适格”的图景——[[surgery/perioperative-care]]、[[blood/anaemia]]、[[endocrine/diabetes-complications]]、[[gastrointestinal/clinical-nutrition]]；静脉血栓的预防与早期活动、以及对膀胱与肠道及谵妄的预判——[[blood/thrombosis-anticoagulation]]、[[geriatrics-palliative/delirium-dementia-care]]；加速康复的路径与“当日出院的试点”的证据、以及“居家优先与康复的去处”这个公平的问题——[[public-health/health-systems-economics]]、[[public-health/determinants-inequalities]]；以及那条长长的尾巴——“以持续的疼痛或窦道或松动为表现的假体周围的关节的感染”、以及“来自牙科与皮肤及泌尿的道源的急性的血行播散”这场辩论、无菌的松动与骨溶解、以及金属与钴铬及磁共振的伪影的问题、脱位与假体周围的骨折、以及“预防性的抗生素与牙科指导”片 会移动的证据的沙地——[[infectious-diseases/healthcare-infections]]、[[microbiology/bacteria]]、[[musculoskeletal/fractures]]。）**
:::

::: example 那次“等待名单”的谈判 {#ex-waitlist}
一名64岁患严重的“三个间室的膝骨关节炎”、体质指数38、糖化的血红蛋白72、每天吸10支烟、被告知“你得先减重并戒烟，我们才能给你预约”；她现在无法爬上卧室、并已停止工作。
::: solution
**一场“体重与吸烟的壁垒的文化”与“风险获益的现实”的相遇（[[#def-surgery-below]]、[[#def-management-pyramid]]）：诚实的证据——肥胖与吸烟会提高并发症的比率、但“在极端之外”并不抹去获益、而“不经个体化风险获益的分析也不提供支持的项目”的一刀切的阈值政策，是“给手术定一个很远的日期”、不是医学（[[public-health/determinants-inequalities]]、[[medical-ethics-law/justice-resources]]）；重构——一个“带日期与指标及支持的、有时限优化的项目”预康复的运动与营养、以及戒烟的药物、以及铁与血糖的优化（与糖尿病的团队、并配一场共同的“风险的测算”的谈话，它以一次决定、而不是以一道悬崖告终——[[surgery/perioperative-care]]、[[gastrointestinal/clinical-nutrition]]、[[endocrine/diabetes-complications]]、[[public-health/prevention-promotion]]）；份必须是真实的过渡期的“减负”的计划，因为等待是真实存在的——急性发作的计划与注射的选项与活动的辅具与“职业治疗的居家评估”、以及工作与福利的导航、以及心理健康的检查——[[#def-management-pyramid]]、[[geriatrics-palliative/falls]]、[[psychiatry/mood-disorders]]、[[public-health/health-systems-economics]]；记录与倡导——“个体化风险的评估”要写在纸上、以及当“阈值”其实是“伪装成临床标准的 配额限制”时的“第二意见与投诉的路径”（[[clinical-skills/records-handover]]、[[medical-ethics-law/professionalism-regulation]]）；以及结局的问责——“实施之后审计：谁的手术因为哪一个数字的标准被延迟了”——份“存在就会改变政策的审计”（审计的环路见[[public-health/health-systems-economics]]、[[epidemiology-ebm/measuring-disease]]）。**

## 通向何处

关节的生物学与检查在[[musculoskeletal/bones-joints]]；炎症的鉴别在[[musculoskeletal/inflammatory-arthritis]]；创伤后的骨关节炎在[[musculoskeletal/fractures]]；外科的技术与并发症在[[surgery/orthopaedics]]；围手术期的优化在[[surgery/perioperative-care]]；体重的干预在[[gastrointestinal/clinical-nutrition]]；慢性疼痛的机制在[[musculoskeletal/back-pain]]。

::: history
**骨关节炎那场漫长的“从年龄的侵蚀降级为全关节的疾病”：希波克拉底那句“关节被劳作所摧毁”的框架、以及十八世纪把炎症的关节与退变的关节分开的“白色的肿”的描述；亨特对软骨的关注、以及十九世纪“解剖室的年代”里对“关节器质的虚弱”的分类；流行病学的转向——富兰明汉与费尔兹及钦福德的肩与膝及手的队列、使骨关节炎成为一种可测量的人群的疾病、并带来肥胖那“铁证般的风险系数”——[[epidemiology-ebm/observational-studies]]；全髋置换的革命与查恩利的低摩擦的关节成形带水泥与摩擦界面的配对及生存率的曲线，可以说是二十世纪“每一质量调整的生命年”上最有价值的一台手术——[[surgery/orthopaedics]]、[[public-health/health-systems-economics]]；软骨修复的热情与它的边界——微骨折与“基质诱导软骨的生成”及骨软骨的移植物，证明了“局灶缺损的生物学不同于弥散的骨关节炎的生物学”；关节镜的清理与半月板切除的对照安慰剂的试验与它们那堂“外科的谦逊”的课——[[epidemiology-ebm/randomised-trials]]；以及运动医学与康复的证据从“轻轻活动”成熟为“有剂量的肌力与有氧的处方、并配上依从的工程学”——[[physiology/muscle]]、[[public-health/prevention-promotion]]。**
:::

::: exercise 为那位虚弱的髋做咨询 {level=2}
一名79岁的寡妇患严重的髋骨关节炎、射血分数降低的心力衰竭、虚弱、住在护理院里，她问：“我是不是太老了、做不了髋的手术？”请组织这场谈话。
::: solution
**四根柱子（[[#def-surgery-below]]、[[surgery/perioperative-care]]）：获益——为严重的骨关节炎做髋的置换通常能把“困在家里的疼痛”变成“能活动的舒适”、即便在更年长与更虚弱的患者身上也有真实的生活质量的获益、而老年科的共同管理与麻醉的规划正在改善风险的范围（[[cardiovascular/heart-failure]]、[[geriatrics-palliative/ageing-frailty]]、[[surgery/anaesthesia-pain]]）；风险——心脏的失代偿与谵妄及输血及脱位及感染及静脉血栓，要用她的数字而不是平均数来量化（[[geriatrics-palliative/delirium-dementia-care]]、[[blood/thrombosis-anticoagulation]]、[[musculoskeletal/fractures]]）；不做手术那一栏——被优化的非手术的处理、以及它诚实的天花板（[[#def-management-pyramid]]）；以及她的目标——“坐到花园里、抱一抱我的孙辈”是一条正当手术的适应证——价值为先的决策、配上思考的时间与家属的在场（[[clinical-skills/communication]]、[[medical-ethics-law/consent-capacity]]、[[geriatrics-palliative/palliative-care]]）。说了“是”之后的系统的工作——预康复与优化与血液的管理与谵妄的预防及“康复去处的规划”——用“准备得是否充分”取代“是否太老”[[public-health/health-systems-economics]]、[[physiology/muscle]]。**
:::

::: exercise 髋、腰、还是两个都 {level=2}
一名68岁有腰背痛与臀部及大腿的痛；髋的内旋轻度受限、腰椎的后伸复现出一些疼痛；平片显示中度的髋骨关节炎与多节段的椎间盘的病。请在“不上手术名单”的前提之下规划下一步。
::: solution
**脊柱与髋并存的问题（[[#def-diagnosis]]、[[musculoskeletal/back-pain]]）：先“为归因而检查”——髋的模式内旋的丧失伴腹股沟的牵涉对“神经根的或关节突的或狭窄的”模式、以及“疼避开步态的站立与行走的再测”的序列（[[clinical-skills/physical-examination]]）；接下来安排——把有记录的“对目标治疗的反应”当作诊断的信息来读针对髋的运动与注射配清楚前后的功能的评分、对比针对脊柱的保守的处理（配狭窄的行走试验与神经的线索）——[[#def-management-pyramid]]、[[clinical-skills/clinical-reasoning]]；保留——在真正的“多个来源的”病例中、把诊断性的关节内的麻醉的阻滞偶尔还有选择性神经根的阻滞作为“一个外科的问题”的辅助、而不是作为一种爱好——[[clinical-skills/medical-imaging]]、[[surgery/anaesthesia-pain]]；影像的纪律——在没有危险信号、也没有“它会改变的那个决定”时，不去拍“到底哪里更痛的磁共振”（[[clinical-skills/medical-imaging]]、[[public-health/health-systems-economics]]）；以及那句“答案可以正当地是：两个都有，先处理那个主导的、再按功能重新评估”——一份说出来的计划胜过一张片子（[[clinical-skills/records-handover]]、[[clinical-skills/communication]]）。**
:::

::: summary
- 骨关节炎是全关节也是全人的疾病：软骨的分解代谢、骨与滑膜的反应、肌肉的失败、以及一套可能“跑赢了组织”的疼痛系统。
- 诊断是临床的；影像为不寻常的表现做确认、为外科做分期；而C反应蛋白与僵硬的时间能抓住大部分模仿者。
- 运动、体重的管理与教育是“改变疾病的核心”——要像药一样被处方、被定剂量、被随访，因为它们本来就是药。
- 药物是带着风险预算的辅助：先外用再口服、在年长多病的患者身上算好非甾的账、注射用于急性发作而不是未来、阿片几乎永远不用。
- 置换是医学里最成功的一台手术、它仍然需要正确的“患者的时刻”、那个优化的集束、以及诚实的长期数字。
:::

## 练习

::: exercise 解释这个诊断 {level=1}
用一段面向患者话解释膝的骨关节炎、而且不得使用“磨损”“骨对骨”或“炎”这几个词。
::: solution
**一个可能的版本（把[[#def-pathophysiology]]用朴素的语言呈现、依据[[clinical-skills/communication]]）：“你膝盖里那层起缓冲作用的衬里变薄了、而关节做出了反应——下面的骨变厚了、那层衬里在急性发作时会发炎、而周围的肌肉因为一路护着它而变弱了；这个组合作出了疼痛与僵硬、而其中的每一部分都是可以治疗的、尽管那层衬里本身不会重新长回来；运动、你的体重、必要时用的镇痛药、以及如果需要的话一台手术，各自帮助这幅图里的不同部分。“份”被禁的措辞“的审计是刻意的——”制造威胁”的语言会改变结局（[[public-health/prevention-promotion]]、[[psychiatry/anxiety-disorders]]）。**
:::

::: exercise 为手分类 {level=1}
给出三种手的模式：远端指间与腕掌的骨关节炎、近端指间与腕的类风湿、以及“焦磷酸钙或血色病的近端指间”的模式，并给出鉴别用的检查。
::: solution
**骨关节炎——坚硬骨性远端指间的结节与第一腕掌、以及“抓握时痛、休息后短暂僵硬”（[[#def-diagnosis]]）；类风湿——柔软滑膜炎样的近端指间与腕的肿、伴长时间的晨僵与对称及C反应蛋白升高与血清学（[[musculoskeletal/inflammatory-arthritis]]、[[clinical-skills/laboratory-tests]]）；焦磷酸钙或血色病——第二与第三近端指间的侵蚀或“钩状的骨赘”的模式、伴平片上软骨的钙化、以及铁的检查和穿刺液的晶体的确认（[[musculoskeletal/inflammatory-arthritis]]、[[gastrointestinal/liver-disease]]）；这个临床的习惯——手的分布加僵硬的时间，在抽任何血之前就已经完成了大部分分类[[clinical-skills/history-taking]]。**
:::

::: exercise 算那道非甾的算术 {level=2}
一名76岁的髋骨关节炎患者、3期的肾病、“用双氯芬酸时曾发生过胃肠的出血”、并在雷米普利与一种利尿药之下有高血压：请与她一起商定她的镇痛。
::: solution
**外用非甾的、或者不用全身的非甾的（[[#def-management-pyramid]]、[[pharmacology/patient-variation]]）：那个“三重风险”的解释（肾的灌注与血压与胃肠的出血、叠在心血管的风险之上——与她一起明确地做出这几栏风险的账、以及那句“胃的保护是一张免费通行证”的要点——[[renal/chronic-kidney-disease]]、[[cardiovascular/hypertension]]、[[gastrointestinal/oesophagus-stomach]]）；替代的阶梯——“如果有效就规律用”乙酰氨基酚、考虑度洛西汀处理那部分慢性疼痛、辣椒素作为“有些人喜欢”的辅助、以冰与负荷的调整并“考虑为那个主导的关节做一次注射”作为急性发作的计划、以及那个诚实的阿片的立场（[[pharmacology/adverse-reactions]]、[[geriatrics-palliative/symptom-control]]）；非药物的加强——有目标的物理治疗与辅具与睡眠及情绪及“疼痛的再编程”（[[physiology/muscle]]、[[psychiatry/mood-disorders]]）；以及那场迟早要摆上桌外科的谈话——按风险分层的髋的置换、而不是什么也不做（[[#def-surgery-below]]、[[surgery/perioperative-care]]）。**
:::

::: exercise 抓住“急性发作”的陷阱 {level=2}
一名已知的膝骨关节炎患者在四个月内因为“反复发作”接受了第三次激素的注射。门诊应该问哪三个问题？
::: solution
**第一——驱动发作的还是骨关节炎吗？还是滑膜炎、晶体病、半月板的病变、或感染藏在这个标签的背后（[[#def-diagnosis]]、[[musculoskeletal/inflammatory-arthritis]]、化脓的关节那条规则见[[musculoskeletal/bones-joints]]——“任何一个热而肿的关节，无论标签是什么，都要再穿一次”）？第二——这套注射的计划，是不是在替代那份“能改变轨迹的运动与体重与负荷的计划”？而间隔与总剂量是不是在安全的包络之内（[[#def-management-pyramid]]）？第三——这种持续对外科谈话意味着什么？有没有带着诚实的时间数字向她提供过那场谈话（[[#def-surgery-below]]）？治理的脚注——病历里那行“反复注射而未经复查”的标志是一台审计的触发器、不是个人的失败（[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]）。**
:::

::: exercise 设计骨关节炎的服务 {level=3}
一个地区有很长的关节置换的等待、却没有初级保健骨关节炎的路径。请以证据的金字塔、公平的那一层与经济学设计这个服务。
::: solution
**把金字塔当作路径——一个“由初级保健主导保守的核心”（结构化的教育与“有剂量的运动”及体重的管理的服务、配上转诊的标准与有时限的复查、以及开放通道肌肉骨骼的执业者、并由物理治疗师主导的注射与监测的门诊——[[#def-management-pyramid]]、[[physiology/muscle]]、[[gastrointestinal/clinical-nutrition]]、[[public-health/prevention-promotion]]）；升级的门——预康复与优化的门诊、按风险分层的“手术的排期”、以及明确的“阈值的透明”配上支持、不是惩罚（[[#def-surgery-below]]、[[surgery/perioperative-care]]、[[medical-ethics-law/justice-resources]]）；公平的那一层——按贫困与语言及职业及照护者的负担调整的准入、以及交通与“线上对面对面”的项目、以及给上班的人的晚间与周末的时段（[[public-health/determinants-inequalities]]、[[public-health/health-systems-economics]]）；经济学——“保守的核心只有在被完成、而不只是被出席时才减少手术的需求”、而预康复省下的是并发症与床位日、以及“等待名单对健康资本的扭曲效应”（[[epidemiology-ebm/observational-studies]]、[[public-health/health-systems-economics]]）；以及测量——在每一步收集“患者报告的结局”与“功能的结局”的评分、按公平分层的结局报告、以及从关节置换的登记系统借来的那份登记的纪律（登记作为监测——[[epidemiology-ebm/measuring-disease]]、[[surgery/orthopaedics]]）。**

::: exercise 读那份登记 {level=2}
一份国家关节置换的登记报告“十年的生存率为95%”、但在55岁以下的人群中翻修的比率在上升。请解释登记系统做得好的是什么、漏掉的是什么、以及这会怎样改变咨询。
::: solution
**登记的优势——连续真实世界的全人群队列、以及“植入物与术者与医院”的比较、以及把翻修作为硬的终点（监测的相邻见[[public-health/screening]]、[[epidemiology-ebm/observational-studies]]、[[surgery/orthopaedics]]）；它漏掉的——患者报告的结局、以及“那些不需要翻修的并发症”、以及“除非与患者报告的结局及住院的数据相链接，否则就没有病例的组成与贫困的梯度”（[[epidemiology-ebm/measuring-disease]]、[[public-health/determinants-inequalities]]）；咨询的后果——那条生存率的曲线是一个人群的平均值、而那位55岁以下的患者应当听到“在他这一生中翻修的风险百分比”、以框定的绝对值来表述、配上再手术与摩擦界面与骨丢失的后果、以及那句总结：“目标是让第二次手术变得不必要、但要把第一次手术规划成也许需要”（绝对的风险的框定——[[epidemiology-ebm/measuring-disease]]、[[clinical-skills/communication]]）；以及“可改变的那部分”的诚实——体重与吸烟及机械的超负荷及感染的风险，都会改变一个人围绕那条曲线的位置（[[#def-surgery-below]]、[[gastrointestinal/clinical-nutrition]]、[[public-health/prevention-promotion]]）。**
