骨关节炎是世界上最常见的关节疾病。全球疾病负担研究估计，2020年约有5.95亿人患有骨关节炎，它是老年人疼痛和残疾的主要原因之一。人们常把它轻描淡写为“磨损”，认为这是衰老的必然结果，无可奈何。这两种看法都有误导性。骨关节炎是累及关节每一种组织的活跃疾病过程；虽然不能治愈，但把运动、体重管理、合理用药，以及必要时的关节置换恰当地结合起来，可以使大多数人的疼痛和功能明显改善。

本章讲述骨关节炎是什么、为什么会发生、如何诊断（通常不需要影像学）、如何按照英国现行指南处理，以及关节置换的原则和并发症。本章假定读者已熟悉[[musculoskeletal/bones-joints]]中软骨和滑膜关节的结构。

## 骨关节炎是什么 {#sec-what}

::: definition 骨关节炎 {#def-oa}
**骨关节炎（OA）**是整个滑膜关节的疾病，组织损伤与修复失衡导致：

- 局灶性**关节软骨丢失**；
- **软骨下骨重塑**，出现硬化（密度增高），有时有囊变和骨髓病变；
- **骨赘**：关节边缘新生骨和软骨的赘生物；
- 程度不一、通常为低度的**滑膜炎**；
- **关节囊、韧带、半月板和肌肉**的改变，包括关节囊增厚、半月板退变，以及活动和保护关节的肌肉无力。

临床上表现为与使用相关的关节痛、短暂的僵硬、活动和功能下降，有时出现畸形。
:::

最常受累的关节是**膝关节**、**髋关节**、**手**（远端和近端指间关节以及拇指根部的第一腕掌关节）、**第一跖趾关节**和**脊柱**的小关节。掌指关节、腕、肘、肩和踝在没有特定原因（如既往损伤、晶体病或血色病）时很少受累。这种分布本身就是诊断线索：发生在不寻常部位的骨关节炎应促使人们寻找原因。

## 为什么会发生 {#sec-pathogenesis}

多年来，骨关节炎被认为只是软骨被磨掉。现代观点认为，关节组织在不断适应施加于其上的负荷，当这种适应失败时就发生骨关节炎。

::: theorem 负荷与组织承受能力 {#thm-load-capacity}
当关节所受的**机械负荷**超过其组织承受和适应负荷的**能力**时，就会发生骨关节炎。因此，它可以源于正常关节受到异常负荷（例如半月板撕裂后、力线不良或肥胖），也可以源于组织应对能力下降的关节受到正常负荷（例如衰老或软骨和骨的遗传变异）。
:::

::: proof
软骨细胞对负荷有反应。适度的周期性负荷维持软骨基质；过度或异常的负荷、损伤或炎症信号使软骨细胞转向**分解代谢**状态，产生降解基质的酶，尤其是胶原酶**MMP-13**和聚集蛋白聚糖酶**ADAMTS-4和ADAMTS-5**。聚集蛋白聚糖最先丢失，软骨保水减少而变软；随后Ⅱ型胶原网络被切断，表面磨损（**纤维化**）并出现裂隙。由于软骨没有血供且细胞稀少，这种损伤很难修复。

软骨下骨的反应是重塑增加和硬化，使其变硬，可能把应力集中到其上方的软骨。关节边缘的生长因子刺激形成**骨赘**，骨赘可能部分稳定不稳定的关节。软骨碎片和其他降解产物刺激滑膜，产生低度滑膜炎和积液，而这又释放更多炎症介质。

**疼痛**并不来自没有神经的软骨。它来自软骨下骨（尤其是MRI上的骨髓病变区）、滑膜、关节囊和关节周围组织。随着时间推移，神经系统本身变得更加敏感（**中枢敏化**），因此疼痛可以持续或扩散，与结构改变不相称。这就是X线严重程度与疼痛相关性差的原因：有些人X线改变严重却很少疼痛，有些人改变轻微却疼痛剧烈。
:::

主要危险因素都可由这一原理推出。

- **年龄**：最强的危险因素，反映组织承受能力下降和负荷累积。
- **女性**：膝和手骨关节炎在女性中更常见，尤其是绝经后。
- **肥胖**：增加负重关节的负荷，还有代谢和炎症作用；肥胖也与非负重关节——手的骨关节炎相关。
- **关节损伤**：半月板撕裂、交叉韧带断裂和关节内骨折大大增加该关节以后发生骨关节炎的风险，常在10至20年内出现。
- **关节形态与力线**：发育性髋关节发育不良、股骨髋臼撞击、膝内翻或膝外翻。
- **职业与活动**：反复跪地和重体力搬运（农民、建筑工人）；精英级的冲击性运动。关节健康者进行休闲跑步似乎并不增加风险。
- **遗传**：手和髋骨关节炎遗传性尤其强；许多常见变异各自增加少许风险。
- **肌无力**，尤其是股四头肌无力，会减少膝关节在负荷时受到的保护。

体重值得强调，因为它可以改变，而且其作用会被放大。行走时，膝关节所受的力是体重的数倍。在一项针对超重的老年膝骨关节炎患者的试验中，Messier及其同事（2005年）发现，每减轻1千克体重，每走一步膝关节的峰值压缩负荷就减少约4千克。

## 临床特征与诊断 {#sec-diagnosis}

典型病史是关节痛在使用后和傍晚加重，休息缓解，静止后有短暂僵硬（“胶着感”）。晚期可出现静息痛和夜间痛。患者会描述关节打软、活动范围减小、摩擦感，以及做特定动作困难：膝关节是上楼梯和从椅子上站起，髋关节是穿鞋袜，拇指根部是拧开瓶盖。

体格检查可见：

- **骨性膨大**（骨赘），例如远端指间关节的赫伯登结节、近端指间关节的布夏尔结节，以及拇指根部呈方形；
- 活动时**摩擦感**；
- 少量、不热的**积液**；
- **活动范围减小**，活动末端疼痛；髋关节最先丧失的是**内旋**；
- **畸形**，如内侧间室骨关节炎所致的膝内翻（O形腿）；
- **股四头肌萎缩**和疼痛步态；髋骨关节炎可出现特伦德伦堡步态。

::: definition 骨关节炎的临床诊断 {#def-oa-diagnosis}
NICE指南NG226（2022年）建议，对符合以下条件的人**依据临床、不做影像学检查**诊断骨关节炎：

- 年龄**45岁或以上**，且
- 有**与活动相关的关节痛**，且
- **没有晨起关节僵硬**，或晨僵持续**不超过30分钟**。

除非有**不典型特征**，否则不常规做影像学检查。不典型特征包括近期外伤史、晨僵时间长、症状或畸形迅速加重、关节红热肿胀，或提示感染或恶性肿瘤的特征，或提示其他诊断或合并诊断的特征。
:::

拍X线片时，骨关节炎的四个经典征象可以用英文缩写**LOSS**来记忆：关节间隙变窄（**L**oss of joint space，通常不对称，例如膝关节内侧间室）、骨赘（**O**steophytes）、软骨下硬化（**S**ubchondral sclerosis）和软骨下囊变（**S**ubchondral cysts）。**Kellgren–Lawrence**分级把影像学严重程度分为0级（无）到4级（严重：大骨赘、明显狭窄、严重硬化和畸形）。它用于研究，也有助于交流，但NICE建议不要用数值化的严重程度评分来决定是否转诊手术，因为症状和功能比影像更重要。

骨关节炎的血液检查正常，诊断也不需要血液检查。怀疑其他诊断时血液检查才有用：炎症标志物和自身抗体用于炎症性关节炎，尿酸用于痛风，铁蛋白和转铁蛋白饱和度用于血色病（可在第二、三掌指关节引起类似骨关节炎的改变）。

::: example 典型的膝关节 {#ex-knee}
一名62岁女性，在学校当厨师，双膝痛三年，上楼梯时和下班时加重。晨僵约十分钟。BMI为33 kg/m²。双膝有摩擦感，右膝有少量不热的积液，轻度膝内翻，股四头肌萎缩。她问是否需要拍X线片。诊断是什么？她需要影像学检查吗？
::: solution
她符合NICE关于膝骨关节炎**临床诊断**的全部三条标准（[[#def-oa-diagnosis]]）：年龄超过45岁，疼痛与活动相关，晨僵不到30分钟。没有不典型特征（无外伤、无红热肿胀的关节、无快速进展、无全身症状）。

她**不需要拍X线片**来诊断，X线片也不会改变她的初始处理。可以向她解释原因：X线片上改变的程度并不能预测她会有多疼，也不能预测她对治疗的反应。如果以后她到了考虑转诊做膝关节置换的阶段，手术团队会安排影像学检查。

处理从提供信息、以股四头肌强化和整体体能为重点的个体化**治疗性运动**方案，以及支持**减重**开始（见[[#sec-management]]）。
:::
:::

::: example 来自髋关节的膝痛 {#ex-hip}
一名71岁男性左膝痛六个月。他跛行，穿左侧袜子困难。膝关节外观和触诊正常，活动范围完整且无痛。左髋内旋明显受限，并诱发腹股沟和大腿前方疼痛。问题在哪里？为什么会以这种方式表现？
::: solution
问题几乎可以肯定在**左髋**，最可能是**髋骨关节炎**。髋关节痛主要在**腹股沟**和大腿前方，但常**牵涉到膝关节**，因为闭孔神经和股神经同时支配这两个关节。膝关节检查正常而髋内旋疼痛受限，可以定位问题所在。

教训是：只要膝痛无法解释，就要**检查上方的关节**，尤其是儿童（股骨头骨骺滑脱和Perthes病也这样表现）和老年人。如果他的症状是跌倒后突然出现的，就需要排除髋部骨折；如果他有长期使用糖皮质激素或大量饮酒等危险因素，股骨头**缺血性坏死**是另一种可能。
:::
:::

老年人关节痛的鉴别诊断包括：炎症性关节炎（晨僵时间长、软组织肿胀、炎症标志物升高）、**晶体性关节炎**（痛风和焦磷酸钙沉积，常与骨关节炎并存并引起急性发作）、**化脓性关节炎**（关节发热，尤其是置换过的关节）、**缺血性坏死**、**牵涉痛**（髋牵涉到膝，脊柱牵涉到髋或臀部）、大转子疼痛综合征和鹅足滑囊炎等关节周围问题，以及**恶性肿瘤**（夜间痛、体重下降、癌症病史）。

## 处理 {#sec-management}

处理的目标是减轻疼痛、改善功能和生活质量，并帮助患者保持活动和继续工作。在英国，处理遵循NICE指南NG226（2022年）。重点是非药物治疗，药物用来辅助而不是取代非药物治疗。

::: definition 骨关节炎的核心处理（NICE NG226） {#def-management}
**适用于所有人**

- 个体化的**信息与支持**，解释骨关节炎不只是“磨损”，不一定会越来越重，而且治疗有帮助。
- 个体化的**治疗性运动**，如局部肌肉强化和整体有氧体能训练。要提前告知患者开始运动时疼痛可能加重，而长期规律、持续的运动是有益的。
- 对超重或肥胖者进行**体重管理**。任何程度的减重都可能有帮助，但减轻体重的10%可能比5%更好。

**其他非药物选择**

- 下肢骨关节炎使用助行器具（如手杖）。
- 手法治疗只能与治疗性运动同时使用，不能单独使用。
- 除非存在关节不稳或负荷异常且运动无效或不适合，否则不常规提供鞋垫、支具、贴扎和夹板。
- **不**提供针灸、干针和电疗（包括经皮神经电刺激和超声治疗）。

**药物**（与运动同时使用，使用最低有效剂量、尽可能短的时间）

- 膝骨关节炎提供**外用非甾体抗炎药**，其他关节可以考虑。
- 外用治疗无效或不适合时，考虑**口服非甾体抗炎药**，需考虑胃肠道、肾、肝和心血管风险，并同时使用质子泵抑制剂等**胃保护**药物。
- **不常规**提供**对乙酰氨基酚和弱阿片类药物**，因为缺乏有力的获益证据；除非在其他所有药物都不适合时偶尔用于短期缓解。
- **不**提供**氨基葡萄糖**和**强阿片类药物**。
- 当其他药物无效或不适合时，或为了支持运动，考虑**关节腔内注射糖皮质激素**；它只能短期缓解，约2至10周。
- **不**提供**关节腔内注射透明质酸**。

**手术**

- 当髋、膝或肩骨关节炎的症状严重影响生活质量，且非手术处理无效或不适合时，考虑转诊进行**关节置换**。
- 骨关节炎**不提供关节镜下灌洗或清理术**。
:::

有几点值得说明。运动是基础，因为它确实有效：强化股四头肌和髋部肌肉减轻疼痛、改善功能的效果与非甾体抗炎药相当，只要坚持运动，效果就能持续，而且没有药物毒性。英国的ESCAPE-pain等项目把教育与集体运动结合起来。

非甾体抗炎药的选择反映了风险。外用非甾体抗炎药在膝和手的浅表组织中达到有效浓度，而血药浓度很低，因此避免了口服非甾体抗炎药的大部分胃肠道和肾脏损害。口服非甾体抗炎药有效，但骨关节炎老年患者恰恰是胃肠道出血、肾损伤、液体潴留和心血管事件风险最高的人群（[[pharmacology/adverse-reactions]]）。

不推荐对乙酰氨基酚是对旧做法的改变。大型系统评价发现它对骨关节炎疼痛的作用很小，低于患者能感觉到的程度，因此NICE不再常规推荐。避免使用强阿片类药物，是因为在长期骨关节炎疼痛中，其危害（跌倒、便秘、依赖）超过了有限的获益。

::: warning 不要治疗X线片
有两种常见错误源于过度依赖影像。第一种是**为诊断典型骨关节炎而开X线或MRI检查**，这会增加费用和延误，还可能造成伤害：满是“退行性改变”的报告会让人害怕活动，而中年人膝关节MRI常显示半月板撕裂，许多没有疼痛的人也有这种撕裂。第二种是**治疗影像而不是治疗人**：因退行性膝关节或MRI所见的半月板撕裂而提供关节镜“清理”。比较关节镜手术与假手术或运动治疗的随机试验发现，它对退行性膝关节病没有有意义的获益，NICE也不推荐。应根据症状、功能和体格检查决定治疗。
:::

::: example 选择药物 {#ex-drugs}
一名78岁男性患髋和膝骨关节炎，有3b期慢性肾脏病（eGFR 38 mL/min/1.73 m²）、心力衰竭和十二指肠溃疡病史。他规律服用对乙酰氨基酚两年，几乎无效，要求“更强的药”。他很少走路。按照现行指南，你将如何处理他的疼痛？
::: solution
**复查他正在用的药。**对乙酰氨基酚几乎无效；NICE建议不常规使用，因此可以讨论停用。

在他的情况下，**口服非甾体抗炎药风险很高**：慢性肾脏病（非甾体抗炎药减少肾血流，可致急性肾损伤）、心力衰竭（液体潴留）和消化性溃疡病史（出血）。通常应避免使用。

膝关节使用**外用非甾体抗炎药**是合理的选择，全身吸收很少。

由于跌倒、意识模糊和依赖的风险，尤其是在他这个年龄，骨关节炎不推荐使用**强阿片类药物**。

膝关节或（在影像引导下）髋关节**关节腔内注射糖皮质激素**可以短期缓解疼痛，帮助他开始运动。

**非药物处理最重要**：个体化的治疗性运动方案，可以在监督下进行；在病情较重的髋关节对侧手中使用手杖；并关注他的心力衰竭和体能。

如果尽管如此症状仍然严重并影响生活质量，就应讨论**转诊进行关节置换**。他的合并症增加了手术风险，但NICE建议年龄和合并症本身不是拒绝转诊的理由；应与他一起权衡风险和获益。
:::

应向所有骨关节炎患者提供治疗性运动（例如局部肌肉强化和整体有氧体能训练），同时提供信息与支持，并在适用时进行体重管理。对乙酰氨基酚不常规提供，氨基葡萄糖不提供，关节镜下灌洗或清理术也不提供。
:::
:::

## 关节置换 {#sec-arthroplasty}

全髋关节置换和全膝关节置换是医学中最成功的手术之一。大多数人疼痛明显缓解、功能改善，现代假体常能使用20年或更久。髋关节置换时，股骨头被安装在股骨柄上的金属或陶瓷球头替代，与衬有聚乙烯或陶瓷的髋臼杯形成关节。膝关节置换时，股骨和胫骨的末端用金属部件进行表面置换，中间以聚乙烯衬垫隔开。假体可以用骨水泥固定，也可以依靠骨长入粗糙表面来固定。只有一个间室受累时，可以选择**单髁**（部分）膝关节置换。

NICE建议在症状严重影响生活质量、非手术治疗失败或不适合时考虑转诊。转诊决定应基于临床评估而不是数值评分，不应因年龄、性别、吸烟、合并症或体重指数而把人排除在外，尽管这些因素会改变风险，应加以讨论。

::: definition 关节置换的并发症 {#def-arthroplasty-complications}
**早期**

- **静脉血栓栓塞**：深静脉血栓形成和肺栓塞。按指南使用机械和药物预防（[[blood/thrombosis-anticoagulation]]）。
- **感染**：浅表伤口感染或深部**假体周围关节感染（PJI）**，后者在初次髋膝关节置换中约占1%。
- 髋关节置换后**脱位**，尤其是在最初几个月内。
- **神经损伤**，如髋关节置换时的坐骨神经损伤和膝关节置换时的腓总神经损伤。
- **出血**、伤口问题，以及麻醉和手术的一般风险，包括老年患者的心肌梗死、卒中和谵妄。
- 髋关节置换后**双下肢不等长**。

**晚期**

- 假体**无菌性松动**，常由磨损颗粒引起炎症反应和假体周围骨吸收（**骨溶解**）所致。
- **晚期假体周围感染**，包括菌血症播散所致的感染。
- **假体周围骨折**，通常在跌倒后发生。
- **持续疼痛和不满意**：尤其是膝关节置换后，少数人（常被引用的数字是多达约五分之一）对结果不满意，这就是术前要讨论期望的原因。
:::

全国关节登记系统，例如英格兰、威尔士、北爱尔兰、马恩岛和根西岛的国家关节登记系统（National Joint Registry，2003年建立），记录每一个假体及其结局。它们能识别早期失败的假体：在21世纪第一个十年后期，登记数据在发现某些金属对金属髋关节设计的高失败率方面起了核心作用。

::: example 发热的置换膝关节 {#ex-pji}
一名69岁女性六周前做了左侧全膝关节置换。四天来膝关节越来越痛、发热、肿胀，伤口有一小处渗液。体温37.9 °C；她其他方面情况良好，血压正常。她的全科医师正考虑开始口服抗生素。担忧的是什么？应该怎么做？
::: solution
担忧的是**假体周围关节感染（PJI）**。关节置换后疼痛加重、发热、肿胀和伤口渗液，在被证明不是之前都应视为感染。

除非她有脓毒症，**否则不应在专科评估前在社区开始使用抗生素**。盲目使用抗生素会抑制病原体，使培养呈阴性，更难识别和治疗感染；而这种感染通常涉及生活在假体表面**生物膜**中的细菌。

她应紧急转诊到**为她做手术的骨科团队**，由他们抽血检查（包括CRP）、**关节穿刺**做细胞计数和培养，并制订治疗方案。早期感染（术后数周内）有时可以通过外科清创、更换组配式聚乙烯衬垫并保留假体（缩写为DAIR）来治疗，随后进行较长疗程的针对性抗生素治疗。已形成的或晚期感染通常需要一期或二期翻修手术。如果她有脓毒症的征象，就需要做血培养并立即静脉使用抗生素（[[infectious-diseases/fever-sepsis]]）。
:::
:::

::: history
英国医师**威廉·赫伯登（William Heberden）**在1802年出版的《疾病史与治疗评注》中描述了以他命名的指关节骨性结节。1957年，曼彻斯特的**乔纳斯·凯尔格伦（Jonas Kellgren）**和**约翰·劳伦斯（John Lawrence）**发表了骨关节炎的影像学分级，至今仍在使用。现代髋关节置换由兰开夏郡赖廷顿医院的**约翰·查恩利（John Charnley）**发展而来，他从1962年起在低摩擦关节成形术中把小号金属股骨头与高密度聚乙烯髋臼杯、骨水泥和洁净空气手术室结合起来。膝关节置换在20世纪70年代随之出现。2002年，**布鲁斯·莫斯利（Bruce Moseley）**及其同事在《新英格兰医学杂志》报告，膝骨关节炎的关节镜灌洗和清理术并不优于假手术，这是外科领域最著名的安慰剂对照试验之一，它改变了外科文化。
:::

## 后续内容

关节置换和翻修的手术细节见[[surgery/orthopaedics]]，术前评估见[[surgery/perioperative-care]]。可以模拟或并发于骨关节炎的炎症性疾病和晶体病见[[musculoskeletal/inflammatory-arthritis]]。脊柱骨关节炎和椎间盘退变病见[[musculoskeletal/back-pain]]。慢性疼痛机制在[[nervous-system/headache-pain]]中展开，镇痛药的安全使用见[[surgery/anaesthesia-pain]]和[[geriatrics-palliative/polypharmacy]]。

::: summary
- 骨关节炎是整个关节的疾病（软骨丢失、软骨下骨重塑、骨赘、滑膜炎和关节周围改变），而不是被动的磨损。
- 当负荷超过关节组织的适应能力时发生骨关节炎。主要危险因素是年龄、女性、肥胖、关节损伤、关节形态、职业、遗传和肌无力。
- 疼痛来自骨、滑膜和关节囊而不是软骨，并因中枢敏化而放大，因此X线严重程度与症状相关性差。
- 典型部位是膝、髋、手指间关节、拇指根部、第一跖趾关节和脊柱。不寻常部位的骨关节炎需要解释。
- NICE NG226：对45岁或以上、有与活动相关的疼痛、无晨僵或晨僵短暂（30分钟或更短）的人，依据临床诊断，不做影像学检查。
- 核心治疗是信息、治疗性运动和体重管理。膝骨关节炎提供外用非甾体抗炎药；必要时口服非甾体抗炎药并加用胃保护药物；对乙酰氨基酚和弱阿片类药物不常规使用；氨基葡萄糖、强阿片类药物、透明质酸注射和关节镜灌洗或清理术一概不用。
- 当非手术处理后症状仍严重影响生活质量时考虑关节置换。主要并发症是静脉血栓栓塞、感染、脱位、松动、假体周围骨折和持续疼痛。
- 发热疼痛的置换关节在被证明不是之前都视为感染；避免盲目使用抗生素，紧急转诊穿刺。
:::

## 习题

::: exercise 说出这些征象 {level=1}
列出骨关节炎的四个经典影像学征象，并说明每个征象反映的是哪种组织。
::: solution
**关节间隙变窄**：关节软骨丢失（软骨在X线片上不显影，所以其变薄表现为骨间间隙变窄）。**骨赘**：关节边缘新生的骨和软骨。**软骨下硬化**：受损软骨下方的骨因重塑而密度增高。**软骨下囊变**：软骨下骨内的充液腔隙。
:::
:::

::: exercise 哪些关节？ {level=1}
下列关节中，哪些是原发性骨关节炎的典型受累关节，哪些会让你去寻找其他原因：远端指间关节、第二和第三掌指关节、第一腕掌关节、踝关节、髋关节？
::: solution
**典型**：远端指间关节、第一腕掌关节和髋关节。**不典型**：第二和第三掌指关节（考虑血色病或焦磷酸钙沉积）和踝关节（通常继发于既往骨折或韧带损伤）。发生在不典型部位的骨关节炎应促使人们寻找原因。
:::
:::

::: exercise 体重指数 {level=1 check="round(10*102/1.68^2)/10"}
一名膝骨关节炎女性体重102 kg，身高1.68 m。计算她的体重指数（kg/m²），四舍五入到一位小数。
::: solution
BMI $= 102 / 1.68^2 = 102 / 2.8224 \approx 36.1$ kg/m²。这属于肥胖范围（30或以上），因此体重管理是她治疗的核心部分。
:::
:::

::: exercise 减重与膝关节负荷 {level=2 check="48"}
同一名女性经过一年努力减轻了体重的10%，取整为12 kg。根据每减轻1千克体重、每步膝关节峰值压缩负荷约减少4千克的发现，她每步膝关节峰值负荷减少了多少千克？解释为什么NICE说减轻10%可能比5%更好。
::: solution
减少量$= 12 \times 4 = 48$ kg/步。每天走几千步，这是膝关节累积负荷的巨大减少。减重越多，负荷减少成比例地越多，在试验中疼痛和功能的改善也越大，因此NICE建议任何程度的减重都可能有帮助，但减轻体重的10%可能比5%更好。减重还能减少脂肪组织的代谢和炎症作用。
:::
:::

::: exercise 她需要做影像检查吗？ {level=2}
对下列每个人，判断是否需要影像学检查并说明理由。(a) 58岁，与活动相关的膝痛三年，晨僵五分钟。(b) 52岁，膝痛在六周内迅速加重，伴夜间痛和体重下降。(c) 47岁，手痛伴掌指关节肿胀，每天晨僵两小时。
::: solution
(a) **不需要影像学检查**：符合NICE骨关节炎的临床诊断标准。

(b) **需要影像学检查**：迅速加重、夜间痛和体重下降是不典型特征，令人担心恶性肿瘤（如骨转移瘤或原发性骨肿瘤）或感染。X线片是首选检查，必要时紧急进一步检查。

(c) 这**不是典型的骨关节炎**：掌指关节受累和晨僵时间长提示**炎症性关节炎**。她需要紧急转诊风湿科；手足X线片、血液检查，可能还有超声，将作为评估的一部分来安排（[[musculoskeletal/inflammatory-arthritis]]）。
:::
:::

::: exercise 解释指南 {level=2}
一名膝骨关节炎患者在网上读到对乙酰氨基酚是“关节炎的一线止痛药”，而且膝关节“冲洗”能治好他撕裂的半月板。用适合他的通俗语言解释英国现行指南的说法及其理由。
::: solution
较好的解释可以这样说：“很多年来对乙酰氨基酚一直被推荐为首选，但把大型研究汇总起来后发现，它对骨关节炎的作用非常小，小到大多数人都感觉不到。所以指南不再推荐把它作为常规的规律用药。抹在膝盖上的消炎药凝胶效果更好，而且对大多数人是安全的。微创冲洗或清理手术已经和假手术做过比较，结果做假手术的人效果一样好。MRI显示的半月板小撕裂在我们这个年龄的人中很常见，包括很多不痛的人，所以它们通常不是疼痛的原因。真正有帮助的是设计良好、能增强膝关节周围肌肉的运动方案，保持活动，如果超重就减重。如果疼痛仍然严重影响您的生活，可以考虑膝关节置换。”
:::
:::

::: exercise 韧带损伤之后 {level=3}
一名34岁女性曾在郡级水平踢足球，十年前前交叉韧带断裂并撕裂内侧半月板，半月板被部分切除。现在同一膝关节出现与活动相关的疼痛。(a) 用[[#thm-load-capacity]]解释她骨关节炎风险增加的原因。(b) 她符合NICE的临床诊断标准吗？(c) 你会建议什么？
::: hint
想一想半月板和交叉韧带在负荷分布和稳定性方面的作用，并核对[[#def-oa-diagnosis]]中的年龄标准。
:::
::: solution
(a) 半月板把负荷分散到整个胫骨平台。切除一部分会使负荷**集中**到更小的软骨面积上。前交叉韧带缺失或重建后的膝关节还有异常运动和**不稳定**，产生剪切力。因此单位面积负荷超过了组织的适应能力，创伤后骨关节炎常在这种损伤后10至20年出现，往往发生在年轻成人中。

(b) 她**不**符合NICE的临床诊断标准，因为她不到45岁。这并不意味着她没有骨关节炎，而是意味着不能想当然地作出诊断，做**影像学检查**（X线片，如怀疑不稳定或再次半月板撕裂，可做MRI）来评估关节并排除其他问题是合理的。

(c) 处理遵循同样的原则：教育、循序渐进的**力量和神经肌肉训练方案**、保持健康体重，以及调整而不是放弃活动。外用非甾体抗炎药可能有帮助。如有不稳定或提示半月板撕裂移位的机械症状，或有明显的力线不良，应转诊给膝关节专科医师；对较年轻者可考虑截骨术等保关节手术。
:::
:::

::: exercise 髋关节置换后新出现的跛行 {level=3}
一名76岁男性八年前做了全髋关节置换，效果一直很好。六个月来他在负重时和刚站起来时出现腹股沟和大腿痛（“启动痛”）。他其他方面情况良好，无发热，CRP正常。(a) 最可能的原因是什么？(b) 必须考虑哪些鉴别诊断？(c) 哪些检查有帮助？
::: hint
想一想[[#def-arthroplasty-complications]]中的晚期并发症，以及启动痛提示假体出了什么问题。
:::
::: solution
(a) 最可能的原因是股骨柄或髋臼杯**无菌性松动**。开始负重时疼痛和大腿痛提示假体相对于骨有移动。松动常由来自关节面的磨损颗粒引起，这些颗粒刺激巨噬细胞释放细胞因子，激活破骨细胞，在假体周围造成**骨溶解**。

(b) 鉴别诊断包括**低毒力假体周围感染**（CRP可以正常或仅轻度升高；痤疮皮肤杆菌（*Cutibacterium acnes*）和凝固酶阴性葡萄球菌可引起隐匿性感染）、**假体周围骨折**、腰椎病变所致的牵涉痛、大转子疼痛，以及少见得多的转移性疾病。

(c) 与既往片子对比的**系列X线片**可显示假体周围透亮线、骨溶解、假体位置改变或骨折。血液检查（CRP、血沉），如有感染可能，在使用任何抗生素之前做**髋关节穿刺**培养。转诊给关节置换专科医师，以确定是否需要翻修手术，因为区分感染与无菌性松动会改变手术方式。
:::
:::
