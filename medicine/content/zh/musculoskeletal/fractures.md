骨折是骨的连续性中断。骨折是急诊科最常见的损伤之一，发生于两类截然不同的人群。年轻成人在高能量损伤中骨折，如道路交通事故、高处坠落和运动损伤。老年人（大多是患骨质疏松症的女性）则在从站立高度跌倒这样的低能量损伤中骨折。两类人群需要同样的核心知识：如何准确描述骨折、骨如何愈合、治疗如何控制愈合环境，以及哪些并发症威胁肢体或生命。

本章以[[musculoskeletal/bones-joints]]中的骨结构与骨重建以及[[pathology/chronic-inflammation-repair]]中修复的一般生物学为基础。手术细节属于[[surgery/orthopaedics]]，严重创伤患者的处理属于[[surgery/trauma]]。

## 骨折的描述 {#sec-describe}

骨折描述应能让没看过X线片的同事在电话中准确想象出骨折的样子。按固定顺序描述骨折可以做到这一点。

::: definition 骨折的描述 {#def-description}
完整的描述包括：

1. **患者与影像**：姓名、年龄、日期、拍摄了哪些X线体位，以及左侧还是右侧。
2. **骨与部位**：对长骨而言，骨折位于**骨干**、**干骺端**（膨大的骨端）还是**骨骺**（生长板以外的骨端），以及是否累及关节（**关节内**骨折）。
3. **形态**：
   - **横形**：横贯骨干，通常由直接打击或弯曲引起；
   - **斜形**：呈一定角度；
   - **螺旋形**：绕骨干盘旋，由扭转力引起；
   - **粉碎性**：多于两个骨折块；
   - **多段**：两条独立的骨折线隔出一段骨干；
   - **撕脱**：骨块被肌腱或韧带拉脱；
   - **嵌插**或**压缩**：骨折块相互嵌入，如许多椎体骨折。
4. **移位**，总是描述**远端**骨折块相对于近端骨折块的位置：**侧方移位**（向侧方移动，以骨干宽度的百分比表示）、**成角**（以度数表示，并说明成角尖端指向的方向）、**旋转**，以及**短缩**或分离。
5. **开放还是闭合**。在**开放性**骨折中，骨折或其血肿通过皮肤或黏膜的伤口与外界相通。
6. 是否伴有关节**脱位**，以及提示潜在骨病的特征。
:::

有些特殊类型因病因和处理不同而有专门的名称。

- **病理性骨折**发生在被疾病削弱的骨上：骨质疏松症、转移瘤、骨髓瘤、原发性骨肿瘤、骨佩吉特病或感染。轻微外力后发生的骨折，或穿过外观异常骨区的骨折，应促使人们寻找病因。
- **应力性骨折**由反复负荷超过骨重建能力所致，如新兵的跖骨或长跑者的胫骨。X线片起初常正常；MRI能早期显示。
- **儿童骨折**有其特有的类型。**青枝骨折**一侧骨皮质断裂，另一侧弯曲；**隆突（环形）骨折**是干骺端骨皮质受压后的皱褶。累及生长板（骺板）的损伤按**Salter–Harris**分型：Ⅰ型穿过骺板；Ⅱ型穿过骺板后经干骺端穿出（最常见）；Ⅲ型穿过骺板后经骨骺穿入关节；Ⅳ型贯穿干骺端、骺板和骨骺；Ⅴ型为骺板挤压伤。分型越高，生长障碍的风险越大。

开放性骨折按**Gustilo–Anderson**分型，反映损伤能量和软组织状况。Ⅰ型伤口清洁，长度小于1 cm；Ⅱ型伤口长1至10 cm，无广泛软组织损伤；Ⅲ型有广泛软组织损伤，通常由高能量损伤所致。Ⅲ型又分为ⅢA（软组织仍能覆盖骨）、ⅢB（骨膜剥离，骨需要皮瓣覆盖）和ⅢC（有需要修复的动脉损伤）。最终分型要在手术室清创后确定，因为实际损伤范围往往比伤口所显示的更大。

## 骨折如何愈合 {#sec-healing}

骨是少数通过再生而非形成瘢痕来愈合的组织之一。愈合后的骨折经过重塑，可以与原来的骨无法区分。愈合方式取决于骨折间隙内的力学环境。

::: definition 骨折二期愈合的阶段 {#def-healing}
大多数骨折通过骨痂进行**二期（间接）愈合**。各阶段相互重叠：

1. **血肿与炎症期**（最初几天）。骨和骨膜出血形成血肿。血小板和炎症细胞释放细胞因子和生长因子。骨折端的骨因失去血供而有一小段坏死。
2. **软骨痂期**（大约最初两到三周）。肉芽组织长入血肿。来自骨膜和周围组织的间充质细胞分化为成纤维细胞和软骨细胞，形成桥接间隙的纤维软骨。骨折变得“发黏”，疼痛减轻，但还不牢固。
3. **硬骨痂期**（数周至数月）。软骨矿化，并通过软骨内成骨被**编织骨**替代，同时骨膜下也直接成骨。当骨痂桥接骨折、骨折处不再压痛或异常活动时，骨折达到**临床愈合**。当X线片显示桥接骨痂跨过骨折线时，达到**影像学愈合**。
4. **重塑期**（数月至数年）。破骨细胞和成骨细胞以**板层骨**替代编织骨，并沿应力线重塑骨的形态。儿童的重塑能纠正相当大的成角，尤其是靠近生长板并位于关节活动平面上的成角；但不能纠正旋转。

**一期（直接）愈合**只发生在骨折块解剖复位并被坚强加压固定时（例如使用加压钢板），此时由破骨细胞和成骨细胞组成的切割锥直接穿过骨折线，不形成骨痂。
:::

为什么有的骨折形成骨痂、有的直接愈合，可以用间隙内的应变来解释。

::: theorem 骨折端间应变 {#thm-strain}
**应变**是骨折间隙内组织长度的相对变化：如果间隙宽度为$L$，骨折块在负荷下移动$\Delta L$，则

$$\varepsilon = \frac{\Delta L}{L}.$$ {#eq-strain}

只有能耐受间隙内应变的组织才能在间隙中形成。按照Perren的应变理论，肉芽组织能耐受很高的应变（可达约100%），软骨和纤维组织耐受中等应变（约10%），而骨几乎不能耐受（约2%）。因此愈合需要应变逐步下降：每形成一种组织，间隙就变硬一些，应变降低到足以让下一种组织形成。
:::

::: proof
在**绝对稳定**（解剖复位加压）下，活动从而应变保持在约2%以下，骨可以不经骨痂直接形成。在**相对稳定**（石膏、髓内钉或桥接钢板）下，存在一定活动。几个百分点直到约10%的应变会刺激骨痂形成；骨痂增大有效横截面并使骨折变硬，应变逐渐降低，直到编织骨能够形成。如果应变一直过高，只有肉芽组织或纤维组织能存活，骨折可能不愈合。

这个公式还解释了一个违反直觉的现象。对同样的活动量，**窄**间隙的应变比宽间隙**更高**。一个间隙1 mm的简单骨折若允许活动0.3 mm，应变为30%，对骨来说太高。同样的活动发生在粉碎性骨折中，负荷分散在更长的区域内，应变较低。这就是为什么简单骨折通常采用绝对稳定固定、粉碎性骨折采用相对稳定固定，也是为什么用不够坚强的钢板固定的简单骨折，只要有少量活动就可能导致不愈合。
:::

愈合时间取决于骨、患者和损伤。一个粗略的规则（Perkins规则）是：成人上肢长骨螺旋形骨折约六周愈合，横形骨折需要两倍时间，下肢骨折再加倍；儿童愈合快得多。以下情况愈合较慢：

- **血供差**：伴软组织剥离的高能量损伤，以及血供不稳定的部位，如舟骨、股骨颈和距骨；
- **活动过多或过少**（见[[#thm-strain]]）；
- **感染**；
- **患者因素**：高龄、吸烟、糖尿病、营养不良、周围血管病和某些药物（长期使用糖皮质激素；非甾体抗炎药对愈合的影响尚有争议，对不愈合风险高的骨折常避免使用）。

::: example 钢板固定骨折中的应变 {#ex-strain}
一处桡骨横形骨折用钢板固定。由于钢板加压不良，骨折间隙为1.0 mm，每次前臂活动时移动0.3 mm。一处股骨干粉碎性骨折用髓内钉固定，有效间隙为3.0 mm，相同条件下移动0.05 mm。计算两者的应变，并预测各自如何愈合。
::: solution
用[[#eq-strain]]：

- 桡骨：$\varepsilon = 0.3/1.0 = 0.30$，即**30%**。这远高于骨（约2%）和软骨（约10%）的耐受限度，只有肉芽组织和纤维组织能够存活，因此骨折有**不愈合**的风险。需要的是更高的稳定性：对骨折加压，使间隙和活动量都接近零。
- 股骨：$\varepsilon = 0.05/3.0 \approx 0.017$，即约**1.7%**。这低到足以成骨；在边缘应变较高处会形成骨痂，预计骨折可以愈合。

要点在于：稳定性必须与骨折形态相匹配——简单骨折用绝对稳定，粉碎性骨折用相对稳定。
:::
:::

## 处理原则 {#sec-management}

骨折处理从整个患者开始。肢体损伤触目惊心的人，可能有隐匿的头部、胸部或腹部损伤，而这些损伤会先致命。结构化的初级评估（气道并保护颈椎、呼吸、循环并控制出血、神经功能障碍和暴露）先于肢体处理（[[emergency-critical-care/acute-assessment]]和[[surgery/trauma]]）。骨盆骨折和股骨骨折各自都可以丢失一升或更多血液。

对肢体本身：

1. **评估**损伤远端的皮肤、循环和神经，并在任何手法操作前后**记录**所见。
2. **镇痛**并**夹板固定**肢体。把严重畸形的肢体拉直并固定，可以减轻疼痛和出血，并可能恢复循环。
3. 正确地**拍片**：至少两个互相垂直的体位，包括骨折上下方的关节。
4. 然后遵循经典顺序：**复位**（如果移位不可接受）、**固定**（维持复位直到愈合）和**康复**（恢复活动、力量和功能）。

并非所有骨折都需要复位。当移位能够被重塑或不影响功能时可以接受，例如许多锁骨骨折或小指掌骨颈骨折。相反，关节内骨折通常需要精确复位，因为关节面的台阶会导致骨关节炎。

::: definition 骨折的固定方法 {#def-fixation}
- **非手术**：吊带、石膏（熟石膏或玻璃纤维）、夹板，以及允许关节活动的**功能支具**。大多数儿童骨折和许多成人骨折采用这种方法。
- **牵引**：沿肢体长轴牵拉以使骨折块对线，现在主要用作临时措施。
- **内固定**：
  - **螺钉**和**钢板**，可提供绝对稳定（加压钢板）或相对稳定（桥接钢板）；
  - **髓内钉**，沿髓腔插入，是许多股骨干和胫骨干骨折的标准治疗；它与骨共同承担负荷，允许早期负重；
  - 用于小骨块的**钢丝**和张力带。
- **外固定**：骨内的钉或针连接到皮肤外的支架。用于严重开放性骨折、作为不稳定患者的临时“损伤控制”手段，以及肢体重建。
- **关节置换（关节成形术）**：当骨折破坏了关节或其血供时使用，如许多老年人的移位型股骨颈骨折。
:::

### 开放性骨折

开放性骨折是外科急症，因为细菌已经到达骨。在英国，英国骨科协会创伤标准（BOAST）中关于开放性骨折的标准（2017年）列出了主要步骤，大多数体系的做法与之相似：

- 尽快静脉使用**抗生素**，最好在受伤后**一小时内**，按当地方案用药；
- 核查**破伤风**免疫状况，必要时给予预防；
- 给伤口**拍照**，去除肉眼可见的污染物，用生理盐水浸湿的敷料覆盖伤口；夹板固定肢体并复查神经血管状况；
- 由高年资骨科和整形外科医师共同进行**外科清创**（清除坏死和污染组织）：对高度污染的伤口（如农业或污水污染）或血管受损者立即进行，其他高能量损伤在12小时内，其他低能量开放性骨折在24小时内；
- 由骨科与整形外科（“骨整形”）团队共同计划最终固定和软组织覆盖。

::: example 开放性胫骨骨折 {#ex-open}
一名32岁摩托车手在碰撞后被送来。初级评估未发现危及生命的损伤后，见其左小腿中段成角，胫前有一4 cm伤口，可见骨外露。足部苍白发凉，未触及脉搏；足底感觉减退。应如何处理？
::: solution
这是**开放性胫骨干骨折**，伤口长于1 cm，并有**血管受损的体征**。

1. 在镇痛下**立即使肢体恢复对线并夹板固定**。严重成角可使腘血管和胫血管扭曲；恢复对线后脉搏常可恢复。之后复查并记录脉搏、毛细血管再充盈和感觉。
2. 立即**静脉使用抗生素**（最好在受伤后一小时内），并核查破伤风免疫状况。
3. 给伤口拍照，去除肉眼可见的污染物，用生理盐水浸湿的敷料覆盖。
4. 如果恢复对线后脉搏仍未恢复，这是**威胁肢体的血管损伤**：紧急CT血管造影，或与血管外科一起直接进入手术室，**立即**清创、临时稳定（常用外固定架）并修复动脉。如需修复动脉，则至少是Gustilo–Anderson ⅢC型损伤。
5. 监测**骨筋膜室综合征**，它常继发于胫骨骨折和血管修复后的再灌注。

胫骨前方软组织覆盖很少，因此此处的开放性骨折感染率和不愈合率都很高；早期的骨整形联合处理可改善结局。
:::
:::

### 脆性骨折与髋部骨折

老年人髋部骨折既是外科急症，也是内科急症。约四分之一到三分之一的患者在一年内死亡，许多人再也无法恢复以前的活动能力。髋部骨折按其与关节囊的关系分类：

- **囊内**（股骨颈）骨折可以破坏沿股骨颈走行到股骨头的支持带动脉，因此**移位型**囊内骨折**缺血性坏死**和不愈合的风险很高。通常采用置换股骨头的方法治疗：**半髋关节置换**；对于以前能借助不超过一根手杖独立户外行走且身体条件允许的人，采用**全髋关节置换**（NICE CG124，2023年更新）。无移位骨折可用螺钉固定。
- **囊外**（转子间和转子下）骨折保留了股骨头的血供，采用固定治疗：大多数转子部骨折用滑动髋螺钉，转子下骨折用髓内钉。

NICE建议在入院当天或次日手术，由老年骨科医师共同管理，早期活动，并评估跌倒风险和骨健康。每一次脆性骨折都是一个警告：发生过一次的人再次骨折的风险很高。**骨折联络服务**负责识别这些人，并启动骨质疏松症的评估和治疗（[[musculoskeletal/bones-joints]]和[[geriatrics-palliative/falls]]）。

::: example 在家中跌倒 {#ex-hip}
一名84岁女性被发现倒在厨房地板上。她的右腿短缩并外旋。X线片显示右股骨颈移位型头下型（囊内）骨折。跌倒前她能拄手杖走到商店，独自生活。她有心房颤动，服用阿哌沙班。概述她的诊治。
::: solution
**立即处理**：镇痛（对乙酰氨基酚、谨慎使用阿片类药物，以及股神经或髂筋膜神经阻滞）、静脉补液，评估跌倒的原因（晕厥、心律失常、感染、卒中、药物）以及是否长时间卧地（压力性损伤、横纹肌溶解、低体温、脱水）。查血常规、肾功能、电解质、血型鉴定与抗体筛查、心电图和胸片。

**抗凝**：停用直接口服抗凝药，并按当地指南与麻醉科共同计划手术时机；不应使手术延误超过必要的时间（[[blood/thrombosis-anticoagulation]]）。

**手术**：在入院当天或次日。移位型囊内骨折缺血性坏死风险高，因此首选置换而不是固定。由于她能拄手杖独立户外活动，如果身体条件允许，可考虑全髋关节置换；否则行骨水泥型半髋关节置换。

**术后**：术后第一天开始活动，由老年骨科医师复查，预防谵妄，预防静脉血栓栓塞，注意营养，并计划出院。出院前她需要进行**跌倒评估**和**骨健康评估**；发生髋部脆性骨折后，她通常会接受骨质疏松症治疗。
:::
:::

### 儿童与儿童保护

儿童的骨更有弹性，骨膜厚，因此容易发生青枝骨折和隆突骨折，且愈合很快。生长板损伤必须识别出来，因为它可导致肢体不等长或成角畸形。大多数儿童骨折是意外造成的，但也有一些不是。应引起对**非意外伤害**担忧的特征包括：尚不会活动的儿童发生任何骨折、新旧不一的多处骨折、后肋骨折、婴儿干骺端“角状”骨折、损伤与病史或儿童发育水平不符，以及延迟就医。疑虑应按当地儿童保护程序上报（[[paediatrics/safeguarding]]）。

## 并发症 {#sec-complications}

并发症最好按时间来学习：最初数小时至数天内威胁肢体或生命的并发症，以及数周至数年后出现的并发症。

::: definition 骨折的并发症 {#def-complications}
**早期（数小时至数天）**

- **出血和休克**，尤其是骨盆骨折和股骨骨折。
- **动脉损伤**，例如膝关节脱位和股骨髁上骨折时的腘动脉损伤，或儿童肱骨髁上骨折时的肱动脉损伤。
- **神经损伤**：肱骨干骨折时的桡神经（腕下垂）、肩关节脱位和肱骨近端骨折时的腋神经，以及腓骨颈处的腓总神经（足下垂）。
- **急性骨筋膜室综合征**（见下文）。
- **脂肪栓塞综合征**：通常在长骨或骨盆骨折后24至72小时出现，表现为气促和低氧血症、意识模糊，以及上半身、结膜和口腔的瘀点样皮疹。
- **静脉血栓栓塞**，尤其是骨盆和下肢骨折后。
- **感染**，尤其是开放性骨折和手术后。
- 挤压伤或长时间卧地后的**横纹肌溶解**，有急性肾损伤的风险（[[renal/acute-kidney-injury]]）。

**晚期（数周至数年）**

- **延迟愈合**（愈合比预期慢）和**不愈合**（愈合已停止而未桥接）。骨痂丰富但活动过多时称为**肥大性**不愈合（需要稳定）；因生物学条件差而骨痂很少时称为**萎缩性**不愈合（需要植骨并改善血供）。
- **畸形愈合**：在异常位置愈合，导致畸形、短缩或关节负荷异常。
- **缺血性坏死（骨坏死）**：失去血供的骨死亡，典型部位是囊内骨折后的**股骨头**、**舟骨近极**和**距骨体**。
- 关节内骨折后的**创伤后骨关节炎**。
- **关节僵硬**和肌萎缩。
- **复杂性区域疼痛综合征**：损伤后出现与损伤不相称的疼痛、肿胀，以及皮肤颜色、温度和出汗的改变，常见于桡骨远端骨折后。
- 儿童骺板损伤后的**生长障碍**。
:::

### 骨筋膜室综合征

四肢的肌肉位于由坚韧、无弹性的筋膜包绕的骨筋膜室内。骨折、挤压或再灌注后，骨筋膜室内的肿胀使其压力升高。当骨筋膜室压力接近毛细血管压力时，肌肉和神经的血流就会停止，尽管大动脉仍然通畅、脉搏仍可触及。数小时内肌肉开始坏死。最常见的部位是胫骨骨折后的小腿，其次是前臂。

::: theorem 骨筋膜室内的灌注压 {#thm-compartment}
组织灌注取决于驱动血液流入的压力与组织内压力之差。对肌肉骨筋膜室而言，这用**压差（delta pressure）**表示：

$$\Delta P = \text{舒张压} - \text{骨筋膜室压力}.$$ {#eq-delta-p}

$\Delta P$低于约**30 mmHg**表明灌注不足，支持骨筋膜室综合征的诊断（这是英国骨科协会骨筋膜室综合征标准所用的阈值）。
:::

::: proof
血液沿压力梯度从小动脉经毛细血管流向小静脉。当组织压力升高时，薄壁的小静脉和毛细血管首先受压，静脉回流受阻，维持毛细血管开放所需的压力随之升高。用舒张压而不是平均动脉压留出了安全余量。压差比单独的骨筋膜室压力更有用，因为低血压患者在某个骨筋膜室压力下就可能失去灌注，而高血压患者却能耐受同样的压力。
:::

诊断主要依靠**临床**。最早、最可靠的特征是：

- **疼痛与损伤不相称**，尽管镇痛充分仍不断加重，阿片类药物需求常不断增加；
- 被动牵拉骨筋膜室内肌肉时**疼痛**（例如被动背伸足趾，检查小腿深后室和前室）；
- 骨筋膜室紧张、肿胀；
- 稍后，穿过该骨筋膜室的神经分布区出现感觉异常和麻木。

当患者不能可靠地报告疼痛时（麻醉或镇静状态、幼儿、神经阻滞后）才测量压力。治疗是**把所有敷料和石膏全长剖开直至皮肤**，使肢体保持在心脏水平（抬高肢体会降低灌注压），纠正低血压；一旦确诊，紧急对所有受累骨筋膜室行**筋膜切开术**。

::: warning 脉搏不是检查方法
可触及的脉搏、温暖的足部和正常的生命体征**不能**排除骨筋膜室综合征。足以杀死肌肉的骨筋膜室压力远低于动脉收缩压，所以大动脉仍在搏动。脉搏消失是晚期表现，到那时肌肉通常已经坏死。疼痛加重和被动牵拉痛才是需要行动的信号。区域神经阻滞和患者自控阿片镇痛可以掩盖疼痛，因此高风险患者需要定期、有记录的再评估。
:::

::: example 测量压力 {#ex-compartment}
一名19岁男性道路交通事故后在重症监护病房，处于镇静和机械通气状态。他的闭合性胫骨骨折8小时前用髓内钉固定。小腿紧张。血压105/58 mmHg。测得前室压力为40 mmHg。压差是多少？意味着什么？
::: solution
用[[#eq-delta-p]]：$\Delta P = 58 - 40 = 18$ mmHg。

这远低于30 mmHg，因此前室灌注不足。由于他处于镇静状态，无法评估通常的临床体征，而这正是测压最有价值的情形。他需要紧急对小腿四个骨筋膜室都行**筋膜切开术**。还应优化血压，因为舒张压偏低会降低$\Delta P$。术后注意横纹肌溶解和急性肾损伤。
:::
:::

::: quiz
一名25岁女性摔倒时手掌撑地。她解剖鼻烟窝有压痛，但腕部X线片（包括舟骨位）未见骨折。最合适的下一步是什么？
- [ ] 因X线片正常，安慰后让其离院
- [x] 固定腕部并安排进一步影像学检查（MRI；如无MRI则复查X线片）
- [ ] 安排紧急手术内固定
- [ ] 向腕关节内注射糖皮质激素
::: solution
舟骨骨折在最初的X线片上常常看不出来。舟骨的血供从远端进入，因此漏诊的腰部或近极骨折有近端骨块**不愈合**和**缺血性坏死**的风险。跌倒后鼻烟窝压痛时，应固定腕部并安排进一步影像学检查；有条件时首选MRI。手术仅用于移位骨折、近极骨折和不愈合。
:::
:::

::: history
骨折治疗是医学中最古老的部分之一。**希波克拉底**文集中的《论骨折》（约公元前400年）描述的牵引、复位和夹板固定，今天仍可辨认。1852年，荷兰军医**安东尼乌斯·马蒂森（Antonius Mathijsen）**引入了浸有熟石膏的绷带，使石膏有了现代的形式。**威廉·伦琴（Wilhelm Röntgen）**发现的X射线（1895年）使人们能看到骨折并检查复位情况。第一次世界大战期间，**罗伯特·琼斯（Robert Jones）**把他舅舅**休·欧文·托马斯（Hugh Owen Thomas）**设计的夹板用于开放性股骨骨折，这被认为使这类损伤的死亡率大幅下降。1939年，德国外科医师**格哈德·金切尔（Gerhard Küntscher）**在股骨中使用了髓内钉。1958年，包括**莫里斯·米勒（Maurice Müller）**在内的一群瑞士外科医师创立了AO（内固定研究学会），使内固定原则标准化。20世纪50年代在苏联，**加夫里尔·伊利扎洛夫（Gavriil Ilizarov）**发明了环形外固定架，并证明骨可以通过逐渐牵开而延长。
:::

## 后续内容

手术技术、固定器械和关节置换在[[surgery/orthopaedics]]中展开；作为整体的创伤患者见[[surgery/trauma]]；伤口感染见[[surgery/wounds-surgical-infection]]。脆性骨折与[[musculoskeletal/bones-joints]]和[[endocrine/bone-calcium]]中的骨质疏松症相关，也与[[geriatrics-palliative/falls]]中的跌倒相关。创伤后关节损伤引向[[musculoskeletal/osteoarthritis]]，脊柱骨折引向[[musculoskeletal/back-pain]]。

::: summary
- 按固定顺序描述骨折：骨与部位、形态、远端骨折块的移位、开放或闭合、伴随的关节损伤和骨质异常。
- 开放性骨折按Gustilo–Anderson分型；生长板损伤按Salter–Harris分型。轻微外力所致的骨折可能是病理性骨折。
- 二期愈合经历血肿、软骨痂、硬骨痂和重塑；一期愈合只在坚强加压固定时发生。
- 骨折端间应变（$\Delta L / L$）决定哪种组织能形成：骨只能耐受约2%。简单骨折需要绝对稳定；粉碎性骨折在相对稳定下愈合良好。
- 先处理患者再处理肢体，然后复位、固定、康复。开放性骨折需要早期使用抗生素，并由骨整形联合团队及时清创。
- 移位型囊内髋部骨折有缺血性坏死的风险，通常行置换；囊外骨折行固定。手术应在入院当天或次日进行，之后进行跌倒和骨健康评估。
- 骨筋膜室综合征依据与损伤不相称的疼痛和被动牵拉痛作出临床诊断；脉搏通常存在。$\Delta P$低于30 mmHg支持诊断。治疗是筋膜切开术。
- 晚期并发症包括不愈合、畸形愈合、缺血性坏死（股骨头、舟骨、距骨）、创伤后骨关节炎和复杂性区域疼痛综合征。
:::

## 习题

::: exercise 描述骨折 {level=1}
一名成人右前臂X线片（正位和侧位）显示一条横贯桡骨干中三分之一的单一骨折线。远端骨折块向外侧移位半个骨干宽度，并向掌侧成角15度（成角尖端指向掌侧）。皮肤完整。按[[#def-description]]中的顺序写一句描述。
::: solution
“右桡骨干中段（骨干）闭合性横形骨折，远端骨折块向外侧移位骨干宽度的50%，并有15度掌侧（尖端指向掌侧）成角。”完整的描述还应说明下尺桡关节是否破坏（Galeazzi损伤），因为单纯桡骨干骨折常伴有这种损伤，并应评价骨质。
:::
:::

::: exercise Salter–Harris分型 {level=1}
一名12岁儿童腕部骨折，骨折线沿桡骨远端生长板走行，然后穿过一小块三角形的干骺端骨块穿出。这是Salter–Harris哪一型？一般而言生长障碍的风险是高还是低？
::: solution
这是**Salter–Harris Ⅱ型**：穿过骺板后经干骺端穿出（干骺端骨块有时称为Thurston Holland骨块）。它是最常见的类型，生长障碍风险一般**较低**，但仍需适当复位和随访。
:::
:::

::: exercise 开放性骨折分型 {level=1}
一名45岁男性从梯子上跌落，胫骨远端开放性骨折，伤口清洁，长0.8 cm。另一名患者为高能量开放性胫骨骨折，骨膜广泛剥离，需要肌瓣覆盖骨。给出两者可能的Gustilo–Anderson分型，以及两者都适用的抗生素标准。
::: solution
第一例可能是**Ⅰ型**（伤口小于1 cm、清洁、低能量），但最终分型要在清创时确认。第二例是**ⅢB型**（骨膜剥离后骨外露，需要皮瓣覆盖）。两者都需要按当地方案尽快静脉使用抗生素，最好在受伤后一小时内。
:::
:::

::: exercise 压差 {level=2 check="22"}
一名前臂骨折患者血压130/70 mmHg，测得屈肌室压力为48 mmHg。计算$\Delta P$（单位mmHg），并说明它是否支持骨筋膜室综合征的诊断。
::: solution
$\Delta P = 70 - 48 = 22$ mmHg。这低于30 mmHg，因此支持诊断。结合临床所见，这是紧急筋膜切开术的指征。
:::
:::

::: exercise 骨折间隙中的应变 {level=2 check="25"}
一处用外固定架固定的骨折，间隙为2 mm，骨折块在负荷下移动0.5 mm。计算骨折端间应变的百分数（精确值）。按照Perren理论，在这种环境中哪些组织能够形成？
::: solution
$\varepsilon = 0.5/2 = 0.25$，即**25%**。这超过了骨（约2%）和软骨（约10%）的耐受限度，因此在这一应变下只有肉芽组织和纤维组织能够形成。要愈合，需要加强外固定架的刚度（或对间隙加压），使应变下降。
:::
:::

::: exercise 老年人的腕部损伤 {level=2}
一名66岁女性在冰面上滑倒，发生桡骨远端背侧移位骨折，经复位后打石膏。(a) 这一骨折说明她的骨骼有什么问题？(b) 在她结束骨折治疗之前应做什么？(c) 说出两种应提醒她注意的并发症。
::: solution
(a) 从站立高度跌倒导致的桡骨远端骨折是**脆性骨折**。它常是骨质疏松症的第一个征象，并预示以后会发生椎体和髋部骨折。

(b) 应把她转诊到**骨折联络服务**或相应机构，进行骨折风险评估（FRAX或QFracture，有指征时做DXA）、继发性病因检查，并考虑骨保护治疗，同时进行跌倒风险评估。

(c) 并发症包括**复位丢失**（在石膏内再移位）、**畸形愈合**、**石膏过紧**引起肿胀和神经受压（正中神经症状）、**僵硬**、拇长伸肌腱断裂，以及**复杂性区域疼痛综合征**。
:::
:::

::: exercise 第二天出现气促 {level=3}
一名23岁男性道路交通事故后发生闭合性股骨干骨折。入院36小时后，在牵引下等待手术时，他出现意识模糊和气促。未吸氧时血氧饱和度86%，体温38.1 °C，脉搏124次/分。胸部、腋窝和结膜可见瘀点。给出最可能的诊断、两个鉴别诊断以及处理原则。
::: hint
考虑长骨骨折后的时间，以及肺、脑和皮肤同时受累的组合。
:::
::: solution
最可能的诊断是**脂肪栓塞综合征**。它通常在长骨或骨盆骨折后24至72小时出现，表现为三联征：**呼吸窘迫（低氧血症）**、**神经系统改变（意识模糊）**以及上半身、结膜和口腔的**瘀点样皮疹**。发热和心动过速常见。来自骨髓的脂肪滴进入循环，堵塞小血管，并在肺内引起炎症反应。

鉴别诊断：**肺栓塞**（伤后制动）；**肺炎**或误吸；**脓毒症**；其他原因所致的**急性呼吸窘迫综合征**；**颅脑损伤**（解释意识模糊）；以及可能性较小的输血相关性肺损伤。

处理以**支持治疗**为主：高流量吸氧，必要时升级到通气支持（[[respiratory/respiratory-failure]]），维持液体平衡，并进行检查以排除其他诊断（CT肺动脉造影、胸片、血液检查）。**早期稳定骨折**（通常在患者情况允许时用髓内钉）可降低进一步栓塞的风险；肺功能受损时手术时机应由高年资医师决定。大多数患者在支持治疗下康复。
:::
:::

::: exercise 婴儿骨折 {level=3}
一名5个月大的女婴因活动右大腿时哭闹被带到急诊科。父亲说她前一天从沙发上滚落。X线片显示股骨干螺旋形骨折。(a) 什么让你担忧？为什么？(b) 下一步应做什么？(c) 说出一种可在婴儿期导致骨折、应予考虑的疾病。
::: hint
一个5个月大的婴儿能自己对股骨产生扭转力吗？考虑这个孩子的发育阶段。
:::
::: solution
(a) **尚不会活动的婴儿**发生股骨骨折是**非意外伤害**的强烈警示征象。螺旋形骨折意味着扭转力，而5个月大的婴儿翻滚时无法产生这种力，因此损伤与病史不符。延迟就医也可能有关。

(b) 治疗骨折和疼痛，并立即遵循**当地儿童保护程序**：通知高年资医师和儿童保护儿科团队，逐字记录病史，并安排推荐的检查，通常包括**全身骨骼检查**（寻找其他骨折，如新旧不一的后肋骨折或干骺端骨折）、皮肤检查、眼底检查以寻找视网膜出血，并考虑脑部影像学检查。其兄弟姐妹也可能需要评估（[[paediatrics/safeguarding]]）。

(c) **成骨不全**（Ⅰ型胶原缺陷；注意蓝巩膜、家族史和牙本质发育不全），以及**佝偻病**或早产儿骨病等代谢性骨病。考虑这些疾病是公正、全面评估的一部分；但它们并不能免除儿童保护评估的必要。
:::
:::
