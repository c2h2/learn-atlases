骨折是有生命的组织里一次“材料的失效”、而之后的一切——愈合、并发症、康复——都是同样三个问题：**骨在不在正确的位置、它在位置上稳不稳到能愈合、以及这位患者的生物学与身体准没准备好去完成愈合。**骨科的判断力，就是知道这三者中哪一个是“约束的那一环”。

本章涵盖骨折的生物学与分类、愈合、处理的原则、并发症、以及“主导临床实践的骨折”的识别清单。

## 失效与它的描述

::: definition 骨折的力学与分类 {#def-classification}
**材料的逻辑（骨那“各向异性的复合材料”——抗压强、抗拉与抗剪较弱——解释了经典的形态：弯曲造成的横行、扭转造成的斜行与螺旋、压缩与粉碎造成的碎裂、“肌腱打赢了骨”的撕脱、以及在“跑动或正步训练”中“低于失效强度的负荷重复数千次”造成的应力骨折、或在“骨质疏松或有动脉硬化的骨”这种“不足的骨”中造成的应力骨折——骨折的风险与骨的质量的背景见[[endocrine/bone-calcium]]、运动的生物放在[[physiology/muscle]]）；能量的转移与它所写下损伤的模式老年人低能量的跌倒落在髋与腕与椎体、高能量的摩托与自高处坠落的模式（连同它们“伴随损伤的搜寻”——严重创伤时对骨盆与脊柱及胸及头的清点——[[surgery/trauma]]、[[emergency-critical-care/major-incidents]]；以及儿童与被照护的成人身上“非意外伤”之问——“脱离了发育背景骨折的模式”、与“延迟就诊与说法不一致”的故事、以及那份“高于诊断的不适”的保护者的职责——[[paediatrics/safeguarding]]、对年长者的虐待的披露的伦理见[[medical-ethics-law/confidentiality]]）。分类作为沟通第一个问题“开放对闭合”——开放伤的分型与它“清创的时机与抗生素及破伤风”的不可违抗——见下文[[#def-open]]与[[infectious-diseases/healthcare-infections]]；“关节内对关节外”，因为关节面的“台阶与间隙”预示着创伤后的骨关节炎——[[musculoskeletal/osteoarthritis]]；儿童中的“完全对不完全”以及青枝与隆突环状的骨折、以及“骺”的分型带着它们的生长停滞的风险、以及“儿童重塑的宽容”会改变“可接受的对位”——[[paediatrics/acute-childhood-illness]]；以及经病灶的病理性骨折（骨髓瘤与转移与骨发育不良及佩吉特病——见[[blood/lymphoma-myeloma]]与下面的“寻找病理性骨折”。）**
:::

## 愈合

::: definition 骨折愈合的生物学 {#def-healing}
**继发的间接的愈合——默认的那一种血肿与炎症的阶段，其“先中性粒细胞、再巨噬细胞、再淋巴细胞”的次序与骨折血肿的机化、“软骨内成骨与膜内成骨”的软痂阶段带软骨母细胞软骨的模板、硬痂的矿化、以及遥远的重塑（骨小梁沿着应力的线条重新定向、耗时数月到数年——细胞的与信号的编排可与[[cell-biochemistry/signalling-cell-cycle]]、[[pathology/chronic-inflammation-repair]]、以及[[endocrine/bone-calcium]]里提到的形态发生蛋白与Wnt及核因子κB受体活化因子配路的信号一起读）；原发的直接的愈合——外科的变异（“刚性压迫的固定”让骨单位逐个直接跨过裂隙、没有骨痂、以及为什么“你看不见的那种骨痂”并不是更好的愈合、而是不同的力学——稳定“由植入物与骨共享”——[[surgery/orthopaedics]]）。各部分的生物学骨膜与骨髓的干细胞池、台“需要稳定之内的微动，而不是不稳定之内的动”的力敏感的骨痂、以及那个让“保护软组织的包被”本身就是一项愈合策略的“血管长入”的先决条件——而开放骨折与“界面假体置换”及“板对髓内钉”的选择都是愈合哲学的选择——外科入路的生物学见[[surgery/orthopaedics]]；以及吸烟尼古丁的血管收缩与氧与营养（蛋白与维生素C及维生素D及总能量与糖尿病的血糖控制、以及非甾的之争、以及激素与年龄——这份“可改变的愈合的投入”的清单——[[cell-biochemistry/nutrition]]、[[endocrine/diabetes-complications]]、[[pharmacology/adverse-reactions]]、戒烟见[[public-health/prevention-promotion]]）。预期的时间线与监测临床的愈合对影像的愈合对重塑、它们按骨与年龄与血供各有各的时钟、“第几周该出现骨痂”的复查的纪律、以及骨折门诊里“没有进展就触发CT或换钉或植骨”的检查、以及那份“写在记录里复出的与工作运动的时序”因为患者会问——[[clinical-skills/records-handover]]、[[physiology/muscle]]。**
:::

::: example 例“其实是内科收住”的髋部骨折 {#ex-nof}
一名81岁的妇女独居、用助行架行走、服9种药、有轻度的痴呆、没有胸痛但心电图出现“新的不齐的节律”、在厨房里平地跌倒、患肢短而外旋、不能负重、钠131、血红蛋白108、滤过率48、体温36.9。
::: solution
**在被排除之前就是股骨颈的骨折、并且要“点名”一个老年骨科的服务（[[musculoskeletal/fractures]]、[[surgery/orthopaedics]]）：即刻的集束是镇痛（带髂筋膜的阻滞与氧与液体与压疮的区域、以及“静脉血栓风险的计算、还不是治疗”、以及“不要让她在走廊的推车上分诊六小时”——[[emergency-critical-care/acute-assessment]]、[[blood/thrombosis-anticoagulation]]、[[surgery/anaesthesia-pain]]）；外科的决定（“移位关节内的做置换、不移位的做固定”的逻辑、以及为“在社区里能走的人对卧病且认知受损的人”而做的那个“低阈值植入物的选择”的谈话——同一个决定在口述记录里写成“假体的类型”）；“并行地、而不是在手术之前”进行内科的共同管理新发心律失常的“心率与抗凝与治病因”、以及“今天或明天手术、而不是下周”的决定、低钠的病因的清扫（包括噻嗪类、急性肾损伤补液的复查、谵妄的预防包、用药的对账、跌倒与骨的查因、以及那份“从入院就开始的出院去处的规划”——[[cardiovascular/arrhythmias]]、[[renal/water-sodium]]、[[geriatrics-palliative/delirium-dementia-care]]、[[geriatrics-palliative/polypharmacy]]、[[geriatrics-palliative/falls]]、[[endocrine/bone-calcium]]）；“值得向家属引用”的结局的数字（一年死亡率与“独立行走”的基线、以及为什么“早期手术与老年科的共同管理及康复与再骨折的预防”每一项都会移动它们——[[public-health/health-systems-economics]]、[[epidemiology-ebm/measuring-disease]]）；以及那项“必须在她出院后接住她”的骨折联络服务——她的第二个髋就是下一个质量指标——[[endocrine/bone-calcium]]。**

## 处理的原则与并发症

::: definition 那个“三问”的计划：复位、维持、活动 {#def-management}
**复位（恢复长度与旋转的对位及关节的吻合——用“镇静或血肿阻滞镇痛下闭合的整复”、对“切开并用解剖的钢板”、对“间接的髓内钉”、以及作为“损伤控制与粉碎的工作”的外固定架——时机的规则：脱位的“小时数”关乎“假体髋与原生肩的缺血性坏死的风险”、开放骨折的小时数关乎感染、肿的肢体骨筋膜室的风险——[[surgery/orthopaedics]]、[[#def-open]]、以及急诊复位的“清醒镇静呼吸道的安全”——[[emergency-critical-care/airway-ventilation]]）；维持（石膏与夹板与支具、对钢板与髓内钉与外固定架、以及每种植入物“分担与不分担多少负荷”、以及它日后“取出与应力遮挡与感染与植入物失效”、以及金属与磁共振的问题——植入物的那几行见[[surgery/orthopaedics]]、力学见[[musculoskeletal/bones-joints]]、围手术期的“抗凝的桥接”见[[blood/haemostasis-bleeding]]与[[surgery/perioperative-care]]）；活动（康复的契约——“关节面的保护对僵硬的预防”，配上控制活动的方案、“写清楚并被复述的负重状态”、以及助行器与职业治疗与物理治疗的处方、以及“对侧肢体与核心与信心与居家的运动”的规划、以及被打包进同一次门诊跌倒的预防与骨及吸烟与营养的干预——[[physiology/muscle]]、[[geriatrics-palliative/falls]]、[[gastrointestinal/clinical-nutrition]]）。随访的系统（骨折门诊与石膏的复查与系列的X线的方案、以及不愈合的路径、以及“植入物取出”的问题、以及“驾驶与重返工作与运动的证明”的往来——[[clinical-skills/records-handover]]、驾驶适格的指导见[[endocrine/diabetes-complications]]的那几行）。**
:::

::: definition 早发与晚发的并发症 {#def-complications}
**早期的、局部的骨筋膜室综合征它完整的逻辑在[[musculoskeletal/bones-joints]]；脱位或关节内的碎块造成的关节的损伤；在“血供的解剖预言了灾难”处的缺血性坏死——股骨颈与头、舟骨的近极、距骨、胫骨平台——带着“保头对置换”的后果——[[surgery/orthopaedics]]，而缺血性坏死的鉴别镰状细胞与激素与酒精见[[blood/haemoglobin-disorders]]、[[endocrine/adrenal]]、[[psychiatry/substance-use]]；神经与肌腱的损伤原发的或医源的——在夹板固定之前把它们记录下来——腋神经在肩、桡神经在肱骨、腓总神经在腓骨小头、以及急性的腕管——[[nervous-system/motor-systems]]、[[anatomy/back-upper-limb]]、[[anatomy/lower-limb]]；以及血管的损伤（膝的脱位与骨盆及“髁上”的肢体——[[surgery/vascular-urological-surgery]]）。早期的、全身的（长骨与骨盆骨折后的脂肪栓塞综合征、带着“缺氧与意识模糊与瘀点”的三联、支持性通气的照护、以及“早期固定能预防”的论证——[[respiratory/respiratory-failure]]、[[surgery/trauma]]；下肢固定与髋及骨盆及大的骨创伤之后的静脉血栓、带着那套“按风险分层的预防”的算术——[[blood/thrombosis-anticoagulation]]、[[surgery/perioperative-care]]；肺炎与压疮及去适应、横纹肌溶解的急性肾损伤、以及年长的骨折患者中的谵妄与药物的毒性——[[geriatrics-palliative/delirium-dementia-care]]、[[renal/acute-kidney-injury]]、[[respiratory/respiratory-infections]]）。晚发的畸形愈合与不愈合——“机械的稳定与生物学与机械的打击与感染”的理由，以及“换钉与植骨与生物的刺激”答案——[[#def-healing]]；慢性的骨髓炎，带着它“死骨与包壳与窦道”的解剖、糖尿病足与人工关节的变异、以及“长程的按培养定向的抗生素与清创的外科”这一配对——[[microbiology/bacteria]]、[[endocrine/diabetes-complications]]、[[surgery/orthopaedics]]；每一个关节内的台阶都要付出的“创伤后的骨关节炎”——[[musculoskeletal/osteoarthritis]]；以及复杂的局部疼痛综合征——不成比例的疼痛与触诱发痛与水肿与出汗及颜色的改变，带着“早期控制疼痛与活动它、避免失用”的逻辑，以及那份“诊断标准的现实”它是一个临床的诊断、既不能靠影像确诊、也不能靠影像排除——[[nervous-system/headache-pain]]。 {#def-open-link}**
:::

::: definition 开放骨折与“撕脱伤相邻”的软组织急症 {#def-open}
**为什么开放骨折会重排一整天（皮肤是一个器官：与外界相通把一次机械的损伤变成一个“污染、干燥与感染”的问题、而它的证据基础是“伤口的清创与照射”、不只是骨科的事——[[infectious-diseases/healthcare-infections]]、[[microbiology/bacteria]]）；最初几小时的集束（尽早的广谱抗生素、并按“土壤与农场及木头及水”的变异调整、以日计而不是以周计、以及对照“有记录的病史”核查破伤风的加强或免疫球蛋白——[[public-health/vaccination-programmes]]、梭菌的邻居见[[microbiology/viruses]]；拍照并取出异物、用浸湿生理盐水的无菌敷料与夹板、以及那两个“不要在急诊探查伤口、也不要自己缝合伤口”的决定——[[emergency-critical-care/acute-assessment]]；以及“手术室的冲洗与清创的时钟”、配“第二次探查的培养与切除”的纪律、以及骨骼的稳定次序——[[surgery/orthopaedics]]、[[surgery/perioperative-care]]）。软组织的覆盖之问撕脱与挤压及“骨筋膜室的相邻”的损伤，在那里整形的外科的决策树是“活力与损伤的带及皮瓣对植皮对负压对二期愈合”、以及那场所谓“截肢对保肢”的谈话（带着它的功能的评分与“早期义肢的规划”的诚实——[[surgery/wounds-surgical-infection]]、[[surgery/orthopaedics]]；那个决定“这条肢体是资源还是负担”的“毁损的肢体团队”的时机；以及“保肢或截肢”之后漫长的心理与职业的恢复、配同伴的支持与义肢——[[psychiatry/mood-disorders]]、康复服务的现实见[[public-health/health-systems-economics]]）。**
:::

::: example 处“只是摔了一跤”的腕 {#ex-scaphoid}
一名19岁在踢足球时以伸出的手着地；鼻烟窝有压痛、沿拇指轴向挤压时痛；最初三位的腕部X线正常；他想在考试之前“把它了结”。
::: solution
**在被排除之前就是舟骨的损伤、因为漏掉的那一处会是一场诉讼与一辈子的腕痛（[[musculoskeletal/fractures]]、[[surgery/orthopaedics]]）：解释了一切的那段解剖（逆行的血供、以及“近极的不愈合与缺血性坏死”的后果、以及为什么这是那处“按怀疑治疗”的骨折——用固定与重复的影像、或现在就做磁共振或CT、而不是“安心加复查”——生物学的部分见[[#def-healing]]、[[clinical-skills/medical-imaging]]）；共同的决定（一张正常的X线并不能排除、“石膏对夹板对早期磁共振定案的路径”在时间与舒适上的代价、以及那份恢复运动的计划、以及“考试是两周，而不愈合是两年”这个框架——[[clinical-skills/communication]]、[[physiology/muscle]]）；后续的规则（被记录的神经血管与活动的基线、石膏的复查、驾驶、以及“对抗性运动的许可”的时序、以及为那位依从的运动员“经皮的螺钉固定”这个选项的转诊——[[surgery/orthopaedics]]、[[clinical-skills/records-handover]]）；以及安全网句“再次受伤或鼻窝持续疼痛就回来”的指示（给出一个日期，不是一种感觉、以及那个放在脑后的问题：“一个孩子身上有多处解释不了的伤、而病史一直在变”——[[paediatrics/safeguarding]]）。**
:::

::: example 出现呼吸困难的股骨 {#ex-fat-embolism}
在股骨干骨折与“扩髓的髓内钉”之后的第2天、一名27岁变得意识模糊、呼吸快而缺氧、胸部出现瘀点性的皮疹；体温38.8、心率128、格拉斯哥13、血小板在下降、胸片弥漫的异常。
::: solution
**在“经典的时钟”上的脂肪栓塞综合征（长骨或骨盆骨折或“器械的操作”之后24到72小时——它是一个临床的诊断、不是实验室的诊断——[[#def-complications]]、[[surgery/trauma]]）：一步“气道到暴露的评估、升级、并请重症监护”，同时并行地清扫鉴别——肺炎与误吸与肺栓塞及早期的呼吸窘迫、以及输血反应、以及来自伤口的脓毒症——[[emergency-critical-care/resuscitation]]、[[respiratory/respiratory-infections]]、[[blood/transfusion]]、呼吸窘迫的背景见[[respiratory/gas-exchange]]；处理是支持性的通气肺保护策略与血流动力学、并交代病因、而“激素的预防”这场争论要以“争论”的姿态说出——[[emergency-critical-care/airway-ventilation]]、[[emergency-critical-care/critical-care]]；给这个单元的预防的教训——“早期的确定性固定与限制反复的整复、以及尽量减少不必要的扩髓、以及充分的复苏”作为外科策略的证据（[[surgery/orthopaedics]]、[[epidemiology-ebm/randomised-trials]]）；以及家属与事件的沟通“这可以伤到任何一个遇到它的人”、以及那份“带预警触发器的、被记录的恶化的时间线”——它抓住了这次、或者本该抓住——[[clinical-skills/patient-safety]]、[[clinical-skills/communication]]。**

::: example 农夫、马蹄铁与胫骨 {#ex-open-tibia}
一名39岁的农夫被一匹挽马踢穿了靴子：胫骨前内侧面一处4厘米的不整齐的伤口、骨可见、第10小时白细胞在上升、破伤风的状态“不清楚、也许是儿童期”、伤口发黑并被土壤污染；X线显示一处节段的胫骨骨折、伴一处与伤口相通骨皮质的窗。
::: solution

## 处境中的骨折：你继承的那份流行病学

今天骨折的工作量是一种“老龄化与活动度的混合”、更多由人口学、而不是由任何单一干预塑造：脆性骨折的流行（髋、椎体、桡骨远端、肱骨近端、骨盆）乘在“更长的寿命加上晚发绝经后的骨丢失”之上、带着“跌倒风险”的聚类（多重用药与视力与肌少症与住房）、以及每一份审计都测得出的那个“骨质疏松治疗的缺口”[[endocrine/bone-calcium]]、[[geriatrics-palliative/falls]]、[[geriatrics-palliative/polypharmacy]]、[[nervous-system/sensory-systems]]；年轻人高能量的那一股道路交通伤、工作、运动、带着它与“多发伤及颅脑创伤及肢体损伤”的交叉[[surgery/trauma]]、[[nervous-system/motor-systems]]；应力骨折的那一股、它的处理是一场“负荷与能量可得性”的谈话、需要与运动及内分泌及营养的团队一起做——那个“女性运动员的三联征与相对的能量不足”的骨健康的叙事、若被漏掉就以早发的骨质疏松告终[[gastrointestinal/clinical-nutrition]]、[[endocrine/reproductive-endocrinology]]、[[physiology/muscle]]；以及儿童骨折的那一股、在那里“骺的生物学与重塑的宽容与对保护的警惕”定义了胜任[[paediatrics/acute-childhood-illness]]、[[paediatrics/safeguarding]]。每一股都有一根比任何植入物都更强大的预防的杠杆——骨折的门诊是一间“假装成外科服务预防的门诊”[[public-health/prevention-promotion]]。

## 通向何处

愈合背后的骨生物学在[[musculoskeletal/bones-joints]]；外科的技术与植入物在[[surgery/orthopaedics]]；创伤的初评在[[surgery/trauma]]；脆性骨折预防的系统在[[endocrine/bone-calcium]]；围手术期的抗凝在[[blood/thrombosis-anticoagulation]]；静脉血栓的预防也在同一处；康复的生理在[[physiology/muscle]]。

::: history
**骨折的处理比医学的其他各章都古老——埃德温·史密斯纸草的外科病例与环锯、希波克拉底的牵引与复位以及那双“熟练的手”的理想、以及安布鲁瓦兹·帕雷用“动脉的结扎与敷料”把截肢的手术台变得人性化；约翰·亨特实验植骨的生物学、以及“骨痂究竟是炎症还是修复”场长达数个世纪的争论；铁路时代的骨折大爆发、以及骨折门诊的诞生与托马斯的夹板、以及在利斯特使“内固定”变得可以幸存之前那场关于“切开复位”的辩论；套“压迫与稳定的固定”的学会的奠基原则、与“生物学接骨板”的反革命；从昆彻到“扩髓的交锁钉”的髓内钉的血脉；髋部骨折的“骨科加老年医学”的模型、以及它在“国家髋部骨折审计”时代产出的结局数据、以及它输出到全世界的“审计驱动的早期手术与共同管理”的标准；以及现代关于“时机与冲洗的压力及伤口的关闭”的开放骨折的证据之战——它教的是：连最古老的那台手术也是一个“在被检验的假说”（[[epidemiology-ebm/randomised-trials]]、[[public-health/health-systems-economics]]）。**
:::

::: summary
- 一处骨折由机制、位置、形态、稳定性、关节与软组织、以及患者来描述——按这个临床的次序，不是按字母。
- 愈合是“服从力学的生物学”：耐受的微动之内的稳定、被保护的血供、以及被优化的宿主的因素——吸烟、营养、血糖、负荷。
- 用“能买到足够的稳定”的最小损害的路径复位；用“能维持它”的最少的植入物维持；然后活动“计划可以腾出来”的关节。
- 危险的日子在早期——骨筋膜室与血管、脂肪栓塞、静脉血栓、感染；危险的月份在晚期——不愈合与缺血性坏死、骨关节炎、复杂性局部疼痛综合征、以及“下一块骨的骨质疏松”。
- 每一处脆性骨折都是一个“骨健康的诊断”加一个“跌倒的诊断”、只是裹了一层石膏；固定是其中容易的部分。
:::

**修正的脊柱——一个“骨折的联络服务”带一位具名负责人的护士、一份来自每一条骨折路径的“抓取的清单”、出院之前或30天之内的“骨折风险的评估与骨密度的检查与化验与开始治疗”、以及把“第二次骨折的比率”作为公开的指标（[[endocrine/bone-calcium]]、[[public-health/screening]]、[[#def-management]]）；证据——二级预防的效应量、以及“药物的依从性与输液的门诊的解决方案”、以及那份“治这个人、不治这个髋”的试验与观察的基础（[[epidemiology-ebm/randomised-trials]]、[[epidemiology-ebm/observational-studies]]）；公平与伦理的那一层——贫困与性别及族裔的治疗的缺口、为痴呆患者进行“风险削减的谈话”时的能力与同意、以及“检查的成本对再次骨折的成本”与那份委托的论证、以及关于“谁不应该被治疗”的一级预防边界的辩论（[[public-health/determinants-inequalities]]、[[medical-ethics-law/consent-capacity]]、[[medical-ethics-law/justice-resources]]、[[public-health/health-systems-economics]]）；以及治理的环路——“医师实际开了什么对联络服务的方案”的审计、以及智能的重复处方与登记的数据采集、好让这个系统能学习——[[clinical-skills/records-handover]]、[[public-health/prevention-promotion]]。**
