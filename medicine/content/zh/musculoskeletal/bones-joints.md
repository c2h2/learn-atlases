人们常把骨与关节想象成身体里没有生命的支架：只有在断裂或磨损时才值得关注的支柱和铰链。这种看法错得很有临床意义。骨是一种活组织，不断地被移除和重建；它储存着人体99%的钙，并对激素、药物、负荷和疾病作出反应。滑膜关节本身就是一个器官：它有可以发炎的衬里、可以抽取化验的液体，以及难以自我修复的软骨表面。

本章为整个课程打下基础。内容包括骨的结构及其重建方式、钙与骨转换的生物化学、骨量在一生中的变化、滑膜关节的解剖与生理，以及用来判断疼痛关节问题所在的体格检查和辅助检查。各个肢体的解剖见[[anatomy/lower-limb]]和[[anatomy/back-upper-limb]]；钙的内分泌调控在[[endocrine/bone-calcium]]中有深入讲述。

## 作为活组织的骨 {#sec-bone}

骨是一种复合材料。其干重约三分之二是矿物质，即一种称为羟基磷灰石的磷酸钙晶体，提供刚度和抗压能力；其余大部分是蛋白质，主要是Ⅰ型胶原，提供韧性以及抗拉伸和抗弯曲的能力。粉笔坚硬但脆，绳子坚韧但软；骨兼具两者之长。干扰其中某一成分的疾病正好说明这一点：成骨不全时，Ⅰ型胶原有缺陷，骨很容易折断；而骨软化症时，矿化不良的骨会弯曲变形。

::: definition 骨的结构与骨细胞 {#def-bone}
**皮质骨（密质骨）**构成每块骨致密的外壳和长骨骨干。它约占骨骼总量的80%，由**骨单位**组成：骨单位是围绕中央管（哈弗斯管）排列的同心骨板圆柱，中央管内有血管和神经通过。

**小梁骨（松质骨）**是椎体、骨盆和长骨两端内部由薄板和细杆构成的网格。它约占骨骼总量的20%，但表面积大得多，因此重建更快，对疾病和治疗的反应也更早。

三种细胞维持着骨：

- **成骨细胞**来源于间充质干细胞。它们分泌**类骨质**（未矿化的基质，主要是Ⅰ型胶原），然后指导其矿化。它们释放碱性磷酸酶，因此骨形成活跃时血清**碱性磷酸酶（ALP）**升高。
- **骨细胞**是被埋入基质中的成骨细胞。它们是数量最多的骨细胞，通过穿行于细小骨小管中的长突起彼此相连。它们感受机械应变并向其他细胞发出信号，部分是通过抑制骨形成的蛋白**硬骨抑素**。
- **破骨细胞**是来源于单核-巨噬细胞系的大型多核细胞。它们附着于骨表面，封闭出一个空间，用酸溶解矿物质，用组织蛋白酶K等酶降解胶原。

**骨膜**是覆盖骨外表面的纤维膜，其内层含有成骨细胞，对骨折愈合至关重要（[[musculoskeletal/fractures]]）。
:::

### 骨重建

在整个成年期，小块旧骨不断被移除和替换。完成这项工作的是**基本多细胞单位（BMU）**：一组破骨细胞，随后是一组成骨细胞。任一部位的过程分四个阶段：

1. **激活**：破骨细胞前体被募集到某个表面，这往往是骨细胞发出微损伤信号的地方。
2. **吸收**：破骨细胞在约两到四周内挖出一个凹坑（小梁骨）或隧道（皮质骨）。
3. **逆转**：表面被清理并做好准备。
4. **形成**：成骨细胞用类骨质填充腔隙，类骨质随后在数月内矿化。

骨重建修复疲劳损伤，使骨骼适应所承受的负荷，并在需要时释放钙。成人骨骼每年约有十分之一被更新。

关键的分子开关是**RANK–RANKL–OPG系统**。成骨细胞和骨细胞表达**RANKL**，它与破骨细胞前体上的受体**RANK**结合，驱使其成熟并进行骨吸收。它们还释放**骨保护素（OPG）**，这是一种诱饵受体，可以把RANKL吸附掉。RANKL与OPG的比值决定骨吸收的多少。雌激素、甲状旁腺激素（PTH）、糖皮质激素和炎症细胞因子都部分通过这一比值发挥作用。

::: theorem 骨重建平衡 {#thm-remodelling}
骨量随时间的变化取决于两个量：**每个BMU内的平衡**（同一部位形成的骨减去吸收的骨）和**激活频率**（单位时间内新启动的BMU数目）。当每个BMU的平衡为负时骨量丢失，而活跃的BMU越多，丢失越快。
:::

::: proof
在健康的年轻成人中，每个BMU几乎恰好补回它所移除的骨，平衡接近于零，此时激活频率无关紧要。随着年龄增长，成骨细胞的效能下降，每个BMU都留下少量亏空。绝经后雌激素下降使RANKL升高、激活频率增加，于是同时工作的、略呈负平衡的单位大大增多，骨量迅速丢失，尤以小梁骨为甚。糖皮质激素主要通过抑制成骨细胞起作用，使每个单位的平衡更加偏负。这一原理也解释了药物的作用方式。**双膦酸盐**（如阿仑膦酸和唑来膦酸）与骨矿物质结合并被破骨细胞摄取，从而减少骨吸收和激活频率。**地舒单抗（denosumab）**是抗RANKL抗体，总体效果相同。**特立帕肽（teriparatide）**是间歇性每日给药的PTH片段，刺激成骨细胞，使骨形成超过骨吸收。**罗莫佐单抗（romosozumab）**阻断硬骨抑素，既增加骨形成又减少骨吸收。
:::

机械负荷同样重要。骨细胞感受应变，承受负荷的骨得以维持或增强，而不承重的骨则会丢失。处于微重力中的宇航员、卧床的人和打石膏的肢体都会迅速丢失骨量。骨会根据所承受的负荷调整其结构，这一观念通常称为**沃尔夫定律（Wolff's law）**。

### 钙、磷与骨的生物化学

血清钙由三种激素维持在狭窄的范围内：**PTH**通过增加骨吸收、减少肾脏钙丢失并刺激维生素D活化来升高血钙；**骨化三醇**（1,25-二羟维生素D）增加肠道对钙和磷的吸收；**降钙素**在人体中的作用则小得多。维生素D在紫外线B照射下由皮肤合成或从食物摄入，先在肝脏羟化为25-羟维生素D（评估维生素D状态时测定的就是这种形式），再在肾脏羟化为骨化三醇。详细内容见[[endocrine/bone-calcium]]和[[renal/potassium-calcium-phosphate]]。

血清钙约45%与白蛋白结合。白蛋白降低时，即使具有生理活性的离子钙正常，总钙也会下降。因此许多实验室报告**校正钙**。常用公式为

$$\text{校正 Ca} = \text{总 Ca} + 0.02 \times (40 - \text{白蛋白})$$ {#eq-adjusted-ca}

其中钙的单位为mmol/L，白蛋白为g/L。各地公式略有不同；当结果关系重大时，血气分析仪测定的离子钙更为可靠。

::: example 并不低的低钙 {#ex-calcium}
一名74岁女性因肺炎入院，总钙为2.02 mmol/L（参考范围2.20–2.60），白蛋白为26 g/L。她有低钙血症吗？
::: solution
用[[#eq-adjusted-ca]]：校正钙$= 2.02 + 0.02 \times (40 - 26) = 2.02 + 0.28 = 2.30$ mmol/L。

这在参考范围之内。总钙偏低可由白蛋白偏低解释，而低白蛋白在急性疾病中很常见。仅凭这一点她不需要补钙。如果有低钙血症的症状（麻刺感、肌肉痉挛、QT间期延长），测定离子钙即可明确。
:::
:::

常见的代谢性骨病在常规血液检查中呈现不同的模式。下表是典型表现的指南而非规则；实际患者往往同时存在不止一种过程。

| 疾病 | 钙 | 磷 | ALP | PTH | 要点 |
|---|---|---|---|---|---|
| 骨质疏松症 | 正常 | 正常 | 正常 | 正常 | 依据骨密度而非血液检查诊断 |
| 骨软化症（维生素D缺乏） | 降低或正常 | 降低 | 升高 | 升高 | 矿化不良；骨痛、近端肌无力 |
| 原发性甲状旁腺功能亢进症 | 升高 | 降低或正常 | 正常或升高 | 升高或不适当地正常 | 通常为甲状旁腺腺瘤 |
| 骨佩吉特病 | 正常 | 正常 | 升高（常显著） | 正常 | 骨重建紊乱且过度 |
| 骨转移 | 正常或升高 | 正常 | 常升高 | 血钙升高时降低 | 寻找原发肿瘤 |

## 一生中的骨量 {#sec-bone-mass}

骨量在儿童期和青春期增加，在二十多岁时达到**峰值**，维持数年大致稳定，然后下降。峰值骨量主要由遗传决定，但营养、体力活动、青春期时间和儿童期疾病都有影响。女性的峰值低于男性，并在绝经前后及绝经后数年内快速丢失骨量；男性丢失较慢。结果是到老年时，许多女性和相当一部分男性的骨骼稍受外力就会骨折。

::: definition 骨质疏松症与脆性骨折 {#def-osteoporosis}
**骨质疏松症**是一种以骨量低下和骨微结构破坏为特征、导致骨脆性增加和骨折风险升高的骨骼疾病。

骨密度（BMD）用**双能X线吸收法（DXA）**测定，通常测髋部和腰椎。结果用**T值**表示，即与同性别健康年轻成人均值相差的标准差数：

$$T = \frac{\text{测得 BMD} - \text{年轻成人平均 BMD}}{\text{年轻成人 SD}}$$ {#eq-tscore}

按世界卫生组织的定义（用于绝经后女性和50岁及以上男性）：

- 正常：$T \ge -1.0$；
- 低骨量（骨量减少）：$-2.5 < T < -1.0$；
- 骨质疏松症：$T \le -2.5$；
- 严重（确立的）骨质疏松症：$T \le -2.5$且有一处或多处脆性骨折。

**脆性骨折**是指从站立高度或更低处跌倒所致、或无明确外伤的骨折。典型部位是椎体、髋部、桡骨远端和肱骨近端。
:::

骨密度只是骨折的预测因素之一。年龄、既往骨折、使用糖皮质激素、父母髋部骨折史、吸烟、饮酒、低体重、类风湿关节炎和跌倒都独立增加风险。**FRAX**（由设在谢菲尔德的世界卫生组织合作中心开发）和**QFracture**等工具综合这些因素，估算10年内主要骨质疏松性骨折和髋部骨折的概率。在英国，国家骨质疏松指南小组（NOGG）基于FRAX发布干预阈值；NICE建议对65岁及以上女性、75岁及以上男性以及有危险因素的较年轻者评估骨折风险。

::: example 解读DXA结果 {#ex-tscore}
一名68岁女性在湿滑地面上滑倒后腕部骨折，接受DXA检查。她的股骨颈BMD为0.550 g/cm²。扫描仪所用的参考人群中，年轻成人均值为0.858 g/cm²，标准差为0.120 g/cm²。计算她的T值并作出解释。
::: solution
用[[#eq-tscore]]：

$$T = \frac{0.550 - 0.858}{0.120} = \frac{-0.308}{0.120} \approx -2.57.$$

T值$-2.6$（保留一位小数）低于$-2.5$，按世界卫生组织定义她的股骨颈存在骨质疏松症。由于她已有一次腕部脆性骨折，这属于严重（确立的）骨质疏松症。她的骨折风险很高，在排查继发性病因（例如血钙、维生素D、肾功能、甲状腺功能，必要时筛查骨髓瘤）之后，通常会给予骨保护治疗。跌倒评估与药物同样重要，因为大多数髋部骨折是在跌倒之后发生的（[[geriatrics-palliative/falls]]）。
:::
:::

## 滑膜关节 {#sec-joint}

关节按连接骨的组织分类。**纤维连结**（如颅缝）几乎不能活动。**软骨连结**（如耻骨联合和椎间盘）可稍有活动。**滑膜关节**可以自由活动，大多数关节疾病都发生在这里。

::: definition 滑膜关节 {#def-joint}
**滑膜关节**由以下部分组成：

- **关节软骨**：覆盖骨端、厚数毫米的透明软骨。它没有血管、神经和淋巴管。其细胞——**软骨细胞**——数量稀少，位于由**Ⅱ型胶原**和**蛋白聚糖**（主要是**聚集蛋白聚糖**）构成的基质中。聚集蛋白聚糖带有大量负电荷，吸收水分，使软骨像充水的垫子一样抵抗压缩。
- **软骨下骨**：软骨下方的骨板，吸收负荷，神经分布丰富。
- **关节囊**：把骨连在一起的纤维套，由**韧带**加强。
- **滑膜**：衬于关节囊内面（但不覆盖软骨）的薄膜。其细胞清除碎屑并分泌滑液的成分。正常滑膜仅有几层细胞厚；在炎症性关节炎中会显著增厚。
- **滑液**：少量黏稠液体，本质上是血浆的滤出液，富含**透明质酸**和**润滑素**。它润滑关节面，并为自身没有血供的软骨细胞提供营养。
- 有些关节还有关节内结构，例如膝关节的半月板和交叉韧带。
:::

这种设计带来两个后果。第一，由于软骨没有血供且细胞稀少，其损伤很难愈合；这是骨关节炎的基础（[[musculoskeletal/osteoarthritis]]）。第二，由于滑膜是血管丰富、细胞众多的组织，它是炎症性关节炎（[[musculoskeletal/inflammatory-arthritis]]）和关节感染的主要靶点。关节疼痛可以来自骨、软骨-骨交界、滑膜、关节囊、韧带、关节周围的肌腱和滑囊，或者是神经把疼痛牵涉到关节。

肌腱、韧带和滑囊值得单独一提。**肌腱**把肌肉附着于骨；肌腱止于骨的连接处称为**附着点**，该处的炎症（附着点炎）是脊柱关节炎的标志。**滑囊**是减少摩擦的充液囊，例如髌骨前方的髌前滑囊；滑囊炎可类似关节炎，但肿胀局限，关节活动常不受影响。

## 肌肉骨骼系统的检查 {#sec-exam}

大多数肌肉骨骼疾病的诊断依靠病史和体格检查。血液检查和影像学用于完善诊断或排除危险的其他可能。

### 病史

首要问题是：问题是**炎症性**的还是**机械性**的？答案把类风湿关节炎、痛风和脊柱关节炎等疾病与骨关节炎、损伤以及大多数腰痛区分开来。

::: definition 炎症性与机械性关节痛 {#def-inflammatory}
**炎症性关节痛**通常在休息后加重、活动后减轻。伴有**较长时间的晨僵**（通常超过30分钟，常超过1小时）、关节软组织肿胀，有时伴乏力、体重下降或发热等全身表现。炎症标志物常升高。

**机械性关节痛**在活动时加重，休息可缓解。晨僵短暂（通常不足30分钟），肿胀多为骨性或由少量积液所致。没有全身表现，炎症标志物正常。
:::

第二个问题是**模式**：

- **受累关节数**：一个（单关节炎）、二至四个（少关节炎）或五个及以上（多关节炎）。
- **分布**：小关节还是大关节；对称还是不对称；上肢还是下肢；是否累及脊柱。
- **病程**：突发（数小时，如痛风或感染）、亚急性（数天至数周）或慢性（数月）。
- **伴随表现**：皮疹、银屑病、眼部炎症、腹泻、尿道炎、口腔溃疡、雷诺现象、近期感染或旅行。

功能与诊断同样重要。要询问患者现在做不了什么：能否工作、穿衣、上楼和照顾自己，以及希望重新能做什么。

### 体格检查

**GALS**（步态、上肢、下肢、脊柱）之类的快速筛查检查只需几分钟，能发现大多数重要异常。筛查中发现异常的关节再按**望、触、动**的顺序详细检查，然后做特殊试验：

- **望**：肿胀、发红、畸形、肌萎缩、瘢痕，以及皮肤或指甲改变（银屑病斑块、甲凹点）。
- **触**：皮温、压痛和肿胀的性质：软而有揉面感（滑膜炎）、有波动感（积液）或坚硬（骨性膨大，如骨关节炎）。横向挤压掌指（MCP）关节或跖趾（MTP）关节是筛查小关节滑膜炎的有用方法。
- **动**：先主动活动关节，再被动活动。主动活动受限而被动活动正常，提示肌肉、肌腱或神经问题；两者均受限提示关节本身病变。注意摩擦音和活动末端的疼痛。

各部位检查的细节见[[clinical-skills/physical-examination]]。

::: example 两双手 {#ex-hands}
两人因手痛来到同一个门诊。

A是一名63岁女性，指尖关节酸痛两年，园艺劳动后加重，晨僵持续10分钟。几个远端指间（DIP）关节和拇指根部有坚硬的肿大。

B是一名41岁女性，双手指节和腕部疼痛肿胀8周。每天早晨僵硬两小时，拧瓶盖困难。MCP关节柔软、肿胀、压痛，横向挤压时疼痛。

两人各自最可能的诊断是什么？各自的问题有多紧急？
::: solution
A具有**机械性**特征（活动后疼痛、晨僵短暂），并有手骨关节炎典型分布的**骨性**肿大：DIP关节（赫伯登结节）和拇指根部的第一腕掌关节。诊断无需血液检查。处理不紧急，以锻炼、手部治疗和外用药为主（[[musculoskeletal/osteoarthritis]]）。

B具有**炎症性**特征（晨僵时间长、软组织肿胀），表现为累及MCP关节和腕关节的**对称性小关节多关节炎**。这是持续性滑膜炎，最可能的病因是类风湿关节炎。她需要**紧急转诊风湿科**，因为早期改善病情治疗可防止关节破坏。可以送检血液（类风湿因子、抗CCP抗体、CRP、血沉），但不应因此延误转诊（[[musculoskeletal/inflammatory-arthritis]]）。

两者的区分依据的是病史和肿胀的触感，而不仅仅是年龄。
:::
:::

### 血液检查

**炎症标志物**显示是否存在全身性炎症，但不能说明部位或原因。

- **C反应蛋白（CRP）**由肝脏在白细胞介素-6刺激下合成。炎症刺激后数小时内升高，炎症消退后迅速下降，因此适合追踪急性变化。
- **红细胞沉降率（血沉，ESR）**测量红细胞在试管中沉降的速度。血浆纤维蛋白原和免疫球蛋白增加时升高，变化缓慢。它还随年龄增长、贫血和女性而升高，在骨髓瘤、巨细胞动脉炎和风湿性多肌痛中显著升高。

这两项检查都不特异。CRP正常使活动性炎症性关节炎的可能性降低，但不能排除；CRP升高可能来自肺部感染而非关节。类风湿因子和抗核抗体等自身抗体只有在临床表现已提示相关疾病时才有用，因为它们在健康人中也很常见；这一点在[[musculoskeletal/connective-tissue-vasculitis]]中展开讨论。

### 滑液

关节穿刺抽液是评估红热肿胀关节最有用的单项检查。抽出的液体要检查外观、白细胞计数、革兰氏染色和培养，并在偏振光显微镜下寻找晶体。

::: definition 滑液分析 {#def-synovial-fluid}
| 特征 | 正常 | 非炎症性（如骨关节炎） | 炎症性（如类风湿、痛风） | 化脓性 |
|---|---|---|---|---|
| 外观 | 清亮、淡黄 | 清亮、黄色 | 浑浊、黄色 | 混浊，常呈脓性 |
| 黏稠度 | 高 | 高 | 降低 | 低 |
| 白细胞（/mm³） | < 200 | < 2,000 | 2,000–50,000 | 通常 > 50,000 |
| 中性粒细胞 | < 25% | < 25% | 常 > 50% | 通常 > 90% |
| 革兰氏染色和培养 | 阴性 | 阴性 | 阴性 | 常为阳性 |

**晶体**：痛风中的**尿酸钠**晶体呈针状，具**负性双折光**（与补偿器轴平行时呈黄色）。焦磷酸钙沉积病（CPPD，旧称假性痛风）中的**焦磷酸钙**晶体呈菱形，具弱**正性双折光**。

各类别之间有重叠。痛风的白细胞计数可超过50,000/mm³，而部分治疗过或早期的感染计数可以较低。
:::

::: warning 晶体不能排除感染
在红热关节中发现尿酸盐或焦磷酸钙晶体，**不能**排除化脓性关节炎。两者可以并存，而且受损的关节更容易感染。同样，体温正常、血白细胞正常或CRP仅轻度升高也不能排除感染，尤其是在老年人、使用免疫抑制剂者和有人工关节者中。如果临床表现提示感染，在培养结果出来之前都应按感染处理。
:::

::: example 红热的膝关节 {#ex-septic}
一名71岁男性，患2型糖尿病和膝骨关节炎，右膝红、热、肿、剧痛两天。他不能负重，几乎不让人活动该膝关节。体温37.6 °C。两周前他有小腿溃疡。CRP为148 mg/L。关节穿刺抽出混浊液体，白细胞85,000/mm³，中性粒细胞95%，并见少量焦磷酸钙晶体。革兰氏染色未见细菌。工作诊断是什么？下一步应怎么做？
::: solution
工作诊断是**化脓性关节炎**。支持它的特征有：急性单关节炎，任何活动都引起剧痛；有可能的感染源（小腿溃疡）；有危险因素（年龄、糖尿病、既往受损的关节）；CRP很高；滑液白细胞超过50,000/mm³，且以中性粒细胞为主。

焦磷酸钙晶体并不改变这一判断（[[#def-synovial-fluid]]）：在这个年龄的男性骨关节炎膝关节中，晶体沉积很常见，可能只是偶然发现。革兰氏染色阴性在化脓性关节炎中也很常见，不能据此排除。

下一步（按当地指南）：

1. 送检滑液培养（已完成），并在使用抗生素前做**血培养**。
2. 及时开始**经验性静脉抗生素**治疗，按当地方案选择覆盖金黄色葡萄球菌和链球菌（最常见病原体）的药物，之后根据培养结果调整。
3. 紧急转诊骨科行**关节冲洗**（关节镜或切开），因为脓液在数天内就会破坏软骨。
4. 寻找并处理感染源，评估是否存在脓毒症（[[infectious-diseases/fever-sepsis]]）。

化脓性关节炎在老年人中有相当高的死亡率，且常遗留永久性关节损害。速度比诊断上的确定性更重要。
:::
:::

::: quiz
一名30岁男性第一跖趾关节红热肿胀，一夜之间起病。关节穿刺的哪一项发现最有力地支持痛风？
- [ ] 菱形、弱正性双折光的晶体
- [x] 针状、负性双折光的晶体
- [ ] 滑液白细胞计数150/mm³
- [ ] 血CRP升高
::: solution
针状、负性双折光的晶体是尿酸钠晶体，可确诊痛风。菱形、正性双折光的晶体是焦磷酸钙（CPPD）。白细胞150/mm³属于正常滑液，不支持任何急性关节炎。CRP升高不特异：痛风、感染和许多其他疾病都会出现。记住，晶体不能排除合并感染。
:::
:::

### 影像学

每种影像方法回答不同的问题。

- **X线平片**显示骨：骨折、关节间隙变窄、骨赘、骨侵蚀、钙化和骨密度改变，但对早期骨量丢失和早期炎症性关节炎不敏感。
- **超声**显示软组织：积液、滑膜炎（包括多普勒显示的血流增加）、肌腱撕裂、附着点炎，以及软骨表面尿酸盐沉积的“双轨征”。它可以引导穿刺和注射。
- **MRI**显示骨髓水肿、软骨、韧带、半月板、椎间盘和神经根，以及骶髂关节的早期炎症改变。
- **CT**详细显示复杂骨折和骨性解剖；双能CT可识别尿酸盐沉积。
- **DXA**测定骨密度，如前所述。

影像学异常在无症状者中很常见，尤其随着年龄增长。X线或MRI上的退行性改变并不能证明它们就是疼痛的原因。这一主题在[[musculoskeletal/osteoarthritis]]和[[musculoskeletal/back-pain]]中还会出现。

## 综合起来：疼痛关节的四个问题 {#sec-four-questions}

对任何疼痛的关节，按下列顺序问四个问题是一个有用的习惯：

1. **会不会是感染？**化脓性关节炎数天内即可毁坏关节，还可致死。单个红热肿胀的关节，在被证明不是之前都按化脓性处理。
2. **是炎症性的吗？**炎症性关节炎需要及时的专科评估，因为最初几个月的治疗会改变长期结局。
3. **是机械性的吗？**社区中大多数关节痛是机械性的：骨关节炎、损伤、肌腱问题和过度使用。
4. **疼痛是否来自别处？**髋关节病变常表现为膝痛；颈部问题把疼痛牵涉到肩和上肢；内脏问题可把疼痛牵涉到背部和肩部。

对每个答案，都值得说出一个能改变你想法的发现。这种习惯能抓住“第二个诊断”：感染关节中的晶体性关节炎、“骨关节炎”背后的骨肿瘤，或最初被归咎于年龄的炎症性关节炎。

::: history
1691年，英国医师**克洛普顿·哈弗斯（Clopton Havers）**描述了骨的显微结构，哈弗斯管因他而得名。1892年，德国外科医师**尤利乌斯·沃尔夫（Julius Wolff）**提出骨的内部结构会适应其所承受的负荷，这一观念今称沃尔夫定律。1895年**威廉·伦琴（Wilhelm Röntgen）**发现X射线，人们第一次能够看到活人体内的骨，骨折和关节的诊治在几年内就发生了改变。20世纪60年代，美国骨科研究者**哈罗德·弗罗斯特（Harold Frost）**描述了基本多细胞单位和“力学调控器”，解释了骨重建与负荷之间的联系。20世纪90年代末，各研究团队鉴定出骨保护素和RANKL，找到了分子开关；不到十年，一种抗RANKL抗体——地舒单抗——就进入了临床。2008年，谢菲尔德世界卫生组织合作中心的**约翰·卡尼斯（John Kanis）**及其同事发布了FRAX，使骨质疏松症的诊治从单一的骨密度测量转向对绝对骨折风险的估算。
:::

## 后续内容

骨折及其愈合和并发症是[[musculoskeletal/fractures]]的主题。软骨失效和全关节疾病见[[musculoskeletal/osteoarthritis]]。滑膜炎症和晶体病见[[musculoskeletal/inflammatory-arthritis]]，系统性自身免疫病见[[musculoskeletal/connective-tissue-vasculitis]]。钙的激素调控和骨质疏松症的药物在[[endocrine/bone-calcium]]中有更全面的讲述，骨骼肌的生理见[[physiology/muscle]]。

::: summary
- 骨是由Ⅰ型胶原和羟基磷灰石构成的活的复合材料。皮质骨提供强度；小梁骨表面积大，转换更快。
- 成骨细胞形成骨，破骨细胞吸收骨，骨细胞感受负荷并协调两者。RANKL/OPG比值是骨吸收的主要开关。
- 当每个重建单位都留下亏空时骨量丢失；活跃单位越多丢失越快，如绝经后。抗骨吸收药物减缓骨吸收；促合成药物增强骨形成。
- 骨质疏松症在DXA上定义为T值$-2.5$或更低。其血液检查正常；做血液检查是为了寻找继发性病因和类似疾病。骨折风险工具把骨密度与临床危险因素结合起来。
- 校正钙用于在白蛋白偏低时校正总钙：总Ca $+ 0.02 \times (40 - \text{白蛋白})$。
- 滑膜关节由无血管的透明软骨、软骨下骨、关节囊、滑膜和滑液组成。软骨难以愈合；滑膜是炎症的靶点。
- 先区分炎症性与机械性疼痛，再确定模式（数目、分布、病程、伴随表现）。
- 单个红热肿胀的关节在被证明不是之前按化脓性处理。要穿刺；晶体不能排除感染。
:::

## 习题

::: exercise 骨细胞 {level=1}
说出分别执行以下功能的细胞：(a) 分泌类骨质和碱性磷酸酶；(b) 用酸溶解骨矿物质；(c) 感受机械应变并分泌硬骨抑素。每种细胞来源于哪个细胞系？
::: solution
(a) **成骨细胞**，来源于间充质干细胞。(b) **破骨细胞**，单核-巨噬细胞系的多核细胞。(c) **骨细胞**，即埋入矿化基质中的成骨细胞。骨细胞分泌的硬骨抑素抑制骨形成；负荷可减少硬骨抑素，这是运动维持骨量的途径之一。
:::
:::

::: exercise 计算T值 {level=1 check="-2"}
一名58岁男性长期服用泼尼松龙，腰椎BMD为0.700 g/cm²。参考人群的年轻成人均值为0.940 g/cm²，标准差为0.120 g/cm²。计算他的T值（精确值）并进行分类。
::: solution
$T = (0.700 - 0.940)/0.120 = -0.240/0.120 = -2.0.$

该值介于$-1.0$与$-2.5$之间，属于低骨量（骨量减少）。由于他长期使用糖皮质激素，其骨折风险高于单凭骨密度所提示的水平。糖皮质激素既降低骨密度也降低骨质量，指南对这一人群设定了更低的治疗阈值。
:::
:::

::: exercise 校正钙 {level=1 check="2.34"}
一名患者总钙为2.10 mmol/L，白蛋白为28 g/L。用[[#eq-adjusted-ca]]中的公式计算校正钙（mmol/L，精确值）。
::: solution
校正钙$= 2.10 + 0.02 \times (40 - 28) = 2.10 + 0.24 = 2.34$ mmol/L。这在通常的参考范围之内，因此总钙偏低反映的是白蛋白偏低。
:::
:::

::: exercise 解读生化结果 {level=2}
一名52岁女性很少外出，外出时全身遮盖。她骨痛、上楼困难、步态蹒跚。钙为2.12 mmol/L（校正后），磷降低，ALP升高，PTH升高。最可能的诊断是什么？每项结果如何解释？你还会申请哪一项检查？
::: hint
把这一模式与代谢性骨病表格比较。哪种激素缺乏会同时减少钙和磷的吸收？
:::
::: solution
最可能的诊断是**维生素D缺乏所致的骨软化症**。缺少日照使皮肤合成的维生素D减少。维生素D不足使肠道对钙和磷的吸收减少。血钙下降刺激PTH分泌（继发性甲状旁腺功能亢进），使血钙恢复至接近正常，代价是肾脏丢失磷增加，因而血磷降低。成骨细胞在未矿化的类骨质上忙碌工作，因此ALP升高。近端肌无力导致蹒跚步态。关键的进一步检查是**血清25-羟维生素D**。骨质疏松症的生化应正常，原发性甲状旁腺功能亢进症则血钙升高。
:::
:::

::: exercise 机械性还是炎症性？ {level=2}
对下列每个人，判断疼痛更可能是炎症性还是机械性，并给出两条支持你判断的特征。(a) 26岁男性，腰痛6个月，下半夜痛醒，运动后改善。(b) 70岁女性，右膝行走时痛，休息缓解，晨僵5分钟。(c) 35岁女性，双腕疼痛肿胀3个月，晨僵持续90分钟。
::: solution
(a) **炎症性**：40岁前起病且病程长，下半夜夜间痛，运动后改善。这是中轴型脊柱关节炎中炎症性腰背痛的模式（[[musculoskeletal/back-pain]]）。

(b) **机械性**：活动后痛，休息缓解，晨僵短暂，年龄符合骨关节炎的典型人群。

(c) **炎症性**：晨僵时间长，双腕软组织肿胀3个月。这是持续性滑膜炎，需要紧急转诊风湿科。
:::
:::

::: exercise 解读滑液 {level=2}
肿胀膝关节抽出的滑液浑浊、黏稠度降低，白细胞18,000/mm³（中性粒细胞70%），未见晶体，革兰氏染色和培养均阴性。这属于哪一类？给出三种可能产生这种滑液的疾病。
::: solution
这是**炎症性**滑液（[[#def-synovial-fluid]]）：白细胞计数在2,000至50,000/mm³之间，以中性粒细胞为主；黏稠度降低是因为炎症中的酶降解了透明质酸。

可能的疾病包括**类风湿关节炎**、**反应性关节炎**或其他脊柱关节炎、**银屑病关节炎**，以及漏检晶体的**痛风或CPPD**（晶体可能很少，标本应由有经验的观察者及时检查）。还必须考虑部分治疗过的**化脓性关节炎**：使用抗生素后培养可呈阴性，而淋球菌性关节炎的滑液培养常为阴性。临床表现、血液检查，有时再次穿刺，可在它们之间作出判断。
:::
:::

::: exercise 根据滑液计算验后概率 {level=3 check="round(100*(0.25*7.7)/(1+0.25*7.7))"}
一项关于成人红热关节的系统评价（Margaretten及其同事，《美国医学会杂志》（*JAMA*）2007）发现，滑液白细胞计数≥50,000/mm³对化脓性关节炎的阳性似然比约为7.7。医师估计某患者穿刺前患化脓性关节炎的概率为20%。结果回报为62,000/mm³。用比值（odds）计算化脓性关节炎的验后概率，以百分数表示并四舍五入到整数。
::: hint
把概率换算成比值，乘以似然比，再换算回来：概率 $=$ 比值$/(1 + $比值$)$。
:::
::: solution
验前比值$= 0.20/0.80 = 0.25$。

验后比值$= 0.25 \times 7.7 = 1.925$。

验后概率$= 1.925/(1 + 1.925) = 1.925/2.925 \approx 0.658$，即**66%**。

这一结果使概率大幅上升，但并未达到确定。实际工作中，这么高的概率意味着在等待培养结果时按化脓性关节炎处理（培养、抗生素和骨科会诊）。还要注意，计数低于50,000并不能排除感染；阴性结果的似然比远没有那么有说服力。这类诊断试验推理在[[epidemiology-ebm/diagnostic-tests]]中展开。
:::
:::

::: exercise 单纯ALP升高 {level=3}
一名72岁男性常规血液检查显示ALP为640 U/L（参考上限130），钙、磷、肝转氨酶、胆红素和γ-谷氨酰转移酶均正常。他提到帽子不再合适，右大腿酸痛。(a) ALP更可能来自肝还是骨？为什么？(b) 最可能的诊断是什么？(c) 说出两种应询问的并发症和一项支持诊断的检查。
::: hint
ALP既来自肝也来自骨。其他肝功能指标告诉你什么？哪种骨病会使颅骨增大？
:::
::: solution
(a) **骨**。肝源性ALP升高通常伴有γ-谷氨酰转移酶升高，并常有其他肝功能异常。必要时可通过同工酶分析或骨特异性ALP确认来源。

(b) **骨佩吉特病**：老年人中一种局灶性的、过度而紊乱的骨重建疾病，先有体积大、活性过强的破骨细胞，随后是杂乱的新骨形成。颅骨增大和大腿痛（股骨受累）与之相符。钙和磷通常正常。

(c) 并发症包括骨痛、畸形（股骨或胫骨弯曲）、颅骨受累压迫耳蜗或听神经所致的**耳聋**、病理性骨折、邻近关节的继发性骨关节炎、神经受压，以及罕见的骨肉瘤。受累部位的**X线**显示骨膨大、骨小梁增粗紊乱，或核素**骨扫描**显示受累范围，均可支持诊断。活动性佩吉特病所致的骨痛可用双膦酸盐治疗。
:::
