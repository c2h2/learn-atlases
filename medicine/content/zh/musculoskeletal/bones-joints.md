肌肉骨骼系统是“生物化学变成建筑”的地方：**一种沿着应力的线条重建的、有生命的复合材料、一副润滑的铰链——它在疼之前会安静地失效数十年——以及身体的钙的银行、磷的沉淀池。**风湿科与骨科都从这里开始、而两者都犯同一个新手的错误——治疗“图像”而不是机制。

本章涵盖骨的结构与重建、关节的解剖与肌肉骨骼的检查、以及本课程的后续疾病共用的词汇。

## 作为器官的骨

::: definition 骨的结构、重建与力学的规则 {#def-bone}
**层级（密质对松质的分裂——致密骨干的“外壳”对代谢的“海绵”、以及为什么在两者之一变薄时髋与脊柱与椎体会骨折；骨单位、骨小梁的“板与杆”的几何、以及刚度对韧性的力学——块由矿物与胶原构成的复合材料使骨同时刚、强、且“耐受损伤”、以及为什么“矿物与基质的平衡”会随年龄与疾病翻转——区域的解剖见[[anatomy/back-upper-limb]]与[[anatomy/lower-limb]]、蛋白与酶见[[cell-biochemistry/proteins-enzymes]]）；细胞重建的单位——骨细胞作为“被埋藏的力感受器与指挥的网络”它感受应变与微损伤、并调度事务、成骨细胞作为“来自间充质干细胞成骨的谱系”带着它们在信号分子中的角色、以及破骨细胞作为“多核的、带质子泵与组织蛋白酶的挖掘队”（派生自单核的前体——谱系见[[blood/haematopoiesis]]、旁分泌的信号见[[cell-biochemistry/signalling-cell-cycle]]）；重建与塑形“基本的多细胞单位”的次序——激活、吸收、逆转、形成、以及通常维持平衡的偶联、以及让“吸收跑在形成之前”的转变（年龄与雌激素的撤退及糖皮质激素及失用及炎症的细胞因子、以及骨质疏松的后果（完整内容见[[endocrine/bone-calcium]]）；沃尔夫与福斯特的“机械恒定器”——应变的量与速率如何调定骨的量、为什么负荷与冲击的运动建造骨、以及为什么卧床与航天及偏瘫及石膏固定能在数月之内把它拿走——钙的内分泌的控制见[[endocrine/bone-calcium]]、失用性的高钙这条见[[renal/acute-kidney-injury]]）；矿物与激素的整合（羟基磷灰石作为身体的“磷酸钙的储存库”、以及那个“甲状旁腺激素—维生素D—成纤维细胞生长因子23—磷—肾—骨”的轴——见[[endocrine/bone-calcium]]、[[renal/potassium-calcium-phosphate]]、以及“肾性的骨营养不良”这一连续过程见[[renal/chronic-kidney-disease]]。）**
:::

## 作为铰链的关节

::: definition 滑膜关节的解剖与肌肉骨骼的检查 {#def-joint}
**滑膜的架构（透明软骨那“低摩擦的承重面”、它无血管、软骨细胞包在“细胞周基质的领地”里、而“压缩驱动流体的润滑膜”的物理学——区域关节的解剖见[[anatomy/back-upper-limb]]与[[anatomy/lower-limb]]、II型胶原与聚集蛋白聚糖的软骨基质见[[cell-biochemistry/proteins-enzymes]]；滑膜作为一层“选择性通透绒毛的膜”、分泌富含润滑蛋白的液体、而发炎的滑膜是“积液与波动感及胶样脉搏”的来源——化脓关节穿刺的逻辑见[[#def-red-flags]]与[[infectious-diseases/healthcare-infections]]；纤维的囊、“压力与吻合”带来的稳定、以及盂唇与半月板及滑囊及附着点——附着点作为脊柱关节炎与过度使用的综合征中“疼痛的附着处”——[[musculoskeletal/inflammatory-arthritis]]、过度使用的肌腱病见[[musculoskeletal/back-pain]]）。非滑膜的关节（纤维与软骨的类型——颅骨缝与耻骨联合及椎间盘、以及为什么椎间盘的“纤维环与核的水合及退变的胶原”的生物学构成了整个背痛那一章的基础——[[musculoskeletal/back-pain]]、[[cell-biochemistry/proteins-enzymes]]）。检查作为一套算法——风湿科的“看、触、动、专门的检查、功能”的次序步态与姿势与对称的视诊；关节线与软组织的触诊；主动对被动的活动度与抗阻的动作、以及“关节囊型对非关节囊型”的限制；炎症的对机械的模式识别（晨起牵长的僵硬随活动减轻、对“随使用而加重的僵硬”、小关节的对称对大关节的不对称、夜间的疼痛与全身的特征——[[clinical-skills/physical-examination]]、[[clinical-skills/history-taking]]；那张“专门检查的证据表”——半月板与韧带及撞击及“芬克尔斯坦”及“法伦”的试验、带着它们在“似然比”上的现实、以及为什么“影像申请跟的是检查、不是心情”——[[clinical-skills/medical-imaging]]、[[epidemiology-ebm/diagnostic-tests]]）。影像与液体“看骨与骨折及终末期的关节，X线为先”的逻辑、磁共振对骨髓与软组织及感染、以及早期侵蚀的敏感性（外加偶然发现的代价、以及超声对积液与侵蚀及“引导的注射”的可移动性——[[clinical-skills/medical-imaging]]、骨密度的检查见[[endocrine/bone-calcium]]、核素的扫描见[[clinical-skills/medical-imaging]]；以及滑液的分析作为“微生物、晶体、细胞计数”的三岔分诊——化脓的、对炎症的、对退变的、对出血的——见下一节与[[microbiology/laboratory-diagnosis]]。）**
:::

::: definition 危险信号与那条疼的肢体 {#def-red-flags}
**藏在“关节与背痛”里的五种急症化脓的关节——急性的、热的、肿的“单个关节”伴全身的特征、以及那个有意思的真相：“三分之一并没有发热”、以及“血培养与立即的穿刺与骨科的冲洗与静脉抗生素”的路径、连同“人工关节与免疫抑制及静脉吸毒及类风湿”变异——晶体的模仿者见[[musculoskeletal/inflammatory-arthritis]]、[[infectious-diseases/fever-sepsis]]、[[immunology/immunodeficiency]]；感染的椎间盘炎与椎体的骨髓炎，以及它们的“背痛加发热加C反应蛋白升高”、磁共振的诊断、血培养、长程的抗生素、以及对神经恶化的观察——血行的源头见[[renal/urinary-tract]]、[[nervous-system/motor-systems]]；骨折它有自己的一章——经转移与骨髓瘤及佩吉特病的病理性骨折、以及那根“提示未治疗的骨质疏松”的脆性的骨折——[[musculoskeletal/fractures]]、[[endocrine/bone-calcium]]、[[blood/lymphoma-myeloma]]；神经血管的肢体——骨折与石膏及挤压之后的骨筋膜室综合征（疼痛与体征不相称、被动牵拉的痛、以及“切开减压的决定不等无脉”、及急性肢体缺血的“六个P”与紧急的动脉的路径——并发症见[[musculoskeletal/fractures]]、[[surgery/vascular-urological-surgery]]；以及马尾与脊髓的压迫——鞍区的麻木与膀胱直肠的功能障碍及双下肢的无力、以及“已知肿瘤或发热的背痛”——即刻的磁共振与地塞米松与神经外科紧急减压的逻辑——[[musculoskeletal/back-pain]]、[[surgery/orthopaedics]]）。慢性表现背后的“恶性与系统性炎症的模式”（不缓解的夜间的疼痛与体重的下降及肿瘤学的危险因素、以及“牵涉痛”的地图——髋作为膝、肩作为颈、以及内脏牵涉的陷阱——[[clinical-skills/physical-examination]]、膈的牵涉的模式见[[anatomy/thorax]]）。软组织与区域的综合征肌腱病是退变的、不是“炎”、带着它的负荷的管理与离心的训练的证据；滑囊炎与附着点病、以及冻结的肩（连同它与糖尿病及甲状腺病的关联、以及那份“按自然史的分期与安心”——[[endocrine/diabetes-complications]]、[[endocrine/thyroid]]、[[musculoskeletal/back-pain]]；以及纤维肌痛与“伤害可塑性疼痛”这一范式——中枢的敏化、异常的伤害处理、而不是“非器官性的疼痛”、以及“渐进的运动与睡眠与心理的技能与药物”的分诊的路径——[[psychiatry/mood-disorders]]、[[nervous-system/headache-pain]]。）**
:::

::: example 擦伤之后那个热的膝 {#ex-septic-knee}
一名67岁的糖尿病患者、右膝热肿18小时、不能负重、最轻微的被动活动都痛、体温38.4、C反应蛋白280、白细胞17；他在两周前擦伤过小腿；X线显示软骨的钙化。
::: solution
**在穿刺液说话之前它就是化脓的关节、无论X线显示什么（[[#def-red-flags]]）：立即穿刺做细胞计数与分类、革兰染色、培养、以及晶体——同一支注射器回答两个问题、而这两个诊断可以共存——[[clinical-skills/laboratory-tests]]、[[musculoskeletal/inflammatory-arthritis]]；血培养、以及在“临床的怀疑很高”的那一小时通知骨科、冲洗与静脉抗生素、而不是观察、而“糖尿病加旧的关节加皮肤的入口”就是教科书上那组危险因素——[[microbiology/bacteria]]、[[endocrine/diabetes-complications]]。教学的要点：焦磷酸钙晶体的存在不排除感染、而感染也不排除晶体液体永远两项都送；人工的或近期注射过的关节提高了赌注、并改变了微生物的构成——[[surgery/orthopaedics]]、[[infectious-diseases/healthcare-infections]]；对“有凝血障碍或在抗凝的”穿刺者，不是“必要的关节穿刺”的禁忌——[[blood/haemostasis-bleeding]]；以及风暴之后的计划——抗生素的疗程与关节功能的物理治疗、以及糖尿病与皮肤入口的审计、以及“道擦伤究竟为什么感染了”——康复与伤口护理及[[clinical-skills/records-handover]]。**
:::

## 一条曲线、两种将来

::: definition 一生的骨量 {#def-bonemass}
**在第三个十年达到峰值的骨量、一段长长的平台、然后加速的丢失——在松质骨中更快、在绝经之后更快、在八十多岁更是快上加快——这就是本课程几乎每一个诊断背后的轨迹（[[endocrine/bone-calcium]]）。临床的杠杆恰恰就是那条轨迹的修饰因子：年轻时的负荷史、雌激素的状态、糖皮质激素的暴露、跌倒、以及把曲线压平的治疗——这就是为什么“一生的骨策略”读起来像是把[[#def-bone]]的生理学“按十年展开”。**
:::

::: example 那个疼得太厉害的石膏 {#ex-compartment}
一名24岁在胫骨骨折被复位进“后托”之后6小时、疼痛在升级、需要静脉的阿片、被动伸趾时疼痛、小腿紧张而肿胀；足是温的、脉搏可及；护士标了一句“生命体征正常”。
::: solution
**在切开减压说话之前它就是急性的骨筋膜室综合征——而那句“生命体征正常”的安心正是经典的陷阱（[[#def-red-flags]]）：脉搏通常存在、而脉搏的消失是临终的征象、诊断是临床的——疼痛与体征不相称、被动牵拉痛、感觉异常、紧张的骨筋膜、以及“镇痛需求不断升级”这个标志——而观察的记录可以完全正常——[[musculoskeletal/fractures]]、[[surgery/orthopaedics]]、观察的要点见[[emergency-critical-care/acute-assessment]]；行动——移除所有的敷料、并把石膏“剪开到皮肤”、把肢体放在心脏的水平不是抬高于灌注之上、立即升级给骨科、反复地复查、并在“检查不可靠（被镇静或年幼）”时对“测骨筋膜的压力”保持低的阈值——压力的细节与“镇痛药的混淆”见[[surgery/anaesthesia-pain]]；切开减压的决定“看时间、不看化验”、而延迟的代价挛缩与神经及横纹肌溶解及肾要在事件的文件中被点名——[[renal/acute-kidney-injury]]、[[musculoskeletal/fractures]]；以及这类病例的“法医学的解剖”——被记录的神经血管观察的频率、以及那条“起了作用或没起作用护士升级的路径”——[[clinical-skills/patient-safety]]、[[clinical-skills/records-handover]]。**
:::
:::

::: example 带鞍区征象的那个“坏背” {#ex-cauda}
一名44岁在两周加重的腰背痛与双侧的坐骨神经痛之后、现在报告排尿犹豫与肛周麻木；磁共振“被订在下周二”；C反应蛋白正常、无热。
::: solution
**马尾综合征是一桩“同一小时”的外科诊断、而“已经预约的磁共振”就是那个错误（[[#def-red-flags]]、[[musculoskeletal/back-pain]]）：膀胱与鞍区及双侧的神经的发现，要求即刻脊柱外科的转诊、紧急的“现在”的“全脊柱”的磁共振、把“排尿后的膀胱残余”作为床旁的辅助、并在减压的时钟走动的同时按本地的方案讨论地塞米松——[[clinical-skills/physical-examination]]、[[nervous-system/motor-systems]]、[[surgery/orthopaedics]]；鉴别——巨大中央的椎间盘对肿瘤对“硬膜外的积脓或积血”静脉吸毒与抗凝及免疫的那几行——改变的是治疗、不是紧迫性——[[infectious-diseases/healthcare-infections]]、[[blood/haemostasis-bleeding]]、转移的压迫见[[surgery/orthopaedics]]；安全网的治理——“在每一次背痛的分级中记录危险信号的清单”、以及那条“让下周二不可能出现的非工作时间直接通道的磁共振路径”——[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]；以及结局的诚实——膀胱的结局取决于时钟的程度超过取决于刀、所以与家属的那场谈话与转院的决定都是时间关键的——[[clinical-skills/communication]]、[[emergency-critical-care/resuscitation]]。**
:::

::: example 两双手 {#ex-hands}
一名72岁、晨僵3分钟、拇指根部与远端指间关节疼痛、坚硬的骨的增大、握力弱、C反应蛋白正常——手X。一名34岁、晨僵90分钟、双侧的近端指间关节与腕关节肿热、疲劳、C反应蛋白48——手Y。
::: solution
**并排读两个原型（[[#def-joint]]、[[clinical-skills/history-taking]]）：手X是骨关节炎——短暂的“起步的僵硬”、远端指间与第一腕掌的分布、坚硬的骨的结节、机械性疼痛的模式、生物化学正常、“临床的诊断、只有在不确定的时候才拍片”——[[musculoskeletal/osteoarthritis]]；手Y在被排除之前就是滑膜炎——长时间的晨僵、对称的近端指间与腕的肿、全身性炎症、紧急的风湿科转诊与“抗环瓜肽抗体与类风湿因子”的血清学及影像的基线——因为“早期治疗的窗口”让每一周都重要——[[musculoskeletal/inflammatory-arthritis]]、[[immunology/autoimmunity]]、[[clinical-skills/laboratory-tests]]；陷阱——早期炎症的病藏在“只是一只疼的手”里、而晚期的骨关节炎的急性发作可以模仿滑膜炎、而晶体喜欢这两者痛风与焦磷酸钙的伪装；以及随后“跟着模式、不跟着年龄”的那个处理的岔路——手的治疗与适应、对“改善病情的药与治疗达标”——[[musculoskeletal/osteoarthritis]]、[[musculoskeletal/inflammatory-arthritis]]、[[pharmacology/dosing-principles]]。**
:::

- [x] 被动牵拉该筋膜内的肌肉时剧痛
- [ ] 体温38.5
- [ ] C反应蛋白90

**疼痛与体征不相称、以及被动牵拉痛是先导；脉搏、体温与C反应蛋白分别属于“晚、没有、不相干”（[[#def-red-flags]]、[[musculoskeletal/fractures]]）；无脉的肢体那一章是血管的急症[[surgery/vascular-urological-surgery]]；镇痛可以掩盖、但绝不排除、所以“升级与反复的检查胜过单次的观察”——[[clinical-skills/patient-safety]]。**

值得明确教授的一个“检查收尾的习惯”：在每一个疼的关节上、合格的临床医师按顺序问四个问题——它感染了吗、它是炎症的吗、它是机械的吗、还是别处把疼痛牵涉到这里——并且能说出“那个会推翻当前答案的单一发现”（[[clinical-skills/clinical-reasoning]]、[[clinical-skills/history-taking]]）。正是这种“在每次复查时更新的、有纪律的不确定”抓住了第二个诊断：片“骨关节炎”之下的肿瘤、那个藏在化脓关节里的晶体病、以及那次被归咎于年龄的首发的炎症性的多关节炎（[[musculoskeletal/inflammatory-arthritis]]、[[musculoskeletal/osteoarthritis]]、[[pathology/cancer-diagnosis]]）。

**骨与关节的医学那场漫长的侦察：奥尔布赖特在1940年代“以综合征为先”地把骨质疏松描述为一种“量与脆性”的疾病、以及那几篇奠定了“骨量的思考”的论文；诺丁与二十世纪“钙的平衡”的代谢学者，把佝偻病与骨软化变成了可以测量的轴——[[endocrine/bone-calcium]]；“以滑膜为靶”的洞见先于、并随后正当化了类风湿关节炎那整个生物制剂的时代——[[musculoskeletal/inflammatory-arthritis]]、[[immunology/vaccines-immunotherapy]]；亨奇1949年那个“化合物E”的揭示、以及糖皮质激素与内分泌学共享的命运它们的骨与肌腱与软骨的代价是在那之后慢慢学会的——[[endocrine/adrenal]]、[[endocrine/bone-calcium]]；骨科固定的革命——“压迫与稳定及保护生物学”的复位的原则、让内固定成为一门“关于力学与愈合的窗口”的科学——[[musculoskeletal/fractures]]；关节镜“供给过剩”的教训——安慰剂对照的试验显示“退变的半月板切除除了安慰效应之外一无所获”、成为“外科的证据”的教科书案例——[[epidemiology-ebm/randomised-trials]]、[[public-health/health-systems-economics]]；以及从格拉克与查恩利的“带水泥的髋”到现代的摩擦界面与加速康复的“低摩擦的关节置换”这条血脉——关节置换后静脉血栓的教训见[[blood/thrombosis-anticoagulation]]。**
:::

## 机制的延伸

“机械恒定器”的临床的表亲——应力骨折与骨的应力损伤的分期、以及“恢复运动”的负荷的谈话——与[[physiology/muscle]]的运动医学、以及[[musculoskeletal/back-pain]]的过度使用的模式在一起；从缺血性坏死到褐黄病的软骨生物学的失败出现在[[musculoskeletal/osteoarthritis]]；康复的医学——门“把一处修补好的结构变成一条可用的肢体”的功能的恢复与目标的设定的纪律——是把这里的每一章通向“出院的去处”的那条线、并与上面的机械恒定器共享它负荷的逻辑。那个“由免疫驱动的关节”作为治疗的靶，贯穿[[musculoskeletal/inflammatory-arthritis]]与[[musculoskeletal/connective-tissue-vasculitis]]、连同[[pharmacology/dosing-principles]]的生物制剂与监测的药理学、以及[[immunology/vaccines-immunotherapy]]的“对感染的警惕”的权衡。

::: summary
- 骨是“有生命复合的建筑”：骨细胞感受、破骨细胞挖掘、成骨细胞回填、而激素与负荷决定这两支队伍之间的平衡。
- 重建的平衡被年龄、雌激素的撤退、激素、失用、炎症与肾衰竭所倾覆——同一份清单出现在前面每一种骨的病里。
- 滑膜的关节以两大模式失效——“随使用的痛”的机械的磨损、与“静息的僵硬”的炎症的滑膜炎——而病史在任何检查之前告诉你哪一种。
- 检查是一台概率的机器；专门的检查与影像只是重新加权。
- 一个热而肿的关节、一个伴发热或神经的背、以及一条“疼得不相称”的肢体，第一是急症、第二才是诊断。
:::

## 练习

::: exercise 画出那个重建的单位 {level=1}
向一位正要开始用糖皮质激素的患者解释：为什么他们的骨处于风险之中、以及预防的清单里有什么。
::: solution
**一句话的机制：激素把重建的平衡推向吸收、并抑制形成以及钙的吸收以及“建造骨细胞的功能”、而丢失在最初的几个月里最快（[[endocrine/adrenal]]、[[endocrine/bone-calcium]]）；预防的清单——“最低的有效剂量与省激素的方案”、钙与维生素D的充足饮食为先、然后明智的补充、抗阻与冲击的运动、不吸烟、饮酒节制、按风险监测骨密度、以及“按骨折风险的评估决定治疗的阈值”、以及按风险而不是按年龄尽早开始骨质疏松的药物——[[endocrine/bone-calcium]]、[[public-health/screening]]、[[gastrointestinal/clinical-nutrition]]、[[physiology/muscle]]。**
:::
:::

::: exercise 判读滑液 {level=1}
给出那三分的滑液的模式细胞计数、外观、关键的加做项目，把化脓的、炎症的与退变的分开。
::: solution
**化脓的——脓性的、极高的中性粒细胞的计数常常远高于炎症的范围、但有重叠、革兰或培养阳性、以及那条“临床的信任”的规则按怀疑治疗、绝不等培养；炎症的——混浊、高的白细胞伴中性粒细胞、晶体阳性或培养阴性、并放在“自身免疫血清学的背景”里；退变的——清亮、细胞少、而且是一个“靠模式”的诊断——份临床的评分、以及“只有当影像会改变处理时才做超声或磁共振”的纪律（[[clinical-skills/laboratory-tests]]、[[microbiology/bacteria]]、[[musculoskeletal/inflammatory-arthritis]]、[[musculoskeletal/osteoarthritis]]、[[clinical-skills/medical-imaging]]）。**
:::
:::

::: exercise 把机械的与炎症的分开 {level=2}
一名54岁有25分钟的晨僵、休息后加重、手部小关节的对称、以及C反应蛋白升高。另一名54岁有5分钟的僵硬、在一天结束时加重、膝关节线的压痛、C反应蛋白正常。请给出诊断与下一步的检查。
::: solution
**第一例是一份“炎症的模式”的病史、需要为类风湿关节炎做紧急的转诊评估——抗环瓜肽抗体与类风湿因子及C反应蛋白与血沉、以及手与足超声或磁共振——而那个早期治疗的窗口“让转诊的时机成为一项治疗的变量”（[[musculoskeletal/inflammatory-arthritis]]、[[immunology/autoimmunity]]、[[clinical-skills/laboratory-tests]]）；第二例是骨关节炎的模式、适用“临床的诊断不需要常规的影像”这条规则、配上体重与运动与肌力与“疼痛的素养”的计划、以及那份“什么时候该拍片、对照紧迫性的标志”（[[musculoskeletal/osteoarthritis]]、体重管理的服务见[[public-health/prevention-promotion]]、[[physiology/muscle]]）。**
:::
:::

::: exercise 为影像辩护或拒绝它 {level=2}
两周的、无并发症的腰背痛、没有危险信号、而焦虑的患者要求做磁共振、“好歹得看到点什么”。请决定并辩护。
::: solution
**温和地拒绝：没有适应证的影像会增加费用、焦虑与偶然发现、却不改善结局、而自然史对大多数发作是有利的（[[musculoskeletal/back-pain]]、[[public-health/health-systems-economics]]、[[clinical-skills/medical-imaging]]）；套“辩护的套餐”才是真正的治疗——“严重原因的排除已经做过了”、“保持活动、不要卧床”的建议、带告诫清单的镇痛阶梯、预期恢复的时间框架、以及“为哪些危险信号要回来”的具名的清单、以及“若超出预期的窗口仍在”的随访的触发连同心理与工作的障碍的筛查——[[clinical-skills/communication]]、[[psychiatry/anxiety-disorders]]、镇痛药的危害见[[pharmacology/adverse-reactions]]；以及审计环路的诚实——如果这个服务“约磁共振比解读磁共振还快”、那么路径本身就在制造需求（[[public-health/health-systems-economics]]、[[epidemiology-ebm/measuring-disease]]）。**
:::
:::

::: exercise 解释冻结的肩 {level=2}
一名52岁的1型糖尿病患者有一处疼痛的、全面僵的肩、被动的外旋消失；X线正常。请说出这个模式、要查的关联、以及分期的逻辑。
::: solution
**关节囊型的限制就等于冻结的肩粘连的关节囊炎、不是肩袖或关节面的问题——“关节囊型的被动活动丧失”是检查的签名（[[#def-joint]]、[[clinical-skills/physical-examination]]）；糖尿病与甲状腺的关联是真实的、并且“与控制程度双向”——查糖化的血红蛋白与促甲状腺激素、以及另一侧的肩、以及那份“预测性的咨询”与“其他原因的清扫”（[[endocrine/diabetes-complications]]、[[endocrine/thyroid]]）；分期的逻辑——“疼痛的冻结期”需要控制疼痛与早期的关节内激素与物理治疗、对“冻结期”需要松动与“扩张或外科的选项”、以及“不要漏掉那场内分泌门诊的谈话”（[[musculoskeletal/back-pain]]的肩的那几行、注射后“血糖的小幅波动”的咨询见[[pharmacology/adverse-reactions]]、注射的技术见[[clinical-skills/physical-examination]]）。**
:::

::: exercise 设计社区的骨的服务 {level=3}
一个地区只在髋部骨折之后治疗骨质疏松。请以证据、经济学与公平这几个成分，建一个“预防为先”的服务。
::: solution
**证据的脊柱——骨折风险的评估与有目标的骨密度的检查、以及“双膦酸盐与地舒单抗与合成代谢的臂”、以及“椎体骨折识别的缺口”（[[endocrine/bone-calcium]]、[[clinical-skills/laboratory-tests]]）；交付的脊柱——为每一位脆性骨折患者的“骨折的联络服务”带具名负责人的随访、以及把“再次骨折的比率”作为头条的关键指标（[[musculoskeletal/fractures]]、[[clinical-skills/records-handover]]、[[public-health/screening]]）；经济学的论证——髋部骨折对“通用的双膦酸盐”的成本的比较、以及“避免进护理院与失去独立”、以及“输液门诊规模的经济”（[[public-health/health-systems-economics]]、[[geriatrics-palliative/ageing-frailty]]）；公平与可及的那一层——诊断与治疗中的贫困与族裔与性别的缺口、以及社区药房与“骨的视频门诊”与远程的依从、以及“跌倒的预防与视力与鞋及住房的隐患”的规划（[[public-health/determinants-inequalities]]、[[geriatrics-palliative/falls]]、视力那一行见[[nervous-system/sensory-systems]]）；以及安全的治理——“不典型的股骨骨折与颌骨的坏死”的披露的诚实、“药物的假期”的政策、以及药物警戒的反馈环路（[[pharmacology/adverse-reactions]]、[[musculoskeletal/fractures]]）。**
:::

::: exercise 安全地运行穿刺的门诊 {level=3}
为“关节的注射与穿刺”设计一个日间单元：适应证、安全的核查、同意、感染控制、抗凝、治理。
::: solution
**临床的脊柱——疑似化脓的关节绝不用日间单元、而是直接去骨科（[[#def-red-flags]]）；晶体与骨关节炎与滑囊与“肩关节的注射”的诊室、配上“超声引导的准确性”的证据、以及“注射后休息、不要立刻负重使用”的计划（[[musculoskeletal/osteoarthritis]]、[[clinical-skills/medical-imaging]]）。安全的核查——与放射科及血液科共同的方案来决定抗凝的阈值、以及“绝不扣住那记救命的穿刺、但”择期的激素“可以推迟”这个逻辑（[[blood/haemostasis-bleeding]]、[[blood/thrombosis-anticoagulation]]）；感染控制——“清洁而非无菌的野”这一证据对实践、以及给糖尿病患者“注射后血糖”的咨询（[[infectious-diseases/healthcare-infections]]、[[endocrine/diabetes-complications]]）；同意与沟通——注射后的急性发作与失眠与面部潮红、以及“肌腱或软骨的罕见的伤害”、以及“往关节里打激素既是一项治疗、也是一项诊断的试验”这个框架（[[clinical-skills/communication]]、[[pharmacology/adverse-reactions]]）；治理——可追溯性与批号的记录与皮肤的核对表与并发症的标志、以及对“疼痛的评分与再注射的间隔”的审计（[[clinical-skills/records-handover]]、容量的那一行见[[public-health/health-systems-economics]]）。**
:::

::: exercise 读流行病学 {level=2}
肌肉骨骼的疼痛是全球“带残疾生存的年数”的首要的原因、却只消耗卫生预算中很小的一份。请给出这一错配的三个机制与一项指标的修正。
::: solution
**机制——那个“用生存、而不是用失能来计价”的指标的偏倚它低估了残疾、以及那种“弥散而不是局限”的性质它让以医院为中心的服务失灵、以及康复与社区的肌肉骨骼的人力相对于“操作性的专科”的低地位（[[public-health/determinants-inequalities]]、[[epidemiology-ebm/measuring-disease]]、[[public-health/health-systems-economics]]）；指标的修正——按“失能调整的生命年或带残疾生存年数的减少、以及功能的量表、以及重返工作、以及疼痛的登记”来资助与比较、而不是按入院的次数；以及“把肌肉骨骼的疾病当作慢性疼痛的疾病”这一政策的重构连同心理与睡眠及工作的整合——[[public-health/prevention-promotion]]、[[psychiatry/anxiety-disorders]]、[[epidemiology-ebm/critical-appraisal]]。**
