结缔组织病和血管炎是医学中伟大的模仿者。一位疲乏、关节痛伴皮疹的年轻女性；一位头痛伴双肩酸痛的老年男性；一位咳嗽、尿血并流鼻血的吸烟者：每个人都可能患有一种即将损害肾脏、眼睛或大脑的系统性自身免疫病。这些疾病单独来看都不常见，但合起来是年轻成人和老年人严重疾病的重要原因，而且如果能早期识别，其中许多现在都可以很好地治疗。

本章贯穿两种技能。第一是**模式识别**：知道哪些特征组合提示哪种疾病。第二是**明智地使用自身抗体检查**：临床表现相符时它们很有力，不相符时则会误导。本章依次讲述系统性自身免疫性风湿病（系统性红斑狼疮、抗磷脂综合征、干燥综合征、系统性硬化症和炎性肌病），然后是风湿性多肌痛和巨细胞动脉炎，最后是血管炎的分类和治疗。自身免疫的免疫学见[[immunology/autoimmunity]]；炎症性关节炎见[[musculoskeletal/inflammatory-arthritis]]。

## 自身抗体及其使用 {#sec-antibodies}

**抗核抗体（ANA）**检测是结缔组织病常用的筛查试验。它以人上皮细胞（HEp-2）层为底物，用间接免疫荧光法进行：把患者血清逐步稀释，报告仍能看到核染色的最高稀释度（滴度）以及染色模式。几乎所有系统性红斑狼疮患者ANA都阳性，因此阴性结果对排除该病非常有用。但低滴度ANA在健康人中也很常见，尤其是女性和老年人，也见于感染、自身免疫性甲状腺病等其他自身免疫病以及某些癌症。

::: theorem 验前概率决定抗体检查的意义 {#thm-pretest}
自身抗体阳性提示患病的概率，即**阳性预测值**，不仅取决于检查的敏感性和特异性，还取决于受检者患病的**验前概率**。根据贝叶斯定理，

$$\text{PPV} = \frac{\text{敏感性} \times p}{\text{敏感性} \times p + (1 - \text{特异性}) \times (1 - p)},$$ {#eq-ppv}

其中$p$是验前概率。当$p$很低时，即使特异性良好的检查，其阳性结果也大多是假阳性。
:::

::: proof
设想1,000个人。其中比例为$p$的人患病，检查能检出其中一定比例（敏感性）：这些是真阳性。其余$1 - p$的人未患病，检查错误地把其中比例为$(1 - \text{特异性})$的人判为阳性：这些是假阳性。PPV等于真阳性除以全部阳性。由于假阳性是庞大健康人群的一部分，只要受检人群中该病罕见，假阳性就会淹没真阳性。只检测临床表现已提示该病的人，可以提高$p$，缩小健康人群，从而提高PPV。
:::

::: example 疲乏女性的ANA阳性 {#ex-ana}
一名34岁女性因疲乏和全身酸痛六个月就诊于全科医师。体格检查正常。血常规、肾功能、尿液分析、CRP和甲状腺功能均正常。ANA检测报告为1:80阳性，斑点型。她担心自己患了狼疮。假设系统性红斑狼疮的验前概率为1%，ANA敏感性98%，特异性87%。她患系统性红斑狼疮的概率是多少？应该怎么做？
::: solution
用[[#eq-ppv]]，或用1,000名类似女性的自然频数：

- 患系统性红斑狼疮者：$1{,}000 \times 0.01 = 10$，其中约$9.8$人检测阳性；
- 未患系统性红斑狼疮者：$990$，其中$990 \times 0.13 \approx 128.7$人检测阳性。

PPV $= 9.8 / (9.8 + 128.7) \approx 0.071$，约为**7%**。

因此，没有特异性表现的低滴度ANA阳性，意味着系统性红斑狼疮的可能性仍然不大。她不需要因为这一结果而接受治疗。合理的做法是：解释这一结果意味着什么、不意味着什么；再次寻找特异性表现（光敏性皮疹、口腔溃疡、炎症性关节炎、浆膜炎、雷诺现象、血细胞减少、蛋白尿）；考虑疲乏和全身疼痛的其他原因；并做好安全网：如果出现特异性表现，再做更特异的检查（抗dsDNA、可提取核抗原抗体、补体）并转诊风湿科。教训是：当临床表现提示结缔组织病时才申请ANA，而不是把它当作疲乏的筛查。
:::
:::

## 系统性红斑狼疮 {#sec-sle}

::: definition 系统性红斑狼疮 {#def-sle}
**系统性红斑狼疮（SLE）**是一种慢性多系统自身免疫病，特征为针对核抗原的抗体、免疫复合物沉积和补体激活。女性患病率约为男性的九倍，通常在十几岁后期至四十几岁起病，在非洲、加勒比、亚洲和西班牙裔血统人群中更常见，且往往更严重。

其表现包括：

- **全身症状**：疲乏、发热、体重下降；
- **皮肤黏膜**：光敏性皮疹；面颊和鼻部的**颧部（“蝶形”）红斑**，不累及鼻唇沟；盘状狼疮（留瘢痕的斑块）；无痛性口腔溃疡；非瘢痕性脱发；
- **肌肉骨骼**：炎症性关节痛或关节炎，通常无骨侵蚀；即使出现畸形也可复位（Jaccoud关节病）；
- **浆膜炎**：胸膜炎、心包炎；
- **肾脏**：**狼疮肾炎**，可能直到晚期都没有症状；
- **血液**：溶血性贫血、白细胞减少、淋巴细胞减少、血小板减少；
- **神经精神**：癫痫发作、精神病、认知障碍、卒中；
- **免疫学**：ANA、抗dsDNA、抗Sm、抗磷脂抗体，以及**补体降低（C3和C4）**，后者反映疾病活动期免疫复合物对补体的消耗。

2019年EULAR/ACR分类标准要求ANA滴度至少1:80作为准入条件，然后在临床和免疫学领域中加权计分；总分10分或以上且至少有一项临床标准，即分类为系统性红斑狼疮。
:::

一个有用的实验室线索是：活动性系统性红斑狼疮常使**血沉**升高，而**CRP**保持正常或仅轻度升高。狼疮患者CRP显著升高提示感染或浆膜炎，应促使寻找感染，而感染是系统性红斑狼疮的主要死因之一。

**狼疮肾炎**见于相当一部分系统性红斑狼疮患者，是致病的主要原因之一。免疫复合物沉积在肾小球，可引起从轻度蛋白尿到快速进展性肾小球肾炎的各种表现。由于它常没有症状，系统性红斑狼疮患者要定期检查**血压**、**尿试纸**（血和蛋白）、**尿蛋白/肌酐比值**和肾功能。显著蛋白尿或活动性尿沉渣应进行**肾活检**，以对疾病分型（Ⅰ至Ⅵ型）并指导治疗。

::: definition 系统性红斑狼疮的治疗原则 {#def-sle-treatment}
- 除非有禁忌，几乎所有系统性红斑狼疮患者都使用**羟氯喹**：它减少复发、器官损害和血栓形成，并改善生存。长期使用者需要视网膜筛查。
- **防晒**，因为紫外线会诱发复发。
- 复发时用**糖皮质激素**，剂量尽可能低、时间尽可能短，因为它们是长期损害的主要原因（骨质疏松症、糖尿病、白内障、缺血性坏死、感染、心血管疾病）。
- 根据受累器官使用**免疫抑制剂**：皮肤和关节病变用甲氨蝶呤或硫唑嘌呤；狼疮肾炎诱导治疗用**吗替麦考酚酯**或小剂量静脉**环磷酰胺**；部分病例使用生物药物，如**贝利尤单抗**（针对B细胞活化因子）、**阿尼鲁单抗**（针对Ⅰ型干扰素受体）和**利妥昔单抗**。
- **关注长期风险**：心血管危险因素、骨健康、疫苗接种，以及**妊娠计划**（受孕前疾病应至少稳定六个月，药物必须与妊娠相容，并须了解抗Ro和抗磷脂抗体状况）。
:::

::: example 伴脚踝水肿的狼疮复发 {#ex-nephritis}
一名26岁尼日利亚裔女性两年前确诊系统性红斑狼疮（颧部红斑、关节炎、ANA和抗dsDNA阳性），六个月前停用了羟氯喹。现在她脚踝水肿。血压152/96 mmHg。尿试纸显示蛋白3+、血2+；尿蛋白/肌酐比值为310 mg/mmol。肌酐从68升至104 µmol/L。抗dsDNA升高，C3和C4降低。发生了什么？处理原则是什么？
::: solution
这是**系统性红斑狼疮复发伴活动性狼疮肾炎**：大量蛋白尿（蛋白/肌酐比值310 mg/mmol约相当于每天3 g，达到肾病范围）、血尿、新发高血压和肌酐上升，伴血清学活动（抗dsDNA升高、补体降低）。停用羟氯喹可能是诱因之一。

**处理原则**（在肾脏科和风湿科专科环境中，遵循当地指南）：

1. **紧急肾活检**以确诊并对肾炎分型；增生性肾炎（Ⅲ型和Ⅳ型）需要强化免疫抑制。
2. **诱导治疗**：糖皮质激素（常先静脉甲泼尼龙，再口服泼尼松龙并按计划减量）加**吗替麦考酚酯**或小剂量静脉**环磷酰胺**；可加用贝利尤单抗等药物。
3. **重新开始羟氯喹**。
4. **肾脏保护**：控制血压，使用ACE抑制剂或血管紧张素受体阻滞剂减少蛋白尿；处理水肿和血脂。
5. **妊娠**：吗替麦考酚酯和环磷酰胺有致畸性，因此有效避孕和妊娠试验必不可少。
6. **预防治疗的危害**：骨保护、有指征时预防感染、疫苗接种。

狼疮肾炎在非洲和加勒比血统人群中更常见，历史上结局也更差，因此定期尿液监测尤其重要。
:::
:::

### 抗磷脂综合征

**抗磷脂综合征（APS）**是一种自身免疫病，持续存在的抗磷脂抗体导致**血栓形成**（静脉、动脉或小血管）和**病理妊娠**。它可以单独发生（原发性APS），也可以与系统性红斑狼疮并存。诊断需要典型的临床事件加上**间隔至少12周的两次**抗体阳性，因为感染时抗体可以一过性出现。病理妊娠包括反复早期流产、不明原因的胎儿死亡，以及因重度子痫前期或胎盘功能不全而早产。2023年ACR和EULAR修订了分类标准。

伴血栓形成的APS患者通常需要**长期使用华法林**。APS**不**推荐使用直接口服抗凝药，尤其是三种抗体都阳性（“三阳性”）者，因为一项利伐沙班试验因血栓事件过多而提前终止。妊娠期间，APS女性在专科照护下使用**小剂量阿司匹林**，并根据病史使用**低分子量肝素**（[[blood/thrombosis-anticoagulation]]、[[obstetrics-gynaecology/pregnancy-complications]]）。

### 干燥综合征

**干燥综合征**（Sjögren病）是一种慢性自身免疫病，淋巴细胞浸润外分泌腺，尤其是泪腺和唾液腺，引起**眼干**和**口干**（干燥症状）、腮腺肿大、疲乏和关节痛。它可以是原发性的，也可以伴随RA或系统性红斑狼疮。系统表现包括间质性肺病、肾小管酸中毒、周围神经病、血管炎和血细胞减少。抗Ro、抗La抗体和类风湿因子常见。**B细胞淋巴瘤**风险明显增加，尤其是唾液腺黏膜相关淋巴组织（MALT）淋巴瘤；持续性腺体肿大应进行检查。治疗以对症为主（人工泪液和人工唾液、口腔护理），系统病变用羟氯喹或免疫抑制剂。

### 系统性硬化症与雷诺现象

**雷诺现象**是指动脉对寒冷或情绪产生的过度血管痉挛反应。手指先变白（缺血），再变紫（脱氧），然后变红（反应性充血）。**原发性雷诺现象**常见，起病于十几或二十几岁，呈对称性，无组织损伤，ANA阴性，**甲襞毛细血管**正常。**继发性雷诺现象**提示存在基础疾病：其特征包括约30岁后起病、不对称、指端溃疡或凹陷性瘢痕、ANA阳性，以及甲襞毛细血管异常（扩张或缺失）。系统性硬化症是最重要的病因。

**系统性硬化症（SSc）**兼有小血管损伤、自身免疫以及皮肤和内脏纤维化。按皮肤增厚的范围分型：

- **局限皮肤型SSc**：手、前臂、足和面部皮肤增厚；雷诺现象病史长；**抗着丝点**抗体。其特征曾被概括为CREST：钙质沉着、雷诺现象、食管动力障碍、指端硬化和毛细血管扩张。晚期严重并发症是**肺动脉高压**，每年用超声心动图、肺功能和NT-proBNP筛查。
- **弥漫皮肤型SSc**：皮肤增厚快速进展，扩展到上臂、大腿或躯干，早期即有内脏受累：**间质性肺病**（与抗Scl-70相关）和**硬皮病肾危象**（与抗RNA聚合酶Ⅲ相关）。

**硬皮病肾危象**表现为突发的严重高血压和急性肾损伤，有时伴微血管病性溶血。它用**ACE抑制剂**治疗，这使它从通常致命的并发症变为可治疗的并发症。中高剂量糖皮质激素是已知的诱因，因此在弥漫型SSc中要谨慎使用。

### 炎性肌病

**特发性炎性肌病**引起肌肉炎症和无力：

- **皮肌炎**：对称性**近端肌无力**（从椅子上站起、爬楼梯、举臂困难），伴特征性皮肤体征：上眼睑紫红色的**向阳性皮疹**、指关节伸面的**Gottron丘疹**、上胸部和背部的光敏性皮疹（V字征和披肩征），以及甲襞毛细血管扩张。在成人中它与**癌症**相关，尤其是诊断后最初几年，因此要进行与年龄和性别相适应的癌症筛查。
- **多发性肌炎**（在识别出抗体定义的亚组后，这一诊断现在用得较少）和**抗合成酶综合征**（肌炎、间质性肺病、关节炎、发热、雷诺现象和皲裂的“技工手”，伴抗Jo-1或相关抗体）。
- **免疫介导的坏死性肌病**，包括由他汀类药物诱发、伴抗HMG-CoA还原酶抗体的类型。
- **包涵体肌炎**：见于50岁以上者，男性更多；**指屈肌**和**股四头肌**缓慢进展性无力，常不对称；对免疫抑制治疗无反应。

检查包括**肌酸激酶**（升高，常显著升高）、肌炎特异性抗体、肌肉MRI、肌电图和肌肉活检，以及肺功能和吞咽评估。皮肌炎和多发性肌炎的治疗使用糖皮质激素加甲氨蝶呤、硫唑嘌呤或吗替麦考酚酯等节制激素药物，难治性病例用静脉免疫球蛋白或利妥昔单抗。

## 风湿性多肌痛与巨细胞动脉炎 {#sec-pmr-gca}

这两种疾病见于50岁以上者，常相互重叠，有共同的炎症过程。约五分之一的风湿性多肌痛患者会发生巨细胞动脉炎，而许多巨细胞动脉炎患者有多肌痛症状。

**风湿性多肌痛（PMR）**引起双侧**肩带和髋带**及颈部的疼痛和僵硬，早晨最重，亚急性起病，通常伴血沉和CRP升高。肌力和肌酸激酶正常。对中等剂量泼尼松龙（例如每天15 mg）的反应通常在数天内十分显著；无反应应促使重新考虑诊断。随后在一年或更长时间内缓慢减量，并进行骨保护。由于晚发型RA、骨髓瘤和其他癌症、甲状腺功能减退、感染和他汀类肌病等疾病可以模仿PMR，建议进行基线检查（血常规、肾功能、肝功能和甲状腺功能、血钙、蛋白电泳、肌酸激酶、尿液分析，常加胸片）。

::: definition 巨细胞动脉炎 {#def-gca}
**巨细胞动脉炎（GCA）**是大、中动脉的肉芽肿性血管炎，尤其累及颈外动脉的分支（包括颞动脉）、眼动脉和睫后动脉，以及主动脉及其主要分支。几乎总是发生在50岁以上者。

典型特征包括：

- **新发头痛**，常在颞部；
- **头皮压痛**（梳头时疼痛）；
- **下颌跛行**（咀嚼时颌部肌肉疼痛），是最特异的症状；
- **视觉障碍**：一过性视力丧失（一过性黑蒙）、复视，或前部缺血性视神经病变所致的突发无痛性永久视力丧失；
- 全身表现（发热、体重下降、疲乏）和多肌痛症状；
- 体格检查发现颞动脉增粗、压痛或无搏动；上肢跛行或双臂血压不等提示大血管受累。

血沉和CRP通常升高。诊断通过**颞动脉超声**（水肿的动脉壁形成“晕征”）或**颞动脉活检**（肉芽肿性炎症伴巨细胞）证实；但由于存在跳跃性病变，活检阴性不能排除GCA。
:::

::: warning 不要等待活检
疑似GCA是内科急症，因为缺血性视神经病变所致的视力丧失很少恢复，而且另一只眼可能在数天内相继受累。高度怀疑GCA时，在超声或活检之前**立即开始大剂量糖皮质激素**。英国风湿病学会指南（2020年）建议大多数人每天使用泼尼松龙40至60 mg，有视觉症状者考虑静脉甲泼尼龙，并通过**快速通道**紧急评估；新发视力丧失或复视应当天由眼科医师评估。开始使用激素后，活检所见至少在一到两周内仍可检出。随后继续治疗并缓慢减量，同时进行骨保护；复发或难治性病例使用**托珠单抗**（IL-6受体阻滞剂）。
:::

::: example 头痛与一只眼视物模糊 {#ex-gca}
一名74岁女性新发右侧头痛三周。梳头时头皮痛，吃肉后下颌酸痛。今天早晨，她右眼视野变灰约五分钟后恢复。她体重下降了3 kg。右颞动脉增粗、压痛。血沉86 mm/h，CRP 64 mg/L。现在应该怎么做？
::: solution
在被证明不是之前，这是**巨细胞动脉炎**，并有一次**一过性视力丧失（一过性黑蒙）**，提示永久失明的风险很高。

1. **立即开始大剂量糖皮质激素**，就在今天，不等待确诊。由于她有视觉症状，可按当地指南静脉给予甲泼尼龙，随后口服大剂量泼尼松龙。
2. 因视觉症状**当天进行眼科评估**，并**通过GCA快速通道紧急转诊**做颞动脉超声和（或）活检；这些应在数天内完成，开始使用激素后仍有诊断价值。
3. **支持措施**：骨保护（钙、维生素D，通常加双膦酸盐），有指征时胃保护，并监测血糖和血压。检查有无大血管受累（双臂脉搏和血压）。
4. **长期**：在监测下缓慢减量；如复发或无法减量，使用托珠单抗。

50岁以上者出现新发头痛、头皮压痛、下颌跛行、视觉症状和炎症标志物显著升高，这一组合使诊断的可能性很高。短疗程激素的风险远小于失明的风险。
:::
:::

## 血管炎 {#sec-vasculitis}

**血管炎**是血管壁的炎症，可导致出血、狭窄、闭塞或动脉瘤，从而使所供应的组织缺血。其表现取决于受累血管的大小和分布。

::: definition 按血管大小对血管炎分类 {#def-vasculitis}
2012年修订的**国际Chapel Hill共识会议**命名主要按受累血管的大小对血管炎分类。

| 血管大小 | 疾病 | 主要特征 |
|---|---|---|
| **大血管**（主动脉及其主要分支） | 巨细胞动脉炎 | 50岁以上；颅部动脉和主动脉 |
| | 大动脉炎（Takayasu动脉炎） | 通常为40岁以下女性；主动脉及其分支；无脉、上肢跛行 |
| **中等血管**（主要内脏动脉） | 结节性多动脉炎 | 坏死性动脉炎伴微动脉瘤；累及肾、肠、神经和皮肤；与乙型肝炎相关；ANCA阴性；不累及肾小球 |
| | 川崎病 | 幼儿；发热、结膜炎、口唇红、皮疹、手足肿胀、淋巴结肿大；冠状动脉瘤 |
| **小血管**，ANCA相关 | 肉芽肿性多血管炎 | 上呼吸道（鼻窦炎、鼻腔结痂、鞍鼻）、肺结节、肾小球肾炎；抗PR3 |
| | 显微镜下多血管炎 | 肾小球肾炎和肺出血；抗MPO |
| | 嗜酸性肉芽肿性多血管炎 | 哮喘、嗜酸性粒细胞增多、神经病；少数ANCA阳性（通常为MPO） |
| **小血管**，免疫复合物 | IgA血管炎（过敏性紫癜） | 主要见于儿童；腿部和臀部可触及的紫癜、关节痛、腹痛、肾炎 |
| | 冷球蛋白血症性血管炎 | 紫癜、关节痛、神经病、肾炎；与丙型肝炎相关 |
| | 抗GBM病 | 肾小球肾炎和肺出血 |
| **可变血管** | 白塞综合征 | 反复口腔和生殖器溃疡、葡萄膜炎、皮损、静脉和动脉血栓形成 |
:::

**小血管炎**典型表现为**可触及的紫癜**（压之不褪色的隆起紫色斑点，通常在腿部）、**肾小球肾炎**（血尿、蛋白尿、红细胞管型、肌酐上升）、**肺出血**（咯血、浸润影、血红蛋白下降）、多发性单神经炎，以及巩膜外层炎或巩膜炎。肺和肾同时受累，即**肺肾综合征**，是内科急症。

**ANCA相关血管炎**（AAV）分两个阶段治疗。**诱导**阶段以糖皮质激素加**利妥昔单抗**或**环磷酰胺**达到缓解；对部分严重肾病或肺出血者考虑血浆置换；口服补体C5a受体抑制剂**阿伐可泮**可用于减少糖皮质激素暴露。随后以利妥昔单抗或硫唑嘌呤进行数年的**维持**治疗。未经治疗的全身性AAV通常在一年内致命；经过治疗大多数人能存活，但复发、肾损害和感染仍是主要问题。

::: example 鼻出血与尿血 {#ex-gpa}
一名58岁男性鼻塞、鼻腔结痂伴血性分泌物三个月，按鼻窦炎治疗。两周来他出现咳嗽带血丝、关节酸痛和胫前皮疹。肌酐210 µmol/L（一年前为85）。尿试纸显示血3+、蛋白2+。胸片显示两个空洞性结节。最可能的诊断是什么？如何证实？有多紧急？
::: solution
最可能的诊断是**肉芽肿性多血管炎（GPA）**，一种ANCA相关小血管炎，累及**上呼吸道**（结痂、血性分泌物）、**肺**（空洞性结节、咯血）和**肾**（肌酐迅速上升伴血尿和蛋白尿，提示快速进展性肾小球肾炎）。胫前皮疹可能是血管炎性紫癜。

**证实**：**ANCA**检测（抗PR3是GPA的典型表现；抗MPO更多见于显微镜下多血管炎）、抗GBM抗体（抗GBM病也引起肺肾综合征）、尿镜检寻找红细胞管型，以及**组织活检**（通常为肾活检），显示寡免疫性坏死性新月体性肾小球肾炎。胸部和鼻窦CT确定病变范围。必须排除感染（鉴于有空洞，包括结核）。

**紧急程度**：这是**内科急症**。肾功能可在数天内丧失，肺出血可以致命。他需要当天转诊到肾脏科或血管炎团队；一旦高度怀疑诊断，常立即开始糖皮质激素加利妥昔单抗或环磷酰胺治疗，有时在活检结果出来之前。如果对每个不明原因全身性疾病的患者都做尿试纸检查，就能提前数周发现这一问题。
:::

::: history
1862年，法国医师**莫里斯·雷诺（Maurice Raynaud）**在博士论文中描述了发作性的指端缺血。四年后的1866年，**阿道夫·库斯莫尔（Adolf Kussmaul）**和**鲁道夫·迈尔（Rudolf Maier）**描述了今称结节性多动脉炎的结节性动脉炎。1890年，**乔纳森·哈钦森（Jonathan Hutchinson）**描述了一名颞动脉疼痛发炎的老年男性；1932年，梅奥诊所的**贝亚德·霍顿（Bayard Horton）**及其同事把颞动脉炎确定为一种独立的疾病。1936年，**弗里德里希·韦格纳（Friedrich Wegener）**描述了长期以他命名的肉芽肿性血管炎；后来这一名称被肉芽肿性多血管炎取代，部分原因是他曾是纳粹党员。1948年，梅奥诊所的**马尔科姆·哈格雷夫斯（Malcolm Hargraves）**在狼疮患者骨髓中描述了“LE细胞”，这是第一项自身免疫病的实验室检查，开启了自身抗体时代。1983年，伦敦的**格雷厄姆·休斯（Graham Hughes）**及其同事描述了血栓形成、流产和抗磷脂抗体组成的综合征，该综合征以他的名字被称为休斯综合征。
:::

## 后续内容

这些疾病的免疫机制在[[immunology/autoimmunity]]和[[immunology/hypersensitivity]]中展开。肾小球肾炎和急性肾损伤见[[renal/acute-kidney-injury]]和[[renal/chronic-kidney-disease]]，间质性肺病和肺动脉高压见[[respiratory/interstitial-vascular-disease]]，血栓形成见[[blood/thrombosis-anticoagulation]]。自身免疫病患者的妊娠在[[obstetrics-gynaecology/pregnancy-complications]]中讨论，川崎病见[[paediatrics/acute-childhood-illness]]。狼疮和皮肌炎的皮肤表现与[[musculoskeletal/skin]]相关。

::: summary
- 结缔组织病和血管炎是多系统疾病；诊断依靠临床模式加有针对性的自身抗体检查。
- 抗体阳性的意义取决于验前概率：没有特异性表现者的低滴度ANA通常不意味着狼疮。ANA阴性使系统性红斑狼疮的可能性很小。
- 系统性红斑狼疮累及皮肤、关节、浆膜、血液、肾和脑，伴ANA、抗dsDNA、抗Sm和补体降低。监测尿液和血压以发现肾炎。几乎所有人都用羟氯喹；尽量减少激素。
- 抗磷脂综合征引起血栓形成和病理妊娠；抗体必须持续存在12周。血栓形成后用华法林，而不是直接口服抗凝药。
- 系统性硬化症：局限型（抗着丝点、肺动脉高压）与弥漫型（抗Scl-70伴肺纤维化；抗RNA聚合酶Ⅲ伴肾危象，用ACE抑制剂治疗）。继发性雷诺现象有甲襞毛细血管异常。
- 皮肌炎兼有近端肌无力、典型皮疹，并与癌症相关；包涵体肌炎累及指屈肌和股四头肌，对免疫抑制无反应。
- PMR引起肢带疼痛和僵硬，对激素反应显著。GCA是急症：立即开始大剂量糖皮质激素并安排快速通道评估。
- 血管炎按血管大小分类（Chapel Hill 2012）。肺肾综合征是急症；ANCA相关血管炎用糖皮质激素加利妥昔单抗或环磷酰胺治疗，然后维持治疗。
:::

::: exercise 检查的预测值 {level=1 check="round(100*0.02*0.98/(0.02*0.98+0.98*0.05))"}
在风湿科门诊，一项检查对某病的敏感性为98%，特异性为95%，受检者中该病的验前概率为2%。计算阳性预测值，以百分数表示并四舍五入到整数。
::: solution

::: exercise 双肩酸痛 {level=2}
一名71岁男性双肩和双髋疼痛僵硬六周，早晨加重，持续两小时。他起床困难。测试肌力正常。血沉58 mm/h，CRP 36 mg/L。(a) 最可能的诊断是什么？(b) 你会专门询问哪三个症状？为什么？(c) 开始治疗前应做哪些检查？
::: solution
(a) **风湿性多肌痛**。

(b) 询问**头痛**、**下颌跛行**和**视觉障碍**（以及头皮压痛），因为相当一部分患者同时有巨细胞动脉炎，这会改变处理：需要紧急、更大剂量的糖皮质激素和快速通道评估。

(c) 排除类似疾病的检查：血常规、肾功能和肝功能、血钙、甲状腺功能、**肌酸激酶**（排除肌炎）、蛋白电泳（骨髓瘤）、尿液分析，常加类风湿因子或抗CCP以及胸片。然后用中等剂量泼尼松龙治疗，缓慢减量并进行骨保护；约一周内无反应应促使重新考虑诊断。
:::

::: exercise APS的抗凝 {level=2}
一名39岁女性首次发生无诱因的深静脉血栓形成，发现狼疮抗凝物、抗心磷脂和抗β2-糖蛋白Ⅰ抗体均阳性，14周后复查再次证实。她要求服用直接口服抗凝药，因为它不需要验血。你会给出什么建议？为什么？
::: solution
她患有**三阳性**的**抗磷脂综合征**，血栓风险最高。现行指南建议**长期使用华法林**（监测INR）而不是直接口服抗凝药，因为一项在高风险（三阳性）APS中比较利伐沙班与华法林的随机试验，因利伐沙班组血栓事件（主要是动脉血栓）过多而提前终止。她还应得到妊娠计划方面的建议：华法林有致畸性，因此在怀孕前或一经确认怀孕，应在专科照护下改用低分子量肝素（加小剂量阿司匹林）。
:::

::: exercise 老年男性的手无力 {level=2}
一名69岁男性三年来抓握和爬楼梯困难缓慢加重。体格检查发现指屈肌和股四头肌无力，左侧更重。肌酸激酶轻度升高。他曾因推测为多发性肌炎而服用泼尼松龙，但没有改善。最可能的诊断是什么？为什么这很重要？
::: solution
最可能的诊断是**包涵体肌炎**：50岁以后起病，男性更常见，缓慢进展，**指屈肌**和**股四头肌**常不对称性无力，肌酸激酶轻度升高，**对糖皮质激素无反应**。肌肉活检（镶边空泡、炎症、蛋白聚集）和抗体（部分患者有抗cN1A）支持诊断。这很重要，因为免疫抑制治疗无效且有害，所以应撤停激素；处理包括物理治疗、预防跌倒、吞咽评估（吞咽困难常见）和支持治疗。
:::
:::

::: exercise 对血管炎分类 {level=3}
对每个病例，说出最可能的血管炎及受累血管大小：(a) 一名6岁儿童咽痛后出现臀部和腿部可触及的紫癜、膝痛和绞痛性腹痛；(b) 一名3岁儿童发热五天，双侧非化脓性结膜炎，口唇皲裂发红，皮疹，手部肿胀；(c) 一名28岁女性上肢跛行，双臂血压不等，锁骨下动脉处有杂音；(d) 一名45岁乙型肝炎患者，睾丸痛、足下垂、新发高血压，ANCA阴性。
::: hint
结合年龄和伴随表现，使用[[#def-vasculitis]]中的表格。
:::
::: solution
(a) **IgA血管炎**（过敏性紫癜）：小血管，免疫复合物型。检查尿液和血压以发现肾炎。

(b) **川崎病**：中等血管。需要紧急儿科治疗，静脉免疫球蛋白加阿司匹林，并做超声心动图检查冠状动脉瘤。

(c) **大动脉炎**：大血管，典型见于年轻女性。

(d) **结节性多动脉炎**：中等血管，经典地与乙型肝炎相关；引起多发性单神经炎、肾动脉受累伴高血压和睾丸痛，ANCA阴性。抗病毒治疗是处理的一部分。
:::
:::

::: exercise 解读检查结果 {level=3}
一名66岁女性不适、关节痛和气促两周，检查结果：血红蛋白92 g/L（三周前为128），肌酐340 µmol/L，尿试纸血3+、蛋白2+，胸片双侧肺泡影，MPO-ANCA强阳性，抗GBM阴性，ANA阴性，补体正常。(a) 这是什么综合征？(b) 最可能的诊断是什么？(c) 血红蛋白下降的原因是什么？(d) 当前的首要任务是什么？
::: hint
把肺和肾的发现放在一起，然后用抗体结果在该综合征的各种病因中作出选择。
:::
::: solution
(a) **肺肾综合征**：肾小球肾炎（肌酐迅速上升伴血尿和蛋白尿）加肺泡影。

(b) **显微镜下多血管炎**，一种MPO-ANCA相关血管炎。抗GBM阴性使抗GBM病的可能性较小，补体正常和ANA阴性不支持狼疮。

(c) **弥漫性肺泡出血**：肺泡内出血导致肺部阴影和血红蛋白下降，即使没有明显咯血。肾病和炎症所致的贫血也可能有影响。

(d) 首要任务：评估并支持**氧合**（她可能需要高级呼吸支持）；紧急转诊肾脏科和血管炎团队；排除感染；条件安全时行**肾活检**；及时开始**诱导治疗**，大剂量糖皮质激素加利妥昔单抗或环磷酰胺，对严重肾受累或肺泡出血按专科指南考虑血浆置换。可能需要透析。延误会使患者失去肾功能和生命。
:::
:::
