炎症性的关节炎是“延迟会损害关节、而损害会夺走独立”的那一组：**类风湿关节炎与它的亲族在最初的几个月里就摧毁关节、痛风多年里无声地摧毁肾与肌腱、而两者在早期并积极地治疗时都会有戏剧性的反应——这让本章在很大程度上讲的是速度、模式的识别、以及“治疗达标”的纪律。**

本章涵盖类风湿关节炎、脊柱关节炎这一族、晶体的关节病、以及“反应性与感染性的相邻”。

## 类风湿关节炎

::: definition 类风湿关节炎：从免疫学到床旁 {#def-ra}
**免疫学（在一个“遗传上易感的宿主”中，对“被瓜氨酸化与被修饰的自身的抗原”失去了耐受——人类的白细胞抗原DRB1的共享表位、以及“吸烟黏膜的创伤与瓜氨酸化”的论证、以及“牙周与类风湿因子及抗环瓜肽抗体的分层”——遗传的风险在[[genetics/common-disease-genetics]]、先天与适应的机制在[[immunology/innate-immunity]]与[[immunology/adaptive-responses]]、以及[[immunology/hypersensitivity]]那种III型与IV型的过敏的色彩；滑膜作为战场——巨噬细胞与T细胞及成纤维的基质的编排、肿瘤坏死因子与白细胞介素6及17及1、以及B细胞与自身抗体的往来、血管的生成、以及血管翳对“骨与软骨的界面”的侵犯、以及为什么侵蚀会出现在“血管翳碰到裸区的皮质”的地方——每一类生物制剂背后的细胞因子的逻辑在[[immunology/vaccines-immunotherapy]]）；临床的图景对称的、炎症的滑膜炎，落在手、足与腕、伴掌指与近端指间及跖趾的肿而避开远端指间、长时间的晨僵并随活动而改善、典型的“以周计隐匿起病”的病程与急性的“复发缓解的变异”；以及关节外的那本账——类风湿的结节与间质性的肺病及胸腔的积液与巩膜炎及表层巩膜炎与“继发干燥综合征”与血管炎及神经病变与正细胞的贫血与血小板增多及Felty综合征及大血管的炎症——[[respiratory/interstitial-vascular-disease]]、[[nervous-system/motor-systems]]、[[blood/anaemia]]、血管炎的相邻见[[musculoskeletal/connective-tissue-vasculitis]]；以及“颈椎的不稳与寰枢的半脱位”（带着它的麻醉与外科的含义、还有“环杓关节与气道”一行——[[surgery/anaesthesia-pain]]、[[musculoskeletal/back-pain]]）；诊断与预后的判断临床的模式加抗环瓜肽抗体与类风湿因子、加C反应蛋白与血沉、加“用于亚临床的滑膜炎与侵蚀的超声或磁共振”——同时记住“血清阴性的疾病确实存在、而血清的阳性预示着侵蚀性的严重的疾病”——[[clinical-skills/laboratory-tests]]、[[clinical-skills/medical-imaging]]；份“分类的标准不是诊断的标准”的诚实、以及那个“转诊紧迫性的阈值不应该取决于C反应蛋白高到某个程度”（模式的几行见[[musculoskeletal/bones-joints]]、[[epidemiology-ebm/diagnostic-tests]]）；以及现代的目标：按一份复合的指标达到缓解或低疾病的活动度（[[clinical-skills/records-handover]]。）**
:::

::: definition 类风湿关节炎：治疗的阶梯 {#def-ra-treatment}
**传统改善病情的药甲氨蝶呤作为锚定的药——带着它的叶酸的补充与“每周一次给药错误的护栏”与肝的毒性及肺炎及血细胞的减少的监测与致畸性及药物的相互作用——完整的药理学见[[pharmacology/dosing-principles]]与[[pharmacology/adverse-reactions]]与[[pharmacology/drug-development-prescribing]]；来氟米特与柳氮磺吡啶与羟氯喹、带着它们各自监测的卡片与超敏的反应、以及羟氯喹“视网膜筛查的时代”（眼科的相邻——眼底筛查见[[nervous-system/sensory-systems]]；以及“联合的策略对早期的生物制剂的升级”，配上“以递减的剂量做激素的桥接”与“省激素的紧迫性”——危害的那几行见[[endocrine/adrenal]]、骨的保护见[[endocrine/bone-calcium]]）；生物制剂与靶向的合成的小分子（抗肿瘤坏死因子与抗白细胞介素6的受体及阿巴西普及利妥昔单抗及“Janus激酶的抑制剂”这几大家族、它们的机制与细胞因子的生物学的对应映射在[[immunology/vaccines-immunotherapy]]；用生物制剂之前的那次安全的清扫——结核与乙丙型肝炎及人免疫缺陷病毒与疫苗的接种的状态、以及“恶性与淋巴增殖的病史”、以及心力衰竭与脱髓鞘的告诫、以及“Janus激酶时代的静脉血栓与主要的不良的心脏事件及带状疱疹”的信号——[[infectious-diseases/tuberculosis]]、[[microbiology/viruses]]、[[infectious-diseases/hiv]]、[[cardiovascular/heart-failure]]、[[nervous-system/neuroinflammation]]、[[blood/leukaemia]]；活的疫苗的排除、以及每年的流感与肺炎链球菌及“带状疹重组的疫苗”的政策、以及那段“被免疫抑制者的旅行”的谈话——[[public-health/vaccination-programmes]]、[[infectious-diseases/tropical-infections]]；以及围手术期与妊娠与哺乳的修改——甲氨蝶呤的停药日期、以及羟氯喹与柳氮磺吡啶的相容性、以及“抗肿瘤坏死因子的经胎盘的转运的时机”——[[obstetrics-gynaecology/contraception-fertility]]、[[surgery/perioperative-care]]、[[pharmacology/patient-variation]]）；支持与外科的边缘（手与足的治疗与夹板与鞋与运动及体能的训练、以及工作场所的适应、以及驾驶与器械的评估——[[public-health/prevention-promotion]]、[[physiology/muscle]]；滑膜的切除与肌腱的修补及断裂的重建、以及“被摧毁的肩与肘与髋与膝的关节置换”——[[surgery/orthopaedics]]。）**
:::

::: example “醒来时僵”的手 {#ex-early-ra}
一名41岁的教师双侧的腕与掌指及近端指间肿了8周、晨僵2小时、疲劳、C反应蛋白42、类风湿因子阳性、抗环瓜肽抗体强阳性；手的X线正常。
::: solution
**早期的类风湿关节炎——X线正常也一样——侵蚀要好几个月、而“转诊与治疗的那扇窗”就是现在（[[#def-ra]]）：按临床的综合征与血清学做紧急的风湿科的转诊、不等X线、甚至不等第二套血、必要时用超声记录滑膜炎（[[clinical-skills/medical-imaging]]、[[musculoskeletal/bones-joints]]）；抗环瓜肽抗体的阳性与高的炎症负荷，把这一例标记为“侵蚀轨迹的类型”、并证明了“改善病情的药要快”、而不是“等等看它会不会自己平息”（[[#def-ra-treatment]]）；初始的方案逻辑——以甲氨蝶呤为锚、配叶酸与安全的血液检查、以及一段“激素桥接的递减”配上骨的保护与胃的保护的算术、以及每4到12周一次“治疗达标”的复查、如果没走上轨道就升级——省激素才是重点（[[pharmacology/dosing-principles]]、[[endocrine/bone-calcium]]）；抢先的咨询——生育的计划与疫苗的接种、以及戒烟它是一个真正的疾病严重度的修饰因子、以及工作场所的谈话、以及“在用甲氨蝶呤之前的避孕的核查”（[[obstetrics-gynaecology/contraception-fertility]]、[[public-health/vaccination-programmes]]、[[pharmacology/patient-variation]]）；以及那场“轨迹”的谈话——以现代的治疗，“缓解并过正常的生活”就是预期的结局、而“我们已经无法只靠及时性来预防的损害”这个论证[[clinical-skills/communication]]、[[public-health/health-systems-economics]]。**
:::

## 脊柱关节炎这一族

::: definition 脊柱关节炎：脊柱、附着点、皮肤、肠道 {#def-spa}
**这一族与机制（强直性脊柱炎与银屑病性的关节炎及反应性的关节炎及“肠病性的关节炎”及未分化的簇、伴人类的白细胞抗原B27的关联、以及“黏膜的免疫与白细胞介素23到17这条轴”的病灶、以及“附着点炎作为原发的病灶”与类风湿的滑膜炎的对照——主要组织相容性复合体的遗传学见[[genetics/common-disease-genetics]]、免疫的逻辑见[[immunology/adaptive-responses]]、而“皮肤与肠道与关节的串扰”见[[musculoskeletal/skin]]与[[gastrointestinal/bowel-disease]]）；轴心的疾病在年轻人身上隐匿起病的“炎症性的背痛”——45岁之前起病、以周计隐匿、晨僵超过30分钟、夜间的疼痛并“因活动而非休息”而缓解、以及“对非甾的反应良好”这一线索——交替臀部的疼痛、以及“胸廓的扩张与 腰部活动度 试验及髋的活动试验及肋椎关节”这套检查——[[musculoskeletal/back-pain]]、[[clinical-skills/physical-examination]]；影像的进展——从“骶髂关节磁共振上的活动性炎症的病灶”到X线上的侵蚀与硬化、再到融合、以及“融合的脊柱在轻微创伤下骨折的风险”——[[clinical-skills/medical-imaging]]、[[musculoskeletal/fractures]]；以及“额外的”——急性的前葡萄膜炎（问那只红、痛、怕光的眼、当日请眼科——[[nervous-system/sensory-systems]]；主动脉瓣的关闭不全与传导的疾病及心尖的纤维化那几行——[[cardiovascular/valve-congenital-disease]]、[[cardiovascular/arrhythmias]]；以及“病程长久融合的疾病”中那少见的终末的马尾综合征——[[musculoskeletal/back-pain]]）；外周与附着点的类型（不对称的下肢的寡关节炎与“腊肠趾的指炎”、以及跟腱与足底及肋软骨区域的“侵蚀性的附着点炎”、以及银屑病性关节炎的模式：不对称的寡关节、以远端指间为主、“残缺性的关节炎”、以及“强直的改变”——银屑病的几行见[[musculoskeletal/skin]]、对照的几行见[[#def-ra]]）；反应性的关节炎（在“生殖泌尿的沙眼衣原体”与“胃肠的空肠弯曲菌与沙门菌及志贺菌及耶尔森菌”之后的那种“无菌的滑膜炎”、带着它的结膜炎与葡萄膜炎及“环状的龟头炎”及“掌跖的角皮病”的变异、份关于“人类的白细胞抗原B27与慢性化及复发”的诚实的咨询、句“不要为关节去追抗生素”的要点、以及“当性传播的感染还在活动时治疗触发因素”的规则——[[infectious-diseases/sexually-transmitted-infections]]、[[gastrointestinal/bowel-disease]]、[[microbiology/bacteria]]。）**
:::

## 晶体

::: definition 痛风与钙的晶体 {#def-crystals}
**尿酸盐的生物学（嘌呤代谢的终末产物、以排泄为主的“肾的处理”、尿酸转运体与有机阴离子转运体及“尿酸盐外排的转运体”的变异；高尿酸血症来自饮食与酒精与啤酒与“含糖的饮料”及肾功能的不足与利尿药与肥胖及银屑病及细胞的周转、以及领先的遗传学——核苷酸代谢的家在[[cell-biochemistry/lipid-amino-acid-metabolism]]、肾的转运在[[renal/tubular-function]]、药物引起高尿酸的清单在[[pharmacology/adverse-reactions]]；以及“单尿酸钠的晶体激活炎症小体、引发白细胞介素1驱动的中性粒细胞的滑膜炎”——一堂用一个病讲完的“先天免疫的课”——[[immunology/innate-immunity]]）；急性的痛风第一跖趾那个“夜间爆发”的经典、以及踝与膝及肘及滑囊及中足的变异；那个“它会模仿化脓的关节炎”的真相与“不要假定”的规则、以及“诊断性的穿刺细胞内的、负的双折光的、针状的晶体”；触发因素——疾病的发作与手术及禁食及一次酒精的暴食及创伤、以及“开始或停止降尿酸治疗”、以及那句“发作时尿酸可以正常”的经典告诫；治疗——有效剂量非甾的或秋水仙碱带着肾与药物的相互作用及骨髓抑制的现实、或多病者用激素的注射或口服、以及那条“绝不突然停用已经建立的降尿酸治疗、也绝不在急性的关节上启动它”的规则（被现行的指南所细化——[[renal/acute-kidney-injury]]、秋水仙碱吸收的相邻见[[gastrointestinal/digestion-absorption]]）；慢性与痛风石性的痛风（那类“治疗不足、诊断不足”的“慢性破坏性尿酸负荷的疾病”、带痛风石与慢性的滑膜炎及“带悬边的骨的侵蚀”、以及“通常多年都没有被怀疑”这个诊断的现实、以及那一簇肾与代谢的共存病——[[renal/chronic-kidney-disease]]、[[cardiovascular/hypertension]]、[[endocrine/diabetes]]、共存见[[musculoskeletal/osteoarthritis]]）；降尿酸的治疗“治疗达标到0.36以下、痛风石者到0.30以下”的逻辑；别嘌醇“低起点、缓慢加量”、带着“在某些族裔中的严重的超敏”与“出皮疹立即停药”的规则——药物基因组学的案例见[[pharmacology/patient-variation]]与[[genetics/common-disease-genetics]]；非布司他带着那份心血管的告诫；以及“促尿酸排泄的药”（苯溴马隆与“丙磺舒在低排泄型中的位置——带着”水化与尿酸的酸化及药物的相互作用“的核查。）**
:::

::: example 利尿药之后那只红的趾 {#ex-gout}
一名70岁在服用氢氯噻嗪样的利尿药与小剂量的阿司匹林既往的心肌梗死，出现12小时爆发的右侧第一跖趾关节、红到一碰就痛、是一个喝过葡萄酒的生日之后的夜里；体温37.8、白细胞13、C反应蛋白98；这是第一次发作。
::: solution
**经典急性的痛风、外加一个“虽小但不要跳过”的排除（[[#def-crystals]]）：如果关节能穿而怀疑还在，就穿刺——晶体的确认与感染的排除“用同一支注射器完成”——低热的白细胞增多在痛风与化脓的关节炎中一模一样（危险信号的规则见[[musculoskeletal/bones-joints]]、[[clinical-skills/laboratory-tests]]）；立即用“考虑了共存病”的选择治疗——“近期的心梗与肾及高血压的背景”使非甾的不合适，于是用按剂量调整的秋水仙碱、或单关节的关节内的激素、或短程口服激素、以及那句“不要因痛风而停阿司匹林”、以及与处方者一起复查利尿药（[[cardiovascular/coronary-artery-disease]]、[[pharmacology/adverse-reactions]]、[[pharmacology/dosing-principles]]）；场“这不是一种一次发作的疾病”的谈话——复发与痛风石及肾与心血管及代谢的轨迹、以及“至少在第二次发作时提供降尿酸的治疗、如果有慢性肾病或痛风石现在就提供”（[[renal/chronic-kidney-disease]]、[[cardiovascular/hypertension]]、[[endocrine/diabetes]]）；份诚实的饮食与生活方式的账——饮酒的模式与含糖的饮料与体重、以及“回避嘌呤的效果是温和的、不是要人禁欲”（[[gastrointestinal/clinical-nutrition]]、[[psychiatry/substance-use]]）；以及预防的规划——如果启动了降尿酸，就同时处方“发作的覆盖”、并解释为什么“第一周会引起疼痛的那片药、到第五年会预防畸形”（[[pharmacology/dosing-principles]]、[[clinical-skills/communication]]）。**

::: example 片“从来不只是皮肤”的皮疹 {#ex-psa}
一名38岁有6个月的右侧示指肿痛像“一根腊肠”、跟腱与胸壁的痛、以及她称为“皮肤干”的指甲剥脱；类风湿因子与抗环瓜肽抗体阴性、C反应蛋白28；皮肤科的检查发现了她从未提起的头皮斑块。
::: solution
**按模式就是银屑病性的关节炎——指炎加附着点炎加指甲病加头皮的银屑病加血清阴性的炎症（[[#def-spa]]、[[musculoskeletal/skin]]）：诊断与转诊的那一步——为“早期炎症银屑病性的疾病”请早期的风湿科，因为外周的侵蚀性的类型会进展、而治疗的窗口就是现在、而“阴性类风湿的血清学”是支持、而不是安心（对照见[[#def-ra]]）；在开药之前做一次“领域的清点”——数过的关节与附着点与指炎与脊柱与皮肤皮损的面积与严重度的指数与指甲与生活质量、以及肠道与眼睛之问、以及那一簇“肥胖与高血压及血脂异常及脂肪肝及抑郁”的代谢的共存病——[[gastrointestinal/liver-disease]]、[[cardiovascular/hypertension]]、[[psychiatry/mood-disorders]]；治疗的逻辑——轻的外周用非甾的与物理治疗、外周用传统改善病情的药、而“生物制剂或靶向的选择按主导的领域”决定（白细胞介素17与23及肿瘤坏死因子及Janus激酶各自的证据画像、以及“用抗肿瘤坏死因子时矛盾地出现银屑病”这份诚实；而炎症的肠病或葡萄膜炎会把选择推向单克隆的抗肿瘤坏死因子或17或Janus、皮肤为主则偏向23而17对肠病无效——[[immunology/vaccines-immunotherapy]]、[[gastrointestinal/bowel-disease]]、[[nervous-system/sensory-systems]]）；以及“全人”的那一层——那种污名与“洗得太用力”及“头皮藏在帽子里”的谈话，而“皮肤与风湿共同门诊”的一体化门诊的模型能从结构上修好它——[[public-health/health-systems-economics]]、[[clinical-skills/communication]]。**

::: example 老年人肿的手 {#ex-rs3re}
一名78岁有10周的双手与腕的对称的可凹性的水肿伴晨起僵硬、类风湿因子与抗环瓜肽抗体阴性、C反应蛋白轻度升高、无侵蚀；一位“非工作时间的医师”“为了风湿性多肌痛”给她开了泼尼松龙30毫克、部分缓解、而在减量时反复复发。
::: solution
**晚发的类风湿对“缓解性血清阴性的对称的滑膜炎伴凹陷性水肿”对风湿性多肌痛的重叠、以及由它造成的那台“激素的跑步机”（[[#def-other]]）：鉴别的细节——凹陷性的水肿与血清的阴性指向那一种老年男性的综合征；以腱鞘炎为主的超声与屈肌的鞘的炎症，支持晚发炎症的关节炎；那种“复发缓解的病程并累及肩带”会模糊风湿性多肌痛的边界、而两者可以共存——[[clinical-skills/medical-imaging]]、[[#def-ra]]；那种“减量时反复复发”应当触发的恶性与模仿者的清扫——副肿瘤性的“回环性风湿症”与老年成人中的“缓解性血清阴性的等价物”、以及“水肿的肢体”要排除感染与积脓——[[pathology/cancer-diagnosis]]、感染的规则见[[musculoskeletal/bones-joints]]；对这两种实体都适用的“省激素”的答案——甲氨蝶呤或羟氯喹或柳氮磺吡啶、以及在“许可允许”处的白细胞介素6的阻断、配“结构化缓慢减量的计划”，以及那份30毫克的激素在一名78岁身上大声呼唤的“骨与血糖与眼与血压的保护”的集束——[[endocrine/bone-calcium]]、[[endocrine/diabetes-complications]]、[[endocrine/adrenal]]、[[nervous-system/sensory-systems]]；以及系统的教训——针“在诊断之前就起了作用的非工作时间经验性的激素”，会把下游的一切都搅浑：共同决定的记录、早期风湿科复查的触发、以及那行“这个减量由谁负责”的记录——[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]。**

## 更宽的炎症的门诊

::: definition 风湿性多肌痛、病毒性与未分化的关节炎 {#def-other}
**风湿性多肌痛（那个65岁以上、双侧的肩与髋带的疼痛与僵硬的综合征、伴长时间的晨僵与血沉及C反应蛋白升高、以及“用小剂量的激素有戏剧性的反应”——它被“知情地用作诊断、而它本身不是诊断”——与巨细胞动脉炎重叠的“大血管的相邻”的生物学见[[musculoskeletal/connective-tissue-vasculitis]]、而超声上是腱与滑囊的影像的签名——[[clinical-skills/medical-imaging]]；处理的弧线——按指南的剂量起始泼尼松龙、缓慢而结构化的减量、以及复发的处理、以及“省激素的甲氨蝶呤与白细胞介素6的抑制剂”辅助、以及那段“两年激素的疗程”所要求的“骨与血糖与眼的保护”的集束——[[endocrine/bone-calcium]]、[[endocrine/diabetes-complications]]、下丘脑垂体肾上腺抑制的那几行见[[endocrine/adrenal]]；以及“不要漏掉的模仿者”——晚发的类风湿与多肌炎及甲状腺功能减退及恶性、以及佩吉特病以肩带为表现——[[endocrine/thyroid]]、肌炎的那一行见[[musculoskeletal/connective-tissue-vasculitis]]、佩吉特的那一行见[[endocrine/bone-calcium]]、[[pathology/cancer-diagnosis]]）。病毒性与病毒后的关节炎（细小病毒B19与乙丙型肝炎及风疹的疫苗相邻、以及“基孔肯雅与登革及寨卡及人免疫缺陷病毒的血清转换”及莱姆的“对称与游走的模式”、带着它们的暴露的病史与旅行及蜱及肝的问题——[[microbiology/viruses]]、[[infectious-diseases/tropical-infections]]、莱姆的那一行见[[microbiology/bacteria]]；份“大多数会自行限制”的咨询、基孔肯雅慢性化的那个例外、以及通向[[#def-spa]]的反应性关节炎的桥；以及把莱姆的关节炎放在“地方的暴露与先用抗生素后用抗炎”的序列之中——[[infectious-diseases/tropical-infections]]）。未分化与回环性的表现（那群“滑膜炎数周、尚未达到标准”的人：观望需要一个“有安全网的、带复查日期的”安排、配上血清学与超声的风险的分层、以及一条敞开的门——进展为类风湿的预测的文献、以及“在为痛风或类风湿或焦磷酸钙彩排”的回环性的发作——[[#def-ra]]、[[#def-crystals]]、[[musculoskeletal/osteoarthritis]]。）**
:::

::: definition 与免疫抑制共存 {#def-immunosuppressed-life}
**处方是一份契约的开始、不是一次门诊的结束。份常规的教育集“发热或新发的呼吸困难或咳嗽或腹泻或管路感染就今天打电话”的规则（配具名的联系人、以及“生病的日子不要停激素、但在严重感染时要停甲氨蝶呤或霉酚酸”的逻辑——[[endocrine/adrenal]]、[[clinical-skills/patient-safety]]）；份被安排在治疗之前的疫苗日历——每年的流感与肺炎链球菌及“带状疹重组的疫苗”及乙肝与人乳头瘤病毒及旅行的加强、带着“活疫苗的排除与家庭接触者的规则”——政策的细节见[[public-health/vaccination-programmes]]、而“利妥昔单抗的患者反应被钝化”的机制由[[immunology/adaptive-responses]]解释；日晒与皮肤的那一层——硫唑嘌呤的光敏、以及长期免疫抑制中皮肤癌的监测、以及“移植与生物制剂时代非黑色素的皮肤癌”的证据——[[musculoskeletal/skin]]、[[musculoskeletal/skin-cancer]]；围手术期与牙科的计划——哪种药为哪种操作停、用哪种覆盖重叠、以及“植入物的感染”的算术——[[surgery/perioperative-care]]；旅行的计划——活疫苗对目的地的矛盾、以及叮咬与水、以及药品的携带量与“液体与针头的携带的信”——[[infectious-diseases/tropical-infections]]、携带的信见[[clinical-skills/records-handover]]；生育的计划——逐药停药的日期、以及生育力保存的时机、以及哺乳的相容性——[[obstetrics-gynaecology/contraception-fertility]]；癌症筛查的姿态——被免疫抑制女性的宫颈筛查最低要求、以及皮肤与生活方式的红利——[[public-health/screening]]、[[obstetrics-gynaecology/gynaecological-cancer]]；以及“药物的假期”这个问题——谁在活动的缓解中“可以最先减什么、在多久之后”、复发风险的沟通、以及“生物类似药的费用与选择”的谈话——这些都由患者参与产生的那份治疗达标的数据来治理（[[pharmacology/dosing-principles]]、[[public-health/health-systems-economics]]、[[medical-ethics-law/consent-capacity]]。）**
:::

## 服务的形状：为什么“速度”才是那项干预

炎症性关节炎结局的梯度，组织学上的成分不亚于药理学的成分：从社区到风湿科转诊的间隔、早期关节炎门诊的通量、超声的可及性、治疗达标复查的纪律、以及护士与治疗师的升级的自主权，决定了患者是否真的在治疗的窗口之内收到了证据[[public-health/health-systems-economics]]、[[pharmacology/dosing-principles]]。荷兰与英国及澳洲的早期关节炎的队列项目显示：“承诺加方案”的门诊在缓解与工作的结局上击败了“专家排队”的门诊——而从缝隙里掉下去的人，不成比例地是贫困者、农村的人、不说当地语言的人、社交焦虑的人、以及“疼痛在被任何人检查关节之前就被归因于肥胖、年龄或心理健康”的人[[public-health/determinants-inequalities]]、[[psychiatry/anxiety-disorders]]、[[clinical-skills/communication]]。对生物制剂安全性登记的监测、为外科的那条尾巴设立国家关节的登记、以及“对转诊间隔在各贫困梯度上的公平性”的诚实的审计——就是那些不光彩的日常的机器，让整个领域保持诚实、也让本章的乐观保持诚实[[epidemiology-ebm/measuring-disease]]、[[public-health/screening]]。

对任何要建造或重建这样一个服务的人，有两个设计的选择值得强调。第一，把关的问题不是“这家门诊存不存在”，而是“由全科医师触发的转诊实际达成的间隔是多少、而在炎症模式滑膜炎的患者中有多大比例在这个间隔之内被看到”——把这个单一的指标测量出来、公布出来、并据此行动，它压缩损害曲线的程度超过任何新药[[public-health/health-systems-economics]]、[[epidemiology-ebm/observational-studies]]。第二，“改善病情的药与生物制剂的安全”所要求监测的工作量——化验、血压、疫苗的复查、骨的保护、皮肤的检查、生育的规划、流感状态的谈话——恰恰是护士主导与药师主导的“用药依从”的门诊能比“医师时间的稀缺”更好地交付的工作量，前提是“因急性发作与毒性升级到风湿科”的路径是明确的、有资源的、并被兑现的[[pharmacology/patient-variation]]、[[clinical-skills/records-handover]]、[[public-health/prevention-promotion]]。

::: history
**炎症关节炎的那个世纪：古代的“痛风尿与活动的结石坑”、以及列文虎克“通过显微镜看见针状的晶体”的那个时刻；阿奇博尔德·加罗德那句“先天代谢的错误”的框架，在转运体被克隆之前一个世纪就把痛风变成了一种“关于转运体的生物化学的疾病”——[[cell-biochemistry/lipid-amino-acid-metabolism]]、[[genetics/mendelian-inheritance]]；“类风湿的”命名的时代、与那个被亨奇的化合物E的革命刺破的“中世纪治疗的虚无主义”、以及在甲氨蝶呤进入风湿科之前那一场“有毒的金与抗疟药及青霉胺及环孢素”的轮换——[[endocrine/adrenal]]；从肿瘤坏死因子的克隆到抗体、再到整个生物制剂的军火库这条弧线——“细胞因子的思考”、最初的病人与奇迹般的反应、以及它催生出的“感染与恶性的风险”的科学——[[immunology/vaccines-immunotherapy]]、[[infectious-diseases/immunocompromised-host]]；白细胞介素6的受体与Janus激酶的抑制剂这一代、与治疗达标的一致意见、以及那个“以年为单位改变了预后”的早期转诊服务的设计——[[pharmacology/drug-development-prescribing]]、[[public-health/health-systems-economics]]；以及脊柱关节炎的统一——“这一族的识别”、全基因组的关联研究带来的“白细胞介素23这条轴”的遗传学的洪水、以及那台“在X线能看到之前就把病找到”的磁共振的革命——[[genetics/common-disease-genetics]]、[[clinical-skills/medical-imaging]]。**

::: exercise 处理“生物制剂的关口”处的潜伏结核 {level=2}

::: exercise 移植患者的痛风 {level=2}

::: summary
- 炎症的滑膜炎是一个“时间关键”的诊断：长时间的晨僵、掌指与腕及跖趾的肿、全身性炎症——在X线改变之前就转诊。
- 类风湿要用一枚“改善病情的药的锚”按目标治疗、并按时钟升级；激素负责桥接、绝不负责任掌舵。
- 脊柱关节炎是一个家族——脊柱、附着点、皮肤、肠道、眼——关于银屑病与肠病及葡萄膜炎及尿道炎的问题，本身就是检查的一部分。
- 痛风是一种“可治的尿酸转运的疾病”、带着一张“由白细胞介素1驱动”的炎症的脸；可能感染时要穿刺，而降尿酸时要做尿酸的治疗达标。
- 每一张免疫抑制的处方都连带着“感染与疫苗及妊娠及恶性及围手术期”的谈话、而谈话属于一个具名的服务、不属于运气。
- 风湿性多肌痛、晚发的与未分化的表现、是年长者得到“激素的跑步机”与漏诊的地方；一份减量的计划与一个复查的日期就是安全装备（[[#def-other]]）。
:::

**每周不是每天给药、用大号字体、指定一个具名的日子、第二天服叶酸——“按天服的错误是一项公认致命的错误”、安全的核对表都适用（[[pharmacology/dosing-principles]]、[[clinical-skills/patient-safety]]）；监测——血细胞与肾及肝的功能作为基线、之后按指南的间隔、并设一条“出血或口腔溃疡或呼吸困难就停药并讨论”的阈值（[[clinical-skills/laboratory-tests]]）；相互作用——甲氧苄啶与高剂量的非甾的及“质子泵的改变”及酒精及“怀孕的意图”、以及活疫苗的规则（[[pharmacology/adverse-reactions]]、[[public-health/vaccination-programmes]]）；警告——“怀孕的预防：双重避孕、男女都算、并在受孕前给出停药的日期”、以及“伴发热或新发的呼吸短促的感染，是一个今天就打电话、而不是明天的症状”[[obstetrics-gynaecology/contraception-fertility]]、肺炎的那一行见[[respiratory/interstitial-vascular-disease]]、[[clinical-skills/communication]]。**

::: exercise 为年轻人的背痛分类 {level=2}
一名23岁有5个月的臀部疼痛、在夜间的后半段更重、活动后好转、耳后有一块银屑病。检查怎么做？哪个是错误的第一个标签？
::: solution
**轴心与银屑病性的脊柱关节炎的模式（[[#def-spa]]）：炎症背痛的特征加夜间加交替加皮肤加附着点的清点、加葡萄膜炎与肠病的问题；检查——C反应蛋白与血沉、把人类白细胞抗原B27当背景（而不是诊断、骶髂关节的磁共振（配“短TI的反转恢复的序列”以及全脊柱与颈椎的基线、以及与皮肤及眼科及“肠道问卷”的配对（[[clinical-skills/medical-imaging]]、[[musculoskeletal/skin]]）；错误的标签——“机械的背痛”的安心与“只是银屑病的指甲”、以及那圈“非甾的有效、但没有诊断”的恶性循环——[[musculoskeletal/back-pain]]）；正确的路径——早期的风湿科配一段非甾的试验与“生物制剂的适格性”的思考、并把物理治疗与运动及戒烟与骨的健康打包在一起——年轻人用非甾的背景见[[pharmacology/adverse-reactions]]、[[endocrine/bone-calcium]]、[[physiology/muscle]]）；以及那一代“脊柱已融合”的人从未得到过的“预后与工作”的谈话——工作场所的谈话见[[public-health/health-systems-economics]]。**

::: exercise 围绕妊娠开药 {level=2}
一名29岁的类风湿控制良好者正在用甲氨蝶呤、羟氯喹与小剂量的泼尼松龙，她想要怀孕。请重建她的方案与时间线。
::: solution
**孕前那次重建（[[#def-ra-treatment]]、[[obstetrics-gynaecology/contraception-fertility]]）：停甲氨蝶呤配共同商定的“清洗的间隔、并回答”关于配偶的疑问“、然后桥接到”与妊娠相容的控制“——羟氯喹继续用并改善结局、柳氮磺吡啶配叶酸是相容的带着”男性因素“这个告诫、硫唑嘌呤是一个选项、而”抗肿瘤坏死因子的升级”可以按-certolizumab或阿达木的策略、并调整经胎盘转运的时机（[[pharmacology/patient-variation]]、[[immunology/vaccines-immunotherapy]]）；妊娠本身——“产后而不是孕期的急性发作的风险”、这个婴儿在“宫内暴露于生物制剂”之后“活疫苗要推迟”的疫苗日历、以及那张哺乳的相容性的表（[[public-health/vaccination-programmes]]、[[paediatrics/immunisation]]、[[obstetrics-gynaecology/postnatal-period]]）；泼尼松龙的减量、以及骨与妊娠相关风险的咨询（[[endocrine/bone-calcium]]、[[obstetrics-gynaecology/pregnancy-complications]]）；以及那份“什么在何时停、谁建议了什么”的记录与那封共同照护的信（[[clinical-skills/records-handover]]、[[clinical-skills/communication]]）。**

::: exercise 处理困难的痛风 {level=2}
一名66岁的痛风石性的痛风、滤过率38、心力衰竭、尽管“多年来一直吃别嘌醇100毫克”仍反复发作。三个失败是什么？计划是什么？
::: solution
**失败一，剂量不足（[[#def-crystals]]）：别嘌醇要按目标的尿酸滴定、远高于遗留的剂量——按肾功能调整起点、但仍然要滴定、目标定在0.36与0.30以下（[[pharmacology/dosing-principles]]、[[renal/chronic-kidney-disease]]）；失败二，没有发作的预防、也没有复查、于是每一次加量都把她吓退了（[[clinical-skills/records-handover]]）；失败三，没有人处理促成因素——利尿药与小剂量阿司匹林的背景、以及肥胖与酒精及肾的进展——以及那个被误诊的“慢性破坏性的疾病”依然无人触碰（[[pharmacology/adverse-reactions]]、[[cardiovascular/hypertension]]、[[gastrointestinal/clinical-nutrition]]、[[psychiatry/substance-use]]）。计划——确认诊断如果痛风石可及就穿刺查晶体与培养（危险信号的规则见[[musculoskeletal/bones-joints]]）、结构化的滴定配尿酸的监测、并按肾功能调整剂量的“秋水仙碱或非甾的”的覆盖、以及发作的计划、以及“痛风石减容的转诊”的思考、以及与心血管及肾的共同管理——并讨论非布司他与别嘌醇之间“心血管证据的立场”（[[cardiovascular/coronary-artery-disease]]、[[endocrine/diabetes]]）。**

::: exercise 设计生物制剂的安全系统 {level=3}
你的信托每年开始数百次生物制剂的输注与Janus激酶的处方。请建立安全的系统：筛查、疫苗、药物警戒、公平。
::: solution
**筛查的脊柱——份“结核与肝炎及人免疫缺陷病毒与肾及血液学及恶性史”的方案、配结果的追踪、以及“潜伏结核的评估没有闭合就绝不继续”的规则、以及由专科护士主导输注前的复查（[[infectious-diseases/tuberculosis]]、[[microbiology/viruses]]、[[clinical-skills/laboratory-tests]]）；疫苗的那一层——“治疗期间绝不接种活疫苗”的规则、以及在利妥昔单抗之前“按计划错开疫苗”的安排、以及“带状疹重组的疫苗”的使用、以及每年的流感与肺炎链球菌的政策（[[public-health/vaccination-programmes]]、[[immunology/vaccines-immunotherapy]]）；输液中心的设计——反应的识别与复苏的准备、以及“分级处理的输注反应”与教育（[[immunology/hypersensitivity]]、[[emergency-critical-care/anaphylaxis]]）；药物警戒——对罕见事件信号检出的现实、以及“Janus激酶与主要不良心脏事件及静脉血栓及带状疹”的标签的历史、以及直接报告的文化（[[pharmacology/adverse-reactions]]、[[pharmacology/drug-development-prescribing]]）；公平与准入的那一层——输液地点的地理、以及家庭输液与共同照护、以及“因工作交通签证与身份而中断的治疗”、以及妊娠与生育及青少年同意相邻的决定（[[public-health/determinants-inequalities]]、[[medical-ethics-law/consent-capacity]]）；以及费用的纪律——生物类似药转换的证据与沟通、以及真正能安全省钱的“治疗达标后的退出”的政策（[[public-health/health-systems-economics]]、[[pharmacology/dosing-principles]]）。**
