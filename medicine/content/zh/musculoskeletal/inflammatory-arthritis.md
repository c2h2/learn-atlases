在炎症性关节炎中，问题不在关节的力学，而在于免疫系统或晶体对关节的攻击。滑膜本是只有几层细胞厚的薄衬里，此时变成充满免疫细胞和新生血管的增厚炎症组织，炎症可在数月内侵蚀软骨和骨。与骨关节炎不同，这些疾病可以累及全身；也与骨关节炎不同，它们对正确的治疗反应显著。这两点结合起来，使快速识别成为本章最重要的临床技能。

本章涵盖三组疾病：**类风湿关节炎**，最常见的自身免疫性炎症性关节炎；**脊柱关节炎**，它们共同与HLA-B27相关，并倾向于累及附着点和脊柱；以及**晶体性关节炎**，即痛风和焦磷酸钙沉积病。本章以[[musculoskeletal/bones-joints]]中的关节解剖和炎症性与机械性的区分，以及[[immunology/autoimmunity]]中的免疫学为基础。

## 类风湿关节炎 {#sec-ra}

::: definition 类风湿关节炎 {#def-ra}
**类风湿关节炎（RA）**是一种慢性系统性自身免疫病，主要特征是手足小关节**持续性、对称性、炎症性多关节炎**；如不治疗，会导致软骨和骨侵蚀、畸形和残疾。

它影响约0.5%至1%的成人，女性约为男性的两到三倍，最常在30至60岁起病。大多数患者有自身抗体：**类风湿因子（RF）**，一种针对IgG的Fc段的抗体（通常为IgM）；以及**抗环瓜氨酸肽（抗CCP）抗体**，又称抗瓜氨酸化蛋白抗体（ACPA）。约70%的患者RF阳性，但它不特异（也见于其他自身免疫病、慢性感染和一些健康老年人）。抗CCP抗体敏感性相近，但对RA的特异性高得多，通常超过95%。
:::

### 病因与机制

RA源于基因与环境的相互作用。最强的遗传风险在于**HLA-DRB1**的某些等位基因，它们在肽结合槽中共有一段序列（“共同表位”）。最明确的环境危险因素是**吸烟**，它促进肺内的**瓜氨酸化**（蛋白质中精氨酸转变为瓜氨酸）。在遗传易感者中，瓜氨酸化蛋白被当作外来物，出现抗CCP抗体，常在任何关节症状出现之前数年。

在关节内，活化的T细胞、B细胞和巨噬细胞驱动滑膜增生。滑膜成纤维细胞变得具有侵袭性，增厚的滑膜称为**血管翳**，在关节边缘覆盖并长入软骨和骨。细胞因子**肿瘤坏死因子（TNF）**、**白细胞介素-6（IL-6）**和**白细胞介素-1**驱动炎症，并通过RANKL刺激破骨细胞，在滑膜与骨相接处产生**骨侵蚀**。IL-6还作用于肝脏，导致CRP升高、乏力和慢性病贫血。这些步骤中的每一步都已成为药物靶点。

### 临床特征

典型起病在数周至数月内，**掌指（MCP）**关节、**近端指间（PIP）**关节、腕关节和**跖趾（MTP）**关节出现疼痛、肿胀和**长时间晨僵**（常超过一小时），通常是对称性的。横向挤压MCP或MTP关节会引起疼痛。远端指间关节典型地不受累。膝、肩、肘和踝等较大关节也可受累。乏力、低热和体重下降常见。

未经治疗的长期病变会产生特征性畸形：MCP关节处手指**尺侧偏斜**、**天鹅颈**和**纽扣花**畸形，以及**Z形拇指**。在颈部，**寰枢关节半脱位**可压迫脊髓，这在气管插管和全身麻醉时很重要。

RA是一种系统性疾病。**关节外表现**包括类风湿结节、**间质性肺病**和胸腔积液、**巩膜炎**和巩膜外层炎、继发性**干燥综合征**（眼干和口干）、贫血、Felty综合征（RA伴脾大和中性粒细胞减少）、类风湿血管炎、**骨质疏松症**，以及显著增加的**心血管疾病**风险——后者是超额死亡的主要原因。由于炎症得到更早控制，这些表现现在已较少见。

::: definition 2010年ACR/EULAR分类标准 {#def-ra-criteria}
美国风湿病学会和EULAR的分类标准适用于至少有一个关节存在明确临床滑膜炎、且不能用其他疾病更好解释的人。把四个领域的得分相加；总分**10分中达到6分或以上**即分类为明确的RA。

| 领域 | 类别 | 分值 |
|---|---|---|
| A. 关节受累 | 1个大关节 | 0 |
| | 2–10个大关节 | 1 |
| | 1–3个小关节（有或无大关节受累） | 2 |
| | 4–10个小关节（有或无大关节受累） | 3 |
| | 超过10个关节（至少1个小关节） | 5 |
| B. 血清学 | RF和抗CCP均阴性 | 0 |
| | RF或抗CCP低滴度阳性（不超过正常上限的3倍） | 2 |
| | RF或抗CCP高滴度阳性（超过正常上限的3倍） | 3 |
| C. 急性期反应物 | CRP和血沉正常 | 0 |
| | CRP或血沉异常 | 1 |
| D. 症状持续时间 | 少于6周 | 0 |
| | 6周或以上 | 1 |

小关节指MCP、PIP、第二至第五MTP、拇指指间关节和腕关节。大关节指肩、肘、髋、膝和踝关节。分类标准的设计目的是为研究识别同质的人群；在临床上，它们支持但不能取代专科诊断。
:::

::: example 早期关节炎的分类 {#ex-classify}
一名44岁吸烟女性，双手疼痛肿胀10周。风湿科医师发现四个MCP关节、两个PIP关节和右腕关节有滑膜炎。抗CCP抗体为180 U/mL（正常上限7），RF阴性。CRP为24 mg/L（正常低于5）。应用2010年标准。
::: solution
- **关节**：4个MCP + 2个PIP + 1个腕 = 7个小关节，属于“4–10个小关节”：**3分**。
- **血清学**：抗CCP超过正常上限的25倍，属于高滴度阳性：**3分**。
- **急性期反应物**：CRP升高：**1分**。
- **病程**：10周，为6周或以上：**1分**。

总分$= 3 + 3 + 1 + 1 = 8$，达到6分或以上，因此她符合RA的分类标准。她的高滴度抗CCP和吸烟史提示侵蚀性疾病风险较高，因此治疗目标应是**缓解**（NICE NG100），戒烟也是治疗的一部分。
:::
:::

### 类风湿关节炎的处理

现代RA治疗的核心理念是：早期、持续地控制炎症可以防止关节损害。

::: theorem 早期治疗与达标治疗 {#thm-treat-to-target}
在炎症性关节炎中，**炎症活动期间不可逆的关节损害不断累积**。因此，当症状出现后尽早开始改善病情治疗，并反复调整治疗以达到既定目标——**缓解**，或在无法缓解时达到**低疾病活动度**——结局最好。
:::

::: proof
起病后数月内即可在X线片或MRI上看到骨侵蚀，而损害一旦形成就不会愈合。比较强化“达标治疗”策略（频繁测量疾病活动度，未达标时即升级治疗）与常规治疗的试验显示，前者炎症控制更好、影像学进展更少、功能更好，而费用相近。其道理与血压相似：被测量并据以行动的指标会得到改善。最初几个月可能是一个“机会窗口”，此时免疫过程更容易被改变，因此NICE建议对疑似持续性滑膜炎的人紧急转诊，并最好在症状持续三个月内开始传统改善病情抗风湿药（DMARD）。
:::

疾病活动度用综合评分测量。英国使用最广泛的是**DAS28**（基于28个关节的疾病活动度评分），它综合了28个关节（肩、肘、腕、MCP、PIP和膝）中压痛关节数（TJC）和肿胀关节数（SJC）、以mm/h为单位的血沉，以及患者对健康状况的总体评价（GH，0–100分）：

$$\text{DAS28} = 0.56\sqrt{\text{TJC}} + 0.28\sqrt{\text{SJC}} + 0.70\ln(\text{ESR}) + 0.014\,\text{GH}$$ {#eq-das28}

DAS28低于**2.6**表示缓解，3.2或以下为低疾病活动度，高于3.2至5.1为中度活动，高于**5.1**为高度活动。也有用CRP代替血沉的版本。

:::

::: definition 类风湿关节炎的药物 {#def-ra-drugs}
**传统合成DMARD（csDMARD）**

- **甲氨蝶呤**：基石药物。**每周一次**（口服或皮下注射），另一天服用叶酸以减少副作用。不良反应包括恶心、口腔溃疡、骨髓抑制、肝毒性和肺炎；需要血液监测。它有**致畸性**，计划怀孕前必须停用。
- **柳氮磺吡啶**：可在妊娠期使用；引起胃肠道不适、皮疹，罕见骨髓抑制。
- **来氟米特**：抑制嘧啶合成；引起腹泻、高血压和肝毒性；有致畸性，半衰期很长。
- **羟氯喹**：作用较弱，用于轻度或回纹型疾病以及联合用药；长期使用需要视网膜筛查。

**糖皮质激素**：在DMARD起效前（通常需要6至12周）作为短期“桥接”治疗（口服、肌内注射或关节腔内注射）。因其危害众多，避免长期使用。

**生物DMARD（bDMARD）**

- **TNF抑制剂**：阿达木单抗、依那西普、英夫利西单抗、培塞利珠单抗、戈利木单抗。
- **IL-6受体阻滞剂**：托珠单抗、沙利鲁单抗。
- **T细胞共刺激阻滞剂**：阿巴西普。
- **B细胞清除**：利妥昔单抗（抗CD20）。

**靶向合成DMARD（tsDMARD）**：口服的**Janus激酶（JAK）抑制剂**托法替布、巴瑞替尼、乌帕替尼和非戈替尼。

生物制剂和靶向药物增加感染风险。用药前要筛查**潜伏性结核**、**乙型和丙型肝炎**以及**HIV**，并更新疫苗接种；治疗期间一般避免接种活疫苗。由于试验数据显示托法替布的主要心血管事件和癌症多于TNF抑制剂，英国监管机构建议，对65岁或以上者、当前吸烟或既往长期吸烟者，以及有其他心血管或癌症危险因素者，只有在没有合适替代药物时才使用JAK抑制剂。
:::

在英国，NICE NG100（2018年）建议尽快提供一线**csDMARD单药治疗**（口服甲氨蝶呤、来氟米特或柳氮磺吡啶），对轻度或回纹型疾病可考虑以羟氯喹替代，考虑短期桥接糖皮质激素，如未达标则以逐步升级策略加用其他csDMARD。疾病活动期间，在专科每月测量CRP和DAS28等综合评分，直到达标。NICE技术评估规定了何时可以使用生物制剂和靶向药物，一般是在充分试用csDMARD后，DAS28测得的疾病活动度仍持续为中度或高度的人。

::: warning 甲氨蝶呤是每周一次的药
治疗RA的甲氨蝶呤**每周服用一次**，而不是每天一次。由于处方、配药或患者的差错而把每周剂量每天服用，曾导致严重骨髓抑制、黏膜炎和死亡。安全做法包括只开一种规格的片剂、在处方上写明星期几服药、向患者提供清晰的说明，以及检查相互作用：**甲氧苄啶**和复方磺胺甲噁唑（叠加的抗叶酸作用）与甲氨蝶呤合用尤其危险。任何服用甲氨蝶呤者出现咽痛、口腔溃疡、瘀斑或发热，都需要紧急查血常规。
:::

::: example 评估治疗反应 {#ex-das28}
一名52岁男性开始用甲氨蝶呤治疗RA。基线时有9个压痛关节和7个肿胀关节，血沉42 mm/h，总体健康评分64。三个月后有2个压痛关节和1个肿胀关节，血沉12 mm/h，总体健康评分20。计算两次的DAS28，并决定下一步。
::: solution
用[[#eq-das28]]：

基线：$0.56\sqrt{9} + 0.28\sqrt{7} + 0.70\ln 42 + 0.014 \times 64 = 1.68 + 0.741 + 2.616 + 0.896 \approx 5.93$。这是**高疾病活动度**（高于5.1）。

三个月：$0.56\sqrt{2} + 0.28\sqrt{1} + 0.70\ln 12 + 0.014 \times 20 = 0.792 + 0.28 + 1.739 + 0.28 \approx 3.09$。这是**低疾病活动度**（3.2或以下），但**未达到缓解**（低于2.6）。

他的反应良好，下降了近2.8个单位。是否升级治疗取决于既定目标。如果目标是缓解（NICE对进展风险较高者，如有抗CCP抗体或骨侵蚀者，建议以缓解为目标），下一步是优化甲氨蝶呤的剂量或给药途径，并考虑加用另一种csDMARD，继续每月复查直到达标。
:::
:::

## 脊柱关节炎 {#sec-spa}

::: definition 脊柱关节炎 {#def-spa}
**脊柱关节炎（SpA）**是一组具有共同临床、遗传和免疫学特征的炎症性疾病：

- **脊柱和骶髂关节**的炎症（中轴病变）；
- **不对称性少关节炎**，常累及下肢（外周病变）；
- **附着点炎**：肌腱和韧带附着于骨处的炎症，例如足跟处的跟腱和足底筋膜；
- **指（趾）炎**：整个手指或足趾肿胀（“腊肠指/趾”）；
- **关节外表现**：急性前葡萄膜炎、银屑病和炎症性肠病；
- 与**HLA-B27**相关，并与**IL-23/IL-17**通路相关，而不是与RA中的自身抗体相关。RF和抗CCP通常阴性，这就是这些疾病曾被称为“血清阴性”的原因。

主要成员是**中轴型脊柱关节炎**（包括X线片显示骶髂关节炎的**强直性脊柱炎**和X线片未显示骶髂关节炎的放射学阴性中轴型SpA）、**银屑病关节炎**、**反应性关节炎**和**炎症性肠病相关关节炎**。
:::

**中轴型脊柱关节炎**通常在十几岁后期至三十几岁起病。关键症状是**炎症性腰背痛**：大约40岁前隐匿起病，持续超过三个月，休息后加重、运动后改善，伴晨僵，下半夜痛醒，常有交替性臀部疼痛。晚期病变中，新生骨桥接椎体（韧带骨赘），形成僵硬的“竹节样脊柱”、腰椎前凸消失和固定的胸椎后凸；胸廓扩张度减小。由于腰背痛非常常见，诊断常延误数年；NICE NG65（2017年）列出了应促使转诊风湿科的特征。骶髂关节MRI能在X线片改变之前显示早期炎症。治疗把**运动和物理治疗**与**非甾体抗炎药**结合起来；如果疾病仍然活动，使用**TNF抑制剂**或**IL-17抑制剂**（司库奇尤单抗、依奇珠单抗）。甲氨蝶呤等传统DMARD对中轴病变无效，但柳氮磺吡啶可能对外周关节炎有帮助。

::: example 七年的"腰不好" {#ex-axspa}
一名31岁女性自24岁起腰和臀部疼痛。她看过好几位医务人员，被告知是“机械性腰痛”。疼痛使她在凌晨4点左右醒来，每天早晨僵硬一小时，游泳后感觉好些。去年她左眼红痛伴视物模糊，用糖皮质激素滴眼液治疗。布洛芬很有效。体格检查发现腰椎前屈受限。可能的诊断是什么？为什么被漏诊？现在应该怎么做？
::: solution
可能的诊断是**中轴型脊柱关节炎**。她有**炎症性腰背痛**（二十多岁起病、持续多年、下半夜夜间痛、晨僵时间长、运动后改善）、提示骶髂关节炎的交替性臀部疼痛、高度提示**急性前葡萄膜炎**的病史，以及对非甾体抗炎药反应良好。

漏诊的原因是：腰背痛极为常见，其中大多数是机械性的；医务人员并不总是专门询问炎症性腰背痛；而且中轴型SpA曾被认为主要累及男性，女性往往诊断较晚。平均数年的诊断延误已有充分记录。

她应**转诊风湿科**（NICE NG65把这些特征列为转诊理由）。检查通常包括**CRP**、**HLA-B27**以及**骶髂关节和脊柱MRI**，因为疾病早期X线片常正常。治疗把结构化运动方案与非甾体抗炎药结合起来，如果疾病仍然活动，使用TNF或IL-17抑制剂。应告诉她，今后任何眼红痛都要当天进行眼科检查。
:::
:::

**银屑病关节炎**发生于相当一部分银屑病患者，常被引用的比例是多达约三分之一。它可以先于皮肤病变出现。类型包括不对称性少关节炎、类似RA的对称性多关节炎、以**远端指间关节**为主的受累（与**甲病变**——甲凹点和甲剥离——密切相关）、中轴病变，以及罕见的破坏性**残毁性关节炎**。指（趾）炎和附着点炎常见。NICE建议每年用经过验证的工具（如银屑病流行病学筛查工具PEST）筛查银屑病患者是否有关节炎。治疗使用csDMARD（甲氨蝶呤也能治疗皮肤病变），然后是针对TNF、IL-17或IL-23的生物制剂，或其他靶向药物（[[musculoskeletal/skin]]）。

**反应性关节炎**是继发于身体其他部位感染的无菌性炎症性关节炎，通常发生在泌尿生殖道感染（*沙眼衣原体*）或胃肠炎（*沙门菌*、*志贺菌*、*弯曲菌*、*耶尔森菌*）后1至4周。典型表现为不对称性下肢少关节炎伴附着点炎，有时伴结膜炎或葡萄膜炎、尿道炎，以及手掌和足底的皮损。大多数病例在六个月内消退，但有些转为慢性。应在相关情况下寻找并治疗诱发感染，并处理性伴侣（[[infectious-diseases/sexually-transmitted-infections]]）。

## 晶体性关节炎 {#sec-crystals}

### 痛风

**痛风**由**尿酸钠**晶体在关节内及其周围沉积所致。尿酸是人体嘌呤代谢的终产物，因为人类缺乏尿酸酶。当血清尿酸持续高于其饱和点（体温下约6.8 mg/dL，即约400 µmol/L）时，就可能形成晶体，尤其是在较凉的外周关节。大多数尿酸升高的人从不发生痛风，但尿酸越高，风险越大。

::: definition 痛风 {#def-gout}
**痛风**是一种由尿酸钠晶体沉积引起的炎症性关节炎，源于血清尿酸持续升高（**高尿酸血症**）。表现为：

- **急性发作**：疼痛、发红和肿胀迅速出现，常在一夜之间，经典部位是**第一跖趾关节**（足痛风），也可见于中足、踝、膝、腕、指关节和鹰嘴滑囊；即使不治疗，发作通常在一至两周内消退；
- **痛风石**：尿酸盐晶体沉积物，常见于耳廓、肘、手指和关节周围，见于长期病变；
- **慢性痛风性关节炎**：长年未治疗的高尿酸血症后出现的持续性关节炎症和侵蚀性损害。

高尿酸血症通常反映尿酸**肾脏排泄减少**（约90%的病例），较少由**生成过多**所致。相关因素包括尿酸转运体的遗传变异、男性、肥胖、慢性肾脏病、高血压、饮酒（尤其是啤酒和烈酒）、含糖饮料和果糖、富含嘌呤的食物，以及药物：**噻嗪类和袢利尿剂**、小剂量阿司匹林和环孢素。生成过多见于细胞更新加快（骨髓增殖性疾病、肿瘤溶解）和罕见的酶缺陷。
:::

发作时的炎症由固有免疫系统驱动：巨噬细胞吞噬尿酸盐晶体，晶体激活**NLRP3炎症小体**，释放**白细胞介素-1β**，大量募集中性粒细胞。这解释了秋水仙碱（损害中性粒细胞功能和炎症小体激活）和IL-1阻滞剂为何有效。

在英国，NICE NG219（2022年）建议：

- **诊断**：一个或两个第一MTP关节迅速出现剧痛、发红和肿胀，或有痛风石时，应怀疑痛风。测定血清尿酸以证实临床诊断：**360 µmol/L（6 mg/dL）或以上**支持诊断。由于发作期间尿酸可能下降，发作期间低于360 µmol/L者应在发作消退至少两周后复查。诊断不确定时考虑关节穿刺和晶体显微镜检查；如不可行，则做影像学检查（X线、超声或双能CT）。关节发热时必须始终考虑**化脓性关节炎**。
- **治疗发作**：根据合并症、相互作用和患者意愿，选择非甾体抗炎药（加质子泵抑制剂）、**秋水仙碱**或短疗程**口服糖皮质激素**；这些不适合时用糖皮质激素注射；只有在其他方法都不适合时，经风湿科转诊后才使用IL-1抑制剂。冰敷有帮助。
- **降尿酸治疗（ULT）**：采用达标治疗策略，向多次或症状困扰的发作、3至5期慢性肾脏病、使用利尿剂、有痛风石或慢性痛风性关节炎的人**提供**；在首次或之后的任何一次发作后与患者讨论。ULT在发作消退至少2至4周后开始（如果发作频繁，也可在发作期间开始），从小剂量起始，根据血清尿酸每月加量。目标是低于**360 µmol/L（6 mg/dL）**；有痛风石、慢性痛风性关节炎或仍频繁发作者，目标是低于**300 µmol/L（5 mg/dL）**。**别嘌醇或非布司他**均可作为一线药物，但有严重心血管疾病者首选别嘌醇。加量期间可用秋水仙碱（或小剂量非甾体抗炎药或糖皮质激素）预防发作。ULT通常需终身使用，达标后每年复查尿酸。
- **生活方式**：没有证据表明特定饮食能预防发作；建议健康饮食、体重管理和限制饮酒。

有两种药物相互作用和一种遗传风险值得了解。**别嘌醇**抑制黄嘌呤氧化酶，而该酶也使**硫唑嘌呤**和巯嘌呤失活；两者合用可引起危及生命的骨髓抑制，除非在专科指导下大幅减少硫嘌呤剂量。别嘌醇是严重皮肤不良反应（Stevens–Johnson综合征、中毒性表皮坏死松解症和DRESS）的常见原因；携带**HLA-B\*58:01**者风险高得多，该等位基因在汉族、泰国和韩国人群中常见，一些指南建议对这些人群进行检测。**秋水仙碱**治疗窗窄，与克拉霉素等强效CYP3A4和P-糖蛋白抑制剂有相互作用；中毒先引起腹泻，然后是骨髓抑制和多器官衰竭。

::: example 首次发作还是长期治疗？ {#ex-gout}
一名58岁男性过去一年右大脚趾疼痛发作三次，每次持续约一周。他因高血压服用苄氟噻嗪，有慢性肾脏病，eGFR为52 mL/min/1.73 m²。今天距上次发作三周，他情况良好，无痛风石。血清尿酸为498 µmol/L。应该给他降尿酸治疗吗？如果应该，怎样进行？
::: solution
**应该。**按照NICE NG219，他符合**提供**ULT的多项标准：多次发作、**3a期CKD**（eGFR 45–59）和**利尿剂治疗**。

**时机**：发作已消退三周，符合“发作消退后2至4周”的建议。

**药物**：别嘌醇或非布司他；通常选用别嘌醇，如果他有严重心血管疾病则首选别嘌醇。从小剂量开始（CKD时剂量更低），根据血清尿酸每月加量。

**目标**：低于360 µmol/L，因为他没有痛风石或慢性关节炎。

**预防发作**：尿酸下降可使晶体动员，在最初几个月诱发发作，因此要讨论秋水仙碱预防，如他愿意则提供（注意他的肾功能和药物相互作用）。

**其他措施**：复查会升高尿酸的噻嗪类药物；可考虑换用其他降压药，如**氯沙坦**（有轻度促尿酸排泄作用）或钙通道阻滞剂。就饮酒、含糖饮料和体重给出建议，并解释ULT通常需要终身使用，加量期间的早期发作并不表示治疗失败。
:::
:::

### 焦磷酸钙沉积病

**焦磷酸钙沉积（CPPD）**病在老年人中常见。晶体在软骨中形成，在X线片上可表现为线状钙化（**软骨钙质沉着症**），尤其见于膝关节半月板和腕关节三角纤维软骨。急性**焦磷酸钙晶体性关节炎**（旧称“假性痛风”）在老年人中引起关节红热肿胀，典型部位是膝或腕，有时由疾病或手术诱发。关节穿刺可见**菱形、弱正性双折光**的晶体，穿刺对排除感染至关重要。发作的治疗包括关节穿刺抽液、关节腔内注射糖皮质激素、非甾体抗炎药或秋水仙碱；没有与降尿酸治疗相当的疗法。约60岁以下者出现CPPD，应检查相关的代谢性疾病：**甲状旁腺功能亢进症**、**血色病**、**低镁血症**和**低磷酸酯酶症**。

::: quiz
对一名新发炎症性关节炎患者，哪项特征最有力地支持银屑病关节炎而非类风湿关节炎？
- [ ] MCP关节对称性肿胀
- [ ] 抗CCP抗体阳性
- [x] 一个足趾的指（趾）炎伴甲凹点
- [ ] 晨僵持续两小时
::: solution
指（趾）炎（“腊肠”趾或指）和甲凹点是银屑病关节炎的典型表现。MCP对称性肿胀是RA的典型表现，尽管银屑病关节炎可以模仿它。抗CCP抗体强烈支持RA。长时间晨僵两者都有，只说明是炎症性疾病。
:::
:::

::: history
法国医师**奥古斯丁·雅各布·朗德雷-博韦（Augustin Jacob Landré-Beauvais）**在1800年的博士论文中描述了今天被认为是类风湿关节炎的疾病；19世纪40年代后期，伦敦的**阿尔弗雷德·巴林·加罗德（Alfred Baring Garrod）**证明痛风患者血中尿酸过多，从而把痛风与其他关节炎区分开来。1940年挪威的**埃里克·瓦勒（Erik Waaler）**和1948年纽约的**哈里·罗斯（Harry Rose）**描述了类风湿血清中一种能凝集致敏红细胞的因子：类风湿因子。1961年，**丹尼尔·麦卡蒂（Daniel McCarty）**和**约瑟夫·霍兰德（Joseph Hollander）**用偏振光显微镜在痛风滑液中发现了尿酸盐晶体。1973年报道了**HLA-B27**与强直性脊柱炎的强相关。1985年，**迈克尔·温布拉特（Michael Weinblatt）**及其同事发表对照试验，确立了每周小剂量甲氨蝶呤治疗RA的地位；1994年，**马克·费尔德曼（Marc Feldmann）**、**拉温德·梅尼（Ravinder Maini）**及其同事在随机试验中证明，用抗体（后来命名为英夫利西单抗）阻断TNF能降低RA活动度，开启了生物治疗时代。
:::

## 后续内容

系统性自身免疫性风湿病、风湿性多肌痛和血管炎见[[musculoskeletal/connective-tissue-vasculitis]]。炎症性腰背痛与机械性腰背痛的比较见[[musculoskeletal/back-pain]]，银屑病见[[musculoskeletal/skin]]。免疫机制在[[immunology/autoimmunity]]中展开，生物药物见[[immunology/vaccines-immunotherapy]]。葡萄膜炎和巩膜炎与[[nervous-system/sensory-systems]]相关，炎症性肠病与[[gastrointestinal/bowel-disease]]相关。

::: summary
- 类风湿关节炎是对称性小关节炎症性多关节炎，晨僵时间长，不累及DIP关节。抗CCP抗体的特异性远高于类风湿因子。
- 由TNF、IL-6和IL-1驱动的滑膜血管翳侵蚀骨；RA是系统性疾病，可累及肺、眼、血液和心血管系统。
- 疑似持续性滑膜炎应紧急转诊。早期治疗，以缓解或低疾病活动度为目标达标治疗，用DAS28测量（缓解低于2.6，低活动度3.2或以下，高活动度高于5.1）。
- 一线治疗是csDMARD单药（甲氨蝶呤、来氟米特或柳氮磺吡啶）加桥接糖皮质激素，然后逐步升级联合用药，必要时在感染筛查后使用生物制剂或JAK抑制剂。甲氨蝶呤每周一次。
- 脊柱关节炎共有HLA-B27、附着点炎、指（趾）炎、葡萄膜炎和中轴病变。炎症性腰背痛运动后改善；TNF和IL-17抑制剂可治疗中轴病变，而csDMARD无效。
- 痛风源于尿酸盐晶体沉积；发作用非甾体抗炎药、秋水仙碱或短疗程糖皮质激素治疗。降尿酸治疗的目标是低于360 µmol/L（有痛风石或慢性关节炎者低于300 µmol/L），每月调整剂量。
- CPPD表现为软骨钙质沉着症和急性关节炎，晶体为正性双折光的菱形；年轻患者应寻找代谢性病因。任何关节发热都要排除感染。
:::

## 习题

::: exercise RF还是抗CCP？ {level=1}
解释为什么在确认类风湿关节炎时抗CCP抗体比类风湿因子更有用，并举出RA以外两种可出现类风湿因子阳性的疾病。
::: solution
两种检查的**敏感性**大致相近（在已确诊的RA中各约60%–70%阳性），但抗CCP抗体的**特异性**高得多（通常超过95%），所以阳性结果更可能意味着RA。抗CCP还预示更具侵蚀性的病程。RF可在**干燥综合征**、**系统性红斑狼疮**、**丙型肝炎**和感染性心内膜炎等慢性感染、冷球蛋白血症中阳性，也见于一部分健康老年人。
:::
:::

::: exercise 计算分类标准得分 {level=1 check="8"}
一名37岁男性关节痛8周。风湿科医师发现两个MCP、三个PIP和左膝关节有滑膜炎。抗CCP为正常上限的3.5倍；CRP升高。计算他的2010年ACR/EULAR总分。
::: solution
关节：5个小关节（加一个大关节）属于“4–10个小关节”：3分。血清学：抗CCP超过正常上限3倍，为高滴度阳性：3分。急性期反应物异常：1分。病程8周：1分。总分$= 3 + 3 + 1 + 1 = 8$，达到6分的阈值。
:::

国外某实验室报告血清尿酸为7.5 mg/dL。用1 mg/dL $= 59.48$ µmol/L换算为µmol/L，四舍五入到整数，并说明是否达到NICE治疗目标。
::: solution
$7.5 \times 59.48 = 446.1$，约为**446 µmol/L**。这高于360 µmol/L（6 mg/dL）的目标，因此如果他正在接受降尿酸治疗，需要加量。

::: exercise 计算DAS28 {level=2 check="round(100*(0.56*sqrt(4)+0.28*sqrt(4)+0.70*ln(25)+0.014*40))/100"}
一名RA女性在28个关节中有4个压痛、4个肿胀，血沉25 mm/h，总体健康评分40。计算她的DAS28（保留两位小数），并对疾病活动度分级。
::: hint
用[[#eq-das28]]。25的自然对数约为3.219。
:::
::: solution
$0.56\sqrt{4} + 0.28\sqrt{4} + 0.70\ln 25 + 0.014 \times 40 = 1.12 + 0.56 + 2.253 + 0.56 = 4.493$，即**4.49**。这是**中度疾病活动度**（高于3.2且不超过5.1）。按照达标治疗策略，应升级治疗。

::: exercise 安全地开始甲氨蝶呤 {level=2}
列出一名29岁RA女性开始使用甲氨蝶呤之前及之后不久应检查或解释的主要事项。
::: solution
**开始前**：血常规、肾功能和肝功能，常做基线胸片；乙型和丙型肝炎（常加HIV）血清学；疫苗接种情况。**妊娠**：甲氨蝶呤有致畸性，因此要讨论避孕和生育计划；计划怀孕前必须停药，柳氮磺吡啶或羟氯喹是与妊娠相容的选择。**给药**：每周一次，固定在某一天，叶酸在另一天服用。**饮酒**：限制饮酒，因为两者的肝毒性叠加。**相互作用**：避免甲氧苄啶和复方磺胺甲噁唑；谨慎使用非甾体抗炎药和其他降低肾脏清除的药物。**警示症状**：咽痛、口腔溃疡、发热、瘀斑或出血（骨髓抑制）以及新出现的咳嗽或气促（肺炎）需要紧急就医。**监测**：按共同照护方案定期验血，最初几个月更频繁。**感染**：推荐接种灭活疫苗（流感、肺炎球菌、新冠）；活疫苗需听取专科意见。
:::

::: exercise 膝关节肿胀的年轻男性 {level=2}
一名24岁男性度假时腹泻，三周后出现左膝疼痛肿胀和右足跟痛。他的眼睛发红、有沙砾感。膝关节穿刺液白细胞22,000/mm³，无晶体，未见病原体；培养阴性。可能的诊断是什么？哪些病原体可能诱发了它？如何处理？
::: solution
可能的诊断是**反应性关节炎**：胃肠炎后出现的不对称性下肢少关节炎，伴**附着点炎**（跟腱附着处或足底筋膜的足跟痛）和**结膜炎**，滑液为无菌性炎症性滑液。诱因包括*沙门菌*、*志贺菌*、*弯曲菌*和*耶尔森菌*；*沙眼衣原体*是主要的泌尿生殖道诱因，因此询问性接触史并进行检测是合适的。**处理**：排除化脓性关节炎（已通过穿刺和培养完成）和淋球菌性关节炎；非甾体抗炎药，膝关节可关节腔内注射糖皮质激素；治疗任何持续存在的感染（衣原体，并通知性伴侣）。如有眼痛、畏光或视力下降，提示**前葡萄膜炎**而非结膜炎，需要眼科检查。大多数病例在数月内消退；持续性病变可能需要柳氮磺吡啶或甲氨蝶呤。
:::

::: exercise 痛风与移植患者 {level=3}
一名61岁肾移植男性服用硫唑嘌呤、环孢素和泼尼松龙。他痛风反复发作。他的全科医师打算开始使用别嘌醇。(a) 必须考虑哪种危险的相互作用？(b) 他的哪种药物可能促成了痛风？(c) NICE关于转诊有什么建议？
::: hint
想一想别嘌醇抑制的是哪种酶，以及这种酶还代谢什么药物。
:::
::: solution
(a) 别嘌醇抑制**黄嘌呤氧化酶**，而该酶是使**硫唑嘌呤**（经其代谢物6-巯嘌呤）失活的主要途径。两者合用会使活性硫嘌呤代谢物蓄积，可能导致致命的**骨髓抑制**。如果必须合用，应在专科指导下大幅减少硫唑嘌呤剂量并密切监测血象，或把硫唑嘌呤换成其他药物（如吗替麦考酚酯）。

(b) **环孢素**减少肾脏尿酸排泄，是移植受者高尿酸血症和痛风的公认原因。肾功能下降也有作用。如果使用利尿剂，也会加重这一问题。

(c) NICE NG219建议，对**器官移植**后、3b至5期CKD，或治疗有禁忌、不耐受或无效的痛风患者，考虑转诊风湿科。处理应与移植团队协调。秋水仙碱也与环孢素有相互作用（秋水仙碱浓度升高和肌毒性），因此发作的治疗也需谨慎。
:::
:::

::: exercise 哪种关节炎？ {level=3}
三个人因关节炎就诊。为每人匹配最可能的诊断，并给出最有用的一项确诊检查。(a) 一名82岁女性，髋部手术后两天，右膝红热肿胀；X线片显示半月板线状钙化。(b) 一名35岁女性，MCP和腕关节对称性肿胀三个月，抗CCP阳性。(c) 一名28岁男性，腰痛三年，夜间痛醒，运动后改善，曾有一次眼红痛伴畏光。
::: hint
在每个病例中寻找一个鉴别特征：软骨钙质沉着、一种抗体，以及腰背痛与眼部问题的组合。
:::
::: solution
(a) 手术诱发的**急性焦磷酸钙晶体性关节炎**（CPPD）。软骨钙质沉着支持这一诊断，但最有用的检查是**关节穿刺**，以显示正性双折光的菱形晶体，更重要的是通过革兰氏染色和培养排除**化脓性关节炎**。

(b) **类风湿关节炎**。诊断依靠临床，抗CCP支持诊断；手足X线片可确定是否有骨侵蚀，基线CRP和血沉可用于测量疾病活动度。她需要紧急专科诊治和早期DMARD治疗。

(c) **中轴型脊柱关节炎**，病史提示**急性前葡萄膜炎**。最有用的检查是**骶髂关节MRI**（能在X线改变之前显示炎症）；HLA-B27检测和CRP支持诊断。今后任何眼红痛伴畏光都需要当天进行眼科检查。
:::
