皮肤是最大的器官，也是最看得见的器官、而它会因为“粗糙的思考”受到两次的惩罚：**皮疹是一个“分布与形态”的诊断、必须在把激素到处撒之前完成；而皮肤同时也是通向全身性疾病的窗——狼疮与血管炎及淋巴癌及内分泌的衰竭及药物的反应与内脏的恶性，全都在这儿做广告。**一间皮肤病的门诊在很大程度上是“模式的识别”，再加上那句“我不知道——去活检、或去转诊”的坦然。

本章涵盖皮肤的结构与症状、湿疹、银屑病、痤疮及其严重的亲族、皮肤的感染、药物的疹与起疱的疾病。

## 结构与词汇

::: definition 皮肤的生物学与“只会痒的器官” {#def-structure}
**架构表皮作为“角化复层鳞状的屏障”，带着基底的干细胞的生态位、以及它的“转运与分化的级联”——角化的被膜与板层的小体及透明角质颗粒的序列、以及丝聚蛋白与它的同伴的皮肤屏障蛋白的遗传学在[[genetics/mendelian-inheritance]]与[[cell-biochemistry/proteins-enzymes]]；真皮作为胶原与弹性蛋白的力学、带着它的肥大细胞与“站岗的朗格汉斯细胞”——细胞外基质的相邻见[[cell-biochemistry/proteins-enzymes]]、[[immunology/innate-immunity]]；附属器——皮脂腺作为“雄激素驱动脂质的工厂”与大小汗腺、以及作为干细胞的蓄水池的毛囊，及“毛囊炎与多毛的表现”的来源——雄激素的那几行见[[endocrine/reproductive-endocrinology]]；以及皮下组织作为脂肪的垫与“炎症的部位（脂膜炎”与“注射的落点”——脂肪生物学的相邻见[[gastrointestinal/clinical-nutrition]]）；免疫的皮肤皮肤作为“被主动巡逻的屏障”，带着[[immunology/innate-immunity]]的抗菌的肽与防御素及 Toll 样受体的逻辑、以及“定居记忆的T细胞与皮肤归巢的地址素”（它解释了为什么有些皮疹就待在它们待的地方——[[immunology/adaptive-responses]]、以及把荨麻疹与血管性水肿及“接触性皮炎与湿疹及血清病样的与血管炎性药物的疹”映射到免疫学各章的“一到四型的过敏”的地图——[[immunology/hypersensitivity]]）；痒（那种“痒觉的独立性”——组胺能的对非组胺能的痒、以及“辣椒素受体与白细胞介素31及胆汁的酸及尿毒症的及神经的及心因的”这一分类学、带着那堂“为什么抗组胺的药在大多数痒里失败”的课、以及“搔抓与发痒的循环”的慢性化的机制——[[nervous-system/sensory-systems]]、痒的那一行见[[renal/chronic-kidney-disease]]、胆汁淤积的痒那一行见[[gastrointestinal/liver-disease]]、[[endocrine/thyroid]]）；以及描述的纪律（形态为先的语言——斑与丘疹及斑块及结节及水疱及大疱及脓疱及风团及鳞屑及痂及糜烂及溃疡及苔藓化及瘢痕——以及分布与构型的术语：环状与线状及按皮区及“光分布的”及“沿克林坎线”的；外加那条“先用描述、后用名字”的规则，它让另一位皮肤科医师仅凭文字就能看见这片疹。）**
:::

## 湿疹与银屑病

::: definition 特应性与接触性的湿疹 {#def-eczema}

:::

::: definition 银屑病与它严重的亲族 {#def-psoriasis}
**免疫学（那类“由T细胞驱动的白细胞介素23到17的轴的角质形成细胞过度增殖的疾病”、带着“幼年或第二个成年期”的双峰的发病、以及皮肤的“花的样斑与鳞屑”及“以天而不是以周计的角质形成细胞的周转”、以及“角化不全与微脓疡”的组织学、以及从那几个易感位点到“整个生物制剂的军火库”的遗传与免疫的桥梁——[[immunology/adaptive-responses]]、[[immunology/vaccines-immunotherapy]]、[[genetics/common-disease-genetics]]）；形态与分布伸侧与头皮与耳与臀沟及脐上的“银白色鳞屑性红斑性的斑块”、以及“点状出血征”与“同形反应创伤后定位”、以及甲的点状凹陷与“甲的剥离及油斑”、以及那“被水分剥掉了鳞屑”的屈侧与生殖器的味道——[[clinical-skills/physical-examination]]；鉴别清单——慢性皮肤的真菌病与脂溢性皮炎及“毛发红糠疹（邻近的剥脱性皮炎”、以及“在每一次复查时都要问的关节炎的问题”，因为关节的损害才是那个要紧的结局——[[musculoskeletal/inflammatory-arthritis]]）；严重度与全身（套“体表的面积与生活质量的指数及严重程度评分”的框架、以及“10%不是唯一的触发——当它是手或足或生殖器或面、或是剥脱性或脓疱性的银屑病、或是甲或关节的疾病”；以及那一簇代谢的综合征与脂肪肝及抑郁及心血管的风险的共存病——以及那句“不要把体重归咎于患者”的框架——[[gastrointestinal/liver-disease]]、[[cardiovascular/hypertension]]、[[psychiatry/mood-disorders]]、[[musculoskeletal/inflammatory-arthritis]]）；治疗外用的激素加维生素D的类似物的复方、以及以润肤剂为骨架与“煤焦油与地蒽酚历史上的染渍”、以及用于“薄的皮肤的部位”的钙调磷酸酶的抑制剂——[[pharmacology/dosing-principles]]；窄带的紫外B的光疗带着光敏的药物的回避与皮肤癌的监测、以及“补骨脂素加紫外A的累积剂量遗留的数据”——[[musculoskeletal/skin-cancer]]；甲氨蝶呤与阿维A及环孢素——传统全身治疗的层（类视黄醇用于脓疱的病；而环孢素的肾与高血压及致畸，与阿维A“长达数十年妊娠的回避”的告诫——[[pharmacology/patient-variation]]、[[renal/chronic-kidney-disease]]。）**

## 毛囊、感染、药物与起疱

::: definition 痤疮、化脓性汗腺炎与毛囊的疾病 {#def-acne}
**寻常的痤疮那个“皮脂腺的单位”——雄激素驱动皮脂的输出与“痤疮的棒状杆菌”的定植及“毛囊的角化与先天的炎症的活化”、以及“粉刺到丘疹到脓疱到结节到囊肿”的分级的形态、带着面与胸与背的分布、以及“在深肤色中瘢痕与色素的赌注”——色素的相邻见[[musculoskeletal/skin-cancer]]、雄激素受体的相邻见[[cell-biochemistry/signalling-cell-cycle]]；处理——外用的维A酸与过氧化苯甲酰及外用抗生素的联合带着“抗生素耐药的管家”与“绝不单用外用的抗生素”这条规则、以及“成人的下颌线模式的”激素的选项复合口服的避孕药与螺内酯——[[endocrine/reproductive-endocrinology]]、[[obstetrics-gynaecology/contraception-fertility]]、[[microbiology/antimicrobials]]；以及全身治疗的层——口服的四环素类注意光的安全、以及异维A酸（带着致畸与避孕以及“妊娠预防方案的严格”、以及“精神与炎症的肠病的辩论”的诚实、以及血脂与肝的监测的背景、以及痤疮的瘢痕的“激光与皮下剥离转诊的时机”——[[pharmacology/patient-variation]]、[[microbiology/bacteria]]）。玫瑰痤疮的味道中央的面的红斑与毛细血管的扩张及“潮红的触发辛辣与酒精及热”与“毛囊虫”、以及眼部的玫瑰痤疮与“鼻的肥大”、以及口周的皮炎与“面霜误用造成激素性的玫瑰痤疮”、以及与狼疮的蝶形的疹的鉴别（带着“光分布与鼻唇沟的豁免”这一细微差别——狼疮的疹的那几行见[[musculoskeletal/connective-tissue-vasculitis]]、眼表干燥的重叠见[[nervous-system/sensory-systems]]）。化脓性的汗腺炎（那类“毛囊的堵塞，发生在大汗腺部位化脓的疾病”——腋与腹股沟与会阴及乳下的“隧道与管道及双头的粉刺及有味的渗出及瘢痕”、以及“诊断的延迟与羞耻”及吸烟与肥胖及代谢及肠病及关节炎的关联、以及阶梯的处理——外用与病灶内的激素与克林霉素与锌的组合、以及“已获许可的生物制剂”、以及为隧道式的疾病的“广泛的切除与整形的重建的手术”、以及“这种疾病被设计出来要制造的那份心理的负担”——[[gastrointestinal/bowel-disease]]、[[psychiatry/mood-disorders]]、[[public-health/environmental-occupational]]。）**

::: definition 皮肤的感染 {#def-infections}
**细菌的（脓疱疮——儿童那种“蜜色结痂的病灶”、以及深脓疱与毛囊炎及“疖与痈”、带着金黄色葡萄球菌与化脓性链球菌的领地、以及耐甲氧西林的菌株与社区的传播及卫生的集束——[[microbiology/bacteria]]、[[infectious-diseases/healthcare-infections]]；蜂窝织炎与丹毒——那种链球菌的真皮的感染、带着“足癣与裂口及伤口的入口”及淋巴的破坏及“反复发作的预防”、以及那份“绝不要漏掉的鉴别清单”——双侧红腿的郁积性皮炎的模仿、以及“疼痛与体征不相称与中毒的外观与捻发音与快速蔓延”的坏死性筋膜炎的那一对——血管的复查见[[surgery/vascular-urological-surgery]]、坏死性的感染要外科这条规则见[[surgery/wounds-surgical-infection]]；以及丹毒对蜂窝织炎这一命名的现实、以及牙科与会阴及咬伤的微生物的相邻——咬伤与水的暴露见[[microbiology/bacteria]]）。病毒的单纯疱疹——反复的水疱、以及“在有皮肤病的皮肤上爆发疱疹性的湿疹”这是一桩眼科与收住的急症、以及“新生儿与脑炎”的相邻——[[microbiology/viruses]]、[[paediatrics/newborn]]、[[nervous-system/neuroinflammation]]；水痘带状疱疹——按皮节的带状疹、带着“疱疹后神经痛的预防”与疫苗、以及“早期抗病毒的那扇窗”、以及在免疫抑制者中播散与“眼的急迫性”——[[immunology/immunodeficiency]]、[[public-health/vaccination-programmes]]、眼支的那一点见[[nervous-system/sensory-systems]]；以及传染性软疣与疣（带着湿疹的并发症与免疫抑制的信号、以及疫苗相邻的肛门生殖器的病——[[infectious-diseases/sexually-transmitted-infections]]、[[public-health/vaccination-programmes]]；以及儿童的发疹与“药物对病毒的混淆”——[[paediatrics/acute-childhood-illness]]）。真菌与寄生的（头癣与体癣及足癣与“股癣及甲癣”，用氢氧化钾与培养来诊断、以及特比萘芬与唑类及“与光疗的模仿的边界”、以及“被误用的激素造成的难辨认癣”——[[microbiology/fungi-parasites]]；念珠菌的“擦伤处的皮炎与尿布区的皮炎及外阴阴道的炎及管路感染”、以及那个糖尿病的信号——[[endocrine/diabetes-complications]]、[[infectious-diseases/healthcare-infections]]；疥疮——指缝与生殖器的结节及夜间的痒及“全家一起治疗”、以及在“神经科的病人”中的结痂型的疥疮——[[nervous-system/neuroinflammation]]、[[infectious-diseases/healthcare-infections]]。）**

::: definition 药物的疹与起疱的疾病 {#def-drug-blister}
**药物的疹的分类那个“麻疹样药物的疹”作为常见的良性的默认、以及时间的规则——新药的“数日到两周”、以及按族裔的基因型的易感在开始那两种药之前要做检测的“人类白细胞抗原”的型——[[pharmacology/patient-variation]]、[[genetics/common-disease-genetics]]；严重皮肤药物的不良反应——“史蒂文斯-约翰逊综合征与中毒性的表皮坏死松解”：带着黏膜炎与“剥脱的表面积”与尼科尔斯基征、以及“立即停药”的那批 元凶别嘌醇与抗癫痫药及“替拉那韦”及磺胺、以及烧伤单元与“严重度的评分”时代的照护；以及“伴嗜酸的细胞增多与全身的症状的药物反应”：带面的肿与嗜酸及肝与肾及血液的器官的累及、以及“人类的疱疹病毒6的再激活”；以及“急性泛发脓疱的疹”：带脓疱与发热以及与抗生素的关联；以及“固定性药物的疹”（在同一处复发——[[infectious-diseases/immunocompromised-host]]、[[gastrointestinal/liver-disease]]、[[renal/acute-kidney-injury]]、[[blood/haematopoiesis]]）。免疫起疱的疾病“对抗真皮与表皮黏附的分子”的自身抗体——寻常的天疱疮：抗桥粒芯糖的蛋白、表皮内松弛的水疱、以及以口的糜烂为首发的表现、以及尼科尔斯基征与“临床医师的搜寻”；以及大疱性的类天疱疮：抗半桥粒、在老年人的皮肤上“紧张的水疱”伴荨麻疹的前驱、以及“二肽基肽酶4的抑制剂”那个诚实的药物的关联；以及疱疹样的皮炎与“麸质敏感性的肠病”这对孪生；以及“线状的免疫球蛋白A”与药物的味道；以及“迟发皮肤的红斑狼疮……不、是皮肤卟啉病”与“假性卟啉病”在日晒的部位起疱——[[immunology/autoimmunity]]、乳糜的那一行见[[gastrointestinal/bowel-disease]]、类天疱疮的那一行见[[endocrine/diabetes]]；诊断——“取活检做常规染色、并在病灶周围取材做直接免疫的荧光”、血清的抗体；以及免疫抑制的管理（氨苯砜与硫唑嘌呤及霉酚酸的省激素的策略、以及天疱疮用利妥昔单抗、以及大面积起疱的“伤口与营养及液体的支持”、以及收住的阈值）。以及紧急的疹（伴全身特征的紫癜——血管炎与脑膜炎球菌血症及凝血病及血小板的问题的检查——[[musculoskeletal/connective-tissue-vasculitis]]、[[blood/haemostasis-bleeding]]、[[infectious-diseases/fever-sepsis]]；以及那“其实是剥脱性皮炎”的皮疹——那个“被烫伤的患者”的鉴别：银屑病与药物及淋巴癌及“塞扎里”、以及体温与液体及蛋白及感染的那本账。）**

::: example 一位清洁工的那双发痒的手 {#ex-hand-dermatitis}
一名34岁的超市收银的清洁工有8个月的“发痒、开裂、脱屑的手指侧面与手掌、在上班之后更重”；没有哮喘、但儿童期有湿疹的病史；她不停地“用消毒剂洗手”、有时在棉内衬之外戴丁腈的手套；在药房那一次“对皮疹的边缘做了氢氧化钾的检查”是阴性的。
::: solution
**慢性的手的皮炎、而它的鉴别是“刺激性对过敏性接触、对特应性的急性发作、对皮肤的真菌、对银屑病”——通常是几样同时存在（[[#def-eczema]]）：场暴露病史的法医学——洗手的频率与消毒剂及“手套的封闭”及洗涤剂的溅到及食物的接触、以及“每天湿式工作的小时数”——这让它在“带有赔偿的含义”时成为一种职业的疾病——[[public-health/environmental-occupational]]；检查——斑贴的试验镍与香精及促进剂及防腐剂及消毒剂及手套的化学品、以及“对她自己的消毒剂做重复的开放的应用的试验”、以及真菌的复测，因为“一次的阴性不能把门关死”——[[clinical-skills/laboratory-tests]]、[[microbiology/fungi-parasites]]；处理的集束——减少湿式的工作、手套的规程合适的手套、要更换而不是一整天戴着、以及棉内衬的现实、无香精的清洁剂、以及“每次洗后都上润肤剂”、以及“强效外用的激素：定时而不胆怯”、之后用“钙调磷酸酶或省激素的维持”、以及在“难治内源性的手的湿疹”里那一小块地带着它的致畸的咨询——[[pharmacology/dosing-principles]]、[[obstetrics-gynaecology/contraception-fertility]]；升级——按许可“用于手的湿疹的类型的生物制剂”、以及“手的局部窄带的紫外或补骨脂素加紫外、或与类视黄醇的联合”的时代——[[immunology/vaccines-immunotherapy]]；以及职业学的收尾——场“关于手套与清洁剂与排班的改变”的与雇主的谈话作为临床的建议被记录、以及职业健康的转诊、以及那句“这片疹子就是你的工作”的诚实——它决定了治疗究竟能不能起效——[[clinical-skills/communication]]、[[clinical-skills/records-handover]]。**

## 拍照、转诊与两周的规则

两项贯穿全章的习惯为这一章收尾。第一，为“会动的皮疹”、以及“等到有任何高年资的人看到时早就变了样”的表现拍照——病历里一张带日期临床的照片，能把“真的是荨麻疹吗？”变成一个可解的问题；而在“恶性的时机很重要”的色素的病灶与可疑的溃疡上，远程皮肤病的“图像转诊”缩短了等待——永远要配同意、存储的治理、以及影像的伦理所要求的“身份的核对”的保障措施（[[clinical-skills/records-handover]]、[[musculoskeletal/skin-cancer]]、[[medical-ethics-law/confidentiality]]、[[public-health/health-systems-economics]]）。第二，把两周的规则与紧急转诊的触发背得滚瓜烂熟，因为皮肤的癌与严重的药物反应是“没人能赢回来”的两座时钟：任何一个在长大、在改变、在出血、在某一处发痒、或一个月都不愈合的单一的病灶——尤其在“免疫抑制或既往的放疗”的背景上——值得专家的眼睛；而任何伴黏膜炎或剥脱、或“面的肿伴全身的不适”、或紫癜加“自我感觉全身不适”的皮疹，都是当日与医院的谈话、不是一张门诊的表格（[[#def-drug-blister]]、[[musculoskeletal/skin-cancer]]、[[emergency-critical-care/acute-assessment]]）。

## 通向何处

免疫的机制在[[immunology/hypersensitivity]]与[[immunology/autoimmunity]]；银屑病与关节的轴在[[musculoskeletal/inflammatory-arthritis]]；化脓性的汗腺炎与炎症的肠病在[[gastrointestinal/bowel-disease]]；药物的遗传学在[[pharmacology/patient-variation]]；感染的处理在[[microbiology/bacteria]]与[[microbiology/viruses]]；皮肤的恶性在[[musculoskeletal/skin-cancer]]。

::: history
**皮肤病学从“性病与化妆品”中缓慢的浮现：以模式为先的维也纳学派——赫巴那部“皮肤的架构”的目录、教会了一代人“在看之后再放血”、以及那个“对丘疹与疱疹的分类”的时代；丝聚蛋白与特应性皮炎的定位克隆作为“特应性的行军获得了它的屏障的机制”的那一天、以及“与人类白细胞抗原DQ及白细胞介素13的关联的研究”的湿疹的遗传学与过敏的疾病的流行病学、成熟为卫生与微生物组的假设——[[genetics/common-disease-genetics]]、[[microbiology/microbiota]]；银屑病从“麻风的那个穷表亲”以及焦油与地蒽酚及瓷灯的时代，走向“白细胞介素23到17的轴的道理”——它把一种皮肤的疾病变成了细胞因子的医学的旗舰——[[immunology/vaccines-immunotherapy]]；异维A酸的故事——它由致畸恐慌催生风险管理的架构，成为此后每一种高风险的药的模型、以及它那场“证据大体上但不完全已经让它安静下来情绪的争议”——[[pharmacology/patient-variation]]、[[medical-ethics-law/research-ethics]]；莱尔在1956年对中毒性的表皮坏死松解的描绘、以及随后“病例对照的元凶的药物”的流行病学——这是药物警戒最自豪的方法学的一章——[[pharmacology/adverse-reactions]]、[[epidemiology-ebm/observational-studies]]、[[public-health/health-systems-economics]]；以及天疱疮的“被动的转移与免疫的荧光”的发现、把起疱的疾病“从绝望中的诊断”变成了“有滴度、有治疗、也有缓解的抗体的疾病”——[[immunology/autoimmunity]]、[[pathology/diagnostic-pathology]]。**

::: summary
- 先描述，再诊断：形态与分布及时间与症状；一张照片与一条时间线，胜过大多数经验性的激素。
- 湿疹是屏障加2型的炎症——润肤剂就是药、强效外用的激素要正确而主动地使用、而手要去做“职业学与过敏原的搜寻”。
- 银屑病是一种“以皮肤为旗帜”的“白细胞介素23到17的全身的疾病”；在每一次复查时问关节与甲及情绪及代谢的风险、并把“让皮肤变干净”当作一个正当的治疗目标。
- 抗生素造成四片要记住危险的疹——重型的红斑与“伴嗜酸增多与全身的症状的反应”、急性泛发的脓疱、以及良性的“麻疹样的默认”——而早早停药就是治疗。
- 起疱的疾病靠“直接免疫的荧光”诊断、并针对抗体治疗；天疱疮黏膜的糜烂比皮肤早几个月，而且会被漏掉。
- 蜂窝织炎在双侧时被过度诊断、在中毒的患者身上被诊断不足；永远要问“这对红的腿不是什么”。
:::

## 练习

::: exercise 说出这片疹的名字 {level=1}
给出首选的诊断与确认的检查：(a) 发痒的腕的指缝伴阴茎的结节；(b) 老年人单侧的、按皮区结痂的水疱；(c) 小腿上“中央清亮环状鳞屑性的斑块”；(d) 抗生素之后“伴口腔糜烂疼痛靶形的斑”。
::: solution
**甲疥疮——刮取或在皮肤镜下找螨、并用“拟除虫菊酯或伊维菌素的方案”治疗接触者——疥疮那一行见[[#def-infections]]、[[public-health/communicable-disease-control]]；乙带状疱疹——在非典型时对疱液做聚合酶链、以及抗病毒的窗口与疫苗的规划——[[microbiology/viruses]]、[[public-health/vaccination-programmes]]；（丙）皮肤的真菌——氢氧化钾的制片与培养、以及“激素不作首选”这条规则——[[microbiology/fungi-parasites]]、[[clinical-skills/laboratory-tests]]；（丁）疑似重型的“红斑与表皮坏死松解的谱”——紧急临床的诊断配活检、并停药与转给专科——[[#def-drug-blister]]、[[emergency-critical-care/critical-care]]。**
:::
:::

::: exercise 明智地开外用的激素 {level=1}
为一个害怕“往皮肤上用的激素”的家庭写下教学的脚本。
::: solution
**份“被量化了的安全”的脚本（[[#def-eczema]]、[[pharmacology/dosing-principles]]、[[clinical-skills/communication]]）：按“指尖的单位”给药、并按部位选强度面与屈侧用弱的、上用中的、手与足用强的；以及“一两周让皮肤干净、之后主动的周末维持”的时间表；以及放在背景里的副作用——误用可能造成皮肤的变薄与膨胀纹、极端的用量会有吸收；而未受控制的严重的湿疹，其代价是睡眠与感染及生活质量——以及每次复查“不要漏掉的指尖用量的审计”：对激素的恐惧造成的治疗不足，与互联网上的天然疗法之间的平衡（[[pharmacology/adverse-reactions]]、[[public-health/prevention-promotion]]）。**
:::

::: exercise 处理剥脱性皮炎 {level=2}
一名67岁在用氨氯地平的“严重的银屑病”患者，从颈到踝都是红的、热的、渗液并发抖、心率118、体温35.8、白蛋白低、腿水肿。请按优先次序写收住的计划。
::: solution
**剥脱性皮炎就是皮肤的衰竭、要收住（[[#def-drug-blister]]剥脱性皮炎那一行、体温调节与液体的生理见[[physiology/homeostasis-body-fluids]]）：复苏——用温的液体并避免过度的引流；营养高蛋白与体温的控制温暖的房间；以及液体与电解质及白蛋白及“血栓的预防”因为患者会制动并水肿；并在年长的贫血者中监测心输出量的负荷——[[renal/water-sodium]]、[[blood/thrombosis-anticoagulation]]、[[gastrointestinal/clinical-nutrition]]、[[cardiovascular/circulation-blood-pressure]]；并行地找病因——“激素撤除或不依从之后的银屑病的发作”与药物反应及“皮肤T细胞的淋巴癌塞扎里”及结痂的疥疮及接触性及全身性的及特发性的；以及用药与酒精的“对账”——[[musculoskeletal/inflammatory-arthritis]]、[[pharmacology/adverse-reactions]]、[[blood/lymphoma-myeloma]]、结痂的疥疮见[[#def-infections]]；针对皮肤的治疗——温和的润肤剂与非刺激的外用的、稳定后低剂量的紫外B、以及按疾病特异的全身治疗，并监测感染与液体；配上“第一天就要有皮肤科的资深医师复查”这条规则——[[#def-psoriasis]]；以及对“虚弱反复的剥脱性皮炎”场诚实的预后与预先规划的谈话——[[geriatrics-palliative/palliative-care]]。**
:::

::: exercise 在用生物制剂之前筛查 {level=2}
一位严重银屑病的患者被预约用“白介素12与23的抑制剂”；他来自结核高流行的国家、从未被筛查过。列出你治疗前的组合与那场疫苗的谈话。
::: solution
**一组：结核的筛查用释放试验与胸部的影像、以及“在开始之前按方案治疗潜伏的结核、或记录一次低风险的决定”——[[infectious-diseases/tuberculosis]]、[[respiratory/respiratory-infections]]；乙肝与丙肝及人免疫缺陷病毒的血清学，若核心或表面抗原阳性则加病毒载量与肝病科的意见、以及免疫球蛋白的基线——[[microbiology/viruses]]、[[infectious-diseases/hiv]]；在开始之前完成活疫苗的接种与家庭的规则、并规划“灭活的流感与肺炎链球菌及带状疹的重组的疫苗”——[[public-health/vaccination-programmes]]；常规安全的血液与血压及体重及酒精及药物的相互作用的复查、以及生育的计划与皮肤癌病史——[[pharmacology/patient-variation]]、[[musculoskeletal/skin-cancer]]、[[obstetrics-gynaecology/contraception-fertility]]；以及记录加安全网——病历上的“被免疫抑制者的警报”与那张发热的卡片、以及手术与妊娠的修改的规则、以及“共同照护的处方：皮肤科负责生物制剂、初级保健负责其余”——[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]。**
:::

::: exercise 为这张处方辩护 {level=2}
一名15岁的结节囊肿性的痤疮被转诊要用异维A酸；父母被互联网吓坏了。请组织这次门诊：获益、伤害、那个方案、以及随访。
::: solution
**这次门诊要把获益放在最前（[[#def-acne]]）：“瘢痕与负担”的论证——结节囊肿性的痤疮若不充分治疗会造成“永久性的毁容”、而异维A酸是唯一一种“能改变疾病轨迹并有很高的缓解率”的药；以及放在视角里的伤害——致畸性与“妊娠预防条件的契约”、黏膜与皮肤的干燥、以及血脂与肝及肌的监测、以及“精神信号的历史”带着实际证据的权重诚实地讲——[[pharmacology/patient-variation]]、[[obstetrics-gynaecology/contraception-fertility]]；方案的后勤——按本地政策的妊娠的检测与避孕的要求、以及“哪些避孕的方法”与“每月的到场”的规则、以及学业与驾驶的考量、以及累积的剂量与疗程与复发后再治疗的预期——[[clinical-skills/communication]]、避孕的机制见[[obstetrics-gynaecology/contraception-fertility]]；支持的那一层——深肤色中“炎症后的色素”的赌注、以及日的防护与瘢痕的计划、以及那扇心理健康敞开的门不要把青春期归罪于药物、以及那份“真的存在的、面向家长的信息单”——色素见[[musculoskeletal/skin-cancer]]、[[psychiatry/lifespan-psychiatry]]、[[clinical-skills/records-handover]]；以及“治疗同盟的收尾”——“我们一起监测它，每月一次、而你随时可以通过与我们说话来停下”——[[clinical-skills/patient-safety]]、[[medical-ethics-law/consent-capacity]]。**

::: exercise 审计一间皮肤科的服务 {level=3}
就你们服务中“高伤害皮肤病学的”一个主题设计一项审计或质量改进的项目：重型药物反应的“归因于哪一种药”、蜂窝织炎的过度诊断、生物制剂筛查的完整性、或手湿疹的职业学的结局。
::: solution
**选择的架构——表型的定义与编码及“病历检索的策略”、并由两位评审者用科帕一致性做“手工病历的审阅”——[[epidemiology-ebm/measuring-disease]]、审计的方法见[[public-health/screening]]；按主题的指标——对于重型的药物反应：五类元药物的“暴露时间的记录”与皮肤科复查的延迟、以及黄卡的完成率、以及“出院之后还在开元凶的药物”的交叉核对（[[pharmacology/adverse-reactions]]、[[clinical-skills/records-handover]]）；对于蜂窝织炎：双侧的腿以及“排除郁积与红斑的比率”及抗生素的天数及复发的预防、以及深静脉血栓的检查——[[surgery/wounds-surgical-infection]]、[[blood/thrombosis-anticoagulation]]；对于生物制剂：结核与肝炎及疫苗的筛查的完整性、以及“从预约到第一剂的间隔”——[[infectious-diseases/tuberculosis]]、[[public-health/vaccination-programmes]]；对于手的湿疹：斑贴试验的可及性与职业学的转诊的比率及工作的保留——[[public-health/environmental-occupational]]；干预的设计——核对表与“病历系统的硬性停止”及多学科的病例及教育、并重新测量并与对照点对比——[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]；以及“审计对研究”的伦理与数据治理，在一个皮肤图像拍照服务的背景之下——[[medical-ethics-law/research-ethics]]、[[medical-ethics-law/confidentiality]]。**
