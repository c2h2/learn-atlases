皮肤是人体最大的器官，成人约1.5至2平方米。它把水分留在体内，把微生物、化学物质和紫外线挡在体外，调节体温，感受触觉和痛觉，合成维生素D，并参与免疫防御。皮肤问题是就医最常见的原因之一，它们影响人们对自己的感受，其中许多还是内部疾病的线索。

本章讲述皮肤的结构、如何描述所见，以及常见疾病：湿疹、银屑病、痤疮、荨麻疹、皮肤感染、药疹和大疱性疾病。皮肤癌见[[musculoskeletal/skin-cancer]]，过敏和药物反应的免疫学见[[immunology/hypersensitivity]]。

## 结构与功能 {#sec-structure}

::: definition 皮肤的分层 {#def-skin-structure}
皮肤有三层。

**表皮**：无血管的复层鳞状上皮，主要由**角质形成细胞**构成。新的角质形成细胞在**基底层**产生，向外移动，经过**棘层**（细胞由**桥粒**连接，桥粒由包括**桥粒芯糖蛋白**在内的蛋白构成）、**颗粒层**（细胞产生含**聚丝蛋白**的透明角质颗粒和含脂质的板层小体），在手掌和足底还要经过透明层。最后在**角质层**中变成扁平的死亡**角质细胞**并脱落。这一过程约需四周。表皮中的其他细胞有：

- 基底层的**黑素细胞**，产生**黑素**并通过黑素小体转运给周围的角质形成细胞，在那里遮护细胞核免受紫外线照射。各种肤色的人黑素细胞数量相近；肤色取决于黑素的量和类型，以及黑素小体的大小和分布；
- **朗格汉斯细胞**，捕获抗原并在淋巴结中呈递抗原的树突状细胞；
- **默克尔细胞**，参与触觉。

**基底膜带**：表皮与真皮的交界。基底层角质形成细胞通过**半桥粒**锚定于其上，半桥粒含有**BP180**和**BP230**蛋白。

**真皮**：由胶原和弹性蛋白构成的结缔组织，含血管、淋巴管、神经和皮肤附属器：**毛囊**及其**皮脂腺**（合称毛囊皮脂腺单位）、**外泌汗腺**（分布于全身，用于体温调节）和**顶泌汗腺**（腋窝和腹股沟）。

**皮下组织**：脂肪和结缔组织，起保温、缓冲和储存能量的作用。
:::

**角质层**是主要屏障，常被比作一堵砖墙：角质细胞是砖，来自板层小体的脂质（神经酰胺、胆固醇、游离脂肪酸）是灰浆。**聚丝蛋白**使角蛋白聚集，并被分解为天然保湿因子。有几种皮肤病本质上是屏障或黏附的疾病：特应性湿疹（屏障）、天疱疮（桥粒）和大疱性类天疱疮（半桥粒）。

::: theorem 屏障失效驱动炎症 {#thm-barrier}
表皮屏障失效时，水分流失，刺激物、变应原和微生物穿透皮肤。这会激活固有免疫和适应性免疫反应，引起**炎症和瘙痒**。搔抓进一步破坏屏障，因此屏障失效与炎症相互加强，形成自我维持的**瘙痒–搔抓循环**。
:::

::: proof
聚丝蛋白基因（*FLG*）功能丧失变异是特应性湿疹最强的遗传危险因素。变应原通过有漏洞的屏障与树突状细胞相遇，驱动以**IL-4、IL-13和IL-31**为特征的2型免疫反应：IL-4和IL-13进一步减少聚丝蛋白和脂质，IL-31引起瘙痒。搔抓损伤表皮，让更多变应原和*金黄色葡萄球菌*进入。治疗同时作用于两端：润肤剂修复屏障，抗炎治疗打断免疫环路。
:::

## 描述皮损 {#sec-lesions}

准确的描述使诊断成为可能，也让同事明白你看到了什么。先描述**分布**（身体哪个部位、是否对称、曝光部位还是遮盖部位、屈侧还是伸侧），再描述**单个皮损**：类型、大小、形状、颜色、表面以及触感。

::: definition 原发损害与继发损害 {#def-lesions}
**原发损害**直接由疾病产生：

- **斑疹**：小而平、不可触及的颜色改变区；较大的称为**斑片**；
- **丘疹**：小的隆起性实性皮损；较大且常较深的称为**结节**；
- **斑块**：比丘疹大的隆起、顶部扁平的区域，常由丘疹融合而成；
- **水疱**：含清亮液体的小疱；较大的称为**大疱**；
- **脓疱**：肉眼可见的脓液积聚（可以是无菌的，如脓疱型银屑病）；
- **风团**：一过性、瘙痒的隆起性水肿，持续不到24小时（荨麻疹）；
- **瘀点**和**紫癜**：小的和较大的皮内出血区，**压之不褪色**。

区分大小的界限（斑疹与斑片、丘疹与结节、水疱与大疱）在一些教科书中约为0.5 cm，在另一些教科书中为1 cm。

**继发改变**在皮损演变或被搔抓时出现：**鳞屑**（角质层碎片）、**结痂**（干燥的浆液、血液或脓液）、**糜烂**（部分表皮缺失，愈合不留瘢痕）、**溃疡**（表皮和部分真皮缺失，可留瘢痕）、**抓痕**（搔抓痕迹）、**苔藓样变**（长期摩擦导致增厚、皮纹加深）、**萎缩**（变薄）和**瘢痕**。
:::

有色皮肤上的颜色需要留意。**红斑**在较深肤色上可呈紫红、深褐或灰色，更容易漏看；皮温、肿胀和质地有助于判断。炎症常遗留持续数月的**炎症后色素沉着**。教学图片历来以白色皮肤为主，这导致深肤色人群的诊断延误。

皮肤病的范围常用**体表面积（BSA）百分比**估计。一个有用的规则是，一个人手指并拢时的手掌面积约为其BSA的**1%**。所需外用药量用**指尖单位（FTU）**计量：从标准药管中挤出、覆盖成人示指远端一节的药量，约**0.5 g**，可涂抹相当于两个成人手掌的皮肤面积，即约2%的BSA。

## 湿疹 {#sec-eczema}

::: definition 湿疹（皮炎） {#def-eczema}
**湿疹**（与**皮炎**通用）是一种炎症性皮肤反应，有瘙痒和边界不清的红斑，根据阶段不同，可有水疱、渗出和结痂（急性），或干燥、脱屑和苔藓样变（慢性）。主要类型有：

- **特应性湿疹**：慢性复发性疾病，通常在婴儿期或幼儿期起病，常有哮喘、过敏性鼻炎或食物过敏的个人或家族史。婴儿累及面部和伸侧；年长儿童和成人累及**屈侧**（肘窝、腘窝、腕部、颈部）。在有色皮肤上，可表现为更多的毛囊性丘疹、伸侧受累和色素改变。
- **刺激性接触性皮炎**：水、洗涤剂、溶剂和摩擦的直接损伤，典型见于医务人员、清洁工、理发师和餐饮从业者的手部。
- **变应性接触性皮炎**：对特定变应原的Ⅳ型（迟发型）超敏反应，如镍、香料、防腐剂（如甲基异噻唑啉酮）、染发剂（对苯二胺）、橡胶化学品或外用药。分布常提示病因。**斑贴试验**可确定变应原。
- **脂溢性皮炎**（头皮、眉毛和鼻唇沟的油腻性脱屑，与*马拉色菌*相关）、**钱币状**湿疹、小腿**静脉性（淤积性）**湿疹，以及**汗疱疹**（手掌和足底的水疱）。
:::

特应性湿疹的处理依靠三项工作：修复屏障、控制炎症和治疗并发症。

- **润肤剂**要大量、频繁使用，包括代替肥皂；最好的润肤剂是患者愿意用的那一种。不同质地适合不同部位和时间。
- **外用糖皮质激素**是主要的抗炎治疗，按部位和严重程度选择**强度**：**弱效**（1%氢化可的松）、**中效**（0.05%丁酸氯倍他松）、**强效**（0.1%戊酸倍他米松、0.1%糠酸莫米松）和**超强效**（0.05%丙酸氯倍他索）。面部、屈侧和婴儿用较弱的制剂。发作时每天涂一到两次，有时在易发作部位每周两次使用以预防复发。
- **外用钙调神经磷酸酶抑制剂**（他克莫司、吡美莫司）是节制激素的选择，适用于面部和眼睑。
- 严重病例在专科照护下：**光疗**；系统免疫抑制剂（**环孢素**、**甲氨蝶呤**、硫唑嘌呤、吗替麦考酚酯）；阻断2型通路的生物药物（针对IL-4受体α链的**度普利尤单抗**；针对IL-13的**曲罗芦单抗**和**来瑞组单抗**）；以及口服**JAK抑制剂**（阿布昔替尼、巴瑞替尼、乌帕替尼）。

对外用激素的恐惧是治疗不足的常见原因。合理使用时它们是安全的：皮肤变薄和全身作用主要来自在薄皮肤或大面积上长期使用强效制剂。清楚说明用哪种制剂、涂在哪里、用多少、用多久，是治疗的一部分。

::: example 为婴儿制订治疗计划 {#ex-infant}
一名9个月大的男婴患瘙痒性湿疹四个月，现累及双颊、双小腿前侧和双上臂背侧，有抓痕。父母每天用少量“天然”乳霜一次，担心使用激素。按手掌规则，约25%的皮肤受累。你将如何为他制订治疗计划？
::: solution
**解释**：特应性湿疹是一种常见、可治疗的疾病，源于皮肤屏障漏洞和炎症（[[#thm-barrier]]）；它常随年龄增长而好转；治疗能控制但不能治愈。

**润肤剂**：大量、频繁地使用温和的润肤剂（每天数次），洗澡时也用来代替肥皂；处方量要足（对湿疹广泛的婴儿，也许每周250 g）。避免含香料的产品。

**外用糖皮质激素**用于发作：面部用**弱效**激素（1%氢化可的松），四肢用弱效或**中效**激素，每天一到两次涂于炎症皮肤，直到消退（通常1至2周）。解释以这种方式短期使用不会使皮肤变薄。

**安全网**：如果湿疹突然加重，出现疼痛、簇集、凿缘状的糜烂或水疱，或孩子精神变差，应紧急复诊（可能是**疱疹样湿疹**）。细菌感染的征象（渗液、结痂、脓疱、发热）也需要复查。
:::
:::

::: warning 疱疹样湿疹是急症
**疱疹样湿疹**（单纯疱疹病毒在湿疹皮肤上播散）表现为成簇的疼痛性凿缘状糜烂或水疱，常伴发热。它很容易被误认为细菌感染或普通发作。它需要**立即抗病毒治疗**（阿昔洛韦）并当天进行专科评估，如累及眼部需紧急眼科检查。不要只用更强的激素来应对突然的疼痛性发作。
:::

## 银屑病 {#sec-psoriasis}

::: definition 银屑病 {#def-psoriasis}
**银屑病**是一种慢性免疫介导的炎症性皮肤病，影响英国和欧洲约2%的人。树突状细胞产生**IL-23**，维持产生**IL-17**的**Th17**细胞；IL-17和TNF驱动角质形成细胞增殖并招募中性粒细胞。表皮更新只需数天而不是数周，形成厚的鳞屑性斑块。

主要类型：

- **慢性斑块型银屑病**（最常见）：边界清楚的红色或橙红色斑块，覆有银白色鳞屑，位于**伸侧**（肘、膝）、**头皮**、下背部和脐部。在较深肤色上，斑块可呈紫红色或灰褐色，并遗留色素改变。新斑块可出现在损伤部位（**同形反应**，即Koebner现象）。
- **点滴型银屑病**：躯干上许多小的“雨滴状”斑块，常见于儿童和年轻成人**链球菌性咽炎**后2至3周。
- **屈侧（反向）银屑病**：腹股沟、臀沟和乳房下方光滑、发红、发亮的无鳞屑斑块。
- **脓疱型银屑病**：局限于手掌和足底，或**泛发性**（von Zumbusch型），后者伴发热和成片脓疱，是内科急症。
- **红皮病型银屑病**：累及超过90%的皮肤，是急症（见[[#sec-drugs]]）。
- **甲银屑病**：甲凹点、甲剥离（甲板与甲床分离）、“油滴样”变色和甲下角化过度；与银屑病关节炎密切相关。

诱因包括链球菌感染、精神压力、吸烟、饮酒、皮肤损伤和药物（锂、β受体阻滞剂、抗疟药，以及**停用系统性糖皮质激素**，后者可诱发脓疱性发作）。
:::

银屑病是一种系统性炎症性疾病，与**银屑病关节炎**（[[musculoskeletal/inflammatory-arthritis]]）、**心血管疾病**、肥胖、糖尿病、脂肪肝、**炎症性肠病**和**抑郁**相关。NICE（CG153）建议评估严重程度（体表面积、**PASI**）和影响（**DLQI**），至少每年筛查一次银屑病关节炎（例如用PEST），并评估心血管风险。

治疗遵循阶梯：

1. **外用**：躯干和四肢用**强效糖皮质激素**加卡泊三醇等**维生素D类似物**；面部和屈侧用较弱的激素或钙调神经磷酸酶抑制剂。
2. **光疗**：窄谱中波紫外线（UVB）。
3. **系统性非生物药物**：**甲氨蝶呤**（通常为首选）、**环孢素**、**阿维A**（一种高度致畸的口服维A酸类药物）、阿普米司特和氘可来昔替尼。
4. 严重病例用**生物药物**：TNF抑制剂（如阿达木单抗）、IL-17抑制剂（如司库奇尤单抗和比美吉珠单抗）、IL-23抑制剂（如古塞奇尤单抗和利生奇珠单抗）和IL-12/23抑制剂（乌司奴单抗）。现在许多人能达到皮损完全或几乎完全清除。

::: example 皮肤以外的银屑病 {#ex-psoriasis}
一名46岁男性患慢性斑块型银屑病20年。尽管外用治疗，斑块现已覆盖约15%的体表，包括头皮和双手，他因此不愿陪孩子游泳。他有甲凹点，六个月来右手中指整根肿胀，双手有晨僵。他吸烟，每周饮酒40单位，BMI 34 kg/m²，血压152/94 mmHg。需要处理哪些问题？治疗选择有哪些？
::: solution
**皮肤**：外用治疗无法控制的广泛斑块型银屑病（15% BSA，且累及头皮和双手等影响大的部位），对生活质量有明显影响（可用DLQI量化）。他符合**光疗或系统治疗**的条件。

**关节**：甲凹点伴**指炎**和炎症性晨僵，强烈提示**银屑病关节炎**。他需要转诊风湿科，因为早期治疗可防止关节损害（[[musculoskeletal/inflammatory-arthritis]]）。

**合并症**：吸烟、大量饮酒、肥胖和血压升高，叠加在银屑病本已带来的心血管风险之上。他需要心血管风险评估，以及戒烟、减少饮酒和减重的支持；还应询问情绪状况。

**治疗选择**：**甲氨蝶呤**能同时治疗皮肤和关节，但有肝毒性，这对他的饮酒量是个问题。**环孢素**因他的高血压而受限。在筛查结核和肝炎后，**生物药物**（IL-17、IL-23或TNF抑制剂）是同时治疗皮肤和关节的有力选择。
:::
:::

## 痤疮、玫瑰痤疮与化脓性汗腺炎 {#sec-acne}

::: definition 寻常痤疮 {#def-acne}
**寻常痤疮**是毛囊皮脂腺单位的慢性炎症性疾病，影响大多数青少年和许多成人。四个过程起作用：雄激素驱动的**皮脂分泌**；毛囊口**角化异常**，形成**粉刺**（开放性“黑头”和闭合性“白头”）；*痤疮皮肤杆菌*；以及**炎症**，产生丘疹、脓疱，严重痤疮还有**结节**和**囊肿**。瘢痕和炎症后色素沉着可以是永久性的，任何严重程度的痤疮都可能造成明显的心理困扰。
:::

在英国，痤疮按照NICE NG198（2021年）处理。一线选择是以下之一的**12周疗程**：

- 外用**阿达帕林与过氧化苯甲酰**固定复方制剂（任何严重程度）；
- 外用**维A酸与克林霉素**固定复方制剂（任何严重程度）；
- 外用**过氧化苯甲酰与克林霉素**固定复方制剂（轻至中度）；
- 对中至重度痤疮，外用阿达帕林与过氧化苯甲酰**加**口服赖甲环素或多西环素，或外用**壬二酸加**口服赖甲环素或多西环素。

为限制耐药，避免抗生素**单药治疗**以及外用与口服抗生素合用；口服抗生素通常使用不超过6个月。妊娠期和12岁以下不用四环素类。结节囊肿性痤疮、有瘢痕、持续性色素沉着、明显心理困扰，或充分的一线疗程无效者，转诊至**由皮肤科顾问医师领导的团队**。

### 异维A酸 {#sec-isotretinoin}

口服**异维A酸**是一种维A酸类药物，能使皮脂腺萎缩，大幅减少皮脂分泌，并使毛囊角化恢复正常。它是唯一能使许多人在一个疗程后获得痤疮长期缓解的治疗。它用于**重度痤疮**，以及经过充分的系统抗生素加外用标准治疗仍无效的痤疮，只能由**皮肤科顾问医师领导的团队**开具或在其监督下使用，该团队的主处方医师须具备系统性维A酸类药物方面的专长。12岁以下不使用。

按照英国药品和保健品管理局（MHRA）的规定，其重要危害和相应的安全措施如下：

- **致畸性**：异维A酸会导致严重的出生缺陷。任何可能怀孕的人都必须加入**妊娠预防计划**，该计划要求从治疗前直到停药后至少一个月使用高效避孕措施，并在治疗前、治疗期间（通常每月一次）和治疗后进行**医学监督下的妊娠试验**。自2025年10月起，在有适当监督的情况下，监督下的检测可以远程进行。
- **精神方面的作用**：已有抑郁、焦虑、情绪改变以及罕见的自杀念头的报告。人用药品委员会的一项审查认为，由于证据存在空白，无法确定异维A酸是否确实导致这些作用。**治疗前评估心理健康**，包括使用患者报告结局量表，并在每次随访时监测。
- **性方面的副作用**：已有性欲减退和勃起功能障碍的报告，有些在停药后仍持续存在。开始治疗前和随访时询问性功能。
- **常见作用**：口唇干燥（几乎人人都有）、皮肤和眼睛干燥、鼻出血、肌肉和关节酸痛、光敏感，以及血脂和肝酶升高，需要验血监测。罕见作用包括良性颅内压增高，尤其是与四环素类合用时，这就是两者不能同时使用的原因。

英国的要求最近有所变化。2023年10月，MHRA引入的措施中包括：18岁以下者开始使用异维A酸前须由两名独立处方医师同意。2026年1月，MHRA发现这一步骤延误了部分年轻人获得治疗，却没有明确证据表明增加了安全性，于是用其他措施取代了第二处方医师的要求：更新的（数字化）**风险确认表**、英国皮肤科医师协会制作的须在治疗开始前观看的**患者信息视频**，以及定期的**全国临床审计**。妊娠预防计划、针对心理健康和性方面副作用的咨询与监测、主处方医师要求、患者提示卡和药师核对清单都继续实行，首次就诊应面对面进行。由于这些安排仍在不断变化，应遵循当地指南和MHRA的最新建议。

### 玫瑰痤疮与化脓性汗腺炎

**玫瑰痤疮**引起潮红、面中部发红和毛细血管扩张，常有丘疹和脓疱，但**没有粉刺**。治疗包括避免诱因、外用伊维菌素、甲硝唑或壬二酸，以及口服多西环素。面部外用强效激素会使玫瑰痤疮和**口周皮炎**加重。

**化脓性汗腺炎**在腋窝、腹股沟和乳房下方引起疼痛性反复发作的结节、脓肿和流脓窦道。它与吸烟和肥胖相关，常诊断较晚，治疗包括长疗程抗生素、生物制剂（阿达木单抗、司库奇尤单抗、比美吉珠单抗）和手术。

## 荨麻疹 {#sec-urticaria}

**荨麻疹**由**风团**组成，每个风团持续不到24小时，源于真皮内肥大细胞释放组胺；更深部的肿胀是**血管性水肿**。**急性荨麻疹**（不到6周）常继发于病毒感染，较少由药物或食物引起。**慢性荨麻疹**（6周或以上）通常是**自发性**的，有时由压力、寒冷或搔抓诱发。治疗是规律服用**非镇静性H1抗组胺药**，慢性荨麻疹在监督下可加量至说明书剂量的四倍，难治者用**奥马珠单抗**。

有两个例外很重要。**不伴风团的血管性水肿**提示缓激肽介导的病因，如**ACE抑制剂**或**遗传性血管性水肿**，它们对抗组胺药、糖皮质激素或肾上腺素无反应。风团持续超过24小时或遗留瘀斑提示**荨麻疹性血管炎**。荨麻疹伴呼吸困难、低血压或虚脱是**过敏性休克**（[[emergency-critical-care/anaphylaxis]]）。

::: example 无皮疹的嘴唇肿胀 {#ex-angioedema}
一名63岁英国黑人男性两个月内三次出现无痛性嘴唇肿胀，有一次舌头也肿，每次持续约两天。无瘙痒，无皮疹。四个月前他开始服用雷米普利治疗高血压。有一次急诊科给他用了氯苯那敏和氢化可的松，效果甚微。可能的原因是什么？应该怎么做？
::: solution
可能的原因是**ACE抑制剂所致的血管性水肿**。**不伴风团或瘙痒**、持续一天或更久、对抗组胺药和糖皮质激素无反应的血管性水肿，提示**缓激肽介导**的机制：ACE通常降解缓激肽，抑制ACE会使缓激肽蓄积。它可在开始用药后数月甚至数年才出现，在非洲黑人或加勒比血统人群中更常见。

**永久停用雷米普利**，记录为不良反应，今后避免使用ACE抑制剂；改用其他降压药，如钙通道阻滞剂。发作可能还会持续几周。舌或咽喉肿胀是急症，因为气道可能阻塞。如果发作持续或有家族史，检测**C4和C1酯酶抑制物**水平。
:::
:::

## 皮肤感染 {#sec-infections}

::: definition 常见皮肤感染 {#def-infections}
**细菌感染**

- **脓疱疮**：*金黄色葡萄球菌*和（或）*化脓性链球菌*引起的浅表感染，主要见于儿童，有金黄色“蜂蜜样”结痂。NICE NG153建议，对全身情况良好的局限性非大疱性脓疱疮，使用1%过氧化氢乳膏；对广泛或大疱性病变，口服氟氯西林等抗生素。
- **蜂窝织炎**及较浅表、边界清楚的**丹毒**：发热、压痛、扩散的红斑区，通常在**一条**腿上，细菌常经趾间皲裂或足癣进入。双侧红腿很少是蜂窝织炎。
- **坏死性筋膜炎**：迅速扩散的筋膜感染，**疼痛与可见体征不相称**，伴全身中毒症状；是**外科急症**（[[surgery/wounds-surgical-infection]]）。

**真菌感染**：躯干、足、腹股沟、头皮和甲的**皮肤癣菌（癣）**感染，表现为环形鳞屑性斑块，边缘活跃，通过刮屑镜检和培养确诊（用外用激素治疗癣会改变其外观：**难辨认癣**）；以及潮湿皮肤皱褶处伴卫星脓疱的**念珠菌**性间擦疹。

**病毒感染**：**单纯疱疹**（簇集性水疱，在同一部位复发）；**带状疱疹**（一个**皮节**内的疼痛和簇集性水疱；出疹72小时内抗病毒治疗；眼支受累需紧急眼科评估；接种疫苗可降低风险）；**病毒疣**和**传染性软疣**。

**寄生虫感染**：**疥疮**，由*人疥螨*引起，夜间剧烈瘙痒，指蹼和腕部有隧道，生殖器有丘疹。所有家庭成员和密切接触者同时治疗（通常用氯菊酯乳膏，一周后重复）。体弱或免疫抑制者的**结痂性疥疮**会在养老院引起暴发。
:::

## 药疹、大疱性疾病与皮肤衰竭 {#sec-drugs}

大多数**药疹**是**麻疹样皮疹**，即在开始使用新药后4至14天出现、停药后消退的小红色斑疹和丘疹。关键技能是识别少数危及生命的反应的警示特征：黏膜受累、水疱或剥脱、皮肤疼痛、面部肿胀、发热和全身性疾病。

::: definition 严重皮肤不良反应 {#def-scar}
**Stevens–Johnson综合征（SJS）**和**中毒性表皮坏死松解症（TEN）**是同一谱系的严重反应，角质形成细胞死亡，表皮剥离。通常在开始用药后4至28天，先有发热和不适，随后出现疼痛性暗红色斑疹、不典型靶形损害、水疱和**表皮剥离**（尼氏征阳性），伴**两处或以上黏膜糜烂**。按剥离的体表面积分类：

- **SJS**：少于10%；
- **SJS/TEN重叠**：10%至30%；
- **TEN**：超过30%。

常见致病药物包括**别嘌醇**、**卡马西平**、**拉莫三嗪**、**苯妥英**、**磺胺类**（复方磺胺甲噁唑）、**奈韦拉平**和昔康类非甾体抗炎药。携带特定HLA等位基因者风险高得多：**HLA-B\*15:02**与卡马西平（对汉族和东南亚血统人群，建议用药前检测）以及**HLA-B\*58:01**与别嘌醇。

**SCORTEN**评分根据入院24小时内存在的七个因素估计死亡率，每项1分：年龄40岁或以上；恶性肿瘤；心率每分钟120次或以上；初始剥离BSA超过10%；血清尿素超过10 mmol/L；血糖超过14 mmol/L；血清碳酸氢盐低于20 mmol/L。预测死亡率随评分急剧上升，从0或1分时的百分之几到5分或以上时的90%以上。

**伴嗜酸性粒细胞增多和全身症状的药物反应（DRESS）**起病较晚，通常在用药后2至8周，表现为发热、泛发皮疹、**面部肿胀**、淋巴结肿大、**嗜酸性粒细胞增多**，以及**肝**、肾、肺或心脏受累。人类疱疹病毒6型再激活常见。抗惊厥药、别嘌醇和某些抗生素是常见原因。
:::

SJS/TEN和DRESS的第一步是**停用可疑药物**。SJS/TEN患者在烧伤或重症监护病房中按烧伤处理：补液、体温、创面、眼部和黏膜护理、营养以及感染监测。致病药物必须终身避免，并上报该反应（在英国通过黄卡系统）（[[pharmacology/adverse-reactions]]）。

::: example 新药后的皮疹 {#ex-ten}
一名52岁男性18天前开始服用别嘌醇治疗痛风。两天来他发热、眼痛、口腔溃疡疼痛，现在躯干出现暗红色斑片伴水疱；轻压时皮肤剥脱，范围约占体表的18%。心率每分钟128次。尿素12 mmol/L，血糖9 mmol/L，碳酸氢盐18 mmol/L。无癌症病史。对这一反应分类并计算他的SCORTEN。
::: solution
这是伴表皮剥离和黏膜受累的严重皮肤不良反应，是典型的**SJS/TEN**。剥离面积占BSA的18%，属于**SJS/TEN重叠**范围（10%至30%）。18天前开始使用的别嘌醇可能是致病药物。

**SCORTEN**：年龄40岁或以上（1）；恶性肿瘤（0）；心率120次或以上（1）；剥离BSA超过10%（1）；尿素超过10 mmol/L（1）；血糖超过14 mmol/L（0）；碳酸氢盐低于20 mmol/L（1）。总分**5**，预示死亡率很高。

**处理**：立即停用别嘌醇；紧急转入烧伤或重症监护病房；补液、保温、镇痛、创面护理和营养；紧急眼科检查。绝不能再次使用别嘌醇：记录为过敏并上报该反应。
:::
:::

**免疫性大疱病**由针对维系皮肤结构的蛋白的自身抗体引起。

- **寻常型天疱疮**：针对**桥粒芯糖蛋白3**（常同时针对桥粒芯糖蛋白1）的抗体使表皮内分离，产生**松弛性**水疱和疼痛性糜烂；**口腔糜烂**常是首发表现。用糖皮质激素和利妥昔单抗治疗。
- **大疱性类天疱疮**：针对**BP180**和**BP230**的抗体使表皮下分离，在瘙痒的皮肤上产生**紧张性**水疱，主要见于70岁以上者；部分病例与DPP-4抑制剂（格列汀类）相关。治疗包括超强效外用糖皮质激素、多西环素或口服糖皮质激素。
- **疱疹样皮炎**：肘、膝和臀部剧烈瘙痒的水疱，与**乳糜泻**及真皮乳头IgA沉积相关；对无麸质饮食和氨苯砜有反应（[[gastrointestinal/bowel-disease]]）。

诊断依靠皮肤活检做组织学和**直接免疫荧光**，加上血清抗体检测。**红皮病**是超过90%皮肤表面的炎症，病因包括湿疹、银屑病、药物反应和皮肤T细胞淋巴瘤。它是一种**急性皮肤衰竭**：热量和液体丢失、蛋白丢失、感染风险以及高输出量心脏负荷。需要紧急评估，通常需要住院。

::: quiz
一名80岁女性瘙痒数周后，大腿和腹部出现大的紧张性充液水疱。口腔未受累，按压时水疱不扩展。最可能的诊断是什么？
- [ ] 寻常型天疱疮
- [x] 大疱性类天疱疮
- [ ] 中毒性表皮坏死松解症
- [ ] 疱疹样皮炎
::: solution
老年人先有瘙痒前驱期、随后出现紧张性水疱、无黏膜受累，是**大疱性类天疱疮**的典型表现。天疱疮引起松弛性水疱和糜烂，通常累及口腔；TEN引起伴黏膜受累和全身性疾病的广泛疼痛性剥离。
:::
:::

::: history
伦敦医师**罗伯特·威兰（Robert Willan）**以《论皮肤病》（自1798年起出版）奠定了现代皮肤病学的基础，按皮损外观对皮肤病分类。1925年，梅奥诊所的**威廉·格克曼（William Goeckerman）**引入了先用煤焦油、再照紫外线治疗银屑病的方法。1956年，苏格兰皮肤科医师**艾伦·莱尔（Alan Lyell）**描述了中毒性表皮坏死松解症。1982年异维A酸在美国获批用于重度痤疮；其致畸性催生了所有药物中最严格的风险管理计划之一。2006年，**欧文·麦克莱恩（Irwin McLean）**及其同事证明聚丝蛋白基因变异是特应性湿疹的主要危险因素。
:::

## 习题

::: exercise 说出皮损名称 {level=1}
给出每项的正确术语：(a) 直径4 mm、平坦不可触及的褐色斑点；(b) 直径3 cm、隆起、顶部扁平、有鳞屑的区域；(c) 直径2 cm、充满清亮液体的水疱；(d) 数小时内消失的瘙痒性隆起肿胀；(e) 直径2 mm、压之不褪色的紫色斑点。
::: solution
(a) **斑疹**。(b) **斑块**（伴鳞屑）。(c) **大疱**。(d) **风团**。(e) **瘀点**（小面积紫癜）。
:::
:::

::: exercise 在哪一层？ {level=1}
说明(a)寻常型天疱疮和(b)大疱性类天疱疮中自身抗体的靶点以及皮肤分离的层次。解释为什么一种产生松弛性水疱，另一种产生紧张性水疱。
::: solution
(a) 寻常型天疱疮：**桥粒芯糖蛋白3**（常同时有桥粒芯糖蛋白1），为桥粒的组成部分；分离发生在**表皮内**。(b) 大疱性类天疱疮：**BP180和BP230**，为半桥粒的组成部分；分离发生在**表皮下**。天疱疮的疱顶只是部分表皮，所以水疱松弛并破裂成糜烂；类天疱疮由整个表皮构成较牢固的疱顶，所以水疱紧张。
:::
:::

::: exercise 需要多少激素？ {level=1 check="140"}
一名成人湿疹发作，累及20%的体表面积，需每天两次外用糖皮质激素，共14天。按1 FTU $= 0.5$ g覆盖2% BSA计算，整个疗程需要多少克？
::: solution
每次需要$20/2 = 10$ FTU $= 10 \times 0.5 = 5$ g。每天两次共14天，即28次：$28 \times 5 = 140$ g。一支30 g的药膏用不到三天，这解释了许多表面上的治疗失败。
:::
:::

::: exercise 躯干新发皮疹 {level=2}
一名17岁女孩咽痛两周后，躯干和上肢出现数十个小的、有鳞屑的粉红色“滴状”斑块。她父亲患银屑病。可能的诊断是什么？哪项检查可支持诱因？预后如何？
::: solution
**点滴型银屑病**，典型地由儿童和年轻成人的**链球菌性咽炎**诱发；咽拭子或抗链球菌溶血素O滴度升高可支持这一点。它常在数周至数月内经润肤剂、外用治疗或窄谱UVB而消退；部分人以后会发展为慢性斑块型银屑病。
:::
:::

::: exercise 选择痤疮治疗 {level=2}
一名16岁男孩患中至重度痤疮，面部、胸部和背部有许多丘疹和脓疱，并有少量早期瘢痕。他用过药店买的过氧化苯甲酰凝胶。按照NICE NG198，你会提供什么治疗？用多久？何时转诊？
::: solution
提供中至重度痤疮一线方案的**12周疗程**，例如**外用阿达帕林与过氧化苯甲酰加口服赖甲环素或多西环素**（口服药物对背部和胸部有帮助）。避免抗生素单药治疗。12周时复查。由于他已有**瘢痕**，NICE建议考虑转诊至皮肤科顾问医师领导的团队，在那里异维A酸可能是合适的。询问他的情绪和心理影响。
:::
:::

::: exercise 关于异维A酸的咨询 {level=2}
一名19岁女性患结节囊肿性痤疮并有瘢痕，即将在皮肤科团队指导下开始使用异维A酸。列出必须涵盖的主要安全要点。
::: solution
**妊娠预防**：她加入妊娠预防计划：从开始用药前直到停药后至少一个月使用高效避孕措施，并在治疗前、治疗期间（通常每月一次）和治疗后进行监督下的妊娠试验。治疗期间及停药后短期内不得与他人分享药物，也不得献血。

**心理健康**：开始前用患者报告结局量表评估，并在每次随访时评估；她和家人应及时报告情绪低落、焦虑或自伤念头，必要时紧急求助。

**性功能**：开始前和随访时询问；已有性方面副作用的报告，偶尔在停药后仍持续。

**常见作用**：口唇、皮肤和眼睛干燥，鼻出血，酸痛，光敏感；验血检查血脂和肝功能。治疗期间不用四环素类（颅内压增高）。

**程序**：风险确认表、患者信息视频、患者提示卡以及配药时的药师核对；她可以随时要求第二意见。
:::
:::

::: exercise SCORTEN {level=3 check="2"}
一名35岁女性开始服用拉莫三嗪10天后发生TEN。入院时剥离面积占BSA的35%，心率每分钟110次，尿素8 mmol/L，血糖15 mmol/L，碳酸氢盐22 mmol/L，无恶性肿瘤。计算她的SCORTEN。
::: hint
逐一检查[[#def-scar]]中的七个因素。
:::
::: solution
年龄40岁或以上：0。恶性肿瘤：0。心率120次或以上：0。剥离BSA超过10%：**1**。尿素超过10 mmol/L：0。血糖超过14 mmol/L：**1**。碳酸氢盐低于20 mmol/L：0。SCORTEN总分$= 2$。剥离面积35%使该反应归类为TEN。她仍需要烧伤或重症监护处理；第3天重新计算SCORTEN，拉莫三嗪必须停用且永不再用。
:::
:::

::: exercise 两条红腿 {level=3}
一名76岁心力衰竭女性以“双侧蜂窝织炎”入院。双小腿发红、发热、脱屑、瘙痒，有褐色色素沉着和静脉曲张。她无发热，白细胞计数和CRP正常。已用过两个疗程抗生素，未见改善。(a) 最可能的诊断是什么？(b) 哪些特征会使真正的蜂窝织炎更有可能？(c) 应如何处理？
::: hint
蜂窝织炎几乎总是单侧的。想一想静脉循环及其上方的皮肤。
:::
::: solution
(a) **静脉性（淤积性）湿疹**，可能伴脂性硬皮病或对外用药的变应性接触性皮炎，背景是心力衰竭所致的静脉高压和水肿。双侧、脱屑、瘙痒的发红伴含铁血黄素沉着和静脉曲张，无发热，炎症标志物正常，使蜂窝织炎的可能性很小。

(b) 真正的蜂窝织炎通常是**单侧**的，急性**疼痛和压痛**而非瘙痒，呈扩散性，常伴发热、白细胞和CRP升高，并有入侵门户（如趾间皲裂或足癣）。可引起淋巴管炎或局部淋巴结压痛。

(c) **停用抗生素**。用**润肤剂**和短疗程**中效或强效外用糖皮质激素**治疗湿疹，如怀疑对乳膏接触过敏则做斑贴试验。治疗水肿（心力衰竭治疗、抬高患肢），在用踝肱压力指数排除动脉疾病后使用**加压**治疗。
:::
:::
