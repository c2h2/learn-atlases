背与颈的疼痛是医学最大的单一的失能的来源、也是最常见的抱怨、而把它处理得最好的是一个悖论：**做一次足够仔细的病史采集，把危险的少数排除掉，然后克制住“找到点什么”的冲动，因为在九成的患者身上，问题就是脊柱平常的力学，而治疗是安心、活动与时间。**这门手艺不是影像、也从来不是影像；这门手艺是那场危险信号的访谈、套“有意义”的神经系统的检查、以及那场“防止一次正常的酸痛变成一种失能的生活”的沟通——每位临床医师每周都要进行好几次的谈话。

本章涵盖机械性的背与颈的疼痛、神经根与脊髓的综合征、“特定的”脊柱的疾病、以及围绕它们慢性疼痛的系统。

## 常见的背

::: definition 机械性的腰背痛 {#def-mechanical}
**流行病学与负担（接近八成的终身患病率、与“在所有肌肉骨骼的病因中点患病率最高”、以及全球“带残疾生存的年数”由腰背痛主导、并带着那个“让预防成为唯一可放量的治疗”的复发的比率——[[public-health/determinants-inequalities]]、[[epidemiology-ebm/measuring-disease]]）；这种酸痛的解剖腰部的运动节——椎间盘作为液压的垫（带纤维环的层板与终板的生理学，胶原与蛋白聚糖的那几行见[[cell-biochemistry/proteins-enzymes]]、关节突作为“本体感觉的铰链”、胸腰的筋膜与多裂肌及髋与臀的运动学、骶髂关节作为一个“有它自己那套有争议的诊断”的疼痛的来源、以及椎旁的肌的耐力与疲劳的关联——[[physiology/muscle]]）；诊断的框架（非特异性的腰背痛占了八五%的诊断、以及“神经根性的与特定的病变”这两个分裂、它们组织了下面的一切；以及那场危险信号的访谈——肿瘤的病史与“无法解释体质性的症状”及免疫抑制及静脉吸毒及近期的器械的操作及尿的感染的症状及创伤、以及骨质疏松的风险及激素的使用、以及年龄的告诫——带着它们的似然比的算术、以及那句诚实的话：“没有单一的标志是敏感的”——[[clinical-skills/history-taking]]、危险信号的逻辑见[[musculoskeletal/bones-joints]]）；影像的政策（平片很少用、而在最初的六周里“只有当结果会改变处理时才做磁共振”；以及那个偶然发现的产业——无症状志愿者里的“椎盘的膨出与纤维环的撕裂及关节突的囊肿”让正常看起来很严重——以及“把良性的变异可视化”所带来的被贴标签的伤害——[[clinical-skills/medical-imaging]]、[[epidemiology-ebm/diagnostic-tests]]、安慰效应的那几行见[[psychiatry/anxiety-disorders]]）；急期的处理保持活动与相对的休息以日计、不以周计、按阶梯的镇痛非甾为先、乙酰氨基酚作为辅助而不是锚、以及“肌松药镇静的代价”、以及阿片那个例外（最短的疗程、并诚实地对待、以及“不要用空洞的话来安心”，因为安心必须具体地说出恢复的时间框架——[[pharmacology/adverse-reactions]]、[[clinical-skills/communication]]。）**
:::

::: definition 坐骨神经痛、狭窄与神经的综合征 {#def-radicular}
**椎间盘与神经根那个“以节段为界的疼痛与麻木及无力及反射的改变”的模式、带着“咳嗽与打喷嚏与持续的椎旁姿势”加重器、以及直腿抬高与“对侧的直腿抬高”的运动学后者的特异性更高、以及股神经的牵拉在高位的根；椎间盘的病理解剖与“为什么L4到5与L5到S1解释了大多数”（骺的解剖见[[anatomy/lower-limb]]、疼痛与炎症的机制见[[pathology/acute-inflammation]]）；马尾份危险信号的清单——鞍区的感觉与膀胱及肠的功能、以及双侧的神经的症状、以及“它可以在任何已经预约好腰椎的病变上突然出现”——以及“当下的检查加上随时可以复查的安全网”（[[clinical-skills/physical-examination]]、[[musculoskeletal/bones-joints]]、减压的时机见[[surgery/orthopaedics]]）；以及椎管狭窄（那条“神经源性间歇的跛行”的病史——在行走与站立时腿的沉重与麻木、“在屈曲与坐下时缓解”、因而“推着一辆购物车就能走更远”；以及它与“血管的跛行”的鉴别、以及“在老年人群中它比椎间盘的突出常见得多”这个现实——[[surgery/vascular-urological-surgery]]、[[geriatrics-palliative/ageing-frailty]]）。**
:::

## 特定的脊柱

::: definition 感染、肿瘤、骨折与炎症的脊柱 {#def-specific}
**感染“背痛加发热加C反应蛋白升高”三联、以及在“静脉吸毒或近期器械操作或菌血症”的背景下的椎间盘炎与椎体的骨髓炎——血行的源头常常在尿（[[renal/urinary-tract]]），而磁共振是首选的检查、血培养常能定论、治疗“以抗生素为主”且常长程（[[microbiology/bacteria]]、[[infectious-diseases/healthcare-infections]]）——以及硬膜外的积脓：那种“迅速演变神经的缺失”需要“紧急的引流”（[[nervous-system/motor-systems]]）——以及地方性的模仿者脊柱的结核（波特病与布鲁菌病——[[infectious-diseases/tuberculosis]]、[[infectious-diseases/tropical-infections]]）。肿瘤那种夜间的与不缓解的疼痛，以及“已知的原发性或年龄加体重下降”的加成的价值；转移与骨髓瘤及淋巴瘤，加上“脊髓的压迫”一条独立的急症通道，配地塞米松与紧急的影像与肿瘤专科（[[blood/lymphoma-myeloma]]、[[pathology/cancer-diagnosis]]、[[surgery/orthopaedics]]）。骨折脆性骨折——“提个购物袋或打了个喷嚏”，以及“在骨质疏松年龄段的任何急性背痛都算一次骨折、直到X线或磁共振说了别的”；以及创伤（带着严重创伤与脊柱的清点“——[[musculoskeletal/fractures]]、[[surgery/trauma]]、[[endocrine/bone-calcium]]）；以及“应力与功能不全的骨折”“只在磁共振上出现”的线（骶骨与椎弓）（[[physiology/muscle]]）。炎症那个“45岁之前起病、隐匿、晨僵超过30分钟、夜间后半段因痛醒、因活动而改善、并对非甾的反应良好”的、脊柱关节炎的背（[[musculoskeletal/inflammatory-arthritis]]）——与机械性的背的对照、以及那张“如果背痛在16到40岁之间起病，就值得问一问”的提醒（[[clinical-skills/history-taking]]）。**
:::

::: definition 颈与它的神经 {#def-neck}
**机械性的颈痛（那个“由机械调节的颈痛”的诊断、带着它的姿势与职业及睡眠的背景；以及挥鞭伤相关综合征的轨迹——早期的活动与多模式的处理、对“颈圈与慢性化的驱动因素”，带着“心理的回避与信念”及交通与赔偿的体系的文献——颈的肌的那一行见[[physiology/muscle]]、[[psychiatry/anxiety-disorders]]、[[public-health/health-systems-economics]]）。颈椎的神经根病（按皮区分布的臂的疼痛伴反射与肌节的改变、以及“椎间孔的狭窄对椎间盘的突出”的机制、以及“压头试验对牵开试验”这一对；以及“能毁掉一个职业生涯”的鉴别——臂丛的病与“神经痛性的肌萎缩”及肺尖的肿瘤及“胸廓的出口”、以及以无痛的无力起病的运动神经元病——[[nervous-system/motor-systems]]、[[respiratory/lung-cancer-pleura]]、血管性胸廓出口的相邻见[[surgery/vascular-urological-surgery]]；以及“自然史对经椎间孔硬膜外的注射、对椎间孔的切开与椎间盘的切除融合”决定、带着多节段与骨性增生的背景——[[surgery/orthopaedics]]）。颈椎的脊髓病（那个“缓慢的手与步态”的综合征——灵活性的丧失与笨拙及痉挛的步态与反射亢进及霍夫曼与巴宾斯基，以及“手指逃逸的征”与莱米特征、以及晚期的膀胱的尿急；以及“骨性增生对韧带的骨化对类风湿的不稳”脊柱里的“脊髓的受压”的机制；以及那条“不要去按摩、也不要不要去整脊一节不稳定或受压的脊柱”的安全规则、以及“手术减压的时机对脊髓病的病程”的论证、以及“类风湿寰枢的半脱位在麻醉之前要影像”——颈椎的那一行见[[musculoskeletal/inflammatory-arthritis]]、[[surgery/anaesthesia-pain]]、[[nervous-system/motor-systems]]、[[surgery/orthopaedics]]。）**
:::

::: example 台全科医师拒绝开的磁共振 {#ex-refused-mri}
一名34岁的仓库工人搬举之后有3周的中央的腰背痛、无放射、神经的检查正常、没有危险信号、而害怕“一个滑脱的椎盘”；他要求做磁共振，因为他哥哥“得过并且做了手术”。
::: solution
**不做影像、外加一段“能与他哥哥竞争”的解释（[[#def-mechanical]]）：场概率的谈话——正常的检查加三周轴心的疼痛，让“严重的病变”非常不可能——而“早早做磁共振的人平均结局更差”，因为标签与偶然发现及延迟的复工会跟着他们；以及那句诚实的话：这不是“用费用去审查”、而是有证据的“避免伤害”——[[clinical-skills/medical-imaging]]、[[epidemiology-ebm/observational-studies]]、[[public-health/health-systems-economics]]；份像药一样清楚地讲出来的“处理的处方”——继续活动与“工作的调整不是撤除”、运动的项目与镇痛、配上安全网、以及那个“大多数人六周之内好转”的恢复的窗口、以及“哪些恶化要回来”的具名的清单——[[physiology/muscle]]、[[pharmacology/adverse-reactions]]、[[clinical-skills/communication]]；工作关系的那一层——与雇主的谈话与“支持恢复、而不是证明无助”的“适合工作的证明”的策略、以及赔偿与出勤的激励的现实——[[public-health/environmental-occupational]]、[[public-health/health-systems-economics]]；以及随访的纪律——一个复查的日期，好让那份安心是一项计划、不是一种打发；以及“如果轨迹不对”的升级的路径——份“什么会改变我的想法”的清单——[[clinical-skills/records-handover]]、[[clinical-skills/clinical-reasoning]]。**
:::
:::

::: example 带着新发的背痛的已知的癌症 {#ex-mets}
一名63岁在3年前因乳腺癌接受过治疗的女性，报告6周的胸背部疼痛、在夜间与平卧时更重、不是机械性的、并出现新的“带状腹部的感觉”；检查发现局部胸椎的压痛与下肢轻度的反射亢进。
::: solution
**转移脊柱的疾病伴可能的早期的脊髓的受压——今天就做紧急的影像（[[#def-specific]]、危险信号见[[musculoskeletal/bones-joints]]）：现在做“增强全脊柱的磁共振”、并在无力到来之前按神经外科与肿瘤科的建议给地塞米松；把膀胱与肠的问题问到并记录为基线——[[nervous-system/motor-systems]]、[[clinical-skills/medical-imaging]]、激素的“胃的保护与血糖”这一点见[[pharmacology/adverse-reactions]]；团队的决定——“分离的手术对放疗对全身的治疗”的排序带脊柱稳定性的评分与肿瘤的生物学及放疗的敏感度的地图、以及鞘内对硬膜外的镇痛这两块地、以及支具与活动的限制——[[surgery/orthopaedics]]、肿瘤学的机制见[[pathology/cancer-diagnosis]]；全身的背景——“当组织会改变治疗时”的重新分期与活检、以及“骨调节的药与钙与牙科”的复查、以及早期整合的姑息治疗谈疼痛的目标与功能——[[endocrine/bone-calcium]]、[[geriatrics-palliative/palliative-care]]、放疗的相邻见[[pathology/cancer-diagnosis]]；以及与家属那场诚实的时间尺度的谈话——这次转诊是为了保住行走，不是为了“排除担心”——[[clinical-skills/communication]]、[[clinical-skills/patient-safety]]。**
:::
:::

::: example 那个需要做决定的椎间盘 {#ex-disc-surgery}
一名42岁有11周的右侧S1的神经根病尽管做了物理治疗与药物、磁共振显示“相符的、压迫S1的巨大椎间盘的脱出”、现在有加重的小腿三头肌的无力与“无法用脚尖站起”；膀胱正常、无鞍区的症状。
::: solution
**进行性运动的缺失加影像的相符，正是“保守优先”那条规则所要保护的那条手术适应证（[[#def-radicular]]）：转诊是现在、不是下个月，因为“无力的轨迹就是时钟”、而手术显微椎间盘的切除与他的症状与病灶相匹配——份诚实的效应量：手术加快的是腿的疼痛与无力的恢复、而不是对两者做保证，并给出复发与硬膜的撕裂及感染及“疼痛复发的数字”——[[surgery/orthopaedics]]、绝对数字的框架见[[epidemiology-ebm/measuring-disease]]；把马尾的安全网重新书面给出、因为他现在有了一个巨大中央的椎间盘在病史里——那张“膀胱与鞍区及双侧症状”的提醒卡、以及那条“腿无力就不要开车”的谈话——[[clinical-skills/communication]]、驾驶适格的那几行见[[endocrine/diabetes-complications]]；决定满意度围手术期的细节——麻醉的体位与抗生素的预防及静脉血栓、以及日间单元与导尿及出院的规划、以及那份诚实的“预期活动的时间线”驾驶与提重与复工的时序——[[surgery/perioperative-care]]、[[blood/thrombosis-anticoagulation]]；以及那件“之后的背痛”的问题——“腿的疼痛被治好了、轴心的疼痛还在”这一现实的期望的设定、以及核心的训练与复工的康复及“心理的灵活性”的计划，好让我不漂向慢性疼痛——[[physiology/muscle]]、[[psychiatry/anxiety-disorders]]。**
:::

::: example 夜间的发热与老人的背 {#ex-discitis}
一名81岁的糖尿病患者在“带保留导尿管的尿的感染”之后两周，出现不断加重的持续的腰部疼痛、夜间的出汗、体温38.1、椎旁的压痛、最初的神经的检查正常；C反应蛋白140、血培养在等待中、平片“只有退变”。
::: solution
**在磁共振说了别的之前，它就是“椎体的骨髓炎与椎间盘炎与硬膜外的积脓”这一谱（[[#def-specific]]）：本应提高这个反射的那叠风险——糖尿病与导尿管与尿的来源与年龄、加上“不断加重的非机械的夜间的疼痛”配合发热与C反应蛋白——这里平片毫无用处、而“正常的神经”是一个时刻、不是一个承诺，因为硬膜外的积聚宣称自己宣称得很晚——[[clinical-skills/medical-imaging]]、[[renal/urinary-tract]]、[[microbiology/bacteria]]；路径——紧急的“增强全脊柱的磁共振”与血培养、以及“在流行病学相符时”的布鲁菌与旅行的背景、以及在培养阴性时的CT引导的活检、以及感染科与脊柱外科的共同管理、以及“现在就引流”的触发神经的恶化或脓毒症的进展或诊断的不确定——[[nervous-system/motor-systems]]、[[surgery/orthopaedics]]、[[infectious-diseases/healthcare-infections]]；治疗的算术——长程的按微生物定向的抗生素带线路与“经外周中心的通路”及按肾的剂量的调整、以及金黄色葡萄球菌的菌血症时“心内膜炎与血管内的来源”的清扫、以及住院期间“血糖与压疮与营养”的集束——[[microbiology/antimicrobials]]、[[cardiovascular/valve-congenital-disease]]、[[endocrine/diabetes-complications]]、[[gastrointestinal/clinical-nutrition]]；以及稳定与康复的问题——当塌陷与畸形在进展时“支具对早期手术”、以及那场老年住院的“去适应的战斗”配物理治疗与谵妄的预防——[[geriatrics-palliative/delirium-dementia-care]]、[[physiology/muscle]]。**

## 慢性疼痛的系统

在五到八%的背痛的人身上，疼痛会变成“长期的失能的”、而预测因子很少在脊柱里。黄旗的文献如今已是普通的医学：对运动的恐惧与对疼痛的灾难化，比磁共振的发现更能预测失能；“脊柱已经损坏并且危险”这个信念驱动着回避、去适应、阿片的依赖与福利的退出；而“缺席会拖延”的最强的职业学的预测因子，是患者自己对重返工作的期望——它更多由职场的文化与工作的满意度及赔偿的设计塑造、而不是由病灶的严重度。这并不是说疼痛是想象出来的——伤害性的、炎症的与神经相关的疼痛是真实的、而中枢的放大是一种被描述的生理现象（见[[musculoskeletal/bones-joints]]与[[psychiatry/anxiety-disorders]]）——而是说：成功的治疗把功能当作终点，并在组织之外同时处理“心理与睡眠及情绪及工作与社会”这几层。

服务的后果随之而来。分层的照护——在首次接触时用简单的筛查“把支持的强度匹配到慢性化的风险”——胜过一刀切的物理治疗；对已经确立的失能性的疼痛，多学科的康复有一份“温和但真实”的证据基础，而阿片一分都没有；而最重要的谈话发生得早、用朴素的语言、并带一个具名复查的日期：普通的背痛如何表现、片子说明了什么又没说明什么、为什么运动就是药、职场能现实地改变什么、以及当轨迹“偏离了预期的曲线”时什么时候该重新评估。临床医师那支最强的慢性疼痛的药，是一个准确而不带威胁的解释、并且被良好地交付；而那一次“永远不会错”的转诊，是由“改变的故事”、而不是由“改变的片子”引发的那一次；而最有力的诊断仪器，是在随访时注意到“这位患者的故事已经不是一个背的故事了”。

在一个服务不足的领域里，有两组人值得“刻意地过度服务”。老年人悄无声息地累积脊柱的疾病——那个被归咎于“年龄”的狭窄、处“扭了一下”之后从未被照过的骨折、份被解释为“只是不稳”的脊髓病——而一位八十多岁背痛患者的一次跌倒、一次身高的减少、或新的手的笨拙，是一个“病史的问题”、不是一条“年龄的事实”，而问一句只花九十秒。而疼痛不会消退的患者，需要他们的诊断被按期重新打开、而不是被辩护：处被说成“机械性的”长达一个月骶髂化脓的关节、处以“生长的疼痛”起病的淋巴瘤、那个“把膀胱的症状读成阿片造成的尿潴留”的马尾。一条“很快就安心”的路径，必须同样“很快就重新发问”。

复发是流行病学的另一半：在好转的人中，大约一半会在一两年内再次发作、这就是为什么这一次发作应当被当作一次教育的门诊——那个已经学会了自己的触发因素、自己的运动与自己的危险信号的人，会在数日之内自我管理下一次发作、而不是重新开启那条“影像转诊手术”的瀑布。教授自我管理与渐进的活动的预防的项目、以及在“任何一次发作之后仍保留调整的职责”的职场，是唯一被证明能把复发曲线折弯的干预、而两者都比一次磁共振便宜。

有一条安全的脚注值得重复，因为它偶尔会致死：颈的高速的手法操作有造成椎动脉与颈动脉损伤的小的风险、而在“疑似的不稳、脊髓的受压、骨折、感染、肿瘤、以及结缔组织与血管的疾病”中它是被断然禁忌的——类风湿的寰枢关节与“齿状突的分离”应当出现在每一位转诊者的排除清单上，在任何人去“咔一下”一截脖子之前；而把一个“不舒服的患者”送去手法操作是一次系统的失败、不是治疗师的错误。

## 通向何处

危险信号与检查的逻辑在[[musculoskeletal/bones-joints]]；炎症的脊柱在[[musculoskeletal/inflammatory-arthritis]]；骨质疏松的骨折与骨的健康在[[endocrine/bone-calcium]]；血管跛行的鉴别在[[cardiovascular/vascular-disease]]；神经的缺失在[[nervous-system/motor-systems]]；肿瘤的分期在[[pathology/cancer-diagnosis]]；外科的决策在[[surgery/orthopaedics]]。

::: history
**背痛在“机制与道德主义”之间那场漫长的摆动：十九世纪那场“铁路的脊柱”的争论——它在“试图判断一截脊柱能否在没有病灶的情况下被损坏”的同时发明了心理创伤学，是今天的“伤害可塑性的疼痛”的辩论的直接祖先；二十世纪的姿势至上主义的年代——张力不足的背与紧身衣与“腹部肌的理论”以及“用膝、不要用背”的搬运的运动——它的“人机工程”活过了它的机制；椎间盘的造影与融合的扩张的那几十年与它们带来的谦卑——“融合对结构化的保守的照护”治疗非特异性背痛随机的比较、以及那两场重设了两个产业的市场安慰剂对照的椎体成形术的试验——[[epidemiology-ebm/randomised-trials]]、[[public-health/health-systems-economics]]；影像革命的双刃——“在无痛的脊柱里也有椎间盘的异常”的研究、以及随后那批“被贴标签的伤害”的文献——[[clinical-skills/medical-imaging]]、[[epidemiology-ebm/diagnostic-tests]]；生物心理社会的转向——实施的网络与风险的分层的旗帜、以及“北欧主动的模式与荷兰的指南的模型”，把治疗从休息移到工作、从结构移到功能——[[public-health/prevention-promotion]]、[[psychiatry/anxiety-disorders]]；以及阿片的那一段——一种“为背痛开药的习惯”如何变成一条人群的死亡率曲线、以及它强迫产生的“减药”的科学——[[pharmacology/adverse-reactions]]、[[geriatrics-palliative/polypharmacy]]。**
:::

::: summary
- 约85%的诊断是非特异性机械性的疼痛；临床医师的价值在于“需要不同的医学的”一小片特定的部分。
- 危险信号是访谈的发现、不是化验：肿瘤的病史与夜间的疼痛及感染的背景及创伤、以及那两道“膀胱与鞍区”的、为急症把关的提问。
- 早早影像通常是有害的：偶然的退变给正常的衰老贴上标签、而标签会改变行为、保险与期望。
- 神经根病大多会消退；马尾与进行性的运动的缺失，是“整个系统被设计去接住”的那两个例外。
- 颈藏着危险的模仿者——脊髓病与肿瘤及臂丛的病及椎动脉的症状——所以臂的痛的检查，看反射与步态的程度不亚于压头试验。
- 活动——步行与骑车与游泳及渐进的力量训练——是那支改变疾病的药；而处方、随访与职场的计划就是它的剂量、复查与续方。
:::
