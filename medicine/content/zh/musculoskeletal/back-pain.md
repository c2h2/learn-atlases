根据全球疾病负担研究，腰痛是全世界导致伤残生命年最多的单一原因。大多数成人一生中都会有腰痛，它是就医和请病假最常见的原因之一。然而在绝大多数人中找不到具体的结构性病因，一次急性发作的预后也良好。因此临床任务有两项：找出少数有严重或特定病因（癌症、感染、骨折、马尾综合征、炎症性疾病）的人；并以帮助其他所有人康复、保持活动的方式进行处理，而不是让他们因疼痛和恐惧而致残。

本章讲述有关的解剖、腰背痛的结构化分诊、非特异性腰痛的处理、坐骨神经痛与神经根检查、马尾综合征、椎管狭窄、严重的特定病因、颈痛，以及使急性疼痛变成慢性残疾的因素。除非另有说明，处理均遵循NICE指南NG59（16岁以上人群的腰痛和坐骨神经痛）。

## 有关的解剖 {#sec-anatomy}

腰椎有五块椎骨，每块前方是承重的椎体，后方是骨性椎弓，围成椎管。椎体之间是**椎间盘**。每个椎间盘有坚韧的纤维软骨外环，即**纤维环**，包绕着凝胶样的中心，即**髓核**。后方每对椎骨通过两个小的滑膜**关节突关节**相连。韧带（包括衬于椎管后壁的黄韧带）和椎旁肌完成了整个结构。

成人**脊髓**大约在L1–L2椎间盘水平以**脊髓圆锥**终止。其下方椎管内是**马尾**，即向下走行至各自出口的腰骶神经根束。支配膀胱、肠道和生殖器的神经根（S2至S4）走行在神经根束的中间。

每条腰神经根从**同序数椎骨椎弓根下方**的椎间孔出椎管：L4神经根从L4与L5之间穿出，L5神经根从L5与S1之间穿出。典型的L4–L5**后外侧椎间盘突出**不会压迫已从上方椎间孔穿出的L4神经根，而是压迫正向下走行至其出口的**L5**神经根。L5–S1突出通常压迫**S1**。极外侧型突出是例外，它影响同一节段的出口神经根。

许多结构都能产生腰背痛：椎间盘、关节突关节、骶髂关节、韧带、肌肉和椎体。实际上很少能说清是哪一个结构引起的，即使说清了也很少改变治疗。这就是为什么第一步是分诊，而不是解剖学诊断。

## 分诊：三组 {#sec-triage}

::: definition 腰背痛的分诊 {#def-triage}
经过病史采集和体格检查，腰背痛患者可分为三组之一：

1. **非特异性（机械性）腰痛**：腰骶部疼痛，可放射到臀部或大腿，没有神经根受压或严重疾病的体征。占绝大多数，常被引用的比例约为90%。
2. **根性疼痛（坐骨神经痛）**：沿神经根分布放射到膝以下的疼痛，常比腰痛更重，有时伴麻木、无力或反射改变。占腰背痛患者的少数，约5%至10%。
3. **特定或严重病变**：在初级医疗中约占1%至2%，包括：
   - **马尾综合征**；
   - **恶性肿瘤**：转移瘤（乳腺癌、前列腺癌、肺癌、肾癌和甲状腺癌常转移到骨）和骨髓瘤；
   - **感染**：椎间盘炎、椎体骨髓炎、硬膜外脓肿、结核；
   - **骨折**：骨质疏松性椎体骨折或创伤；
   - **炎症性疾病**：中轴型脊柱关节炎；
   - 来自脊柱以外的**牵涉痛**：腹主动脉瘤、胰腺炎、肾脏疾病、消化性溃疡和妇科疾病。
:::

应引起对严重病变怀疑的特征传统上称为**红旗征**：

- **癌症**：癌症病史；不明原因的体重下降；50岁以上新发疼痛；持续性、进行性、夜间加重或休息不能缓解的疼痛；胸背痛。
- **感染**：发热；静脉注射毒品；免疫抑制（HIV、激素、化疗）；近期细菌感染或脊柱操作；糖尿病。
- **骨折**：明显外伤；长期使用糖皮质激素；已知骨质疏松症；高龄且在轻微用力后突然起病。
- **马尾综合征**：见[[#sec-ces]]。
- **神经功能缺损**：进行性或广泛性无力，或脊髓受累的体征（步态障碍、上运动神经元体征）。
- **全身性疾病**：感觉不适、炎症标志物升高、不明原因的贫血。

::: warning 红旗征不是核对清单
单个红旗征的**准确性很差**。许多红旗征（如50岁以上或夜间痛）在普通腰痛患者中也很常见，所以逐项打勾会产生大量假警报和不必要的扫描。另一些红旗征在严重疾病早期并不出现。脊柱恶性肿瘤最好的单一预测因素是**既往癌症病史**。红旗征最好用作促使思考的提示，并结合整体情况及其随时间的演变：新出现的神经体征、未按预期好转或全身情况恶化，都应促使重新评估。首次就诊正常并不能保证没有严重问题，因此患者需要得到何时复诊的明确建议。
:::

## 非特异性腰痛 {#sec-nslbp}

::: definition 非特异性腰痛 {#def-nslbp}
**非特异性腰痛**是指下位肋骨与臀沟之间的疼痛，伴或不伴放射至膝以上的腿部，且未发现特定病因（如感染、癌症、骨折、炎症性疾病或神经根受压）。按病程分为**急性**（不足6周）、**亚急性**（6至12周）和**慢性**（超过12周）。
:::

大多数急性发作在几周内明显好转，但复发常见，少数人会发展为持续的致残性疼痛。哪些人会这样，与其说取决于脊柱的样子，不如说取决于心理和社会因素。

::: theorem 疼痛不是损伤的量度 {#thm-pain-damage}
在腰背痛中，**疼痛和残疾的程度并不反映脊柱结构损伤的多少**。疼痛是神经系统对潜在威胁信号的反应，并受信念、情绪、注意力、睡眠、既往经历和社会环境的调节。影像学上的退行性改变在无痛者中很常见，与症状相关性差。
:::

::: proof
有三方面证据支持这一原理。第一，对**没有**腰痛者的影像学研究表明，随着年龄增长，“异常”是常态。一项关于无症状者MRI和CT的系统评价（Brinjikji及其同事，2015年）发现，椎间盘退变在20岁人群中占37%，到80岁升至96%；椎间盘膨出从30%升至84%。第二，最能预测哪些人会发展为持续致残性疼痛的不是影像学发现，而是**心理社会**因素：害怕活动会造成伤害、对疼痛的灾难化思维、情绪低落、对康复期望低，以及工作和赔偿问题（有时称为**黄旗征**）。第三，许多慢性疼痛患者已被证实存在**中枢敏化**，即脊髓和大脑中伤害性感受通路反应性增强，这解释了疼痛为何持续存在或扩散到组织损伤之外。所有这些人的疼痛都是真实的；薄弱的是疼痛与损伤之间的联系。
:::

NICE NG59规定了伴或不伴坐骨神经痛的腰痛的处理：

- **评估**：排除特定病因，并在每次复查时考虑其他诊断。首次接触时考虑用**STarT Back**问卷等工具进行**风险分层**，使照护与风险相匹配：对预后不良风险低的人提供较简单的支持（安慰、建议保持活动、自我管理），对风险较高的人提供更强化的支持（运动方案，伴或不伴手法治疗）。
- **影像学**：在非专科环境中**不常规提供**；在专科环境中，只有结果可能改变处理时才做。
- **自我管理**：提供关于腰痛的信息，鼓励**继续正常活动**。不建议卧床休息。
- **运动**：考虑集体运动方案（生物力学、有氧、身心或其组合）。
- **手法治疗**（推拿、松动术、按摩）只能作为包含运动的综合方案的一部分。
- **不提供**：腰带或护腰、足部矫形器、摇椅底鞋、牵引、针灸、超声、经皮神经电刺激、经皮电神经刺激（PENS）和干扰电疗法。
- **药物**：考虑**口服非甾体抗炎药**，需考虑胃肠道、肾和心血管风险，以最低有效剂量、最短时间使用，适当时加用胃保护药物。只有当非甾体抗炎药有禁忌、不耐受或无效时，才考虑对急性疼痛使用**弱阿片类药物**（加或不加对乙酰氨基酚）。**不提供单用对乙酰氨基酚**。**慢性腰痛不提供阿片类药物**。腰痛**不提供**抗抑郁药（SSRI、SNRI、三环类）以及**加巴喷丁类或其他抗癫痫药**。
- **有创治疗**：腰痛不提供脊柱注射。对经阳性诊断性内侧支阻滞、认为疼痛来自关节突关节的部分慢性疼痛患者，考虑**射频去神经术**。
- **工作**：促进并帮助患者重返工作和正常活动。

2026年7月，NICE在一次监测评审认为其可能已经过时后，撤回了此前关于心理治疗以及身体与心理联合方案的建议；对持续疼痛高风险者关注恐惧、情绪和期望的重要性毋庸置疑，但如何实施应遵循当地指南。

::: example 搬家工人的急性腰痛 {#ex-acute}
一名38岁男性两天前搬沙发时突然腰痛。疼痛横跨下背部并延伸到右臀部，弯腰时加重，静卧时缓解。他没有膝以下的腿痛、没有麻木、没有膀胱或肠道改变、没有发热，也没有癌症病史。体格检查发现椎旁肌痉挛、前屈受限，下肢神经系统检查正常。他要求做MRI“看看哪里坏了”，并要一个月的病假条。你将如何处理？
::: solution
这是**急性非特异性腰痛**：没有神经根病、马尾综合征或严重病变的特征。

**影像学检查**没有指征。解释原因很重要：MRI很可能显示他这个年龄的无痛者也常见的“退行性”改变，这可能会让他惊慌，却不会改变治疗（[[#thm-pain-damage]]）。

**解释与安慰**：大多数这样的发作在几周内会明显好转；腰背是强壮的；疼痛不等于损伤；轻柔的活动加快康复，而卧床休息则会延缓康复。

**保持活动并计划重返工作**：与其休息一个月，不如讨论调整工作内容，或短期休息并计划好返岗，因为长期休假本身就是慢性残疾的危险因素。STarT Back问卷可以判断他是否需要比简单建议更多的支持。

**镇痛**：如无禁忌，短期以最低有效剂量口服布洛芬等非甾体抗炎药。不推荐单用对乙酰氨基酚。热敷可能有帮助。

**安全网**：如果出现肛门或生殖器周围麻木、排尿或排便困难或失控，或新出现腿部无力，应紧急复诊；如果疼痛未按预期好转或出现新症状，也应复诊。
:::
:::

## 坐骨神经痛与神经根病 {#sec-sciatica}

::: definition 根性疼痛与神经根病 {#def-radiculopathy}
**根性疼痛（坐骨神经痛）**是从腰部或臀部放射到腿部（典型地到膝以下）、沿某一腰骶神经根分布的疼痛。它由神经根受刺激或压迫引起，最常见的原因是**椎间盘突出**，较少见的是退行性改变或椎体滑脱导致的椎间孔狭窄。**神经根病**是指同时有神经功能丧失：该神经根支配区的麻木、无力或反射减弱。

最常受累的神经根及其常见表现：

| 神经根 | 疼痛和感觉丧失 | 无力 | 反射 |
|---|---|---|---|
| L3 | 大腿前方至膝 | 伸膝、屈髋 | 膝反射可减弱 |
| L4 | 大腿前方至小腿内侧和踝 | 伸膝；踝背屈（胫前肌） | 膝反射减弱 |
| L5 | 小腿外侧至足背和大脚趾 | 伸大脚趾；踝背屈；髋外展 | 通常无可靠的反射 |
| S1 | 小腿后方至足底和足外侧缘 | 踝跖屈；足外翻 | 踝反射减弱 |

**直腿抬高试验**（在约30至70度之间抬高伸直的腿，诱发膝以下腿痛）检查L5和S1神经根；**股神经牵拉试验**（患者俯卧，屈膝时伸髋）检查L3和L4。
:::

椎间盘突出所致坐骨神经痛的自然病程良好。突出的椎间盘物质常通过炎症和巨噬细胞反应被吸收，大多数人在6至12周内无需手术即明显好转。

NICE NG59建议，坐骨神经痛**不提供加巴喷丁类、其他抗癫痫药、口服糖皮质激素和苯二氮䓬类药物**，因为总体上没有获益的证据，却有危害的证据；**慢性坐骨神经痛不提供阿片类药物**。可以使用非甾体抗炎药，但要了解其证据有限和风险。对急性重度坐骨神经痛，考虑**硬膜外注射**局部麻醉药和激素。当非手术治疗未能改善疼痛或功能，且影像学发现与症状一致时，考虑转诊进行**脊柱减压术**（如显微椎间盘切除术）。手术能更快缓解腿痛，但在许多试验中，一到两年时的结果与继续保守治疗大致相似。**进行性或严重的运动无力**（如新出现的足下垂）和**马尾综合征**需要紧急专科评估。

::: example 园艺劳动后的腿痛 {#ex-sciatica}
一名44岁女性两周来左臀部剧痛，沿小腿外侧放射到足背，比腰痛更重，足背有麻刺感。体格检查：左侧直腿抬高40度时诱发腿痛。左侧伸大脚趾和踝背屈轻度无力（5级中的4级）。膝反射和踝反射正常。左足背感觉减退。肛周感觉正常，无膀胱或肠道症状。受累的是哪条神经根？可能的病因是什么？计划是什么？
::: solution
这一表现符合**左侧L5神经根病**：小腿外侧和足背的疼痛及感觉改变、伸大脚趾和背屈无力、直腿抬高试验阳性，以及反射正常（L5没有可靠的反射）。可能的病因是**L4–L5后外侧椎间盘突出**压迫走行的L5神经根。

**没有马尾综合征的特征**：症状为单侧，鞍区感觉正常，括约肌功能正常。

**计划**：解释良好的自然病程；镇痛（如适合，谨慎使用非甾体抗炎药；按照NICE NG59，不用加巴喷丁类或口服激素）；尽可能保持活动；以及物理治疗。无进展的轻度无力可以观察，但应复查；如果无力**加重**（如发展为足下垂），需要紧急专科转诊和MRI。如果保守治疗后剧痛仍持续，做MRI并转诊考虑硬膜外注射或减压术是合适的。必须给她明确的**马尾综合征安全网**建议，尽可能以书面形式。
:::
:::

## 马尾综合征 {#sec-ces}

::: definition 马尾综合征 {#def-ces}
**马尾综合征（CES）**是脊髓圆锥以下的腰骶神经根受压，通常由巨大的**中央型椎间盘突出**引起，较少由肿瘤、感染、血肿或严重狭窄引起。它产生以下表现的某种组合：

- **双侧**坐骨神经痛（或单侧坐骨神经痛变为双侧）；
- **鞍区麻木**：会阴、臀部和大腿内侧感觉减退或改变；
- **膀胱功能障碍**：膀胱充盈感改变、排尿踌躇、尿流细弱，然后是无痛性**尿潴留**伴充溢性尿失禁；
- **肠道功能障碍**：感觉改变、失控；
- **性功能障碍**：生殖器感觉丧失、勃起或射精功能障碍；
- 肛门张力降低（晚期体征）。

可分为**疑似**（CES-S：有症状但无客观缺损）、**不完全**（CES-I：膀胱感觉改变、排尿欲丧失或尿流细弱，但仍能自主控制）和伴**尿潴留**（CES-R：无痛性尿潴留和充溢性尿失禁）。在出现尿潴留之前手术，结局要好得多。

:::

由于结局取决于时机，而早期症状又很隐匿，疑似CES需要**急诊MRI**。在英格兰，“一次做对”（GIRFT）项目2023年发布的全国疑似马尾综合征路径要求，无论白天黑夜，在申请后尽快、最迟四小时内完成MRI；如果证实受压，立即转诊脊柱外科团队进行紧急减压。

::: warning 不要等到尿潴留
行动的时机是在膀胱功能衰竭**之前**。除非被直接问到，患者往往意识不到膀胱或鞍区感觉的细微变化。每个腰痛或坐骨神经痛患者都应被专门询问鞍区麻木、膀胱和肠道功能以及性功能，并得到明确的书面建议：一旦这些发生变化就寻求急诊救治。膀胱扫描测量排尿后残余尿量可以辅助评估，但结果正常不能排除早期CES。出现无痛性尿潴留时，取得最佳结局的时间窗往往已经错过。
:::

::: example 腰痛伴"下面"麻木 {#ex-ces}
一名39岁男性有三年间歇性腰痛史，两天来双腿剧痛。从今天早晨起，他注意到便后擦拭时有麻木感，开始排尿困难。体格检查发现肛周针刺觉减退，双侧踝反射减弱。排尿后膀胱扫描显示残余尿350 mL。诊断是什么？现在必须做什么？
::: solution
这是**马尾综合征**，至少是**不完全型（CES-I）**，并可能有早期尿潴留：双侧坐骨神经痛、**鞍区麻木**、**排尿踌躇**伴大量**排尿后残余尿**，以及双侧S1反射消失。可能的病因是巨大的中央型椎间盘突出，可能在L4–L5或L5–S1。

行动：

1. 腰椎**急诊MRI**，按全国路径尽快并在四小时内完成，不论何时。
2. **立即转诊值班脊柱外科团队**；如果MRI证实受压，紧急行**手术减压**（椎间盘切除术）。
3. 镇痛；如有尿潴留则导尿；仔细记录肛周感觉、肛门张力、下肢神经系统和膀胱检查结果，并注明时间。

延误会降低膀胱、肠道和性功能恢复的机会。马尾综合征也引发了许多医疗法律索赔，几乎都与识别、影像学检查或手术的延误有关。
:::
:::

## 椎管狭窄 {#sec-stenosis}

**腰椎管狭窄**是椎管或侧隐窝及椎间孔的狭窄，通常由退行性改变引起：椎间盘膨出、关节突关节肥大和黄韧带增厚，有时伴退行性椎体滑脱。典型见于60岁以上者，引起**神经源性跛行**：站立和行走时出现臀部和腿部疼痛、沉重、麻木或无力，**坐下或向前弯腰可缓解**。前屈使椎管扩大，这解释了为什么患者骑自行车或扶着购物车行走的距离常比直立行走远得多。

| 特征 | 神经源性跛行（椎管狭窄） | 血管性跛行（外周动脉病） |
|---|---|---|
| 诱因 | 站立和行走；下坡行走 | 行走，尤其是上坡；站立不诱发 |
| 缓解方式 | 坐下或向前弯腰，需数分钟 | 停下站立不动，一两分钟内 |
| 骑自行车 | 通常可以耐受 | 也引起疼痛 |
| 脉搏 | 正常 | 减弱或消失；踝肱压力指数低 |
| 皮肤 | 正常 | 可有慢性缺血的征象 |

处理从运动（常以前屈为主）、镇痛和调整活动开始。当保守治疗后症状仍严重限制行走和生活质量时，考虑减压手术，并用MRI明确解剖。这两种疾病在老年人中常并存，因此要检查脉搏和踝肱压力指数（[[cardiovascular/vascular-disease]]）。

## 严重的特定病因 {#sec-serious}

**转移性脊髓压迫（MSCC）**是肿瘤急症，可能是癌症的首发表现。警示特征包括胸背痛或进行性背痛、躺下或咳嗽时加重的疼痛、环绕胸部的带状根性疼痛，随后出现肢体无力、感觉平面、步态障碍和括约肌问题。NICE NG234（2023年）要求医疗服务对疑似MSCC且有神经症状或体征者在24小时内提供MRI，并建议对有神经症状或体征者尽快口服地塞米松，随后以手术或放疗进行确定性治疗。结局取决于治疗时的行走能力。

::: example 前列腺癌男性的背痛 {#ex-mscc}
一名72岁男性两年前治疗过前列腺癌，三周来背中部疼痛。疼痛持续存在，平躺和咳嗽时加重，现在像一条带子一样向胸部扩散。从昨天起他双腿感觉沉重，绊倒了两次。体格检查发现T8处压痛，双腿轻度无力，膝反射活跃，脐以下针刺觉减退。可能的诊断是什么？现在应该做什么？
::: solution
可能的诊断是约T8–T10水平的**转移性脊髓压迫**：有常转移到骨的癌症病史，躺下和咳嗽时加重的胸背痛，带状根性疼痛，以及新出现的**上运动神经元**体征和感觉平面。这是肿瘤急症。

按照NICE NG234和当地MSCC路径采取行动：

1. **立即联系MSCC协调员或急症肿瘤团队**。
2. 在24小时内（如需尽早开始治疗则更早）**紧急行全脊柱MRI**，因为转移常不止一个节段。
3. 对有神经症状或体征者尽快给予**地塞米松**，同时进行胃保护和血糖监测。
4. **镇痛**，在影像结果复核前就体位和脊柱稳定性给出建议。
5. 由多学科团队迅速决定**确定性治疗**：根据他的整体情况和脊柱稳定性，选择手术减压和稳定，或放疗。

速度之所以重要，是因为开始治疗时仍能行走的人，治疗后继续行走的可能性要大得多。如果在他只有持续胸背痛和癌症病史时就能识别出来，会更好。
:::
:::

**脊柱感染**（椎间盘炎、椎体骨髓炎、硬膜外脓肿）在注射毒品、糖尿病、免疫抑制或近期有菌血症或脊柱操作的人中引起进行性、持续性疼痛伴局部压痛，常伴发热。炎症标志物通常升高；MRI是关键检查，血培养和常常需要的活检可确定病原体（最常见的是*金黄色葡萄球菌*；在流行地区或高危人群中是结核）。硬膜外脓肿可迅速导致瘫痪。

**骨质疏松性椎体骨折**使老年人突然出现剧烈的胸背或腰痛，有时发生在轻微用力后，常伴身高下降和驼背。许多椎体骨折未被诊断。每一次都是脆性骨折，应促使进行骨质疏松症评估（[[musculoskeletal/bones-joints]]）。

**中轴型脊柱关节炎**在年轻成人中引起炎症性腰背痛，在[[musculoskeletal/inflammatory-arthritis]]中描述。

::: quiz
一名73岁男性步行约200米后双侧臀部和大腿疼痛。他必须坐下几分钟才能缓解，推着超市购物车能走得更远。足背动脉搏动容易触及。最可能的原因是什么？
- [ ] 外周动脉病
- [x] 腰椎管狭窄
- [ ] 急性L5椎间盘突出
- [ ] 马尾综合征
::: solution
行走诱发、坐下或前屈缓解的疼痛（“购物车征”），且脉搏正常，是腰椎管狭窄所致**神经源性跛行**的典型表现。血管性跛行站立不动即可迅速缓解，脉搏通常减弱。急性椎间盘突出引起的根性疼痛与行走距离没有特定关系，马尾综合征则有鞍区和括约肌障碍。
:::
:::

## 颈痛 {#sec-neck}

大多数颈痛是非特异性的，处理原则与腰痛相同：解释、保持活动、运动和短期镇痛。道路交通事故后的**挥鞭样损伤相关疾病**通常在数周内好转；急性期只对符合经过验证的可能骨折标准（如加拿大颈椎规则）的人进行影像学检查。

**颈神经根病**引起沿神经根分布的上肢痛：C5（肩部和上臂外侧；三角肌无力；肱二头肌反射）、C6（前臂外侧和拇指；屈肘和伸腕；肱二头肌和肱桡肌反射）、C7（中指；肱三头肌和屈腕；肱三头肌反射）、C8（小指和前臂内侧；屈指和手内在肌）。

**退行性颈脊髓病**是颈段脊髓受压，通常由老年人的退行性改变引起。由于它发展缓慢，很容易漏诊。表现包括双手笨拙、麻木（扣纽扣和写字困难）、步态不稳，体格检查有**上运动神经元体征**：反射亢进、Hoffmann征阳性、病理征阳性（跖反射伸性）和阵挛。它需要MRI并转诊脊柱外科医师，因为减压能阻止进展，却很少能逆转已形成的缺损。**类风湿关节炎**患者可发生寰枢关节半脱位，后果类似。

::: history
在19世纪的大部分时间里，人们认为坐骨神经痛是坐骨神经本身的炎症。直腿抬高试验与法国医师**夏尔·拉塞格（Charles Lasègue）**联系在一起；他1864年关于坐骨神经痛的论文启发了这一体征，后来由他的学生**J. J. 福斯特（J. J. Forst）**详细描述。1934年，波士顿的**威廉·米克斯特（William Mixter）**和**约瑟夫·巴尔（Joseph Barr）**在《新英格兰医学杂志》上证明，椎间盘破裂压迫神经根，可通过手术解除，开启了被称为“椎间盘王朝”的时代。1987年，苏格兰骨科医师**戈登·沃德尔（Gordon Waddell）**提出腰痛的生物-心理-社会模式，指出腰痛所致残疾的增加无法用脊柱病理的任何变化来解释。2011年，基尔大学的**乔纳森·希尔（Jonathan Hill）**、**纳丁·福斯特（Nadine Foster）**及其同事在《柳叶刀》发表随机试验，证明用STarT Back工具对患者分层并使治疗与风险相匹配，可以改善残疾结局并降低费用。
:::

## 后续内容

神经根、脊髓和疼痛的神经病学在[[nervous-system/motor-systems]]和[[nervous-system/headache-pain]]中展开。脊柱转移性疾病与[[pathology/cancer-diagnosis]]及骨转移的肿瘤学相关；脊柱感染与[[infectious-diseases/fever-sepsis]]和[[infectious-diseases/tuberculosis]]相关。脊柱手术见[[surgery/orthopaedics]]，血管性跛行见[[cardiovascular/vascular-disease]]，医学上无法解释的疼痛和慢性疼痛见[[psychiatry/anxiety-disorders]]。

::: summary
- 把腰背痛分诊为非特异性疼痛（大多数）、根性疼痛以及特定或严重病变（约1%–2%）：马尾综合征、癌症、感染、骨折、炎症性疾病和牵涉痛。
- 红旗征是促使思考的提示，而不是自动做影像学检查的指令；癌症病史的信息量最大。病程不符合预期时要重新评估。
- 疼痛不是损伤的量度：退行性影像学表现在无痛者中很常见，心理社会因素比影像更能预测慢性残疾。
- NICE NG59：非专科环境不常规做影像学检查；建议保持活动；运动方案；如适合可用非甾体抗炎药；不单用对乙酰氨基酚；慢性腰痛不用阿片类药物；腰痛不用抗抑郁药或加巴喷丁类；坐骨神经痛不用加巴喷丁类、口服激素或苯二氮䓬类。
- 椎间盘突出所致的大多数坐骨神经痛在6–12周内好转。L4–L5后外侧突出压迫L5；L5–S1突出压迫S1。要熟记神经根表。
- 马尾综合征（双侧坐骨神经痛、鞍区麻木、膀胱、肠道或性功能障碍）需要急诊MRI（按全国路径在四小时内）和紧急减压。不要等到尿潴留；给每个人提供安全网建议。
- 椎管狭窄所致的神经源性跛行坐下或前屈可缓解，脉搏正常。
- 转移性脊髓压迫、脊柱感染和椎体骨折是主要的严重特定病因。颈部要注意脊髓病：双手笨拙、步态障碍和上运动神经元体征。
:::

## 习题

::: exercise 哪条神经根？ {level=1}
一处椎间盘突出导致踝跖屈无力、足外侧缘感觉丧失和踝反射消失。受累的是哪条神经根？后外侧突出最可能在哪个椎间盘节段？
::: solution
**S1**神经根。压迫走行S1神经根的后外侧突出通常位于**L5–S1**椎间盘。
:::
:::

::: exercise 属于哪一组？ {level=1}
把每个人归入非特异性腰痛、根性疼痛或可能的严重病变：(a) 30岁，搬重物后腰痛，无腿部症状，体格检查正常；(b) 67岁，有乳腺癌病史，新发持续性胸背痛，夜间加重；(c) 45岁，疼痛从臀部沿小腿后方放射到足底，直腿抬高试验阳性，踝反射减弱。
::: solution
(a) **非特异性**腰痛。(b) **可能的严重病变**：鉴于癌症病史、胸背痛和持续性夜间痛，可能是脊柱转移瘤；她需要紧急检查，如有任何神经症状，需评估转移性脊髓压迫。(c) **根性疼痛**，S1神经根病。
:::
:::

::: exercise NICE的建议 {level=1}
说明NICE NG59对腰痛或坐骨神经痛是否推荐以下各项：(a) 腰痛单用对乙酰氨基酚；(b) 集体运动方案；(c) 坐骨神经痛用加巴喷丁；(d) 全科常规拍腰椎X线片；(e) 腰痛口服非甾体抗炎药。
::: solution
(a) **否**，不提供单用对乙酰氨基酚。(b) **是**，考虑集体运动方案。(c) **否**，坐骨神经痛（及腰痛）不提供加巴喷丁类。(d) **否**，非专科环境不常规提供影像学检查。(e) **是**，考虑口服非甾体抗炎药，以最低有效剂量、最短时间使用，并考虑危险因素。
:::
:::

::: exercise 神经源性还是血管性？ {level=2}
一名69岁吸烟的糖尿病男性描述，上坡走100米后小腿疼痛，站立不动一分钟内缓解。他能长时间站立而无不适，骑自行车也会引起小腿疼痛。这是哪种跛行？哪项体格检查和哪项检查可以支持这一判断？
::: solution
这是外周动脉病所致的**血管性跛行**：行走时疼痛（上坡加重），站立不动一两分钟内缓解，骑车时疼痛，站立无问题。他有主要危险因素（吸烟、糖尿病）。体格检查寻找**足部脉搏减弱或消失**、慢性缺血的征象和血管杂音；关键检查是**踝肱压力指数**。处理包括降低心血管风险和有监督的运动（[[cardiovascular/vascular-disease]]）。
:::
:::

::: exercise 癌症的验后概率 {level=2 check="round(100*(0.007/0.993*15)/(1+0.007/0.993*15))"}
为便于说明，假设在初级医疗中因腰痛就诊的人有0.7%患脊柱恶性肿瘤，而既往癌症病史的阳性似然比为15。计算一个有腰痛和既往癌症病史的人患脊柱恶性肿瘤的概率，以百分数表示并四舍五入到整数。
::: hint
把验前概率换算为比值，乘以似然比，再换算回概率。
:::
::: solution
验前比值$= 0.007/0.993 \approx 0.00705$。验后比值$= 0.00705 \times 15 \approx 0.1057$。概率$= 0.1057/1.1057 \approx 0.096$，即约**10%**。癌症病史把一个可能性极小的诊断变成必须检查的现实可能，但即便如此，这类人中的大多数并没有脊柱转移。这就是为什么红旗征用于指导进一步评估，而不是自动确诊疾病。
:::
:::

::: exercise 笨拙的钢琴手 {level=2}
一名64岁退休音乐教师一年来弹钢琴和扣纽扣困难，在黑暗中行走时感到不稳。她的颈部僵硬但不太痛。体格检查发现四肢反射活跃、Hoffmann征阳性和跖反射伸性。可能的诊断是什么？为什么不能把她的症状归因于手部关节炎？
::: solution
可能的诊断是**退行性颈脊髓病**：颈段脊髓受压，引起双手笨拙麻木、步态不稳（因本体感觉受损而在黑暗中加重），以及上下肢的**上运动神经元体征**。把手部症状归因于关节炎或腕管综合征是延误的常见原因。由于这种疾病是进行性的，而减压主要是防止进一步恶化而不是逆转已形成的缺损，她需要**颈椎MRI**并**转诊脊柱外科医师**。在评估之前，应建议她避免颈部外伤风险高的活动。
:::
:::

::: exercise 发热的腰背 {level=3}
一名46岁注射海洛因的男性，三周来持续性下腰痛逐渐加重，令他无法入睡。今天他感到双腿无力。体温38.4 °C。L3处明显压痛。双腿肌力5级中的4级。CRP 186 mg/L。(a) 最可能的诊断是什么？(b) 需要做哪些检查？有多紧急？(c) 最可能的病原体是什么？
::: hint
考虑注射毒品、发热、局灶性压痛和新出现的神经功能缺损这一组合。
:::
::: solution
(a) **脊柱感染**：椎体骨髓炎或椎间盘炎伴**硬膜外脓肿**，注射毒品（菌血症）、发热、持续进行性疼痛、局灶性压痛、CRP很高和新出现的双腿无力都提示这一诊断。

(b) 今天就做**全脊柱增强急诊MRI**，因为伴神经功能缺损的硬膜外脓肿可在数小时内进展为瘫痪。如不延误治疗，在使用抗生素前做**血培养**（多套）；血常规、肾功能、HIV和肝炎血清学；**超声心动图**寻找心内膜炎。紧急转诊脊柱外科团队进行减压和引流。如血培养阴性，做椎间盘或骨活检。

(c) ***金黄色葡萄球菌***（在某些环境中包括MRSA）是最常见的病原体。经验性静脉抗生素遵循当地指南，并根据培养结果进行较长疗程的治疗。
:::

::: exercise 为什么变成了慢性？ {level=3}
一名41岁仓库工人14个月前搬重物时伤了腰，此后一直没有工作。他相信自己的脊柱正在“崩解”，因为MRI报告写着“多节段退行性椎间盘病”。他每天服用可待因和普瑞巴林，睡眠差，很少出门，正与雇主发生纠纷。神经系统检查正常。(a) 找出维持他残疾状态的因素。(b) NICE建议腰痛不使用他的哪些药物？为什么？(c) 概述处理方法。
::: hint
寻找信念、行为、情绪、药物和社会因素，并运用[[#thm-pain-damage]]。
:::
::: solution
(a) **维持因素**：对正常的年龄相关MRI表现作了令人恐惧的解读（“脊柱崩解”）；害怕活动并回避活动，导致体能下降；长期缺勤和劳动纠纷；睡眠差，很可能情绪低落；以及依赖不太可能有帮助的药物。这些是“黄旗征”：持续残疾的心理社会预测因素。

(b) NICE NG59建议**慢性腰痛不用阿片类药物**（可待因），因为缺乏获益的证据，而依赖和伤害的风险很大；并建议腰痛**不用加巴喷丁类**（普瑞巴林），因为没有获益且有伤害的证据，包括依赖和滥用。任何减量都必须有计划地逐步进行，并作出解释，遵循NICE关于可致依赖或戒断症状药物的指南。

(c) **处理**：诚实地重新解释他的MRI发现（椎间盘改变在无痛者中很常见，并不意味着他的脊柱在崩解）；商定以功能为重点的目标；循序渐进的**运动方案**，最好是集体进行；处理睡眠和情绪问题（筛查抑郁，如有则治疗）；有计划地逐步减少可待因和普瑞巴林；提供**职业支持**，在职业健康部门参与下计划分阶段重返工作。如有条件，同时处理身体、心理和工作因素的多学科疼痛或康复服务是合适的。目标是功能和参与，而不是疼痛评分降为零。
:::
