皮肤癌是浅肤色人群中最常见的癌症，其发病率几十年来持续上升。大多数皮肤癌是**角质形成细胞癌**，即基底细胞癌和皮肤鳞状细胞癌，它们极为常见，通常可以治愈，很少致命。由黑素细胞发生的**黑色素瘤**少见得多，却造成了大多数皮肤癌死亡；在英国，它是最常见的五种癌症之一。三者都与紫外线辐射密切相关，这使皮肤癌成为最可预防的癌症之一；三者都长在皮肤表面看得见的地方，这使得仅凭仔细观察就有可能早期发现。

本章讲述紫外线如何致癌、癌前病变和角质形成细胞癌、黑色素瘤的识别、分期和治疗（包括现代靶向治疗和免疫治疗），以及预防。本章以[[musculoskeletal/skin]]中的皮肤结构和[[pathology/cancer-diagnosis]]中癌症诊断与分期的一般原则为基础。

## 紫外线与皮肤癌 {#sec-uv}

到达地面的阳光含有两个具有重要生物学意义的紫外线波段。**UVB**（波长约280–315 nm）大部分被表皮吸收；它引起晒伤并直接损伤DNA。**UVA**（约315–400 nm）含量更多，可穿透到真皮，引起晒黑和光老化，并通过活性氧间接损伤DNA。两者都促成皮肤癌，日光浴床也同时发出两者。

::: theorem 紫外线印记 {#thm-uv}
UVB被DNA中相邻的嘧啶碱基吸收并使其相连，形成**环丁烷嘧啶二聚体**及相关损伤。如果在细胞分裂前未被修复，它们会产生一种特征性的突变模式，主要是**两个相邻嘧啶位点上的C→T置换**（包括CC→TT改变）。这种“紫外线印记”在来自曝光皮肤的大多数基底细胞癌、鳞状细胞癌和黑色素瘤的基因组中大量存在，直接把这些癌症与阳光联系起来。
:::

::: proof
细胞通常通过**核苷酸切除修复**清除嘧啶二聚体。有两项观察表明未修复的紫外线损伤会导致皮肤癌。第一，**着色性干皮病**（一种遗传性核苷酸切除修复缺陷）患者在很小的年龄就在曝光皮肤上发生皮肤癌，发病率是常人的许多倍。第二，皮肤癌测序显示有数千个带紫外线印记的突变，累及关键基因：鳞状细胞癌中的***TP53***（带紫外线印记的*TP53*突变在受日光损伤的正常皮肤和光线性角化病中已经存在）、基底细胞癌中刺猬（hedgehog）通路的***PTCH1***，以及黑色素瘤中***BRAF***和***NRAS***等生长信号基因。黑素通过吸收紫外线和清除自由基起保护作用，这就是易晒伤的浅肤色风险最高的原因。手掌、足底和甲床的黑色素瘤是深肤色人群中最常见的类型，它们带紫外线印记的突变很少，与病因不同相符。
:::

暴露模式很重要。**鳞状细胞癌**与一生的**累积**暴露相关：发生在老年人和户外工作者长期曝光的部位（面部、耳、头皮、手背）。**黑色素瘤**和**基底细胞癌**与**间歇性强烈**暴露和**晒伤**（尤其是儿童期）的关系更密切：比如度假时晒伤的办公室职员。

::: definition 皮肤癌的危险因素 {#def-risk}
- **皮肤类型**：易晒伤、不易晒黑的浅肤色（Fitzpatrick Ⅰ型和Ⅱ型），红发或浅色头发（常与黑皮质素1受体基因*MC1R*的变异相关），浅色眼睛和雀斑。
- **紫外线暴露**：晒伤（尤其是儿童期）、户外工作、居住在赤道附近，以及**使用日光浴床**。
- **痣**：大量普通痣（约100个以上）或多个不典型（发育不良）痣会增加黑色素瘤风险。
- 皮肤癌的**个人史或家族史**；在一些家族中，家族性黑色素瘤与*CDKN2A*变异相关。
- **免疫抑制**：器官移植受者鳞状细胞癌风险增加许多倍，且可能具有侵袭性；HIV和某些药物也增加风险。
- **其他**：高龄；着色性干皮病和其他遗传综合征；电离辐射；砷；人乳头瘤病毒（与部分鳞状细胞癌相关）；慢性伤口和瘢痕（慢性溃疡中发生的鳞状细胞癌称为Marjolin溃疡）。
:::

紫外线剂量用**紫外线指数（UVI）**衡量，每一个单位对应0.025 W/m²的红斑加权辐照度。UVI达到3或以上通常是建议防晒的阈值；在英国，夏季正午的数值常达到6至8。恰好使皮肤发红的剂量称为**最小红斑量（MED）**，它随皮肤类型而不同。把两者结合起来就得出晒伤所需时间：在UVI为$u$时，每分钟的有效剂量是$0.025 u \times 60 = 1.5u$ J/m²，所以

$$t_{\text{burn}} \approx \frac{\text{MED}}{1.5\,u} \text{ 分钟},$$ {#eq-burn}

其中MED以红斑加权的J/m²为单位。

## 癌前病变与角质形成细胞癌 {#sec-keratinocyte}

::: definition 角质形成细胞癌前病变与癌 {#def-keratinocyte}
**光线性（日光性）角化病**：长期受日光损伤皮肤上的粗糙、鳞屑性、粉红色或肤色斑片，常常摸起来比看起来更明显。它们标志着累积紫外线暴露量大。每一处进展为鳞状细胞癌的风险都很小，许多会自行消退。有症状或数量多时进行治疗，可用外用**氟尿嘧啶**、**咪喹莫特**或双氯芬酸凝胶、**冷冻治疗**或**光动力疗法**。

**鲍恩病（原位鳞状细胞癌）**：缓慢扩大、边界清楚的红色鳞屑性斑块，常见于老年女性的小腿。它可以进展为浸润性癌，可用外用药物、冷冻治疗、光动力疗法、刮除术或切除治疗。

**基底细胞癌（BCC）**：白种人中最常见的癌症，起源于基底层角质形成细胞。它生长缓慢，侵袭和破坏局部组织，**极少转移**。类型：

- **结节型**：珍珠样、半透明的丘疹或结节，边缘卷起，有细小的**毛细血管扩张**，常有中央溃疡（“侵蚀性溃疡”），典型见于面部；
- **浅表型**：粉红色、有鳞屑、缓慢生长的斑片，边缘呈细线状，常见于躯干；
- **硬斑病样（浸润型）**：苍白、瘢痕样、边界不清的斑块，实际范围比看上去更广，更容易复发。

**皮肤鳞状细胞癌（cSCC）**：角质形成细胞的恶性肿瘤，表现为日光损伤皮肤上的角化性（结痂、脱屑）或溃疡性结节，在数周至数月内长大，常有压痛。与BCC不同，它可以**转移**，通常首先转移到区域淋巴结。高危特征包括直径超过2 cm、侵犯超出皮下脂肪、低分化、神经周围浸润、位于耳或唇、复发以及免疫抑制。**角化棘皮瘤**是快速生长的圆顶状结节，中央有角质栓；由于临床上可能无法与cSCC区分，按cSCC处理。
:::

在英国，NICE NG12建议对怀疑**cSCC**的皮损按**疑似癌症路径**转诊。对疑似**BCC**通常**常规**转诊；只有当担心因皮损部位或大小而延误会造成重大影响时，才使用疑似癌症路径。部分低风险BCC由经过适当培训的人员在初级医疗中处理。

角质形成细胞癌的治疗以手术为主。**低风险BCC**通常以约4 mm的临床切缘切除，高风险BCC切缘更宽（约5 mm或以上）。低风险cSCC以约4 mm切缘切除，高风险cSCC以6 mm或以上切缘切除（英国皮肤科医师协会指南）。**Mohs显微描记手术**由外科医师分薄层切除肿瘤，在缝合前于显微镜下检查全部切缘，在保留组织的同时治愈率最高，用于面部高危肿瘤、复发肿瘤和硬斑病样BCC。浅表型BCC可用外用咪喹莫特或氟尿嘧啶、光动力疗法或刮除术治疗。不适合手术者可选择**放疗**。对罕见的局部晚期或转移性肿瘤，系统治疗包括BCC用**刺猬通路抑制剂**（维莫德吉、索尼德吉），cSCC用**PD-1抑制剂西米普利单抗**。

::: example 鼻部珍珠样结节 {#ex-bcc}
一名71岁退休农民鼻侧有一处缓慢生长的皮损已18个月。它是一个7 mm的珍珠样、半透明结节，边缘卷起，表面有细小分支状血管，中央有小痂，洗脸时出血。他的头皮和手背有许多粗糙的鳞屑性斑片。最可能的诊断是什么？其他皮损提示什么？如何处理？
::: solution
最可能的诊断是**结节型基底细胞癌**：珍珠样、半透明结节，边缘卷起，有树枝状毛细血管扩张和中央溃疡，在一位户外暴露多的老年男性面部于数月间缓慢生长。

粗糙的鳞屑性斑片可能是**光线性角化病**，是累积紫外线暴露量大的标志。它们有小的鳞状细胞癌风险，并提示他需要定期检查皮肤以发现更多的皮肤癌。

**处理**：转诊皮肤科。鼻部是BCC的高危部位（面中部的“H区”，肿瘤更易复发，组织也很珍贵），因此常首选**Mohs显微描记手术**而非标准切除，以最少的组织损失和最低的复发率切除肿瘤。不适合手术时可选放疗。预后极好，因为BCC极少转移。光线性角化病可用区域治疗（如外用氟尿嘧啶）。应向他提供防晒建议，并请他报告任何新发或变化的皮损。
:::
:::

## 黑色素瘤 {#sec-melanoma}

::: definition 黑色素瘤 {#def-melanoma}
**黑色素瘤**是黑素细胞的恶性肿瘤。大多数发生于正常皮肤，少数发生于原有的痣。它通常先沿表皮生长（**水平生长期**），然后侵入真皮（**垂直生长期**），此时获得向淋巴结和远处器官扩散的能力。主要临床类型有：

- **浅表扩散型黑色素瘤**：白种人中最常见的类型，形状不规则、颜色多样的扁平或略隆起皮损，在数月内扩大，男性常见于背部，女性常见于腿部。
- **结节型黑色素瘤**：快速生长的结节，常呈均匀深色，有时为红色或肤色（**无色素性**），可出血。它很早进入垂直生长期，因此诊断时常已较厚。它可能不符合ABCD规则；警示征象是**隆起、质硬、不断长大**（EFG）。
- **恶性雀斑样痣黑色素瘤**：发生于**恶性雀斑样痣**（长期日光损伤皮肤中的原位黑色素瘤，通常在老年人面部），在侵袭前可缓慢生长多年。
- **肢端雀斑样痣黑色素瘤**：位于**手掌、足底和甲下**。它是深肤色人群中最常见的类型，与紫外线暴露关系不大，常诊断较晚。**甲下黑色素瘤**表现为甲上逐渐增宽的纵行色素带；色素延伸到甲襞（**Hutchinson征**）是警示征象。
- **黏膜**黑色素瘤（口、鼻、生殖器、肛门）和**葡萄膜**黑色素瘤（眼内）较少见，行为也不同。
:::

### 识别黑色素瘤

有两种广泛讲授的辅助方法。**ABCDE**规则列出可疑色素性皮损的特征：不对称（**A**symmetry）、边缘不规则（**B**order irregularity）、颜色不均（**C**olour variation）、直径大于6 mm（**D**iameter）和演变（**E**volution，大小、形状、颜色或症状的变化）。演变最重要。**“丑小鸭”征**提醒人们注意一个与患者其他痣看起来不同的痣。

在英国，NICE NG12推荐在初级医疗中用**加权7点检查表**评估色素性皮损：

| 特征 | 分值 |
|---|---|
| **主要**：大小改变 | 2 |
| **主要**：形状不规则 | 2 |
| **主要**：颜色不规则 | 2 |
| **次要**：最大直径7 mm或以上 | 1 |
| **次要**：炎症 | 1 |
| **次要**：渗液 | 1 |
| **次要**：感觉改变 | 1 |

得分**3分或以上**，或因其他原因有强烈临床担忧（如提示结节型黑色素瘤的皮损），应按**疑似癌症路径**转诊；皮肤镜下有黑色素瘤特征的色素性皮损也是如此。

**皮肤镜**（使用能消除表面反光的手持放大镜）可显示表面下的色素模式和血管，在训练有素者手中能提高诊断准确性。对有许多不典型痣的人，皮损的数码摄影有助于发现随时间的变化。

::: example 一个变化的痣 {#ex-mole}
一名38岁女性注意到小腿上的一个痣在四个月内长大了。它直径8 mm，轮廓不规则，含有两种深浅的褐色和一块黑色。无炎症、无渗液、不痒。用加权7点检查表评分，并决定如何处理。
::: solution
- 大小改变：**2**（主要）。
- 形状不规则：**2**（主要）。
- 颜色不规则：**2**（主要）。
- 最大直径7 mm或以上：**1**（次要）。
- 炎症、渗液、感觉改变：**0**。

总分$= 2 + 2 + 2 + 1 = 7$，远高于3分的阈值。她应按**疑似癌症路径**转诊到皮肤科或皮肤癌服务。在初级医疗中**不应**用削除或部分活检的方法去除该皮损，因为病理医师需要完整的皮损来测量其厚度。在专科通常以窄临床切缘（一般约2 mm）连同一圈脂肪进行**切除活检**，以便测量全层深度。
:::
:::

### 分期与预后

没有扩散的原发性黑色素瘤最重要的单一预后因素是**Breslow厚度**：从表皮颗粒层顶部（或溃疡基底）到最深浸润肿瘤细胞的深度，以毫米计。原发灶**溃疡**是第二重要的特征。两者共同决定国际通用的美国癌症联合委员会（AJCC）分期系统第8版的**T分类**：

| T分类 | Breslow厚度 | a | b |
|---|---|---|---|
| Tis | 原位（无浸润） | | |
| T1 | 1.0 mm或以下 | 小于0.8 mm且无溃疡 | 小于0.8 mm伴溃疡，或0.8–1.0 mm |
| T2 | 大于1.0至2.0 mm | 无溃疡 | 有溃疡 |
| T3 | 大于2.0至4.0 mm | 无溃疡 | 有溃疡 |
| T4 | 大于4.0 mm | 无溃疡 | 有溃疡 |

总分期再把T与**N**（区域淋巴结，以及原发灶与淋巴结之间皮肤的移行转移或卫星转移）和**M**（远处转移）结合起来。大体上，0期是原位黑色素瘤；**Ⅰ期和Ⅱ期**是局限性疾病（Ⅱ期是较厚或有溃疡的肿瘤）；**Ⅲ期**是区域扩散到淋巴结或移行转移部位；**Ⅳ期**是远处转移，最常转移到肺、肝、脑、骨或远处皮肤。血乳酸脱氢酶（LDH）为Ⅳ期提供额外的预后信息。

生存率随分期下降，但Ⅲ期内部差异很大。在AJCC第8版数据中，ⅢA期的5年黑色素瘤特异性生存率约为93%，而ⅢD期只有约32%。这些数字早于辅助治疗的广泛应用。

**前哨淋巴结活检（SLNB）**通过在原发部位注射放射性示踪剂和染料，找到引流肿瘤的第一个淋巴结，并将其切除做详细检查。它提供准确的分期和预后信息。NICE NG14（2022年更新）建议对ⅠA期黑色素瘤**不**提供SLNB（或分期影像学检查）；对Breslow厚度0.8至1.0 mm且有溃疡、淋巴血管浸润或核分裂率每平方毫米2个或以上的黑色素瘤考虑SLNB；对所有厚度超过1.0 mm的黑色素瘤考虑SLNB。前哨淋巴结阳性后，通常不再切除所有其余淋巴结（完全淋巴结清扫），因为试验显示没有生存获益；而是用超声监测，并考虑辅助治疗。

### 治疗

**手术**是原发性黑色素瘤的主要治疗。在诊断性切除活检之后，**扩大局部切除**在瘢痕周围切除一圈正常皮肤以减少局部复发。NICE NG14建议0期（原位）黑色素瘤的临床切缘至少**0.5 cm**，Ⅰ期为**1 cm**，Ⅱ期为**2 cm**（如2 cm会造成不可接受的毁容或损害，则为1 cm）。

两项发现改变了晚期黑色素瘤的治疗；在2011年之前，没有任何疗法能延长其生存。

::: definition 黑色素瘤的系统治疗 {#def-systemic}
**靶向治疗**：约一半皮肤黑色素瘤携带激活性**BRAF V600**突变，它开启MAPK生长信号通路。**BRAF抑制剂**与**MEK抑制剂**联合（达拉非尼加曲美替尼，或康奈非尼加比美替尼）在大多数BRAF突变患者中产生快速缓解，但常出现耐药。因此对晚期和高危黑色素瘤进行BRAF检测：NICE NG14建议对ⅡB至Ⅳ期进行检测，对ⅡA期考虑检测。

**免疫检查点抑制剂**：解除T细胞“刹车”的抗体。**伊匹木单抗**阻断**CTLA-4**；**纳武利尤单抗**和**帕博利珠单抗**阻断**PD-1**。单用（抗PD-1）或联合使用（伊匹木单抗加纳武利尤单抗）可产生持久缓解，一些转移性黑色素瘤患者在治疗后多年仍存活且无进展。其不良反应是**免疫相关不良事件**，即几乎任何器官的自身免疫性炎症，最常见的是结肠炎、肝炎、肺炎、皮疹和内分泌疾病（甲状腺炎、垂体炎、肾上腺功能不全，以及罕见的1型糖尿病）。这些可能很严重，需要及时识别并用糖皮质激素治疗。

**辅助治疗**：**Ⅲ期**黑色素瘤完全切除后，一年的抗PD-1治疗（BRAF突变者可用BRAF/MEK抑制剂）可降低复发风险；根据国家评估，抗PD-1治疗也用于部分切除后的高危**Ⅱ期**疾病。对可触及的淋巴结病变，越来越多地在手术前使用**新辅助**免疫治疗。
:::

治疗后随访的目的是发现复发和新的原发黑色素瘤，并支持患者。NICE NG14建议ⅠA期黑色素瘤随访1年，ⅠB至Ⅳ期随访5年，较高分期者进行影像学检查。患过一次黑色素瘤的人要学会自查皮肤，因为他们再患的风险增加。

::: warning 绝不要削除可疑色素性皮损
可疑色素性皮损应以窄切缘**完整切除**，不能削除、刮除、冷冻或部分切除，在未明确诊断前也绝不能用激光或冷冻治疗。部分切除可能使Breslow厚度无法测量，而Breslow厚度是分期以及以后关于前哨淋巴结活检、切缘和辅助治疗的每一项决定的关键。同样，每一个切除的色素性皮损都必须送组织学检查。在初级医疗中，对可疑皮损最安全的做法是按疑似癌症路径转诊。
:::

::: example 大脚趾甲上的黑色条纹 {#ex-acral}
一名58岁英国黑人男性发现右大脚趾甲上有一条深褐色条纹已约一年。它现在宽5 mm，根部比尖端宽，颜色不均，色素延伸到甲襞皮肤上。他不记得受过伤。他的全科医师曾认为这是瘀伤。担忧的是什么？为什么这类皮损常诊断较晚？
::: solution
担忧的是**甲下肢端雀斑样痣黑色素瘤**。警示特征包括：纵行色素带**逐渐增宽**（近端即甲母质处更宽）、**颜色不规则**、色带宽度超过约3 mm、成人单个甲受累（尤其是拇指或大脚趾），以及色素延伸到甲襞（**Hutchinson征**）。瘀伤（甲下血肿）通常有外伤史，并随指甲生长而外移，后面留下正常的甲。

肢端黑色素瘤是**深肤色人群中最常见的黑色素瘤亚型**。它常诊断较晚，原因是：发生在人们很少检查的部位；与日光暴露无关，因而不在以防晒为中心的宣传信息之列；被误认为瘀伤、真菌感染或疣；而且人们对深肤色者也会患黑色素瘤的认识有限。诊断延迟导致这些人群的结局更差。

他需要按**疑似癌症路径**转诊皮肤科进行评估并做**甲母质活检**。
:::
:::

::: example 从活检到治疗 {#ex-staging}
一名47岁男性背部一个变化的痣做了切除活检。组织学显示浅表扩散型黑色素瘤，Breslow厚度1.6 mm，有溃疡，切缘阴性。未触及淋巴结肿大。(a) T分类是什么？(b) 应向他提供前哨淋巴结活检吗？(c) 前哨淋巴结内有0.4 mm的黑色素瘤沉积灶；这对他的分期和治疗意味着什么？
::: solution
(a) 厚度大于1.0至2.0 mm并有溃疡，在AJCC第8版中为**T2b**。

(b) **是**：NICE NG14建议对厚度超过1.0 mm的黑色素瘤考虑SLNB。他还应做扩大局部切除，Ⅱ期厚度肿瘤的切缘通常为2 cm（如2 cm会造成不可接受的损害则为1 cm）。

(c) 前哨淋巴结阳性意味着**Ⅲ期**疾病（区域淋巴结扩散），尽管沉积灶是显微镜下的。他通常不做完全淋巴结清扫，因为试验没有发现生存获益；而是用超声监测淋巴结区域。对他的肿瘤检测**BRAF V600**突变。在讨论获益和副作用后，向他提供约一年的**辅助系统治疗**，使用抗PD-1免疫治疗，或如为BRAF突变则使用达拉非尼加曲美替尼。分期影像学检查是检查的一部分，随访持续5年。
:::
:::

::: quiz
在没有扩散时，原发性黑色素瘤的哪项特征是最重要的预后因素？
- [ ] 皮损的直径
- [ ] 皮损中颜色的数目
- [x] Breslow厚度
- [ ] 患者的皮肤类型
::: solution
**Breslow厚度**，即以毫米计的浸润深度，是局限性黑色素瘤结局最强的预测因素，其次是溃疡；两者共同决定T分类。直径和颜色有助于识别但不能判断预后，皮肤类型影响的是患黑色素瘤的风险，而不是某一肿瘤的预后。
:::

## 预防与早期发现 {#sec-prevention}

**一级预防**旨在减少紫外线暴露，尤其是在儿童期：

- **遮阴**，尤其是在紫外线指数为3或以上时和正午前后；
- **衣物**、宽檐帽和防紫外线太阳镜；
- **防晒霜**作为遮阴和衣物的补充而非替代：使用防晒系数（SPF）至少30、UVA防护良好的广谱产品（在英国为UVA评级4星或5星），大量涂抹，并在游泳、出汗或擦干后重新涂抹；
- **避免晒伤和日光浴床**。英国禁止18岁以下者使用日光浴床。

防晒霜试验支持其使用：在澳大利亚Nambour试验中，每天规律使用防晒霜减少了鳞状细胞癌，长期随访还显示减少了浸润性黑色素瘤。实际上，大多数人的用量远少于实验室SPF测试所用的2 mg/cm²，因此他们得到的防护远低于标签所示。

由于阳光是维生素D的主要来源，严格避免日晒可导致维生素D缺乏；避免日晒、遮盖皮肤、深肤色或患过黑色素瘤的人可能需要按国家建议补充。

**二级预防**是指早期发现。英国没有全国性的皮肤癌筛查计划，因为人群筛查尚未被证明能减少黑色素瘤死亡，还会导致大量切除。相反，重点放在公众和专业人员的认识、自我检查、可疑皮损的快速评估通道，以及对高危人群（如器官移植受者、有许多不典型痣者和既往患黑色素瘤者）的监测。

::: history
1775年，伦敦外科医师**珀西瓦尔·波特（Percivall Pott）**把扫烟囱工人的阴囊癌与烟灰联系起来，这是人类第一次认识到环境暴露可以致癌，而所致的正是一种皮肤癌。1969年，美国病理学家**华莱士·克拉克（Wallace Clark）**按解剖浸润层次对黑色素瘤分类；1970年，**亚历山大·布雷斯洛（Alexander Breslow）**证明测得的肿瘤厚度能更好地预测结局，为黑色素瘤分期提供了核心数字。20世纪90年代初，**唐纳德·莫顿（Donald Morton）**及其同事把前哨淋巴结活检引入黑色素瘤诊治。1981年，澳大利亚维多利亚州癌症委员会发起了“Slip! Slop! Slap!”运动（穿上衬衫、抹上防晒霜、戴上帽子），成为全世界防晒运动的范本。2002年，惠康基金会桑格研究所的**迈克尔·斯特拉顿（Michael Stratton）**及其同事报告大多数黑色素瘤中存在激活性**BRAF**突变，不到十年就催生了BRAF抑制剂。2011年，基于**詹姆斯·艾利森（James Allison）**对CTLA-4研究的**伊匹木单抗**成为第一种被证明能延长转移性黑色素瘤生存期的药物；艾利森与发现PD-1的**本庶佑（Tasuku Honjo）**分享了2018年诺贝尔生理学或医学奖。
:::

## 后续内容

癌症的分子生物学，包括癌基因、抑癌基因和DNA修复，在[[pathology/cancer-biology]]中展开，遗传性癌症易感性见[[genetics/cancer-genetics]]。肿瘤免疫学和检查点抑制剂见[[immunology/transplant-tumour-immunology]]和[[immunology/vaccines-immunotherapy]]，筛查原则见[[public-health/screening]]。器官移植受者的皮肤癌与[[immunology/transplant-tumour-immunology]]相关，免疫治疗的内分泌不良反应与[[endocrine/endocrine-emergencies]]相关。

::: summary
- 紫外线辐射（UVB直接、UVA间接）造成DNA损伤；未修复的嘧啶二聚体在皮肤癌中留下C→T“紫外线印记”。着色性干皮病显示了DNA修复的作用。
- 鳞状细胞癌与累积暴露相关；黑色素瘤和BCC与间歇性强烈暴露和晒伤相关。浅肤色、多痣、家族史、日光浴床和免疫抑制增加风险。
- 光线性角化病和鲍恩病是cSCC的前驱病变。BCC是伴毛细血管扩张的珍珠样结节，极少转移；cSCC是角化性、常有压痛的结节，可扩散到淋巴结。
- 角质形成细胞癌主要通过切除治疗（低风险肿瘤切缘约4 mm，高风险更宽），面部高危和复发肿瘤用Mohs手术，浅表病变用外用药物或其他疗法。
- 黑色素瘤类型：浅表扩散型、结节型（隆起、质硬、长大）、恶性雀斑样痣型、肢端雀斑样痣型（深肤色中最常见；甲上的Hutchinson征）和黏膜型。
- 使用ABCDE、丑小鸭征和NICE加权7点检查表（3分或以上转诊）。可疑皮损要完整切除；绝不削除。
- Breslow厚度和溃疡决定T分类；有不良特征时从0.8 mm起考虑前哨淋巴结活检，所有超过1.0 mm的黑色素瘤都考虑。扩大切除切缘：0.5 cm（原位）、1 cm（Ⅰ期）、2 cm（Ⅱ期）。
- BRAF/MEK抑制剂和免疫检查点抑制剂改变了晚期黑色素瘤的治疗，并用作切除后Ⅲ期和部分Ⅱ期疾病的辅助治疗；免疫相关不良事件可累及任何器官。
- 预防依靠遮阴、衣物、大量涂抹SPF 30以上的广谱防晒霜，以及避免晒伤和日光浴床。
:::

## 习题

::: exercise BCC还是SCC？ {level=1}
列出三个有助于区分结节型基底细胞癌与皮肤鳞状细胞癌的特征，并说明两者行为上的关键差异。
::: solution
**BCC**：珍珠样、半透明外观；边缘卷起；细小的树枝状毛细血管扩张；在数月至数年内缓慢生长；常无痛。**cSCC**：角化、结痂或脱屑的表面；在数周至数月内较快生长；常有压痛；通常在长期日光损伤的皮肤上，有时由光线性角化病或鲍恩病发展而来。**行为**：BCC极少转移，但有局部破坏性；而cSCC可以转移，通常转移到区域淋巴结。
:::
:::

::: exercise 给皮损评分 {level=1 check="3"}
一名63岁男性肩部有一个色素性皮损。直径5 mm，轮廓不规则，颜色为均匀的褐色。已经痒了一个月，但无炎症、无渗液，也没有长大。计算加权7点检查表得分，并说明是否达到按疑似癌症路径转诊的阈值。
::: solution
大小改变：0。形状不规则：**2**。颜色不规则：0。直径7 mm或以上：0。炎症：0。渗液：0。感觉改变（瘙痒）：**1**。总分$= 2 + 1 = 3$，**达到**3分的阈值，因此应按疑似癌症路径转诊。检查表是一种结构化辅助工具：得分低于3分的皮损如有强烈临床担忧，仍应转诊。
:::
:::

::: exercise 晒伤时间 {level=1 check="round(10*250/(1.5*8))/10"}
用[[#eq-burn]]计算MED为250 J/m²的人在紫外线指数为8时接受一个MED所需的时间（分钟），四舍五入到一位小数。
::: solution
$t = 250/(1.5 \times 8) = 250/12 \approx 20.8$分钟。英国夏季正午，浅肤色皮肤约20分钟就会晒伤，这就是为什么遮阴和衣物比单靠防晒霜更重要。
:::
:::

::: exercise 现实中的防晒霜 {level=2 check="round(300/(1.5*6)*sqrt(30))"}
一名MED为300 J/m²的人在紫外线指数为6时待在户外。(a) 无防护皮肤接受一个MED需要多久？(b) 他涂了SPF 30的防晒霜，但厚度只有实验室测试所用厚度的一半。一个常用模型假设实际获得的防护为$\text{SPF}^{f}$，其中$f$是涂抹量占测试厚度的比例。估计涂防晒霜后接受一个MED所需的时间（分钟），四舍五入到整数。
::: hint
对于(b)，有效防护系数是$30^{0.5}$；用它乘以无防护时间。
:::
::: solution
(a) $t = 300/(1.5 \times 6) = 300/9 \approx 33.3$分钟。

(b) 有效SPF $= 30^{0.5} \approx 5.48$。时间$\approx 33.3 \times 5.48 \approx 182.6$，即约**183分钟**，约三小时，而不是标签可能暗示的$33.3 \times 30 \approx 1{,}000$分钟。大量涂抹并重新涂抹防晒霜很重要，也不应借助防晒霜来延长有意的日晒。
:::
:::

::: exercise T分类是什么？ {level=2}
给出下列原发性黑色素瘤的AJCC第8版T分类：(a) Breslow 0.6 mm，无溃疡；(b) Breslow 0.9 mm，无溃疡；(c) Breslow 3.2 mm，有溃疡；(d) Breslow 4.5 mm，无溃疡。NICE会建议对哪些考虑前哨淋巴结活检？
::: solution
(a) **T1a**（小于0.8 mm，无溃疡）。(b) **T1b**（0.8至1.0 mm）。(c) **T3b**（大于2.0至4.0 mm，有溃疡）。(d) **T4a**（大于4.0 mm，无溃疡）。

SLNB：(a)不做，属于ⅠA期。对于(b)，NICE建议只有在有溃疡、淋巴血管浸润或核分裂指数2或以上时，才对0.8–1.0 mm的黑色素瘤考虑SLNB；没有这些特征时不常规提供。(c)和(d)厚度超过1.0 mm，考虑SLNB。
:::
:::

::: exercise 移植受者 {level=2}
一名61岁男性12年前做了肾移植，服用他克莫司、吗替麦考酚酯和泼尼松龙。他两年内切除了三个鳞状细胞癌，现在头皮上又长出一个有压痛、结痂的新结节。为什么他的风险如此之高？哪些措施有帮助？
::: solution
**原因**：长期免疫抑制削弱了对紫外线损伤角质形成细胞的免疫监视，某些免疫抑制剂（尤其是硫唑嘌呤）还会增加紫外线所致的DNA损伤。因此器官移植受者cSCC风险增加许多倍，而且可能多发、侵袭性强、更易转移。人乳头瘤病毒也可能起作用。

**措施**：紧急评估并切除新皮损（疑似cSCC）；在移植皮肤科门诊定期进行专科皮肤监测；严格防晒并自查；对光线性角化病进行区域治疗；与移植团队一起审查免疫抑制方案，因为换用**mTOR抑制剂**（如西罗莫司）或减轻总体免疫抑制负担可减少新的皮肤癌；某些情况下用口服维A酸类药物（阿维A）或烟酰胺进行**化学预防**。
:::
:::

::: exercise 免疫治疗期间的腹泻 {level=3}
一名55岁女性因转移性黑色素瘤接受伊匹木单抗和纳武利尤单抗治疗，在第二个周期后两周出现每天七次水样腹泻伴腹部绞痛。十天后她又诉新发头痛和乏力，血钠偏低。(a) 腹泻可能的原因是什么？(b) 什么可以解释头痛、乏力和低钠血症？(c) 处理原则是什么？
::: hint
检查点抑制剂引起自身免疫性炎症；想一想肠道和内分泌腺。
:::
::: solution
(a) **免疫相关性结肠炎**，最常见的严重免疫相关不良事件之一，尤其是CTLA-4与PD-1抑制剂联合使用时。必须排除感染（包括*艰难梭菌*）。

(b) **垂体炎**（垂体的自身免疫性炎症），是伊匹木单抗的典型不良反应：头痛、乏力和继发性**肾上腺功能不全**（ACTH和皮质醇低），可导致低钠血症、低血压和虚脱。应检查甲状腺功能、皮质醇和其他垂体激素，并考虑垂体MRI。

(c) 处理遵循按严重程度分级的肿瘤科方案：对这种频率的结肠炎，**暂停免疫治疗**，给予**全身糖皮质激素**，如无效则升级为抗TNF药物（英夫利西单抗）或维得利珠单抗；请消化科参与。对垂体炎，在任何甲状腺激素替代之前先**补充皮质醇**（氢化可的松，配合患病日规则和激素急救卡），因为先给甲状腺素可诱发肾上腺危象。内分泌缺陷常是永久性的，需要终身替代。使用检查点抑制剂的患者应携带警示卡，并能快速联系肿瘤团队（[[endocrine/endocrine-emergencies]]）。
:::

::: exercise 制订防晒宣传信息 {level=3}
一所中学请你就皮肤癌预防为学生提供建议，许多学生夏天在农场户外劳动，有些学生肤色较深。概述关键信息及其背后的证据，并解释为什么关于黑色素瘤的信息不应只针对浅肤色学生。
::: solution
**关键信息**：避免晒伤，尤其是在儿童期和青春期，因为晒伤与黑色素瘤和BCC密切相关；利用**遮阴**，尤其是在正午前后紫外线指数3或以上时；穿戴**衣物、宽檐帽和太阳镜**；使用UVA防护良好的广谱**SPF 30或以上**防晒霜，大量涂抹并定期重涂，作为遮阴和衣物的补充；**绝不使用日光浴床**（英国18岁以下使用属违法）。户外劳动时，把工作安排在早晚，穿长袖、戴帽子。**证据**：紫外线造成皮肤癌中所见的DNA损伤；Nambour试验中使用防晒霜减少了鳞状细胞癌和黑色素瘤；使用日光浴床与黑色素瘤风险增加相关。

**深肤色**：深肤色人群患紫外线相关皮肤癌的风险低得多，但他们仍可能患黑色素瘤，最常见的是手掌、足底和甲的**肢端黑色素瘤**，它并非由日光暴露引起，而且常诊断较晚。因此所有学生都应学会检查自己的皮肤，包括手掌、足底和指（趾）甲，并报告新发或变化的痣或甲上的黑色条纹。还应包括维生素D方面的建议，因为避免日晒和深肤色都会增加缺乏的风险。
