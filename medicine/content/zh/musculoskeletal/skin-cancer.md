皮肤癌是“一种可预防的癌症却不断上升”的典范：**紫外辐射是一类致癌原，大多数的角质形成细胞的癌与很大比例的黑色素瘤都是它的收据；而临床的技能组合小到一下午就能教完——好好地看、好好地切、知道哪些病灶需要专科，然后把职业生涯的其余部分花在“阳光的政治”上。**

本章涵盖致癌与风险、角质形成细胞的癌、黑色素瘤、附属器与罕见的皮肤癌、以及在人群与个体层面的预防。

## 致癌与风险

::: definition 紫外、遗传学与“谁会长皮肤癌” {#def-carcinogenesis}
**紫外的生物学（中波紫外作为直接的致突变原，造成“环丁烷嘧啶的二聚体”与“在二嘧啶位点的C到T的转换”、而长波紫外造成氧化的应激与免疫的抑制、带着那套“突变的签名”的逻辑；以及剂量的几何的规则——“间断暴发的暴露与晒伤”对应黑色素瘤、“累积的总剂量”对应角质形成细胞的癌；以及室内的“美黑设备”的分类与它在使用年限短用户中的黑色素瘤风险的系数——[[cell-biochemistry/gene-expression]]、[[pathology/cancer-biology]]、脱氧核糖核酸修复的相邻见[[cell-biochemistry/energy-metabolism]]；以及那场被完整谈过的“维生素D的反驳”——皮肤癌对缺乏的平衡，靠“饮食与补充的维生素D”、而不是靠“晒到发红”来解决——[[cell-biochemistry/nutrition]]、[[endocrine/bone-calcium]]）。遗传的土壤野外的癌变与体细胞的景观；以及“把皮肤癌变成一次遗传科的门诊”的种系的综合征——家族性的黑色素瘤（伴胃与胰及“相邻的表型”、以及那个“红发、白肤、日晒敏感”的谱与着色性干皮病的“核苷酸切除修复的缺陷”、以及“基底细胞癌的综合征”、以及移植的免疫抑制所倍增的风险——遗传的易感在[[genetics/cancer-genetics]]与[[genetics/common-disease-genetics]]）。风险的登记皮肤的分型I与II与“晒伤对晒黑的相对能力”、以及雀斑的计数与痣的计数——普通的获得性的与不典型的痣的计数与“高风险的类型”；以及黑色素的家族史与既往的皮肤癌与累积的紫外及“职业户外的劳动”及美黑的病史、以及在鳞状细胞癌中年长的男性、以及免疫抑制尤其在移植与人免疫缺陷病毒、以及在鳞状细胞癌中的人类乳头瘤病毒、以及既往的放疗与慢性的瘢痕及窦道（烧伤的瘢痕、以及化学的与砷的暴露及补骨脂素加紫外遗留的队列、以及遗传的综合征的旗帜——淋巴细胞皮肤癌的关联见[[blood/lymphoma-myeloma]]、[[immunology/immunodeficiency]]、[[infectious-diseases/hiv]]）；以及筛查与监测的政策（“对普通人群没有筛查的证据基础”这一立场、对“为高风险的人群做有目标的监测”；以及“全身皮肤检查的技术与拍照及序列的影像”——以及“让检查可重复”的那门学问。）**

## 角质形成细胞的癌

::: definition 日光性的角化、鲍恩病、基底细胞癌与鳞状细胞癌 {#def-keratinocyte}
**癌前的野外（日光性的角化作为“日晒损伤皮肤里的角质形成细胞的不典型增生”、以及“野外的癌变”这一概念、以及“数量对单一病灶的风险”的算术、以及处理的菜单——针对病灶的冷冻或刮除，对“针对野外的”氟尿嘧啶或咪喹莫特或“活性成分的植物提取物”或光动力，带着那场“预期炎症的反应”的咨询、以及复发与“转向鳞状细胞的癌”的风险的框架——[[pharmacology/adverse-reactions]]、外用肿瘤学的药物见[[pharmacology/drug-development-prescribing]]；以及鲍恩病作为“原位”的鳞癌、对生殖器区域的人类乳头瘤病毒相邻的“鲍恩样的丘疹病”；以及派杰病那“要去查底下的腺癌”的反差的对比——派杰的那一行见[[surgery/breast-endocrine-surgery]]、外阴的那一行见[[obstetrics-gynaecology/gynaecological-cancer]]）。基底细胞癌（那类“由紫外驱动的、走刺猬的通路”的瘤、伴基底样的组织学、以及“几乎不转移、但在局部有破坏性”的行为；以及形态的目录——结节的“卷边而珍珠样伴毛细血管扩张及溃疡”、浅表的“湿疹样躯干的模仿者”、硬皮病样的、以及“口周与眼周高危的亚部位”的规则；以及在脸上“不要挤莫氏的手术队、也不要制造毁容与复发”的那份张力——[[clinical-skills/physical-examination]]、浅表的基底细胞癌对湿疹对银屑病对派杰的那几行见[[musculoskeletal/skin]]；按风险分层路径的处理——“带切缘与关闭的规划的手术的切除”，对“经选择小病灶的刮除与电灼”，对“不适合外科候选者的放疗”，对“浅表疾病外用的与光动力”，对“局部晚期的与综合征的刺猬通路的抑制剂”，对免疫治疗的小块地——关闭与皮瓣的相邻见[[surgery/wounds-surgical-infection]]、切缘报告的判读见[[pathology/cancer-diagnosis]]、放疗的选项见[[pathology/cancer-biology]]）。鳞状细胞癌枚“中央有角质的坑的结节”的角化棘皮瘤、以及鳞癌的风险的分层——厚度与深度包括脂肪以下与低分化及“神经周与淋巴管的侵犯”及部位（耳、唇、头皮及免疫抑制及大小及复发——它们驱动着切缘与淋巴结及影像的决定；以及移植的患者的那份“数量与严重度都爆表”的账。）**

## 黑色素瘤

::: definition 从痣到免疫治疗的黑色素瘤 {#def-melanoma}
**生物学那条“黑色素细胞与痣的序列”——作为“起始的事件”的BRAF的突变与衰老、以及“向恶性的转变”伴随另外的几个打击；以及那个“高的肿瘤突变负荷”的紫外突变的签名它解释了免疫治疗的应答性；以及肢端的与黏膜的及“葡萄膜的和结节的和恶性雀斑样的变异”它们各有各的遗传学、以及那“起源于别处”对“与痣相关”的辩论（约3%的黑色素瘤——[[pathology/cancer-biology]]、[[genetics/cancer-genetics]]、[[cell-biochemistry/signalling-cell-cycle]]）。检出（套“的形状颜色直径演变”与“丑小鸭”的启发法、以及它们真实敏感度的极限；以及“要记得后背与头皮及足底和甲下”与“让伴侣拍照”这个习惯；以及皮肤镜的模式与规则、以及“甲、乙、丙的顺序”、以及为高风险的队列做的“序列数字的成像”；以及“无黑色素型的与结节的及黏膜的及甲下的赫钦森的征”的漏诊——正是它们制造了诉讼与年轻人的死亡——[[clinical-skills/physical-examination]]、葡萄膜眼底的相邻见[[nervous-system/sensory-systems]]；以及转诊的阈值：任何可疑的病灶都值得一记“带窄切缘切除的活检做组织学”——不是刮除、不是部分、不是激光、不是冷冻、也不是等待）。预后的判断布莱斯洛的厚度作为首要的预后因子、伴溃疡与核分裂的比率及“淋巴管的侵犯”；以及在“中等的与厚的黑色素瘤”中“前哨淋巴结的活检”的阈值的讨论带着微转移的检出、以及它在分期与治疗的时代里的位移——[[pathology/diagnostic-pathology]]、[[clinical-skills/medical-imaging]]；以及那套分期的架构（从原位到厚的、有淋巴结的、远处转移的疾病、配上“按分期监测影像的强度”的现实、以及“用化验与症状的教育对抗全身扫描的焦虑”——[[public-health/screening]]）。处理按厚度决定的“广泛局部切除的切缘”与重建、以及“淋巴结区域的超声”、以及在多学科团队之后“补全的清扫对观察”并行地做辅助的治疗的决定；辅助的免疫治疗帕博利珠或纳武利尤、以及在“有突变的”高危疾病中靶向的联合（带着复发风险降低的那几个数字、以及“晚期疾病现代的组合”（免疫的联合与靶向及对“难治的”的“病灶内的治疗”）——[[immunology/adaptive-responses]]、[[pathology/cancer-diagnosis]]。）**
:::

::: example 那个没人拍过照的后背 {#ex-melanoma-back}
一名56岁的男子的妻子注意到他“肩胛之间有一块深色的、不规则的、在增大的斑”；皮肤科的切除报告为“2.4毫米结节的黑色素瘤伴溃疡、核分裂的比率高、只做了窄切缘的活检、没有记录淋巴管的侵犯”。
::: solution
**因为“后背不在男性的自我检查的清单里”而被发现的、厚的、溃疡的、迟发的黑色素瘤（[[#def-melanoma]]）：分期的序列——“按厚度合适切缘广泛局部的切除”、在同一次麻醉下做“前哨淋巴结的活检（带淋巴的映射”、淋巴结的结果决定辅助治疗的适格、以及为三期的“横断面的影像”和“要不要做脑的磁共振”的问题——[[pathology/diagnostic-pathology]]、[[clinical-skills/medical-imaging]]、关闭的相邻见[[surgery/wounds-surgical-infection]]；场多学科与数字的谈话——五年生存的数字“放在背景里引用、不是当成判决”；以及“辅助的免疫治疗或靶向治疗”的基于证据的复发的风险的降低、以及“提一句试验的适格、而不是管理希望”、以及那份“带淋巴结区域的超声与皮肤及症状的危险信号（头痛与神经及呼吸及骨”的监测的时间表——[[immunology/adaptive-responses]]、[[public-health/screening]]、[[nervous-system/motor-systems]]）；家族与遗传学的清扫——痣的数目与家族的病史及白肤的类型、以及“在有聚集的家族中做种系的检测并配遗传的咨询”的考虑——[[genetics/cancer-genetics]]、[[medical-ethics-law/confidentiality]]）；场“行为的顿悟”不带责备地处理——对某些患者是“我从不美黑、可还是得了”的现实、对所有人则是“早早的自我检查”的教育；以及“把伴侣包括进来的关于后背与头皮的教学”、以及那套“序列的拍照”，好让下一次的变化是可测量的——[[clinical-skills/communication]]、[[clinical-skills/records-handover]]。**

::: example 移植患者“长在太阳穴上的第三个瘤” {#ex-transplant-scc}
一名59岁的肾移植的受者在环孢素与泼尼松龙及霉酚酸之下，在18个月里有三个头皮鳞状细胞的癌、几个切出的厚度达6毫米、“两侧的太阳穴都有野外的改变”、以及一个正在被讨论的耳前的淋巴结的增大。
::: solution
**由免疫抑制驱动的、有淋巴结风险的侵袭性鳞状细胞的癌——皮肤科与移植及“头颈的外科”要在同一个房间里（鳞癌的风险见[[#def-keratinocyte]]、[[immunology/transplant-tumour-immunology]]）：场“免疫抑制的重新谈判”——减少或停用环孢素、并“转换为哺乳动物雷帕霉素的抑制剂”（证据温和地支持，配上排斥风险的谈话（由肾科共同拥有、不是由皮肤科单独决定、以及“最小的可用的泼尼松龙与霉酚酸的复查”——[[renal/chronic-kidney-disease]]、手术期间“肾上腺的覆盖”的相邻见[[endocrine/adrenal]]与[[surgery/perioperative-care]]）；肿瘤学的路径——用超声与“细针的抽吸”评估淋巴结、以及横断面的影像、以及“腮腺与颈的清扫”的问题、以及“为高危的特征的辅助的放疗”的考虑、以及多学科团队的记录——[[clinical-skills/medical-imaging]]、[[pathology/cancer-diagnosis]]）；野外与一级预防的项目——严格日的防护与帽子及回避、以及“全身皮肤检查的时间表”、以及“强化野外的治疗（光动力或外用”、以及对看得见的病灶的皮肤外科、以及“全身类视黄醇化学的预防”的谈话、以及“从每月到每季度的密切的随访”——[[public-health/prevention-promotion]]、[[pharmacology/patient-variation]]）；以及那个人类免疫缺陷病毒与人类乳头瘤病毒的“平行的宇宙”的核查、以及疫苗与“癌症的筛查”的状态的复查——[[infectious-diseases/hiv]]、[[public-health/vaccination-programmes]]；心理的负荷——慢性癌症的风险与“无休止的门诊”、以及“太阳穴手术后视野受影响时要不要开车”、以及帽子与瘢痕的遮盖及“职业的暴露”的协商——[[clinical-skills/communication]]、[[public-health/environmental-occupational]]。**

::: example 处“一次次长回来”的鼻 {#ex-bcc-sequel}
一名82岁的杂货商在别处做过两次刮除之后、右侧鼻翼的沟上复发了一处2厘米结节的基底细胞癌；最后一次病理写的是“碎片化的、切缘无法评估”；他因房颤服用阿哌沙班、并拒绝“在全身麻醉下住院开刀”。
::: solution
**高危部位复发的基底细胞癌，是一个““切缘控制的手术”、或“测绘式的切除”并重建“的决定、而他的拒绝是知情的、不是最终的（[[#def-keratinocyte]]）：为”切缘控制的手术“辩护的理由——鼻翼的亚部位与复发及”碎片化的切缘“，意味着无论走哪条路，”蒙着眼睛切“的组织经济都是不能接受的；以及”莫氏对分期的砖墙式的堆叠的切除“选项、以及鼻翼的重建的计划——”转移的皮瓣对植皮对二期愈合“的”美容的现实”要在皮肤癌的多学科团队里谈——[[surgery/wounds-surgical-infection]]、[[pathology/diagnostic-pathology]]；是优化、不是一票否决——围手术期阿哌沙班的管理配心脏血栓风险的算术、以及“在日间单元用局麻加镇静”——这正是对他真实的恐惧他怕的是被睡着，不是手术的回答；以及“抗凝与血肿与皮瓣的存活”的咨询——[[blood/thrombosis-anticoagulation]]、[[cardiovascular/arrhythmias]]、[[surgery/anaesthesia-pain]]、[[surgery/perioperative-care]]；那个放疗的问题——为一个“不适合外科的候选者”做“根治性或辅助的放疗”，在82岁这个年龄谈它的治愈与“第二原发及放射性皮炎及脱发及晚期的坏死”的取舍用真实数字的诚实、以及“晶体与软骨的邻近”的限制——[[pathology/cancer-biology]]；以及后续——“由皮肤癌护士主导复查的时间表”与全身的皮肤的检查，因为他是一个“多发瘤的类型”、以及那位杂货商日晒的病史、以及“教孙辈涂防晒霜”的那个时刻——继发的预防就是这样传播的——[[public-health/prevention-promotion]]、[[clinical-skills/records-handover]]。**

::: example 那位八十岁的颊上“在变化的斑” {#ex-lentigo}
一名79岁退役的水手，一侧的颧突上有一处缓慢增大的4厘米的“不规则的黄褐到棕色的斑”、“从1990年代就在”，现在其中出现了一处更黑的结节；他其余方面健康、没有重要的用药。
::: solution
**“恶性雀斑样痣伴一个可疑的结节”是同时存在的两个问题——原位的野外与侵袭的成分（[[#def-melanoma]]）：活检的规则——那个结节要得到“一记足够大、能测布莱斯洛厚度的切除或深的刮除或钻取活检”、而那片斑要被“取样或测绘、而不是被毁掉”；以及与病理的那场谈话（在“严重日晒损伤的面部皮肤里厚度测量的准确度极限、以及微囊肿的附属器与”促结缔组织增生的模仿“——[[pathology/diagnostic-pathology]]、皮肤镜测绘的技术见[[clinical-skills/physical-examination]]）；在“结节的数字”出来之后的处理的岔路——对侵袭的部分做广泛的切除；而对原位的野外，选择包括“分期缓慢的莫氏或砖墙式（配广泛表面的测绘”、对外用的咪喹莫特或放疗（在“面积大而美容与功能都敏感”的区域、对“被观察的薄片的钻取的审计”、以及面部的“拍照监测的时间表”——[[surgery/wounds-surgical-infection]]、[[pharmacology/adverse-reactions]]）；场“为什么这件事花了几十年”的谈话——恶性雀斑样痣长得慢是真的、而责备谁都不利、真正改变预后的是那个结节；以及把“自我与伴侣的检查”聚焦在“老的斑上出现新的肿块”、配规律拍照的随访——[[clinical-skills/communication]]、[[public-health/screening]]）；以及“日与免疫抑制与家族的风险”的收尾——在79岁，帽子与防晒霜与回避仍然是值得的；以及第二原发与鳞癌及“日光野外的治疗”、以及“封写给全科医师并用平实的语言写下监测间隔门诊的信”——[[public-health/prevention-promotion]]、[[clinical-skills/records-handover]]。**

## 谁应当尽快被看到

本章转诊的分诊短到可以背下来。任何“有令人信服改变的病史”的色素的病灶；任何“在同一处出血或结痂一个月”的瘤；任何在数周之内长大的新发的结节；任何不愈合的溃疡或瘢痕；以及任何“让一位有经验的观察者担心”的病灶无论是否符合标准——都属于两周的皮肤科或整形外科的路径，而来自初级保健远程的拍照在被好好使用时可以正当地抄近队（[[#def-melanoma]]、[[public-health/screening]]）。当周紧急的复查适用于：“野外迅速退变的”被免疫抑制的患者、“侵犯了眼或鼻或耳或唇”的面部的病灶在那里“保组织的手术”会改变重建、以及任何疑似的默克尔的细胞癌它以周计的倍增时间使它成为大多数临床医师一辈子会看到的最快的皮肤癌（[[#def-rare]]、[[#def-keratinocyte]]）。其余的所有人——稳定脂溢性的角化、“存在了十年而对称的痣”、“戴着脂质的冠的睑黄瘤”——用解释、拍照与时间来处理，这是医学里最便宜、也最少被处方的皮肤病学的干预（[[musculoskeletal/skin]]、[[clinical-skills/communication]]）。

## 实践的视野

有三处的操作细节，把“称职皮肤癌的服务”与“鲁莽的”分开来。第一是真实约束之下的切缘的策略。莫氏的显微手术在患者等待的同时检查病灶切缘的百分之百、这就是为什么它在“每一毫米都值得钱或美或两者”的高危面部的瘤上既保组织又防复发；在莫氏的能力稀缺的地方，“缓慢的莫氏配过夜的测绘”或“带当日切缘评估砖墙式堆叠的切除”用不同的资源达到接近的目标；而两样都没有的服务，至少应当“在重建之前用系列双向的切片为高风险的病灶测绘”，而不是在周一的报告上才发现切缘阳性（[[pathology/diagnostic-pathology]]、[[surgery/wounds-surgical-infection]]）。第二是那场辅助的治疗的谈话本身。对被切除的三期的黑色素瘤，现代辅助的免疫治疗或靶向治疗在相对的意义上把复发的风险降低大约三分之一；换算成个体的绝对的数字，它可能意味着“观察对治疗”的差别。患者值得听到“以带不确定的范围框定的数字”、份免疫毒性的清单被“读成一份要早早报告的事的时间表”、而不是一叠恐怖的清单、以及“在内分泌科的那位联系人被具名”才打第一剂——因为[[endocrine/hypothalamus-pituitary]]与[[endocrine/adrenal]]与[[endocrine/thyroid]]里描述的垂体炎与甲状腺炎及肾上腺的不足，会准时到来、而当一位全科医师对它毫无准备时会非常糟糕（[[immunology/adaptive-responses]]、[[clinical-skills/communication]]）。第三是数据：皮肤癌的登记、相互链接的病理与分期的数据集、以及被拍照并序列记录的病灶——它们把这一章“从手艺变成了流行病学”；它们也终将显示今天的美黑禁令与学校的遮阴的规划，“对现在正在满40岁的那一代究竟有没有用”——这是唯一一种能证明今天的付出值得的证据。

## 治愈之后：监测与第二原发

治愈与监测是两种不同的手艺、最好由不同的人在不同的时钟上实践；把它们混为一谈，随访就会要么变成表演、要么变成失守。一位因一处角质形成细胞的癌被治疗过的患者，带着“下一处明显升高的比率”——在高风险的队列里大约是每年两到三处，而背景的比率很小——这就是为什么移植的受者与多发的瘤的患者会得到“按方案全身皮肤的检查”、而不是“担心就回来”；也是为什么每一次就诊同时是一次病灶的检查、一次野外的治疗、一次日光防护的咨询、以及一次“为他们正在讨厌的那套外用的方案”做的依从的门诊（[[#def-keratinocyte]]、[[public-health/prevention-promotion]]）。黑色素瘤的监测倚赖别的数字：大多数复发发生在头两三年、大多数第二处的黑色素瘤是被患者或他们的伴侣、而不是在门诊里发现的；监测时间表的存在，是为了“把淋巴结与皮肤的检查与教学结合起来”——这就是为什么“由护士主导、带清楚准入路径的随访”表现得和专家门诊一样好，还能把更稀缺的门诊容量留给新的肿块（[[#def-melanoma]]、[[public-health/screening]]、[[clinical-skills/communication]]）。“癌症的监测”这份心理的载荷是真实的：对复发的恐惧“聚集在扫描的间隔与随访的日子周围”，而诚实的服务会命名它、围绕它安排时间、并提供对付焦虑的工具——而不是在日历上再加一张“没有标签的扫描”（[[psychiatry/anxiety-disorders]]、[[epidemiology-ebm/diagnostic-tests]]）。

**检验点抑制剂低下的脑垂体炎或原发的肾上腺的皮质功能不全或甲状腺的轴的障碍带着中枢的模式线索（[[#def-melanoma]]的免疫治疗、[[endocrine/hypothalamus-pituitary]]、[[endocrine/adrenal]]）：当日转诊给肿瘤科与内分泌科、而不是等一个门诊的空位；立即开始“生病日子的激素与注射的套件”的教育；以及全轴的查因——配对的促肾上腺皮质激素与皮质醇及甲状腺功能及抗体、以及钠与渗透压及泌乳素及性腺的激素、以及“鞍区的磁共振（带着头痛与视野的问题”——[[clinical-skills/laboratory-tests]]、[[nervous-system/sensory-systems]]）；治疗的次序——按严重度“先应激剂量的糖皮质激素的替代、然后是生理的剂量”、而左甲状腺素只在皮质醇之后、以及“激素的替代对大剂量的免疫抑制（针对肿物的效应”的决定——[[endocrine/adrenal]]、[[endocrine/thyroid]]）；与肿瘤科的沟通——检验点毒性的分级、以及暂停还是继续、以及“其他器官的免疫的不良的事件”的登记（结肠与肝及肺及皮肤、以及那张安全网的卡片——[[infectious-diseases/immunocompromised-host]]、[[respiratory/interstitial-vascular-disease]]、[[gastrointestinal/liver-disease]]）；以及那份“会不会永久”的咨询——低下的脑垂体炎与肾上腺及甲状腺的缺陷常常持续；以及医疗的警示的手环、驾驶、以及“独自生活人生病日子的计划”——驾驶与手环那几行见[[endocrine/adrenal]]。**

::: exercise 定下监测的时间表 {level=2}

::: solution
**证据与偏好的中间的路（[[#def-melanoma]]、[[public-health/screening]]）：时间表——5到10年的规律的皮肤与淋巴结的临床的检查、以及“每月一次的自我检查（配伴侣与拍照的工具”、以及那份症状的危险信号的清单（头痛与骨的疼痛及呼吸困难及持续的咳嗽及新的肿块、以及低阈值的联系方式；以及“按两期方案影像的监测”——讨论“额外获得的早期检出”对“辐射与偶然瘤及焦虑”的代价——[[clinical-skills/medical-imaging]]、[[epidemiology-ebm/diagnostic-tests]]）；为回避者的安心的建筑——一页纸写下来的计划、以及“年度复查的邀请”、以及这个框架：“来门诊是为了新的病灶与淋巴结、不是为了盯着灾难”；以及紧急的准入的承诺、好让监测不像在排队；以及为“表现为失眠与工作受损的恐惧”转介心理的支持——[[psychiatry/anxiety-disorders]]、[[clinical-skills/communication]]）；以及记录与信——“在辅助治疗或有检验点的病史时，与内分泌科及全科共同随访”、以及保险与旅行的文件的问题被书面地回答一次——[[clinical-skills/records-handover]]、[[public-health/health-systems-economics]]。**
