急性的肾的损伤就是[[renal/filtration]]与[[renal/tubular-function]]中描述的滤过与调节的器官的突然的损失：**一个带有正式分期标准的综合征、一个三个间隙的病因（肾前；肾小管与间质；以及肾小球血管的和梗阻的）、一个尿沉渣解读的传统、一小撮药物和脓毒症及手术的暴露使它成为住院的最常见的实验室的紧急，以及一个多数是支持性的精确的管理**——带着紧急的肾脏的替代治疗的指征和一份预防的清单。

本章涵盖定义与分期、病因的分类与尿的诊断、支持与替代的治疗，以及预防。

## 定义与识别

::: definition 分期的标准、流行病学与假性的升高 {#def-ak}
**分期KDIGO)：在48小时内肌酐上升26微摩尔每升；或在七天之内升至基线的1.5倍或以上（一期），2倍（二期）或3倍（三期）；或尿的每小时少于0.5毫升每公斤六小时，或每小时少于0.3毫升每公斤24小时，或新开始的肾脏的替代的治疗。分期按最严重的标准。假性的升高（在开始一条急性的路径之前先排除）：肌肉的量（横纹肌的溶解[[renal/potassium-calcium-phosphate]]）与干扰（酮与头孢及果糖的假性升高[[clinical-skills/laboratory-tests]]）、药物的阻断分泌（甲氧苄啶与西咪替丁和抗逆转录病毒）会升高肌酐而不降低滤过率（[[renal/filtration ]]）、梗阻的（[[#ex-postrenal ]]）以及实验室的变异。流行病学：住院的20%（在重症中更多）与手术的（心脏的大手术）与感染相关的；而这一章的事实是急性的损伤会转变为慢性的肾的疾病：一次急肾损伤的发作会提高之后的分期，尤其是重复的发作[[renal/chronic-kidney-disease]]。预防的登记与出院后的随访（一个复查的肌酐和尿的白蛋白，以及在高危者中的药物审查）会把发作变成机会（[[clinical-skills/records-handover ]]）。**
:::

::: definition 三个间隙的分类与尿的诊断 {#def-class}
**肾前的（灌注减少而肾小管完整：容量耗竭与出血和低血压及心输出量的下降[[cardiovascular/heart-failure]]与肝的[[gastrointestinal/liver-disease]]；药物的血液动力学的（非甾体与转换酶的阻断剂以及钠的丢失[[renal/filtration]]的三重的打击）；肾前性的诊断会保住钠（尿的钠低于20，钠的分数低于1，尿素的比例升高）——只是利尿剂与慢性肾病会让数字失真谎[[#ex-prerenal-diuretic]]）。内在的肾的：肾小管的坏死（缺血与毒物：对比剂与氨基糖苷和万古霉素及横纹肌的溶解、血红蛋白[[blood/haemoglobin-disorders]]）：颗粒浑浊棕色的管型，钠的分数通常大于2但旧的阈值并不可靠；间质的肾炎（药物性的：抗生素与非甾体，带着白色的细胞管型与无菌的脓尿和有时皮疹[[pharmacology/adverse-reactions]]、感染的和免疫的疾病）；肾小球的（急进性的肾炎与血管炎：红色细胞的管型与蛋白尿和系统的特征[[renal/chronic-kidney-disease]]、[[musculoskeletal/connective-tissue-vasculitis]]）；以及血管的（血栓性的微血管病[[blood/haemostasis-bleeding]]、胆固醇的栓塞[[#ex-athero]]、恶性的高血压[[cardiovascular/hypertension]]和肾动脉的事件）。肾后的（梗阻：前列腺与结石和腹膜后的纤维化[[renal/urinary-tract]]）：一个超声的肾盂；永远不要在急性时没有做过一次肾的成像或膀胱的扫描就下结论[[clinical-skills/medical-imaging]]。尿的套：沉渣（管型与细胞和结晶）；电解质（钠的分数与尿素的比例）；蛋白（白蛋白对肌酐）；以及培养在感染中[[clinical-skills/laboratory-tests]]。**
:::

::: example 不是肾前的那一幅图形 {#ex-prerenal-diuretic}
一位有慢性利尿剂的心衰患者在呕吐的三天后肌酐升高；尿的钠为60，钠的分数为3；临床上是低的容量；而停止利尿剂之后尿量会改善。
::: solution
**尿的数字被利尿剂弄坏：在最近的暴露后，被损害的钠的重吸收会人为地升高尿的钠和分数（[[#def-class]]、[[renal/water-sodium]]）。替代的指标：尿素的比例（升高的比率在肾前中，即使在利尿剂下）、尿的渗透（在肾前中高）、以及对容量补充的临床反应（肌酐下降和尿量增加）。这一临床的教训：检查会修改但不能推翻这个床边的容量的评估；而这一位患者需要被仔细调整的液体（心脏的患者会被过度补充[[cardiovascular/heart-failure ]]）、止吐与钾和镁的监测，以及一个利尿剂剂量的重新评估（被呕吐的患者的剂量在低容量时会造成发作[[geriatrics-palliative/polypharmacy ]]）。记录：尿的数字的解释必须与药物时间线一起读，否则它们会把人带到错误的路径上[[clinical-skills/clinical-reasoning]]。**
:::
:::

::: example 导管的实验室之后的后果 {#ex-athero}
在冠状动脉的介入后十天，肌酐会升到峰值，而脚的网状的青斑与青趾；嗜酸性细胞升高，而尿的沉渣大体温和。
::: solution
**胆固醇的栓塞（动脉粥样化的碎片被导管刮落）：一个迟发的（数天到数周）的急性的或亚急性的肾的损伤，带着皮肤的征象与青趾和嗜酸性的细胞的增多、补体的降低，以及常常在多个器官的缺血[[cardiovascular/coronary-artery-disease]]、[[renal/filtration]]、[[immunology/hypersensitivity]]。这与对比剂的肾病分岔（后者会在48到72小时达到高峰并在7天恢复[[renal/filtration]]）：一个延迟的进展和皮肤的发现与栓塞的其他部位（眼与胃肠[[gastrointestinal/gi-bleeding-cancer ]]）。没有被证明的治疗（他汀启停的辩论与补体的阻断的未定的试验）：支持性、避免再次插管、血运重建风险的重新讨论、以及肾的与血管的内外科的共同管理（[[surgery/vascular-urological-surgery]]）。提醒：抗凝在部分病例中会加剧发作；而预后的图形比对比剂更差——所以要早期标记患者的轨迹[[renal/chronic-kidney-disease]]。**
:::

::: example 会防止灾难的病房查房 {#ex-oliguric}
重症胰腺炎的第二天：尿量每小时0.3毫升每公斤持续八小时，尽管液体的剂量；体重累计正7升；钾6.4；碳酸氢盐13酸碱度7.18)；肌酐从90升到340；钙下降；血压靠去甲肾上腺素维持。
::: solution
**三期急的肾的损伤带着三个紧急的指征（[[#def-support]]）：难治的高钾与重度的酸中毒以及在去甲肾上腺素上正7升的容量负荷[[emergency-critical-care/critical-care]]、[[emergency-critical-care/shock-fluids]]。行动：同时（膜与转移（钙与胰岛素/葡萄糖[[renal/potassium-calcium-phosphate]]）与紧急的肾脏的替代治疗的启动（一个连续的策略因为血压低；剂量的处方按液体的目标）；碳酸氢盐作为桥梁而不是答案[[renal/acid-base-disorders]]）；以及这个胰腺炎与脓毒症的处理[[gastrointestinal/pancreas-biliary]]、[[infectious-diseases/fever-sepsis]]。错误：继续给剂量而等待尿，或用呋塞米试验去决定透析（他们不会把患者变成非透析的[[renal/filtration ]]）。记录：一个升级的触发（每小时的尿量与钾和酸碱的阈值）与一次到重症团队清楚的手交班[[clinical-skills/records-handover]]。**
:::
:::

::: definition 支持性的管理、肾脏替代的治疗与预防 {#def-support}
**支持性的精确：液体（在低容量中恢复灌注，但避免过多——正的平衡会预测这些不良的结局[[emergency-critical-care/shock-fluids]]与[[surgery/perioperative-care]]）、血压目标（平均的65与个体的灌注）、钾（[[renal/potassium-calcium-phosphate]]：在少尿的状态中避免钾的输入与库血）、酸（碳酸氢盐在选择性的情形中）、药物（肾的剂量的调整；避免非甾体；以及肾毒的组合的停用：三重的打击[[renal/filtration]]）；剂量（抗菌的按滤过率并按连续的策略的额外的剂量[[pharmacology/dosing-principles]]与[[immunology/transplant-tumour-immunology]]的抗排异的）；营养（在重症的损伤中不过度限制蛋白）与透析的线路的感染的预防[[clinical-skills/patient-safety]]。这些没有被证明的药物：呋塞米的试验不会预防或治疗（除了容量的管理），多巴胺肾剂量的神话已被埋葬，而利尿剂的组合只在容量的目标中[[cardiovascular/heart-failure]]。肾脏替代治疗的指征（难治的）：钾；酸；容量（肺水肿）；尿毒症的征象（心包炎与脑病）以及中毒（醇与水杨酸盐及锂[[emergency-critical-care/poisoning]]）——以及一个按血流动力学的选择：连续的（在低血压中更好耐受）对照间断的（更快的清除与更短的单位的时间）；时机（在没有其他指征时不追逐数字：大的试验未能显示早期策略的获益，除了选择性的情形[[renal/chronic-kidney-disease]]）；以及恢复（多数肾小管的坏死会恢复：多尿的阶段需要液体与电解质，而在数周内肌酐的下降是常见的轨迹[[#def-ak]]的曲线）。预防：高危者的识别（糖尿病与慢的肾的疾病及老的年龄和心衰）；对手术与对比剂对液体的优化和药物的暂停（非甾体与转换酶的阻断剂及利尿剂，以及在风险中的双胍[[endocrine/diabetes-complications]]）；以及急的肾的损伤的包（下面的练习[[#def-ak]]）。**
:::

::: example 抗胆碱的无尿 {#ex-postrenal}
一位79岁在用一种膀胱的药、带着抗组胺与鸦片及抗胆碱的处方清单的人，在关节替换的麻醉后第四天，12小时未排尿；肌酐从88升到210；膀胱可被触及；无热。
::: solution
**肾后的梗阻，在这个病例中是在膀胱的水平：抗胆碱的负担（膀胱的药加抗组胺加鸦片）在老年中会触发急性的尿潴留，而硬的膜外的麻醉会掩盖感觉[[geriatrics-palliative/polypharmacy]]与[[renal/urinary-tract]]、[[surgery/anaesthesia-pain]]。紧急的诊断与治疗：一个膀胱的扫描（或肾的超声，如果膀胱是空的——上段的梗阻需要肾盂的造瘘/支架[[clinical-skills/medical-imaging]]、[[renal/urinary-tract ]]）；导尿会解除并给出一个立即的缓解（双侧的肾积水会造成无尿）。后续：后梗阻的利尿（在解除之后的大的尿量与钠和钾及镁的损失[[renal/water-sodium]]、[[renal/potassium-calcium-phosphate ]]）、肌酐的轨迹（多数会在数天内恢复，而持续不恢复会提示实质的伤害[[renal/chronic-kidney-disease]]）、以及这个药物清单的修剪（抗胆碱负担的审查就是这里的预防）与一个排尿的计划（男性下尿路的疾病[[renal/urinary-tract]]）。这一整件事是可预防的[[clinical-skills/patient-safety]]。**
:::

::: history
**这一章是医院医学的历史：从术后的与创伤的急性肾小管坏死的最初的描述与少尿的死亡，到透析让病例变得可存活的时代（在人身上被开发的间断的透析[[renal/chronic-kidney-disease ]]），到加重的损伤与多器官的衰竭的重症的照护（连续的策略从九十年代起）；对比剂与药物性的间质的肾炎的识别（把皮疹与嗜酸性的细胞的关联先当作真理然后当作神话）；分期的尝试（风险与损伤及失败的标准，然后2012年的统一），以及急性的肾的损伤作为住院的可预防的伤害的宣言（国家的审计与急的肾的损伤的项目[[clinical-skills/patient-safety]]与[[public-health/health-systems-economics]]）；以及把急到慢的转换变为随访的政策的队列（[[renal/chronic-kidney-disease]]）。时机的试验（早对晚）会总结这一章的现代的姿态：指征是并发症，而不是数字。**
:::

## 通向何处

滤过的生理学在机制之上在[[renal/filtration]]；肾小管的损伤在[[renal/tubular-function]]；钾与酸碱的危险在[[renal/potassium-calcium-phosphate]]与[[renal/acid-base-disorders]]；肾后的疾病在[[renal/urinary-tract]]；慢性的轨迹在[[renal/chronic-kidney-disease]]；液体的管理在[[emergency-critical-care/shock-fluids]]；对比剂与手术的预防在[[clinical-skills/medical-imaging]]与[[surgery/perioperative-care]]；以及药物在机制中在[[pharmacology/adverse-reactions]]。

::: exercise 诊断硬化的肾 {level=2}
一位失代偿的肝硬化（腹水，自发细菌性的腹膜炎在五天前被治疗）肌酐从68升到132，尽管白蛋白充足的治疗并停用利尿剂；尿的钠为8，沉渣温和，超声正常，没有休克也没有肾毒的。给这个综合征与它的生理和治疗的阶梯。
::: solution
**肝肾的综合征（一型）：因为内脏的血管扩张和动脉的充盈减少，被压力感受器读作低容量，肾的血管的收缩把滤过降低[[gastrointestinal/liver-disease]]、[[renal/water-sodium]]、[[#def-class]]（一个肾前的图形，带一个温和的沉渣与低的尿的钠，而在没有对液体的反应时）。阶梯：停用利尿剂并给白蛋白（一个充分两天的试验）；然后血管的收缩剂（特利加压素或去甲肾上腺素或血管加压素）加白蛋白；把感染识别并治疗（自发性细菌性腹膜炎的预防）[[infectious-diseases/healthcare-infections]]；避免肾毒的药物与对比剂；以及移植的讨论（一个肝的移植会治愈这个肾，而肾的替代的治疗作为桥梁）[[gastrointestinal/liver-disease]]与[[renal/chronic-kidney-disease]]。鉴别：急性肾小管的坏死（一个沉渣与尿的钠升高、暴露）与梗塞（[[cardiovascular/vascular-disease]]）和单纯的利尿剂相关的发作[[geriatrics-palliative/polypharmacy]]。**
:::

::: summary
- 急性的肾的损伤被肌酐的轨迹与尿量定义（标准），为风险分期，并且总是一个预后事件：每一次发作都会把慢性的肾的疾病的随访排进日程。
- 快速地分入三个间隙：肾前（纠正灌注）；内在的（读沉渣：浑浊的管型就是肾小管的坏死，而白色的细胞的管型加药物时间线就是间质的肾炎，以及红色的细胞的管型就是肾小球的紧急，以及皮肤加波动就是动脉粥样化的栓塞），肾后（超声并减压——在无尿时梗阻直到被证明别的）。
- 尿的指标（钠的分数与尿素的比例）只在背景下有帮助——利尿剂与慢的肾的疾病会使它们无效；临床充盈的评估与轨迹会胜过任何单一的数字。
- 管理是支持性的精确：移除原因；液体与离子和酸碱的纪律；药物的重新计算；以及按并发症触发肾脏替代的治疗（钾与酸碱及容量与尿毒症和中毒），带着支持观望的早对晚的时机的试验。
- 预防是系统的工作：对比剂的卫生；围手术液体的默认；生病时的规则；以及药物的登记——多数医院急的肾的损伤是医源性的并可被预测。
:::

## 练习

::: exercise 为急的肾的损伤分期 {level=1}
肌酐88（已知的基线）在第二天到156，第三天到240；尿量每小时0.4毫升每公斤十小时。给出分期与它的演进的逻辑。
::: solution
**第二天：156就是基线的1.77倍——一期；第三天：240是2.7倍——接近三期的阈值3倍但没有达到，所以按肌酐仍是一期；而尿量（每小时0.4持续十小时）符合一期（每小时0.5以下持续六小时以上）。分期按最严重的标准并逐日重新评估：一个上升的轨迹比一个单一的值更重要（[[#def-ak]]）。操作的含义：分期会驱动审查（药物的剂量与肾毒的药物）、监测的频率（钾与酸碱及容量）与升级的阈值[[clinical-skills/patient-safety]]、[[pharmacology/dosing-principles]]。提醒：基线的缺失会让分期不确定，而一个突然的升高可能是一个急到慢的发作——所以要寻找慢的标志（贫血与小的肾[[renal/chronic-kidney-disease]]）。**
:::

::: exercise 计算并给出告诫 {level=2}
尿的钠32，血浆的钠138，尿的肌酐每升6毫摩尔，血浆的肌酐每升138微摩尔：计算钠的分数，并在一个服呋塞米的人与一个肝硬化患者中解读。
::: solution
**钠的分数等于（尿的钠除以血浆的钠）除以（尿的肌酐除以血浆的肌酐）乘100：(32/138)/(6000/138)乘100约等于0.55%：低于1，符合一个肾前的、保住钠的状态[[#def-class]]。然而：在呋塞米下这个分数会假性正常化（利尿剂会排出钠），所以尿素的比例会更有用；而在肝硬化中低的分数反映生理（充盈减少）而治疗就是充盈与病因（[[#def-support]]、[[gastrointestinal/liver-disease]]）。普遍的规则：指标会被药物与慢的肾的疾病破坏[[renal/chronic-kidney-disease]]；而梗阻与肾小球的疾病会给出低的分数——所以数字永远不会替代这个超声与沉渣[[clinical-skills/medical-imaging]]。**

::: exercise 匹配沉渣 {level=2}
把每一个尿的发现与它可能的间隙配对：(a) 浑浊棕色颗粒的管型；(b) 棘形的红细胞与红色的细胞的管型伴蛋白尿；(c) 白色细胞的管型与无菌的脓尿；(d) 草酸的钙的结晶；(e) 大体温和与无尿。
::: solution
**（a）肾小管的坏死（缺血与毒物）[[#def-class]]；（b）肾小球的（急进性的肾炎与血管炎——紧急[[renal/chronic-kidney-disease]]、[[musculoskeletal/connective-tissue-vasculitis]]）；（c）间质的肾炎（药物[[pharmacology/adverse-reactions]]）与感染；（d）草酸盐（乙二醇的中毒与肠的草酸盐的过多[[emergency-critical-care/poisoning]]、[[gastrointestinal/bowel-disease ]]）以及结石[[renal/urinary-tract]]；（e）肾后的（一个完全梗阻）或血管的（梗塞与皮质的坏死[[cardiovascular/vascular-disease]]）——而无尿会把梗阻与血管的事件以及重度的肾小管的坏死带进来[[#ex-postrenal]]。规则：沉渣是便宜的活检，而它们会先于血清学[[clinical-skills/laboratory-tests]]。**

::: exercise 对比剂的那一天 {level=2}
一个三b期的慢肾疾病的糖尿病患者（滤过率38，服用双胍与转换酶的抑制剂和噻嗪）来做一个对比剂的计算机断层。给出围操作的计划与扫描后的规则。
::: solution
**风险：慢性肾的疾病与糖尿病（尽管新的证据会对第二代的对比剂的风险更安心）[[renal/chronic-kidney-disease]]、[[clinical-skills/medical-imaging]]。术前：确认必要性（这个扫描会改变管理？替代的超声与这些不增强方案？）；用等张的晶体在前后（高风险者；口服的没有用）；暂停非甾体与利尿剂，并在风险中把转换酶的抑制剂暂时移出；把双胍在扫描日暂停并在48小时与复查的肌酐之后重新开始（乳酸酸中毒的风险，而不是对比剂的）[[endocrine/diabetes-complications]]。术后：避免另一次负荷；监测轨迹（在48到72小时达到高峰并在7到10天恢复[[renal/filtration]]）；教育（生病时的规则）；以及一个复查的预约。被移除的做法：盲目的液体与乙酰半胱氨酸的神话与术后常规透析[[renal/chronic-kidney-disease]]。**

::: exercise 决定肾脏替代的治疗 {level=2}
列出在急的肾的损伤中启动肾脏替代治疗的并发症的触发，并解释为什么一个孤立的肌酐600不算一个。
::: solution
**难治的并发症：钾（对医学的治疗的反射性的高钾）；酸碱（重度的酸中毒，尤其是在容量的限制中）；容量（带着利尿剂抵抗的肺水肿[[cardiovascular/heart-failure]]）；尿毒症（心包炎与脑病及这些不能解释的癫痫发作[[geriatrics-palliative/delirium-dementia-care]]）；中毒（可清除的：醇与水杨酸盐及锂[[emergency-critical-care/poisoning ]]）；以及难以控制的体温与液体策略在特殊情形中[[emergency-critical-care/critical-care]]。为什么一个数字不是指征：肌酐本身不造成症状，而早对晚的时机的试验（除了选择性的情形）没有显示常规早期启动的生存获益，并会造成更多的导管与低血压[[renal/chronic-kidney-disease]]。实际的：设定阈值并记录，为恢复留出时间（多数肾小管的坏死恢复[[#def-support]]）以及共享的决策，因为连续与间断的选择是血流动力学的一个决定。**
:::

::: exercise 识别微血管病 {level=2}
产后第6天：急性的肾的损伤，血小板55，溶血的（乳酸脱氢的升高与结合珠蛋白的低及破碎的红细胞），意识混乱，凝血正常；头的计算机断层清晰。给这个综合征、第一个小时的行动以及陷阱。
::: solution
**一个血栓性的微血管病：在产后补体的疾病（非典型性的溶血尿毒）与ADAMTS13的缺乏（免疫性血栓性的血小板减少性紫癜）都会造成一个微血管病的溶血伴血小板减少与肾的损伤，凝血正常（把它们与弥散性的血管内的凝血分开[[infectious-diseases/fever-sepsis]]、[[blood/haemostasis-bleeding ]]）。陷阱：把意识混乱归因于其他，或在等待测试时延迟血浆的交换（ADAMTS13的活动与抑制物；补体的测试[[immunology/hypersensitivity]]）——第一个小时：血浆的交换（如果神经的征象，为ADAMTS13的缺乏治疗），红细胞的支持，避免血小板的输注除非出血[[blood/transfusion]]，以及肾的替代在需要时[[#def-support]]。共同管理：产科与肾和血液[[obstetrics-gynaecology/pregnancy-complications]]、[[renal/chronic-kidney-disease]]；补体的阻断在非典型的病例中[[renal/chronic-kidney-disease]]。**

::: exercise 建设急的肾损伤预防的服务 {level=3}
设计一个全院急肾损伤的预防与响应的程序：监测、包的触发、药物的和解的接口，以及结局的审计。
::: solution
**监测：从实验室对肌酐的轨迹（规则：上升超过26或在七天内1.5倍）自动地旗标，并把警告发到团队的记录上；在风险中（重症与心脏手术与对比剂及败血症）对尿量的测量[[surgery/perioperative-care]]、[[clinical-skills/laboratory-tests]]。包：急的肾的损伤一小时的包（确认分期；药物的审查与肾毒的暂停；钾与酸碱；灌注的评估；超声在梗阻中；以及一个升级的电话）[[renal/chronic-kidney-disease]]。药物的接口：在旗标时开药的中断；肾的剂量的检查与生病时的规则的教育和药物的登记（非甾体与三重）[[pharmacology/adverse-reactions]]、[[geriatrics-palliative/polypharmacy]]。出院：一个记录在案的随访（复查的肌酐与尿的白蛋白）以及一个患者的卡片[[renal/chronic-kidney-disease]]、[[clinical-skills/records-handover]]。审计：发病率与分期及这些可预防的比例（对比剂与围手术的）；随访的完成；以及在死亡或伤害后的审查[[clinical-skills/patient-safety]]、[[public-health/health-systems-economics]]。**
