急性肾损伤（AKI）是肾功能在数小时到数天内突然下降。它常见，往往无症状，而且常常是可以预防的。它见于很大比例的急诊入院患者，尤其是老年人，并影响许多重症监护患者。大多数病例不是由原发性肾脏疾病引起的，而是由其他环节出了问题：脱水、脓毒症、心力衰竭、某种药物、膀胱梗阻。肾脏是揭示身体其他部位病得有多重的器官。

AKI之所以重要有三个原因。它带来即刻的危险：高钾血症、酸中毒、液体过负荷和药物蓄积。即使是轻度AKI也与较高的死亡率相关，且风险随分期升高。AKI的幸存者以后更可能发展为慢性肾脏病。

本课时定义AKI并进行分期，说明如何用三分类法寻找病因，并阐述处理原则、透析指征和预防。它以[[renal/filtration]]（GFR和肌酐）、[[renal/water-sodium]]（容量）和[[renal/potassium-calcium-phosphate]]（高钾血症）为基础。全课时引用的英国框架是NICE指南NG148（2019），它采用KDIGO的定义。

## 定义与分期

::: definition KDIGO的AKI定义与分期 {#def-ak}
KDIGO（改善全球肾脏病预后组织，2012）对**急性肾损伤**的定义为符合下列任一项：

- **48小时内**血清肌酐升高**26.5 µmol/L（0.3 mg/dL）或以上**；
- 已知或推测在**过去7天内**血清肌酐升高至**基线的1.5倍或以上**；
- 尿量**低于0.5 mL/kg/h持续6小时或以上**。

AKI**按肌酐或尿量标准中分期较高者进行分期**：

| 分期 | 血清肌酐 | 尿量 |
|---|---|---|
| 1 | 基线的1.5～1.9倍，或升高26.5 µmol/L或以上 | 低于0.5 mL/kg/h持续6～12小时 |
| 2 | 基线的2.0～2.9倍 | 低于0.5 mL/kg/h持续12小时或以上 |
| 3 | 基线的3.0倍或以上，或肌酐354 µmol/L（4.0 mg/dL）或以上，或已开始肾脏替代治疗 | 低于0.3 mL/kg/h持续24小时或以上，或无尿12小时或以上 |

肾功能下降持续7～90天称为**急性肾脏病**（AKD）；超过90天则符合慢性肾脏病的定义。
:::

这一定义的设计着眼于灵敏度。肌酐的小幅升高也算在内，因为即使小幅升高也预示较差的结局。代价是有些“AKI”并不是真正的肾损伤。进食肉类后，或使用阻断肾小管肌酐分泌的药物（如甲氧苄啶）时，肌酐可轻度升高。单次升高的数值应结合临床表现解读并复查。

**基线**肌酐是此前三个月内的最低值；若有，也可用三到十二个月前数值的中位数。在英格兰，实验室运行自动化的AKI算法，把每次肌酐与此前结果比较，并发出**AKI预警分期**提醒临床医生。

### 为什么肌酐滞后

肌酐不是很好的实时标志物。GFR突然下降时，肌酐仍在生成并逐渐蓄积，直到达到新的稳态。所需时间取决于新的GFR。

这种滞后有两个后果。在最初一两天内肌酐低估AKI的严重程度，所以**尿量**往往是更早的预警。由不断上升的肌酐计算的eGFR会高估真实GFR，所以在肌酐变化期间不应用eGFR评估AKI或确定药物剂量（[[renal/filtration]]）。

## 寻找病因

::: definition 肾前性、肾性和肾后性AKI {#def-class}
**肾前性AKI**是肾灌注减少引起的GFR下降，肾脏本身结构完整。病因包括低血容量（出血、呕吐、腹泻、利尿药、摄入不足）、低血压（脓毒症、心源性休克）、有效容量减少（心力衰竭、肝硬化）以及损害自身调节的药物（非甾体抗炎药、ACE抑制剂、血管紧张素受体阻滞剂）。恢复灌注后可迅速逆转。持续或严重的低灌注会进展为肾小管损伤。

**肾性AKI**是肾脏本身的损伤：
- **急性肾小管损伤**（常称急性肾小管坏死，ATN），最常见的肾性病因，由缺血、脓毒症或毒物（氨基糖苷类、碘对比剂、横纹肌溶解中的肌红蛋白、骨髓瘤中的轻链）引起；
- **急性间质性肾炎**，通常为药物反应（质子泵抑制剂、青霉素类、非甾体抗炎药、免疫检查点抑制剂）或感染引起；
- **肾小球肾炎**，尤其是急进性类型（ANCA相关血管炎、抗GBM病、狼疮）；
- **血管性**疾病：血栓性微血管病、胆固醇栓塞、肾动脉或肾静脉闭塞、恶性高血压。

**肾后性AKI**是从肾盂到尿道任何部位的尿流梗阻。梗阻必须累及双侧肾脏或唯一有功能的肾脏才会引起AKI。常见病因有前列腺增大、药物或便秘引起的尿潴留、结石、盆腔肿瘤和导尿管堵塞。
:::

实践中，按固定顺序问几个问题就能找到病因。

1. **是否有梗阻？**检查有无可触及的膀胱，进行膀胱扫描，确认导尿管通畅。NICE NG148建议，在未找到病因或怀疑梗阻时，**24小时内**行急诊泌尿系超声；若怀疑感染性梗阻肾（脓肾），则在**6小时内**进行。
2. **灌注是否不足？**评估容量状态、相对于平时水平的血压、心力衰竭和脓毒症。
3. **是否有肾毒性物质？**审查每一种药物、近期对比剂使用，以及横纹肌溶解或溶血的原因。
4. **是否有肾实质病变的证据？**每一位AKI患者都要做尿试纸检查。尿试纸示血和蛋白、且没有导尿管或感染等明显的其他解释时，提示肾小球肾炎，需要紧急检查并与肾内科医生讨论。

### 尿液检查

**尿沉渣**直接提供来自肾脏的证据。泥棕色颗粒管型和肾小管上皮细胞提示急性肾小管损伤。红细胞管型和畸形红细胞提示肾小球肾炎。白细胞管型和无菌性脓尿提示间质性肾炎。

尿钠说明肾小管是否仍在保钠。肾前性AKI时，完整的肾小管强烈重吸收钠，尿钠低；肾小管损伤时，钠的处理失灵，更多钠漏出。

::: theorem 钠排泄分数 {#thm-fena}
**钠排泄分数**（FENa）是滤过的钠中被排出的百分比：

$$
\text{FENa} (\%) = \frac{U_{Na} \times P_{Cr}}{P_{Na} \times U_{Cr}} \times 100
$$ {#eq-fena}

在少尿性AKI中，FENa**低于1%**提示肾小管功能完整的肾前性状态；高于**2%**提示肾小管损伤。使用过利尿药时，**尿素排泄分数**受影响较小；低于约35%提示肾前性状态。
:::

::: proof
排泄分数是排出的钠除以滤过的钠。每分钟排出的钠为$U_{Na} V$。滤过的钠为$\text{GFR} \times P_{Na}$，GFR可用肌酐清除率$U_{Cr} V / P_{Cr}$估计。所以

$$
\text{FENa} = \frac{U_{Na} V}{(U_{Cr} V / P_{Cr}) \times P_{Na}} = \frac{U_{Na} P_{Cr}}{P_{Na} U_{Cr}}
$$

尿流率$V$被约去，所以FENa可以用随机样本计算。用与肌酐的比值校正了尿液的浓缩程度，这是单看尿钠做不到的。

FENa只是参考。在某些肾性病因中它偏低（对比剂肾病、横纹肌溶解、早期脓毒症、肾小球肾炎），而在利尿药阻断了钠重吸收或慢性肾脏病限制了保钠能力的肾前性状态中它偏高。尿素主要在近端小管重吸收，位于袢利尿药和噻嗪类利尿药作用部位的上游，所以即使使用利尿药，肾前性状态下其排泄分数仍然偏低。
:::

::: example 被利尿药掩盖的肾前性表现 {#ex-prerenal-diuretic}
一名80岁心力衰竭男性服用呋塞米。食欲差和腹泻一周后，他的肌酐从110升至220 µmol/L。血压96/60 mmHg（平时135/80），站立时头晕。尿钠45 mmol/L，血浆钠134 mmol/L，尿肌酐8 mmol/L。尿尿素200 mmol/L，血浆尿素20 mmol/L。计算FENa和尿素排泄分数并解读。
::: solution
把肌酐换算为同一单位：$U_{Cr} = 8000$ µmol/L，$P_{Cr} = 220$ µmol/L。

$$
\text{FENa} = \frac{45 \times 220}{134 \times 8000} \times 100 = 0.92\%
$$

尿素排泄分数：

$$
\text{FEUrea} = \frac{200 \times 220}{20 \times 8000} \times 100 = 27.5\%
$$

他的肌酐翻倍：**AKI 2期**。低血压、体位性头晕和液体丢失的临床表现提示**肾前性**病因。由于呋塞米阻断钠重吸收，他的尿钠45看起来“偏高”，但FENa略低于1%，FEUrea低于35%，二者都符合肾前性状态。

处理：在他容量不足期间暂停呋塞米和任何ACE抑制剂，谨慎补液并频繁再评估（心力衰竭限制了他能耐受的液体量），监测尿量和肌酐，恢复后作为计划复查的一部分重新开始心力衰竭用药。
:::
:::

::: example 导管室之后 {#ex-athero}
一名72岁吸烟男性经股动脉接受冠状动脉造影和支架置入。三周后，他的肌酐从120升至310 µmol/L。他的脚趾出现疼痛的紫色斑驳，双腿有网状皮疹（网状青斑），嗜酸性粒细胞增多，补体水平低。可能的病因是什么？时间进程有何帮助？
::: solution
这是**胆固醇栓塞（动脉粥样栓塞性肾病）**。导管在有粥样硬化的主动脉内操作时使胆固醇结晶脱落，栓塞于肾脏、皮肤和肠道的小动脉，引发炎症。嗜酸性粒细胞增多和低补体常见。

时间进程可将其与**对比剂相关AKI**区分：碘对比剂之后，肌酐通常在24～72小时内升高，并在一到两周内恢复；而动脉粥样栓塞性AKI常在数天到数周后出现，呈阶梯式进展，常恢复不完全。治疗是支持性的：尽可能避免再次血管操作，控制血压，针对基础动脉粥样硬化使用他汀类。通常避免抗凝，因为它可能促进进一步栓塞。
:::
:::

## 处理

::: definition AKI的处理原则 {#def-support}
没有药物能治愈受损的肾脏。处理的目标是**去除病因、恢复灌注、防止进一步损伤并治疗并发症**，直至肾脏恢复。与NICE NG148一致的核心措施为：

- **评估并纠正容量状态**：给低血容量者补液，并频繁再评估；避免液体过负荷，它会使结局恶化；
- 休克时**恢复血压**，必要时在重症监护中使用血管升压药；
- 及时**治疗脓毒症**；
- **审查每一种药物**：停用肾毒性药物（非甾体抗炎药，尽可能停用氨基糖苷类），暂停损害自身调节或加重容量不足的药物（ACE抑制剂、血管紧张素受体阻滞剂、利尿药），暂停会蓄积并造成伤害的药物（二甲双胍、某些口服降糖药），并调整经肾清除药物的剂量；
- 用导尿管**解除梗阻**，上尿路梗阻则行肾造瘘或输尿管支架置入；
- **监测**尿量、液体平衡、体重、肌酐和钾；
- 以下情况**转诊肾内科**：怀疑肾实质病变（包括肾小球肾炎）、AKI 3期、并发症对内科治疗无反应，或肾移植受者发生AKI。
:::

袢利尿药不能治疗AKI，也不改善结局，但在肾脏仍有反应的人中可帮助处理液体过负荷。

**肾脏替代治疗**（RRT；透析或血液滤过）在肾脏恢复期间替代肾功能。其指征是危及生命且对内科治疗无反应的并发症：

- 内科治疗后仍持续的**高钾血症**；
- 严重且难治的**代谢性酸中毒**；
- 利尿药无效的**液体过负荷**，尤其是肺水肿；
- **尿毒症并发症**：心包炎、脑病、尿毒症血小板功能障碍引起的出血；
- 可透析毒物**中毒**，如锂、甲醇、乙二醇或水杨酸。

在出现这些并发症之前更早地开始RRT，并未显示能提高生存率。在STARRT-AKI试验（2020）中，对重度AKI危重患者采取加速策略，与标准策略相比并未降低90天死亡率，且与90天时更多的透析依赖相关。因此RRT通常因明确的指征而开始，而不是因某个数值。

::: example 防止危机的一次查房 {#ex-oliguric}
一名68岁女性因肺炎入院。第2天，她的肌酐从70 µmol/L（基线）升至150 µmol/L。她体重60 kg，过去12小时排尿220 mL。血压92/50 mmHg（平时130/80）。她服用雷米普利、呋塞米、二甲双胍和萘普生（naproxen），均仍在医嘱中。血钾5.7 mmol/L。对AKI进行分期并列出处理措施。
::: solution
**肌酐**：$150/70 = 2.14$倍基线，2期。

**尿量**：$220 / 12 / 60 = 0.31$ mL/kg/h，持续12小时，低于0.5达12小时或以上：2期。

**AKI 2期**，最可能是**脓毒症**伴低血压引起的肾前性损伤并向肾小管损伤进展，损害自身调节的药物使其加重。

**措施**：
- 按脓毒症路径治疗肺炎和脓毒症；评估容量并给予补液冲击后再评估；
- **停用萘普生**；在她低血压和容量不足期间暂停雷米普利和呋塞米；暂停二甲双胍（AKI时有乳酸酸中毒风险）；审查抗生素剂量；
- 每小时测尿量，若需要准确监测可考虑留置导尿；
- 尿试纸检查；若无改善或无明确病因，考虑超声；
- 通过停用相关药物处理轻度高钾血症并复查血钾；警惕中度或重度高钾血症；
- 至少每天复查肌酐和钾，若补液后低血压仍持续则升级至重症监护。

恢复后，出院小结中应写明重新开始常规用药的计划和随访肌酐的安排。
:::
:::

::: example 抗胆碱能药引起的无尿 {#ex-postrenal}
一名79岁良性前列腺增大男性因瘙痒开始服用一种有抗胆碱能作用的抗组胺药。三天后他下腹痛，只能排出点滴尿液，并出现意识模糊。肌酐340 µmol/L（基线95），血钾6.2 mmol/L。膀胱扫描示1400 mL。解释并概述处理，包括治疗后可能出现的情况。
::: solution
前列腺增大男性使用抗胆碱能药物引起**急性尿潴留**，导致**肾后性AKI**，3期（肌酐超过基线3倍）。逆向压力使双侧肾脏GFR下降。

**处理**：经尿道导尿（失败则耻骨上造瘘），停用抗组胺药，处理中度高钾血症并监测。若梗阻时间短，肌酐通常在数天内下降。

严重梗阻解除后可出现**梗阻后利尿**：尿量可在数小时内超过200 mL/h。它由潴留的盐、水和尿素排出以及暂时受损的肾小管浓缩功能引起。大部分利尿是恰当的，但有些人丢失过多，出现容量不足或钠、钾紊乱。因此要密切监测液体平衡、体重和电解质，并根据临床状态补充部分丢失量。在尝试拔除导尿管之前应评估他的前列腺（[[renal/urinary-tract]]）。
:::
:::

::: warning 不要等待肌酐 {#warn-aki}
肌酐比损伤滞后一天或更久，所以在病程早期肌酐“正常”或仅轻度升高并不能排除AKI。不适患者尿量减少是更早的预警，但前提是有人在测量。第二个常见错误是在急性疾病期间“自动”续开药物：在脱水或脓毒症患者中继续使用非甾体抗炎药、ACE抑制剂、利尿药和二甲双胍，会把可逆的问题变成危险的问题。AKI的每个阶段都要审查用药医嘱。
:::

## 特殊情况与预防

**对比剂相关AKI。**碘对比剂可使肌酐在24～72小时内升高，不过现代研究提示，扫描后所见的AKI很大程度上是由促使进行扫描的疾病本身引起的。eGFR低于30 mL/(min·1.73 m²)、糖尿病和心力衰竭者风险最大。NICE NG148建议，对eGFR低于30或肾移植的成人考虑静脉扩容（用0.9%盐水或等渗碳酸氢钠），并对AKI患者暂停二甲双胍。不应因为担心AKI而放弃必需的增强扫描。

**横纹肌溶解。**肌肉破坏（挤压伤、跌倒后长时间不能活动、极限运动、癫痫发作、他汀类与相互作用药物合用、某些娱乐性药物）释放肌红蛋白、钾和磷。肌红蛋白损伤肾小管。肌酸激酶明显升高，尿试纸示隐血阳性而无红细胞。早期充分的液体复苏是主要治疗，并密切关注血钾。

**肝肾综合征。**在晚期肝硬化中，强烈的肾血管收缩可在肾脏本身正常的情况下引起AKI。在白蛋白扩容无效并排除其他病因后诊断，在专科治疗下使用特利加压素等血管收缩药加白蛋白（[[gastrointestinal/liver-disease]]）。

**预防**比治疗更有效。这意味着识别高危人群（高龄、慢性肾脏病、糖尿病、心力衰竭、肝病、脓毒症、低血容量、肾毒性药物、近期使用对比剂、大手术），保持其水化，有替代方案时避免肾毒性药物，急性疾病期间监测肌酐和尿量，并给服用ACE抑制剂、血管紧张素受体阻滞剂、利尿药、二甲双胍和非甾体抗炎药的人提供明确建议，在发生脱水性疾病时暂停这些药物（“患病日指导”）。

::: quiz
一名54岁女性因消化不良开始服用奥美拉唑。六周后，她的肌酐从75升至210 µmol/L。她有低热和淡淡的皮疹。尿试纸示白细胞2+、蛋白1+、亚硝酸盐阴性，培养无菌生长。最可能的诊断是什么？
- [ ] 容量不足引起的肾前性AKI
- [ ] 急性肾盂肾炎
- [x] 急性间质性肾炎
- [ ] 对比剂引起的急性肾小管损伤
::: solution
开始使用新药数周后发生AKI，伴发热、皮疹和无菌性脓尿，是**药物性急性间质性肾炎**的典型表现。质子泵抑制剂是最常见的病因之一；许多人只有部分典型特征。通常的治疗是停用该药；有时在专科建议下给予糖皮质激素，诊断不确定时肾活检可确诊。亚硝酸盐阴性和培养无菌不支持感染。
:::
:::

::: history
1940—1941年伦敦大轰炸期间，拜沃特斯（Eric Bywaters）和比尔（Desmond Beall）描述了从倒塌建筑中救出、肢体被压数小时的人。这些伤者起初看起来情况良好，随后出现休克、深色尿和肾衰竭，并在数天内死亡。他们1941年发表在《英国医学杂志》（*British Medical Journal*）上的报告《伴肾功能损害的挤压伤》把肌肉损伤与肾衰竭联系起来，后来的工作确定肌红蛋白是罪魁祸首。挤压综合征的经验，即早期补液和关注血钾，至今仍应用于地震和建筑倒塌之后。同一场战争期间，科尔夫（Willem Kolff）在荷兰制造了第一台实用的人工肾，并于1945年挽救了第一位急性肾衰竭患者。
:::

## 后续内容

有些人不能从AKI中恢复，进展为急性肾脏病，再进展为慢性肾脏病，相关内容见[[renal/chronic-kidney-disease]]，其中还包括可以表现为AKI的各种肾小球肾炎。休克、液体复苏和器官支持见[[emergency-critical-care/shock-fluids]]和[[emergency-critical-care/critical-care]]。肾功能减退时的药物剂量见[[pharmacology/dosing-principles]]，术后AKI见[[surgery/perioperative-care]]。

::: summary
- AKI（KDIGO）：48小时内肌酐升高26.5 µmol/L或以上，或7天内升至基线的1.5倍，或尿量低于0.5 mL/kg/h持续6小时或以上。
- 按肌酐和尿量中较重者分期：1期（1.5～1.9倍；低于0.5 mL/kg/h持续6～12 h），2期（2.0～2.9倍；低于0.5 mL/kg/h持续12 h或以上），3期（3倍或以上、肌酐354 µmol/L或以上或开始RRT；低于0.3 mL/kg/h持续24 h或以上，或无尿12 h或以上）。
- 肌酐滞后于损伤；肌酐变化期间eGFR无效；尿量是更早的信号。
- 将病因分为肾前性、肾性（肾小管、间质、肾小球、血管）或肾后性。始终寻找梗阻，做尿试纸检查并审查用药。
- FENa低于1%提示肾前性状态；使用利尿药后FEUrea低于约35%更可靠。
- 处理：治疗病因，恢复灌注，停用肾毒性药物，在病程中暂停ACE抑制剂、血管紧张素受体阻滞剂、利尿药和二甲双胍，解除梗阻，监测血钾和液体。
- RRT用于难治性高钾血症、酸中毒、液体过负荷、尿毒症并发症或可透析毒物中毒；更早的常规开始并不提高生存率。
:::

## 习题

::: exercise AKI分期 {level=1 check="2"}
一名男性基线肌酐90 µmol/L。因胃肠炎入院两天后肌酐为250 µmol/L。过去8小时他的尿量为0.4 mL/kg/h。他的AKI是KDIGO几期？以数字表示。
::: solution
肌酐比值$= 250/90 = 2.78$，在2.0～2.9范围内：**2期**。尿量低于0.5 mL/kg/h持续8小时，按尿量为1期。分期取较重者，所以为**2**期。
:::
:::

::: exercise 匹配尿沉渣 {level=1}
将下列尿镜检结果与最可能的肾性AKI病因配对：(a) 红细胞管型；(b) 泥棕色颗粒管型；(c) 白细胞管型伴无菌性脓尿；(d) 尿试纸隐血3+而镜检无红细胞。
::: solution
(a) 肾小球肾炎。(b) 急性肾小管损伤。(c) 急性间质性肾炎（若存在感染则为肾盂肾炎）。(d) 横纹肌溶解引起的肌红蛋白尿（或血管内溶血引起的血红蛋白尿）。
:::
:::

::: exercise 透析指征 {level=1}
列出AKI中紧急肾脏替代治疗的五项指征。
::: solution
内科治疗无效的高钾血症；治疗无效的重度代谢性酸中毒；利尿药无效的液体过负荷（尤其是肺水肿）；尿毒症并发症，如心包炎或脑病；以及可透析物质中毒，如锂、甲醇、乙二醇或水杨酸。
:::
:::

::: exercise 计算FENa {level=2 check="round(10*200/(135*12000)*100*100)/100"}
一名少尿患者：尿钠10 mmol/L，血浆钠135 mmol/L，尿肌酐12 mmol/L，血浆肌酐200 µmol/L。计算FENa百分比，保留两位小数，并解读。
::: solution
$U_{Cr} = 12\,000$ µmol/L。

$$
\text{FENa} = \frac{10 \times 200}{135 \times 12\,000} \times 100 = 0.12\%
$$

远低于1%：肾小管在强烈保钠，符合**肾前性**状态（假设未使用利尿药）。应评估患者是否有低血容量或灌注不良；FENa是辅助检查，不能替代临床评估。
:::
:::

::: exercise 对比剂检查日 {level=2}
一名66岁2型糖尿病女性，eGFR 26 mL/(min·1.73 m²)，因怀疑肠癌需要做增强CT。她服用二甲双胍、雷米普利和呋塞米。概述降低其AKI风险的原则。
::: solution
若诊断需要，不应放弃扫描。eGFR低于30，她符合NICE NG148考虑围检查期静脉扩容（0.9%盐水或等渗碳酸氢钠）的阈值，按当地方案执行。审查用药：当地指南常建议eGFR降低者在对比剂检查前后暂停二甲双胍，确认肾功能稳定后再恢复；若她容量不足，考虑暂停利尿药。使用能获得诊断性图像的最低对比剂剂量。扫描后48～72小时复查肌酐。
:::
:::

::: exercise 识别血栓性微血管病 {level=2}
一名6岁男孩参观农场后出现血性腹泻四天，随后面色苍白、尿少。血红蛋白72 g/L，血涂片见破碎红细胞，血小板38 × 10⁹/L，肌酐290 µmol/L。诊断是什么？机制是什么？
::: solution
**溶血尿毒综合征**（HUS），由**产志贺毒素的*大肠埃希菌***（常为O157:H7）引起，通常经农场动物、未煮熟的肉或污染的食物获得。毒素损伤肾小球内皮，形成微血管血栓，使红细胞破碎（微血管病性溶血性贫血）、消耗血小板并阻塞肾小球毛细血管（AKI）。处理以支持治疗为主，必要时透析；一般避免使用抗生素和止泻药，因为它们可能增加毒素释放。大多数儿童肾功能恢复，但部分有长期肾损害。HUS须报告，接触者可能需要公共卫生随访（[[paediatrics/acute-childhood-illness]]）。
:::
:::

::: exercise 决定是否透析 {level=2}
一名59岁男性因感染性休克在重症监护室，AKI 3期。血钾5.9 mmol/L且在治疗下下降，pH 7.29，正在使用去甲肾上腺素，双肺清晰，氧需求稳定。尿量10 mL/h。一位同事建议“趁情况还没变坏”现在就开始透析。证据提示什么？
::: solution
他是AKI 3期，但**目前没有难治性并发症**：血钾已控制，酸中毒轻，没有液体过负荷。比较早期与标准时机开始的试验，包括STARRT-AKI（2020），均未显示在指征出现之前开始RRT有生存获益，而加速策略使更多人承受透析的风险（导管并发症、低血压），并与90天时更多的透析依赖相关。合理的做法是继续支持治疗并密切监测，与重症和肾内科团队讨论，制定明确的RRT开始标准（难治性高钾血症、酸中毒加重、液体过负荷，或一段时间后仍无恢复）。
:::
:::

::: exercise 设计AKI预防路径 {level=3}
某医院审计显示，一半的医院获得性AKI发生在入院时已属高危、却被开具非甾体抗炎药或在急性患病期间继续使用ACE抑制剂的人中。设计一条减少医院获得性AKI的路径，并解释每一环节背后的生理学。
::: solution
1. **入院时风险评估**：标记慢性肾脏病、糖尿病、心力衰竭、肝病、年龄超过65岁、脓毒症、低血容量或使用肾毒性药物的人。这些人的GFR最依赖前列腺素和血管紧张素Ⅱ对肾小球压力的维护。
2. **入院时和每天审查用药**：电子提示，对低血压、脓毒症或容量不足者停用非甾体抗炎药，暂停ACE抑制剂、血管紧张素受体阻滞剂、利尿药和二甲双胍，并记录恢复用药的计划。
3. **监测**：高危患者每天查肌酐；液体平衡和尿量记录要有人审阅，而不只是填写。
4. **电子AKI预警**与处理集束（液体评估、尿试纸、用药审查、有指征时超声）关联，使预警触发行动，而不只是一条消息。
5. **对比剂和肾毒性药物方案**：eGFR低于30时扩容，监测氨基糖苷类和万古霉素的血药浓度。
6. 对医生、护士和药师进行肾前性生理和三重打击方面的**教育**。
7. **出院**：患病日指导、随访肌酐以及明确的恢复用药计划。
8. 向各病房**审计并反馈**AKI发生率，以维持改进。
:::
:::

::: exercise 解读变化轨迹 {level=3}
用图中的模型，起始肌酐80 µmol/L，GFR突然降至正常的10%，24小时后肌酐约为290 µmol/L。(a) 这是几期？(b) 24小时时eGFR计算会报告什么？为什么具有误导性？(c) 为什么实际危重患者的肌酐上升可能比模型预测的慢？
::: solution
(a) $290/80 = 3.6$倍基线：**3期**。

(b) eGFR方程会把290 µmol/L当作稳态值，根据年龄和性别报告约15～20 mL/(min·1.73 m²)的eGFR。真实GFR约为10 mL/min，而肌酐仍在向其新的稳态800 µmol/L上升。只要肌酐在上升，eGFR就高估GFR。

(c) 危重患者往往生成的肌酐较少（肌肉量减少、制动、脓毒症相关的生成减少），而且液体复苏使肌酐分布容积增大，稀释了肌酐。二者都减慢肌酐上升，可能使AKI看起来比实际轻。这是尿量以及研究中的新型生物标志物与肌酐并用的原因之一。
:::
