滤过把每日180升的带溶质血浆的水呈递给一条管道，而它字面上就是一个每小时的重处理的工厂：**肾小管回收约99%的水与几乎全部的葡萄糖和氨基酸，把钠与钾及钙和氢调到每日的摄入的百分之几以内，并对着它自己建立的梯度来浓缩或稀释尿。**这里的每一个转运体都是一个药的目标（利尿剂与钠葡萄糖的抑制剂和乙酰唑胺），每一个遗传的缺陷都是一个被命名的综合征，而每一个临床电解质的课都在本章的细胞的生理之后。

本章涵盖肾小管转运的原则、肾单位的节段、浓缩的机制、转运的最大值，以及肾小管的综合征。

## 转运的原则

::: definition 肾小管的细胞与它的转运体的工具箱 {#def-transport}
**肾小管的细胞把它的转运体分开放置，而这就是这一切的关键：顶膜的（朝向管腔的）转运体把溶质带入，而基底外侧的把溶质排出到血液；由于转运体的种类与数量不同，每个节段就有一个不同的工作。驱动这一整个系统的泵就是钠钾的三磷酸腺苷的酶（在基底的外侧膜内，把钠泵出细胞并把钾泵入，维持低细胞的钠与负的内部的电位——这两股的力量使钠能沿着它的梯度过多地进入管腔的转运体）。钠的进入有四种的方式：共转运（同向的转运体：钠葡萄糖与钠氨基酸及钠氢的交换、钠钾二氯；钠依赖继发主动的例子），逆向交换（钠氢的交换把氢分泌出去——近端的碳酸氢盐的重吸收和药物的清除），通道（钠的通道在上皮的钠的通道在集合管的主细胞，被抗利尿的激素与醛固酮调节——钾的分泌的电压的来源），以及泵（氢的三磷酸腺苷的酶与氢钾的交换在A的闰细胞；以及氯化物的通道）。水跟着盐：通过水孔蛋白跨膜的水的通道（在血管加压素的作用下在集合管上皮细胞顶膜的通道里被插入的）与紧密的连接；而尿素与有机溶质有它们自己的路径。第二个的概念就是转运的最大值：因为一个转运体的数量是有限的，被重吸收的量会在一个阈值之上进入平台（葡萄糖这个经典的例子：肾小球滤过的率超过每分钟的滤过的负荷，与载体饱和，尿里出现糖——所以血糖的正常与糖尿的存在可以共存，而在家族性的缺陷中会有糖尿而没有高血糖[[#ex-tm ]]）。第三：梯度本身也是被转运的产物：氯化钠主动的回收创造了电位（在远节段管腔的负的电位，驱动钾的分泌）与渗透的差距（在髓质的渗透的梯度，被保存直的小血管，被用来浓缩尿[[#def-concentrate ]]）。第四：细胞的机制会在疾病中改变：类固醇与肽会插入或移除通道，酸的中毒症会重配置转运体的表达，而缺钾会损伤浓缩。这个工具箱就是[[renal/water-sodium]]与[[renal/potassium-calcium-phosphate]]和[[renal/acid-base-disorders]]的章节临床电解质的层下面那一段解剖。**
:::

::: example 回收葡萄糖的负荷 {#ex-tm}
在一位糖尿病的患者中血葡萄糖升到22：滤过的负荷等于滤过率乘以血浆等于每分钟0.125升乘以每升22毫摩尔即每分钟2.75毫摩尔；尿的葡萄糖的排出为每分钟0.7毫摩尔。估计有效转运的最大值，并解释为什么葡萄糖在约11时就出现在尿中，虽然饱和只在接近22时才完成。
::: solution
**重吸收等于负荷减去排出等于2.75减0.7等于每分钟2.05毫摩尔；在这个血葡萄糖下载体已被饱和，所以被重吸收的通量会估计葡萄糖的转运的最大值约为每分钟2毫摩尔（约每分钟360毫克——教科书的约每分钟375毫克对一个标准成人的身体，随肾单位的质量缩放）。在半饱和时出现的谜题就是分散：肾单位群体的异质性（一些肾单位的更短的小管与更低的载体的含量会更早地饱和）加上流量依赖的重吸收时间的减少——所以这个阈值（约11）位于理论上的完全的饱和点之下，而这也就是为什么试纸是一个不敏感的糖的测量（[[renal/filtration]]的量化规则），以及为什么钠葡萄糖的抑制剂（在任何的血糖下通过把尿的糖提高约每日60克）通过降低有效转运的最大值而起效。**
:::
:::

## 节段

::: definition 近端的小管：大量的回收者 {#def-proximal}
**近端的（卷曲与直行的）小管（带刷状的微绒毛与富含的线粒体）回收约65%到70%被滤过的钠与水（等渗的——溶质相关的、水孔蛋白1与密蛋白的细胞的缝隙的水的跟随），约80%到90%的碳酸氢盐（通过顶膜钠氢的交换对管腔的碳酸的酐酶二氧化碳的化学，以及基底的外侧的氯与碳酸氢盐的交换——可被乙酰唑胺阻断的这一[[#ex-fanconi ]]）、基本上所有被滤过的葡萄糖（钠葡萄糖的共转运体然后完成——[[#ex-tm]]）、所有氨基酸与乳酸和柠檬酸盐（柠檬酸盐对钙的结石的杠杆[[renal/urinary-tract]]）、约85%的磷酸盐（被甲状旁腺激素与成纤维细胞的生长因子的下调[[renal/potassium-calcium-phosphate]]）、以及大部分的尿酸（回收—分泌—回收的净的转运，转运体是痛风的基因的关联[[renal/acid-base-disorders]]）。它也分泌：有机的酸与碱通过它们开放的转运体家族（把药物与毒素和标记物从血液移到尿里——马尿酸与磺胺和头孢及利尿剂；而相互的抑制就是丙磺舒增强抗生素的机制）；这也解释了有机的物质被清除而滤过率被保留。这一段的失败会产生范科尼的综合征（糖与氨基酸及磷酸盐和碳酸氢盐及尿酸的共同泄漏，加上近端肾小管的酸中毒[[#ex-fanconi ]]）：在成人中遗传的疾病与药物及轻链的原因。临床的话：近端碳酸氢盐重吸收的失败会造成一个部分的酸中毒，带一个可被滴定的尿的酸碱度，而近端的缺陷会泄漏在远端无法完全被回收的东西。**
:::

::: definition 袢与远的肾小管，以及稀释与浓缩的机制 {#def-loop}
**髓质的粗的升支就是这段稀释者以及这个发生器：钠钾二氯的共同转运体（袢的利尿剂的靶点）摄取钠钾与二氯；钾的向后的泄漏与氯的通道的出口使管腔为正（正5到正10毫伏），驱动细胞外的钙与镁的重吸收（密蛋白的孔——所以袢的利尿剂会浪费钙与镁并造成会持续低钾的低镁[[renal/potassium-calcium-phosphate]]）；而水不通透的升支在没有水的情况下把溶质沉降到髓质——逆流倍增的引擎。细的支与直的小血管完成髓质的架构（降支的被动的氯化钠的出口，与在血管加压素之下的集合管的尿素的上皮转运体的沉降，被直的小血管回收——尿素构成内髓渗透的至一半[[#def-concentrate]]）。远的小管（细的上升段与弯曲的部分，也就是噻嗪的节段）通过钠氯的共转运体在细胞外无电中性回收氯化钠，产生最稀释的尿（低的钙与低的渗透）和负5毫伏管腔的电位；这个节段的遗传的缺陷就是吉特曼的综合征[[#ex-bartter-gitelman]]。集合管在两种的细胞上做激素的决定：主细胞（上皮的钠的通道与钾的通道：钠的回收为钾与氢的分泌提供这个电压，被醛固酮和非甾体放大；以及被锂阻断的通道[[renal/acute-kidney-injury]]），以及闰细胞（A型通过氢的三磷酸腺苷的酶与氢钾的交换分泌酸，这是酸碱的与钾的这两者的末端的路径；B型分泌碳酸氢盐——逆向转运体的缺陷会造成远端肾小管的酸中毒与结石）。抗利尿的激素会插入水孔蛋白2，并上调通道和泵：这一段就是尿被最终定稿之处。**
:::

::: definition 浓缩尿：逆流的系统与抗利尿的激素 {#def-concentrate}
**皮质到髓质渗透的梯度（皮质约300到内髓的1200到1400毫渗透摩尔）被建立与维持通过：主动单一的效应（升支的氯化钠与尿素的沉降[[#def-loop]]）；逆流的倍增（发夹的几何把重复的小的单一的效应变成一个指数垂直的梯度）；尿素的再循环（在抗利尿的激素之下的内髓尿素转运体的出口，沉降了间质的总的渗透的相当一部分，并被直的小血管回收）；以及直的小血管的逆流交换（低通透发夹毛细血管的技巧，供给髓质而不洗掉梯度——这也解释了为什么髓质的血流会如此之少而它的损伤会如此之快：非甾体与镰状的疾病和对比剂）。然后在收集管管腔的侧做决定：在血管加压素与它的V2受体和环磷酸腺苷的级联之下，水孔蛋白2被插入到顶膜，所以水会出来对着这个梯度；而尿素通道也被插入，把尿素贡献给梯度；同时血管加压素会提高升支的转运和直的小血管的通透。结果：在最大量的激素下的尿会被浓缩到1200以上，而在没有激素的时候，同一份尿在同样的髓质中会保持为50毫渗透摩尔——因为稀释是永远都在被制造的，只有水的那个跟随是可以被开关的。临床的表型：中枢性的（激素的缺乏：手术和创伤和肿瘤和浸润[[endocrine/hypothalamus-pituitary]]）、肾源性的（激素作用的缺陷：锂和高钙和高钾的缺乏以及慢性的梗阻和遗传的通道缺陷[[renal/acute-kidney-injury]]）、以及原发的多饮（这个梯度被冲洗）。这个诊断的序列（测定的渗透、对钠与水的操作的试验，和精氨酸加压素的替代）在[[#ex-di]]与[[renal/water-sodium]]。**
:::

## 肾小管的综合征

::: example 全球性近端的渗漏 {#ex-fanconi}
一位在用含替诺福韦的抗逆转录病毒治疗的38岁的人有骨的疼痛与无力：尿的糖为三个加号而血的糖正常，磷酸盐的清除升高，碳酸氢盐16带正常阴离子的差距和尿的酸碱度5.2，钾2.9，尿酸很低，并有微量的蛋白尿而针对白蛋白的读数为正常；在另一个病房的那个有同样的组合的儿童有佝偻病与生长停滞。
::: solution
**范科尼的综合征——被广义的近端的重吸收的失败（[[#def-proximal]]）：带正常血糖的糖尿（转运最大的载体的崩溃）；磷酸盐尿与低磷酸盐的骨软化和儿童的佝偻病（[[renal/potassium-calcium-phosphate]]与[[endocrine/bone-calcium]]）；二型（近端）的肾小管的酸中毒（碳酸氢盐阈值的缺陷，带一旦血低于阈值就可被酸化的尿[[renal/acid-base-disorders]]）；低尿酸血症带高尿酸的清除；氨基酸尿；低分子量的蛋白尿；以及由碳酸氢盐尿所驱动的低钾（[[renal/potassium-calcium-phosphate]]）——加上由容量收缩所致的继发醛固酮的增多（[[renal/water-sodium]]）。成因与管理：药物（替诺福韦与异环磷酰胺及顺铂和抗逆转录病毒与传统的小管的毒物）；轻链（[[blood/lymphoma-myeloma]]）；遗传的疾病（转运体的缺陷与线粒体的疾病和溶酶体的储存的疾病[[genetics/mendelian-inheritance]]）。管理就是停止 致病的药物、替代（碳酸氢盐的大剂量；磷酸盐；以及骨的）；并在孩子中治疗病因——因为疾病的表现就是生长与骨骼。**
:::
:::

::: example 两个排盐者，两个转运体 {#ex-bartter-gitelman}
这两位患者都有低钾的代谢的碱中毒带正常的血压与高的肾素和醛固酮：(a) 一位12岁有多尿与肾的钙质沉着和高尿的钙；(b) 一位26岁有抽搐与低的血的镁和低的尿的钙。病房上的另外两个成人服用利尿剂来控制体重。
::: solution
**表型就是两个被克隆的转运体（[[#def-loop]]、[[#def-concentrate]]）：巴特的综合征（袢的粗升支的共同转运体与通道：带高尿钙与肾的钙质沉着和浓缩受损，在早年出现，像一个先天利尿剂的过量）；而吉特曼的这个（远的小管钠氯的共转运体：低尿钙与低镁和抽搐，在成年出现，像一个慢性噻嗪的暴露）。这两个都会有低钾的碱中毒与正常的血压与升高的激素（这两个都会有继发的醛固酮的增多与正常的血压：这就把综合征与高血压的过多的矿皮质激素的状态分开[[renal/potassium-calcium-phosphate ]]）。尿的钙就是这个区分器（高对低）。服利尿剂的成人就是同一个的图形被伪装：泌尿道利尿剂的筛查与在院内被见证的停药和电解质的轨迹会解决它[[psychiatry/eating-personality-disorders]]。管理：钾与镁的替代（在吉特曼中先把镁，否则钾会持续）、非甾体（在严重巴特的儿童中减少前列腺素的驱动）、在适当孩子中的血管紧张素的阻断，以及长期的肾脏的随访——以及在伪装者中一个饮食提问的转诊。**
:::
:::

::: warning 在你们贴一个肾小管综合征的标签之前 {#warn-tubular}
巴特对吉特曼的尿钙的推理要求排除药理学的模仿者（袢与噻嗪的使用——包括哺乳的母亲与伪装的和代理的做作的可能性），以及呕吐与腹泻加上利尿剂的组合；尿的利尿剂的筛查与在院内被见证的停药和电解质的轨迹会解决它（[[psychiatry/substance-use]]与[[psychiatry/eating-personality-disorders ]]）。同样，**永远不要把多尿称为精神性的而没做正式的检查**——给一个原发多饮的患者去氨加压素会造成水的中毒的低钠，而在真正的尿崩症中剥夺水会造成高钠；被监督的、带体重与钠的监测的方案与精氨酸加压素前体测定的时代[[endocrine/hypothalamus-pituitary]]。**
:::

::: example 双重的开颅之后的口渴 {#ex-di}
在严重头部的外伤与垂体的区域的手术之后的第三天，一位患者每小时排出600毫升的清的尿；血的钠在12小时内从138升到154，钾正常，血浆的渗透322而尿的渗透110；口渴存在而他在喝水，但镇静限制了摄入。
::: solution
**术后中枢性的尿崩症（[[#def-concentrate]]、[[endocrine/hypothalamus-pituitary]]）：一个自由水的排泄（尿的渗透远低于血浆，在高血浆的钠与渗透之下）在一个神经外科的背景中。提醒：三个模式（持续的和三相的——初始的尿崩与第二相的抗利尿的激素的释放和第三相的永久；以及延迟的，在四十八小时之后——所以手术之后的钠的轨迹都要监测）、水的平衡的规则（在清醒的患者中按口渴口服的液体；在镇静者中带着每六小时的钠低流量的维持，及下丘脑的损伤的避免过度矫正），以及去氨加压素的策略（作用短的制剂和按计划而不是按反应的给药，带故意的窗以避免低钠；以及这个鼻的在颅内手术的缺陷）。为什么钾正常而钠会上升：这个自由水的清除，不是钠。长期的提问：其他的垂体的轴的评估，以及在第三相中水限制的危险[[renal/water-sodium]]。**
:::

**这一章从近端与远端的区分开始（十九世纪末的，与二十世纪初的把尿的形成分割为滤过与随后的过程的模型），然后被微穿刺改写（定量单个小管的标本证明了一个等渗的近端的液体与一个稀释升支的液体，并测量了转运的最大值的饱和）。逆流的模型（1940年代）曾被拒绝，因为它太好了；然后被直接的髓质的测量与微的穿刺所证实。遗传的综合征成为转运体的探针：巴特的儿童与吉特曼的成人以及假性醛固酮的过多与远端与小管的酸中毒的家族（通道病学的家族：肾的类型的通道与转运体的突变），在分子的身份被克隆之前定义了这个袢与这个远端的小管和集合管的细胞。药理学走回了这条路：利尿剂按它们的节段被理解，而受体和通道变成了分子（β与α的肾上腺素的受体与血管加压素的V2和盐皮质激素的；以及水孔蛋白的通道——它们的发现者在2000年获得诺贝尔的确认）。这一章的临床的章节——盐的浪费与综合征——就是细胞生物学被读回成床边的电解质。**
:::

## 通向何处

喂养这一回收的滤过的那一步在[[renal/filtration]]；被详细阐述激素的控制器在[[renal/water-sodium]]与[[renal/potassium-calcium-phosphate]]；酸碱的算术在[[renal/acid-base-disorders]]；损伤的综合征在[[renal/acute-kidney-injury]]；进展与透析的世界的在[[renal/chronic-kidney-disease]]；结石与感染在[[renal/urinary-tract]]；利尿剂的药理学在[[cardiovascular/heart-failure]]；以及药物的转运的相互作用在[[pharmacology/metabolism-excretion]]。

::: exercise 为什么多饮的尿是稀释的 {level=2}
一位精神科的住院患者每日喝12升，尿的渗透为60而钠正常。为什么这里的稀释的尿是恰当的，以及为什么这个习惯不能被突然地纠正？
::: solution
**因为肾小管正在做它被要求做的事：在血管加压素被恰当地被移除之后，集合管对水不通透，而这一稀释被髓质的正常的能力所保证（[[#def-concentrate]]、[[#def-transport]]）——一个会浓缩尿以对抗自由的水的摄入的肾就是不当的。尿的渗透60就排除了溶质的利尿（糖与尿素的）并要求一个水的。为什么不能被突然纠正：慢性的多饮会冲洗髓质的渗透的梯度，所以浓缩的能力在数天内是受损的；而真正的危险不是这个行为而是它的终止——一个习惯了12升的人被突然地限制会保留水并变成低钠（尤其若精神病的药物或疾病会刺激血管加压素[[endocrine/hypothalamus-pituitary]]），带癫痫发作的风险。实践：分阶段的减少与钠的监测和精神的原因的治疗，以及不要在没有测试下使用去氨加压素（[[#warn-tubular]]）[[renal/water-sodium]]。**
:::
:::

::: summary
- 肾小管就是一台极化上皮的机器，由基底外侧的钠的泵供电：节段特异顶膜的载体（钠葡萄糖的共转运体与钠氢的交换及钠钾二氯和钠氯的共转运体及上皮的钠的通道）决定什么会回来，而有机的阴离子与阳离子的分泌的系统会处理身体的酸和碱及药物。
- 重吸收可被饱和（转运的最大值与分散——糖尿的阈值）并受梯度的限度；近端的小管回收三分之二的一切，而它的全球性的失败就是范科尼的综合征。
- 升支会建造髓质渗透的堆栈（逆流的倍增与尿素的再循环，被直的小血管保护），而抗利尿的激素驱动的水孔蛋白之后会利用它——从50到1200毫渗透摩尔浓缩的范围就是水的平衡的工作空间。
- 每一个转运体都有一个药和一个疾病：袢对转运体对巴特；噻嗪对共转运体对吉特曼；上皮的钠的通道对李德尔与表观的过多的矿皮质激素；以及水孔蛋白与受体的尿崩症——遗传的与药理的表型相互镜像。
- 多尿与低钾的排盐的工作检查都是转运体的定位的练习：尿的钙与镁及氯和利尿剂的筛查会在任何一个基因之前做诊断。
:::

## 练习

::: exercise 为这个泵供电 {level=1}
为什么钠钾的三磷酸腺苷的酶的抑制（地高辛）与三磷酸腺苷的耗尽（缺血）在近端是有毒的，并命名两个重吸收的后果。
::: solution
**这个泵会设定那股进入的钠的梯度，而这股梯度会为几乎每一个顶膜进入的步骤供电（[[#def-transport]]）：缺血会崩溃钠葡萄糖与钠氢的交换（碳酸氢盐）和钠磷酸盐的重吸收——一个像范科尼的与三磷酸腺苷和细胞骨架失败的级联[[cell-biochemistry/energy-metabolism]]与[[pathology/cell-injury]]，它的形态的特征（刷状边缘的丢失）与浑浊的有颗粒的管型以及糖尿和氨基酸尿和磷酸盐尿会重新出现（[[#ex-fanconi]]的组合的缺血的形式）。**
:::
:::

::: exercise 酸与刷状的边缘 {level=1}
乙酰唑胺会阻断被滤过的碳酸氢盐的哪一部分，在哪里，以及为什么这个药的酸中毒会自我限制？
::: solution
**近端钠氢的交换与碳酸的酐酶的系统（约85%的回收——[[#def-proximal]]）：酶的抑制会使管腔的二氧化碳的穿梭的氢的产生饥饿。它会自我限制，因为血的碳酸氢盐会下降到被降低的阈值（约18到20）——在阈值之下滤过的递送自己会成为限度；而远端的酸化是完整的，所以在稳定的状态下尿仍然可被酸化（[[renal/acid-base-disorders]]的二型的区别），带治疗的用途（青光眼与特发的颅内的高压[[nervous-system/headache-pain]]、高原与碱中毒及癫痫[[nervous-system/epilepsy]]应用）。**
:::
:::

::: exercise 追溯这个电压 {level=2}
一步步地解释一个共同转运体的突变如何造成低钾（三个机制）与低镁带低尿钙的缺席（为什么巴特会浪费钙而吉特曼不会）。
::: solution
**低钾：（i）远端的钠与流量的递送会提高被上皮的钠通道耦合的钾的分泌（[[renal/potassium-calcium-phosphate]]）；（ii）由排盐所致继发醛固酮的增多加强它；（iii）代谢的碱中毒（[[renal/acid-base-disorders]]）会把钾移到细胞内并持续分泌。钙与镁：共同转运体的被丢失的管腔的正的电压会关掉细胞外的钙与镁的重吸收（尿钙过多——肾的钙质沉着），而吉特曼的远的小管的损害会把升支的电压保持完整并增强远端的钙的重吸收（[[#def-loop]]）——低尿钙加低镁（远的小管的镁的路径）标记它；所以尿的钙对肌酐的比率与镁会在一个基因之前定位这个转运体。**
:::
:::

::: exercise 做水的算术 {level=2}
在尿的渗透100与每日12升的流量、血浆300与正常的600毫渗透摩尔溶质的负荷下：计算自由的水与渗透的清除，并决定这种稀释的多尿是否可能是完整的。
::: solution
**渗透的清除等于尿的渗透乘以流量除以血浆的渗透：100乘以12除以300等于每日4升；自由的水的清除等于流量减去渗透的清除等于12减4等于正每日8升（最大水的利尿的领域）。这个机关：600毫渗透摩尔义务的溶质不能在12升中以100的浓度离开（12升乘以0.1等于1200毫渗透摩尔）——算术会说溶质的排出过多（渗透的利尿：糖与甘露醇及尿素的回收和高的蛋白肠内的营养[[gastrointestinal/clinical-nutrition]]）或一个部分的缺陷；在原发的多饮对尿崩症的剥夺水的检查之前检查尿的糖与尿素及钠和钾的含量（[[renal/water-sodium]]）。**
:::
:::

::: exercise 锂的两种肾小管的损伤 {level=2}
给出锂诱导肾源性尿崩症的机制，以及锂的慢性的肾小管间质损害的机制，还有管理的杠杆。
::: solution
**上皮的钠的通道就在主细胞的顶膜上，而它就是锂的进入的门（它会模仿钠——[[renal/potassium-calcium-phosphate]]）；被积累的锂会抑制激酶并损害水孔蛋白的转录与转运（抗利尿激素的抵抗[[#def-concentrate]]和[[cell-biochemistry/signalling-cell-cycle ]]），产生稀释的多尿与口渴（以及在摄入与盐都下降时的钠的缺乏的毒性的环[[renal/water-sodium]]）；慢性的损伤就是空泡的与微囊肿的纤维化的轨迹，产生进展慢性的肾的疾病（[[renal/chronic-kidney-disease]]）。杠杆：浓度的监测与剂量的策略（更低的目标与更少的剂量）；对肾源性的尿崩症的去氨加压素（部分地有效）、容量的规则（在盐的缺乏与发热时暂停，因为钠的回收会增加锂的重吸收）、停用的决定与肾内科的转移，以及长期的滤过与尿的浓缩的监测。**
:::
:::

::: exercise 定位糖尿 {level=2}
带正常血糖的糖尿：构建这个鉴别（四个机制），每个都配一个有鉴别力的检查。
::: solution
**（i）近端小管的疾病（范科尼——[[#ex-fanconi]]：带磷酸盐和碳酸氢盐及尿酸的共同的渗漏低转运的泄漏与氨基酸尿）；（ii）孤立肾性的糖尿（钠葡萄糖共转运体的损失——良性的并被妊娠所揭露[[obstetrics-gynaecology/pregnancy-antenatal]]）；（iii）药物（钠葡萄糖的抑制剂——治疗的糖尿[[endocrine/diabetes]]——以及异环磷酰胺与替诺福韦的清单[[pharmacology/adverse-reactions]]）；（iv）罕见发育的原因（糖原储存的疾病[[genetics/mendelian-inheritance]]与[[gastrointestinal/digestion-absorption]]）。鉴别者：近端的功能的完整的一组（磷酸盐与尿酸及碳酸氢盐）；血浆的葡萄糖与糖耐量的曲线；用药史；以及在儿童中的生长与骨骼。**
:::

::: exercise 设计多尿的路径 {level=3}
为被记录的多尿设计住院与门诊的路径：阈值、最初的检查、剥夺水的与前体的算法、安全的规则，以及这三个答案的随访。
::: solution
**这个阈值与证实：以每日超过50毫升每公斤（或每1.73平方米超过3升）的二十四小时收集的定义，带同时的血浆（[[#def-concentrate]]的多尿与慢性的肾的疾病及梗阻后的告诫，以及尿崩症的模仿的排除：糖与甘露醇及钙和钾[[renal/acid-base-disorders ]]）。这第一层：配对尿的渗透与钠和钾及葡萄糖和尿素（溶质对水的利尿的分裂[[#ex-di]]）；加上血浆的渗透与钠及钙和钾；以及锂与药物的病史[[pharmacology/adverse-reactions]]；以及原发的多饮的筛查（精神的病史与用药[[psychiatry/psychiatric-assessment]]）。第二层：精氨酸加压素前体的测定与被监督的剥夺水（带体重的限度与钠的系列）和随后的去氨加压素，按规则的中断——安全的规则（不要盲目地给去氨加压素；在试验期间避免锂；以及在低钠的风险中的试验的小时）。这三条答案各自的随访：中枢性的（垂体的轴与影像[[endocrine/hypothalamus-pituitary]]）、肾源性的（锂的规则与钾和钙的纠正[[renal/acute-kidney-injury]]、以及遗传的测试）、以及行为的（渐进的减少与精神的治疗和钠的防护[[renal/water-sodium]]）。**
