肾小球每天滤过约180升血浆，其中含约25 000 mmol钠、900 mmol葡萄糖和4000 mmol碳酸氢根。而一个人排出的尿液也许只有1.5升，含150 mmol钠，不含葡萄糖，几乎不含碳酸氢根。二者之间的差别就是肾小管的工作。它重吸收99%以上滤过的水和盐、全部葡萄糖和氨基酸以及几乎全部碳酸氢根，并对剩余部分进行微调以与摄入相匹配。

肾小管不是一个结构，而是一系列节段，每一段都有自己的转运体和自己的任务。近端小管大量重吸收。髓袢把盐和水分开，并建立髓质的浓度梯度。远端小管和集合管在激素控制下作最后的调整。大多数利尿药和大多数遗传性肾小管疾病，都可以理解为某一节段中某一个转运体被关闭。

本课时以[[renal/filtration]]中的滤过物理学和[[physiology/homeostasis-body-fluids]]中的膜转运原理为基础。把钠和水作为临床变量来调节的内容见[[renal/water-sodium]]。

## 肾小管细胞如何转运溶质

肾小管上皮细胞具有极性。**顶膜**（管腔膜）面向小管液；**基底侧膜**面向间质和管周毛细血管。相邻细胞之间由**紧密连接**相连，紧密连接在近端小管较疏松，在集合管较紧密。

::: definition 肾小管转运 {#def-transport}
**重吸收**是从小管腔回到血液的移动；**分泌**是从血液进入小管腔的移动。二者都可经两条途径：

- **跨细胞途径**：穿过顶膜，经过细胞，再穿出基底侧膜；
- **细胞旁途径**：在细胞之间经紧密连接通过，由浓度梯度或电压梯度驱动。

几乎所有跨细胞转运都直接或间接由基底侧膜上的**Na⁺/K⁺-ATP酶**供能。它把钠泵出细胞，使细胞内钠浓度保持较低、细胞内为负电位。钠随后顺其电化学梯度跨顶膜进入细胞，或单独经通道进入，或经**同向转运体**（同方向转运，如Na⁺–葡萄糖）和**交换体**（反方向转运，如Na⁺–H⁺）与其他溶质偶联。利用钠梯度使溶质逆其自身梯度移动，称为**继发性主动转运**。
:::

水跟随溶质。凡是有盐被重吸收且上皮含有水通道（水孔蛋白）的地方，水都会通过渗透移动。上皮缺乏水通道的地方，盐可以被移走而水留下；肾脏就是这样产生稀释尿的。

载体介导的转运有上限。载体数量有限，所以像葡萄糖这样的物质，其重吸收速率不能无限升高。

::: theorem 转运最大值与肾阈 {#thm-tm}
对于由可饱和载体重吸收的溶质，重吸收速率随滤过负荷增加而升高，直至载体饱和，达到**转运最大值**（$T_m$）。超过此值后，额外滤过的溶质全部排出：

$$
\text{排出量} = \text{滤过负荷} - T_m = \text{GFR} \times P_x - T_m \quad (\text{当 } \text{GFR} \times P_x > T_m)
$$ {#eq-tm}

**肾阈**是溶质开始出现于尿中时的血浆浓度。由于各肾单位的转运能力不同，有些先于其他肾单位饱和，所以肾阈低于由$T_m$/GFR预测的数值，而且过渡是弯曲的而不是陡然的（这种弯曲称为**展开**）。
:::

健康成人的葡萄糖肾阈约为10～11 mmol/L（180～200 mg/dL）。低于此值时，尿中基本不出现葡萄糖。约90%滤过的葡萄糖在近端小管前段由**SGLT2**（钠–葡萄糖同向转运体2）重吸收，其余在更远处由**SGLT1**重吸收。

::: example 尿中的葡萄糖 {#ex-tm}
一名未控制的糖尿病患者血浆葡萄糖为20 mmol/L，GFR为125 mL/min。取葡萄糖转运最大值为2.0 mmol/min。忽略展开，估算葡萄糖排出速率。
::: solution
滤过负荷$= \text{GFR} \times P = 0.125 \text{ L/min} \times 20 \text{ mmol/L} = 2.5$ mmol/min。

重吸收上限为$T_m = 2.0$ mmol/min，所以排出量$= 2.5 - 2.0 = 0.5$ mmol/min，约每天720 mmol（130 g）。

小管液中的葡萄糖会携带水分，引起**渗透性利尿**：多尿、口渴和脱水，即高血糖的典型症状。同一原理解释了SGLT2抑制剂的作用机制。通过阻断主要的葡萄糖载体，它们降低了有效肾阈，使葡萄糖在血糖正常时也从尿中丢失，肾功能正常者每天约60～80 g。它们对肾脏和心脏结局的益处见[[renal/chronic-kidney-disease]]。
:::
:::

## 肾单位的各个节段

### 近端小管

::: definition 近端小管 {#def-proximal}
**近端小管**重吸收约三分之二滤过的钠和水、几乎全部滤过的葡萄糖和氨基酸、约80%滤过的碳酸氢根，以及大部分滤过的磷、钾和尿酸。此处的重吸收是**等渗性**的：水通过疏松的上皮（富含水孔蛋白-1）紧随溶质移动，因此小管液的渗透压始终与血浆相同。

近端小管也是**分泌**有机阴离子和阳离子的主要部位，包括许多药物（青霉素类、甲氨蝶呤、二甲双胍）、尿酸和肌酐。
:::

关键的顶膜转运体是**钠–氢交换体NHE3**。分泌入管腔的氢离子与滤过的碳酸氢根结合成碳酸，刷状缘上的碳酸酐酶将其分解为CO₂和水。CO₂扩散进入细胞，重新转变为H⁺和HCO₃⁻，碳酸氢根经基底侧膜离开细胞。净效应是滤过的碳酸氢根被重吸收。碳酸酐酶抑制剂乙酰唑胺（acetazolamide）阻断这一过程，导致碳酸氢根从尿中丢失。

磷由钠–磷同向转运体（NaPi-IIa和IIc）重吸收。甲状旁腺激素和FGF23使这些转运体从细胞膜上移除，导致磷酸盐尿（[[renal/potassium-calcium-phosphate]]）。

近端小管还由谷氨酰胺生成氨。这在酸中毒时变得重要，此时铵的排泄是肾脏排酸的主要途径（[[renal/acid-base-disorders]]）。

### 髓袢

::: definition 髓袢 {#def-loop}
**降支细段**对水通透，对盐通透性不高。**升支粗段**（TAL）对水不通透，并通过顶膜的**Na⁺–K⁺–2Cl⁻同向转运体（NKCC2）**主动重吸收约25%滤过的氯化钠。由于盐被移出而水没有跟随，离开TAL的液体是低渗的，约100 mOsm/kg，与机体的水平衡无关。因此TAL被称为**稀释段**。
:::

经NKCC2进入细胞的钾通过**ROMK**通道漏回管腔。这种再循环使NKCC2有钾可用，并使管腔呈正电位。正电位的管腔推动钙和镁经细胞之间、通过称为claudin的紧密连接蛋白移出。因此TAL是镁重吸收的主要部位，也是钙重吸收的重要部位。

**袢利尿药**（呋塞米、布美他尼）阻断NKCC2。它们是作用最强的利尿药，因为其作用节段处理四分之一滤过的钠，还因为它们消除髓质梯度，阻止尿液浓缩。由于消除了管腔正电位，它们也增加钙和镁的丢失。

### 远曲小管

**远曲小管**（DCT）通过**钠–氯同向转运体（NCC）**重吸收约5%～7%滤过的钠。它同样对水不通透，所以进一步稀释尿液。**噻嗪类利尿药**阻断NCC。与袢利尿药不同，噻嗪类*减少*尿钙。在DCT中，钙在甲状旁腺激素控制下经顶膜的TRPV5通道重吸收；阻断NCC使细胞内钠降低，从而驱动更多钙经基底侧膜移出细胞，于是更多钙被重吸收。这就是噻嗪类被用于预防钙结石、又可能引起轻度高钙血症的原因。

### 连接小管与集合管

最后的节段含有两种主要细胞。

- **主细胞**通过**上皮钠通道（ENaC）**重吸收钠，并通过ROMK分泌钾。钠进入使管腔呈负电位，从而驱动钾分泌。**醛固酮**增加ENaC通道和Na⁺/K⁺-ATP酶泵的数量。主细胞也是**抗利尿激素**（ADH，血管升压素）的作用部位：它与V2受体结合使cAMP升高，并将**水孔蛋白-2**水通道插入顶膜。
- **闰细胞**处理酸和碱。A型（α）细胞通过顶膜H⁺-ATP酶分泌H⁺，是排酸所必需的。B型（β）细胞通过pendrin以氯离子交换分泌碳酸氢根。

虽然这些节段只处理2%～5%滤过的钠，但它们决定尿液的最终成分。**阿米洛利**（amiloride）阻断ENaC；**螺内酯**（spironolactone）和**依普利酮**（eplerenone）阻断醛固酮受体。二者都减少钾分泌，因此称为保钾利尿药，也因此可能引起高钾血症。

| 节段 | 占滤过Na⁺的比例 | 关键顶膜转运体 | 作用于此的利尿药 | 对K⁺和Ca²⁺排泄的影响 |
|---|---|---|---|---|
| 近端小管 | 约65% | NHE3、SGLT2 | 乙酰唑胺、SGLT2抑制剂 | K⁺增加（远端输送增加） |
| 升支粗段 | 约25% | NKCC2 | 呋塞米、布美他尼 | K⁺增加，Ca²⁺增加 |
| 远曲小管 | 约5%～7% | NCC | 噻嗪类 | K⁺增加，Ca²⁺减少 |
| 集合管 | 约2%～5% | ENaC | 阿米洛利；螺内酯（受体） | K⁺减少 |

作用于集合管上游的利尿药引起**低钾血症**，原因有二：更多的钠和液体到达主细胞，增加钾分泌；由此造成的容量丢失激活醛固酮。

## 尿液的浓缩与稀释

健康人可以产生稀至约50 mOsm/kg、浓至约1200 mOsm/kg的尿液。肾脏实现这一范围的方法是：在髓质间质中建立渗透压梯度，从皮髓交界处约290 mOsm/kg到乳头尖端约1200 mOsm/kg；然后改变贯穿这一梯度的集合管的水通透性。

::: theorem 逆流机制 {#thm-countercurrent}
髓质渗透梯度由髓袢的**逆流倍增**产生，由**尿素再循环**加强，并由直小血管的**逆流交换**保持。在ADH存在时，集合管变得对水通透，水从集合管进入高渗的髓质，直至尿液接近乳头间质的渗透压。
:::

::: proof
在髓质的任何一个水平，升支粗段把盐泵入间质而不带水，使间质比旁边上行的液体稍浓；这一单一效应只有约200 mOsm/kg。相邻的降支对水通透，于是水离开降支，降支液浓缩到与间质相同。浓缩的液体绕过发夹弯进入升支，在更深的水平又有更多盐被泵出。由于两支中液体流动方向相反，这一小的横向差异沿髓袢全长不断重复，被倍增为大的纵向梯度。髓袢越长，梯度越陡。

尿素增加内髓的梯度。在ADH作用下，内髓集合管通过尿素转运体对尿素通透；在上段集合管中浓缩的尿素扩散到内髓，贡献了内髓约一半的渗透压。

直小血管本可能冲走梯度，但它们也呈发夹形。下行进入髓质的血液获得溶质、失去水；返回时失去溶质、重新获得水。因此血液离开髓质时只比进入时稍浓，梯度得以保持。
:::

::: definition 尿液浓缩与ADH {#def-concentrate}
**抗利尿激素**（精氨酸血管升压素）在下丘脑合成，当血浆渗透压升高或有效循环容量下降时从垂体后叶释放。它作用于集合管的V2受体，插入水孔蛋白-2通道，产生浓缩尿。没有ADH时，集合管几乎不透水，来自TAL和DCT的稀释液进入尿中（**水利尿**）。

**最小尿量**取决于尿液每天必须携带的溶质负荷和肾脏能达到的最大浓度：

$$
V_{\min} = \frac{\text{排出溶质 (mOsm/day)}}{U_{\text{osm, max}} \text{ (mOsm/kg)}}
$$ {#eq-vmin}
:::

典型的西方饮食每天产生600～900 mOsm溶质，主要是尿素和盐。最大尿渗透压为1200 mOsm/kg时，600 mOsm可在0.5 L尿中排出。反过来，**最大**尿量等于溶质负荷除以最小尿渗透压。溶质为600 mOsm、最小尿渗透压为50 mOsm/kg时，一个人每天最多可排出12 L水。吃得很少（溶质少）而大量喝啤酒或茶的人，其上限要低得多，这解释了啤酒饮用者低钠血症（[[renal/water-sodium]]）。

自由水清除率用数值表示肾脏相对于溶质是在增加还是在清除水。渗透清除率为$C_{osm} = U_{osm} V / P_{osm}$，即以血浆渗透压排出尿中溶质所需的容积。**自由水清除率**为$C_{H_2O} = V - C_{osm}$。尿液稀释时它为正值（肾脏在排出纯水），尿液浓缩时为负值（肾脏在保留水）。

## 肾小管疾病

遗传性肾小管疾病少见，但它们是生理学中最清晰的实验之一：每一种都显示了单个转运体失灵时会发生什么。由药物和毒物引起的获得性类型则很常见。

::: example 近端小管全面渗漏 {#ex-fanconi}
一名64岁女性有骨痛和乏力。她的血浆葡萄糖为5.2 mmol/L，但尿试纸示葡萄糖2+。血浆磷0.55 mmol/L（低），尿酸低，碳酸氢根17 mmol/L且阴离子间隙正常，尿中有氨基酸。她的血清游离轻链明显异常。请解释。
::: solution
血糖正常的糖尿、磷丢失、低尿酸、氨基酸尿，以及碳酸氢根丢失引起的阴离子间隙正常型酸中毒，合在一起意味着近端小管重吸收全面衰竭：**肾性范科尼综合征**。其酸中毒属于近端（2型）肾小管酸中毒。

在成人中，获得性病因比遗传性病因多见。异常的轻链提示**单克隆轻链**损伤了近端小管细胞，这些细胞通过内吞摄取滤过的轻链；她需要检查骨髓瘤或其他浆细胞疾病（[[blood/lymphoma-myeloma]]）。其他获得性病因包括药物，如富马酸替诺福韦二吡呋酯（tenofovir disoproxil）、异环磷酰胺（ifosfamide）和一些较老的氨基糖苷类，以及重金属。在儿童中，胱氨酸病是最常见的遗传性病因。她的骨痛可能反映慢性失磷引起的骨软化症。
:::
:::

::: example 两种失盐综合征 {#ex-bartter-gitelman}
两名年轻成人有低钾血症、代谢性碱中毒、血压正常或偏低，以及肾素和醛固酮升高。患者A 22岁，有低镁血症，尿钙极低。患者B早产，产前有羊水过多，尿钙高并有肾钙质沉着。各自最可能是哪个转运体缺陷？
::: solution
二人都像是在服用利尿药却并未服用：盐丢失，容量下降，肾素和醛固酮升高，远端钠输送增加加上高醛固酮驱动钾和氢的分泌，引起低钾性碱中毒。由于原发问题是失盐，血压不高。

**患者A**是**Gitelman综合征**，即远曲小管噻嗪敏感的NCC功能缺失。与噻嗪类一样，它降低尿钙。低镁血症是其特征。通常在青春期或成年后因肌肉痉挛、乏力或偶然发现低钾而就诊。

**患者B**是**Bartter综合征**，即升支粗段的缺陷（NKCC2、ROMK或氯通道ClC-Kb及其亚基barttin）。与袢利尿药一样，它增加钙排泄，引起肾钙质沉着；产前型可引起胎儿多尿和羊水过多。
:::
:::

::: warning 诊断肾小管综合征之前 {#warn-tubular}
隐匿使用利尿药、滥用泻药和自行催吐都会产生伴高肾素、高醛固酮的低钾性代谢性碱中毒，在血液检查上可能与Bartter或Gitelman综合征无法区分。尿氯有帮助：呕吐后尿氯低（低于约20 mmol/L），而使用利尿药和遗传性综合征时尿氯高。尿液利尿药筛查（有时需重复）可以区分后两者。应以不带评判的态度对待这些可能性，因为它们常与进食障碍有关（[[psychiatry/eating-personality-disorders]]）。基因检测可确诊遗传性综合征。
:::

*增强*肾小管钠重吸收的突变则产生镜像表现：**高血压**伴低钾血症和低肾素。在**Liddle综合征**中，ENaC因不能从细胞膜上移除而过度活跃；醛固酮受抑制，该病对阿米洛利有效而对螺内酯无效。原发性醛固酮增多症产生类似表现，但醛固酮升高（[[endocrine/adrenal]]）。

### 尿崩症

::: definition 尿崩症 {#def-di}
**尿崩症**（DI）是由于ADH缺乏或无效而产生大量稀释尿。**中枢性尿崩症**（现也称精氨酸血管升压素缺乏症）是垂体后叶释放的ADH不足，例如垂体手术、头部外伤后，或见于肿瘤和浸润性疾病。**肾性尿崩症**（精氨酸血管升压素抵抗）是集合管不能对ADH产生反应，如长期使用锂剂、高钙血症、低钾血症，或遗传性V2受体或水孔蛋白-2突变。**原发性烦渴**，即ADH完整而饮水过多，也会引起稀释性多尿，必须加以鉴别。成人多尿通常定义为每天超过约3 L（或超过40～50 mL/kg/天）。
:::

::: example 垂体手术后多尿 {#ex-di}
一名45岁男性因垂体腺瘤接受经蝶窦手术。当晚他每小时排尿400 mL。血浆钠从140升至149 mmol/L，血浆渗透压305 mOsm/kg，尿渗透压110 mOsm/kg。他清醒并要求喝水。请解读并概述处理。
::: solution
血浆渗透压高而尿液不适当地稀释（远低于血浆），说明肾脏在应当保水时没有保水：**尿崩症**。在垂体手术的背景下，最可能是垂体后叶或垂体柄损伤引起的**中枢性**尿崩症。

他清醒能饮水时是受保护的，因为口渴可以补充丢失；一旦他嗜睡或被要求禁食禁饮，危险就会增加。处理遵循当地内分泌方案：允许他按口渴饮水，记录液体出入量并定期测血钠，若多尿持续且血钠上升则给予**去氨加压素**（desmopressin，一种V2选择性ADH类似物）。对去氨加压素有反应（尿渗透压明显升高、尿量减少）可证实中枢性尿崩症。

垂体手术后的尿崩症常为一过性，有些人表现为**三相模式**：尿崩症，然后是数天由退变神经元引起的ADH不适当释放（有低钠血症风险，尤其是继续使用去氨加压素时），之后部分人出现永久性尿崩症。因此反复测定血钠必不可少。
:::
:::

在术后情境之外，鉴别中枢性尿崩症、肾性尿崩症和原发性烦渴在专科中心进行。经典的**禁水试验**在监护下禁止饮水并测定尿渗透压，然后给予去氨加压素。中枢性尿崩症禁水时不能浓缩尿液，但对去氨加压素有反应；肾性尿崩症两者都无反应；原发性烦渴能部分浓缩，不过长期水利尿会冲刷髓质梯度，使最大浓缩能力降低。**和肽素**（copeptin）是与ADH由同一前体裂解产生的稳定片段，越来越多地在高渗盐水或精氨酸刺激后测定，因为它比禁水试验给出更明确的答案。

锂剂值得一提。它经ENaC进入主细胞，干扰水孔蛋白-2的生成。长期服用锂剂的人中相当一部分会发生肾性尿崩症，停药后可能持续存在。阻断锂经ENaC进入的阿米洛利有时在专科建议下使用。长期锂治疗还可引起缓慢进展的慢性间质性肾炎，这就是治疗期间要监测肾功能的原因（[[psychiatry/treatments-mental-health-law]]）。

::: quiz
一人因原发性烦渴每天饮水10 L。其血浆钠为136 mmol/L。关于其尿液，下列哪项正确？
- [ ] 由于ADH处于最大水平，尿渗透压约为600 mOsm/kg
- [x] 由于ADH受抑制，尿液是稀释的；若随后禁水，尿液可能因髓质梯度被冲刷而不能达到完全浓缩
- [ ] 由于肾脏不能排出自由水，会发生高钠血症
- [ ] 其自由水清除率为负值
::: solution
大量饮水使血浆渗透压轻度下降，从而抑制ADH；集合管变得不透水，尿液稀释，所以自由水清除率为正值。持续的高尿流把溶质带出髓质，降低了髓质梯度。禁水时ADH升高，但尿液不能达到健康肾脏的最大浓度。因此部分浓缩是原发性烦渴的典型表现，这也是它与部分性尿崩症难以鉴别的原因之一。
:::
:::

::: history
1951年，瑞士物理化学家库恩（Werner Kuhn）和他的学生哈吉泰（Bartholomew Hargitay）建立了一个物理模型，说明具有逆向流动液流的发夹环如何把小的单一效应倍增为大的梯度。同年，维尔茨（Heinrich Wirz）、哈吉泰和库恩测定了大鼠肾组织切片的渗透压，发现它从皮质到乳头稳步升高，正是理论所预测的梯度。1953年，迪维尼奥（Vincent du Vigneaud）先后合成了催产素和血管升压素，这是在实验室中合成的第一批肽类激素，他因此获得1955年诺贝尔化学奖。血管升压素移入细胞膜的水通道一直是假说，直到1992年阿格雷（Peter Agre）及其同事证明，一种红细胞膜蛋白（后来命名为水孔蛋白-1）能使蛙卵在稀释的水中迅速肿胀；阿格雷分享了2003年诺贝尔化学奖。
:::

## 后续内容

钠和水的重吸收、肾素-血管紧张素-醛固酮系统和ADH在[[renal/water-sodium]]中得到临床应用。集合管的钾分泌以及钙和磷的处理在[[renal/potassium-calcium-phosphate]]中展开。酸的分泌和肾小管酸中毒见[[renal/acid-base-disorders]]。近端小管排泄药物的机制见[[pharmacology/metabolism-excretion]]。

::: summary
- 肾小管转运由基底侧膜Na⁺/K⁺-ATP酶供能；顶膜同向转运体和交换体利用钠梯度转运其他溶质。
- 可饱和载体有转运最大值。血浆葡萄糖高于约10～11 mmol/L时尿中出现葡萄糖；SGLT2重吸收约90%滤过的葡萄糖。
- 近端小管等渗地重吸收约三分之二滤过的钠和水、全部葡萄糖和氨基酸、大部分碳酸氢根和磷，并分泌许多药物。
- 升支粗段（NKCC2，袢利尿药）不带水地重吸收约25%的钠，为髓质梯度提供动力；DCT（NCC，噻嗪类）约5%～7%；集合管（ENaC，醛固酮；水孔蛋白-2，ADH）作最后调整。
- 逆流倍增、尿素再循环和逆流交换建立并保持高达约1200 mOsm/kg的髓质梯度；ADH决定集合管移出多少水。
- 最小尿量 = 溶质负荷 / 最大尿渗透压。
- 单一转运体疾病模拟利尿药：Bartter（袢）、Gitelman（噻嗪）、Liddle（ENaC过度活跃）。范科尼综合征是近端小管全面衰竭。尿崩症分中枢性和肾性，须与原发性烦渴鉴别。
:::

## 习题

::: exercise 为泵供能 {level=1}
解释为什么毒化基底侧膜的Na⁺/K⁺-ATP酶会减少近端小管对葡萄糖的重吸收，尽管该ATP酶并不转运葡萄糖。
::: solution
SGLT2把葡萄糖与顺电化学梯度进入细胞的钠偶联，从而把葡萄糖转运进细胞。这一梯度（细胞内低钠、细胞内负电位）由Na⁺/K⁺-ATP酶维持。如果泵停止，细胞内钠升高，梯度消失，SGLT2就不能再把葡萄糖逆浓度梯度转入细胞。这就是继发性主动转运：能量通过钠梯度间接来自ATP。
:::
:::

::: exercise 利尿药与钙 {level=1}
一名70岁女性有反复发作的草酸钙结石和高钙尿症，需要用利尿药治疗高血压。哪一类利尿药同时有助于预防结石，哪一类可能使结石加重？用肾小管生理学解释。
::: solution
**噻嗪类**有帮助。阻断远曲小管的NCC会增加该处的钙重吸收，降低尿钙。**袢利尿药**会使结石更容易形成：阻断NKCC2消除了升支粗段驱动细胞旁钙重吸收的管腔正电位，因此尿钙升高。
:::
:::

::: exercise 钠排泄分数 {level=1 check="round(150/(180*140)*1000)/10"}
一名健康成人的GFR为每天180 L，血浆钠140 mmol/L，每天排出150 mmol钠。滤过的钠中有百分之几被排出？保留一位小数。
::: solution
滤过的钠$= 180 \times 140 = 25\,200$ mmol/天。排泄分数$= 150 / 25\,200 \times 100 = 0.595\%$，约**0.6%**。99%以上滤过的钠被重吸收。重吸收只要改变1%，钠排泄就会每天改变250 mmol，超过典型的日摄入量，这就是肾小管对钠的处理受到如此严密调节的原因。
:::
:::

::: exercise 自由水清除率 {level=2 check="round((6-100*6/290)*100)/100"}
一名原发性烦渴患者每天排尿6 L，尿渗透压100 mOsm/kg。血浆渗透压290 mOsm/kg。计算自由水清除率（L/天），保留两位小数。
::: hint
$C_{osm} = U_{osm} V / P_{osm}$，然后$C_{H_2O} = V - C_{osm}$。
:::
::: solution
$C_{osm} = 100 \times 6 / 290 = 2.07$ L/天。$C_{H_2O} = 6 - 2.07 = 3.93$ L/天。肾脏每天排出近4 L无溶质的水，这正是摄入量高时它应该做的。
:::
:::

::: exercise 追踪电压 {level=2}
解释为什么升支粗段是镁重吸收的主要部位，并预测长期使用袢利尿药同时服用质子泵抑制剂（减少肠道镁吸收）对血浆镁的影响。
::: solution
在TAL中，经NKCC2进入细胞的钾通过ROMK再循环回管腔，使管腔相对于间质约为+10 mV。这一正电位推动镁和钙经细胞之间、通过紧密连接中基于claudin的通道移出管腔。袢利尿药阻断NKCC2，消除电压，增加尿镁丢失。质子泵抑制剂独立地减少肠道镁吸收。二者合用可引起明显的低镁血症，而低镁血症又会引起难治性低钾血症和低钙血症（[[renal/potassium-calcium-phosphate]]）。
:::
:::

::: exercise 最小尿量 {level=2 check="750/300"}
一名晚期慢性肾脏病患者的尿液既不能浓缩也不能稀释到超出约300 mOsm/kg。他每天排出750 mOsm溶质。他能产生的最小尿量是多少（L/天）？他为什么夜间要起床排尿？
::: solution
$V_{\min} = 750 / 300 = 2.5$ L/天。健康肾脏可在$750/1200 = 0.625$ L中排出同样的溶质。由于夜间不能通过浓缩来减少尿量，尿液整夜以稳定速率生成，导致夜尿。同样由于丧失浓缩能力，这些患者不能饮水时很快脱水，也不能排出大量水负荷，因此对高钠血症和低钠血症都易感。
:::
:::

::: exercise 锂剂与集合管 {level=2}
一名52岁女性因双相障碍服用锂剂20年，每天排尿5 L。她因跌倒入院，嗜睡两天。血浆钠158 mmol/L，锂浓度高于治疗范围。解释事件的经过。
::: solution
长期锂治疗引起了**肾性尿崩症**：锂经ENaC进入主细胞并减少水孔蛋白-2表达，因此她的集合管不能对ADH产生反应，产生大量稀释尿。她能按口渴饮水时可维持平衡。跌倒后嗜睡期间她无法饮水，持续失水而发生高钠血症。脱水降低GFR并增加近端小管对锂的重吸收（锂的处理方式与钠相似），使锂浓度升高，又加重嗜睡，形成危险的循环。处理应遵循当地指南：在血钠安全纠正速度内谨慎补水（[[renal/water-sodium]]），停用锂剂，并请专科评估是否需要透析清除锂。
:::
:::

::: exercise 定位糖尿 {level=3}
解释下列各例的糖尿并说明其机制。(a) 一名妊娠28周的女性，血浆葡萄糖6.0 mmol/L，尿糖1+。(b) 一名2型糖尿病男性开始服用达格列净（dapagliflozin）后，血浆葡萄糖7.0 mmol/L，尿糖3+。(c) 一名男性血浆葡萄糖22 mmol/L。(d) 一名健康的30岁人，持续尿糖2+，血糖正常，无其他肾小管异常。
::: solution
(a) 妊娠时GFR升高约50%，在任何血浆水平下葡萄糖滤过负荷都升高，而肾小管的转运能力并未同等增加。血糖正常时尿中也可出现葡萄糖。妊娠期糖尿常见，它不是妊娠期糖尿病的检测手段，后者需要葡萄糖耐量试验（[[obstetrics-gynaecology/pregnancy-complications]]）。

(b) 达格列净是**SGLT2抑制剂**：通过阻断近端小管前段的主要葡萄糖转运体，它降低了肾阈，使葡萄糖在血糖正常时被排出。这是预期效应。

(c) 滤过负荷超过**转运最大值**：高血糖引起的溢出性糖尿。

(d) 血糖正常、其他肾小管功能正常的孤立性糖尿是**家族性肾性糖尿**，通常由编码SGLT2的*SLC5A2*基因变异引起。它是良性的。这一“自然实验”使研发者相信用药物抑制SGLT2很可能是安全的。
:::
:::

::: exercise 设计多尿诊疗路径 {level=3}
为自述排尿量大的成人概述一套合乎逻辑的问题和检查顺序，从确认多尿到明确病因。
::: solution
1. 用24小时尿量**确认多尿**（每天超过约3 L），并与尿量少的尿频（膀胱或前列腺问题）和单纯夜尿相区别。
2. **测定尿渗透压**，区分**溶质性利尿**（尿渗透压接近或高于血浆，总溶质排出量高）和**水利尿**（尿液稀释，低于约300 mOsm/kg，常低于150）。
3. 对溶质性利尿，寻找溶质：葡萄糖（糖尿病、SGLT2抑制剂）、尿素（急性肾损伤恢复期或梗阻解除后、高蛋白营养）、钠（盐水输注、利尿药）、甘露醇。
4. 对水利尿，检查血浆钠、钙、钾和葡萄糖，并回顾用药（锂剂）。血钠正常偏高或升高支持尿崩症；血钠正常偏低支持原发性烦渴。
5. 若仍不明确，转诊进行专科检查：禁水加去氨加压素试验，或刺激后和肽素检测，以区分中枢性尿崩症、肾性尿崩症和原发性烦渴。
6. 对中枢性尿崩症，进行垂体和下丘脑影像检查（MRI）并评估垂体前叶功能；对肾性尿崩症，纠正可逆病因。
:::
