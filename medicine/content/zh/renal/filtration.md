心脏每分钟泵出的血液中，约有五分之一流经两个总重约300 g的器官。肾脏并不是为了自身代谢才需要如此大的血流。它们需要这样的血流，是因为其首要任务是滤过血浆，而滤器的用处取决于它能处理的容量。健康青年人的肾小球每天产生约180升滤液，其中几乎全部在肾单位的后续部分被重吸收，最后只留下一到两升尿液。

本课时讨论第一步：血液如何到达肾小球，滤过屏障允许什么通过，什么力驱动滤过，以及血压变化时肾脏如何保持滤过稳定。随后转向测定。肾小球滤过率（GFR）是肾脏病学中最有用的单一数值，但几乎从不直接测定。理解它是如何估算的、估算值何时会产生误导，可以在床旁避免实实在在的伤害。本课时最后介绍能在血液检查发生变化之前就揭示肾小球损伤的尿液检查。

接收滤液的肾小管是[[renal/tubular-function]]的主题。肾脏及其血管的解剖见[[anatomy/abdomen]]，体液分布见[[physiology/homeostasis-body-fluids]]。

## 血液供应与肾单位

每条肾动脉依次分为段动脉、叶间动脉、弓形动脉和小叶间动脉。小叶间动脉发出**入球小动脉**，每条入球小动脉供应一个肾小球。血液离开肾小球时不经小静脉，而是经第二条小动脉，即**出球小动脉**。两条阻力血管串联、中间夹着一个毛细血管床，这种不寻常的结构正是肾脏控制滤过的关键。

出球小动脉之后，血液进入第二个毛细血管网。在皮质肾小管周围，这就是**管周毛细血管**网，负责收回肾小管重吸收的液体。靠近髓质的肾小球的出球小动脉还发出细长的发夹形血管，即**直小血管**，它们供应髓质而不会冲走髓质的浓度梯度。

::: definition 肾血流与肾单位 {#def-flow}
静息成人的**肾血流量**（RBF）约为1.1 L/min，约占心输出量的20%～25%。**肾血浆流量**（RPF）是其中的血浆部分，即RBF ×（1 − 血细胞比容），约为600～650 mL/min。

**肾单位**是肾脏的功能单位：肾小球及其鲍曼囊，后接近端小管、髓袢、远曲小管和连接小管，连接小管汇入集合管。人的一个肾脏平均约含一百万个肾单位，个体差异很大。**皮质肾单位**的肾小球位于外层皮质，髓袢较短；**近髓肾单位**的肾小球靠近髓质，髓袢较长，深入髓质。

**滤过分数**是进入肾小球的血浆中被滤过的比例：

$$
\text{FF} = \frac{\text{GFR}}{\text{RPF}} \approx \frac{125}{650} \approx 0.2
$$ {#eq-ff}
:::

如此高的血流带来两个后果。第一，肾脏获得的氧远多于其消耗，因此肾静脉血的氧合程度相对较高。第二，髓质是例外：直小血管只承载一小部分血流，外髓的工作状态接近其供氧极限。这是灌注下降时髓袢升支粗段和近端小管直部最先受损的原因之一（[[renal/acute-kidney-injury]]）。

**球旁器**位于同一肾单位的升支粗段返回并接触其自身肾小球的部位，由三部分组成：**致密斑**，一小片感受小管液中氯化钠浓度的小管细胞；入球小动脉壁中的**颗粒细胞（球旁细胞）**，储存并释放肾素；以及位于二者之间的球外系膜细胞。这个小结构把肾小管与供应它的血流联系起来。

## 滤过屏障

滤液从肾小球毛细血管进入鲍曼囊腔，必须穿过三层结构。

1. **有孔内皮**。毛细血管壁上有直径约70～100 nm的窗孔，覆盖着带负电荷的糖萼。血细胞不能通过，血浆可以通过。
2. **肾小球基底膜**（GBM）。这是由Ⅳ型胶原、层粘连蛋白和硫酸乙酰肝素等带负电荷的蛋白聚糖构成的致密网状结构，由内皮和足细胞共有。
3. **足细胞**。这些上皮细胞以相互交错的足突包绕毛细血管。足突之间的间隙由**裂孔隔膜**桥接，这是一种拉链样结构，由nephrin和podocin等蛋白构成。

::: definition 肾小球滤过屏障 {#def-barrier}
**肾小球滤过屏障**是有孔内皮、肾小球基底膜和足细胞裂孔隔膜共同构成的整体。它主要按**大小**、其次按**电荷**限制分子通过。水、电解质、葡萄糖、尿素和肌酐可自由通过。半径小于约2 nm的分子几乎可以自由滤过；大于约4 nm的几乎完全不能通过。白蛋白（半径约3.6 nm，带负电荷）大部分被阻挡，因此正常滤液中只含少量白蛋白，并由近端小管重吸收。
:::

任何一层受损都会使蛋白质漏出。nephrin基因（*NPHS1*）突变引起先天性肾病综合征，说明了裂孔隔膜的重要性。Ⅳ型胶原链基因突变引起Alport综合征，患者的GBM分层断裂，出现血尿、进行性肾脏病，且常伴耳聋。在成人中，足细胞损伤是微小病变病、局灶节段性肾小球硬化和糖尿病肾病的基础，这些内容见[[renal/chronic-kidney-disease]]。

**系膜**位于毛细血管袢之间。系膜细胞支撑毛细血管丛，能够收缩，并清除滞留的蛋白质。沉积于此的免疫复合物是IgA肾病的起点，IgA肾病是全世界最常见的原发性肾小球肾炎。

## 驱动滤过的力

肾小球毛细血管的滤过遵循与所有毛细血管液体交换相同的Starling原理。跨毛细血管壁作用的有两种静水压和两种胶体渗透压。

::: theorem 肾小球的Starling力 {#thm-starling}
肾小球滤过率等于**超滤系数**$K_f$与**有效滤过压**的乘积：

$$
\text{GFR} = K_f \left[ (P_{GC} - P_{BS}) - (\pi_{GC} - \pi_{BS}) \right]
$$ {#eq-starling}

式中$P_{GC}$是肾小球毛细血管静水压，$P_{BS}$是鲍曼囊腔静水压，$\pi_{GC}$是毛细血管内血浆蛋白的胶体渗透压，$\pi_{BS}$是鲍曼囊腔的胶体渗透压，由于滤液几乎不含蛋白质，它接近于零。$K_f$是屏障的水通透性与其面积的乘积。
:::

::: proof
人类肾小球的典型教科书数值为$P_{GC} \approx 60$ mmHg、$P_{BS} \approx 18$ mmHg、平均$\pi_{GC} \approx 32$ mmHg，有效滤过压约为10 mmHg。取$K_f \approx 12.5$ mL/(min·mmHg)，得到GFR约为125 mL/min。

与肌肉毛细血管相比有两点不同。肾小球静水压高，且沿毛细血管几乎恒定，因为下游的出球小动脉是阻力血管，维持着压力。另外，血液流经毛细血管丛时约有五分之一的血浆水被移出，而蛋白质留在血管内，所以蛋白质浓度以及$\pi_{GC}$从入球端到出球端逐渐升高。有效滤过压在血液进入处最高，沿毛细血管逐渐下降。任何减慢血浆流动的因素都会使$\pi_{GC}$升高得更多、更早，因此GFR既取决于压力，也取决于血浆流量。
:::

::: example 两端的Starling力 {#ex-starling}
某肾小球中，$P_{GC}$全程为60 mmHg，$P_{BS}$为18 mmHg。胶体渗透压在入球端为28 mmHg，在出球端为36 mmHg。计算两端的有效滤过压并解释其差异。
::: solution
入球端：$60 - 18 - 28 = 14$ mmHg。

出球端：$60 - 18 - 36 = 6$ mmHg。

两端的静水压相同，因此全部差异来自胶体渗透压。滤过移出的是不含蛋白质的水，使留在毛细血管中的蛋白质浓缩，于是对抗滤过的力沿毛细血管丛逐渐增大。平均驱动压约10 mmHg，数值很小。这就是为什么肾小球需要一个非常大、通透性非常高的表面（高$K_f$）才能每分钟滤过125 mL。
:::
:::

这个方程可以解释疾病改变GFR的大多数方式。

- **$K_f$下降**：肾小球肾炎或糖尿病性硬化导致滤过面积丧失，或系膜收缩。
- **$P_{GC}$下降**：低血压；入球小动脉收缩（非甾体抗炎药去除前列腺素的扩血管作用、环孢素、休克时的去甲肾上腺素）；或出球小动脉扩张（ACE抑制剂或血管紧张素受体阻滞剂）。
- **$P_{BS}$升高**：尿路梗阻使压力沿肾小管逆向传递到鲍曼囊腔。
- **$\pi_{GC}$升高**：严重脱水伴血液浓缩，或血浆蛋白浓度很高，如骨髓瘤。

两条小动脉就像两个阀门。收缩**入球**小动脉会同时减少血流和肾小球压力，因此GFR下降。收缩**出球**小动脉会升高肾小球压力，因此GFR起初上升；但它同时减少血流，所以强烈收缩时胶体渗透压迅速升高，GFR又会下降。

## 保持GFR稳定：自身调节

如果GFR直接随血压变化，一个人站起来、跑步赶车或睡觉都会使尿量以及盐平衡改变数倍。实际上，在很宽的平均动脉压范围内，肾血流量和GFR几乎保持恒定。

::: definition 肾脏自身调节 {#def-autoregulation}
**自身调节**是指平均动脉压在约80～180 mmHg之间变化时，肾脏使肾血流量和GFR大致保持恒定的内在能力。它依赖两种作用于入球小动脉的机制：

- **肌源性反应**：入球小动脉平滑肌在压力升高被牵拉时收缩，压力下降时舒张；
- **管球反馈**：GFR升高时，到达致密斑的氯化钠增多；致密斑随即（主要通过腺苷和ATP）发出信号，使同一肾单位的入球小动脉收缩，使GFR回落。
:::

在自身调节范围之外，以及在调节范围上移的慢性高血压患者中，血流随压力变化。长期高血压的患者，若血压被迅速降到健康肾脏能耐受的水平，可能出现GFR下降。

激素和神经在自身调节之上发挥作用。

- **血管紧张素Ⅱ**收缩两条小动脉，但出球小动脉更敏感。因此灌注不足时，血管紧张素Ⅱ通过维持肾小球压力来保护GFR。
- **前列腺素**（PGE₂和PGI₂）扩张入球小动脉。健康时作用不大，但在肾脏灌注不足时，如心力衰竭、肝硬化、容量不足或慢性肾脏病时，就变得必不可少。
- **交感神经**收缩入球小动脉并刺激肾素释放。休克时可使肾血流量急剧减少。
- **心房钠尿肽**扩张入球小动脉、收缩出球小动脉，使GFR升高。

这就解释了肾脏病学中最著名的药物相互作用。

::: example 三重打击 {#ex-triple}
一名71岁女性患有心力衰竭，服用雷米普利（ramipril）和呋塞米（furosemide）。她因膝痛自行购买布洛芬（ibuprofen）。一周后她腹泻三天，肌酐从105升至290 µmol/L。解释其机制。
::: solution
发生了三件事，每一件都去除了维持肾小球压力的一道防线。

1. 利尿药和腹泻导致**容量不足**，使肾灌注下降。此时GFR依赖前列腺素扩张入球小动脉和血管紧张素Ⅱ收缩出球小动脉。
2. **布洛芬**抑制环氧合酶，去除了前列腺素对入球小动脉的扩张作用，于是进入肾小球的血液减少。
3. **雷米普利**阻止血管紧张素Ⅱ生成，使出球小动脉舒张，肾小球压力进一步下降。

肾小球压力崩溃，GFR下降。利尿药、ACE抑制剂或血管紧张素受体阻滞剂与非甾体抗炎药的这种组合被称为**三重打击**。通常的处理是停用非甾体抗炎药、恢复容量，并按当地急性肾损伤指南在她患病期间暂停ACE抑制剂和利尿药。更普遍的经验是给服用这些药物的人提供**患病日**建议：在发生伴脱水的疾病时暂停这些药物，恢复正常饮食饮水后再重新服用。
:::
:::

## 肾功能的测定

### 清除率

肾脏对任何物质的处理都可以用清除率来描述。

::: definition 肾清除率 {#def-clearance}
物质$x$的**肾清除率**是单位时间内肾脏将其中的$x$完全清除的血浆容积：

$$
C_x = \frac{U_x \times V}{P_x}
$$ {#eq-clearance}

式中$U_x$为尿中浓度，$V$为尿流率，$P_x$为血浆浓度。清除率的单位是容积/时间，通常为mL/min。
:::

清除率是比较排出量与滤过量的一种方法。

::: theorem 清除率揭示什么 {#thm-clearance}
如果某物质可自由滤过，且既不被肾小管重吸收也不被分泌，则其清除率等于GFR。如果其清除率低于GFR，说明存在净重吸收；如果高于GFR，说明存在净分泌。
:::

::: proof
对于可自由滤过的物质，每分钟的滤过量（**滤过负荷**）为$\text{GFR} \times P_x$，每分钟的排出量为$U_x \times V$。如果肾小管既不加入也不移除该物质，二者相等：$\text{GFR} \times P_x = U_x V$，所以$\text{GFR} = U_x V / P_x = C_x$。任何重吸收都会使排出量小于滤过负荷，所以$C_x < \text{GFR}$；任何分泌都会使其大于滤过负荷，所以$C_x > \text{GFR}$。
:::

**菊粉**是一种植物果糖聚合物，其行为正是如此，其清除率是测定GFR的参照方法。葡萄糖清除率正常为零，因为滤过的葡萄糖全部被重吸收。**对氨基马尿酸**（PAH）被滤过且被大量分泌，以致肾静脉血浆中几乎不剩，因此其清除率近似于肾血浆流量。实践中，今天测定GFR使用注射标志物（如碘海醇或⁵¹Cr-EDTA）的血浆清除率。只有在准确数值确实重要时才使用，例如评估潜在的活体肾脏捐献者或为毒性药物确定剂量。

### 肌酐与估算GFR

肌酐由肌肉中的肌酸以相当稳定的速率生成。它可自由滤过且不被重吸收，但尿中肌酐约有10%～20%来自近端小管分泌。因此由定时尿收集计算的肌酐清除率会略高估GFR，且GFR越低误差越大。

稳态时，肌酐生成量$G$等于排出量，约为$\text{GFR} \times P_{Cr}$。因此

$$
P_{Cr} \approx \frac{G}{\text{GFR}}
$$ {#eq-hyperbola}

血浆肌酐与GFR成反比。二者的关系是一条双曲线，这一形状具有重要意义。

曲线的前段平坦。一个人可能丧失一半的GFR，而肌酐仍在实验室参考范围之内。曲线后段陡峭，GFR再小幅下降也会使肌酐大幅升高。

肌酐生成量取决于肌肉量、饮食和年龄。一位肌肉发达的年轻男性和一位衰弱的老年女性可能肌酐相同而GFR相差悬殊。为此，实验室会报告由肌酐、年龄和性别计算的**估算GFR**（eGFR）。

::: definition 估算GFR {#def-measure}
**估算GFR**（eGFR）是根据血清肌酐（有时加上胱抑素C）、年龄和性别，用在测定过GFR的人群中推导出的方程计算的数值。其单位为mL/(min·1.73 m²)，即按平均体表面积标准化。

- **CKD-EPI**（慢性肾脏病流行病学协作组）方程是标准方程。截至2026年，英国实验室按照NICE（NG203，2021）和英国肾脏协会的意见，报告**不含**种族系数的2009年CKD-EPI肌酐方程。其他一些国家使用不含种族因素的2021年CKD-EPI方程。
- **胱抑素C**是所有有核细胞都产生的小分子蛋白。它较少依赖肌肉量，在肌肉量异常时，单独使用或与肌酐联合使用胱抑素C计算eGFR会有帮助。
- **Cockcroft–Gault公式**根据年龄、体重、性别和肌酐估算肌酐清除率，单位为mL/min（未按体表面积标准化）。许多药物剂量建议是用它制定的。

所有这些方程都假定处于**稳态**：肌酐的生成和排出必须平衡。
:::

Cockcroft–Gault公式的国际单位制形式为

$$
\text{CrCl (mL/min)} = \frac{(140 - \text{年龄}) \times \text{体重 (kg)} \times k}{\text{肌酐 } (\mu\text{mol/L})}
$$ {#eq-cg}

男性$k = 1.23$，女性$1.04$。

::: example 并不正常的“正常”肌酐 {#ex-creatinine-trap}
一名84岁女性，体重48 kg，肌酐95 µmol/L，在实验室参考范围内。她即将开始服用一种经肾脏清除的药物，若肌酐清除率低于30 mL/min须减量。估算她的肌酐清除率。
::: solution
用Cockcroft–Gault公式：

$$
\text{CrCl} = \frac{(140 - 84) \times 48 \times 1.04}{95} = \frac{2795.5}{95} \approx 29 \text{ mL/min}
$$

她的肌酐看起来正常，是因为她肌肉很少，生成的肌酐也少。她实际的清除率约为年轻成人的四分之一，刚好低于剂量调整阈值。药物剂量应根据产品说明书和当地指南调整。一般规律是：在体型小、年老或衰弱的人中，“正常”的肌酐可能掩盖明显降低的GFR。应通过方程来解读肌酐，并在确定药物剂量时使用患者的实际体重。
:::
:::

::: warning eGFR的两个陷阱 {#warn-egfr}
**肌酐在变化时，eGFR没有意义。**肾功能突然丧失后，肌酐需要一到三天才升到新的稳态水平。在这段时间内，用不断上升的数值计算出的eGFR会高估真实的GFR，有时高估得非常厉害。一个已经无尿的人在第一天早晨的“eGFR”仍可能在60以上。在急性肾损伤中，应追踪肌酐的变化和尿量，而不是eGFR（[[renal/acute-kidney-injury]]）。

**eGFR是按1.73 m²标准化的。**为体型很大或很小的人确定药物剂量时，以mL/min表示的绝对清除率才是关键。一个45 kg、eGFR为50 mL/(min·1.73 m²)的人，其绝对GFR比这个数值所提示的更小。许多药品说明书因此使用Cockcroft–Gault肌酐清除率。
:::

还有一些因素会改变肌酐而不改变GFR。进食熟肉后数小时内肌酐会升高。某些药物，特别是甲氧苄啶（trimethoprim）和西咪替丁（cimetidine），阻断肾小管对肌酐的分泌，使血浆肌酐轻度升高，而真实GFR不变。较老的比色法（Jaffe法）可被酮体干扰而假性升高，如糖尿病酮症酸中毒时。胱抑素C也有自身的干扰因素：糖皮质激素、甲状腺疾病和炎症可独立于GFR改变其水平。

::: quiz {#quiz-creatinine}
一名25岁健美运动员服用肌酸补充剂，肌酐140 µmol/L，eGFR 58 mL/(min·1.73 m²)。尿试纸检查正常，自觉良好。下列哪一项下一步检查最能判断他的GFR是否真的降低？
- [ ] 明天复查肌酐
- [ ] 按慢性肾脏病开始服用ACE抑制剂
- [x] 测定胱抑素C并据此计算eGFR
- [ ] 安排肾活检
::: solution
肌酸补充剂和大量肌肉都会增加肌酐生成，因此肌酐会夸大GFR的下降。复查肌酐只会得到同样的结果。胱抑素C受肌肉量影响小得多，所以基于胱抑素C（或肌酐与胱抑素C联合）的eGFR才是判断他的肾功能是否真的降低的正确方法。尿液正常、仅凭单次基于肌酐的数值，没有理由进行治疗或活检。
:::
:::

::: example 定时尿收集 {#ex-clearance}
一名40岁男性的24小时尿收集量为1.8 L，尿肌酐浓度为8.0 mmol/L。其血浆肌酐为100 µmol/L。计算他的肌酐清除率（mL/min）。
::: solution
先统一两个浓度的单位：$U_{Cr} = 8.0$ mmol/L $= 8000$ µmol/L。

$$
C_{Cr} = \frac{U \times V}{P} = \frac{8000 \times 1.8}{100} = 144 \text{ L/day}
$$

一天有1440分钟，所以$144\,000 \text{ mL} / 1440 = 100$ mL/min。

这是正常值。定时尿收集最大的实际误差是收集不全：漏掉一次排尿会降低测得的清除率。一个有用的核对方法是肌酐总排出量，此处为$8.0 \times 1.8 = 14.4$ mmol/天，对一名普通成年男性来说是合理的（取决于肌肉量，约为每天9～18 mmol）。
:::
:::

## 观察尿液

血液检查显示肾功能，尿液则显示肾损伤，而且往往更早显示。

::: definition 蛋白尿与血尿 {#def-urine-markers}
**白蛋白尿**以随机尿的**白蛋白/肌酐比值**（ACR）测定，以校正尿液浓度。正常ACR低于3 mg/mmol。ACR 3～30 mg/mmol为中度增高，高于30 mg/mmol为重度增高（即慢性肾脏病中使用的A1～A3分级）。**蛋白/肌酐比值**（PCR）测定全部蛋白质，包括轻链和肾小管蛋白；PCR约300 mg/mmol大致相当于每天3 g蛋白质，即肾病范围。

**血尿**是尿中有血。**肉眼**血尿肉眼可见；**镜下**血尿由尿试纸检出（1+或以上），并经重复检查确认。来自肾小球的红细胞常变形（畸形红细胞），并可形成**红细胞管型**，证明出血来源于肾小球。
:::

尿试纸检查便宜，信息量大：血、蛋白、白细胞、亚硝酸盐、葡萄糖和比重。它的局限也值得了解。蛋白试剂块检测白蛋白而不检测轻链，因此会漏诊骨髓瘤肾病。隐血试剂块对血红蛋白和肌红蛋白以及完整红细胞都有反应，所以试纸阳性而镜检无红细胞提示横纹肌溶解或溶血。

显微镜下，**管型**是在肾小管中塑形的蛋白质（Tamm–Horsfall蛋白，又称尿调节素）圆柱体。透明管型在浓缩尿中是正常的。红细胞管型提示肾小球肾炎，白细胞管型提示肾盂肾炎或间质性肾炎，颗粒性“泥棕色”管型提示急性肾小管坏死。

::: example 从微量蛋白到三克 {#ex-proteinuria}
一名52岁英国黑人男性患2型糖尿病12年，进行常规复查。尿试纸示蛋白1+。ACR为45 mg/mmol，两个月后复查为52 mg/mmol。eGFR为64 mL/(min·1.73 m²)。血压148/92 mmHg。解读这些结果。
::: solution
两次ACR均高于30 mg/mmol，证实为**重度增高的白蛋白尿（A3）**。结合eGFR 64（G2级），即使单看eGFR不会提示，他也患有慢性肾脏病，因为白蛋白尿是肾损伤的标志。对于长期糖尿病且无其他特征的人，最可能是糖尿病肾病，它始于足细胞和GBM损伤，在GFR下降之前就漏出白蛋白。

白蛋白尿之所以重要，是因为它既预测肾功能更快丧失，也预测心血管事件。它也是治疗靶标：控制血压、ACE抑制剂或血管紧张素受体阻滞剂，以及SGLT2抑制剂都能减少白蛋白尿并延缓进展，见[[renal/chronic-kidney-disease]]。血尿、活动性尿沉渣或eGFR快速下降则提示可能是另一种肾小球疾病，应转诊。
:::
:::

::: history
1842年，鲍曼（William Bowman）详细描述了肾小球，证明每个毛细血管丛都位于一条肾小管的盲端。19世纪40年代，路德维希（Carl Ludwig）提出尿液起始于由血压驱动的血浆滤液，这一观点花了八十年才得到证实。1924年，韦恩（Joseph Wearn）和理查兹（Alfred Richards）将细玻璃微管插入蛙肾的鲍曼囊腔，证明其中的液体不含蛋白质，但所含葡萄糖和氯离子与血浆浓度相同：这是真正的超滤液。1926年，丹麦生理学家雷贝格（Poul Brandt Rehberg）提出以肌酐清除率衡量滤过；20世纪30年代，史密斯（Homer Smith）和香农（James Shannon）确立了菊粉清除率作为参照方法。现代的eGFR方程正是这一清除率概念在临床上的后代。
:::

## 后续内容

180升滤液的去向是[[renal/tubular-function]]的主题。钠和水的调节依赖GFR和球旁器释放的肾素，见[[renal/water-sodium]]。GFR的突然下降是急性肾损伤（[[renal/acute-kidney-injury]]）；缓慢下降并伴有白蛋白尿这一标志的，是慢性肾脏病（[[renal/chronic-kidney-disease]]）。肾功能减退时的药物剂量以本课时的清除率概念为基础，见[[pharmacology/dosing-principles]]。

::: summary
- 肾脏接受约20%～25%的心输出量；肾血浆流量约600～650 mL/min，GFR约125 mL/min，滤过分数约为0.2。
- 滤液穿过有孔内皮、肾小球基底膜和足细胞裂孔隔膜，它们按大小和电荷限制分子通过；白蛋白大部分被阻挡。
- GFR $= K_f \times$有效滤过压。肾小球压力由入球和出球小动脉张力的平衡决定；胶体渗透压沿毛细血管逐渐升高。
- 自身调节（肌源性反应和管球反馈）使GFR在平均动脉压约80～180 mmHg之间保持稳定。前列腺素扩张入球小动脉，血管紧张素Ⅱ收缩出球小动脉；非甾体抗炎药和ACE抑制剂去除这些防线。
- 清除率$= UV/P$。菊粉清除率等于GFR；肌酐因被分泌，其清除率略高估GFR。
- 血浆肌酐与GFR成反比，因此早期的GFR丧失几乎不改变肌酐。eGFR方程校正了年龄和性别，但假定处于稳态，在急性肾损伤和肌肉量极端时会产生误导。
- 白蛋白/肌酐比值、尿试纸和显微镜检查可发现肾小球损伤；红细胞管型证明出血来源于肾小球。
:::

## 习题

::: exercise 滤过分数 {level=1 check="0.2"}
一名男性肾血流量为1000 mL/min，血细胞比容0.40，GFR 120 mL/min。以小数形式计算他的滤过分数。
::: hint
先求肾血浆流量：RPF = RBF ×（1 − 血细胞比容）。
:::
::: solution
RPF $= 1000 \times (1 - 0.40) = 600$ mL/min。滤过分数$= 120 / 600 = 0.2$。进入肾小球的血浆中有五分之一被滤过。
:::
:::

::: exercise 排列各种压力 {level=1}
列出肾小球的四种Starling力，并说明每一种是促进还是对抗滤过。其中哪一种沿毛细血管变化最大？为什么？
::: solution
肾小球毛细血管静水压（$P_{GC}$）促进滤过。鲍曼囊腔静水压（$P_{BS}$）对抗滤过。肾小球毛细血管胶体渗透压（$\pi_{GC}$）对抗滤过。鲍曼囊腔胶体渗透压（$\pi_{BS}$）本应促进滤过，但由于滤液几乎不含蛋白质，它接近于零。毛细血管内的胶体渗透压变化最大：血液流经毛细血管丛时，不含蛋白质的液体被移出，剩余血浆变得更浓，所以$\pi_{GC}$从入球端到出球端逐渐升高。
:::
:::

::: exercise 定时清除率 {level=1 check="round(6000*2.4/120/1.44)"}
24小时尿收集量为2.4 L，尿肌酐浓度为6.0 mmol/L。血浆肌酐为120 µmol/L。计算肌酐清除率（mL/min），四舍五入到整数。
::: hint
把尿肌酐换算成µmol/L，先算出以L/day表示的清除率，再换算为mL/min（1 L/day = 1000/1440 mL/min）。
:::
::: solution
$U = 6000$ µmol/L。清除率$= 6000 \times 2.4 / 120 = 120$ L/day。换算为mL/min：$120\,000 / 1440 = 83.3$，即约**83 mL/min**。
:::
:::

::: exercise 鲍曼囊腔压力升高 {level=2 check="12.5*(60-25-32)"}
某肾小球$K_f = 12.5$ mL/(min·mmHg)，$P_{GC} = 60$ mmHg，平均$\pi_{GC} = 32$ mmHg。一块梗阻性结石使鲍曼囊腔压力从18升至25 mmHg。假设其他数值不变，计算新的GFR（mL/min）。在接下来的数小时内实际会发生什么？
::: solution
有效滤过压$= 60 - 25 - 32 = 3$ mmHg，所以GFR $= 12.5 \times 3 = 37.5$ mL/min，原来为$12.5 \times 10 = 125$ mL/min。

实际上其他数值确实会变。梗阻早期，入球小动脉扩张（通过前列腺素），部分恢复肾小球压力。之后，血管紧张素Ⅱ和血栓素收缩血管，肾血流量下降。长时间梗阻会导致肾小管萎缩和永久性功能丧失，这就是为什么梗阻的肾脏需要及时减压，若合并感染则须立即减压（[[renal/urinary-tract]]）。
:::
:::

::: exercise Cockcroft–Gault公式 {level=2 check="round(70*80*1.23/110)"}
一名70岁男性，体重80 kg，肌酐稳定在110 µmol/L。用Cockcroft–Gault公式估算其肌酐清除率，四舍五入到整数mL/min。
::: solution
$$
\text{CrCl} = \frac{(140 - 70) \times 80 \times 1.23}{110} = \frac{6888}{110} = 62.6
$$

即约**63 mL/min**。这只是因为他的肌酐稳定，估算才合理；在急性肾损伤期间该公式无效。
:::
:::

::: exercise 选择估算方法 {level=2}
为下列每个人选择最合适的肾功能评估方法并说明理由。(a) 一名78岁男性，患肌萎缩侧索硬化，肌肉明显萎缩，肌酐55 µmol/L。(b) 一名40岁女性，正在接受活体肾脏捐献评估。(c) 一名30岁男性，因血管炎服用大剂量泼尼松龙（prednisolone），肌酐88 µmol/L。
::: solution
(a) **基于胱抑素C的eGFR**。他肌肉很少，生成的肌酐也少，因此基于肌酐的eGFR会高估他的GFR。

(b) **测定GFR**，例如碘海醇或⁵¹Cr-EDTA的血浆清除率。捐献不可逆，这一决定值得用测定值而不是估算值。

(c) **基于肌酐的eGFR**，谨慎解读；若准确数值会改变处理，则测定GFR。糖皮质激素可独立于GFR升高胱抑素C，所以胱抑素C估算会低估他的GFR。
:::
:::

::: exercise 两条小动脉 {level=2}
预测下列情况对GFR和肾血浆流量的即时影响：(a) 入球小动脉强烈收缩；(b) 出球小动脉中度收缩；(c) 双侧肾动脉狭窄患者服用ACE抑制剂引起出球小动脉扩张。逐一解释。
::: solution
(a) 二者都下降。进入肾小球的血液减少，肾小球压力下降。

(b) GFR上升，血浆流量下降。收缩部位上游的肾小球压力升高，但流出的血液减少，所以滤过分数增加。若收缩严重，胶体渗透压沿毛细血管升高过多，GFR也会下降。

(c) GFR急剧下降。双侧肾动脉狭窄时，到达肾小球的压力低，GFR依赖血管紧张素Ⅱ维持出球小动脉收缩。去除血管紧张素Ⅱ使肾小球压力下降。这就是为什么开始使用ACE抑制剂或血管紧张素受体阻滞剂一到两周后要复查肌酐；肌酐升高超过约30%（或eGFR下降超过25%）时，需重新评估用药并寻找肾血管疾病。
:::
:::

::: exercise 隐藏的一半 {level=3 check="9600/160"}
用稳态模型$P_{Cr} = G/\text{GFR}$，取$G = 9.6$ µmol/min。(a) 一名女性的肌酐在两年内从80升至160 µmol/L，期间身体状况良好。假设$G$不变，她新的GFR是多少mL/min？(b) 解释为什么肌酐加倍被描述为GFR减半，以及为什么因此仍在或接近参考范围的肌酐可能掩盖大量的肾功能丧失。
::: hint
以L/min表示的GFR等于$G/P_{Cr}$，其中$G$单位为µmol/min，$P_{Cr}$单位为µmol/L。乘以1000得到mL/min。
:::
::: solution
(a) GFR $= 9.6 / 160$ L/min $= 0.06$ L/min $= 60$ mL/min。她原来的GFR为$9.6/80 = 0.12$ L/min，即120 mL/min。

(b) 由于$P_{Cr}$与GFR成反比，无论起点如何，肌酐乘以二就意味着GFR除以二。在曲线起始段，肌酐绝对值改变80 µmol/L对应GFR丧失60 mL/min；而在曲线后段，同样从400升至480只对应丧失4 mL/min。女性肌酐参考上限约为100 µmol/L，这意味着一位起始值为50的女性可以丧失一半GFR，而每次结果都报告为正常。趋势、eGFR和白蛋白尿比单次肌酐对照参考范围更有信息量。
:::
:::

::: exercise 解读尿试纸 {level=3}
检测三份尿样。(a) 一名19岁跑步者马拉松后：隐血3+，蛋白1+，镜检无红细胞，肌酸激酶48 000 U/L。(b) 一名15岁男孩两天前咽痛：肉眼血尿，隐血3+，蛋白1+，可见红细胞管型，血压正常，肌酐正常。(c) 一名68岁女性，背痛伴贫血：尿试纸蛋白阴性，但PCR 250 mg/mmol，ACR 8 mg/mmol。分别给出最可能的解释。
::: solution
(a) 隐血试剂块是对**肌红蛋白**而非红细胞起反应：极限运动后的**横纹肌溶解**。肌红蛋白对肾小管有毒性，他有发生急性肾损伤的风险；首要任务是补液并监测肌酐和钾。

(b) 咽部感染后一到两天出现的肉眼血尿伴红细胞管型，提示**IgA肾病**（咽炎同步血尿）。链球菌感染后肾小球肾炎通常在感染后一到三周出现。红细胞管型证实出血来源于肾小球。

(c) 总蛋白（PCR）与白蛋白（ACR）之间差距很大，而尿试纸阴性，说明大部分蛋白质不是白蛋白。结合背痛和贫血，这种蛋白很可能是来自**骨髓瘤**的**游离轻链**。她需要检查血清游离轻链和蛋白电泳（[[blood/lymphoma-myeloma]]）。
:::
:::
