肾的第一个动作就是滤过：**一个高压的、双毛细血管的器官，把四分之一的心输出量推过一个按电荷与大小选择的滤器，把血浆（减去它的蛋白）呈递给四厘米上皮的管道，以便每小时被重新处理。**本章建立血液动力学（斯塔林的力与自身的调节）、滤过的屏障（内皮与基底膜和足细胞）、肾小球滤过的率的量化（肌酐的数学与它臭名的陷阱）、以及让肾小管与肾小球的疾病在血液的检查改变之前就可见的尿的化验。肾小球的疾病自己与它们的慢性的后果在[[renal/chronic-kidney-disease]]；下游的管道在[[renal/tubular-function]]。

本章涵盖肾血液的流动与滤过的屏障、肾小球滤过的率的控制、肾的功能的测量与估计，以及尿的筛查。

## 流动与滤器

::: definition 肾的血液的流动与肾单位的血管的特化 {#def-flow}
**肾接受每分钟1.1到1.2升——约为身体的0.4%的质量得到心输出量的20%到25%（[[cardiovascular/cardiac-cycle]]的器官分配的表）——通过短而直接的来自主动脉的肾动脉，并且约90%分配到皮质（肾小球：高的流量与低的阻力），约10%分配到髓质（直的小血管：低的流量并保存盐与尿素——[[renal/tubular-function]]的逆流的经济——并易受非甾体的与镰状的以及对比剂的髓质的缺氧：[[renal/acute-kidney-injury]]的乳头坏死的这份清单）。独有的架构：串联的两个毛细血管的床（入球的与出球的 arterioles 之间的肾小球）；出球小动脉下游的第二个毛细血管丛（在皮质管周的毛细血管，在髓质的直的小血管）因此没有被压力的降落所剥夺而血浆的蛋白被浓缩——这是肾小管的重吸收的物理的基础（[[#ex-starling]]）；以及近的小球的装置（入球颗粒细胞肾素的储存与致密斑，以及肾小球外系膜的细胞）作为[[renal/water-sodium]]的肾素与血管紧张素及醛固酮的系统以及[[#def-autoregulation]]的感觉与效应的节点。滤过自己：肾的毛细血管静水的压力（约60毫米汞柱）被鲍曼的囊的静水的压力与血浆的胶体的渗透的压力对抗；而滤过的屏障——有窗的内皮与带阴离子唾液酸蛋白聚糖的基底膜，以及带裂隙的膜的足细胞——按大小与电荷选择：白蛋白几乎被拒绝，而小的阳离子比同样的阴离子更容易通过。每日约180升的超滤液，其中约99%被重新吸收——这就是为什么滤过的缺陷，而不是滤过的负荷，才是钠的潴留的机制（[[renal/water-sodium]]）。**
:::

::: definition 自身的调节与激素的叠加 {#def-autoregulation}
**肾的血液的流动与肾小球的滤过的率在约80到180毫米汞柱动脉的压力之间被保持在接近恒定（自身的调节），通过两个内在的机制：肌原的反应（入球小动脉的平滑肌牵张的收缩——贝利斯的效应；[[physiology/integrative-physiology ]]）；以及肾小管的肾小球的反馈（致密斑对钠与氯的阅读，通过[[renal/tubular-function]]的个共同的转运体，也就是袢的利尿剂的靶点，来决定腺苷的释放与入球的张力：更多远端的盐意味着需要更少的滤过，所以入球收缩——单个肾单位自身的调节与整个的肾共享的机制让滤过的分数保持恒定）。在这个内在的框架上，这个系统叠加：交感的α的反应（在出血与脓毒症以及心衰中的强烈的收缩者——肾前的少尿，以及[[cardiovascular/heart-failure]]与[[renal/acute-kidney-injury]]的心肾与肝肾的综合征，还有[[renal/chronic-kidney-disease]]的有效动脉血容量的课）；血管紧张素II（优先出球的收缩——在灌注下降时保住滤过的压力这一适应的动作；但同时会把系统的高血压传递到肾小球，这是狭窄的肾动脉的教训）；以及前列腺素（一种局部的血管的扩张者，保持入球的小动脉开放，尤其在低流量的状态中——这就是非甾体把肾前的状态变成急性肾损伤的那个分子的位置）。临床的含义就是三重的：自身的调节这一曲线解释了为什么系统性的高血压会到达肾小球；环的利尿剂会通过打断致密斑的阅读来干扰反馈；而当前列腺素与血管紧张素同时被阻断时（非甾体加上转换酶抑制剂的组合，再加利尿剂导致的容量下降这一第三种打击），滤过的压力会崩溃——也就是[[#ex-triple]]。**
:::

::: example 斯塔林的力：两端 {#ex-starling}
肾的毛细血管：静水的48，鲍曼囊静水的12，毛细血管胶体渗透的25，鲍曼囊胶体的0毫米汞柱。管周的毛细血管：静水的13，间质静水的负2，毛细血管胶体渗透的32，间质胶体的8毫米汞柱。计算这两净的力，并解释它们生理相反的方向。
::: solution
**肾小球：(48 − 12) − (25 − 0) = 36 − 25 = 正11毫米汞柱的净的滤过（向外）。胶体的项沿着毛细血管上升（当血浆被滤过时蛋白被保留），所以净力在出球的一端之前接近于零（滤过压力的平衡——而当血浆的蛋白高或流量低时它更早地发生[[#def-flow ]]）。管周的毛细血管：(13 − (−2)) − (32 − 8) = 15 − 24 = 负9毫米汞柱的净的重吸收（向内）：双重压力的降落（两个小动脉）留下低静水的项，而20%的滤过的分数浓缩了出球的蛋白——两项都支持被重吸收的液体的吸收（近端小管把溶质与水拉出的物理的基础；以及在肾病综合征中胶体下降时形成水肿的翻转[[renal/chronic-kidney-disease]]与[[pathology/haemodynamics]]，或在心衰中静水的上升时[[cardiovascular/heart-failure ]]）。**
:::
:::

## 量化功能

::: definition 肾小球的滤过率：测量、估计与它的陷阱 {#def-measure}
**肾小球的滤过率有功能的肾单位的滤过的总和——正常约为每分钟90到120毫升每1.73平方米，在四十岁之后每年下降约1)被清除率测量（物质的标准——自由地被滤过，既不被重吸收也不被分泌也不被合成：菊粉与碘的海他酸及铬的乙二胺四乙酸与碘海醇参考的方法——[[clinical-skills/laboratory-tests]]的特殊化学的角落，以及让它们成为研究而不是门诊的工具的尿的收集与血的采样的后勤）。在实践中，肌酐肌肉磷酸肌酸非酶降解的产物——被滤过加上约10%到20%被分泌，所以肌酐的清除率会稍微高估滤过率；的测定的干扰（Jaffe的方法对酮体与头孢及葡萄糖的多读），以及决定性的稳定的状态的假设——生产必须是恒定的，所以滤过的任何急的改变都会让血肌酐成为一个滞后的指标（[[#quiz-creatinine ]]）)填满了常规照护，并被内源性的估计的方程所改变：以肌酐为基础的方程（带关于种族的系数与肌肉的质量的这场持续的辩论）、以胱抑素C为基础的（由所有有核的细胞产生，不受肌肉影响，但在炎症与甲状腺的状态中会变），以及两者的组合；并且要记得方程被校准于人群，而被应用于个体（[[renal/chronic-kidney-disease]]的分期与剂量）。陷阱：稳定的状态（急性的肾的损伤期间肌酐会滞后[[#quiz-creatinine ]]）；肌肉的质量与饮食（素食与肉食；截肢与神经肌肉的疾病；以及高与低的体重指数[[#ex-creatinine-trap ]]）；分泌（让肌酐的清除率高估滤过率约10%到20%，而甲氧苄啶与西咪替丁会阻断它）；以及肾外的途径（在少的尿量时对肠的渗漏，这在晚期疾病中会变得重要）。测量的适应证：当方程不可靠时（肥胖与截肢；素食；重症的肌病；以及药物剂量的边界）、在供者的评估中，以及在临床试验中。**
:::

::: example 骗人正常的肌酐 {#ex-creatinine-trap}
三位患者的血的肌酐都是每升90微摩尔：一位24岁的健美者；一位79岁带卒中后的偏瘫与摄入差的女性体重指数17)；以及一位在三十周妊娠的34岁的人。谁有正常的肾的功能？
::: solution
**几乎可以肯定只有那位健美者。肌酐既是滤过的报告者，也是肌肉的质量与稀释的报告者（[[#def-measure]]）：有消瘦与低摄入的年轻卒中后的生还者产生很少的肌酐——每升90微摩尔可能与真正的低于40的滤过率相伴（在药物剂量之前用胱抑素C或测量的清除率来验证这一规则[[pharmacology/dosing-principles]]与[[geriatrics-palliative/polypharmacy]]）；孕妇被扩张的血容量与肾小球的超滤过会驱肌酐到每升50到60——90就是一个相对升高，需要重复与尿的化验（妊娠参考范围的纪律[[obstetrics-gynaecology/pregnancy-antenatal]]）；而健美者的高的生产能掩盖一个早期的下降（胱抑素C的决胜）。概括：**永远不要在没有肌肉的质量与容量的状态，以及趋势和尿的情况下读一个肌酐；而在身体组成的极端处，停止估计并开始测量（[[renal/chronic-kidney-disease]]的证实的算法）.**
:::
:::

::: example 三重的打击 {#ex-triple}
一位76岁因高血压服用雷米普利与苄氟噻嗪的人，如今又为新发的髋痛服用布洛芬（加上病毒性胃肠炎的一周），带着意识混乱与钾6.1就诊，而肌酐在十天内从95升到了240。
::: solution
**由经典药理的三重加上容量不足所致的血液动力学介导急性的肾的损伤（[[renal/acute-kidney-injury]]与[[pharmacology/adverse-reactions]]共享的范例）：噻嗪与胃肠炎耗尽容量（入球的收缩者主导）；非甾体移除了前列腺素入球扩张的制动（[[#def-autoregulation]]）；而转换酶的抑制剂移除了血管紧张素II的出球的收缩——正是它在维持滤过的压力——所以滤过率从小动脉的两端崩溃（这条双曲线把肌酐的上升转化为超过60%的滤过的下降）。高钾是三重的来源：转换酶的阻断与酸中毒（[[renal/acid-base-disorders]]）以及低远端的流量——[[renal/potassium-calcium-phosphate]]的分泌的要求。管理：停用这三种元凶的药物（并带上被记录的过敏的标签替代镇痛的计划——对乙酰氨基酚与局部及物理治疗的路径[[musculoskeletal/osteoarthritis ]]）；扩容并监测（心电与钙及胰岛素和葡萄糖的急的钾的方案）；在容量被纠正后复查；教育（在疾病的期间和新的非甾体的处方期间生病时的停药这一规则）；并把这个组合写进这份记录，因为未来的每一个处方者都会读到肌酐。**
:::
:::

:::

## 筛查尿

::: definition 尿的标记物：蛋白尿与血尿 {#def-urine-markers}
**蛋白尿同时是肾的疾病的最早的标记物、这个中介物以及这个治疗的目标（慢性的肾的疾病这一网格的白蛋白尿对进展的风险的条轴；以及让微量的白蛋白尿也成为一份系统内皮报告的心血管风险的标记物，[[cardiovascular/coronary-artery-disease ]]）。按机制解读：肾小球的（电荷与大小的屏障的失败——以白蛋白为主，以及[[renal/chronic-kidney-disease]]的肾病范围的每日超过3克这个故事）；肾小管的（重吸收失败低分子量的蛋白——β2-微球蛋白与视黄醇的结合的蛋白及氨基酸尿——在针对白蛋白的试纸上看不见或只有痕迹，只能被总的蛋白或特异的测定捕获——所以骨髓瘤与药物的肾小管的病变会不一致：[[blood/lymphoma-myeloma]]的轻链的蛋白尿，以及一些药物的肾病）；以及溢出的（滤过负荷的超出——轻链与肌红蛋白及溶菌酶，[[blood/anaemia]]与[[blood/leukaemia ]]）。白蛋白尿的量化：早晨第一份尿的白蛋白对肌酐的比率（取代了收集的笨拙），它把分级与风险相连，并被运动与发热及月经和充血以及高血糖所影响——这些会引发重复的确认。试纸的限度：它检测白蛋白，不检测轻链，在碱性的与稀释的尿里会假阳性，并在浓缩的尿里假阴性；所以持续的蛋白尿需要定量的确认。显微镜的部分让诊断变得具体：肾小管的管型意味着肾的实质的疾病；红细胞的管理意味着肾小球的出血；白的细胞与管理的意义弱（感染、间质的肾炎），而结晶与卵形脂肪的椭圆体是有用的。血尿：肾小球（畸形红细胞、管理，以及伴随的蛋白尿——转诊到肾内科）对非肾小球（整个尿路的血块——转诊到泌尿外科，并在风险者中终身进行恶性的排除[[renal/urinary-tract]]；运动后的与月经的和良性的家庭性血尿解释，以及IgA的肾病这个经典的首次发现）。**
:::

::: example 从痕迹到三克 {#ex-proteinuria}
一位29岁的无症状的运动员在职业的体检中试纸的蛋白为加号；重复的晨尿为阴性；而他训练之后的那份为三个加号；肾的功能与血压以及沉渣都正常；没有水肿。
::: solution
**经典良性的这份工作检查：被证明为暂时或体位或运动相关孤立试纸的阳性（阴性的晨的第一份尿就是有鉴别力的那个检查——年轻人的直立与运动后的蛋白尿[[#def-urine-markers ]]）。负责任的路径：用定量的白蛋白对肌酐的比率在晨的第一份尿与晚些的那份尿重复（体位的模式——平卧正常而直立升高——只在含糊时通过夜间分割的收集来确认）；血压与估计的滤过率和沉渣；以及（如果持续）超声与转诊的触发（蛋白尿加血尿加高血压加功能受损这个组合必须转诊肾内科——[[renal/chronic-kidney-disease]]的肾小球疾病的那个门槛）；对运动员的咨询（运动诱发良性的蛋白尿不需要限制，但关于补充剂与非甾体和对比剂的这场对话，以及每年的血压与尿是明智的）；以及值得审计的记录，它会停止重复检查的螺旋（过度的检查与保险的影响这场对话）。**
:::

::: history
**滤过这一学说从鲍曼1842年的囊的解剖与路德维格超滤过这个模型成长起来，通过魏尔顿与威恩以及理查兹的直接肾的静脉与微穿刺的证据（尿开始为一个无蛋白的滤液，然后被修饰）；霍默史密斯的清除率的时代与菊粉的金标准；四五十年代的微穿刺与清除率的综合（单个肾单位滤过率的证明）；肾小管肾小球反馈的发现（七十年代致密斑的规划）；肾素的血统（十九世纪末加压的物质，与两派的血压与钠的调节的学说，以及血管紧张素激素的级联）；以及前列腺素与内皮的因子（内皮舒张的因子的发现与它被移除时的高血压和肾的损伤这一链接，和环的抑制剂与转换酶的阻断剂如何把这一分子的知识变成一个床边的禁忌）。这一章的数字所来自的传统就是把力与标记物和反馈环变成可测量的与可干预的东西。**
:::

::: warning 造成真实伤害的两个陷阱 {#warn-egfr}
第一：**在一个非稳定状态单一的肌酐上朝任一个方向行动**——在慢性的肾的疾病中对一个小的升高的反应不足（这条双曲线的悬崖——[[#def-measure]]的组件），以及在肌肉的质量高或流量低的状态中对一个升高的肌酐反应过度；在用肾的剂量紧急之前用趋势或胱抑素C或测量的清除率来确认。第二：**错过梗阻的与血管的肾后的原因**（前列腺与腹膜后的纤维化以及肾动脉的狭窄，伪装成医学的肾的疾病——[[renal/urinary-tract]]与[[renal/acute-kidney-injury]]的先做超声的反射）——这一章的数字必须总是与管道这一现实相对账。
:::

::: summary
- 肾以每分钟约125毫升滤过血浆，通过一个按大小与电荷选择的双毛细血管的屏障（内皮与基底膜及足细胞），它的压力的经济学来自两个小动脉；每日180升的超滤液中约99%被重新吸收。
- 自身的调节（肌原的加上肾小管肾小球的反馈）在约80到180毫米汞柱之间稳定流量与滤过；前列腺素与血管紧张素II以及交感的张力叠加其上——也就是非甾体与转换酶抑制剂及利尿剂的损伤的组合分子的位置。
- 滤过率被清除率测量，并被肌酐的方程估计；每一个估计都带有稳定的状态与肌肉的质量及测定的假设——这条双曲线意味着小的肌酐的改变就是大的滤过的改变。
- 试纸与显微镜和白蛋白对肌酐的比率把滤过的屏障与肾小管的损伤变成早期而廉价的信号；蛋白尿同时是标记物、中介物与治疗的目标，而血尿的形态把患者路由到肾内科或泌尿外科。
:::

## 练习

::: exercise 排列压力 {level=1}
为什么肾的毛细血管的静水的压力（约48毫米汞柱）比肠的（约17）高得多，是哪两个解剖的特征负责？
::: solution
**被插入的第二个小动脉：出球小动脉下游的阻力会把压力顶回肾小球（而短而直接的肾动脉会把主动脉的搏动传递进来），而在出球之上的第二次降落让管周的丛保持低压（[[#def-flow]]、[[#ex-starling]]）。同一个这一布置让滤过的分数变高，而管周的胶体的渗透的压力变高——这两个床的重吸收的配对（[[physiology/homeostasis-body-fluids]]的毛细血管水肿的分类的对照）.**
:::
:::

::: exercise 滤过的分数算术 {level=1}
肾的血浆的流量每分钟600毫升，滤过率每分钟120毫升：给出滤过的分数，并解释为什么在出血降低血浆的流量而滤过率被相对保留时，出球的胶体会上升。
::: solution
**滤过的分数等于120除以600等于0.220%)。血管紧张素II的出球的收缩在流量下降时维持滤过率，所以更小的血浆的流量的更大的一部分被滤过——蛋白的浓度（胶体渗透的压力）沿着毛细血管朝着平衡陡峭地上升（[[#def-flow]]、[[#def-autoregulation]]）：同样的算术会浓缩近端小管溶质的递送（[[renal/tubular-function]]的肾小管的平衡的课），并驱动管周的重吸收（[[#ex-starling]]）。**
:::
:::

::: exercise 让它自身调节 {level=2}
一个高的盐的负荷会升高远端的钠与氯的递送。逐个细胞地追溯肾小管肾小球反馈的序列，并命名阻断这个传感器的药与它的后果。
::: solution
**致密斑的共同转运体的摄取（钠钾二氯）→ 激酶与一氧化氮合酶及腺苷的信号 → 入球小动脉的收缩（加上肾素的抑制）→ 单个肾单位的滤过率回落（[[#def-autoregulation]]、[[renal/tubular-function]]）。袢的利尿剂阻断这个转运体并取消这个反馈的信号（矛盾性入球的扩张与肾素的刺激，以及为什么它们滤过的效应是由容量的缺乏、而不是盐的传感器的过多所驱动）（[[renal/water-sodium]]）；同一个这个节点就是致密斑在钠葡萄糖共转运体的抑制剂对肾小管的反馈对糖尿病的超滤过的效应上作用的基础（[[endocrine/diabetes-complications ]]）。**
:::
:::

::: exercise 计算一个清除率 {level=2}
尿每日1.2升，尿的肌酐每升8毫摩尔，血的肌酐每升100微摩尔：计算肌酐的清除率，并说明它是高估还是低估真正的滤过率，给两个理由。
::: solution
**清除率等于尿的浓度乘流量除以血的浓度：尿的每升8毫摩尔即每升8000微摩尔对每升100微摩尔，得到80的浓缩的因子；流量每日1.2升即每分钟0.833毫升；80乘以0.833约为每分钟67毫升。** 它**会因为10%到20%的肾小管分泌的成分而高估真正的滤过率，而收集的错误（不完全）会朝任一方向加入噪声；以及[[#def-measure]]的测定的与非稳定的状态的告诫。**
:::
:::

::: exercise 选择这个估计 {level=2}
为每位患者挑选最好的功能的评估并为它辩护：(a) 一位82岁的肌萎缩侧索硬化的人，肌酐62；(b) 一位40岁的肾移植供者的候选；(c) 一位30岁在大剂量的皮质类固醇的人，肌酐88。
::: solution
**（a）胱抑素C（与肌肉无关）——肌萎缩侧索硬病肌肉的减少会让肌酐对真正的滤过的损失失明（[[nervous-system/neuromuscular]]、[[renal/chronic-kidney-disease]]的剂量的规则）；（b）测量的清除率血浆的清除率或测量的肌酐加收集，或移植的项目的方案——这个决定的不可逆性要求测量而不是估计（[[immunology/transplant-tumour-immunology]]与[[medical-ethics-law/consent-capacity]]）；（c）朝相反的方向告诫——糖皮质激素会在与滤过无关的情况下升高胱抑素C（而甲状腺的状态也会[[endocrine/thyroid]]）——用肌酐加被证实的趋势，或在数字驱动治疗时用一个被测量的清除率（[[renal/chronic-kidney-disease]]的证实的算法）.**
:::
:::

::: exercise 给红细胞路由 {level=2}
一位66岁的吸烟者带血块的肉眼血尿，对照一位12岁在感冒后有镜下的血尿而血压与功能正常：给出这两份工作检查与推理。
::: solution
**吸烟者：同形的红细胞带血块等于非肾小球，直到被证明别的——尿路的部分：上段的影像（计算机的尿路造影）加上膀胱镜（膀胱的癌的排除——[[renal/urinary-tract]]与[[pathology/cancer-diagnosis]]）；以及抗凝的审计（永远不要在没有检查的情况下把血尿归咎于稀释的药[[blood/thrombosis-anticoagulation ]]）。儿童：感染后的不痛的镜下或肉眼血尿带正常的检查=儿科肾炎的鉴别免疫球蛋白A为主的感染后的模式，对照良性的家庭性——父母的尿的检验与补体和链球菌的抗体的滴度及血清学的一组；以及阿尔波特的耳聋与眼病的家族史（[[genetics/mendelian-inheritance]]、[[nervous-system/sensory-systems]]）→ 监测血压与功能及白蛋白的比率，并在有相关的体征时转诊——成人的路径会跳过畸形的细胞与管型的确认（[[renal/chronic-kidney-disease]]的血尿的方法，与[[renal/urinary-tract]]的过度检查伤害的告诫）。**
:::

::: exercise 出球的困境 {level=2}
双侧肾动脉狭窄的患者：解释为什么转换酶的抑制剂会造成急性的肾的损伤，以及为什么尽管如此，转换酶的抑制剂在糖尿病的肾病中仍保护肾。
::: solution
**上游的狭窄意味着肾小球的压力依赖血管紧张素II的出球的张力（[[#def-autoregulation]]）；移除它会崩溃滤过的梯度（[[renal/acute-kidney-injury]]的血管的原因的行，以及肌酐的升高超过30%就停药并做影像的规则[[clinical-skills/medical-imaging]]的选项与再血管化辩论的试验，以及[[cardiovascular/hypertension]]的继发高血压的章）。在糖尿病的肾病中这一病理是相反的——入球的松弛与肾小球的内的高血压与超滤过（[[renal/chronic-kidney-disease]]的肾小管的反馈与超滤过的悖论：近端的重吸收增多会降低致密斑的盐，并通过肾小管的反馈与肾素的环矛盾性地收缩出球）——所以降低出球的张力与系统的压力会减少蛋白尿并减慢进展（系统阻断试验的血统，与更新的钠葡萄糖的抑制剂和非奈酮及胰高血糖素样肽肾结局的层次[[endocrine/diabetes-complications]]）——同一个药，相反的裁决，由小动脉的哪一端需要帮助来决定。**
:::
:::

::: exercise 设计功能的检查的门诊 {level=3}
设计一个能早期捕获肾的疾病并正确地为它分期的服务：人群、检查、证实的算法、药物安全的接口，以及审计。
::: solution
**人群与触发：糖尿病与高血压与心血管的疾病及家族史与非甾体和锂及对比剂的暴露的登记（病例的发现：每年的白蛋白的比率加肌酐[[endocrine/diabetes-complications]]与[[cardiovascular/hypertension]]）；急的入院的肌酐与尿的反射，带急的肾的损伤之后的随访的门诊（急到慢转换的监测，与出院时的生病时的规则的问题[[renal/acute-kidney-injury]]与[[geriatrics-palliative/polypharmacy ]]）。证实：趋势对快照的政策（为分期在三个月以上重复；急的值标记[[renal/chronic-kidney-disease]]）；为肌肉的质量的极端（[[#ex-creatinine-trap]]的队列）的胱抑素C或测量的清除率的升级；以及蛋白尿的定性的阶梯（晨的第一份尿白蛋白的比率，与白蛋白对总的蛋白的轻链的问题，带年龄加系统的特征所要求骨髓瘤的筛查[[blood/lymphoma-myeloma ]]）。接口：与药房的肾功能与剂量的检查；生病时规则的教育；在危险人群中的对比剂之前与手术之前的记录；以及转诊的标准（分期的阈值与快速的下行的斜率及蛋白尿加血尿和系统的症状）。审计：分期与白蛋白的比率的分级与斜率的编码；急的肾的损伤之后的随访的比率；以及药物安全的事件。公平的读（[[public-health/determinants-inequalities]]）与过度检查的平衡（良性的血尿与体位的蛋白尿的不再行动的方案——[[public-health/screening]]）——整个的服务都建立在本章的这两句话上：压力制造滤液，而屏障决定什么通过，而肌酐只有在你们审问它时才会报告它们的产物。**
