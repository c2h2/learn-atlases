钠和水决定容量和张力。钾、钙、镁和磷决定的则是更直接的事情：神经能否兴奋，肌肉能否收缩，心脏能否保持稳定的节律。它们的血浆浓度很小，正常与危险之间的余地很窄。血钾4 mmol/L是正常的；7 mmol/L则可能在数分钟内使心脏停搏。

这些离子有一个共同的模式。每一种都主要储存在血浆以外的地方：钾在细胞内，钙和磷在骨骼中。因此血浆水平既取决于储存库与细胞外液之间的**分布**，也取决于**外部平衡**，即摄入与排出之差。肾脏决定长期平衡，但医院里见到的许多突然变化是由腔隙之间的转移引起的。

本课时最详细地讨论钾，因为钾紊乱常见且有即刻危险，然后讨论钙、镁和磷。本课时以[[renal/tubular-function]]中的集合管生理为基础。心电图改变背后的心脏电生理见[[cardiovascular/electrophysiology-ecg]]，钙和骨骼的内分泌调控见[[endocrine/bone-calcium]]。

## 钾

### 钾在哪里，如何移动

一名70 kg成人体内约有3500 mmol钾。其中约98%在细胞内，浓度约为140～150 mmol/L，主要在骨骼肌中。细胞外液只含约60 mmol，浓度为3.5～5.0 mmol/L。二者之比决定了每个可兴奋细胞的静息膜电位。

由于细胞外的钾如此之少，微小的转移也会对血浆水平产生很大影响。

::: definition 钾稳态 {#def-k}
**内部平衡**（细胞与ECF之间的分布）在数分钟内受到调控。使钾**进入细胞**的因素有**胰岛素**、**β₂肾上腺素能刺激**和**碱中毒**。使钾**移出细胞**的因素有胰岛素缺乏、β受体阻滞、由无机酸（有机酸较少）引起的**代谢性酸中毒**、高渗状态以及细胞破坏（横纹肌溶解、溶血、肿瘤溶解）。

**外部平衡**主要由肾脏决定，肾脏排出约90%的日摄入量（通常为70～100 mmol），其余由结肠排出。滤过的钾在到达远端肾单位之前几乎全部被重吸收。尿中的钾量由连接小管和集合管的**分泌**决定。
:::

::: theorem 钾分泌的决定因素 {#thm-k-secretion}
主细胞的钾分泌随以下因素增加：

1. **醛固酮**，它增加ENaC通道、ROMK通道和Na⁺/K⁺-ATP酶；
2. 到达远端肾单位的**钠输送量和流量**，它增加经ENaC的钠进入（使管腔负电位更大），并冲走已分泌的钾；
3. **血浆钾**本身，它刺激醛固酮并直接增加分泌。

反之，醛固酮低、远端钠输送少和流量低都会减少钾分泌。
:::

::: proof
主细胞通过基底侧膜Na⁺/K⁺-ATP酶从血液中摄取钾，并通过ROMK和BK通道把钾释放到管腔中。钾移出的驱动力是跨顶膜的电化学梯度。经ENaC进入的钠使顶膜去极化，使管腔呈负电位，有利于带正电的钾移出。输送到这些细胞的钠越多，ENaC驱动的钠进入就越多，管腔负电位就越大。流速越快，管腔钾浓度越低，浓度梯度得以维持。醛固酮增加每一步所涉及的通道和泵的数量。这解释了为什么袢利尿药和噻嗪类利尿药（远端钠和流量增加，加上容量丢失引起的醛固酮升高）引起低钾血症，而ACE抑制剂、螺内酯、阿米洛利和甲氧苄啶（阻断ENaC）引起高钾血症。
:::

### 高钾血症

::: definition 高钾血症 {#def-hyperk}
**高钾血症**是血浆钾高于5.5 mmol/L。英国肾脏协会指南将其分为**轻度**（5.5～5.9 mmol/L）、**中度**（6.0～6.4 mmol/L）和**重度**（6.5 mmol/L或以上）。病因分为三类：

- **排出减少**：急性肾损伤、晚期慢性肾脏病、药物（ACE抑制剂、血管紧张素受体阻滞剂、盐皮质激素受体拮抗剂、阿米洛利、甲氧苄啶、非甾体抗炎药、钙调磷酸酶抑制剂）、醛固酮减少症（艾迪生病、4型肾小管酸中毒）；
- **移出细胞**：胰岛素缺乏（糖尿病酮症酸中毒）、酸中毒、横纹肌溶解、肿瘤溶解、溶血、β受体阻滞剂、地高辛中毒、琥珀胆碱；
- **摄入过多**，通常只在排出同时受损时才会发生。
:::

治疗之前，值得先问一问结果是否真实。**假性高钾血症**是样本中钾高而患者体内并不高。见于抽血困难导致红细胞溶血、样本放置数小时或在分离前被冷藏、止血带绑扎过久并反复握拳、血小板或白细胞极高，或样本被血常规管中的EDTA钾污染（同时会出现不可能的低钙）。若患者情况良好、心电图正常且没有高钾的原因，应及时复查样本。若有任何疑问，则在等待结果的同时进行治疗。

高钾血症降低静息膜电位梯度。起初它使心肌细胞兴奋性增高、复极加快；随后它使钠通道失活、传导减慢。**心电图改变**大致依次出现：高尖T波；P波低平、消失，PR间期延长；QRS波群增宽；正弦波图形；最终为心室颤动或心搏停止。心动过缓和传导阻滞常见。心电图是不灵敏的指标：有些重度高钾血症患者的心电图几乎正常，随后却发生心搏骤停。

高钾血症的处理按英国肾脏协会指南分为五步。以下剂量是该指南中的典型成人方案，仅供理解；治疗应遵循当地方案。

1. **保护心脏。**若有心电图改变，**静脉给予钙剂**（例如10%葡萄糖酸钙30 mL，10分钟内注射，若心电图无改善可重复）可在数分钟内稳定心肌细胞膜，作用持续约30～60分钟。它不降低血钾。
2. **使钾进入细胞。****胰岛素加葡萄糖**（例如10单位短效胰岛素加25 g葡萄糖）在15～30分钟内使血钾降低约0.6～1.0 mmol/L，作用持续数小时。之后必须监测血糖数小时，因为低血糖常见，尤其是在肾脏病患者中。重度病例加用**雾化沙丁胺醇**可产生额外效果。
3. **把钾排出体外。**钾结合剂（环硅酸锆钠、帕替罗默）增加经肠道的丢失；在急性肾损伤中恢复尿量，必要时**透析**，可彻底清除钾。
4. **监测**血钾和血糖。
5. **预防**复发：停用或减少致病药物，治疗病因，并给予饮食建议。

::: example 高尖T波 {#ex-hyperk}
一名79岁男性患2型糖尿病和慢性肾脏病（基线eGFR 32），服用雷米普利、螺内酯，最近因胸部感染开始服用复方磺胺甲噁唑（co-trimoxazole）。他感到乏力。血钾7.1 mmol/L，肌酐280 µmol/L（基线170），静脉血pH 7.28。心电图示高尖T波，QRS时限130 ms。解释高钾血症的原因并概述紧急处理。
::: solution
**血钾为什么高。**四个因素叠加。他的肾功能急剧恶化（慢性肾脏病基础上的急性肾损伤），排出减少。雷米普利降低醛固酮，螺内酯阻断其受体，复方磺胺甲噁唑中的甲氧苄啶像阿米洛利一样阻断ENaC：三者都减少集合管分泌。酸中毒使钾移出细胞。

**紧急处理**（伴心电图改变的重度高钾血症，遵循当地方案）：持续心电监护；静脉注射葡萄糖酸钙稳定心肌；胰岛素加葡萄糖使钾进入细胞，并监测血糖数小时；雾化沙丁胺醇作为辅助；停用雷米普利、螺内酯和复方磺胺甲噁唑（改用其他抗生素）；评估容量状态并恢复灌注；开始使用钾结合剂；并尽早请肾内科会诊，因为急性肾损伤中的难治性高钾血症是透析指征（[[renal/acute-kidney-injury]]）。一到两小时内复查血钾，之后定期复查，因为使钾转移的治疗作用会消退。
:::
:::

### 低钾血症

::: definition 低钾血症 {#def-hypok}
**低钾血症**是血浆钾低于3.5 mmol/L；低于2.5 mmol/L为重度。病因：

- **进入细胞**：胰岛素（包括治疗糖尿病酮症酸中毒时）、β₂受体激动剂、碱中毒、再喂养、甲状腺毒性和家族性周期性麻痹；
- **胃肠道丢失**：腹泻、滥用泻药、高输出量造口、绒毛状腺瘤；呕吐引起低钾血症主要是通过肾脏，因为碳酸氢根输送和醛固酮增加使钾分泌增加；
- **肾脏丢失**：袢利尿药和噻嗪类利尿药、渗透性利尿、盐皮质激素过多（原发性醛固酮增多症、库欣综合征、甘草）、Bartter和Gitelman综合征、1型和2型肾小管酸中毒、低镁血症；
- **摄入不足**，可起作用，但很少单独引起低钾血症。
:::

低钾血症使肌肉和神经超极化。它引起无力、肌肉痉挛、便秘和肠梗阻，严重时引起瘫痪和横纹肌溶解。心电图示T波低平、ST段压低和明显的**U波**，有发生房性和室性心律失常的风险，尤其是服用地高辛或有心脏病的人。慢性低钾血症损害尿液浓缩（肾性尿崩症）。

病因不明显时，随机尿钾可区分肾性与肾外丢失：尿钾低于约20 mmol/L（或钾/肌酐比值低）提示肾脏在恰当地保钾。血压和酸碱状态可以进一步缩小肾性病因的范围。低钾血症伴高血压提示盐皮质激素过多；伴血压正常和碱中毒提示利尿药、呕吐或Bartter/Gitelman综合征；伴酸中毒则提示腹泻或肾小管酸中毒。

尽可能口服补钾。静脉补钾用于重度低钾血症、有症状、有心电图改变或不能使用胃肠道时。由于高浓度静脉钾可引起致命性心律失常，其使用受严格的当地规定约束：使用预混袋装制剂，限制外周静脉输注速度（常为每小时约10 mmol），较快速度时需心电监护。若镁低，必须同时补**镁**；否则钾会持续丢失。

::: example 无法维持纠正的低钾 {#ex-hypok-workup}
一名46岁女性虽然服用三种降压药，血压仍为168/104 mmHg。她的血钾3.1 mmol/L，碳酸氢根31 mmol/L，血钠143 mmol/L。她没有服用利尿药。尿钾45 mmol/L。最可能的诊断是什么？如何检查？
::: solution
难治性高血压伴低钾血症、代谢性碱中毒、血钠正常偏高以及不适当的尿钾丢失，提示**盐皮质激素过多**，最常见的病因是**原发性醛固酮增多症**（Conn综合征）。过多的醛固酮增加经ENaC的钠重吸收（扩张容量、升高血压，从而抑制肾素），并增加钾和氢的分泌。

筛查试验是**醛固酮/肾素比值**，最好先纠正血钾并回顾干扰药物。比值高者随后进行确诊试验、肾上腺影像检查，通常还需肾上腺静脉取血，以区分单侧腺瘤（可手术治愈）和双侧增生（用盐皮质激素受体拮抗剂治疗）（[[endocrine/adrenal]]）。
:::
:::

::: example 大餐后突然无力 {#ex-thyrotoxic-pp}
一名28岁东亚裔男性在吃了一顿高碳水化合物大餐并在健身房度过一个晚上后醒来，双腿不能活动。他最近体重下降，并有震颤。血钾1.9 mmol/L。TSH测不出，游离T4升高。请解释，并指出治疗的风险。
::: solution
这是**甲状腺毒性周期性麻痹**。甲状腺激素增加肌肉中Na⁺/K⁺-ATP酶的活性，碳水化合物负荷（胰岛素）或运动后的肾上腺素使钾突然进入细胞。全身钾总量正常；问题在于分布。该病在东亚裔男性中更常见得多，他们的一种肌肉钾通道（Kir2.6）的遗传变异增加了易感性。

风险是**反跳性高钾血症**：转移一旦逆转，钾就从细胞中返回。因此补钾要谨慎，小量给予并频繁监测。非选择性β受体阻滞剂如普萘洛尔（propranolol）可逆转肾上腺素能驱动，有所帮助。彻底治疗甲状腺毒症可防止再次发作（[[endocrine/thyroid]]）。
:::
:::

## 钙

::: definition 钙平衡 {#def-ca}
正常血浆总钙约为2.2～2.6 mmol/L。约45%为**离子钙**（有生理活性的部分），约40%与白蛋白结合，其余与枸橼酸根和磷酸根等阴离子形成复合物。白蛋白低时总钙下降，而离子钙可能正常，所以实验室报告**校正（白蛋白校正）钙**。一个广泛使用的公式为

$$
\text{校正钙 (mmol/L)} = \text{总钙} + 0.02 \times (40 - \text{白蛋白 (g/L)})
$$ {#eq-adjca}

不过许多实验室使用本地推导的版本。用血气分析仪直接测定的离子钙在危重病中更可靠。碱中毒增加钙与白蛋白的结合，降低离子钙，这就是过度通气引起刺痛和手足痉挛的原因。

钙受以下因素调控：
- **甲状旁腺激素**（PTH），离子钙下降时释放；它使骨骼释放钙，增加远端小管钙重吸收，增加磷排泄，并激活肾脏1α-羟化酶；
- **骨化三醇**（1,25-二羟维生素D），在近端小管生成，增加肠道对钙和磷的吸收；
- **FGF23**，磷高时由骨骼释放；它增加磷排泄并抑制骨化三醇。
:::

### 高钙血症

高钙血症（校正钙高于约2.6 mmol/L）在门诊通常由**原发性甲状旁腺功能亢进症**引起，在住院患者中通常由**恶性肿瘤**引起；二者合计约占90%。用一项检查即可区分：甲状旁腺功能亢进症时PTH升高或不适当地正常，而恶性肿瘤和大多数其他病因时PTH受抑制。恶性肿瘤通过PTH相关肽（鳞状细胞癌、肾癌和乳腺癌）、骨破坏（骨髓瘤、骨转移）或过多的骨化三醇（淋巴瘤）升高血钙。其他病因包括肉芽肿性疾病（结节病、结核病）、维生素D过量、噻嗪类、锂剂、制动、甲状腺毒症和家族性低尿钙性高钙血症。

症状包括口渴和多尿（高钙引起肾性尿崩症）、便秘、腹痛、恶心、意识模糊、乏力、抑郁、肾结石和骨痛。心电图可示QT间期缩短。重度高钙血症引起脱水，脱水减少钙排泄，使血钙进一步升高：形成恶性循环。

重度或有症状的高钙血症的处理从**静脉补液**（0.9%盐水）开始，以恢复容量并促进钙排泄。随后静脉给予**双膦酸盐**减少骨吸收，其效果在两到四天内显现。特定情况下的其他选择包括降钙素（起效快但作用短暂）、地舒单抗、糖皮质激素（用于淋巴瘤和结节病等骨化三醇驱动的病因）和透析。同时治疗病因。

### 低钙血症

低钙血症引起**神经肌肉兴奋性增高**：口周和指尖刺痛、肌肉痉挛、手足痉挛、喉痉挛和癫痫发作。教学中有两个床旁体征：**Trousseau征**（血压袖带充气至收缩压以上最多三分钟时出现腕部痉挛）和**Chvostek征**（叩击面神经时面部肌肉抽动）。心电图示QT间期延长。

病因包括**甲状旁腺功能减退症**（最常见于甲状腺或甲状旁腺手术后）、**维生素D缺乏**、**慢性肾脏病**（骨化三醇低、磷高）、**低镁血症**（损害PTH的分泌和作用）、急性胰腺炎、横纹肌溶解、大量输血中的枸橼酸盐，以及甲状旁腺切除术后的“骨饥饿”。有症状的低钙血症在心电监护下静脉给予葡萄糖酸钙；慢性低钙血症口服钙剂和维生素D（甲状旁腺功能减退症和肾脏病时使用活性维生素D）。

## 镁与磷

::: definition 镁与磷 {#def-mg}
**镁**（正常血浆约0.7～1.0 mmol/L）主要存在于骨骼和细胞中，主要在升支粗段重吸收。**低镁血症**由腹泻、酒精使用、营养不良、袢利尿药和噻嗪类利尿药、质子泵抑制剂以及某些药物（如顺铂）引起。它引起无力、震颤、心律失常（包括尖端扭转型室性心动过速），并使**低钾血症**和**低钙血症**难以纠正。高镁血症少见，主要为医源性，见于肾衰竭或子痫前期镁剂治疗期间。

**磷**（正常血浆约0.8～1.5 mmol/L）主要存在于骨骼中，是ATP和2,3-二磷酸甘油酸所必需的。**低磷血症**由进入细胞（再喂养、胰岛素、呼吸性碱中毒）、肾脏丢失（甲状旁腺功能亢进症、范科尼综合征、FGF23过多）以及摄入或吸收不足引起。重度低磷血症（低于约0.3 mmol/L）引起肌无力、呼吸衰竭、心力衰竭、溶血和意识模糊。**高磷血症**常见于肾衰竭和细胞破坏（肿瘤溶解、横纹肌溶解）；它通过沉淀降低血钙，在慢性肾脏病中驱动血管钙化。
:::

::: example 再喂养引起的崩溃 {#ex-refeed}
一名23岁女性患神经性厌食，BMI 13 kg/m²，入院后开始鼻胃管喂养。第3天她出现意识模糊、气促和无力。血磷0.25 mmol/L，血钾2.9 mmol/L，血镁0.5 mmol/L。请解释。
::: solution
这是**再喂养综合征**。饥饿期间，即使血浆水平正常，细胞内的磷、钾和镁也已耗竭。给予碳水化合物刺激胰岛素分泌，胰岛素驱动葡萄糖、磷、钾和镁进入细胞，并启动消耗磷的合成代谢过程（ATP合成）。血浆水平急剧下降。低磷引起呼吸肌无力、心力衰竭和意识模糊；低钾和低镁引起心律失常。硫胺素缺乏也可能被暴露出来。

**预防**（NICE营养指南）是识别高危者（BMI极低、超过10天几乎未进食、体重快速下降、喂养前电解质低），谨慎开始喂养并缓慢增加，喂养前和喂养期间给予硫胺素和维生素，每天检查并补充磷、钾和镁。她现在的治疗是补充电解质、减慢喂养速度，并在合适的病房中监测（[[gastrointestinal/clinical-nutrition]]和[[psychiatry/eating-personality-disorders]]）。
:::
:::

::: warning 结合情境看待数值 {#warn-electrolytes}
电解质方面有两种常见错误，方向相反。第一种是不核实结果是否真实就根据实验室数值进行治疗：溶血和EDTA污染的样本会给出假性高钾血症和低钙血症，而白蛋白低时总钙低可能对应正常的离子钙。第二种是因为患者“看起来很好”或心电图正常而忽视危险的数值：重度高钾血症可能在没有心电图预警改变的情况下引起心搏骤停。结果出乎意料时，应及时复查；若结果可能真实且危险，应在等待复查结果的同时进行治疗。
:::

::: quiz
一名67岁男性患糖尿病酮症酸中毒，入院时血浆钾5.8 mmol/L。下列哪项正确？
- [ ] 他的全身钾总量高，因此在血钾低于4.0之前应避免补钾
- [x] 他的全身钾总量很可能偏低；胰岛素会使钾进入细胞，因此血钾降至约5.5 mmol/L以下时通常需要在补液中加钾
- [ ] 应在血钾正常之前暂停胰岛素
- [ ] 这一数值反映溶血，应予忽略
::: solution
在糖尿病酮症酸中毒中，胰岛素缺乏和高渗状态使钾移出细胞，同时渗透性利尿使钾从尿中丢失。血浆水平可能偏高，而全身钾总量偏低。胰岛素治疗使钾回到细胞内，血浆钾可迅速下降，引起危险的低钾血症。因此英国的方案在血浆钾低于5.5 mmol/L时在补液中加钾，并频繁监测（[[endocrine/endocrine-emergencies]]）。除非就诊时血钾很低（此时应先补钾），否则不暂停胰岛素。
:::
:::

::: history
1882年和1883年，伦敦医生兼药理学家林格（Sydney Ringer）在研究离体蛙心。他发现，用伦敦自来水配制的盐水灌注的心脏能持续跳动数小时，而用蒸馏水配制的盐水灌注的心脏很快停跳。他把差别追溯到自来水中的钙，并证明心脏需要比例适当的钙和钾才能收缩。他设计的平衡盐溶液是“林格液”以及今天医院所用哈特曼液的前身。1925年，多伦多的科利普（James Collip）制备了有活性的甲状旁腺提取物，证明它能升高被切除甲状旁腺的动物的血钙并缓解手足搐搦。
:::

## 后续内容

集合管在钾和酸分泌中的作用与[[renal/acid-base-disorders]]直接相关，低钾血症和碱中毒在那里相伴出现。高钾血症作为透析指征见[[renal/acute-kidney-injury]]；慢性肾脏病–矿物质和骨异常，即肾衰竭的钙磷紊乱，见[[renal/chronic-kidney-disease]]。甲状旁腺疾病和维生素D见[[endocrine/bone-calcium]]。

::: summary
- 98%的体内钾在细胞内；1%的钾移出细胞可使血浆钾升高约2.5 mmol/L。胰岛素、β₂受体激动剂和碱中毒使钾进入细胞。
- 尿钾由集合管的分泌决定，受醛固酮、远端钠输送和流量驱动。
- 高钾血症（轻度5.5～5.9、中度6.0～6.4、重度≥6.5 mmol/L）：排除假性高钾血症，评估心电图，然后保护心脏（钙剂）、转移（胰岛素–葡萄糖、沙丁胺醇）、排出（结合剂、透析）、监测和预防。
- 低钾血症：转移、胃肠道丢失或肾脏丢失；尿钾和血压可区分病因；同时补镁。
- 校正钙 ≈ 总钙 + 0.02 ×（40 − 白蛋白）。高钙血症主要是原发性甲状旁腺功能亢进症（PTH未受抑制）或恶性肿瘤（PTH受抑制）；用补液和双膦酸盐治疗。
- 低钙血症引起手足搐搦、癫痫发作和QT延长；低镁血症引起难治性低钾血症和低钙血症。
- 再喂养综合征是磷、钾和镁危险地进入细胞；应预见并预防。
:::

## 习题

::: exercise 阅读心电图 {level=1}
按通常出现的顺序列出血浆钾升高时的心电图改变，以及低钾血症的心电图改变。
::: solution
**血钾升高**：高尖T波；PR间期延长、P波低平或消失；QRS增宽；正弦波图形；心室颤动或心搏停止。心动过缓和传导阻滞可出现于任何阶段。**低钾血症**：T波低平或倒置、ST段压低、明显的U波、QT（实为QU）间期表观延长，以及房性和室性早搏及心律失常。
:::
:::

::: exercise 校正钙 {level=1 check="2.05+0.02*(40-25)"}
一名肝硬化女性总钙2.05 mmol/L，白蛋白25 g/L。用本课时的公式计算她的校正钙（mmol/L）。
::: solution
校正钙$= 2.05 + 0.02 \times (40 - 25) = 2.05 + 0.30 = 2.35$ mmol/L，在正常范围内。她的总钙低反映的是白蛋白低。若准确数值很重要（例如她有症状），应直接测定离子钙。
:::
:::

::: exercise 分级与分类 {level=1}
用英国肾脏协会的分级对下列血钾进行分级，并给出一个可能的病因：(a) 一名因心力衰竭开始服用螺内酯的男性，5.7 mmol/L；(b) 一名脓毒症后急性肾损伤的女性，6.3 mmol/L；(c) 一名挤压伤后的年轻男性，7.0 mmol/L；(d) 一名大量腹泻的女性，2.4 mmol/L。
::: solution
(a) **轻度**高钾血症（5.5～5.9）：醛固酮受体阻断使集合管分泌减少，常伴一定程度的肾功能损害。

(b) **中度**高钾血症（6.0～6.4）：急性肾损伤时排出减少，加上酸中毒使钾移出细胞。

(c) **重度**高钾血症（6.5或以上）：受损肌肉释放细胞内钾（横纹肌溶解），常伴肌红蛋白引起的急性肾损伤。

(d) **重度低钾血症**（低于2.5）：富含钾的液体从胃肠道丢失，加上容量丢失引起的继发性醛固酮增多使肾脏丢失增加。
:::
:::

::: exercise 小转移，大升幅 {level=2 check="0.01*3500/14"}
一个人细胞内有3500 mmol钾，细胞外液容积为14 L。若1%的细胞内钾移入ECF（例如横纹肌溶解时），忽略排泄，血浆钾升高多少（mmol/L）？
::: solution
3500 mmol的1%是35 mmol。分布在14 L中，使血钾升高$35/14 = 2.5$ mmol/L，足以把正常的4.5变成危险的7.0。因此挤压伤、横纹肌溶解和肿瘤溶解可在数小时内引起重度高钾血症，尤其是在急性肾损伤妨碍排泄时。
:::
:::

::: exercise 追踪分泌 {level=2}
解释下列各项如何改变集合管的钾分泌：(a) 呋塞米；(b) 螺内酯；(c) 甲氧苄啶；(d) 低钠饮食伴容量不足和极低的远端输送，如重度心力衰竭时。
::: solution
(a) 呋塞米增加到达集合管的钠输送和流量，并引起容量丢失而升高醛固酮：**分泌增加**，低钾血症。

(b) 螺内酯阻断醛固酮受体，减少ENaC和ROMK：**分泌减少**，有高钾血症风险。

(c) 甲氧苄啶像阿米洛利一样阻断ENaC，减小管腔负电位：**分泌减少**。大剂量或肾功能损害时更易发生高钾血症。

(d) 醛固酮高，本应增加分泌，但极低的钠输送和流量限制了分泌。此时血钾可能升高，尤其是加用ACE抑制剂或盐皮质激素受体拮抗剂时。
:::
:::

::: exercise 病房里的高钙血症 {level=2}
一名71岁女性因意识模糊、便秘和多尿入院。校正钙3.4 mmol/L，磷1.2 mmol/L，PTH受抑制，肌酐140 µmol/L（基线80）。她有乳腺癌病史。概述可能的机制和处理原则。
::: solution
PTH受抑制不支持甲状旁腺功能亢进症。结合乳腺癌病史，可能的病因是通过骨转移或PTH相关肽引起的**恶性肿瘤**。高钙血症引起肾性尿崩症和呕吐，因此她脱水，而急性肾损伤又进一步减少钙排泄。

处理：静脉输注0.9%盐水恢复容量并促进钙排泄，仔细记录液体平衡；静脉给予双膦酸盐，剂量按产品说明书根据肾功能调整；停用噻嗪类、钙剂和维生素D补充剂；检查并治疗肿瘤，这决定了预后。每天复查血钙。
:::
:::

::: exercise 镁的关联 {level=2}
一名58岁男性长期服用奥美拉唑和噻嗪类，血钾2.9 mmol/L，口服补钾三天后仍低于3.2 mmol/L。他的校正钙为1.95 mmol/L。缺少了哪项检查？为什么重要？
::: solution
**血镁**。质子泵抑制剂减少肠道镁吸收，噻嗪类增加尿镁丢失。细胞内镁低时，对ROMK通道的正常阻断作用消失，钾漏入尿中，在补镁之前无法纠正。低镁血症还损害PTH的分泌和作用，引起低钙血症。补镁并重新评估奥美拉唑和噻嗪类的使用，可使血钾和血钙得到纠正。
:::
:::

::: exercise 门诊的血钾6.8 {level=3}
全科医生的实验室打电话报告一项结果：一名52岁男性当天上午门诊常规复查，血钾6.8 mmol/L。他服用雷米普利治疗高血压；去年eGFR为78。样本在寒冷的天气里过了六小时才送到实验室，他的血常规示血小板计数650 × 10⁹/L。讨论如何解读这一结果并采取行动。
::: solution
若干特征提示**假性高钾血症**：分离前延迟很久，低温保存（减慢红细胞Na⁺/K⁺-ATP酶，使钾漏出），以及血小板增多（血小板在凝血时释放钾）。他的肾功能正常，在肾脏正常时单用雷米普利很少引起重度高钾血症。

然而，6.8的血钾可能是真实且危险的，不见到患者就无法确定。安全的做法是当天联系他，询问症状，并安排紧急复查，样本迅速处理（例如肝素抗凝样本用血气分析仪检测，或在急诊科检测），同时做心电图。若不能及时评估，或他有症状或心电图改变，应送医院。若复查正常，则原结果是假象；血小板增多本身也需要解释（[[clinical-skills/laboratory-tests]]）。
:::
:::

::: exercise 设计再喂养方案 {level=3}
某病房每月收治数名有再喂养综合征风险的患者。描述一个安全诊疗路径的各个环节，从识别到监测，并解释每一步的生理学依据。
::: solution
1. **入院时识别风险**，使用公认的筛查工具（BMI极低、超过5～10天几乎未进食、体重快速下降、酒精滥用、喂养前钾、磷或镁低）。风险取决于此人近期的饥饿状况，而不仅仅取决于血浆水平。
2. **喂养前测定电解质**并纠正严重缺乏，同时认识到血浆水平低估了细胞内的耗竭程度。
3. 在最初几天之前和期间**给予硫胺素和复合维生素**，因为碳水化合物代谢消耗硫胺素，可诱发韦尼克脑病。
4. **缓慢开始喂养**（起始能量低，数天内逐渐增加），以限制驱动磷、钾和镁进入细胞的胰岛素激增。
5. 至少在最初几天每天**监测**磷、钾和镁，以及液体平衡、心率和水肿（胰岛素也引起钠水潴留）。
6. 按当地方案及时**补充**电解质，若水平急剧下降则减慢喂养。
7. **参与人员**包括营养师，对进食障碍者还包括专科团队，并有明确的升级标准。
:::
