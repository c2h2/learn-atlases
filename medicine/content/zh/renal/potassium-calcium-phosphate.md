钾、钙、镁和磷酸盐都沿着同一个这一肾单位被处理（[[renal/tubular-function]]），而它们的紊乱会共享一个共同临床的结构：一个膜的症状学（钾与钙会改变兴奋性）、一个内分泌的控制器（甲状旁腺与激素[[endocrine/bone-calcium]]）、一个转移的欺骗（酸碱度与胰岛素会移动钾；白蛋白会移动钙），以及心电的征象会把急症分类。本章为它们中的每一个建立原则，然后走急性的综合征。

本章涵盖钾的内稳态与高钾与低钾血症、钙与甲状旁腺的轴、以及镁和磷酸盐的紊乱。

## 钾

::: definition 钾的内稳态：分布，然后排出 {#def-k}
**钾几乎全在细胞内（约98%，梯度约140比4.5)：膜的电位依赖它，而这也就是为什么急的变化会比慢性的变化更危险。两个层级控制着血浆的浓度：（i）分布的控制——胰岛素与β肾上腺素的激动剂会通过钠钾的三磷酸腺苷的酶把钾推进细胞，而酸中毒（尤其是非有机的）会把钾移出，而低渗透会拖着它（糖的过高会假性升高它[[endocrine/diabetes-complications ]]）；药物会阻断钾向内的移动（β阻滞剂与地高辛的过量及钾通道的阻断）[[pharmacology/autonomic-drugs]]；(ii）排出这一最终的决定者：近端的回收，然后集合管的主细胞分泌（基底外侧的摄取，加上顶膜上皮钠通道的钠的重吸收提供负管腔的电位驱动通过钾的通道；被醛固酮与流量增强——这也就是为什么远的利尿剂的递送会排钾[[renal/tubular-function]]）。慢性的负荷被适应：在食物中钾会刺激醛固酮与通道的表达。激素的控制器：醛固酮（保钠与排钾：过多的状态会同时产生高血压与低钾[[endocrine/adrenal]]；而缺陷会造成高钠的丢失与高钾[[#def-hyperk ]]）；糖皮质激素（在高浓度时的矿皮质激素的作用[[renal/acute-kidney-injury ]]）；以及胰岛素与儿茶酚胺（餐后的缓冲[[physiology/hormones ]]）。诊断的线索就在尿：钾的排出低（低于20到30）意味着这个肾正在恰当地保存（胃肠的损失与低的摄入），而高的排出指向肾的原因或矿皮质激素的障碍；而一个血浆的梯度（钠加钾减去氯的差）会揭示隐藏胃肠的[[#ex-hypok-workup]]。**
:::

::: definition 高钾血症 {#def-hyperk}
**高钾血症（钾高于5.5，紧急在6.5或心电的改变）几乎总是一个排出受损的组合：肾的功能下降（急性与慢性的[[renal/acute-kidney-injury]]、[[renal/chronic-kidney-disease]]）加上一个药物（转换酶的阻断剂与血管紧张素受体的阻滞剂及保钾的利尿剂和非甾体、矿皮质激素的拮抗剂（螺内酯）与抗菌的甲氧苄啶以及肾素的抑制剂）加上一个钾的负荷（输注与库存的血、膳食的改变[[blood/transfusion]]）或一个转移的移出（酸中毒与胰岛素缺乏及β阻滞剂、组织的分解代谢和横纹肌的溶解[[renal/acute-kidney-injury]]、以及药物的瘫痪[[surgery/anaesthesia-pain]]）。伪高钾：被反复挤压的标本（拳头与止血带的时间长）与血小板和白细胞的过多——血浆对血清的差异：在开药之前总是要用一个新的、被恰当处理的标本确认一个中度孤立的高值（[[clinical-skills/laboratory-tests ]]）。效应就是膜的：静息的电位去极化，然后通道会失活——肌肉的无力与心电的进展：高峰的T波，然后P波平坦和PR延长，然后QRS变宽到正弦的波与室性的心律失常和停搏[[clinical-skills/physical-examination]]的心电的章节。治疗按三个提问分层：（1）这个心肌危险吗——静脉的钙（氯的或葡萄糖的酸盐，在分钟起效，稳定这个膜，不动钾）；(2钾会被移到细胞内吗——胰岛素与葡萄糖和β二激动剂的雾化以及碳酸氢盐（在酸中毒中最有用；效应的暂时）；以及（3）钾会被移除吗——袢的利尿剂带容量（一个 functioning 的肾）、结合剂（新的锆循环的结合剂与传统的树脂，带着它们的肠的风险[[gastrointestinal/bowel-disease]]）以及透析（最可靠：在严重的或难治的病例中，带着紧急的指征[[renal/acute-kidney-injury]]）。长期的：钾的膳食的顾问与停止/减少药物、结合剂、以及在透析的患者中的频率与处方；以及在复发中醛固酮的轴的重新检查[[endocrine/adrenal]]。**
:::

::: example 高峰的T波 {#ex-hyperk}
一位68岁在雷米普利与螺内酯和布洛芬（它自己加了）的心衰患者在少尿的两天后被带来；钾7.2，肌酐升高，而心电显示出宽的QRS与平坦的P波。
::: solution
**带着心电的改变的重度的高钾：这是在分钟内的一个紧急[[emergency-critical-care/acute-assessment]]与[[emergency-critical-care/resuscitation]]。步骤：静脉的钙（一个立即的膜的稳定；重复如果波形仍在）、胰岛素与葡萄糖（带着随后的血糖的监测，因为低血糖常见）、以及高剂量的β二激动剂的雾化；碳酸氢盐（如果酸中毒）；同时准备好这个起搏/除颤的规则与钾的透析的咨询（[[renal/chronic-kidney-disease]]的紧急肾脏替代的指征[[renal/acute-kidney-injury ]]）。移除：利尿剂如果这个肾有反应，结合剂，而透析是决定性的。原因都在这里：三个减少钾排出的药物（转换酶的抑制剂和矿皮质激素的拮抗剂加上非甾体的肾的血液动力学的削减）加上一个急的肾的损伤：停用药，教育（生病时停止规则）并审查这个方案的必要（螺内酯在心衰中会拯救生命，所以要重新引入低剂量与结合剂和饮食的计划[[cardiovascular/heart-failure]]与[[pharmacology/adverse-reactions ]]）。后续的错误：重复的高值就是处方的决定，不是实验室的噪声[[geriatrics-palliative/polypharmacy]]。**
:::
:::

::: definition 低钾血症 {#def-hypok}
**低钾血症（钾低于3.5）来自三个机制：摄入少（饥饿液体茶与酒）、胃肠的损失（呕吐带的碱与继发的醛固酮，和腹泻的碳酸氢盐钾损失的腹泻）、以及肾的排泄（利尿剂、矿皮质激素的过多、高的流量的状态、肾小管的酸中毒和低镁[[#def-mg]]）。症状：肌无力与反射减少和肠的麻痹及横纹肌的溶解（在低的2以下）、心电的（平坦的T波和U波与QT的延长和心律失常，尤其在洋地黄[[cardiovascular/arrhythmias ]]）、以及肾的（肾源性的尿崩症与浓缩的缺陷[[renal/tubular-function ]]）。危险的伴随：低镁会让低钾难纠正，而低钾会造成碱中毒与生长的异常。方法：尿的钾低：胃肠摄入的；高：肾的，然后看血压（高血压提示矿皮质激素的过多——醛固酮与皮质醇的比率[[endocrine/adrenal]]；正常低提示利尿剂和巴特/吉特曼的综合征[[renal/tubular-function]]与酸碱的扰动），加上镁与氯。治疗：口服的钾 最安全 而缓慢（肠的病灶与胶囊的伤害）；静脉的钾带浓度和速度的上限和监测（一个外围的线路会限制毫摩尔每小时），在缺镁被纠正后；并纠正原因（β阻滞剂的反讽、钾的节约的利尿剂、镁的替代，以及在手术/疾病期间停用利尿剂[[geriatrics-palliative/polypharmacy ]]）。**
:::

::: example 无法被纠正的低钾 {#ex-hypok-workup}
一位有难治的低钾（钾2.7，尽管每日口服80毫摩尔）的46岁的人血压118/74，碳酸氢盐31，镁0.48（低），尿的钾62，而尿的钙低正常；她服用奥美拉唑与噻嗪，并否认其他用药。
::: solution
**线索就在镁：低镁会通过肾的外侧的钾的通道（通道在低镁时抑制被解除）造成持续尿的钾的损失，所以钾在镁被补充之前无法被纠正[[#def-hypok]]、[[#def-mg]]。低镁的成因在这里：质子泵的抑制剂（在吸收的部位的通道的损害）与噻嗪；以及一个低尿钙加低钾的碱中毒会同时提示吉特曼的综合征（远的小管转运体的损失[[renal/tubular-function]]）。步骤：静脉或口服的镁（带着深腱的反射和呼吸的监测在高剂量时），然后钾；停用或替换质子泵的抑制剂并考虑停噻嗪；以及如果被怀疑就遗传的测试（在决定长期治疗之前[[genetics/mendelian-inheritance]]）。规则：永远不要在低镁的未检查的情况下诊断难治的低钾；以及在低的镁的原因中筛查药物的清单[[pharmacology/adverse-reactions]]。**
:::

## 钙、镁与磷酸盐

::: definition 钙：调节、过多与缺乏 {#def-ca}
**钙的一半被结合（主要与白蛋白）并被氢的离子竞争：所以总钙要按白蛋白被校正，或在酸碱的扰动中用被测量的离子钙[[renal/acid-base-disorders]]与[[clinical-skills/laboratory-tests]]。控制器：甲状旁腺激素（在钙下降时被主细胞的感受器释放：它会把骨吸收与肾的钙的重吸收和磷酸盐的排泄及活性的维生素D的产生升高——这三条轴[[endocrine/bone-calcium ]]）、维生素D（把肠的吸收驱动）、以及降钙素（一个在人类中小的作用）。急性的症状（低钙）都是膜的：口周的与指端的感觉异常与抽筋及喉支气管的痉挛和癫痫发作，带QT的延长；体征（面神经的叩击与腕足的痉挛）、而慢性的（基底节的钙化与皮肤和牙的）。高的钙：症状的韵律（精神的石、腹痛与骨、带着少尿与心律失常）；最常见的原因：门诊的甲旁亢与恶性肿瘤（骨转移和相关的肽及维生素D的生成[[obstetrics-gynaecology/gynaecological-cancer]]与肿瘤的分类）；以及额外的维生素D与噻嗪和锂及肉样的疾病[[gastrointestinal/bowel-disease]]。治疗：高钙危象就是静脉的盐水（一个大的容量）与双膦酸盐（急性肿瘤的）或手术/拟钙剂（甲旁亢）和糖皮质激素在维生素D介导的疾病中；停用噻嗪与维生素D[[endocrine/bone-calcium]]。慢性的手术：无症状甲旁亢的标准与外科的合作——因为这是内分泌的外科的最被测量的结果之一。**
:::

::: definition 镁与磷酸盐 {#def-mg}
**镁几乎全在细胞内，被这个升支通过紧密细胞的通道与顶膜的通道（在远的节段被主动重吸收）调节——所以袢会浪费它，而低镁会（通过解除对钾的通道的抑制）造成难治的低钾[[#ex-hypok-workup]]与难治的低钙（甲状旁腺激素的分泌与作用的缺陷）。低的镁：胃肠（酗酒与腹泻和质子泵的抑制剂、移植的药物）与肾（袢和噻嗪与顺铂及遗传的综合征[[renal/tubular-function ]]）；效应：抽搐与心律失常（扭转的尖端）和支气管的痉挛与癫痫；治疗：镁（在肾功能不全时带着监测；静脉的硫酸镁是子痫的方案[[obstetrics-gynaecology/pregnancy-complications]]）。高的镁：只在肾的衰竭时（泻药的蓄积）；反射的消失与低血压和呼吸的抑制。磷酸盐：饮食的磷酸盐被肠（维生素D）吸收，被这个肾排出（甲状旁腺激素与成纤维细胞的生长因子23会把钠磷酸的共转运体下调[[renal/tubular-function]]、[[endocrine/bone-calcium]]），并与钙共享沉淀的规则。低的磷酸盐（危险在1.0以下）：再喂养的综合征与酒精与呼吸性碱中毒和甲旁亢及药物（磷的结合剂与碳酸酐酶的抑制剂）；症状：肌无力和呼吸的衰竭与心衰和意识改变及溶血[[#ex-refeed]]；治疗：口服或静脉的磷酸盐，带着对钙的乘积与肾的功能和镁的监测——因为磷的补充会拖着钙。高的磷酸盐：肾的衰竭（一个慢的矿皮质激素的目标[[renal/chronic-kidney-disease]]）与肿瘤的溶解[[blood/leukaemia]]；把磷酸盐降低就是结合剂与饮食及透析。**
:::

::: example 再喂养的崩溃 {#ex-refeed}
一位体重指数14的人在八天饥饿之后被开始着积极的营养；在第三天她变得无力、意识混乱和低磷，伴钠与钾和水分的下降，以及心电图的改变。
::: solution
**再喂养的综合征（[[#def-mg]]、[[gastrointestinal/clinical-nutrition]]）：重新暴露于糖会触发胰岛素，把磷酸盐与钾和水推入细胞，并消耗维生素B1的储备：所以急剧的磷的下降会造成呼吸的肌无力和心衰及癫痫，而硫胺的耗尽会造成威尼克式的图形[[nervous-system/dementia-neurodegeneration]]与[[gastrointestinal/clinical-nutrition]]。预防的规则：识别风险（体重指数低于16或下降超过15%，或长的禁食）；缓慢地开始热量并逐日地升级；在治疗前开始硫胺，然后维生素与矿物质；每天两次监测磷和钾和镁并在升级之前补充；以及液体的限制（胰岛素会储钠）。当前的治疗：静脉或口服的磷酸盐（带着钙的乘积和肾的功能的监护）、镁和钾的补充（一起；镁先）、硫胺（在葡萄糖前）、以及暂时放慢营养——而不是停止它们。这个审查：把再喂养的风险在入院时计算，因为这是一个被广泛认识而广泛错过的伤害[[clinical-skills/patient-safety]]。**
:::
:::

::: example 嗜睡并腿无力的亚洲男性 {#ex-thyrotoxic-pp}
一位28岁来自东亚的男性带着在数小时内从腿部发生的无力被带来；钾为2.1；反射降低；心率118；他最近被诊断出 弥漫性的毒性甲状腺肿但未治疗；尿的钾被矛盾地低。
::: solution
**甲状腺毒性周期性的瘫痪：甲状腺激素会把钠钾的三磷酸腺苷的酶的活性上调，而在一个易感的个体中碳水化合物或肾上腺素的激增会把钾驱入细胞——一个转移性低钾而不是缺失（尿的钾低；总量正常），在亚洲的男性中更常见（通道变异的易感[[genetics/mendelian-inheritance]]、[[endocrine/thyroid]]）。危险：心律失常与呼吸的肌无力和反常的心动过缓；以及医源性的反弹的高钾（钾的剂量会在分钟至小时中被逆转，因为这一转移会消退）：所以治疗就是谨慎的、被监测的钾补充（小的剂量带着系列）加上一个非选择性的β阻滞剂（普萘洛尔，把泵的驱动阻住）以及甲状腺的急性的治疗（抗甲状腺的药和碘的方案[[endocrine/thyroid]]与[[endocrine/endocrine-emergencies]]）；避免高碳水的餐食。鉴别：低钾麻痹的综合征（远端与小管的酸中毒与矿皮质激素的过多[[endocrine/adrenal]]）与横纹肌的溶解和脊髓的综合征（感觉平面与膀胱[[nervous-system/motor-systems]]）。这是内分泌的一个紧急：决定性的治疗就是控制甲状腺。**
:::

::: quiz
被镁的耗竭所造成的低钾，会因为什么在只用钾时无法被纠正？
- [ ] 镁与钾会竞争吸收
- [x] 低的细胞内的镁会解除钾的通道上正常镁塞子的抑制，所以这个肾会继续分泌钾
- [ ] 吸收口服的钾需要镁
- [ ] 低镁会抑制醛固酮
::: solution
**集合管的钾的通道会被镁的离子阻塞（一个内源的整流器）；当镁低时，通道会开放，钾会流失。镁会先，然后钾（[[#def-mg]]、[[#ex-hypok-workup]]）。**
:::

**钾与这个心脏从生理的盐水的灌注与钾的停搏实验成长起来（[[physiology/membrane-potentials]]），从战时的胰岛素休克死亡的记录与五十年代的洋地黄的钾的相互作用[[cardiovascular/valve-congenital-disease]]的时代；然后是巴特1962与吉特曼1966以及它们九十年代克隆的重聚[[renal/tubular-function]]；原发的醛固酮过多的重生（腺瘤的描述与后来的肾素的比率筛查的时代[[endocrine/adrenal ]]）；甲状腺毒性周期性瘫痪的基因的些时代（家族的研究与通道的变异[[endocrine/thyroid]]）；钙的调节的内分泌（甲状旁腺激素的测定与相关的肽的克隆，以及骨与肾的轴[[endocrine/bone-calcium]]）；再喂养综合征的描述；以及被新的钾的结合剂与矿皮质激素拮抗剂试验塑造的急的与慢的肾的疾病的钾的现代实践[[renal/chronic-kidney-disease]]与[[cardiovascular/heart-failure]]。本章就是细胞生物学与内分泌和心电的记录被折叠成床边的数字。**
:::

## 通向何处

集合管的钾的通道在[[renal/tubular-function]]；钠与容量的控制器在[[renal/water-sodium]]；矿物质与骨的轴在[[endocrine/bone-calcium]]与[[endocrine/adrenal]]；急的与慢的肾的疾病的钾的决定在[[renal/acute-kidney-injury]]与[[renal/chronic-kidney-disease]]；心电的模式在[[cardiovascular/arrhythmias]]；以及急的方法的顺序在[[emergency-critical-care/acute-assessment]]。

::: exercise 处理无症状的6.1 {level=2}
一个稳定四期慢肾疾病的患者（估计的滤过率26）在雷米普利与达格列净上，在常规的血里钾为6.1，无症状，心电正常。给出合理的顺序与你们不会做什么。
::: solution
**确认（溶血与时间的重新检查——[[#def-hyperk]]）并审查（膳食与盐的替代品及非甾体和甲氧苄啶的历史，便秘，以及并发的疾病[[renal/acute-kidney-injury]]）。保守地治疗：结合剂的开始与低钾的膳食的顾问，以及在有高血压与水肿时加袢[[renal/chronic-kidney-disease ]]；钠葡萄糖抑制剂的轻的降钾就是把达格列净留下的一个理由（心与肾的获益[[endocrine/diabetes-complications]]与[[cardiovascular/heart-failure]]）；而雷米普利剂量减半或换用而不是停用（阻断剂撤药伤害的文献[[cardiovascular/hypertension]]）。你们不会：在一个正常的心电与无症状的患者中给紧急的胰岛素或钙（急性治疗的风险会超过它们的小时）；不会把阻断剂永久地移除而没有重新审查（心脏与肾的证据会保护他）；也不会忽略后续（一个复发的计划：膳食的顾问与结合剂和被商定的阈值）。记录的交流：未来的处方者必须看到钾对药物的决定，因为这样的沉默会毁掉治疗。**
:::
:::

::: summary
- 高钾血症在三个时钟上被管理：钙来稳定，胰岛素和β的激动剂来隐藏，利尿剂与结合剂及透析来移除——带着心电的阶梯与共存因子的阈值来引导这个紧急。
- 低钾的方法是一棵血压与酸碱及尿的氯和钙的树；镁必须被补充否则钾永不被纠正；而转移性的低钾（甲状腺毒性周期性的瘫痪）被β的阻滞与克制来治疗，而不是积极的钾。
- 钙的紊乱是按白蛋白被校正、被甲状旁腺激素鉴别的紧急：高钙用盐水加上破骨的抑制，而低钙用先静脉后口服的钙并带着镁与维生素D的逻辑。
- 磷酸盐就是再喂养的离子：严重的低磷会瘫痪呼吸的泵并造成溶血；缓慢地再喂养，在第三天监测，并尽可能口服磷酸盐。
:::

## 练习

::: exercise 读心电 {level=1}
钾6.8：列出顺序心电的改变，与两个会让轨迹比预期晚的混淆。
::: solution
**窄的高峰T波，然后P波平坦与PR延长，然后QRS变宽，然后正弦的波与停搏[[cardiovascular/electrophysiology-ecg]]；混淆：共存低钙与低钠会加速损伤（更低的阈值：这个组件的共存因子的逻辑），而一个缓慢上升慢性的钾（慢的肾疾病中的适应）会在惊人的数字上显示出很少的改变（[[renal/chronic-kidney-disease]]）——而在上升时，一个正常的心电不会延迟治疗（[[emergency-critical-care/acute-assessment]]）。**
:::
:::

::: exercise 选择液体 {level=1}
给出钾7.0带QRS宽的、在一位服用地高辛的患者中的紧急的医嘱；注意这两个药的特异的陷阱。
::: solution
**静脉的钙（关于地高辛的辩论的时代：现在这一缓慢地并自信地给的读法，以及在中毒时特异片段的证据——陷阱一）、胰岛素与葡萄糖（陷阱二：洋地黄中毒自己高钾的报道与β阻滞剂转移的细节[[emergency-critical-care/poisoning]]）、以及低风险的沙丁胺醇的添加（在心动过速中的判断[[cardiovascular/arrhythmias]]）；并早期请透析的会诊（地高辛不可被透析而钾与肾的功能会是——[[renal/chronic-kidney-disease]]）；加上地高辛的水平与治疗后反弹低钾的监测与片段的剂量。**
:::
:::

::: exercise 追溯分泌 {level=2}
一步一步解释为什么袢会造成低钾（四个贡献者）以及为什么同一个药会造成低镁与尿钙过多。
::: solution
**容量收缩与醛固酮（[[renal/water-sodium]]）；远的流量与钠的递送（[[renal/tubular-function]]与[[#def-k]]）；到达上皮钠通道电原性的钠与氯的负荷（可被阿米洛利阻断的成分）；以及钾的损失而没有可比的钙与镁的重吸收。钙与镁：共同转运体的被丢失的管腔的正的电压会关掉细胞外的重吸收（[[renal/tubular-function]]的升支的课）——所以尿钙过多（一个治疗高钙的用途[[#def-ca]]）与尿镁过多（吉特曼的模仿——[[#ex-hypok-workup]]）。**
:::
:::

::: exercise 解读醛固酮的轴 {level=2}
血压168/102，钾2.9，代谢的碱中毒，肾素低，醛固酮高。给这个综合征，三个确认路径的选项，以及检查前的用药的规则。
::: solution
**原发的醛固酮过多（[[endocrine/adrenal]]与[[cardiovascular/hypertension]]的继发的高血压）：一个低的肾素与高的醛固酮带高血压、低钾和碱中毒（[[#def-hypok]]、[[renal/water-sodium]]）。确认：筛查的比率（被结合的测定，在重复上被确认），然后抑制的试验（口服的钠的负荷或氟氢考的松的抑制，带着标准的限度）；以及分型（肾上腺计算机的断层[[clinical-skills/medical-imaging]]，带着静脉的取样的选择性在某些的手术的患者中）。检查前的规则：停用会误导测定的药（矿皮质激素的拮抗剂螺内酯与依普利酮会升高肾素并压低比率：在试验前二到四周停用，用α阻滞剂与维拉帕米类及肼苯哒嗪类替代；纠正钾[[#def-hypok]]；并警告假阳性与负荷的试验期间的低钾）。为什么这重要：一个被确认的单侧的腺瘤可以通过手术治愈卒中的风险，而双侧的疾病就拮抗剂——所以测试必须在开始它们之前被安排[[geriatrics-palliative/polypharmacy]]。**
:::
:::

::: exercise 用校正的公式来校正 {level=2}
白蛋白22，被测量的钙1.98；而被测量的离子钙为1.32（升高）。解释并给出在一个骨髓瘤患者中管理的含义。
::: solution
**低的白蛋白会把结合的分数降低，所以总钙会被人为地低：粗略的校正每10克的白蛋白的下降把钙加上约0.02，把1.98升到一个接近正常的值[[#def-ca]]、[[clinical-skills/laboratory-tests]]。但被测量的离子钙才是被测量的真相，而这里它是高的：这个患者有高钙血症，不管这个表观的低值。在骨髓瘤中原因：骨的溶解与细胞因子的通路[[blood/lymphoma-myeloma]]；治疗：盐水，然后双膦酸盐或单抗，治疗这个肿瘤，避免噻嗪与维生素D[[endocrine/bone-calcium]]，带着心电的与钾和肾的监测[[renal/acute-kidney-injury]]。教训：不要用一个校正去代替一个被测量的离子钙；以及不要在没有检查离子钙的情况下把低白蛋白的人从钙的异常中免除。**
:::
:::

::: exercise 预防反弹 {level=2}
一个甲状腺毒性瘫痪的患者在四小时内接受80毫摩尔的钾；在第6小时钾为6.4并在上升，而瘫痪在消退。解释，并给出预防的规则。
::: solution
**这一转移被逆转了：被甲状腺激素与胰岛素上调的钾进入细胞内的泵，随着驱动者消退而卸载，于是细胞内的钾返回：一个被输注的大的总量的高钾血症会随后出现[[#ex-thyrotoxic-pp]]。这就是为什么钾的补充是谨慎的（半的经验性的缺失，带着每小时的系列）和非选择性的β阻滞剂是治疗（它们会阻断泵的驱动并预防反弹），而真正的治疗是控制甲状腺（抗甲状腺的药和碘[[endocrine/thyroid]]、[[endocrine/endocrine-emergencies ]]）。现在：停止钾；重复检查；如果心电的改变会治疗（糖与胰岛素、β激动剂——反讽地这里会合适）；以及透析的备用很少被需要[[renal/chronic-kidney-disease]]。预防的规则：在转移性低钾中为钾开药就像它们在反转，因为它们会。**
:::
:::

::: exercise 设计电解质安全的套 {level=3}
为钾钙镁的组设计一个病房的这套：处方的警卫、监测的标准、升级的规则，以及教育。
::: solution
**处方的警卫：钾的输注标准化的浓度与速度，带强制双重的独立检查与外周的限制（[[clinical-skills/patient-safety ]]）；在肾的功能受损时高剂量钾或补钾的自动警报；以及在钾高于5.5时的血管紧张素的阻断与矿皮质激素拮抗剂的审查提示[[geriatrics-palliative/polypharmacy]]。监测：一个按钾与钙和镁的水平的频率检查的矩阵（在急的纠正时每次小时）与心电的在紧急；低的白蛋白的校正与离子的钙在被怀疑时。升级：一个写好高钾的方案（钙与胰岛素/葡萄糖及结合剂与透析的阈值[[#def-hyperk]]、[[renal/chronic-kidney-disease ]]）、在钾大于6.5或钙的危象时一个必须呼叫的数值，以及一个夜间的责任。教育的目标：钾的膳食与盐的替代品与非甾体；以及在肾的衰竭中的结合剂与规则；以及把药和剂量（利尿剂与质子泵的抑制剂与结合剂）与疾病期间的用药规则联系起来。审计的指标：高钾事件的可预防性、过度的纠正、低镁的未测的低钾、复发，以及在死亡后的审查。**
:::
