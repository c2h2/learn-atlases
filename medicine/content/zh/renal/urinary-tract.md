尿液经肾盂离开肾脏，靠蠕动沿输尿管下行，储存在膀胱中，再经尿道排出。这一引流系统的大多数问题有三个来源：从外部上行的感染、阻碍尿流的结石和其他梗阻，以及从黏膜长出的肿瘤。每一种都威胁到其后方的肾脏，而且每一种都有特征性的表现方式：烧灼感和尿频、绞痛、排尿困难或血尿。

本课时讨论尿路感染、肾结石、梗阻和前列腺、多囊肾病以及主要的泌尿系统肿瘤。重点是检查和处理背后的机制和推理；手术操作见[[surgery/vascular-urological-surgery]]。本课时以[[anatomy/pelvis-perineum]]中的盆腔解剖和[[microbiology/bacterial-pathogenesis]]中的细菌致病机制为基础。所引用的英国指南来自NICE（关于下尿路感染的NG109、关于肾盂肾炎的NG111、关于16岁以下儿童感染的NG224、关于肾和输尿管结石的NG118，以及关于疑似癌症的NG12）。

## 尿路感染

### 感染如何到达尿路

几乎所有尿路感染（UTI）都是**上行性**的。来自肠道的细菌定植于会阴，进入尿道并在膀胱中繁殖。其中一些再沿输尿管上行到肾脏。经血流播散到肾脏少见，提示金黄色葡萄球菌菌血症。

机体有几道防线：规律地完全排空膀胱，把细菌冲出去；男性尿道较长；尿液的酸性和高尿素含量；结合细菌的尿调节素（Tamm–Horsfall蛋白）；起瓣膜作用的输尿管膀胱连接部；以及受感染膀胱黏膜细胞的脱落。

突破这些防线的因素可以预测谁会发生UTI：女性尿道短和性交；妊娠（孕酮引起输尿管扩张，以及子宫压迫）；排空不全（前列腺增大、神经源性膀胱、脱垂）；异物（导尿管、结石）；结构异常（儿童的膀胱输尿管反流）；糖尿病；以及绝经后雌激素减少改变阴道菌群。

细菌因素同样重要。**尿路致病性大肠埃希菌**带有附着于尿路上皮的菌毛（P菌毛和1型菌毛）。**变形杆菌**属产生**脲酶**，把尿素分解为氨，使尿液碱化，促进鸟粪石结石形成。

::: definition 尿路感染 {#def-uti}
**尿路感染**是尿路任何部位的感染。按部位和宿主分类：

- **下尿路感染（膀胱炎）**：膀胱感染，引起排尿困难、尿频、尿急、耻骨上疼痛、新出现的夜尿和尿液浑浊；
- **上尿路感染（急性肾盂肾炎）**：肾脏感染，引起发热、寒战、腰痛和叩痛，常伴恶心呕吐，可伴或不伴下尿路症状；
- **单纯性**UTI发生于尿路正常的非妊娠女性；**复杂性**UTI发生于男性、妊娠、儿童、有结构或功能异常、导尿管、结石、免疫抑制或肾脏病的人；
- **导尿管相关UTI**发生于留置导尿管的人；
- **尿源性脓毒症**是源于尿路的脓毒症；
- **无症状菌尿**是尿中有细菌而无感染症状。

大肠埃希菌引起大多数单纯性UTI。其他病原体包括腐生葡萄球菌（年轻、性活跃女性）、克雷伯菌、变形杆菌、肠球菌，在复杂性和导尿管相关感染中还有铜绿假单胞菌和耐药菌。
:::

### 诊断

对于有典型症状的65岁以下女性，诊断常凭临床作出。英国诊断指南（来自英国卫生安全局）使用三个关键症状：排尿困难、新出现的夜尿和尿液浑浊。具备两项或以上时UTI可能性大；只有一项时，尿试纸有帮助。**亚硝酸盐**阳性强烈支持细菌感染，因为大肠埃希菌等能还原硝酸盐的细菌把尿中来自饮食的硝酸盐转化为亚硝酸盐。**白细胞酯酶**提示有白细胞，它伴随感染出现，也见于其他炎症。

65岁以上者和留置导尿管者不用尿试纸诊断UTI，因为这些人群中无症状菌尿极为常见，尿试纸阳性无法区分感染与定植。男性、妊娠、儿童、脓毒症、治疗失败、反复感染、留置导尿管以及有耐药风险者应送尿**培养**。

尿试纸的价值取决于检查前感染的概率。

### 处理原则

以下概述截至2026年的NICE抗菌药物处方指南；药物、剂量和疗程按反映当地耐药模式的现行当地指南为每个人选择。

- **非妊娠女性下尿路感染**：症状轻者可考虑自我护理或备用处方，因为许多感染可自行缓解；否则给予**3天疗程**的呋喃妥因（eGFR 45或以上时）或甲氧苄啶（耐药风险低时）。
- **妊娠女性**：给予**7天疗程**治疗（呋喃妥因为一线，临近足月时避免），送尿培养，并治疗筛查发现的**无症状菌尿**，因为它增加肾盂肾炎和早产的风险。
- **男性**：**7天疗程**，并送培养。反复感染或有前列腺炎、肾盂肾炎特征的男性需要进一步评估。
- **急性肾盂肾炎**：使用能在肾组织达到良好浓度的抗生素，疗程更长（视药物而定，通常7～10天），如头孢氨苄或阿莫西林克拉维酸（以培养结果为指导），适当时使用喹诺酮类；若患者有脓毒症、呕吐或妊娠，则静脉给药并收住院。
- **儿童**：NICE NG224规定了何时检测和影像检查；疑似UTI的3个月以下婴儿应紧急转诊儿科。

呋喃妥因在尿中浓缩，对膀胱炎有效，但在肾脏或血液中达不到足够浓度，所以不用于肾盂肾炎或脓毒症。

::: example 感染性梗阻肾 {#ex-uro-sepsis}
一名54岁女性右腰痛24小时，发热39.4 °C伴寒战。心率118次/分，血压88/50 mmHg，乳酸4.1 mmol/L。尿试纸示亚硝酸盐和白细胞阳性。CT示右输尿管上段7 mm结石伴肾积水。诊断是什么？当务之急是什么？
::: solution
**感染性梗阻肾引起的感染性休克**（梗阻性肾盂肾炎）。结石后方的脓液在压力下无法引流，单靠抗生素难以渗透。

**优先事项**，按脓毒症路径：血培养和尿培养，一小时内静脉给予广谱抗生素，液体复苏并升级至重症监护。关键的泌尿外科措施是作为急诊对肾脏进行**紧急减压**，可经皮**肾造瘘**或逆行置入**输尿管支架**。结石本身待感染控制后再处理。未能对感染性梗阻肾减压是公认的可避免死亡原因。
:::
:::

::: example 养老院里有异味的尿 {#ex-asb}
养老院工作人员送检一名86岁痴呆女性的尿样，因为她的尿有强烈气味、颜色深。她没有发热，除基线外没有新的意识模糊，没有排尿困难，也没有腰痛。尿试纸白细胞和亚硝酸盐阳性，培养生长大肠埃希菌。她应该使用抗生素吗？
::: solution
不应该。无症状菌尿在老年女性中非常常见（几乎所有长期留置导尿管的人都有）。单纯尿液有异味或浑浊不是感染的征象，尿色深通常意味着她饮水太少。在老年人中治疗无症状菌尿并不改善结局，反而带来伤害：药物不良反应、艰难梭菌感染和抗微生物药物耐药性。

正确的做法是鼓励饮水，观察真正的感染征象（新出现的排尿困难、发热、腰痛、无其他原因的新发或加重的意识模糊），并且在这一年龄组没有特定症状时不送尿试纸检查。妊娠和计划进行的泌尿外科操作是治疗无症状菌尿的主要情况（[[infectious-diseases/stewardship-outbreaks]]）。
:::
:::

## 肾结石

::: definition 尿石症 {#def-stones}
**尿石症**是尿路中形成结石。当尿液中某种成石盐**过饱和**而结晶抑制物（如枸橼酸和镁）不足时，就会形成结石。主要类型有：

- **草酸钙**（绝大多数）和**磷酸钙**：与尿量少、高钙尿症、高草酸尿症（包括肠切除或减重手术后）、低枸橼酸尿症、原发性甲状旁腺功能亢进症和远端肾小管酸中毒相关；
- **尿酸**：与酸性尿、痛风、代谢综合征和细胞更新加快相关；X线平片不显影但CT可见；可通过碱化尿液溶解；
- **鸟粪石**（磷酸镁铵）：在感染产脲酶细菌（如变形杆菌）时于碱性尿中形成；可长成充满肾盂的大“鹿角形”结石；
- **胱氨酸**：见于遗传性疾病胱氨酸尿症；自儿童期起反复发作。
:::

结石很常见，在许多高收入国家约有十分之一的人一生中会患病，而且常常复发。肾内结石可无症状。当结石进入输尿管并造成梗阻时，就引起**肾绞痛**：腰部突发剧烈绞痛，放射至腹股沟或外生殖器，伴烦躁不安、恶心呕吐和血尿（常为镜下血尿）。结石易嵌顿在输尿管狭窄处：肾盂输尿管连接部、跨越髂血管处和输尿管膀胱连接部。

**检查与处理**（NICE NG118）：
- 成人就诊后24小时内行肾、输尿管和膀胱**低剂量非增强CT**（妊娠时以及通常在儿童中用超声）；
- 一线镇痛用任何途径的**非甾体抗炎药**，必要时用静脉对乙酰氨基酚，然后用阿片类；
- 对小于10 mm的输尿管远端结石考虑使用**α受体阻滞剂**帮助排石；
- 大多数小结石（小于约5 mm）可自行排出；较大或位于近端的结石、不能排出的结石以及引起不能控制的疼痛的结石需要治疗：**输尿管镜**、**冲击波碎石**，大的肾结石用**经皮肾镜取石术**；
- **任何伴梗阻和感染的结石**都需要紧急减压，如[[#ex-uro-sepsis]]。

::: example 两次绞痛与预防 {#ex-stone-prevention}
一名38岁男性屋顶工人在户外工作，两年内第二次发生肾绞痛。两次结石都是草酸钙。他每天饮水约1 L，主要是可乐，并吃大量咸的加工食品。血清钙和尿酸正常。哪些建议和检查能降低其复发风险？
::: solution
他的主要危险因素是**尿量少**，工作时出汗使之加重。最有效的单一措施是饮足够的水，使**每天尿量达到2.5～3 L**，以白开水为好，而不是含糖或碳酸饮料；加入新鲜柠檬汁可增加尿枸橼酸这一结晶抑制物。

针对草酸钙结石的其他饮食措施：**减少盐**（钠增加尿钙），保持**正常的钙摄入**（饮食中的钙在肠道结合草酸；限制钙会增加草酸吸收和结石风险），适量摄入动物蛋白，避免草酸摄入过多。

由于他是复发性结石，应进行**代谢评估**：血清钙（已做）、尿酸，以及24小时尿液分析（尿量、钙、草酸、枸橼酸、尿酸和钠），据此指导特异性治疗，如对高钙尿症用噻嗪类，对低枸橼酸尿症用枸橼酸钾。
:::
:::

## 梗阻与前列腺

::: definition 尿路梗阻 {#def-prostate}
**梗阻性尿路病**是尿流受阻；由此引起的肾盂和肾盏扩张称为**肾积水**。梗阻可位于**上尿路**（结石、肾盂输尿管连接部梗阻、肿瘤、腹膜后纤维化、妊娠）或**下尿路**（前列腺增大、尿道狭窄、膀胱肿瘤、神经源性膀胱、药物和便秘引起的尿潴留）。

良性前列腺增生引起的**良性前列腺增大**是老年男性下尿路梗阻最常见的原因。它引起**下尿路症状**：排尿期症状（排尿踌躇、尿线细弱、费力、排空不尽感、终末滴沥）和储尿期症状（尿频、尿急、夜尿）。

**急性尿潴留**是伴膀胱膨胀的疼痛性不能排尿。**慢性尿潴留**无痛，残余尿量大；膀胱压力高时可引起双侧肾积水和CKD。
:::

男性**下尿路症状的处理**（NICE CG97）包括生活方式措施（减少晚间饮水、咖啡因和酒精），对中重度排尿期症状使用**α受体阻滞剂**（如坦索罗辛），它松弛前列腺平滑肌，数天内起效；对前列腺增大或进展风险高的男性使用**5α还原酶抑制剂**（如非那雄胺），它在6～12个月内使腺体缩小。对重度症状、尿潴留或有并发症者提供手术（经尿道切除术和较新的技术）。

**急性尿潴留**通过导尿解除。通常在尝试拔除导尿管之前开始使用α受体阻滞剂。治疗或去除便秘、抗胆碱能药物、阿片类、酒精和感染等诱因。

::: example 无痛的大膀胱 {#ex-retention}
一名74岁男性数月来夜间“尿床”，尿线细弱。他没有疼痛。腹部可触及一个浊音、无压痛、上达脐部的包块。肌酐260 µmol/L（无既往结果），超声示双侧肾积水，膀胱残余尿量1600 mL。解释这些表现，以及导尿后可能出现的情况。
::: solution
**高压性慢性尿潴留**，最可能由前列腺梗阻引起。膀胱被缓慢拉伸，直至在高压下容纳大量尿液。夜间尿湿是**充溢性尿失禁**，不是储尿问题。膀胱高压传递到双侧肾脏，引起**双侧肾积水**和肾功能损害。

**导尿**后，肾功能通常在数天到数周内改善，但部分损失可能是永久性的。随后可能出现**梗阻后利尿**，每天尿量可达数升；应监测液体平衡、体重和电解质，若出现容量不足则补液。有些临床医生在大量引流减压期间仔细监测血压。长期选择是手术解除梗阻或长期留置导尿管，取决于他的身体状况和意愿。由于膀胱肌肉长期被拉伸，尝试拔除导尿管不太可能成功。
:::
:::

## 囊性疾病与肿瘤

::: definition 多囊肾病与泌尿系统肿瘤 {#def-cancers}
**常染色体显性多囊肾病**（ADPKD）是最常见的遗传性肾病，主要由*PKD1*或*PKD2*变异引起。双肾囊肿进行性增大，使肾脏增大并破坏正常组织，因此许多患者在中年时发生肾衰竭（*PKD2*者较晚）。其特征包括高血压、腰痛、血尿、囊肿感染、结石、肝囊肿，少数人有颅内动脉瘤。血管升压素V2受体拮抗剂**托伐普坦**可减缓部分快速进展的成人患者的囊肿生长。随年龄增长常见的单纯性肾囊肿是另一种情况，通常无害。

**膀胱癌**通常为**尿路上皮癌**。其主要危险因素是**吸烟**；其他危险因素有芳香胺的职业暴露（染料和橡胶工业），以及在世界范围内的血吸虫病（与鳞状细胞癌相关）。其典型表现为**无痛性肉眼血尿**。

**肾细胞癌**起源于肾小管上皮；透明细胞型最常见，与*VHL*基因缺失有关。危险因素包括吸烟、肥胖和高血压。如今大多数是在影像检查中偶然发现的；血尿、腰痛和肿块的经典三联征是晚期表现。它可引起副肿瘤效应（红细胞增多症、高钙血症）。

**前列腺癌**是英国男性最常见的癌症。早期通常无症状。对**前列腺特异性抗原**（PSA）升高的评估如今在活检之前先做多参数**MRI**。PSA不具特异性：良性增大、感染、近期射精和导尿也会使其升高。
:::

::: example 无痛的红色尿液 {#ex-haematuria}
一名63岁女性吸烟40年、每天20支，一周内三次排出鲜红色带小血块的尿液。她没有疼痛，也没有排尿症状；尿试纸亚硝酸盐和白细胞阴性。最需要排除的诊断是什么？如何排除？
::: solution
**老年吸烟者的无痛性肉眼血尿在被证明是其他原因之前都应视为膀胱癌。**肾和上尿路肿瘤也有可能。NICE NG12建议，45岁及以上、无尿路感染而有不明原因肉眼血尿，或UTI成功治疗后肉眼血尿持续或复发者，按疑似癌症路径转诊。

血尿门诊的评估包括**软性膀胱镜**检查膀胱、**上尿路影像**（CT尿路造影或超声）、肾功能和血压。若发现膀胱肿瘤，经内镜切除（经尿道膀胱肿瘤切除术），同时提供用于分期的组织。应为她提供戒烟支持，戒烟可降低复发风险。
:::
:::

::: warning 不要把血尿归咎于显而易见的原因 {#warn-haematuria}
服用抗凝药或有尿路感染的人出现血尿时，常被归咎于抗凝药或感染。抗凝药更多是暴露了潜在病变的出血，而不是引起出血，所以服用抗凝药时的肉眼血尿应与其他人一样进行检查。伴UTI的血尿应在治疗后复查；若持续存在，需要检查。同样，红色尿液并不总是血：甜菜根、利福平和其他一些药物会使尿液着色，而尿试纸隐血阳性但镜检无红细胞提示肌红蛋白或游离血红蛋白（[[renal/filtration]]）。
:::

::: quiz
一名26岁未妊娠女性排尿困难和尿频一天。她没有发热或腰痛，过去一年没有发生过UTI。哪种处理最符合NICE指南？
- [ ] 环丙沙星14天疗程
- [ ] 送尿培养，在结果出来之前不治疗
- [x] 给予3天疗程的合适抗生素（如呋喃妥因），症状轻者也可给予备用处方并提供自我护理建议
- [ ] 肾脏和膀胱超声
::: solution
这是非妊娠女性的单纯性下尿路感染。NICE建议3天疗程的呋喃妥因（肾功能允许时）或甲氧苄啶（耐药风险低时），症状轻者也可给予备用处方并提供自我护理建议，因为许多感染无需抗生素即可缓解。常规不需要培养。由于不良反应和耐药问题，喹诺酮类留作特定情况使用；单次单纯性感染不需要影像检查。
:::
:::

::: history
历史上大部分时间里，肾结石靠开放手术取出，“切石术”是最古老、最危险的手术之一。冲击波碎石改变了这一切。德国航空航天公司多尼尔（Dornier）的工程师注意到冲击波能损坏材料，他们与慕尼黑大学的泌尿外科医生一起研制出一台从体外把冲击波聚焦于结石的机器。1980年2月，肖西（Christian Chaussy）及其同事治疗了第一位患者：患者坐在水浴中，结石被击碎成足以排出的小碎片。十年之内，碎石术和内镜技术已使开放取石手术变得罕见。
:::

## 后续内容

结石、前列腺疾病和泌尿系统肿瘤的外科处理见[[surgery/vascular-urological-surgery]]。儿童UTI（包括膀胱输尿管反流）见[[paediatrics/acute-childhood-illness]]，妊娠期UTI见[[obstetrics-gynaecology/pregnancy-complications]]。抗生素管理和耐药见[[microbiology/antimicrobials]]，急性肾损伤的梗阻性病因见[[renal/acute-kidney-injury]]。

::: summary
- 大多数UTI是上行性的；带黏附菌毛的大肠埃希菌引起大部分感染。危险因素包括女性解剖、妊娠、排空不全、导尿管、结石和结构异常。
- 65岁以下女性的下尿路感染根据症状诊断，可加尿试纸；65岁以上者和留置导尿管者不用尿试纸。男性、妊娠、儿童和复杂性感染需送培养。
- NICE：非妊娠女性单纯性下尿路感染治疗3天，男性和妊娠女性7天；只在妊娠和泌尿外科操作前治疗无症状菌尿。
- 感染性梗阻肾是需要减压的泌尿外科急症。
- 大多数结石是草酸钙。肾绞痛：24小时内CT，非甾体抗炎药为一线，小于10 mm的远端结石用α受体阻滞剂。通过多饮水、少盐和正常饮食钙预防复发。
- 良性前列腺增大引起排尿期和储尿期症状、急性和慢性尿潴留；高压性慢性尿潴留引起双侧肾积水，导尿后出现梗阻后利尿。
- 成人无痛性肉眼血尿需要检查是否为泌尿系统肿瘤；ADPKD是肾衰竭最常见的遗传性病因。
:::

## 习题

::: exercise 感染分类 {level=1}
将下列情况分为上尿路或下尿路、复杂性或单纯性：(a) 一名30岁女性排尿困难和尿频；(b) 一名45岁男性排尿困难、尿频和发热；(c) 一名妊娠20周的25岁女性腰痛伴寒战；(d) 一名长期留置导尿管的70岁女性出现发热和新的意识模糊。
::: solution
(a) 下尿路，单纯性。(b) 男性下尿路感染按定义是复杂性的；发热提示可能有前列腺炎或肾盂肾炎。(c) 上尿路（肾盂肾炎），因妊娠而为复杂性；她需要住院静脉治疗。(d) 导尿管相关UTI，可能伴尿源性脓毒症，复杂性；通常更换导尿管，并在使用抗生素前从新导尿管留取培养。
:::
:::

::: exercise 为什么查亚硝酸盐？ {level=1}
解释亚硝酸盐尿试纸检测的生化基础，并给出真正的UTI时其结果可能为阴性的两个原因。
::: solution
许多革兰阴性尿路病原体，包括大肠埃希菌，能把尿中的硝酸盐（来自饮食）还原为亚硝酸盐，试纸检测的就是亚硝酸盐。结果可能为阴性的原因：(1) 病原体不能还原硝酸盐，如肠球菌或腐生葡萄球菌；(2) 尿液在膀胱中停留的时间不够长（约四小时），来不及转化，如膀胱炎时频繁排尿；或 (3) 饮食中硝酸盐少或尿液非常稀释。
:::
:::

::: exercise 选择结石的治疗 {level=1}
对下列每种情况，说明最合适的初始处理：(a) 输尿管膀胱连接部4 mm结石，疼痛已控制；(b) 输尿管近端8 mm结石，48小时后疼痛仍不能控制；(c) 6 mm输尿管结石伴肾积水、发热和低血压。
::: solution
(a) 观察等待，镇痛（非甾体抗炎药），远端结石可加或不加α受体阻滞剂；这种大小的结石大多能排出。(b) 积极治疗，如输尿管镜或冲击波碎石；自行排出的可能性小且疼痛不能控制。(c) 紧急减压（肾造瘘或支架）加抗生素和复苏；结石的确定性治疗稍后进行。
:::
:::

::: exercise 尿试纸的预测值 {level=2 check="round(0.3*0.5/(0.3*0.5+0.7*0.05)*100)/100"}
在一组有泌尿症状的女性中，UTI的患病率为30%。某亚硝酸盐检查的示意性灵敏度为50%，特异度为95%。计算亚硝酸盐阳性的阳性预测值，以小数表示，保留两位小数。
::: hint
在1000名女性中，数出真阳性和假阳性的人数。
:::
::: solution
1000名女性中：300人患UTI，其中150人检测阳性（真阳性）。700名未患UTI者中有5%检测阳性：35名假阳性。PPV $= 150/(150 + 35) = 0.81$。亚硝酸盐阳性使UTI的可能性很大。但一半UTI患者检测阴性，所以在症状典型时，亚硝酸盐阴性并不能排除感染。
:::
:::

::: exercise 解读肾积水 {level=2}
一名62岁女性五年前因宫颈癌接受放疗，她的肌酐在六个月内从80升至190 µmol/L。超声示双侧肾积水而膀胱空虚。膀胱空虚说明什么？可能的病因有哪些？
::: solution
双侧肾积水而膀胱空虚，说明梗阻位于**膀胱以上**，累及双侧输尿管。可能的病因有**盆腔恶性肿瘤复发**压迫输尿管、**放射性输尿管狭窄或纤维化**，或腹膜后纤维化。需要CT明确病因。用肾造瘘或输尿管支架解除梗阻可能保住肾功能，决策需与她本人一起作出，并考虑基础诊断和她的照护目标。
:::
:::

::: exercise 解读PSA {level=2}
一名66岁男性因朋友被确诊而要求查PSA。他的PSA为6.2 ng/mL。两周前他患过UTI。讨论如何解读以及下一步。
::: solution
前列腺癌、良性增大、感染或炎症、近期射精、骑自行车等剧烈运动以及器械操作都可以使PSA升高。近期UTI是PSA一过性升高的常见原因，所以应在感染消退后（常在约六周后）复查。若PSA仍高于与年龄相应的转诊阈值，转诊泌尿外科，那里用**多参数MRI**决定是否需要活检。对无症状男性进行PSA检测需要权衡可能的获益（较早发现有临床意义的癌症）和伤害（假阳性、过度诊断生长缓慢的癌症以及治疗副作用），检测前应与他讨论（[[public-health/screening]]）。
:::
:::

::: exercise 儿童反复UTI {level=3}
一名2岁女孩六个月内第二次发生发热性UTI；第一次培养出非典型病原体，且对治疗反应慢。解释为什么儿童UTI的检查与成人不同，以及所用影像检查的目的。
::: solution
在幼儿中，发热性UTI更常累及肾脏，反复的肾盂肾炎可引起**肾瘢痕**，日后可导致高血压和CKD。幼儿UTI也可能是**结构异常**的首发表现，尤其是**膀胱输尿管反流**（排尿时尿液反流至输尿管）或梗阻。按照NICE NG224，幼儿的非典型或反复感染需要影像检查：感染期间或感染后不久行**超声**寻找梗阻和结构异常；数月后行**DMSA扫描**发现瘢痕；对部分幼儿行**排尿性膀胱尿道造影**显示反流。处理包括及时治疗以后的感染、关注便秘和排尿习惯，以及专科随访。年龄较大的儿童和成人单次单纯性感染不需要这些检查。
:::
:::

::: exercise 家族中的多囊肾病 {level=3}
一名38岁高血压男性超声发现双肾增大、有多个囊肿。他父亲54岁开始透析。讨论诊断、对他本人和家人的意义以及处理原则。
::: solution
**常染色体显性多囊肾病**，鉴于其父亲较早发生肾衰竭，最可能是*PKD1*变异引起。他的每个孩子都有50%的概率遗传该病。

**对他本人**：控制血压（ACE抑制剂或血管紧张素受体阻滞剂），保持健康体重，适量限盐并充分饮水；监测肾功能；评估是否快速进展（用影像学肾脏体积和eGFR下降速度），以决定是否适合使用**托伐普坦**，并监测肝功能；处理疼痛、囊肿出血和感染；若有动脉瘤或蛛网膜下腔出血家族史，筛查**颅内动脉瘤**。尽早规划肾衰竭的应对，包括肾移植。

**对家人**：遗传咨询。对成年亲属（包括其子女成年后）进行检测是个人决定，涉及保险和活体肾捐献：考虑向他捐肾的亲属必须被证明没有ADPKD（[[genetics/genetic-testing]]）。
:::
