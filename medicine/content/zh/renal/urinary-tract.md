在滤过的机器下面是管道——而管道有它们自己的疾病：**从这些会阴上升的感染、在尿被浓缩的地方生长的结晶、安静地摧毁这两个肾的梗阻、以及上皮的衬里和实质的四个不同的肿瘤。**这一章也是肾的应用的微生物学与抗菌的约束的章节（[[microbiology/laboratory-diagnosis]]与[[infectious-diseases/healthcare-infections]]、[[microbiology/antimicrobials]]）以及门诊的操作的路径。

本章涵盖尿路的感染、结石、梗阻与潴留、囊性的疾病以及尿路的肿瘤。

## 感染

::: definition 尿路感染：解剖、分类与病原 {#def-uti}
**解剖会决定路径：女性的短的尿道与这些会阴的菌群（性的活动与杀精剂及绝经后的变化会增加风险）；在男性中的长的尿道会保护直到前列腺改变流体的动力学（梗阻与器械[[#def-prostate]]）；而任何会阻塞尿的东西都会感染它（结石与导管和妊娠[[obstetrics-gynaecology/pregnancy-antenatal]]、神经的膀胱[[nervous-system/motor-systems]]）。病原：肠道的（大肠杆菌与克雷伯菌和肠球菌及假单胞菌在器械的宿主中），葡萄球菌在年轻的女性中，以及念珠菌在导管和糖尿病中[[microbiology/bacteria]]、[[microbiology/fungi-parasites]]；耐药的模式（广谱的β内酰胺酶与耐甲氧西林的[[microbiology/antimicrobials]]、[[infectious-diseases/stewardship-outbreaks]]）会指导经验的选择。分类就是决定：下（膀胱炎：尿道的症状伴白细胞的尿而无症状的全身的）；上（肾盂肾炎：发热与肋痛的叩击的疼痛和恶心）；导管的（总是症状而不是气味的定义）；复杂的（男性与妊娠及结构的异常和器械与免疫抑制[[infectious-diseases/immunocompromised-host ]]）；以及梗阻性的化脓的（一个紧急[[#ex-uro-sepsis]]）。检查：非复杂的女性不需要培养；在复杂的/上部的病例中在开始之前先培养（[[microbiology/laboratory-diagnosis ]]）；影像（超声/计算机的断层）在重症与梗阻的怀疑和治疗失败时[[clinical-skills/medical-imaging]]。治疗：在下（短的疗法：呋喃妥因或磷霉素或美西林酯类，按当地的敏感性[[microbiology/antimicrobials]]）；在肾盂肾炎（口服或静脉的一个氟喹诺酮或一个头孢曲松，带着耐药的数据，然后被降级的按培养）；复杂的（更广的覆盖与来源的控制）；妊娠（被允许的药物与在妊娠晚期的预防[[obstetrics-gynaecology/pregnancy-complications ]]）；以及复发（行为与局部的雌激素和微生物的策略、疫苗、以及在选择性中预防的抗生素，避开常规的轮换[[infectious-diseases/stewardship-outbreaks]]）。这些不要做：无症状的菌尿不被治疗，除了妊娠与泌尿外科的操作之前[[#ex-asb]]；而在导管的患者中去除气味不是适应证[[geriatrics-palliative/polypharmacy]]。**
:::

::: example 被梗阻的脓 {#ex-uro-sepsis}
一位有已知的8毫米近段的输尿管结石的人（在一个心脏的事件后开始着抗凝）因发热39.4与寒战和肋腹的疼痛及意识混乱就诊；乳酸4.2，肌酐210基线105)，血小板下降；计算机的断层显示出梗阻的结石伴肾周的条纹和一个不增强的集合系统。
::: solution
**一个被梗阻的感染的肾就是外科的紧急：被感染的尿在压力下会把细菌冲进血流，而抗生素不会穿透被梗阻的集合（一个被梗阻的脓的收集无法被药物治愈）。行动按分钟：复苏的包（培养，然后广谱的抗生素，液体和乳酸的轨迹[[emergency-critical-care/shock-fluids]]、[[infectious-diseases/fever-sepsis]]）与即刻的减压（逆行输尿管的支架或经皮的肾造瘘——按当地的专长与解剖；两者同样有效，而延误会杀死）[[clinical-skills/medical-imaging]]、[[surgery/vascular-urological-surgery]]；然后在感染被解决后结石的治疗（不会被立即）[[#def-stones]]。伴随：急的肾损伤的管理[[renal/acute-kidney-injury]]与抗凝的逆转在操作前（血栓的风险与出血的平衡[[blood/thrombosis-anticoagulation ]]）；以及脓毒症和梗阻的标记（意识混乱与少尿）在重症的照护中[[emergency-critical-care/critical-care]]。系统的工作：一个泌尿道脓毒症的路径（急的肾的超声与周末的介入的放射学）会减少延误（[[#ex-haematuria]]）。**
:::

## 结石、梗阻、囊肿与肿瘤

::: definition 尿路的结石：成分、绞痛与预防 {#def-stones}
**成分：以草酸的钙为主（约75%到80%）与磷酸的钙，以及尿酸的（约10%：一个低的尿的酸碱度与痛风及代谢的综合征和高的嘌呤与腹泻的肠造口的酸尿的环境[[gastrointestinal/bowel-disease]]、[[endocrine/diabetes]]）、感染性的 struvite 的结石（产尿素酶的生物与珊瑚形的快速的生长者[[microbiology/bacterial-pathogenesis]]、[[#def-uti]]）、以及胱氨酸的（遗传的[[genetics/mendelian-inheritance]]）。风险：低的尿量（职业与气候）与家族的病史和饮食（钠与草酸盐及嘌呤）、肥胖与肠的疾病（脂肪的吸收不良会把草酸盐的吸收增加[[gastrointestinal/bowel-disease]]）以及药物（托吡酯与磺胺的结石）。表现：绞痛（剧烈波动性的肋腹向腹股的放射，带坐立不安与恶心；常常显微镜的血尿而肉眼可见的会见于三分之一；一个不痛的梗阻的肾是危险的版本）；梗阻与感染（[[#ex-uro-sepsis]]）；以及慢性的损害的反复发作。诊断：非增强计算机的断层（金标准：大小与HU和积水[[clinical-skills/medical-imaging]]）或急的妊娠/儿童的超声[[obstetrics-gynaecology/pregnancy-complications]]与[[paediatrics/acute-childhood-illness]]；以及感染与肾的损伤的排除[[renal/acute-kidney-injury]]、[[#def-uti]]。管理：镇痛（非甾体的首选，带着肾的告诫[[renal/filtration]]；阿片类的添加）；排石的治疗（α阻滞剂用于远段的结石）；干预（体外的冲击波或输尿管镜/经皮的肾镜在失败时或大的结石或在单肾与职业中[[surgery/vascular-urological-surgery ]]）；以及永远不要漏掉感染结石（[[#ex-uro-sepsis]]）。预防（第二次结石的患者）：24小时的尿的评估（体积与钙及草酸盐和枸橼酸盐与尿酸[[#ex-stone-prevention]]）；共同的规则（液体的体积（把尿增加到2.5升以上）、钠的减少、正常膳食的钙（不要限制它！）、草酸盐的调节和柠檬的汁）、按表型（噻嗪用于高尿钙；枸橼酸钾用于低的枸橼酸盐与尿酸的结石的酸碱度的碱化；别嘌醇在选择的病例中；感染结石完全的清除[[#def-uti]]）；以及影像的随访。**
:::

::: definition 梗阻、潴留与前列腺 {#def-prostate}
**下尿路的梗阻：良性前列腺增生症状的架构（储存的（频率与夜尿及急迫）与排尿的（踌躇与细的尿线及排空不全）；症状的评分与尿流率和排后的残余的评估；以及在真正的出口梗阻对照膀胱的去活动之间的尿流动力学的研究[[renal/filtration]]的肾后的诊断）；伴随的：急性的潴留（剧痛与这些不能排尿；导尿与α阻滞剂和之后的试验的拔管；感染与肾的损伤[[renal/acute-kidney-injury]]）、慢性的（无痛的膨胀与溢出性的失禁）、以及后梗阻的利尿[[renal/water-sodium]]。原因：男性在老年中的前列腺；女性的脱垂与手术[[obstetrics-gynaecology/menstrual-pelvic-disorders]]；神经源性的膀胱（脊髓的损伤与多发的硬化和糖尿病[[nervous-system/motor-systems]]、[[endocrine/diabetes-complications]]）；药物的抗胆碱（[[renal/acute-kidney-injury]]的抗胆碱的负担[[geriatrics-palliative/polypharmacy ]]）；结石与凝块[[#def-stones]]、[[#ex-haematuria]]；以及腹膜后的纤维化与肿瘤（[[obstetrics-gynaecology/gynaecological-cancer]]、[[surgery/vascular-urological-surgery]]）。上尿路的梗阻：结石与外源的压缩和上皮的狭窄——一个孤立的肾或双侧的梗阻会造成少尿与急的肾的损伤[[renal/acute-kidney-injury]]；诊断就是超声（积水）与计算机的断层；治疗就是减压（支架/造瘘）。长期：梗阻性肾病与反流的损害（在儿童中的瘢痕与妊娠[[paediatrics/congenital-genetic]]、[[obstetrics-gynaecology/pregnancy-complications]]）、以及下尿路的症状在男性中的管理（α阻滞剂和5还原酶的抑制剂和手术的经尿道的电切激光[[surgery/vascular-urological-surgery]]，带着尿潴留与肾功能保护的指征，以及PSA的讨论[[#def-cancers]]）。**
:::

::: definition 囊性的疾病与尿路的癌症 {#def-cancers}
**囊性的肾：简单的囊肿（年老的一个几乎普遍的发现，以及影像的分类把它们归为良性的[[clinical-skills/medical-imaging ]]）对照常染色体显性的多囊（多囊的1与2的纤毛信号的疾病：早发的高血压与增大的肾和囊肿、肝的囊肿与动脉瘤（脑[[nervous-system/stroke]]）及瓣膜的异常和结肠的憩室[[genetics/mendelian-inheritance]]、[[gastrointestinal/bowel-disease]]）与常染色体隐性的（儿童的肝纤维化[[paediatrics/congenital-genetic]]）。管理：家族的咨询与筛查和血压（阻断剂）以及疾病修饰的治疗（血管加压素的拮抗剂在选择中期的中）、疼痛与感染和结石[[#def-stones]]、以及肾的衰竭的路径（透析与移植，带着大的肾的挑战[[#def-prostate]]、[[#def-prostate ]]）。尿路的癌症：上皮的（膀胱的移行细胞：无痛血尿的吸烟者与职业的芳香的胺的暴露[[#ex-haematuria]]；经尿道的切除与膀胱内的卡介苗/化疗对肌层浸润的膀胱切除或放化疗[[pathology/cancer-diagnosis]]、[[pathology/cancer-diagnosis]]）；肾细胞（经典的三联征（血尿与疼痛与肿物）很少；偶然发现的肿物；细胞减灭的肾切除带转移免疫的/靶向的治疗[[immunology/vaccines-immunotherapy]]）；肾盂与输尿管的上皮的（上道的血尿与输尿管镜）；前列腺（[[#def-prostate]]的PSA的筛查的辩论与风险分层的管理——主动监测对治疗[[surgery/vascular-urological-surgery]]）；以及睾丸（年轻男性的肿物与生育力的保存[[obstetrics-gynaecology/contraception-fertility]]）和阴茎（HPV相关[[immunology/hypersensitivity]]）。共同的规则：无痛的肉眼血尿需要上尿路与膀胱镜的评估，无论尿的结果[[renal/filtration]]；以及转介的路径的两星期癌症的标准会减少延误[[clinical-skills/patient-safety]]。**
:::

::: example 双胞胎的绞痛 {#ex-stone-prevention}
两个45岁的人会排草酸的钙的结石：(a) 24小时的尿：体积1.1升，钙9，草酸盐正常，枸橼酸盐低正常，钠高；(b) 体积2.2升，钙3，草酸盐0.65（高），枸橼酸盐低，有胃旁路手术的病史。
::: solution
**同一个的结石，两种不同的表型（[[#def-stones]]）：(a一个低尿量与高尿钙伴高的钠：液体（每日2.5升以上的尿）与钠的减少，以及如果持续就噻嗪（带着钾与枸橼酸盐，因为袢会浪费钙[[renal/tubular-function]]，而噻嗪会回收它）；以及正常的膳食的钙（限制钙会增加草酸盐的吸收与结石）[[gastrointestinal/clinical-nutrition]]。(b肠源性：因为脂肪的吸收不良导致的草酸盐的过多吸收与低的枸橼酸盐和碱的缺失（胃的旁路与肠的疾病的经典的后果[[gastrointestinal/bowel-disease]]）：把液体升高、减少草酸盐的食物、口服的钙与餐一起（会在肠内结合草酸盐）、枸橼酸钾（碱与枸橼酸盐两者）以及脂肪的策略。两者：结石的分析与24小时的重复（在改变之后）和影像；复发率是动机[[clinical-skills/clinical-reasoning]]。**
:::
:::

::: example 发臭的尿的转介 {#ex-asb}
一个有痴呆与长期的导管的84岁的护理之家的居民因黑暗发臭的尿被转介；她无热，在基线清醒，血流动力学正常；尿的试纸：亚硝酸盐与白细胞都强烈阳性。
::: solution
**一个被定植的导管就是无症状的菌尿：气味与颜色不改变管理，而试纸的阳性在有导管的人中是预期的[[#def-uti]]、[[#ex-asb]]。正确的行动：检查这个导管（阻塞与环路）并优化护理（引流袋的位置与排空和这些会阴的卫生、液体的状态）、审查症状（发热与疼痛及意识改变和血流动力学）、以及停止反射性抗生素的医嘱[[geriatrics-palliative/polypharmacy]]。为什么这重要：在导管的居民中治疗无症状的菌尿会造成艰难梭菌的感染与耐药，并会把将来的发作弄得更难（[[microbiology/antimicrobials]]、[[infectious-diseases/healthcare-infections]]、[[microbiology/infection-control]]）。例外：妊娠与泌尿外科的操作（[[obstetrics-gynaecology/pregnancy-complications]]）。教育：给 staff 的一份书面的政策，并把这次会诊作为一个避免的处方记录下来[[clinical-skills/patient-safety]]。**
:::
:::

::: example 不痛的尿 {#ex-haematuria}
一位61岁的退休的油漆工（三十包年）注意到两天的不痛的肉眼血尿伴小的血块；没有排尿的疼痛；血压132/78；肌酐96；试纸的血4+；超声显示出1.5厘米膀胱充盈的缺损与正常的肾。
::: solution
**在吸烟男性中的不痛的肉眼血尿就是直到被证明别的膀胱的癌：超声充盈的缺损就是膀胱的病变，而路径就是经尿道切除（诊断与分期：肌层的侵犯决定管理）与膀胱内的治疗（低风险单发的与高危的复发的卡介苗/化疗），对肌层浸润的膀胱切除或保留的策略[[#def-cancers]]、[[pathology/cancer-diagnosis]]、[[surgery/vascular-urological-surgery]]。伴随的要求：上尿路的评估（计算机的断层尿路造影：肾盂与输尿管的上皮的肿瘤[[clinical-skills/medical-imaging]]）与膀胱镜（超声会漏掉扁平的病变）；对肾功能的评估与抗凝的审查（永远不要因为稀释的药而不去调查[[blood/thrombosis-anticoagulation]]）；以及肾小球的的排除（畸形的红细胞与管型及蛋白尿[[renal/filtration]]）。预后与随访：复发的方案与细胞学的局限；以及戒烟的咨询[[public-health/prevention-promotion]]。**
:::

::: history
**尿路感染抗菌治疗的时代从五十年代磺胺预防的试验与八十年代氟喹诺酮的浪潮以及随之而来保留的反弹开始；无症状菌尿的不治疗的证据（护理之家的学派与2019年的指南）与导管的定植的观察不会造成伤害的研究[[infectious-diseases/healthcare-infections]]；结石医学的血统（代谢分型的计划与噻嗪和枸橼酸盐的试验，以及把外科变成内镜与激光的操作的碎石的技术[[surgery/vascular-urological-surgery ]]）；多囊的基因的克隆与疾病修饰治疗的试验[[genetics/mendelian-inheritance]]；以及尿路的癌症的路径（两星期的转介与膀胱保存的策略）和卡介苗的免疫治疗（把感染用作治疗[[immunology/vaccines-immunotherapy]]）。本章就是微生物的约束、结石的代谢与腔内的外科的累积。**

## 通向何处

滤过与肾后的诊断在[[renal/filtration]]与[[renal/acute-kidney-injury]]；抗菌的选择与耐药在[[microbiology/antimicrobials]]与[[infectious-diseases/stewardship-outbreaks]]；导管的感染在[[infectious-diseases/healthcare-infections]]；肾后梗阻的损伤在[[renal/chronic-kidney-disease]]；妊娠的尿路在[[obstetrics-gynaecology/pregnancy-complications]]；儿童的尿路在[[paediatrics/congenital-genetic]]；手术的路径在[[surgery/vascular-urological-surgery]]；以及血液的尿在[[renal/filtration]]。

::: exercise 咨询这个家庭 {level=2}
一位有常染色体显性多囊的肾的33岁的人（多囊的肾与一个肝的囊肿，而他的父亲在50岁时透析）询问对他的两个孩子以及他自己的血压的筛查。给出遗传的对话与管理的清单。
::: solution
**遗传：常染色体的显性多囊的1与2)：每一个的孩子有50%的风险[[genetics/mendelian-inheritance]]；症状的起始与基因的类型会不同（多囊的1会更早更重），而预测的测试在孩子中是有伦理的（一个没有被提供的治疗的儿童期的预测[[medical-ethics-law/consent-capacity]]、[[paediatrics/immunisation]]）。成人有风险的人的选项（超声/磁共振与基因的面板）以及保险的告诫（[[medical-ethics-law/consent-capacity]]）。血压与管理：严格血压的控制（阻断剂在有风险的年轻人中会减缓囊肿的生长与蛋白尿[[cardiovascular/hypertension]]）；液体（在疾病的中期血管加压素的拮抗剂会减少囊肿，带着选择与排水的副作用[[renal/water-sodium ]]）；疼痛与结石（[[#def-stones]]）与囊肿的感染（脂溶性的抗生素[[microbiology/antimicrobials]]）以及血尿的卧床的休息；筛查：颅内动脉瘤在有出血的家族史或高风险的职业中[[nervous-system/stroke]]；瓣膜的与结肠的憩室[[gastrointestinal/bowel-disease]]与疝；以及肾的衰竭的路径[[#def-prostate]]、[[renal/chronic-kidney-disease]]。生活：接触运动的告诫（囊肿的破裂）与妊娠的咨询[[obstetrics-gynaecology/contraception-fertility]]。**
:::
:::

::: summary
- 尿路感染的管理就是分类加约束：简短地治疗有症状下尿路的疾病，果断地治疗上尿路的并带着来源的控制，而在妊娠与泌尿外科的手术之外永不治疗无症状的菌尿。
- 一个被梗阻的感染的肾就是按小时计量引流的紧急；而这个结石的其他疾病靠镇痛、排出和择期的泌尿外科，以及24小时尿代谢的预防用于反复的排石者。
- 梗阻会隐藏：肾后急的肾的损伤与夜尿以及仅仅是年老的潴留都要求一个膀胱的扫描和一个前列腺与药物的审查；在肾单位谈判之前先减压。
- 囊肿多数是良性的年老，除了多囊——一个带有动脉瘤与肝的疾病和家族的影响的系统性的纤毛病，而现在有一个疾病修饰的药。
- 尿路的癌症按衬里不同：吸烟驱动上皮的（血尿的路径）、肾细胞的（免疫治疗的组合）、前列腺的（风险分层的监测）以及睾丸的（被铂类治愈；先保存精子）。
:::

## 练习

::: exercise 治疗膀胱炎 {level=1}
一位非妊娠的26岁的人有排尿的疼痛与频率，无发热也无肋腹的疼痛，亚硝酸盐阳性，无并发症：给出处方的逻辑。
::: solution
**一个非复杂的下尿路感染（[[#def-uti]]）：一个短的疗法（呋喃妥因五日或磷霉素的单剂或美西林酯类七日方案，按当地的敏感性[[microbiology/antimicrobials ]]）；不需要培养；不需要影像。保留（氟喹诺酮会保留给上尿路的与复杂的疾病，因为它们严重的不良反应与耐药的压力[[infectious-diseases/stewardship-outbreaks]]）。提醒：在发热或肋腹痛时把肾盂肾炎治疗[[#def-uti]]；在妊娠中始终培养（[[obstetrics-gynaecology/pregnancy-complications]]）；在男性中视为复杂[[#def-prostate]]；以及在四次到六周内的复发或非典型的症状会引出检查[[clinical-skills/clinical-reasoning]]。预防：在选中者中的性交后/每天的策略与局部的雌激素在绝经后的女性中，加上非抗菌的选项（蔓越莓的证据薄弱[[public-health/prevention-promotion]]）。**
:::
:::

::: exercise 解释脓尿 {level=2}
无菌的脓尿：列出五个原因与每一个一个有鉴别力的检查。
::: solution
**结核（分枝杆菌的培养/核酸的扩增与影像[[microbiology/laboratory-diagnosis]]、[[infectious-diseases/tuberculosis]]）；部分治疗的或腔内治疗的感染，或上尿路的（重复的培养与影像[[clinical-skills/medical-imaging]]）；结石（计算机的断层[[#def-stones]]）；间质的肾炎（药物与嗜酸性的细胞[[renal/acute-kidney-injury]]、[[pharmacology/adverse-reactions]]）；肾小球的疾病（畸形的红细胞与管型及蛋白尿[[renal/filtration]]）；以及邻近的化脓的来源（阑尾炎与脓肿[[surgery/acute-abdomen]]）与囊肿/瘘[[obstetrics-gynaecology/menstrual-pelvic-disorders]]。实践：始终要送检尿的培养并询问治疗；而持续的无菌的脓尿需要上尿路和肾实质的影像[[clinical-skills/patient-safety]]。**
:::
:::

::: exercise 管理潴留 {level=2}
一位74岁在16小时无尿并疼痛的人，前列腺60克，肌酐220，服用三环类与膀胱的药：给出最初的48小时与三个月的计划。
::: solution
**一个由药物与前列腺共同造成急性的潴留（[[#def-prostate]]、[[renal/acute-kidney-injury]]）：减压（经尿道的导管与放空的规则；如果置管困难就上尿路的选择[[surgery/vascular-urological-surgery]]），带着后梗阻的利尿与钠钾及镁的监测[[renal/water-sodium]]与肌酐的轨迹[[renal/acute-kidney-injury]]；开始α阻滞剂；停用抗胆碱的负荷（三环与膀胱的药会触发潴留[[geriatrics-palliative/polypharmacy ]]）；并治疗便秘与感染。三个月：在七到十四天后试验的拔管（成功的机会在激素后更高）；如果失败就长期的导管或手术的（切除的激光与更大的腺体的选择[[surgery/vascular-urological-surgery ]]）；手术前后的药物审查（避免抗胆碱的处方）；以及如果肾功能不恢复就慢的肾的疾病评估[[renal/chronic-kidney-disease]]。**
:::
:::

::: exercise 解读前列腺特异的抗原 {level=2}
一位无症状的66岁在两年前开始5还原酶抑制剂的人前列腺特异的抗原为5.2：解读并给出现代的路径。
::: solution
**药物几乎会使数值减半：一个被报告的5.2在两年的治疗后大约相当于一个未治疗的人的10：不要把它当作安心，也绝不要把未经调整的参考范围应用于用药者[[#def-cancers]]、[[#def-prostate]]。步骤：确认依从性与时间（操作与射精和前列腺炎会升高值）；重复的测量与风险分层（密度的方法与比值及生物标记物的面板/磁共振的第一，在穿刺之前[[clinical-skills/medical-imaging ]]）；以及在持续的升高时经直肠超声引导的或靶向的穿刺[[pathology/cancer-diagnosis]]。筛查的谈话：获益与过度诊断（一个指南的预期寿命与共同决策[[medical-ethics-law/justice-resources]]、[[public-health/screening]]），以及被诊断为癌症的风险分层的管理（主动的监测对治疗[[surgery/vascular-urological-surgery ]]）。**
:::
:::

::: exercise 给这个肿块分类 {level=2}
一个4厘米的不均一的上极的肾的肿块被偶然发现；给出这个鉴别（四个）、影像的细化，以及包括年龄与合并症的调节的管理的选项。
::: solution
**鉴别：肾细胞（透明细胞的最常见的）；血管平滑肌的脂肪瘤（脂肪的密度是有诊断性的[[clinical-skills/medical-imaging]]、[[genetics/mendelian-inheritance]]的结节性硬化症）；囊肿（复杂的：分类）；以及少见的（淋巴瘤与转移和脓肿[[blood/leukaemia]]、[[renal/acute-kidney-injury]]）。影像：增强方案分期的特征（皮质时期的强化与排泄期的收集系统的侵犯；静脉的血栓[[surgery/vascular-urological-surgery]]、[[cardiovascular/vascular-disease]]）。选项：一个部分的肾切除优先在T1)；根切的肾切除在大的/中央的；消融在小的肿物与这些不适合手术者中；主动监测在小的病灶与有限寿命者中；以及转移的（细胞减灭的与免疫的和靶向的组合[[immunology/vaccines-immunotherapy]]、[[pathology/cancer-diagnosis]]）。调节：年龄与合并症及孤立的肾和家族的综合征（年轻的患者）；穿刺（在消融/监测或怀疑的淋巴瘤/转移中，而不是在切除前常规）。**
:::

::: exercise 预防复发 {level=2}
一个有他的第三次结石的30岁的人（都是尿酸的，尿的酸碱度5.0，体重指数34，痛风在服用别嘌醇后 最近ly 自行停用）：设计预防并解释酸碱度的化学。
::: solution
**尿酸的结石在持续低（5.0以下）的尿的酸碱度与浓缩的中形成（未解离的尿酸会沉淀；肥胖与胰岛素抵抗会损害肾的氨的产生，这是经典的驱动[[endocrine/diabetes]]、[[renal/tubular-function]]、[[#def-stones]]）。治疗：液体的（大于2.5升的尿）、体重与代谢的（饮食：嘌呤的减少与碱）；把尿的酸碱度碱化到6.5到7.0（枸橼酸钾的剂量并监测碳酸氢盐[[renal/acid-base-disorders ]]）——这可以溶解结石；别嘌醇（尤其是高尿酸尿的）带依从性；以及钙的保护（避免草酸盐的策略）。监测：尿的酸碱度的条与24小时的重复和影像。为什么尿酸的结石重要：它们是可溶解的——唯一的不需要外科的结石[[surgery/vascular-urological-surgery]]。**
:::
:::

::: exercise 建设尿路脓毒症的路径 {level=3}
设计一个从急诊的尿路脓毒症到结石预防门诊全天候的路径：识别、减压的时间、微生物学的接口，以及公平与预防的尾巴。
::: solution
**识别：发热的患者伴肋腹痛或尿路的操作/结石的历史会被旗标；急的乳酸与培养，以及在可疑的梗阻时的急的影像（超声或计算机的断层），带一个CT泌尿系的路径[[clinical-skills/medical-imaging]]、[[emergency-critical-care/acute-assessment]]。治疗：一小时内抗生素（当地的图谱与旅行的/导管的风险[[microbiology/antimicrobials]]）与复苏[[emergency-critical-care/shock-fluids]]；而感染结石=减压：一个写好时间的标准（在几小时内支架或造瘘的可用，全天候）与介入的放射和泌尿的共同待命[[surgery/vascular-urological-surgery]]、[[clinical-skills/patient-safety]]。微生物学的接口：被快速的药敏的降阶梯和被持续的疗程（[[infectious-diseases/stewardship-outbreaks]]）、耐药生物的的隔离[[microbiology/infection-control]]、以及反复的发作的病例的讨论。尾巴：结石的分析与24小时的在排出后（[[#ex-stone-prevention]]）与一个预防的门诊；复发感染的审查（影像与残留的结石和排空[[#def-prostate]]）；以及预防的教育（液体）[[public-health/prevention-promotion]]。公平：被延迟的转诊与夜间/周末的结果以及职业的驾驶与保险的障碍[[public-health/determinants-inequalities]]；审计：减压的延迟、抗生素的时间、入住重症的结石、以及复发。**
