酸碱的医学就是[[physiology/acid-base]]的缓冲化学临床的版本：**三道防线（在秒内起作用化学的缓冲，在分钟到小时内呼吸的代偿，以及在数天内的肾的纠正——[[renal/tubular-function]]）以及一个解读的纪律——系统的读酸碱度与二氧化碳和碳酸氢盐、阴离子与渗透的差距、尿的电解质以及临床的故事——会把一台血气的机器变成一个诊断。**本章走代谢的酸中毒（升高与正常的差距）、代谢的碱中毒、呼吸的紊乱，以及把合起来的混合的图形。

本章涵盖解读的方法、代谢酸中毒的两种类别与代谢的碱中毒、呼吸的紊乱与混合的图形。

## 解读

::: definition 防线与解读的方法 {#def-method}
**读气的这六步：（1）酸血症还是碱血症——酸碱度的方向（7.35到7.45是边界；一个正常酸碱度不意味着正常，因为紊乱可能相互抵消[[#ex-deltadelta ]]）；(2原发——碳酸氢盐（代谢的）或二氧化碳（呼吸的），与酸碱度的方向一致；30分钟规则：代谢的紊乱会立刻开始被呼吸补偿，而呼吸的在数天内需要肾的反应[[renal/tubular-function]]；(3代谢阴离子的差距（钠减去氯和碳酸氢盐，约8到16；白蛋白的校正：在白蛋白每低于40的10克加约2.5[[clinical-skills/laboratory-tests]]）；(4为碳酸氢盐被预期的代偿检查（代谢酸中毒中的Winters的公式：二氧化碳约等于1.5乘碳酸氢盐加8；代谢的碱中毒：每1的碳酸氢盐上升二氧化碳上升约0.7)；以及呼吸的规则（急的与慢的：在慢的呼吸性酸中毒中每10的二氧化碳上升碳酸氢盐约上升3.5[[respiratory/respiratory-failure ]]）；(5）如果阴离子的差距升高，差值的比率（阴离子差距的超出除以正常的碳酸氢盐减去被测量的碳酸氢盐）会筛查出混合代谢的紊乱（比率约1提示一个单纯高差距的酸中毒，大于2提示一个并存的代谢的碱中毒，小于1提示一个正常差距的成分[[#ex-deltadelta ]]）；(6在怀疑醇时渗透的差距（被计算的渗透减去被测量的；醇与酮和甘露醇会扩大它[[#ex-methanol ]]）。尿的检查（在正常差距的酸中毒中）：尿的阴离子的差距（钠加钾减氯；负的意味着铵排出良好，胃肠的损失；正的意味着这个肾无法酸化——远端肾小管的酸中毒[[renal/tubular-function]]）与渗透的差距（铵的替代）。临床的对应：呼吸的模式（深的大口的呼吸与中枢的潮式）与状态的改变和容量；以及轨迹重于一个单一的数字[[emergency-critical-care/acute-assessment]]。**
:::

## 代谢的紊乱

::: definition 阴离子差距升高代谢的酸中毒 {#def-aga}
**一个升高阴离子的差距意味着未测量的酸（有机的：酮和乳酸以及外源的毒素）在积累，而碳酸氢盐在缓冲它们。原因的清单：酮症（糖尿病与酒精和饥饿[[endocrine/diabetes-complications ]]）、乳酸（类型的A的低灌注与类型的B的药物和疾病）、肾的衰竭（硫酸盐与磷酸盐的潴留[[renal/chronic-kidney-disease ]]）、以及中毒（醇与乙二醇和水杨酸盐及副醛；焦谷氨酸的在慢性对乙酰氨基酚和营养不良中[[emergency-critical-care/poisoning]]）。方法：血糖与酮、乳酸（样本的规则：压迫与停留会假性升高它）和肾的功能、渗透的差距与水杨酸盐的测定[[#ex-methanol]]、[[#ex-aspirin]]；以及临床的背景（休克与癫痫发作和药物）。治疗就是这个来源：酮症用液体与胰岛素[[endocrine/diabetes-complications]]；乳酸通过恢复灌注（这个脓毒症的集束[[infectious-diseases/fever-sepsis]]、出血[[blood/haemostasis-bleeding]]、心源性[[cardiovascular/heart-failure]]）和移除药物（双胍与线粒体的毒素）；中毒用解毒剂（乙醇的竞争与抗解毒的）与透析，加上碳酸氢盐在选择性的病例中（肾的丢失的酸与水杨酸盐的碱化；以及高钾的酸中毒[[renal/potassium-calcium-phosphate ]]）。警告：碳酸氢盐不会在乳酸与酮症中被常规给予（它们会代谢回碳酸氢盐，而酸毒症会突然反转[[renal/acute-kidney-injury]]）；而一个在恢复中的图形会转向碱中毒，因为酸被清除。**
:::

::: definition 正常的差距（高氯的）代谢的酸中毒 {#def-naga}
**在这里，碳酸氢盐被丢失或被酸替换而氯会跟随：阴离子的差距正常，而尿的检查会做诊断。胃肠的丢失（腹泻与胰液的引流和尿肠的吻合：碳酸氢盐被排出而铵保持完整，所以尿阴离子的差距为负[[#ex-vomiting]]的镜像）；肾小管的酸中毒远端的一型：氢的泵的缺陷带一个无法被酸化的尿（酸碱度高于5.5)、低钾与结石[[renal/tubular-function]]、[[renal/urinary-tract]]；近端的二型：碳酸氢盐的阈值泄漏，与范科尼的图形关联[[renal/tubular-function]]；四型（高钾的）：矿皮质激素的抵抗缺陷，药物（钾的节约的利尿剂与转换酶的阻断剂及非甾体）与肾病的疾病[[renal/potassium-calcium-phosphate]]、[[endocrine/adrenal ]]）；以及外源的酸（氯化铵与阳离子交换的树脂、静脉的营养、水杨酸盐的早期阶段）和早期的肾的衰竭（铵的生成减少[[renal/chronic-kidney-disease ]]）。治疗：纠正钾（会同时改善酸中毒与结石的风险）、碱（碳酸氢盐或柠檬酸盐的混合物；远端的需要大剂量）、以及原因（腹泻的病原，药物被移除，以及矿皮质激素的状态[[endocrine/adrenal ]]）。警告：一个正常差距的酸中毒在腹泻中会伴有低钾，而在肾小管的酸中毒中会伴有钾的异常——而尿的阴离子的差距会在模糊的病例中把胃肠的丢失与肾的分开。**
:::

::: definition 代谢的碱中毒 {#def-ma}
**代谢的碱中毒就是碳酸氢盐被保留或被酸丢失，而尿的氯会把原因分成两族：氯反应性（尿的氯低于20： 呕吐或鼻胃的吸引（氢与氯的丢失以及随后的容量的收缩把碳酸氢盐保住[[#ex-vomiting]]）、利尿剂的后效应、后高碳酸血症的状态、以及囊性的纤维化）与氯抵抗的（尿的氯高：矿皮质激素的过多与钾的缺乏及严重的低镁、碱的负荷）[[renal/potassium-calcium-phosphate]]、[[endocrine/adrenal]]、[[renal/tubular-function]]。维持的机制比起始的更重要：容量的收缩（一个钠饥渴的肾会保住钠而不伴随的碳酸氢盐的排出）、低钾（细胞的转移与闰细胞的适应性会增加酸的和碳酸氢盐重吸收）、以及氯的缺乏（一个氯缺乏的肾无法把碳酸氢盐排掉，因为顶膜的氯化物与碳酸氢盐的交换器无法工作[[renal/tubular-function]]）——所以治疗就是盐水与钾与氯（一个氯反应性）、以及原因（矿皮质激素的缺陷被治疗；利尿剂被调整）。危险的程度：碱中毒会左移解离的曲线（组织的缺氧）、会把钙和钾及磷酸盐降低（抽搐与心律失常[[renal/potassium-calcium-phosphate]]）、并会抑制呼吸（在慢性阻塞肺病中危险呼吸的驱动[[respiratory/asthma-copd]]）。严重的（高于7.6）或有症状的病例：氯化钾与盐水和碳酸酐酶的抑制剂在某些病例中，或透析对有肾的衰竭者[[renal/chronic-kidney-disease]]；而在一个有鼻胃吸引的患者中，把吸引停止才是治疗。**
:::

::: example 呕吐的解读 {#ex-vomiting}
一位有长期的人为的呕吐的28岁的人酸碱度为7.52，碳酸氢盐为34，钾为2.8，氯为84，钠为136；尿的氯低于10；血压低。
::: solution
**一个低钾低氯代谢的碱中毒（[[#def-ma]]），尿的氯证实了氯反应性：氢与氯的丢失（呕吐）以及随后由容量的收缩（醛固酮）与低钾（转移与肾的适应性）维持的碳酸氢盐重吸收，而氯的缺乏使碳酸氢盐的排出不可能[[renal/tubular-function]]。这鉴别在尿的氯：低于20就是胃肠的丢失或利尿剂的后效应；高就是矿皮质激素的状态[[endocrine/adrenal]]。治疗按次序：氯化钾（先镁，因为它会决定钾是否能被保留[[renal/potassium-calcium-phosphate]]、[[renal/potassium-calcium-phosphate]]），然后盐水以恢复容量并关闭激素；停止吸引；以及这个行为的原因的治疗，带着进食的障碍的服务（[[psychiatry/eating-personality-disorders]]）——因为不处理它们，这个碱中毒就会回来。警告：快速的纠正会把钾移动并会诱发低钙的症状；以及在有长期碱中毒的患者中避免把二氧化碳降低得太快[[emergency-critical-care/critical-care]]。**
:::
:::

::: example 差值对差值 {#ex-deltadelta}
脓毒症患者的酸碱度为7.18，碳酸氢盐为8，二氧化碳为20，钠为140，氯为96，而乳酸为6。判断紊乱并检查代偿。
::: solution
**算术：阴离子的差距等于140减（96加8）等于36（升高）；被预期的二氧化碳（Winter的公式）等于1.5乘8加8约20——被测量为20：呼吸的代偿是恰当的[[#def-method]]。然后差值：阴离子差距的超出约2036减16)，而碳酸氢盐的缺失为1624减8)；比率约1.25：一个占主导高阴离子差距的酸中毒（乳酸），并有一个轻正常差距的成分（比率低于1会提示更多；这里腹泻与肾的碳酸氢盐的损失[[#def-naga]]都要被考虑）。如果这个比率为2以上，我们会说出一个并存的代谢的碱中毒（呕吐[[#ex-vomiting]]）。关键：被治疗的休克期间乳酸会消退，图形会转向一个代谢的碱中毒，加上输入的柠檬酸盐（[[renal/acute-kidney-injury]]、[[blood/transfusion]]）——所以要重新检查而不是被最初的数字安慰[[emergency-critical-care/critical-care]]。**
:::

::: example 渗透差距的迁移 {#ex-methanol}
一个有饮酒历史的人带着意识混乱和视觉的主诉被带来；酸碱度为6.9，碳酸氢盐为4，阴离子的差距为34，而被测量的渗透为340对照被计算的288；乙醇的测定为阴性。
::: solution
**一个被升高的渗透的差距伴随一个重度高阴离子差距的酸中毒：这是有毒的醇（甲醇会生成甲酸与视神经的损害[[#def-aga]]；乙二醇会生成草酸盐的结晶与肾的衰竭[[renal/acute-kidney-injury]]；异丙醇会生成酮而没有酸中毒）（[[emergency-critical-care/poisoning]]、[[emergency-critical-care/critical-care]]）。算术的教益：母体的醇会被代谢成酸，所以在早期渗透的差距会大而阴离子的会小；而现在这个差距会下降（母体已被清除），而阴离子的差距会主导：同一个的中毒在小时中迁移。紧急的治疗：静脉乙醇的负荷或抑制剂（会阻断代谢的酶）；碳酸氢盐（甲酸的离子捕获与眼的担忧）；以及透析（会同时移除母体与酸：一个紧急的指征[[renal/chronic-kidney-disease]]）；加上叶酸（甲酸盐的清除）与眼的评估和重症的照护[[emergency-critical-care/critical-care]]。报告的陷阱：被计算的渗透的公式与实验室的差异（在解释一个差距之前建立你们实验室正常的范围[[clinical-skills/laboratory-tests ]]）。**
:::
:::

::: example 两个紊乱，一瓶药片 {#ex-aspirin}
一个摄入后的45岁的人呼吸快；酸碱度为7.50，二氧化碳为19，碳酸氢盐为15，钠为142，氯为104，而乳酸为2；随后在数小时内酸碱度变为7.20。
::: solution
**一个早期混合的图形：水杨酸盐会直接刺激呼吸的中枢（一个呼吸的碱中毒）并同时产生一个高阴离子差距的酸中毒（解偶联的代谢产物与乳酸和酮）：这里碱中毒主导（酸碱度7.50，碳酸氢盐为15的代谢的酸中毒被二氧化碳19过度补偿）[[#def-method]]、[[#def-aga]]、[[emergency-critical-care/poisoning]]。随后的酸血症是经典的迁移（储备被耗尽与酸积累）并标志着严重的毒性：治疗就是碳酸氢盐（会把钾给足）以把水杨酸盐碱化（离子的捕获会把肾的清除提高数倍，而血的酸碱度不会升得太高）、钾（会不可避免被丢失[[renal/potassium-calcium-phosphate]]）、剂量与浓度的系列和重复的剂量碳（长的胃肠的效应）、以及早期的透析的咨询在重的病例中（水杨酸盐可被透析[[renal/chronic-kidney-disease]]）。不要把过度通气的患者仅仅当作焦虑：气体会分岔[[respiratory/respiratory-failure]]。**
:::

::: history
**方程（1908到1916）与酸碱度的标度和开放系统碳酸氢盐的语言，以及体液的图谱（1937）奠定了算术；然后是肾的铵的捕获的生理（四与五十年代的氨的研究与1959年的远端肾小管酸中毒的特征）；以及粪的化学与儿科的脱水的血统（[[paediatrics/acute-childhood-illness]]）；乳酸的分类（A对B的区别，1976）与阴离子的差距进入临床的算法；有毒的醇的代谢与解毒的阻断的治疗；以及糖尿病酮症酸中毒护理的试验，包括儿童脑水肿的规则（[[endocrine/diabetes-complications]]与[[paediatrics/acute-childhood-illness ]]）。本章就是一场化学向床边算术的转化：一条防线接一条防线的读法，被公式来使代偿的失败变得可见。**
:::

## 通向何处

缓冲的化学在[[physiology/acid-base]]；肾小管的效应在[[renal/tubular-function]]；钾的交换在[[renal/potassium-calcium-phosphate]]；通气的代偿在[[respiratory/control-breathing-tests]]，而它的失败在[[respiratory/respiratory-failure]]；乳酸与休克的那个世界在[[emergency-critical-care/shock-fluids]]与[[emergency-critical-care/resuscitation]]；中毒在[[emergency-critical-care/poisoning]]；糖尿病的酮症酸中毒在[[endocrine/diabetes-complications]]；而液体的试验在[[surgery/perioperative-care]]。

::: exercise 四个快速的解读 {level=2}
为每一个分类（单一或混合）：(a) 酸碱度7.32，二氧化碳20，碳酸氢盐10；(b) 酸碱度7.48，二氧化碳28，碳酸氢盐21；(c) 酸碱度7.35，二氧化碳60，碳酸氢盐32；(d) 酸碱度7.02，二氧化碳46，碳酸氢盐8。
::: solution
**（a）代谢的酸中毒带着恰当的代偿（Winter：1.5乘10加8等于23，正负2——20在这个边界：可接受，或一个额外呼吸碱中毒的低语——脓毒症与疼痛的检查）；（b）急的呼吸性的碱中毒（每10下降2的规则：二氧化碳28会预期碳酸氢盐约21到22——纯的）；（c）慢的呼吸性酸中毒代偿的图形（慢性阻塞肺病的潴留者：每10上升3到4会得到约32——恰当的，不是碱中毒[[respiratory/asthma-copd]]）；（d）代谢的酸中毒带一个不当的高的二氧化碳（Winter预期的约20，而实际46：一个叠加呼吸性的酸中毒——疲劳或被镇静的患者——需要现在插管的气体[[respiratory/respiratory-failure]]、[[emergency-critical-care/acute-assessment]]）——这就是代偿的公式的四行的算术。**
:::

::: summary
- 按一个固定的次序读气：酸碱度，然后原发紊乱，然后代偿的算术，然后阴离子的差距（白蛋白的校正），然后差值的比率，然后渗透的差距，然后尿的探针，然后临床的故事；一个正常的酸碱度带着异常的成分是混合的紊乱，不是正常的结果。
- 升高差距的酸中毒就是乳酸（A/B）与酮及尿毒症和有毒的醇、水杨酸盐与焦谷氨酸的搜寻；这个原因就是酸，而匹配通气会保护代偿。
- 正常差距的酸中毒用尿阴离子的与渗透的差距把肠与肾分开；肾小管酸中毒的亚型与四型的生理就是这一章自己的这份清单。
- 代谢的碱中毒被氯与容量及钾的损失所产生，并被肾的氯的耗竭所维持；尿的氯就是这个分岔，而盐水加钾加氯就是治愈。
- 有毒的醇会把它们的差距从渗透的迁移到阴离子的；而水杨酸盐会在一个接近正常的酸碱度之后把碱中毒与差距的酸中毒混合——两者都会通过气道与通气的决定造成死亡。
:::

## 练习

::: exercise 做算术 {level=1}
钠140，氯110，碳酸氢盐14，白蛋白40：计算这个阴离子的差距并分类；再加上被预期的二氧化碳。
::: solution
**阴离子的差距等于140减（110加14）等于16——在这个白蛋白顶部处的边界；分类：一个正常差距（高氯的）的代谢的酸中毒[[#def-naga]]（盐水的负荷与胃肠的丢失及肾的丢失都在此列）。被预期的二氧化碳（Winter）等于1.5乘14加8等于约29，正负2：一个高于这个的测量的二氧化碳会加上一个呼吸性的酸中毒，而一个更低的会加上一个呼吸性的碱中毒[[#def-method]]。提醒：白蛋白低患者的被校正的差距会把一个隐藏高差距的酸中毒揭露出来（[[#def-aga]]），而一个混合的图形（腹泻伴盐水）会同时给出两种的特征。**
:::
:::

::: exercise 命名紊乱 {level=1}
酸碱度7.20，二氧化碳75，碳酸氢盐28，在一个停搏到达的气体上：急的还是慢的呼吸性的酸中毒，以及被预期的碳酸氢盐是什么？
::: solution
**急的：每10毫米汞柱二氧化碳的上升会把碳酸氢盐升高约1（急的），而从基线40二氧化碳上升35会给出约24加3.5等于27.5：被测量的28符合一个纯粹急呼吸性的酸中毒（停搏的通气[[emergency-critical-care/resuscitation ]]）。一个慢的会需要每10上升3.5到4（约36到38）并要求潴留的疾病[[respiratory/asthma-copd]]、[[respiratory/respiratory-failure]]。含义：这个治疗就是通气，而不是碱；以及在恢复自主的通气后，被潴留的二氧化碳会被快速排出——所以要监测碱中毒[[#def-ma]]。**
:::
:::

::: exercise 设定呼吸机 {level=2}
一个严重慢肾疾病的患者（碳酸氢盐10，酸碱度7.25，自主呼吸时二氧化碳22）因疲劳而被插管；呼吸机被设定在频率12与潮气量450毫升。预测一小时后的气体与这一教学。
::: solution
**二氧化碳会被分钟通气量设定：从一个被代偿的22到一个正常的分钟通气量的设置，二氧化碳会升到约40，把一个代偿性的酸血症变成一个重度的酸血症（酸碱度会降到约7.05）[[#def-method]]、[[respiratory/respiratory-failure]]。数字：碳酸氢盐10与二氧化碳40：比值10对1.2会给出约7.02。这一教学：代谢酸中毒的患者需要被匹配的分钟通气量（更快的频率和更大的潮气量，在小的限制之内），并在开始镇静之前考虑插管的必要；以及在碳酸氢盐的补充上讨论[[renal/chronic-kidney-disease]]。后续的：不要把设置当作正常的数字——它们是处方[[emergency-critical-care/critical-care]]。**
:::
:::

::: exercise 解读尿的电解质 {level=2}
一个酸中毒的患者：尿的钠30，钾55，氯20。计算尿阴离子的差距并解读；然后给出渗透差距的告诫。
::: solution
**尿的阴离子的差距等于30加55减20等于正的65：一个不能把铵排出足够的肾（远端与四型的肾小管的酸中毒，或肾的功能受损）[[#def-naga]]、[[renal/tubular-function]]；一个胃肠的丢失会给出一个负的差距。告诫：差距只有在把渗透的（铵的伴随的氯化物与碳酸氢盐会改变离子）与钾的高时才有用，在低的尿的钠时不可靠，并在碳酸氢盐尿中会误导（在近端的丢失与碱治疗后）；尿的渗透的差距（被测量的减去被计算的）会估计铵，但需要尿量的条件[[clinical-skills/laboratory-tests]]。**
:::
:::

::: exercise 选择液体 {level=2}
一位术后的患者已接受8升的0.9%盐水，现在碳酸氢盐15，氯118差距13)，酸碱度7.26而尿量良好。解释并给出管理，带试验级别的论证。
::: solution
**一个高氯的、正常差距代谢的酸中毒由大量盐水的负荷造成（氯化物会稀释碳酸氢盐并酸化[[#def-naga]]、[[surgery/perioperative-care]]）：平衡的晶体（乳酸或醋酸的）会产生更少的酸中毒与更少的肾的损伤（大的试验的结果与它们的争论[[emergency-critical-care/shock-fluids]]、[[clinical-skills/laboratory-tests ]]）。管理：切换到平衡的溶液；停止额外的盐水；碳酸氢盐很少需要（如果这个肾有功能，氯化物会被排出）；监测钠与氯和尿量。教训：一个酸中毒不是一个损失的诊断——在大量输液后的图表常常就是医源性的[[clinical-skills/patient-safety]]。**
:::
:::

::: exercise 高碳酸血症的谜题 {level=2}
一个慢性阻塞肺病的患者（慢性的二氧化碳72，碳酸氢盐36）在术后被通气到二氧化碳40，而变成酸碱度7.55、钾2.8和低血压。解释并给出纠正的计划。
::: solution
**一个后高碳酸血症代谢的碱中毒：肾的碳酸氢盐会保持升高数天，而二氧化碳快速的正常化会暴露它们（[[#def-ma]]、[[respiratory/respiratory-failure]]）。后果：碱中毒会把钾移入细胞（低钾[[renal/potassium-calcium-phosphate]]）与钙离子降低，会左移解离的曲线并抑制呼吸（撤机的失败）并会造成低血压和心律失常。计划：把目标二氧化碳返回到慢性约65到70)；缓慢地在数天内把碳酸氢盐降下来；氯化钾（先镁）；以及允许高的二氧化碳的策略，因为碱中毒会消退[[emergency-critical-care/critical-care]]。预防：用慢性的数字设定通气，并在术后最初小时监测气体[[surgery/perioperative-care]]。**
:::
:::

::: exercise 设计酸碱安全的套 {level=3}
围绕气体的解读设计全院的培训与安全的程序：这些能力的目标、中毒与术后的路径，以及审计的集。
::: solution
**这些能力的目标：每一个住院医生都必须演示六步的解读（[[#def-method]]）与代偿的公式和差距的算术，带被评估的案例而不是讲座（[[clinical-skills/clinical-reasoning]]）；急的程序的演练（有毒的醇与水杨酸盐：解毒剂和透析的呼叫[[emergency-critical-care/poisoning]]、[[renal/chronic-kidney-disease ]]）。路径：一个酮症酸中毒的路径（钾与胰岛素和液体以及频率）[[endocrine/diabetes-complications]]；一个中毒的路径（测定的周转时间）；一个术后/重症的路径（液体平衡的晶体默认与对代谢的酸中毒的通气匹配的警告[[surgery/perioperative-care]]、[[emergency-critical-care/critical-care ]]）；以及一个腹泻/肾小管的路径（尿的检查[[#def-naga]]）。安全的规则：不要在一个未确定的图形上下碱的医嘱；在插管前为分钟通气量做计划；以及在高的差距时追踪乳酸的清除。审计：未识别的中毒与碳酸氢盐的误用、撤机延迟对碱中毒、酮症酸中毒低钾的事件、以及气体的解读的培训的效果。**
:::
