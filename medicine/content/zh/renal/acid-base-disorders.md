动脉血气是急症医学中最快速、信息量最大的检查之一。一分钟之内它就能显示患者是酸血症还是碱血症，是肺还是代谢导致的，再加上一点算术，还能显示是否隐藏着第二种紊乱。这些算术很重要。许多最重要的酸碱表现，如水杨酸中毒、伴呕吐的糖尿病酮症酸中毒或慢性肺病患者发生脓毒症，都同时涉及两三种紊乱，只有逐一核对每个数值与其应有数值的人才能看出来。

缓冲系统的生理学、pH的呼吸和肾脏调节以及Henderson–Hasselbalch方程的推导见[[physiology/acid-base]]。本课时将其应用于临床。它给出解读血气的方法，然后讨论四种原发性紊乱、阴离子间隙以及揭示混合性紊乱的其他计算，还有肾小管酸中毒。每一步都配有病例演示。

单位：英国实验室以kPa报告$P_{a}\text{CO}_2$；许多文献和代偿规则使用mmHg。换算关系为1 kPa = 7.5 mmHg。本课时两者并列给出。

## 方法

::: definition 正常值与原发性紊乱 {#def-method}
典型的动脉血参考范围为：**pH** 7.35～7.45；**$P_a\text{CO}_2$** 4.7～6.0 kPa（35～45 mmHg）；**碳酸氢根** 22～26 mmol/L。pH低于7.35为**酸血症**，高于7.45为**碱血症**。引起它们的过程分别是**酸中毒**和**碱中毒**。

四种原发性紊乱是：
- **代谢性酸中毒**：碳酸氢根原发性降低；
- **代谢性碱中毒**：碳酸氢根原发性升高；
- **呼吸性酸中毒**：$P_a\text{CO}_2$原发性升高（通气不足）；
- **呼吸性碱中毒**：$P_a\text{CO}_2$原发性降低（过度通气）。

**代偿**是另一变量的继发性改变，用以限制pH的变化：肺在数分钟到数小时内代偿代谢性紊乱，肾在三到五天内代偿呼吸性紊乱。代偿很少能使pH完全恢复正常。
:::

pH由碳酸氢根与$\text{CO}_2$之比决定：

$$
\text{pH} = 6.1 + \log_{10} \frac{[\text{HCO}_3^-]}{0.23 \times P_a\text{CO}_2\,(\text{kPa})}
$$ {#eq-hh}

（用mmHg时系数为0.03而不是0.23。）碳酸氢根由肾脏控制，$\text{CO}_2$由肺控制，所以pH是肾与肺之比。每一种紊乱改变比值的一方；代偿使另一方朝同一方向移动。

::: theorem 解读血气的五个步骤 {#thm-five-steps}
1. **看患者，看氧合。**是否存在低氧血症？血气要结合临床表现解读。
2. **是酸血症还是碱血症？**看pH。
3. **原发性紊乱是什么？**若$P_a\text{CO}_2$的变化方向能解释pH，原发性紊乱是呼吸性的；若碳酸氢根能解释，则是代谢性的。
4. **代偿是否恰当？**将另一变量与下述规则得出的预期值比较。超出预期范围意味着存在**第二种原发性紊乱**。
5. **任何代谢性酸中毒都要计算阴离子间隙**，用白蛋白校正；若间隙升高，比较间隙的升高与碳酸氢根的降低（delta比值）。若可能为有毒醇类中毒，考虑渗透压间隙。
:::

预期代偿规则是经验性的，来自只有单一紊乱的人群。

| 原发性紊乱 | 预期代偿 |
|---|---|
| 代谢性酸中毒 | $P_a\text{CO}_2$（mmHg）$= 1.5 \times [\text{HCO}_3^-] + 8 \pm 2$（Winter公式）；以kPa表示约为$0.2 \times [\text{HCO}_3^-] + 1.1 \pm 0.3$ |
| 代谢性碱中毒 | 碳酸氢根每升高1 mmol/L，$P_a\text{CO}_2$约升高0.7 mmHg，很少超过约55～60 mmHg（7.3～8 kPa） |
| 急性呼吸性酸中毒 | $P_a\text{CO}_2$每升高10 mmHg（1.3 kPa），碳酸氢根约升高1 mmol/L |
| 慢性呼吸性酸中毒 | $P_a\text{CO}_2$每升高10 mmHg，碳酸氢根约升高3.5 mmol/L |
| 急性呼吸性碱中毒 | $P_a\text{CO}_2$每降低10 mmHg，碳酸氢根约降低2 mmol/L |
| 慢性呼吸性碱中毒 | $P_a\text{CO}_2$每降低10 mmHg，碳酸氢根约降低4～5 mmol/L |

::: proof
这些规则反映了每种防御的时间尺度和机制。急性呼吸性紊乱时只有化学缓冲可用：$\text{CO}_2$水合成碳酸，非碳酸氢盐缓冲系统（主要是血红蛋白和蛋白质）接受氢离子，生成少量碳酸氢根。因此变化很小，约每10 mmHg 1 mmol/L。几天之后，肾脏加入自身的反应：呼吸性酸中毒时以铵的形式增加排酸并生成新的碳酸氢根，呼吸性碱中毒时减少碳酸氢根重吸收。因此慢性变化更大。代谢性酸中毒时，外周和中枢化学感受器感知低pH，在数分钟内增加通气，形成Winter线性关系。代谢性碱中毒时通气反应很弱，因为通气不足会引起低氧血症，而低氧血症本身又驱动通气，所以代偿有限。
:::

## 代谢性酸中毒

**阴离子间隙**是代谢性酸中毒分类的关键。血浆必须保持电中性。测得的阳离子（钠，有时加上钾）多于测得的阴离子（氯和碳酸氢根）；差额由未测定的阴离子补足，主要是白蛋白、磷酸根和硫酸根。

$$
\text{AG} = [\text{Na}^+] - ([\text{Cl}^-] + [\text{HCO}_3^-])
$$ {#eq-ag}

现代分析仪的典型参考范围约为8～12 mmol/L（较老的教科书为12 ± 4），但应使用各实验室自己的范围。向血浆中加入酸HA时，H⁺被碳酸氢根缓冲，A⁻作为未测定阴离子留下：碳酸氢根下降，间隙升高。碳酸氢根丢失而由氯替代时，间隙保持正常。

白蛋白是正常情况下主要的未测定阴离子，所以**低白蛋白血症会降低阴离子间隙**，并可能掩盖间隙升高。常用的校正方法是白蛋白每低于40 g/L 10 g/L，间隙加约2.5 mmol/L。

::: definition 高阴离子间隙代谢性酸中毒 {#def-aga}
**高阴离子间隙代谢性酸中毒**由阴离子不是氯离子的酸蓄积引起。主要病因为：

- **乳酸酸中毒**：A型由组织低灌注或缺氧引起（休克、脓毒症、心搏骤停、肠系膜缺血）；B型不伴低灌注（肝衰竭、二甲双胍蓄积、恶性肿瘤、某些药物）；
- **酮症酸中毒**：糖尿病性、酒精性和饥饿性；
- **肾衰竭**：硫酸根、磷酸根和有机阴离子潴留；
- **毒物**：甲醇（甲酸）、乙二醇（乙醇酸和草酸）、水杨酸，以及焦谷氨酸（5-氧脯氨酸），后者与营养不良或脓毒症者规律服用对乙酰氨基酚有关。
:::

::: definition 阴离子间隙正常（高氯性）代谢性酸中毒 {#def-naga}
**阴离子间隙正常的代谢性酸中毒**由**碳酸氢根丢失**或**肾脏排酸障碍**引起，氯升高以替代丢失的碳酸氢根。主要病因为：

- **胃肠道碳酸氢根丢失**：腹泻、高输出量回肠造口或瘘、输尿管改道入肠；
- **肾小管酸中毒**（RTA）；
- **碳酸酐酶抑制剂**（乙酰唑胺）；
- **大量0.9%盐水**，其含氯154 mmol/L而不含碳酸氢根。

**尿阴离子间隙**$[\text{Na}^+]_u + [\text{K}^+]_u - [\text{Cl}^-]_u$可估计尿铵。腹泻时肾脏大量排出铵（伴随氯），所以尿阴离子间隙为**负值**。远端RTA时铵排泄受损，间隙为**正值**。
:::

### 肾小管酸中毒

| 类型 | 缺陷 | 酸中毒时尿pH | 钾 | 典型病因 |
|---|---|---|---|---|
| 1型（远端） | 集合管不能分泌H⁺ | 总是高于5.5 | 低 | 干燥综合征、系统性红斑狼疮、两性霉素、遗传型；肾钙质沉着和结石常见 |
| 2型（近端） | 近端小管碳酸氢根重吸收减少 | 碳酸氢根低时可降至5.5以下 | 低 | 范科尼综合征（骨髓瘤、替诺福韦、胱氨酸病）、乙酰唑胺 |
| 4型（高钾性） | 醛固酮低或醛固酮抵抗 | 通常低于5.5 | 高 | 糖尿病肾病（低肾素性醛固酮减少症）、ACE抑制剂、血管紧张素受体阻滞剂、螺内酯、肾上腺皮质功能不全 |

4型是成人中最常见的类型。其酸中毒通常较轻，高钾血症是主要的临床问题。高钾血症本身减少近端小管的氨生成，从而加重酸中毒。

### delta比值

在单纯的高阴离子间隙酸中毒中，每多一个未测定阴离子，大致对应丢失一个碳酸氢根。比较这两种变化可以揭示隐藏的第二种紊乱。

$$
\text{delta 比值} = \frac{\Delta \text{AG}}{\Delta [\text{HCO}_3^-]} = \frac{\text{AG} - 12}{24 - [\text{HCO}_3^-]}
$$ {#eq-delta}

作为参考：低于0.4提示阴离子间隙正常的酸中毒；0.4～0.8提示高间隙与正常间隙酸中毒合并存在；1～2提示单纯的高阴离子间隙酸中毒（乳酸酸中毒倾向于1.6，因为部分乳酸离开血浆，部分H⁺由细胞缓冲；酮症酸中毒倾向于1，因为酮体从尿中丢失）；高于2提示合并**代谢性碱中毒**，或慢性呼吸性酸中毒导致的基础碳酸氢根偏高。这些是经验法则，不是精确的界值。

::: example 伴呕吐的酮症酸中毒 {#ex-deltadelta}
一名19岁1型糖尿病女性呕吐两天。结果：pH 7.32，$P_a\text{CO}_2$ 4.3 kPa（32 mmHg），碳酸氢根16 mmol/L，钠136，氯88 mmol/L，葡萄糖28 mmol/L，血酮5.8 mmol/L，白蛋白42 g/L。请解读。
::: solution
**第二步**：pH 7.32，酸血症。

**第三步**：碳酸氢根低，所以是代谢性酸中毒。

**第四步**：Winter公式：预期$P_a\text{CO}_2 = 1.5 \times 16 + 8 = 32 \pm 2$ mmHg。实测32 mmHg，代偿恰当。

**第五步**：AG $= 136 - (88 + 16) = 32$，升高。白蛋白正常。血酮5.8，这是**糖尿病酮症酸中毒**。

delta比值$= (32 - 12)/(24 - 16) = 20/8 = 2.5$。碳酸氢根下降远少于间隙升高。有什么增加了碳酸氢根：两天的**呕吐**（丢失胃酸HCl）引起了**代谢性碱中毒**。低氯支持这一点。

所以她有两种原发性紊乱：糖尿病酮症酸中毒和呕吐引起的代谢性碱中毒。接近正常的碳酸氢根掩盖了酮症酸中毒的严重程度；她的血酮水平和阴离子间隙才反映真实情况（[[endocrine/endocrine-emergencies]]）。
:::
:::

::: example 渗透压出现间隙的中毒 {#ex-methanol}
一名45岁男性被送来时嗜睡，主诉视物模糊。结果：pH 7.12，$P_a\text{CO}_2$ 2.9 kPa（22 mmHg），碳酸氢根7 mmol/L，钠140，氯101 mmol/L，葡萄糖5 mmol/L，尿素5 mmol/L，乳酸2.0 mmol/L，酮体阴性。实测血浆渗透压330 mOsm/kg。请解读。
::: solution
重度代谢性酸中毒。Winter公式：$1.5 \times 7 + 8 = 18.5 \pm 2$ mmHg；实测22 mmHg略高于预期，提示他开始疲劳或存在一定程度的呼吸抑制，这是危险的。

AG $= 140 - (101 + 7) = 32$，明显升高，乳酸和酮体都不能解释。

**渗透压间隙**：计算渗透压$= 2 \times 140 + 5 + 5 = 290$。实测330。间隙$= 40$ mOsm/kg（正常低于约10）。存在一种未测定的有渗透活性的物质。高阴离子间隙加高渗透压间隙以及视觉症状，提示**甲醇**中毒（甲酸损伤视神经）；乙二醇中毒表现相似，但伴肾损伤和尿中草酸钙结晶。

处理遵循毒理学建议（在英国为TOXBASE和国家毒物信息服务）：给予阻断乙醇脱氢酶的解毒剂（甲吡唑或乙醇），血液透析清除毒物及其代谢产物，纠正酸中毒，并给予叶酸或亚叶酸（[[emergency-critical-care/poisoning]]）。注意，随着醇被代谢为酸，渗透压间隙会下降，所以就诊较晚时可表现为高阴离子间隙而渗透压间隙正常。
:::
:::

## 代谢性碱中毒

::: definition 代谢性碱中毒 {#def-ma}
**代谢性碱中毒**是碳酸氢根原发性升高。需要两个条件：一个**产生**碳酸氢根的过程（从胃或尿中丢失酸，或获得碱），和一个**维持**它的过程，使肾脏不能排出多余的碳酸氢根。通常的维持因素是容量不足、氯缺乏、低钾血症和盐皮质激素过多。

按尿氯分类：
- **氯反应性**（尿氯低于约20 mmol/L）：呕吐、鼻胃管引流、停用利尿药后、慢性高碳酸血症纠正后；给予氯化钠和氯化钾可纠正；
- **氯抵抗性**（尿氯高于约40 mmol/L）：正在使用利尿药、盐皮质激素过多（原发性醛固酮增多症、库欣综合征、甘草）、Bartter和Gitelman综合征、重度低钾血症。
:::

::: example 幽门梗阻引起的呕吐 {#ex-vomiting}
一名68岁胃癌男性一周来每餐后都呕吐。结果：pH 7.53，$P_a\text{CO}_2$ 6.5 kPa（49 mmHg），碳酸氢根39 mmol/L，钠134，氯82，钾2.8 mmol/L，尿素14 mmol/L，尿氯8 mmol/L，尿pH 5.5。请解读。
::: solution
碱血症伴碳酸氢根升高：**代谢性碱中毒**。预期$P_a\text{CO}_2 = 40 + 0.7 \times (39 - 24) = 50.5$ mmHg，实测49：呼吸代偿恰当。

**产生**：呕吐从胃中丢失HCl。壁细胞每分泌一个H⁺，就有一个碳酸氢根进入血液。

**维持**：容量和氯缺乏（尿氯8）使肾脏在近端小管随碳酸氢根一起强烈重吸收钠；醛固酮（因容量丢失而升高）增加远端H⁺和钾的分泌。结果是经典的**反常性酸性尿**：尽管全身碱中毒，尿液却是酸性的，因为肾脏优先保容量和保钾。

**治疗**：遵循当地指南给予0.9%盐水加氯化钾。有了氯和容量，肾脏就能排出多余的碳酸氢根，碱中毒得到纠正。梗阻本身需要外科或内镜处理。
:::
:::

## 呼吸性紊乱

::: definition 呼吸性酸中毒与呼吸性碱中毒 {#def-resp}
**呼吸性酸中毒**由肺泡通气不足引起：呼吸驱动受抑制（阿片类、镇静剂、脑损伤）、神经肌肉无力（吉兰-巴雷综合征、重症肌无力、运动神经元病）、胸壁疾病（重度脊柱后侧凸、肥胖低通气）或肺部疾病（慢阻肺、重症哮喘患者疲劳时）。**急性**呼吸性酸中毒碳酸氢根升高很少；**慢性**呼吸性酸中毒因肾脏代偿而升高较多。

**呼吸性碱中毒**由过度通气引起：焦虑和疼痛、低氧血症（肺炎、肺栓塞、高原）、脓毒症、肝衰竭、妊娠（孕酮刺激通气）、水杨酸中毒和中枢神经系统疾病。
:::

一个有用的模式是**慢性基础上的急性**呼吸性酸中毒：一名慢阻肺患者原有稳定的高$P_a\text{CO}_2$和相应升高的碳酸氢根，发生胸部感染后$P_a\text{CO}_2$进一步升高，碳酸氢根来不及同步升高，pH下降。另一个是**高碳酸血症后碱中毒**：慢性$\text{CO}_2$潴留者接受机械通气、$P_a\text{CO}_2$被迅速降低时，代偿性升高的碳酸氢根仍然存在，出现代谢性碱中毒。缓慢降低$P_a\text{CO}_2$并补充氯可以避免。

::: example 一瓶药引起两种紊乱 {#ex-aspirin}
一名23岁女性数小时前服用了大量阿司匹林片。她有耳鸣、恶心，呼吸急促。结果：pH 7.46，$P_a\text{CO}_2$ 3.2 kPa（24 mmHg），碳酸氢根16 mmol/L，钠140，氯102 mmol/L。请解读。
::: solution
pH轻度碱血症。$P_a\text{CO}_2$低，碳酸氢根低。

若原发性紊乱是代谢性酸中毒，Winter公式预测$1.5 \times 16 + 8 = 32 \pm 2$ mmHg。实测24 mmHg远低于此：还存在**呼吸性碱中毒**。AG $= 140 - (102 + 16) = 22$，升高：存在**高阴离子间隙代谢性酸中毒**。

这是典型的水杨酸中毒表现。水杨酸直接刺激呼吸中枢（呼吸性碱中毒，常为最早的改变），并使氧化磷酸化解偶联，导致乳酸和酮酸蓄积（代谢性酸中毒）。成人中二者常同时存在，使pH接近正常或呈碱血症。

危险信号是pH下降。酸血症使更多水杨酸（一种弱酸）保持非离子化状态并进入脑内。若她变得嗜睡或需要气管插管，机械通气必须保持$P_a\text{CO}_2$低，因为$\text{CO}_2$升高会加重酸血症并驱使水杨酸进入脑内。处理遵循毒理学指南：适当时给予活性炭，静脉给予碳酸氢钠碱化尿液（将离子化的水杨酸“困”在尿中），补钾，重度中毒时血液透析（[[emergency-critical-care/poisoning]]）。
:::
:::

::: warning pH正常可能掩盖两种严重紊乱 {#warn-normal-ph}
pH正常并不意味着酸碱状态正常。两种原发性紊乱使pH朝相反方向变化时，pH可以处于正常范围，而碳酸氢根和$P_a\text{CO}_2$都严重异常。例如水杨酸中毒（代谢性酸中毒加呼吸性碱中毒）以及伴呕吐的酮症酸中毒（代谢性酸中毒加代谢性碱中毒）。即使pH为7.40，也要始终核对代偿和阴离子间隙。同样，低白蛋白者的阴离子间隙正常可能掩盖了间隙升高；应予校正。
:::

::: quiz
一名72岁慢阻肺男性在病情稳定时的结果为：pH 7.37，$P_a\text{CO}_2$ 8.0 kPa（60 mmHg），碳酸氢根33 mmol/L。哪种描述最合适？
- [ ] 急性呼吸性酸中毒
- [x] 慢性呼吸性酸中毒伴恰当的肾脏代偿
- [ ] 代谢性碱中毒伴呼吸代偿
- [ ] 呼吸性酸中毒合并代谢性酸中毒
::: solution
$P_a\text{CO}_2$比正常高20 mmHg。慢性呼吸性酸中毒时碳酸氢根应每10 mmHg升高约3.5 mmol/L，即升高约7 mmol/L，达到约31。他的33接近这一数值，pH几乎正常：**慢性呼吸性酸中毒伴恰当的肾脏代偿**。同样幅度的急性升高只会使碳酸氢根增加约2 mmol/L，pH降至约7.26。原发性代谢性碱中毒会使pH呈碱血症，而且60 mmHg的$P_a\text{CO}_2$已处于代偿极限。
:::
:::

::: history
1908年，美国生物化学家亨德森（Lawrence Henderson）描述了碳酸和碳酸氢根如何缓冲血液；1916年，丹麦医生哈塞尔巴尔赫（Karl Albert Hasselbalch）用当时新出现的pH记法把亨德森方程改写为对数形式。临床酸碱分析是在一场危机中成长起来的。1952年哥本哈根脊髓灰质炎流行期间，许多呼吸麻痹患者血浆碳酸氢根升高，最初被解读为代谢性碱中毒。麻醉医生伊布森（Bjørn Ibsen）认为这反映的是$\text{CO}_2$潴留，检验科医生阿斯楚普（Poul Astrup）则开发了在床旁测定pH和$P_a\text{CO}_2$的方法。伊布森采用气管切开和人工正压通气（由医学生轮流连续数周进行），使死亡率大幅下降，并为重症医学的创立作出了贡献。
:::

## 后续内容

急性肾损伤中的酸中毒以及因酸中毒开始透析的决定见[[renal/acute-kidney-injury]]。慢性肾脏病的慢性代谢性酸中毒及其口服碳酸氢盐治疗见[[renal/chronic-kidney-disease]]。糖尿病酮症酸中毒见[[endocrine/endocrine-emergencies]]，呼吸衰竭见[[respiratory/respiratory-failure]]，各种中毒见[[emergency-critical-care/poisoning]]。

::: summary
- 正常值：pH 7.35～7.45，$P_a\text{CO}_2$ 4.7～6.0 kPa（35～45 mmHg），碳酸氢根22～26 mmol/L。pH取决于碳酸氢根（肾）与$\text{CO}_2$（肺）之比。
- 分五步解读血气：患者与氧合；pH；原发性紊乱；预期代偿；阴离子间隙和delta比值（必要时加渗透压间隙）。
- Winter公式：预期$P_a\text{CO}_2$（mmHg）$= 1.5 \times \text{HCO}_3^- + 8 \pm 2$。代偿超出预期范围意味着存在第二种紊乱。
- 阴离子间隙$= \text{Na}^+ - (\text{Cl}^- + \text{HCO}_3^-)$；白蛋白低时校正（白蛋白每低于40 g/L 10 g/L加2.5）。间隙升高：乳酸、酮体、肾衰竭、毒物。间隙正常：腹泻、RTA、盐水、乙酰唑胺。
- delta比值（ΔAG/ΔHCO₃⁻）可揭示隐藏的代谢性碱中毒（高于2）或合并的正常间隙酸中毒（低于1）。
- 渗透压间隙升高加阴离子间隙升高提示甲醇或乙二醇中毒。
- 代谢性碱中毒需要产生和维持两个环节；尿氯区分氯反应性与氯抵抗性病因。
- pH正常可能掩盖两种相反的紊乱。
:::

## 习题

::: exercise 阴离子间隙 {level=1 check="138-(110+14)"}
计算以下结果的阴离子间隙：钠138，氯110，碳酸氢根14 mmol/L。这是高阴离子间隙还是正常阴离子间隙酸中毒？给出两个可能的病因。
::: solution
AG $= 138 - (110 + 14) = 14$ mmol/L，处于或刚刚高于典型现代参考范围的上限：基本上是**阴离子间隙正常（高氯性）酸中毒**，氯替代了碳酸氢根。病因包括腹泻、肾小管酸中毒、大量0.9%盐水和乙酰唑胺。尿阴离子间隙有助于区分胃肠道与肾脏病因。
:::
:::

::: exercise Winter公式 {level=1 check="1.5*12+8"}
一名代谢性酸中毒患者碳酸氢根12 mmol/L。计算预期$P_a\text{CO}_2$（mmHg，取中心值，不含±2）。
::: solution
预期$P_a\text{CO}_2 = 1.5 \times 12 + 8 = 26$ mmHg（约3.5 kPa），范围24～28 mmHg。实测值高于28意味着合并呼吸性酸中毒（常为患者疲劳）；低于24意味着合并呼吸性碱中毒。
:::
:::

::: exercise 命名紊乱 {level=1}
指出原发性紊乱并说明代偿是否恰当：(a) pH 7.25，$P_a\text{CO}_2$ 8.5 kPa（64 mmHg），碳酸氢根27；(b) pH 7.50，$P_a\text{CO}_2$ 3.6 kPa（27 mmHg），碳酸氢根21；(c) pH 7.30，$P_a\text{CO}_2$ 3.7 kPa（28 mmHg），碳酸氢根13。
::: solution
(a) **急性呼吸性酸中毒**：$P_a\text{CO}_2$升高了24 mmHg，碳酸氢根应升高约2.4，达到约26～27。对急性紊乱而言代偿恰当；例如阿片类过量或疲劳的哮喘患者。

(b) **急性呼吸性碱中毒**：$P_a\text{CO}_2$降低了13 mmHg，碳酸氢根应降低约2.6，至约21。代偿恰当；例如焦虑、疼痛或肺栓塞。

(c) **代谢性酸中毒**：Winter公式预测$1.5 \times 13 + 8 = 27.5 \pm 2$ mmHg；实测28。呼吸代偿恰当。下一步是计算阴离子间隙。
:::
:::

::: exercise 按白蛋白校正间隙 {level=2 check="(140-104-22)+0.25*(40-20)"}
一名ICU脓毒症患者钠140，氯104，碳酸氢根22 mmol/L，白蛋白20 g/L。计算白蛋白校正的阴离子间隙（白蛋白每低于40 g/L 1 g/L加0.25 mmol/L）并解读。
::: solution
未校正AG $= 140 - (104 + 22) = 14$。校正值$= 0.25 \times (40 - 20) = 5$。校正后AG $= 19$ mmol/L，明显**升高**。低白蛋白掩盖了未测定阴离子的蓄积，在脓毒症中最可能是乳酸。应测定乳酸。
:::
:::

::: exercise 渗透压间隙 {level=2 check="320-(2*138+6+4)"}
一名男性被发现时意识模糊，身旁有一个空的防冻液瓶。实测血浆渗透压320 mOsm/kg；钠138，葡萄糖6，尿素4 mmol/L。计算渗透压间隙（mOsm/kg）并解释其意义。
::: solution
计算渗透压$= 2 \times 138 + 6 + 4 = 286$。间隙$= 320 - 286 = 34$ mOsm/kg，明显升高。最可能的未测定渗透物质是**乙二醇**。随着它被代谢为乙醇酸和草酸，渗透压间隙下降，阴离子间隙升高，引起代谢性酸中毒、急性肾损伤和草酸钙结晶。可能需要紧急的毒理学建议、乙醇脱氢酶阻断剂和血液透析。
:::
:::

::: exercise 解读尿液 {level=2}
两人都有阴离子间隙正常的代谢性酸中毒，碳酸氢根15 mmol/L。A：尿钠40，钾30，氯100 mmol/L；尿pH 5.2。B：尿钠50，钾30，氯55 mmol/L；尿pH 6.6；血浆钾2.9 mmol/L，超声示肾钙质沉着。分别解释。
::: solution
A：尿阴离子间隙$= 40 + 30 - 100 = -30$，为负值。肾脏在大量排铵（伴随氯），尿液呈酸性。肾脏排酸功能正常：酸中毒源于**胃肠道碳酸氢根丢失**，最可能是腹泻。

B：尿阴离子间隙$= 50 + 30 - 55 = +25$，为正值。排铵很少，尽管全身酸中毒，尿pH仍高于5.5。加上低钾血症和肾钙质沉着，这是**远端（1型）肾小管酸中毒**。病因包括干燥综合征和其他自身免疫病。
:::
:::

::: exercise 慢阻肺合并脓毒症的血气 {level=3}
一名70岁慢阻肺女性患肺炎并出现低血压。结果：pH 7.18，$P_a\text{CO}_2$ 7.8 kPa（59 mmHg），碳酸氢根21 mmol/L，钠138，氯100 mmol/L，乳酸6 mmol/L，白蛋白30 g/L。她病情稳定时的血气示碳酸氢根30 mmol/L。找出存在的全部紊乱。
::: solution
**呼吸性酸中毒**：$P_a\text{CO}_2$高。她稳定时的碳酸氢根（30）提示慢性代偿性呼吸性酸中毒，现因肺炎使通气恶化而成为慢性基础上的急性加重。

**代谢性酸中毒**：$P_a\text{CO}_2$为59 mmHg时，慢性代偿预测碳酸氢根约为$24 + 3.5 \times 1.9 \approx 31$。她的碳酸氢根21低得多：代谢性酸中毒消耗了约10 mmol/L。

**阴离子间隙**：$138 - (100 + 21) = 17$；按白蛋白校正为$17 + 0.25 \times 10 = 19.5$，升高。乳酸为6，这是感染性休克引起的**乳酸酸中毒**。

以她自身的基线碳酸氢根30计算，碳酸氢根下降了9，而校正后间隙升高了约7.5：delta比值接近1，符合在慢性呼吸性酸中毒基础上的单纯高间隙酸中毒。

因此三个过程同时存在：慢性呼吸性酸中毒、呼吸性酸中毒的急性加重和乳酸酸中毒。她的通气（可能需要无创通气或气管插管）和循环都需要紧急支持。
:::
:::

::: exercise 设计血气核对清单 {level=3}
设计一份一页纸的核对清单，供低年资医生在夜间安全地解读任何动脉血气。解释每一项为什么要列入。
::: solution
1. **患者信息和$F_I\text{O}_2$**：不知道吸入氧浓度就无法解读氧合；吸入60%氧时“正常”的$P_a\text{O}_2$意味着严重低氧血症。
2. **动脉还是静脉？**静脉血气可用于pH、碳酸氢根、乳酸和电解质，但不能用于氧合；静脉$P\text{CO}_2$比动脉高几个mmHg。
3. **pH**：酸血症还是碱血症。
4. **原发性紊乱**：$P_a\text{CO}_2$和碳酸氢根中哪一个能解释pH。
5. 根据规则（印在清单上）得出的**预期代偿**；若代偿超出范围，写明第二种紊乱。
6. 每一例代谢性酸中毒都计算**阴离子间隙**并作白蛋白校正；间隙升高时计算**delta比值**。
7. **乳酸、葡萄糖和酮体**，它们能解释大多数间隙升高。
8. 间隙升高原因不明或可能中毒时计算**渗透压间隙**。
9. **钾**，因为酸中毒和碱中毒使钾转移，其处理可能很紧急。
10. **临床综合与升级**：用一句话概括所有紊乱及其可能病因，并写明请上级医生评估的明确标准（pH低于7.2、$P_a\text{CO}_2$上升、乳酸高于4、疑似中毒）。
:::
