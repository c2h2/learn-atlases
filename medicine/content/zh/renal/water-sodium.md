有两个问题听起来相似，答案却不同。*体内含有多少钠？*决定细胞外液的容量：一个人是干的、正常的还是水肿的。*血浆中钠的浓度是多少？*反映水的平衡：相对于溶质，水是太多还是太少。肾脏用两个独立的系统控制这两者。钠含量由循环容量感受器调节，通过肾素-血管紧张素-醛固酮系统、交感神经和利钠肽起作用。水平衡由渗透压感受器调节，通过抗利尿激素（ADH）和口渴起作用。

一旦在头脑中把这两个系统分开，围绕“低钠”和“高钠”的大部分困惑就会消失。低钠血症几乎总是水太多的问题，而不是钠太少。高钠血症几乎总是水太少的问题。水肿是钠太多的问题。

本课时解释这两个控制系统，然后讨论低钠血症和高钠血症：如何分类，为什么纠正速度如此重要，以及如何计算治疗的效果。本课时以[[renal/tubular-function]]和[[physiology/homeostasis-body-fluids]]中的体液分布为基础。休克时的静脉补液见[[emergency-critical-care/shock-fluids]]。

## 两个变量，两个控制系统

钠是细胞外液（ECF）的主要阳离子，连同伴随的阴离子构成了ECF的大部分渗透活性。水在细胞与ECF之间自由移动，使两者渗透压相等。由此得出一条简单的规律。

::: theorem 钠含量决定容量，水决定浓度 {#thm-two-systems}
体内钠的**总量**决定细胞外液的**容量**。**血浆钠浓度**由可交换钠和钾的总量相对于总体水决定：

$$
[\text{Na}^+]_p \approx \frac{\text{Na}^+_e + \text{K}^+_e}{\text{TBW}}
$$ {#eq-edelman}

因此，无论ECF容量如何，血浆钠低意味着水相对过多，血浆钠高意味着水相对过少。
:::

::: proof
水跨细胞膜分布，直至细胞内外渗透压相等。细胞内的大部分渗透活性物质是钾盐，细胞外的大部分是钠盐，所以全身体液的渗透压由可交换钠加钾的总量除以总体水决定。血浆钠是这一渗透压的良好标志。如果向体内加入钠而不加水，渗透压升高，口渴和ADH引入水使其恢复，多出的盐和水留在ECF中：容量增大，但浓度恢复正常。如果加入水而不加溶质，水分布到所有体液腔隙并将其全部稀释；ECF只轻度扩张，但钠浓度下降。埃德尔曼（Isidore Edelman）及其同事于1958年通过实验证明了这一关系。
:::

这个方程也解释了钾为什么重要：给缺钾的人补充氯化钾会升高血浆钠，因为钾进入细胞，钠和水随之移动。纠正低钠血症时必须把这一点考虑在内。

### 渗透压调节：ADH与口渴

::: definition 渗透压调节 {#def-osmo}
**血浆渗透压**正常为275～295 mOsm/kg，可估算为

$$
P_{osm} \approx 2[\text{Na}^+] + [\text{葡萄糖}] + [\text{尿素}] \quad (\text{单位均为 mmol/L})
$$ {#eq-posm}

下丘脑前部的**渗透压感受器**能察觉1%～2%的渗透压变化。超过约280～285 mOsm/kg的阈值后，ADH释放急剧增加，肾脏保留水。再高几个mOsm/kg时开始出现**口渴**。ADH限制水的丢失；只有口渴才能补充已经丢失的水。

ADH也受**非渗透性刺激**而释放：有效循环容量下降超过约10%、恶心、疼痛、应激、低血糖以及许多药物。大的容量刺激会压倒渗透信号，因此机体会以牺牲张力为代价来维护容量。
:::

渗透压控制系统灵敏而迅速。健康人喝下一升水后约半小时内ADH即被抑制，在随后几小时内以稀释尿排出多余的水。要使血浆钠下降，饮水量必须超过肾脏的排水能力，或者ADH在本不应存在时存在。

### 容量调节：有效动脉血容量

机体并不直接测量ECF容量。它感受的是动脉系统、心脏以及肾脏自身入球小动脉中的压力和牵张。

::: definition 有效动脉血容量 {#def-volume}
**有效动脉血容量**（EABV）是循环中灌注组织的那部分，由颈动脉窦、主动脉弓、心房和入球小动脉中的压力感受器感知。EABV下降时，肾脏通过以下途径保钠：

- **肾素-血管紧张素-醛固酮系统**：球旁细胞释放的肾素生成血管紧张素Ⅰ，再转化为血管紧张素Ⅱ；后者收缩小动脉，增加近端小管钠重吸收，并刺激醛固酮分泌，醛固酮增加集合管的钠重吸收；
- **交感神经**，增加肾素释放和近端小管重吸收；
- 下降幅度大时的**非渗透性ADH释放**。

EABV升高时，**利钠肽**（心房分泌的ANP、心室分泌的BNP）增加钠排泄，上述系统受到抑制。
:::

EABV通常与ECF容量一致，但并非总是如此。在心力衰竭和肝硬化中，ECF总容量增加（患者水肿），而动脉循环充盈不足，原因是心输出量低或外周血管扩张。肾脏的反应如同患者脱水：保留钠和水。这解释了这些疾病中的水肿，以及通过非渗透性ADH引起的低钠血症。

容量的临床评估依靠病史（丢失、摄入、体重变化）、体格检查（脉搏、卧位和立位血压、颈静脉压、毛细血管再充盈时间、皮肤弹性、水肿、肺部湿啰音）和检查（尿素和肌酐、尿钠）。没有任何单一体征是可靠的；把多项体征结合起来并反复评估，容量评估才会更准确。

::: example 两位水肿患者 {#ex-oedema}
(a) 一名61岁血液透析男性错过两次透析。他体重增加5 kg，气促，颈静脉压升高，双肺底有湿啰音，踝部水肿。(b) 一名34岁肾病综合征复发的女性体重增加8 kg，有踝部和骶部水肿及腹水。她的颈静脉压看不到，站立时头晕，血清白蛋白15 g/L。二人都有钠负荷过多。他们的循环有何不同？
::: solution
二人的ECF总量都扩张了，因为水肿就是间质中多出的钠和水。

(a) 这名男性的肾脏不能排出钠和水，所以多余的液体既充满间质也充满循环。他是**充盈过度**：静脉压升高和肺水肿。治疗是透析除水。

(b) 这名女性白蛋白极低，降低了血浆胶体渗透压，因此液体从循环转移到组织中。在像她这样的部分肾病患者中，尽管有水肿，循环却**充盈不足**：体位性头晕，颈静脉压低平。积极利尿有引起低血压和急性肾损伤的风险。另一些肾病患者则是充盈过度，因为肾脏直接保钠；需靠仔细的床旁评估来判断属于哪一种。

结论：水肿告诉你全身钠总量高；它并不告诉你循环是否充盈。
:::
:::

## 低钠血症

::: definition 低钠血症 {#def-hyponatraemia}
**低钠血症**是血浆钠低于135 mmol/L。欧洲指南（2014）在生化上将其分为**轻度**（130～135 mmol/L）、**中度**（125～129 mmol/L）和**重度**（低于125 mmol/L），并另按症状分级。已知在48小时内发生者为**急性**，持续更久或病程不明者为**慢性**。
:::

低钠血症是医院中最常见的电解质紊乱。即使是轻度慢性低钠血症，在老年人中也与跌倒、骨折和注意力问题相关。急性重度低钠血症引起脑水肿，可致死。

### 为什么大脑是关键

血浆渗透压下降时，水进入脑细胞，使其在坚硬的颅骨内肿胀。在24～48小时内，大脑通过排出钾、氯和有机渗透物质（如谷氨酸、牛磺酸和肌醇）来适应，恢复细胞容积。这种适应解释了两个临床事实。

1. **急性**低钠血症（马拉松后的水中毒、摇头丸使用、术后输注低渗液体）在相对轻的水平就有危险，因为大脑还没有时间适应。
2. **慢性**低钠血症往往耐受得出奇地好，但已适应的大脑在血钠被过快升高时很脆弱，因为它无法足够快地重新摄入渗透物质。

### 逐步诊断方法

**第一步：是否为低渗性？**测定血浆渗透压。

- 钠低而**渗透压正常**提示**假性低钠血症**：当极高的血脂或副蛋白占据了血浆容积、而分析仪使用间接离子选择电极时出现的实验室假象。血气分析仪使用直接电极，给出真实数值。
- **渗透压高**意味着另一种渗透物质把水从细胞中吸出。通常是葡萄糖。葡萄糖每升高5.6 mmol/L（100 mg/dL），血浆钠约下降1.6～2.4 mmol/L。甘露醇和某些冲洗液也有同样作用。
- **渗透压低**证实为真性低渗性低钠血症。

**第二步：症状有多严重？**严重症状（呕吐、癫痫发作、意识水平下降、心肺窘迫）需要在病因明确之前就进行紧急治疗。中度严重症状包括不伴呕吐的恶心、意识模糊和头痛。

**第三步：ADH是否在起作用？**测定尿渗透压。低于100 mOsm/kg意味着ADH受抑制，肾脏在恰当地排出稀释尿；问题是饮水过多或溶质摄入极低（原发性烦渴、啤酒饮用者低钠血症、“茶加吐司”饮食）。高于100 mOsm/kg意味着ADH在起作用。

**第四步：ADH为什么在起作用？**测定尿钠并评估容量。

- **尿钠低于30 mmol/L**提示有效循环容量低：肾外丢失（呕吐、腹泻、烧伤）或心力衰竭和肝硬化的充盈不足状态。
- **尿钠高于30 mmol/L**提示使用利尿药（尤其是噻嗪类）、肾脏疾病、肾上腺皮质功能减退、伴碳酸氢盐尿的呕吐、脑性盐耗，或**抗利尿不适当综合征**（SIAD，也称SIADH）。

::: definition 抗利尿不适当综合征 {#def-siad}
**SIAD**是由于ADH释放（或ADH样效应）不受渗透压或容量驱动而引起的低渗性低钠血症。其基本特征为：

- 血浆渗透压低于275 mOsm/kg；
- 尿渗透压高于100 mOsm/kg；
- 临床上容量正常；
- 在盐和水摄入正常时尿钠高于30 mmol/L；
- 近期未使用利尿药，甲状腺和肾上腺功能正常。

常见病因有**中枢神经系统疾病**（脑膜炎、卒中、头部外伤、出血）、**肺部疾病**（肺炎、结核病）、**恶性肿瘤**（尤其是小细胞肺癌）、**药物**（SSRI类、卡马西平、奥卡西平、抗精神病药、环磷酰胺、阿片类、MDMA）以及**非特异性刺激**（疼痛、恶心、术后状态）。
:::

SIAD是排除性诊断。甲状腺功能减退症和糖皮质激素缺乏（包括垂体疾病引起的肾上腺皮质功能不全，它不引起高钾血症）可以完全模拟SIAD，必须通过甲状腺功能和皮质醇检测加以排除（[[endocrine/adrenal]]）。

::: example 术后癫痫发作 {#ex-hypo}
一名74岁女性服用舍曲林（sertraline），接受择期髋关节手术。术后她以125 mL/h输注5%葡萄糖。第2天她出现意识模糊并发生全面性癫痫发作。术前血浆钠为137 mmol/L，现为116 mmol/L。她看起来容量正常。尿渗透压520 mOsm/kg，尿钠78 mmol/L。请解释并概述处理原则。
::: solution
**机制。**手术、疼痛、恶心和阿片类药物刺激非渗透性ADH释放，舍曲林又加重了这一作用。5%葡萄糖在葡萄糖被代谢后实际上就是自由水。由于ADH在起作用（尿渗透压520，远高于排出水所需），水被保留下来。血钠在不到48小时内下降了21 mmol/L：伴**严重**症状的**急性**低钠血症。

**紧急处理**（遵循当地和欧洲指南）：
- 静脉推注**3%高渗盐水**（成人通常为150 mL，20分钟内输完），复查血钠，必要时再重复最多两次直至症状改善，目标是第一小时血钠升高约**5 mmol/L**；
- 保护气道并控制癫痫发作；
- 停用低渗液体和舍曲林，处理疼痛和恶心。

**随后**：将总升幅限制在纠正限度之内（[[#warn-correction]]），每隔几小时监测血钠，并观察尿量。当ADH刺激消退（疼痛和恶心缓解）时，肾脏可能突然排出大量稀释尿，导致快速过度纠正。

**预防**：术后确实需要静脉输液时用等渗液体作维持，服用致低钠药物的人术前检查血钠，术后监测。
:::
:::

### 治疗原则

**严重症状**：如上所述给予高渗盐水，不论病因，然后治疗病因。

**无症状或轻度症状的慢性低钠血症**：纠正病因并限制水。

- **低容量性**：用等渗盐水补充容量。容量恢复后，非渗透性ADH刺激消失，随之出现水利尿，血钠可能迅速上升。
- **SIAD**：停用致病药物并治疗病因。**限制液体**（通常限制在每天约1 L以下，视尿量而定）是一线治疗。二线选择包括口服**尿素**（增加溶质排泄从而增加水排泄），或袢利尿药加盐。**伐普坦类**（血管升压素V2受体拮抗剂，如托伐普坦）因有过度纠正和肝毒性风险，属于专科用药。
- **高容量性**（心力衰竭、肝硬化）：治疗原发病并限制水；袢利尿药对心力衰竭有帮助。
- **溶质摄入不足**：增加饮食中的溶质（蛋白质、盐）并限制水。

::: warning 纠正限度源于渗透性脱髓鞘 {#warn-correction}
在**慢性**低钠血症中，血钠升高过快会引起**渗透性脱髓鞘综合征**（ODS，旧称脑桥中央髓鞘溶解症）。通过丢失渗透物质而适应的脑细胞此时失水皱缩，损伤少突胶质细胞和髓鞘，尤其是在脑桥。症状通常在过快纠正后**2～6天**出现，常在最初好转之后：构音障碍、吞咽困难、痉挛性四肢轻瘫、行为改变，严重者呈“闭锁”状态。可能不可逆。

英国大多数医院遵循的限度来自欧洲指南（2014）：

- **最初24小时内**血钠升高**不超过10 mmol/L**，**此后每24小时不超过8 mmol/L**，直至血钠达到130 mmol/L；
- 对ODS**高危**者（血钠105 mmol/L或以下、酒精使用障碍、营养不良、低钾血症、晚期肝病），按照美国专家建议，目标是**任何24小时内不超过8 mmol/L**。

这些限度是上限而不是目标。若血钠升高快于计划（常因开始水利尿），专科团队可能停用高渗盐水或盐水，并在严密监测下用无电解质的水（5%葡萄糖）、加或不加去氨加压素，使血钠重新下降。

同一原理反过来适用于**慢性高钠血症**：血钠降得过快会使水涌入已适应的脑细胞，引起脑水肿。血钠通常每天降低不超过约**10～12 mmol/L**（约每小时0.5 mmol/L）。已知在数小时内发生的高钠血症可以更快纠正。
:::

### 预测输液的效果

一个广泛讲授的公式来自阿德罗盖（Horacio Adrogué）和马迪亚斯（Nicolaos Madias），用于估算输注一升液体后血浆钠的变化：

$$
\Delta[\text{Na}^+] \approx \frac{[\text{Na}^+]_{\text{输液}} + [\text{K}^+]_{\text{输液}} - [\text{Na}^+]_{\text{血浆}}}{\text{TBW} + 1}
$$ {#eq-am}

总体水（TBW）按体重的一定比例估算：较年轻男性约0.6，较年轻女性和老年男性约0.5，老年女性约0.45。3%盐水含钠513 mmol/L，0.9%盐水含钠154 mmol/L。

该公式的主要弱点是忽略了尿液。在尿渗透压高于0.9%盐水渗透压（308 mOsm/kg）的SIAD中，输注盐水甚至可能*降低*血钠：盐被排入较少量的浓缩尿中，部分水被保留（本课时末的一道习题演算了这些数字）。

::: example 并不低的血钠 {#ex-pseudo}
一名70岁男性有体重下降和背痛，实验室血浆钠为126 mmol/L。实测血浆渗透压289 mOsm/kg。他的总蛋白很高，为120 g/L。血气分析仪测得钠为139 mmol/L。请解读。
::: solution
低钠血症而实测渗透压正常提示**假性低钠血症**。主要的实验室分析仪在测钠之前先稀释样本（间接离子选择电极），并假定血浆约93%为水。大量副蛋白降低了血浆的含水比例，因此稀释后样本中的钠少于预期。血气分析仪直接测定血浆水中的钠，显示真实数值139 mmol/L。不存在需要治疗的水过多。高蛋白加背痛提示**骨髓瘤**，需要进一步检查（[[blood/lymphoma-myeloma]]）。严重高甘油三酯血症也会引起同样的假象。
:::
:::

## 高钠血症

::: definition 高钠血症 {#def-hypernatraemia}
**高钠血症**是血浆钠高于145 mmol/L。它总是意味着水相对于溶质不足，且总是高渗的。由于口渴是强有力的防御，高钠血症通常只发生在**不能**充分饮水的人：婴儿，以及高龄、衰弱、意识模糊、镇静、气管插管或口渴感受损的人。其病因为：

- **失水而未补充**：不显性丢失（发热、烧伤、机械通气）、腹泻、渗透性利尿（高血糖、尿素）、尿崩症；
- **钠摄入过多**，少见得多：高渗盐水或碳酸氢钠、摄入食盐、高渗营养液。
:::

症状来自脑细胞皱缩：嗜睡、易激惹、无力，继而癫痫发作和昏迷。脑组织皱缩可撕裂桥静脉，引起颅内出血。慢性高钠血症耐受较好，因为大脑会增加渗透物质。

尿渗透压有助于寻找病因。尿液最大程度浓缩（高于约600～800 mOsm/kg）说明肾脏反应正常，失水是肾外性的或摄入不足。高钠血症时尿液仍稀释则意味着尿崩症（[[renal/tubular-function]]）。

**缺水量**可以估算：

$$
\text{缺水量 (L)} = \text{TBW} \times \left( \frac{[\text{Na}^+]}{140} - 1 \right)
$$ {#eq-deficit}

这是在其他条件不变时使血钠回到140所需的水量。还必须加上持续丢失量。慢性高钠血症的缺水量至少在48小时内补充，最好经口或经鼻饲管给水，若肠内途径不可行则静脉输注5%葡萄糖。

::: example 养老院居民血钠168 {#ex-hyper}
一名84岁女性患晚期痴呆，住在养老院，胸部感染期间数天进食饮水很少。她体重50 kg。血浆钠168 mmol/L，尿素22 mmol/L，肌酐150 µmol/L（基线85）。尿渗透压820 mOsm/kg。估算她的缺水量并概述处理。
::: solution
**解读。**高钠血症伴高度浓缩尿，说明她的肾脏在恰当地保水。病因是摄入不足（痴呆、疾病以及饮水依赖他人），加上发热增加的不显性丢失。尿素和肌酐升高说明存在肾前性急性肾损伤。

**缺水量。**老年女性TBW $\approx 0.45 \times 50 = 22.5$ L。

$$
\text{缺水量} = 22.5 \times \left( \frac{168}{140} - 1 \right) = 22.5 \times 0.2 = 4.5 \text{ L}
$$

**计划**（遵循当地指南）：在48～72小时内补充缺水量加持续丢失量，目标是血钠每天下降不超过约10～12 mmol/L；若能安全吞咽则经口补液，否则静脉输注5%葡萄糖；治疗感染；起初每4～6小时复查血钠；回顾用药；并解决她脱水的原因，包括在养老院中协助饮水。对于某些临近生命终末期的人，照护目标可能更倾向于舒适措施；这一决定应与家属共同作出，并尽可能体现她本人的意愿（[[geriatrics-palliative/palliative-care]]）。
:::
:::

::: quiz
一名30岁男性在马拉松后晕倒被发现。他在每个补给站都喝了水。血钠121 mmol/L，意识模糊并呕吐。最合适的首选治疗是什么？
- [ ] 限制液体至每天1 L
- [ ] 以1 L/h输注0.9%盐水
- [x] 推注3%高渗盐水并反复测定血钠
- [ ] 等待症状缓解，因为纠正有渗透性脱髓鞘的风险
::: solution
这是急性症状性低钠血症，原因是运动期间非渗透性ADH高，饮水超过了排水能力（运动相关性低钠血症）。呕吐和意识模糊是脑水肿引起的严重症状。首要任务是用高渗盐水迅速使血钠升高几个mmol/L。由于是在数小时内发生的，渗透性脱髓鞘的风险低，而不治疗的脑水肿风险高。限制液体太慢，0.9%盐水的渗透压不足以在高ADH下可靠地升高血钠。
:::
:::

::: history
在1947年的克鲁尼安讲座中，英国生理学家维尼（Ernest Basil Verney）介绍了狗的实验：向颈动脉少量注射高渗溶液可抑制水利尿，提示脑内存在控制抗利尿激素释放的“渗透压感受器”。十年后，即1957年，施瓦茨（William Schwartz）、巴特（Frederic Bartter）等人描述了两名肺癌患者，他们有低钠血症，尿钠持续丢失且尿液浓缩；作者提出这是抗利尿激素分泌不当，即今天所称的SIAD。1959年，亚当斯（Raymond Adams）、维克多（Maurice Victor）和曼考尔（Elliott Mancall）在酒精使用障碍和营养不良的人中描述了脑桥中央髓鞘溶解症。它与低钠血症快速纠正之间的联系在20世纪80年代得到确立，从而形成了今天使用的纠正限度。
:::

## 后续内容

钾在血浆钠方程和集合管中都与钠相互作用，见[[renal/potassium-calcium-phosphate]]。急性肾损伤中的容量与钠以及透析指征见[[renal/acute-kidney-injury]]。心力衰竭和肝硬化这两大高容量性低钠血症病因分别见[[cardiovascular/heart-failure]]和[[gastrointestinal/liver-disease]]。尿崩症的垂体病因见[[endocrine/hypothalamus-pituitary]]。

::: summary
- 钠**含量**决定细胞外液容量；血浆钠**浓度**反映水平衡。
- 渗透压调节通过渗透压感受器、ADH和口渴实现；容量调节通过压力感受器、肾素-血管紧张素-醛固酮系统、交感神经和利钠肽实现。有效容量大幅下降时，即使渗透压低也会触发ADH。
- 低钠血症：确认低渗透压，评估症状，然后用尿渗透压（ADH是否在起作用？）和尿钠结合容量状态（为什么？）分析。
- SIAD要求：血浆渗透压低、尿渗透压高于100 mOsm/kg、容量正常、尿钠高于30 mmol/L，并排除利尿药、甲状腺功能减退症和糖皮质激素缺乏。
- 严重症状：推注3%盐水，目标升高约5 mmol/L。慢性：治疗病因，限制水，避免快速纠正。
- 纠正限度：最初24小时内不超过10 mmol/L，此后每24小时不超过8 mmol/L（高危者任何24小时内不超过8 mmol/L），以避免渗透性脱髓鞘。
- 高钠血症是缺水，通常发生在不能饮水的人。缺水量 = TBW ×（Na/140 − 1）；慢性高钠血症每天降低不超过约10～12 mmol/L。
:::

## 习题

::: exercise 计算血浆渗透压 {level=1 check="2*132+18+12"}
一名糖尿病男性血浆钠132 mmol/L，葡萄糖18 mmol/L，尿素12 mmol/L。用标准公式计算他的血浆渗透压（mOsm/kg）。
::: solution
$P_{osm} = 2 \times 132 + 18 + 12 = 294$ mOsm/kg。尽管血钠低，由于葡萄糖的贡献，他的渗透压正常。尿素可自由通过细胞膜，所以它增加实测渗透压，但不增加有效渗透压（张力）；在缺乏胰岛素时，葡萄糖是有效渗透物质，会把水从细胞中吸出，这就是他血钠低的原因。
:::
:::

::: exercise 按葡萄糖校正血钠 {level=1 check="128+2.4*(33.5-5.5)/5.6"}
一名糖尿病酮症酸中毒青少年血浆钠128 mmol/L，葡萄糖33.5 mmol/L。按葡萄糖每高于5.5 mmol/L 5.6 mmol/L、血钠校正2.4 mmol/L计算校正后血钠。
::: solution
超出的葡萄糖$= 33.5 - 5.5 = 28$ mmol/L，即$28 / 5.6 = 5$个5.6 mmol/L。校正值$= 5 \times 2.4 = 12$ mmol/L。校正后血钠$= 128 + 12 = 140$ mmol/L。胰岛素降低葡萄糖后，水回到细胞内，实测血钠应向这一数值上升。若葡萄糖下降时实测血钠也下降，则是自由水过多和脑水肿风险的警示信号（[[endocrine/endocrine-emergencies]]）。
:::
:::

::: exercise 低钠血症的分类 {level=1}
给出最可能的类型和病因：(a) 血钠126，尿渗透压60 mOsm/kg，一名每天喝8品脱啤酒、吃得很少的男性。(b) 血钠124，容量正常，尿渗透压480，尿钠62，一名开始服用卡马西平的女性。(c) 血钠128，尿钠8 mmol/L，一名肝硬化腹水男性。(d) 血钠129，尿钠55 mmol/L，一名3周前开始服用苄氟噻嗪（bendroflumethiazide）的女性。
::: solution
(a) **溶质摄入不足（啤酒饮用者低钠血症）**：尿液最大程度稀释，ADH受抑制。啤酒主要是水，溶质很少，他又很少摄入蛋白质和盐，所以他的溶质排泄量以及最大排水量都很低。

(b) **SIAD**，由卡马西平引起，前提是甲状腺和肾上腺功能正常。

(c) 肝硬化的**高容量性低钠血症**：动脉循环充盈不足，强烈保钠，加上非渗透性ADH。

(d) **噻嗪类引起的低钠血症**：噻嗪类阻断远端小管的稀释功能而保留髓质梯度，所以肾脏不能排出自由水。它们是低钠血症最常见的药物性原因，尤其见于老年女性。
:::
:::

::: exercise SIAD中的盐水 {level=2 check="1-308/616"}
一名SIAD男性的尿渗透压固定在616 mOsm/kg。给他输注1 L 0.9%盐水（308 mOsm）。假设输入的溶质全部以616 mOsm/kg从尿中排出，输入的水有多少升被保留？
::: hint
求出以616 mOsm/kg排出308 mOsm所需的尿量。
:::
::: solution
所需尿量$= 308 / 616 = 0.5$ L。他输入了1 L水，所以有$1 - 0.5 = $ **0.5 L**无溶质的水被保留，血钠进一步下降。这就是为什么等渗盐水不是尿液浓缩的SIAD的治疗方法，也是为什么对被认为低容量的人进行盐水“试验”后需要复查血钠。
:::
:::

::: exercise 在限度内制定计划 {level=2}
一名58岁女性有酒精使用障碍且营养不良，血钠108 mmol/L，血钾2.8 mmol/L。她嗜睡但无癫痫发作。入院6小时后，在输注1 L 0.9%盐水并补钾后，她的血钠为114 mmol/L，并排出大量稀释尿。解释正在发生什么以及为什么危险。
::: solution
她是渗透性脱髓鞘的**高危**者：重度、几乎肯定是慢性的低钠血症，酒精使用，营养不良，低钾血症。推荐的上限是24小时内升高8 mmol/L。她在6小时内已经升高了6 mmol/L。

盐水恢复了她的容量，去除了非渗透性ADH刺激。溶质摄入不足也可能起了作用。现在ADH受抑制，她在排出自由水，使血钠迅速上升。补钾也会升高血钠（钾进入细胞，钠离开细胞；血浆钠方程包含钾）。若不采取措施，她将在数小时内超过限度。这种情况下，专科团队每1～2小时监测血钠，测定尿量，并可能停止继续输注盐水，给予无电解质的水并使用去氨加压素终止水利尿，使升幅保持在安全范围内。
:::
:::

::: exercise 缺水量 {level=2 check="0.5*70*(160/140-1)"}
一名72岁男性体重70 kg，腹泻数天后血浆钠160 mmol/L。用0.5的TBW比例计算他的缺水量（L）。
::: solution
TBW $= 0.5 \times 70 = 35$ L。缺水量$= 35 \times (160/140 - 1) = 35 \times 0.142857 = 5$ L。还须加上持续的腹泻和不显性丢失，补液应分配好，使血钠每天下降不超过约10～12 mmol/L；本例从160降到140大约需要两天。
:::
:::

::: exercise 输液计算 {level=3 check="round((513-116)/(0.45*60+1)*10)/10"}
一名74岁女性体重60 kg，血浆钠116 mmol/L。用Adrogué–Madias公式、TBW比例0.45，估算输注一升3%盐水后血浆钠的升幅，保留一位小数。然后估算推注150 mL后的升幅，并解释实测升幅可能不同的两个原因。
::: solution
TBW $= 0.45 \times 60 = 27$ L。每升升幅$= (513 - 116)/(27 + 1) = 397/28 = 14.2$ mmol/L。推注150 mL约升高$0.15 \times 14.18 = 2.1$ mmol/L。

实测升幅可能不同，因为：(1) 公式假定没有尿量；若开始水利尿（恶心或低容量缓解后ADH下降），血钠上升会远快于预测；若她持续有ADH作用而排出浓缩尿，升幅可能更小；(2) TBW只是估计值，其他输液、补钾和经口摄入也会改变血钠。这就是为什么公式只用于制定计划，而血钠要反复测定。
:::
:::

::: exercise 肿瘤病房的低血钠 {level=3}
一名66岁吸烟男性在常规检查中发现血钠121 mmol/L。他有轻度意识模糊。看起来容量正常。血浆渗透压252 mOsm/kg，尿渗透压610 mOsm/kg，尿钠70 mmol/L。TSH正常，晨间皮质醇420 nmol/L。胸片示肺门肿块。给出诊断、可能的病因和处理原则。
::: solution
**诊断**：慢性（病程不明）、重度低钠血症，伴中度严重症状，符合**SIAD**标准：血浆渗透压低、尿液不适当地浓缩、尿钠高于30、容量正常、甲状腺和肾上腺功能正常、未提及利尿药。

**可能的病因**：**小细胞肺癌**异位分泌ADH，吸烟史和肺门肿块支持这一点（[[respiratory/lung-cancer-pleura]]）。

**处理原则**：由于症状为中度而非严重，且低钠血症为慢性，应避免快速纠正；限制液体是一线治疗，但尿渗透压高达610时单靠限水往往不够，可考虑尿素或由专科主导使用伐普坦类；治疗肿瘤，这可能纠正SIAD；仔细监测血钠，保持在纠正限度之内。只有在症状变为严重时才使用高渗盐水。
:::
