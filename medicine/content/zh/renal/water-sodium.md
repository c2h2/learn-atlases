钠是细胞外的液体的渗透摩尔，所以**身体用两个重叠的系统来调节钠与水，它们回答两个不同的提问：循环满了吗（容量的调节——压力感受器与肾素及血管紧张素及醛固酮的系统、利钠的肽和压力的尿钠），以及血浆被稀释了吗（渗透的调节——口渴与抗利尿的激素）**（[[physiology/homeostasis-body-fluids]]与[[physiology/hormones]]）。临床的钠的疾病多数是一个戴着钠的标签的水的问题——低钠几乎总是意味着被保留的水太多——而本章的疾病（钠的异常与容量的状态和水肿）就是内科每天的算术。

本章涵盖容量与渗透的调节、低钠与高钠血症的方法、安全纠正的限度，以及水肿的状态。

## 调节

::: definition 容量的调节：有效动脉的血容量 {#def-volume}
**身体调节的不是总的钠，而是有效动脉的血容量：被充盈的动脉的树所感知的那一部分，所以感受器会在心力衰竭与肝硬化和肾病综合征中被误导（被保留的钠与水尽管有升高静脉的容量而积聚在第三个间隙[[cardiovascular/heart-failure]]与[[gastrointestinal/liver-disease]]与[[renal/chronic-kidney-disease]]）——这就是这些不足充盈对过多的充盈的水肿的分裂[[#ex-oedema]]。传感器：动脉的压力感受器（主动脉的弓与颈动脉窦：迷走的传入到下丘脑，改变血管加压素与交感的输出）、心脏房室的感受器（心房肽的释放）、肾的（球旁装置的压力与钠的传感器）。效应器：交感的神经（入球的收缩与肾素的释放和直接的钠的重吸收）；肾素与血管紧张素与醛固酮的轴（肾素把底物裂解为血管紧张素I和肽的转换酶的血管紧张素II：血管的收缩以及出球的小动脉的保滤过与醛固酮的肾上腺的分泌——保钠与排钾和氢——[[renal/potassium-calcium-phosphate]]与[[endocrine/adrenal]]）；抗利尿的激素（在超过8%到10%的容量下降时被压力感受器非渗透地释放——这就是为什么容量会赢过渗透，而这也就是为什么低容量的低钠会带着一个不当的浓缩的尿[[#def-hyponatraemia]]）；以及利钠的肽（心房与脑的肽：从被拉伸的心房释放，把钠排掉并抑制肾素——它们临床的用途就是它们自己的故事[[cardiovascular/hypertension]]）；加上压力的尿钠（被升高的灌注的压力增加钠的排泄——长期血压的设定器[[renal/filtration ]]）。诊断的工具就是尿：尿的钠与氯低于20意味着这个肾正在保住钠（肾外的损失或对肾的有效的动脉血容量的下降），而高于40意味着肾的浪费或盐皮质激素的缺陷；而这尿素的清除与分数可以分辨出利尿剂和综合征[[#ex-hypo]]。**
:::

::: definition 渗透的调节：抗利尿的激素与口渴 {#def-osmo}
**下丘脑的渗透感受器会把血浆的渗透读到一个窄的范围内（约280到295毫渗透摩尔，阈值之间约1到2%的差异）：渗透升高时细胞会收缩，并触发两个反应——从神经垂体终端释放的血管加压素（它的肽的神经元把轴突伸到集合管，插入水孔蛋白[[renal/tubular-function]]）和口渴（皮层有意识的驱动，需要完整的一个机制与进入水的能力：这就是为什么高钠几乎总是发生在无法喝水的人中[[#def-hypernatraemia]]）。这两者的增益都很高：在约280之上的渗透的一个1%到2%的上升会使血管加压素成倍升高，并让尿被浓缩（这个组件的图的这条曲线的陡峭的部分）；而渗透在阈值之下会让这个激素完全被移除，并让每日多升到20升的水可以被排出[[renal/tubular-function]]。非渗透的输入会移位这条曲线：容量的下降与心输出量的下降（压力感受器）、恶心与疼痛与应激（最强的刺激之一：术后与药物）；药物会增强（鸦片类与抗抑郁药和抗癫痫的卡马西平）或抑制（锂，它会制造对激素的抵抗[[renal/tubular-function]]）；以及激素（在月经的周期与妊娠中的类固醇会设定更低的阈值）。关键解释的规则：血管加压素的活性本身既不好也不好，除非它与同时的钠和渗透（血浆和尿的张力）被配对——而在一个稀释的血浆中一个浓缩的尿就是本章的核心这一发现[[#def-hyponatraemia]]。**
:::

::: example 骨髓瘤的面具 {#ex-pseudo}
在常规的血清中钠为124，而患者无症状；总蛋白为95，而血脂正常；而肾的功能与尿都正常。
::: solution
**假性低钠：被蛋白（在这个骨髓瘤的副蛋白中）或脂质占据一个大血浆的水的分数，使钠离子间接的方法读出一个低的浓度，而这个水的相是真的正常[[blood/lymphoma-myeloma]]与[[clinical-skills/laboratory-tests]]。在直接电极（血气的分析仪）与冰点降低渗透测量的（正常）下确认；渗透的差距（被计算的减去被测量的）会指向渗透摩尔（甘露醇与醇和糖）。处理：没有——这个值就是一个人工产物；把方法写进这份记录，以便未来的一次急诊不追着这个数字，并追踪这个副蛋白。同样的伪装：在输注后抽血的标本从上面的液体（一个稀释的标本）与甘露醇或造影的过量的负荷：在开始一条治疗的路径之前先测渗透。**
:::

## 钠的异常

::: definition 低钠血症 {#def-hyponatraemia}
**低钠就是钠的浓度低于135：几乎总是一个相对于钠的过多的水；按步骤来进方法（[[emergency-critical-care/acute-assessment]]）。步骤一：症状——恶心与头痛及意识混乱和癫痫发作（脑的水肿，在急性的下降中更严重，因为适应性渗透的排泄需要数小时）。有严重症状时就是急诊。步骤二：血浆的渗透（真性的低渗透对照假性的与高渗透的[[#ex-pseudo]]）。步骤三：尿的渗透（低于100：这个轴正在工作，所以水的摄入过多（原发的多饮[[renal/tubular-function]]、低溶质的饮食与啤酒、或重设的渗透感受器）；高于100：血管加压素在活动，而接下来提问为什么）。步骤四：容量的状态与尿的钠：低容量（腹泻与利尿剂及盐的皮质激素的缺乏和脑的疾病）——血管加压素就恰当，而盐会治疗它；等容量（抗利尿激素的不当的分泌这一综合征与甲状腺和肾上腺的缺陷及药物：噻嗪是经典的伪装者[[pharmacology/adverse-reactions]]）；高容量（心与肝和肾的疾病——稀释钠过多的水[[#ex-oedema]]）。检查：皮质醇与甲状腺的测试与肾的功能和尿的钠与钾；抗利尿的激素不当的分泌的标准把其他的原因排除，而尿素的分数与尿酸在分辨中有用。管理的规则：治疗症状（在有癫痫患者中高渗盐紧急的小的量），然后原因（停止药物；液体的限制；在低容量状态中的盐；在慢性抗利尿的激素不当的分泌中的尿素或口服的盐以及血管加压素的拮抗剂带谨慎）；而最重要的就是速度[[#warn-correction]]。**
:::

::: definition 高钠血症 {#def-hypernatraemia}
**高钠意味着相对于水有太多的钠——几乎总是一个水的问题，而这个机制几乎总是一个不能喝：依赖的（在护理之家的居民与婴儿与失能的）；被限制的（镇静的与插管的患者）；下丘脑口渴的缺陷或血管加压素的缺乏（[[renal/tubular-function]]与[[endocrine/hypothalamus-pituitary]]）。它也会来自高渗的暴露（管的配方与液体及盐水灌洗）、溶质的利尿（甘露醇与高糖及管的喂养）和矿皮质激素的过多（一个温和的，因为口渴会补偿[[endocrine/adrenal ]]）。危险：脑的收缩的效应——在数天内适应性的渗透摩尔会回来，所以快速的纠正会水肿：限度与钠的每小时的下降一样严格。症状：肌无力和反射亢进与意识改变和癫痫（更少）。方法：水缺失（自由的水的百分比与持续的需求）、口服的水（如果安全且可得）或低渗的液体（糖水）；在容量不足时先用等张的盐纠正容量的缺失；每二到四小时的钠的系列与尿；以及在慢性的（超过四十八小时）的高钠中不超过钠每小时10毫摩尔的下降。关键的混淆：尿（肾的水的损失：不浓缩的尿在高钠中就是血管加压素缺乏或肾源性的抵抗：锂及高钙和梗阻；而浓缩的尿则指向肾外的损失或不充分的水[[#ex-hyper ]]）。**
:::

::: warning 纠正的限度存在是因为脱髓鞘 {#warn-correction}
渗透性脱髓鞘的综合征（以前被称为脑桥中央髓鞘的溶解）发生在低钠被纠正得太快的时候，而在已经耗竭的人（酒精依赖与营养不良、低钾的和女性）与严重慢性的（超过四十八小时的）低钠中风险更高。限度就是标准：钠的每二十四小时的上升低于8到10毫摩尔；而在高风险的患者中低于8——并加上安全边际（更低的上限，每四到六小时的钠，一个被预先商定下降的药物方案（当钠跑得太快）和一名在夜间被点名的医生，因为这就是伤害发生的时候）。规则：如果癫痫发作就用高渗的盐的小的紧急的剂量（这些不会造成过度纠正——目标是症状，不是这个正常）；用液体的限制和盐的组合来避免自发快速的排水（一个被恢复的血管加压素或容量的输入会突然地解除水，并造成一个被忽视的过度纠正——尿的输出就是警报）；不要一次同时改变这两项（液体的限制与盐）；以及每一次钠的异常都在记录上写明限度与检查的间隔。结果：迟发的（二到六天）构音障碍与吞咽困难和四肢瘫闭锁的图形——不可逆，而病房的可避免的伤害的清单上常列第一位。
:::

::: example 手术后的癫痫发作 {#ex-hypo}
一位72岁在髋的替换后第二天的女性变得意识混乱，然后出现全身性的癫痫发作；她用氢氯噻嗪与鸦片类的镇痛；钠为118；她接受低渗维持的液体。
::: solution
**有症状重度的急性（或亚急性）的低钠：这是紧急之一[[emergency-critical-care/acute-assessment]]与[[emergency-critical-care/resuscitation]]。机制的叠加：噻嗪（一个损坏稀释的节段加上钠的耗竭：一个经典的原因[[pharmacology/adverse-reactions]]）；鸦片类与非渗透的血管加压素的刺激（恶心与疼痛和应激[[#def-osmo]]）；以及低渗的液体的维持（一个无法排水的患者被给的水）。即刻：高渗盐紧急的小的剂量（一个缓慢静脉的小的量，带重复用于癫痫的发作，带着每二到四小时钠）；停止噻嗪和低渗的液体；并预测一个快速自发的排水（一旦鸦片类被反转并容量被恢复，血管加压素会消失并尿会流出——过度纠正这一风险，用去氨加压素钳夹的这策略去匹配指南[[#warn-correction]]）。后续：把钾与镁补充（低钾会损害纠正的安全）、把氢氯噻嗪放在过敏/不良反应的列表上（一个别高血压的药物）、以及在老年的患者中的手术后液体政策的审查（常规维持液体的处方作为低钠的伤害的原因的文献[[clinical-skills/patient-safety]]）。**
:::
:::

::: example 护理之家的钠168 {#ex-hyper}
在一名在护理之家的有痴呆症的68岁的人中，在发热的几天里钠上升到168；她喝得很少；尿的输出存在；生命体征显示出容量的不足；没有腹泻。
::: solution
**高钠与自由的水的缺失（[[#def-hypernatraemia]]）：一个口渴进入受损的人加上一个不显性的损失（发热）和低的水的提供——一个机构护理的失败，以及一个可预防的病房之外发生的伤害[[clinical-skills/patient-safety]]与[[geriatrics-palliative/ageing-frailty]]。步骤：计算自由的水的缺失（体重的历史会估计它）；经口的水为首选，如果她不能安全吞咽则用鼻管或低渗的静脉液体（糖水），按钠的每小时的限制调整（在慢性的病例中低于10，用每四到六小时的钠）；用等张的液体来纠正症状容量的缺失，然后计算水；寻找加重者（高钙与低钾和溶质的利尿、管的喂养自由的水的间隔）；并治疗发热与感染。系统的修复：被规定的饮水与液体的图表、在疾病期间的水的目标、以及作为质量指标的钠的审计——而把这些都写下来，因为这个事件的类就是这些可预防的。**
:::
:::

::: example 两位肿胀的患者 {#ex-oedema}
两名有外周水肿的患者：一位有射血分数降低的心力衰竭与颈静脉的扩张和肝的增大；另一位有肾病综合征与蛋白尿为每日4克和眼睑的水肿。
::: solution
**这两种都是身体的过多的钠与水，但被这些不同的机制与这些不同的治疗（[[#def-volume]]）：不足充盈的（心力衰竭：因为泵被降低的有效动脉的血容量被压力感受器感知，神经激素被激活，钠与水被保留而循环被充压——治疗就是这个泵和利尿剂：袢的减少充盈，而这些都是改善生存的治疗[[cardiovascular/heart-failure]]）；过多充盈的（肾病综合征：滤过屏障的渗漏会造成低白蛋白与动脉的血管的充盈减少以及继发的钠的潴留——治疗就是利尿剂加这个基础疾病的激素/免疫抑制治疗与血管紧张素的阻断减少蛋白尿，加上盐和类固醇的纪律[[renal/chronic-kidney-disease]]与[[immunology/hypersensitivity ]]）。分辨的这线索：颈静脉的压力与心音与肝的增大和胸的积液对肾病范围蛋白尿与低白蛋白和脂质的分布的水肿；尿的钠在这两者都可以是低（一个有效动脉容量低的肾）；对钠的潴留的治疗在这两者都是袢的利尿剂，但心衰患者需要疾病特异的治疗。关键的警告：水肿的钠潴留与低钠并存：稀释的钠，而不是一个盐的缺乏[[#def-hyponatraemia]]。**
:::

::: history
**1957年巴特与施瓦茨的病例把抗利尿的激素的不当的分泌命名；五十年代的盐与水两个系统的重新表述，与压力的尿钠的长环模型的时代（[[cardiovascular/hypertension]]的自己的基础）；渗透感受器与血管加压素关系的量化与临床的渗透感受器的概念（七与八十年代）；水孔蛋白分子的时代（[[renal/tubular-function]]）；渗透脱髓鞘的综合征临床病理的描述（1959年的临床病理讨论的病例）；以及设定纠正限度的过度纠正病例的系列——以及血管加压素的拮抗剂被引入作为排水的治疗和它们对过度纠正的担忧，与在住院的人群中的低钠作为一个可修改的伤害的标记物流行病学的重新定义（[[clinical-skills/patient-safety]]）。本章今天的实践就是一个被清楚的机制与被伤害驱动的限度所塑造床边的算术。**
:::

## 通向何处

本章把基础的生理与[[renal/tubular-function]]和[[renal/filtration]]连接；低钠的病因的鉴别与肾上腺的缺陷在[[endocrine/adrenal]]与[[endocrine/hypothalamus-pituitary]]；钾的伴随在钠的调节中在[[renal/potassium-calcium-phosphate]]；急性方法的规则在[[emergency-critical-care/acute-assessment]]；心肝肾水肿的状态在[[cardiovascular/heart-failure]]与[[gastrointestinal/liver-disease]]与[[renal/chronic-kidney-disease]]；噻嗪和利尿剂在[[pharmacology/adverse-reactions]]与[[pharmacology/autonomic-drugs]]；而在护理之家的伤害在[[geriatrics-palliative/ageing-frailty]]。

::: summary
- 两个系统共享肾单位：容量的调节（压力感受器的反射与肾素轴及利钠的肽和压力的尿钠）保卫有效动脉的充盈；而渗透的调节（口渴加血管加压素）在约1%之内保卫张力。
- 低钠就是水的过多：确认张力、为它定日期、按容量与尿的检查分类，然后在症状乘以慢性度的网格上治疗——紧急时用高渗盐的小的剂量，而慢性的多数用液体的限制与盐及停药。
- 纠正的上限（在慢性的低钠中每二十四小时8到10；在高钠中类似的限制）会预防渗透的脱髓鞘与脑的水肿；预期意外的过度纠正，并在需要时钳夹。
- 高钠标记着失败的口渴或失败的水的进入；在两到三日内自由水缺失的算术，以肠内的水为先，就是这个治疗。
- 水肿就是不足充盈对过多的充盈的算术——颈静脉的压力与白蛋白和这个轴被读出——而利尿的速度被血浆的补充的速度限制，而不是被肿胀的量。
:::

## 练习

::: exercise 纠正钠 {level=1}
一个血糖为42伴随一个钠为126。估计被纠正的钠，并说明真正的低钠是否共存。
::: solution
**校正大约为每高于正常的5.6毫摩尔的糖加1.6到2.4：这个糖高于6约36毫摩尔，所以加10到15，纠正后约136到141：没有明显的水的紊乱——钠被稀释，而不是低（[[#def-hyponatraemia]]的高渗的类别与[[endocrine/diabetes]]和[[endocrine/diabetes-complications]]的液体的表格[[renal/acute-kidney-injury ]]）。同样的校正（以一个更小的因子）适用于甘露醇。**
:::
:::

::: exercise 给这个图形分类 {level=1}
钠128，血浆的渗透268，尿的渗透620，尿的钠55，在三周前开始的噻嗪上，临床上等容量。给出两个候选的机制与有鉴别力的病史。
::: solution
**噻嗪诱导的低钠（[[pharmacology/adverse-reactions]]的经典：被损坏的稀释的节段（[[renal/tubular-function]]的钠氯的共转运体）加上轻容量介导的血管加压素加上高的水的摄入）对抗利尿的激素的不当的分泌（药物与特发的等容量的图形）；尿的检查会重叠，所以鉴别者就是时间线（开始之后的周）、盐的浪费的体征（亚临床容量的耗竭与尿酸及尿素和血细胞比容的上升）对照抗利尿的激素不当的分泌的低尿酸与低尿素的稀释的图形，以及对停药加轻容量补充的反应（[[#def-hyponatraemia]]）。老的年龄与低的身体质量和高的水的摄入会完成这个经典的档案（[[geriatrics-palliative/polypharmacy ]]）。**
:::
:::

::: exercise 写下抗利尿的激素不当的分泌的检查 {level=2}
确认抗利尿激素的不当的分泌意味着排除模仿。在一位80岁的人中列出它们与每一个的检查。
::: solution
**甲状腺（促甲状腺的激素——[[endocrine/thyroid]]的黏液性水肿的低钠是一个罕见而便宜的检查）、肾上腺（上午九时的皮质醇与促肾上腺激素的测定和兴奋的试验——[[endocrine/adrenal]]的继发肾上腺的功能不全的细节与低的激素的陷阱）、肾（肌酐与估计的滤过率和尿的沉渣——[[renal/chronic-kidney-disease]]）、利尿剂停止并重复——[[#ex-hypo]]；在不确定中的尿利尿剂的筛查（[[renal/tubular-function]]的利尿剂模仿的告诫）、低的溶质的摄入（日的历史——饮食的表型与[[gastrointestinal/clinical-nutrition]]的白蛋白）、以及药物（抗抑郁与抗癫痫和镇痛及抗肿瘤的审查[[pharmacology/adverse-reactions]]）；再加上容量的评估与尿的渗透和钠。只有在被排除之后，这个诊断与影像（在这些不典型的病例中的胸与垂体的成像[[clinical-skills/medical-imaging]]）才是合理的。**
:::
:::

::: exercise 规划纠正 {level=2}
慢性的钠118（时间不明，轻的症状），体重60公斤，而在液体限制的十二小时之后这位患者排尿1.8升的稀释的尿。正在发生什么，以及这两个管理的选项是什么？
::: solution
**这个血管加压素的刺激正在消失（药物或容量或恶心被移除）：稀释的尿会排出自由的水，而钠可以比限度更快飙升——危险的过度纠正[[#warn-correction]]。这两个选项：（i）替换自由的水（口服或低渗的液体以匹配尿的输出，带着每二到四小时的钠）；或（ii）把尿与钠一起钳夹（去氨加压素的剂量加高渗的盐的计划，一个在内分泌的指导下被使用的策略），并停止液体的限制（它现在会隐藏输出）。数字：每二十四小时8到10的上限；一个预先写好在超过时下降的指令；以及在夜间的复查。**
:::
:::

::: exercise 计算缺失 {level=2}
一位70公斤的男性钠为154。计算自由的水的缺失并设计最初的24小时（路径、液体、监测），假设吞咽完整。
::: solution
**自由的水的缺失约等于体重的0.4到0.5乘以（被测量的钠除以140再减一）：在70公斤时0.5乘以上升的比值，约4升的缺失；在两到三日中替代一半加持续的损失（口服的水为首选，通过鼻管或在无法使用时使用葡萄糖的水，钠的每小时不超过10）；每四到六小时的钠与尿的输出与液体平衡；并寻找原因（进入的水的缺失对不显性的损失对溶质的利尿[[#def-hypernatraemia ]]）。把容量缺失先用等张的液体来纠正，然后计算水。**
:::
:::

::: exercise 不足充盈还是过多的充盈 {level=2}
分配这个机制与首选的钠的处理的策略：(a) 失代偿的肝硬化带腹水；(b) 抗中性粒细胞血管炎的肾小球肾炎；(c) 一个错过治疗透析的患者；(d) 微小病变的复发。
::: solution
**（a）不足充盈：因为肝的被降低的有效动脉的血容量，钠被继发性地保留——盐和抗醛固酮的利尿剂及对难治的腹水的穿刺的引流，避免过快的利尿（[[gastrointestinal/liver-disease]]与[[renal/acute-kidney-injury]]的肝肾）；（b）肾的钠的潴留带一个被充压的循环：袢的与疾病的治疗和肾的替代如果肾的功能崩溃（[[musculoskeletal/connective-tissue-vasculitis]]与[[renal/chronic-kidney-disease]]）；（c）没有肾的功能：钠与水只能通过透析移除（超滤的目标与剂量的安排和依从性[[renal/chronic-kidney-disease ]]）；（d）被降低的胶体的与肾的潴留：袢的利尿剂与这个基础疾病的类固醇和血管紧张素的阻断（[[renal/chronic-kidney-disease]]）。共同的这线程：在水肿状态中的钠的治疗就是这个机制被识别；而利尿剂的速度被血浆的补充的速率限制。**
:::
:::

::: exercise 马拉松的完成者 {level=3}
一位马拉松的跑者在喝了惯常的八瓶以及运动的饮料之后带着意识混乱倒下；体重上升了2.5公斤。解释这个病理生理、这个紧急的治疗与这个预防的信息。
::: solution
**运动相关的低钠血症：在血管加压素非渗透的刺激（疼痛与恶心和应激与药物）下过量饮水会超过肾的稀释的能力，而盐的损失帮较少[[emergency-critical-care/acute-assessment]]与[[gastrointestinal/clinical-nutrition]]。体重在赛后上升2.5公斤意味着水被保留，而不是被缺失。紧急：脑水肿的症状——高渗盐紧急的小的剂量，带一个钠的每小时的有控制的上升，以及转运和重复的钠（癫痫的发作与呼吸的窘迫是风险）。预防的消息：按口渴喝；体重变化的指导（避免在运动中增加体重）；以及在长的事件中更少的饮料而不是更多——而不是盐的片剂的神话。鉴别：高钠的脱水与热射病（一个干燥与热的跑者与高的钠）和心脏的事件：钠与液体会分岔[[endocrine/hypothalamus-pituitary]]。**
:::
:::

::: exercise 设计钠安全的整套 {level=3}
设计一个全院钠异常安全的程序：处方的默认、监测的规则、交接的标准，以及审计的指标。
::: solution
**处方的默认：让低渗维持的液体成为对成人的例外并需要理由（住院低钠伤害的文献[[clinical-skills/patient-safety]]）；在噻嗪与抗抑郁药的处方上附上钠的检查；液体的图表在入院时带着风险的重新评估。监测的规则：在钠异常时一个写好纠正的方案（限度与检查和一名被点名的医生和夜间复查）；一个过度纠正自动的警报（在二十四小时的上升超过8时）与一个下降的指令（去氨加压素或糖的水）；每四到六小时钠在严重的情形中；以及在开药前对肾的剂量的检查[[pharmacology/dosing-principles]]。交接的标准：在病房与交班的检查单上的钠与计划的检查（[[clinical-skills/records-handover ]]）。审计的指标：医源性的低钠与过度的纠正的比率、手术后的伤害、护理之家的高钠的事件（[[geriatrics-palliative/ageing-frailty]]）、记录上的限度、以及死亡或伤害的审查。治理：一个钠多学科的路径（肾与药学和重症）、把异常按急性的与慢性的编码，以及把病例作为安全的学习被发表。**
:::
