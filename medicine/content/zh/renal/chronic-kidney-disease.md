慢性肾脏病（CKD）常见，通常无症状，且大多由本身就很常见的疾病引起：糖尿病、高血压和血管疾病。在许多高收入国家，约十分之一的成人有某种程度的CKD，其中大多数处于早期，许多人并不知道。只有一小部分人最终需要透析或肾移植。更多的人会先发生心肌梗死或卒中，因为CKD成倍增加心血管风险。

照护目标由此自然得出。在高危人群中测定eGFR和尿白蛋白，以早期发现CKD。通过控制血压和使用保护肾脏的药物延缓其进展。降低心血管风险。处理随肾功能下降而出现的并发症：贫血、骨与矿物质紊乱、酸中毒、高钾血症和液体过负荷。并提前规划，使走向肾衰竭的人能有充分的准备时间，在透析、肾移植和保守治疗之间作出选择。

本课时还讨论引起CKD、有时引起急性肾损伤的肾小球疾病，以及透析和肾移植的原则。它以[[renal/filtration]]中的GFR和白蛋白尿以及[[renal/acute-kidney-injury]]为基础。肾小球肾炎的免疫机制见[[immunology/autoimmunity]]，移植免疫学见[[immunology/transplant-tumour-immunology]]。全课时的英国参考是NICE指南NG203（2021），并参照KDIGO 2024 CKD指南。

## 定义与分类

::: definition 慢性肾脏病 {#def-ckd}
**慢性肾脏病**是肾脏结构或功能异常，持续**超过3个月**，并对健康有影响。诊断依据为下列任一项：

- **GFR低于60 mL/(min·1.73 m²)**，或
- 一项或多项**肾损伤标志**：白蛋白尿（ACR 3 mg/mmol或以上）、尿沉渣异常（如肾源性持续血尿）、肾小管疾病引起的电解质或其他异常、组织学或影像学异常（如多囊肾），或肾移植史。

CKD按**病因、GFR分级和白蛋白尿分级**分类（CGA分类）：

| GFR分级 | eGFR（mL/(min·1.73 m²)） | 描述 |
|---|---|---|
| G1 | 90或以上 | 正常或升高 |
| G2 | 60～89 | 轻度下降 |
| G3a | 45～59 | 轻至中度下降 |
| G3b | 30～44 | 中至重度下降 |
| G4 | 15～29 | 重度下降 |
| G5 | 低于15 | 肾衰竭 |

| 白蛋白尿分级 | ACR（mg/mmol） | 描述 |
|---|---|---|
| A1 | 低于3 | 正常至轻度增高 |
| A2 | 3～30 | 中度增高 |
| A3 | 高于30 | 重度增高 |

只有同时存在肾损伤标志时，G1和G2才算作CKD。
:::

一个人进展和发生心血管事件的风险随GFR降低和白蛋白尿增加而升高。G3a A1者的风险远低于G3a A3者。这就是白蛋白尿总要与eGFR同时测定的原因。在英国，NICE建议对CKD G3～G5患者用肾衰竭风险方程（使用年龄、性别、eGFR和ACR）估算**5年肾衰竭风险**。

英国成人CKD的**病因**包括糖尿病肾病（肾衰竭最常见的病因）、高血压和肾血管疾病、肾小球肾炎、常染色体显性多囊肾病、慢性肾盂肾炎和反流性肾病、梗阻性尿路病，以及药物（锂剂、长期使用非甾体抗炎药、钙调磷酸酶抑制剂）。在许多老年人中病因不明，CKD反映的是血管老化、既往AKI和累积的损伤。

**谁应该检测？**NICE建议对以下人群检测eGFR和ACR：糖尿病、高血压、既往AKI、心血管疾病、尿路结构性疾病、可累及肾脏的多系统疾病（如狼疮）、痛风、有肾衰竭或遗传性肾病家族史者，以及服用锂剂等肾毒性药物的人。

## CKD为什么会进展

::: theorem 适应性高滤过与进展 {#thm-hyperfiltration}
肾单位丧失后，剩余肾单位通过升高肾小球压力和血流来增加自身的滤过（**单个肾单位高滤过**）。这在一段时间内维持了总GFR，却损伤了剩余的肾小球，引起蛋白尿和硬化，导致进一步的肾单位丧失。因此，一旦丧失的肾单位达到临界数量，即使最初的病因已经去除，CKD也倾向于进展。
:::

::: proof
肾单位丧失后，血管紧张素Ⅱ和其他信号使存活肾单位的入球小动脉比出球小动脉扩张得更多，于是肾小球毛细血管压力和血流升高，每个存活的肾小球都增大。20世纪80年代初，布伦纳（Barry Brenner）及其同事在切除大部分肾组织的大鼠中进行实验，证明残余肾小球出现高滤过随后发生硬化，而降低肾小球压力（用低蛋白饮食，后来用ACE抑制）可延缓损伤。高压牵拉并损伤足细胞，而足细胞不能分裂补充。经受损肾小球漏出的蛋白质被近端小管细胞摄取，触发间质的炎症和纤维化。间质纤维化与GFR丧失的相关性比肾小球损伤更密切。每一步都会损失更多肾单位，增加剩余肾单位的负荷。
:::

这解释了主要的肾脏保护治疗。**控制血压**降低传递到肾小球的压力。**ACE抑制剂和血管紧张素受体阻滞剂**扩张出球小动脉，特异性地降低肾小球压力，从而减少白蛋白尿。**SGLT2抑制剂**增加到达致密斑的钠，恢复管球反馈并收缩入球小动脉。这两类药物在最初几周都会引起eGFR小幅、预期中的下降，这是肾小球压力下降的标志，随后长期的下降速度减慢。

## 延缓进展与降低心血管风险

与NICE NG203和KDIGO 2024一致的主要干预措施如下。药物选择和阈值按现行指南应用于个体。

- **血压。**对CKD且ACR低于70 mg/mmol者，NICE建议诊室血压目标低于140/90 mmHg（收缩压目标范围120～139）；ACR为70 mg/mmol或以上者，低于130/80 mmHg（收缩压120～129）。KDIGO建议在可耐受时，以标准化条件测量的收缩压低于120 mmHg为目标。衰弱者的目标应个体化。
- **ACE抑制剂或血管紧张素受体阻滞剂**（不可二者合用），滴定至可耐受的最大许可剂量，适用于ACR高于3 mg/mmol的CKD合并糖尿病者、ACR高于30 mg/mmol的高血压者，以及任何ACR为70 mg/mmol或以上者。开始用药或加量之前及之后1～2周检查血钾和肌酐。
- **SGLT2抑制剂**（如达格列净或恩格列净）。大型试验（CREDENCE、DAPA-CKD、EMPA-KIDNEY）显示，无论是否合并糖尿病，CKD患者的进展均减慢，心血管事件减少。NICE建议用于ACR高于30 mg/mmol的2型糖尿病合并CKD者，ACR较低时也可考虑；NICE技术评估把其使用扩展到许多非糖尿病患者。KDIGO 2024建议用于eGFR 20或以上且ACR约22.6 mg/mmol（200 mg/g）或以上、或合并心力衰竭的人。
- **非奈利酮**（finerenone），一种非甾体盐皮质激素受体拮抗剂，可减少伴白蛋白尿的2型糖尿病的进展，需监测高钾血症。
- **他汀类**：建议在CKD中使用阿托伐他汀进行心血管疾病的一级和二级预防。
- **生活方式**：戒烟、体力活动、健康体重、限盐。避免极高蛋白饮食；低蛋白饮食只在专科营养师监督下使用。
- **避免伤害**：尽量避免非甾体抗炎药，按肾功能调整药物剂量，提供患病日指导，接种流感和肺炎球菌疫苗，即将透析者接种乙肝疫苗。

::: example CKD门诊的一次复查 {#ex-progression}
一名64岁南亚裔男性患2型糖尿病和高血压。eGFR 41 mL/(min·1.73 m²)，一年来稳定；ACR 48 mg/mmol。服用氨氯地平时血压146/88 mmHg。HbA1c 62 mmol/mol。他服用二甲双胍，并因背痛服用布洛芬，且吸烟。对他的CKD进行分类并概述计划。
::: solution
**分类**：G3b A3，很可能是糖尿病肾病。他进展和发生心血管事件的风险都很高。

**计划**，遵循现行指南：
- **停用布洛芬**，改用其他镇痛方法。
- **开始ACE抑制剂或血管紧张素受体阻滞剂**（糖尿病且ACR高于3即有指征），滴定至最大耐受剂量，1～2周后检查血钾和肌酐。肌酐升高不超过30%是可以接受的。
- **加用SGLT2抑制剂**，它也有助于控制血糖；若白蛋白尿持续且血钾允许，以后可考虑非奈利酮。
- **血压**：他的ACR低于70，所以NICE目标是低于140/90；ACE抑制剂与氨氯地平合用应能达到。
- **二甲双胍**：按产品说明书继续使用与其eGFR相适应的减量剂量。
- **他汀类**：阿托伐他汀。
- **戒烟**支持。
- 计算他的5年肾衰竭风险，至少每6个月复查eGFR和ACR。若ACR升至70或以上（除非可由糖尿病解释且已得到恰当治疗）、eGFR快速下降，或5年肾衰竭风险超过5%，则转诊肾内科。
:::
:::

## CKD的并发症

随着GFR下降，肾脏的其他功能也随之衰竭。它生成的促红细胞生成素和骨化三醇减少，排出的磷、酸和钾减少，并丧失调节钠和水排泄的能力。

::: definition CKD的并发症 {#def-complications}
- **贫血**：主要由**促红细胞生成素**生成减少引起，铁缺乏和炎症也起作用。eGFR低于约30～45时变得常见。为正细胞正色素性贫血。
- **CKD–矿物质和骨异常**（CKD-MBD）：磷潴留使**FGF23**升高、骨化三醇降低；钙吸收减少；**PTH**升高（继发性甲状旁腺功能亢进症）。结果是骨病（肾性骨营养不良），以及更重要的**血管钙化**，后者促进心血管疾病。
- **代谢性酸中毒**：铵排泄减少导致碳酸氢根降低，加速肌肉和骨量丢失，并可能加快CKD进展。
- **高钾血症**，ACE抑制剂和其他药物会使其加重。
- **钠水潴留**：高血压和水肿。
- 晚期CKD的**尿毒症症状**：乏力、瘙痒、恶心、食欲差、不安腿、认知迟缓，以及如今已少见的心包炎和脑病。
- **心血管疾病**：CKD的首要死因。
- **药物处置改变**：经肾清除的药物蓄积。
:::

**贫血**的检查包括铁状态和排除其他病因。在CKD中，铁缺乏的定义比通常宽松（例如铁蛋白低于100 µg/L，或转铁蛋白饱和度低于20%），因为炎症会升高铁蛋白。首先补铁，晚期CKD常静脉补铁。然后使用**红细胞生成刺激剂**（促红素、达依泊汀），目标血红蛋白约**100～120 g/L**（NICE NG8）。试验中以正常血红蛋白为目标增加了卒中和其他心血管事件，这就是有意把目标设定在正常以下的原因。较新的口服低氧诱导因子脯氨酰羟化酶抑制剂可刺激机体自身的促红细胞生成素。

**CKD-MBD**的处理包括限制饮食中的磷，然后随餐服用**磷结合剂**；治疗维生素D缺乏；对持续的继发性甲状旁腺功能亢进症，使用活性维生素D类似物、拟钙剂（西那卡塞）或行甲状旁腺切除术。

**酸中毒**：NICE建议对eGFR低于30且血清碳酸氢根低于20 mmol/L的人考虑口服碳酸氢钠。

::: warning 药物与CKD {#warn-drugs}
CKD中许多药物不良事件是可以预见的。经肾清除的药物（某些抗生素、加巴喷丁类、低分子量肝素、直接口服抗凝药、地高辛、锂剂、二甲双胍、磺脲类）随GFR下降而蓄积；剂量按产品说明书调整，常使用Cockcroft–Gault肌酐清除率和实际体重。有些药物有肾毒性（非甾体抗炎药、氨基糖苷类）。有些引起高钾血症（ACE抑制剂、血管紧张素受体阻滞剂、盐皮质激素拮抗剂、甲氧苄啶）。吗啡等阿片类药物的活性代谢产物会蓄积，引起嗜睡和呼吸抑制。晚期CKD时药师审查用药很有价值（[[pharmacology/dosing-principles]]）。
:::

## 肾衰竭：透析、肾移植与保守治疗

当eGFR降至15～20左右、预计一年左右会发生肾衰竭时，就开始做准备。向患者介绍所有选择，并支持他们选择适合其生活和价值观的方案。

::: definition 肾脏替代治疗 {#def-rrt}
**血液透析**在体外循环中通过半透膜弥散清除溶质，并通过超滤清除液体。通常每周三次，每次约四小时，在透析中心或家中进行。最好的血管通路是**动静脉内瘘**，需提前数月手术建立以便其成熟；人工血管和中心静脉导管的感染和血栓发生率较高。

**腹膜透析**以腹膜作为透析膜。透析液经导管注入腹腔，留置平衡后引流出来，可由患者每天数次手工进行（持续非卧床腹膜透析），或由机器在夜间进行（自动化腹膜透析）。它在家中进行，能很好地保留残余肾功能；主要并发症是腹膜炎，以及多年后腹膜功能丧失。

**保守性肾脏管理**是不透析的积极治疗：处理症状、液体、贫血和其他并发症，并为生命终末期做计划。对于某些患多种疾病的老年人，透析可能无法有意义地延长生命，反而增加沉重的治疗负担，因此保守治疗是与患者共同作出的合理选择。
:::

开始透析的决定依据症状和并发症，而不是单一的eGFR数值。在IDEAL试验（2010）中，计划在eGFR 10～14 mL/min时早期开始透析，与在5～7 mL/min时晚期开始相比，并未改善生存率或其他结局，而晚期组的大多数人是在出现症状时开始的。

::: quiz {#quiz-access}
一名58岁女性CKD G4，eGFR每年下降6 mL/(min·1.73 m²)，已选择血液透析。她目前的eGFR为18。现在最重要的是安排哪一步？
- [ ] 置入带隧道的中心静脉导管
- [x] 转诊建立动静脉内瘘，保护非优势手臂的静脉
- [ ] 立即开始透析
- [ ] 12个月后复查eGFR
::: solution
内瘘需要数周到数月才能成熟，所以要在需要之前建立，通常在预计6～12个月内发生肾衰竭时。拟建内瘘手臂的静脉应避免穿刺置管和抽血。经中心静脉导管开始透析与更多感染和较差结局相关。没有症状或并发症时现在开始透析没有指征，而等待12个月则可能在没有通路的情况下需要紧急透析。
:::
:::

::: example 浑浊的透析袋 {#ex-peritonitis}
一名61岁男性接受持续非卧床腹膜透析，他发现引流液浑浊，并有轻度腹痛。他没有脓毒症表现。可能的诊断是什么？如何确诊？治疗原则是什么？
::: solution
腹膜透析患者出现浑浊的透出液伴腹痛，在被证明是其他原因之前都应视为**腹膜透析相关腹膜炎**。确诊方法是将透出液送检白细胞计数（留腹至少两小时后，每微升超过100个细胞且中性粒细胞超过50%）和培养。病原体通常是交换操作时接触污染进入的皮肤细菌（凝固酶阴性葡萄球菌、金黄色葡萄球菌），较少见的是肠道细菌。

治疗按ISPD指南和当地方案，**腹腔内给予抗生素**，同时覆盖革兰阳性和革兰阴性菌，获得培养结果后调整。大多数发作可以缓解。复发性或真菌性腹膜炎通常需要拔除腹膜透析导管。应与他一起检查交换操作技术，以防复发。
:::
:::

::: definition 肾移植 {#def-tx}
对于大多数能耐受手术的肾衰竭患者，**肾移植**是最好的治疗：与继续透析相比，它带来更长的生存期和更好的生活质量。肾脏来自**活体供者**（亲属、伴侣、朋友或利他捐献者）或**已故供者**。活体供肾通常工作时间更长。在需要透析之前进行的移植（**抢先**移植）效果最好。

移植肾置于髂窝，与髂血管和膀胱相连。受者需要终身**免疫抑制**，通常为一种钙调磷酸酶抑制剂（他克莫司）、一种抗增殖药（吗替麦考酚酯），以及在许多中心使用的糖皮质激素。主要的长期问题是**排斥反应**、**感染**（巨细胞病毒、BK多瘤病毒、机会性感染）、**癌症**（尤其是皮肤癌和移植后淋巴组织增生性疾病）、心血管疾病和药物毒性。
:::

::: example 移植后四个月肌酐上升 {#ex-transplant}
一名45岁女性四个月前接受了已故供者肾移植。她的肌酐从稳定的110升至165 µmol/L。她感觉良好。他克莫司浓度在目标范围内。尿液无感染证据。列出主要可能性和关键检查。
::: solution
移植受者肌酐持续升高50%是**移植肾功能障碍**，需要及时检查。主要可能性有：

- **急性排斥反应**，T细胞介导或抗体介导（检测供者特异性抗体）；
- **钙调磷酸酶抑制剂毒性**（血药浓度在目标范围内时可能性较小，但仍有可能）；
- **BK多瘤病毒肾病**，典型发生于第一年内，通过检测血中BK病毒发现；
- **梗阻**（超声）或**移植肾动脉狭窄**（多普勒超声）；
- 脱水等**肾前性**原因；
- 原发病**复发**。

检查：复查肌酐、超声加多普勒、BK病毒PCR、供者特异性抗体，通常还需要**移植肾活检**，这是确诊性检查。治疗取决于病因：排斥反应增加免疫抑制，BK病毒肾病则减少免疫抑制。正确诊断很重要，因为治疗方向截然相反。
:::
:::

## 肾小球疾病

肾小球疾病损伤滤过屏障。它们大致表现为两种模式，不过许多疾病兼有二者的特征。

::: definition 肾病综合征与肾炎综合征 {#def-gn}
**肾病综合征**是大量蛋白尿（每天超过约3 g，PCR高于约300 mg/mmol）伴**低白蛋白血症**（白蛋白低于约30 g/L）和**水肿**，通常伴高脂血症。它由足细胞或GBM损伤引起，炎症不明显。其并发症包括静脉和动脉血栓形成（抗凝蛋白丢失、凝血因子升高）、感染（免疫球蛋白丢失）和高脂血症。

**肾炎综合征**由肾小球炎症引起：血尿伴红细胞管型、蛋白尿（通常未达肾病范围）、高血压、水肿，以及GFR下降伴尿量减少。GFR在数天到数周内下降、活检见新月体时，称为**急进性肾小球肾炎**（RPGN），是内科急症。

| 疾病 | 典型模式 | 主要特征 |
|---|---|---|
| 微小病变病 | 肾病综合征 | 儿童最常见的病因；光镜正常，足突消失；通常对糖皮质激素有效 |
| 局灶节段性肾小球硬化 | 肾病综合征 | 原发性、遗传性，或继发于肥胖、肾单位数量减少、HIV；有进展风险 |
| 膜性肾病 | 肾病综合征 | 白人成人最常见的原发性病因；大多数原发病例抗PLA2R抗体阳性；与癌症、药物、乙肝和狼疮相关 |
| 糖尿病肾病 | 肾病综合征或白蛋白尿 | 长期糖尿病，常伴视网膜病变 |
| 淀粉样变性 | 肾病综合征 | AL型（轻链）或AA型（慢性炎症） |
| IgA肾病 | 肾炎综合征，常表现为血尿 | 全世界最常见的原发性肾小球肾炎；咽部感染后1～2天出现肉眼血尿 |
| 感染后肾小球肾炎 | 肾炎综合征 | 链球菌咽部或皮肤感染后1～3周；C3低；儿童大多恢复 |
| ANCA相关血管炎 | RPGN | 抗PR3或抗MPO抗体；可累及肺、上呼吸道、皮肤 |
| 抗GBM病 | RPGN | 针对Ⅳ型胶原的抗体；伴肺出血时称为Goodpasture病 |
| 狼疮性肾炎 | 两者皆可 | 按活检分类；补体低，抗dsDNA阳性 |
:::

检查包括尿镜检、ACR和PCR、肾功能、补体（C3、C4）、抗核抗体和抗dsDNA抗体、ANCA、抗GBM抗体、抗PLA2R、血清游离轻链和蛋白电泳、乙肝、丙肝和HIV血清学，大多数成人还需**肾活检**。表现典型的肾病综合征儿童通常不做活检即用糖皮质激素治疗，因为大多数是微小病变病。

::: example 腿肿和泡沫尿 {#ex-nephrotic}
一名52岁男性双腿肿胀六周，注意到尿中有泡沫。血压138/84 mmHg。尿PCR 820 mg/mmol（约8 g/天），白蛋白18 g/L，胆固醇9.8 mmol/L，eGFR 72。尿镜检未见红细胞管型。抗PLA2R抗体强阳性。请解读并概述处理原则。
::: solution
**肾病综合征**：大量蛋白尿、低白蛋白血症、水肿和高脂血症。成人肾病综合征伴抗PLA2R抗体阳性强烈提示**原发性膜性肾病**；针对足细胞磷脂酶A2受体的抗体在足细胞下形成免疫沉积物。有些中心接受高滴度作为无需活检的诊断依据。仍应考虑与年龄相适应的癌症筛查，因为膜性肾病可继发于癌症。

**支持治疗**：袢利尿药和限盐治疗水肿；ACE抑制剂或血管紧张素受体阻滞剂减少蛋白尿；他汀类；并评估血栓风险，因为白蛋白如此低的膜性肾病发生静脉血栓（包括肾静脉血栓）的风险很高，常考虑预防性抗凝。

**特异性治疗**：有些人可自发缓解，因此要监测抗体水平和蛋白尿。进展风险高者在专科指导下接受免疫抑制治疗，常用**利妥昔单抗**，并以抗PLA2R水平为指导。
:::
:::

::: history
1943年，在被占领的荷兰，科尔夫（Willem Kolff）用香肠肠衣和一个类似洗衣机的水槽制造了转鼓式透析器。他的头几位患者大多死亡，但1945年一名急性肾衰竭女性在透析后康复，证明了这一原理。长期透析需要可反复使用的血管通路；1960年西雅图的斯克里布纳（Belding Scribner）发明了连接动脉和静脉的特氟龙分流管，1966年西米诺（James Cimino）、布雷西亚（Michael Brescia）等人描述了今天仍为首选的手术建立的动静脉内瘘。1954年12月23日，在波士顿的彼得·本特·布里格姆医院，默里（Joseph Murray）团队与梅里尔（John Merrill）和泌尿外科医生哈里森（Hartwell Harrison）一起，在同卵双胞胎罗纳德·赫里克（Ronald Herrick）和理查德·赫里克（Richard Herrick）之间进行了肾移植。由于双胞胎基因相同，没有发生排斥反应，理查德又活了八年。默里分享了1990年诺贝尔生理学或医学奖。后来，由林福坤（Fu-Kuen Lin）于1985年克隆、并由埃施巴赫（Joseph Eschbach）等人于1987年证明能纠正透析患者贫血的重组人促红细胞生成素，替代了肾脏的一种激素功能。
:::

## 后续内容

高血压作为CKD的病因和后果见[[cardiovascular/hypertension]]。糖尿病肾病属于[[endocrine/diabetes-complications]]。血管炎和狼疮见[[musculoskeletal/connective-tissue-vasculitis]]。器官分配的伦理见[[medical-ethics-law/justice-resources]]，关于保守治疗的决策见[[geriatrics-palliative/end-of-life-care]]。

::: summary
- CKD：肾脏结构或功能异常超过3个月；eGFR低于60或有肾损伤标志，如ACR 3 mg/mmol或以上。按病因、GFR分级（G1～G5）和白蛋白尿分级（A1～A3）分类。
- 风险随eGFR降低和ACR升高而增加；肾衰竭风险方程估算5年肾衰竭风险。
- 存活肾单位高滤过，起初维持了GFR，却驱动进展；降低肾小球压力的治疗可延缓进展。
- 肾脏保护：控制血压、ACE抑制剂或血管紧张素受体阻滞剂、SGLT2抑制剂、伴白蛋白尿的2型糖尿病使用非奈利酮、他汀类、戒烟、避免非甾体抗炎药。
- 并发症：贫血（先补铁再用ESA，目标血红蛋白约100～120 g/L）、CKD-MBD（磷、PTH、血管钙化）、酸中毒、高钾血症、液体过负荷、心血管疾病、药物蓄积。
- 肾衰竭的选择：血液透析（首选内瘘）、腹膜透析、肾移植（对大多数能耐受者最好）和保守治疗；依据症状而非eGFR数值开始透析。
- 肾病综合征（蛋白尿超过3 g/天、白蛋白低于30 g/L、水肿）与肾炎综合征（血尿伴管型、高血压、GFR下降）；RPGN是急症。
:::

## 习题

::: exercise CKD分级 {level=1}
给出下列情况的GFR分级和白蛋白尿分级：(a) eGFR 38，ACR 12 mg/mmol；(b) eGFR 78，ACR 1.5 mg/mmol，超声示多囊肾；(c) eGFR 52，ACR 1.2 mg/mmol，间隔四个月测定两次；(d) eGFR 22，ACR 160 mg/mmol。
::: solution
(a) G3b A2。(b) G2 A1；因为影像显示结构损伤，所以属于CKD。(c) G3a A1；因为eGFR低于60已超过3个月，所以属于CKD。(d) G4 A3；风险极高，而且ACR 70或以上本身就是转诊肾内科的理由。
:::
:::

::: exercise 距肾衰竭的年数 {level=1 check="(45-15)/5"}
一名女性eGFR为45 mL/(min·1.73 m²)，并以每年5 mL/(min·1.73 m²)的速度稳定下降。若这一速度按直线持续，多少年后她的eGFR降到15？
::: solution
$(45 - 15)/5 = 6$年。若治疗使下降速度减半至每年2.5，时间就加倍到12年。一年内下降超过15 mL/(min·1.73 m²)，或12个月内持续下降25%或以上并伴分级改变，本身就是NICE转诊肾内科的标准。
:::
:::

::: exercise 肾病综合征还是肾炎综合征 {level=1}
对下列每种表现，说明是肾病综合征还是肾炎综合征，并指出最可能的疾病：(a) 一名4岁儿童眼睑浮肿、全身水肿，白蛋白14 g/L，尿沉渣无特殊；(b) 一名9岁儿童脓疱疮后两周出现深色尿、水肿和高血压，C3低；(c) 一名67岁男性咯血，肌酐迅速上升，有红细胞管型，MPO-ANCA阳性。
::: solution
(a) 肾病综合征；**微小病变病**，通常对糖皮质激素有效。(b) 肾炎综合征；**链球菌感染后肾小球肾炎**。(c) 肾炎综合征，急进性；伴肺部受累的**ANCA相关血管炎**（显微镜下多血管炎），是需要免疫抑制治疗的急症。
:::
:::

::: exercise 处理贫血 {level=2}
一名70岁女性CKD G4，血红蛋白92 g/L，MCV 84 fL，铁蛋白85 µg/L，转铁蛋白饱和度15%。她活动后气促。概述处理她贫血的方法。
::: solution
根据情况排除贫血的其他原因（失血、维生素B12和叶酸缺乏、溶血、骨髓瘤）。按CKD标准她存在**铁缺乏**（铁蛋白低于100 µg/L，转铁蛋白饱和度低于20%），所以首先**补铁**，晚期CKD常静脉补铁，因为口服铁吸收差且耐受性较差。若补足铁后贫血仍持续，考虑使用**红细胞生成刺激剂**，目标血红蛋白约100～120 g/L。正常血红蛋白不是目标，因为试验显示较高的目标增加了卒中和心血管事件。应监测血压，因为ESA可升高血压。
:::
:::

::: exercise 选择透析方式 {level=2}
两名肾衰竭患者正在选择透析方式。(a) 一名42岁教师，希望继续工作，手部灵活，家中有支持。(b) 一名81岁男性，有严重心力衰竭、视力差和中度痴呆，独居。分别讨论其选择。
::: solution
(a) **腹膜透析**（夜间自动化腹膜透析使她白天可以工作）或**家庭血液透析**符合她的目标；还应评估她能否接受**肾移植**，若有活体供者，最好进行抢先移植，因为这能带来最好的长期结局。

(b) 透析会很困难：腹膜透析需要视力和手部灵活性，中心血液透析意味着每周三次往返，而心力衰竭会加重透析中的低血压。鉴于他的合并症，透析可能无法有意义地延长生命。**保守性肾脏管理**是值得讨论的合理选择，需要他本人和家属参与，必要时进行决策能力评估（[[medical-ethics-law/consent-capacity]]）。若他选择透析，可考虑辅助腹膜透析或中心血液透析。
:::
:::

::: exercise 区分排斥反应 {level=2}
解释为什么对肌酐上升的移植受者，区分急性排斥反应与BK多瘤病毒肾病很重要，以及如何区分。
::: solution
二者的治疗方向相反。排斥反应用**更多**免疫抑制治疗（如糖皮质激素冲击或抗体治疗），而BK肾病由免疫抑制过度引起，治疗是**减少**免疫抑制。对BK肾病增加免疫抑制会让病毒破坏移植肾；对排斥反应减少免疫抑制则会让排斥反应进展。区分方法是检测血中BK病毒DNA和**移植肾活检**：BK肾病可见病毒包涵体和SV40染色阳性，排斥反应则有特征性的炎症；供者特异性抗体支持抗体介导的排斥反应。
:::
:::

::: exercise 磷的问题 {level=3}
解释晚期CKD中从GFR下降到PTH升高和血管钙化的一系列事件。为什么CKD G3时血清磷“正常”并不能排除磷的问题？
::: solution
随着GFR下降，肾脏排磷能力下降。在血清磷升高之前，骨骼释放**FGF23**，它增加每个肾单位的磷排泄，并抑制肾脏1α-羟化酶。骨化三醇下降，肠道钙吸收减少，**PTH升高**，后者也增加磷排泄。这些激素变化使CKD G3时血清磷保持正常，代价是FGF23和PTH升高，而二者本身就与左心室肥厚和骨病相关。只有在更晚期的CKD中这些代偿才失效，磷才升高。高磷、高钙磷乘积加上钙化抑制因子丢失，促使血管平滑肌细胞向成骨样细胞转化，引起**血管钙化**，这是CKD心血管死亡的主要原因之一。所以G3期磷正常掩盖了已经激活的激素反应。
:::
:::

::: exercise 急进性肾小球肾炎 {level=3}
一名71岁女性两周来乏力、鼻出血和关节痛。肌酐410 µmol/L（六个月前正常），尿试纸隐血3+、蛋白2+，可见红细胞管型。胸片示斑片状阴影，她有咯血。讨论鉴别诊断、紧急检查和处理原则。
::: solution
**急进性肾小球肾炎伴肺出血**（肺肾综合征）。主要病因是**ANCA相关血管炎**（上呼吸道症状提示肉芽肿性多血管炎；或显微镜下多血管炎）、**抗GBM病**（Goodpasture病），较少见的是狼疮。

**紧急检查**：ANCA（PR3和MPO）和抗GBM抗体，当天出结果；补体、抗核抗体和抗dsDNA抗体；血气和血氧饱和度；在安全时尽快行**肾活检**。

**处理**：这是急症。若临床表现明确，常在活检前就开始免疫抑制治疗（大剂量糖皮质激素加利妥昔单抗或环磷酰胺）。抗GBM病使用**血浆置换**，部分重症血管炎也可考虑。支持治疗包括必要时透析，以及针对肺出血的呼吸支持。结局取决于开始治疗时残存的肾功能，这就是为什么每一位AKI不适患者都做尿试纸检查如此重要（[[musculoskeletal/connective-tissue-vasculitis]]）。
:::
:::
