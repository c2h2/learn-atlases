慢性的肾的疾病就是前面六章所开始一切的轨迹的末端：**一个进展肾单位损失的综合征，它的早期阶段是无声的，它的并发症会触及每一个器官，它的心血管的死亡会超过它的肾的，而它的最后的共同的路径——透析或移植——是医学的伟大的（不平等的）技术之一。**附在这里的是肾小球的疾病的图谱，因为肾小球的疾病会解释晚期病例的一大部分，并会把免疫学（[[immunology/autoimmunity]]）带入这一章。

本章涵盖定义与原因与进展的机制、系统的并发症、透析与移植的选项，以及肾小球的疾病的图谱。

## 这一轨迹

::: definition 慢性的肾的疾病：定义、原因与进展的引擎 {#def-ckd}
**定义：一个肾的结构或功能的异常持续超过三个月，与健康的后果相关；分期把估计的滤过率（1、2为保留而伴标志物；3a与3b；4；5）与白蛋白尿的等级（1到3）结合，因为这两个轴会独立地预测进展与死亡（这个网格）[[renal/filtration]]。原因：糖尿病（一个全球的第一）；高血压；肾小球的疾病（[[#def-gn]]）；梗阻与反流的肾病（[[renal/urinary-tract]]）；囊性的疾病（多囊[[genetics/mendelian-inheritance]]）；间质的疾病（镇痛药与锂）；血管的（缺血与栓塞[[renal/acute-kidney-injury]]）；以及遗传的（Alport与膜性的疾病[[nervous-system/sensory-systems ]]）。进展的引擎： 肾单位质量的损失会提高剩余肾单位单肾单位的负荷（入球的松弛与肾小球的高压及肥大的适应，白蛋白尿的毒性把小管间质纤维化驱动，以及素与血管紧张素及生长因子会放大瘢痕[[physiology/homeostasis-body-fluids ]]）——这就是为什么阻断剂与新的钠葡萄糖的抑制剂与非奈酮会减慢它。这些可修改的加速器：血压；蛋白尿；血糖；磷酸盐与PTH和酸中毒与钾；药物（非甾体）；吸烟与肥胖；以及反复的急的肾的损伤[[renal/acute-kidney-injury]]。测量的提醒：一个斜率比一个单一的数字更有用，而在边缘处的值上确认（胱抑素或测量的清除）会避免错误的分期[[renal/filtration]]。**
:::

::: definition 系统的并发症 {#def-complications}
**并发症就是被下降的滤过的尿毒症器官的清单：血液（贫血：促红细胞生成素的不足与铁的耗竭和炎症及短的寿命[[blood/anaemia]]，以及血小板功能障碍造成出血的倾向[[blood/haemostasis-bleeding]]）；骨与矿物（磷酸盐潴留与成纤维细胞生长因子的升高会把PTH与维生素D的缺乏驱动，产生高转换与低转换的骨病与血管的钙化[[renal/potassium-calcium-phosphate]]与[[endocrine/bone-calcium]]）；钾与酸碱（四型肾小管的酸中毒与高钾[[renal/acid-base-disorders]]）；水与钠（钠的潴留与水肿与高血压和肺的膨胀[[renal/water-sodium]]与[[cardiovascular/heart-failure]]）；心血管（死亡的主要原因：左室的肥大与硬化的疾病及钙化的瓣膜和心包炎[[cardiovascular/valve-congenital-disease]]）；神经与精神的（神经病与睡眠的障碍及意识改变[[nervous-system/dementia-neurodegeneration]]）；生殖（月经与生育力[[obstetrics-gynaecology/contraception-fertility]]）；以及皮肤（瘙痒[[musculoskeletal/skin]]）。管理：按分期监测（血液的与矿物的和酸碱的）；贫血（铁（口服或静脉）与促红细胞的生成剂药剂，带着目标，避开正常的数值[[blood/anaemia]]，以及新的口服的低氧诱导的因子的抑制剂）；矿物（磷酸盐的结合剂与饮食及活性的维生素D的类似物与钙的模拟剂[[renal/potassium-calcium-phosphate]]）；酸（碳酸氢盐）；钾（结合剂与膳食及袢[[renal/potassium-calcium-phosphate ]]）；血压与蛋白尿（阻断剂与钠葡萄糖的抑制剂及非奈酮和利尿剂[[endocrine/diabetes-complications]]、[[cardiovascular/hypertension]]）；以及脂质的与血管的预防[[cardiovascular/coronary-artery-disease]]。**
:::

::: example 优化的访问 {#ex-progression}
一位54岁在二型的糖尿病患者（滤过率42，白蛋白的比率为180，血压148/86，HbA1c 58，服用最大剂量的阻断剂与二甲双胍，吸烟）在三分钟内被评估。
::: solution
**这是这些会减慢这一条曲线干预的候选人（[[#def-ckd]]）：血压（把收缩压低于120的目标与家庭/动态的测量；一个利尿剂的加入，以及把钠降低[[cardiovascular/hypertension]]与[[renal/potassium-calcium-phosphate ]]）；蛋白尿（继续阻断剂；一个血管紧张素受体的阻断加非奈酮加入带钾的监测[[endocrine/adrenal]]）；血糖（用一个钠葡萄糖的抑制剂（一个心肾的获益）和胰高血糖素样的肽去替换或添加[[endocrine/diabetes-complications]]）；脂质的（一个他汀[[cardiovascular/coronary-artery-disease]]）；把酸与磷酸盐及钾正常化[[renal/acid-base-disorders]]、[[renal/potassium-calcium-phosphate]]；戒烟与体重[[public-health/prevention-promotion]]；避免非甾体与对比剂（[[renal/acute-kidney-injury]]、[[clinical-skills/medical-imaging]]）；以及疫苗与剂量[[immunology/vaccines-immunotherapy]]、[[pharmacology/dosing-principles]]。随访：斜率的轨迹（每三到六个月的肌酐与白蛋白的比率），以及如果在进展就转向肾科的标准（斜率快或分期4或并发症）[[renal/chronic-kidney-disease]]。**
:::
:::

## 替代与移植

::: definition 透析：决定、方式与并发症 {#def-rrt}
**决定（一个共享的决定，在分期5的前后与症状/指征之前）：生存与质量（透析会在尿毒症中挽救生命；在年老与多病的患者中它未必胜过被支持的保守的管理——一个偏好驱动的对话[[geriatrics-palliative/end-of-life-care]]与[[medical-ethics-law/consent-capacity]]）、方式（血液透析（单位的方案或家庭/夜间的方案；动力学的获益与时间的负担）；腹膜透析（一个腹膜作为膜；自主与连续性好处；禁忌：手术与疝和失效）；以及提前的移植[[#def-tx]]）与时机（不是数字，而是症状/指征[[renal/acute-kidney-injury]]的紧急）。通路（提前计划）：动静脉的内瘘（最好的：在开始时就把手臂的静脉保存下来，避开锁骨下的与外周置入中心的导管[[#quiz-access]]）、移植物、以及导管（感染与狭窄——一个应该被避免的默认）[[clinical-skills/patient-safety]]。并发症：急的（低血压与痉挛和心律失常[[cardiovascular/arrhythmias]]、管道的凝血与空气栓塞、失衡的综合征）；慢的（通路的失败与血栓，感染（败血症与心内膜炎[[infectious-diseases/healthcare-infections]]）、淀粉样变与瘙痒和贫血、血压与钙磷、抑郁与这些就业[[psychiatry/mood-disorders]]）；以及腹膜透析的（腹膜炎——浑浊的袋与疼痛（[[#ex-peritonitis]]）、出口的部位、渗漏与疝，以及膜的失败[[gastrointestinal/bowel-disease]]）。处方：剂量与超滤的目标（避免干体重错误与容量过多[[cardiovascular/heart-failure]]）、透析的充分性测量与钾与碳酸氢盐[[renal/acid-base-disorders]]、以及药物剂量的调整（被清除的药物要在透析之后给[[pharmacology/dosing-principles ]]）。**
:::

::: definition 移植：分配、免疫学与长期的随访 {#def-tx}
**结果（一个移植（活的或尸体的）胜过同年龄人群透析的生存与质量，尽管早期风险[[#def-rrt]]）与分配（等待的名单与死亡、共享的交换与这些不平等（[[public-health/determinants-inequalities]]、[[medical-ethics-law/justice-resources]]）：一个伦理与操作的双重挑战）与评估（肿瘤/感染的筛查与心血管的风险；依从性的评估与社会的支持[[psychiatry/substance-use]]；以及疫苗在之前[[immunology/vaccines-immunotherapy ]]）。免疫学：人类白细胞抗原的配型与细胞毒的抗体的交叉配合（抗供者的抗体会把超急的排斥带来[[immunology/transplant-tumour-immunology]]、[[immunology/hypersensitivity]]）、诱导与维持的方案（钙调磷酸酶的抑制剂（肾毒急性的与慢性的损害[[renal/filtration]]）与抗代谢的药（白细胞减少[[blood/anaemia]]）和激素/哺乳动物靶点的抑制剂；以及共刺激的阻断选项）；排斥的发作细胞的（肌酐的上升与活检；用激素的脉冲或抗T细胞的药剂治疗）与抗体的（供者特异性的抗体与补体的沉积，用血浆的交换与免疫球蛋白治疗）；感染（机会的：巨细胞病毒与BK的多瘤病毒（输尿管的狭窄）以及肺的肺炎和李斯特菌[[infectious-diseases/immunocompromised-host]]、[[microbiology/viruses]]）；以及肿瘤（皮肤的与淋巴增殖的疾病[[blood/lymphoma-myeloma]]、[[musculoskeletal/skin-cancer]]）。长期的：药物相互作用（钙调磷酸酶的抑制剂与唑类和大环内酯类[[pharmacology/metabolism-excretion]]）、血压与血糖与脂质的[[endocrine/diabetes-complications]]、骨（[[endocrine/bone-calcium]]）、妊娠的咨询[[obstetrics-gynaecology/pregnancy-antenatal]]、疫苗（避活的）与皮肤的和肿瘤的筛查，以及依从性支持（青少年与年轻的成人的停药是移植物损失的原因之一[[psychiatry/lifespan-psychiatry ]]）。**
:::

::: quiz {#quiz-access}
一位滤过率为16的58岁的人正在为可能的透析做准备。哪一个行动会保护未来的血液透析的通路？
- [ ] 从任一手对静脉的常规穿刺
- [x] 现在转诊做内瘘的静脉的测绘并保存前臂的静脉（保存静脉，避免外周置入中心的与锁骨下的导管）
- [ ] 一个被建立的导管以防万一
- [ ] 把肾的教育延迟到症状出现
::: solution
**内瘘需要静脉：在早期就转诊肾科以做上肢的静脉的映射，避免锁骨下与外周置入中心的导管，并使用最小的针与替代的（手背要保留）——一个被毁坏的血管床就是永久性的导管，而它们会带着感染和死亡（[[#def-rrt]]、[[clinical-skills/patient-safety]]）。**
:::
:::

::: example 第四个月的肌酐上升 {#ex-transplant}
第四个月肾的移植，肌酐从78升到124；患者报告漏服；血压150/90；环孢平的水平被记录下来在低正常；尿温和；超声正常。
::: solution
**在第一个年内一个肌酐上升两个常见的原因：药物暴露不足（漏服与相互作用）和急性的排斥；以及钙调磷酸酶抑制剂的毒性会在两端造成[[#def-tx]]。步骤：确认水平与服药的记录（相互作用的审查：唑类与大环内酯类会升高水平而利福平会降低[[pharmacology/metabolism-excretion ]]）；一个对依从性和副作用（激素与美容的担忧）的非指责的谈话[[psychiatry/lifespan-psychiatry]]；供者特异性的抗体（抗体的排斥）；以及一个移植物活检（细胞对抗体对中毒对慢性变化）——管理会分岔（激素的脉冲对血浆的交换对减少钙调磷酸酶）[[immunology/transplant-tumour-immunology]]。伴随：血压与蛋白尿（用阻断剂[[cardiovascular/hypertension]]）、感染筛查（BK与巨细胞病毒[[infectious-diseases/immunocompromised-host]]）、以及一个被记录的随访的计划，因为移植物丢失常常是丢失的联系，而不是一次灾难[[clinical-skills/records-handover]]。**
:::
:::

::: example 浑浊的袋 {#ex-peritonitis}
在腹膜透析第四个月的腹痛；流出的透析液是浑浊的；细胞计数为每毫升200个白色的细胞；无热；出口的部位正常。
::: solution
**相关的腹膜炎直到被证明别的（[[#def-rrt]]）：浑浊的袋与腹痛和每毫升超过100个白色的细胞（中性粒细胞为主）就是诊断的阈值。行动：革兰氏阳性与革兰氏阴性覆盖经验的腹腔内抗生素（中心相关的操作，带有肠的原因的双重覆盖的可能[[gastrointestinal/bowel-disease]]、[[infectious-diseases/healthcare-infections ]]）、在48小时重复细胞计数与培养（在治疗的改进）；疼痛的控制与操作的审查（出口与导管的技术，以及肠的来源：疝与便秘[[renal/urinary-tract]]）；以及失败（难治的/复发的、真菌的，或同时的导管感染）时导管的移除[[infectious-diseases/healthcare-infections]]。预防：接触的技术与消毒的数据以及出口部位的抗生素/药膏的策略；疫苗[[immunology/vaccines-immunotherapy]]；以及教育性的复核——因为腹膜炎就是住住院与技术失败首要的原因[[clinical-skills/patient-safety]]。**
:::

::: example 肿胀的肾的蛋白 {#ex-nephrotic}
一位52岁的人有五周的面部与腿的水肿和泡沫尿：白蛋白19，白蛋白的比率为1900，胆固醇11，肌酐92；肝炎与人类免疫缺陷及狼疮和糖尿病的筛查为阴性；肾的超声正常；年龄适当的癌的筛查是最新的。
::: solution
**一个肾病综合征（[[#def-gn]]）：在成人中最常见的原因是膜性的肾病与微小的病变及局灶的节段性的硬化（糖尿病的被排除）；步骤：原因的筛查被做了（自身抗体与补体和感染及副蛋白[[blood/lymphoma-myeloma]]、[[immunology/autoimmunity]]），以及一个活检（在成人中，因为管理会按组织学来分岔[[pathology/cancer-diagnosis]]）。风险的并发症：血栓（肾静脉与肺的栓塞，在白蛋白低膜性的病例中尤其（抗凝血酶的损失[[blood/thrombosis-anticoagulation]]）——在阈值之下的预防性的抗凝）；感染（肺炎球菌与腹膜炎[[immunology/hypersensitivity]]、[[infectious-diseases/healthcare-infections]]——疫苗与脾样的功能）；脂质的（他汀[[cardiovascular/coronary-artery-disease ]]）；以及水肿（袢与盐的限制，带着白蛋白的谨慎的输入[[renal/water-sodium]]）。治疗按组织学：阻断剂用于蛋白尿[[cardiovascular/hypertension]]；在指征中激素与其他免疫抑制（疾病活动的规则）[[immunology/tolerance-regulation]]；以及复发的监测[[renal/chronic-kidney-disease]]。**

## 图谱

::: definition 肾小球的疾病：工作的图谱 {#def-gn}
**表现：无症状的尿的异常（孤立的血尿与轻的蛋白尿的路径[[renal/filtration]]与[[renal/urinary-tract]]）、慢性渐进的肾炎（免疫球蛋白A与补体的疾病的缓慢的下降进入[[#def-ckd]]）、肾病性的（[[#ex-nephrotic]]的路径），以及肾炎的与急进性的紧急（血尿与蛋白尿及高血压和少尿及在数天到数周内翻倍的肌酐——当天的肾科与血清学和常常活检[[pathology/diagnostic-pathology]]与[[renal/acute-kidney-injury]]）。模式的图谱：免疫球蛋白A的肾病（感染同步的血尿与系膜的沉积；从良性的发作到快速的疾病；治疗：支持性阻断剂与靶向的释放的布地奈德/在高危者中的激素和新的内皮素与补体的[[renal/filtration]]的血尿的方法）；微小病变（儿童首位的肾病与成人发作：激素敏感的复发和钙调磷酸酶的策略[[paediatrics/acute-childhood-illness]]）；膜性肾病（磷脂酶A2受体的抗体与继发的形式（肿瘤与乙肝和药物[[musculoskeletal/connective-tissue-vasculitis]]）和风险的分期）；局灶节段性肾小球硬化（足细胞的疾病与通透性的因子）；膜增生性（补体的疾病与副蛋白[[blood/lymphoma-myeloma]]、[[immunology/hypersensitivity]]）；抗肾小球基底膜的疾病（肺的出血[[respiratory/interstitial-vascular-disease]]与急进性：血浆的交换与细胞毒的药[[immunology/hypersensitivity ]]）；ANCA相关的血管炎（肺肾的综合征；激素与环磷酰胺或利妥昔单抗和补体的阻断/避免复发[[musculoskeletal/connective-tissue-vasculitis ]]）；狼疮的肾炎（分类与分层的治疗[[immunology/autoimmunity]]与[[medical-ethics-law/consent-capacity]]的移植的）；以及补体的（非典型溶血尿毒[[renal/acute-kidney-injury]]、[[blood/haemostasis-bleeding]]）与遗传的（Alport：感音神经的耳聋与眼的[[nervous-system/sensory-systems]]、[[genetics/mendelian-inheritance]]）。共同的规则：血清学不会替代活检当管理会改变；治疗会减少炎症与蛋白尿；以及一个快速下降的曲线就是急诊[[renal/acute-kidney-injury]]。**
:::

::: history
**透析的时代从1913年的动物的血液透析与1943年的战时的人工肾、以及后续的改良开始；五与六十年代慢性血液透析的出生（分流的发明与伦理的第一次——第一个分配的委员会（神明的委员会）[[medical-ethics-law/justice-resources]]）；腹膜透析的血统（动物的工作与间断的时代，以及现代的自动的循环）；移植的突破（同卵双胞胎成功的实验与硫唑嘌呤和环磷酰胺，然后是环孢平的时代与新的方案[[immunology/transplant-tumour-immunology]]）；肾小球疾病的（免疫荧光的技术把疾病分开：膜性的与微小的病变及新月体的疾病，以及血清学的抗体（磷脂酶A2的受体与ANCA）把分类变成分子[[immunology/autoimmunity]]与[[pathology/diagnostic-pathology]]）；以及分期的框架与试验的浪潮（贫血与矿物的指南，以及把延缓进展药物的一类接一类（阻断剂、他汀，然后钠葡萄糖的抑制剂与非奈酮和新的内皮的与补体的）[[endocrine/diabetes-complications]]）。本章就是技术的胜利、分配的选择与分子的图谱的累积。**
:::

## 通向何处

滤过的测量与阈值在[[renal/filtration]]；肾小管的机制在[[renal/tubular-function]]；钠与水及钾和酸碱的管理在[[renal/water-sodium]]、[[renal/potassium-calcium-phosphate]]与[[renal/acid-base-disorders]]；急的发作与指征在[[renal/acute-kidney-injury]]；感染的宿主在[[infectious-diseases/immunocompromised-host]]；血管的疾病在[[cardiovascular/hypertension]]；药物的剂量在[[pharmacology/dosing-principles]]；以及妊娠的结局在[[obstetrics-gynaecology/pregnancy-complications]]。

::: exercise 为并发症定时 {level=2}
移植后第二个月：哪些感染会占主导？第八个月？第五年？给每一个窗口一个非感染的移植物功能不全的原因。
::: solution
**第一个月：与手术相关的（伤口的与导管的感染和泌尿道[[infectious-diseases/healthcare-infections]]）以及被供者传来的；非感染：急性肾小管的坏死/灌注的损害[[renal/acute-kidney-injury]]。一到六个月：机会性的（巨细胞病毒与BK及肺囊虫和曲霉[[microbiology/fungi-parasites]]、[[infectious-diseases/immunocompromised-host ]]）；非感染：急性的排斥与钙调磷酸酶的抑制剂毒性[[#ex-transplant]]、[[immunology/transplant-tumour-immunology]]。在六个月后：社区的（呼吸道的病毒与尿路[[renal/urinary-tract]]）与慢性的病毒的（肝炎与乳头瘤[[microbiology/viruses]]）；非感染：慢性移植物的病变（供者特异性的抗体与血管病）、复发（肾小球的[[#def-gn]]）以及肿瘤[[blood/lymphoma-myeloma]]。实践：把时间线用于预防（疾病的预防与疫苗[[immunology/vaccines-immunotherapy]]）与对发热的快速的评估[[emergency-critical-care/acute-assessment]]。**
:::

::: summary
- 慢的肾的疾病就是肾单位的损失的生理：超滤过与蛋白尿及肾小管间质的纤维化会自我持续这条斜率；血压与肾素轴的阻断、钠葡萄糖的抑制剂、非奈酮与胰高血糖素样的肽以及生活方式会把这条斜率量回来。
- 并发症是全身的：心血管的死亡会占主导；而贫血与矿物与骨的疾病及酸中毒、高钾、感染和药物的毒性各有它们自己的方案和它们自己试验的历史。
- 透析是一个决定，不是一个开关：在滤过率15到20时准备，保存手臂的静脉，与生活的目标一起选择方式，并把保守的管理作为一个真实的路径提供。
- 移植是生存的最优化治疗；排斥与病毒的碰撞，活检决定，而长期的随访是一个免疫学与肿瘤学及妊娠的程序。
- 肾小球的图谱（免疫球蛋白A与膜性的及微小的病变和局灶节段的、狼疮与血管炎及基底膜的抗体和补体的）是模式加血清学加活检的医学；治疗机制，而不是水肿。
:::

## 练习

::: exercise 把这个患者放入这个网格 {level=1}
滤过率42带白蛋白的比率90，糖尿病的肾病：给出分级、随访间隔的逻辑，以及两个进展风险的陈述。
::: solution
**3b期（滤过率30到44）伴白蛋白尿的2级的升高（中等增高的风险），因为这两个轴会相乘：这个网格就是这个预后（[[#def-ckd]]、[[renal/filtration]]）。随访：三到六个月的肌酐与白蛋白的比率与血压和家庭测量；在快速进展时更频繁。进展的陈述：斜率（每年下降到超过5就异常）；以及一个血管紧张素的阻断加一个钠葡萄糖的抑制剂并把血压和血糖降低到目标会减少两者（[[endocrine/diabetes-complications]]、[[cardiovascular/hypertension ]]）。伴随：并发症的筛查（贫血与矿物和酸碱[[#def-complications]]）、疫苗[[immunology/vaccines-immunotherapy]]，以及在阈值时转诊肾科[[renal/chronic-kidney-disease]]。**
:::

::: exercise 处理贫血 {level=2}
四期慢的肾的疾病，血红蛋白96，平均红细胞的血红蛋白量89，铁蛋白90，转铁蛋白的饱和度16%，C反应蛋白轻的升高，出血被排除：解读并排列治疗。
::: solution
**一个肾贫血的混合（促红细胞生成素的不足[[#def-complications]]）加绝对性的铁缺乏（一个低的饱和度伴一个在炎症中不令人安心正常的铁蛋白：一个低的饱和度低于20%就需要铁[[blood/anaemia]]、[[clinical-skills/laboratory-tests]]）。次序：先补铁（因为炎症口服的常常不足：静脉的）并重新检查；然后在持续的低于100-110时开始促红细胞生成剂的药剂（目标的范围，避免正常的数值与卒中的风险），带血压的监测[[cardiovascular/hypertension]]；并寻找其他的原因（维生素B12与叶酸和出血；甲状旁腺与炎症和潜在的溶血[[blood/haemoglobin-disorders ]]）。陷阱：在没有先纠正铁的情况下用药剂会失败；以及没有调查就输血（同种免疫会危害未来的移植[[immunology/transplant-tumour-immunology]]、[[blood/transfusion]]）。**

::: exercise 选择透析的故事 {level=2}
两个78岁的人：(a) 独立，射血分数降低的心衰，滤过率9伴恶心；(b) 晚期的痴呆，住在护理之家，滤过率8伴反复的住院。为每一个写下他们需要肾计划的对话。
::: solution
**（a）一个候选：一个目标的对话（时间与旅行和自主，与透析的获益）；把方式一起选择（腹膜透析可能会更好地保留功能并会避免旅行；家庭血液透析的支持[[#def-rrt]]）；提前通路（内瘘的测绘[[#quiz-access]]）；优化的并发（心脏的药物[[cardiovascular/heart-failure]]）；以及移植的评估在适当时（年龄不是绝对的禁忌[[#def-tx]]）[[geriatrics-palliative/palliative-care]]。(b一个保守的路径作为偏好的一个真实的选择：以舒适为重点的照护与症状（恶心与瘙痒和液体[[renal/potassium-calcium-phosphate]]、[[geriatrics-palliative/symptom-control]]），避开透析（在晚期的痴呆中它未必延长生存，而它会增加住院和约束[[geriatrics-palliative/end-of-life-care]]）；与家属和这个护理之家的决定；一个症状的包与升级的界限被记录[[medical-ethics-law/end-of-life-ethics]]。共同：被记录决定，在疾病时重新审议，以及同样的服务（两者都会需要钾与液体的管理[[renal/acute-kidney-injury ]]）。**

::: exercise 区分排斥 {level=2}
列出肾移植排斥的类型与它们的时机、机制和治疗，以及那个现在因为交叉配合而罕见的。
::: solution
**超急的（分钟：预存抗供者的抗体会把补体和血栓把移植物摧毁——现在被抗体的筛查与交叉配合所预防，除了紧急的脱敏的方案[[#def-tx]]、[[immunology/hypersensitivity]]）；急的细胞的（数天到数年：T细胞会浸润小管与血管；肌酐上升，活检确诊，用激素的脉冲和抗T细胞的药剂治疗，然后维持的强化[[immunology/transplant-tumour-immunology ]]）；急性抗体的（天：供者特异性的抗体会把补体把微血管损伤；用血浆的交换和免疫球蛋白以及B/浆细胞的靶向治疗）；以及慢性的（年：移植物血管病与间质的纤维化，抗体的驱动与暴露的不足；治疗就是危险因子与依从性和很少的再移植[[renal/chronic-kidney-disease ]]）。实践的规则：一个上升的肌酐永远不是正常的：确认药物水平和感染与梗阻，然后用活检来分岔[[clinical-skills/medical-imaging]]。**

::: exercise 读活检 {level=2}
把每一个活检的描述与它的疾病配对：(a) 光镜阴性，只有足细胞突起的消失（电镜），儿童；(b) 毛细血管的壁增厚带钉与穹顶及颗粒的免疫球蛋白G与抗体的阳性；(c) 系膜的免疫球蛋白A为主；(d) 线性基底膜的免疫球蛋白G；(e) 少免疫的坏死性伴新月体。
::: solution
**（a）微小病变（儿童首位的肾病；激素敏感；成人也这样[[paediatrics/acute-childhood-illness]]、[[#ex-nephrotic]]）；（b）膜性肾病（原发的与继发的形式和风险）；（c）免疫球蛋白A的肾病（[[#def-gn]]）；(d抗肾小球基底膜的疾病（肺的出血的风险与紧急的血浆的交换[[immunology/hypersensitivity]]、[[respiratory/interstitial-vascular-disease]]）；（e）ANCA相关的血管炎（激素与环磷酰胺或利妥昔单抗[[musculoskeletal/connective-tissue-vasculitis]]）。共同的模式：电子显微镜会分离出足细胞的疾病，而免疫荧光的模式（颗粒对线性对少免疫对系膜）会把诊断分开——这就是为什么一个肾的活检会是一个治疗性的决定，而不是一个标签[[pathology/diagnostic-pathology]]。**
:::

::: exercise 磷酸盐的提问 {level=2}
四期：磷酸盐1.7，甲状旁腺激素升高3倍，钙2.20，维生素D低正常，而成纤维细胞生长因子非常高。解释这一轴与治疗的目标，以及结合剂的作用与选择。
::: solution
**这一轴：被损失的肾单位会保留磷酸盐并把成纤维细胞生长因子升高，后者会促使它的排泄同时抑制维生素D的活性（低钙与继发的甲状旁腺激素的增多）；PTH会把骨的转换升高并会把磷酸盐暂时给下来（[[#def-complications]]、[[renal/potassium-calcium-phosphate]]、[[endocrine/bone-calcium]]）。目标：把磷酸盐正常化（与餐一起吃的结合剂与植物性的饮食）、维持钙正常，并把PTH降低到上升范围的附近（避开过度的抑制——低转换的骨）。结合剂：含钙的（有效但在血管的钙化中的谨慎）；这些不含钙的（碳酸镧/蔗糖的复合物，在高磷酸盐的负荷与低转换的骨中）、以及新的钠的氢的交换的阻断剂；以及活性的维生素D的类似物（带钙的监测）或在有透析者的钙的模拟剂[[#def-rrt]]。陷阱：把磷酸盐当作钙的旁系；以及在没有测量骨疾病的情况下治疗数字（骨折与钙化就是临床的终点[[renal/chronic-kidney-disease ]]）。**
:::

::: exercise 设计慢肾疾病的服务 {level=3}
设计一个地区的从病例的发现到转换与死亡的服务：人群的工作、门诊的架构、教育、队伍以及公平。
::: solution
**病例的发现：在风险登记（糖尿病与高血压和心血管的疾病，以及家族史与镇痛药及尿路的疾病）中的年度白蛋白的比率与肌酐[[public-health/screening]]、[[endocrine/diabetes-complications]]、[[cardiovascular/hypertension]]；以及急的肾的损伤后的随访[[renal/acute-kidney-injury]]。架构：把分期按风险分层（3a的门诊与4/5的专门的门诊、肾病护士与药剂师和营养的人）；血压与贫血和矿物的协议；以及清晰的标准转诊（斜率和分期及并发症/肾小球的疾病[[#def-gn]]）。教育：分期与轨迹（斜率的语言）、生病时的规则与避免的暴露[[pharmacology/adverse-reactions]]、以及在阈值时替代的教育（方式和通路[[#def-rrt]]）和提前移植的讨论[[#def-tx]]。转换：与全科医生共享的照护与记录（剂量[[pharmacology/dosing-principles]]）；在年轻人中儿科转换的项目[[paediatrics/neurodevelopment]]；以及和姑息的共同管理（保守的路径[[geriatrics-palliative/end-of-life-care]]、[[medical-ethics-law/end-of-life-ethics]]）。公平：被剥夺群体与少数群体更晚的转诊与更少的移植（[[public-health/determinants-inequalities]]、[[public-health/global-health]]）；翻译与旅行的支持；以及审计（分期与转诊时机的编码、通路的创建、移植的率、以及死亡的原因[[clinical-skills/patient-safety]]）。**
