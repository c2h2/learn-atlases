肝病是英国少数几个在二十世纪末和二十一世纪初持续上升的主要死因之一，它致人死亡的年龄比心脏病或大多数癌症都轻。三种病因占主导：酒精、与肥胖和糖尿病相关的代谢功能障碍，以及病毒性肝炎。这三种病因在很大程度上都可以预防，而且都在出现症状之前默默造成多年损害。

共同的通路是**纤维化**。反复损伤激活肝星状细胞，后者沉积胶原。经过多年，纤维化把门管区与中央静脉连接起来，肝的结构被瘢痕包绕的再生肝细胞结节所取代。这就是**肝硬化**。肝硬化有两个后果，几乎驱动了所有并发症：**门静脉高压**，因为瘢痕和扭曲的血管阻碍血流；以及**肝细胞功能衰竭**，因为能工作的细胞减少了。

本章介绍肝病的主要病因，然后是肝硬化及其并发症、急性肝衰竭和肝移植。本章以[[gastrointestinal/liver-function]]中对肝脏检查的解读为基础。

## 肝病的病因

::: definition 脂肪性、酒精相关性和药物性肝病 {#def-causes}
- **代谢功能障碍相关脂肪性肝病**（MASLD）是超过5%的肝细胞内有脂肪，伴至少一项心血管代谢危险因素（如肥胖、2型糖尿病、高血压或血脂异常），且无其他原因。其伴肝细胞损伤的炎症形式是**代谢功能障碍相关脂肪性肝炎**（MASH）。这些术语于2023年取代了"非酒精性脂肪性肝病"。
- **酒精相关性肝病**从脂肪变性到**酒精性肝炎**和肝硬化。
- **药物性肝损伤**（DILI）是由药物、草药制品或补充剂引起的肝损伤。它可以是剂量依赖、可预测的，如对乙酰氨基酚；也可以是特异质性、不可预测的，如阿莫西林-克拉维酸。
:::

### 脂肪性肝病

MASLD现在是许多国家最常见的肝病，影响约四分之一到三分之一的成年人。大多数MASLD患者只有单纯脂肪变性，永远不会发生肝脏并发症；他们的主要风险是心血管疾病。少数人发展为MASH和进行性纤维化。**纤维化分期是肝相关结局最强的预测因素**，这就是为什么[[gastrointestinal/liver-function]]中介绍的FIB-4指数和弹性成像是诊治的核心。

治疗是通过饮食和体力活动减重，并控制糖尿病、血压和血脂。减轻7～10%的体重可以减轻脂肪性肝炎，有时也能减轻纤维化。引起体重下降的药物如GLP-1受体激动剂和减重手术都有帮助。治疗MASH的特异性药物已在一些国家开始获批，其使用遵循现行指南。2023年的命名还为饮中等量酒的MASLD患者定义了**MetALD**，承认两种病因常同时存在。

### 酒精

酒精在肝内主要由乙醇脱氢酶代谢，摄入量大时还经CYP2E1代谢。两条途径都产生NADH，促进脂肪合成和脂肪变性；以及乙醛，损伤蛋白质并触发炎症。几乎所有大量饮酒者都会发生脂肪变性，戒酒后可逆转。少数人发展为肝硬化；风险随饮酒量和持续时间增加，女性、肥胖以及*PNPLA3*等遗传变异也增加风险。

**酒精性肝炎**是大量饮酒者的急性炎症性疾病：黄疸、发热、肝大伴压痛、中性粒细胞增多，AST常约为ALT的两倍，但很少超过300～400 U/L。严重程度用**Maddrey判别函数**等评分评估：

$$
\text{DF} = 4.6 \times (\text{PT}_{\text{患者}} - \text{PT}_{\text{对照}}) + \text{胆红素 (mg/dL)}
$$ {#eq-df}

DF达到或超过32提示重症，短期死亡率高。把胆红素从µmol/L换算为mg/dL，除以17.1。STOPAH试验（2015年）发现，泼尼松龙并未显著改善重症酒精性肝炎90天或1年的生存率；在经过选择的患者中可能有小的短期获益，是否使用由专科决定。戒酒、营养、治疗感染和处理酒精戒断是核心。

### 病毒性肝炎

| 病毒 | 基因组 | 主要传播途径 | 慢性感染 | 说明 |
|---|---|---|---|---|
| 甲型肝炎 | RNA | 粪-口 | 无 | 有疫苗 |
| 乙型肝炎 | DNA | 血液、性接触、母婴 | 出生时感染约90%，成人感染不到5% | 有疫苗；抗病毒药可抑制 |
| 丙型肝炎 | RNA | 血液（注射吸毒、不安全的医疗操作） | 约75% | 直接抗病毒药物治愈率超过95% |
| 丁型肝炎 | RNA | 血液 | 有 | 需要乙型肝炎病毒才能复制 |
| 戊型肝炎 | RNA | 粪-口；在欧洲经未煮熟的猪肉 | 仅见于免疫抑制者 | 妊娠期重症（基因1型和2型） |

**乙型肝炎血清学**依据几个标志物解读。**HBsAg**（表面抗原）表示现症感染；持续超过6个月则为慢性感染。**抗HBc IgM**表示近期感染。**抗HBs**表示有免疫力，可来自单纯接种疫苗（抗HBc阴性）或已清除的感染（抗HBc阳性）。**HBeAg**和**HBV DNA**反映病毒复制。当有明显的病毒复制、炎症或纤维化时，慢性乙型肝炎用替诺福韦（tenofovir）或恩替卡韦（entecavir）等核苷（酸）类似物治疗。这些药物抑制病毒但很少清除病毒，因此通常需要长期治疗。化疗或生物制剂可引起乙型肝炎再激活，因此使用前需要筛查。

**丙型肝炎**现在大多数人口服8～12周直接抗病毒药物即可治愈。WHO设定了到2030年消除病毒性肝炎这一公共卫生威胁的目标，这取决于找出许多不知道自己感染的人（[[public-health/communicable-disease-control]]）。

### 自身免疫性、胆汁淤积性和遗传性疾病

::: definition 自身免疫性、胆汁淤积性和遗传性肝病 {#def-other-causes}
- **自身免疫性肝炎**：免疫攻击肝细胞，女性更常见，ALT升高，IgG升高，抗平滑肌抗体或抗核抗体阳性。对糖皮质激素和硫唑嘌呤有反应。
- **原发性胆汁性胆管炎**（PBC）：肝内小胆管的自身免疫性破坏，主要见于中年女性，呈胆汁淤积模式，抗线粒体抗体阳性。一线治疗是熊去氧胆酸（ursodeoxycholic acid）；反应不足时使用二线药物。
- **原发性硬化性胆管炎**（PSC）：肝内外胆管的炎症和狭窄，与溃疡性结肠炎密切相关，MRCP显示"串珠样"胆管树可诊断。没有药物被证明能延缓其进展。它发生**胆管癌**和结直肠癌的风险很高。
- **遗传性血色病**：铁过载，通常由*HFE* C282Y纯合引起，转铁蛋白饱和度和铁蛋白升高。用放血治疗。
- **Wilson病**：由*ATP7B*变异引起的常染色体隐性遗传铜蓄积，累及肝和脑。用螯合剂或锌治疗。
- **α1-抗胰蛋白酶缺乏症**：错误折叠的蛋白（通常为PiZZ基因型）在肝细胞内蓄积，引起肝病，而循环水平低则引起肺气肿。
:::

::: example 沉重的铁蛋白 {#ex-haemochromatosis}
一名49岁爱尔兰裔男性乏力、手部关节痛，新诊断2型糖尿病。ALT 68 U/L。铁蛋白1,850 µg/L，转铁蛋白饱和度78%。每周饮酒8单位。基因检测显示*HFE* C282Y纯合。请解释机制、铁蛋白水平的意义和治疗原则。
::: solution
**机制。** HFE蛋白帮助肝感知铁储存并合成**铁调素**。C282Y纯合者铁调素不适当地降低，因此膜铁转运蛋白持续活跃，肠道吸收过多的铁（[[gastrointestinal/digestion-absorption]]）。多余的铁沉积在肝、胰腺、关节、心脏、皮肤和垂体。

**解读结果。** 转铁蛋白饱和度升高是最早、最特异的征象。铁蛋白反映储存铁的量，但炎症、酒精和脂肪肝也会使其升高。铁蛋白超过1,000 µg/L伴ALT升高，增加进展期纤维化或肝硬化的可能性，因此他需要用弹性成像或活检评估纤维化。他的糖尿病和关节病是铁过载的典型表现。

**治疗。** **放血**，每次约450～500 mL，开始时每周一次，之后减少频率，直到铁蛋白降到正常低值，然后维持。这种方法便宜而有效。如果存在肝硬化，他需要每6个月监测肝细胞癌。应为一级亲属提供检测。
:::
:::

::: example 精神科病房里的黄疸 {#ex-wilson}
一名19岁女性因黄疸入院。过去一年中她出现情绪低落、写字笨拙和言语含糊。胆红素210 µmol/L，ALT 160 U/L，ALP 30 U/L（偏低），血红蛋白82 g/L，直接抗球蛋白试验阴性，INR 2.4。必须紧急考虑什么诊断？如何证实？
::: solution
**模式识别。** 年轻人肝病伴神经精神表现，在排除之前应假定为**Wilson病**。铜在肝内蓄积，当超过肝的容量时蓄积到脑（尤其是基底节），引起运动障碍和精神改变。

**血液结果。** 急性肝损伤、铜释放入血引起的**Coombs阴性溶血**、不成比例的**低ALP**以及INR升高，这一组合是Wilson病以**急性肝衰竭**起病的典型表现。

**证实。** 血清**铜蓝蛋白**降低、24小时尿铜升高、裂隙灯检查发现**Kayser–Fleischer环**，以及*ATP7B*变异的基因检测。可在活检标本中测定肝铜含量。

**紧迫性。** 她有黄疸、INR升高和溶血，需要立即与肝移植中心讨论。以急性肝衰竭起病的Wilson病通常需要肝移植。较轻的疾病终身使用铜螯合剂如青霉胺（penicillamine）或曲恩汀（trientine），或使用锌治疗。应筛查兄弟姐妹。
:::
:::

## 肝硬化及其并发症

尚未发生并发症的肝硬化为**代偿期**；一旦出现腹水、静脉曲张出血、肝性脑病或黄疸，即为**失代偿期**。失代偿后生存率急剧下降：从代偿期的许多年降到中位约2年。

严重程度主要用两种方法评分。**Child–Pugh评分**对胆红素、白蛋白、INR、腹水和肝性脑病计分。总分5～6分为A级，7～9分为B级，10～15分为C级。**MELD评分**使用胆红素、INR和肌酐：

$$
\text{MELD} = 3.78\ln(\text{胆红素, mg/dL}) + 11.2\ln(\text{INR}) + 9.57\ln(\text{肌酐, mg/dL}) + 6.43
$$ {#eq-meld}

小于1的值按1计。MELD预测3个月死亡率，在美国用于确定肝移植的优先顺序；加入钠的版本（MELD-Na）现已常用。英国使用相关的**UKELD**评分决定何时把患者列入肝移植等待名单。

### 门静脉高压

::: definition 门静脉高压 {#def-portal}
**门静脉高压**是门静脉系统压力升高。它通过**肝静脉压力梯度**（HVPG）间接测定，即肝静脉楔压与游离压之差。正常HVPG不超过5 mmHg。HVPG达到**10 mmHg或以上**为**临床显著性门静脉高压**：它预示静脉曲张和失代偿。HVPG低于12 mmHg时很少发生静脉曲张出血。
:::

::: theorem 门静脉压力等于血流乘以阻力 {#thm-portal}
与任何血管一样，门静脉压力梯度等于门静脉血流乘以血流阻力：$\Delta P = Q \times R$。肝硬化门静脉高压既源于阻力增加，也源于血流增加，各种治疗作用于其中一方或两者。
:::

::: proof
**阻力**首先增加。纤维化和结节使肝血窦扭曲，活化的星状细胞收缩，受损的内皮生成一氧化氮减少，增加了一个可逆的成分。

**血流**随后增加。内脏小动脉扩张，原因是病变的肝不能清除一氧化氮和其他血管扩张物质，于是更多血液涌入门静脉系统。全身血管扩张降低有效动脉血容量，激活肾素-血管紧张素-醛固酮系统和交感神经系统，导致水钠潴留。这种**高动力循环**解释了腹水和肾脏的易损性。

治疗由此而来。非选择性β受体阻滞剂通过降低心输出量（β1）并使内脏血管收缩（β2阻断）来减少血流。卡维地洛（carvedilol）另有α1阻断作用，可降低肝内阻力。特利加压素收缩内脏小动脉。TIPS连接门静脉和肝静脉，完全绕过阻力。
:::

门静脉血经**门体侧支**寻找压力较低的途径返回体循环，部位在胃食管交界处（静脉曲张）、脐周（海蛇头）和直肠。绕过肝的血液把氨和其他毒素带入体循环。淤血使脾增大，脾扣留血小板，因此**血小板计数低**常常是肝硬化的第一个线索。

当前共识（Baveno VII，2022年）建议，对有临床显著性门静脉高压的代偿期肝硬化患者，使用非选择性β受体阻滞剂（首选**卡维地洛**）预防失代偿。有中度或大的静脉曲张而不能使用β受体阻滞剂者，行内镜下套扎。急性静脉曲张出血的处理见[[gastrointestinal/gi-bleeding-cancer]]。

### 腹水与自发性细菌性腹膜炎

**腹水**是腹腔内的游离液体。在肝硬化中，它由门静脉高压和钠潴留引起。所有新出现腹水的患者和所有因腹水住院的患者都要做诊断性腹腔穿刺。**血清-腹水白蛋白梯度**（SAAG）是血清白蛋白减去腹水白蛋白。SAAG**达到或超过11 g/L**提示门静脉高压；梯度较低提示腹膜疾病，如恶性肿瘤或结核病。

肝硬化腹水的治疗遵循英国胃肠病学会指南（2020年）：适度限制饮食中的盐，使用醛固酮拮抗剂**螺内酯**（spironolactone），需要时加用**呋塞米**（furosemide）。张力性或难治性腹水通过**大量腹腔穿刺放液**引流；放液超过5 L时，按每放1升补充8 g人血白蛋白，以预防循环功能障碍和肾损伤。对部分难治性腹水患者，TIPS是一种选择。

::: definition 自发性细菌性腹膜炎及其他并发症 {#def-infections-complications}
- **自发性细菌性腹膜炎**（SBP）是没有外科来源的腹水感染，诊断标准为腹水**中性粒细胞计数超过250个/mm³**。它常常腹部体征很少，可能只表现为意识模糊、急性肾损伤或病情恶化。按当地指南使用抗生素治疗，并静脉给予白蛋白以降低肾衰竭风险。
- **肝性脑病**是肝功能不全和门体分流引起的脑功能障碍，临床分级从轻度意识模糊（West Haven 1级）到昏迷（4级）。氨是主要参与因素。
- **肝肾综合征-急性肾损伤**（HRS-AKI）是进展期肝硬化中肾血管强烈收缩引起的功能性肾衰竭。用特利加压素和白蛋白治疗。
- **肝细胞癌**（HCC）主要发生在肝硬化的肝脏。肝硬化患者接受**每6个月一次的超声监测**，可加或不加甲胎蛋白。
:::

肝性脑病通常有诱因。常见诱因是感染、消化道出血、便秘、脱水和电解质紊乱、镇静药物和酒精。治疗是找出并纠正诱因，并给予**乳果糖**（lactulose），它使结肠酸化，把氨以铵的形式截留，并加快转运。不易吸收的抗生素**利福昔明**（rifaximin）可减少复发。

::: example 伴腹水的意识模糊患者入院 {#ex-ascites}
一名58岁酒精性肝硬化男性，已戒酒一年，因两天来嗜睡、思维混乱被送来。他无发热，有轻度腹部不适。张力性腹水，有扑翼样震颤。肌酐从80升至150 µmol/L。诊断性腹腔穿刺示腹水中性粒细胞计数620个/mm³；腹水白蛋白9 g/L，血清白蛋白29 g/L。请解读这些发现并概述处理。
::: solution
**第1步：腹水。** SAAG $= 29 - 9 = 20$ g/L，至少为11，因此腹水由门静脉高压引起。腹水中性粒细胞计数620个/mm³超过250：**自发性细菌性腹膜炎**，尽管他没有发热，腹部体征也很少。

**第2步：意识模糊。** 嗜睡伴扑翼样震颤是**肝性脑病**，此次由感染诱发。

**第3步：肾脏。** 他的肌酐升高超过基线的1.5倍，属于急性肾损伤。在SBP中，急性肾损伤可能进展为肝肾综合征。

**第4步：处理。** 按当地指南立即开始抗生素治疗，并把腹水注入血培养瓶送检。静脉给予白蛋白，可减少SBP伴肾功能不全时的肾衰竭和死亡。停用利尿剂和肾毒性药物。给予乳果糖，使每天排两到三次软便，并寻找消化道出血等其他诱因。恢复后他需要长期抗生素预防SBP复发，并评估肝移植。
:::
:::

::: warning 氨基转移酶正常不能排除肝硬化
在已形成的肝硬化中，活跃的肝细胞可能太少，释放不出多少ALT，因此肝酶可以正常或仅轻度升高。线索在别处：血小板计数低、白蛋白低、INR或胆红素升高、AST:ALT比值大于1，以及蜘蛛痣或脾大等体征。判断严重程度应使用纤维化检查，而不是ALT。
:::

### 肝硬化患者的手术

肝硬化患者对手术耐受很差。出血、感染、伤口愈合不良、腹水漏和术后失代偿都更常见，风险随Child–Pugh分级和MELD评分急剧上升。Child–Pugh A级择期手术一般是安全的，B级需要仔细评估，C级通常应避免。急诊手术风险最高。

::: example 等待髋关节置换的肝硬化患者 {#ex-preop}
一名66岁MASLD肝硬化女性被转诊行择期髋关节置换。胆红素41 µmol/L，白蛋白30 g/L，INR 1.6，轻度腹水经螺内酯控制，无肝性脑病。计算她的Child–Pugh分级并讨论手术风险。
::: solution
**Child–Pugh计分：** 胆红素34～50 µmol/L：2分；白蛋白28～35 g/L：2分；INR低于1.7：1分；轻度、已控制的腹水：2分；无肝性脑病：1分。总分$= 2 + 2 + 1 + 2 + 1 = 8$，为**B级**。

**风险。** B级肝硬化大手术后并发症和死亡的风险显著高于A级。髋关节置换是择期手术，目的是改善生活质量，因此需要她本人与骨科医生、麻醉医生和肝病医生仔细、共同地讨论获益和风险。

**如果进行手术的优化措施。** 术前控制腹水；评估营养和衰弱；检查静脉曲张；避免肾毒性药物和镇静药；根据黏弹性检测而不是单凭INR管理血制品，因为在肝硬化中INR不能很好地反映出血风险；并计划在有肝病支持的中心进行术后护理。
:::
:::

## 急性肝衰竭与肝移植

**急性肝衰竭**是在没有基础肝病的人中，数天至数周内发生的严重肝损伤，伴凝血障碍（INR至少1.5）和**肝性脑病**。在英国，**对乙酰氨基酚过量**是最常见的原因。其他原因包括病毒性肝炎、特异质性药物反应、自身免疫性肝炎、Wilson病、缺血和妊娠相关肝病。对乙酰氨基酚中毒使用乙酰半胱氨酸（acetylcysteine），在一些非对乙酰氨基酚病例中也有使用。中毒的处理见[[emergency-critical-care/poisoning]]。

急性肝衰竭患者应尽早与专科肝病中心讨论，因为他们可能在数小时内恶化。并发症包括脑水肿、感染、低血糖、肾衰竭和多器官衰竭。**King's College标准**等标准可识别不做肝移植难以存活的患者。

**肝移植**的适应证包括符合移植标准的急性肝衰竭、预计生存期差的失代偿期肝硬化、在规定大小和数目标准内的HCC，以及某些代谢性疾病。疗效良好：在英国，大多数受者5年时仍然存活。限制因素是器官供应、终身免疫抑制以及某些疾病的复发。酒精相关性肝病患者与其他患者一样接受移植评估，包括对持续戒酒的支持。

::: quiz
一名45岁肝硬化女性有腹水。腹水白蛋白12 g/L，血清白蛋白18 g/L，腹水中性粒细胞90个/mm³。哪一项说法正确？
- [ ] SAAG为6 g/L表明腹水不是门静脉高压所致
- [x] SAAG为6 g/L偏低，因此应考虑腹膜恶性肿瘤或结核病等其他原因
- [ ] 中性粒细胞计数证实为自发性细菌性腹膜炎
- [ ] 低SAAG是肝硬化腹水的典型表现
::: solution
SAAG $= 18 - 12 = 6$ g/L，低于11。低梯度不支持门静脉高压是病因，这在肝硬化中出乎意料，因此应寻找腹膜疾病（恶性肿瘤、结核病）或其他原因，如肾病综合征、胰腺炎或浆膜炎；偶尔两种原因同时存在。中性粒细胞90低于250，因此没有SBP。
:::
:::

::: history
1965年，布隆伯格（Baruch Blumberg）在一名澳大利亚原住民男子的血液中发现了一种抗原，即"澳大利亚抗原"，后来证明它是乙型肝炎病毒的表面蛋白。这带来了诊断试验和第一批乙型肝炎疫苗，布隆伯格分享了1976年诺贝尔奖。1989年，Chiron公司的霍顿（Michael Houghton）及其同事与布拉德利（Daniel Bradley）合作，克隆了引起大多数"非甲非乙型"肝炎的病毒基因组，将其命名为丙型肝炎病毒。阿尔特（Harvey Alter）、霍顿和赖斯（Charles Rice）因这项工作获得2020年诺贝尔奖。在外科方面，斯塔兹尔（Thomas Starzl）于1963年在丹佛进行了第一例人类肝移植，1967年完成了第一例长期存活的肝移植；剑桥的卡恩（Roy Calne）发展了欧洲的肝移植项目，并在二十世纪七十年代末引入了环孢素免疫抑制。
:::

::: summary
- 酒精、代谢功能障碍和病毒性肝炎引起大多数肝病；纤维化分期决定预后。
- MASLD是伴心血管代谢危险因素的脂肪肝；治疗以减重和控制危险因素为中心。
- 重症酒精性肝炎通过Maddrey判别函数（32或以上）等评分识别；戒酒和营养是核心。
- 乙型肝炎可用抗病毒药抑制、用疫苗预防；丙型肝炎可用直接抗病毒药物治愈。
- 自身免疫性肝炎、PBC、PSC、血色病、Wilson病和α1-抗胰蛋白酶缺乏症各有特征性的检查模式。
- 门静脉高压（HVPG 10 mmHg或以上为临床显著性）驱动静脉曲张、腹水和脾大；卡维地洛可减少失代偿。
- 每次因腹水入院都要穿刺：SAAG 11 g/L或以上意味着门静脉高压，中性粒细胞超过250个/mm³意味着SBP。
- Child–Pugh和MELD评估严重程度；急性肝衰竭和失代偿期肝硬化需要尽早进行专科和移植评估。
:::

::: exercise 为什么用乳果糖？ {level=1}
解释乳果糖如何减轻肝性脑病，并列出肝硬化患者出现意识模糊时应寻找的四个常见诱因。
::: solution
乳果糖被结肠细菌发酵为有机酸，降低结肠pH。氨（NH₃）转化为铵（NH₄⁺），后者难以吸收并被排出；其通便作用也缩短了氨生成和吸收的时间。常见诱因：感染（包括SBP）、消化道出血、便秘、脱水或电解质紊乱（常由利尿剂引起），以及镇静药或酒精。
:::
:::

::: exercise 计算SAAG {level=2 check="22"}
一名腹水患者血清白蛋白30 g/L，腹水白蛋白8 g/L。计算血清-腹水白蛋白梯度（g/L）并解读。
::: hint
用血清白蛋白减去腹水白蛋白。
:::
::: solution
SAAG $= 30 - 8 = 22$ g/L。达到或超过11 g/L，因此腹水由**门静脉高压**引起，最常见为肝硬化。心力衰竭和布-加综合征也产生高梯度。
:::
:::

::: exercise 腹腔穿刺放液后的白蛋白 {level=2 check="64"}
大量腹腔穿刺放液时放出8 L腹水。按照英国指南（放液超过5 L时每升补充8 g白蛋白），应给予多少克白蛋白？为什么要给？
::: hint
用放液量乘以每升的剂量。
:::
::: solution
$8 \times 8 = 64$ g白蛋白。大量放出腹水会使有效动脉血容量进一步下降，激活缩血管系统，称为穿刺后循环功能障碍。它可引起低钠血症、肾损伤和腹水再积聚。白蛋白扩充循环血容量，减少这些并发症。
:::
:::

::: exercise 判断酒精性肝炎的严重程度 {level=2 check="73"}
一名41岁酒精性肝炎女性，凝血酶原时间24秒（对照12秒），胆红素300 µmol/L。计算Maddrey判别函数，四舍五入到整数，并加以解读。
::: hint
胆红素除以17.1换算为mg/dL。
:::
::: solution
胆红素$= 300/17.1 = 17.54$ mg/dL。DF $= 4.6 \times (24 - 12) + 17.54 = 55.2 + 17.54 = 72.74$，四舍五入为**73**。远高于32，提示**重症酒精性肝炎**，未来一个月死亡风险高。她需要专科诊治、评估感染、营养支持、处理戒断，并由专科决定是否使用糖皮质激素，其获益至多是短期的。
:::
:::

::: exercise 代偿期还是失代偿期？ {level=3}
一名55岁丙型肝炎肝硬化男性，3年前经抗病毒治疗治愈。他感觉良好。血小板95 × 10⁹/L，肝硬度28 kPa，无腹水，无出血史，内镜显示小的静脉曲张。他处于疾病的哪个阶段？治愈丙型肝炎是否消除了他的风险？他需要怎样的随访？
::: hint
考虑去除病因后的门静脉高压和癌症风险。
:::
::: solution
**阶段：** **代偿期肝硬化**伴**临床显著性门静脉高压**，由血小板低、肝硬度高和存在静脉曲张提示。

**治愈是否消除风险？** 病毒学治愈去除了损伤的主要驱动因素，纤维化和门静脉压力常在数年内改善。但已形成的肝硬化和门静脉高压可能持续，**肝细胞癌的风险在治愈后仍然存在**，只是较低。

**随访：** 按Baveno VII使用非选择性β受体阻滞剂（首选卡维地洛）以降低失代偿风险；**每6个月超声监测HCC**；定期评估肝功能；接种甲型和乙型肝炎及肺炎球菌疫苗；就饮酒、体重和应避免的药物提供建议。再次暴露可再次感染，因此在相关情况下应提供减少伤害的建议。
:::
:::

::: exercise 解读MELD评分 {level=3 check="19"}
一名60岁肝硬化男性胆红素4 mg/dL，INR 2.0，肌酐1.0 mg/dL。用[[#eq-meld]]计算他的MELD评分，四舍五入到整数。如果他的肌酐升至2.0 mg/dL，评分会怎样？为什么肾功能的权重如此之大？
::: hint
$\ln 4 = 1.386$，$\ln 2 = 0.693$，$\ln 1 = 0$。
:::
::: solution
$\text{MELD} = 3.78 \times 1.386 + 11.2 \times 0.693 + 9.57 \times 0 + 6.43 = 5.24 + 7.76 + 0 + 6.43 = 19.43$，四舍五入为**19**。

如果肌酐升至2.0 mg/dL，肌酐项变为$9.57 \times 0.693 = 6.63$，评分升至约26。肌酐翻倍一次所增加的分数多于胆红素翻倍（$3.78 \times 0.693 = 2.6$分）。

肾功能权重大，是因为在进展期肝硬化中，肌酐上升通常反映门静脉高压引起的循环衰竭（走向肝肾综合征的道路），它是短期死亡最强的预测因素之一。还要注意，在肌肉量少的人中肌酐会高估肾功能，而这在肝硬化中很常见，因此"正常"的肌酐可能给人虚假的安慰。
:::
:::
