慢性肝病是一种有一千种病因和一百种失代偿方式的疾病。组织逻辑是：**无论打击是什么、纤维化都会累积、窦状隙压力升高、而患者从代偿跨越到失代偿——即腹水、出血、脑病或黄疸出现、而在没有移植或病因逆转时预后以数年计的那个点。**本章的一切都为这两句话服务。

本章涵盖慢性肝病的病因、以及门脉高压与失代偿的识别、预防和处理。

## 病因

::: definition 脂肪变、酒精与药物 {#def-causes}
**代谢功能障碍相关脂肪性肝病（2023年把“非酒精性脂肪性肝病”改名、带其心代谢标准、一个命名与科学并重的行为、及与酒精的重叠类别——酒精与代谢相关肝病——[[gastrointestinal/liver-disease]]的诚实建议推论）：流行病学（四分之一的成年人、随肥胖上升——[[endocrine/diabetes]]、[[public-health/determinants-inequalities]]）；发病机制（胰岛素抵抗与脂肪脂质通量及从头脂肪生成与脂毒性物质、及肠纤维微生物群的第二击——[[cell-biochemistry/lipid-amino-acid-metabolism]]、[[microbiology/microbiota]]）；组织学谱（脂肪变→伴气球样变与腺泡炎症的脂肪性肝炎→带窦周与门周模式的纤维化）；临床问题（它是沉默的、所以FIB-4然后弹性成像的级联就是在糖尿病与初级照护肥胖门诊中找病例——[[clinical-skills/medical-imaging]]、[[public-health/screening]]）；及处理（运动与膳食减重——组织学反应的阈值；他汀神话的纠正与心血管风险的优先性——[[cardiovascular/vascular-disease]]、[[pharmacology/adverse-reactions]]）；胰高糖素样肽1受体激动剂与瑞司替罗及法尼醇X受体激动剂的证据浪潮——[[endocrine/diabetes]]、[[gastrointestinal/liver-function]]的胆汁酸注及[[gastrointestinal/digestion-absorption]]；减重手术的附带获益及其围手术期细微——[[surgery/gastrointestinal-surgery]]。**酒精相关肝病（风险的剂量病程曲线、带基因型与吸烟及肥胖病毒辅因子——[[pharmacology/patient-variation]]、[[psychiatry/substance-use]]）：发病机制（乙醛与氧化及亚硝化应激及免疫激活——[[cell-biochemistry/lipid-amino-acid-metabolism]]的酒精通路、[[immunology/innate-immunity]]的肠源内毒素信号）；呈现（脂肪变可逆、肝炎、肝硬化——及天门冬氨酸氨基转移酶比丙氨酸氨基转移酶带其γ谷氨酰转移酶与平均红细胞体积及缺失糖基化转铁蛋白标志物组及其诚实极限——[[gastrointestinal/liver-function]]）；急性重症酒精性肝炎（黄疸发热触痛肝大不适综合征、判别评分及其他预后评分、带感染与消化道出血及肾守卫的激素试验、及无反应的停止规则、及作为治疗其余部分的营养优先——[[gastrointestinal/clinical-nutrition]]）；并行运行的戒断与依赖管理（葡萄糖前先给硫胺素与Wernicke-Korsakoff的警觉——[[nervous-system/dementia-neurodegeneration]]、[[psychiatry/substance-use]]）；肝病成瘾联合门诊与移植规划适当性谈话——[[medical-ethics-law/justice-resources]]。**药物性肝损伤可预测的剂量相关型（扑热息痛的NAPQI化学——[[emergency-critical-care/poisoning]]、[[pharmacology/metabolism-excretion]]）对特发性的代谢与免疫型（氟氯西林与奈韦拉平及阿莫西林克拉维酸的人类白细胞抗原关联——[[pharmacology/patient-variation]]、[[immunology/antigen-recognition]]）；反复出现的罪魁清单（抗生素、非甾体抗炎药抗癫痫药抗甲状腺药、结核方案——[[infectious-diseases/tuberculosis]]、抗逆转录病毒药、草药与绿茶提取物及合成类固醇、检查点抑制剂及其他肿瘤药的肝免疫毒性——邻近[[immunology/vaccines-immunotherapy]]的免疫相关不良事件管理[[gastrointestinal/gi-bleeding-cancer]]）；带潜伏期逻辑与RUCAM式因果性评分的排除诊断；Hy定律（肝细胞性加黄疸的组合及其死亡率信号）与强制报告习惯——[[pharmacology/adverse-reactions]]、[[pharmacology/drug-development-prescribing]]。**
:::

::: definition 遗传性、自身免疫性与胆汁淤积性疾病 {#def-other-causes}
**遗传性血色病HFE C282Y纯合、以转铁蛋白饱和度升高为首筛及铁蛋白第二步、外显率问题与家系级联检测；器官内铁综合征（肝纤维化与肝细胞癌风险、糖尿病、关节病与假性痛风、心肌病与心律失常、性腺功能减退、皮肤色素沉着、疲乏——[[endocrine/diabetes]]、[[endocrine/reproductive-endocrinology]]、邻近[[musculoskeletal/inflammatory-arthritis]]的焦磷酸钙[[musculoskeletal/bones-joints]]、[[cardiovascular/heart-failure]]、[[endocrine/bone-calcium]]）；放血治疗带铁蛋白靶目标与促红细胞生成素限制逻辑（输血依赖的表亲伴继发性铁过载——[[blood/transfusion]]、[[blood/haematopoiesis]]）；及作为真正干预的消除酒精与代谢相关脂肪性肝病辅因子——[[#def-causes]]；及筛查规划之争（[[public-health/screening]]）。Wilson病（ATP7B铜转运、年轻患者规则（40岁以下的肝炎或无法解释的肝硬化或神经精神疾病——被误标多年的精神科呈现——[[psychiatry/psychotic-disorders]]）、低铜蓝蛋白与高尿铜及Kayser-Fleischer环的检查及肝铜测定、青霉胺与曲恩汀及锌治疗带血液与神经监测、暴发性疾病的肝移植救援、及同胞检测与治疗义务——[[genetics/mendelian-inheritance]]、[[genetics/genetic-testing]]）。α1抗胰蛋白酶缺乏（PiZZ聚合贮积病带其肺的配对——[[respiratory/interstitial-vascular-disease]]与[[genetics/common-disease-genetics]]）。自身免疫性肝炎（中年女性以及偶尔任何人的模式；抗核抗体与抗平滑肌抗体及升高的免疫球蛋白G及界面性肝炎；带硫唑嘌呤维持与硫嘌呤甲基转移酶检查的治疗与减量与复发方案——[[pharmacology/patient-variation]]）；与原发性胆汁性胆管炎及原发性硬化性胆管炎的重叠综合征、及模仿两者而应答激素的免疫球蛋白G4相关硬化性疾病——[[immunology/autoimmunity]]、[[gastrointestinal/liver-function]]的抗体组、[[pathology/diagnostic-pathology]]。原发性硬化性胆管炎（年轻男性伴炎症性肠病的胆管病——[[gastrointestinal/bowel-disease]]的溃疡性结肠炎配对；串珠与狭窄的胆管造影及优势狭窄刷检细胞学纪律——[[clinical-skills/medical-imaging]]、[[pathology/cancer-diagnosis]]）；胆管癌与胆囊新生物监测规划及其收益之争——[[gastrointestinal/pancreas-biliary]]、[[public-health/screening]]；无经证实的内科治疗、失代偿时移植、及移植复发与炎症性肠病结肠切除时机的谜题——[[immunology/transplant-tumour-immunology]]。慢性病毒型肝炎B与C有自己的微生物学处理（[[microbiology/viruses]]、邻近[[infectious-diseases/hiv]]的共感染门诊）：丙肝治愈时代与乙肝抑制时代对纤维化逆转、肝细胞癌风险降低、及“找病例就是筛查”的公共健康策略的含义——[[public-health/screening]]、[[public-health/global-health]]。**

## 失代偿

::: definition 门脉高压及其并发症 {#def-portal}
**生理（结构扭曲加内皮功能障碍造成的窦状隙阻力、然后内脏血管扩张伴有效动脉充盈不足、然后肾素血管紧张素醛固酮与抗利尿激素及交感潴留及高动力循环——与[[renal/water-sodium]]、[[cardiovascular/circulation-blood-pressure]]及[[endocrine/adrenal]]的醛固酮对读；肝静脉压力梯度作为替代测量、及预测失代偿的临床显著阈值）。腹水（SAAG——血清腹水白蛋白梯度不低于11克每升说明门脉高压、然后总蛋白把心源性从肝源性分开——[[#ex-ascites]]、[[gastrointestinal/liver-function]]的合成页；检查程序总包括细胞计数与培养查自发性细菌性腹膜炎、先于其他一切——[[#def-infections-complications]]）；治疗：限钠及螺内酯呋塞米滴定带钾与肌酐监测（[[renal/potassium-calcium-phosphate]]、[[renal/acute-kidney-injury]]）、带白蛋白替代的大容量腹腔穿刺、难治性腹水的层级（门体分流带其脑病取舍——[[gastrointestinal/liver-disease]]自己的血管路径[[clinical-skills/medical-imaging]]；留置泵与腹静脉分流的历史遗迹；移植时机）、及不要做清单（非甾体抗炎药与氨基糖苷类及低钠时的强力利尿——[[pharmacology/adverse-reactions]]、[[renal/water-sodium]]）。静脉曲张与出血（[[anatomy/abdomen]]的门体通路；筛查内镜与非选择性β阻滞剂对套扎的一级预防规则、他汀与门脉压假说的前沿——邻近[[cardiovascular/vascular-disease]]；急性曲张静脉出血属于[[gastrointestinal/gi-bleeding-cancer]]的规程）。肝性脑病（氨与神经炎症及锰及γ氨基丁酸A神经类固醇的多重打击伴星形胶质细胞肿胀——[[cell-biochemistry/energy-metabolism]]的星形胶质细胞谷氨酰胺化学、邻近[[physiology/membrane-potentials]]的胶质生理）；West-Haven分级与轻微脑病驱动及职业咨询义务（邻近[[medical-ethics-law/professionalism-regulation]]的驾照规则；诱因搜寻——感染与出血及便秘及脱水及镇静剂——在给诊断贴标签之前；乳果糖滴定与利福昔明预防带用药管理警诫——[[microbiology/antimicrobials]]）；及移植与门体分流选择含义——[[gastrointestinal/liver-function]]的脑病引用。肝肾综合征（排除诊断、带无结构疾病与容量扩充试验逻辑、特利加压素白蛋白逆转桥接到移植、肝硬化患者的急性肾损伤易感性与肾毒素避免清单——[[renal/acute-kidney-injury]]、[[renal/filtration]]）。凝血障碍（前与抗凝因子均降低的再平衡止血、在此情境中国际标准化比值无意义的论证带血栓弹力图纠正、及保护患者免于不必要血浆的操作阈值算术——[[blood/haemostasis-bleeding]]、[[blood/transfusion]]、[[gastrointestinal/liver-function]]的合成课）。肌少症、衰弱与骨病（肌肉作为代谢储备器官的论证与移植结局数据——[[geriatrics-palliative/ageing-frailty]]、[[gastrointestinal/clinical-nutrition]]、[[endocrine/bone-calcium]]）；急性慢性肝衰竭的感染与急性肾损伤及消化道出血触发项（急性慢性肝衰竭综合征带其重症监护分层的死亡率——[[emergency-critical-care/critical-care]]、[[infectious-diseases/fever-sepsis]]）；疫苗与筛查卫生（甲乙肝与肺炎球菌及每年流感；肝硬化者的肝细胞癌超声监测规则及其甲胎蛋白警诫——[[public-health/vaccination-programmes]]、[[public-health/screening]]）；及移植（适应证与MELD分配引擎——[[gastrointestinal/liver-function]]的评分；绝对与相对禁忌之争、酒精规划要求的伦理——[[medical-ethics-law/justice-resources]]；活体供肝与分肝选项——[[surgery/gastrointestinal-surgery]]；移植后免疫抑制与复发及代谢综合征的长跑——[[immunology/transplant-tumour-immunology]]、[[geriatrics-palliative/polypharmacy]]）；症状负荷与诚实预后的姑息照护平行轨道、包括为不宜移植者的肝病单元伙伴关系——[[geriatrics-palliative/palliative-care]]、[[medical-ethics-law/end-of-life-ethics]]。**
:::

::: definition 自发性细菌性腹膜炎与感染规则 {#def-infections-complications}
**自发性细菌性腹膜炎（由易位驱动、腹水常常沉默的感染而无外科来源：为何每一例肝硬化入院与每一次恶化都要诊断性穿刺——多形核细胞每微升不低于250的治疗阈值、用血培养瓶技术培养以战胜低菌量问题、带本地耐药意识的第三代头孢经验覆盖、白蛋白在高风险组的肾保护剂量、及诺氟沙星或甲氧苄啶的二级预防规则——[[microbiology/antimicrobials]]、[[clinical-skills/laboratory-tests]]）；“同时治疗诱因”的三联：肝肾、低血压与低血容量——[[renal/acute-kidney-injury]]、[[emergency-critical-care/shock-fluids]]。更宽的感染手册（肝硬化免疫麻痹——一个先天与适应性联合衰竭、表现得像药物诱导的免疫缺陷——[[immunology/innate-immunity]]、[[immunology/immunodeficiency]]；尿、胸与皮肤感染的高率及非典型呈现的警觉；带多重耐药风险的抗菌药物用药管理钢丝——[[infectious-diseases/healthcare-infections]]、[[infectious-diseases/stewardship-outbreaks]]；重症与抗生素暴露者的真菌性腹膜炎与黏膜皮肤隐球菌风险——[[microbiology/fungi-parasites]]）；及入院包裹的常识（应暂停的药——出血或急性肾损伤期间的非甾体抗炎药利尿剂血管紧张素转换酶抑制剂β阻滞剂剂量——[[pharmacology/adverse-reactions]]、[[renal/water-sodium]]；白蛋白与容量推理；及在频繁入院轨迹中较早进行的目标照护谈话——[[geriatrics-palliative/palliative-care]]、[[clinical-skills/records-handover]]）。**
:::

::: example 意识混乱的腹水入院 {#ex-ascites}
一名56岁酒精相关肝硬化患者被送来时意识混乱而发热；张力性腹水、心率110、血压96/58、体温38.4；胆红素85、国际标准化比值1.9、肌酐155（基线85）、钠127、白细胞16、乳酸3.1；腹水穿刺：每微升900个多形核细胞、蛋白8克每升。
::: solution
**伴自发性细菌性腹膜炎、脑病、急性肾损伤与低钠的失代偿肝硬化——一次失代偿从不独自出行（[[#def-portal]]、[[#def-infections-complications]]）：自发性细菌性腹膜炎的诊断已成立（多形核细胞900不低于250；低蛋白标记高复发风险的液体——[[clinical-skills/laboratory-tests]]）；开始头孢菌素与白蛋白方案、并在床边把血与腹水培养接入培养瓶（[[microbiology/antimicrobials]]、[[infectious-diseases/fever-sepsis]]）；急性肾损伤的检查程序与容量之问（白蛋白挑战与停利尿剂及非甾体抗炎药及血管紧张素转换酶抑制剂审计、并寻找出血——[[renal/acute-kidney-injury]]、[[gastrointestinal/gi-bleeding-cancer]]）；脑病诱因清扫（感染已找到、接下来是便秘与脱水及苯二氮䓬及消化道出血及纠正过快的低钠——[[renal/water-sodium]]的渗透性脱髓鞘规则、[[pharmacology/adverse-reactions]]）；低钠的解读（稀释性且有预后意义——限液推理与血管加压素拮抗剂的诚实——[[renal/water-sodium]]）；自发性腹膜炎的白蛋白与特利加压素可及性及重症阈值（急性慢性肝衰竭分级与重症监护谈话——[[emergency-critical-care/critical-care]]）；出院前的二级预防与利尿优化及营养与戒酒支持规划（[[gastrointestinal/clinical-nutrition]]、[[psychiatry/substance-use]]）；移植中心转诊时机与目标记录（[[medical-ethics-law/end-of-life-ethics]]、[[clinical-skills/records-handover]]）；及教学要点：入院时的诊断性穿刺是改变这个结局的单一动作——把它写进规程（[[clinical-skills/patient-safety]]）。**

::: example 沉重的铁蛋白 {#ex-haemochromatosis}
一名49岁新发2型糖尿病与关节痛的男性：铁蛋白1450微克每升、转铁蛋白饱和度78%、丙氨酸氨基转移酶88、肝炎血清学阴性、酒精每周6单位、无贫血；母亲有“肝病与糖尿病”。

**在证明否则之前是HFE血色病（转铁蛋白饱和度优先规则——[[#def-other-causes]]）：用HFE基因型确认（绝大多数为C282Y纯合）、然后给损害分期（弹性成像或磁共振铁及纤维化评估、及磁共振定量铁选项——[[clinical-skills/medical-imaging]]；糖尿病的胰腺与心脏及性腺及关节评估——[[endocrine/diabetes-complications]]、[[cardiovascular/heart-failure]]、[[endocrine/reproductive-endocrinology]]、[[musculoskeletal/bones-joints]]）；用放血治疗（每周到每两周的诱导到铁蛋白靶目标、带血红蛋白刹车——[[blood/haematopoiesis]]、邻近[[blood/anaemia]]的铁红细胞生成生理[[gastrointestinal/digestion-absorption]]）；及常在铁耗竭后仍持续的疲乏与关节与性欲症状（咨询期望落差——[[clinical-skills/communication]]）；消除辅因子（酒精最小化、体重与代谢控制、甲乙肝疫苗——[[gastrointestinal/liver-function]]的合成保护逻辑、[[public-health/vaccination-programmes]]）；家庭层（一级亲属检测带级联检测物流及保险与生育咨询——[[genetics/genetic-testing]]、[[genetics/mendelian-inheritance]]）；及肝细胞癌监测边界（仅肝硬化期监测——[[public-health/screening]]、[[gastrointestinal/gi-bleeding-cancer]]）。**

::: example 伴黄疸的精神科入院 {#ex-wilson}

::: example 等待髋关节置换的肝硬化患者 {#ex-preop}
一名64岁代偿期酒精相关肝硬化（腹水一次、现已控制；胆红素28、白蛋白32、国际标准化比值1.4、血小板96、MELD 12）被列入全髋置换治疗缺血性坏死。骨科问：“通过评估了吗？”
::: solution
**“通过了”是错误的问题——量化并优化（[[#def-portal]]）：出血与感染及失代偿风险真实但可评分（Child-Pugh与MELD及外科结局指数；MELD 12带来数倍的围手术期死亡风险、及择期手术推迟对进行的争论——[[surgery/perioperative-care]]）；优化窗口（即使术前的短间隔戒断也有帮助及肌肉与营养建设——[[gastrointestinal/clinical-nutrition]]、[[psychiatry/substance-use]]；腹水与低钠及肾功能优化——[[renal/water-sodium]]；疫苗与牙科及皮肤脓毒症决定——[[public-health/vaccination-programmes]]）；国际标准化比值1.4不是禁忌、而血浆不是计划这一论证（再平衡止血与粘弹性检测指导的输血、血小板阈值推理、及术中粘弹性检测可及性——[[blood/haemostasis-bleeding]]、[[blood/transfusion]]）；术中与术后生理（避免肾毒素与低血容量及便秘及镇静负荷；脑病与急性肾损伤与自发性腹膜炎的触发项群集在术后头两周——[[renal/acute-kidney-injury]]、[[#def-infections-complications]]、[[pharmacology/adverse-reactions]]）；血栓预防悖论继续（肝硬化与制不动及关节成形等于高风险、不顾国际标准化比值——[[blood/thrombosis-anticoagulation]]）；及诚实的联合会诊（风险数字、若失代偿则推迟的条件、及记录的目标——[[clinical-skills/communication]]、[[surgery/perioperative-care]]、[[clinical-skills/records-handover]]）。**

::: quiz
SAAG的计算是：
- [ ] 腹水白蛋白减去血清白蛋白
- [x] 血清白蛋白减去腹水白蛋白；不低于11克每升指示门脉高压
- [ ] 血清蛋白除以腹水蛋白
- [ ] 腹水乳酸脱氢酶除以血清乳酸脱氢酶
::: solution
**这个梯度之所以有效，是因为门脉压把蛋白稀少的水推入腹膜——高梯度（不低于11克每升）见于肝硬化、心源性腹水与Budd-Chiari；低梯度见于腹膜疾病（结核、腹膜癌病、肾病）——[[#ex-ascites]]、[[#def-portal]]、邻近[[renal/urinary-tract]]的肾病蛋白丢失[[gastrointestinal/clinical-nutrition]]；总蛋白随后把心源性（高）与肝源性（低）分开、而同样的Starling算术支配水肿各章——[[gastrointestinal/digestion-absorption]]与[[cardiovascular/heart-failure]]。**

::: history
**肝硬化的长疾病分类史（Laennec 181年在停尸厨房对“钉状”肝的描述；1950年代世界胃肠病大会关于蛋白缺乏对肝炎理论的争吵、后来部分各胜一局——[[public-health/global-health]]的营养时代回声）；酒精疾病命名的政治（“酒精性肝硬化”标签及其治疗虚无主义后果——现代的酒精相关肝病改名运动、[[psychiatry/substance-use]]、[[clinical-skills/communication]]）；Trousseau 1865年的“青铜色糖尿病”与1996年HFE基因的识别（基因型时代的筛查争论——[[public-health/screening]]）；Wilson 1912年的进行性豆状核变性和Cumings的铜理论（[[genetics/mendelian-inheritance]]）；自身免疫性肝炎时代（1950-60年代γ球蛋白输注灾难被糖皮质激素试验逆转——[[pharmacology/adverse-reactions]]）；移植谱系（Starzl 1963年的犬源然后人肝移植；背驮式与活体供肝的改进——[[immunology/transplant-tumour-immunology]]、[[surgery/gastrointestinal-surgery]]）；乙肝疫苗然后丙肝治愈的弧线（[[microbiology/viruses]]、[[public-health/vaccination-programmes]]、[[microbiology/antimicrobials]]的直接抗病毒药化学）；MELD分配实施的争议（[[medical-ethics-law/justice-resources]]）；及2023年代谢相关脂肪性肝病的共识改名（[[gastrointestinal/liver-disease]]自己的命名注——语言重要的论证[[clinical-skills/communication]]）。**
:::

::: summary
- 任何病因的纤维化都汇聚于窦状隙高压；代偿到失代偿的过渡是定义预后的那一步。
- 按病因的治疗改变自然史：代谢相关脂肪性肝病的体重与代谢控制、酒精的戒断、血色病的放血、Wilson的螯合、自身免疫性肝炎的免疫抑制、丙肝的治愈、乙肝的抑制。
- 每一次失代偿都是一次搜寻：腹水需要诊断性穿刺、脑病需要一个诱因、急性肾损伤需要容量与药物审计、而感染需要早期培养与抗生素。
- 预后用品面评分追踪；为移植的转诊是一个在首次失代偿而非末次时做出的时机决定。
- 接种疫苗、在有指征处筛查肝细胞癌、保护骨与肌肉、并为症状负荷与诚实目标并行运行姑息照护。
:::

::: exercise 解读这个凝血障碍 {level=2}
