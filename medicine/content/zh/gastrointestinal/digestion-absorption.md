肠道的工作、用工程学陈述：**每天把9升水与约1公斤底物推过一个七米的生物反应器、在正确的地址把聚合物消化成单体、跨一层细胞的 上皮吸收它们、并把骑在这层上皮外侧的10的14次方微生物排除在外——一切都在双重神经与激素控制之下。**几乎每一个临床胃肠综合征——腹泻、吸收不良、酸病——都是机器之一在失效；本章是让本课程其余部分可读的生理学。

本章涵盖动力与分泌控制、消化与吸收、及腹泻吸收不良综合征。

## 移动与分泌

::: definition 动力：壁、线路与模式 {#def-motility}
**肠壁（黏膜、黏膜下、肌层与浆膜——[[anatomy/abdomen]]）携带肠神经系统：驱动动力的肌间（Auerbach）神经丛与驱动分泌及局部血流黏膜下（Meissner）神经丛、2亿到6亿神经元半自主运作、受副交感（迷走与盆神经、兴奋性——[[physiology/autonomic-nervous-system]]“休息与消化”的放大）与交感（抑制性、括约肌张力性）调节、并依赖Cajal间质细胞作为起搏器（慢波发生器——及同一谱系的肿瘤、胃肠道间质瘤、在[[gastrointestinal/gi-bleeding-cancer]]）及合胞体平滑肌（[[physiology/muscle]]）。** 模式：**蠕动（肠的“定律”反射——食团之上收缩、之下放松——及带括约肌协调的吞咽级联——[[gastrointestinal/oesophagus-stomach]]）；用于混合的分节运动；移行性运动复合（禁食期的清洁工、与胃动素相关——早餐前的涟漪、及糖尿病自主神经病变的胃瘫——[[endocrine/diabetes-complications]]与[[nervous-system/neuromuscular]]）；容受性舒张与适应（胃底作为储器——早期饱胀背后的压力容量曲线——[[gastrointestinal/oesophagus-stomach]]）；及胃结肠反射、回肠刹车与排便反射（直肠取样反射区分气体与内容物、及皮层训练出的节制——[[paediatrics/growth-development]]的排便生理与[[anatomy/pelvis-perineum]]）。括约肌（上下食管括约肌、幽门、回盲、及成对的内不随意与外随意肛门括约肌——邻近[[nervous-system/motor-systems]]的阴部神经控制）为每个腔室设门、而各有各的病：失弛缓的下食管括约肌、婴儿肥厚性狭窄的幽门（[[paediatrics/acute-childhood-illness]]）、及产伤的肛门括约肌（[[obstetrics-gynaecology/labour-birth]]与[[obstetrics-gynaecology/menstrual-pelvic-disorders]]）。**
:::

::: definition 分泌：唾液、酸、胆汁、胰液与肠激素 {#def-secretion}
**唾液（每天1-1.5升——浆液与黏液腺泡受自主控制（交感厚干对副交感稀的悖论）、携带淀粉酶、脂肪酶、免疫球蛋白A、溶菌酶与牙釉质保护蛋白——[[immunology/adaptive-responses]]与[[gastrointestinal/oesophagus-stomach]]）。****胃液每天1.5-2升、酸度达腔内160 mmol/L：壁细胞的质子泵带其碳酸酐酶化学、小管放大与线粒体负荷（[[cell-biochemistry/membranes-transport]]、及远端肾小管的质子泵作为表亲——[[renal/tubular-function]]）；三个汇聚输入——M3上的乙酰胆碱、肠嗜铬样细胞H2上的组胺、胃窦G细胞CCK2上的胃泌素带其酸碱度反馈——这就是为何泵阻滞剂单独就能关闭全部三条（[[pharmacology/drug-receptor]]的最终共同通路例子、及[[#def-secretion]]餐前定时的质子泵抑制剂设计）；胃蛋白酶原在pH 5以下自激活；及黏液碳酸氢盐上皮前列腺素防御（环氧化酶1来源的前列腺素维持黏液、碳酸氢盐与灌注——一句话讲清非甾体抗炎药溃疡：[[pharmacology/adverse-reactions]]、[[gastrointestinal/oesophagus-stomach]]、及与[[renal/filtration]]入球小动脉张力相同的前列腺素逻辑）。****胰液（每天1-2升：腺泡细胞分泌酶（酶原颗粒；胰蛋白酶原受缩胆囊素与迷走控制——[[cell-biochemistry/proteins-enzymes]]）、而导管细胞在促胰液素下通过依赖囊性纤维化跨膜电导调节器的机制分泌富含碳酸氢盐的液体——这一条通道的失效同时产出囊性纤维化的胰、肺、汗与胎粪性肠梗阻表型（[[genetics/mendelian-inheritance]]、[[respiratory/respiratory-infections]]、[[paediatrics/congenital-genetic]]）；肠激酶胰蛋白酶级联与其过早激活问题在[[gastrointestinal/pancreas-biliary]]）。****胆汁肝的胆固醇到胆汁酸合成在限速酶一步、带核受体成纤维细胞生长因子19反馈——[[gastrointestinal/liver-function]]；毛细胆管转运体分泌、其缺陷即家族性胆汁淤积——[[gastrointestinal/liver-disease]]；胆囊浓缩与缩胆囊素驱动的排出（[[gastrointestinal/pancreas-biliary]]）；及在末端回肠重吸收约95%胆盐池的肠肝循环（[[renal/tubular-function]]的转运体动力学再次）——熊去氧胆酸治疗、及回肠切除后胆汁酸性腹泻与胆石风险的基础（[[gastrointestinal/bowel-disease]]与[[#ex-stones-ileum]]）。****肠激素弥散内分泌细胞系统——胃泌素、缩胆囊素、促胰液素、葡萄糖依赖性促胰岛素肽、胃动素、胰高血糖素样肽1、肽YY——来自Starling与Bayliss 1902年铸造“激素”一词的促胰液素（[[physiology/hormones]]）；肠促胰效应如今成为治疗学（[[endocrine/diabetes]]）；激素分泌肿瘤综合征——胃泌素瘤、胰高血糖素瘤、血管活性肠肽瘤、类癌（[[gastrointestinal/pancreas-biliary]]与[[pathology/cancer-diagnosis]]）；及饱胀与呕吐的肠脑信号（迷走传入与化学感受器触发带——邻近[[geriatrics-palliative/symptom-control]]的止吐药理学）。**
:::

## 消化与吸收

::: definition 巨量营养素的化学与转运 {#def-digest}
**液体预算：每天约9升进入小肠（摄入1-2升、分泌约7升）、约99%被重吸收——空肠大量的渗透与溶剂拖曳吸收（[[renal/filtration]]的Starling配对）、回肠与结肠的回收直至约1.5升（[[renal/water-sodium]]）——所以几升处理不当就是临床腹泻（[[#def-diarrhoea]]）。** **碳水化合物：淀粉酶到双糖、然后刷状缘麦芽糖酶葡萄糖淀粉酶、蔗糖酶异麦芽糖酶与乳糖酶（其发育性下调是世界上最常见的正常变异、而乳糖持续是调控变异的成功案例——[[genetics/common-disease-genetics]]）；葡萄糖与半乳糖经钠葡萄糖协同转运体1然后基底侧葡萄糖转运体2出去（[[cell-biochemistry/membranes-transport]]）、果糖经葡萄糖转运体5；未吸收的糖留住渗透性水并发酵——乳糖呼气试验原理（[[clinical-skills/laboratory-tests]]）。** **蛋白质：胃蛋白酶加胰蛋白酶级联（肠激酶激活胰蛋白酶原——[[gastrointestinal/pancreas-biliary]]）成二肽三肽由肽转运体1吸收、加游离氨基酸由钠与氢偶联系统；罕见的转运病跨器官阅读——胱氨酸尿症既是结石也是转运课（[[renal/urinary-tract]]）、及Hartnup病作为色氨酸丢失的糙皮病（[[gastrointestinal/clinical-nutrition]]与[[genetics/mendelian-inheritance]]）。** **脂质：最依赖分泌的巨量营养素——胆汁酸微团加胰脂肪酶与辅脂酶、肠细胞再酯化与载脂蛋白B48上的乳糜微粒组装（[[cell-biochemistry/lipid-amino-acid-metabolism]]与[[cardiovascular/vascular-disease]]）、淋巴乳糜管转运（因此其梗阻时出现乳糜腹水与蛋白丢失性肠病——[[gastrointestinal/liver-disease]]）；中链甘油三酯绕过微团一步——短肠配方的教训（[[gastrointestinal/clinical-nutrition]]）；而胰功能不全因此首先造成脂肪泻（[[#def-diarrhoea]]）。** **微量营养素地址（[[#def-diarrhoea]]的缺乏地图）：铁在十二指肠（金属离子转运体1、膜铁转运蛋白、及作为总开关的铁调素——[[blood/anaemia]]与[[immunology/innate-immunity]]）、钙与维生素D在十二指肠空肠（[[endocrine/bone-calcium]]）、叶酸在空肠、及维生素B12内因子在末端回肠（[[blood/anaemia]]与[[#ex-b12]]）。** **以及屏障：紧密连接、黏液层、分泌型免疫球蛋白A与Peyer结（[[immunology/adaptive-responses]]）、及微生物群黏膜界面——发酵纤维产生的短链脂肪酸作为结肠细胞燃料、抗生素后的菌群失调、及肠肺与肠脑信号文献（[[microbiology/microbiota]]）。**
:::

::: example 渗透性对分泌性 {#ex-diarrhoea-types}
两份水样腹泻。(a) 24岁者在大量饮奶后：粪便渗透压290 mOsm/kg、钠40、钾40；症状随禁食停止。(b) 一位归国旅行者：粪便渗透压295、钠140、钾20、输出约每小时1升、禁食后持续。
::: solution
**算术就是诊断（[[#def-diarrhoea]]）：(a) 渗透间隙 = 290 − 2×(40+40) = 90——高：有未测量的渗透活性糖；乳糖酶缺乏、禁食试验停止、酸性发酵粪便（[[clinical-skills/laboratory-tests]]）。(b) 间隙 = 295 − 2×160 = 15——近零、钠主导、禁食持续：分泌性。霍乱的腺苷二磷酸核糖基化把刺激型G蛋白环磷酸腺苷锁在开放的囊性纤维化跨膜电导调节器上（[[microbiology/bacterial-pathogenesis]]与[[cell-biochemistry/signalling-cell-cycle]]）——“毒素麻痹吸收”的故事一半是神话：钠葡萄糖协同转运体1仍可工作、这正是口服补液所利用的（下文、在[[gastrointestinal/clinical-nutrition]]）。同一条通道与囊性纤维化构成首尾（[[genetics/mendelian-inheritance]]）。要管理的后果：钾与碳酸氢盐丢失（[[renal/potassium-calcium-phosphate]]与[[renal/acid-base-disorders]]）、休克风险（[[emergency-critical-care/shock-fluids]]）、粪便培养与通报义务（[[microbiology/laboratory-diagnosis]]与[[public-health/communicable-disease-control]]）、及旅行医学预防谈话（[[public-health/global-health]]）。**
:::
:::

::: definition 作为综合征的腹泻与吸收不良 {#def-diarrhoea}
**腹泻（≥3次稀便或每天>200克）：急性（<14天——感染性、药物性（[[pharmacology/adverse-reactions]]的二甲双胍质子泵抑制剂缓泻剂镁化疗清单）、迁延性、或慢性（≥4周）。四机制分类学：渗透性（粪便间隙高、禁食有反应——糖、吸收不良、镁）；分泌性（间隙低、禁食持续——毒素、胆汁酸吸收不良（[[gastrointestinal/pancreas-biliary]]）、神经内分泌肿瘤（血管活性肠肽、胃泌素、类癌——[[gastrointestinal/pancreas-biliary]]）、及缓泻剂滥用（[[psychiatry/eating-personality-disorders]]））；炎症性（血与脓、发热、钙卫蛋白乳铁蛋白筛查、组织学——[[gastrointestinal/bowel-disease]]与[[pathology/diagnostic-pathology]]的炎症性肠病检查程序）；及动力紊乱（糖尿病性、术后与感染后、甲状腺毒症——[[endocrine/thyroid]]））、带夜间模式作为器质性红旗。** 转向紧急检查的红旗（血、体重下降、夜间症状、50岁后新发、癌家族史、免疫抑制、发热、近期抗生素——[[gastrointestinal/gi-bleeding-cancer]]路径与[[public-health/screening]]的诊断延迟审计）对肠易激模式管理（[[gastrointestinal/bowel-disease]]的罗马标准与[[#ex-stones-ileum]]及[[#def-diarrhoea]]的试验治疗）。检查阶梯（[[clinical-skills/laboratory-tests]]）：**粪便（培养、艰难拟梭菌、寄生虫、虫卵、免疫抑制中的微孢子虫——[[microbiology/laboratory-diagnosis]]、[[infectious-diseases/immunocompromised-host]]）、血（乳糜病血清学加总免疫球蛋白A、全血细胞、铁蛋白、维生素B12叶酸、甲状腺功能、人类免疫缺陷病毒——[[infectious-diseases/hiv]]）、粪弹性蛋白酶、氢甲烷呼气（小肠细菌过度生长与碳水吸收不良——[[microbiology/microbiota]]）、及带靶向活检的内镜。** 按机制治疗、而补液到处是降低死亡率的那一项（[[gastrointestinal/clinical-nutrition]]、[[paediatrics/acute-childhood-illness]]的口服补液与锌规划、及[[public-health/global-health]]的霍乱与轮状病毒规划）。** 吸收不良（脂肪泻、体重下降、脂溶性维生素缺乏——因维生素K出血（[[blood/haemostasis-bleeding]]）、骨软化（[[endocrine/bone-calcium]]）、夜盲（[[nervous-system/sensory-systems]]）——加铁叶酸与维生素B12的贫血（[[blood/anaemia]]））：三层病因搜寻——**腔内（胰功能不全伴粪弹性蛋白酶低（[[gastrointestinal/pancreas-biliary]]）；梗阻或回肠疾病致胆汁酸缺乏（[[gastrointestinal/liver-disease]]与[[gastrointestinal/bowel-disease]]）；小肠细菌过度生长（[[microbiology/microbiota]]）；罕见的酶与转运病（[[genetics/mendelian-inheritance]]））；黏膜（乳糜病——组织转谷氨酰胺酶加总免疫球蛋白A、人类白细胞抗原DQ2/DQ8、绒毛萎缩、疱疹样皮炎（[[gastrointestinal/bowel-disease]]与[[musculoskeletal/skin]]）；人类免疫缺陷病毒肠病与贾第鞭毛虫及热带口炎性腹泻（[[infectious-diseases/hiv]]、[[microbiology/fungi-parasites]]、[[public-health/global-health]]）；药物肠病包括奥美沙坦模仿者（[[pharmacology/adverse-reactions]]）；放射、淀粉样、Whipple、肥大细胞与嗜酸细胞疾病（[[pathology/chronic-inflammation-repair]]与[[microbiology/bacteria]]））；及外科解剖性（伴肠衰竭的短肠、全肠外营养与适应阶段（[[gastrointestinal/clinical-nutrition]]）；盲袢与改道解剖带代谢手术的缺乏台账（[[surgery/gastrointestinal-surgery]]与[[endocrine/diabetes]]倾倒生理）；内瘘与粘连（[[surgery/gastrointestinal-surgery]]））。缺乏地图成语：只有铁说十二指肠或失血；只有维生素B12说回肠或胃；全面缺乏说空肠广泛黏膜病或胰液缺失（[[#def-digest]]的地址）。**

::: example 舌痛的贫血 {#ex-b12}
一名68岁长期素食者、服二甲双胍15年：血红蛋白88、平均红细胞体积112、中性粒细胞分叶过多、维生素B12低、叶酸临界、舌炎、趾麻；抗壁细胞抗体阳性。
::: solution
**伴神经病变的大细胞贫血除非证明否则就是维生素B12缺乏（[[blood/anaemia]]与后索与皮质脊髓受累的亚急性联合变性模式——[[nervous-system/motor-systems]]）。病因叠加（[[#def-digest]]的维生素B12地址）：恶性自身免疫萎缩性胃炎（壁细胞与内因子丢失——[[gastrointestinal/oesophagus-stomach]]的癌监测推论、要筛查的多腺体自身免疫关联——[[endocrine/thyroid]]、[[endocrine/adrenal]]、[[immunology/autoimmunity]]；抗体对加胃泌素辅助——[[clinical-skills/laboratory-tests]]）；二甲双胍按剂量与疗程相关的回肠维生素B12吸收干扰（[[endocrine/diabetes-complications]]与年度监测论点）；及饮食。两个经典危险：**叶酸单药治疗纠正血象而神经病变继续进展、及甲基丙二酸与同型半胱氨酸生物化学（[[cell-biochemistry/lipid-amino-acid-metabolism]]）带其心血管风险假说与其流行病学澄清（[[epidemiology-ebm/observational-studies]]）。补充：**肌注羟钴胺的负荷与维持方案（非神经非恶性病例的高剂量口服选项——[[blood/anaemia]]）、预期补充过程中的低钾与铁缺乏揭露（[[renal/potassium-calcium-phosphate]]）、并按病因终末处理（恶性贫血的终身注射对二甲双胍风险获益对补充剂；叶酸强化的神经管预防背景——[[obstetrics-gynaecology/pregnancy-antenatal]]与[[public-health/prevention-promotion]]）；及难治病例回路（核查依从、叶酸、骨髓增生异常与铜——[[blood/haematopoiesis]]）。**

::: example 回肠切除三年后 {#ex-stones-ileum}
一名34岁克罗恩病患者、末端回肠切除60厘米、反复稀便、一枚4毫米输尿管结石（分析为草酸钙）、维生素B12为90 pmol/L。
::: solution
**一次切除、三堂生理课（[[#def-secretion]]与[[#def-digest]]）：(i) 胆汁酸池被打断——切除短时、未吸收的胆汁酸驱动结肠分泌（胆汁性腹泻、胆酪胺有反应——[[gastrointestinal/bowel-disease]]）；切除长时、池被耗竭而脂肪本身消化不良（脂肪泻——[[#def-diarrhoea]]）；(ii) 腔内钙被耗竭（忙着把未吸收的脂肪变成钙皂）使草酸游离供结肠吸收——肠性高草酸尿与草酸钙结石、正是[[renal/urinary-tract]]结石病例的机制（其自身的泌尿外科后遗）；及iii) 末端回肠没了——维生素B12吸收不良带其贫血神经病变轨迹（[[#ex-b12]]）及胆汁酸丢失加重腹泻。处理：**维生素B12替代（因部位而用肠外）、胆汁酸螯合剂试验对相反处理（若脂肪泻主导就停它——100厘米规则）、结石预防算术（液体、餐中钙作为草酸结合剂、柠檬酸盐——[[gastrointestinal/clinical-nutrition]]）、脂溶性维生素与叶酸铁的清扫（[[endocrine/bone-calcium]]与[[blood/anaemia]]）、炎症性肠病复发监测（[[gastrointestinal/bowel-disease]]）及参照全肠外营养的严重度界线（[[gastrointestinal/clinical-nutrition]]）。**
:::
:::

::: example 不长身体的幼儿 {#ex-cf}
一名11月龄（生长迟缓、体重低于第0.4百分位）有大量油腻恶臭粪便、腹胀、维生素D 28 nmol/L伴碱性磷酸酶升高、今冬两次肺部感染；汗氯96 mmol/L。
::: solution
**以吸收不良呈现的囊性纤维病胰腺外分泌功能不全（邻近[[genetics/mendelian-inheritance]]与[[paediatrics/congenital-genetic]]与[[respiratory/respiratory-infections]]）：导管囊性纤维化跨膜电导调节器失败使分泌变稠、阻塞胰管、并摧毁腺泡——脂肪酶与蛋白酶递送首先失败（[[#def-digest]]规则：脂肪是最依赖分泌的巨量营养素）、于是脂肪泻、热量丢失、脂溶性维生素缺乏（这里的维生素D与骨图像——[[endocrine/bone-calcium]]；维生素K出血风险——[[blood/haemostasis-bleeding]]；维生素A——[[nervous-system/sensory-systems]]）及必需脂肪酸缺陷跟随、而肺、汗、肝胆与肠并发症并行（胎粪性肠梗阻等价物的远端肠梗阻综合征、胆道疾病、及新生儿筛查故事——[[paediatrics/growth-development]]与[[public-health/screening]]）。** 处理：**按体重与进餐时脂肪症状定量的胰酶替代（[[gastrointestinal/pancreas-biliary]]的酶充分性标志物——粪弹性蛋白酶在此持续偏低所以无法用于监测治疗——[[clinical-skills/laboratory-tests]]）；高热量高蛋白膳食带维生素矿物质补充与酶协调（[[gastrointestinal/clinical-nutrition]]团队）；生长曲线与膳食回顾监测（[[paediatrics/growth-development]]）；胸部理疗与微生物规划及调节剂时代（[[genetics/genomic-medicine]]的突变特异囊性纤维化跨膜调节剂正在改变营养轨迹本身）；为家庭的遗传咨询与同胞的新生儿筛查级联（[[genetics/genetic-testing]]）；及从开始就有的过渡规划习惯（[[paediatrics/acute-childhood-illness]]的儿童转成人门诊交接文献与[[clinical-skills/records-handover]]）。**

::: history
**Pavlov学派的头部期假饲狗；Bayliss与Starling的促胰液素（1902）——铸造“激素”一词的发现（[[physiology/hormones]]）；Ivy的胃泌素提取物（1937）及后来缩胆囊素、葡萄糖依赖性促胰岛素肽与胃动素的纯化；** **Castle的内因子（1929）带Minot与Murphy及Whipple的肝脏治疗时代、首次使恶性贫血成为可治之病（诺贝尔1934——[[blood/anaemia]]）；** **质子泵生物化学（Sachs与Ganser学派、1970年代）及奥美拉唑1979年的到来（[[pharmacology/drug-receptor]]）；** **霍乱毒素环磷酸腺苷级联（1970年代）遇见囊性纤维化跨膜电导调节器的克隆（1989）——毒素与疾病作为镜像通道生理（[[microbiology/bacterial-pathogenesis]]与[[genetics/mendelian-inheritance]]）；** **口服补液革命（1960-70年代霍乱研究实验室从生理到公共卫生的转化——[[public-health/global-health]]）；** **肠促胰之路从1906年“提取物”事件与1932年观察到胰高血糖素样肽1生物学及其药物（[[endocrine/diabetes]]）；**及**乳糜病血清学与粪钙卫蛋白的诊断现代化（[[clinical-skills/laboratory-tests]]与[[gastrointestinal/bowel-disease]]）**完成了从消化生理到现代胃肠门诊的血脉。**
:::

## 通向何处

酸疾病在[[gastrointestinal/oesophagus-stomach]]；动力与功能疾病及炎症性肠病在[[gastrointestinal/bowel-disease]]；胰功能不全在[[gastrointestinal/pancreas-biliary]]；胆汁与肝处理在[[gastrointestinal/liver-function]]与[[gastrointestinal/liver-disease]]；肠衰竭的挽救在[[gastrointestinal/clinical-nutrition]]；神经控制在[[physiology/autonomic-nervous-system]]与[[anatomy/abdomen]]；缺乏的后遗在[[blood/anaemia]]与[[endocrine/bone-calcium]]；微生物群在[[microbiology/microbiota]]。

::: exercise 预测相互作用 {level=2}
长期质子泵抑制剂治疗：用生理学解释铁、维生素B12、伊曲康唑与镁吸收减少、并说出补偿措施。
::: solution
**依赖酸的溶解与释放：三价到二价铁的还原与盐的溶解需要pH<3（十二指肠铁摄取——[[#def-digest]]、[[blood/anaemia]]）；蛋白结合的维生素B12需要胃酸从食物中释放之后才能结合内因子（[[#ex-b12]]）；伊曲康唑胶囊需要胃酸（[[pharmacology/absorption-distribution]]——溶液剂型与酸性饮料变通的警诫）；镁的细胞旁吸收下降（[[renal/tubular-function]]与[[renal/potassium-calcium-phosphate]]的镁课）驱动伴继发性低钙低钾的低镁综合征（[[renal/potassium-calcium-phosphate]]与[[endocrine/bone-calcium]]）。补偿：在安全处分开给药并酸化、监测并补充（在长期使用者风险人群中的镁、维生素B12与铁年度检查——[[pharmacology/patient-variation]]）、及每一次复审都复查适应证——[[#def-secretion]]章的去处方规程。**
:::

::: summary
- 动力由起搏器驱动并由反射组织（蠕动、分节、禁食期移行性运动复合、括约肌门）；其失败按地址产出类似梗阻、反流与动力障碍综合征。
- 酸输出是迷走、组胺与胃泌素汇聚到一个泵之处——因此质子泵抑制剂覆盖面宽、而非甾体抗炎药溃疡经前列腺素削减防御而具特异性。
- 吸收具有地址特异并由转运体定义（钠葡萄糖协同转运体1、肽转运体1、先微团后乳糜微粒、金属离子转运体1、内因子回肠）；缺乏地图像皮节图一样定位黏膜病变。
- 腹泻按禁食试验、粪便渗透间隙、钙卫蛋白与病史分为渗透性、分泌性、炎症性与动力性——各自有自己的治疗。
- 吸收不良区分腔内、黏膜与外科病因；胰液、胆汁、一个工作的黏膜与肠长度是吸收的四个前提。
:::

## 练习

::: exercise 画出这个泵 {level=1}
把盐酸分泌从碳酸酐酶一路画到毛细胆管、并标出三个受体靶点与最终共同通路。
::: solution
**二氧化碳水合给出细胞内氢离子（氯离子经氯通道随电位跟进、钾被循环）、由质子泵排出（[[cell-biochemistry/membranes-transport]]、[[renal/tubular-function]]）；靶点为M3（乙酰胆碱）、H2（组胺）、CCK2（胃泌素）——及泵自身、在三者下游（[[pharmacology/drug-receptor]]、[[gastrointestinal/oesophagus-stomach]]）；防御一侧（前列腺素、黏液、碳酸氢盐、灌注）就是米索前列醇的立论（[[pharmacology/adverse-reactions]]）。**

::: exercise 解释结石 {level=1}
为何回肠切除短段时造成腹泻、而长段时造成胆石与肾石？
::: solution
**胆汁酸经济学（[[#def-secretion]]）：小量丢失留下未吸收的胆汁酸刺激结肠（分泌性胆汁性腹泻、胆酪胺有反应——[[gastrointestinal/bowel-disease]]）；大量丢失耗竭池→脂肪消化不良与脂肪泻（[[#def-diarrhoea]]）、钙结合脂肪而不结合草酸→肠性高草酸尿与草酸钙结石（[[renal/urinary-tract]]）、及缩小的胆盐池造成成石性胆汁→胆固醇胆石（[[gastrointestinal/pancreas-biliary]]）；加上在其地址的维生素B12丢失（[[#ex-b12]]）。见[[#ex-stones-ileum]]——一次切除、四处病变。**
:::

::: exercise 用这个间隙 {level=2}
可疑缓泻剂滥用腹泻：粪便钠60、钾50、渗透压295。计算间隙、并解释为何单靠数字无法定案。
::: solution
**间隙 = 295 − 2×(60+50) = 75——一个中间值：粪便渗透压按构造接近血浆、而当标本放置过久（细菌消耗）或脂质与未测阴离子（缓泻剂盐、镁）移动时间隙会误导（[[clinical-skills/laboratory-tests]]）。定案的检验是粪便刺激性泻药与镁筛查、内镜下的结肠黑变病线索（[[gastrointestinal/bowel-disease]]）、低钾伴碱中毒对酸中毒模式（[[renal/potassium-calcium-phosphate]]与[[renal/acid-base-disorders]]——血管活性肠肽瘤给出酸性、水样、富氯的丢失）、及以非对抗方式完成的精神科框定（[[psychiatry/eating-personality-disorders]]、[[clinical-skills/communication]]）。**
:::

::: exercise 选择口服补液盐 {level=2}
为何葡萄糖出现在口服补液盐中、而它不能以同样渗透压加入静脉液体？
::: solution
**葡萄糖是共底物、使钠葡萄糖协同转运体1（每个葡萄糖两个钠）的电中性并产生渗透水的吸收在毒素驱动的分泌之下继续（[[#def-digest]]与霍乱测验）；低渗透压配方在钠糖偶联最大化与腔内张力之间取平衡（[[gastrointestinal/clinical-nutrition]]与世界卫生组织规划证据——[[public-health/global-health]]）。静脉内同样的葡萄糖水组合是错误的途径（静脉绕过转运体、而低张糖水输注造成高血糖渗透性利尿与低钠血症——[[renal/water-sodium]]）；口服补液盐是一项肠道技术（[[paediatrics/acute-childhood-illness]]的口服补液与锌、及需要静脉者用[[emergency-critical-care/shock-fluids]]）。**
:::

::: exercise 定位缺乏 {level=2}
[[#def-diarrhoea]]层级的哪一层解释每一对：(a) 铁缺乏而维生素B12正常；(b) 维生素B12与叶酸都低；(c) 脂肪泻伴维生素D低而粪弹性蛋白酶正常？
::: solution
**(a) 腔内正常、黏膜十二指肠（乳糜病、幽门螺杆菌胃炎、自身免疫）或失血——铁地址规则（[[#def-digest]]、[[blood/anaemia]]、[[gastrointestinal/oesophagus-stomach]]）；(b) 广泛的空肠回肠黏膜病、或药物加饮食组合（热带口炎性腹泻、人类免疫缺陷病毒、二甲双胍加抗癫痫药——[[public-health/global-health]]、[[infectious-diseases/hiv]]、[[pharmacology/adverse-reactions]]）；(c) 不是胰源性：胆汁酸缺乏（胆汁淤积、回肠疾病）或黏膜脂肪吸收失败（[[gastrointestinal/liver-disease]]、[[gastrointestinal/bowel-disease]]）——弹性蛋白酶是胰源与否的裁判（[[clinical-skills/laboratory-tests]]、[[gastrointestinal/pancreas-biliary]]）。**
:::

::: exercise 质子泵抑制剂之问 {level=2}
一名服奥美拉唑六年的患者要求停药。给出复查、减量与反跳生理。
::: solution
**复查适应证（糜烂性食管炎、Barrett、溃疡出血预防→继续（[[gastrointestinal/oesophagus-stomach]]、[[gastrointestinal/gi-bleeding-cancer]]）；无适应证的消化不良→停药试验）。诚实命名的风险：骨折与镁及维生素B12铁信号（[[endocrine/bone-calcium]]、[[renal/potassium-calcium-phosphate]]、[[#ex-b12]]）、艰难拟梭菌与院内肺炎关联（[[infectious-diseases/healthcare-infections]]）、及带适应症混杂警诫的慢性肾病关联（[[renal/chronic-kidney-disease]]、[[epidemiology-ebm/observational-studies]]）。反跳机制：**慢性抑酸升高胃泌素与泵表达、所以突然停用会过度分泌约1-3周（[[#def-secretion]]及其图注的夜间要点）——因此减量或隔日给药、带按需藻酸盐抗酸覆盖与4周复查（[[clinical-skills/records-handover]]、[[geriatrics-palliative/polypharmacy]]的去处方框架、及功能症状应对计划——[[gastrointestinal/bowel-disease]]的脑肠调节）。**

::: exercise 设计腹泻门诊 {level=3}
设计一个慢性腹泻服务：分诊、套餐架构、经验性试验阶梯、及随访数据集。
::: solution
**分诊：红旗之门通向紧急内镜与断层影像（[[gastrointestinal/gi-bleeding-cancer]]、[[clinical-skills/medical-imaging]]）带粪钙卫蛋白作为炎症对功能的分界（[[gastrointestinal/bowel-disease]]）；免疫抑制与旅行史路径（[[infectious-diseases/immunocompromised-host]]、[[public-health/global-health]]）。套餐：粪便组（培养、艰难拟梭菌、寄生虫、电解质与间隙、钙卫蛋白——[[microbiology/laboratory-diagnosis]]、[[clinical-skills/laboratory-tests]]）、血清组（乳糜二项加总免疫球蛋白A、全血细胞铁蛋白维生素B12叶酸、甲状腺功能、人类免疫缺陷病毒、弹性蛋白酶配对——[[endocrine/thyroid]]、[[infectious-diseases/hiv]]、[[gastrointestinal/pancreas-biliary]]）、及带产甲烷者警诫的氢甲烷呼气（[[microbiology/microbiota]]）。按产出排序的试验阶梯：**膳食试验（乳糖、果糖、低发酵寡糖双糖单糖和多元醇配营养师——[[gastrointestinal/clinical-nutrition]]）、螯合剂试验（胆汁酸性腹泻——[[gastrointestinal/pancreas-biliary]]）、酶试验（胰功能不全——按体重定量）、抗炎路径（炎症性肠病升级——[[gastrointestinal/bowel-disease]]）及分泌性搜寻（神经内分泌肿瘤影像与降钙素及儿茶酚胺——[[gastrointestinal/pancreas-biliary]]、[[endocrine/thyroid]]、[[endocrine/adrenal]]）带伪造品筛查（[[psychiatry/eating-personality-disorders]]）。随访数据集：粪便日记、体重、水化与电解质安全监测（[[renal/potassium-calcium-phosphate]]）、生活质量评分、升级标准、及转诊精确度关键指标（[[clinical-skills/clinical-reasoning]]、[[public-health/health-systems-economics]]）——门诊首诊规则重述：在再加一种止泻药之前按机制分类（[[gastrointestinal/digestion-absorption]]）。**
