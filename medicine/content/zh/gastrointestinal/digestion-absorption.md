成年人每天摄入含有数百克碳水化合物、蛋白质和脂肪的食物，另外还要喝约2升液体。消化道自身再加入约7升分泌液。等到残渣以粪便形式排出时，这些水分几乎全部、营养物质也几乎全部已经进入体内。胃肠道依靠四种协同工作的功能完成这件事：**动力**推动并混合内容物，**分泌**提供酶、酸、碳酸氢盐和胆汁，**消化**把大分子分解成小分子，**吸收**把小分子转运过肠黏膜。

大多数胃肠道症状都是这四种功能之一出了问题。腹泻通常是吸收不足或分泌过多。吸收不良是消化或吸收的失败。反流和许多溃疡属于动力和胃酸分泌的紊乱。理解了正常生理，本课程其余部分的疾病就容易推理得多。

本章介绍消化道管壁的结构与调控、动力、主要分泌液及调控它们的激素、各类营养物质的消化与吸收、铁、维生素B12和胆盐这几个特殊情况，最后介绍腹泻与吸收不良的机制。

## 消化道管壁及其调控

从食管到直肠，管壁的基本分层是一致的。**黏膜**包括上皮、其下支持的固有层和一薄层肌肉。**黏膜下层**含有血管、淋巴管和一个神经丛。**固有肌层**由内环外纵两层平滑肌构成。在腹膜内的肠段，外表面覆盖**浆膜**。解剖细节见[[anatomy/abdomen]]。

在小肠，环状皱襞、绒毛和微绒毛使吸收面积扩大数百倍。成熟的吸收细胞位于绒毛上，分裂中的干细胞位于隐窝内。上皮每3～5天更新一次，这正是它对化疗和放疗如此敏感的原因。

::: definition 动力及其调控 {#def-motility}
**胃肠动力**是消化道平滑肌混合和推进内容物的协调收缩。它在三个层面受到调控：

- **起搏细胞。** Cajal间质细胞产生有节律的膜电位**慢波**。慢波决定收缩的最高频率：胃约每分钟3次，十二指肠约每分钟12次，回肠更少。
- **肠神经系统。** 位于两层肌肉之间的**肌间（Auerbach）神经丛**主要控制动力。**黏膜下（Meissner）神经丛**主要控制分泌和局部血流。两者共含数亿个神经元，可以在没有大脑输入的情况下完成反射。
- **外来神经和激素。** 副交感纤维（迷走神经和盆神经）通常增强动力和分泌。交感纤维通常减弱它们并使括约肌收紧。胃肠激素对两者都有调节作用。
:::

单独的慢波并不引起收缩；必须有由牵张、乙酰胆碱或激素触发的锋电位叠加在慢波之上。慢波设定节律，神经决定每一拍是否被利用。

临床上重要的运动形式有三种。**蠕动**是食团后方收缩、前方舒张的波。它是由牵张触发的局部反射，食管正是靠它在几秒内把吞下的食物送走。**分节运动**是原地的收缩，把小肠内容物分割并重新混合，增加与黏膜的接触。**移行性复合运动**（MMC）是一带强有力的收缩，在空腹时大约每90分钟从胃扫向回肠一次。它在两餐之间清除残渣和细菌。胃动素触发它，进食使它消失；红霉素作用于胃动素受体，因此可以用作促动力药。

胃有自己的特点。胃的上部即胃底在食物到达时舒张（**容受性舒张**），因此一餐饭可以储存而压力不升高。胃窦把食物研磨后推向正在关闭的幽门，只允许直径小于约2 mm的颗粒通过。液体很快离开胃；固体大致呈线性排空，历时2～4小时。十二指肠内的脂肪和酸通过神经和激素减慢胃排空，所以油腻的一餐在胃内停留更久。

结肠推进内容物很慢，历时1～3天，以便吸收水分和细菌发酵。每天数次，常在餐后（**胃结肠反射**），**集团运动**把内容物推送一大段距离。

## 分泌液与胃肠激素

消化道及其腺体每天分泌约7升液体。每种分泌液都有自己的任务和调控系统。

::: definition 主要消化液 {#def-secretion}
| 分泌液 | 每日量 | 主要成分 | 主要刺激 |
|---|---|---|---|
| 唾液 | 约1～1.5 L | 水、碳酸氢盐、淀粉酶、黏液 | 副交感神经 |
| 胃液 | 约2 L | 盐酸、胃蛋白酶原、内因子、黏液 | 迷走神经、胃泌素、组胺 |
| 胰液 | 约1.5 L | 碳酸氢盐、蛋白酶、脂肪酶、淀粉酶 | 促胰液素、CCK、迷走神经 |
| 胆汁 | 约0.5～1 L | 胆盐、磷脂、胆固醇、胆红素 | CCK（胆囊收缩）、促胰液素（胆管碳酸氢盐） |
| 肠液 | 约1.5 L | 水和电解质、黏液 | 局部反射、CFTR氯离子通道 |

各量为近似值，随饮食而变化。
:::

### 胃酸

胃体和胃底的**壁细胞**分泌浓度最高约150 mmol/L的盐酸，使胃腔pH达到1～2。最后一步由**H⁺/K⁺-ATP酶**即质子泵完成，它在细胞顶膜上以氢离子交换钾离子。氯离子经顶膜通道随之分泌。每分泌一个氢离子，就有一个碳酸氢根离子从细胞基底外侧进入血液。餐后这会使血碳酸氢盐轻度升高，称为**碱潮**。

三种刺激作用于壁细胞，并相互增强：

- 迷走神经末梢释放的**乙酰胆碱**作用于毒蕈碱M3受体。
- 胃窦G细胞分泌的**胃泌素**作用于CCK2受体。胃泌素还刺激**肠嗜铬样（ECL）细胞**释放组胺。
- ECL细胞释放的**组胺**作用于H2受体。它是最强的单一放大环节，因为迷走和胃泌素信号都部分经它传递。

制动因素是D细胞分泌的**生长抑素**，当胃窦pH降到约3以下时释放。它抑制胃泌素释放，也直接抑制胃酸分泌。这种负反馈意味着胃酸分泌能自我限制。

胃酸分泌分三期。**头期**中，食物的形、气味和味道通过迷走神经起作用。**胃期**中，餐食的牵张和肽类引起胃泌素释放；这一期产生大部分胃酸。**肠期**中，十二指肠内的酸和脂肪主要起抑制胃分泌的作用。

这些通路是抑酸药的靶点。**H2受体拮抗剂**阻断组胺信号。**质子泵抑制剂**（PPI），如奥美拉唑（omeprazole）和兰索拉唑（lansoprazole），与活化的质子泵不可逆结合，阻断最后共同环节，因此抑酸更彻底。由于PPI只作用于正在分泌的质子泵，在餐前服用、质子泵正被激活时效果最好。新的质子泵约一天内合成，所以疗效需要数天逐渐建立，并在一次给药后持续存在。

### 胰液与胆汁

胰腺有两套分泌系统。**腺泡细胞**合成消化酶，大多以无活性的前体形式存在。**胰蛋白酶原**在十二指肠被刷状缘上的**肠肽酶**（肠激酶）激活，胰蛋白酶再激活其他酶原。这一顺序保护胰腺不消化自身；当这一过程在腺体内部失控时，就发生胰腺炎（[[gastrointestinal/pancreas-biliary]]）。**导管细胞**分泌大量富含碳酸氢盐的液体，在十二指肠中和胃酸。导管细胞依靠**CFTR**氯离子通道驱动这种分泌，这就是囊性纤维化中胰腺损害如此常见的原因。

**胆汁**由肝细胞生成，并由胆管细胞加以修饰。其关键成分是**胆盐**，由胆固醇合成，起去污剂作用。两餐之间Oddi括约肌关闭，胆汁储存于胆囊并被浓缩。进食油腻食物后，缩胆囊素使胆囊收缩、括约肌舒张。

### 胃肠激素

消化道是体内最大的内分泌器官。分泌激素的细胞散布在普通上皮细胞之间，感知肠腔内容物。有五种激素值得详细了解。

| 激素 | 分泌细胞 | 释放刺激 | 主要作用 |
|---|---|---|---|
| 胃泌素 | G细胞，胃窦 | 肽类、牵张、迷走神经 | 刺激胃酸分泌和黏膜生长 |
| 缩胆囊素（CCK） | I细胞，十二指肠和空肠 | 脂肪和蛋白质 | 胆囊收缩，胰酶分泌，减慢胃排空，产生饱腹感 |
| 促胰液素 | S细胞，十二指肠 | 酸 | 胰液和胆汁中的碳酸氢盐分泌，抑制胃酸分泌 |
| GIP和GLP-1 | K细胞（十二指肠）和L细胞（回肠、结肠） | 葡萄糖和脂肪 | 增加餐后胰岛素释放（肠促胰岛素效应）；GLP-1还减慢胃排空并降低食欲 |
| 胃动素 | M细胞，十二指肠 | 空腹 | 触发移行性复合运动 |

生长抑素对其中许多激素都起总体制动作用。GLP-1已具有重要的临床意义：GLP-1受体激动剂用于2型糖尿病和肥胖（[[endocrine/diabetes]]、[[gastrointestinal/clinical-nutrition]]），它们减慢胃排空，这解释了其主要副作用恶心和饱胀感。

## 营养物质的消化与吸收

::: definition 消化与吸收 {#def-digest}
**消化**是把大的食物分子分解成足以被吸收的小单位：多糖分解为单糖，蛋白质分解为氨基酸和小肽，甘油三酯分解为脂肪酸和单酰甘油。**吸收**是这些小单位连同水、电解质、维生素和矿物质，从肠腔穿过上皮进入血液或淋巴的转运过程。

消化发生在两个地方。**腔内消化**利用肠腔中的酶，主要来自胰腺。**刷状缘（膜）消化**利用固定在肠上皮细胞表面的酶，在吸收的部位完成最后一步。
:::

### 碳水化合物

淀粉被唾液和胰液中的**淀粉酶**分解为麦芽糖、麦芽三糖和带分支的小片段。随后刷状缘酶完成消化：麦芽糖酶和异麦芽糖酶作用于淀粉片段，**蔗糖酶**作用于蔗糖，**乳糖酶**作用于乳糖。产物是葡萄糖、半乳糖和果糖。

葡萄糖和半乳糖通过**SGLT1**进入肠上皮细胞，这种转运体每转运一个糖分子同时转运两个钠离子。基底外侧Na⁺/K⁺-ATP酶造成的细胞内低钠为这种摄取提供动力。果糖通过**GLUT5**以易化扩散进入。三种糖都经**GLUT2**离开细胞进入血液。

在世界上大多数成年人中，断奶后乳糖酶活性下降。这是人类祖先的正常模式；**乳糖酶持续性**即成年后仍保持乳糖酶活性，是在北欧以及部分非洲和中东人群中常见的遗传变异。乳糖酶活性低的人大量饮奶时，乳糖留在肠腔内。乳糖在小肠内通过渗透作用保留水分，结肠细菌将其发酵为气体和短链脂肪酸，引起腹胀和腹泻。

### 蛋白质

胃蛋白酶在胃内开始消化蛋白质，但大部分工作由胰蛋白酶类和刷状缘肽酶完成。游离氨基酸经针对不同氨基酸类别的钠偶联载体进入细胞。二肽和三肽经质子偶联转运体**PepT1**进入，在细胞内被水解。

### 脂肪

脂肪的消化最为复杂，因为脂肪不溶于水。它需要三个步骤。

1. **乳化。** 胃的搅拌和胆盐把脂肪分散成小滴，增大酶作用的表面积。
2. **脂解。** 胰**脂肪酶**由**辅脂酶**锚定在油滴表面，把甘油三酯水解为游离脂肪酸和2-单酰甘油。
3. **形成微胶粒。** 胆盐把这些产物连同胆固醇和脂溶性维生素聚集成**微胶粒**：这是微小的水溶性聚集体，可携带脂肪穿过不流动水层到达肠上皮细胞表面。

在肠上皮细胞内，脂肪酸和单酰甘油重新合成为甘油三酯，并与载脂蛋白B-48一起包装成**乳糜微粒**。乳糜微粒太大，不能进入毛细血管，因此进入淋巴管（乳糜管），经胸导管到达血液。中链脂肪酸是例外：它们直接进入门静脉血，这就是中链甘油三酯补充剂对脂肪吸收不良有帮助的原因。

由于脂肪吸收依赖胆盐和胰脂肪酶，二者任何一种缺乏时，脂肪都是最先受影响的营养物质。未被吸收的脂肪造成**脂肪泻**：粪便色浅、量大、油腻、恶臭，漂浮于水面且不易冲走。随后出现脂溶性维生素A、D、E、K缺乏。

### 水和电解质

每天约有9升液体进入小肠：约2升来自饮水，约7升来自分泌液。其中小肠吸收约7.5升，结肠吸收约1.3升，只剩约100～200 mL随粪便排出。当到达的液体增多时，结肠的吸收量可增至约每天4～5升，从而缓冲小肠的中等程度丢失。

::: theorem 水跟随溶质 {#thm-water}
肠上皮没有转运水的泵。水的吸收或分泌只是因为溶质——主要是钠、氯和营养物质——先被转运，水再顺着它们造成的渗透梯度移动。
:::

::: proof
小肠上皮是"渗漏"的：水很容易通过紧密连接和细胞膜上的水通道蛋白。当Na⁺/K⁺-ATP酶把钠从肠上皮细胞泵入侧方细胞间隙时，这一间隙变得轻度高渗，水随之进入。钠从肠腔进入细胞有几条途径：经SGLT1与葡萄糖同转运，与氨基酸同转运，以及经NHE3与氢离子交换。在结肠，钠还经ENaC通道进入，醛固酮上调该通道。

分泌过程方向相反。隐窝细胞经Na⁺/K⁺/2Cl⁻同向转运体从血液侧摄取氯，再经**CFTR**及其他氯离子通道释放到肠腔。钠从细胞间随之进入以保持电中性，水又跟随盐分。任何使CFTR保持开放的因素，例如霍乱毒素引起的环磷酸腺苷升高，都会使大量盐和水涌入肠腔。

由此可知，一种不能被吸收的溶质会把水留在肠腔内。未吸收的乳糖、镁和聚乙二醇都是这样引起腹泻的。
:::

这一原理是**口服补液盐**（ORS）的基础。即使在严重的霍乱中，钠-葡萄糖同向转运体SGLT1仍然工作。按适当比例同时给予钠和葡萄糖，就能在毒素驱动的分泌存在时仍吸收钠，从而吸收水。WHO低渗口服补液盐含钠75 mmol/L、葡萄糖75 mmol/L，总渗透浓度245 mOsm/L。它在全球的影响见[[public-health/global-health]]。

### 矿物质和维生素

一些微量营养素在肠道中有各自的"地址"，知道它们在哪里被吸收，就能预测疾病或手术的后果。

| 营养素 | 主要吸收部位 | 说明 |
|---|---|---|
| 铁 | 十二指肠和空肠上段 | 三价铁还原为二价铁；经DMT1进入；经膜铁转运蛋白排出，铁调素阻断后者 |
| 钙 | 十二指肠（主动），整个小肠（被动） | 主动摄取需要维生素D |
| 叶酸 | 空肠 | 乳糜泻中常见缺乏 |
| 维生素B12 | 回肠末段 | 需要胃分泌的内因子 |
| 胆盐 | 回肠末段 | 经顶膜钠依赖性胆汁酸转运体主动摄取 |
| 脂溶性维生素 | 小肠，与脂肪一起 | 需要胆盐和脂肪酶 |

**铁**的平衡在吸收环节受到调控，因为机体没有受调控的排铁途径。储铁充足时，肝合成**铁调素**，使膜铁转运蛋白降解，把铁困在随后脱落的肠上皮细胞中。炎症也使铁调素升高，这是慢性病贫血的部分原因（[[blood/anaemia]]）。

**维生素B12**的吸收途径最为复杂。在胃内，它被酸和胃蛋白酶从食物蛋白中释放，与唾液中的结合咕啉（haptocorrin）结合。在十二指肠，胰蛋白酶类消化结合咕啉，B12转而与壁细胞分泌的**内因子**结合。B12-内因子复合物运行到**回肠末段**，被特异受体（cubilin）摄取。肝内储存可供数年之用，因此吸收障碍后缺乏症发展缓慢。

因此B12的途径可在五处中断：摄入不足（严格素食）、缺乏胃酸或内因子（自身免疫性胃炎、胃切除）、胰腺功能不全、细菌过度生长消耗B12，或回肠末段病变或切除。

::: example 舌痛和足麻 {#ex-b12}
一名64岁非洲-加勒比裔女性，乏力6个月，舌红疼痛，双足刺痛。她患有甲状腺功能减退症。血红蛋白92 g/L，平均红细胞体积114 fL，血涂片见中性粒细胞核分叶过多。血清B12降低，叶酸正常。内因子抗体阳性。请用B12吸收的生理解释诊断，并概述治疗原则。
::: solution
**第1步：贫血分类。** 平均红细胞体积升高伴中性粒细胞核分叶过多，属于**巨幼细胞性**贫血。常见原因是B12或叶酸缺乏，两者都是DNA合成所必需的。神经病变指向B12，因为B12缺乏损害髓鞘，而叶酸缺乏不会。

**第2步：找出吸收失败的环节。** 内因子抗体对**恶性贫血**高度特异，这是一种破坏壁细胞的自身免疫性胃炎。没有内因子，无论摄入多少，B12都无法在回肠末段吸收。常合并其他自身免疫病，如她的甲减。恶性贫血并不局限于年长的欧洲白人，在非洲和加勒比裔人群中也有充分记载，有时发病年龄更轻。

**第3步：选择治疗途径。** 由于缺乏内因子，通常的治疗是肌内注射羟钴胺（hydroxocobalamin），绕过肠道，终身维持；有神经系统表现时以注射开始是标准做法。不能单独补充叶酸，因为叶酸可以纠正贫血，而神经损害却继续进展。

自身免疫性胃炎还增加胃肿瘤的风险（[[gastrointestinal/oesophagus-stomach]]）。处理遵循当地指南。
:::
:::

## 肠肝循环

胆盐合成代价高，机体会循环利用它。**胆盐池**总量只有约3 g，而肝每天分泌约15～30 g胆盐。因此胆盐池每天必须循环数次。

::: theorem 胆盐被循环利用 {#thm-enterohepatic}
分泌到十二指肠的胆盐约95%以上被重吸收，主要在回肠末段经主动转运吸收，并经门静脉血返回肝脏再次分泌。这一**肠肝循环**使胆盐池每天大约循环4～12次，餐后更多。每天随粪便丢失约0.5 g，由胆固醇新合成的胆盐补充。
:::

::: proof
肝细胞从门静脉血中高效摄取胆盐，因此进入体循环的极少。在回肠末段，顶膜钠依赖性胆汁酸转运体（ASBT）把胆盐转运进肠上皮细胞，基底外侧的载体再把它们释放入门静脉血。胆盐返回后会抑制自身的合成：回肠释放激素FGF19，抑制肝内的胆固醇7α-羟化酶。

如果回肠末段病变或被切除，会发生两种变化。更多胆盐到达结肠，刺激氯和水的分泌。同时肝失去反馈信号，于是增加合成。回肠丢失较短时，增加的合成能够跟上，主要问题是**胆汁酸腹泻**。丢失较长时，合成跟不上，胆盐池缩小，微胶粒形成失败，随之出现**脂肪泻**。
:::

经验法则是：切除回肠末段少于约100 cm会引起胆汁酸腹泻，可用考来烯胺（colestyramine）等胆汁酸螯合剂治疗；切除更多则引起脂肪吸收不良，而螯合剂会使其加重。100 cm只是参考，不是截然的界限。

::: example 回肠切除三年后 {#ex-stones-ileum}
一名34岁克罗恩病男性，三年前切除了60 cm回肠末段。现在他每天水样泻4～6次，出现草酸钙肾结石，血清B12降低。结肠镜检查显示克罗恩病处于缓解期。请解释每个问题。
::: solution
**腹泻。** 60 cm回肠被切除后，胆盐重吸收减少。未被吸收的胆盐到达结肠并刺激分泌，造成**胆汁酸腹泻**（[[#thm-enterohepatic]]）。由于丢失少于约100 cm，肝能合成足够的新胆盐维持脂肪消化，因此脂肪泻并不突出。试用胆汁酸螯合剂是合理的诊断兼治疗步骤；在有条件的地方，SeHCAT扫描可直接测定胆汁酸潴留。

**肾结石。** 正常情况下，膳食中的钙在肠道内结合草酸，草酸钙不被吸收。脂肪吸收不良时，脂肪酸转而结合钙。草酸被游离出来并在结肠吸收，而胆盐还增加结肠通透性。尿草酸升高，形成草酸钙结石。这就是**肠源性高草酸尿**，它要求结肠完整。

**B12降低。** B12-内因子复合物只在回肠末段吸收。切除这样长度的回肠后，通常需要终身注射补充B12，并定期复查水平。
:::
:::

## 腹泻与吸收不良

::: definition 腹泻及其机制 {#def-diarrhoea}
**腹泻**是排出异常稀薄或频繁的粪便，通常为每天三次或以上稀便。持续少于14天为**急性**，超过4周为**慢性**。主要机制有四种，许多疾病兼有几种：

- **渗透性**：难以吸收的溶质把水留在肠腔。例如乳糖酶缺乏时的乳糖、镁盐、山梨醇。**禁食后停止**。
- **分泌性**：主动的氯分泌或钠吸收受阻，驱使盐和水进入肠腔。例如霍乱和产肠毒素性大肠埃希菌、胆汁酸腹泻、罕见的分泌激素的肿瘤。**禁食后持续**，量可以很大。
- **炎症性（渗出性）**：受损的黏膜渗出血液、蛋白和黏液，吸收功能差。例如炎症性肠病、侵袭性感染。典型表现为便血、发热和炎症指标升高。
- **动力改变**：转运加快减少了接触时间。例如甲状腺功能亢进症、肠易激综合征、糖尿病自主神经病变。
:::

**粪便渗透压间隙**有助于区分渗透性和分泌性腹泻。结肠内粪便与血浆处于渗透平衡，因此其渗透压接近290 mOsm/kg。分泌性腹泻中，这一渗透压几乎全部来自钠盐和钾盐。渗透性腹泻中，相当一部分来自未被测定的溶质。间隙估算的就是这部分未测定的溶质：

$$
\text{粪便渗透压间隙} = 290 - 2\left([\text{Na}^+] + [\text{K}^+]\right)
$$ {#eq-gap}

乘以2是为了计入伴随阳离子的阴离子。间隙高于约125 mOsm/kg提示渗透性腹泻，低于约50 mOsm/kg提示分泌性腹泻。介于两者之间则不确定。之所以采用固定值290，是因为粪便收集后细菌继续发酵，实测渗透压会升高；实测值远高于290提示标本送检延迟，远低于290则提示标本被水或稀释的尿液稀释。

::: example 渗透性还是分泌性？ {#ex-diarrhoea-types}
两名成人出现水样泻。计算每人的粪便渗透压间隙并对腹泻分类。

(a) 一名26岁华裔男性，开始高蛋白饮食（包括每天一升牛奶）后出现腹胀和腹泻。粪便钠35 mmol/L，钾45 mmol/L。禁食48小时期间腹泻停止。

(b) 一名50岁女性每天排水样便3升，禁食时仍持续。粪便钠110 mmol/L，钾30 mmol/L。
::: solution
使用[[#eq-gap]]。

(a) 间隙$= 290 - 2(35 + 45) = 290 - 160 = 130$ mOsm/kg。高于125，因此为**渗透性**腹泻。禁食后停止与之相符。可能的溶质是乳糖：成年后乳糖酶活性低是东亚血统人群的多数模式。减少乳糖试验或氢呼气试验可以证实。

(b) 间隙$= 290 - 2(110 + 30) = 290 - 280 = 10$ mOsm/kg。非常低，说明粪便的渗透压几乎全部来自钠盐和钾盐：**分泌性**腹泻。禁食后持续和大量排便与之相符。鉴别诊断包括胆汁酸腹泻、显微镜下结肠炎、隐瞒的刺激性泻药使用和罕见的神经内分泌肿瘤。检查应遵循当地指南，从常见原因开始。
:::
:::

::: warning 禁食并不能排除所有渗透性原因
只有当致病溶质来自食物时，禁食试验才有帮助。含镁的抗酸药或泻药，或"无糖"药物中的山梨醇，在禁食期间仍会使渗透性腹泻持续。解读这一试验前要完整询问用药史。
:::

**吸收不良**是一种或多种营养物质吸收障碍。它可发生在三个阶段：

- **腔内（消化）失败**：胰酶不足（慢性胰腺炎、囊性纤维化、胰腺癌）或胆盐不足（胆汁淤积、回肠丢失、分解胆盐的细菌过度生长）。
- **黏膜失败**：吸收表面受损或减少，如乳糜泻、小肠克罗恩病或切除后的短肠（[[gastrointestinal/bowel-disease]]）。
- **黏膜后失败**：营养物质离开肠上皮细胞的途径受阻，如淋巴管阻塞或肠淋巴管扩张症。

吸收不良表现为体重下降、腹泻或脂肪泻，以及能提示部位的缺乏：近端小肠疾病中缺铁和叶酸，回肠疾病中缺B12，脂肪吸收不良中缺维生素D和K。**粪便弹性蛋白酶**降低提示胰腺外分泌功能不全。

::: example 不长个子的幼儿 {#ex-cf}
一名11个月男婴的体重在生长曲线上不断下跌。他排大量色浅、油腻、恶臭的粪便，腹部膨隆，今冬已有两次胸部感染。由于在国外出生，没有新生儿筛查结果。粪便弹性蛋白酶极低，汗液试验示汗液氯为96 mmol/L。请解释吸收不良的原因并概述处理原则。
::: solution
**第1步：定位。** 色浅、量大、恶臭的粪便意味着**脂肪泻**，脂肪没有被消化或吸收。极低的粪便弹性蛋白酶把障碍定位在肠腔：胰腺没有输送消化酶。

**第2步：解释机制。** 在规范操作的试验中，汗液氯达到或超过60 mmol/L支持**囊性纤维化**，96 mmol/L远高于此值。CFTR是驱动胰腺导管细胞分泌液体的氯离子通道。缺乏它，胰液黏稠，导管阻塞，腺泡组织被破坏，常常在出生前就已发生。从临床上看，脂肪酶输送最先失败，因为脂肪消化最依赖胰酶。胸部感染反映了同一缺陷在气道中的表现。

**第3步：处理原则。** 脂肪吸收不良导致能量丢失和维生素A、D、E、K缺乏。治疗由囊性纤维化专科团队主导，遵循国家指南。包括每餐和每次加餐时进行**胰酶替代治疗**，根据脂肪含量、症状和生长情况调整；高能量饮食；补充脂溶性维生素；以及呼吸道护理。CFTR调节剂能改善携带相应变异者的通道功能，现已成为治疗的一部分（[[genetics/mendelian-inheritance]]）。
:::
:::

::: quiz
某人接受了全胃切除术。如果不进行终身治疗，最肯定会出现的吸收问题是哪一项？
- [ ] 果糖吸收不良
- [x] 维生素B12缺乏
- [ ] 胆汁酸腹泻
- [ ] 不能吸收氨基酸
::: solution
全胃切除后没有壁细胞，因此没有**内因子**。没有内因子，维生素B12无法在回肠末段吸收，一旦几年后肝储存耗尽，缺乏就不可避免。因此终身补充B12是标准做法。果糖和氨基酸由不依赖胃的小肠转运体吸收。胆汁酸腹泻是回肠末段的问题，而不是胃的问题。胃切除后铁和钙的吸收也常减少，但较难预测。
:::
:::

::: history
1822年，加拿大船夫圣马丁（Alexis St Martin）因霰弹枪伤，胃与皮肤之间留下一个永久性开口。美国陆军外科医生博蒙特（William Beaumont）在随后十年里利用它直接研究消化：他采集胃液，证明胃液含酸并能在体外消化食物，还记录了情绪和疾病如何改变胃液。他于1833年发表了观察结果。1902年，贝利斯（William Bayliss）和斯塔林（Ernest Starling）证明，即使切断神经，十二指肠内的酸仍能引起胰液分泌，因为十二指肠黏膜向血液释放了一种物质。他们称之为**促胰液素**，斯塔林后来提出了"激素"一词。大约同一时期，巴甫洛夫（Ivan Pavlov）用狗研究消化液分泌的神经调控，并于1904年获得诺贝尔生理学或医学奖。
:::

::: summary
- 消化道运动、分泌、消化和吸收。Cajal间质细胞产生的慢波设定节律；肠神经系统、外来神经和激素决定何时收缩。
- 胃酸来自壁细胞质子泵，由乙酰胆碱、胃泌素和组胺驱动，由生长抑素制动。PPI阻断最后共同环节。
- 碳水化合物和蛋白质被消化为单体，经钠偶联载体吸收。脂肪需要胆盐、脂肪酶和微胶粒，因此胆汁或胰酶缺乏时它最先受影响。
- 水总是跟随溶质。分泌性腹泻时钠-葡萄糖同向转运仍然工作，这就是口服补液盐有效的原因。
- 铁在十二指肠吸收，受铁调素调控；B12在回肠末段与内因子一起吸收；胆盐经肠肝循环在回肠末段吸收。
- 腹泻分为渗透性、分泌性、炎症性和动力相关性。粪便渗透压间隙$290 - 2([\text{Na}^+]+[\text{K}^+])$可区分渗透性与分泌性原因。
- 吸收不良可发生在腔内、黏膜或黏膜后，其缺乏谱提示问题所在部位。
:::

WHO低渗口服补液盐的成分（mmol/L）为：钠75、氯65、葡萄糖75、钾20、枸橼酸10。假设每种溶质每摩尔贡献一个渗透摩尔，计算其总渗透浓度（mOsm/L）。为什么要加入葡萄糖？

::: solution
渗透浓度$= 75 + 65 + 75 + 20 + 10 = 245$ mOsm/L。加入葡萄糖是因为SGLT1把钠与葡萄糖一起转运进肠上皮细胞。这种同向转运不受引起分泌性腹泻的毒素影响，因此钠被吸收，水随之吸收（[[#thm-water]]）。溶液略呈低渗，也避免把水吸入肠腔。

::: hint

::: solution
间隙$= 290 - 2(40 + 30) = 290 - 140 = 150$ mOsm/kg。高于125，因此为**渗透性**腹泻。应询问含镁药物或补充剂、渗透性泻药、"无糖"产品中的山梨醇或其他糖醇，以及乳糖摄入。乳糜泻等黏膜疾病引起的碳水化合物吸收不良也可能参与。禁食试验预计会使排便量减少。

::: exercise 循环胆汁 {level=2 check="0.54"}
在一个示意模型中，胆盐池为3 g，每天循环6次。每次循环中，回肠末段重吸收通过它的胆盐的97%。计算每天随粪便丢失的胆盐（克），保留两位小数。肝必须怎样做才能维持胆盐池恒定？
::: hint
先求每天分泌的胆盐总量，再求未被重吸收的部分。
:::
::: solution
每日分泌量$= 3 \times 6 = 18$ g。粪便丢失$= 18 \times (1 - 0.97) = 18 \times 0.03 = 0.54$ g/天。为维持胆盐池恒定，肝每天必须由胆固醇合成0.54 g新胆盐。如果回肠病变使重吸收减少，丢失增加，FGF19反馈信号下降，肝就会增加合成（[[#thm-enterohepatic]]）。
:::
:::

::: exercise 没有胰腺疾病的脂肪泻 {level=2}
一名58岁原发性硬化性胆管炎男性，粪便色浅、油腻，凝血酶原时间延长。粪便弹性蛋白酶正常。请解释他脂肪泻和凝血酶原时间延长的机制。为什么补充胰酶没有帮助？
::: hint
除脂肪酶外，脂肪吸收还需要哪种成分？
:::
::: solution
粪便弹性蛋白酶正常说明他的胰腺分泌了足够的脂肪酶。问题在于**胆汁**：胆汁淤积使到达十二指肠的胆盐减少，微胶粒不能形成，脂解产物无法有效到达肠上皮细胞。脂肪吸收不良，脂溶性**维生素K**也随之吸收不良。凝血因子II、VII、IX和X的γ-羧化需要维生素K，因此凝血酶原时间延长。补充胰酶不能替代胆盐。如果肝的合成功能保留，胃肠外补充维生素K应能纠正凝血酶原时间（[[gastrointestinal/liver-function]]）。
:::
:::

::: exercise 解读慢性腹泻的检查结果 {level=3}
一名39岁男性腹泻10个月，体重下降6 kg，伴腹胀。结果：血红蛋白108 g/L，平均红细胞体积78 fL，铁蛋白6 µg/L，血清叶酸降低，B12正常，白蛋白33 g/L，校正钙2.08 mmol/L，碱性磷酸酶轻度升高，粪便弹性蛋白酶正常，粪便钙卫蛋白轻度升高。问题最可能在肠道的哪个部位？最可能的单一诊断是什么？首先应申请什么检查？
::: hint
铁和叶酸在近端小肠吸收；B12在回肠末段吸收。
:::
::: solution
**定位。** 缺铁和叶酸缺乏而B12正常，指向**近端小肠**（十二指肠和空肠），因为铁和叶酸在那里吸收，而吸收B12的回肠末段似乎功能正常。粪便弹性蛋白酶正常使胰腺功能衰竭不太可能，因此缺陷在黏膜。

**解读骨相关结果。** 低钙伴碱性磷酸酶升高提示维生素D缺乏伴骨软化症，与脂溶性维生素吸收不良及十二指肠钙吸收减少相符。低白蛋白反映营养不良，也可能有蛋白丢失。

**诊断。** 最可能的诊断是**乳糜泻**，它对近端小肠损害最重。首选检查是**组织转谷氨酰胺酶IgA加总IgA**，须在患者仍进食麸质时采血；进一步评估遵循国家指南（[[gastrointestinal/bowel-disease]]）。鉴别诊断包括小肠克罗恩病、细菌过度生长和贾第虫病。
:::
:::

::: exercise 设计腹泻门诊问诊表 {level=3}
你正在为新开设的慢性腹泻门诊编写结构化问诊表。根据[[#def-diarrhoea]]中的四种机制，为每种机制写出一两个提示性问题，并列出三项需要紧急检查以排除癌症或炎症性肠病的"红旗"特征。
::: hint
想想每种机制产生的临床特征：对禁食的反应、排便量、便血、转运速度。
:::
::: solution
**渗透性：** 不吃东西时腹泻会停止吗？您是否饮用牛奶、食用无糖产品、服用镁剂或泻药？

**分泌性：** 夜间或禁食时腹泻是否持续？量是否很大，是否会因排便而夜间醒来？是否做过胆囊或回肠手术，或服用新的药物？

**炎症性：** 有无便血或黏液？有无发热、口腔溃疡、关节痛、皮疹或眼部炎症？有无炎症性肠病家族史？

**动力性：** 腹痛是否在排便后缓解，是否与便秘交替出现？有无甲状腺功能亢进的症状，或长期糖尿病？

**红旗特征：** 直肠出血、非故意的体重下降、缺铁性贫血、腹部或直肠肿块，或结直肠癌家族史。转诊遵循NICE NG12等国家指南（[[gastrointestinal/gi-bleeding-cancer]]）。
:::
