胆囊、胆管和胰腺共用一个通向十二指肠的出口。胆总管和主胰管通常在开口于**Vater壶腹**之前汇合，壶腹由Oddi括约肌把守。这一共同的解剖解释了为什么一颗小胆结石可以引起胰腺炎，为什么胰头癌会引起黄疸，以及为什么一种内镜操作（ERCP）可以治疗两个器官的疾病。

本章的疾病，既有非常常见、通常良性的胆结石，也有医学中最致命的一些癌症。急性胰腺炎介于两者之间：大多数发作较轻，数天内消退，但约五分之一会变成重症，伴器官衰竭和相当高的死亡风险。

本章介绍胆结石及其并发症，急性和慢性胰腺炎，自身免疫性胰腺炎，以及胰腺和胆管的癌症与囊肿。胆汁生理见[[gastrointestinal/digestion-absorption]]，全章用到的肝脏检查见[[gastrointestinal/liver-function]]。

## 胆结石

::: definition 胆结石及其并发症 {#def-stones}
**胆结石**（胆石症）是胆囊内的固体凝结物。主要有两类：

- **胆固醇结石**，西方国家最常见的类型，当胆汁中的胆固醇超过胆盐和磷脂能保持溶解的量时形成。
- **色素结石**主要由胆红素钙构成。**黑色**色素结石在慢性溶血和肝硬化时形成于胆囊。**棕色**色素结石形成于胆管，与感染和胆汁淤滞有关。

大多数胆结石患者终生没有症状。并发症包括**胆绞痛**、**急性胆囊炎**、伴梗阻性黄疸的**胆总管结石**、**急性上行性胆管炎**和**胆源性胰腺炎**。
:::

胆结石很常见：西方国家约十分之一的成人有胆结石，女性和年长者比例更高。胆固醇结石在三个条件同时出现时形成：胆汁中胆固醇**过饱和**，胆固醇结晶**成核**，以及使结晶得以长大的**胆囊动力减退**。危险因素包括女性、妊娠和雌激素、肥胖、快速减重（包括减重手术后）、糖尿病、回肠疾病或切除，以及某些族群，尤其是几个美洲原住民群体。

偶然发现的无症状胆结石通常不予切除。无症状结石者每年只有一小部分出现症状，对大多数人来说手术的风险超过获益。

### 胆绞痛与胆囊炎

**胆绞痛**由结石在胆囊收缩时暂时阻塞胆囊出口（胆囊管）引起。疼痛位于右上腹或上腹部，虽名为绞痛却是持续性而非阵发性，常在油腻饮食后发生，持续约30分钟到数小时。无发热，血液检查正常。

梗阻持续、胆囊壁发生炎症并可能继发感染时，就发展为**急性胆囊炎**。疼痛持续时间更长，有发热，**Murphy征**阳性：检查者按压右肋缘下方时，发炎的胆囊下移碰到手，患者吸气突然中止。超声显示结石、胆囊壁增厚和胆囊周围积液。**东京指南**（2018年）结合局部体征、全身炎症和影像学确定诊断，并按器官功能障碍把严重程度从轻度分到重度。

NICE指南CG188建议，对有症状的胆囊结石患者行腹腔镜胆囊切除术，对急性胆囊炎在**诊断后一周内**手术。早期手术缩短总住院时间，避免等待期间反复发作。病情太重不能手术者可经皮引流胆囊（经皮胆囊造瘘术）。

### 胆总管结石与胆管炎

进入胆总管的结石可引起**梗阻性黄疸**，肝脏检查呈胆汁淤积模式，超声见胆管扩张。它也可以阻塞壶腹而引起胰腺炎。胆管结石用**MRCP**或**超声内镜**证实，经**ERCP**取出：把侧视内镜送入十二指肠，插管进入胆管，切开括约肌（括约肌切开术）。

::: definition 急性胆管炎 {#def-cholangitis}
**急性胆管炎**是梗阻胆道的细菌感染，最常由胆总管结石、狭窄或支架堵塞引起。典型表现为**Charcot三联征**：发热伴寒战、黄疸和右上腹痛。三联征加上意识模糊和低血压构成**Reynolds五联征**，提示伴脓毒性休克的重症。
:::

胆管炎是外科和内镜急症，因为受压的感染胆汁会反流入血。治疗把复苏和静脉抗生素与**胆道引流**结合，通常经ERCP引流。重症需紧急引流。如果不能做ERCP，可由介入放射科经肝引流胆管。

::: example 寒战 {#ex-cholangitis}
一名81岁华裔女性因寒战、意识模糊和眼睛发黄被送来。体温39.2 °C，脉搏每分钟118次，血压84/50 mmHg。右上腹压痛。胆红素96 µmol/L，ALP 420 U/L，ALT 260 U/L，白细胞计数19 × 10⁹/L，乳酸4.2 mmol/L。超声显示胆结石，胆总管直径12 mm。诊断是什么？首要任务是什么？
::: solution
**第1步：诊断。** 发热、黄疸和右上腹痛是**Charcot三联征**。加上意识模糊和低血压，她有**Reynolds五联征**：伴脓毒性休克的重症**急性胆管炎**。胆管扩张和胆结石指向梗阻性胆总管结石。在东亚和东南亚人群中，也可能是在胆管内形成的棕色色素结石，有时与寄生虫感染有关。

**第2步：复苏和抗生素。** 按脓毒症路径处理：静脉补液、血培养、根据当地指南选用广谱抗生素，并在重症监护环境中评估是否需要血管升压药（[[infectious-diseases/fever-sepsis]]）。

**第3步：引流是确定性治疗。** 抗生素无法使受压的感染胆汁无菌。她需要紧急**ERCP**引流胆管，通常同时取石或放置支架。如果ERCP失败，替代方法是经皮经肝引流。

**第4步：以后。** 康复后，考虑行胆囊切除以防复发，需权衡她的年龄和身体状况。
:::
:::

## 急性胰腺炎

::: definition 急性胰腺炎 {#def-pancreatitis}
**急性胰腺炎**是胰腺的急性炎症。诊断需要满足以下三项中的**两项**：

1. 典型腹痛：急性、剧烈、上腹部，常放射至背部；
2. 血清**脂肪酶或淀粉酶至少为正常上限的3倍**；
3. 影像学（CT、MRI或超声）的特征性表现。

按**修订版亚特兰大分类**（2012年），严重程度分为：

- **轻症**：无器官衰竭，无局部或全身并发症；
- **中度重症**：48小时内恢复的一过性器官衰竭，或有局部并发症，或合并症加重；
- **重症**：**持续性器官衰竭**超过48小时。
:::

两个最常见的病因是**胆结石**和**酒精**，合计占大多数病例。其他病因包括高甘油三酯血症（通常高于约11 mmol/L）、高钙血症、ERCP、药物（例如硫唑嘌呤、丙戊酸盐和某些利尿剂）、创伤、自身免疫性胰腺炎、基因变异（*PRSS1*、*SPINK1*、*CFTR*）以及解剖变异。有一个有用的记忆口诀，但病史（饮酒、药物、家族史）、超声查胆结石、钙和甘油三酯就能在大多数人中找到病因。

::: theorem 胰腺炎是胰蛋白酶的过早激活 {#thm-trypsin}
当胰蛋白酶原在**腺泡细胞内**而不是在十二指肠中被激活为胰蛋白酶时，急性胰腺炎就开始了。胰蛋白酶接着激活其他消化酶，腺体开始消化自身。局部损伤触发炎症反应，如果足够大就变成全身性的。
:::

::: proof
正常情况下有几道防线阻止胰腺内激活。酶以无活性的前体形式合成，储存在与溶酶体分开的颗粒中；胰蛋白酶抑制物（SPINK1）阻断少量活化的胰蛋白酶；胰蛋白酶还能通过自溶破坏自身。胆结石阻塞壶腹、酒精和其他损伤扰乱腺泡细胞内的钙信号，使酶原颗粒与溶酶体融合，让组织蛋白酶B激活胰蛋白酶原。*PRSS1*（阳离子胰蛋白酶原）的功能获得性变异使胰蛋白酶不易失活，引起遗传性胰腺炎，有力地支持了这一模型。

受损的腺泡细胞释放细胞因子，募集中性粒细胞和巨噬细胞。在大多数人中，炎症局限于局部。在一部分人中，**全身炎症反应**引起毛细血管渗漏、低血容量、急性呼吸窘迫综合征和肾衰竭，这就是重症胰腺炎按器官衰竭而不是按胰腺外观来定义的原因。
:::

### 评估严重程度

淀粉酶和脂肪酶可以确诊，但**不能衡量严重程度**。淀粉酶几天内恢复正常，所以升高持续时间较长的脂肪酶对就诊较晚者更有用。严重程度取决于在最初几天中逐渐演变的器官衰竭。有几种工具有助于预测：

- **改良Glasgow（Imrie）评分**，在48小时内对八项标准各计1分：PaO₂低于8 kPa，年龄超过55岁，白细胞计数高于15 × 10⁹/L，钙低于2 mmol/L，尿素高于16 mmol/L，LDH高于600 U/L（或AST高于200 U/L），白蛋白低于32 g/L，葡萄糖高于10 mmol/L。3分或以上预示重症；
- 48小时时**CRP高于150 mg/L**；
- 持续超过48小时的全身炎症反应综合征征象。

诊断典型胰腺炎不需要增强CT。如果患者在约72小时后仍未好转，CT有助于寻找**坏死**和积液。

### 处理

处理以支持治疗为主，早期大多数死亡来自器官衰竭。

- **液体复苏。** 静脉输注晶体液，通常是平衡液如Hartmann液或乳酸林格液，根据临床反应调整。WATERFALL试验（2022年）比较了积极与适度液体复苏，因积极补液导致更多液体过负荷而结局并无改善而提前终止。现在倾向于适度、目标导向的液体治疗。
- **镇痛**，常用阿片类药物。
- **营养。** 轻症患者能耐受时鼓励早期经口进食。在中度重症或重症胰腺炎中，NICE（NG104）建议在72小时内开始**肠内营养**，需要时经鼻胃管或鼻空肠管。只有肠内喂养失败时才使用肠外营养（[[gastrointestinal/clinical-nutrition]]）。
- **抗生素**不作预防使用。用于已证实或高度怀疑的感染，如胆管炎或感染性坏死。
- 伴胆管炎的胆源性胰腺炎需要早期**ERCP**，但无胆管炎的胰腺炎不常规需要。
- 轻症胆源性胰腺炎建议在**同次住院期间**行**胆囊切除**，因为等待有复发风险。重症则推迟到炎症消退后。

::: example 入院时即为重症 {#ex-severe-panc}
一名47岁大量饮酒男性，剧烈上腹痛放射至背部并呕吐24小时。脉搏每分钟120次，血压98/60 mmHg，呼吸频率每分钟28次，未吸氧时SpO₂ 91%。脂肪酶为正常上限的9倍。48小时内：PaO₂ 7.6 kPa，白细胞计数17 × 10⁹/L，钙1.9 mmol/L，尿素18 mmol/L，LDH 520 U/L，白蛋白30 g/L，葡萄糖8 mmol/L。计算他的改良Glasgow评分并概述处理。
::: solution
**诊断。** 典型疼痛加脂肪酶超过正常3倍：**急性胰腺炎**，可能与酒精有关。仍需用超声排除胆结石。

**改良Glasgow评分。** PaO₂低于8 kPa：1分。年龄超过55岁：0分。白细胞高于15：1分。钙低于2：1分。尿素高于16：1分。LDH高于600：0分。白蛋白低于32：1分。葡萄糖高于10：0分。总分$= 5$，预示**重症**。

**按亚特兰大分类的严重程度。** 他已有呼吸功能受损和临界循环状态。如果器官衰竭持续超过48小时，这次发作就归为**重症**。

**处理。** 收入高依赖病房或重症监护病房；吸氧并评估是否需要呼吸支持；适度、目标导向的静脉补液，密切监测以避免过负荷；镇痛；72小时内开始肠内营养；给予硫胺素并监测酒精戒断；不预防使用抗生素。如果72小时后仍未好转，做CT寻找坏死。出院前提供戒酒支持，因为继续饮酒会导致复发和慢性胰腺炎。
:::
:::

### 局部并发症

胰周积液按**时间**和有无**坏死**分类：

| | 4周内 | 4周后（已包裹） |
|---|---|---|
| 无坏死（间质水肿性胰腺炎） | 急性胰周液体积聚 | **假性囊肿** |
| 有坏死（坏死性胰腺炎） | 急性坏死物积聚 | **包裹性坏死** |

大多数早期积液会自行吸收。干预只用于引起症状、压迫胃或胆管，或发生**感染**的积液。当患者病情恶化（常在第2～4周）伴发热和炎症指标上升，有时CT见积液内有气体时，应怀疑感染性坏死。现代方法是**升阶梯策略**：先用抗生素，再引流（常经内镜穿过胃壁），只在需要时才经内镜或微创方式清除坏死组织（坏死组织清除术）。PANTER试验（2010年）表明，与开腹坏死组织清除术相比，这一方法减少了严重并发症和死亡。

::: example 第五周的积液 {#ex-won}
一名39岁女性正从坏死性胆源性胰腺炎中恢复。入院五周后，她出现早饱和呕吐。无发热。CT显示一个14 cm的包裹性积液，内含液体和固体碎屑，压迫胃。这是什么积液？应如何处理？
::: solution
**分类。** 坏死性胰腺炎4周以后出现、有明确囊壁和固体碎屑的积液，是**包裹性坏死**。

**治疗指征。** 它是无菌的（无发热，无气体），但体积大并引起**胃出口梗阻**，因此有干预指征。

**处理。** 超声内镜引导下经胃壁引流，通常使用管腔贴合型金属支架；如果固体碎屑不能清除，再行内镜下坏死组织清除。这属于升阶梯策略的一部分，避免了开腹手术。她还需要营养支持，康复后行胆囊切除以防胆源性胰腺炎再发。
:::
:::

## 慢性胰腺炎

::: definition 慢性胰腺炎与自身免疫性胰腺炎 {#def-other-pancreas}
**慢性胰腺炎**是胰腺进行性的炎症和纤维化，导致外分泌和内分泌组织永久丧失。其主要特征是**疼痛**、伴脂肪泻的**外分泌功能不全**和**糖尿病**（3c型，胰源性）。酒精和吸烟是主要危险因素；基因变异、复发性急性胰腺炎和胰管梗阻也有作用。

**1型自身免疫性胰腺炎**是**IgG4相关疾病**在胰腺的表现。IgG4相关疾病是一种纤维炎症性疾病，还可累及胆管、唾液腺、肾和腹膜后。它常引起无痛性黄疸和弥漫性胰腺肿大，可与癌症非常相似，对糖皮质激素有反应。
:::

慢性胰腺炎主要靠影像诊断：CT显示钙化、胰管扩张和萎缩，MRI和超声内镜能发现更早期的改变。**粪便弹性蛋白酶**是外分泌功能的简单检测。处理包括戒酒和戒烟；**胰酶替代治疗**（PERT），随每餐和每次加餐服用，并根据食物的脂肪含量和症状调整；补充脂溶性维生素并评估骨健康；治疗糖尿病，由于胰高血糖素分泌也已丧失，低血糖风险很高；以及疼痛处理。长期疼痛中阿片类药物依赖是真实的风险，因此采用多学科疼痛管理，对经过选择、有胰管梗阻的患者行内镜或手术引流。慢性胰腺炎还增加胰腺癌风险。

::: example 肿大的胰腺 {#ex-ig4}
一名66岁男性无痛性黄疸伴体重下降。CT显示胰腺弥漫性增大，呈"腊肠样"，周围有一圈薄的低密度环，胆总管远端变窄，但无独立肿块。血清IgG4升高。他还有颌下腺肿大。可能的诊断是什么？为什么仍须仔细考虑癌症？
::: solution
**可能的诊断。** 胰腺弥漫性增大伴周边环、胆道狭窄、IgG4升高和唾液腺受累，提示**1型自身免疫性胰腺炎**，属于**IgG4相关疾病**。

**为什么仍须考虑癌症。** 这个年龄男性的无痛性黄疸和体重下降，也是**胰腺癌**的典型表现。某些癌症中IgG4也可以中度升高，而两者的治疗完全不同。诊断依靠综合影像、血清学、其他器官受累和组织学，组织通常经超声内镜引导下活检获得。对漏诊的癌症开始使用糖皮质激素会是严重的错误。

**确诊后的治疗。** 糖皮质激素通常产生迅速的反应，这本身就支持诊断；需要时放置胆道支架。复发常见，可在专科指导下使用维持治疗或利妥昔单抗（rituximab）。
:::
:::

## 胰腺和胆道癌症

::: definition 胰腺和胆道癌症 {#def-cancers}
- **胰腺导管腺癌**约占胰腺癌的90%。大多数发生在胰**头**，阻塞胆管，引起无痛性梗阻性黄疸；胰体和胰尾肿瘤表现较晚，伴疼痛和体重下降。
- **胆管癌**起源于肝内或肝外的胆管上皮。危险因素包括原发性硬化性胆管炎，以及在东南亚慢性感染麝猫后睾吸虫（*Opisthorchis viverrini*）和华支睾吸虫（*Clonorchis sinensis*）等肝吸虫。
- **胆囊癌**与长期胆结石有关，在南美洲和南亚部分地区常见。
- **胰腺神经内分泌肿瘤**和**囊性肿瘤**，如导管内乳头状黏液性肿瘤（IPMN），较少见，预后一般较好。
:::

胰腺癌是生存率最差的癌症之一：在英国确诊的人中，5年生存者不到十分之一，主要原因是大多数人就诊时肿瘤已不能切除。危险因素包括吸烟、肥胖、长期糖尿病、慢性胰腺炎和家族史。老年人**新发糖尿病**，尤其伴体重下降时，可能是早期征象。

表现包括无痛性黄疸、体重下降、上腹或背部疼痛、脂肪泻和新发糖尿病。黄疸患者可触及无压痛的胆囊提示恶性梗阻（**Courvoisier定律**）。NICE NG12建议，40岁及以上有黄疸者按疑似癌症通道转诊；60岁及以上有体重下降并伴某些其他症状（如背痛、腹痛、腹泻、恶心或新发糖尿病）者紧急行CT检查。

关键检查是**胰腺专用方案CT**，它显示肿瘤及其与大血管的关系，从而决定可否切除。肿瘤标志物**CA19-9**支持诊断和监测，但不是筛查试验：它在良性梗阻时也升高，而缺乏Lewis抗原的人不产生它。只有少数人的病变可以切除。胰头肿瘤的手术是**胰十二指肠切除术**（Whipple手术），术后辅助化疗。对于不立即手术的黄疸患者，内镜下胆道支架可解除梗阻和瘙痒。对大多数患者来说，姑息治疗、胰酶替代和营养支持是核心。

::: warning 外科医生看过扫描之前不要放支架
对疑似可切除胰腺癌的患者，常规术前胆道引流会增加并发症。除非胆管炎或其他紧急指征迫使提早引流，关于支架、活检和手术的决定应在分期CT后由专科多学科团队作出。
:::

::: quiz
一名34岁女性患轻症胆源性胰腺炎。她的疼痛在3天内消退，饮食正常。对她的胆囊推荐的方案是什么？
- [ ] 出院，3个月后外科门诊预约
- [x] 同次住院期间行胆囊切除
- [ ] 不手术，因为胰腺炎已经消退
- [ ] 出院前对每位患者都行ERCP加括约肌切开
::: solution
**轻症胆源性胰腺炎**后，建议在**同次住院期间**（或短间隔内）行胆囊切除，因为等待期间胰腺炎复发或发生其他胆结石并发症的风险相当大。除非有胆管炎或持续胆管梗阻，否则不常规需要ERCP。在重症胰腺炎中，手术推迟到炎症消退之后。
:::
:::

::: history
1882年，德国外科医生朗根布赫（Carl Langenbuch）在柏林完成了第一例胆囊切除术。1889年，哈佛病理学家菲茨（Reginald Fitz）把急性胰腺炎描述为一种独立疾病，并主张早期识别。1935年，纽约的惠普尔（Allen Whipple）报告了治疗壶腹癌的胰十二指肠切除术，改进了考施（Walther Kausch）最早尝试的手术。腹腔镜胆囊切除术在二十世纪八十年代问世，首批手术由德国的米厄（Erich Mühe）于1985年和法国的穆雷（Philippe Mouret）于1987年报告，并迅速成为标准术式。
:::

::: summary
- 胆结石很常见，通常无症状；胆绞痛、胆囊炎、胆管结石、胆管炎和胰腺炎是其并发症。
- 急性胆囊炎在诊断后一周内行腹腔镜胆囊切除术治疗（NICE CG188）。
- 胆管炎表现为Charcot三联征；重症还有意识模糊和休克。引流（通常经ERCP）是确定性治疗。
- 急性胰腺炎的诊断需满足以下两项：典型疼痛、脂肪酶或淀粉酶至少为正常3倍、影像学表现。严重程度按器官衰竭定义（修订版亚特兰大分类）。
- 处理以支持为主：适度目标导向补液、镇痛、早期肠内营养、不预防使用抗生素，轻症胆源性胰腺炎后同次住院行胆囊切除。
- 积液按时间和坏死分类；感染性坏死采用升阶梯策略处理。
- 慢性胰腺炎引起疼痛、外分泌功能不全和糖尿病；自身免疫性胰腺炎可模仿癌症。
- 胰腺导管腺癌通常就诊较晚；胰腺专用方案CT决定可否切除。
:::

## 习题

::: exercise 绞痛还是胆囊炎？ {level=1}
列出区分急性胆囊炎与胆绞痛的三项特征，并说出首选影像检查。
::: solution
急性胆囊炎的疼痛持续超过数小时，有发热和炎症指标（白细胞计数、CRP）升高，Murphy征阳性。胆绞痛在数小时内消退，无发热，血液检查正常。首选影像检查是**腹部超声**，可显示结石、胆囊壁增厚和胆囊周围积液。
:::
:::

::: exercise 给积液命名 {level=1}
说出每种情况下的积液名称：(a)间质水肿性胰腺炎2周后，无囊壁的均匀液体积聚；(b)间质性胰腺炎6周后，边界清楚、有囊壁的液体积聚；(c)坏死性胰腺炎6周后，含固体碎屑的包裹性积液。
::: solution
(a)急性胰周液体积聚。(b)假性囊肿。(c)包裹性坏死。
:::
:::

::: exercise 急性胰腺炎的病因 {level=1}
一名28岁女性第二次发作急性胰腺炎。她不饮酒，超声未见胆结石。列出可能找到病因的另外四项检查或问诊内容。
::: solution
空腹**甘油三酯**（极高水平可引起胰腺炎）和**钙**；仔细的**用药史**，包括硫唑嘌呤和丙戊酸盐；**超声内镜或MRCP**，寻找微结石和解剖变异；IgG4和自身免疫性胰腺炎的影像特征；以及在年轻时反复发作或有家族史时做**基因检测**（*PRSS1*、*SPINK1*、*CFTR*）。
:::
:::

::: exercise 计算Glasgow评分 {level=2 check="4"}
一名70岁胆源性胰腺炎女性在48小时内的结果如下：PaO₂ 9.2 kPa，白细胞计数16 × 10⁹/L，钙2.1 mmol/L，尿素17 mmol/L，LDH 450 U/L，白蛋白29 g/L，葡萄糖9 mmol/L。计算她的改良Glasgow评分。
::: hint
以下每项计1分：PaO₂低于8 kPa，年龄超过55岁，白细胞高于15，钙低于2，尿素高于16，LDH高于600，白蛋白低于32，葡萄糖高于10。
:::
::: solution
PaO₂ 9.2 kPa：0分。年龄70岁：1分。白细胞16：1分。钙2.1：0分。尿素17：1分。LDH 450：0分。白蛋白29：1分。葡萄糖9：0分。总分$= 4$，预示**重症**胰腺炎。她需要在高依赖病房密切监测器官衰竭。
:::
:::

::: exercise 适度补液 {level=2 check="2520"}
某急性胰腺炎适度液体复苏方案给予平衡晶体液1.5 mL/kg/h。不计初始推注，70 kg的人在最初24小时内会输入多少毫升？什么因素决定是否调整速度？
::: hint
速度乘以体重再乘以24小时。
:::
::: solution
$1.5 \times 70 \times 24 = 2520$ mL。应使用临床指标频繁重新评估速度：心率、血压、尿量，以及尿素和血细胞比容等指标，同时注意液体过负荷的征象，如需氧量上升。这些是示意数字；方案遵循当地指南。
:::
:::

::: exercise 无症状结石 {level=2 check="33"}
假设一名无症状胆结石者每年出现症状的概率恒为2%。20年内出现症状的概率是多少？取最接近的整数百分比。
::: hint
20年都保持无症状的概率是$0.98^{20}$。
:::
::: solution
$1 - 0.98^{20} = 1 - 0.668 = 0.332$，取整数为**33%**。因此大多数无症状结石者几十年都没有症状，这就是不建议大多数人预防性切除胆囊的原因。这个模型是简化的：风险并不恒定，而且因人而异。
:::
:::

::: exercise 胰腺炎后的脂肪泻 {level=3}
一名52岁酒精相关慢性胰腺炎男性体重下降9 kg，粪便色浅、漂浮，并出现了糖尿病。粪便弹性蛋白酶很低。HbA1c很高，使用胰岛素期间发生过两次严重低血糖。解释每个问题并概述处理原则。
::: hint
同时考虑胰腺的外分泌和内分泌部分，包括胰高血糖素。
:::
::: solution
**体重下降和脂肪泻：** 腺泡组织丧失意味着到达十二指肠的脂肪酶太少。脂肪不能被消化，引起脂肪泻、能量丢失和脂溶性维生素缺乏。很低的粪便弹性蛋白酶证实了**外分泌功能不全**。

**糖尿病：** 胰岛丧失导致**3c型糖尿病**。分泌胰岛素的β细胞和分泌胰高血糖素的α细胞都丧失了。没有胰高血糖素，对低血糖的反向调节受损，因此使用胰岛素时低血糖频繁而严重。未经治疗的吸收不良导致吸收不规律，加剧了不稳定。

**处理原则：** 每餐和每次加餐都服用胰酶替代，根据症状和体重调整；营养师支持，正常摄入脂肪而不是低脂饮食；补充维生素A、D、E和K；评估骨密度；设计尽量减少低血糖的胰岛素方案，配合教育，有条件时使用连续血糖监测，并由糖尿病专科参与；支持戒酒和戒烟；并意识到胰腺癌风险增加。
:::
:::

::: exercise 无痛性黄疸：规划诊疗路径 {level=3}
一名72岁女性无痛性黄疸，体重下降6 kg，新发糖尿病。胆红素180 µmol/L，ALP 640 U/L，CA19-9升高。超声显示肝内外胆管扩张和胰管扩张（"双管征"）。给出鉴别诊断以及检查和决策的顺序，并解释多学科团队的作用。
::: hint
两条管道都扩张，指向它们汇合处的病变。
:::
::: solution
**鉴别诊断：** 胰头癌（鉴于新发糖尿病和体重下降，可能性最大）、壶腹癌、远端胆管癌、自身免疫性胰腺炎，可能性较小的是胆总管结石或慢性胰腺炎。双管征指向壶腹或胰头的病变。

**顺序：** 按疑似癌症通道紧急转诊；行胸、腹、盆腔的**胰腺专用方案CT**，用于分期和评估血管受累；需要组织时行超声内镜引导下活检；检测IgG4以帮助排除自身免疫性胰腺炎。CA19-9支持诊断但不能确诊，因为单纯胆道梗阻就会使其升高。

**多学科团队的决策：** 肿瘤是可切除、交界可切除还是不可切除；她是否能耐受Whipple手术；治疗前是否需要胆道引流（如计划早期手术则避免，除非有胆管炎）；以及化疗放在手术前还是手术后。如果病变不可切除，与她一起规划内镜下金属支架、适当时的姑息化疗、胰酶替代、糖尿病管理和姑息治疗。
:::
:::
