胰腺与胆道呈现外科腹部最文雅的疾病（胆绞痛）与最凶残的疾病（重症急性胰腺炎），加上最致命的常见癌。解剖学负责教学：**一个在导管梗阻时会消化自身的腺体、一条胆汁之河、其三条支流（胆囊、胆囊管、胆总管）把结石送进同一条引流胰管的壶腹部——Opie 1901年的“共同通道”至今仍能解释一半的入院。**

本章涵盖胆石病及其并发症、急慢性胰腺炎、自身免疫IgG4疾病、胰腺与胆道癌、及囊性病变。

## 结石

::: definition 胆结石与胆囊炎 {#def-stones}
**结石形成（胆固醇结石来自过饱和、成核、易淤滞的胆汁——致石三联——带雌激素与贝特类及肥胖及快速减重及回肠切除的风险叠加、色素结石来自溶血与肝硬化的胆红素负荷、及淤滞时肠菌去结合的棕色结石——[[gastrointestinal/digestion-absorption]]的胆汁酸循环与[[gastrointestinal/liver-function]]的胆红素组分；[[blood/haemoglobin-disorders]]的色素逻辑与[[obstetrics-gynaecology/pregnancy-antenatal]]的激素减速及[[endocrine/diabetes]]的贝特类与减重门诊[[gastrointestinal/clinical-nutrition]]）。胆绞痛（结石暂时嵌塞胆囊管——30分钟到数小时的上升性、非绞痛性、持续的右上腹或上腹痛伴恶心及与油腻餐的关联、而后者更像民俗而不是物理；发作间期查体正常、血液检验正常——“不要叫它胆囊炎”规则——[[clinical-skills/history-taking]]）；检查（先超声——阴影结石与胆囊管不显影的判读、对结石敏感而对并发症不敏感——[[clinical-skills/medical-imaging]]）；处理（择期腹腔镜胆囊切除、对照复发与并发症的自然史来咨询；“仅在无症状偶然发现的结石才观察等待”的推论——[[surgery/gastrointestinal-surgery]]）。急性胆囊炎（嵌塞的结石加炎症加继发感染：持续疼痛、发热、Murphy征、肌卫、C反应蛋白与中性粒细胞升高；东京指南的严重度分级；超声带壁增厚、液体、超声Murphy与壁不灌注特征；当诊断重要而仍不确定时的核素扫描——[[clinical-skills/medical-imaging]]；病原——肠源与厌氧覆盖按本地耐药——[[microbiology/antimicrobials]]、[[microbiology/laboratory-diagnosis]]）；处理（抗生素与镇痛及在本次入院内的早期腹腔镜胆囊切除——早期对延迟的试验证据——[[surgery/gastrointestinal-surgery]]；为不适宜手术而重症者的经皮或内镜胆囊造瘘引流选项、及拔管与复发算术；坏疽穿孔产气性胆囊炎的升级[[surgery/acute-abdomen]]与Mirizzi狭窄陷阱——[[gastrointestinal/pancreas-biliary]]自己的[[#def-stones]]行）。** **胆总管结石及其呈现（结石进入胆总管——疼痛、然后是带结合型模式的黄疸及陶土便——[[gastrointestinal/liver-function]]的结合型模式；结合胆红素与胆管直径与肝酶及扫描所见结石的风险分层；按概率检查：中度的磁共振胆胰管成像或超声内镜、高概率与治疗意图的内镜逆行胆胰管造影带清除——[[clinical-skills/medical-imaging]]、[[surgery/gastrointestinal-surgery]]；内镜的风险——胰腺炎、穿孔、出血与胆管炎、及知情同意算术——[[medical-ethics-law/consent-capacity]]）；上行性胆管炎（梗阻感染胆汁的急症：Charcot三联与带休克及意识混乱的Reynolds五联征；血培养与抗生素及紧急胆道引流（内镜或经皮或外科）；脓毒症包裹复苏——[[infectious-diseases/fever-sepsis]]、[[emergency-critical-care/shock-fluids]]、[[gastrointestinal/liver-function]]的黄疸节）；及胆囊切除后综合征（残留与复发导管结石、胆囊管残端、胆汁酸性腹泻——[[gastrointestinal/digestion-absorption]]的结肠胆汁酸机制——Oddi括约肌功能障碍、及功能性疼痛重叠——[[gastrointestinal/bowel-disease]]的脑肠框定）。**
:::

## 自我消化的腺体

::: definition 急性胰腺炎 {#def-pancreatitis}
**病因（胆石与酒精占主导；然后高甘油三酯（通常超过约20毫摩尔每升——乳糜微粒综合征及胰岛素与贝特类及酒精驱动——[[cell-biochemistry/lipid-amino-acid-metabolism]]、[[endocrine/diabetes]]）、内镜后、药物（硫唑嘌呤与噻嗪及丙戊酸及甲硝唑清单——[[pharmacology/adverse-reactions]]）、高钙、自身免疫IgG4疾病（[[#def-other-pancreas]]）、创伤与毒液及感染（[[infectious-diseases/tropical-infections]]）、遗传与囊性纤维化及解剖变异（胰腺分裂、胆管囊肿——[[anatomy/embryology]]）、及反复特发的检查程序（遗传、IgG4、甘油三酯、超声内镜的隐匿结石）——[[genetics/mendelian-inheritance]]）。病理生理细胞内胰蛋白酶原过早激活——一个本应只在肠腔发生的肠激酶类似开关——然后腺泡损伤、炎症级联、及可进展为多器官衰竭的毛细血管漏全身炎症反应综合征；第三间隙潴留的腹腔间隔室综合征后果——[[physiology/homeostasis-body-fluids]]、[[immunology/innate-immunity]]、[[cell-biochemistry/proteins-enzymes]]的酶原化学、[[renal/acute-kidney-injury]]的低血容量打击、及胸腔积液与急性呼吸窘迫的呼吸后遗（[[respiratory/gas-exchange]]、[[respiratory/interstitial-vascular-disease]]）。诊断（三条中两条：特征性疼痛、脂肪酶超过正常上限三倍（淀粉酶窗口较窄且非胰腺原因——[[clinical-skills/laboratory-tests]]）、影像特征；第一天的问题是“为何”——胆石病因搜寻（肝功能与超声）因为它改变入院计划；早期计算机断层的问题答案是“不常规”——增强计算机断层用于诊断存疑与第二周以上的坏死判读、修订Atlanta逻辑）。严重度（评分家族——Ranson与Balthazar及APACHE的遗产对床旁BISAP与C反应蛋白斜率路径——及唯一重要的定义：超过48小时的持续器官衰竭等于重症——[[#def-pancreatitis]]；液体反应性与肌酐及血细胞比容轨迹作为实时判读——[[renal/water-sodium]]）。头48小时的处理（镇痛与氧及监护下的容量替代、用中等目标的晶体液——积极补液有害的WATERFALL时代教训、与低血容量权衡——[[emergency-critical-care/shock-fluids]]、[[cardiovascular/heart-failure]]；早期按耐受经口进食——禁食教条被试验逆转、[[gastrointestinal/clinical-nutrition]]；抗生素不作预防——仅用于证实与疑似感染及感染性坏死——[[microbiology/antimicrobials]]、[[infectious-diseases/stewardship-outbreaks]]；内镜的适应证规则（仅在并发胆管炎或持续胆道梗阻时急诊内镜——对常规早期内镜的阴性试验诚实——[[gastrointestinal/pancreas-biliary]]自己的[[#def-stones]]）；及重症触发项（持续器官衰竭、腹腔间隔室综合征监测、及“为间隔室综合征而非为胰腺开腹”原则——[[emergency-critical-care/critical-care]]、[[surgery/acute-abdomen]]））。局部并发症与其日历（胰周液体积聚然后急性坏死然后包裹性坏死的时间线；假性囊肿对包裹性坏死对脓肿的区分带导管中断之问；脾与门静脉血栓带其静脉曲张与脾大后遗（左侧门脉高压伴胃底静脉曲张——[[gastrointestinal/gi-bleeding-cancer]]、[[blood/thrombosis-anticoagulation]]）；假性动脉瘤出血（先导出血规则与血管栓塞——[[clinical-skills/medical-imaging]]）；胰源性腹水与内瘘；及感染性坏死的升阶梯处理（推迟并引流然后内镜或微创坏死组织清除——PANTER与TENSION试验架构、引流对手术的排序及抗真菌对细菌之争——[[surgery/gastrointestinal-surgery]]、[[microbiology/fungi-parasites]]））。长尾外分泌功能不全伴脂肪泻及粪弹性蛋白酶确认——[[gastrointestinal/digestion-absorption]]的脂肪消化规则；胰源性3c型糖尿病带其脆性糖尿病的微血管悖论与酶协调的胰岛素问题——[[endocrine/diabetes-complications]]；慢性疼痛与坏死及生活质量负荷——[[geriatrics-palliative/symptom-control]]；及对新发糖尿病与体重下降的老年吸烟者的癌症关联警觉——[[#def-cancers]]。**
:::

::: definition 慢性胰腺炎与IgG4疾病 {#def-other-pancreas}
**慢性胰腺炎（反复损伤纤维化导管病的终点：酒精与吸烟作为驱动、带吸烟剂量反应与戒烟回报、遗传（遗传性胰蛋白酶原与SPINK及囊性纤维化跨膜调节因子相关疾病）、热带营养相关、及梗阻与自身免疫病因——[[genetics/mendelian-inheritance]]、[[public-health/global-health]]、[[psychiatry/substance-use]]）；疼痛综合征导管高压、胰腺内神经炎症与中枢敏化——这就是为何伤害性镇痛失败而多模式慢性疼痛框定适用（邻近[[gastrointestinal/clinical-nutrition]]的营养与酒精规划、邻近[[psychiatry/anxiety-disorders]]的疼痛心理学、及[[nervous-system/headache-pain]]式的神经调节逻辑）；结构后果（钙化与导管结石及狭窄、假性囊肿与胆道及门静脉压迫综合征、及[[#def-pancreatitis]]长尾的外分泌内分泌衰竭）；检查（平片与计算机断层钙化判读、磁共振胆胰管成像分泌刺激试验的导管形态、超声内镜用于早期疾病带其观察者依赖、及功能检验粪弹性蛋白酶血清酶晚期模式——[[clinical-skills/medical-imaging]]、[[clinical-skills/laboratory-tests]]）；治疗阶梯戒酒与戒烟是唯一改变疾病的步骤；膳食与酶及抗酸药联合治疗及脂溶性维生素与骨监测（[[gastrointestinal/clinical-nutrition]]、[[endocrine/bone-calcium]]）；带阿片危害意识的镇痛与神经调节策略（[[geriatrics-palliative/symptom-control]]、[[pharmacology/adverse-reactions]]）；导管结石与狭窄的内镜治疗（体外冲击波碎石与扩张及置入支架——[[surgery/gastrointestinal-surgery]]）；为难治者的外科选项（引流——Puestow的侧胰空肠吻合与Frey及Beger的挖除术——对切除（远端与聚焦胰头）、及带其确定性糖尿病的全胰切除带胰岛自体移植的最后手段——[[surgery/gastrointestinal-surgery]]、[[endocrine/diabetes]]）；及癌症风险背景（慢性胰腺炎作为风险、遗传性胰蛋白酶原变异属最高之列——[[genetics/cancer-genetics]]）。**自身免疫性胰腺炎（IgG4相关：无痛黄疸、香肠样肿胀胰腺带包膜边缘、及未被识别时产生不必要Whipple手术的“癌模仿者”；血清IgG4升高但不完美、其他器官成员资格（硬化性胆管炎——[[gastrointestinal/liver-disease]]的原发性硬化性胆管炎模仿点、唾液与泪腺、腹膜后纤维化——[[renal/urinary-tract]]、肾与肺及淋巴结病变——[[immunology/autoimmunity]]、[[pathology/diagnostic-pathology]]的席纹状纤维化与IgG4浆细胞组织学）；戏剧性的激素应答伴减量时复发及激素节省的利妥昔单抗与硫唑嘌呤选项——[[pharmacology/adverse-reactions]]；及在那个标签之前强制的癌症排除——[[#def-cancers]]）。**
:::

::: example 肿胀的香肠 {#ex-ig4}
一名67岁男性6周无痛黄疸与体重下降6公斤；计算机断层显示弥漫增大“香肠形”胰腺带帽样边缘、肝内外胆管不规则狭窄、及唾液腺增大；胆红素128、IgG4升高5倍、CA19-9轻度升高、超声内镜无肿块。
::: solution
**伴相关硬化性胆管炎的IgG4相关自身免疫性胰腺炎——经典的癌模仿者（[[#def-other-pancreas]]、[[#def-cancers]]）：鉴别项（弥漫而非肿块形成性疾病、帽状边缘、唾液腺与胆道的多器官成员资格、IgG4升高但其特异度不完美、及无细胞学阳性病变——[[pathology/cancer-diagnosis]]、[[immunology/autoimmunity]]）；激素之前的强制癌症排除（超声内镜取样与刷检细胞学及随访影像纪律——[[clinical-skills/medical-imaging]]、[[gastrointestinal/liver-function]]的胆汁淤积检查程序）；激素诱导与减量方案伴撤药时复发统计、及利妥昔单抗与硫唑嘌呤的激素节省层（[[pharmacology/adverse-reactions]]、邻近[[geriatrics-palliative/polypharmacy]]）；胆管炎或深度黄疸的胆道引流之问（[[#def-stones]]）；其他器官筛查（腹膜后纤维化伴输尿管肾积水——[[renal/urinary-tract]]、肾与肺及垂体病变——[[endocrine/hypothalamus-pituitary]]、[[respiratory/interstitial-vascular-disease]]）；及重新警觉规则（2周内未“消融”就把诊断翻转回癌症——[[clinical-skills/clinical-reasoning]]、[[gastrointestinal/gi-bleeding-cancer]]）。**

::: solution
**伴感染性休克的Reynolds五联征上行性胆管炎（梗阻感染胆汁的急症——[[#def-stones]]）：第一小时包裹（[[infectious-diseases/fever-sepsis]]、[[emergency-critical-care/shock-fluids]]）：血培养然后广谱抗生素带胆道与厌氧覆盖按本地耐药（[[microbiology/antimicrobials]]）；液体与血管升压药复苏带重症复审（[[emergency-critical-care/critical-care]]）；确定性治疗是引流——急诊内镜括约肌切开球囊取石、若内镜失败或不可用则经皮或外科引流（[[clinical-skills/medical-imaging]]、[[surgery/gastrointestinal-surgery]]）；括约肌切开前的凝血障碍与抗凝算术（可被维生素K纠正的胆汁淤积国际标准化比值、及血小板与直接口服抗凝药规则——[[gastrointestinal/liver-function]]的合成课、[[blood/haemostasis-bleeding]]、[[blood/thrombosis-anticoagulation]]）；“来源控制时钟”的记录（到抗生素时间与到减压时间作为被审计的关键指标——[[clinical-skills/patient-safety]]）；及后续修复残留结石清除与胆总管考虑、及二级预防咨询（邻近[[gastrointestinal/gi-bleeding-cancer]]、[[gastrointestinal/liver-disease]]的胆囊切除后注、[[#def-stones]]）。**

## 恶性与囊肿

::: definition 胰腺癌与胆管癌 {#def-cancers}
**胰腺导管腺癌流行病学（随肥胖与老龄及吸烟上升——[[public-health/prevention-promotion]]）；风险阶梯（吸烟、慢性胰腺炎、糖尿病、新发糖尿病既是标志又可能是成因、及强家族史及综合征——BRCA2与Peutz-Jeghers及Lynch及非典型家族性腺瘤性息肉病及遗传性胰蛋白酶原——邻近[[gastrointestinal/gi-bleeding-cancer]]的[[genetics/cancer-genetics]]、及携带者高危监测规划之争——[[public-health/screening]]）；呈现（全身性体重下降厌食及背痛、若位于胰头则伴无痛黄疸——[[gastrointestinal/liver-function]]的梗阻性黄疸例、游走性血栓性静脉炎Trousseau综合征[[blood/thrombosis-anticoagulation]]、及门脾静脉侵犯[[cardiovascular/vascular-disease]]）；关于抑郁与惊恐前驱描述的诚实（[[psychiatry/mood-disorders]]）；诊断（胰腺方案计算机断层与磁共振及超声内镜带细针穿刺、及CA19-9不用于诊断且在胆汁淤积中也会升高——[[clinical-skills/medical-imaging]]、[[pathology/cancer-diagnosis]]、[[clinical-skills/laboratory-tests]]）；肿瘤董事会分支可切除——直接手术对正在转移的新辅助时代试验；边界可切除——新辅助然后重新评估；局部进展与转移——氟尿嘧啶伊立替康奥沙利铂与吉西他滨白蛋白紫杉醇的选择、分子检测BRCA与微卫星以期为罕见的免疫治疗赢家（[[pharmacology/dosing-principles]]、[[genetics/genomic-medicine]]、[[immunology/vaccines-immunotherapy]]）；外科（胰十二指肠切除Whipple或Traverso重建的三重吻合、及加速康复外科与远端胰切除、及血管切除重建的生态位、及渗漏与胃排空延迟下的死亡率下降——[[surgery/gastrointestinal-surgery]]）；姑息（黄疸与十二指肠梗阻的支架对外科旁路、预防性胃空肠吻合与十二指肠支架、及腹腔神经丛阻滞与神经毁损用于疼痛——[[geriatrics-palliative/symptom-control]]、[[gastrointestinal/liver-function]]的瘙痒阶梯）；及预后坦率的谈话与预先规划常规（[[geriatrics-palliative/palliative-care]]、[[medical-ethics-law/end-of-life-ethics]]）。**胆管癌肝门部Klatskin及远端及肝内的解剖；原发性硬化性胆管炎与肝吸虫及胆管囊肿及肝内胆管结石风险集——[[gastrointestinal/liver-disease]]、[[microbiology/fungi-parasites]]、[[anatomy/embryology]]；黄疸与瘙痒及胆管炎的呈现、及CA19-9与C反应蛋白的混杂；组织获取的困难与刷检细胞学的低收益及超声内镜活检选项（[[pathology/cancer-diagnosis]]）；可切除性的几何与体积测量及胆道引流与门静脉栓塞及肝再生科学[[surgery/gastrointestinal-surgery]]、[[gastrointestinal/liver-function]]的储备测试；为选定的早期原发性硬化性胆管炎相关肝门部规划的移植（[[immunology/transplant-tumour-immunology]]）；及支架对经皮引流与放疗及全身治疗的姑息（邻近[[gastrointestinal/gi-bleeding-cancer]]与[[geriatrics-palliative/palliative-care]]）。**壶腹部与十二指肠及乳头肿瘤（间断黄疸伴隐匿出血贫血的呈现（[[gastrointestinal/gi-bleeding-cancer]]的隐匿出血规则）与家族性腺瘤性息肉病的壶腹监测关联[[gastrointestinal/bowel-disease]]与[[genetics/cancer-genetics]]；内镜对外科乳头切除术的决定）。**胰腺囊性病变假性囊肿对导管内乳头状黏液性肿瘤对黏液性囊性肿瘤对浆液性囊腺瘤对神经内分泌肿块鉴别——随断层影像的“偶然囊肿流行”（[[clinical-skills/medical-imaging]]）；令人担忧的特征（壁结节与主胰管扩张及症状及囊肿增长）带修订国际Fukuoka与欧洲监测规则及过度治疗风险（[[public-health/screening]]）；超声内镜细针穿刺细胞学与癌胚抗原及淀粉酶及分子GNAS与KRAS辅助（[[pathology/cancer-diagnosis]]、[[genetics/genomic-medicine]]）；及防止不必要胰腺切除的“多数囊肿是观察而不是切除”咨询（[[clinical-skills/communication]]、[[surgery/gastrointestinal-surgery]]）。**
:::

::: example 到场即重症 {#ex-severe-panc}
一名58岁大量饮酒且已知胆结石的患者以上腹痛与呕吐2天就诊；心率118、呼吸26、空气下血氧93%、体温38.6、少尿；脂肪酶2400、钙1.9、肌酐168、尿素18、氧合指数210、碱剩余负6；胸片示左侧胸腔积液；腹部超声：多发小胆结石、胆总管6毫米、未见导管结石。
::: solution
**伴器官衰竭的重症急性胰腺炎、在证明否则之前是胆源性（入院即满足修订Atlanta定义——持续器官衰竭才是诊断而不是评分——[[#def-pancreatitis]]）：头数小时包裹——**气道呼吸循环、立即请重症监护或高层级监护复审（[[emergency-critical-care/acute-assessment]]、[[emergency-critical-care/critical-care]]）；用平衡晶体液做中等目标的液体复苏并重新评估容量过负荷（[[renal/acute-kidney-injury]]、[[cardiovascular/heart-failure]]的毛细血管漏警诫）；硬膜外或静脉多模式逻辑的镇痛（[[geriatrics-palliative/symptom-control]]、[[surgery/anaesthesia-pain]]）；内镜决定——不作为常规、但若胆管炎或持续胆道梗阻则是（本例的胆红素趋势与发热模式决定——[[#def-stones]]）；带行动的病因搜寻（日后小结石与正常胆总管的计算机断层或磁共振或超声内镜之问、及轻度胆源性胰腺炎的同院胆囊切除对重症的间隔规划——时机试验的细微[[surgery/gastrointestinal-surgery]]）；营养之问（早期开始经口或肠内；鼻空肠对鼻胃的非劣效及误吸翻位警诫——[[gastrointestinal/clinical-nutrition]]）；钙镁葡萄糖与乳酸台账（[[renal/potassium-calcium-phosphate]]、[[endocrine/bone-calcium]]）；不用预防性抗生素这一行（[[microbiology/antimicrobials]]）；及并行的家庭沟通与重症目标（[[clinical-skills/communication]]、[[medical-ethics-law/end-of-life-ethics]]）。**
:::
:::

::: example 第5周的积聚 {#ex-won}
在重症坏死性胰腺炎的第6周、一名患者因发热与疼痛恶化；计算机断层显示40%腺体坏死伴气体及一个压迫胃的包裹性积聚；碳青霉烯在2天前于别处开始。
::: solution
**在可操作时刻的感染性包裹性坏死（[[#def-pancreatitis]]的并发症日历）：升阶梯方法是证据（PANTER及后续：先经皮或内镜经壁引流、仅在失败时微创或视频辅助坏死组织清除——外科早期开放坏死组织清除有害的历史——[[surgery/gastrointestinal-surgery]]、[[clinical-skills/medical-imaging]]）；积聚的成熟使它可治（包裹的囊壁允许引流而无腹膜广泛污染——第4周规则带临床例外[[emergency-critical-care/critical-care]]）；微生物学驱动的抗生素与带引流液培养的抗真菌重新考虑（长时间碳青霉烯后的耐药微生物问题——[[microbiology/antimicrobials]]、[[microbiology/laboratory-diagnosis]]）；引流管维护冲洗加粗到外科的顺序、及“临床反应决定”原则（邻近[[geriatrics-palliative/symptom-control]]的重症支持）；导管解剖之问（磁共振或超声内镜查中断导管、及经乳头支架对内置引流的选择——[[gastrointestinal/pancreas-biliary]]自己的[[#def-pancreatitis]]）；新发内分泌外分泌功能衰竭筛查（3c型[[endocrine/diabetes-complications]]与粪弹性蛋白酶[[gastrointestinal/digestion-absorption]]）；及恢复规划坏死后的糖尿病与功能不全随访方案、及酒精与吸烟治疗参与（[[psychiatry/substance-use]]、[[gastrointestinal/clinical-nutrition]]、[[clinical-skills/records-handover]]）。**
:::

::: history
**共同通道的故事（Opie 1901年的壶腹部嵌塞理论、至今仍能解释胆源性胰腺炎——[[#def-pancreatitis]]）；Kehr与Langenbuch 1882年代的胆囊切除先驱、及Mühle（1985）的腹腔镜革命与Reddick的推广——[[surgery/gastrointestinal-surgery]]；内镜逆行胆胰管造影的成熟（McCune 1968年首次内镜乳头插管与Demling-Classen的括约肌切开时代——[[clinical-skills/medical-imaging]]）；Whipple（1935）与Traverso-Longmire的保留幽门再手术（1972）——[[surgery/gastrointestinal-surgery]]；Atlanta分类（1992）及其修订Atlanta精炼（2012），把“严重度”从民俗变成器官衰竭的定义（[[#def-pancreatitis]]）；“胰腺休息与全肠外营养”教条被早期肠内营养试验推翻（[[gastrointestinal/clinical-nutrition]]）；坏死组织清除的升阶梯试验（PANTER、TENSION——[[surgery/gastrointestinal-surgery]]）；积极液体治疗的再纠正（WATERFALL与目标导向治疗时代——[[emergency-critical-care/shock-fluids]]）；IgG4综合征的综合（Sarles与Yoshida的发现把“自身免疫性胰腺炎”与硬化性胆管炎及Mikulicz的观察统一起来——[[immunology/autoimmunity]]、[[gastrointestinal/liver-disease]]）；及罕见胰腺肿瘤生物学的分子检测与免疫治疗前沿（[[genetics/genomic-medicine]]、[[immunology/vaccines-immunotherapy]]）。**
:::

::: exercise 治疗这种胆汁酸性腹泻 {level=1}

::: solution

::: exercise 给酶定剂量 {level=2}

::: exercise 追踪甘油三酯 {level=2}
一名29岁患者的第三次“特发性”胰腺炎：取样时甘油三酯34毫摩尔每升、体质指数31、糖化血红蛋白48、超声内镜无结石、“乳浆样血浆”家族史。处理急性期与终身。
::: solution
**高甘油三酯性胰腺炎（乳糜微粒栓子与游离脂肪酸毒性机制——[[cell-biochemistry/lipid-amino-acid-metabolism]]、[[#def-pancreatitis]]的病因行）：家族性乳糜微粒综合征检查程序（脂蛋白脂酶轴基因与继发驱动审计——糖尿病与酒精及雌激素及维A酸及普萘洛尔——[[pharmacology/adverse-reactions]]、[[genetics/mendelian-inheritance]]）；急性期选择（胰岛素与葡萄糖输注对血浆置换之争、带证据薄弱的诚实[[endocrine/diabetes-complications]]、[[emergency-critical-care/critical-care]]）；终身规划（近乎完全限脂的膳食带中链甘油三酯补充与脂溶性维生素、及贝特类与omega-3及他汀逻辑及证据所在[[gastrointestinal/clinical-nutrition]]、[[cardiovascular/vascular-disease]]）；血糖规划（[[endocrine/diabetes-complications]]）；避免酒精与吸烟（[[psychiatry/substance-use]]）；为一个伴胰腺炎风险沟通的隐性疾病做遗传咨询（[[genetics/genetic-testing]]）；及胰腺炎预防终点（甘油三酯靶目标与脂肪摄入及体重规划、带反复发作与慢性胰腺炎的利害关系[[#def-other-pancreas]]）。**

::: summary
- 症状性胆结石意味着胆囊切除；导管结石意味着按风险分层的磁共振胆胰管成像或超声内镜或内镜；胆管炎意味着抗生素加紧急引流及脓毒症照护。
- 急性胰腺炎按逐小时的生理处理：中等液体、早期进食、不用预防性抗生素、内镜仅用于胆管炎或梗阻、计算机断层用于并发症日历。
- 感染性坏死在最晚可行时刻经升阶梯路径治疗；先引流、仅在需要时坏死组织清除。
- 慢性胰腺炎的处理始于戒酒与戒烟（方案中唯一改变疾病的药物），然后多模式镇痛、导管的内镜治疗、及为难治者手术。
- 老年成人的无痛黄疸在胰腺方案计算机断层说明否则之前是胰腺癌；IgG4疾病是那个必须在切除前由影像、血清学与激素应答逻辑排除的模仿者。
:::

## 练习

::: exercise 给疼痛分类 {level=1}
对胆绞痛、急性胆囊炎、上行性胆管炎、胆源性胰腺炎，各给出一个鉴别特征与关键检验。
::: solution
**绞痛：一过性自行缓解的疼痛、发作间期血液与查体正常、超声查结石（[[#def-stones]]）；胆囊炎：伴发热与Murphy征及C反应蛋白的持续疼痛、超声的壁与超声Murphy所见及东京分级（[[#def-stones]]）；胆管炎：黄疸发热休克伴结合型模式及胆管扩张、血培养与紧急减压（[[#def-stones]]、[[infectious-diseases/fever-sepsis]]）；胆源性胰腺炎：疼痛伴脂肪酶超过正常3倍、及肝功能与超声的病因搜寻加胆管炎内镜决定（[[#def-pancreatitis]]）。**
:::
:::

::: exercise 明智地选液体 {level=1}
“积极补液挽救胰腺炎患者”——用现代证据与生理更新这个口号。
::: solution
**中等、有目标、反复评估（[[#def-pancreatitis]]）：毛细血管漏与第三间隙潴留的生理要求早期给容量（[[physiology/homeostasis-body-fluids]]、[[emergency-critical-care/shock-fluids]]），但过度复苏会推动肺水肿、腹腔间隔室压力与更差结局（积极对中等的随机证据）；滴定目标（心率与乳酸及肌酐与尿量、并定期重新评估而不是固定升数处方）；及心肾共病的调整（[[cardiovascular/heart-failure]]、[[renal/chronic-kidney-disease]]）。**
:::

::: exercise 读这份囊肿报告 {level=2}
一名66岁的磁共振显示一个2.6厘米钩突囊肿伴4毫米强化的壁结节及6毫米主胰管；CA19-9轻度升高而胆红素正常。给出咨询。
::: solution
**在证明否则之前是带令人担忧特征的导管内乳头状黏液性肿瘤（[[#def-cancers]]的囊肿行）：壁结节是高危特征、及主胰管直径之问、及转诊做超声内镜带细针穿刺与细胞学及分子检测（[[clinical-skills/medical-imaging]]、[[pathology/cancer-diagnosis]]）；监测对手术的平衡（结节偏向切除；年龄与共病及单一病灶风险的算术、及“许多囊肿永不进展”的诚实——[[public-health/screening]]、[[clinical-skills/communication]]）；CA19-9的解读（胆汁淤积与良性升高的警诫——[[clinical-skills/laboratory-tests]]）；胰腺病学家与肝胆外科医师的多学科转诊（[[surgery/gastrointestinal-surgery]]）；及若选择监测则记录在案的安全网（带具名责任的间隔影像计划——[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]）。**
:::

::: exercise 管好这个疼痛门诊 {level=2}
