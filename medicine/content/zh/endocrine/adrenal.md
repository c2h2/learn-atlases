肾上腺是两座小工厂、其衰竭与过多各自产生一个综合征、其中一个（未治疗的肾上腺危象）在数小时内致死、而另一个（外源性类固醇过多）是它所模拟疾病的最常见病因。**内分泌性高血压也住在这里：醛固酮过多与儿茶酚胺过多是每个难治性高血压规程都该搜寻的两个“可查”病因。**

本章涵盖肾上腺生理与试验、肾上腺皮质功能减退、库欣综合征、原发性醛固酮增多症、嗜铬细胞瘤与偶发瘤。

## 生理与试验

::: definition 三个带与其激素 {#def-physiology}
**架构（球状带在肾素-血管紧张素与钾的驱动下产生醛固酮——不以促肾上腺皮质激素为主；束状带在垂体促肾上腺皮质激素下产生皮质醇带其强昼夜节律——[[physiology/hormones]]；网状带产生肾上腺雄激素；髓质是一个分泌儿茶酚胺的 修饰的交感神经节——[[physiology/autonomic-nervous-system]]、[[anatomy/abdomen]]）；类固醇生化（胆固醇经StAR与CYP11A1变为孕烯醇酮、然后分支酶CYP21A2、CYP11B1与B2、CYP17A1及醛固酮合酶——先天性肾上腺增生的酶阻断及其失盐与男性化及高血压表型属于[[genetics/mendelian-inheritance]]与[[paediatrics/congenital-genetic]]与[[endocrine/reproductive-endocrinology]]领地；[[cell-biochemistry/lipid-amino-acid-metabolism]]）。皮质醇作用（糖异生与胰岛素拮抗及蛋白分解及脂肪重分布——[[cell-biochemistry/metabolic-integration]]、[[endocrine/diabetes]]；对血管张力的允许可儿茶酚胺效应——[[cardiovascular/circulation-blood-pressure]]；免疫重编程与类固醇-淋巴细胞故事——[[immunology/innate-immunity]]、[[immunology/adaptive-responses]]；骨与肌肉及皮肤与脑——[[endocrine/bone-calcium]]、[[psychiatry/mood-disorders]]；11β-羟类固醇脱氢酶2在盐皮质激素靶细胞中灭活皮质醇——醛固酮特异性的许可证、在甘草与表观盐皮质激素过多综合征中丧失——[[renal/tubular-function]]）。醛固酮作用（远端肾单位钠钾交换与钾感知环——[[renal/tubular-function]]、[[renal/potassium-calcium-phosphate]]；逃逸生理及为何无水肿）。试验晨起皮质醇与短效促皮质素试验查功能减退、带测定阈值与近期激素警诫——[[clinical-skills/laboratory-tests]]；库欣筛查三联——尿游离皮质醇、夜间1毫克地塞米松、深夜唾液——及两个异常试验规则；醛固酮-肾素比值带其药物与血钾及体位及肾功能混杂——β阻滞剂假阳性与血管紧张素转换酶抑制剂及利尿剂假阴性算术——[[clinical-skills/laboratory-tests]]、[[cardiovascular/hypertension]]；血浆与尿甲氧基肾上腺素类查嗜铬细胞瘤带三环抗抑郁药与拟交感及穿刺应激警诫；及[[endocrine/hypothalamus-pituitary]]的动态试验哲学。**

## 过少

::: definition 肾上腺皮质功能减退 {#def-insufficiency}
**原发性（Addison病——主导发达国家系列的自身免疫性肾上腺炎、带其与甲状腺及性腺及胃及皮肤及垂体病的多腺体聚集——[[immunology/autoimmunity]]、[[endocrine/thyroid]]、[[endocrine/reproductive-endocrinology]]、[[gastrointestinal/oesophagus-stomach]]的恶性贫血行、[[musculoskeletal/skin]]的白癜风；感染——结核与真菌及HIV——[[infectious-diseases/tuberculosis]]、[[infectious-diseases/hiv]]、[[microbiology/fungi-parasites]]；出血、尤其伴抗凝药与脓毒症——[[blood/haemostasis-bleeding]]、[[infectious-diseases/fever-sepsis]]；浸润性——转移与淀粉样变及IgG4及血色病——[[gastrointestinal/liver-disease]]、[[pathology/chronic-inflammation-repair]]；药物——类固醇抑制反跳及依托咪酯与酮康唑及检查点抑制剂内分泌病——[[pharmacology/adverse-reactions]]、[[immunology/vaccines-immunotherapy]]）。继发性（全部病因中最常见——外源性类固醇撤除抑制下丘脑-垂体-肾上腺轴、带吸入与外用及关节腔注射及肾上腺抑制意外清单——[[respiratory/asthma-copd]]、[[musculoskeletal/inflammatory-arthritis]]、[[geriatrics-palliative/polypharmacy]]；及垂体病——[[endocrine/hypothalamus-pituitary]]）。决定治疗的区别（原发性丢失盐皮质激素——高钾、低钠、体位下降、因促肾上腺皮质激素共同分泌的色素沉着——[[renal/potassium-calcium-phosphate]]、[[renal/water-sodium]]；继发性保留醛固酮所以电解质常常平淡、且从不需要氟氢可的松——诊断性的促肾上腺皮质激素划分）。表现（隐匿的疲劳体重下降嗜盐饥饿恶心低血压综合征、被误贴标签为抑郁或肠易激数月——[[psychiatry/mood-disorders]]、[[gastrointestinal/bowel-disease]]；危象——呕吐休克低血糖低钠高钾、其病死率完全是识别时间的函数——[[endocrine/endocrine-emergencies]]、[[emergency-critical-care/shock-fluids]]、[[renal/acute-kidney-injury]]）。诊断（皮质醇低伴促肾上腺皮质激素高即原发；短效促皮质素无反应带其近期激素与继发带部分抑制警诫；病因的肾上腺自身抗体与影像——[[clinical-skills/laboratory-tests]]、[[clinical-skills/medical-imaging]]）。治疗（模拟节律分次氢化可的松替代——依从性与合病加倍规则、急救针、及作为四件安全件的身份手环与激素卡与病日规程——原发性加氟氢可的松；[[surgery/perioperative-care]]的围手术期应激剂量阶梯；过度替代的骨与体重与情绪警觉——[[endocrine/bone-calcium]]、[[gastrointestinal/clinical-nutrition]]；及作为首要干预的教育——注射的回授、疾病视频、及晕厥发作的驾驶规则——[[clinical-skills/communication]]、[[medical-ethics-law/professionalism-regulation]]）。**

## 过多

::: definition 库欣综合征 {#def-cushing}
**按现实排位的病因外源、外源、外源——在任何抽血之前的处方与注射及乳膏及吸入剂及草药掺假审计——[[pharmacology/adverse-reactions]]、[[musculoskeletal/skin]]；然后促肾上腺皮质激素分泌性垂体腺瘤（库欣病——[[endocrine/hypothalamus-pituitary]]）；肾上腺肿瘤（多为单侧、影像与生化一致——[[clinical-skills/medical-imaging]]）；及异位促肾上腺皮质激素（小细胞肺癌与神经内分泌肿瘤带其快速分解代谢表现——[[respiratory/lung-cancer-pleura]]、[[gastrointestinal/pancreas-biliary]]）。识别（区分性特征——易瘀斑、近端肌病、紫红色膨胀纹、颈背与面部脂肪重分布、及肥胖与高血压及糖尿病及月经少及抑郁及背痛的低特异群——[[endocrine/diabetes]]、[[cardiovascular/hypertension]]、[[endocrine/bone-calcium]]、[[psychiatry/mood-disorders]]、[[endocrine/reproductive-endocrinology]]；及疾病账本——感染与血栓及骨折及心脏——[[immunology/innate-immunity]]、[[blood/thrombosis-anticoagulation]]）。确证（两种不同模态的两个异常筛查试验、然后晨促肾上腺皮质激素划分依赖对非依赖、然后大剂量抑制与促肾上腺皮质激素释放激素及岩下窦梯度用于MRI阴性的依赖病例——[[endocrine/hypothalamus-pituitary]]手艺、[[clinical-skills/laboratory-tests]]、[[clinical-skills/medical-imaging]]；假性库欣混杂——抑郁、酒精、肥胖、多囊卵巢、轮班与依从不良——及深夜唾液与尿不一的锤定音——[[psychiatry/mood-disorders]]、[[psychiatry/substance-use]]、[[endocrine/reproductive-endocrinology]]）。治疗（库欣病经蝶手术优先、带缓解与肾上腺功能减退恢复历程——[[endocrine/hypothalamus-pituitary]]、[[endocrine/endocrine-emergencies]]；肾上腺来源的单侧肾上腺切除（[[surgery/gastrointestinal-surgery]]内分泌外科实践；激素覆盖与恢复月数规程）；药物桥接或归宿——类固醇合成抑制剂及垂体定向与受体阻断选项带其监测——[[pharmacology/dosing-principles]]；及隐匿来源的确定性对双侧肾上腺切除之争）。治愈后的时代（轴苏醒期间长期糖皮质激素覆盖——数月的疲劳与关节痛及情绪波动咨询及危象预防措施的延续——[[endocrine/endocrine-emergencies]]、[[clinical-skills/communication]]；及缓慢消融的骨与体重及心理负担带其生活质量指标与心血管风险残余——[[endocrine/bone-calcium]]、[[gastrointestinal/clinical-nutrition]]、[[public-health/prevention-promotion]]）。**
:::

::: definition 醛固酮过多与儿茶酚胺过多 {#def-aldosteronism}
**原发性醛固酮增多症（自主性醛固酮性高血压——腺瘤对双侧增生的划分驱动治疗岔路；如今“常见”而非“罕见”的流行病学、高血压门诊就诊者多达五分之一伴难治性高血压富集——[[cardiovascular/hypertension]]；病例发现触发——难治或早发高血压、自发性或利尿剂诱发的低钾、肾上腺偶发瘤、早发卒中家族史——[[renal/potassium-calcium-phosphate]]、[[nervous-system/stroke]]；醛固酮-肾素比值带其停药与补钾及肾功能及昼夜警诫——假阳性与假阴性药理——[[pharmacology/adverse-reactions]]、[[clinical-skills/laboratory-tests]]；按规程的确证抑制试验或直接手术路径逻辑；肾上腺CT与肾上腺静脉取血的真相讲述（使取血成为手术候选者仲裁者的影像不一率——[[clinical-skills/medical-imaging]]）；治疗——腹腔镜单侧肾上腺切除对盐皮质激素受体阻滞（螺内酯与依普利酮男性乳腺发育与高钾及妊娠规则——[[endocrine/reproductive-endocrinology]]、[[renal/potassium-calcium-phosphate]]）、目标是控制血压与正常血钾而非醛固酮数字；靶器官奖赏——醛固酮超出血压的过多纤维化与心房颤动及慢性肾病及代谢风险——[[cardiovascular/arrhythmias]]、[[renal/chronic-kidney-disease]]、[[endocrine/diabetes]]；及低肾素高血压鉴别——盐皮质激素模拟者：甘草与 甘珀酸 及表观盐皮质激素过多综合征与Liddle综合征（上皮钠通道获得功能、用阿米洛利而不是螺内酯治疗——[[renal/tubular-function]]、[[genetics/mendelian-inheritance]]）；及肾素分泌与肾血管性继发醛固酮增多状态——[[cardiovascular/vascular-disease]]、[[renal/filtration]]）。嗜铬细胞瘤与副神经节瘤嗜铬组织的儿茶酚胺分泌肿瘤——肾上腺外交感副神经节瘤带其仅去甲肾上腺素化学、及头颈副交感副神经节瘤的不同行为——[[anatomy/head-neck]]；如今占多数的遗传学——VHL与2型多发性内分泌腺瘤病及1型神经纤维瘤病及琥珀酸脱氢酶级联、及“最年轻者与家族史者都检测”共识——[[genetics/cancer-genetics]]、[[genetics/genetic-testing]]、[[endocrine/reproductive-endocrinology]]、视网膜血管母细胞瘤检查——[[nervous-system/sensory-systems]]；表现（经典的阵发头痛心悸出汗三联、及潜伏清单：高血压危象带儿茶酚胺心肌病与肺水肿及卒中及高血糖——[[cardiovascular/heart-failure]]、[[respiratory/gas-exchange]]邻近水肿、[[nervous-system/stroke]]、[[endocrine/diabetes]]——加上持续性高血压与偶发瘤及休克假脓毒症极端）；诊断（血浆游离甲氧基肾上腺素带分析前严格与药物干扰表、然后CT或MRI及功能影像——[[clinical-skills/laboratory-tests]]、[[clinical-skills/medical-imaging]]；规则：阻滞之前不穿刺、未准备的麻醉不做——[[surgery/anaesthesia-pain]]）；准备与手术α阻滞先、然后β、绝不β先、带体位下降与盐及液体负荷逻辑及术中危象药理——酚妥拉明与硝普钠及镁及夹闭后去甲肾上腺素补充——[[surgery/gastrointestinal-surgery]]、[[emergency-critical-care/critical-care]]、[[pharmacology/autonomic-drugs]]；之后（按基因型的复发与转移监测——琥珀酸脱氢酶的恶性风险——[[public-health/screening]]；家系级联检测——[[genetics/genetic-testing]]；及罕见的膀胱副神经节瘤排尿晕厥与颈动脉体瘤变体——[[renal/urinary-tract]]、[[anatomy/head-neck]]）。**

55岁因肾绞痛做的CT显示一个边界清晰3.4厘米肾上腺肿块伴低密度；自诊断以来他“多汗焦虑的夜晚”；血浆甲氧基肾上腺素回报升高3倍。
::: solution
**两条规则刚刚相撞（[[#def-aldosteronism]]嗜铬行、[[clinical-skills/clinical-reasoning]]）：每个肾上腺偶发瘤都做一次激素检查组合（库欣筛查、高血压则醛固酮-肾素、及甲氧基肾上腺素——影像看不到的轻度自主皮质醇分泌综合征与嗜铬比例——[[clinical-skills/laboratory-tests]]）、而每个甲氧基肾上腺素阳性的肿块在未阻滞未切除之前都是嗜铬细胞瘤。顺序：**CT特征的警诫（低密度提示腺瘤但在生化上不证明任何事——[[clinical-skills/medical-imaging]]）；带分析前严格与用药审计的复查甲氧基肾上腺素（[[pharmacology/adverse-reactions]]）；MRI定性与功能影像搜寻肾上腺外（[[clinical-skills/medical-imaging]]）；α先于β的阻滞与盐负荷准备及禁触诊禁穿刺警告——穿刺一个未阻滞的嗜铬是经典伤害故事（[[surgery/anaesthesia-pain]]、[[endocrine/endocrine-emergencies]]）；带动脉与麻醉专长的手术切除及夹闭后低血压与低血糖监测（[[surgery/gastrointestinal-surgery]]、[[emergency-critical-care/critical-care]]）；基因检测提供（年龄与家族史及多发规则——[[genetics/genetic-testing]]、[[genetics/cancer-genetics]]、[[endocrine/reproductive-endocrinology]]）；及长期监测与“焦虑原来是肿瘤”的复盘——它使未来的症状报告恢复可信（[[public-health/screening]]、[[clinical-skills/communication]]、[[psychiatry/anxiety-disorders]]）。**
:::
:::

::: example 低钾的快速衰退 {#ex-ectopic}
63岁重度吸烟者、已知慢阻肺、因3周近端无力、新发意识模糊、血糖19、三次补钾下钾仍2.4、代谢性碱中毒、及“数周内形成的”面部多血就诊；促肾上腺皮质激素340、所有筛查中皮质醇均未被抑制；CT显示右肺门肿块。
::: solution
**胸腔内肿瘤的异位促肾上腺皮质激素——经典脂肪重分布来不及形成的快速分解代谢库欣变体（[[#def-cushing]]：大量皮质醇饱和11β-羟类固醇脱氢酶的盐皮质激素溢出综合征解释低钾性碱中毒与高血压——[[renal/tubular-function]]、[[renal/potassium-calcium-phosphate]]、[[physiology/hormones]]受体特异性逻辑）；急性处理（积极的钾与镁补充带心律失常监测——[[renal/potassium-calcium-phosphate]]、[[cardiovascular/arrhythmias]]）；血糖控制——[[endocrine/diabetes]]；阻断类固醇合成的紧急选项（甲吡酮或酮康唑带肝功警觉、或ICU静脉用药）在肿瘤治疗之前打断皮质醇毒性——[[pharmacology/dosing-principles]]、[[emergency-critical-care/critical-care]]；感染与静脉血栓栓塞预防的思考（类固醇免疫抑制与高凝账本——[[immunology/innate-immunity]]、[[blood/thrombosis-anticoagulation]]）；胸腔来源的组织诊断与分期（[[respiratory/lung-cancer-pleura]]、[[pathology/cancer-diagnosis]]）；及确定计划（肿瘤治疗加[[#def-cushing]]治愈后行的肾上腺功能减退覆盖逻辑、带预后诚实沟通——[[geriatrics-palliative/palliative-care]]、[[clinical-skills/communication]]）。**
:::

::: quiz
嗜铬细胞瘤患者在α阻滞之前开始β阻滞剂是危险的、因为：
- [x] 无对抗的α介导血管收缩能诱发高血压危象与肺水肿
- [ ] 它造成低血糖
- [ ] 它阻断儿茶酚胺释放
- [ ] 它只造成不可逆心动过缓
::: solution
**β2血管扩张被移除、α收缩无对抗、而后负荷激增落在一个儿茶酚胺收缩的循环上——[[#def-aldosteronism]]的危象与水肿生理带其[[respiratory/gas-exchange]]与[[cardiovascular/circulation-blood-pressure]]后果；正确顺序（先α后β、绝不反转、绝不单用β）是药理学永久红规则之一——[[pharmacology/autonomic-drugs]]、[[endocrine/endocrine-emergencies]]。**
:::

::: history
**Addison于1855年描述“肾上腺黑色消耗”与漫长的皮质醇之前时代、当时此病是一个死刑——内分泌学会的经典病例；Kendall 1914年从屠宰场肾上腺（来自大西部牲畜市场）做氯仿提取物（数千毫升腺体换数毫克）、及Hench与Cartland 1940年代的可的松时代一夜之间使类风湿关节炎与肾上腺皮质功能减退可治（1950年诺贝尔奖）——[[musculoskeletal/inflammatory-arthritis]]、[[immunology/innate-immunity]]；促皮质素试验的标准化；Conn于1955年描述“伴肾上腺皮质腺瘤与低钾的高血压综合征”——第一个可治愈高血压的故事——[[cardiovascular/hypertension]]、[[renal/potassium-calcium-phosphate]]；嗜铬反应时代（Fraenkel与Fraenkel 1912年手术切除Langerhans的肿瘤）遇上现代遗传学洪水（VHL与2型多发性内分泌腺瘤病及琥珀酸脱氢酶级联——[[genetics/cancer-genetics]]）；1990-2000年代肾上腺静脉取血的转变证明了CT一半时间是错的（[[clinical-skills/medical-imaging]]）；隐匿库欣的岩下窦采样手艺时代（[[endocrine/hypothalamus-pituitary]]）；及检查点抑制剂垂体炎与肾上腺炎文献为两千年历史的腺体增添了二十一世纪的病因（[[immunology/vaccines-immunotherapy]]）。**
:::

## 通向何处

垂体驱动在[[endocrine/hypothalamus-pituitary]]；急症（危象、嗜铬、危象风暴）在[[endocrine/endocrine-emergencies]]；类固醇代谢后果在[[endocrine/diabetes]]；骨在[[endocrine/bone-calcium]]；遗传学在[[genetics/cancer-genetics]]；高血压在[[cardiovascular/hypertension]]；围手术期类固醇管理在[[surgery/perioperative-care]]。

::: exercise 读这个比值、读两遍 {level=2}
一名因偏头痛服普萘洛尔患者的醛固酮-肾素比值回报“阳性”350、钾3.2、估算肾小球滤过率55、在一次繁忙门诊后15:00立位取样。列出问题并重建规程。
::: solution
**四个以上混杂（[[#def-aldosteronism]]、[[clinical-skills/laboratory-tests]]）：β阻滞剂抑制肾素（假阳性方向）、低钾抑制醛固酮（假阴性——而其本身是一个应追查的发现）、肾小球滤过率降低扭曲两者并改变阈值、而时机与体位规则被违反；重建——补钾、按规程暂停盐皮质激素受体拮抗剂与阿米洛利数周并换用维拉帕米或多沙唑嗪等、晨起活动后坐位标准、复查带确证试验逻辑、及解读中的肾功能警诫（[[renal/chronic-kidney-disease]]、[[pharmacology/adverse-reactions]]）；及提醒：β阻滞剂下肾素受抑而醛固酮正常仍可意味着自主疾病——第二试验纪律（[[cardiovascular/hypertension]]）。**
:::
:::

::: exercise 为避孕药片校正 {level=2}
一名服复方口服避孕药的女性“总皮质醇高”而地塞米松抑制模棱；游离皮质醇与唾液试验正常。解释并计划。
::: solution
**雌激素升高皮质醇结合球蛋白、使总皮质醇与总甲状腺素式测量膨胀而不改变游离激素（[[#def-physiology]]结合蛋白行、[[endocrine/thyroid]]平行、[[pharmacology/patient-variation]]）；因此当雌激素在场时使用游离皮质醇或唾液或深夜模态的规则（[[clinical-skills/laboratory-tests]]）；计划——相信正常的游离皮质醇与唾液对、不再影像、记录结合蛋白解释使下一位临床医师不重启级联（[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]）；及同样推理应用于甲状腺素结合球蛋白与妊娠及肾病与肝硬化的扰动（[[obstetrics-gynaecology/pregnancy-antenatal]]、[[gastrointestinal/liver-function]]）。**
:::

::: summary
- 肾上腺皮质功能减退用皮质醇与促肾上腺皮质激素及促皮质素试验诊断、并靠教育存活：卡片、注射、病日规则与围手术期覆盖。
- 外源性类固醇仍是库欣综合征与继发性肾上腺功能减退的首要病因——在开检验之前先审计处方。
- 库欣确证需要两种不同类型的异常筛查，然后才有人去碰MRI。
- 原发性醛固酮增多症是高血压常见而可治愈的贡献因素；带着药物与血钾的考量解读醛固酮-肾素比值、并让静脉取血而不是CT决定手术。
- 嗜铬细胞瘤是生化优先、α阻滞先于β阻滞、多数人查遗传学、而绝不在未准备时穿刺。
:::

## 练习

::: exercise 解读晨起皮质醇 {level=1}
一名不适患者随机14:00皮质醇220 nmol/L：这能排除肾上腺皮质功能减退吗？什么能？
::: solution
**不能——时机与疾病及结合蛋白混杂（[[#def-physiology]]、[[clinical-skills/laboratory-tests]]）；排除需要正确临床与药物背景下足够的兴奋应答（短效促皮质素峰值阈值）、最好有晨起基线带促肾上腺皮质激素（[[#def-insufficiency]]）；对急性不适患者、先治疗并毫不延迟地检测的逻辑适用（[[endocrine/endocrine-emergencies]]）。**
:::
:::

::: exercise 说出电解质签名 {level=1}
低钠伴高钾与高促肾上腺皮质激素；对低钠伴正常血钾与低促肾上腺皮质激素——哪个是哪个？
::: solution
**原发性（Addison病——醛固酮丢失、钾潴留、肾素与促肾上腺皮质激素升高、色素沉着——[[#def-insufficiency]]、[[renal/potassium-calcium-phosphate]]）对继发性（垂体——醛固酮经肾素保留、促肾上腺皮质激素低——[[endocrine/hypothalamus-pituitary]]）；两者都能以危象表现（[[endocrine/endocrine-emergencies]]）而两者都需要氢化可的松、只有一个需要氟氢可的松。**
:::
:::

::: exercise 分拣高血压 {level=2}
下列各需要什么第二意见检查组合：(a) 32岁三种药下钾3.1；(b) 60岁阵发头痛与出汗及视网膜病变；(c) 44岁近端肌病与瘀斑及新发需胰岛素糖尿病？
::: solution
**(a) 醛固酮-肾素比值路径带补钾与药物管理（[[#def-aldosteronism]]、[[cardiovascular/hypertension]]）；(b) 甲氧基肾上腺素然后影像带未准备不造影不麻醉不穿刺规则（[[#def-aldosteronism]]）；(c) 库欣筛查三联带先做外源审计（[[#def-cushing]]、[[endocrine/diabetes]]、[[pharmacology/adverse-reactions]]）；每个都从[[#def-aldosteronism]]与[[#def-cushing]]的病例发现触发表开始。**
:::
:::

::: exercise 计划减量 {level=2}
39岁哮喘患者每日泼尼松龙10毫克已8个月，问能否停药。写出基于生理的计划。
::: solution
**抑制风险规则（疗程超过3周且剂量超过生理量及夜间对晨间方案的细微——[[respiratory/asthma-copd]]、[[#def-insufficiency]]）：评估然后小步降级带肾上腺功能不全恢复监测、及在生理阈值时晨起皮质醇与短效促皮质素（[[clinical-skills/laboratory-tests]]）；桥接计划（每一步之前哮喘控制复审与吸入优化[[respiratory/asthma-copd]]与[[pharmacology/dosing-principles]]）；减量期间的合病与牙科及手术覆盖教育（[[surgery/perioperative-care]]、[[endocrine/endocrine-emergencies]]）；撤药症状对危象的咨询（[[clinical-skills/communication]]）；及记录在一份共享计划中的减量速度与复发暂停规则（[[clinical-skills/records-handover]]、[[geriatrics-palliative/polypharmacy]]）。**
:::
:::

::: exercise 为手术建议 {level=2}
44岁皮质醇分泌性肾上腺腺瘤伴促肾上腺皮质激素受抑患者做腹腔镜肾上腺切除。什么覆盖术后时期、为何它会很难熬？
::: solution
**单侧伴抑制的格局意味着剩下的腺体在沉睡（[[#def-cushing]]治愈后行）：围手术期然后递减的氢化可的松覆盖按垂体-肾上腺苏醒的数周到一年以上时间线（[[surgery/perioperative-care]]、[[endocrine/endocrine-emergencies]]）；提前咨询的皮质醇撤除综合征（疲劳关节痛恶心情绪低落与体位症状而化验正常）、使它不被误读为手术失败或新病（[[clinical-skills/communication]]、[[psychiatry/mood-disorders]]）；覆盖期间的病日规则与卡片（[[#def-insufficiency]]）；及代谢消融随访（体重重分布与血糖及血压改善对持续、骨恢复与抑郁恢复曲线——[[endocrine/diabetes]]、[[endocrine/bone-calcium]]、[[gastrointestinal/clinical-nutrition]]）。**
:::

::: exercise 设计肾上腺偶发瘤规程 {level=3}
写出从CT报告到出院或门诊的放射触发路径、覆盖激素、影像特征、大小规则、嗜铬安全与遗传学。
::: solution
**报告模板触发（肾上腺方案与密度及形态特征、及“不要把一个肿块降级为一个形容词”的放射规则——[[clinical-skills/medical-imaging]]；默认激素组合——甲氧基肾上腺素、库欣筛查、高血压或低钾则醛固酮-肾素、及轻度自主皮质醇分泌讨论——[[clinical-skills/laboratory-tests]]、[[#def-cushing]]、[[#def-aldosteronism]]）；安全联锁——排除并阻滞嗜铬之前不穿刺不手术（[[endocrine/endocrine-emergencies]]、[[surgery/anaesthesia-pain]]）；大小与手术规则（生长与可疑影像及超过4厘米的讨论带癌症绝对风险数字——[[surgery/gastrointestinal-surgery]]）；随访网格（复查影像与再评估间隔带造影与辐射负担逻辑及停止规则——[[public-health/screening]]、[[public-health/environmental-occupational]]）；年轻、双侧、多发或家族史队列的遗传学通道——[[genetics/genetic-testing]]、[[genetics/cancer-genetics]]、[[endocrine/reproductive-endocrinology]]；闭合初级照护环路文书与安全网信（[[clinical-skills/records-handover]]、[[clinical-skills/patient-safety]]）；及审计组套（干预前嗜铬检出率、生化检查完整度、作为过度手术反向指标的切除标本恶性率、及从CT到决定的时间——[[public-health/health-systems-economics]]）。**
