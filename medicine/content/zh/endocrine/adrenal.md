每侧肾上腺只有几克重，却包含两个器官。外层的**皮质**合成类固醇激素：皮质醇、醛固酮和肾上腺雄激素。内层的**髓质**是一个特化的交感神经节，分泌肾上腺素。皮质醇过少可在数小时内致命；皮质醇过多，经年累月会损害骨骼、肌肉、皮肤、血管和精神。醛固酮过多是高血压最常见的可治愈病因之一，但严重漏诊。

本课介绍肾上腺生理、肾上腺皮质功能减退症（包括糖皮质激素药物引起的抑制）、库欣综合征、原发性醛固酮增多症、嗜铬细胞瘤、先天性肾上腺皮质增生症以及偶然发现的肾上腺肿物。肾上腺危象和嗜铬细胞瘤危象的急诊处理见[[endocrine/endocrine-emergencies]]。

## 生理 {#sec-physiology}

::: definition 肾上腺的分带及其激素 {#def-physiology}
肾上腺皮质有三层，每层有各自的酶和调控者：

| 分带 | 主要产物 | 主要调控者 |
|---|---|---|
| 球状带（外层） | 醛固酮（盐皮质激素） | 血管紧张素Ⅱ和血钾 |
| 束状带（中层） | 皮质醇（糖皮质激素） | ACTH |
| 网状带（内层） | 脱氢表雄酮（DHEA）及其他雄激素 | ACTH |
| 髓质 | 肾上腺素，少量去甲肾上腺素 | 交感节前神经 |

所有肾上腺类固醇都由胆固醇经一系列酶（大多为细胞色素P450酶）合成。重要的酶包括**21-羟化酶**（皮质醇和醛固酮合成均需要）和**11β-羟化酶**（合成皮质醇的最后一步）。
:::

醛固酮的独立调控有一个关键的临床后果。由于醛固酮主要受肾素-血管紧张素系统和血钾而非ACTH驱动，垂体原因引起的肾上腺皮质功能减退基本保留了醛固酮，而肾上腺本身的破坏则使醛固酮丧失。

**皮质醇**有很强的**昼夜节律**：醒来后不久达峰，午夜前后降至最低。它在感染、手术或创伤等躯体应激时也会急剧升高。其作用包括：

- 通过刺激糖异生和拮抗胰岛素而升高血糖；
- 分解肌肉蛋白，并使脂肪向躯干重新分布；
- 使血管对儿茶酚胺保持反应性，从而维持血压；
- 抑制炎症和免疫反应；
- 帮助肾脏排泄自由水；
- 影响情绪、睡眠和记忆。

皮质醇也能与盐皮质激素受体结合。肾脏用**11β-羟类固醇脱氢酶2型**保护该受体，这种酶将皮质醇转化为无活性的可的松。当皮质醇水平极高时，例如异位ACTH分泌，该酶被压倒，皮质醇便像醛固酮一样起作用，引起低钾血症和高血压。

**醛固酮**作用于远端肾单位，重吸收钠并分泌钾和氢离子（[[renal/tubular-function]]）。

## 肾上腺皮质功能减退症 {#sec-insufficiency}

::: definition 肾上腺皮质功能减退症 {#def-insufficiency}
**肾上腺皮质功能减退症**是皮质醇生成不足，伴或不伴醛固酮缺乏。

- **原发性肾上腺皮质功能减退症（艾迪生病，Addison's disease）**是肾上腺皮质的衰竭。在英国，约五分之四的病例是自身免疫性的；其他病因包括结核（全球最常见的病因）、肾上腺出血、转移瘤、HIV相关感染以及遗传性疾病。皮质醇和醛固酮均丧失，ACTH升高。
- **继发性肾上腺皮质功能减退症**是垂体疾病引起的ACTH缺乏。**三发性**是下丘脑引起的CRH缺乏。所有病因中最常见的是**糖皮质激素药物**对该轴的抑制。醛固酮得以保留，ACTH低或正常。
:::

皮质醇缺乏的症状模糊且发展缓慢：乏力、虚弱、食欲减退、体重减轻、恶心、腹痛、站立时头晕、嗜盐和情绪低落。原发性疾病另有两个特有表现。**色素沉着**见于皮肤皱褶、瘢痕、牙龈和颊黏膜内侧，原因是ACTH与促黑素细胞激素来自同一前体（阿黑皮素原），而ACTH非常高。深色皮肤者的色素沉着可能较难察觉，此时颊黏膜和掌纹是值得检查的部位。**高钾血症**伴低钠血症反映醛固酮丧失。

许多艾迪生病患者在确诊前看过多位医生，有些人首次就诊即为**肾上腺危象**：低血压、呕吐、意识模糊和虚脱，常由感染诱发。肾上腺危象是急症，治疗不应等待确诊（[[endocrine/endocrine-emergencies]]）。

### 检查

- **上午9时皮质醇**是有用的初筛检查。极低值（例如低于约100 nmol/L）强烈提示肾上腺皮质功能减退；高于约400–450 nmol/L则可能性不大。切点取决于检测方法；对于口服雌激素者结果不可靠，因为雌激素会升高皮质醇结合球蛋白。
- **短程促皮质素（Synacthen）试验**用于确诊。给予合成ACTH（替可克肽，tetracosactide），在30分钟（常加60分钟）测定皮质醇。健康的肾上腺反应为升至某一依检测方法而定的阈值以上，现代检测方法常为约420–450 nmol/L。不能升高即证实肾上腺皮质功能减退。
- **ACTH**用于区分原发性（ACTH高）与继发性（ACTH低或正常）。原发性疾病因缺乏醛固酮而**肾素**升高。**肾上腺自身抗体**（抗21-羟化酶抗体）支持自身免疫性艾迪生病。

在新近发生的继发性肾上腺皮质功能减退中，例如垂体手术后最初数周，肾上腺尚未萎缩，仍能对Synacthen产生反应，因此短程Synacthen试验正常并不能排除。

### 替代治疗与患病期间的用药规则

治疗是补充所缺乏的激素。**氢化可的松**分次给药，早晨剂量较大，以模拟自然节律；成人每日总量通常约15–25 mg（仅为示意；请遵循当地指南）。在原发性疾病中，用**氟氢可的松（fludrocortisone）**补充醛固酮，根据血压、血钾和肾素调整。

人体在患病时通常会使皮质醇输出增加数倍。接受替代治疗的人做不到这一点，因此患者教育至关重要：

- **患病期间的用药规则（sick-day rules）**：发热或需要抗生素的疾病期间，将平时的糖皮质激素剂量加倍，并及早求医。
- 如果呕吐或无法服用片剂，应**紧急肌内注射氢化可的松**（患者及家属会接受相关培训），并紧急就医。
- 随身携带**NHS类固醇急救卡**（2020年推出），并考虑佩戴医疗警示手环。
- 手术、分娩和侵入性操作时给予额外的糖皮质激素覆盖。

::: theorem 外源性糖皮质激素抑制该轴 {#thm-suppression}
糖皮质激素药物对下丘脑和垂体施加负反馈，与皮质醇完全相同。若以高于生理替代量的剂量服用数周，它们会抑制CRH和ACTH，肾上腺皮质因缺乏刺激而萎缩。如果突然停药，或者此人患上急性疾病，肾上腺无法作出反应，可能发生肾上腺危象。停药后该轴的恢复可能需要数月。
:::

2024年欧洲内分泌学会与美国内分泌学会联合发布的糖皮质激素所致肾上腺皮质功能减退指南建议，服用相当于泼尼松龙每日5 mg或以上、持续四周或更长时间的人应被视为有风险。这种风险也适用于大剂量吸入、关节内注射和外用类固醇及其联合使用，尤其是与抑制CYP3A4（例如利托那韦）而升高类固醇水平的药物合用时。这些人需要类固醇急救卡、患病期间用药指导，以及撤药时逐渐减量。

为便于比较剂量，糖皮质激素的近似等效剂量为：氢化可的松20 mg ≈ 泼尼松龙5 mg ≈ 地塞米松0.75 mg。

## 库欣综合征 {#sec-cushing}

::: definition 库欣综合征 {#def-cushing}
**库欣综合征**是长期暴露于过量糖皮质激素所致的临床表现。最常见的病因是**外源性**糖皮质激素药物。**内源性**库欣综合征分为：

- **ACTH依赖性**（约80%）：**库欣病**，即分泌ACTH的垂体腺瘤（占大多数），或其他部位肿瘤（如小细胞肺癌或神经内分泌肿瘤）的**异位ACTH**分泌。
- **ACTH非依赖性**：分泌皮质醇的肾上腺腺瘤或癌，抑制ACTH。
:::

库欣综合征的许多表现在普通人群中也很常见：体重增加、高血压、糖尿病、情绪低落。鉴别价值最大的是蛋白分解引起的表现：**易出现瘀斑**、**宽大的紫纹**（超过1 cm）、**近端肌无力**和**皮肤变薄**，以及多血质面容。其他表现包括向心性肥胖伴满月脸和颈背部脂肪垫、骨质疏松和骨折、感染、月经紊乱、痤疮和多毛，儿童表现为体重增加伴生长减慢。

检查按固定顺序进行，第一条规则是排除外源性类固醇，包括吸入、外用和注射形式。

1. 用以下一两项检查**确认皮质醇过多**：
   - **1 mg过夜地塞米松抑制试验**：晚11时服用地塞米松，次日上午9时测皮质醇。健康人皮质醇被抑制（低于50 nmol/L）；库欣综合征则不被抑制。
   - **午夜唾液皮质醇**：正常的午夜低谷消失。
   - **24小时尿游离皮质醇**：每日总排出量。
2. 测定血浆ACTH以**判断是否依赖ACTH**。ACTH被抑制提示肾上腺来源；ACTH正常或升高提示垂体或异位来源。
3. **定位**：ACTH非依赖性者行肾上腺CT；ACTH依赖性者行垂体MRI，并常需**岩下窦采血**以比较中枢与外周的ACTH。

抑郁、过量饮酒、重度肥胖和控制不佳的糖尿病等情况可轻度激活该轴，产生假阳性结果（"假性库欣"）。因此检查仅用于有提示性表现、多种进行性表现，或出现与年龄不符的异常（如年轻成人的骨质疏松或高血压）的人。

治疗是去除病源：经蝶窦垂体手术、肾上腺切除，或切除异位肿瘤。阻断类固醇合成的药物如美替拉酮（metyrapone）和奥西卓司他（osilodrostat），可在等待手术期间或手术失败时控制皮质醇。手术成功后，剩余的正常轴仍处于抑制状态，因此需要糖皮质激素替代数月。

## 原发性醛固酮增多症 {#sec-aldosteronism}

::: definition 原发性醛固酮增多症 {#def-aldosteronism}
**原发性醛固酮增多症**是不适当地升高且不依赖肾素的醛固酮生成。两大主要病因是**双侧肾上腺增生**和单侧**醛固酮瘤（康恩综合征，Conn's syndrome）**。过多的醛固酮导致钠潴留并引起高血压，抑制肾素，并可引起低钾血症。
:::

在高血压患者中，原发性醛固酮增多症约占5–10%，在难治性高血压中更多。大多数患者血钾正常，因此不应以低钾血症作为检查的前提。它之所以重要，是因为醛固酮对心脏、肾脏和血管的损害超出单纯血压的作用，增加心房颤动、卒中和心力衰竭的风险，并且有特异的治疗方法。

筛查采用**醛固酮/肾素比值（ARR）**。ARR升高且醛固酮不低，提示原发性醛固酮增多症。若干药物会改变肾素和醛固酮，从而影响该比值：盐皮质激素受体拮抗剂和利尿剂使肾素升高（假阴性），β受体阻滞剂使肾素降低（假阳性）。低钾血症会降低醛固酮，检查前应予纠正。筛查阳性通常用抑制试验如**盐水输注试验**确认，原发性醛固酮增多症时醛固酮不能下降。

考虑手术的人随后行肾上腺CT和**肾上腺静脉采血**，比较双侧肾上腺静脉的醛固酮，以确定过量是否来自一侧。仅凭CT不可靠，因为小的无功能腺瘤很常见。单侧病变采用**腹腔镜肾上腺切除术**治疗，常能纠正低钾血症并改善或治愈高血压。双侧病变用**盐皮质激素受体拮抗剂**治疗，如螺内酯（spironolactone，男性乳房发育是常见不良反应）或依普利酮（eplerenone）。

筛查对象正在变化。英国的实践传统上针对难治性高血压、低钾血症、年轻时发病的高血压、肾上腺偶发瘤，或无其他原因的心房颤动患者。2025年美国内分泌学会指南建议对所有高血压患者进行筛查，这是一项有条件的推荐，反映出这一诊断被漏诊的频繁程度（[[cardiovascular/hypertension]]）。

## 嗜铬细胞瘤 {#sec-phaeo}

**嗜铬细胞瘤**是肾上腺髓质分泌儿茶酚胺的肿瘤；起源于肾上腺外交感或副交感神经节的类似肿瘤称为**副神经节瘤**。典型表现为阵发性：头痛、出汗和心悸发作，高血压可为持续性或阵发性。现在许多肿瘤是在影像检查中偶然发现的。

筛查试验是**血浆游离甲氧基肾上腺素类物质**（或尿分馏甲氧基肾上腺素类物质）。甲氧基肾上腺素类物质在肿瘤内由儿茶酚胺持续生成，因此比间歇释放的儿茶酚胺更可靠。影像检查（CT或MRI，有时用功能显像）应在生化检查阳性之后进行，而不是相反。

多达约40%的嗜铬细胞瘤和副神经节瘤与胚系突变有关，例如**RET**（MEN2）、**VHL**（希佩尔-林道病）、**NF1**（1型神经纤维瘤病）或**SDH**基因。所有这类肿瘤患者都应接受基因检测。

治疗是在**α受体阻滞**（酚苄明或多沙唑嗪）一至两周后手术切除，同时充分补液和摄盐以使收缩的血容量重新扩张。之后可加用β受体阻滞剂控制心动过速。

::: warning 嗜铬细胞瘤绝不能先用β受体阻滞剂
嗜铬细胞瘤患者单独使用β受体阻滞剂，会阻断骨骼肌中β2介导的血管舒张，使α介导的血管收缩失去对抗。血压可能急剧而危险地升高。必须始终先用α受体阻滞剂。出于同样的理由，任何疑似MEN2的人在手术前都必须排除嗜铬细胞瘤。
:::

## 先天性肾上腺皮质增生症与偶然发现的肾上腺肿物 {#sec-cah}

**先天性肾上腺皮质增生症（CAH）**是一组常染色体隐性遗传的皮质醇合成缺陷。约95%由**21-羟化酶缺乏**引起。低皮质醇解除了反馈，ACTH升高，肾上腺被驱动大量合成阻断点之前的前体，这些前体转而生成雄激素。在严重的失盐型中，醛固酮也缺乏，受累新生儿可在生后最初几周出现危及生命的失盐危象。经典型女婴出生时可有外生殖器男性化。诊断标志物是**17-羟孕酮**升高。较轻的非经典型在较晚时以多毛和月经不规律为表现，需与多囊卵巢综合征鉴别（[[endocrine/reproductive-endocrinology]]）。

**肾上腺偶发瘤**是在因其他原因所做影像检查中发现的肾上腺肿物。在腹部CT中检出率为百分之几，并随年龄增加。2023年欧洲内分泌学会与欧洲肾上腺肿瘤研究网络共同制定的指南提出两个问题：

1. **是否为恶性？** 平扫CT上密度均匀、衰减值为10 HU或更低的肿物富含脂质，几乎可以肯定是良性腺瘤，不需要进一步影像检查。较大或性质不确定的肿物需要进一步影像检查或专科评估。
2. **是否分泌激素？** 每个人都应做1 mg过夜地塞米松抑制试验。服用地塞米松后皮质醇高于50 nmol/L提示**轻度自主性皮质醇分泌**，它与高血压、糖尿病和心血管风险相关。有高血压或低钾血症者需检查原发性醛固酮增多症；除非肿物明确为富含脂质的腺瘤，否则应测定甲氧基肾上腺素类物质。

::: example 停用类固醇三周后虚脱 {#ex-crisis}
一位67岁风湿性多肌痛女性服用泼尼松龙每日15 mg五个月后，因体重增加而突然停药。三周后她出现腹泻和呕吐，意识模糊，血压78/40 mmHg。血钠126 mmol/L，血钾4.4 mmol/L，血糖3.4 mmol/L。解释这一表现及即刻处理。
::: solution
**机制。** 五个月泼尼松龙剂量为生理等效量的三倍（泼尼松龙15 mg ≈ 氢化可的松60 mg），抑制了她的轴（[[#thm-suppression]]）。她的肾上腺已经萎缩。停药后又患胃肠炎，她无法产生皮质醇反应。

**表现符合继发性肾上腺皮质功能减退。** 低血压反映血管对儿茶酚胺的反应性丧失和容量丢失。低钠血症反映自由水排泄受损。低血糖反映失去皮质醇对糖异生的支持。血钾正常，因为醛固酮得以保留。

**处理**按肾上腺危象进行，不等待结果：若不耽误治疗，抽血查皮质醇，**立即静脉或肌内注射氢化可的松100 mg**，然后继续氢化可的松（通常24小时内200 mg），快速静脉输注0.9%氯化钠，用葡萄糖纠正低血糖，并治疗诱因。此处剂量为典型成人方案；请遵循当地指南。恢复后，她需要糖皮质激素替代并缓慢减量、患病期间用药规则、类固醇急救卡，以及之后对轴恢复情况的检测。她原有的疾病也需要重新评估。
:::
:::

::: example 伴低血钾的难治性高血压 {#ex-conn}
一位44岁非洲裔黑人男性，在服用氨氯地平、雷米普利和吲达帕胺的情况下血压仍为168/102 mmHg。血钾3.2 mmol/L。醛固酮640 pmol/L，直接肾素浓度2.0 mU/L。实验室ARR的示意性筛查阈值为70 pmol/mU。计算该比值并制定下一步计划。
::: solution
$$
\text{ARR} = \frac{640}{2.0} = 320 \text{ pmol/mU}，
$$

远高于示意性阈值70。肾素被抑制而醛固酮升高：这是原发性醛固酮增多症的模式。

**审慎解读。** 雷米普利和吲达帕胺预期会升高肾素，从而降低比值，因此在服用它们的情况下比值仍高，更有说服力。低钾血症会降低醛固酮，因此若结果处于临界，应纠正后复查。

**下一步**：转诊专科；确认试验（例如盐水输注）；肾上腺CT；如果他愿意接受手术，行肾上腺静脉采血以寻找单侧来源。单侧者行腹腔镜肾上腺切除术；双侧者用盐皮质激素受体拮抗剂。年轻成人对三种药物仍难以控制的高血压，本身就是寻找继发性病因的理由。
:::
:::

::: example 低患病率人群中的筛查 {#ex-screening}
某门诊提议对所有合并肥胖的2型糖尿病患者做1 mg过夜地塞米松抑制试验，以发现库欣综合征。假设该人群患病率为1%，检查灵敏度95%，特异度85%（示意性数值；肥胖和控制不佳的糖尿病会增加假阳性率）。阳性预测值是多少？
::: solution
设有10,000人。患病率1%时，100人患库欣综合征，9,900人未患。

- 真阳性：$0.95 \times 100 = 95$。
- 假阳性：$(1 - 0.85) \times 9{,}900 = 0.15 \times 9{,}900 = 1{,}485$。

$$
\text{PPV} = \frac{95}{95 + 1{,}485} = \frac{95}{1{,}580} \approx 0.060。
$$

阳性结果中只有约**6%**是真阳性。每发现一例真病例，就有15人以上需要进一步检查。这就是指南建议只检查有鉴别性表现者的原因，因为这类人群的验前概率更高。可在下图中探索患病率如何改变预测值。
:::

::: example 偶然发现的肾上腺肿物 {#ex-incidentaloma}
一位58岁女性因肾结石做CT检查，发现左肾上腺一个2.8 cm、密度均匀、6 HU的肿物。她患有高血压和2型糖尿病。需要做哪些检查？
::: solution
**恶性问题。** 小于4 cm、密度均匀、衰减值≤10 HU的肿物是富含脂质的良性腺瘤。就此问题而言不需要进一步影像检查。

**激素分泌。**
1. **1 mg过夜地塞米松抑制试验**。若皮质醇高于50 nmol/L，她存在轻度自主性皮质醇分泌（或更重），可能参与其高血压和糖尿病；随后需进一步评估，并讨论肾上腺切除还是对合并症进行药物治疗。
2. 由于她有高血压，应查**醛固酮/肾素比值**。
3. 对衰减值≤10 HU的肿物，不常规要求测定甲氧基肾上腺素类物质，因为嗜铬细胞瘤几乎从不富含脂质，尽管许多中心仍会检测。

应清楚告诉她发现了什么以及为何要做这些检查，因为偶然发现会引起可以理解的焦虑。
:::
:::

::: quiz
一位自身免疫性艾迪生病女性有色素沉着和高钾血症。一位垂体肿瘤伴ACTH缺乏的男性两者都没有。差异如何解释？
- [ ] 该男性的ACTH高于该女性。
- [x] 原发性疾病中ACTH高且醛固酮丧失；继发性疾病中ACTH低且醛固酮保留。
- [ ] 高钾血症由皮质醇缺乏引起。
- [ ] 色素沉着由低醛固酮引起。
::: solution
色素沉着来自高ACTH（及相关的黑皮质素肽），只发生在原发性疾病中。高钾血症来自醛固酮缺乏；醛固酮依赖肾素-血管紧张素系统，在ACTH缺乏时得以保留。
:::
:::

::: history
1855年，伦敦盖伊医院的**托马斯·艾迪生（Thomas Addison）**描述了一种以贫血样虚弱、心脏无力、胃肠不适和皮肤变色为特征、与肾上腺病变相关的致命疾病。次年，**夏尔-爱德华·布朗-塞卡（Charles-Édouard Brown-Séquard）**证明切除双侧肾上腺对动物是致命的。20世纪30年代，**爱德华·肯德尔（Edward Kendall）**和**塔德乌什·赖希施泰因（Tadeus Reichstein）**分离出肾上腺皮质类固醇；1948年，梅奥诊所的**菲利普·亨奇（Philip Hench）**给一位类风湿关节炎女性使用可的松，效果显著；亨奇、肯德尔和赖希施泰因分享了1950年诺贝尔奖。1955年，**杰罗姆·康恩（Jerome Conn）**描述了一位患高血压、肌无力和低钾血症的女性的原发性醛固酮增多症，她在切除一个肾上腺肿瘤后痊愈。
:::

## 后续内容

肾上腺危象和嗜铬细胞瘤危象见[[endocrine/endocrine-emergencies]]。库欣病在[[endocrine/hypothalamus-pituitary]]中介绍。继发性高血压的背景见[[cardiovascular/hypertension]]，治疗性糖皮质激素的不良反应见[[pharmacology/adverse-reactions]]。

::: summary
- 皮质合成醛固酮（受肾素-血管紧张素和血钾调控）、皮质醇和雄激素（受ACTH调控）；髓质合成肾上腺素。
- 原发性肾上腺皮质功能减退引起色素沉着、高钾血症和ACTH升高；继发性疾病保留醛固酮，ACTH低。
- 糖皮质激素药物是肾上腺皮质功能减退最常见的病因；有风险者需要类固醇急救卡、患病期间用药规则和逐渐减量。
- 用上午9时皮质醇和短程Synacthen试验诊断肾上腺皮质功能减退；疑似肾上腺危象绝不延误治疗。
- 疑似库欣综合征时首先排除外源性类固醇；确认皮质醇过多，测定ACTH，然后定位。
- 原发性醛固酮增多症常见，常不伴低钾，用醛固酮/肾素比值筛查；肾上腺静脉采血可发现单侧病变。
- 嗜铬细胞瘤用甲氧基肾上腺素类物质诊断；先α阻滞再β阻滞；应提供基因检测。
- 对每个肾上腺偶发瘤都要评估恶性（平扫CT衰减值）和激素过多（地塞米松试验及其他必要检查）。
:::

## 习题

::: exercise 原发性还是继发性 {level=1}
某人上午9时皮质醇低。列出三项提示原发性而非继发性肾上腺皮质功能减退的发现。
::: solution
以下任意三项：血浆ACTH升高；色素沉着；高钾血症；肾素升高（醛固酮低）；21-羟化酶抗体阳性；其他自身免疫病，如白癜风或1型糖尿病。继发性疾病ACTH低或正常、无色素沉着、醛固酮保留。
:::
:::

::: exercise 类固醇等效剂量 {level=1 check="7.5*4"}
按近似等效关系氢化可的松20 mg ≈ 泼尼松龙5 mg，与每日泼尼松龙7.5 mg等效的氢化可的松剂量是多少mg？
::: solution
氢化可的松的效价是泼尼松龙的四分之一，因此乘以4：$7.5 \times 4 = 30$ mg氢化可的松。
:::
:::

::: exercise 谁需要急救卡 {level=1}
指出下列哪些人应被视为有糖皮质激素所致肾上腺皮质功能减退的风险：(a) 因哮喘服用泼尼松龙30 mg共5天；(b) 泼尼松龙每日10 mg共6个月；(c) 大剂量吸入氟替卡松并同时服用利托那韦。
::: solution
(a) 通常不是：少于三至四周的短疗程很少引起有临床意义的抑制，尽管多次疗程会累积。(b) 是：泼尼松龙每日超过5 mg，持续超过四周。(c) 是：利托那韦抑制CYP3A4，使吸入氟替卡松的全身暴露大大增加；已有医源性库欣综合征和肾上腺抑制的充分报道。
:::
:::

::: exercise 比值 {level=2 check="480/1.5"}
计算醛固酮480 pmol/L、直接肾素浓度1.5 mU/L时的醛固酮/肾素比值，单位pmol/mU。
::: solution
$480 / 1.5 = 320$ pmol/mU。肾素被抑制而醛固酮不低，按大多数实验室阈值，这是原发性醛固酮增多症筛查阳性。
:::

::: exercise 解读地塞米松试验 {level=2}
晚11时服用1 mg地塞米松后，一位女性次日上午9时皮质醇为290 nmol/L。她服用复方口服避孕药并患有抑郁症。讨论如何解读。
::: solution
健康人服用1 mg地塞米松后皮质醇降至50 nmol/L以下，因此这是抑制失败。此处有两个因素可导致假阳性。口服雌激素升高皮质醇结合球蛋白，从而升高总皮质醇，因此理想情况下应在检查前停用避孕药约六周，或改用受结合影响较小的检查（午夜唾液皮质醇、24小时尿游离皮质醇）。抑郁可轻度激活该轴。不应将这一结果视为库欣综合征的证据；需要在专科中复查或采用其他检查，并根据她有多少鉴别性临床表现来指导。
:::
:::

::: exercise 阳性预测值 {level=2 check="round(100*(0.95*0.05)/(0.95*0.05+0.15*0.95))"}
对一个患病率为5%、灵敏度95%、特异度85%的人群重复[[#ex-screening]]中的计算。以百分比给出阳性预测值，四舍五入到整数。
::: solution
每人的真阳性：$0.95 \times 0.05 = 0.0475$。假阳性：$0.15 \times 0.95 = 0.1425$。PPV $= 0.0475/(0.0475 + 0.1425) = 0.0475/0.19 = 0.25$，即**25%**。验前概率从1%升至5%，PPV从约6%升至25%：选择检查对象与检查本身同样重要。
:::
:::

::: exercise 阵发性发作 {level=3}
一位31岁女性有搏动性头痛、出汗和心悸的发作。一次发作时血压182/110 mmHg。她的全科医生已开始用普萘洛尔治疗"伴心悸的焦虑"。讨论鉴别诊断、当前治疗的危险以及检查计划。
::: hint
想一想α肾上腺素能刺激失去对抗时对血压有何影响。
:::
::: solution
**鉴别诊断**：嗜铬细胞瘤或副神经节瘤；惊恐障碍；甲状腺毒症；药物使用（可卡因、苯丙胺类）或戒断；低血糖；较少见的类癌综合征或绝经相关潮热（31岁时可能性小）。

**危险**：如果这是嗜铬细胞瘤，在未预先α阻滞的情况下给予非选择性β受体阻滞剂，会消除β2介导的血管舒张，可诱发严重的高血压危象。应紧急重新评估普萘洛尔的使用。

**计划**：血浆游离甲氧基肾上腺素类物质（或24小时尿甲氧基肾上腺素类物质）、甲状腺功能，以及详细的用药史。如果甲氧基肾上腺素类物质明显升高，行腹部和盆腔断层影像以定位肿瘤；然后转诊专科团队进行α阻滞、手术和基因检测。如果甲氧基肾上腺素类物质正常，嗜铬细胞瘤的可能性极小，可以考虑其他诊断。
:::
:::

::: exercise 设计类固醇安全流程 {level=3}
某医院发现数名长期服用泼尼松龙的人在术后发生了肾上腺危象。请设计一个预防流程，并用轴抑制的生理学解释每一步。
::: solution
好的答案应涵盖每个风险节点的识别、教育和行动：

1. **识别**：从处方记录中识别有风险的人：泼尼松龙等效剂量每日5 mg或以上、持续四周或以上，大剂量吸入或其他途径，以及合用CYP3A4抑制剂等相互作用药物。依据：这些剂量会抑制CRH和ACTH（[[#thm-suppression]]）。
2. **标记**：在电子病历中标记，并发放**类固醇急救卡**。
3. **教育**：患病期间用药规则，以及绝不突然停用类固醇。
4. **围手术期方案**：在麻醉诱导时和术后最初几天给予额外的糖皮质激素覆盖，剂量按手术大小调整，因为被抑制的肾上腺无法产生正常的手术应激反应。
5. **及时识别**：这类患者术后出现不明原因的低血压、呕吐、低钠血症或低血糖时，立即给予氢化可的松。
6. **撤药**：停用长期类固醇时缓慢减量，并在适当时检测轴的恢复。
7. **审核**：审核执行情况和不良事件。
:::
