# Quant Trading Atlas — Chinese translation guide (简体中文)

Not started. Do not add `content/zh/` lessons until an English lesson has passed
`php tools/check.php` with no depth warnings.

When translation begins, follow the file layout in
`../economics/tools/TRANSLATION_GUIDE_ZH.md`: a course overlay of translatable fields only, and
a lesson with the same blocks, anchors, numbers and caveats as the English.

Render the education-only notice as **仅供教育学习，不构成投资或交易建议**.

Keep Latin tickers and library ids (W01, O03, WF04). Suggested terms: 简单收益率, 对数收益率,
夏普比率, 最大回撤, 胜率, 盈亏比, 波动率目标, 风险平价, 移动平均, 布林带, 相对强弱指标,
时间序列动量, 横截面动量, 均值回归, 配对交易, 走步验证 (walk-forward), 清洗 (purge),
禁运期 (embargo), 回测过拟合. Do not strengthen a reported backtest into a recommendation.
