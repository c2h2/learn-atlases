两个价格可以一起上涨一个月，同时留下一个越走越远、再也不回来的价差。**配对交易**构造试图把那个价差孤立出来：因为公共成分已被减掉，它可能比两个价格中的任何一个都更稳定。这个减法是一个估计。对数价格比率使用的是"按一比一、在对数里"的估计。回归对冲使用的是一个对数价格对另一个的回归斜率。一个很大的相关系数既不能为这两种估计背书，也不是协整。

协整，按恩格尔与格兰杰（Engle and Granger，1987）的含义，是一个关于单整阶数的论断。它问的是：是否存在一个固定的对冲，使残差本身不像一个单位根序列。算一个相关系数，或打印一个$z$分数，都不回答那个问题。本章陈述这个两步思路及其假设，在编造的价格上算一个滚动$z$分数与一个对冲比率，不报告单位根统计量，也不报告$p$值。发明其中任何一个，都比重跑之前把检验搁下更糟。

这里没有任何东西推荐一对名字、一个$z$的门槛、或把库内条目KO/PEP与EWA/EWC当作值得持有的账簿。那些标签指认的是行。行是别人报告的实验。

## 对数比率及其$z$分数

设$P^{(1)}_t$与$P^{(2)}_t$为两个正的价格，记$x_t = \ln P^{(1)}_t$、$y_t = \ln P^{(2)}_t$。**对数比率**为$q_t = x_t - y_t$，即$P^{(1)}_t/P^{(2)}_t$的对数。对数里的一比一对冲是一个建模选择。它说的是：第二个价格的某个百分比变动，要用第一个价格同量的百分比变动来抵消。如果你想要的抵消不是一比一，对数比率照样会动，因为对冲错了，而不只是因为残差冲击到来。

:::definition 滚动对数比率$z$分数 {#def-z}
固定窗口长度$n \ge 2$。在日期$t \ge n-1$，取对数比率$q_{t-n+1},\ldots,q_t$。设$\mu_t$为其算术平均，$\sigma_t$为以$n-1$为分母的样本标准差，并假设其为正。**滚动$z$分数**为
$$
z_t = \frac{q_t - \mu_t}{\sigma_t}.
$$
窗口止于$t$，所以当前对数比率同时进入分子与两个估计。由$z_t$选定的头寸只挣$t$之后发生的东西。改用总体分母$n$代替$n-1$，是另一个分数。
:::

读数$2$的意思是"高出这个窗口均值两个样本标准差"。它不是说明天价差会趴在$\mu_t$上。被检验的那个点也在拉动均值与宽度，所以短窗口让单根收盘价无法看起来任意极端。这与[[reversion/rsi-and-bands]]里那个上界是同一套几何，只是从价格窗口搬到了价差窗口。这个上界不是平稳性检验的替身。

## 对冲比率是一个斜率

$x$对$y$的带截距普通最小二乘，选择$\alpha$与$\beta$以最小化残差$x_u - \alpha - \beta y_u$在写明窗口上的平方和。斜率$\beta$就是对数里的**对冲比率**：$y$每变动一单位，$x$的拟合变动。残差$e_u = x_u - \alpha - \beta y_u$就是这个对冲蕴含的价差。单回归元的公式推导在[[statistics/regression-on-a-signal]]。这里回归元是一个对数价格，不是更早定日期的信号，而残差是我们之后可能要标准化的对象。定日期仍然要紧：在止于$t$的窗口上拟合出的斜率，在$t$已知。它不挣$x_t$也不挣$y_t$。

:::definition 滚动对数价格对冲 {#def-hedge}
在以$t$结尾的$n \ge 2$个日期的窗口上，**滚动对冲比率**$\hat\beta_t$是$\ln P^{(1)}$对$\ln P^{(2)}$的最小二乘斜率，带截距$\hat\alpha_t$。窗口最后一个日期上的残差价差为
$$
e_t = \ln P^{(1)}_t - \hat\alpha_t - \hat\beta_t \ln P^{(2)}_t.
$$
窗口是拖尾的：$t$之后的任何价格都不进入$\hat\alpha_t$或$\hat\beta_t$。更晚的窗口可能、而且通常会给出一条不同的斜率。残差以对数点计。只有当权重映射说明各持有两价格的多少单位之后，它才成为收益率。
:::

下面的编造价格不是一对乔装的真股票。只在本例之内把它们称为A与B。

$$
\begin{align*}
P^{(A)} &= (100,\ 104,\ 99,\ 106,\ 110,\ 103,\ 112,\ 116),\\
P^{(B)} &= (50,\ 51,\ 50,\ 52,\ 53,\ 52,\ 54,\ 55),
\end{align*}
$$

日期为$0$到$7$。在全部八个日期上，两个价格水平的相关系数为$0.9762$，七个对数价格变动的相关系数为$0.9896$，都是四位小数。这些数很大。它们正是本章要说的那种诱惑。

:::example 五日的对冲比率 {#ex-hedge}
只用日期$0$到$4$，把$\ln P^{(A)}$对$\ln P^{(B)}$做带截距的回归。把斜率与截距报告到四位小数。
:::solution
在该窗口上取完整精度的自然对数，得中心化交叉乘积和
$$
\sum (y_u - \bar y)(x_u - \bar x) = 0.004328622, \qquad \sum (y_u - \bar y)^2 = 0.002574180,
$$
其中$x = \ln P^{(A)}$、$y = \ln P^{(B)}$。斜率是这两个和之比，
$$
\hat\beta = 0.004328622 / 0.002574180 = 1.6816
$$
（四位小数），而配合两个均值的截距为$\hat\alpha = -1.9760$（四位小数）。用文字说：在这个窗口、这条直线之内，B的对数价格每变动一，A的被拟合对数价格变动约$1.6816$对数点。以六位小数显示的对数，A为$4.605170$、$4.644391$、$4.595120$、$4.663439$、$4.700480$；B为$3.912023$、$3.931826$、$3.912023$、$3.951244$、$3.970292$。用舍入后的对数重建这两个和，斜率在小数点第四位之前移动不到$0.0001$；引用的斜率用的是完整精度。这个斜率不是一个持有建议，它是五个编造点上一个平方和的最小值点。
:::
:::

:::example 同日的$z$分数，与下一步 {#ex-z}
在同样五个对数比率上，用样本分母$n-1 = 4$，按[[#def-z]]计算$z_4$。再设一条规则：$z_t > 1$时做空一单位对数比率，$z_t < -1$时做多一单位，其余时候空仓。这一单位挣的是对数比率的下一个变动，不是货币收益率。这条规则从日期$4$到日期$5$挣什么？
:::solution
五个对数比率$q_t = \ln P^{(A)}_t - \ln P^{(B)}_t$，六位小数为$0.693147$、$0.712565$、$0.683097$、$0.712195$、$0.730188$。均值为$\mu_4 = 0.706239$。样本标准差为$\sigma_4 = 0.018412$。最后一个偏差为$0.730188 - 0.706239 = 0.023949$，所以
$$
z_4 = 0.023949 / 0.018412 = 1.3008
$$
（四位小数）。因为$z_4 > 1$，规则做空一单位对数比率。下一个对数比率在日期$5$，为$0.683485$，所以变动为$0.683485 - 0.730188 = -0.046703$。空头单位挣得
$$
-1 \times (-0.046703) = 0.046703
$$
对数点。这是$q$的变动，不是一本有资金账户的利润。有资金的账户要说明：$q$的一单位如何映射成A与B的权重、交易它们要花多少钱。那张映射在[[portfolio/from-signal-to-weight]]。在一条编造路径上的一次有利对数点变动，不是"$z$高于$1$是任何人都该用的入场"的证据。
:::
:::

:::example 窗口滚动，斜率就动 {#ex-roll}
在日期$1$到$5$上重复[[#ex-hedge]]的回归。把$\hat\beta$报告到四位小数，并说出斜率的变化是什么、又不是什么。
:::solution
在新窗口上同样的正则方程给出$\hat\beta = 1.5927$，截距$-1.6329$，都是四位小数。斜率移动了$1.6816 - 1.5927 = 0.0889$。两个窗口各有五个点、彼此重叠，而只滚掉一个日期就足以让第二位小数动起来。这一移动不是单位根$p$值，不是协整检验，也不是A对B的裁决。它是证据，证明"那个"对冲比率从来就不是这两条序列的、与窗口无关的性质。一条在日期$4$之后冻结$1.6816$的规则，与一条重新拟合的规则，是不同的规则。[[#ex-z]]里对数比率的$z$分数根本没用这条斜率。比率与回归不是同一个价差的两个视角，它们是两个价差。
:::
:::

在日期$1$到$5$上，对数比率的$z$分数按同一定义是$-1.0148$。[[#ex-z]]的门槛规则会做多一单位比率，而$q$的下一个变动是$+0.046030$，于是这个多头单位会挣得$+0.046030$对数点。在八个编造收盘价、相关系数接近$1$的路径上连赢两步，仍然是一个玩具。样本内第三个合格日期，即日期$6$，$z_6 = 0.9317$，处在无交易区内，所以规则带着空仓走完最后一步。空仓那一步是规则的一部分。因为"什么也没发生"就把它扔掉，会把任何后来的平均值推向$|z|$较大的那些日期。

图中的第二个序列，构造为第一个序列的20加2倍、再加一个振幅为3的正弦。所以对冲比率在2处有一个家，那里的价差就是平移了20的那个正弦。比率为1时，价差里留下一个趋势。在一个生来就该平坦的序列上看到平坦，不是发现了什么优势。

## 相关不是协整

恩格尔与格兰杰（1987）为成对序列提出了一个两步残差检验。第一步：把一个序列对另一个回归，规格含截距时就带截距，留下残差。第二步：对这个残差做单位根检验，并使用考虑到"残差是估计出来的、不是观察到的"这一点的临界值。在写明的显著性水平下、并在诸假设成立时，拒绝单位根原假设，才能让你在那个样本上称这对序列为协整。未能拒绝，不是存在单位根的证据。我们对编造的价格两步都不做，对库内的配对也两步都不做。本章没有$p$值。

让这套程序"说的等于它的含义"的那些假设，列出来容易，跳过更容易。

- 每个输入序列都是一阶单整的：水平里有单位根，差分里没有。两条本来就平稳的序列，可以因为一个琐碎的理由得到平稳的残差，而通常的残差临界值是错的参照。
- 协整向量若存在，在样本内是固定的。一个会跳的对冲——[[reversion/when-reversion-fails]]的主题——是这个假设的断裂，不是一点估计误差。
- 在一个配对里，有意思的那个向量在相差一个缩放的意义上本质上是唯一的。把第一个序列的系数归一化为$1$是一个缩放选择；这就是为什么$\beta$只在该归一化之后才成为"那个"对冲比率。
- 残差检验使用恩格尔–格兰杰临界值，或某套同样为估计残差推导出来的临界值。把一个刚刚拟合出的残差，当作一条预先指定的序列，去查教科书上的迪基–富勒（Dickey–Fuller）$p$值，那不是该检验。
- 一个结果——如果我们算出一个——是关于那个样本与那个规格的。它不承诺残差在最后一个日期之后仍保持稳定的均值。

水平的、变动的、或单个$z_t$的相关系数，都不在那个清单里。

:::proposition 变动的完美相关未必回归 {#prop-corr}
设$\Delta x_t$为一个固定的实数序列，样本方差为正，并令$\Delta y_t = \Delta x_t + c$，$c \neq 0$为常数。由$x_0 = y_0 = 0$出发、把变动累加，构造对数价格。则$(\Delta x, \Delta y)$的样本相关系数等于$1$，而单位对冲价差$y_t - x_t$等于$c\, t$。那个价差是一个算术趋势，它不回到任何固定均值。进一步，没有任何常数$\beta$能使$y_t - \beta x_t$在样本内每一点上为常数，因为那将迫使$\Delta x$本身为常数。
:::

:::proof
把变动中心化。$\Delta y$的样本均值是$\Delta x$的样本均值加$c$，所以
$$
\Delta y_t - \overline{\Delta y} = \Delta x_t - \overline{\Delta x}.
$$
中心化后的两个向量完全相同。只要$\Delta x$不是常数，样本相关系数就恰为$1$。

从共同的起点$0$累加，得$y_t = x_t + c\, t$。对冲为$1$的价差是$c\, t$：每一步移动$c$，不再回来。

设某个固定的$\beta$使$y_t - \beta x_t$在整个样本上为常数。则一阶差分应当消失：
$$
\Delta y_t - \beta \Delta x_t = (1-\beta)\Delta x_t + c = 0
$$
对每个$t$成立，于是$\Delta x_t = -c/(1-\beta)$对每个$t$成立，是一个常数。若$\beta = 1$，同一行给出$c = 0$，而这被排除了。这与$\Delta x$非常数矛盾。所以没有固定对冲能把这条路径压成常数。这段论证是对一个有限序列的代数。它不是单位根检验，也不产出$p$值。
:::

:::example 命题的数字 {#ex-corr}
取$c = 0.004$与
$$
\Delta x = (0.010,\ -0.020,\ 0.015,\ -0.005,\ 0.020,\ -0.010,\ 0.008).
$$
确认那个相关论断与期末的单位对冲价差。
:::solution
每个元素加$0.004$得$\Delta y$。两个中心化序列逐元素相同，所以样本相关系数为$1$，正如[[#prop-corr]]所断言。共七步，所以单位对冲价差终于$7 \times 0.004 = 0.028$。它经过$0.004, 0.008, \ldots, 0.028$，再没有向$0$回来过。止步于"相关系数等于1，所以价差均值回归"的研究者，跳过的正是价差。价差才是那个必须回归的对象，而这个构造里它恰好相反。我们仍然不为这个残差引用迪基–富勒统计量。单位对冲的残差是一条直线，光这一点，就足够拒绝把"均值回归"这个词用在那个对冲上。
:::
:::

A/B价格上的高相关，被刻意放在这条命题旁边。水平相关$0.9762$、对数变动相关$0.9896$都很大，而窗口上滚掉一个日期，对冲比率仍从$1.6816$动到了$1.5927$。我们不得出"A与B协整"的结论，也不得出"以正式检验的口径它们不协整"的结论。我们得出的结论是：相关系数是错误的对象，而一个我们没做的检验，没有$p$值可报告。

:::warning 不要借临界值
即便在一条适合做单位根回归的序列上，由估计的对冲得到的残差也不是一条原始序列。原假设的分布会移动，因为$\hat\beta$正是为了让残差变小才被挑出来的。对这个残差用一张普通的迪基–富勒表，再把结果当恩格尔–格兰杰结果来读，是第二个错误叠在第一个错误上。为了"演示"而报告一个编造的$p$值，就是在重复这个错误。[[statistics/stationarity-and-regimes]]把单位根思想保持在模型假设的层面。本章不往编造的残差上添一个假的检验统计量。
:::

## 两个库内条目

下面的数字是2026年读入时quants.md上那个QuantJourney示例（Apache-2.0）所报告的数字。本图谱没有重跑这些回测。被报告的夏普比率是他们的数字。我们不知道他们的无风险收益率与年化方式，也不去"修正"某一行报告年化复合增长率为正、报告夏普比率为负的条目。

W13，"Pairs Ratio Z Score"：被描述为KO对PEP的市场中性账簿，使用对数比率$z$分数，26年的日K线。库内报告总收益率$+48.8\%$、年化复合增长率$+1.54\%$、夏普比率$-0.05$、最大回撤$-23.6\%$、胜率$49.1\%$、盈亏比$1.14$。KO与PEP是那一行里的名字。点名它们，是我们指向那一行的方式。它不是交易那对股票的建议，也不是"它们的对数比率协整"的发现。库内那一行没有报告单位根$p$值，我们也没有。

W14，"Pairs Hedge Ratio"：被描述为EWA对EWC的市场中性账簿，使用滚动普通最小二乘对冲比率价差，同样是26年的日K线。库内报告总收益率$+12.4\%$、年化复合增长率$+0.45\%$、夏普比率$-0.30$、最大回撤$-14.3\%$、胜率$50.2\%$、盈亏比$1.06$。EWA与EWC是给那一行用的标签，不是本章背书的国别基金交易。那一行说对冲是一个滚动回归，但没有公布窗口，我们不替它发明。我们那个五日斜率是一个课堂计算，好让$\hat\beta$是一个你能徒手除出来的数。它不是对W14的重建。

两行都报告为正的年化复合增长率、为负的夏普比率。这种组合是可能的，比如夏普比率并不是"同一条净值路径的年化增长除以它的波动率"——例如一个为正的融资利率进入了超额收益，或两个统计量是在不同序列上算的。我们不挑一个解释、再把它当事实。我们也不把被报告为负的夏普比率翻转成对面那本账。亏损，或小赚旁边的负夏普比率，是关于那个规格在那个样本里的证据。配对账簿的对面是另一个规格：空头边变多头边，成本不会免费变号，对冲比率也不会因为你改了主意就变成它自己的倒数。

W13与W14还是两种不同的减法，这正是同时给出[[#def-z]]与[[#def-hedge]]的用意。一个标准化的是对数比率，另一个标准化的是拟合斜率的残差。在我们的玩具上，那两个不是同一个价差，而斜率也没有站住不动。库内报告的两个年化复合增长率$+1.54\%$与$+0.45\%$也各不相同，而样本被描述为同样长。即便如此，你也不能把这一差距只交给"比率对对冲"：名字不同，窗口未公布，两行我们都没有重跑。实现方式是结果的一部分——上一章那两条RSI条目已经如此。

盖特夫、戈茨曼与鲁文霍斯特（Gatev, Goetzmann and Rouwenhorst，2006）规定了一个基于距离的配对规则，并且重要的是，把第一笔交易推迟到配对窗口之后，使"选配对"这个动作不去偷看那笔配对事后被记功的收益率。一个包含当前价格的$z$分数，如[[#def-z]]所做的，是对该窗口的合法描述。若同一个价格还被当作这个$z$分数本可以预见的成交来对待，它就不合法了。2006年的延迟，是针对配对选择步骤中那类泄漏的设计选择。我们的玩具没有配对选择步骤。八个价格是提前写定的，这就是它们确认不了任何配对溢价的原因。

:::quiz
哪句话是一个恩格尔–格兰杰协整结果？
- [ ] 两个对数价格变动的相关系数是$0.99$。
- [ ] 滚动$z$分数在窗口最后一天打印出$1.30$。
- [x] 都不是本章计算的任何量。没有计算任何残差单位根统计量。
- [ ] 五个日期上的最小二乘斜率等于$1.6816$。
:::solution
相关系数、$z$分数、对冲比率，全都不需要单位根检验即可定义。[[#prop-corr]]给出了一个变动相关系数恰为$1$、而单位对冲价差是一条直线趋势的例子。恩格尔与格兰杰的第二步没有做，所以没有$p$值可引用，也没有协整结果可宣布。
:::
:::

:::quiz
[[#def-z]]里的$z$分数用哪个分母、哪些日期？
- [ ] 总体分母$n$，窗口排除当前对数比率，好让分数能更极端。
- [x] 样本分母$n-1$，窗口止于$t$，因此包含$q_t$。
- [ ] 哪个分母能让$|z_t|$超过$2$就用哪个，否则规则永不交易。
- [ ] 恩格尔–格兰杰临界值，重新缩放。
:::solution
[[#def-z]]写明的是样本分母与止于$t$的窗口。排除$q_t$、或除以$n$，都是另一个分数。单位根表上的临界值不是标准差。
:::
:::

:::intuition 残差在拒绝成为什么
最小二乘直线使拟合窗口上的残差、在含截距时求和为零。这是那次拟合的性质，不是下一个残差的性质。$z$分数接着再用同一个窗口上估出的宽度，去缩放最后一个残差、或最后一个对数比率。这些全都可以做完，而你手里仍然可能拿着一个带漂移对冲的趋势。这套算术是强制的，"协整"这个词不是。
:::

:::history
2006年，埃文·盖特夫（Evan Gatev）、威廉·戈茨曼（William Goetzmann）与K. 赫特·鲁文霍斯特（K. Geert Rouwenhorst）在美国股票上规定了一个基于距离的配对规则，并在一个限制了配对选择步骤中前视的延迟之后，报告其历史表现。延迟是设计的一部分：第一笔价差交易被允许时，用来选配对的已经是很旧的信息。一个算到与输入其中的价格同一天的$z$分数，是对那个窗口的描述。它本身不是那个带延迟的实验。
:::

## 通向何处

[[reversion/cross-sectional-reversal]]把短期限思想带回许多名字的排名——那才是1990年证据的形状——而不是两个价格之间的对冲。关系断裂时会跳的对冲比率，是[[reversion/when-reversion-fails]]里的失效方式之一。$\hat\beta$所用的最小二乘公式在[[statistics/regression-on-a-signal]]；单位根为什么是一个模型而不是一句口号，在[[statistics/stationarity-and-regimes]]。

:::summary
- 对数比率$q_t = \ln P^{(1)}_t - \ln P^{(2)}_t$是对数里的一比一对冲。滚动$z$分数减去窗口均值、除以样本标准差（分母$n-1$），含当前点。它挣的是其后的变动，不是当前的变动。
- 滚动对冲比率是一个对数价格对另一个的、带截距的最小二乘斜率，在拖尾窗口上。在编造价格上：日期$0$到$4$给出$\hat\beta = 1.6816$；日期$1$到$5$给出$\hat\beta = 1.5927$。
- 日期$4$上对数比率的$z$分数是$1.3008$。做空一单位对数比率挣下一个变动，$+0.046703$对数点。那不是货币收益率，也不是推荐。
- 若对数价格的变动相差一个非零常数，它们的样本相关系数为$1$，而单位对冲价差是一条直线趋势。没有任何固定的$\beta$能使那个价差为常数。相关不是协整。
- 恩格尔与格兰杰的检验是：先回归，再对残差做单位根检验，并用为估计残差准备的临界值。本章陈述了假设，没有计算任何$p$值。
- 2026年报告、未在此重跑：W13（KO/PEP对数比率$z$分数）年化复合增长率$+1.54\%$、夏普比率$-0.05$；W14（EWA/EWC滚动对冲）年化复合增长率$+0.45\%$、夏普比率$-0.30$。名字指认的是行，不是交易；被报告夏普比率的符号也不是翻转账簿的命令。
- 正的年化复合增长率旁边放着负的夏普比率，这件事被留而不决。我们不知道他们的超额收益口径，也不替他们发明一个。
:::

## 习题

:::exercise 一次除法 {level=1 check="1.5"}
一个对数比率是$0.73$，滚动均值是$0.70$，滚动样本标准差是$0.02$。$z$是多少？（输入$z$分数。）
:::solution
$z = (0.73 - 0.70)/0.02 = 0.03/0.02 = 1.5$。只有算出$0.70$与$0.02$的人把当前点放了进去，当前点才在均值与宽度里。题目把这两个已经完工的估计交给你，所以算术就是一次除法。$1.5$的$z$分数不是做空价差的指令。
:::
:::

:::exercise 期末趋势价差 {level=1 check="0.028"}
在[[#ex-corr]]里，单位对冲价差在七步中的每一步增加$0.004$，从$0$出发。七步之后价差是多少？（输入价差。）
:::solution
$7 \times 0.004 = 0.028$。价差的路径是$0.004, 0.008, \ldots, 0.028$。它不穿回零点。与此同时，变动的相关系数是$1$。这就是[[#prop-corr]]的内容。
:::
:::

:::exercise 平移序列的相关 {level=1 check="1"}
$\Delta y_t = \Delta x_t + c$，$c \neq 0$，且$\Delta x$非常数。两个变动序列的样本相关系数是多少？（输入相关系数。）
:::solution
中心化消去$c$，所以中心化后的序列相同，样本相关系数为$1$。只要$c$是常数，这个值就不依赖$c$有多大。价差$y - x$倒是依赖$c$。相关系数把那份信息扔掉了。
:::
:::

:::exercise 回归元动一点 {level=2 check="0.0168"}
用[[#ex-hedge]]的$\hat\beta = 1.6816$。若$\ln P^{(B)}$上升$0.01$而残差与截距保持不动，被拟合的$\ln P^{(A)}$上升多少？舍入到四位小数。（输入拟合变动。）
:::solution
拟合变动是$\hat\beta \times 0.01 = 1.6816 \times 0.01 = 0.016816$，四位小数为$0.0168$。这是已经拟合好的那条直线的性质。它没有说残差会在下一个日期保持不动，也没有说持有$1.6816$单位是谁都该拿的账簿。
:::
:::

:::exercise 比率对残差 {level=2}
在日期$0$到$4$上，对数比率对冲隐含$\beta = 1$，而拟合对冲是$\hat\beta = 1.6816$。为什么$q_t = \ln P^{(A)}_t - \ln P^{(B)}_t$的$z$分数不是最小二乘残差的$z$分数？
:::solution
对数比率把斜率定成$1$、不用截距。残差$x_t - \hat\alpha - \hat\beta y_t$把斜率定成$1.6816$、并去掉$\hat\alpha = -1.9760$。那是两个不同的序列。标准化其中一个，并不标准化另一个，哪怕就在同样五个日期上。[[#ex-roll]]随后又把$\hat\beta$变了。在对冲写定之前，"价差的$z$分数"这样一句话还没有给任何一个价差命名。
:::
:::

:::exercise W13没有报告什么 {level=2}
W13为KO/PEP对数比率账簿报告年化复合增长率$+1.54\%$、夏普比率$-0.05$，这是2026年库里所写。给出那一行确实报告的一个业绩事实，再给出一个协整论断需要、而那一行不含的一个事实。
:::solution
那一行确实报告了：一个年化复合增长率、一个总收益率、一个夏普比率、一个最大回撤、一个胜率、一个盈亏比——26年日频跨距上，一条被描述为这两只股票的市场中性对数比率$z$分数规则。一个协整论断则需要：写明的对冲、一个残差、一套单位根程序、以及适合估计残差的临界值。库内那一行这些都没有，本章也不提供$p$值来填空。那个被报告为负的夏普比率，不是把KO对PEP反做的命令。反做账簿会是一次新实验，带着它自己的成本。
:::
:::

:::exercise 中心化的变动为什么相同 {level=3}
从样本相关系数的定义出发，证明[[#prop-corr]]的相关那一半，不要借助该命题的其余部分。假设$\Delta x$的样本方差为正。
:::hint
把$\overline{\Delta y}$用$\overline{\Delta x}$与$c$写出。再把它从$\Delta y_t = \Delta x_t + c$中减去。两个中心化向量是同一个向量，所以协方差等于方差。
:::
:::solution
$\Delta y$的样本均值是$\overline{\Delta x} + c$。于是
$$
\Delta y_t - \overline{\Delta y} = (\Delta x_t + c) - (\overline{\Delta x} + c) = \Delta x_t - \overline{\Delta x}.
$$
$(\Delta x, \Delta y)$的样本协方差等于$\Delta x$的样本方差，而$\Delta y$的样本方差等于同一个方差。定义样本相关系数的那个比值是$1$。这段论证从头到尾没有用到价差的水平。相关系数为$1$，与变动里任何一个常数缺口$c$相容——包括一个使$y_t - x_t$成为趋势的缺口。
:::
:::

:::exercise 没有常数残差 {level=3}
在[[#prop-corr]]里，假设有人提出$\beta = 2$，作为也许能消掉趋势的对冲。用一阶差分恒等式证明：$y_t - 2x_t$在样本上不是常数。
:::hint
常数的路径一阶差分为零。计算$\Delta y_t - 2\Delta x_t$，并用$\Delta y_t = \Delta x_t + c$。你只需找到一个结果非零的$t$，或证明它不可能对一切$t$为零。
:::
:::solution
所提残差的一阶差分是
$$
\Delta y_t - 2\Delta x_t = (\Delta x_t + c) - 2\Delta x_t = c - \Delta x_t.
$$
取$c = 0.004$，它只在$\Delta x_t = 0.004$时为零。给定的$\Delta x$含有$0.010$与$-0.020$，两者都不等于$0.004$。所以至少两个一阶差分非零，$y_t - 2x_t$不是常数。对一般$\beta \neq 1$的同样计算，就是[[#prop-corr]]证明的第二半：一阶差分是$(1-\beta)\Delta x_t + c$，除非$\Delta x$为常数，它不可能对每个$t$都消失。全程没有$p$值进场。
:::
:::
