一个指标打印出30，感觉像是关于市场的事实。它其实是关于一个公式、一个窗口、一个平滑器的事实。**相对强弱指标（RSI）**把近期的盈利与近期的亏损压缩成0到100之间的一个数。**布林带**在近期收盘价周围放置一条移动平均与一个移动标准差。两个对象中的任何一个，都可以做入场与出场的输入。两个对象都不是[[reversion/the-reversion-hypothesis]]里的那个短期限假说，两个数也都不是交易的指令。

本章先固定可计算的定义，在路径A上运行它们，然后读三条使用同一家族语言、却使用不同时钟的库内实验。其中两条实验在RSI(14)低于35时入场、高于60时出场：一条提交市价单，一条每周设定权重。第三条在下轨之下买入、到中线离场。被报告的路径彼此并不一致，这才是值得留下的结果。一个公布的盈利，不是一条可以拿来就用的带；一个公布的亏损，也不是做对面的信号。

路径A又是
$$
P = (100,\ 102,\ 101,\ 104,\ 103,\ 107,\ 106,\ 110)
$$
日期为$0$到$7$。收盘到收盘的变动是$+2, -1, +3, -1, +4, -1, +4$。七个变动撑不起一个14期窗口，所以下文每一个RSI都是对这个玩具的3期计算，并已如此标注。它不是库里的那个RSI(14)。

## 平均盈利、平均亏损、一个数

一个变动被拆成盈利与亏损。收盘价上涨$u > 0$，盈利为$u$、亏损为$0$；收盘价下跌$u > 0$，盈利为$0$、亏损为$u$；收平则两者都贡献零。威尔斯·怀尔德（J. Welles Wilder）1978年的构造随后对这两个序列做平滑。他发表的平滑是递归的；在固定窗口上取简单平均是另一个函数。软件里两者用同一个名字。规格说明必须写清是哪一种。

:::definition 简单平均RSI {#def-rsi}
在$n \ge 1$个收盘到收盘变动的窗口上，把$n$个盈利的算术平均称为**平均盈利**，把$n$个亏损的算术平均称为**平均亏损**。若平均亏损为正，
$$
\mathrm{RS} = \frac{\text{平均盈利}}{\text{平均亏损}}, \qquad \mathrm{RSI} = 100 - \frac{100}{1+\mathrm{RS}}.
$$
若平均亏损为$0$而平均盈利为正，该比值无定义；本章的约定是把RSI设为$100$。若两个平均都为$0$，把RSI设为$50$，因为窗口里没有可供归一的变动。这是简单平均，不是怀尔德的递归平滑器；变动以价格点计，不以百分比计。窗口止于某个写明的日期，数值在收盘那一刻已知。
:::

公式是两个平均之比的单调函数：两平均相等时RSI为$50$，盈利占优时高于$50$，亏损占优时低于$50$。它不认识"便宜"这个词。读数$20$的意思只是：在所选的窗口与所选的平滑器下，亏损相对盈利偏大。账簿拿这个读数做什么，是第二句话：入场、出场、订单与成本。

:::algorithm 一次怀尔德更新 {#alg-wilder}
从最初$n$个变动的简单平均出发，记作$\bar g$与$\bar \ell$。下一个变动到来、其盈利为$g$、亏损为$\ell$时，把两个平均替换为
$$
\bar g \leftarrow \frac{(n-1)\bar g + g}{n}, \qquad \bar \ell \leftarrow \frac{(n-1)\bar \ell + \ell}{n},
$$
再由[[#def-rsi]]重算RS与RSI。不要把平均从头重算。新的平均保留旧平均的$(n-1)/n$，所以一次冲击只随后续变动的到来才衰减。 每当你把结果称为怀尔德的RSI，就要写明$n$，并写明使用的是这个递归。
:::

在路径A上取$n = 3$，简单平均的读数与一步怀尔德更新很容易并排放，而它们对不上。

:::example 路径A上的简单平均RSI {#ex-rsi-path}
用$n = 3$与[[#def-rsi]]，计算收盘价$104, 103, 107, 106, 110$处的RSI。
:::solution
变动依次为$+2, -1, +3, -1, +4, -1, +4$。每个窗口是其中三个，数值在窗口止于的那个收盘价已知。

在$104$处，变动为$+2, -1, +3$。平均盈利$(2+0+3)/3 = 5/3$，平均亏损$(0+1+0)/3 = 1/3$，所以$\mathrm{RS} = 5$，
$$
\mathrm{RSI} = 100 - 100/6 = 83.3333
$$
（四位小数）。

在$103$处，变动为$-1, +3, -1$。平均盈利$1$，平均亏损$2/3$，$\mathrm{RS} = 1.5$，$\mathrm{RSI} = 100 - 100/2.5 = 60$恰为整。

在$107$处，变动为$+3, -1, +4$。平均盈利$7/3$，平均亏损$1/3$，$\mathrm{RS} = 7$，$\mathrm{RSI} = 100 - 100/8 = 87.5$恰为整。

在$106$处，变动为$-1, +4, -1$。平均盈利$4/3$，平均亏损$2/3$，$\mathrm{RS} = 2$，$\mathrm{RSI} = 100 - 100/3 = 66.6667$（四位小数）。

在$110$处，变动为$+4, -1, +4$。平均盈利$8/3$，平均亏损$1/3$，$\mathrm{RS} = 8$，$\mathrm{RSI} = 100 - 100/9 = 88.8889$（四位小数）。

五个读数没有一个低于$35$。最低的是$60$，出现在收盘价$103$处。一条只在这个RSI低于$35$时入场的规则，在路径A上永不入场。这份沉默，是一条上涨、交替、以$n = 3$度量的玩具路径的性质。它不是算术里的缺陷，也不是对一条在不同序列上算出的14期指标的评论。
:::
:::

:::example 一次递归更新，另一个数 {#ex-wilder}
从收盘价$104$处的简单平均出发——它们也正是$n = 3$时[[#alg-wilder]]的合法种子。在下一个变动$-1$上应用一次怀尔德更新，并把RSI与$103$处简单平均的读数作比较。
:::solution
种子是$\bar g = 5/3$与$\bar \ell = 1/3$。下一个变动是亏损$1$，所以$g = 0$、$\ell = 1$。于是
$$
\bar g = \frac{2 \times (5/3) + 0}{3} = \frac{10}{9}, \qquad \bar \ell = \frac{2 \times (1/3) + 1}{3} = \frac{5}{9}.
$$
比值为$2$，$\mathrm{RSI} = 100 - 100/3 = 66.6667$（四位小数）。同一收盘价上的简单平均是$60$。同样的变动、同样的$n$、两个平滑器、两个读数，而且没有一个低于$35$。只写"RSI(3)"的回测没有指定一条规则。下面的O02与W03写的是RSI(14)和一对门槛；但在一行式的库内描述里，它们没有说代码用的是这个递归还是一个滚动简单平均。我们不猜，也没有重跑它们。
:::
:::

:::warning 用零亏损做分母
一个窗口全是盈利时，平均亏损为零，RS除不下去。把RSI设为$100$是一个约定，不是定理。删掉那个日期、或沿用上一个RSI，都会改变序列，而改变可以传导到一个定义为"RSI高于60"的出场。把约定写在$n$的旁边。整窗都是平变动时同样适用这条警告：两个平均都为零，$50$也仍然只是一个约定——[[#def-rsi]]把它写出来，好让本章有一个答案。
:::

## 一条带是一个平均加一个宽度

布林格（Bollinger）的构造——他在2001年的书里写明的、他从1980年代初就在用的——是一条移动平均加上并减去移动标准差的一个倍数。倍数$2$与窗口$20$是他选的约定，不是[[reversion/the-reversion-hypothesis]]蕴含的。该构造里的标准差除以窗口长度$n$，不除以$n-1$。本章沿用这个分母并在此说明。换用样本分母，是另一条带。

:::definition 窗口上的布林带 {#def-band}
设$P_{t-n+1},\ldots,P_t$为以$t$结尾的$n \ge 2$个收盘价，算术平均为$m_t$。设$s_t$为这$n$个收盘价的总体标准差，于是$n s_t^2$是对$m_t$的偏差平方和。对倍数$k > 0$，在$t$已知的**布林带**是区间$[m_t - k s_t,\ m_t + k s_t]$，而$m_t$称为**中轨**。收盘价$P_t$就在这条带所由建成的窗口之内。一条改为把$P_t$与在$t-1$已知的带作比较的规则是另一条规则，必须如此命名。
:::

把收盘价放进它自己的窗口，给这个收盘价能看起来有多极端立了一个硬上限。

:::proposition 一个点跑不出它自己的短窗口 {#prop-bound}
设$x_1,\ldots,x_n$为实数，$n \ge 2$，不全相等，均值为$m$，总体标准差$s > 0$。对每个下标$j$，
$$
\frac{\lvert x_j - m\rvert}{s} \le \sqrt{n-1}.
$$
特别地，若$n = 3$且$k = 2$，窗口内的每个收盘价都严格位于[[#def-band]]那条带之内，因为$\sqrt{2} < 2$。
:::

:::proof
记$d_i = x_i - m$，则$\sum_{i=1}^{n} d_i = 0$且$s^2 = n^{-1}\sum_{i=1}^{n} d_i^2$。固定$j$，则$d_j = -\sum_{i \neq j} d_i$。对其余$n-1$个偏差用柯西–施瓦茨不等式得
$$
d_j^2 = \Big(\sum_{i \neq j} d_i\Big)^2 \le (n-1)\sum_{i \neq j} d_i^2 = (n-1)\Big(\sum_{i=1}^{n} d_i^2 - d_j^2\Big).
$$
于是$n d_j^2 \le (n-1)\sum_i d_i^2$，即$d_j^2 / s^2 \le n-1$。当其余偏差相等时可以取等，所以这个上界是紧的；但我们需要的只是这个"$\le$"。$n = 3$时上界为$\sqrt{2} \approx 1.4142$，小于$2$。一个参与建成3期、$k = 2$带的收盘价，不可能待在那条带之外。若窗口是平的，$s = 0$，带作为双侧宽度就没有定义；假设$s > 0$排除了这种情形。
:::

这条命题正是以下事实的原因：只要带包含了被检验的那个收盘价，$n = 3$、$k = 2$的下轨买入规则就在一切路径上沉默，而不只是在路径A上。拉长窗口、增大某个收盘价远离其余$n-1$个的机会、或拿昨天的带来检验今天的收盘价，是让触发成为可能的三种不同方式。它们是三条不同的规则。

:::example 通往104途中那条带 {#ex-band-104}
在收盘价$102, 101, 104$上，计算$m$、总体$s$、$k = 2$的带，以及$104$的总体$z$分数。说明一条按[[#def-band]]在收盘价低于下轨时买入的规则是否会买入。
:::solution
均值为$(102+101+104)/3 = 307/3 = 102.333333$。偏差平方到六位小数为$0.111111$、$1.777778$与$2.777778$，相加得$4.666667$。总体方差为$4.666667/3 = 1.555556$，所以$s = \sqrt{14/9} = 1.247219$（六位小数）。从完整精度舍入，带$m \pm 2s$为$[99.838895,\ 104.827772]$。
最后一个收盘价的$z$分数为$(104 - 102.333333)/1.247219 = 1.3363$（四位小数），在[[#prop-bound]]要求的$\sqrt{2}$之内，更远在$k = 2$之内。收盘价并不低于$99.838895$。该规则不买入。在这个定义下，它在路径A的任何一天也都不买入：$n = 3$、$k = 2$时，它在任何一条路径上都不可能买入。
:::
:::

:::example 昨天的带，今天的收盘价 {#ex-lag-band}
日期$0$到$4$的收盘价为$100, 102, 101, 90, 95$。在日期$3$上比较两条规则。规则A按[[#def-band]]用包含$90$的窗口，取$n = 3$、$k = 2$。规则B把$90$与日期$2$已知的$n = 3$、$k = 2$带作比较，若买入，则挣$R_4$。不要把两个触发中的任何一个，当作从$101$跌到$90$时逢低买入的建议。
:::solution
规则A用$102, 101, 90$。均值为$97.666667$。总体标准差为$5.436502$。下沿从完整精度舍入为$86.793662$。收盘价$90$在这个沿之上。总体$z$分数为$(90 - 97.666667)/5.436502 = -1.4102$，在$\sqrt{2}$之内。规则A不买入。[[#prop-bound]]本来就已禁止$k = 2$的突破。

规则B用较早的窗口$100, 102, 101$。均值为$101$，总体标准差为$\sqrt{2/3} = 0.816497$，所以下沿是$101 - 1.632993 = 99.367007$。新收盘$90$低于$99.367007$，于是规则B在日期$3$收盘买入一单位。该头寸挣得
$$
R_4 = 95/90 - 1 = 0.055556.
$$
这笔利润，是在一条编造的路径上持有多头、且价格从$90$弹回$95$的算术后果。规则A在同一条路径上没有交易，所以什么也没挣。下面库内W21那一行，没有说明它的带是否包含被检验的那个收盘价。两条规则不可互换，而这个玩具也指认不出库里跑的是哪一条。
:::
:::

一条带是一个滚动平均加减k倍样本标准差。图中在一条玩具均值回归路径上画了一条。带内的样本标准差用分母n−1。收盘价落在带外，是关于这个样本的一个事实，不是指令。

:::intuition 宽度与窗口互相拆台
更大的$k$让突破更罕见。更大的$n$让某个反常收盘价能以总体$z$分数待在更外面——至多$\sqrt{n-1}$——于是同一个$k$可能开始触发。看过突破情况之后再挑$n$与$k$，是一场搜索。给一张搜索网格按"看了几遍"收费，是[[statistics/testing-and-snooping]]的事。本章只需要那个更小的论点：$n$与$k$属于定义这条规则的那句话。
:::

## 三个库内条目，不是一个RSI结果

本节的数字是2026年读入时quants.md上那个QuantJourney示例（Apache-2.0）所报告的数字。本图谱没有重跑这些回测。被报告的夏普比率是他们的数字。我们不知道他们的无风险收益率与年化方式，也不把被报告的夏普比率换算成我们玩具上用的每步比率。三条没有一条是预测，也没有一条是可以照抄的策略。

O02，"Market RSI Reversion"：在RSI(14)低于35时买入、RSI高于60时卖出，用市价单，25年的日K线。库内报告总收益率$+29.08\%$、年化复合增长率$+1.03\%$、夏普比率$-0.17$、最大回撤$-16.01\%$、胜率$71.6\%$、盈亏比$1.81$。

W03，"Weekly RSI Reversion"：同样的入场与同样的出场——RSI(14)低于35、高于60——但每周、在周五设定权重，26年的日K线。库内报告总收益率$+373\%$、年化复合增长率$+6.16\%$、夏普比率$0.34$、最大回撤$-49.2\%$、胜率$62.1\%$、盈亏比$2.15$。

W21，"Bollinger Reversion"：在下轨之下买入、在中线出场，26年的日K线。一行式的描述没有给出窗口与倍数，我们不替它填。库内报告总收益率$+487\%$、年化复合增长率$+7.04\%$、夏普比率$0.42$、最大回撤$-35.2\%$、胜率$59.8\%$、盈亏比$1.96$。

O02与W03共用14、35、60这三个整数，却不共用一个实验。一条发送订单，一条设定每周目标权重。样本相差一年。被报告的年化复合增长率一行是$+1.03\%$、另一行是$+6.16\%$；被报告的最大回撤是$-16.01\%$对$-49.2\%$。没有一次受控的重跑——我们没有做过——你就不能把这一差距交给某一个原因：订单、周五的时钟、年份、账簿里的名字。谈论"那个"RSI回测，会抹掉这两行干净支撑着的唯一事实：实现方式是结果的一部分。

O02被报告的夏普比率为负，而它被报告的年化复合增长率为正，胜率是$71.6\%$。当盈利相对那个夏普比率的计算尺度偏小，或当夏普比率并不是"增长除以某个波动率"时，高胜率与负的报告夏普比率并存是可能的。我们不替他们挑选哪一种解释属于他们。我们也不会把负的夏普比率翻转成一条做空规则。正负号混着的公布数字，是对那个条目的描述。

W21不是O02与W03之间的决胜局。它是第三个规格：用带而不振荡指标，在中线而非RSI 60出场。它被报告的年化复合增长率是三行中最大的；它被报告的回撤比O02深、比W03浅。把三个年化复合增长率排个序、留下赢家，是一场三次浏览的搜索，发生在事后，对象是三个从未被设计成同场竞技的实验。[[#prop-bound]]提醒我们："下轨之下"是空的还是频繁的，取决于$n$、$k$和时钟。W21那一行没有为这些选择定案。

在我们的定义下，路径A从不打印出低于35的3期简单平均RSI，也从不打印出走出它自己的3期、$k = 2$带的收盘价。指望库内门槛在玩具上"显灵"的读者，是在要求这个玩具当一本25年的成交簿。它是八个收盘价。

- [ ] 一条带的回测里被报告为正的年化复合增长率。
:::solution
$n = 3$时，窗口内任何一点的总体$z$分数至多为$\sqrt{2} < 2$。昨天的带是另一条规则，[[#ex-lag-band]]就给出了一个确实跌出它的收盘价。这条命题对别人报告的年化复合增长率不作声。
:::
:::

:::application 这些条目拿来做什么
把O02、W03与W21当作规格说明的算例，不当菜单。写了"35以下入场、60以上出场"，你还欠：平滑器、K线、订单或权重、再平衡、成本。写了"下轨买入"，你还欠：$n$、$k$、$s$里的分母、以及收盘价在不在窗口之内。库内已经展示过：把第一句话以两种方式补全，可以报告出$+1.03\%$的年化复合增长率与$+6.16\%$的年化复合增长率。在看过这些条目之后、用你自己挑的数据去补全那句话，会是一次额外的浏览，不是一次确认。
:::

:::history
1978年，威尔斯·怀尔德（J. Welles Wilder）在*New Concepts in Technical Trading Systems*里定义了相对强弱指标：固定窗口上平均盈利与平均亏损之比的一个归一化。O02与W03所用的14期长度是他的建议，不是公式的推论。约翰·布林格（John Bollinger）2001年的书写明了他从1980年代初就在使用的带构造：一条移动平均加上并减去移动标准差的一个倍数。
:::

## 通向何处

围绕单一价格画一条带，是关于那个价格的陈述。[[reversion/pairs-and-spreads]]从两个价格构造价差——经由对数比率、也经由对冲比率——并把这两种构造与协整分开。把"RSI高于60"换成移动止损的出场，是[[reversion/when-reversion-fails]]的主题，不是入场眼熟时可以忽略的小调整。与信号$s_t$相区别，权重在[[portfolio/from-signal-to-weight]]里映射。

:::summary
- 简单平均RSI是$100 - 100/(1+\mathrm{RS})$，其中$\mathrm{RS}$是写明的价格变动窗口上平均盈利与平均亏损之比。怀尔德更新保留前一个平均的$(n-1)/n$，不从头重算。
- 路径A上$n = 3$时，简单平均在收盘价$104, 103, 107, 106, 110$处的读数为$83.3333$、$60$、$87.5$、$66.6667$、$88.8889$，没有一个低于35。在$103$处一步怀尔德更新给出$66.6667$，不是$60$。
- 本章的布林带是$m_t \pm k s_t$，$s_t$为以$t$结尾的$n$个收盘价的总体标准差。倍数$2$是一个约定。
- 任何点在其自身窗口内的总体$z$分数至多为$\sqrt{n-1}$。$n = 3$、$k = 2$时收盘价出不了带。把收盘价与昨天的带比较是另一条规则：在跌到$90$的编造路径上，后者买入，含自身窗口的版本不买。
- O02与W03都写着RSI(14)低于35、高于60。2026年报告、未在此重跑：O02的年化复合增长率为$+1.03\%$、夏普比率$-0.17$；W03的年化复合增长率为$+6.16\%$、夏普比率$0.34$、最大回撤$-49.2\%$。同样的门槛，不同的实验。
- W21在下轨之下买入、在中线出场，报告年化复合增长率$+7.04\%$、夏普比率$0.42$、最大回撤$-35.2\%$。那一行没有说明$n$与$k$。我们不发明它们，也不把W21排在另外两行之上、当作一个可供交易的选择。
- 负的夏普比率挨着正的年化复合增长率（O02如是），被留作那个条目的一个事实。它不是做对面的理由。
:::

## 习题

:::exercise 两平均相等 {level=1 check="50"}
一个窗口平均盈利$2$、平均亏损$2$。按[[#def-rsi]]，RSI是多少？（输入RSI。）
:::solution
$\mathrm{RS} = 2/2 = 1$，所以$\mathrm{RSI} = 100 - 100/2 = 50$。两平均相等是量表的正中点，不是做任何事的信号。
:::
:::

:::exercise 三比一的比 {level=1 check="75"}
平均盈利$3$、平均亏损$1$。RSI是多少？（输入RSI。）
:::solution
$\mathrm{RS} = 3$，所以$\mathrm{RSI} = 100 - 100/4 = 75$。因为盈利占优，读数在50以上。它不是卖出的指令；而且除非你也已经把60写为你的出场，它还算不上O02意义上的"高于60"。这里题目只要指标数值。
:::
:::

:::exercise 短窗上界 {level=1 check="1.4142"}
$n = 3$时，[[#prop-bound]]把总体$z$分数以$\sqrt{n-1}$封顶。把这个上界输入到四位小数。
:::solution
$\sqrt{2} = 1.41421356\ldots$，四位小数是$1.4142$。因为$1.4142 < 2$，一个包含收盘价自身的$k = 2$带，在$n = 3$时不可能被那个收盘价突破。
:::
:::

:::exercise 路径A最低的简单RSI {level=2 check="60"}
从[[#ex-rsi-path]]的五个简单平均读数看，最低的RSI是多少？（输入数值。）
:::solution
读数为$83.3333$、$60$、$87.5$、$66.6667$、$88.8889$。最低的是$60$，在收盘价$103$处，对应变动$-1, +3, -1$。35的入场门槛不会开火；"严格高于60"的出场门槛在这天也不会开火，因为读数等于60、不是高于60。等号必须写明，否则以后会被误打误撞地填上。
:::
:::

:::exercise 徒手算总体方差 {level=2 check="1.555556"}
收盘价$102, 101, 104$。均值为$102.333333$，偏差平方和为$4.666667$。总体方差是多少（六位小数）？（输入方差，不是标准差。）
:::solution
除以$n = 3$，不是除以$2$。方差是$4.666667/3 = 1.555556$。标准差是它的平方根$1.247219$，正是[[#ex-band-104]]画带用的那个数。改用$n-1$会让$s$变宽，那是与[[#def-band]]不同的另一种约定。
:::
:::

:::exercise 全是盈利 {level=2}
三个变动的窗口是$+1, +2, +4$。应用[[#def-rsi]]里的零亏损约定，写出RSI。在回测里，"留空"为什么是一个危险的替代方案？
:::solution
平均盈利为$7/3$，平均亏损为$0$。比值除不下去。[[#def-rsi]]把RSI设为$100$。留空会强迫每一处下游规则自己发明一个数值：沿用上次的RSI、跳过这根K线、或把空当成零。这些选择会改变"RSI高于60"的出场是否开火。约定是任意的，但它必须在结果算出来之前写定，而不是在某个空格子显得碍事之后。
:::
:::

:::exercise 样本分母，仍然在内 {level=3}
样本标准差用分母$n-1$代替$n$。证明对应的$z$分数等于总体$z$分数乘以$\sqrt{(n-1)/n}$，并计算$n = 3$时相应的上界。解释为什么改用样本分母，仍然无法把一个收盘价推出三条收盘价的$k = 2$带。
:::hint
总体方差是$\sum d_i^2 / n$，样本方差是$\sum d_i^2 /(n-1)$，所以样本标准差按$\sqrt{n/(n-1)}$更大。分母更大，$z$分数就更小。然后套用[[#prop-bound]]。
:::
:::solution
记$s_{\mathrm{pop}}^2 = \sum d_i^2 / n$、$s_{\mathrm{sam}}^2 = \sum d_i^2 /(n-1)$。则$s_{\mathrm{sam}} = s_{\mathrm{pop}}\sqrt{n/(n-1)}$，而
$$
\frac{\lvert d_j\rvert}{s_{\mathrm{sam}}} = \frac{\lvert d_j\rvert}{s_{\mathrm{pop}}}\sqrt{\frac{n-1}{n}}.
$$
[[#prop-bound]]把总体比率以$\sqrt{n-1}$封顶，所以样本比率至多为
$$
\sqrt{n-1}\cdot\sqrt{(n-1)/n} = (n-1)/\sqrt{n}.
$$
$n = 3$时上界是$2/\sqrt{3} \approx 1.1547$，仍小于$2$。样本带更宽，收盘价看起来就更不极端。换分母造不出那个被$k = 2$与$n = 3$禁止的突破。
:::
:::

:::exercise 两种补全，一句话 {level=3}
O02报告年化复合增长率$+1.03\%$、夏普比率$-0.17$。W03报告年化复合增长率$+6.16\%$、夏普比率$0.34$。两条库内描述都在RSI(14)低于35时入场、高于60时出场。给出库里写明的两个流程差异，并解释为什么这些差异使你不能把年化复合增长率的差距归因于门槛。
:::hint
看订单对权重，再看再平衡与样本长度。门槛本身是两行相同的部分。数字为2026年所报告；本图谱没有重跑。
:::
:::solution
O02提交市价单，报告跨距25年。W03每周、在周五设定权重，报告跨距26年。入场整数与出场整数一致。在被报告的数字里，$6.16 - 1.03 = 5.13$个百分点的年化复合增长率差距，旁边至少站着这两个流程差异，可能还有两个一行式描述没有列出的差异。单一原因没有被指认。特别地，两条规则共用的门槛，不可能是"造成"这两条规则之间差距的东西。O02那个被报告为负的夏普比率，不是跑O02反面的理由；W03那个被报告更高的年化复合增长率，也不是偏爱周五权重的理由。两个条目都仍然是对本图谱未曾重复的实验的描述。
:::
:::
