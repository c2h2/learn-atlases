均值的通常标准误之所以除以$\sqrt{n}$，是因为它把观测当作相互独立的抽取。一个收益率序列是一条路径。重抽样问的是：若用这条路径自己的碎片把它重新拼出来，它还可能是什么别的模样。长度为1的碎片会毁掉连段。作为块的碎片则保住了那些装得进一个块的连段。这两种程序都发明不出路径里从未有过的收益率，而且这两种程序都不是一笔交易决定。

$\sqrt{n}$这个尺度本身，就是在独立、方差有限的模型之下中心极限定理的结论。证明在数学图谱的[极限定理](/learn/maths/lesson.php?c=probability&l=limit-theorems)里。本章不证明它，也不假装一张自助均值的直方图就是那个定理。自助法是另一种构造：它对一条已观测的序列做重抽样。

## 长度为1的抽取

:::definition 独立同分布自助样本 {#def-iid-boot}
设$x_1,\ldots,x_n$是已观测的序列。**独立同分布自助样本**是一个序列$X_1^\star,\ldots,X_n^\star$，其中每个坐标都从$\{x_1,\ldots,x_n\}$中独立、均匀、有放回地抽出。自助法分布——记作$\E^\star$、$\Var^\star$与$\Corr^\star$——就是在把观测数字固定住的前提下这些抽取的分布。它是样本的重排与重复之上的一个概率模型。它不是一整年新价格的模型。
:::

自助均值$\bar X^\star = n^{-1}\sum_{t=1}^n X_t^\star$就是人们拿来与$\bar x$比较的那个统计量。它的自助期望不是关于市场的一条新事实。它是一个恒等式。

:::proposition 自助均值与自助相关系数 {#prop-iid}
在[[#def-iid-boot]]之下，对每个$t$有$\E^\star[X_t^\star] = \bar x$，因此$\E^\star[\bar X^\star] = \bar x$。若观测值不全相等，则对$t \neq s$

$$
\Corr^\star(X_t^\star, X_s^\star) = 0.
$$

特别地，自助法分布的滞后1阶相关为零，无论原序列是不是这样。
:::

:::proof
一次抽取在这$n$个观测值上均匀，所以

$$
\E^\star[X_t^\star] = \frac{1}{n}\sum_{i=1}^n x_i = \bar x.
$$

自助均值是$n$个这样的抽取的平均，而期望可以进到平均里面，所以$\E^\star[\bar X^\star] = \bar x$。这一步不要求各个$x_i$互不相同。

不同的坐标由独立同分布自助法的定义而相互独立。两个方差有限的随机变量独立，意味着它们的协方差为零。单个坐标的自助方差是

$$
\Var^\star(X_t^\star) = \frac{1}{n}\sum_{i=1}^n (x_i - \bar x)^2,
$$

它就是样本上离散均匀分布的方差，除数取$n$而不是$n-1$。若观测值不全相等，这个方差是正的。两个不同坐标的相关系数，是一个零协方差除以一个正的标准差之积，因此为零。原序列可以有一个很大的样本滞后1阶相关。自助法分布刚刚把所有位置对的相关都设成了零。一次有限的重抽样不会有恰为零的样本相关系数；它会在一个相关为零的分布周围抖动。抖动是下一个例子。分布才是这条命题。
:::

这就是为什么独立同分布自助法无法表示一个滞后1阶相关正是研究对象的序列。自助法从中抽样的那个世界，是按那个相关等于零建造起来的。用它为一个均值造一个区间，等于宣称对这个特定的统计量而言相依性可以忽略，或者宣称根本不存在相依性。[[statistics/stationarity-and-regimes]]里满是让后一句话不成立的序列，即便带符号的滞后1阶相关本身就接近零，因为绝对值收益率仍然会聚集。一个把聚集假设掉的区间，是针对另一个问题的区间。

:::quiz
观测序列的样本滞后1阶相关是$0.720887$，而八个值不全相等。在独立同分布自助法分布之下，$\Corr^\star(X_t^\star, X_{t-1}^\star)$是多少？
- [ ] $0.720887$，因为自助法复制了样本。
- [x] $0$，因为不同的抽取独立，而自助方差为正。
- [ ] $-0.016687$，因为那是种子为$61$的那次重抽样的相关系数。
- [ ] $1$，因为每次抽取都取自同一个样本。
:::solution
[[#prop-iid]]在观测值不全相等时把不同位置的相关设为零。样本相关$0.720887$描述的是原来的顺序。数字$-0.016687$是一次有限的重抽样，它被允许偏离分布。从一个样本里抽取，并不会强迫两个独立坐标的相关等于$1$。
:::
:::

## 块

块是原始路径上一段连续的片段。复制这段片段，就复制了它内部的相依性。

:::definition 重叠块 {#def-block}
设$\ell$是满足$1 \le \ell \le n$的整数。从下标$i$开始、长度为$\ell$的**重叠块**，对$i = 1,\ldots, n-\ell+1$，是片段$(x_i, x_{i+1}, \ldots, x_{i+\ell-1})$。这样的块有$M = n - \ell + 1$个。它们相互重叠。观测$x_1$只坐在第一个块里。处于中间的观测最多坐在$\ell$个块里。当$\ell = 1$时，块就是原来的那些点，而$M = n$，也就是独立同分布自助法的那副牌。
:::

:::algorithm 移动块自助法 {#alg-block}
给定这个序列、一个块长$\ell$、以及一个期望的样本长度$n$：

1. 造出[[#def-block]]的$M = n - \ell + 1$个重叠块。
2. 从$M$个可能的起点中独立、均匀、有放回地抽取起点。抽$\lceil n/\ell \rceil$个。
3. 把选中的块按抽中的顺序拼接起来。
4. 保留拼接结果的前$n$个观测。若$\ell$整除$n$，第2步恰好抽出$n/\ell$个块，什么也不需要裁掉。
5. 在那个拼接结果上计算统计量。重新抽取一次起点，就得到一个新的自助样本。

块与块之间的接缝不是原来的相邻。相距超过$\ell$的相依性不会被复制。块长是一个选择；因为某个长度造出了一个讨喜的区间就多试几个长度，是一场搜索，是[[statistics/testing-and-snooping]]意义上的搜索。
:::

单个块有一个性质是精确成立的，而这正是块长不是一个装饰性参数的原因。

:::proposition 一枚随机的相邻配对保持样本相关系数 {#prop-pair}
设$\ell = 2$，于是$M = n - 1$，而块恰好就是这个序列的全部相邻配对。均匀地抽取一个起点。设$(Y, Z)$是被选中的块里的两个观测。如果这个序列的样本滞后1阶相关存在，那么$(Y, Z)$在这次抽取之下的相关系数，就等于那个样本滞后1阶相关。
:::

:::proof
一个均匀的起点把质量$1/M$放在每个相邻配对$(x_i, x_{i+1})$上。一个固定点清单上的离散均匀分布的相关系数，就是那个清单的普通样本相关系数：均值、中心化坐标的乘积以及两个平方和，都是样本滞后1阶相关里出现的同样这些和，而除数$M$在协方差与方差之间消去。因此随机块之下的$\Corr(Y, Z)$等于$x$的样本滞后1阶相关。如果那个样本相关是正的，那么一枚长度为$2$的块的分布就有同样这个正的相关。[[#prop-iid]]说两次独立同分布自助抽取的分布相关为零。这两个程序不是彼此的小变体。它们对"相邻的还待在一起吗？"这个问题编码了相反的答案。

[[#alg-block]]里的拼接不如单个块那样整齐。块内部，相邻就是原来的相邻。跨过一个接缝，两个观测来自各自独立抽出的块，而这一对的表现像一次独立同分布的抽取。一次更长的拼接，会被这些接缝把样本相关稀释掉。选$\ell = n$会复制整个序列、不产生任何接缝，但也不产生任何新样本。块长是一个折中：一边要复制相依性，一边要有不止一个彼此不同的重抽样。这条命题是"复制"那一半的$\ell = 2$情形。
:::

均值上有一个边缘效应，而它不该被挥手放过。因为序列中段坐落的重叠块比两端更多，$M$个块均值的平均不恰为$\bar x$。对下面例题里的序列，$n = 8$而$\ell = 2$，每个位置分别出现在$1, 2, 2, 2, 2, 2, 2, 1$个块里，样本均值是$0.0235$，而七个块均值的平均是$0.163/7 \approx 0.023286$。差距大约是$0.000214$。一个循环块自助法——把序列首尾相接，使得每个位置恰坐在$\ell$个块里——能去掉这个具体的差距。本章使用[[#alg-block]]那种朴素的重叠块，不把它们的均值称为无偏。独立同分布情形是无偏的，理由见[[#prop-iid]]。块情形在这个序列上很接近，但不精确。

这个程序同样看不见样本之外。

:::proposition 重抽样的支撑集 {#prop-support}
每个独立同分布自助样本的坐标，以及每个移动块自助样本的坐标，都等于某个原始观测$x_1,\ldots,x_n$。一个不在那$n$个值之中的数，不在任何一个重抽样的支撑集里。
:::

:::proof
由[[#def-iid-boot]]，每个独立同分布坐标都从$\{x_1,\ldots,x_n\}$中抽出。由[[#alg-block]]，每个块都是原序列的一段，而拼接是由这些片段做成的。拼接中的一个坐标就是某个$x_i$。两种构造都不添加冲击、不外推尾部、也不插入一个未曾贡献任何观测的体制。如果每个观测到的收益率都落在区间$[m, M]$里，那么每个重抽样的收益率也落在$[m, M]$里。
:::

自助法区间覆盖不了一个尚未发生的断裂，意义就在于此。区间是一条已观测路径的函数。一个落在观测值集合之外的未来收益率，对两种重抽样都是不可见的。甚至一个等于某个过去值、但以块无法表示的构型到来的未来收益率——一种从未发生过的、长度超过$\ell$的连段——块抽取也不知道该如何构造它，除非碰巧出现一个接缝。这个区间是对一个统计量在某条路径的一个指定重排之下的抽样变动的描述。它不是下一个体制待在最后一个体制里面的概率。

:::quiz
观测到的收益率是$0.01$、$0.00$、$-0.01$与$0.02$。哪个数可以作为一个移动块自助样本的坐标出现？
- [ ] $-0.10$，如果块长足够长、能够够到后来的崩盘。
- [ ] $0.05$，因为一个块均值可能落在各个观测之间。
- [x] $-0.01$，因为它是原始观测之一。
- [ ] $0.0235$，因为每个重抽样的坐标都等于样本均值。
:::solution
[[#prop-support]]说每个重抽样的坐标都等于某个原始观测。四个选项里只有$-0.01$在观测集合之中。更长的块仍然是已观测路径上的一块碎片，所以它装不下$-0.10$。块均值是事后算出的一个统计量；它不是重抽样的一个坐标。样本均值不是四个观测之一。
:::
:::

## 一条给定种子的路径

本节的序列是编造的。叫它一条带有两个尺度的短收益率路径，而不是价格路径：

$$
x = (0.005,\ 0.004,\ 0.006,\ 0.003,\ 0.040,\ 0.035,\ 0.050,\ 0.045).
$$

共有$n = 8$个观测。它们的和是$0.188$，所以样本均值是$0.188/8 = 0.0235$。按[[statistics/moments-and-dependence]]的配对意义，样本滞后1阶相关是$0.720887$。相邻的看起来彼此相像：四个小收益率，然后四个更大的。这个序列就是照着这样建的，好让一次重抽样就能演示独立同分布的抽取如何把这种相像撕碎。

下面的抽取来自NumPy的`numpy.random.default_rng`，版本$2.3.3$，以$61$为种子。独立同分布的下标是对那个生成器的一次`integers(0, 8, size=8)`调用。块的起点来自一个单独的生成器，重新以$61$为种子，调用`integers(0, 7, size=4)`，因为当$\ell = 2$时$M = 7$，而四个长度为$2$的块拼成一条长度为$8$的序列。下标从$0$开始，与生成器一致。重抽出的值都列在下面，因此不借助生成器也能核对这些均值。

:::example 一次独立同分布抽取与一次块抽取 {#ex-seed}
独立同分布的下标是$3, 2, 6, 6, 3, 5, 5, 5$。块的起点是$2, 2, 5, 5$。把两个重抽样都写出来，算出两个均值，再算出两个样本滞后1阶相关系数。
:::solution
$x$的下标$3$是$0.003$，下标$2$是$0.006$，下标$6$是$0.050$，下标$5$是$0.035$。独立同分布的重抽样是

$$
0.003,\ 0.006,\ 0.050,\ 0.050,\ 0.003,\ 0.035,\ 0.035,\ 0.035.
$$

它的和是$0.217$，均值是$0.217/8 = 0.027125$。它的样本滞后1阶相关是$-0.016687$。原来的相关是$0.720887$。一次独立同分布的抽取把它打到了一个在八个点的精度下与零无法区分的水准上。这正是[[#prop-iid]]在单个样本中的现身：分布的相关为零，而这次抽取恰好落在分布附近。换一个种子就会抖到别处去。命题说的是分布，而这个例子是从它抽出的一次抽取——用种子固定下来，好让这套算术可以复算。

从$0$开始编号的起点$2$，换成从$1$开始编号的说法，就是块$(x_3, x_4) = (0.006, 0.003)$。起点$5$是$(x_6, x_7) = (0.035, 0.050)$。按$2, 2, 5, 5$的顺序抽出这些起点，拼接得到

$$
0.006,\ 0.003,\ 0.006,\ 0.003,\ 0.035,\ 0.050,\ 0.035,\ 0.050.
$$

和是$0.188$，均值是$0.188/8 = 0.0235$，在这次特定的抽取里与原均值相同——而这并非靠那条无偏恒等式，那条恒等式对重叠块并不精确成立。拼接的样本滞后1阶相关是$0.718163$。它接近原来的$0.720887$。在每个块内部，原来的相邻被复制了下来，这就是[[#prop-pair]]。接缝——这次抽取里有三个——碰巧没有毁掉相关。它们并不欠着必须这么客气。对一个相依性恰为中间一处断裂的序列，块长取$2$，仍然可能在某个起点恰好落在断裂上时把两半搅在一起。这里的起点$2$与$5$都落在两半的内部，而重复抽到的块把它们原样再现了。

挑这个种子，是为了让两个相关系数构成的对照清楚可读：原序列大约$0.72$，块重抽样大约$0.72$，独立同分布重抽样大约$0$。均值的对照——$0.0235$比$0.027125$比$0.0235$——是真实的，但不是重点。在这个例子里，两个程序都冲着均值去，只因为均值容易相加。独立同分布程序的破坏落在相依性上，而均值不记录相依性。
:::
:::

:::example 七个块均值 {#ex-edge}
对同一个序列与$\ell = 2$，列出七个重叠块的块均值并求平均。
:::solution
这些块及其均值是

| 起点（从$0$开始编号） | 块 | 均值 |
|---:|---|---:|
| $0$ | $0.005, 0.004$ | $0.0045$ |
| $1$ | $0.004, 0.006$ | $0.0050$ |
| $2$ | $0.006, 0.003$ | $0.0045$ |
| $3$ | $0.003, 0.040$ | $0.0215$ |
| $4$ | $0.040, 0.035$ | $0.0375$ |
| $5$ | $0.035, 0.050$ | $0.0425$ |
| $6$ | $0.050, 0.045$ | $0.0475$ |

七个均值的和是$0.163$，而$0.163/7 = 0.0232857\ldots$，保留六位小数为$0.023286$。八个观测的样本均值是$0.0235$。这个差就是边缘效应：第一个与最后一个观测各坐在一个块里，中间六个观测各坐在两个块里。跨过断裂的那个块，起点$3$，它的均值$0.0215$把一个小收益率和一个大收益率混在了一起。抽到这个起点的自助法，复制的是断裂本身，而不是任何一个体制的内部。把七个块均值取平均，就是把那个跨断块与其他块等而视之。它不是任何东西的一个特别好的估计量。它是一个证据："抽重叠块"并不是"抽一个样本均值的无偏复制"的同义语。
:::
:::

:::example 重抽样无法产生的一个收益率 {#ex-support}
观测到的收益率是$0.01, 0.00, -0.01, 0.02$。后来的某一天产生了收益率$-0.10$。证明：由这四个观测出发的独立同分布自助样本与移动块自助样本，都不可能含有$-0.10$。可能出来的最小的数是多少？
:::solution
观测集合是$\{0.01,\ 0.00,\ -0.01,\ 0.02\}$。由[[#prop-support]]，每个重抽样的坐标都是这四个数之一。值$-0.10$不在其中，所以它在两个自助法分布之下的概率都是零。能观测到的最小重抽样值就是那个最小的观测，$-0.01$。

用这四个点的自助均值构成的一个区间，落在$\{0.01, 0.00, -0.01, 0.02\}$的诸平均的范围之内。那个区间可以很宽，因为样本很短。但它不会变成一个关于$-0.10$的区间。一个没有在样本中发生过的断裂，在支撑集之外——无论你重抽样多久。块长帮不上忙：块是一条从未含有$-0.10$的路径上的一块碎片。这是方法的局限，不是种子的缺陷。从同一条路径取出的走步验证折——[[validation/walk-forward]]中讨论过——共有这一局限。它们重排并扣留同一段历史的碎片。它们补不上这段历史漏掉的那次崩盘。
:::
:::

:::example 独立同分布分布如何对待一个正相关 {#ex-law}
序列$x$的样本滞后1阶相关是$0.720887$。不抽取任何样本，说出独立同分布自助法分布的滞后1阶相关，并说出一枚均匀抽出的、长度为$2$的重叠块的相关。
:::solution
对独立同分布分布，[[#prop-iid]]给出$\Corr^\star(X_t^\star, X_{t-1}^\star) = 0$，因为不同的抽取相互独立、八个数不全相等，所以自助方差为正。[[#prop-pair]]给出一枚均匀抽出的相邻配对的相关等于$x$的样本滞后1阶相关，即$0.720887$。两个答案——$0$与$0.720887$——是两个分布的性质。[[#ex-seed]]是每个程序各一次抽取，其中实现出来的样本相关是$-0.016687$与$0.718163$。实现出来的数字被允许偏离分布。在这个种子上，它们偏离得不多。
:::

小工具从一个总体里抽出独立的复制。自助法从一个样本里抽出复制。画在小工具上方的那条正态曲线，是中心极限定理对相互独立的各项之平均给出的近似。它是当$n$增大时关于独立模型的三角阵的一则陈述。它不是关于从单条金融路径拼出的块拼接的陈述，而本章不为它提供任何证明。当路径带有波动聚集时，一个均值真正有关的方差，不是把边际$\sigma^2$代入得到的$\sigma^2/n$。相依性改变和的方差。块自助法是一种尝试：让样本在块内部自己携带这个变动，而不写下一个方差公式。它能成功到什么程度，取决于块看起来有多像人们将会再次面对的那种相依性。[[#prop-support]]就是这句话上的硬性止步。

:::warning 这个区间以一条历史为条件
自助法的百分位区间报告的是一个统计量在已观测序列的各次重抽样之间的散布。它不报告一个没有贡献任何观测的体制的概率。它撤销不了一场搜索：如果这条序列本身就是二十条规则中最佳者的盈亏，那么对这条序列做重抽样，就是把赢家当作事先指定过的。对付那场搜索的补救，是把搜索放进重抽样内部——这正是[[statistics/testing-and-snooping]]里怀特（White）现实检验的思想——而不是只对赢家做自助法，然后称这个区间诚实。在看到区间之后再挑$\ell$，是一场追加的搜索。
:::

:::intuition 长度1对阵长度$\ell$
一次独立同分布的抽取问样本：出现过哪些值？然后把顺序忘掉。一次块抽取问：出现过哪些短路径？[[#ex-seed]]是同样这八个数在两个问题之下的样子。均值动了一点。滞后1阶相关没有：其中一个被毁掉，另一个被保住。在一个你真的愿意称之为弱相依的序列里，一条关于均值的论断，也许经受得住独立同分布这个简化。一条关于持续性的论断——[[trend/the-trend-hypothesis]]所指的那种——在[[#prop-iid]]之下连被听一听的机会都没有，因为在任何区间造出来之前，自助法分布就已经把相关设成了零。
:::

:::application 这个区间是干什么用的
用得小心时，块自助法区间是这样一种办法：当相依性是局部的、而块长既长到足以罩住它、又短到能留下不止一个块时，它给一个事先指定的统计量——一个均值、一个滞后1阶相关、一个定义提前定好的夏普比率——配上一个抽样散布。这个散布是以已观测路径为条件的。它让一个论断变得更宽。它不能拿另一个十年、另一个标的范围或另一种成本来确认这个论断。走步验证扣留的是同一条路径的较后切片，它回答的是另一个问题：一条在较早切片上冻结的规则，在较后切片上还能得分吗。两者都是单段历史的程序。把这一点说出来，是报告它们的一部分。
:::

:::remark 种子是例子的一部分，不是方法的一部分
下标$3, 2, 6, 6, 3, 5, 5, 5$与起点$2, 2, 5, 5$是一次抽取。另一个种子会产生另一对序列。那些命题才是不依赖种子的部分。把$0.027125$当作这个序列的"那个"独立同分布自助均值来引用，会与把一条回测路径当作一个参数来引用是同一个错误。它不过是这个种子碰巧抽出的那次重抽样的均值。那个均值在独立同分布分布之下的自助期望是$0.0235$，见[[#prop-iid]]，而那条恒等式不需要任何种子。
:::

:::history
2000年，怀特（White）给出了一个自助法检验：当搜索本身被计入之后，一部长目录中的最佳规则是否胜过一个基准。那个检验里的重抽样，是对日期的重抽样，且把每个日期上所有规则的结果保持在一起，从而最大值在每次重抽样内部被重新计算。本章的独立同分布构造与块构造，是它底下更简单的对象：一条序列如何被重新拼出，以及重拼对一个滞后做些什么。怀特的检验不是一条库里的回测，它没有在上面那个编造序列上跑过，也不会把一个均值为$0.0235$的序列提升成一条规则。
:::

## 通向何处

一个正相依在中间期限上是关于市场的事实、而不是关于某一个自助世界的事实——这个假说见[[trend/the-trend-hypothesis]]。留出单段历史的较后切片——自助法并不做这件事——见[[validation/walk-forward]]。至少一次错误拒绝的概率——对赢家的自助法并不能把它去掉——见[[statistics/testing-and-snooping]]。体制，以及这条警告——平静天气里抽出的块不含任何从未被观测到的压力——见[[statistics/stationarity-and-regimes]]。

:::summary
- 独立同分布自助样本从经验集合中独立地抽取观测值。它对样本均值的期望等于样本均值。它在不同位置之间的相关为零。
- 长度为$\ell$的重叠块是一段连续的片段。这样的块有$n - \ell + 1$个。移动块自助法拼接随机选出的块，并裁剪到长度$n$。
- 一枚均匀抽出的、长度为$2$的块，其相关等于样本滞后1阶相关。独立同分布分布的相关为零。这两个程序对相邻之事意见相反。
- 在那个编造的八点序列上——均值$0.0235$、滞后1阶相关$0.720887$——种子$61$给出了一个均值为$0.027125$、相关为$-0.016687$的独立同分布重抽样，以及一个均值为$0.0235$、相关为$0.718163$的块重抽样。
- 重叠块给样本中段比给两端更多的权重。在这个序列上，七个块均值的平均约为$0.023286$，不是$0.0235$。
- 每个重抽样的坐标都是一个观测值。一个尚未发生的断裂在区间的支撑集之外。
- 中心极限定理的那条正态曲线是另一个定理，在别处证明，讲的是独立抽取。它不是一个自助法区间的证明。
:::

## 习题

:::exercise 均值的自助期望 {#exr-mean level=1 check="3"}
观测样本是$1, 3, 5$。独立同分布自助法之下的$\E^\star[\bar X^\star]$是多少？（输入期望。）
:::solution
由[[#prop-iid]]，重抽样均值的自助期望等于样本均值。样本均值是$(1+3+5)/3 = 3$。期望是$3$。
:::
:::

:::exercise 有多少个块 {#exr-count level=1 check="7"}
一个序列长度为$8$，块长为$2$。有多少个重叠块？（输入个数。）
:::solution
[[#def-block]]给出$M = n - \ell + 1 = 8 - 2 + 1 = 7$。有$7$个重叠块。
:::
:::

:::exercise 给定种子的独立同分布均值 {#exr-iidmean level=1 check="0.027125"}
[[#ex-seed]]中的独立同分布重抽样是$0.003, 0.006, 0.050, 0.050, 0.003, 0.035, 0.035, 0.035$。计算它的均值。（输入均值。）
:::solution
和是$0.003 + 0.006 + 0.050 + 0.050 + 0.003 + 0.035 + 0.035 + 0.035 = 0.217$。均值是$0.217/8 = 0.027125$。均值是$0.027125$。
:::
:::

:::exercise 给定种子的块均值 {#exr-blockmean level=2 check="0.0235"}
[[#ex-seed]]中的块拼接是$0.006, 0.003, 0.006, 0.003, 0.035, 0.050, 0.035, 0.050$。计算它的均值。（输入均值。）
:::solution
和是$0.006 + 0.003 + 0.006 + 0.003 + 0.035 + 0.050 + 0.035 + 0.050 = 0.188$。均值是$0.188/8 = 0.0235$。均值是$0.0235$，在这次抽取里等于原始样本均值。
:::
:::

:::exercise 要抽多少个块 {#exr-k level=2 check="4"}
一条长度为$12$的序列要用$\ell = 3$的移动块自助法重新拼出，而$3$整除$12$。[[#alg-block]]要抽多少个块？（输入个数。）
:::solution
因为$\ell$整除$n$，算法抽$n/\ell = 12/3 = 4$个块，而拼接结果已经长度为$12$。它抽$4$个块。
:::
:::

:::exercise 一个端点 {#exr-end level=2 check="1"}
在$n = 8$、$\ell = 2$时，第一个观测出现在多少个重叠块里？（输入个数。）
:::solution
长度为$2$的块只有在起点就是第一个观测时才包含第一个观测。任何更晚的起点都从第二个观测或更晚处开始。第一个观测出现在$1$个块里。沿整条序列，各位置的出现次数是$1, 2, 2, 2, 2, 2, 2, 1$。
:::
:::

:::exercise 为什么独立同分布的相关系数为零 {#exr-corr level=3}
证明：在[[#def-iid-boot]]之下，若观测值不全相等，则两个不同坐标的自助相关为零。
:::hint
不同的抽取依构造独立。独立给出零协方差。相关系数的分母为正，恰恰是因为各值不全相等。不要把自助法分布之下这个总体相关，与一次重抽样的样本相关混为一谈。
:::
:::solution
固定$t \neq s$。坐标$X_t^\star$与$X_s^\star$相互独立，且各自在观测样本上服从离散均匀分布，所以每个的期望都是$\bar x$、方差都是$n^{-1}\sum_i (x_i - \bar x)^2$。独立性给出$\Cov^\star(X_t^\star, X_s^\star) = 0$。方差为正，因为并非所有$x_i$都相等：否则每个偏差的平方都会是零。因此相关是$0/(\text{正数}) = 0$。这既是[[#prop-iid]]的滞后1阶情形，也适用于其他每一个滞后。它并不是说一次长度为$n$的重抽样会有恰为零的样本相关。[[#ex-seed]]落在了$-0.016687$，那是相关为零的一个分布之下的一个样本相关。
:::
:::

:::exercise 支撑集之外 {#exr-support level=3 check="-0.01"}
观测收益率是$0.01, 0.00, -0.01, 0.02$。作为一个独立同分布或移动块自助样本的坐标，可能出现的最小的值是多少？（输入那个值。）
:::hint
[[#prop-support]]说每个重抽样坐标都是某个观测收益率的复制。因此重抽样中的最小坐标就是那个最小的观测，而不是比它更小的某个数。
:::
:::solution
观测值是$0.01$、$0.00$、$-0.01$与$0.02$。最小的是$-0.01$。自助坐标等于四者之一，所以它不可能小于$-0.01$；而当被抽到的正是那个观测、或含它的块正是被抽到的那个块时，它就可以等于$-0.01$。假想中后来出现的收益率$-0.10$在支撑集之外。可能出来的最小的值是$-0.01$。
:::
:::
