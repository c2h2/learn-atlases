价格可以一走不返，永远安定不到某个均值附近。单一步长上的收益率是另一个序列，而对它的建模常常假设它的均值与方差静止不动。这个模型可能在一种精确的意义上是错的：大幅波动成群地到来，而一段平静日子里估出的相关系数未必能描述下一段日子。一个两状态的链，是关于这种成群而至所能有的最小图景。一个根据整个样本判断哪些日子是压力日子的滤波器，是另一个被搜索过的参数，而不是第二次独立的实验。

平稳分布底下的那套概率，证明在数学图谱的[马尔可夫链](/learn/maths/lesson.php?c=probability&l=markov-chains)里。本章只解一个$2 \times 2$的方程组，并说明这个解不许裁决什么。这里没有任何结果构成这样一种建议：当一个状态标签翻转时就调动资金。

## 价格水平不是收益率

宽平稳性是关于我们对一个序列的假设，不是对一个拟合得好的模型的夸奖。

:::definition 宽平稳性 {#def-stationary}
设收益率序列$(R_t)$满足以下三条，则称它是**宽平稳**的。均值$\E[R_t]$有限，且不依赖于$t$。方差$\Var(R_t)$有限，且不依赖于$t$。协方差$\Cov(R_t, R_{t-k})$有限，且只通过滞后$k$依赖于这一对日期。从一个方差有限的分布中独立抽取，是宽平稳的。一个序列可以是宽平稳的而仍然相依：滞后$k$处的协方差允许非零，条件是把整对日期沿日历整体平移时它不改变。
:::

[[statistics/moments-and-dependence]]里的滞后1阶相关，只有在这类假设之下才有一个总体值。没有它，$\Cov(R_t, R_{t-1}) / \Var(R_t)$会随$t$漂移，而一个样本数字就成了对一个移动目标取的平均。

这种假设若去价格里找，就找错了地方。

:::definition 随机游走价格 {#def-rw}
设$\varepsilon_1, \varepsilon_2, \ldots$相互独立，满足$\E[\varepsilon_t] = 0$且$\Var(\varepsilon_t) = \sigma^2$，其中$\sigma^2 > 0$有限，并设$P_0$是一个常数。**随机游走价格**

$$
P_t = P_0 + \varepsilon_1 + \cdots + \varepsilon_t
$$

是这个价格水平的一个单位根模型。增量$\Delta P_t = P_t - P_{t-1} = \varepsilon_t$于是独立于过去且宽平稳。简单收益率$P_t/P_{t-1} - 1 = \varepsilon_t / P_{t-1}$则不是$\varepsilon_t$的一个独立复制，因为分母记住了路径。
:::

把一个价格称作随机游走，与把一个收益率称作随机游走，是两句话。前一句说的是价格水平由冲击累加而成。后一句说的是冲击本身没有记忆。简单收益率要除以一个价格，所以即便是价格水平上一个纯粹的随机游走，也不会白送给你相互独立的简单收益率。

:::proposition 随机游走价格的方差 {#prop-var-rw}
在[[#def-rw]]之下，对每个$t \ge 1$有$\E[P_t] = P_0$且$\Var(P_t) = t\,\sigma^2$。随机变量族$(P_t)_{t \ge 0}$不是宽平稳的，因为方差依赖于$t$。
:::

:::proof
和的期望是期望的和，所以$\E[P_t] = P_0 + \sum_{i=1}^t \E[\varepsilon_i] = P_0$。至于方差，增量的独立性正是允许方差相加的那个假设：对$i \neq j$，$\varepsilon_i$与$\varepsilon_j$之间没有协方差项。每个增量贡献$\sigma^2$，而这样的增量有$t$个，所以$\Var(P_t) = t\,\sigma^2$。价格水平的宽平稳会要求$\Var(P_t)$对每个$t$都是同一个数。$t$的严格增函数不是常数。一阶差分$\varepsilon_t$确实满足定义：它的均值与方差不依赖于$t$，而由独立性，它在每个非零滞后上的协方差为零。

若把假设放宽为增量不相关而非独立，同样的相加仍然成立。[[#def-rw]]里写出的独立是更强的假设，比方差公式所需要的更多。它不是一个可以偷偷搬回简单收益率的假设。
:::

这条命题里没有任何东西是一个检验。单位根统计量有一个非标准的零分布，而本章不会为路径A或任何一条库里的序列发明一个P 值。路径A的价格在七步之内从$100$走到$110$。那条路径很短、在上涨，而在七个点上未能拒绝一个单位根，会与拒绝一样没有信息量。这条命题是一个检验所要瞄准的总体事实：如果价格水平是这种形式的随机游走，它的方差就随步数成正比地增长，因此从一张价格图上算出的样本方差，是若干彼此不可比的对象之上的方差。

:::example 公平步，逐一枚举 {#ex-enum}
设每个增量以等概率$1/2$取$+1$或$-1$，相互独立，且$P_0 = 100$。这就是[[#def-rw]]取$\sigma^2 = 1$。按定义枚举$\Var(P_2 - P_0)$与$\Var(P_3 - P_0)$：在等可能的结果上，对和的平方取平均。
:::solution
$t = 1$时，两个结果是$+1$与$-1$，概率都是$1/2$。均值为$0$，平方均值为$1 = 1 \cdot \sigma^2$。

$t = 2$时有四个结果，$(+1,+1)$、$(+1,-1)$、$(-1,+1)$、$(-1,-1)$，和为$2, 0, 0, -2$。和的平均为$0$。平方均值为$(4 + 0 + 0 + 4)/4 = 2$，即$t\sigma^2$。

$t = 3$时有八个结果。和及其重数为$+3$（一种）、$+1$（三种）、$-1$（三种）与$-3$（一种）。均值为$0$。平方均值为

$$
\frac{1}{8}\bigl(9 + 3 \times 1 + 3 \times 1 + 9\bigr) = \frac{24}{8} = 3,
$$

又是$t\sigma^2$。一条实现的路径，比如$101, 100, 101$，单凭自身并不显示数字$3$。[[#prop-var-rw]]里的方差是对路径取的平均。一张价格图只是一条路径。它的样本方差不是$t\sigma^2$；看着它游走也不是对$\sigma^2$的测量——除非有一个模型能把这张图变回一个平均。
:::
:::

:::quiz
在[[#prop-var-rw]]且$\sigma^2 = 1$之下，哪个序列可以是宽平稳的？
- [ ] 价格$P_t$，因为它的均值$P_0$不依赖于$t$。
- [ ] 价格$P_t$，因为假设了独立增量。
- [x] 增量$\varepsilon_t$，但价格不行。
- [ ] 简单收益率$\varepsilon_t / P_{t-1}$，自动成立，因为增量是平稳的。
:::solution
$P_t$的均值是常数，而方差$t\sigma^2$不是，所以价格不满足[[#def-stationary]]。增量满足定义。除以$P_{t-1}$会得到一个新序列，它的方差仍然取决于价格水平走出了多远，而那条命题并没有把这个序列称为平稳。
:::
:::

## 聚集

平稳的增量仍然可能是收益率的错误模型。收益率序列里的常见失效，不是方差像$t$那样增长，而是方差本身有持续性：一个大波动之后跟着一个大波动，而符号尽可以相互抵消。

:::definition 波动聚集 {#def-cluster}
当$\abs{R_t}$的大值之后往往跟着$\abs{R_{t+1}}$的大值时——其含义是$(\abs{R_t})$、或$(R_t^2)$的滞后1阶相关为正，哪怕$(R_t)$本身的滞后1阶相关接近零或为负——就称这个收益率序列显示出**波动聚集**。取绝对值与平方是把符号丢掉、把幅度留下。聚集是一个关于幅度的相依性假设。它不是第二个均值。
:::

下一个例题里的样本相关系数，就是[[statistics/moments-and-dependence]]里的配对相关。它们是对一个构造序列的样本内描述。绝对值收益率的相关为正与宽平稳是相容的：定义允许固定滞后上的协方差非零。聚集所打破的，是那个更强的习惯——把方差当作一个可以估上一次、然后就从此相信的常数。一个恒定的无条件方差，可以与一个会动的条件方差并存。无条件方差是对平静日子与压力日子取的平均。一条只经历过其中一种体制的规则，并不住在这个平均里。

:::example 符号相消，幅度延续 {#ex-cluster}
设构造序列（以收益率单位计）为

$$
0.01,\ -0.01,\ 0.01,\ -0.01,\ 0.05,\ -0.05,\ 0.05,\ -0.05.
$$

它不是路径A，也不是市场。计算这个序列以及它的绝对值的样本滞后1阶相关系数。
:::solution
带符号的序列每一步都交替，而且它还改变尺度：四个小收益率，然后四个大收益率。带符号序列的样本滞后1阶相关系数是$-0.934199$。相邻带符号收益率的乘积为负，相关系数记录下了这一点。

绝对值是$0.01, 0.01, 0.01, 0.01, 0.05, 0.05, 0.05, 0.05$。它们的样本滞后1阶相关系数恰为$3/4 = 0.75$。相邻的幅度彼此一致：前半段里小跟着小，后半段里大跟着大。跨过断点的那一个配对$(0.01, 0.05)$，不足以把相关系数拉回零。

于是带符号序列看上去像强一步反转，而幅度序列看上去像持续。用全部八个点算出的一个方差，把两种尺度混在了一起。一条只用符号的单日规则，和一条用滚动方差定头寸规模的规则，读的是同样这八个数的两个不同相关系数。这两个相关系数都不是可以搬用的参数。它们之所以都大，是因为这个序列就是照着让它们大来构造的，而且只有七个配对。
:::
:::

## 两个体制

马尔可夫链是这样一个模型：下一个状态只通过当前状态依赖于过去。这里用到的链有两个状态，平静与压力，以及课程小工具图中的那张转移矩阵，

$$
P = \begin{pmatrix} 0.85 & 0.15 \\ 0.30 & 0.70 \end{pmatrix}.
$$

第一行是在链处于平静状态的条件下，下一个状态的条件分布。链以概率$0.85$留在平静，以概率$0.15$进入压力。第二行以概率$0.30$离开压力，以概率$0.70$留在压力。每一行都加起来等于$1$。这张矩阵是波动率体制的一幅草图。它不是从路径A估计出来的，也不是对任何一条实际交易的序列的预测。

若概率行向量$\pi = (\pi_{\mathrm{c}}, \pi_{\mathrm{s}})$满足$\pi P = \pi$且$\pi_{\mathrm{c}} + \pi_{\mathrm{s}} = 1$，且两个坐标都非负，则称它是**平稳**的。如果链从$\pi$出发，那么它在之后每一个时刻的分布都是$\pi$。数学图谱证明了：一个每个状态都能到达其他每个状态的有限链，恰有一个这样的分布。这张$P$的每个元素都是正的，所以平静一步可达压力，压力一步可达平静。唯一性适用。下面的代数找出这个分布。它不重新证明唯一性。

:::proposition 两状态草图的平稳分布 {#prop-pi}
对上面的矩阵$P$，唯一的平稳分布是

$$
\pi_{\mathrm{c}} = \frac{2}{3}, \qquad \pi_{\mathrm{s}} = \frac{1}{3}.
$$
:::

:::proof
唯一性就是数学图谱里的有限不可约情形，它适用是因为每个转移概率都是正的。剩下的只是把$\pi P = \pi$与$\pi_{\mathrm{c}} + \pi_{\mathrm{s}} = 1$联立求解。$\pi P = \pi$的第一个坐标读作

$$
\pi_{\mathrm{c}} = 0.85\,\pi_{\mathrm{c}} + 0.30\,\pi_{\mathrm{s}}.
$$

整理得：$0.15\,\pi_{\mathrm{c}} = 0.30\,\pi_{\mathrm{s}}$。这就是两个状态之间的流量平衡。代入$\pi_{\mathrm{s}} = 1 - \pi_{\mathrm{c}}$：

$$
0.15\,\pi_{\mathrm{c}} = 0.30\,(1 - \pi_{\mathrm{c}}) = 0.30 - 0.30\,\pi_{\mathrm{c}}.
$$

两边加上$0.30\,\pi_{\mathrm{c}}$：$0.45\,\pi_{\mathrm{c}} = 0.30$，于是$\pi_{\mathrm{c}} = 0.30/0.45 = 2/3$且$\pi_{\mathrm{s}} = 1/3$。

要核对第二个坐标，而不是假定行和约束在算术里已经让它多余。第二个方程是$\pi_{\mathrm{s}} = 0.15\,\pi_{\mathrm{c}} + 0.70\,\pi_{\mathrm{s}}$。右端是

$$
0.15 \times \frac{2}{3} + 0.70 \times \frac{1}{3} = \frac{0.30}{3} + \frac{0.70}{3} = \frac{1}{3},
$$

等于$\pi_{\mathrm{s}}$。两个平稳方程都成立，而坐标加起来等于$1$。

同样的代数就是细致平衡。从平静到压力的流量是$\pi_{\mathrm{c}} \times 0.15 = (2/3) \times 0.15 = 0.10$。从压力到平静的流量是$\pi_{\mathrm{s}} \times 0.30 = (1/3) \times 0.30 = 0.10$。两个流量吻合。细致平衡在数学图谱里是平稳性的一个充分条件；在这里它是对这些分数的一次校验，不是第二次推导。
:::

平稳质量不是一次停留的长度。从平静出发，链每一步都以概率$0.15$离开，且与它已经停留了多久无关，因为转移概率只依赖当前状态。因此一次平静停留的长度$L$满足$\Prob(L = k) = 0.85^{k-1} \times 0.15$，$k = 1, 2, \ldots$，而

$$
\E[L] = \frac{1}{0.15} = \frac{20}{3} \approx 6.667
$$

步。一次压力停留的平均长度是$1/0.30 = 10/3 \approx 3.333$步。长期中处于平静的那些步的比例，是一个典型周期里花在平静上的份额，

$$
\frac{20/3}{20/3 + 10/3} = \frac{20}{30} = \frac{2}{3},
$$

与$\pi_{\mathrm{c}}$一致。这种一致是一个有用的校验。它不是任何理由，让你把一个自己并未建模的日期上"市场是平静的"的概率当成$2/3$。

:::example 从压力出发两步 {#ex-two-step}
链从压力出发，所以第$0$步的分布是$(0, 1)$。求两步之后的分布，以及在那个期限上处于平静的概率。
:::solution
从压力出发一步是$P$的第二行，即$(0.30, 0.70)$。两步需要$P^2$的第二行。计算

$$
P^2 = \begin{pmatrix} 0.85 & 0.15 \\ 0.30 & 0.70 \end{pmatrix}
\begin{pmatrix} 0.85 & 0.15 \\ 0.30 & 0.70 \end{pmatrix}
= \begin{pmatrix} 0.7675 & 0.2325 \\ 0.4650 & 0.5350 \end{pmatrix}.
$$

第二行是从压力出发两步之后的分布：平静的概率是$0.465$，压力的概率是$0.535$。同一行也是$(0, 1)\, P^2$。平稳分布是$(2/3,\ 1/3) \approx (0.667,\ 0.333)$。两步之后，链已经从$(0, 1)$朝着那一行移动，但还没有到达。如果从平静出发，$P$的第一行是$(0.85, 0.15)$，而$P^5$的第一行约为$(0.683, 0.317)$，又近了一些。下面的图就画出这种逼近。图中一条模拟的路径不是那个分布，而那个分布也不是对一条从未被声称服从$P$的价格序列的预测。
:::
:::

:::example 一个长期计数 {#ex-count}
假设链已经从它的平稳分布出发运行。在$300$步里，期望有多少步落在平静里？有多少步落在压力里？
:::solution
第$t$步处于平静这一示性变量的期望，由平稳性，对每个$t$都是$\pi_{\mathrm{c}} = 2/3$。期望的线性性给出

$$
\E[\text{平静步数}] = 300 \times \frac{2}{3} = 200,
$$

而压力步的期望个数是$300 \times 1/3 = 100$。两个计数加起来是$300$。这是模型之下的一个期望，不是对某个给定的$300$步窗口含有$200$个平静步的承诺。计数的方差是正的，因为停留会持续好几步：平静期平均长$20/3$步，所以这$200$个平静步到来的串数更少、每串更长，而不是像在相同概率$2/3$的独立每日抛硬币之下那样。状态自身的聚集恰恰就是这份额外的成团性。期望看不见它。一个假定各天独立的样本方差也看不见它。
:::
:::

:::example 用整个样本算出的中位数 {#ex-median}
编造的收益率$0.01, 0.01, 0.05, -0.04$：当其绝对值超过这四个绝对值的样本中位数时被标注为"压力"，否则标注为"平静"。采用这样的约定：四个数的样本中位数，是依序排列的第二与第三个数的平均。哪些日期被标为压力？而第一个日期的标签，为什么在第一个日期拿不到？
:::solution
绝对值是$0.01, 0.01, 0.05, 0.04$。依序排列为$0.01, 0.01, 0.04, 0.05$。中位数是$(0.01 + 0.04)/2 = 0.025$。严格高于$0.025$的日子是第三天（绝对收益率$0.05$）与第四天（绝对收益率$0.04$）。这两个日期被标为压力。前两个被标为平静。

中位数$0.025$用到了第三个与第四个绝对收益率。因此第一个日期的标签取决于在第一个日期尚未发生的价格。一条以这个标签为条件的规则，用的是未来。把全样本中位数替换成严格早于决策日的绝对收益率的中位数，能去掉这一处具体的泄漏。但如果阈值、窗口，或者干脆"要不要用中位数"这个决定，都是因为标注之后的回测好看才被选定的，它就消不掉那场搜索。那场搜索就是下面的警告。
:::
:::

:::widget markov
matrix: 0.85,0.15; 0.30,0.70
states: Calm; Stress
steps: 24
caption: 两状态草图。平静上的平稳质量是2/3，压力上是1/3，无论起点是哪一个。一条模拟路径是一次抽取，不是那个分布，而这张矩阵是演示性的，不是估计出来的。
:::

:::warning 在样本内拟合的体制滤波器是另一个被搜索过的参数
挑选一个阈值、一个概率或一个窗口，好让平静子样本与压力子样本讲出一个干净的故事，是一场对规则的搜索。[[statistics/testing-and-snooping]]已经把那场搜索计入过。在随后被用来夸奖这个滤波器的同一个样本上估计$P$，是把样本花了两遍。一个使用全样本中位数的标签，如[[#ex-median]]那样，在单个日期之内就把它花了两遍：一次用来形成标签，一次用来给收益率计分。样本之外，链可以走到一个从未被见过的转移概率上。上面算出的平稳分布，无法描述两状态草图漏掉的第三个状态。
:::

:::intuition 水平会游走，增量未必，方差却仍可能
三个层层嵌套的错误，很容易按顺序犯下。第一个是把一张价格图当作平稳序列，并且为"价格"报出一个方差——而[[#prop-var-rw]]说，随机游走的方差随$t$增长。第二个是对价格做差分、或者改看收益率，然后把结果当作独立噪声。第三个是注意到聚集，并作出这样的回应：在同一段历史上拟合一条体制规则，而带着一道从未为这次拟合收过费的门槛。第一个错误夸大了水平的作用。第二个低估了幅度的相依性。第三个把对聚集的描述变成了一个过拟合的状态机。在描述之后收手，是允许的。
:::

:::application 一个状态允许改变什么
在这幅草图内部，一个状态可以改变下一个收益率的条件分布。一个条件方差收紧的平静状态，配一个条件方差放大的压力状态，是通常的故事，而[[#ex-cluster]]就是一个玩具：其中的绝对值收益率恰好如此，却没有任何一张被估计的矩阵。平稳权重$2/3$与$1/3$是这个模型的长期混合。对一个条件性的问题来说，它们是错误的权重。一个在已知链处于压力时做出的决定，应当使用压力那一行：它的一次停留平均为$10/3$步，而它一步之后仍在压力的概率是$0.70$。用$\pi$而不用当前那一行，就把这个模型建立起来所要携带的那个状态扔掉了。使用一个用未来数据标注的状态——如[[#ex-median]]那样——则无论条件的问题还是长期的问题，一个也答不上。
:::

:::remark 停留时间与平稳质量回答的是不同的问题
一次平静停留的平均长度是$20/3$步。平静的平稳概率是$2/3$。这两个数都不是"从一个已知的起点出发有限步之后处于平静"的概率：[[#ex-two-step]]给出的是压力之后两步的$0.465$，不是$2/3$。数学图谱里的平均返回时间，即倒数$1/\pi_{\mathrm{c}} = 3/2$，把每一个仍然留在平静的步都算作一次回到平静。它不是一次停留的长度。把$1.5$当作"平静持续多久"来引用，是把这些定义混为一谈。停留长度是$1/(1 - 0.85) = 20/3$。
:::

:::history
1900年，路易·巴舍利耶（Louis Bachelier）把一只法国政府债券的价格建模为随机游走；那篇博士论文是投机价格之数学理论的开端。在那个模型里具有独立增量的对象，是价格的变化；不是每一个十年里都保持不变的方差，也不是一个事后拟合的两状态滤波器。[[#prop-var-rw]]就是位于价格水平的随机游走之下那个初等的方差计算。聚集，以及矩阵$P$，则是对"一个收益率序列以种种方式拒绝成为那些独立增量"的较晚的描述。巴舍利耶的博士论文不是一条体制规则，而平稳分布$2/3,\ 1/3$也不是1900年的成果。
:::

## 通向何处

对一个有聚集的序列做重抽样、又不把聚集撕碎，见[[statistics/resampling]]。聚集有意忽略的那个滞后1阶相关——带符号的那个——见[[statistics/moments-and-dependence]]。一折走步验证恰好落在一个体制内部，而与下一折一致只是因为体制没有变——这就是[[validation/what-a-fold-does-not-prove]]记录下的局限。$\pi$的存在性与唯一性，以及当链是非周期的时分布向$\pi$的收敛，留在数学图谱里。

:::summary
- 宽平稳性要求均值恒定、方差为有限常数，而协方差只通过滞后依赖于时间。
- 随机游走价格$P_t = P_0 + \sum_{i=1}^t \varepsilon_i$的方差是$t\sigma^2$。水平不是宽平稳的。增量可以是。简单收益率是又一个不同的序列。
- 波动聚集是$\abs{R_t}$或$R_t^2$的正的滞后1阶相依性。在那个构造的八点序列上，带符号的相关是$-0.934199$，绝对值的相关是$0.75$。
- 对$P = \begin{pmatrix} 0.85 & 0.15 \\ 0.30 & 0.70 \end{pmatrix}$，唯一的平稳分布是$(2/3,\ 1/3)$。一次平静停留平均持续$20/3$步，一次压力停留平均持续$10/3$步。
- 压力之后两步，平静的概率是$0.465$，不是$2/3$。平稳质量是一个长期混合，不是有限期限的预测。
- 一个使用全样本中位数的状态标签依赖于未来的收益率。一个阈值在样本内选定的体制滤波器，是另一个被搜索过的参数。
:::

## 习题

:::exercise 期限上的方差 {#exr-var level=1 check="4"}
在[[#prop-var-rw]]且$\sigma^2 = 1$之下，计算$\Var(P_4)$。（输入方差。）
:::solution
该命题给出$\Var(P_t) = t\sigma^2$。在$t = 4$处方差是$4$。均值仍是$P_0$。方差是$4$。
:::
:::

:::exercise 平稳质量 {#exr-pi level=1 check="2/3"}
对[[#prop-pi]]中的转移矩阵，平静的平稳概率是多少？（用分数输入概率。）
:::solution
平衡$0.15\,\pi_{\mathrm{c}} = 0.30\,(1 - \pi_{\mathrm{c}})$给出$0.45\,\pi_{\mathrm{c}} = 0.30$，于是$\pi_{\mathrm{c}} = 2/3$。平静的平稳概率是$2/3$。
:::
:::

:::exercise 一次压力停留的长度 {#exr-sojourn level=1 check="10/3"}
从压力出发，链每一步以概率$0.70$留在压力、以概率$0.30$离开。停留的期望长度是多少？（用分数输入期望。）
:::solution
停留长度服从离开概率为$0.30$的几何分布，所以它的期望是$1/0.30 = 10/3$。期望长度是$10/3$。这不是平稳概率，也不是$1/\pi_{\mathrm{s}} = 3$。
:::
:::

:::exercise 从压力出发两步 {#exr-twostep level=2 check="0.465"}
链从压力出发。两步之后处于平静的概率是多少？（输入概率。）
:::solution
由[[#ex-two-step]]，$P^2$的第二行是$(0.465, 0.535)$。平静的概率是$0.465$。它低于平稳质量$2/3$，因为两步不是长期。
:::
:::

:::exercise 另一张矩阵 {#exr-other level=2 check="4/5"}
设$Q = \begin{pmatrix} 0.9 & 0.1 \\ 0.4 & 0.6 \end{pmatrix}$，其中第一个状态称为平静。求平静的平稳概率。（用分数输入。）
:::solution
流量平衡给出$0.1\,\pi_{\mathrm{c}} = 0.4\,(1 - \pi_{\mathrm{c}})$，于是$0.1\,\pi_{\mathrm{c}} = 0.4 - 0.4\,\pi_{\mathrm{c}}$且$0.5\,\pi_{\mathrm{c}} = 0.4$。故$\pi_{\mathrm{c}} = 0.8 = 4/5$。与[[#prop-pi]]中相同的唯一性理由适用：每个元素都是正的。平稳概率是$4/5$。
:::
:::

:::exercise 绝对值的相关系数 {#exr-abs level=2 check="3/4"}
对绝对值$0.01, 0.01, 0.01, 0.01, 0.05, 0.05, 0.05, 0.05$，样本滞后1阶相关系数已在[[#ex-cluster]]中算出。用分数报告它。（输入这个分数。）
:::solution
这些绝对值的相关系数是$0.75 = 3/4$。把每个元素乘以$100$不会改变相关系数，而会还原出整数序列$1, 1, 1, 1, 5, 5, 5, 5$。相关系数是$3/4$。
:::
:::

:::exercise 随机游走方差的归纳法 {#exr-induct level=3}
在[[#def-rw]]的假设之下，用对$t$的归纳法证明$\Var(P_t) = t\sigma^2$。你可以使用：当$U$与$V$不相关时，$\Var(U + V) = \Var(U) + \Var(V)$，其中$U = P_{t-1}$、$V = \varepsilon_t$。
:::hint
基础情形$t = 1$是单个增量的方差。归纳步骤加上一个不相关的增量，因此加上的是$\sigma^2$，不是一个协方差。
:::
:::solution
对$t = 1$，$P_1 - P_0 = \varepsilon_1$且$\Var(P_1) = \sigma^2 = 1 \cdot \sigma^2$。设对某个$t \ge 2$有$\Var(P_{t-1}) = (t-1)\sigma^2$。增量$\varepsilon_t$独立于$\varepsilon_1,\ldots,\varepsilon_{t-1}$，从而与$P_{t-1} = P_0 + \varepsilon_1 + \cdots + \varepsilon_{t-1}$不相关。因此

$$
\Var(P_t) = \Var(P_{t-1} + \varepsilon_t) = \Var(P_{t-1}) + \Var(\varepsilon_t) = (t-1)\sigma^2 + \sigma^2 = t\sigma^2.
$$

由归纳法，公式对每个$t \ge 1$成立。同样的论证给出$\E[P_t] = P_0$，因为每个新增量的均值为零。这就是写成归纳法形式的[[#prop-var-rw]]。它仍然说不出任何关于简单收益率的东西，因为后者要除以$P_{t-1}$。
:::
:::

:::exercise 一个前视的中位数 {#exr-med level=3 check="0.025"}
对绝对收益率$0.01, 0.01, 0.04, 0.05$，用排序后第二与第三个数的平均计算样本中位数。然后说出一个中位数所依赖、但在第一个日期并不拿得到的绝对收益率。（输入中位数。）
:::hint
先给四个数排序，再取平均。让第一个日期的标签成为未来的函数的，正是较晚的那些日期，如[[#ex-median]]。
:::
:::solution
排序后的值已经是$0.01, 0.01, 0.04, 0.05$。第二个与第三个是$0.01$与$0.04$，它们的平均是$0.025$。中位数依赖于$0.04$，而当第一个收益率$0.01$是迄今唯一观测时，$0.04$并不在可得的信息之列。它还依赖于$0.05$。任一个较晚的值都足以说明这一点。一个以$0.025$为阈值区分平静与压力的标签，在第一个日期不是过去的函数。中位数是$0.025$。
:::
:::
