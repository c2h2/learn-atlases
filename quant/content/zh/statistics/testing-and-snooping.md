一个$t$统计量回答的，是在看到数字之前就已问出的那个问题。对二十条规则的一场搜索问了二十个问题，然后把赢家报告成好像它就是唯一的问题。这一分别的算术很小。它不依赖任何市场，也不是拿幸存下来的那条规则去交易的许可证。

单个检验的全套机器——零假设、水平、P 值，以及独立正态模型下的学生氏$t$分布——在数学图谱的[假设检验](/learn/maths/lesson.php?c=statistics&l=hypothesis-testing)中证明。本章把它特化到一个平均超额收益，然后推出若干条真零假设一起检验时至少出现一次错误拒绝的概率。怀特（White）的现实检验与因子动物园的警告以思想的形式陈述，不重新推导。

## 一个均值，一个检验

设$X_1,\ldots,X_n$是相对一个给定的无风险收益率的超额收益。在例题中无风险收益率为零，所以$X_t$就是简单收益率本身，而零假设说的是平均收益率为零。样本均值是$\bar X$，样本标准差$s$使用除数$n-1$。

:::definition 均值的$t$统计量 {#def-t}
零假设$\E[X] = 0$的**$t$统计量**为

$$
t = \frac{\bar X}{s / \sqrt{n}} = \frac{\bar X}{s}\sqrt{n},
$$

前提是$s > 0$。在附加假设——$X_1,\ldots,X_n$独立，且每一个都服从均值为零、方差相同的正态分布——之下，这个统计量服从自由度为$n-1$的学生氏$t$分布。一个水平为$\alpha$的双侧检验，在$\abs{t}$超过该分布的$1 - \alpha/2$分位数时拒绝。这个关于分布的论断，证明就是数学图谱里的那一个。本章不复述它。
:::

在查表之前把假设再读一遍。当收益率有自相关时独立性失效，而那正是[[statistics/moments-and-dependence]]的内容。当少数几次大变动主导了整个和时，正态性尤其会失效。统计量$t$仍然算得出来：它是一个缩放了平均数的均值。随假设一起失效的是参考分布。从$t_{n-1}$表里取的一个P 值，于是在真零假设之下并不是一个概率。厚尾与相依两者都倾向于让极端均值比表格所说的更常见，所以这张表格不是一个可以安全忽略的保守装饰。

水平$\alpha$是一个事先指定的检验的性质。除非例题另有说明，本章通篇默认$\alpha = 0.05$、双侧。在看到均值出来为正之后再改选单侧，是对同一个样本的第二次看。这被记录为一个选择，不是一种改进。

:::example 产生$t = 2$的均值 {#ex-t2}
超额收益$0.01, 0.01, 0.01, 0.05$是编造的，无风险收益率为零。计算$\bar X$、除数为$n-1$的$s$，以及$t$统计量。自由度为$3$的$t$分布的双侧$5\%$临界值保留三位小数为$3.182$，它取自那个参考分布，而不是取自这四个数。如果假装独立正态模型成立，检验会拒绝吗？
:::solution
均值是$(0.01 + 0.01 + 0.01 + 0.05)/4 = 0.08/4 = 0.02$。相对$0.02$的偏差是$-0.01, -0.01, -0.01, +0.03$。平方和是$3 \times 0.0001 + 0.0009 = 0.0012$。用除数$n-1 = 3$，

$$
s^2 = 0.0012 / 3 = 0.0004, \qquad s = 0.02.
$$

标准误是$s/\sqrt{n} = 0.02 / 2 = 0.01$，所以$t = 0.02 / 0.01 = 2$。由于$\abs{2} < 3.182$，在独立正态模型之下，水平$0.05$的双侧检验不拒绝零假设。均值为正，统计量是大家熟悉的"大约二"，而三个自由度上的临界值仍然比$2$更靠外。从正态$z$检验——其双侧$5\%$点是$1.96$——继承来的那条经验法则，对$n = 4$是错误的参照。这四个收益率仍然是一个编造的样本。不拒绝不是真实均值为零的证据；这句话的意思是：当样本这样短、模型又被准予时，这么大的均值在零假设之下并不出人意料。
:::
:::

:::example 假设之下的路径A {#ex-path-t}
路径A有七个简单收益率，样本均值$0.013930$，除数为$n-1$的样本标准差$0.022848$。无风险收益率取零。把$t$统计量算到三位小数。$t_6$参考分布的双侧$5\%$临界值保留三位小数为$2.447$。这个比较允许什么？而这条路径的交替又禁止什么？
:::solution
标准误是$0.022848 / \sqrt{7}$。由于$\sqrt{7} \approx 2.64575$，标准误约为$0.008636$，于是

$$
t = 0.013930 / 0.008636 \approx 1.613.
$$

从精确价格比率出发得到同样的三位小数，其均值与标准差舍入后就是这里用到的这些数。因为$1.613 < 2.447$，如果准予独立正态模型，双侧检验在水平$0.05$上不拒绝零均值。

这项准予在这条路径上是假的。七个收益率符号交替，而[[statistics/moments-and-dependence]]中算出的滞后1阶相关是$-0.953430$。扰动不是独立抽取的。$t_6$的P 值，在那个假设之下约为$0.16$，不是一个可以附在路径A上的概率。这套算术中有用的部分是尺度：均值在零以上$1.613$个标准误处，而七个观测留下的标准误足够大，以至于在承认相依之前，这个均值就已经越不过一道常规的双侧门槛。在看到均值为正之后选择单侧检验，会把$2.447$换成单侧$5\%$点$1.943$，而$1.613$仍然够不到。而仅仅因为均值出来为正才做这个选择，则另算一次对同一样本的第二次看。
:::
:::

:::quiz
在独立正态模型下，零均值的双侧$t$检验在水平$0.05$上于哪个事件发生时拒绝？
- [ ] 样本均值为正。
- [ ] 在备择假设下算出的P 值低于$0.05$。
- [x] 绝对值$t$统计量超过[[#def-t]]中指明的$t_{n-1}$分布的$1 - \alpha/2$分位数，其中$\alpha = 0.05$。
- [ ] 样本标准差低于样本均值。
:::solution
水平是在零假设之下算出的概率，而[[#def-t]]中的拒绝域是一个关于$\abs{t}$的尾部陈述。均值为正不够：四点例题的均值为正、$t = 2$，它在三个自由度上不拒绝。P 值是在零假设下算的，不是在备择假设下算的。
:::
:::

## 许多条真零假设

一个水平$0.05$的检验，在水平精确时，以$0.05$的概率拒绝一条真零假设。二十个这样的检验，各自当作唯一的检验来做，则是另一个实验。下面这个结果是至少出一次丑的概率。它的证明只用独立性，别无所用。

:::proposition 至少一次拒绝 {#prop-multiplicity}
设$m$个检验相互独立，并且各自的零假设为真时水平恰为$\alpha$。若全部$m$条零假设都为真，则至少一个检验拒绝的概率为

$$
1 - (1 - \alpha)^m.
$$

若改为每个检验的水平至多为$\alpha$、而检验保持独立，则至少一次拒绝的概率至多为$1 - (1 - \alpha)^m$。
:::

:::proof
设$A_i$为检验$i$拒绝这一事件，并把它的补事件记作$A_i^c$。在该检验的零假设之下，精确情形有$\Prob(A_i) = \alpha$，所以$\Prob(A_i^c) = 1 - \alpha$。检验之间的独立意味着这些事件之间的独立。因此所有检验都不拒绝的概率是

$$
\Prob(A_1^c \cap \cdots \cap A_m^c) = \prod_{i=1}^m \Prob(A_i^c) = (1 - \alpha)^m.
$$

"至少一次拒绝"是它的补事件，所以其概率是$1 - (1 - \alpha)^m$。

若改为$\Prob(A_i) \le \alpha$，则$\Prob(A_i^c) \ge 1 - \alpha$。这些$\Prob(A_i^c)$的乘积于是至少为$(1 - \alpha)^m$，而补事件的概率至多为$1 - (1 - \alpha)^m$。离散的检验统计量常常是水平至多$\alpha$而不是恰为$\alpha$，因为在格点上拒绝概率打不准$\alpha$。不等式是覆盖它们的那个版本，仍然要求独立。这套论证既不要求这些检验关于同一个参数，也不要求样本一样长。它要求独立，并要求每条零假设都为真。一条零假设为假的检验会因为另一个原因贡献一次拒绝，那个原因叫功效，不在这个概率之内。
:::

$m = 1$时公式返回$\alpha$，这是它必须做到的。当全部零假设为真、每个水平恰为$\alpha$时，把$m$个示性函数相加，拒绝次数的期望是$m\alpha$。期望与"至少一次"的概率是两种不同的汇总。对罕见事件，它们接近。对$\alpha = 0.05$与$m = 20$，它们不接近，而下一个例子会把两者分开。

:::example 二十个独立检验 {#ex-twenty}
取$m = 20$、$\alpha = 0.05$，在[[#prop-multiplicity]]的精确假设之下，每条零假设都为真。计算没有检验拒绝的概率、至少一个检验拒绝的概率，以及拒绝次数的期望。
:::solution
给定的检验不拒绝的概率是$0.95$。独立性把这些概率相乘：

$$
0.95^{20} = 0.358486
$$

保留六位小数。至少一次拒绝的概率是

$$
1 - 0.95^{20} = 0.641514,
$$

舍入为$0.6415$。大约每三次里就有两次，一组二十个独立的真零假设检验在水平$0.05$上会产生至少一次拒绝。拒绝次数的期望是$20 \times 0.05 = 1$。于是错误拒绝的典型次数是一，而一次都没有的概率只有大约$0.36$。只报告二十个中最小的P 值而不报告那二十个，就把一个概率为$0.6415$的事件变成了一项看起来的发现。这个计算完整地用到了独立性。共享一个样本的检验不独立；此时这个公式只是关于看的次数的一种类比，不是这一组检验的P 值。
:::
:::

:::example 九次看，以及一张有九个格子的网格 {#ex-nine}
计算$1 - (1 - 0.01)^9$。另外，走步验证目录条目WF04是九种组合的一张网格：快窗取$\{20, 50, 80\}$、慢窗取$\{100, 150, 200\}$，每一格以一个回测的夏普比率计分，跨距$26$年。按2026年的阅读，quants.md上关于那个QuantJourney示例（Apache-2.0）的报告称，该页面是一张那种形状的参数网格。本图谱没有重跑过这些回测，而库表没有报告九个夏普比率或任何P 值。数字$0.0865$可以拿来跟什么比？不可以跟什么比？
:::solution
首先，$0.99^9 = 0.913517$保留六位小数，于是

$$
1 - 0.99^9 = 0.086483.
$$

保留四位小数，这个概率是$0.0865$。在九个独立检验、每个水平恰为$0.01$、每条零假设都为真之下，至少一次拒绝的概率约为$0.0865$。错误拒绝次数的期望是$9 \times 0.01 = 0.09$。

WF04包含九个已计分的回测。整数九是那种类比。这个公式不是WF04的家族错误率。九个格子共享一段历史，慢窗与快窗跨格重叠，而一个夏普比率不是由一个事先指定的均值$t$检验算出的P 值。库没有报告那些夏普值，所以本章不替它们发明数字，也不宣称任何一格拒绝过任何东西。九个回测之间的相依性意味着：那个独立零假设下的计算只是看的次数计数。对一个已经冻结下来的选择之后再走步验证，与产生这个选择的那九次看，是两个不同的对象。同一目录中的WF05，是一个采样器的三十次试验加上对赢家的走步验证；那三十次试验是更大的看的次数，它们在[[validation/parameter-search]]中被当作一场搜索来讨论，而不是当作三十次确认。
:::
:::

不需要独立性的那个界更粗；而当每条规则都是同样这些年份的函数时，仍然适用的正是它。

:::proposition Bonferroni界 {#prop-bonferroni}
设$m$个检验在各自零假设为真时水平至多$\alpha/m$。这些检验不必独立。若全部$m$条零假设都为真，则至少一个检验拒绝的概率至多为$\alpha$。
:::

:::proof
设$A_i$为检验$i$的拒绝。至少一个检验拒绝这一事件是并集$A_1 \cup \cdots \cup A_m$。对任意事件，无论独不独立，

$$
\Prob(A_1 \cup \cdots \cup A_m) \le \sum_{i=1}^m \Prob(A_i).
$$

这就是并集界。每个水平假设给出$\Prob(A_i) \le \alpha/m$，所以这个和至多为$m \cdot (\alpha/m) = \alpha$。这套论证一点也没有用到相依结构。正相依——许多规则在同一份历史上计分时的通常情形——会把这个界放宽：拒绝事件相互重叠时，并集小于和。松不等于错。界依然成立。它的代价是功效。对每条规则用$\alpha/m$来检验，是一道比用$\alpha$检验更难的门槛；一个真实效应本来能越过$\alpha$，却可能越不过$\alpha/m$。
:::

:::example 二十个检验上的这个界 {#ex-bonf}
$20$个检验各自以水平$0.05/20 = 0.0025$来做，而每条零假设都为真。[[#prop-bonferroni]]给出什么？此外，若这些检验独立且水平精确，$1 - (1 - 0.0025)^{20}$是多少？
:::solution
Bonferroni界给出概率至多$0.05$，不需要任何独立性假设。在水平精确且独立之下，更精确的公式适用：

$$
1 - (1 - 0.0025)^{20} = 1 - 0.9975^{20} = 0.048830
$$

保留六位小数。独立情形恰好落在界的下方。这个差距是拒绝事件之间的重叠：两个检验可以同时拒绝，并集界对那种结果计了两次，而精确公式只计一次。在单段金融历史上这些检验不独立，所以$0.048830$不是一个人应当引用的概率。如果每个检验的水平真的是$0.0025$，数字$0.05$仍然是一个上界。以未经调整的水平$0.05$发表二十个中的最佳者，然后再引用一个事后只在赢家身上算出的Bonferroni调整，并没有执行这个命题。这个调整必须支配跑过的每一个检验，包括那些没有写进论文的。
:::
:::

:::intuition 赢家是一个不同的随机变量
在真零假设之下，一个事先指定的均值在尺度$s/\sqrt{n}$上波动。$m$个这样的均值中的最大值在一个更宽的尺度上波动。把赢家与单个检验的参考分布比较，就是把最大值当作一次普通的抽取来对待。当检验独立时，[[#prop-multiplicity]]正是这种对待的确切代价：隐含检验"若最佳P 值低于$\alpha$就拒绝"的水平是$1 - (1-\alpha)^m$，不是$\alpha$。对$m = 20$与$\alpha = 0.05$，这个水平是$0.6415$。这个程序在大多数时候都会拒绝一条真的全局零假设。
:::

## 一场在零假设内部的搜索

怀特（White）发表于2000年的现实检验（reality check），瞄准的正是这个最大值。思想如下，推导不在其列。零假设是：在一部事先指定的目录中，没有哪条规则能胜过一个给定的基准。检验统计量是目录中最佳规则的表现，不是事先选定的某条规则的表现。参考分布必须是零假设为真时那个最佳表现的分布。

把每条规则的收益率重新中心化，使其相对基准的样本均值优势被移除，就造出一个零假设按构造成立的样本。对整段日期做重抽样、并在每个重抽出的日期上把所有规则的横截面保持在一起，就保住了共享同一天的那些规则之间的相依。在每个重抽样本上，重新计算每条规则的表现，然后取其最大值。再把原来的、未中心化的最大值与那个最大值的自助法分布比较。如果原来的赢家，在每个优势都已被重新中心化掉的条件下所产生的诸赢家之中是典型的，那么这场搜索就没有发现对零假设的偏离。用于那个比较的自助法，是[[statistics/resampling]]的主题。本章不把怀特的统计量展开成一个公式，也不把这套程序用到WF04上：库没有公布那九个夏普比率——这套程序需要它们——而在编造的夏普值上跑一次现实检验，只是一场戏。

坎贝尔·哈维（Campbell R. Harvey）、Yan Liu与Heqing Zhu在2016年记录了已发表因子文献背后的多重性，并论证已发表的$t$统计量夸大了证据。他们的实践性结论是：一旦认真对待已经试过的因子个数，一道接近$t$统计量$3$、而不是单检验那道接近$2$的门槛，才是更诚实的基准。那道门槛是他们对一片文献的论证，不是本章的定理，也不是把某条被搜索出来的规则上的$t$统计量$3.1$当作已被证实的许可证。门槛移动的是单检验的临界值。它本身并不像现实检验试图做的那样，把搜索放进零假设内部。为被搜索过的回测发展出的收缩（deflated）夏普比率，在[[validation/the-deflated-sharpe]]中处理——同样，那里它是一道随试验次数上升的门槛，而不是一个为库中网格算出来的数。

:::widget hypothesis
test: t
tail: two
alpha: 0.05
effect: 0.3
n: 60
caption: 一个事先指定的双侧t 检验。阴影的两个尾部就是水平。这个小工具画不出被丢弃的另外十九个检验。若那二十个检验独立且每条零假设都为真，在这个水平上至少一次拒绝的概率约为0.64。
:::

:::warning 事后的P 值
P 值是在一个于统计量被选定之前就陈述过的零假设之下算出的。因为$t$统计量出来大，就挑选规则、滞后阶、窗口或资产，然后再像那条规则是唯一试过的规则一样去读$t$表，这就重复了[[#prop-multiplicity]]所度量的错误。路径A的统计量$1.613$是为本课程早已固定的一条路径算出的，而即便在那里，正态参考分布也不适用。附在一个九格网格的最佳格子上的P 值，对其余八格只字不提，不是水平$0.05$的P 值。
:::

:::application 在看到$t$之前应当写下什么
具有水平$\alpha$的那个对象是一个二元组：一条规则，和一个检验，两者都在评估样本被查看之前固定。"固定"意味着写了下来，而不仅仅是心里想过。一个把窗口留作自由的设定，一张只显示$t$统计量最大的那个窗口的表格，就是[[#ex-twenty]]那一组检验，只不过$m$没有公布。当检验共享数据时，Bonferroni界是为公布了$m$的检验埋单的一种方式。怀特的构造是另一种，瞄准的是最大值而不是每一个单独的水平。这两种构造都不会把一次对零假设的拒绝变成一个交易决定。它们两者谈的都是这次拒绝的意义。
:::

:::remark 功效是另一种错误
[[#prop-multiplicity]]完全是在谈真零假设。一条为假而检验没能拒绝的零假设是Ⅱ 型错误，而拒绝一条假零假设的概率是功效。数学图谱为单个检验画了功效随样本量变化的图。有两条事实可以搬过来。功效随以标准误度量的均值的绝对值上升，而当门槛从$\alpha$提高到$\alpha/m$时下降。一组如实处理多重性的检验，宣告一个小的真实效应显著的倾向更弱。这就是把整组检验的水平保持在$\alpha$附近的代价，而不是跳过调整的正当理由。一个要经过二十次未经调整的看才看得见的小的真实效应，从来就没有在水平$0.05$上被估计过。
:::

:::quiz
二十个对真零假设的独立检验，每个都以精确水平$0.05$来做。哪个数字是至少一个检验拒绝的概率？
- [ ] $0.05$
- [ ] $1$
- [ ] $0.05/20 = 0.0025$
- [x] $1 - 0.95^{20} \approx 0.6415$
:::solution
[[#prop-multiplicity]]取$m = 20$、$\alpha = 0.05$给出$1 - 0.95^{20} = 0.641514$，约$0.6415$。拒绝次数的期望是$1$，那是另一种汇总量，不是概率。Bonferroni门槛$0.0025$，是当整组检验而不是其中每个成员被保持在水平$0.05$上时，每个检验所应与之比较的数。
:::
:::

:::history
2016年，坎贝尔·哈维（Campbell R. Harvey）、Yan Liu与Heqing Zhu记录了因子文献背后的多重性，并论证已发表的$t$统计量夸大了证据。同一个警告以目录中最佳规则的自助法检验的形式出现，就是怀特（White）2000年的现实检验：当搜索本身被计入之后，赢家是否胜过一个基准的检验。两篇论文谈的都是允许拿哪个统计量去与单检验的表格比较。它们都不是对某个库示例的回测，也都没有挑选一个策略。
:::

## 通向何处

现实检验内部的自助法，以及重抽样单日与重抽样分块之间的区别，见[[statistics/resampling]]。把一张夏普值的网格变成一个被选定的统计量——以WF04与WF05为库自己的网格——见[[validation/parameter-search]]。一道像若干噪声夏普的期望最大值那样增长的门槛，见[[validation/the-deflated-sharpe]]。本章拒绝给它配上经典P 值的回归斜率，见[[statistics/regression-on-a-signal]]。

:::summary
- 平均超额收益的$t$统计量是$\bar X \sqrt{n} / s$，其中$s$使用除数$n-1$。只有在独立正态抽样下，它才有$t_{n-1}$的零分布。那个定理在数学图谱里。
- 在一个编造的四点样本上，统计量等于$2$，对着$t_3$临界值$3.182$在水平$0.05$上不拒绝。在路径A上它等于$1.613$，对着$t_6$的$2.447$不拒绝，而且那里的正态模型无论如何都是假的。
- 若$m$个独立检验每个都有精确水平$\alpha$且每条零假设都为真，则至少一次拒绝的概率是$1 - (1-\alpha)^m$。对$m = 20$与$\alpha = 0.05$，这个概率是$0.6415$。
- 对九个以精确水平$0.01$做的独立检验，同一个概率是$0.0865$。WF04有九个格子；这个计数是类比，不是那个页面的P 值。
- Bonferroni界不需要独立性：对$m$条零假设各以水平$\alpha/m$检验，任何错误拒绝的概率至多为$\alpha$。
- 怀特的现实检验把最佳规则与重新中心化零假设下最佳规则的自助法分布比较。它是关于最大值的一个思想，不是这里推导的公式。
- 只留下赢家之后再算出的P 值，不是事先指定的检验的P 值。
:::

## 习题

:::exercise 两个检验 {#exr-two level=1 check="0.0975"}
两个独立检验各有精确水平$0.05$，两条零假设都为真。计算至少一个检验拒绝的概率。（输入这个概率。）
:::solution
由[[#prop-multiplicity]]，概率是$1 - 0.95^2 = 1 - 0.9025 = 0.0975$。它比$0.05 + 0.05 = 0.10$略小，因为并集界对两个检验都拒绝的那种结果重复计了数。这个概率是$0.0975$。
:::
:::

:::exercise 四点的统计量 {#exr-t level=1 check="2"}
对超额收益$0.01, 0.01, 0.01, 0.05$，无风险收益率为零，计算[[#def-t]]的$t$统计量。（输入统计量。）
:::solution
如[[#ex-t2]]，均值是$0.02$，除数为$3$的样本标准差是$0.02$。于是$t = 0.02 / (0.02 / \sqrt{4}) = 2$。统计量是$2$。
:::
:::

:::exercise 一道Bonferroni门槛 {#exr-bon-thresh level=1 check="0.0025"}
一组$20$个检验要用Bonferroni界保持在家族水平$0.05$上。每个单独的检验应以什么水平来做？（输入单个水平。）
:::solution
[[#prop-bonferroni]]使用单个水平$\alpha/m = 0.05/20 = 0.0025$。每个检验以水平$0.0025$来做。
:::
:::

:::exercise 九个以百分之一水平做的检验 {#exr-nine level=2 check="0.086483"}
在[[#prop-multiplicity]]的精确假设下，把$1 - 0.99^9$算到六位小数。（输入保留六位小数的概率。）
:::solution
$0.99^9 = 0.9135172475\ldots$，所以$1 - 0.99^9 = 0.0864827525\ldots$，保留六位小数等于$0.086483$。这就是[[#ex-nine]]里的概率。它不是WF04九个格子的P 值。这个概率是$0.086483$。
:::
:::

:::exercise 期望错误拒绝数 {#exr-expect level=2 check="1"}
二十个对真零假设的独立检验各有精确水平$0.05$。拒绝次数的期望是多少？（输入期望。）
:::solution
每个检验贡献一个期望为$0.05$的示性函数。期望的线性性给出$20 \times 0.05 = 1$，而且它不需要独立性。独立性是用在至少一次拒绝的概率$0.6415$上的，那是另一个数。期望是$1$。
:::
:::

:::exercise 路径A的缩放均值 {#exr-path level=2 check="1.613"}
用均值$0.013930$、样本标准差$0.022848$与$n = 7$，把$t$统计量算到三位小数。（输入统计量。）
:::solution
标准误是$0.022848/\sqrt{7} \approx 0.008636$。于是$t \approx 0.013930/0.008636 = 1.613$，保留三位小数，见[[#ex-path-t]]。统计量是$1.613$。它低于双侧$t_6$的$5\%$点$2.447$；而$t_6$参考对一条交替路径来说无论如何都是错误的模型。
:::
:::

:::exercise 证明乘积公式 {#exr-prove level=3}
证明[[#prop-multiplicity]]中的等式：若$m$个检验独立，且每个检验在自己的真零假设下水平恰为$\alpha$，则至少一次拒绝的概率是$1 - (1-\alpha)^m$。并指出独立性用在哪里。
:::hint
对每个检验都不拒绝这一补事件做推导。独立性把一个联合概率变成一个乘积。只有因为水平精确，每个因子才等于$1-\alpha$。
:::
:::solution
设$A_i$为检验$i$拒绝这一事件。真零假设下的精确水平给出$\Prob(A_i^c) = 1 - \alpha$。没有拒绝这一事件是交$A_1^c \cap \cdots \cap A_m^c$。独立性用在这里，而且只用在这里：它把联合概率分解为$\prod_i \Prob(A_i^c) = (1-\alpha)^m$。至少一次拒绝的概率是这个的补，$1 - (1-\alpha)^m$。没有独立性，这一步乘积就是假的，这就是为什么在同一份历史上的一张回测网格不能沿用这个公式。当乘积不可用时，剩下的就是[[#prop-bonferroni]]的并集界。
:::
:::

:::exercise 相依的网格不是九枚硬币 {#exr-grid level=3 check="0.3698"}
把$1 - 0.95^9$算到四位小数。然后说明为什么这个数字不是WF04的九个窗口对网格产生一次错误发现的概率。（输入保留四位小数的概率。）
:::hint
独立的算法就是[[#prop-multiplicity]]里的那个乘积。目录的九个格子是对同一段$26$年历史的九次看，不是九个分开的实验。库没有报告九个P 值。
:::
:::solution
$0.95^9 = 0.6302494097\ldots$，所以$1 - 0.95^9 = 0.3697505902\ldots$，保留四位小数等于$0.3698$。那是在九个水平恰为$0.05$的独立检验、每条零假设都为真时，至少一次拒绝的概率。WF04的九个格子共享一个样本，窗口相互重叠，而报告出来的分数是夏普比率，不是事先指定的$t$检验的P 值。库表没有列出九个夏普值，本图谱也没有重跑过它们。数字$0.3698$数的是九次独立的看。它不是附在那个页面上的概率。保留四位小数的值是$0.3698$。
:::
:::
