均值不用信号。一条规则背后的论断是：某个在决策时刻可用的数字，与那之后赚得的收益率对得上。把这条论断写成一条直线，它是

$$
R_{t+1} = a + b\, s_t + \varepsilon_{t+1},
$$

其中$s$上的下标和斜率同样重要。本章用最小二乘拟合这条直线，用的数字小到足以手工验算，并把拟合与预测分开。这条直线使残差平方和最小的证明住在数学图谱里，见[一元线性回归](/learn/maths/lesson.php?c=statistics&l=regression)与[最小二乘](/learn/maths/lesson.php?c=linear-algebra&l=least-squares)。这里推导的是时钟：哪个变量允许坐在等号右边。拟合不是拿这个信号去交易的建议。

## 一个日期为$t$的信号

图谱的决策时钟在[[markets/systematic-question]]中固定。一个日期为$t$的特征可以使用截至$t$时刻的价格。它赚得$t$之后实现的收益率。对收盘到收盘的简单收益率，那个收益率是$R_{t+1} = P_{t+1}/P_t - 1$，而不是$R_t$。信号与收益率的乘积只有在信号是两者中较早的一个时才合法。

:::definition 滞后信号回归 {#def-lag-reg}
设$s_t$是在$t$时刻已知的信号，$R_{t+1}$是从$t$到$t+1$赚得的简单收益率。在$n \ge 3$个决策时刻的样本上，**滞后信号回归**是模型

$$
R_{t+1} = a + b\, s_t + \varepsilon_{t+1},
$$

用观测到的下期收益率对观测到的信号与一个常数做最小二乘来拟合。信号必须是在$t$时刻可得信息的函数。扰动$\varepsilon_{t+1}$是直线没有捕捉到的一切。这里还没有假设扰动独立、正态或方差恒定。这些假设是后面的标准误所需要的，而把一个方程写下来并不赋予它们。
:::

总体读法（如果你愿意陈述它的话）是：$a + b s_t$是给定信号时$R_{t+1}$的条件期望。样本读法更谦逊：$a$与$b$是使直线在最小二乘意义下尽可能贴近观测配对的那两个数。样本内的贴近不是夏普比率，也不是关于下一个样本的证据。

回忆这些公式，假设信号不全相等。对配对$(s_i, y_i)$，$i = 1,\ldots,n$，把两个样本均值记作$\bar s$与$\bar y$，并记

$$
S_{ss} = \sum_{i=1}^n (s_i - \bar s)^2, \qquad
S_{sy} = \sum_{i=1}^n (s_i - \bar s)(y_i - \bar y), \qquad
S_{yy} = \sum_{i=1}^n (y_i - \bar y)^2.
$$

数学图谱证明了$\sum_i (y_i - a - b s_i)^2$的唯一最小化点是

$$
\hat b = \frac{S_{sy}}{S_{ss}}, \qquad \hat a = \bar y - \hat b\, \bar s.
$$

拟合值是$\hat y_i = \hat a + \hat b\, s_i$，残差是$e_i = y_i - \hat y_i$。本章使用这些公式，不再重新证明。

:::definition 残差与决定系数 {#def-r2}
对一条带截距且$S_{yy} > 0$的滞后信号回归，**残差平方和**与**决定系数**为

$$
\mathrm{SSE} = \sum_{i=1}^n e_i^2, \qquad
R^2 = 1 - \frac{\mathrm{SSE}}{S_{yy}} = \frac{S_{sy}^2}{S_{ss}\, S_{yy}}.
$$

$R^2$是：在这个样本里，下期收益率的样本方差中与信号线性关联的那部分比例。对带截距的回归，它落在$[0, 1]$之内。它不是平均收益率，不是与银行账户的相关系数，也不是夏普比率。对这单信号回归，它等于$s$与下期收益率之间样本相关系数的平方，因此它把$\hat b$的符号丢掉了。
:::

斜率的符号是一条规则会在意的那部分，而$R^2$已经把它扔了。斜率$-0.01$与斜率$+0.01$可以共用同一个$R^2$。只报告$R^2$会隐瞒直线指向哪一边。

:::proposition 对信号重新缩放 {#prop-rescale}
设一条滞后回归有$S_{ss} > 0$，并用$s'_t = c\, s_t$（$c > 0$）替换信号。最小二乘的截距不变，斜率除以$c$，$R^2$不变。
:::

:::proof
上面回忆的公式是出发点；它们的推导是数学图谱里的最小二乘定理。$s'$的偏差是$s$的偏差的$c$倍，所以$S_{s's'} = c^2 S_{ss}$且$S_{s'y} = c\, S_{sy}$。新的斜率是

$$
\hat b' = \frac{c\, S_{sy}}{c^2 S_{ss}} = \frac{1}{c}\hat b.
$$

新的信号均值是$c\, \bar s$，于是

$$
\hat a' = \bar y - \hat b' (c\, \bar s) = \bar y - \hat b\, \bar s = \hat a.
$$

决定系数是$S_{sy}^2 / (S_{ss} S_{yy})$。分子与分母中的$S_{ss}$因子都带上一个$c^2$，于是消去。等价地，$R^2$是一个相关系数的平方，而正缩放不改变相关系数，见[[statistics/moments-and-dependence]]中的缩放结果。把一个信号乘以$100$让斜率显得更小，或者乘以$0.01$让它显得更大，造不出一个更好的样本内拟合。
:::

## 前视

把$s_t$换成一个日期为$t+1$的变量，不是下标上的表面文章。收益率$R_{t+1}$已经依赖于$P_{t+1}$。一个同样依赖$P_{t+1}$的解释变量，用的是这个收益率由以构成的那个价格。

:::proposition 同期解释变量 {#prop-lookahead}
设$R_1,\ldots,R_n$是不全相等的收益率，考虑把$R_i$对它自身、带截距地做一元回归。唯一的最小二乘拟合是$\hat a = 0$、$\hat b = 1$、每个残差都是$0$、$R^2 = 1$。如果所描述的对象是$t$时刻之后赚得的收益率，那么一个只许使用$t$时刻可得信息的决策，就不能用$R_{t+1}$当解释变量。
:::

:::proof
直线$a = 0$、$b = 1$在每个$i$上给出残差$R_i - R_i = 0$。残差平方和是$0$。没有别的直线能做得更好，因为平方和不能为负。至于唯一性：设对每个$i$都有$a + b R_i = R_i$。那么对每个$i$都有$a + (b - 1) R_i = 0$。若$b \neq 1$，每个$R_i$都等于$-a/(b-1)$，与收益率不全相等的假设矛盾。于是$b = 1$，随之$a = 0$。

时钟的那一半是决策时刻的定义，不是另一条代数恒等式。简单收益率$R_{t+1} = P_{t+1}/P_t - 1$依赖于$P_{t+1}$。日期为$t$的信息可以使用截至$t$的价格，并在之后赚得$R_{t+1}$，这就是[[markets/systematic-question]]中的约定。一个等于$R_{t+1}$的解释变量，在决策做出时是不可得的。拟合它得到上面刚推导出的那条完美直线，它描述的是一个恒等式，不是预测。
:::

:::corollary 仿射前视 {#cor-affine}
在同样的假设下，若解释变量是$s_i = c + d R_i$且$d \neq 0$，则$R_i$对$s_i$的唯一最小二乘拟合的残差恒为零，$R^2 = 1$，斜率$1/d$，截距$-c/d$。
:::

:::proof
把仿射关系解出收益率：$R_i = -c/d + (1/d)\, s_i$。那条直线在每个观测上精确拟合，所以残差平方和为零，$R^2 = 1$。信号不全相等，因为收益率不全相等且$d \neq 0$，所以由给出$\hat b = S_{sy}/S_{ss}$的同一个定理，最小二乘的斜率与截距是唯一的。任何信号，只要它是它本要预测的那个收益率的可逆仿射函数，在样本内就会显得完美。那种完美就是前视，在代数里看得见。
:::

未加工的同期K线收益率是那个显然非法的解释变量。这条推论则不那么显然：一个用今日收盘价构造的"特征"，插在即昨日收盘到今日收盘的收益率旁边时，仍然可以是那个收益率的一个仿射函数。判据是特征所用最后一个价格的日期，不是特征的名字。

:::quiz
在滞后模型$R_{t+1} = a + b s_t + \varepsilon_{t+1}$中，哪个解释变量遵守决策时钟？
- [ ] $s_{t+1}$，因为它更接近被解释的那个收益率。
- [ ] $R_{t+1}$本身，因为[[#prop-lookahead]]给出$R^2 = 1$，而更大的$R^2$是更好的预测。
- [x] $s_t$，一个在$t$时刻可得信息的函数。
- [ ] $s_t$与$R_{t+1}$的平均，因为合法信号与非法信号的平均是半个合法。
:::solution
左端的收益率在$t$之后才实现。选项中只被要求在$t$时刻已知的解释变量是$s_t$。把$R_{t+1}$对它自己回归得到的完美$R^2$，是[[#prop-lookahead]]里的恒等式，不是预测。一个仍然依赖$R_{t+1}$的平均，其日期仍然落在决策之后。
:::
:::

## 四个配对，手工拟合

这道例题的样本是编造的。信号取值$0, 1, 2, 3$。下期收益率取值$0.02, 0.00, 0.01, 0.05$。四个配对里没有一个是市场，而斜率不是一个头寸。

:::example 四个配对上的最小二乘 {#ex-four}
对配对$(s, y) = (0, 0.02),\ (1, 0.00),\ (2, 0.01),\ (3, 0.05)$拟合$y = a + b s$。报告$\hat a$、$\hat b$、四个残差与$R^2$。
:::solution
信号均值是$\bar s = (0+1+2+3)/4 = 1.5$。收益率均值是$\bar y = (0.02 + 0.00 + 0.01 + 0.05)/4 = 0.08/4 = 0.02$。信号偏差是$-1.5, -0.5, +0.5, +1.5$，而

$$
S_{ss} = (-1.5)^2 + (-0.5)^2 + (0.5)^2 + (1.5)^2 = 2.25 + 0.25 + 0.25 + 2.25 = 5.
$$

收益率相对$0.02$的偏差是$0, -0.02, -0.01, +0.03$。交叉和是

$$
S_{sy} = (-1.5)(0) + (-0.5)(-0.02) + (0.5)(-0.01) + (1.5)(0.03) = 0 + 0.01 - 0.005 + 0.045 = 0.05.
$$

于是$\hat b = 0.05 / 5 = 0.01$，$\hat a = 0.02 - 0.01 \times 1.5 = 0.005$。拟合值$0.005 + 0.01 s$是$0.005, 0.015, 0.025, 0.035$。残差是

$$
\begin{align*}
0.02 - 0.005 &= 0.015, \\
0.00 - 0.015 &= -0.015, \\
0.01 - 0.025 &= -0.015, \\
0.05 - 0.035 &= 0.015.
\end{align*}
$$

它们相加为零，这正是截距的正则方程，也是一个有用的算术校验。残差平方和是$4 \times (0.015)^2 = 4 \times 0.000225 = 0.0009$。总平方和是

$$
S_{yy} = 0^2 + (-0.02)^2 + (-0.01)^2 + (0.03)^2 = 0.0004 + 0.0001 + 0.0009 = 0.0014.
$$

因此$R^2 = 1 - 0.0009/0.0014 = 0.0005/0.0014 = 5/14 \approx 0.357143$。这四个收益率的样本内方差中，约三分之一落在信号的方向上，三分之二没有。斜率是正的，而且很小：在这个样本里，信号每多一个单位，下期收益率对得上一个百分点。这句话是对四个敲进去的配对的描述。它不是预测区间，也不是权重。
:::
:::

:::example 同一批收益率，用了两次 {#ex-illegal}
取四个下期收益率$0.02, 0.00, 0.01, 0.05$，把每一个对它自己回归。报告这个拟合，然后说明为什么同样这四个数作为早一步日期化的信号，会是另一个回归。
:::solution
收益率不全相等。由[[#prop-lookahead]]，拟合是$\hat a = 0$、$\hat b = 1$、每个残差是$0$、$R^2 = 1$。数值上，$S_{sy} = S_{ss} = S_{yy}$，所以斜率公式返回$1$，截距公式返回$\bar y - \bar y = 0$。

如果同样这四个数早一个决策就可已知——如果它们是$s_t$而左端是一个更晚的收益率——这个回归就会是[[#def-lag-reg]]的滞后模型，而$R^2 = 1$将是一种真实的样本内关联，而不是恒等式。代数看不出这个区别。日期能。在两边都写$R_{t+1}$，就把解释变量的日期定在了$t+1$。完美的拟合是症状，不是业绩统计量。
:::
:::

:::example 路径A，滞后且样本内 {#ex-path}
使用路径A的精确简单收益率，把每个收益率对它前一个收益率回归。共有六个配对。把$\hat a$、$\hat b$与$R^2$报告到六位小数，并把残差报告到六位小数。
:::solution
路径A的七个精确简单收益率保留六位小数为$0.020000$、$-0.009804$、$0.029703$、$-0.009615$、$0.038835$、$-0.009346$、$0.037736$，见[[statistics/moments-and-dependence]]。滞后回归有六个配对。对精确比率做最小二乘给出

$$
\hat a = 0.023538, \qquad \hat b = -1.066049, \qquad R^2 = 0.909028.
$$

拟合值保留六位小数为$0.002217$、$0.033990$、$-0.008127$、$0.033789$、$-0.017862$、$0.033501$。残差保留六位小数为$-0.012021$、$-0.004287$、$-0.001489$、$0.005046$、$0.008516$、$0.004235$。在那个精度下它们相加为零。改用六位小数的收益率而不是精确比率出发，$R^2$只在小数点后第六位发生变化。

$R^2 = 0.909028$是滞后1阶相关$-0.953430$的平方。斜率为负，因为那个相关系数为负：在这条路径上，一个高收益率在样本内之后跟着一个低收益率。斜率上的经典$t$统计量会显得巨大，这里不把它报告成P 值。它的参考分布假设扰动独立。收益率的相邻配对相互重叠，所以这个回归里的扰动不独立，而六个点不是大样本。这个拟合是路径A的一个描述。[[#def-r2]]禁止把$0.909028$读成夏普比率。业绩课程已经记录了同样这七个收益率的年化比率会有多误导人。
:::
:::

:::example 一个不波动的信号 {#ex-flat}
设信号是$1, 1, 1, 1$，下期收益率是$0.02, 0.00, 0.01, 0.05$。斜率公式会怎样？
:::solution
每个信号偏差都是$0$，所以$S_{ss} = 0$。公式$\hat b = S_{sy}/S_{ss}$除以零。最小二乘定理的假设——解释变量不是常数——不成立，唯一斜率不存在。每条直线$y = \bar y + b(s - \bar s)$都塌缩成水平直线$y = 0.02$，因为$s - \bar s = 0$，而每个这样的$b$给出同样的拟合值。残差是收益率偏差$0, -0.02, -0.01, 0.03$；如果仍去计算$1 - \mathrm{SSE}/S_{yy}$，则$R^2 = 0$，因为这条直线在均值之外没有解释任何东西。一个在样本上恒定的信号记不到斜率的功。这是一种退化，不是斜率为零。斜率为零需要$S_{ss} > 0$且$S_{sy} = 0$。
:::
:::

:::intuition 直线经过均值点
截距公式$\hat a = \bar y - \hat b\, \bar s$说的就是$(\bar s, \bar y)$落在拟合直线上。在四个配对的例题里，点$(1.5, 0.02)$满足$0.005 + 0.01 \times 1.5 = 0.02$。如果一条画出来的直线没经过均值点，那就是算术出了错，或者回归没有带截距。本章始终带截距。一条被强行拉过原点的回归是另一个模型，而均值为零的信号是两个模型共享斜率的唯一情形。
:::

:::warning $R^2$不是夏普比率
一个样本内$R^2$回答的是一个很窄的问题：在这些下期收益率相对它们自己均值的偏差平方中，有多大比例落在这些信号的方向上？路径A的滞后回归在六个配对上回答$0.909028$。四个配对的例题回答$5/14$。这两个数都不是平均超额收益，都没有除以一条盈亏序列的标准差，也都没有减去成本。来自同期解释变量的高$R^2$，如[[#prop-lookahead]]里那样，是最高的可能值，也是最坏的可能研究错误。因为$R^2$出来大就挑选信号、滞后阶或样本，那是一场搜索；而下一章会把这场搜索当作论断的一部分来处理。
:::

:::application 斜率允许意味着什么
在一个事先指定的样本内部，$\hat b$是在截距保持自由的前提下，信号每增加一个单位、下期收益率的样本内变化。只有当$s_t$在下期收益率被查看之前就固定下来时——也就是[[#def-lag-reg]]的意义——它才成为研究对象。此时，一个正的估计是"这个信号与后续收益率对得上"的样本投影。它仍然不是权重。把信号映射成权重是一个进一步的函数；除非被拟合的就是那个映射本身，回归就不估计它。成本、延迟以及收盘价与成交价之间的差别，都在四个配对之外。即使$\hat b$一动不动，它们也会挪动一个真实交易出来的结果。
:::

:::remark 残差和为零，而那不是一个诊断
在有截距时，$\sum_i e_i = 0$且$\sum_i s_i e_i = 0$，因为它们就是正则方程。四个残差$0.015, -0.015, -0.015, 0.015$通过两项校验：和为零，而信号加权和是$0(0.015) + 1(-0.015) + 2(-0.015) + 3(0.015) = 0$。这些校验确认的是算术。它们确认不了决策时钟，也确认不了扰动是独立的。残差对时间的图形可以显示一串符号，而正则方程并不禁止这串符号，因为正则方程约束的是一个和，不是顺序。
:::

:::quiz
四个配对的拟合有$R^2 = 5/14$与斜率$0.01$。只凭这两个数，哪个结论是站得住的？
- [ ] 应当以与$0.01$成比例的权重交易这个信号。
- [ ] 该信号的夏普比率是$5/14$。
- [x] 在这个样本里，最小二乘直线解释了下期收益率相对其均值偏差平方的$5/14$。
- [ ] 下个四期会得到同样的$R^2$。
:::solution
[[#def-r2]]是一个样本内方差比例。它不指定权重，不是夏普比率，而拟合里没有任何东西把它推广到之后的样本。斜率的符号与大小，同$R^2$是两份分开来的报告。
:::

:::history
1970年，尤金·法玛（Eugene F. Fama）的综述整理了价格是否反映信息的证据，并命名了后来实证研究所争论的弱式、半强式与强式形态。滞后回归是这场论证采取的形态之一。按对弱式的严格读法，一个只用过去价格构造的信号在[[#def-lag-reg]]中应有斜率零。估计斜率，与发现对信号的一场搜索能够制造出一个非零斜率，是两种不同的活动。后者是下一章的主题。1970年的综述不是一条拟合直线，本章也不把任何数值斜率归于它。
:::

## 通向何处

均值的$t$统计量，以及拟合许多信号再只留下赢家所造成的损害，见[[statistics/testing-and-snooping]]。$R_t$与$R_{t-1}$之间的相依性——路径A的斜率就是由它构成的——见[[statistics/moments-and-dependence]]。同期K线回测是[[#prop-lookahead]]的时钟错误在研究流水线中通常采取的形式；回测课程在[[backtesting/timing-costs-and-biases]]中处理这条流水线。这里用到的最小二乘定理，包括正则方程与残差的几何，留在数学图谱里。

:::summary
- 研究用的回归是$R_{t+1} = a + b s_t + \varepsilon_{t+1}$，其中$s_t$在$t$时刻已知。下标就是决策时钟。
- 当信号不全相等时，最小二乘给出$\hat b = S_{sy}/S_{ss}$与$\hat a = \bar y - \hat b\, \bar s$。证明在数学图谱；本章应用它。
- 在四个编造的配对上，$\hat a = 0.005$、$\hat b = 0.01$、残差是$\pm 0.015$、$R^2 = 5/14$。
- 对信号做正缩放，把斜率除以同一个常数，而截距与$R^2$不变。
- 把收益率对它自己回归给出$\hat a = 0$、$\hat b = 1$、$R^2 = 1$。那个拟合是恒等式，不是预测。同一个收益率的任何仿射函数都一样。
- 路径A的滞后回归在六个重叠配对上斜率为$-1.066049$、$R^2 = 0.909028$。这个$R^2$不是夏普比率，而经典的斜率$t$统计量在这里不是有效的P 值。
- 恒定的信号使$S_{ss} = 0$。此时斜率无定义，这与斜率为零不是一回事。
:::

## 习题

:::exercise 由交叉和求斜率 {#exr-slope level=1 check="0.01"}
在四个配对的例题里，$S_{sy} = 0.05$、$S_{ss} = 5$。计算$\hat b$。（输入斜率。）
:::solution
$\hat b = S_{sy}/S_{ss} = 0.05/5 = 0.01$。斜率是$0.01$。
:::
:::

:::exercise 截距 {#exr-intercept level=1 check="0.005"}
四个下期收益率的均值为$0.02$，信号的均值为$1.5$，且$\hat b = 0.01$。计算$\hat a$。（输入截距。）
:::solution
$\hat a = \bar y - \hat b\, \bar s = 0.02 - 0.01 \times 1.5 = 0.02 - 0.015 = 0.005$。截距是$0.005$。
:::
:::

:::exercise 一个残差 {#exr-resid level=1 check="0.015"}
在$s = 0$处的拟合值是$0.005$，观测到的下期收益率是$0.02$。计算残差。（输入残差。）
:::solution
残差是观测值减拟合值：$0.02 - 0.005 = 0.015$。残差是$0.015$。
:::
:::

:::exercise 方差比例 {#exr-r2 level=2 check="5/14"}
对同样四个配对，$\mathrm{SSE} = 0.0009$、$S_{yy} = 0.0014$。把$R^2$算成最简分数。（输入这个分数。）
:::solution
$R^2 = 1 - 0.0009/0.0014 = 0.0005/0.0014 = 5/14$。这个分数已经是最简的，因为$5$与$14$没有大于$1$的公因子。这个值是$5/14$。
:::
:::

:::exercise 残差平方和 {#exr-sse level=2 check="0.0009"}
四个残差是$0.015, -0.015, -0.015, 0.015$。计算$\mathrm{SSE}$。（输入平方和。）
:::solution
每个平方是$0.000225$，一共有四个：$4 \times 0.000225 = 0.0009$。残差被平方时符号消失了，这就是为什么两个为正、两个为负而幅度相同的残差，与四个正的残差贡献同样的平方和。平方和是$0.0009$。
:::
:::

:::exercise 把信号加倍 {#exr-double level=2 check="0.005"}
从四个配对样本上的$\hat b = 0.01$出发。把每个信号换成它的两倍，下期收益率保持不变。新的斜率是多少？（输入斜率。）
:::solution
由[[#prop-rescale]]取$c = 2$，斜率除以$2$。新的斜率是$0.01/2 = 0.005$。截距保持$0.005$，$R^2$保持$5/14$。更大的信号单位换来更小的斜率，换不来多一点的拟合。
:::
:::

:::exercise 证明恒等式拟合 {#exr-identity level=3}
设$R_1,\ldots,R_n$是不全相等的收益率。证明把$R_i$对$R_i$回归的唯一最小二乘直线是$0 + 1 \cdot R_i$，并由此得出$R^2 = 1$。
:::hint
平方和至少为零。先展示一条取到零的直线，再说明任何其他一条完美直线都会迫使收益率恒为常数。
:::
:::solution
直线$a = 0$、$b = 1$在每个观测上的残差为$0$，所以它的残差平方和是$0$。任何与之竞争的直线残差平方和至少为$0$，所以这条直线是一个最小化者。若对所有$i$都有$a + b R_i = R_i$，则对所有$i$都有$a + (b-1)R_i = 0$。收益率不全相等，所以$R_i$的系数必须消失：$b = 1$，于是$a = 0$。零残差向量给出$\mathrm{SSE} = 0$。因为收益率不全相等，$S_{yy} > 0$，而$R^2 = 1 - 0/S_{yy} = 1$。这就是[[#prop-lookahead]]去掉时钟那一段的版本。时钟阻止的，正是把恒等式报告成预测。
:::
:::

:::exercise 一个没有变动的信号 {#exr-constant level=3 check="0"}
信号在四个决策时刻都取值$1$，下期收益率不全相等。计算$S_{ss}$。然后再用一句话解释为什么最小二乘斜率是无定义而不是零。（输入$S_{ss}$。）
:::hint
$S_{ss}$是信号相对信号均值的偏差平方和。当交叉和为零而信号的平方和为正时，公式返回的才是斜率为零。
:::
:::solution
信号均值是$1$，每个偏差都是$0$。于是$S_{ss} = 0 + 0 + 0 + 0 = 0$。斜率公式除以$S_{ss}$，所以它不返回一个数。斜率为零的情形是$S_{sy} = 0$且$S_{ss} > 0$：信号有变动，而中心化信号与中心化收益率正交。一个恒定的信号永远到不了那种情形。$S_{ss}$的值是$0$。
:::
:::
