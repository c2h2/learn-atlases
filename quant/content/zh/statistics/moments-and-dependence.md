一列收益率有一个中心与一个散布。它还有一层顺序。中心可以为正，而相邻的数值却朝相反的方向偏倚；一连串平滑的上涨可以藏在一列均值接近零的收益率里。趋势规则与均值回归规则说的是这层顺序。它们不是关于均值的论断；而六个重叠配对上的一个大数，也还不是这两个论断中任何一个能在另一个样本上幸存的证据。

本课程通篇使用的价格称为路径A，它是

$$
P = (100,\ 102,\ 101,\ 104,\ 103,\ 107,\ 106,\ 110).
$$

七个简单收益率保留六位小数为$0.020000$、$-0.009804$、$0.029703$、$-0.009615$、$0.038835$、$-0.009346$、$0.037736$。业绩课程记录了除数为$n-1$的样本均值$0.013930$与样本标准差$0.022848$。这两个数字描述的是把顺序丢掉之后的那列数。本章要把顺序放回来，而把它底下的概率指给数学图谱：[期望](/learn/maths/lesson.php?c=probability&l=expectation)与[协方差](/learn/maths/lesson.php?c=probability&l=joint-distributions)。这里算出的任何东西都不是交易建议。

## 中心与散布

一旦陈述了一个模型，单个收益率$R$就是一个随机变量。这个模型可以谦逊到"这七个数就是总体"，也可以强硬到假设相邻的日子是同一分布的独立复制。下面的符号在两种读法下相同；假设却不同。

:::definition 收益率的期望与方差 {#def-moments}
设$R$是一个满足$\E[R^2] < \infty$的收益率。它的**期望**（均值）与**方差**为

$$
\E[R], \qquad \Var(R) = \E\bigl[(R - \E[R])^2\bigr] = \E[R^2] - (\E[R])^2.
$$

标准差为$\sqrt{\Var(R)}$。给定观测$R_1,\ldots,R_n$，**样本均值**与**除数为$n-1$的样本方差**为

$$
\bar R = \frac1n\sum_{t=1}^n R_t, \qquad
s^2 = \frac{1}{n-1}\sum_{t=1}^n (R_t - \bar R)^2.
$$

除数$n-1$就是路径A所用的那一个。除数$n$则是把质量$1/n$放在每个观测上的离散均匀分布的方差。当$n$很小时，两种约定不可互换；而且哪一种都用不到观测的顺序。
:::

在路径A上，$n = 7$，$\bar R = 0.013930$，$s = 0.022848$。比率$\bar R / s = 0.6097$是一个每步尺度，不是年化夏普比率。把它乘以$\sqrt{252}$会造出一个七天支撑不了的大数；这一对比属于[[performance/uncertainty-of-performance]]。路径上的复合简单收益率为$0.10$，因为$110/100 - 1 = 0.10$，而它不是简单收益率之和。把简单收益率相加是另一种运算，[[performance/simple-and-log-returns]]已把它与复合分开过。

样本均值是线性的。样本方差不是。两个序列可以有相同的均值与方差，却依然在规则在意的一切方面不同，因为规则在意的是哪个收益率挨着哪个收益率。

:::quiz
路径A的样本均值是$0.013930$，复合简单收益率是$0.10$。哪一句话是正确的？
- [ ] 复合收益率等于七个简单收益率之和。
- [ ] 除数为$n-1$的样本方差用到了七个收益率的顺序。
- [x] 均值与方差描述的是把顺序丢掉之后的那列收益率。
- [ ] 均值为正会迫使滞后1阶相关系数为正。
:::solution
把这七个收益率换一种顺序写，样本均值与样本方差不变。复合收益率不是简单收益率之和。均值的符号与滞后1阶相关的符号是两回事，而在这条路径上它们彼此相反。
:::
:::

## 协方差、相关系数与一个和

分散化是一条关于协方差的陈述。代数很短，而它是组合计算中属于这里、不属于某条权重规则的那一部分。

:::definition 协方差与相关系数 {#def-corr}
设$X$与$Y$的方差有限，且$\Var(Y) > 0$、$\Var(X) > 0$。**协方差**与**相关系数**为

$$
\Cov(X, Y) = \E\bigl[(X - \E X)(Y - \E Y)\bigr], \qquad
\Corr(X, Y) = \frac{\Cov(X, Y)}{\sqrt{\Var(X)\,\Var(Y)}}.
$$

只有当两个方差都为正时相关系数才有定义。它落在$[-1, 1]$之内。样本版本把期望替换为你实际持有的那些配对的平均，而且你必须说清除数是配对数还是配对数减一。只要协方差与两个方差用的是同一个除数，除数就会在相关系数中消去。
:::

:::proposition 和的方差 {#prop-var-sum}
若$X$与$Y$的方差有限，则

$$
\Var(X + Y) = \Var(X) + \Var(Y) + 2\,\Cov(X, Y).
$$

若协方差为零，方差相加。若协方差为负，$\Var(X+Y)$小于$\Var(X) + \Var(Y)$。
:::

:::proof
把定义里面的平方展开。写$X' = X - \E X$与$Y' = Y - \E Y$，于是$\E X' = \E Y' = 0$，且$X + Y - \E(X+Y) = X' + Y'$。那么

$$
\Var(X+Y) = \E[(X' + Y')^2] = \E[X'^2] + \E[Y'^2] + 2\E[X'Y'],
$$

这就是$\Var(X) + \Var(Y) + 2\Cov(X, Y)$。关于协方差符号的那两句话立即可得：协方差为零时交叉项消失，协方差为负时它是往外扣的。方差有限是让每一项都存在的那个假设。$X$与$Y$独立足以给出零协方差，但零协方差不要求独立。
:::

这个命题就是两个收益率序列之间的负关联会缩小它们之和的方差的原因。它不是一套对冲配方。公式里的协方差是一个输入。从短窗口估出来时它会变；而电子表格里的一个$-1$相关系数，是一个假设两条序列恰好精确抵消的设定，而成交的价格并不是这样。

:::proposition 重新缩放与相关系数的符号 {#prop-scale}
设$\Corr(X, Y)$存在，$c > 0$且$d \neq 0$。那么

$$
\Corr(cX,\ dY) = \operatorname{sign}(d)\,\Corr(X, Y).
$$

两个序列同乘正常数，相关系数不变。只把其中一个序列乘以负常数，符号翻转。
:::

:::proof
协方差按常数的乘积缩放：$\Cov(cX, dY) = cd\,\Cov(X, Y)$。因为$c > 0$，$cX$的标准差是$X$的标准差的$c$倍。$dY$的标准差是$Y$的标准差的$\abs{d}$倍，出现绝对值是因为标准差是一个平方根。于是

$$
\Corr(cX, dY) = \frac{cd}{c\,\abs{d}}\Corr(X, Y) = \operatorname{sign}(d)\,\Corr(X, Y),
$$

其中最后一步是$d/\abs{d} = \operatorname{sign}(d)$。原相关系数存在这一假设，就是两个方差皆正且有限这一假设，所以缩放后的方差也正。
:::

改变收益率的计价单位，或者用百分比而不是小数来报它，是一种正向缩放。相关系数不会察觉。改变多空配对里哪一条腿被叫作"左"腿，可以翻转一个符号；而这个命题说，翻转在定义里，不在数据里。

:::quiz
两个收益率序列的样本相关系数是$0.4$。第一个序列的每个收益率都乘以$10$，第二个序列的每个收益率都乘以$-2$。新的相关系数是多少？
- [ ] $0.4$
- [ ] $-8$
- [ ] $8$
- [x] $-0.4$
:::solution
由[[#prop-scale]]取$c = 10$，第一个序列上的正缩放对相关系数不起作用。第二个序列上的负缩放翻转符号，不改变大小。新的相关系数是$-0.4$，不是$-8$：相关系数没有单位可以去吸收因子$20$。
:::
:::

## 滞后1阶自相关

单期规则所争论的那种相依性，是一个收益率与它前一个收益率之间的关联。

:::definition 滞后1阶样本相关系数 {#def-rho}
设$R_1,\ldots,R_n$是一个$n \ge 3$的收益率序列，并设前$n-1$个值不全相等、后$n-1$个值不全相等。记

$$
\bar R_{-} = \frac{1}{n-1}\sum_{t=1}^{n-1} R_t, \qquad
\bar R_{+} = \frac{1}{n-1}\sum_{t=2}^{n} R_t.
$$

**滞后1阶样本相关系数**是那$n-1$个配对$(R_{t-1}, R_t)$的普通相关系数：

$$
\hat\rho_1
= \frac{\sum_{t=2}^{n}(R_{t-1} - \bar R_{-})(R_t - \bar R_{+})}
{\sqrt{\sum_{t=2}^{n}(R_{t-1} - \bar R_{-})^2\;\sum_{t=2}^{n}(R_t - \bar R_{+})^2}}.
$$

$\hat\rho_1$为正，意味着在每一段都对自己的均值中心化之后，乘积$(R_{t-1}-\bar R_{-})(R_t-\bar R_{+})$平均而言为正。$\hat\rho_1$为负，意味着这些乘积平均而言为负。在平稳模型之下，总体版本只用一个方差，$\rho_1 = \Cov(R_t, R_{t-1}) / \Var(R_t)$。上面的样本定义并不假设两段有相同的方差。
:::

:::proposition 滞后1阶样本相关系数的符号 {#prop-sign}
在[[#def-rho]]中，分母为正。因此$\hat\rho_1$与$\sum_{t=2}^{n}(R_{t-1}-\bar R_{-})(R_t-\bar R_{+})$同号，且$\hat\rho_1 = 0$当且仅当那个和为零。
:::

:::proof
由[[#def-rho]]中的假设，两段都不是常数，所以分母里每个平方和都为正。正数的平方根是正的，两个正数的乘积是正的。分母既不能翻转分子的符号，也不能把为零的分子变成一个非零的相关系数。$\hat\rho_1$的符号就是中心化乘积之和的符号，这正是命题所说的。
:::

符号的全部内涵就是这些。一个趋势假说，在一个指明阶数的滞后上，就是这个和在总体中为正的假说：一个高于其均值的收益率之后，往往跟着另一个高于其均值的收益率。一个短周期均值回归假说，则是这个和为负的假说。在滞后的阶数、标的范围与期限变得相同之前，这两个假说并不互相矛盾。一个序列可以在一个滞后阶上正相关、在另一个滞后阶上负相关，而下一个例子正是为让这种对立恰好成立构造的。

另一种约定把同一个均值——全部$n$个收益率的均值——放进两个因子，并除以偏差平方和$\sum_{t=1}^{n}(R_t - \bar R)^2$。这是一种常见的软件自相关。它不是[[#def-rho]]里的相关系数。在路径A上，这两个数是$-0.953430$与$-0.833314$。两者都为负。它们不是同一个统计量；后面的一道习题会要你在一个四点序列上把它们分辨开。

:::example 路径A的滞后1阶相关 {#ex-path-a}
对路径A的七个精确简单收益率计算$\hat\rho_1$。共有六个配对。报告两段的均值、中心化乘积之和以及相关系数。
:::solution
精确的简单收益率来自价格比率$P_t/P_{t-1} - 1$。保留六位小数就是开头那张清单；六个配对$(R_{t-1}, R_t)$是

| 配对 | $R_{t-1}$ | $R_t$ |
|---|---:|---:|
| 1 | $0.020000$ | $-0.009804$ |
| 2 | $-0.009804$ | $0.029703$ |
| 3 | $0.029703$ | $-0.009615$ |
| 4 | $-0.009615$ | $0.038835$ |
| 5 | $0.038835$ | $-0.009346$ |
| 6 | $-0.009346$ | $0.037736$ |

符号交替，所以每个原始乘积$R_{t-1} R_t$本来就已为负。中心化并不改变这个结论。前六个收益率的均值是$\bar R_{-} = 0.009962$。后六个的均值是$\bar R_{+} = 0.012918$。两者都与七点均值$0.013930$不同，因为第二个收益率序列里没有第一个收益率，第一个收益率序列里没有最后一个收益率。六个中心化乘积之和是$-0.002634$。由[[#prop-sign]]，相关系数为负。它的值由精确比率算出，为

$$
\hat\rho_1 = -0.953430.
$$

两段的样本标准差（除数为$5$）是$0.022230$与$0.024856$。它们接近，但不相等，这就是单一方差公式是进一步的建模选择的原因。先把每个收益率舍入到六位小数再算相关，只在小数点后第六位改动结果，变为$-0.953429$。

六个重叠配对是一个短样本。收益率共享各项——第二个收益率作为后项出现一次、作为前项出现一次——所以这些配对不是独立的二元样本。在白噪声假设下，样本自相关的一个粗略的大样本尺度是$1/\sqrt{n} = 1/\sqrt{7} \approx 0.378$。估计值$-0.953430$在幅度上大于那个尺度，而这个尺度本身在这里并不是一个有效的标准误：$n$很小，配对重叠，而交替是在同样这七个点上注意到的。这个数字记录的是这条路径上的符号。它不在为任何别的资产估计一个均值回归参数，也不是一条规则。
:::
:::

:::example 反转一个序列会翻转符号 {#ex-reverse}
取两个滞后值$u = (0.01,\ 0.03)$与两个后值$v = (0.02,\ 0.04)$。计算配对$(0.01, 0.02)$与$(0.03, 0.04)$的相关系数。然后只把后值序列反转成$v' = (0.04,\ 0.02)$，再算一次相关系数。
:::solution
$u$的均值是$0.02$，所以偏差是$-0.01$与$+0.01$。$v$的均值是$0.03$，所以偏差是$-0.01$与$+0.01$。两个中心化乘积都为正，而两点位于一条正斜率的直线上，所以相关系数是$+1$。

反转后的序列$v'$有同一个均值$0.03$，偏差是$+0.01$与$-0.01$。中心化乘积现在都是负的，直线向下倾斜，所以相关系数是$-1$。

只反转后值序列、而把滞后序列留在原处，会翻转$\hat\rho_1$的符号。只有两个配对时，任何两个非常数序列的相关系数都是$+1$或$-1$，因为两点确定一条直线，而样本相关系数只记录这条直线斜率的符号。这个例子把这个符号孤立出来。它对市场上可能见到的幅度什么都没说，而且它不是路径A。把整条路径倒序是另一种操作：相邻配对回来时两个坐标互换，而互换两个坐标不改变相关系数。这一点在下面是一道习题；这也是为什么"倒放磁带"不是把正滞后变成负滞后的办法。
:::
:::

:::example 等权重与被选定的相关系数 {#ex-sum}
设$X$与$Y$是假想的收益率贡献，标准差为$0.02$与$0.02$，相关系数为$0.5$。这些数字是选定的，不是估计的。求等权重和$\tfrac12 X + \tfrac12 Y$的方差。把它与相关系数$0$、相关系数$1$和相关系数$-1$比较。
:::solution
相关系数$0.5$时的协方差是$0.5 \times 0.02 \times 0.02 = 0.0002$。对权重$w_X = w_Y = \tfrac12$，

$$
\begin{align*}
\Var(w_X X + w_Y Y)
&= w_X^2 \Var(X) + w_Y^2 \Var(Y) + 2 w_X w_Y \Cov(X, Y) \\
&= \tfrac14(0.0004) + \tfrac14(0.0004) + 2\cdot\tfrac12\cdot\tfrac12\cdot 0.0002 \\
&= 0.0001 + 0.0001 + 0.0001 = 0.0003.
\end{align*}
$$

标准差是$\sqrt{0.0003} \approx 0.017321$。同样这套算术，把交叉项去掉或替换掉，给出：

- 相关系数$0$：方差$0.0002$，标准差$\sqrt{0.0002} \approx 0.014142$；
- 相关系数$1$：方差$0.0004$，标准差$0.02$，与每个成分相同，因为两个成分此时除均值平移外完全一样；
- 相关系数$-1$：方差$0$。

最后一行就是[[#prop-var-sum]]在协方差恰好大到抵消两个方差项时的样子。它是在我们输入的一个假设之下的代数恒等式。它不是从路径A得到的估计，也不是任何成交配对会相互抵消的证据。
:::
:::

:::example 两个滞后阶，两个符号 {#ex-two-lags}
设构造序列为$1, 2, 1, 2, 1, 2$。它不是来自市场的收益率序列。按与[[#def-rho]]相同的方式在配对$(x_t, x_{t+2})$上定义并计算滞后2阶样本相关系数，同时计算滞后1阶样本相关系数。
:::solution
滞后1阶配对是$(1, 2)$、$(2, 1)$、$(1, 2)$、$(2, 1)$、$(1, 2)$。每当第一个坐标是较小的值，第二个就是较大的值，反之亦然。中心化乘积全为负，点位于斜率$-1$的直线上，所以$\hat\rho_1 = -1$。

滞后2阶配对是$(1, 1)$、$(2, 2)$、$(1, 1)$、$(2, 2)$。每个配对的两个坐标都相等，所以滞后2阶相关系数是$+1$。

一个序列同时带有两个符号。"这个序列是持续的"这类说法，不指明滞后阶就不算说完。[[trend/the-trend-hypothesis]]接手的趋势假说与[[reversion/the-reversion-hypothesis]]接手的短周期均值回归假说，是关于不同滞后阶、不同标的范围、或者两者皆不同的假说。路径A只是一个滞后1阶的计算，在七个点上，带一个负号。它不替任何一个假说裁决。
:::
:::

:::intuition 顺序不是单个边际分布的矩
均值与方差是由清单$\{R_t\}$作为一组带重数的取值算出来的。路径A的任何重排都有同样的样本均值与同样的样本方差。[[#def-rho]]的滞后1阶相关用的是配对，所以重排一般会改变它。收益率的直方图，无论它与正态曲线拟合得多好，都已经把配对丢掉了。在这幅图里，相依性是看不见的。
:::

:::warning 短路径上的一个大相关系数
值$-0.953430$看起来有决定性，因为它接近$-1$。它是从六个重叠配对、在一条凭肉眼就交替的路径上算出来的。换掉滞后阶、延长路径、或者重排同样这七个数，都能使它移动。[[#prop-scale]]说改变计价单位不会使它移动。读者有时会拿同样这七个点对$\bar R / s$做年化；那个错误住在业绩课程里，而它是同一种把玩具样本当作稳定参数的习惯。不要把$-0.953430$提升成一个均值回归速度，也不要因为一条教科书路径交替过，就逆着最后一笔变动去交易。
:::

:::application 这个符号是什么的证据
正的总体滞后1阶相关，是一个单期趋势论断的统计投影：一个中心化收益率的符号倾向于延续一步。负的总体滞后1阶相关，是一个单期均值回归论断的投影。"投影"是恰当的措辞。相关系数不是权重、不是订单、也不是含成本的回测。在长的周频股票序列上估计它，也是方差比统计量要探查的东西，而且更高效；下面1988年的那个结果就用了那个统计量。本章止步于后面的假说必须点名的那个相关系数。
:::

:::remark 两种约定，一条路径
在路径A上，[[#def-rho]]的配对相关是$-0.953430$；而在两个因子里都用$\bar R = 0.013930$、分母用七点偏差平方和的全均值自相关是$-0.833314$。打印"acf"的软件常常算的是后者。引用数字时请连同公式一起引用。这里符号一致。符号一致不等于统计量相同；而在短序列上，两个分母可以相差很大，$(0, 1, 2, 0)$那道习题就说明了这一点。
:::

:::history
1988年，安德鲁·洛（Andrew W. Lo）与A. 克雷格·麦金莱（A. Craig MacKinlay）用一个方差比检验拒绝了美国周频股票收益率的随机游走假说。那种相依性可以在统计上可检出，同时在经济上很小。滞后1阶相关，是一个单期规则所指的最简单的相依性。在一个长样本中、在一个事先指定的检验之下检出对零的偏离，不是一个交易决定；而[[#ex-path-a]]里那个七点估计也不是那种检出。
:::

## 通向何处

下一章把配对$(s_t, R_{t+1})$变成一条直线，并要求信号在$t$时刻已知。那就是[[statistics/regression-on-a-signal]]。平稳性——本章在写出总体$\rho_1$时顺手一提的平稳性——见[[statistics/stationarity-and-regimes]]。$\hat\rho_1$在指明期限上的两个符号，是[[trend/the-trend-hypothesis]]与[[reversion/the-reversion-hypothesis]]的假说。均值的标准误，以及七个观测为什么支撑不了一个年化比率，见[[performance/uncertainty-of-performance]]。

:::summary
- 期望与方差描述的是丢掉顺序之后的收益率。在路径A上，它们是$0.013930$与$0.022848^2$，除数为$n-1$。
- $\Var(X+Y) = \Var(X) + \Var(Y) + 2\Cov(X, Y)$。负的协方差缩小和的方差。这个恒等式不是对冲。
- 相关系数在正缩放下不变；若恰有一个自变量乘以负常数，则符号翻转。
- 滞后1阶样本相关系数是配对$(R_{t-1}, R_t)$的相关系数。它的符号是中心化乘积之和的符号。
- 在路径A上，这个相关系数是$-0.953430$，出自六个重叠配对。这个估计噪声很大，也不是一条交易规则。
- 在两点的例子里，只反转后值序列、而不是整盘磁带，会翻转符号。同一个序列的两个滞后阶上可以同时出现两个符号。
- 一条采用路径A的均值与标准差的边际正态曲线，显示不出这种相依性。
:::

## 习题

:::exercise 三个收益率 {#exr-three level=1 check="0.01"}
简单收益率$0.02$、$-0.01$与$0.02$不是路径A。计算它们的样本均值。（输入样本均值。）
:::solution
和是$0.02 - 0.01 + 0.02 = 0.03$，而$0.03/3 = 0.01$。均值与顺序无关。样本均值是$0.01$。
:::
:::

:::exercise 三点的符号 {#exr-sign level=1 check="-1"}
对序列$1, 3, 2$计算滞后1阶样本相关系数。共有两个配对。（输入相关系数。）
:::solution
配对是$(1, 3)$与$(3, 2)$。滞后段的均值是$(1+3)/2 = 2$，所以滞后段的偏差是$-1$与$+1$。后值段的均值是$(3+2)/2 = 2.5$，所以后值段的偏差是$+0.5$与$-0.5$。中心化乘积是$-0.5$与$-0.5$，两点位于一条下行直线上。相关系数是$-1$。
:::
:::

:::exercise 和的方差 {#exr-var level=1 check="11"}
设$\Var(X) = 4$、$\Var(Y) = 9$、$\Cov(X, Y) = -1$，三个矩都有限。计算$\Var(X+Y)$。（输入方差。）
:::solution
由[[#prop-var-sum]]，$\Var(X+Y) = 4 + 9 + 2(-1) = 11$。负的协方差把和的方差从$13$降到$11$。它没有把方差变成负的。方差是$11$。
:::
:::

:::exercise 一个四点相关系数 {#exr-four level=2 check="-1/2"}
按[[#def-rho]]的定义计算$0, 1, 2, 0$的滞后1阶样本相关系数。（输入相关系数，以分数表示。）
:::solution
配对是$(0, 1)$、$(1, 2)$与$(2, 0)$。滞后段的均值是$(0+1+2)/3 = 1$，偏差是$-1$、$0$、$+1$。后值段的均值是$(1+2+0)/3 = 1$，偏差是$0$、$+1$、$-1$。中心化乘积是$0$、$0$与$-1$，所以分子是$-1$。每个平方和都等于$1 + 0 + 1 = 2$，所以分母是$\sqrt{2 \times 2} = 2$。相关系数是$-1/2$。
:::
:::

:::exercise 把相关系数代入 {#exr-plug level=2 check="0.0003"}
用标准差$0.02$与$0.02$、相关系数$0.5$重做[[#ex-sum]]的等权重计算。（输入等权重和的方差。）
:::solution
协方差是$0.0002$。方差是

$$
\tfrac14(0.0004) + \tfrac14(0.0004) + \tfrac12(0.0002) = 0.0003.
$$

交叉项贡献了第三个$0.0001$。方差是$0.0003$。
:::
:::

:::exercise 另一个滞后阶 {#exr-lag2 level=2 check="1"}
对构造序列$1, 2, 1, 2, 1, 2$计算滞后2阶样本相关系数。（输入相关系数。）
:::solution
滞后2阶配对是$(1, 1)$、$(2, 2)$、$(1, 1)$与$(2, 2)$，如[[#ex-two-lags]]。每个配对的两个坐标都吻合，所以相关系数是$1$。同一序列的滞后1阶相关是$-1$。本题要的答案是滞后2阶的值，$1$。
:::
:::

:::exercise 倒放磁带 {#exr-tape level=3}
设$x_1,\ldots,x_n$是一个滞后1阶样本相关系数存在的序列。设$y_t = x_{n+1-t}$是时间倒序序列。证明$y$的滞后1阶样本相关系数等于$x$的滞后1阶样本相关系数。
:::hint
把$y$的相邻配对列出来。其中每一个都是原来的相邻配对、两个坐标互换、按相反次序写成的。相关系数不在乎那个次序，而且它对两个坐标是对称的。
:::
:::solution
$x$的相邻配对是$(x_1, x_2), (x_2, x_3), \ldots, (x_{n-1}, x_n)$。$y$的相邻配对是$(x_n, x_{n-1}), (x_{n-1}, x_{n-2}), \ldots, (x_2, x_1)$。那是同一组点，坐标互换、清单倒序。倒转一张清单不改变样本相关系数。把每个点的两个坐标互换，是把$\Corr(U, V)$换成$\Corr(V, U)$，而只要其中任何一个存在，二者就是同一个数。因此滞后1阶样本相关系数在时间倒序下精确不变。它不翻转。[[#ex-reverse]]里的符号翻转，来自只反转两个序列中的一个，而不是来自倒放磁带。
:::
:::

:::exercise 一个序列上的两个公式 {#exr-acf level=3 check="-13/44"}
对$x = (0, 1, 2, 0)$，[[#def-rho]]的配对相关是$-1/2$，见[[#exr-four]]。现在计算全均值自相关

$$
\frac{\sum_{t=2}^{4}(x_t - \bar x)(x_{t-1} - \bar x)}{\sum_{t=1}^{4}(x_t - \bar x)^2},
$$

其中$\bar x$是全部四个点的均值。（输入这个值，以分数表示。）
:::hint
四点均值是$3/4$，不是皮尔逊计算里用的分段均值$1$。分母要把四个偏差分别平方，而且不要把那个分母替换成两个单独分段范数的乘积。
:::
:::solution
均值是$\bar x = (0+1+2+0)/4 = 3/4$。$(x_1, x_2, x_3, x_4)$相对$3/4$的偏差是$-3/4$、$1/4$、$5/4$、$-3/4$。分子用到三个相邻乘积

$$
\bigl(\tfrac14\bigr)\bigl(-\tfrac34\bigr) + \bigl(\tfrac54\bigr)\bigl(\tfrac14\bigr) + \bigl(-\tfrac34\bigr)\bigl(\tfrac54\bigr)
= -\tfrac{3}{16} + \tfrac{5}{16} - \tfrac{15}{16} = -\tfrac{13}{16}.
$$

分母是

$$
\bigl(-\tfrac34\bigr)^2 + \bigl(\tfrac14\bigr)^2 + \bigl(\tfrac54\bigr)^2 + \bigl(-\tfrac34\bigr)^2
= \tfrac{9}{16} + \tfrac{1}{16} + \tfrac{25}{16} + \tfrac{9}{16} = \tfrac{44}{16} = \tfrac{11}{4}.
$$

比值是$(-13/16) / (11/4) = -13/44$。这不是$-1/2$。两个公式都是自相关。它们对序列的中心化方式不同，标准化方式也不同。在一个短序列上，这个数值差是答案的一部分，不是舍入误差。这个值是$-13/44$。
:::
:::
