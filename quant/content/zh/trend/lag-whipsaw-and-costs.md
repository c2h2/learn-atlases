一条平均值无法在制造它的那个收盘价的同一时刻报出一个转折。最新的收盘价是和式里的一项，其余各项都更旧。那个延迟就是滞后。如果滞后的信号翻转、然后又翻回来，账户就在一段没有延续的变动上进场付一次、离场再付一次。这样一个回合就是来回止损。每单位换手的成本把这个回合变成了算术。三者都不是趋势规则的脚注。规则一旦被写成一个持有，它们每一个都是那条规则所主张内容的一部分。

交叉已经用过的那条路径就是路径A，收盘价$100, 102, 101, 104, 103, 107, 106, 110$，$t = 0,\ldots,7$。[[trend/moving-averages]]算出了$\mathrm{SMA}_3$对$\mathrm{SMA}_5$规则的头寸：到$t = 3$为止持币，在$t = 4, 5, 6, 7$做多，头寸变动一次，毛复合收益率$7/103 = 0.067961$，来自获支付的交易日$R_5, R_6, R_7$。本章以单边成本$c = 0.001$为那一次变动定价。要数得了一次翻回去，还需要第二条更长的编造路径。它下面就算出来，而不是一处市场。

## 直线上的滞后与波峰处的滞后

:::definition 回看窗口的滞后 {#def-lag}
$\mathrm{SMA}_n$的**滞后**，指在讲得通的一条路径上，收盘价上的一个参考日期与该平均值反映出该参考的日期之间的交易日数。在一条直线上，这个数目是精确的，等于$(n-1)/2$。在一条有波峰的路径上，本章把滞后度量成收盘价的波峰与较晚到来的平均值的波峰之间的交易日数。更长的窗口的直线滞后至少一样大，因为$(n-1)/2$随$n$增加。更大的滞后是更晚的信号，不是一种更保守的哲学。
:::

:::proposition 直线上的SMA等于线上更早的一点 {#prop-linear-lag}
设对每个整数$t$都有$P_t = a + bt$，$a$与$b$为常数。对$n \ge 1$与$t \ge n - 1$，

$$
\mathrm{SMA}_n(t) = a + b\Bigl(t - \frac{n-1}{2}\Bigr),
$$

那是那条直线在$t$之前$(n-1)/2$个交易日的取值。当$n$为奇数时，这个值就是被观察到的收盘价之一，位于窗口的正中。
:::

:::proof
由定义，

$$
\mathrm{SMA}_n(t) = \frac1n\sum_{i=0}^{n-1} \bigl(a + b(t-i)\bigr) = a + bt - \frac{b}{n}\sum_{i=0}^{n-1} i.
$$

从$0$开始的前$n$个非负整数之和等于$(n-1)n/2$，所以被减去的项是$b(n-1)/2$。因此平均值等于$a + b\bigl(t - (n-1)/2\bigr)$，即$P$在时刻$t - (n-1)/2$的取值。若$n = 2m+1$，滞后是整数$m$，而窗口$\{t-n+1,\ldots,t\}$的正中是观察值$t - m$。
:::

$n = 3$时滞后为$1$个交易日。$n = 5$时为$2$。一条"快均线高于慢均线时做多"的规则，在一条上升的直线上，比较的是同一条直线的两个延迟副本。快的那个副本更新一些，所以在两个窗口都存在之后，只要$b > 0$，不等式就成立。没有任何新消息到来。交叉是两个滞后的排序。

波峰是这样一个地方：延迟在那里变成了关于时点的一个错误，而不是沿一条直线的一次平移。插图用的是一条每个交易日采样一次的正弦，

$$
Q_t = 100 + 10\sin\bigl(\pi t / 6\bigr), \qquad t = 0, 1, \ldots, 12.
$$

在周期的整数倍处的取值很平常：$Q_0 = 100$、$Q_1 = 105$、$Q_3 = 110$、$Q_5 = 105$、$Q_6 = 100$、$Q_7 = 95$、$Q_9 = 90$、$Q_{12} = 100$。不在格点上的采样是$Q_2 = Q_4 = 100 + 5\sqrt{3} \approx 108.660254$与$Q_8 = Q_{10} = 100 - 5\sqrt{3} \approx 91.339746$。$Q$的唯一最大值在$t = 3$。

:::example 平均值的波峰来得更晚 {#ex-sine}
在序列$Q_t$上，在$\mathrm{SMA}_3$与$\mathrm{SMA}_5$存在的每个日期计算它们，保留四位小数，并报告各自最大值的日期。
:::solution
$\mathrm{SMA}_3$舍入到四位小数，从$t = 2$一直排到$t = 12$：

$$
104.5534,\ 107.8868,\ 109.1068,\ 107.8868,\ 104.5534,\ 100,\ 95.4466,\ 92.1132,\ 90.8932,\ 92.1132,\ 95.4466.
$$

唯一最大值是$109.1068$，在$t = 4$，比收盘价在$t = 3$处见峰晚一个交易日。那就是一个三日窗口的直线滞后，此刻在一次转折上看得见：在$t = 4$，收盘价已经回落到大约$108.6603$，而平均值仍在报出它的高点，因为$t = 3$处的那个高收盘价刚刚走到窗口的正中央。

$\mathrm{SMA}_5$从$t = 4$到$t = 12$，保留四位小数：

$$
106.4641,\ 107.4641,\ 106.4641,\ 103.7321,\ 100,\ 96.2679,\ 93.5359,\ 92.5359,\ 93.5359.
$$

唯一最大值是$107.4641$，在$t = 5$，比收盘价见峰晚两个交易日。五日平均比三日平均更晚，正如[[#prop-linear-lag]]所提示的那样，也像一个波峰会使其变得昂贵的那样：到$t = 5$，收盘价是$105$，比它的高点低五个点，而慢平均值这才刚刚到达它自己的高点。一个等待慢均线的交叉，要等过那段下跌。等待不因为窗口更长就免费。
:::
:::

把图中的慢窗口拉长。慢均值的变化比价格更慢，而交叉的次数变少。在一条直线上，本章证明$n$日的均值等于那条直线提前(n−1)/2步的取值。这条路径不是直线，所以那条恒等式不是读数里的那个数目。滞后仍然是阴影没有落在价格的波峰上的原因。

这个控件是同一件事实的连续版本。$\sin$在$[x-L, x]$上的均值等于$\frac{2}{L}\sin(L/2)\sin(x - L/2)$——只要$L$不是那种会使振幅归零的$2\pi$的倍数——而相位$L/2$就是滞后。增大$L$会把波峰推得更晚。它根本不会移动原始正弦的波峰。

## 来回止损

:::definition 来回止损 {#def-whipsaw}
**来回止损**是这样一对方向相反的头寸变动：它把账户带回它已经离开过的一个状态，而在其间的一段上，为第一次变动提供理由的那段价格变动并没有朝那个方向延续。在多头或持币的情形，这个形态是：做多、然后持币、然后再做多：从一个状态两次出场；若把入场、出场与再入场都数进去，就是三次单位变动。中间那个状态挣得现金收益率。外面两个状态挣到的是风险收益率本身，而到滞后的信号到来时，那个符号可能已经是错的了。
:::

路径A不包含这个形态。它的3对5旗标是先持币、后做多，各一次。把那次入场叫作来回止损，会把这个词掏空。真正包含它的路径是路径B，为本章而发明，并用精确分数核对过：

$$
P^{B} = (100,\ 102,\ 106,\ 110,\ 112,\ 108,\ 102,\ 98,\ 103,\ 109,\ 115),
$$

交易日$t = 0,\ldots,10$。收盘价升到$t = 4$处的$112$，跌到$t = 7$处的$98$，再升到$t = 10$处的$115$。

:::example 一个翻转又翻回去的交叉 {#ex-pathb}
在路径B上，在两者都存在处计算$\mathrm{SMA}_3$与$\mathrm{SMA}_5$，列出[[trend/moving-averages]]的多头或持币旗标，并列出头寸发生变动的交易日。写出被支付的风险收益率。
:::solution
两个均值都从$t = 4$起存在。

| $t$ | $P^{B}_t$ | $\mathrm{SMA}_3$ | $\mathrm{SMA}_5$ | 旗标 |
|---|---|---|---|---|
| $4$ | $112$ | $328/3 \approx 109.3333$ | $106$ | 做多 |
| $5$ | $108$ | $110$ | $107.6$ | 做多 |
| $6$ | $102$ | $322/3 \approx 107.3333$ | $107.6$ | 持币 |
| $7$ | $98$ | $308/3 \approx 102.6667$ | $106$ | 持币 |
| $8$ | $103$ | $101$ | $104.6$ | 持币 |
| $9$ | $109$ | $310/3 \approx 103.3333$ | $104$ | 持币 |
| $10$ | $115$ | $109$ | $105.4$ | 做多 |

旗标依次为做多、做多、持币、持币、持币、持币、做多。在$t = 4$之前从持币起步，头寸在$t = 4$（入场）、$t = 6$（出场）与$t = 10$（再入场）处变动。那就是[[#def-whipsaw]]里的那个形态。

标注在$t$的头寸挣$R_{t+1}$。因此被支付的风险收益率只有$R_5$与$R_6$：

$$
R_5 = \frac{108}{112} - 1 = -\frac{1}{28}, \qquad R_6 = \frac{102}{108} - 1 = -\frac{1}{18}.
$$

现金为$0$时的增长因子是$(27/28)\cdot(17/18) = 51/56$。复合收益率为$-5/56 = -0.089286$，六位小数。从$98$到$115$的反弹是真实的，而且几乎完全没有被支付：慢均线让旗标一直到$t = 9$都持币，而$t = 10$处的再入场在样本之内没有下一个交易日。滞后正是这件事的原因：在波峰处的入场与在末尾的再入场，把账户实际持有过的一段下跌夹在中间，而账户没有持有过的那段回升，躺在持币的那一段里。这是一条构造出来的路径。它展示的是机制。它没有展示交叉在市场上一概亏损。
:::
:::

换手是目标权重相对$0$起步的各次绝对变动之和。在路径B上，三次变动每次的量都是$1$，所以换手为$3$。在路径A上，唯一那次入场的量为$1$，所以换手为$1$。两种情形都不追加期末清仓。一条在最后一个收盘价处把账簿清成空仓的规格说明，会在任何以做多收尾的路径上再加一个单位，而那将是另一条规格说明。

## 按每一单位成交收取的成本

:::definition 比例换手成本 {#def-cost}
固定满足$0 \le c < 1$的$c$。当财富为$W$的那一刻，目标权重变动$\tau$，其中$\tau \ge 0$为以$W$的分数计的成交名义额，则财富乘以$1 - c\tau$，条件是$c\tau < 1$。这笔收费在调仓时收取，先于账户挣得下一个交易日的收益率。除某句话另有说明外，现金收益为$0$。一连串调仓，把这些因子与实际持有的各个交易日的毛收益因子一起连乘。
:::

收费$c\tau$对那一刻的成交名义额是线性的。在两个不同时刻各一次、量都为$1$的调仓，贡献两个$1 - c$的因子。一次量为$2$的调仓——例如从多头翻到空头——贡献单个因子$1 - 2c$，它与$(1-c)^2$并不相同。下面的命题只用第一种情形。

:::proposition 做多、持币、再做多的成本因子 {#prop-cost}
假设[[#def-cost]]中的成本模型、现金收益率为$0$，风险简单收益率为$R_a > -1$、$R_b > -1$。头寸路径（此外别无其他）是：从持币入场一个单位，做多的期间挣$R_a$，出场到持币，持币的期间挣$0$，再次入场一个单位，做多的期间挣$R_b$。共有三次调仓，每次的量都是$\tau = 1$，且没有期末清仓。设$G_0 = (1+R_a)(1+R_b)$为同一条头寸路径在$c = 0$之下的增长因子。则净增长因子为

$$
G(c) = G_0\,(1-c)^3.
$$

净复合收益率$G(c) - 1$不等于$(G_0 - 1)\,(1-c)^3$，也不等于$G_0 - 1 - 3c$，除非在输入的某些孤立的取值上。
:::

:::proof
从财富$1$开始。入场乘以$1 - c$。做多的那段乘以$1 + R_a$。出场乘以$1 - c$。持币的那段乘以$1$。再入场乘以$1 - c$。第二段做多乘以$1 + R_b$。乘积是$(1+R_a)(1+R_b)(1-c)^3$，即$G_0(1-c)^3$。

毛复合收益率是$G_0 - 1$。把这个量乘以$(1-c)^3$，会让那个$-1$也一并被同一个因子乘过，于是恢复不出$G(c) - 1 = G_0(1-c)^3 - 1$。而从$G_0 - 1$中减去$3c$，既忽略了收费在一个乘积之内的时点，也忽略了$1 - 3c + 3c^2 - c^3$与$1 - 3c$的差别。这两个表达式只在一堆特殊情形上相符，而不是作为恒等式。
:::

因子$(1-c)^3$是这条头寸路径的显式成本因子。它乘的是毛增长因子。它不乘毛复合收益率。路径A的那个算例，正是可以看出"减去$c$"会在一个确定的分数上落空的地方。

:::example 千分之一成本下的路径A {#ex-cost-a}
3对5交叉在路径A上头寸变动一次，变动量为一个单位，其毛增长因子为$110/103$。施加$c = 0.001$的[[#def-cost]]。计算净复合收益率。再算出从毛复合收益率中减去$0.001$所得的数，以及这两个答案之间的差。
:::solution
只有一次量为$1$的调仓，所以成本因子是$1 - c = 999/1000$，不是$(1-c)^3$。这条路径做多了不止一次，不是做多—持币—再做多。[[#prop-cost]]是一般形态；这个算例使用同一个成本定义，配上当作已经数过的换手，即$1$。

$$
G = \frac{110}{103}\cdot\frac{999}{1000} = \frac{109890}{103000} = \frac{10989}{10300}.
$$

净复合收益率为$689/10300$，六位小数$0.066893$。

毛复合收益率为$7/103 = 0.067961165\ldots$。减去$0.001$得到

$$
\frac{7}{103} - \frac{1}{1000} = \frac{6897}{103000} = 0.066961165\ldots,
$$

六位小数舍入为$0.066961$。精确的净复合收益率比它小

$$
\frac{6897}{103000} - \frac{6890}{103000} = \frac{7}{103000} \approx 0.00006796,
$$

六位小数为$0.000068$。这个差等于$c$乘以毛复合收益率：从复合收益率中减去$c$，等于忘了成本本是入场那一刻财富的一个分数，此后毛增长仍然作用在剩下的部分上。在这个玩具上，落空出现在第五位小数。失效的那条恒等式，与$c$很大时失效的是同一条。在把$G$压到$1$的盈亏平衡成本上，$c = 1 - 103/110 = 7/110 \approx 0.063636$，从$7/103$中减去$c$得不到零。因子的形式做得到。
:::
:::

:::example 同样的成本施加在来回止损上 {#ex-cost-b}
把$c = 0.001$施加到路径B的三次单位调仓上。毛增长因子为$51/56$。把净复合收益率算到六位小数。
:::solution
[[#prop-cost]]直接适用：头寸路径是做多、持币、做多，带三笔单位交易，而两个风险因子已经乘在$51/56$里。持币的那一段贡献$1$。净增长因子为

$$
\frac{51}{56}\,(0.999)^3 = \frac{51}{56}\cdot 0.997002999.
$$

净复合收益率为$-0.092015$，六位小数。毛复合收益率为$-0.089286$，六位小数。成本使一个亏损的来回止损稍微更亏一点。它没有制造那个亏损。亏损是在一次滞后的入场之后持有下来的那两个下跌交易日。若有一位读者从$-5/56$中减去$3c = 0.003$，会得$-0.092286$，六位小数，那不是$-0.092015$。因子$(1-c)^3$才是[[#prop-cost]]推导出的表达式；那个减法，是那条命题拒绝使用的近似。
:::
:::

一条库内行就足以展示一条出场规则叠在一个趋势入场之上，并主导了发表出来的摘要。O09被描述为一种趋势入场，其出场由一个$4\%$的移动止损来管理。日频K线，跨距$25$年。按quants.md对那个QuantJourney示例（Apache-2.0）的报告，按2026年的阅读，总收益率为$+30.0\%$，年化复合增长率为$+1.06\%$，已报告夏普比率为$-0.33$，最大回撤为$-7.0\%$。本图谱没有重跑过该回测，也没有核实夏普的约定。移动止损的订单机制不在这里推导；它们属于[[orders/trailing-brackets-and-oco]]。属于这里的要点更狭窄。出场叠加是头寸路径的一部分。相对于对入场的一次随意解读，它能改变一个已报告夏普的符号，而一个为负的已报告夏普挨着一个不高却为正的年化复合增长率，就按报告保留。这不是站到入场的另一边的理由，也不是把出场从规格说明里删掉、以挽救"趋势"这个形容词的理由。

:::intuition 延迟在进场和出场都要付钱
在一条直线上，滞后只挪动平均值与线上某个已经越过该线的价格相合的日期。在路径B上，同样的算术在一个波峰附近入场，持有两个下跌交易日，出场，又在回升之后再入场。那三次权重变动中的每一次，都是[[#def-cost]]乘以$1 - c$的一个日子。把窗口拉长以"避开来回止损"，会增大[[#prop-linear-lag]]里的滞后。有时这样跳过了一次假转折。有时，像[[#ex-sine]]那样，它甚至更晚才到达一次真转折。窗口长度是一个连着滞后的参数，不是一种道德设定。
:::

:::warning 把成本从复合收益率里减掉
路径A上的毛复合收益率六位小数为$0.067961$，而$c = 0.001$。差$0.066961$不是净复合收益率。净数字是$0.066893$，因为财富先乘以$1 - c$，再被$110/103$乘过。[[#prop-cost]]记录了那个减法的一般性失效。再小的差，也仍是一个错误的表达式。按名义额的分数来规定的成本，属于乘积之内。
:::

- [ ] $0$，因为一条直线的平均值就是那条直线
- [x] $2$，即$(5-1)/2$

:::
:::

:::quiz
路径A的3对5交叉，无期末清仓，换手为$1$，毛增长因子为$110/103$。在$c = 0.001$之下，哪个量是净增长因子？
- [ ] $110/103 - 0.001$
- [ ] $(7/103)\cdot 0.999$
- [x] $(110/103)\cdot 0.999$
- [ ] $(110/103)\cdot(0.999)^3$，因为每个交叉都是一个来回止损
:::solution
换手是一笔单位交易，所以[[#def-cost]]只贡献单个因子$0.999$，乘在毛增长因子$110/103$上。从增长因子中做减法、把复合收益率乘以因子、以及使用[[#prop-cost]]里那三笔交易的成本因子，是三个不同的表达式。路径A没有翻回去，所以三笔交易的因子不适用。
:::
:::

:::remark 订单与权重各归何处
一个单位的换手，只有在选定一个映射之后，才是一次目标权重的变动，或一张订单的名义额。[[portfolio/from-signal-to-weight]]写下从信号到权重的映射。[[orders/market-and-limit-orders]]写下从一笔想要的成交到订单类型的映射。本章止步于乘进财富里的$1 - c\tau$。它不选择交易场所、限价或股数。提到O09的移动止损，是为了让一个出场叠加在已报告的夏普里看得见；止损本身不再另行设定。

同样的边界也适用于前面各章的那些库内行。一个已报告的年化复合增长率，是别人的成本模型上的期末增长。往路径A上放一个$c = 0.001$，既没有调整O01、W01、W22或W06，也没有说那些实验省略了成本。它们的成本假设就是其源头所用的那套。它们没有在这里被重跑。
:::

:::history 成本本来就是争论的一部分
布罗克（Brock）、拉科尼肖克（Lakonishok）与勒巴隆（LeBaron）在1992年检验了道琼斯（Dow Jones）指数上的移动平均规则与交易区间规则，发现了历史上为正的结果。课程记录提到，后来的工作就成本、数据挖掘以及结果是否幸存展开争论。[[#prop-cost]]里的成本因子，正是那场论证需要的对象：一个显式的乘数，系于一条头寸路径，而不是一般的怀疑。赫斯特（Hurst）、Ooi与佩德森（Pedersen）在2017年是一个跨期货市场、跨年份的平均；课程参考文献说要读那篇论文的市场清单与其成本假设。那些假设迁移不进一条股票基金的订单规则，而路径B的三笔交易也迁移不进那个平均。
:::

## 通往何处

一个信号只有在一个映射之后才成为权重，一个权重只有在一个订单类型之后才成为成交。[[portfolio/from-signal-to-weight]]与[[orders/market-and-limit-orders]]就是这两步。趋势假说、那些平均值、通道、MACD线与名单滤波器，全都是标注在$t$的特征。滞后、来回止损与$1 - c\tau$，是这些特征一旦获准去改变一个头寸时的代价。它们没有一个是追随趋势、加宽窗口、或持有库内行点名的任何序列的建议。

:::summary
- 在一条直线上，$\mathrm{SMA}_n(t)$等于那条直线提前$(n-1)/2$个交易日的取值。$n = 3$时滞后是一个交易日；$n = 5$时是两个。
- 在采样的正弦上，收盘价在$t = 3$处见峰，$\mathrm{SMA}_3$在$t = 4$见峰，$\mathrm{SMA}_5$在$t = 5$见峰。更长的窗口只是更晚，并不自动更温和。
- 多头或持币情形下的来回止损，就是做多、持币、再做多的形态。路径B的3对5交叉正是如此，换手为$3$，被支付的复合收益率为$-5/56$。路径A的交叉不是；它的换手就是已经数过的那一次入场。
- 若三次单位调仓各把财富乘以$1-c$，净增长因子等于毛增长因子乘以$(1-c)^3$。净复合收益率是那个乘积减一，不是毛复合收益率乘上同一个因子。
- 在路径A上取$c = 0.001$，净复合收益率为$0.066893$。从毛复合收益率中减去$0.001$得$0.066961$，那是错误的表达式。
- O09报告夏普$-0.33$、年化复合增长率$+1.06\%$，入场是一个趋势入场、由移动止损管理。叠加是结果的一部分。止损的机制留给订单课程。
:::

:::exercise 长窗口的滞后 {level=1 check="2"}
在一条直线上，$\mathrm{SMA}_5$有几个交易日的滞后？输入一个整数。
:::solution
$(5-1)/2 = 2$。

:::exercise 路径A上的换手 {level=1 check="1"}
路径A上的3对5交叉先持币、后做多，没有期末清仓。输入它的换手，从头寸相对持币起步的单位变动数起。
:::solution
只有一次变动，在慢平均值存在、快均线在其上方的第一个日期，从$0$到$1$。换手为$1$。
:::

:::exercise 路径A上的净复合收益率 {level=2 check="0.066893"}
毛增长因子$110/103$，一笔单位交易，$c = 0.001$。把净复合收益率输入到六位小数。
:::solution
净增长因子为$(110/103)\cdot(999/1000) = 10989/10300$。减去$1$得$689/10300$，六位小数$0.066893$。
:::
:::

:::exercise 路径B上有几笔交易？ {level=2 check="3"}
输入路径B上3对5旗标的单位头寸变动数目，把入场、出场与再入场都算进去，任何期末清仓都不算。
:::solution
[[#ex-pathb]]记录了$t = 4$、$t = 6$与$t = 10$处的变动。数目是$3$。
:::

:::exercise 路径B上的毛复合收益率 {level=2 check="-0.089286"}
输入$c = 0$时路径B交叉的复合收益率，舍入到六位小数。
:::solution
被支付的因子是$27/28$与$17/18$，乘积为$51/56$。复合收益率为$-5/56 = -0.0892857\ldots$，舍入为$-0.089286$。

:::exercise 减法之差 {level=3 check="0.000068"}
在路径A的成本算例上，用从毛复合收益率减去$0.001$所得的数，减去精确的净复合收益率。输入这个差，舍入到六位小数。
:::hint
那个粗糙的差是$7/103 - 1/1000 = 6897/103000$。精确的净复合收益率是$689/10300 = 6890/103000$。先把这两个分数相减，再舍入。
:::
:::solution
$$
\frac{6897}{103000} - \frac{6890}{103000} = \frac{7}{103000} \approx 0.00006796,
$$
舍入为$0.000068$。这个差等于$c \cdot (7/103)$，即成本乘以毛复合收益率。在这个算例里，它正是一次减法把净复合收益率多报出的那部分。
:::
:::

:::exercise 慢峰所在的交易日 {level=3 check="5"}
在$Q_t = 100 + 10\sin(\pi t/6)$、$t = 0,\ldots,12$上，$\mathrm{SMA}_5$在哪个交易日取得它的唯一最大值？输入交易日编号。
:::hint
收盘价本身在$t = 3$处最大。五日平均需要那个仍然包含波峰、并尽可能多地包含高点邻域的窗口。比较$t = 4$、$t = 5$与$t = 6$处的平均值；四位小数的值为$106.4641$、$107.4641$与$106.4641$。
:::
:::solution
$t = 4, 5, 6$处的平均值约为$106.4641$、$107.4641$与$106.4641$，而[[#ex-sine]]中$\mathrm{SMA}_5$的序列在$t = 5$之后下降，在$t = 4$之前不存在。唯一最大值在第$5$个交易日，比收盘价见峰晚两个交易日。这个滞后与$(5-1)/2$相符，尽管$Q_t$不是直线。相符是这一份特定的正弦样本的特征，在数字里看得见，不是[[#prop-linear-lag]]的第二个证明。
:::
