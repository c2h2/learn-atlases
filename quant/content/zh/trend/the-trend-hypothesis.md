价格上涨是关于过去的一个事实。这次上涨的正负号能否对下一个收益率说明什么，则是另一句话；趋势假说就是把那句话说成能够被推翻的样子。这里研究的版本是**时间序列动量**：资产自身过去收益的符号——在某个写明的期限上取得——是关于同一资产自身下一个收益之符号的一个假说。它不是若干资产之间的一个排名，也不是持有任何东西的指令。

两个已发表的均值确定了本课程谈到历史论断时所指的期限。2012年，莫斯科维茨（Moskowitz）、Ooi与佩德森（Pedersen）报告了一个正关系：在股票指数、货币、商品与债券期货中，一个资产过去十二个月的收益率与其下一个收益率正相关。2017年，赫斯特（Hurst）、Ooi与佩德森汇编了一段很长的期货历史，并论证平均结果并不是最近几十年的假象。两者都是跨市场、跨年份的平均。两者都不是交易所交易产品，而一个成本超过它的规则一旦碰上，两者都站不住。什么样算是对这个假说不利的，在下面写明，先于任何算出来的玩具利润。

算术使用的是路径A，即本图谱共用的八个虚构收盘价：

$$
P = (100,\ 102,\ 101,\ 104,\ 103,\ 107,\ 106,\ 110),
$$

在交易日$t = 0, 1, \ldots, 7$上。这些是一条编造序列的收盘价。没有任何东西拆过股，也没有任何东西派过息，所以没有可争的复权。简单收益率是$R_t = P_t/P_{t-1} - 1$。化成最简分数，

$$
R = \Bigl(\frac{1}{50},\ -\frac{1}{102},\ \frac{3}{101},\ -\frac{1}{104},\ \frac{4}{103},\ -\frac{1}{107},\ \frac{2}{53}\Bigr),
$$

六位小数为$0.020000,\ -0.009804,\ 0.029703,\ -0.009615,\ 0.038835,\ -0.009346,\ 0.037736$。符号交替出现，以一次上涨开头。价格仍然收在$110$，所以从第一个收盘价到最后一个收盘价的复合简单收益率为$0.10$。一条路径可以上涨，而每一个滞后一日的符号都是错的。这是这些定义必须首先说得容易的第一件事。

## 一个带有时钟的信号

:::definition 时间序列动量信号 {#def-tsm}
固定一个$k \ge 1$个交易日的回看长度，并把资产自身在这个回看长度上的简单收益率写成$P_t/P_{t-k} - 1$，它在$t \ge k$时有定义。**时间序列动量信号**是

$$
s_t^{(k)} = \sgn\bigl(P_t/P_{t-k} - 1\bigr),
$$

其中$\sgn(u) = 1$若$u > 0$，$\sgn(u) = -1$若$u < 0$，而$\sgn(0) = 0$。$k = 1$的情形就是最新单期收益率的符号。上文引用的历史论断用十二个月自身收益率代替这个$k$，然后谈论下一个收益率。那是对$k$和持有时长的不同选择。它们共享一个形状，却不是同一个假说。
:::

这个信号是$\{-1, 0, +1\}$中的一个数，在到$t$为止的收盘价已知时它已知。它还不是一个权重。权重是一个占净资产值的目标比例，而订单是给交易场所的一条指令。两者都需要进一步的映射。[[markets/systematic-question]]把这些对象分开；本章只搭建这个带符号的输入，以及它被允许去乘的那个收益率。

:::definition 合法的带符号利润 {#def-legal}
标注在$t$的特征可以使用在$t$可得的信息，包括到$t$为止的收盘价。与$s_t^{(k)}$相连的单期利润是乘积$s_t^{(k)} R_{t+1}$，并约定：当下一个收益率不存在时该乘积为$0$。同K线乘积$s_t^{(k)} R_t$不是这个信号的利润。只要$|s_t^{(k)}| = 1$，下面的玩具就把账户视为在那个下一交易日满仓多头或满仓空头；只要$s_t^{(k)} = 0$，它就挣得现金收益率，除非某个玩具另有说明，该收益率取$0$。在后面的某一章把成本写下来之前，不收取任何成本。
:::

合法的乘积，是在$t$收盘时做出的决策仍然能够挣到的那一个。到$t$收盘时，从$P_{t-1}$到$P_t$的变动已经发生。乘上它是对过去的描述，不是一次持有。前视错误的完整目录在[[backtesting/timing-costs-and-biases]]。这里一个对照就够了，它在[[#ex-illegal]]中算出。

:::proposition 交替使每个合法的一日带符号利润都亏损 {#prop-alt}
假设在收益率存在的每个交易日都有$R_t \ne 0$，并且符号严格交替：只要两个收益率都存在就有$\sgn(R_{t+1}) = -\sgn(R_t)$。取$s_t = \sgn(R_t)$，即[[#def-tsm]]中$k = 1$的信号。则对每一个拥有下一个收益率的$t$，

$$
s_t R_{t+1} = -\lvert R_{t+1}\rvert < 0
$$

成立。
:::

:::proof
严格交替给出$\sgn(R_{t+1}) = -\sgn(R_t)$。因为$R_{t+1} \ne 0$，

$$
R_{t+1} = \sgn(R_{t+1})\,\lvert R_{t+1}\rvert = -\sgn(R_t)\,\lvert R_{t+1}\rvert.
$$

乘上$s_t = \sgn(R_t)$。一个符号与自身的乘积是$1$，所以$s_t R_{t+1} = -\lvert R_{t+1}\rvert$，它严格为负。
:::

路径A从$R_1$到$R_7$满足假设：没有收益率是零，而符号是$+,-,+,-,+,-,+$。于是[[#prop-alt]]适用于六个乘积$s_t R_{t+1}$（$t = 1,\ldots,6$）中的每一个。这个结论是关于这条路径和这个$k$的。它不是关于期货的评论，也不是关于$k$等于十二个月的评论。

:::quiz
在路径A上，$R_1 = 0.020000$且$R_2 = -0.009804$。信号$s_1 = \sgn(R_1)$的合法单期利润是哪一个乘积？
- [ ] $s_1 R_1$，因为信号与收益率共用一个下标
- [x] $s_1 R_2$
- [ ] $R_1 + R_2$，因为趋势是收益率的和
- [ ] $s_2 R_1$，因为较晚的符号才是"确认"那次上涨的那个符号
:::solution
[[#def-legal]]把一个标注在$t$的信号乘上$t$之后到来的收益率。这里$t = 1$，所以利润是$s_1 R_2$。乘积$s_1 R_1$用的是一个在$s_1$已知时就已经结束的变动。
:::
:::

## 什么能算作对假说不利的证据

一个不可能失败的假说只是一句口号。两个失败就足够，而其中任何一个单独也足够。

- 符号关系在样本外消失了。必须事先指明期限、资产类别与统计量：例如在同一类期货更靠后的一段样本上、用事先声明的$k$计算$s_t^{(k)} R_{t+1}$的均值。如果那个均值落在零的另一边，历史平均就没有跟过来。
- 成本超过了毛关系。如果$s_t^{(k)} R_{t+1}$的均值为正，而持有$s_t^{(k)}$所要求的换手花费比那个均值还多，那么符号可以是真的，交易起来的规则却仍是亏损。[[trend/lag-whipsaw-and-costs]]写下成本因子。一个在写明成本之后的亏损是关于那条规则的证据，不是拿相反符号来做交易的邀请。

第三种失败方式更安静。如果$k$是在扫过许多回看长度之后挑出来的，那么这次扫描就是实验的一部分。[[statistics/testing-and-snooping]]与[[validation/parameter-search]]处理的就是这种搜索。一个干净的定义并不能把它抵消掉。

路径A做不了其中任何检验。八个收盘价不含更靠后的样本，而塞进八个收盘价的一个成本只是一道算术。这条路径在这里，是为了让合法的乘积、期限和交替结果能够用分数看清楚。

:::intuition 符号，而不是斜率
路径A上的价格从$100$走到$110$。盯着图看的人会叫它上升趋势。一日信号不问图是否向上倾斜。它问的是上一个交易日的符号与下一个交易日的符号是否一致。在这条路径上它们从不一致。十二个月自身收益率问的是第三个问题，问的是另一个窗口。三个问题，三个不同的对象。其中只有一个是在写明的$k$下的[[#def-tsm]]。
:::

横截面动量又是一个问题：它按过去收益给若干资产排序，做多胜者、做空负者。一个为正的秩关系不会证实[[#def-tsm]]，秩关系失灵也不会反驳它。这个划分是[[momentum/two-kinds-of-momentum]]的主题。个股上的短周期负自相关，即均值回归假说，是关于滞后另一端的论断；[[reversion/the-reversion-hypothesis]]把那个期限与十二个月的期货平均分开放。把它们混在一起，会产生一个任何样本都回答不了的句子。

## 路径A上的一日规则

取$s_t = \sgn(R_t)$。在下一个交易日持有的头寸是$s_t$，利润是$s_t R_{t+1}$。$R_1$期间没有头寸，因为$R_1$是第一个收益率，而本可以挣得它的信号需要一个早于$t = 0$的收盘价。

:::example 路径A上的合法头寸 {#ex-sign-path}
对每个$t = 1,\ldots,6$，用路径A的六位小数收益率写出$s_t$与合法利润$s_t R_{t+1}$。
:::solution
$R_1,\ldots,R_6$的符号是$+,-,+,-,+,-$。来自[[#prop-alt]]的交替迫使每个利润都是下一个收益率的相反数，在这条路径上也就是一个正数的相反数。

| $t$ | $s_t$ | 下一个收益率 | 利润$s_t R_{t+1}$ |
|---|---|---|---|
| $1$ | $+1$ | $-0.009804$ | $-0.009804$ |
| $2$ | $-1$ | $0.029703$ | $-0.029703$ |
| $3$ | $+1$ | $-0.009615$ | $-0.009615$ |
| $4$ | $-1$ | $0.038835$ | $-0.038835$ |
| $5$ | $+1$ | $-0.009346$ | $-0.009346$ |
| $6$ | $-1$ | $0.037736$ | $-0.037736$ |

没有一个利润是正的。头寸在每一个下跌交易日做多、在每一个上涨交易日做空。那就是[[#prop-alt]]所承诺的表，不是一个市场结果。
:::
:::

这些玩具里的财富从$1$开始，每一步乘上$1 + s_t R_{t+1}$，也就是[[#def-legal]]，再加上为$0$的现金收益率与零成本。各步上的**复合收益率**就是那个增长因子减一。把表中六个利润相加得六位小数$-0.135039$，那不是复合收益率。简单收益率不能跨时间相加；[[performance/simple-and-log-returns]]就是讲这条警告的那一章。下一个例子做乘法。

:::example 同一个符号的三种复合收益率 {#ex-compound-sign}
在路径A上用精确的分数，计算（i）合法的多头空头规则$s_t = \sgn(R_t)$、（ii）只在$R_t > 0$时做多、否则持有收益率为$0$的现金的合法的多头或持币规则的复合收益率，并且（iii）不要给这两个数做年化。
:::solution
（i）六个增长因子是$1 + s_t R_{t+1}$：

$$
\frac{101}{102},\quad \frac{98}{101},\quad \frac{103}{104},\quad \frac{99}{103},\quad \frac{106}{107},\quad \frac{51}{53}.
$$

第一个是$1 + R_2$。第二个是$1 - R_3 = 1 - 3/101$。模式照[[#ex-sign-path]]继续。约去$101$，再约去$103$：

$$
\frac{98}{102}\cdot\frac{99}{104}\cdot\frac{106}{107}\cdot\frac{51}{53} = \frac{49}{51}\cdot\frac{99}{104}\cdot\frac{106}{107}\cdot\frac{51}{53} = \frac{49\cdot 99}{52\cdot 107} = \frac{4851}{5564}.
$$

复合收益率是$4851/5564 - 1 = -713/5564 = -0.128145$，六位小数。

（ii）多头或持币规则只保留$s_t = +1$的因子，并把做空的步换成$1$。那三个因子是$101/102$、$103/104$与$106/107$。乘积是$1102718/1135056 = 551359/567528$，复合收益率是$-16169/567528$，六位小数为$-0.028490$。这个规则恰好在$R_2$、$R_4$与$R_6$——三个下跌交易日——做多，而在上涨交易日持币。去掉空头会缩小亏损。它不会把亏损变成盈利。收益率为$0$的现金修复不了一个只在下跌交易日持有的多头头寸。

（iii）这里有六步，而不是$252$。把$-0.128145$乘上$\sqrt{252}$，就是把一件玩具打扮成一个年度夏普比率。[[performance/uncertainty-of-performance]]解释了为什么寥寥几个观测撑不起那样的做法。这个例子中的无风险利率是$0$，因为现金被定义为收益$0$；上面的比率是复合收益率，不是夏普比率。
:::
:::

:::example 同一路径上的同K线乘积 {#ex-illegal}
把合法利润替换成$t = 1,\ldots,7$上的$s_t R_t = \lvert R_t\rvert$，计算复合收益率。说明为什么这个数字作为持有不能与[[#ex-compound-sign]]相提并论。
:::solution
每个因子是$1 + \lvert R_t\rvert$：

$$
\frac{51}{50},\ \frac{103}{102},\ \frac{104}{101},\ \frac{105}{104},\ \frac{107}{103},\ \frac{108}{107},\ \frac{55}{53}.
$$

约去$104$、$103$与$107$，然后把$51$对$102 = 2\cdot 51$约，再把$55$对$50 = 2\cdot 25$、$105$对余下的$5$约：

$$
\frac{21\cdot 27\cdot 11}{101\cdot 53} = \frac{6237}{5353}.
$$

复合收益率是$884/5353$，六位小数$0.165141$。每个因子都大于$1$，因为这个规则把每个收益率乘上它自己的符号。一个知道$R_t$的决策已经知道了$P_t$，所以$R_t$内部的那段变动已经无利可挣。[[#ex-compound-sign]]里的合法复合收益率为负，非法的那个为正。这个差距是时钟。它不是支持或反对十二个月期货平均的证据，也不是一项成本。
:::
:::

:::example 把回看长度改为两个交易日 {#ex-two-day}
保留路径A。对$t = 2,\ldots,6$取$s_t^{(2)} = \sgn(P_t/P_{t-2} - 1)$，并在下一个交易日持有该信号。计算每个过去两个交易日的收益率，以及合法多头空头规则的复合收益率。
:::solution
两个交易日的收益率是

$$
\begin{align*}
t = 2&\colon P_2/P_0 - 1 = 1/100 = 0.010000,\\
t = 3&\colon P_3/P_1 - 1 = 1/51 \approx 0.019608,\\
t = 4&\colon P_4/P_2 - 1 = 2/101 \approx 0.019802,\\
t = 5&\colon P_5/P_3 - 1 = 3/104 \approx 0.028846,\\
t = 6&\colon P_6/P_4 - 1 = 3/103 \approx 0.029126.
\end{align*}
$$

每一个都是正的，所以在这五个日期上都有$s_t^{(2)} = +1$。这个规则挣得$R_3,\ldots,R_7$，别无其他。增长因子裂项相消：

$$
\frac{104}{101}\cdot\frac{103}{104}\cdot\frac{107}{103}\cdot\frac{106}{107}\cdot\frac{110}{106} = \frac{110}{101}.
$$

复合收益率是$9/101$，六位小数$0.089109$。把$k$从$1$移到$2$，就把规则从"在每个上涨交易日做空"翻成了"从第$2$个交易日到第$7$个交易日一路做多"。定义没有改变形状。起作用的是期限。八个收盘价上的五个正的两日收益率，是关于这张数字清单的一个事实，不是偏爱两日规则的理由，也不是对2012年论文中十二个月回看长度的检验。
:::
:::

:::warning 交替的玩具不是反驳
[[#prop-alt]]说，一条严格交替的路径会让一日合法符号在每一步都亏损。路径A就是这样一条路径，选它出来是因为它是一个共用的数值算例，不是来自期货市场的一个样本。用它来废掉一个十二个月的平均，或者用一个十二个月的平均来给一条一日股票规则贴金，两个假说都没有回答。算数的失败是上面点名的那两个：写明的符号关系在更靠后的样本上失灵，或者持有它的成本超过了毛均值。
:::

一条单调的路径展示同一定义的另一面，免得"符号规则必亏"凝固成民间传说。

:::example 一条不交替的路径 {#ex-monotone}
收盘价$100, 101, 103, 106$。施加$k = 1$的合法多头空头规则。报告头寸与复合收益率。
:::solution
收益率是$1/100$、$2/101$与$3/103$，全为正。因此$t = 1$与$t = 2$处的信号是$+1$。这个规则只挣第二个和第三个收益率。增长因子是

$$
\frac{103}{101}\cdot\frac{106}{103} = \frac{106}{101},
$$

复合收益率是$5/101$，六位小数$0.049505$。第一个收益率挣不到，理由与路径A上是同一个时钟理由。这个规则在这里赚了钱，因为路径不交替。[[#prop-alt]]不适用，而定义里也没有任何东西说它应当适用。
:::
:::

- [x] 在该论断点名的期货市场的一个更靠后的样本上，回看长度事先固定，$s_t R_{t+1}$的均值为负，或者毛均值小于事先写明的持有$s_t$的成本

:::remark 相关是同一个符号的总体版本
[[statistics/moments-and-dependence]]定义了滞后1阶自相关。正的自相关是"上一个符号与下一个符号一致"的统计投影；负的自相关是交替的投影。路径A只有六个相邻配对，这就是本章从符号本身而不是从四舍五入到两位小数的那个相关来论证的原因。就算符号再明显，这个估计也会很嘈杂。负的滞后1阶自相关与一个为正的十二个月关系可以同时为真，因为它们是不同的滞后。均值回归课程从短滞后起步。本课程不是。

接下来几章要引用的那些开放库股票基金规则，不是那个十二个月期货关系的估计。它们是具体的移动平均、通道与滤波实验。把一个读作对另一个的确认，就跳过了期限与工具。

:::history 期货的平均，不是一个产品
2012年，莫斯科维茨（Moskowitz）、Ooi与佩德森（Pedersen）记录了一个正关系：在股票指数、货币、商品与债券期货中，一个资产过去十二个月的收益率与其下一个收益率正相关。2017年，赫斯特（Hurst）、Ooi与佩德森汇编了一段很长的期货历史，并论证趋势跟踪的平均结果并不是最近几十年的假象。课程记录明确说，第二个结果是跨市场、跨年份的平均，不是关于单条交易所交易规则的承诺。本章把这两个陈述用作[[#def-tsm]]的历史形式，而使用路径A只是为了把时钟钉住。
:::

## 通往何处

下一章把符号变成一个平滑器。移动平均交叉仍然是关于持续性的一个论断，但特征不再是$\sgn(R_t)$；[[trend/moving-averages]]把平均值写下来，然后拒绝谈论"那个"移动平均回测。能让$s_t R_{t+1}$的期望为正的那种相依性，在[[statistics/moments-and-dependence]]。上面用到的业绩算术——复合收益率对着简单收益率之和——在[[performance/simple-and-log-returns]]。

:::summary
- 时间序列动量是一个假说，说的是在你必须指明的一个期限上，给定资产自身过去收益的符号，其自身下一个收益的符号如何。
- 这里用到的2012与2017年的期货平均是跨许多市场的历史平均，不是交易所交易产品，也不是一次持有。
- 标注在$t$的信号，其合法利润是$s_t R_{t+1}$。乘积$s_t R_t$在路径A上看上去更好，恰恰因为它不是持有。
- 若单期收益率严格交替，每一个合法的一日带符号利润都是负的。路径A是交替的；多头空头的复合收益率是$-0.128145$。
- 同一个定义取两日回看长度时，在路径A上是做多，并复合到$0.089109$。期限是论断的一部分。
- 如果那个符号关系在样本外缺席，或者持有信号的成本超过毛均值，假说就失败。八个收盘价哪个检验都演示不了。
:::

## 练习

:::exercise 路径A一个收益率的符号 {level=1 check="-1"}
收盘价从$102$走到$101$。那个交易日的$\sgn(R_t)$是多少？输入$-1$、$0$或$1$。
:::solution
$R = 101/102 - 1 = -1/102 < 0$，所以符号是$-1$。
:::
:::

:::exercise 一个合法利润 {level=1 check="-0.009804"}
取$s_t = +1$，设下一个简单收益率为路径A的数字$-0.009804$。把合法利润输入到六位小数。
:::solution
[[#def-legal]]把信号乘以下一个收益率：$(+1)\times(-0.009804) = -0.009804$。
:::
:::

:::exercise 有多少个合法利润为正？ {level=1 check="0"}
在路径A上，$k = 1$，六个合法多头空头利润中有几个严格为正？输入一个整数。
:::solution
[[#prop-alt]]适用，而[[#ex-sign-path]]列出了六个利润。每一个都是负的。数目是$0$。
:::
:::

:::exercise 多头空头的复合收益率 {level=2 check="-0.128145"}
输入路径A上合法多头空头一日规则的复合收益率，到六位小数，如[[#ex-compound-sign]]所计算。
:::solution
增长因子化简为$4851/5564$。减去$1$得$-713/5564$，六位小数为$-0.128145$。
:::
:::

:::exercise 一条短的单调路径 {level=2 check="0.049505"}
收盘价为$100, 101, 103, 106$。输入$k = 1$的合法多头空头规则的复合收益率，到六位小数。
:::solution
拥有下一个收益率的两个信号都是$+1$。增长因子是$(103/101)\cdot(106/103) = 106/101$。复合收益率是$5/101$，六位小数$0.049505$。开头的那个收益率$1/100$挣不到。
:::
:::

:::exercise 两种不同的失败 {level=2}
说出本章陈述的、能算作对时间序列动量假说不利的两种结果。不要把路径A的一日亏损算作其中之一。
:::solution
第一，符号关系在样本外消失：在期限与资产类别事先固定的情况下，合法乘积在更靠后样本上的均值不为正。第二，成本超过毛关系：$s_t R_{t+1}$的均值可以为正，却仍小于持有$s_t$的成本。路径A是交替之下合法乘积的一个例证。它不是十二个月期货论断的样本外检验。
:::
:::

:::exercise 交替之下的增长 {level=3}
假设收益率严格交替且没有一个是零，如同[[#prop-alt]]。证明在拥有下一个收益率的那些步上，合法多头空头增长因子等于$\prod (1 - \lvert R_{t+1}\rvert)$，并且只要至少有一个这样的收益率存在，它就严格小于$1$。然后化简这个乘积，在路径A上核对这个恒等式。
:::hint
在写出因子$1 + \text{利润}$之前，把每个利润换成$-\lvert R_{t+1}\rvert$。在路径A上，六个因子已经列在[[#ex-compound-sign]]里。
:::
:::solution
由[[#prop-alt]]，每个合法利润都等于$-\lvert R_{t+1}\rvert$，所以每个增长因子是$1 - \lvert R_{t+1}\rvert$。每个因子都严格小于$1$；只要每个简单收益率大于$-1$——价格保持为正时正是如此——所有因子就都为正。$(0, 1)$中诸数的乘积严格小于$1$。在路径A上，这个乘积在[[#ex-compound-sign]]里已化简为$4851/5564 < 1$，复合收益率$-0.128145$。
:::
:::

:::exercise 同K线规则为什么复利在零之上 {level=3}
证明在一条没有零收益率的路径上，同K线的多头空头增长因子等于$\prod_t (1 + \lvert R_t\rvert)$，并用两句话解释为什么这个恒等式使得这个规则在成本之前就无法作为持有来使用。把路径A化简后的值$6237/5353$用作对代数的核对，而不是业绩摘要。
:::hint
$s_t = \sgn(R_t)$乘上$R_t$给出绝对值。然后问：在$s_t$已知的时刻，$R_t$是否还在未来。
:::
:::solution
若$R_t \ne 0$，则$\sgn(R_t)\, R_t = \lvert R_t\rvert$，所以增长因子是$\prod (1 + \lvert R_t\rvert)$。每一项至少是$1$，任何一处出现严格大于，乘积就严格大于$1$。在路径A上，乘积化简为$6237/5353$，六位小数复合收益率$0.165141$，如[[#ex-illegal]]。这个恒等式无法作为持有来使用，因为$R_t$依赖$P_t$与$P_{t-1}$。当收盘价$P_t$已知时，那个收益率已经被实现。一个挣得$\lvert R_t\rvert$的规则是在给过去盖上符号，任何路径都会给它报酬。
:::
:::
