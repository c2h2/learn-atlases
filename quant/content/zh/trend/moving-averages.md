移动平均是一个带有时钟的平滑器。它并不发现藏在价格里的趋势。它把一段窗口的收盘价换成一个数字，把另一段窗口换成另一个数字，而一个交叉比较这两个数字。那个比较是[[trend/the-trend-hypothesis]]意义上的一个时间序列符号：一个在$t$已知的特征，作为关于$t$之后收益率的一个假说被提出。特征不再是原始收益率的符号。把窗口写下来，才使这个假说成为一条规则而不是一种心情。

数值路径仍是路径A，

$$
P = (100,\ 102,\ 101,\ 104,\ 103,\ 107,\ 106,\ 110)
$$

在交易日$t = 0,\ldots,7$上；虚构的收盘价，无需复权，因为这条序列从未拆股、从未派息。简单收益率就是上一章的那些。两个库内实验再加第三个——全都由移动平均构建、全都互不相同——占据了本章的中段。它们被报告的摘要不是预测、不是建议，也不是一个结果。

## 两个平均

:::definition 简单移动平均 {#def-sma}
对整数窗口$n \ge 1$与日期$t \ge n - 1$，收盘价的**简单移动平均**为

$$
\mathrm{SMA}_n(t) = \frac{1}{n}\sum_{i=0}^{n-1} P_{t-i}.
$$

当存在的收盘价不足$n$个时它没有定义。权重相等、和为$1$，所以一个恒定价格的平均值就是那个常数。平均值的日期是其中最新收盘的日期。较早的$n - 1$个收盘价仍在和式之内，这就是$P_t$的一次转折只把平均值推动该转折的$1/n$的原因。
:::

:::definition 指数移动平均 {#def-ema}
固定一个衰减$\lambda$，满足$0 < \lambda \le 1$，以及一个等于某个写明收盘价的种子$E_{t_0}$。于是**指数移动平均**服从

$$
E_t = \lambda P_t + (1 - \lambda)\, E_{t-1}, \qquad t > t_0.
$$

从跨度$n$出发的一个常见换算式是$\lambda = 2/(n+1)$。这个换算式是一个约定，不是一个定理，而使用它的章节必须说明这一点。在种子被写明之前，$E_t$还不是一个数字。
:::

把这个递归展开，得到一个有限的折现和；手工核对应当用这个形式。

:::proposition 带种子的EMA的折现权重 {#prop-ema}
假设$E_0 = P_0$且$0 < \lambda \le 1$。则对每个$t \ge 0$，

$$
E_t = \lambda\sum_{k=0}^{t-1} (1-\lambda)^k P_{t-k} + (1-\lambda)^t P_0,
$$

其中$t = 0$时和式为空。系数非负、和为$1$。
:::

:::proof
$t = 0$时上式就是$E_0 = P_0$。假设对某个$t \ge 1$，公式在$t - 1$成立。递归给出

$$
E_t = \lambda P_t + (1-\lambda)\Biggl(\lambda\sum_{k=0}^{t-2}(1-\lambda)^k P_{t-1-k} + (1-\lambda)^{t-1} P_0\Biggr).
$$

以$j = k + 1$对和式重新定指标。于是$(1-\lambda)$乘以和式等于$\lambda\sum_{j=1}^{t-1}(1-\lambda)^j P_{t-j}$，且$(1-\lambda)\cdot(1-\lambda)^{t-1} P_0 = (1-\lambda)^t P_0$。加上$\lambda P_t$就得到$t$处的公式。

各系数之和为$\lambda\sum_{k=0}^{t-1}(1-\lambda)^k + (1-\lambda)^t$。当$\lambda < 1$时，等比和等于$\bigl(1 - (1-\lambda)^t\bigr)/\lambda$，所以总和是$1 - (1-\lambda)^t + (1-\lambda)^t = 1$。若$\lambda = 1$，则$E_t = P_t$，唯一幸存的系数是$1$。
:::

无限历史的图景——$k = 0, 1, 2, \ldots$上的权重$\lambda(1-\lambda)^k$——是这个公式在种子远退时的极限，而且只有当$\lvert 1 - \lambda\rvert < 1$时才成立。在八个收盘价上，种子并不遥远。[[#ex-ema]]使用有限形式。

:::definition 交叉规则 {#def-cross}
选取一个快窗口与一个慢窗口，或一个快衰减与一个慢衰减，其中快均线是把更多权重放在最新收盘价上的那一个。在两个平均值都存在的日期上，**交叉信号**为

$$
c_t = \begin{cases} +1 & \text{当快均线严格高于慢均线},\\ 0 & \text{否则} \end{cases}
$$

在慢平均值存在之前，本章令$c_t = 0$。合法的持有就是[[trend/the-trend-hypothesis]]里的那个：$c_t$可以使用到$t$为止的收盘价，并乘上$R_{t+1}$，而不是$R_t$。"快均线高于慢均线时做多"就是这个$c_t$。除非规格说明另有规定，它是一条多头或持币规则，而不是多头空头规则。两个平均值的交叉本身不是订单，本身也不是权重。
:::

:::algorithm 由SMA交叉得出头寸 {#alg-cross}
1. 固定$n_{\mathrm{fast}} < n_{\mathrm{slow}}$与收盘价序列。
2. 在每个$t$处，若$t < n_{\mathrm{slow}} - 1$，令$c_t = 0$。
3. 否则由[[#def-sma]]计算$\mathrm{SMA}_{n_{\mathrm{fast}}}(t)$与$\mathrm{SMA}_{n_{\mathrm{slow}}}(t)$。若快值严格较大则$c_t = 1$，否则$c_t = 0$。
4. 在下一个交易日挣得的利润是$c_t R_{t+1}$。若$t$是最后一个交易日，记录$c_t$，不要臆造一个更靠后的收益率。
5. 换手（turnover），供后面使用，等于$\sum_t \lvert c_t - c_{t-1}\rvert$，其中$c_{-1} = 0$。一次变动只数一次，就在它发生时。除非规格说明说要把账簿清成空仓，不要在样本末尾添加一笔卖出。
:::

等权重容易审计，醒得却慢：最新收盘价权重是$1/n$，与窗口内最旧的收盘价相同。EMA把权重$\lambda$给最新收盘价，让其余部分衰减。这两种权重都谈不上"正确"。它们是不同的特征，而把两者换一换的回测就是另一个实验。

## 路径A，逐窗口来看

这条路径的档案把$\mathrm{SMA}_3$从第三个收盘价起记为$101$、$102.3333$、$102.6667$、$104.6667$、$105.3333$、$107.6667$。下一个例子推出这些数字，然后把$\mathrm{SMA}_5$摆在它们旁边。

:::example 路径A上的SMA(3) {#ex-sma3}
计算$t = 2,\ldots,7$的$\mathrm{SMA}_3(t)$。给出精确分数，以及舍入到四位小数的值；当出现末尾无限循环的$6$时，恰为一半者取远离一侧。
:::solution
窗口与和式如下：

| $t$ | 窗口内的收盘价 | 和 | $\mathrm{SMA}_3(t)$ | 四位小数 |
|---|---|---|---|---|
| $2$ | $100, 102, 101$ | $303$ | $101$ | $101.0000$ |
| $3$ | $102, 101, 104$ | $307$ | $307/3$ | $102.3333$ |
| $4$ | $101, 104, 103$ | $308$ | $308/3$ | $102.6667$ |
| $5$ | $104, 103, 107$ | $314$ | $314/3$ | $104.6667$ |
| $6$ | $103, 107, 106$ | $316$ | $316/3$ | $105.3333$ |
| $7$ | $107, 106, 110$ | $323$ | $323/3$ | $107.6667$ |

$307/3 = 102.3\overline{3}$舍入为$102.3333$。$308/3 = 102.6\overline{6}$舍入为$102.6667$。同一规则确定了另外两个循环三分之一。这些就是为路径A定下的六个值。在$t = 2$处，平均值等于收盘价，因为$(100+102+101)/3 = 101$。当后面某一章对平均值使用严格不等式时，等号会有影响。
:::
:::

:::example SMA(3)在何处高于SMA(5) {#ex-cross-dates}
对路径A上$\mathrm{SMA}_5(t)$有定义的每个$t$计算它，并列出快平均值严格高于慢平均值的日期。
:::solution
从$t = 4$起存在五个收盘价。

| $t$ | $P_{t-4},\ldots,P_t$之和 | $\mathrm{SMA}_5(t)$ | $\mathrm{SMA}_3(t)$ | 快均线在慢均线之上？ |
|---|---|---|---|---|
| $4$ | $510$ | $102$ | $308/3 \approx 102.6667$ | 是，差$2/3$ |
| $5$ | $517$ | $103.4$ | $314/3 \approx 104.6667$ | 是，差$19/15$ |
| $6$ | $521$ | $104.2$ | $316/3 \approx 105.3333$ | 是，差$17/15$ |
| $7$ | $530$ | $106$ | $323/3 \approx 107.6667$ | 是，差$5/3$ |

快平均值在$t = 4, 5, 6, 7$严格高于慢平均值，在更早的日期都不是，因为慢平均值在更早时不存在。在两者重叠的日期里，没有一天出现不等式翻回去的情况。在这条路径上，交叉没有改主意。这是关于八个收盘价的一个事实。它不是移动平均的一般性质，而讲来回止损的那一章需要先有第二条路径，才能数得了一次翻转。
:::
:::

以窗口$3$与$5$施加[[#alg-cross]]。于是$t = 0, 1, 2, 3$时$c_t = 0$，$t = 4, 5, 6, 7$时$c_t = 1$。头寸改变了一次，在$t = 4$从持币变为做多。它没有再改变。在$c_{-1} = 0$且期末不清仓之下，换手为$1$。其收益率真正被挣到的交易日，是那些拥有下一个收益率且$c_t = 1$的交易日，即$t = 4, 5, 6$，挣得$R_5$、$R_6$与$R_7$。$t = 7$处的多头信号是真实的，但在样本内未被支付。[[trend/lag-whipsaw-and-costs]]会为这一次变动定价；这里先算出毛复合收益率，好让成本有一个基数。

:::example 3对5交叉的毛复合收益率 {#ex-cross-gross}
利用刚得到的头寸，计算路径A上$c_t R_{t+1}$的复合收益率，现金收益率为$0$。
:::solution
只有$R_5$、$R_6$与$R_7$被持有。它们的毛因子是$107/103$、$106/107$与$110/106$。乘积坍缩为$110/103$。复合收益率是

$$
\frac{110}{103} - 1 = \frac{7}{103} = 0.067961
$$

六位小数为上式。这三个收益率并非全为正：$R_6 = -1/107$。乘积为正，是因为从$103$到$110$的变动压过了那一个下跌交易日。从第一个收盘价到最后一个收盘价的买入并持有复合到$0.10$，那是一组不同的交易日。不说明持有了哪些交易日就把$7/103$与$0.10$放在一起比较，那不是比较。
:::
:::

:::example 衰减为二分之一的EMA {#ex-ema}
以$E_0 = P_0 = 100$为种子，取$\lambda = 1/2$。在路径A上计算$E_t$直到$t = 7$。然后另行从同一个种子出发，把一条较慢的平均$\lambda = 1/3$推进一步，并说明在$t = 1$处"快均线高于慢均线"是否成立。
:::solution
在$\lambda = 1/2$之下，递归就是新收盘价与前一个EMA的平均。这些值精确地是

$$
100,\ 101,\ 101,\ \frac{205}{2},\ \frac{411}{4},\ \frac{839}{8},\ \frac{1687}{16},\ \frac{3447}{32},
$$

也就是$100$、$101$、$101$、$102.5$、$102.75$、$104.875$、$105.4375$、$107.71875$。走进$t = 5$的那一步值得手工核对：前一个值是$411/4 = 102.75$，收盘价是$107$，而

$$
\tfrac12\cdot 107 + \tfrac12\cdot 102.75 = 53.5 + 51.375 = 104.875.
$$

[[#prop-ema]]说，这八个数是迄今所见收盘价的加权平均，不是一条无限长尾。

较慢的递归$F_t = \tfrac13 P_t + \tfrac23 F_{t-1}$，取$F_0 = 100$，有$F_1 = \tfrac13\cdot 102 + \tfrac23\cdot 100 = 302/3 \approx 100.666667$。$t = 1$处的快值是$101 > 302/3$，所以一个"当$\lambda = 1/2$的平均高于$\lambda = 1/3$的平均时做多"的交叉，在$t = 1$处是做多。用精确算术继续这个慢递归，快平均值在$t = 1,\ldots,7$的每一个都保持在慢平均值之上。与SMA交叉一样，这一对具体的平均值在路径A上不翻转。稍后一个MACD例子会翻转，因为它对两个平均值求差，再对差平滑。一个平均值的水平与一个差值的符号是不同的特征。
:::
:::

这幅图用的是一条虚构的起伏路径，不是路径A。路径A那条短促的上涨清单不会为算例里的窗口产生一个交叉，所以它不是一幅好的交叉图。把任何一个窗口拉长，平均值的响应就更慢。阴影部分是快平均值严格高于慢平均值的那些日期的集合。那是对这条路径的描述。

在一条直线上，滞后是精确的，而不是视觉上的。若$P_t = a + bt$，那么[[#def-sma]]等于那条直线在$t$之前$(n-1)/2$个交易日的取值。这个恒等式在[[trend/lag-whipsaw-and-costs]]中证明，那一章的主题就是滞后。用在这里，它只警告：在一条上升的直线上，"快均线高于慢均线"是关于两个延迟的陈述，而不是关于一条新消息的陈述。

:::intuition 交叉是把粗糙度平均掉之后的符号
[[trend/the-trend-hypothesis]]取了$\sgn(R_t)$，它在路径A上交替并亏损。平均值并不会仅仅因为收盘价交替而交替。路径A上的$\mathrm{SMA}_3$从$101$上升到$107.\overline{6}$，其间只在第一个日期上与收盘价有一次持平的比较；而一旦两者都存在，$\mathrm{SMA}_3$就保持在$\mathrm{SMA}_5$之上。平滑能把交替的收盘价变成一个单边的信号。这是特征的改变。它不是平滑后的信号在样本外将挣得下一个收益率的证据。
:::

## 三行库内示例，不是一个回测

按2026年的阅读，开放库包含若干移动平均实验。其中三个是本章允许详细讨论的。下面的每个数字都是按quants.md对那个QuantJourney示例（Apache-2.0）的报告，按2026年的阅读。本图谱没有重跑过那些回测，没有核实已报告夏普内部的年化约定，也不把这些行当作建议或预测。

**O01，Market SMA Cross。**一句话规则是：当$\mathrm{SMA}(20)$上穿$\mathrm{SMA}(50)$时买入，反向交叉时卖出；市价单；股票交易所交易基金；趋势。日频K线，跨距$25$年。已报告总收益率$+126.66\%$，年化复合增长率$+3.33\%$，已报告夏普比率$0.21$，最大回撤$-16.35\%$，胜率$51.9\%$，盈亏比$2.18$。

**W01，Daily SMA Trend。**目录规则在$\mathrm{SMA}(50) > \mathrm{SMA}(200)$期间对每只行业交易所交易基金持有多头权重，并且每日调仓。日频K线，跨距$26$年。已报告总收益率$+537\%$，年化复合增长率$+7.38\%$，已报告夏普比率$0.45$，最大回撤$-34.7\%$，胜率$72.6\%$，盈亏比$2.48$。

**O18，Signal Change Rotation Orders。**只在SMA趋势信号翻转时交易，不用日历。日频K线，跨距$25$年。一句话规则没有重述窗口长度，所以本章不去臆造它们。已报告总收益率$+130\%$，年化复合增长率$+3.38\%$，已报告夏普比率$0.22$，最大回撤$-16.3\%$，胜率$52.4\%$，盈亏比$2.21$。

把三个年化复合增长率放进一句话里，它们看上去像一个排名：$+7.38\%$、$+3.38\%$、$+3.33\%$。这个排名不是关于移动平均的结果。这几行相异之处，每一个都改变了实验。

- 特征不同。O01比较窗口$20$与$50$，并在一个交叉上行动。W01比较窗口$50$与$200$，并在不等式成立期间行动，那是[[#def-cross]]的水平规则，而不仅仅是发生上穿的那个交易日。O18说的是"SMA趋势信号"，而目录那一行并没有公布同一对窗口。
- 对象不同。O01提交市价单。W01设定目标权重并每日调仓。O18只在信号翻转时提交订单。权重不是订单。[[backtesting/weights-versus-orders]]把两套引擎分开；[[portfolio/from-signal-to-weight]]是信号变成权重的地方。本章只需要这个推论：同一个形容词"趋势"坐在三张从特征到头寸的不同映射之上。
- 时钟不同。交叉是一个事件。每日调仓是一个日历，它可能仅仅因为权重已经漂移、而信号没有改变就发生交易。一个只在翻转时交易的规则拒绝那个日历。在路径A上，3对5信号改变一次，所以一个事件规则与一个日频0或1权重恰好在同一个交易日交易。那个巧合就是单标的0或1的特例。它不是W01——W01持有一列行业交易所交易基金并每日调仓。
- 样本不同。二十五年与二十六年不是同一个窗口。不能拿O01的年化复合增长率减去W01的，再把差额称作每日权重的价值。
- 已报告的回撤得不出一个简单的教训。W01已报告的年化复合增长率是三者中最大的，已报告的最大回撤$-34.7\%$也是最深的。O01与O18报告的回撤接近$-16\%$，年化复合增长率接近$+3.3\%$。回撤的深度是已报告摘要的一部分。它不是一个人必须支付的价格，也不是偏爱数字温和那一行的理由。这些路径是不同的实验。
- 胜率与盈亏比是目录字段。本图谱没有重新定义那些回测把什么计为一笔胜。一个$2.48$的盈亏比挨着$72.6\%$的胜率，在不知道那个定义时，不能与一个$2.18$的盈亏比挨着$51.9\%$相比。[[performance/win-rate-and-profit-factor]]才是为一个写明的单位定义这个比率的地方。

:::warning 不存在"那个"移动平均回测
O01、W01与O18是三个规格说明。把一个夏普引为"移动平均所能做的"，就把窗口、订单还是权重的选择、调仓时钟和样本全丢掉了。已报告的夏普$0.21$、$0.45$与$0.22$是本图谱尚未核实的约定之下的库内数字。它们不是路径A的均值除以路径A的标准差，也不是可以根据年化复合增长率重算的年化数字。
:::

:::application 把三行当作实现来读
取一列，问：要让这个单元格存在，必须有什么为真。年化复合增长率单元格需要一个起始值、一个期末值和一个以年为单位的跨距。夏普单元格需要一条超额收益率序列，还需要除以一个散布量，而所用的约定没有写在一句话规则里。最大回撤单元格需要一条财富路径，而不仅仅是一笔期末财富。两条规则可以共享一个期末年化复合增长率而在回撤单元格上不同，也可以共享一个回撤而在时钟上不同。[[research-craft/comparing-implementations]]把O01摆在W01旁边，作为一次实现的对照比较。本章要带走的一点更狭窄：如果规格说明没有点明窗口、对象（权重还是订单）和时钟，就没有什么可比较的。
:::

:::quiz
在路径A上，哪些交易日有$\mathrm{SMA}_3(t) > \mathrm{SMA}_5(t)$？
- [ ] 任何交易日都没有，因为价格不单调
- [ ] 只在$t = 2$与$t = 3$
- [x] 在$t = 4, 5, 6, 7$，而在此之前慢平均值没有定义
- [ ] 从$t = 2$起的每一个交易日
:::solution
$\mathrm{SMA}_5$只从$t = 4$起存在。[[#ex-cross-dates]]显示快平均值在这四个日期中的每一个都在慢平均值之上。在$t = 4$之前，[[#def-cross]]里的交叉被定义为持币，而不是做多。
:::
:::

:::quiz
哪种改动会使O01与W01成为同一个实验？
- [ ] 把W01已报告的夏普$0.45$换成O01已报告的夏普$0.21$
- [x] 任何只动已报告摘要的编辑都不行。两条规则在窗口上、在权重对市价单上、在每日调仓对交叉上、在写明的样本池与跨距上都不同
- [ ] 把两个年化复合增长率都舍入到最接近的百分点
- [ ] 给两者都起名叫"SMA趋势"
:::solution
已报告数字是输出。编辑一个输出不会让规格说明变得一致。目录那两行在窗口、引擎、时钟、样本池与跨距上已经不同。共享一个绰号不是共享一个实验。
:::
:::

:::remark 路径A对这些行允许说什么
路径A上的3对5交叉在四个日期做多，挣三个交易日，复合到$7/103$。这个计算核对的是[[#alg-cross]]。它不近似O01的窗口$20$与$50$——那些窗口装不进八个收盘价——也不近似W01对一列行业基金的每日调仓。如果一个玩具与一行25年的记录不一致，玩具不能反驳那一行。如果一致，玩具也不能确认它。库内各行作为别人实验的被报告摘要原样站立。玩具作为你可以重算的算术站立。
:::

:::history 被检验过的规则，不是一个绰号
1992年，布罗克（Brock）、拉科尼肖克（Lakonishok）与勒巴隆（LeBaron）在道琼斯（Dow Jones）指数上检验了移动平均规则与交易区间规则，发现了历史上为正的结果。课程记录提到，后来的工作就成本、数据挖掘以及结果是否幸存展开争论。有用的遗产是检验的形式：一个窗口、一个交叉或一个区间，以及一个写明的市场。"跟随移动平均"不是那种形式。O01、W01与O18更接近它，而它们仍是三种形式而不是一个。
:::

## 通往何处

通道高点与MACD差值，是接下来两种被作为同一类符号提出的特征。[[trend/breakouts-and-macd]]定义它们，并引用另一对库内行。[[#alg-cross]]数出的那一次头寸变动，就是[[trend/lag-whipsaw-and-costs]]将以$0.001$的单边成本定价的那个换手。权重与O01里的市价单有何不同，见[[backtesting/weights-versus-orders]]；把实现并排来读，见[[research-craft/comparing-implementations]]。

:::summary
- $\mathrm{SMA}_n(t)$是以$t$结尾的$n$个收盘价的等权均值。EMA是带有写明种子的递归$E_t = \lambda P_t + (1-\lambda)E_{t-1}$，展开后成为和为$1$的折现权重。
- 当快平均值严格高于慢平均值时交叉做多，在慢平均值存在之前持币。合法利润是$c_t R_{t+1}$。
- 在路径A上，$\mathrm{SMA}_3$与六个已记录的值相符，并且只在$t = 4, 5, 6, 7$严格高于$\mathrm{SMA}_5$。头寸改变一次。毛复合收益率为$7/103 = 0.067961$。
- O01、W01与O18已报告年化复合增长率$+3.33\%$、$+7.38\%$、$+3.38\%$，夏普比率$0.21$、$0.45$、$0.22$，最大回撤$-16.35\%$、$-34.7\%$、$-16.3\%$，作为本图谱没有重跑过的目录数字。
- 那三行在窗口、订单对权重、时钟与样本上互不相同。不存在可以引用的那个移动平均回测。
:::

:::solution
收盘价$104$在$t = 3$处。窗口是$102, 101, 104$，和是$307$，$307/3$四位小数为$102.3333$。

:::exercise 快均线在多少个日期之上？ {level=1 check="4"}
在路径A上，有多少个交易日满足$\mathrm{SMA}_3(t) > \mathrm{SMA}_5(t)$？输入一个整数。
:::solution
两个平均值在$t = 4, 5, 6, 7$处都存在，而[[#ex-cross-dates]]显示不等式在每处都成立。数目是$4$。
:::

:::exercise 一步EMA {level=1 check="104.875"}
一个$\lambda = 1/2$的EMA等于$102.75$，下一个收盘价是$107$。输入下一个EMA值。
:::solution
$E = \tfrac12\cdot 107 + \tfrac12\cdot 102.75 = 53.5 + 51.375 = 104.875$。这就是[[#ex-ema]]中从$t = 4$到$t = 5$的那一步。
:::
:::

:::exercise 交叉的毛复合收益率 {level=2 check="0.067961"}
在路径A上用窗口$3$与$5$施加[[#alg-cross]]，现金收益率$0$，无成本，输入复合收益率，到六位小数。
:::solution
信号在$t = 4, 5, 6, 7$处做多。这些日期中只有前三个拥有下一个收益率。增长因子是$110/103$，复合收益率$7/103$六位小数为$0.067961$。
:::
:::

:::exercise 首个重叠处的差距 {level=2 check="0.6667"}
输入路径A上的$\mathrm{SMA}_3(4) - \mathrm{SMA}_5(4)$，舍入到四位小数。
:::solution
$\mathrm{SMA}_3(4) = 308/3$而$\mathrm{SMA}_5(4) = 102 = 306/3$，所以差距是$2/3 = 0.6666\ldots$，舍入为$0.6667$。
:::
:::

:::exercise 说出一个不是年化复合增长率的差别 {level=2}
O01已报告年化复合增长率$+3.33\%$，W01已报告$+7.38\%$。给出两个实验之间一个不属于已报告摘要统计量之差别的差别。只使用目录描述。
:::solution
以下任何一条都足够。O01使用窗口$20$与$50$，在股票交易所交易基金的交叉上提交市价单，跨距$25$年。W01在$\mathrm{SMA}(50) > \mathrm{SMA}(200)$期间持有每只行业交易所交易基金，每日调仓权重，跨距$26$年。窗口、订单对权重、事件对每日调仓、写明的样本池与跨距，全是规格说明上的差别。年化复合增长率的差距是一个输出，不是那些差别之一。这些数字是2026年读到的原样报告，这里没有重跑。
:::
:::

:::exercise 在t = 2处核对展开的EMA {level=3 check="101"}
在路径A上以$\lambda = 1/2$与$E_0 = P_0 = 100$使用[[#prop-ema]]。由折现和公式而不是递归计算$E_2$，并输入该值。
:::hint
$t = 2$处的公式包含两个折现收盘价加上种子项$(1-\lambda)^2 P_0$。当$\lambda = 1/2$时，每个系数都是二分之一的幂。
:::
:::solution
$$
E_2 = \tfrac12 P_2 + \tfrac12\cdot\tfrac12 P_1 + \bigl(\tfrac12\bigr)^2 P_0 = \tfrac12\cdot 101 + \tfrac14\cdot 102 + \tfrac14\cdot 100 = 50.5 + 25.5 + 25 = 101.
$$
[[#ex-ema]]中的递归给出同样的值。这个练习核对的是：展开后的权重——其和为$1/2 + 1/4 + 1/4 = 1$——能够重现它。
:::
:::

:::exercise 一条直线与SMA(5) {level=3 check="110"}
设$t = 0, 1, \ldots, 7$时$P_t = 100 + 2t$，于是收盘价依次为$100, 102, \ldots, 114$。输入$\mathrm{SMA}_5(7)$。
:::hint
对$P_3$到$P_7$这五个收盘价取平均。在一条直线上，这等于$t = 7$之前$(5-1)/2 = 2$个交易日的收盘价。滞后恒等式在成本一章证明；这里只需要那个平均值。
:::
:::solution
五个收盘价是$106, 108, 110, 112, 114$。它们的和是$550$，均值是$110$。那就是$P_5$，$t = 7$之前的第二个交易日，也就是$n = 5$时的滞后$(n-1)/2$。答案是$110$。
:::
:::
