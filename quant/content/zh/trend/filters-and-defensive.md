到目前为止，那些规则把一个序列的一个特征映射成同一个序列上的多头或持币头寸。滤波器做的是另一件事。它把一个信号映射到一个样本池上：哪些标的有资格入选，或者哪一份具名名单才是权重可以非零的那一份。经济论断仍然是一个趋势论断。有人在断言：一个参考序列的符号，对于那个被切换进来的名单的收益率含有信息。这个映射不是持有参考序列的建议，也不是持有那份名单的建议。

路径A仍是那八个编造的收盘价$P = (100, 102, 101, 104, 103, 107, 106, 110)$，$t = 0,\ldots,7$。由[[trend/moving-averages]]，$t = 2,\ldots,7$的$\mathrm{SMA}_3(t)$是$101$、$307/3$、$308/3$、$314/3$、$316/3$、$323/3$。本章的玩具按收盘价是否严格高于那条平均值，对同一个序列做多或持有现金。它是二值滤波器的一幅单标的图景。它不是一份多标的的防御性配置，下面引用的那条库内行也不是那个玩具。

## 从一个信号到一份名单

:::definition 滤波器 {#def-filter}
设样本池$\mathcal{U}$是标的的一个有限集合，又设$\mathcal{L}_1, \ldots, \mathcal{L}_m$是$\mathcal{U}$的子集，称为名单。**滤波器**是一条规则：在每个日期$t$，它只使用在$t$可得的信息，并返回一份名单$\mathcal{L}_{I_t}$。所选名单之外的标的得到目标权重$0$。名单之内的标的得到又一个映射所赋予的任何权重。滤波器本身不设定那些权重。标注在$t$的信号仍然挣取$t$之后的收益率：在$t$选定的名单暴露给产生$R_{t+1}$的那个交易日，而不是$R_t$。
:::

若$m = 2$，且两份名单中一份是单个风险序列、另一份是现金，滤波器就坍缩成一条多头或持币规则。那个坍缩就是下面的玩具。W06是本章节围绕其展开的库内案例，它不会那样坍缩。它的目录那一行是：若SPY高于其$\mathrm{SMA}(200)$，则持有风险偏好（risk-on）交易所交易基金名单，否则持有防御性名单，并在信号变化时交易。日频K线，跨距$19$年。按quants.md对那个QuantJourney示例（Apache-2.0）的报告，按2026年的阅读，总收益率为$+132\%$，年化复合增长率为$+4.54\%$，已报告夏普比率为$0.26$，最大回撤为$-24.6\%$，胜率为$41.1\%$，盈亏比为$1.64$。本图谱没有重跑过该回测，没有核实夏普的约定，而且从那一句话规则无从得知任一名单的成分。为那些名单臆造代码，就是臆造一个实验。

SPY在那句话里出现，是作为其均值负责挑选名单的那个序列。说出它的名字是描述那个被报告的实验的一部分。这不是"该序列应当被持有"的发现，防御性名单也是同一个实验里的一个标签，不是本图谱提议的一组持仓。想要成分的读者必须去读源头。本章不提供替代品。

已报告的胜率$41.1\%$挨着一个为正的已报告年化复合增长率。在一笔胜被定义之前，这一对里没有张力。不论那个回测按什么单位计数，一半以下的胜率都可以与一个为正的复合收益率并存：只要盈利的单位大于亏损的单位，或者那个单位不是一整个持有期限。[[performance/win-rate-and-profit-factor]]才给出这个定义；盈亏比$1.64$是目录的伴随单元格，不是这里重新算出的量。这一对不是采纳这个滤波器的理由，为正的年化复合增长率也不是。

:::definition 收盘价对均值的二值滤波器 {#def-binary}
固定一个窗口$n$，以及每交易日为常数、且事先已知的现金收益率$c_f$。对$t \ge n - 1$，设

$$
f_t = \begin{cases} 1 & \text{当 } P_t > \mathrm{SMA}_n(t),\\ 0 & \text{否则} \end{cases}
$$

在均值存在之前，设$f_t = 0$。若$f_t = 1$，账户在下一个交易日挣得$R_{t+1}$。若$f_t = 0$，它挣得$c_f$。比较是严格的。收盘价恰好等于其均值时是现金，不是风险。该规则是[[#def-filter]]意义上的一个滤波器，它的两份名单是"这一个序列"与"现金"。
:::

:::proposition 现金收益为零时的增长 {#prop-cash}
假设$c_f = 0$，每个风险简单收益率满足$R_{t+1} > -1$，财富从$1$开始。设$A$是那些$f_t = 1$且$R_{t+1}$存在的日期$t$的集合。则[[#def-binary]]的增长因子为

$$
G = \prod_{t \in A} (1 + R_{t+1}),
$$

其中空乘积等于$1$。在其余因子保持为正的条件下，把一个被持有的因子$1 + R$换成现金因子$1$，当$R < 0$时抬高$G$，当$R > 0$时压低$G$，当$R = 0$时$G$不变。
:::

:::proof
在$f_t = 0$的日期，财富乘以$1 + c_f = 1$。在$f_t = 1$且存在下一个收益率的日期，财富乘以$1 + R_{t+1}$。没有下一个收益率的日期不再给财富增加任何乘数。这些$1$与那些被持有因子的乘积，就是$A$上的乘积。

考虑那个乘积内部的一个因子$1 + R > 0$，并把$G$写成$G = (1+R)\, G_{\setminus}$，其中$G_{\setminus} > 0$。现金替代给出$G' = G_{\setminus}$。于是$G' - G = G_{\setminus}\bigl(1 - (1+R)\bigr) = -R\, G_{\setminus}$。$G' - G$的符号与$R$的符号相反，且当$R$为零时两者都为零。
:::

第二句话就是"防御性"这个词在这个玩具里的全部内容。跳过一段下跌交易日，期末财富高于持有它。跳过一段上涨交易日则更低。一个在一段涨势里以现金度过的滤波器，在那段涨势里谈不上防御性；它是缺席。缺席是否有用，取决于它丢掉了哪些收益率——那是事后才可观察的，而不是滤波器在$t$所知道的东西。[[#prop-cash]]里没有任何一句话说$P_t > \mathrm{SMA}_n(t)$能挑出为正的下一个收益率。

:::algorithm 二值滤波器的信号变化交易 {#alg-switch}
1. 在每个输入存在的日期，由[[#def-binary]]计算$f_t$。
2. 设$f_{-1} = 0$。当$f_t \ne f_{t-1}$时，在$t$需要一次交易。
3. 若风险侧是单只满仓标的，则这笔交易在旗标从$0$到$1$时是入场，从$1$到$0$时是出场。权重变动的量为$1$。
4. 若风险侧是一份内部带权重的名单，一次信号变化可能需要对每一个目标发生变动的标的交易；而在信号没有变化的日子，若规格说明要求对漂移调仓，也仍可能需要交易。W06那一行说，被报告的规则在信号变化时交易。每日调仓的规则是另一个时钟。单标的玩具显不出这个差别，因为$\{0, 1\}$中的权重不会漂移。
:::

## 路径A上的玩具

把$P_t$与$\mathrm{SMA}_3(t)$相比较。在$t = 2$处两者都等于$101$，所以严格规则持有现金。在$t = 3, 4, 5, 6, 7$，收盘价严格高于均值：$104 > 307/3$、$103 > 308/3$、$107 > 314/3$、$106 > 316/3$、$110 > 323/3$。于是旗标从$0$变到$1$只发生了一次，在$t = 3$，之后保持$1$。[[#alg-switch]]在样本内记录一次入场、没有出场。

:::example 现金收益为零时的复合收益率 {#ex-filter}
在路径A上以$n = 3$与$c_f = 0$施加[[#def-binary]]。哪些下一个交易日的收益率被挣到，复合收益率是多少？
:::solution
在$t$的决策挣得$R_{t+1}$。旗标在$t = 2$为$0$，所以$R_3$不被挣到。旗标在$t = 3, 4, 5, 6$为$1$，所以$R_4, R_5, R_6, R_7$被挣到。$t = 7$处的旗标没有下一个收益率。

被持有的因子是$103/104$、$107/103$、$106/107$与$110/106$。约去$103$、$107$与$106$：

$$
\frac{103}{104}\cdot\frac{107}{103}\cdot\frac{106}{107}\cdot\frac{110}{106} = \frac{110}{104} = \frac{55}{52}.
$$

[[#prop-cash]]说过，增长因子恰恰就是那个乘积。复合收益率为$55/52 - 1 = 3/52$，六位小数为$0.057692$。

被跳过的收益率$R_3 = 3/101 > 0$是一段上涨交易日，即从$101$到$104$的那段变动。由[[#prop-cash]]的第二部分，跳过它使增长因子低于持有它。从$P_2$一直持有到$P_7$会复合到$110/101 - 1 = 9/101 = 0.089109$。滤波器的$3/52$是从$104$到$110$的变动，即那个持币交易日之后剩下的部分。在后来的那些下跌交易日上，现金没有以压过这笔算术的方式帮到忙，因为那些下跌交易日是被持有的：裂项相消把它们保留下来，结果仍约简为$110/104$。这个滤波器只在持平处"防御"过，而那个持平之后紧接着一次上涨。
:::
:::

:::example 持平就是全部的差别 {#ex-tie}
只改动[[#def-binary]]中的不等号，从严格改为带等号，使收盘价等于$\mathrm{SMA}_3$时即为持有。在路径A上以$c_f = 0$重新计算复合收益率。
:::solution
唯一的持平在$t = 2$。带等号的规则设$f_2 = 1$，因此除$R_4,\ldots,R_7$外还挣得$R_3$。多出的因子是$104/101$，而

$$
\frac{104}{101}\cdot\frac{110}{104} = \frac{110}{101}.
$$

复合收益率为$9/101 = 0.089109$，六位小数。一个日期——收盘价等于均值的日期——把复合收益率从$0.057692$挪到$0.089109$。规格说明选$>$而不是$\ge$，不是装饰。它就是这两个玩具之间的全部差别。算术不推荐任何一种选择。两者都是定义。
:::
:::

:::example 唯一持币交易日上的非零现金收益率 {#ex-cash-rate}
保留严格规则，并在每一个拥有下一个收益率的持币交易日上设$c_f = 0.001$。计算复合收益率。
:::solution
这样的交易日只有一个，即挣得$R_3$的那一步，账户在那一步现在乘以$1.001$而不是$1$。每个被持有的因子都不变，所以增长因子为

$$
1.001 \cdot \frac{55}{52} = \frac{1001}{1000}\cdot\frac{55}{52} = \frac{11011}{10400}.
$$

复合收益率为$611/10400$，精确地是$0.05875$。与$3/52 = 0.057692\ldots$相比，现金收益添进一点点，并不改变持有了哪些风险交易日。若现金收益率大于被跳过的风险收益率，影响会大得多；$0.001$远在$R_3 = 3/101$之下。这仍然是一个带着编造现金利率的单标的玩具。它不是国债，也不是一份防御性名单。
:::
:::

:::example 玩具为什么复现不了W06的时钟 {#ex-clock}
在路径A上的严格滤波器上，列出[[#alg-switch]]会交易的交易日。解释为什么对同一个旗标做每日调仓会在同样的交易日交易，以及为什么若风险侧是一份内部权重会漂移的名单，那个一致就会失效。
:::solution
旗标在$t = 0, 1, 2$为$0, 0, 0$（均值在前两个日期不存在，而在$t = 2$处持平即为持币），此后一直是$1$。唯一的变动在$t = 3$，从$0$到$1$。信号变化交易入场一次。

在单只标的上取$0$或$1$、且每逢旗标被求值就重置的权重，只在旗标变动时移动。每日求值与信号变化求值看到的是同一次唯一的变动。没有漂移需要修正：入场之后目标保持为$1$，而单只满仓的标的本没有东西可供对漂移调仓。

相反，若选中的名单包含若干只目标之和为$1$的标的，那么一旦各标的的收益率出现差异，那些权重就会漂移，哪怕滤波器的旗标仍停在"风险偏好"上。每日调仓会对漂移交易。而按W06目录那一行所描述的信号变化规则，要到旗标更换名单才会交易。路径A上的一致，是单只标的的$\{0, 1\}$权重造成的假象。关于那条$19$年的记录除了目录那一行已有的文字之外还用了哪个时钟，它什么也没有说，这也不是偏爱任何一个时钟的理由。
:::
:::

W06已报告的$-24.6\%$最大回撤，是目录所计算的那条财富路径的一个性质。玩具的财富路径很短，终结于$55/52$，而且它唯一的持币一步在获支付窗口的开头，所以它内部没有一段值得引作回撤教训的峰谷落差。[[performance/volatility-and-drawdown]]把期末收益率与回撤分开处理。一个为正的$3/52$并不描述乘积内部的那条路径。

## 切换不是一笔收益

滤波器的旗标是一个两状态对象。可以画一条马尔可夫链，作为一本在风险偏好名单与防御性名单之间移动的账簿的草图，同时记住：草图不是W06，也不是对路径A拟合出来的模型。

:::widget markov
matrix: 0.90,0.10; 0.25,0.75
states: Risk-on; Defensive
steps: 24
caption: 从Risk-on出发，读几步之后的分布。这条链是切换的一幅图画，不是W06；两个状态都不是本图谱叫你去持有的名单。
:::

设两个状态依序为风险偏好与防御性，转移矩阵为

$$
\begin{pmatrix} 0.90 & 0.10 \\ 0.25 & 0.75 \end{pmatrix}.
$$

平稳行向量$\pi$满足$\pi = \pi P$与$\pi_1 + \pi_2 = 1$。第一个坐标服从$\pi_1 = 0.90\,\pi_1 + 0.25\,(1 - \pi_1)$，于是$0.35\,\pi_1 = 0.25$，因此$\pi_1 = 5/7$、$\pi_2 = 2/7$。若这条链就是数据生成过程——而它并不是——那么这条链一段很长的运行中，恰有大约七分之五花在风险偏好状态上。这个比例$5/7$不是年化复合增长率，不是夏普比率，也不是胜率。它是一个为配图选定的矩阵的平衡方程。换掉矩阵就换掉了这个比例。在同一段样本上拟合这个矩阵、之后又用同一段样本去评判这个滤波器，是另一个被搜索过的对象；[[statistics/stationarity-and-regimes]]才是把体制滤波器当作参数而不是装饰来处理的地方。

:::intuition 缺席也是一个仓位
持币、现金，或"防御性名单"，是一个自有其收益率的仓位。在玩具里，收益率是$0$或$0.001$，由写算例的人选定。在W06里，替代收益率就是那份防御性名单在那个实验里交出的成绩，本图谱没有重新计算过。把替代品称作防御性的，描述的是对其回撤的一种期望。这份期望不在[[#def-filter]]里。定义只说：选出一份名单，另一份得到权重零。
:::

:::warning 参考序列不是持仓
W06把一只宽基指数基金离其$200$个交易日均值的距离用作一个开关。描述那条规则，需要说出目录所说的那个序列的名字。那个名字是别人的一个规格说明的输入。本章没有说要持有那个序列，没有说要持有一只防御性篮子，也没有说要追随趋势。已报告的年化复合增长率$+4.54\%$是本图谱没有重跑过的某个回测里的一个单元格。单元格不是指令。
:::

:::quiz
在路径A上，严格滤波器$P_t > \mathrm{SMA}_3(t)$在$t = 2$持币。那个持币决策拒绝了哪个收益率？
- [ ] $R_2$，即在$t = 2$刚刚到达的那个收益率
- [x] $R_3$，即下一个交易日的收益率
- [ ] $R_7$，因为滤波器总是拒绝最后一个收益率
- [ ] 哪个也不是，因为持平按约定即为持有
:::solution
标注在$t = 2$的特征，持有就挣$R_3$，持币就挣现金收益率。持平使严格规则持币，所以被拒绝的风险收益率是$R_3$。[[#def-binary]]不把持平投入。
:::
:::

:::quiz
目录为W06报告胜率$41.1\%$与年化复合增长率$+4.54\%$。不重跑回测，哪句话是站得住的？
- [ ] 该规则亏了钱，因为胜率不足一半
- [ ] 该规则应当加仓，因为年化复合增长率为正
- [x] 两个单元格可以并排成立，而两个单元格都没有指明被称作一笔胜的单位。本图谱没有重新定义那个单位，也没有重跑检验
- [ ] 胜率必定是排印错误，因为为正的年化复合增长率会迫使胜率超过一半
:::solution
复合收益率与胜率回答的是不同的问题。没有单位，一半以下的胜率决定不了复合收益率的符号。为正的年化复合增长率是一个被报告的单元格，不是建议。两个数字都按2026年读到的原样。
:::

:::remark 名单、权重，以及仍然缺的东西
即便$I_t$已经选出一份名单，名单内的每只标的仍需要一个权重，而权重需要一条调仓规则。[[portfolio/from-signal-to-weight]]正是从那个缺口起步。一个对权重保持沉默的滤波器，就对名单内部的换手保持沉默，这正是[[#ex-clock]]拒绝把单标的玩具当作W06的模型的理由。趋势假说因为被应用于一份名单而没有变得更温和。它变成了这样一个假说：在参考信号的条件之下，名单的收益率如何。成本与滞后照样适用，只是上升了一层：参考均值滞后于参考转折，而每一次换名单，都要为每一个进入或离开名单的标的支付换手。
:::

:::history 趋势工具与极值读数工具
惠尔德（Wilder）的 *New Concepts in Technical Trading Systems*（1978）收录了好几个指标，其中包括相对强弱指标，并把趋势读数与极值读数当作分开的工具。一个因为参考收盘价高于长均值而更换名单的滤波器，站在这条分界的趋势一侧：它赌的是一个符号会持续。因为一个读数处于极值而入场，是另一个赌注，在均值回归课程里展开。1978年的这条分界不背书任何一个赌注，也没有指名一份防御性名单。
:::

## 通往何处

更换名单去掉不了滞后。一条长均线在价格转折之后才转折，而一个等待均线的切换要等过那次转折。[[trend/lag-whipsaw-and-costs]]为那次等待定价，包括本章在$t = 3$数出的那一次入场，尽管成本一章在路径A上的主算例是移动平均交叉而不是这个滤波器。滤波器仍然需要的那个权重映射是[[portfolio/from-signal-to-weight]]。

:::summary
- 滤波器把$t$处的信息映射到一份名单。不在名单上的标的得到权重零。名单上的权重是又一个映射。在$t$选定的名单挣取$t$之后的收益率。
- W06按SPY是否高于其$\mathrm{SMA}(200)$，在风险偏好交易所交易基金名单与防御性名单之间切换，并在信号变化时交易。已报告年化复合增长率$+4.54\%$，夏普比率$0.26$，最大回撤$-24.6\%$，胜率$41.1\%$。那个序列的名字是目录的输入，不是持仓。
- 玩具$P_t > \mathrm{SMA}_3(t)$在路径A上只在持平$t = 2$处持币，此后做多。现金为$0$时增长因子为$55/52$，复合收益率为$0.057692$。把持平当作持有，复合收益率变为$0.089109$。
- 跳过一个为正的收益率，期末财富相对持有它而言更低。防御性这个词推翻不了那个算术。
- 在单只取$0$或$1$的标的上，信号变化交易与每日调仓在同样的日期交易。在一份会漂移的名单上则不然。W06那一行写明的是信号变化。
- 用图中那个矩阵的两状态链，平稳质量$5/7$花在第一个状态上。那个质量不是业绩统计量。
:::

## 练习

:::exercise 持平处是持币还是持有？ {level=1 check="0"}
在路径A上用严格规则$P_t > \mathrm{SMA}_3(t)$，输入$f_2$。
:::solution
$P_2 = \mathrm{SMA}_3(2) = 101$。不等式是严格的，所以$f_2 = 0$。
:::
:::

:::exercise 一个更晚的日期 {level=1 check="1"}
对同一条严格规则，输入$f_6$。
:::solution
$P_6 = 106$而$\mathrm{SMA}_3(6) = 316/3 \approx 105.3333$。因为$106 > 316/3$，$f_6 = 1$。
:::
:::

:::exercise 玩具的复合收益率 {level=1 check="0.057692"}
输入路径A上严格滤波器在现金收益率为$0$之下的复合收益率，到六位小数。
:::solution
增长因子约简为$55/52$。复合收益率为$3/52 = 0.057692$，六位小数。
:::
:::

:::exercise 把持平算作持有 {level=2 check="0.089109"}
若收盘价等于$\mathrm{SMA}_3$即为持有，输入路径A上现金为$0$的复合收益率，到六位小数。
:::solution
多出的那个持有因子是$104/101$，增长因子变为$110/101$。复合收益率为$9/101 = 0.089109$，六位小数。
:::
:::

:::exercise 现金挣千分之一 {level=2 check="0.05875"}
保留严格滤波器，并在唯一那个获支付的持币交易日上把现金收益率设为$0.001$。输入复合收益率。
:::solution
把$55/52$乘以$1.001$。增长因子为$11011/10400$，复合收益率为$611/10400 = 0.05875$。
:::
:::

:::exercise 一半以下的胜率 {level=2}
W06报告胜率$41.1\%$、年化复合增长率$+4.54\%$。给出一个理由，说明这一对本身为什么不构成矛盾。不要提议一笔交易。
:::solution
胜率是满足"胜"之定义的单位数，除以单位总数。年化复合增长率是一段以年计的跨距上的复合增长。若盈利的单位大于亏损的单位，或者那个单位不是"整个账户的一次持有期限"，一半以下的胜率就可以挨着一个为正的复合收益率。目录还报告了盈亏比$1.64$，这与"在它所用的单位上盈利超过亏损"相符，但本图谱没有重新定义那个单位，也没有重跑检验。为正的年化复合增长率仍是一个被报告的单元格，不是指令。
:::
:::

:::exercise 把乘积裂项相消 {level=3 check="55/52"}
写出[[#ex-filter]]的四个被持有毛因子并把它们约掉。以最简分数输入增长因子。
:::hint
因子是$103/104$、$107/103$、$106/107$与$110/106$。用一个分子与一个较晚的分母相约。
:::
:::solution
先约去$103$，再约去$107$，再约去$106$。乘积为$110/104 = 55/52$。那就是增长因子。复合收益率是$3/52$，而那并不是题目要的。
:::
:::

:::exercise 平稳质量 {level=3 check="5/7"}
对图中那个转移矩阵，两行为$(0.90,\ 0.10)$与$(0.25,\ 0.75)$，以最简分数输入第一个状态的平稳概率。
:::hint
把$\pi_1 = 0.90\pi_1 + 0.25(1-\pi_1)$与概率之和为$1$联立求解。
:::
:::solution
平衡方程整理为$\pi_1 - 0.65\pi_1 = 0.25$，所以$0.35\pi_1 = 0.25$，$\pi_1 = 0.25/0.35 = 5/7$。互补的质量是$2/7$。这个比例是那个矩阵的性质，不是回测结果；而两个状态是草图上的标签，不是可以去持有的名单。
:::
:::
