移动平均交叉比较的是收盘价的两个平滑器。突破比较的是收盘价与一个高点，而MACD比较的是平滑器之差与该差值的又一个平滑器。两者仍然是[[trend/the-trend-hypothesis]]意义上的符号规则：一个标注在$t$的特征，只由$t$可得的信息构建，作为关于$t$之后收益率的一个假说被提出。它们改变的是特征。它们没有把那个经济论断变成别的东西，也不会变成持有那个特征所由以计算的资产的指令。

路径A仍是同样那八个虚构收盘价，$t = 0,\ldots,7$，

$$
P = (100,\ 102,\ 101,\ 104,\ 103,\ 107,\ 106,\ 110).
$$

这条序列只给出收盘价。一个定义在最高价与最低价上的通道，在写明替代值之前无法计算。这里使用的替代值就是收盘价本身：玩具中一个交易日的最高价就是它的收盘价，最低价是同一个数。这是例子的一个局限，不是说最高价无关紧要的论断。在库内规则写"20日高点"的地方，目录的意思是一次最高价。玩具的意思是一个较早的收盘价。

## 一个通道与一个止损价

:::definition 前窗通道 {#def-channel}
固定整数$N \ge 1$。在日期$t \ge N$处，收盘价序列的**前窗通道**的上沿为

$$
U_t = \max\{P_{t-N},\ldots,P_{t-1}\}
$$

下沿为$L_t = \min\{P_{t-N},\ldots,P_{t-1}\}$。窗口止于$t - 1$。收盘价$P_t$不是它被要求去超越的那个最大值的集合的成员。突破信号是：$P_t > U_t$时$b_t = 1$，否则$b_t = 0$。合法利润是$b_t R_{t+1}$。如果把$P_t$包括进$U_t$，就会迫使$P_t \le U_t$，信号便永远不会触发。
:::

唐奇安（Donchian）式通道就是这个构造在输入换成最高价与最低价而不是收盘价时的情形：上沿是写明窗口内的最高价之最高值，而突破就是一笔穿过那个高点的成交。这个名字标记的是这个构造。除了课程记录已经就通道规则说过的内容，本章不再给它附加年份。

:::definition 通道之上的买入止损单 {#def-stop}
**买入止损单**是这样一种订单：若市场以高于当前报价的一个写明价格成交，它就意图买入。在一个突破的规格说明里，止损价由通道设定，设在前高之上或紧贴前高。[[#def-channel]]里的信号$b_t$不是那张订单。它是收盘价与一个先前最大值之间的比较。是否选用止损单、以及它以什么价格成交，取决于K线内部的成交与订单类型。那些机制属于[[orders/stops-and-stop-limits]]。在路径A上没有K线内部的成交，所以本章从不假装让一个止损单成交。它只计算$b_t$。
:::

开放库中的O05是止损单入场的突破：在最近的20日高点之上放一张买入止损单。日频K线，跨距$25$年。按quants.md对那个QuantJourney示例（Apache-2.0）的报告，按2026年的阅读，总收益率为$+41.44\%$，年化复合增长率为$+1.40\%$，已报告的夏普比率为$-0.19$，最大回撤为$-10.5\%$，胜率为$61.9\%$，盈亏比为$1.45$。本图谱没有重跑过该回测，也没有核实夏普的年化或其无风险利率约定。这一行不是建议，也不是预测。

一个为正的总收益率挨着一个为负的已报告夏普比率，很容易被朝错误的方向"纠正"——翻一个符号，或者删掉两个单元格中的一个。下一条命题说明，为什么在本图谱使用的定义之内，翻转是行不通的。

:::proposition 两期复合增长与均值的符号 {#prop-mean}
设$a > -1$、$b > -1$，并假设$(1+a)(1+b) > 1$。则$a + b > 0$。于是，如果这两个简单收益率就是整个样本、无风险利率为$0$、且$\{a, b\}$的样本标准差为正，那么以均值除以那个标准差定义的夏普比率就是正的。
:::

:::proof
不等式$(1+a)(1+b) > 1$展开为$a + b + ab > 0$，所以$a + b > -ab$。

用反证法：假设$a + b \le 0$。于是$-ab < a + b \le 0$，这就迫使$ab > 0$。再结合和非正，$a$与$b$都严格为负：和为零而积为正是不可能的，因为$b = -a$会给出$ab = -a^2 \le 0$。由假设两者也大于$-1$，所以$0 < 1+a < 1$且$0 < 1+b < 1$。它们的乘积严格小于$1$，与假设矛盾。因此$a + b > 0$。

两个收益率的均值是$(a+b)/2 > 0$。除以一个为正的样本标准差，在无风险利率为$0$之下，得到的是一个为正的夏普比率。
:::

:::remark 从两期到长样本
对$n$个简单收益率，每个都大于$-1$，增长因子为$G = \prod(1+R_t) > 1$，由对数函数在$(0, \infty)$上的凹性，得到

$$
\frac1n\sum_{t=1}^{n}\log(1+R_t) \le \log\Bigl(1 + \bar R\Bigr).
$$

左边等于$(\log G)/n > 0$，所以$\bar R > 0$。本章把凹性作为$\log$的一个具名性质使用，不再重新证明它。在那个性质之下，一个简单收益率序列的正复合增长迫使同一个序列的算术均值为正。于是只要样本标准差为正，我们在无风险利率为$0$之下的夏普就是正的。

O05报告总收益率$+41.44\%$，所以目录的期末增长在$1$之上，而它报告的夏普为$-0.19$。这两个单元格不可能是在正的样本标准差之下、由产生那个总收益率的同样那些简单收益率算出的、我们的零无风险利率夏普。在形成比率之前减去一个为正的融资利率，或者一套完全不同的约定，都可能产生这样一对数字。本图谱没有核查目录用的是哪套约定。两个单元格并排保留。它们不是待修复的错误，而负的已报告夏普也不是去做突破另一边的理由。
:::

通道规则的期货版本又是另一个实验。O20是在数据商的连续期货序列上按整张合约确定头寸规模；合约算术留给[[asset-classes/futures]]，不会把它当作O05重讲一遍。

:::algorithm 由收盘价得出突破旗标 {#alg-break}
1. 选取$N$与一个收盘价序列。若最高价存在且规格说明点名用它们，就在最大值中用最高价代替收盘价；否则说明你用的是收盘价。
2. 对每个$t \ge N$，令$U_t = \max\{P_{t-N},\ldots,P_{t-1}\}$，且$P_t > U_t$时$b_t = 1$，否则$b_t = 0$。
3. 挣$b_t R_{t+1}$。不要挣$b_t R_t$。突破发生的那个交易日的$R_t$包含了越过先前最大值的那段变动，而那段变动已经在$P_t$里了。
4. 如果你需要说某个收盘价坐在通道内部，就记录下沿；但除非规格说明要求，不要把下沿变成一条卖出规则。本章的玩具是多头或持币，不是多头或空头。
:::

## 路径A上的三个交易日通道

取$N = 3$。第一个拥有三个先前收盘价的日期是$t = 3$。

:::example 前三交易日的通道 {#ex-channel}
对路径A上的$t = 3,\ldots,7$，列出先前的窗口、$U_t$、$L_t$与$b_t$。
:::solution
窗口不包含当前收盘价。

| $t$ | 先前的收盘价 | $U_t$ | $L_t$ | $P_t$ | $b_t$ |
|---|---|---|---|---|---|
| $3$ | $100, 102, 101$ | $102$ | $100$ | $104$ | $1$ |
| $4$ | $102, 101, 104$ | $104$ | $101$ | $103$ | $0$ |
| $5$ | $101, 104, 103$ | $104$ | $101$ | $107$ | $1$ |
| $6$ | $104, 103, 107$ | $107$ | $103$ | $106$ | $0$ |
| $7$ | $103, 107, 106$ | $107$ | $103$ | $110$ | $1$ |

在$t = 4$处，收盘价$103$严格坐在$[101, 104]$内部。信号是持币，不是因为路径"停止了趋势"，而是因为$103$没有超过先前的最大值$104$。在$t = 7$处信号做多，而样本内没有下一个收益率，所以[[#alg-break]]的第3步记录下旗标，不再支付任何东西。
:::
:::

:::example 三个交易日突破的复合收益率 {#ex-break-pnl}
把[[#ex-channel]]里的$b_t$持有到下一个交易日，现金收益率为$0$。计算复合收益率。
:::solution
获得支付的日期是$t = 3$与$t = 5$。它们挣得$R_4 = -1/104$与$R_6 = -1/107$。持币的日期贡献因子$1$。增长因子是

$$
\frac{103}{104}\cdot\frac{106}{107} = \frac{5459}{5564}.
$$

复合收益率是$-105/5564$，六位小数$-0.018871$。两个被持有的交易日都是下跌交易日。把收盘价推过先前最大值的那几个上涨交易日——$R_3$、$R_5$与$R_7$——恰恰是合法时钟拒绝支付的那几个交易日，因为它们每一个都是以突破为终点的那个收益率。同K线的版本本会收割那些上涨交易日，而那是另一个、非法的实验。这个负的玩具结果不确认O05负的已报告夏普，也不反驳O05为正的已报告年化复合增长率。窗口、工具与订单类型都对不上。
:::
:::

两交易日的先前窗口（$N = 2$）恰好在同样的日期$t = 3, 5, 7$触发，并在$t = 4, 6$保持持币。在额外多出的日期$t = 2$，先前的最大值是$\max(100, 102) = 102$而收盘价是$101$，所以$b_2 = 0$。获得支付的交易日依旧是$R_4$与$R_6$，复合收益率依旧是$-0.018871$。$N = 2$与$N = 3$在这条路径上一致，是关于路径A的一个事实。它不是关于通道的定理，也不是一份在任何别的路径上把窗口长度当作无关紧要的许可。

## MACD

:::definition MACD线与信号线 {#def-macd}
在$(0, 1]$中选取衰减$\lambda_{\mathrm{f}}$与$\lambda_{\mathrm{s}}$，把较大的一个作为快衰减，并以一个写明的收盘价给两个指数平均都播种。设$E^{\mathrm{f}}_t$与$E^{\mathrm{s}}_t$为[[trend/moving-averages]]里的递归。**MACD线**为

$$
M_t = E^{\mathrm{f}}_t - E^{\mathrm{s}}_t.
$$

再选一个衰减$\lambda_{\mathrm{g}}$以及信号线的种子。**信号线**$S_t$是$M_t$在该衰减下的指数平均。用作库内示例之形状的多头或持币规则，在$M_t > S_t$时$m_t = 1$，否则$m_t = 0$。合法利润是$m_t R_{t+1}$。
:::

杰拉尔德·阿佩尔（Gerald Appel）的这个构造，课程记录把它定在1979年，是用一个较快的指数平均减去一个较慢的指数平均，再把差值平滑一次。交易台上通常引用的跨度长于八个交易日。下面的玩具使用$\lambda_{\mathrm{f}} = 2/3$（跨度$2$，在约定$\lambda = 2/(n+1)$之下）、$\lambda_{\mathrm{s}} = 1/2$（跨度$3$）与$\lambda_{\mathrm{g}} = 2/3$，两个价格平均都以$P_0 = 100$播种，信号线以$M_0 = 0$播种。这些跨度的选取使每一步都落在路径A上。它们不是库内规则的重构，而把跨度换成$12$、$26$与$9$的读者是在跑另一件玩具。

W22，MACD Trend，规则是：只要MACD线在其信号线之上就做多。日频K线，跨距$26$年。按quants.md对那个QuantJourney示例（Apache-2.0）的报告，按2026年的阅读，总收益率为$+186\%$，年化复合增长率为$+4.13\%$，已报告的夏普比率为$0.22$，最大回撤为$-35.6\%$，胜率为$63.5\%$，盈亏比为$1.24$。本图谱没有重跑过该回测，也没有核实夏普的约定。已报告的回撤比O05的$-10.5\%$更深，已报告的年化复合增长率更高。跨距相差一年，一条规则是止损单入场的突破，另一条是在一个MACD不等式成立期间的权重。这两行不是"突破对MACD"的配对检验。

:::example 路径A上的玩具MACD {#ex-macd}
用刚刚说明的衰减与种子，计算$M_t$与$S_t$直到$t = 7$。标出$M_t > S_t$的日期。用分数展示从$t = 0$到$t = 1$的那一步，后面各行则把同一递归用精确算术求值后再舍入到六位小数。
:::solution
在$t = 0$处，$E^{\mathrm{f}} = E^{\mathrm{s}} = 100$，所以$M_0 = 0$且$S_0 = 0$。不等式不是严格的，于是$m_0 = 0$。

在$t = 1$处，

$$
E^{\mathrm{f}}_1 = \tfrac23\cdot 102 + \tfrac13\cdot 100 = \tfrac{304}{3}, \qquad E^{\mathrm{s}}_1 = \tfrac12\cdot 102 + \tfrac12\cdot 100 = 101,
$$

于是$M_1 = 304/3 - 101 = 1/3 = 0.333333$。信号线的更新是$S_1 = \tfrac23\cdot(1/3) + \tfrac13\cdot 0 = 2/9 = 0.222222$。因为$1/3 > 2/9$，规则在$t = 1$处做多。

其余各行，由精确分数舍入到六位小数，如下：

| $t$ | $M_t$ | $S_t$ | $M_t > S_t$ |
|---|---|---|---|
| $0$ | $0.000000$ | $0.000000$ | 否 |
| $1$ | $0.333333$ | $0.222222$ | 是 |
| $2$ | $0.111111$ | $0.148148$ | 否 |
| $3$ | $0.537037$ | $0.407407$ | 是 |
| $4$ | $0.262346$ | $0.310700$ | 否 |
| $5$ | $0.795782$ | $0.634088$ | 是 |
| $6$ | $0.452761$ | $0.513203$ | 否 |
| $7$ | $0.911337$ | $0.778626$ | 是 |

该线在从$1$到$7$的奇数日期上位于其信号线之上，在从$2$到$6$的偶数日期上位于其下。在这条路径上，用这些很短的跨度，这个玩具在种子之后每个交易日来回翻转一次。这是一个特征自身的来回止损，在任何成本被收取之前就能看见。它不是W22，W22的跨度与样本池都不是这些。
:::
:::

:::example 交替的MACD实际挣到什么 {#ex-macd-pnl}
把[[#ex-macd]]的玩具信号持有到下一个交易日。计算复合收益率，现金收益率为$0$。
:::solution
信号在$t = 1, 3, 5, 7$处做多。其中最后一个没有下一个收益率。获得支付的利润是$R_2$、$R_4$与$R_6$，它们在路径A上每一个都是负的：因子为$101/102$、$103/104$与$106/107$。乘积是$551359/567528$，复合收益率是$-16169/567528$，六位小数$-0.028490$。

同样的三个交易日、同样的复合收益率，曾以[[trend/the-trend-hypothesis]]里那条一日多头或持币符号规则的面目出现。这个相等是这条路径与这几个衰减凑成的巧合：玩具MACD恰好在做多的那些日期，其下一个收益率都是下跌交易日。它不是MACD与$\sgn(R_t)$之间的恒等式。改变$\lambda_{\mathrm{f}}$会改变做多的日期。W22已报告的$+4.13\%$年化复合增长率，是在另一套规格说明之下的一个26年目录数字，不是对一个负的八收盘价玩具的反驳。
:::
:::

:::intuition 突破一个高点仍然是在赌下一个符号
$P_t > U_t$说的是收盘价在一个近期的最大值之上报出。如果有人肯费心把它陈述出来，那个假说是：在那次报出之后，下一个收益率为正的情形比某个写明的替代假设更多。O05用一张买入止损单实现了其中一个版本，并在一个为正的年化复合增长率旁边报告了一个为负的夏普。W22用一个平滑过的差值实现了另一个版本，并在一个深得多的回撤旁边报告了一个为正的夏普。两行都没有回答路径A上的一日通道，而路径A也没有回答其中任何一行。
:::

:::warning 不要为你看不见的止损单成交
收盘价高于前一个收盘价，并不是那张设在前高之上一个tick的买入止损单将会成交的证据，也不是它将成交于什么价格的证据。路径A没有最高价，也没有成交。[[#def-stop]]把那张订单挡在玩具之外。O05的目录那一条是止损单入场规则；它被报告的成交假设不在这里重述，也绝不能用玩具的收盘到收盘因子去替换。
:::

:::quiz
[[#def-channel]]为什么把$P_t$挡在定义$U_t$的那个最大值之外？
- [ ] 因为收盘价对最高价而言是一个比开盘价更差的估计
- [x] 因为$P_t$不可能严格超过一个已经包含$P_t$的集合所取的最大值
- [ ] 因为合法信号被禁止使用$P_t$
- [ ] 因为$N = 3$太短，容不下当前这根K线
:::solution
这个信号问的是当前收盘价是否胜过了先前的窗口。包含当前收盘价的最大值至少是当前收盘价，所以严格不等式永远不成立。信号可以使用$P_t$。它不可以做的，是把$R_t$当作那次比较的利润。
:::
:::

:::quiz
O05已报告年化复合增长率$+1.40\%$、夏普$-0.19$。哪一种读法与本章一致？
- [ ] 夏普应当报成正的，因为年化复合增长率为正
- [ ] 年化复合增长率应当报成负的，因为夏普为负
- [x] 两个单元格都照报告保留。在我们的、无风险利率为零的定义之下，同一条简单收益率序列不可能既复合为盈利又有负的均值，所以目录的那一对数字不是那个比率。这里的约定没有被重新推导过
- [ ] 负的夏普意味着突破假说对每个窗口都已被拒绝
:::solution
[[#prop-mean]]与随后的评注，把我们的零利率夏普与一个约定未经核实的已报告单元格区分开来。改动一个单元格去迁就另一个，就是发明一个库里没有的数字。一行25年的记录不会拒绝每一种突破规格说明。
:::
:::

:::history 平均之差，再平滑一次
课程记录把MACD定在1979年，并描述杰拉尔德·阿佩尔（Gerald Appel）于1970年代后期引入的移动平均收敛/发散振荡器：一个较慢的指数平均被从一个较快的指数平均中减去，差值再平滑一次。那就是[[#def-macd]]的形状。记录没有固定跨度、样本池或成本。W22是后来的一个规格说明：当该线在其信号线之上时做多，其已报告摘要已在上面引用。1979年的那个构造并没有产生那个摘要。

## 通往何处

滤波器取一个信号——可能是一个通道，也可能是一条长均线——并用它来选择一张列表，而不是单个多头或持币的旗标。[[trend/filters-and-defensive]]写出那个映射，并引用库内的防御性切换。一个像玩具MACD那样频繁翻转的旗标的成本，是[[trend/lag-whipsaw-and-costs]]的主题。止损单作为订单而不是作为特征，在[[orders/stops-and-stop-limits]]。

:::summary
- 前窗通道把上沿设为先前$N$个收盘价的最大值，不包含当前收盘价。突破旗标只在当前收盘价严格高于那条上沿时做多，并且挣得下一个收益率。
- 在路径A上取$N = 3$，旗标在$t = 3, 5, 7$处做多。获得支付的复合收益率为$-0.018871$。创下新高的那些上涨交易日，并不是合法时钟支付的那些交易日。
- 在一个高点之上的买入止损单是一张订单。路径A上的旗标不是一笔成交。
- O05在25年上已报告年化复合增长率$+1.40\%$、夏普$-0.19$、最大回撤$-10.5\%$。在我们的零利率定义之下，正的复合增长与负的均值不能共存；已报告的那一对照报告保留。
- 用上面那些很短的衰减的玩具MACD，在种子之后隔一个交易日做多，复合到$-0.028490$。W22是另一个实验，在26年上已报告年化复合增长率$+4.13\%$、夏普$0.22$、最大回撤$-35.6\%$。
- O20是期货的整张合约通道实验，不是O05。它的细节住在期货那一章，不在玩具里。
:::

## 练习

:::exercise 一个先前的最大值 {level=1 check="104"}
在路径A上取$N = 3$，输入$U_5$，即第$5$个交易日之前三个收盘价的最大值。
:::solution
先前的收盘价是$P_2, P_3, P_4 = 101, 104, 103$。最大值是$104$。
:::
:::

:::exercise 第4个交易日是突破吗？ {level=1 check="0"}
在路径A上用$N = 3$的[[#def-channel]]，输入$b_4$，取$0$或$1$。
:::solution
$U_4 = 104$且$P_4 = 103$。因为$103 > 104$为假，$b_4 = 0$。
:::
:::

:::exercise 第一个MACD值 {level=1 check="0.333333"}
用[[#ex-macd]]的玩具衰减，输入$M_1$到六位小数。
:::solution
$M_1 = 1/3 = 0.333333$，六位小数，来自[[#ex-macd]]中$304/3 - 101$的减法。
:::
:::

:::exercise 突破的复合收益率 {level=2 check="-0.018871"}
输入路径A上$N = 3$的合法突破的复合收益率，现金收益率为$0$，到六位小数。
:::solution
获得支付的因子是$103/104$与$106/107$。增长因子是$5459/5564$，复合收益率为$-105/5564$，六位小数$-0.018871$。
:::
:::

:::exercise 有多少个MACD交易日获得支付？ {level=2 check="3"}
在[[#ex-macd-pnl]]中，有多少个交易日贡献了非零利润？输入一个整数。
:::solution
信号在$t = 1, 3, 5, 7$处做多。只有$t = 1, 3, 5$拥有下一个收益率。获得支付的交易日数目是$3$。这些交易日上的每一笔利润都是非零的，因为对应的路径A收益率是非零的。
:::
:::

:::exercise 已报告的那一对为什么不加修改 {level=2}
O05已报告正的年化复合增长率与负的夏普。从本章内部给出一个理由，说明不要把夏普换成它的绝对值。
:::solution
在这里使用的定义之下，无风险利率为$0$；一条复合为盈利的简单收益率序列有正的均值——两期情形由[[#prop-mean]]，更长期限情形由$\log$的凹性。于是一个负的比率就不是我们对那条序列的夏普。尽管如此，目录仍在正的总收益率旁边报告$-0.19$。那个单元格背后的约定没有被核实，所以把$-0.19$换成$0.19$就是发明一个库没有报告的数字。那一对按2026年读到的原样报告引用，回测没有重跑。
:::
:::

:::exercise 符号相反的情形 {level=3}
在[[#prop-mean]]的证明中，乘积$ab$可能为负。在不使用"两者皆负"情形那个反证论证的前提下，证明：若$a > -1$、$b > -1$、$(1+a)(1+b) > 1$且$ab < 0$，则$a + b > 0$。
:::hint
展开乘积不等式直到得到$a + b > -ab$，并利用$ab$的符号。
:::
:::solution
$(1+a)(1+b) > 1$展开为$a + b + ab > 0$，因此$a + b > -ab$。假设$ab < 0$意味着$-ab > 0$。于是$a + b > -ab > 0$，所以$a + b > 0$。限制$a > -1$与$b > -1$在这一步短论证中并不需要；它们保证原始收益率不是全部损失，并在完整证明的"两者皆负"那一半中被使用。
:::
:::

:::exercise 一个巧合，不是一个恒等式 {level=3 check="-0.028490"}
输入玩具MACD在路径A上的复合收益率，到六位小数。然后说明它与多头或持币一日符号规则的相等，是不是两个定义之间的恒等式。
:::hint
获得支付的MACD日期是$t = 1, 3, 5$。把这些日期与$R_t > 0$的日期比较。
:::
:::solution
增长因子是$101/102 \cdot 103/104 \cdot 106/107 = 551359/567528$，复合收益率为$-0.028490$，六位小数。多头或持币的一日符号规则在$R_t > 0$时做多，这在路径A上是奇数日期，而那些恰恰是玩具MACD做多的日期。共享的复合收益率是这条序列与这三个衰减的巧合。两个定义并不相同：一个看$\sgn(R_t)$，另一个看$M_t - S_t$。换一个$\lambda_{\mathrm{f}}$，未必在同一批交易日上触发。
:::
:::
