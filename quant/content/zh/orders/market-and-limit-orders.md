权重是净资产值的一个比例。它对头寸将以什么价格出现、甚至头寸是否会出现，一无所告。在权重与头寸之间坐着一张**订单**：一条把尚未走出的路径映射为一次成交、一次撤销或一次错过的消息。这个映射是研究定义的一部分。它不是预测；把它写下来，也不是把它发给经纪人的指令。

两条消息覆盖了本章里的日K线情形。**市价单**请求与已经挂着的流动性成交。在日K线上，订单簿并未被观察到，所以模拟器必须点名一个价格，假装那份流动性曾给出过它。**限价单**点名它所能接受的最差价格，只有当路径在那里交易时它才成交。第二条规则听起来谨慎。在日K线实际大多采用的那个约定之下，它同时也是乐观的，而这种乐观正是"看起来完美的胜率"的一个来源。

这一页上的任何内容，都不是买入、卖出或持有任何证券、基金或规则的建议。除某句话点名了路径A或库中某行之外，示例价格都是编造的。路径A的收盘价为\(100, 102, 101, 104, 103, 107, 106, 110\)。

## 订单是路径的函数

标注在\(t\)的信号可以使用截至\(t\)处决策为止的价格。它挣到的一切，都在\(t\)之后挣到。[[markets/prices-and-bars]]把一根K线的收盘价当作通常的决策价，[[trend/moving-averages]]则展示了把这些收盘价变成一个符号的一种办法。这两个对象都不是订单。一次移动平均交叉可以作为市价单发出去，可以作为限价单发出去，也可以因为限价从未被触及而根本不发出去。这些是不同的函数，而一个没有说明自己用了哪一个的回测，还没有把规则规定完。

:::definition 订单 {#def-order}
**订单**是从未来价格路径到一个结果的函数：在一个写明的价格与数量上成交、撤销、或错过。这个函数可以依赖一个限价、一个触发、一个数量与一个**有效期**（time in force），但只能通过模拟器事先声明的一个约定来依赖。在其K线结束时尚未成交的*当日*有效单成为一次撤销。一根K线上未成交的*撤销前有效*单是那次K线上的一次错过，并且继续挂着。订单不是权重，也不是预测。
:::

这三个结果在日常语言里很容易被混在一起。错过意味着路径没有产生交易，而这条消息仍然受它的有效期约束。撤销意味着这条消息已经死了，无论是因为它到期了，还是因为另一条消息杀了它。成交意味着一个价格与一个数量现在成了一个头寸。盈亏从成交价开始算，不是从决策价开始算——除非约定已把这两个价格强行捏成了同一个。

:::definition 市价单，日K线 {#def-market}
**市价单**请求立即与挂着的流动性成交。当订单簿可见时，市价买单付出**卖价**（最低的已挂卖出限价单），市价卖单收到**买价**（最高的已挂买入限价单）。**价差**是卖价减买价。日K线里不包含买价或卖价。在日K线上，模拟器必须点名成交价。本章允许三个点名过的时钟，不允许任何未点名的：下一根K线的开盘价、下一根K线的收盘价，或决策收盘价加上一个写明的滑点。按决策收盘价本身成交，使用的是决策已经看到过的价格；那是一个与\(t\)之后成交不同的实验，必须照此标注。
:::

滑点作为它自己的模型，以及把半个价差从每一笔市价成交里扣掉，是[[orders/fills-slippage-and-spread]]的工作。这里的"决策收盘加滑点"只意味着规格说明写下了一个数字。它若不写，本章就不替它发明一个。

:::definition 限价单与区间约定 {#def-limit}
设在\(\ell\)的**买入限价单**是一条以不劣于\(\ell\)的价格买入的指令。设在\(\ell\)的**卖出限价单**是一条以不劣于\(\ell\)的价格卖出的指令。在日K线上，**乐观区间约定**在\(\ell\)落在从该K线最低价\(L\)到最高价\(H\)的闭区间内时，按\(\ell\)成交任何一张，否则把那根K线记为一次错过。成交是全有或全无的：本章不把数量拆分到一个队列上。这个约定之所以乐观，是因为一笔在\(\ell\)上、排在队列末尾的打印，就被当作整张订单在\(\ell\)上成交。
:::

区间约定并不是一个人能写的唯一规则，也不是一张可成交限价单在可见订单簿上会做的事。倘若整根K线严格位于买入限价之下，每一笔打印都是比\(\ell\)更便宜的买入，但\(\ell\)本身不在\([L, H]\)里，所以区间约定记一次错过。一个*开盘可成交*（marketable-open）的替代约定，会在开盘价已经位于\(\ell\)或更低时按开盘价成交那张买单。除非某句话明说，我们不用那个替代。在一次回测里混用这两个而不说明，改变的就是函数本身。

:::quiz
一张买入限价挂在98。下一根K线最低99、最高103。在乐观区间约定下，这张订单在那根K线上会怎样？
- [ ] 在98成交，因为这根K线里的每一笔成交都比98的价格更好
- [x] 错过，因为98不在最低价与最高价之间
- [ ] 在99成交，即这根K线的最低价
- [ ] 变成市价单并在收盘价成交
:::solution
区间约定只在限价本身落在K线区间内时成交限价，并且按那个限价成交。这里98严格低于最低价，所以这根K线上的结果是一次错过。按最低价成交，或把一根更便宜的K线当作可成交来处理，会是另一个约定。
:::
:::

## 成交价允许是什么

区间约定附带一小段算术，而算术正是那个能从分母里制造出"胜"的地方。

:::proposition 从成交到收盘的收益率 {#prop-ftc}
设一根K线最低为\(L\)、最高为\(H\)、收盘为\(C\)，并设买入限价挂在\(\ell > 0\)。在乐观区间约定下，这张订单成交当且仅当\(L \le \ell \le H\)，且成交价为\(\ell\)。若它成交，从成交到该K线收盘的简单收益率为\(C/\ell - 1\)，当且仅当\(C > \ell\)时为正。另一张在\(\ell' < L\)的买入限价不成交，所以不贡献任何交易。因此，一个以成交笔数为分母的胜率，可以在这样一个样本上等于1：其中每一张*成交的*订单恰好都在高于其成交价的出场处计分，而每一次错过的订单在那个比率面前都不可见。
:::

:::proof
由[[#def-limit]]，\(\ell \in [L, H]\)是成交的充分必要条件，且那次成交的价格是\(\ell\)，不是\(C\)也不是\(L\)。从正价\(\ell\)到\(C\)的简单收益率按定义是\(C/\ell - 1\)，其符号就是\(C - \ell\)的符号。若\(\ell' < L\)，则\(\ell' \notin [L, H]\)，于是第二张订单在这根K线上错过。错过不是成交。任何除以成交笔数的统计量都把它从分子与分母里同时删掉。于是，一个所有成交出场都满足\(C > \ell\)——或在研究用于给交易计分的任何更晚价格上那个类似的比较成立——的样本，其按成交计的胜率为1，哪怕其他信号从未交易过。这个比率对错过的路径什么也不说，也不决定账簿的复合增长。
:::

这条命题并*没有*说每个限价回测的胜率都是1。在高于计分价格的\(\ell\)上成交是一笔亏损。命题说的是：一个被报告的比率1必然从哪里来——被允许进入分母的那个路径集合。那是一个成交假设。

:::algorithm 市价单的三个时钟 {#alg-market}
输入是决策收盘价、下一根K线的开盘价与收盘价，以及一个点名的约定。
1. 若约定是*下一开盘*，成交价为下一开盘价。
2. 若约定是*下一收盘*，成交价为下一收盘价。
3. 若约定是*决策收盘加滑点*，成交价为决策收盘价加上一个写明的买入滑点，或减去一个写明的卖出滑点。滑点可以为零，但零必须被写下来。
4. 若三个都没有点名，这个回测就没有规定成交。本章不提供默认值。
:::

同一根K线内、按决策收盘价的成交，不在名单上。它可以被当作一个坏掉的时钟来研究，[[backtesting/timing-costs-and-biases]]研究它的方式就是这样。它不是上面三个诚实的日频时钟之一，因为决策已经用过那个收盘价。

:::example 同一根K线上的两张限价单 {#ex-touch}
取一根编造的K线，最低99、最高103、收盘101。一张当日买入限价挂在100，另一张挂在98。应用区间约定。然后把收盘价换成99，保持同样的最低价与最高价，再给那张100的限价按成交到收盘计分。
:::solution
区间\([99, 103]\)包含100而不包含98。100的买入限价在100成交。98的买入限价错过。在第一个收盘价下，成交到收盘的简单收益率为\(101/100 - 1 = 0.01\)。

第二根K线上，区间仍包含100，所以限价仍在100成交。成交到收盘的简单收益率为\(99/100 - 1 = -0.01\)。触碰规则是一样的。收益率的符号是收盘减限价的符号，正如[[#prop-ftc]]所说。限价成交不自动是胜。
:::
:::

:::example 路径A上的三个时钟 {#ex-clocks}
一笔市价买入在路径A的收盘104处决策，头寸在路径A后来的收盘110处被清空。收盘103的那根K线是下一根K线。它的开盘、最高与最低不在路径A里；把它们取为105、105与102，使这根K线成为一根与那个收盘价相容的、可能的OHLC K线。计算三个时钟各自到110出场的简单收益率。第三个时钟取零滑点，并把它标注为一个同决策价的成交，而不是"下一收盘"。
:::solution
下一开盘在105成交。简单收益率为\(110/105 - 1 = 0.047619\)，按四舍五入取到六位小数（精确值是\(5/105\)）。

下一收盘在103成交。简单收益率为\(110/103 - 1 = 0.067961\)，六位小数。

决策收盘加零滑点在104成交。简单收益率为\(110/104 - 1 = 0.057692\)，六位小数。这个时钟使用的是决策已经看到过的价格。它不是下一收盘时钟，而在这条路径上，它甚至不是占便宜的那个：下一收盘是103，低于决策收盘，所以等到下一收盘反而*改善*了这笔买入。当规则声称在收盘处决策、然后交易时，同一根K线内成交仍然是一个错时钟。下一收盘收益率与下一开盘收益率之差是六位小数下的\(0.067961 - 0.047619 = 0.020342\)。一条写在规格说明里的话，在一条只从略高于100走到110的路径上挪动了大约两个百分点。
:::
:::

:::intuition 限价单选择路径，路径也选择限价单
低于市价的买入限价，是一个只在价格降下来时才交易的愿望。它成交的那些路径，不是信号为真的那些路径的一个随机样本。它们是曾在\(\ell\)交易过的那些路径。其中一些继续下跌，那就是[[#ex-touch]]第二根K线上的亏损。一些根本不降下来，那就是98上的错过。按成交计的胜率，在第一组恰好回升时留下它们，而把第二组删掉。这个删除就是那个成交假设。它不是这种资产的一个性质。
:::

:::example 卖出限价单用的是同一个区间 {#ex-sell}
一笔编造的多头更早以100成交入场。出场K线最低101、最高107、收盘104。一张当日卖出限价挂在106，另一张挂在108。应用区间约定，并在有出场成交时计算从入场成交到出场成交的简单收益率。
:::solution
区间\([101, 107]\)包含106而不包含108。106的卖出限价在106成交，从入场起的简单收益率为\(106/100 - 1 = 0.06\)。108的卖出限价错过；没有出场成交，也没有收益率可计分。相对按这根K线收盘104卖出，在106的成交每单位资产多收\(106 - 104 = 2\)个记账单位。这两单位的缺口就是那种乐观：约定假设整个出场都在106成交，因为最高价打印过107，而没有队列、没有部分成交。
:::
:::

:::example 胜率为1、增长平平的账户 {#ex-wins}
四条编造的当日订单信号各放出一张买入限价。三张成交，而按照我们即将给出的出场，每一笔成交的交易都是胜。第四条错过。给按成交与按信号的胜率计分、算盈亏比，以及一个从100起步、每次交易一单位的账户的现金路径计分。另外，记下从100到110的一次被错过的上涨。
:::solution
三次成交各以100买入一单位，又依次在102、在101、在103卖出。现金走\(100 \to 102 \to 103 \to 106\)。复合简单收益率为\(106/100 - 1 = 0.06\)。毛盈利为\(2 + 1 + 3 = 6\)。毛亏损为0，所以盈亏比——盈利除以亏损的绝对值——为无穷。按成交计的胜率为\(3/3 = 1\)。

第四条信号是一次错过，所以按信号计的胜率——把错过算作不胜——为\(3/4 = 0.75\)。被错过的路径是一根最低价100、收盘价110、而买入限价挂在99的K线。区间不包含99，所以区间约定什么也没买。一笔在100决策、在110清掉的下一收盘市价买入，简单收益率会是\(0.10\)，大于整个限价账户的\(0.06\)。那\(0.10\)没有一分进入限价账户的胜率。1这个胜率就是分母。我们选这三个出场都为胜，是为了让算术一目了然。它不是对任何已公布交易清单的重建。
:::
:::


图中第一根K线就是算过的那根：最低99、最高103、收盘101。拖动限价。在乐观区间约定下，这根K线成交当且仅当限价位于最低价与最高价之间，且成交价就是这个限价。100的限价成交。98的限价错过，因为98不在区间里。买入与卖出用的是同一个区间检验。

## 两个已报告的限价单回测

O03，Limit RSI Dip，是在RSI走弱时于收盘之下被动限价买入的例子，日K线，跨距$25$年。O04，Limit Trend Pullback，等待上升趋势中$1\%$的回调并以限价入场，同样是日K线，跨距$25$年。下面的数字是按quants.md对那些QuantJourney示例（Apache-2.0）的报告，按2026年的阅读。本图谱没有重跑过这些回测。它们不是预测，也不是建议。

O03报告总收益率$+94.66\%$、年化复合增长率$+2.70\%$、已报告夏普比率$0.14$、最大回撤$-19.09\%$、胜率$100\%$、盈亏比为无穷。无穷意味着被报告的毛亏损为零：在那个页面称之为"一笔交易"的任何单位上，一个亏损单位都没有被计入。胜率$100\%$是对分母的同一句话。这两个数字都没有说每条路径都赚了钱。净值路径仍然有一次$-19.09\%$的最大回撤，而年化复合增长率是$+2.70\%$，不是一幅稳赚的画面。$100\%$的胜率是那一次已报告回测的一个成交与记账事实。它不是好消息。

O04报告总收益率$+56.83\%$、年化复合增长率$+1.82\%$、已报告夏普比率$-0.04$、最大回撤$-6.85\%$、胜率$48.2\%$、盈亏比$1.36$。胜率不是$100\%$。一个不同的限价，另一行已报告的数据。我们没有核实过这两个夏普中的任何一个是如何年化的；两者都是"已报告的夏普比率"，而不是对该库使用了绩效各章那个均值除以标准差的约定的任何主张。一条为正的年化复合增长率挨着一个略微为负的已报告夏普，在一行已报告的数据里是允许的，它也不是一个待交易掉的谜。比较才是这一课的教训。一旦订单改变，就不存在什么"那个"RSI回落或"那个"回调，这两行也都没有偏爱某一种消息的理由。

$1\%$的回调只是一个距离。在一个编造的决策收盘100上，它会挂在99。那张限价是否成交，仍然是[[#def-limit]]里的那个问题，而O04那一行是某台已公布的引擎在$25$年里报告的东西，不是那根玩具K线。

:::warning 胜率为$100\%$
不要把O03的胜率读作这条规则不会亏钱的证据。盈亏比为无穷，因为被报告的亏损为零，而同样的这一行显示着$-19.09\%$的回撤和只有$+2.70\%$的年化复合增长率。[[#ex-wins]]故意搭了一个这种形状的小模型：每一笔成交都胜，被错过的上涨从不进入比率，而账户的增长平平。要问一次胜是什么、一次错过是否在分母里、回撤干了什么。绩效的定义在[[performance/win-rate-and-profit-factor]]。
:::

:::application 读那一行，而不是口号
三项检查能防止一个限价回测变成一句口号。第一，点名时钟：下一开盘、下一收盘，或决策价加一个写下的滑点，如[[#alg-market]]。第二，点名触碰规则，并说明一根从未打印出限价的K线是否仍可能因为穿过它而成交。第三，点名胜的单位。若单位是一笔成交的完整往返，那么错过就不是亏损，而接近1的胜率可以安坐在一个平平的年化复合增长率上。O03只在一个微弱的意义上通过检查而不只是口号：目录在讨好人的那些列旁边，把别扭的那些列也打印了出来。别扭的列是结果的一部分。
:::

:::remark 队列与部分成交
即便一根真正打印过\(\ell\)的K线，也可能只打印了它的一个单位，而且是在这张订单并未加入的队列的前面。区间约定仍然把整个数量在\(\ell\)上成交。这是第二种乐观，与[[orders/fills-slippage-and-spread]]着手处理的逆向选择相分别：不仅是一次触碰*是否*是公平样本，还有那次触碰*本可以带走多少*订单。一张大订单和一笔一手的示例不共享一个成交函数。本章的示例都是一单位的示例。
:::

:::quiz
对O03已报告的$100\%$胜率与无穷盈亏比，正确的读法是什么？
- [ ] 这条规则不会亏，所以回撤那一列一定是打印错误
- [ ] $+2.70\%$的年化复合增长率是对未来增长的预测
- [x] 在被报告的那个单位上没有亏损交易被计入，这是关于成交与记账的一个事实，不是净值路径不会下跌的证据
- [ ] 被动限价总在收盘之上成交，所以这个胜率是一个恒等式
:::solution
[[#prop-ftc]]与[[#ex-touch]]表明，一次限价成交从成交到收盘可以亏钱。O03的无穷盈亏比意味着被报告的毛亏损为零，而同样的这一行报告了$-19.09\%$的最大回撤与$+2.70\%$的年化复合增长率。这个完美的胜率既不是好消息，也不是预测。本图谱没有重跑过这个回测。
:::
:::

:::history
1985年，格洛斯坦（Lawrence Glosten）与米尔格罗姆（Paul Milgrom）把买卖价差建模为与可能消息更灵通的人交易所得到的补偿。在那个模型里，被动成交并不是对市价单的一次免费改进：对手方肯与那张挂着的限价单成交这件事，本身就是信息。[[#def-limit]]里的区间约定无视那种选择。只要K线的区间包含限价它就成交，仿佛那次触碰是一份礼物。
:::

## 通向何处

止损是下一条消息：它等待一个触发，然后变成市价单或限价单。那是[[orders/stops-and-stop-limits]]。半价差、一个线性成本，以及被动成交为何是一个被选出的样本，在[[orders/fills-slippage-and-spread]]。O03与O04上用到的胜率与盈亏比这两个词，作为统计量在[[performance/win-rate-and-profit-factor]]里定义；而让区间约定成为可能的那根K线，就是[[markets/prices-and-bars]]里的OHLC K线。

:::summary
- 订单是从未来路径到成交、撤销或错过的一个函数。它不是权重，也不是预测。
- 在日K线上，市价单需要一个点名的成交时钟：下一开盘、下一收盘，或决策收盘加一个写明的滑点。
- 乐观区间约定在限价落在K线最低价与最高价之间时按限价成交那张限价单，否则记一次错过。
- 按成交计的胜率会删掉每一次错过。它可以等于1，盈亏比可以为无穷，而账户的增长保持平平。
- O03报告$100\%$的胜率、无穷盈亏比、$+2.70\%$的年化复合增长率与$-19.09\%$的最大回撤。这个完美的胜率是一个成交假设，不是好消息。
- O04，一条不同的限价规则，报告$48.2\%$的胜率、$+1.82\%$的年化复合增长率、以及$-0.04$的已报告夏普比率。订单是结果的一部分。
- 这些库中数字是2026年为那些QuantJourney示例所报告的。本图谱没有重跑过它们，它们也不是建议。
:::

## 习题

:::exercise 触及与成交价 {level=1 check="100"}
一根编造的K线最低99、最高103。一张买入限价挂在100。在乐观区间约定下，成交价是什么？（输入成交价。）
:::solution
100位于99与103之间，所以这张订单成交，而区间约定按限价成交它。成交价是100。
:::
:::

:::exercise K线从未打印出的限价 {level=1 check="0"}
在同一根K线——最低99、最高103——上，一张买入限价挂在98。若这张订单在那根K线上错过请输入0，否则输入成交价。
:::solution
98严格低于最低价，所以98不在区间里。区间约定记一次错过。输入0。开盘可成交的约定若开盘低于98会做别的事；这道题不用那个约定。
:::
:::

:::exercise 从成交到收盘 {level=1 check="0.01"}
一张买入限价在100成交。这根K线收盘101。从成交到收盘的简单收益率是多少？（输入简单收益率。）
:::solution
\(101/100 - 1 = 0.01\)。收益率为正，因为收盘高于成交，这正是[[#prop-ftc]]里的符号检验。它不是挂出那张限价的建议。
:::
:::

:::exercise 路径A出场上的下一开盘 {level=2 check="0.047619"}
用[[#ex-clocks]]里的那笔市价买入。成交时钟是下一开盘，即编造价格105，出场是路径A的收盘110。按四舍五入取到六位小数的简单收益率是多少？（输入简单收益率。）
:::solution
\(110/105 - 1 = 1/21 = 0.047619047\ldots\)，六位小数是0.047619。决策收盘104不是成交。
:::
:::

:::exercise 时钟挪动了多少收益率 {level=2 check="0.020342"}
在同一个110出场处，下一收盘成交是路径A的103，下一开盘成交是105。在每个收益率各自四舍五入到六位小数之后，下一收盘的简单收益率比下一开盘的简单收益率大多少？（输入差。）
:::solution
下一收盘收益率为\(110/103 - 1 = 0.067961\)，六位小数。下一开盘收益率为0.047619。差是\(0.067961 - 0.047619 = 0.020342\)。是一个点名的时钟、而不是信号的变化，制造了那个缺口。
:::
:::

:::exercise 按信号计，而不只按成交计 {level=2 check="0.6"}
五个信号各放出一张买入限价。其中三张成交，而这三个成交各被计为一胜。另外两个错过。若错过算作不胜，按信号计的胜率是多少？（用小数输入胜率。）
:::solution
分母是那五个信号，不是三次成交。分子是那三胜。按信号计的胜率是\(3/5 = 0.6\)。按成交计的胜率会是\(3/3 = 1\)，那是另一个统计量，也是[[#ex-wins]]警告不要单独去读的那一个。
:::
:::

:::exercise 挂了三根K线的限价单 {level=3 check="0.07"}
一张撤销前有效的买入限价100在第一根K线之前挂出。第一根K线最低101、最高104、收盘103。第二根K线最低99、最高102、收盘101。第三根K线最低100、最高108、收盘107。区间约定生效，且较早K线上的成交不会被再次成交。从成交价到第三根K线收盘的简单收益率是多少？（输入简单收益率。）
:::hint
这张订单在第一根区间包含100的K线上按100成交，此后才有可以在第三根K线收盘上盯市的头寸。一根最低价为101的K线不包含100。
:::
:::solution
第一根K线最低101，所以100不在区间里。这张订单错过，并且因为是撤销前有效单而继续挂着。第二根K线的区间是\([99, 102]\)，包含100，所以这张订单在100成交。第三根K线在成交之后；它不制造第二次成交。从100到收盘107的简单收益率为\(107/100 - 1 = 0.07\)。

相对按第二根K线收盘价买入的现金差，是每单位\(101 - 100 = 1\)个记账单位。那一个单位是那次触碰的乐观，不是第二笔交易。收益率0.07已经把100的成交用作它的入场。
:::
:::

:::exercise 区间约定对开盘可成交约定 {level=3 check="97"}
一根编造的K线以97开盘，最高97.5、最低96、收盘96.5。一张买入限价挂在98。区间约定记录一个结果。一个替代的*开盘可成交*约定，在开盘价已经位于限价之下或恰在限价上时按开盘价成交买入限价。开盘可成交约定记录哪个成交价？（输入成交价。）
:::hint
问两个分开的问题。区间包含98吗？而开盘对于一张98的买入限价已经是合法价格吗？这道题要的是第二个约定的价格。
:::
:::solution
最高价是97.5，所以98不在\([96, 97.5]\)里。区间约定记一次错过，尽管这根K线里的每一笔打印都是比98更便宜的买入。这是故意的：区间约定要求限价本身在这根K线之内。

开盘可成交约定看到的是97的开盘，而\(97 \le 98\)，所以它按开盘成交。成交价是97。两个约定分歧整整一笔交易的大小：一个没有头寸，另一个以97持多。一个没有说出它用了哪个函数的规格说明，就没有把订单规定完。这个分歧不是去交易哪一个函数的理由。
:::
:::
