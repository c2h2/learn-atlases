一股股票的数量可以一次变动一股。一个标准外汇手数与一张期货合约却做不到：数量是跳变的，而跳变是订单的一部分。1.6张合约的目标，在一条取整规则把它映射为一个整数之前，还不是一张订单。4.54个标准手的目标，在同一种规则把它映射为整手之前，也不是一张订单。这个映射是从一个研究数量到一条场所网格愿意接受的消息的函数。它不是预测，也不是去交易货币、期货或任何其他工具的建议。

下面的价格都是编造的，除某句话点名了库内某行。一条连续期货序列并不是扛着近月合约穿越到期日的盈亏；那个区分属于[[markets/adjustment-universes-and-rolls]]与[[asset-classes/futures]]。本课止步于数量与日内K线。

## 美元报价货币对上的标准手

一个**美元报价**的货币对，其价格是以美元计的每单位基础货币。报价上涨，就是一单位基础货币的美元价值上涨。这个约定是报价约定，不是持有任何一种货币的建议。倘若美元是基础货币而不是报价货币，换算就会不同，而规格说明就得写明这一点。本节里每一个美元数字都假定报价货币是美元。

:::definition 标准手 {#def-lot}
一**标准手**是100,000单位基础货币。当报价按每单位基础货币变动\(\Delta q\)美元时，\(n\)标准手的美元盈亏为\(n \times 100{,}000 \times \Delta q\)。10,000单位基础货币的迷你手与1,000单位的微型手，是同一个公式配一个更小的块。本课的算例使用标准手。
:::

:::proposition 手数盈亏与简单收益率 {#prop-lot}
设报价从\(q_0 > 0\)变动到\(q_0 + \Delta q\)。一张标准手的美元盈亏为\(100{,}000 \times \Delta q\)。报价的简单收益率为\(\Delta q / q_0\)。该收益率等于美元盈亏除以起始美元名义额\(100{,}000 \times q_0\)。特别地，\(\Delta q = 0.0050\)给出每标准手500美元的盈利，无论\(q_0\)本来是多少。简单收益率仍然依赖\(q_0\)。
:::

:::proof
由报价约定，每个基础单位的美元价值变动\(\Delta q\)。一张标准手持有100,000单位基础货币，所以它的美元变动是\(100{,}000 \times \Delta q\)。当\(\Delta q = 0.0050\)时，那个乘积是\(100{,}000 \times 0.0050 = 500\)美元。起始名义额是那些基础单位在\(q_0\)处的美元价值，即\(100{,}000 \times q_0\)。用盈利除以那个名义额，100,000被约掉，剩下\(\Delta q / q_0\)，即报价的简单收益率。以美元计的盈利不需要\(q_0\)；收益率需要。对\(n\)的线性就是\(n\)手时的同一个乘积，因为每一手都是独立的一块100,000单位基础货币，而报价变动不依赖\(n\)。
:::

:::example 500美元，以及一个不是0.0050的收益率 {#ex-lot}
一张标准手，美元报价，从1.1000走到1.1050。计算美元盈利、起始名义额，以及取到六位小数的报价简单收益率。
:::solution
变动是\(\Delta q = 0.0050\)。由[[#prop-lot]]，美元盈利是500。起始名义额是\(100{,}000 \times 1.1000 = 110{,}000\)美元。简单收益率为\(0.0050 / 1.1000 = 0.004545\)，六位小数，而\(500 / 110{,}000\)是同一个比值。把这个变动说成"半个百分点"是错的：0.0050是在一个接近1的报价上每单位半分钱，约为1.1000的0.45%，不是0.50%。两张标准手在同一变动上会是\(2 \times 500 = 1{,}000\)美元。公式是线性的。这里没有任何东西说要持有这个货币对。
:::
:::

## 合约，然后是整数

期货盈亏对价格变动、对乘数、对合约张数都是线性的。张数必须是一个整数。若一张合约要求保证金，保证金是挂在头寸旁边的抵押品。它不是盈亏，也不会再从下面的盈亏公式里被扣掉一次。[[markets/instruments]]引入了乘数；本课把它当作算术来用。

:::definition 期货盈亏 {#def-fut}
\(n\)张合约在价格变动\(\Delta F\)上的盈亏——乘数\(M\)以每一点的记账单位计——为\(n \times M \times \Delta F\)。这里的\(n\)是一个整数。一个分数目标\(q\)还不是这个\(n\)。
:::

从一个正目标\(q\)出发的两个映射在下面被用到，而一条规格说明必须挑一个。**预算下取整**是\(n = \lfloor q \rfloor\)，即不超过\(q\)的最大整数，于是这张订单永远不会拿比目标更多的合约。**最近整数**取最接近的整数；在\(q = k + 1/2\)的平局上（\(k\)为整数），朝远离零的方向取整。对目标1.6没有平局：到1的距离是0.6，到2的距离是0.4，所以最近整数是2，而下取整是1。

:::proposition 取整把盈亏按\(n/q\)缩放 {#prop-ratio}
设\(M \Delta F \ne 0\)，设\(q > 0\)是一个分数目标，而\(n\)是一条写明规则返回的整数。\(n\)张合约的盈亏除以分数目标的盈亏是\(n/q\)。对\(q = 1.6\)，下取整实现分数盈利的\(1/1.6 = 0.625\)，最近整数实现它的\(2/1.6 = 1.25\)。在\(M = 50\)与\(\Delta F = 10\)下，分数盈亏是800，下取整盈亏是500，最近整数盈亏是1,000，全部以记账单位计。
:::

:::proof
由[[#def-fut]]，分数表达式\(q \times M \times \Delta F\)与整数表达式\(n \times M \times \Delta F\)共享因子\(M \Delta F\)，它不为零。它们的比是\(n/q\)。1.6的下取整是1而最近整数是2，所以两个比是\(1/1.6 = 0.625\)与\(2/1.6 = 1.25\)。代入\(M = 50\)与\(\Delta F = 10\)：公共因子\(M \Delta F\)是500，而\(1.6 \times 500 = 800\)、\(1 \times 500 = 500\)、\(2 \times 500 = 1{,}000\)。\(\Delta F\)的符号会把三者按同样的方式缩放。这个比例没有说一项研究应当采纳哪条取整规则。它说的是：那条规则是盈亏上的一个缩放因子，不是一处装饰性的打印。
:::

到达1.6的一种方式——编造的，不是一项政策——是一个波动率预算。设乘数为50，并设期货价格的编造日标准差为20点。一张合约的美元式波动率是\(50 \times 20 = 1{,}000\)记账单位。一个1,600的预算于是要求\(1{,}600 / 1{,}000 = 1.6\)张合约，而上一段把1.6变成1或2。同一个预算的股票版本更温和，因为网格是一股。在价格100、日简单收益率波动率0.01之下，一股的波动率是\(100 \times 0.01 = 1\)记账单位。同样1,600的预算要求1,600股，已经是一个整数。一个1,600.8股的目标会下取整到1,600，丢掉0.8的预算。外汇网格是那个严厉的情形，下面紧接着算。

:::example 两张合约，以及还不是订单的1.6 {#ex-round}
一个编造的期货价格从4,000走到4,010，所以\(\Delta F = 10\)。乘数是50。计算2张合约的盈亏。然后对同一变动上1.6张合约的目标应用两条取整规则，记下三个盈亏：分数、下取整与最近整数。
:::solution
两张合约做出\(2 \times 50 \times 10 = 1{,}000\)记账单位。那就是手里已经有一个整数的[[#def-fut]]。

分数目标做出\(1.6 \times 50 \times 10 = 800\)。预算下取整拿1张合约，做出\(1 \times 500 = 500\)，即\(0.625 \times 800\)。最近整数拿2，做出1,000，即\(1.25 \times 800\)。真正能成为一条消息的订单是那个500或那个1,000，不是那个800。若1.6来自上面的预算，选下取整使波动率预算不被超出。选最近整数则超出它。两者都是合法的规格说明。两者都不是交易这张合约的建议，而乘数50是一个算术选择，不是一只上市产品。
:::
:::

:::example 半本账簿，还不是整数手 {#ex-weight}
净资产值为1,000,000美元。一个美元报价货币对在1.1000处的目标权重是0.5。把权重换算成标准手，然后应用下取整与最近整数。报告名义额与权重。
:::solution
目标美元名义额是\(0.5 \times 1{,}000{,}000 = 500{,}000\)。基础货币单位数是\(500{,}000 / 1.1000 = 5{,}000{,}000/11 = 454{,}545.\overline{45}\)。标准手是那个数量除以100,000，即\(50/11 = 4.\overline{54}\)。

下取整是4手。名义额\(4 \times 100{,}000 \times 1.1000 = 440{,}000\)美元。权重是\(440{,}000 / 1{,}000{,}000 = 0.44\)，比目标少0.06，即60,000美元没有发出去的名义额。

最近整数是5，因为\(4.545\ldots\)离5比离4更近。名义额\(5 \times 110{,}000 = 550{,}000\)美元。权重是0.55，超出目标0.05，即50,000美元。在股票草算里丢掉0.8股的那个下取整，在这里丢掉60,000美元。整手不是权重的一个次要打印。O19是开放库的整手案例；它的那一行在下面被引用，而它是负的。
:::
:::

第二个编造的预算，是为手准备的，不是为合约准备的：日报价波动率0.0060使一张标准手变动\(100{,}000 \times 0.0060 = 600\)美元。一笔1,600美元的这种波动率预算要求\(1{,}600 / 600 = 8/3 = 2.\overline{6}\)手。下取整是2，最近整数是3。由[[#prop-ratio]]，在任何后来的变动上，它们分别实现分数盈利的\(2/(8/3) = 0.75\)与\(3/(8/3) = 1.125\)。0.0060是编造的。它不是一个测出来的外汇波动率，也不是一个该发出去的大小。

## 日历上偏短的K线

一根5分钟K线仍然是一根OHLC K线。许多路径共享它，正如许多路径共享一根日K线。止损可能在一根K线内部被触碰，而收盘价并不显示那次触碰，所以区间约定与跳空约定仍然有活要干。变的是交易时段与样本的长度。本课的日内约定，在时段结束而一张挂着的订单仍未成交时撤销它。过夜持有会是另一个函数。

用390分钟的时段来计数，那是一个6.5小时现金股票交易日的长度，只当作一种计数约定来使用。一个时段容纳\(390/5 = 78\)根5分钟K线，以及\(390/30 = 13\)根30分钟K线。四个星期、每周五个时段是20个时段与\(20 \times 78 = 1{,}560\)根5分钟K线。八个星期是40个时段与\(40 \times 13 = 520\)根30分钟K线。K线根数不是独立天数。二十个工作日时段就是二十天，或者——若某个参数是在同样的那些天里选出来的——更少。

:::proposition 一个空白的年化复合增长率不是零，也不该由你去填 {#prop-nocagr}
在跨多年的库内行里，年化复合增长率是\((V_T / V_0)^{1/Y} - 1\)，跨距\(Y\)以年计，而开放库只在它报告了一个的时候才打印一个。打印成—的一格是未报告。它不是零。把一个单一的短跨距收益率抬到\(52/W\)次幂——\(W\)为以周计的跨距——制造的是一个数字，不是一个策略的年化复合增长率。特别地，一个编造的四周年简单收益率0.01——它不是O15所报告的收益率——满足\((1.01)^{13} - 1 = 0.138\)，三位小数，而那个0.138不是本图谱将要引用的一个增长率。
:::

:::proof
指数\(52/4 = 13\)只有在假设那个四周收益率独立同分布地重复十三次时，才把四个星期换算成一年。一个观察到的四周窗口就是一个窗口。乘方造不出另外十二个。开放库自己那些跨多年的行覆盖7、16或25年，并在它们有一个年化复合增长率的时候打印它。O15的跨距是四个星期，它的年化复合增长率那一格是—。O16的跨距是八个星期，那一格也是—。按刚刚给出的定义，那些空白保持空白。数值\((1.01)^{13} - 1 = 0.138093\ldots\)，按四舍五入取到三位小数，是0.138。它是从一个编造的0.01算出来的，好让没有人会把它误认作O15那个+1.1%的年化。我们根本不计算那个年化。
:::

:::example 四个星期能教什么，不能教什么 {#ex-intra}
在上面的约定下数四个星期里的5分钟K线。然后把O15写明的括号单距离+0.6%与−0.4%，放在一个编造的100入场处，计算两个干净的出场价格。不要把O15或O16年化。
:::solution
四个星期，每周五个时段，每时段78根K线：\(4 \times 5 \times 78 = 1{,}560\)根K线，而只有20个时段。K线根数是网格的一个描述。它不是一个年化复合增长率的样本量。

O15的一行式描述是一个RSI回落，配一张在+0.6%与−0.4%的括号单，5分钟K线，四个星期。在100的入场上，那些距离坐在100.6与99.6。[[orders/trailing-brackets-and-oco]]里括号单命题的那些干净路径，施加在这些距离上，当获利价是K线里唯一的价格时返回\(+0.006\)，当止损价是唯一的价格时返回\(-0.004\)。那是那条消息的形状。它不是O15的交易清单。O15报告总收益率+1.1%、最大回撤−1.3%。年化复合增长率、夏普比率、胜率与盈亏比都是—。开放库没有报告它们，而四个星期支撑不起一个年化复合增长率。

O16是一张挂在12根K线高点之上的买入止损单，带一个固定持有期，30分钟K线，八个星期。它报告总收益率−13.9%、最大回撤−14.8%。其他格子都是—。八个星期同样支撑不起一个年化复合增长率。收益率为负。我们不取对面，也不在"固定持有期"这几个字之外发明持有期的长度。在每一根30分钟K线内部，买入止损仍然是上一课的那个止损：一个穿过12根K线高点的开盘，在跳空约定下按开盘成交。这根K线的收盘价不是那个检验的替身。
:::
:::

O19，FX Momentum Lots，是美元报价现货货币对上考虑合约的整手动量，日K线，跨距$16$年。按quants.md对那些QuantJourney示例（Apache-2.0）的报告，按2026年的阅读，总收益率为−14.2%，年化复合增长率为−0.95%，已报告夏普比率为−0.71，最大回撤为−15.3%。胜率与盈亏比是—。开放库没有报告它们。本图谱没有重跑过这个回测。那些数字不是预测，也不是建议。那一行为负，是一条整手规则公布的结果。它不是把符号取反的理由。外汇作为工具类别的更多细节在[[asset-classes/foreign-exchange]]；数量约定才是本课刚刚算过的东西。

O20，Futures Donchian Contracts，是在一个数据商的连续期货上按整张合约计规模，日K线，跨距$7$年。同样的署名适用。它报告总收益率+35.5%、年化复合增长率+4.67%、已报告夏普比率0.30、最大回撤−16.7%、胜率48.0%、盈亏比1.34。这里的开放库确实报告了一个年化复合增长率，而它写明的跨距是$7$年。七年不会因为一个年化复合增长率打印得出来，就变成一个长样本。一行式描述提到了ATR规模；我们不重新推导那条规模规则，也不把连续序列当作一份被持有的合约。移仓留在[[asset-classes/futures]]。一个为正的已报告夏普不是交易期货的建议。与O19并排，这一对只说：整单位是两个不同实验的一部分，一个跨$16$年被报告为负，另一个跨$7$年被报告为正。

:::warning 不要把四个星期年化
O15的年化复合增长率那一格是—。O16的那一格也是—。[[#prop-nocagr]]就是那些空白保持空白的理由，其中也包括那个编造的幂\((1.01)^{13} - 1 \approx 0.138\)——它是一个计算器在一个编造的1%上的输出，仍然不是一个年化复合增长率。一张1,560根K线的图感觉很长。它是二十个时段。
:::

:::history
1996年上线的Island ECN，是把美股交易搬离交易大厅的那批电子限价单市场之一，它让公开的订单簿成了模拟器必须模仿的对象。在那种订单簿上，数量可以是一股。一个标准手与一张期货合约是更粗的网格：那条消息以100,000单位基础货币、或以一张合约为跳变，无论一个分数目标本来会不会是权重的一次更清楚的表达。Island是一个股票场所。这个比较只关于网格。日内股票K线——包括那些短的库内样本——把这样一本订单簿压缩成OHLC，然后把订单簿扔掉。
:::

## 通向何处

成交仍然要付价差，以及写进规格说明的任何滑点。那是[[orders/fills-slippage-and-spread]]。作为资产类别假说的外汇——包括把为负的已公布动量结果当作结果来读——继续在[[asset-classes/foreign-exchange]]里讲。期货、移仓与连续序列在[[asset-classes/futures]]。为什么几个星期的细K线扛不起一个绩效比率，在[[backtesting/intraday-samples]]里再次被提起。

:::summary
- 一张标准手是100,000单位基础货币。在美元报价货币对上，0.0050的变动是每标准手500美元。简单收益率仍然除以起始报价。
- 期货盈亏是合约张数乘乘数乘价格变动。保证金是抵押品，不是那个盈亏。
- 1.6张合约的目标下取整为1或取整为2。在乘数50与10点的变动下，盈亏是500或1,000，对照分数的800。
- 同一个下取整，作用在1,000,000美元的一半权重、报价1.1000上，发出4手而不是\(50/11\)，名义额缺口60,000美元。
- O19报告跨$16$年的收益率−14.2%、年化复合增长率−0.95%、已报告夏普比率−0.71。O20报告跨$7$年的年化复合增长率+4.67%、已报告夏普比率0.30。两行都不是建议。
- O15，四个星期的5分钟K线，报告+1.1%与−1.3%的回撤，没有年化复合增长率。O16，八个星期的30分钟K线，报告−13.9%与−14.8%的回撤，没有年化复合增长率。
- 那些空白是未报告，不是零。一个短样本支撑不起一个年化复合增长率。那些数字是2026年所报告的；本图谱没有重跑过它们。
:::

## 习题

:::exercise 一手，一次变动 {level=1 check="500"}
一个美元报价货币对变动0.0050。一张标准手的美元盈利是什么？（输入美元数。）
:::solution
\(100{,}000 \times 0.0050 = 500\)。美元盈利不需要起始报价。
:::
:::

:::exercise 两手 {level=1 check="1000"}
同样的0.0050的变动。两张标准手的美元盈利是什么？（输入美元数。）
:::solution
盈利对手数是线性的：\(2 \times 500 = 1000\)美元。
:::
:::

:::exercise 三张合约 {level=1 check="600"}
三张期货合约，乘数50，价格变动\(\Delta F = 4\)。以记账单位计的盈亏是什么？（输入盈亏。）
:::solution
\(3 \times 50 \times 4 = 600\)。乘数是一个算术输入，不是一张点名的上市合约。
:::
:::

:::exercise 1.6的下取整 {level=2 check="1"}
一个波动率预算产生1.6张合约的目标。规则是预算下取整。订购多少张合约？（输入整数。）
:::solution
不超过1.6的最大整数是1。订单是1张合约，不是1.6，也不是2。
:::
:::

:::exercise 1.6的最近整数 {level=2 check="2"}
同样的目标，1.6张合约，在最近整数规则之下。订购多少张合约？（输入整数。）
:::solution
从1.6到2的距离是0.4，到1的距离是0.6。最近整数是2。没有半个整数处的平局需要裁决。
:::
:::

:::exercise 报价的简单收益率 {level=2 check="0.004545"}
报价从1.1000走到1.1050。按四舍五入取到六位小数的简单收益率是什么？（输入简单收益率。）
:::solution
\(\Delta q = 0.0050\)而\(q_0 = 1.1000\)，所以简单收益率是\(0.0050/1.1000 = 0.00454545\ldots\)，六位小数是0.004545。一张标准手的美元盈利仍是500。收益率不是0.0050。
:::
:::

:::exercise 最近整数手实际拥有的权重 {level=3 check="0.04"}
净资产值为1,000,000美元。报价为每单位基础货币1.0000美元。目标权重是0.36。把由此产生的标准手数取整到最近整数，并报告那个整数所产生的权重的绝对误差。（输入绝对误差。）
:::hint
在报价为1时，美元名义额与基础货币单位数重合。手数是名义额除以100,000。取整之后，把整数手数换算回权重，再减去目标。
:::
:::solution
目标名义额是\(0.36 \times 1{,}000{,}000 = 360{,}000\)美元。在报价1.0000下那是360,000单位基础货币，于是\(360{,}000 / 100{,}000 = 3.6\)标准手。最近整数是4。4手的名义额为\(4 \times 100{,}000 \times 1 = 400{,}000\)美元，权重为\(400{,}000 / 1{,}000{,}000 = 0.40\)。绝对误差是\(|0.40 - 0.36| = 0.04\)。

下取整本来会发出3手，权重0.30，绝对误差0.06。题目问的是最近规则。选报价1，是为了让网格、而不是一次别扭的除法，成为整道题。它不是市场。
:::
:::

:::exercise 先对合约数下取整，再去缩放亏损 {level=3 check="-200"}
目标是2.4张合约。乘数是20。期货价格变动\(\Delta F = -5\)。规则是预算下取整。取整后的头寸做出多少盈亏，以记账单位计？（输入盈亏，带符号。）
:::hint
下取整不会超出目标。然后把整数、乘数与\(\Delta F\)相乘，保留那个负号。分数盈亏是一个比较，不是答案。
:::
:::solution
2.4的下取整是2。最近整数也是2，因为2.4离2比离3更近，但题目问的是下取整，无论如何都是2。盈亏是\(2 \times 20 \times (-5) = -200\)。

分数目标本来会做出\(2.4 \times 20 \times (-5) = -240\)。下取整实现那笔亏损的\(-200 / -240 = 5/6\)，即\(2/2.4\)，也就是[[#prop-ratio]]里的那个比例。取整没有消掉亏损。它缩放了亏损。那个负号是价格变动，不是一个做空或做多的建议。
:::
:::
