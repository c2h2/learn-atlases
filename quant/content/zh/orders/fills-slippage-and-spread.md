两台模拟器可以点名同一张订单，却记下不同的成交。一台付出卖价。一台按中间价成交。一台只要K线区间包含限价，就成交一张被动限价单，然后只在成交了的那些路径上计一胜。这两本账簿之间的缺口就是本课的主题：半价差、一个线性滑点率，以及被动成交里内置的那种选择。订单仍然是一个从未来路径到一次成交、一次撤销或一次错过的函数。给成交加一个成本，没有把这个函数变成建议，也没有说怎样把一张实盘订单路由给经纪人。回测的账簿不是一个经纪人。

O03那个已报告的100%胜率在这里回来了，作为一条关于成交的事实，不是一个值得欣赏的结果，也不是对限价单的一次完整重述。现在付冲击与等待之间的权衡，来自2001年的阿尔格伦（Robert Almgren）与克里斯（Neil Chriss），只作陈述，不作推导。示意价格是编造的。库内数字一旦出现就注明出处。

## 用算术写下来的半价差

当一簿订单簿可见时，**中间价**是买价与卖价的平均。**半价差**是卖价减买价的一半。市价买单吃掉卖价，即中间价加上半价差。市价卖单打到买价，即中间价减去半价差。在本课通篇使用的数字上，中间价是100，半价差是0.01，于是买价是99.99、卖价是100.01。每单位一分钱，就是跨越的那笔单边成本。一根日K线不打印买价或卖价。想要这个成本的规格说明，必须亲手把它加回去。

:::definition 一次成交的执行缺口 {#def-shortfall}
设\(D\)是决策价，常常是决策时的中间价，设\(F\)是成交价。对一笔买入，每单位的**执行缺口**（implementation shortfall）是\(F - D\)。对一笔卖出，它是\(D - F\)。为正的缺口意味着成交劣于决策价。一次错过没有成交，因而也没有缺口；它有的是一次胜率眼看就要忽略掉的机会。
:::

:::definition 线性成本 {#def-linear}
费率为\(c \ge 0\)的单边**线性成本**，在那条边上收取成交名义额的\(c\)倍，以记账单位计。一笔买入名义额\(N\)、卖出名义额\(N\)的完整往返，收费约为\(2cN\)，当两条边都按同一个\(N\)收费时恰好是\(2cN\)。规格说明必须写明\(c\)是已经包含了半价差，还是叠在它之上。默默地把两个都用上，就是把价差重复计算了。
:::

在中间价\(m = 100\)、半价差\(h = 0.01\)下，与中间价名义额上的半价差相匹配的费率是\(c = h/m = 0.0001\)。于是\(c \times m = 0.01\)，就是那一分钱。这个\(c\)是把价差翻译成名义额的一个分数。它不是一个测出来的冲击系数。

:::proposition 中间价不动时的完整往返 {#prop-rt}
设中间价\(m > 0\)不动，半价差是满足\(0 \le h < m\)的常数\(h\)，一笔市价买入之后跟一笔市价卖出一单位。买入在\(m+h\)成交，卖出在\(m-h\)成交。现金亏损是\(2h\)。以买入价为基的简单收益率为
\[
\frac{m-h}{m+h} - 1 = -\frac{2h}{m+h}.
\]
在\(m = 100\)与\(h = 0.01\)下，现金亏损是0.02，简单收益率等于\(-0.000200\)，六位小数。
:::

:::proof
付出现金\(m+h\)，收回现金\(m-h\)，所以变动是\((m-h) - (m+h) = -2h\)。以付出现金为基的简单收益率是\((m-h)/(m+h) - 1\)。那个差分的分子是\((m-h) - (m+h) = -2h\)，分母是\(m+h\)，这就是所展示的恒等式。代入\(m = 100\)与\(h = 0.01\)：现金亏损是\(0.02\)，收益率是\(-0.02/100.01 = -0.00019998\ldots\)。按四舍五入取到六位小数，那是\(-0.000200\)。

线性费率\(c = h/m\)，若每条边都按它自己的成交名义额收费，则收取\(c(m+h) + c(m-h) = 2cm = 2h\)，同样是那0.02。在中间价名义额上收两遍\(c\)，也还是\(2cm = 2h\)。简单收益率并不恰好是\(-2c\)。这里\(-2c = -0.0002\)，而\(-2h/(m+h)\)在幅度上还要小一丝，因为收益率除以的是卖价，不是中间价。两个模型在现金亏损上一致，在收益率的第六位小数上不一致。规格说明应当写明它在复利哪一个。
:::

:::algorithm 账簿被允许扣掉什么 {#alg-fill}
这是一本回测的账簿，不是一张通往经纪人的路由表。
1. 点名决策价\(D\)。在本课它是中间价。
2. 若这张订单是市价买单、成本模型是半价差，成交价为\(D + h\)，再加上规格说明以价格单位写明的任何额外滑点。市价卖单在\(D - h\)成交，减去那份额外滑点。
3. 若成本模型只有线性费率\(c\)，且\(c\)被声明为*包含*价差，就不要再往成交价上加\(h\)。每条边收取一次\(c\)倍名义额。
4. 若一张被动限价单在[[orders/market-and-limit-orders]]的区间约定下成交，成交价就是那个限价。不要再扣一次\(h\)。限价本来就是成交。逆向选择不是靠对成交再征一道税来修复的；它是靠说出哪些路径成交了来报告的。
5. 若正文没有说\(c\)是否包含\(h\)，成本模型就没有写完。不要猜。
:::

:::example 一边一分钱 {#ex-rt}
中间价100，半价差0.01，中间价不动。市价买入一单位，再市价卖回。计算两个成交价格、现金亏损，以及取到六位小数的简单收益率。
:::solution
买入在\(100 + 0.01 = 100.01\)成交。卖出在\(100 - 0.01 = 99.99\)成交。付出现金100.01，收回现金99.99，亏损\(0.02\)，即一边一分钱。由[[#prop-rt]]，简单收益率是\(-0.02/100.01 = -0.00019998\ldots\)，即六位小数的\(-0.000200\)。买入的执行缺口是\(100.01 - 100 = 0.01\)。卖出的执行缺口是\(100 - 99.99 = 0.01\)。完整往返的缺口是两者之和，0.02，因为中间价没有动，没有贡献它自己的任何一分。一张挂在100、并在那里成交的买入限价单，对这个中间价的缺口为零，却仍然暴露于下一节的那个选择之下。缺口为零不是免费午餐。
:::
:::

## 一个会重复的成本

一笔占净资产值\(0.0002\)分数的完整往返，看起来无足轻重。一个每个交易时段都来一笔的账簿，是在每个时段乘一次一个略低于1的数。一旦那句话说明白了"两次"指的是两条单边腿还是两次完整往返，那个乘积就是"一天交易两次"的全部内容。

:::proposition 成本连乘 {#prop-cost}
设一个账簿从净资产值\(V_0\)起步。在第\(t\)天，中间价的变动在费前把价值乘以毛因子\(G_t > 0\)，随后一次完整往返成本把结果乘以常数因子\(1-\delta\)，其中\(0 \le \delta < 1\)。\(T\)天之后
\[
V_T = V_0 \Bigl(\prod_{t=1}^{T} G_t\Bigr) (1-\delta)^T.
\]
若每个中间价变动都是零，则\(G_t = 1\)且\(V_T = V_0 (1-\delta)^T\)。毛简单收益率为\(g\)——于是\(G = 1+g\)——的一天的净简单收益率为\((1+g)(1-\delta) - 1 = g - \delta - g\delta\)。
:::

:::proof
由假设中的那两次乘法按那个顺序施行，一天之后\(V_1 = V_0 G_1 (1-\delta)\)。设公式到第\(T-1\)天成立。第\(T\)天乘以\(G_T(1-\delta)\)。因子\(1-\delta\)不依赖\(t\)，所以它们归拢成\((1-\delta)^T\)，毛因子归拢成连乘。若每个\(t\)都有\(G_t = 1\)，那个乘积就是1。一天的那个恒等式只是展开：\((1+g)(1-\delta) - 1 = 1 + g - \delta - g\delta - 1\)。当\(g = 0\)时，净简单收益率为\(-\delta\)，没有交叉项。交叉项\(g\delta\)正是那个马虎的"从年化复合增长率里减去\(c\)"只是近似的原因。上面的连乘才是这个模型的精确账簿。
:::

取\(\delta = 2c = 0.0002\)——它是\(c = 0.0001\)时的线性完整往返——以及中间价不动的\(T = 252\)个交易时段。于是\(100 \times (1-0.0002)^{252} = 95.0844\ldots\)，按四舍五入取到分为95.08。那就是一天一次完整往返的全账簿版本：两条单边交易，若每笔交易都是一次跨越，那是"一天交易两次"的自然读法。它是一个编造的成本安排，不是某个市场测出来的拖累。

:::example 252个不动的中间价 {#ex-year}
从净资产值100起步。中间价停在100，半价差停在0.01。用精确的价差因子\(99.99/100.01\)，对252个交易时段复利每个时段一笔市价完整往返。与线性近似\((1-0.0002)^{252}\)比较。然后说明，若"一天两次"被误读成两次完整往返，什么会变。
:::solution
一次完整往返把价值乘以\(99.99/100.01\)。从100起步，第一个时段收盘在\(100 \times 99.99/100.01 = 99.980002\)，六位小数。第二个时段收盘在99.960008，六位小数。252个时段之后，乘积是\(100 \times (99.99/100.01)^{252} = 95.0849\ldots\)，按四舍五入取到分为95.08。

线性因子\((1-0.0002)^{252} \times 100 = 95.0844\ldots\)，取到分同样是95.08。两步费率相差约\(2 \times 10^{-8}\)，那是拿\(2h/(m+h)\)去对\(2c\)。它们在一年的交易时段上于分的位上一致，却不是同一个函数。一篇论文复利其中一个、报告另一个，改动了一日收益率的第六位小数，而在252天里，改动的仍然只是初始100之下不足一分的尘土。账簿更大，尘土也按比例放大。规格说明点名因子。

一个时段两次完整往返是四条单边腿。线性的每日分数是\(4 \times 0.0001 = 0.0004\)。在价差模型下，平方因子的252时段乘积从100起步，收在分位的90.41。不定义"一笔交易"的"一天交易两次"，在这条编造的、平坦的中间价路径上，就是95.08与90.41的差别。两个数字都不是预测。
:::
:::

用widget里那本编造的账簿，净\(= 0.05 - 0.001\,\tau\)，其中\(\tau\)是以净资产值倍数计的年单边换手，而0.001是一个编造的单边成本，是那个与中间价100上一分钱半价差相匹配的0.0001的十倍。在\(\tau = 10\)、\(\tau = 50\)、以及\(\tau = 504\)处计算净值——后者是252个时段、每个时段两笔单边交易。

换手10处，净值为\(0.05 - 0.001 \times 10 = 0.04\)。换手50处为\(0.05 - 0.05 = 0\)。换手504处为\(0.05 - 0.001 \times 504 = 0.05 - 0.504 = -0.454\)。50处的那个零就是图中的交点。那个\(-0.454\)说的是：把一分钱的故事讲成十倍大的成本，摆在一个全年每个时段跨越两次的账簿上，花掉的比编造的毛值还多。0.05、0.001与\(-0.454\)，没有一个是什么库内统计量。它们是一幅关于减法的图画，不是一份已公布的回测。

## 成交是一个被选出的样本

一张被动买单在有卖家按那个限价成交时才成交。那些K线并不是信号为真的那些K线的一个随机子集。格洛斯坦（Lawrence Glosten）与米尔格罗姆（Paul Milgrom）1985年对价差的解释——[[orders/market-and-limit-orders]]的那条历史注记——就是把同一种选择讲在一本可见的订单簿上：价差是对"对面可能更知情"这件事的补偿。日K线的区间约定无视那份补偿，却仍然保留着那个选择，因为它只在触到了限价的K线上成交。

:::example 五个下期收益率，其中两个成交 {#ex-adv}
五个编造的信号各挂出一张买入限价。下一根K线的简单收益率依次为\(0.02\)、\(0.01\)、\(-0.03\)、\(-0.01\)与\(0.04\)。限价只在第三根与第四根上成交。计算五个收益率的无条件均值、成交上的均值，以及错过上的均值。
:::solution
五个收益率之和是\(0.02 + 0.01 - 0.03 - 0.01 + 0.04 = 0.03\)，所以无条件均值是\(0.03/5 = 0.006\)。

成交了的收益率是\(-0.03\)与\(-0.01\)。它们的均值是\(-0.04/2 = -0.02\)。

错过的收益率是\(0.02\)、\(0.01\)与\(0.04\)。它们的和是\(0.07\)，均值是\(0.07/3 = 0.023333\ldots\)。

成交了的路径是那些跌下去的路径。错过了的路径是那些涨上去的路径。一个只在成交上计算的胜率，永远看不见\(0.02\)、\(0.01\)或\(0.04\)。若在此之上，研究的出场规则碰巧把每一笔成交都记成了一胜，那么成交上的胜率将是1，而这个玩具里成交上的下期平均收益率是\(-0.02\)。这个玩具的出场没有规定到下一根K线之外，所以胜率在这里甚至谈不上有定义；条件均值有。选择不需要一个戏剧性的故事。它只需要一个把错过删掉的分母。
:::
:::

O03，Limit RSI Dip，是RSI走弱时的被动限价买入，日K线，跨距$25$年。按quants.md对那些QuantJourney示例（Apache-2.0）的报告，按2026年的阅读，总收益率为+94.66%，年化复合增长率为+2.70%，已报告夏普比率为0.14，最大回撤为−19.09%，胜率为100%，盈亏比为无穷。本图谱没有重跑过这个回测。那些数字不是预测，也不是建议。

盈亏比为无穷，意味着已报告的毛亏损为零。胜率100%是对同一个分母的那句话。[[#ex-adv]]不是对O03那些交易的重建；它是一个成交过滤器的形状。乐观区间约定在K线触到限价时成交那张限价，而一个只保留成交的胜统计量，删掉了市场从未降下来光顾过的每一张信号。O03的净值路径仍然显示一次−19.09%的最大回撤，年化复合增长率是+2.70%，不是一条不会亏的规则的画面。100%的胜率是一个成交假设。它不是好消息。

一张在决策中间价之下成交的限价，由[[#def-shortfall]]，缺口为负，其后仍然可能跟着[[#ex-adv]]里的那些负收益率。把那样的缺口记成优势，又不去管哪些K线成交了，就是重演那份礼物。[[#alg-fill]]已经禁止把半价差扣第二次。

:::warning 同时两份礼物
只要K线包含那个限价，区间约定就在那个限价上成交一张被动限价单。一个成本模型若随后还把那笔成交当作赚到了半价差来处理——没有错过的K线，也没有选择——就是连递了两份礼物给这个回测。O03的100%胜率与无穷盈亏比，挨着一个−19.09%的回撤与一个+2.70%的年化复合增长率，正是一个慷慨的分母在汇总列里长成的样子。不要把\(h\)叠在一个已经包含\(h\)的\(c\)上。不要把胜率读成增长率。
:::

:::intuition 你遇到的是想要对面的那股东单流
一张挂着的买单，是在有人卖出时被人打到的。在那个玩具里，就是下期收益率为负的时候。半价差是流动性的可见价格；条件收益率是一根日K线仍然能显示的东西。冲击——下一节的主题——是另一种成本。一条规格说明可以同时带上两者。
:::

## 冲击对等待

2001年，罗伯特·阿尔格伦与尼尔·克里斯把执行提出为市场冲击与等待风险之间的权衡。立刻交易整张订单要付冲击：订单在拿走流动性时，价格逆着它动。把订单摊开会降低那份冲击，但把未成交的剩余规模暴露在寻常的价格变动之下。他们推导出了介于一条纯风险最小化路径与一条激进路径之间的执行调度。本课不重新推导那些调度，也不把它们变成一套切分实盘订单的手续。

研究账簿需要的，是一条简单成交悄悄选定的那个角点。一张在下一收盘成交、没有半价差也没有\(c\)的市价单，假定冲击为零、等待一根K线，并把成交价设成那个收盘价。加上一个常数半价差，保留了那次等待，把一个常数量换了进来。这两个角点都不是阿尔格伦与克里斯刻画的那条内部调度。凯尔（Albert S. Kyle）1985年在一张知情订单与它所引发的价格变动之间的线性关系，是冲击这一项的祖先；我们点名它，不去拟合斜率。一个想要冲击的回测必须写出一个函数。在它写出来之前，诚实的那句话是：冲击被设成了零，或设成了一个常数。

[[#def-linear]]里的线性成本，本身并不会让一条快的调度比一条慢的调度更贵。给激进情形一个更大的\(c\)，是一个情景，不是一个估计。[[#ex-turn]]就是那一类情景。

:::application 一条成本线需要的三个数字
把成交写完了的规格说明写着三样东西。半价差\(h\)，或者一句明话：这个账簿不付价差。线性费率\(c\)，以及它是否包含\(h\)。这条规则实际产生的换手，以每年的单边名义额计，好让[[#prop-cost]]手里有一个\(\delta\)，而不是一句口号。"一天交易两次"还不是一个\(\delta\)。[[#ex-year]]把一种读法在252个中间价不变的交易时段上变成了约0.9508的因子，把另一种读法变成了约0.9041。坐在这本账簿旁边的时效偏差——包括按决策收盘价的成交——在[[backtesting/timing-costs-and-biases]]。
:::

:::quiz
中间价100，半价差0.01，中间价不动。一笔市价买入之后跟一笔市价卖出一单位。现金亏损是什么？
- [ ] 0.01，即半价差，因为卖出把它挣回来了
- [x] 0.02，即整个价差：买付一分钱，卖付一分钱
- [ ] 零，因为中间价没有动
- [ ] 0.04，因为每条腿都付整个价差
:::solution
[[#prop-rt]]给出现金亏损\(2h = 0.02\)。没有动过的中间价不贡献任何盈利来抵它。每条腿付的是半价差，不是整个价差，所以一次完整往返恰好付一次整个价差。
:::
:::

:::quiz
O03那个已报告的100%胜率，为这场关于成本的讨论增添了什么？
- [ ] 一张被动限价单没有成本的证明，因为每一笔交易都赢了
- [ ] 一个预测：接下来的$25$年将重复+2.70%的年化复合增长率
- [x] 一个提醒：一个完美的胜率可以是一个关于哪些成交进入了分母的性质，并且与一个−19.09%的回撤相容
- [ ] 那个回测里半价差为零的证据
:::solution
目录把100%的胜率、一个无穷盈亏比、+2.70%的年化复合增长率与−19.09%的最大回撤并排印在一起。[[#ex-adv]]展示了一个成交过滤器如何移除从未触到限价的那些路径。这些没有一句话说半价差为零，也没有一句是预测。本图谱没有重跑过O03。
:::
:::

:::history
2001年，罗伯特·阿尔格伦（Robert Almgren）与尼尔·克里斯（Neil Chriss）把执行设定为市场冲击与等待风险之间的权衡，并推导出了介于一条纯风险最小化路径与一条激进路径之间的执行调度。本课的常数半价差与线性费率不是那些调度。它们是一本账簿在不假装解掉了那个权衡之下真正写得下来的角点：一次点名的等待，以及一个为零或为常数的冲击。凯尔（Albert S. Kyle）1985年的线性冲击模型是冲击那一侧的祖先。我们不去拟合它，也不把任何一篇论文变成发送一张订单的指令。
:::

## 通向何处

一个完工的回测必须共同声明的时钟、成本与偏差清单，在[[backtesting/timing-costs-and-biases]]。用它的乐观成交开启了那个选择故事的限价单，在[[orders/market-and-limit-orders]]。胜率与盈亏比——包括无穷的情形——作为统计量在[[performance/win-rate-and-profit-factor]]。在\(c\)所乘的那个名义额之下，仍然坐着一张数量网格；那张网格在[[orders/lots-contracts-and-intraday]]。

:::summary
- 在中间价不动时做一次市价完整往返，损失整个价差。中间价100、半价差0.01时，现金亏损是0.02，简单收益率取六位小数为\(-0.000200\)。
- 中间价上相匹配的线性费率是\(c = 0.0001\)。把它与半价差一起收取就是重复计算，除非规格说明写明\(c\)是额外加收的。
- 成本连乘。每个时段一笔线性完整往返、252个中间价不变的时段（\(\delta = 0.0002\)），把100的起步带到约95.08。每个时段两次完整往返，把价差模型的账簿带到约90.41。"一天两次"必须说清是哪一种。
- 一个编造的毛值0.05减去一个编造的单边成本0.001乘以换手，在换手50处为零。那条线是一幅图画，不是一个库内结果。
- 被动成交是一个被选出的样本。在五个收益率的玩具里，无条件均值是0.006，成交上的均值是\(-0.02\)。
- O03报告100%的胜率、一个无穷盈亏比、+2.70%的年化复合增长率与−19.09%的最大回撤。那个胜率是一个成交假设，不是好消息。
- 2001年的阿尔格伦与克里斯用冲击换等待。一个带常数价差、在下一收盘成交的成交，是那个权衡的一个角点，不是推导出的调度。这些库内数字是2026年所报告的；本图谱没有重跑过它们，它们也不是建议。
:::

## 习题

:::exercise 卖价 {level=1 check="100.01"}
中间价是100，半价差是0.01。一笔市价买入付出卖价。成交价格是什么？（输入成交价格。）
:::solution
卖价是中间价加半价差：\(100 + 0.01 = 100.01\)。相对中间价的缺口是每单位0.01。
:::
:::

:::exercise 现金里的完整往返 {level=1 check="0.02"}
中间价停在100，半价差停在0.01。以一单位市价买入、市价卖出。现金亏损是什么？（把亏损输入为一个正数。）
:::solution
100.01买入，99.99卖出。现金亏损是\(100.01 - 99.99 = 0.02\)，即\(2 \times 0.01\)。中间价什么也没有贡献。
:::
:::

:::exercise 按写明名义额收取的线性费用 {level=1 check="2.5"}
单边费率\(c = 0.0001\)，被声明为包含价差，一条边的名义额是25,000。那条边的成本是什么？（输入成本。）
:::solution
\(0.0001 \times 25{,}000 = 2.5\)。因为\(c\)被声明为包含价差，账簿不再往上面加一个半价差。同样名义额的第二条边会再收2.5。
:::
:::

:::exercise 是收益率，不是现金 {level=2 check="-0.000200"}
中间价100，半价差0.01，中间价不动，一笔市价完整往返。以买入价为基、按四舍五入取到六位小数的简单收益率是什么？（输入简单收益率。）
:::solution
买入价是100.01，卖出价是99.99。简单收益率是\(99.99/100.01 - 1 = -0.02/100.01 = -0.00019998\ldots\)，即六位小数的\(-0.000200\)。现金亏损0.02是另一个对象：它还没有除以卖价。
:::
:::

:::exercise 一个交易时段里的两次完整往返 {level=2 check="0.0004"}
线性费率是每条单边腿\(c = 0.0001\)，按整个账簿收取。一个时段包含两次完整往返，于是四条腿。那一天作为净资产值分数的成本是什么？（输入分数。）
:::solution
每条腿收\(0.0001\)。四条腿收\(4 \times 0.0001 = 0.0004\)。一次完整往返本来是\(0.0002\)。若中间价因子\(G_t\)也一并施加，因子\(1 - 0.0004\)就是[[#prop-cost]]接下来要乘的东西。题目只问0.0004这个分数。
:::
:::

:::exercise 成交上的均值 {level=2 check="-0.02"}
用[[#ex-adv]]的五个下一根K线简单收益率：\(0.02\)、\(0.01\)、\(-0.03\)、\(-0.01\)、\(0.04\)。买入限价只在第三根与第四根上成交。成交上的平均收益率是什么？（输入均值。）
:::solution
成交了的收益率是\(-0.03\)与\(-0.01\)。它们的均值是\(-0.04/2 = -0.02\)。全部五个的无条件均值是\(0.006\)，那不是所问的。两者之间的缺口就是那个选择。
:::
:::

:::exercise 把价差按一年的交易时段复利 {level=3 check="95.08"}
从净资产值100起步。252个交易时段中的每一个，中间价不变、停在100，账簿做一笔半价差0.01的市价完整往返，把价值乘以\(99.99/100.01\)。按四舍五入取到分的期末价值是什么？（输入价值。）
:::hint
一个时段的因子是\(99.99/100.01\)。把它抬到252次幂，再乘以100。未舍入的乘积约为95.0849。按四舍五入取到两位小数。线性近似\((1-0.0002)^{252} \times 100\)很接近，但它不是本题所问的因子。
:::
:::solution
一个时段乘以\(99.99/100.01\)。252个时段之后，价值是
\[
100 \times \left(\frac{99.99}{100.01}\right)^{252} = 95.0849\ldots.
\]
按四舍五入取到分，那是95.08。单是第一个时段就收在99.980002附近，那正是同一个因子乘一次；剩下的就是连乘。线性近似\(100 \times (1-0.0002)^{252} = 95.0844\ldots\)也舍入到95.08，但本题复利的是价差因子，不是\(1-0.0002\)。在一个平坦的中间价上以95.08收尾，是成本，不是行情，也不是预测。
:::
:::

:::exercise 编造的边在哪里消失 {level=3 check="50"}
一个编造的毛值0.05，减去一个编造的单边成本0.001乘以年换手\(\tau\)，如本课图中的那条线。什么换手让净值恰好为零？（输入换手。）
:::hint
令\(0.05 - 0.001\tau = 0\)，解出\(\tau\)。0.05与0.001都是编造的。它们既不是O03的年化复合增长率，也不是中间价100上的半价差。
:::
:::solution
\(0.05 - 0.001\tau = 0\)给出\(\tau = 0.05/0.001 = 50\)。在那个换手处，编造的毛值已经全部花在了编造的成本上。换手504——252个时段、每个时段两笔单边交易——在同一个编造费率下会留下\(0.05 - 0.504 = -0.454\)。图中那个成本0.001是\(0.0001\)的十倍，而\(0.0001\)正是与中间价100上一分钱半价差相匹配的费率。不把话说清就把这两个费率混在一起，就是[[#alg-fill]]所禁止的重复计算。两条线都不是已公布的回测。
:::
:::
