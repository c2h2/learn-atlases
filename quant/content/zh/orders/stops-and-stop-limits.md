限价单等待一个价格，若价格打印，就按那个价格交易。**止损单**等待一个价格，然后改变它自己成为哪种订单。在触发打印之前，它只是一个条件。触发之后，它要么是市价单、要么是限价单，而这两种后续者不会在同样的路径上成交。整个对象仍然是一个从未来路径到成交、撤销或错过的函数。它不是预测，也不是开出或平掉任何头寸的建议。

棘手的情形是跳空。止损说95。下一根K线以90开盘。没有95上的打印可供这张订单去交易，因为这根K线的第一个价格已经穿过了触发。按本章声明的约定，变成了市价单的止损在90成交。变成了限价的止损可能根本不成交。这两种结果都是定义的一部分。两者都不是对一笔已公布的亏损去取对面的理由，也都不是要求经纪人接收的指令。

上一章的区间约定与它的三个市价时钟在这里是假定已知的。除某句话点名了库中某行，此处的路径语言都是编造的。

## 触发，然后换一种订单

人们谈论保护性止损与突破止损，仿佛它们是两种不同的工具。不等式是同一个。**卖出止损单**挂在市价之下，是多头通常的出场。**买入止损单**挂在市价之上，是突破上通常的入场。[[trend/breakouts-and-macd]]把一个突破作为关于高点的假说持有。本章持有成交。O05的一行式描述是一张挂在近期高点之上的买入止损单；那个高点本身不在这里重新计算。

:::definition 止损市价单 {#def-stopmarket}
触发在\(s\)的**止损市价单**在一根K线穿过\(s\)之前一直处于休眠。此后它变成市价单。对卖出止损单，"穿过"指这根K线的最低价不高于\(s\)。对买入止损单，它指这根K线的最高价不低于\(s\)。**跳空约定**点名成交价。若开盘已经在\(s\)之外，成交为开盘，因为那是一个市价单能撞上的第一个价格。若开盘不在\(s\)之外而区间在，成交为\(s\)：一次乐观的触碰，与一张因为区间包含其价格而成交的限价单是同一种乐观。若区间没有到达\(s\)，这根K线是一次错过。
:::

触碰情形借来了[[orders/market-and-limit-orders]]的乐观。仅仅等于\(s\)的最低价，被当作整张数量在\(s\)上的成交，没有队列。跳空情形则是对止损价之乐观的反面。市场从未报出\(s\)，而约定拒绝假装它报出过。

:::definition 止损限价单 {#def-stoplimit}
**止损限价单**有一个触发\(s\)与一个限价\(\ell\)。当这根K线穿过\(s\)时，这张订单变成一张在\(\ell\)的限价，而不是市价单。对卖出止损限价单，限价是卖出的下限，所以\(\ell \le s\)：这张订单不会在\(\ell\)之下卖出。对买入止损限价单，限价是买入的上限，所以\(\ell \ge s\)：这张订单不会在\(\ell\)之上买入。变成限价并不意味着成交。若这根K线从不在那个限价的合法价格上交易，这根K线上的结果就是一次错过。错过之后的当日单随即撤销；一张撤销前有效单仍然挂着，仍然未成交。
:::

O07的一行式描述——"限定最高成交价"——是一张买入止损限价单。O08的那条，趋势入场之下挂止损限价卖出的，是保护性版本。上限与下限是同一个想法面向相反的两个方向。一张从未被交易的上限，是这张订单拒绝的一次突破。一个被跳空穿过的下限，是一笔这张订单没能砍掉的亏损。两者都是错过，不是\(\ell\)上不出声的成交。

:::algorithm 结算一根K线 {#alg-stop}
输入是这根K线的开盘、最高、最低，以及这张订单。第一个匹配的情形胜出。
1. *触发\(s\)的卖出止损市价单。*若最低价高于\(s\)，错过。若开盘不高于\(s\)，按开盘成交。若开盘高于\(s\)而最低价不高于\(s\)，按\(s\)成交。
2. *触发\(s\)的买入止损市价单。*若最高价低于\(s\)，错过。若开盘不低于\(s\)，按开盘成交。若开盘低于\(s\)而最高价不低于\(s\)，按\(s\)成交。
3. *卖出止损限价单，触发\(s\)，限价\(\ell \le s\)。*若最低价高于\(s\)，错过。若开盘严格低于\(\ell\)，错过：这根K线穿过了下限。若\(\ell \le\)开盘\(\le s\)，按开盘成交。若开盘高于\(s\)而最低价不高于\(s\)，按\(s\)成交。
4. *买入止损限价单，触发\(s\)，限价\(\ell \ge s\)。*若最高价低于\(s\)，错过。若开盘严格高于\(\ell\)，错过：这根K线穿过了上限。若\(s \le\)开盘\(\le \ell\)，按开盘成交。若开盘低于\(s\)而最高价不低于\(s\)，按\(s\)成交。
:::

情形3的最后一步按\(s\)成交而不是按最低价成交。乐观的触碰说触发成交过，而由于\(s \ge \ell\)，\(s\)是卖出的合法价格。它没有说这张订单卖在最低价上。情形4是镜像：当路径在限价之内从下方穿过触发时，买入按\(s\)成交、不按最高价成交。

:::quiz
一张卖出止损市价单挂在95。下一根K线以90开盘。跳空约定记录哪个成交？
- [ ] 95，因为那是写在止损单上的价格
- [x] 90，开盘价，因为止损已经变成了市价单，而开盘已经在95之外
- [ ] 不成交，因为止损从不比它的触发更差地成交
- [ ] 收盘价，无论它是什么，因为止损按收盘价成交
:::solution
一旦开盘不高于卖出触发，[[#def-stopmarket]]就把止损变成市价单并按开盘成交它。按95成交会发明一根K线没有的打印。一张下限高于90的止损限价单则可能改为错过；这道题是止损市价单。
:::
:::

## 跳空是更差的价，不是舍入误差

这段算术很短，而它就是"我的止损在95"的全部内容。

:::proposition 卖出止损单的跳空亏空 {#prop-gap}
设一笔多头在\(E > 0\)入场，并设卖出止损市价单挂在\(s\)，\(0 < s < E\)。下一根K线以\(O \le s\)开盘。在跳空约定下成交为\(O\)，从入场到成交的简单收益率为\(O/E - 1\)。倘若成交是触发价，简单收益率为\(s/E - 1\)。两个收益率之差是\((O - s)/E\)，它在\(O < s\)时严格为负。卖方每单位资产比触发价所暗示的少收\(s - O\)个记账单位。特别地，\(E = 100\)、\(s = 95\)、\(O = 90\)给出收益率\(-0.10\)与\(-0.05\)，而现金缺口为每单位5个记账单位。
:::

:::proof
由[[#alg-stop]]的情形1，不高于卖出触发的开盘按开盘成交，所以成交价是\(O\)，简单收益率是\(O/E - 1\)。减去按触发价的收益率：\((O/E - 1) - (s/E - 1) = (O - s)/E\)。当\(O < s\)时分子为负而\(E > 0\)，所以差为负。每单位的现金差就是同一个分子，\(O - s\)。代入三个价格：\(90/100 - 1 = -0.10\)，\(95/100 - 1 = -0.05\)，而\((90 - 95)/100 = -0.05\)。卖方每单位资产比按触发价成交少收\(95 - 90 = 5\)个记账单位。最高价与收盘价不进来，因为开盘已经定下了成交。
:::

入场100的百分之五是5，所以95的触发是一个$5\%$的保护性距离。那就是O06的一行式描述里点名的距离，在这里施加于一个编造的入场。它不是O06的成交，也不是一个$5\%$的必然亏损。在这根K线上，跳空把$5\%$变成$10\%$，而订单票纹丝未动。

:::proposition 止损限价单可以拒绝跳空 {#prop-miss}
设一张卖出止损限价单有触发\(s\)与限价\(\ell \le s\)，并设下一根K线以\(O < \ell\)开盘。这张止损限价单在那根K线上不成交。同样\(s\)的卖出止损市价单则成交，按\(O\)。这两张订单是不同的函数：在穿过下限的跳空上，限价不会把亏损封顶在\(\ell\)，也不会封顶在\(s\)。
:::

:::proof
由\(O < \ell \le s\)推出\(O < s\)。所以[[#alg-stop]]的情形1按\(O\)成交那张止损市价单。情形3在选择任何成交价之前，就把严格低于\(\ell\)的开盘当作错过。错过既没有\(\ell\)上的成交，也没有\(s\)上的成交。头寸仍然开着。任何盯市都要用一个更晚的价格，而那个价格是这张订单没有选择的。所以"下行在\(\ell\)处受到保护"这句话在这条路径上是假的，尽管\(\ell\)写在订单上。
:::

:::example 止损在95、开盘在90 {#ex-gap}
一笔多头在100入场。一张当日卖出止损市价单挂在95。下一根K线以90开盘，最高92、最低88、收盘91。应用跳空约定。用一个假想的按触发成交来比较这个成交，从简单收益率与记账单位两方面。
:::solution
开盘90不高于95，所以[[#prop-gap]]按90成交，不按95，也不按最低价88。从入场起的简单收益率为\(90/100 - 1 = -0.10\)。按触发的成交本会是\(95/100 - 1 = -0.05\)。差是\(-0.05\)，卖方每单位资产少收5个记账单位。收盘91与成交无关；只有当这张订单错过、而头寸正在被盯市时，它才要紧。这张止损市价单没有错过。
:::
:::

:::example 同样的跳空，下限设在94 {#ex-miss}
保持入场100与触发95，但把订单做成一张当日卖出止损限价单，限价94。用同一根K线，开盘90、最高92、最低88、收盘91。然后只把开盘换成94.5，再结算这张订单。第二个版本那根K线的最高、最低与收盘可以保持96、94与95；在第一个比较里干活的只有开盘，但第二根K线必须是一根可能的OHLC，所以取它开盘94.5、最高96、最低94、收盘95。
:::solution
在第一根K线上，开盘90严格低于下限94，所以[[#alg-stop]]的情形3记一次错过。没有94上的卖出，没有95上的，也没有90上的。一张当日单随即撤销。头寸仍然持多。按收盘91盯市，未实现的从入场起的简单收益率为\(91/100 - 1 = -0.09\)，它比止损市价单已实现的\(-0.10\)更好，只是因为这是一个盯市、不是成交。亏损没有被封顶。若头寸仍然持有，下一根K线想干什么就干什么。

在第二根K线上，开盘94.5满足\(94 \le 94.5 \le 95\)，所以止损限价按开盘成交。简单收益率为\(94.5/100 - 1 = -0.055\)。那比按95成交更差，每单位差半个记账单位，而且它是一笔真实的成交：开盘穿过了触发，但没有穿过下限。跳空约定与限价都在这里起了约束作用。这两个数字都不是使用94这个下限的建议。
:::
:::

:::example 确实让止损限价单成交的一次触碰 {#ex-touch}
同一张卖出止损限价单，触发95、限价94，遇到一根以97开盘的K线，最高99、最低94.5、收盘96。入场是100。它在哪里成交，简单收益率是多少？
:::solution
开盘97高于触发，而最低94.5不高于95，所以止损从上方被触发。情形3按触发95成交，不按最低价。因为\(95 \ge 94\)，触发是这张限价的合法价格。简单收益率为\(95/100 - 1 = -0.05\)。最低价打印了94.5，在下限之内，但乐观的触碰并不把最低价送给卖方。它送出的是触发。倘若最低价是93、而开盘仍是97，同样的情形仍会在95成交：一旦开盘高于\(s\)，规则看的是最低价是否到达\(s\)，而不看它越过了\(\ell\)多远。最后一句话就是那种乐观。一条从95直穿到93、而从未在95交易的路径，被宣布为交易了95。
:::
:::

:::example 买入止损单：触碰与跳空 {#ex-break}
一张买入止损市价单挂在105，那是一个突破入场的形状，而不是20日高点。两根编造的K线是彼此独立的实验。第一根以103开盘，最高108、最低102、收盘106。第二根以110开盘，最高112、最低109、收盘111。应用[[#alg-stop]]，并把每个成交对照它自己那根K线的收盘计分。
:::solution
在第一根K线上，开盘103低于105而最高108高于它，所以成交是触发105。从该成交到收盘的简单收益率为\(106/105 - 1 = 0.009524\)，六位小数。

在第二根K线上，开盘110已经高于105，所以成交是开盘110。从该成交到收盘的简单收益率为\(111/110 - 1 = 0.009091\)，六位小数。一个假想的按触发的成交、按同样的收盘盯市，会是\(111/105 - 1 = 0.057143\)，六位小数。跳空约定不授予那个收益率。入场每单位资产差5个记账单位，是110而不是105，而收盘对成交的收益率塌掉了，因为开盘已经吃掉了这段行情的绝大部分。一张在第二根K线上带上限106的买入止损限价单不会修复这个价格：开盘110高于106，所以情形4记一次错过。跳空而过的突破，正是上限所拒绝的那个突破。
:::
:::


默认的K线以90开盘，最高94、最低88，卖出止损市价单挂在95。开盘已经在触发之外，所以跳空约定按开盘成交，不按95。换成一张限价93、开盘价不变的卖出止损限价单：开盘穿过了下限，这根K线错过。

:::intuition 触发价不是承诺
写在止损单上的那个数字，是一条消息里的一个条件，不是市场已经答应的交易。[[#prop-gap]]就是移除了那种混淆之后剩下的东西：若开盘在触发之外，市价式的止损拿走开盘，而你写下的那个距离不是亏损。止损限价单恢复了一个你愿意接受的价，而[[#prop-miss]]是这次恢复的代价。在最需要出场的那条路径上，限价可以站到一边。
:::

## 四个已报告的止损回测

O05、O06、O07与O08都是日K线、跨距$25$年的订单模式示例。下面的数字是按quants.md对那些QuantJourney示例（Apache-2.0）的报告，按2026年的阅读。本图谱没有重跑过这些回测。它们不是预测，也不是建议。"已报告夏普比率"指的是他们的夏普，在一个本图谱没有核实过的约定之下。

O05，Stop Breakout Entry，是一张挂在近期20日高点之上的买入止损单。它报告总收益率$+41.44\%$、年化复合增长率$+1.40\%$、已报告夏普比率$-0.19$、最大回撤$-10.5\%$、胜率$61.9\%$、盈亏比$1.45$。

O06，Protective Stop Loss，是一个带$5\%$保护性止损的趋势入场。它报告总收益率$+60.1\%$、年化复合增长率$+1.90\%$、已报告夏普比率$0.00$、最大回撤$-16.2\%$、胜率$44.7\%$、盈亏比$1.70$。已报告夏普比率$0.00$并不是"止损什么也没做"的主张。同样这一行有一个为正的年化复合增长率和一个$-16.2\%$的回撤。这个零是他们的汇总统计量，照印出来的样子读。

O07，Stop Limit Breakout，做突破入场，但限定最高成交价。它报告总收益率$+56.2\%$、年化复合增长率$+1.80\%$、已报告夏普比率$-0.05$、最大回撤$-6.4\%$、胜率$63.0\%$、盈亏比$1.63$。

O08，Stop Limit Protection，是一个在下行一侧带止损限价卖出的趋势入场。它报告总收益率$+63.6\%$、年化复合增长率$+1.99\%$、已报告夏普比率$0.02$、最大回撤$-14.2\%$、胜率$43.1\%$、盈亏比$1.81$。

把O05与O07并排，O06与O08并排。每一对都是市价式止损对一个止损限价单，摆在一个相关的经济故事上：突破或保护。已报告的回撤各不相同：突破那一对是$-10.5\%$对$-6.4\%$，保护那一对是$-16.2\%$对$-14.2\%$。那是他们各自行里的数字。一个更小的已报告回撤不是偏爱上限的理由，因为成交函数已经改变，被错过的突破在两个实验里不在同一个地方，而本图谱没有重跑过其中任何一个。O07的$63.0\%$胜率不是O03的$100\%$。一个上限本身制造不出一个完美的分母；[[#ex-break]]演示了它制造一次错过。

O05与O07上为负的已报告夏普，以及O06与O08上接近零的数字，与跳空算术是同一个教训的一部分。出场或入场是路径的函数。把止损市价单改成止损限价单改变的就是函数。已公布的摘要会动，而它们不会动成一个关于读者该交易什么的故事。

:::warning 开盘已经跳空时按触发价记账
常见的口误是，因为止损说了$5\%$就扣掉$5\%$。[[#ex-gap]]就是反例：触发95、开盘90、成交90、简单收益率$-0.10$。另一个口误是加一个限价来"修好"它，然后继续假定成交。[[#ex-miss]]以90开盘、下限在94，没有卖出。一笔还不是成交的已保护亏损，仍然是一个头寸。
:::

:::remark 止损单不知道自己为何被下达
[[#alg-stop]]里没有任何东西在问这张订单是在保护一个多头还是在突破一个区间。这张订单留下的头寸是不同的——出场清空，入场开出——但成交价是开盘、最高、最低与票上两个价格的同一个函数。一篇研究札记说"止损对突破管用"或"止损作为保护管用"，援引O05对O06，仿佛"管用"这个动词在夏普那一列里看得见，就已经换掉了题目。O05的已报告夏普是$-0.19$。O06的是$0.00$。哪一列都不是许可证。
:::

:::quiz
一张卖出止损限价单有触发95与限价94。下一根K线以90开盘。[[#alg-stop]]记录什么？
- [ ] 在94成交，因为限价是允许的最差卖出
- [ ] 在90成交，因为当开盘跳空时，每个止损都按开盘成交
- [x] 一次错过：开盘穿过了下限，所以止损变成的那张限价不交易
- [ ] 在95成交，即触发，而一旦跳空够大，限价就被忽略
:::solution
[[#prop-miss]]适用：开盘严格低于下限，所以止损限价单错过，而一张95的止损市价单本会以90卖出。下限不会因为被写下来就变成一笔成交。
:::
:::

:::history
1985年，凯尔（Albert S. Kyle）给出了一个知情订单与它所引发的价格变动之间的线性关系，它是后来那些冲击公式的祖先。一张止损市价单，一旦被触发，就在朴素的意义上是主动的：它在当下有什么价格的地方拿走流动性，无论交易里的某一方是否知情。本章没有去拟合凯尔的那条线，也没有把[[#prop-gap]]里的跳空变成一个测出来的冲击系数。点名这个模型的用意更窄：一个被触发的止损的成交，不是订单上印着的那个数。
:::

## 通向何处

一个只朝有利方向移动的止损，和一对互相撤销的出场，在[[orders/trailing-brackets-and-oco]]。本章把一个止损变成的那些市价与限价消息，在[[orders/market-and-limit-orders]]。买入止损单理应挂在它之上的那个突破高点，在[[trend/breakouts-and-macd]]。一次跳空成交在更差的价之外仍然要付的那些成本，在[[orders/fills-slippage-and-spread]]。

:::summary
- 当一根K线穿过触发时，止损市价单变成市价单。若开盘已经在触发之外，跳空约定按开盘成交，不按触发。
- 止损限价单变成一张限价，而限价会错过。卖出下限被跳空穿过就成了错过；买入上限被跳空穿过也成了错过。
- 在入场100、卖出止损95、开盘90时，简单收益率是$-0.10$，不是$-0.05$。现金缺口为每单位5个记账单位。
- 同样的开盘配上94的下限不会卖出。成交不了的保护仍然是一个头寸。
- O05与O07是突破那一对，止损对止损限价，已报告夏普为$-0.19$与$-0.05$。O06与O08是保护那一对，已报告夏普为$0.00$与$0.02$。
- 那些行是2026年为QuantJourney示例所报告的。本图谱没有重跑过它们。一个更小的已报告回撤不是偏爱上限的理由。
- O06描述里的那个$5\%$距离，在一根K线可以跳空之后，就不再是一个$5\%$的必然亏损。
:::

## 习题

:::exercise 跳空成交 {level=1 check="90"}
一张卖出止损市价单挂在95。下一根K线以90开盘。在跳空约定下，成交价是什么？（输入成交价。）
:::solution
开盘已经在触发之外，所以止损已经变成了市价单，成交是开盘。成交价是90，不是95。
:::
:::

:::exercise 从入场起的收益率 {level=1 check="-0.1"}
多头在100入场，跳空成交为90。从入场到成交的简单收益率是多少？（输入简单收益率。）
:::solution
\(90/100 - 1 = -0.1\)。按触发价的收益率本会是\(-0.05\)。[[#prop-gap]]把它们相减得到\(-0.05\)，而那不是本题所问：本题问的是这个约定实际记下的收益率。
:::
:::

:::exercise 开盘已经击败的下限 {level=1 check="0"}
一张卖出止损限价单有触发95与限价94。这根K线以90开盘，最高92。若这张订单错过请输入0，否则输入成交价。
:::solution
开盘严格低于94，所以[[#alg-stop]]的情形3记一次错过。最高92再也没有回到下限。输入0。
:::
:::

:::exercise 向上穿过止损的突破 {level=2 check="105"}
一张买入止损市价单挂在105。这根K线以103开盘，最高108、最低102。成交价是什么？（输入成交价。）
:::solution
开盘低于触发而最高价高于它，所以这是触碰情形，不是跳空情形。成交是触发。成交价是105。
:::
:::

:::exercise 突破跳空了 {level=2 check="110"}
一张买入止损市价单挂在105。下一根K线以110开盘。在跳空约定下成交价是什么？（输入成交价。）
:::solution
开盘已经在触发之上，所以买入止损市价单按开盘成交。成交价是110。一张106的上限本会改为错过；这道题没有上限。
:::
:::

:::exercise 跳空在现金上花了多少 {level=2 check="5"}
入场100，卖出止损市价单95，开盘90，成交90。卖方每单位资产比按触发成交本应付出的少收多少个记账单位？（输入那个正的差。）
:::solution
按95成交本会收到95。跳空成交收到90。差是每单位资产\(95 - 90 = 5\)个记账单位。简单收益率之差是\(-0.05\)，那是除以入场100之后的那个现金缺口。题目要的是现金缺口，5。
:::
:::

:::exercise 两根K线、一个$5\%$止损 {level=3 check="93"}
一笔多头以100入场，带一张当日卖出止损市价单95，一个$5\%$的距离。第一根K线以101开盘，最高104、最低96、收盘102。第二根K线以93开盘，最高96、最低92、收盘94。若第一根没有触发这张止损，它在第二根开始时仍然挂着。成交价是什么？（输入成交价。）
:::hint
严格高于触发的最低价不会点燃一张卖出止损。不高于触发的开盘按开盘成交，即使最高价后来又交易回触发之上。
:::
:::solution
第一根K线最低96，高于95，所以止损不被触发。收盘102只是一个收盘。第二根K线以93开盘，而\(93 \le 95\)，所以跳空约定按开盘成交。成交价是93。从入场起的简单收益率为\(93/100 - 1 = -0.07\)，比\(-0.05\)更差，又比开盘90的情形更好，因为这个开盘只在触发之外穿了3个单位，而不是5个。第二根K线的最高96不会把成交拉回95。
:::
:::

:::exercise 哪根K线能在上限下存活 {level=3 check="105"}
一张买入止损限价单有触发105与限价106。K线A以107开盘，最高109、最低106、收盘108。K线B以104开盘，最高105.5、最低103、收盘105。这两根K线是彼此独立的实验，不是一个序列。在成交的那根K线上，成交价是什么？（输入成交价。）
:::hint
先把每个开盘与上限比较，再看最高价。高于106的开盘是一次错过。低于触发的开盘配上一个够得着触发的最高价，按触发成交，因为触发坐落在上限之内。
:::
:::solution
K线A以107开盘，严格高于上限106。[[#alg-stop]]的情形4记一次错过。最低价106恰等于上限，但规则不会在一个穿过上限的开盘之后再去抢救一笔成交；第一个匹配的情形就是那次错过。

K线B以104开盘，低于触发，而最高105.5不低于105。成交是触发105，它因为\(105 \le 106\)而坐落在上限之内。成交价是105。最高105.5不是成交：触碰式买入不付最高价。倘若最高价只是104.5，这张订单就会错过，因为触发从未打印，而开盘也还没有进入\([105, 106]\)之内。
:::
:::
