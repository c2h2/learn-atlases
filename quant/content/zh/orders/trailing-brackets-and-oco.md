一个固定止损是在头寸开出时选定的一个数。**移动止损**允许移动，但只许朝着锁定一个更有利极值的方向：多头是向上，然后不许回来。**括号单**在同一个头寸上放两个出场，一个在上、一个在下，再加一条撤销链接，让第一笔成交杀掉另一笔。**入场OCO**（one-cancels-the-other，一撤其一）在同一个信号上放两个*入场*，一个回落、一个突破，并杀掉没有成交的那一个。每一种情形里，这个对象仍然是一个从未来路径到成交、撤销或错过的函数。这个函数的几何就是整课的教训。它不是预测，也不是去追踪、去括起来、或让任何一张订单继续挂着的建议。

O09的一行式描述用一个$4\%$的追踪。O12的用一个在$+6\%$与$-3\%$的括号单。下面的路径在编造的价格上运用这些距离，好让算术看得见。它们不是这些回测的交易。已报告的那些行排在这些算术之后，而其中几个已报告夏普为负。这一簇就是要把它们放在一起读。

## 会棘轮上移的止损

驱动多头追踪的那个极值是一个滚动最大值。止损是那个最大值的一个固定分数。当价格下跌时，最大值不跌，所以止损也不跌。把高点回吐出去，只被"等到止损被打到"允许，不被"把止损放松"允许。

:::definition 移动止损 {#def-trail}
固定一个距离\(\delta\)，\(0 < \delta < 1\)，当算例用的是O09的那个距离时这里\(\delta = 0.04\)。一个多头的**移动止损**维护一个有利极值\(X\)，以入场价为起点。在每一根没有导致出场的K线之后，\(X\)变成它先前的值与这根K线最高价的最大值。当前止损是\(s = (1 - \delta) X\)。这张止损是一张在\(s\)的卖出止损市价单，按[[orders/stops-and-stop-limits]]的跳空约定结算，只是在这根K线未能打到从先前K线继承来的止损之前，\(s\)不允许使用这根K线自己的最高价。
:::

最后这个从句就是同一根K线规则。一根日K线没有说最高价是否发生在最低价之前。若继承来的止损被触及，我们就按那个继承来的止损成交，而不先用这根K线的最高价抬高\(X\)。先抬高它就会发明一个刚由这根K线自己的最高价制造出来的、更紧的止损。我们拒绝那个函数。

:::algorithm 多头移动止损的一根K线 {#alg-trail}
在一根K线开始时，极值\(X\)与止损\(s = (1-\delta)X\)已经已知。
1. 若开盘不高于\(s\)，按开盘成交。不更新\(X\)。另一张出场——若这个追踪坐在一个括号单里——被撤销。
2. 若开盘高于\(s\)而最低价不高于\(s\)，按\(s\)成交。不更新\(X\)。
3. 若最低价高于\(s\)，没有出场。把\(X\)换成\(\max(X, H)\)，把\(s\)换成新极值的\((1-\delta)\)倍。
4. 一个追踪式*止损限价单*使用同一个触发。在触发处，它变成一张在当前\(s\)的卖出限价，而不是市价单。若那张限价的价格不在K线之内，这根K线是一次错过，头寸保留。这是O11的描述的形状，不是O11的样本。
:::

一旦极值离开了入场价，极值的百分之四就不再是四个记账单位。100的百分之四是4，所以初始止损是96。110的百分之四是4.40，所以挂在\(110 \times 0.96 = 105.60\)的止损在那个高点下方4.40处。若那个止损成交，从入场起的简单收益率是对入场计算，不是对高点计算。

:::example $4\%$的移动止损：三根K线 {#ex-trail}
一笔多头在100成交，这就是极值的起点。距离是$4\%$。其后是三根K线。第一根：开盘101、最高104、最低100.5、收盘103。第二根：开盘103、最高110、最低106、收盘109。第三根：开盘107、最高108、最低103、收盘104。应用[[#alg-trail]]，并报告出场价与从入场起的简单收益率。
:::solution
起点是\(X = 100\)、\(s = 100 \times 0.96 = 96\)。

第一根K线最低100.5，高于96，所以没有出场。最高104取代极值。新止损是\(104 \times 0.96 = 99.84\)。

第二根K线最低106，高于99.84，所以没有出场。最高110取代极值。新止损是\(110 \times 0.96 = 105.60\)。从这个高点起的回吐是\(110 - 105.60 = 4.40\)，不是4。

第三根K线以107开盘，高于105.60，而最低103不高于105.60。第2步按105.60成交。最高108被忽略，而且它本来也抬不动极值，因为108低于110。从入场起的简单收益率为\(105.60/100 - 1 = 0.056\)。现金收益为每单位5.60个记账单位。讲述同一笔成交的另一句话——"它从高点回吐了4.40"——是\(110 - 105.60\)，那不是利润。两句话都是真的，而它们回答的是不同的问题。
:::
:::

:::example 既创新高又打到旧止损的那根K线 {#ex-samebar}
把[[#ex-trail]]的追踪保持到第二根K线结束，于是继承的极值是110，继承的止损是105.60。把第三根换成开盘101、最高120、最低90、收盘100。什么会成交，而什么是不合法的？
:::solution
开盘101已经不高于105.60，所以第1步按开盘101成交。极值不更新。从入场100起的简单收益率为\(101/100 - 1 = 0.01\)。

先用最高价会设\(X = 120\)、\(s = 120 \times 0.96 = 115.20\)。日K线并不包含打印的这个先后次序。[[#alg-trail]]按101成交。一个先做棘轮再成交的规格说明是另一个实验，不是一个舍入选择。
:::
:::

:::intuition 移动止损卖出的是最优打印的一个固定比例
从高点\(X\)出发，按这条规则，多头愿意回吐\(\delta X\)、仅此而已。那是关于出场消息的一句话，不是关于路径很可能续涨的一句话。若路径穿过\(s\)下落，这个函数出场。若路径继续创新高，这个函数收紧。O09报告了这样一个函数在$25$年里做了什么。那份报告的符号，并不由棘轮的精巧推出。
:::

## 两个价格，一次撤销

括号单是两条带共同撤销链接的出场。入场OCO是两个带共同撤销链接的入场。当一根K线同时触及两个价格时，这条链接是同一个词、而不是同一个约定，因为一种情形已经有一个头寸，另一种没有。

:::definition 括号单 {#def-bracket}
一个在\(E > 0\)入场的多头**括号单**，在\(E(1+u)\)挂一张卖出限价单、在\(E(1-d)\)挂一张卖出止损市价单，其中\(u > 0\)、\(0 < d < 1\)。这两条出场是一撤其一：第一笔成交撤销另一笔。若一根K线两个价格都不包含，两张都保留，那是那根K线上出场的错过，不是撤销。若两个价格都在K线区间内，本课的平局约定在开盘高于止损时成交止损并撤销获利，在开盘已经在止损之外时按开盘成交。这个平局约定对多头是悲观的。一个假定获利先打印的研究是另一个实验。
:::

O12的距离是\(u = 0.06\)与\(d = 0.03\)。在一个编造的入场100上，获利限价是106，止损是97。O13的距离是\(u = 0.04\)与\(d = 0.02\)，所以同一个入场会把出场放在104与98。那条命题覆盖这两对。算过的那几根K线用O12的那一对。

:::proposition 括号单的干净路径 {#prop-bracket}
设[[#def-bracket]]的括号单挂着，并设这根K线开盘\(O\)、最低\(L\)、最高\(H\)。
1. 若\(E(1-d) < L \le E(1+u) \le H\)，卖出限价在\(E(1+u)\)成交，止损被撤销，从入场起的简单收益率为\(u\)。
2. 若\(H < E(1+u)\)、\(O > E(1-d)\)而\(L \le E(1-d)\)，止损在\(E(1-d)\)成交，限价被撤销，简单收益率为\(-d\)。

在\(E = 100\)、\(u = 0.06\)、\(d = 0.03\)下，那些收益率是\(0.06\)与\(-0.03\)。
:::

:::proof
在第一个从句里，止损价\(E(1-d)\)严格低于最低价，所以卖出止损不被触发。获利价落在\([L, H]\)里，所以区间约定按\(E(1+u)\)成交那张卖出限价。撤销链接杀掉止损。简单收益率是\(E(1+u)/E - 1 = u\)。

在第二个从句里，获利价严格高于最高价，所以卖出限价错过。开盘高于止损而最低价不高于它，所以止损市价单的触碰情形按\(E(1-d)\)成交。撤销链接杀掉那张限价。简单收益率是\(E(1-d)/E - 1 = -d\)。

两个从句都要求两根出场价里恰好有一根在这根K线之内。当这一点失败时，本课用的是[[#def-bracket]]里的平局约定。在入场100处代入O12的距离给出\(100 \times 1.06 = 106\)与\(100 \times 0.97 = 97\)，以及收益率\(0.06\)与\(-0.03\)。用O13的距离做同样的代数，在任意满足同样两种形状的K线上给出收益率\(0.04\)与\(-0.02\)。这里没有任何东西说下一根K线会长成这两种形状中的哪一种。
:::

:::definition 入场OCO挂单 {#def-oco}
一张**入场OCO**挂两张入场订单，这里是一张在回落价上的买入限价单与一张在突破价上的买入止损市价单，由一条撤销链接相连。若这根K线恰好触及其中一张，那张订单按通常的限价或止损规则成交，另一张被撤销。若它一张也不触及，两张都保留。若两个价格都在K线区间内，这根K线没有说哪个先打印：本课撤销两张，不记录任何成交。开出一个头寸会发明一条路径。这个拒绝不是括号单的那个平局约定，而且也不应该是。括号单已经有一个头寸，并选择一个悲观的出场；入场OCO没有头寸，并拒绝发明一个。
:::

:::example 获利K线与止损K线 {#ex-bracket}
入场100、获利限价106、保护性止损97，即O12的距离。K线P：开盘102、最高107、最低101、收盘105。K线S：开盘99、最高100、最低94、收盘96。把每根K线当作彼此独立的实验结算。
:::solution
K线P最低101，高于97，而区间从101到107包含106。[[#prop-bracket]]的从句1按106成交卖出限价并撤销止损。简单收益率为\(106/100 - 1 = 0.06\)。收盘105不是成交。区间约定按限价卖出，因为最高价打印穿过了它。

K线S最高100，低于106，所以获利没被触及。开盘99高于97而最低94低于97，所以止损按97成交，不按开盘、不按最低。那张获利限价被撤销。简单收益率为\(97/100 - 1 = -0.03\)。现金亏损为每单位3个记账单位。倘若开盘是94，跳空约定本会以94卖出，收益率本会是\(-0.06\)，即止损那一章的跳空情形坐进了括号单里。这个开盘没有那么干。
:::
:::

:::example 突破撤销了回落 {#ex-oco}
一张入场OCO在98挂一张买入限价，在105挂一张买入止损市价单。一根K线以100开盘，最高106、最低99、收盘104。第二根彼此独立的K线以100开盘，最高101、最低97、收盘99。第三根以100开盘，最高106、最低97、收盘103。应用[[#def-oco]]。
:::solution
第一根K线上，最高106够到105，而最低99够不到98。只有买入止损被触及。开盘100低于105，所以触碰式成交是105，不是跳空式成交。那张买入限价被撤销。它的结果是一次撤销，而不是一次活到下一根K线的错过。

第二根K线上，最低97够到98，而最高101够不到105。那张买入限价在98成交。那张买入止损被撤销。从该成交到收盘的简单收益率为\(99/98 - 1 = 0.010204\)，六位小数。这个收益率是这根编造K线的一个性质，不是偏爱回落的理由。

第三根K线上，98与105都落在\([97, 106]\)里。这个约定撤销两张，不记录成交。没有入场价可以计分。一个仍然按105成交、或仍然按98成交的规格说明，加进了一条OHLC K线里并不存在的路径。
:::
:::

:::example 当追踪变成限价 {#ex-tlim}
取[[#ex-trail]]第二根之后的那个追踪，于是当前止损是105.60，但把触发换成一张在105.60的卖出限价，如[[#alg-trail]]第4步。下一根K线以100开盘，最高102、最低99、收盘99。在同一根K线上与止损市价式的追踪比较。
:::solution
开盘100低于105.60，所以追踪式止损市价单按开盘成交。从入场100起的简单收益率为\(100/100 - 1 = 0\)。

追踪式止损限价单变成一张在105.60的卖出限价。最高价是102，所以105.60不在区间内，这张限价错过。头寸仍然持多。按收盘99盯市，从入场起的未实现简单收益率为\(99/100 - 1 = -0.01\)。这次换算没有改善出场：它拒绝了这个跳空。O11是这种换算在库中的那一版；这根K线不是他们的那根K线。
:::
:::

:::warning 不要用把你扫出的那根K线做棘轮
继承下来的止损是这根K线上唯一可能被点燃的止损。[[#ex-samebar]]正是人们会糊弄过去的那种情形：最高120、开盘101、继承止损105.60。成交是101。先把极值更新到120、再宣称止损在115.20，用的是成交约定不允许看见的一个价格。同一种纪律也适用于括号单内部。若获利与止损都在区间内，[[#def-bracket]]取止损，不取获利。
:::

## 已报告的出场行做了什么

O09、O10、O11、O12、O13与O14都是日K线、跨距$25$年的订单模式示例。数字是按quants.md对那些QuantJourney示例（Apache-2.0）的报告，按2026年的阅读。本图谱没有重跑过这些回测。它们不是预测，也不是建议。

O09，Trailing Stop Trend，是一个带$4\%$移动止损的趋势入场。它报告总收益率$+30.0\%$、年化复合增长率$+1.06\%$、已报告夏普比率$-0.33$、最大回撤$-7.0\%$、胜率$47.6\%$、盈亏比$1.71$。

O11，Trailing Stop Limit，在触发处把追踪换成一张限价。它报告总收益率$+28.1\%$、年化复合增长率$+1.00\%$、已报告夏普比率$-0.38$、最大回撤$-6.2\%$、胜率$47.6\%$、盈亏比$1.69$。胜率在打印精度上与O09的一致。夏普不一致，而[[#ex-tlim]]正说明为什么胜率的一致本不可能是必然的：一张限价可以在市价式追踪会成交的地方错过。

O12，Bracket Trend，是一个带$+6\%$／$-3\%$括号单的趋势入场。它报告总收益率$+29.4\%$、年化复合增长率$+1.04\%$、已报告夏普比率$-0.38$、最大回撤$-6.8\%$、胜率$45.8\%$、盈亏比$1.58$。

O13，Bracket RSI Reversion，是一个带$+4\%$／$-2\%$括号单的RSI回落。它报告总收益率$+8.5\%$、年化复合增长率$+0.33\%$、已报告夏普比率$-0.43$、最大回撤$-11.6\%$、胜率$45.8\%$、盈亏比$1.07$。胜率照打印的样子与O12一致。年化复合增长率不一致。同样的括号形状、不同的距离、不同的入场故事、不同的行。

O14，OCO Dip Or Breakout，让一张买入限价与一张买入止损互相对峙。它报告总收益率$+45.5\%$、年化复合增长率$+1.51\%$、已报告夏普比率$-0.08$、最大回撤$-13.2\%$、胜率$58.0\%$、盈亏比$1.27$。

O10，Trailing Stop RSI，是一个超卖RSI入场配$5\%$移动止损。它报告总收益率$-12.2\%$、年化复合增长率$-0.52\%$、已报告夏普比率$-0.41$、最大回撤$-39.0\%$、胜率$39.8\%$、盈亏比$0.91$。收益率为负。那是关于那个样本里那个组合的证据。它不是取对面的理由。同一行在均值回归一侧的解读属于[[reversion/when-reversion-fails]]。这里只要明白：一个追踪式出场没有把入场故事变成一个为正的已报告年化复合增长率，就够了。

这六行的已报告夏普是$-0.33$、$-0.41$、$-0.38$、$-0.38$、$-0.43$与$-0.08$。五个年化复合增长率为正而温和；O10的不是。追踪、追踪限价、括号单与互相竞争的入场是不同的函数，而在这一簇里，已报告夏普没有变正。我们不对其做进一步年化。

:::application 这一簇就是结果
只引O14的$+1.51\%$年化复合增长率、而不引它的已报告夏普$-0.08$或它的回撤$-13.2\%$，就是在剪辑这一行。只引O10的亏损、再把符号取反，就是朝反方向剪辑。这一组里的已报告夏普都处在零或零以下。这是六个已公布的实验，不是出场的排名。
:::

:::remark 回吐不是入场收益率
在[[#ex-trail]]里，头寸从$110$的高点回吐了4.40，而从入场看的简单收益率仍有\(0.056\)。它们分别是\(\delta\)与\((1-\delta)X/E - 1\)。O09的$47.6\%$胜率用的是他们的单位，本图谱没有重建过那个单位。
:::

- [ ] 它被撤销，因为追踪只在价格上涨时适用
- [x] 它停在原处：极值不跌，所以止损不跌
- [ ] 它向入场回摆一半，作为一个折中
:::solution
由[[#def-trail]]，极值是一个滚动最大值。一根既没创新高、又没打到止损的K线，让极值与止损都保持不变。以价格单位计的距离保持为旧高点的一个固定分数，不是拴在最新打印上的一根橡皮筋。
:::
:::

:::quiz
一张入场OCO的买入限价与买入止损都在同一根日K线的区间之内。本课记录什么？
- [ ] 按买入止损成交，因为突破优于回落
- [ ] 按买入限价成交，因为限价是更好的价
- [ ] 两个价格都成交，开出两个头寸
- [x] 没有成交：两张订单都被撤销，因为这根K线没有说哪个价先打印
:::solution
[[#def-oco]]在两个入场价都落在区间内时拒绝这笔交易。括号单那个悲观的平局约定是另一个约定，适用于一个已经存在的头寸。把它用在这里会发明一个入场。
:::
:::

:::history
2002年，布沙尔（Jean-Philippe Bouchaud）、梅扎尔（Marc Mézard）与波茨（Marc Potters）测量了巴黎高流动性股票的订单簿，在到来的限价价格与平均订单簿的形状中发现了规律。一个移动止损、一个括号单与一对OCO挂单，是关于一个价格坐落在这样一本订单簿的哪里、以及该撤销哪条消息的规则。一根日K线留下了最高与最低，扔掉了那个形状。[[#alg-trail]]里的棘轮与本章里的两个平局约定，是关于那两个数的约定。它们用不上一本可见的订单簿本会提供的规律，因为K线里已经不再包含它们。
:::

## 通向何处

数量是下一个约束。一个追踪或一个括号单挂在一个编造的单位上，并没有说这条消息对应多少个外汇手数或多少张期货合约；那在[[orders/lots-contracts-and-intraday]]。追踪变成的那张止损市价单，包括跳空在内，在[[orders/stops-and-stop-limits]]。O10为负的那一行，读作一个追踪没能救回的均值回归入场，在[[reversion/when-reversion-fails]]里续讲。

:::summary
- 一个多头的移动止损把极值棘轮上移到新的高点，此外把它冻住。当前止损是这个极值的\((1-\delta)\)倍。
- 一根K线上可能被点燃的止损，是开盘时继承下来的那个止损。这根K线自己的最高价不允许先把它抬高。
- 从一个入场100、$4\%$的追踪出发，先后$104$与$110$的高点把止损放在$99.84$与$105.60$。其后一个穿过$105.60$的最低价在$105.60$出场，简单收益率为$0.056$——只要开盘没有跳空穿过。
- 一个从100出发、在$+6\%$与$-3\%$的括号单，在干净路径上于106或97出场，收益率为$0.06$与$-0.03$。若两个价格都在K线之内，本课成交止损。
- 一张发现回落与突破都在同一根K线之内的入场OCO，撤销两张，不发明成交。
- O09、O11、O12、O13与O14报告夏普$-0.33$、$-0.38$、$-0.38$、$-0.43$与$-0.08$。O10报告收益率$-12.2\%$、年化复合增长率$-0.52\%$。出场是结果的一部分。亏损不是取对面的理由。
- 这些数字是2026年为那些QuantJourney示例所报告的。本图谱没有重跑过它们，它们也不是建议。
:::

## 习题

:::exercise 初始止损 {level=1 check="96"}
一个多头追踪以入场100为起点，距离$4\%$。在任何后来高点之前，当前止损是什么？（输入止损。）
:::solution
\(100 \times (1 - 0.04) = 96\)。止损是96。还没有任何K线交易过，所以没有什么可棘轮。
:::
:::

:::exercise 高点110之后 {level=1 check="105.6"}
同一个$4\%$的追踪，有利极值为110。当前止损是什么？（输入止损。）
:::solution
\(110 \times 0.96 = 105.6\)。等价地，回吐是\(110 \times 0.04 = 4.4\)，而\(110 - 4.4 = 105.6\)。极值一动，止损就不会留在96。
:::
:::

:::exercise 获利价 {level=1 check="106"}
一个括号单在100入场，上行距离$6\%$。卖出限价价格是什么？（输入价格。）
:::solution
\(100 \times 1.06 = 106\)。在下方$3\%$的止损会是97；题目只要获利限价。
:::
:::

:::exercise 干净的获利路径 {level=2 check="0.06"}
入场100、获利限价106、止损97。一根K线最低101、最高107，开盘102。按[[#prop-bracket]]，从入场起的简单收益率是多少？（输入简单收益率。）
:::solution
最低价高于止损而最高够到获利，所以从句1按106成交并撤销止损。简单收益率为\(106/100 - 1 = 0.06\)。
:::
:::

:::exercise 干净的止损路径 {level=2 check="-0.03"}
入场100、获利限价106、止损97。一根K线以99开盘，最高100、最低94。从入场起的简单收益率是多少？（输入简单收益率。）
:::solution
最高没有够到106。开盘高于97而最低低于它，所以止损按97成交，获利限价被撤销。简单收益率为\(97/100 - 1 = -0.03\)。开盘没有穿过止损，所以成交不是99也不是94。
:::
:::

:::exercise 哪张入场活下来 {level=2 check="105"}
一张入场OCO在98挂一张买入限价，在105挂一张买入止损市价单。这根K线以100开盘，最高106、最低99。成交的那张订单，其成交价是什么？（输入成交价。）
:::solution
最高够到105而最低够不到98，所以只有买入止损被触及。开盘100低于105，所以成交是触发105。那张买入限价被撤销。
:::
:::

:::exercise 一个得自己动手更新的追踪 {level=3 check="101.76"}
一个$4\%$的多头追踪以100为起点。第一根：开盘101、最高104、最低100、收盘103。第二根：开盘103、最高106、最低102、收盘105。第三根：开盘104、最高105、最低100、收盘101。出场价是什么？（输入价格。）
:::hint
只在最低价保持在继承止损之上的K线上更新极值。在打到的那根K线上，若开盘仍高于继承止损，就按继承止损成交。不要用那根K线的最高价。验算\(106 \times 0.96\)。
:::
:::solution
初始止损是96。第一根K线最低100，高于96，所以没有出场。极值变成104，止损变成\(104 \times 0.96 = 99.84\)。

第二根K线最低102，高于99.84，所以没有出场。极值变成106，止损变成\(106 \times 0.96 = 101.76\)。

第三根K线以104开盘，高于101.76，而最低100低于101.76。[[#alg-trail]]的第2步按101.76成交。最高105反正低于极值106，即便它更高也会被忽略。从入场起的简单收益率为\(101.76/100 - 1 = 0.0176\)。题目要的出场价是101.76。
:::
:::

:::exercise 两条出场在同一根K线内 {level=3 check="97"}
一个在100入场的括号单，获利限价在106、止损在97。这根K线以100开盘，最高108、最低95、收盘102。本课记录哪个成交价？（输入成交价。）
:::hint
106与97都落在最低价与最高价之间，所以[[#prop-bracket]]的干净从句不适用。用括号单的平局约定，不要用入场OCO的拒绝，也不要用获利。
:::
:::solution
获利价106与止损价97都落在\([95, 108]\)里。[[#def-bracket]]于是看开盘。开盘100高于止损，所以平局约定按97成交止损并撤销获利。它不按106成交，尽管最高够到了108，也不把两张都撤销——那是还不存在的头寸所适用的入场OCO规则。简单收益率为\(97/100 - 1 = -0.03\)。成交价是97。

倘若开盘是95，同一条定义会按开盘成交，因为开盘本会已经在止损之外。那不是这根K线。
:::
:::
