等权给每个开着的名字相同的账簿份额。那是一张映射，而它无视了一个研究者可能早已写下的事实：这些名字并非同样吵。逆波动率与波动率目标都除以一个风险估计。它们回答的不是同一个问题。逆波动率设定相对规模。波动率目标则在某张相对映射已经被选定之后，设定整本账簿的尺度。把这两者混为一谈，正是规格在无人编辑信号的情况下自行漂移的方式。

下面的数字是研究札记里的公式。一个缩放因子，包括大于$1$的缩放因子，不是借入资金的建议，也不是对某个收益率的预测。

## 相对规模

设$\sigma_i > 0$为名字$i$的一个波动率估计，在决策时点已经拿到手。本章不重建估计量。当这个估计是简单收益率的样本标准差时，规格说明必须说清除数是$n$还是$n-1$，以及这个序列是用$\sqrt{252}$年化过，还是保留为每步的。在下面的算术里，波动率是给定的，因此没有任何除数或年化因子藏在其中。[[performance/volatility-and-drawdown]]正是这些选择被定义的地方。

:::definition 逆波动率权重 {#def-invvol}
给定$\sigma_i > 0$与一个总敞口预算$g > 0$——风险权重的绝对值之和将等于它——当每个权重都被要求非负时，**逆波动率权重**为

$$
w_i = g \cdot \frac{1/\sigma_i}{\sum_j 1/\sigma_j},
$$

原始分数$1/\sigma_i$不是权重。分母才是映射。
:::

[[#def-invvol]]里的预算$g$与[[portfolio/from-signal-to-weight]]里的总敞口预算是同一类对象。在它被写明之前，那些倒数是持有不了的。在所有比较相对规模的例子里，$g = 1$且每个权重都是正的，因此权重相加为$1$。

:::proposition 两个波动率 {#prop-two-vol}
设两个名字的波动率分别为$\sigma > 0$与$k\sigma$，其中$k > 0$，并设逆波动率权重为正且相加为$1$。则

$$
w_1 = \frac{k}{k+1}, \qquad w_2 = \frac{1}{k+1}.
$$

特别地，若第二个波动率是第一个的两倍，权重就是$2/3$与$1/3$。
:::

:::proof
原始分数是$1/\sigma$与$1/(k\sigma)$。它们的和是$(k+1)/(k\sigma)$。相除，

$$
w_1 = \frac{1/\sigma}{(k+1)/(k\sigma)} = \frac{k}{k+1}, \qquad w_2 = \frac{1/(k\sigma)}{(k+1)/(k\sigma)} = \frac{1}{k+1}.
$$

两者都是正的，并且相加为$1$。取$k = 2$给出$w_1 = 2/3$与$w_2 = 1/3$。较安静的那个名字，即波动率为$\sigma$的那个，得到较大的权重。这就是这个公式的全部含义。它不是说较安静的名字有一个更高的均值。
:::

:::example 波动率减半，原始分数翻倍 {#ex-two-thirds}
波动率是$0.10$与$0.20$。计算相加为$1$的逆波动率权重。
:::solution
原始分数：$1/0.10 = 10$与$1/0.20 = 5$。和是$15$。权重是$10/15 = 2/3$与$5/15 = 1/3$。

[[#prop-two-vol]]取$\sigma = 0.10$与$k = 2$给出同一对权重，而不必经过$10$与$5$这两个原始分数。较吵名字上的权重是较安静名字上权重的一半，因为它的波动率大一倍，而两个权重必须相加为$1$。$2/3$的一半是$1/3$。
:::
:::

三个名字是同样的算术。波动率$0.10$、$0.20$与$0.40$的原始分数是$10$、$5$与$2.5$，相加为$17.5$。权重是$10/17.5 = 4/7$、$5/17.5 = 2/7$与$2.5/17.5 = 1/7$。最吵的名字没有被剔除。它被给了最小的正权重。把它剔除会是另一张映射：一个过滤器接一个逆波动率，而规格说明必须对此作出说明。

逆波动率不使用名字之间的相关。两个波动率为$0.10$的名字，无论同涨同跌与否，都收到同样的逆波动率权重。当对象是对组合方差的贡献、而不只是孤立波动率时，相关才进入。那是[[portfolio/risk-parity]]。在对角协方差上，两张映射一致；离开那条对角线，它们未必一致。使用逆波动率是一个选择无视那个区别的决定，不是一个暗中把它包括进来的捷径。

## 账簿的尺度

相对权重可以已经固定，而相对于一个写明的风险预算，账簿的大小仍然不对。波动率目标缩放整个向量。

:::definition 波动率目标缩放 {#def-scale}
设$w$是一个权重向量，它的风险权重按产出它们的那张映射的意义已经相加为$1$，并设$\hat\sigma_p > 0$是这本账簿的简单收益率的波动率的一个估计。对一个目标$\sigma_\star > 0$，**波动率目标缩放因子**为

$$
k = \frac{\sigma_\star}{\hat\sigma_p}.
$$

缩放后的权重是在每个风险名字上的$k w_i$。当前缩放的风险权重相加为$1$时，现金权重是$1 - k$。若$k > 1$，现金权重为负。
:::

估计$\hat\sigma_p$是一个输入，正如$\sigma_i$曾经是一个输入一样。它可以是最近的组合收益率的样本标准差，配一个写明的除数；也可以是由一个在决策之前就已固定的协方差算出的$\sqrt{w^{\mathsf T}\Sigma w}$。例子里会说明是哪一种。目标$\sigma_\star$是映射的一个参数。它不是一个最优的风险水平，本章也没有一个用来选择它的程序。

:::proposition 缩放把两侧一起乘 {#prop-scale}
假设前缩放的风险权重相加为$1$，账簿在缩放之前的组合简单收益率本来是$R_p$，而现金余额挣$0$的简单收益率。那么缩放后的简单收益率是$k R_p$。特别地，一个正的$R_p$与一个负的、大小相同的$R_p$，在缩放之后仍然大小相同，而两者都被乘以$k$。若$k > 1$，现金权重$1-k$为负：在这个记账里，那就是杠杆。杠杆把盈利与亏损按同一个因子放大。这里没有任何东西在建议使用它。若现金挣一个非零利率，或者为负的现金权重融资有成本，恒等式$k R_p$就不成立，而规格说明必须说出是什么取代了它。
:::

:::proof
缩放之后，风险权重是旧权重的$k$倍，因此它们对简单收益率的贡献是$k R_p$。现金权重是$1-k$，挣$0$，什么都不添加。总和是$k R_p$。把$R_p$换成$-R_p$，缩放后的收益率就换成$-k R_p$。因子$k$不知道$R_p$的符号。

若$k > 1$，则$1-k < 0$。账簿大于净资产值，而在本模型里由利率$0$的借款提供融资。风险账簿上的一笔盈利大于未缩放的盈利，一笔亏损也大于未缩放的亏损，放大的是同一个因子。这就是"两侧一起放大"的意思。一个坐在估计值之上的目标恰好产生这种情形，因为当$\sigma_\star > \hat\sigma_p$时，$k = \sigma_\star/\hat\sigma_p$超过$1$。公式仍然是定义良好的。使用它是一个本图谱并不推荐的建模选择。
:::

:::example 小于一的缩放因子 {#ex-scale-down}
一本账簿的估计波动率是$0.16$。目标是$0.10$。缩放这本账簿，并在[[#prop-scale]]的假设下，把这个缩放作用到$+0.04$与$-0.04$的组合简单收益率上。
:::solution
缩放因子是$k = 0.10/0.16 = 0.625$。等价地，$0.10/0.16 = 5/8$。风险权重乘以$5/8$，现金权重是$1 - 0.625 = 0.375$，挣$0$。

缩放后的收益率是$0.625 \times 0.04 = 0.025$与$0.625 \times (-0.04) = -0.025$。两侧按同一个因子缩小。目标没有消除亏损。它把亏损与盈利一起缩小。一个记住了$0.025$却忘记了$-0.025$的读者，没有应用这张映射。
:::
:::

:::example 大于一的缩放因子 {#ex-scale-up}
单个名字的估计波动率是$0.08$。目标是$0.10$。计算缩放因子，并把它作用到$+0.02$与$-0.02$的组合简单收益率上。说出现金权重是什么。
:::solution
缩放因子是$k = 0.10/0.08 = 1.25$。缩放后的收益率是$1.25 \times 0.02 = 0.025$与$1.25 \times (-0.02) = -0.025$。现金权重是$1 - 1.25 = -0.25$。

这就是[[#prop-scale]]意义下的杠杆。$0.02$的盈利变成$0.025$，$0.02$的亏损变成$-0.025$。两侧都被放大。这套记账假定负现金挣$0$。一笔借款成本会让亏损比$-0.025$更糟，也会削减盈利。本图谱不建议这个缩放因子、这笔借款或这个目标。这个例子的存在，是为了让一个大于$1$的缩放在出现时能被认出，而不是为了被使用。
:::
:::

两张映射可以复合，而这个复合容易被漏看。逆波动率先设定相加为$1$的相对权重。目标再把每个风险权重乘以$k$。这个乘积既不是逆波动率，也不是单独的目标。

:::example 一本账簿上的两张映射 {#ex-both}
从[[#ex-two-thirds]]里波动率$0.10$与$0.20$上的权重$2/3$与$1/3$出发。假设协方差是对角的，于是组合方差是$(2/3)^2(0.10)^2 + (1/3)^2(0.20)^2$。计算那个波动率。然后把账簿缩放到$0.10$的目标，写出最终的风险权重。
:::solution
方差是

$$
\frac{4}{9}\cdot 0.01 + \frac{1}{9}\cdot 0.04 = \frac{0.04 + 0.04}{9} = \frac{0.08}{9} = \frac{2}{225}.
$$

波动率是$\sqrt{2/225} = \sqrt{2}/15 \approx 0.094281$。逆波动率这一步已经让账簿比$0.10$略安静一些，因为权重不相等，而协方差里没有协方差项。（对角协方差上的等权不会是这个数字。那是另一张映射。）

缩放到$0.10$的目标是

$$
k = \frac{0.10}{\sqrt{2}/15} = \frac{1.5}{\sqrt{2}} = \frac{3\sqrt{2}}{4} \approx 1.060660.
$$

由于$k > 1$，现金权重为负，而任何组合收益率的两侧都被放大，一如[[#prop-scale]]。这不是应用这个缩放因子的建议。若这个缩放因子仍然是规格说明，最终的风险权重将会是

$$
k\cdot\frac{2}{3} \approx 0.707107, \qquad k\cdot\frac{1}{3} \approx 0.353553,
$$

它们相加为$k$而不是$1$。在逆波动率之后停下，会留下$(2/3,1/3)$与现金权重$0$。在一个目标之后停下、而没有逆波动率那一步，则会要求某本别的前缩放账簿。规格说明里的那两句话不可互换。
:::
:::

:::warning 相对规模不是目标
一个常见的差错是算出$2/3$与$1/3$，然后把账簿描述成"做了波动率目标"。那些权重相加为$1$。它们只与协方差碰巧蕴含的那个特定的组合波动率的目标相合，而且只有当那个波动率等于$\sigma_\star$时才相合。在[[#ex-both]]里它约为$0.094281$，不是$0.10$，也不是$0.16$。另一个差错是反方向的：把每个信号乘以$0.625$，然后把结果称为逆波动率。缩放因子根本不看各个$\sigma_i$。
:::

那张图把缩放因子$0.10/\hat\sigma$画在估计波动率之上。曲线坐在$1$上方的地方，就是目标高于估计的地方。


默认值是两个波动率0.10与0.20。预算为1时权重是2/3与1/3。宽柱是这些权重。窄柱是同一批权重乘以把零相关账簿的波动率带到目标的那个缩放因子之后的结果。大于1的缩放因子是这套算术做出来的东西。它不是借入资金的建议，而零相关的账簿不是市场。

波动率$0.10$与$0.20$，权重相加为$1$。哪个向量是逆波动率映射？
- [ ] $(1/2,\ 1/2)$，因为有两个名字。

## 目录怎么对待这两张映射

开放库里有三行权重模式用了这些映射，而它们不是一个实验。接下来的图**是按quants.md对那个QuantJourney示例（Apache-2.0）的报告，按2026年的阅读**。本图谱**没有**重跑过这些回测。被报告的夏普比率是他们的数字；本章不声称它是按[[performance/sharpe-and-its-relatives]]的均值除以标准差的约定算出来的，也不声称用了任何写明的年化。

W05，"Monthly Inverse Vol"，按$63$日波动率的倒数给每只ETF定规模，并在月末设定权重。日K线，$19$年。被报告总收益率$+174\%$、年化复合增长率$+5.45\%$、夏普比率$0.45$、最大回撤$-20.4\%$、胜率$73.2\%$、盈亏比$3.59$。$63$日的窗口与月末的时钟是映射的参数。一个$20$日的窗口，或每日再平衡，都会是一条不同的规则。那一行没有说$63$日这个数字用的是除数$n-1$还是$n$。我们不去替它填上。

W17，"Vol Target Trend"，把一个SMA趋势篮子缩放到$10\%$的波动率目标。日K线，$19$年。被报告总收益率$+169\%$、年化复合增长率$+5.35\%$、夏普比率$0.36$、最大回撤$-28.9\%$、胜率$63.8\%$、盈亏比$1.93$。

W18，"Vol Target Momentum"，把一个动量篮子缩放到$15\%$的波动率目标。日K线，$19$年。被报告总收益率$+621\%$、年化复合增长率$+10.96\%$、夏普比率$0.57$、最大回撤$-41.2\%$、胜率$64.6\%$、盈亏比$2.05$。

把W17与W18并排放下，把两列都读了。被报告的年化复合增长率在W18上更高，而被报告的最大回撤更深：$-41.2\%$对$-28.9\%$。这一对就是这场比较的要点，不是一个可以据以行动的排名。篮子不同，趋势对着动量；目标也不同，$10\%$对着$15\%$。每当估计波动率坐在目标之下，一个更高的目标就抬高缩放因子，而[[#prop-scale]]说一个更大的缩放因子把两侧一起放大。六个被报告的数字里没有一个预测。它们里没有一个构成偏爱$15\%$目标、偏爱动量篮子、或偏爱这两条规则之反面的理由。

W05不是第三个目标。它是那张相对规模映射，在一个月末时钟上，带着它自己的窗口。它被报告的最大回撤$-20.4\%$不是"逆波动率会做的事"。它是那个规格在那个样本上、在本图谱没有重跑的成本与成交规则之下做出来的事。[[momentum/momentum-across-assets]]在一个不同的资产类别上再次与逆波动率权重相遇；映射是同一类对象，而结果并不被假定可以迁移。

:::intuition 没有窗口的目标是一句没说完的话
符号$\hat\sigma_p$看起来像一个常数。在一个回测里它是被重新计算的。W05说窗口是$63$天。一个目标行若没有说明窗口、除数，也没有说明这个估计是组合收益率的标准差还是一个协方差公式，它就没有把$k$规定下来。两个实现可以共享"目标$10\%$"这句话，却在每一个权重上都不一致。这与W17对照W18是同一课，只是往前一步：听起来像是整条规则的那句话，只是缩放因子。
:::

:::history
托宾（Tobin）在1958年证明了一个分离结果：在他的假设之下，每一个均值–方差投资者都持有无风险资产与一个风险资产切点组合的一个搭配。风险的内部配比不依赖投资者的风险偏好；依赖的是那个组合与无风险资产之间的配比。波动率目标是这个拆分后来的、更粗糙的亲戚。它拿起一本已经选好的账簿——被一条趋势规则、一条动量规则、一张逆波动率映射选好——并朝一个数字去缩放它。它不推导切点组合，也不继承托宾的假设。这个日期不是任何特定目标的凭据。本章不建议大于一的缩放因子，那正是[[#def-scale]]里现金头寸为负的情形。
:::

:::quiz
一本账簿的估计波动率是$0.16$，目标是$0.10$。对$k = 0.625$的哪种读法是对的？
- [ ] 账簿被加了杠杆，因为目标总是放大收益率。
- [x] 风险权重乘以$0.625$；若现金挣$0$且旧权重相加为$1$，现金权重是$0.375$；一笔盈利与一笔亏损都被缩小到$0.625$倍。
- [ ] 每个名字的权重变成它自己波动率的倒数。
- [ ] 作为一个恒等式，最大回撤变成原来深度的$0.625$倍。
:::solution
[[#prop-scale]]只在零现金利率假设之下把组合简单收益率乘以$k$。它本身并不去乘一个回撤：回撤是净值路径的一个路径性质，一旦缩放因子自己也随时间变动，回撤就未必按$k$缩放。这里没有使用逆波动率。而$k < 1$不是杠杆；$k > 1$才是，而且那会把两侧一起放大。
:::
:::

## 通向何处

[[portfolio/risk-parity]]要求每个名字贡献同样多的组合方差。在对角协方差上，那个要求复现[[#def-invvol]]。相关不相等时它不会复现，这就是本章的相对规模映射必须被写出来、而不假装它见过协方差的原因。一个完工的风险平价向量一与目标相比较，缩放因子$k$就回来了：等风险贡献固定相对权重，而若使用一个目标，它是一次进一步的乘法，[[#prop-scale]]里的警告原样不变。一个被报告的夏普比率有多难从噪声里分辨出来，那是[[performance/uncertainty-of-performance]]的事，不是$k$的性质。

:::summary
- 逆波动率权重与$1/\sigma_i$成比例，然后归一化。预算为$1$时它们相加为$1$。它们设定相对规模，并且无视相关。
- 波动率$0.10$与$0.20$给出权重$2/3$与$1/3$。较安静的名字得到较大的权重。
- 波动率目标把一本完工的账簿乘以$k = \sigma_\star/\hat\sigma_p$。它不看各个$\sigma_i$。
- 估计波动率$0.16$与目标$0.10$给出$k = 0.625$。在零现金利率之下，$\pm 0.04$的收益率变成$\pm 0.025$。
- 若目标坐在估计之上，则$k > 1$，现金权重为负，两侧都被放大。那是杠杆。本图谱不建议它。$0.08$对目标$0.10$的情形有$k = 1.25$。
- 在对角协方差上，$2/3$、$1/3$那本账簿的波动率是$\sqrt{2}/15 \approx 0.094281$。把它缩放到$0.10$会把$k$推到略高于$1$。
- W05是一张$63$日的逆波动率映射，在月末。W17与W18是$10\%$与$15\%$的目标，作用在不同的篮子上。W18更高的被报告年化复合增长率挨着一个更深被报告的回撤。那是比较，不是排名。
:::

## 习题

:::exercise 安静的名字 {level=1 check="2/3"}
波动率是$0.10$与$0.20$。逆波动率权重相加为$1$。波动率为$0.10$的名字上的权重是多少？（输入分数。）
:::solution
原始分数$10$与$5$相加为$15$。较安静的名字得到$10/15 = 2/3$。[[#prop-two-vol]]取$k = 2$给出同一个分数。
:::
:::

:::exercise 标准的缩放因子 {level=1 check="0.625"}
组合的估计波动率是$0.16$，目标是$0.10$。缩放因子$k$是多少？（输入小数。）
:::solution
$k = 0.10/0.16 = 0.625$。若前缩放的权重相加为$1$且现金挣$0$，现金权重是$0.375$。一笔组合收益率的两侧都被乘以$0.625$。
:::
:::

:::exercise 三个相等的波动率 {level=1 check="1/3"}
三个名字的波动率都是$0.20$。逆波动率权重相加为$1$。第一个名字上的权重是多少？（输入分数。）
:::solution
三个原始分数相等，于是归一化给每个名字$1/3$。当每一个波动率都相同时，逆波动率复现等权。相关，若有的话，不是输入。
:::
:::

:::exercise 三个里最吵的 {level=2 check="1/7"}
波动率是$0.10$、$0.20$与$0.40$。逆波动率权重相加为$1$。波动率为$0.40$的名字上的权重是多少？（输入分数。）
:::solution
原始分数是$10$、$5$与$2.5$，相加为$17.5$。最吵的权重是$2.5/17.5 = 1/7$。其余的是$4/7$与$2/7$。
:::
:::

:::exercise 缩小一笔亏损 {level=2 check="-0.025"}
缩放因子是$0.625$，现金挣$0$，未缩放的组合简单收益率是$-0.04$。缩放后的简单收益率是多少？（输入小数。）
:::solution
[[#prop-scale]]把收益率乘以$k$。缩放后的收益率是$0.625 \times (-0.04) = -0.025$。配上的一笔$+0.04$盈利本会变成$+0.025$。这张映射把两者都缩小。
:::
:::

:::exercise 认出杠杆 {level=2 check="1.25"}
估计波动率是$0.08$，目标是$0.10$。缩放因子是多少？（输入小数。）
:::solution
$k = 0.10/0.08 = 1.25$。它大于$1$，因此在零利率记账里现金权重是$-0.25$，而一笔盈利与一笔亏损都被放大到$1.25$倍。这个数字是一个规格说明将会使用的缩放因子。它不是使用它的建议，而且非零的借款成本没有被包括进来。
:::
:::

:::exercise 两名账簿的对角波动率 {level=3 check="0.094281"}
权重$2/3$与$1/3$，波动率$0.10$与$0.20$，对角协方差。组合波动率是多少，精确到六位小数？（输入六位小数的近似值。）
:::hint
组合方差是各个权重平方乘以波动率平方的和。没有样本除数：波动率是给定的。最后再开平方根。精确值是$\sqrt{2}/15$。
:::
:::solution
方差：

$$
\bigl(\tfrac23\bigr)^2 (0.10)^2 + \bigl(\tfrac13\bigr)^2 (0.20)^2 = \tfrac{4}{9}\cdot 0.01 + \tfrac{1}{9}\cdot 0.04 = \tfrac{2}{225}.
$$

波动率$\sqrt{2}/15 \approx 0.094281$。一个$0.10$的目标随后会需要一个约$1.060660$的缩放因子，而它把两侧一起放大。计算波动率并不要求应用那个缩放因子。
:::
:::

:::exercise 复合两张映射 {level=3 check="5/12"}
波动率$0.10$与$0.20$上的逆波动率权重相加为$1$。这本账簿随后被$0.625$缩放，即[[#ex-scale-down]]的缩放因子，现金挣$0$。较安静名字上的最终权重是多少？（输入分数。）
:::hint
较安静名字上的逆波动率权重是$2/3$。乘以$5/8$，也就是$0.625$。这两步只有在都被写下来之后才是同一张映射。
:::
:::solution
缩放之前较安静的权重是$2/3$。缩放之后它是

$$
\frac{2}{3}\times 0.625 = \frac{2}{3}\times\frac{5}{8} = \frac{5}{12}.
$$

较吵的最终权重是$(1/3)\times(5/8) = 5/24$，而现金权重是$1 - 5/8 = 3/8$。风险权重相加为$0.625$，不是$1$。把$5/12$称为逆波动率权重会丢掉缩放因子。把它称为纯粹的目标会掩盖另一个风险权重恰是它的一半这个事实。
:::
:::
