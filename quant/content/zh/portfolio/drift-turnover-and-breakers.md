一个目标权重是在时刻$t$的一个决策。价格随后变动，而账簿实际拥有的权重不再是目标，即使没有任何人交易。那个差距就是漂移。一条研究规则可以无视它而在日历上做交易，只在差距越过一条带子时交易，只在一份换手预算之内交易，只在相对一个基准的跟踪误差足够大时交易，或者在一次回撤之后把权重整个扔掉。这些每一条都是对交易的约束。它们没有一条是产生那个目标的信号的一个性质。

在一条玩具路径上一个更浅的回撤是一条规则的一个性质，不是装上那条规则的理由。同样的警告覆盖下面的每一行目录。

## 漂移

取一个权重为$w$的风险腿与一个权重为$1-w$的现金腿。风险腿挣简单收益率$R$。现金挣$0$。不发生交易。新的风险权重不是$w$。

:::definition 漂移后的权重 {#def-drift}
在那些假设之下，**漂移后的权重**为

$$
w' = \frac{w(1+R)}{1 + w R}.
$$

现金权重漂移到$1-w'$。一条规则在没有新信号的情况下能看到的距离是$\abs{w' - w^\star}$，其中$w^\star$是目标。目标可能仍然是$w$，也可能一个新信号已经改变了它。
:::

:::proposition 公式从何而来 {#prop-drift}
假设风险腿一开始占净资产值的一个比例$w$，现金一开始是$1-w$而挣$0$的简单收益率，这一步上的风险简单收益率为$R > -1$，并且不交易任何东西。那么这一步末尾的风险比例是$w(1+R)/(1+wR)$。若$R > 0$且$0 < w < 1$，风险权重上升。若$-1 < R < 0$，它下降。
:::

:::proof
设风险头寸价值$V$、现金价值$C$，于是$w = V/(V+C)$且$C/V = (1-w)/w$。这一步之后风险头寸价值$V(1+R)$，现金仍然价值$C$。新的权重为

$$
w' = \frac{V(1+R)}{V(1+R)+C} = \frac{w(1+R)}{w(1+R) + (1-w)} = \frac{w(1+R)}{1+wR}.
$$

在这个全额出资的设定里分母是正的，因为$R > -1$且$w \le 1$；更仔细地说，$1+wR = (1-w) + w(1+R) > 0$。把$w'$与$w$比较：

$$
w' - w = \frac{w(1+R) - w(1+wR)}{1+wR} = \frac{w(1-w)R}{1+wR}.
$$

若$0 < w < 1$，分数$w(1-w)/(1+wR)$为正，所以$w'-w$与$R$同号。
:::

那个公式就是全部机制。一个不被削减的赢家会变成账簿的一个更大的比例。一个不被补仓的输家会变成一个小一些的。这两个事实都不告诉研究者去交易。它们告诉研究者的是：如果他们不交易，权重是什么。

:::example 从$0.40$到$0.47$ {#ex-drift}
风险权重从$0.40$开始，现金挣$0$，风险简单收益率是$35/106$。计算漂移后的权重。一条$b = 0.10$的带子只在从漂移后的权重到目标$0.40$的距离严格大于$0.10$时交易。这一步会交易吗？一条$0.05$的带子会交易吗？
:::solution
[[#prop-drift]]给出

$$
w' = \frac{0.40\bigl(1 + 35/106\bigr)}{1 + 0.40\cdot(35/106)}.
$$

由于$1 + 35/106 = 141/106$且$0.40 = 2/5$，

$$
w' = \frac{(2/5)\cdot(141/106)}{1 + (2/5)\cdot(35/106)} = \frac{282/530}{600/530} = \frac{282}{600} = 0.47.
$$

按记账单位：风险价值$40$按因子$141/106$增长到$2820/53$，现金停在$60$，而$2820/53$除以$6000/53$是$0.47$。

距离是$\abs{0.47 - 0.40} = 0.07$。这并不严格大于$0.10$，所以$0.10$的带子不交易。它严格大于$0.05$，所以$0.05$的带子会交易。信号从头到尾没有出场。同一个漂移后的权重在这一条带子里、在那一条带子外，因为带子是不同的参数。

一条总把$0.40$恢复回去的月末规则会在这一步交易，即使$0.07 < 0.10$。日历再平衡与漂移带是不同的约束。[[momentum/rotation-and-calendars]]针对另一个差距——从$0.50$到$0.62$——做了那个比较。这里的算术才是本章自己拥有的那一个。
:::
:::

:::definition 漂移带 {#def-band}
给定一个目标$w^\star$、一个漂移之后的当前权重$w^{\mathrm{cur}}$，以及一个门槛$b \ge 0$，**漂移带**只在

$$
\abs{w^{\mathrm{cur}} - w^\star} > b
$$

时朝$w^\star$交易，否则让账簿保持不变。门槛以权重为单位，不是权重的一个百分比。一条$0.10$的带子在$0.40$周围从$0.30$延伸到$0.50$。它不是从$0.40\times 0.90$到$0.40\times 1.10$的区间，那会是$0.36$到$0.44$。
:::

那张图复合的是一步$2\%$的恒定风险收益率，从权重$0.40$开始，现金挣$0$，且不交易。它是[[#prop-drift]]迭代之后的闭式，$w(1.02)^n\big/\bigl(w(1.02)^n + 1 - w\bigr)$，不是一条市场路径。

:::widget sequence
a: 0.40*(1.02)^n/(0.40*(1.02)^n+0.60)
mode: terms
N: 40
caption: 一条腿的漂移：它从权重$0.40$开始，一步挣$2\%$，而现金挣$0$，没有任何人交易。权重在第$20$与第$21$步之间越过$0.50$。在$0.40$周围一条$0.10$的带子就是从$0.30$到$0.50$的区间，所以那次越界正是这条特定的带子会做交易的第一个时点。那条曲线是漂移公式，不是本图谱推荐的规则。
:::

## 换手与跟踪误差

当一条带子、一个日历或一个新信号要求从$w^{\mathrm{cur}}$朝$w^\star$移动时，那次移动本身可能被设了上限。

:::definition 换手预算 {#def-turnover}
从$w^{\mathrm{cur}}$到一个候选$w^{\mathrm{new}}$的一个变化的**换手**，按本章的约定，为

$$
\tau(w^{\mathrm{new}}, w^{\mathrm{cur}}) = \sum_i \abs{w^{\mathrm{new}}_i - w^{\mathrm{cur}}_i}.
$$

一份**换手预算**$\tau_{\max}$只有在那个和至多为$\tau_{\max}$时才容许这个变化。若走向$w^\star$的整一步超出预算，被实现的权重为

$$
w^{\mathrm{new}} = w^{\mathrm{cur}} + \lambda(w^\star - w^{\mathrm{cur}}), \qquad \lambda = \min\Bigl(1,\ \frac{\tau_{\max}}{\tau(w^\star, w^{\mathrm{cur}})}\Bigr),
$$

前提是$\tau(w^\star, w^{\mathrm{cur}}) > 0$。这个约定把一笔由现金承接的交易的两边都计进去。有的作者除以$2$。一个只写"换手"却不写公式的规格说明，并没有说它用了哪个约定。成本，在被收取时，收在这个约定所定义的换手上；每单位的成本在哪里进入复合收益率，在[[trend/lag-whipsaw-and-costs]]。
:::

:::proposition 两条腿，两边都计 {#prop-two-turn}
若账簿由一个风险权重与一个现金权重组成，那么当风险权重移动$\delta$时，两个权重变动的绝对量相同。[[#def-turnover]]里的换手是$2\abs{\delta}$。
:::

:::proof
现金变动$-\delta$，使权重仍然相加为$1$。绝对变动之和是$\abs{\delta} + \abs{-\delta} = 2\abs{\delta}$。
:::

:::example 没有做完事的预算 {#ex-budget}
漂移后的权重是$0.47$，目标是$0.40$，一如[[#ex-drift]]。现金是另一条腿。计算完全恢复到目标的换手。然后施加一份$0.10$的换手预算，并报告被实现的风险权重。
:::solution
风险权重的完整变动是$\delta = 0.40 - 0.47 = -0.07$。按[[#prop-two-turn]]，换手是$2\times 0.07 = 0.14$。

预算$0.10$小于$0.14$，所以$\lambda = 0.10/0.14 = 5/7$。被实现的变动是$(5/7)\cdot(-0.07) = -0.05$。新的风险权重是$0.47 - 0.05 = 0.42$，而现金是$0.58$。实际用到的换手是$2\times 0.05 = 0.10$，它满足预算，却没有到达目标。以后的一步也许会把剩下的搬过去，或者到那时目标又移动了。这份预算是对这笔交易的约束，不是说$0.42$是一个好权重。
:::
:::

跟踪误差需要一个信号并不提供的基准。

:::definition 事前跟踪误差 {#def-te}
设$w$是账簿的权重，$w^{b}$是一个基准的权重，$\Sigma$是在决策时点固定下来的一个协方差。**事前跟踪误差**为

$$
\mathrm{TE}(w, w^{b}) = \sqrt{(w - w^{b})^{\mathsf T}\Sigma(w - w^{b})}.
$$

一个**跟踪误差门槛**只在这个数超过一个写明的门槛时才容许一笔交易，或只在那笔交易否则会把跟踪误差留在门槛之上的时候才容许。两条规则中的任何一条都是对交易的约束。那个平方根不是已实现主动收益率的一个样本的标准差；那个已实现的数字是另一个对象，与[[performance/sharpe-and-its-relatives]]里的信息比率有关。
:::

对一个风险名字、基准权重$w^{b}$、账簿权重$w$、波动率$\sigma$，以及波动率为$0$的现金，那个二次型退化成一项。

:::example 单个名字对抗一个基准 {#ex-te}
风险权重已经漂移到$0.47$。基准权重是$0.50$。风险波动率是$0.20$而现金波动率是$0$。计算事前跟踪误差。一个只在跟踪误差超过$0.01$时才交易的门槛——这本账簿会交易吗？
:::solution
主动的风险权重是$0.47 - 0.50 = -0.03$。主动的现金权重是它的相反数，而现金不添加任何方差。于是

$$
\mathrm{TE} = \abs{-0.03}\cdot 0.20 = 0.006.
$$

由于$0.006$并不大于$0.01$，那个门槛不交易。到[[#ex-drift]]那个信号目标的距离——从$0.40$算起是$0.07$——是另一个比较。一个门槛可以是关着的，而围绕信号目标的一条带子却是开着的，因为基准与信号目标是不同的向量。门槛$0.01$是这个例子的规格说明的一部分。它不是被推荐的触发。
:::
:::

## 把权重设为现金的回撤

漂移、带子、预算与门槛修改的是朝一个目标的交易。一个熔断器替换的是目标。

:::definition 熔断器 {#def-breaker}
设$V_t$是账簿的净资产值，设$P^\star_t = \max\{P^\star_{t-1}, V_t\}$是历史峰值，$P^\star$从第一个值开始。回撤是$D_t = V_t/P^\star_t - 1$。一个门槛为$d \in (0,1)$、冷却期为$H$的**熔断器**行动如下。若$D_t < -d$——回撤严格深于$d$——接下来$H$个决策区间的权重被设为现金。在冷却期内，账簿挣的是现金收益率，在下面的例子里那是$0$。第一次越过门槛的那根K线仍然按旧权重挣得：那次越界要在那段收益率发生之后才知道。冷却期之后，信号权重可以再次使用。峰值是否重置是规格说明的一部分；那个例子结束在冷却期之内，所以用不到重置。
:::

"超过$d$"是严格不等式。正好落在$D = -d$上不触发这个定义。一个缺口可以从一个浅于$d$的回撤跳到一个深得多的回撤，因为检查发生在K线收盘时刻。

:::example 同一条路径，带与不带熔断器 {#ex-path}
始终持仓账簿的净资产值，按记账单位，为

$$
100,\ 110,\ 99,\ 88,\ 70,\ 98.
$$

峰值是$110$。一个熔断器取$d = 0.15$，并在第一根收盘时严格低于峰值$15\%$以上的K线之后设置两个期间的冷却期。现金挣$0$。计算两个期末财富，以及两个最大回撤。
:::solution
始终持仓路径相对历史峰值的回撤：$100$与$110$是峰值，回撤$0$。然后$99/110 - 1 = -0.10$，并不严格低于$-0.15$。然后$88/110 - 1 = -0.20$，严格低于$-0.15$。越界的那根K线是全额挣下的：在熔断器做任何事之前，财富是$88$。冷却期覆盖了资产的接下来两次变动，从$88$到$70$以及从$70$到$98$——假如仍然持仓的话。

带着熔断器，财富在冷却期里保持在$88$。期末财富是$88$。财富的路径是$100, 110, 99, 88, 88, 88$。最大回撤是$88/110 - 1 = -1/5 = -0.20$。

没有熔断器，期末财富是$98$。谷底是$70$，而最大回撤是$70/110 - 1 = -4/11 \approx -0.363636$。

在这条路径上，熔断器使最大回撤更浅，$-0.20$而不是$-4/11$，也使期末财富更低，$88$而不是$98$。它把更深的下跌与反弹一起跳过了。一个转入现金的冷却期做的就是这件事。它既不是支持熔断器、也不是反对熔断器的一个结果。

假如资产路径停在$70$，没有反弹，同一个触发会把熔断器留在$88$，而持仓账簿留在$70$。财富的排名会翻面，而回撤的排名仍然会偏向熔断器。财富差距的符号是路径依赖的。一个玩具选不出一条政策。沿着持仓路径的简单收益率是$0.10$、$-0.10$、$-1/9$、$-9/44$与$0.40$，来自价格比率$110/100$、$99/110$、$88/99$、$70/88$与$98/70$。从$100$到$98$的复合是$-0.02$。从$100$到$88$的复合是$-0.12$。
:::
:::

:::warning 门槛不是已实现的回撤
熔断器的规格写的是$15\%$，而玩具在触发那根K线上的已实现回撤是$20\%$。只在K线收盘时刻检查，允许了超出。反方向在发表的摘要里也会出现：一个已报告的最大回撤可以是比规则里写明的门槛更小的数字，因为那两个百分比未必是同一个对象。不要把一个目录单元"改正"成与规则名字里的门槛一致。
:::

## 四行目录

这一节的数字**是按quants.md对那个QuantJourney示例（Apache-2.0）的报告，按2026年的阅读**。本图谱**没有**重跑过这些回测。已报告的夏普比率是他们的数字，不是[[performance/sharpe-and-its-relatives]]里的那个每步比率。

W02，"Monthly Drift ETF"，是一个ETF上的SMA$(50/200)$趋势，在月末，带一条$5\%$的漂移带。多资产，日K线，$19$年。已报告总收益率$+138\%$、年化复合增长率$+4.66\%$、夏普比率$0.31$、最大回撤$-19.4\%$、胜率$63.5\%$、盈亏比$1.73$。那条带子是五个百分点的权重，按[[#def-band]]的意义——前提是那份实现与这个说法的通常读法一致。那一行没有印出代码。月末加上一条带子是两条约束：日历可以拒绝查看，而查看了，带子也可以拒绝交易。W02不是"那个"移动平均结果。信号与其他行共享；对交易的约束不共享。

W12，"Daily Partial Drift"，是一个动量倾斜，只在名字越过$10\%$漂移带时才交易它们。日K线，$26$年。已报告总收益率$+269\%$、年化复合增长率$+5.15\%$、夏普比率$0.30$、最大回撤$-36.8\%$、胜率$68.2\%$、盈亏比$1.62$。一条$10\%$的带子会让[[#ex-drift]]里的那个差距不做交易，因为$0.07$并不大于$0.10$。同一个差距会在W02的$5\%$带子下交易，假如目标和漂移是那个例子里的——而它们不是：W02与W12是不同的样本池、不同的跨度与不同的信号。合法的比较只有一条：$0.05$与$0.10$是不同的门槛，而[[#ex-drift]]给出了一个坐在两者之间的差距。

W11，"Quarterly TE Cost Gate"，是一个带着跟踪误差触发与一份换手预算的动量。日K线，$19$年。已报告总收益率$+266\%$、年化复合增长率$+7.07\%$、夏普比率$0.44$、最大回撤$-25.5\%$、胜率$66.4\%$、盈亏比$2.67$。名字里的那两个对象都是对交易的约束，一如[[#def-te]]与[[#def-turnover]]。仪表盘没有印出跟踪误差门槛或预算。我们不替它们编造。已报告的年化复合增长率不是门槛会抬高年化复合增长率的证据。它是一份规格说明在一个样本上的结果。

W10，"Monthly Circuit Breaker"，是一个月度ETF趋势，在一个$15\%$回撤时把账簿压平为空仓，然后等过一段冷却期。日K线，$19$年。已报告总收益率$+14.2\%$、年化复合增长率$+0.70\%$、夏普比率$-0.45$、最大回撤$-10.6\%$、胜率$53.3\%$、盈亏比$1.11$。把夏普比率与回撤放在一起读。已报告的最大回撤，$-10.6\%$，是这一行上那个更浅的回撤数字，而已报告的夏普比率为负。熔断器做了回撤即空仓的规则被设计要去瞄准的事——一条已报告回撤并不深的路径——而那条路径上已报告的夏普比率是$-0.45$，在目录里那$19$年上的年化复合增长率是$+0.70\%$。一个更浅的回撤旁边坐着一个为负的夏普比率，这就是那一行的要点。它不是加一个熔断器的理由，也不是站到那条趋势规则另一边的理由。[[#ex-path]]里的玩具不是这个回测。它只显示了一个转入现金的冷却期如何能在一条写明的路径上砍掉一次回撤并放弃期末财富。我们同样不强迫$-10.6\%$等于$15\%$。规则里的门槛与仪表盘里的最大回撤都是已报告的；它们不是自动同一个测量。

:::intuition 约束能主导信号
两条动量规则共享一个排序公式，而差别在一条$10\%$的带子、一份换手预算或一个回撤冷却期上，那就是两个实验。一份报告里信号那一列，是作者们喜欢点名的部分。净值曲线真正改变的地方往往在约束上，因为约束决定了信号的那些交易里哪些被允许发生。当一条发表的路径看起来出奇地安静、或出奇地忙，带子与熔断器属于最先该重读的那几句话。[[backtesting/reading-published-tests]]把这个习惯变成一张清单。
:::

:::history
马科维茨（Markowitz）在1952年把组合选择陈述为在持有者实际承受得起的那些约束之下对权重做的一个优化：一个预算，并且常常是拒绝做空。一个假定权重在输入一动就被重置的方差公式，与一条只在越过一条带子时交易、只在一份换手预算之内交易、或在冷却期内根本不交易的规则，是两个不同的模型。漂移带与熔断器是后来的操作性约束。1952年那篇论文不包含它们，本章也不假装它包含。这个年份要紧，是因为决策变量已经是权重而不是信号，而对一笔交易的约束就是对这些权重跨时间的约束。
:::

:::quiz
一个风险权重从$0.40$漂移到$0.47$，而目标仍然是$0.40$。哪条带子会交易？
- [ ] $0.10$的带子，因为$0.47$比$0.40$高$17.5\%$。
- [ ] $0.10$的带子与$0.05$的带子都交易，因为任何差距都交易。
- [x] $0.05$的带子，而$0.10$的带子不交易，因为以权重单位计的差距是$0.07$。
- [ ] 都不交易，因为现金挣$0$。
:::solution
[[#def-band]]以权重为单位，把$\abs{0.47-0.40} = 0.07$与$b$比较。于是$0.07 > 0.05$，而$0.07$并不大于$0.10$。把$0.40$乘以$17.5\%$，是把一个相对价格变动与一个权重差距搞混了。制造那次漂移的那个收益率是$35/106$，约$0.330$，那又是第三个对象。
:::
:::

:::quiz
在[[#ex-path]]里，熔断器改变了什么？
- [ ] 它避开了从$110$到$88$的下跌，所以触发那根K线没有被感受到。
- [x] 它把期末财富留在$88$而不是$98$，把最大回撤留在$-0.20$而不是大约$-0.3636$。
- [ ] 它把期末财富抬到持仓路径之上，因为回撤规则会修复亏损。
- [ ] 它把回撤设成了恰好$-15\%$。
:::solution
到达$88$的那根K线是在冷却期开始之前全额挣下的。现金随后跳过了到$70$的那次变动与到$98$的那次变动。在这条特定的反弹路径上，期末财富相对持仓路径下跌了，而$70$处的谷底被跳过，所以最大回撤更浅。已实现的触发回撤是$-20\%$，不是$-15\%$，因为检查发生在K线收盘时刻。
:::
:::

## 通向何处

那些带子与熔断器作用在已经住在某个可行集里的权重向量上。[[portfolio/long-only-and-neutral]]写下那些向量从中取样的只做多单纯形与中性预算。一份换手预算同时是一个成本输入：一旦$\sum_i\abs{\Delta w_i}$已知，[[backtesting/timing-costs-and-biases]]就能把它变成一项拖累，而成本模型仍须写明。产生$w^\star$的信号可以是一个趋势权重或一个动量权重；无论哪种，漂移规则都是第二张映射，叠在[[portfolio/from-signal-to-weight]]的那张映射之上。

:::summary
- 若现金挣$0$且不交易，风险权重$w$变成$w(1+R)/(1+wR)$。一个正的收益率抬升一个严格在$0$与$1$之间的权重。
- 从$0.40$出发、收益率$35/106$的那一步在$0.47$收尾。差距$0.07$在$0.10$的带子里，在$0.05$的带子外。
- $0.10$的带子是十个百分点的权重，不是权重的百分之十。
- 本章的换手把每条腿上的绝对权重变动相加。从$0.47$恢复$0.40$在那个和里花掉$0.14$。一份$0.10$的预算在权重$0.42$处停下。
- 相对一个基准的事前跟踪误差是$\sqrt{(w-w^b)^{\mathsf T}\Sigma(w-w^b)}$。在单名字例子里它是$0.006$，而$0.01$处的门槛不交易。
- 熔断器在一次严格深于$d$的回撤之后把权重设为现金，持续一个冷却期。在路径$100,110,99,88,70,98$上，期末财富带熔断器是$88$、不带是$98$，而最大回撤是$-0.20$与$-4/11$。
- W10把夏普比率$-0.45$报在最大回撤$-10.6\%$旁边。那个更浅的回撤数字与那个为负的已报告夏普比率就是那行熔断器的要点，不是一条政策。
:::

## 习题

:::exercise 以权重单位计的差距 {level=1 check="0.07"}
一个权重从$0.40$漂移到$0.47$，而目标停在$0.40$。绝对差距是多少？（输入小数。）
:::solution
$\abs{0.47-0.40} = 0.07$。一条$0.10$的带子不把这看作一笔交易。一条$0.05$的带子会。
:::
:::

:::exercise 两条腿的完整换手 {level=1 check="0.14"}
风险权重从$0.47$移到$0.40$，现金取另一侧。使用绝对权重变动之和，换手是多少？（输入小数。）
:::solution
每条腿变动$0.07$。绝对变动之和是$0.14$，按[[#prop-two-turn]]即$2\times 0.07$。
:::
:::

:::exercise 单名字跟踪误差 {level=1 check="0.006"}
账簿权重$0.47$，基准权重$0.50$，波动率$0.20$，现金波动率$0$。事前跟踪误差是多少？（输入小数。）
:::solution
$\mathrm{TE} = \abs{0.47-0.50}\times 0.20 = 0.006$。一个$0.01$处的门槛不会交易。那个公式是[[#def-te]]的单名字退化形式，不是过去主动收益率的样本标准差。
:::
:::

:::exercise 套用漂移公式 {level=2 check="0.47"}
从风险权重$0.40$、现金收益率$0$、风险简单收益率$35/106$开始。漂移后的权重是多少？（输入小数。）
:::solution
$w' = 0.40\times(141/106) / (1 + 0.40\times 35/106) = 0.47$，一如[[#ex-drift]]里的化简。分数$282/600$约成$47/100$。
:::
:::

:::exercise 一次部分交易 {level=2 check="0.42"}
风险权重从$0.47$移到$0.40$的完整变动的换手是$0.14$，现金在另一侧。一份$0.10$的预算缩放了那次移动。被实现的风险权重是多少？（输入小数。）
:::solution
$\lambda = 0.10/0.14 = 5/7$。风险权重朝目标移动$(5/7)\times 0.07 = 0.05$，从$0.47$到$0.42$。现金变成$0.58$。预算用尽，而目标没有到达。
:::
:::

:::exercise 带熔断器的期末财富 {level=2 check="88"}
在[[#ex-path]]的路径上，熔断器在财富触及$88$时触发，而冷却期覆盖路径的其余部分。现金挣$0$。从$100$出发，期末财富是多少？（输入数字。）
:::solution
越界的那根K线是实打实挨的，所以财富是$88$。之后资产的变动，跌到$70$与涨到$98$，都没有接。期末财富是$88$。没有熔断器本会是$98$。
:::
:::

:::exercise 一个更干净的漂移 {level=3 check="1/3"}
风险权重从$1/4$开始。风险简单收益率是$1/2$。现金挣$0$，且不交易任何东西。漂移后的权重是多少？（输入分数。）
:::hint
使用$w(1+R)/(1+wR)$，取$w = 1/4$、$R = 1/2$。分母是$1 + (1/4)(1/2)$。
:::
:::solution
$$
w' = \frac{(1/4)\cdot(3/2)}{1 + (1/4)\cdot(1/2)} = \frac{3/8}{1 + 1/8} = \frac{3/8}{9/8} = \frac{3}{9} = \frac{1}{3}.
$$
权重从$1/4$升到$1/3$，因为风险腿上涨了，又没有削减它。差距是$1/3 - 1/4 = 1/12 \approx 0.0833$，一条$0.10$的带子会放着不交易，一条$0.05$的带子会交易。
:::
:::

:::exercise 恰好落在门槛上的财富 {level=3 check="93.5"}
历史峰值是$110$。从那个峰值恰好$15\%$的回撤对应什么净资产值？按[[#def-breaker]]，触发是严格的，所以这个值本身不会把账簿压平。（输入小数。）
:::hint
恰好$0.15$的回撤意味着$V/110 - 1 = -0.15$，于是$V = 0.85\times 110$。[[#ex-path]]里前一根K线是$99$，仍然在这个水平之上。
:::
:::solution
$V = (1-0.15)\times 110 = 0.85\times 110 = 93.5$。于是$D = 93.5/110 - 1 = -0.15$，它并不严格小于$-0.15$，所以熔断器的这个定义不开火。[[#ex-path]]里的路径从$99$跳到$88$，从不落在$93.5$上。那个超出，是连续检查与在K线收盘时刻检查之间的差别。从$99$出发，恰好落在$93.5$上的那个简单收益率是$93.5/99 - 1 = -11/198 \approx -0.055556$。从$99$出发的任何严格更差的收益率都在$93.5$之下收尾，都会触发。
:::
:::
