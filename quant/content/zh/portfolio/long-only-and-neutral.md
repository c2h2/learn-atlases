本课程里的每一张映射都落在一个允许权重的集合里。只做多权重住在一个单纯形里：不做任何空，而持仓要么相加为$1$，要么在允许现金时相加至多为$1$。一本美元中性的账簿相加为零，并把一份总敞口预算一起花在多头与空头身上。一本贝塔中性的账簿把贝塔的加权和压到零，那是另一条线。两个资产、两个不同的贝塔时，既美元中性又贝塔中性的唯一向量是零向量。想要总敞口为$1$，就得二选一。

一份中性预算是一个可行集。它不是一个要去建立的市场头寸，而把总敞口预算抬到$1$以上会把两侧一起放大。本章不建议这样做。

## 单纯形

:::definition 只做多权重 {#def-long}
风险名字上的一个权重向量$w$是**只做多、全额投资**的，当

$$
w_i \ge 0 \quad\text{对每个 } i, \qquad \sum_i w_i = 1.
$$

当$w_i \ge 0$且$\sum_i w_i \le 1$时它是**允许现金的只做多**，余额$1 - \sum_i w_i$是现金。这两个集合不同。全额投资拒绝余额。允许现金则容许一个余额。本章总会说明正在使用的是哪个集合。玩具里的现金挣$0$的简单收益率，那是一个建模选择，不是一种现金工具。
:::

全额投资的集合是一个单纯形。它的极点是那些单名字账簿：一个权重等于$1$，其余为$0$。等权是中心，不是极点。一张输出了集合之外向量的信号映射还没有做完。还有东西要做投影、截断或拒绝。

这里使用的约定是刻意而初等的。它不被声称是到单纯形上的欧几里得投影——那解的是一个不同的二次问题。

:::definition 截断并缩放 {#def-clip}
设$z$是一个期望向量。把每个负坐标替换成$0$，并把结果叫作$z^+$。设$s = \sum_i z^+_i$。若$s = 0$，该约定返回零风险向量。

- 全额投资，且$s > 0$：设$w = z^+/s$。于是$w_i \ge 0$且$\sum_i w_i = 1$。
- 允许现金：若$s > 1$，设$w = z^+/s$；若$0 \le s \le 1$，设$w = z^+$。于是$w_i \ge 0$且$\sum_i w_i \le 1$。

当$s > 1$时两张约定一致。当$0 < s < 1$时它们不一致：全额投资向上缩放，允许现金的不。
:::

:::example 全额投资对抗现金余额 {#ex-cash}
期望的风险权重是$(0.2,\ 0.3)$。按[[#def-clip]]构造全额投资的只做多向量与允许现金的向量。两个期望坐标本来都非负，且相加为$0.5$。
:::solution
这里$z^+ = z$而$s = 0.5$，它严格在$0$与$1$之间。

全额投资除以$s$：

$$
w^{\mathrm{full}} = \bigl(0.4,\ 0.6\bigr).
$$

现金权重$0$。这些权重的下一个收益率贡献是$0.4\,R_1 + 0.6\,R_2$。

允许现金保留期望向量，因为$s \le 1$：

$$
w^{\mathrm{cash}} = \bigl(0.2,\ 0.3\bigr),
$$

现金权重$0.5$挣$0$。下一个收益率贡献是$0.2\,R_1 + 0.3\,R_2$，每当现金挣$0$时，它恰好是全额投资贡献的一半。向上缩放就是全部的差别。它不是对这两个名字的一个观点。一个写着"只做多"却不说明相加是$1$还是至多$1$的规格说明，把这个因子留成了自由的。
:::
:::

:::example 一个负坐标 {#ex-clip}
期望向量是$(-0.2,\ 0.5,\ 0.7)$。对全额投资的集合施加[[#def-clip]]。
:::solution
负坐标变成$0$。正部$(0,\ 0.5,\ 0.7)$相加为$1.2$。因为$s > 1$，全额投资与允许现金一致：

$$
w = \bigl(0,\ \tfrac{0.5}{1.2},\ \tfrac{0.7}{1.2}\bigr) = \bigl(0,\ \tfrac{5}{12},\ \tfrac{7}{12}\bigr).
$$

期望向量里的那个空头不在账簿里。期望向量的总敞口是$0.2+0.5+0.7 = 1.4$；$w$的总敞口是$1$。那是不同的敞口。保留$-0.2$会是美元中性的地盘，或一张多空映射，而不是这个可行集。
:::
:::

## 净零不是贝塔零

这里的**美元中性**意味着权重相加为零。"美元"一词是约定。它指一单位的净资产值，不是一种货币，也不是把现金持在某种特定货币里的建议。

:::definition 美元中性与总敞口 {#def-dollar}
当$\sum_i w_i = 0$时，向量$w$是**美元中性**的。一份**总敞口预算**$g > 0$添加$\sum_i \abs{w_i} = g$。对两个名字与$g = 1$，解为

$$
\bigl(\tfrac12,-\tfrac12\bigr) \qquad\text{且}\qquad \bigl(-\tfrac12,\tfrac12\bigr).
$$

净敞口是$0$。总敞口是$1$。两个向量是相反的朝向。一份预算$g > 1$把任一向量乘以$g$，并在零利率记账里把多头与空头的支付都按$g$放大。那是杠杆。本图谱不建议总敞口超过$1$。算过的数字使用$g = 1$。
:::

贝塔中性需要一张贝塔列表，每个名字一个，在权重之前固定下来。一个贝塔可以是这个名字的简单收益率对一个写明因子的回归系数，在一个写明的窗口上估计。[[statistics/regression-on-a-signal]]就是那个回归。本章把这些数当作输入。

:::definition 贝塔中性 {#def-beta}
给定贝塔$\beta_i$，当

$$
\sum_i w_i\beta_i = 0
$$

时，向量$w$是**贝塔中性**的。美元中性不蕴含这个，而这个也不蕴含美元中性，除非所有贝塔都相等。
:::

:::proposition 两条约束，只有零账簿 {#prop-only-zero}
设两个名字的贝塔为$\beta_1 \ne \beta_2$。

$$
w_1 + w_2 = 0, \qquad \beta_1 w_1 + \beta_2 w_2 = 0
$$

的唯一解是$(w_1,w_2) = (0,0)$。特别地，不存在总敞口为$1$的既美元中性又贝塔中性的两名字账簿。
:::

:::proof
系数矩阵是

$$
\begin{pmatrix} 1 & 1 \\ \beta_1 & \beta_2 \end{pmatrix},
$$

其行列式为$\beta_2 - \beta_1 \ne 0$。一个行列式非零、右端为零的方阵方程组只有零解。零向量的总敞口是$0$，不是$1$。添加一个总敞口约束不会给那两个线性方程造出新解；它只是把零向量排除在外。于是对两个贝塔不同的名字，三条要求合起来是空的。

若贝塔相等，第二个方程就是第一个方程乘以$\beta$，而每个美元中性的向量都是贝塔中性的。正是不同的贝塔使两条直线只在原点相交。
:::

所以一本两名账簿可以在总敞口为$1$时美元中性，也可以在总敞口为$1$时贝塔中性，但它不能两者都是。下一条命题选定贝塔中性线与总敞口。

:::proposition 总敞口为一的贝塔中性 {#prop-beta-gross}
设$\beta_1 > 0$，$\beta_2 > 0$。

$$
w_1 - w_2 = 1, \qquad \beta_1 w_1 + \beta_2 w_2 = 0
$$

的唯一解是

$$
w_1 = \frac{\beta_2}{\beta_1+\beta_2}, \qquad w_2 = -\frac{\beta_1}{\beta_1+\beta_2}.
$$

于是$w_1 > 0 > w_2$，总敞口是$w_1 - w_2 = 1$，净敞口是$(\beta_2-\beta_1)/(\beta_1+\beta_2)$，而贝塔是$0$。相反的朝向$-w$是$w_2 - w_1 = 1$与同一个贝塔方程合起来的唯一解。它同样有总敞口$1$与贝塔$0$，而它的净敞口是上面那个净敞口的相反数。
:::

:::proof
$\begin{pmatrix} 1 & -1 \\ \beta_1 & \beta_2 \end{pmatrix}$的行列式是$\beta_1 + \beta_2 > 0$，所以存在唯一解。把$w_1 = 1 + w_2$代入贝塔方程给出

$$
\beta_1(1+w_2) + \beta_2 w_2 = 0, \qquad \beta_1 + (\beta_1+\beta_2)w_2 = 0,
$$

于是$w_2 = -\beta_1/(\beta_1+\beta_2)$，而$w_1 = 1 + w_2 = \beta_2/(\beta_1+\beta_2)$。因为$w_2 < 0$，总敞口是$w_1 + \abs{w_2} = w_1 - w_2 = 1$。贝塔按第二个方程为零。把两个权重都取负保持了贝塔方程，翻转了$w_1 - w_2$的符号，并保持了总敞口。同样的行列式论证给出那个翻转朝向的唯一性。
:::

方程$w_1 - w_2 = 1$是写成线性方程的总敞口预算，而它之所以是线性的，只是因为我们已经选定了符号。绝对值约束$\abs{w_1}+\abs{w_2} = 1$是两段线性片段，不是一段。[[#prop-beta-gross]]解的是其中一段。[[#def-dollar]]里美元中性的那一对是另一段常见的，即$w_1 + w_2 = 0$加上$w_1 - w_2 = 1$。

:::example 美元中性，贝塔为$1.2$与$0.8$ {#ex-dollar}
贝塔是$1.2$与$0.8$。取总敞口为$1$的两个美元中性朝向。计算每本账簿的贝塔$\sum_i w_i\beta_i$。
:::solution
两个朝向是$(1/2,-1/2)$与$(-1/2,1/2)$。

$$
\tfrac12\cdot 1.2 + \bigl(-\tfrac12\bigr)\cdot 0.8 = 0.6 - 0.4 = 0.2,
$$

$$
\bigl(-\tfrac12\bigr)\cdot 1.2 + \tfrac12\cdot 0.8 = -0.6 + 0.4 = -0.2.
$$

两种情形下净敞口都是$0$、总敞口都是$1$，而两个贝塔都不是$0$。美元中性没有对冲那个因子。贝塔的绝对值$0.2$是$1.2$与$0.8$之间差距的一半，那是做多第一个名字的朝向的一般两名字模式$(\beta_1-\beta_2)/2$。这个方程组通过用Python解$w_1+w_2 = 0$、$w_1-w_2 = 1$核对过：解是$(1/2,-1/2)$。
:::
:::

:::example 总敞口为一的贝塔中性 {#ex-beta}
同样的贝塔，$1.2$与$0.8$。解$w_1 - w_2 = 1$与$1.2\,w_1 + 0.8\,w_2 = 0$。然后写出相反的朝向。对每一本，记下净敞口、总敞口与贝塔。
:::solution
[[#prop-beta-gross]]取$\beta_1 = 6/5$、$\beta_2 = 4/5$给出

$$
w_1 = \frac{4/5}{2} = \frac{2}{5}, \qquad w_2 = -\frac{6/5}{2} = -\frac{3}{5}.
$$

消元法到达同一点。从$w_1 - w_2 = 1$与$(6/5)w_1 + (4/5)w_2 = 0$的增广矩阵出发：

$$
\begin{pmatrix} 1 & -1 & 1 \\ 6/5 & 4/5 & 0 \end{pmatrix}.
$$

从第二行减去第一行的$(6/5)$倍。第二行变成$(0,\ 2,\ -6/5)$，因为$4/5 - (6/5)(-1) = 2$而$0 - 6/5 = -6/5$。于是$w_2 = (-6/5)/2 = -3/5$，而$w_1 = 1 + w_2 = 2/5$。Python对同一个$2\times 2$方程组的解一致。

净敞口是$2/5 - 3/5 = -1/5 = -0.2$。总敞口是$2/5+3/5 = 1$。贝塔是

$$
\tfrac25\cdot 1.2 + \bigl(-\tfrac35\bigr)\cdot 0.8 = 0.48 - 0.48 = 0.
$$

相反的朝向是$(-2/5,\ 3/5)$。净敞口是$+0.2$，总敞口是$1$，贝塔是$0$。

对照[[#ex-dollar]]。总敞口为$1$的美元中性留下了$\pm 0.2$的贝塔与$0$的净敞口。总敞口为$1$的贝塔中性留下$0$的贝塔与$\pm 0.2$的净敞口。四个向量是四本不同的账簿。[[#prop-only-zero]]说，从这一对贝塔里收齐净敞口$0$、贝塔$0$与总敞口$1$的第五个向量不存在。
:::
:::

那四本账簿容易混淆，因为好几个汇总数字是$0$、$1$或$0.2$。一个期间的收益率就把它们分开。设下一个简单收益率是第一个名字$0.05$、第二个名字$0.01$。现金，在只做多余额用到它的地方，挣$0$。这里没有任何一本是受青睐的账簿。

- 美元中性、做多第一个名字，$(1/2,-1/2)$：组合收益率$\tfrac12\cdot 0.05 + (-\tfrac12)\cdot 0.01 = 0.025 - 0.005 = 0.020$。账簿的贝塔是$0.2$，净敞口是$0$。
- 美元中性，另一个方向，$(-1/2,1/2)$：同样的算术、符号翻面，所以组合收益率是$-0.020$。
- 贝塔中性，$(2/5,-3/5)$：$\tfrac25\cdot 0.05 + (-\tfrac35)\cdot 0.01 = 0.020 - 0.006 = 0.014$。账簿的贝塔是$0$，净敞口是$-0.2$。
- 相反的贝塔中性账簿挣$-0.014$。
- 一本只是持有$(1/2,1/2)$的全额投资只做多账簿，对[[#def-long]]是合法的，也不是那些中性解之一，挣$\tfrac12\cdot 0.05 + \tfrac12\cdot 0.01 = 0.030$。它的贝塔是$\tfrac12\cdot 1.2 + \tfrac12\cdot 0.8 = 1.0$，而它的净敞口是$1$。

五个合法向量，五个组合收益率：$0.020$、$-0.020$、$0.014$、$-0.014$与$0.030$。信号甚至不在这张列表里。可行集与朝向就足以改变符号和大小。这就是约束能够主导信号的意义：信号可能选定了一个方向，而可行集可能把那个方向扔掉了，正如[[#ex-clip]]对坐标$-0.2$所做的那样。

总敞口超过$1$与波动率目标的缩放因子超过$1$是同一个机制。在零利率记账里，把$(1/2,-1/2)$翻倍成$(1,-1)$会把组合收益率翻倍——在这些下一个收益率上从$0.020$到$0.040$——并把同一形态的亏损从$-0.020$翻倍成$-0.040$。两侧都在动。在做放大这件事的是总敞口预算，不是对这些名字的一个新观点。本章的例子保持总敞口等于$1$，不建议那本翻倍的账簿。空头上的融资成本，或借入现金上的融资成本，会再次改变翻倍后的数字；规格说明必须说出这一点，而这一段不提供那个成本。

作为输入使用的一个贝塔，只和产生它的那个回归一样稳定。一个不同的窗口，或一个不同的因子，产生一个不同的$\beta$，因此产生[[#prop-beta-gross]]的一个不同的解。两个都写着"贝塔中性、总敞口一"却带着不同贝塔前来的研究者，跑的不是同一个约束。[[#ex-beta]]里的$1.2$与$0.8$是选来让算术闭合的。它们不是任何点名证券的估计贝塔，也不是用一个名字去对冲另一个名字的建议。

那个小部件对贝塔中性方程组做行化简。那条线把右端分开。一步步走完，结束于$2/5$与$-3/5$。

:::widget rowreduce
matrix: 1,-1,1; 6/5,4/5,0
caption: 方程组$w_1 - w_2 = 1$、$(6/5)w_1 + (4/5)w_2 = 0$，贝塔为$1.2$与$0.8$，朝向是做多较高的那个贝塔。化简结束于$w_1 = 2/5$、$w_2 = -3/5$。那是一个约束的线性代数，不是一个要去建立的对冲。
:::

:::warning 美元中性不是贝塔中性
差错在于听到"市场中性"，核对权重相加为零，然后停下。在[[#ex-dollar]]里，权重$(1/2,-1/2)$相加为零，而当贝塔是$1.2$与$0.8$时它们的贝塔仍然是$0.2$。账簿的贝塔是$0.2$，做多那个因子，不是零。想要$\sum w_i\beta_i = 0$的读者并没有得到它。反过来的差错是因为贝塔为零，就把$-0.2$的净敞口叫作"空仓"。净敞口与贝塔是不同的线性泛函。[[#prop-only-zero]]就是一个数无法为两个名字同时干这两份活的原因。
:::

:::intuition 总敞口是规模，净敞口是倾斜
在$(2/5,-3/5)$上，总敞口是$1$而净敞口是$-1/5$。总敞口是预算花掉的绝对敞口。净敞口说空头比多头大，大净资产值的五分之一。若加权的贝塔要化为零，那种不均衡正是不相等的贝塔所要求的：较高的贝塔$1.2$以绝对权重$2/5$持有，较低的贝塔$0.8$以绝对权重$3/5$持有。那些绝对权重的比率是$(3/5)/(2/5) = 3/2$，也就是$\beta_1/\beta_2$。它是一个约束之内的对冲比率。它不是一个第二个名字会下跌的预测。
:::

:::application 一本配对账簿坐在哪里
[[reversion/pairs-and-spreads]]里的一条配对规则，是一份总敞口预算与一个接近零的净敞口一起出现的一种方式：多一个名字，空另一个，常常带着一个从价格估计出的对冲比率。本章不估计那个比率，也不引述一个配对回测。它只点名权重必须落进的那个可行集。美元中性是那个净敞口约束。当两个贝塔是输入、而不是一个回归对冲——或除了回归对冲之外——贝塔中性就是可用的。[[#prop-only-zero]]说，如果贝塔不同，把两条约束同时施加在两个名字上只留下零账簿。一个声称两者都满足的配对规格说明应当被仔细读：要么一条约束是软的，要么名字多于两个，要么贝塔相等。
:::

:::history
夏普（Sharpe）1964年的资本资产定价模型提供了单因子贝塔：在那篇论文的假设之下，一项资产的超额收益对市场超额收益的斜率。一个贝塔中性约束把这样一些贝塔的加权和设为零。那个模型是可以施加在一个权重向量上的一条约束。它不是一个你必须完全相信的描述，也不是对那个市场组合的一条推荐。Qian、Hua与Sorensen在他们2007年关于量化股票组合管理的书里，把同一套约束语言——只做多集合、风险模型、预算——展开到一份规格说明所需要的层面。点名那本书不是对书中某个组合的背书。
:::

:::quiz
贝塔是$1.2$与$0.8$，权重是$(1/2,-1/2)$。哪个说法是对的？
- [ ] 账簿是贝塔中性的，因为权重相加为$0$。
- [x] 账簿是美元中性的、总敞口为$1$，而它的贝塔是$0.2$，不是$0$。
- [ ] 账簿是只做多的，因为第一个权重是正的。
- [ ] 总敞口是$0$，因为权重相互抵消。
:::solution
净敞口是$1/2-1/2 = 0$，所以账簿是美元中性的。总敞口是$1/2+1/2 = 1$。贝塔是$0.5\times 1.2 - 0.5\times 0.8 = 0.2$。第二个权重是负的，所以账簿不是只做多的。抵消影响的是净敞口，不是总敞口。
:::
:::

:::quiz
为什么不存在一个两名字账簿，在这些贝塔之下同时做到美元中性、贝塔中性与总敞口$1$？
- [ ] 因为总敞口$1$大于两个贝塔。
- [ ] 因为$1.2$与$0.8$都是正的，而贝塔中性需要在输入列表里有某个负的贝塔。
- [x] 因为当贝塔不同时，两个线性约束只有零解，而零解的总敞口是$0$。
- [ ] 因为单纯形不包含空头。
:::solution
[[#prop-only-zero]]：行列式$\beta_2-\beta_1 = -0.4$不是零，所以核是平凡的。总敞口$1$于是把唯一的线性解排除在外。只要贝塔中性是可能的，在权重$(2/5,-3/5)$与相反朝向处。只要美元中性也是可能的，在$(1/2,-1/2)$与相反朝向处。输入里不需要包含负的贝塔；负号由权重来携带。
:::
:::

## 通向何处

[[asset-classes/market-neutral-books]]把这些可行集带进特定的工具，在那里总敞口预算会遇到合约大小与本章忽略掉的借券约束。进入单纯形或中性线的权重仍然必须来自一张映射：信号在[[portfolio/from-signal-to-weight]]，而如果一张映射在约束起作用之前把方差贡献拉平，那张映射在[[portfolio/risk-parity]]。一个上限、一条带子或一个熔断器随后可以再削减那个向量；那些削减在[[portfolio/drift-turnover-and-breakers]]，而它们不在乎交易前的向量是否是中性。

:::summary
- 只做多、全额投资：权重非负且相加为$1$。允许现金的只做多：非负且相加至多为$1$。余额挣$0$只是因为玩具这么说。
- 期望的$(0.2,0.3)$在必须相加为$1$时变成$(0.4,0.6)$，在允许余额时保持$(0.2,0.3)$并带着$0.5$的现金。
- 截断并缩放把$(-0.2,0.5,0.7)$送到$(0,5/12,7/12)$。期望里的那个空头不在只做多的账簿里。
- 美元中性意味着权重相加为$0$。在总敞口$1$时，两名字的解是$(\pm 1/2,\mp 1/2)$。贝塔为$1.2$与$0.8$时，那些账簿的贝塔是$\pm 0.2$。
- 贝塔中性意味着$\sum w_i\beta_i = 0$。在总敞口$1$、做多较高的贝塔的朝向下，解是$(2/5,-3/5)$。净敞口是$-1/5$，贝塔是$0$。相反的朝向是$(-2/5,3/5)$。
- 如果两个贝塔不同，美元中性与贝塔中性合起来强迫零向量。总敞口$1$则不可能。
- 超过$1$的总敞口预算把两侧都相乘。例子保持总敞口$1$，不建议杠杆。
:::

## 习题

:::exercise 美元中性一对权重的净敞口 {level=1 check="0"}
权重是$(1/2,-1/2)$。净敞口是多少？（输入数字。）
:::solution
$1/2 + (-1/2) = 0$。账簿是美元中性的。总敞口不是$0$。
:::
:::

:::exercise 同一对的总敞口 {level=1 check="1"}
权重是$(1/2,-1/2)$。总敞口是多少？（输入数字。）
:::solution
$\abs{1/2}+\abs{-1/2} = 1$。净敞口是$0$而总敞口是$1$。这两个汇总并不矛盾。
:::
:::

:::exercise 美元中性账簿的贝塔 {level=1 check="0.2"}
权重$(1/2,-1/2)$，贝塔$1.2$与$0.8$。$\sum_i w_i\beta_i$是多少？（输入小数。）
:::solution
$0.5\times 1.2 + (-0.5)\times 0.8 = 0.6 - 0.4 = 0.2$。对这些贝塔，美元中性不意味着贝塔中性。
:::
:::

:::exercise 贝塔中性解里的空头 {level=2 check="-3/5"}
贝塔$1.2$与$0.8$。解$w_1 - w_2 = 1$与$1.2 w_1 + 0.8 w_2 = 0$。$w_2$是多少？（输入分数。）
:::solution
[[#prop-beta-gross]]给出$w_2 = -\beta_1/(\beta_1+\beta_2) = -1.2/2 = -3/5$。于是$w_1 = 2/5$。总敞口是$1$，净敞口是$-1/5$，贝塔是$0$。
:::
:::

:::exercise 留在桌上的现金 {level=2 check="0.5"}
期望的风险权重是$(0.2,0.3)$，两个为正。可行集是允许现金的只做多，使用[[#def-clip]]，而期望的和本来就在$1$之下。现金权重是多少？（输入小数。）
:::solution
正部的和是$0.5 \le 1$，所以风险权重保持$(0.2,0.3)$，而现金权重是$1-0.5 = 0.5$。全额投资的约定本会改为缩放到$(0.4,0.6)$。这个玩具里现金挣$0$，所以组合简单收益率是全额投资那本的一半。
:::
:::

:::exercise 截断之后 {level=2 check="7/12"}
期望权重是$(-0.2,0.5,0.7)$。把负数截断成$0$，并把其余重新缩放至相加为$1$。第三个名字上的权重是多少？（输入分数。）
:::solution
正部相加为$1.2$。第三个权重是$0.7/1.2 = 7/12$。第二个是$5/12$，第一个是$0$。
:::
:::

:::exercise 另一对贝塔 {level=3 check="1/4"}
贝塔是$1.5$与$0.5$。解$w_1 - w_2 = 1$与$1.5 w_1 + 0.5 w_2 = 0$。$w_1$是多少？（输入分数。）
:::hint
或者使用[[#prop-beta-gross]]里的$w_1 = \beta_2/(\beta_1+\beta_2)$，或者把$w_2 = w_1 - 1$代入贝塔方程。两个贝塔都是正的，所以解的总敞口自动是$1$。
:::
:::solution
$w_1 = 0.5/(1.5+0.5) = 0.5/2 = 1/4$。于是$w_2 = -1.5/2 = -3/4$。核对朝向：$1/4 - (-3/4) = 1$。核对贝塔：$1.5\times(1/4) + 0.5\times(-3/4) = 0.375 - 0.375 = 0$。总敞口是$1$，净敞口是$1/4-3/4 = -1/2$。与正文里相同的警告在这里同样适用：这是一个线性方程组的一个可行点，不是一个要去建立的对冲。
:::
:::

:::exercise 只有原点 {level=3 check="-0.4"}
贝塔$1.2$与$0.8$。美元中性与贝塔中性方程组的行列式$\det\begin{pmatrix} 1 & 1 \\ 1.2 & 0.8 \end{pmatrix}$是多少？（输入小数。）
:::hint
$\begin{pmatrix} a & b \\ c & d \end{pmatrix}$的行列式是$ad-bc$。这里那是$1\times 0.8 - 1\times 1.2$。行列式非零意味着只有零向量满足两个方程。
:::
:::solution
$1\times 0.8 - 1\times 1.2 = 0.8 - 1.2 = -0.4$。行列式不是零，所以[[#prop-only-zero]]适用：唯一的公共解是$(0,0)$，它的总敞口是$0$。对这两个贝塔，不存在既美元中性又贝塔中性、总敞口为$1$的账簿。行列式的符号取决于行的次序；绝对值$0.4$是$\abs{\beta_1-\beta_2}$。
:::
:::
