一条均线交叉、一个动量排名和一个RSI门槛是三个不同的故事，而它们是同一类对象。每一个都在给定的日子给一个名字附上一个数。那个数就是**信号**。组合拿不住信号。组合拿住的是**权重**：占净资产值的一个目标比例。从前者到后者的那一步是一张映射，而映射有它自己的参数。两个研究者可以在每个符号上达成完全一致，却依然在跑不同的账簿，因为他们选了不同的映射。

本课程余下的部分研究一张张具体的映射——逆波动率、波动率目标、等风险贡献、漂移带、只做多约束、中性约束。本章固定这些映射共享的词汇。这套算术是一份规格说明，不是持有、买入或卖出任何证券、基金或策略的指令。

## 信号还不是持仓

固定一个决策时点$t$。把$P_{i,t}$记作在那个时刻使用的名字$i$的价格，并说出这个序列什么时候是复权收盘价。在$t$处结束的那个简单收益率是$R_{i,t} = P_{i,t}/P_{i,t-1} - 1$。一旦$P_{i,t}$已知，它就是已知的。它不是权重。

:::definition 信号 {#def-signal}
**信号**$s_{i,t}$是在时刻$t$附在名字$i$上的一个数，它是$t$时刻可得信息的函数。在这里的例子里，$s_{i,t}$通常是$\{-1,0,1\}$中的一个符号或一个实数分数。向量$s_t = (s_{1,t},\ldots,s_{n,t})$是整个样本池上的信号。信号不是持仓。
:::

:::definition 权重 {#def-weight}
**权重**$w_{i,t}$是在决策时点$t$占净资产值的名字$i$的一个目标比例。向量$w_t$是一个**组合**。**映射**是一条把信号向量变成权重向量的写明的规则$w_t = M(s_t)$。在$M$被写下来之前，$s_t$不决定$w_t$。
:::

现金允许是名字之一。当它没有被列出时，**现金权重**就是使列出的权重加上现金权重相加为$1$的那个余额，并且本章每个玩具里的这个余额都挣$0$的简单收益率。什么时候用它就说什么：一只债券、一张国库券或一个真实账户里一笔未投资的余额挣的都不是零，而本章并没有在它们之间做挑选。

:::definition 总敞口与净敞口 {#def-gross}
对一个权重向量$w$，

$$
G(w) = \sum_i \abs{w_i}, \qquad N(w) = \sum_i w_i.
$$

$G(w)$是**总敞口**。$N(w)$是**净敞口**。若现金权重被计入在内且各权重相加为$1$，净敞口就是$1$。总敞口与净敞口回答不同的问题：净敞口可以很小而总敞口很大，因为多头与空头在求和里相互抵消，却在绝对值之和里相互叠加。
:::

在$s_i = 1$的名字之间等权、其余留在现金里、总敞口为$1$，这是一张映射。按原始信号成比例、再缩放至总敞口为$1$，那是另一张。它们不是仅有的两张。无论用哪一张，任何使用都必须把它点出来。

:::algorithm 只做多等权 {#alg-long-only}
给定符号$s_i \in \{-1,0,1\}$与一个满足$0 \le g \le 1$的总敞口预算$g$：

1. 设$A = \{i : s_i = 1\}$为激活集，并设$m = \abs{A}$。
2. 若$m = 0$，把每个风险权重设为$0$，并把$1$的权重放在现金上。
3. 若$m \ge 1$，对$i \in A$设$w_i = g/m$，对每个其余的风险资产设$w_i = 0$。
4. 把现金权重设为$1 - g$。

输出是一个权重向量。在这张特定的映射下，$A$之外的名字的符号被丢掉：做空信号与空仓信号都变成零。
:::

:::proposition 总敞口为一的成比例映射 {#prop-proportional}
设$s \in \R^n$满足$\sum_i \abs{s_i} > 0$，并定义

$$
w_i = \frac{s_i}{\sum_j \abs{s_j}}.
$$

则$G(w) = 1$，且每当$s_i \ne 0$时，$w_i$与$s_i$同号。净敞口为$N(w) = \sum_i s_i \big/ \sum_j \abs{s_j}$，它等于$1$仅当每个非零信号都是正的。
:::

:::proof
把正常数$c = \sum_j \abs{s_j}$从两个求和里提出：

$$
G(w) = \sum_i \abs{s_i}/c = c/c = 1, \qquad N(w) = \sum_i s_i / c.
$$

若$s_i > 0$则$w_i > 0$，若$s_i < 0$则$w_i < 0$。当$\sum_i s_i = \sum_i \abs{s_i}$时净敞口等于$1$，而这恰好没有一个$s_i$为负时成立。
:::

[[#prop-proportional]]是一个归一化，不是一个关于期望收益率的观点。把分母换成$\sum_j s_j$，只要有一个信号为负或各信号相互抵消，它就会失败。把它换成$n$，总敞口就会取决于分数碰巧有多大。命题里的分母正是迫使总敞口为$1$的那一个。另一个总敞口预算$g$就是同一个向量乘以$g$。若$g > 1$，这个乘法就是杠杆：它把下面零利率记账里的盈利与亏损一起放大。本图谱不是在建议这样做。本章算过的映射保持$g = 1$或$g < 1$。

:::quiz
四个名字上的信号是$(1,1,0,-1)$。在映射被选定之前，哪个说法是对的？
- [ ] 每个信号为$1$的名字必须有权重$1$。
- [ ] 第四个名字必须做空，因为信号是$-1$。
- [x] 同一个信号向量与不止一个权重向量相容。
- [ ] 总敞口已经是$1$。
:::solution
信号不是权重。[[#alg-long-only]]把这个向量映到$(1/2,1/2,0,0)$。[[#prop-proportional]]把它映到$(1/3,1/3,0,-1/3)$。两张映射都是合法的规格说明。哪一个都不被符号本身蕴含，所以总敞口同样还没有被确定。
:::
:::

## 同样的符号，两本账簿

取$s = (1,1,0,-1)$。两个名字做多，一个空仓，一个做空。

:::example 同一个信号的两张映射 {#ex-two-maps}
对$s = (1,1,0,-1)$应用总敞口预算$g = 1$的[[#alg-long-only]]，再应用[[#prop-proportional]]。写出两个权重向量，以及各自的总敞口与净敞口。
:::solution
激活集有$m = 2$个名字。$g = 1$的只做多等权给出

$$
w^{\mathrm{L}} = \bigl(\tfrac12,\tfrac12,0,0\bigr).
$$

现金权重$1 - 1 = 0$。总敞口$1/2+1/2 = 1$。净敞口$1$。做空信号被换成了零。那是映射，不是一个隐藏的论断——说第四个名字不值得持有。

对成比例映射，$\sum \abs{s_i} = 3$，于是

$$
w^{\mathrm{P}} = \bigl(\tfrac13,\tfrac13,0,-\tfrac13\bigr).
$$

总敞口$1/3+1/3+1/3 = 1$。净敞口$1/3+1/3-1/3 = 1/3$。

两个向量在第一、第二与第四个坐标上不一致。同样的信号，不同的组合。净敞口之所以不同，是因为有一张映射拒绝做空。
:::
:::

那套算术里没有任何东西说哪张映射是合适的。一个研究规格必须挑定一张并守着它。在看到结果之后从$w^{\mathrm{L}}$改到$w^{\mathrm{P}}$，是第二个实验，不是一条脚注。

不是符号的分数也需要同样的那句话。在归一化被写明之前，分数$2$并不是分数$1$的"两倍做多"。

:::example 不是符号的分数 {#ex-scores}
设$z = (2,-1,1/2)$。构造成比例的总敞口$1$权重。然后构造只做多权重：把每个负分数设为$0$，并把剩下的正分数重新归一化至相加为$1$。
:::solution
绝对分数之和是$2 + 1 + 1/2 = 7/2$。[[#prop-proportional]]给出

$$
w^{\mathrm{P}} = \frac{2}{7/2},\ \frac{-1}{7/2},\ \frac{1/2}{7/2} = \bigl(\tfrac47,-\tfrac27,\tfrac17\bigr).
$$

总敞口$4/7+2/7+1/7 = 1$。净敞口$(4-2+1)/7 = 3/7$。

只做多约定把中间的分数丢掉。正部是$(2,0,1/2)$，它的和是$5/2$。除以这个和，

$$
w^{\mathrm{L}} = \bigl(\tfrac{2}{5/2},\ 0,\ \tfrac{1/2}{5/2}\bigr) = \bigl(\tfrac45,0,\tfrac15\bigr).
$$

又是两个向量不同。成比例的账簿做空第二个名字。只做多的账簿一点都不持有它，并且往第一个名字上压得更多，因为空头不再占用任何总敞口预算。
:::
:::

:::intuition 激活集是一个参数
等权看起来好像不含任何选择。它含。选择就是激活集，还有总敞口预算。开着两个名字时，$g = 1$的[[#alg-long-only]]给每个名字$1/2$的权重。开着四个名字时，每个得到$1/4$。每个名字上的信号可以仍然是"做多"。权重动了，是因为名字的数目动了。一条往样本池里加名字的规则会改变其他每一个权重，即使没有任何符号翻转。
:::

那张图画的就是这个依赖关系，此外什么都不画。它不是一个价格，也不是一个被推荐的持仓数目。

:::widget plot

## 权重挣的是什么

日期为$t$的权重是在截至$t$的价格已知时选定的。那些价格已经挣出的收益率是$R_{i,t}$。在那段收益率期间，权重并不在场。在$t$与$t+1$之间，若账簿按兵不动，名字$i$贡献$w_{i,t}$乘以下一个简单收益率。

:::proposition 合法的乘积 {#prop-clock}
假设：决策价格$P_{i,t}$在$t$已知；简单收益率$R_{i,t} = P_{i,t}/P_{i,t-1}-1$用到那个价格；权重$w_{i,t}$可以依赖$t$时刻可得的信息，包括$P_{i,t}$；在$t+1$之前没有进一步的交易；而不在向量里的名字不挣任何东西。那么账簿从$t$到$t+1$的简单收益率为

$$
R_{p,t+1} = \sum_i w_{i,t}\, R_{i,t+1},
$$

其中$R_{i,t+1} = P_{i,t+1}/P_{i,t} - 1$。乘积$\sum_i w_{i,t}\, R_{i,t}$把一段在$w_{i,t}$被选定之时就已经走完的变动记入了贷方。
:::

:::proof
在决策价格$P_{i,t}$与下一个价格$P_{i,t+1}$之间的区间上，有净资产值的一个比例$w_{i,t}$持在名字$i$里。按简单收益率的定义，这个比例的简单收益率就是$R_{i,t+1}$。对名字求和就给出$R_{p,t+1}$，因为权重是同一个净资产值的比例，并且在这个模型里，挣这个区间的权重正是区间开始时选定的权重。

收益率$R_{i,t}$等于$P_{i,t}/P_{i,t-1}-1$。那两个价格在时刻$t$都已经固定。乘以$w_{i,t}$并没有描述一个$w_{i,t}$曾经在场的区间，除非有一条单独的规则已经在$t-1$设下同一个权重。若$w_{i,t}$内部的信号用到了$P_{i,t}$，那么$\sum_i w_{i,t} R_{i,t}$还用上了它自称挣得的那段收益率的期末价格。那是前视，不是更精确的回测。这个时钟与[[markets/systematic-question]]里的是同一个：$t$时刻的信息，$t$之后的支付。
:::

在单个名字上，[[#alg-long-only]]的只做多符号映射是具体的。当$R_t > 0$时令$s_t = 1$，否则令$s_t = 0$，并设$w_t = s_t$。那么$w_t$挣$R_{t+1}$，或在信号空仓时挣$0$。带符号的映射$w_t = \operatorname{sign}(R_t)$，用$+1$或$-1$而从不用$0$，就是[[#prop-proportional]]作用在一个一维非零信号上：总敞口为$1$，符号被保留。路径A是图谱共用的玩具价格路径，不是市场。

:::example 路径A在两张映射之下 {#ex-path-a}
路径A的价格是$100, 102, 101, 104, 103, 107, 106, 110$。简单收益率四舍五入到六位小数为$0.020000$、$-0.009804$、$0.029703$、$-0.009615$、$0.038835$、$-0.009346$、$0.037736$。使用刚观察到的那个收益率的符号，构造只做多权重与带符号的总敞口$1$权重，各自挣下一个收益率，现金收益率为$0$。把两本账簿都复合起来。第一个收益率没有对应的信号，而最后一个收益率是一个后面没有收益率的信号。
:::solution
把收益率编号为$R_1,\ldots,R_7$。只做多权重$w_t = 1$当$R_t > 0$，否则为$0$，它对$t = 1,\ldots,6$挣$R_{t+1}$。那个范围内的正收益率是$R_1$、$R_3$与$R_5$，而它们各自的下一个收益率都是负的。因此这本账簿挣的是$R_2$、$R_4$与$R_6$，而在三次下跌之后的那三步上挣$0$。把精确的毛价格比率相乘，

$$
\frac{101}{102}\cdot\frac{103}{104}\cdot\frac{106}{107} = \frac{551359}{567528} \approx 0.971510.
$$

六位小数的复合简单收益率为$0.971510 - 1 = -0.028490$。六位小数的收益率复现出同样的六位小数。

带符号权重是$w_t = \operatorname{sign}(R_t)$。它带着多头迎向那三次下跌中的每一次，又带着空头迎向紧跟在下跌之后的那三次上涨中的每一次。六个毛因子是$101/102$、$98/101$、$103/104$、$99/103$、$106/107$与$51/53$。它们的乘积是$4851/5564 \approx 0.871855$，于是六位小数的复合简单收益率为$-0.128145$。

两个数字都是亏损。路径A在交替，所以在这条特定的路径上，最后一个收益率的符号是对下一个收益率的一个糟糕的描述。这一对的要点不是亏损的符号。要点是亏损彼此不同：$-0.028490$对$-0.128145$。信号——"最后一个收益率的符号"——没有决定复合收益率。映射决定了它。七个步子不是关于趋势的证据，也不是偏爱某一张映射的理由。[[trend/the-trend-hypothesis]]才是那个假说被陈述的地方。
:::
:::

不看任何路径，一步就足以看到这个同样的分裂。

:::example 一步，两个名字 {#ex-one-period}
信号是$(1,-1)$。接下来的简单收益率是$0.02$与$-0.01$。现金挣$0$。计算总敞口为$1$的只做多等权之下、以及成比例的总敞口$1$映射之下的组合简单收益率。
:::solution
只做多只保留第一个名字：$w^{\mathrm{L}} = (1,0)$。组合收益率是$0.02$。

成比例映射除以$\abs{1}+\abs{-1} = 2$，所以$w^{\mathrm{P}} = (1/2,-1/2)$。组合收益率是

$$
\tfrac12\cdot 0.02 + \bigl(-\tfrac12\bigr)\cdot(-0.01) = 0.010 + 0.005 = 0.015.
$$

同样的信号，同样的下一个收益率，两个组合收益率。第二本账簿并不是本章认可意义上的"把信号用得更充分"。它是另一种敞口：总敞口$1$、净敞口$0$，而不是总敞口$1$、净敞口$1$。
:::
:::

:::warning 符号不是头寸
差错在于把$s_i = 1$读作"持有这个名字"、把$s_i = -1$读作"做空这个名字"，而不再做任何算术。那个读法偷带了一张映射：单个名字上的总敞口$1$，或者总敞口$1$以某种未言明的方式摊到许多名字上。[[#ex-two-maps]]就是反例。把激活集、总敞口预算与归一化写进与信号同一句话里。
:::

## 开放库里的一行权重

开放库把权重模式的研究与订单模式的研究分开。在权重模式里，规则的输出是一个目标权重，不是一张订单。W01，"Daily SMA Trend"，就是这样一条规则：只要$50$日均值高于$200$日均值，就持有每只行业交易所交易基金，每日再平衡。两个均值的比较是每个名字上一个$\{0,1\}$里的信号。映射是属于[[#alg-long-only]]一族的多头或现金，其总敞口取决于开着多少个名字。每日再平衡是第三个选择。它不被那两个均值蕴含。那条规则被报告的路径属于[[trend/moving-averages]]，这里不复述。点名这条规则，不是持有一只行业交易所交易基金的建议，也不是每日再平衡的建议。

本章从那一条目录行需要的只是这个分离。后来引述一次权重回测的读者，引述的是一个信号、一张映射和一个再平衡时钟。把映射丢掉，或者把映射换掉，产出的是一个不同的实验。[[backtesting/weights-versus-orders]]从另一侧讲同一个分离：订单同样不是权重。

:::remark 现金是一个权重
一本"离场"的账簿仍然有一个权重向量。在这里的玩具里，余额挣$0$，所以空仓在复合乘积里贡献因子$1$。那是一个建模选择，它的用处在于让算术可见。它不是对任何现金工具的描述。若余额挣一个非零利率，每个空仓期间都会乘以那个利率，而[[#ex-path-a]]会改变。规格说明必须说出它用了哪个利率。
:::

:::quiz
在[[#ex-one-period]]里，为什么成比例账簿的收益率是$0.015$而不是$0.02$？
- [ ] 因为第二个信号被忽略了。
- [x] 因为一半的总敞口做空第二个名字，而那个名字的下一个收益率为负，所以这个空头贡献了正的$0.005$。
- [ ] 因为权重总是除以$4$。
- [ ] 因为在这个时钟下只做多映射不合法。
:::solution
两张映射都合法：信号在下一个收益率之前就已经已知。成比例权重是$(1/2,-1/2)$。空头那一半乘$-0.01$，贡献$+0.005$。只做多映射永远不取那一项，因为它把第二个权重设为$0$，并把全部总敞口放在第一个名字上。
:::
:::

:::history
马科维茨（Markowitz）1952年关于组合选择的论文把决策放在了权重上。组合的均值与方差是权重向量的函数，也是一个均值向量与一个协方差的函数，而不是一个未归一化分数的函数。约束——非负权重、相加为一的预算——是那个问题的一部分，因为它们描述的是组合实际能够持有的持仓。信号，若后来的研究者手里有一个的话，可以是均值或滤波器的一个输入。它本身不是持仓。那篇论文里没有任何东西是对某只证券的推荐，本章也没有借用任何一条。
:::

## 通向何处

[[portfolio/inverse-volatility-and-targets]]把开着的名字之间的等权换成一张用到波动率估计的映射。本章的总敞口预算与时钟继续有效：波动率的倒数在被归一化之前仍然不是权重，而且它挣的仍然是下一个收益率。[[portfolio/long-only-and-neutral]]写下[[#alg-long-only]]与[[#prop-proportional]]一直在取样的那些可行集。最终产出的那本账簿的业绩在[[performance/simple-and-log-returns]]与[[performance/volatility-and-drawdown]]里度量，而不是用信号的大小。

:::summary
- 信号$s_{i,t}$在$t$已知。权重$w_{i,t}$是占净资产值的一个目标比例。把两者接起来的是映射。
- 总敞口把绝对权重相加。净敞口把权重带符号相加。两者只在特殊情形下相等。
- 只做多等权保留信号为$+1$的名字，把一个写明的总敞口在它们之间平分，并丢掉其余。成比例映射除以绝对信号之和，并保留每一个符号。
- 同一个向量$(1,1,0,-1)$依照映射变成$(1/2,1/2,0,0)$或$(1/3,1/3,0,-1/3)$。
- 分数$(2,-1,1/2)$在那两个约定下变成$(4/7,-2/7,1/7)$或$(4/5,0,1/5)$。
- 账簿挣$\sum_i w_{i,t} R_{i,t+1}$。乘上一段已经走完的收益率是另一个一般不合法的乘积。
- 在路径A上，那两个符号映射分别复合到$-0.028490$与$-0.128145$。信号没有决定是哪一个。
:::

## 习题

:::exercise 成比例账簿的总敞口 {level=1 check="1"}
对$w = (1/3,1/3,0,-1/3)$，总敞口是多少？（输入数字。）
:::solution
把绝对值相加：$1/3+1/3+0+1/3 = 1$。
:::
:::

:::exercise 成比例账簿的净敞口 {level=1 check="1/3"}
对同一个向量$w = (1/3,1/3,0,-1/3)$，净敞口是多少？（输入分数。）
:::solution
带符号相加：$1/3+1/3+0-1/3 = 1/3$。总敞口可以是$1$而净敞口是$1/3$，因为空头在净敞口里抵消掉一个多头，在总敞口里却加入多头之间。
:::
:::

:::exercise 大分数上的只做多权重 {level=1 check="4/5"}
分数是$(2,-1,1/2)$。负数被设为$0$，正分数被重新归一化至相加为$1$。第一个名字上的权重是多少？（输入分数。）
:::solution
正部是$(2,0,1/2)$，相加为$5/2$。第一个权重是$2/(5/2) = 4/5$。
:::
:::

:::exercise 混合分数，成比例 {level=2 check="-1/4"}
分数是$(4,-2,2)$。使用成比例的总敞口$1$映射。第二个名字上的权重是多少？（输入分数。）
:::solution
绝对分数之和是$4+2+2 = 8$。第二个权重是$-2/8 = -1/4$。第一个与第三个权重分别是$4/8 = 1/2$与$2/8 = 1/4$，而绝对值相加为$1$。
:::
:::

:::exercise 作为余额的现金 {level=2 check="0.5"}
风险权重是$(0.2,0.3)$，而现金权重是使所有权重连同现金相加为$1$的那个数。这道题里现金挣$0$。现金权重是多少？（输入小数。）
:::solution
风险权重相加为$0.5$，所以现金权重是$1 - 0.5 = 0.5$。风险部分的总敞口也是$0.5$，因为两个风险权重都是正的。整个向量连同现金的净敞口是$1$。
:::
:::

:::exercise 合法的一步 {level=2 check="-1/35"}
一个名字的价格先是$100$，然后$105$，然后$102$。只做多符号映射在一个正简单收益率之后把权重设为$1$，在一个负收益率之后把权重设为$0$，而权重挣下一个收益率。在它拥有合法信号的唯一那一步上，组合的简单收益率是多少？（输入分数。）
:::solution
第一个简单收益率是$105/100 - 1 = 0.05 > 0$，所以那时选定的权重是$1$。它挣下一个简单收益率，$102/105 - 1 = -3/105 = -1/35$。第一步没有更早的收益率可以为一个权重作依据，而最后一个价格之后没有收益率。答案$-1/35$就是整本账簿，因为那一步没有用到现金，而权重是$1$。
:::
:::

:::exercise 四个名字，一步 {level=3 check="7/300"}
信号是$(1,0,-1,1)$。接下来的简单收益率是$(0.02,\ 0.05,\ -0.04,\ 0.01)$。使用成比例的总敞口$1$映射，而现金在这些名字之外不挣任何东西。组合简单收益率是多少？（输入分数。）
:::hint
先把信号除以它的绝对值之和，再乘以接下来的收益率。第二个信号是零，所以第二个收益率不进入。
:::
:::solution
绝对信号之和是$1+0+1+1 = 3$，所以

$$
w = \bigl(\tfrac13,\ 0,\ -\tfrac13,\ \tfrac13\bigr).
$$

组合收益率是

$$
\tfrac13\cdot 0.02 + 0\cdot 0.05 + \bigl(-\tfrac13\bigr)\cdot(-0.04) + \tfrac13\cdot 0.01 = \tfrac{0.02 + 0.04 + 0.01}{3} = \tfrac{0.07}{3} = \tfrac{7}{300}.
$$

收益率$0.05$是真实的，却没有被用到，因为映射把那个权重设成了$0$。那不是前视。那就是映射。
:::
:::

:::exercise 小于一的总敞口预算 {level=3 check="0.01"}
三个名字的信号是$(1,1,1)$。映射把$0.6$的总敞口预算在它们之间平分，而现金权重$0.4$挣$0$。接下来的简单收益率是$0.10$、$-0.05$与$0$。组合简单收益率是多少？（输入小数。）
:::hint
每个风险权重是$0.6/3$。把每个乘上它自己的下一个收益率再相加。现金项是零。
:::
:::solution
每个风险权重是$0.6/3 = 0.2$。组合收益率是

$$
0.2\cdot 0.10 + 0.2\cdot(-0.05) + 0.2\cdot 0 + 0.4\cdot 0 = 0.020 - 0.010 = 0.01.
$$

若总敞口预算是$1$，每个权重会是$1/3$，组合收益率会是$0.10/3 - 0.05/3 = 1/60 \approx 0.016667$。把总敞口从$1$砍到$0.6$，按$0.6$缩放这个特定的收益率，因为现金挣$0$。这个尺度是映射的一部分。它不是持有现金的建议，而一个非零的现金收益率会破坏这个简单的缩放。
:::
:::
