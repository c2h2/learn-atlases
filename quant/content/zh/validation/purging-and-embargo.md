一道日历上的切分可以看上去干净、却照样泄漏。设测试窗从索引$100$开始，而索引$99$上的一个训练决策被允许使用那个结束在$100$的收益率。决策索引早于测试。标签不早。它已经伸进了本折声称扣住未看的那些日期。**清洗（purge）**剔除每一个标签与测试窗相交的训练决策。**禁运期（embargo）**随后再剔除一块训练决策，不是因为它们的标签与测试相交，而是因为序列相依性能让一个合法标签与紧接在它之后的那些收益率发生相关。

开放库的第三个走步验证页面WF03，是带两种剔除的锚定设计。按quants.md对那个QuantJourney示例（Apache-2.0）的报告，按2026年的阅读，该页面在每次测试窗之前使用固定数量与按百分比的剔除，$48$折，跨距$26$年。本图谱没有重跑过那个回测。库内笔记记载的目录描述，给WF03的身份与WF01、WF02相同：切片诊断，而非独立的样本外证据。清洗一道边界，不会把一折升格成一次独立的重复。$48$次清洗过的折，仍然是一段跨距的$48$个函数。

索引约定就是[[validation/walk-forward]]里的那一个。窗口是含两端的整数区间。一个日期为$t$的特征可以使用$t$时可得的信息，挣到$t$之后的收益率。新登场的对象是标签：它被允许朝$t$之后看一个明说过的步数，因此它有一个宽度。

## 标签是区间，不是瞬间

:::definition 标签的跨度 {#def-label}
固定一个标签视野（horizon）$h$，一个正整数。索引$t$上一个决策的标签，是索引集合$\{t+1, t+2, \ldots, t+h\}$。等价地说，标签使用的是结束于那些索引的简单收益率。标签与一个测试窗**相交**，如果两个索引集合有一个公共元素。
:::

视野$h = 1$就是寻常的下一个收益率。$t$的标签是单点集$\{t+1\}$，它只在$t+1$位于测试之内时，才与始于$\tau$的测试相交，所以触及始于$\tau$的测试的训练决策只有$t = \tau-1$——前提是这个索引在训练窗里。视野$h = 5$把标签向右抹开五步。坐在切分之前好几处的决策，仍然触及测试。这抹开的拖影，正是"决策在$\tau$之前"这条规则不等于"标签在$\tau$之前"这条规则的全部原因。

定义里没有任何一句话说，这个标签是一个好预测、一个效用或一个交易目标。它说的是计分函数读哪些日期。若规格说明换一个视野，被清洗的集合就跟着变。两个研究者在日历上同一切处切开、却用不同的视野来标注，跑的就是不同的实验。

:::proposition 清洗剔走的是哪些训练决策 {#prop-which}
设测试窗为$[\tau,\ \tau+H-1]$，$H \ge 1$，标签视野为$h \ge 1$。一个决策$t \le \tau-1$的标签与测试相交，当且仅当$t \ge \tau-h$。特别地，若候选训练集包含从$\tau-h$到$\tau-1$的每一个索引，清洗恰好剔除$h$个决策：$\tau-h, \tau-h+1, \ldots, \tau-1$。
:::

:::proof
标签是$\{t+1, \ldots, t+h\}$。因为$t \le \tau-1$，左端满足$t+1 \le \tau$，所以标签从第一个测试索引处或之前开始。于是它与$[\tau,\ \tau+H-1]$相交，当且仅当它的右端至少为$\tau$，即$t+h \ge \tau$，也就是$t \ge \tau-h$。两个界合起来就是$\tau-h \le t \le \tau-1$。若这些整数每一个都在候选训练集里，就有$h$个。
:::

这个证明用到的是含两端的区间，以及决策坐在测试之前的假设。它不假设收益率独立，也没有说剩下的训练行相互独立。训练窗内部相互重叠的标签仍然共享日期。清洗止住的是一处训练对测试的泄漏。它不是一个向独立样本的变换。第二种相依在[[statistics/moments-and-dependence]]里讨论。

:::example 一个五天标签对着一道始于100的测试 {#ex-touch}
候选训练集是$[0,99]$，测试是$[100,119]$，$h = 5$。列出每一个标签与测试相交的训练决策，并写出其中最左一个的标签集合，以及它前面那个决策的标签集合。
:::solution
按[[#prop-which]]取$\tau = 100$，剔除$t = 95, 96, 97, 98, 99$。

其中最左的是$t = 95$。它的标签是$\{96, 97, 98, 99, 100\}$，在$100$处碰到测试。再往下一个决策是$t = 94$。它的标签是$\{95, 96, 97, 98, 99\}$，整个落在训练窗之内，不碰测试。所以$94$不被相交规则清洗。它是否仍应被剔除，那是禁运期的问题，不是清洗的问题。

立此存照，其余的标签是$\{97, \ldots, 101\}$、$\{98, \ldots, 102\}$、$\{99, \ldots, 103\}$与$\{100, \ldots, 104\}$。它们每一个都与$[100,119]$相交。若视野是$1$，就只会清洗$t = 99$。多出来的四个决策，是朝前看五天所要付的价钱。
:::
:::

## 清洗，以及那道不是清洗的间隔

:::definition 清洗 {#def-purge}
给定一个候选训练集与一个测试窗，清洗就是剔除每一个标签——在[[#def-label]]的意义上——与测试相交的训练决策。幸存下来的训练决策，是一折被清洗之后用来选参数的唯一那些决策。参数随后被冻结。测试标签用来给它计分，而不是用来选它。
:::

:::definition 禁运期 {#def-embargo}
一个禁运$m$个额外决策，$m \ge 0$，再剔除紧挨被清洗块左边（若清洗一无所剔，则紧挨测试左边）的$m$个训练索引。这$m$个索引之所以被剔除，是因为序列相依，而不是因为它们的标签与测试相交。在本章算到底的协议里，对一个含$n$个决策的候选训练集取比例为$\rho$的百分比禁运：当$\rho n$是整数时$m = \rho n$，否则$m = \lfloor \rho n \rfloor$。
:::

这两次剔除回答两种不同的失效。清洗回答一个逻辑上的重叠：标签集合与测试集合共享一个索引，于是那一行训练已经看到了答案的一部分。禁运回答一个统计上的重叠：哪怕一个停在$\tau-1$的标签，也可能与那个结束在$\tau$的收益率相关。多剔两天，并不能证明相关性已经没有了。那是一道明说的间隔。它的宽度属于规格说明，正如视野属于规格说明。一个找不到$h$、$m$与$\rho$的读者，还不算知道跑的是哪个实验。

按目录记载，WF03在每次测试之前使用固定数量的剔除和按百分比的剔除。库表没有说道实现取的是一个固定数与一个百分比数之和、最大值、还是别的某种组合，也没有发表这些数。因此本章分开教这两个控制量，并且在本章算到底的数字里，把标签清洗和百分比禁运当作相继的两步来施加。这个相继是我们的教学协议。它不是库内代码的一行被重构出来的话。把某个特定的组合规则安到WF03头上，就是发明一个。

:::algorithm 先清洗，再禁运 {#alg-exclude}
从候选训练索引与测试窗出发。剔除每一个标签与测试相交的训练索引。然后，把$m$取为一个固定数、或[[#def-embargo]]中施加到原始候选长度$n$上的百分比规则所给的数，剔除离测试最近的$m$个幸存索引。只在剩下的东西上拟合。只在测试上计分。看过测试分数之后，不得把一个被清洗或被禁运的索引搬回拟合里。
:::

在$n = 100$个候选训练决策、索引$0$到$99$的例子里，$2\%$的禁运给出$m = 0.02 \times 100 = 2$。视野为$5$的清洗已经剔除了$95$到$99$。禁运再剔除紧挨左边的两个，$93$与$94$。最后一个幸存的索引是$92$。幸存的训练决策数是$100 - 5 - 2 = 93$。测试$[100,119]$分毫未动。为了让其中五个决策看不见任何测试日期、再让另外两个离边界远一些，一共剔掉了七个训练决策。

:::example 两个百分点，然后两天 {#ex-two-percent}
用训练窗$[0,99]$、测试$[100,119]$与$h = 5$，然后对$100$个候选训练决策取$2\%$的禁运。禁运剔除哪些索引，哪个索引是最后的幸存者，还剩下多少个训练决策？
:::solution
清洗剔除$95, 96, 97, 98, 99$，依据[[#ex-touch]]。$100$的$2\%$是$2$，所以禁运剔除$93$与$94$。最后的幸存者是$92$。剩下的训练窗是$[0,92]$，有$93$个索引。被剔掉的七个索引是这份协议的一个属性。它们不是关于WF03页面上那些未发表天数的任何主张。

$94$处的标签是$\{95, 96, 97, 98, 99\}$。它不与测试相交。禁运照样剔除$94$。这就是那个分别的全部内容：相交对清洗是充分的，对禁运却不是必要的。
:::
:::

:::example 一道太薄的固定间隔 {#ex-short-fixed}
有人保留同样的训练窗、同样的测试，无视视野，只剔掉固定的两个决策，$98$与$99$。对$h = 5$，哪些训练决策的标签仍然碰到测试？其中最小的决策索引是多少？
:::solution
[[#prop-which]]仍然把$95, 96, 97, 98, 99$全部标记出来。剔掉$98$与$99$之后，$95$、$96$与$97$留在拟合里。其中最左的是$95$。它的标签包含$100$，第一个测试索引，于是这个拟合正在被出示一个测试日期。一个两天的固定剔除和一个五天的标签视野，不是彼此的替身。WF03的目录那一行足够仔细，把固定的与按百分比的两种剔除都点了名。一份只点名一个小的固定间隔、同时又用长标签的报告，没有堵上[[#prop-which]]所描述的那处泄漏。
:::
:::

:::warning 清洗不管制特征
设$h = 5$，而清洗在一个始于$100$的测试之前正确地剔除了$95$到$99$。$t = 90$处的决策留了下来，因为它的标签$\{91, \ldots, 95\}$在测试之前停住。如果$t = 90$处的特征是用$93$处的价格造的，这个特征就在用一个$90$处的决策还不曾有的价格。标签相交检验抓不到这个。特征内部的前视，是[[backtesting/timing-costs-and-biases]]那一类的时钟错误。清洗与禁运不是万能消毒剂。它们关上一扇门：标签，以及一道明说的相依间隔，在一道切分上的。
:::

:::example 视野为三的短训练窗 {#ex-small}
候选训练集$[0,11]$，测试$[12,15]$，视野$h = 3$。哪些训练决策被清洗？若视野改为$1$，会被清洗的那一个决策是哪一个？
:::solution
这里$\tau = 12$，所以[[#prop-which]]剔除$t = 9, 10, 11$。它们的标签是$\{10, 11, 12\}$、$\{11, 12, 13\}$与$\{12, 13, 14\}$。每一个都碰到测试。决策$t = 8$的标签是$\{9, 10, 11\}$，就清洗而言它留下来。

当$h = 1$时，同一条命题只剔除$t = 11$，它的标签是单点集$\{12\}$。视野不是一个装门面的参数。把它从$3$改成$1$，改变的是训练集。
:::
:::

## 锚定折，把剔除写下来

:::definition 锚定走步验证 {#def-anchored}
锚定走步验证把训练的左缘固定在一个锚点$a$上。对始于$\tau > a$的测试，候选训练集是$[a,\ \tau-1]$。这一折随后施加[[#alg-exclude]]的清洗与禁运，并只在测试上给冻结的参数计分。测试向前跳时，锚点不跟着向前跳。
:::

若锚点是$0$、而唯一的剔除是清洗，这个设计就是[[validation/walk-forward]]的扩张走步验证、把那次清洗写了进去。一个百分比禁运，或一道比标签视野更宽的固定间隔，会让右缘严于那个无剔除的扩张定义。锚点$a > 0$在每一折上都扔掉$a$之前的日期。那是一个与锚在样本起点不同的信息集。"锚定的"不是一个可以往图上随便撒的同义词。它是一条左缘，加上一道右端的剔除，再加上一次测试。

WF03是库里锚定的那个页面：$48$折，$26$年，每次测试之前固定与按百分比的剔除，外加诊断的告诫。按quants.md对那个QuantJourney示例（Apache-2.0）的报告，按2026年的阅读，那些就是本图谱重复的全部事实。我们不发明该页面的锚点、它的视野、或它的两条剔除规则的组合方式。我们也不把"$48$"读成$48$次熬过了清洗的独立检验。清洗改变的是哪些行有资格。它改变不了这些行来自一段已记录的跨距这个事实。同一句警告，正是[[validation/what-a-fold-does-not-prove]]的要点。

还有第二道边界，在样本的右缘，而不是在训练与测试之间。若决策$100$到$119$是测试而$h = 5$，则$t = 115$的标签是$\{116, \ldots, 120\}$。若样本结束在$119$，那个标签就要一个样本没有的索引。决策$115$到$119$个个如此。一份规格说明必须说道：这些决策是被剔掉、被改短，还是按一个截断的标签计分。把这个选择留白，会让同一份日历产生两个不同的检验统计量。下面的习题数一数那些不完整的标签。这个计数是写下协议的一部分，而不是用一个还不曾到达的价格去拉伸样本的理由。

:::intuition 决策右端的一抹拖影
把决策画成一个点，把标签画成它右端一条宽度为$h$的拖影。测试是一块上了阴影的方块。任何伸进方块的拖影都必须丢掉，哪怕投出那抹拖影的点坐在左边的空白区域里。禁运是第二道、没有上阴影的间隔，之所以把它描上，是因为拖影并不是信息移动的唯一途径。收益率可以隔着一条拖影没有越过的边界发生相关。
:::

:::quiz
训练窗$[0,99]$，始于$100$的测试，视野$5$。清洗剔除哪些决策索引？
- [ ] 只有$99$，因为它是最后一个训练索引。
- [ ] $90$到$99$，因为一个五天的标签应当配一道十天的间隔。
- [x] $95, 96, 97, 98$与$99$。
- [ ] $100$到$104$，因为那些是标签在测试内部使用的日期。
:::solution
[[#prop-which]]剔除紧挨测试之前的$h = 5$个决策，即$95$到$99$。测试索引本身不是训练决策，所以不是清洗所开列的东西。一个一天的标签只会剔除$99$。干活的是视野。
:::
:::

:::quiz
一个两天的禁运在始于$100$的测试之前剔掉了索引$98$与$99$。标签视野是$5$。训练对测试的标签泄漏补上了吗？
- [x] 没有。决策$95$、$96$与$97$的标签仍然包含测试索引。
- [ ] 补上了。任何正的禁运都能补上每一处标签重叠。
- [ ] 补上了，因为$98$早于$100$。
- [ ] 这个问题没有意义，因为禁运取代了视野。
:::solution
一个两天的禁运不是一道五天的清洗。$95$处的标签包含测试索引$100$。相交是由[[#prop-which]]定夺的，不由另一道更薄的间隔的存在定夺。禁运是为相交之外的序列相依准备的。除非它的宽度恰好不小于视野，它干不了清洗的活。
:::
:::

:::application WF03的身份
WF03很容易被读过头，因为那些剔除听起来像严谨，而严谨很容易被错当成重复。这个页面给走步验证这个想法添上了一种锚定的几何与两种剔除。按quants.md对那个QuantJourney示例（Apache-2.0）的报告，按2026年的阅读，它仍然是$26$年跨距上的$48$折，而目录仍然把这些结果称为切片诊断，而非独立的样本外证据。本图谱没有重跑过它。要带走的教训是那套机器：固定间隔与百分比间隔是你写得下来的控制量，而写下来并不会成倍地增加历史的条数。对间隔的宽度进行搜索，会是一次进一步的试验，在[[validation/parameter-search]]的意义上，而不是同一个单次检验的一个更严的版本。
:::

:::remark 这个百分比乘的是哪个基数
算到底的禁运用的是原始候选训练长度（清洗之前）的一个分数。$100$的$2\%$是$2$，无论按标签规则是否还要再清洗五个索引。一份改为取清洗后长度的$2\%$、或全样本长度的$2\%$的规格说明，是另一条规则。在这些具体的数字上，清洗后$95$个决策的$2\%$是$1.9$，而$\lfloor 1.9 \rfloor = 1$，于是禁运只剔一个索引而不是两个。在它乘的那个基数被写明之前，这个分数是不可解读的。库表没有写明WF03的基数。我们不猜。
:::

这里采纳的是马克斯·洛佩斯·德·普拉多（Marcos López de Prado）在*Advances in Financial Machine Learning*（2018年）里的说法：金融里的标签常常在时间上重叠，所以只检查决策索引的切分会泄漏，而带禁运的清洗就是提出的补救。这本书也讨论了训练行可以坐在测试之后的交叉验证设计，在那些设计里，测试另一端的禁运同样要紧。一条因果的走步验证早已禁止在未来上训练。它的泄漏——本章算的就是它——是那个伸过切分的标签，加上切分处的序列相依。开放库的WF03页面是一个实用近亲，带着固定的与按百分比的剔除，也带着诊断的告诫。
:::

## 通向何处

当切分与间隔都写明之后，仍然可以毁掉这份协议：试许多个间隔、许多个视野或许多个窗口，然后留下最好的分数。那场搜索在[[validation/parameter-search]]。随尝试次数增长的那把尺度、以及定义完整的收缩（deflated）夏普比率的那篇论文，在[[validation/the-deflated-sharpe]]。一次小心清洗之后剩下的那些折，仍然是一条路径，这就是[[validation/what-a-fold-does-not-prove]]。序列相依——禁运之所以存在的那个原因——在[[statistics/moments-and-dependence]]。

:::summary
- 决策$t$上视野为$h$的标签使用索引$t+1$到$t+h$。哪怕$t$本身早于测试，它也可以与一个较晚的测试相交。
- 若训练窗跑到始于$\tau$的测试，清洗恰好剔除$h$个决策：$\tau-h, \ldots, \tau-1$。
- 禁运为序列相依再剔一道间隔。在算到底的协议里，$100$个训练决策的$2\%$就是另外两个索引。
- 一道比视野薄的固定间隔堵不上标签泄漏。清洗与禁运不是彼此的替身。
- WF03报告$26$年里的$48$折锚定折，带固定与按百分比的剔除，而这些是切片诊断，而非独立的样本外证据。
- 清洗修不了一个读取决策之后价格的特征，也修不了一条历史变成多条。
:::

## 习题

:::exercise 第一个被清洗的索引 {level=1 check="95"}
测试始于索引$100$，标签视野是$5$。候选训练集包含紧挨测试之前的每一个索引。清洗剔除的最小的决策索引是多少？（输入那个索引。）
:::solution
[[#prop-which]]剔除$\tau-h = 100-5 = 95$，以及从那到$99$的每一个整数。最小的是$95$。
:::
:::

:::exercise 更长训练窗上的两个百分点 {level=1 check="5"}
一个百分比禁运对$n = 250$个决策的候选训练集取$\rho = 0.02$，而$0.02 \times 250$是一个整数。禁运再剔掉多少个决策？（输入那个计数。）
:::solution
$0.02 \times 250 = 5$。在[[#def-embargo]]的规则之下，禁运的宽度是$5$个决策。这没有说道那五个对某个特定的视野就够了。视野决定清洗。百分比决定禁运。两者是分开设定的。
:::
:::

:::exercise 多少训练行幸存 {level=1 check="93"}
从$100$个候选训练决策出发。视野为$5$清洗掉其中五个，$2\%$的禁运再剔两个。还剩下多少个训练决策？（输入那个计数。）
:::solution
$100 - 5 - 2 = 93$。在索引集$[0,99]$、测试在$100$处的情形里，幸存者是$[0,92]$。
:::
:::

:::exercise 一个标签的右端 {level=2 check="101"}
视野是$h = 5$，决策是$t = 96$。标签使用的最后一个索引是多少？（输入那个索引。）
:::solution
标签使用$t+1$到$t+h$，所以最后一个索引是$96+5 = 101$。若测试始于$100$，那么$101$是一个测试索引，这个决策就被清洗。同样的结论也可以从$96 \ge 100-5$得到。
:::
:::

:::exercise 一道薄的固定间隔 {level=2 check="95"}
在始于$100$的测试之前只剔掉索引$98$与$99$。视野是$5$。仍然有标签与测试相交的最小的决策索引是多少？（输入那个索引。）
:::solution
相交规则仍然把$95, 96, 97, 98, 99$全部标记出来。$98$与$99$被剔掉之后，$95$留了下来，而且它是最小的。它的标签包含$100$。那个两天的固定间隔并没有执行[[#prop-which]]。
:::
:::

:::exercise 短训练窗上的视野三 {level=2 check="3"}
候选训练集$[0,11]$，测试$[12,15]$，视野$3$。清洗剔掉多少个训练决策？（输入那个计数。）
:::solution
[[#prop-which]]剔除$9, 10, 11$。计数是$h = 3$。若视野为$1$，计数本来会是$1$，所以这个数不是日历切分本身的一个属性。
:::
:::

:::exercise 伸出样本末端的标签 {level=3 check="5"}
测试决策是$100$到$119$含两端，视野是$5$，样本结束在索引$119$。这些测试决策里有多少个的标签要求一个严格大于$119$的索引？（输入那个计数。）
:::hint
$t$的标签需要索引$t+h$。找出每一个满足$t+5 > 119$的测试决策。
:::
:::solution
不等式$t+5 > 119$就是$t > 114$，而$t$必须落在$100, \ldots, 119$之中，所以$t = 115, 116, 117, 118, 119$。这样的决策有五个。一份悄悄把它们的标签改短的协议，和一份把它们剔掉的协议，产出的是不同的测试集。训练与测试之间的清洗回答不了这个问题。它是规格说明的单独一行。$20$个测试决策里有五个不完整的标签，大到忽略它就不是一个舍入误差。
:::
:::

:::exercise 一个清洗看不见的特征 {level=3 check="93"}
视野是$5$，测试始于$100$，而清洗已经剔除了$95$到$99$。决策$t = 90$在那次清洗里幸存。$t = 90$处的一个非法特征，是从$90$处的价格到$93$处的价格的简单收益率，所以它读取了那个更晚的价格。那个特征使用的最后一个价格索引是多少？（输入那个索引。）
:::hint
把两个问题分开。$t = 90$的标签与测试相交吗？这个特征读的是哪个价格索引？清洗只回答第一个。
:::
:::solution
那个特征使用$93$处的价格。那个索引就是答案。$t = 90$的标签是$\{91, 92, 93, 94, 95\}$，停在$95$，不碰始于$100$的测试，所以[[#prop-which]]正确地把$t = 90$留在训练窗里。这个特征仍然是非法的，因为一个$90$处的决策在使用$93$处的价格。清洗与禁运堵住的是标签的泄漏，以及一道切分上一道明说的相依间隔。它们不扫描特征里的前视。那道检查是[[backtesting/timing-costs-and-biases]]里的时钟，而且它必须先于一个被清洗的折的任何意义通过。
:::
