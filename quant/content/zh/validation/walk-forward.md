一条在它随后被计分的同一些日期上被选定的规则，已经看到了它声称后来才遇到的那些结果。把那些日期切开，是一份研究记录至少能做到的事。**走步验证**协议把一条已记录的历史切成若干窗口对：较早的一个窗口，用来冻结一个选择；较晚的一个窗口，用来给那个被冻结的选择计分。这道切分是关于时钟的一句话。它本身并不是证据，证明这个选择会在一条尚未被记录的路径上挣到任何东西；它也不是一条去交易的指令。

开放库的前两个走步验证页面，各自在$26$年的跨距上使用$48$折。按quants.md对那些QuantJourney示例（Apache-2.0）的报告，按2026年的阅读，WF01让一个定长训练窗与一个定长测试窗向前滑动，并在测试切片之前带一次清洗（purge）；WF02则让训练窗增长到包含测试之前的一切，同样对着一个滑动的测试窗。本图谱没有重跑过这两个回测中的任何一个。按本图谱库内笔记的记载，目录自己的描述把这些页面的输出称为切片诊断，而非独立的样本外证据。这句话属于对那些页面是什么的一份定义。它不是我们欣赏过一个数字之后补上去的客套。

本章通篇，日期都是整数索引。一个写成$[a,b]$的窗口包含满足$a \le t \le b$的每一个整数$t$。一个日期为$t$的特征可以使用直到并包括$t$处收盘的价格，它挣到的是$t$之后的简单收益率。在一折内部，参数只是训练窗的函数。测试期间它保持冻结。测试内部的一个特征仍然可以使用直到它自己决策时点的价格。它不得用一个测试标签去重新调那个该折声称已经冻结的参数。把溢过切分的标签清洗掉，是[[validation/purging-and-embargo]]的主题。一摞折为什么仍然可能像一个对象一样一起移动，是[[validation/what-a-fold-does-not-prove]]的主题。

## 滑动窗与扩张窗

固定三个正整数：训练窗长度$L$、测试窗长度$H$与步长$S$。步长是这一对窗口移动的距离。取$S = H$，相邻的测试首尾相接。取$S$小于$H$，测试彼此重叠。两种设计都是走步验证设计。它们不是同一个实验，而且哪种设计都造不出新的历史。

:::definition 滑动走步验证 {#def-rolling}
在日期$0, 1, \ldots, T-1$上，编号$k = 0, 1, 2, \ldots$的滑动折的训练窗为$[kS,\ kS+L-1]$，测试窗为$[kS+L,\ kS+L+H-1]$，前提是测试窗落在$0, \ldots, T-1$之内。在测试上计分的参数，是这一折自己的训练窗的函数，是规格说明的函数，而不是测试标签中任何东西的函数。
:::

训练窗长度在每一折上都保持等于$L$。随着$k$增大，旧日期从左缘掉出去，新日期从右缘进入。某一较早折的测试日期，可以坐在某一较晚折的训练窗内部。对那较晚的一折说这是合法的，因为那些日期早于较晚的测试。但对"两个测试分数是在不同样本上的重复"这种说法，这件事是致命的。

:::definition 扩张走步验证 {#def-expanding}
在同样的日期上，一条锚点为$a$、测试窗相同的扩张折，对始于索引$\tau$的测试，使用训练窗$[a,\ \tau-1]$，再算上规格说明紧挨$\tau$之前放置的任何剔除。锚点不移动。训练窗随$\tau$向前移动而增长。
:::

按目录记载，WF02就是扩张设计：一个不断增长的训练窗对着一个滑动的测试窗。WF01是滑动设计，每次测试之前带一次清洗。清洗改变的是右端哪些训练索引有资格计分；"定长"与"不断增长"的几何，才是两个定义之间的分别。在同一些测试日期上算出的两个分数，一个来自滑动拟合、一个来自扩张拟合，是两个实验。把它们平均，造不出第三个更精确的重复。

测试开始时什么已知，这件事好标、也好夸大。一个滑动测试开始时，拟合可以使用该折的$L$个训练索引，不能使用任何更晚的标签。一个扩张测试开始时，拟合，在剔除之后，可以使用从锚点起直到测试——但不包括测试——的每一个索引。两种情形下，该折被允许挣到的第一个收益率，都是从最后一个有资格的训练收盘到下一个收盘的简单收益率。给那个结束在某个训练日期上的收益率计分，是一个样本内分数，哪怕一篇报告的后面某段把它称为样本外。

:::algorithm 构造滑动折的清单 {#alg-folds}
输入满足$T \ge L+H$的正整数$T$、$L$、$H$与$S$。对$k = 0, 1, 2, \ldots$，当$kS+L+H-1 > T-1$时停止。否则发出训练窗$[kS,\ kS+L-1]$与测试窗$[kS+L,\ kS+L+H-1]$。这一对窗口的参数只在训练窗上估计，然后冻结，然后只在测试窗上计分。
:::

:::proposition 能容下多少滑动折 {#prop-count}
在[[#def-rolling]]之下，若$T \ge L+H$且$S \ge 1$，折数为$\lfloor (T-L-H)/S \rfloor + 1$。若$S = H$，相邻的测试窗不交且相接：测试$k+1$的第一个索引，是紧接测试$k$最后一个索引之后的那个整数。若$S < H$，相邻的测试窗恰好共享$H-S$个索引。
:::

:::proof
折$k$的测试结束于$kS+L+H-1$。该索引至多为$T-1$，当且仅当$kS \le T-L-H$。由于$S > 0$，这就是$k \le (T-L-H)/S$。容许的整数$k$是$0, 1, \ldots, \lfloor (T-L-H)/S \rfloor$，共有$\lfloor (T-L-H)/S \rfloor + 1$个。

现在取$S = H$。测试$k$结束于$kH+L+H-1 = (k+1)H+L-1$。测试$k+1$开始于$(k+1)H+L$。这两个索引相差$1$，所以两个窗口既不共享任何东西，也不留下缺口。若改为$S < H$，测试$k+1$开始于$kS+S+L$，而测试$k$一直跑到$kS+L+H-1$。共享的索引从$kS+S+L$跑到$kS+L+H-1$，其个数是$H-S$。
:::

同样的算术给出相邻滑动训练窗的重叠。训练$k$是$[kS,\ kS+L-1]$，训练$k+1$是$[(k+1)S,\ (k+1)S+L-1]$。当$L > S$时，两者共享$L-S$个索引。一个长的训练窗加上一个短的步长，造出的各折，其拟合参数几乎是同一批日期的函数。测试不交并不能撤销这一点。参数仍然可能很接近，测试分数也仍然可能一起移动，因为喂给特征的是同一条路径。[[#prop-count]]数的是窗口。它不数独立的实验。

## 一折被允许知道什么

考察$30$个日期，索引$0$到$29$，取$L = 12$、$H = 6$与$S = 6$。[[#prop-count]]给出$\lfloor (30-12-6)/6 \rfloor + 1 = 3$折滑动折。

- 折$0$在$[0,11]$上训练，在$[12,17]$上测试。测试开始时，拟合只能使用$0$到$11$上的价格。它能挣到的第一个收益率，是从索引$11$到索引$12$的简单收益率。
- 折$1$在$[6,17]$上训练，在$[18,23]$上测试。拟合可以使用$6$到$17$上的价格。那些训练索引里有六个，曾就是折$0$的整个测试。
- 折$2$在$[12,23]$上训练，在$[24,29]$上测试。折$0$的每一个测试索引如今都是一个训练索引。相对它自己的测试，这一折仍然是合法的走步验证。它不是对一段崭新历史的第二次看。

锚点为$0$、三个测试相同、且暂时还没有任何剔除的扩张设计，在$[0,11]$上训练折$0$，在$[0,17]$上训练折$1$，在$[0,23]$上训练折$2$。第二个扩张训练窗有$18$个索引。第二个滑动训练窗有$12$个。索引$0$到$5$在一个拟合里，而不在另一个里。一个研究者报告"那个"走步验证结果，却不说是用了这些信息集中的哪一个，那他就没有给这个实验起过名字。这个比较，正是目录把WF01与WF02作为两个页面分开发表所强加的那个比较：定长与不断增长是不同的协议，哪怕两个页面都诚实地拒绝把自己的折称为独立的证据。

:::intuition 切一条面包
把一条面包切成四十八片，烤不出四十八条面包。一片面包仍然可以传递信息。第$12$片的面包芯会告诉你一些关于这条面包的事。它不会告诉你，另一条在别的日子里、用别的面粉烤出来的面包会是什么样子。走步验证是一种小心的切法。这份小心在日期的次序上。片的数目不是条的数目。
:::

重叠的测试添上一种更进一步的、纯算术的相依。若$S < H$，则由[[#prop-count]]，同一个简单收益率是两个测试窗里的成员。两个窗均值的平均，会把那个收益率计两次。不同测试日期各自的均值是另一个数，而当某个共享的收益率很大时，它甚至可能符号相反。本章末尾的习题会让这笔算术无法回避。在那道题做完之前，没有借口把重叠折分数的平均，当作各折已被拼接成一个容量为$2H$的样本一样对待。

## 四十八是一个几何，不是重复计数

WF01与WF02各自报告$48$折与$26$年的跨距，而且每个页面都带着那条诊断的告诫。本图谱引用的那张库表，没有写明训练窗长度、测试窗长度或步长。许多个三元组$(L, H, S)$都会得到$48$的折数。一个用我们自己的每年$252$个交易日计数约定搭出来的例证是$T = 26 \times 252 = 6552$、$L = 504$、$H = 126$与$S = 126$。于是

$$
\lfloor (6552 - 504 - 126)/126 \rfloor + 1 = \lfloor 5922/126 \rfloor + 1 = 47 + 1 = 48,
$$

因为$126 \times 47 = 5922$。这个恒等式展示了折数如何从[[#prop-count]]里出来。它没有指明WF01页面上的窗口。把它当作一个找回来的规格说明来用，就会发明一个目录没有给我们的设计。这个恒等式确实展示的是：$48$个窗口可以沿着一段几千个日期的跨距铺开。它们随后就是那段跨距的$48$个函数。

而且$48$也不是[[performance/uncertainty-of-performance]]里那个标准误的样本量。那个标准误只在一条明说的相依假设之下，才除以一个收益率的计数。一条历史上的折分数从构造上就违反了独立的情形：相邻的滑动训练窗共享$L-S$个日期，较晚的训练窗吞掉较早的测试，而一个比$H$更长的体制同时坐在许多测试之内。一次诚实的样本量谈话，要从规格说明和相依出发，而不是从折的计数器出发。

:::warning 不交不等于独立
当$S = H$时，相邻的测试不共享任何索引。到此为止、然后把折分数称为独立的，很诱人。它们是一条路径一段段的函数。一个比测试窗更长的漂移、波动率水平或单一政策体制，于是会出现在不止一个分数里。不共享日历索引，去掉的是被计了两次的收益率。它去掉不了这条路径。
:::

:::example 二十个日期上的两折滑动 {#ex-twenty}
日期索引为$0$到$19$，所以$T = 20$。取$L = 10$、$H = 5$与$S = 5$。列出每一个容得下的滑动折的训练与测试索引，并说说第二个训练窗与第一个测试有什么共同之处。
:::solution
[[#prop-count]]给出$\lfloor (20-10-5)/5 \rfloor + 1 = 2$折。折$0$在$[0,9]$上训练，在$[10,14]$上测试。折$1$在$[5,14]$上训练，在$[15,19]$上测试。第三折会测试$[20,24]$，装不下。

第二个训练窗是$[5,14]$。第一个测试是$[10,14]$。那五个索引两边都在。折$1$被允许用它们来训练，因为它自己的测试从$15$开始。于是折$0$的五个测试收益率，是折$1$所冻结的那个参数的输入。两个测试分数不是两个不同样本上的两个实验。
:::
:::

:::example 三折，以及扩张的另一个版本 {#ex-thirty}
用索引$0$到$29$、$L = 12$、$H = 6$与$S = 6$，列出三个滑动折。然后列出锚点为$0$、无剔除时，测试$[18,23]$的扩张训练窗。有多少个索引在那个扩张窗里、而不在同一个测试的滑动窗里？

三个滑动折是$[0,11]$对$[12,17]$、$[6,17]$对$[18,23]$，以及$[12,23]$对$[24,29]$。这就是上面图里画出的那个清单。

对始于$18$的测试，扩张训练窗是$[0,17]$，有$18$个索引。同一个测试的滑动训练窗是$[6,17]$，有$12$个索引。只在扩张拟合里的索引是$0, 1, 2, 3, 4, 5$：六个日期。两个拟合知道的信息不一样。报告一个测试分数，却不说那个被冻结的参数是哪个拟合产生的，报告的就是一个没有做完的实验。
:::

:::example 路径A上的单折时钟 {#ex-path-a}
路径A的价格是$100, 102, 101, 104, 103, 107, 106, 110$。直到$104$收盘的三个简单收益率是$0.020000$、$-0.009804$与$0.029703$，与本图谱别处一致。这条规则冻结一个单一的二元选择：若那三个收益率的均值为正，就在之后的四个简单收益率上持有该资产；若均值为负，就持有现金、收益率为$0$。现金情形下的无风险收益率是由这条规格说明定为$0$的，不是由市场报价。计算测试的复合收益率。把它同两样东西比较：在同样这四个收益率上始终持有该资产，以及从$100$到$104$的复合收益率。
:::solution
三个舍入后的训练收益率之和是$0.020000 - 0.009804 + 0.029703 = 0.039899$，所以均值为正。舍入后的数字离零足够远，六位小数的舍入翻不动这个符号。于是这条规则持有该资产。

之后的四个价格从$104$走到$110$。叠缩之后，毛复合增长是$110/104 = 55/52$，复合简单收益率是$55/52 - 1 = 3/52$，六位小数为$0.057692$。在同一个测试窗上始终做多的头寸挣到同样的$3/52$，因为被冻结的选择是做多。这一折核对了时钟。它没有把这条规则同在那四个日期上买入并持有区分开来。

从$100$到$104$的复合收益率是$0.04$。那个数字只用训练日期。它是一个样本内增长，不是走步验证的结果。四个测试收益率对一年化夏普来说也太短。我们不把它们年化。训练均值的符号若相反，就会让测试持有现金、挣到$0$，而买入并持有的复合数还是$3/52$。无论如何，一条短路径上的一次二元选择，是一次把时钟走到底的演练，不是一次确认。这里没有任何东西是持有该资产、持有现金、或持有任何可交易工具的建议。
:::
:::

:::example 当场搭出的四十八折 {#ex-forty-eight}
按一年数$252$个交易日，设$T = 26 \times 252$。取$L = 504$、$H = 126$与$S = 126$，能容下多少个滑动折？这个结果告诉你WF01页面上用的窗口长度了吗？
:::solution
$T = 6552$。[[#prop-count]]里的公式是$\lfloor (6552-504-126)/126 \rfloor + 1$。取整符号里的分子是$5922$，而$5922/126 = 47$恰好，所以折数是$48$。

它没有告诉你WF01的窗口长度。库表写明的是折数、跨距、滑动设计、测试前一次清洗的存在，以及诊断的告诫。它没有写明$L$、$H$或$S$。这里用的三元组是为了让公式返回$48$而选的，是公式的演示。把$504$与$126$当成库没有发表的参数，就是发明一个规格说明。这个演示作为反方向的警告依然成立：$48$个折，就是当长度固定之后，从一段很长的跨距上能得到的东西。它不是$48$条历史。
:::
:::

:::quiz
相邻的滑动测试按$S = H$搭建。哪句话是对的？
- [ ] 测试在$H/2$个索引上重叠，所以每个收益率都被计了两次。
- [x] 测试不共享索引：下一个测试从前一个测试结束之后紧接着的那个整数开始。
- [ ] 不共享索引，就把折分数变成了独立的随机变量。
- [ ] 在测试收益率被看到之前，测试窗口无法列出。
:::solution
当$S = H$时，[[#prop-count]]把测试$k+1$的起点恰当地放在测试$k$终点之后一个索引处。窗口不交。一条路径的不交子集不是独立的样本。索引算术只用到$L$、$H$、$S$与$T$，所以它不等收益率。
:::
:::

:::application WF01与WF02的贡献
这两个页面有用，既因为它们具体，也因为它们克制。WF01是滑动的，WF02是扩张的，两者都是$48$折，都跨$26$年，而且都被它们自己的目录描述为切片诊断。按quants.md对那些QuantJourney示例（Apache-2.0）的报告，按2026年的阅读，本图谱会重复的数值主张就是这些的全部：折数与跨距。本图谱没有重跑过这些回测，而库表没有为这两个页面给出夏普比率、年化复合增长率或回撤。发明一个，会把一部仔细的目录变成同人小说。这两个页面的研究用处，在于这个对照：同一段跨距，不同的训练几何，同样拒绝把折当作独立的样本外证据。
:::

:::remark 移动平均规则的去向
这些库页面内部的规则，是[[trend/moving-averages]]里研究过的那一类移动平均交叉。本章不重新尝试那些交叉，也不给它们排序。一个交叉是一条带参数的规则。走步验证是在较晚的日期上给一个冻结的参数计分的方法。分数的好坏，是时钟的好坏、以及你愿意承担多少相依的函数。它不是"移动平均"这几个字的属性。
:::

:::history
马克斯·洛佩斯·德·普拉多（Marcos López de Prado）的*Advances in Financial Machine Learning*（2018年）提出了针对时间上重叠的标签的、带清洗与禁运期的交叉验证。开放库里的走步验证页面，是这一套规矩的一个实用近亲：一个训练块、一个较晚的测试块，以及一次测试前的剔除。2018年那本书没有把一条历史上的一摞块变成一摞独立的历史，而为WF01与WF02记录的目录文字，用的是切片诊断的语言说同一件事。怀特（White）2000年的现实检验——它属于本图谱多重检验的那几章——是另一件仪器：它检验的是被搜索出来的赢家。本章谈的是切分本身。
:::

## 通向何处

下一刀不是几何的。一个要用之后好几个收益率的标签，可以从一个训练决策伸进测试——哪怕决策索引本身早于测试——这就是为什么[[validation/purging-and-embargo]]要剔除那些决策、并在其后留下一道更宽的间隔。数试验，而不是数折，在[[validation/parameter-search]]。不交的折为什么仍不是重复，在[[validation/what-a-fold-does-not-prove]]。作为这些折之容器的回测，仍然是[[backtesting/the-backtest-as-an-experiment]]里描述的那个实验：一份规格说明、一个时钟和一个损失函数，不是一家券商。

:::summary
- 一折走步验证在一个训练窗上冻结参数，并在一个较晚的测试窗上给它计分。
- 滑动折保持训练窗长度$L$。扩张折保持锚点固定、让训练窗增长。它们是不同的信息集。
- 滑动折的数目是$\lfloor (T-L-H)/S \rfloor + 1$。当$S = H$时测试不交；当$S < H$时它们共享$H-S$个索引。
- 一个较晚的滑动训练窗可以合法地包含一个较早的测试。这份合法，恰恰就是各折不是不同样本的原因。
- WF01与WF02各自报告$26$年里的$48$折，并被目录标为切片诊断，而非独立的样本外证据。本图谱没有重跑过它们。
- 折的数目不是样本量，不是资产类别的数目，也不是一条去交易的决定。
:::

## 习题

:::exercise 有几折 {level=1 check="4"}
$0$到$39$的日期可用，所以$T = 40$。滑动窗取$L = 20$、$H = 5$与$S = 5$。能容下几折？（输入折数。）
:::solution
[[#prop-count]]给出$\lfloor (40-20-5)/5 \rfloor + 1 = \lfloor 15/5 \rfloor + 1 = 4$。
:::
:::

:::exercise 测试从哪里开始 {level=1 check="20"}
滑动折编号$k = 0, 1, 2, \ldots$，取$L = 10$、$H = 5$与$S = 5$。折$k = 2$的测试窗的第一个索引是多少？（输入那个索引。）
:::solution
折$k$的测试始于$kS+L$。对$k = 2$，那是$2 \times 5 + 10 = 20$。测试是索引$20$到$24$这五个，前提是样本够长。
:::
:::

:::exercise 共享的训练日期 {level=1 check="6"}
两个相邻的滑动训练窗取$L = 12$与$S = 6$。有多少个索引同时落在两个窗口里？（输入那个计数。）
:::solution
当$L > S$时，相邻滑动训练窗的重叠是$L-S = 6$。若训练$k$始于$kS$，训练$k+1$始于六个索引之后，而第一个窗口还剩下六个索引。
:::
:::

:::exercise 扩张的长度 {level=2 check="18"}
在$30$日期的例子里，第二个测试是$[18,23]$。扩张协议取锚点$0$、无剔除。那个训练窗里有多少个索引？（输入长度。）
:::solution
训练窗是$[0,17]$，包含$18$个索引。同一个测试的滑动训练窗只是$[6,17]$。长度$18$是扩张的那个实验，不是滑动的那个。
:::
:::

:::exercise 路径A，冻结之后计分 {level=2 check="3/52"}
用[[#ex-path-a]]里的规则与价格，训练均值为正，测试从价格$104$跑到价格$110$。测试上的复合简单收益率是多少？（输入精确值；接受分数。）
:::solution
价格沿路径相消：$103/104 \times 107/103 \times 106/107 \times 110/106 = 110/104 = 55/52$。复合简单收益率是$55/52 - 1 = 3/52$。在同样那些日期上始终做多的头寸挣到同样的值，因为被冻结的选择是做多。从$100$到$104$的样本内上涨是另一个数，$0.04$，不是这个答案。
:::
:::

:::exercise 重叠的测试 {level=2 check="5"}
相邻的滑动测试长度为$H = 8$，步长为$S = 3$。有多少个索引同时落在两个测试窗里？（输入那个计数。）
:::solution
[[#prop-count]]给出重叠$H-S = 5$。两个测试窗均值的平均，会把那五个收益率每一个都计两次。它不是两个窗口并集的均值——并集的长度是$8+8-5 = 11$，不是$16$。
:::
:::

:::exercise 倒推折数，并且不发明规格说明 {level=3 check="504"}
按一年$252$个交易日计数，设$T = 26 \times 252 = 6552$。你要恰好$48$折滑动折，取$S = H = 126$。那要求什么训练窗长度$L$？（输入$L$。）
:::hint
设$\lfloor (T-L-H)/S \rfloor + 1 = 48$。取$S = H = 126$，取整符号里的比是一个整数，所以你可以去掉取整、解出$L$。然后再读解答里关于这个$L$不是什么的那句话。
:::
:::solution
方程$(6552 - L - 126)/126 + 1 = 48$化为$(6426 - L)/126 = 47$，所以$6426 - L = 47 \times 126$。由于$47 \times 126 = 5922$，得到$L = 6426 - 5922 = 504$。

这个$L$是让我们的例证返回$48$的那个训练窗长度。它不是对WF01页面的一次测量。目录没有发表$L$，而凑中一个折数也不是找回一个规格说明。在这个计数约定之下，无论什么长度的$48$折，都仍然是一段$6552$个日期跨距的四十八片。
:::
:::

:::exercise 一个计了两次的平均 {level=3 check="-1/800"}
六个简单收益率，在索引$0$到$5$上，是$1/100$、$1/100$、$-1/25$、$1/100$、$1/100$与$1/50$。折A在索引$0$到$3$上测试。折B在索引$2$到$5$上测试。计算两个折均值的平均。（把那个平均输入为精确的分数或小数。）
:::hint
把两个窗的均值再平均。不要把六个收益率的和除以$8$，也不要在平均两个均值之前丢掉共享的索引。这道题的要点就是这两种做法之间的差距。
:::
:::solution
折A的和是$1/100 + 1/100 - 4/100 + 1/100 = -1/100$，所以它的均值是$-1/400$。折B的和是$-4/100 + 1/100 + 1/100 + 2/100 = 0$，所以它的均值是$0$。两个均值的平均是$-1/800$。

索引的并集是$0$到$5$，六个收益率，和为$1/50$。它们的均值是$1/300$，为正。折均值的平均为负，因为那个共享的收益率$-1/25$在两个窗口之内，被计了两次。重叠的折给不出一个容量为$4+4$的样本。这里不同测试索引的数目是$6$。而即便这个$6$的计数，也不是一个独立的样本量：这些收益率是为了这笔算术铺成的一条短路径，不是作为六次独立的实验抽出来的。
:::
:::
