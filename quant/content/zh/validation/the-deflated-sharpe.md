许多次尝试之中的最优者，是一个与任何一次事先点过名的试验都不同的随机变量。[[validation/parameter-search]]数过那些试验：WF04上的九个网格格子，WF05上的三十次序贯试验。本章问的是，在一个刻意狭窄的概率模型之下，那个计数会对一个业绩统计量做什么，并且它停在那个模型停止的地方。收缩（deflated）夏普比率，按Bailey与马克斯·洛佩斯·德·普拉多（Marcos López de Prado）在2014年的Journal of Portfolio Management中的定义，是一个被报告的夏普比率针对三样东西的校正：试验之间的选择、样本的长度、以及非正态的收益。本课不复制他们的表达式。写出一个记不全的半版本，会比指着那篇论文更糟。这里推导的，是试验计数经由它进来的那个正态近似：在一条真零假设与独立的正态试验之下，$N$个标准化的统计量的期望最大值像$\sqrt{2\ln N}$那样增长。

那个短语是一个关于增长的陈述，不是一条你可以贴在一个夏普比率上面的恒等式。对象$\sqrt{2\ln N}$，是以标准化单位计的一个**首项选择尺度**。它本身不是一个夏普比率，不是一条年化的及格线，也不是收缩（deflated）夏普比率。一旦这个统计量被学生化，一个被报告的样本内夏普比率就必须越过一道随$N$上升的门槛。样本长度就是你学生化的方式。偏度与更厚的尾会再次改变这个学生化。那两项校正都在2014年的那篇论文里。它们不在$\sqrt{2\ln N}$这个符号里。

这一页上的任何东西，都不是一条超过它就该交易一条规则的门槛。在本图谱引用的那张表里，库页面没有报告WF04那九个格子的夏普比率，也没有报告WF05赢家的夏普比率。所以那些页面上没有任何东西，是我们可以让它通过或不通过的。编造一个通过，就是编造一个回测。

## 最大值的尺度，以及它假定了什么

标准化先行。一个原始的夏普比率是一个均值除以一个标准差。在一条没有优势的零假设之下，它的抽样分布在大的样本里、在进一步的假设之下，集中在零附近，并有一个标准误。把这个估计除以那个标准误，就得到一个标准化的统计量。若这个标准化是对的，那么当零假设为真时，这个统计量近似标准正态。选择问题于是关切若干个这样的统计量的最大值。

:::definition 首项选择尺度 {#def-scale}
设$Z_1, \ldots, Z_N$是$N$次试验的标准化的统计量，记$M_N = \max_i Z_i$。当$N \ge 2$时，首项选择尺度是$\sqrt{2\ln N}$。它就是[[#prop-union]]的并集界所使用的那个水平。它不是一个夏普比率。试验数$N$是实际被计分的配置的数目，在[[validation/parameter-search]]的意义上，不是一次后来的冻结检验的走步验证折数，也不是一张从未被跑过的网格里格子的数目。
:::

这把尺度能够描述一个零假设下的最大值所赖以成立的假设是狭窄的，每算一次这个数，都应当把它们念一遍。

- 零假设对每次试验都为真。没有一个配置有优势。这把尺度于是是一个关于噪声的陈述，不是一次对技巧的测量。
- 每个$Z_i$都是标准正态。造出它的那个标准化已经用过了样本长度，并且已经对收益的形状作了假设。偏度与超额峰度恰恰是这条假设排除掉的那类形状。
- 试验是独立的。共享日期、共享体制、嵌套的窗口、一个序贯的采样器，都违反这一条。真实的金融试验不是独立的。WF04的九个格子共享一条历史。WF05的三十次TPE试验在构造上就是相依的，因为采样器根据较早的分数提出较晚的试验。
- $N$至少是$2$，好让对数为正。一次单独的事先指定的试验，在零假设之下的标准化期望是$0$。$N = 1$处的尺度是$\sqrt{2\ln 1} = 0$，与那个期望相符，而下面的并集界是对$N \ge 2$陈述的。

去掉其中任何一条，$\sqrt{2\ln N}$就不再是$M_N$的一个经过校准的分位数。对库内页面而言，最要紧的失效是相依。它不只是添一条脚注。它意味着这把尺度不是WF04或WF05的一个P 值。这个错误的方向，不是我们在本章里用一个假的有效$N$糊得过去的东西。一条历史上的相依试验常常一起动，所以最大值并不像一次独立的计算所暗示的那样极端。这个观察是怀疑那个独立公式的一个理由，不是忽略选择的一个理由，也不是一个我们能从目录里取来的数。目录没有报告WF04那些格子之间的相关。

:::proposition 首项处的并集界 {#prop-union}
设$Z_1, \ldots, Z_N$是独立标准正态随机变量，$N \ge 2$，记$M_N = \max_i Z_i$。则

$$
\Prob\bigl(M_N > \sqrt{2\ln N}\bigr) < \frac{1}{\sqrt{4\pi \ln N}}.
$$
:::

:::proof
把$\phi$记作标准正态密度，把$\Phi$记作分布函数。对$t > 0$与$x \ge t$，有$x/t \ge 1$，而在一个正测度集上$x/t > 1$。于是

$$
1-\Phi(t) = \int_t^{\infty} \phi(x)\,dx < \int_t^{\infty} \frac{x}{t}\,\phi(x)\,dx = \frac{1}{t\sqrt{2\pi}}\exp(-t^2/2) = \frac{\phi(t)}{t}.
$$

$x\exp(-x^2/2)$的积分是$-\exp(-x^2/2)$，中间那个等式由它而来。下一步并不要求并集界与独立都在：哪怕没有独立，

$$
\Prob(M_N > t) \le \sum_{i=1}^{N} \Prob(Z_i > t) = N\bigl(1-\Phi(t)\bigr) < \frac{N}{t\sqrt{2\pi}}\exp(-t^2/2).
$$

取$t = \sqrt{2\ln N}$。因为$N \ge 2$，有$t > 0$，而$t^2/2 = \ln N$，所以$\exp(-t^2/2) = 1/N$。乘积$N\exp(-t^2/2)$等于$1$，于是不等式化简为$1/(t\sqrt{2\pi})$。由于$t\sqrt{2\pi} = \sqrt{2\ln N}\,\sqrt{2\pi} = \sqrt{4\pi \ln N}$，所得的不等式就是所声称的那一个。
:::

把这个界读仔细。它说的是，**超过**首项的机会在$N = 9$时小于大约$0.190$，在$N = 30$时小于大约$0.153$。它没有说期望最大值等于首项。在多数次抽取里，最大值可以坐在首项之下，而首项仍然是那个水平：$N$条高斯尾部在它之上不再很多。"像$\sqrt{2\ln N}$那样增长"意思是，这就是那个水平的尺度，而这个尺度随$N$趋于无穷，慢慢地。一个更细的渐近展开会减去低阶项。Bailey与洛佩斯·德·普拉多的期望最大值基准就是这样一个更细的对象，它是为夏普比率而非为一个一般的标准正态建造的，而本课不把它写下来。

这个界也随$N$增大而趋于零，因为分母在增大。这并没有把最大值拉回零。水平$\sqrt{2\ln N}$本身在向外推进。待在一个向外移动的水平之上的概率变得很小。期望最大值变得很大。两句话都是真的，而它们回答的是不同的问题。

:::proposition 期望最大值随试验数上升 {#prop-rise}
设$Z_1, Z_2, \ldots$是独立标准正态随机变量，记$M_N = \max_{i \le N} Z_i$。则对每个$N > 1$，$\E[M_N] > \E[M_{N-1}]$，并且$\E[M_N] > 0$。
:::

:::proof
$M_N = \max(M_{N-1}, Z_N) \ge M_{N-1}$，所以那个差是非负的。它不是几乎必然为零的：在$M_{N-1} = m$的条件下，下一个变量$Z_N$仍然是标准正态，而$\Prob(Z_N > m) > 0$对每个有限的$m$成立。一个不是几乎必然为零的非负随机变量，一旦可积，期望就是正的。可积性成立，因为$|M_N| \le |Z_1| + \cdots + |Z_N|$，而每个标准正态都是可积的。于是$\E[M_N] > \E[M_{N-1}]$。由于$M_1 = Z_1$的均值为$0$，期望$\E[M_N]$对$N > 1$是正的。
:::

这两条命题合起来说了我们将用什么、不会用什么。独立标准正态的期望最大值随$N$上升，所以在一个被选定的统计量面前，门槛在WF05的预算处比在WF04的预算处更高——在这些预算实际上并不满足的假设之下。首项$\sqrt{2\ln N}$是那个最大值的上尾的一个经过证明的尺度，不是它的均值的一个经过证明的公式，也不是收缩（deflated）夏普比率。

:::algorithm 如何使用这把尺度而不过度声称 {#alg-read}
数出实际被计分的试验。那个计数就是$N$。不要把一个后来的折数插进去代替$N$，也不要插入一张从未被跑过的网格的大小。对$N \ge 2$，以标准化单位计算$\sqrt{2\ln N}$。把这个实验不满足的[[#def-scale]]里的那些假设列出来，独立排第一。不要把这个尺度年化成一条及格线，也不要把结果描述成一个收缩（deflated）夏普比率。至于Bailey与洛佩斯·德·普拉多定义的那个概率，去读他们2014年发表在Journal of Portfolio Management上的那篇论文。
:::

## 两个预算，算出来

自然的输入就是那两个已经数过的预算。WF04给$N = 9$个格子计分。WF05在给赢家做任何后来的走步验证之前，给$N = 30$次试验计分。走步验证不往$N$上加。那些试验不是三十次确认，那九个格子也不是九次确认。它们是那把尺度里的$N$——前提是有人愿意谈尺度这件事。

:::example 九次与三十次处的首项 {#ex-sqrt}
用自然对数计算$\sqrt{2\ln 9}$与$\sqrt{2\ln 30}$，并算出两者的差。先给出一个更精确的值，再把每个报告数字舍入到三位小数。
:::solution
Python的`math.sqrt(2 * math.log(9))`——其中`math.log`是自然对数——返回$2.096294\ldots$。舍入到三位小数，$\sqrt{2\ln 9} = 2.096$。用$30$的同一个调用返回$2.608140\ldots$，所以$\sqrt{2\ln 30} = 2.608$，三位小数。差是$0.511846\ldots$，舍入为$0.512$。

在标准化单位下，三十次试验处的门槛比九次处更高，高出约半个首项单位——在[[#prop-union]]的假设之下。那些假设包括独立与一条真零假设。WF04的九个夏普比率是一条历史的九个函数，而WF05的三十次试验是序贯的。$2.096$与$2.608$这两个数，仍然是那个近似所点名的表达式的正确取值。它们不是那两个库内页面的P 值，不是夏普比率，也不是一条交易的门槛。哪怕要开始一场比较，都需要那些格子的分数，而目录没有报告它们；本图谱也没有重跑过那些页面。
:::
:::

:::example 并集界有多小 {#ex-bound}
用[[#prop-union]]，对$N = 9$与$N = 30$计算数值上界$1/\sqrt{4\pi \ln N}$。保留四位小数。
:::solution
对$N = 9$，$\ln 9 = 2.197225\ldots$，而$4\pi \ln 9 = 27.612\ldots$。平方根是$5.2547\ldots$，倒数是$0.190308\ldots$，四位小数为$0.1903$。对$N = 30$，$\ln 30 = 3.401197\ldots$，同一个倒数是$0.152960\ldots$，四位小数为$0.1530$。

所以这个独立正态模型说，最大值越过它自己的首项的机会，在$N = 9$处低于五分之一，在$N = 30$处低于$0.16$。在这个模型里，越过首项是一个强事件。坐在它下面某处才是寻常事件。一个把$\sqrt{2\ln N}$当作每个最大值的典型值、而不是当作尾部界里一道高位的读者，把这个命题读反了。而一个把这两个概率中的任何一个当作WF04或WF05"运气好"的概率的读者，是把这些页面并不拥有的独立性搬了进来。
:::
:::

:::example $N = 2$处，首项不是均值 {#ex-two}
设$Z_1$与$Z_2$是独立的标准正态。证明$\E[\max(Z_1, Z_2)] = 1/\sqrt{\pi}$，并与$\sqrt{2\ln 2}$比较。
:::solution
恒等式$\max(Z_1, Z_2) = \bigl(Z_1 + Z_2 + |Z_1 - Z_2|\bigr)/2$与$\E[Z_1] = \E[Z_2] = 0$给出$\E[\max(Z_1, Z_2)] = \tfrac12 \E|Z_1 - Z_2|$。两个独立标准正态之差服从均值为$0$、方差为$2$的正态分布，所以它的标准差是$\sqrt{2}$。一个中心为零、标准差为$\sigma$的正态变量的期望绝对值是$\sigma\sqrt{2/\pi}$。于是$\E|Z_1-Z_2| = \sqrt{2}\,\sqrt{2/\pi} = 2/\sqrt{\pi}$，而它的一半是$1/\sqrt{\pi}$。

数值上，$1/\sqrt{\pi} = 0.564190\ldots$，三位小数为$0.564$。首项是$\sqrt{2\ln 2} = 1.177410\ldots$，三位小数为$1.177$，约为那个期望的两倍。$N = 2$处的并集界是$1/\sqrt{4\pi \ln 2} = 0.3388\ldots$，它只控制上尾。$0.564$与$1.177$之间的那个差距，就是本章说"那样增长"而拒绝写下$\E[M_N] = \sqrt{2\ln N}$的原因。在$N = 9$与$N = 30$这两个预算处，首项仍然是[[#prop-union]]里的一个上尾尺度，不是期望的替代品，也不是Bailey与洛佩斯·德·普拉多（2014年）里那个期望最大值项的替代品。
:::
:::

## 样本长度从哪里进来，以及我们仍然为什么不写论文里那个公式

学生化是把样本长度带进来的那一步，而且这一步我们从[[performance/uncertainty-of-performance]]就已经认识了——那里有一张必须重念一遍的假设清单。洛（Lo）在2002年给出了夏普比率的一个近似标准误。在超额收益独立同分布且服从正态、且夏普比率$S$没有年化的那个特例下，标准误近似为$\sqrt{(1 + \tfrac12 S^2)/n}$，其中$n$是收益率的个数。在真零假设$S = 0$之下，那个表达式塌缩为$1/\sqrt{n}$。

当估计$\hat S$是每步夏普比率、而零假设标准误是$1/\sqrt{n}$时，一个标准化的统计量就约为$\hat S \sqrt{n}$。让这个标准化的统计量等于首项尺度，得到大小为$\sqrt{2\ln N}/\sqrt{n}$的每步夏普比率。这个换算是我们的。它用的是洛的零假设标准误与[[#def-scale]]里的首项。它不是收缩（deflated）夏普比率。2014年那个公式还对偏度、以及对夏普比率的标准误依赖于夏普比率本身这个事实做校正，并且为期望最大值使用了一个比$\sqrt{2\ln N}$更精确的基准。那个表达式，我们指向Journal of Portfolio Management，2014年。我们不重构它。

:::example 两个样本长度，一把尺度 {#ex-student}
取$N = 9$，所以首项是$2.096294\ldots$，如[[#ex-sqrt]]。假设超额收益独立同分布且服从正态、无风险收益率$0$、真夏普比率$0$，于是洛的标准误是$1/\sqrt{n}$。当$n = 2520$以及$n = 252$时，多大的每步夏普比率会学生化成那个首项？保留五位小数。不要把这两个数中的任何一个年化。
:::solution
对$n = 2520$——按一年$252$天的计数是大约十年的交易日——$\sqrt{2520} = 50.1996\ldots$，而

$$
\frac{2.096294\ldots}{\sqrt{2520}} = 0.041759\ldots,
$$

五位小数为$0.04176$。对$n = 252$，同一计数约定下的一年，这个商是$0.132054\ldots$，五位小数为$0.13205$。

标准化的尺度没有变。映射到它的那个原始的每步夏普比率变了，因为样本越短，标准误越宽。样本长度因而是任何一次诚实校正的一部分，而在$\sqrt{2\ln N}$本身里面它是看不见的。那种不可见，就是首项不是收缩（deflated）夏普比率的原因之一。

在$N = 30$处做同样的算术，首项为$2.608140\ldots$，当$n = 2520$时每步得到$0.051955\ldots$，五位小数为$0.05196$。从$0.04176$到$0.05196$的这个上升，就是这个狭窄模型内部、在一个长样本上、以每步单位计的试验数效应。

我们在年化之前停下。把一个每步数字乘以$\sqrt{252}$，造出一个很容易被误读成"一个策略本应当被要求的年化夏普比率"的数。这个乘法背后的模型需要独立同分布的收益率、零假设标准误、以及首项尺度，而人们想从它那里引出的结论是一条交易规则。这些一样都不在提供之列。数字$0.04176$与$0.05196$，是在明说的假设之下一个尾部尺度的换算。它们不是及格线。它们不是对WF04或WF05的估计。它们不是收缩（deflated）夏普比率。
:::
:::

:::warning 把这把尺度毁掉的三种代入
把$N = 9$换成$N = 48$——因为某张走步验证页面用了$48$折——回答的是另一个问题。那些折是一条路径的切片，不是$48$个被计分的配置——除非一场搜索真的给$48$个配置计了分。用一个被报告的夏普比率替换$\sqrt{2\ln N}$，无视了单位：这把尺度是标准化的，而夏普比率不是——在一个标准误被引进来之前不是。用$\sqrt{2\ln N}$替换2014年的那个公式，就丢掉了样本长度、偏度校正、以及论文自己的那个期望最大值项。合法的那句话更窄。在真零假设与独立正态试验之下，$N$个标准化的统计量的期望最大值像$\sqrt{2\ln N}$那样增长。真实的金融试验不是独立的。完整的收缩（deflated）夏普比率在Bailey与洛佩斯·德·普拉多，Journal of Portfolio Management，2014年。
:::

WF05给30次TPE试验计分，然后把赢家向前做走步验证。在本章的定义之下，$\sqrt{2\ln N}$里那个$N$在搜索阶段该取哪个值？
- [ ] $1$，因为只有赢家被向前走步验证。
- [ ] $48$，因为别的走步验证页面用了48折。
- [x] $30$，搜索中被计分的试验数目，附带一条警告：那些试验不是独立的，也不是30次确认。
- [ ] $30 \times 48$，试验预算与另一张页面借来的一个折数的乘积。
:::solution
搜索给30次试验计了分，所以尺度里的试验数是30，而对一个序贯采样器来说，独立假设已经是假的了。后来的那次走步验证，若赢家被冻结，并不会把确认数目乘以30。从WF01借来的一个折数不是WF05的试验数。两者的乘积不是样本量。
:::
:::

:::intuition 尾部尺度，不是均值
想象$N$个独立的标准正态抽取，和一道放在$\sqrt{2\ln N}$处的横杆。[[#prop-union]]说，最高的那次抽取越过横杆的次数少于那个界所说的次数。它没有说最高的那次抽取通常站在横杆上。在$N = 2$处我们算出了这两个对象：较高抽取的期望高度是$0.564$，而横杆在$1.177$。横杆是一道用来控制一条尾部的高标记。2014年的论文为夏普比率造了一道更尖的高标记，然后把样本长度与非正态性纳入。我们的横杆，是让随$N$的增长变得可见的那个课堂对象。
:::

:::remark 相依做了什么，而不做假的校正
若全部$N$次试验交出完全相同的统计量，最大值就等于那个统计量，其行为就是$N = 1$的行为。首项$\sqrt{2\ln N}$于是是一个错误的描述，而$\sqrt{2\ln 1} = 0$正是那个共享的统计量在零假设之下的期望。WF05没有走到那个极端。TPE试验经由共享的数据与采样器正相依，而不是全同。独立的计算与全同的计算夹住一个范围。它们认不出范围之内的那一点。要认出它，就需要那三十个分数的联合分布，而目录没有报告它，本图谱也不会发明它。诚实的输出是这一对计算，加上那条引用。
:::

:::history
哈尔伯特·怀特（Halbert White）2000年发表于Econometrica的现实检验，把一场搜索找到的最优规则，对"试过的规则里没有一条有价值"这条零假设做检验。它是后来那些收缩器的前身：搜索在检验的内部，而不是一场私下的热身。Bailey与洛佩斯·德·普拉多（2014年），在Journal of Portfolio Management上，定义了收缩（deflated）夏普比率，把一个被报告的夏普比率针对选择、试验的次数、样本、以及非正态的收益做校正。本章把2014年的那篇论文用作完整表达式所在地。本章用怀特，只用在一个历史观点上：一个被搜索过的最大值，才是要被检验的对象。这两篇论文都不是一条交易规则，除了正态首项$\sqrt{2\ln N}$与解释它的并集界之外，它们的符号在这里也都没有被复制。
:::

## 通向何处

一把尺度哪怕在本章的每一条假设都成立的情况下幸存下来，仍然会是一条已记录的历史的一个陈述。[[validation/what-a-fold-does-not-prove]]就是那堆折——清洗过、禁运过、收缩过——成不了一条去交易的决定，其原因所在。它作为输入采用的试验计数，是[[validation/parameter-search]]里的那些计数。它在种种假设之下借用的标准误，是[[performance/uncertainty-of-performance]]里的那一个，而被标准化的那个夏普比率，是[[performance/sharpe-and-its-relatives]]里的对象。假设检验作为一个主题、不附带一张窗口的网格，在数学图谱的[假设检验](/learn/maths/lesson.php?c=statistics&l=hypothesis-testing)那一章。

:::summary
- 在真零假设与独立正态试验之下，$N$个标准化的统计量的期望最大值像$\sqrt{2\ln N}$那样增长。
- Python给出$\sqrt{2\ln 9} = 2.096294\ldots$与$\sqrt{2\ln 30} = 2.608140\ldots$，三位小数即$2.096$与$2.608$。它们与WF04和WF05的试验预算相符。它们不是那些页面的夏普比率。
- 一个并集界把$\Prob(M_N > \sqrt{2\ln N})$压在$N = 9$处的$0.1903$之下、$N = 30$处的$0.1530$之下。首项没有被证明等于期望最大值。在$N = 2$处，期望最大值是$1/\sqrt{\pi} \approx 0.564$，而首项是$1.177$。
- 对独立标准正态，期望最大值随$N$上升。真实的金融试验不是独立的，所以这把尺度不是一张网格或TPE的一个经过校准的P 值。
- 样本长度在一个夏普比率被学生化时进来。2014年的收缩（deflated）夏普比率还对非正态性做校正。本课不写那个公式。
- 这把尺度不是一条年化的门槛，也不是一条去交易的决定。
:::

## 习题

:::exercise 一个更大的试验数 {level=1 check="3.035"}
用自然对数计算$\sqrt{2\ln 100}$，舍入到三位小数。（输入舍入后的值。）
:::solution
Python返回$3.034854\ldots$。第四位小数是$8$，所以舍入到三位小数的值是$3.035$。从$\sqrt{2\ln 9} = 2.096$到$3.035$的上升是真的，而且是慢的。一百次独立的正态试验与九次是不同的模型。它们仍然不是一条交易规则的一百次确认。
:::
:::

:::exercise 九次处的界 {level=1 check="0.190"}
对$N = 9$，计算并集界的天花板$1/\sqrt{4\pi \ln 9}$，并舍入到三位小数。（输入舍入后的值。）
:::solution
[[#ex-bound]]得到了$0.190308\ldots$。舍入到三位小数是$0.190$。在独立标准正态模型里，超过首项的概率小于$0.190$。它不等于$0.190$，而那个模型不是WF04。
:::
:::

:::exercise 哪个预算 {level=1 check="9"}
WF04给[[validation/parameter-search]]里那张九格的网格计分。对于那场搜索，哪个试验数$N$属于首项尺度？（输入$N$。）
:::solution
那场搜索给九个格子计了分，所以$N = 9$。WF01的一个折数$48$，不是WF04计过分的配置的数目。独立假设对这九个格子不成立，因为它们共享一条历史。这个不成立改变的是校准。它改变不了九个格子被计过分这个事实。
:::
:::

:::exercise 两个预算之间的差距 {level=2 check="0.512"}
计算$\sqrt{2\ln 30} - \sqrt{2\ln 9}$，用自然对数，并舍入到三位小数。（输入舍入后的差。）
:::solution
由[[#ex-sqrt]]，两个首项是$2.608140\ldots$与$2.096294\ldots$。差是$0.511846\ldots$，舍入为$0.512$。在独立正态模型之下，这就是预算从WF04的网格走到WF05的试验数时，尾部尺度上升的幅度。它不是期望财富的一次上升，而这两个预算对它们自己的数据也不是独立的。
:::
:::

:::exercise 一个每步的换算 {level=2 check="0.04176"}
用[[#ex-student]]的假设，$N = 9$而$n = 2520$，多大的每步夏普比率会学生化成那个首项？保留五位小数。（输入舍入后的每步值。）
:::solution
商$(2.096294\ldots)/\sqrt{2520}$等于$0.041759\ldots$，五位小数为$0.04176$。假设是一条真零假设、独立同分布的正态超额收益、无风险收益率$0$、以及洛的零假设标准误$1/\sqrt{n}$。这个结果不是收缩（deflated）夏普比率，也不是一条交易的门槛。我们不把它乘以$\sqrt{252}$。
:::
:::

:::exercise 完美相依 {level=2 check="0"}
全部$N$次试验交出恰好相同的标准化的统计量，而零假设为真，于是那个共享的统计量的期望是$0$。$\sqrt{2\ln 1}$是多少，即对一个单独共享的统计量合适的那个首项？（输入那个值。）
:::solution
$\ln 1 = 0$，所以$\sqrt{2\ln 1} = 0$，与那个零假设下的期望相符。独立的试验尺度$\sqrt{2\ln N}$若被用于全同的副本，会夸大选择效应。真实的TPE试验既不独立也不全同。这道习题只认出那两个极端。它没有为WF05估计一个相依校正。
:::
:::

:::exercise 让指数相消的那个水平 {level=3 check="2.197"}
对$N = 9$，[[#prop-union]]的证明取$t = \sqrt{2\ln 9}$，并使用$t^2/2 = \ln 9$。把$\ln 9$算到三位小数。（输入那个舍入后的对数。）
:::hint
自然对数就是首项里面的那一个。你在核对恒等式$t^2/2 = \ln N$，不是在造一个夏普比率。Python的`math.log(9)`就是自然对数。
:::
:::solution
`math.log(9)`返回$2.197225\ldots$，三位小数为$2.197$。于是按照$t$被选定方式，$t^2/2 = \ln 9$，而$N\exp(-t^2/2) = 9 \times e^{-\ln 9} = 9 \times (1/9) = 1$。那次相消，正是首项——而不是$\sqrt{\ln N}$的某个别的倍数——出现在并集界里的全部原因。把$\ln 9$舍入到$2.197$是一个展示上的选择。恒等式本身在舍入之前是精确的。
:::
:::

:::exercise 界在缩小、水平却在涨 {level=3 check="0.107"}
在$N = 1000$处计算并集界的天花板$1/\sqrt{4\pi \ln N}$，舍入到三位小数。然后说明一个更小的天花板为什么不意味着期望最大值在变小。（输入舍入后的天花板。）
:::hint
在更大的$N$处求[[#prop-union]]里同一个表达式。水平$\sqrt{2\ln N}$在向上移动，与此同时，超过它的概率的界在向下移动。
:::
:::solution
Python返回$0.107331\ldots$，舍入为$0.107$。在独立标准正态模型里，$N = 1000$处超过首项的概率小于$0.107$；而首项本身已经移到$\sqrt{2\ln 1000} = 3.716922\ldots$，三位小数为$3.717$。对一道更高的横杆的一次更罕见的越过，与一个更大的期望最大值是相容的。[[#prop-rise]]已经说了期望最大值随$N$增大。缩小的天花板不与它矛盾。这两个数都不是收缩（deflated）夏普比率，而一千次独立的正态试验，不是一条金融历史的描述。
:::
:::
