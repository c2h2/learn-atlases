一条已记录的历史的四十八个切片，仍然是一条已记录的历史。一道清洗可以让一个标签不再越过一道切分。一道禁运期可以为序列相依插进一道间隔。一场网格搜索可以被数下来，而一把首项尺度可以在一场搜索并不满足的假设之下算出来。这些修补没有一样能造出第二条路径。一次走步验证跑出规格说明所希望的样子，是关于那条被喂进来的路径、在被写下来的那些规则之下的一个事实。它不是一条新历史上的重复，不是关于每一个资产类别的结果，也不是一条去交易的决定。

WF01是要摆在眼前的那张页面。按quants.md对那个QuantJourney示例（Apache-2.0）的报告，按2026年的阅读，它在26年跨距上有48折滑动的折，每次测试之前都有一道清洗，而目录把这些输出称为切片诊断，而非独立的样本外证据。本图谱没有重跑过那个回测。同一句话也盖住WF02与WF03。在前面几章的机器就位之后，本章就是那句话的用处。机器是值得有的。它压不过那句话。

## 折是一条路径的函数

:::definition 折统计量 {#def-foldstat}
固定一条已记录的价格路径与一份规格说明：样本池、时钟、规则、窗口、清洗、禁运期、成本与计分函数。第$k$折的**折统计量**，就是那个计分函数在第$k$折的测试窗上返回的那个数。它是那一条路径与那份规格说明的一个函数。全体折统计量组成的向量，是同样那两个对象的函数。
:::

这个定义是有意严苛的。它没有提到一个关于路径的抽样分布，因为只有一条历史的研究者并没有抽取过一条。它也没有提到一个经纪商、一笔订单、或任何人应当持有的一个头寸。改规格说明，就改函数。一条路径的两个函数可以作为代数来比较。它们不能被堆在一起，然后称为一次来自一个从未被观察过的历史总体的抽样。

:::definition "通过"被允许是什么意思 {#def-passed}
在本图谱唯一使用的意义上，一次**通过的走步验证**，是指一个由规格说明固定的计分规则，在一条已记录的路径的测试窗上，满足了一个同样由规格说明固定的数值条件。它不是一个预测、一条独立历史上的重复，也不是一条买入、卖出、持有、加杠杆或选择一家经纪商的决定。
:::

:::proposition 一条路径，一个sigma-代数 {#prop-one}
设已记录的价格是一个序列$P_0, \ldots, P_{T-1}$。[[#def-foldstat]]里的每个折统计量都是这个序列的一个函数。$K$个折统计量组成的向量因此是一条序列的一个函数。它不是$K$个独立复制的样本——那种复制会把一个折统计量算在$K$条独立的序列上——因为那些别的序列没有被观察到。互不相交的测试窗改变不了这个结论：一条序列的互不相交的函数，仍然是一条序列的函数。
:::

:::proof
由[[#def-foldstat]]，第$k$折的统计量$\theta_k$由规格说明、以及由落在$P$上的那些索引处的价格算出。映射$P \mapsto (\theta_1, \ldots, \theta_K)$于是是一个单自变量的函数。一次跨历史的独立复制，本应是对$K$条序列的抽取，每条产生自己的$\theta$，并且联合分布发生分解。这样的抽取没有做过。把进入$\theta_k$的那些索引限制到测试窗互不重叠，改变的是每个$\theta_k$读取$P$的哪些坐标。它没有添上第二条序列。若一个体制、一个漂移或一个波动率水平本身是$P$的函数，并且比测试长度变化得更慢，那么若干个$\theta_k$读的就是同一个慢函数的碎片。它们的一致，更多是那个慢函数的再次露面。
:::

这条命题就是那个否定结论的全部。它没有说折统计量没有用。一条路径的函数仍然可以测出一个坏掉的时钟、一个把毛收益吞掉的成本模型、或一条所有测试窗都失败的规则。那些是已经跑过的这个实验的事实。这条命题只说，这些事实是关于那个实验的。WF01的48折，是一条26年跨距的一条路径的一个函数的48个坐标。目录的那句"切片诊断，而非独立的样本外证据"，就是[[#prop-one]]用库自己的话写出的样子。

当每个测试窗都坐在同一场牛市里时，折与折之间的一致特别容易被读过头。两条只做多的规则，或者同一条只做多的规则被计了两次分，只要路径在这两个窗口里都是上涨的，就都会挣钱。这两个窗口不必共享一天。共享的对象是那个上涨。把一致称为两个实验，就是把那个上涨数了两遍。

:::example 两个不共享一天的牛市窗口 {#ex-bull}
折A的简单收益率是$0.01$、$0.02$、$-0.005$、$0.015$、$0.01$。折B在更晚且互不相交的日期上，简单收益率是$0.012$、$0.008$、$0.02$、$-0.004$、$0.011$。这些收益率是为了这个计数编造的。它们不是一条库内的路径，也不是路径A。计算每个窗口的平均收益率与复合简单收益率。一个只做多的头寸全程持有于这两个窗口，无成本。这两个复合数的一致，算得上两个实验吗？
:::solution
折A的和是$0.01 + 0.02 - 0.005 + 0.015 + 0.01 = 0.05$，所以均值是$0.05/5 = 0.01$。毛乘积是$1.01 \times 1.02 \times 0.995 \times 1.015 \times 1.01 = 1.050829$，保留六位小数，复合简单收益率是$0.050829$。

折B的和是$0.012 + 0.008 + 0.02 - 0.004 + 0.011 = 0.047$，所以均值是$0.0094$。毛乘积保留六位小数是$1.047736$，复合简单收益率是$0.047736$。

两个复合数都是正的，而两个窗口不共享索引。一位同学如果说这条规则被确认了两次，他就是把一个向上的漂移数了两遍。同一批日期上一个买入持有的头寸有同样的复合数，因为那个头寸全程是多头。这一折并没有把那条规则与那个体制分开。[[#prop-one]]是同一个观点的抽象形式：两个统计量都是一条牛市路径的函数。这两个复合数的符号里，没有任何一样是一个对任何被交易的资产做多的决定。
:::
:::

:::example 一次崩盘，两个重叠的窗口 {#ex-crash}
索引$0$到$6$的简单收益率是$0.002$、$0.001$、$-0.05$、$0.002$、$0.001$、$0.003$、$0.002$。窗口1是索引$0$到$4$。窗口2是索引$2$到$6$。步长短于窗口，所以两个窗口重叠。计算每个窗口的平均值与复合简单收益率。然后去掉共享的那个崩盘收益率，把窗口1的平均值重新算一遍，剩下其余四个收益率。
:::solution
窗口1的和是$0.002 + 0.001 - 0.05 + 0.002 + 0.001 = -0.044$，所以均值是$-0.0088$。复合简单收益率保留六位小数是$-0.044288$。窗口2的和是$-0.05 + 0.002 + 0.001 + 0.003 + 0.002 = -0.042$，所以均值是$-0.0084$。复合简单收益率保留六位小数是$-0.042378$。

两个窗口看起来都是小亏，而两笔亏损都是那个$-0.05$的崩盘坐在寥寥几笔极小的收益率之中。重叠是索引$2, 3, 4$。把$-0.05$从窗口1里去掉，剩下$0.002$、$0.001$、$0.002$、$0.001$，它们的平均值是$0.0015$，复合简单收益率保留六位小数是$0.006013$。那个五天平均值的符号，就是那个共享的日子。

这就是[[validation/walk-forward]]里的几何相依，被做成了数值。这是一种与[[#ex-bull]]不同的机制，那里两个窗口不共享任何一天，却仍然一致。一堆折成不了两个实验，既可能因为测试互相重叠，也可能因为一个体制比它们之间的间隔更长。WF01的目录那一行，没有说道它的步长是否等于测试长度。无论哪种情形，[[#prop-one]]都适用。
:::
:::

## 一个模型，看计数塌得有多快

不必假装测量过WF01，也可以给这个塌缩安上一个数。这个数是一个模型。库表没有报告折分数之间的相关，而本图谱不会发明一个。

:::proposition 等相关下的有效计数 {#prop-keff}
设$X_1, \ldots, X_K$有共同的方差$\sigma^2 > 0$与共同的两两相关$\rho$，把它们的平均记作$\bar X$。协方差矩阵是$(1-\rho)I + \rho\,\mathbf{1}\mathbf{1}^{\mathsf{T}}$，其中$\mathbf{1}$是全1向量。它的特征值是重数为$K-1$的$1-\rho$，与重数为$1$的$1+(K-1)\rho$。这个矩阵是半正定的，当且仅当$-1/(K-1) \le \rho \le 1$。只要它是，

$$
\Var(\bar X) = \frac{\sigma^2}{K}\bigl(1+(K-1)\rho\bigr).
$$

由$\sigma^2/K_{\mathrm{eff}} = \Var(\bar X)$定义的**有效计数**是$K_{\mathrm{eff}} = K / \bigl(1+(K-1)\rho\bigr)$。若$\rho = 0$，则$K_{\mathrm{eff}} = K$。若$\rho > 0$，则$K_{\mathrm{eff}} < K$。若$\rho \to 1$，则$K_{\mathrm{eff}} \to 1$。
:::

:::proof
若$v$与$\mathbf{1}$正交，则$\mathbf{1}^{\mathsf{T}} v = 0$，所以这个矩阵把$v$送到$(1-\rho)v$。全1向量本身被送到$(1-\rho)\mathbf{1} + \rho K \mathbf{1} = \bigl(1+(K-1)\rho\bigr)\mathbf{1}$。这些就是特征值，重数如所述，因为$\mathbf{1}$的正交补的维数是$K-1$。两个特征值都非负，恰当$\rho \le 1$且$\rho \ge -1/(K-1)$。

至于方差，把$\Var(\sum_i X_i) = K\sigma^2 + K(K-1)\rho\sigma^2 = K\sigma^2\bigl(1+(K-1)\rho\bigr)$展开。除以$K^2$就得到平均的方差。把它等于$\sigma^2/K_{\mathrm{eff}}$，再解出。与$K$以及与$1$的比较，由$\rho$的符号与那个极限直接得到。
:::

对$K = 48$，$\rho$的下界是$-1/47$，约$-0.0213$。一个$48$个折分数的等相关模型，不可能合法地带有一个大的负相关。模型之内可用的说法只有"几乎不相关"与"正相关，因此有效计数小得多"。那是一个数学限制，不是一个关于WF01的发现。它确实挡得住一种特定的借口。一个人不能一边留在等相关里，一边说"折是强负相关的，所以它们$48$个甚至比$48$个独立观测更值钱"。强的负等相关对$K = 48$不是一个可能的协方差。

:::example 四十八折，两个假定的相关 {#ex-keff}
在$K = 48$下假设[[#prop-keff]]的模型。计算$\rho = 0.5$与$\rho = 0.2$处的$K_{\mathrm{eff}}$。说明这个计算不是什么。
:::solution
在$\rho = 0.5$处，分母是$1 + 47 \times 0.5 = 24.5$，而$K_{\mathrm{eff}} = 48/24.5 = 96/49 = 1.959184\ldots$，两位小数为$1.96$。在$\rho = 0.2$处，分母是$1 + 47 \times 0.2 = 10.4$，而$K_{\mathrm{eff}} = 48/10.4 = 60/13 = 4.615385\ldots$，两位小数为$4.62$。

在二分之一的相关之下，四十八个等相关的折，就其平均的方差而言，表现得像大约两个独立观测。在$0.2$的相关之下，它们表现得像大约五个。这两个$\rho$都不是对WF01、WF02或WF03的测量。目录没有报告它。这段算术展示的是模型之内塌缩的速率：根本不需要一个靠近$1$的相关，$48$就不再是一个相关的样本量。把$K_{\mathrm{eff}}$当作一个从库页面上估计出来的标准误输入来用，会假装我们估计过了$\rho$。我们没有。
:::
:::

## 一个无视切分的体制

哪怕互不相交的折，当体制跨过边界持续存在时，也共享一个体制。一个两状态的草图就足够看见这种持续性，而它是一幅草图。它不是库里任何市场的拟合模型。

取平静与压力两个状态，以及行和为一的转移矩阵

$$
\begin{pmatrix} 0.85 & 0.15 \\ 0.30 & 0.70 \end{pmatrix}.
$$

从平静出发，下一步以概率$0.85$仍是平静。从压力出发，下一步以概率$0.70$仍是压力。落在两步之间的一道折边界不会重置状态。这条链就是下面那张图的内容。

:::example 这条链通常待在原地 {#ex-markov}
对上面的转移矩阵，求平静的平稳概率，以及一步之后的状态与当前状态相同的平稳概率。
:::solution
设$\pi_C$是平静的平稳概率，$\pi_S = 1 - \pi_C$。平稳性给出$\pi_C = 0.85\,\pi_C + 0.30\,\pi_S$。代入$\pi_S$：$\pi_C = 0.85\,\pi_C + 0.30(1-\pi_C) = 0.55\,\pi_C + 0.30$。于是$0.45\,\pi_C = 0.30$，所以$\pi_C = 0.30/0.45 = 2/3$，而$\pi_S = 1/3$。

在平稳分布之下，留在当前状态的概率是

$$
\frac{2}{3}\times 0.85 + \frac{1}{3}\times 0.70 = \frac{1.70 + 0.70}{3} = \frac{2.40}{3} = 0.80.
$$

在这个平稳草图里，五次里有四次，边界之后的状态等于边界之前的状态。于是相邻的折哪怕不共享任何日历索引，也共享一个体制。这个矩阵是为了图景清楚而选的，不是从价格估计的。改对角线上的元素，会改$0.80$。它改不了那个定性的教训：跨过一道切分的持续性，是一条对角线很大的链的默认行为，而一道走步验证的切分不会造出这条链的一次新的抽取。
:::
:::

:::widget markov
matrix: 0.85,0.15; 0.30,0.70
states: Calm; Stress
steps: 24
caption: 一个两体制的草图，不是一个拟合的市场，也不是一个库内的结果。平静以概率0.85保持平静。落在两步之间的一道折边界通常不改变状态，所以相邻的折共享一个体制，哪怕它们的测试窗互不相交。
:::

:::intuition 边界不是一个新的世界
把折边界画在一条已经生成出来的路径上，画成一条竖线。这条线改变的是你把哪些日期称为"测试"。它不会重掷这条路径。若路径在线的左边是平静的，上面那条链在线的右边通常仍是平静的。两个都算得很好的折统计量，于是都是在平静状态里读出来的。它们的一致，是持续性造出来的东西。它不是对两个世界的两次访问。
:::

## 一个资产类别，一份规格说明，一道订单

一条路径不只是一条时间序列。它是一个样本池。在本图谱引用的那张表里，WF01的摘要给出了折数、几何、清洗、诊断的告诫，以及一段26年的跨距。在那张表里，它没有重述资产清单。无论那个页面用了什么清单，结果都是关于那个清单在那段跨距上的。第二个资产类别是第二个实验。股票账簿、期货账簿与外汇账簿，是对不同工具的不同函数，这就是它们住在[[asset-classes/equity-etf-books]]、[[asset-classes/futures]]与[[asset-classes/foreign-exchange]]里、而不是作为一次走步验证的推论的原因。本章不给那些工具排序，也不建议持有任何一个。它说的是：其中一个上的一次通过，不会是其余那些上的一次通过。

规格说明是同一个观点的一部分。[[#def-foldstat]]把成本包括在内。改成本，折统计量就改。一个毛复合收益率与一个净复合收益率，不是同一个实验的两种意见。它们是两份规格说明。[[research-craft/writing-a-specification]]正是要求一份规格说明点名样本池、时钟、窗口、成本、统计量与搜索的地方。在这些字段被填上之前，"这一折通过了"并不指称一个对象。

:::example 同样的窗口，一个写明的成本 {#ex-cost}
用[[#ex-bull]]里折A的毛乘积，即六位小数的$1.050829$。一份规格说明在窗口开始处收取一笔一次性成本，为初始名义本金的比例$c$，再无其他成本。期末净值是毛乘积的$(1-c)$倍。计算$c = 0.01$与$c = 0.05$处的净复合简单收益率。这些成本是为这段算术编造的。它们不是一项被推荐的费用，也不是一个库内的输入。
:::solution
在$c = 0.01$处，期末净值是$0.99 \times 1.050829 = 1.040321$，六位小数，净复合收益率是$0.040321$。在$c = 0.05$处，期末净值是$0.95 \times 1.050829 = 0.998288$，六位小数，净复合收益率是$-0.001712$。

毛复合数是$0.050829$。一份规格说明仍然显示一笔盈利。另一份只差一个写明的成本，显示的是一笔亏损。两者都是同样五个收益率的函数。两者都不是新的一条路径上的一次确认，而这个符号不是折的几何的一个性质。它是规格说明的一个性质。一份说走步验证通过了、却没有点名$c$的写作，没有说是哪个函数通过了。本图谱也不接着去推荐那个成本、那个窗口、或任何一笔会把这两者之一付诸实盘的交易。
:::
:::

:::warning 通过不是一道订单
假设每个测试窗都满足了规格说明的数值条件，清洗就位，试验计数已经披露，而一把选择尺度是在作者真正相信的假设之下算出来的。输出仍然是一条历史路径的一个陈述。它不包含买入、卖出或持有任何证券的指令，不包含偏好一个资产类别、选择一家经纪商、或把一条quants.md曲线当作预测的指令。[[#def-passed]]是对词汇的一条限制。"通过"可以意味着规格说明里的那个不等式在这条路径上成立。它不可以意味着"交易它"。
:::

:::quiz
两个互不相交的测试窗都坐在同一个上涨的市场里，而一条只做多的规则在每个窗口都挣到了一个正的复合收益率。这证明了什么？
- [ ] 两次独立的重复，因为两个窗口不共享日期。
- [ ] 一个保留多头头寸的决定，因为两折取得了一致。
- [x] 同一条上涨的路径造出了两个正的分数。两个窗口之间的一致不是两个实验。
- [ ] 这个结果延伸到每一个资产类别，因为那个符号不依赖于上涨内部那些特定的日期。
:::solution
[[#ex-bull]]就是这个情形的数字版。两个窗口可以互不相交，却仍然是一条漂移的两次读取。一个正的符号不是一道订单，一个样本池也不是每一个样本池。
:::
:::

:::quiz
在$K = 48$、$\rho = 0.5$的等相关模型下，有效计数会怎样？
- [ ] 它保持$48$，因为模型假设了共同的方差。
- [ ] 它超过$48$，因为正相关是有信息量的。
- [x] 就平均的方差而言，它落到$96/49$，约$1.96$。这是一个模型，不是对WF01的一个测量。
- [ ] 对任何正相关，它都恰好等于$1$。
:::solution
[[#prop-keff]]给出$K_{\mathrm{eff}} = 48/(1+47\times 0.5) = 96/49 \approx 1.96$。这个计数只在极限$\rho \to 1$处等于$1$。目录没有报告$\rho$，所以这个数是一个塌缩的例证，不是WF01的一个经过估计的标准误。
:::
:::

:::application 重述WF01，而不升格它
WF01仍然是48折滑动的折，26年，每次测试之前一道清洗，外加一个目录身份：切片诊断，而非独立的样本外证据。按quants.md对那个QuantJourney示例（Apache-2.0）的报告，按2026年的阅读，而这里没有重跑，那就是全部数值主张。本章添进去的东西是否定性的，而那正是要点。那些折共享一条路径。它们可能共享体制。它们坐在一个样本池里。一把来自[[validation/the-deflated-sharpe]]的选择尺度，哪怕它的假设都曾成立，也仍然是那条路径的一个统计量的尺度。它不会是第二条路径。把这个页面当作$48$次确认的一堆，或把它当作交易其中那条规则的理由，既与这个页面自己的身份相矛盾，也与[[#prop-one]]相矛盾。
:::

:::remark 负相关几乎不可用
当$\rho < -1/(K-1)$时，特征值$1+(K-1)\rho$为负。对$K = 48$，那个下限是$-1/47 \approx -0.0213$。等相关的折分数不可能既是强负相关的、又有一个合法的协方差。有效计数只在零之下一个窄窄的区域里，才可以略微超过$48$。任何指望"折之间的分散化"会让$48$个切片值钱到几百个独立观测的人，都在模型之外，而不是在模型里一个讨人喜欢的角落。重叠的窗口与持续的体制把$\rho$推高，而不是压低。这个模型没有在库页面上测量那次推动。
:::

:::history
怀特（White）的现实检验（Econometrica，2000年）早已要求：一条被搜索找到的规则，要作为一条被搜索过的规则来评判，对"试过的规则里没有一条有价值"这条零假设。Bailey与洛佩斯·德·普拉多（Journal of Portfolio Management，2014年）把同一种直觉带进了夏普比率。两篇论文谈的都是研究者手中数据上一个统计量的分布。本章再往前的那一点，比这两个公式中的任何一个都更老，也不是从他们那里引来的话。一条历史的路径，无论被切片、清洗、搜索、收缩得多么小心，仍然是一条路径。开放库的走步验证页面用切片诊断的语言说了这一点。上面的数学，是那种语言并非为谦逊而谦逊的原因。它就是那些页面实际拥有的样本。
:::

## 通向何处

一折即便被拒绝了交易的资格，仍然必须被写得足够精确，让另一个人能够重算它。那份文书就是[[research-craft/writing-a-specification]]。它点名的切分是[[validation/walk-forward]]与[[validation/purging-and-embargo]]。它必须披露的试验数是[[validation/parameter-search]]，而它不得说错的那把选择尺度是[[validation/the-deflated-sharpe]]。带着同样的拒绝去读别人发表的一条曲线，是[[backtesting/reading-published-tests]]。

:::summary
- 每个折统计量都是一条已记录的路径与一份规格说明的一个函数。其中四十八个，是一个带四十八个坐标的函数，不是四十八条历史。
- 互不相交的测试窗去掉的是共享的日期。它们去不掉一个共享的体制。两个牛市窗口可以不共享一天却彼此一致。
- 重叠的窗口可以把一次崩盘放进两个平均值里。在算到底的崩盘例子里，删去那个$-0.05$的共享收益率，把第一个窗口的平均值从$-0.0088$翻成了$0.0015$。
- 在等相关之下，$K = 48$与$\rho = 0.5$给出$K_{\mathrm{eff}} = 96/49 \approx 1.96$。在$\rho = 0.2$处，有效计数是$60/13 \approx 4.62$。这些不是对WF01的估计。
- 对$K = 48$，等相关要求$\rho \ge -1/47$。强的负相关跨折，在模型之内是不可用的。
- 一次通过的走步验证，是关于一份规格说明与一条路径的一个数值事实。它不是一条去交易的决定，也不是关于每一个资产类别的一个结果。
:::

## 习题

:::exercise 独立的基准 {level=1 check="48"}
在等相关模型里，$K = 48$而$\rho = 0$。有效计数是多少？（输入那个计数。）
:::solution
[[#prop-keff]]给出$\rho = 0$时$K_{\mathrm{eff}} = K$，所以计数是$48$。这是其他值从中离开的那个基准。它不是WF01的相依结构。独立的折分数需要那个命题置为零的协方差，而一条共享的路径不会免费提供那个协方差。
:::
:::

:::exercise 二分之一处的分母 {level=1 check="24.5"}
对$K = 48$与$\rho = 0.5$，计算分母$1+(K-1)\rho$。（输入那个分母。）
:::solution
$1 + 47 \times 0.5 = 1 + 23.5 = 24.5$。有效计数是$48/24.5$，不是$24.5$本身。这个问题只问那个分母，也就是相依相对于独立情形把平均的方差放大的那个因子。
:::
:::

:::exercise 重叠的长度 {level=1 check="6"}
两个相继的测试窗长度为$H = 10$，步长为$S = 4$。有多少个索引同时落在两个窗口里？（输入那个计数。）
:::solution
重叠是$H - S = 6$，依据[[validation/walk-forward]]里的滑动几何。六个共享的收益率，就足以让两个窗口平均值成为一条路径的一个公共片段的函数。有效计数模型是进一步的、可选的一个摘要。重叠本身已经是相依，在索引算术里看得见，而且它不需要一个相关参数。
:::
:::

:::exercise $\rho = 0.2$处的有效计数 {level=2 check="4.62"}
用[[#prop-keff]]，$K = 48$而$\rho = 0.2$，计算有效计数并舍入到两位小数。（输入舍入后的值。）
:::solution
分母是$1 + 47 \times 0.2 = 10.4$。于是$48/10.4 = 60/13 = 4.61538\ldots$，舍入为$4.62$。在这个模型之内，$0.2$的相关之下，四十八折变成大约五个有效观测。这个模型不是对WF01的拟合，而$4.62$也不是一个可以被丢进那个页面的某个标准误里的样本量。
:::
:::

:::exercise 一个翻掉符号的成本 {level=2 check="-0.001712"}
一个测试窗的毛乘积是$1.050829$。一笔一次性成本为初始名义本金的比例$c = 0.05$，在开始处收取，期末净值是毛乘积的$(1-c)$倍。净复合简单收益率是多少，保留六位小数？（输入舍入后的净收益率。）
:::solution
期末净值是$0.95 \times 1.050829 = 0.99828755$，净复合收益率是$0.99828755 - 1 = -0.00171245$，舍入为$-0.001712$。毛复合收益率本来是正的，约$0.050829$。带$c = 0.05$的规格说明没有通过一个"正的净复合"条件。带$c = 0$的通过了。它们是同一些收益率上的两个不同的实验。这笔成本是为算术编造的，不是任何人被告知要去支付的一笔费用，而这个符号也不是一笔交易。
:::
:::

:::exercise 链的一步 {level=2 check="0.85"}
[[#ex-markov]]里的链现在是平静的。下一步仍是平静的概率是多少？（输入那个概率。）
:::solution
转移矩阵的第一行给出$0.85$。于是，若状态是平静的，落在单独那一步上的一道折边界，就以概率$0.85$在两侧看到同一个体制。例题里的那个平稳计算对起始状态取了平均，得到$0.80$。两个数说的是同一件定性的事：那道切分不是一次新的抽取。这两个数都不是从市场数据里来的估计。
:::
:::

:::exercise 哪个相关把四十八砍到二 {level=3 check="23/47"}
在$K = 48$的等相关模型里，哪个相关$\rho$产生$K_{\mathrm{eff}} = 2$？（输入精确值。）
:::hint
设$48 / \bigl(1+47\rho\bigr) = 2$，解出$\rho$。核对结果坐在$-1/47$之上，好让协方差仍然合法，并忍住不把$\rho$称为WF01的一个性质。
:::
:::solution
方程$1+47\rho = 48/2 = 24$给出$47\rho = 23$，所以$\rho = 23/47$。数值上$23/47 = 0.489362\ldots$，刚好低于二分之一，与[[#ex-keff]]相符：在$\rho = 0.5$处，有效计数已经是$96/49 \approx 1.96$，比$2$差之毫厘。由于$23/47 > 0 > -1/47$，矩阵是正定的，模型是合法的。这个值是在等相关内部、四十八折要携带两个独立观测的方差信息所必须存在的那个相关。它不是从WF01那页页面上估计出来的相关。那一页没有报告相关。
:::
:::

:::exercise 改写那个主张 {level=3}
一位同学说："两个测试窗都是正的，所以这条规则被确认了两次，而你应该交易它。"那两个窗口就是[[#ex-bull]]里的两个牛市窗口。它们不共享日期。把这个主张改写成一条关于一条路径的陈述，并说出两个这份证据不支持的决定。
:::hint
数路径，不数折。[[#def-passed]]限制了"通过"这个动词。本图谱不把一折转换成一道订单、一家经纪商或第二个资产类别。两个窗口的一致，就是[[#ex-bull]]里算出的那个共享的上涨。
:::
:::solution
两个复合数都是一条编造的上涨路径的函数。折A的复合数约为$0.050829$，折B约为$0.047736$。它们不共享索引，却仍然共享路径上涨这个事实。一个只做多的头寸挣到那个上涨，是因为它是多头，不是因为两条历史取得了一致。合法的那句话是：在这一条路径上，在一个无成本的只做多的规格说明之下，两个测试窗的复合简单收益率都是正的。

这份证据不支持一个交易这条规则的决定，也不支持把结论搬到第二个资产类别上、或搬到一笔实盘订单上。它也不支持把两个窗口称为独立的重复。[[#prop-one]]禁止那次升格，甚至早到任何人还没问那个上涨是否还会再来。那位同学的"你应该交易它"在本图谱之外。一份规格说明仍然可以被写下来，如[[research-craft/writing-a-specification]]那样，让那个数值事实可以被复现。可复现与可交易不是一回事。
:::
