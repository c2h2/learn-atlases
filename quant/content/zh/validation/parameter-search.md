搜索不是验证。一张网格给九个移动平均窗口的组合按一个样本内夏普比率计分，然后引用这九个数里最大的那个，就施行了九个实验、然后留下了赢家。赢家是一个**被选定的统计量**。它的分布，哪怕在一条"没有优势"的真零假设之下，也是一个最大值的分布，而不是一个在任何分数被看到之前就写下来的窗口所对应的数的分布。把这个赢家冻结、事后再对它做走步验证，是一个后来的协议。那不是一种重新解释，仿佛那九个分数从来就是九次确认。

开放库把这两个阶段分得比大多数发表的曲线更细。按quants.md对那些QuantJourney示例（Apache-2.0）的报告，按2026年的阅读，WF04给九种组合的一张网格计分：快窗取$\{20, 50, 80\}$，慢窗取$\{100, 150, 200\}$，每一种组合都作为一个回测跑一遍、按一个夏普比率计分，跨距$26$年。WF05对整数简单移动平均窗口跑Optuna的Tree-structured Parzen Estimator的$30$次试验，快窗严格短于慢窗，然后对赢家跑一次滑动走步验证，同样是$26$年。本图谱没有重跑过这两个页面。库表没有报告九个格子级的夏普比率、没有报告获胜的窗口、也没有为走步验证阶段报告一个夏普比率。那些缺席的格子保持缺席。下面算到底的例子里的数字，是为一个最大值的算术编造的。它们不是对WF04的重构。

那三十次试验不是三十次确认。它们是那场搜索。那个走步验证——如果赢家在它开始之前就被冻结——是对一个被冻结的选择的后来一次检验。如果走步验证的结果被允许把研究者送回去改选另一次试验，那走步验证就已经被当作又一步搜索花掉了。

## 一张网格是一份试验清单

:::definition 网格与试验 {#def-trial}
一次**试验**是一个被完全说明的配置，在一个明说的样本上、由一个明说的统计量计分一次。一张**网格**是由取所列参数值的每一种组合得到的试验集合，可以在一条会剔掉非法组合的约束之后再取。试验数$N$是实际被计分的配置数目。搜索从未跑过的配置不贡献$N$，也不贡献那个最大值。
:::

按目录读出的WF04网格，是笛卡尔积

$$
\{20, 50, 80\} \times \{100, 150, 200\}.
$$

共有$3 \times 3 = 9$个对子：$(20,100)$、$(20,150)$、$(20,200)$、$(50,100)$、$(50,150)$、$(50,200)$、$(80,100)$、$(80,150)$、$(80,200)$。每一个对子都满足快窗 $<$ 慢窗，因为快窗的最大值是$80$，而慢窗的最小值是$100$。在这张具体的网格上，这条约束没有剔掉任何格子。在两个取值区间相互穿插的一张网格上，同一条约束会剔掉格子，而$N$是幸存者的数目，不是那个矩形的面积。WF05点明这条约束，因为它的整数区间可能相互穿插。目录没有发表那些区间。它发表的是试验预算，$30$，以及那条约束。

WF04的九个格子，每一个都是"按一个真实回测的夏普比率计分"，这是目录的措辞。我们自己那些短例子里的夏普比率，是平均超额简单收益率除以超额简单收益率的样本标准差，无风险收益率明说（通常为零），并且除非点名了一个因子就没有年化。库已报告的夏普比率，只要某个页面报告了一个，未必用这套约定。WF04的页面，在本图谱引用的那张表里，根本没报告那九个数。把一个格子称为"那条"移动平均策略，是把菜单与一道菜混为一谈。移动平均那一章拥有作为一条规则的交叉。本章拥有这个事实：九个被计分的交叉是一场搜索。

:::algorithm 枚举一张带约束的网格 {#alg-enum}
列出快值与慢值。对每一个对子，若它满足约束——这里是快窗 $<$ 慢窗——就保留，否则丢弃。把每一个保留的对子计一次分，样本由规格说明点名，统计量也由规格说明点名。把$N$记为保留并被计分的数目。被选定的值是这$N$个分数的最大值，连同达到最大的那个对子的身份。并列是结果的一部分：若两个对子共享最大值，在任何一个对子被称为赢家之前，规格说明需要一个平局裁定。
:::

:::example 一条真的会剔格子的约束 {#ex-constraint}
快窗是$\{10, 20, 30\}$，慢窗是$\{15, 25, 40\}$。只当快窗严格短于慢窗时保留一个对子。列出幸存的对子与被计分的数目。
:::solution
矩形有$3 \times 3 = 9$个对子。幸存者是$(10,15)$、$(10,25)$、$(10,40)$、$(20,25)$、$(20,40)$与$(30,40)$。被丢弃的对子是$(20,15)$、$(30,15)$与$(30,25)$，其中快窗至少和慢窗一样长。所以$N = 6$，不是$9$。WF04自己的九个对子在同样风格的约束下全部幸存，这正是那个页面的试验数是$9$而不是更小数的原因。计数跟着清单走，不跟着你本来可能先画出来的那个矩形的形状走。
:::
:::

## 最大值是一个不同的随机变量

设$X_1, \ldots, X_N$是$N$次试验的分数，记$M = \max\{X_1, \ldots, X_N\}$。若单独一个对子$(j)$在任何分数算出之前就被指定，那么被关注的对象是$X_j$。搜索之后，被引用的对象是$M$。它们不是数据的同一个函数。选择不是一个普通平均之上装门面的描述。它改变的是被估计量。

:::definition 被选定的统计量 {#def-selected}
一个统计量被称为**被选定的**，当被报告的那个数据的函数、本身是看着数据挑出来的。$N$次试验分数的最大值是被选定的。赢家那次试验的分数也是。一个附在分数被看到之前就固定的配置上的分数，没有被这场搜索选定，尽管它可能被更早的、未被报告的一场搜索选定过。
:::

:::proposition 最大值压在一个事先指定的试验之上 {#prop-max}
设$X_1, \ldots, X_N$是可积随机变量，记$M_N = \max_{i \le N} X_i$。则$\E[M_N] \ge \E[X_1]$。若$\Prob(M_N > X_1) > 0$，不等式是严格的。特别地，若$X_1, \ldots, X_N$是独立同分布的连续随机变量，则只要$N > 1$就有$\E[M_N] > \E[X_1]$。
:::

:::proof
最大值至少和第一个坐标一样大，所以$M_N - X_1 \ge 0$。一个非负随机变量的期望为零，当且仅当该变量几乎必然为零；而当它以正概率为正时，期望为正。于是$\E[M_N] \ge \E[X_1]$，而且不等式严格恰当$\Prob(M_N > X_1) > 0$。

若这些变量独立同分布且连续，且$N > 1$，则$\Prob(X_2 > X_1) > 0$，从而$\Prob(M_N > X_1) > 0$。最大值的可积性由$\abs{M_N} \le \abs{X_1} + \cdots + \abs{X_N}$得到。
:::

这条命题是有意放低的。它没有给出那个差距的大小，也不假设正态分布。它说的是：在一条每个事先指定的试验都有同样期望分数的真零假设之下，只要$N > 1$而且分数可以不同，赢家的期望就更大。把$M_N$当作它有$X_1$的期望那样引用，就是那个选择偏误。这个偏误有多大——以标准化单位计、在一个正态近似之下——是[[validation/the-deflated-sharpe]]的工作。那一章还得说道那个正态近似在哪里不适用。同一条历史上的金融试验是相依的，而一个序贯采样器还会造出更多的相依。[[#prop-max]]以它的弱形式$\E[M_N] \ge \E[X_1]$在相依之下幸存，因为证明从头到尾没有去分解那个联合分布。严格增大用到的那个条件，完美相依可以让它失效：若$X_2 = X_1$恒成立，最大值纹丝不动。

:::example 编造的九个样本内分数 {#ex-nine}
下面九个数是编造的样本内夏普比率，无风险收益率$0$，未年化，一个格子一个。它们不是WF04的结果，而库表没有报告那些结果。按顺序$(20,100)$、$(20,150)$、$(20,200)$、$(50,100)$、$(50,150)$、$(50,200)$、$(80,100)$、$(80,150)$、$(80,200)$，分数是

$$
0.21,\ 0.45,\ 0.33,\ 0.12,\ 0.58,\ 0.40,\ 0.27,\ 0.51,\ 0.36.
$$

求最大值、均值、两者之间的差距，以及中位数。
:::solution
以百分之一为单位相加，$21+45+33+12+58+40+27+51+36 = 323$。均值是$323/900 = 0.358\overline{8}$，四位小数为$0.3589$。最大值是$0.58$，在编造的格子$(50,150)$处。最大值与均值之间的差距是$0.58 - 323/900 = 199/900 = 0.22\overline{1}$，四位小数为$0.2211$。

排序之后，九个数是$0.12$、$0.21$、$0.27$、$0.33$、$0.36$、$0.40$、$0.45$、$0.51$、$0.58$。中位数是第五个，$0.36$。最大值超出中位数$0.22$。

格子$(50,150)$是这张编造清单的最大点。它不是一个谁有理由去交易的窗口，也不是一个WF04的输出。算术要点是那个差距：一份引用$0.58$、对其余八个分数只字不提的报告，引用的就是一个被选定的统计量。一份引用均值$0.3589$的报告，描述的是菜单。两个数都不是预测。[[#prop-max]]正是为什么：当分数可以不同时，就该预期被引用的最大值坐在一个事先点过名的格子的分数之上。
:::
:::

:::quiz
九个配置被计分，而发表的是最大的那个夏普比率。被发表的是哪个对象？
- [ ] 一个在分数被看到之前就固定的配置的夏普比率。
- [x] 一个被选定的统计量，九个分数的最大值。
- [ ] 九个分数的均值。

:::solution
发表九个分数里最大的那个，发表的就是最大值。均值是另一个函数。网格搜索不是走步验证。走步验证是在较晚的日期上给一个被冻结的选择计分。网格是在挑选那个选择本身。
:::

## 三十次试验，然后一次冻结的走步验证

一场基于模型的序贯搜索，把一份试验预算花在同一条历史上，并让后来的试验依赖较早的分数。WF05目录那一行点名的采样器，Tree-structured Parzen Estimator，就是这一类的。在本图谱需要的层面上，这个采样器保留至今计分过的试验，对产生了较好分数的那片参数区域形成一个画像，对其余的区域再形成一个画像，然后在那个较好分数的画像看来更可信的地方提出下一个试验。第$15$次试验的提议，被允许依赖第$1$到第$14$次试验的分数。这就是一个序贯采样器的要点。它也是这三十个分数不是三十次独立抽取、更不是对一个在试验$1$之前就固定的规则的三十次确认的原因。

Bergstra与Bengio在2012年发表于*Journal of Machine Learning Research*的论文表明，随机搜索是超参数优化一个强而简单的基线。随机搜索抽候选时不看先前的分数。一张网格看的确是一份事先指定的清单，但它照样保留最好的格子。在一两个维度上，一张小网格可以均匀地盖住坐标轴；选择的问题还在，因为被报告的那个数仍然是一个最大值。随机搜索不是一种验证方法，也不是一条交易结果。它是关于一场搜索如何探索参数空间的一个基线。2012年那篇论文的警告，用在这里是：换一个搜索器，并不会把$N$变回$1$。

Akiba、Sano、Yanase、Ohta与Koyama在2019年的KDD大会上发布了Optuna。那篇论文是关于这个优化器的。它不是关于任何市场的证据，而WF05的库内条目不会因为用了那个采样器就变成一条市场结果。采样器解释了为什么三十次试验是序贯的。试验预算解释了为什么搜索阶段的$N = 30$。

WF05随后跑的那个走步验证，是另一个阶段。公道地读，赢家先被冻结，然后才被走步验证。一次滑动走步验证的折几何在[[validation/walk-forward]]。在本图谱引用的那张表里，WF05那一行没有为那第二个阶段单独给出折数。切片的数目是几，那些切片就只是一条路径上的诊断——除非一条货真价实的新历史被造了出来——而那三十次试验仍然是选出了那个被冻结的参数的那场搜索。把$30$乘上一个折数、或者因为另一个页面用了$48$折就乘上$48$，没有数出这份协议交付过的任何东西。这个乘积不是样本量。

:::example 一份预算、一次冻结、一个假的乘积 {#ex-freeze}
一场搜索给$N = 30$次试验计分，并冻结一个赢家。一个后来的玩具走步验证——不是那个未发表的WF05设计——然后在一条路径上切出三个测试窗，按[[validation/walk-forward]]那个$30$日期例子的方式。这个走步验证在多少个配置之间重新选择？如果一个读者把$30$乘上$3$、然后报告$90$次确认，被数出来的是什么？
:::solution
这个走步验证在一个配置之间重新选择，那个被冻结的赢家——前提是协议禁止回头。那三个窗口是一条路径上的三个切片，带着为折已经讨论过的那种相依。它们不是三次确认——在三个历史的意义上——也不是三十次确认。

乘积$30 \times 3 = 90$数的是一个虚构。它把每一次被丢弃的试验都当作曾被走步验证过，又把每一个切片都当作是对每一个被丢弃配置的一次独立试验。这两件事哪件都没有发生。搜索给三十个配置计了分。后来的协议给其中一个计了分，在一条路径的切片上。如果研究者看了那三个切片、然后把选择解冻，连那个"一个配置"的读法也没了：走步验证已经变成又一步搜索，而试验计数必须把那一步被允许在其间挑选的那些配置也算进去。
:::
:::

## 家族错误率的计数是另一个故事

感觉到$N$之效用的第二种、更老的办法。设跑$N$个检验，每个的水平都是$\alpha$，每个检验的零假设都为真，而且这些检验相互独立。给定一个检验不拒绝的概率是$1-\alpha$。它们一个都不拒绝的概率是$(1-\alpha)^N$。至少一个拒绝的概率是

$$
1 - (1-\alpha)^N.
$$

拒绝次数的期望是$N\alpha$，由线性性，而线性性不需要独立。概率公式需要。对$\alpha = 0.05$，错误拒绝的期望在$N = 9$时是$0.45$，在$N = 30$时是$1.5$。在独立之下，至少一次错误拒绝的概率，当$N = 9$时是$1 - 0.95^{9} = 0.3698$（四位小数），当$N = 30$时是$1 - 0.95^{30} = 0.7854$（四位小数）。一场在这个水平上、由三十次独立的真零假设检验组成的搜索，多半会造出某个东西，让一道门槛规则为之加冕。

:::example 两个家族错误率的概率 {#ex-fwe}
假设独立、每次试验的零假设都为真、拒绝水平$\alpha = 0.05$。对$N = 9$与$N = 30$算$1 - 0.95^{N}$，保留四位小数，并算每种情形下拒绝次数的期望。
:::solution
$N = 9$时，$0.95^{9} = 0.630249$保留六位小数，所以$1 - 0.95^{9} = 0.369751$，四位小数为$0.3698$。拒绝次数的期望是$9 \times 0.05 = 0.45$。

$N = 30$时，$0.95^{30} = 0.214639$保留六位小数，所以$1 - 0.95^{30} = 0.785361$，四位小数为$0.7854$。拒绝次数的期望是$30 \times 0.05 = 1.5$。

这些算术不是WF04或WF05的夏普比率，也不是收缩（deflated）夏普比率。它们描述的，是在库内那些搜索并不满足的假设之下的一个拒绝计数。九个格子共享一条历史，所以它们的分数是相依的。那三十次TPE试验是序贯的，所以第一次之后的每次试验都是较早分数的函数。相依意味着$1 - (1-\alpha)^N$对那两个页面不是一个经过校准的概率。它仍然是一件有用的算术：就连独立的情形——那是对"许多次分开的看"这种主张最客气的情形——已经会让一次错误的加冕成为常事。下一章会把那个拒绝的说法换成一把尺度，用于标准化的统计量的最大值，并在那套设定里重讲一遍关于独立的警告。
:::
:::

:::widget hypothesis
test: z
tail: right
alpha: 0.05
effect: 0.3
n: 60
caption: 一次事先指定的均值检验。一张九个夏普比率的网格是九次看，一份三十次试验的TPE预算是三十次看。把样本量加大，只会让这一张单独的图变尖。它花不掉那个多重性，也冻结不了一个赢家。
:::

:::warning 不要升格获胜的那个格子
一张样本内网格里的最大值，是一个在一场比较中获胜的格子的分数。它不是"那条"策略的业绩，因为那条策略正是为了这个数的大小才被选中的。它不是一个走步验证结果，除非一次后来的、被冻结的检验真被跑过、而且被引用的就是它。它不是去交易那些获胜窗口的理由。WF04的九个格子与WF05的三十次试验，存在的意义就是被数。数它们，就是那个校正。只引用赢家，就是把计数扔掉了。
:::

:::intuition 菜单与那道菜
一家餐馆让你尝九道菜、然后报告你最喜欢的那道菜的分数，它没有告诉过你一道被随机派给的菜会得几分。喜欢是真的。品尝是真的。选择就是全部的故事。在品尝之前把那道菜写下来，或者拿起那道最喜欢的、在一场并没有用它来挑选的后来宴席上评判它，是另一个协议。WF04是品尝。对一个被冻结的WF05赢家的走步验证，是对那场后来宴席的一次尝试。那场后来的宴席用的仍然是同一家厨房的历史。
:::

- [ ] 一次试验，因为只有赢家被报告。
:::solution
那三十次试验是搜索的预算。它们选出了赢家，而一个序贯采样器让后来的试验依赖较早的分数。走步验证检验那个被冻结的赢家一次，在一个配置的意义上。只报告赢家，并没有把搜索缩成一次试验。那些被计过分数的配置仍然计入$N$。
:::
:::

:::remark 并列与重复的试验
若两个格子交出同样的分数，在说出一个平局裁定之前，[[#alg-enum]]不知道哪个窗口是赢家。若一个采样器把完全相同的配置计了两次分，第二次跑不是一次新的看，而一个把它当作新的来算的试验数会夸大$N$。反方向的错误同样存在：一张$125$个可以想象的格子的网格，其中只有$30$个被计过分，对那个实际算出的最大值来说$N = 30$。没跑过的格子不在那个最大值里。它们也不给任何人假装那个最大值是在整张网格上取的资格。$N$是被计分的配置的数目，既不是一个幻想网格的大小，也不是$1$。
:::

:::history
Bergstra与Bengio（2012年），在*Journal of Machine Learning Research*上，把随机搜索变成了一张网格在问题是对参数空间的探索时必须拿来对照的那个基线。这个对照并不为任何一种搜索洗脱多重性。Akiba、Sano、Yanase、Ohta与Koyama（2019年）描述了Optuna，它的Tree-structured Parzen Estimator就是WF05目录那一行点名的那个序贯采样器。那篇论文是关于优化器的。Bailey与马克斯·洛佩斯·德·普拉多（Marcos López de Prado）（2014年）的收缩（deflated）夏普比率——也就是下一章——谈的是一场搜索被允许挑出赢家之后，一个业绩数字身上会发生什么。年份要紧，因为这些工具常常被堆在同一段话里，仿佛它们是一个结果。它们是三项不同的工作。
:::

## 通向何处

尺度$\sqrt{2\ln N}$——在一个金融试验通常违反其假设的正态近似之下——在[[validation/the-deflated-sharpe]]里算；那一章也指向2014年的那篇论文去看完整的收缩（deflated）夏普比率，而不是拿那个尺度去取代它。后来那次走步验证的折，仍然是[[validation/walk-forward]]里的那些对象，而且它们仍然因为[[validation/what-a-fold-does-not-prove]]里的原因成不了独立的重复。不挂着移动平均网格的、抽象的多重检验，在[[statistics/testing-and-snooping]]。

:::summary
- WF04是一张九个回测的网格，快窗$\{20, 50, 80\}$、慢窗$\{100, 150, 200\}$，按一个夏普比率计分。九个之中的最大值是一个被选定的统计量。
- 一条像快窗 $<$ 慢窗这样的约束会剔掉格子。$N$是实际被计分的数目。
- 对可积的分数，期望最大值至少是任何一个事先指定的试验的期望分数；而当一次更好的试验可能发生时，不等式是严格的。
- WF05的$30$次Optuna TPE试验是一场序贯搜索。它们不是$30$次确认。对一个被冻结的赢家的后来一次走步验证，检验的是一个选择。
- 在独立与一条真零假设之下，$1-0.95^{9} = 0.3698$、$1-0.95^{30} = 0.7854$，四位小数，水平$0.05$。真实的格子与TPE试验并不独立，所以这些是例证，不是库内页面的P 值。
- 网格的没有一个格子是一条去交易的建议。
:::

## 习题

:::exercise 数一数WF04 {level=1 check="9"}
网格$\{20, 50, 80\} \times \{100, 150, 200\}$里有多少种组合？（输入那个计数。）
:::solution
快值有三个，慢值有三个，而$3 \times 3 = 9$。每一个对子都有快窗 $<$ 慢窗，所以一条那样形式的约束一个都不剔。WF04按目录记载的试验数，就是这个$9$。
:::
:::

:::exercise 一条咬得动的约束 {level=1 check="6"}
快值$\{10, 20, 30\}$与慢值$\{15, 25, 40\}$相互组合，且只有当快值严格更小时才保留一个对子。保留了几个对子？（输入那个计数。）
:::solution
六个对子是$(10,15)$、$(10,25)$、$(10,40)$、$(20,25)$、$(20,40)$与$(30,40)$。三个对子被丢弃。$N = 6$，不是$9$。
:::
:::

:::exercise 期望的错误拒绝数 {level=1 check="0.45"}
九个独立的检验各在水平$0.05$上做，而每条零假设都为真。拒绝次数的期望是多少？（输入那个期望。）
:::solution
由线性性，期望数是$N\alpha = 9 \times 0.05 = 0.45$。这个期望不需要独立。独立是需要的地方，在[[#ex-fwe]]里算的那个概率$1 - 0.95^{9}$上。这两个计算都不是夏普比率，也都不是把WF04那些相依的格子当作九个独立检验的许可证。
:::
:::

:::exercise 更干净的一个差距 {level=2 check="9/50"}
九个编造的样本内夏普比率，无风险收益率$0$、未年化，是$0.10$、$0.20$、$0.15$、$0.40$、$0.25$、$0.05$、$0.30$、$0.35$与$0.18$。它们不是库内数字。计算最大值与均值之间的差距。（输入精确的差距。）
:::solution
以百分之一为单位的和是$10+20+15+40+25+5+30+35+18 = 198$。均值是$198/900 = 11/50 = 0.22$。最大值是$0.40 = 2/5 = 4/10$。差距是$0.40 - 0.22 = 0.18 = 9/50$。引用$0.40$而不带均值，引用的就是这张清单被选定的那一头。这张清单仍然是一件为算术而编造的东西，不是一个回测结果，也不是一条建议。
:::
:::

:::exercise 走步验证被允许选什么 {level=2 check="1"}
三十次试验已被计分，而赢家在一个走步验证开始之前就被冻结。这个走步验证不被允许换到另一次试验。这个走步验证在多少个配置之间做选择？（输入那个数目。）
:::solution
它在一个配置之间做选择，那个被冻结的赢家。那三十次试验是产生了这次冻结的那场搜索。它们不是藏在走步验证里面的三十次确认。如果协议后来被放宽、让一次令人失望的走步验证可以重开那张菜单，答案就不再是$1$。
:::
:::

:::exercise 从未被计分的格子 {level=2 check="95"}
一个参数空间包含$125$个可以想象的格子。一场搜索给$30$个不同的格子计了分，其余的没有跑。有多少个格子没有被计分？（输入那个计数。）
:::solution
$125 - 30 = 95$个格子没有被计分。那三十个之中的最大值不是全部$125$个之上的最大值，因为其余的格子没有分数。没跑过的格子也不把$N$降到$1$。就那个被算出来的最大值而言，$N = 30$。
:::
:::

:::exercise 数一张带约束的矩形 {level=3 check="270"}
快窗是整数$5, 6, \ldots, 20$，慢窗是整数$10, 11, \ldots, 30$。只有当快窗严格短于慢窗时，一个对子才被计分。有多少个对子被计分？（输入那个计数。）
:::hint
把快值分成严格小于$10$的那些——每一个慢窗都合格——与$10$到$20$的那些——慢窗必须从紧挨快值之上那个整数一直取到$30$。
:::
:::solution
快值有$16$个，慢值有$21$个，所以约束之前矩形有$16 \times 21 = 336$个对子。

快值$5$到$9$是五个整数，每一个都严格小于每个慢值，而慢值从$10$起步。它们贡献$5 \times 21 = 105$个对子。

对从$10$到$20$的一个快值$f$，合法的慢值是$f+1, \ldots, 30$，共$30-f$个。各值是$20, 19, \ldots, 10$。它们的和是$(1+\cdots+20) - (1+\cdots+9) = 20 \times 21/2 - 9 \times 10/2 = 210 - 45 = 165$。

总数是$105 + 165 = 270$。所以若每个幸存的对子都被计分，$N = 270$，不是$336$。一份只给这$270$个中的$30$个计分的预算，试验数是$30$。合法集合的大小，不是实际跑过的那场搜索的大小。
:::
:::

:::exercise 一个重复的格子不是一次新的看 {level=3 check="8"}
九个记录在案的分数各自附在一个格子上了，但九条记录里有两条是同一个配置跑了两次。其余的记录是唯一的。有多少个不同的配置被计过分？（输入那个计数。）
:::hint
同一个配置的第二次跑，数据相同、规格说明相同，并不添一次试验。在你被告知那份重复是精确的之后，数不同的对子，不要数日志里的行数。
:::
:::solution
有八个不同的配置被计过分。在一个后来的选择尺度里用$N = 9$，会夸大看的次数。因为宣布了赢家就用$N = 1$，又会低估它。对一个精确的重复，正确的计数是不同配置的数目，这里是$8$。

倘若那两条记录相差一个窗长，或相差一个成本，它们就是不同的试验。"看起来相同"不是"是同一个配置"。题目说道那份重复是精确的。一个序贯采样器也可以重访一个点。决定$30$次试验是不是$30$个不同配置的，是日志，不是在一张图注里印出来的预算。目录为WF05写明了一份$30$次试验的预算。它没有把日志交到我们手上。我们数$30$次试验，按写明的预算数，而我们不把$30$次试验叫作$30$次确认。
:::
:::
