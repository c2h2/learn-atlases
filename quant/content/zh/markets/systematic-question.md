写不下来的规则不可能出错，而不可能出错的规则也谈不上研究。系统性交易研究要求的，比一个关于市场的故事更狭窄。在给定的时点$t$，规则只能读取当时已经存在的信息，并且只能用那之后发生的结果来计分。本图谱后面的一切——移动平均、波动率目标、止损单、走步验证中的一折——都是关于这条规则、以及用来批评它的实验的选择。

规则背后的经济期望并不是规则本身。"买入强势"说出的是一种期望。它没有说明哪些价格算强势、决策在何时做出、持有什么、允许把哪个收益率当作结果。两个人可以怀有同一个期望，却运行两个不同的实验。看起来相似的公布数字，可能来自根本不共用同一个时钟的实验。本章固定这些对象，好让后面的各章能够精确地分歧。

本图谱通篇使用的开放库，是按2026年所见的quants.md公开目录，取材自Apache-2.0协议的QuantJourney示例。这个库把自己的案例分成三个家族。本图谱没有重跑过那些回测。它们是协议的演示，不是预测，也不是持有任何东西的建议。该项目自己就把这套软件描述为：不是经纪商，不是实盘交易系统，也不是投资建议。这条边界就是本课程的边界。

## 决策允许知道什么

价格将记作$P_t$，其中$t$为决策时点。在本章中，$t$是一根K线的收盘时刻，而$P_t$就是这个收盘价。以$t$收尾的简单收益率为

$$
R_t = \frac{P_t}{P_{t-1}} - 1,
$$

在$P_{t-1} \neq 0$时有定义。从$t$开始、到下一个收盘为止的收益率是$R_{t+1}$。这两个数用的是不同的价格。把它们混为一谈的这个错误，本章存在的意义就是先让它在纸面上变得昂贵，免得它在一项研究中变得昂贵。

:::definition 信息集与信号 {#def-information}
**信息集**$\mathcal{F}_t$是规则在时点$t$允许读取的数值全体。一个数属于$\mathcal{F}_t$，只有当在你所声明的数据约定下，它在时点$t$之前已经确定。**信号**$s_t$是仅由$\mathcal{F}_t$计算出的值。我们把$s_t \in \mathcal{F}_t$写作这条限制的简记。特别地，在收盘约定下，$P_t$可以进入$s_t$，而$P_{t+1}$不可以。
:::

这是一条研究约定，不是测度论课程。使用它不需要sigma-代数，只需要一张清单。如果清单上写着"到$t$为止的日收盘价"，那么K线内部的一个盘中最高价就不在清单上，即使某个数据商本来能把它打印出来。如果清单上写着"收盘价在$t$已知"，那么$P_t$就是允许的。清单是规则的一部分。改动清单，就改变了实验。

信号可以是一个比特、一个秩、一个实数，或者每个证券对应一个分量的向量。这些对象都还不是头寸。"信号为正"这句话，没有说明投入了多少资金、敞口是多是空、是否向市场发出了什么指令。那些是进一步的映射，而每个映射都必须写下来。

:::definition 权重 {#def-weight}
**权重**$w_t$是在某个决策时点标定的、占净资产值的一个目标比例。它属于$\mathcal{F}_t$：目标可以依赖信号和其他已经已知的数字，而不能依赖之后的价格。只有在写明映射之后，信号才成为权重。在那个映射写下来之前，$s_t$不是持仓。
:::

同一个信号可以有不止一种映射方式。一种映射把正比特映到$w_t = 1$，把非正比特映到$w_t = 0$，现金则按你同样声明的利率计息（短例中常取$0$）。另一种映射把$s_t \in \{-1,+1\}$映为满仓多头或满仓空头，即$w_t = s_t$。这是两个不同的实验。两者都是权重。两者都不是订单，因为净资产值的一个比例并没有说明这笔交易是市价单还是限价单，也没有说明期望的交易未能发生时怎么办。

:::definition 订单 {#def-order}
**订单**是一份带有方向、数量和类型的指令：它请求市场——或市场的某个模型——去成交、撤销或错过。订单可以是$\mathcal{F}_t$的函数，但它不是权重。权重指明一个目标比例；订单指明一条消息。消息本身并不是成交。
:::

把这三个词分清，就是全部的纪律。信号是你能够从过去算出的东西。权重是你同意据此计分的一个目标比例。订单是一条消息，其结果取决于你尚未看到的路径。走步验证——库中的第三个家族——不是这一类之外的第四种对象。它是在同一条历史的后续切片上重复实验的一种方式。目录把这些页面描述为切片诊断，而非独立的样本外证据。我们将按原文使用这一描述，也不会把一折升格为预测。

:::quiz
到日期$t$为止的收盘价的二十日均值是下列哪一种对象？
- [ ] 权重，因为均值是一个比例
- [ ] 订单，因为它告诉经纪人该做什么
- [x] 信号，只要它只由$\mathcal{F}_t$计算得到，而尚未成为权重或订单
- [ ] 成交，因为这个均值的输入是成交价格
:::solution
这个均值是由规则允许读取的收盘价算出的数字。一旦窗口被写明，它就是一个信号。只有当从均值到净资产值某个比例的映射被写明，它才成为权重；只有当一条消息被写明，它才成为订单。均值使用了成交价格，并不会让这个均值成为成交。
:::
:::

## 合法的乘积

被计分的结果自有时钟。在收盘到收盘约定下，于$P_t$已知时做出的决策，不可能挣得从$P_{t-1}$到$P_t$的这段涨幅。这段涨幅已经属于过去。下一段涨幅，从$P_t$到$P_{t+1}$，才是这个决策尚未观察到的第一个收益率。

:::proposition 合法的收盘到收盘乘积 {#prop-legal}
假设四件事。决策时点是第$t$根K线的收盘时刻。简单收益率$R_t = P_t/P_{t-1} - 1$是$(P_{t-1}, P_t)$的函数，所以它在$t$已经确定，而在$t-1$一般尚未确定。信号$s_t$属于$\mathcal{F}_t$，因而可以依赖$P_t$。在第$t$根K线收盘时选定的头寸，并不挣得$t-1$与$t$之间已经发生的价格变动。

于是乘积$s_t R_t$给这样一个收益率计分，其右端价格$P_t$正是信号被允许看到的价格。只在决策之后才开始的那个收益率是$R_{t+1}$。合法的收盘到收盘乘积是$s_t R_{t+1}$。
:::

:::proof
由第二条假设，$R_t$依赖$P_t$。要挣得$R_t$的决策必须只用$P_t$到来之前的信息做出，而在这个时钟下，那意味着$\mathcal{F}_{t-1}$。乘积$s_t R_t$中的信号标注在时刻$t$，于是第三条假设允许它依赖$P_t$。同一个价格就既在信号之内，又在被计分收益率的终点。第四条假设说，$t$时的决策并未挣得那个终点价：信号形成时，终点价已经确定。

把被计分的收益率换成$R_{t+1} = P_{t+1}/P_t - 1$。信号仍然可以使用$P_t$，这是允许的。新的终点是$P_{t+1}$，它不属于$\mathcal{F}_t$。因此乘积$s_t R_{t+1}$才是与四条假设一致的收盘到收盘计分。任何其他配对，要么在信号内部用了未来的价格，要么用一个信号已经见过的收益率来付给它。
:::

上面这条结论并不是说按收盘价成交是现实的。它说的是：既然选了这个约定，代数就必须与它匹配。在下一根开盘价成交的约定挣的是另一个增量——从那个开盘价到某个更晚的价格——合法乘积随约定而变。不变的是时间的次序。成交价不是发出成交请求的那个信号的输入。

:::warning 用做决定那根K线来计分
常见的失误是由$P_t$、或由$R_t$构造$s_t$，然后再乘上$R_t$。在一个没有零收益率的符号规则上，这个乘积等于$\abs{R_t}$，于是每根K线都像在赚。这份盈利是一个规则已经观察到的收益率的绝对值。它不是一个决策的结果。[[#prop-legal]]就是补救办法：保留信号，乘以下一个收益率。
:::

:::intuition 一只上了锁的文件柜
把$\mathcal{F}_t$当作一只在时点$t$上锁的文件柜。你可以用柜内已有的纸张来构造$s_t$和$w_t$。收益率$R_{t+1}$是上锁之后才送达的一张纸。合法的计分，把柜内的纸与随后送达的那张纸配成一对。非法的计分，是把柜内已有的一张纸复印一份，然后称这张复印件为利润。
:::

:::algorithm 为收盘到收盘规则计分 {#alg-score}
从写明的收盘价序列、写明的$s_t$公式、以及写明的从$s_t$到权重$w_t$的映射开始。若权重未满仓，现金按写明的利率计息；除非另有说明，该利率取$0$。

1. 由相邻收盘价计算每个简单收益率$R_{t+1}$。不要用最高价、最低价或后来的修正值。
2. 只由$\mathcal{F}_t$计算$s_t$。如果公式提到$P_{t+1}$，停下：这个时钟不合法。
3. 施加映射得到$w_t$。如果你没有映射，停下：你手里的是信号，不是结果。
4. 形成单期结果$w_t R_{t+1}$（若现金利率不为零，再加上未投资部分的现金利息）。
5. 对拥有下一个收益率的那些日期，把毛收益因子$\prod (1 + w_t R_{t+1})$复利累乘。样本最后一个日期上的信号，在样本内已经无可挣之收益。让它不计分。
:::

这套步骤就是把上面那条结论变成一张清单。第5步在短序列上很容易漏掉。最后一个信号并不是一笔漏掉的利润：它没有下一个收盘价。

## 四个句子

平实的语言会掩盖一个人究竟界定了哪种对象。下面的例子要归类四个句子——读者很可能以为它们说的是同一个策略。

:::example 四个句子，四种对象 {#ex-four}
把每个句子归类为信号、权重、订单或不合法的时钟。不要往句子里添加它没有包含的映射。

1. "二十日均值高于五十日均值。"
2. "当上述比较为真时，净资产值的目标比例为$1$，否则为$0$。该权重挣得下一个收盘到收盘收益率。现金收益率为$0$。"
3. "当二十日均值上穿五十日均值时，提交一份买入$100$股的市价单。"
4. "今天收盘价涨了，所以把今天的涨幅记作今天做出的多头头寸的利润。"
:::solution
第一句说的是两个均值的比较。一旦窗口和日期被固定，这个比较就是$\mathcal{F}_t$中的一个比特。它是信号。它不是权重：没有任何话说明这个比特对应净资产值的哪个比例。它不是订单：没有提交任何东西。

第二句取一个这样的信号，写明了映射、时钟和现金利率。目标比例$1$和$0$是按[[#def-weight]]的权重。"挣得下一个收盘到收盘收益率"一语，是由[[#prop-legal]]给出的合法乘积，其中$w_t$代替了裸信号。它仍然不是订单。权重为$1$并没有说是市价还是限价，也没有说交易失败时持有什么。

第三句要的是一条消息：买入、市价、$100$股，由交叉触发。按[[#def-order]]，这是一笔订单。交叉是触发这条消息的信号。数量的单位是股，不是净资产值的比例，所以这句话还不是一个权重规则。这张市价单是否成交、以什么价格成交，句子没有说。之后的订单课程处理成交。这里只需要明白，消息和成交是两回事。

第四句用今天的收盘价做决定，再用今天的收益率计分。两边都用了$P_t$。这就是被[[#prop-legal]]禁止的非法乘积$s_t R_t$。合法的改写要计分下一个收益率，而这句话没有做。把它归类为"一个多头策略"，就是替这个时钟洗白。
:::
:::

这四个句子可以都出现"移动平均"这几个字，却仍是四个实验。日后，当两个库内页面都提到移动平均、却印出两个不同的复合增长率时，第一个要问的是每个页面改动的是这几种对象中的哪一种，而不是哪个页面"赢了"。

## 一条有两个时钟的路径

贯穿本图谱的算例是路径A，八个虚构的收盘价

$$
P = (100,\ 102,\ 101,\ 104,\ 103,\ 107,\ 106,\ 110),
$$

对应日期$t = 0, 1, \ldots, 7$。这里没有任何东西是市场。简单收益率按路径陈述的口径舍入到六位小数，为

$$
0.020000,\ -0.009804,\ 0.029703,\ -0.009615,\ 0.038835,\ -0.009346,\ 0.037736.
$$

七个收益率，八个价格。从$100$到$110$的复合简单收益率为$0.10$。我们将用这些整数价格作输入，并把复合结果报告到六位小数。把上面这些六位小数收益率复利累乘，在本章各数字上得到的六位小数完全相同；这些算术在写下之前已用Python核验。

:::example 同样的正负号，两种计分 {#ex-clock}
对$t = 1, \ldots, 7$定义：$R_t > 0$时$s_t = +1$，$R_t < 0$时$s_t = -1$。这条路径上没有零收益率，所以信号总是有定义。取映射$w_t = s_t$，即满仓多头或满仓空头，无融券费用，无融资成本。设这个空头一侧只是为了把映射写清楚的算术装置，不是建议谁去卖空任何东西。

计算非法乘积$s_t R_t$与合法乘积$s_t R_{t+1}$。把两个序列各自复利累乘。最后一个信号没有$R_8$；在合法累乘中略去它。
:::solution
七个收益率的正负号交替出现：正、负、正、负、正、负、正。因此$s_t = \operatorname{sign}(R_t)$，并且只在这条路径上，只要两者存在就有$\operatorname{sign}(R_{t+1}) = -s_t$。这种交替是关于这八个数字的事实，不是关于市场的结论。

非法乘积在每个日期都是$s_t R_t = \abs{R_t}$。这七个绝对收益率复利累乘得到的简单收益率为$0.165141$。每一步都是盈利，因为规则是被用它的信号据以构造的那个收益率的绝对值付了酬。[[#prop-legal]]说明，在收盘到收盘的时钟下，这个数不是回测。

对$t = 1, \ldots, 6$，合法乘积是下面各收益率的相反数：

$$
-0.009804,\ -0.029703,\ -0.009615,\ -0.038835,\ -0.009346,\ -0.037736.
$$

由于上面指出的交替，每一项都是负的。它们的复合简单收益率为$-0.128145$。期末毛收益因子为$0.871855$。$t = 7$处的信号是$+1$，不计分：样本没有第八个收益率。

作为对照，从第一个收盘价到最后一个收盘价、每个日期权重恒为$+1$的头寸，挣得路径A的总收益$0.10$。在这件玩具上，合法的带符号规则挣得比这个恒定期头更少；非法的带符号规则挣得比恒定期头更多。只有合法的数字是按[[#alg-score]]的计分，而这个数字也不过是八个虚构的价格，不是证据。
:::
:::

请按这个顺序来读这个比较。当较大的那个数字是靠读出收益率的终点产生的时候，数字大并不说明规则好。就在这条路径上，合法规则在每一个计分期都亏钱。这份亏损只是这件玩具被自己的正负号逼出来的表现。它不是改用相反信号的理由，也不是抛弃这个时钟的理由。一个只保留在你眼前样本上赚过钱的规则的时钟，是同一类作弊的第二种形式。

:::example 同一信号、换一种映射 {#ex-weight}
保留[[#ex-clock]]中的$s_t$。换掉映射。$s_t = +1$时$w_t = 1$，$s_t = -1$时$w_t = 0$。现金收益率为$0$。对$t = 1, \ldots, 6$计分$w_t R_{t+1}$并复利累乘。
:::solution
在$t = 1, \ldots, 6$上的权重是$1, 0, 1, 0, 1, 0$。下行日期上的带符号信号已被换成空仓。六个单期结果是

$$
-0.009804,\ 0,\ -0.009615,\ 0,\ -0.009346,\ 0.
$$

零是持币的期间，不是缺失数据。复合简单收益率为$-0.028490$，期末毛收益因子为$0.971510$。

这个例子与[[#ex-clock]]相比，信号没有变，变的是映射。合法的带符号组合亏了$0.128145$；合法的"多头或持币"组合亏了$0.028490$；未被计分的非法组合"赚了"$0.165141$；恒为多头的组合赚了$0.10$。四个数字，一条路径，一个信号公式。把其中任何一个引为"符号规则的表现"，就是删掉了映射和时钟。两者都是结果的一部分。

权重$w_t = 0$是一个决策。它挣的是现金利率——这里是零——而不是空白单元格那种意义上的"没有收益"。如果现金有不为零的利率，每个空仓期间都会贡献那个利率，复合结果就会移动。把利率声明为零是一种建模选择，而且具有约束力。
:::
:::

:::quiz
在路径A上，信号$s_3$由收盘价$104$和前一个收盘价$101$构造。按[[#prop-legal]]，它允许挣得哪一个收益率？
- [ ] 从$101$到$104$的收益率，因为正是这个收益率设定了信号
- [x] 从$104$到$103$的收益率，因为这个收益率始于决策收盘价
- [ ] 从$103$到$107$的收益率，因为信号应该跳过一天
- [ ] 从$100$到$110$的复合收益率，因为整条路径才是结果
:::solution
标注在收盘价$104$的信号可以使用那个收盘价。下一个收盘价是$103$，该步上的$R$是$-0.009615$。从$101$到$104$的收益率正是信号的构造依据，所以拿它计分就是非法乘积。再往后从$103$到$107$的那一步，是下一次决策之后的$R$，不是挂在这次决策上的收益率。
:::
:::

## 复利累乘不是策略

毛收益因子可以在完全没有规则的情况下画出图形。那样的图只是算术的图画。只有当这些台阶是[[#alg-score]]的输出时，它才成为回测。

:::example 恒定的毛收益率 {#ex-compound}
每步恒定简单收益率$0.001$的毛收益因子是$1.001$。在$40$步上，复合简单收益率为$(1.001)^{40} - 1$。把它算出来。另外，求每步的恒定简单收益率，使它在七步上复合成路径A的期末倍数$1.10$。
:::solution
Python给出$(1.001)^{40} - 1 = 0.040790$（六位小数）。那只是把$1.001$连乘起来的描述。没有声明信息集，没有计算信号，也没有选择权重。把这条曲线称为策略，就是把这三样全都凭空造出来。

路径A在七个收益率之后停在$110/100 = 1.10$。满足$(1+g)^7 = 1.10$的恒定简单比率$g$为

$$
g = 1.10^{1/7} - 1 = 0.013709
$$

六位小数为上式。一条每步上涨$0.013709$的路径，会与路径A有相同的期末财富，却不会有路径A的中间收盘价。期末倍数只是一个摘要。它还原不了决策：恒定路径里根本没有决策，而真实规则里的决策，也无法仅凭期末倍数辨认。仪表盘一章在从页面上读出年化复合增长率时，还会回到这一点。
:::
:::

mode: terms
N: 40
caption: 恒定为1.001的毛收益率的前四十项。这条曲线是算术，不是策略。第n步上没有做出任何决定，也没有声明信息集。复利累乘是在描述一条路径，不是在为它辩护。

这个控件画出$1.001$、$1.001^2$，如此下去。目光沿着它滑动并不是研究结论。日后当有人根据一个公布的复合增长率画出$(1 + g)^x$时，同样的形状还会出现。那条曲线仍然只是对一个被报告的比率的光滑摘要。它不是净值路径，也不是采用那条被摘要的规则的理由。

:::example 给三个库内案例归类 {#ex-families}
只根据库内的一句话描述，把O01、W01和WF01归入三个家族。不要把归类当作排名。
:::solution
O01是"Market SMA Cross"：当二十日均值上穿五十日均值时买入，反向交叉时卖出，使用市价单。被改动的对象是订单。它属于订单家族。均线是触发消息的信号。不需要知道它报告的增长率就能看出这一点。

W01是"Daily SMA Trend"：只要五十日均值高于二百日均值，就持有每个行业交易所交易基金，每日调仓。被设定的对象是用权重表达的持有规则，不是市价单消息。它属于权重家族。两个页面都提到了价格的均值，但并没有提到相同的窗口、相同的调仓或相同的对象。"移动平均策略"不是一个定义良好的实验。

WF01是"Rolling Walk-Forward Validation"：$48$折，滑动的训练窗和测试窗，带有测试前剔除，跨距由目录给出为$26$年。2026年对照目录阅读，库自己的表述是：这些是切片诊断，不是独立的样本外证据。其家族是走步验证。折数不是独立试验的次数。本图谱没有重跑过这个页面。

三种归类中的任何一种都没有说，读者应该去交易那条均线、那只基金或那一折。归类回答的是"这个页面声称自己计算的是什么对象？"它不回答"应该持有什么？"
:::

:::history
1602年，荷兰东印度公司（Vereenigde Oostindische Compagnie）发行了可转让的股票，围绕这些股票的二级市场在阿姆斯特丹成长起来。这段往事通常被当作现代股份制股票的起点。可转让性才使后来的价格序列成为可能：一份不能易手的索取权，没有可供规则读取的二级市场价格。本章的系统性之问，只是在索取权存在之后，才向这些价格提出。这个日期并没有把任何一个现代市场变成邀请你去做其继承者的东西；它确定的是：这些价格是"什么"的价格。
:::

## 通往何处

下一章[[markets/instruments]]说明权重是"什么"的权重：一张现金股票、一份基金份额、一种货币的美元价格，还是带乘数的一份期货合约。这里用到的收益率$R_t$将在[[performance/simple-and-log-returns]]中展开，包括对数收益率，以及为什么不能把简单收益率相加、然后把和当作结果。[[#ex-families]]中点名的那些家族所公布的数字行，在序列本身被诚实地调整之后，将在[[markets/reading-a-dashboard]]里按仪表盘来阅读。

:::summary
- 系统性规则是信息集$\mathcal{F}_t$的函数。它不是故事，也不是期末财富。
- 信号$s_t$由$\mathcal{F}_t$算出。权重$w_t$是在写明映射之下的目标比例。订单是一条消息。三者是不同的对象。
- 在收盘到收盘的时钟下，合法乘积是$s_t R_{t+1}$；写明映射之后是$w_t R_{t+1}$。乘积$s_t R_t$偷看了它所计分的收益率的终点。
- 在路径A上，带符号映射$w_t = \operatorname{sign}(R_t)$按合法方式计分复合为$-0.128145$，按非法方式计分复合为$0.165141$。这个差距是时钟，不是市场事实。
- 改动映射而不改信号，把那个合法结果变成了$-0.028490$。引用数字时，请把映射一并引用。
- 形如$(1.001)^n$的恒定复合曲线只是算术。只有当台阶是写明规则的输出时，它才成为回测。
- 按2026年的阅读，开放库有$25$个权重示例、$20$个订单示例和$5$个走步验证示例。本图谱没有重跑过它们。它们不是建议；按库自己的说法，走步验证页面是切片诊断。
:::

## 练习

:::exercise 路径A的第一步 {level=1 check="0.02"}
路径A的收盘价以$100$、$102$开头。把这一步的简单收益率以小数输入。
:::solution
$R = 102/100 - 1 = 0.02$。同一个数字就是七个路径收益率中的第一个，六位小数为$0.020000$。它只用了这两个收盘价，别的一概不用。标注在收盘价$102$的信号可以把这个收益率用作输入，但不得把它记作自己的利润：那就是[[#prop-legal]]里的非法乘积。
:::
:::

:::exercise 信号能用的最新收盘价 {level=1 check="104"}
路径A上标注在$t = 3$的信号使用[[#def-information]]的收盘约定。输入它允许读取的最新价格。
:::solution
日期从$t = 0, \ldots, 7$，价格为$100, 102, 101, 104, 103, 107, 106, 110$。$t = 3$时的收盘价是$104$。此日期之后的价格——从$103$起——不属于$\mathcal{F}_3$。较早的收盘价$100$、$102$和$101$，在公式需要时是允许的。允许的最新价格是$104$。
:::
:::

:::exercise 一个合法乘积 {level=1 check="-0.009615"}
在路径A上取$s_3 = +1$，它来自$101$到$104$的上涨。用路径在$104$到$103$那一步上舍入后的收益率，把合法乘积$s_3 R_4$输入到六位小数。
:::solution
下一个收益率是路径的第四个简单收益率$-0.009615$，它在打印精度下等于$103/104 - 1$（精确值为$-1/104$）。信号是$+1$，所以乘积是$-0.009615$。同一天的非法乘积将是从$101$到$104$的正收益率，即$0.029703$。那个正数是信号的形成过程。它不是得分。
:::
:::

:::exercise 两个毛收益因子 {level=2 check="-0.039216"}
在[[#ex-clock]]中，按路径的六位小数收益率，头两个合法单期结果是$-0.009804$和$-0.029703$。把仅这两步的复合简单收益率输入到六位小数。也可以用精确的价格比率；在这个精度下两者一致。
:::solution
按六位小数，毛收益因子为$1 - 0.009804 = 0.990196$和$1 - 0.029703 = 0.970297$。由整数价格看，同样这两个因子（合法乘积的符号已经计入）是$101/102$和$104/101$，其乘积为$0.960784$。减去$1$得$-0.039216$（六位小数）。六步的完整合法累乘$-0.128145$是一个更长的乘积。只走到两步是另一个窗口，必须照此标注。这两步里并没有藏着一个正的读数：两个因子都小于$1$。
:::
:::

:::exercise 下一个收益率的一半 {level=2 check="0.01"}
信号$s_t = +1$被映射为权重$w_t = 1/2$，下一个简单收益率为$0.02$。未投资的一半持币，收益率为$0$。输入单期组合的简单收益率。
:::solution
投资的一半贡献$(1/2) \times 0.02 = 0.01$。持币的一半贡献$0$。组合简单收益率为$0.01$。信号是$+1$，权重是$1/2$；若报告$0.02$，就是悄悄把映射换成了满仓。[[#def-weight]]正是阻止这种替换的东西。如果这一步的现金利率是$0.001$，持币的一半将添加$0.0005$，组合收益率就是$0.0105$。利率必须写进那句话里。
:::
:::

:::exercise 有多少个合法亏损 {level=2 check="6"}
在路径A上，$w_t = \operatorname{sign}(R_t)$按下一个收益率计分，六个合法乘积中有几个严格为负？输入这个数目。
:::solution
$R_1, \ldots, R_7$的符号是$+,-,+,-,+,-,+$。相邻符号每一对都不一致，所以六个乘积$s_t R_{t+1}$中的每一个都等于$-\abs{R_{t+1}}$，严格为负。这个数是$6$。这是这七个收益率中交替现象的一个性质。一条符号不交替的路径会给出不同的数目。这个数目里没有预测；那些全为正的非法乘积，也不是同一个数目的修正版。
:::
:::

:::exercise 非法组合为何不可能亏任何一步 {level=3}
假设$R_t \neq 0$且$s_t = \operatorname{sign}(R_t)$。证明$s_t R_t = \abs{R_t} > 0$，从而同一根K线上的符号规则没有亏的一步。然后解释：按[[#prop-legal]]，那些绝对收益率的复合为什么仍然不是回测。
:::hint
由符号的定义写出$\operatorname{sign}(R_t)\, R_t$，然后看两个因子共用哪个价格。
:::
:::solution
若$R_t > 0$，则$\operatorname{sign}(R_t) = +1$，乘积为$R_t = \abs{R_t}$。若$R_t < 0$，则$\operatorname{sign}(R_t) = -1$，乘积为$-R_t = \abs{R_t}$。假设$R_t \neq 0$使绝对值严格为正。每一根同K线的台阶都是盈利，盈利的复合仍是盈利。在路径A上，那个复合是$0.165141$。

这里没有争议的是代数，有争议的是时钟。信号使用$R_t$，因此使用了$P_t$，而被计分的收益率同样终止于$P_t$。[[#prop-legal]]说，收盘到收盘的决策在$t$并未挣得$R_t$。绝对收益率的复合，是规则已经观察过的那些收益率的复合。若信号伸进它所计分的收益率，[[#alg-score]]就会在第2步拒绝它；即使信号公式在其他方面很简单，它同样拒绝这种配对。靠这种方式得到的"样本上从不亏一步"的规则，是对绝对值的描述，不是对一个决策的检验。
:::
:::

:::exercise 对库内数字取平均意味着什么 {level=3}
按2026年的阅读，库中有$25$个权重模式示例、$20$个订单模式示例和$5$个走步验证示例。假设有读者把$25$个权重模式的复合增长率取平均，并把这个平均称为"权重模式的业绩"。请解释：即使每个比率都已知、即使本图谱把每一页都重跑过，这句话为什么仍然与系统性之问毫不相干。不要真的去算一个平均。
:::hint
平均数是数字的函数。要问的是：这些数字没有固定住什么——信息集、映射、期限，以及库自己对"一页是什么"的表述。
:::
:::solution
这$25$个页面就是$25$个实验。它们不共用样本池、窗口、跨距、成本、现金约定，也不共用被平均的那个统计量的定义。例如W01是行业基金上的日频权重规则，均线长度为$50$和$200$；同一个计数里的其他权重页面用的是不同的规则和不同的期限，其中还包括跨距以天或周计的日内页面。一个平均数把这些协议搅成一个数字，然后冠上一个软件模式的名字。模式不是信息集。

重跑这些页面——本图谱并没有做——也修不好这句话。对二十五个不同函数的二十五次诚实复现，仍然是二十五个函数。[[#def-weight]]说，权重是在写明映射之下的目标比例。在这个平均数的底下，并不存在一个叫作"权重模式"的统一映射。走步验证页面不在这$25$个之内，而且库甚至没有把那些页面呈现为独立的样本外证据。把这个平均当作偏好权重而非订单的理由，或当作入场交易的理由，就是添加了一条输入所无法支持的推荐。系统性之问是针对一个写明的函数、在一个写明的时钟提出的。一个删掉了函数的平均，并没有提出这个问题。
:::
