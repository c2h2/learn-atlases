两句研究陈述共享"动量"这个词，而它们看的并不是同一类信息。一句对样本池排序。另一句只读每个资产自身的过去，从不问房间里还有谁。单条价格上的一条移动平均规则——在趋势课程里已经作为时间序列动量学过——可以为一个只有一个个体的样本池陈述。赢家减输家组合做不到这一点：只有一个名字时，没有任何东西可以排序。把这两句话当成同一个策略，然后把它们各自报告的夏普拿来比较，仿佛不同的只是标签——把严谨的页面碾成口号，就是这么碾的。

横截面这句话，在美国股票上，由贾加迪什（Jegadeesh）与蒂特曼（Titman）在1993年钉死。他们按三到十二个月窗口上的过去收益给股票排序，留下一小段间隔，并把得到的组合持有相近的时长。在那个样本里，过去的赢家平均跑赢过去的输家。那是关于一个排名的历史陈述。它不是持有任何东西的指令，也不是单个资产自身过去收益率的符号那样的对象。

## 每条规则被允许看什么

标注在$t$的信号只能使用在$t$已知的信息。它挣的是$t$之后发生的东西。把$F_{i,t}$写成资产$i$的一个过去简单收益率，由截至$t$的价格算出，窗口留到下一章去钉死。数$F_{i,t}$是一个输入。规则能拿它做什么，取决于你选了哪句话。

:::definition 横截面动量信号 {#def-cs}
设$U_t$为在日期$t$已知的样本池，并对每个$i \in U_t$，设$F_{i,t}$为在$t$已知的一个过去简单收益率。$i$的**横截面动量信号**是$F_{i,t}$在$U_t$内部的排名，最大的那个值记排名$1$。一条组合规则是从这些排名到权重$w_{i,t}$的一条写明的映射。这个映射是实验的一部分。光有排名不是一个权重。
:::

:::definition 时间序列动量信号 {#def-ts}
资产$i$在$t$的**时间序列动量信号**是该资产自身过去简单收益率的符号，
$$
s_{i,t} = \sgn(F_{i,t}),
$$
并约定$\sgn(0) = 0$。它不依赖于任何其他资产。这与[[trend/the-trend-hypothesis]]里的趋势假说是同一个对象，在这里重述一遍，好让对照始终可见。
:::

横截面规则可以做空一个自身过去收益率为正的标的，因为总有别的标做得更好。时间序列规则不能：自身过去收益率为正就是一个多头信号，无论样本池的其余部分做了什么。反过来同样锋利。一个自身过去收益率为负的标的，在时间序列规则下是空头，哪怕它是整个样本池里最不难看的名字；而一个只做空排名最底部一截的横截面规则，可能根本不动它。

:::intuition 赛跑，还是日记
横截面动量是一场赛跑：信号是在写明的一场比赛里谁先冲线。时间序列动量是一本日记：信号是这一个资产自身的过去收益率是否为正。日记可以为单独一个名字记；赛跑没法用单独一个名字来跑。给每个跑者的时间加上同一个常数，不改变冲线次序，却可以改变日记——这就是[[#prop-shift]]的内容。
:::

## 从排名到一本零和账簿

映射还是得写下来。本章通篇使用的版本是等权赢家减输家账簿：给最好的$K$个名字每一个相同的权重，给最差的$K$个名字每一个相反的权重，给处在中间的每一个名字权重零。平局会让规则不完备，所以陈述假设没有平局。平局裁决是进一步的选择，不是细节。

:::algorithm 等权赢家减输家账簿 {#alg-wml}
固定$K \ge 1$，并设样本池有$n \ge 2K$个名字，且在$F_{i,t}$上没有平局。

1. 把样本池按$F_{i,t}$排序，最大的在前。
2. 给前$K$个名字——赢家——每一个权重$+1/K$。
3. 给后$K$个名字——输家——每一个权重$-1/K$。
4. 给每一个其余的名字权重$0$。
5. 这些权重从$t$处的决策起持有，直到下一次决策。它们挣得简单收益率$R_{i,t+1}$，用的是$t$之后的价格。
:::

于是每一侧各自合计到$+1$或到$-1$。总敞口——权重绝对值之和——是$2$：一个单位的多头，由一个单位的空头融资。权重的净和为$0$。但那句话里没有任何东西说这本账簿没有市场敞口。权重之和等于零不是beta等于零。beta需要一个写明的基准和一个协方差，而本章不做任何估计。组合课程在[[portfolio/long-only-and-neutral]]里把这些约束分开。

:::proposition 赢家减输家 {#prop-wml}
假设使用[[#alg-wml]]的权重，并把赢家的下一个简单收益率的等权平均写成$\bar R^{(W)}_{t+1}$，把输家的写成$\bar R^{(L)}_{t+1}$。则组合的简单收益率为
$$
R_{p,t+1} = \sum_i w_{i,t} R_{i,t+1} = \bar R^{(W)}_{t+1} - \bar R^{(L)}_{t+1},
$$
并且$\sum_i w_{i,t} = 0$。
:::

:::proof
赢家共$K$个，每个权重$1/K$，所以赢家一侧贡献
$$
\sum_{i \in W} \frac{1}{K} R_{i,t+1} = \bar R^{(W)}_{t+1}.
$$
$K$个输家每个权重$-1/K$，贡献$-\bar R^{(L)}_{t+1}$。中间的名字什么都不贡献。把这几块加起来就得到那个恒等式。权重之和是$K \cdot (1/K) + K \cdot (-1/K) = 0$。
:::

这个恒等式一行写完了整个策略。这个账簿在下一期挣到钱，当且仅当赢家的平均简单收益率超过输家的。两侧可以都在涨，也可以都在跌。进入$R_{p,t+1}$的只有差距。

:::corollary 共同的下一期收益率 {#cor-common}
若$\sum_i w_{i,t} = 0$，且每个资产的下一个简单收益率都被平移同一个常数$c$，则组合的简单收益率不变。
:::

:::proof
$$
\sum_i w_{i,t} (R_{i,t+1} + c) = \sum_i w_{i,t} R_{i,t+1} + c \sum_i w_{i,t} = \sum_i w_{i,t} R_{i,t+1},
$$
因为第二个和是零。假设$\sum w = 0$是对这个具体映射在[[#prop-wml]]里证明过的结果。同一套一行论证适用于任何其他零和权重向量。
:::

对*形成期*收益率做共同平移是另一种操作。它作用在信号上，而不是下一期上，本章的两句话对它的答案并不相同。

:::proposition 形成期收益率的共同平移 {#prop-shift}
把每一个形成期收益率换成$F_{i,t} + c$，$c$为同一个常数。每个排名都不变，于是[[#alg-wml]]的权重也不变。时间序列的符号却未必不变：若$F_{i,t} < 0$且$F_{i,t} + c > 0$，则$\sgn(F_{i,t} + c) = +1$而$\sgn(F_{i,t}) = -1$。
:::

:::proof
若$F_{a,t} > F_{b,t}$，则$F_{a,t} + c > F_{b,t} + c$。严格不等式——以及没有平局的样本池里的排名——对加上$c$保持不变。赢家集合与输家集合还是同样的集合，所以权重还是同一个向量。关于符号的那句就是$\sgn$的定义：一个负数与一个正数符号相反。两个名字的情形$F = -0.02$与$F = 0.03$、取$c = 0.05$是一个见证。平移后的值是$0.03$与$0.08$。次序纹丝未动。第一个符号从$-1$翻成了$+1$。
:::

:::quiz
对一个只有一个资产的样本池，下列哪一项能够算出来？
- [ ] 它的过去收益率的横截面排名
- [x] 它自身过去收益率的符号
- [ ] 一个$+1/K$的赢家减输家权重
- [ ] 赢家减输家命题里的那个恒等式，它需要一个输家集合
:::solution
排名要成为一次比较，至少需要两个形成期收益率；赢家减输家账簿既要一个顶部也要一个底部。单个资产自身过去收益率的符号，不援引任何别的东西就有定义。这就是为什么时间序列动量在概念上属于趋势课程，以及为什么它可以为单条价格序列陈述。
:::
:::

## 一本四个名字账簿，两种方式算

本节里的数字是编造的。它们不是W15的一个样本，也不是预测。它们存在，是为了让权重与下一期收益率能被完整地看到。

:::example 四个形成期收益率 {#ex-rank}
四个名字的十二个月简单收益率（已经算出、在决策时已知）为：北$0.30$、东$0.12$、南$-0.08$、西$0.04$。没有平局。用[[#alg-wml]]、取$K = 2$造出账簿。按（北、东、南、西）的顺序写出权重向量，并核对权重之和为零。
:::solution
按形成期收益率排序，最大的在前：北$0.30$、东$0.12$、西$0.04$、南$-0.08$。

赢家是北与东，每个权重$+1/2$。输家是西与南，每个权重$-1/2$。按要求的顺序，权重是
$$
(0.5,\ 0.5,\ -0.5,\ -0.5).
$$
和为$0.5 + 0.5 - 0.5 - 0.5 = 0$。总敞口是$2$。西被做空，尽管它自身的形成期收益率为正。对排名来说这是被允许的，对符号规则来说这是被禁止的。
:::
:::

:::example 下个月，以及那个恒等式 {#ex-next}
保留[[#ex-rank]]的权重。下个月的简单收益率（做决策时并不知道）为：北$0.02$、东$-0.01$、南$0.04$、西$0.05$。先用权重算组合的简单收益率，再用[[#prop-wml]]算一遍。
:::solution
由权重，
\begin{align*}
R_p &= (0.5)(0.02) + (0.5)(-0.01) + (-0.5)(0.04) + (-0.5)(0.05) \\
&= 0.010 - 0.005 - 0.020 - 0.025 \\
&= -0.040.
\end{align*}
赢家的下一个收益率平均为$(0.02 + (-0.01))/2 = 0.005$。输家的平均为$(0.05 + 0.04)/2 = 0.045$。恒等式说
$$
R_p = 0.005 - 0.045 = -0.040,
$$
同一个数。名字们不必非得下跌。输家涨得比赢家还多，而一个做多赢家、做空输家的账簿在这一个月亏了$0.040$。按[[#cor-common]]，给四个下一期收益率统统加上同一个常数，$-0.040$也不会变。这笔亏损是一个差距，不是一个市场水平。
:::
:::

:::example 同样四个名字，记日记的方式 {#ex-ts}
用[[#ex-rank]]里的形成期收益率，写出时间序列符号。给每个名字绝对权重$1/2$、符号取它自身形成期收益率的符号，把敞口缩放到同样的总敞口$2$。在与[[#ex-next]]相同的下一月收益率上计算这个组合的简单收益率。
:::solution
形成期收益率对北、东、南、西的符号是$+$、$+$、$-$、$+$。绝对权重$1/2$下，时间序列权重是
$$
(0.5,\ 0.5,\ -0.5,\ 0.5).
$$
它们不加总到零：三个多头一个空头，净权重$0.5 + 0.5 - 0.5 + 0.5 = 1$。对上了总敞口，对不上净敞口。组合收益率为
\begin{align*}
R^{\mathrm{ts}} &= (0.5)(0.02) + (0.5)(-0.01) + (-0.5)(0.04) + (0.5)(0.05) \\
&= 0.010 - 0.005 - 0.020 + 0.025 \\
&= 0.010.
\end{align*}
横截面账簿在同一个下个月返回$-0.040$。分歧出在西。形成期收益率$+0.04$把西放进这个样本池的后半，所以[[#alg-wml]]做空西，而符号规则做多西。一个名字，两句话，方向相反的头寸。把$-0.040$与$0.010$取平均，哪个规则都不描述。
:::
:::

:::example 一个排名视而不见的平移 {#ex-shift}
两个资产的形成期收益率为$-0.02$与$+0.03$。给两者都加上$c = 0.05$。用$\sgn(0) = 0$（仅当某个值恰好落在零上时）陈述平移前后的排名，以及平移前后的时间序列符号。
:::solution
平移前，次序是第二个资产在前、第一个在后。符号是$-1$与$+1$。平移后，形成期收益率是$0.03$与$0.08$。第二个资产仍然领先，所以赢家减输家映射不变：$K = 1$时，仍然做多第二个、做空第一个。符号现在成了$+1$与$+1$。第一个资产翻了。[[#prop-shift]]就是这套算术，不是数$0.05$有什么特殊。任何$c > 0.02$都会让第一个形成期收益率变正，而对排名毫发无损。
:::
:::

:::warning 一个标签，两个实验
把两个规则都叫动量，然后开口闭口"动量的夏普"，就把信息的选择藏了起来。[[#ex-next]]里的横截面账簿与[[#ex-ts]]里的时间序列账簿看到的是同样四个数、同一个月下。它们持有的头寸不同，挣到的收益率也不同。后面某一章改动窗口、跳过或再平衡日历，是在再一次改变实验。这些改动中的每一个都不是对另外哪一个的评论。
:::

共用笔记里的路径A，价格$(100, 102, 101, 104, 103, 107, 106, 110)$，是一条只有一个资产的路径，所以[[#def-cs]]里的排名无法形成。它的七个简单收益率符号交替。于是，一个带一步合法滞后的时间序列规则——挣得收益率$t$的头寸是收益率$t-1$的符号——在它被允许迈出的每一步上都在错误的一侧。这是这个短小的交替玩具的一个性质，不是一条关于市场的发现。头寸清单与完整的趋势假说在[[trend/the-trend-hypothesis]]。这里的要点只是那个缺席的对象：没有第二个名字，所以没有横截面。

:::widget plot
f: 100*exp(0.01*x); 130*exp(-0.005*x)
x: 0, 40
labels: Starts behind; Starts ahead
caption: 两条编造的价格路径。一条起点更低、增长更快。哪个名字领先，取决于你在哪个窗口上排序。符号规则从不问那个问题：它只问每条路径自身的过去收益率是否为正。这里没有任何东西是预测。

## W15报告了什么，以及没报告什么

开放库里的那张横截面页面是一个单独的规格说明，不是对1993年假说的一个裁决。W15的描述是：按十二个月收益率做多头部$3$只、做空尾部$3$只，每月再平衡。K线是日频的。跨度$26$年。按quants.md对那个QuantJourney示例（Apache-2.0）的报告（2026年读入），那一行是：已报告总收益率$+1.3\%$，年化复合增长率$+0.05\%$，已报告夏普比率$-0.24$，最大回撤$-25.4\%$，胜率$49.4\%$，盈亏比$1.00$。本图谱没有重跑这个回测，也没有核实已报告夏普里的年化方式与无风险利率。这个数是他们报的。它不是本图谱为短例子定义的那个夏普比率。

把这一行读成一个平淡的公开结果。年化复合增长率$+0.05\%$按$26$年复利大约就是$+1.3\%$，与已报告的总收益率相符：$(1.0005)^{26} - 1 \approx 0.013$。这是同一条平静的路径被描述了两遍，不是两种不同的成功。盈亏比$1.00$意味着，无论目录把什么单位叫作一次胜，正贡献之和与负贡献的绝对值之和相等。它不是一个接近零的盈亏比，也不是一个很大的。胜率$49.4\%$在那个单位已知之前无法解读；业绩课程在[[performance/win-rate-and-profit-factor]]里发出那条警告。已报告的夏普是负的，挨着一个微小的正年化复合增长率。若超额是相对一个为正的融资利率取的，或者两个统计量不是同一个序列，这两格也可以并存。本图谱不会替谁凭空编一个调停。

诚实的那句话是那句乏味的。在那一页印出的窗口与规格说明上，这个横截面账簿没有复利成任何值得读者钦佩的东西，而回撤依然是$-25.4\%$。一页平淡不是拿相反权重的理由。反方向的账簿是另一个实验，有它自己的成本，而开放库没有报告它。一页平淡也不是宣布1993年的平均结果为假的理由。W15是一种实现：前三名对后三名，十二个月收益率，一个月度时钟，那些数据，那些成本。贾加迪什与蒂特曼的样本、窗口和股票池不是这一页。把它们中的任何一个与[[trend/moving-averages]]里的一条时间序列移动平均回测相比较，就把信号、样本池和时钟同时换掉了。两个已报告夏普之间的差距，不会是两个假说之间的差距。

:::quiz
W15在$26$年里报告年化复合增长率$+0.05\%$、盈亏比$1.00$。哪种读法对得上这一行？
- [ ] 盈亏比接近零，所以输家占了上风
- [ ] 已报告的夏普为负，意味着总收益率必定为负
- [x] 公开的路径是平的：盈亏比说胜负在目录的单位上相互抵消，年化复合增长率约为零
- [ ] 这一行是持有前三账簿之相反方向的理由
:::solution
盈亏比$1.00$意味着比率两侧相等。它不是说分子接近零。年化复合增长率略微为正，所以总收益率那一格不是亏损。反方向的账簿页面上没有报告，而一个平淡的结果不是把权重反手做的指令。
:::
:::

:::remark 已报告的夏普
每当本课程引用一个来自开放库的夏普比率，所用的字样都是**已报告的夏普**。我们自己的短例子里使用的那个定义——超额收益率的均值除以超额收益率的标准差，无风险利率写明、常取零——并不假定就是他们的定义。
:::

:::history
贾加迪什与蒂特曼，1993年，Journal of Finance：他们按中期限的过去收益给美国股票排序，并持有过去的赢家对抗过去的输家。在三、六、九、十二个月的形成与持有窗口上，赢家在他们的样本里平均跑赢输家。六个月乘六个月那一格，是后来的摘要通常说成大约每月百分之一的那个。本图谱没有重算那张表。卡哈特（Carhart）在1997年，把一个赢家减输家因子放到法玛（Fama）–弗伦奇（French）三因子模型旁边，作为共同基金研究里的一个控制。那个因子是一件研究工具。它不是一个产品，也不是W15。

## 通往何处

排名还需要一个窗口、一个可以被跳过的月份，以及一条当资产自身过去收益率为负时该怎么办的规则。这就是[[momentum/formation-skip-and-dual]]。同一本零和账簿有一条平均数藏不住的左尾，在[[momentum/momentum-crashes]]里研究。日记版本——一个资产自身过去的符号——留在[[trend/the-trend-hypothesis]]，而让符号有信息量或没用的那种相依性，是[[statistics/moments-and-dependence]]里的滞后1阶自相关。

:::summary
- 横截面动量按过去收益给一个样本池排序。时间序列动量只用每个资产自身过去的符号。后者可以为一个资产陈述；前者不能。
- 等权赢家减输家映射给$K$个赢家中的每一个权重$+1/K$，给$K$个输家中的每一个$-1/K$。权重之和为$0$，总敞口为$2$。
- 在这个映射下，下一个简单收益率等于赢家的下一个平均收益率减去输家的下一个平均收益率。对每个下一期收益率的共同平移会被消掉。对每个形成期收益率的共同平移让排名纹丝不动，却能把时间序列符号翻面。
- 一个名字可以是相对的输家、绝对上的赢家。在四个名字的玩具里，西在排名里是空头，在符号规则里是多头，两本账簿在同一个下个月返回$-0.040$与$+0.010$。
- W15——按十二个月收益率前三对后三、每月——是$26$年上已报告的平淡结果：已报告总收益率$+1.3\%$，年化复合增长率$+0.05\%$，已报告夏普比率$-0.24$，最大回撤$-25.4\%$，盈亏比$1.00$。本图谱没有重跑。这一行不是把账簿反手做的理由，也不是1993年的样本。
:::

## 练习

:::exercise 中间形成期收益率上的权重 {level=1 check="-0.5"}
四个名字A、B、C、D的形成期收益率为$0.15$、$0.02$、$-0.07$与$0.09$，没有平局。用[[#alg-wml]]、取$K = 2$。B上的权重是多少？（用小数输入权重。）
:::solution
排序：A $0.15$、D $0.09$、B $0.02$、C $-0.07$。赢家是A与D，每个$+1/2$。输家是B与C，每个$-1/2$。B上的权重是$-0.5$。
:::
:::

:::exercise 该账簿的下月收益率 {level=1 check="0.04"}
保留上一题的权重。下一个简单收益率为A $0.03$、B $0.01$、C $-0.02$、D $0.04$。组合的简单收益率是多少？（输入一个小数。）
:::solution
权重是A $+0.5$、B $-0.5$、C $-0.5$、D $+0.5$。
$$
R_p = (0.5)(0.03) + (-0.5)(0.01) + (-0.5)(-0.02) + (0.5)(0.04) = 0.015 - 0.005 + 0.010 + 0.020 = 0.040.
$$
赢家的平均为$(0.03+0.04)/2 = 0.035$，输家的平均为$(0.01 + (-0.02))/2 = -0.005$，而$0.035 - (-0.005) = 0.040$。
:::
:::

:::exercise 总敞口 {level=1 check="2"}
对同样的$K = 2$账簿，权重绝对值之和是多少？（输入一个整数。）
:::solution
四个名字各携带绝对权重$1/2$，而$K = 2$时四个名字的样本池中点是空的。总敞口是$4 \times 1/2 = 2$。净和仍是$0$。
:::
:::

:::exercise 同样四个名字上的时间序列权重 {level=2 check="0.05"}
形成期收益率仍为A、B、C、D的$0.15$、$0.02$、$-0.07$、$0.09$，下一个收益率为$0.03$、$0.01$、$-0.02$、$0.04$。给每个名字绝对权重$1/2$与它自身形成期收益率的符号。组合的简单收益率是多少？（输入一个小数。）
:::solution
形成期收益率的符号是$+$、$+$、$-$、$+$。权重：$(0.5,\ 0.5,\ -0.5,\ 0.5)$。
$$
R = (0.5)(0.03) + (0.5)(0.01) + (-0.5)(-0.02) + (0.5)(0.04) = 0.015 + 0.005 + 0.010 + 0.020 = 0.050.
$$
横截面账簿在同样的下一组收益率上挣$0.040$。C在两个规则下都是空头。B在排名里是输家、因而在那里是空头，在符号规则下却是多头。这两个收益率没有义务相等。
:::
:::

:::exercise 平移后的形成期收益率 {level=2 check="0.03"}
一个资产的形成期收益率是$-0.02$。你加上$c = 0.05$，如同[[#ex-shift]]。平移后的形成期收益率是多少？（输入一个小数。）
:::solution
$-0.02 + 0.05 = 0.03$。符号从$-1$翻到$+1$。对另一个形成期收益率为$+0.03$、现为$+0.08$的资产的排名不变，因为正如$-0.02 < 0.03$，也有$0.03 < 0.08$。
:::
:::

:::exercise 共同的下一期收益率 {level=2 check="0"}
一个赢家减输家账簿的权重之和为零。下一期里每个资产——赢家与输家都一样——的简单收益率为$0.07$。组合的简单收益率是多少？（输入一个小数。）
:::solution
按[[#cor-common]]，从以零为基准出发、对每个下一期收益率平移$0.07$，加上的是$0.07$乘以权重之和。那个和是$0$，所以$R_p = 0$。[[#prop-wml]]里的恒等式说的是同一件事：两个平均都等于$0.07$，差为$0$。一个零和动量账簿不会为一次把每个名字抬同等幅度的上涨拿到报酬。
:::
:::

:::exercise 只用那两个平均 {level=3 check="-0.03"}
没有人告诉你个别的下一期收益率。只告诉你账簿按[[#alg-wml]]形成，赢家等权平均的下一期收益率为$0.02$，输家等权平均的下一期收益率为$0.05$。$R_p$是多少？（输入一个小数。）
:::hint
两个平均一旦已知，个别名字就不再需要了。去看那个把$R_p$写成两个平均之差的恒等式。
:::
:::solution
[[#prop-wml]]给出$R_p = 0.02 - 0.05 = -0.03$。赢家涨了，输家涨得更多。你自始至终没看见任何一个亏钱的资产，而账簿亏了$0.03$。
:::
:::

:::exercise 路径A第一步上的合法滞后 {level=3 check="-0.009804"}
路径A的前两个简单收益率为$0.020000$与$-0.009804$。一个时间序列规则把挣得某一期收益率的头寸设为上一期收益率的符号，而且它不得使用自己正要挣的那个收益率。第二个收益率上每单位绝对头寸的简单盈亏是多少？（输入六位小数的数。）
:::hint
乘在第二个收益率上的符号，是第一个收益率的符号，不是第二个收益率自己的符号。头寸是$+1$。
:::
:::solution
第一个收益率为正，所以第二步的合法头寸是$+1$。盈亏是$(+1) \times (-0.009804) = -0.009804$。用第二个收益率自己的符号将是同K线规则。那不是[[#def-ts]]定义的信号。
:::
:::
