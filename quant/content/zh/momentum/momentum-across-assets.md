前面几章的那些话没有提到过股票。它们提到过一个过去收益率、一个排名或一个符号、以及一个权重。那些话可以被读在货币对上。把它们读在货币对上，与得到同号的结果，不是一回事。在这个开放库里，属于本章的三页外汇动量，在它们报告的窗口上为负。一个为负的已发表结果，是记录的一部分。它不是一张开相反交易的指令，也不是下一个窗口将为负的预测。它是关于那些规格说明、那些报价、那些成本与那些年的证据。

工具换了，那两句话仍然是两句话。时间序列动量仍然看一对货币对自己的过去收益率。横截面动量仍然给一个货币对样本池排序，并把最强的对抗最弱的持有。其中一页上的亏损，不是关于另一页的一个结果。把它们混进"外汇动量"里，然后再把符号翻过来，是一次犯下两个错误。

## 同样的两句话，指向一个报价

W23是以美元报价的即期货币对上的六个月时间序列动量，带逆波动率权重。W24是每月做多最强的、做空最弱的XXX/USD货币对。第一句是日记，每一对一个符号，即[[momentum/two-kinds-of-momentum]]里定义、并且已经作为趋势学过的那一类。第二句是排名，即同一章里定义的那一类，只是每一端取极端的那一对，而不是一个庞大的赢家集合与一个庞大的输家集合。O19是又一份规格说明：整手，用在以美元报价的即期货币对上。美元报价意味着什么、手是什么，在[[asset-classes/foreign-exchange]]与[[orders/lots-contracts-and-intraday]]里已经讲完。本章不重新推导合约。它认领已报告结果的符号，以及拒绝把那个符号转过来的态度。

"以美元报价"与"XXX/USD"是目录的用词。翻转一个报价，就翻转了多头头寸想要的方向。这也是读者不能从一块仪表盘上自创相反交易的一个理由：在报价约定写明之前，一个被印出的收益率的相反数甚至都没有良好定义。工具那一章是展开这个约定的地方。在这里，让库的措辞原样不动就够了。

## 逆波动率权重，两个都是多头

组合课程推导逆波动率映射，以及波动率目标这个分开的问题。这里需要的只有共用笔记里已经钉死的两资产算术。若两个资产的波动率估计为正的$0.10$与$0.20$，原始倒数权重是$10$与$5$，除以它们的和$15$，得$2/3$与$1/3$。

:::definition 多头账簿的逆波动率权重 {#def-invvol}
设一个时间序列信号已经选定一组合做多持有的资产，且每个资产的波动率估计$\sigma_i > 0$在决策日期已知。**逆波动率权重**为
$$
w_i = \frac{1/\sigma_i}{\sum_j 1/\sigma_j}.
$$
权重为正且加总到$1$。$\sigma_i$内部的窗口，以及选出这组资产的符号内部的期限，都是规格说明的一部分。W23把六个月符号与逆波动率映射一起使用。这个定义只是那张映射。
:::

若一些符号是空头，带符号的原始分数就是$\sgn(F_i)/\sigma_i$，而一个共同的归一化除以诸原始分数绝对值之和，使得总敞口为$1$。那个带符号的映射不是$2/3$、$1/3$那个例子。那个例子是多头账簿，两个符号都是多头，即共用笔记算过的情形。一个为负的自身过去收益率，本来会把一对货币从[[#def-invvol]]里移除，或在带符号的映射里翻掉它的符号。说清你在用哪条规则。W23的一行式描述说的是"一条趋势规则上的逆波动率权重"，而按趋势的意思，它可以是空头。下面的玩具是更容易的对象：两个权重都为正。带符号的映射记在下一个定义里，好让一个为负的自身过去收益率有一个权重，而不是被悄悄丢掉。

:::definition 带符号的逆波动率权重 {#def-signed}
设每个资产有一个时间序列符号$s_i \in \{-1,+1\}$与一个波动率估计$\sigma_i > 0$，两者都在$t$已知。原始分数为$s_i/\sigma_i$。**带符号的逆波动率权重**除以诸原始分数绝对值之和，
$$
w_i = \frac{s_i/\sigma_i}{\sum_j |s_j|/\sigma_j},
$$
于是$\sum_i |w_i| = 1$。若每个符号都是$+1$，这与[[#def-invvol]]是同一个权重向量。若任何符号为$-1$，权重便不再全为正，而它们的和也不必须是$1$。
:::

:::example 两对货币，权重$2/3$与$1/3$ {#ex-inv}
货币对Low的波动率为$0.10$，货币对High的波动率为$0.20$。两个时间序列信号都是多头。下一个简单收益率为Low的$+0.01$与High的$-0.05$。计算逆波动率权重与组合的简单收益率。在同样的两个收益率上计算等权组合收益率。
:::solution
原始倒数：$1/0.10 = 10$与$1/0.20 = 5$。和是$15$。权重是$10/15 = 2/3$与$5/15 = 1/3$。
$$
R_p = \frac23(0.01) + \frac13(-0.05) = \frac{0.02}{3} - \frac{0.05}{3} = \frac{-0.03}{3} = -0.01.
$$
等权，$1/2$与$1/2$，给出
$$
\frac12(0.01) + \frac12(-0.05) = 0.005 - 0.025 = -0.020.
$$
逆波动率账簿亏了一个百分点。等权账簿亏了两个。较大的亏损坐在较小的权重上，所以在*这两个数字上*，加权账簿亏得少。这是算术。它不是偏爱逆波动率映射的理由，不是对W23的一个描述，也不是持有任何一对货币的建议。W23的已报告结果——下面引用——是十六年上的一笔亏损，不是一个一期之内把亏损减小的故事。
:::
:::

一个共同的下一期收益率本来谁都帮不了。若两对都返回$+0.03$，两本账簿都会返回$+0.03$，因为两个权重向量都加总到一。$-0.01$与$-0.020$之间的差距，完完全全是在如何分摊收益率的一个*差距*上，两个映射意见不同。逆波动率是一条符号规则内部的一个缩放选择。它不是第三种动量。

## 为什么印出来的亏损不能翻过来

设对一个时期，毛组合收益率在成本拖累之前是$g = \sum_i w_i R_i$。设拖累$\kappa > 0$依赖于换手，而符号取反的权重$-w$有同样绝对值的交易，所以付同样的$\kappa$。这是关于成本的一个建模假设，不是一个测出来的价差。它已经足够挡下那句口号。

:::proposition 取反的账簿不是取负的净收益 {#prop-flip}
在刚才陈述的成本假设下，净收益率满足
$$
\mathrm{net}(-w) = -\mathrm{net}(w) - 2\kappa.
$$
若$\kappa$未知，$-\mathrm{net}(w)$就不是对面账簿的一份被报告为盈利的结果。若$\kappa = 0$，一期净收益恰好互为相反数，而超过一期的复合收益率，仍然不是原复合收益率的相反数。
:::

:::proof
写$\mathrm{net}(w) = g - \kappa$与$\mathrm{net}(-w) = -g - \kappa$。于是
$$
\mathrm{net}(-w) = -g - \kappa = -(g - \kappa) - 2\kappa = -\mathrm{net}(w) - 2\kappa.
$$
取负的净收益，把取反账簿的净收益高估了拖累的两倍。那就是一期的论断。

若$\kappa = 0$，则在那个单独时期内$\mathrm{net}(-w) = -g = -\mathrm{net}(w)$。两期之上，原复合收益率是$(1+g_1)(1+g_2)-1$，所以它的相反数是$1 - (1+g_1)(1+g_2) = -(g_1+g_2) - g_1 g_2$。取反后的复合收益率是$(1-g_1)(1-g_2)-1 = -(g_1+g_2) + g_1 g_2$。二者仅当$g_1 g_2 = 0$时相等。两个毛收益率的一个非零乘积，会破坏这个取负。复合与改变符号不可交换。
:::

那个证明里的交叉项正是全部要点，而一对干净的理由难让人跳过。下面的例子又把成本放了回来。

:::example 一期，然后两期 {#ex-cost}
单个时期上，取$g = -0.010$与$\kappa = 0.002$。计算原来的净收益、取反后的净收益，以及对原来净收益的朴素取负。

然后取两期，毛收益率为$-0.010$与$-0.020$，每期同样的$\kappa = 0.002$。计算原来账簿与取反后账簿的复合净收益率，保留六位小数。
:::solution
一期：原来的净收益是$-0.010 - 0.002 = -0.012$。取反后的毛收益率是$+0.010$，所以取反后的净收益是$0.010 - 0.002 = 0.008$。对原来净收益的朴素取负是$+0.012$。差距是$0.012 - 0.008 = 0.004 = 2\kappa$，这就是[[#prop-flip]]。

两期，原来的净收益：$-0.012$与$-0.022$。财富比率是$0.988 \times 0.978$。
$$
0.988 \times 0.978 = 0.966264, \qquad 0.966264 - 1 = -0.033736.
$$
取反后的净收益：$+0.008$与$+0.018$。财富比率是$1.008 \times 1.018 = 1.026144$，所以复合收益率是$0.026144$。对原复合收益率的朴素取负本会是$+0.033736$。取反后的账簿，甚至在任何人争论报价约定之前，复合成$0.026144$，而不是$0.033736$。而这些数字没有一个是库的结果。它们是那个恒等式，外加写明了的成本。W23的成本拖累没有作为单独的单元格报告，所以那个恒等式无法在那一页上求值。那是停下来的理由，不是假定$\kappa = 0$、照样把符号翻过去的理由。
:::
:::

:::example 两期，完全不带成本 {#ex-nocost}
保留毛收益率$-0.010$与$-0.020$，并设$\kappa = 0$。取反后账簿的复合收益率是什么？原复合收益率的相反数是什么？
:::solution
取反后的简单收益率为$+0.010$与$+0.020$。复合收益率是$1.01 \times 1.02 - 1 = 1.0302 - 1 = 0.0302$。

原来的财富比率是$0.99 \times 0.98 = 0.9702$，所以原复合收益率是$-0.0298$。它的相反数是$+0.0298$，不是$0.0302$。差距就是证明里的那个交叉项：$(1-g_1)(1-g_2) - 1$与$-\bigl((1+g_1)(1+g_2) - 1\bigr)$之差等于$2 g_1 g_2 = 2(0.010)(0.020) = 0.0004$，而$0.0302 - 0.0298 = 0.0004$。零成本修好了一期的口号，却让跨期的口号仍然是假的。
:::
:::

## 三页为负

下面的数字按quants.md对那个QuantJourney示例（Apache-2.0）的报告（2026年读入）原样照录。本图谱没有重跑这三个回测中的任何一个，也没有核实已报告夏普里面的年化方式。目录印着短横的地方，该统计量是未报告。三条外汇行的胜率与盈亏比都没有报告。本课不替它们填上。

W23，以美元报价的即期货币对上的六个月时间序列动量，逆波动率权重，日K线，$16$年：总收益率$-27.3\%$，年化复合增长率$-1.97\%$，已报告夏普比率$-0.59$，最大回撤$-29.4\%$。

W24，每月做多最强的、做空最弱的XXX/USD货币对，日K线，$16$年：总收益率$-34.1\%$，年化复合增长率$-2.58\%$，已报告夏普比率$-1.00$，最大回撤$-41.4\%$。

O19，考虑合约规格的整手动量，用在了以美元报价的即期货币对上，日K线，$16$年：总收益率$-14.2\%$，年化复合增长率$-0.95\%$，已报告夏普比率$-0.71$，最大回撤$-15.3\%$。

三个符号都是负的。幅度并不一致，而这种不一致是有信息量的。一个带逆波动率权重的六个月符号、一个每月横截面的两端那一对、一个整手约束，是三个实验。O19更温和的已报告亏损，不是"使用整手能把符号修好"的证据，也不是去做整手交易的建议。整手的取整是一个工具约束。相对一个分数权重，它改变了账簿，这就是已报告路径可以与W23的不同、而两页都没有被误读的原因。把$-0.59$、$-1.00$与$-0.71$平均成一根外汇动量夏普，会犯下本课从第一章起就在拒绝的同一个错误：不同的信号，一个标签。

共同的符号同样许可不了对面的账簿。一旦承认一个为正的拖累，[[#prop-flip]]就已经在单个时期之内让那句口号落空，而即便拖累为零，它跨期也让那句口号落空。在那套代数之上还有：W23的反面不是W24的反面。反转一条时间序列符号规则，与反转一条"做多最强、做空最弱"的规则，是不同的新策略。库两个都没有报告。一个跨市场的研究平均又是第三个对象。阿斯内斯（Asness）、莫斯科维茨（Moskowitz）与佩德森（Pedersen）2013年在Journal of Finance上，跨资产类别一起研究了价值与动量，货币也在其中。那篇论文不是W23的十六年期以美元报价的规格说明，而W23也不是那篇论文。一页为负的库页面，抵消不了一篇已发表的跨市场平均。一个跨市场平均，也抵消不了一页为负的库页面。本章这两种抵消都拒绝。

:::example 横截面那句话，用在三个编造的货币对上 {#ex-cs}
三个货币对的形成期收益率为$+0.07$、$+0.01$与$-0.04$。横截面规则是W24那句话缩放到一个玩具：以$+1/2$与$-1/2$做多最强、做空最弱，中间权重$0$。下一个简单收益率为$-0.02$、$+0.01$与$+0.03$。组合收益率是多少？

同样这些形成期收益率的时间序列符号是$+$、$+$与$-$。给每个名字绝对权重$1/3$，于是总敞口为$1$，并在同样的下一组收益率上计算那本账簿的收益率。
:::solution
横截面权重：$(+1/2,\ 0,\ -1/2)$。
$$
R^{\mathrm{cs}} = (1/2)(-0.02) + (-1/2)(0.03) = -0.010 - 0.015 = -0.025.
$$
时间序列权重：$(+1/3,\ +1/3,\ -1/3)$。
$$
R^{\mathrm{ts}} = \frac{-0.02 + 0.01 - 0.03}{3} = \frac{-0.04}{3} = -0.013333\ldots,
$$
六位小数为$-0.013333$。中间那一对在两端那一对的账簿里持币，在符号账簿里是多头。那就是股票那一章里的同一个不一致，搬到了货币对上。两个玩具收益率都是负的，是因为下一组收益率被选成了那个样子，不是因为W24必须为负。W24为负，是一个十六年期的已报告复合结果。一个编造的月份不是一次回测，而一笔亏过钱的回测，也修不好——哪怕换一个玩具、把下一组收益率挑得让人高兴一点。
:::
:::

:::warning 不要去交易那个负号
$-27.3\%$的已报告收益率，不是另一侧$+27.3\%$的已报告收益率，而$-1.00$的已报告夏普比率，也不是邀请你持有相反权重的请柬。账簿改符号时，成本不会跟着改符号。报价不会自我解释。三页彼此相差的，不只是一个符号。本章里那些负号的唯一用处，是把它们留着：本开放库里已发表的外汇动量例子，在印出的那些窗口上，亏了钱。读者拿一种货币做什么，不是图谱的议题。
:::

:::quiz
在[[#ex-cost]]里，$g = -0.010$且$\kappa = 0.002$，取反后一期的净收益是哪个数？
- [ ] $+0.012$，原来净收益的相反数
- [x] $+0.008$，取反后的毛收益率减去同一笔拖累
- [ ] $-0.008$，因为一页为负就必须一直为负
- [ ] $0$，因为成本恰好抵消了毛收益率
:::solution
取反后的毛收益率是$+0.010$。减去$\kappa = 0.002$，剩下$+0.008$。对原来净收益的取负是$+0.012$，它把取反后的净收益高估了$2\kappa = 0.004$。第三个选项把一个库符号与一个恒等式搞混了：取反后的玩具是正的，而那个为正仍然既不是建议，也不是库的结果。

:::intuition 同样的话，不同的工具，不同的一页
排名、符号、逆波动率公式里，没有任何东西用到过"股票"这个词。这就是那些话能够远行的原因。结果没有跟着它们一起远行，在这三页上，以一个刚从一篇股票动量论文里走出来的读者也许会期待的方向。同时握住这两个念头，就是这一章。那些话是可携带的。一次具体回测的符号不是那些话的一个属性。它是那一页的一个属性。
:::

:::remark 当一个符号为负时的总敞口
[[#def-invvol]]里权重加总到一，是因为每个被选中的名字都是多头。一条做空一对、做多另一对的带符号逆波动率规则，不加总到一。它需要一个写明的总敞口，正如赢家减输家映射需要一个的那样。在一本实际上做空高波动率那一对的账簿上使用$2/3$与$1/3$，会是一个符号错误，不是权重上的什么微妙之处。[[#ex-inv]]里的玩具声明两个信号都是多头，好让共用的$2/3$、$1/3$那些数字适用。
:::

:::application O19被允许教什么
O19的已报告总收益率为$-14.2\%$，已报告最大回撤为$-15.3\%$，两个单元格都比W23温和。规格说明是整手，而不是分数的逆波动率权重。一个停在"温和"上、并得出整手才是该跑的版本的读者，是把两页亏损之间的比较变成了一次挑选。两页在已报告的窗口上都亏了钱。没那么负的那一页仍然是负的。在亏钱的规格说明之间做挑选，用的又是产生那些亏损的同一段窗口，是一场搜索。为搜索定价的地方在验证课程。本章的差事，是把那些负号留在目录放它们的地方。
:::

:::history
阿斯内斯、莫斯科维茨与佩德森，Journal of Finance，2013年：一起研究了跨市场与跨资产类别的价值与动量，货币包括在内，还有两种溢价之间的相关性。一篇从美国股票起步的课程欠着其他工具一章，那篇论文就是理由。它不是关于库那些外汇页面的一张业绩承诺，而那些页面也不是对那篇论文的反驳。它们是在另一份样本上的另一种构造。丹尼尔（Daniel）与莫斯科维茨2016年的崩盘证据，不在这里被重述成一次外汇回归。崩盘仍然是关于赢家减输家支付的一个事实，在那篇论文研究的样本里。无论在股票上还是在货币对上，它们都不是一个产品。

## 通往何处

逆波动率映射，以及把一整本账簿缩放到一个波动率目标这个不同的动作，在[[portfolio/inverse-volatility-and-targets]]。报价约定、手数与那种工具的其余部分，住在[[asset-classes/foreign-exchange]]。一个平均所能藏起的崩盘形状，包括进入一场反弹的路上，在[[momentum/momentum-crashes]]。拒绝把两个同名的夏普当作一个实验，始于[[momentum/two-kinds-of-momentum]]。

:::summary
- 货币对上的时间序列动量用的是那对货币自己的过去符号。横截面动量给货币对排序。W23是第一句话带上逆波动率权重。W24是第二句话，做多最强、做空最弱。它们不是一条策略。
- 波动率$0.10$与$0.20$给出多头账簿权重$2/3$与$1/3$。在下一组收益率$+0.01$与$-0.05$上，组合收益率是$-0.01$，等权则$-0.02$。那个差距是这些输入上的一个缩放效应，不是对W23的一个裁决。
- 如果一笔为正的换手成本$\kappa$在每个权重都取反时保持不变，那么取反后的净收益等于取负的净收益减去$2\kappa$。$\kappa = 0$时，一期净收益恰好翻面，两期复合却不翻：$-0.010$随后$-0.020$复合成$-0.0298$，而取反后的路径复合成$+0.0302$。
- 按报告、未重跑：W23在$16$年里返回$-27.3\%$（年化复合增长率$-1.97\%$、已报告夏普比率$-0.59$、最大回撤$-29.4\%$）；W24返回$-34.1\%$（年化复合增长率$-2.58\%$、已报告夏普比率$-1.00$、最大回撤$-41.4\%$）；O19返回$-14.2\%$（年化复合增长率$-0.95\%$、已报告夏普比率$-0.71$、最大回撤$-15.3\%$）。胜率与盈亏比未报告。那些符号不许翻面。
- 一篇2013年论文里的一个跨市场平均，与一页为负的十六年期库页面，是不同的对象。两者互相抵消不了。
:::

## 练习

:::exercise 逆波动率组合收益率 {level=1 check="-0.01"}
权重$2/3$压在随后收益率为$+0.01$的一对货币上，$1/3$压在随后收益率为$-0.05$的一对上。组合的简单收益率是多少？（输入一个小数。）
:::solution
$(2/3)(0.01) + (1/3)(-0.05) = 0.02/3 - 0.05/3 = -0.03/3 = -0.01$。
:::
:::

:::exercise 同一对上的等权收益率 {level=1 check="-0.02"}
同样两个下一期收益率，$+0.01$与$-0.05$，以等权持有。组合的简单收益率是多少？（输入一个小数。）
:::solution
$(1/2)(0.01) + (1/2)(-0.05) = 0.005 - 0.025 = -0.020$，作为两位小数的输入是$-0.02$。逆波动率账簿在这一对特定的收益率上亏得少些。本课不推崇任何一种权重法。
:::
:::

:::exercise 一期的取反净收益 {level=1 check="0.008"}
毛收益率为$g = -0.010$，成本拖累为$\kappa = 0.002$，取反后的账簿再付一次同样的拖累。取反后账簿的净收益率是多少？（输入一个小数。）
:::solution
取反后的毛收益率是$+0.010$。扣掉拖累：$0.010 - 0.002 = 0.008$。对原来净收益的取负本会是$-(-0.012) = 0.012$，大了$0.004$。
:::
:::

:::exercise 两端那一对的玩具 {level=2 check="-0.025"}
权重为$+1/2$、$0$与$-1/2$。下一个简单收益率为$-0.02$、$+0.01$与$+0.03$。组合的简单收益率是多少？（输入一个小数。）
:::solution
$(1/2)(-0.02) + 0 \cdot (0.01) + (-1/2)(0.03) = -0.01 - 0.015 = -0.025$。中间那个收益率进不来。那就是"两端"那句话，而它不是W24的十六年结果。
:::
:::

:::exercise 同样三个下一期收益率上的符号规则 {level=2 check="-0.013333"}
权重为$+1/3$、$+1/3$与$-1/3$。下一个简单收益率为$-0.02$、$+0.01$与$+0.03$。组合的简单收益率是多少，保留六位小数？（输入六位小数的数。）
:::solution
下一组收益率的带符号之和是$-0.02 + 0.01 - 0.03 = -0.04$。除以$3$得$-0.013333\ldots$，六位小数为$-0.013333$。这本账簿做多中间那一对。两端那一对的账簿没有。收益率不同。
:::
:::

:::exercise 一个共同的下一期收益率 {level=2 check="0.03"}
一个$2/3$、$1/3$账簿里的两对货币，下一个简单收益率都是$+0.03$。组合的简单收益率是多少？（输入一个小数。）
:::solution
权重加总到$1$，所以$R_p = (2/3)(0.03) + (1/3)(0.03) = 0.03$。等权本会给出同样的数字。逆波动率改变不了两个名字共同拥有的收益率。
:::
:::

:::exercise 带成本的两期取反复合 {level=3 check="0.026144"}
毛收益率为$-0.010$与$-0.020$。每期向原来的账簿收$\kappa = 0.002$，并向取反后的账簿收同样的$\kappa$。取反后账簿的复合净收益率是多少？（输入该数，保留六位小数。）
:::hint
先把每个毛收益率翻面，然后减$0.002$，然后复合。两个净简单收益率为$+0.008$与$+0.018$。不要把原来的复合收益率取负；那正是[[#prop-flip]]拒绝的口号。
:::
:::solution
取反后的净收益：$0.010 - 0.002 = 0.008$与$0.020 - 0.002 = 0.018$。财富比率是$1.008 \times 1.018 = 1.026144$。复合收益率是$1.026144 - 1 = 0.026144$。原来的净收益$-0.012$与$-0.022$复合成$-0.033736$，而那个数的相反数不是$0.026144$。
:::
:::

:::exercise 零成本的两期取反 {level=3 check="0.0302"}
毛收益率为$-0.010$与$-0.020$，且$\kappa = 0$。符号取反后账簿的复合收益率是多少？（输入一个小数。）
:::hint
零成本之下，取反后的简单收益率恰为$+0.010$与$+0.020$。把这两个数复合。然后，作为核对而不是作为答案，把原来的收益率复合并取负。两个计算相差$0.0004$。
:::
:::solution
$1.01 \times 1.02 - 1 = 1.0302 - 1 = 0.0302$。原来的复合收益率是$0.99 \times 0.98 - 1 = -0.0298$，而$-(-0.0298) = 0.0298 \neq 0.0302$。连成本为零的一行取反，在两期上都不成立。一个已报告的十六年期复合收益率，离一行取反之远，远过这个玩具。
:::
:::
