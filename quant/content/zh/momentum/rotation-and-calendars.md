今天标注的一个动量信号，并不说账簿什么时候被允许交易。形成窗口、跳过与双动量过滤器选出一个目标权重向量。第二条规则再决定：这个目标是在一个日历日期上执行，还是只在信号旗标翻面时执行，抑或只在某个权重漂出了一条带子那么远时执行。这些就是换手政策。它们不是同一个回测的三个名字，而用来示例它们的开放库页面，也不是一个只换时钟的受控实验。

记账要先于政策讲清楚。如果你不交易，价格会替你把权重挪动。一个原本占账簿一半、随后上涨的名字，会变成超过一半，而其间没有做过任何决策。任何一条"每月再平衡"的规则，都是一条在某一天把这种漂移抹掉的规则。一条等待新信号的规则，则把漂移留在原地。这是一个差值，而下面这个数是算出来的，不是画出来的。

## 漂移是一个恒等式，不是一个观点

设在日期$t$的决策把权重$w_i$定为净资产值的比例，$\sum_i w_i = 1$，并且在下一次查看账簿之前没有外部现金流。资产$i$在这段区间上的毛简单收益率就是$G_i = 1 + R_i > 0$。起始价值为$w_i$的头寸，结束时价值为$w_i G_i$。组合结束于$\sum_j w_j G_j$；因为权重加总到一，这个数也就是组合的毛增长。

:::definition 漂移后的权重 {#def-drift}
在$\sum_i w_i = 1$且没有现金流入流出时，资产$i$的**漂移后权重**是
$$
w_i' = \frac{w_i G_i}{\sum_j w_j G_j}.
$$
那个名字的**漂移**是$w_i' - w_i^{\star}$，其中$w_i^{\star}$是你查看那一刻的目标权重。如果信号没有重新计算，目标就还是旧权重，漂移就是$w_i' - w_i$。
:::

:::proposition 两个资产的漂移 {#prop-drift}
设两个资产的权重为$w$与$1-w$，毛收益率为$G_1$与$G_2$。则
$$
w' = \frac{w G_1}{w G_1 + (1-w) G_2}.
$$
特别地，若$w = 1/2$且$G_2 = 1$，则$w' = G_1 / (G_1 + 1)$。
:::

:::proof
[[#def-drift]]的定义取两个名字就是第一个展示式：分母是权重乘毛收益率的和。代入$w = 1/2$与$G_2 = 1$。分母变成$(1/2) G_1 + (1/2) \cdot 1 = (G_1 + 1)/2$，分子是$(1/2) G_1$，于是比值化简为$G_1 / (G_1 + 1)$。
:::

:::corollary 相同的毛收益率不移动权重 {#cor-nodrift}
若$\sum_i w_i = 1$且每个资产的毛收益率都是同一个$G > 0$，则对每个$i$都有$w_i' = w_i$。
:::

:::proof
[[#def-drift]]的分母是$\sum_j w_j G = G \sum_j w_j = G$。分子是$w_i G$。把非零的$G$约掉，剩下$w_i$。一个每个所持资产简单收益率都相同的行情，改变不了一本满仓账簿的权重。漂移是一次相对变动，这就是为什么一个刚刚挑中奖器的账簿会对它敞口暴露：无论信号是判对了还是只是蒙对了，最有可能一骑绝尘的名字就是那个中奖者。
:::

:::example 从一半到$0.62$ {#ex-062}
两个资产A与B，起始权重$1/2$与$1/2$。区间内A的毛收益率为$31/19$，B的毛收益率为$1$。没有交易。求A漂移后的权重，以及相对原目标$1/2$的漂移。A的简单收益率是多少？
:::solution
由[[#prop-drift]]，
$$
w_A' = \frac{31/19}{31/19 + 1} = \frac{31/19}{50/19} = \frac{31}{50} = 0.62.
$$
漂移是$0.62 - 0.50 = 0.12$。A的简单收益率是$31/19 - 1 = 12/19$，六位小数为$0.631579$。B的简单收益率为$0$。用同一个恒等式取余量，B的新权重是$1 - 0.62 = 0.38$，漂移$-0.12$。这里不需要任何关于动量的观点。一个原本已经占一半权重的名字涨了，就把那个权重拉到了$0.62$。
:::
:::

这个距离$0.12$是净资产值的十二个百分点。它不是"大约十个百分点"那种能待在宽度$0.10$的带子里的说法。下面的政策使用一条绝对带：当绝对漂移超过$b$时交易；$b = 0.10$意味着十个百分点，与组合章节那条带的单位相同。在这条路径上，不等式$|0.12| > 0.10$为真。

一次更小的上涨会留在带子里，而政策之间的对照同样需要这条路径。

:::example 一条带子不理会的上涨 {#ex-inside}
起始权重仍保持$1/2$与$1/2$，现在让A的毛收益率为$1.20$，B的为$1$。计算漂移后的权重、六位小数的漂移，并说明宽度$b = 0.10$的带子是否被突破。
:::solution
$$
w_A' = \frac{1.20}{1.20 + 1} = \frac{1.20}{2.20} = \frac{6}{11} = 0.5454545\ldots,
$$
六位小数为$0.545455$。漂移是$6/11 - 1/2 = 1/22 = 0.0454545\ldots$，六位小数为$0.045455$。绝对漂移约为$0.045$，不大于$0.10$。十点带不交易。但月末的问题仍然悬而未决，因为日历不咨询这个不等式。
:::
:::

:::example 两个名字同步时，什么都不漂 {#ex-equal}
两个资产起始权重都是$1/2$。各自的毛收益率都是$1.10$。没有现金流。求第一个资产漂移后的权重，以及一条重置回同一目标的日历的单边换手。
:::solution
[[#def-drift]]的分子是$(1/2) \times 1.10 = 0.55$。分母是$(1/2) \times 1.10 + (1/2) \times 1.10 = 1.10$。比值是$0.55/1.10 = 0.50$。[[#cor-nodrift]]就是把这次约分写了一遍。漂移后的向量已经是目标，所以在这条具体的路径上，一次日历重置的单边换手为$0$。共同的变动不制造交易；只有*相对*变动会。这就是[[#ex-062]]里的那次上涨动了账簿、而这一次没有的原因。
:::
:::

## 对同一次漂移的三个回答

:::definition 三种再平衡政策 {#def-policies}
设$w'$为漂移后的权重向量，$w^{\star}$为决策时已知的信号所蕴含的目标——只使用当时可得的信息。

1. **日历。** 在一个固定集合的日期上——例如月末或季末——从$w'$交易到$w^{\star}$。信号不必发生过变化。
2. **信号变化。** 只在信号的离散旗标与上一次交易时的旗标不同的那次交易。一个已经漂移、而旗标未变的权重，就随它去。
3. **漂移带。** 若任何名字有$|w_i' - w_i^{\star}| > b$——写明的绝对带$b$——就把整本账簿从$w'$交易回$w^{\star}$。否则不交易。本课说十点带时，取$b = 0.10$。逐名字的带子与部分交易是另一条规则；W12的那个版本归组合课程所有。

从$w'$交易到一个新向量$u$的**单边换手**是
$$
\tau = \frac12 \sum_i |u_i - w_i'|.
$$
二分之一这个因子，把一次卖出与与之配对的一次买入计为一次。若不交易，$\tau = 0$。
:::

在[[#ex-062]]的路径上，取信号旗标未变、目标仍为$(1/2,\ 1/2)$。于是三个政策以一种能写成三个换手的数的方式发生分歧。

- 信号变化换手为$0$，因为旗标没有翻面。账簿被留在$(0.62,\ 0.38)$。
- 日历换手：落在这天的月末会把账簿重置为$(0.50,\ 0.50)$。绝对变动是$0.12$与$0.12$，于是$\tau = \tfrac12(0.12 + 0.12) = 0.12$。
- 十点带也交易，因为$0.12 > 0.10$；若目标相同，它的换手也是同样的$0.12$。

在[[#ex-inside]]的路径上，旗标再次未变。

- 信号变化换手为$0$。
- 日历换手为$\tfrac12 \times 2 \times (1/22) = 1/22 \approx 0.045455$。
- 带子换手为$0$，因为绝对漂移不超过$0.10$。

第二条路径，正是十点带保持沉默而月末规则不沉默的那条。第一条路径——从$0.50$走到$0.62$——则是带子与日历都交易、只有信号变化规则保持沉默的那条。把$0.62$一眼看成"离一半不到百分之十"，恰恰是[[#ex-062]]要来拦住的错误。距离是$0.12$。

:::example 一个真会翻面的旗标 {#ex-flip}
三个资产的漂移后权重为$(0.62,\ 0.38,\ 0)$，也就是[[#ex-062]]的两个名字上涨，再加一个权重仍为零的第三名字。此时信号发生变化。新目标是$(0,\ 0.5,\ 0.5)$：第一个名字退出了赢家集合，第三个名字进入了。计算交易到新目标的单边换手。日历日期、信号变化规则与十点带都看到第一个名字的变动远大于$0.10$。它们都会交易吗？
:::solution
变动是$0 - 0.62 = -0.62$、$0.5 - 0.38 = 0.12$与$0.5 - 0 = 0.50$。绝对变动之和是$0.62 + 0.12 + 0.50 = 1.24$。单边换手是$1.24 / 2 = 0.62$。这些变动加总到零——两个向量都是满仓时，它们必须如此。

三个政策都交易。日历交易，因为这天是再平衡日，而目标动了。信号变化规则交易，因为旗标变了：赢家集合变成了另一个集合。带子交易，因为$|0.62 - 0| = 0.62 > 0.10$，而且$|0 - 0.50| = 0.50 > 0.10$。在一次翻面上达成一致，并不使这些政策成为同一条规则。在旗标安静、而权重从$0.50$走到$0.62$的那条路径上，它们就已经不一致了。
:::
:::

:::warning 十二个点在十点带的外面
一条$10\%$的带子，在本课以及组合章节对同一个对象的陈述里，都是一个绝对距离$0.10$：当$|w' - w^{\star}| > b$时交易。漂移后的权重$0.62$对着目标$0.50$，距离是$0.12$。带子交易。带子跳过的路径是更小的那条——从$0.50$到大约$0.545$——那里距离是$1/22$。一条月末规则在两条路径上都交易。不说明用的是这三个反应中的哪一个，就引用一个"再平衡过的动量"收益率，引用的是一个混合物。
:::

:::widget plot
f: x/(x+1)
x: 1, 2.2
hlines: 0.5; 0.6
caption: 一个从一半起步的名字的新权重，另一名字的毛收益率保持为1。0.60处的水平线是围绕0.50的十点带的边缘。中奖者的毛收益率一旦超过1.5，曲线就穿过0.60；在毛收益率为31/19处它穿过0.62。这是一个记账恒等式，不是预测。
:::

:::quiz
信号旗标未变。政策是信号变化。中奖者的权重已经从$0.50$漂到了$0.62$。单边换手是多少？
- [ ] $0.12$，因为权重动了
- [x] $0$，因为旗标没有变
- [ ] $0.62$，因为那是新权重
- [ ] $0.10$，带的宽度
:::solution
只要离散旗标与上一次交易时相同，信号变化换手就是零。漂移是真的，而日历会为了把它抹掉交易$0.12$的单边换手。信号变化规则的定义就是不管它。
:::
:::

:::quiz
满仓的两资产账簿里，两个资产的毛收益率都是$1.10$。第一个的起始权重是$0.50$。漂移后的权重是多少？
- [ ] $0.55$，因为两者都涨了权重的百分之十
- [ ] $0.60$，十点带的边缘
- [x] $0.50$，因为相同的毛收益率不移动权重
- [ ] $1.10$，毛收益率本身
:::solution
[[#cor-nodrift]]把共同的毛收益率约掉了。两个名字都涨百分之十，会抬高净资产值，也按同一个因子抬高每个头寸的价值。净资产值中的份额原地不动。
:::
:::

## 开放库的页面是什么，以及不是什么

O17是一个多资产账簿上、以订单执行的月度事件驱动动量轮动。日K线，$19$年。按quants.md对那个QuantJourney示例（Apache-2.0）的报告（2026年读入）：已报告总收益率$+381\%$，年化复合增长率$+8.62\%$，已报告夏普比率$0.53$，最大回撤$-28.2\%$，胜率$52.1\%$，盈亏比$1.78$。本图谱没有重跑这个回测。"月度"一词，是[[#def-policies]]意义上的日历。"订单"意味着成交记录在项目里的订单模式而非权重模式；订单成交是另一门课程，本章不重新推导。"事件驱动"是目录对那些订单如何递交的说法，不是一张把O17当作信号变化政策的许可证。一句话的描述说的是月度，这里用到的就是月度那部分。

年化复合增长率$+8.62\%$与最大回撤$-28.2\%$这一对已报告的数，是对那个完整规格说明在$19$年上的描述。它不是日历之间的排名，也不是目标。更深的回撤挨着更高的年化复合增长率，本身既不是偏好那张页面的理由，也不是回避它的理由。页面上没有任何东西叫读者去跑这个轮动。

O18只在一条SMA趋势信号翻面时交易，目录自己的那一行说没有日历。日K线，$25$年。按对quants.md的同一次阅读：已报告总收益率$+130\%$，年化复合增长率$+3.38\%$，已报告夏普比率$0.22$，最大回撤$-16.3\%$，胜率$52.4\%$，盈亏比$2.21$。本图谱没有重跑。产生那次翻面的移动平均交叉在[[trend/moving-averages]]里推导；翻面规则照样会遭受的来回止损，在[[trend/lag-whipsaw-and-costs]]里讨论。这里一段就够，因为O18不是把日历拿掉之后的O17。信号是平均值交叉而不是动量排序，跨度是$25$年而不是$19$年，样本池是那个示例的样本池。拿$+8.62\%$减$+3.38\%$、把差值称为"月末时钟的价值"，就是把两页上所有其他差别都记到日历头上。[[#def-policies]]里的三个政策之所以在上面用共同的玩具路径比较，正是为了让时钟成为唯一改变的东西。开放库不提供那样一对页面。

W12是一个只在越过$10\%$漂移带时才做交易的动量倾斜。按报告，它在$26$年里的年化复合增长率为$+5.15\%$。完整的那一行——包括已报告夏普比率$0.30$与最大回撤$-36.8\%$——连同带子、换手预算与熔断器的代数，在[[portfolio/drift-turnover-and-breakers]]里讨论。本章从那页只借一个事实：带子是第三种政策，区别于月末，也区别于信号翻面。不借$+5.15\%$充当"给O17加上带子"的效果。不同的页面，不同的跨度，规格说明的其余部分也不同。

:::application 平静的一月
取带内路径：权重$0.545455$，目标$0.50$，旗标未变。每个月末都再平衡的研究者，交易账簿约$0.045$（单边），并为这笔交易支付成本。用十点带的研究者什么都不交易。只在信号变化时交易的研究者也什么都不交易。若下个月两个资产的收益率完全相同，[[#cor-nodrift]]说权重不会因那个月再移动分毫。在日历账簿里，成本付在了返回一个只被相对收益率轻轻扰动过的目标上。这笔成本值不值得付，是信号衰减的性质，也是成本的性质，而不是"轮动"这个词的性质。
:::

:::remark 不留意中奖者的目标
一份固定名单的等权账簿，无论去年谁赢，目标都相同。漂移照样发生，日历照样把它交易回去，但只要所持有的名单不是排序的函数，针对排序的信号变化规则就永远不触发。在本课的意义上，轮动指的是目标本身依赖动量信号。O17的目标就是这样。一个固定等权组合的每月再平衡，只是把第一条政策施加在一个并非由动量选出的目标上。
:::

:::history
贾加迪什与蒂特曼的1993年设计，无论后来的作者们是否把它描述成一条再平衡政策，其中已经含有一个日历。他们每个月启动一个队列、持有$K$个月，并把活着的队列取平均。那是把一个月度形成日历，粘在一个数月长的持有窗口上，也就是[[momentum/formation-skip-and-dual]]的重叠子组合构造。选$K$，以及选择每月形成而不是只在排名变化时形成，是研究设计的一部分。那不是他们漏写的一条券商惯例。W04所用那种季末双动量排序，是同一个大家族里较晚的一个规格说明，带着另一个时钟。两种情形里，时钟都是结果的一部分。
:::

## 通往何处

一条让赢家减输家账簿待在目标上的日历，同时也让它对那本账簿摔得很惨的那些时段保持敞口。那些时段在[[momentum/momentum-crashes]]。W12只演示了一下的带子代数，在[[portfolio/drift-turnover-and-breakers]]。O17实际交易的订单模式，在[[backtesting/weights-versus-orders]]里与权重模式分开；O18里的移动平均翻面，则留在[[trend/moving-averages]]。

:::summary
- 若权重加总到一且没有现金流，一个名字的权重漂到$w_i G_i$除以组合的毛增长。相同的毛收益率不移动权重。
- 一个以权重$1/2$起步的名字（另一名字毛收益率为$1$），自身毛收益率为$31/19$时落在权重$0.62$。漂移是$0.12$。毛收益率为$1.20$时落在权重$6/11$，漂移是$1/22$。
- 日历在那一天把账簿交易回目标。信号变化规则只在旗标翻面时交易。十点绝对带只在某个名字移动超过$0.10$时交易。在通往$0.62$的路径上带子交易；在通往$6/11$的路径上不交易。日历在两条路径上都交易。旗标安静时，信号变化哪条都不交易。
- 单边换手是绝对权重变动之和的一半。把$(0.62,\ 0.38)$重置回$(0.50,\ 0.50)$的单边换手是$0.12$。三名字翻面到$(0,\ 0.5,\ 0.5)$的单边换手是$0.62$。
- O17是订单模式里的月度动量轮动：已报告年化复合增长率$+8.62\%$，已报告夏普比率$0.53$，最大回撤$-28.2\%$，跨度$19$年。O18是一条SMA翻面规则，没有日历，信号不同，跨度也不同。W12是一条$10\%$漂移带，它的代数住在组合课程里。不要把两者的年化复合增长率相减，再把差称为日历效应。本图谱没有重跑那些页面。
:::

## 练习

:::exercise 毛收益率为$31/19$时漂移后的权重 {level=1 check="0.62"}
两个资产以权重$1/2$与$1/2$起步。第一个的毛收益率为$31/19$，第二个的毛收益率为$1$。第一个资产漂移后的权重是多少？（输入一个小数。）
:::solution
由[[#prop-drift]]，$w' = (31/19) / (31/19 + 1) = 31/50 = 0.62$。
:::
:::

:::exercise 漂移本身 {level=1 check="0.12"}
上一题里目标仍是$1/2$，因为你没有重新计算信号。第一个资产的漂移是多少？（输入一个小数。）
:::solution
$0.62 - 0.50 = 0.12$。第二个资产的漂移是$-0.12$，因为两个漂移后的权重仍然加总到一。
:::
:::

:::exercise 共同的毛收益率 {level=1 check="0.5"}
两个资产的毛收益率都是$1.10$，第一个以权重$0.50$起步。它的漂移后权重是多少？（输入一个小数。）
:::solution
[[#cor-nodrift]]给出$w' = 0.50$。分子是$0.50 \times 1.10$，分母是$1.10$，因子相消。答案是$0.5$。
:::
:::

:::exercise 两成上涨之后的漂移 {level=2 check="0.045455"}
第一个资产的毛收益率为$1.20$，第二个的为$1$，两者都以权重$1/2$起步。第一个资产相对$1/2$的漂移是多少，保留六位小数？（输入六位小数的数。）
:::solution
新权重是$1.20 / 2.20 = 6/11 = 0.5454545\ldots$，舍入为$0.545455$。漂移是$6/11 - 1/2 = 1/22 = 0.0454545\ldots$，舍入为$0.045455$。$0.10$的带子没有被突破。
:::
:::

:::exercise 带子沉默时的换手 {level=2 check="0"}
用上一题的漂移。信号旗标未变，所以目标仍是$1/2$。政策是[[#def-policies]]里的十点带。单边换手是多少？（输入一个小数。）
:::solution
绝对漂移约为$0.045$，不大于$0.10$。带子不交易。换手为$0$。同一条路径上，一个月末日历的单边换手是$1/22$，约$0.045455$。两种政策差的恰好就是这笔交易。
:::
:::

:::exercise 三名字翻面的换手 {level=2 check="0.62"}
漂移后权重为$(0.62,\ 0.38,\ 0)$，新目标为$(0,\ 0.5,\ 0.5)$。单边换手是多少？（输入一个小数。）
:::solution
绝对变动：$|0 - 0.62| = 0.62$、$|0.5 - 0.38| = 0.12$、$|0.5 - 0| = 0.50$。和为$1.24$。它的一半是$0.62$。
:::
:::

:::exercise 正好落在带子边缘的毛收益率 {level=3 check="1.5"}
一个名字以权重$1/2$起步，另一个名字的毛收益率为$1$。哪个毛收益率$G$把漂移后的权重正好放在$0.60$——围绕$0.50$的十点带的边缘——上？（输入一个小数。）
:::hint
用$w' = G/(G+1)$。令它等于$0.60$，解出$G$。本课的带子只在距离严格大于$0.10$时交易，所以边缘本身还不算一次交易。问你要的是边缘，不是边缘之外的一个点。
:::
:::solution
解$G/(G+1) = 0.60$。则$G = 0.60\, G + 0.60$，于是$0.40\, G = 0.60$，$G = 0.60/0.40 = 1.5$。简单收益率为$+0.50$时，漂移后的权重恰为$0.60$。[[#ex-062]]的路径，简单收益率$12/19 \approx 0.63$，已经越过这个边缘，这就是那条带子会交易的原因。毛收益率为$1.20$的那条路径没有越过。
:::
:::

:::exercise 两个名字都动 {level=3 check="0.666667"}
两个资产以权重$1/2$各自起步。毛收益率为$1.8$与$0.9$。第一个资产的漂移后权重是多少，保留六位小数？（输入六位小数的数。）
:::hint
分母是$(1/2)(1.8) + (1/2)(0.9)$，不是$1$。用第一个头寸的结束价值除以那个和。两个毛收益率不相等，所以那条让权重纹丝不动的推论并不适用。
:::
:::solution
分子：$(1/2) \times 1.8 = 0.9$。分母：$0.9 + 0.45 = 1.35$。新权重是$0.9 / 1.35 = 2/3 = 0.666666\ldots$，六位小数为$0.666667$。漂移是$2/3 - 1/2 = 1/6 \approx 0.166667$，大于$0.10$，所以十点带交易。回到$1/2$的单边换手也是$1/6$，因为$2 \times (1/6)$的一半等于$1/6$。
:::
:::
