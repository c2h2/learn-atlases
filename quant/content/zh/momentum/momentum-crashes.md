一条平均可以温和，而一条路径并不温和。动量研究有这个差距的一个特殊版本。赢家减输家组合有跌得很惨的区段，常常是在一个一直在下跌的市场猛然回弹、而一直在输的名字正是上涨的那些名字的时候。丹尼尔（Daniel）与莫斯科维茨（Moskowitz）2016年在Journal of Financial Economics上记录了那些事件，以及它们赋予支付的类期权形状。历史平均溢价与条件左尾，都是关于他们所研究的样本的事实。两个事实互相抵消不了，两个事实也都不是指令。

那篇论文还估计了一个条件均值与一个条件方差，并研究了一个随它们变化的权重。那个估计不在这里推导。一段关于崩盘何时成过簇的描述——在下跌之后、在波动率高涨的时候、以及在反弹进行之中——不是一台择时器，也不是本图谱建议任何人持有的一笔对冲。本课停在亏损的形状上：一个为正的均值如何能安坐在一个为负的复合收益率之上，以及一场昨天的输家领涨的反弹如何使赢家减输家恒等式为负，尽管两侧都在上涨。

## 同一条路径的两个摘要

:::definition 算术平均与复合收益率 {#def-two-summaries}
对简单收益率$R_1, \ldots, R_T$，每一个都大于$-1$，**算术平均**是$\bar R = T^{-1} \sum_{t=1}^{T} R_t$。**复合收益率**是$\prod_{t=1}^{T}(1 + R_t) - 1$。净值指数从$1$起步，终结于$\prod (1+R_t)$。**最大回撤**是那个指数最负的峰谷变动，一个小于或等于零的分数。
:::

业绩课程会恰当地分离这些对象，包括对数，以及一条不是动量账簿的路径的回撤。崩盘的算术开始之前需要两个事实。第一，$\sum \ln(1+R_t) = \ln\bigl(\prod(1+R_t)\bigr)$，所以诸对数收益率之和的符号就是复合增长的符号。第二，当$R$小时$\ln(1+R) \approx R - R^2/2$，而二次项永远是一种拖累。一次大幅下跌，在复合之中，不会被一次算术幅度相同的上涨抵消。下面两期的例子幅度足够大，近似只是一个指引，精确的乘积才是结果。

:::proposition 均值为正，复合收益率为负 {#prop-mean-compound}
设$R_1 > -1$且$R_2 > -1$。算术平均严格为正且两期复合收益率严格为负，当且仅当
$$
R_1 + R_2 > 0 \qquad \text{且} \qquad R_1 R_2 < -(R_1 + R_2).
$$
任何这样的一对都符号相反。
:::

:::proof
均值恰在$R_1 + R_2 > 0$时为正。复合收益率恰在$(1+R_1)(1+R_2) < 1$时为负。把乘积展开给出$1 + R_1 + R_2 + R_1 R_2 < 1$，于是$R_1 R_2 < -(R_1 + R_2)$。两个不等式合起来就是论断。

若乘积$R_1 R_2$为正或为零，它就不可能严格小于$-(R_1+R_2)$，因为只要和严格为正，那个量就严格为负。所以一个收益率为正，另一个为负。负的那一个，幅度大到足以击穿复合，却不够大到击穿和。对一笔幅度为$a \in (0,1)$的亏损与一笔$b > 0$的盈利，两个不等式变成$a < b < a/(1-a)$。只要$a > 0$，上界就超过$a$，所以区间非空。
:::

:::corollary 第二步就是回撤 {#cor-dd}
设净值只在$0$、第一期期末与第二期期末三个地方盯市，且$R_1 > 0$、$R_2 < 0$。这三个标记的最大回撤是$R_2$。
:::

:::proof
那些标记是$1$、$1+R_1$与$(1+R_1)(1+R_2)$。因为$R_1 > 0$，中间的标记严格在第一个之上，所以第一步之后的历史峰值是$1+R_1$。最后一个标记除以那个峰值是$1+R_2$，而$1+R_2 - 1 = R_2 < 0$。不存在更早的谷，因为路径从$1$升到了$1+R_1$。最负的峰谷变动因此是$R_2$。特别地，回撤等于崩盘那一步，不等于两期复合收益率，也不等于算术平均。
:::

:::example 先涨一半，再跌五分之二 {#ex-two}
一个动量账簿两期的简单收益率为$+0.50$，随后$-0.40$。计算算术平均、简单收益率之和、复合收益率、对数收益率之和（保留六位小数），以及净值标记$1$、$1.5$与$0.9$的最大回撤。
:::solution
均值是$(0.50 + (-0.40))/2 = 0.05$。简单收益率之和是$0.10$。把简单收益率相加的人会报告一笔盈利。

复合收益率是$1.50 \times 0.60 - 1 = 0.90 - 1 = -0.10$。净值标记恰为$1$、$1.5$与$0.9$。这本账簿在两期里跌了十分之一，而两个简单收益率的均值是正的。这一对坐在[[#prop-mean-compound]]之内：和$0.10$为正，而乘积$(0.50)(-0.40) = -0.20$小于$-0.10$。

对数收益率是$\ln 1.5 = 0.405465$与$\ln 0.6 = -0.510826$，六位小数，其和为$\ln 0.9 = -0.105361$。二次近似$R - R^2/2$给出$0.50 - 0.125 = 0.375$与$-0.40 - 0.08 = -0.48$，二者相加得$-0.105$。近似很近，但它不是结果。结果是那个乘积。

按[[#cor-dd]]，最大回撤是第二个收益率，$-0.40$。$0.10$的复合亏损藏着一场$40\%$的峰谷跌幅。报告均值$0.05$，或和$0.10$，把两样都藏了起来。
:::
:::

证明里的那个区间很容易被错过，所以值得再看一眼这些特定的数字。亏损是$a = 0.40$。盈利必须严格坐在$0.40$与$0.40/0.60 = 2/3 \approx 0.6667$之间。盈利$0.50$在那个区间之内。一笔$0.70$的盈利本会让和更大、让复合为正：$1.70 \times 0.60 - 1 = 0.02$。一笔$0.30$的盈利本会让均值为负。"先涨，然后跌得少一点"自动给不出为正的复合，而"涨得比跌多"也自动给不出为正的均值。两个门槛是不同的。

:::example 一笔小到翻不动复合的亏损 {#ex-noclash}
简单收益率为$+0.20$，随后$-0.10$。计算均值与复合收益率。这一对满足[[#prop-mean-compound]]里的两个不等式吗？
:::solution
均值是$(0.20 - 0.10)/2 = 0.05 > 0$。复合收益率是$1.20 \times 0.90 - 1 = 0.08 > 0$。净值走$1 \to 1.20 \to 1.08$。诸收益率的乘积是$(0.20)(-0.10) = -0.02$，而$-(0.20 - 0.10) = -0.10$。因为$-0.02$不严格小于$-0.10$，第二个不等式不成立，复合收益率保持为正。[[#prop-mean-compound]]里的那种冲突要求符号相反，但符号相反并不充分。按[[#cor-dd]]，三个标记的回撤是$-0.10$，比$-0.40$的崩盘那一步温和，而且与那次崩盘不同，它把期末财富留在了起点之上。
:::
:::

:::example 四笔安静的盈利与一次崩盘 {#ex-five}
五个简单收益率为$+0.12$、$+0.12$、$+0.12$、$+0.12$与$-0.40$。计算算术平均与复合收益率，保留六位小数。在每一步给净值盯市，并说出最大回撤。
:::solution
和是$4 \times 0.12 - 0.40 = 0.08$，所以均值是$0.08/5 = 0.016$。

净值从$1$起步，连乘四次$1.12$，再乘$0.60$：
$$
1,\quad 1.12,\quad 1.2544,\quad 1.404928,\quad 1.57351936,\quad 0.944111616.
$$
六位小数下，峰值是$1.573519$，终值是$0.944112$。复合收益率是$0.944111616 - 1 = -0.055888$，六位小数。均值仍然是正的。

历史峰值是第五个标记。最后一步把它乘以$0.60$，所以那一步的回撤是$-0.40$，而更早的步子没有下跌过。最大回撤是$-0.40$。一句只说"平均收益率是每步$+1.6\%$"的话，没有描述过这条路径。同样的警告，针对一个一般的股票指数而非一个动量玩具，正是[[performance/volatility-and-drawdown]]的要点：一个波动率数字同样点不出那个谷的名字。这里被拒绝描述的对象是均值。
:::
:::

## 当昨天的输家领涨

回想[[momentum/two-kinds-of-momentum]]里的那个恒等式。对等权赢家减输家映射，账簿下一期的简单收益率是赢家的平均简单收益率减去输家的平均。账簿的符号就是那个差距的符号。恒等式里没有任何东西要求赢家下跌。

丹尼尔与莫斯科维茨把那个坏差距安放在一个特定的地方。在他们的讲述里，崩盘与恐慌状态排在一起：它们紧随市场下跌，它们在市场波动率高的时候到来，它们与市场反弹同时发生。他们强调的机制是一个条件beta。在他们的美国样本里，大幅下跌之后，过去输家十分位组合的beta急剧上升——他们报告了可以超过$3$的数字——而过去赢家十分位组合的beta下降，数字低于二分之一。一场快速反弹随后把空头一侧抬升得比多头一侧更多。这本账簿对它不曾要求的一场反弹，持有一笔很大的负敞口。那些beta是他们样本里的一个发现，报告在这里是为了让算术有一个理由。它们不是拿到活市场上去的门槛，而本课不估计任何beta。

那个模式在历史上的极端程度，是论文自己叙事的一部分，不是玩具。在他们1927–2013年的美国股票样本里，一本做多过去十二个月赢家的顶部十分位组合、做空底部十分位组合的账簿，最差的两个月是连续的：1932年7月与8月。在那段短的窗口里，过去输家十分位组合的收益率为$232\%$，而过去赢家十分位组合上涨了$32\%$。本图谱没有重算过那些月份。那些数字是他们的。它们足够让人看见那个恒等式在工作：两侧都在上涨，而动量账簿做空的那一侧涨得多得多。缩放后的多空在那两个月亏了多少，取决于融资，也取决于本课不会重造的权重。十分位组合之间的差距本身已经是事实。

:::example 一场两侧都享受的反弹 {#ex-rebound}
三个过去赢家在反弹那个月的简单收益率为$+0.05$、$+0.02$与$0.00$。三个过去输家为$+0.40$、$+0.35$与$+0.30$。这本账簿是取$K = 3$的等权赢家减输家映射，所以它的收益率是两个平均之差。计算该收益率，保留六位小数。有没有哪个赢家的收益率为负？
:::solution
赢家的平均是$(0.05 + 0.02 + 0.00)/3 = 0.07/3 = 0.023333\ldots$。输家的平均是$(0.40 + 0.35 + 0.30)/3 = 1.05/3 = 0.35$。账簿返回
$$
0.07/3 - 0.35 = -0.98/3 = -0.326666\ldots,
$$
六位小数为$-0.326667$。每个赢家收益率都非负。每个输家收益率都为正且很大。在多头一侧合计到$+1$、空头一侧合计到$-1$的约定下，这本多空账簿在一期里亏掉大约三分之一的资本。一个只做多、持有赢家的投资者本会有一笔小赚。这里的崩盘不是"赢家跌了"。它是"空头一侧涨得更多"。那就是1932年的形状，缩放到编造的数字上，好让算术看得见。它不是1932年的复原，也不是说下一场反弹会像这两个之中的任何一个。
:::
:::

把两个例子并排放，报告的诱惑就一目了然。一段几乎全是安静盈利的样本，比如四步$+0.12$，有一个令人愉快的均值。一场[[#ex-rebound]]那样的反弹，或者一步$-0.40$，就会把复合翻面，并支配回撤。一个取了几十年的平均溢价，在一篇论文里可以为正，同时仍是一条带着几个难以承受的月份的路径的平均。丹尼尔与莫斯科维茨的要点，用课程记录所用的话说，是那些崩盘构成了动量的类期权支付的很大一部分：账簿之所以像期权空头的那一侧，是因为左尾正是那形状的一大块住的地方。本图谱没有重新估计过那个分解。两期玩具是同一种张力的最小精确版本。均值是$+0.05$，复合收益率是$-0.10$。

:::warning 一簇不是择时器
在论文的样本里，那些事件在下跌之后与动荡的反弹之中成簇。那是关于那些样本的一句话。它不是一条"市场跌过之后，就改变头寸"这种形式的规则。那个形式的规则是一条新策略：又一个信号、又一次搜索、又一笔成本、又一种迟到的方式。作者们研究过一个这样的权重。在这里教它，会把一个关于崩盘的事实变成一个择时产品，而这恰恰是本章不迈的那一步。同一种拒绝反方向也成立。左尾不是把历史平均扔掉的理由，而平均也不是把那个尾说得好像是个意外的理由。W15，在[[momentum/two-kinds-of-momentum]]里，已经展示过一页平淡的横截面，最大回撤$-25.4\%$。那一页不是这篇论文的样本。它是一个提醒：一条温和的年化复合增长率与一个很深的谷可以共用一行。
:::

:::intuition 做空那些受伤的名字，然后眼看它们恢复
赢家减输家账簿做多那些扛住了的名字，做空那些受伤的名字。如果受伤的名字正是高beta的名字，一场反弹就会付钱给你做空的那些人。看见这笔亏损不需要一个新公式。你需要那个恒等式：组合收益率等于赢家平均减去输家平均。当第二个平均是大的那一个，账簿的收益率为负，而一个头条指数为正。把那个月叫作"市场涨了，所以动量赚了"，看的是错的那一列。
:::

:::quiz
哪一对的算术平均为正而复合收益率为负？
- [ ] $+0.20$，随后$-0.10$
- [x] $+0.50$，随后$-0.40$
- [ ] $-0.50$，随后$+0.40$
- [ ] $+0.10$，随后$+0.10$
:::solution
第一对复合成$1.20 \times 0.90 - 1 = 0.08 > 0$，尽管均值为正。第二对就是[[#ex-two]]：均值$+0.05$，复合$-0.10$。第三对的和为负，所以均值为负。第四对在两个摘要上都是正的。那种冲突要求符号相反，但符号相反并不充分。
:::
:::

:::quiz
在[[#ex-rebound]]里，哪个描述是对的？
- [ ] 赢家跌了，所以是多头一侧造成了亏损
- [ ] 账簿的收益率等于输家的平均，因为赢家平均而言不涨不跌
- [x] 两侧都在上涨，而账簿亏了，因为输家涨得更多
- [ ] 当每个名字的收益率都为正时，一本零和账簿不可能亏钱
:::solution
赢家的平均约为$0.023$，输家的平均为$0.35$。差约为$-0.327$。每个名字的收益率都非负。[[momentum/two-kinds-of-momentum]]里的共同平移推论说，一个*共同的*正收益率本来会被消掉。这些收益率并不共同。空头一侧涨得比多头一侧多，而那个差距就是亏损。
:::
:::

:::application 只有一句话的空间时，该报告什么
假设从[[#ex-two]]里你被允许带走的唯一数字，是单独一个摘要。均值说$+0.05$。复合收益率说$-0.10$。回撤说$-0.40$。这些不是一个量的三个估计。一份报告长窗口平均收益率、却略去最坏峰谷跌幅的规格说明，做的正是那条命题所警告的选择。本课程引用的那些库内行，正因为如此才同时印着年化复合增长率与最大回撤。只用那个温和的单元格，是一个阅读错误，不是那一页的一个特性。
:::

:::history
丹尼尔与莫斯科维茨2016年在Journal of Financial Economics上发表了 *Momentum crashes* 一文。他们展示了赢家减输家策略有不频繁的、持续的连串亏损，集中于市场下跌之后的动荡反弹之中，而这个左尾是类期权支付的很大一部分。他们美国样本里1932年7月与8月的事件——输家十分位组合上涨$232\%$、赢家十分位组合上涨$32\%$——正是他们用来把那个形状讲具体的那个极端。论文走得更远，用对均值与方差的预测构造了一个动态权重。本课使用那个事件与那个算术。它不使用那个权重。
:::

## 通往何处

同样那句赢家减输家的话可以被读在货币对上，在这个开放库里，好几页已发表的结果在它们报告的窗口上为负。那就是[[momentum/momentum-across-assets]]，而一页为负仍然不是一条择时规则。对数、以及把简单收益率相加之禁，在[[performance/simple-and-log-returns]]。回撤作为一个波动率决定不了的对象，在[[performance/volatility-and-drawdown]]。把那场反弹变成亏损的那个恒等式，在[[momentum/two-kinds-of-momentum]]。

:::summary
- 算术平均与复合收益率回答不同的问题。对两个简单收益率，均值与复合收益率一正一负，恰在和为正、而两个收益率的乘积小于那个和的相反数的时候。那时两个收益率符号相反。
- 那对$+0.50$、$-0.40$：均值$+0.05$，简单收益率之和$+0.10$，复合收益率$-0.10$，最大回撤$-0.40$。把简单收益率相加会藏起亏损。回撤等于崩盘那一步，不等于两期的复合。
- 四笔$+0.12$的盈利与一笔$-0.40$的亏损：均值$+0.016$，复合收益率$-0.055888$。最大回撤又是$-0.40$。
- 在赢家减输家恒等式之下，一场输家比赢家涨得更多的反弹就是账簿的一笔亏损，即使每个赢家都在涨。编造的那场反弹返回$-0.326667$。丹尼尔与莫斯科维茨的1932年十分位组合差距，在迥然不同的尺度上是同一个形状。
- 崩盘在下跌之后成簇，是关于那篇论文里那些样本的一个事实。它不是一条头寸规模规则。他们的动态权重是一个进一步的实验，本课不教它。

## 练习

:::exercise 两步崩盘的均值 {level=1 check="0.05"}
简单收益率为$+0.50$与$-0.40$。算术平均是多少？（输入一个小数。）
:::solution
$(0.50 - 0.40)/2 = 0.05$。为正的均值决定不了复合收益率。
:::
:::

:::exercise 同一对的复合收益率 {level=1 check="-0.10"}
对同样这两个收益率，复合收益率是多少？（输入一个小数，两位。）
:::solution
$1.50 \times 0.60 - 1 = 0.90 - 1 = -0.10$。若从$1$起步，净值终结于$0.90$。
:::
:::

:::exercise 两步路径的回撤 {level=1 check="-0.40"}
净值在$1$、然后$1.5$、然后$0.9$处盯市。最大回撤是多少？（输入一个小数，两位。）
:::solution
峰值是$1.5$。较晚的标记是$0.9$。变动是$0.9/1.5 - 1 = 0.6 - 1 = -0.40$。[[#cor-dd]]给出的数字与第二个简单收益率相同，因为那个收益率为负而第一个为正。
:::
:::

:::exercise 不冲突的一对 {level=2 check="0.08"}
简单收益率为$+0.20$，随后$-0.10$。复合收益率是多少？（输入一个小数。）
:::solution
$1.20 \times 0.90 - 1 = 1.08 - 1 = 0.08$。均值是$(0.20-0.10)/2 = 0.05 > 0$，复合收益率也是正的。核对[[#prop-mean-compound]]里的乘积检验：$(0.20)(-0.10) = -0.02$，而$-(0.20-0.10) = -0.10$。因为$-0.02$不小于$-0.10$，复合收益率不会转负。符号相反还不够。
:::
:::

:::exercise 赢家在涨，输家涨得更多 {level=2 check="-0.18"}
反弹那个月，赢家的平均简单收益率为$0.04$。输家的平均为$0.22$。账簿是等权赢家减输家映射。它的简单收益率是多少？（输入一个小数。）
:::solution
恒等式给出$0.04 - 0.22 = -0.18$。两个平均都是正的。账簿跌了十八个百分点，因为它做空的是涨得更多的那个平均。
:::
:::

:::exercise 四笔$12\%$盈利之后的峰值 {level=2 check="1.573519"}
净值从$1$起步，连乘四次$1.12$，其间没有别的盯市标记。那四步之后的净值是多少，保留六位小数？（输入六位小数的数。）
:::solution
$1.12^2 = 1.2544$。再乘$1.12$是$1.404928$。再乘一次$1.12$是$1.57351936$，六位小数为$1.573519$。第五步$-0.40$本会把这个峰值整整拉低$40\%$，并让全部五步上的复合收益率为负，如同[[#ex-five]]。峰值本身六位小数仍是$1.573519$。
:::
:::

:::exercise 复合收益率为零的边界 {level=3 check="-0.166667"}
第一个简单收益率为$+0.20$。找出使两期复合收益率恰为零的第二个简单收益率$R_2$。（输入该值，保留六位小数。）
:::hint
令$(1.20)(1+R_2) = 1$并求解。之后核对：这个边界处的算术平均仍然为正，所以该边界是[[#prop-mean-compound]]中那个区域的边缘，而不是一个已经在负均值区域内部的点。命题里的那个严格不等式，就是这个边界的开口一侧。
:::
:::solution
$1 + R_2 = 1/1.20 = 5/6$，所以$R_2 = 5/6 - 1 = -1/6 = -0.166666\ldots$，六位小数为$-0.166667$。和是$0.20 - 1/6 = 0.033333\ldots > 0$，所以均值为正。乘积$(1.20)(5/6) = 1$，所以复合收益率为零，尚未为负。任何严格介于$-0.20$与$-1/6$之间的$R_2$，都有为正的均值与为负的复合收益率。在$R_2 = -0.20$处，均值为零。
:::
:::

:::exercise 和误导到什么程度 {level=3 check="0.20"}
对收益率$+0.50$与$-0.40$，从简单收益率之和中减去复合收益率。你得到什么？（输入一个小数。）
:::hint
简单收益率之和是$0.10$。复合收益率为负。减去一个负数会拉大差距。业绩那章的警告是：和不是一个财富比率。
:::
:::solution
和是$0.50 - 0.40 = 0.10$。复合收益率是$-0.10$。差是$0.10 - (-0.10) = 0.20$。报告那个和，等于宣称一笔十分之一的盈利。净值指数跟着复合走，宣称的是一笔十分之一的亏损。在一条只有两步的路径上，两种说法相差$0.20$。对数之和$-0.105361$（六位小数）站在复合那一边，不站在算术和那一边。
:::
:::
