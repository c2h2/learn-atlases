规格说明一旦冻结，后来的K线就不是编辑它的许可。它们是写下的时候没有看到的一个样本。一份纸面记录把冻结的规则应用到那些K线上，存下的是一个假想的净值路径。没有任何订单被发往市场。这份记录能逮到一条不再与规格说明相符的数据流、一条在代码底下变了的拆股规则，或一个窗口或时钟已经漂移了的信号。它逮不到未来。记录与一次重新计算相符，说的是实现在手头的K线上遵循了规格说明。它不是说规格说明会持续产出它在研究里产出的那份财富。

本章的玩具是[[research-craft/writing-a-specification]]里示例账簿A的冻结形式，对准的是一条新的、不是路径A的五个收盘价的路径。这套算术的要点，是一个错误制造的分歧，不是对较大倍数的偏好。

## 存的是什么

:::definition 纸面记录 {#def-paper}
一份冻结规格说明的**纸面记录**，是在该规格说明的字段被固定之后才到来的K线上算出的一条假想财富路径。它至少存下：时钟允许使用的输入、公式返回的信号、映射本来会产出的权重或订单*类型*、成本模型所收的费用，以及随之而来的财富倍数。它什么都不发往市场，不开立账户，也不会因为持续了很多天就变成一笔实盘订单。一次**匹配**，是按规格说明的算术，在存下的财富与从同样冻结的字段、同样的K线出发的一次独立重新计算之间，所成立的相等。一次**不匹配**就是它的反面。
:::

"类型"上的斜体是刻意的。记录可以说"映射的权重是$1$"，也可以说"规格说明的订单类型本来会是一张带这个限价的市价单"。它两者都不传输。描述一个订单类型——好让一个订单类型上的不匹配检测得出来——仍然留在研究之内。把记录连到一个经纪商是另一个项目，本章不描述它。

第一版全球投资业绩标准（Global Investment Performance Standards，GIPS），由现在的CFA协会在1999年发布，把一份被展示的业绩记录当作一件需要写下方法的东西来对待。值得借的就是那份直觉。一份纸面记录不是一份GIPS业绩记录。GIPS作为一个合规制度，管的是真实被管理过的组合（composite），带着本章不教、也没有资格适用的那些规则。下面这条纸面路径没有被管理过。叫它一份业绩记录，就是从一个要求纸面路径所没有的一个投资组合的制度那里，偷一个词。

:::proposition 一次匹配能裁决什么 {#prop-match}
假设规格说明完整到可以重新计算，纸面记录与重新计算使用同样的K线，而算术是规格说明的算术。如果存下的财富$N$与重新算出的财富$M$满足$N \neq M$，那么"这份记录在这些K线上实现了该规格说明"这个主张为假。如果$N = M$，那个主张对这些K线为真。无论哪种情形，关于最后一个K线之后的收益率的论断都不得到裁决：这样一个收益率不是数对$(N, M)$的函数。
:::

:::proof
按假设限定的那个实现主张，就是等式$N = M$。它的真值就是那个等式的真值，所以一次不匹配推翻它，一次匹配在这些K线上证实它。设$R_{\star}$是尚未到来的后一段区间上的一个简单收益率。$R_{\star}$不被$N$与$M$决定。任何其真假依赖$R_{\star}$取值的句子——它将为正、它将重复一个研究均值、财富倍数将保持在$1$之上——都可以在$(N, M)$保持固定的情况下为真或为假。因此观察这个数对裁决不了那句话。
:::

这条命题是刻意狭窄的。一次匹配并不表明成本模型是现实的，只表明记录使用了那个被写下的成本模型。如果冻结的成本是零，一份匹配的记录确认的就是一个零成本。它没有测量一个规格说明忘了写的价差。监控发现的是与规格说明的分歧。它不会悄悄升级规格说明。在看到一条难受的纸面路径之后加上一个价差，又不把这次添加写成一份新的规格说明，就是上一章那个空白字段的失误，往后挪了一步。

:::warning 纸面路径不是券商路径
失误是把一份长期匹配的记录当作"同样的订单本来会成交"的证据。成交取决于一本订单簿、一个队列与一张费用表，纸面记录并不包含它们，除非规格说明把它们建了进去。示例账簿A不包含它们。一次匹配确认的是存下的K线上权重与成本的算术。它不确认一次执行。本章没有任何东西是取得一次执行的手续。
:::

## 一条冻结的规则跑五个新的收盘价

监控周是编造的：收盘价$30$、$33$、$32$、$36$、$34$。它不是研究样本所迫出的延续，也不是路径A。规格说明带着一个自成一体的预热来应用：在三个收盘价存在之前，$\mathrm{SMA}_3$无定义，信号是$0$。其他字段与示例账簿A保持一致。合法时钟挣下一个收益率。平局是严格的。按比例的成本是$c = 0.001$，在下一个收益率之前按权重变动的绝对值收取，期末不清仓。现金挣$0$。没有任何订单离开这一页。

四段步上的简单收益率是$33/30 - 1 = 0.10$、$32/33 - 1 = -1/33$、$36/32 - 1 = 0.125$与$34/36 - 1 = -1/18$。三点均值在有定义之后，在收盘价$32$处是$(30+33+32)/3 = 95/3$，在收盘价$36$处是$(33+32+36)/3 = 101/3$，在收盘价$34$处是$(32+36+34)/3 = 34$。那三个收盘价上的严格信号是$1$、$1$与$0$，因为$32 > 95/3$、$36 > 101/3$，且$34 = 34$。

:::example 规格说明实际推出的那份记录 {#ex-week}
计算冻结的合法规则在监控周上的毛与净复合简单收益率。
:::solution
五个收盘价上的信号是$(0,0,1,1,0)$。四个收益率上的合法权重是$(0,0,1,1)$：空仓，然后从$32$持多到$34$。毛倍数叠缩为，

$$
\frac{36}{32} \cdot \frac{34}{36} = \frac{34}{32} = 1.0625,
$$

所以毛复合收益率是$0.0625$。只有一次权重变动，从$0$到$1$。因为成本与财富成比例，净倍数是$0.999 \times 1.0625 = 1.0614375$，净复合收益率是$0.0614375$。两个数字都是假想的。它们没有被发往任何地方。在这些同样的收盘价、这份同样的规格说明之下存下另一个倍数的一份纸面记录，就是[[#prop-match]]意义下的一次不匹配。
:::
:::

:::example 错误的窗口 {#ex-bug}
代码用了$\mathrm{SMA}_2$而不是$\mathrm{SMA}_3$，其他都忠实：严格平局、合法时钟、$c = 0.001$、期末不清仓。计算毛复合收益率与净复合收益率。
:::solution
两点均值从第二个收盘价起是$31.5$、$32.5$、$34$与$35$。五个收盘价上的严格信号是$(0,1,0,1,0)$。四个收益率上的合法权重是$(0,1,0,1)$。毛倍数是

$$
\frac{32}{33} \cdot \frac{34}{36} = \frac{272}{297} = 0.9158249158\ldots,
$$

毛复合收益率是$-25/297 = -0.084175$，保留六位小数。权重变动三次：$0 \to 1$、$1 \to 0$、$0 \to 1$。按比例的费用在毛倍数之前贡献一个因子$(0.999)^3$，所以净倍数是$0.9130801876\ldots$，净复合收益率是$-0.086920$，保留六位小数。这不是那条冻结的规则。只要一份记录存着窗口-$3$的财富、代码却产出窗口-$2$的财富，或相反，[[#prop-match]]就说实现主张为假。两个数字里更讨人喜欢的那个不是补救。补救是让代码使用规格说明点名的那个窗口，或者冻结一份诚实地写着$\mathrm{SMA}_2$的新规格说明。
:::
:::

这个错误在未来没有任何视图的情况下就可检测。两条财富路径都是那五个收盘价的函数。这就是[[#prop-match]]有用的一半。没用的那一半，如果一个人指望过预言的话，是两条路径都不含第六个收盘价。

:::example 数据流忘记的一次拆股 {#ex-split}
规格说明说收盘价是拆股复权的。两个收盘价之间发生了一次2对1的拆股。复权后的收盘价是$50$再到$52$。原始数据流显示$50$再到$26$。规格说明推出哪个简单收益率，原始数据流推出哪个收益率，而一次不匹配裁决什么？
:::solution
规格说明的简单收益率是$52/50 - 1 = 0.04$。原始数据流的简单收益率是$26/50 - 1 = -0.48$。如果纸面记录把$-0.48$复合进去，而从冻结的复权规则出发的一次重新计算把$0.04$复合进去，那么$N \neq M$，实现主张为假。如果数据流被修正、两边都显示$0.04$，那次匹配就在这一步上确认了复权。它没有确认下一次拆股会被处理——处理下一次拆股，靠的是那一次拆股到来时再跑同一次检查——它也没有说$0.04$会不会是典型的。[[markets/adjustment-universes-and-rolls]]定义复权；纸面记录只检查被冻结的那个选择是不是文件里的那个。
:::
:::

:::example 同样五个收盘价上的一个时钟错误 {#ex-clockbug}
保留$\mathrm{SMA}_3$、严格平局与$c = 0$，但让$s_t$乘$R_t$。计算复合简单收益率，并与毛的合法数字$0.0625$比较。
:::solution
四个收益率上的同根K线权重，就是那些收益率终点上的信号：$(0,1,1,0)$。倍数是

$$
\frac{32}{33} \cdot \frac{36}{32} = \frac{36}{33} = \frac{12}{11} = 1.090909\ldots,
$$

复合收益率是$1/11 = 0.090909$，保留六位小数。合法的毛复合收益率是$0.0625$。这个差距是对冻结时钟的一次不匹配。这一周上同根K线的数字更大。[[#prop-match]]不偏爱它。一份悄悄切换到较大数字的监控日志，已经改动了规格说明，而且，除非搜索与时钟都被重写，它就篡改了记录，而不是拯救了记录。
:::
:::

:::quiz
一份纸面记录与重新计算在六十个新的交易日里相符。哪个结论是[[#prop-match]]所支持的？
- [ ] 下一个交易日的收益率将接近研究均值
- [ ] 成本模型已被证明包含了经纪商会收的每一笔费用
- [x] 在那六十个交易日上，存下的路径实现了冻结的规格说明，而下一个交易日仍未决定
- [ ] 因为方法被写下来了，这份匹配就是一份GIPS业绩记录
:::solution
一次匹配在进入了那个等式的K线上确认实现主张。下一个收益率不是那个等式的函数。写下的方法，是与1999年那份标准共享的直觉；它不会把一条假想路径变成一个被管理的组合。从来没有写进规格说明的费用，不会被一次针对该规格说明的匹配确认。
:::
:::

## 日志能被建成看见什么

[[#alg-recompute]]是一张清单，供[[#prop-match]]所使用的那个比较照章办事。它不是一份部署配方。每一步读或写的都是一个研究文件。

:::algorithm 重新计算并比较 {#alg-recompute}
给定一份冻结的规格说明与一批新的K线，做下面这些事，然后停下。

1. 记下这批数据的数据版本，包括数据流声称适用的那条公司行动规则。
2. 只使用时钟在每个$t$允许的信息，从公式、窗口与平局重新计算信号。
3. 施加权重映射或点名的订单类型。不要传输它。
4. 按规格说明陈述的顺序施加成本模型，包括写明的零。
5. 把得到的财富、信号与成本，同纸面记录存下的值做比较。
6. 如果它们不同，写下"不匹配"与不同的那个字段。不要用你偏好的路径替换存下的路径。
7. 如果它们相符，写下"本批相符"。不要写任何关于不在这一批里的K线的句子。
:::

一条坏掉的数据流常常在第2步或第5步上失败，而财富数字只是把这种失败摘要了一下。一个重复的收盘价、一个陈旧沿用的收盘价、或缺失的一个交易日，都会改动$\mathrm{SMA}_3$，并可能改动一个严格不等式。对的日志存下收盘价与信号，而不只存复合收益率。两个不同的错误可能碰巧共享一个财富倍数，就像宽松平局与同根K线时钟在路径A上共享过一个倍数一样。在规格说明点名了信号的地方，财富相等而信号不等，仍然是一次不匹配。

体制的话不会扩大这条命题。一个"看起来像"研究样本的星期与一个不像的星期，一到来了就都在$(N, M)$之内，一到未来之前就都在它之外。监控可以描述这个星期——规则在做多，复合收益率毛的$0.0625$，一笔再平衡被收费。描述不是一个择时信号。[[research-craft/combination-and-decay]]会把一个不断缩小的纸面结果当作一个观察来处理，而它仍然不说明进入或离开一个市场。

:::intuition 记录是一次在新输入上的单元测试
把规格说明当作一个函数，把纸面记录当作那个函数的第二个实现，在新输入出现时运行。单元测试逮的是实现之间的分歧。它们不证明函数的输出下一次会让任何人满意。满意从来就不是那个测试。
:::

:::remark 一个零成本确认什么
假设监控周带着冻结的$c = 0.001$被重新计算，而记录与$0.0614375$相符。那次匹配确认的是那笔收费。如果后来有人观察到，一个真实成交的价差本来会大于$0.001$，那个观察是对规格说明现实性的一条批评，不是[[#prop-match]]内部的一次不匹配。诚实的回应是一份带新的成本字段、明确标记的新规格说明，加一份新的记录。就地编辑旧记录，会毁掉"旧规格说明曾被实现"这件事的唯一证据。
:::

:::application 一次不带预测的数据流检查
拆股那个例子，对股息与移仓也是这个模式。规格说明点名一种复权。数据流要么适用它，要么不适用。纸面记录是分歧变成一个数字的地方——在这个玩具上是$0.04$对$-0.48$——而不是一丝怀疑。[[backtesting/timing-costs-and-biases]]给这些失效的研究版本编了目录。监控就是同一份目录朝时间的前方一指，仍然不带"下一个数字会匹配上一个"的论断。
:::

:::quiz
窗口-$2$的错误在监控周上亏钱，而冻结的窗口-$3$规则不亏。日志该说什么？
- [ ] 把规格说明换成窗口$2$，因为这个错误揭示了真实的窗口
- [ ] 仅仅因为赚了钱就把规格说明换成窗口$3$
- [x] 不匹配：代码的窗口不是冻结的那个窗口。保留规格说明，或者公开地替换它。不要按利润的符号来挑选
- [ ] 发出窗口-$3$的权重，因为它们与研究想法相符
:::solution
假想利润的符号，不是关于哪个窗口被冻结的证据。被冻结的窗口早已写下。一次不匹配推翻实现主张，此外什么都不做。发出权重会离开纸面记录的定义。
:::
:::

## 通向何处

若干条纸面路径，各自系在自己那份冻结的规格说明上，它们之间有一个协方差。[[research-craft/combination-and-decay]]做那笔算术，并把它和一笔为账簿注资的决策分开。[[research-craft/the-boundary]]是那条防止一份匹配记录被叙述成一个承诺的界线。[[backtesting/the-backtest-as-an-experiment]]是往前一步的同一个想法：一次回测本来就是一场实验，不是一个经纪商。

:::summary
- 一份纸面记录是在规格说明冻结之后算出的一条假想财富路径。它什么都不发往市场。
- 一次匹配确认记录在手头的K线上实现了规格说明。一次不匹配推翻那个主张。
- 两种结果都对最后一个K线之后的收益率一无所语，而一次匹配也不会升级一个被写成零或$0.001$的成本模型。
- 在编造的那一周$30,33,32,36,34$上，冻结的$\mathrm{SMA}_3$规则复合到毛的$0.0625$、净的$0.0614375$。
- $\mathrm{SMA}_2$的错误复合到毛的$-0.084175$，保留六位小数。这个差距是一次失败的实现，不是一个关于窗口的研究发现。
- 一次被忘记的2对1复权把$0.04$变成$-0.48$，是同一种失效，不用预测就看得见。
- 这一周上的同根K线时钟复合到$1/11$，它大于$0.0625$，却仍然是错误的时钟。
- 1999年的业绩标准供给了"记录需要一个写下方法"的直觉。它们没有把这条假想路径变成一份业绩记录。
:::

## 习题

:::exercise 这一周的毛复合收益率 {level=1 check="0.0625"}
输入冻结的$\mathrm{SMA}_3$规则在收盘价$30, 33, 32, 36, 34$上的毛复合简单收益率。
:::solution
合法权重只从$32$持多到$34$。倍数是$34/32 = 1.0625$，所以复合收益率是$0.0625$。这条路径是假想的，没有被发往任何地方。
:::
:::

:::exercise 漏掉一次拆股后的原始收益率 {level=1 check="-0.48"}
复权收盘价$50$再到$52$，在数据流里被替换成原始收盘价$50$再到$26$。输入原始数据流推出的简单收益率。
:::solution
$26/50 - 1 = -0.48$。规格说明的收益率是$0.04$。如果规格说明要求那次复权，这个差距就是一次不匹配。它不是下一个收盘价的预测。
:::

:::exercise 信号能做多之前需要的收盘价数 {level=1 check="3"}
在冻结的规则之下，$\mathrm{SMA}_3$有定义需要几个收盘价？（输入个数。）
:::solution
均值使用这个收盘价与前面两个收盘价，所以它在第三个收盘价上有定义。在那之前，按预热规则信号是$0$。个数是$3$。
:::
:::

:::exercise 那个错误的毛复合收益率 {level=2 check="-0.084175"}
输入监控周上$\mathrm{SMA}_2$合法错误的毛复合简单收益率，保留六位小数。
:::solution
权重$(0,1,0,1)$给出倍数$(32/33)\cdot(34/36) = 272/297$。复合收益率是$-25/297 = -0.084175084\ldots$，六位小数为$-0.084175$。如果代码唯一的过错是那个窗口，一个不匹配的记录存的就是这个数。
:::
:::

:::exercise 冻结这一周的净复合收益率 {level=2 check="0.0614375"}
输入监控周上$c = 0.001$的冻结规则的净复合简单收益率。
:::solution
一次按比例的入场把$1.0625$乘以$0.999$。净倍数是$1.0614375$，在这个十进制下复合收益率恰为$0.0614375$。对着点名$c = 0.001$的规格说明存下毛的$0.0625$的一份记录，已经是一次不匹配，尽管两个数字都为正。
:::
:::

:::exercise 这一周上的同根K线复合收益率 {level=2 check="0.090909"}
输入监控周上$c = 0$的同根K线$\mathrm{SMA}_3$计算的复合简单收益率，保留六位小数。
:::solution
倍数是$36/33 = 12/11$，而$12/11 - 1 = 1/11 = 0.09090909\ldots$，六位小数为$0.090909$。它超过合法的毛复合收益率$0.0625$。这个大小关系不是采用同根K线时钟的理由。冻结的时钟是合法的那个，而[[#prop-match]]打的是与被冻结之物的相符分。
:::
:::

:::exercise 一个来得太晚的收益率 {level=3}
这一周上的毛合法倍数是$1.0625$。假设在冻结的规则给定某些后来的收盘价、碰巧持多的那一段步上，出现了一个后来的简单收益率$-0.20$。计算那个额外步之后的财富倍数。这一周的纸面记录为什么本来不可能包含它？
:::hint
把$1.0625$乘以$1 + (-0.20)$。然后用[[#prop-match]]：那个额外的收益率不是这一周的$(N, M)$的函数。
:::
:::solution
$1.0625 \times 0.80 = 0.85$。那五个收盘价的纸面记录在毛的$1.0625$处结束。后来的那个收益率不是那个数字的一个输入，所以这一周上无论匹配还是不匹配，都裁决不了它。数字$0.85$说的是：如果那个后来的收益率到来了、而规则在持多，倍数会变成什么。它不是收益率将为$-0.20$的一个预测，也没有被存在这一周的记录里。
:::
:::

:::exercise 三笔收费 {level=3}
说明为什么$\mathrm{SMA}_2$错误的净倍数等于它的毛倍数乘以$(0.999)^3$，并输入保留六位小数的净复合收益率。
:::hint
列出三次权重变动。每一次在变动处把财富乘以$0.999$，而空仓那一步把财富乘以$1$。按比例的因子与毛收益率可交换。
:::
:::solution
四个收益率上的权重是$(0,1,0,1)$，从$0$起步。变动是一次入场、一次离场、再一次入场：三笔收费。毛倍数是$272/297$。空仓那一步贡献一个因子$1$，所以它不打乱那个乘积。净倍数是$(0.999)^3 \times 272/297 = 0.9130801876\ldots$。净复合收益率是$-0.086919812\ldots$，舍入为$-0.086920$。如果成本是一笔固定费用而不是财富的一个比例，那个因子就不会从乘积里这么干净地出来，而规格说明就得把这件事写明。
:::
