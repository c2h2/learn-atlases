本图谱有一条不越的线，而这条线是这门课的一部分。前面各章规定过一条规则、比较过两个实现而不给任何一个加冕、保存过一条什么都不发送的假想记录、用一个协方差合并过账簿结果。这些动作没有哪一个推荐一只证券、一个权重、一家经纪商或一档杠杆，没有一个提交实盘订单，也没有哪一个说quants.md上报告的一条曲线会再次发生。本章把这条线写下来，好让它能用作其余每一章的标准。解释一个机制——包括一张订单如何运作——留在线内。告诉读者把订单发出去则不然。

法律与监管取决于司法辖区。这里没有任何话陈述读者在其居住的地方可以合法地做什么。这不是法律建议。想要一套交易系统的读者必须离开本文本，去接受本文本不会承担的那些责任。

## 图谱不会做的事

这些拒绝是具体的。图谱不会推荐一只证券、一只基金、一类资产或一个策略。它不会推荐一个权重。它不会推荐一家经纪商。它不会推荐一档杠杆。它不会给出、也不会演示发送一笔实盘订单。它不会声称quants.md上的一条曲线、或这些课里画出的任何一次回测，会再次发生。已发表数字被引用，是为了让一个协议可以被阅读。它们不是预测，而库里的一笔亏损也不会被翻成站到对面去的建议。

图谱会解释机制。一张市价单、一张限价单、一张止损单、一个权重、一笔成本、一个时钟、走步验证的一折、一个被选定的窗口，都是读者应当能够识别的对象。识别包括识别一次同根K线回测、一笔缺失的成本、一场没有披露的搜索，以及一条仅仅用来图示一个已报告年化复合增长率的光滑曲线。[[markets/systematic-question]]从那种描述性的立场出发：一条规则是$t$时点可得信息的一个函数，而它挣的是$t$之后发生的事。这个立场，若少了那份"这个函数并不为之辩护的行为"的清单，是不完整的。

:::definition 建议句 {#def-advice}
在本图谱中，一句**建议句**至少做下面的一件事：它点名一只证券、一只基金、一类资产或一个策略，说读者应当买入、卖出或持有它；它说出一个读者应当使用的权重；它点名一家读者应当使用的经纪商；它说出读者应当承担的一档杠杆；它指示读者提交一笔实盘订单；或者它断言一条被报告的回测曲线会再次发生。一句**机制句**描述一个对象、一个协议或一笔计算，包括它的假设与它的失效，而它不做上述任何一件事。教育性的措辞不能把一句话从第一类挪进第二类。
:::

:::proposition 机制句不是伪装的建议 {#prop-mech}
取一句包含对一张订单、一个权重或一个已报告数字的真实描述的建议句。把[[#def-advice]]里的每一条指令替换成一个定义、一个假设或一次删除，不引入新的指令，也不附带一个预测。得到的就是一句机制句。它保住了描述，而没有保住那条推荐。在这个定义之内，不存在第三个类别："建议，但只是为了教育"。
:::

:::proof
[[#def-advice]]的每一个子句是一条指令或一个预测。一个定义不蕴含一条指令：说一张限价单在市场成交到限价时有什么资格做到什么，并不蕴含任何人应当提交这样一张单子。说一个被建模的乘数对一个被建模的收益率做缩放，并不蕴含任何人应当去借款。把一个已报告的年化复合增长率按已报告的样子引用，并不蕴含这个年化复合增长率会再次发生；会不会再次发生是另一句话，而它被删掉，不是被改写成一句更软的承诺。因为那些子句是被移走的而不是被替换的，那条推荐没有被保住。因为这个定义不承认任何教育性的例外，在原句前面加上"为了学习"或"在一只假想的基金里"并不构成那次改写。
:::

接下来的三个例子是反例。每一对里的第一句话在本图谱之外。第二句是本图谱所能容纳的那一类句子。改写里的价格与权重是用来被计算的，不是用来被使用的。

:::example 限价单不是让你逢低买入的回调 {#ex-limit}
改写"你应该挂一张限价单逢低买入。"
:::solution
原句是一句建议句：它告诉读者去买入，而它把一个回调当作由头。一句机制句是：一张买入限价单是一种订单类型，只有以它的限价或更优的价格才有资格成交；如果市场从未成交到那里，它就不成交；那次成交，在它存在时，不是那个限价是一个好的预测的证据。那是对[[orders/market-and-limit-orders]]里定义的一个对象的描述。它不点名证券，不说读者应当输入哪个限价，也不说价格的一次下跌是有吸引力的。原句不能留在改写旁边充当动机。那种形式的动机就是那条指令本身。
:::
:::

:::example 乘数不是去借款的建议 {#ex-lev}
改写"把$60\%$放进趋势账簿，再上两倍杠杆。"
:::solution
原句点名了一个读者应当使用的权重和一档杠杆。一句机制句把那些数字留作代数，而把指令丢掉。一个研究权重$0.60$意味着被建模财富的十分之六。一个$2$倍的杠杆乘数，如果一个模型假设了它、并且忽略融资，会在模型里把那个权重缩放到$1.20$，并把一个简单收益率$r$缩放到$2r$。如果$r = 0.01$在这些假设之下，缩放后的简单收益率就是$0.02$。融资、保证金与一笔借入费用是进一步的字段；把它们忽略是一个假设，不是一个细节。这句话没有说去借款，没有点名一家愿意出借的经纪商，也没有说$0.60$或$2$对任何人是合适的。示例账簿A的映射是$w_t \in \{0,1\}$、带一笔点名的成本、不带杠杆，那是另一份规格说明，不是这条建议的一个更温和的版本。
:::
:::

:::example 一个已报告的年化复合增长率不是一个承诺 {#ex-recur}
改写"W01一年赚了$7.38\%$，所以那条曲线会在你交易它时再次发生。"
:::solution
W01已报告的年化复合增长率是$+7.38\%$，按quants.md对那个QuantJourney示例（Apache-2.0）的所报告，按2026年的阅读。本图谱没有重跑过这次回测。机制句到此为止，或者加上[[research-craft/comparing-implementations]]里已经用到的那些协议事实：每日行业权重、SMA($50$)对SMA($200$)、$26$年、已报告的夏普比率$0.45$、已报告的最大回撤$-34.7\%$。"所以你交易它，那条曲线就会再次发生"这个子句是一个预测加上一个指令。两个都被删掉。没有任何已报告的单元格蕴含它们。一批后来K线的纸面记录可以检查一次实现；按[[research-craft/paper-records-and-monitoring]]，它裁决不了下一个收益率。
:::
:::

O02已报告的夏普比率是$-0.17$，已报告的年化复合增长率是$+1.03\%$，是同一个归属、同样拒绝重跑。"O02亏了，所以站到对面去"误读了那一页，然后还给出建议。那个总收益率单元格是正的。那个已报告的夏普比率是负的。"对面"不是那一页定义过的一个策略。一个负的单元格留作一个负的单元格。反转那些订单会是一份新的规格说明，而即便那份诚实的规格说明，也不是这个图谱会告诉读者去跑的东西。

:::warning 教育性的前缀没有用
"为了学习，你应该挂一张限价单逢低买入"在[[#def-advice]]之下仍然是一句建议句。"想象你的经纪商，然后把这张订单发出去"也是，"这个玩具说这条曲线会再次发生，但只是假想地"也是。点名的故事主角应当持有的一个真实产品的虚构，是同一个失效。编造的价格，被点名为编造的，以及库内数字，按已报告引用而不被推荐，是这个图谱改用的形式。一条假想的纸面财富路径不是一个漏洞：它只在不发出订单、不声称再次发生的时候，才保持假想。
:::

## 搜索比单个检验更常拒绝真零假设

一章越线的第二种方式，是把一条令人印象深刻的样本内曲线当作是产生了它的那场搜索没有发生过。规格说明一章要求过搜索字段。比较一章拒绝发明WF04的获胜夏普比率。下面这个概率，就是那些拒绝存在着的课堂理由。它不是这份目录的一个P 值。

:::theorem 至少一次拒绝 {#thm-fwer}
设$m$个检验相互独立，每个检验有精确的水平$\alpha \in (0,1)$，且每条零假设都为真。设发现规则为：只要至少一个检验拒绝就拒绝。发现一个东西的概率是$1 - (1-\alpha)^m$。
:::

:::proof
给定的检验不拒绝的概率是$1-\alpha$，因为水平是精确的，且零假设为真。独立性把这些概率相乘，所以$m$个检验里没有一个拒绝的概率是$(1-\alpha)^m$。发现事件是它的补事件，其概率是$1 - (1-\alpha)^m$。这个证明用到独立性与每条都真的零假设。它没有用一个市场模型。丢掉独立性，乘积公式可能朝任一个方向失败；那个定性的警告——一场搜索比一个事先声明的检验有更多拒绝的机会——在相依之下需要一个单独的论证。
:::

:::example 九个单元格，只作为一个计数 {#ex-nine}
取$\alpha = 0.05$与$m = 9$。计算[[#thm-fwer]]里的概率。说一下这对WF04说了什么、又没说什么。
:::solution
$(0.95)^2 = 0.9025$。$(0.95)^4 = 0.9025^2 = 0.81450625$。$(0.95)^8 = 0.81450625^2 = 0.6634204313$。再乘一次$0.95$，$(0.95)^9 = 0.6302494097$。补数是$0.3697505903$，四位小数为$0.3698$。一条在九个独立的水平$0.05$真零假设检验里保留任何一个拒绝的规则，大约$37\%$的时候会"发现"一个东西，而一个检验是$5\%$。WF04是一个$9$对SMA窗口的网格，按一次回测的夏普比率计分，跨距$26$年。这份目录不报告一个P 值，九个夏普比率在这里所确立的任何意义上都不是对一条真零假设的独立检验，而获胜的夏普比率不在本图谱使用的这张表里被报告。数字$0.3698$解释了为什么一场搜索在每一格都是噪声时仍可能看上去有决定性。它不是WF04的错误发现率，也不是去交易、或避开任何一格的理由。
:::
:::

:::widget hypothesis
test: z
tail: right
alpha: 0.05
effect: 0
n: 60
caption: 在真实效应为零时，备择假设坐在零假设上，而一次水平0.05的单侧检验以alpha的概率拒绝。一场保留多个检验里最好的那一个的搜索，比这张单独的图更常拒绝一条真零假设。这张图是一个检验。它不是对任何quants.md页面的一纸裁决。
:::

Bailey、Borwein、洛佩斯·德·普拉多与Zhu在2014年那篇发表于*Notices of the American Mathematical Society*的回测过拟合论文里，把警告既投向金融之外的读者、也投向金融之内的读者：一条令人印象深刻的样本内曲线可能是一场搜索的残留，而这条曲线令人印象深刻这件事，并不是它会在样本外再次发生的证据。[[#thm-fwer]]是那个警告里的小型独立情形，不是对他们那些定理的一个摘要。本图谱的边界，是那个警告被实行而不是被喝彩的地方。引用一个库内年化复合增长率、然后说它会再次发生，就会是他们描述过的那个失效，穿上一身图谱的外衣。

:::quiz
哪句话在[[#def-advice]]之下是一句机制句？
- [ ] 你应该挂一张限价单逢低买入，但只是作为一个教学算例
- [ ] 用这家经纪商，因为那里的算例订单更清楚
- [x] 一张买入限价单只有以限价或更优的价格才有资格成交，而市场从不成交到那里时它不成交
- [ ] W01已报告的年化复合增长率$+7.38\%$会在接下来的$26$年里大致再次发生
:::solution
第三句话定义了一个成交条件，然后停下。第一句在一个教育性的标签之下留下了一条指令。第二句点名了一家经纪商。第四句断言了再次发生。[[#prop-mech]]容许第三句，而排除其余的。
:::
:::

:::quiz
一份纸面记录在一批新的K线上与冻结的规格说明相符，而这批K线的复合收益率是正的。写下的那段说明可以声称什么？
- [ ] 那个正的收益率会再次发生，因为记录相符了
- [ ] 那次相符显示出哪家经纪商本来会成交那些权重
- [x] 在那批K线上，实现与规格说明一致，而下一个收益率不由那次相符决定
- [ ] 读者应当持有那本纸面账簿持有的同一个权重
:::solution
一次相符裁决的是那批里的K线上的实现主张。它不裁决下一个收益率，不在一个规格说明从未点名的经纪商那里制造一次成交，也不把一个纸面权重变成一个被推荐的权重。
:::
:::

## 一句话发表之前该怎么读

:::algorithm 给动词归类 {#alg-classify}
在一句话被加进一课、一则笔记或一条图注之前，做下面这些事。

1. 标出动词。如果它告诉读者去买、去卖、去持有、去配置、去加杠杆、去选一家经纪商、去发一张订单，或去期待一条曲线再次发生，这句话就是建议。停下，改写，或删掉它。
2. 如果动词是定义、计算、比较、报告或假设，这句话只是一个候选。再检查[[#def-advice]]的每一个子句。"算一下你在这只基金里的订单"用了一个安全的动词，而它仍然是建议。
3. 如果出现一个库内数字，把归属挂上：按quants.md对那个QuantJourney示例（Apache-2.0）的所报告，按2026年的阅读，且没有重跑。不要挂"所以"。
4. 如果出现一个玩具数字，说它是编造的或假设的。不要给它一个代码，然后告诉读者去持有那个代码。
5. 如果这句话不合格，不要把它留下来当作一个修辞性的开头。开头是本章的一部分。
:::

第5步就是这样把本课程好几句诱人的第一行挡在门外的。一章可以用一句"某个时钟回答什么问题"来开头。它不能用一句"读者应当去交易哪个答案"来开头。同一个检验适用于图注。比较一章里那条光滑的年化复合增长率草图，被标成两个已报告数字的一幅草图，而不是标成一条可以期待的净值路径。上面那张假设检验图被标成一条真零假设之下的一个检验，而不是标成对一个产品的一纸裁决。

司法辖区被有意放在算法之外。把一句话归为机制而不是建议，是本文本的一条写作规则。它不是说这个机制可以合法地部署，也不是说它不可以合法地部署。那些陈述将会是关于一个本书不认识的地点与个人的法律建议。因此这个算法没有任何一步说"现在把它发出去"，也没有任何一步说"这是禁止它的法条"。

:::application 倒过来用这个标准
用[[#alg-classify]]读一遍一章写好的课文。示例账簿A点名一项虚构资产与一个在$\{0,1\}$里的权重，并说这份笔记不是一项持仓。O01对W01的比较算出$4.05$个百分点，并拒绝一个原因与一个赢家。纸面那一周存下$0.0625$，而什么都不发送。在说明的假设之下，相关系数$0.9$处的等权方差是$0.0095$，而W01的年化复合增长率没有被加到W18的上面。这些句子中的每一句，都可能在后来的一次编辑加上"所以读者应当……"时失败。这个标准是在编辑时被重新应用的，而不只是在初稿时。[[validation/the-deflated-sharpe]]是[[#thm-fwer]]的统计学亲戚：一个在一场搜索之后幸存下来的夏普比率，不是一个事先声明的单次检验的夏普比率。那一章也是阅读一个数字的一个机制，不是去交易幸存下来的那个数字的许可。
:::

:::remark "识别一张订单"不包括什么
一个读完了订单课程的读者，能说出一个括号单、一个移动止损或一张止损限价单有什么资格做到什么，也能说出一次回测在假装那张订单成交在止损价时假设了什么。那份知识就是机制这门课的要旨。它不包括某个具名经纪商的应用程序接口、一个密钥、一份部署清单，也不包括一段职责是把订单放出去的代码片段。那些省略就是边界本身，不是没有写完的课。一份纸面记录可以把"市价单"几个字存成规格说明本来会点名的类型。存下这几个字不是发送那张订单。
:::

:::intuition 这条线是一条你可以检验的写作约束
[[#def-advice]]是可以像时钟那样被检验的。要么这句话告诉某人持有什么、使用哪个权重、给哪家经纪商打电话、加多少杠杆、发哪张订单、或期待哪条曲线再次发生，要么它不告诉。灰色的热情（"这个结果令人兴奋"）已经在接近一个再次发生的主张了，如果这份兴奋是关于未来的。写一句关于算了些什么、在哪些假设之下算的、以及什么会证伪实现的话。
:::

:::history
2014年，David H. Bailey、Jonathan M. Borwein、马克斯·洛佩斯·德·普拉多（Marcos López de Prado）与Qiji Jim Zhu把他们对回测过拟合的陈述发表在*Notices of the American Mathematical Society*上，面对的听众并不只是金融听众。本图谱的边界继承那批听众：一条在被搜索过的那个样本之内令人印象深刻的曲线，并不凭那种令人印象深刻，就成为一条会再次发生的曲线。与洛佩斯·德·普拉多相联的那份2018年可复现性标准，是与之配对的正面要求，它已经被当作一份规格说明的字段清单用过了。这两处引用在这里都没有超出那些描述所能支持的范围，而它们也都不是一项交易授权。

## 通向何处

这条线向后适用于[[markets/systematic-question]]，向前穿过每一门引用一个库内页面的课程。[[research-craft/writing-a-specification]]是一个机制如何保持具体到可以被批评。[[research-craft/paper-records-and-monitoring]]是一个冻结的机制如何被检查而不变成一张订单。[[backtesting/reading-published-tests]]是把同一条线从别人的页面上读出来：一个已报告数字就是一个已报告数字，或者带着一个协议，或者带着一个空白，而不是一个指令。

:::summary
- 图谱解释机制。它不推荐一只证券、一只基金、一类资产或一个策略。
- 它不推荐一个权重、一档杠杆或一家经纪商，也不给出或传送一笔实盘订单。
- 它不声称quants.md上的一条曲线、或任何一课的回测，会再次发生。数字是被报告的、被归属的、且没有被重跑的。
- 一句建议句不能被"为了教育"、"假想地"或"作为一个玩具"这些词救回来，如果那条指令还留着。
- 一张买入限价单有一个成交条件。说出那个条件不是逢低买入的建议。一个$2$倍乘数对一个被建模的收益率做缩放。说出那个缩放不是去借款的建议。
- W01已报告的年化复合增长率$+7.38\%$是一个历史单元格。说这个单元格会再次发生的那个子句在本图谱之外。
- 在独立性与真零假设之下，$m$个水平$\alpha$的检验产生至少一次拒绝的概率是$1-(1-\alpha)^m$。对$\alpha = 0.05$与$m = 9$，那个概率约为$0.3698$。这不是给WF04的一个P 值。
- 库内的一笔亏损不是站到对面去的一个指令。特定辖区的法律不在这里作为法律建议教授。
:::

## 习题

:::exercise 数一数建议句 {level=1 check="3"}
下面几句话里，有几句在[[#def-advice]]之下是建议句？（1）"挂一张限价单逢低买入。"（2）"如果市场从不在限价成交，限价单就不成交。"（3）"算例就用这家经纪商。"（4）"那个已报告的年化复合增长率会再次发生。"（输入个数。）
:::solution
第（1）、（3）、（4）句各自满足定义的一个子句：一条买入的指令、一家点名的经纪商、一个再次发生的主张。第（2）句说出一个成交条件，然后停下。个数是$3$。
:::
:::

:::exercise 九个独立的真零假设 {level=1 check="0.3698"}
输入$1 - (0.95)^9$，保留四位小数。
:::solution
$(0.95)^9 = 0.6302494097\ldots$，补数是$0.3697505903\ldots$，舍入为$0.3698$。假设是独立性、精确水平$0.05$、以及每一格里一条真的零假设。WF04没有被声称满足它们。
:::
:::

:::exercise 一个被建模的毛权重 {level=1 check="1.2"}
一个模型权重$0.60$被一个$2$倍杠杆因子相乘，忽略融资。输入模型里缩放后的权重。
:::solution
$0.60 \times 2 = 1.2$。这个数字是[[#ex-lev]]里那句建议句的一个代数像，只作为代数被保留。它不是任何人被告知要持有的一个权重，而被忽略的融资是那个假设的一部分，不是一个市场报价。
:::
:::

:::exercise 缩放后的简单收益率 {level=2 check="0.02"}
在同一个忽略融资的假设之下，一个模型简单收益率$0.01$被乘数$2$缩放。输入缩放后的简单收益率。
:::solution
$2 \times 0.01 = 0.02$。[[#prop-mech]]容许这句话作为一句关于模型的话。它不容许进一步的那句：读者应当对一本真实的账簿加杠杆，以便得到$0.02$。如果融资没有被忽略，规格说明就得在报告任何一个缩放后的数字之前点名融资收益率。
:::
:::

:::exercise 两个检验 {level=2 check="0.0975"}
输入$1 - (0.95)^2$，即$m = 2$个独立的水平$0.05$真零假设检验的发现概率。
:::solution
$(0.95)^2 = 0.9025$，而$1 - 0.9025 = 0.0975$。两次独立的机会已经把单个检验的水平差不多翻了一倍，而还没有到九次机会的那个$0.3698$。公式是[[#thm-fwer]]。它不是一对库内P 值。
:::
:::

:::exercise 引用一个回撤而不推荐那本账簿 {level=2 check="-34.7"}
输入W01已报告的最大回撤，按目录摘录里所印，以百分数计，包括符号。
:::solution
已报告的最大回撤是$-34.7$。引用它，附上那个归属——按quants.md对那个QuantJourney示例（Apache-2.0）的所报告，按2026年的阅读，且没有重跑——就是一句机制句。加上"所以持有那本行业账簿"或"所以避开它"就会是建议。那个单元格不是一个关于下一个回撤的承诺。
:::
:::

:::exercise 证明补事件 {level=3}
证明：$m$个独立的精确水平$\alpha$的真零假设检验，产生至少一次拒绝的概率是$1-(1-\alpha)^m$。
:::hint
写出一个单个检验不拒绝的概率。独立性把联合不拒绝变成一个乘积。发现规则是联合不拒绝的补事件。
:::
:::solution
每个检验以概率$1-\alpha$不拒绝，因为零假设为真、水平是精确的。独立性给出每一个检验都不拒绝这一事件的$(1-\alpha)^m$。发现规则在补事件上触发，其概率是$1-(1-\alpha)^m$。乘积那一步，正是相依将需要一个不同证明的地方。这个结果没有说任何目录网格是一组独立的检验，也没有推荐对一次拒绝做出什么回应。
:::
:::

:::exercise 一个负单元格的对立面 {level=3}
O02报告年化复合增长率$+1.03\%$、夏普比率$-0.17$，按quants.md对那个QuantJourney示例（Apache-2.0）的所报告，按2026年的阅读；本图谱没有重跑过它。解释为什么"夏普比率是负的，所以站到那些市价单的对面去"在本图谱之外，尽管它提到了一个库内的类似亏损的单元格。
:::hint
把那一页报告的东西与这句话加上去的动词分开。检查"亏了"甚至算不算对每一列的一个公道的读法，以及"对面"算不算那一页定义过的一个策略。
:::
:::solution
那一页报告了一个正的年化复合增长率与一个负的夏普比率，外加一个胜率与一个盈亏比，在一个市价单RSI规则之下。"亏了"已经把这些列塌缩成了一个单元格们并不共享的判断。"站到对面去"是一条去交易一个那一页没有定义过的策略的指令：一张有条件的市价单规则的对面，不是一个已报告夏普比率的符号所能决定的。[[#def-advice]]排除那条指令。[[#prop-mech]]会容许一句把$-0.17$报告为已报告的夏普比率、然后停下的话。反转那条规则会是一份新的规格说明，带着它自己的时钟、成本与搜索字段，而即便是那份规格说明，也不会是这个图谱告诉任何人去发的一张订单。一个负的已报告数字不会被翻成一笔交易。
:::
:::
