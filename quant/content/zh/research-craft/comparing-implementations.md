"交易这条移动平均"不是一个实验的名字。"当RSI低于$35$时买入、高于$60$时卖出"也不是一个实验的名字。每一句话都把[[research-craft/writing-a-specification]]里的那些字段留出一些空白，而开放库用不止一种方式填那些空白。本章把两对填法并排放下：一本移动平均订单账簿放在一本移动平均权重账簿旁边，一本RSI订单账簿放在一本RSI权重账簿旁边。方法是一张协议表挨着一张指标表，然后是一个拒绝。这个拒绝就是结果。两个差距都没有被点名单一的原因，两对也都没有被排成一个该去交易的赢家。

下面每一个库内数字，都是按quants.md对那个QuantJourney示例（Apache-2.0）的所报告，按2026年的阅读。本图谱没有重跑过那些回测。目录单元格沉默之处，协议行写"未报告"。沉默不是一封从邻近那一行借成本、样本池或夏普约定的邀请函。

## 两张表，以及一个差距说不出什么

:::definition 协议比较 {#def-protocol}
两份已发表检验的**协议比较**，是一对只由手头这份源材料建立的表。一张表列出规格说明字段：信号公式、窗口、时钟或再平衡的措辞、订单模式或权重模式、样本池的措辞、K线尺寸、样本跨距、成本、基准、统计量与搜索。源材料没有写明的字段，写的是"未报告"，不是猜测。另一张表列出源材料确实写明的、已报告的指标，每一个都标为已报告。一句把数字差距解释成"协议行中的某一行就是*那个*原因"的话，不属于这个比较，除非有一场进一步的实验只改动那一行。
:::

这条定义之所以严格，是因为一个标量差距是一条微弱的证据。[[#prop-gap]]说的是它有多弱。

:::proposition 一个认不出原因的差距 {#prop-gap}
假设两个实验在$k \ge 2$个被记录的协议字段上不同，而可用的唯一数量比较是一个实数$\delta$，即一个被报告统计量的差。假设没有使用任何改动一个字段、固定其他字段的受控重跑。那么$\delta$无法确定唯一的单字段原因。
:::

:::proof
任何满足$d_1 + \cdots + d_k = \delta$的实数组$(d_1,\ldots,d_k)$，都是把这个差距分解为各字段贡献的一种可以想象的分解，交互作用被包含在那些$d_i$之内。当$k \ge 2$时，这样的数组不止一个。特别地，$(\delta, 0, \ldots, 0)$与$(0, \delta, 0, \ldots, 0)$的和都是$\delta$。那两个被报告的统计量只提供$\delta$的值，不提供第二个方程。因此它们无法从那些数组里挑出一个。把一个字段点名为原因将是一条额外的假设，而[[#def-protocol]]不会添加它。
:::

这条命题没有说原因在原则上不可知。它说的是，原因从这对头条数字里无从得知。后一份只改时钟、其他都不改的规格说明——像上一章示例账簿A在路径A上做的那样——可以支持一句更窄的话：在那条路径上，财富比率就是那个被争议的收益率。本章的库内两对不是那后一份规格说明。它们的窗口、样本池、跨距与实现家族是一起动的。

:::corollary 排名未必一致 {#cor-rank}
如果在[[#def-protocol]]之下，统计量$A$把实验$1$排在实验$2$之前、统计量$B$把实验$2$排在实验$1$之前，那么除非添加一个$A$与$B$之间的偏好，这一对报告决定不了哪个实验"更好"。本图谱不添加这样的偏好，而即便添加了，偏好仍然不是一个去交易的决策。
:::

:::proof
一个单一的排序无法同时吻合两个排名。任何宣布实验$1$是两者中更好的声明，都选了$A$而不是$B$，或者相反。指标本身不包含那个选择。下面的RSI那一对就是一个见证：已报告的胜率与较温和的已报告回撤把一个页面排在另一个之前，而已报告的年化复合增长率、已报告的夏普比率与已报告的盈亏比把它们排在反方向。两个排名都是已报告单元格上的算术。两个排名都不挑选一本账簿。
:::

:::intuition 减法不是机制
$7.38 - 3.33 = 4.05$作为两个已报告年化复合增长率百分数上的算术是真的。同一个数字也是$4.05 + 0$、$0 + 4.05$与$2 + 2.05$。算术分不清那些故事。一句机制的话必须来自一个能关掉一个故事的对照，而不是来自那个减法本身。
:::

## O01与W01并排

O01，"Market SMA Cross"，是那个订单模式标签：当SMA($20$)上穿SMA($50$)时买入；反向时卖出；市价单；规则单元格写的是股票交易所交易基金、趋势。已报告的跨距是$25$年的日K线。已报告的数字是总收益率$+126.66\%$、年化复合增长率$+3.33\%$、夏普比率$0.21$、最大回撤$-16.35\%$、胜率$51.9\%$、盈亏比$2.18$。

W01，"Daily SMA Trend"，是那个权重模式标签：只要SMA($50$)高于SMA($200$)，就持有每个行业交易所交易基金；每日再平衡。已报告的跨距是$26$年的日K线。已报告的数字是总收益率$+537\%$、年化复合增长率$+7.38\%$、夏普比率$0.45$、最大回撤$-34.7\%$、胜率$72.6\%$、盈亏比$2.48$。

把$0.21$与$0.45$称为**已报告的夏普比率**。本图谱对夏普比率的定义——超额收益的均值除以超额收益的样本标准差——并未被声称是那些单元格背后的约定。最大回撤按目录引用它的方式来引用，以百分数计，不是从一条我们没有的路径重新推导的。

| 字段 | O01 | W01 |
|---|---|---|
| 家族 | 在交叉上市价单 | 目标权重，每日再平衡 |
| 窗口 | $20$与$50$ | $50$与$200$ |
| 规则形状 | 交易这个交叉与其反向 | 快均线高于慢均线期间持有 |
| 样本池措辞 | 股票交易所交易基金，趋势 | 每个行业交易所交易基金 |
| K线 | 日频 | 日频 |
| 跨距 | $25$年 | $26$年 |
| 成本模型 | 本图谱所用的表未报告 | 本图谱所用的表未报告 |
| 基准 | 本图谱所用的表未报告 | 本图谱所用的表未报告 |
| 获胜的单位 | 本图谱所用的表未定义 | 本图谱所用的表未定义 |
| 搜索 | 本图谱所用的表未报告 | 本图谱所用的表未报告 |

两个年化复合增长率单元格相差$7.38 - 3.33 = 4.05$个百分点。按[[#prop-gap]]，那个差不点名一个原因。至少窗口、规则形状、家族（订单对权重）、样本池措辞与跨距是不同的，所以$k \ge 2$绰绰有余。一个说"权重以$4.05$个百分点击败订单"的读者，是把差距归给了一个行、把其他行设成了零。一个说"是更长的均线干的"的读者做了另一个归属。两者都与同一个$\delta$相容。本章两个都不背书。

回撤单元格在相反的方向上不同。W01的已报告最大回撤是$-34.7\%$，O01的是$-16.35\%$。已报告年化复合增长率较高的那个页面，有着较深的已报告回撤。选较高的年化复合增长率与选较温和的回撤，是不同的偏好。[[#cor-rank]]说，这两张表决定不了这个偏好。它们也没有说较温和的回撤在任何未来的样本上更安全：两个数字都是对它们各自被报告的那条路径的描述。

胜率是$51.9\%$与$72.6\%$，盈亏比是$2.18$与$2.48$。一个订单回测里的胜率与一个权重回测里的胜率，是对表没有定义的那些事件的计数。在单位被共用——一笔交易、一天、一星期——之前，这两个百分数不是同一件事的频率。[[performance/win-rate-and-profit-factor]]保持着那个区分。这里没有任何东西把任何一个盈亏比转化为盈利的概率。

:::example 你可以计算却不许解释的一个差 {#ex-cagr-gap}
计算W01与O01已报告年化复合增长率之间的差距。说出一个[[#prop-gap]]允许的分解，以及一句那个分解所禁止的话。
:::solution
差距是$7.38 - 3.33 = 4.05$个百分点。一个被允许的分解把全部$4.05$个百分点归给从订单模式到权重模式的改动，把$0$归给窗口、跨距、样本池措辞与规则形状。另一个把全部$4.05$个百分点归给从$(20,50)$到$(50,200)$的改动，把$0$归给家族。两者的和是同一个已报告差距。被禁止的那句话，是把那些归属中的任何一个当作两个页面已经展示了的东西来呈现。两个页面展示的是两个年化复合增长率与一份差异清单。移动平均机制本身在[[trend/moving-averages]]里讨论；它认不出是哪一个实现产出了$\delta$。
:::
:::

:::example 一个字段改动就能认出的差距 {#ex-path-gap}
在路径A上，示例账簿A的毛合法复合收益率保留六位小数为$0.057692$，同根K线复合收益率为$0.089109$。只有时钟在变。计算这个差距。
:::solution
在每个项各自舍入到六位小数的口径下，差距是$0.089109 - 0.057692 = 0.031417$；精确地，它是$110/101 - 110/104 = 165/5252 = 0.03141660\ldots$。在这里，对实际跑过的那个对照而言$k = 1$：信号、窗口、平局、成本与路径都被固定了。[[#prop-gap]]在那种情形下不阻拦归属。这个归属仍然只关乎路径A。它不迁移到O01对W01上，那里时钟不是唯一在动的字段，路径也不是这个玩具。
:::
:::

把舍入后的年化复合增长率复利起来，是另一道陷阱。$(1.0333)^{25} - 1 = 1.268092$，保留六位小数，而O01的已报告总收益率是$+126.66\%$，作为纯数即$1.2666$。这个出入约为$0.0015$。$(1.0738)^{26} - 1 = 5.368078$，保留六位小数，挨着W01已报告的$+537\%$。接近不是恒等。从舍入后的年化复合增长率画出的一条光滑曲线，不是发表出来的净值路径，也不是一个预测。本章的那张图就是刻意做成那种草图的。

:::widget plot
f: (1.0333)^x; (1.0738)^x
x: 0, 25
labels: O01 reported CAGR, smoothed; W01 reported CAGR, smoothed
caption: 在两个已报告年化复合增长率上的光滑复合增长，画在一条共用的$25$年横轴上，好让图读得动。W01的页面报告的是$26$年，不是$25$年。这些曲线不是发表出来的净值路径，不是重跑，也不是预测。那个竖直差距不是一个原因。
:::

## O02与W03并排

阈值是一致的，这正是那一对容易被读错的原因。O02，"Market RSI Reversion"，在RSI($14$)低于$35$时买入、RSI高于$60$时卖出，使用市价单。已报告的跨距是$25$年的日K线。已报告的数字是总收益率$+29.08\%$、年化复合增长率$+1.03\%$、夏普比率$-0.17$、最大回撤$-16.01\%$、胜率$71.6\%$、盈亏比$1.81$。那一行式规则没有点名样本池。

W03，"Weekly RSI Reversion"，在RSI($14$)低于$35$时入场、RSI高于$60$时离场，每星期五、每周一次。K线是日频的，已报告的跨距是$26$年。已报告的数字是总收益率$+373\%$、年化复合增长率$+6.16\%$、夏普比率$0.34$、最大回撤$-49.2\%$、胜率$62.1\%$、盈亏比$2.15$。那一行式规则也没有点名样本池。说这两个页面"交易同样的交易所交易基金"就是发明一个字段。[[reversion/rsi-and-bands]]主管这个指标的构造；本节只主管那两份已报告协议的比较。

共用的措辞：RSI($14$)，低于$35$入场，高于$60$离场。不共用的措辞：市价单对每周权重，$25$年对$26$年，以及一条O02那一行没有写明的星期五日程。成本、基准、获胜的单位与RSI平滑器的精确形态，在本图谱所用的表里都未报告。已报告的夏普比率$-0.17$与$0.34$同样不带着经过核实的年化。

:::example 两个排名 {#ex-rank}
只用已报告的单元格，按年化复合增长率、按已报告的夏普比率、按胜率、按最大回撤的深度（较温和即绝对值较小），给O02与W03排名。
:::solution
年化复合增长率：W03（$+6.16\%$）排在O02（$+1.03\%$）之前。已报告的夏普比率：W03（$0.34$）排在O02（$-0.17$）之前。胜率：O02（$71.6\%$）排在W03（$62.1\%$）之前。回撤深度：O02（$-16.01\%$）比W03（$-49.2\%$）温和。盈亏比，如果作为第五列加上，与年化复合增长率和夏普比率一致：$2.15 > 1.81$。[[#cor-rank]]适用。O02的已报告年化复合增长率为正，而它已报告的夏普比率为负，所以即使单个页面也不是每一列都指向同一个方向。没有哪一列是一条推荐。已报告年化复合增长率的差距是$6.16 - 1.03 = 5.13$个百分点，而[[#prop-gap]]挡住对那$5.13$的任何一行式原因，和它挡住上面那个$4.05$的一个原因一样坚定。
:::
:::

一个高的已报告胜率挨着一个负的已报告夏普比率，是一个有用的警告：不要把胜率单元格读成品格。它仍然只是一个关于怎样读一张表的警告。它不是与O02反着做的建议，也不是照抄W03那套星期五权重的建议。库内的亏损，凡是出现的，都留作一个已报告的亏损。O02的已报告总收益率为正；它已报告的夏普比率为负。这两个事实都不是站到那些市价单对面去的指令。

:::warning 不要给某一列加冕
失误是按一列给目录排序，再把那个排序叙述成一个关于市场的发现。那个排序是一列的性质。在这一对上，另一列会朝反方向排。加上"所以应该交易最上面那一行"这句话，就彻底离开了协议比较，进入了建议，而[[research-craft/the-boundary]]把建议排除在外。
:::

## 网格赢家不是一折

WF04是一场搜索的页面，不是上面那两张策略页面的双胞胎。目录描述了$9$个组合：SMA快窗口在$\{20, 50, 80\}$中，慢窗口在$\{100, 150, 200\}$中，每一个都按一次回测的夏普比率计分，跨距$26$年。本图谱使用的这张表没有报告哪个单元格赢了，也没有报告获胜的夏普比率。那些数字不在这里被发明。

WF01是$48$折：滑动的定长训练窗与测试窗，带一次测试前清洗，同样跨距$26$年。目录说，走步验证页面是切片诊断，不是独立的样本外证据。一折，如果源材料自己都不称之为独立的确认，就不能因为被放在一场搜索的赢家旁边而升格。

:::example 你不许写的话 {#ex-wf}
一份笔记写着："WF04的最佳单元格与一折典型的WF01都是样本外的，所以它们确认了同一条移动平均规则。"只用目录的描述，那句话有什么错？
:::solution
三处，任何一处就够。第一，目录没有报告WF04的最佳单元格，所以那句话指向的，是源材料按本处的用法没有给出的一个数字。第二，WF01自己的描述拒绝了"独立的样本外证据"这个身份；把一折称为样本外的确认，与那个页面相矛盾。第三，一个因为得分在$9$个组合中最高而被保留的单元格，有一个事先声明的折所没有的选定步骤。即使两个对象都是诊断，它们也不是同类。[[validation/parameter-search]]与[[validation/walk-forward]]把这些设计分开。[[#def-protocol]]的比较方法把缺席的赢家标成"未报告"，然后停下。
:::
:::

计数$9 = 3 \times 3$是关于那张被宣布的网格的一个事实，不是一个显著性水平。只有在本章不向目录授予的那些额外假设之下，它才成为一个概率。边界一章会计算这样一个玩具概率，并把它标注为玩具，恰恰是为了让它不能被塞到WF04那个未报告的赢家底下。

:::quiz
O01与W01都提到了收盘价的移动平均，都在日K线上。哪个结论能从协议表推出？
- [ ] $4.05$个百分点的年化复合增长率差距是每日再平衡造成的
- [ ] $4.05$个百分点的差距是W01中较长的窗口造成的
- [x] 这个差距作为算术是真的，作为原因则未被识别，因为好几个协议字段不同，而源里没有单字段重跑
- [ ] W01是该照抄的实现，因为$7.38 > 3.33$
:::solution
只要$k \ge 2$而唯一的证据是$\delta$，[[#prop-gap]]就适用。这张表列出了不止两处差异。照搬较大的那个年化复合增长率会是一条建议，而且它还会无视同一个页面上较深的已报告回撤。
:::
:::

:::quiz
RSI阈值$35$与$60$同时出现在O02与W03里。在两个页面成为同一个实验之前，还有什么必须一致？
- [ ] 别的什么都不必，如果指标与阈值一致
- [x] [[#def-protocol]]里的那些字段：家族、日程、跨距，以及每一个事实上不同或未报告的字段
- [ ] 只有胜率，因为$71.6\%$与$62.1\%$很接近
- [ ] 只有已报告年化复合增长率的符号
:::solution
共用的阈值是一个字段。O02是市价单，跨距$25$年；W03是一条星期五的权重规则，跨距$26$年。未报告的成本与未定义的获胜的单位，是进一步不要把两行合并的理由。胜率接近，不是实验相同。
:::
:::

:::remark 已报告总收益率比年化复合增长率更忌混用
O01的$+126.66\%$与W01的$+537\%$分别是$25$年与$26$年上的增长。它们的比不是一种相对技能，它们的差也不是一年的差距。年化复合增长率的单元格至少引了一个共用的单位，一年的百分数，而即便是那些单元格，作为原因仍然是未被识别的。混用总收益率的单元格，连这点部分的保护也跳过了。两个单元格都不是接下来$25$年的预测。
:::

:::application 受控对照会住在哪里
如果有人把一份规格说明重跑两次，只改动"市价单"对"每日权重"，并把两条完整路径都发表出来，[[#prop-gap]]就不再描述那一对。那次重跑会是一个新的源，带着它自己的时钟、成本与版本。本图谱没有执行过它，也不描述怎样把任何一个版本路由给经纪商。在那个源存在之前，O01与W01的诚实摘要就是那两张表。
:::

:::history
尤金·法玛（Eugene Fama）1970年的综述把一个市场假说当作一个带有言明范围的东西来对待：什么信息，以及对反映进价格的什么论断。那一脉后来的论证，靠收窄范围而存亡，而不是靠添加形容词。一张协议表就是把同一种直觉用在一个回测标签上。两个窗口不同、订单约定不同的移动平均页面，是两个范围。把两者都叫作"那个趋势结果"，就删掉了法玛那种论断本来会在第一句里保留的范围。
:::

## 通向何处

一个协议比较可以被冻结，然后被观看。[[research-craft/paper-records-and-monitoring]]就是那种观看：在随后的K线上一份假想的记录，仍然不发出一张订单。[[backtesting/weights-versus-orders]]是引擎的分叉，权重模式对订单模式，O01与W01演示了它，却没有裁决它。[[research-craft/combination-and-decay]]是被拒绝作为排名之后，两个年化复合增长率的不能为：不要把两者相加做成一个混合。

:::summary
- 用一张协议表挨着一张指标表来比较实现，并写"未报告"而不是猜测。
- 当两个或更多协议字段不同、且没有可用的单字段重跑时，两个统计量之间的差距$\delta$点不名单一的原因。
- O01与W01都是移动平均的标签，却不是一个实验：窗口$20/50$对$50/200$，市价单对每日权重，$25$年对$26$年，已报告年化复合增长率$+3.33\%$对$+7.38\%$，已报告最大回撤$-16.35\%$对$-34.7\%$。
- $4.05$个百分点的年化复合增长率差距是算术。它不是权重的、窗口的、或那多出的一年的一个被识别的效应。
- O02与W03共用RSI($14$)的阈值$35$与$60$，除此之外，表写明的东西几乎什么都不共用。它们的列排名不一致。
- WF04的获胜单元格在本图谱所用的表里没有报告，而即使报告了，它也不会是一折WF01的同类。WF01的折是切片诊断，不是独立的样本外证据。
- 本章没有任何排名是一个去交易、去反转、或去偏好某经纪商对任何一个标签之实现的决策。
- 在已报告年化复合增长率上的光滑曲线是两个数字的图示，不是净值路径，也不是预测。
:::

## 习题

:::exercise 年化复合增长率差距 {level=1 check="4.05"}
输入W01与O01已报告年化复合增长率的差，以个百分点计。
:::solution
$7.38 - 3.33 = 4.05$。单位是已报告年化复合增长率的百分点，不是一个概率，也不是一个原因。[[#prop-gap]]就是那句话到此为止的理由。
:::
:::

:::exercise 已报告夏普比率差距 {level=1 check="0.51"}
输入$0.34 - (-0.17)$，即W03与O02已报告夏普比率的差。
:::solution
$0.34 + 0.17 = 0.51$。这些是已报告的夏普比率。本图谱没有核实过它们的年化，所以$0.51$不是两个按本图谱约定的夏普比率之差。它仍然是对单元格做的那个数，而它仍然没有单字段的原因。
:::
:::

:::exercise 回撤差距，以个百分点计 {level=1 check="18.35"}
从W01已报告的$-34.7$最大回撤中减去O01已报告的$-16.35$最大回撤，按印出来的百分数来算，并输入绝对差距。
:::solution
印出来的大小相差$34.7 - 16.35 = 18.35$个百分点。W01的已报告回撤是两者中更深的。这个事实反转了年化复合增长率的排名，而它仍然不是采用O01的理由。
:::
:::

:::exercise RSI那一对的胜率差距 {level=2 check="9.5"}
输入O02的已报告胜率减去W03的已报告胜率，以个百分点计。
:::solution
$71.6 - 62.1 = 9.5$。O02在这一列排名更高，在已报告年化复合增长率与已报告夏普比率上排名更低。获胜的单位在表里没有定义，所以$9.5$是已报告百分数之间的差距，不是一个被证实的、在同一事件频率上的差距。
:::
:::

:::exercise 玩具路径上的时钟差距 {level=2 check="0.031417"}
使用路径A时钟对照中六位小数的复合收益率$0.089109$与$0.057692$，输入其差。
:::solution
$0.089109 - 0.057692 = 0.031417$。这个差距在它自己的规格说明内部有一个点得出名字的原因：时钟，因为其他字段被固定了。不要把"原因是时钟"这句话照搬到O01与W01上。
:::
:::

:::exercise 被宣布网格的大小 {level=2 check="9"}
WF04给快窗口在$\{20, 50, 80\}$、慢窗口在$\{100, 150, 200\}$的每一个组合计分，且在每个组合里快窗口都短于慢窗口。那是多少个组合？（输入个数。）
:::solution
$3$个快窗口中的每一个都与$3$个慢窗口中的每一个配对，而快窗口集合里的每个值都低于慢窗口集合里的每个值，所以那个约束一个也删不掉。个数是$9$，与目录一致。这个个数不是对获胜夏普比率的报告，本处所用的表没有给出那个比率。
:::
:::

:::exercise 两个分解 {level=3}
把$4.05$个百分点的年化复合增长率差距写成"家族"贡献与"窗口"贡献，写出两种不同的实数分解。解释协议表为什么无法在这两者之间做选择。
:::hint
任何和为$4.05$的实数对都是一个分解。挑两对在哪个分量为零上不一致的。然后数一数那两个年化复合增长率单元格实际给了你几个方程。
:::
:::solution
一个分解是家族$4.05$、窗口$0$。另一个是家族$0$、窗口$4.05$。第三个同样被算术允许：家族$2$、窗口$2.05$。那两个年化复合增长率单元格只确定了这个和。跨距、样本池措辞、规则形状与未报告的成本，是[[#prop-gap]]同样会留白的更多分量。选定一个分解，是一条源材料里不含有的假设。因此这个比较记录$\delta = 4.05$，而不点名原因。
:::
:::

:::exercise 舍入后的年化复合增长率对已报告总收益率 {level=3}
计算$(1.0333)^{25} - 1$，减去O01的、写成纯数$1.2666$的已报告总收益率。把差保留六位小数。
:::hint
一个被舍入到四位小数的年化复合增长率的平滑复合，未必能还原一个被另行舍入的总收益率。使用$1.0333$，而不是一个重建的比率。
:::
:::solution
$(1.0333)^{25} - 1 = 1.268092355\ldots$。减去$1.2666$得$0.001492355\ldots$，六位小数为$0.001492$。这个出入，是把已报告总收益率与已报告年化复合增长率各留作一个已报告单元格的理由，也是不要把小工具那条光滑曲线当作O01净值路径的理由。它不是目录"有错"的证据，也不是重新交易那笔检验的理由。
:::
:::
