两本账簿的研究结果之间有一个协方差，无论有没有人对它们取平均。对账簿做等权，是关于那个协方差的一笔计算。这套代数与组合课程对资产使用的那套代数是同一套代数，而含义并不相同，因为你有资格插进去的那个相关系数，是账簿结果的相关系数。两本趋势账簿可以在其底下的资产并不同步的情况下同步。把资产的相关系数插进去，回答的是一个不同的问题。

拥挤与衰减，是关于一个已发表的模式为什么后来可能变小的假说。可观察的迹象——与同类账簿联动更多的结果、在规格说明的成本之后缩小的净结果——是描述。它们不是交易信号。停止一项研究是允许的。把两个库内年化复合增长率相加不是一个混合，本章也不做这件事。

## 属于那个公式的相关系数

:::definition 账簿相关系数 {#def-corr}
设$X$与$Y$是两本研究账簿在一组公共期间上的简单收益率序列，每本账簿都从它自己那份冻结的规格说明算出。**账簿相关系数**是$X$与$Y$在那些期间上的样本相关系数，并且写明样本协方差的除数（本章在一个样本被估计时使用除数$n-1$的口径，在一个数字是假设时使用给定的$\rho$）。账簿相关系数不是底层资产的相关系数，除非每本账簿*就是*那个资产本身，以权重$1$持有。
:::

这个定义拒绝一条捷径。一个每当一条慢均线上升就持有一篮子资产的规格说明，与第二个用一条类似规则持有同一篮子的规格说明共享一个因子。它们的账簿相关系数可以很高。那一篮子里的一对资产仍然可以有一个温和的相关系数。[[portfolio/from-signal-to-weight]]为一本账簿把一个信号映射为一个权重。它本身并不供给两本账簿之间的相关系数。

:::proposition 等权合并的方差 {#prop-var}
设$X$与$Y$是随机变量，满足$\Var(X) = \Var(Y) = \sigma^2$、$\Corr(X,Y) = \rho$，其中方差存在且$|\rho| \le 1$。设$Z = (X+Y)/2$为等权合并，并做再平衡，使每本账簿在那些收益率所指的期间开始时都拥有权重$1/2$。那么

$$
\Var(Z) = \frac{\sigma^2}{2}(1+\rho), \qquad \sqrt{\Var(Z)} = \sigma \sqrt{\frac{1+\rho}{2}}.
$$

这个恒等式是关于二阶矩的一个事实。它不是预测，不是效用，也不是持有这个合并账簿的一条建议。
:::

:::proof
双线性给出

$$
\Var(Z) = \frac14 \Var(X) + \frac14 \Var(Y) + \frac12 \Cov(X,Y).
$$

协方差是$\rho\,\sigma\,\sigma = \rho\sigma^2$，所以

$$
\Var(Z) = \frac14\sigma^2 + \frac14\sigma^2 + \frac12\rho\sigma^2 = \frac{\sigma^2}{2}(1+\rho).
$$

标准差是非负的平方根。权重$1/2$是这条命题的一个假设。一个不同的权重向量是一个不同的随机变量，需要它自己的展开式。
:::

:::corollary 方差随账簿相关系数上升 {#cor-mono}
在[[#prop-var]]之下，固定$\sigma > 0$，$\Var(Z)$在$[-1,1]$上关于$\rho$严格递增。在$\rho = 1$处，$\Var(Z) = \sigma^2$。在$\rho = -1$处，$\Var(Z) = 0$。
:::

:::proof
映射$\rho \mapsto (\sigma^2/2)(1+\rho)$的斜率是$\sigma^2/2 > 0$，所以它严格递增。代入两个端点得到$\sigma^2$与$0$。完全相关移除了等权看似承诺的那个方差削减。完全负相关在这套二阶矩算术里把两本账簿相互抵消。两个端点都不是市场事实；它们都是对那个公式的检验。
:::

取每本账簿$\sigma = 0.10$，作为一个背后没有被估计样本的建模假设。在账簿相关系数$0.2$处，

$$
\Var(Z) = \frac{0.01}{2}(1.2) = 0.006, \qquad \sqrt{\Var(Z)} = 0.077460
$$

保留六位小数。在账簿相关系数$0.9$处，

$$
\Var(Z) = \frac{0.01}{2}(1.9) = 0.0095, \qquad \sqrt{\Var(Z)} = 0.097468
$$

保留六位小数。单本账簿的方差是$0.01$，标准差是$0.10$。两个等权方差是那个单账簿方差的$60\%$与$95\%$。标准差是$0.10$的$77.46\%$与$97.47\%$，按舍入后的平方根。在相关系数$0.2$处看得见的方差削减，到了相关系数$0.9$已经大多不见了。

如果这些账簿的相关系数真的是$0.9$，而计算里插入的是$0.2$，只因那是某个人记得的某个资产相关系数，那么被报告成$0.006$的那个方差，对应的二阶矩值是$0.0095$。比值$0.0095/0.006 = 1.5833$，保留四位小数：被插入的那个方差按这个因子偏小。公式没有失败。那个输入是错的那一对序列的相关系数。[[#def-corr]]就是点名是哪一对的那条指令。

:::example 两个玩具方差 {#ex-two-var}
对$\sigma = 0.10$，计算$\rho = 0.2$与$\rho = 0.9$处的$\Var(Z)$与标准差，以及端点$\rho = 1$处的方差。
:::solution
由[[#prop-var]]，$\Var(Z) = (0.01/2)(1+\rho) = 0.005(1+\rho)$。在$\rho = 0.2$处，方差是$0.006$，标准差是$\sqrt{0.006} = 0.077460$，保留六位小数。在$\rho = 0.9$处，方差是$0.0095$，标准差是$\sqrt{0.0095} = 0.097468$，保留六位小数。在$\rho = 1$处，方差是$0.01$，标准差是$0.10$，与单独一本账簿相等。这些输入里没有一个是从一个库内页面上估计出来的。
:::
:::

## 复合收益率不能取平均

一个单期间的等权确实对简单收益率取平均：如果两本账簿在同一个期间分别挣得$0.04$与$-0.02$，等权的简单收益率就是$0.01$。一旦有了两个期间、而统计量是复合收益率，这个恒等式就死了。[[#prop-avg]]就是那个精确的差距。

:::proposition 两个期间的复合数不能取平均 {#prop-avg}
设两本账簿在两个期间上的简单收益率是$(r, u)$与$(s, v)$。假设这个合并在每个期间开始时被再平衡到权重$1/2$、$1/2$，没有成本。这个合并的增长倍数是

$$
\left(1 + \frac{r+s}{2}\right)\left(1 + \frac{u+v}{2}\right).
$$

两本账簿增长倍数的平均是$\bigl[(1+r)(1+u) + (1+s)(1+v)\bigr]/2$。那个平均减去这个合并的倍数等于$(r-s)(u-v)/4$。特别地，复合收益率的平均等于这个合并的复合收益率，对所有这样的输入成立，仅当一本账簿在第一个期间或第二个期间与另一本相同。
:::

:::proof
把这个合并的倍数展开：

$$
1 + \frac{r+s}{2} + \frac{u+v}{2} + \frac{(r+s)(u+v)}{4}.
$$

把倍数的平均展开：

$$
1 + \frac{r+s}{2} + \frac{u+v}{2} + \frac{ru + sv}{2}.
$$

从第二个里减去第一个。线性项相互抵消，剩下的部分是

$$
\frac{ru+sv}{2} - \frac{(r+s)(u+v)}{4} = \frac{(r-s)(u-v)}{4}.
$$

复合收益率是增长倍数减$1$，所以同一个差对它们也成立。这个差对所有对子为零，仅当对每一个选择都有$r = s$或$u = v$，而对任意的账簿这不是真的。
:::

:::example 一个数值反例 {#ex-counter}
账簿X先挣$0.10$、后挣$-0.10$。账簿Y先挣$0$、后挣$0$。计算每一本的复合收益率、它们的平均，以及那个再平衡的等权合并的复合收益率。
:::solution
账簿X按$1.10 \times 0.90 = 0.99$增长，所以它的复合收益率是$-0.01$。账簿Y的复合收益率是$0$。复合收益率的平均是$-0.005$。等权的简单收益率是$0.05$与$-0.05$。这个合并按$1.05 \times 0.95 = 0.9975$增长，所以它的复合收益率是$-0.0025$。那个差，平均减合并，是$-0.0025$，与$(r-s)(u-v)/4 = (0.10 - 0)(-0.10 - 0)/4 = -0.0025$相符。在这个玩具上，把复合收益率取平均，相对于那个再平衡的合并夸大了亏损。在另一个玩具上，这个不等式可能翻转。值得相信的那个恒等式是[[#prop-avg]]里的那个，而不是把摘要数字取平均的那个习惯。
:::
:::

:::example 只有一个期间，于是平均是诚实的 {#ex-one}
两本账簿在一个单期间里分别挣得$0.04$与$-0.02$。等权的简单收益率是多少，为什么这不是一张把多年年化复合增长率取平均的许可证？
:::solution
等权的简单收益率是$(0.04 + (-0.02))/2 = 0.01$。[[#prop-avg]]需要两个期间，那个交叉项才会出现，所以这里没有矛盾。一条多年之上的年化复合增长率不是一个单期间的简单收益率。把两条年化复合增长率取平均，既跳过了那个交叉项，也在那些跨距不同时，跳过了那些期间对齐这个假说。数字$0.01$是一个课堂收益率。它不是任何已发表账簿的一个混合。
:::
:::

## 两个人们可能忍不住相加的库内账簿

W01，"Daily SMA Trend"，报告年化复合增长率$+7.38\%$、跨$26$年，已报告的夏普比率$0.45$，最大回撤$-34.7\%$。W18，"Vol Target Momentum"，报告年化复合增长率$+10.96\%$、跨$19$年，已报告的夏普比率$0.57$，最大回撤$-41.2\%$。两句话用的都是按quants.md对那个QuantJourney示例（Apache-2.0）的所报告，按2026年的阅读。本图谱没有重跑过任何一次回测。W18的一行式规则是一个被缩放到$15\%$波动率目标的动量篮子；W01的是一条每日行业趋势权重。那个波动率目标的机制属于[[portfolio/inverse-volatility-and-targets]]。在这里，那些账簿只作为读者可能想用标题数字上的算术来混合的对象出现。

把两条年化复合增长率相加得到$7.38 + 10.96 = 18.34$，那不是库里任何一次实验的一个年化复合增长率。把它们取平均得到$(0.0738 + 0.1096)/2 = 0.0917$，作为一个纯数，即$9.17\%$。那个平均也不是一个组合的年化复合增长率。那些跨距是$26$年与$19$年，所以[[#prop-avg]]的那个两期间恒等式甚至还没走到它的假设：页面上没有一对公共的期间收益率。那些总收益率，$+537\%$与$+621\%$，更没有资格被相加。一次认真的合并需要那两条简单收益率序列、一个共享的时钟、账簿之间的一个权重，以及一笔成本。这里使用的库内摘录不提供那些序列。本章前面那些玩具方差，是我们在不假装拥有更多输入的情况下所能算的东西。

:::warning 不要把标题数字相加
那个失误是把两条有吸引力的年化复合增长率当作食材。加法假设一个公共的单位与一个公共的样本，然后，如果你想要的对象是一个再平衡混合的复合收益率，它算出来的仍然是那个错误的函数。W01与W18在公共样本那一步就失败了，甚至轮不到那个函数出错。把两条年化复合增长率并排报告，带着那句归属，是允许的。把$18.34\%$或$9.17\%$报告为一个混合"本来会赚到的"东西，是不允许的。
:::

## 拥挤、衰减与停止

**拥挤**，在这里的用法中，是一个假说：随着更多资本跑一个已发表的模式，成本之后的净结果缩小，因为后来的参与者在同一个方向上交易，而价格冲击对他们不利。**衰减**是更宽的那个观察：一个在后来窗口上测得的模式，可能比当初令那个窗口成名的模式更小，而不对某一个原因做承诺。两者都是关于研究结果的假说。两者都不是进入或离开一个市场的门槛。

与拥挤*相容*——同时也与其他故事相容——的迹象包括：对共享该模式的同类规则而言不断上升的账簿相关系数，以及在冻结的成本之下、向零移动或跌过零的那个净纸面结果。[[research-craft/comparing-implementations]]里那个认不出原因的差距的结果，已经禁止把单个差距读成单个原因。一个缩小的净结果可以是拥挤、一次体制变化、一次数据修订，或者是一场留下了一个幸运窗口的搜索的迟来的账单。一个上升的相关系数可以是拥挤，或者一个一直都在、只是变得更显眼的共同因子。把这些迹象列出来是科学的一部分。把一个迹象升格成一张订单不是。

停止是一项研究决策。一份规格说明可以被标记为退役，因为一条事先写下的规则这么说：监控统计量离开了那条在新的K线到来之前就写下的带。它可以退役，因为那份规格说明被发现是不完整的，或者因为它所问的问题不再是那个问题。停止维护日志。它不是对那条规则的一笔卖空，也不是对一个并不持有那条规则的读者的建议。本图谱里没有可以离场的头寸。

一条事先写下的带本身就是一个字段。"如果接下来$20$个交易日里的纸面复合收益率低于$-0.05$，就停止研究日志"，如果它是在那些交易日之前固定下来的，就可以是诚实的。"因为路径让我们失望了就停止，并把阈值倒填日期"是一场搜索，而搜索字段必须把这件事说出来。那句话说的那个阈值$-0.05$，是一个形状的一个例示，不是本章为任何一本账簿推荐的阈值，包括W01与W18。

:::example 一个迹象不允许什么 {#ex-sign}
假设两本纸面账簿，各自按假设有$\sigma = 0.10$，在一个较早的窗口里有账簿相关系数$0.2$，在一个较晚的窗口里有$0.9$。等权的方差从$0.006$升到$0.0095$。较晚窗口里的净复合收益率也更小。你可以得出什么结论？
:::solution
你可以得出那个算术：在[[#prop-var]]之下，如果标准差真的保持在$0.10$，等权合并的方差在较高相关系数处更高，$0.0095$对$0.006$。如果纸面记录那么说，你可以记下那个净结果缩小了。你不可以得出拥挤是唯一的原因，因为一个共同因子或一次体制变化也可以抬高相关系数、砍掉一个净结果，而没有任何新资本追随过那条规则。你不可以把从$0.2$到$0.9$的那个上升转化成一张减少、反转或增加一个市场头寸的订单。对那个较小的净结果，停止研究日志仍然可以是那个事先写下的回应。那是关于日志的一个决策。
:::
:::

:::quiz
两个资产按$0.2$相关。两本经常一起做多那些资产中同一个的账簿按$0.9$相关。如果每本账簿的标准差是$0.10$，哪个方差属于为这些账簿的等权混合而准备的[[#prop-var]]？
- [ ] $0.006$，因为那些资产按$0.2$相关
- [x] $0.0095$，因为这些账簿按$0.9$相关
- [ ] $0.01$，因为等权处理总是保住方差
- [ ] $0.006 + 0.0095$，即两种解读之和
:::solution
[[#def-corr]]把账簿相关系数放进公式。那个资产相关系数只有对一个由这些资产本身组成的等权混合才是正确的输入。在$\rho = 0.9$处，方差是$0.0095$，不是$0.006$，而这两个数字不相加。
:::
:::

:::quiz
账簿X在那个两期间玩具上复合到$-0.01$，账簿Y复合到$0$。为什么$-0.005$不是等权的复合收益率？
- [ ] 因为复合收益率必须用与波动率成比例的权重来平均
- [x] 因为增长倍数的平均与简单收益率的平均的增长倍数之间相差$(r-s)(u-v)/4$
- [ ] 因为一个负的复合收益率不能被混合
- [ ] 因为等权的复合收益率总是零
:::solution
[[#prop-avg]]在这个玩具上给出那个差$-0.0025$，所以这个合并的复合收益率是$-0.0025$，不是那个平均$-0.005$。这个结果使用等权与零成本。它不使用波动率权重，而一个负的数可以是一个输入。
:::
:::

:::remark 给规则做分散化不是给资产做分散化
"这些账簿是不同的想法，所以相关系数低"这句话是一条额外的假设。不同的英文描述可以共享一个因子。同一句英文描述，在一页上作为订单实现、在另一页上作为权重实现，相关系数仍然可以很高，或者不高：O01与W01在本图谱使用的这张表里没有报告它们的收益率序列的相关系数，本章也不发明它。低相关系数是你在那些序列上测出来的东西，或者像那些$\sigma = 0.10$的玩具那样明确假设的东西。它不是那些形容词能保证的东西。
:::

:::intuition 平方根掩盖得没有人们以为的那么多
从相关系数$0.2$走到$0.9$，只把标准差从大约$0.077$移到大约$0.097$，看上去温和，而方差从$0.006$移到$0.0095$，一个$1.58$的因子。如果一个风险限额写在方差上，那条看上去温和的标准差曲线，已经跨过了回到单账簿方差$0.01$的那段差距的很大一部分。去读那个限额实际上点名的那个矩。
:::

:::history
理查德·格林诺德（Richard Grinold）与罗纳德·卡恩（Ronald Kahn）在*Active Portfolio Management*（2000年）里，把信号的合并当作一个协方差问题，把信息比率当作阅读一个结果的一种方式，而不是一条交易的指令。[[#prop-var]]里的等权恒等式是那种态度的那个二阶矩部件，剥掉了关于一个信息系数的任何主张。那本书不是一份把W01与W18混合起来的授权，那个恒等式也不是他们的公式抄进一个库内页面。

## 通向何处

这些计算停在研究日志处。[[research-craft/the-boundary]]说什么是不能加到它们上面的：一只证券、一个要去使用的权重、一家经纪商、一档杠杆、一笔实盘订单，或者一个已发表的曲线会重演的承诺。[[research-craft/comparing-implementations]]就是那两条年化复合增长率从一开始就不是[[#prop-avg]]的输入的原因。[[portfolio/long-only-and-neutral]]是权重约束住的地方，当那个对象真的是一篮资产的组合、而不是一对假想账簿的时候。

:::summary
- 账簿相关系数是两份规格说明的结果之间的相关系数，不是那些规格说明点名的那些资产之间的相关系数。
- 对两本方差相等为$\sigma^2$、相关系数为$\rho$的账簿，等权方差是$(\sigma^2/2)(1+\rho)$。
- 在$\sigma = 0.10$处，那个方差在$\rho = 0.2$时是$0.006$，在$\rho = 0.9$时是$0.0095$。标准差保留六位小数是$0.077460$与$0.097468$。
- 在这些账簿按$0.9$相关时使用$0.2$，把这个合并的方差低估一个因子$1.5833$，四位小数。
- 两个复合收益率的平均等于那个等权混合的复合收益率，只在特殊情形下。在那个两期间玩具里，两个数字是$-0.005$与$-0.0025$。
- W01已报告的年化复合增长率是跨$26$年的$+7.38\%$，W18的是跨$19$年的$+10.96\%$。它们的和与它们的平均都不是混合结果。
- 拥挤与衰减是假说。一个上升的相关系数或一个缩小的净结果不识别一个唯一的原因，也不是一个交易信号。
- 停止一份研究日志可以是事先写下的。它不是一张离开头寸的订单。
:::

## 习题

:::exercise 相关系数$0.2$处的方差 {level=1 check="0.006"}
两本账簿各有标准差$0.10$、相关系数$0.2$。输入等权的方差。
:::solution
$\Var(Z) = 0.005 \times (1 + 0.2) = 0.006$。这个输入不需要标准差。这些输入是假设，不是库内估计。
:::
:::

:::exercise 相关系数$0.9$处的方差 {level=1 check="0.0095"}
同样这两本账簿的相关系数改为$0.9$。输入等权的方差。
:::solution
$\Var(Z) = 0.005 \times 1.9 = 0.0095$。按[[#cor-mono]]，它必须超过那个在相关系数$0.2$处的方差。
:::
:::

:::exercise 完全相关的检验 {level=1 check="0.10"}
在$\sigma = 0.10$与$\rho = 1$时，输入等权的标准差。
:::solution
[[#cor-mono]]给出$\sigma$本身，所以标准差是$0.10$。当这些账簿是同一个随机变量时，等权处理不降低离散度。
:::
:::

:::exercise 相关系数$0.2$处的标准差 {level=2 check="0.077460"}
输入$\sqrt{0.006}$，保留六位小数。
:::solution
$\sqrt{0.006} = 0.07745966\ldots$，舍入为$0.077460$。这就是$\sigma\sqrt{(1+\rho)/2}$在那些说明的输入处的值。它小于$0.10$，而大于你在$\rho = -1$处会得到的那个零。
:::
:::

:::exercise 等权的两期间复合收益率 {level=2 check="-0.0025"}
使用账簿收益率先$0.10$后$-0.10$，以及先$0$后$0$，输入那个再平衡的等权合并的复合收益率。
:::solution
这个合并的各期间收益率是$0.05$与$-0.05$。倍数是$1.05 \times 0.95 = 0.9975$。复合收益率是$-0.0025$。那些各自复合收益率的平均，$-0.005$，正是[[#prop-avg]]存在就是为了逮住的那个陷阱。
:::
:::

:::exercise 错的相关系数低估得有多厉害 {level=2 check="1.5833"}
把$\rho = 0.9$处的等权方差除以$\rho = 0.2$处的等权方差。保留四位小数。
:::solution
$0.0095 / 0.006 = 1.58333\ldots$，四位小数是$1.5833$。如果$0.9$是账簿相关系数、而被插入的是$0.2$，那么被插入的那个方差按这个因子偏小。这个比值本身不是一个相关系数。
:::
:::

:::exercise 推导方差 {level=3}
从双线性推导$\Var\bigl((X+Y)/2\bigr) = (\sigma^2/2)(1+\rho)$，并说出那些假设。
:::hint
展开$\Var(aX + bY)$，取$a = b = 1/2$。把协方差换成$\rho\sigma^2$。不要假设独立性。
:::
:::solution
假设$\Var(X) = \Var(Y) = \sigma^2$、$\Cov(X,Y) = \rho\sigma^2$，且$Z = X/2 + Y/2$。那么

$$
\Var(Z) = \frac14\sigma^2 + \frac14\sigma^2 + 2\cdot\frac12\cdot\frac12\cdot\rho\sigma^2 = \frac{\sigma^2}{2} + \frac{\rho\sigma^2}{2} = \frac{\sigma^2}{2}(1+\rho).
$$

独立性会强制$\rho = 0$、方差$\sigma^2/2$，也就是$\sigma = 0.10$时的那个特殊情形$0.005$。这个推导不推荐权重$1/2$。
:::
:::

:::exercise 标题上的平均不是一个混合 {level=3}
计算$(0.0738 + 0.1096)/2$。然后说明为什么这个结果不是W01与W18的一个合并年化复合增长率。
:::hint
那些已报告的跨距是$26$年与$19$年。[[#prop-avg]]甚至在你被允许对复合数取平均之前，就需要对齐的期间收益率。那份库内摘录没有给出那些期间收益率。
:::
:::solution
$(0.0738 + 0.1096)/2 = 0.0917$。W01已报告的年化复合增长率是跨$26$年的$+7.38\%$，W18的是跨$19$年的$+10.96\%$，按quants.md对那些QuantJourney示例（Apache-2.0）的所报告，按2026年的阅读，而这里没有重跑。数字$0.0917$是把两个跨距不同的纯数取平均。它不是一个等权混合的复合收益率，因为这个混合的各期间收益率不在源里，而[[#prop-avg]]表明，即便对齐的复合收益率在一般情形下也不能取平均。那个和$0.1834$也不是一个年化复合增长率。
:::
:::
