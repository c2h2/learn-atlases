"移动平均趋势，股票交易所交易基金，大约四分之一个世纪"是一个故事，不是一份协议。开放库里有两张页面，一个粗心的摘要会把它们称为同一个故事。它们已报告的年化复合增长率相差$4.05$个百分点。这两张页面的差别不止一种原料，所以这个差距没有一个原因。本章先说这两个模式实际在算什么，然后把两行已报告的目录行放在一处，并拒绝单一原因的读法。

权重是净资产值的一个目标比例。订单是一条消息。这条消息可能被成交、被部分成交，或者根本没有成交。一个写下那个比例、又假定那个比例已经取得的回测，回答的问题与一个发出消息、把成交保留下来的回测不同。两个答案都不是券商，也都是持有某只基金、某个行业或某条移动平均线的建议。

## 完成流水线的两种方式

回想[[backtesting/the-backtest-as-an-experiment]]里的流水线：信号之后是一张映射，然后是成交，然后是头寸，然后是净资产值。权重模式与订单模式是两张映射，各自附带一个关于成交的故事。

:::definition 权重模式 {#def-weight}
**权重模式**把账簿换成一个在写明的再平衡时点上的目标权重向量。在本章的例子里，除非某句话另有说明，允许零碎持仓，账户按成交价盯市，没有费用，并且假定一次到目标的再平衡在那个价格上全额成交。再平衡之后的头寸，是那个目标权重所隐含的股数。一份不写明再平衡规则——每根K线、日历，还是漂移带——的权重模式报告，是一份不完整的协议。
:::

:::definition 订单模式 {#def-order}
**订单模式**提交消息。在下面这些例子里，市价单要求以点名的价格、点名的数量立即成交。限价单只要求以限价或更优的价格成交，而且它可能什么也得不到。现金按成交价乘以成交数量更新，而不是按目标权重更新。如果协议禁止借贷，一张超出可用现金的订单不会悄悄全额成交。例子允许时允许部分成交。头寸是累计成交数量，它未必等于信号索要的数量。
:::

库对这次分开自己的描述——为QuantJourney引擎（Apache-2.0）记录、按2026年的阅读——是权重模式设定目标权重，订单模式提交显式订单。本图谱没有重跑过那些示例。上面的定义是为接下来的算术使用的课堂版本。它们不是主张那个引擎的每一行都符合这里声明的简化，也不是发出任何一种订单的指令。

:::intuition 在有什么成交之前，一个目标只是一个愿望
净资产值可以写成$V = C + q P$：现金加上股数乘以一个盯市价。目标权重$w^\star$是关于$q P / V$的一个愿望。在[[#def-weight]]之下，权重模式凭假设满足这个愿望。订单模式只在消息被带回来已经成交的程度上满足它。有意思的失败，是那个假定为假、而报告照样打印$w^\star$的那些。
:::

## 打印出来的权重就是真实权重的时候

:::proposition 全额成交，错过的限价 {#prop-fillweight}
设净资产值为$V > 0$，盯市价为$P > 0$，现金为$C$，股数为$q$，满足$V = C + q P$。设没有别的头寸变动，允许零碎股，且没有费用。

如果一张$\Delta$股的市价单在盯市价$P$上全额成交，新的股数是$q' = q + \Delta$，现金变为$C - \Delta P$，而净资产值不变。选择

$$
\Delta = \frac{w^\star V}{P} - q
$$

产出新的权重$q' P / V = w^\star$。

而如果一张限价单没有成交，那么$\Delta = 0$，权重停留在$q P / V$处，而这只在账户本来就已经在那里时才等于$w^\star$。
:::

:::proof
在盯市价上全额成交之后，现金加持仓为

$$
(C - \Delta P) + (q + \Delta) P = C + q P = V.
$$

新的权重是$(q + \Delta) P / V$。令其等于$w^\star$并解出：$q + \Delta = w^\star V / P$，所以$\Delta = w^\star V / P - q$。这个数量在命题里允许零碎股的那句话之下是容许的。

如果限价单没有成交，$\Delta = 0$，恒等式$V = C + q P$分毫未动，所以权重就是成交前的权重。此时与$w^\star$的相等是一个关于过去的陈述，不是关于这张订单的陈述。
:::

这条命题是在声明过的假设之下的一条记账恒等式。它没有说市价单优于限价单，也没有说一半的目标是一个值得持有的组合。它说的是：一张在未成交的限价单之后照样打印目标的报告，跳过了第二段。

:::example 一张达到目标的市价单 {#ex-market}
净资产值是$1000$个记账单位，全部是现金，盯市价是$100$。目标权重是$0.5$。允许零碎股，市价单在$100$成交。发出的数量是多少，得到的权重是多少？
:::solution
[[#prop-fillweight]]里的公式给出$\Delta = 0.5 \cdot 1000 / 100 - 0 = 5$。现金变为$1000 - 500 = 500$。持仓按$5 \cdot 100 = 500$盯市。净资产值保持$1000$。权重是$500/1000 = 0.5$。目标之所以达成，是因为协议假定了在盯市价上全额成交。那个假定与$0.5$一样是这个结果的一部分。
:::
:::

:::example 一张从未成交的限价单 {#ex-miss}
同一个账户对[[#ex-market]]里的那五股发出一个$99$的买入限价单。协议说这张限价单只在价格以$99$或对买方更优的价格成交时才成交，而这根K线的最低价是$100$。成交数量是多少，权重是多少？
:::solution
最低价从未到达限价，所以成交数量是$0$，$\Delta = 0$。现金保持$1000$，股数保持$0$，权重保持$0$，不是$0.5$。一条实现本来是这张限价单的规则之下、一根K线上写$0.5$的权重模式行，是另一个实验。它把[[#def-order]]换成了[[#def-weight]]。错过成交不是偏爱市价单的理由。它是在读权重之前先点名订单类型的理由。
:::
:::

:::example 一笔部分成交，盯市偏离成交价 {#ex-partial}
从$1000$单位现金重新开始。一个$99$的买入限价单成交了$2$股。这根K线随后收在$100$，账户按收盘价盯市。权重是多少？
:::solution
现金支出$2 \cdot 99 = 198$，所以现金是$802$。持仓的盯市值是$2 \cdot 100 = 200$，不是$198$。净资产值是$802 + 200 = 1002$，比$1000$高出从成交价到收盘价的两个记账单位的盯市增益。权重是$200/1002 = 100/501$，保留六位小数为$0.199601$。它不是$0.5$，也不是$198/1000$。盯市价与成交价是两个不同的价格。把这句话省掉，会产出第三个权重。
:::
:::

还有两个约束很容易被省略，因为按单个目标定义的权重模式从来碰不到它们。

一条整股规则是协议的一次改动。目标名义额$500$、价格$30$，是$500/30 = 16.\overline{6}$股。如果规则向下舍入到整股、并且拒绝超过目标名义额，账户买入$16$股，名义额$480$，权重$480/1000 = 0.48$。四舍五入到最近的整股会买$17$股、花掉$510$、权重$0.51$，那就破坏了"不许超过"那句话。权重$0.48$是这条规则做到了的事。它不是报告里的一个舍入误差。它就是报告本身。

现金约束是另一个改动。设净资产值为$1000$，其中$700$是在这份协议里不许卖出的持仓，$300$是现金。新资产盯市为$50$，禁止借贷，并且不许任何其他卖出。你能花的最多是$300$，即$6$股、权重$0.3$。一条把新权重设为$0.5$、却不说是哪个别的权重落下来的权重模式指令，是一份不完整的协议。如果融资靠的是卖出已有的持仓，那笔卖出就是第二张订单，或者第二个目标，它应该写进说明。订单模式让缺失的现金看得见，因为一条消息花不出那一行现金所没有的东西。

:::remark 融资是映射的一部分
从信号到权重的恒等映射——[[backtesting/the-backtest-as-an-experiment]]里在路径A上使用的那一张——从来不必去筹现金：权重是收益率公式$w_t R_t$里的一个数字，不是资产负债表上的一行股数。它之所以是一份正当的协议，只是因为它说清楚了。一旦实验声称自己是单个账户里的一张订单，[[#prop-fillweight]]与现金检查就开始适用。把两种语言混在同一段里，就是$0.5$的一个目标在一笔什么都没买到的限价单之后幸存下来的方式。
:::

在一张没有成交的限价单之后，账户的权重是下列哪一项？

- [x] 成交前的权重
- [ ] 零，因为一张未成交的订单会取消头寸
- [ ] 如果目标是二分之一，就是一半
:::solution
取$\Delta = 0$的[[#prop-fillweight]]让$q$与$C$都不变，所以权重停在原地。照样打印目标，是权重模式，不是这张限价单的描述。

## 两条库内行，和一个没有单一作者的差距

本章欠你的比较，在两条目录行之间。下面两组数字都是按quants.md上对那个QuantJourney示例（Apache-2.0）的报告，按2026年的阅读。本图谱没有重跑过其中任何一个回测。两行都不是预测，也都不是可买的基金。

O01，"Market SMA Cross"：当$20$日简单移动平均上穿$50$日均线时买入，反向交叉时卖出，使用市价单，标的是股票交易所交易基金，日频K线，跨距$25$年。已报告的总收益率是$+126.66\%$，已报告的年化复合增长率是$+3.33\%$，已报告的夏普比率是$0.21$，已报告的最大回撤是$-16.35\%$，已报告的胜率是$51.9\%$，已报告的盈亏比是$2.18$。

W01，"Daily SMA Trend"：只要$50$日均线高于$200$日均线，就持有每只行业交易所交易基金，并按日再平衡，日频K线，跨距$26$年。已报告的总收益率是$+537\%$，已报告的年化复合增长率是$+7.38\%$，已报告的夏普比率是$0.45$，已报告的最大回撤是$-34.7\%$，已报告的胜率是$72.6\%$，已报告的盈亏比是$2.48$。

已报告的年化复合增长率相差$7.38 - 3.33 = 4.05$个百分点。已报告的回撤也不同：W01已报告的那个坑更深。一个更高的已报告增长率坐在一个更深的已报告回撤旁边，已经足够叫停一个词的分高下。而且还不止，因为这些协议至少同时在四处不同。

- 窗口是$20/50$对$50/200$。一短一长是两种不同的特征，不是"趋势"的两种拼法。
- 实现是一次交叉上的市价单，对上一条快均线高于慢均线期间持有的每日目标权重。那是[[#def-order]]对[[#def-weight]]，而且是一次交叉对一条持有规则。
- 跨距是$25$年对$26$年。年化复合增长率不会抵消一个不同的窗口；它只是给页面实际拥有的那条路径重新定标。
- 账簿是在股票交易所交易基金上的一次交叉，对上一本逐名字持有的行业账簿。O01的目录行没有写"一个代码"，本图谱也不会替一行没有写明的样本池发明样本池。我们会说：一本按日再平衡的行业账簿，与一次用市价单交易的交叉，不是同一个设计。

本图谱拒绝把这$4.05$个百分点的差距归因于权重模式，或归因于更长的均线，或归因于多出来的那一年，或归因于行业账簿。四扇门都开着。关上其中三扇将是一个新的实验，而本图谱没有跑过它。把W01称为"O01在权重模式下本来会有的样子"，恰恰是[[#prop-fillweight]]禁止的那句话：它打印了一个协议没有分离出来的目标。同样的拒绝在反方向也适用。O01更浅的已报告回撤不是市价单的奖品。

已报告的夏普比率$0.21$与$0.45$，就是它们已报告的夏普比率。本图谱没有核实那些列里面的年化约定或无风险收益率，也不把它们换算成课堂路径上使用的单步比率。胜率在"赢"按同一个单元定义之前是不可比的。订单日志里一笔交易的赢，不是权重日志里一天的赢。$2.18$与$2.48$这两个盈亏比继承了这重含混。

:::warning 形容词不是对照
"两者都是移动平均的趋势检验"是一个标签，不是一对配好的对照。一对配好的对照会共享样本池、窗口、跨距、成本模型与时钟，只改动一个阶段。这两张页面共享的是家族相似。家族相似认不出原因。如果你需要一个地方把两份规格说明并排写下来当文档做，那个练习是[[research-craft/comparing-implementations]]。目标权重的算术——而不是到不了目标的订单——在[[portfolio/from-signal-to-weight]]里继续。
:::

:::example 什么才算一个原因 {#ex-cause}
纯作为一个设计、而不是一个报告来设想：第三个实验重复O01的样本池、跨距、窗口与时钟，只把"一次交叉上的市价单"这句话改成"等于同一个交叉信号的每日权重"。那$4.05$个百分点的目录差距，会归因于这句话吗？
:::solution
不会，就凭上面那两行不行。那两行还改了窗口、跨距与账簿。这个想象中的第三个实验是正确的问题形状，而它的结果不是本图谱拥有的一个数字。在它跑出来之前，已报告的$+3.33\%$与已报告的$+7.38\%$之间的差距，仍然是两个协议之间的差距。把任何一个数字引作"那个"移动平均的结果，就是本章存在所要命名的错误。
:::
:::

## 通向何处

这些权重与订单被允许使用的时钟是[[backtesting/timing-costs-and-biases]]。市价单与一张可能错过的限价单，作为消息而不是作为模式，在[[orders/market-and-limit-orders]]中被写明。把两条库内行写成完整的规格说明——而不是写成对单一原因的警告——是[[research-craft/comparing-implementations]]。

:::summary
- 权重模式在一个写明的再平衡规则之下设定目标比例。在本章的主要命题里，允许零碎持仓，并假定在盯市价上全额成交。
- 订单模式提交消息。一张没有成交的限价单把成交前的权重留在原地。
- 净资产值$1000$、盯市价$100$时，买入五股并全额成交的市价单达到$0.5$的目标权重。同一个目标作为$99$的限价单发出、最低价是$100$时，什么也达不到，权重停在$0$。
- 一笔两股、成交价$99$、盯市$100$的部分成交，权重是$100/501$，不是$0.5$。
- 向下舍入到整股把$0.5$的目标变成了$0.48$。一本$1000$的账簿里$300$的现金上限，把$0.5$的愿望变成了至多$0.3$。
- O01报告跨距$25$年的年化复合增长率$+3.33\%$；W01报告$26$年的$+7.38\%$。这$4.05$个百分点的差距没有归因于某一个原因。
- 这两张页面还在窗口（$20/50$对$50/200$）、订单对权重、一次交叉对一个行业账簿上不同。已报告的夏普比率原样保留，仍是已报告的夏普比率。
:::

## 习题

:::exercise 全额成交 {level=1 check="0.5"}
净资产值是$1000$个记账单位，全是现金，盯市价是$100$。一张市价单在$100$买入$5$股并全额成交。输入得到的权重。
:::solution
持仓是$500$，现金是$500$，所以权重是$500/1000 = 0.5$。这是[[#prop-fillweight]]在$w^\star = 0.5$下的结论，不是持有任何资产一半的建议。
:::
:::

:::exercise 错过的限价单 {level=1 check="0"}
上一题里的账户改为发出一个$99$的买入限价单。这根K线的最低价是$100$，而协议只在$99$或更优时成交这张限价单。输入这根K线之后的权重。
:::solution
什么都没成交。股数保持$0$，权重保持$0$。
:::
:::

:::exercise 整股，向下舍入 {level=1 check="0.48"}
目标名义额是一本$1000$的账簿里的$500$个记账单位。价格是$30$。规则买入名义额不超过$500$的最大整股数。输入权重。
:::solution
$500/30 = 16.\overline{6}$，不超过它的最大整数是$16$。名义额是$480$。权重是$480/1000 = 0.48$。买$17$股会花掉$510$，破坏给你的那条规则。
:::
:::

:::exercise 现金上限 {level=2 check="0.3"}
净资产值是$1000$，现金是$300$，其余是这份协议不许卖出的持仓。禁止借贷。新资产盯市为$50$。输入现金能买到的最大权重。
:::solution

:::exercise 解出市价单的数量 {level=3}
推导[[#prop-fillweight]]里的股数$\Delta$。说出你用到的每一个假设，并说一张错过的限价单把论证留在了哪里。
:::hint
在盯市价上的成交让现金与持仓变动等量而反向，所以净资产值不变。令新持仓的盯市值等于$w^\star V$。
:::
:::solution
设$V = C + q P$，其中$P > 0$且$V > 0$，允许零碎股，无费用，没有别的头寸变动，并在用作盯市值的同一价格$P$上全额成交。于是新现金是$C - \Delta P$、新股数是$q + \Delta$，而两个$\Delta P$项相消，所以净资产值保持$V$。新的权重是$(q + \Delta) P / V$。令其等于$w^\star$并整理，得$\Delta = w^\star V / P - q$。如果这张订单是一张没有成交的限价单，推导在第一步就停下了：$\Delta$轮不到你来选，它是$0$，而权重保持$q P / V$。
:::
:::
