一分钟K线是同一类问题的一个更小的容器，不是更大的一份独立证据的样本。这些K线的六天，仍然是六天。开放库里有五个页面画在比日K线更细的K线上，跨距以天或以周计，而不是以年计。每一页报告一个样本收益率与一个最大回撤。每一页都把年化复合增长率留白，也把夏普比率、胜率与盈亏比一并留白。那个空白，正是一个小心的读者理应注意到的那个结果。把它填上，就是本章要对付的那个错误。

下面的内容没有一样是建议你在日内交易、建议在五分钟K线与小时K线之间偏好前者、或建议你对一个亏过钱的页面取对面。库里的亏损是功课的一部分。它不是一个把规则反过来的信号。那些页面是QuantJourney示例（Apache-2.0），按quants.md的报告，按2026年的阅读。本图谱没有重跑过它们。

## K线改变什么，不改变什么

:::definition 跨距与K线根数 {#def-span}
一次检验的**跨距**是样本的日历长度，以论断所需要的单位来计。关于一天的论断用天。关于一年的论断用年。**K线根数**是文件里的行数。一个一分钟文件在单独一天里就可以有几百行。那些行共享当天的开盘、当天的消息与当天的收盘。它们不是一个日频实验的几百份独立复制。在同一段跨距上选出的参数，不是那段跨距的一次新鲜观测。
:::

更细的K线改变你看得见的机制。一个几个十分之一个百分点的括号单，在日收盘上是看不见的。一个挂在十二根K线高点之上的止损，在三十分钟K线上意味着一回事，在日K线上意味着另一回事，因为"十二根K线"是一段不同的时间。[[backtesting/timing-costs-and-biases]]里的合法乘积不会因为K线短就放松。一个带着分钟$t$时间戳的特征可以使用直到第$t$分钟的价格，而它挣的是第$t$分钟之后的收益率。一分钟文件上的同根K线乘积仍然是一个同根K线乘积。时钟感觉更精确了。罪名没有变。

细K线不改变的东西，是跨距。把一段以天计的跨距年化，就是把一个嘈杂的总收益率当作了一年，而那个重缩放的代数就是下面这条命题。库在这五个页面上的回应，是把年化复合增长率留作未报告。本图谱不会去发明那个缺失的单元格。

## 五个页面，作为机制来读

本节的数字只是LIBRARY.md记录的数字。单元格是"—"的地方，目录没有报告那个统计量。"—"不是零，也不是一声邀请。

W08，"Intraday EMA Scalp 1m"，是一对指数移动平均，$9$与$21$，在一分钟K线上被当作一条趋势或现金规则来用。跨距是$6$天。被报告的样本收益率是$-0.2\%$。被报告的最大回撤是$-0.2\%$。年化复合增长率、夏普比率、胜率与盈亏比都是未报告。两个$-0.2\%$说的是：在该页面使用的那些盯市时点上，路径结束在它的最差峰谷所坐的那个位置。它们没有说这条规则有一个稳定的日亏损，也没有说亏损小到可以忽略。它们说，这一页给你看的是一个星期，不是一段职业生涯。

W07，"Intraday RSI 15m"，在相对强弱指标超卖时持有一个等权篮子，十五分钟K线，跨距$3$个星期。被报告的样本收益率是$+2.6\%$。被报告的最大回撤是$-1.1\%$。目录行没有给出超卖阈值的数值。本图谱不会从另一个页面抄一个阈值、然后把它安到W07头上。增长率、夏普比率、胜率与盈亏比都是未报告。一个为正的几个百分点的样本收益率，旁边摆着一个大约一个百分点的回撤，跨三个星期，是对那个窗口的一段描述。它不是一个优势。

W09，"Intraday SMA Trend 1h"，是一对简单移动平均，$10$与$30$，趋势或现金，小时K线，跨距$9$个星期。被报告的样本收益率是$+1.5\%$。被报告的最大回撤是$-3.5\%$。回撤大于样本收益率，这是允许的：一条路径可以收高，而中途曾经下跌得更多。年化复合增长率与其余的比率都是未报告。九个星期不是一小时趋势的一个长样本。它们就是九个星期。

O15，"Intraday Bracket Reversion 5m"，在RSI回落时入场，并挂上一张$+0.6\%$与$-0.4\%$的括号单，五分钟K线，跨距$4$个星期。被报告的样本收益率是$+1.1\%$。被报告的最大回撤是$-1.3\%$。其余的比率列是未报告。这一行能教的，是一张括号单的形状：围绕一个入场的两段距离，互不相等。它不能教的，是那些距离是不是一个好主意。那张订单，作为一张订单，与其余的日内订单页面一起在[[orders/lots-contracts-and-intraday]]里讨论。本章感兴趣的是跨距。

O16，"Intraday Stop Breakout 30m"，在一个挂在12根K线高点之上的止损上买入，并持有一段固定的时长，三十分钟K线，跨距$8$个星期。被报告的样本收益率是$-13.9\%$。被报告的最大回撤是$-14.8\%$。其余的比率列是未报告。八周的窗口上那么大的亏损，是已发表图景的一部分。它不是一个年化复合增长率，因为该页面没有报告一个。它也不是发出相反订单的理由。一个短样本亏损的对面是另一个实验，而"取对面"会是一条本课程不给出的建议。那一行确实记录下来的机制，是一个挂在向前数十二根三十分钟K线的高点之上的止损，后面跟着一个被一行式描述称为固定的持有期。若时段是连续的，十二根K线就是六个小时。库里的时段是否连续，那一行式描述没有说，所以本图谱不断言它。K线根数口径下的回看期是事实。在一份协议这么说之前，小时数不是。

:::example 六天里有几天 {#ex-days}
W08的跨距是$6$天。如果你在乎的采样单位是天，而且那些天里没有一个参数被选定，那个页面包含几个独立的天？如果一场对规则的搜索在这同样的六天上被计过分，还剩下几个新鲜的天留作证据？
:::solution
没有搜索时，计数是$6$。天与天仍然可以是相依的，所以$6$是独立日观测的一个上界计数，不是独立性的保证。它已经远远低于一个一分钟文件的K线根数。如果这条规则，或它内部的一个阈值，是因为在这六天上看上去最好才被选出来的，新鲜计数就是$0$。这些天已经花在选择上了。[[#def-span]]就是那个区分：在跨距上拟合的参数不是那段跨距的第二份复制。就本图谱拥有的那条目录行而言，页面本身没有报告一场搜索。那个零，是当真有过一场搜索时你必须写下的数。它不是对W08做过搜索的指控。
:::
:::

:::example K线不是天 {#ex-bars}
只把本习题当作一个计数约定：一个$390$根一分钟K线的时段，也就是一个六个半小时的现金股票交易日的长度。这个约定不是关于W08的交易场所或日历的断言。$6$个时段是多少根一分钟K线，而那个数字为什么不是一个关于日的论断的样本量？
:::solution
$6 \times 390 = 2340$根K线。一个关于日的论断——比如"这条规则一天大约输掉五分之一个百分点"——在这段跨距里至多有$6$个观测，而不是$2340$个。那$2340$行共享六个开盘与六个收盘。把它们当作一个日频优势的$2340$次独立抽取，就是把一个标准误除以$\sqrt{2340}$，而不是除以一个不超过$\sqrt{6}$的数。这两个除数之比是$\sqrt{2340}/\sqrt{6} = \sqrt{390} \approx 19.75$，所以在那个粗糙的比较上，按K线根数算的标准误大约小了$19.75$倍。合法的回应不是一个修正过的夏普比率。W08没有报告夏普比率。回应是拒绝把K线根数当作样本量。
:::
:::

## 填上空白的函数，以及它为什么不该

设$R > -1$是一段$y$年期限上的总简单收益率，$y > 0$，并定义朴素年化

$$
A(R) = (1 + R)^{1/y} - 1.
$$

若$y = 1$，则$A(R) = R$：一年的总收益率本来就是一个年度数字。若$y$是一年的一小部分，$A$会把$R$放大。库的年化复合增长率，在它报告一个的时候，是它自己的一列，处在一个本图谱没有重新推导过的约定之下。$A$不是那一列。$A$是一个读者忍不住想贴进空白单元格的函数。

:::proposition 朴素年化的斜率 {#prop-annual}
固定$y > 0$，并对$R > -1$令$A(R) = (1+R)^{1/y} - 1$。则

$$
A'(R) = \frac{1}{y} (1+R)^{1/y - 1},
$$

且$A'(0) = 1/y$。若期限是一个$252$天之年里的$d$个交易日，即$y = d/252$，则$A'(0) = 252/d$。
:::

:::proof
设$u = 1 + R > 0$。则$A = u^{1/y} - 1$。对$R$求导，并使用$du/dR = 1$，

$$
\frac{dA}{dR} = \frac{1}{y}\, u^{1/y - 1} = \frac{1}{y} (1+R)^{1/y - 1}.
$$

在$R = 0$处，$1$的幂是$1$，所以$A'(0) = 1/y$。代入$y = d/252$得$1/y = 252/d$。这个导数是关于函数$A$的一个事实。它不是一个抽样分布，也不是一张许可证，允许在目录的单元格为空时把$A(R)$当作年化复合增长率来报告。
:::

:::corollary 六天的斜率 {#cor-six}
在[[#prop-annual]]的$252$天约定之下，一段$6$个交易日的跨距有$A'(0) = 42$。一个大小为$\varepsilon$的收益率误差，在零附近，会在年化函数里被放大约$42$倍。
:::

:::proof
$252/6 = 42$，而[[#prop-annual]]说$A'(0) = 252/d$。
:::

同一个约定，每一次都写出来、好让它保持为一个约定，给出$252/15 = 16.8$——若三个星期的跨距被当作$15$个交易日——$252/45 = 5.6$——若九个星期是$45$个交易日——$252/20 = 12.6$——若四个星期是$20$个交易日——以及$252/40 = 6.3$——若八个星期是$40$个交易日。与$1$相比，这些斜率都是大的，而$1$正是一年期限的$A'(0)$。库的五个跨距都坐在大的那一边。这就是空白单元格才是保守的那个对象的原因，也是"库忘了那个年化复合增长率"是错误的描述的原因。库扣下了一个跨距支撑不起的数字。

:::example 放大器，用一次，而且不是一个结果 {#ex-amp}
W08报告了一个$-0.2\%$的样本收益率，按小数是$-0.002$，跨距$6$天。用$y = 6/252$计算$A(-0.002)$，并说出这个数字不是什么。
:::solution
$1/y = 42$，所以$A(-0.002) = (0.998)^{42} - 1 = -0.080646$，保留六位小数。在零附近，导数$42$本来会提示$42 \times (-0.002) = -0.084$，而$A$的精确值要温和一点点，因为$(1+R)^{42}$并不完全线性。数字$-0.080646$是函数$A$在被报告的样本收益率处的取值。它不是一个年化复合增长率。它不是一个库内数字。它不会被写进W08的空白单元格。本图谱不会为W07、W09、O15或O16计算同样的装饰。一个放大器就够看清那个斜率了。五个假的年化会看起来像一列。
:::
:::

:::warning 不要把那一行补完
一个把$A(R)$发表到W08旁边的读者，发明了一个目录拒绝给出的统计量，用的还是一个目录没有写明的天数约定。$252$天一年是我们为那个导数设立的约定，不是关于那一页的一个发现。被报告的对象是样本收益率$-0.2\%$与最大回撤$-0.2\%$，跨距$6$天，一分钟K线，规则是一对长度为$9$与$21$的指数移动平均。那就是那一行全部的定量内容。机制是那对长度，以及趋势或现金的二者择一。证据不在那里。
:::

:::algorithm 读一行短样本 {#alg-short}
1. 按页面使用的单位读跨距：天或星期。不要把它换算成一个年化复合增长率。
2. 读K线尺寸。用它来理解规则的回看期，而不是把它当作样本量的乘数。
3. 只抄那一行真正打印出来的统计量。如果增长率、夏普比率、胜率或盈亏比是一道"—"，就写"未报告"。
4. 说出那一行式规则点名了什么机制：一张括号单、一个挂在高点之上的止损、一对移动平均、一个振荡指标超卖时的篮子。
5. 说出该页面支撑不起什么：一个优势、一个夏普比率、一个年化复合增长率，或者一个取亏损对面的决定。
6. 如果你把$A(R)$当作[[#prop-annual]]里的一次练习算了出来，就把它标注为$A$的取值，并把它留在表外。
:::

## 通向何处

一个短页面用与长页面相同的清单来读，那在[[backtesting/reading-published-tests]]。坐在其中一些规则内部的括号单、止损与整张合约的约束，作为订单在[[orders/lots-contracts-and-intraday]]里被写明。一分钟特征仍然不得不服从的那个时钟，是[[backtesting/timing-costs-and-biases]]。

:::summary
- K线根数不是跨距。一段六天的一分钟文件就是六天，无论它装着多少行。
- W08报告$-0.2\%$与最大回撤$-0.2\%$，跨$6$天的一分钟K线。W07报告$+2.6\%$与$-1.1\%$，跨$3$个星期的十五分钟K线。W09报告$+1.5\%$与$-3.5\%$，跨$9$个星期的小时K线。
- O15报告$+1.1\%$与最大回撤$-1.3\%$，跨$4$个星期的五分钟K线，配一张$+0.6\%$与$-0.4\%$的括号单。O16报告$-13.9\%$与$-14.8\%$，跨$8$个星期的三十分钟K线。
- 在全部五个页面上，年化复合增长率、夏普比率、胜率与盈亏比都是未报告。那些空白保持空白。
- 在一个$252$天的约定之下，朴素年化在零收益率处的导数是$252/d$。对$6$天来说，那个斜率是$42$。那个函数的取值不是一个库内年化复合增长率。
- 这些页面能展示一条规则在细K线上的形状。它们不能展示一个优势，而一个亏损也不是一声取对面的指令。
- 本图谱没有重跑过那些页面。那些数字是目录的，按2026年的阅读。
:::

:::exercise 空白不是零 {level=1 check="0"}
O15的年化复合增长率单元格是空的。若本图谱把那格当作未报告，输入$0$；若它把空白当作一个报告过的、为零的增长率，输入$1$。
:::solution
空白是未报告。输入是$0$，意思是"未报告"，不是意思是增长率为零。O15被报告的样本收益率仍然是跨$4$个星期的$+1.1\%$，那是另一个对象。

:::exercise 三个星期作为一个斜率 {level=2 check="16.8"}
把W07的$3$个星期的跨距当作一个$252$天之年里的$15$个交易日。输入$A'(0)$，保留一位小数。不要把W07被报告的收益率年化。
:::solution
$252/15 = 16.8$。那个斜率说的是，一个很小的总收益率在零附近会被放大约$16.8$倍。W07被报告的样本收益率是$+2.6\%$，被报告的最大回撤是$-1.1\%$，而它的年化复合增长率是未报告。要输入的数字是$16.8$，它是$1/y$，不是一个增长率。
:::
:::

:::exercise 八个星期作为一个斜率 {level=2 check="6.3"}
把O16的$8$个星期的跨距当作一个$252$天之年里的$40$个交易日。输入$A'(0)$，保留一位小数。
:::solution

:::exercise 把年化求导 {level=3}
对$A(R) = (1+R)^{1/y} - 1$导出$A'(R)$，其中$y > 0$固定而$R > -1$。在$R = 0$处求这个导数。
:::hint
设$u = 1+R$，用链式法则对$u^{1/y}$求导。
:::
:::solution
设$u = 1+R > 0$，则$A = u^{1/y} - 1$。于是$dA/dR = (1/y)\, u^{1/y - 1} \cdot 1 = (1/y)\, (1+R)^{1/y - 1}$。在$R = 0$处，$1$的幂是$1$，所以$A'(0) = 1/y$。若$y = d/252$，这就是$252/d$。这个推导假设$y$固定，且$R > -1$以保证$u$保持为正。它没有假设$R$是一个库内收益率，而$A$在一个短样本收益率处的取值，也不是一个目录出于疏忽而扣下的年化复合增长率。
:::
:::

:::exercise 一场搜索会花掉样本 {level=3}
假设一条指数移动平均规则里的长度$9$与$21$，是因为在若干对之中，它们在一个特定的六天文件上造出了最不坏的结果才被选出来的。那些天里还剩几天，作为被选定那一对的证据？用[[#def-span]]的语言解释。这不是说W08以那种方式选过它的长度。
:::hint
用来挑规则的那一天，不能被重新用作对你挑中的那条规则的一次未经触碰的检验。
:::
:::solution
一天也不剩。那六天是这次选择被计分所依据的跨距，所以新鲜计数是$0$。[[#def-span]]说，在跨距上选出的参数不是那段跨距的一次新观测。W08的目录行没有报告这样一场搜索；本习题是一个反事实。把被选定那一对的$-0.2\%$报道得好像那两个长度是事先定好的，会夸大六天所能确认的东西。合法的说法是：如果那些长度是在这些天上被搜索的，这些天就不能确认它们。
:::
:::
