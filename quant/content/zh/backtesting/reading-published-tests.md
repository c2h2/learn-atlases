年化复合增长率那一列里的数字，是最后才读的东西。在它之前，页面其实已经告诉过你——有时靠它打印的东西，有时靠它留白的东西——样本有多长、什么被允许算作一笔成交、一次"胜"有没有被定义，以及作者是不是已经警告过你：一堆折是一堆诊断，而不是一堆独立的实验。读一份已发表的检验，工作是先把那份协议找回来，然后再把那个形容词复述到增长率旁边。本章不重跑那五十个库页面。它也不信任它们。它们仍然是QuantJourney示例（Apache-2.0），按quants.md的报告，按2026年的阅读。

一页纸可以写得谨慎，却依然容易被读过头。四十八折感觉像四十八次确认。$100\%$的胜率感觉像错误的缺席。两位数的增长率感觉像一份已经把回撤吸收进去的摘要。这些感觉，没有一个在下面这份清单里占一步。

## 没有代码也能用的清单

:::definition 阅读清单 {#def-check}
对一份已发表回测的**阅读清单**，按顺序问：

1. **跨距。** 样本有多长，以一个论断撑得起的单位计？天与星期支撑不起一个年化复合增长率；库里几行日内页面是故意把那格留白的，[[backtesting/intraday-samples]]对此有记录。
2. **时钟。** 一个日期为$t$的特征，挣的是$t$之后的收益率，还是结束在$t$的那个收益率？如果页面没有说，时钟就是未经审计的，而不是已被确认的。
3. **成本。** 有没有写明一个成本模型，包括那个数字与它所乘的换手？沉默不是零。一个写明的零是一个零。
4. **样本池。** 在每个决策时点，哪些名字有资格入选，退市的名字有没有为它们存在过的那些日期被保留下来？
5. **配置。** 在打印出来的那一条被选定之前，有多少条规则、窗口或阈值被计过分？单独打印的一行，本身不是一个"一"的计数。
6. **获胜的单位。** 在页面说明一次"胜"是一张交易、一天、一个名字还是一次再平衡之前，胜率是没有意义的。
7. **页面自己的标签。** 如果页面把输出称为切片诊断，或者否认那些折是独立的样本外证据，那句话就是结果的一部分。它凌驾于净值曲线的气氛之上。

清单回答的是页面支撑得起什么。它不产出一个替代的统计量，也不产出一笔交易。
:::

:::algorithm 应用清单 {#alg-read}
1. 照抄跨距、K线尺寸与每一个被报告的统计量，包括一个回撤的符号。
2. 在那一行没有包含的任何一列旁边写"未报告"。不要塞进一个零、一个约定或一个从邻近页面算出来的数。
3. 列出你看得见的协议差异，以及你看不见的协议句子。一个看不见的时钟是审计里的一处缺口，不是一次通过。
4. 如果页面自己限制了那些折可以怎么读，就用平实的语言引用那条限制，然后停下。不要因为跨距长，就把一个诊断升格为证据。
5. 如果有若干个配置被计过分，先说这件事，再说赢家的增长率。下面那条命题就是理由。
6. 把一个大的被报告增长率与一个大的被报告回撤分开。它们是两列。一列不抵消另一列。
:::

## 两股纯粹噪声里的最优者

清单上的配置那一行摆在那里，是因为若干个噪声分数的最大值有一个为正的期望，即使每一个真实均值都是零。下面的模型是让那句话成为一个定理的最小的模型。它不是一个可以贴到目录页上的修正因子。

:::proposition 两个噪声均值的期望最大值 {#prop-max}
设$Z_1$与$Z_2$独立，各自服从$\Normal(0, \tau^2)$分布，$\tau > 0$。则

$$
\E\bigl[\max(Z_1, Z_2)\bigr] = \frac{\tau}{\sqrt{\pi}}.
$$
:::

:::proof
对任意两个数，$\max(z_1, z_2) = (z_1 + z_2)/2 + |z_1 - z_2|/2$。取期望，并使用$\E[Z_1] = \E[Z_2] = 0$，

$$
\E\bigl[\max(Z_1, Z_2)\bigr] = \frac{1}{2}\, \E\bigl|Z_1 - Z_2\bigr|.
$$

独立性给出$\Var(Z_1 - Z_2) = \Var(Z_1) + \Var(Z_2) = 2\tau^2$，所以$Z_1 - Z_2$是均值为$0$、方差为$2\tau^2$的正态变量。

剩下的是计算$W \sim \Normal(0, \sigma^2)$的$\E|W|$。由对称性，

$$
\E|W| = \int_{-\infty}^{\infty} |w|\, \frac{1}{\sigma\sqrt{2\pi}}\, e^{-w^2/(2\sigma^2)}\, dw = \frac{2}{\sigma\sqrt{2\pi}} \int_0^{\infty} w\, e^{-w^2/(2\sigma^2)}\, dw.
$$

换元$u = w^2/(2\sigma^2)$，于是$du = w\, dw / \sigma^2$而$w\, dw = \sigma^2\, du$。积分限保持$0$与$\infty$。积分变成

$$
\frac{2}{\sigma\sqrt{2\pi}} \cdot \sigma^2 \int_0^{\infty} e^{-u}\, du = \frac{2\sigma}{\sqrt{2\pi}} = \sigma \sqrt{\frac{2}{\pi}}.
$$

这里$\sigma = \tau\sqrt{2}$，所以$\E|Z_1 - Z_2| = \tau\sqrt{2} \cdot \sqrt{2/\pi} = 2\tau/\sqrt{\pi}$。它的一半是$\tau/\sqrt{\pi}$。

假设是：独立性、公共的方差、每个估计量的期望为零，以及报告最大值而不是两者之中事先指定的那一个的习惯。如果这两个分数是在同样的价格上拟合出来的，它们就不会独立，而那个公式也不能当作一个数来套用。定性的警告仍然成立：选择把被报告的均值往上推。这条命题没有为任何库页面估计过那个推动的量。
:::

:::example 玩具的一个数值规模 {#ex-tau}
取$\tau = 0.01$，它是一个均值的标准差，不是一个收益率预测。$\E[\max(Z_1, Z_2)]$保留六位小数是多少，而一个无视选择的读者会报告什么？
:::solution
$\E[\max] = 0.01/\sqrt{\pi} = 0.00564189\ldots$，保留六位小数为$0.005642$。每个真实均值都是零。一个打印赢家的均值、就好像它是唯一被尝试过的规则的读者，打印出的是一个期望约为五十六个基点的数字——以$\tau$的计量单位计——而不是零。这个数字是两个独立正态估计量的一个性质。它不是一个夏普比率，也不是一个预测。如果协议在看到两个分数之前就点名了规则，那么在这个模型之下，被报告均值的期望本来会是零。清单的配置那一行，就是区分那两份协议的那个问题。
:::
:::

WF04，一句话、到此为止，给$9$个移动平均窗口的组合计分，每一个都按一次回测的夏普比率，跨距$26$年。计数$9$就是[[#def-check]]要你写下来的东西。本章不把[[#prop-max]]从两个独立正态变量扩展到那九个相依的夏普比率。那个扩展是另一条定理，而那场搜索在[[validation/parameter-search]]里处理。收缩（deflated）夏普比率在[[validation/the-deflated-sharpe]]。提到那个计数，就是这里义务的全部。

:::quiz
在[[#prop-max]]之下，两个独立的零均值估计量被计分，较大的那个被报告。报告的期望是下面哪一项？
- [ ] 零，因为每个估计量的期望都是零
- [ ] $\tau$，标准差本身
- [x] $\tau/\sqrt{\pi}$，它是正的
- [ ] 两个真实均值中较大的那个，而两者都是零，所以是零
:::solution
估计量的最大值，在你已经选定它之后，就不再是零的一次无偏报告了。证明把那个期望归约到期望绝对差的一半，即$\tau/\sqrt{\pi} > 0$。报告一个事先指定的估计量而不是较大的那一个，本来会把期望保持在零。
:::
:::

## 页面已经怎样说起它的折

WF01，"Rolling Walk-Forward Validation"，是$48$折：滑动的定长训练与测试窗口，在每一段样本外切片之前带一次清洗（purge），跨距$26$年。目录写明：该页面把这些称为切片诊断，而非独立的样本外证据。同样的告诫也挂在库里其余的走步验证行上。就本图谱拥有的WF01那一行而言，它不报告收益率、年化复合增长率、夏普比率或回撤。那些缺席不是要从W01或任何别处填上的洞。

应用[[#alg-read]]。跨距是长的，$26$年，日历长度足够让一个增长率成为一个有定义的路径统计量——*前提是该页面打印过一个，并把它作为一次单独的检验提供出来*。页面没有。它打印了$48$折，外加一条关于它们该怎么读的限制。算法的第$4$步在这里停下。四十八是切片的数目。它不是独立实验的数目。把这些折称为独立的样本外证据，会与该页面自己的那句话相矛盾。本图谱不会那么做，也不会发明一个那一行没有包含的合并夏普比率。

相依性就是页面那份谨慎形状恰当的原因，哪怕还没有引用它。滑动的测试窗口是一条历史路径的碎片。即使测试窗口互不重叠，它们也是同一样本的有序切片，暴露于同样的市场；而在一条规则是在相关的训练数据上被选出来的地方，还暴露于一场共享的搜索。一次独立的实验会是一条不共享那段历史的路径。在对象是一条路径的地方数出$48$，就是按切分的次数去乘样本量。[[#prop-max]]是另一种失效，关于一个最大值。WF01的失效方式，正如页面自己命名的那样，是切分。两者都属于清单。它们不是同一行。

每次测试窗口之前的清洗，是目录那句话的一部分。它是协议的一个真实部件，而它不会把一个诊断变成一组独立的试验。清洗在[[validation/purging-and-embargo]]里被推进得更远。一折不能证明什么，在[[validation/what-a-fold-does-not-prove]]。走步验证设计本身，在[[validation/walk-forward]]。本章的工作只是拒绝从"$48$次诊断"到"$48$次确认"的升格。

跨距是$26$年，折数是$48$，两者均为已报告。页面自己的标签是：那些折是切片诊断，而非独立的样本外证据。本图谱使用的WF01那一行没有报告收益率、增长率、夏普比率或回撤，所以这里一个都不插入。替换后的句子是：WF01报告了$48$段滑动的切片，带测试前清洗，跨距$26$年，并把它们称为切片诊断，而非独立的样本外证据。本图谱没有重跑过那个页面。确认，是清单没有挣来的一个词。

## 一个大的增长率挨着一个大的坑

W18，"Vol Target Momentum"，把一个动量篮子缩放到$15\%$的波动率目标，日K线，跨距$19$年。下面的数字是按quants.md对那个QuantJourney示例（Apache-2.0）的报告，按2026年的阅读。本图谱没有重跑过那个回测。被报告的总收益率是$+621\%$。被报告的年化复合增长率是$+10.96\%$。被报告的夏普比率是$0.57$。被报告的最大回撤是$-41.2\%$。被报告的胜率是$64.6\%$。被报告的盈亏比是$2.05$。$15\%$的目标是目录里那条规则的一句话。它不是要你去瞄准的波动率，而那个篮子也不是本课程推荐的一个组合。

增长率是大的。回撤也是大的。把绝对回撤除以增长率，$0.412 / 0.1096 = 3.759$，保留三位小数，说的是被报告的那个坑约是被报告的一年增长率的$3.76$倍。那个比是两个被报告列上的算术。它不是在某个经过核实的定义之下的杨（Young）比率，也不是一个效用。它挡住的是这样一种读法：$+10.96\%$已经"净掉"了$-41.2\%$。被报告增长率的一年，填不平那个坑。按这个算术，要好几年才行，而且只有当坑之后的路径长得像增长率所摘要的那个平均数时才行——而清单并不做这个假设。

跨距，$19$年，足够长，长到年化复合增长率可以是对该页面所拥有那条路径的一个有定义的摘要。有定义不等于能预测，也不等于经过审计。在本图谱拥有的那一行里，那一行没有写明成本模型，也没有写明决策时钟。因此两者都是未报告，而不是通过。$64.6\%$的胜率在等待获胜的单位，而那一行同样没有定义它。为正的已报告夏普比率$0.57$就是他们已报告的夏普比率。本图谱没有核实过它内部的年化。

:::warning 增长率不是没有回撤
目光落在$+10.96\%$上，把$-41.2\%$归档为布景。[[#alg-read]]把两个数字放进同一句话。W18是对一个按该页面自己的规格说明做了波动率目标缩放的动量篮子的一次例证，包括一个很深的已报告回撤。它不是一条你在别处嫌回撤碍事的规则的更干净版本。把它与另一页动量比较，会重新打开[[backtesting/weights-versus-orders]]里的单因错误：不同的句子太多了。
:::

:::quiz
W18报告了一个$+10.96\%$的年化复合增长率与一个$-41.2\%$的最大回撤。哪个读法与清单相符？
- [ ] 回撤无关紧要，因为增长率为正
- [ ] 该页面表明一个$15\%$的波动率目标避免了大额亏损
- [x] 两个数字都是报告的一部分，而回撤约是被报告的一年增长率的几倍
- [ ] $0.57$的夏普比率已经被核实与本图谱的每步定义一致
:::solution
$0.412/0.1096 = 3.759$，所以绝对回撤约是被报告的年增长率的$3.76$倍。波动率目标是一句规则，不是一场亏损保持微小的证明：被报告的回撤是$-41.2\%$。夏普比率仍然是一个已报告的夏普比率，其约定未经审计。
:::
:::

:::example 一个被发明的仪表盘，被拒绝 {#ex-toy}
一页纸的便条，不是库里的，写着："年化复合增长率$12\%$，跨三天，成本未提，试过四十个阈值，胜率$90\%$，按交易计。"应用[[#def-check]]，说出你不会把哪个数字当作证据复述。
:::solution
跨距是三天，支撑不起一个年化复合增长率；那个$12\%$是短样本的装饰，正是[[backtesting/intraday-samples]]拒绝升格的那一类。成本未提，所以它们不是零。四十个阈值是一次选择，而[[#prop-max]]是赢家的均值被推高这件事的两规则版本；四十更糟，而这里没有给它公式。获胜的单位至少是写明的：交易。按交易计的$90\%$胜率可以与一个负的复合数并排坐着，只要亏损够大——这一点属于[[performance/win-rate-and-profit-factor]]，而不在这张空洞的便条上重新证明。不可以当作证据复述的数字，是那个$12\%$的增长率。这张便条是编造的。它出现在这里，是因为库页面很容易比这张直白到赤裸的便条得到更温柔的对待，而清单是同一张清单。
:::
:::

小工具抽取的是独立的样本。这就是覆盖概率对它是一句有意义的陈述的原因。按页面自己的说法，WF01的折不是独立的样本，所以你没法从折数上读出一个覆盖概率。这幅图是一个对照，不是目录的一个模型。

:::remark 已报告的数字留在它们的列里
O01与W01，在[[backtesting/weights-versus-orders]]里做过比较，讲的是不要给一个差距乱认单一的出处。它们不在这里重新审理。O03无穷的盈亏比是关于获胜单位的一课。W18的增长率是关于把回撤放在同一口气里读的一课。W10是关于未必共享一个符号的两列的一课。WF01是关于一条作者已经写下来的限制的一课。一个想把其中某一页当作"那个"结果的读者，跳过了清单。
:::

:::history
2000年，怀特（White）的现实检验，给了本课程一个日期，对应一个具体的要求：一场大的样本内搜索的赢家，需要一个把搜索本身包含进来的检验，而不是一份就好像赢家是唯一被尝试过的规则那样写出来的检验。[[#prop-max]]是那项要求为什么有一个符号的两估计量速写。清单是那项要求的阅读版。它不取代怀特的检验，也不为WF04的九个组合去计算它。它挡住一个读者，让他不能在奔向增长率的路上跳过配置计数。
:::

## 通向何处

WF01拒绝升格的那些折，作为一个设计、而不是一张警告标签，在[[validation/walk-forward]]里被写明。在一场已于此处证明的两噪声玩具之外正确地数一场搜索，是[[validation/parameter-search]]与[[validation/the-deflated-sharpe]]。一折被仔细算完之后还剩下的东西，是[[validation/what-a-fold-does-not-prove]]。胜率与盈亏比——包括无穷的那一个——在[[performance/win-rate-and-profit-factor]]里定义。

:::summary
- 在读增长率之前，先读跨距、时钟、成本、样本池、配置数目、获胜的单位与页面自己的标签。
- 一个空白单元格保持空白。对成本保持沉默不是一个零。一个未经审计的时钟不是一个通过的时钟。
- 两个独立、零均值、方差为$\tau^2$的正态估计量的最大值的期望是$\tau/\sqrt{\pi}$。对$\tau = 0.01$，保留六位小数是$0.005642$。
- WF01的$48$折，按页面自己的话，是切片诊断，不是独立的样本外证据。那一行不报告增长率或夏普比率，这里也不发明一个。
- W18报告了一个$+10.96\%$的年化复合增长率与一个$-41.2\%$的最大回撤，跨距$19$年。绝对回撤是增长率的$3.759$倍。$15\%$的波动率目标不是建议。
- O03报告了$100\%$的胜率、无穷的盈亏比与$+2.70\%$的增长率，旁边是$-19.09\%$的最大回撤。问一次"胜"是什么。不要钦佩那个$100\%$。
- W10报告了$+0.70\%$的增长率与$-0.45$的夏普比率。两个符号未必一致，而本图谱不强迫它们一致。
:::

按本课程记录的WF01页面，那$48$折是独立的样本外证据吗？输入$0$表示否，输入$1$表示是。

:::exercise W18的回撤 {level=1 check="-0.412"}
W18被报告的最大回撤是$-41.2\%$。把那个回撤按小数输入。
:::solution
$-41.2\%$是$-0.412$。被报告的年化复合增长率$+10.96\%$是另一列，这里没有问它。
:::

:::exercise 回撤对着增长率 {level=2 check="3.759"}
使用W18被报告的$-41.2\%$的最大回撤与它被报告的$+10.96\%$的年化复合增长率，输入绝对回撤除以增长率的商，保留三位小数。
:::solution
$0.412 / 0.1096 = 3.759124\ldots$，保留三位小数为$3.759$。这个比的意思是被报告的那个坑约是被报告的一年增长率的$3.76$倍。它不是一个效用，也不是一个坑会被填平的预测。
:::
:::

:::exercise 两股噪声的期望 {level=2 check="0.005642"}
对[[#prop-max]]里的$\tau = 0.01$，输入$\tau/\sqrt{\pi}$，保留六位小数。
:::solution
$0.01/\sqrt{\pi} = 0.005641895\ldots$，四舍五入为$0.005642$。每个真实均值都是零。为正的期望是报告较大的那个估计量的效应。它不是一笔市场收益率。
:::

:::exercise O03的增长率，不当作战利品来读 {level=2 check="2.70"}
以百分数输入O03被报告的年化复合增长率，保留两位小数，不带百分号。解答还必须记下胜率，并说出不要拿它做什么。
:::solution
被报告的增长率是$+2.70\%$，所以要输入的数字是$2.70$。被报告的胜率是$100\%$，被报告的盈亏比是无穷，旁边是$-19.09\%$的最大回撤。清单问一次"胜"是如何定义的。它不把$100\%$当作钦佩那一行或照抄那张限价单的理由。本图谱没有重跑过那个页面。
:::
:::

:::exercise 绝对差的一半 {level=3}
对独立的$Z_i \sim \Normal(0, \tau^2)$，导出$\E[\max(Z_1, Z_2)]$。你可以使用对$W \sim \Normal(0, \sigma^2)$的$\E|W| = \sigma\sqrt{2/\pi}$，或者推导那个积分。写明独立性的假设。
:::hint
把最大值写成平均值加上绝对差的一半。两个估计量之差的方差是$2\tau^2$。
:::
:::solution
$\max(Z_1, Z_2) = (Z_1+Z_2)/2 + |Z_1-Z_2|/2$，所以因为均值为零，期望是$\E|Z_1-Z_2|$的一半。独立性正是使$\Var(Z_1-Z_2) = 2\tau^2$成立、而不是$2\tau^2 - 2\Cov(Z_1, Z_2)$的东西。由$\sigma = \tau\sqrt{2}$，$\E|Z_1-Z_2| = \tau\sqrt{2}\cdot\sqrt{2/\pi} = 2\tau/\sqrt{\pi}$，而它的一半是$\tau/\sqrt{\pi}$。如果你推导那个绝对矩：$w$乘以半正态密度的积分，配上换元$u = w^2/(2\sigma^2)$，就化简为$\sigma\sqrt{2/\pi}$。这个结果不能当作一个数，用在来自一条共享价格路径的相依分数上。WF01不是这条命题。WF04的九个组合也不是这条命题。
:::
:::

:::exercise 空白里不许写什么 {level=3}
O03的一行式目录行没有写明成本。一个读者想在[[#def-check]]的成本那一格里要一个数字。哪种代入是不合法的，而你改写什么？
:::hint
把[[#alg-read]]里关于"—"单元格的指示，与把"未提及"当作"免费"的愿望比较一下。
:::
:::solution
写$0$是不合法的。沉默不是一个写明的零成本模型；[[backtesting/timing-costs-and-biases]]做的是同一个区分，而库里的一个空白是一个未报告的单元格，不是一个测量出来的零。这一行清单里的成本那一格是"未报告"。同样的答案适用于时钟："未报告"不是"合法"。O03被报告的数字——增长率$+2.70\%$、夏普比率$0.14$、最大回撤$-19.09\%$、胜率$100\%$、盈亏比无穷——留在它们的列里，而缺失的成本不从邻近的算例里填。本图谱没有重跑过那个页面，而拒绝发明一个成本，也不是在判断那张限价单是贵还是便宜。
:::
