一个以美元报价的即期汇率，是一个单位基础货币以美元计的价格。从\(1.1000\)到\(1.1050\)的一次上升，意味着一个单位的基础货币比之前多买到千分之五美元。它不是一只股票的价格，而它本身也不是利润。利润（如果有的话）取决于账簿持有多少单位、它在报价的哪一边持有，以及那份报告记得收取了哪些成本。

本章把那套算术算出来，然后读三页亏过钱的已发表外汇动量页面。那些亏损留着当亏损。它们不会被翻成一条规则，而这里没有一样东西是交易一种货币、持有美元、或站到一本已报告账簿对面的指令。米斯（Meese）与罗戈夫（Rogoff）1983年的对照随机游走比较，是一份预测必须战胜的基准。一次回测若不先说出那个基准，就还没有说出"管用"会是什么意思。

## 报价与手

:::definition 以美元报价的即期汇率 {#def-quote}
一个**以美元报价的即期汇率**\(S_t\)，是在时刻\(t\)一个单位基础货币的美元价格。\(S\)的上升，是一个单位基础货币的美元价值之上升。一个基础货币一单位的多头头寸，按美元盯市，其简单收益率为

$$
R_t = \frac{S_t}{S_{t-1}} - 1.
$$ {#eq-fx-ret}

变动\(S_t - S_{t-1}\)不是那个收益率，除非\(S_{t-1} = 1\)。一个日期为\(t\)的特征可以使用直到\(t\)的报价，而在\(t\)之后的收益率上计分。
:::

:::definition 标准手 {#def-lot}
本章中的一张**标准手**是\(100\,000\)单位基础货币。在报价\(S\)处，一张标准手的美元名义额是\(100\,000 \times S\)。\(Q\)单位基础货币的一个多头头寸，在从\(S_{t-1}\)到\(S_t\)的一次变动上的美元盯市盈亏，不计成本，为\(Q\,(S_t - S_{t-1})\)。迷你手与微型手在下面不使用。一个负的\(Q\)将是一个基础货币的空头头寸；那些需要负权重的例子，把它说成一份已发表风格映射里的一个权重，而不是一笔做空某种货币的指令。
:::

报价约定就是全部的关键。在一个美元报价的货币对里，美元是报价货币，不是基础货币。一个混进按每美元若干美元报的货币对——完全反过来的那种——的研究者，会在不改变任何经济学含义的情况下改变每个收益率的符号，然后把那个符号错误加到每个权重上。本章使用一个约定，并坚守它。

:::proposition 盈亏与简单收益率 {#prop-pnl}
设一个头寸在\(t-1\)到\(t\)之间持有常数\(Q\)单位基础货币，美元报价为\(S_{t-1} > 0\)与\(S_t\)，没有佣金、价差或融资。美元盈亏是\(Q\,(S_t - S_{t-1})\)。除以起始美元价值\(Q\, S_{t-1}\)（对\(Q \neq 0\)）就还原出[[#eq-fx-ret]]里的\(R_t\)。等价地，美元盈亏等于起始美元价值乘以简单收益率。这个恒等式针对一个单位步长上的常数\(Q\)。它不包含一次移仓、一个掉期点、或两种货币之间的利差。
:::

:::proof
起始美元价值是\(V = Q S_{t-1}\)。同样那些单位的期末美元价值是\(Q S_t\)。两者之差是\(Q S_t - Q S_{t-1} = Q\,(S_t - S_{t-1})\)。除以\(V\)：

$$
\frac{Q\,(S_t - S_{t-1})}{Q S_{t-1}} = \frac{S_t}{S_{t-1}} - 1 = R_t,
$$

其中对\(Q \neq 0\)，\(Q\)约掉了。于是盈亏\(= V R_t\)。若有人用\(1\)而不是用\(S_{t-1}\)去除价格变动，除非报价从\(1\)起步，他们算的就不是\(R_t\)。
:::

:::example 从1.1000到1.1050 {#ex-move}
一个美元报价的汇率从\(1.1000\)走到\(1.1050\)。把一个分数形式的简单收益率、一张标准手多头的美元盈亏、以及一个错误计算所隐含的盈亏都算出来：把\(0.0050\)的变动当作一张标准手名义额上已经是一个简单收益率的东西。
:::solution
简单收益率是

$$
R = \frac{1.1050}{1.1000} - 1 = \frac{1}{220} = 0.00454545\ldots
$$

一张标准手是\(Q = 100\,000\)单位基础货币。美元盈亏是\(100\,000 \times (1.1050 - 1.1000) = 100\,000 \times 0.0050 = 500\)美元。对照[[#prop-pnl]]核对：起始名义额是\(100\,000 \times 1.1000 = 110\,000\)美元，而\(110\,000 \times (1/220) = 500\)美元。两条路径一致。

那个变动\(0.0050\)是五十个\(0.0001\)的点，在这个报价约定下常被称为点（pip）。它不是一个\(0.50\%\)的收益率。一个\(0.50\%\)的收益率，在\(110\,000\)美元的名义额上会是\(550\)美元，也就是\(100\,000 \times 0.0055\)，那是另一个变动。一张标准手上的一个点（pip）是\(100\,000 \times 0.0001 = 10\)美元。五十个点（pip）是\(500\)美元，与上面的盈亏相符，而它仍然不是名义额的\(0.50\%\)。

对数收益率是\(\ln(1.1050/1.1000) = \ln(221/220) \approx 0.00453516\)，略低于\(1/220\)，而对任何\(R \neq 0\)，\(\ln(1+R)\)总是如此。美元盈亏使用的是报价的简单差分，不是对数收益率。对数可以在时间上相加；它们不给一张手定价。
:::
:::

:::quiz
一个美元报价的汇率上升。哪句话与[[#def-quote]]相符？
- [ ] 基础货币以美元计变得更便宜了。
- [ ] 简单收益率等于报价的变动，不做除法。
- [x] 一个单位的基础货币值更多美元，而简单收益率用新报价除以旧报价。
- [ ] 一张标准手多头上的美元盈亏永远是\(500\)美元。
:::solution
美元报价的上升，是每单位基础货币的美元数之上升。简单收益率是\(S_t/S_{t-1} - 1\)，所以旧报价留在分母上。那个\(500\)美元是一次特定变动——从\(1.1000\)到\(1.1050\)——上的盈亏，不是一个常数。
:::
:::

## 由权重得到手

一个动量权重是净资产值的一个目标分数。订单那一章定义了手；本章把它应用在一个货币报价上。整手正是O19那一页所说它交易过的东西。一个\(0.25\)的权重不会凭魔法变成四分之一张手。它先变成一个美元敞口，然后是一个基础货币单位数，然后是一个手的张数，而只有在一条取整规则之后才是一个整数。

:::algorithm 由权重得到整手 {#alg-lots}
输入：净资产值\(V > 0\)（美元）、目标权重\(w\)、美元报价\(S > 0\)，以及一条取整规则。
1. 美元敞口是\(w V\)。基础货币单位数是\(w V / S\)。
2. 未取整的标准手是\(w V / (100\,000 \times S)\)。
3. 把写明的取整规则应用上去，得到一个整数\(N\)。向零截断与取最近整数是不同的规则。写下你用了哪一条。
4. 实际建成的美元敞口是\(N \times 100\,000 \times S\)，而实际建成的权重是那个敞口除以\(V\)。它等于\(w\)，仅当第3步没有改变手的张数。
5. \(w\)的符号就是在基础货币上的头寸的符号。这个算法没有告诉你去选一个负的符号。若一份已发表的映射产出了一个，就把它作为那张映射的输出记录下来。
:::

:::example 二十五万美元，在1.1000处 {#ex-lots}
净资产值是\(1\,000\,000\)美元。目标权重是\(+0.25\)。报价是\(1.1000\)。计算未取整的标准手张数、若张数向零截断到整数时实际建成的权重，以及目标敞口与实际建成敞口之间的美元差距。
:::solution
一张手的名义额是\(100\,000 \times 1.1000 = 110\,000\)美元。目标敞口是\(0.25 \times 1\,000\,000 = 250\,000\)美元。未取整的手是\(250\,000 / 110\,000 = 25/11 = 2.272727\ldots\)

向零截断给出\(2\)张手。实际建成的敞口是\(2 \times 110\,000 = 220\,000\)美元，而实际建成的权重是\(220\,000 / 1\,000\,000 = 0.22\)。差距是\(250\,000 - 220\,000 = 30\,000\)美元，即净资产值的\(0.03\)。取最近整数也会选\(2\)，因为\(0.2727 < 0.5\)。一个不同的报价，或一个\(2.6\)张手的目标，会让两条规则分道扬镳。在规则被写明之前，"大约两张手"不是一个头寸。

下一个简单收益率，若报价移动而那两张手被持有，仍然是[[#eq-fx-ret]]作用在实际建成的敞口上。那没有投出去的净资产值的\(0.03\)，挣得剩余现金所能挣的任何东西：在一个玩具里常被建模为\(0\)，而若规格说明忘了它，就压根儿没有建模。
:::
:::

## 两个货币对上的逆波动率

路径A为两个波动率共享的那个事实在这里复用，因为那些外汇页面按逆波动率确定规模，而这套算术不该被重新发明。若最近的波动率是\(0.10\)与\(0.20\)，原始逆波动率就是\(10\)与\(5\)。归一化到相加为\(1\)，权重是\(2/3\)与\(1/3\)。那次归一化是一张只做多、全额投资的映射：两个符号都为正。一张时间序列动量映射把每个逆波动率乘以一个符号再重新缩放，常常使得各权重绝对值之和等于一个总敞口预算。那是两张不同的映射。W23的目录那一行说的是在一条六个月趋势上的"逆波动率权重"。在我们拥有的那一行里，它没有写出总敞口预算。下面的例子写明它们实际使用的映射。

:::example 两个符号都为正 {#ex-ivol}
波动率是\(0.10\)与\(0.20\)。两个趋势符号都是正的，而权重被归一化到相加为\(1\)，于是\(2/3\)与\(1/3\)。接下来的简单收益率是\(0.012\)与\(-0.009\)。计算账簿收益率。假设那些权重是在那些收益率之前固定的。
:::solution
逆波动率\(1/0.10 = 10\)与\(1/0.20 = 5\)相加为\(15\)。权重是\(10/15 = 2/3\)与\(5/15 = 1/3\)。账簿收益率是

$$
\frac{2}{3} \times 0.012 + \frac{1}{3} \times (-0.009) = 0.008 - 0.003 = 0.005.
$$

较低波动率的那个货币对得到两倍的权重，而在这一编造的步长上，得到那个为正的收益率。这不是去搜寻低波动率的理由。把两个收益率对调，账簿收益率的符号模式就会改变：这个公式不偏爱任何一个货币对。它只是给一对符号已经为\(+1\)的货币对确定规模。
:::
:::

:::example 符号相反，总敞口为一 {#ex-signed}
使用同样的波动率，但符号为\(+1\)与\(-1\)。逆波动率的绝对值又是\(10\)与\(5\)。把它们缩放，使各权重绝对值之和为\(1\)：权重\(+2/3\)与\(-1/3\)。两个货币对接下来的简单收益率都是\(+0.009\)。计算账簿收益率。那个负权重是这张写明的映射在一个负符号上的输出。它不是一笔做空某种货币的指令。
:::solution
账簿收益率是

$$
\frac{2}{3} \times 0.009 + \left(-\frac{1}{3}\right) \times 0.009 = 0.006 - 0.003 = 0.003.
$$

两个报价都以同一个简单收益率上升。账簿仍然显示一个为正的收益率，因为总敞口没有均分：正权重的绝对值是负权重绝对值的两倍。美元中性会需要相加为零的权重，例如\(+1/2\)与\(-1/2\)，而那本账簿在两个相等的简单收益率上会返回\(0\)。逆波动率没有产出美元中性。把\(0.003\)报告成"市场中性"，会把两个词都用错。市场中性约束是这门课的最后那一章。
:::
:::

:::warning 变动不是收益率，而亏损不是一笔反手交易
什么都不除——把\(1.1050 - 1.1000 = 0.0050\)当作一个\(0.50\%\)的收益率——会高估简单收益率，后者是\(1/220\)。第二个疏漏更大。下面引用的W23、W24与O19报告的是亏损。仅仅因为已报告的路径亏了钱就把每个权重翻面，是一条符号在看过路径之后才被选定的新规则。那不是对面那本账簿的一次样本外检验。那是同一个样本，倒过来读。本章不这么做，也不建议你这么做。
:::

## 三笔已发表的亏损

动量课程跨资产地持有这些结果的正负号。本章持有的是工具：美元报价的即期汇率、手，以及逆波动率权重。接下来的那些数字，是按quants.md上对那些QuantJourney示例（Apache-2.0）的报告，2026年读入。本图谱没有重跑过那些回测。下面已报告的夏普是他们的数字，不是说它与我们的超额收益率均值除以超额收益率标准差之比相符。目录印着短横的地方，库没有报告那个统计量。不要去填那道短横。

W23是以美元报价的即期货币对上的六个月时间序列动量，带逆波动率权重。已报告跨距为16年。已报告总收益率为\(-27.3\%\)，已报告年化复合增长率为\(-1.97\%\)，已报告夏普比率为\(-0.59\)，最大回撤为\(-29.4\%\)。库没有为W23报告胜率或盈亏比。一个16年之上的为负的总收益率就是头条。逆波动率在这条已报告的路径上，没有把那些六个月的符号变成一笔盈利。那张确定规模的映射仍然可以被研究，正如[[#ex-ivol]]与[[#ex-signed]]那样。研究它不是去跑它的理由，而那笔亏损也不是去跑那个符号翻面的孪生版本的理由。

W24是横截面的：目录把它描述为每月做多最强的、做空最弱的美元报价货币对，跨越16年。已报告总收益率为\(-34.1\%\)，已报告年化复合增长率为\(-2.58\%\)，已报告夏普比率为\(-1.00\)，最大回撤为\(-41.4\%\)。库没有报告胜率或盈亏比。这里的"做多"与"做空"这些词，是目录对那条规则的描述。它们不是指令。空头那条腿正是读者必须去问借券、融资与报价约定的一部分原因。那一页，按本图谱的目录所载，没有把这些成本逐项列出。沉默不是一项成本为零的测量。

O19是以美元报价的即期货币对上的、考虑合约规格的整手动量，同样跨越16年。已报告总收益率为\(-14.2\%\)，已报告年化复合增长率为\(-0.95\%\)，已报告夏普比率为\(-0.71\)，最大回撤为\(-15.3\%\)。库没有报告胜率或盈亏比。整手，也就是[[#alg-lots]]里的那个整数，是这一页的设计要点。那个整数在已报告的路径上，没有产出一个为正的总收益率。把O19的\(-14.2\%\)与W23的\(-27.3\%\)相比较然后宣布一个赢家，会无视两份规格说明之间所有其他的差别：权重对订单，整手取整对分数权重，以及每一页各自使用的任何成本模型。本图谱没有重跑过这两页中的任何一页，也不给它们排名。

三个跨距都是16年，比下一章里的七年期期货窗口更长，而仍然是一条历史路径。一个为负的已报告夏普比率，与一条在那条路径上没有战胜零均值基准的规则是相容的。它不是一个标准误，也不是一笔交易。

:::intuition 随机游走的预测是"不变"
对即期汇率的一个随机游走预测说，下一个报价等于这个报价。被预测的简单收益率是零。任何其他预测——一个六个月的符号、一个宏观经济学方程、一个横截面的排名——都必须在一个事先选定的损失函数上、在样本外战胜那个零预测，才有资格作为证据被数进来。在提出那条规则的那个样本之内战胜它，不算数。上面那些已报告的亏损，就是那些页面所报告的东西。它们本身不是一条"没有任何货币规则永远能战胜随机游走"的定理。它们也不是一封站到对面去的邀请函。
:::

:::history
1983年，理查德·米斯（Richard Meese）与肯尼斯·罗戈夫（Kenneth Rogoff）在*Journal of International Economics*上，在样本外把标准的汇率宏观经济学模型与一个随机游走作了比较。那些模型没有战胜随机游走。本章里的随机游走基准，就是那个结果的实用形式：对即期汇率不变的预测，于是被预测的简单收益率为零。后来的工作在其他样本与其他损失函数上同那个发现争论过。这场争论不会被W23、W24或O19定下来，而那些页面也不是米斯与罗戈夫的一次重跑。它们是在美元报价货币对上的动量规格说明，而目录报告的是亏损。1972年CME上的货币期货将一份交易所交易的合约由一个汇率做成；期货那一章接手那份合约。1983年的那些预测讲的是即期汇率。[[#def-quote]]是本章对那一类价格使用的报价约定，不是关于那篇论文的表格的一个主张。
:::

:::remark 美元盈亏漏掉了什么
[[#prop-pnl]]里没有买卖价差，没有佣金，也没有利差。一个持有过夜的即期头寸，在经济学上是一对存款，而那个利差能够加上或减去一笔报价变动并不显示的收益率。一个只对\(S_t\)盯市的回测，是报价的一个回测，不是一个带融资的货币头寸的回测，除非规格说明把融资那一块加了进去。O19的"考虑合约规格"之说讲的是手。按目录那一行，它不是一份本图谱能够审计的完整融资台账。若台账在报告里缺席，就说出这一点，而不要去发明那笔缺失的利差收益（carry）。
:::

## 通往何处

期货，在[[asset-classes/futures]]里，用一个乘数与一个整数份数的合约，替换那张\(100\,000\)基础货币单位的手；它们用一个会到期的合约，替换一个即期报价。外汇结果的正负号，不带着这些工具细节，也在[[momentum/momentum-across-assets]]里讨论过。作为订单层面话题的整手取整，在[[orders/lots-contracts-and-intraday]]。那些页面里没有一页，本页也不是，是交易一种货币的建议。

:::summary
- 一个美元报价的即期汇率是每单位基础货币的美元数。一次上升是那个美元价值之上升。简单收益率除以旧报价（[[#def-quote]]、[[#eq-fx-ret]]）。
- 一张标准手是\(100\,000\)基础货币单位。一个常数持有的美元盈亏是\(Q\)乘以报价的变动，不计成本（[[#prop-pnl]]）。
- 从\(1.1000\)到\(1.1050\)，简单收益率是\(1/220\)，不是\(0.0050\)。一张标准手多头赚到\(500\)美元。那张手上的一个点（pip）是\(10\)美元。
- 一个目标权重只有在一条写明的取整规则之后才变成整数张的手。在\(1.1000\)处，\(1\,000\,000\)美元上的权重\(0.25\)是\(2.2727\ldots\)张手；两张手建成权重\(0.22\)。
- 波动率\(0.10\)与\(0.20\)在两个符号都为正、权重相加为一时给出权重\(2/3\)与\(1/3\)。符号相反、总敞口为一给出\(+2/3\)与\(-1/3\)，那不是美元中性。
- W23、W24与O19报告16年上的亏损：总收益率\(-27.3\%\)、\(-34.1\%\)与\(-14.2\%\)。库没有为它们报告胜率或盈亏比。那些亏损在这里不被翻面。
- 米斯（Meese）与罗戈夫（Rogoff）（1983）是那个随机游走基准：一份预测必须在样本外战胜"不变"。这些页面不是那个检验，它们也不是一个建议。
:::

## 练习

:::exercise 简单收益率 {level=1 check="1/220"}
一个美元报价的汇率从\(1.1000\)走到\(1.1050\)。把一个最简分数形式的简单收益率算出来。（输入那个分数。）
:::solution
\(1.1050/1.1000 - 1 = 0.0050/1.1000 = 5/1100 = 1/220\)。那个变动\(0.0050\)不是简单收益率。
:::
:::

:::exercise 一张标准手 {level=1 check="500"}
在同一次变动上，计算一张标准手多头的美元盈亏，不计成本。（输入美元数。）
:::solution
\(Q = 100\,000\)，而报价上涨\(0.0050\)，所以盈亏是\(100\,000 \times 0.0050 = 500\)美元。等价地，名义额\(110\,000\)乘以\(1/220\)是\(500\)。
:::
:::

:::exercise 每个点（pip）多少美元 {level=1 check="10"}
一个点（pip）是\(0.0001\)的报价变动。一张标准手多头每个点（pip）赚多少美元，不计成本？（输入美元数。）
:::solution
\(100\,000 \times 0.0001 = 10\)美元。五十个点（pip）是\(500\)美元，即上一题里的盈亏，不是一个\(0.50\%\)的收益率。
:::
:::

:::exercise 实际建成的权重 {level=2 check="0.22"}
净资产值是\(1\,000\,000\)美元，目标权重是\(+0.25\)，报价是\(1.1000\)。头寸被向零截断到整数张标准手。实际持有的权重是多少？（输入实际建成的权重。）
:::solution
未取整的手是\(250\,000 / 110\,000 = 25/11 \approx 2.2727\)。向零截断保留\(2\)张手，敞口\(220\,000\)美元，权重\(220\,000/1\,000\,000 = 0.22\)。
:::
:::

:::exercise 逆波动率账簿收益率 {level=2 check="0.02"}
权重是\(2/3\)与\(1/3\)，在收益率之前固定。接下来的简单收益率是\(0.03\)与\(0\)。计算账簿收益率。（输入账簿收益率。）
:::solution
\((2/3) \times 0.03 + (1/3) \times 0 = 0.02\)。那个为零的收益率仍然占着账簿的三分之一；它什么也不贡献，而第一个权重不是\(1\)。
:::
:::

:::exercise 符号相反，收益率相等 {level=2 check="0.003"}
权重是\(+2/3\)与\(-1/3\)，来自一张写明的符号乘逆波动率、总敞口为一的映射。两个接下来的简单收益率都是\(+0.009\)。计算账簿收益率。那个负权重是映射的输出，不是一笔指令。
:::solution
\((2/3) \times 0.009 + (-1/3) \times 0.009 = 0.006 - 0.003 = 0.003\)。相等的简单收益率并不抵消，因为那些权重不是等大小的相反数。
:::
:::

:::exercise 报价的下跌 {level=3 check="-1000"}
美元报价从\(1.1000\)走到\(1.0900\)。计算一张标准手多头的美元盈亏，不计成本。（输入美元数，带着它的符号。）
:::hint
报价的变动是\(-0.01\)，不是\(-0.01/1\)。乘以\(100\,000\)。基础货币的一个多头头寸，在美元报价下跌时亏美元。让符号留在负上。不要报告简单收益率；这个问题要的是美元。
:::
:::solution
变动是\(1.0900 - 1.1000 = -0.01\)。盈亏是\(100\,000 \times (-0.01) = -1000\)美元。简单收益率本会是\(-0.01/1.1000 = -1/110\)，而\(-1/110 \times 110\,000 = -1000\)也一样。把符号翻过来，描述的就是一个基础货币的空头头寸，而这个问题并没有持有它。
:::
:::

:::exercise 另一个报价处的向零截断 {level=3 check="0.0625"}
净资产值是\(2\,000\,000\)美元。目标权重是\(+0.10\)。美元报价是\(1.2500\)。标准手被向零截断。计算实际建成的权重。（输入那个权重。）
:::hint
一张标准手是\(100\,000\)基础货币单位，所以它的美元名义额是\(100\,000 \times 1.25 = 125\,000\)。目标敞口是\(200\,000\)美元，也就是\(1.6\)张手。向零截断保留\(1\)张手，不是\(2\)张。把那一张手的美元名义额除以净资产值。
:::
:::solution
未取整的手是\(0.10 \times 2\,000\,000 / 125\,000 = 200\,000 / 125\,000 = 1.6\)。向零截断保留\(1\)。实际建成的敞口是\(125\,000\)美元。实际建成的权重是\(125\,000 / 2\,000\,000 = 0.0625\)。取最近整数本会保留\(2\)张手和一个不同的权重；那不是这里写明的规则。
:::
:::
