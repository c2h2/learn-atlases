一只行业基金与它里面的那些股票不是同一个研究对象。这只基金有一个交易价格。那些股票有许多价格、一篮子由基金自己选定的成分、由基金处理过的公司行动，以及一笔若已经从净资产值中扣除、就永远不会作为单独账单到来的费用。跑在基金价格上的一条移动平均规则，回答的是一个关于那个价格的问题。它并不回答关于一条在成分股之间挑挑拣拣的规则的那个同样的问题。

本章把两条早先课程留成一般形式的约束落到具体。第一条是工具：一只股票**交易所交易基金（ETF）**是一份对一篮子资产的可交易索取权，所以在它的价格上做的一次回测是对那份索取权的回测。第二条是权重的符号：一本**只做多**账簿从不赋予负的权重。两条约束都不是持有某只基金、某只股票或现金的建议。下面的算术使用虚构的费用与编造的价格。它不是一份预测，也不是一份建议。

开放库里那些长周期的股票例子，大多是对ETF价格的研究，而不是一条选股规则的研究。其中之一，W01，是行业交易所交易基金上的每日简单移动平均趋势。趋势课程持有那个案例。本章只需要这个区分：一份行业ETF研究不是关于其背后那些名字的研究，无论代码多么眼熟。

## 交易价格里已经装着什么

一个ETF价格是基金份额的一个市场价格。在这一个数字之内，几个不同的机制已经发生过作用，而一个收盘到收盘的回测并不会把它们分开看到，除非研究者另行构建一个模型。

篮子是第一个。基金按它自己的规则设定的权重持有成分股，而这些权重会在基金再平衡时、或在价格移动时移动。一条经过复权的ETF序列显示不出内部权重。把它换成今天的成员的等权平均、在样本期末计算，是一个不同的实验，一个幸存者偏差实验。样本池规则属于[[markets/adjustment-universes-and-rolls]]。

公司行动是第二个。一次拆股或一笔成分股股息，在股东去看价格之前就已经在基金内部处理掉了。若那条序列是一条**价格序列**，一只派息基金的股息会离开价格，而简单收益率会漏掉股东收到的那笔现金。若那条序列是一条**总收益序列**，那笔现金就已经被构建者的规则放了回去，而那条规则未必与基金实际的分配相符。规格说明点名那条序列。于是\(R_t = P_t/P_{t-1} - 1\)是那条序列的简单收益率，而不自动是股东的总收益率。

费用是第三个。一笔费用率是逐期计提、冲减资产的，所以净资产值低于一个费前反事实，而被交易的价格在市场为净资产值定价的范围内反映这一点。再把同一个费率减一遍就是重复计算它。把它加回来则是假装研究者知道一个价格并不显示的反事实。本章两个都不做：下面的代数使用一个虚构的毛收益率，而一条真实的ETF序列原样放着。

申购与赎回是第四个，而本章不对它们建模。授权参与人（authorized participant）可以对篮子申购或赎回份额，而二级市场价格可以处在相对净资产值的一个溢价或一个折价上。一个日收盘价包含了那个缺口。除非有人提供，它不包含一本申购赎回台账。忽略那个缺口是一次建模选择，属于规格说明。

这些没有一条使ETF成为与它的最大成分股相同的对象，也没有一条是买入那只基金的建议。它只固定了一次跑在一条序列上的回测所能主张的东西。

:::definition 股票ETF的研究对象 {#def-etf}
本章中的一本**股票ETF账簿**是一条规则，其交易工具是一或多只股票ETF的价格。价格\(P_t\)是规格说明里点名的那条序列（价格或总收益），在决策时钟处观察。一个日期为\(t\)的特征可以使用直到\(t\)的价格，而在\(t\)之后的收益率上计分。该账簿研究那条序列。它本身不研究一条挑选成分股的规则；那条序列已经装着的一笔费用、一项股息政策、一个相对净资产值的溢价，它也不加撤销。
:::

:::definition 只做多权重 {#def-long-only}
当对每个资产\(i\)与每个决策日期\(t\)都有\(w_{i,t} \ge 0\)时，权重\(w_{i,t}\)是**只做多**的。当\(\sum_i w_{i,t} = 1\)时，账簿是**全额投资**的。若允许现金，则\(\sum_i w_{i,t} \le 1\)，而剩余权重\(1 - \sum_i w_{i,t}\)挣得一个写明的现金收益率，除非规格说明另有说明，该收益率为\(0\)。在一个从信号到权重的映射被写明之前，一个信号\(s_{i,t}\)不是权重。下面例子里使用的只做多映射把一个为负的期望权重送到\(0\)。
:::

这两个定义把一条工具约束与一条符号约束分开了。一条只做多规则可以跑在一只单一股票上。一只ETF上的负权重是另一本账簿，带着市场中性那一章接手的借券问题。本章把那个权重设为零。这条约束不是一个"负权重本会亏钱"的预测。

:::quiz
一次回测载入一只股票ETF的一条总收益序列。那条序列已经反映了那只基金的费用。哪种读法与[[#def-etf]]相符？
- [ ] 那条路径是关于一条在当前成分股上的选股规则的证据。
- [x] 那条路径是关于那条被交易的序列的，而再把同一笔费用减一遍就是重复计算它。
- [ ] 费用的同一性说明为了保守起见应当把费用加回来。

:::solution
[[#def-etf]]里定义的对象是那条被点名的序列，不是成分股，也不是一个费前反事实。一个负权重会违反[[#def-long-only]]，无论权重是否相加为一。
:::

## 一笔从期末资产中取的费用

本节里的虚构费率是每年\(0.10\%\)，写作\(f = 0.001\)。它不是任何一只有名字的基金（包括SPY）的已公布费用率。它的存在是为了让一个\(5\%\)的毛年化复合增长率有一个你能手算出来的净对应值。

:::proposition 按期末资产计的费用 {#prop-fee}
设一年有毛简单收益率\(g > -1\)，并写\(G = 1+g\)为毛增长因子。假设一笔费率为\(f\)、满足\(0 < f < 1\)的费用，是在那次毛增长之后按资产的一个比例收取的，并假设不收取其他成本。则净增长因子为\(G(1-f)\)，而净简单收益率为

$$
g_{\mathrm{net}} = (1+g)(1-f) - 1 = g - f - gf.
$$ {#eq-fee}

特别地\(g_{\mathrm{net}} = (g-f) - gf\)，所以当\(g > 0\)时，净收益率比朴素差值\(g-f\)小一个交叉项\(gf\)。这个恒等式假定这笔费用还没有包含在\(g\)之内。把它再用在一条已经包含同一笔费用的序列上，就是对那笔收费的重复计算。
:::

:::proof
展开乘积：\((1+g)(1-f) - 1 = 1 + g - f - gf - 1 = g - f - gf\)。最后一步把\(g - f - gf\)归组为\((g-f) - gf\)。当\(g > 0\)且\(f > 0\)时，交叉项\(gf\)为正，所以\(g_{\mathrm{net}} < g - f\)。当\(g < 0\)时，交叉项为负，而\(-gf\)相对\(g-f\)抬高了\(g_{\mathrm{net}}\)：费用是从一个更小的期末价值中取的。两种情形下都有\(g_{\mathrm{net}} - g = -f(1+g) < 0\)，所以费用仍然降低增长因子。重复计算的那句警告，就是\(g\)不含这笔费用那个假定。若\(g\)已经是净的，这套代数描述的是第二笔费用，不是那只基金的费用。
:::

交叉项是\(0.05 \times 0.001 = 0.00005\)，在一个\(5\%\)的年份里是半个基点。从\(5\%\)里减去\(0.10\%\)并把\(4.9\%\)报告出来，一年之内是接近的。在一个长样本上，被漏掉的是每年的因子\((1-f)\)，而\((1-f)^T\)不是舍入上的方便。朴素差值在一个下跌年份里的形状也是错的。精确的那一行是[[#eq-fee]]。

:::example 一个5%的年份与一笔0.10%的费用 {#ex-fee}
一个虚构的毛简单收益率是\(g = 0.05\)。费率\(f = 0.001\)从期末资产中取，而\(g\)还不包含\(f\)。计算朴素差值\(g-f\)、交叉项\(gf\)，以及净简单收益率。
:::solution
朴素差值是\(0.05 - 0.001 = 0.049\)。交叉项是\(0.05 \times 0.001 = 0.00005\)。由[[#eq-fee]]，

$$
g_{\mathrm{net}} = 0.05 - 0.001 - 0.00005 = 0.04895.
$$

同一个数字来自增长因子：\(1.05 \times 0.999 = 1.04895\)，而\(1.04895 - 1 = 0.04895\)。一个单位的起始资产结束时在\(1.04895\)，不在\(1.049\)，也不在\(1.05\)。
:::
:::

:::example 同一笔拖累的十年与二十六年 {#ex-wealth}
每年保留\(g = 0.05\)与\(f = 0.001\)，按期末资产收取，没有其他成本。计算\(10\)年之后与\(26\)年之后的毛与净财富因子（从一个单位起步），以及费用之后剩余的毛财富的比例。财富因子按四舍五入取到六位小数。
:::solution
每年的因子是\(1.05\)与\(1.04895\)。同一个毛收益率被重复，好让费用是唯一的差别；这种重复是一个假定，不是一个市场。\(10\)年之后，从一个高精度的幂按四舍五入取到六位小数，因子是\(1.05^{10} = 1.628895\)与\(1.04895^{10} = 1.612679\)。差距是每个起始财富单位\(0.016216\)。费用保留了毛期末财富的\(0.999^{10} = 0.990045\)这个比例。

\(26\)年之后，因子是\(1.05^{26} = 3.555673\)与\(1.04895^{26} = 3.464372\)。差距是每个起始单位\(0.091301\)，而保留的比例是\(0.999^{26} = 0.974322\)。二十六年对这个玩具只是一个时间跨度。它不是W01的结果，而这一笔费用也没有被叠加在一条ETF序列上。
:::
:::

:::widget sequence
a: (1+r)^n
sliders: r=0.05:0.048:0.052:0.00005
N: 26
mode: terms
caption: 从1起步、以常数的年因子1+r逐年复利n年之后的财富。把r设为0.05，再设为0.04895，并把第26年的项与十年与二十六年那个例子里的因子作比较。这是在一个被重复的玩具收益率上的复利，不是一个市场，不是一只基金，也不是一份预测。
:::

若\(g = 0\)，则[[#eq-fee]]给出\(g_{\mathrm{net}} = -f = -0.001\)。当费用按期末价值收取、且还没有在价格之内时，不动的资产仍然按费用的数额缩水。一个下跌年份显示出交叉项改变了符号。

:::example 一个下跌年份，以及一只两只股票的篮子 {#ex-basket}
再用\(f = 0.001\)。第一，取一个还不包含这笔费用的虚构毛收益率\(g = -0.05\)，计算净简单收益率。第二，取一只编造的两只股票的篮子。基金从净资产值\(100\)起步。它把\(50\)持有一只上涨\(10\%\)的股票，把\(50\)持有一只下跌\(20\%\)的股票，为期一期，期中不再平衡。然后同一笔费用按期末资产收取。计算毛基金收益率与净基金收益率。
:::solution
下跌年份：\(0.95 \times 0.999 = 0.94905\)，所以\(g_{\mathrm{net}} = 0.94905 - 1 = -0.05095\)。朴素差值\(g - f = -0.051\)把亏损高估了交叉项\(0.00005\)那么多。净收益率仍然比毛收益率差：\(-0.05095 < -0.05\)。相对一个没有费用的世界，费用并没有"软化"那一年。它只是不等于那个朴素减法。

篮子：费用之前的期末价值是\(50 \times 1.10 + 50 \times 0.80 = 55 + 40 = 95\)。毛简单收益率是\(95/100 - 1 = -0.05\)。这与成分股简单收益率的等权平均\((0.10 + (-0.20))/2 = -0.05\)一致，那正是起始美元相等时一期的恒等式。然后费用取走\(0.001 \times 95 = 0.095\)，所以净资产值为\(94.905\)，净简单收益率为\(94.905/100 - 1 = -0.05095\)。一期、起始美元相等、一笔按比例的费用：基金收益率是加权的成分股收益率，然后[[#eq-fee]]。它不是关于任何一只股票的一个新的事实。
:::
:::

:::warning 把费用算两遍，或者一遍都不算
算过的那笔费用适用于一个被定义为不含它的毛收益率。一条ETF的供应商总收益序列常常已经扣除了费用率，因为被交易的净资产值是净的。把[[#eq-fee]]跑在那条序列上，是在计算第二笔费用。相反的错误是把一笔股息造成的一次价格下跌当作损失掉的经济价值。规格说明点名那条序列，以及仍然在它之外的那些成本。
:::

## 只做多的界限只有一期长

一本全额投资的只做多账簿，在一期之内，是它的各资产的一个加权平均。在一份报告显示一本账簿的收益率落在各资产收益率的范围之外之前，或者在有人把一期的界限一路复利过十年之前，这听起来都像一句老生常谈。

:::proposition 一期范围 {#prop-bound}
设\(R_1,\ldots,R_n\)是一期之内的简单收益率，设\(w_i \ge 0\)且\(\sum_{i=1}^n w_i = 1\)。用\(R = \sum_{i=1}^n w_i R_i\)定义账簿收益率。则

$$
\min_i R_i \le R \le \max_i R_i.
$$

这个结果用的是一期的加权和。它不适用于把简单收益率在时间上相加，也不适用于多期之上的复合收益率，即便每一期都是只做多且全额投资的。若允许收益率为\(0\)的现金、且某些\(w_i\)为零，那么在主张这个界限之前，必须把现金收益率作为它自己的一个资产包括进来。
:::

:::proof
设\(m = \min_i R_i\)。则\(R - m = \sum_i w_i (R_i - m)\)。每个权重非负，每个\((R_i - m)\)非负，而权重之和为\(1\)，所以\(R - m \ge 0\)。同样的论证用\(M = \max_i R_i\)给出\(M - R = \sum_i w_i (M - R_i) \ge 0\)。若某个权重为负，两步都会失效，因为那时\(w_i(R_i - m)\)可以为负。两步讲的都是那一期的加权和。一个复合收益率\(\prod_t (1+R_t) - 1\)不是各成分复合量的一个加权和，所以那个不等式延续不到它上面。
:::

:::example 界限之内的权重，与一个不是只做多的权重 {#ex-weights}
两个虚构资产在一期上返回\(0.04\)与\(-0.01\)。只做多、全额投资的权重是\(0.6\)与\(0.4\)。第二对，\(1.2\)与\(-0.2\)，相加为\(1\)，却不是只做多的。计算两个账簿收益率，并把它们与[[#prop-bound]]核对。
:::solution
只做多账簿返回\(0.6 \times 0.04 + 0.4 \times (-0.01) = 0.024 - 0.004 = 0.02\)。资产收益率的范围从\(-0.01\)到\(0.04\)，而\(0.02\)坐在那个范围之内。

第二对返回\(1.2 \times 0.04 + (-0.2) \times (-0.01) = 0.048 + 0.002 = 0.05\)。数值\(0.05\)严格高于较大的那个资产收益率。[[#prop-bound]]不适用，而突破界限的是那个负权重。把这本账簿称为只做多的一份报告，是在一个定义所排除的账簿上使用那个词。这个算术不是偏爱那个负权重的理由。它是一个诊断：在一项全额投资的主张之下，一个落在资产范围之外的一期收益率，意味着某个权重为负，或者那个收益率恒等式不是那个加权和。
:::
:::

:::example 复合量离开一期的范围 {#ex-compound}
两个资产，两个时期，每期分别只做多且全额投资。第1期用权重\((1, 0)\)与资产收益率\((0.10, -0.50)\)，所以账簿收益率是\(0.10\)。第2期用权重\((0, 1)\)与资产收益率\((0.10, 0.50)\)，所以账簿收益率是\(0.50\)。计算账簿的复合收益率与每个资产的复合收益率。
:::solution
账簿按\(1.10 \times 1.50 - 1 = 0.65\)复合。第一个资产按\(1.10 \times 1.10 - 1 = 0.21\)复合。第二个按\(0.50 \times 1.50 - 1 = -0.25\)复合。账簿的复合收益率\(0.65\)落在从\(-0.25\)到\(0.21\)的区间之外。每一期都满足[[#prop-bound]]。复合量没有，因为加权和的复合不是复合量的加权和。一条只做多约束是每次再平衡时关于权重的一句话。它不是一条财富曲线待在各成分股财富曲线之间的承诺。
:::
:::

路径A是图谱各处共享的那条八个价格的路径：\(100, 102, 101, 104, 103, 107, 106, 110\)。那七个简单收益率符号交替。那种交替是这八个数字的一个性质。它不是一桩市场事实，而一条在七步上求值的头寸规则不是一份业绩记录。不确定性那一章在这条路径上展示了均值与标准差之比噪声大到不能年化。这里，那条路径只说明一条只做多映射之下的一个合法时钟。

:::example 路径A上的只做多，带一个合法的滞后 {#ex-path}
价格是路径A。下一步的期望权重是：刚完成的那个简单收益率为正时取\(1\)，为负时、或还没有任何收益率完成时取\(0\)。该权重挣得下一个简单收益率，从不挣得同一个。计算那七个权重、账簿的复合增长因子，以及按四舍五入取到六位小数的复合简单收益率。现金挣\(0\)。
:::solution
这些简单收益率，作为价格的分数，是\(1/50\)、\(-1/102\)、\(3/101\)、\(-1/104\)、\(4/103\)、\(-1/107\)、\(2/53\)。它们的符号是正、负、正、负、正、负、正。压在每个那些收益率上的合法权重用的是前一个符号，而第一个权重是\(0\)。所以权重是\(0, 1, 0, 1, 0, 1, 0\)。

在这条路径上，账簿在上涨的日子里空仓，在三个下跌的日子里做多。那是滞后加上交替，不是一桩市场事实。增长因子是

$$
\frac{101}{102} \times \frac{103}{104} \times \frac{106}{107} = \frac{551359}{567528}.
$$

复合简单收益率是\(551359/567528 - 1 = -0.028490\)，六位小数。同样价格上的买入并持有按\(110/100 - 1 = 0.10\)复合。那条只做多的滞后规则是那条路径的一个不同的函数。比较这两个数字，并没有说出应该在任何别的路径上跑哪个函数。

作对比，那个用同一个它所挣得的收益率来设定权重的非法时钟，仍然只做多，恰好在那四个上涨的日子里做多。它的增长因子是\(102/100 \times 104/101 \times 107/103 \times 110/106\)，而复合简单收益率是\(0.132258\)，六位小数。那个非法的数字更大，因为它用了它所计分的那次移动的符号。那是前视，在[[backtesting/timing-costs-and-biases]]里作为一种偏差讨论过。它不是一个ETF效应，也不是支持那条规则的证据。
:::
:::

:::intuition 基金是一个价格
把ETF想成一件被市场整个定价的包裹。用那个价格回答的问题，是一个关于那个包裹的问题。打开它——成分股、申购、费用计提——需要价格里不含的数据。把这个合着的包裹称为一次选股回测，就是凭假定把那些数据放了回去。[[#def-etf]]就是让它合着、并说出这一点的决定。
:::

:::application W01坐在哪里
W01在其价格的50日均值高于200日均值期间持有每只行业交易所交易基金，每日再平衡，已报告跨距26年。移动平均那一章持有那条规则与那条已报告的路径，如quants.md上对那个QuantJourney示例（Apache-2.0）的报告，2026年读入，而这里没有重跑。对象是行业交易所交易基金序列。抄下那些代码，做不出一份成分股层面的研究，也不会使那条路径成为一条持有那些基金的建议。库里多数长周期股票例子都是这个形状：那条序列就是那只基金。
:::

若忘记把现金包括进来，现金会改变那个界限。一只风险ETF返回\(0.10\)，权重\(0.5\)，而现金挣\(0\)。账簿收益率是\(0.05\)，低于唯一的那个风险收益率。[[#prop-bound]]没有被主张过，因为风险权重不相加为一。把现金作为一个收益率为\(0\)、权重为\(0.5\)的资产包括进来，\(0.05\)就坐在\(0\)与\(0.10\)之间。一句对剩余现金没有交代的"只做多"，是一条没有完成的约束。

:::remark 本章不估计什么
虚构的\(0.10\%\)不是一只有名字的基金的费用率，也不是一个买卖价差。价差、佣金、相对招募说明书指数的跟踪差异，在那套代数里都是零，除非某一行把它们放了进去。跟踪差异是一个结果，不是一个发明出来"纠正"一个价格的输入。一笔成本进入的方式，就是[[#prop-fee]]进入的方式：一个写明的费率，与一个写明的基数。
:::

:::history
1993年由道富（State Street）完成的SPY上市，把一只市值加权的股票篮子变成了一个单一的交易所交易价格。对研究而言，改变的是那个习惯：载入一条股票序列，然后把结果称为一次股票市场回测。那条序列是那只基金的价格；它的费用与它的公司行动，只在那条序列已经反映它们的范围内包含在内。那个更小的主张就是[[#def-etf]]。
:::

## 通往何处

下一章，[[asset-classes/multi-asset-books]]，保留ETF作为工具，改变样本池：不止一个分支，以及一个不自动是现金的后备。只做多的符号约束在[[portfolio/long-only-and-neutral]]里以一般形式写明，而移动平均的ETF案例W01在[[trend/moving-averages]]里处理。简单与总收益——决定一笔股息是否在\(P_t\)之内的那个区分——在[[performance/simple-and-log-returns]]。那些页面上没有一样东西，这里也没有一样东西，是买入、卖出或持有一只基金或一只股票的指令。

:::summary
- 一次股票ETF回测研究那只被点名的基金序列。它不研究一条在成分股上的选股规则，也不撤销一笔那条序列已经装着费用（[[#def-etf]]）。
- 只做多意味着每个权重非负。全额投资意味着权重相加为一。若允许现金，它有一个写明的收益率（[[#def-long-only]]）。
- 一笔费率为\(f\)、从期末资产中取的费用，把毛增长\(1+g\)变成\((1+g)(1-f)\)。净简单收益率是\(g - f - gf\)，而不只是\(g-f\)（[[#prop-fee]]）。
- 在一个虚构的\(5\%\)年份与一笔\(0.10\%\)的费用上，净简单收益率是\(0.04895\)。在\(26\)个被重复的年份里，相对毛路径的财富差距是每个起始单位\(0.091301\)，仅在这个玩具里。
- 在一期之上，一本全额投资的只做多账簿的收益率坐在最差与最好的资产收益率之间（[[#prop-bound]]）。一个负权重可以离开那个范围。一个多期复合量不一定坐在各成分复合量之间。
- 一个合法的权重使用在它所挣得的收益率之前可得的信息。在路径A上，只做多的滞后符号规则复合到大约\(-0.028490\)；同一根K线的版本看起来更好，因为它欺骗了时钟。
- W01是一份行业交易所交易基金研究。指着它，不是持有那些基金的理由，而本章没有把它的路径当作新证据重新报告。
:::

## 练习

:::exercise 一年，按比例的费用 {level=1 check="0.04895"}
一个虚构的毛简单收益率是\(0.05\)。一笔\(0.001\)的费用从期末资产中取，而毛收益率还不包含这笔费用。计算净简单收益率。（输入净简单收益率。）
:::solution
由[[#eq-fee]]，\(1.05 \times 0.999 - 1 = 1.04895 - 1 = 0.04895\)。那个朴素减法\(0.049\)漏掉了交叉项\(0.00005\)。
:::
:::

:::exercise 净增长因子 {level=1 check="1.04895"}
与上一题同样的毛收益率与同样的费用。计算净增长因子，不是净简单收益率。（输入净增长因子。）
:::solution
净增长因子是\((1+g)(1-f) = 1.05 \times 0.999 = 1.04895\)。只有当问题要一个简单收益率时才减去一。
:::
:::

:::exercise 一个只做多的加权和 {level=1 check="0.02"}
两个资产返回\(0.04\)与\(-0.01\)。权重是\(0.6\)与\(0.4\)。计算这一期的账簿收益率。（输入账簿收益率。）
:::solution
\(0.6 \times 0.04 + 0.4 \times (-0.01) = 0.024 - 0.004 = 0.02\)。两个权重都非负且相加为一，而\(0.02\)坐在\(-0.01\)与\(0.04\)之间，正如[[#prop-bound]]所要求的。
:::
:::

:::exercise 一个下跌年份里的费用 {level=2 check="-0.05095"}
一个虚构的毛简单收益率是\(-0.05\)，对于一笔从期末资产中取的\(f = 0.001\)的费用仍是毛的。计算净简单收益率。
:::solution
净增长因子是\(0.95 \times 0.999 = 0.94905\)，所以净简单收益率是\(0.94905 - 1 = -0.05095\)。等价地，\(g - f - gf = -0.05 - 0.001 - (-0.05)(0.001) = -0.05095\)。这比朴素的\(-0.051\)亏损更小，而比毛的\(-0.05\)亏损更大。
:::
:::

:::exercise 两期，仍然只做多 {level=2 check="0.5"}
第1期：权重\((1, 0)\)，资产收益率\((0.20, -0.10)\)。第2期：权重\((0, 1)\)，资产收益率\((-0.10, 0.25)\)。不持有现金，因为每期都是全额投资的。计算账簿跨两期的复合简单收益率。（输入那个复合收益率。）
:::solution
账簿收益率在第1期是\(0.20\)，在第2期是\(0.25\)。复合收益率是\(1.20 \times 1.25 - 1 = 1.50 - 1 = 0.5\)。每期都是一个合法的只做多加权和。复合量是另一个对象，那正是[[#ex-compound]]的要点。
:::
:::

:::exercise 路径A有多少步是投资的 {level=2 check="3"}
使用路径A价格\(100, 102, 101, 104, 103, 107, 106, 110\)。下一步的只做多权重是：刚完成的那个简单收益率为正时取\(1\)，否则取\(0\)，而第一个收益率上没有头寸。那七个简单收益率里有多少个是以权重\(1\)挣得的？（输入那个计数。）
:::solution
那七个收益率符号交替，从正开始。合法的权重是\(0, 1, 0, 1, 0, 1, 0\)。权重在七个收益率中的三个上等于\(1\)。那个计数就是被要求的对象。那三步的复合收益率是另一个问题，在[[#ex-path]]里算过。
:::
:::

:::exercise 一笔击中一个已写明的净收益率的费用 {level=3 check="1/105"}
在期末资产约定之下，一个\(0.05\)的虚构毛简单收益率应当产生一个\(0.04\)的净简单收益率。求费率\(f\)。（把\(f\)作为一个最简分数输入。）
:::hint
设\((1.05)(1-f) = 1.04\)，并解出\(f\)。答案不是\(0.01\)，因为费用是期末资产的一个比例，而不是从简单收益率里减一笔。
:::
:::solution
当净简单收益率是\(0.04\)时，净增长因子是\(1.04\)。所以\(1.05 \,(1-f) = 1.04\)，于是\(1-f = 1.04/1.05 = 104/105\)，而\(f = 1 - 104/105 = 1/105\)。作为小数，\(1/105 \approx 0.009524\)，略低于\(1\%\)，而不是\(1\%\)本身。交叉项就是在一个为正的年份里，一个百分点整的费用比从\(0.05\)减掉一个点产生稍多一点拖累的原因。
:::
:::

:::exercise 二十六年的财富差距 {level=3 check="0.091301"}
重复[[#ex-wealth]]的玩具：毛简单收益率每年\(0.05\)，费用每年从期末资产中取\(0.001\)，持续\(26\)年，起始财富一个单位。计算毛期末财富减净期末财富，按四舍五入取到六位小数。（输入那个取整后的差距。）
:::hint
每年的净增长因子是\(1.04895\)，不是\(1.049\)。计算\(1.05^{26} - 1.04895^{26}\)，按四舍五入取到六位小数。不要把这笔费用用在一个市场序列上，也不要把这个差距当作一份预测。
:::
:::solution
毛期末财富是\(1.05^{26} = 3.555673\)，六位小数。净期末财富是\(1.04895^{26} = 3.464372\)，六位小数。差是\(3.555673 - 3.464372 = 0.091301\)，与未取整之差的直接取整值相符。毛财富的保留比例是\(0.999^{26}\)，不是\(1 - 26 \times 0.001\)。这仍然是一个关于常数毛收益率的复利玩具。
:::
:::
