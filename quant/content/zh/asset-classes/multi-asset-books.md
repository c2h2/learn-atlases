一条在一只股票基金上已经完成的规则，当第二个分支一出现就还没有完成。规格说明必须点名样本池，而且必须点名账簿在不想要风险分支时持有什么。收益率为零的现金是一个后备。一个有它自己收益率的第二个分支是另一个。即便那个开关被一字不差地复制，它们也是两本不同的账簿。

本章把那个开关当作一个你可以计算的对象来对待，而不是一份供你持有的基金名单。没有哪只债券基金、黄金基金或股票基金被点名为你应该买入的东西。一个后备挣得规格说明写下的那个简单收益率。若那个收益率不是零，这本账簿就不是一本现金账簿。开放库里那些多资产页面按其已报告的形状被引用，然后就放着不动：本图谱没有重跑过它们，而一条已报告的路径不是一份预测。

## 样本池、滤波器、后备

把风险分支称为\(A\)，把后备分支称为\(F\)。每个分支本身可以是一只篮子。当账簿待在一个分支里时，那个分支在当期有一个由它内部各权重构建的简单收益率。多资产的问题是哪一个分支是激活的，而不是移动平均如何定义。移动平均住在[[trend/moving-averages]]。防御性开关，作为一条信号，在[[trend/filters-and-defensive]]里引入。这里的新东西是\(F\)的收益率。

:::definition 样本池与后备 {#def-universe}
一本**多资产账簿**点名一个分支的样本池与一个**后备**分支\(F\)。后备是当规则不在风险分支里时所持有的分支。它在当期的简单收益率是一个数\(R^F\)，可以为正、为零、或为负。现金是特殊情形\(R^F = 0\)。一只债券基金、一只股票基金，或任何其他被交易的序列，都不是现金，除非它在样本里的收益率确实为零。本章不把一只真实的基金点名为\(F\)。那个符号就是规格说明。
:::

:::definition 二值滤波器账簿 {#def-filter}
一个**二值滤波器**\(I_t \in \{0,1\}\)在第\(t\)期开始时已知，使用日期早于第\(t\)期收益率的信息。账簿的简单收益率是

$$
R_t = I_t \, R^A_t + (1-I_t)\, R^F_t.
$$ {#eq-filter}

\(R^A_t\)是风险分支的简单收益率，\(R^F_t\)是后备的。当\(I_t = 1\)时，账簿挣得\(R^A_t\)而不挣得\(R^F_t\)。当\(I_t = 0\)时，它挣得\(R^F_t\)而不挣得\(R^A_t\)。一个作为\(R^A_t\)自身的函数的滤波器，已经看过了它所计分的收益率。那个时钟是非法的，与[[backtesting/timing-costs-and-biases]]里一根同期K线上的信号是同一个意义。
:::

那个指示变量不是分支内部的一个权重。若风险分支持有多只ETF，它们的权重是第二张映射，只在\(I_t = 1\)的时期里应用。等权是一张映射。逆波动率是另一张，由[[portfolio/inverse-volatility-and-targets]]持有。把两张映射混为一谈——把滤波器当作它已经是一组百分比——会产生一本谁也没有规定过的账簿。

这些例子里的一期是一年，好让一个\(0.01\)的后备意味着那一年之内的一个百分点。同样的代数对一天也成立，只要每个收益率都是一个日简单收益率、而后备是一个日收益率，而不是一个粘贴在日频规则上的年利率。因为"债券挣一个百分点"就把一个\(0.01\)放进一个日频格子里，是一个单位错误。说出时间跨度。

:::quiz
滤波器关闭，那一年的风险分支简单收益率是\(-0.08\)，而后备的简单收益率是\(0.01\)。[[#eq-filter]]为账簿记下什么？
- [ ] \(-0.08\)，因为风险分支才是真实的市场。
- [ ] \(0\)，因为"防御性"意味着现金。
- [x] \(0.01\)，后备收益率，因为\(I_t = 0\)。
- [ ] \(0.01 - 0.08\)，因为两个分支总是被持有。
:::solution
当\(I_t = 0\)时，[[#eq-filter]]丢掉\(R^A_t\)，保留\(R^F_t\)。现金会是更进一步的特殊情形\(R^F_t = 0\)，而这个后备不是。账簿不会同时挣那两个收益率。
:::
:::

## 后备为常数时的财富之比

假设后备收益率在每个关闭的时期都等于同一个\(f > -1\)，而现金是作为比较的那本账簿，在那些时期挣\(0\)、在打开的时期挣同样的风险收益率。于是打开的时期在一个期末财富之比中抵消。

:::proposition 关闭年份之比 {#prop-ratio}
固定一个时期的集合。设对两本账簿而言，二值滤波器与\(I_t = 1\)的时期上的风险收益率都相同。账簿\(B\)在每个\(I_t = 0\)的时期上挣一个常数的简单收益率\(f > -1\)。账簿\(C\)在那些时期上挣\(0\)。设\(n_{\mathrm{off}}\)是关闭时期的个数。则从同一个单位起步的期末财富之比为

$$
\frac{W_B}{W_C} = (1+f)^{n_{\mathrm{off}}}.
$$ {#eq-ratio}

这个结果假定开关上没有额外成本，\(I_t\)里没有前视，而现金收益率恰好为零。它没有说\(W_B\)胜过一本一直待在风险分支里的账簿。那第三本账簿在关闭的时期上挣\(R^A_t\)，而那些因子并不抵消。
:::

:::proof
从一单位起步，写\(W_B = \prod_t (1+R^B_t)\)与\(W_C = \prod_t (1+R^C_t)\)。在每个打开的时期上，\(R^B_t = R^C_t = R^A_t\)，所以那些因子一致。在每个关闭的时期上，\(1+R^B_t = 1+f\)而\(1+R^C_t = 1\)。因此那个比值在每个关闭的时期上乘一次\(1+f\)、在每个打开的时期上乘\(1\)，也就是\((1+f)^{n_{\mathrm{off}}}\)。这个论证里没有一样东西依赖打开时期的收益率，这就是它们抵消的原因。把账簿\(C\)换成一本一直待在风险分支里的账簿，会消掉这个抵消，因为那本账簿在关闭的时期上贡献的是\(1+R^A_t\)，而不是\(1\)。
:::

:::algorithm 构建各期收益率 {#alg-book}
输入：一个合法的滤波器\(I_t\)、风险分支收益率\(R^A_t\)，与后备收益率\(R^F_t\)，每期一个。
1. 对每个\(t\)，由[[#eq-filter]]设定\(R_t\)。不要平均\(R^A_t\)与\(R^F_t\)，除非规格说明写明账簿同时持有两者、且权重写明。
2. 按\(\prod_t (1+R_t) - 1\)复合。不要把简单收益率相加。
3. 若比较对象是现金，把\(R^F_t\)换成\(0\)重复一遍，然后才构成比值\(W_B/W_C\)。
4. 若\(R^F\)是按一个年化利率报出的、而那一期的时间单位不是一年，就换算那个利率，或者拒绝做那个乘积。不要把那个年度数字原样插进去。
:::

这个算法是记账。它不选择一个你应该持有的后备。一个为正的\(f\)只在[[#prop-ratio]]的假定之内、在实际关闭的那些时期上、且只相对现金，才抬高财富。一个亏钱的后备会相对现金降低财富。这两句话都是算术。

:::example 四年，后备为百分之一 {#ex-four}
四年的滤波器是\((1, 0, 0, 1)\)。风险分支的简单收益率是\(0.12\)、\(-0.08\)、\(0.05\)、\(0.03\)。后备收益率在每个关闭的年份里是\(0.01\)。现金挣\(0\)。计算账簿的四个收益率、它的复合收益率、现金账簿的复合收益率，以及一本总是待在风险分支里的账簿的复合收益率。
:::solution
由[[#eq-filter]]，账簿返回\(0.12\)、\(0.01\)、\(0.01\)、\(0.03\)。关闭的年份不挣\(-0.08\)与\(0.05\)。增长因子是

$$
1.12 \times 1.01 \times 1.01 \times 1.03 = 1.17678736,
$$

所以复合收益率是\(0.17678736\)。现金账簿返回\(0.12\)、\(0\)、\(0\)、\(0.03\)，而\(1.12 \times 1.03 = 1.1536\)，复合收益率为\(0.1536\)。总是风险的账簿返回\(0.12\)、\(-0.08\)、\(0.05\)、\(0.03\)：

$$
1.12 \times 0.92 = 1.0304, \quad 1.0304 \times 1.05 = 1.08192, \quad 1.08192 \times 1.03 = 1.1143776.
$$

它的复合收益率是\(0.1143776\)。在这四个编造的年份上，后备账簿收在现金与总是风险的分支两者之上。那个排序是这四个数字的一个性质，特别是关闭年份里那条风险路径\(0.92 \times 1.05 = 0.966\)的一个性质，它比\(1.01 \times 1.01 = 1.0201\)更差。它不是一个持有后备分支是好事的证据，而这些年份也不是任何一个市场的样本。
:::
:::

:::example 核对那个比值，然后一个亏钱的后备 {#ex-ratio}
使用[[#ex-four]]里的账簿，计算\(W_B/W_C\)，并与\((1.01)^2\)比较。然后只替换第一个关闭的年份：两个关闭年份里后备返回\(-0.03\)、\(0.01\)，而打开的年份保持\(0.12\)与\(0.03\)。计算那本账簿的复合收益率，并与现金比较。
:::solution
财富水平是\(1.17678736\)与\(1.1536\)。它们的比值是\(1.17678736 / 1.1536 = 1.0201\)。而\((1.01)^2 = 1.0201\)。[[#eq-ratio]]相符，\(n_{\mathrm{off}} = 2\)，\(f = 0.01\)。打开年份的因子抵消了，正如证明所说的那样。

亏钱的后备产生收益率\(0.12\)、\(-0.03\)、\(0.01\)、\(0.03\)。因子是

$$
1.12 \times 0.97 = 1.0864, \quad 1.0864 \times 1.01 = 1.097264, \quad 1.097264 \times 1.03 = 1.13018192.
$$

复合收益率是\(0.13018192\)，低于现金账簿的\(0.1536\)。一个为负的后备年份，就足以在这条路径上输掉与现金的比较。后备不是一张免费期权。它贡献它自己的收益率，而规格说明必须容许那个收益率为负。把一个分支称为"防御性的"，既不会把那个收益率设为零，也不会让它保持为正。
:::
:::

:::example 一个等权分支，然后一年关闭 {#ex-sleeve}
在一个打开的年份里，风险分支以等权的起始权重持有两只编造的ETF，简单收益率为\(0.08\)与\(-0.02\)。第二年滤波器关闭，而后备返回\(0.01\)。开关上不收取成本。计算打开年份里的分支收益率，以及账簿的两年复合收益率。
:::solution
一期之内的等权起始美元给出算术平均：\((0.08 + (-0.02))/2 = 0.03\)。那就是打开年份的\(R^A\)。关闭的年份贡献\(0.01\)，而不是对没有被持有的成分再做一次平均。复合收益率是\(1.03 \times 1.01 - 1 = 0.0403\)。那个\(0.03\)是一期的加权和，当权重只做多且全额投资时，它在[[asset-classes/equity-etf-books]]里被界定。那个\(0.0403\)是两个不同分支的一个复合。不要把\(0.0403\)描述为"那两只ETF的平均"。
:::
:::

:::example 一个欺骗那一年的滤波器 {#ex-clock}
假设有人当\(R^A_t > 0\)时设\(I_t = 1\)，否则设\(I_t = 0\)，使用同一年的风险收益率，后备为\(0\)。在风险收益率\(0.12\)、\(-0.08\)、\(0.05\)、\(0.03\)上，计算这本非法账簿的复合收益率，并且只作为时钟之差与[[#ex-four]]里的合法账簿比较。
:::solution
同一年的符号是正、负、正、正，所以非法的收益率是\(0.12\)、\(0\)、\(0.05\)、\(0.03\)。因子是\(1.12 \times 1 \times 1.05 \times 1.03 = 1.21128\)，复合收益率是\(0.21128\)。[[#ex-four]]里的合法后备账簿在一个不同的滤波器上复合到\(0.17678736\)，所以这两个数字不是一个纯粹的前视差距：滤波器不同，时钟也不同。干净的那一点更小。那条非法的规则用\(R^A_t\)来决定是否保留\(R^A_t\)。那个决定在一年开始时不可得。从那种使用中得到的一份更高的复合收益率，不是多资产投资的一个性质。它是在选出分支之前先读完了那一年这个事实的一个性质。
:::
:::

:::warning 后备不是一种美德
两个疏漏很常见。第一个是写下"防御性"，然后按零复利，而规格说明里点名的那个分支返回的是别的东西，包括一笔亏损。第二个是把一条已公布的开关读成一张购物清单：行情好的时候的风险偏好名字，其余时候的其他名字。[[#def-universe]]允许一个带收益率的符号\(F\)。它没有点名一只基金，也没有说读者应该持有一只。第三个疏漏——把一个令人失望的风险分支翻成"那就持有后备"——把同一个样本用了两次。那些关闭的时期，本来就是建议过这次翻面的那条路径的一部分。
:::

## 库里那些页面实际改变的是什么

W06与W02是开放库里的多资产ETF研究。趋势课程持有W06的滤波器，而组合课程持有漂移带。这一节只记录当账簿不再是一条单一的股票序列时什么改变了，以及那些页面报告了什么。那些数字是按quants.md上对那些QuantJourney示例（Apache-2.0）的报告，2026年读入。本图谱没有重跑过那些回测。它们不是预测，也不是建议。当一句一行的描述说"防御性"时，那个词是它们在那个实验里对一个分支的标签。它不是一种你应该买下的通用资产。

W06在一条信号改变时更换分支，而不是按日历。目录里的那条规则是：若SPY高于其200日均值，则持有风险偏好交易所交易基金名单；否则持有防御性名单。已报告跨距为19年。已报告总收益率为\(+132\%\)，已报告年化复合增长率为\(+4.54\%\)，已报告夏普比率为\(0.26\)，最大回撤为\(-24.6\%\)，胜率为\(41.1\%\)，盈亏比为\(1.64\)。胜率低于一半而盈亏比高于一，意味着如果两个统计量共用同一个单位，那么盈利的单位在平均上大于亏损的单位。那一页本身不会告诉你那个单位。SPY，在这一句话里，是一条已公布滤波器的输入。说出它的名字不是持有它的建议，而那份防御性名单也不是建议。

W02是在一个多资产ETF样本池上的一个不同的实验：一个SMA(50)/SMA(200)趋势，在月末、以及一个头寸已经漂移穿过一条\(5\%\)的带子时交易。已报告跨距又是19年。已报告总收益率为\(+138\%\)，已报告年化复合增长率为\(+4.66\%\)，已报告夏普比率为\(0.31\)，最大回撤为\(-19.4\%\)，胜率为\(63.5\%\)，盈亏比为\(1.73\)。那条\(5\%\)的带子是那份规格说明的一部分。它不是每本账簿的默认带子。一个从\(0.50\)移动到\(0.52\)的权重，其相对漂移为\(0.52/0.50 - 1 = 0.04\)，没有穿过一条\(5\%\)的带子；一个从\(0.50\)到\(0.53\)的移动，其相对漂移为\(0.06\)，穿过了。组合那一章正确地推导漂移。这里唯一的要点是，W02的日历加带子不是W06的信号改变规则。相似的年化复合增长率数字，\(4.66\%\)与\(4.54\%\)，坐在不同的开关上。那个"多资产趋势结果"，不是这两页页面所能支持的东西。

两页页面都可能在他们已报告的回撤上损失掉财富的一大块，尽管已报告的年化复合增长率为正。一个后备分支并不会删掉那句话。他们的后备或防御性名单是挣得一个接近零的收益率、接近一只债券的收益率、还是别的东西，是一个关于他们的持仓与他们的数据的问题，本图谱没有重新推导过。把\(+4.54\%\)读成"现金加一点"，会发明一个目录那一行并没有给出的分解。

:::intuition 抵消就是全部的戏法
[[#prop-ratio]]感觉比它实际更强，因为打开的年份消失了。它们只是从与现金的比较中消失，而且只是当打开年份确实相同的时候。改变一个打开年份的收益率，比值就会移动。与一本一直风险的账簿比较，关闭年份的风险收益率就回到乘积里来，正如在[[#ex-four]]里那样，那条总是风险的复合收益在那条编造的路径上是三者中最差的。抵消是代数。它不是各分支之间的一个排名。
:::

:::remark 年利率，日频账簿
一个说"后备每年挣\(1\%\)"的规格说明，还没有说一天挣什么。把\(0.01\)摊到\(252\)个交易日上、作为\(0.01/252\)，是一个约定。复利一个日因子\(1.01^{1/252}\)是另一个。它们不同，而两者都不是某一只债券基金在某一特定日子实际做过的事。若研究序列是日频的，诚实的输入是那条被点名的后备序列的日简单收益率，包括那些为负的日子。那句年度的说法不是替代品。
:::

:::history
安蒂·伊尔马宁（Antti Ilmanen）的*Expected Returns*（2011）综述了跨资产类别的证据，并把样本期间放在主张旁边。在[[#def-filter]]意义上的多资产账簿，是比那篇综述更小的对象：一个被点名的样本池、一个合法的滤波器，以及一个后备收益率。那本账簿不是那篇综述，而一条单独的已公布路径，包括W06或W02，也不是一条跨资产定律。日期要紧，是因为把几个ETF分支放进同一条规则的那个习惯，相对于其底层市场是近来的事，而一个开关的算术不是。
:::

## 通往何处

外汇，在[[asset-classes/foreign-exchange]]里，保留一种多资产的形状——几条序列、可以依赖波动率的权重——而把工具换成一个以美元报价的即期汇率。库里关于那个工具的那些外汇页面报告的是亏损。选择一个防御性分支的那个滤波器在[[trend/filters-and-defensive]]。W02那种漂移带在[[portfolio/drift-turnover-and-breakers]]。这些章节里没有一章点名一只基金、一只债券、或一种货币供你持有。

:::summary
- 一本多资产账簿点名一个风险分支与一个后备。后备收益率是一个输入。它只在规格说明说现金时才为零（[[#def-universe]]）。
- 一个合法的二值滤波器在它计分的收益率之前已知。账簿在每一期恰好挣两个分支收益率中的一个（[[#eq-filter]]）。
- 相对一本打开年份相同的现金账簿，常数的后备收益率\(f\)把期末财富按\((1+f)\)的关闭时期数次方缩放（[[#prop-ratio]]）。
- 在那条编造的四年路径上，后备\(0.01\)复合到\(0.17678736\)，现金到\(0.1536\)，而总是风险的分支到\(0.1143776\)。一个为负的后备年份就抹掉了相对现金的优势。
- 一个等权的打开年份是那一期的成分股收益率的算术平均。下一个关闭年份不会为账簿没有持有的成分求平均。
- W06与W02是多资产ETF样本池上的不同开关，在19年上的已报告年化复合增长率为\(+4.54\%\)与\(+4.66\%\)。那些数字不是建议，而本图谱没有重跑过它们。
- "防御性"是规格说明里的一个标签。它不是那个分支的收益率为正的证明，也不是一份供买入的基金名单。
:::

## 练习

:::exercise 关闭的那一年 {level=1 check="0.01"}
滤波器关闭。风险分支本会返回\(-0.08\)。后备收益率是\(0.01\)。账簿记下什么简单收益率？（输入账簿的简单收益率。）
:::solution
\(I_t = 0\)的[[#eq-filter]]返回\(R^F_t = 0.01\)。那个风险收益率没有被使用。现金本会记下\(0\)，那是另一个后备。
:::
:::

:::exercise 与现金相比一个关闭的年份 {level=1 check="1.01"}
两本账簿共享每一个打开年份的收益率。恰好有一个关闭的年份。后备账簿那一年挣\(0.01\)，而现金账簿挣\(0\)。它们的期末财富之比是多少？（输入那个比值。）
:::solution
由[[#eq-ratio]]，比值是\((1.01)^1 = 1.01\)。打开年份的收益率不需要，只要它们相同。
:::
:::

:::exercise 三个年份，其中一年关闭 {level=1 check="0.03929"}
滤波器是\((1, 0, 1)\)。风险收益率是\(0.05\)、\(0.20\)、\(-0.02\)。后备在关闭的年份里挣\(0.01\)。计算账簿的复合收益率。（输入那个复合收益率。）
:::solution
账簿返回\(0.05\)、\(0.01\)、\(-0.02\)。中间那个风险收益率\(0.20\)没有被挣到。因子是\(1.05 \times 1.01 \times 0.98 = 1.03929\)，所以复合收益率是\(0.03929\)。
:::
:::

:::exercise 同样的三年，用现金 {level=2 check="0.029"}
把上一题重复一遍，把\(0.01\)的后备换成收益率为\(0\)的现金。计算复合收益率。
:::solution
收益率是\(0.05\)、\(0\)、\(-0.02\)。因子是\(1.05 \times 0.98 = 1.029\)，所以复合收益率是\(0.029\)。财富水平之比\(1.03929 / 1.029 = 1.01\)，那就是[[#prop-ratio]]的一个关闭年份的情形。
:::
:::

:::exercise 分支内部的等权 {level=2 check="0.03"}
当滤波器打开时，四个编造的资产返回\(0.08\)、\(0.02\)、\(-0.04\)与\(0.06\)，在那一期里以等权的起始权重持有。计算分支的简单收益率。（输入分支收益率。）
:::solution
一期之内的等权起始权重给出算术平均：\((0.08 + 0.02 - 0.04 + 0.06)/4 = 0.12/4 = 0.03\)。这不是一个复合量，也不是一个后备收益率。
:::
:::

:::exercise 一个为负的中间年份 {level=2 check="-0.00187"}
各年收益率是\(0.05\)、\(-0.03\)、\(-0.02\)，它们已经是滤波器施加之后的账簿收益率。计算复合收益率。
:::solution
因子是\(1.05 \times 0.97 \times 0.98 = 0.99813\)。复合收益率是\(0.99813 - 1 = -0.00187\)。若把简单收益率相加，本会得到\(0\)，那是错误的对象。
:::
:::

:::exercise 四个关闭的年份 {level=3 check="1.04060401"}
一本后备账簿与一本现金账簿共享相同的打开年份收益率。后备收益率在四个关闭的年份里各为\(0.01\)，而现金在那些年份里挣\(0\)。计算期末财富之比，后备比现金。（输入那个比值。）
:::hint
打开年份的因子抵消。[[#eq-ratio]]留下\((1+f)\)的关闭年份数次方。这里\(f = 0.01\)，而有四个关闭的年份。不要把风险收益率插进那个比值。
:::
:::solution
比值是\((1.01)^4 = 1.04060401\)。任何共享的打开年份路径都同时乘在两个财富水平上，然后约掉。那个比值不是一个复合收益率；只有当问题要一个收益率时才减去一。
:::
:::

:::exercise 一条短路径之内的两个关闭年份 {level=3 check="0.03968592"}
滤波器是\((1, 0, 1, 0)\)。风险收益率是\(0.04\)、\(0.10\)、\(-0.02\)、\(0.07\)。后备在滤波器关闭时挣\(0.01\)。计算账簿的复合收益率。（输入那个复合收益率。）
:::hint
关闭的年份挣\(0.01\)，不是风险收益率\(0.10\)与\(0.07\)，也不是零。计算\(1.04 \times 1.01 \times 0.98 \times 1.01\)再减去\(1\)。
:::
:::solution
账簿返回\(0.04\)、\(0.01\)、\(-0.02\)、\(0.01\)。然后\(1.04 \times 1.01 = 1.0504\)，\(1.0504 \times 0.98 = 1.029392\)，而\(1.029392 \times 1.01 = 1.03968592\)。复合收益率是\(0.03968592\)。那些没有被使用的风险收益率并不进来。
:::
:::
