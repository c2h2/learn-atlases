美元中性把权重之和设为零。贝塔中性把贝塔的加权和设为零。在两个贝塔不同的名字上，那是两条不同的线，而它们只在原点相交。一本账簿可以满足一条而错过另一条。负权重上的一笔借券费会再次改变结果，无论一页已发表的页面是否提到那笔费用。

本章把库里那些配对页面与排名页面放进那个框架里。每一页在目录的描述里都有一条空头腿。空头腿是那条已发表规则的一部分。它不是做空一只股票、一只基金、一种货币或一份期货合约的指令，而本章从不把一侧的亏损变成持有另一侧的建议。容量——那本账簿本来可以有多大，多到它自己的交易动了价格为止——是库内那些页面不回答的一个问题。

## 两条约束

下面的贝塔是给定的数字，不是估计。一个没有系在一个窗口与一个基准上的贝塔，还不是一条约束；在代数里，那个数字只是一个叫\(\beta_i\)的输入。

:::definition 美元中性 {#def-dollar}
当\(\sum_i w_i = 0\)时，那些权重是**美元中性**的。**总**敞口是\(g = \sum_i |w_i|\)。例子里一个常用的规模是\(g = 1\)，于是一本两名字美元中性的账簿是\((1/2, -1/2)\)或\((-1/2, 1/2)\)。一期的简单收益率贡献，不计成本，是\(\sum_i w_i R_i\)。在规格说明说出用的是哪个分母之前，那个贡献既不是总敞口上的收益率，也不是只做多的净资产值上的收益率。这里它被报告为那些权重在其上被定义的那个净资产值的一个分数。
:::

:::definition 贝塔中性 {#def-beta}
给定贝塔\(\beta_i\)，当\(\sum_i w_i \beta_i = 0\)时，那些权重是**贝塔中性**的。美元中性不是这句话，除非每一个贝塔都等于同一个常数，或者那些权重全为零。一本只做多的账簿，\(w_i \ge 0\)，只在琐碎的情形里才是贝塔中性的，因为当贝塔为正时，非负项\(w_i \beta_i\)之和为零，只在每一项都为零的时候。本章里的市场中性例子因此使用一个负权重。那个负权重是一条线性约束里的一个坐标。它不是一条交易建议。
:::

:::proposition 只有零账簿同时站在两条线上 {#prop-only-zero}
设两个资产的贝塔为\(\beta_1 \ne \beta_2\)。既美元中性又贝塔中性的唯一权重是\(w_1 = w_2 = 0\)。
:::

:::proof
美元中性给出\(w_2 = -w_1\)。贝塔中性于是给出\(\beta_1 w_1 + \beta_2 (-w_1) = (\beta_1 - \beta_2)\, w_1 = 0\)。因为\(\beta_1 - \beta_2 \ne 0\)，所以\(w_1 = 0\)，然后\(w_2 = 0\)。当贝塔不同时，那两个方程是独立的：系数矩阵的行列式正比于\(\beta_2 - \beta_1 \ne 0\)，所以那个齐次方程组的唯一解是零。一份总敞口预算\(g = 1\)，不丢掉两个中性条件之一，或不加进第三个资产，就加不到那套方程之上。
:::

:::corollary 相等的贝塔把两条约束合并 {#cor-equal}
若\(\beta_1 = \beta_2 = \beta\)，则每一对美元中性的权重都是贝塔中性的，因为\(\beta w_1 + \beta w_2 = \beta\,(w_1 + w_2) = 0\)。反过来不是免费的：在一个共同的贝塔\(\beta \ne 0\)上，贝塔中性同样强迫\(w_1 + w_2 = 0\)，于是两条约束重合。若两个名字的\(\beta\)都是\(0\)，则每一个权重都是贝塔中性的，而美元中性是一个另外的要求。
:::

只做多的一期界限，在一个负权重之下活不下来。权重\((1/2, -1/2)\)，简单收益率\(0.01\)与\(-0.10\)，贡献是

$$
\frac12 \times 0.01 + \left(-\frac12\right) \times (-0.10) = 0.005 + 0.05 = 0.055,
$$

它落在从\(-0.10\)到\(0.01\)的那个区间之外。一本全额投资的只做多账簿打印不出那个数字。这个计算是关于那条约束的一个诊断。它不是去选择那个负权重的理由，而那些收益率是编造的。

:::example 两个名字，总敞口一 {#ex-two}
贝塔是\(1.2\)与\(0.8\)。求一个总敞口为\(1\)、第一个名字上权重为正的美元中性对。求一个总敞口为\(1\)、第一个名字上权重为正的贝塔中性对。计算美元中性那一对的贝塔，以及贝塔中性那一对的净美元之和。
:::solution
美元中性、总敞口\(1\)、且\(w_1 > 0\)，给出\(w_1 = 1/2\)，\(w_2 = -1/2\)。组合贝塔是

$$
1.2 \times \frac12 + 0.8 \times \left(-\frac12\right) = 0.6 - 0.4 = 0.2,
$$

不是零。那一对是美元中性的，而不是贝塔中性的。

贝塔中性给出\(1.2\, w_1 + 0.8\, w_2 = 0\)，所以\(w_2 = -1.5\, w_1\)。总敞口\(1\)与\(w_1 > 0\)给出\(w_1 + 1.5\, w_1 = 2.5\, w_1 = 1\)，于是\(w_1 = 0.4\)而\(w_2 = -0.6\)。核对贝塔：\(1.2 \times 0.4 + 0.8 \times (-0.6) = 0.48 - 0.48 = 0\)。净美元之和是\(0.4 + (-0.6) = -0.2\)，不是零。那一对是贝塔中性的，而不是美元中性的。[[#prop-only-zero]]说过，除非权重消失，两者不可能同时成立。在这里它们没有同时成立。相反的符号形态\((-0.4, 0.6)\)是另一个贝塔中性、总敞口\(1\)的解。它是同一条线把符号翻了过来，不是一个第二个经济学想法，也不是一笔受青睐的交易。
:::
:::

:::quiz
贝塔是\(1.2\)与\(0.8\)。哪一对权重是美元中性而非贝塔中性？
- [ ] \((0.4, -0.6)\)
- [x] \((0.5, -0.5)\)
- [ ] \((0, 0)\)
- [ ] \((0.6, 0.4)\)
:::solution
\((0.5, -0.5)\)相加为零，所以它是美元中性的，而它的贝塔是\(0.2 \neq 0\)。那一对\((0.4, -0.6)\)是贝塔中性的，相加为\(-0.2\)。零那一对满足两条约束，却在一条总敞口\(1\)上不合格。\((0.6, 0.4)\)是只做多的。
:::
:::

## 空头腿上的借券

一个负权重，在账簿的记账里是一个空头头寸。那些股票——如果它们是股票——必须被借入，而借券有费用。例子里的费用是每年空头名义额的\(0.5\%\)，写成\(b = 0.005\)。那个比率是一个易借的编造数字，供算术使用。它不是任何点名股票的报价。难借的名字成本更高，有时高得多。若一期不是一年，\(0.005\)就是一个错误的输入，直到它被换算。

:::algorithm 扣掉借券费之后 {#alg-borrow}
输入：权重\(w_i\)、同一期的简单收益率\(R_i\)，以及那一期的一笔借券比率\(b\)，按期初的空头名义额计收。
1. 价格贡献：\(\sum_i w_i R_i\)。
2. 空头占比：\(\sum_{i:\, w_i < 0} |w_i|\)。
3. 费用：\(b\)乘以空头占比。把它减掉。不要减\(b\)乘以总敞口，除非总敞口的每一个单位都是空头，而事实不是。
4. 假定：卖空所得款项没有返息，多头腿上没有额外的融资费用，以及一笔简单而非连续复利的费用。若那一页库内页面没有报告一笔借券费，就不要声称已报告的结果包含了它，也不要声称它为零。沉默不是一项测量。
:::

:::example 同样的收益率，两条约束 {#ex-borrow}
接下来的简单收益率是\(0.04\)与\(0.01\)，在贝塔\(1.2\)与\(0.8\)上。那一期是一年。借券比率是\(0.005\)，作用在空头占比上。使用[[#ex-two]]里总敞口为\(1\)的那些对，计算美元中性那一对、以及贝塔中性那一对\((0.4, -0.6)\)的价格贡献与扣掉借券后的净额。
:::solution
美元中性的价格贡献：

$$
\frac12 \times 0.04 + \left(-\frac12\right) \times 0.01 = 0.02 - 0.005 = 0.015.
$$

空头占比是\(1/2\)，所以费用是\(0.005 \times 1/2 = 0.0025\)。净额是\(0.015 - 0.0025 = 0.0125\)。

贝塔中性的价格贡献：

$$
0.4 \times 0.04 + (-0.6) \times 0.01 = 0.016 - 0.006 = 0.010.
$$

空头占比是\(0.6\)，所以费用是\(0.005 \times 0.6 = 0.003\)。净额是\(0.010 - 0.003 = 0.007\)。

那两个净额之所以不同，是因为约束不同，也因为空头占比不同。两个净额都不是预测。把费用丢掉，本会留下\(0.015\)与\(0.010\)，那是当[[#alg-borrow]]的第3步被省略时，一页页面所能打印的数字。那个省略只有当规格说明说费用为零、或说费用缺席时才看得见。一个空白格两样都没有说。
:::
:::

有了三个资产，那两个中性条件不再强迫零账簿。它们是三个未知数上的两个方程。一个规模条件把那个方程组封住。

:::example 三个名字，然后一笔费用压在一个持平的价格结果上 {#ex-three}
贝塔是\(1.2\)、\(0.8\)与\(1.0\)。与\((1, 1, -2)\)成比例的权重既美元中性又贝塔中性。把它们缩放到总敞口\(1\)。然后施加接下来的简单收益率\(0.03\)、\(0.01\)与\(0.02\)，以及作用在空头占比上的借券比率\(0.005\)。计算价格贡献与净额。
:::solution
未缩放的那些权重相加为\(1 + 1 - 2 = 0\)。贝塔是\(1.2 \times 1 + 0.8 \times 1 + 1.0 \times (-2) = 1.2 + 0.8 - 2 = 0\)。\((1, 1, -2)\)的总敞口是\(4\)。除以\(4\)给出\((1/4, 1/4, -1/2)\)，在两条线上仍然中性，总敞口为\(1\)。

价格贡献是

$$
\frac14 \times 0.03 + \frac14 \times 0.01 + \left(-\frac12\right) \times 0.02 = 0.0075 + 0.0025 - 0.010 = 0.
$$

空头占比是\(1/2\)。费用是\(0.0025\)。净额是\(0 - 0.0025 = -0.0025\)。两个中性都成立，加权价格收益率为零，而账簿仍然亏掉了那笔借券费。一个忽略费用的已报告结果会显示一本持平的账簿。持平的是价格。费用是第二条线。这就是为什么一页不提名借券的页面，不能被读成一份扣掉借券后的业绩记录。
:::
:::

:::widget rowreduce
matrix: 1,1,1,0; 6,4,5,0; 1,0,0,1
augmented: true
caption: 一步步化简到简化形式。第一行是美元中性。第二行是贝塔为1.2、0.8与1.0时的五倍贝塔中性。第三行把第一个权重设为1。你应该读出权重1、1与-2，然后，若想要总敞口1，除以总敞口4。那张图是一个线性方程组，不是预测，也不是一份要去空仓的名字清单。
:::

小部件的第三行是一个规模，不是一个市场。把它清掉，就产生[[#ex-three]]里那个未缩放的三元组。两个资产容不下那个非零解，这正是[[#prop-only-zero]]的又一次现身：一个右端为零的类似的两列方程组，化简到零权重。

:::example 一期，两个排名 {#ex-rank}
四个编造的名字按一个过去的收益率排序，而那个收益率只用来给它们排名。最高的过去收益率是名字A，最低的是名字D。接下来的简单收益率——那些权重不得预先使用它们——是A的\(-0.04\)与D的\(+0.08\)。规则H给A配\(+1/2\)，给D配\(-1/2\)。规则L给D配\(+1/2\)，给A配\(-1/2\)。借券为\(0.005\)，作用在\(1/2\)的空头占比上。计算两个净额。不要把任何一条规则当作一笔交易。
:::solution
规则H，做多过去的赢家、做空过去的输家，贡献是

$$
\frac12 \times (-0.04) + \left(-\frac12\right) \times 0.08 = -0.02 - 0.04 = -0.06
$$

在费用之前，而\(-0.06 - 0.0025 = -0.0625\)在费用之后。规则L，相反的那个配置，贡献是

$$
\frac12 \times 0.08 + \left(-\frac12\right) \times (-0.04) = 0.04 + 0.02 = 0.06
$$

在费用之前，而\(0.06 - 0.0025 = 0.0575\)在费用之后。那两条规则是不同的规格说明。在这一段编造的期间上，它们相差一个悬殊的幅度，而借券费没有翻转任何一个符号。一期不是一场检验。因为这一段偏爱规则L就选它，是看过接下来的收益率之后才选规则，那是非法的时钟。那些过去收益率从未进入盈利；它们只选出了那些权重。把它们当作\(\sum w_i R_i\)里的\(R_i\)来用，是第二个、分开的错误。
:::
:::

:::warning 中性不是一张费用豁免券
一个美元中性或贝塔中性的标签不会把借券费设为零，也不会把账簿收益率放回只做多的范围之内。本章前面那个\(0.055\)的贡献落在那个资产收益率区间之外，恰恰是因为那个负权重。减去一笔费用会让那个编造对上的净额成为\(0.0525\)，仍然在那个范围之外，仍然不是持有那一对的建议。另一个疏漏在言语上。目录那一行里的“做空输家”是对一条已发表排名的描述。把它当作建议来重复，是把一本教科书当作一个券商。这本书不是一个券商。
:::

## 四本带空头腿的库内账簿

W13、W14、W15与W16是开放库里的市场中性例子：两本配对账簿与两本排名账簿。配对构造住在回归课程，而排名的时钟由动量与横截面反转持有。本章的活是那条空头腿：中性、借券，以及一个已报告的总结可以摆在一条一行式条目从不提及的费用旁边这个事实。那些数字是按quants.md上对那些QuantJourney示例（Apache-2.0）的报告，2026年读入。本图谱没有重跑过那些回测。已报告的夏普是他们的数字，不是它们与我们的超额收益率约定相符的一份验证。四页页面里没有一页是做空那条规则里那些名字的建议。

W13是KO与PEP上的一对市场中性配对，使用一个对数比率的z分数，日K线，跨距26年。已报告总收益率为\(+48.8\%\)，已报告年化复合增长率为\(+1.54\%\)，已报告夏普比率为\(-0.05\)，最大回撤为\(-23.6\%\)，胜率为\(49.1\%\)，盈亏比为\(1.14\)。W14是EWA与EWC上的一对市场中性配对，使用一个滚动的普通最小二乘对冲比率，同样26年。已报告总收益率为\(+12.4\%\)，已报告年化复合增长率为\(+0.45\%\)，已报告夏普比率为\(-0.30\)，最大回撤为\(-14.3\%\)，胜率为\(50.2\%\)，盈亏比为\(1.06\)。

一个为正的总收益率摆一个为负的已报告夏普，可能的原因不止一个：他们的夏普之内有一个无风险利率，一个相对于一个很小的均值而言很大的波动率，或者一个本图谱没有见过的约定。本章不挑原因，也不“修正”那个夏普。那两个数字被允许立着。它们所不代表的东西是：一笔已经付清了借券的干净的市场中性盈利。目录那些行没有提到一笔借券费。已报告的结果也许漏掉了一笔。它也可能包含一笔一行式条目没有复述的费用。[[#alg-borrow]]是要问的那个问题，不是一个贴进他们的年化复合增长率里的数字。

W15按12个月收益率做多前三、做空后三，月度，跨距26年。已报告总收益率为\(+1.3\%\)，已报告年化复合增长率为\(+0.05\%\)，已报告夏普比率为\(-0.24\)，最大回撤为\(-25.4\%\)，胜率为\(49.4\%\)，盈亏比为\(1.00\)。W16按一个月收益率做多输家、做空赢家，周度，跨距26年。已报告总收益率为\(-1.7\%\)，已报告年化复合增长率为\(-0.07\%\)，已报告夏普比率为\(-0.24\)，最大回撤为\(-33.7\%\)，胜率为\(47.5\%\)，盈亏比为\(1.00\)。报告成\(1.00\)的盈亏比意味着，无论那一页用了什么单位，盈利与亏损几乎相抵。那些年化复合增长率接近零。那个近乎持平不是一份证明，证明相反的排名本来也会持平：成本与借券未必要对称。在[[#ex-rank]]里，那两个价格贡献是精确的相反数，而同样的借券费把两个净额都往下拉，所以那两个净额构成的对不再关于零对称。在26年之上，目录的W15与W16，就其已报告年化复合增长率而言，都只是接近持平，而相对于那些年化复合增长率有巨大的回撤。因为W16的总收益率为负就翻它的符号，会是一个已经看过W16的新实验。

那些名字KO、PEP、EWA与EWC出现，是因为它们是那些已发表规则里的工具。点名它们不是交易那一对的建议，也不是说那一对容易借券。那笔\(0.5\%\)的编造费用不是从那些名字估计出来的。

:::intuition 总敞口是空头腿的分母
美元中性让多头名义额与空头名义额相等，所以在总敞口\(1\)时，空头占比是\(1/2\)。贝塔不等时的贝塔中性会移动那个占比，正如\(-0.6\)相对\(+0.4\)所做的那样。费用在乎的是那个绝对空头权重，而不是贝塔之和是否为零。一个只核对\(\sum w_i \beta_i = 0\)、然后就对\(\sum w_i R_i\)复利的读者，核对了一条约束而跳过了[[#alg-borrow]]。两次核对都属于规格说明。通过一个不等于通过另一个。
:::

## 容量是一个问题，不是表格里的一格

库内那些页面没有说一本账簿本来可以有多大，大到它的订单动了价格为止。它们没有报告一个参与率或一条成交量序列。一个玩具会把那个缺失的输入摆得明明白白。假设一条规则拒绝超过一天成交量的\(5\%\)，价格是\(40\)个记账单位，而那一天的成交量是\(1\,000\,000\)股。那么股数上限是\(0.05 \times 1\,000\,000 = 50\,000\)股，而美元上限是\(50\,000 \times 40 = 2\,000\,000\)。改变那个\(5\%\)、那个成交量、或那个价格，上限就变。那三个数字没有一个在W13–W16的目录行里。那个\(2\,000\,000\)不是对任何点名配对的估计。它是一条那些页面没有声明的约束的算术。

盖特夫（Gatev）、戈茨曼（Goetzmann）与鲁文霍斯特（Rouwenhorst），在2006年的*Review of Financial Studies*上，发表了一条配对规则，其配对、入场、出场与延迟写得足够明确，可以与之争论。那个规格说明的标准，就是一本市场中性账簿欠读者的东西。它不是一条本章被允许编造的收益率序列，也不是W13。W13是另一页上的另一条配对规则。因为两样都说“配对”就把它们混为一谈，是一篇严谨的论文变成一个代码的方式。

:::remark 对冲比率不是什么
W14的对冲比率是一个滚动的回归系数，用来让一条腿相对另一条腿定规模。一个为\(h\)的对冲比率意味着规格说明从\(h\)设定那些相对权重。它不意味着那本账簿相对股票市场是贝塔中性的，除非\(h\)是作为那个贝塔、在一个写明的基准上估计的，而且那些权重被约束到它。美元中性、贝塔中性、以及一个回归对冲，是三句话。一页只说“市场中性”的页面，没有在那三者之间做选择。[[#ex-two]]就是前两句话已经有分歧的那个演示。
:::

:::history
埃文·盖特夫（Evan Gatev）、威廉·戈茨曼（William Goetzmann）与K·格尔特·鲁文霍斯特（K. Geert Rouwenhorst）在2006年的配对研究，是本章指向的那个规格说明标准：配对、入场、出场与延迟都写了下来，所以读者可以与它们争论。美元约束与贝塔约束是更老的组合事实；重述它们的要点，是[[#prop-only-zero]]里那个两名字的不可能性，而一个“市场中性”的标签常常跳过它。库内页面W13到W16是晚得多的教学例子，不是那篇2006年的论文，而它们已报告的总结里有回撤，W16那一页还有一笔为负的总收益率。一条完全写明的规则仍然可以亏钱。规格说明是你怎么知道是什么亏了的方式。它不是另一个符号的一个承诺。
:::

## 通往何处

一本在这门课里活下来的账簿，仍然需要一份写明的规格说明：样本池、时钟、公式、权重、成本，以及那个被主张的统计量。那份清单在[[research-craft/writing-a-specification]]。配对构造的更多细节在[[reversion/pairs-and-spreads]]，而只做多的对照在[[portfolio/long-only-and-neutral]]。期货与外汇那些章节，是一条空头腿是一份合约符号或一个报价符号、而不是一只借来的股票的地方。在每一种情形里，那个权重里的符号是一个坐标。它不是本图谱正在下的一张订单，也不是本图谱正在请你下的一张订单。

:::summary
- 美元中性是\(\sum w_i = 0\)。贝塔中性是\(\sum w_i \beta_i = 0\)。贝塔不等而只有两个名字时，两者只在零权重处成立（[[#prop-only-zero]]）。
- 在贝塔\(1.2\)与\(0.8\)上，总敞口\(1\)的美元中性对\((1/2, -1/2)\)的贝塔是\(0.2\)。贝塔中性那一对\((0.4, -0.6)\)的美元之和是\(-0.2\)。
- 一笔借券费是一个比率乘以空头占比。在每年\(0.005\)时，美元中性那个例子净额为\(0.0125\)，贝塔中性那个例子净额为\(0.007\)，在编造的收益率\(0.04\)与\(0.01\)上。
- 三个名字允许两个中性同时成立。缩放到总敞口\(1\)后，权重\((1/4, 1/4, -1/2)\)可以有一个为零的价格贡献，而在借券之后净额仍为\(-0.0025\)。
- 一个负权重可以把一个一期的贡献放到那些资产收益率的范围之外。那个事实不会把那条空头腿选为一笔交易。
- W13、W14、W15与W16在目录里都有一条空头腿。好几页报告一个为正的总收益率摆一个为负的夏普；W16报告一笔亏损。那些一行式条目里没有一条写明一笔借券费。本图谱没有重跑过它们，也不翻它们。
- 容量不在那些页面里。一个\(5\%\)的成交量上限是一个编造的输入，不是一个已报告的结果。那篇2006年的配对论文是一个规格说明的标准，不是一份代码清单。
:::

## 练习

:::exercise 美元中性那一对的贝塔 {level=1 check="0.2"}
权重是\(1/2\)与\(-1/2\)。贝塔是\(1.2\)与\(0.8\)。计算组合贝塔。（输入那个贝塔。）
:::solution
\(1.2 \times 1/2 + 0.8 \times (-1/2) = 0.6 - 0.4 = 0.2\)。美元中性成立。贝塔中性没有。
:::
:::

:::exercise 贝塔中性那一对的美元之和 {level=1 check="-0.2"}
权重是\(0.4\)与\(-0.6\)。权重之和是多少？（输入那个和。）
:::solution
\(0.4 + (-0.6) = -0.2\)。那一对仍然可以有零贝塔，正如在[[#ex-two]]里。一个零贝塔不是一个零美元之和。
:::
:::

:::exercise 美元中性扣除借券之后 {level=1 check="0.0125"}
价格贡献是\(0.015\)。空头占比是\(1/2\)。借券比率是\(0.005\)。计算净额。（输入那个净额。）
:::solution
费用是\(0.005 \times 1/2 = 0.0025\)。净额是\(0.015 - 0.0025 = 0.0125\)。
:::
:::

:::exercise 贝塔中性的价格贡献 {level=2 check="0.01"}
权重是\(0.4\)与\(-0.6\)。接下来的简单收益率是\(0.04\)与\(0.01\)。在任何一笔费用之前计算价格贡献。（输入那个贡献。）
:::solution
\(0.4 \times 0.04 + (-0.6) \times 0.01 = 0.016 - 0.006 = 0.01\)。那笔\(0.003\)的费用是后来的一次减法，不是这个数字的一部分。
:::
:::

:::exercise 在那个更大的空头之后 {level=2 check="0.007"}
从上一题里\(0.01\)的那个价格贡献出发。空头占比是\(0.6\)，借券比率是\(0.005\)。计算净额。（输入那个净额。）
:::solution
费用是\(0.005 \times 0.6 = 0.003\)。净额是\(0.01 - 0.003 = 0.007\)。空头占比大于\(1/2\)，因为这一对不是美元中性的。
:::
:::

:::exercise 一个持平的价格结果 {level=2 check="-0.0025"}
一本三名字账簿的价格贡献是\(0\)，空头占比是\(1/2\)。借券比率是\(0.005\)。计算净额。（输入那个净额。）
:::solution
费用是\(0.0025\)。净额是\(0 - 0.0025 = -0.0025\)。价格的持平付不了借券。
:::
:::

:::exercise 一个排名与一笔费用 {level=3 check="-0.0625"}
一个过去的收益率只用来排名。过去的赢家的下一个简单收益率是\(-0.04\)。过去的输家的下一个简单收益率是\(+0.08\)。权重是过去赢家上的\(+1/2\)与过去输家上的\(-1/2\)。借券为\(0.005\)，作用在空头占比上。计算净额。那个负权重是那条规则在这个编造排名上的输出，不是一张指令。（输入那个净额。）
:::hint
不要把那些权重乘以那些过去收益率。那条空头腿的下一个收益率是\(+0.08\)，而一个负权重乘一个正收益率是一笔亏损。价格贡献是\(-0.06\)。然后减去\(0.005 \times 1/2\)。
:::
:::solution
价格贡献：\((1/2) \times (-0.04) + (-1/2) \times 0.08 = -0.02 - 0.04 = -0.06\)。费用：\(0.0025\)。净额：\(-0.06 - 0.0025 = -0.0625\)。相反的排名是一条不同的规则，而题目没有要它。
:::
:::

:::exercise 相等的贝塔不豁免那笔费用 {level=3 check="0.0275"}
两个贝塔都是\(1.1\)。权重是\(1/2\)与\(-1/2\)，所以那一对既美元中性，又由[[#cor-equal]]是贝塔中性的。接下来的简单收益率是\(0.05\)与\(-0.01\)。借券为\(0.005\)，作用在空头占比\(1/2\)上。计算扣掉借券后的净额。（输入那个净额。）
:::hint
相等的贝塔让贝塔为零。题目要的不是贝塔。它要的是净额收益率。第二个权重为负而第二个收益率为负，所以那条腿在费用之前贡献一笔盈利。然后减去\(0.0025\)。
:::
:::solution
价格贡献：\((1/2) \times 0.05 + (-1/2) \times (-0.01) = 0.025 + 0.005 = 0.030\)。费用：\(0.0025\)。净额：\(0.030 - 0.0025 = 0.0275\)。组合贝塔是\(1.1 \times 1/2 + 1.1 \times (-1/2) = 0\)，它证实了[[#cor-equal]]，而不是那个答案字符串。
:::
:::
