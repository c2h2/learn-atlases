南非的季度实际国内生产总值、印度的月度消费者价格，以及奈拉的日度收盘报价，都以**时间上的序列**到来。相邻观测几乎从来不是相互独立的。一次高通货膨胀读数之后，通常跟着另一次高读数；一个产出下降的季度，更常跟着另一个疲弱季度，而不是繁荣。[[econometrics]]中的方法——普通最小二乘、$t$检验、$R^2$——是为随机样本推导的，在那种样本里观测的次序无关紧要。对时间序列来说，次序**就是**信息。把120个月的通货膨胀当作120次独立抽取，会得到过小的标准误，并且得到忽略样本中最有用事实的预测：上个月的通货膨胀是对本月的一个好猜测。

本章为这种相依性建立概率语言。一条时间序列是一个**随机过程**的一次实现。当过程的均值与自协方差不依赖于日期时，过程是**弱平稳**的。自协方差函数，以及由它得到的自相关函数，于是成为我们可以从一条有限记录中估计的、定义良好的对象。**白噪声**是没有序列相关的特例；它是本课程其余部分每一个线性模型由之装配起来的构件。这里用到的概率工具——数学期望、协方差、大数定律——在数学图谱中有完整发展；我们把它们引进来，而不是重新推导。

本章仅供教育学习。引用带有来源与日期的历史序列是为了说明概念；它们不是预测，这里也没有任何内容构成投资或理财建议。

## 时间序列数据

一条**时间序列**是以等间隔时间标号的序列$\{y_t\}_{t=1}^{T}$。间隔是定义的一部分：季度实际GDP与月度工业生产即使描述同一个经济体，也是不同的序列。本图谱中的典型来源是国家统计机构与中央银行数据库（FRED、ONS、Eurostat、IBGE、MOSPI、南非统计局、中国国家统计局、尼日利亚国家统计局）。在写下任何模型之前，必须回答三个平凡问题，因为它们会改变被建模的对象。

- **水平还是变换。**许多宏观序列在对数上分析，从而使一阶差分近似为增长率。价格指数$P_t$变成$p_t = \log P_t$，且$\Delta p_t \approx (P_t - P_{t-1})/P_{t-1}$。金融资产的收益率常被算成$r_t = \log P_t - \log P_{t-1}$；这一选择及其局限在[[asset-pricing/returns-and-risk]]中讨论。本课程中的示例数字不是计算、持有或交易任何收益率的建议。
- **季节调整。**月度零售额与季度GDP具有季节成分。统计机构常常公布季节调整后的数据版本；使用它再加入季节虚拟变量，会把季节算两遍。使用未调整版本又忽略季节，会留下一个看起来像序列相关的周期性均值。
- **修订与数据版本。**宏观数据会被修订。用2020年版本的GDP增长对一项政策冲击做回归，与用同一批日期的2026年版本做回归，不是同一次回归。时间序列计量经济学施加于一个选定的数据版本；版本是数据描述的一部分。

::: definition 随机过程与实现 {#def-process}
**随机过程**是定义在同一个概率空间上的一族随机变量$\{Y_t : t \in \Z\}$。一次**实现**（或样本路径）是整族的一次抽取，记为$\{y_t\}$。计量经济学家观测到一次实现的有限片段$y_1,\ldots,y_T$，并希望对生成它的过程说些什么。
:::

过程与实现的区分不是学究气。对住户的随机样本，我们观测同一个随机变量的许多独立副本。对时间序列，我们观测**一条**过程副本的许多日期。要从一条路径学习$Y_t$的均值，需要这条路径造访过程的典型行为——而这正是平稳性与遍历性所编码的。

::: example 一条短的虚构路径 {#ex-path}
一条虚构的季度增长率（百分点，不是某个真实国家的数据）读作

$$
1.2,\ 0.4,\ -0.3,\ 0.8,\ 1.1,\ 0.2,\ -0.5,\ 0.6.
$$

计算样本均值以及前两个样本自协方差，自协方差使用除数$T$（下文[[#def-sample-acf]]的惯例）。
::: solution
这里$T = 8$，且$\bar y = (1.2+0.4-0.3+0.8+1.1+0.2-0.5+0.6)/8 = 3.5/8 = 0.4375$。去均值后的值为

$$
0.7625,\ -0.0375,\ -0.7375,\ 0.3625,\ 0.6625,\ -0.2375,\ -0.9375,\ 0.1625.
$$

以$T$为除数的样本方差是$\hat\gamma_0 = T^{-1}\sum_{t=1}^{T}(y_t-\bar y)^2 = 2.77375/8 = 0.3467$（四位小数）。滞后1自协方差是$\hat\gamma_1 = T^{-1}\sum_{t=2}^{T}(y_t-\bar y)(y_{t-1}-\bar y) = -0.3766/8 = -0.0471$。滞后2自协方差是$\hat\gamma_2 = T^{-1}\sum_{t=3}^{T}(y_t-\bar y)(y_{t-2}-\bar y) = -0.5481/8 = -0.0685$。相应的样本自相关是$\hat\rho_1 = \hat\gamma_1/\hat\gamma_0 = -0.136$以及$\hat\rho_2 = -0.198$。长度为8的路径太短，这些数字说明不了多少；它们说明的是算术，而不是关于增长的发现。
:::
:::

## 弱平稳性

一个过程可以是严平稳的——每一个有限集合$(Y_{t_1+k},\ldots,Y_{t_n+k})$对每一个平移$k$都有相同的分布——也可以是弱平稳的，后者只限制前二阶矩。弱平稳性是ARMA建模所使用的，并且除非加上更严格的限定，本课程所说的“平稳”就是这个意思。

::: definition 弱平稳性 {#def-weak-stat}
过程$\{Y_t\}$是**弱平稳**的（协方差平稳的），如果

1. $\E[Y_t] = \mu$有限且不依赖于$t$；
2. $\Var(Y_t) = \gamma_0$有限且不依赖于$t$；
3. $\Cov(Y_t, Y_{t-k}) = \gamma_k$存在，并且对$t$与$t-k$的依赖只通过滞后$k$。

序列$\{\gamma_k\}_{k\in\Z}$是**自协方差函数**。它满足$\gamma_{-k} = \gamma_k$以及$|\gamma_k| \le \gamma_0$。
:::

第三条是重要的那一条。对弱平稳过程，本季度与上季度之间的协方差，与1987年第二季度和1987年第一季度之间的协方差是同一个数。这是一个假设，不是一个事实：战争、货币制度的改变或大流行病都可以打破它。后面章节的诊断，部分就是检查这一假设对手头样本并非毫无希望。

两个不满足[[#def-weak-stat]]的过程不断出现，并将占据[[time-series/unit-roots]]。

- **确定性趋势**$Y_t = \alpha + \delta t + U_t$，其中$\{U_t\}$平稳，其均值随$t$增长。去势序列$Y_t - \hat\alpha - \hat\delta t$可以是平稳的。
- **随机游走**$Y_t = Y_{t-1} + \varepsilon_t$，其中$\varepsilon_t$为白噪声，若$Y_0 = 0$则$\Var(Y_t) = t\,\sigma^2$，无界增长。恢复平稳性的运算是差分，而不是去势。

::: warning 平稳并不等于“看起来平坦”
一条序列可以游荡很久而仍然平稳：系数为$0.95$的AR(1)均值回复慢到几百个观测的样本看起来像随机游走。反过来，随机游走在某个特定样本里也可以看起来像在向均值回复。用眼睛看图不是检验。样本自相关函数以及[[time-series/unit-roots]]中的单位根检验，才是使这一区分可操作的工具。
:::

::: intuition 为什么均值必须是常数
如果$\E[Y_t]$依赖于$t$，样本平均$\bar y = T^{-1}\sum_{t=1}^{T} y_t$就是不同均值的平均。在温和条件下，它收敛到这些均值在样本上的平均，而不是过程“那个”均值——根本没有那一个。把$\bar y$当作长期水平的预测于是会系统地偏离。这是在谈论序列相关**之前**对趋势序列做差分、或加入时间趋势的最简单理由。
:::

只要二阶矩存在，严平稳就蕴含弱平稳。反过来不成立：一个过程可以有常数均值和自协方差，而条件分布的方差仍随$t$变化，无条件方差却看不见这一点。[[time-series/volatility]]中的GARCH过程（在参数限制下）是弱平稳的，但不是独立同分布的；它们的条件方差在变动，尽管$\gamma_0$不变。

## 自协方差与自相关

弱平稳过程的自协方差函数若用方差来缩放，跨序列就更容易比较。

::: definition 自相关函数 {#def-acf}
弱平稳过程的**自相关函数**（ACF）是

$$
\rho_k = \frac{\gamma_k}{\gamma_0} = \Corr(Y_t, Y_{t-k}), \qquad k \in \Z.
$$

特别地$\rho_0 = 1$且$|\rho_k| \le 1$。**偏自相关**$\phi_{kk}$是在对$Y_{t-1},\ldots,Y_{t-k+1}$做线性投影并偏掉之后，$Y_t$与$Y_{t-k}$的相关；它在[[time-series/arma-models]]中构造。
:::

一对随机变量的协方差与相关在数学图谱中定义（[联合分布](/a/maths/lesson.php?c=probability&l=joint-distributions&lang=zh)）。这里唯一的新要素是这一对是$(Y_t, Y_{t-k})$，并且平稳性使相关只是$k$的函数。

一类作为本章贯穿例子、并在下一章充分发展的平稳过程，是**一阶自回归**。

::: proposition AR(1)的ACF {#prop-ar1-acf}
设$\varepsilon_t$是方差为$\sigma^2$的白噪声，并且

$$
Y_t = c + \phi Y_{t-1} + \varepsilon_t, \qquad |\phi| < 1.
$$ {#eq-ar1}

则$\{Y_t\}$弱平稳，且

$$
\mu = \frac{c}{1-\phi}, \qquad \gamma_0 = \frac{\sigma^2}{1-\phi^2}, \qquad \rho_k = \phi^{|k|}.
$$
:::

::: proof
把[[#eq-ar1]]向后迭代$n$步：

$$
Y_t = c\frac{1-\phi^n}{1-\phi} + \phi^n Y_{t-n} + \sum_{j=0}^{n-1} \phi^j \varepsilon_{t-j}.
$$

当$n\to\infty$时，因为$|\phi|<1$故$\phi^n \to 0$，并且无穷和$\sum_{j=0}^{\infty}\phi^j\varepsilon_{t-j}$均方收敛（其方差$\sigma^2\sum\phi^{2j} = \sigma^2/(1-\phi^2)$有限）。取期望得$\mu = c/(1-\phi)$。去均值过程$X_t = Y_t - \mu$满足$X_t = \phi X_{t-1} + \varepsilon_t$。于是$\gamma_0 = \E[X_t^2] = \phi^2\gamma_0 + \sigma^2$，所以$\gamma_0 = \sigma^2/(1-\phi^2)$。对$k\ge 1$，$\gamma_k = \E[X_t X_{t-k}] = \phi\,\E[X_{t-1}X_{t-k}] = \phi\gamma_{k-1}$，迭代即得$\gamma_k = \phi^k\gamma_0$。
:::

条件$|\phi|<1$是AR(1)的平稳性条件。若$\phi = 1$，过程是随机游走（带漂移$c$），这是[[time-series/unit-roots]]的主题。若$|\phi|>1$，过程可以改写成在时间变号后平稳的前瞻序列，但那种表示对向前记录的经济数据很少有用。

::: example AR(1)的理论ACF {#ex-ar1-theo}
对[[#eq-ar1]]取$\phi = 0.7$、$c = 0$且$\sigma^2 = 1$，计算$\mu$、$\gamma_0$以及$k = 1,\ldots,5$的$\rho_k$。对$\phi = -0.6$再做一遍。
::: solution
$c = 0$时$\mu = 0$。对$\phi = 0.7$，

$$
\gamma_0 = \frac{1}{1-0.49} = \frac{1}{0.51} \approx 1.961,
$$

且$\rho_k = 0.7^k$，所以

$$
\rho_1 = 0.700,\ \rho_2 = 0.490,\ \rho_3 = 0.343,\ \rho_4 = 0.240,\ \rho_5 = 0.168.
$$

ACF为正并几何衰减。对$\phi = -0.6$，$\gamma_0 = 1/(1-0.36) = 1/0.64 = 1.5625$且$\rho_k = (-0.6)^k$，所以

$$
\rho_1 = -0.600,\ \rho_2 = 0.360,\ \rho_3 = -0.216,\ \rho_4 = 0.130,\ \rho_5 = -0.078.
$$

ACF符号振荡，仍然几何衰减。两种情形都有$|\rho_k|\to 0$，这就是平稳AR(1)“忘记”其起点的含义。
:::
:::

::: widget plot

sliders: phi=0.7:0.05:0.95:0.05
x: 0, 16

:::

同样的几何衰减就是AR(1)的脉冲响应：一单位冲击$\varepsilon_t$平均使$Y_{t+k}$提高$\phi^k$。ACF的缓慢衰减与长寿命的脉冲响应是同一件事实。

## 白噪声

本课程中每一个线性时间序列模型，都由一个从其自身过去不可预测的冲击序列驱动。

::: definition 白噪声 {#def-wn}
过程$\{\varepsilon_t\}$是**白噪声**，记作$\varepsilon_t \sim \mathrm{WN}(0,\sigma^2)$，如果$\E[\varepsilon_t] = 0$，$\Var(\varepsilon_t) = \sigma^2 < \infty$，并且对每一个$k \neq 0$有$\Cov(\varepsilon_t, \varepsilon_{t-k}) = 0$。它是**强白噪声**（或独立同分布白噪声），如果$\varepsilon_t$独立同分布、均值为$0$、方差为$\sigma^2$。高斯白噪声是独立同分布$\Normal(0,\sigma^2)$。
:::

白噪声是弱平稳的，对$k \neq 0$有$\rho_k = 0$。强白噪声是严平稳的特例。这一区分对波动率很要紧：GARCH过程可以有不相关的水平（因而水平是白噪声），而**平方**却有很强的序列相关。把一条收益率序列叫做“白噪声”，并不是说它独立同分布，也不是说它是高斯的。

::: proposition 白噪声的自协方差 {#prop-wn}
若$\varepsilon_t \sim \mathrm{WN}(0,\sigma^2)$，则$\gamma_0 = \sigma^2$，且对$k \neq 0$有$\gamma_k = 0$。因此ACF是滞后$0$处的一个尖峰。线性组合$Y_t = \mu + \sum_{j=0}^{\infty} \psi_j \varepsilon_{t-j}$（$\sum_j \psi_j^2 < \infty$）是弱平稳的，且

$$
\gamma_k = \sigma^2 \sum_{j=0}^{\infty} \psi_j \psi_{j+k}.
$$ {#eq-wold-gamma}
:::

::: proof
关于$\varepsilon_t$的陈述就是定义。对线性组合，$\E[Y_t] = \mu$，因为每个$\varepsilon$均值为零。协方差公式是$\E[(Y_t-\mu)(Y_{t-k}-\mu)]$的双线性展开，其中$\E[\varepsilon_{t-j}\varepsilon_{t-k-\ell}] = \sigma^2$仅当指标匹配，即$j = \ell + k$，否则为零。无穷和的均方收敛由$\sum\psi_j^2 < \infty$得出。
:::

[[#eq-wold-gamma]]是ARMA建模的计算引擎。沃尔德（Wold）于1938年证明的分解说了更强的话：**每一个**弱平稳、纯非确定性过程都有这样的表示，其中$\psi_0 = 1$，且$\varepsilon_t$等于一步预测误差。下一章的ARMA模型，就是$\psi_j$服从线性递推的参数化特例。

::: quiz
下列哪个过程是弱平稳的？
- [ ] $Y_t = 0.3\, t + \varepsilon_t$，其中$\varepsilon_t \sim \mathrm{WN}(0,1)$
- [x] $Y_t = 2 + 0.8 Y_{t-1} + \varepsilon_t$，其中$\varepsilon_t \sim \mathrm{WN}(0,1)$
- [ ] $Y_t = Y_{t-1} + \varepsilon_t$，其中$\varepsilon_t \sim \mathrm{WN}(0,1)$且$Y_0 = 0$
- [ ] $Y_t = \varepsilon_t^2$，其中$\varepsilon_t = t^{-1/2} \eta_t$且$\eta_t \sim \mathrm{WN}(0,1)$
::: solution
该AR(1)有$|\phi| = 0.8 < 1$，故[[#prop-ar1-acf]]适用：它弱平稳，均值为$2/(1-0.8) = 10$。线性趋势有随时间变化的均值。随机游走有$\Var(Y_t) = t$。最后一个过程有$\Var(Y_t) = \E[\varepsilon_t^4]$，即使$\eta_t$是高斯的，它也通过$\E[\varepsilon_t^4]$中的因子$t^{-2}$依赖于$t$。
:::
:::

## 样本ACF

给定长度为$T$的一次实现，$\mu$与$\gamma_k$的自然估计量用样本平均代替期望。因为我们只有一条路径，这些平均是对时间取的，而不是对独立副本取的。当过程对相关矩遍历时，这是正当的：时间平均收敛到总体平均。对自协方差绝对可和的弱平稳过程，$\sum_k |\gamma_k| < \infty$，均值与自协方差的遍历性成立；AR根在单位圆外的ARMA过程满足该条件。背后的[大数定律](/a/maths/lesson.php?c=probability&l=limit-theorems&lang=zh)与独立同分布情形是同一个想法，相依性衰减得足够快，以扮演独立性的角色。

::: definition 样本均值与样本ACF {#def-sample-acf}
对样本$y_1,\ldots,y_T$，**样本均值**是$\bar y = T^{-1}\sum_{t=1}^{T} y_t$。滞后$k \ge 0$的**样本自协方差**是

$$
\hat\gamma_k = \frac{1}{T} \sum_{t=k+1}^{T} (y_t - \bar y)(y_{t-k} - \bar y),
$$

**样本自相关**是$\hat\rho_k = \hat\gamma_k / \hat\gamma_0$。除数是$T$，不是$T-k$：这使样本自协方差矩阵保持半正定。
:::

在弱平稳且$\sum |\gamma_k| < \infty$时，$\bar y$对$\mu$一致，渐近方差为$T^{-1}\sum_{k=-\infty}^{\infty}\gamma_k$。相对独立同分布公式$\sigma^2/T$多出来的因子$\sum_k \rho_k$，就是序列相关的代价：正的$\rho_k$放大样本均值的方差，这就是忽略序列相关的OLS标准误过小的原因（[[econometrics/inference]]）。

对样本ACF本身，巴特利特（Bartlett）的一个经典结果在真值为白噪声时给出可用的标准误。

::: proposition 白噪声的巴特利特公式 {#prop-bartlett}
若$\{Y_t\}$独立同分布且四阶矩有限，则对每个固定的$k \ge 1$，

$$
\sqrt{T}\,\hat\rho_k \ \to_d\ \Normal(0, 1).
$$

因此白噪声原假设下$\hat\rho_k$的近似95%带是$\pm 1.96/\sqrt{T}$。更一般地，若$Y_t$是白噪声（不相关，不必独立同分布），四阶矩有限，且对$k \neq \ell$有$\E[Y_t^2 Y_{t-k} Y_{t-\ell}] = 0$，则同样的$\Normal(0,1)$极限成立。
:::

::: proof
在独立同分布下，$\hat\gamma_k = T^{-1}\sum_{t=k+1}^{T} (Y_t-\bar Y)(Y_{t-k}-\bar Y)$是均值为零的项的样本平均，外加$\bar Y$的一个$O_p(T^{-1})$贡献。中心极限定理（[极限定理](/a/maths/lesson.php?c=probability&l=limit-theorems&lang=zh)）给出$\sqrt{T}\,\hat\gamma_k \to_d \Normal(0, \gamma_0^2)$。斯卢茨基（Slutsky）引理与$\hat\gamma_0 \to_p \gamma_0$给出$\hat\rho_k$的结果。不相关情形用鞅差中心极限定理代替独立同分布中心极限定理；额外的矩限制消灭了不同滞后求和项之间的协方差。
:::

带$\pm 1.96/\sqrt{T}$画在应用工作中的每一张相关图上。它是白噪声原假设下的**逐点**带，不是许多滞后的同时带，并且在序列相关时并不成立。对$\phi = 0.7$的AR(1)，$\Var(\hat\rho_1)$小于$1/T$，而大$k$的$\Var(\hat\rho_k)$更大；用白噪声带来“看滞后8是否显著”，是对[[#prop-bartlett]]的误读。

一次看许多滞后的综合统计量是Ljung-Box的$Q$。

::: definition Ljung-Box统计量 {#def-lb}
滞后$h$的**Ljung-Box统计量**是

$$
Q(h) = T(T+2)\sum_{k=1}^{h} \frac{\hat\rho_k^2}{T-k}.
$$

在序列独立同分布的原假设下（或者，对估计的ARMA$(p,q)$残差，在**新息**独立同分布的原假设下），且$h$固定时，$Q(h) \to_d \chi^2_{h}$（残差则为$\chi^2_{h-p-q}$）。大的$Q$拒绝不相关性。
:::

$\chi^2$近似是大样本陈述；关于$p$值的含义见[假设检验](/a/maths/lesson.php?c=statistics&l=hypothesis-testing&lang=zh)。拟合模型后的残差$Q$检验在[[time-series/arma-models]]中讨论。

::: example 白噪声，种子42 {#ex-wn-sim}
一条长度为$T = 200$的高斯白噪声序列按$\varepsilon_t \iid \Normal(0,1)$抽取，NumPy种子为$42$。前八个值是$0.497$，$-0.138$，$0.648$，$1.523$，$-0.234$，$-0.234$，$1.579$，$0.767$。样本均值是$-0.041$，样本方差（除数$T-1$）是$0.867$。滞后$1$到$8$的样本ACF是

$$
-0.052,\ -0.039,\ 0.002,\ -0.120,\ 0.109,\ 0.052,\ 0.043,\ -0.061.
$$

这里有任何与白噪声矛盾的东西吗？计算95%巴特利特带以及等于$8.85$的Ljung-Box $Q(10)$。
::: solution
巴特利特带是$\pm 1.96/\sqrt{200} = \pm 0.139$。每一个报告的$\hat\rho_k$都落在带内；绝对值最大的是$\hat\rho_4 = -0.120$。在白噪声原假设下这并不令人意外：八个滞后里偶尔会有接近边界的。Ljung-Box统计量$Q(10) = 8.85$与$\chi^2_{10}$比较，后者的5%临界值是$18.31$。$p$值是$0.55$。样本不拒绝白噪声，它本来就不该拒绝：它就是从白噪声抽出的。样本方差$0.867$略低于$1$，因为$T = 200$有限；那是抽样变异，不是设定错误。
:::
:::

::: example AR(1)的样本ACF，种子7 {#ex-ar1-sim}
从$Y_t = 0.7 Y_{t-1} + \varepsilon_t$、$\varepsilon_t \iid \Normal(0,1)$、NumPy种子$7$抽取长度为$250$的AR(1)，丢掉前$50$个观测作为预热，留下$T = 200$。样本均值是$-0.035$，样本方差是$1.591$（理论方差是$1.961$）。样本与理论自相关：

| 滞后$k$ | $1$ | $2$ | $3$ | $4$ | $5$ | $6$ | $7$ | $8$ |
|---|---|---|---|---|---|---|---|---|
| $\hat\rho_k$ | $0.675$ | $0.472$ | $0.358$ | $0.266$ | $0.170$ | $0.176$ | $0.155$ | $0.111$ |
| $\phi^k$ | $0.700$ | $0.490$ | $0.343$ | $0.240$ | $0.168$ | $0.118$ | $0.082$ | $0.058$ |

$y_t$对常数与$y_{t-1}$的OLS回归给出$\hat\phi = 0.679$（标准误$0.052$）。样本ACF与[[#prop-ar1-acf]]相比如何，白噪声巴特利特带$\pm 0.139$又错误地暗示了什么？
::: solution
样本ACF在前五个滞后紧密跟踪$\phi^k$，其后略高——这是$T = 200$时普通的抽样变异。OLS估计$0.679$比$0.7$低$0.4$个标准误。巴特利特带$\pm 0.139$是**白噪声**带。在它之下，滞后$1$到$8$都会被宣布“显著”，这在定性上是对的（序列不是白噪声），但一旦承认相依性，它对任何一个特定$\hat\rho_k$都是错误的标准误。水平值上的Ljung-Box $Q(10)$是$199.1$，在任何常规水平上拒绝白噪声。在OLS残差上它是$5.53$（相对$\chi^2_9$的$p = 0.79$），这正是设定良好的AR(1)应当产生的。
:::
:::

负的$\phi$产生振荡的ACF，如[[#ex-ar1-theo]]。一条$\phi = -0.6$、种子$8$、预热后$T = 200$的模拟AR(1)，样本ACF为

$$
-0.503,\ 0.164,\ 0.034,\ -0.035,\ -0.006,\ -0.081

对照理论值$-0.600$，$0.360$，$-0.216$，$0.130$，$-0.078$，$0.047$。前两个滞后符号正确、数量级正确；更高滞后嘈杂，因为$\phi^k$已经很小。

::: quiz
一条长度为$T = 100$的月度序列有$\hat\rho_1 = 0.22$和$\hat\rho_{12} = 0.41$。只用白噪声巴特利特带，哪一句陈述是合理的？
- [ ] 两个滞后都与白噪声一致，因为$0.22 < 1$
- [ ] 只有滞后$1$是不利于白噪声的证据
- [x] 滞后$12$远在$\pm 1.96/\sqrt{100} = \pm 0.196$之外，因此白噪声不是好的描述；季节ARMA项是一个候选
- [ ] 样本ACF在滞后$12$不能用，因为$12 > \sqrt{T}$
::: solution
白噪声下的逐点95%带是$\pm 0.196$。于是$0.22$在滞后$1$是温和拒绝，$0.41$在滞后$12$是清楚拒绝。月度序列在滞后$12$常常有季节尖峰；那是建模线索，不是丢掉该滞后的理由。没有ACF在$\sqrt{T}$之外就不能用的规则，尽管$\hat\rho_k$的方差确随$k$增大，非常大的$k$（$T$的可观比例）不应被过度解释。
:::
:::

## 证据：经济序列中的持续性

某一条经济序列是更好地近似为均值周围的平稳、趋势周围的平稳，还是一阶单整，这是一个经验问题，而且是有争议的。本课程的其余部分发展这些检验。若干有文献记载的规律性先定下场景；它们是典型化事实，不是定理。

实际产出的增长率比产出的**水平**更接近平稳。对美国，季度实际GDP（FRED序列GDPC1，2017年链式美元，季节调整）在1947–2024年的水平上有强烈上升趋势；其环比对数差分的样本一阶自相关通常在$0.2$–$0.4$范围内，取决于确切窗口（一个有代表性的1984年后窗口偏向较低端）。纳尔逊（Nelson）与普洛瑟（Plosser）（1982年，*Journal of Monetary Economics*）不能拒绝14条历史美国宏观序列中13条**水平**上的单位根；他们的论文启动了[[time-series/unit-roots]]的单位根文献。随后的工作（Perron 1989；Rudebusch 1993；Christiano and Eichenbaum 1990）表明，在几百个观测的样本里，趋势断裂与单位根的区分很难做出。争论在如下强的意义上尚未解决：对同一官方序列、统计上站得住的不同变换，导向不同的短期模型。

通货膨胀是持续的，但有多持续取决于货币制度。对英国，年度CPI通货膨胀（ONS，2015=100）在1970年代高且持续，然后在1992年通货膨胀目标制以及1997年英格兰银行独立之后更低。在一个“大稳健”窗口上对月度通货膨胀计算的一阶自相关，远小于1970–1990年的同一统计量。南非CPI通货膨胀（南非统计局）与巴西IPCA通货膨胀（IBGE）显示同样的定性模式：持续性是一个样本的性质，不是“通货膨胀”的不变量。因此，把整个战后样本建模为一条平稳AR(1)，是一个应当加以论证、而不是假定的设定选择。

相比之下，金融收益率在日度和周度水平上的样本自相关通常很小。法马（Fama）（1965年，*Journal of Business*）对美国股票记录了这一点；孔特（Cont）（2001年，*Quantitative Finance*）把“没有线性自相关”列为资产收益率的典型化事实之一，同时还有平方收益率中**存在**强自相关——波动聚集，即[[time-series/volatility]]的主题。收益率的小自相关不是有效市场的定理，也不是对未来收益率的预测。它是带有来源与日期的样本规律性，并且既与鞅差模型相容，也与带有一个小的、难以探测的可预测成分的模型相容（[[time-series/financial-econometrics]]）。

另一种证据是季节性。印度的工业生产指数（MOSPI）与中国的工业增加值序列（国家统计局）有很强的年内模式；几乎每一个公布零售额的国家也是如此。季节未调整月度序列的样本ACF通常在滞后$12$、$24$、$36$显示尖峰。那些尖峰不是在滞后$1$差分的理由；它们是使用季节滤波、季节虚拟变量或季节ARMA项的理由。

::: application 持续序列的样本均值
设月度通货膨胀是$\phi = 0.8$、新息方差为$\sigma^2$的AR(1)，我们从$T = 120$个月估计均值。$\bar y$的渐近方差是

$$
\frac{\gamma_0}{T}\sum_{k=-\infty}^{\infty}\rho_k = \frac{\sigma^2}{T(1-\phi)^2(1+\phi)}\cdot(1+\phi) = \frac{\sigma^2}{T(1-\phi)^2},
$$

这是独立同分布公式$\gamma_0/T$的$(1+\phi)/(1-\phi) = 9$倍。使用$s/\sqrt{T}$的置信区间窄了三倍。这就是在报告“平均通货膨胀率”、仿佛各月是随机样本时，忽略[[#def-weak-stat]]与[[#prop-ar1-acf]]的一个具体代价。
:::

::: widget distribution
dist: normal
params: mu=0, sigma=1
a: -1.96
b: 1.96
caption: 在白噪声原假设下，$\sqrt{T}\,\hat\rho_k$近似标准正态（[[#prop-bartlett]]）。给$\pm 1.96$涂阴影，并与乘以$\sqrt{T}$的样本自相关比较。对$T = 200$，[[#ex-wn-sim]]中使用的带$\pm 0.139$正是这一区间映射回$\hat\rho$尺度。拖动边界，并记住这一校准是针对一个滞后的，不是针对二十个滞后的捕捞。
:::

## 由此通向何处

一条带有衰减ACF的弱平稳序列，是[[time-series/arma-models]]的原材料：我们将把参数化的ACF（自回归、移动平均或混合）与样本ACF匹配，并估计参数。那些模型产生[[time-series/forecasting]]的最小均方误差预测。当样本ACF衰减过慢，或当$\hat\rho_1$接近$1$时，平稳性假设本身就成问题，于是[[time-series/unit-roots]]接手。若干这样的序列仍可能一起运动；那就是协整（[[time-series/cointegration]]）。若干序列被联合建模、而不先对外生与内生表态，就是向量自回归（[[time-series/var-models]]）。而一条**水平**看起来像白噪声、**平方**却不像的序列，是[[time-series/volatility]]的起点。

始终，概率模型才是兴趣对象。样本ACF是对$\rho_k$的估计，不是独立于过程的“数据”性质。改变样本、变换或季节滤波会改变估计，因为它改变了被近似的过程。

::: history
**1926年，尤尔（G. Udny Yule）。**在“为什么我们有时会在时间序列之间得到无意义相关？”一文中，尤尔表明两条独立的单整序列可以呈现很大的样本相关。该文是伪回归文献的祖先。

**1927年，斯卢茨基（Eugen Slutsky）。**斯卢茨基表明，对白噪声求和（移动平均）会产生看起来像经济周期的循环——这是对图中的周期性并非周期机制之证据的警告。

**1938年，沃尔德（Herman Wold）。**沃尔德的《平稳时间序列分析研究》（*A Study in the Analysis of Stationary Time Series*）证明，每一个弱平稳、纯非确定性过程都有以其新息表示的无限移动平均表示。线性时间序列建模从此一直是那种表示的参数化版本。

**1976年，博克斯（George Box）与詹金斯（Gwilym Jenkins）**（1970年著作的第二次印刷）。他们的识别–估计–检验循环，使样本ACF与PACF成为应用工作者观察平稳序列的标准图像。
:::

::: summary
- 时间序列是随机过程的一次实现。从一条路径学习过程需要平稳性（以及遍历性）：不依赖于日期的均值与自协方差（[[#def-process]]，[[#def-weak-stat]]）。
- ACF $\rho_k = \gamma_k/\gamma_0$概括线性序列相依。对平稳AR(1)，$\rho_k = \phi^{|k|}$且$|\phi|<1$（[[#prop-ar1-acf]]）。
- 白噪声是不相关的（不必独立同分布或高斯），并且是线性模型的构件（[[#def-wn]]，[[#prop-wn]]）。
- 样本ACF $\hat\rho_k$在$\gamma_k$可和时一致。在白噪声下，$\sqrt{T}\,\hat\rho_k \approx \Normal(0,1)$，给出带$\pm 1.96/\sqrt{T}$（[[#prop-bartlett]]）。Ljung-Box的$Q$一次检验许多滞后（[[#def-lb]]）。
- 增长率比水平更接近平稳；通货膨胀持续性取决于货币制度；日度收益率往往有小的$\hat\rho_k$但有大的$\widehat{\Corr}(r_t^2, r_{t-k}^2)$。这些是带有来源的样本规律性，不是定理，也不是预测。
- 缓慢衰减的样本ACF是$|\phi|$接近$1$或存在单位根的线索；这一区分是ARMA建模之后的下一件正事。
:::

::: exercise 哪些$\hat\rho_k$拒绝白噪声？ {level=2}
一条长度为$T = 200$的序列有$\hat\rho_1 = 0.11$，$\hat\rho_2 = -0.04$，$\hat\rho_4 = -0.18$，$\hat\rho_{12} = 0.21$。用逐点95%巴特利特带，哪些滞后与白噪声不一致？
::: hint
带是$\pm 1.96/\sqrt{200}$。
:::
::: solution
$1.96/\sqrt{200} \approx 0.139$。于是$|\hat\rho_1| = 0.11$与$|\hat\rho_2| = 0.04$落在带内；$|\hat\rho_4| = 0.18$与$|\hat\rho_{12}| = 0.21$落在带外。滞后$4$与$12$在5%逐点水平上与白噪声原假设不一致。（需要像Ljung-Box这样的联合检验来控制族错误率。）
:::

::: exercise 样本均值的方差 {level=2}
设$Y_t$是平稳AR(1)，$\phi = 0.5$，$\sigma^2 = 1$，$c = 0$。用渐近公式$T^{-1}\sum_{k=-\infty}^{\infty}\gamma_k$计算$\Var(\bar Y)$，取$T = 64$。把它与独立同分布公式$\gamma_0/T$比较。
::: hint
对平稳AR(1)，$\sum_{k=-\infty}^{\infty}\rho_k = (1+\phi)/(1-\phi)$。
:::
::: solution
$\gamma_0 = 1/(1-0.25) = 4/3$。于是$\sum_k \gamma_k = \gamma_0(1+\phi)/(1-\phi) = (4/3)\cdot 1.5/0.5 = (4/3)\cdot 3 = 4$，所以$\Var(\bar Y) \approx 4/64 = 1/16 = 0.0625$。独立同分布公式给出$(4/3)/64 = 1/48 \approx 0.0208$，按因子$(1+\phi)/(1-\phi) = 3$更小。在这条序列上使用$s/\sqrt{T}$会把均值的不确定性低估$\sqrt{3}$倍。
:::
:::

::: exercise Ljung-Box算术 {level=2 check="4.38"}
设$T = 80$且$\hat\rho_1 = 0.20$，$\hat\rho_2 = 0.10$，$\hat\rho_3 = -0.05$。把Ljung-Box统计量$Q(3)$算到两位小数。$\chi^2_3$的5%临界值是$7.81$。$Q(3)$在5%水平拒绝白噪声吗？（输入到两位小数的$Q(3)$。）
::: solution
$$
Q(3) = 80\cdot 82\left(\frac{0.20^2}{79} + \frac{0.10^2}{78} + \frac{(-0.05)^2}{77}\right) = 6560\left(\frac{0.04}{79} + \frac{0.01}{78} + \frac{0.0025}{77}\right).
$$

括号中的和是$0.00050633 + 0.00012821 + 0.00003247 = 0.00066701$，所以$Q(3) = 6560 \times 0.00066701 = 4.38$（两位小数）。这低于$7.81$，因此检验在5%水平不拒绝白噪声。
:::
:::

::: exercise 一个$\chi^2$临界值 {level=2 check="18.31"}
白噪声下$Q(10)$需要$\chi^2_{10}$的5%临界值。输入到两位小数（常规表列值）。
::: solution
$\chi^2_{10}$的0.95分位数是$18.31$（更精确为$18.307$）。大于此的Ljung-Box $Q(10)$在5%水平拒绝独立同分布噪声。
:::

::: exercise 去均值与$\hat\gamma_k$ {level=3}
证明：如果不减去样本均值——即如果计算$T^{-1}\sum_{t=k+1}^{T} y_t y_{t-k}$——结果估计的是$\gamma_k + \mu^2$，而不是$\gamma_k$。解释为什么这对均值远离零的序列（例如价格**水平**）很要紧。
::: hint
写$y_t = \mu + (y_t-\mu)$并展开乘积。
:::
::: solution
$y_t y_{t-k} = \bigl(\mu + (y_t-\mu)\bigr)\bigl(\mu + (y_{t-k}-\mu)\bigr) = \mu^2 + \mu(y_t-\mu) + \mu(y_{t-k}-\mu) + (y_t-\mu)(y_{t-k}-\mu)$。取平均，若$\bar y \to_p \mu$，交叉项依概率消失，剩下$\mu^2 + \gamma_k$。对均值以百计的价格水平，$\mu^2$淹没$\gamma_k$，未去均值的“ACF”在每一个滞后都接近$1$。那是非零均值的人为产物，不是单位根的证据——尽管单位根也**会**产生缓慢衰减的ACF，原因不同。读相关图之前，永远先去均值（或若模型中有趋势则去势）。
:::

::: exercise MA($\infty$)均值的遍历性 {level=3}
设$Y_t = \sum_{j=0}^{\infty} \psi_j \varepsilon_{t-j}$，其中$\varepsilon_t \sim \mathrm{WN}(0,\sigma^2)$且$\sum_{j=0}^{\infty}|\psi_j| < \infty$。证明$\sum_{k=-\infty}^{\infty}|\gamma_k| < \infty$，并结论$\Var(\bar Y) = O(T^{-1})$。（$\psi$的绝对可和比平方可和更强，是对ARMA过程通常引用的充分条件。）
::: hint
使用[[#eq-wold-gamma]]并交换求和次序。
:::
::: solution
由[[#eq-wold-gamma]]，$|\gamma_k| \le \sigma^2 \sum_{j=0}^{\infty}|\psi_j|\,|\psi_{j+k}|$。对$k \ge 0$求和，

$$
\sum_{k=0}^{\infty}|\gamma_k| \le \sigma^2 \sum_{j=0}^{\infty}|\psi_j|\sum_{k=0}^{\infty}|\psi_{j+k}| \le \sigma^2 \Bigl(\sum_{j=0}^{\infty}|\psi_j|\Bigr)^2 < \infty.
$$

$k<0$的一半相同，因为$\gamma_{-k}=\gamma_k$。于是$\Var(\bar Y) = T^{-1}\sum_{|k|<T}(1-|k|/T)\gamma_k$被$T^{-1}\sum_k|\gamma_k| = O(T^{-1})$界住。MA系数的绝对可和——对AR根在单位圆外的任何因果ARMA过程都成立——因此足以使样本均值具有通常的$1/T$速率。
:::

::: exercise 振荡的ACF {level=2}
一个过程有$\rho_k = (-0.5)^{|k|}$。计算$\rho_1$、$\rho_2$、$\rho_3$，并用文字勾勒相关图的样子。什么样的AR(1)系数产生这一ACF？
::: solution
$\rho_1 = -0.5$，$\rho_2 = 0.25$，$\rho_3 = -0.125$。相关图符号交替，每个滞后幅度减半。由[[#prop-ar1-acf]]，这恰好是$\phi = -0.5$的平稳AR(1)的ACF。
:::
