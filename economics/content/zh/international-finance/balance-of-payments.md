2025年，美国经常账户赤字为GDP的3.6%；中国盈余3.8%，德国4.5%，日本4.9%，印度赤字0.9%（IMF《对外部门报告》2026年，附表1.1.2，采用2026年4月《世界经济展望》）。这些数字不是分数。经常账户赤字意味着该国对世界其余部分获得的债权，少于世界其余部分对它获得的债权——它是净借款人，或动用了已持有的净债权。盈余则相反。这是否构成问题，取决于该国*为何*借入：是为了建工厂、为了消费、为了弥补政府赤字，还是因为外国储蓄者在敲门。本章建立使这句话精确的账户。下文数字仅供教育学习，不构成投资或理财建议。

[[macroeconomics/national-income]]中的封闭经济恒等式是$Y = C + I + G$。一旦该国贸易，就出现第四项：净出口。一旦它交易*资产*，又出现一组分录：金融账户与对外净资产存量。两者是相连的。今日的经常账户（几乎）就是该存量的变化。几乎，是因为即使没有新交易，汇率和资产价格也会对存量重新估值。

## 开放经济国民账户

从生产开始。**国内生产总值**$Y$是国内生产的最终商品和服务的价值。居民还从持有的国外资产获得收入，并对外国人持有的国内资产支付收入。**国民生产总值**（或国民总收入）是GDP加上来自国外的**净初次收入**。在封闭经济中二者重合。在开放经济中，它们相差**净国际投资头寸**（定义见下）的净回报。下文恒等式使用GDP，并把净收入放在经常账户中——IMF就是这样处理的。

开放经济的支出恒等式是

$$
Y = C + I + G + NX,
$$ {#eq-open-y}

其中**净出口**$NX$是商品和服务出口减去进口。改写得$NX = Y - C - I - G$：贸易余额是该国生产与吸收之差。吸收$C+I+G$只有在该国进口差额时才能超过生产。

::: definition 经常账户 {#def-ca}
**经常账户**$CA$是商品和服务净出口，加上**净初次收入**（投资收入与雇员报酬），再加上**净二次收入**（经常转移，如汇款与官方援助）：

$$
CA = NX + NFIA + NUT.
$$

**经常账户盈余**（$CA > 0$）意味着该国在该期内是对世界其余部分的净贷款人。**赤字**意味着它是净借款人。经常账户是*流量*。对应的*存量*是[[#def-niip]]中的净国际投资头寸。
:::

当净收入与转移较小时，$CA \approx NX$，记者就把“贸易余额”说成经常账户。对2025年的美国，二者符号相近但幅度不同：货物赤字大于经常账户赤字，因为服务和初次收入是盈余（美国经济分析局国际交易账户，2025年）。对净对外资产头寸很大的国家——日本、德国、新加坡——净初次收入是$CA$的一阶组成部分，不是舍入误差。

本章最有用的恒等式不是$CA \approx NX$。它是经常账户与储蓄、投资的联系。

::: proposition 经常账户等于储蓄减投资 {#prop-s-i}
令**国民储蓄**为$S = Y + NFIA + NUT - C - G$，即国民收入中未被家庭或政府消费的部分。则由[[#eq-open-y]]与[[#def-ca]]，

$$
CA = S - I.
$$ {#eq-s-i}

等价地，把储蓄拆成私人与公共，$S = S_p + S_g$，其中$S_p = Y + NFIA + NUT - T - C$，$S_g = T - G$，

$$
CA = (S_p - I) - (G - T).
$$ {#eq-twin}

若私人储蓄减投资没有一对一上升以抵消，则政府预算赤字$G-T$与经常账户赤字相伴。这种相伴是恒等式，不是行为命题；它是**双赤字**算术。
:::

::: proof
由[[#eq-open-y]]，$NX = Y - C - I - G$。两边加上$NFIA + NUT$：

$$
CA = NX + NFIA + NUT = (Y + NFIA + NUT - C - G) - I = S - I.
$$

拆分$S = S_p + S_g$只是两条储蓄流的定义。于是$CA = S_p + (T-G) - I = (S_p - I) - (G-T)$。
:::

恒等式并不说预算赤字*导致*经常账户赤字。若政府借债为减税融资而家庭把减税全部储蓄起来——[[macroeconomics/consumption-and-saving]]中的李嘉图情形——则$S_p$随$G-T$上升，$CA$不变。若家庭不储蓄减税，或额外政府支出挤入投资，则$CA$会动。恒等式是预算约束；行为模型在[[international-finance/current-account]]。

::: example 棕榈国的国民账户 {#ex-palmia-na}
虚构的棕榈岛产出$Y = 1000$。消费$C = 650$，投资$I = 200$，政府购买$G = 180$，净出口$NX = -30$。扣除转移后的税收$T = 150$。净初次收入与净转移为零。核验[[#eq-open-y]]，计算私人、公共与国民储蓄，并验证[[#eq-s-i]]与[[#eq-twin]]。
::: solution
支出加总为$650 + 200 + 180 + (-30) = 1000 = Y$，故[[#eq-open-y]]成立。私人储蓄$S_p = Y - T - C = 1000 - 150 - 650 = 200$。公共储蓄$S_g = T - G = 150 - 180 = -30$。国民储蓄$S = 200 - 30 = 170$。于是$S - I = 170 - 200 = -30 = NX = CA$。预算赤字$G - T = 30$，且$S_p - I = 0$，故[[#eq-twin]]为$CA = 0 - 30 = -30$。棕榈国本期经常账户赤字恰好等于其公共赤字：私人储蓄刚好覆盖私人投资，仅此而已。
:::
:::

该控件是[[#prop-s-i]]的小型开放经济图景。在小国，实际利率由国外给定；储蓄与投资不必相等，缺口就是经常账户。在封闭经济中，$r$会调整直到$S=I$。在这一加总层次上，这就是棕榈国与封闭岛屿的全部差别。

::: warning 经常账户不是政府预算
$CA$与$G-T$是不同对象。一国可以在预算盈余的同时出现经常账户赤字——澳大利亚长期如此，用外国储蓄为私人投资融资——也可以在预算赤字的同时出现经常账户盈余，只要私人储蓄足够大（德国在2010年代若干年份，日本在1990年代与2000年代的大部分时间）。[[#eq-twin]]只说*若*$S_p-I$保持不变，则两个赤字一起变动。把$S_p-I$固定是假设，不是恒等式。
:::

## 国际收支账户

**国际收支**是一段时期内居民与非居民之间交易的统计记录。几乎每个国家都按IMF的BPM6编制。每笔交易记两笔，一贷一借，因为每一次交换都有两面。棕榈国居民从国外购买一台机器，记一笔进口（经常账户借方）和一笔支付（金融账户贷方，若支付减少银行债权或增加负债）。在测度完美的世界里，账户会加总为零。它们并不如此，缺口是**净误差与遗漏**。

::: definition 国际收支恒等式 {#def-bop}
以$KA$记BPM6意义上的**资本账户**（资本转移与非生产非金融资产的获得——通常很小），以$FA^{\mathrm{in}}$记**净资本流入**：对非居民负债的净发生减去对非居民债权的净获得，不含储备资产。令$OR$为官方储备资产的增加，$EO$为净误差与遗漏。则

$$
CA + KA + FA^{\mathrm{in}} - OR + EO = 0.
$$ {#eq-bop}

教科书简写中，忽略$KA$、$OR$和$EO$，

$$
CA + FA^{\mathrm{in}} = 0:
$$

经常账户盈余由净资本*流出*匹配。IMF在BPM6中自己的金融账户加总符号相反：BPM6金融账户为正意味着债权的净*获得*（资本流出）。除非表格标明BPM6，本课程使用教科书符号$FA^{\mathrm{in}}$。
:::

$FA^{\mathrm{in}}$的拆分在经济上比总额更有意思。**直接投资**是对企业的持久利益（BPM6门槛是表决权的10%）。**证券投资**是低于该门槛的债务与股权证券。**其他投资**是银行贷款、存款与贸易信贷。**金融衍生品**单独记录。**储备资产**——外汇储备、特别提款权持有、在IMF的储备头寸、黄金——是中央银行的债权，也是出清钉住的残差，[[international-finance/exchange-rate-regimes]]将会用到。

::: example 四笔交易的复式记账 {#ex-double}
棕榈国的货币是棕榈。在[[#def-bop]]下，经常账户贷记为$+CA$，资本*流入*为$+FA^{\mathrm{in}}$，因此当储备与误差不变时二者必须加总为零。记录每笔交易。(a) 棕榈国进口一台价值$10$的机器，并通过提取在外国银行的存款支付。(b) 一名外国居民购买$5$的棕榈国政府债券，并通过提取她已持有的棕榈国银行存款支付。(c) 棕榈国出口价值$8$的水果，并以在*外国*银行的存款收款。(d) 棕榈国政府收到$2$的官方援助（外汇），中央银行将其计入储备。四笔合计的$CA$、$FA^{\mathrm{in}}$和$OR$是多少？
::: solution
棕榈国对外*资产*增加是资本*流出*（$FA^{\mathrm{in}} < 0$）。棕榈国对非居民*负债*增加是资本*流入*（$FA^{\mathrm{in}} > 0$）。官方储备资产增加为$+OR$。

(a) 进口：$CA = -10$。提取外国银行存款减少棕榈国资产，这是流入：$FA^{\mathrm{in}} = +10$。

(b) 债券出售增加棕榈国负债，$FA^{\mathrm{in}} = +5$。支付提取非居民持有的棕榈国银行存款，这*减少*棕榈国负债，$FA^{\mathrm{in}} = -5$。净$FA^{\mathrm{in}} = 0$。棕榈国把一种负债（存款）换成另一种（债券）。经常账户未受影响。

(c) 出口：$CA = +8$。收款是棕榈国对外国银行的新债权，故棕榈国资产上升：$FA^{\mathrm{in}} = -8$。

(d) 援助是二次收入：$CA = +2$。外汇作为储备持有：$OR = +2$。无私人金融账户分录。

合计：$CA = -10 + 8 + 2 = 0$，$FA^{\mathrm{in}} = +10 - 8 = +2$，$OR = +2$。于是$CA + FA^{\mathrm{in}} - OR = 0 + 2 - 2 = 0$，这就是$KA = EO = 0$时的[[#eq-bop]]。四笔交易轧平。若(c)改打入棕榈国银行，则棕榈国负债会上升（$FA^{\mathrm{in}} = +8$），恒等式会要求合并账上别处再有一笔匹配的流出——这就是题干指定*外国*银行的原因。
:::
:::

[[#ex-double]]的长解答，正是BPM6公布符号惯例以及配套的《国际储备与外币流动性》模板的原因，也是每篇经验论文都要说明正的金融账户是否为流入的原因。读表时，读脚注。

::: intuition 同一笔贷款的两面
经常账户赤字不是堆在柜子里的未付账单。它是一笔贷款，或一次股权出售，或一次储备动用，记在账户的另一面。世界其余部分的某人正在获得一项棕榈国资产。问“赤字将如何融资？”仿佛融资是额外决策，就是把同一个问题问了两遍。融资*就是*赤字，从另一张桌子看。
:::

::: quiz
棕榈国$CA = -30$，没有资本账户或误差与遗漏分录。官方储备不变。在[[#def-bop]]下$FA^{\mathrm{in}}$是多少？
- [ ] $-30$，资本流出
- [x] $+30$，净资本流入
- [ ] $0$，因为储备没有动
- [ ] 只有政府是借款人时才是$+30$
::: solution
$KA=OR=EO=0$时[[#eq-bop]]为$CA + FA^{\mathrm{in}} = 0$，故$FA^{\mathrm{in}} = +30$。私人部门、政府或二者，向非居民出售了债权（或减少了国外资产）。恒等式不点名借款人；点名公共部门的拆分是[[#eq-twin]]。
:::
:::

## 净国际投资头寸

流量累积为存量。**净国际投资头寸**（NIIP），也称**对外净资产**$B$，是居民对非居民的债权与非居民对居民的债权在某一日期估值之差。负的NIIP是净债务国头寸。2025年底美国NIIP约为GDP的$-88\%$；德国约$+85\%$，日本$+85\%$，中国$+21\%$，巴西$-49\%$（IMF《对外部门报告》2026年，附表1.1.2）。美国的数字很大，而且几十年来一直很大，这是我们还会遇到的一个谜：美国一代人时间里一直有经常账户赤字，NIIP却没有以同样速度爆炸，原因是估值。

::: definition 净国际投资头寸 {#def-niip}
令$B_t$为第$t$期末的NIIP，$CA_t$为第$t$期经常账户，$\mathit{VAL}_t$为既有存量上的**估值变动**（汇率变动、资产价格变动，以及其他非交易引起的物量变动）。则

$$
B_t = B_{t-1} + CA_t + \mathit{VAL}_t.
$$ {#eq-niip}

估值不是图方便的残差。对美国而言，它常常与经常账户同阶，且符号相反：美国居民对外债权中股权份额更大，相对主导美国负债的国债往往升值（古兰沙（Gourinchas）与雷伊（Rey），“From World Banker to World Venture Capitalist”，NBER，2007年；随后的《对外部门报告》有更新）。这一模式有时被称为**过度特权**。它是关于过去回报的经验规律，不是保证。
:::

::: proposition 稳定的NIIP对产出比率要求一个经常账户比率 {#prop-stable-b}
忽略估值。令产出增长率为$g$，故$Y_t = (1+g)Y_{t-1}$，并令$b_t = B_t/Y_t$。则

$$
b_t = \frac{1}{1+g} b_{t-1} + \frac{CA_t}{Y_t}.
$$

因此稳定比率$b$要求

$$
\frac{CA}{Y} = \frac{g}{1+g}\, b.
$$ {#eq-stable-ca}

若$b < 0$（净债务国）且$g > 0$，该规模的*赤字*与稳定比率相容。更大的赤字把$b$送向$-\infty$。公式是会计约束，不是最优性检验。
:::

::: proof
由[[#eq-niip]]并令$\mathit{VAL}=0$，$B_t = B_{t-1} + CA_t$。除以$Y_t$：

$$
b_t = \frac{B_{t-1}}{Y_t} + \frac{CA_t}{Y_t} = \frac{B_{t-1}}{(1+g)Y_{t-1}} + \frac{CA_t}{Y_t} = \frac{b_{t-1}}{1+g} + \frac{CA_t}{Y_t}.
$$

令$b_t = b_{t-1} = b$并整理。
:::

对美国，$b \approx -0.88$且$g \approx 0.04$（一个凑整的长期名义美元增长率，不是预测）会给出$CA/Y \approx (0.04/1.04)\times(-0.88) \approx -3.4\%$。2025年GDP的3.6%赤字就在这一邻域，*若*忽略估值且*若*4%是正确的$g$。两个“若”都不是免费的，且[[#eq-stable-ca]]并不说$-3.6\%$是可取的。它说的是：GDP的$-88\%$这一比率可以在该赤字下持续而不趋势化。跨期意义上的可持续性——未来贸易盈余的现值是否覆盖$-B$——是[[international-finance/current-account]]。

::: example 估值与NIIP {#ex-val}
棕榈国年初$B_0 = -400$。年内$CA = -46$。棕榈国对外股权债权年初值$200$，以棕榈计升值$10\%$；棕榈国负债值$600$，以棕榈计不变。计算$B_1$以及变化中由经常账户引起的份额。
::: solution
资产上的估值是$0.10 \times 200 = 20$。负债上的估值是$0$。故$\mathit{VAL} = 20$，且

$$
B_1 = -400 + (-46) + 20 = -426.
$$

NIIP恶化了$26$，其中$46$是经常账户赤字，$-20$是估值收益。只报告$CA$会夸大恶化。只报告$B_1 - B_0$会低估棕榈国借入的数量。两个数字都需要。
:::
:::

::: example 净初次收入 {#ex-nfia}
棕榈国$B_0 = -400$。存量年内支付的平均回报率为$4\%$。净出口$NX = -30$，净转移为零。计算净初次收入和经常账户。（把回报视为作用于期初存量，忽略年内累积。）
::: solution
$NFIA = 0.04 \times (-400) = -16$。于是$CA = -30 + (-16) + 0 = -46$，即[[#ex-val]]所用数字。净债务国向国外支付收入，故经常账户赤字*大于*贸易赤字。日本$b > 0$，常因同一原因、相反符号，经常账户盈余大于贸易盈余（日本内阁府国民账户；IMF IFS，各年）。
:::
:::

## 如何阅读盈余或赤字

三种混淆反复出现。第一种是重商主义：盈余就是“赢”。[[#prop-s-i]]说盈余是储蓄超过投资。那可以是美德（节俭、国外良好的投资气候），也可以是症状（国内投资疲弱、经济萧条、实际汇率低估）。中国的盈余在2007年接近GDP的10%，2025年为3.8%；德国相对欧元区伙伴的盈余自2000年代中期以来一直很大（IMF WEO数据库，2026年访问）。这些盈余是否“太大”，是关于实际汇率与需求的问题，在[[international-finance/ppp]]和[[international-finance/mundell-fleming]]中讨论，不是恒等式能裁定的问题。

第二种混淆是道德性的：赤字就是“入不敷出”。若“手段”包括以未来产出为抵押借入的能力，且借入为$I$而非$C$融资，则这句话会误导。[[#ex-palmia-na]]中的棕榈国有$S_p = I$和公共赤字；另一个$S_g = 0$且$I$很大的棕榈国，会像许多年份的澳大利亚或加拿大——经常账户赤字与家庭和企业的资本积累并存。第三种混淆是把经常账户当成政策工具。政府设定税收、支出、政策利率，有时还有钉住。经常账户是*结果*。在浮动下，它是世界利率与本国收入下$S-I$变成的任何值；在钉住下，它是与储备增减相容的任何值。政策只有通过瞄准储蓄、投资或实际汇率，才能瞄准它。

::: application 全球失衡，2000年代及之后
2000年代中期，美国经常账户赤字为GDP的5%–6%，由中国、日本、德国和石油出口国的盈余匹配（IMF WEO，历史序列）。伯南克（Bernanke）（2005年，“全球储蓄过剩”演讲）强调外国储蓄的外生上升；另一些人强调美国财政政策和宽松的美国信贷。恒等式[[#eq-s-i]]在两个故事中都成立。2008年危机和2010年代缩小了其中一些缺口，又打开了另一些：德国盈余仍然很大；中国占GDP的比重下降；石油余额随油价变动。IMF自2012年起的年度《对外部门报告》把经常账户分类为相对工作人员规范“偏强”或“偏弱”。那些规范是模型，不是事实，而且有争议。本课程把该《报告》用作*数据*来源（上文2025年比率），并把工作人员“缺口”当作诸多评估中的一种。
:::

## 证据

若干规律有充分记载，但不是定理。

**典型化事实1（费尔德斯坦-堀冈）。**跨国来看，国民储蓄与国内投资高度相关，仿佛资本并不流动。费尔德斯坦（Feldstein）与堀冈（Horioka）（1980年，《经济学杂志》）报告1960—1974年OECD国家的截面系数接近$0.9$。后来样本找到更小但仍为正的系数（奥伯斯法尔德（Obstfeld）与罗戈夫（Rogoff），“The Six Major Puzzles”，NBER宏观经济学年刊，2000年）。在[[#prop-s-i]]中，该相关就是较小的$CA$。对完美资本流动的世界，这是一个谜；对存在本土偏好、非贸易品和经常账户目标的世界，这是常识。

**典型化事实2（投资组合的本土偏好）。**居民持有的本国股权份额远大于世界CAPM所预测的（弗伦奇（French）与波特巴（Poterba），1991年，《美国经济评论》论文与会议录）。NIIP是两个巨大总存量的*净额*。总存量比净额增长更快：金融全球化主要是双向总持有，而不是单向净放贷（莱恩（Lane）与米莱西-费雷蒂（Milesi-Ferretti），“The External Wealth of Nations Mark II”，《国际经济学杂志》，2007年，以及IMF的更新）。

**典型化事实3（估值重要）。**对美国而言，累积经常账户与NIIP变动之间的缺口是持久的，并且在1980—2020年与累积赤字本身同阶（BEA IIP表；古兰沙与雷伊，各文）。对新兴市场，估值往往走另一方向：当货币贬值时，外币负债对借款人重新估值。那是[[international-finance/crises]]中的危机机制。

国家覆盖不应停在北大西洋。尼日利亚和沙特阿拉伯的经常账户跟随油价；孟加拉国若有盈余，往往是$NUT$中的汇款；智利的余额随铜而动；肯尼亚通常出现由FDI与官方流动混合融资的经常账户赤字（IMF IFS与WEO，2026年访问）。恒等式相同。$CA$与$FA^{\mathrm{in}}$的构成不同。

## 由此通向何处

汇率是这样的价格：在浮动制度下，它们帮助$NX$和$CA$调整；在钉住制度下，中央银行用$OR$捍卫它们。那是[[international-finance/exchange-rates]]。实际汇率的长期行为是[[international-finance/ppp]]。棕榈国*是否应当*借入、以及$-426$是否为可持续的$B$，是[[international-finance/current-account]]。短期产出、利率与汇率合在一起是[[international-finance/mundell-fleming]]。当$FA^{\mathrm{in}}$在几周内逆转时，账户仍然加总，经济却可能不行：[[international-finance/crises]]。

::: history
大卫·休谟（David Hume）1752年的文章《论贸易平衡》，收入《政治论丛》，是本章恒等式以及金本位调整机制的祖先。休谟认为贸易盈余把金银引入该国、推高价格，从而扼杀盈余；赤字则相反。机制是**物价-现金流动**。它假定金属本位、弹性价格，以及不对金银流动进行冲销。休谟在反驳把金银盈余当作目的的重商主义者。恒等式$CA = S - I$更晚——它是国民核算，二十世纪——但休谟关于盈余是*改变存量从而改变价格的流量*的论点，已经是[[#eq-niip]]的NIIP逻辑，只是还没有金融资产。米德（Meade）的《国际收支》（1951年）是第一部系统的现代处理；IMF第一部《国际收支手册》出现于1948年，BPM6于2009年。
:::

::: summary
- 在开放经济中$Y = C+I+G+NX$。经常账户是$CA = NX + NFIA + NUT$，即对世界其余部分净放贷的流量。
- $CA = S - I = (S_p - I) - (G - T)$。双赤字关系是给定$S_p-I$下的恒等式，不是因果定律。
- 国际收支把每一笔居民/非居民交易记两遍。教科书简写是$CA + FA^{\mathrm{in}} = 0$；BPM6对金融账户的符号相反。官方储备是中央银行的残差。
- NIIP服从$B_t = B_{t-1} + CA_t + \mathit{VAL}_t$。估值对美国以及负有外币债务的国家是一阶的。
- 稳定的$B/Y$要求$CA/Y = \frac{g}{1+g} b$。对$b = -0.88$和$g = 0.04$，那大约是GDP的$-3.4\%$，是会计基准，不是目标。
- 盈余不是胜利，赤字不是恶行。二者都是储蓄、投资与相对价格的结果。
:::

## 习题

::: exercise 棕榈国的吸收 {level=1 check="-30"}
在[[#ex-palmia-na]]中，$Y = 1000$，吸收为$C+I+G$。输入经常账户$CA$（它等于$NX$）。
::: solution
吸收为$650+200+180 = 1030$。于是$NX = Y - \text{吸收} = 1000-1030 = -30 = CA$。
:::
:::

::: exercise 私人储蓄 {level=1 check="200"}
使用同一组棕榈国数字，$T = 150$，$C = 650$。输入私人储蓄$S_p$。
::: solution
$S_p = Y - T - C = 1000 - 150 - 650 = 200$。减去$30$的公共赤字后国民储蓄为$170$；题目问的是私人储蓄。
:::
:::

::: exercise 双赤字算术 {level=1 check="-50"}
保持棕榈国$S_p = 200$和$I = 200$，但把公共赤字$G-T$从$30$提高到$50$。输入新的$CA$。
::: solution
[[#eq-twin]]在$S_p-I = 0$时给出$CA = -(G-T) = -50$。恒等式成立是因为我们把$S_p$和$I$固定了。若家庭储蓄了额外赤字，$CA$就不会动。
:::
:::

::: exercise 稳定比率经常账户 {level=2 check="-3.2"}
一国有$b = B/Y = -0.80$，产出增长$g = 0.04$。忽略估值，输入使$b$稳定的经常账户比率$CA/Y$，以*百分数*计（因此$-3.2\%$输入$-3.2$）。
::: solution
[[#eq-stable-ca]]给出$CA/Y = \frac{0.04}{1.04}\times(-0.80) = -0.032$，即GDP的$-3.2\%$。更负的比率会把$b$送下去；不那么负的比率会把$b$抬向零。
:::
:::

::: exercise 更新NIIP {level=2 check="-426"}
重复[[#ex-val]]：$B_0 = -400$，$CA = -46$，估值$+20$。输入$B_1$。
::: solution
由[[#eq-niip]]，$B_1 = -400 - 46 + 20 = -426$。
:::
:::

::: exercise 收入账户 {level=2 check="-46"}
期初NIIP为$-400$，期初存量回报率$4\%$，$NX = -30$，净转移$0$。输入$CA$。
::: solution
$NFIA = -16$，$CA = -30-16 = -46$，如[[#ex-nfia]]。
:::
:::

::: exercise 谁在借款？ {level=3}
一国$CA$为GDP的$-4\%$，$G-T$为GDP的$2\%$，$I$为GDP的$22\%$。(a) $S_p$占GDP的百分数是多少？(b) 国民储蓄是多少？(c) 解释哪个部门是对世界其余部分的净借款人。使用[[#eq-twin]]。
::: hint
由$CA = (S_p - I) - (G-T)$解出$S_p$。国民储蓄为$S_p + S_g = S_p - (G-T)$。
:::
::: solution
(a) $-4 = (S_p - 22) - 2$，故$S_p - 22 = -2$，从而$S_p$为GDP的$20\%$。(b) $S_g = -2$，故$S$为GDP的$18\%$，且$S-I = 18-22 = -4 = CA$。(c) 公共部门赤字为GDP的$2\%$。私人投资超过私人储蓄GDP的$2\%$。每个部门都是GDP的$2\%$的净借款人；合在一起从国外借入GDP的$4\%$。世界其余部分是对手方。拆分是会计；它并不说哪个部门“造成”了经常账户赤字。
:::
:::

::: exercise 估值与交易 {level=3}
A国$B_0 = 0$，连续五年每年$CA = -10$，没有估值变动。B国$B_0 = 0$，每年$CA = 0$，但仅在第3年遭受$10$的估值损失。(a) 计算第5年末各自的NIIP。(b) 就经常账户意义而言，哪一国从世界其余部分借入了？(c) 为何B国的危机仍可能被描述为“外部”危机？
::: hint
逐年应用[[#eq-niip]]。然后问$CA$测度了$B$所没有测度的什么。
:::
::: solution
(a) A国：$B_5 = 0 + 5\times(-10) = -50$。B国：$B_5 = 0 + 0 + (-10) = -10$。(b) 只有A在经常账户意义上借入：A进口的商品、服务和收入借方超过出口，并发行债权来支付。B没有。(c) B的净负债仍然上升了，因为既有债权被重新估值——例如B的货币相对外币债务贬值，或B的国外资产的本币价格下跌。B的居民可能在重新估值后的存量上面临展期问题，即使他们没有流量赤字。这就是[[#def-niip]]把$CA$与$\mathit{VAL}$分开的原因，也是危机各章同时看流量与存量货币构成的原因。
:::
