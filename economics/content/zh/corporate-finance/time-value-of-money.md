A企业今天可以收取100单位货币，或一年后收取110单位，但不能两者兼得。这两项要约并不是同一个数字的两种写法。若100单位今天到达，可以贷出直到明年；若110单位明年才到达，今天就不能花。比较它们，就是**货币的时间价值**的全部内容：一单位现金带有日期，不同日期的现金通过向前复利或向后贴现来换算。一旦换算就位，工厂、债券和股票就都变成有日期的现金流清单，而这些清单可以相加。

换算因子是**利率**，或更一般地，**贴现率**。在本章中，该利率是一个给定的数，即把现金占用一个既定期限的机会成本。这个数从何而来——报价贷款利率、债券收益率、由风险构造的资本成本——是后续各章的主题。这里我们把利率当作数据，说明它是年利率、有效利率还是连续复利，然后计算。每一个数值例都使用示意性现金流和虚构企业。计算是关于这些编造数字的算术。它们不是预测，也不是放贷、借款或接受项目的建议。图谱仅供教育学习，不构成投资或理财建议。

所用数学是几何级数和指数函数，已在[[mathematical-economics/integration]]中用于剩余和现值。经济学内容则是给现金标注日期，以及不把生活在不同时点的单位相加的纪律。贴现率所要捕捉的，是[[principles/thinking-like-an-economist]]中的机会成本：同一期限、同一风险类别上现金的最佳替代用途。直到[[corporate-finance/risk-and-return]]之前，我们把“同一风险类别”当作允许使用单一利率的短语，而不是一个被推导出来的对象。

## 复利与贴现

以每期不变利率$r$投资的一单位现金，每期增长因子$1+r$。经过$t$期后，该单位变成$(1+r)^t$。这就是**复利**：利息本身也赚利息。**单利**只把$r$作用于原始本金，是另一种惯例，本课程的估值恒等式并不使用它。

::: definition 终值与现值 {#def-pv}
设$r > -1$为跨日期不变的每期贴现率。在日期$0$收到的现金流$C_0$在日期$t$的**终值**为

$$
\mathrm{FV}_t(C_0) = C_0\,(1+r)^t.
$$ {#eq-fv}

在日期$t$收到的现金流$C_t$在日期$0$的**现值**为

$$
\mathrm{PV}(C_t) = \frac{C_t}{(1+r)^t} = C_t\,(1+r)^{-t}.
$$ {#eq-pv}

一条**现金流序列**$(C_0, C_1, \dots, C_T)$的现值为$\sum_{t=0}^{T} C_t (1+r)^{-t}$。假定利率$r$适用于每一期以及这一风险类别的现金流。日期$0$是“现在”；除非题目另有说明，现金流在每期期末收到。
:::

这两个运算互为逆运算：把现值复利$t$期就恢复未来现金流，把终值贴现就恢复现值。因子$(1+r)^{-t}$是日期$t$的**贴现因子**。当$r > 0$时，贴现因子随$t$下降：更远的现金今天更不值钱，因为等待放弃了更多复利。当$r = 0$时，每一日期的贴现因子都是$1$，标注日期不再重要。负利率在某些货币市场出现；只要$r \neq -1$，代数仍然成立。

::: proposition 现值的线性性 {#prop-linearity}
在固定利率$r$下，现值对现金流是线性的。对任意序列$C$和$D$以及任意标量$\alpha, \beta$，

$$
\mathrm{PV}(\alpha C + \beta D) = \alpha\,\mathrm{PV}(C) + \beta\,\mathrm{PV}(D).
$$

特别地，一条序列的现值等于其各期片段现值之和，而按常数缩放的现金流，其现值按同一常数缩放。
:::

::: proof
每一项$C_t (1+r)^{-t}$对$C_t$是线性的，有限个线性映射之和仍是线性的。对无穷序列，只要现值级数绝对收敛，从而重排合法，同一恒等式也成立。
:::

线性性说明企业为何可以通过列出增量现金流并逐期贴现来给项目估值。它也说明两个互不作用的项目可以通过把净现值相加来排序。相互作用——共享约束、被蚕食的销售、取决于二者的税收——打破的是“互不作用”这一条款，而不是[[#prop-linearity]]的代数。

::: example A企业的两项要约 {#ex-two-offers}
A企业被提供今天100单位或一年后110单位。这类现金流的资本机会成本是每年有效利率$r = 0.08$。哪一项要约的现值更高？若按$8\%$复利，100单位一年后的终值是多少？
::: solution
一年后110单位的现值是$110 / 1.08 = 101.85185\ldots$，四舍五入为$101.85$单位。这大于$100$，因此**在这一利率下**延迟的要约更值钱。等价地，100单位复利一年变成$108$，小于$110$。按现值单位排序与按终值单位排序相同，因为乘以$1.08$不改变不等式。

若利率是$12\%$，延迟要约的现值将是$110 / 1.12 = 98.214\ldots$，低于$100$，排序就会反过来。算术并不说A企业在现实中“应当”接受哪一项；它只说一旦现金按既定利率标注日期，哪一项更大。改变利率就改变排序。$8\%$和$12\%$都是示意性的。
:::
:::

::: example 五年复利 {#ex-five-years}
一笔$100$单位的现金流按每年有效$8\%$复利五年。终值是多少？同一利率下，五年后收到的$100$单位的现值是多少？
::: solution
终值为

$$
100 \times (1.08)^5 = 146.93280768,
$$

四舍五入为$146.93$单位。五年后$100$单位的现值是逆运算：

$$
\frac{100}{(1.08)^5} = 68.05831970,
$$

四舍五入为$68.06$单位。有用的核对：$68.05831970 \times (1.08)^5 = 100$。两个数字$146.93$和$68.06$描述不同的现金流日期；把它们相加会混淆日期，并不是现值。
:::
:::

复利值序列$100, 100(1+r), 100(1+r)^2, \ldots$是几何序列。提高$r$会使它变陡；在$r = 0$时它是平的。

::: widget sequence

:::

翻倍时间的常用近似是**72法则**：余额按年利率$r$（以百分数计）翻倍所需年数约为$72 / (100r)$。在$8\%$下该法则给出$9$年；精确翻倍时间是$\ln 2 / \ln(1.08) \approx 9.006$年。这是助记，不是定理，并且当$r$离开$8\%$附近时会变差。

::: intuition 标注日期是单位换算
现值是单位换算，从“日期$t$的货币单位”换成“日期$0$的货币单位”。汇率就是贴现因子$(1+r)^{-t}$。拒绝换算、把日期$3$的现金流加到日期$0$的现金流上，与把米加到秒上是同一类错误。换算后的数字可以相加，由[[#prop-linearity]]，因为它们已被带到同一日期。
:::

## 年金与永续年金

许多合约会重复。水平贷款还款、固定利率债券的票息、不变租金，以及教科书例子中的不变股利，都是**年金**：在$n$期的每一期期末收到现金流$C$。**永续年金**是$n = \infty$的同一对象。**增长**年金或永续年金每期按不变增长因子缩放现金流。闭式公式省去把一长串贴现项相加，它们来自几何级数。

::: definition 普通年金、预付年金、永续年金 {#def-annuity}
$n$次支付的**普通年金**是序列$(0, C, C, \dots, C)$，$C$出现在随后$n$期的每一期期末。**预付年金**在$n$期的每一期**期初**支付同一$C$，因此第一次支付是立即的。**水平永续年金**是无穷普通序列$(0, C, C, C, \dots)$。第一次支付为从现在起一期后的$C$、增长率为$g$的**增长永续年金**是序列$(0, C, C(1+g), C(1+g)^2, \dots)$。
:::

::: proposition 水平年金与永续年金的现值 {#prop-annuity-pv}
设$r \neq 0$。$n$次支付、每次为$C$的普通年金的现值为

$$
\mathrm{PV}_{\text{年金}} = C \cdot \frac{1 - (1+r)^{-n}}{r}.
$$ {#eq-annuity}

水平永续年金的现值为$C/r$，前提是$r > 0$。第一次支付为$C$、增长为$g$的增长永续年金的现值为$C/(r-g)$，前提是$r > g$。$n$次支付的预付年金价值为相应普通年金的$(1+r)$倍。
:::

::: proof
普通年金是$C$乘以$\sum_{t=1}^{n} (1+r)^{-t}$。这是首项为$(1+r)^{-1}$、公比为$(1+r)^{-1}$的几何级数。$n$项之和为

$$
(1+r)^{-1}\,\frac{1 - (1+r)^{-n}}{1 - (1+r)^{-1}} = \frac{1 - (1+r)^{-n}}{r},
$$

这就是[[#eq-annuity]]。令$n \to \infty$且$r > 0$：项$(1+r)^{-n}$消失，永续年金价值为$C/r$。对增长永续年金，从$\sum_{t=0}^{\infty} \bigl((1+g)/(1+r)\bigr)^{t}$中提出$C/(1+r)$。公比小于$1$当且仅当$r > g$，和为$C/(r-g)$。预付年金是普通年金向前移动一期，从而把它的现值乘以$1+r$；等价地，它是今天的$C$加上$n-1$次支付的普通年金。
:::

较少使用、但按同一方式导出的增长年金公式是

$$
\mathrm{PV} = \frac{C}{r-g}\Bigl(1 - \bigl(\tfrac{1+g}{1+r}\bigr)^{n}\Bigr), \qquad r \neq g.
$$ {#eq-growing-annuity}

当$r = g$时，$n$笔贴现支付每笔都等于$C/(1+r)$，因此现值为$nC/(1+r)$。当$r \le g$时，增长永续年金没有有限现值：现金流的增长至少与被贴现一样快，级数发散。这是关于公式的陈述，不是预测任何企业的股利会永远以高于贴现率的速度增长。

::: example 十年年金 {#ex-annuity}
A企业将在随后十年的每年年末收到$50$单位。贴现率是每年有效$6\%$。普通年金的现值是多少？若十次支付改在每年年初到达，现值会是多少？
::: solution
[[#eq-annuity]]给出

$$
50 \cdot \frac{1 - (1.06)^{-10}}{0.06} = 368.00435257,
$$

四舍五入为$368.00$单位。预付年金是其$1.06$倍：$390.08461372$，四舍五入为$390.08$单位。多出的$22.08$单位是每笔支付早一年收到的价值。把十个未贴现的$50$相加会得到$500$，这只在$r = 0$时才是现值。在$6\%$下，标注日期值这$500$中的$132$单位。
:::
:::

::: example 水平与增长永续年金 {#ex-perpetuity}
一份合约每年永远支付$20$单位，第一次支付在一年后。在$r = 5\%$下现值为$20 / 0.05 = 400$单位。第二份合约一年后支付$20$单位，然后每年按$g = 3\%$永远增长。在$r = 8\%$下，其现值是多少？为什么答案仍是同一个$400$？
::: solution
增长永续年金公式适用，因为$8\% > 3\%$：

$$
\frac{20}{0.08 - 0.03} = 400.
$$

两份合约并不是同一条序列。第一条是按$5\%$贴现的水平$20$；第二条是按$8\%$贴现的增长序列。它们恰好在这些特定利率下共享一个现值。把第二份合约中的$g$换成$4\%$，会把现值提高到$20 / 0.04 = 500$。把$g$换成$8\%$会使公式不适用：$r = g$是无穷和发散的边界。
:::
:::

::: warning 第一次支付的日期
永续年金公式$C/r$，以及增长永续年金的$C/(r-g)$，都假定第一次支付在**一期**后到达，而不是今天。一份立即支付$C$、然后每期期末再支付$C$的永续年金，价值为$C + C/r$。对立即永续年金使用$C/r$，会把现值低估一次支付。年金上的同一失误是把普通年金与预付年金混淆。[[corporate-finance/valuing-bonds]]中处理的债券票息是普通的：下一期票息并不是买到债券的那一瞬间就到期，除非购买落在票息日且惯例另有规定。
:::

**贷款摊还**是反向运行的年金公式。若金额为$L$的贷款按利率$r$以$n$次相等的期末支付偿还，则支付额是使[[#eq-annuity]]等于$L$的那个$C$：

$$
C = L \cdot \frac{r}{1 - (1+r)^{-n}}.
$$ {#eq-pmt}

每笔支付一部分是剩余本金上的利息，一部分是本金偿还。利息部分在贷款寿命内下降；本金部分上升。一旦给定$r$和剩余本金，这一分割是会计恒等式。它不是接受或再融资任何贷款的建议。

::: example 五年期水平贷款 {#ex-loan}
一位虚构借款人借入$20{,}000$单位的贷款，按每年有效$7\%$以五次相等的年支付偿还。年支付是多少？第一笔支付中有多少是利息？
::: solution
[[#eq-pmt]]给出

$$
C = 20{,}000 \cdot \frac{0.07}{1 - (1.07)^{-5}} = 4{,}877.81388883,
$$

四舍五入为$4{,}877.81$单位。第一年利息是$0.07 \times 20{,}000 = 1{,}400$单位，因此第一年偿还的本金是$4{,}877.81 - 1{,}400 = 3{,}477.81$单位。第二年年初剩余本金是$16{,}522.19$单位。五次支付合计仍为$24{,}389.07$单位；高出$20{,}000$的那$4{,}389.07$是贷款寿命内支付的利息，以未贴现单位计。这笔额外并不是现值成本：五次支付在$7\%$下的现值，由构造恰好是$20{,}000$。
:::
:::

::: quiz
一份增长永续年金一年后第一次支付$12$单位，增长率为$2\%$。贴现率是$8\%$。其现值是多少？
- [ ] $12 / 0.08 = 150$
- [x] $12 / (0.08 - 0.02) = 200$
- [ ] $12 / 0.02 = 600$
- [ ] 现值无穷大，因为支付永远增长
::: solution
[[#prop-annuity-pv]]给出$C/(r-g) = 12 / 0.06 = 200$，且$r > g$，因而级数收敛。把增长序列按$r$贴现却当作不增长，$12/0.08$，忽略了后来更大的支付。除以$g$没有现值含义。**未贴现**支付的无穷增长，在这些支付被贴现得比增长更快时，并不会使贴现和发散。
:::
:::

## 有效利率与连续复利

报价利率在其复利惯例被命名之前，并不是定义清楚的贴现率。按季复利的$8\%$**名义**年利率意味着每季$2\%$，一年四次。$1$在一年内变成的金额是$(1.02)^4 = 1.08243216$，因此**有效年利率**约为$8.24\%$，而不是$8\%$。把按季复利的报价与按年复利的报价不加换算就比较，是与把不同日期的现金相加同类的单位错误。

::: definition 有效年利率 {#def-ear}
若名义年利率$r_{\text{名义}}$一年复利$m$次，则**有效年利率**（EAR）为

$$
\mathrm{EAR} = \Bigl(1 + \frac{r_{\text{名义}}}{m}\Bigr)^{m} - 1.
$$ {#eq-ear}

两个报价利率只有在被换算到同一复利频率、或换算成EAR之后才可比较。消费信贷监管中的**年百分率**（APR）是名义利率；它一般并不是EAR。惯例因市场和司法辖区而异；题目必须说明它所使用的惯例。
:::

当$m \to \infty$时，[[#eq-ear]]的右边趋于$e^{r_{\text{名义}}} - 1$。这就是**连续复利**。若余额按连续复利利率$r$增长，则$t$年后其价值是起始价值的$e^{rt}$倍，日期$t$的现金流$C_t$的现值是$C_t e^{-rt}$。

::: proposition 不变现金流的连续现值 {#prop-continuous-pv}
区间$[0, T]$上每年速率为$C$的连续现金，按不变连续复利利率$r \neq 0$贴现，其现值为

$$
\int_0^{T} C e^{-rt}\,\mathrm{d}t = C\,\frac{1 - e^{-rT}}{r}.
$$ {#eq-cont-pv}

当$T \to \infty$且$r > 0$时，这趋于$C/r$，即永续年金公式的连续对应物。离散普通年金[[#eq-annuity]]是同一积分的黎曼和表亲。
:::

::: proof
$e^{-rt}$的原函数是$-e^{-rt}/r$。从$0$到$T$取值得到$(1 - e^{-rT})/r$，再乘以$C$即得[[#eq-cont-pv]]。无穷期限极限是$C/r$，因为当$r > 0$时$e^{-rT} \to 0$。把$C e^{-rt}$在$[0, T]$的$n$个相等分割上作右黎曼和，得到每期利率为$e^{rT/n} - 1$的离散年金；当$n \to \infty$时该和收敛到积分。
:::

::: widget riemann
f: 10*exp(-0.06*x)
a: 0
b: 5
n: 8
method: mid
caption: 每年10单位、为期五年、按连续复利6%贴现的连续现值的中点矩形。增大n：和趋于10(1 − e^{−0.30})/0.06 ≈ 43.20。该现金流是编造的。
:::

::: example 报价、有效与连续 {#ex-ear}
一则储蓄报价是“$8\%$，按季复利”。EAR是多少？产生同一EAR的连续复利利率是多少？另外，每年$10$单位、为期五年的连续现金流按连续复利$6\%$贴现。其现值是多少？
::: solution
EAR是$(1 + 0.08/4)^4 - 1 = (1.02)^4 - 1 = 0.08243216$，约$8.243\%$。与这一EAR匹配的连续复利利率$r$满足$e^{r} - 1 = 0.08243216$，因此$r = \ln(1.08243216) \approx 0.0792$，略低于$8\%$的报价。按所报$8\%$本身做连续复利，会给出EAR $e^{0.08} - 1 \approx 0.083287$，约$8.329\%$，这并不是按季惯例。

连续现值为

$$
10 \cdot \frac{1 - e^{-0.06 \times 5}}{0.06} = 10 \cdot \frac{1 - e^{-0.30}}{0.06} \approx 43.19696,
$$

约$43.20$单位。每年$10$单位、为期五年、按**有效**$6\%$计的离散普通年金是$10(1 - 1.06^{-5})/0.06 \approx 42.12$单位。这两个数字回答两个不同的时间安排问题：全年细水长流，对每年年末一笔。把惯例混在一起，再把$43.20$与$42.12$比较，仿佛其中一个“更精确”，是把建模选择与测量误差混淆了。
:::
:::

::: quiz
一家银行报价$12\%$，按月复利。哪一项陈述正确？
- [ ] 有效年利率是$12\%$。
- [x] 有效年利率是$(1 + 0.12/12)^{12} - 1 \approx 12.68\%$。
- [ ] 有效年利率是$12 \times 12 = 144\%$。
- [ ] 按月复利与按$12\%$连续复利相同。
::: solution
[[#eq-ear]]取$r_{\text{名义}} = 0.12$、$m = 12$，给出$(1.01)^{12} - 1 \approx 0.126825$，约$12.68\%$。所报$12\%$是名义利率，不是EAR。把$12\%$乘以$12$，是把每月$12\%$的利率与每月$1\%$的利率混淆了。按$12\%$连续复利会给出$e^{0.12} - 1 \approx 12.75\%$，接近但并不等于按月复利。
:::
:::

## 使用现值

资本预算一章将把**净现值**定义为项目现金流的现值，包括（通常为负的）初始支出，并在既定假设下把NPV当作决策规则。本节只记录时间价值工具箱对该规则已经意味着什么，以便后续各章可以把线性性与标注日期当作已知。

若项目的序列是$(C_0, C_1, \dots, C_T)$，其风险类别的贴现率是$r$，则净现值为$\mathrm{NPV} = \sum_{t=0}^{T} C_t (1+r)^{-t}$。当$C_0 < 0$且随后的$C_t$为正时，NPV是流入现值减去流出现值。对这类常规项目，NPV对$r$的图像向下倾斜：更高的贴现率更惩罚遥远的流入，使项目看起来更差。NPV穿过零的那个利率是**内部收益率**，在[[corporate-finance/capital-budgeting]]中计算，对债券则作为到期收益率在[[corporate-finance/valuing-bonds]]中计算。

费雪（Fisher）的分离论证，出自《利息理论》（*The Theory of Interest*，1930），是企业根本可以使用市场利率的经济学理由。若所有者能在完备资本市场中按同一利率$r$借入和贷出，则企业通过按该利率最大化其现金流的现值来最大化所有者财富，然后所有者再借入或贷出，按自己的愿望把消费跨期移动。投资决策与消费决策分离。当所有者不能按共同的$r$交易，或现金流的风险方式不被市场张成时，分离失败，单一贴现率不再是充分统计量。这些失败正是后续各章在风险、资本结构和治理上花费那么长时间的原因。

::: remark 实际利率与名义利率
若现金流按名义单位预测——包含通货膨胀——则必须按名义利率贴现。若按实际单位预测，则必须按实际利率贴现。把实际现金流预测与名义贴现率混用，或反过来，是打扮成通货膨胀的标注日期错误。费雪关系$1 + i = (1+r)(1+\pi^{e})$把名义利率$i$、实际利率$r$和预期通货膨胀$\pi^{e}$联系起来；它用于[[money-banking/interest-rates]]。本课程中题目会说明$r$是实际还是名义。从不提及通货膨胀的示意性例子，是把$r$当作实际现金流上的实际有效利率，或等价地当作已经是名义的现金流上的名义利率，并把通货膨胀作为建模选择设为零。
:::

::: application 有限寿命的工厂
虚构制造商赫利俄斯有限公司（Helios Ltd）可以建设一座工厂，日期$0$成本$100$单位，并在企业的规划表格中预期随后四年每年年末产生$40$单位的实际现金流入。按$10\%$的实际贴现率，流入的现值为

$$
40 \cdot \frac{1 - (1.10)^{-4}}{0.10} = 126.79461785,
$$

约$126.79$单位，因此NPV约$26.79$单位。在$20\%$下NPV降到约$3.55$单位；在$0\%$下是$60$单位。这些数字将作为[[corporate-finance/capital-budgeting]]的贯穿例子再次出现。它们不是建设任何工厂的理由。它们表明，在维持的时间安排和维持的利率下，$40$的四年年金和$100$的支出在$10\%$下有正NPV，在$20\%$下更小。
:::

## 证据

现值算术是定义，不是经验主张，但企业中对现值的**使用**是经验问题。约翰·格雷厄姆（John Graham）与坎贝尔·哈维（Campbell Harvey）调查了392位首席财务官，并在《金融经济学杂志》（第60卷，2001年）中报告：内部收益率和净现值是被引用最频繁的两种资本预算工具，回收期仍被广泛使用。该调查是20世纪90年代末大多为美国大企业的报告实践快照，不是经理行为的定律，也不是家庭或其他国家企业的样本。随后的调查，包括格雷厄姆与同事的后续工作，发现了同样的工具排序，重点有所移动；它们在[[corporate-finance/capital-budgeting]]中被引用。

复利所产生的几何增长，在任何再投资余额的长序列中都看得见，但市场收益率并不是常数$r$。迪姆森、马什与斯汤顿（Dimson, Marsh and Staunton）的长期年鉴记载，股票、债券和国库券的已实现实际收益率在年份之间和国家之间差异很大；常数$r$的计算是模型，不是对这些路径的描述。把历史平均收益率用作项目的贴现率，是进一步的建模步骤，在[[corporate-finance/risk-and-return]]中讨论，它并不由本章的代数推出。

::: history
复利比公司金融更古老。斐波那契（Fibonacci）的《算盘书》（*Liber Abaci*，1202）已经处理贴现问题；约翰·德维特（Johan de Witt）1671年为荷兰议会所作的生命年金报告，通过贴现给或有支付序列定价。资本是收入的现值、以及竞争性资本市场使投资与消费决策分离，这一现代陈述属于欧文·费雪（Irving Fisher），见《利率》（*The Rate of Interest*，1907）以及更完整的《利息理论》（*The Theory of Interest*，1930）。约翰·伯尔·威廉斯（John Burr Williams）的《投资价值理论》（*The Theory of Investment Value*，1938）把同一现值想法用于股票，把价格写成贴现股利——[[corporate-finance/valuing-stocks]]的起点。
:::

## 由此通向何处

债券是有限期年金加上本金偿还；其价格和收益率是[[#eq-annuity]]再加一项，在[[corporate-finance/valuing-bonds]]中展开。股票在[[corporate-finance/valuing-stocks]]中被建模为增长永续年金或其两阶段表亲。[[corporate-finance/capital-budgeting]]中的资本预算采用上面定义的NPV，把它与回收期和IRR比较，并问哪些现金流是增量的。这里当作数据的贴现率，在[[corporate-finance/risk-and-return]]中由风险构造。连续贴现会再次出现为现金流密度的现值积分，以及在[[derivatives/options]]中乘在期权支付上的$e^{-rT}$。

::: summary
- 不同日期的现金流在按既定利率$r$复利或贴现到同一日期之前，不能相加。
- $C_t$的现值是$C_t (1+r)^{-t}$；现值对现金流是线性的，因此一条序列是其各期片段之和。
- $n$次支付、每次为$C$的普通年金价值为$C\bigl(1-(1+r)^{-n}\bigr)/r$；水平永续年金价值为$C/r$；第一次支付为$C$的增长永续年金在$r > g$时价值为$C/(r-g)$。
- 不同复利频率的报价利率必须先换算成有效年利率（或同一频率）再比较；连续复利把$(1+r)^{t}$换成$e^{rt}$。
- 公式假定不变利率、已知现金流，以及被命名的时间惯例（期末对连续）。它们在这些假设下是恒等式，不是预测，也不是放贷、借款或投资的建议。
- 净现值是包含初始支出的项目现金流现值；它作为决策规则的使用，以及由风险构造$r$，属于后续各章。
:::

## 习题

::: exercise 一笔终值 {level=1 check="231.53"}
一笔$200$单位的现金流按每年有效$5\%$复利三年。终值是多少，四舍五入到两位小数？（输入该四舍五入值。）
::: solution
$200 \times (1.05)^3 = 200 \times 1.157625 = 231.525$，四舍五入为$231.53$。
:::
:::

::: exercise 一笔现值 {level=1 check="367.51"}
按每年有效$8\%$，四年后收到的$500$单位的现值是多少？四舍五入到两位小数。
::: solution
$500 / (1.08)^4 = 500 / 1.36048896 \approx 367.5149$，四舍五入为$367.51$。
:::
:::

::: exercise 增长永续年金 {level=1 check="200"}
一份增长永续年金一年后支付$12$单位，然后每年按$2\%$永远增长。贴现率是$8\%$。现值是多少？（输入精确现值。）
::: solution
$r > g$，因此[[#prop-annuity-pv]]给出$12 / (0.08 - 0.02) = 200$。
:::
:::

::: exercise 普通年金 {level=2 check="379.08"}
B企业将在随后五年的每年年末收到$100$单位。贴现率是每年有效$10\%$。这一普通年金的现值是多少，四舍五入到两位小数？
::: solution
$100 \times \bigl(1 - (1.10)^{-5}\bigr) / 0.10 = 379.07867694$，四舍五入为$379.08$。
:::
:::

::: exercise 有效年利率 {level=2 check="0.1268"}
$12\%$的名义利率按月复利。有效年利率是多少，四舍五入到四位小数（因此$12.68\%$输入为$0.1268$）？
::: solution
$(1 + 0.12/12)^{12} - 1 = (1.01)^{12} - 1 \approx 0.126825$，四舍五入为$0.1268$。
:::
:::

::: exercise 预付年金与普通年金 {level=2 check="390.08"}
使用[[#ex-annuity]]中十次$50$单位支付和$6\%$利率，**预付年金**的现值是多少，四舍五入到两位小数？
::: solution
普通现值是$368.00435257$。乘以$1.06$得到$390.08461372$，四舍五入为$390.08$。等价地，$50$加上$6\%$下九次支付的普通年金产生同一数字。
:::
:::

::: exercise 连续现值 {level=3 check="62.96"}
每年$8$单位、为期十年的连续现金流按连续复利$5\%$贴现。现值是多少，四舍五入到两位小数？
::: hint
使用[[#eq-cont-pv]]，取$C = 8$，$r = 0.05$，$T = 10$。
:::
::: solution
$8 \times (1 - e^{-0.5}) / 0.05$。现$e^{-0.5} \approx 0.60653066$，因此$1 - e^{-0.5} \approx 0.39346934$，现值为$8 \times 7.8693868 \approx 62.955$，四舍五入为$62.96$。
:::
:::

::: exercise 增长年金 {level=3 check="187.90"}
一份增长年金一年后支付$C = 30$单位，然后每年按$g = 4\%$增长，共$n = 8$次支付。贴现率是$r = 9\%$。现值是多少，四舍五入到两位小数？
::: hint
因为$r \neq g$，[[#eq-growing-annuity]]适用。
:::
::: solution
$$
\frac{30}{0.09-0.04}\Bigl(1 - \bigl(\tfrac{1.04}{1.09}\bigr)^{8}\Bigr) = 600 \bigl(1 - (1.04/1.09)^{8}\bigr).
$$

现$(1.04/1.09)^{8} \approx 0.68683866$，因此$1$减去该比约$0.31316134$，$600$乘以它是$187.8968$，四舍五入为$187.90$。
:::
:::

::: exercise 把报价利率配到连续利率 {level=3}
一则报价是“$8\%$按季复利”，如[[#ex-ear]]。求产生同一有效年利率的连续复利利率$r$，作为四位小数。然后确认$e^{r} - 1$恢复按季EAR。
::: hint
EAR是$(1.02)^4 - 1$。匹配的$r$是一加上该EAR的自然对数。
:::
::: solution
$\mathrm{EAR} = (1.02)^4 - 1 = 0.08243216$。于是$r = \ln(1.08243216) \approx 0.07922$，或四位小数$0.0792$。核对：$e^{0.07922} - 1 \approx 0.08243$，与按季EAR在五位小数上匹配。匹配的连续利率**低于**$8\%$的报价，因为按$8\%$连续复利会超过按季EAR。
:::
:::
