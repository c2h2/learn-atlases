一项明年期望支付115个货币单位的要求权，一般不会在今天卖到115个单位。若这115是确定的，折扣就只是利息。若这115是一个分散彩票的均值，还会出现进一步的折扣，而这进一步的折扣正是资产定价的主题。本章为后面各章将要定价的对象命名：一个**收益率**、一种**风险**度量，以及一种把风险变成价格的**风险厌恶**。除非附有来源与日期，数字都是虚构的。这里没有任何内容是对任何市场的预测，也没有任何内容构成买入、卖出或持有任何证券的建议。

上一门课把资本成本当作企业决策的投入（[[corporate-finance/risk-and-return]]）。在这里资本成本是产出：它是出清给定风险之市场所要求的预期收益率。为此我们需要不混用单位的算术、对支付的统计描述，以及一种可以拒绝公平赌博的偏好。概率与抽样在数学图谱中展开；本章使用它们，而不再推导均值的抽样分布。

## 简单收益率、对数收益率与超额收益率

报价不是收益率。两份合约可以代表相同的经济敞口却带着不同的报价，因为一种报价用了不同单位，或因为一种报价是期货价格而不是现金价格。在接近50的报价上移动2，与在接近200的报价上移动2，不是同一个对象。除以上一期价格就去掉了单位。

::: definition 简单收益率与总收益率 {#def-simple}
设 $P_{t-1}$ 与 $P_t$ 为相继的正价格，或一个在两日之间既不追加也不抽走现金的满仓账户的相继正水平。该步上的**总收益率**是 $P_t/P_{t-1}$。**简单收益率**是

$$
R_t = \frac{P_t}{P_{t-1}} - 1.
$$

等价地，$P_t = P_{t-1}(1+R_t)$。简单收益率 $0.04$ 就是移动了4%。定义要求 $P_{t-1} \neq 0$。它不要求 $P_t > 0$，但非正的 $P_t$ 使总收益率为非正，并使 [[#def-log]] 的对数收益率没有定义。
:::

在 $T$ 步之内既不追加也不抽走现金时，终端水平等于起始水平乘以每一步的总收益率。因此从日期 $0$ 到日期 $T$ 的**复合简单收益率**是

$$
\frac{P_T}{P_0} - 1 = \prod_{t=1}^{T}(1+R_t) - 1.
$$

乘积才是右边。求和 $\sum_t R_t$ 是另一个数。对两步，代数很短：

$$
(1+a)(1+b) - 1 = a + b + ab.
$$

额外的一项 $ab$ 是交叉项。它为零，仅当至少一个简单收益率为零。当两个收益率都为正时交叉项为正，因而复合收益率超过求和；当收益率异号时交叉项为负。并不存在一般不等式说“求和是保守的”。

股利、票息、拆股与现金缴款会打破价格比与账户之间的等同。若在 $t-1$ 与 $t$ 之间支付股利 $D_t$，且报价是除息价，则账户上的简单收益率是 $(P_t + D_t)/P_{t-1} - 1$，而不是 $P_t/P_{t-1} - 1$。上面的望远镜乘积对你喂给它的任何正序列都成立。建模选择是哪一条序列是账户。在本章中，除非例题另有说明，价格被当作一个没有外部现金的满仓账户的标记。[[corporate-finance/valuing-stocks]] 是股利的簿记；对拆股与展期的序列调整是量化图谱中处理的数据问题。

::: example 五个虚构收盘价 {#ex-five}
一家虚构的A公司股票有月末收盘价 $50, 52, 49, 53, 51, 55$，以货币单位计，无股利。精确计算五个简单收益率、这些收益率之和，以及从第一个收盘价到最后一个收盘价的复合简单收益率。
::: solution
五个简单收益率是

$$
\begin{align*}
R_1 &= 52/50 - 1 = 0.04,\\
R_2 &= 49/52 - 1 = -3/52 = -0.057692307\ldots,\\
R_3 &= 53/49 - 1 = 4/49 = 0.081632653\ldots,\\
R_4 &= 51/53 - 1 = -2/53 = -0.037735849\ldots,\\
R_5 &= 55/51 - 1 = 4/51 = 0.078431373\ldots.
\end{align*}
$$

四舍五入到六位小数是 $0.040000$，$-0.057692$，$0.081633$，$-0.037736$，$0.078431$。它们的和在六位小数上是 $0.104636$。复合简单收益率并不使用这个和。它使用两端的价格：

$$
\frac{55}{50} - 1 = 0.10.
$$

等价地，五个精确总收益率的乘积望远镜到 $55/50 = 1.10$。复合收益率比求和大约小 $0.0046$。这个缺口就是累积的交叉项。它很小，因为简单收益率只有几个百分点，而且它不是零。把 $0.104636$ 报告为“五个月的收益率”，与报告 $0.10$ 是不同的主张。
:::
:::

::: definition 对数收益率 {#def-log}
给定相继的正价格 $P_{t-1}$ 与 $P_t$，**对数收益率**（连续复利收益率）是

$$
r_t = \ln(1+R_t) = \ln P_t - \ln P_{t-1}.
$$

对数收益率随时间相加：$\sum_{t=1}^{T} r_t = \ln(P_T/P_0)$。它们并不在组合中跨资产相加。简单收益率在组合中跨资产相加（组合简单收益率是成分简单收益率的价值加权平均），并不随时间相加。
:::

当 $R_t$ 很小时，两个对象在一阶上一致，因为 $\ln(1+x) = x - x^2/2 + \cdots$。对简单收益率 $0.04$，对数收益率是 $\ln(1.04) \approx 0.039221$。缺口是二阶的。对简单收益率 $0.50$，对数收益率是 $\ln(1.50) \approx 0.405465$，缺口就不再是舍入误差。选定一种惯例并坚持使用，是陈述模型的一部分。把它们混用——把各月简单收益率相加，或把各名称的对数收益率在组合中平均并称之为组合收益率——会产生一个不是任何既定账户之收益率的数字。

::: example 同一组收盘价上的对数收益率 {#ex-log}
在 [[#ex-five]] 的收盘价上，计算五个对数收益率，并确认它们之和等于 $\ln(55/50)$。
::: solution
五个对数收益率是 $\ln(52/50)$，$\ln(49/52)$，$\ln(53/49)$，$\ln(51/53)$ 与 $\ln(55/51)$。到六位小数它们是 $0.039221$，$-0.059423$，$0.078472$，$-0.038466$ 与 $0.075508$。它们的和是 $0.095310$，在所有印出的小数位上等于 $\ln(1.10)$。望远镜是恒等式，不是近似：每一个中间的 $\ln P_t$ 都消掉。复合简单收益率 $0.10$ 与总对数收益率 $0.095310$ 是从 $50$ 到 $55$ 同一条路径的两种描述。两者都不是对下一条路径的预测。
:::
:::

一旦把无风险替代放上桌面，就需要第三个对象。

::: definition 超额收益率 {#def-excess}
设 $R_t$ 为风险账户的简单收益率，$R_{f,t}$ 为同一日期上、在该步开始时已知的无违约账户简单收益率（在许多经验实施中是国库券收益率）。**超额收益率**是 $R_t^e = R_t - R_{f,t}$。当它为常数时，**净无风险利率**是 $r_f$；**总无风险利率**是 $R_f = 1+r_f$。在本课程中，不带上标的 $R$ 按周围记号是总的或净的简单收益率，$r$ 是对数收益率或净利率；每一章都会说明是哪一种。
:::

超额收益率是均值–方差投资者因承担风险而得到补偿的那个量。它也是因子模型将被要求解释的那个量。减去 $R_{f,t}$ 并不使剩余不可预测，也并不使 $R_{f,t}$ 在实际项下字面无风险：$t-1$ 与 $t$ 之间的通货膨胀在 $t-1$ 时并不知道。当我们需要实际无风险支付时，我们会说出来。

::: warning 把简单收益率跨时间相加
[[#ex-five]] 的五个简单收益率加起来约为 $0.1046$。从 $50$ 持有一股到 $55$ 的账户赚到的是 $0.10$。把简单收益率相加，是与把它们复合起来不同的算术。同一警告也沿另一方向成立：把对数收益率在组合的各名称之间平均，并不给出组合的对数收益率，因为 $\ln(\sum_i w_i e^{r_i})$ 不是 $\sum_i w_i r_i$。用简单收益率混合资产，用对数收益率混合日期，或者显式换算。
:::

## 均值、方差与夏普比率

未来一步上的收益率是随机变量。我们写 $\E[R]$ 表示其均值，$\Var(R)$ 表示其方差，$\sigma(R) = \sqrt{\Var(R)}$ 表示其标准差，在本领域中常称为**波动率**。对两个收益率，$\Cov(R_i, R_j) = \E[(R_i-\E[R_i])(R_j-\E[R_j])]$，当两个标准差都为正时相关系数是 $\rho_{ij} = \Cov(R_i,R_j)/(\sigma_i\sigma_j)$。这些是总体对象。容量为 $T$ 的已实现收益率样本 $\hat R_1,\ldots,\hat R_T$ 产生**样本均值** $\bar R = T^{-1}\sum_t \hat R_t$，**样本方差** $s^2 = (T-1)^{-1}\sum_t (\hat R_t - \bar R)^2$，以及类似定义的样本协方差。帽号或“样本”一词就是区别。把样本均值当作 $\E[R]$，就是把历史表变成预测的那一步；除非模型如此声称，本课程不走那一步。

::: definition 夏普比率 {#def-sharpe}
对同一期限上的收益率 $R$ 与无风险利率 $r_f$，**夏普比率**是

$$
S = \frac{\E[R] - r_f}{\sigma(R)},
$$

前提是 $\sigma(R) > 0$。样本夏普比率用样本矩替换总体矩。该比率对步长并不不变：月度夏普并不是年度夏普的十二倍，因为均值随时间成比例缩放，而标准差在增量不相关时随时间的平方根缩放。
:::

夏普比率是均值–标准差空间中的斜率。[[asset-pricing/portfolio-choice]] 将表明，每一位面对无风险资产的均值–方差投资者，都想要夏普比率最大的风险组合。那是均值–方差问题的性质，而不是供读者遵循的基金排名。交易成本、期权式支付与非正态性都使该比率成为不完整的概括；[[#def-sharpe]] 并不另有主张。

::: example 五个收益率上的样本矩 {#ex-moments}
在 [[#ex-five]] 的五个简单收益率上，计算样本均值、样本标准差（除数 $T-1 = 4$），以及相对于月度无风险简单收益率 $0.002$ 的样本夏普比率。
::: solution
五个收益率在九位小数上加总为 $0.104635869$，因此样本均值是 $0.104635869/5 = 0.020927174$。除数为 $4$ 的样本方差是 $0.004244508$，样本标准差在六位小数上是 $0.065150$。样本平均超额收益率是 $0.020927174 - 0.002 = 0.018927174$，因此样本夏普比率是 $0.018927174/0.065150 \approx 0.290$。这个数字是这五个虚构数字的性质。它不是预期夏普比率，也不能与从另一序列算出的年度夏普比率相比较。
:::
:::

若对数收益率被建模为独立同分布正态，则简单收益率是独立同分布对数正态。简单收益率的均值于是超过中位数，因为对数正态随机变量向右偏。显式地，若 $r \sim N(\mu, \sigma^2)$，则 $\E[e^r] = \exp(\mu + \sigma^2/2)$，因此预期简单收益率是 $\exp(\mu+\sigma^2/2)-1$，而中位数简单收益率是 $e^\mu - 1$。在 $\mu = 0.08$、$\sigma = 0.20$ 时这两个数是 $0.105171$ 与 $0.083287$。把 $0.08$ 叫做“预期收益率”而不说它是对数的均值还是简单收益率的均值，是对象的混淆。正态模型已经是一种约束：已实现收益率直方图通常比具有相同方差的正态密度在中心更尖、在尾部更厚，这一规律性在下面记录。

均值与波动率的**年化**是在关于相依性的假设之下的单位换算。若月度简单收益率不相关且具有常数均值 $\mu_m$ 与方差 $\sigma_m^2$，则在简单收益率求和惯例下年度均值是 $12\mu_m$，在复合惯例下是 $(1+\mu_m)^{12}-1$，而*求和*的年度标准差是 $\sigma_m\sqrt{12}$。这两个年度均值不是同一个数，一旦存在序列相关或时变波动率，两种换算都不成立。写“$16\%$ 波动率”而不写期限，是未完成的。

## 期望效用与风险厌恶

为什么会有人愿意为均值是 $115$ 的彩票支付少于 $115$？因为额外一单位财富在已经富裕的状态到来时，在效用上不如在贫穷状态到来时值钱。这个想法比投资组合理论更古老。

::: definition 期望效用 {#def-eu}
一位对财富 $W$ 上的彩票具有冯·诺依曼–摩根斯坦偏好的决策者，由一个严格递增、二次可微的**效用函数** $u$ 代表，该函数在正仿射变换下唯一，并以 $\E[u(W)]$ 给彩票排序。若 $u$ 严格凹，决策者是**风险厌恶**的；若 $u$ 线性，是**风险中性**的；若 $u$ 严格凸，是**风险爱好**的。由詹森不等式，风险厌恶等价于对每一个非退化彩票有 $\E[u(W)] < u(\E[W])$。
:::

彩票 $W$ 的**确定性等价** $C$ 由 $u(C) = \E[u(W)]$ 定义；它是决策者觉得与该彩票无差异的确定财富。该彩票的**风险溢价** $\Pi$ 是 $\E[W] - C$。对风险厌恶的决策者，$\Pi > 0$：他们愿意付费，用均值替换彩票。到此尚未说明 $\Pi$ 如何依赖于 $u$ 的形状或赌博的大小。那是阿罗–普拉特理论的内容。

::: definition 阿罗–普拉特系数 {#def-arrow-pratt}
对二次可微且 $u' > 0$ 的 $u$，在财富 $W$ 处的**阿罗–普拉特绝对风险厌恶系数**是

$$
A(W) = -\frac{u''(W)}{u'(W)},
$$

而**相对风险厌恶系数**是

$$
R(W) = -W\frac{u''(W)}{u'(W)} = W\, A(W).
$$

若 $A'(W) < 0$，偏好是**递减绝对风险厌恶**（DARA）；若 $A$ 为常数，是**常绝对风险厌恶**（CARA）；若 $A'(W) > 0$，是递增绝对风险厌恶；相对风险厌恶同理（DRRA、CRRA、IRRA）。
:::

::: proposition 阿罗–普拉特近似 {#prop-ap}
设 $W = \bar W + \tilde\varepsilon$，其中 $\E[\tilde\varepsilon] = 0$ 且 $\Var(\tilde\varepsilon) = \sigma^2$ 很小。对风险厌恶的 $u$，该彩票的风险溢价 $\Pi$ 满足

$$
\Pi = \tfrac12 A(\bar W)\, \sigma^2 + o(\sigma^2).
$$

特别地，在两个二次可微效用中，在 $\bar W$ 处 $A$ 更大的那个，对小赌博要求更大的溢价。假设：$u$ 在 $\bar W$ 的邻域内是 $C^2$ 的，$u'(\bar W) > 0$，并且泰勒余项中用到的 $\tilde\varepsilon$ 的矩有限。
:::

::: proof
把 $u(\bar W + \tilde\varepsilon)$ 在 $\bar W$ 处做泰勒展开：

$$
u(\bar W + \tilde\varepsilon) = u(\bar W) + u'(\bar W)\tilde\varepsilon + \tfrac12 u''(\bar W)\tilde\varepsilon^2 + r(\tilde\varepsilon),
$$

其中在矩假设下，当 $\sigma \to 0$ 时 $r(\tilde\varepsilon)/\sigma^2$ 在期望上趋于 $0$。取期望，$\E[u(W)] = u(\bar W) + \tfrac12 u''(\bar W)\sigma^2 + o(\sigma^2)$。确定性等价满足 $u(\bar W - \Pi) = \E[u(W)]$。展开左边，$u(\bar W) - u'(\bar W)\Pi + o(\Pi) = u(\bar W) + \tfrac12 u''(\bar W)\sigma^2 + o(\sigma^2)$。对 $\Pi$ 求解并使用 $A = -u''/u'$ 即得命题。两个效用的比较是普拉特关于小风险的定理；全局版本（一个效用比另一个更风险厌恶，当且仅当它是另一个的凹变换）见普拉特（Pratt，1964，《计量经济学杂志》）。
:::

两个族被经常使用。**CARA**（指数）效用 $u(W) = -e^{-AW}$（$A > 0$）有 $A(W) = A$，与财富无关。**CRRA**（等弹性、幂）效用

$$
u(C) = \begin{cases}
C^{1-\gamma}/(1-\gamma) & \gamma > 0,\; \gamma \neq 1,\\
\ln C & \gamma = 1,
\end{cases}
$$

有 $R(C) = \gamma$，与 $C$ 无关。对数效用是幂族在 $\gamma \to 1$ 时的极限。CRRA 是 [[asset-pricing/consumption-based-pricing]] 中基于消费的定价的主力，因为它使组合份额与财富无关，并且它定义在乘性冲击上。CARA 对加性正态冲击方便，它有一个不好的含义：更富的主体在给定的加性赌博中投入*相同数量的单位*。

一位具有 $u(W) = \ln W$ 的决策者面对财富为 $150$ 或 $80$ 的 $50$–$50$ 彩票。计算期望财富、期望效用、确定性等价与风险溢价。
::: solution
期望财富是 $0.5\times 150 + 0.5\times 80 = 115$。期望效用是 $0.5\ln 150 + 0.5\ln 80 = \ln\sqrt{12000} = \ln(109.544511\ldots)$。因此确定性等价是 $C = \sqrt{12000} \approx 109.545$。风险溢价是 $115 - 109.545 = 5.455$。决策者在该彩票与确定的 $109.545$ 之间无差异，并且愿意最多支付 $5.455$ 用均值替换彩票。这些是 $\ln W$ 在这张彩票上的性质。它们不是任何资产“必须”赚到的溢价。
:::
:::

::: example 同一彩票在 $\gamma = 2$ 下 {#ex-gamma2}
用 $u(C) = -1/C$（即 $\gamma = 2$ 的CRRA）重复 [[#ex-log-ce]]。
::: solution
期望效用是 $0.5(-1/150) + 0.5(-1/80) = -0.00958333\ldots$。确定性等价满足 $-1/C = -0.00958333\ldots$，因此 $C = 1/0.00958333\ldots = 104.3478$。风险溢价是 $115 - 104.348 = 10.652$。相对于对数效用，$\gamma = 2$ 在这张彩票上更风险厌恶，正如 [[#prop-ap]] 所要求的，因为 $R(W) = 2 > 1$。两个效用的排序是凹性的排序，不是关于任何人如何或应当如何选择的陈述。
:::
:::

::: example CARA下的小加性赌博 {#ex-cara}
一位具有 $u(W) = -e^{-0.02 W}$ 的决策者当前财富为 $100$，面对 $+10$ 或 $-10$ 的 $50$–$50$ 加性赌博。计算精确的风险溢价以及阿罗–普拉特近似 $\tfrac12 A \sigma^2$。
::: solution
两个财富水平是 $110$ 与 $90$。期望效用是

$$
0.5\bigl(-e^{-0.02\times 110}\bigr) + 0.5\bigl(-e^{-0.02\times 90}\bigr) = -0.138051023.
$$

确定性等价满足 $-e^{-0.02 C} = -0.138051023$，因此 $C = -\ln(0.138051023)/0.02 \approx 99.0066$。风险溢价是 $100 - 99.0066 = 0.9934$。该赌博均值为零、方差为 $100$，且 $A = 0.02$，因此近似是 $\tfrac12 \times 0.02 \times 100 = 1.00$。精确溢价与近似相差不到百分之一，对并非财富很大一部分的赌博本应如此。近似是局部陈述。它不是A公司股票的定价公式。
:::
:::

::: intuition 凹效用更重地给坏状态定价
从 $\bar W$ 损失一单位，比获得一单位所增加的效用，代价更大，因为 $u'$ 递减。因此期望效用比算术均值更看重下行。这种再加权就是本模型中风险厌恶的全部。关于收益与损失的另一种心理学在 [[asset-pricing/behavioural-finance]] 中讨论；它不是可以在 [[#def-eu]] 内部默默施加的修正。
:::

## 风险的价格

能够交易的风险厌恶主体，不会把与他们已经面对的一切都不相关的公平赌博留在桌上：他们可以拿一点点，提高期望效用，然后停下。若拿它会恶化已经很糟的状态，他们*会*把公平赌博留在桌上。因此，支付与主体边际效用的协方差，才是必须得到补偿的量。那句话是 [[asset-pricing/stochastic-discount-factor]] 的随机贴现因子观点，并且在这里已经可见。

对小风险与光滑的 $u$，[[#prop-ap]] 给出均值–方差近似：主体近似地按 $\E[R_p] - \tfrac12 A \Var(R_p)$ 给组合排序。在这种排序下，一项支付对主体风险的贡献，是它与他们已经持有的组合的协方差。在均衡中，若每一位主体都持有同一组合的一块——那一步将产生CAPM——该协方差就变成与市场的协方差。这些步骤没有一步是免费的，每一步都在接下来两章中被点名。

历史上，股票相对于短期无违约债务所支付的补偿，相对于股票与消费的协方差来说一直很大。梅赫拉与普雷斯科特（Mehra and Prescott，1985，《货币经济学杂志》）报告，对1889–1978年的美国，标准普尔综合指数的平均实际年收益率是 $6.98\%$，短期债务的平均实际收益率是 $0.80\%$，差额——**股权溢价**——是 $6.18$ 个百分点，实际股票收益率的标准差是 $16.54\%$。一个具有幂效用与中等 $\gamma$ 的代表性主体模型，在那些消费矩上最多只能产生零点几个百分点的溢价；这个缺口就是**股权溢价之谜**，在 [[asset-pricing/consumption-based-pricing]] 中处理。这些数字是历史样本。它们不是1979年以后的预期溢价，也不是任何具名股票的要求收益率。

覆盖更多国家与更长窗口的更广历史记录，是迪姆森–马什–斯汤顿（Dimson–Marsh–Staunton）数据库。在《瑞士信贷全球投资回报年鉴2023》中，他们报告，从1900年到2022年（123年），世界股票指数以美元计的年化实际收益率是 $5.0\%$，债券为 $1.7\%$，票据为 $0.4\%$；世界股票每年跑赢票据 $4.6\%$，跑赢债券 $3.3\%$。在他们研究的全部 $35$ 个市场中，股票都跑赢了债券、票据与通货膨胀。澳大利亚录得年化实际美元收益率 $6.43\%$，美国 $6.38\%$。这些是收入再投资的几何（复合）实际收益率，不是预测，也不是读者应当持有股票的国家排名。世界数字低于美国数字，这是不把美国记录当作代表性主体参数的原因之一。

::: quiz
一个满仓账户在五个月内从 $50$ 走到 $55$，简单收益率如 [[#ex-five]]。哪一个数字是该账户的复合简单收益率？
- [ ] $0.104636$，五个简单收益率之和
- [x] $0.10$，等于 $55/50 - 1$
- [ ] $0.095310$，五个对数收益率之和
- [ ] $0.020927$，五个简单收益率的样本均值
::: solution
复合简单收益率使用两个端点价格，或总收益率的乘积，等于 $0.10$。简单收益率之和是不同的算术。对数收益率之和等于 $\ln(1.10)$，是总对数收益率，不是简单复合。样本均值是每月平均，不是五个月的复合。
:::
:::

## 证据：收益率的典型化事实

下面的统计规律性是**典型化事实**：在特定样本上记录的经验规律，不是定理，也不是下一样本看起来会相同的主张。它们约束我们写下的模型。它们本身并不识别风险溢价。

**厚尾。** 日度与月度股票指数收益率在极端处的质量，多于具有相同方差的正态分布。曼德博（Mandelbrot，1963，《商业杂志》）在棉花价格上做出这一观察；法马（Fama，1965，《商业杂志》）在美国股票价格上记录了它。自由度为三到六的学生 $t$ 是日度指数收益率的常见漫画。峰度估计依赖于样本，并被单日拉动；正态低估崩盘频率这一定性事实，在主要指数的战后样本中稳定。

**指数中的负偏度，个股中的正偏度。** 指数收益率，尤其在日度与周度期限上，通常是负偏的：大的下跌日比大的上涨日更大。个股收益率往往正偏。加总，以及股票倾向于一起下跌，是对这一差别的通常解释。偏度是三阶矩；均值–方差理论忽略它，这是 [[asset-pricing/portfolio-choice]] 的局限，而不是数据的缺陷。

**波动聚集。** 大的移动后面往往跟着大的移动，无论符号。恩格尔（Engle）的ARCH模型（1982，《计量经济学杂志》）与博勒斯莱夫（Bollerslev）的GARCH（1986，《计量经济学杂志》）是标准统计描述。聚集本身并不产生风险溢价：风险中性主体对方差成串到来的公平赌博仍然无差异。它确实意味着高频上常数 $\sigma$ 的假设为假，并且短窗口上的样本夏普比率是嘈杂的。

**杠杆相关。** 对股票指数，波动率往往在指数下跌时上升。布莱克（Black，1976）提出了杠杆故事（更低的股价提高企业的债务股权比）；风险溢价故事——提高预期收益率的消息提高当前波动率并压低当前价格——是主要替代。该相关是关于指数的事实。对个股和许多非股票资产，它更弱，有时不存在。

**特质噪声的分散化。** 特质冲击不相关的 $n$ 只股票等权组合的方差，像 $1/n$ 一样下降，再加上任何共同因子。在共同标准差 $0.20$、每只名称特质标准差 $0.25$ 时，组合标准差是 $\sqrt{0.20^2 + 0.25^2/n}$，在 $n=1$ 时为 $0.320$，在 $n=5$ 时为 $0.229$，在 $n=10$ 时为 $0.215$，在 $n=100$ 时为 $0.202$。到几十只名称，大部分特质方差已经消失；共同因子仍在。那一算术是 [[asset-pricing/portfolio-choice]] 的起点。它不是持有任何特定 $n$ 的建议。

这些规律性没有一条是定理，也没有一条是交易规则。它们是定价模型被要求消化的原材料的形状。

## 由此通向何处

[[asset-pricing/portfolio-choice]] 把均值与方差当作主体的选择对象并构造有效前沿。[[asset-pricing/capm]] 把许多这样的主体放入均衡，并给与市场的协方差定价。[[asset-pricing/stochastic-discount-factor]] 回到与边际效用的协方差，并表明本课程中每一个无套利模型都是 $p = \E[mx]$ 的特例。上面引用的股权溢价数字在 [[asset-pricing/consumption-based-pricing]] 中变成定量检验。自始至终，样本均值就是样本均值。用 $\E[R]$ 替换它是建模步骤，应当被写下来。

::: history
1738年，丹尼尔·伯努利（Daniel Bernoulli）在圣彼得堡帝国科学院《评注》上发表《关于风险度量新理论的说明》。一个以概率 $2^{-k}$ 支付 $2^k$ 单位、$k = 1, 2, \ldots$ 的彩票具有无穷期望值，却没有人会为它支付无穷价格；那就是圣彼得堡悖论。伯努利提出，赌博的价值是财富*对数*的期望，对该彩票它是有限的，并且他用额外财富的边际价值递减来为对数提供动机。这篇论文是 [[#def-eu]] 与对数效用的祖先。它不是市场价格理论：没有出清，也没有第二个主体。现代形式的期望效用理论是冯·诺依曼（von Neumann）与摩根斯坦（Morgenstern）1944年的《博弈论与经济行为》；阿罗–普拉特系数来自普拉特（Pratt，1964，《计量经济学杂志》）与阿罗（Arrow）1965年的于尔约·扬松讲座《风险承担理论的若干方面》。
:::

::: summary
- 简单收益率是 $R_t = P_t/P_{t-1} - 1$。复合简单收益率把总收益率相乘；它们不相加。在虚构收盘价 $50$ 到 $55$ 上，复合简单收益率是 $0.10$，五个简单收益率之和约为 $0.1046$。
- 对数收益率 $r_t = \ln(1+R_t)$ 随时间相加，并不跨资产相加。简单收益率在组合中跨资产相加，并不随时间相加。
- 超额收益率是 $R_t - R_{f,t}$。夏普比率是单位标准差上的平均超额收益率，在既定期限上。
- 样本均值不是 $\E[R]$。年化均值与波动率使用关于相依性的假设，应当被陈述。
- 风险厌恶是 $u$ 的凹性。阿罗–普拉特系数 $A(W) = -u''(W)/u'(W)$ 把小方差转换成风险溢价 $\Pi \approx \tfrac12 A \sigma^2$。
- CRRA效用具有常数相对风险厌恶 $\gamma$；CARA具有常数绝对风险厌恶 $A$。对数效用是 $\gamma = 1$ 的CRRA。
- 梅赫拉与普雷斯科特（1985）报告1889–1978年美国实际股权溢价为 $6.18$ 个百分点。迪姆森、马什与斯汤顿（2023）报告1900–2022年世界几何实际股票收益率为每年 $5.0\%$，票据为 $0.4\%$。两者都是历史样本，不是预期收益率。
:::

::: solution

::: exercise 对数正态均值 {level=1 check="0.105171"}
对数收益率被建模为 $N(0.08, 0.20^2)$。输入预期简单收益率 $\exp(\mu+\sigma^2/2) - 1$，到六位小数。
::: solution
$\mu + \sigma^2/2 = 0.08 + 0.02 = 0.10$，因此 $\exp(0.10) - 1 = 0.105170918\ldots$，四舍五入为 $0.105171$。中位数简单收益率是 $e^{0.08}-1 \approx 0.083287$，一个更小的数。问题中的 $0.08$ 是*对数*的均值，不是简单收益率的均值。
:::

::: exercise 样本夏普 {level=2 check="0.290"}
使用 [[#ex-moments]] 中的样本平均超额收益率 $0.018927$ 与样本标准差 $0.065150$，输入样本夏普比率，到三位小数。
::: solution
$0.018927 / 0.065150 \approx 0.29048$，四舍五入为 $0.290$。输入已经减去了月度无风险简单收益率 $0.002$。用乘以 $\sqrt{12}$ 来年化这个数字，将是关于序列相关的进一步假设，并未被问到。

::: exercise 对数效用下的确定性等价 {level=2 check="109.545"}
对 [[#ex-log-ce]] 的彩票，输入确定性等价，到三位小数。
::: solution
$C = \sqrt{150\times 80} = \sqrt{12000} \approx 109.544511$，四舍五入为 $109.545$。期望财富是 $115$；风险溢价约为 $5.455$。平方根是两个结果的几何平均，它是对数效用在等概率两点彩票上的确定性等价。
:::
:::

::: exercise 小赌博上的阿罗–普拉特 {level=2 check="1"}
一位CARA决策者有 $A = 0.02$，面对方差为 $100$ 的零均值加性赌博。输入阿罗–普拉特近似风险溢价 $\tfrac12 A\sigma^2$。
::: solution
$\tfrac12 \times 0.02 \times 100 = 1$。[[#ex-cara]] 把两点赌博 $+10$ 或 $-10$ 上的精确溢价算成 $0.993$，那是同一近似目标。公式是局部的；它不是一只股票的价格。
:::

::: exercise 不相关噪声的分散化 {level=3 check="0.215"}
每只名称有共同因子标准差 $0.20$ 与特质标准差 $0.25$，特质冲击跨名称不相关。输入 $n = 10$ 只名称等权组合的标准差，到三位小数。
::: hint
组合方差是 $0.20^2 + 0.25^2/n$。
:::
::: solution
$\sqrt{0.04 + 0.0625/10} = \sqrt{0.04625} \approx 0.215058$，四舍五入为 $0.215$。在 $n=1$ 时同一公式给出 $0.320$；在 $n=100$ 时给出 $0.202$。共同因子是地板。计算假设等权、相同残差方差与零残差相关；若残差相关，地板更高。
:::
:::

::: exercise 幂效用的相对风险厌恶 {level=3}
对 $u(C) = C^{1-\gamma}/(1-\gamma)$，$\gamma > 0$，$\gamma \neq 1$，计算 $A(C)$ 与 $R(C)$。然后取极限 $\gamma \to 1$，恢复 $\ln C$ 的系数。
::: hint
求导：$u'(C) = C^{-\gamma}$，$u''(C) = -\gamma C^{-\gamma-1}$。相对风险厌恶是 $-C u''/u'$。
:::
::: solution
$u'(C) = C^{-\gamma}$，$u''(C) = -\gamma C^{-\gamma-1}$，因此

$$
A(C) = \frac{\gamma C^{-\gamma-1}}{C^{-\gamma}} = \frac{\gamma}{C}, \qquad R(C) = C\cdot\frac{\gamma}{C} = \gamma.
$$

相对风险厌恶是常数，等于指数。对 $u(C) = \ln C$，$u' = 1/C$，$u'' = -1/C^2$，因此 $A(C) = 1/C$，$R(C) = 1$，这就是 $\gamma \to 1$ 的情形。因此该族对每一个 $\gamma > 0$ 都是CRRA，包括对数。绝对风险厌恶随 $C$ 下降，因此该族既是DARA也是CRRA：更富的主体愿意接受更大的*加性*赌博，但在乘性赌博中投入财富的常数*份额*。
:::
:::
