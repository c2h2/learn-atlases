若每一位均值–方差主体都持有现金与同一切点组合的混合，则该切点组合必须是正净供给中一切东西的价值加权组合。那一识别把需求理论变成对预期收益率的均衡约束：一项资产的预期超额收益率等于它相对市场的**贝塔**，乘以市场的预期超额收益率。该约束就是**资本资产定价模型**（CAPM）。本章导出它，陈述承载推导的假设，并记录主要经验检验——包括模型失败的那些检验。CAPM是一个模型。历史平均收益率不是预期收益率，拟合的贝塔不是买入或卖出任何股票的理由。

需求方是 [[asset-pricing/portfolio-choice]]：两基金分离，共同的 $r_f$ 与同质信念。新的元件是市场出清。

## 从切点到市场

写 $R_m$ 表示**市场组合**的简单收益率，即全部投资财富的价值加权组合——每一只股票、每一张债券、每一块私人持有的资本、每一亩土地，在每一个国家。在任何实际检验中，$R_m$ 被代理替换，通常是股票市场指数。理论市场与代理之间的区别不是装饰性的；那是下面的罗尔批判。

::: definition 贝塔 {#def-beta}
资产 $i$ 相对组合 $m$ 的**贝塔**是

$$
\beta_{im} = \frac{\Cov(R_i, R_m)}{\Var(R_m)},
$$

前提是 $\Var(R_m) > 0$。等价地，$\beta_{im}$ 是总体回归 $R_i = \alpha_i + \beta_{im} R_m + \varepsilon_i$ 中的斜率，其中 $\E[\varepsilon_i] = 0$，$\Cov(\varepsilon_i, R_m) = 0$。**残差**（或**特质**）方差是 $\Var(\varepsilon_i) = \Var(R_i) - \beta_{im}^2\Var(R_m)$。
:::

贝塔是回归系数。它不是波动率。一项资产可以非常波动而仍然有很小的贝塔，若其方差大部分是残差。前一章中的分散化，说的是残差方差可以在分散良好的组合中被赶到接近零；贝塔不能，因为它是共同的。

::: proposition 残差方差不被定价 {#prop-idio}
在 [[#thm-sml]] 的假设下，两个具有相同 $\beta_{im}$ 的资产具有相同的预期收益率，不论 $\Var(\varepsilon_i)$ 如何。分散良好的组合的预期收益率只依赖于其平均贝塔。假设：[[#thm-sml]] 的那些；特别地，残差不是伪装的共同因子。
:::

::: proof
证券市场线是 $\E[R_i] = r_f + \beta_{im}(\E[R_m]-r_f)$。右边不含 $\Var(\varepsilon_i)$。对权重为 $\mathbf{w}$ 的组合，$\beta_{pm} = \mathbf{w}\T\boldsymbol\beta$，$\Var(\varepsilon_p) = \mathbf{w}\T \Sigma_\varepsilon \mathbf{w}$，若残差不相关且有界，它像 $1/n$ 一样消失。$p$ 的证券市场线仍然只使用 $\beta_{pm}$。若残差实际上是共同因子，它们属于 $m$，单因子CAPM是设定错误，而不是“给残差方差定价”。
:::

::: theorem CAPM证券市场线 {#thm-sml}
设两基金分离的假设成立（[[asset-pricing/portfolio-choice#thm-twofund]]），每一种资产都处于正净供给，并且市场出清。则切点组合就是市场组合，并且对每一种资产 $i$

$$
\E[R_i] = r_f + \beta_{im}\bigl(\E[R_m] - r_f\bigr).
$$

等价地，预期超额收益率与贝塔成比例，截距为零，斜率等于市场风险溢价 $\E[R_m]-r_f$。假设，汇集如下：一期；均值–方差（或联合正态收益率，或二次效用）；可无限借入贷出的共同无风险利率；关于 $\boldsymbol\mu$ 与 $\Sigma$ 的同质信念；没有非交易收入；无摩擦市场（无税收、无交易成本、无限可分的股份）；全部投资财富的市场组合。
:::

::: proof
两基金分离说，每一位主体 $h$ 把 $y^h$ 持有在切点组合 $T$ 中，把 $1-y^h$ 持有在无风险资产中。对主体求和，对风险束的总需求是 $(\sum_h y^h W^h) \mathbf{w}_T$。无风险资产处于零净供给（借入等于贷出），因此对风险资产的净需求必须等于它们的未偿价值。那只有在 $\mathbf{w}_T$ 等于那些资产的价值权重向量时才可能，而那就是市场 $\mathbf{w}_m$。故 $T = m$。

切点一阶条件是 $\boldsymbol\mu - r_f\mathbf{1} = \kappa\, \Sigma\mathbf{w}_m$，其中正标量 $\kappa$（加总约束上的拉格朗日乘子，等于 $(\E[R_m]-r_f)/\Var(R_m)$）。该向量方程的第 $i$ 行是 $\E[R_i] - r_f = \kappa\, \Cov(R_i, R_m)$。除以市场自身的同一方程 $\E[R_m]-r_f = \kappa\,\Var(R_m)$，即得证券市场线。残差方差不出现：它在构造 $T$ 时已被分散，并且不被定价。
:::

证券市场线（SML）是关于*预期*收益率的陈述。*已实现*收益率对贝塔的散点是该线周围的散点，单期的散点可以看起来像任何东西。对CAPM的检验，是检验*平均*残差是否为零，以及平均收益率对贝塔的斜率是否等于平均市场超额收益率。

::: example 一个贝塔、一个残差与SML {#ex-beta}
设 $r_f = 0.03$，$\E[R_m] = 0.10$，$\sigma_m = 0.16$，因此 $\Var(R_m) = 0.0256$。资产 $i$ 有 $\sigma_i = 0.40$，$\Cov(R_i, R_m) = 0.032$。计算 $\beta_{im}$、CAPM预期收益率、系统性标准差 $\lvert\beta_{im}\rvert\sigma_m$，以及残差标准差。
::: solution
$\beta_{im} = 0.032/0.0256 = 1.25$。SML给出 $\E[R_i] = 0.03 + 1.25\times 0.07 = 0.1175$。系统性标准差是 $1.25\times 0.16 = 0.20$。残差标准差是 $\sqrt{0.40^2 - 0.20^2} = \sqrt{0.12} \approx 0.3464$。该资产波动率的大部分是残差。在CAPM下，该残差得不到补偿。数字是虚构的；$0.1175$ 不是任何具名股票的预测。
:::
:::

::: example 作为SML残差的阿尔法 {#ex-alpha}
同一资产在一个虚构样本中被观察到平均收益率为 $0.14$。把**阿尔法**定义为 $\alpha_i = \E[R_i] - r_f - \beta_{im}(\E[R_m]-r_f)$，并用 [[#ex-beta]] 的CAPM输入代替总体均值来计算它。非零阿尔法在模型内部意味着什么，作为样本统计量又意味着什么？
::: solution
$\alpha_i = 0.14 - 0.03 - 1.25\times 0.07 = 0.0225$。在模型内部，非零*总体*阿尔法是对 [[#thm-sml]] 的矛盾：该资产并不按其贝塔被定价。作为*样本*统计量，$0.0225$ 是该资产在该样本中赚到的平均收益率，超过在同一份样本的 $r_f$、$\beta$ 与市场溢价上拟合的SML。抽样变异、糟糕的市场代理、变化的贝塔，以及（相对该模型的）真正错误定价，都会产生非零样本阿尔法。把它们区分开是下面的检验问题，不是该资产应当被买入的信号。
:::
:::

## 零贝塔CAPM与指数模型

所列假设中特别脆弱的两个是：可无限借入的无风险资产，以及把 $m$ 等同于股票指数。

布莱克（Black，1972，《商业杂志》）去掉无风险资产。均值–方差主体于是持有两个前沿组合的搭配，市场出清仍然迫使市场在风险资产中均值–方差有效。SML变成

$$
\E[R_i] = \E[R_z] + \beta_{im}\bigl(\E[R_m] - \E[R_z]\bigr),
$$

其中 $z$ 是 $\beta_{zm} = 0$ 的前沿组合（**零贝塔**组合）。截距不再是 $r_f$；它是没有市场协方差的组合的预期收益率。经验上，允许自由截距的检验往往发现它高于国库券利率，这是对布莱克模型的一种解读，也是对借入约束的一种解读。

**单指数模型**是统计表亲，不是均衡：

$$
R_{it} - r_{f,t} = \alpha_i + \beta_i (R_{mt} - r_{f,t}) + \varepsilon_{it}, \qquad \E[\varepsilon_{it}\mid R_{mt}] = 0.
$$

若CAPM在总体中成立，则对每一个 $i$ 有 $\alpha_i = 0$。无论CAPM是否成立，指数模型都可以被估计；那时它是方差分解，不是定价模型。教科书版本中假设残差跨 $i$ 不相关，这对估计 $\Sigma$ 方便，并且为假（行业、因子）。[[asset-pricing/factor-models]] 把那些额外的共同残差作为具名因子放回去。

::: example 两种资产，一个贝塔 {#ex-same-beta}
资产 $U$ 有 $\beta = 1.25$，残差标准差 $0.10$。资产 $V$ 有 $\beta = 1.25$，残差标准差 $0.40$。使用 [[#ex-beta]] 的SML输入，计算两者的预期收益率。对市场持有者哪一种更有风险，对只持有该资产的持有者哪一种更有风险？
::: solution
两个预期收益率都是 $0.1175$，由 [[#prop-idio]]。对市场持有者，$V$ 的额外残差被分散，在CAPM意义上不是额外风险。对只持有该资产的持有者，$V$ 风险大得多：总标准差是 $\sqrt{0.20^2 + 0.40^2} \approx 0.447$，而 $U$ 是 $\sqrt{0.20^2 + 0.10^2} \approx 0.224$。这一区别就是“系统性对特质”的全部。它是模型的性质，不是持有市场的建议，也不是声称 $V$ 的残差实际上与其他一切都不相关。
:::
:::

::: example 六次观测的时间序列回归 {#ex-ols}
一项资产与一个市场代理在六个时期上的虚构超额收益率是

$$
\begin{align*}
R_m^e &= (0.02,\; -0.01,\; 0.03,\; 0.01,\; -0.02,\; 0.04),\\
R_i^e &= (0.039,\; -0.012,\; 0.041,\; 0.009,\; -0.013,\; 0.050).
\end{align*}
$$

用OLS估计 $\alpha$ 与 $\beta$，并计算 $R^2$。
::: solution
设计矩阵有一列壹和一列 $R_m^e$。OLS给出 $(\hat\alpha, \hat\beta) \approx (0.00530,\; 1.1739)$，$R^2 \approx 0.941$。残差很小，因为序列被建为 $0.005 + 1.2 R_m^e$ 加上一点噪声；估计量在抽样误差内恢复了那个斜率。六次观测不是对CAPM的检验。它们提醒 $\beta$ 是回归系数，带着标准误被估计，并且六点上的 $\hat\alpha = 0.0053$ 不是对 $\alpha = 0$ 的拒绝。
:::
:::

## 检验CAPM

一项检验需要市场代理、样本、资产清单，以及处理贝塔被估计而不是已知这一事实的方法。两种经典设计主导早期文献。

**时间序列检验。** 布莱克、詹森与斯科尔斯（Black, Jensen and Scholes，1972）按估计贝塔把美国股票分组成组合，在每一组合上运行指数模型回归，并问 $\hat\alpha$ 是否为零，以及 $\hat\alpha$ 加上 $\hat\beta$ 乘以样本市场溢价是否匹配样本平均收益率。他们发现SML太平坦：低贝塔组合平均赚得比CAPM预测的更多，高贝塔组合赚得更少。截距更接近布莱克的零贝塔利率，而不是国库券利率。

**横截面检验。** 法马与麦克贝思（Fama and MacBeth，1973，《政治经济学杂志》）在滚动窗口中估计贝塔，然后每月把该月收益率横截面对贝塔回归，并研究横截面截距与斜率的时间序列。在CAPM下，平均截距等于平均 $r_f$（或平均零贝塔利率），平均斜率等于平均市场超额收益率。他们发现1935–1968年美国数据中贝塔上有正斜率、正截距，以及残差方差几乎没有额外解释力——这正是CAPM关于残差方差所说的，也是对该模型最有利的那部分证据。

**1963年以后平坦的SML。** 法马与弗伦奇（Fama and French，1992，《金融学杂志》）在1963–1990年的美国股票上发现，当贝塔被允许独立于规模而变化时，贝塔与平均收益率之间的关系是平坦的，即使贝塔是唯一回归元。规模与账面市值比吸收了贝塔、杠杆和盈利收益率曾被记功的横截面变异。那篇论文是通向 [[asset-pricing/factor-models]] 的桥梁。它是关于那个样本和那种设计的陈述，不是贝塔从未重要过的定理。

**罗尔批判。** 罗尔（Roll，1977，《金融经济学杂志》）观察到，CAPM的可检验内容是*市场*组合的均值–方差有效。任何真子集——股票指数、股票与债券混合、仅美国的账本——都是代理。若代理有效，SML在样本中看起来会是线性的，无论真实市场是否有效；若代理无效率，SML看起来会是错的，无论真实市场是否有效。在CRSP价值加权股票指数上对CAPM的检验，是对该指数有效性的检验，外加估计该检验所需的辅助假设。没有声称代理接近市场，它们就不是对 [[#thm-sml]] 的检验。

**联合假说问题。** 法马（Fama，1970）已经指出，对定价模型的任何检验都是对模型与市场有效性的联合检验，因为预期收益率观察不到。拒绝可以意味着CAPM为假，或市场在样本中无效率，或代理、贝塔估计、或矩为常数的假设为假。同一联合问题在 [[asset-pricing/market-efficiency]] 中再次出现：对有效性的拒绝是对有效性*加上*预期收益率模型的拒绝。两支文献都没有绕过联合检验的统计手法；两者都有义务把这一点说出来。

那么，就证据而言，CAPM的地位是什么？在使用股票指数代理的美国1963年后样本上，证券市场线太平坦，并且在控制贝塔之后规模与价值价差仍然存在。在更早的美国样本上，贝塔上的斜率更可见。国际证据是混合的，并且对代理敏感（本地指数对世界指数）。该模型仍然是其他模型被拿来比较的基准，因为它有一个因子、清晰的理论推导，以及 $\alpha_i = 0$ 这一定义良好的原假设。被拒绝的基准仍然可以是正确的起点。就这些证据而言，它不是对平均收益率横截面的充分描述。

::: warning 把股票指数当作市场来用
[[#thm-sml]] 的市场包括债券、私募股权、未上市土地、人力资本。斯坦博（Stambaugh，1982）与贾格纳坦和王（Jagannathan and Wang，1996）用更广的代理和劳动收入因子做实验；对CAPM的裁决会移动，这就是用数字表达的罗尔的要点。报告相对标普500、或相对CRSP价值加权指数的贝塔，是定义良好的统计操作。把那个贝塔叫做“那个”CAPM贝塔，是关于代理的主张。本课程把名称分开。
:::

::: quiz
在CAPM下，下列哪一项被定价？
- [ ] 每一种资产的总波动率 $\sigma_i$
- [ ] 残差标准差 $\sigma(\varepsilon_i)$
- [x] 该资产与市场组合的协方差，等价地 $\beta_{im}$
- [ ] 该资产过去十二个月的样本阿尔法
::: solution
[[#thm-sml]] 给 $\beta_{im}$ 定价，其他什么也不给。总波动率包括残差方差，分散化把它从市场组合中去掉。样本阿尔法是统计量，不是风险的总体价格。
:::
:::

## 由此通向何处

[[asset-pricing/factor-models]] 保持线性定价并放弃一个市场代理就够了的主张：由CAPM错过的横截面所激发的额外因子进入时间序列回归，截距再次被要求消失。[[asset-pricing/market-efficiency]] 问一个不同的问题——价格是否纳入信息——没有某种预期收益率模型就无法回答，而CAPM是历史上的默认。[[asset-pricing/stochastic-discount-factor]] 将把 [[#thm-sml]] 改写为 $\E[m R_i] = 1$，其中 $m$ 对 $R_m$ 线性，而这正是本课程中每一个后来模型被陈述的形式。

::: history
威廉·夏普（William Sharpe）的《资本资产价格：风险条件下的市场均衡理论》发表于1964年9月的《金融学杂志》。约翰·林特纳（John Lintner）的《风险资产的估值与股票组合及资本预算中风险性投资的选择》（《经济学与统计学评论》，1965）与扬·莫辛（Jan Mossin）的《资本资产市场中的均衡》（《计量经济学杂志》，1966）给出独立推导。费希尔·布莱克（Fischer Black）的《受限制借入下的资本市场均衡》（《商业杂志》，1972）用零贝塔前沿组合替换无风险资产。早期检验是布莱克、詹森与斯科尔斯（1972）以及法马与麦克贝思（1973）。罗尔1977年的批判、法马与弗伦奇（1992），以及法马（1970）中的联合假说讨论，是不把拒绝或未拒绝当作论证终点的标准理由。夏普与马科维茨、米勒分享了1990年诺贝尔经济学纪念奖。
:::

::: summary
- 贝塔是 $\Cov(R_i,R_m)/\Var(R_m)$，是回归斜率，不是波动率。残差方差是 $\Var(R_i)$ 的其余部分。
- 在两基金分离与市场出清下，切点组合就是市场，并且 $\E[R_i] = r_f + \beta_{im}(\E[R_m]-r_f)$。那就是CAPM。残差方差不被定价。
- 在虚构例子中，$\beta = 1.25$ 与市场溢价 $0.07$ 给出SML预期收益率 $0.1175$。样本平均 $0.14$ 是样本阿尔法 $0.0225$，它本身不是拒绝。
- 布莱克的零贝塔CAPM去掉无风险资产；截距变成零贝塔前沿组合的 $\E[R_z]$。
- 布莱克、詹森与斯科尔斯（1972）发现太平坦的SML。法马与麦克贝思（1973）发现贝塔上有正斜率，残差方差几乎不起作用。法马与弗伦奇（1992）在1963–1990年美国数据上发现，一旦控制规模，贝塔–收益率关系是平坦的。
- 罗尔（1977）：在股票指数代理上的检验是对该代理有效性的检验。每一项检验都是对模型与用以实施它的辅助条件的联合检验。
:::

## 习题

::: exercise 读一个贝塔 {level=1 check="1.25"}
使用 $\Cov(R_i,R_m) = 0.032$ 与 $\Var(R_m) = 0.0256$，输入 $\beta_{im}$。
::: solution
$0.032/0.0256 = 1.25$。系统性标准差于是是 $1.25\times 0.16 = 0.20$，那不是被问的问题。
:::
:::

::: exercise SML预期收益率 {level=1 check="0.1175"}
在 $r_f = 0.03$、$\E[R_m] = 0.10$ 与 $\beta = 1.25$ 下，以小数输入CAPM预期收益率。
::: solution
$0.03 + 1.25\times 0.07 = 0.1175$。这是 [[#ex-beta]]。同一资产上样本平均 $0.14$ 不是CAPM预期收益率。
:::
:::

::: exercise 残差波动率 {level=1 check="0.346"}
在 $\sigma_i = 0.40$ 与系统性标准差 $0.20$ 下，输入残差标准差，到三位小数。
::: solution
$\sqrt{0.16-0.04} = \sqrt{0.12} \approx 0.346410$，四舍五入为 $0.346$。在CAPM下这个数字不进入预期收益率。
:::
:::

::: exercise 样本阿尔法 {level=2 check="0.0225"}
以小数输入 [[#ex-alpha]] 的样本阿尔法。
::: solution
$0.14 - 0.03 - 1.25\times 0.07 = 0.0225$。总体阿尔法是对CAPM的违反；这个数字是虚构数字上的样本统计量。
:::
:::

::: exercise 指数模型OLS斜率 {level=2 check="1.174"}
从 [[#ex-ols]]，输入OLS贝塔，到三位小数。
::: solution
六对虚构点上的OLS斜率是 $1.1739$，四舍五入为 $1.174$。截距约为 $0.0053$，$R^2$ 约为 $0.941$。六个点并不检验 [[#thm-sml]]。
:::
:::

::: exercise 零贝塔截距 {level=2}
一个零贝塔组合的预期收益率是 $0.05$，市场的预期收益率是 $0.11$，$\beta_{im} = 0.8$。计算 $i$ 上的布莱克CAPM预期收益率。你如何把这一预测与同一贝塔上 $r_f = 0.03$ 的夏普–林特纳SML区分开？
::: solution
布莱克：$\E[R_i] = 0.05 + 0.8\times(0.11-0.05) = 0.05 + 0.048 = 0.098$。夏普–林特纳：$0.03 + 0.8\times(0.11-0.03) = 0.03 + 0.064 = 0.094$。两个预测在这一贝塔上相差 $0.004$，并且缺口随贝塔下降而*变宽*：在 $\beta = 0$ 处布莱克说 $0.05$，夏普–林特纳说 $0.03$。因此，截距高、过于平坦的拟合SML，比与夏普–林特纳相比，更容易与布莱克调和，这是对布莱克、詹森与斯科尔斯（1972）的一种解读。算术并不决定哪个模型为真；它说明它们的截距如何不同。
:::
:::

::: exercise 一段话中的罗尔 {level=3}
陈述罗尔批判。然后解释，为什么发现CRSP价值加权股票指数无效率，本身并不是对 [[#thm-sml]] 的拒绝，以及为什么发现它有效也不是确认。
::: hint
CAPM的可检验主张是全部投资财富之市场组合的有效性。股票指数是子集。
:::
::: solution
罗尔（1977）指出，CAPM等价于全部投资财富之市场组合的均值–方差有效。用代理替换该组合的检验，是对*代理*有效性的检验。若CRSP价值加权股票指数无效率，CAPM仍可能成立，因为真实市场包括债券、私人资本、外国资产与人力资本，即使它的一片无效率，整体仍可能有效。若CRSP指数*是*有效的，相对该指数的SML看起来会是线性的，无论真实市场是否有效：子集的有效并不蕴含整体的有效，但它确实蕴含*相对该子集*的SML。因此，两种发现都与 [[#thm-sml]] 的真和假相容。该发现*确实*决定的是，那个特定代理能否在检验中充当 $m$。诚实的报告是“这个代理在这个样本中（不）有效”，而不是“CAPM为（假）真”。
:::
:::

::: exercise 从切点一阶条件导出SML {level=3}
从 $\boldsymbol\mu - r_f\mathbf{1} = \kappa\, \Sigma\mathbf{w}_m$ 出发，其中 $\kappa = (\E[R_m]-r_f)/\Var(R_m)$，对单个资产 $i$ 导出 [[#thm-sml]]。指出何处使用了市场出清，何处使用了两基金分离。
::: hint
写出向量方程的第 $i$ 行，然后除以市场自己的方程。
:::
::: solution
第 $i$ 行说 $\E[R_i] - r_f = \kappa\, \Cov(R_i, R_m)$，因为 $(\Sigma\mathbf{w}_m)_i = \Cov(R_i, R_m)$。对市场，$\E[R_m]-r_f = \kappa\,\Var(R_m)$。把两个所示方程相除（或代入 $\kappa$）得到 $\E[R_i]-r_f = \beta_{im}(\E[R_m]-r_f)$。两基金分离被用来把每一位主体持有的风险束识别为单一组合 $T$。市场出清被用来令 $T$ 等于价值加权市场：无风险资产处于零净供给时，能够被加总持有的唯一风险束就是市场本身。没有出清，$T$ 只是“主体碰巧想要的东西”；没有两基金分离，主体并不共享共同的风险束，也就没有单一的 $T$ 可以与 $m$ 等同。
:::
:::
