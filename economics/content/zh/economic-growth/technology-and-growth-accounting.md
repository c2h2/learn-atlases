上一章的索洛模型产生一个富裕的稳态然后停住。前沿人均GDP并没有停住：一个半世纪以来它大约每年增长百分之二（[[economic-growth/growth-facts]]）。某种不是人均资本的东西必须在移动生产函数。本章把那东西命名为**劳动增进型技术变化**，把它放进索洛模型，然后问一个度量问题：我们观察到的增长中，多少是额外资本，多少是额外劳动，多少是残差？

残差就是**全要素生产率**（TFP）。它是一个核算对象，不是实验室的照片。索洛（Solow，1957，《经济学与统计学评论》）发现，它解释了1909至1949年美国每小时产出上升的大部分。应用到横截面的发展核算，在富国与穷国的差距中发现了同样大的残差（Hall and Jones 1999；Caselli 2005）。两项发现都是从这里起技术——以及藏在残差里的其他东西——坐在课程中心的原因。

## 劳动增进型技术

令$A(t)$为附着于劳动的生产率指数，常称为劳动的**有效性**。产出为

$$
Y = F\bigl(K, A L\bigr),
$$ {#eq-yn}

$F$仍然规模报酬不变、严格凹、满足稻田条件。乘积$AL$是**有效劳动**。技术变化以这种方式进入时是**劳动增进型**（或哈罗德中性）的。

::: definition 劳动增进型技术变化 {#def-labour-aug}
**劳动增进型**（哈罗德中性）技术变化是一条使$Y = F(K, AL)$的路径$A(t)$。若$Y = A F(K,L)$则是**希克斯中性**的，若$Y = F(AK, L)$则是**资本增进型**（索洛中性）的。在柯布–道格拉斯下，三者直到对$A$的重新标记都不可区分，因为$K^\alpha (AL)^{1-\alpha} = A^{1-\alpha} K^\alpha L^{1-\alpha}$。在不同的替代弹性下它们可区分，并且一般只有劳动增进型变化与平衡增长相容（Uzawa 1961）。
:::

宇泽定理是教科书把$A$放在$L$旁边的原因。若要素份额要保持不变、同时$K/Y$不变且两种要素都在增长，技术变化必须看起来是劳动增进型的。那是对技术变化**表示**的限制，不是关于创新实际上如何发生的断言。创意的微观经济学是[[economic-growth/endogenous-growth]]。

假定$\dot A / A = g \ge 0$为常数，故$A(t) = A_0 e^{gt}$。人口仍以$n$增长。定义每**有效**工人资本

$$
\tilde k \equiv \frac{K}{AL}, \qquad \tilde y \equiv \frac{Y}{AL} = f(\tilde k).
$$

::: proposition 带劳动增进型技术的索洛模型 {#prop-solow-g}
在$Y=F(K,AL)$且$\dot A/A = g$、$\dot L/L = n$下，

$$
\dot{\tilde k} = s f(\tilde k) - (n+g+\delta)\tilde k.
$$ {#eq-ktilde}

存在唯一的正稳态$\tilde k^*$，满足$s f(\tilde k^*) = (n+g+\delta)\tilde k^*$。沿着$\tilde k$不变的路径，人均产出$y = Y/L = A f(\tilde k)$以速率$g$增长，而$K$、$Y$与$C$以速率$n+g$增长。
:::

::: proof
$\tilde k = K/(AL)$给出$\dot{\tilde k}/\tilde k = \dot K/K - g - n$。代入$\dot K = sY - \delta K = s F(K,AL) - \delta K$与$Y/(AL)=f(\tilde k)$得到[[#eq-ktilde]]。其余就是[[economic-growth/solow-model]]：把$n$换成$n+g$，把$k$换成$\tilde k$。在$\tilde k^*$处，$Y = AL\, f(\tilde k^*)$以$n+g$增长，故$Y/L$以$g$增长。$K = \tilde k^* AL$以$n+g$增长，因此$K/Y$不变。
:::

这就是**平衡增长**：$K$、$Y$、$C$以同一速率增长，$K/Y$不变，并且——在柯布–道格拉斯下——要素份额不变。卡尔多事实(1)–(5)在平衡路径上成立，劳动生产率以$g$而不是以零增长。

索洛图在$(\tilde k, s f(\tilde k))$空间中不变。保本射线现在是$(n+g+\delta)\tilde k$：投资还必须装备因$A$增长而增长的有效劳动。$g$的上升**降低**$\tilde k^*$，正如$n$的上升所做的，同时**提高**$y$的增长率。水平与增长率再次分道。

::: widget plot
f: s*x^(1/3); (n+g+d)*x
sliders: s=0.2:0.05:0.5:0.01; g=0.02:0:0.05:0.005; n=0.01:0:0.03:0.005; d=0.05:0.02:0.08:0.01
x: 0, 12
y: 0, 2
labels: \text{sf}(\tilde k); \text{(n+g+δ)}\tilde k
caption: 有效劳动单位下的索洛图，$f(\tilde k)=\tilde k^{1/3}$。提高$g$：射线变陡，$\tilde k^*$下降，但**每个工人**的产出$y=A f(\tilde k)$开始更快增长。$y$的长期增长率是$g$，与$s$无关。那是本章主要的比较静态结果。
:::

::: example 平衡增长数字 {#ex-balanced}
保持$\alpha=1/3$、$s=0.2$、$n=0.01$、$\delta=0.05$，并加入$g=0.02$。计算$\tilde k^*$、$\tilde y^*$，$Y$、$K$、$y$与$k$的增长率，以及资本–产出比$K/Y$。
::: solution
$n+g+\delta=0.08$，故

$$
\tilde k^* = \bigl(0.2/0.08\bigr)^{3/2} = 2.5^{1.5} = 3.953, \qquad \tilde y^* = (3.953)^{1/3} = 1.581.
$$

在平衡路径上$Y$与$K$以$n+g=0.03$增长；$y=Y/L$与$k=K/L$以$g=0.02$增长。资本–产出比为$K/Y = \tilde k^*/\tilde y^* = 3.953/1.581 = 2.50$，为常数，且等于$s/(n+g+\delta)=0.2/0.08=2.5$。人均消费也以$g$增长。把$\tilde k^*=3.95$与上一章无技术例子中的$k^*=6.09$比较：额外的保本项$g\tilde k$使经济在**每有效工人**意义上资本更少，即使工人本身在稳步变得更有生产性。
:::
:::

::: warning 转型期间$A$的增长不是$Y/L$的增长
在平衡路径上，$g_y = g$。偏离它时，$y = A f(\tilde k)$有两个增长来源：$g$本身，以及$\tilde k$正在发生的任何事情。正在把$\tilde k$积累向$\tilde k^*$的国家增长**快于**$g$；正在把$\tilde k$消耗掉的国家增长更慢。观察到十年里人均GDP每年增长6%，并不是观察到$g=0.06$。1978年后的中国是通常的说明：那每年5.7%（麦迪森2023，1978–2019）的一部分是转型，一部分是$g$，而增长核算是人们借以形成看法的办法。
:::

## 增长核算

取$Y = F(K, AL)$，或更常见于度量的$Y = A F(K,L)$，其中希克斯中性的$A$代表TFP。对柯布–道格拉斯$Y = K^\alpha (AL)^{1-\alpha}$，两个$A$相差一个幂次。对数微分——[[mathematical-economics/derivatives-and-elasticities]]中“取对数再微分”的连续时间版本——给出**增长核算恒等式**。

::: proposition 增长核算恒等式 {#prop-accounting}
若$Y = F(K,L,t)$可微且要素按其边际产量得到支付，资本份额为$\alpha_t \equiv F_K K/Y$，则

$$
\frac{\dot Y}{Y} = \alpha_t \frac{\dot K}{K} + (1-\alpha_t)\frac{\dot L}{L} + \frac{\dot Z}{Z},
$$ {#eq-account}

其中$\dot Z/Z$是**索洛残差**（TFP增长），被定义为剩余。对具有常数$\alpha$的柯布–道格拉斯，这就是希克斯中性标记下的$g_Y = \alpha g_K + (1-\alpha)g_L + g_A$，或劳动增进型标记下的$g_Y = \alpha g_K + (1-\alpha)(g_A+g_L)$。人均产出服从

$$
g_y = \alpha g_k + \text{TFP贡献}.
$$
:::

::: proof
$Y=F(K,L,t)$给出$\dot Y = F_K \dot K + F_L \dot L + F_t$。除以$Y$：$\dot Y/Y = (F_K K/Y)(\dot K/K) + (F_L L/Y)(\dot L/L) + F_t/Y$。竞争性支付要素以及欧拉定理（$K,L$上的规模报酬不变）使前两个系数为$\alpha_t$与$1-\alpha_t$。最后一项是残差。柯布–道格拉斯是$F_t/Y = \dot A/A$（希克斯）或$(1-\alpha)\dot A/A$（哈罗德）的特例。把$Y$除以$L$并重复，得到人均形式，使用$g_y = g_Y - g_L$与$g_k = g_K - g_L$。
:::

该恒等式不是关于TFP的理论。它是把$g_Y$划分成我们已经度量的项（$K$、$L$、份额）与我们尚未度量的项。任何在不提高$K$或$L$的情况下提高$Y$的东西——更好的配方、同样$K$与$L$在企业间更好的配置、未度量的劳动质量、利用率——都落进残差。

::: example 一个十年分解 {#ex-ten-year}
一个示意经济有$Y_0 = 100$，$Y_{10} = 134.39$（每年3%），$K_0 = 300$，$K_{10} = 444.07$（每年4%），$L_0 = 50$，$L_{10} = 55.23$（每年1%），以及常数资本份额$\alpha = 1/3$。按希克斯中性柯布–道格拉斯意义计算TFP增长，以及产出增长中由TFP、资本与劳动解释的份额。
::: solution
年速率：$g_Y = 0.03$，$g_K = 0.04$，$g_L = 0.01$。则

$$
g_A = g_Y - \alpha g_K - (1-\alpha)g_L = 0.03 - \tfrac13(0.04) - \tfrac23(0.01) = 0.03 - 0.01333 - 0.00667 = 0.01.
$$

在产出增长的3.0个百分点中，资本贡献$1.33$，劳动$0.67$，TFP $1.00$。TFP是$g_Y$的三分之一，是$g_y = 0.02$的一半（人均计算是$g_y = \alpha g_k + g_A = (1/3)(0.03)+0.01 = 0.02$）。水平核对：$A_t = Y_t / (K_t^\alpha L_t^{1-\alpha})$给出$A_0 = 100/(300^{1/3}50^{2/3}) = 100/76.37 = 1.309$与$A_{10} = 134.39/(444.07^{1/3}55.23^{2/3}) = 134.39/92.89 = 1.447$，且$(1.447/1.309)^{1/10}-1 = 0.010$，相符。
:::
:::

索洛（1957）把[[#eq-account]]的离散版本应用到美国私人非农GDP，1909–1949，并把每小时产出增长的约$87.5\%$归于残差。后来用更好的资本服务数据所做的工作（Jorgenson and Griliches 1967，以及随后的美国劳工统计局与EU KLEMS项目）通过度量劳动与资本中的构成变化——教育、经验、从建筑物向设备的转移——缩小了残差。它并没有消除残差。旧金山联储的Fernald等人，以及世界大型企业联合会的总经济数据库，仍然发现TFP是美国与前沿长期增长中的主导项，并有2004–2005年后有据可查的放缓。

PWT 10.01报告TFP水平（`ctfp`，相对美国）以及按不变本国价格计的TFP（`rtfpna`）。对2019年，中国的`rtfpna`（2017=1）为0.96，美国序列在不同的本国价格指数上；**水平**比较使用`ctfp`。水平比较是下一节。

::: example 柯布–道格拉斯上的哈罗德对希克斯 {#ex-harrod-hicks}
设$Y = K^{1/3}(AL)^{2/3}$沿平衡路径以$g_Y=0.03$、$g_K=0.03$、$g_L=0.01$增长。劳动增进型标记下的$g_A$是多少？$Y=Z K^{1/3}L^{2/3}$中怎样的希克斯中性TFP增长$g_Z$匹配同一路径？
::: solution
劳动增进型：$g_Y = (1/3)g_K + (2/3)(g_A+g_L)$，故$0.03 = (1/3)(0.03) + (2/3)g_A + (2/3)(0.01)$，从而$0.03 = 0.01 + (2/3)g_A + 0.00667$，故$(2/3)g_A = 0.01333$且$g_A=0.02$。那就是索洛平衡路径的$g$：$Y/L$以$g_A=0.02$增长。希克斯中性：$g_Y = g_Z + (1/3)g_K + (2/3)g_L$给出$g_Z = 0.03 - 0.01 - 0.00667 = 0.0133$。两个残差由$g_Z = (1-\alpha)g_A = (2/3)\times 0.02$相连。报告“TFP增长1.3%”或“技术增长2%”可以描述同一路径；必须点明标记。
:::
:::

::: quiz
在柯布–道格拉斯且$\alpha=0.4$的增长核算恒等式中，产出增长4%，资本增长5%，劳动增长1%。TFP增长是
- [ ] 4%
- [x] 1.4%
- [ ] 0%，因为要素解释了一切
- [ ] 5%
::: solution
$g_A = 0.04 - 0.4\times 0.05 - 0.6\times 0.01 = 0.04 - 0.02 - 0.006 = 0.014$，即1.4%。除非残差碰巧为零，要素并不耗尽观察到的增长；这里它超过$g_Y$的三分之一。
:::
:::

## 水平核算

增长核算分解的是**变化**。**发展核算**（水平核算）分解的是**比值**。在柯布–道格拉斯情形写下

$$
\frac{y_i}{y_{\mathrm{US}}} = \Bigl(\frac{k_i}{k_{\mathrm{US}}}\Bigr)^\alpha \Bigl(\frac{h_i}{h_{\mathrm{US}}}\Bigr)^{1-\alpha} \frac{A_i}{A_{\mathrm{US}}}
$$ {#eq-levels}

其中$h$是人均人力资本。取对数，$\ln y$的缺口是$\ln k$的加权缺口、$\ln h$的加权缺口，以及$\ln A$的残差缺口。

Hall and Jones（1999，《经济学季刊》）发现，$A$解释了例如美国与尼日尔之间差距的大部分；一旦允许$A$本身影响$k$，资本–产出比的差异并不够大。Caselli（2005，《经济增长手册》）是标准综述：在$\alpha=1/3$以及观察到的$K$与受教育年限下，麦迪森最富与最穷之间90倍差距的很大多数在残差里。把$\alpha$提高到$2/3$（“广义资本”）会缩小残差但消除不了它，并且与度量到的资本份额相处不安。

对大的$A$缺口有两种相互竞争的解释，本课程不挑选赢家。

- **技术。** 穷国不使用前沿配方。Parente and Prescott（《通向富裕的障碍》，2000）强调采用现有技术的壁垒；Comin and Hobijn记录了特定技术扩散的长滞后。
- **错配。** 同样的配方，应用到$K$与$L$在企业间被扭曲的配置上，看起来像低的$A$。Hsieh and Klenow（2009，《经济学季刊》）估计，若使制造业工厂的边际产量相等，中国与印度会有很大的TFP增益；该练习是对**潜力**的度量，不是政策预测。

第三种解释是度量：穷国的GDP更难估值，非正式活动被遗漏，PPP篮子并不完美。那是一个真实问题（Deaton and Heston 2010）。在任何已发表的敏感性核对上，它都不够大，不能把90倍差距变成3倍差距。

::: example 一次微型发展核算 {#ex-levels}
两个示意国家有$y_R = 16$，$y_P = 2$，$k_R = 64$，$k_P = 8$，且$\alpha = 1/3$；人力资本相同。$y$的对数缺口中多大比例由资本解释，多大比例由$A$解释？
::: solution
$y_R/y_P = 8$且$k_R/k_P = 8$，故

$$
\frac{A_R}{A_P} = \frac{y_R/y_P}{(k_R/k_P)^\alpha} = \frac{8}{8^{1/3}} = \frac{8}{2} = 4.
$$

$\ln(y_R/y_P) = \ln 8 = 2.079$；资本的贡献是$\alpha \ln(k_R/k_P) = (1/3)\ln 8 = 0.693$（对数缺口的三分之一）；$A$贡献$\ln 4 = 1.386$（三分之二）。即使$k$上有八倍差距、与$y$的差距相匹配，对数缺口的大部分仍留在残差里，因为$k$被升到$\alpha=1/3$次幂。这就是Hall and Jones背后的算术：若没有$A$，资本差异必须**巨大**才能解释收入差异。
:::
:::

## 时间序列中的残差

三项经验规律性约束人们如何谈论TFP。

**顺周期性。** 度量到的TFP在衰退中下降。那可以是真实技术（被摧毁的批次、推迟的研发），也可以是未度量的利用率与劳动窖藏。Basu, Fernald and Kimball（2006，《美国经济评论》）从TFP中净化利用率，并发现一个不那么顺周期、有时逆周期的对象——这是一项警告：索洛残差不是季度技术冲击。TFP在经济周期中的使用属于[[business-cycles/real-business-cycles]]。

**2000年代中期的放缓。** 美国TFP增长在2004–2005年左右下台阶，早于2008年危机（Fernald 2014，旧金山联储工作论文）。类似放缓出现在其他前沿经济体。候选解释——1990年代信息技术浪潮的消退、数字产品的错误度量、研究生产率放缓（Bloom, Jones, Van Reenen and Webb 2020，《美国经济评论》）——尚未有定论。增长课程记录这次放缓，并不假装给它的结束定时。

**要素份额漂移。** 若劳动份额下降，如Karabarbounis and Neiman（2014）对1980年代以来许多国家所记录的，柯布–道格拉斯就被设错了。带时变份额的增长核算（Törnqvist指数）是稳健的回应：[[#eq-account]]从不需要常数$\alpha$。下降**意味着**什么——更便宜的投资品、全球化、市场势力、住房——是一场仍在进行的争论，不是本章已解决的输入。

::: intuition TFP是对我们无知的度量，带着量级
Abramovitz（1956）称残差为“对我们无知的度量”。那是正确的态度，也是错误的打发。解释增长一半、或对数收入缺口三分之二的无知，是**主要**对象，不是舍入误差。接下来各章给无知起名字：创意、制度、错配、我们未能计数的人力资本。它们并不靠愿望使残差变小。
:::

## 通向何处

[[economic-growth/convergence]]问穷国是否比富国增长更快，正如共同$A$下的索洛转型所意味的，或者$A$本身的差异是否大到足以抵消那股力量。[[economic-growth/endogenous-growth]]用关于创意的理论替换外生的$g$。[[economic-growth/institutions-and-growth]]问为什么$A$与$s$与$n$一开始就不同。

拉姆齐与戴蒙德两章保持$A$外生并把$s$内生化。那是穿过同一套核算的另一刀：它们是关于增长核算当作投入的储蓄的理论。

仅供教育学习，不构成投资或理财建议。TFP残差不是对生产率的预测，发展核算缺口也不是对投资目的地的排序。

::: history
**1957年，索洛。** 《技术变化与总量生产函数》（《经济学与统计学评论》）把残差应用到1909–1949年美国数据，发现每小时产出增长的大部分不是资本深化。John Kendrick与Moses Abramovitz当时在并行地做度量项目；Abramovitz 1956年的NBER论文已经称残差为对无知的度量。Dale Jorgenson与Zvi Griliches（1967）表明其中多少可以被推回已度量的投入。现代实施是KLEMS传统（Jorgenson、Timmer、van Ark）以及PWT 10.01中的TFP序列。
:::

::: summary
- 以$g$增长的劳动增进型$A(t)$把索洛模型变成平衡增长理论：长期$y$以$g$增长，$K/Y$不变，$s$仍是水平参数。
- 宇泽定理：一般只有劳动增进型变化与不变要素份额和不变$K/Y$相容。
- 增长核算：$g_Y = \alpha g_K + (1-\alpha)g_L + g_{\mathrm{TFP}}$。最后一项是残差，在索洛（1957）中很大，在Jorgenson式修正之后仍然很大。
- 发展核算也把富–穷**水平**缺口的大部分放进$A$，除非资本份额远高于国民核算的值。
- 度量到的TFP是顺周期的，在2000年代中期之后于前沿放缓，并且坐在劳动份额下降的争论里面。它不是“技术”的同义词。
:::

## 习题

::: exercise 平衡增长速率 {level=1}
在带劳动增进型技术的索洛模型中，$n=0.01$，$g=0.02$，$\delta=0.05$。$Y$、$Y/L$、$K/L$与$K/Y$的长期增长率是多少？
::: solution
$Y$以$n+g=0.03$增长；$Y/L$与$K/L$以$g=0.02$增长；$K/Y$不变，故其增长率为0。
:::
:::

::: exercise 稳态$\tilde k$ {level=1 check="64"}
$f(\tilde k)=\sqrt{\tilde k}$，$s=0.4$，$n=0.01$，$g=0.02$，$\delta=0.02$。$\tilde k^*$是多少？（输入整数。）
::: solution
$s\sqrt{\tilde k^*}=(n+g+\delta)\tilde k^* = 0.05\tilde k^*$，故$\sqrt{\tilde k^*}=0.4/0.05=8$且$\tilde k^*=64$。
:::
:::

::: exercise 一个残差 {level=1 check="0.01"}
产出增长3%，资本增长3%，劳动增长1.5%，$\alpha=1/3$。希克斯中性TFP增长是多少？（输入小数，例如0.02。）
::: solution
$g_A = 0.03 - (1/3)(0.03) - (2/3)(0.015) = 0.03 - 0.01 - 0.01 = 0.01$。
:::
:::

::: exercise 人均核算 {level=2}
用[[#ex-ten-year]]的数字，把人均产出2%的增长分解为资本深化与TFP。
::: solution
$g_y = 0.02$，$g_k = 0.04-0.01=0.03$，$\alpha=1/3$，故$\alpha g_k = 0.01$且$g_A=0.01$。人均增长的一半是资本深化，一半是TFP。这种50/50的划分是示意速率的产物；索洛1909–1949年的划分远更偏残差。
:::
:::

::: exercise 资本–产出比 {level=2}
在柯布–道格拉斯的平衡路径上，证明$K/Y = s/(n+g+\delta)$。在$s=0.2$、$n=0.01$、$g=0.02$、$\delta=0.05$处求值。若$s$升到$0.3$，长期$K/Y$会怎样，$Y$的**增长率**会怎样？
::: solution
$K/Y = \tilde k / f(\tilde k)$。在稳态$s f(\tilde k^*)=(n+g+\delta)\tilde k^*$，故$\tilde k^*/f(\tilde k^*)=s/(n+g+\delta)$。其值为$0.2/0.08=2.5$。若$s$升到$0.3$，$K/Y$升到$0.3/0.08=3.75$。$Y$的增长率仍为$n+g=0.03$。一个水平参数被改变了；$g$没有。
:::
:::

::: exercise 带人力资本的发展核算 {level=2}
把[[#ex-levels]]扩展为给富国两倍于穷国的人力资本，$h_R/h_P=2$，仍$\alpha=1/3$，$y_R/y_P=8$，$k_R/k_P=8$。由[[#eq-levels]]重新计算$A_R/A_P$。现在$y$的对数缺口中多大比例坐在$A$里？
::: solution
$$
\frac{A_R}{A_P} = \frac{8}{8^{1/3}\, 2^{2/3}} = \frac{8}{2 \times 1.587} = \frac{8}{3.175} = 2.52.
$$

$\ln 8 = 2.079$；$A$贡献$\ln 2.52 = 0.924$（对数缺口的44%）；资本仍为0.693（33%）；人力资本$(2/3)\ln 2 = 0.462$（22%）。加入人力资本上两倍的差距——相对Barro–Lee受教育年限已经很大——仍然留下可观的残差。
:::
:::

::: exercise 为什么宇泽定理重要 {level=3}
设$Y = K^\alpha (AL)^{1-\alpha}$（劳动增进型）对$Y = (BK)^\alpha L^{1-\alpha}$（资本增进型），$\dot A/A = g_A$与$\dot B/B = g_B$为常数。(a) 在劳动增进型情形，平衡路径上什么以恒定速率增长，$K/Y$是否不变？(b) 在资本增进型情形，若$g_B \neq 0$，$K/Y$与资本份额能否同时不变？(c) 为什么柯布–道格拉斯掩盖了这一区分？
::: hint
在平衡路径上$K$与$Y$以同一速率增长。资本份额在两种柯布–道格拉斯形式中都始终是$\alpha$。
:::
::: solution
(a) $Y$与$K$以$n+g_A$增长，$K/Y$不变，资本份额为$\alpha$。(b) 若$B$以$g_B\neq 0$增长且$L$以$n$增长，不变的$K/Y$要求$K$与$Y$以同一速率增长。但$Y = B^\alpha K^\alpha L^{1-\alpha}$于是以$\alpha g_B + \alpha g_K + (1-\alpha)n$增长。令$g_Y=g_K$给出$g_K = \alpha g_B + \alpha g_K + (1-\alpha)n$，故$(1-\alpha)g_K = \alpha g_B + (1-\alpha)n$，或$g_K = n + \frac{\alpha}{1-\alpha}g_B$。然后$g_Y=g_K$是一致的，且$K/Y$**是**不变的——**因为**柯布–道格拉斯使资本增进型变化成为对$A$的重新标记（令$A^{1-\alpha}=B^\alpha$）。对不等于一的CES弹性，资本增进型变化把资本份额赶到0或1（Uzawa；见Acemoglu 2009，第2章）。(c) 柯布–道格拉斯的替代弹性为一，因此技术变化的三种分类在观察上等价。那是一种方便，也是本课程能把$A$放在$L$旁边而不对弹性表态的原因——劳动份额下降文献不再愿意推迟的一种表态。
:::
:::

::: exercise 微型索洛（1957） {level=3}
40年里，一个示意经济中每小时产出翻一番，每小时资本上升50%。取$\alpha=1/3$。(a) 隐含的TFP（希克斯中性，按每小时）上升了多少倍？(b) 每小时产出对数增长中残差占多少份额？(c) 索洛的87.5%是针对1909–1949年美国每小时产出的。在$y$翻倍的情况下，资本深化必须怎样，才能把残差份额削到一半，仍取$\alpha=1/3$？
::: solution
(a) $y_1/y_0 = 2$，$k_1/k_0 = 1.5$，故$A_1/A_0 = 2 / 1.5^{1/3} = 2/1.145 = 1.747$。(b) $\ln 2 = 0.693$；资本深化贡献$(1/3)\ln 1.5 = 0.135$；残差$\ln 1.747 = 0.558$，即对数增长的80%——在索洛数字附近。(c) $\ln 2$的一半是$0.347 = \alpha \ln(k_1/k_0)$，故$\ln(k_1/k_0)=1.040$且$k_1/k_0 = 2.83$。每小时资本必须上升近三倍，而不是50%，才能平分功劳。1909–1949年的资本深化并没有那么大，这就是残差占主导的原因。
:::
