1960年，菲律宾的人均实际GDP约为2350国际元（2011年价格）；韩国约为1550——只有前者的三分之二。到2019年，排序已经颠倒，而且不止于此：韩国38900，菲律宾8600（麦迪森项目数据库2023）。同样六十年里，博茨瓦纳从560升到15700，而1960年比博茨瓦纳更富的加纳只从2200升到4100。年增长率上的微小差别，若能持续，就会改写国家的排序。这就是本课程的主题。

问题并不新。为什么生活水平的持续增长会发生——在此前数千年里，普通人并不比罗马帝国时期富裕多少？它为何在那个时候、那个地方开始？为什么有的国家现在每年增长百分之六，有的只有百分之一？后面各章建立模型。本章陈述这些模型需要拟合的事实，并附上出处与度量选择。

通篇以**人均实际GDP**作为平均生活水平的头条度量。它不是福利，不是中位收入，并且省略了家庭生产、环境损害以及大部分闲暇。它是现有国民核算能够跨越世纪与国家加以比较的对象，而本课程的模型就是关于它的模型。

## 度量生活水平

国民核算记录一年中最终产品与服务的价值。除以人口得到人均GDP。跨时期比较这个数字需要价格指数；跨国家比较则需要一种不是市场汇率的换算。

::: definition 人均实际GDP {#def-gdp-pc}
第$t$年的**人均实际GDP**是名义GDP除以价格指数再除以人口。**购买力平价**（PPP）换算把不同国家的GDP表示成同一套国际价格，从而使一单位国际元在各处买到可比的篮子。市场汇率则按外汇市场上的货币价格换算，并且通常低估穷国的实际收入——那里非贸易品便宜。
:::

本课程通篇出现三套数据。

- **麦迪森项目数据库2023**（Bolt and van Zanden 2024）给出2011年国际元的人均GDP，许多国家回溯到1820年，有的更早。它是长期比较的来源。1900年以前（非洲许多地方则是1950年以前）的估计建立在不完整记录与间接方法上；它们是现有最好的，但不是普查级的。
- **宾大世界表10.01**（Feenstra、Inklaar与Timmer；183个国家，1950–2019，2017年美元链式PPP）是战后水平、资本存量、劳动投入与生产率的主力。产出侧实际GDP（`rgdpo`）是生产的正确对象；支出侧实际GDP（`rgdpe`）更接近生活水平。
- **世界银行世界发展指标**与各国统计机构（美国经济分析局、英国国家统计局、中国国家统计局等）给出近几十年常用的、更新频繁的序列。它们不会在不做进一步处理的情况下拼接到麦迪森的2011年国际元上。

“人均10000美元”这个数字，在基年、PPP版本以及产出对支出的区分被点明之前，并不是一个提法清楚的断言。本课程会点明它们。

::: example 三种方式引用2019年的美国 {#ex-three-measures}
麦迪森项目数据库2023报告，2019年美国人均GDP为56469（2011年国际元）。宾大世界表10.01对同一年报告的是另一个2017年美元链式PPP数字。世界银行WDI报告的是2021年不变国际元的人均GDP，又不相同。为什么三者并不重合，增长一章应当用哪一个？
::: solution
它们回答的问题略有不同。麦迪森的2011年国际元是为**长期**可比性设计的：1990年以前用1990年PPP，2011年以后用2011年PPP，中间加以调整，并把历史基准（包括1909年美英比较）拼接到国民核算增长上。PWT 10.01使用2017年美元链式PPP和适合1950–2019的多基准方法，并区分产出侧与支出侧实际GDP。世界银行WDI使用国际比较项目（ICP）的PPP版本（这里是2021），并随新的价格调查而修订。

把1870年的美国与2019年的美国相比较，属于麦迪森。把2019年80个国家的资本–产出比相比较，属于PWT。2023年对极端贫困的更新属于世界银行。把三者混在一句话里而不点明单位，是制造一个其实只是计价单位变化的谜题的常见办法。
:::
:::

人均GDP是一个平均数。如果不平等上升，一个国家可以在国民核算中增长，而中位家庭并不增长。分配是[[development-economics/poverty-and-inequality]]的主题；这不是丢掉平均数的理由——在增长理论的生产一侧，平均数仍是正确的对象。

## 两个世纪的现代增长

有记载的历史的大部分时间里，平均生活水平几乎不动。麦迪森的世界人均GDP在1820年约为1130国际元（2011年价格）。1700年的英格兰为2412，以当时的标准已经富裕；此后120年里它以每年0.26%增长，到1820年为3306。那不是停滞，但与随后到来的是另一种机制。

::: definition 现代经济增长 {#def-modern-growth}
本课程意义上的**现代经济增长**，是人均实际GDP以每年百分之一到百分之二的量级持续上升、延续许多十年，并伴随着人均资本存量上升、工业然后服务业份额扩大，以及死亡率下降。它不同于一次性的收成恢复、资源繁荣，或马尔萨斯约束下有限技术变化所伴随的那种前工业时代的缓慢漂移。
:::

起飞是[[economic-history/industrial-revolution]]与[[economic-history/great-divergence]]的主题。增长理论使用的数字是这些。

在美国，以2009年美元计的人均实际GDP从1870年的约3000升到2014年的5万以上，增长17倍，平均每年约2.0%（Jones，《宏观经济学手册》，2016，使用美国经济分析局国民核算）。峰到峰的速率：1870–1929年为1.76%，1929–2007年为2.23%，1870–2007年合计2.03%。在麦迪森的2011年国际元中，同一国家的路径是1870年的4803到2019年的56469，增长12倍，每年1.67%——那是不同的平减指数和不同的PPP，而不是关于美国是否增长的分歧。

**前沿**——当时最富裕的大型经济体——一个半世纪以来以接近每年百分之二的速度增长。十九世纪由英国领先；二十世纪的大部分时间由美国领先。前沿增长率的这种稳定性本身就是一件有待解释的事实。它不是定律：1950–1973年的西欧与日本更快（日本1950–1990年：3062到29949，即每年5.9%，麦迪森2023），而美国与西欧的劳动生产率增长在2005年之后放缓。百分之二这个数字是对美国长序列的概括，不是预测。

在现代增长之前，[[economic-history/malthusian-world]]中的马尔萨斯机制把生活水平限制在狭窄区间：技术改进提高的是人口而不是人均收入。逃出那个区间是第一件大事。第二件是：逃出并非普遍发生。

## 世界收入分配

2019年，以麦迪森的2011年国际元计，人均GDP在挪威为85100，美国为56500，韩国为38900，中国为16900，巴西为14300，印度为7300，尼日利亚为5200，埃塞俄比亚为2000，中非共和国为624。美–中非之比约为90；挪威–埃塞俄比亚之比约为42。石油国（卡塔尔151000）因另一种原因坐在同一张表的顶端。

这些是**平均数**。它们已经使用了PPP，因此不是穷国便宜理发按市场汇率换算的伪象。它们仍然巨大。Hall and Jones（1999，《经济学季刊》）以及随后的发展核算文献追问：这类差距有多少是资本，多少是人力资本，多少是残差生产率；那种分解属于[[economic-growth/technology-and-growth-accounting]]。

分布并不是冻结的。Pritchett（1997，《经济学展望杂志》，“大分叉”）记录了从1870年到二十世纪末最富与最穷之比如何扩大，因为前沿在增长而许多穷国没有。大约1990年以来，世界收入不平等的**国家之间**部分收窄了，主要因为中国与印度的增长，尽管一些非洲国家与脆弱国家并未缩小差距（Sala-i-Martin 2006；麦迪森与世界银行数据的后续更新）。两句话可以同时为真：右尾曾一个世纪地甩开左尾，然后两个很大的国家移向了中间。

::: example 一代人里的逆转 {#ex-korea-philippines}
用麦迪森2023，计算1960至2019年韩国与菲律宾人均实际GDP的平均年增长率。韩国/菲律宾之比变化了多少倍？
::: solution
韩国：$1{,}548$到$38{,}936$，59年，故

$$
g_{\mathrm{KR}} = \Bigl(\frac{38936}{1548}\Bigr)^{1/59} - 1 = 0.0562
$$

（每年5.62%；增长25倍）。菲律宾：$2{,}353$到$8{,}602$，故

$$
g_{\mathrm{PH}} = \Bigl(\frac{8602}{2353}\Bigr)^{1/59} - 1 = 0.0222
$$

（2.22%；增长3.7倍）。韩国/菲律宾之比从$1548/2353 = 0.66$变为$38936/8602 = 4.53$，约6.9倍。四个百分点的额外增长，持续六十年，就是另一个国家。
:::
:::

战后数据中的增长**奇迹**是成簇的：日本1950–1990；韩国、中国台湾、新加坡、中国香港自1960年代起；中国自1978年起（1744到2019年的16880，每年5.7%）；博茨瓦纳1960–2019（5.8%）。增长**灾难**也成簇：1980年后拉丁美洲许多地方的失去的十年；苏联体系的崩溃；阿根廷的相对停滞（1960年的8861到2019年的17913，1.2%——一个1900年的富国没有留在前沿）；以及冲突与国家失败的时期。加纳在1960–2019年每年1.1%并不是崩溃，但它说明了一个起点远高于博茨瓦纳的国家如何以远低于后者的水平结束。

::: intuition 增长是速率，富裕是水平
一个国家可以增长很快却仍然贫穷（1980年代的中国），也可以增长很慢却仍然富裕（美国近几十年的任何一个十年）。下一章的索洛模型将分开**水平效应**（储蓄率移动平衡增长路径）与**增长效应**（只有技术移动人均产出的长期增长率）。数据已经暗示这一区分：韩国的增长率随其接近前沿而放缓，那是转型的样子，而不是永久5.6%增长率的样子。
:::

## 复利与70规则

若变量$x_t$以恒定速率$g$增长，则离散时间下$x_T = x_0 (1+g)^T$，连续时间下$x(T) = x(0)\, e^{gT}$。当$g$只有几个百分点时二者接近：$(1.02)^{35} = 2.000$而$e^{0.02\times 35} = 2.014$。

::: proposition 70规则 {#prop-rule70}
以每年$g$个百分点增长的量，大约在$70/g$年里翻一番。更精确地，离散时间下翻倍时间为$\ln 2 / \ln(1+g/100)$年，连续时间下为$(\ln 2)/(g/100)$。对介于1与10之间的$g$，三个公式相差的是月而不是年。
:::

::: proof
令$(1+g/100)^T = 2$，则$T = \ln 2 / \ln(1+g/100)$。对小的$z$，$\ln(1+z)\approx z$，且$\ln 2 \approx 0.693$，故$T \approx 69.3/g$年。惯用的70是一种四舍五入，也部分抵消了$\ln(1+z)\approx z$的近似。连续时间下，$e^{gT/100}=2$精确给出$T = 69.3/g$。
:::

在2%时，翻倍需要35年；在7%时，约10年。一个世纪里，2%产生7.2倍的增长；7%产生868倍。这就是为什么在本课程中“一个百分点的增长”不是一个小对象。

::: example 两座岛 {#ex-two-islands}
A岛人均GDP为5（某种单位），每年增长2%。B岛从1起步，每年增长7%。50年后谁更富，相差多少倍？（这些速率是示意性的；它们与一个前沿经济体和一个增长奇迹的量级相符。）
::: solution
50年后，

$$
x_A = 5\times(1.02)^{50} = 5\times 2.692 = 13.46, \qquad x_B = 1\times(1.07)^{50} = 29.46.
$$

起步时穷五倍的B岛现在富2.2倍。交叉发生在$5\times(1.02)^t = (1.07)^t$，即$t = \ln 5 / \ln(1.07/1.02) = 33.6$年。复利不是比喻。它是把增长率上5个百分点的差距变成世界分布逆转的机制。
:::
:::

::: warning 把增长率与水平相混，把百分比与百分点相混
增长率从8%降到6%，是下降了**两个百分点**，或者说增长率下降了**四分之一**。它不是GDP下降了2%。GDP本身继续上升。新闻里“增长崩溃25%”有时指后者，有时指前者。本课程中，增长率是$g_X = \dot X/X$（连续）或$X_{t+1}/X_t - 1$（离散）；水平是$X$。
:::

一个相关的算术事实被不断使用。若$z = xy$，则$g_z = g_x + g_y$（连续时间，或对数近似）。若$z = x/y$，则$g_z = g_x - g_y$。人均产出是产出除以人口，因此其增长率是产出增长减去人口增长。人均资本同理。对数导数在[[mathematical-economics/derivatives-and-elasticities]]中展开。

::: quiz
实际GDP每年增长3%，人口每年增长1%。人均实际GDP会怎样？
- [ ] 它每年增长3%。
- [x] 它大约每年增长2%。
- [ ] 它不变，因为额外产出被额外的人吸收。
- [ ] 它每年增长4%。
::: solution
$g_{Y/L} = g_Y - g_L \approx 0.03 - 0.01 = 0.02$。（离散时间恒等式是$(1+g_Y)/(1+g_L) - 1 = 0.0198$，四舍五入为2%。）额外的人的确吸收额外产出，但当产出本身比人口增长更快时，并不是一对一的。
:::
:::

## 卡尔多的典型化事实

1961年，尼古拉斯·卡尔多（Nicholas Kaldor）列出了工业增长的若干规律性，认为理论应当尊重它们。它们不是定理。它们是对当时英国、美国和其他几个工业经济体时间序列的概括，并且已经被核对过许多次。

::: definition 卡尔多的典型化事实 {#def-kaldor}
卡尔多的事实，用略为现代化的语言重述，是：(1)劳动生产率（人均产出）在长期内以大致恒定的速率增长；(2)人均资本以大致恒定的速率增长；(3)资本的实际收益率没有趋势；(4)资本–产出比没有趋势；(5)国民收入中资本与劳动的份额大致不变；(6)人均产出的增长率在各国之间有实质性差异。
:::

事实(1)–(5)合在一起就是后面各章所称的**平衡增长**：$Y$、$K$与$C$以同一速率增长，$K/Y$不变，要素份额$F_K K / Y$与$F_L L / Y$不变。柯布–道格拉斯生产$Y = K^\alpha (AL)^{1-\alpha}$自动给出不变份额，这就是它在本课程中作为默认情形的原因——作为匹配(5)的方便情形，而不是声称每个行业都是柯布–道格拉斯。

(3)与(5)旁边还要放上两点限定。Piketty and Zucman（2014，《经济学季刊》）记录了1970年代以来若干富国私人财富–收入比的上升，Karabarbounis and Neiman（2014，《经济学季刊》）记录了相近窗口里许多国家劳动份额的下降。这两项发现都没有废除卡尔多事实作为一个世纪数据的一阶近似；它们都意味着“大致不变”不是“精确不变”，并且一个唯一稳态具有固定劳动份额的模型会错过近四十年的一个特征。课程在讨论资本增进型技术变化与替代弹性时会回到这一点。

Jones（2016）加了第二份清单，有时称为**新卡尔多事实**：稳定的前沿增长率；具有巨大离散的世界收入分配；现代人均收入与人口增长之间弱的（历史上为负的）相关；增长奇迹集中在少数十年与地区；城市化与结构变化的重要作用；以及大学工资溢价的上升。其中若干将在[[economic-growth/convergence]]与[[economic-growth/endogenous-growth]]中处理。

::: example 柯布–道格拉斯经济中的要素份额 {#ex-shares}
设$Y = K^{0.3} L^{0.7}$，其中$K = 1{,}000$、$L = 200$（示意单位）。计算产出、边际产量与要素份额。若$K$与$L$都加倍，份额会怎样？
::: solution
$Y = 1000^{0.3}\times 200^{0.7} = 324.13$。边际产量为$F_K = 0.3\, Y/K = 0.0972$与$F_L = 0.7\, Y/L = 1.134$。支付耗尽产出：$F_K K + F_L L = Y$。资本份额为$0.3$，劳动份额为$0.7$，与$K$和$L$无关。两种投入都加倍会使$Y$加倍（规模报酬不变）并把份额留在$0.3$与$0.7$。那是欧拉定理加上单位替代弹性，也是柯布–道格拉斯从构造上匹配卡尔多第五条事实的原因。
:::
:::

::: quiz
卡尔多的哪一条事实是关于**跨国差异**的陈述，而不是关于单个工业经济体路径的陈述？
- [ ] 资本–产出比大致不变。
- [ ] 要素份额大致不变。
- [x] 人均产出的增长率在各国之间有实质性差异。
- [ ] 人均资本以大致恒定的速率增长。
::: solution
事实(1)–(5)是工业经济体在平衡路径上的时间序列性质。事实(6)是横截面：增长率并非处处相同，而这正是奇迹、灾难与转型动态所关于的。
:::
:::

## 证据：工时、人力资本与残差

人均GDP可以因为人们工作更多小时、因为他们有更多资本、因为他们有更多技能、或因为同样的小时、资本与技能生产得更多而上升。战后富国的事实与其中第一项相左。西欧、美国与日本自1950年代以来每个工人的年平均工时**下降了**（PWT 10.01，变量`avh`）：人均GDP上升的一部分是每小时GDP的上升，而不是工时的上升。Boppart and Krusell（2020）以及更早的闲暇文献记录了收入上升时市场工时的长期下降，这对劳动供给无弹性的模型是一个谜，也是对劳动供给有弹性的模型的动机。

人力资本——受教育年限，以及这些年限的回报——几乎在各处都上升了（Barro and Lee数据；PWT的`hc`指数）。Mankiw, Romer and Weil（1992）把它当作额外的积累要素；后面各章也如此。它并不能独自填平差距。Hall and Jones（1999）与Caselli（2005，《经济增长手册》）发现，在计入资本与教育之后，人均产出跨国方差的很大一部分仍然留下。那个残差就是**全要素生产率**，被度量成生产函数中的一个楔子，而不是技术的一张照片。错配、度量误差，以及真正的技术差别，都坐在它里面。[[economic-growth/technology-and-growth-accounting]]中的增长核算使分解精确。

人口增长在富国已经放缓，最近在东亚与拉丁美洲的许多地方也是如此（联合国《世界人口展望》2024修订）。在索洛模型中，更低的$n$提高稳态人均资本与人均产出——一种水平效应。在基于创意的模型中，研究部门更大的**规模**可以提高增长率；这一张力在[[economic-growth/endogenous-growth]]中处理。事实本身并不能裁决：1960年后增长最快的国家并不总是最大的，而爱尔兰、新加坡与爱沙尼亚都很小。

世界银行以2017年PPP每天2.15美元度量的极端贫困，从1990年约占世界人口的38%降到2019年的不足9%（世界银行WDI，2026年访问），中国贡献了下降的很大一部分，而撒哈拉以南非洲在仍然贫穷的人口中所占**份额**在上升。人均GDP平均增长对任何给定年份的减贫既非必要也非充分——分配与人口增长坐在中间——但大规模减贫的时期，都是人均GDP快速增长的时期。

## 通向何处

本章的事实是对理论的约束。一个储蓄率决定人均产出长期**增长**率的模型，必须解释为什么美国储蓄率游走而美国增长没有。一个穷国自动赶上的模型必须解释阿根廷，一个穷国永不赶上的模型必须解释韩国。一个没有残差的模型必须解释，为什么按竞争性份额计价的资本与劳动积累，把美国1909–1949年增长的大部分留作未解释（Solow 1957）。

下一章[[economic-growth/solow-model]]取尊重边际报酬递减与卡尔多平衡增长事实的最简单机制：固定储蓄率下的物质资本积累。它给出人均产出的稳态**水平**、转型增长，以及没有技术变化时人均产出没有长期增长。最后那个结论就是[[economic-growth/technology-and-growth-accounting]]存在的原因。趋同、最优储蓄、世代交叠、创意与制度随之而来。

仅供教育学习，不构成投资或理财建议。历史增长率不是任何国家未来增长的预测，本章中没有任何内容是持有任何资产的推荐。

::: history
**1956–1961年，索洛、斯旺、卡尔多。** 罗伯特·索洛（Robert Solow，1956，《经济学季刊》）与特雷弗·斯旺（Trevor Swan，1956，《经济记录》）给了这个行业一个模型，其中边际报酬递减下的资本积累产生稳态；索洛（1957，《经济学与统计学评论》）随后表明，美国1909–1949年每小时产出上升的大部分并不是资本积累。尼古拉斯·卡尔多（Nicholas Kaldor，1961）列出了那个模型被要求匹配的典型化事实。事实已被细化——劳动份额下降、2005年后的放缓、中国的崛起——但1956–1961年的议程仍是接下来三章的议程。
:::

::: summary
- 按PPP计的人均实际GDP是头条度量；点明数据集（长期用麦迪森2023，1950–2019用PWT 10.01，近期更新用WDI）与单位。
- 前沿生活水平自1870年以来在美国国民核算中上升了约17倍，大约每年2%（Jones 2016）；麦迪森的2011年美元美国序列增长稍慢（1870–2019年1.67%），因为平减指数不同。
- 跨国差距巨大：2019年美国与中非共和国之间约为90倍（麦迪森2023）。奇迹（韩国、博茨瓦纳、1978年后的中国）与相对停滞（加纳、阿根廷）表明排序不是固定的。
- 复利是机制：70规则，以及恒等式$g_{Y/L} = g_Y - g_L$。
- 卡尔多事实描述工业经济体中的平衡增长；它们是经验规律性，不是定理，并且近几十年劳动份额已经下降。
- 富国工时已经下降；人力资本已经上升；时间序列与横截面中都留下很大的残差。
:::

## 习题

::: exercise 翻倍时间 {level=1 check="35"}
一国人均实际GDP每年增长2%。用70规则，翻一番需要多少年？（输入年数。）
::: solution
$70/2 = 35$年。精确的离散时间数字是$\ln 2 / \ln(1.02) = 35.00$年，因此这里规则并不是近似。
:::
:::

::: exercise 从速率到水平 {level=1}
实际GDP今年为800，每年增长3%；人口为40，每年增长1%。今年人均GDP是多少，10年后是多少（按年离散复利）？
::: solution
今年：$800/40 = 20$。10年后，GDP为$800\times(1.03)^{10} = 1{,}075.13$，人口为$40\times(1.01)^{10} = 44.18$，故人均GDP为$24.33$。等价地，人均增长为$(1.03)/(1.01)-1 = 0.0198$，且$20\times(1.0198)^{10} = 24.33$。
:::
:::

::: exercise 读麦迪森 {level=1}
麦迪森2023给出中国1978年为1744（2011年国际元）、2019年为16880，美国在同样两年为29286与56469。计算1978–2019年各国的平均年增长率。美–中之比是上升还是下降？
::: solution
中国：$(16880/1744)^{1/41}-1 = 0.0569$（5.69%）。美国：$(56469/29286)^{1/41}-1 = 0.0160$（1.60%）。美/中之比从$29286/1744 = 16.8$降到$56469/16880 = 3.3$。从低起点的快速增长会缩小比值，即使富国继续增长。
:::
:::

::: exercise 70规则对精确公式 {level=2}
在每年$g = 7\%$时，比较70规则的翻倍时间与精确离散时间翻倍时间。哪一个更长，长几个月？
::: hint
精确时间$T = \ln 2 / \ln(1.07)$。把差额乘以12换成月。
:::
::: solution
70规则：$70/7 = 10$年。精确：$\ln 2 / \ln(1.07) = 10.245$年。精确翻倍时间更长$0.245\times 12 \approx 2.9$个月。在7%时70规则略为乐观，因为$\ln(1.07) < 0.07$。
:::
:::

::: exercise 工时与生产率 {level=2}
在一个示意性的富国，人均实际GDP每年增长1.8%，每个工人的平均工时每年下降0.3%，就业–人口比不变。每小时GDP以什么速率增长？
::: solution
人均GDP$= \bigl(\text{每小时GDP}\bigr)\times\bigl(\text{每工人工时}\bigr)\times\bigl(\text{就业/人口}\bigr)$。最后一项不变时，

$$
g_{Y/L} = g_{Y/H} + g_{H} \implies g_{Y/H} = 0.018 - (-0.003) = 0.021
$$

（2.1%）。下降的工时使每小时产出的增长**高于**人均产出的增长。在工时下降的时期用人均GDP作为生产率度量，会低估生产率增长。
:::
:::

::: exercise 要素份额 {level=2 check="0.25"}
产出为$Y = K^{1/4} L^{3/4}$。若资本按其边际产量得到支付，资本的收入份额是多少？（输入小数，例如0.3。）
::: solution
$F_K = (1/4) Y/K$，故$F_K K / Y = 1/4 = 0.25$。在竞争性要素支付下，柯布–道格拉斯中$K$的指数**就是**资本份额。
:::
:::

::: exercise 奇迹与算术 {level=3}
博茨瓦纳的人均GDP（麦迪森2023）从1960年的564升到2019年的15747；加纳从2197到4143。(a) 计算各自的平均年增长率。(b) 按这些恒定速率，从1960年算起，博茨瓦纳在哪一年会超过加纳？(c) 为什么(b)是一项计算而不是一项历史断言？
::: hint
令$564\times(1+g_B)^t = 2197\times(1+g_G)^t$并求解$t$。
:::
::: solution
(a) 博茨瓦纳：$(15747/564)^{1/59}-1 = 0.0581$（5.81%）。加纳：$(4143/2197)^{1/59}-1 = 0.0108$（1.08%）。(b) $564(1.0581)^t = 2197(1.0108)^t$给出$(1.0581/1.0108)^t = 2197/564 = 3.896$，故$t = \ln 3.896 / \ln(1.0468) = 29.7$年，大约1990年。(c) 实际路径不是恒定速率路径：博茨瓦纳的增长依赖钻石与制度，并不是平滑的5.81%；加纳有周期。拟合端点的两条指数曲线的交叉日期是会计装置，不是关于1990年的叙事。
:::
:::

::: exercise 为什么百分之二并不小 {level=3}
考虑两个假想国家，都从5000单位人均实际GDP起步。一个以每年2.0%增长100年，另一个以0.5%增长。(a) 计算两个终点水平及其比值。(b) Jones（2016）把美国前沿增长概括为约2%。用70规则，一个世纪的2%增长是多少次翻倍？(c) 用一段话说明，为什么这种算术使增长核算中的“残差”是一阶的，而不是好奇。
::: solution
(a) 快的：$5000\times(1.02)^{100} = 5000\times 7.245 = 36{,}223$。慢的：$5000\times(1.005)^{100} = 5000\times 1.647 = 8{,}234$。比值：$4.40$。(b) 翻倍时间35年，故一个世纪是$100/35 \approx 2.9$次翻倍，约$2^{2.9} \approx 7.5$倍，与$7.24$一致。(c) 一个世纪里，增长率上1.5个百分点的差别——索洛残差相对于单靠资本积累所造成的那种差别——会产生生活水平上四倍的差别。若残差主要是技术，或主要是错配，或主要是我们未能度量的人力资本，那四倍差距就是增长理论必须指派的东西。把TFP当作“真实”要素被计数之后的剩余，把量级弄反了。
:::
