索洛模型把储蓄率当作参数。人并不如此。一个能够等待的家庭在资本回报高时会多储蓄、在回报低时会多消费，而一个关心后代的计划者不会把资本堆过额外机器产出低于贴现率的那一点。**拉姆齐–卡斯–库普曼斯**模型就是用那种行为替换$s$的索洛模型。

弗兰克·拉姆齐（Frank Ramsey，1928，《经济学杂志》）提出了计划者问题；戴维·卡斯（David Cass，1965，《经济研究评论》）与佳林·库普曼斯（Tjalling Koopmans，1965）用现代最优控制语言重写它并加入了人口增长。完全市场、无限寿命家庭的竞争性均衡与计划者路径重合（在标准凸性下），因此该模型也是关于市场的理论。前几章的黄金律被纳入了不耐的**修正黄金律**所替换。索洛过度储蓄那种动态无效率不能发生：一个把回报低于贴现率的资本堆起来的家庭会干脆把它消费掉。

工具是欧拉方程与二维相图。动态优化在[[mathematical-economics/dynamic-optimisation]]中展开；相平面与[数学图谱中关于非线性系统的一章](/a/maths/lesson.php?c=ode&l=nonlinear-systems&lang=zh)是同一对象。接下来是现代宏观经济学的主力：同一欧拉方程再出现在实际经济周期模型中、作为动态IS曲线出现在新凯恩斯模型中，以及作为给未来定价的规则出现在气候–经济模型中。把它做对，连同鞍点与修正黄金律，就是本章的要点。代数并不比索洛更难；额外的心智状态是$c$被选择，而不是剩余。

## 计划者

一个以速率$n$增长的代表性家庭，具有瞬时效用$u(c)$，满足$u'>0$、$u''<0$，以及稻田条件$u'(0)=\infty$、$u'(\infty)=0$。计划者以速率$\rho > n$贴现，并最大化

$$
\int_0^\infty e^{-(\rho-n)t} u\bigl(c(t)\bigr)\, dt
$$ {#eq-welfare}

约束为$\dot k = f(k) - \delta k - c - n k$，$k(0)$给定，$k\ge 0$，$c\ge 0$。（人口增长出现在贴现中，因为福利是对不断增长的氏族的人均效用；约束是人均资本。）技术变化被省略到本章末尾；加入以速率$g$的劳动增进型$A$，在下面的公式中用$f'(\tilde k)$替换$f'(k)$，并用$\rho + \theta g$替换$\rho$，其中$\theta$是跨期替代弹性的倒数。

::: definition 等弹性效用 {#def-crra}
**等弹性**（CRRA）效用是

$$
u(c) = \frac{c^{1-\theta}-1}{1-\theta}, \qquad \theta > 0,\ \theta \neq 1,
$$

若$\theta=1$则为$u(c)=\ln c$。参数$\theta$是**相对风险厌恶系数**，也是**跨期替代弹性**的倒数。下面的欧拉方程为这一类而写；相图的定性性质对任何满足$u'>0>u''$的$u$都成立。
:::

在本章中$\theta$不是回归系数，也不是CAPM贝塔。它是$u$的曲率。

::: proposition 凯恩斯–拉姆齐规则 {#prop-euler}
计划者问题的内部解满足**欧拉方程**

$$
\frac{\dot c}{c} = \frac{1}{\theta}\bigl(f'(k)-\delta-\rho\bigr)
$$ {#eq-euler}

以及资本约束

$$
\dot k = f(k)-(n+\delta)k - c
$$ {#eq-kdot-r}

和**横截性条件**$\lim_{t\to\infty} e^{-(\rho-n)t} u'(c(t)) k(t) = 0$。
:::

::: proof
现值哈密顿函数为$\mathcal{H} = u(c) + \mu\bigl(f(k)-(n+\delta)k-c\bigr)$。一阶条件：$u'(c)=\mu$且$\dot\mu = (\rho-n)\mu - \mu\bigl(f'(k)-n-\delta\bigr)$。微分$u'(c)=\mu$并使用$u''(c)\dot c = \dot\mu$以及等弹性$u$（$u''(c)c/u'(c)=-\theta$）得到[[#eq-euler]]。横截性是无限期界边界条件，要求资本的贴现值趋于零；没有它，以牺牲消费为代价永远积累资本的路径可以伪装成候选。
:::

欧拉方程是无套利陈述。左边是给定曲率$\theta$时消费所要求的增长。右边是资本净边际产量超过贴现率的盈余。若资本非常能产，消费应当增长（等待是值得的）。若资本相对$\rho$不能产，消费应当下降。

::: example 一个离散时间欧拉 {#ex-discrete-euler}
一个具有$u(c)=c^{1-\theta}/(1-\theta)$、$\theta=2$、$\beta=0.96$（一年贴现因子）的家庭面对无风险净回报$r=0.08$。若$c_t=10$，$c_{t+1}$是多少？
::: solution
离散欧拉方程为$c_t^{-\theta} = \beta (1+r) c_{t+1}^{-\theta}$，或

$$
\frac{c_{t+1}}{c_t} = \bigl(\beta(1+r)\bigr)^{1/\theta} = (0.96\times 1.08)^{1/2} = 1.0182.
$$

故$c_{t+1}=10.18$。当$\beta(1+r)>1$时消费增长，即当回报超过贴现率$1/\beta-1=0.0417$时。在$r=0.04$处增长实质上为零：$(0.96\times 1.04)^{1/2}-1 = -0.0008$。连续时间对应物是$\dot c/c = (r-\rho)/\theta$，其中$\rho\approx -\ln\beta$。
:::
:::

## 相图

方程[[#eq-euler]]–[[#eq-kdot-r]]是$(k,c)$中的自治平面系统。**$k$零倾线**是$\dot k=0$，即$c = f(k)-(n+\delta)k$，一座在黄金律资本$k_{\mathrm{gold}}$处见顶的驼峰，那里$f'(k_{\mathrm{gold}})=n+\delta$。**$c$零倾线**是$\dot c=0$，即$f'(k)=\rho+\delta$（或$c=0$）。把那一资本存量称为$k_{\mathrm{rck}}$：**修正黄金律**存量。

::: definition 修正黄金律 {#def-mgr}
**修正黄金律**资本存量$k_{\mathrm{rck}}$满足

$$
f'(k_{\mathrm{rck}}) = \rho + \delta
$$ {#eq-mgr}

在没有技术变化的模型中（在以速率$g$的劳动增进型进步下为$f'(\tilde k_{\mathrm{rck}})=\rho+\delta+\theta g$）。因为$\rho>n$（要使[[#eq-welfare]]在常数$c$的稳态处有限，这是需要的），有$k_{\mathrm{rck}} < k_{\mathrm{gold}}$：计划者因不耐而在黄金律之前停下。
:::

两条零倾线在内部唯一稳态$(k_{\mathrm{rck}}, c^*)$处相交。在那里线性化系统产生一个正特征值和一个负特征值：一个**鞍点**。恰好一条轨线，**鞍点路径**，收敛到稳态。对每个$k(0)$，计划者选择该轨线上唯一的$c(0)$；任何其他$c(0)$最终碰到$c=0$或$k=0$并违反横截性。

::: widget phaseplane
f: x^(1/3) - 0.05*x - y
g: (y/2)*((1/3)*x^(-2/3) - 0.07)
x: 0.4, 16
y: 0.05, 2.4
points: 2, 0.7; 2, 1.3; 10, 1.2; 10, 1.8; 10.4, 1.66
nullclines: true
caption: $f(k)=k^{1/3}$、$\theta=2$、$\rho=0.02$、$\delta=0.05$、$n=0$的拉姆齐相平面。$k$零倾线是驼峰$c=f(k)-\delta k$；$c$零倾线是竖直线$f'(k)=\rho+\delta=0.07$，在$k_{\mathrm{rck}}=10.39$。在交叉附近点击：一条轨线喂进稳态（鞍点路径）。$c$过高的起点碰到$k=0$轴；$c$过低的起点过度积累。驼峰的黄金律顶点更靠右，在$k_{\mathrm{gold}}=17.2$。
:::

::: example 定位稳态 {#ex-locate}
对$f(k)=k^{1/3}$、$\theta=2$、$\rho=0.02$、$\delta=0.05$、$n=0$，计算$k_{\mathrm{rck}}$、$k_{\mathrm{gold}}$、$c^*$，以及隐含的长期储蓄率$s^* = 1-c^*/f(k_{\mathrm{rck}})$。
::: solution
$f'(k)=(1/3)k^{-2/3}=\rho+\delta=0.07$给出$k^{-2/3}=0.21$，故$k^{2/3}=1/0.21=4.762$且$k_{\mathrm{rck}}=4.762^{3/2}=10.39$。黄金律资本满足$f'(k)=\delta=0.05$，故$k_{\mathrm{gold}}=6.667^{3/2}=17.21$。然后$y^*=10.39^{1/3}=2.182$，$\delta k^*=0.519$，$c^*=1.663$，且$s^*=1-1.663/2.182=0.238$。黄金律消费为$17.21^{1/3}-0.05\times 17.21=2.582-0.860=1.722$，略高于$c^*$，如[[#def-mgr]]所承诺。计划者因$\rho>0$而在黄金律之前停下。
:::
:::

::: intuition 为什么鞍点就是全部理论
$k$是状态：它不能跳。$c$是控制：它可以跳。鞍点路径稳定性说的是，家庭用$c$的跳跃把经济放到既不在$k$上爆炸、也不通向$k=0$的唯一路径上。固定$s$的索洛家庭不能做那一跳；它沿着$\dot k = sf(k)-(n+\delta)k$爬行，即使那条路径是动态无效率的。额外的维度就是排除过度储蓄的东西。
:::

## 竞争性均衡

具有完全市场、代表性无限寿命家庭、以及租用资本并雇用劳动的竞争性企业的竞争性均衡，复制计划者。

企业：$f'(k)=r+\delta$（租金覆盖利息与折旧）且$f(k)-kf'(k)=w$。家庭：欧拉方程$\dot c/c = (1/\theta)(r-\rho)$以及其现值形式为横截性条件的预算约束。合在一起，$r=f'(k)-\delta$把市场欧拉放到[[#eq-euler]]上。产品市场恒等式$\dot k = f(k)-(n+\delta)k-c$是资源约束。因此$(k,c)$跟随计划者的鞍点路径。

这是动态经济的福利第一定理：无外部性、完全市场、凸技术、代表性主体。它在下一章的世代交叠模型中失败，那里不存在无限寿命主体的横截性条件，并且过度积累可以发生。

::: example $\delta$的上升 {#ex-delta}
在[[#ex-locate]]的模型中（$f(k)=k^{1/3}$，$\rho=0.02$，$n=0$），折旧从$0.05$永久升到$0.07$。计算新的$k_{\mathrm{rck}}$，并说明若从旧稳态出发、在冲击瞬间$c$向上跳还是向下跳。
::: solution
新的修正黄金律是$f'(k)=\rho+\delta=0.09$，故$(1/3)k^{-2/3}=0.09$，$k^{2/3}=3.704$，$k_{\mathrm{rck}}=3.704^{3/2}=7.13$，从$10.39$下降。$k$零倾线$c=f(k)-\delta k$也**下降**，因为给定的$k$现在支撑更少的消费。在旧的$k=10.39$——它现在**高于**新的$k_{\mathrm{rck}}$——家庭想把资本消耗掉：$c$**向上**跳（吃掉一些变得更贵于维持的资本），然后$c$与$k$都沿新鞍点路径下降。更高的折旧是财富损失，但$c$的瞬时跳跃可以向上，因为替代办法是维持一笔不再划算的存量。
:::
:::

::: warning 贴现不是市场失灵
一种常见抱怨是计划者（或市场）因为$\rho>0$使$k_{\mathrm{rck}}$低于$k_{\mathrm{gold}}$而“低估未来”。在模型内部那是偏好，不是失灵：家庭**想要**现在的消费甚于以后的消费，而市场交付这一点。$\rho$**应当**小与否则，是拉姆齐本人苦恼过的规范问题，并且欧拉方程并不回答它。把$\rho$选在接近零（Stern 2007）对接近观察到的市场回报（Nordhaus）的气候–经济模型，是在这条轴上选一个点。不要把价值判断与错过的套利相混。
:::

## 比较静态与转型

$\rho$的上升（更不耐）把$c$零倾线左移：$k_{\mathrm{rck}}$下降，$c^*$可能上升或下降，取决于人在黄金律驼峰的哪一侧（通常下降，因为$k_{\mathrm{rck}}$已经低于$k_{\mathrm{gold}}$）。$\theta$的上升在没有$g$的模型中并不移动**稳态**（$\dot c=0$处的欧拉不涉及$\theta$），但它使鞍点路径变平：消费更不愿意跳，因此冲击的更多部分被$k$的缓慢转型所吸收。

在以速率$g$的劳动增进型技术变化下，平衡路径上的欧拉要求$r = \rho + \theta g$，即**平衡增长的拉姆齐–凯恩斯规则**。实际利率由偏好参数与$g$钉住，而不是由$s$。那是一项尖锐的预测，也是拉姆齐模型成为新古典经济周期与气候–经济文献骨干的原因：$r$不是自由残差。

::: example 平衡路径上的实际利率 {#ex-r}
取$\rho=0.02$、$\theta=2$、$g=0.02$。平衡路径上的$r$是多少？若$\alpha=1/3$且$\delta=0.05$，$\tilde k^*$是多少？与[[economic-growth/technology-and-growth-accounting#ex-balanced]]中$s=0.2$、$n=0.01$、$g=0.02$、$\delta=0.05$的索洛$\tilde k^*$比较。
::: solution
$r=\rho+\theta g=0.02+2\times 0.02=0.06$。然后$f'(\tilde k)=r+\delta=0.11$，故$(1/3)\tilde k^{-2/3}=0.11$，$\tilde k^{2/3}=3.030$，$\tilde k^*=3.030^{3/2}=5.275$。$s=0.2$处的索洛$\tilde k^*$是$3.95$。在这些偏好参数下，拉姆齐家庭会选择比$s=0.2$所交付的更高的资本密集度——等价地，更高的储蓄率。匹配两个模型是对$s$（或对$\rho,\theta$）的校准，不是定理。
:::
:::

::: quiz
在没有技术变化的拉姆齐模型中，贴现率$\rho$的上升
- [ ] 提高长期$k$，因为人们为一个更不耐的未来储蓄
- [x] 降低长期$k$，因为$f'(k)=\rho+\delta$要求更高的边际产量
- [ ] 对$k$没有效应，只对$c$有
- [ ] 使稳态动态无效率
::: solution
[[#eq-mgr]]左移。不耐减少积累。只要$\rho>n$，新稳态仍低于$k_{\mathrm{gold}}$，因此它不是动态无效率的。动态无效率是$k>k_{\mathrm{gold}}$现象，本模型不能从有限的$\rho$产生它。
:::
:::

## 拉姆齐模型增加了什么，没有增加什么

它增加：对$r$作出反应的内生$s$；一个福利准则；竞争性路径有效的理由；平衡路径上关于$r$的理论；消费跳跃而资本爬行的鞍点路径转型动态。

它不增加：关于$g$的理论（仍为外生）；异质性（代表性主体）；不完全市场；有限寿命的世代交叠；政府，除非用手放进去。在这里，在与[[macroeconomics/consumption-and-saving]]中李嘉图等价相同的条件下，公共债务是中性的：无限寿命家庭把它抵消。在下一章债务不是中性的。

经验上，具有稳定$\rho$与$\theta$的拉姆齐模型在很长时期里对$r$的**水平**有困难（无风险利率很低），并且对$r$与$g$的联合行为有困难（安全资产文献，以及长期停滞争论，部分是关于$\rho$的争论）。那些是未决问题。当问题是效率时，它们不是回到固定$s$的理由。

## 通向何处

[[economic-growth/overlapping-generations]]丢掉无限寿命。欧拉方程于是在一代**之内**成立，而不是跨越所有未来时间，并且$k$可以超过$k_{\mathrm{gold}}$。[[economic-growth/endogenous-growth]]保持无限寿命（或王朝）并把$g$内生化。经济周期课程[[business-cycles/real-business-cycles]]就是带冲击的拉姆齐模型。

仅供教育学习，不构成投资或理财建议。欧拉方程是对模型家庭的描述，不是对任何个人消费路径的推荐。

::: history
**1928–1965年，拉姆齐、卡斯、库普曼斯。** 拉姆齐25岁时写的1928年《经济学杂志》论文最大化未贴现的效用积分，并得到现在以他命名的规则；作为编辑的凯恩斯写了一篇导言。未贴现的目标需要特殊论证（后来是超越准则）来给路径排序。卡斯（1965）与库普曼斯（1965）引入了$\rho>0$、人口与哈密顿装置。鞍点路径图现在如此标准，以至于容易忘记它是1960年代的对象。
:::

::: summary
- 计划者最大化$\int e^{-(\rho-n)t}u(c)\,dt$，约束为$\dot k=f(k)-(n+\delta)k-c$。欧拉方程为$\dot c/c=(1/\theta)(f'(k)-\delta-\rho)$。
- 稳态是修正黄金律$f'(k)=\rho+\delta$，只要$\rho>n$就有$k_{\mathrm{rck}}<k_{\mathrm{gold}}$。
- $(k,c)$系统是鞍点。消费跳上稳定臂；资本不跳。
- 完全市场与代表性无限寿命家庭把计划者分散化。动态无效率不能发生。
- 有技术变化时，平衡路径上$r=\rho+\theta g$：实际利率由偏好与$g$钉住。
:::

## 习题

::: exercise 修正黄金律 {level=1 check="39.0625"}
令$f(k)=\sqrt{k}$，$\rho=0.03$，$\delta=0.05$，$n=0$。$k_{\mathrm{rck}}$是多少？（输入精确小数，例如39.0625。）
::: solution
$f'(k)=0.5 k^{-1/2}=\rho+\delta=0.08$，故$k^{1/2}=0.5/0.08=6.25$且$k_{\mathrm{rck}}=39.0625$。
:::
:::

::: exercise 黄金对修正 {level=1}
在上一题中，计算$k_{\mathrm{gold}}$以及两个资本存量处的$c$。哪一个更大？
::: solution
$f'(k_{\mathrm{gold}})=\delta=0.05$，故$0.5/\sqrt{k}=0.05$，$\sqrt{k}=10$，$k_{\mathrm{gold}}=100$。然后$c_{\mathrm{gold}}=\sqrt{100}-0.05\times 100=5$。在$k_{\mathrm{rck}}$处，$c=\sqrt{39.0625}-0.05\times 39.0625=6.25-1.953=4.297$。黄金律消费更大，正如计划者的不耐所预测。
:::
:::

::: exercise 欧拉增长 {level=1}
取$\theta=2$、$\rho=0.02$且$r=0.06$，消费以什么速率增长（连续时间）？
::: solution
$\dot c/c = (r-\rho)/\theta = 0.04/2 = 0.02$，即每年2%。
:::
:::

::: exercise $c$的一次跳跃 {level=2}
一个经济体在其拉姆齐鞍点路径上。发生一次未预期的、永久的$\rho$上升。在相图中，哪条零倾线移动，向哪边，并且若$k$预定在旧稳态附近的一个值，$c$在冲击瞬间向上跳还是向下跳？
::: solution
$c$零倾线$f'(k)=\rho+\delta$左移（$k_{\mathrm{rck}}$下降）。$k$零倾线不移动。新鞍点路径在旧$k_{\mathrm{rck}}$附近一般位于旧路径之下：在旧资本存量处，家庭想**现在**多消费（它变得更不耐）然后把$k$消耗掉。因此$c$**向上**跳，并且$k$向新的、更低的$k_{\mathrm{rck}}$下降。（若旧$k$远低于甚至新的$k_{\mathrm{rck}}$，跳跃可能有相反符号；在旧稳态附近，$c$的向上跳是标准情形。）
:::

::: exercise 匹配索洛 {level=2}
在$n=0$、$g=0$且柯布–道格拉斯$\alpha$的拉姆齐平衡路径上，隐含储蓄率为$s=\delta k/f(k)=\alpha\delta/(\rho+\delta)$。在$\alpha=1/3$、$\delta=0.05$、$\rho=0.02$处计算$s$。与前几章的索洛$s=0.2$比较。
::: solution
$s = \alpha \delta/(\rho+\delta) = (1/3)(0.05)/0.07 = 0.01667/0.07 = 0.238$。这与[[#ex-locate]]相符。它略高于示意性的索洛$s=0.2$：在这些参数下拉姆齐家庭积累略多。要匹配$s=0.2$，可以把$\rho$提高到$\alpha\delta/s - \delta = (1/3)(0.05)/0.2 - 0.05 = 0.0833-0.05=0.033$。
:::

::: exercise 横截性 {level=2}
一条候选路径有$k(t)$永远以正速率增长，且$f'(k)-\delta$趋近$r_\infty < \rho$。为什么它在等弹性效用下违反横截性？
::: solution
$u'(c)=c^{-\theta}$，并且在$r_\infty < \rho$时，欧拉方程以速率$(\rho-r_\infty)/\theta>0$把$c$送向0，故$u'(c)$以速率$\theta \times (\rho-r_\infty)/\theta = \rho-r_\infty$**增长**。贴现影子价值项$e^{-(\rho-n)t}u'(c)k$于是表现得像$e^{-(\rho-n)t} e^{(\rho-r_\infty)t} k(t) = e^{-(r_\infty-n)t}k(t)$乘以一个常数。若$k$本身并不比$e^{(r_\infty-n)t}$更快地趋于零，乘积就不趋于0。特别地，若$k$收敛到高于$k_{\mathrm{rck}}$的常数或增长，横截性失败。该条件排除“永远积累、永不消费”的路径。
:::

::: exercise 加入$g$ {level=3}
引入以速率$g$的劳动增进型技术。计划者最大化$\int e^{-(\rho-n)t}u(c)\,dt$，其中$c$是**人均**消费，且$\tilde k = k/A$为状态（这里$k=K/L$）。对等弹性$u$推导平衡路径欧拉条件$r=\rho+\theta g$。然后，取$\rho=0.01$、$\theta=1$（对数）、$g=0.02$、$\delta=0.05$、$\alpha=1/3$，计算$\tilde k^*$与$r$。
::: hint
在平衡路径上$c$以$g$增长，故$\dot c/c=g$。欧拉为$\dot c/c=(1/\theta)(f'(\tilde k)-\delta-\rho)$。
:::
::: solution
等弹性欧拉：$\dot c/c = (1/\theta)\bigl(f'(\tilde k)-\delta-\rho\bigr)$。$c$以速率$g$的平衡增长迫使$g=(1/\theta)(r-\rho)$，其中$r=f'(\tilde k)-\delta$，故$r=\rho+\theta g$。数字：$r=0.01+1\times 0.02=0.03$，$f'(\tilde k)=0.03+0.05=0.08$，$(1/3)\tilde k^{-2/3}=0.08$，$\tilde k^{2/3}=4.167$，$\tilde k^*=4.167^{3/2}=8.51$。对数效用（$\theta=1$）产生比[[#ex-r]]中$\theta=2$更低的$r$和更高的$\tilde k^*$，因为家庭更愿意跨期替代，因此当$g$要求消费增长时积累更多。
:::

::: exercise 一段话中的效率 {level=3}
一个$s>\alpha$的索洛经济是动态无效率的。具有相同技术与$n$、$\delta$的拉姆齐经济不能是。用欧拉方程与$k_{\mathrm{gold}}$的定义，用一段针对读过[[economic-growth/solow-model]]但未读本章的人的短文解释为什么。
::: solution
动态无效率是$k>k_{\mathrm{gold}}$，即$f'(k)<n+\delta$。拉姆齐家庭在稳态（无技术变化）的欧拉方程要求$f'(k)=\rho+\delta$。贴现效用积分仅当$\rho>n$时收敛，故$f'(k)=\rho+\delta > n+\delta$，即$k<k_{\mathrm{gold}}$。家庭不会选择持有产出低于$\rho$的资本：它会把它吃掉。产生过度积累的索洛$s$干脆不是欧拉方程的$s$。无限寿命加上对未来产出要求权的完全市场，是使那种拒绝成为可能的制度；它们就是下一章所去掉的。
:::
