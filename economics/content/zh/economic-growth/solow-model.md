一个国家能否靠多储蓄变富？在封闭经济中，储蓄就是投资，投资形成资本存量，更多资本生产更多产出。这条链条就其本身而言是对的。它不会永远走下去。若多一台机器带来的额外产出随着机器堆积而缩小，那么更高的储蓄率提高的是人均产出的**水平**，而不是——在长期——它的增长率。这就是索洛–斯旺模型的内容，也是下一章必须把技术用手加进去的原因。

模型归功于罗伯特·索洛（Robert Solow，1956，《经济学季刊》）与特雷弗·斯旺（Trevor Swan，1956，《经济记录》）。它仍是讨论资本积累、黄金律与转型增长的默认框架。数学是一个一阶微分方程，属于[[mathematical-economics/difference-and-differential-equations]]所处理的那一类，更深入的讨论见[数学图谱中关于一阶常微分方程的一章](/a/maths/lesson.php?c=ode&l=first-order&lang=zh)。

## 环境

时间是连续的。一种物品被生产、消费与投资。没有政府，没有对外贸易：$Y = C + I$。资本以恒定速率$\delta > 0$折旧。人口（眼下也就是劳动力）以恒定速率$n \ge 0$增长，

$$
\dot L(t) = n L(t), \qquad L(t) = L_0 e^{nt}.
$$

产出的一个恒定份额$s \in (0,1)$被储蓄并投资，故$I = sY$且$C = (1-s)Y$。储蓄率是外生的。那是模型的定义性捷径，在[[economic-growth/ramsey-model]]与[[economic-growth/overlapping-generations]]中被放松。

::: definition 索洛–斯旺模型 {#def-solow}
没有技术变化的**索洛–斯旺模型**就是上述环境，再加上生产函数$Y = F(K,L)$：它二次连续可微，对每个自变量严格递增且严格凹，一次齐次（规模报酬不变），并满足稻田条件——$K \to 0$时$F_K \to \infty$，$K \to \infty$时$F_K \to 0$，以及对$L$的类似条件。资本按

$$
\dot K = s F(K,L) - \delta K.
$$ {#eq-Kdot}

积累。
:::

规模报酬不变使我们能在**集约形式**下工作。定义$k \equiv K/L$（人均资本）与$y \equiv Y/L = F(k,1) \equiv f(k)$（人均产出）。集约生产函数$f$继承$f(0)=0$、$f'>0$、$f''<0$，以及稻田条件$f'(0)=\infty$、$f'(\infty)=0$。柯布–道格拉斯$F(K,L) = K^\alpha L^{1-\alpha}$，$\alpha \in (0,1)$，给出$f(k) = k^\alpha$，是主要例子。

::: proposition 集约形式的运动定律 {#prop-intensive}
在[[#def-solow]]的索洛–斯旺模型中，人均资本服从

$$
\dot k = s f(k) - (n+\delta) k.
$$ {#eq-kdot}
:::

::: proof
微分$k = K/L$：$\dot k = \dot K/L - n k$。代入[[#eq-Kdot]]与$F(K,L) = L f(k)$：

$$
\dot k = \frac{s F(K,L) - \delta K}{L} - n k = s f(k) - \delta k - n k.
$$
:::

项$s f(k)$是人均总投资。项$(n+\delta)k$是**保本投资**：为使$k$保持不变，每个工人所需的投资，覆盖折旧并为新工人配备与现有工人相同的资本。

x: 0, 20
y: 0, 2.5
labels: \text{sf}(k); \text{(n+δ)k}
caption: $f(k)=k^{1/3}$的索洛图。曲线是人均投资$sf(k)$；射线是保本投资$(n+\delta)k$。交点是稳态。用滑块提高$s$：曲线抬起，$k^*$上升。提高$n$或$\delta$：射线变陡，$k^*$下降。稻田条件使曲线开始时垂直并逐渐变平，因此对任何$s,n,\delta>0$恰好存在一个内部交点。
:::

## 稳态

**稳态**是使$\dot k = 0$的$k^*$。由[[#eq-kdot]]，

$$
s f(k^*) = (n+\delta) k^*.
$$ {#eq-ss}

在稻田条件下存在唯一的$k^* > 0$，并且它是全局稳定的：$k < k^*$时$\dot k > 0$，$k > k^*$时$\dot k < 0$。人均产出、消费与资本收敛到常数$y^* = f(k^*)$、$c^* = (1-s)f(k^*)$。总量变量$Y$、$K$与$C$于是以速率$n$增长：经济在增长，但只是因为人口在增长。人均产出在长期并不增长。

::: definition 索洛模型中的稳态资本 {#def-kstar}
**稳态人均资本存量**$k^*$是$s f(k) = (n+\delta)k$的唯一正根。对柯布–道格拉斯$f(k)=k^\alpha$，

$$
k^* = \Bigl(\frac{s}{n+\delta}\Bigr)^{1/(1-\alpha)}, \qquad y^* = \Bigl(\frac{s}{n+\delta}\Bigr)^{\alpha/(1-\alpha)}.
$$ {#eq-cd-ss}
:::

$y^*$对$s$的弹性是$\alpha/(1-\alpha)$。当$\alpha = 1/3$时，该弹性为$1/2$：储蓄率提高10%（例如从0.20到0.22）使稳态人均产出提高约5%。那是水平效应，而且不大。这就是索洛（1956）断定资本积累不能成为生活水平长期增长引擎的数量原因。

::: example 一个柯布–道格拉斯稳态 {#ex-ss-numbers}
令$f(k) = k^{1/3}$，$s = 0.2$，$n = 0.01$，$\delta = 0.05$。计算$k^*$、$y^*$、$c^*$、资本的边际产量，以及净实际租金$f'(k^*)-\delta$。
::: solution
$n+\delta = 0.06$，故

$$
k^* = \bigl(0.2/0.06\bigr)^{3/2} = (10/3)^{3/2} = 6.086, \qquad y^* = (k^*)^{1/3} = 1.826, \qquad c^* = 0.8\times 1.826 = 1.461.
$$

$f'(k) = (1/3) k^{-2/3}$，故$f'(k^*) = (1/3)(6.086)^{-2/3} = 0.100$且$f'(k^*)-\delta = 0.05$。在柯布–道格拉斯情形，稳态净租金为$(n+\delta)\alpha/(1-\alpha) - \delta$；这里$\alpha=1/3$给出$0.06\times\tfrac12 - 0.05 = 0.05$，相符。这些数字是示意性的；它们不是对任何特定国家的校准。
:::
:::

::: warning 储蓄率并不设定$y$的长期增长
索洛图上常见的一滑是提高$s$，看着$k^*$跳起，并说“经济增长更快了”。在**转型**期间，$\dot k > 0$且$y$确实比以前增长更快。在新稳态，$\dot k = 0$再次成立，$y$为常数。人均产出的增长**率**回到零（或在下一章有技术变化时，回到外生速率$g$）。$s$的跨国差异解释的是$y$的**水平**差异，而不是长期增长率的差异。那是一项预测，[[economic-growth/convergence]]把它带到数据中。
:::

## 比较静态

对[[#eq-ss]]做隐函数微分。对柯布–道格拉斯，弹性从[[#eq-cd-ss]]直接得到：

| 参数 | 对$k^*$的效应 | 对$y^*$的效应 |
|---|---|---|
| $s$上升 | 上升 | 上升 |
| $n$上升 | 下降 | 下降 |
| $\delta$上升 | 下降 | 下降 |
| $\alpha$上升（给定$s>n+\delta$） | 上升 | 上升 |

婴儿潮（更高的$n$）稀释资本存量：仅仅为给新工人配备资本就需要更多投资，故$k^*$下降。更快的折旧也一样。两者都不改变$y$的长期增长率，它仍为零。

人均消费$c^* = (1-s)f(k^*(s))$对$s$不是单调的。储蓄太少使经济缺少资本；储蓄太多使消费没有余地。那就是下面的黄金律问题。

::: example 两座岛，索洛版 {#ex-two-islands-solow}
两座封闭的岛共享$f(k)=k^{1/3}$、$n=0.01$、$\delta=0.05$。A岛储蓄$s=0.1$；B岛储蓄$s=0.3$。计算各岛稳态人均产出与消费。B在产出上富多少倍？在消费上呢？
::: solution
由[[#eq-cd-ss]]，

$$
\begin{aligned}
k_A^* &= (0.1/0.06)^{3/2} = 2.152, & y_A^* &= 1.291, & c_A^* &= 1.162,\\
k_B^* &= (0.3/0.06)^{3/2} = 11.180, & y_B^* &= 2.236, & c_B^* &= 1.565.
\end{aligned}
$$

B岛每个工人生产$2.236/1.291 = 1.73$倍——储蓄率上的三倍买到产出上的$3^{\alpha/(1-\alpha)} = 3^{1/2} \approx 1.73$倍，正如弹性$\alpha/(1-\alpha)=1/2$所承诺的。消费比只有$1.565/1.162 = 1.35$，因为B还消费更大蛋糕中更小的**份额**。多储蓄使一座岛更富。它并不按$s$的比例使它更富，也不使它永远增长。
:::
:::

## 转型动态

微分方程[[#eq-kdot]]可分离变量。对柯布–道格拉斯它有封闭形式。令$z \equiv k^{1-\alpha}$。则

$$
\dot z = (1-\alpha)\bigl(s - (n+\delta) z\bigr),
$$

这是线性方程，解为

$$
k(t)^{1-\alpha} = (k^*)^{1-\alpha} + \bigl(k(0)^{1-\alpha} - (k^*)^{1-\alpha}\bigr) e^{-(1-\alpha)(n+\delta)t}.
$$ {#eq-closed}

变换变量$z$中的缺口以速率$(1-\alpha)(n+\delta)$关闭。在$k^*$附近，同一速率支配$k$本身：线性化[[#eq-kdot]]给出

$$
\dot{\hat k} \approx -(1-\alpha)(n+\delta)\, \hat k, \qquad \hat k \equiv \frac{k-k^*}{k^*}.
$$

缺口的**半衰期**为$\ln 2 / \bigl((1-\alpha)(n+\delta)\bigr)$。当$\alpha=1/3$、$n+\delta=0.06$时，那是$0.693/0.04 = 17.3$年：约一半到稳态的距离在17年里关闭，四分之三在35年里。相对于上一章的几个世纪，这很快，并且作为持续增长率差异的理论，它对模型是一个问题——人力资本（Mankiw, Romer and Weil 1992）以及更宽的资本概念部分缓解了这个问题，如[[economic-growth/convergence]]所讨论。

::: widget odesolver
f: 0.2*y^(1/3) - 0.06*y
y0: 1
t: 0, 80
exact: (10/3 - (7/3)*exp(-0.04*t))^(3/2)
h: 2
methods: rk4
caption: [[#ex-ss-numbers]]例子中的人均资本，从$k(0)=1$出发，对照$k^*=6.086$。精确解是[[#eq-closed]]。步长为$2$的RK4已经贴着曲线；17年的半衰期表现为早期陡升、随后向$6$变平。若想看更粗糙的方法在凹的$f$上如何偏慢，可点开欧拉法。
:::

::: example 数字中的一次转型 {#ex-transition}
在[[#ex-ss-numbers]]的经济中，$k(0)=1$。用[[#eq-closed]]计算$k(10)$、$k(20)$与$k(40)$，以及$t=40$时缺口$k^*-k(0)$还剩的比例。
::: solution
$(k^*)^{2/3} = 0.2/0.06 = 10/3$，且$k(0)^{2/3}=1$，故

$$
k(t) = \Bigl(\tfrac{10}{3} - \tfrac{7}{3}\, e^{-0.04 t}\Bigr)^{3/2}.
$$

于是$k(10)=2.35$，$k(20)=3.45$，$k(40)=4.84$。$t=40$时剩余缺口为$(6.086-4.84)/(6.086-1) = 0.245$，即24.5%；等价地，线性近似给出$e^{-0.04\times 40} = 0.202$的**比例**缺口剩余。从稳态资本的六分之一起步，经济在四十年里走完五分之四。转型增长是前重后轻的。
:::
:::

::: quiz
一个经济体低于其索洛稳态。哪一句正确？
- [ ] $k$的增长率在到达$k^*$之前是常数。
- [x] $k$增长，但速率递减，并且当$k \to k^*$时$\dot k \to 0$。
- [ ] $k$立即跳到$k^*$，因为那是均衡。
- [ ] $k$下降，因为边际报酬递减使额外资本毫无价值。
::: solution
[[#eq-kdot]]在$k^*$以下为正，并随$k$接近$k^*$而降到零（$sf(k)$与$(n+\delta)k$之间的垂直缺口缩小）。没有跳跃：$k$是状态变量。边际报酬递减使额外资本**更不**能产，而不是毫无价值；它们是$k$的增长放缓而不是爆炸的原因。
:::
:::

## 黄金律

稳态消费$c^*(s) = (1-s)f(k^*(s))$有一个内部极大值。达到它的储蓄率是**黄金律**储蓄率：在各稳态中使人均消费最大的$s$。它是跨稳态的比较，不是关于转型的陈述，并且是计划者的准则，不是对家庭选择的描述。

::: proposition 黄金律 {#prop-golden}
在索洛稳态之中，人均消费在满足

$$
f'(k_{\mathrm{gold}}) = n + \delta.
$$ {#eq-golden}

的$k_{\mathrm{gold}}$处被最大化。对柯布–道格拉斯，$s_{\mathrm{gold}} = \alpha$。若$s > s_{\mathrm{gold}}$，经济是**动态无效率**的：永久更低的储蓄率会沿着新路径在每一期都提高消费，相对于停留在$k^*$。
:::

::: proof
在稳态，$c = f(k) - (n+\delta)k$，因为$sf(k)=(n+\delta)k$且$c=(1-s)f(k)$。微分：$dc/dk = f'(k) - (n+\delta)$。唯一临界点是[[#eq-golden]]，且$f''<0$使之成为极大值。对柯布–道格拉斯，$f'(k)=\alpha f(k)/k$，故$\alpha y_{\mathrm{gold}}/k_{\mathrm{gold}} = n+\delta$。但$s_{\mathrm{gold}} y_{\mathrm{gold}} = (n+\delta)k_{\mathrm{gold}}$，因此$s_{\mathrm{gold}}=\alpha$。

若$s>s_{\mathrm{gold}}$，则$k^*>k_{\mathrm{gold}}$且$f'(k^*)<n+\delta$。$s$的一次小的、永久的削减使$k^*$向$k_{\mathrm{gold}}$下降并提高$c^*$。在转型期间$k$在下降，故$c = f(k)-\dot k-(n+\delta)k$得到把资本消耗掉的额外礼物。消费在每一期都更高。那是费尔普斯（Phelps，1961，《美国经济评论》）的黄金律论证，也是[[economic-growth/overlapping-generations]]中动态无效率的种子。
:::

黄金律使资本的边际产量等于维持它的成本。若$f'(k)>n+\delta$，额外一单位资本永远生产的额外产出多于维持它的成本；经济应当多储蓄。若$f'(k)<n+\delta$，额外资本是净负担。

::: example 贯穿例子中的黄金律 {#ex-golden}
对$f(k)=k^{1/3}$、$n=0.01$、$\delta=0.05$，计算$s_{\mathrm{gold}}$、$k_{\mathrm{gold}}$、$c_{\mathrm{gold}}$。把$s=0.2$与$s=0.5$处的$c^*$与$c_{\mathrm{gold}}$比较。
::: solution
$s_{\mathrm{gold}}=\alpha=1/3$。于是$k_{\mathrm{gold}}=( (1/3)/0.06 )^{3/2} = 13.095$，$y_{\mathrm{gold}}=2.357$，$c_{\mathrm{gold}}=(2/3)\times 2.357 = 1.571$。在$s=0.2< s_{\mathrm{gold}}$处，$c^*=1.461$，如[[#ex-ss-numbers]]。在$s=0.5>s_{\mathrm{gold}}$处，$k^*=(0.5/0.06)^{3/2}=19.09$，$y^*=2.674$，$c^*=1.337$，**低于**$c_{\mathrm{gold}}$也低于$s=0.2$的值。过度储蓄是可能的。任何真实经济是否位于黄金律之上是另一个经验问题；Abel, Mankiw, Summers and Zeckhauser（1989，《经济研究评论》）提出了用净回报减去增长的符号所做的检验，并且在他们样本的七国集团中没有发现过度储蓄。
:::
:::

## 离散时间

离散时间的表亲是

$$
K_{t+1} = s F(K_t, L_t) + (1-\delta)K_t, \qquad L_{t+1}=(1+n)L_t,
$$

或集约形式

$$
k_{t+1} = \frac{s f(k_t) + (1-\delta)k_t}{1+n}.
$$ {#eq-discrete}

稳态与连续时间中的$s f(k^*)=(n+\delta)k^*$相同（直到在年度频率上消失的$n\delta k$项）。对柯布–道格拉斯，映射$k \mapsto k_{t+1}$递增且凹，有唯一正不动点，吸引每个$k_0>0$。

序列控件按指标$n$求值一个公式，而不是递推，因此路径是按整数抽样的封闭形式[[#eq-closed]]。从$k_0=1$直接迭代[[#eq-discrete]]，取$s=0.2$、$n=0.01$、$\delta=0.05$、$\alpha=1/3$，给出$k_{10}=2.35$、$k_{20}=3.45$、$k_{50}=5.25$，趋近$k^*=6.09$——与ODE相同的转型，每年抽样一次。

N: 80

limit: 6.086
start: 1
y: 0, 8
caption: 贯穿例子中$k_t$的封闭形式路径，画成序列。虚线是连续时间的$k^*=6.086$。早期项上升很快；后期项爬行。$k$的这种递减增长率是边际报酬递减，而不是$s$的变化。
:::

## 模型解释什么，不解释什么

固定$s$、没有技术变化的索洛模型解释：

- 为什么在边际报酬递减下，单靠资本积累不能产生$y$的永久增长；
- 为什么$s$更高、$n$更低的国家在长期应当**更富**，弹性为$\alpha/(1-\alpha)$，若资本份额为三分之一则该弹性很小；
- 为什么从$k^*$以下起步的国家比从$k^*$起步的国家增长更快——**趋同**的第一个版本；
- 柯布–道格拉斯情形下的卡尔多事实(3)–(5)：常数$K/Y = k^*/y^*$，常数资本份额$\alpha$，以及一旦到达稳态就不变的净回报$f'(k^*)-\delta$。

它不解释：

- 前沿上$y$的永久增长（下一章的$g$）；
- 若$\alpha=1/3$且观察到的$s$与$n$的差异是唯一差异，则观察到的收入差距的**大小**（Mankiw, Romer and Weil 1992把这一点说精确了）；
- 为什么$s$本身不同（拉姆齐、戴蒙德）；
- 为什么技术不同（内生增长、制度）。

那些不是一个从未声称自己是$s$或$A$之理论的模型的失败。它们是随后各章的清单。

## 通向何处

[[economic-growth/technology-and-growth-accounting]]加入以速率$g$增长的劳动增进型技术$A(t)$。集约形式的状态变量变成**每有效工人**的资本，$\tilde k = K/(AL)$，本章的代数在把$n$换成$n+g$后仍然成立。$Y/L$以速率$g$的平衡增长出现，增长核算随之而来。

[[economic-growth/convergence]]把转型动态带到横截面。[[economic-growth/ramsey-model]]用家庭欧拉方程替换常数$s$；黄金律变成修正黄金律，索洛式的动态无效率被构造排除。[[economic-growth/overlapping-generations]]把它带回来。

仅供教育学习，不构成投资或理财建议。本模型中更高的$s$是关于封闭经济会计恒等式的思想实验，不是对任何个人储蓄的推荐。

::: history
**1956年，索洛与斯旺。** 索洛的《经济学季刊》论文与斯旺同年的《经济记录》论文是独立的。索洛的表述围绕本章使用的集约形式图，成为教科书路径；斯旺已经强调哈罗德–多马的刀刃性质以及边际报酬递减如何消除它。埃德蒙·费尔普斯（Edmund Phelps，1961，《美国经济评论》）命名了黄金律；I. F. Pearce等人已经围绕同一阶条件转过。稻田条件得名于稻田献一（Ken-Ichi Inada，1963），是保证唯一内部稳态的方便办法；它们比所需要的更强。
:::

::: summary
- 索洛运动定律是$\dot k = sf(k)-(n+\delta)k$。人均总投资为折旧与资本广化提供资金；其余是资本深化。
- 在稻田条件下存在唯一的正稳态$k^*$并且全局稳定。没有技术变化时人均产出的长期增长为零。
- 储蓄率、人口增长与折旧是**水平**参数。对柯布–道格拉斯，$y^* \propto s^{\alpha/(1-\alpha)}(n+\delta)^{-\alpha/(1-\alpha)}$，在$\alpha=1/3$时弹性$\alpha/(1-\alpha)=1/2$。
- 转型是前重后轻的。半衰期为$\ln 2/((1-\alpha)(n+\delta))$，在标准参数下约17年——很快，并且作为数十年增长差距的理论，对模型是一项挑战。
- 黄金律是$f'(k)=n+\delta$，或在柯布–道格拉斯下$s=\alpha$。储蓄超过那个水平是动态无效率的。
:::

## 习题

::: exercise 用手求稳态 {level=1 check="64"}
令$f(k)=\sqrt{k}$，$s=0.4$，$n=0.02$，$\delta=0.03$。$k^*$是多少？（输入$k^*$的整数值。）
::: solution
$s f(k^*)=(n+\delta)k^*$给出$0.4\sqrt{k^*}=0.05 k^*$，故$0.4 = 0.05 \sqrt{k^*}$，从而$\sqrt{k^*}=8$且$k^*=64$。
:::
:::

::: exercise 产出与消费 {level=1}
在上一题的经济中，计算$y^*$与$c^*$。
::: solution
$y^*=\sqrt{64}=8$，$c^*=(1-0.4)\times 8=4.8$。
:::
:::

::: exercise 弹性 {level=1}
在$\alpha=1/3$的柯布–道格拉斯索洛模型中，若$s$从0.20升到0.22、$n$与$\delta$固定，$y^*$上升百分之几？用弹性，不要重新计算$k^*$。
::: solution
$y^*$对$s$的弹性是$\alpha/(1-\alpha)=1/2$。$s$上升10%（0.20到0.22）使$y^*$上升约5%。（精确因子是$(0.22/0.20)^{1/2}=1.049$，故4.9%。）
:::
:::

::: exercise 半衰期 {level=2 check="17.3"}
取$\alpha=1/3$，$n+\delta=0.06$。距$k^*$的一个小缺口的半衰期是多少年，保留一位小数？（若答案是17.3就输入17.3。）
::: solution
$\ln 2 / ((1-\alpha)(n+\delta)) = 0.693147/( (2/3)\times 0.06 ) = 0.693147/0.04 = 17.3$年。
:::
:::

::: exercise 识别黄金律 {level=2}
一个经济体有$f(k)=k^{0.5}$，$n=0$，$\delta=0.05$。(a) 求$k_{\mathrm{gold}}$与$c_{\mathrm{gold}}$。(b) 若$s=0.4$，稳态在黄金律之上还是之下？(c) 计算$s=0.4$处的$c^*$并与$c_{\mathrm{gold}}$比较。
::: solution
(a) $f'(k)=0.5 k^{-0.5}=0.05$，故$k_{\mathrm{gold}}^{-0.5}=0.1$，$k_{\mathrm{gold}}=100$，$y_{\mathrm{gold}}=10$，$c_{\mathrm{gold}}=10-0.05\times 100=5$。(b) 对柯布–道格拉斯$s_{\mathrm{gold}}=\alpha=0.5$，故$s=0.4$在黄金律**之下**。直接地：$k^*=(0.4/0.05)^2=64<100$。(c) $y^*=8$，$c^*=0.6\times 8=4.8<5$。把$s$向$0.5$提高会提高稳态消费。
:::
:::

::: exercise 一个离散步 {level=2}
用[[#eq-discrete]]，取$f(k)=k^{1/3}$、$s=0.2$、$n=0.01$、$\delta=0.05$且$k_0=1$，计算$k_1$。把它与[[#ex-transition]]连续时间封闭形式的$k(1)$比较。
::: solution
$k_1 = \bigl(0.2\times 1^{1/3} + 0.95\times 1\bigr)/1.01 = 1.15/1.01 = 1.139$。连续时间：$k(1)=\bigl(10/3 - (7/3)e^{-0.04}\bigr)^{3/2} = (3.333-2.241)^{3/2} = 1.092^{1.5}=1.141$。一年的离散步与连续步在两位小数上一致。$n\delta k$的差异是二阶的。
:::
:::

::: exercise 动态无效率 {level=3}
在贯穿的柯布–道格拉斯例子中（$n=0.01$，$\delta=0.05$，$\alpha=1/3$），考虑$s=0.5$。(a) 计算$k^*$与$f'(k^*)$。(b) 验证$f'(k^*)<n+\delta$。(c) 用两三句话解释，为什么把$s$**永久**削减到$1/3$会在随后每一期都提高消费，而不仅仅是在新稳态。
::: hint
沿着$\dot k \le 0$的路径写下$c = f(k)-\dot k-(n+\delta)k$。
:::
::: solution
(a) $k^*=(0.5/0.06)^{3/2}=19.09$，$f'(k^*)=(1/3)(19.09)^{-2/3}=0.0464$。(b) $n+\delta=0.06>0.0464$。(c) 把$s$削到$1/3$使新的$k^*$等于$k_{\mathrm{gold}}=13.10$。转型期间$k$**下降**，故$\dot k<0$且对同一$k$，$c=f(k)-\dot k-(n+\delta)k$高于$f(k)-(n+\delta)k$。此外，在$19.09$与$13.10$之间的每个$k$上，$f(k)-(n+\delta)k$本身就超过旧的$c^*$，因为$f(k)-(n+\delta)k$在$k_{\mathrm{gold}}$处最大，并且对$k>k_{\mathrm{gold}}$递减。消耗资本与向$k_{\mathrm{gold}}$移动两者都提高$c$。没有一代人为这次移动付账。
:::
:::

::: exercise 为什么$\alpha=1/3$使差距难以解释 {level=3}
A国有$s=0.3$，B国有$s=0.1$；它们共享$\alpha=1/3$、$n$与$\delta$。(a) 预测的比值$y_A^*/y_B^*$是多少？(b) 麦迪森2023给出2019年美/埃塞俄比亚之比约为28。若唯一差别是$s$上三倍的差距，$\alpha=1/3$的索洛模型会接近吗？(c) 要使$s$上三倍的差距产生$y^*$上28倍的差距，需要怎样的$\alpha$？用一句话评论该$\alpha$是否与国民核算中的资本份额一致。
::: solution
(a) $y_A^*/y_B^* = (s_A/s_B)^{\alpha/(1-\alpha)} = 3^{1/2} \approx 1.73$。(b) 不会：1.73对28。若资本份额为三分之一，这种大小的储蓄率差异不能产生观察到的收入差异。(c) 需要$3^{\alpha/(1-\alpha)}=28$，故$\alpha/(1-\alpha)=\ln 28/\ln 3=3.03$，从而$\alpha=3.03/4.03=0.75$。四分之三的资本份额远高于国民核算中的三分之一（或有时用于“广义资本”的二分之一）。这就是Mankiw, Romer and Weil（1992）加入人力资本的动机，也是Caselli（2005）做发展核算的起点。接下来两章走这两条路。
:::
