人并不永远活着，并且他们并不完全把未出生者的福利内化。上一章的拉姆齐模型使用了一个两者都做的王朝。用相互交叠的有限寿命世代序列替换王朝，两件事改变了。第一，储蓄由年轻人用工资来做，以便为老年消费提供资金；利率于是必须出清一个老年人把资本卖给年轻人的市场。第二，由此得到的$k$可以超过黄金律存量。额外资本可以是负担而不是礼物，而一次设计良好的从年轻到年老的转移——现收现付养老金，或一笔公共债务存量——可以提高每一代的福利。

那就是戴蒙德（Diamond，1965，《美国经济评论》）世代交叠（OLG）模型。它是思考养老金、公共债务负担，以及竞争性经济可能积累过多资本这一可能性的主力。萨缪尔森1958年的消费贷款经济是纯交换祖先；戴蒙德加入了生产与资本。

## 戴蒙德模型

时间是离散的。每一代活两期，**年轻**与**年老**。在$t$期，$L_t$个年轻人工作；$L_{t-1}$个老年人退休。人口以速率$n$增长，故$L_t = (1+n)L_{t-1}$。一种物品用柯布–道格拉斯（或更一般地，新古典）$Y_t = F(K_t, L_t)$生产，规模报酬不变，稻田条件。资本在一期完全折旧，或以速率$\delta$折旧；下面的代数保留一般的$\delta \in [0,1]$。要素按其边际产量得到支付：

$$
r_t = f'(k_t) - \delta, \qquad w_t = f(k_t) - k_t f'(k_t),
$$

其中$k_t = K_t/L_t$且$f(k)=F(k,1)$。

年轻人供给一单位劳动，消费$c_t^y$，并储蓄$s_t = w_t - c_t^y$。老年人消费其储蓄加利息：$c_t^o = (1+r_t)s_{t-1}$。没有遗赠动机。$t$期出生的一代的偏好为$u(c_t^y) + \beta u(c_{t+1}^o)$，其中$\beta \in (0,1)$。

::: definition 戴蒙德OLG经济 {#def-diamond}
**戴蒙德竞争性均衡**是序列$(k_t, c_t^y, c_t^o, r_t, w_t)$，使得：(i) 每一代最大化$u(c^y)+\beta u(c^o)$，约束为$c^y + s = w$与$c^o = (1+r')s$，把$(w,r')$当作给定；(ii) 企业按下面的[[#eq-factors]]支付；(iii) 资本市场出清：$K_{t+1} = L_t s_t$，或

$$
(1+n)k_{t+1} = s(w_t, r_{t+1}),
$$ {#eq-clearing}

其中$s(\cdot)$是年轻人的储蓄函数。资源约束$c_t^y + c_t^o/(1+n) + (1+n)k_{t+1} = f(k_t) + (1-\delta)k_t$然后由瓦尔拉斯成立。
:::

上面的要素价格是

$$
r_t = f'(k_t)-\delta, \qquad w_t = f(k_t)-k_t f'(k_t).
$$ {#eq-factors}

在对数效用$u(c)=\ln c$下，储蓄是工资的一个与$r$无关的恒定份额：

$$
s = \frac{\beta}{1+\beta}\, w.
$$ {#eq-log-s}

未来利率掉出去，因为收入效应与替代效应抵消。那是一种方便，不是一般性质；当$\theta \neq 1$时储蓄函数依赖$r_{t+1}$，并且[[#eq-clearing]]是$k_{t+1}$中的隐方程。

::: proposition 对数效用动态 {#prop-log}
当$u=\ln$、柯布–道格拉斯$f(k)=k^\alpha$且完全折旧$\delta=1$时，

$$
k_{t+1} = \frac{1}{1+n}\cdot\frac{\beta}{1+\beta}\cdot(1-\alpha)\, k_t^\alpha.
$$ {#eq-log-law}

存在唯一的正稳态

$$
k^* = \Bigl(\frac{\beta(1-\alpha)}{(1+\beta)(1+n)}\Bigr)^{1/(1-\alpha)},
$$ {#eq-kstar-olg}

并且它对任何$k_0>0$都全局稳定。
:::

::: proof
柯布–道格拉斯加上$\delta=1$给出$w=(1-\alpha)k^\alpha$。把[[#eq-log-s]]代入[[#eq-clearing]]得到[[#eq-log-law]]。稳态满足$k = C k^\alpha$，其中$C=\beta(1-\alpha)/((1+\beta)(1+n))$，故得[[#eq-kstar-olg]]。映射$k \mapsto k_{t+1}$递增且凹，在0附近高于45度线（稻田）并对大的$k$低于它，因此唯一不动点吸引每个正的$k_0$。
:::

::: example 一个两期校准 {#ex-olg-ss}
取$\alpha=1/3$、$\beta=0.6$、$n=1$（劳动年龄人口每一代翻一番——一代是25–30年，因此这个$n$略高但使数字整齐）、$\delta=1$。计算$s/w$、$k^*$、$f'(k^*)$与$1+r^*$。$1+r^*$比$1+n$更大还是更小？
::: solution
$s/w = \beta/(1+\beta)=0.6/1.6=0.375$。然后

$$
k^* = \Bigl(\frac{0.6\times(2/3)}{1.6\times 2}\Bigr)^{3/2} = \bigl(0.4/3.2\bigr)^{3/2} = 0.125^{1.5} = 0.0442.
$$

$f'(k)=\alpha k^{\alpha-1}=(1/3)(0.0442)^{-2/3}=2.667$，故$1+r^*=f'(k^*)$（因为$\delta=1$）等于$2.667$，且$1+n=2$。这里$1+r^* > 1+n$：经济**低于**黄金律。不同的、更接近1的$\beta$，或更小的$n$，可以反转不等式——那是下一节。
:::
:::

该控件是缺口关闭的草图，不是精确递推；精确映射是[[#eq-log-law]]。从$k_0=0.01$迭代：$k_1=0.125\times(0.01)^{1/3}=0.0269$，$k_2=0.125\times(0.0269)^{1/3}=0.0375$，$k_3=0.0417$，$k_4=0.0433$，已经在$k^*$。两三代就够了。

## 动态无效率

离散时间黄金律最大化稳态人均消费。当$\delta=1$时，整个资本存量每期都被替换，因此每个年轻人的消费（包括老年人，每个年轻人对应$1/(1+n)$个老人）为$f(k)-(1+n)k$。该表达式在$f'(k_{\mathrm{gold}})=1+n$处最大。对一般$\delta$，条件为$f'(k_{\mathrm{gold}})=n+\delta$，与索洛相同。

::: definition 动态无效率 {#def-dyn-ineff}
稳态$k^*$是**动态无效率**的，若$k^* > k_{\mathrm{gold}}$，等价于$f'(k^*) < n+\delta$（或当$\delta=1$时$1+r^* < 1+n$）。于是一次由从年轻到年老的转移所融资的资本减少，会提高每一代的消费，包括已经活着的与所有未来的。
:::

::: proposition 过度积累的可能性 {#prop-overacc}
在戴蒙德模型中，$k^*$可以位于$k_{\mathrm{gold}}$之上或之下。在对数效用、柯布–道格拉斯且$\delta=1$时，$k^*>k_{\mathrm{gold}}$当且仅当

$$
\frac{\alpha}{1-\alpha} < \frac{\beta}{(1+\beta)(1+n)}\cdot(1+n) = \frac{\beta}{1+\beta},
$$

即若$\alpha$相对年轻人的储蓄倾向较小。不耐的世代（小的$\beta$）与快的人口增长（大的$n$）**推向**效率（更少积累）；小的资本份额推向无效率（作为储蓄来源的工资很大）。
:::

::: proof
由[[#eq-kstar-olg]]，$f'(k^*)=\alpha (k^*)^{\alpha-1} = \alpha(1+n)(1+\beta)/(\beta(1-\alpha))$。与$1+n$比较：$f'(k^*) < 1+n$当且仅当$\alpha(1+\beta)/(\beta(1-\alpha))<1$当且仅当$\alpha/(1-\alpha) < \beta/(1+\beta)$。
:::

机制是与未出生者交易的市场缺失。发现$r < n$的拉姆齐家庭会把资本吃到$r=\rho>n$。年老的戴蒙德主体不能把资本卖给未出生者；年轻人是唯一的买者，并且他们从工资储蓄，而不是从王朝欧拉方程储蓄。若工资高（低的$\alpha$）且年轻人储蓄很多，他们把$k$抬高并把$r$压过$n$。

::: example 越过黄金律 {#ex-cross}
取$\delta=1$与对数效用。(a) 证明$\alpha=1/3$对任何$\beta\in(0,1)$与$n\ge 0$**永不**产生动态无效率。(b) 现在令$\alpha=0.2$、$\beta=0.9$、$n=1$。计算$k^*$、$1+r^*$与$1+n$，并给稳态分类。
::: solution
(a) [[#prop-overacc]]要求$\alpha/(1-\alpha) < \beta/(1+\beta)$。对$\beta<1$，右边严格小于$1/2$，而$\alpha=1/3$使左边等于$1/2$。不等式永不成立。(b) $\alpha/(1-\alpha)=0.25 < 0.9/1.9=0.474$，故准则说无效率。直接地：$k^*=\bigl(0.9\times 0.8/(1.9\times 2)\bigr)^{1/0.8}=(0.72/3.8)^{1.25}=0.1895^{1.25}=0.125$，$f'(k^*)=0.2\times 0.125^{-0.8}=0.919$，且$1+n=2$。由于$1+r^*=0.919<2$，稳态是动态无效率的。
:::
:::

::: example 一代人的预算 {#ex-budget}
一个年轻工人挣$w=6$，面对$r'=1$（故$1+r'=2$），并有$\beta=1$与对数效用。计算$c^y$、$s$与$c^o$。验证欧拉方程$1/c^y = \beta(1+r')/c^o$成立。
::: solution
$\beta=1$的对数效用储蓄一半工资：$s=3$，$c^y=3$，$c^o=(1+r')s=6$。欧拉：$1/3 = 1\cdot 2 / 6 = 1/3$。终生消费，按现值计，为$c^y + c^o/(1+r') = 3+6/2=6=w$。这一代相对**自己的**工资既不是净借款人也不是净贷款人；它所持有的资本是对下一代劳动的要求权，那是世代交叠对拉姆齐王朝对自己要求权的替代。
:::
:::

Abel, Mankiw, Summers and Zeckhauser（1989，《经济研究评论》）提出一项检验：若资本回报超过经济的增长率，按现金流意义（利润超过投资），经济就是动态有效的。他们在其样本的七国集团中没有发现过度积累。随后的工作（Geerolf；Blanchard 2019关于$r<g$与公共债务）为1980年后低安全利率的时代重新打开了问题。**安全**利率$r_f$可以低于$g$，而**资本的边际产量**高于$g$，若风险或流动性溢价坐在中间。动态无效率是关于边际产量的陈述，不是关于国库券利率的陈述。本课程记录这一区分，并不把经验问题当作已关闭。

::: warning 公共债务上的$r<g$不是戴蒙德检验
一个以低于GDP增长率的安全利率滚动债务的政府，可以在债务–GDP比不爆炸的情况下运行正的基本赤字。那种算术是真实的（见[[macroeconomics/fiscal-policy-and-debt]]）。它本身并不是$k>k_{\mathrm{gold}}$的证据。[[#def-dyn-ineff]]的相关$r$是资本的边际产量，它包括股权、住房与私人资本的回报，并且即使$r_f$没有，它在大多数战后样本中仍远高于$g$（见Jordà, Knoll, Kuvshinov, Schularick and Taylor 2019，《经济学季刊》，关于一切东西的回报率）。
:::

## 养老金与公共债务

**现收现付**（PAYG）养老金向年轻人每人征税$\tau$，并向每个老年人支付$(1+n)\tau$（平衡的PAYG方案）。年轻人的终生预算变成$c^y + c^o/(1+r) = w-\tau + (1+n)\tau/(1+r)$。“缴费”上的隐含回报是$n$，不是$r$。

::: proposition 戴蒙德模型中的PAYG {#prop-payg}
一个小的平衡PAYG养老金：(i) 降低$k^*$（若$r>n$，年轻人按现值计有更小的终生资源，并且无论如何从更小的可支配收入工资中储蓄更少）；(ii) 在动态无效率稳态提高福利，因为它是向$k_{\mathrm{gold}}$的移动加上回报为$n>r$的转移；(iii) 在动态有效稳态降低未来世代的福利，而第一代老年人获益。
:::

第一代老年人是标准的政治经济学飞轮：他们得到$(1+n)\tau$而没有付过。引入PAYG只有在无效率区域才是帕累托改进。在有效区域它是从未来到现在的转移，它是否可取是分配判断，不是效率判断。

公共债务，在戴蒙德原来的练习中，是替代品。债务存量$B_t$必须由年轻人连同对物质资本的要求权一起持有，故$(1+n)k_{t+1} + b_{t+1} = s(\cdot)$：债务**挤出**资本。在动态无效率经济中那种挤出是优点。在有效经济中它是成本，要与债务所融资的任何公共物品相权衡。李嘉图等价失败，因为当前年轻人在以后征税时将不再活着，并且他们没有起作用的遗赠。

::: example 挤出，用数字 {#ex-debt}
在对数、柯布–道格拉斯、$\delta=1$模型中，储蓄为$s=\frac{\beta}{1+\beta}(1-\alpha)k^\alpha$。有每个年轻人常数债务$b$时，运动定律为$(1+n)k' + b = s$。用[[#ex-olg-ss]]中的$\alpha=1/3$、$\beta=0.6$、$n=1$，比较$b=0$处的$k^*$与$b=0.02$处的$k^*$。
::: solution
没有债务时，$k^*=0.0442$，如前。有债务时，

$$
2k^* + 0.02 = 0.375\times(2/3)\, (k^*)^{1/3} = 0.25\, (k^*)^{1/3}.
$$

令$z=(k^*)^{1/3}$。则$2z^3 - 0.25 z + 0.02=0$。试$z=0.30$：$2(0.027)-0.075+0.02=0.054-0.075+0.02=-0.001$。接近零；$z\approx 0.301$，$k^*\approx 0.0273$。0.02的债务，不到原来$k^*$的一半，把资本存量削了约38%。挤出在**储蓄**恒等式中是一对一的，而在$k$中超过一对一，因为更低的$k$进一步降低工资与储蓄。
:::
:::

::: quiz
在动态**有效**的戴蒙德稳态中，引入一个小的PAYG养老金
- [ ] 提高每一代的福利
- [x] 提高第一代老年人的福利并降低未来世代的福利
- [ ] 按李嘉图等价没有福利效应
- [ ] 提高$k^*$
::: solution
第一代老人得到他们并未支付的转移。未来世代面对$r>n$，因此隐含PAYG回报$n$比市场更差，且$k^*$下降，那是**离开**$k_{\mathrm{gold}}$的移动。李嘉图等价会要求年轻人用私人遗赠抵消该方案；在戴蒙德中他们并不如此，因为遗赠不在模型里（并且即使在模型里也必须起作用）。
:::
:::

## 遗赠、利他与通向拉姆齐的联系

若每一代以贴现$\beta_{\mathrm{beq}}$看重后代的效用，并且遗赠动机是**起作用的**（内部遗赠），Barro（1974，《政治经济学杂志》）表明OLG经济坍缩为拉姆齐王朝。债务于是中性，PAYG被额外遗赠抵消，动态无效率不能发生。遗赠是否起作用是经验性的：意外遗赠（不完全年金）、温暖发光的给予，以及真正的利他的混合，最后一项并不明显占主导（见Weil《经济增长》中关于世代交叠材料的第3章综述，以及Altonji, Hayashi and Kotlikoff 1997，《政治经济学杂志》的经验工作）。

本课程把拉姆齐与戴蒙德当作互补的极端情形。拉姆齐是关于高频代表性消费者问题的正确极端（经济周期、年度数据上的欧拉方程）。戴蒙德是关于养老金、债务的代际归宿，以及过度积累的逻辑可能性问题的正确极端。

## 通向何处

下一章[[economic-growth/endogenous-growth]]回到无限（或王朝）寿命并问$g$从何而来。最后一章中的制度，是$n$、$\beta$、$\alpha$以及遗赠动机存在与否跨国不同的一个原因。发展经济学[[development-economics]]把养老金与微观保险问题带到穷国，那里非正式的老年支持就是PAYG方案。

仅供教育学习，不构成投资或理财建议。这里没有任何内容是对任何个人养老金、任何政府债务或任何资产的推荐。

::: history
**1958–1965年，萨缪尔森与戴蒙德。** 保罗·萨缪尔森（Paul Samuelson）的《利息的一个精确消费贷款模型》（1958，《政治经济学杂志》）表明纯交换OLG经济可以无效率，并且货币可以是帕累托改进的社会设计。彼得·戴蒙德（Peter Diamond，1965，《美国经济评论》）加入了新古典生产与公共债务，并以$r$与$n$给出了过度积累条件。戴维·盖尔（David Gale）、奥利维尔·布兰查德（Olivier Blanchard）与菲利普·韦尔（Philippe Weil）发展了随后的财政与人口理论；Abel–Mankiw–Summers–Zeckhauser（1989）检验是无效率问题被带到七国集团数据的方式。
:::

::: summary
- 戴蒙德OLG：两期寿命，年轻人从工资储蓄，$K_{t+1}=L_t s_t$。对数效用下，$s=\frac{\beta}{1+\beta}w$，并有封闭形式的$k^*$。
- 竞争性$k^*$可以超过$k_{\mathrm{gold}}$。动态无效率是$1+r < 1+n$（当$\delta=1$时），并且它是缺失市场现象，不是家庭错误。
- PAYG养老金与公共债务挤出资本。当且仅当经济动态无效率时那才是福利改进的；否则它是向当前老年人的转移。
- 政府纸面上的$r_f < g$不是戴蒙德检验。检验使用资本的边际产量。
- 起作用的利他遗赠恢复拉姆齐并取消这些结果。遗赠是否起作用不是定理。
:::

## 习题

::: exercise 对数储蓄 {level=1 check="0.5"}
当$u=\ln$且$\beta=1$时，年轻人储蓄工资的多大比例？（输入小数。）
::: solution
$s/w = \beta/(1+\beta)=1/2=0.5$。
:::
:::

::: exercise 稳态$k$ {level=1}
用[[#eq-kstar-olg]]，取$\alpha=1/2$、$\beta=1$、$n=1$、$\delta=1$，计算$k^*$与$1+r^*$。
::: solution
$k^* = \bigl(1\cdot(1/2)/((2)\cdot(2))\bigr)^{1/(1/2)} = (0.5/4)^2 = 0.125^2 = 0.015625$。然后$f'(k)=\tfrac12 k^{-1/2}=\tfrac12 / 0.125 = 4$，故$1+r^*=4$。且$1+n=2$，故$r^*>n$：有效。
:::
:::

::: exercise 黄金律比较 {level=1}
在上一题中，$\delta=1$下的$k_{\mathrm{gold}}$是多少？$k^*$在它之上还是之下？
::: solution
$f'(k_{\mathrm{gold}})=1+n=2$，故$\tfrac12 k^{-1/2}=2$，$k^{-1/2}=4$，$k_{\mathrm{gold}}=1/16=0.0625$。且$k^*=0.0156<0.0625$：在黄金律之下，与$1+r^*>1+n$一致。
:::

::: exercise 对数柯布–道格拉斯何时无效率？ {level=2}
用[[#prop-overacc]]，求$\delta=1$的对数效用戴蒙德经济可以动态无效率的最大$\alpha$，并说明它是否对任何$\beta<1$达到。
::: solution
需要$\alpha/(1-\alpha) < \beta/(1+\beta) < 1/2$，故$\alpha/(1-\alpha)<1/2$，故$\alpha<1/3$。界限$\alpha=1/3$在$\beta\to 1$时被接近，但对$\beta<1$永不达到。三分之一或更大的资本份额排除对数–柯布–道格拉斯过度积累。这就是为什么教科书“无效率”校准使用更小的$\alpha$或储蓄上收入效应更弱的效用。
:::
:::

::: exercise 一项PAYG税 {level=2}
在对数模型中，回报为$n$的工资税$\tau$按现值把年轻人的可支配收入减少$\tau - (1+n)\tau/(1+r')$。若经济处于$r>n$的稳态，这一现值项符号为正还是负，它提高还是降低储蓄？
::: solution
$\tau - (1+n)\tau/(1+r) = \tau\bigl(1 - (1+n)/(1+r)\bigr)$，当$r>n$时为**正**：年轻人按现值计受损。终生财富下降，故储蓄下降（对数效用：储蓄是终生财富的一个份额，等价于扣除现值税后的工资）。此外，税收一对一降低当前工资，那是现金流渠道。两个渠道都降低$k^*$。
:::
:::

::: exercise 挤出恒等式 {level=2}
设年轻人的储蓄$s$在一阶近似上固定。每个年轻人债务上升$\Delta b$，在小型开放经济对封闭戴蒙德经济中，下一期$k$改变多少？（各一句。）
::: solution
小型开放经济：$k$由$f'(k)=r^*$世界钉住，故$\Delta k=0$；额外债务由外国人持有（或年轻人持有更少的外国资本）。封闭戴蒙德：若$s$固定，$(1+n)\Delta k' = -\Delta b$，故$\Delta k' = -\Delta b/(1+n)$：下一期将使用的资本**存量**按每个年轻人一对一挤出，按人口增长缩放。一旦$s$依赖$w(k)$，封闭经济乘数更大，如[[#ex-debt]]。
:::
:::

::: exercise 设计一次帕累托移动 {level=3}
一个对数、柯布–道格拉斯、$\delta=1$经济有$\alpha=0.2$、$\beta=0.9$、$n=0.5$。(a) 计算$k^*$、$1+r^*$、$1+n$并判定效率。(b) 描述一次一次性转移，连同$k$的永久减少，使每一代都更好。(c) 为什么拉姆齐计划者不需要这一工具？
::: hint
第(a)部分：$k^*=\bigl(\beta(1-\alpha)/((1+\beta)(1+n))\bigr)^{1/(1-\alpha)}$。
:::
::: solution
(a) $k^*=\bigl(0.9\times 0.8/(1.9\times 1.5)\bigr)^{1/0.8}=\bigl(0.72/2.85\bigr)^{1.25}=0.2526^{1.25}=0.178$。$f'(k^*)=0.2\times 0.178^{-0.8}=0.2\times 3.46=0.692$，故$1+r^*=0.692 < 1.5=1+n$：无效率。(b) 向年轻人征小税$\tau$，把所得给当前老年人，并保持该方案（或等价地，发行一小笔永久债务并消费所得）。当前老年人得到转移。随后每一代获益，因为$k$向$k_{\mathrm{gold}}$下降（那里$f'(k)=1+n$）**并且**因为PAYG回报$n$超过$r$。(c) $\rho>n$的拉姆齐家庭本来就不会过度积累；欧拉方程已经把$k$保持在$k_{\mathrm{gold}}$以下。与未出生者交易的缺失市场就是戴蒙德无效率的全部，而王朝把那些交易内化。
:::
:::

::: exercise $r<g$与住房 {level=3}
设企业资本的净边际产量为6%，GDP增长2%，安全利率为0%，都是示意性的。(a) 戴蒙德动态无效率检验通过还是失败？(b) 用两三句话说明$r_f < g < \mathrm{MPK}-\delta$如何能够共存，以及那种组合对**作为资本替代品持有**的额外公共债务、对**被安全储藏价值需求所吸收**的额外公共债务的福利效应意味着什么？
::: solution
(a) 失败（即经济按戴蒙德准则**不是**动态无效率的）：$\mathrm{MPK}-\delta = 0.06 > 0.02 = g \approx n+g_{\mathrm{tech}}$在相关比较中。(b) 对安全、流动要求权（货币、国债、便利收益）的需求可以把$r_f$压到$g$以下，即使生产性资本赚得高于$g$。仅仅满足那种需求的额外公共债务不必一对一挤出$K$，并且滚动起来可以便宜。**是**对$K$的要求权之替代品的额外公共债务仍然挤出$K$，并且因为$\mathrm{MPK}-\delta>g$，那种挤出有一阶成本。布兰查德（Blanchard，2019）强调第一条渠道；戴蒙德（1965）是第二条。它们不是同一实验。
:::
