若索洛模型是对世界的好描述，并且各国共享$s$、$n$、$\delta$、$g$与生产函数，那么穷国——相对$k^*$而言$k$低的国家——应当比富国增长更快。资本稀缺，其边际产量高，边际报酬递减做其余的事。那个预测是**绝对趋同**。它不是整个世界散点图的样子。它更接近OECD国家、或美国各州、或日本各县散点图的样子。这一区分是本章的主题。

两项修正在不假装乍得与瑞士是同一个索洛经济的前提下挽救了这一机制。**条件趋同**允许$s$、$n$与人力资本不同，并预测每个国家离**自己的**稳态越远增长越快。Mankiw, Romer and Weil（1992，《经济学季刊》）的**扩展索洛模型**把人力资本加为积累要素，并且比教科书模型更好地拟合收入水平的横截面。两项修正都没有使$A$处处相同。上一章的发展核算已经说过它不是。

## 绝对趋同与条件趋同

::: definition 绝对趋同与条件趋同 {#def-convergence}
**绝对**（或无条件）**趋同**是如下假说：$g_y$是$y$的减函数，就共享同一稳态的经济体而言。**条件趋同**是如下假说：一旦稳态的决定因素——在索洛模型中是$s$、$n+\delta+g$，以及一旦加入的人力资本——被保持不变，$g_y$就是$y$的减函数。**俱乐部趋同**是如下假说：趋同在共享初始条件或制度的群体内部成立，但在群体之间不成立。
:::

索洛模型对共享参数的经济体预测绝对趋同，对不共享参数的经济体预测条件趋同。它并不预测每个穷国都增长很快。一个$s$低、$n$高的国家有低的$y^*$，即使它在世界排序中贫穷，也可能**高于**自己的稳态。

在$\tilde k^*$附近线性化索洛模型给出精确的速度。

::: proposition 索洛模型中的趋同速度 {#prop-speed}
令$\lambda \equiv (1-\alpha)(n+g+\delta)$。在带劳动增进型技术的索洛模型稳态附近，

$$
\ln y(t) - \ln y^*(t) \approx e^{-\lambda t}\bigl(\ln y(0)-\ln y^*(0)\bigr),
$$ {#eq-speed}

其中$y^*(t)$是平衡增长路径（以$g$增长）。$\ln y$缺口的半衰期为$(\ln 2)/\lambda$。当$\alpha=1/3$、$n+g+\delta=0.08$时，$\lambda=0.053$，半衰期为13年。当$\alpha=2/3$（广义资本）时半衰期增为约三倍，约39年。
:::

::: proof
由[[economic-growth/solow-model]]，$\dot{\tilde k} \approx -(1-\alpha)(n+g+\delta)(\tilde k-\tilde k^*)$。对柯布–道格拉斯，$\ln y = \ln A + \alpha \ln \tilde k + \text{常数}$，因此$\tilde k$中的比例缺口（给定$A$）是$y$中的比例缺口，按$\alpha$缩放；对数缺口关闭的**速率**$\lambda$仍是$(1-\alpha)(n+g+\delta)$。积分线性ODE给出[[#eq-speed]]。令$e^{-\lambda T}=1/2$即得半衰期。
:::

13年的半衰期相对[[economic-growth/growth-facts]]中持续的跨国差距是短的。Barro and Sala-i-Martin（《经济增长》，2004，以及1990年代的一系列论文）在美国各州、日本各县与欧洲地区上估计$\lambda \approx 0.02$——每年2%的**条件**趋同速率，半衰期约35年——这只有在$\alpha$远高于三分之一、或模型用缓慢积累的人力资本加以扩展时，才与索洛模型相符。那是真正的张力，不是舍入误差。

::: widget plot
f: exp(-l*x)
sliders: l=0.02:0.01:0.08:0.005
x: 0, 80
y: 0, 1.1
labels: e^{-\lambda t}
caption: 线性化索洛缺口$e^{-\lambda t}$作为以年为单位的时间的函数。在Barro–Sala-i-Martin估计$\lambda=0.02$处，35年时一半缺口仍在。把$\lambda$升向教科书索洛的0.05（$\alpha=1/3$），缺口在一代人里大体消失。若资本是广义的、或$A$本身不同，收入差异的持续性更容易匹配。

::: example 半衰期 {#ex-halflife}
计算$\lambda=0.02$与$\lambda=0.053$处对数收入缺口的半衰期。40年后，两种情形下缺口还剩多大比例？
::: solution
$T_{1/2}=\ln 2/\lambda$。在$\lambda=0.02$处，$T_{1/2}=34.7$年且$e^{-0.02\times 40}=0.449$（剩45%）。在$\lambda=0.053$处，$T_{1/2}=13.1$年且$e^{-0.053\times 40}=0.120$（剩12%）。四十年OECD式的条件趋同仍留下几乎一半缺口；四十年教科书索洛趋同会把它关闭。在共享制度的地区之间，数据看起来更像$\lambda=0.02$（Barro and Sala-i-Martin 1992，《政治经济学杂志》，关于美国各州）。
:::
:::

## 横截面是什么样子

Baumol（1986，《美国经济评论》）把麦迪森数据中16个工业国家的增长对初始收入作图，发现一条紧密的负斜率——1870年已经富裕的俱乐部内部的绝对趋同。DeLong（1988，《美国经济评论》）表明样本是按因变量选择的：1870年富裕但**未能**趋同的国家不太可能进入这16个。一旦样本是世界，甚至是1960年的宽横截面，负斜率就消失了。

Pritchett（1997，“大分叉”）是世界样本的陈述。从1870年到二十世纪末，最富与最穷之比**上升了**，因为前沿以1.5–2%增长而许多穷国没有。绝对趋同不是关于世界的事实。

它更接近关于某些俱乐部的事实。

- **美国各州**，1880–2000：穷州增长更快（Barro and Sala-i-Martin 1992）。斜率约为每年2%。
- **日本各县**与**欧洲地区**：类似（Barro and Sala-i-Martin 1991，《布鲁金斯论文》）。
- **OECD**国家1950年后：向下倾斜的散点，被OECD成员身份本身与$y^*$相关这一事实所污染。
- **世界**，1960–2019：增长对初始$y$的无条件散点没有向下斜率。中国、韩国、中国台湾与博茨瓦纳坐在云团之上；许多撒哈拉以南非洲国家坐在它下面。[[economic-growth/growth-facts]]中麦迪森2023的数字——韩国从1960年**低于**菲律宾的水平以5.6%增长；加纳从1960年**高于**博茨瓦纳的水平以1.1%增长——就是那片云。

::: example 失败的无条件散点 {#ex-unconditional}
1960年，加纳人均GDP为2197，韩国为1548（麦迪森2023）。1960–2019年平均年增长在加纳为1.08%，在韩国为5.62%。这一对支持绝对趋同吗？博茨瓦纳（564，然后5.81%）对加纳呢？
::: solution
绝对趋同说**更穷意味着更快**。韩国1960年比加纳穷并且增长更快：那一对相符。博茨瓦纳更穷，并且比两者都增长更快：那一对也相符。世界散点并不相符，因为许多1960年贫穷的国家（见Pritchett 1997，以及麦迪森2023中的撒哈拉以南观察）增长缓慢。两三个精心挑选的对子总能被弄得看起来像一条定律。定律是**样本**上的斜率，而世界样本的斜率大致为零。
:::
:::

::: example 一次条件趋同计算 {#ex-cond-calc}
两个国家共享$\alpha=1/3$、$n+g+\delta=0.08$，并且当前以相同单位$y=2$。A国投资率为$s=0.24$；B国为$s=0.12$。用柯布–道格拉斯，哪个国家离自己的$y^*$更远，在索洛模型中谁应当增长更快？
::: solution
$y^* \propto s^{\alpha/(1-\alpha)} = s^{1/2}$，故$y_A^*/y_B^* = \sqrt{2}\approx 1.41$。没有常数，$y^*$的**水平**不能钉住，但$s$更高的国家有更高的目标。若两者都坐在同一当前$y$，A离自己的目标更远（除非两者都已经高于B的$y^*$而A更接近其更高的天花板——所关心的一般情形是两者都在下面）。在稳态附近，$y$相对趋势的增长是$\lambda$乘以对数缺口，因此朝向更高$y^*$的缺口更大的国家增长更快。以$s$为条件就是条件趋同的全部：同样的$y$并不意味着同样的$g_y$。
:::
:::

::: warning 俱乐部里的负斜率不是世界定律
在OECD上拟合$g_i = a + b \ln y_{i0} + u_i$并发现$\hat b < 0$，并不意味着乍得只要等待就会赶上。OECD共享参数；乍得并不。把OECD斜率报告为“那个”趋同速率，是过度解读这一文献最常见的办法。
:::

## 条件趋同与MRW回归

索洛模型自然的经验对应物是一个**以**$y^*$的决定因素为条件的回归。

::: definition 教科书索洛回归 {#def-mrw}
**教科书索洛回归**，以Mankiw, Romer and Weil（1992）估计的形式，是

$$
\ln y_i = c + \frac{\alpha}{1-\alpha}\ln s_i - \frac{\alpha}{1-\alpha}\ln(n_i+g+\delta) + \varepsilon_i,
$$ {#eq-mrw}

在国家横截面上，$s_i$度量成GDP中的投资份额，$n_i$为劳动年龄人口增长。在模型下，两个斜率系数量级相等、符号相反，并且若$\alpha=1/3$则等于$\alpha/(1-\alpha)\approx 1/2$。
:::

MRW在排除石油国的Summer–Heston（宾大世界表）样本上估计了[[#eq-mrw]]。$\ln s$与$\ln(n+g+\delta)$上的系数有正确的符号并且量级大致相等，但它们更接近$1.4$而不是$0.5$：数据表现得好像$\alpha \approx 0.6$，而不是$1/3$。在他们的中间样本中$R^2$约为0.6。模型不是灾难。它在上一章已经标出的方向上数量不对：若资本份额为三分之一，观察到的$s$与$n$的差异并不能产生观察到的$y$的差异。

他们的补救是加入人力资本。

::: proposition 扩展索洛模型 {#prop-augmented}
令$Y = K^\alpha H^\beta (AL)^{1-\alpha-\beta}$，其中$H$是人力资本，以与$K$相同的方式通过放弃消费、以速率$s_h$积累。则沿平衡路径

$$
\ln y = c + \frac{\alpha}{1-\alpha-\beta}\ln s_k + \frac{\beta}{1-\alpha-\beta}\ln s_h - \frac{\alpha+\beta}{1-\alpha-\beta}\ln(n+g+\delta),
$$ {#eq-aug}

并且趋同速度为$\lambda = (1-\alpha-\beta)(n+g+\delta)$，慢于教科书模型。当$\alpha=\beta=1/3$时，$y$对$s_k$的弹性为1（不是$1/2$），且在$n+g+\delta=0.08$处$\lambda \approx 0.027$，半衰期26年。
:::

::: proof
集约形式$\tilde y = \tilde k^\alpha \tilde h^\beta$。稳态：$s_k \tilde y = (n+g+\delta)\tilde k$且$s_h \tilde y = (n+g+\delta)\tilde h$。求解：$\tilde k/\tilde y = s_k/(n+g+\delta)$，$\tilde h/\tilde y = s_h/(n+g+\delta)$。代入$\tilde y = \tilde k^\alpha \tilde h^\beta$并取对数。趋同速度由线性化二维系统得出；支配$\ln y$缺口的特征值为$(1-\alpha-\beta)(n+g+\delta)$（MRW 1992，附录）。
:::

MRW用中学入学率度量$s_h$。在扩展回归中，隐含的$\alpha$与$\beta$都接近三分之一，对三个系数的约束未被拒绝，并且中间样本中$R^2$升到0.8以上。以$s_k$、$s_h$与$n$为条件，更穷的国家增长更快。那是索洛框架最著名的经验成功。

它不是最后的话。

- **识别。** $s_k$与$s_h$是内生的。一个因索洛积累以外的某种原因（制度、$A$）而富裕的国家可能**因为**富裕而储蓄并送孩子上学。MRW把$s_k$与$s_h$当作外生。Islam（1995，《经济学季刊》）把回归放进带国家固定效应的面板，吸收$A_i$，仍然发现条件趋同，且$\lambda$更快。
- **人力资本度量。** 受教育年限不是$H$。教育回报不同，质量不同，健康被省略。Cohen and Soto（2007）以及随后的Barro–Lee修订会改变系数，但不会推翻定性结果。
- **残差仍在。** 即使在MRW中，国家效应也坐在$\varepsilon_i$里。Hall and Jones（1999）以及上一章的发展核算文献在计入$K$与$H$之后仍然发现很大的$A$缺口。条件趋同与生产率上大而持续的差异相容。

::: example 隐含弹性 {#ex-elasticities}
用[[#eq-aug]]并取$\alpha=\beta=1/3$，若$s_k$加倍、$s_h$与$n+g+\delta$固定，长期$y$上升多少倍？与$\alpha=1/3$的教科书索洛弹性比较。
::: solution
$y$对$s_k$的弹性是$\alpha/(1-\alpha-\beta)=1$。$s_k$加倍使长期$y$加倍。在教科书模型中弹性是$\alpha/(1-\alpha)=1/2$，故$s_k$加倍使$y$上升$\sqrt{2}\approx 1.41$倍。人力资本使积累更有力，因为$H$与$K$互补：更多$K$提高$H$的回报，并且在模型中$H$会作为回应而被积累。它在数据中是否**那么**有弹性，就是MRW的识别问题。
:::
:::

::: quiz
条件趋同意味着
- [ ] 每个穷国都比每个富国增长更快
- [x] 给定$s$、$n$与人力资本，一个国家离自己的稳态越远增长越快
- [ ] 国家之间的收入缺口在一代人里消失
- [ ] 索洛残差为零
::: solution
该假说是关于到**自己的**$y^*$的距离的陈述，不是到美国的距离。只有稳态重合时缺口才消失。在有条件趋同的世界里TFP可以跨国不同；它于是是回归所条件于（或留在残差里）的东西之一。
:::
:::

## $\beta$趋同、$\sigma$趋同与俱乐部

增长对初始收入的负斜率是**$\beta$趋同**。它并不意味着$\ln y$的横截面**离散**在下降。那第二个性质是**$\sigma$趋同**。一组经济体可以向不同的$y^*$做$\beta$趋同，同时$y^*$本身的离散在扩大——这是对1870年后世界的一种读法。Quah（1993，《经济学快报》；1996，《欧洲经济评论》）主张世界分布正在极化成双峰，一个富俱乐部和一个穷俱乐部，而不是向均值坍缩。后来用更新数据所做的工作（中国与印度的那些十年）填补了**人**的世界分布的中间，即使不总是填补国家的分布（Sala-i-Martin 2006，《经济学季刊》）。

俱乐部趋同可以由带贫困陷阱的模型产生：$k$中有一个阈值，在它以下$s$或$n$或$A$不同，从而两个稳态都局部稳定。Galor and Weil、Azariadis and Drazen（1990，《经济学季刊》）以及统一增长文献是理论。对阈值的经验识别是脆弱的（Hansen 2000）。本课程记录这种可能性，并不把某个特定陷阱当作对任何点名国家已经确立。

## 证据，注明日期

作为麦迪森2023与PWT 10.01版本下，趋同一章必须与之共存的事实是这些。

1. **1870–1990年没有世界绝对趋同。** Pritchett（1997）；麦迪森2023：1870年美/世界为$4{,}803/1{,}543 = 3.1$，2019年为$56{,}469/16{,}091 = 3.5$——美国对**世界平均**之比并未爆炸，但美国对最穷之比爆炸了（2019年美/埃塞俄比亚：28；美/中非：90）。
2. **许多样本中的条件$\beta$趋同**，约为每年2%，一旦计入$s$、$n$与教育（MRW 1992；Barro and Sala-i-Martin 1992，2004；Islam 1995）。
3. **增长奇迹不是穷人的随机样本。** 它们集中在1960年后的东亚与1978年后的中国，外加少数资源与治理案例（博茨瓦纳）。2%的条件趋同方程并不预测韩国的5.6%。
4. **一些中等收入与曾经富裕的国家没有向前沿趋同。** 阿根廷在1960–2019年每年1.2%（麦迪森2023）是反对把1960年收入读成充分统计量的教科书警告。
5. **大约1990年以来，（人口加权的）人均GDP的国家之间不平等已经下降**，主要因为中国与印度（Sala-i-Martin 2006及更新）。国家内部不平等常常上升。那两个序列回答不同的问题。

对(3)与(4)相互竞争的读法——技术扩散、制度、出口纪律、人口——是[[economic-growth/endogenous-growth]]与[[economic-growth/institutions-and-growth]]的材料。单靠趋同经验研究不会在它们之间做决定。

## 通向何处

无论是否扩展，索洛模型都把$s$、$n$与$A$当作给定。[[economic-growth/ramsey-model]]与[[economic-growth/overlapping-generations]]把$s$内生化。[[economic-growth/endogenous-growth]]把$A$内生化。[[economic-growth/institutions-and-growth]]问为什么参数不同，而这正是绝对趋同触礁的问题。

每年2%的条件趋同速率，若应用于一个比自己的$y^*$低8倍的国家，会在35年里关闭对数缺口的一半——还剩$8^{1/2}\approx 2.8$倍。那是很多剩余缺口，并且那是$y^*$被固定的乐观计算。若$A$本身在前沿增长，赶上一个移动的目标更慢。

仅供教育学习，不构成投资或理财建议。趋同回归不是对任何国家增长的预测，俱乐部也不是投资组合的推荐同伴组。

::: history
**1986–1992年，从Baumol到MRW。** 威廉·鲍莫尔（William Baumol）1986年《美国经济评论》上对16个工业国家的散点使绝对趋同成为头条；布拉德福德·德朗（Bradford DeLong）1988年的评论表明了选择问题。罗伯特·巴罗（Robert Barro）与哈维尔·萨拉-伊-马丁（Xavier Sala-i-Martin）（1991，1992）度量了2%的地区趋同。N.格里高利·曼昆（N. Gregory Mankiw）、戴维·罗默（David Romer）与戴维·韦尔（David Weil）（1992，《经济学季刊》）写下索洛模型实际预测的横截面，加入人力资本，并设定了那十年其余时间使用的经验模板。丹尼·夸（Danny Quah）的双峰论文问了一个$\beta$回归无法回答的分布问题。
:::

::: summary
- 绝对趋同是索洛对共享稳态的经济体的预测。它在世界样本中失败，并在某些俱乐部内部近似成立（美国各州、日本各县、OECD的部分）。
- 一旦$s$、$n$与人力资本不同，条件趋同才是相关的索洛预测。MRW（1992）是经典估计；除非计入人力资本，隐含的$\alpha$过高。
- 线性化速度在教科书索洛中为$\lambda=(1-\alpha)(n+g+\delta)$，一旦人力资本被积累则为$(1-\alpha-\beta)(n+g+\delta)$。估计的$\lambda\approx 0.02$慢于$\alpha=1/3$的教科书索洛。
- $\beta$趋同并不意味着$\sigma$趋同。自1990年以来**人**的世界分布变得不那么不平等，主要因为中国与印度；**国家**的分布是不同的对象。
- 奇迹与灾难不是来自共同2%过程的抽取。它们是接下来各章存在的原因。
:::

## 习题

::: exercise 半衰期算术 {level=1 check="34.7"}
在$\lambda=0.02$处，对数收入缺口的半衰期是多少年，保留一位小数？（若答案是34.7就输入34.7。）
::: solution
$\ln 2 / 0.02 = 0.6931/0.02 = 34.7$年。
:::
:::

::: exercise 剩余缺口 {level=1}
一个国家在2020年低于其平衡增长路径8倍。每年$\lambda=0.02$的条件趋同适用，且$y^*$以$g=0.02$增长。2055年$y$比**当时**的路径低多少倍？（35年是一个半衰期。）
::: solution
一个半衰期关闭**对数**缺口的一半，故倍数缺口从8降到$8^{1/2}\approx 2.83$。该国仍几乎比自己的移动目标穷三倍。目标本身已增长$(1.02)^{35}\approx 2.00$，故该国的$y$在35年里增长了$2 \times (8/2.83) = 5.65$倍——很快，并且赶超并未完成。
:::
:::

::: exercise 教科书索洛系数 {level=1}
若$\alpha=1/3$，[[#eq-mrw]]对$\ln s$与$\ln(n+g+\delta)$上的系数预测什么？
::: solution
$\alpha/(1-\alpha)=1/2$。$\ln s$上的系数为$0.5$；$\ln(n+g+\delta)$上为$-0.5$。
:::
:::

::: exercise 扩展弹性 {level=2}
在[[#eq-aug]]中取$\alpha=\beta=1/3$。(a) 写出$\ln s_k$、$\ln s_h$与$\ln(n+g+\delta)$上的三个系数。(b) 若$s_h$加倍，长期$y$上升多少倍？(c) 为什么$\ln(n+g+\delta)$上的系数等于另外两个之和的相反数？
::: solution
(a) $\ln s_k$上为$\alpha/(1-\alpha-\beta)=1$；$\ln s_h$上为$\beta/(1-\alpha-\beta)=1$；$\ln(n+g+\delta)$上为$-(\alpha+\beta)/(1-\alpha-\beta)=-2$。(b) 2倍。(c) $s_k$、$s_h$与$n+g+\delta$以比值$s_k/(n+g+\delta)$与$s_h/(n+g+\delta)$进入。$(s_k, s_h, n+g+\delta)$上的零次齐次迫使三个系数之和为零。
:::
:::

::: exercise 广义资本与半衰期 {level=2}
教科书索洛，$n+g+\delta=0.075$。在$\alpha=1/3$与$\alpha=2/3$处计算$\lambda$与半衰期。哪个$\alpha$更接近Barro and Sala-i-Martin每年2%？
::: solution
$\lambda=(1-\alpha)(n+g+\delta)$。在$\alpha=1/3$处，$\lambda=(2/3)\times 0.075=0.050$，半衰期$13.9$年。在$\alpha=2/3$处，$\lambda=(1/3)\times 0.075=0.025$，半衰期$27.7$年。2%的估计更接近广义资本（或$\alpha+\beta=2/3$的扩展模型）。那是把“资本”当作不止建筑物与设备的一个理由，并且当问题是那些建筑物与设备上的租金时，不是忽略国民核算要素份额的理由。
:::
:::

::: exercise 图中的绝对对条件 {level=2}
A国有$s=0.3$，B国有$s=0.1$；它们共享$\alpha=1/3$、$n+g+\delta=0.08$，并且当前$y_A=y_B$，水平等于B的稳态。(a) 哪个国家低于自己的$y^*$？(b) 按索洛模型，近期谁增长更快？(c) 这个散点显示绝对趋同吗？
::: solution
(a) $y_A^*/y_B^* = (0.3/0.1)^{1/2}\approx 1.73$，故A低于自己的$y^*$而B**处于**自己的$y^*$。(b) A增长更快（转型增长）；B以$g$增长。(c) 不：它们有相同的当前$y$，因此增长对当前$y$的绝对趋同散点会在同一$x$值上放上两个不同的增长率。额外增长以$s$为条件。
:::
:::

::: exercise 德朗的选择要点 {level=3}
鲍莫尔的16国样本，大致是1979年富裕的国家。用几句话解释，为什么在该样本上用$\ln y_{1870}$估计$g_{1870\text{--}1979}$会偏向于发现绝对趋同，即使世界并没有趋同。你会想要怎样的样本？
::: hint
若一个国家1870年贫穷并且增长很快，它更可能进入“1979年富裕”的俱乐部；若它贫穷并且增长缓慢，它就缺失。
:::
::: solution
进入这16国与$y_{1979}$相关。在$y_{1870}$低的国家中，只有增长快的进入样本；增长慢的仍然贫穷并被排除。在$y_{1870}$高的国家中，增长快的与慢的在1979年都仍然足够富裕而被纳入（或至少更可能被纳入）。增长对初始收入的估计斜率因此过于为负：初始收入的左尾被剥去了失败者。人们想要的样本按**初始**条件定义（1870年有数据的所有国家，或在1960年定义的1960年横截面），而不是按结果。DeLong（1988）加入了1870年富裕但不在鲍莫尔16国中的国家，看着斜率变平。
:::
:::

::: exercise 奇迹太快 {level=3}
韩国人均GDP（麦迪森2023）从1960年的1548升到2019年的38936，59年里为25.2倍。设韩国一直以$\lambda=0.02$向一条美国式路径趋同，而该路径本身从1960年美国水平18057以2%增长。(a) 从1548起步，在那一运动定律下韩国2019年的水平会是多少？(b) 与38936比较。(c) 要使实际路径在索洛框架中成为可能，韩国的$y^*$、$A$或二者必须在发生什么？
::: hint
到移动目标$y^*(t)=y^*(0)e^{gt}$的缺口服从$\ln y(t)-\ln y^*(t) = e^{-\lambda t}(\ln y(0)-\ln y^*(0))$。
:::
::: solution
(a) $y^*(t) = 18057 \times e^{0.02 t}$，故$y^*(59)=18057\times e^{1.18}=18057\times 3.254=58{,}780$。1960年对数缺口为$\ln(1548/18057)=\ln 0.0857=-2.457$。59年后缺口为$e^{-0.02\times 59}\times(-2.457)=0.307\times(-2.457)=-0.755$，故$y(59)=y^*(59)\times e^{-0.755}=58780\times 0.470=27{,}630$。(b) 实际的38936远高于27630。(c) 韩国的稳态路径必须已经**升向**美国路径：$s$与$s_h$提高了，$n$下降了，并且/或者$A$赶上来了。以每年2%向**固定**OECD稳态的索洛转型不是奇迹。奇迹是稳态本身的移动——那是$A$故事、$s$故事或制度故事，而不是$\beta$趋同故事。
:::
:::
