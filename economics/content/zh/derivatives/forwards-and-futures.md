一位磨坊主约定六个月后磨麦，但现在还没有粮食。一位农民六个月后将收割小麦，但现在还不知道收割时的即期价格。双方都可以等待，接受届时实现的即期价格。双方也可以今天订立一份合约，约定六个月后按某个以货币单位计的每单位小麦价格交换。那份合约就是**远期**。任何一方都不必喜欢对方的生意；他们只需要更喜欢一个锁住的价格，而不是未锁住的价格。同一套逻辑，配上清算所、每日结算和标准化规模，就是**期货**合约。

本章用**现金-持有**为这些合约定价：一个复制组合持有标的、为它融资，并交割进合约。由此得到的价格是**持有成本**远期价格。它是相对价格。它说明在给定即期、利率以及标的的收入或仓储时，远期必须是多少。它并不说明即期本身应该是多少。通篇数字都是说明性的：即期$S = 100$，连续复利利率$r = 0.05$，期限$T$为一年或一个季度。它们不是报价，也不是建议去锁住价格、不锁住价格或表达看法。

本章的贴现建立在[[corporate-finance/time-value-of-money]]之上，无套利的含义建立在[[asset-pricing/stochastic-discount-factor]]之上。除非例题另有说明，利率均为连续复利。

## 远期与期货

:::definition 远期合约 {#def-forward}
**远期合约**是场外协议，约定在指定的**交割日**$T$，按订立时商定的**交割价格**$K$买入或卖出标的。同意买入的一方是**多头**；同意卖出的一方是**空头**。在$T$时，多头支付$K$并收到标的，或双方以现金结算差额。当$K$被设定为使合约价值为零时，订立时不交换任何款项。那个$K$就是**远期价格**$F_{0,T}$。
:::

现金结算的多头远期在$T$的支付是$S_T - K$。空头的支付是$K - S_T$。两者都对$S_T$线性。没有期权性：即使$S_T < K$，多头也有义务买入。这就是与看涨期权的全部区别，后者我们在[[derivatives/options]]中遇到。

远期是双边合约。每一方都承担对方的**对手方风险**：输掉$S_T - K$的那一方不付款的风险。抵押品、净额结算和信用支持附件是常见的法律回答；它们不在下面的定价公式里，把它们留在外面是建模选择，不是对每个交易台的描述。

:::definition 期货合约 {#def-futures}
**期货合约**是在交易所交易的标准化远期，有指定的标的、规模、交割月份和交割程序，通过**清算所**的**保证金账户**每日**盯市**。清算所是每一个多头和每一个空头的对手方。**期货价格**$G_{t,T}$是新订立的期货在当日结算后价值为零的交割价格。
:::

标准化使这两种合约作为市场对象而不同。芝加哥小麦期货写明等级、交割地点和乘数；想要略有不同等级的企业仍用该期货做套期保值，并承受本章稍后处理的**基差**风险。每日结算把单一支付$S_T - K$换成一串每日损益，会计上加总相同，但现金沿途支付。

:::example 现金结算远期 {#ex-cash-forward}
一份说明性远期以$K = 102$订立，标的在$T$时将值$S_T$。多头在$T$的现金结算是$S_T - 102$。计算$S_T = 110$和$S_T = 95$时的结算。谁付给谁？
:::solution
若$S_T = 110$，多头从空头收到$110 - 102 = 8$个货币单位。若$S_T = 95$，多头向空头支付$102 - 95 = 7$。合约不允许任何一方走开。这八个单位和七个单位是合约的支付，不是某条交易规则的利润，也不是对$S_T$的预测。
:::
:::

## 现金-持有定价

设标的是**投资资产**：为投资而持有，可以卖空，且不产生收入。金库中的黄金和不派息的股票是常见教科书情形。（确实派息的股票是下一节。）利率$r$为常数，且借贷相同。没有交易成本，也没有卖空限制。这些是下一结果的假定，而且它们是强的。

:::proposition 无收入投资资产的远期价格 {#prop-carry}
在具有常数连续复利无风险利率$r$、无交易成本、且标的多空头寸不受限制的市场中，即期为$S_0$、期限为$T$的不产生收入的投资资产的远期价格为

$$
F_{0,T} = S_0 e^{rT}.
$$ {#eq-carry}

若报价远期价格$F$不同于$S_0 e^{rT}$，则由标的、现金和远期组成的套利组合在每个状态下都有正支付，且今天的成本非正。
:::

:::proof
在$T$时拥有该资产的两种方式，今天必须花费相同。

**现金-持有。**借入$S_0$，买入资产，持有至$T$。在$T$时你欠$S_0 e^{rT}$并且拥有资产。以$F_{0,T}$订立空头远期，在$T$时按$F_{0,T}$卖出资产。锁住的所得是$F_{0,T} - S_0 e^{rT}$。为使这在为正时不构成套利，需要$F_{0,T} \le S_0 e^{rT}$。

**反向现金-持有。**卖空资产，把所得$S_0$贷出，并持有多头远期。在$T$时贷款已增至$S_0 e^{rT}$，多头远期按$F_{0,T}$交付资产，你归还资产以平掉空头。锁住的所得是$S_0 e^{rT} - F_{0,T}$。为使这在为正时不构成套利，需要$F_{0,T} \ge S_0 e^{rT}$。

两个不等式给出[[#eq-carry]]。若报价$F$严格高于$S_0 e^{rT}$，第一个组合（买资产、空远期、借$S_0$）今天成本为零，并在$T$支付$F - S_0 e^{rT} > 0$。若报价$F$严格更低，反向组合以相反符号做同样的事。所用假定：资产可以卖空且仓储无额外成本，现金可以按$r$借入和贷出，远期可以按$F$以一单位标的的规模订立。
:::

论证从未使用概率。远期价格不是预期即期。在[[asset-pricing/stochastic-discount-factor]]的风险中性测度下，确实有$\E^Q[S_T] = S_0 e^{rT}$，因而$F_{0,T} = \E^Q[S_T]$，但这是无套利的重述，不是物理测度下对$S_T$的预测。即期上的风险溢价住在物理漂移里；它已经在$S_0$中，不会在$F_{0,T}$里再出现一次。

:::example 教材数字 {#ex-house-forward}
取$S_0 = 100$，$r = 0.05$连续，$T = 1$。计算$F_{0,1}$。对$T = 0.25$和$T = 0.5$再算一次。
:::solution
对$T = 1$，

$$
F_{0,1} = 100\, e^{0.05} = 105.127
$$

到三位小数。对一个季度，$F_{0,0.25} = 100\, e^{0.05 \times 0.25} = 101.258$。对半年，$F_{0,0.5} = 100\, e^{0.05 \times 0.5} = 102.532$。每个数字都是：若你今天借$100$为购买资产融资，在$T$时会欠下的现金。它不是对未来即期的预测。
:::
:::

:::example 报价过高的远期 {#ex-arb-high}
即期为$100$，$r = 0.05$，$T = 1$，因而$S_0 e^{rT} = 105.127$。交易商报一年期远期为$108$。描述现金-持有交易以及在$T$锁住的现金。
:::solution
报价远期比复制成本高$2.873$。借$100$，买资产，并以$108$空远期。在$T$交割资产，收到$108$，偿还$105.127$。锁住的现金是$108 - 105.127 = 2.873$，不再留下净头寸。这$2.873$是[[#prop-carry]]模型中的套利利润。在市场中，它还得挺过买卖价差、借入的折扣，以及空头远期可能不付款。这些摩擦正是报价可以暂时偏离公式、而机器并不印钞票的原因。
:::
:::

:::intuition 远期是针对资产的预付贷款
用远期买资产就是赊购。信贷费用是$S_0(e^{rT} - 1)$。把这笔费用加到即期上就得到$F_{0,T}$。若资产在你等待时付给你收入，信贷费用缩小；若它让你付出仓储，费用增大。下一节的全部内容，一句话就是这样。
:::

:::quiz
在[[#prop-carry]]的市场中，不派息股票一年期远期价格在$S_0 = 100$、$r = 0.05$时为$105.127$。评论者说“市场预期该股一年后在$105.127$”。精确的陈述是什么？
- [ ] $S_1 = 105.127$以概率一成立
- [ ] 物理预测$\E^P[S_1]$等于$105.127$
- [x] 无套利远期等于$S_0 e^{rT}$；等价地$\E^Q[S_1] = 105.127$
- [ ] 该股被高估，因为$105.127 > 100$
:::solution
[[#eq-carry]]是相对定价恒等式。它并不钉住$S_1$，也不等于物理期望，除非风险溢价恰好为零。风险中性期望$\E^Q[S_1]$确实等于$105.127$，这是由$Q$的构造决定的。最后一项把融资后的未来购买与关于今天即期的陈述混为一谈。
:::
:::

## 收入、仓储与外国利率

对[[#eq-carry]]的三处调整覆盖了条款清单上出现的大多数标的。

:::proposition 带收益率、离散股利与仓储的持有成本 {#prop-carry-q}
假定[[#prop-carry]]的市场。

1. 若资产支付连续股利收益率$q$，则$F_{0,T} = S_0 e^{(r-q)T}$。
2. 若资产支付现值为$I$的离散股利，则$F_{0,T} = (S_0 - I) e^{rT}$。
3. 若持有资产花费连续仓储比例$u$，且资产是投资资产（可以卖空），则$F_{0,T} = S_0 e^{(r+u)T}$。

若资产是不能自由卖空的**消费商品**，现金-持有仍给出$F_{0,T} \le S_0 e^{(r+u)T}$。反向现金-持有不必可行，因而**便利收益**$y \ge 0$由$F_{0,T} = S_0 e^{(r+u-y)T}$定义，它是残差，不是单独观测到的现金流。
:::

:::proof
(1) 持有$e^{-qT}$单位资产的多头，股利再投资，在$T$时长成一单位。其今天的成本是$S_0 e^{-qT}$。为该成本融资，在$T$时产生$S_0 e^{(r-q)T}$，这必须等于$F_{0,T}$。

(2) 从即期减去已知股利的现值，得到价值为$S_0 - I$的不产生收入的或有权益。把[[#prop-carry]]用于该或有权益即得公式。

(3) 仓储是负股利。在(1)中把$q$换成$-u$，当反向现金-持有可行时给出$F_{0,T} = S_0 e^{(r+u)T}$。当不可行时——你无法从想把商品留在库存中的持有者那里借入商品——只剩下现金-持有不等式。便利收益就是使等式恢复的那个$y$；它度量期货市场所不能复制的实物库存的好处。
:::

:::example 离散股利 {#ex-discrete-div}
一只股票以$S_0 = 100$交易，并将在四分之一年后支付股利$2$。连续利率为$r = 0.05$。计算一年期远期价格。
:::solution
股利的现值是$I = 2\, e^{-0.05 \times 0.25} = 1.975$。除息股票的预付远期是$100 - 1.975 = 98.025$，并且

$$
F_{0,1} = 98.025\, e^{0.05} = 103.051
$$

到三位小数。若省略股利而用$100\, e^{0.05} = 105.127$，会高估远期：多头远期收不到这$2$。
:::
:::

:::example 投资商品上的仓储 {#ex-storage}
一种说明性商品以$S_0 = 80$交易，可以卖空，并花费连续仓储比例$u = 0.03$。在$r = 0.05$和$T = 0.5$下，计算远期价格。
:::solution
$$
F_{0,0.5} = 80\, e^{(0.05+0.03)\times 0.5} = 80\, e^{0.04} = 83.265
$$

到三位小数。指数中多出的$0.03$就是仓储。若该商品是持有者不愿意出借的消费品，这个数字会是*上界*，而不是价格。
:::
:::

外币是支付收益率的资产：外国无风险利率$r_f$。本国利率是$r$。若$S_0$是本国每单位外国的即期（例如每欧元的美元），远期就是**利率平价**价格

$$
F_{0,T} = S_0 e^{(r - r_f)T}.
$$ {#eq-irp}

复制组合是：借入外币，兑成本币，贷出本币，并用远期把外币买回来。这就是$q = r_f$的现金-持有论证。[[international-finance/exchange-rates]]中的抛补利率平价就是这一恒等式配上两种货币的票据；货币远期是把它补全的衍生品。

:::example 美元–欧元远期 {#ex-fx-forward}
即期为每欧元$S_0 = 1.10$美元，美元连续利率为$r = 0.05$，欧元连续利率为$r_f = 0.03$，$T = 1$。计算以美元每欧元计的一年期远期。
:::solution
$$
F_{0,1} = 1.10\, e^{(0.05-0.03)\times 1} = 1.10\, e^{0.02} = 1.1222
$$

到四位小数。美元利率更高，因而美元处于远期贴水：一欧元的未来交割要比即期交割花费更多美元。这$1.1222$是无套利兑换率，不是对明年即期的预测。
:::
:::

:::warning 把物理预测当作远期
常见混淆是令$F_{0,T} = \E^P[S_T]$，即物理预期即期。那只有在标的的风险溢价为零时才对，或者有人在风险中性下报期货价格而没有注意到。现金-持有并不问你认为$S_T$会是多少。它问的是用资产和银行账户制造$S_T$要花多少。谷物分析师的收割预测可以是$90$，而持有成本远期是$105$；两个数字都可以内部一致，因为它们回答不同的问题。
:::

:::widget plot
f: s*exp((r-q)*x)
sliders: s=100:50:150:1; r=0.05:0:0.12:0.005; q=0:0:0.08:0.005
x: 0, 2
y: 40, 180
labels: \text{远期价格}
caption: 公式$F = S e^{(r-q)T}$对期限$T$（横轴），带即期、利率和收益率滑块。把$q$升向$r$，曲线变平；固定$q$升高$r$，曲线变陡。曲线是制造交割的成本，不是即期的路径。
:::

一份*既有*多头远期、在当前远期为$F_{t,T}$时以$K$订立，其价值是差额的现值：

$$
V_t = e^{-r(T-t)}\bigl(F_{t,T} - K\bigr) = S_t e^{-q(T-t)} - K e^{-r(T-t)}.
$$ {#eq-fwd-value}

订立时选择$K = F_{0,T}$使$V_0 = 0$。此后$V$随贴现远期一对一变动。期货则相反，每天重置，使价值回到零；损益住在保证金账户里。

## 盯市

期货每日盯市。令$G_{t,T}$为$t$时期限$T$的期货价格。昨天以$G_{t-\Delta,T}$订立的多头，今天在保证金账户中收到$G_{t,T} - G_{t-\Delta,T}$（每单位标的），然后处于新价格$G_{t,T}$的合约中。在合约存续期内，这些每日金额之和是$G_{T,T} - G_{0,T}$。到期时$G_{T,T} = S_T$（或约定的结算指数），因而累计现金是$S_T - G_{0,T}$，与以$G_{0,T}$订立的远期总额相同。现金的*时点*并不相同。

当利率随期货价格变动时，这时点就重要。若每日盈利恰好在期货高时能以高利率再投资，则多头期货比同一交割价格的多头远期更有价值。当利率是确定性的，两个价格重合：$G_{0,T} = F_{0,T}$。当利率随机且与期货正相关时，期货价格略高于远期价格（**盯市**或**凸性**调整）。对短期限的股票与商品期货，这一差距通常当作二阶；对长期限利率期货，它是被报价的调整。本课程除非后面的例子另有说明，都用$G = F$。

保证金是履约担保，不是对标的的首付。**初始保证金**在进入时缴纳；**变动保证金**是每日盯市；**维持保证金**是账户必须补足的下限。数字由清算所设定，并随波动率变化。它们是信用风险控制。它们不是[[#eq-carry]]的输入。

:::application 磨坊主锁定的购买，两种合约
六个月后需要$100{,}000$蒲式耳的磨坊主，可以用这$100{,}000$蒲式耳上的远期锁定买入价——双边、非标准化——或用以例如每张$5{,}000$蒲式耳、因而$20$张合约的上市小麦期货，并承受上市等级与磨坊主等级之间的基差。远期有对手方风险、流动性少。期货有每日现金流和基差风险。两种合约都不是“正确的套期保值”。每一种都是不同的剩余风险捆。本段的磨坊主是例题故事中的模型主体，不是在被告知该怎么做的读者。
:::

## 用期货套期保值

线性合约对冲线性暴露。令$Q_S$为即期头寸（多头持有为正，计划购买为负），$Q_F$为一张期货合约的规模，单位相同。持有$N$张多头期货（因而$N < 0$为空头）在短期限内给出损益

$$
\Delta\Pi = Q_S \Delta S + N Q_F \Delta G.
$$

若$\Delta G \approx \Delta S$，选择$N = -Q_S / Q_F$就抵消一阶变动。当期货是在相关但不同的标的上——股指期货对单只股票，取暖油期货对航空煤油——两次变动是不完全相关的。

:::definition 最小方差套期保值比率 {#def-hstar}
令$\sigma_S$和$\sigma_F$为套期保值期限内$\Delta S$和$\Delta G$的标准差，$\rho$为它们的相关系数。**最小方差套期保值比率**是

$$
h^* = \rho\,\frac{\sigma_S}{\sigma_F}.
$$ {#eq-hstar}

对应的期货合约张数，对规模为$Q_S$的即期头寸和合约规模$Q_F$，对多头即期（空头期货）是$N^* = - h^* Q_S / Q_F$，对计划购买则符号相反。剩余方差是$(1-\rho^2)\sigma_S^2 Q_S^2$。
:::

公式是把$\Delta S$对$\Delta G$回归的斜率。它是两变量模型中的事前方差计算。它并不保证下个月的损益会很小：$\rho$可以变，$\sigma_F$可以跳，而套期保值是线性的，许多真实暴露却不是。残差$(1-\rho^2)\sigma_S^2$就是**基差风险**。完全相关是特例$h^* = \sigma_S/\sigma_F$；完全一对一的标的是更进一步的特例$h^* = 1$。

:::example 说明性农业套期保值 {#ex-hedge-ratio}
一位模型农民将在收割时出售$100{,}000$蒲式耳。一张期货合约是$5{,}000$蒲式耳。在套期保值期限内，一组说明性校准是$\rho = 0.85$，$\sigma_S = 0.25$，$\sigma_F = 0.22$。计算$h^*$和$N^*$。
:::solution
$$
h^* = 0.85 \times \frac{0.25}{0.22} = 0.9659,
$$

到四位小数。农民在拥有未来出售的意义上是即期空头，因而套期保值是规模为

$$
\lvert N^*\rvert = 0.9659 \times \frac{100{,}000}{5{,}000} = 19.32
$$

张的*空头*期货头寸。上市市场不交易$0.32$张合约；最近的整数是$19$。剩余方差比例是$1 - \rho^2 = 1 - 0.7225 = 0.2775$，因而约$28\%$的即期方差仍然留下。这些数字是算过的回归，不是建议卖出十九张合约。
:::
:::

:::remark 套期保值是模型，而模型留下一些东西
交易成本、保证金现金流、税收、收割规模本身随机的可能，以及期货在收割前到期的可能，都在[[#eq-hstar]]之外。在$\Delta S$和$\Delta G$上最小方差的套期保值，在那些额外维度上仍可以是很大的损益。后面关于期权和[[derivatives/risk-management]]的章节处理非线性与尾部暴露；线性套期保值是第一句话，不是最后一句。
:::

:::quiz
计划购买标的，要用期货抵消。在[[#def-hstar]]的记号中，以$Q_S > 0$表示要买入的数量，哪种$N$的符号抵消即期上升？
- [ ] 空头期货（$N < 0$），因为套期保值总是空期货
- [x] 多头期货（$N > 0$），从而使更高的即期被期货盈利抵消
- [ ] $N = 0$，因为购买不是暴露
- [ ] 无论$\rho$如何，总有$N = Q_S / Q_F$
:::solution
计划购买在即期*上升*时亏钱。多头期货在期货上升时盈利。在$\rho > 0$时这就是抵消的符号。口号“套期保值者空期货”描述的是生产者，不是消费者。规模$h^* Q_S/Q_F$并不等于$Q_S/Q_F$，除非$\rho\,\sigma_S/\sigma_F = 1$。
:::
:::

## 证据

持有成本恒等式是无套利陈述，不是经验弹性，但交易这些合约的市场的*规模*是有记录的。

场外远期和互换在名义本金上主导上市期货。2025年6月末，国际清算银行报告场外衍生品未偿名义本金为846万亿美元，其中利率合约约占$79\%$，总市场价值为21.8万亿美元（国际清算银行场外衍生品统计，2025年11月评论）。外汇合约——多为远期和外汇掉期——名义本金为155万亿美元，其中约100万亿美元在一年内到期。名义本金计的是合约面额，不是风险：两份对冲的远期在名义本金上相加，在市场价值上抵消。总市场价值更适合衡量桌上实际有多少钱，而即便那也是重置成本快照，不是压力损失。

交易所交易的期货——十九世纪起CBOT的谷物、1972年起CME国际货币市场的货币、1980年代起的股指与利率期货——名义本金更小、信用更紧，因为清算所净额结算并收取保证金。短期限外汇与股票远期贴近利率平价这一经验规律，是关于普通时期流动性好的G10货币对的陈述；它不是关于每一种货币、每一个日期或每一次压力的定理。2008年后对抛补利率平价的偏离，记录在国际清算银行季评以及Du、Tepper和Verdelhan（《金融杂志》，2018）中，提醒[[#prop-carry]]的假定——不受限制的资产负债表、借贷同一个利率——作为对银行的描述可以失败。

商品远期的国别例子远不止芝加哥。大连商品交易所挂牌铁矿石和豆粕期货，是东亚钢铁与饲料的参考；印度大宗商品交易所挂牌贵金属与能源合约；约翰内斯堡交易所挂牌玉米。在每一种情形中，上市等级都不是每个生产者的等级，因而[[#def-hstar]]的套期保值比率才是关心的对象，而不是一对一恒等。

## 这通向哪里

一串远期就是**互换**：[[derivatives/swaps]]把固定对浮动的利率互换定价为远期利率协议的组合，把货币互换定价为一对债券。一旦允许支付非线性，同样的现金-持有想法就不再是静态的，[[derivatives/options]]从看涨和看跌开始。[[derivatives/binomial-model]]的二叉树将通过交易标的和与远期等价的现金头寸来制造期权，并在每个节点再平衡。自始至终，远期价格$F_{0,T} = S_0 e^{(r-q)T}$仍是风险中性测度下$S_T$的均值，并且是再下一章布莱克公式的自然计价单位。

:::history
**1848年，芝加哥期货交易所。**CBOT于1848年4月3日作为谷物现货市场成立；远期或“到货”合约几乎立刻开始在那里交易（美国商品期货交易委员会，《CFTC历史》）。**1865年。**1865年10月13日，CBOT通过了关于保证金与交割的正式规则，通常被当作标准化期货的标志。**1972年。**芝加哥商业交易所开设国际货币市场并挂牌货币期货，把同一套机器从谷物转到汇率。这一序列是标准化与清算的制度史，不是对企业该用哪种合约的排序。
:::

:::summary
- 远期是在日期$T$以执行价$K$交换标的的双边义务。期货是同一线性支付的标准化、每日保证金版本。
- 对无收入的投资资产，现金-持有给出$F_{0,T} = S_0 e^{rT}$。带连续收益率$q$时，$F_{0,T} = S_0 e^{(r-q)T}$。离散股利先从其现值从$S_0$中减去。
- 外币是收益率为$r_f$的资产：$F_{0,T} = S_0 e^{(r-r_f)T}$。投资商品上的仓储作为负收益率进入。
- 远期不是对$S_T$的物理预测。它是用资产和银行账户制造交割的成本。
- 当利率是确定性的，期货价格与远期价格重合。每日结算改变的是现金的*时点*，不是累计总额$S_T - G_{0,T}$。
- 最小方差套期保值比率$h^* = \rho\,\sigma_S/\sigma_F$是回归斜率。残差$1-\rho^2$是基差风险。公式是带有写明输入的模型，不是建议交易$N^*$张合约。
:::

## 习题

:::exercise 一年持有 {level=1 check="105.127"}
不派息股票有$S_0 = 100$。连续利率为$r = 0.05$。输入一年期远期价格到三位小数。（输入$F_{0,1}$。）
:::solution
[[#eq-carry]]给出$F_{0,1} = 100 e^{0.05} = 105.127$到三位小数，见[[#ex-house-forward]]。这个数字是该股的融资成本，不是对$S_1$的预测。
:::
:::

:::exercise 季度远期 {level=1 check="101.258"}
在同样的$S_0 = 100$和$r = 0.05$下，输入三个月远期价格到三位小数。
:::solution
$F_{0,0.25} = 100 e^{0.05 \times 0.25} = 100 e^{0.0125} = 101.258$到三位小数。
:::
:::

:::exercise 多头远期结算 {level=1 check="8"}
现金结算远期以$K = 102$订立。到期时$S_T = 110$。输入多头的结算，以货币单位计（正表示多头收到）。
:::solution
多头支付是$S_T - K = 110 - 102 = 8$。空头支付$8$。没有取消的选择。
:::
:::

:::exercise 股利调整 {level=2 check="103.051"}
价格为$100$的股票在四分之一年后支付股利$2$。在$r = 0.05$连续下，输入一年期远期价格到三位小数。
:::solution
$I = 2 e^{-0.05 \times 0.25} = 1.975$，然后$F = (100 - 1.975)e^{0.05} = 103.051$到三位小数，见[[#ex-discrete-div]]。用$105.127$会忽略多头远期收不到的股利。
:::
:::

:::exercise 美元–欧元平价 {level=2 check="1.1222"}
即期每欧元$1.10$美元，$r = 0.05$，$r_f = 0.03$，$T = 1$。输入以美元每欧元计的一年期远期，到四位小数。
:::solution
$F = 1.10 e^{0.02} = 1.1222$到四位小数，见[[#ex-fx-forward]]。更高的美元利率使美元处于远期贴水。
:::
:::

:::exercise 既有远期的价值 {level=2 check="4.877"}
一年期多头远期在$S_0 = 100$、$r = 0.05$、$q = 0$时以$K = 100$订立。输入它今天的价值，到三位小数。（输入$V_0$。）
:::solution
[[#eq-fwd-value]]在$t = 0$时给出$V_0 = 100 - 100 e^{-0.05} = 100 - 95.123 = 4.877$到三位小数。等价地$e^{-0.05}(105.127 - 100) = 4.877$。合约在远期意义上已不再平值：$K$位于$F_{0,1}$之下。
:::
:::

:::exercise 反向现金-持有 {level=3}
不派息投资资产上报价的一年期远期为$F = 102$，当时$S_0 = 100$、$r = 0.05$。证明反向现金-持有在$T$锁住正的现金额，并计算该金额到三位小数。陈述三个头寸。
:::hint
卖空资产，贷出所得，并做多便宜的远期。比较$S_0 e^{rT}$与$102$。
:::
:::solution
$S_0 e^{rT} = 105.127 > 102$。卖空一单位资产，贷出$100$，并以$102$订立多头远期。在$T$时贷款值$105.127$，远期按$102$买入资产，资产被归还以平掉空头。锁住的现金是$105.127 - 102 = 3.127$。三个头寸是：空资产、多现金（贷款）、多远期。若资产不能卖空，这一套利不在可行集中，报价$102$可以持续；那就是[[#prop-carry-q]]的消费商品情形。
:::
:::

:::exercise 套期保值比率算术 {level=3 check="19.32"}
在[[#ex-hedge-ratio]]中，$\rho = 0.85$，$\sigma_S = 0.25$，$\sigma_F = 0.22$，$Q_S = 100000$，$Q_F = 5000$。输入$\lvert N^*\rvert$到两位小数。然后在解答中计算剩余方差比例$1-\rho^2$。
:::hint
$h^* = \rho\,\sigma_S/\sigma_F$，然后$\lvert N^*\rvert = h^* Q_S / Q_F$。
:::
:::solution
$h^* = 0.85 \times 0.25 / 0.22 = 0.965909\ldots$，且$\lvert N^*\rvert = 0.965909 \times 20 = 19.32$到两位小数。剩余方差比例是$1 - 0.85^2 = 0.2775$。四舍五入到$19$张整合约是市场约束，不是公式的一部分。计算描述的是两变量方差，不是被推荐的交易。
:::
:::
