一家以浮动利率借款的企业，和另一家以固定利率借款的企业，可以约定支付对方的利息。协议之后，第一家企业是在互换上*支付固定*的浮动利率借款人；第二家是*支付浮动*的固定利率借款人。两笔贷款都没有再融资。互换是交换利息——并且常常交换两种货币本金——而不交换原债权人的旁侧合约。1981年由所罗门兄弟安排的IBM–世界银行货币互换，是这些旁侧合约在市场尺度上的惯常第一笔：世界银行发行美元，并接过IBM的瑞士法郎与德国马克票息。

本章用无套利为普通**利率互换**和**货币互换**定价，使用[[derivatives/forwards-and-futures]]的远期和[[asset-pricing/fixed-income]]的贴现曲线。互换是一串远期。一旦这一点可见，其平价利率就是远期利率的加权平均，而非平价互换是一包固定现金流，其价值从同一条曲线读出。说明性零息——一年$4\%$、两年$4.5\%$、三年$5\%$，年复利——是教材数字，不是报价的收益率曲线，也不是建议支付或收取固定。

## 互换交换什么

:::definition 利率互换 {#def-irs}
**普通利率互换**是一种合约：一方，即固定的**支付方**，在约定日期$t_1,\dots,t_n$对**名义本金**$N$支付固定利率$K$，并在同一名义本金上收取浮动利率（就教科书而言，是在每期期初重置、期末支付的单利）。另一方是固定的**收取方**。名义本金并不交换。互换通常以使合约价值为零的**平价互换利率**$R$发起。
:::

单期互换就是**远期利率协议**（FRA）：双方今天约定将适用于未来贷款期$[T, T+\tau]$的利率。现金结算时，FRA在贷款期*期初*的支付是贴现后的差额

$$
N\,\tau\,\frac{L - K}{1 + L\tau},
$$ {#eq-fra}

其中$L$是该期实现的单利浮动利率，$K$是约定利率。分母中的贴现是因为利息差额在期初而不是期末支付。多期互换是一串这样的FRA，每一期共用同一个$K$。

:::definition 货币互换 {#def-ccy-swap}
**货币互换**交换两种货币的利息，并且通常也按约定汇率交换名义本金。一种标准结构是：起初以$N_d$本币对$N_f$外币交换；各货币上的运行票息；到期时按同一名义本金再交换。经济上它是本币债券与外币债券的组合。
:::

仍出现在某些条款清单传说中的比较优势故事——A公司在美元上借得便宜，B公司在欧元上借得便宜，他们互换——是*动机*，不是定价公式。若两家企业都能进入两个市场，任何优势已经在两条收益率曲线里，互换按那些曲线定价。若一家企业在一个市场被配给，互换可以是绕过配给的办法；那是约束，不是套利。

:::example FRA现金结算 {#ex-fra}
名义本金$N = 1{,}000{,}000$，期限长度$\tau = 0.5$年，约定利率$K = 0.04$，实现的单利$L = 0.05$。计算收取浮动的一方的FRA支付，按[[#eq-fra]]在期初支付。
:::solution
$$
1{,}000{,}000 \times 0.5 \times \frac{0.05 - 0.04}{1 + 0.05\times 0.5} = 500{,}000 \times \frac{0.01}{1.025} = 4{,}878.05
$$

到两位小数。这$4{,}878$由浮动利率的空头支付。它是一百万元上贴现后的半年利息差额，不是对$L$的预测。
:::
:::

## 贴现因子与平价互换利率

令$Z(0,t)$为今天一单位现金在$t$的价格——**贴现因子**。对年复利零息$y_t$，$Z(0,t) = (1+y_t)^{-t}$。对连续零息$r_t$，$Z(0,t) = e^{-r_t t}$。支付单利并在最后一日支付名义本金的浮动利率票据，在重置日值平价：普通互换的浮动腿加上名义本金，就是浮动利率票据。

:::proposition 平价互换利率 {#prop-swap-rate}
在重置日，单位名义本金、在$t_i = i$（$i = 1,\dots,n$）年付、贴现因子为$Z_i = Z(0,t_i)$的普通互换，其平价固定利率为

$$
R = \frac{1 - Z_n}{\sum_{i=1}^{n} Z_i}.
$$ {#eq-swap-rate}

以非平价利率$K$ *收取*固定、名义本金为$N$的互换，其价值为

$$
V_{\mathrm{rec}} = N\bigl(K - R\bigr)\sum_{i=1}^{n} Z_i = N\Bigl(K \sum_{i=1}^{n} Z_i - (1 - Z_n)\Bigr).
$$ {#eq-swap-value}

支付固定的价值是它的相反数。假定：浮动腿是与支付日匹配的标准单利，没有违约，贴现曲线是为两条腿估值所用的曲线（单曲线世界）。
:::

:::proof
在重置日，浮动腿加名义本金值平价，因而浮动加$N$的现值是$N$。名义本金在$t_n$的现值是$N Z_n$。因此浮动票息的现值是$N(1 - Z_n)$。固定票息$N K$的现值是$N K \sum_i Z_i$。令它们相等给出[[#eq-swap-rate]]中的$K = R$。对非平价$K$，两个现值之差是[[#eq-swap-value]]。同一套代数是：收取方互换等于以$K$订立的多头固定利率债券减去多头浮动利率债券，两者名义本金都是$N$；浮动债券值$N$，固定债券值$N K \sum Z_i + N Z_n$。
:::

分母$\sum Z_i$是互换的**年金**或**水平**，有时写成$A$。于是$R = (1-Z_n)/A$且$V_{\mathrm{rec}} = N(K-R)A$。在2008年后的多曲线世界中，人们在隔夜指数互换曲线上贴现，并从另一条曲线（LIBOR，随后SOFR或其他隔夜利率）投影浮动利率。单曲线公式仍是正确的第一幅图；额外的曲线是第二个输入，不是不同的想法。

:::example 三个年付零息 {#ex-par-swap}
年复利零息收益率为$y_1 = 0.04$，$y_2 = 0.045$，$y_3 = 0.05$。计算$Z_1, Z_2, Z_3$以及年付的三年平价互换利率$R$。
:::solution
$$
Z_1 = \frac{1}{1.04} = 0.961538,\qquad
Z_2 = \frac{1}{1.045^2} = 0.915730,\qquad
Z_3 = \frac{1}{1.05^3} = 0.863838,
$$

到六位小数。年金是$A = 0.961538 + 0.915730 + 0.863838 = 2.741106$，并且

$$
R = \frac{1 - 0.863838}{2.741106} = \frac{0.136162}{2.741106} = 0.049674,
$$

即$4.9674\%$。平价利率位于一年与三年零息之间，作为远期的加权平均必须如此。
:::
:::

:::example 非平价价值 {#ex-off-market}
在[[#ex-par-swap]]的曲线上，名义本金$N = 1{,}000{,}000$的三年互换以$K = 0.04$收取固定。计算对收取方的价值。
:::solution
$R = 0.049674$且$A = 2.741106$，因而

$$
V_{\mathrm{rec}} = 1{,}000{,}000 \times (0.04 - 0.049674) \times 2.741106 = -26{,}518
$$

到最接近的货币单位。收取$4\%$的一方在把平价定为$4.967\%$的曲线上低于平价，互换对该方约值$-26{,}518$。支付$4\%$的一方持有相反价值$+26{,}518$。这些是说明性曲线上的模型价值，不是报价。
:::
:::

:::widget plot

x: 0.02, 0.08

:::

控件是$K$的直线：在固定曲线上，$V$对$K$线性。$K$的每一个基点在这条曲线上值$N \times 0.0001 \times A \approx 274$个货币单位。这$274$就是互换的**PV01**。

远期利率是由两个贴现隐含的利率。$(t_{i-1}, t_i)$上的单利远期是

$$
F_i = \frac{1}{\tau_i}\left(\frac{Z_{i-1}}{Z_i} - 1\right),
$$

其中$Z_0 = 1$。平价互换利率是远期的年金加权平均，

$$
R = \frac{\sum_i \tau_i Z_i F_i}{\sum_i \tau_i Z_i},
$$

这是改写的[[#eq-swap-rate]]。通过在$Q$下取预期浮动票息的现值来为互换定价，是同一计算，因为风险中性预期浮动利率就是远期。

:::example 进入第三年的一年远期 {#ex-fwd-23}
在连续零息曲线$r_1 = 0.04$，$r_2 = 0.045$，$r_3 = 0.05$上，计算$Z_2$、$Z_3$、从第二年到第三年的单利一年远期，以及同一时期的连续复利远期。
:::solution
$Z_2 = e^{-0.045\times 2} = 0.913931$，$Z_3 = e^{-0.05\times 3} = 0.860708$。单利远期是

$$
F_{2,3} = \frac{Z_2}{Z_3} - 1 = \frac{0.913931}{0.860708} - 1 = 0.06184,
$$

约$6.184\%$。连续复利远期是$(3\times 0.05 - 2\times 0.045)/1 = 0.06$。两种复利惯例不同；条款清单会写明一种。
:::
:::

:::quiz
普通三年互换在[[#ex-par-swap]]的曲线上平价利率为$R = 0.049674$。评论者说互换“把$4.9674\%$锁住三年，因而三年零息必须是$4.9674\%$”。错在哪里？
- [ ] 没有错：$R$就是三年零息
- [x] $R$是远期的年金加权平均，不是零息收益率$y_3$
- [ ] $R$总是高于曲线上每一个零息收益率
- [ ] $R$是对未来政策利率的物理预测
:::solution
这里$y_3 = 0.05$而$R = 0.049674$。它们在短而相当平坦的曲线上接近，但并不相等。[[#eq-swap-rate]]用贴现之和去除$1-Z_n$，而不是用$n Z_n$。互换利率不是对未来央行利率的预测。
:::
:::

## 作为两只债券的货币互换

在即期$S_0$（本币每单位外币）交换名义本金$N_d$与$N_f$、并在$T$再交换、带运行票息$c_d$和$c_f$的货币互换，对支付外币、收取本币的一方，价值为

$$
V = B_d - S_0 B_f,
$$ {#eq-ccy-swap}

其中$B_d$是带票息$c_d$和本金$N_d$的本币债券，$B_f$是带票息$c_f$和本金$N_f$的外币债券，各自在自己的曲线上贴现。订立时选择名义本金使$N_d = S_0 N_f$，并选择票息使$V = 0$。此后每只债券在其曲线上盯市，即期外汇通过$S_0 B_f$项移动$V$。

1981年8月的IBM–世界银行互换属于这一类：IBM有未偿的瑞士法郎与德国马克负债，想要美元负债；世界银行可以发行美元，想要欧洲货币。所罗门兄弟匹配了票息和初始交换。完整时间表从未全文公布；教科书重构（例如基于罗特伯格（Rotberg）叙述的休斯顿大学案例）把它当作一对债券外加对结算缺口的短期限外汇套期保值。定价恒等式是[[#eq-ccy-swap]]，不是比较优势的传说。

:::example 两债券估值 {#ex-two-bonds}
本币名义本金$N_d = 100$，外币名义本金$N_f = 80$，即期$S_0 = 1.25$本币每单位外币。本币债券（票息加本金，已贴现）值$B_d = 102$；外币债券值$B_f = 79$。计算收取本币、支付外币一方的$V$。
:::solution
$V = 102 - 1.25 \times 79 = 102 - 98.75 = 3.25$。该组合对收取本币的一方实值$3.25$个本币单位。若即期跳到$1.30$而债券价格不变，$V$会变成$102 - 1.30\times 79 = -0.70$。货币互换的外汇暴露是外币债券，不是单单名义本金。
:::
:::

:::warning 把名义本当作仅仅名义本金
因为普通*利率*互换不交换名义本金，学生有时也从*货币*互换中丢掉名义本金。那抹掉了$T$时的本金交换，而这是合约中最大的现金流。[[#eq-ccy-swap]]把它算进去：$B_d$和$B_f$包含本金。相关错误是把两条腿都在本币曲线上贴现。外币票息是外币现金，必须按外币利率贴现，然后按*即期*兑换，而不是按历史汇率。
:::

## 用途，以及模型留下什么

互换可以把浮动利率贷款的利率暴露变成固定利率贷款的暴露，或反过来，而不必提前偿还贷款。货币互换可以改变负债的货币。在两种情形中，互换都是资产负债表头寸之上的衍生品；它并不让原债权人退出。比较优势故事、税收故事和监管套利故事都被用来解释为什么两个名字会互换。其中一些故事对特定交易是真的。一旦两条贴现曲线和即期外汇给定，它们都不是定价输入。

单曲线、无违约模型现在在市场中留下的是一阶的东西。**对手方风险**是输掉$V$的一方违约的风险；**信用估值调整**（CVA）是该风险的市场价格，在[[derivatives/credit-derivatives]]中与信用衍生品一起处理。**抵押品**和**初始保证金**改变贴现（OIS贴现，然后是融资估值调整）。在LIBOR–OIS利差成为常态而不是危机尖峰之后，对浮动利率的**多曲线**投影意味着$R$在单一$Z$上不再恰好是$(1-Z_n)/A$。二十国集团在2009年后推动的通过中央对手方的**压缩与清算**，把一张双边$V$的网换成清算的变动保证金流。[[#prop-swap-rate]]的代数仍是骨架。血肉是那些调整。

:::intuition 互换是共用一个执行价的一串远期
普通IRS的每一期都是一份FRA。迫使每一份FRA共用同一个$K$，才使互换成为互换，而不是一串分别订立的远期。平价$K$是整串合在一起价值为零的水平。非平价时，整串值年金乘以$K-R$。若你能为一份远确定价，你就能为互换定价；额外的工作是相加。
:::

:::application 带有浮动贷款的企业
一家模型企业在[[#ex-par-swap]]的曲线上有名义本金$1{,}000{,}000$的三年浮动利率贷款。以平价利率$R = 0.049674$订立支付方互换，在无违约单曲线观点下，把浮动票息换成固定的$4.9674\%$。贷款的债权人不变。互换的价值从零开始，然后在曲线移动时如[[#ex-off-market]]那样变动。企业更喜欢浮动、更喜欢固定、还是更喜欢什么都不做，是定价公式之外的风险偏好问题。本段是对现金流的描述，不是对企业或读者的建议。
:::

## 证据

利率合约是场外衍生品的主体。2025年6月末，国际清算银行报告场外利率名义本金约666万亿美元，其中互换是主导工具，以及外汇名义本金155万亿美元，其中直接远期和外汇掉期约85万亿美元、货币互换约45万亿美元（国际清算银行场外衍生品统计）。总市场价值小一个数量级：同日利率合约15.0万亿美元，外汇5.4万亿美元。中央对手方清算现在覆盖报告交易商中的大部分利率名义本金；国际清算银行表格把对手方分成报告交易商、其他金融机构、中央对手方和非金融客户。

2008年后LIBOR（及其后继）与隔夜指数互换之间的缺口是被测量的利差，不是脚注。Du、Tepper和Verdelhan（《金融杂志》，2018）记录了2008年后G10远期对抛补利率平价持续数十个基点的偏离；偏离与银行资产负债表成本对齐，而不是算术失败。单曲线教科书互换利率仍是用手算的正确对象。未经调整，它不是2020年代交易商的报价。

互换市场存在于美元和欧元之外的许多货币中。在岸人民币利率互换、印度MIBOR和孟买隔夜互换、巴西CDI互换，以及南非JIBAR互换，都是标准的本地工具。每一种都有本地计日惯例、本地定盘，并且常常有本地清算所。恒等式$R = (1-Z_n)/A$在翻译中存活；曲线构建惯例则不然。

## 这通向哪里

互换上的期权——**互换期权**——属于期权各章；欧式互换期权是未来某日对$V_{\mathrm{rec}}$的期权，带对数正态互换利率的布莱克公式是市场报价惯例。[[derivatives/credit-derivatives]]中的信用违约互换是浮动腿为违约的互换。为互换定价的贴现曲线也是进入二叉树和布莱克–斯科尔斯的那个$r$。不过首先，课程转向支付非线性的合约：[[derivatives/options]]。

:::history
**1981年，IBM与世界银行。**1981年8月，所罗门兄弟安排了IBM与世界银行之间的货币互换。世行发行美元债券（发行日8月11日，结算日8月25日），并接过IBM的瑞士法郎与德国马克票息义务；IBM接过美元票息。世界银行司库尤金·罗特伯格（Eugene Rotberg）和所罗门的约翰·罗森斯特赖希（John Rosenstreich）是与两张资产负债表匹配联系在一起的名字。1970年代较早的背对背贷款，部分用来绕过英国外汇管制，是法律上的祖先。1981年的交易通常被当作互换作为标准化场外产品的标志。随后的ISDA主协议（从1985年起，1992年和2002年文本仍在使用）把该产品变成了市场。
:::

:::summary
- 普通利率互换在本身并不交换的名义本金上，用固定票息$K$交换浮动票息。单期互换是FRA；多期互换是共用一个$K$的一串FRA。
- 在重置日，平价互换利率是$R = (1-Z_n)/\sum Z_i$。非平价时，$V_{\mathrm{rec}} = N(K-R)A$。
- 平价利率是远期利率的年金加权平均，不是$n$年零息，也不是对政策利率的预测。
- 货币互换是本币债券减去即期乘以外币债券。名义本金*确实*交换；丢掉它们是错误。
- 单曲线、无违约估值是骨架。CVA、抵押品、多曲线投影和清算是2020年代报价的血肉。
- 说明性零息$4\%$、$4.5\%$、$5\%$给出$R = 4.967\%$以及一百万$4\%$收取方约$-26{,}518$的非平价价值。那些数字是算过的曲线，不是市场。
:::

:::exercise 两债券货币互换 {level=3}
通过写出交换名义本金的货币互换的本币与外币现金流，各自在自己的曲线上贴现，并把外币现值按即期兑换，证明[[#eq-ccy-swap]]。然后，在$B_d = 102$，$B_f = 79$，$S_0 = 1.25$下，计算$V$并说明哪一方处于实值。
:::hint
若$N_d = S_0 N_f$，初始交换在订立时抵消，两只债券随后处于你被给定的价值$B_d$、$B_f$；此后它们不必抵消。
:::
:::solution
收取本币、支付外币的一方在$T$收取本币票息和$N_d$，并支付外币票息和$N_f$。（若初始交换仍须入账，则是$N_d$对$S_0 N_f$。）把本币流在本币曲线上贴现得到$B_d$。把外币流在外币曲线上贴现得到$B_f$单位外币，值$S_0 B_f$本币。相减给出$V = B_d - S_0 B_f$。用给定数字，$V = 102 - 1.25\times 79 = 3.25$，对本币收取方为实值。若名义本金被省略，$T$时的本金会从$B_d$和$B_f$中缺失，那$3.25$就会是另一个错误的对象。
:::
:::

:::exercise PV01与平行移动 {level=3 check="274"}
在说明性三年曲线上，$A = 2.741106$且$N = 1{,}000{,}000$。输入$K$上升一个基点时收取方价值的变化，到最接近的货币单位。然后在解答中解释，为何每一个远期利率*平行*上升一个基点会使$V_{\mathrm{rec}}$大约反向变动同样的金额。
:::hint
$\partial V_{\mathrm{rec}} / \partial K = N A$。远期的平行上升使$R$大约上升一个基点。
:::
:::solution
$N A \times 0.0001 = 1000000 \times 2.741106 \times 0.0001 = 274.11$，四舍五入为$274$。这是对$K$的PV01。因为$V_{\mathrm{rec}} = N(K-R)A$，且每一个单利远期平行上升一个基点会使$R$上升一个基点（对此加权恰好如此），同一个$274$以相反符号作为对曲线的DV01出现。这两个数字只对这一特定曲线的平行移动重合；提高三年远期并削减一年远期的扭曲，会使$R$按加权金额变动，不必是一个基点。这$274$是模型价值的导数，不是报价的买价。
:::
:::
