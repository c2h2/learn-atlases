2023年，世界跨边界运送了约24万亿美元的货物以及另外7.5万亿美元的商业服务（世界贸易组织，《全球贸易展望与统计》，2024年4月）。越南的电话与电子元器件出口可与其鞋类和稻米出口相匹敌；德国和法国彼此双向出售汽车；尼日利亚的原油从博尼和福卡多斯运出，而精炼汽油经拉各斯运回；新加坡的账面贸易是其国内生产总值的数倍。这些并非趣闻。它们是贸易理论必须面对的事实：谁与谁贸易、贸易什么，以及随着运送货物的成本和协调生产的成本下降，这些格局如何变化。

本章有条理地查看这些事实。它尚未解释它们。后面各章的模型——比较优势、要素禀赋、规模报酬、异质企业——是为匹配这里收集的规律而建立的。本章还引入**引力方程**，这是国际经济学中最可靠的单一经验关系，以及**产业间贸易**与**产业内贸易**的区分，后者将把古典理论与[[international-trade/new-trade-theory]]的新贸易理论分开。

在任何数字之前，先说一句关于度量的话。贸易统计由海关当局和统计局编制，再由世界贸易组织、联合国商品贸易统计数据库（UN Comtrade）、国际货币基金组织的《贸易方向统计》以及世界银行的世界发展指标汇编。货物在出口侧按离岸价格（f.o.b.）计价，在进口侧通常按到岸价格（c.i.f.，含成本、保险和运费）计价，因此世界记录的进口超过记录的出口，差额为运输与保险边际。服务按国际收支口径度量，更难观察。经新加坡、中国香港和荷兰等枢纽的转口会抬高这些经济体的贸易对国内生产总值比率头条数字。后文引用数字时，会标明来源与年份。

## 开放度与贸易构成

一国与世界市场接触的最简单概括是其**贸易对国内生产总值比率**：货物与服务出口加进口之和，再除以国内生产总值。因为出口和进口都在分子中，该比率可以超过100%——许多小型开放经济体确实如此。它是*暴露度*的度量，不是福利的度量。一国可以开放而贫穷，也可以相对封闭而富裕；美国在2023年的贸易对国内生产总值比率接近25%，实际收入却很高，而若干低收入经济体的比率在50%以上（世界银行世界发展指标，指标NE.TRD.GNFS.ZS，2026年访问）。

::: definition 贸易对国内生产总值比率 {#def-openness}
一国在给定年份的**贸易对国内生产总值比率**是$(X + M)/Y$，其中$X$是货物与服务出口，$M$是货物与服务进口，$Y$是国内生产总值，均按现价和同一货币计。**出口对国内生产总值比率**是$X/Y$。这两个比率都不是福利指数：它们随国家规模、生产中可贸易品的份额，以及加工贸易与转口的普遍程度而缩放。
:::

世界贸易相对世界国内生产总值从1970年的约26%上升到2008年的略高于60%，随后走平。2023年世界比率约为58%（世界银行世界发展指标，2026年访问）。2008年之后的平台——有时被称为货物贸易的**缓慢全球化**——与金融危机、中国加工贸易繁荣的成熟，以及后来贸易政策不确定性的上升同时发生。服务贸易，尤其是以数字方式交付的服务，作为总额中的份额继续增长：2023年商业服务约占世界货物与服务贸易的25%，高于2022年的22%（世界贸易组织，2024年）。

规模重要。大型经济体贸易占国内生产总值的较小份额，因为更多需求可以在国内满足；这是美国、日本和巴西在比利时、越南或莱索托旁边显得“封闭”的原因之一。地理也重要：撒哈拉以南非洲和中亚的内陆国家面临更高的运输成本，在其他条件相同下贸易比率更低。自然资源禀赋即使不主导贸易*规模*，也会塑造贸易的*构成*：原油和天然气仍占尼日利亚、安哥拉、卡塔尔和挪威出口的大部分；智利的铜和锂；巴西的大豆、铁矿石和原油；澳大利亚的铁矿石和煤炭（联合国商品贸易统计数据库与各国统计局，近年）。

::: example 三个贸易对国内生产总值比率 {#ex-openness}
在某一年，A国的国内生产总值是2000亿货币单位，货物与服务出口400亿，进口350亿。B国是较小的加工枢纽，国内生产总值400亿，出口520亿，进口500亿。C国是大型大陆经济体，国内生产总值8000亿，出口1000亿，进口1200亿。计算各国的贸易对国内生产总值比率。按这一度量哪国最“开放”，这一排序*没有*告诉你什么？
::: solution
A国：$(400 + 350)/2000 = 0.375$，即37.5%。

B国：$(520 + 500)/400 = 2.55$，即255%。

C国：$(1000 + 1200)/8000 = 0.275$，即27.5%。

按这一定义B最开放，然后是A，然后是C。排序并不说明B的居民境况更好、B的关税更低，或B有更大的*贸易利益*。B的比率被到了又离开的货物的重复计算抬高；C的低比率是大型本土市场的算术。福利比较需要实际收入，而不是贸易比率——[[principles/gains-from-trade]]已经强调过这一点，[[international-trade/ricardian-model]]中的李嘉图模型将把它说精确。
:::
:::

货物贸易的商品构成在几十年中发生了变化。1960年初级产品（食品、燃料、矿石）占世界出口的很大份额；到2010年代制成品占主导，机械、电子和运输设备居于中心，不过当油价跳升时燃料的价值仍会飙升（世界贸易组织《世界贸易统计评论》，各年）。贸易的**扩展边际**——新产品和新的伙伴对——是增长的重要部分，与现有伙伴对中更多贸易的**集约边际**并列（Kehoe和Ruhl 2013年记录了若干自由化中的扩展边际）。服务——运输、旅行、金融、专业、电信——随着通信成本下降变得更可贸易，理查德·鲍德温（Richard Baldwin）把这一主题组织为生产的“第二次拆分”（《大收敛》，2016年）。

第二种切分是按伙伴。区域内贸易在欧洲很高，欧洲联盟的单一市场和密集的供应链网络使德国、法国、意大利和荷兰互为最大伙伴。在北美，它在美墨加协定（USMCA，原北美自由贸易协定）下也很高。东亚和东南亚已成为它们自己的制造回路：零部件在中国、日本、韩国、中国台湾、越南、泰国和马来西亚跨境多次，然后制成品运往最终消费者。非洲内部货物贸易占非洲总贸易的份额仍小于欧洲或亚洲的相应份额，这是非洲大陆自由贸易区（AfCFTA）的陈述动机之一，其法律文书于2019年生效。拉丁美洲的区域内份额介于非洲与欧洲之间；巴西和阿根廷彼此贸易不少，也与中国、美国和欧洲联盟贸易。

::: example 共同语言与引力 {#ex-language}
一项对数引力回归，在$\theta = 1$时发现，共同官方语言在其他条件相同时与多出0.5个对数点的贸易相联系——乘数为$e^{0.5} \approx 1.65$。两个在其他方面相同的国家对，一对共享语言、一对不共享，预测贸易分别为100亿和多少？把0.5当作偏相关（Head和Mayer 2014年综述了这类系数），而不是采用一种语言的因果效应。
::: solution
语言对的预测贸易是$10 \times e^{0.5} \approx 10 \times 1.649 = 16.49$十亿。距离、国内生产总值和残差按构造被固定。仅凭这一系数，一个把某种语言定为官方语言的政府并不能保证贸易上升65%：语言虚拟变量会拾取殖民史、法律渊源和不可观察的口味相关，以及翻译成本。这个数字是引力拟合中的*其他条件不变*的关联。
:::
:::

::: warning 贸易比率不是福利排序
一个常见失误是把$(X+M)/Y$当作分数，仿佛更多贸易总是更好、更少总是更差。该比率会因与效率无关的原因而变动：衰退使国内生产总值比贸易下降更快时*提高*该比率；同时提高出口价值和国内生产总值的大宗商品繁荣可以把它推向任一方向；经枢纽的转口会抬高它。后面各章的贸易利益定理是关于实际收入和消费可能性的陈述，而不是关于这一比率。新加坡高于300%的比率（世界银行世界发展指标，近年）和美国接近25%的比率是关于规模、转口活动和地理的事实。它们不是经济成功的排序。
:::

## 谁与谁贸易：引力方程

数据中最醒目的规律几乎是物理的。大型经济体彼此贸易多于小型经济体；邻国贸易多于遥远的国家对；共同语言、前殖民联系、共享边界和贸易协定在其他条件相同时各自提高双边贸易。扬·丁伯根（Jan Tinbergen）在《塑造世界经济》（1962年）中写下与牛顿万有引力定律的类比：“质量”是国内生产总值，“距离”是地理距离，“力”是双边贸易额。类比是隐喻。经验关系不是。

::: definition 引力方程 {#def-gravity}
从出口方$i$到进口方$j$的贸易额$T_{ij}$的**引力方程**取形式

$$
T_{ij} = G \cdot \frac{Y_i^{\alpha}\, Y_j^{\beta}}{D_{ij}^{\theta}} \cdot \varepsilon_{ij},
$$ {#eq-gravity}

其中$Y_i$和$Y_j$是经济规模（通常是国内生产总值），$D_{ij}$是双边阻力的度量（通常是大圆距离，有时由关税、语言和边界增强），$G$是给定年份对所有国家对共同的因子，$\varepsilon_{ij}$是残差，$\alpha$、$\beta$、$\theta > 0$是弹性。取对数后，

$$
\ln T_{ij} = \ln G + \alpha \ln Y_i + \beta \ln Y_j - \theta \ln D_{ij} + \ln \varepsilon_{ij}.
$$

**结构引力**方程，在Anderson和van Wincoop（2003年）的意义上，用依赖于*每一个*国家对*每一个*其他国家的壁垒的出口方和进口方**多边阻力**项替换单一的$G$。
:::

朴素形式[[#eq-gravity]]已经相当好地拟合双边贸易。Head和Mayer的手册章节（2014年）综述了数十年的估计：一旦设定仔细，贸易对距离的弹性通常接近$-1$，不过已发表数字约在$-0.7$到$-1.5$之间，取决于样本、年份以及是否纳入零贸易对。国内生产总值上的弹性接近1。共享语言、殖民史和自由贸易协定作为$D_{ij}$的移动项（或作为单独的虚拟变量）进入，并与更高的贸易相联系。这些是打扮成回归的会计恒等式中的偏相关；它们本身并不是修建铁路或签署条约的因果效应。下面的警告会回到这一点。

引力为何应当成立？三类模型给出它，它们将出现在后面的章节。**阿明顿**需求系统中，每个国家生产一个独特品种，消费者具有替代弹性不变（CES）偏好，从而得到带有多边阻力的引力方程（Anderson 1979年；Anderson和van Wincoop 2003年）。带有规模报酬的**垄断竞争**，如Krugman（1980年）和[[international-trade/new-trade-theory]]的新贸易理论，给出类似形式。Melitz（2003年）一系的**异质企业**模型，在[[international-trade/firms-in-trade]]中研究，即使只有一部分企业向每个目的地出口，也为加总双边贸易给出引力。在所有三类中，距离弹性$\theta$与品种间的替代弹性相联系：更可替代的商品意味着很小的成本劣势会摧毁更多贸易。

::: proposition 来自CES需求的引力 {#prop-ces-gravity}
设每个国家$i$生产一个独特品种，$j$中的消费者对品种具有弹性$\sigma > 1$的CES偏好，从$i$到$j$的冰山贸易成本为$\tau_{ij} \ge 1$（货物的份额$\tau_{ij}-1$在运输中“融化”）。则$i$对$j$的销售额为

$$
T_{ij} = \frac{Y_i\, Y_j}{Y^W} \left(\frac{\tau_{ij}}{P_i\,\Pi_j}\right)^{1-\sigma},
$$

其中$Y^W$是世界国内生产总值，$P_i$、$\Pi_j$是价格指数——多边阻力项——它们依赖于世界所有贸易成本。假设：CES需求，每国一个品种（或一连续统的对称企业），冰山成本，以及市场出清。这是理论关系，不是估计的弹性。
:::

::: proof
CES需求意味着$j$在$i$的品种上的支出是$T_{ij} = \bigl(p_{ij}/P_j\bigr)^{1-\sigma} Y_j$，其中$p_{ij} = p_i \tau_{ij}$是到岸价格，$P_j$是$j$中的CES价格指数。$i$的产出的市场出清要求$Y_i = \sum_k T_{ik}$。代入并整理得到依赖于$i$进入所有市场的通路的项$P_i^{1-\sigma}$。按Anderson和van Wincoop（2003年）定义向内和向外的多边阻力指数$P_j$和$\Pi_i$，即得所示引力方程。距离弹性是$1-\sigma$乘以$\tau_{ij}$对距离的弹性：若$\tau_{ij} = D_{ij}^{\rho}$，则$\theta = (\sigma-1)\rho$。
:::

多边阻力项是深层要点。法国与德国之间的贸易不仅依赖于法国和德国的国内生产总值以及巴黎到柏林的距离，还依赖于各自对与*所有其他人*贸易的阻力有多大。如果与世界其余部分贸易变得更便宜，法德贸易即使彼此之间毫无变化也会下降——这是替代效应。Anderson和van Wincoop（2003年）表明，省略这些项会使边界的估计效应产生偏误；他们著名的“边界之谜”计算使用1993年加拿大–美国数据，发现国家边界使美国和加拿大省份之间的贸易减少的程度远大于仅由距离所暗示的，但小于McCallum（1995年）忽略多边阻力的较早估计。

::: example 一项引力比较 {#ex-gravity-numbers}
两个进口方$B$和$C$具有相同的国内生产总值。出口方$A$的国内生产总值也给定。距离$D_{AC}$是$D_{AB}$的四倍。用[[#eq-gravity]]且$\alpha = \beta = 1$并忽略残差，计算当距离弹性为$\theta = 1$和当它为$\theta = 1.5$时的比率$T_{AB}/T_{AC}$。（在下面同一形式的习题中输入$\theta = 1.5$时的比率。）
::: solution
在两个进口方国内生产总值相等且出口方规模共同的情况下，

$$
\frac{T_{AB}}{T_{AC}} = \left(\frac{D_{AC}}{D_{AB}}\right)^{\theta} = 4^{\theta}.
$$

对$\theta = 1$比率为$4$。对$\theta = 1.5$它是$4^{3/2} = 8$。大50%的距离弹性使四倍距离的隐含惩罚加倍。这就是$\theta$是*贸易成本*弹性、而不是纯粹地理事实的含义：同样的公里数在商品更可替代或每公里运输更昂贵时摧毁更多贸易。
:::
:::

::: quiz
在朴素引力方程$T_{ij} \propto Y_i Y_j / D_{ij}^{\theta}$中，若两国国内生产总值都加倍而距离不变，则$i$与$j$之间的预测贸易会怎样？
- [ ] 不变，因为引力只依赖于距离
- [x] 变为四倍
- [ ] 加倍
- [ ] 下降，因为更大的国家更自给自足
::: solution
在$\alpha = \beta = 1$时，$T_{ij}$与两国国内生产总值的*乘积*成比例。两者都加倍使乘积乘以4。（大国的确贸易占国内生产总值的较小*份额*，那是关于$T_{ij}/Y_i$的陈述，不是关于$T_{ij}$本身。双边贸易*水平*的引力与*开放度*的规模格局是一致的：两倍大的国家按绝对额贸易更多，作为其自身国内生产总值的份额则更少，因为更多伙伴在效果上是它自己的地区。）
:::

引力中的距离是一束成本的替身：运费、时间、信息、合同执行、口味差异以及政策。Hummels（2007年）记录了1950年代以来航空货运的下降以及海运较慢的下降；集装箱由马尔科姆·麦克莱恩（Malcolm McLean）的“理想X号”于1956年引入商业航程，削减了装卸成本和损坏，并使门到门多式联运成为常规。通信成本比运费下降得更快。Baldwin（2016年）主张，使工厂得以跨边界拆分的是廉价协调，而不仅仅是廉价航运——这就是[[international-trade/firms-in-trade]]的全球价值链。政策也是$D_{ij}$的一部分：在最简单的模型中，10%的关税是10%的冰山成本，而非关税壁垒可以更大。

::: warning 引力系数并不自动具有因果性
把$\ln T_{ij}$对$\ln D_{ij}$以及$\ln Y_i$、$\ln Y_j$回归是在描述数据。它本身并不说明如果政府修建铁路、加入贸易协定或征收关税会发生什么。距离并非随机分配；相近的国家往往共享语言、法律渊源和不可观察的口味。国内生产总值对贸易是内生的。经验文献用结构引力、国家对固定效应以及准实验变异（苏伊士运河的开通、1967年苏伊士的关闭、航空交通自由化、铁幕的倒塌）处理这些问题。本课程引用引力弹性时，引用的是*偏相关*或*按结构解释的*弹性，并会说明区分。不要把$-1$的距离系数读成“建一座港口贸易就会加倍”。
:::

## 产业间贸易与产业内贸易

从李嘉图到赫克歇尔–俄林的古典贸易理论是**产业间贸易**的理论：葡萄牙出口葡萄酒、进口布匹；土地丰裕的国家出口食品、进口制成品；技能丰裕的国家出口飞机、进口服装。世界贸易的很大份额看起来如此。智利的铜、赞比亚的铜、澳大利亚的铁矿石、沙特阿拉伯的原油、埃塞俄比亚的咖啡、孟加拉国的服装，以及德国的机床，都是要素禀赋和技术有助于解释的专业化。

很大份额*并不*看起来如此。德国向法国出口汽车，也从法国进口汽车。美国向欧洲联盟出口药品，也从欧洲联盟进口药品。韩国、日本、中国、墨西哥和美国来回运送电子元器件。Grubel和Lloyd（1975年）为这种相似产品的双向贸易提出了一个简单指数。

::: definition 产业内贸易与格鲁贝尔–劳埃德指数 {#def-gl}
两国在产品类别$k$中的贸易在双向流动的程度上是**产业内**的。类别$k$的**格鲁贝尔–劳埃德指数**是

$$
\mathrm{GL}_k = 1 - \frac{\lvert X_k - M_k \rvert}{X_k + M_k},
$$ {#eq-gl}

其中$X_k$和$M_k$是该类别中的出口和进口。当$X_k = M_k$时指数等于$1$（纯粹双向贸易），当贸易是单向时等于$0$。加总GL指数是各$\mathrm{GL}_k$的贸易加权平均。指数依赖于分类的精细程度：更细的类别产生更低的度量产业内贸易。
:::

产业内贸易在要素禀赋相似的高收入经济体之间、在差异化制成品中、以及在区域集团内部最高。它在同质初级产品中较低。这一格局是典型化事实，不是定理：正是这一事实推动Krugman（1979年、1980年）以及Helpman和Krugman（1985年）建立规模报酬与垄断竞争下的贸易模型，即[[international-trade/new-trade-theory]]的主题。那些模型在相似国家之间产生相似商品的双向贸易，这是2乘2形式的李嘉图和赫克歇尔–俄林模型做不到的。

::: example 计算格鲁贝尔–劳埃德指数 {#ex-gl}
某一年，一国与一伙伴在“机动汽车”上的贸易是出口400亿单位、进口300亿。在“原油”上同一对出口20亿、进口500亿。计算每个类别中的$\mathrm{GL}$。比较暗示了每种流量的何种可能解释？
::: solution
汽车：$\mathrm{GL} = 1 - \lvert 40-30 \rvert/(40+30) = 1 - 10/70 = 4/7 \approx 0.57$。

原油：$\mathrm{GL} = 1 - \lvert 2-50 \rvert/(2+50) = 1 - 48/52 = 4/52 \approx 0.077$。

汽车贸易在相当程度上是双向的；原油几乎是单向的。原油流量是要素禀赋（石油储量）所解释的那种产业间专业化。汽车流量是产品差异化、品牌、规模报酬和跨境生产网络所解释的那种——不是一国“有汽车”而另一国没有的故事。（0.57的GL远低于1：仍有汽车的净出口，其下可以坐落赫克歇尔–俄林或李嘉图的力量。）
:::
:::

垂直专业化模糊了这一区分。当墨西哥从美国进口发动机、组装汽车并把汽车再出口时，海关数据记录“车辆及零件”的双向贸易，即使底层生产链是一连串产业间步骤。Hummels、Ishii和Yi（2001年）以及后来经济合作与发展组织和世界贸易组织的**增加值贸易**（TiVA）统计试图剔除重复计算。按增加值口径，中国对美国的顺差小于按总额口径，因为一项中国出口往往含有日本、韩国、德国和美国的零件（Johnson和Noguera 2012年；Koopman、Wang和Wei 2014年）。总额流量仍是引力的正确对象（它们是越过边界的东西，也是关税所适用的东西）；增加值流量是询问谁*赚取了*收入的正确对象。

## 运输、通信与距离成本的变化

引力的距离弹性并未随着船舶变大和航空货运变便宜而消失。Disdier和Head（2008年）在对1467项估计的元分析中发现，在许多设定中，估计的距离效应在二十世纪下半叶*上升*了，这一结果并不像听起来那么悖论：随着政策壁垒下降，剩余摩擦——地理、时间、信息——占了所剩变异的更大份额。*已经*改变的是所贸易之物的构成以及生产如何组织。

三种成本下降值得分开。

**海运与集装箱。**大宗商品（从澳大利亚和巴西到中国的铁矿石，从波斯湾到东亚和欧洲的原油）由专门船舶运送，其实际运费率在二十世纪下降，在油价或港口拥堵跳升时出现尖峰（如2021–22年）。对制成品而言，集装箱使装卸标准化。“理想X号”1956年4月从纽瓦克到休斯顿的首次航程运载了58个集装箱；到2010年代，载箱量超过20000个二十英尺标准箱（TEU）的船舶停靠上海、新加坡、鹿特丹和洛杉矶。运费占制成品价值的份额在长途航线上现在往往是低个位数，不过对笨重低值货物以及非洲和中亚的内陆出口方仍是严重壁垒，后者还要支付内陆段（联合国贸易和发展会议《海运评论》，各年）。

**航空货运与准时制。**航空占世界贸易的份额按*重量*很小，按*价值*大得多。肯尼亚和哥伦比亚的切花、半导体、时装样品和备件走航空，因为时间昂贵。Hummels和Schaur（2013年）估计，在途每一天值货物价值约0.6%到2%的关税当量，这一数字使航空即使在运费账单看起来很大时也对高价值重量比产品具有竞争力。

**通信与协调。**跨大西洋电话，然后是数据包的成本，自1970年以来下降了几个数量级。这一下降不仅增加了*服务*贸易（软件、后台处理、工程、娱乐）。它改变了*货物*生产的组织。日本或德国的企业现在可以在数小时而不是数月内与越南、墨西哥或波兰的供应商指定零部件、监控质量并修改设计。Baldwin的“第二次拆分”是这样的：第一次拆分在十九世纪把生产与消费在地理上分开；第二次从1990年代起把生产阶段彼此分开。结果是**全球价值链**（GVC），在数据中度量出口中进口投入的高份额，尤其在电子、汽车和纺织中。

全球价值链繁荣在地理上是集中的。东亚、北美和欧洲形成三个“工厂”区域；撒哈拉以南非洲和南美洲的大部分仍然——重要例外包括智利的铜链、摩洛哥的汽车、埃塞俄比亚和孟加拉国的服装——更专业化于大宗商品和较简单货物的最终组装（世界银行，《2020年世界发展报告：全球价值链时代的贸易与发展》）。参与全球价值链在截面上与更快的生产率增长相联系，但这一关联不是定理，价值链上增加值的分配是不均匀的——这是[[international-trade/firms-in-trade]]的主题。

::: application 从咖啡樱桃到一袋烘焙咖啡
埃塞俄比亚和巴西是世界最大的咖啡种植国之列；德国、意大利和美国是最大的烘焙商和零售商之列。奥罗米亚或米纳斯吉拉斯的一公斤樱桃与超市货架上的一公斤品牌胶囊，差别在于加工、品牌、物流和零售加价。总额出口数据把埃塞俄比亚的生咖啡发运和德国的烘焙咖啡发运记录为不同产品；增加值视角询问最终零售价格有多少归于种植者、运输者、烘焙商和零售商。两种视角都不是“正确”的那一种：它们回答不同的问题。本课程的古典模型说明埃塞俄比亚为何出口咖啡、进口机械（禀赋以及作为技术的气候）。它们本身并不说明价值链如何组织。那是企业层面和契约层面的问题。
:::

## 典型化事实

随后的模型是为匹配一份短的规律清单而建立的。经验规律不是定理；每一条都是对数据的描述，带有来源，并且每一条都有例外。

1. **规模与距离。**双边贸易随双方国内生产总值上升、随距离下降，大致如引力所预测（Tinbergen 1962年；Head和Mayer 2014年）。这一关系对货物成立，并以不同的距离弹性对许多服务成立。

2. **开放度随国家规模下降。**贸易对国内生产总值比率对小型经济体高于大型经济体（世界银行世界发展指标，多年）。这与引力一致：大国有大型本土市场。

3. **产业间贸易和产业内贸易都很大。**同质初级产品和某些制成品单向贸易，沿着禀赋和技术的线索。差异化制成品双向贸易，尤其在相似的高收入经济体之间（Grubel和Lloyd 1975年；经济合作与发展组织STAN和联合国商品贸易统计数据库）。

4. **少数企业占出口的大部分。**在美国、法国、中国、智利、南非以及存在微观数据的许多其他国家，按出口额计的前几个百分点的企业占出口的大部分，且出口企业比非出口企业更大、生产率更高（Bernard和Jensen 1995年、1999年；Mayer和Ottaviano 2008年；世界银行《出口企业动态数据库》）。这是Melitz（2003年）所组织的事实，也是[[international-trade/firms-in-trade]]的主题。

5. **在过去半个世纪的大部分时间里贸易比国内生产总值增长更快，然后停顿。**世界$(X+M)/Y$从1970年代升至2008年，此后没有恢复强劲上升趋势（世界银行世界发展指标）。以数字方式交付的服务是主要例外（世界贸易组织2024年）。

6. **政策仍然重要。**高收入经济体制成品的平均实施最惠国关税很低，往往是低个位数，但对农业和某些劳动密集型制成品的关税仍然较高，而**非关税措施**（标准、许可、原产地规则、反倾销）是剩余保护的很大一部分（世界贸易组织–国际贸易中心–联合国贸易和发展会议《世界关税概览》，各年）。优惠协定覆盖不断增长的贸易份额。工具与政治是[[international-trade/tariffs-and-quotas]]和[[international-trade/trade-agreements]]的主题。

7. **利益的分配是不均匀的。**在古典模型的假设下，对贸易开放会提高国民实际收入，但它并不提高每一种要素的实际收入。地方劳动力市场研究——包括Autor、Dorn和Hanson（2013年）关于美国“中国冲击”的研究，以及关于巴西、墨西哥、挪威和德国的相关工作——发现进口竞争地区的集中损失，与消费者以及出口活动中工人的获益并存。利益*与*分配成本都是记录的一部分；后面各章为它们提供理论。

::: history
**1817年，大卫·李嘉图（David Ricardo）。**《政治经济学及赋税原理》给出比较优势的第一次清晰陈述。**1919年，伊莱·赫克歇尔（Eli Heckscher）**，以及**1933年，伯蒂尔·俄林（Bertil Ohlin）**，把贸易的解释从劳动生产率转向要素禀赋。**1962年，扬·丁伯根（Jan Tinbergen）**在《塑造世界经济》中对双边贸易拟合了第一批引力回归。**1975年，赫伯特·格鲁贝尔（Herbert Grubel）和彼得·劳埃德（Peter Lloyd）**出版《产业内贸易》，迫使理论面对相似产品的双向贸易。**1979–80年，保罗·克鲁格曼（Paul Krugman）**表明规模报酬和垄断竞争可以产生那种贸易。**2003年，马克·梅利茨（Marc Melitz）**把企业异质性带入同一框架。本章中的事实是那些理论所瞄准的目标。
:::

## 通向何处

课程的其余部分依次处理这些事实。[[international-trade/ricardian-model]]询问劳动生产率差异在解释产业间专业化和贸易利益上能走多远。[[international-trade/specific-factors]]和[[international-trade/heckscher-ohlin]]引入土地、资本和技能，并随之给出谁受益、谁受损的理论。[[international-trade/new-trade-theory]]和[[international-trade/firms-in-trade]]讨论产业内贸易、规模报酬、出口企业溢价和全球价值链。从[[international-trade/tariffs-and-quotas]]到[[international-trade/trade-agreements]]处理政策：工具、政治，以及约束它们的关税与贸易总协定/世界贸易组织和区域协定。国际*金融*——汇率、经常账户、资本流动——是姊妹课程[[international-finance]]，不是替代：本课程的贸易模型是实物模型，含相对价格和实际收入，在加入货币之前对通货保持沉默。

::: summary
- 世界货物与服务贸易规模很大（2023年约24万亿美元货物和7.5万亿美元商业服务，世界贸易组织），并集中于大而近的经济体之间。
- 贸易对国内生产总值比率度量暴露度，不是福利；它对小型经济体和加工枢纽更高，世界比率升至2008年然后走平（[[#def-openness]]）。
- 引力方程$T_{ij} \propto Y_i Y_j / D_{ij}^{\theta}$组织谁与谁贸易；结构引力加入多边阻力（[[#def-gravity]]，[[#prop-ces-gravity]]）。接近$-1$的距离弹性是稳健的偏相关，本身并不是基础设施的因果效应。
- 产业间贸易追随禀赋和技术；由格鲁贝尔–劳埃德指数度量的产业内贸易在相似经济体之间的差异化制成品中很大（[[#def-gl]]）。
- 航运、航空货运尤其是通信成本的下降，改变了货物*如何*被生产（全球价值链），也改变了*多少*被贸易。
- 少数企业占出口的大部分；贸易利益与特定工人群体和地区的损失都在数据中。后面各章提供理论。
:::

## 习题

::: exercise 一个贸易比率 {level=1 check="0.9"}
一国国内生产总值是500亿单位，货物与服务出口200亿，进口250亿。其贸易对国内生产总值比率是多少？（输入比率，不是百分数：例如50%输入0.5。）
::: solution
$(200+250)/500 = 450/500 = 0.9$。
:::
:::

::: exercise 格鲁贝尔–劳埃德算术 {level=1 check="0.6"}
某类别出口为70，进口为30。计算格鲁贝尔–劳埃德指数[[#eq-gl]]。
::: solution
$\mathrm{GL} = 1 - \lvert 70-30 \rvert/(70+30) = 1 - 40/100 = 0.6$。
:::
:::

::: exercise $\theta = 1$时的引力 {level=1 check="4"}
在[[#eq-gravity]]中$\alpha=\beta=1$且无残差，两个进口方国内生产总值相等，较远的一方距离是四倍。若$\theta = 1$，与较近进口方的预测贸易对与较远进口方的预测贸易之比是多少？
::: solution
$T_{\text{近}}/T_{\text{远}} = (D_{\text{远}}/D_{\text{近}})^{\theta} = 4^{1} = 4$。
:::
:::

::: exercise $\theta = 1.5$时的引力 {level=2 check="8"}
与上一题同一设定，但$\theta = 1.5$。预测的近处贸易对预测的远处贸易之比是多少？
::: solution
$4^{1.5} = (4^{1/2})^3 = 2^3 = 8$，或$4^{3/2} = (4^3)^{1/2} = 64^{1/2} = 8$。
:::
:::

::: exercise 开放度与规模 {level=2}
用引力解释：为何国内生产总值两倍于另一国的国家预期会有*更低*的贸易对国内生产总值比率，即使其贸易*水平*更高。假设一个由许多国家组成的世界，$\alpha=\beta=1$，且较大国家额外的国内生产总值不是其伙伴的国内生产总值。
::: hint
写出$X_i \approx \sum_j T_{ij} \propto Y_i \sum_j Y_j / D_{ij}^{\theta}$。除以$Y_i$。
:::
::: solution
$i$的出口满足$X_i = \sum_{j \neq i} T_{ij} \propto Y_i \sum_{j \neq i} Y_j / D_{ij}^{\theta}$。贸易对国内生产总值比率的出口一半是$X_i/Y_i \propto \sum_{j \neq i} Y_j / D_{ij}^{\theta}$，它*并不*随$Y_i$上升。一旦注意到更大的$Y_i$意味着世界需求中更大份额是国内的（在更完整的引力模型中，多边阻力和本土份额都随国家规模上升），它随$Y_i$*下降*。绝对贸易$X_i$仍随$Y_i$上升。因此美国按美元计比比利时贸易更多，作为国内生产总值的份额则更少。同一代数也说明转口经济体——其$Y_i$相对经过的贸易很小——会报出100%以上的比率。
:::
:::

::: exercise 产业内对禀赋 {level=2}
一个内陆萨赫勒经济体出口原棉和活畜，进口燃料、药品和水泥。一对相邻的欧盟成员国双向交换汽车、药品和机床。哪一种贸易格局主要是产业间的，哪一种主要是产业内的，本课程的哪一章被设计来解释每一种？为何格鲁贝尔–劳埃德指数对产品分类有多细敏感？
::: solution
萨赫勒格局是产业间的：不同货物沿不同方向流动，沿着土地丰裕、气候以及缺乏国内炼油或制药产业的线索。它是李嘉图和赫克歇尔–俄林各章的领地。欧盟格局是产业内的：相似货物双向流动，是新贸易理论（以及异质企业）的领地。如果“车辆”是一个类别，汽车和零件的双向贸易产生高GL；如果每一条8位税则税目是自己的类别，一个出口小型汽车、进口货车的国家将显示更低的GL。该指数是对一种分类的描述，不是物理常数。
:::

::: exercise 多边阻力 {level=3}
在一项*省略*多边阻力的引力回归中，法国和德国彼此贸易减少，发生在若干东亚经济体迅速增长并成为双方更便宜的伙伴之后。用文字，借助[[#prop-ces-gravity]]，解释即使法德贸易成本$\tau_{FG}$不变，这为何可以发生。Anderson和van Wincoop（2003年）把省略$P_i$和$\Pi_j$与何种偏误相联系？
::: hint
对第三国的$\tau$下降会改变价格指数$P$和$\Pi$。
:::
::: solution
在CES引力公式中，$T_{FG} \propto Y_F Y_G (\tau_{FG}/(P_F \Pi_G))^{1-\sigma}$。东亚的迅速增长和贸易成本下降提高每个欧洲国家进入其他市场的通路，并以一种提高法国与德国之间*相对*于世界其余部分的多边阻力的方式提高CES价格指数的外国成分：法国和德国需求中更多花费在亚洲品种上，因此即使$\tau_{FG}$不变$T_{FG}$也下降。（等价地：当亚洲选项改善时，法国支出中花在德国商品上的*份额*下降。）省略$P_i$和$\Pi_j$把那种替代倾倒进误差或估计的边界和距离系数中。Anderson和van Wincoop表明McCallum的加拿大–美国边界效应被这一省略抬高；结构估计的边界效应仍然很大，但更小。
:::
:::

::: exercise 一项增加值修正 {level=3}
一国出口一件出厂价为100的装置。进口零部件占这100中的40；国内劳动、资本和本地生产的中间投入占60。该装置在国外售价100。（a）总额出口是多少？（b）该出口中的国内增加值是多少？（c）若进口国把来自该出口方的进口记为100，它在这笔交易中把出口方的增加值高估了百分之多少？为何只看总额双边余额的政府可能误读对此类商品征收关税的效应？
::: hint
如果零部件出口国也在数据中，总额流量把40计算两次；进口国*双边*数字100仍然高估组装国的增加值。
:::
::: solution
（a）100。（b）60。（c）进口方的双边统计把100的含量归于组装方；那里只增加了60，因此高估是真实增加值的$40/60 \approx 67\%$，或总额流量的40%。对100征收的关税打击组装方的60*以及*零部件供给方的40，后者可能居住在进口国本身或第三国。总额双边逆差是谁将承担关税、以及“回流”会夺回多少国内价值的糟糕指南。经济合作与发展组织–世界贸易组织增加值贸易表正是为做这一修正而存在；它们并不使总额流量对海关或引力变得无关。
:::
:::

::: exercise 读一幅缓慢全球化图 {level=2}
世界贸易/国内生产总值从1970年的约26%升至2008年的约60%，2023年约为58%（世界银行世界发展指标）。给出该比率即使贸易*数量*并未崩溃也可以停止上升的两个原因，以及服务贸易序列在货物走平时可以继续上升的一个原因。
::: solution
该比率是价值份额。如果国内生产总值与贸易增长得一样快，它就会走平，2010年代当中国和其他大型新兴经济体快速增长、加工贸易繁荣成熟时就是如此。如果贸易品的*价格*相对非贸易服务下降（贸易条件或巴拉萨–萨缪尔森效应），它也会走平，从而使同样的集装箱相对国内生产总值对分子的贡献更少。货物数量甚至可以在比率下降时上升。服务，尤其是以数字方式交付的专业、金融和娱乐服务，有不同的成本结构：它们的“距离”弹性往往更低，边际运输成本接近零，因此可以在货物贸易走平后作为贸易份额继续增长（世界贸易组织2024年关于不断上升的服务份额）。
:::

::: exercise 作为一束的距离 {level=3}
列出引力回归中$D_{ij}$可能拾取的四种不同成本，其中一种是政策。对每一种，给出一个来自不同地区（欧洲、东亚、非洲、美洲）的现实世界例示。为何把这些成本中一种的下降当作沿固定$\theta$的稳定引力曲线的移动是错误的？
::: solution
（i）*海运*：从西澳大利亚到中国港口的铁矿石，或从智利到东亚的铜——吨美元仍然重要的笨重大宗商品。（ii）*时间与航空货运*：从肯尼亚奈瓦沙到阿姆斯特丹的切花，或从东亚到美国的半导体；Hummels和Schaur把时间当作关税的估计适用。（iii）*信息与协调*：德国汽车制造商向捷克或波兰供应商指定零件，或日本企业监控越南工厂——Baldwin的第二次拆分。（iv）*政策*：美墨加协定对北美汽车的原产地规则；欧盟对北非农产品进口的关税和标准；非洲大陆自由贸易区未完成的内部自由化。一种成本的下降改变$\tau_{ij}$，并可能改变所贸易之物的*构成*（更多时间敏感商品、更多全球价值链切片），这可以改变有效的$\theta$。带有单一、稳定$\theta$的引力是平均描述，不是地理的结构不变量。
:::
