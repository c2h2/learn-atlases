若处理由抛硬币分配，得到处理的人与未得到的人在抛硬币之前是同一总体。他们的$Y_i(0)$分布相同，$Y_i(1)$分布相同，观测结果均值的朴素比较就是平均处理效应。这就是[[causal-inference/potential-outcomes#prop-random]]，也是一项执行良好的**随机实验**——医学中的随机对照试验（RCT），经济学中的随机评估——成为本课程每一种其他设计被评判的标准的原因。

这一论证比经济学更早。费希尔（Fisher）在1920–1930年代倡导农业试验中的随机化；奈曼1923年的潜在结果正是为同样的地块发明的。在经济学中，现代浪潮始于对社会项目的田野实验（1960–70年代的负所得税实验、拉隆德1986年使用的NSW培训实验），并随着班纳吉、迪弗洛、克雷默及发展领域的许多人，以及劳动、教育、公共财政与产业组织中平行的实验室与田野实验产业，成为一个研究纲领。2019年诺贝尔奖承认了这一纲领。本章是工具箱：有无协变量时的识别、推断与功效、人们不遵从时的意向处理效应，以及样本流失、溢出、霍桑效应等能在事后毁掉随机化的威胁。

## 随机化为何识别ATE

回忆转换方程$Y_i = Y_i(0) + D_i \tau_i$以及[[causal-inference/potential-outcomes#thm-selection]]的选择偏误分解。$D_i$的随机分配使$D_i$独立于$\bigl(Y_i(1), Y_i(0)\bigr)$，因此两组有相同的均值$Y_i(0)$，选择项消失。

::: definition 完全随机化实验 {#def-cre}
在有$n$个单位、其中$n_1$个被处理的**完全随机化实验**中，每一个大小为$n_1$的子集都同样可能成为处理组。在**伯努利试验**中，每个单位独立地以概率$p$被处理。在**分层**（或区组）实验中，样本按协变量划分，并在每一层内做完全随机化。
:::

独立在伯努利试验中稍强（处理人数是随机的），而在完全随机化实验中处理人数固定，故$D_i$与$D_j$弱相关。大样本中这一区别是二阶的。分层是免费的午餐：它平衡你分层所用的协变量，并且通常在不改变估计对象的情况下减小估计ATE的方差。

::: proposition 均值差 {#prop-dim}
在完全随机化实验中，样本均值之差

$$
\hat\tau = \bar Y_1 - \bar Y_0, \qquad \bar Y_d = \frac{1}{n_d}\sum_{i: D_i=d} Y_i,
$$

对有限样本ATE $\tau = n^{-1}\sum_i \bigl(Y_i(1)-Y_i(0)\bigr)$无偏，并在大的超总体中对$\tau_{\mathrm{ATE}}$一致。用奈曼保守方差

$$
\widehat{\Var}(\hat\tau) = \frac{s_1^2}{n_1} + \frac{s_0^2}{n_0},
$$ {#eq-neyman-var}

其中$s_d^2$是组$d$中$Y$的样本方差，正态近似$\hat\tau \big/ \sqrt{\widehat{\Var}(\hat\tau)}$给出有效的（若有偏差，则略偏保守的）置信区间，因为潜在结果的协方差不可识别。
:::

::: proof
无偏性是带示性函数的计算。设$D_i$为完全随机化设计中的处理示性；$\E[D_i] = n_1/n$，$\E[Y_i \mid D_i] = D_i Y_i(1) + (1-D_i) Y_i(0)$。对$\hat\tau$取期望并利用单位间的对称性，得到$\E[\hat\tau] = n^{-1}\sum_i \bigl(Y_i(1)-Y_i(0)\bigr)$。方差公式是奈曼（1923）的：$\hat\tau$的真实抽样方差涉及$\Cov\bigl(Y_i(1), Y_i(0)\bigr)$，由于两个潜在结果从未被共同观测，它无法估计。用柯西–施瓦茨上界代替该协方差就得到[[#eq-neyman-var]]，因此它是保守的。在独立同分配的超总体中，同一公式就是普通两样本方差，并对$\Var(\hat\tau)$一致。
:::

协变量对无偏性不是必需的，但有助于精确。回归

$$
Y_i = \alpha + \tau D_i + X_i'\gamma + u_i
$$ {#eq-ancova}

是协方差分析（ANCOVA）估计量。在随机实验中$D_i$独立于$X_i$，故省略$X$不使$\hat\tau$有偏；纳入$X$减去随机化本不必平衡的$Y$的变异，并通常缩小标准误。林（Lin，2013）建议让$X$与$D$交互（完全饱和的ANCOVA），从而使$\hat\tau$在效应异质时仍对ATE一致。

::: example 一次模拟试验 {#ex-rct-sim}
一项培训实验有$n = 120$人。潜在收入为$Y_i(0) = 50 + 3 X_i + u_i$，$Y_i(1) = 56 + 3 X_i + u_i$，故ATE为$6$；$X_i$与$u_i$为独立正态（标准差$1$与$1.5$）。处理为$p = 1/2$的伯努利。使用`numpy.random.default_rng(7)`，五十六人被处理。均值差为$55.72 - 49.00 = 6.72$，奈曼标准误$0.545$（t统计量$12.3$）。$Y$对$D$与$X$的OLS给出$\hat\tau = 5.83$（标准误$0.26$）。协变量做了什么？
::: solution
随机化已经使朴素比较无偏：$6.72$在$6$的抽样误差之内（偏差$0.72$是$0.72/0.545 \approx 1.3$个标准误，不足为奇）。加入$X$不改变估计对象；它吸收残差变异并把标准误从$0.55$减半到$0.26$。ANCOVA点估计$5.83$略接近$6$，正如人们从更精确的无偏估计量所预期的。复现这些数字：从所述生成器抽取$X$、$u$与$D$，形成$Y = 50 + 3X + u + 6D$，并以$\hat\beta = (X^\T X)^{-1} X^\T y$计算OLS。
:::
:::

## 功效与样本量

一项无法把政策相关效应与零区分开的实验是浪费金钱，即使它无偏。**功效**是当真实效应为$\tau$时拒绝$H_0$：$\tau = 0$的概率。对大小为$\alpha$的双侧检验、两组各有$n$人、共同结果标准差$\sigma$，

$$
\mathrm{Power} \approx 1 - \Phi\Bigl(z_{1-\alpha/2} - \frac{\tau}{\sigma\sqrt{2/n}}\Bigr) + \Phi\Bigl(-z_{1-\alpha/2} - \frac{\tau}{\sigma\sqrt{2/n}}\Bigr),
$$ {#eq-power}

其中$\Phi$是标准正态cdf，$\alpha = 0.05$时$z_{1-\alpha/2} \approx 1.96$。比值$\tau/\sigma$是标准化效应（Cohen的$d$）。在功效$0.8$处对$n$求解，给出通常的经验法则

$$
n \approx \frac{2\sigma^2 \bigl(z_{1-\alpha/2} + z_{0.8}\bigr)^2}{\tau^2} \approx 15.7\,\frac{\sigma^2}{\tau^2}
$$ {#eq-n80}

人*每一臂*。把可检测效应减半，样本变为四倍。

::: example 多大才够大？ {#ex-power}
收入有$\sigma = 10$（与[[#ex-rct-sim]]同一单位）。值得检测的效应是$\tau = 4$。在$\alpha = 0.05$、双侧、80%功效下，每一臂需要多少人？每一臂50人时功效是多少？
::: solution
[[#eq-n80]]给出$n \approx 15.7 \times 100 / 16 = 98.1$，故约每一臂$100$人（共200人）。$n = 50$时，$\hat\tau$的标准误是$10\sqrt{2/50} = 2$，非中心性为$4/2 = 2$，功效约$0.52$——打扮成试验的抛硬币。许多已发表的社会实验更接近第二种计算而不是第一种。功效不足、又按统计显著被选出的研究产生夸大的效应；这是在试验运行前预注册主要结果与最小可检测效应的一个主要原因（见[[causal-inference/external-validity]]）。
:::
:::

::: warning 事后捞鱼
随机化识别的是*你指定的那个结果*的ATE。它不识别从二十个结果、五个子组和三种函数形式中看过数据之后选出的ATE。多重检验膨胀第I类错误；只报告显著的比较膨胀典型的发表效应。实验的理想包括预分析计划：主要结果、子组和估计量，在看$Y$之前写下。探索性分析是有价值的，应被如此标注。
:::

聚类改变算术。若处理在*学校*层面分配，相关的$n$是学校数，不是学生数；[[#eq-neyman-var]]中的方差应聚类，或把数据坍缩为学校均值。迪弗洛、格伦纳斯特与克雷默（Duflo, Glennerster and Kremer，2007）是标准的实践指南：聚类设计的功效计算用$\sigma^2 \bigl(1+(m-1)\rho\bigr)$代替$\sigma^2$，即Moulton因子，其中$m$是簇大小，$\rho$是簇内相关。

## 分层、配对随机化与再随机化

三种设计选择改进抛硬币，而不威胁无偏性。

**分层。** 按预测$Y$的协变量（性别、地点、基线分数）划分，并在每一层内随机化。ATE估计量是层内差的加权平均；只要各层均值结果不同，其方差就小于未分层的方差。绝不要按处理后变量分层。

**配对随机化。** 分层的极端：按$X$配对单位并在对内随机化。估计量是$n/2$个成对差的均值。推断必须尊重配对（随机化单位是对）。

**再随机化。** 若一次完全随机化分配碰巧使重要协变量不平衡，一些实验者会重抽。摩根与鲁宾（Morgan and Rubin，2012）表明，要求在$X$上平衡的再随机化对ATE仍无偏，且方差更小，只要接受规则是处理–对照在$X$上的差的对称函数，并且分析对此加以考虑。

这些都不是挑选使$\hat\tau$变大的分配的许可证。分配规则必须事先规定。

::: intuition 作为缺失数据设计的实验
随机化并不使处理组的$Y_i(0)$被观测到。它使*缺失性*独立于缺失值，这足以用另一组来填补缺失均值。实验出问题的每一种方式——样本流失、不遵从、溢出——都是缺失性终究变得依赖于缺失值的一种方式。
:::

## 不遵从与意向处理

人们并不总是做被分配的事。在就业培训试验中，一些处理组从未露面，一些对照组在别处找到类似课程。设$Z_i$为**分配**（用再下一章的语言，即工具），$D_i$为**实际接受的处理**。转换方程仍是$Y_i = Y_i(0) + D_i \tau_i$；$Z_i$不出现在其中。

::: definition 意向处理 {#def-itt}
**意向处理**（ITT）效应是*分配*对结果的效应：

$$
\tau_{\mathrm{ITT}} = \E[Y_i \mid Z_i = 1] - \E[Y_i \mid Z_i = 0].
$$

它由$Z_i$的随机分配在对$Z$的SUTVA下识别，无论人们遵从得多么差。
:::

ITT回答一个政策问题：若我们*提供*该项目，会发生什么？它不是接受该项目的效应。若接受率低，ITT是对接受者效应的稀释版本。

要恢复*处理*的效应，需要更多。因本斯与安格里斯特（1994）以及安格里斯特、因本斯与鲁宾（1996）把总体划分为**总是接受者**（无论$Z_i$如何$D_i = 1$）、**从不接受者**（无论$Z_i$如何$D_i = 0$）、**遵从者**（$D_i = Z_i$）与**违抗者**（$D_i = 1-Z_i$）。在单调性（无违抗者）与排他限制（$Z$只通过$D$影响$Y$）下，Wald比

$$
\hat\tau_{\mathrm{Wald}} = \frac{\bar Y_{Z=1} - \bar Y_{Z=0}}{\bar D_{Z=1} - \bar D_{Z=0}}
$$ {#eq-wald}

对遵从者的**局部平均处理效应**一致。分母是接受率的第一阶段差。这就是LATE定理，在[[causal-inference/iv-and-late]]中证明并讨论；这里提到它，是因为几乎每一项社会实验都有单边不遵从，因此一旦用接受率去除ITT，估计的就是LATE而不是ATE。

::: example 稀释 {#ex-itt}
分配被随机化。分配到处理臂的接受率是$80\%$，对照臂是$20\%$（一些对照自己获得了处理）。收入上的ITT是$4$。在单调性与排他下，遵从者的LATE是多少？总体中遵从者占多少？
::: solution
第一阶段是$0.80 - 0.20 = 0.60$，故遵从者份额是$0.60$，$\tau_{\mathrm{LATE}} = 4 / 0.60 \approx 6.67$。总是接受者$20\%$，从不接受者$20\%$，遵从者$60\%$，违抗者（由单调性）$0$。ITT是遵从者效应与对总是接受者和从不接受者的零效应的$60$–$40$混合，对这些人分配不改变处理。只报告ITT，或把$4$报告为“培训的效应”，会低估*接受*培训对那些因提供而被移动接受的人的效应。
:::
:::

::: warning 按方案分析不是解决办法
**按方案**分析比较实际接受处理的人与未接受的人，忽略分配。这一比较重新引入选择：总是接受者与从不接受者是不同的人。它丢掉了实验。分析ITT；若你要处理的效应，使用Wald比（或两阶段最小二乘），并说明它是对遵从者的LATE。
:::

## 随机化不能防止的威胁

随机分配在*分配时*平衡潜在结果。若干事情可以在事后使它们不平衡。

**样本流失。** 若人们因与处理及$Y$有关的原因离开样本，剩余的比较就是被选择的。差分流失是长期随访田野实验的一阶威胁。部分补救：密集追踪一个随机子样本（Lee 2009修剪界）、按臂报告流失，以及通过赋予最差与最好的缺失结果来界定ATE（曼斯基型界，如[[causal-inference/potential-outcomes]]的习题）。

**溢出与SUTVA。** 若处理组农民的新种子吹进对照农民的田里，或驱虫项目降低未处理邻居的感染，对照组的$Y_i(0)$就不是无项目潜在结果。米格尔与克雷默（Miguel and Kremer，2004）在肯尼亚布西亚一项随机化的学校驱虫项目中恰好记录了这一点：处理学校蠕虫负荷更低，附近未处理学校也是。把学校当作单位，并用距离估计溢出，把SUTVA违反变成一项发现——驱虫使处理学校的缺勤大约减少四分之一，并对未处理邻居有额外外部性。后来的“蠕虫战争”再分析（Aiken等，2015；Hicks、Kremer与Miguel的回应）争论了幅度与成本有效性，但没有争论溢出的存在。围绕干扰来设计：随机化簇、测量邻居，或二者都做。

**霍桑效应与约翰·亨利效应。** 知道自己在试验中的人可能因为被观察而改变行为（霍桑），或因为自己是对照而更努力（约翰·亨利）。药物试验中标准的双盲在社会项目中往往不可能。部分检查是一个较少被调查的纯对照臂，或一个安慰剂项目。

**平衡不是识别检验，但不平衡是警告。** 协变量很多时，一些处理–对照差会碰巧显著。$D$对$X$的联合$F$检验，或标准化差$\bigl(\bar X_1 - \bar X_0\bigr)\big/\sqrt{(s_1^2+s_0^2)/2}$，比一张星号表更有信息。大的不平衡应被解释（随机化失败、流失、编码错误），若需要则加以调整。

::: quiz
一项实验用抽签分配就业培训。抽签赢家中百分之三十从未参加，输家中百分之十在别处找到等效培训。按*抽签结果*的平均收入差是300。按*实际参加*的差是1200。哪个是ITT，哪个比较只在额外假定下才有因果解释？
- [ ] 1200是ITT；300有偏
- [x] 300是ITT；1200是被选择的比较（按方案），除非变成Wald LATE
- [ ] 二者都是ATE，因为抽签被随机化了
- [ ] 二者都不可解释，因为遵从不完全
::: solution
分配$Z$被随机化，故按抽签结果的比较是ITT，并且对*赢得抽签*的效应是因果的。按参加的比较是按方案的，一般有偏。用第一阶段$0.30-0.10 = 0.20$去除$300$会给出遵从者的Wald LATE $1{,}500$，这*不是*按方案的$1{,}200$。不完全遵从并不毁掉ITT。
:::
:::

## 证据

田纳西STAR班级规模实验（克鲁格1999等）把幼儿园学生随机分配到小班、常规班或带教师助手的常规班。小班使考试成绩提高约$0.2$个标准差，对处境不利学生的效应更大；效应在某些后期测验中消退，但在升学中再现（Chetty等，2011，使用行政随访）。STAR是大型、记录良好的社会实验的典范，也是随后争论的典范：随机化干净吗（是的，对扩大规模与后来分轨有一些限定），以及幼儿园$0.2$个标准差是否证明到处缩小班级的成本合理（一个外部有效性问题）？

墨西哥的Progresa（后来的Oportunidades，再后来的Prospera）于1997年启动，在贫困农村把有条件现金转移的*时点*随机化。Schultz（2004）及许多后续论文发现入学率大幅上升，尤其是向中学过渡时，以及健康改善。因为对照村被安排稍后接受项目，设计估计的是较早铺开的短期效应；长期评估在对照被处理多年后使用原来的随机化，持续性好坏参半。Progresa也是一个政治经济学故事：随机评估被建入一项国家政策，评估被广泛认为帮助该项目在政府更迭后存活。

并非每个实验都像STAR或Progresa。许多发展RCT规模小、期限短，并在NGO已经工作的地点运行。Allcott（2015）记录了节能实验中的**地点选择偏误**：第一批合作公用事业是项目对其最有效的那些，后来地点显示更小的效应。来自错误地点的内部有效估计，对国家政策仍是错误的数。那是[[causal-inference/external-validity]]的主题。

::: example 潜在结果语言中的STAR {#ex-star}
田纳西STAR把幼儿园学生随机分配到小班（约$15$人）或常规班（约$22$人）。克鲁格（1999）报告小班使考试成绩提高约$0.2$个标准差。用本章的语言：$D_i$是什么，ITT是什么，ATT为何可能不同？
::: solution
$D_i$是被分配到小班（在STAR中，分配与入学接近，故ITT $\approx$ ATT）。$0.2$个标准差是实验样本中那些年级学生的ITT。若一些被分配的学生转换了班型（他们确实略有转换：一些家长转走孩子，一些学校回填），ATT就会不同。克鲁格的表既包括分配对比，也包括对交叉的调整；二者非常接近。这个数*不是*把一州每个班都减到$15$人的效应，那会改变教师池（[[causal-inference/external-validity]]中讨论的规模/实施差距）。
:::
:::

::: application 从试验到回归
实验估计量是$Y$对$D$（或许还有$X$）的普通最小二乘。你从[[econometrics/inference]]知道的关于异方差稳健与聚类标准误的一切都适用。新的是*解释*：在随机分配下，$\hat\tau$不是“在$Y$的线性模型中保持$X$不变时$D$上的系数”。它是ATE（或ITT，若$D$是分配）。线性模型是计算装置，不是因果模型。因果模型是$Y_i = Y_i(0) + D_i \tau_i$，且$D_i$独立于潜在结果。
:::

::: history
**1925–1935年，费希尔（Ronald Fisher）与奈曼（Jerzy Neyman）。** 费希尔的《研究人员的统计方法》（1925）与《实验设计》（1935）使随机化成为农业推断的基础，包括作为置换检验的品茶女士。奈曼1923年的论文并行地定义了ATE以及不需要费希尔尖锐原假设的保守方差。

**1970年代，美国的社会实验。** 负所得税实验、兰德健康保险实验与全国支持性工作示范把随机分配带到税收、健康与培训政策。拉隆德（1986）用NSW作为观测估计量的基准。

**1997年–，Progresa与发展RCT运动。** 墨西哥的Progresa把随机评估建入一项国家反贫困项目。班纳吉、迪弗洛、克雷默及合作者把该方法扩展到印度、肯尼亚等地的教育、健康与信贷；2019年诺贝尔奖承认了那项工作。米格尔与克雷默（2004）关于驱虫的研究仍是随机化力量与溢出现实的典范——且有争议——的说明。
:::

## 通向何处

当分配被随机化但接受未被随机化时，ITT被识别，遵从者的LATE在额外假定下被识别；那是[[causal-inference/iv-and-late]]。没有随机化时，后面各章寻找替代：恢复可忽略性的协变量集（[[causal-inference/selection-on-observables]]）、切断点（[[causal-inference/regression-discontinuity]]）、跨期对照（[[causal-inference/difference-in-differences]]），或合成双胞胎（[[causal-inference/synthetic-control]]）。实验也设定那些设计被对照检验的标准，以拉隆德的精神。又因为一个样本中识别良好的效应未必能走出去，[[causal-inference/external-validity]]问如何合并、复制与迁移实验估计。

::: summary
- $D$的随机分配使处理独立于潜在结果，故均值差对ATE无偏（[[#prop-dim]]）。协变量用于精确，不是用于无偏。
- 功效随$n \tau^2/\sigma^2$缩放。检测小效应需要大的（常常是聚类的）样本；功效不足的显著结果被夸大（[[#eq-n80]]）。
- 预先指定主要结果与子组。随机化并不许可对设定的搜寻。
- 有不遵从时，ITT是分配的效应并且仍被识别（[[#def-itt]]）。处理的效应是遵从者的LATE，由第一阶段去除得到——不是通过丢掉不遵从者。
- 样本流失、溢出与霍桑效应可以在分配后毁掉随机化。簇随机化、溢出臂与流失界是设计的一部分，不是事后想法。
:::

## 习题

::: exercise 均值差 {level=1 check="6"}
在完全随机化实验中，处理组（$n_1 = 50$）的结果均值为$22$，未处理组（$n_0 = 50$）均值为$16$。$\hat\tau$是多少？（输入整数。）
::: solution
$\hat\tau = 22 - 16 = 6$。在随机分配下这估计ATE（以及与之重合的ATT）。
:::
:::

::: exercise 奈曼标准误 {level=1 check="2"}
在同一实验中样本方差为$s_1^2 = 100$与$s_0^2 = 100$。用[[#eq-neyman-var]]，$\hat\tau$的标准误是多少？（输入整数。）
::: solution
$\widehat{\Var}(\hat\tau) = 100/50 + 100/50 = 4$，故标准误为$2$。
:::
:::

::: exercise 遵从者份额 {level=1 check="0.5"}
分配到处理者中接受率为$0.70$，分配到对照者中为$0.20$。在单调性下，总体中遵从者占多少？（输入小数。）
::: solution
第一阶段为$0.70 - 0.20 = 0.50$。这一差就是遵从者份额。
:::
:::

::: exercise 由ITT得到Wald {level=2 check="8"}
ITT为$4$，第一阶段（接受率之差）为$0.5$。在单调性与排他下，遵从者的LATE是多少？（输入整数。）
::: solution
$\tau_{\mathrm{LATE}} = 4 / 0.5 = 8$。
:::
:::

::: exercise 样本量 {level=2 check="100"}
用[[#eq-n80]]，在$\sigma = 10$、$\tau = 4$时，大约80%功效需要每一臂多少人？四舍五入到最近的十。（输入整数。）
::: hint
$n \approx 15.7\,\sigma^2/\tau^2$。
:::
::: solution
$15.7 \times 100 / 16 = 98.125$，四舍五入为$100$。（用$z_{0.975} = 1.96$与$z_{0.8} = 0.84$的更精确计算给出$n = 2\sigma^2(1.96+0.84)^2/\tau^2 = 98.1$。）
:::
:::

::: exercise 为何ANCOVA不带来偏误 {level=2}
在随机实验中，$D$独立于处理前协变量$X$。说明为何$Y$只对$D$的回归以及$Y$对$D$与$X$的回归中$D$上的系数都估计ATE（效应为常数时），以及为何第二个通常更精确。
::: solution
$D$与$X$独立意味着$X$不是混杂因素：它不出现在[[causal-inference/potential-outcomes#thm-selection]]的选择偏误项中。由[[econometrics/multiple-regression]]的遗漏变量公式，省略$X$的偏误与$D$对$X$的回归中$X$的系数成比例，而该系数为0。故两个回归对$\tau$都无偏。只要$X$预测$Y$，给定$D$与$X$时$Y$的残差方差就小于只给定$D$时，从而$\hat\tau$的标准误相应缩小。（效应异质时，林的交互设定使估计对象保持为ATE。）
:::
:::

::: exercise 单边不遵从 {level=3}
在许多社会实验中，对照无法获得处理（单边不遵从）：只要$Z_i = 0$就有$D_i = 0$，而一些被分配到处理的人并不接受。证明在排他与SUTVA下，Wald估计量等于ATT（不只是处理组某个严格子集的LATE）。
::: hint
若没有$Z=0$的人被处理，总是接受者就不能存在。那么处理组是谁？
:::
::: solution
$Z_i = 0$意味着$D_i = 0$，故没有总是接受者，也没有违抗者。处理组（$D_i = 1$）因此是被分配到处理者的子集，并且恰好是遵从者。遵从者的LATE就是ATT。Wald分母是$\Prob(D_i=1 \mid Z_i=1) = \Prob(\text{遵从者})$，ITT等于该概率乘以ATT。这就是为何有单边不遵从的实验论文常把“TOT”（对处理组的处理）报告为ITT除以接受率。
:::
:::

::: exercise 流失界 {level=3}
二元结果（就业）对每个处理单位都观测到，$\bar Y_1 = 0.60$，但对照中20%流失。在剩余对照中，$\bar Y_0 = 0.50$。处理组与对照分配组规模相等。当缺失的对照结果可以是$0$或$1$时，给出最差与最好情形的ITT。
::: hint
把缺失的20%对照填为$0$以最大化ITT，填为$1$以最小化它。观测到的对照均值$0.50$适用于留下的80%。
:::
::: solution
最差缺失下（所有缺失对照有$Y=0$）对照均值为$0.8\times 0.50 + 0.2\times 0 = 0.40$，故ITT为$0.60-0.40 = 0.20$。最好缺失下（所有缺失对照有$Y=1$）对照均值为$0.8\times 0.50 + 0.2\times 1 = 0.60$，故ITT为$0.60-0.60 = 0$。识别集是$[0, 0.20]$。忽略流失的点估计$0.60-0.50 = 0.10$落在集内；当人们拒绝假定流失独立于$Y$时，该集是诚实的报告。
:::
:::

::: exercise 聚类功效 {level=3}
一项学校层面实验每校$m = 50$名学生，簇内相关$\rho = 0.05$。相对个体随机化设计，*学生*人数必须增加多少倍以保持同样功效？（Moulton因子为$1+(m-1)\rho$。）
::: solution
Moulton因子为$1 + 49\times 0.05 = 3.45$。学校均值比较的方差是同样学生数下个体随机化方差的$3.45$倍，故需要$3.45$倍的学生——等价地，该设计大约与有$n/3.45$个观测的个体RCT一样精确。有$50$所学校（每臂25所）时，有效样本远更接近$50$而不是$2{,}500$。这就是为何聚类试验的功效计算按簇的数目来做。
:::
:::
