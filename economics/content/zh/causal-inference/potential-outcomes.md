一座城市向失业工人提供为期六个月的培训项目。一年后，受训者的收入平均比未报名者高1200。这个项目每年值1200吗？单凭这一比较不够。报名的人本来就可能更有动力、识字更好，或更接近一份工作机会。我们观察到受训者培训后的收入，却观察不到他们若未培训会有的收入，而那个缺失的数字才是效应。

这就是**因果推断的基本问题**：对每个人，我们只看到两种可能结果中的一种，从不同时看到两种。描述这两种可能的现代语言，是奈曼（Neyman，1923）与鲁宾（Rubin，1974）的**潜在结果**框架。一旦把缺失的结果命名，就可以精确地说数据能恢复哪一种平均、哪一种比较有偏，以及哪一种研究设计——随机化、回归、工具、断点——能修正该偏误。本课程的其余部分，就是由这一想法展开的工具箱。

全文中，**单位**$i$是一个人、企业、村庄或年份；**处理**$D_i \in \{0,1\}$是二元的项目、政策或事件；**结果**$Y_i$是我们关心的量（收入、就业、考试成绩、死亡率）。连续与多值处理也存在，但二元情形已经包含全部概念上的困难。

## 潜在结果

设想对每个单位，世界可以走两条路。

::: definition 潜在结果 {#def-po}
对二元处理$D_i \in \{0,1\}$，单位$i$有两个**潜在结果**：接受处理时为$Y_i(1)$，不接受时为$Y_i(0)$。**个体处理效应**为

$$
\tau_i = Y_i(1) - Y_i(0).
$$

**观测结果**是与实际接受的处理相对应的那个潜在结果：

$$
Y_i = D_i Y_i(1) + (1-D_i) Y_i(0) = Y_i(0) + D_i \tau_i.
$$ {#eq-switching}
:::

[[#eq-switching]]是会计恒等式，不是假定：它只说我们看到处理组的处理结果、对照组的未处理结果。另一个潜在结果是**反事实**。因此个体效应$\tau_i$从未被观测到。霍兰德（Holland，1986）称之为基本问题；此后的一切，都是在额外假定下恢复$\tau_i$的*平均*。

标准设定中还有两条容易被忽略的条件。

::: definition SUTVA {#def-sutva}
**稳定单位处理值假定**（SUTVA）要求：（i）单位$i$的潜在结果不依赖于其他单位的处理（无干扰）；（ii）处理只有一个版本，因此“$D_i = 1$”命名的是单一、定义清楚的干预。
:::

当接种者保护了邻居（干扰）、给$i$的培训名额是剥夺$j$的名额（另一种干扰），或“培训”对一些人是六周课程、对另一些人是两年学徒（多个版本）时，SUTVA失败。这时在更仔细地规定处理与干扰结构之前，$Y_i(1)$与$Y_i(0)$甚至没有良好定义。除非某章另有说明，我们维持SUTVA；[[causal-inference/randomised-experiments]]再讨论溢出。

::: remark 记号
成对$\bigl(Y_i(1), Y_i(0)\bigr)$有时写成$\bigl(Y_i^1, Y_i^0\bigr)$或$\bigl(Y_{1i}, Y_{0i}\bigr)$。本课程中处理为$D_i$，沿用因本斯（Imbens）与鲁宾；有的教材用$W_i$或$T_i$。观测结果在行文中一律写$Y_i$，不写$Y_i(D_i)$，尽管那正是[[#eq-switching]]所说的。回归中的误差项是$u_i$，与[[econometrics/simple-regression]]相同；在本课程中$\beta$是回归系数，从不是贴现因子。
:::

::: example 八名工人 {#ex-eight}
八名失业工人在有无培训项目时的潜在月收入如下（货币单位）。其中四人参加项目（$D_i = 1$）。

| $i$ | $Y_i(0)$ | $Y_i(1)$ | $\tau_i$ | $D_i$ | $Y_i$ |
|---|---|---|---|---|---|
| 1 | 8 | 12 | 4 | 1 | 12 |
| 2 | 6 | 11 | 5 | 1 | 11 |
| 3 | 10 | 13 | 3 | 0 | 10 |
| 4 | 7 | 9 | 2 | 1 | 9 |
| 5 | 12 | 14 | 2 | 0 | 12 |
| 6 | 5 | 10 | 5 | 1 | 10 |
| 7 | 9 | 11 | 2 | 0 | 9 |
| 8 | 11 | 12 | 1 | 0 | 11 |

工人3的处理效应是多少？我们对工人3观测到什么？
::: solution
工人3的处理效应是$\tau_3 = 13 - 10 = 3$。我们观测不到它。工人3未接受处理，因此观测到$Y_3 = Y_3(0) = 10$；处理结果$13$是反事实。这张表是计量经济学家从未完整看到的装置：若把缺失格涂灰，那些格子恰好就是缺失的潜在结果。
:::
:::

## 平均效应

因为$\tau_i$无法逐人识别，我们瞄准平均。

::: definition 平均处理效应 {#def-ate}
在一个总体中（或在有限研究样本中，平均理解为样本均值），**平均处理效应**（ATE）、**处理组平均处理效应**（ATT）与**未处理组平均处理效应**（ATU）为

$$
\begin{aligned}
\tau_{\mathrm{ATE}} &= \E\bigl[Y_i(1) - Y_i(0)\bigr], \\
\tau_{\mathrm{ATT}} &= \E\bigl[Y_i(1) - Y_i(0) \mid D_i = 1\bigr], \\
\tau_{\mathrm{ATU}} &= \E\bigl[Y_i(1) - Y_i(0) \mid D_i = 0\bigr].
\end{aligned}
$$
:::

若每个人的效应相同，或处理与效应独立，这三个数重合。一般它们不同，回答的问题也不同。已经招进一批人、想知道这些人获益多少的财政部门，要的是ATT。决定是否向一批新的、有代表性的人*提供*该项目的部门，要的是ATE。ATU是对目前未参加者的效应——若项目将向他们扩展，这是相关的。

由全期望公式，

$$
\tau_{\mathrm{ATE}} = \pi \,\tau_{\mathrm{ATT}} + (1-\pi)\,\tau_{\mathrm{ATU}},
$$ {#eq-ate-mix}

其中$\pi = \Prob(D_i = 1)$是处理份额。ATE是对得到项目者的效应与对未得到者的效应的加权平均。

::: example 八人表中的平均效应 {#ex-ate-eight}
利用[[#ex-eight]]，计算ATE、ATT与ATU。
::: solution
八个个体效应为$4, 5, 3, 2, 2, 5, 2, 1$。其均值即ATE：

$$
\tau_{\mathrm{ATE}} = \frac{4+5+3+2+2+5+2+1}{8} = 3.
$$

处理组是工人1、2、4、6，效应为$4, 5, 2, 5$，故$\tau_{\mathrm{ATT}} = 4$。未处理组是3、5、7、8，效应为$3, 2, 2, 1$，故$\tau_{\mathrm{ATU}} = 2$。处理份额$\pi = 1/2$，[[#eq-ate-mix]]核对：$\tfrac12 \cdot 4 + \tfrac12 \cdot 2 = 3$。在这一总体中，项目对参加者的作用大于对未参加者——这种模式常称为**对收益的正向选择**。
:::
:::

::: intuition 谁是“平均”的人？
平均处理效应是对*单位总体*的平均，不是对一个平均人的效应。若四个村民获益10、四个损失2，ATE是4，而没有一个村民经历了4。异质性是常态。后面各章恢复*局部*平均——工具下的遵从者（[[causal-inference/iv-and-late]]），或切断点处的人（[[causal-inference/regression-discontinuity]]）——它们可能远离ATE。始终要问：对谁平均？
:::

## 选择偏误

本章开头的比较，是处理组与未处理组*观测*结果均值之差：

$$
\Delta = \E[Y_i \mid D_i = 1] - \E[Y_i \mid D_i = 0].
$$

它总是由数据识别。一般而言，它不是上面任何一种因果平均。

::: theorem 朴素比较的分解 {#thm-selection}
在SUTVA下，

$$
\E[Y_i \mid D_i = 1] - \E[Y_i \mid D_i = 0] = \tau_{\mathrm{ATT}} + \underbrace{\E\bigl[Y_i(0) \mid D_i = 1\bigr] - \E\bigl[Y_i(0) \mid D_i = 0\bigr]}_{\text{选择偏误}}.
$$ {#eq-selection}
:::

::: proof
由[[#eq-switching]]，$\E[Y_i \mid D_i = 1] = \E[Y_i(1) \mid D_i = 1]$，$\E[Y_i \mid D_i = 0] = \E[Y_i(0) \mid D_i = 0]$。加减$\E[Y_i(0) \mid D_i = 1]$：

$$
\begin{aligned}
\E[Y_i(1) \mid D_i = 1] - \E[Y_i(0) \mid D_i = 0]
&= \bigl(\E[Y_i(1) \mid D_i = 1] - \E[Y_i(0) \mid D_i = 1]\bigr) \\
&\quad + \bigl(\E[Y_i(0) \mid D_i = 1] - \E[Y_i(0) \mid D_i = 0]\bigr) \\
&= \tau_{\mathrm{ATT}} + \text{选择偏误}.
\end{aligned}
$$
:::

选择偏误是得到处理的人与未得到处理的人在*未处理*结果上的差。它回答的是：若无人接受处理，两组会如何比较？若受训者即使不上课收入也会高于未受训者，选择偏误为正，朴素比较高估ATT。若受训者是负向选择——项目是前景本已很差者的最后手段——朴素比较低估ATT，甚至可能符号错误。

对称的分解把同一个$\Delta$写成ATU加上$Y_i(1)$上的选择项。最常用的是ATT形式，因为处理组正是我们试图用未处理组去猜测其反事实$Y_i(0)$的那些人。

::: example 选择可以抵消真实效应 {#ex-cancel}
在[[#ex-eight]]中，观测均值的朴素比较为零。把它算出来，并与[[#thm-selection]]对上。
::: solution
观测到的处理组结果：$12, 11, 9, 10$，均值$10.5$。观测到的未处理组结果：$10, 12, 9, 11$，均值$10.5$。故$\Delta = 0$。但ATT是$4$。缺失的一块是$Y_i(0)$上的选择：处理组中$\E[Y_i(0) \mid D_i=1] = (8+6+7+5)/4 = 6.5$；未处理组中$\E[Y_i(0) \mid D_i=0] = (10+12+9+11)/4 = 10.5$。选择偏误等于$6.5 - 10.5 = -4$。于是$4 + (-4) = 0$，与[[#eq-selection]]一致。

项目*确实*使参加者的收入平均提高4。观测均值的比较把这一获益藏了起来，因为报名者的未处理前景差得多。决策者若从$\Delta = 0$得出“培训没有用”，是错的；若得出“对随机一名失业工人培训值4”，也是错的，因为ATE是3而不是4，ATU只有2。
:::
:::

::: warning 关联不是被稀释的因果
人们容易说朴素比较“部分是因果的”。[[#eq-selection]]说得更尖锐：观测到的差等于一个因果效应*加上*一项可以比效应更大、可正可负、且并不因样本变大而缩小的项。有数百万观测时$\Delta$被估得非常精确；若选择偏误不是零，它仍是错的数。精确不是识别。
:::

sliders: tau=4:-2:10; s=-4:-8:8

labels: \text{朴素 }\Delta; \text{ATT}

## 朴素比较何时是因果的？

[[#eq-selection]]使$\Delta = \tau_{\mathrm{ATT}}$的条件一目了然：选择偏误必须为零。

::: definition 可忽略性 {#def-ignorability}
处理是**可忽略的**，或**不可混杂的**，当

$$
\bigl(Y_i(1), Y_i(0)\bigr) \;\perp\; D_i.
$$ {#eq-indep}

给定协变量$X_i$的**条件可忽略性**是$\bigl(Y_i(1), Y_i(0)\bigr) \perp D_i \mid X_i$。较弱的条件$\E[Y_i(0) \mid D_i = 1] = \E[Y_i(0) \mid D_i = 0]$已足以使$\Delta = \tau_{\mathrm{ATT}}$；完全独立则还给出$\Delta = \tau_{\mathrm{ATE}} = \tau_{\mathrm{ATT}} = \tau_{\mathrm{ATU}}$。
:::

处理与潜在结果独立，是关于*分配机制*的陈述，不是关于观测到的$Y_i$。它说处理组与未处理组在任一机制下本会有相同的结果分布。它*并不*说$Y_i$与$D_i$独立——若处理起作用，$Y_i$与$D_i$通过[[#eq-switching]]相关。

::: proposition 随机分配识别ATE {#prop-random}
若$D_i$独立于$\bigl(Y_i(1), Y_i(0)\bigr)$而分配（如在一项执行良好、完全遵从的随机实验中），则

$$
\tau_{\mathrm{ATE}} = \E[Y_i \mid D_i = 1] - \E[Y_i \mid D_i = 0],
$$

且同一差也等于ATT与ATU。自然的估计量是样本均值之差。
:::

::: proof
独立意味着对$d \in \{0,1\}$有$\E[Y_i(d) \mid D_i = 1] = \E[Y_i(d) \mid D_i = 0] = \E[Y_i(d)]$。因此[[#eq-selection]]右边有$\tau_{\mathrm{ATT}} = \tau_{\mathrm{ATE}}$且选择偏误为零。把选择项换成$Y_i(1)$，同样的论证给出ATU结果。
:::

[[#prop-random]]是下一章讨论随机实验的原因。它也是本课程中每一种其他设计都试图*再现*某种独立的原因：对$X_i$条件化、使用几乎如同随机的工具、比较刚刚越过切断点的单位，或构造一个合成双胞胎。

在观测数据中，独立是一条实质性主张。若处理由抽签、切断点或与$Y_i(0)$无关的自然力量分配，它可能成立。若人们盯着自己的$Y_i(0)$或$Y_i(1)$来*选择*$D_i$，它就不成立。劳动、发展、教育与公共经济学中的典型情形正是这种选择，这就是这些领域在设计上花费大量精力的原因。

::: quiz
在[[#ex-eight]]中，处理*不是*可忽略的。哪一条观察就足以看出这一点？
- [ ] ATE是3，不是零
- [ ] 四人接受处理，四人未接受
- [x] 处理组中$Y_i(0)$均值为6.5，未处理组中为10.5
- [ ] 个体效应$\tau_i$并非全都相等
::: solution
可忽略性要求（其中之一）$Y_i(0)$在处理组与未处理组中同分布。均值6.5与10.5不同，故独立失败。单有异质性效应并不违反可忽略性；ATE非零是关于处理的事实，不是关于分配的事实。
:::
:::

## 回归、控制，以及“保持$X$不变”的含义

对选择的常见回应，是在回归中“控制”可观测差异

$$
Y_i = \beta_0 + \beta_1 D_i + X_i'\gamma + u_i.
$$ {#eq-reg}

若$X_i$足够丰富，使$D_i$的剩余变异几乎如同随机——也就是条件可忽略性成立——则$\beta_1$等于协变量特定处理效应的加权平均；若对$X_i$用饱和设定，再加一条重叠条件，它恢复ATE。这是[[causal-inference/selection-on-observables]]的主题。在进入任何匹配或倾向得分装置之前，这里先有三点。

第一，[[#eq-reg]]并不创造可忽略性。它*使用*可忽略性。若某个混杂因素被遗漏，$\hat\beta_1$继承[[econometrics/multiple-regression]]中导出的那种遗漏变量偏误：偏误等于遗漏变量对$Y$的效应乘以它在给定$X$时对$D$的回归系数。增加控制变量只有在它们是混杂因素时才有帮助，若它们是对撞因子或中介则没有（见下）。

第二，系数$\beta_1$是*条件*效应的平均，权重偏向处理变异大的协变量格子。安格里斯特（Angrist，1998）证明，OLS权重与$D_i$给定$X_i$的条件方差成比例。几乎全部被处理、或几乎全部未被处理的组贡献很小。因此即使在可忽略性下，回归估计对象也不自动是ATE。

第三，[[#eq-reg]]中的残差$u_i$不是潜在结果。潜在结果模型$Y_i = Y_i(0) + D_i \tau_i$变成效应为常数$\tau$、误差为$Y_i(0) - \E[Y_i(0)]$的回归，仅当对所有$i$有$\tau_i = \tau$。效应异质时，误差含有$(\tau_i - \beta_1) D_i$，它由构造就与$D_i$相关。这就是IV、RDD与DID不只是“更花哨的回归”的原因之一：它们在写明的假定下瞄准$\tau_i$的某个确定平均，而不是某个特定最小二乘泛函的概率极限。

::: example 效应为常数的回归仍然有偏 {#ex-reg-bias}
设$Y_i(0) = 10 + 2 X_i + u_i$，$Y_i(1) = 14 + 2 X_i + u_i$，故每个人的效应都是$4$，但$D_i = 1$主要发生在$X_i$较大时。一次$n = 200$、种子为42的模拟（$X_i$与$u_i$为标准正态；$D_i = 1\{X_i + 0.5 v_i > 0.4\}$，$v_i$为另一标准正态）给出处理份额$0.34$，朴素处理–对照差距$6.44$，$Y$对$D$的OLS等于$6.44$（标准误$0.24$）。$Y$对$D$与$X$的OLS给出$D$上的系数$4.14$（标准误$0.20$）。解释这三个数。
::: solution
真实ATE（以及ATT、ATU）是$4$。朴素差距$6.44$高估了它，因为处理单位有更高的$X$（均值$0.78$对$-0.45$），而$X$即使没有处理也会提高$Y$。那是大约$2.4$的选择偏误。一旦回归中有$X$，$D$的剩余变异更接近可忽略，系数$4.14$在$4$的抽样误差之内。教训不是回归总是有效——我们生成数据时让$X$成为*唯一*混杂因素——而是潜在结果分解与遗漏变量公式是同一事实的两套记号。
:::
:::

[[#ex-reg-bias]]中的数字可用`numpy.random.default_rng(42)`抽取$X$、$u$与$v$，并以$\hat\beta = (X^\T X)^{-1} X^\T y$做OLS来复现。

## 因果图

潜在结果给反事实命名。珀尔（Pearl）等人发展的**有向无环图**（DAG）给生成$D$与$Y$的*故事*命名：哪些变量导致哪些。DAG不是[[#def-po]]的替代品，但是决定对什么条件化的紧凑方式。

::: definition 混杂因素、中介、对撞因子 {#def-dag}
在$(D, Y)$的DAG中：
- **混杂因素**$X$是$D$与$Y$的共同原因（箭头$X \to D$与$X \to Y$）；
- **中介**$M$位于从$D$到$Y$的因果路径上（$D \to M \to Y$）；
- **对撞因子**$C$是$D$（或$D$的原因）与$Y$（或$Y$的原因）的共同*结果*，例如$D \to C \leftarrow U \to Y$。
:::

要识别$D$对$Y$的因果效应，必须阻断从$D$到$Y$的每一条**后门**路径——每条以指向$D$的箭头开头的路径——并且不得阻断我们试图测量的因果路径。对混杂因素条件化会阻断后门路径。对中介条件化会阻断因果路径，从而估计的不是总效应（而是“仅间接”或受控直接效应，取决于图的其余部分）。对对撞因子条件化会*打开*原本被阻断的路径，诱发虚假关联。

最后一点最常令人吃惊。在入院者（$C = 1$）中，风险因素$D$与疾病$Y$可以负相关，即使它们在总体中独立，因为入院可由二者之一引起。这是**伯克森悖论**。在应用工作中，对撞因子往往是样本纳入规则、处理后变量，或人们在处理后选入的职业。

::: warning 坏控制变量
**坏控制变量**是本身即为处理结果的变量，或对撞因子。把它加入[[#eq-reg]]并不是“把更多东西保持不变”；它改变估计对象，并可以制造原本没有的选择偏误。安全规则是：控制处理前的混杂因素；不要控制处理后的结果。中间变量属于中介分析，那是另一个问题。安格里斯特与皮施克（Angrist and Pischke，2009，§3.2.3）收集了例子；经典之一是估计教育回报时控制职业，这丢掉了通过职业起作用的那部分回报。
:::

::: quiz
一项就业培训研究控制参加者在项目*之后*第一份工作的工资，“以便同类相比”。最可能的问题是什么？
- [ ] 项目后工资是混杂因素，因此必须纳入
- [x] 项目后工资是中介（也是结果），因此控制它会阻断部分效应，并可能打开对撞路径
- [ ] 控制任何工资总能减小标准误，而这就是目标
- [ ] 只要用工资作控制，SUTVA就失败
::: solution
项目后第一份工资位于从培训到后来收入的路径上（或*就是*结果）。对它条件化估计的是扣除工作质量后的直接效应，不是培训的总效应，而且在项目后工资相同的人当中，处理组与未处理组是以不同方式被选出的。SUTVA是关于干扰与处理版本的陈述，不是关于控制变量的陈述。
:::
:::

DAG与潜在结果在用于同一故事时是一致的。一张遗漏混杂因素的DAG，与一个声称给定剩余$X$时可忽略的潜在结果模型，是同一个错误。两者都写的好处是：DAG让“不要对此条件化”看得见，而潜在结果让“这是ATT，不是ATE”看得见。

## 证据

这一框架并非新近风尚。奈曼在1923年引入农业地块的潜在产量。鲁宾（1974）把这一想法改写到心理学与经济学的观测研究。霍兰德（1986）命名了基本问题，并在一句常被重复的口号中坚持“没有操纵就没有因果”：因果效应只对原则上本可以是另一回事的处理有定义。这句口号是对“身为女性的效应”或“GDP的效应”这类松散说法的有用刹车；它不是禁止研究歧视或增长，而是要求把干预规定清楚。

框架的经验力量在拉隆德（LaLonde，1986）之后再也无法忽视。美国1970年代的全国支持性工作（NSW）示范项目随机分配就业培训。对一个男性样本，年收入上ATT的实验估计大约为一两千美元。拉隆德随后丢掉实验对照组，换成来自当期人口调查（CPS）与收入动态追踪研究（PSID）的对照，并运行当时的可观测选择估计量。非实验估计从负的数千美元到正的数千美元不等。一种在它本该适用的情境中无法恢复已知实验基准的方法，不是人们会在没有基准的情境中信任的方法。德赫贾与瓦哈巴（Dehejia and Wahba，1999）后来表明，*某些*匹配估计量在仔细限制、共同支撑很强的NSW样本上可以接近得多；这一争论在[[causal-inference/selection-on-observables]]中继续。拉隆德的持久教训不是观测研究没有希望。而是：因果主张的好坏，取决于使$\E[Y_i(0) \mid D_i=1]$可恢复的设计，而检验一项设计的办法，是问它在实验中本会给出什么。

随机评估此后在发展经济学中大规模使用（班纳吉、迪弗洛、克雷默（Banerjee, Duflo, Kremer）及许多其他人；2019年诺贝尔奖），也用于劳动、教育与公共财政。自然实验——征兵抽签、切断点、交错的法律变化——被用于同一目的（卡德、安格里斯特、因本斯；2021年诺贝尔奖）。这两个奖都没有结束关于一个识别良好的局部效应能推广多远的争论；那是[[causal-inference/external-validity]]。

::: application 作为缺失数据的项目评估
从[[#eq-switching]]看，因果推断是缺失数据问题：$D_i = 0$时$Y_i(1)$缺失，$D_i = 1$时$Y_i(0)$缺失。分配机制就是缺失机制。随机分配是完全随机缺失；给定$X$的可忽略性是随机缺失；工具是一个预测缺失、除通过处理外不预测结果的变量。鲁宾强调的这一类比，解释了为何调查无回答中的技术（加权、填补、界定）会在后面各章以逆概率权重、匹配与曼斯基（Manski）界的形式再次出现。
:::

::: history
**1923年，奈曼（Jerzy Neyman）。** 在关于农业田间实验的博士论文中，奈曼把每一地块在每一品种下的产量定义为潜在结果，并把平均处理效应定义为这些未观测成对产量之差的均值。英译本发表于1990年的*Statistical Science*。

**1974年，鲁宾（Donald Rubin）。** “Estimating Causal Effects of Treatments in Randomized and Nonrandomized Studies”（*Journal of Educational Psychology*）为观测数据陈述了潜在结果模型，并使分配机制成为明确的建模对象。

**1986年，霍兰德（Paul Holland）与拉隆德（Robert LaLonde）。** 霍兰德的*JASA*论文“Statistics and Causal Inference”命名了基本问题。拉隆德的*AER*论文“Evaluating the Econometric Evaluations of Training Programs with Experimental Data”表明当时的标准观测估计量未能恢复一项实验性培训效应，并成为基于设计的推断的宣言。
:::

## 通向何处

下一章[[causal-inference/randomised-experiments]]认真对待[[#prop-random]]：如何分析实验、遵从不完全时怎么办、样本必须多大。没有随机化时，[[causal-inference/selection-on-observables]]使用条件可忽略性；[[causal-inference/iv-and-late]]使用工具并恢复遵从者的*局部*平均；[[causal-inference/difference-in-differences]]使用跨期对照；[[causal-inference/regression-discontinuity]]使用切断点；[[causal-inference/synthetic-control]]从加权供体构造反事实。每一种情形下问题都与这里相同：什么识别$\E[Y_i(0) \mid D_i = 1]$，以及对谁识别？

应用贯穿图谱的其余部分。[[labour-economics/human-capital]]中的教育回报是一年教育的因果效应，不是收入回归中的一个系数。[[labour-economics/labour-market-equilibrium]]中最低工资的就业效应是对受影响工人与企业的ATT（或DID估计对象）。[[development-economics/aid-and-policy]]中的田野实验是随机设计，其溢出常常违反SUTVA。潜在结果语言就是这些估计被陈述的方式。

::: summary
- 每个单位有潜在结果$Y_i(1)$、$Y_i(0)$；我们观测$Y_i = D_i Y_i(1) + (1-D_i) Y_i(0)$，而从未观测$\tau_i = Y_i(1) - Y_i(0)$（[[#def-po]]）。SUTVA排除干扰与多个处理版本。
- 目标平均——ATE、ATT、ATU——回答不同问题，不必重合（[[#def-ate]]）。
- 朴素的处理–对照差距等于ATT加上选择偏误，即两组未处理结果之差（[[#thm-selection]]）。选择偏误不随样本量缩小。
- 处理与潜在结果独立（可忽略性）使朴素差距等于ATE；随机分配给出这一点（[[#prop-random]]）。给定$X$的条件可忽略性是观测对应物。
- 控制处理前的混杂因素；不要控制中介或对撞因子。回归系数是条件效应的方差加权平均，不自动是ATE。
- 拉隆德（1986）表明，不能恢复实验基准的设计，不应在黑暗中被信任。本课程的其余部分是一份试图赢得这种信任的设计目录。
:::

## 习题

::: exercise 读表 {level=1 check="3"}
在[[#ex-eight]]中，工人3的个体处理效应$\tau_3$是多少？（输入整数。）
::: solution
$\tau_3 = Y_3(1) - Y_3(0) = 13 - 10 = 3$。工人3未接受处理，因此这个数在数据中观测不到——只有$Y_3 = 10$。
:::
:::

::: exercise 观测均值 {level=1 check="10.5"}
在[[#ex-eight]]中，处理组观测结果的均值$\E[Y_i \mid D_i = 1]$是多少？（输入均值，需要时带小数。）
::: solution
处理组观测结果为$12, 11, 9, 10$。其均值为$42/4 = 10.5$。
:::
:::

::: exercise 四人 {level=1 check="2"}
四人的潜在结果为$Y(0) = (2, 4, 6, 8)$，$Y(1) = (5, 7, 7, 9)$。处理为$D = (1, 0, 1, 0)$。ATE是多少？（输入整数。）
::: solution
四个效应为$3, 3, 1, 1$。ATE为$(3+3+1+1)/4 = 2$。（ATT也是$2$，即$3$与$1$的平均；观测均值的朴素比较是$(5+7)/2 - (4+8)/2 = 6 - 6 = 0$，故选择偏误为$-2$。）
:::
:::

::: exercise 为偏误命名 {level=2 check="-4"}
在[[#ex-eight]]中，[[#eq-selection]]中的选择偏误项$\E[Y_i(0) \mid D_i=1] - \E[Y_i(0) \mid D_i=0]$是多少？（输入整数，若为负则带负号。）
::: solution
$\E[Y_i(0) \mid D_i=1] = (8+6+7+5)/4 = 6.5$，$\E[Y_i(0) \mid D_i=0] = (10+12+9+11)/4 = 10.5$，故差为$6.5 - 10.5 = -4$。与$\tau_{\mathrm{ATT}} = 4$合在一起，恢复朴素差距$0$。
:::
:::

::: exercise 由混合得到ATT {level=2 check="4"}
一个项目处理总体的一半。ATE为$3$，ATU为$2$。ATT是多少？（输入整数。）
::: hint
使用[[#eq-ate-mix]]：$\tau_{\mathrm{ATE}} = \pi \tau_{\mathrm{ATT}} + (1-\pi)\tau_{\mathrm{ATU}}$。
:::
::: solution
$\pi = 1/2$时，混合公式为$3 = \tfrac12 \tau_{\mathrm{ATT}} + \tfrac12 \cdot 2$，故$3 = \tfrac12 \tau_{\mathrm{ATT}} + 1$，从而$\tau_{\mathrm{ATT}} = 4$。
:::
:::

::: exercise 朴素比较对ATT {level=2}
设$\tau_{\mathrm{ATT}} = 8$，且$\E[Y_i(0) \mid D_i = 1] = 20$，$\E[Y_i(0) \mid D_i = 0] = 26$。朴素的处理–对照差$\Delta$是多少？它高估还是低估ATT？
::: solution
由[[#thm-selection]]，$\Delta = 8 + (20 - 26) = 8 - 6 = 2$。朴素比较把ATT低估了$6$：处理组的未处理结果差于未处理组（负向选择），因此真实获益的一部分被观测均值的比较藏了起来。
:::
:::

::: exercise 疫苗运动中的SUTVA {level=2}
一个200人的村庄被提供疫苗。个人$i$保持未感染的机会依赖于有多少邻居接种。用[[#def-sutva]]的语言说明，为何成对$\bigl(Y_i(1), Y_i(0)\bigr)$按现状没有良好定义，以及你可能如何重新定义处理，使潜在结果有意义。
::: solution
干扰违反SUTVA：$Y_i$依赖于其他人的$D_j$，因此“$Y_i(1)$”——$i$接种、其他所有人的处理未指定——不是一个单一的数。一种修补是定义处理*向量*$\mathbf{d} = (d_1,\dots,d_{200})$与潜在结果$Y_i(\mathbf{d})$。这一对象定义良好但维数很高；实践中人们限制干扰，例如假定$Y_i$依赖于$D_i$以及$i$家庭中的接种份额，从而得到一小族潜在结果。另一种修补是随机化*村庄*而不是人，于是分析单位是村庄，村内干扰被吸收进$Y_g(1)$与$Y_g(0)$。两种策略都出现在[[causal-inference/randomised-experiments]]中。
:::
:::

::: exercise 证明ATU形式 {level=3}
从[[#eq-switching]]出发，推导[[#eq-selection]]的伴侣：

$$
\E[Y_i \mid D_i = 1] - \E[Y_i \mid D_i = 0] = \tau_{\mathrm{ATU}} + \bigl(\E[Y_i(1) \mid D_i = 1] - \E[Y_i(1) \mid D_i = 0]\bigr).
$$

解释新的选择项。
::: hint
加减$\E[Y_i(1) \mid D_i = 0]$，而不是$\E[Y_i(0) \mid D_i = 1]$。
:::
::: solution
$\E[Y_i \mid D_i = 1] = \E[Y_i(1) \mid D_i = 1]$，$\E[Y_i \mid D_i = 0] = \E[Y_i(0) \mid D_i = 0]$。加减$\E[Y_i(1) \mid D_i = 0]$，

$$
\begin{aligned}
&\E[Y_i(1) \mid D_i = 1] - \E[Y_i(0) \mid D_i = 0] \\
&\qquad = \bigl(\E[Y_i(1) \mid D_i = 0] - \E[Y_i(0) \mid D_i = 0]\bigr) + \bigl(\E[Y_i(1) \mid D_i = 1] - \E[Y_i(1) \mid D_i = 0]\bigr) \\
&\qquad = \tau_{\mathrm{ATU}} + \bigl(\E[Y_i(1) \mid D_i = 1] - \E[Y_i(1) \mid D_i = 0]\bigr).
\end{aligned}
$$

新的选择项是接受与不接受处理的人在*处理*结果上的差：若人人都被处理，两组会如何比较？在$Y_i(1)$可忽略时它为零。
:::
:::

::: exercise 一个界定习题 {level=3}
已知结果落在$\{0,1\}$中（例如就业）。样本中$\E[Y_i \mid D_i = 1] = 0.70$，$\E[Y_i \mid D_i = 0] = 0.40$，且$\pi = \Prob(D_i = 1) = 0.50$。在没有任何可忽略性假定下，由缺失潜在结果也落在$\{0,1\}$这一事实，给出ATE的尖锐界。
::: hint
缺失的部分是$\E[Y_i(0) \mid D_i = 1]$与$\E[Y_i(1) \mid D_i = 0]$，每一个都可以在$[0,1]$中任意取值。把ATE写成$\pi \E[Y_i(1) \mid D_i=1] + (1-\pi)\E[Y_i(1) \mid D_i=0] - \pi \E[Y_i(0) \mid D_i=1] - (1-\pi)\E[Y_i(0) \mid D_i=0]$，并代入观测到的部分。
:::
::: solution
ATE展开为

$$
\tau_{\mathrm{ATE}} = \pi \E[Y_i(1) \mid D_i=1] + (1-\pi)\E[Y_i(1) \mid D_i=0] - \pi \E[Y_i(0) \mid D_i=1] - (1-\pi)\E[Y_i(0) \mid D_i=0].
$$

观测到的部分是$\E[Y_i(1) \mid D_i=1] = 0.70$与$\E[Y_i(0) \mid D_i=0] = 0.40$。$\pi = 1/2$时这是

$$
\tau_{\mathrm{ATE}} = \tfrac12 \cdot 0.70 + \tfrac12 \E[Y_i(1) \mid D_i=0] - \tfrac12 \E[Y_i(0) \mid D_i=1] - \tfrac12 \cdot 0.40 = 0.15 + \tfrac12 \bigl(\E[Y_i(1) \mid D_i=0] - \E[Y_i(0) \mid D_i=1]\bigr).
$$

每个缺失的条件期望落在$[0,1]$中，故其差落在$[-1,1]$中，其一半落在$[-0.5, 0.5]$中。因此$\tau_{\mathrm{ATE}} \in [0.15-0.5,\, 0.15+0.5] = [-0.35,\, 0.65]$。这是曼斯基（Manski，1989）的**无假定界**。此处区间很宽，因而包含零；单凭数据、没有设计，不能给ATE定号。可忽略性会把区间坍缩为朴素差距$0.70 - 0.40 = 0.30$。
:::
:::

::: exercise 作为缺失数据机制的随机分配 {level=3}
只用[[#eq-switching]]与$\bigl(Y_i(1), Y_i(0)\bigr) \perp D_i$，证明对$d \in \{0,1\}$有$\E[Y_i \mid D_i = d] = \E[Y_i(d)]$，从而$\tau_{\mathrm{ATE}}$与$\tau_{\mathrm{ATT}}$都等于朴素比较。（这是写成一段你应能不查阅就复现的短推导的[[#prop-random]]。）
::: solution
由[[#eq-switching]]，在事件$\{D_i = d\}$上$Y_i = Y_i(d)$，故$\E[Y_i \mid D_i = d] = \E[Y_i(d) \mid D_i = d]$。成对$\bigl(Y_i(1), Y_i(0)\bigr)$与$D_i$独立意味着$\E[Y_i(d) \mid D_i = d] = \E[Y_i(d)]$。因此$\E[Y_i \mid D_i = 1] - \E[Y_i \mid D_i = 0] = \E[Y_i(1)] - \E[Y_i(0)] = \tau_{\mathrm{ATE}}$。同一独立性给出$\E[Y_i(1) - Y_i(0) \mid D_i = 1] = \E[Y_i(1) - Y_i(0)]$，故ATT等于ATE，二者都等于朴素比较。
:::
:::
