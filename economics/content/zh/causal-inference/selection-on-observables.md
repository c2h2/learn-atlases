随机化是奢侈品。经济学家被要求解释的大多数比较——受训者对未受训者、工会会员对非会员、有土改法的国家对没有的国家——并非由抛硬币分配。在很大一类研究中，希望是：一旦我们把足够多的*观测到的*东西保持不变，处理的剩余变异就几乎如同随机。这一希望是**可观测选择**，或**条件可忽略性**。它是带控制的回归、匹配与逆概率加权背后的识别假定。

假定是强的。它说每一个混杂因素都已被测量。拉隆德（1986）表明，以当时的协变量，当时的估计量并未恢复一项实验性培训效应。德赫贾与瓦哈巴（1999）表明，在限制到共同支撑区域的样本上，匹配估计量可以接近得多。教训不是控制$X$总是有效，也不是它从不有效。而是：假定有内容，它可以被探查（重叠、平衡、安慰剂结果），并且在遗漏混杂因素时会静默失败。本章把内容写精确。

## 条件可忽略性与重叠

::: definition 条件可忽略性与重叠 {#def-cia}
给定协变量$X_i$，处理是**条件可忽略的**（也称为**不可混杂**，或**可观测选择**），若

$$
\bigl(Y_i(1), Y_i(0)\bigr) \;\perp\; D_i \mid X_i.
$$ {#eq-cia}

**重叠**（共同支撑）要求对$X_i$支撑中（几乎）所有$x$有$0 < \Prob(D_i = 1 \mid X_i) < 1$。**倾向得分**为$e(x) = \Prob(D_i = 1 \mid X_i = x)$。
:::

条件可忽略性说，*在$X$的一个格子内*，处理几乎如同随机分配。重叠说每个格子既含处理单位也含未处理单位，从而格子特定的比较确实可以计算。没有重叠，可忽略性或许成立，但ATE不能由数据识别：某些类型的人只在一种机制下被观测到。

::: proposition 可观测选择下的识别 {#prop-soo}
假定SUTVA、[[#eq-cia]]与重叠。则

$$
\begin{aligned}
\tau_{\mathrm{ATE}} &= \E\bigl[\E[Y_i \mid D_i=1, X_i] - \E[Y_i \mid D_i=0, X_i]\bigr], \\
\tau_{\mathrm{ATT}} &= \E\bigl[\E[Y_i \mid D_i=1, X_i] - \E[Y_i \mid D_i=0, X_i] \bigm| D_i=1\bigr].
\end{aligned}
$$ {#eq-soo}

内层差是**条件平均处理效应**$\tau(x)$；外层期望用相关总体（所有人，或处理组）中$X$的分布对它平均。
:::

::: proof
由[[#eq-cia]]，$\E[Y_i(d) \mid D_i, X_i] = \E[Y_i(d) \mid X_i]$，故$\E[Y_i \mid D_i=d, X_i] = \E[Y_i(d) \mid X_i]$。重叠使这些条件期望几乎处处有良好定义。取$\E[Y_i(1)-Y_i(0) \mid X_i] = \tau(X_i)$并应用迭代期望法则得到ATE；把外层期望限制在$\{D_i=1\}$上得到ATT。
:::

该命题是识别结果，不是估计量。它说如果我们知道两个回归函数$m_d(x) = \E[Y \mid D=d, X=x]$，我们就完成了。匹配、回归与逆概率加权是估计这些函数、或对其差取平均的三种方式。

::: intuition 一句话中的匹配
对每个处理单位，找到$X$相同的未处理单位，平均他们的$Y$，再相减。条件可忽略性说那些未处理的$Y$是处理单位$Y(0)$的替身。重叠说替身存在。
:::

## 作为加权匹配的回归

回归

$$
Y_i = \alpha + \tau D_i + X_i'\gamma + u_i
$$ {#eq-ols}

是[[#prop-soo]]最常见的实现。若$X$离散且设定是**饱和的**——$X$的每个格子一个虚拟变量，且$D$与那些虚拟变量交互——则$D$上的系数在格子特定差的加权平均中恢复$\tau(x)$的一个定义清楚的平均。若$X$线性进入，[[#eq-ols]]施加$\tau(x) = \tau$与$m_0(x) = \alpha + x'\gamma$，二者都不是可忽略性所蕴含的。

::: proposition OLS权重 {#prop-ols-weights}
设$D_i$二元，$X_i$离散，我们用OLS估计[[#eq-ols]]（无交互）。则$\hat\tau$对格子特定差$\tau(x)$的方差加权平均一致：

$$
\tau_{\mathrm{OLS}} = \sum_x w(x)\,\tau(x), \qquad w(x) \propto \Prob(X_i=x)\,\Var(D_i \mid X_i=x),
$$

且$\sum w(x) = 1$，$w(x) \ge 0$。处理几乎必然、或几乎不可能的格子得到小权重，因为当$e(x)$接近$0$或$1$时$\Var(D \mid X=x) = e(x)\bigl(1-e(x)\bigr)$很小。
:::

::: proof
这是安格里斯特（1998）的二元处理情形。OLS把$Y$投影到$(1, D, X)$张成的空间上。把$X$从$Y$和$D$中偏出之后（Frisch–Waugh–Lovell定理，[[econometrics/multiple-regression]]），$\hat\tau$是$Y$的残差对$D$的残差回归的系数。给定$X$时$D$的残差方差为$e(X)(1-e(X))$，概率极限是$\E[Y \mid D=1, X] - \E[Y \mid D=0, X]$的$e(1-e)$加权平均。在[[#eq-cia]]下那些格子差就是$\tau(x)$。
:::

两个后果。第一，即使在可忽略性下，OLS也不自动估计ATE：它给$e(x)$接近$1/2$的格子过大权重，给接近$0$或$1$的格子过小权重。若要ATE，要么再加权（见下面的IPW），要么饱和。第二，OLS*静默丢掉*无重叠问题：$e(x) \in \{0,1\}$的格子权重为零，而不是产生警告。必须寻找对应者的匹配与IPW，使重叠失败看得见。

::: example 再次模拟，有$X$与无$X$ {#ex-sim-soo}
回到[[causal-inference/potential-outcomes#ex-reg-bias]]中$n = 200$、种子$42$的模拟：$Y_i(0) = 10 + 2X_i + u_i$，$Y_i(1) = 14 + 2X_i + u_i$（ATE $= 4$），$D_i = 1\{X_i + 0.5 v_i > 0.4\}$。朴素差距为$6.44$。$Y$对$D$与$X$的OLS给出$4.14$（标准误$0.20$）。处理组中$X$均值为$0.78$，未处理组中为$-0.45$。解释重叠的作用。
::: solution
在DGP中给定$X$（唯一混杂因素）时条件可忽略性成立。重叠不完美但并非灾难：$X$连续且选择规则有噪声，故两组占据$X$的很宽范围，处理单位更多在右侧。线性OLS作为*加权*方案略有误设——它不是ATE加权平均——但处理效应为常数时每一个加权平均都等于$4$，$4.14$是抽样误差。若我们设$D_i = 1\{X_i > 0.4\}$且无噪声，重叠会在$0.4$两侧失败，线性OLS会把$m_0(x)$*外推*到处理区域。那种外推是超出[[#eq-cia]]的假定，也是线性控制策略通常隐藏的成本。
:::
:::

## 匹配

**最近邻匹配**通过把每个处理单位与在$X$上使某距离最小的一个或多个未处理单位配对来估计$\tau_{\mathrm{ATT}}$（欧氏、马氏，或在罗森鲍姆与鲁宾1983之后，倾向得分）。估计量为

$$
\hat\tau_{\mathrm{ATT}}^{\mathrm{nn}} = \frac{1}{n_1} \sum_{i: D_i=1} \Bigl(Y_i - \frac{1}{|J_i|}\sum_{j \in J_i} Y_j\Bigr),
$$ {#eq-nn}

其中$J_i$是$i$的匹配对照集合。变体包括有放回匹配、丢掉没有近匹配的处理单位的卡尺，以及使用许多对照加权平均的核匹配。

匹配不要求线性的$m_d(x)$。它确实要求重叠：没有邻居的处理单位要么被丢掉（把估计对象改向有支撑的那些人），要么被匹配到远处的单位（偏误）。阿巴迪与因本斯（2006，2011）导出渐近分布；当$X$连续且邻居数固定时需要偏误修正项，因为匹配差距消失得不够快。

离散$X$上的**精确匹配**是非参数回归：在每个格子内，均值差是$\hat\tau(x)$，ATT是那些差的处理加权平均。当$X$丰富时格子变空——**维数灾难**。倾向得分是标准的降维。

## 倾向得分

::: theorem 罗森鲍姆–鲁宾 {#thm-pscore}
若$\bigl(Y_i(1), Y_i(0)\bigr) \perp D_i \mid X_i$且$e(x) \in (0,1)$，则$\bigl(Y_i(1), Y_i(0)\bigr) \perp D_i \mid e(X_i)$。在标量倾向得分上平衡就足以得到可忽略性；不必在整个$X$上平衡。
:::

::: proof
给定$X_i$时$D_i$是参数为$e(X_i)$的伯努利，故$D_i \perp X_i \mid e(X_i)$。与给定$X_i$的可忽略性合在一起，这意味着给定$e(X_i)$的可忽略性。（Rosenbaum and Rubin 1983，定理3。）
:::

实践流程是：（i）用$D$对$X$的logit（或更灵活的分类器）估计$e(x)$；（ii）通过画出$\hat e(X)$的两个密度并修剪得分接近$0$或$1$的单位来检查**重叠**；（iii）通过比较$\hat e$各层内、或加权后处理组与对照组中$X$的均值来检查**平衡**；（iv）通过在$\hat e$上匹配、按$\hat e$分层或逆概率加权来估计$\tau$。

::: definition 逆概率加权 {#def-ipw}
两个潜在结果均值以及ATE的**霍维茨–汤普森**（IPW）估计量为

$$
\hat\mu_1 = \frac{1}{n}\sum_{i=1}^n \frac{D_i Y_i}{\hat e(X_i)}, \qquad \hat\mu_0 = \frac{1}{n}\sum_{i=1}^n \frac{(1-D_i) Y_i}{1-\hat e(X_i)}, \qquad \hat\tau_{\mathrm{IPW}} = \hat\mu_1 - \hat\mu_0.
$$ {#eq-ipw}

**哈耶克**版本用权重之和代替$n$，这常常减小方差。对ATT，用$\hat e(X)/(1-\hat e(X))$给未处理加权，用$1$给处理加权。
:::

IPW是饱和倾向上的回归，换了一套行头：它再加权处理与未处理样本，使$X$的分布匹配总体（或处理组）。当$\hat e$接近$0$或$1$时权重爆炸，这是重叠问题在自我通报。修剪，或使用有界的“重叠权重”$e(1-e)$，是标准做法。

::: example 二元$X$上的精确匹配 {#ex-exact}
二十人，十人$X=0$，十人$X=1$。在$X=0$中，四人被处理，其$Y$均值为$6$；六名未处理者$Y$均值为$4$。在$X=1$中，八人被处理，$Y$均值为$14$，两名未处理者$Y$均值为$8$。在[[#eq-cia]]下，计算$\tau(0)$、$\tau(1)$、ATE与ATT。
::: solution
$\tau(0) = 6-4 = 2$，$\tau(1) = 14-8 = 6$。ATE为$\tfrac{10}{20}\cdot 2 + \tfrac{10}{20}\cdot 6 = 4$。处理组中（$4+8=12$人）$X=1$的份额为$8/12 = 2/3$，故$\tau_{\mathrm{ATT}} = \tfrac13\cdot 2 + \tfrac23\cdot 6 = 14/3 \approx 4.67$。精确匹配*就是*这些格子差；当$X$是在两个格子都有重叠的单个虚拟变量时，不需要倾向得分。
:::
:::

::: example 四个观测的IPW {#ex-ipw}
四个单位：$(D, Y, e(X)) = (1, 10, 0.5)$，$(1, 14, 0.8)$，$(0, 6, 0.5)$，$(0, 8, 0.2)$。计算霍维茨–汤普森ATE。
::: solution
$$
\hat\mu_1 = \tfrac14 \Bigl(\frac{10}{0.5} + \frac{14}{0.8} + 0 + 0\Bigr) = \tfrac14(20 + 17.5) = 9.375,
$$
$$
\hat\mu_0 = \tfrac14 \Bigl(0 + 0 + \frac{6}{0.5} + \frac{8}{0.8}\Bigr) = \tfrac14(12 + 10) = 5.5,
$$
故$\hat\tau_{\mathrm{IPW}} = 9.375 - 5.5 = 3.875$。（按权重之和正规化的哈耶克版本这里给出$4.77$；$n=4$时二者不同。在大样本且得分估计良好时它们通常一致。）
:::
:::

## 什么会出错

**遗漏的混杂因素。** 条件可忽略性不可检验。一个本不应受处理影响的安慰剂结果（处理前分数、在$D$之前决定的变量）*可以*被检验：其估计“效应”应为零。非零安慰剂是反对可忽略性的证据；零安慰剂与之相容但不能证明它。敏感性分析（罗森鲍姆界；Cinelli and Hazlett 2020）问一个未观测混杂因素必须有多强才能解释掉$\hat\tau$。

**坏控制变量，再次。** 处理后变量不属于$X$。职业、项目后工资，以及入学后测量的“此人是否有动力”是结果、中介或对撞因子。对它们条件化会改变估计对象，并可以制造给定处理前$X$的可忽略性本已去掉的偏误。见[[causal-inference/potential-outcomes#def-dag]]。

**倾向得分logit是一个模型。** 若$e(x)$误设，在$\hat e$上匹配与IPW不一致。双重稳健估计量（Robins、Rotnitzky与Zhao；AIPW估计量）把$m_d(x)$的模型与$e(x)$的模型结合起来，并在*任一*模型正确时保持一致。它们是统计学中很大一部分的默认；在应用经济学中，带灵活$X$与修剪重叠样本的OLS仍是最常见设定，匹配作为稳健性检查。

**拉隆德、德赫贾–瓦哈巴，以及史密斯–托德。** 拉隆德（1986）发现，使用CPS或PSID对照的回归与选择修正估计量并未复现NSW实验ATT。德赫贾与瓦哈巴（1999）把NSW样本限制到有两年处理前收入的子集，在倾向得分上匹配，施加共同支撑，并接近实验数字。Smith and Todd（2005）表明结果对样本限制与对照组敏感：匹配不是无论设计如何都有效的配方。对这一文献的当前解读是：当（i）有吸收大量$Y_i(0)$的处理前结果可用（阿申费尔特低谷：人们在收入低谷后进入培训，故滞后$Y$是关键控制），（ii）重叠是真实的而非外推的，以及（iii）对照来自同一劳动市场时，可观测选择可以有效。这些失败时，正确的回应是另一种设计，而不是更复杂的倾向。

::: example 处理前结果上的安慰剂 {#ex-placebo-soo}
一项就业培训研究在控制年龄、性别与教育后，对项目后年收入估计$\hat\tau = 2{,}000$。同一设定，以*去年*收入为结果，产生$\hat\tau_{\mathrm{pre}} = 1{,}800$。这对给定那些$X$的[[#eq-cia]]说明了什么？
::: solution
去年收入是处理前结果，故对其真实效应为零。$1{,}800$的“效应”意味着，给定年龄、性别与教育，处理组本已比未处理组挣得多得多（或处于低谷——符号取决于情况）。给定*那些*$X$的条件可忽略性失败。把去年收入加入$X$是显然的下一设定；这也是阿申费尔特低谷的教训。小的安慰剂$\hat\tau_{\mathrm{pre}}$本不会*证明*[[#eq-cia]]，但这个大的足以拒绝它。
:::
:::

::: warning 平衡检验不是识别检验
一张显示匹配后处理组与对照组$X$均值接近的表，是匹配做了其*机械*工作的检查。它不是[[#eq-cia]]成立的证据。未观测混杂因素不出现在表中。还可以通过丢掉不平衡的$X$来操纵该表。在看$\hat\tau$之前报告$e(x)$的设定，并在预先指定的清单上报告平衡。
:::

::: quiz
在条件可忽略性与重叠下，$Y$对$D$与线性$X$的OLS估计
- [ ] ATE，总是
- [x] $\tau(x)$的方差加权平均，若$\tau(x)$为常数则等于ATE，但一般不等于
- [ ] ATT，总是
- [ ] 没有任何因果含义，因为OLS要求随机化
::: solution
[[#prop-ols-weights]]：OLS按$e(x)(1-e(x))$给格子加权。当处理效应同质、或$e(x)$碰巧为常数时，该加权平均等于ATE。它也不自动是ATT（ATT按处理组$X$的分布给格子加权）。在可忽略性下OLS*可以*是因果的；它不要求无条件随机化。
:::
:::

## 证据

在NSW之外，可观测选择设计无处不在，其可信性随$X$的质量而变。Dale and Krueger（2002）比较被*同一组*大学录取但选择不同的学生，用录取集合作为未观测能力的代理；他们发现大学选择性的回报很小，远小于朴素收入差距。该设计是在一个信息量很大的$X$上匹配（你还被哪里录取）。Altonji、Elder与Taber（2005）用敏感性方法研究天主教学校教育：他们问相对于可观测选择，需要多少未观测选择才能解释估计效应，并发现所需选择很大。那不是可忽略性的证明；那是陈述怀疑者必须有多不舒服的一种方式。

在发展领域，许多对小额信贷、学校投入与健康项目的“准实验”评估仍依赖给定村庄与家庭协变量的条件独立主张。同一领域中的RCT（见[[causal-inference/randomised-experiments]]）常常发现更小的效应，这是拉隆德模式的重演。正确的回应不是丢掉每一个带控制的回归。而是对每一个$X$问：这是否足以使$D$可忽略，有没有重叠，以及另一种设计会给出什么。

::: application 当滞后结果是要紧的$X$
阿申费尔特（1978）注意到受训者的收入在报名当年下跌。受训者与未受训者的截面比较于是高估ATT，因为处理组被抓在低谷（阿申费尔特低谷）。控制项目前收入，或更好，看*变化*（这已经是迈向[[causal-inference/difference-in-differences]]的一步），吸收选择的很大一部分。在任何人们在冲击后*选择*进入的项目评估中，滞后$Y$不是可有可无的额外项。它是使[[#eq-cia]]最不离谱的协变量。
:::

**1983年，罗森鲍姆（Paul Rosenbaum）与鲁宾（Donald Rubin）。** “The Central Role of the Propensity Score in Observational Studies for Causal Effects”（*Biometrika*）证明了[[#thm-pscore]]，并提议在$e(x)$上分层与匹配。该文是应用工作谈论倾向得分的原因。

**1986年与1999年，拉隆德与德赫贾–瓦哈巴。** 拉隆德的*AER*批评表明当时使用的可观测选择估计量未能通过实验检验。德赫贾与瓦哈巴的*JASA*回应表明，在倾向得分上匹配，加上共同支撑限制与两年处理前收入，可以恢复NSW基准——同样重要的是，结果依赖于那些选择。

**1998年，安格里斯特（Joshua Angrist）。** “Estimating the Labor Market Impact of Voluntary Military Service Using Social Security Data on Military Applicants”（*Econometrica*）导出了带虚拟协变量的OLS的方差加权解释，即其原始设定中的[[#prop-ols-weights]]。
:::

## 通向何处

若你不相信给定你拥有的$X$时的[[#eq-cia]]，你需要一个移动$D$、除通过$D$外不移动$Y$的变量：工具，见[[causal-inference/iv-and-late]]。若处理由切断点分配，你不需要全局可忽略性，只需局部：[[causal-inference/regression-discontinuity]]。若你有对照组与处理前时期，平行趋势可以在水平上代替可忽略性：[[causal-inference/difference-in-differences]]。当$X$真正丰富——滞后结果、录取集合、行政资格记录——并且重叠是事实而非外推时，可观测选择仍是正确的工具。

::: summary
- 条件可忽略性加重叠把ATE与ATT识别为格子特定处理–对照差的平均（[[#prop-soo]]）。假定是每一个混杂因素都在$X$中。
- 带线性控制的OLS估计$\tau(x)$的方差加权平均，不自动是ATE（[[#prop-ols-weights]]）。饱和设定与IPW恢复ATE加权。
- 匹配使反事实明确，并使重叠失败看得见。倾向得分把$X$降为对可忽略性充分的标量（[[#thm-pscore]]）。
- 逆概率加权把各组再加权到$X$的目标分布；巨大权重是重叠差的诊断（[[#def-ipw]]）。
- 安慰剂结果、预先指定$X$上的平衡、修剪与敏感性分析探查设计。它们不能证明可忽略性。拉隆德的警告仍然适用：一种方法在能够在类似你的情境中恢复已知实验基准时才可信。
:::

## 习题

::: exercise 格子差 {level=1 check="4"}
在$X = x$的格子中，处理均值为$14$，未处理均值为$10$。在[[#eq-cia]]下，$\tau(x)$是多少？（输入整数。）
::: solution
$\tau(x) = 14 - 10 = 4$。
:::
:::

::: exercise 重叠 {level=1}
一个协变量格子有$80$个处理单位与$0$个未处理单位。[[#def-cia]]的哪一部分失败，这对ATE意味着什么？
::: solution
重叠失败：此格子中$e(x) = 1$。条件可忽略性或许仍为真，但$\E[Y_i(0) \mid X=x]$不能由数据识别——没有未处理单位可读它。ATE对包括此格子在内的$X$分布平均$\tau(x)$，若不从其他格子外推$m_0$就不能识别。
:::
:::

::: exercise 两个观测的IPW {level=1 check="5"}
两个单位：处理$(Y=12, e=0.5)$与未处理$(Y=7, e=0.5)$。$n=2$时霍维茨–汤普森$\hat\tau_{\mathrm{IPW}}$是多少？（输入整数。）
::: solution
$\hat\mu_1 = \tfrac12 \cdot 12/0.5 = 12$，$\hat\mu_0 = \tfrac12 \cdot 7/0.5 = 7$，故$\hat\tau = 5$。二者$e=0.5$时，IPW与原始差一致。
:::
:::

::: exercise OLS对ATE权重 {level=2}
有两个等可能的格子。格子$A$中$e(A) = 0.5$，$\tau(A) = 10$。格子$B$中$e(B) = 0.1$，$\tau(B) = 0$。计算ATE以及[[#prop-ols-weights]]中的OLS估计对象。
::: solution
ATE为$\tfrac12 \cdot 10 + \tfrac12 \cdot 0 = 5$。OLS权重与$e(1-e)$成比例：$w(A) \propto 0.5\cdot 0.5 = 0.25$，$w(B) \propto 0.1\cdot 0.9 = 0.09$，故$w(A) = 0.25/0.34 \approx 0.735$，$w(B) \approx 0.265$。于是$\tau_{\mathrm{OLS}} \approx 0.735\cdot 10 + 0.265\cdot 0 = 7.35$。OLS给平衡格子过大权重，报告比ATE更大的效应。
:::
:::

::: exercise 匹配ATT {level=2 check="5.5"}
处理单位：$(X,Y) = (2, 12)$与$(5, 18)$。未处理：$(1, 8)$，$(4, 11)$，$(6, 13)$。把每个处理单位匹配到其最近邻（$X$上的欧氏距离；平局时选较小的$X$）。$\hat\tau_{\mathrm{ATT}}$是多少？（输入一位小数。）
::: solution
$X=2$匹配到$X=1$（$Y=8$）；$X=5$距$4$与$6$相等，较小的$X$是$4$（$Y=11$）。两个差为$12-8 = 4$与$18-11 = 7$，故$\hat\tau_{\mathrm{ATT}} = (4+7)/2 = 5.5$。
:::
:::

::: exercise IPW的ATT加权 {level=2}
用一段话说明为何ATT对处理组用权重$1$、对未处理组用$e(X)/(1-e(X))$，而不是ATE权重$D/e$与$(1-D)/(1-e)$。
::: solution
ATT是$\E[Y(1)-Y(0) \mid D=1]$。处理组已经具有$X$的目标分布（处理组分布），故不需要再加权：其均值$Y$估计$\E[Y(1) \mid D=1]$。未处理组必须被再加权以看起来像处理组。机会比$e(X)/(1-e(X))$恰好是把未处理的$X$分布映到处理分布的Radon–Nikodym因子，依据通常恒等式$\Prob(D=1 \mid X)/\Prob(D=0 \mid X) = e/(1-e)$。ATE则把*两组*都再加权到$X$的总体分布。
:::
:::

::: exercise 一个后门计算 {level=3}
$X \in \{0,1\}$，$\Prob(X=1)=0.5$。处理概率：$e(0)=0.25$，$e(1)=0.75$。条件均值：$\E[Y \mid D=1, X=0] = 6$，$\E[Y \mid D=0, X=0] = 4$，$\E[Y \mid D=1, X=1] = 14$，$\E[Y \mid D=0, X=1] = 8$。在[[#eq-cia]]下计算$\tau_{\mathrm{ATE}}$与$\tau_{\mathrm{ATT}}$。
::: hint
先计算$\tau(0)$与$\tau(1)$，再由贝叶斯法则得到处理组中$X$的分布。
:::
::: solution
$\tau(0) = 6-4 = 2$，$\tau(1) = 14-8 = 6$。ATE为$\E[\tau(X)] = 0.5\cdot 2 + 0.5\cdot 6 = 4$。对ATT，$\Prob(X=1 \mid D=1) = e(1)\Prob(X=1)/\pi$，其中$\pi = 0.5\cdot 0.25 + 0.5\cdot 0.75 = 0.5$，故$\Prob(X=1 \mid D=1) = 0.75\cdot 0.5 / 0.5 = 0.75$。于是$\tau_{\mathrm{ATT}} = 0.25\cdot 2 + 0.75\cdot 6 = 5$。处理组集中在高$X$格子，那里效应更大。
:::
:::

::: exercise 为何线性控制在外推 {level=3}
设$D_i = 1\{X_i \ge 0\}$，$Y_i(0) = X_i^2$，$Y_i(1) = X_i^2 + 1$，且$X_i$关于$0$对称。给定$X$时可忽略性成立（事实上$D$是$X$的确定性函数）。重叠成立吗？$Y$对$D$与$X$的线性回归会在估计什么，为何它不是ATE的$1$？
::: solution
重叠处处失败：$e(x) \in \{0,1\}$。ATE是$1$，但不能从$X$格子*内部*的处理–对照比较识别，因为没有格子同时含两组。$Y$对$D$与$X$的线性回归用一条$X$上的斜率去拟合二次的$Y(0)$，用未处理单位（$X<0$）去猜测处理单位（$X>0$）的$Y(0)$。由于$X^2$是偶函数，$X$的线性项大约为$0$，虚拟变量$D$会试图吸收$\{X>0\}$与$\{X<0\}$的平均差，即$1$加上均值$X^2$之差——而由对称性均值$X^2$两侧相同，故在这一特殊情形OLS碰巧恢复$1$。若改为$Y(0) = e^{X}$，未处理侧看起来不像处理侧，虚拟变量严重有偏。这个例子是RDD（再后两章）在切断点使用*局部*比较而不是全局线性控制的原因。
:::
:::

::: exercise 用文字说双重稳健 {level=3}
增广IPW（AIPW）估计量在IPW上加入项$(D - \hat e) \bigl(\hat m_1(X)/\hat e - \hat m_0(X)/(1-\hat e)\bigr)$，其中$\hat m_d$是组$d$中$Y$对$X$的回归。说明为何在倾向正确或两个回归正确（不必二者都正确）时这是一致的。
::: solution
若$\hat e \to e$，IPW已经一致，且加入项均值为零，因为$\E[D-e \mid X] = 0$，无论$\hat m_d$如何。若$\hat m_d \to m_d$但$\hat e$错误，IPW部分不一致，但加入项恰好是从该不一致性在$X$上的投影中减去的影响函数修正；两个误差抵消，剩余是$\E[m_1(X)-m_0(X)]$的样本类似物，在可忽略性下这就是ATE。那就是双重稳健：两个模型，其中一个可以错。（Robins、Rotnitzky与Zhao 1994是原文；教材处理见Hernán与Robins，《What If》。）
:::
