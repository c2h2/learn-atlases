一名学生有一个空闲的晚上。她可以去上有报酬的班次、复习考试，或与朋友去听音乐会。三件事不能同时做。这个小小的事实就是整门学科的缩影。**经济学**研究人们、企业与政府在资源——时间、土地、劳动、机器、注意力——有限而欲望并非有限时如何选择。这个晚上是稀缺的；护士的劳动、流域里的水、政府预算的容量同样稀缺。一旦一种资源有一种以上的有价值用途，选择就有成本：被放弃之物的价值。

本章把这一观察变成一套方法。我们定义稀缺性与机会成本，画出生产可能性边界使权衡可见，并说明为何可以一点一点调整的决策者应当比较**边际**收益与**边际**成本。然后考察激励、模型的用途与限度，以及“是什么”与“应当是什么”的区分。后面的章节会在这套脚手架上安放价格、市场和国民账户。脚手架本身就是经济学的思维方式。

## 稀缺性与机会成本

一种资源若在价格为零时人们想要的数量超过现有数量，就是稀缺的。偏远山谷中的清洁空气在这个意义上可能并不稀缺；拥堵城市中的清洁空气则是稀缺的。稀缺性是手段与目的之间的关系，不是物体的一种属性。同一桶石油在工业经济中是稀缺的，对一个没有用途的社会则不会稀缺。

::: definition 稀缺性 {#def-scarcity}
一种商品或资源是**稀缺的**，如果在零价格下人们希望使用的数量超过可供数量。经济学研究具有多种用途的稀缺手段如何配置。
:::

莱昂内尔·罗宾斯（Lionel Robbins）把同一思想写成一句此后被反复引用的话：经济学“把人类行为当作目的与具有多种用途的稀缺手段之间的关系来研究”（《经济科学的性质和意义》，*An Essay on the Nature and Significance of Economic Science*，1932年，第16页）。关于多种用途的那一从句才是关键。若一种手段只有一种用途，就没有什么可选择。

因此，选择的成本首先并不是转手的货币。货币是方便的量尺。对决策真正要紧的成本，是该决策所排除的次优备选的价值。

::: definition 机会成本 {#def-opportunity-cost}
一项选择的**机会成本**是被放弃的最佳备选的价值。它既包括显性支出，也包括决策者已经拥有的资源（其中有时间）的隐含价值。
:::

机会成本是面向未来的。已经花掉且无法收回的，是**沉没成本**，不属于对剩余备选的比较。已经买了不可退票的学生，仍然面对如何度过这个晚上的选择；票价无论怎样都已经没了。

::: example 音乐会与班次 {#ex-concert}
一名学生可以上三小时晚班，工资为每小时18货币单位，或者去听音乐会。门票为48单位，一经购买不可退。她尚未买票。去听音乐会的机会成本是多少？买票之后，*出席*的机会成本是多少？
::: solution
买票之前，去听音乐会意味着支付48，并放弃本来可以挣得$3 \times 18 = 54$的三小时。机会成本是$48 + 54 = 102$货币单位（再加上她对班次的评价相对金钱或低或高的部分：若她讨厌这份工作，时间的隐含成本低于54；若她会喜欢这个班次，则更高）。票已买且不能转售之后，48已经沉没。出席便只再花费损失的工资54——以及这三小时的次优用途，若那不是工作。
:::
:::

这个例子是算术，但其中已经有建模选择。我们用工资度量时间的价值。当她可以按给定工资任意工作、且晚上没有其他被看重的用途时，这是合理的。若班次并不在可选之列，或晚上的次优用途是无偿照料亲人，这就不合理。机会成本由实际备选定义，不是由账本上的一行定义。

::: warning 会计成本不是机会成本
常见错误是把付出的货币当作全部成本，或把沉没支出算进面向未来的决策。会计师眼中一次出行的成本是燃料、折旧和一份保险。经济学家眼中同一次出行的机会成本，是燃料、车辆和时间的最佳备选用途。无论是否出行都会发生的折旧，不属于这项决策。已经买下的票也不属于。
:::

企业与政府面对同一套逻辑。一座城市把一块值钱的地用作停车场，就放弃了这块地作为住房或店铺本可赚得的租金。一个部委把它最好的工程师派到一个项目，就放弃了他们对另一个项目的贡献。据世界银行（世界发展指标，2026年访问），2023年按当期市场价格计的GDP，美国约为27.8万亿美元，中国约为18.3万亿美元，印度约为3.5万亿美元，巴西约为2.2万亿美元。这些数字度量生产，不是福祉，也没有说明同样的劳动和资本本可以生产别的什么。机会成本是缺失的那一栏。

## 权衡与生产可能性边界

当一种资源可以生产一种以上的产出时，可行组合的集合可以画出来。最简单的图是**生产可能性边界**（PPF）：在给定资源与技术下，这些资源被充分且有效率地使用时所能生产的边界。

::: definition 生产可能性边界 {#def-ppf}
**生产可能性边界**是在给定资源与技术下、这些资源被充分且有效率地使用时所能生产的产出束的集合。边界内部的点可行但浪费；外部的点不可行。边界的斜率是横轴商品多生产一单位的机会成本，用纵轴商品的单位来度量。
:::

对单个人，两种“商品”可以是时间的两种用途。设一名学生有6小时，每小时可做4顿饭或读20页书。若她用$c$小时做饭，则生产$M = 4c$顿饭和$P = 20(6 - c)$页。消去$c$得到边界

$$
P = 120 - 5M, \qquad 0 \le M \le 24.
$$ {#eq-student-ppf}

每一顿额外的饭花费5页。机会成本是常数，因为我们假定每一小时的生产率都相同。当资源是专门化的——一天中某些小时更适合阅读，某些地块更适合某一种作物——边界向外凸出，且每种商品的机会成本随其产量增加而上升。这种**递增的机会成本**是后面章节中的常见形状；直线是正确的起点，因为那时斜率是一个单一的数。

labels: \text{学生的PPF}; \text{对照PPF}

::: example 外凸的边界 {#ex-bowed}
一个小农场可以种玉米和豆子。土地全部种玉米时生产10吨玉米、零豆子；全部种豆子时生产6吨豆子、零玉米。中间配置，以吨计$(\text{玉米}, \text{豆子})$，为$(8, 2)$、$(5, 4)$和$(2, 5.5)$。画出边界，并计算最初2吨豆子、随后2吨、以及最后1.5吨的机会成本。
::: solution
从$(10, 0)$到$(8, 2)$，农场为2吨豆子放弃2吨玉米，故最初2吨豆子的机会成本是每吨豆子1吨玉米。从$(8, 2)$到$(5, 4)$，为2吨豆子放弃3吨玉米，机会成本为每吨豆子$1.5$吨玉米。从$(5, 4)$到$(2, 5.5)$，为1.5吨豆子放弃3吨玉米，机会成本为每吨豆子2吨玉米。从$(2, 5.5)$到$(0, 6)$，最后0.5吨豆子花费2吨玉米，即每吨豆子4吨玉米。当豆子把玉米挤到越来越不适合豆子的土地上时，机会成本上升。过这些点的边界离开原点向外凸。
:::
:::

沿边界的移动是对已充分使用的资源的再配置。从内部移向边界是减少浪费——闲置劳动、关掉的机器、禁止互利交换的禁令。边界本身的移动来自更多资源或更好技术。区分这三者，是本课程在[[principles/supply-and-demand]]中讨论需求与供给时还要用的习惯。

PPF对一个社会应当选择边界上的*哪一点*保持沉默。这一选择取决于偏好，在市场经济中还取决于价格。那是另一个问题，在[[principles/markets-and-welfare]]讨论效率与分配时再处理。

## 在边际上决策

许多选择并不是全有或全无。企业决定本周多生产多少单位；通勤者决定是否多走一趟；政府决定是否把路再延长一公里。此时相关的比较不是总收益与总成本，而是下一步很小一步的收益与成本——**边际**。

::: definition 边际收益与边际成本 {#def-marginal}
一项活动的**边际收益**（MB）是再多一单位带来的额外收益。**边际成本**（MC）是再多一单位的额外成本。二者都在其他条件不变下定义，并且都可以取决于这项活动已经进行了多少。
:::

若MB超过MC，再多做一点会提高净收益。若MC超过MB，少做一点会提高净收益。当活动可以连续变动且函数性状良好时，净收益的最大值出现在二者相等处。

::: proposition 边际相等 {#prop-mb-mc}
设决策者选择一项活动的数量$x \ge 0$，得到收益$B(x)$、承担成本$C(x)$，二者皆可微，$B$凹而$C$凸。净收益$B(x) - C(x)$在内点$x^*$处最大化，当且仅当

$$
B'(x^*) = C'(x^*),
$$ {#eq-mb-mc}

即$\mathrm{MB}(x^*) = \mathrm{MC}(x^*)$，且二阶条件$B''(x^*) - C''(x^*) \le 0$成立。若$B'(0) \le C'(0)$，则最大值在$x^* = 0$。
:::

::: proof
令$N(x) = B(x) - C(x)$。在内点最大值处，$N'(x^*) = 0$，故$B'(x^*) = C'(x^*)$。$B$的凹性与$C$的凸性使$N$为凹，故一阶条件是充分的。若$N'(0) \le 0$，则$N$在$[0, \infty)$上递减，最大值在边界$x = 0$。
:::

同一条件可以从图上读出。把MB和MC对$x$画出。交点是候选最优。若MB开始时高于MC并下降，而MC上升，则交点唯一。

caption: 一小时学习的边际收益$20 - 2x$，对照等于工资$w$的时间机会成本（常数）。在$w = 12$时曲线交于$x = 4$小时。提高工资：学生学习得更少。交点左侧MB与MC之间的面积，是学习而非工作的净收益。

::: example 学习的小时数 {#ex-study}
一名学生有一份每小时12货币单位的有酬工作，小时数可任选。第$x$小时学习的边际收益，以同样单位计，为$20 - 2x$，反映额外复习的报酬递减。她应当学习多少小时？若考试就在明天，边际收益表变为$28 - 2x$呢？
::: solution
令$20 - 2x = 12$。则$2x = 8$，$x^* = 4$。第四小时值12，等于工资；第五小时值10，更少。若MB移至$28 - 2x$，则$28 - 2x = 12$给出$x^* = 8$。在工资不变时，学习的回报更高，会拉长书桌前的晚上。决策不需要学习的总收益；只需要边际。
:::
:::

::: quiz
一名通勤者可以按每趟3单位的票价任意乘坐公交车。第一到第六趟的边际收益，以同样单位计，为$15, 11, 8, 6, 2, 1$。她乘坐多少趟？
- [ ] 2，因为那是MB首次超过票价之处
- [x] 4，因为第四趟是最后一趟$\mathrm{MB} \ge 3$的
- [ ] 5，因为第五趟仍有正的MB
- [ ] 6，以用尽每一趟有正收益的行程
::: solution
对每一单位，若$\mathrm{MB} \ge \mathrm{MC}$就乘坐，并在第一个$\mathrm{MB} < \mathrm{MC}$的单位之前停下。前四趟的边际收益为$15, 11, 8, 6$，都不小于3。第五趟的MB为2，低于票价。她乘坐四趟。离散单位不必恰好打到$\mathrm{MB} = \mathrm{MC}$；它们在格子允许的范围内尽量接近。正的MB不够：第五、第六趟仍有正收益，但不足以覆盖票价。
:::
:::

边际推理也是经济学家思考**沉没成本**的方式。一家已经在一台无法转售的机器上花费50的企业，不应把这50加进使用该机器的成本。使用它只有在磨损它或挡住另一种用途时才有机会成本。这50已经没了。

::: example 未完成的项目 {#ex-sunk}
一家企业已经在一个项目上花费70。完成它还要再花40，并将带来90的收入。放弃则得到0。这70无法收回。企业应当完成该项目吗？
::: solution
70已经沉没。完成带来$90 - 40 = 50$的净额外现金；放弃得到0。应当完成。会计合计$90 - 110 = -20$是相对于从未开工的亏损，但那种比较已经不再可得。另一种错误是：仅仅为了“让沉没成本变得值得”，去完成一个*剩余*成本已超过剩余收益的项目。
:::
:::

## 激励

若一项行动的成本或收益改变，人们就会多做或少做。这句话是经验主张，不是道德主张，也是政策改变时经济学家首先看**激励**的原因。

对一种商品征税，会提高买者支付的价格或降低卖者得到的价格，或二者兼有；[[principles/markets-and-welfare]]一章计算这一分割。补贴则相反。价格上限若有约束力，会使法定价格对卖者更不划算，并通常缩短供给。这些主张都没有说该政策是好是坏。它们说的是：若人们对新的相对价格作出反应，会推出什么。

激励的作用不止通过价格。绩效奖金改变努力的回报。按考试分数录取学生的大学提高了复习的回报，也提高了补习的回报，在最坏的情形下还提高了作弊的回报。设计良好的激励与人们真正想要的结果对齐；设计不良的激励会被钻空子。后续课程[[information-economics]]和[[public-economics]]把这一点当作约束，而不是事后补丁。

人与人不同，并非人人都反应。有些通勤者在任何说得过去的票价下都会坐车；有些人永远不坐。经济学家的主张是关于平均、以及关于接近边际的那些人——对他们而言MB与MC接近，因而其中之一的小小变化就会翻转决策。政策往往通过那些人起作用。

::: intuition 谁在边际上？
当一座城市把公交车票价提高一小点时，停止乘坐的是那些边际收益刚刚高于旧票价、而现在刚刚低于新票价的乘客。边际内乘客——MB高得多的那些——继续乘坐，只是多付钱。关于“人们会做什么”的陈述，几乎总是关于边际群体的陈述，其规模是一个经验问题。
:::

## 模型、其他条件不变与证据

**模型**是一种简化描述，保留所关心的机制、丢掉其余。下下一章的供求图有两条曲线和一个价格。它没有产品的颜色、交易者的生平或天气，除非这些东西会使一条曲线移动。这一纪律的口号是*ceteris paribus*：其他条件不变。

本课程中的模型有三种用法。第一，定义术语——均衡、弹性、剩余——使我们知道自己在谈什么。第二，推导含义：若需求是线性的、供给是线性的，需求的平行移动会把价格和数量提高我们可以算出来的幅度。第三，作为证据的模板：模型说明在把相关当作对价格的反应之前，必须把哪些其他事物保持不变或加以调整。

模型可以既有用又为假。**价格接受**的假设——没有任何买者或卖者能推动市场价格——对只有一座粮磨的村庄为假，对有许多磨坊的批发市场则是好的近似。判断模型不是列出哪些假设并非字面上为真；而是问：当假设被放松时，结论是否仍然近似成立。这是[[microeconomics]]和[[econometrics]]的主题。

本图谱仅供教育学习，不构成投资或理财建议。例题中的说明性数字是虚构的。当出现真实量值时，它们说明一个概念，带有来源和日期，并且不是预测。

## 实证主张与规范主张

::: definition 实证与规范 {#def-positive-normative}
**实证**主张是关于在所述条件下是什么、曾是什么或会是什么的主张。它至少在原则上可由证据判定真假。**规范**主张是关于应当是什么的主张。它既依赖于事实，也依赖于价值。
:::

“对此商品征收6单位的税会使成交量从32降到24”是实证的。“政府应当征这种税”是规范的。前者在给定需求曲线、供给曲线和市场出清的假设下可以核对。后者需要关于谁的福利算数、如何权衡不平等、以及政府还能用这笔收入做什么的看法。

经济学家对第二个问题没有特殊权威。他们对第一个问题有工具，并且对一类*把目标视为给定*的受限规范陈述也有工具：若目标是以总剩余的最小损失筹集给定数量的收入，则在所述假设下，税应更重地落在市场缺乏弹性的一侧（[[principles/elasticity]]，[[principles/markets-and-welfare]]）。即便这个“应当”，也是给定目标下的应当。目标本身是价值判断。

经济学中的争论两类都有，而且容易混在一起。更高的最低工资是否减少某一劳动市场中的就业，是一个实证问题，卡德（Card）与克鲁格（Krueger，1994）以及随后的研究在幅度上、有时在符号上并不一致。给定的就业效应是否值得为留下的就业者支付更高工资，是一个规范问题。本课程将把相互竞争的实证主张连同其证据一并呈现，并标出价值判断，而不是把它们藏在用词里。

::: quiz
下列哪一项是实证主张？
- [ ] 食物应当更便宜。
- [x] 其他条件不变，对食物有约束力的价格上限会减少供给量。
- [ ] 房东提高租金是不公平的。
- [ ] 政府应当对碳征税。
::: solution
第二句是关于数量的预测，在[[principles/supply-and-demand]]的模型下或真或假。另外三句使用“应当”“不公平”和“应当”：它们是规范的，即便有人同意它们。
:::
:::

## 证据

经济学的思维方式是一套问题，不是主张人是自私的或市场总是有效的。这些问题在经验上找到的，是混杂而具体的。

人们的确对相对价格作出反应。当一种主食价格上升时，低收入国家的家庭通常会把数量略微削减，并把其他支出削减得更多；食物的需求价格弹性为负，但绝对值往往远低于1（这一模式在许多场合有记载；例如见稍后[[principles/elasticity]]一章综述的估计）。当一种职业的工资相对另一种上升时，新的队列会转向报酬更好的职业，尽管在职工人移动得更慢。这一切并不要求人们像[[#ex-study]]中的学生那样最优化；它要求*某些*人在边际上注意到条件的变化。

人们也会把钱留在桌上。从最后通牒博弈开始的实验室实验发现，被试会拒绝他们本可以有利可图地接受的不均等分割（Güth、Schmittberger与Schwarze，1982年，*Journal of Economic Behavior & Organization*）。田野实验发现，养老金登记的默认选项会急剧改变参与，这一事实被用于——也被争论于——行为公共政策（Madrian与Shea，2001年，*Quarterly Journal of Economics*）。这些发现并不废除机会成本；它们限定了决策者感知并据此行动的假设。[[behavioural-economics]]讨论这些限定。

宏观经济的量级为后面的章节提供尺度感。2023年，按当期美元计的世界GDP约为105万亿美元（世界银行WDI，2026年访问）。同一来源报告的各国数字约为：美国27.8万亿美元，中国18.3万亿美元，德国4.6万亿美元，印度3.5万亿美元，巴西2.2万亿美元，印度尼西亚1.4万亿美元。这些是按市场汇率计的生产总额，不是典型生活水平的度量；人均GDP和购买力平价比较会给出不同的排序，[[principles/measuring-the-macroeconomy]]将加以整理。

::: history
**1932年，莱昂内尔·罗宾斯（Lionel Robbins）。**在《经济科学的性质和意义》（*An Essay on the Nature and Significance of Economic Science*）中，罗宾斯把经济学定义为把人类行为当作目的与具有多种用途的稀缺手段之间的关系来研究。这一定义取代了把学科绑在“物质福利”或财富上的旧定义，也是本章所用的定义。它并不说目的是自私的，或市场是唯一的配置机制；它说的是：只要手段稀缺且有一种以上用途，就存在经济问题。
:::

## 通向何处

下一章[[principles/gains-from-trade]]把两条生产可能性边界并排放在一起，问专业化和交换何时提高双方的消费。答案——比较优势——就是把机会成本应用于两个人或两个国家。随后[[principles/supply-and-demand]]让价格来做协调，而本课程微观一半的其余部分问这种协调何时有效率、何时没有。宏观一半从度量而不是从选择开始，但沿一条关系移动与使关系本身移动的同一区分，以及对机会成本的同一坚持，都会回来。

若继续往下，[[microeconomics]]从偏好与技术重建消费者和企业，[[macroeconomics]]用预期与动态重建总需求与总供给。本章就是那些课程所假定的思维习惯。

::: summary
- 稀缺性意味着手段相对目的有限且有多种用途；零价格便会留下未满足的欲望。
- 一项选择的机会成本是被放弃的最佳备选的价值，包括时间等隐含成本；沉没成本不属于面向未来的决策。
- 生产可能性边界显示给定资源被充分、有效率地使用时所蕴含的权衡；其斜率是边际机会成本。
- 当数量可以一点一点变动时，通过使边际收益等于边际成本（或停在最后一个$\mathrm{MB} \ge \mathrm{MC}$的离散单位）使净收益最大化。
- 边际上的人对激励作出反应；改变相对价格或支付的政策会改变他们的行为，无论变好还是变坏。
- 模型把其他事物保持不变，以便分离一种机制。实证主张关于是什么或会是什么；规范主张关于应当是什么，并且既需要价值判断也需要证据。
:::

## 习题

::: exercise 失去的下午 {level=1}
一名顾问每小时可以开出80货币单位的账单。她花2小时排队购买一张25的票，然后观看一场3小时的比赛。票不能转售。计算（a）整个出行的机会成本，在她加入队列之前评估；（b）观看比赛的机会成本，在票已在手、队列已在身后时评估。
::: solution
（a）她放弃本可开出$5 \times 80 = 400$账单的5小时，外加票价25，故机会成本为425。（b）票和排队已经沉没。观看仍花费3小时的开账，即240。
:::
:::

::: exercise 线性PPF {level=1}
一个工场有10小时。每小时可生产3把椅子或5只碗。写出椅子$C$在横轴上的PPF方程，给出一把椅子的机会成本，并求若需要12把椅子时碗的最大数量。
::: solution
小时：$C/3 + B/5 = 10$，故$B = 50 - \tfrac{5}{3}C$，其中$0 \le C \le 30$。一把椅子的机会成本是$5/3$只碗。若$C = 12$，则$B = 50 - 20 = 30$只碗。
:::
:::

::: exercise 离散的小时 {level=1}
家庭维修各小时的边际收益，以货币单位计，第1到第5小时为$40, 28, 19, 12, 6$。有酬备选每小时支付15。应当做多少小时维修？若工资升至20呢？
::: solution
把每一小时与15比较：40、28和19超过15；12和6不超过。做3小时。若工资为20，只有前两小时（40和28）超过20；第三小时的MB为19，现已低于工资，故做2小时。
:::
:::

::: exercise 边界的移动 {level=2}
在[[#eq-student-ppf]]中，一台新炉具把做饭生产率从每小时4顿提高到6顿，阅读仍为每小时20页，可用时间仍为6小时。写出新的PPF。一顿饭的机会成本是上升了还是下降了？用第6顿饭的页成本说明。
::: solution
$M = 6c$，$P = 20(6-c)$，故$P = 120 - \tfrac{20}{6}M = 120 - \tfrac{10}{3}M$，其中$0 \le M \le 36$。一顿饭的机会成本从5页降到$10/3 \approx 3.33$页。第6顿饭过去花费5页，现在花费$10/3$页。顿数轴上的截距上升；页数轴上的截距不变，因为阅读生产率和小时数没有变。
:::
:::

::: exercise MB与上升的MC {level=2 check="5"}
一位农民从灌溉用水得到的边际收益，以每毫米的货币单位计，为$24 - 2x$，其中$x$是施用的毫米数。边际成本为$4 + 2x$（水越来越难抽）。求最优的$x$。（输入最优毫米数。）
::: solution
令$24 - 2x = 4 + 2x$。则$20 = 4x$，故$x^* = 5$。二阶条件成立，因为MB递减而MC递增：每一额外毫米对作物的价值更低，抽取成本更高。（输入5。）
:::
:::

::: exercise 沉没成本与第二个报价 {level=2}
一家剧院售出一张30的票。演出当晚一位朋友愿出18买这张票（剧院不退款）。持票人把演出估值20，且出席没有其他成本。她应当出席还是卖掉？若她把演出估值15呢？
::: solution
30已经沉没。出席得到价值20。卖掉得到18。出席，因为$20 > 18$。若她把演出估值15，则卖掉，因为$18 > 15$。原先的价格从不进入。
:::
:::

::: exercise 递增的机会成本 {level=3}
一个沿海地区生产鱼$F$和椰子$K$。可行的有效率束$(F, K)$为$(0, 12)$、$(4, 11)$、$(8, 8)$、$(12, 3)$和$(14, 0)$。计算每一段上鱼的机会成本，以每额外一单位鱼的椰子计。用一段话解释机会成本为何上升，以及为何像$(8, 6)$这样的点不在边界上。
::: hint
一段上的机会成本是绝对斜率$\lvert\Delta K / \Delta F\rvert$。分段线性边界下方的点浪费资源。
:::
::: solution
从$(0, 12)$到$(4, 11)$：$\lvert\Delta K/\Delta F\rvert = 1/4$。从$(4, 11)$到$(8, 8)$：$3/4$。从$(8, 8)$到$(12, 3)$：$5/4$。从$(12, 3)$到$(14, 0)$：$3/2$。机会成本上升，是因为该地区把鱼类生产移到对捕鱼越来越差（或对椰子越来越好）的水域和劳动上。点$(8, 6)$与$(8, 8)$有同样的鱼但椰子更少，故部分劳动或船只闲置或配置不当；它位于边界内部。
:::
:::

::: exercise 一层规范 {level=3}
一座城市可以按每名额外乘客2货币单位的边际成本（常数）运营一条公交线路，乘客的边际收益表为$12 - q$，其中$q$为乘客数。（a）使总剩余$B(q) - C(q)$最大化的数量是多少？（b）若城市收取票价2，该数量会达到吗？（c）一位议员说“票价应当为零，这样没有人被排除”。利用[[#def-positive-normative]]，把零票价所隐含的实证主张与规范主张分开，并在给定这些表的情况下陈述零票价的一项实证后果。
::: hint
总剩余在$\mathrm{MB} = \mathrm{MC}$处最大化。零票价设定的是乘客支付的价格，不是社会成本。
:::
::: solution
（a）$12 - q = 2$给出$q^* = 10$。（b）会：等于边际成本的票价使每位乘客当且仅当MB$\ge 2$时出行，而这正是此处的社会规则（无外部性）。（c）规范主张是：被排除是不可欲的，票价应当为零。隐含的实证主张是：在票价为0时，乘客会一直坐到$\mathrm{MB} = 0$，故$q = 12$。在$q = 12$时，MC仍为2而MB为0，因此额外两名乘客产生的社会损失等于MC与MB之间从10到12的面积：$\int_{10}^{12}(2 - (12-q))\,\mathrm{d}q = \int_{10}^{12}(q-10)\,\mathrm{d}q = 2$。这一损失是否值得为分配目标付出，是价值判断；损失本身是实证后果。
:::
:::
