一年期贷款与十年期贷款不是同一产品，即使两者都是支付货币的承诺。它们在货币何时到达、支付有多不确定、以及债权多容易被出售上不同。这些差别表现为收益率的差别。本章把债务债权上的收益率分成**风险结构**（给定期限下的违约、流动性、税收待遇）和**期限结构**（给定风险类别下收益率跨期限的形态）。

上一章为单只债券定义了到期收益率（[[money-banking/interest-rates]]）。这里必须解释整条由这些收益率组成的曲线。三种古典故事——纯预期、流动性（期限）溢价，以及市场分割——相互竞争，并且并不互斥。评级机构用一个字母概括违约风险；字母不是概率，但字母之间的转移矩阵是评级如何移动的可用模型。虚构债券上的数字是说明性的。注明日期的国债收益率是观察（FRED，H.15），不是预测，也不是被推荐的头寸。

## 利率的风险结构

承诺现金流日期相同的两只债券可以按不同收益率成交。缺口是**利差**，通常以基点报价（一个基点是0.01个百分点）。

::: definition 信用利差 {#def-spread}
风险债券的**信用利差**（或违约利差）是其到期收益率与同一货币、可比期限的政府（或其他无违约）债券收益率之差。**流动性利差**是其他方面相似但较不易交易的工具上的额外收益率。**税收利差**是可归因于支付的不同税收待遇的收益率缺口（例如，在某些利息免征所得税的制度中，应税债券与免税债券之间的缺口）。
:::

违约风险是大多数公司债和主权债相对本国政府曲线利差的主导成分。若债券承诺$C_t$但只以概率$1-\delta$支付（并在违约时支付面值的回收份额$\rho$），风险中性买者贴现的是*期望*支付，而不是承诺支付。由*承诺*现金流解通常现值方程得到的承诺收益率$y_{\mathrm{promised}}$于是超过无违约收益率。即使买者风险中性，

$$
y_{\mathrm{promised}} - y_{\mathrm{safe}} \approx (1-\rho)\delta
$$ {#eq-spread-approx}

对违约概率$\delta$较小的一期债券成立。风险厌恶买者要求更多；无法分散违约（单一名称集中）的买者也是。回收、概率和风险调整都在公布的利差之内，这就是150个基点的利差不是每年1.5%违约概率的原因。

::: proposition 一期风险中性利差 {#prop-rn-spread}
面值为1的一期风险债券以概率$1-\delta$支付$1$，以概率$\delta$支付$\rho$。一期安全债券支付1。若买者风险中性，且两只债券都按期望现金流上的同一贴现率$r$定价，则风险债券的承诺收益率$y$满足$1+y = (1+r)/\bigl(1-\delta(1-\rho)\bigr)$。因而当$\delta(1-\rho)$较小时$y-r \approx \delta(1-\rho)$。
:::

::: proof
风险债券的价格为$P = \bigl[(1-\delta)\cdot 1 + \delta\rho\bigr]/(1+r) = \bigl[1 - \delta(1-\rho)\bigr]/(1+r)$。其承诺收益率满足$P = 1/(1+y)$，因而$1+y = (1+r)/\bigl[1-\delta(1-\rho)\bigr]$。取对数，一阶有$y-r \approx \delta(1-\rho)$。该近似丢掉$\delta(1-\rho)$的高阶项，并使用$\ln(1+x)\approx x$。
:::

**评级**（AAA、AA、…、C、D，以及主要机构的平行标尺）是违约风险的序数概括，由私人公司根据会计、行业和国家信息制作。它们不是概率，跨机构并不唯一，也不是官方的。它们仍是许多投资授权和银行资本规则所使用的语言，这就是降级可以迫使出售、即使没有任何持有人改变自己的预测的原因。为评级动态建模的一种简单方式是**马尔可夫链**：下一期的评级通过转移矩阵依赖于本期评级，而不依赖于更远的过去。

::: widget markov
matrix: 0.90,0.08,0.02,0.00; 0.05,0.85,0.08,0.02; 0.00,0.10,0.80,0.10; 0.00,0.00,0.00,1.00
states: A; BBB; BB; D
start: 0
steps: 20
caption: 一条虚构的四状态评级链。D是吸收的（违约）。从A出发逐步走；再从BB出发。该矩阵不是某家机构公布的表。它展示评级作为状态的逻辑，不是对任何发行人的预测。
:::

当违约风险相近的两份债权因其中一份更难按规模出售而按不同收益率成交时，出现流动性溢价。新发（刚发行的）政府债券通常比久期相近的旧发债券收益率略低——流动性缺口，不是违约缺口。在危机中缺口扩大：持有人为他们能够回购或出售的工具付费。税收溢价在豁免某些利息的制度中是机械的：免税收益率$y_{\mu}$与应税收益率$y$对边际税率为$\tau$的投资者满足$y_{\mu} \approx (1-\tau)y$，若违约与流动性可比。美国观察到的市政债对国债比率在该线附近徘徊而不是坐在其上，因为有违约风险、税法不确定性和客户群效应。

::: example 风险中性的一年期利差 {#ex-one-year-spread}
虚构的一年期安全收益率为5%。一只一年期风险零息券有4%的违约机会，回收面值的40%。风险中性买者要求怎样的承诺收益率？利差是多少基点？与近似$\delta(1-\rho)$比较。
::: solution
每单位面值的期望支付：$0.96 \times 1 + 0.04 \times 0.40 = 0.976$。价格：$0.976/1.05 = 0.92952$。承诺收益率：$1/0.92952 - 1 = 0.07582$，即7.582%。利差：$7.582 - 5 = 2.582$个百分点，即258个基点。近似：$\delta(1-\rho) = 0.04 \times 0.60 = 0.024$，即240个基点。近似略微低估利差，因为它忽略了通过$1+r$的复利（[[#prop-rn-spread]]中的精确公式为$1.05/0.976 - 1 - 0.05 = 0.07582 - 0.05 = 0.02582$）。
:::
:::

::: warning 评级不是概率，利差不是违约率
BBB字母并不意味着“一年违约概率是$x$”。200个基点的利差并不意味着“市场认为每年违约2%”。回收、风险溢价、流动性和税收都在利差之内，而评级是序数类别。把其中任一个翻译成交易观点是另一项（此处未要求的）练习。
:::

## 即期利率、收益率曲线与远期利率

**收益率曲线**（期限结构）是在某一日期、对既定债权类别——通常是无违约政府债券、按既定复利惯例——从期限到收益率的映射。

::: definition 即期利率与远期利率 {#def-spot-forward}
**即期利率**$s_n$（或$i_{nt}$）是距到期$n$期的无违约零息债权的到期收益率。今天的一单位在日期$n$长成$(1+s_n)^n$。今天签约的、从日期$n$到$n+1$的**一期远期利率**$f_{n,n+1}$是满足

$$
(1+s_{n+1})^{n+1} = (1+s_n)^n (1+f_{n,n+1}),
$$ {#eq-forward}

的利率，因而$f_{n,n+1} = (1+s_{n+1})^{n+1}/(1+s_n)^n - 1$。**平价收益率**是给定即期曲线把附息债券按平价定价的票息率。附息债券的到期收益率*不是*即期利率，零息券除外；它们是即期利率的平均，按票息与本金的现值份额加权。
:::

**bootstrap**通过一次剥下一个期限从一组附息债券读出即期：一年期附息（或国库券）给出$s_1$；两年期附息，其第一笔票息按$s_1$贴现，给出$s_2$；依此类推。期限缺失时进行插值。得到的零息曲线是几乎此后每一项定价练习的输入。

曲线是**向上倾斜**的（和平时期数据中的通常情形）、**向下倾斜**或倒挂的、**驼峰**的，或**平坦**的。倒挂——短期利率高于长期利率——在美国数据中常常先于衰退，这是相关，不是定理，也不是交易规则。下一节给出斜率的三种解释。

::: widget plot
f: 0.03 + 0.02*(1-exp(-0.4*x)); 0.055 - 0.015*(1-exp(-0.5*x)); 0.04 + 0*x
x: 0.25, 10
y: 0.02, 0.07
labels: \text{向上}; \text{倒挂}; \text{平坦}
caption: 三条虚构的收益率曲线，横轴为以年计的期限，纵轴为即期利率。切换你所看的曲线。形状是分类，不是对任何政府曲线的预测，也不是建议。
:::

::: example 从三个即期得到远期利率 {#ex-forwards}
按年即期为$s_1 = 4\%$、$s_2 = 4.5\%$、$s_3 = 5\%$。计算一年期远期利率$f_{1,2}$和$f_{2,3}$。
::: solution
$f_{1,2} = (1.045)^2 / 1.04 - 1 = 1.092025/1.04 - 1 = 0.050024$，即5.002%。$f_{2,3} = (1.05)^3 / (1.045)^2 - 1 = 1.157625 / 1.092025 - 1 = 0.060072$，即6.007%。向上倾斜的即期曲线产生位于即期之上的远期利率：每一个新即期是先前即期与新远期的平均，因而远期必须坐在即期之上才能把平均拉上去。
:::
:::

::: example 两年期即期的bootstrap {#ex-bootstrap}
一年期4%按年付息债券（面值100）按平价成交。两年期5%按年付息债券成交价100.96。恢复$s_1$和$s_2$，以及该附息债券隐含的两年期到期收益率（你已经从价格知道它——用它核对到期收益率不是$s_2$这一想法）。
::: solution
平价一年期4%：$s_1 = 0.04$。两年期债券：

$$
100.96 = \frac{5}{1.04} + \frac{105}{(1+s_2)^2} \implies \frac{105}{(1+s_2)^2} = 100.96 - 4.8077 = 96.1523,
$$

因而$(1+s_2)^2 = 105/96.1523 = 1.09202$且$s_2 = 0.04500$（4.50%）。附息债券自身的到期收益率满足$100.96 = 5/(1+y) + 105/(1+y)^2$，给出$y \approx 4.49%$，是$s_1$与$s_2$的混合，略低于$s_2$，因为部分现金流在日期1到来。到期收益率不是两年期即期。
:::
:::

## 期限结构的三种理论

曲线为何通常向上倾斜，又为何会倒挂？

::: definition 纯预期假说 {#def-eh}
**纯预期假说**（EH）在其常见的对数（或近似线性）形式中说，长期利率是预期未来短期利率的平均，远期利率是预期未来即期：

$$
(1+s_n)^n = \prod_{k=0}^{n-1} \bigl(1 + \E i_{t+k}\bigr), \qquad f_{n,n+1} = \E_t s_{1,\, t+n},
$$ {#eq-eh}

其中$i_{t+k}$是$t+k$时的一期短期利率，$s_{1,t+n}$是未来的一期即期。风险溢价为零。较弱的**收益率版本**使各期限上的期望一期收益率相等。
:::

在EH下，向上倾斜的曲线意味着短期利率预期上升；倒挂的曲线意味着它预期下降。故事干净，作为完整描述则是假的。长期债券的期望超额收益率平均不为零：它们随经济周期和不确定性变动。那是期限溢价的入口。

**流动性溢价**（或**期限溢价**）假说保留预期机制，并加上随期限上升的溢价$L_n \ge 0$，因为长期债券有更多久期风险（[[money-banking/interest-rates#def-duration]]），也因为许多持有人偏好短期债权（希克斯（Hicks）1939；偏好栖息地版本是莫迪利安尼与萨奇（Modigliani and Sutch）1966）。于是$f_{n,n+1} = \E_t s_{1,t+n} + L_{n+1}$，即使短期利率预期不动，曲线也可以向上倾斜。倒挂于是要求预期短期利率下降大到足以淹没溢价——这就是为何在*期限溢价世界中*倒挂仍可以是衰退信号，若市场预期中央银行在下行中降息。

**市场分割**（卡尔伯特森（Culbertson）1957）把每一期限当作自己的市场，有自己的需求（长端的养老基金、短端的货币市场基金）和供给（政府的发行）。跨期限替代有限，因而对一个期限供给的冲击会移动该收益率，而预期短期利率没有匹配的移动。偏好栖息地是折中：栖息地存在，但当溢价变大时可以被侵入。

::: proposition EH与斜率 {#prop-eh-slope}
在线性一期EH $s_2 = \tfrac12 \bigl(i + \E i'\bigr)$下，其中$i$是今天的短期利率，$\E i'$是预期下一期短期利率，两期曲线向上倾斜当且仅当$\E i' > i$。在$s_2 = \tfrac12 \bigl(i + \E i'\bigr) + \ell$中带有常数期限溢价$\ell > 0$时，当$\E i' = i$时曲线也可以向上倾斜。
:::

::: proof
在EH下$s_2 - i = \tfrac12(\E i' - i)$，为正当且仅当$\E i' > i$。带溢价时，$s_2 - i = \tfrac12(\E i' - i) + \ell$，且$\E i' = i$已经给出$s_2 - i = \ell > 0$。
:::

没有单一假说是专业界的定论。中央银行和资产定价课程中使用的仿射期限结构模型把预期短期利率和时变溢价放进共同的状态空间机器（[[asset-pricing/fixed-income]]）。对本课程，把曲线读成混合物就够了：一条预期政策利率路径，加上溢价，有时再加上发行和中央银行购买的数量效应。

::: history
**1939年，约翰·希克斯（John Hicks）。**《价值与资本》（*Value and Capital*）给出了期限结构的流动性溢价论述：长期债券平均必须有更高收益率，因为它们承担更多利率风险，也因为许多持有人偏好短期放贷。该想法与纯预期假说（费雪，以及后来的卢茨（Lutz）和迈泽尔曼（Meiselman））以及卡尔伯特森1957年的市场分割论文并列，是本章三种古典故事之一。
:::

::: example 预期与期限溢价 {#ex-eh-lp}
今天的一年期利率为4%。从现在起一年后的预期一年期利率为6%。(a) 在纯EH下，两年期即期（几何版本）是多少？(b) 若把30个基点的期限溢价加到两年期*收益率*上（不是加到远期），$s_2$是多少？
::: solution
(a) $(1+s_2)^2 = 1.04 \times 1.06 = 1.1024$，因而$s_2 = \sqrt{1.1024} - 1 = 0.04995$，即5.00%。(b) $s_2 = 0.04995 + 0.0030 = 0.05295$，即5.30%。隐含远期于是为$(1.05295)^2/1.04 - 1 = 0.0662$，即6%的预期短期利率加上约62个基点的远期溢价——不等于30个基点的收益率溢价，因为收益率是短期利率与远期的平均。把“收益率上的溢价”与“远期上的溢价”混用是标准失误。
:::
:::

::: quiz
若一年期即期为3%、两年期即期为3%，从一年后开始的一年期远期是
- [ ] 0%
- [x] 3%
- [ ] 6%
- [ ] 没有预期假说就不可能计算
::: solution
$f_{1,2} = (1.03)^2/(1.03) - 1 = 0.03$。远期是两个即期的恒等式（[[#eq-forward]]），不是假说。EH会再加上3%也是预期未来即期这一主张。
:::
:::

## 证据

美国国债固定期限收益率（理事会，H.15，经由FRED）是通常的实验室。10年期收益率在2026年10月平均为5.13%（GS10）；截至2026年11月14日，联邦基金目标区间为3.75–4.00%。在那些日期，10年期收益率高于隔夜目标是向上斜率；在其他年份的其他月份斜率符号相反。倒挂的美国曲线（10年期低于3个月，或10年期低于2年期）先于1960年代以来大多数美国衰退，滞后期从几个季度到一年以上，并在1998年前后有一次虚警（埃斯特雷拉与米什金（Estrella and Mishkin）1998是经典论文；随后文献很大）。相关不是结构定理：同一倒挂在EH下是短期利率将下降的预测，而这正是中央银行在下行中所做的。

信用利差（例如穆迪Baa减10年期国债，FRED序列如BAA10Y）在衰退和金融危机中走阔：2008—09年、2020年春季，以及较小的几轮。利差是对违约、对风险、对流动性的补偿，比例会变。新兴市场主权债对国债的利差（J.P.摩根EMBI式指数，由国际清算银行和各国来源报告）随全球风险偏好以及本地基本面移动；它们不是对国家的排序。

机构自己的评级转移研究（年度违约与转移研究）记载，同一字母类别中的违约率在衰退中高于扩张，因而常数马尔可夫矩阵是简化。控件中吸收的D是正确的定性特征：违约不是一个会被升回去的字母。

## 由此通向何处

银行和其他中介靠利差为生：它们按一种收益率借入、按另一种贷出，跨越风险与期限（[[money-banking/financial-intermediation]]，[[money-banking/banking]]）。久期缺口是对期限结构的押注，无论银行是否那样想。中央银行直接影响短端，并通过预期未来短期利率影响长端，在量化宽松下还通过对溢价的数量效应影响长端（[[money-banking/monetary-policy-implementation]]）。资产定价课程走下一步：无套利曲线、仿射模型，以及作为一组可检验限制的预期假说（[[asset-pricing/fixed-income]]）。

::: summary
- 给定期限下收益率的风险结构反映违约、流动性与税收待遇。信用利差不是违约概率。
- 评级是序数类别；马尔可夫转移矩阵是这些类别如何移动的模型，违约通常是吸收的。
- 即期利率贴现零息券。远期利率是即期的恒等式。附息收益率是即期的混合，本身不是即期。
- 纯预期假说把曲线读成预期未来短期利率。期限溢价和栖息地（分割）效应叠在该读法之上，即使短期利率预期不上升也可以使曲线向上倾斜。
- 倒挂常常先于美国衰退；那是有记载的相关，不是定理，也不是交易规则。
:::

::: exercise 以基点计的利差 {level=1 check="150"}
Baa公司债收益率为6.5%，可比国债收益率为5.0%。利差是多少基点？（输入整数。）
::: solution
$(6.5-5.0)\times 100 = 150$。
:::
:::

::: exercise 远期恒等式 {level=1}
$s_1 = 2\%$，$s_2 = 3\%$。计算$f_{1,2}$。
::: solution
$f_{1,2} = (1.03)^2/1.02 - 1 = 1.0609/1.02 - 1 = 0.040098$，即4.01%。
:::
:::

::: exercise 作为状态的评级 {level=1}
在马尔可夫控件的四状态链中，为何已经进入D的行走在再走十步后仍在D？那是什么经济特征？
::: solution
矩阵最后一行为$(0,0,0,1)$：从D出发链以概率1留在D。违约被建模为吸收。在这个玩具中，违约债权不会被升回BB。（实践中重组后的发行人可以被再次评级，那会是另一条链。）
:::
:::

::: exercise 风险中性回收 {level=2}
安全一年期收益率4%。风险一年期零息券有$\delta = 0.10$、回收$\rho = 0.50$。风险中性买者。求承诺收益率和利差。
::: solution
期望支付$0.90 + 0.10\times 0.50 = 0.95$。价格$0.95/1.04 = 0.91346$。承诺收益率$1/0.91346 - 1 = 0.09474$（9.47%）。利差$9.47 - 4 = 5.47$个百分点。近似$\delta(1-\rho) = 5$个百分点。
:::
:::

::: exercise EH两年期 {level=2 check="5"}
一年期利率4%，预期下一个一年期利率6%，纯EH，线性（算术）平均。两年期收益率以百分比计是多少？（输入整数。）
::: solution
$s_2 = (4+6)/2 = 5$。
:::
:::

::: exercise 三年期bootstrap {level=2}
即期$s_1 = 0.03$、$s_2 = 0.04$已知。三年期5%按年付息债券（面值100）定价为102。求$s_3$。
::: solution
$102 = 5/1.03 + 5/(1.04)^2 + 105/(1+s_3)^3$。前两个现值为$4.8544 + 4.6228 = 9.4772$。残差$102 - 9.4772 = 92.5228 = 105/(1+s_3)^3$，因而$(1+s_3)^3 = 105/92.5228 = 1.13486$，$1+s_3 = 1.0431$，$s_3 \approx 4.31%$。
:::
:::

::: exercise 期限溢价与倒挂 {level=3}
设两年期收益率中的期限溢价为常数40个基点，线性EH加溢价关系为$s_2 = \tfrac12(i+\E i') + 0.004$。若$i = 5%$，要使曲线倒挂（$s_2 < i$），$\E i'$必须低到多少？加以解释。
::: hint
令$s_2 < 0.05$并解出$\E i'$。
:::
::: solution
$s_2 < 0.05$当且仅当$\tfrac12(0.05 + \E i') + 0.004 < 0.05$当且仅当$0.05 + \E i' < 0.092$当且仅当$\E i' < 0.042$。预期短期利率必须下降超过80个基点，足以淹没40个基点的收益率溢价。倒挂仍是关于预期宽松的陈述，只是比纯EH下更强（纯EH只要$\E i' < 0.05$就会倒挂）。
:::
:::

::: exercise 为何到期收益率不是即期 {level=3}
用$s_1 = 4\%$、$s_2 = 6\%$，按即期为两年期5%按年付息债券（面值100）定价，然后计算其到期收益率。证明到期收益率位于两个即期之间。直觉上为何？
::: hint
到期收益率是贴现两笔支付的即期的现值加权混合。
:::
::: solution
$P = 5/1.04 + 105/(1.06)^2 = 4.8077 + 93.4496 = 98.257$。到期收益率满足$98.257 = 5/(1+y) + 105/(1+y)^2$。试$y = 0.059$：$5/1.059 + 105/1.059^2 = 4.7214 + 93.626 = 98.347$。相对98.257略高，因而$y$略高于5.9%，仍低于$s_2 = 6%$、高于$s_1 = 4%$。第一笔支付按4%贴现，第二笔按6%；到期收益率是模仿两者的单一利率，因而是混合，被拉向本金日期但不是全程。
:::
:::
