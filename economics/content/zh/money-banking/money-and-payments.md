一张二十英镑纸币、一笔活期存款余额、一笔M-Pesa转账和一笔中央银行账本上的余额是不同的对象。它们的共同点是：陌生人会接受它们来了结债务。这种性质——交换中的普遍可接受性——就是经济学所说的**货币**。它不是一种天然物质，也不同于财富。它是一种解决匹配问题的社会安排：若没有普遍接受的媒介，每一笔交易都需要欲望的双重巧合。

本章从该匹配问题出发，陈述教科书中货币的三项职能，然后对履行过这些职能的对象加以分类：商品货币、代用硬币、法定纸币、银行存款（内部货币）以及近二十年的各种数字债权。随后从对象转向**支付**：把债权从付款人移到收款人的一组报文与分录，并在双方使用不同银行时经过清算所与结算代理人。最后几节讨论统计师如何清点货币（货币总量），以及数量恒等式$MV = PY$说明什么、不说明什么。这里没有任何关于应持有哪种债权的建议。数字要么是说明性的，要么是注明日期的官方统计。

前一门课以货币与通货膨胀的初步讨论作结（[[principles/macroeconomic-policy]]）。这里的问题更原初：那些章节所讨论其数量的东西究竟是什么，以及一笔支付实际上如何发生？

## 匹配问题与货币的职能

设想一个由专业化生产者组成的经济。陶工想要面包；面包师想要鞋子；鞋匠想要陶罐。直接物物交换只有在两个人相遇且各自想要对方所有之物时才可行。杰文斯（Jevons，1875）称之为**欲望的双重巧合**。有$n$种商品时就有$n(n-1)/2$个双边市场，其中大多数在任意一天都是空的。一种普遍接受的交换媒介把这些市场压缩成对媒介的$n$个市场。

::: definition 货币 {#def-money}
**货币**是在给定共同体中被普遍接受为**交换媒介**的任何对象，或任何可转让的电子记录。同一对象通常还充当**记账单位**（价格与债务以它标价）和**价值储藏**（它可以从一个日期带到另一个日期）。三项职能可以分开：记账单位不必是人们实际交出之物，价值储藏也不必具有流动性。
:::

交换媒介职能是把货币与其他资产区分开来的那一项。房屋是价值储藏，不是货币。超市优惠券只在一家连锁店被接受，不是普遍接受。政府债券是价值储藏，并以记账单位标价，但不能用来买午餐。流动性——能够按接近通行价格迅速出售——是程度问题。货币位于该谱系的流动一端。

记账单位职能容易被忽视，因为在单一货币经济中它几乎看不见。在复本位制中，或在一个用美元标租金、用本币付工资的国家，这种分离是明显的。在高通货膨胀时期，记账单位常常迁往外币或某种实际单位（一篮子商品、一单位黄金），即使旧纸币仍作为交换媒介流通。这是三项职能分开的一种方式。

作为价值储藏，只要名义利率为正，货币就被生息资产占优。人们仍然持有它，因为它是用于结算之物。持有不生息货币的机会成本是放弃的利息，这就是下一节中货币需求随名义利率向下倾斜的原因。生息存款模糊了界限：按交换媒介检验它们是货币，同时又支付利率，因此机会成本是相对于一种流动性较差利率的利差，而不是整个利率。

::: proposition 双重巧合与交换媒介 {#prop-double}
在一个有$n \ge 3$种商品且没有交换媒介的经济中，商品$i$的所有者与商品$j$的所有者之间相互想要的成对交易，只有在各自想要对方的商品时才会发生。引入普遍接受的媒介$m$，把该要求替换为较弱的条件：$i$的所有者接受$m$且$j$的所有者接受$m$。可行的成对交易集合扩大，必须组织的市场数目从$n(n-1)/2$降为$n$（每种商品对$m$），再加上$m$的不同品种之间可能存在的市场。
:::

::: proof
没有$m$时，$i$与$j$的相遇成为交易当且仅当$i$想要$j$且$j$想要$i$。当双方都接受$m$时，$i$可以卖出换取$m$，稍后向某个想要$m$的人买$j$，即使那个人不是$j$的原所有者。清点市场：每一无序商品对都是一个潜在的物物交换市场，因而有$n(n-1)/2$个；有了媒介，只需开放商品对$m$的$n$个市场，商品就可以标价和交易。（不同货币之间的市场——纸币对存款、一种通货对另一种——是额外的，它们是下面支付一节的主题。）
:::

该命题是关于可行性的陈述，不是关于福利的陈述。交换媒介可以对社会有用，同时仍是糟糕的价值储藏（高通货膨胀）或糟糕的记账单位（双货币制度）。它也可以由榨取租金的私人网络供给，或由榨取铸币税的公共发行人供给。那些是后面的问题。

::: intuition 记账单位为何重要
一旦价格以共同单位标出，比较购物就变成算术，而不是在商品对之间的汇率上搜寻。这是一种认知上的节约，不同于匹配上的节约。一个经济可以（而且有些经济已经）用一种对象作记账单位、用另一种作交换媒介。教科书里两者重合是一种便利，不是一条定理。
:::

::: example 三个专业化生产者 {#ex-specialists}
A、B、C分别生产苹果、面包和布。A想要面包，B想要布，C想要苹果。没有任何一对具有双重巧合。证明一种普遍接受的代币（每人持有若干）使三项想要的交易都成为可能，并清点物物交换市场与有媒介时的市场。
::: solution
有三种商品，故$n(n-1)/2 = 3$个物物交换市场（苹果–面包、面包–布、布–苹果），在生产者与生产者的成对相遇中没有一个出清。有了代币$m$，A把苹果卖给C换取代币并向B买面包；B现在持有来自A的代币，向C买布；C用代币买苹果。三种商品各有一个对$m$的市场，因而三个货币市场替换了三个空的物物交换市场。代币不必有使用价值；只需被接受。本例是[[#prop-double]]的最小说明。
:::
:::

## 商品货币、法币与内部货币

历史上，媒介常常是一种有使用价值的商品：牲畜、贝币、盐、铜、银、金。**商品货币**是其交换价值至少部分由其在其他用途中的价值以及生产成本锚定的媒介。当金属作为金银块比作为铸币更值钱时，金币会被熔化（下面的格雷欣法则是这一算术的近亲）。十九世纪末的古典金本位是一种商品货币制度，其中各国纸币和存款是按固定价格兑付黄金的承诺。

**代用**或**法定**货币是其材料成本远低于交换价值的媒介，其可接受性建立在惯例、法偿法律或发行人承诺在纳税时收回它之上。现代纸币以及商业银行在中央银行持有的余额（准备金）是法币。国家能够要求以该媒介纳税，是人们接受它的有力（尽管不是唯一）原因（图表主义的观察，自克纳普（Knapp）1905年以来以多种形式重述）。可接受性仍是社会事实：国家愿意收取的纸币，若价格以别的东西标价，仍可能在恶性通货膨胀中失败。

::: definition 外部货币与内部货币 {#def-inside}
**外部货币**是私人部门的净资产：黄金，或对公共部门的债权（纸币、硬币，以及商业银行在中央银行的存款）。**内部货币**是一个私人主体对另一个私人主体的债权——首先是家庭和企业在商业银行持有的可转让存款。内部货币在合并的私人部门资产负债表上净额为零；对其持有人仍是货币，因为它在交换中被接受。
:::

高收入国家人们所称的货币，大部分是内部货币。在美国，经季节调整的M1在2025年11月为189980亿美元，其中流通中通货仅约2423亿美元；其余主要是可转让存款（美国联邦储备系统理事会，H.6货币存量指标，2025年11月，经由FRED）。纸币是外部货币。存款是银行的负债，在银行账本的另一侧由贷款、证券和准备金匹配。通过偿还银行贷款销毁存款会收缩内部货币；印刷纸币会扩张外部货币。两者通过银行体系相连，这是[[money-banking/central-banking]]的主题。

数字债权使形式倍增，而不改变分类。持牌电子货币钱包中的余额通常是对发行人的债权，完全由银行或中央银行的资金匹配——内部货币，或外部货币的窄口径过手，取决于法规。不对任何人构成债权的加密货币更接近私人供给的商品（或法定）货币，其均衡价值可以为零。中央银行数字货币在存在之处是穿上新技术外衣的外部货币。这些句子都不是对使用哪种形式的排序。

::: warning 货币不同于财富
一个持有房屋、股票和一笔存款的家庭是富有的。只有存款（以及任何纸币）是货币。膨胀货币存量本身并不会使社会更富：额外单位会把商品以记账单位计的价格抬高。把两者混淆是误读货币总量的最简单方式，也是“印钞票就是印产出”这一说法背后的错误。
:::

::: example 复本位铸币厂上的格雷欣法则 {#ex-gresham}
铸币厂按法定比率每盎司黄金兑15盎司白银铸造金银币。金银块市场上的比率是15.5。哪种金属作为铸币流通，哪种被熔化或出口？（说明性比率；要点是算术。）
::: solution
一盎司黄金在铸币厂买到15盎司白银，在市场上买到15.5盎司。因此持有黄金的人更愿意把它作为金银块出售（或出口），并用银币支付。白银——铸币厂相对于市场高估的金属——留在流通中；黄金从钱柜中消失。这就是**格雷欣法则**：在两者都按固定比率具有法偿地位、且熔化与出口可行时，法律高估的货币驱逐法律低估的货币。该法则是套利陈述，不是历史普遍规律——当不受青睐的铸币是人们唯一愿意接受的，或当两种货币不是完全替代时，它会失效。
:::
:::

移动货币表明，交换媒介不必是银行存款或中央银行纸币。M-Pesa于2007年在肯尼亚推出，在Safaricom 2026/27财年上半年，肯尼亚有4230万一个月活跃客户（Safaricom PLC业绩，2026年11月）。肯尼亚通信管理局统计，2026年6月30日该国有5400万活跃移动货币订户，超过每名居民一户。印度统一支付接口在2025日历年处理了约2280亿笔交易，价值约300万亿卢比（印度国家支付公司）。这些系统移动的债权，在链条尽头仍是银行或中央银行的余额。它们改变了作为交换媒介的成本，而不是定义。

## 货币总量

统计师通过在流动债权谱系上划一条线、把线靠流动一侧的项目加总来清点货币。这条线是约定的，各国不同，并在监管变动时移动。

::: definition 基础货币与M总量 {#def-aggregates}
**基础货币**（或高能货币）$B$是流通中通货加上银行在中央银行的准备金余额。**M1**是公众手中的通货加上可转让（支票、活期）存款。**M2**是M1加上近似替代品：储蓄存款、小额定期存款和零售货币市场基金，确切清单由统计机构规定。更广的总量（M3、M4、“广义货币”）再加上大额定期存款、批发货币市场基金和某些可流通工具。每一总量都是存量之和，不是关于货币做什么的理论。
:::

在美国，理事会2025年11月的H.6把经季节调整的M2定为22253.2亿美元，M1为18998.1亿美元。同月未经季节调整的基础货币为5302.1亿美元，其中流通中通货2422.6亿美元，准备金余额2879.4亿美元（理事会，H.6与H.4.1，经由FRED）。到2026年8月，经季节调整的M2达到23342.8亿美元（H.6）。这些是某一日期的存量，不是建议，并且会被修订。

美国自2020年以来数字的两个特征是制度性的，而不是经济学的。2020年4月美联储把法定准备金率降为零，2020年5月一项监管变动使储蓄存款被重分类进入M1，于是M1跃向M2。把该断点前后的M1当作定义不变来比较是错误。其他国家划线不同：欧元区的M3、英格兰银行的M4ex、中国人民银行的M2。务必阅读统计注释。

**数量恒等式**写成

$$
MV = PY
$$ {#eq-quantity}

其中$M$是选定的总量，$V$是**流通速度**（每单位货币的名义支出），$P$是价格指数，$Y$是实际产出。作为恒等式，一旦把$V$定义为$PY/M$，它由构造为真。只有对$V$（或对$M$）加上限制，它才成为理论。古典数量论把$V$视为短期内黏性、$Y$由实际面决定，因而$M$的变动表现在$P$上。该限制是经验主张，不是定义，在高通货膨胀中比在平静时期更接近为真。恶性通货膨胀——德国1922—23年、2000年代的津巴布韦、2010年代委内瑞拉的那一轮——是该主张最难否认的实验室：货币存量与价格水平按数量级一起移动。在普通经济周期时间里，$V$会变动，$Y$不是固定的，恒等式是会计框架，而不是从$M$到$P$的地图。

取2025年11月美国M2为22253亿美元（FRED，M2SL，H.6），并取同一季度假想的名义GDP为30000亿美元（说明性的；官方GDP按不同日程公布）。M2流通速度是多少？若改为M2为23343亿美元（2026年8月，H.6）而名义GDP不变，$V$会怎样？
::: solution
$V = PY/M = 30000/22253 \approx 1.348$。M2更大而$PY$相同，$V = 30000/23343 \approx 1.285$。存量上升、名义支出固定，按定义就是流通速度下降。该计算并不说$PY$事实上会不变；它表明当把$M$和$PY$当作输入时，恒等式把什么归于$V$。那些月份的官方GDP应从国民账户读取，而不是从本例读取。
:::

## 支付：清算与结算

**支付**是货币债权从付款人到收款人的转移。当双方使用同一家银行时，银行借记一个账户、贷记另一个账户：支付是内部的，银行资产负债表只是重新配置一项负债。当他们使用不同银行时，出现两个进一步步骤。

::: definition 清算与结算 {#def-clearing}
**清算**是支付信息的交换以及义务的计算：谁欠谁、欠多少，可能经过净额轧差。**结算**是了结这些义务的结算资产的最终转移。在大多数经济中，银行的结算资产是在中央银行的准备金余额。当结算转移不可撤销时，支付是**最终**的。
:::

**净额结算**在一批支付上计算每家银行对其余银行的净头寸，只转移这些净额。从银行A到银行B的二十笔10、反向十九笔10，产生净额10，而不是390的总额转移。轧差节约结算资产；它也在该批次期间造成**风险暴露**，因为已发出支付报文的银行依赖他人完成。**全额结算**，尤其是**实时全额结算（RTGS）**，把每笔支付分开、实时、以中央银行货币结算。RTGS消除批次内信用风险，代价是需要更多结算余额（或中央银行的日内信贷便利）。

大额系统是RTGS：美国的Fedwire，欧元区的TARGET2（及其后继），英国的CHAPS，中国的CNAPS，以及其他中央银行的相应系统。零售系统——支票清算、卡支付的延迟净额结算、快速支付方案——常常轧差，并在指定时点把净额在RTGS中结算。国际清算银行支付与市场基础设施委员会公布这些系统的比较统计；制度细节会变，清算与结算的区分不变。

支付体系是一个网络。不是RTGS直接成员的银行通过作为成员的代理行结算。跨境支付通常把代理行串成链，这就是它们比国内支付更慢、更贵的原因。该网络可以画成银行与一个中心结算节点的图；下一个控件是该图的玩具版本，不是任何在运行系统的地图。

nodes: CB@0,2; A@-2,0; B@2,0; C@0,-2
edges: CB-A; CB-B; CB-C; A-B
caption: 一个玩具支付网络。CB是结算代理人（中央银行）。A、B、C是商业银行；A与B还有双边代理行联系。A的客户向C的客户付款，在RTGS中走A → CB → C。拖动节点；该图是对联系的分类，不是实时暴露地图，也不是预测。
:::

在日内，必须先付出才能收入的RTGS银行需要**流动性**：要么是一笔准备金存量，要么是中央银行提供的抵押日内信贷，要么是时机合适的流入。现代RTGS系统中的流动性节约装置把支付排队并在可能时轧抵，是全额与净额的混合。[[money-banking/monetary-policy-implementation]]中讨论的中央银行常设便利，是对该日内问题的隔夜后盾。

::: example 全额与净额 {#ex-netting}
在一批中，银行A向B发送40、向C发送10；银行B向A发送25、向C发送15；银行C向A发送5、向B发送20。计算每家银行的净头寸以及总额转移之和。在纯全额结算与多边净额结算下各需要多少结算资产？
::: solution
总额转移之和为$40+10+25+15+5+20 = 115$。

银行A的收入为$25+5 = 30$，故A的净额为$30 - 50 = -20$（A支付20）。银行B的收入为$40+20 = 60$，支付$25+15 = 40$，净额$+20$。银行C的收入为$10+15 = 25$，支付$5+20 = 25$，净额$0$。在多边净额结算下，结算代理人把20从A转到B；C轧平。全额结算将要求115的结算资产经过，尽管若支付有顺序则不必同时。这里轧差把结算需要从115降到20。节约是轧差有吸引力的原因；A所欠的20在结算发生前是B（以及体系）的暴露。
:::
:::

最终性之所以重要，是因为可以撤销的支付从收款人的角度看还不是货币。以中央银行货币进行的RTGS被设计成已结算支付是最终的。已经贷记收款人但尚未在银行之间结算的存款转账，仍受付款银行倒闭的影响。这是近三十年来以商业银行货币结算的大额系统被推向中央银行结算的原因之一。

## 铸币税、法偿与国家的角色

代币货币的发行人按面值把它花进流通，并以近乎为零的边际成本生产它。差额就是**铸币税**。对纸币而言，一种便利的度量是发行不生息负债而非生息负债所节省的利息：若公众持有$C$的纸币、相关政府利率为$i$，则每期铸币税约为$iC$（更仔细的度量使用所转移的实际资源）。对支付利息的中央银行存款，铸币税是中央银行资产收益与负债付息之差，在成本之后上缴财政。这些是公共财政事实，不是增发的论据。

法偿法律规定，指定债权必须被接受以了结金钱债务。它们本身并不使人们以该债权标价或把它作为价值储藏持有。在恶性通货膨胀中，法偿纸币继续了结旧债，而新合约迁往另一种单位。税收可接受性——国家以该单位标示纳税义务并接受该媒介缴税——是更强的锚定，若通货膨胀足够高，它仍不足够。

当私人债权更便利（存款、移动货币余额、卡组织）并且被信任能按平价或小额费用兑换成公共媒介时，私人媒介与公共媒介并存。货币史在很大程度上是这些兑换承诺及其偶尔失败的历史。当承诺失败时，私人债权不再是[[#def-money]]意义上的货币：它不再被普遍接受。那是用另一种词汇说出的银行挤兑，是[[money-banking/bank-runs-and-crises]]的主题。

::: history
**1694年，英格兰银行。**一家公司获颁特许状，向王室贷出120万英镑，以换取发行纸币的权利。在随后一个世纪里，这些纸币成为伦敦支付体系的核心。该行的私人起源与公共职能——发行人、政府的银行家，并最终成为最后贷款人——是现代中央银行这一捆职能的祖先，后来从东京到比勒陀利亚被模仿和改造。
:::

## 证据

三类观察约束这些定义。

第一，总量的构成。在上面引用的美国H.6数字中，可转让存款远超通货。欧元区和英国也是同一模式：内部货币是日常生活的交换媒介，外部货币是银行的结算资产。在低收入经济中，通货份额往往更高，移动货币相对于银行存款扮演更大角色——肯尼亚是教科书例子，通信管理局的5400万活跃移动货币订户（2026年6月30日）与仍在发展的银行账户人口并存。

第二，支付量。UPI在2025年的2280亿笔交易（NPCI）以及M-Pesa每年数百亿笔交易（Safaricom年报）不是$M$的增加；它们是既定余额存量周转次数的增加——流通速度，或从现金转向有记录媒介。国际清算银行CPMI红皮书统计记录了成员国电子贷记转账的长期上升和支票使用的下降。交换媒介职能已经迁移；职能本身相同。

第三，通货膨胀极端。卡甘（Cagan）对第一次世界大战后欧洲恶性通货膨胀的研究，以及拉丁美洲、非洲和前苏联后来的几轮，表明一旦流通速度调整，货币存量与价格水平一起移动。那是$V$不是常数、但仍是预期通货膨胀增函数的数量恒等式。它是关于价值储藏职能失败的证据，不是在低通货膨胀地板体系经济中把$MV=PY$当作短期政策规则的理由。

国家例子不应被读成对体系的排序。巴西的Pix、中国曾经的微信支付与支付宝双轨（现处于更紧的支付监管之下）、欧元区的TARGET，以及美联储的FedNow，都是在不同法律与历史约束下对同一清算与结算问题的回答。

## 由此通向何处

下一章中的利率，是未来货币的价格（[[money-banking/interest-rates]]）。一旦记账单位固定，债券就是货币支付的时间表，其价格是现值。再往后，银行是其负债为本章内部货币、其资产为那些债券和贷款的企业（[[money-banking/banking]]）。中央银行是结算资产的发行人，也是RTGS的运营者（[[money-banking/central-banking]]，[[money-banking/monetary-policy-implementation]]）。宏观课程会把$MV=PY$和货币需求放回通货膨胀与产出的模型中（[[macroeconomics/money-and-inflation]]，[[business-cycles]]）。嵌入时定义不变；额外结构会变。

::: summary
- 货币是普遍接受的交换媒介；它通常还充当记账单位和价值储藏，但三项职能可以分开。
- 外部货币是私人部门的净资产（纸币、准备金）；内部货币是私人债权，主要是银行存款，对其持有人仍作为货币起作用。
- 货币总量（基础货币、M1、M2、更广口径）是流动债权的约定加总；监管变动时定义会断裂，如2020年美国M1。
- $MV = PY$是恒等式。只有对流通速度和产出加上限制，它才成为数量论，更适用于高通货膨胀而不是平常时期。
- 支付在义务被计算时被清算，在结算资产带着最终性被转移时被结算。以中央银行货币进行的RTGS是大额最终性的标准；零售系统常常轧差。
- 数字钱包和移动货币改变媒介的技术；它们本身并不改变内部与外部债权的分类。
:::

## 习题

::: exercise 物物交换的对数 {level=1}
一座岛有6种商品、没有货币。有多少个双边物物交换市场？对单一交换媒介有多少个市场？
::: solution
物物交换市场：$n(n-1)/2 = 6\times5/2 = 15$。对媒介的市场：$6$。节约是9个不必组织的市场。
:::
:::

::: exercise 给债权分类 {level=1}
把每一项分类为外部货币、内部货币或不是货币：(a) 一张10英镑纸币；(b) 商业银行的活期账户余额；(c) 政府债券；(d) 商业银行在英格兰银行的准备金账户；(e) 一家上市公司的股权。
::: solution
(a) 外部货币（对公共部门的债权，或由其发行的代币）。(b) 内部货币。(c) 不是货币：价值储藏和记账单位工具，不是交换媒介。(d) 外部货币。(e) 不是货币。
:::
:::

::: exercise 简单流通速度 {level=1 check="1.5"}
名义GDP为1800记账单位，货币存量为1200。流通速度是多少？（输入$V$的值。）
::: solution
$V = PY/M = 1800/1200 = 1.5$。
:::
:::

::: exercise 净头寸 {level=2}
银行X、Y、Z在一批中发送如下总额支付：X→Y 30，X→Z 10，Y→X 12，Y→Z 8，Z→X 20，Z→Y 5。计算每家银行的多边净头寸以及绝对净额之和（轧差下的结算量）。与总额支付合计比较。
::: solution
X：收入$12+20=32$，支付$30+10=40$，净额$-8$。Y：收入$30+5=35$，支付$12+8=20$，净额$+15$。Z：收入$10+8=18$，支付$20+5=25$，净额$-7$。核对：$-8+15-7=0$。绝对净额之和为$|-8|+|15|+|-7|=30$，但若每笔转移只计一次，结算量是其一半：15（Y从X收到8、从Z收到7）。总额合计为$30+10+12+8+20+5=85$。轧差用15的结算替换85的总额。
:::
:::

::: exercise 格雷欣算术 {level=2}
铸币厂按16:1铸造金银。市场比率为15.5:1。哪种金属在铸币厂被高估，哪种流通？
::: solution
在铸币厂，1盎司黄金兑换16盎司白银；在市场上为15.5。铸币厂相对于市场高估了黄金（一盎司黄金在法定比率下买到的白银多于作为金银块）。人们因此把黄金送到铸币厂铸币，并熔化或出口白银。流通中的铸币往往是铸币厂高估的金属——此处为黄金——被低估的金属（白银）从钱柜中消失。可以用两种法偿支付的款项用被高估的铸币支付。这就是[[#ex-gresham]]中的格雷欣法则，只是法定比率现在位于市场比率的另一侧。
:::
:::

::: exercise 内部货币被销毁 {level=2}
一家企业通过借记其在同一银行的存款偿还50单位贷款。给出银行的资产负债表变动以及内部货币的变动。通货不变。
::: solution
资产：贷款$-50$。负债：存款$-50$。内部货币（存款）下降50。外部货币不变。该交易是贷款创造的逆过程。这就是内部货币对银行体系是内生的原因：在存在存款需求时，银行放贷时创造它，贷款偿还时销毁它。
:::
:::

::: exercise 作为限制的数量恒等式 {level=3}
设$Y$固定为100，$V$固定为2，$M$从50升到60。$P$怎样？现在去掉对$V$的限制，设$M$上升时$V$从2降到$5/3$。$P$怎样？每种情形对把[[#eq-quantity]]当作价格水平理论说明了什么？
::: hint
在每种情形下计算$P = MV/Y$。
:::
::: solution
第一种情形：起初$P = 50\times 2 / 100 = 1$；上升后$P = 60\times 2 / 100 = 1.2$。$M$上升20%带来$P$上升20%。第二种情形：$P = 60 \times (5/3) / 100 = 1$，因而价格水平不变。恒等式始终成立；数量*论*是额外主张：$V$（和$Y$）不抵消$M$的移动。没有该主张，$M$和$P$不必一起移动。
:::
:::

::: exercise 设计结算规则 {level=3}
一个四银行体系在17:00运行延迟净额结算批次，以中央银行准备金结算。一家银行在16:50倒闭，带有大额净借记。用一段话解释(i)撤销该行支付并在幸存者之间重跑净额，与(ii)一项损失分担规则——结算原净额并把倒闭银行的借记分配给幸存者——之间的差别。RTGS消除哪种风险，不消除哪种？
::: hint
把幸存者之间的重置成本（或流动性）风险与倒闭净借记的信用风险区分开。
:::
::: solution
(i) 撤销取消倒闭银行已发送和已接收的支付并重新计算净额。一直指望从倒闭银行流入的幸存者现在有流动性缺口；他们的部分对外支付也可能失败，形成连锁。倒闭借记上的信用损失被避免，因为那些支付从未结算，但倒闭银行的收款人收不到资金。(ii) 损失分担结算原批次，因而收款人得到支付，幸存者共同吸收倒闭借记（按公式：按比例、按双边暴露等）。信用风险被互助化；批次中的流动性得以保持。RTGS消除批次内信用暴露，因为每笔支付立即以中央银行货币结算，因而倒闭不会留下一堆未结算净额。它不消除银行在支付*之间*倒闭的风险，也不消除必须在被支付之前实时支付的流动性风险，以及银行在体系外相互放贷的信用风险。
:::
:::
