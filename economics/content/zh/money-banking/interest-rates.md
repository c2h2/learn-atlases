债券是货币支付的时间表。一旦[[money-banking/money-and-payments]]的记账单位固定，买者对该时间表只问一个问题：它*今天*值多少。答案是**现值**，使现值等于市场价格的利率是**收益率**。本章是该答案的算术，外加实际利率与名义利率的区分。

随后的一切由两个事实组织。第一，既定的支付流在以更高利率贴现时价值更低——因而债券价格与收益率反向变动。第二，预期通货膨胀为2%时的6%名义利率，与预期通货膨胀为5%时的6%不是同一笔实际交易。欧文·费雪（Irving Fisher）的分解$1+i = (1+r)(1+\pi^e)$是这一差别的会计。

例题中的数字是虚构发行人的虚构现金流。注明日期的市场收益率（一列国债、一项政策利率）是某一天的观察，有来源，不是预测。本章没有任何买入、卖出或持有任何证券的建议，也不是关于家庭储蓄的理财建议。

## 现值

承诺一年后交付的一单位记账单位，与手中的一单位不是同一对象。若一份安全的一年期债权支付净利率$i$，则今天的1在一年后长成$1+i$，一年后的确定支付$C$今天值$C/(1+i)$。那是一年的**贴现因子**。按常数利率$t$年，贴现因子为$1/(1+i)^t$。

::: definition 现值 {#def-pv}
给定每期贴现率$i$，在第$1,\ldots,n$期末到期的支付流$C_1, C_2, \ldots, C_n$的**现值**为

$$
\mathrm{PV} = \sum_{t=1}^{n} \frac{C_t}{(1+i)^t}.
$$ {#eq-pv}

**永续年金**是$n=\infty$且对所有$t$有$C_t = C$的情形，当$i>0$时求和为$C/i$。**年金**是有限期的等额支付流。公式假定常数利率、按年（或按期）复利，以及确定的支付。若支付不确定，则用期望支付替换$C_t$，并用含风险调整的利率替换$i$——本章不走这一步。
:::

[[#eq-pv]]中的利率$i$是输入。在市场上，它从风险与期限相近的其他工具读取，或是从价格解出的未知数（下一节）。复利惯例要紧：报价为年率6%、一年复利两次的利率，与一年复利一次的6%不是一回事。一年复利$m$次的名义利率$i^{(m)}$的**有效年利率**为$(1 + i^{(m)}/m)^m - 1$。连续复利是极限$m\to\infty$，连续利率$r$的有效年利率为$e^{r} - 1$。

::: widget sequence
a: (1.05)^n
N: 20
mode: terms
start: 0
limit: 0
caption: 一单位按年率5%的复利增长：通项为$a_n = (1.05)^n$。逐步查看$n$。同一算术倒过来就是贴现。5%是说明性利率，不是任何市场的预测。
:::

每年支付8、按5%贴现的永续年金值$8/0.05 = 160$。按8%则值$8/0.08 = 100$。利率加倍使价值减半还不止，因为永续年金有被更高$i$压碎的远期现金流。这种敏感性是萌芽状态的久期。

::: example 作为现值的两年期附息债券 {#ex-two-year-pv}
一家虚构发行人承诺第1年末支付6、第2年末支付106（面值100上6%的票息，按年支付）。按年率5%贴现这些支付。现值是多少？按6%和按7%再做一遍。
::: solution
按5%，

$$
\mathrm{PV} = \frac{6}{1.05} + \frac{106}{1.05^2} = 5.7143 + 96.1451 = 101.859.
$$

按6%，债券值$6/1.06 + 106/1.06^2 = 100$恰好：对按年付息的附息债券，当贴现率等于票息率时，它按**平价**定价。按7%，$\mathrm{PV} = 6/1.07 + 106/1.07^2 = 98.192$。同一笔支付在更高利率下价值更低。三个价格是下面[[#prop-inverse]]的原材料。
:::
:::

::: example 十年期年金 {#ex-annuity}
一份虚构合约在未来10年每年末支付10。按年率6%贴现。现值是多少？与未贴现的10笔10、以及同一利率下支付10的永续年金比较。
::: solution
年金公式为$C\bigl(1 - (1+i)^{-n}\bigr)/i$，因而

$$
\mathrm{PV} = 10 \cdot \frac{1 - 1.06^{-10}}{0.06} = 73.601.
$$

未贴现的10笔10会是100。按6%支付10的永续年金为$10/0.06 = 166.667$。十年期年金是未贴现合计的73.6%，是永续年金的44.2%：永续年金缺失的尾巴——第11年以降——今天仍值$166.667 - 73.601 = 93.066$。在6%下，远期支付并非可忽略。
:::
:::

## 到期收益率与价格-收益率曲线

市场不报价现值；它报价**价格**。使[[#eq-pv]]等于该价格的利率是**到期收益率**。

::: definition 到期收益率 {#def-ytm}
当前价格为$P$、支付为$C_1,\ldots,C_n$的债券的**到期收益率**$y$是方程

$$
P = \sum_{t=1}^{n} \frac{C_t}{(1+y)^t},
$$ {#eq-ytm}

在存在唯一正根时的解。对在$n$期到期、面值为$F$的**零息债券**（贴现工具），$y = (F/P)^{1/n} - 1$。到期收益率是承诺现金流上的内部收益率，不是债券在到期前被出售、或票息以不同利率再投资时将会赚到的收益率的预测。
:::

方程[[#eq-ytm]]是$1/(1+y)$的多项式。笛卡尔符号法则，加上普通附息债券所有$C_t$为正这一事实，给出唯一的正$y$。一旦$n>2$就没有闭式，因而用数值方法求解——牛顿法、二分法或金融计算器。下面的控件对一只说明性的三年期债券做牛顿法。

::: widget newton
f: 5/(1+x) + 5/(1+x)^2 + 105/(1+x)^3 - 97.2
x0: 0.05
steps: 6
x: 0, 0.12
y: -20, 20
caption: 对定价为97.2的虚构三年期5%按年付息债券求到期收益率的牛顿法。函数为$P(x) - 97.2$；根就是收益率。从0.05起步并逐步迭代。现金流是虚构的。根是拟合[[#eq-ytm]]的数，不是预测的市场利率。
:::

::: proposition 债券价格与收益率反向变动 {#prop-inverse}
设$P(y)$为[[#eq-ytm]]右侧作为收益率的函数，对所有$t$有$C_t \ge 0$且对某个$t$有$C_t > 0$。则对$y > -1$有$P'(y) < 0$。因而该映射值域中的每个$P$对应唯一的$y$，收益率上升则价格下降。
:::

::: proof
逐项求导，

$$
P'(y) = \sum_{t=1}^{n} \frac{-t\, C_t}{(1+y)^{t+1}} < 0
$$

只要至少一个$C_t$为正且$1+y>0$。严格单调性在该定义域上给出可逆性：收益率映射是一一的。二阶导数$P''(y) > 0$，因而$P(y)$严格凸——价格-收益率曲线向原点弯曲，这是作为二阶敏感性的**凸性**的来源。
:::

::: widget plot
f: 6/(1+x) + 106/(1+x)^2; 5/(1+x) + 5/(1+x)^2 + 5/(1+x)^3 + 5/(1+x)^4 + 105/(1+x)^5
x: 0.01, 0.12
y: 70, 130
labels: \text{2年期6\%票息}; \text{5年期5\%票息}
caption: 两只虚构按年付息债券的说明性价格-收益率曲线，面值均为100。横轴是收益率$y$。沿任一条曲线看：更高的$y$是更低的价格。五年期债券在此窗口中更陡——更敏感，这是对久期的第一眼。虚构现金流，不是市场，也不是预测。
:::

附息债券在$P$等于面值时按**平价**出售，在$P$高于面值时按**溢价**出售，在$P$低于面值时按**折价**出售。对按年付息债券，平价意味着$y$等于票息率，如[[#ex-two-year-pv]]。溢价债券的$y$低于票息率；折价债券的$y$高于它。正收益率的零息债券总是按低于面值的折价出售。

::: warning 到期收益率不是已实现收益率
[[#def-ytm]]中的收益率是把*承诺*现金流贴现回$P$的常数利率。若债券在一年后被出售，一年收益率是$(C_1 + P_1)/P_0 - 1$，它只在特殊情形下等于$y$（剩余期限一年，或某种特定形状的不变收益率曲线）。若票息以不同于$y$的利率再投资，整个寿命上的复利收益率也不是$y$。把收益率说成有保证的持有期收益率，是标准的误读。
:::

::: example 定价为102的两年期8%债券 {#ex-ytm-solve}
一只虚构的按年付息债券，面值100，每年支付票息8，成交价102。求到期收益率。（二次方程；不必用牛顿法。）
::: solution
$102 = 8/(1+y) + 108/(1+y)^2$。两端乘以$(1+y)^2$：

$$
102(1 + 2y + y^2) = 8(1+y) + 108 \implies 102 y^2 + 196 y - 14 = 0.
$$

判别式为$196^2 + 4\cdot 102\cdot 14 = 38416 + 5712 = 44128$，且$\sqrt{44128} \approx 210.067$。正根为

$$
y = \frac{-196 + 210.067}{204} \approx 0.06895,
$$

即年率6.90%。该债券是溢价债券，因而其收益率低于8%的票息，正如平价规则所要求。
:::
:::

剩余期限较短的**国库券**或零息券，常常按单利（银行贴现或货币市场）而不是按复利收益率报价。面值$F$、价格$P$、距到期$t$天的国库券的**债券等价收益率**为$(F-P)/P \times 365/t$（实际天数/365）。**贴现收益率**把$F$放在分母：在某些国库券市场为$(F-P)/F \times 360/t$。两者不可互换；把国库券与附息债券比较，必须把两者放在同一复利与计日惯例上。

## 久期与价格变动的大小

[[#prop-inverse]]给出方向。**久期**给出一阶大小。

::: definition 麦考利久期 {#def-duration}
对[[#eq-ytm]]中价格为$P(y)$的债券，**麦考利久期**是其支付的现值加权平均期限，

$$
D_{\mathrm{Mac}} = \frac{1}{P} \sum_{t=1}^{n} t \cdot \frac{C_t}{(1+y)^t}.
$$ {#eq-mac}

**修正久期**为$D_{\mathrm{Mod}} = D_{\mathrm{Mac}}/(1+y)$（其中$y$是与付息频率匹配的每期收益率）。于是

$$
\frac{1}{P}\frac{\mathrm{d}P}{\mathrm{d}y} = - D_{\mathrm{Mod}},
$$ {#eq-dp}

因而收益率的小幅上升$\Delta y$使价格大约变动$-D_{\mathrm{Mod}} \cdot P \cdot \Delta y$。久期以时期度量；修正久期是敏感性。
:::

零息债券的麦考利久期等于其期限：只有一笔支付。附息债券的久期严格小于期限，因为部分现值较早到达。收益率上升时久期下降（更多现值在较早的票息中），在其他条件相同下随期限上升，对深度折价长期债券有一条例外，初级课程不必关心。凸性$P''(y)/P$是泰勒展开的下一项，也是一阶近似在收益率向任一方向变动后低估普通附息债券价格的原因。

::: example 两年期6%债券的久期 {#ex-duration}
取[[#ex-two-year-pv]]中收益率为5%的债券，其中$P = 101.859$。计算麦考利久期和修正久期，并近似收益率跳到6%时的价格变动。与6%时的精确价格100比较。
::: solution
两笔支付的现值为$6/1.05 = 5.7143$和$106/1.05^2 = 96.1451$。麦考利久期为

$$
D_{\mathrm{Mac}} = \frac{1\cdot 5.7143 + 2\cdot 96.1451}{101.859} = \frac{198.0045}{101.859} \approx 1.944 \text{年}.
$$

修正久期为$1.944/1.05 \approx 1.851$。收益率上升100个基点预测$\Delta P \approx -1.851 \times 101.859 \times 0.01 \approx -1.886$，因而预测价格为$101.859 - 1.886 = 99.973$。6%时的精确价格是100。线性近似把下跌高估了约0.027，这是凸性余项。对两年期债券上100个基点的变动，误差很小；对长期低票息债券则不然。
:::
:::

在[[money-banking/banking]]中，银行会把久期用作缺口：资产久期与（按杠杆加权的）负债久期之差。算术相同；对象是净值而不是单只债券。资产定价课程把久期作为期限结构模型中的第一个因子（[[asset-pricing/fixed-income]]）。

::: quiz
面值100、成交价96的一年期零息券，其到期收益率（年复利）最接近
- [ ] 4.00%
- [x] 4.17%
- [ ] 贴现基础上的4.00%，与复利收益率相同
- [ ] 96%
::: solution
$y = 100/96 - 1 = 0.041667$，即4.17%。贴现收益率$(100-96)/100 = 4.00%$是不同惯例，不是[[#def-ytm]]中的复利收益率。
:::

## 实际利率与名义利率：费雪关系

名义支付是以货币单位计的支付。实际支付是以商品单位计的支付。若$P_t$是价格水平，名义现金流$C_t$买到$C_t/P_t$的商品。因而通货膨胀$\pi_{t+1} = P_{t+1}/P_t - 1$位于名义利率与实际利率之间。

::: definition 费雪关系 {#def-fisher}
设$i$为一期名义利率，$\pi^e$为同一时期的预期通货膨胀。相应的**事前实际利率**$r$满足

$$
1 + i = (1+r)(1+\pi^e) \qquad\text{因而}\qquad r = \frac{1+i}{1+\pi^e} - 1 \approx i - \pi^e
$$ {#eq-fisher}

当$r$和$\pi^e$较小时。**事后**实际利率用已实现通货膨胀替换$\pi^e$。近似$r \approx i - \pi^e$丢掉了交叉项$r\pi^e$。
:::

费雪（1896，1930）把实际利率视为在商品与储蓄市场上决定，把名义利率视为实际利率加预期通货膨胀。那是关于*$i$如何被决定*的理论，叠在给定$i$和$\pi^e$定义$r$的恒等式之上。恒等式始终成立；理论则不然。在短期，价格黏性时，名义政策利率上升可以提高实际利率，因为$\pi^e$不一对一跳跃——那是大多数新凯恩斯故事的开局（[[business-cycles]]）。在长期古典描述中，$r$由生产率与节俭锚定，$i$一对一继承$\pi^e$的变动（**费雪效应**）。

通货膨胀指数化政府债券在存在之处（美国的TIPS、英国的指数联结金边债券）直接报价实际收益率。相近期限的名义收益率与指数化收益率之差是**盈亏平衡通货膨胀率**。盈亏平衡通货膨胀不是调查预期：它包含通货膨胀风险溢价以及两种工具之间的流动性差别。它是市场隐含的数字，有用，不是用来交易的预测。

::: example 费雪算术 {#ex-fisher}
一年期名义利率为6%。预期通货膨胀为2%。精确的事前实际利率是多少？线性近似是多少？若已实现通货膨胀结果为4%，事后实际利率是多少？
::: solution
精确：$r = 1.06/1.02 - 1 = 0.039216$，即3.92%。近似：$6-2 = 4%$。交叉项$r\pi^e \approx 0.08$个百分点是缺口。事后，$1.06/1.04 - 1 = 0.01923$，即1.92%。未预期到的通货膨胀把实际资源从贷款人转移给借款人。这种转移是通货膨胀风险之所以是风险、以及指数化债券之所以存在的原因。
:::
:::

注明日期的观察，不是预测：美国10年期国债固定期限收益率在2026年10月平均为5.13%（理事会，H.15，FRED序列GS10）。截至2026年11月14日，联邦公开市场委员会的联邦基金利率目标区间为3.75%至4.00%（2026年10月28日FOMC声明；FRED DFEDTARU）。这两个数字是特定日期上的短期利率与长期利率；其差额是斜率，是下一章的主题，不是被推荐的头寸。

**名义**现值使用名义$i$和名义现金流。**实际**现值使用实际$r$和以商品单位计的现金流。把实际利率与名义现金流混用（或反过来）是量纲错误，而且很常见。

::: history
**1930年，欧文·费雪（Irving Fisher）。**《利息理论》（*The Theory of Interest*）重述并扩展了费雪1896年关于升值与利息的论证：名义利率是实际利率加预期通货膨胀，带有交叉项。该书是本章所用费雪关系的来源。给定$i$和$\pi^e$定义事前实际利率的恒等式，不应与费雪关于$i$如何被决定的进一步主张相混淆。
:::

::: quiz
若名义利率为5%、预期通货膨胀为5%，精确的事前实际利率是
- [ ] 0
- [x] $1.05/1.05 - 1 = 0$
- [ ] 10%
- [ ] 无定义，因为近似$r \approx i - \pi^e$才是定义
::: solution
精确公式给出$r = 0$。近似在此特殊情形给出相同结果，因为交叉项$r\pi^e = 0$。近似不是定义；[[#eq-fisher]]才是。
:::
:::

## 证据

两条经验规律有充分记载，但仍不是定理。

关于价格-收益率关系，除算术外没有什么可检验：从[[#eq-ytm]]算出的附息债券价格在$y$上升时下降。经验性的是*$y$的行为*。在中央银行在隔夜市场上操作的体系中，短期名义利率紧跟政策利率（再往后两章）。更长的收益率随预期未来短期利率和期限溢价移动，那是下一章。

关于费雪，名义利率与通货膨胀的长期相关很强。高通货膨胀时期——1970年代的英国和美国、二十世纪末若干轮的巴西和阿根廷、2020年代的土耳其——是高名义利率时期。*事后*实际利率与通货膨胀的短期相关往往为负，因为通货膨胀意外相对于$i$的移动很大。这就是[[#def-fisher]]中事前与事后的区分不是学究气的原因。

实际政策利率，按政策利率减去同期通货膨胀率计算，在2008年后许多发达经济体中多年为负，2020—21年再次为负，并在2023—26年随着通货膨胀比政策利率上升消退得更慢而为正。那些是对注明日期序列的描述（官方政策利率以及各国统计机构的消费者价格通货膨胀）。它们不是关于实际利率“应当”为正的裁决。

## 由此通向何处

违约风险、流动性与税收待遇在同一期限的收益率上加上**风险结构**；预期未来短期利率与期限溢价在不同期限的收益率上加上**期限结构**（[[money-banking/term-structure]]）。银行在资产负债表两侧持有这些工具，因而$y$的移动按久期对资产和负债重新估值（[[money-banking/banking]]）。公司金融课程用同一台现值机器做项目评估（[[corporate-finance/time-value-of-money]]，[[corporate-finance/valuing-bonds]]）。资产定价用随机贴现因子替换常数$i$（[[asset-pricing]]）。[[#eq-pv]]的代数不变；属于其中的利率会变。

::: summary
- 现值按既定利率贴现支付流；支付$C$的永续年金值$C/i$。
- 到期收益率是使债券承诺现金流等于其价格的常数利率。一般而言，它不是已实现的持有期收益率。
- 债券价格与收益率反向变动；对普通附息债券，价格-收益率曲线严格递减且凸。
- 麦考利久期是加权平均期限；修正久期是价格对收益率变动的一阶百分比敏感性。
- 费雪关系把名义利率分成实际利率与预期通货膨胀。给定$\pi^e$，这一分解是恒等式；费雪*效应*是进一步主张：$i$在长期与$\pi^e$一对一移动。
- 把实际利率与名义现金流混用（或反过来）是量纲错误。注明日期的市场收益率是观察，不是预测，也不是建议。
:::

## 习题

::: exercise 永续年金 {level=1 check="125"}
一份永续年金每年支付10。贴现率为8%。其现值是多少？（输入现值。）
::: solution
$10/0.08 = 125$。
:::
:::

::: exercise 平价债券 {level=1}
为什么票息率为$c$、面值100的按年付息附息债券在按$y = c$贴现时恰好值100？
::: solution
$P = \sum_{t=1}^{n} c\cdot 100/(1+c)^t + 100/(1+c)^n$。贴现票息之和是几何级数，等于$100\bigl(1 - (1+c)^{-n}\bigr)$，再加上贴现面值$100/(1+c)^n$剩下100。同一代数就是：利率为$c$、以$c$的票息摊还的贷款，若按平价发行，则在每一日期剩余本金等于面值。
:::
:::

::: exercise 一年期零息券 {level=1 check="4"}
面值100的一年期零息券成交价96.15。其到期收益率以百分比计、四舍五入到最近整数是多少？（输入该整数。）
::: solution
$y = 100/96.15 - 1 \approx 0.04004$，即4.00%。最近整数：4。
:::
:::

::: exercise 两年期价格 {level=2 check="98.19"}
面值100的两年期6%按年付息债券按7%贴现。其价格到两位小数是多少？（输入价格。）
::: solution
$6/1.07 + 106/1.07^2 = 5.6075 + 92.5845 = 98.19$。
:::
:::

::: exercise 费雪：精确与近似 {level=2}
名义利率12%，预期通货膨胀7%。计算精确实际利率和近似$i - \pi^e$。交叉项误差有多大，以百分点计？
::: solution
精确：$1.12/1.07 - 1 = 0.04673$，即4.673%。近似：5%。误差：约0.327个百分点。利率高时近似更差，而这正是人们最希望它好的时候——这是在通货膨胀经济中使用精确公式的一个理由。
:::
:::

::: exercise 零息券的久期 {level=2}
一只10年期零息券按年复利收益率为5%，面值100。计算其价格、麦考利久期，以及收益率上升10个基点时价格的一阶近似。
::: solution
$P = 100/1.05^{10} \approx 61.391$。麦考利久期为10年（单笔支付）。修正久期为$10/1.05 \approx 9.524$。$\Delta P \approx -9.524 \times 61.391 \times 0.001 \approx -0.585$。预测新价格$\approx 60.806$。5.1%时的精确价格为$100/1.051^{10} \approx 60.807$。在10个基点处线性近似已经非常接近。
:::
:::

::: exercise 有效年利率 {level=3}
利率报价为年率12%、按月复利。有效年利率是多少？具有同一有效年利率的连续复利利率是多少？
::: hint
有效年利率为$(1 + i^{(m)}/m)^m - 1$。连续：$e^{r} - 1$等于该数。
:::
::: solution
$(1 + 0.12/12)^{12} - 1 = (1.01)^{12} - 1 \approx 0.126825$，即12.6825%。连续利率$r$满足$e^{r} = 1.126825$，因而$r = \ln 1.126825 \approx 0.1194$，即11.94%。报价12%、按月复利*高于*12%有效，并且它匹配一个*更低*的连续复利利率，因为连续复利是更频繁的时钟。
:::
:::

::: exercise 凸性余项 {level=3}
对$y = 0.05$时的两年期6%债券，$P = 101.859$，$D_{\mathrm{Mod}} \approx 1.851$。凸性$\frac{1}{P}\sum t(t+1)C_t/(1+y)^{t+2}$约等于5.239。用二阶泰勒展开近似$y = 0.06$时的价格，并与精确价格100比较。
::: hint
$\Delta P \approx -D_{\mathrm{Mod}} P \Delta y + \tfrac12 \mathrm{Conv}\, P (\Delta y)^2$。
:::
::: solution
$\Delta y = 0.01$。一阶项：$-1.851 \times 101.859 \times 0.01 \approx -1.886$。二阶项：$0.5 \times 5.239 \times 101.859 \times 0.0001 \approx 0.0267$。预测$\Delta P \approx -1.859$，预测价格$\approx 100.000$。精确价格是100。在100个基点的变动上，对这只短期债券，凸性几乎抹去一阶误差。泰勒级数的余项在此可忽略；对30年期低票息债券和大幅度收益率跳跃则不然。
:::
:::
