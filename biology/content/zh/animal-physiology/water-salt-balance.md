一条鲑鱼在河流里度过早年，它的体液比周围的水咸得多，随后洄游入海，此时它的体液只有海水的三分之一咸。入海几天之内，它的鳃就从吸盐改为排盐，也从滴水不沾改为不停地喝海水。莫哈韦沙漠里的一只更格卢鼠，一生可能都不喝水，靠干燥的种子和自己代谢产生的水过活。一只银鸥喝海水，把盐浓缩成盐水从喙尖滴出。三者都在解决 [[animal-physiology/homeostasis]] 提出的问题：当环境不断把内环境的渗透浓度与离子成分拉离正轨时，把它们保持恒定。

本章涵盖渗透交换的物理基础、动物在海洋、淡水与陆地上的策略、排泄盐、水与含氮废物的器官，以及哺乳类与鸟类的肾如何产生比血液更浓的尿液的逆流机制。所涉转运蛋白见 [[cell-biology/membrane-transport]]，氨、尿素与尿酸的生物化学见 [[biochemistry/metabolic-integration#def-nitrogen]]。

## 渗透与离子调节

动物上皮对水都有程度不同的通透性，水经渗透从上皮较稀的一侧移向较浓的一侧。离子顺电化学梯度扩散。因此，体液与环境不同的动物都在持续得失水与离子，必须靠主动转运补足差额。

::: definition 渗透浓度、张力与渗透调节 {#def-osmolality}
溶液的**渗透浓度**（osmolality）是每千克水中渗透活性微粒的总浓度（osmol kg⁻¹ 或 mOsm kg⁻¹）；1 mmol NaCl 解离为 Na⁺ 与 Cl⁻，贡献近2 mOsm。渗透浓度较高的溶液相对另一个为**高渗**，较低的为**低渗**，相同的为**等渗**。（**张力**指溶液对细胞体积的影响，它还要看哪些溶质能透过膜。）**渗透调节**是对体液渗透浓度的控制；**离子调节**是对特定离子浓度的控制，动物即使不调节总渗透浓度，也可能调节某些离子。
:::

::: proposition 渗透压（van 't Hoff） {#prop-vanthoff}
对稀溶液，渗透压，也就是为阻止水经一块只对水通透的膜进入溶液必须施加的静水压，近似为

$$
\pi = c\,RT,
$$ {#eq-vanthoff}

其中 $c$ 是渗透浓度（osmol 每千克水，按 osmol L⁻¹ 计），$R$ 是气体常数，$T$ 是绝对温度。水透过膜的通量由渗透压之差驱动，并按每种溶质的反射系数缩放（不能透过的溶质为1）。假设条件：稀的、理想的溶液；真实溶液如海水偏离百分之几，这就是生理学家直接测定渗透浓度、通常用冰点降低法的原因。
:::

::: example 大海的吸力有多大？ {#ex-vanthoff}
在15 °C 下计算（a）海水的渗透压（约1000 mOsm kg⁻¹），以及（b）淡水鱼血浆（300 mOsm kg⁻¹）与淡水（取作0）之间的渗透压差。两者都以 kPa 与大气压（101.3 kPa）表示。
::: solution
$RT = 8.314 \times 288 = 2396$ J mol⁻¹。

（a）$\pi = 1000\ \mathrm{mol\,m^{-3}} \times 2396 = 2.40\times10^6$ Pa $= 2.4$ MPa，即24 atm。

（b）$\pi = 300 \times 2396 = 7.2\times10^5$ Pa $= 720$ kPa，即7.1 atm。

这些压力很大。淡水鱼的鳃为了气体交换必须薄而面积大（[[animal-physiology/gas-exchange]]），却暴露在把水压入血液的7个大气压的渗透抽吸之下。气体交换与渗透调节在每一处呼吸表面都相互冲突，这是一个有时称为**渗透-呼吸妥协**（osmo-respiratory compromise）的折中。
:::
:::

## 海洋中的生命

多数海洋无脊椎动物是**渗透压顺应者**：其体液渗透浓度与海水几乎相同，约1000 mOsm kg⁻¹，主要离子大多也相同，尽管它们会调节某些离子（常把 Mg²⁺ 与 SO₄²⁻ 保持得比海水低，把 K⁺ 与 Ca²⁺ 保持得与海水略有不同）。然而它们的细胞无法在1000 mOsm kg⁻¹ 的盐分下工作；细胞用**有机渗透溶质**补足内部渗透浓度的大半，即甘氨酸、丙氨酸、牛磺酸等游离氨基酸，以及甜菜碱等甲胺类，后者在高浓度下不扰乱蛋白质功能。盲鳗是唯一渗透压顺应者的脊椎动物，其血浆渗透浓度也靠 NaCl 保持在接近海水的水平。

其余的海洋脊椎动物让体液远低于海水的盐分，并找到了两种截然不同的办法应对由此而来的后果。

### 鲨与鳐：尿素方案

板鳃类（鲨、鳐与鲼）把血浆 NaCl 保持在约为海水一半的浓度，却通过保留数百 mmol L⁻¹ 的**尿素**与**氧化三甲胺**（TMAO），把总渗透浓度做到与海水相等或略高。如此浓度的尿素会破坏许多蛋白质的稳定，但 TMAO 抵消这一效应，两者常以约2:1的比例共存，在这个比例下它们对蛋白质稳定性的影响大致相消（Paul Yancey 与 George Somero，1979）。由于轻微高渗，板鳃类经鳃渗透获得少量水，为尿液提供自由水，因此从不喝水。盐仍随扩散与食物进入；它由一个特化的**直肠腺**排出，该腺分泌的液体 NaCl 浓度约与海水相当（J. Wendell Burger 与 Walter Hess，1960）。红树林沼泽里的腔棘鱼（*Latimeria*）与食蟹蛙（*Fejervarya cancrivora*）也采用保留尿素的办法。

### 海洋真骨鱼：喝下大海

海洋真骨鱼的血浆约为350–400 mOsm kg⁻¹，约为海水的三分之一。它们经鳃渗透失水，又靠扩散得盐。Homer Smith 在1930年证明，它们靠**喝海水**补水。肠道吸收 NaCl 并随之吸水；二价离子 Mg²⁺ 与 SO₄²⁻ 大部分留在肠内或由肾排出，肾产生的尿量很小、约与血浆等渗（真骨鱼的肾不能产生比血液更浓的尿）。多余的 NaCl 经**离子细胞**排出鳃外，即富线粒体的"氯细胞"，Ancel Keys 与 E. N. Willmer 1932年在鳗鲡的鳃中描述了它们。在每个离子细胞中，基底侧膜上的 Na⁺/K⁺-ATPase 维持细胞内低 Na⁺；Na⁺–K⁺–2Cl⁻ 同向转运体（NKCC1）借 Na⁺ 梯度把 Cl⁻ 从血液带入细胞；Cl⁻ 经顶端上与人 CFTR 同源的通道排入海水；Na⁺ 则在 Cl⁻ 分泌造成的电位驱动下，被动地经漏隙状的细胞间连接紧随其后。

## 淡水中的生命

在淡水中，每种动物都相对环境高渗，倍数从几十到几千。淡水动物面临持续的水的渗透流入与离子的扩散流失。它们以三种方式应对：

- 把体液保持得比海洋亲戚的更稀（淡水蚌的体液是动物中最稀之列，低于50 mOsm kg⁻¹；淡水真骨鱼接近300，螯虾接近400–500），从而压低两种梯度；
- 降低身体表面的通透性，把交换集中到鳃；
- 把进入的水作为大量**稀释尿**排出，并先从尿中重吸收盐分，再经鳃（两栖类则经皮肤）主动从水中吸收 Na⁺ 与 Cl⁻。淡水真骨鱼不喝水，其单位体质量的尿流量可达海洋真骨鱼的十倍以上。

从淡水中吸盐是苦活。在淡水鱼的鳃中，Na⁺ 的吸收据信经顶端 Na⁺ 通道进行，由质子泵 V 型 ATPase 建立的电位梯度驱动，或经 Na⁺/H⁺ 交换体；Cl⁻ 则经 Cl⁻/HCO₃⁻ 交换体，发生在不同的离子细胞类群中；机制因种而异，仍在研究之中。

::: proposition 吸盐的最低能量代价 {#prop-uptake-cost}
把一摩尔电荷为 $z$ 的离子从其浓度为 $c_\mathrm{out}$ 的水溶液移入体内浓度为 $c_\mathrm{in}$ 之处，经一块跨上皮电位为 $\Delta\psi = \psi_\mathrm{in} - \psi_\mathrm{out}$ 的上皮，所需的最低自由能为

$$
\Delta G = RT\ln\frac{c_\mathrm{in}}{c_\mathrm{out}} + zF\Delta\psi,
$$ {#eq-uptake-cost}

即该离子的电化学势差（[[cell-biology/membrane-transport#def-electrochemical]]）。这只是热力学下限；实际 ATP 代价更高，因为转运并非完全高效，而且已吸收的离子会不断漏出、必须再次吸收。严格地说应当使用活度而不是浓度。
:::

::: example 住在淡水的代价 {#ex-uptake}
一条15 °C 的淡水鱼把血浆 Na⁺ 维持在140 mmol L⁻¹，而水中只有0.10 mmol L⁻¹。（a）忽略跨上皮电位，吸收一摩尔 Na⁺ 的最低自由能是多少？（b）若细胞中 ATP 水解约提供50 kJ mol⁻¹，每个 ATP 至多能转运多少个 Na⁺？（c）在含50 mmol L⁻¹ Na⁺ 的半咸水中，代价如何变化？
::: solution
（a）$\Delta G = 2.396 \times \ln(140/0.10) = 2.396 \times 7.24 = 17.4$ kJ mol⁻¹。

（b）$50/17.4 = 2.9$ 个 Na⁺ 每 ATP，这是热力学极限，尚未计入损耗。

（c）$\Delta G = 2.396 \times \ln(140/50) = 2.396 \times 1.03 = 2.5$ kJ mol⁻¹，小了七倍。扩散漏失与浓度差成正比，也更小（90对140 mmol L⁻¹），所以水越咸，离子调节的总代价陡降。渗透调节占鱼类安静代谢的比例究竟多大，历来争论很多；估计从几个百分点到20 %以上不等，取决于物种、盐度与方法。
:::
:::

许多鱼类，即**广盐性**种类，能同时生活在淡水与咸水中。鲑、鳗鲡、刺鱼与鳉在洄游时于两种模式之间切换：在海水中，鳃长出带 NKCC1 与类 CFTR 通道的离子细胞，鱼开始喝水；在淡水中，这些细胞换成吸收离子的细胞，喝水停止，肾加大稀释尿的排出。这一切换受激素控制，皮质醇与生长激素促进海水型，催乳素促进淡水型（[[animal-physiology/endocrine-control]]），需要数日才能完成，这就是鲑在河口停留的原因。

::: warning “淡水鱼大量喝水”与“海水鱼从不喝水，因为海水太咸”
恰恰相反。淡水鱼不断被经鳃渗入的水淹没，并不喝水；它的难题是排水而保盐，靠大量稀释尿与主动吸盐来解决。海洋真骨鱼向大海渗透失水，必须喝海水来补充，再把多余的盐经鳃排出。（鲨因保留尿素而对海水等渗或轻微高渗，根本不需要喝水。）
:::

## 陆地上的生命

在陆地上，难题是蒸发。陆生动物经皮肤与呼吸表面、随尿液与粪便失水，靠饮水、食物含水以及食物氧化产生的**代谢水**来补充。

| 氧化的燃料 | 代谢水（每 g 燃料，g） | 能量 (kJ 每 g) | 代谢水（每100 kJ，g） |
|---|---|---|---|
| 淀粉 | 0.56 | 17.5 | 3.2 |
| 脂肪 | 1.07 | 39 | 2.7 |
| 蛋白质（氧化为尿素） | 0.40 | 17 | 2.4 |

按质量计，脂肪产水最多，这就是驼峰与候鸟的脂肪库有时被说成水库的原因。但按能量计，糖类产水略多，而且氧化脂肪需要更多 O₂、因而呼吸更多，随呼吸失水也更多。脂肪是致密的能量库，不是更好的水源。

哺乳动物中节约水的冠军是更格卢鼠。Knut 与 Bodil Schmidt-Nielsen 在1950年代初证明，梅里亚姆更格卢鼠（*Dipodomys merriami*）不喝水、只靠干燥种子就能无限期活下去，其水分大部分来自代谢水。做到这一点，靠的是白天待在湿润的洞里、排出极浓的尿与极干的粪便，并从呼出的气中回收水。吸气时蒸发把它的鼻腔冷却；当来自肺部的温暖湿气呼过鼻腔时，水凝结并被重新吸收，一个在时间上而非空间上的逆流交换器（K. Schmidt-Nielsen、F. R. Hainsworth 与 D. E. Murrish，1970）。许多鸟类、哺乳类与爬行类以同样方式保存呼吸失水。

::: example 更格卢鼠的水平衡 {#ex-kangaroo-rat}
一只35 g 的更格卢鼠每天耗费35 kJ，全部由干燥种子中的淀粉提供，种子含水5 %（按质量）。（a）它制造多少代谢水？（b）食物另提供多少自由水（每克淀粉17.5 kJ，除水分外假设种子纯为淀粉）？（c）若它每天随粪便与尿液共失水0.5 g，它能承受的蒸发失水是多少？
::: solution
（a）吃下的淀粉 $= 35/17.5 = 2.0$ g；代谢水 $= 2.0 \times 0.56 = 1.1$ g 每天。

（b）吃下的种子 $= 2.0/0.95 = 2.1$ g，含水 $0.11$ g。

（c）总得水量 $= 1.12 + 0.11 = 1.23$ g 每天；蒸发至多为 $1.23 - 0.5 = 0.7$ g 每天，约为体质量的2 %。若它呼出饱和于体温的空气，呼吸失水会高于此数；鼻腔冷却与湿润的洞穴把它压回预算之内。（量级正确的示意数值。）
:::
:::

昆虫体型小、表面积与体积之比大，受这一问题之苦最深。它们的表皮覆有蜡层，减少失水；气门在呼吸之间关闭（[[animal-physiology/gas-exchange]]）；其排泄系统回收水极其高效，见下文。一些沙漠昆虫获取水的方式令人称奇：纳米布沙漠甲虫 *Onymacris unguicularis* 在晨雾中头朝下立在沙丘脊上，让水在其背上凝结、流向口器（W. J. Hamilton 与 M. K. Seely，1976），而黄粉虫（*Tenebrio molitor*）的幼虫能通过直肠从中等湿度的空气中吸收水汽。

## 排泄器官

排泄器官尽管多样，大体都按同样三步工作。

::: definition 尿生成的步骤 {#def-urine}
- **滤过**（或在某些器官中是主动分泌）产生**原尿**：滤过时，血液或血淋巴受压穿过一道屏障，屏障留住细胞与蛋白质，但让水与小溶质通过。
- **重吸收**把有用物质（葡萄糖、氨基酸、多数离子与水）从原尿送回血液，经排泄小管上皮的转运完成。
- **分泌**把血液中的物质加入尿中（H⁺、K⁺、有机酸与碱、尿酸、外来化合物）。

最终的尿就是剩下的东西。因为滤过不加选择，一个以滤过工作的肾能排出任何小分子，包括动物从未遭遇过的分子，而不必为每种分子准备一个专门的转运体。
:::

主要类型有**原肾管**（扁形动物、轮虫、一些环节动物幼虫），盲端小管，"焰细胞"摆动的纤毛把液体抽入管内；**后肾管**（环节动物、软体动物），开口的小管，从体腔引出液体；甲壳类的**触角腺**；昆虫的**马氏管**；以及脊椎动物肾的**肾单位**。

### 昆虫：分泌而非滤过

昆虫的马氏管是盲端小管，漂浮在血淋巴中，于中肠与后肠的交界处开口入肠。血淋巴压力低，它们无法滤过它。相反，正如 J. A. Ramsay 在1950年代所示，管细胞主动把 K⁺（某些种类还有 Na⁺）分泌进管腔，Cl⁻ 与水随后；小溶质随液体被动进入，尿酸被分泌。原尿进入后肠，由**直肠垫**重吸收离子与水。在许多沙漠甲虫与黄粉虫中，马氏管紧裹直肠（**隐肾型**排列），使直肠能如此有效地抽取水分，以致粪便以干粒排出。

### 脊椎动物的肾单位

脊椎动物的肾单位始于**肾小球**，一团位于杯状鲍氏囊内的毛细血管，血压在此驱动滤过。滤液沿小管流去：**近端小管**，在哺乳类约重吸收滤过的水与 NaCl 的三分之二、几乎全部的葡萄糖与氨基酸，且为等渗重吸收；在哺乳类与鸟类还有**亨利氏袢**；**远端小管**；以及**集合管**，其对水的通透性受抗利尿激素控制（哺乳类为血管加压素，其他脊椎动物为精氨酸血管催产素），通过插入水通道蛋白而起作用。

肾的功能用**清除率**衡量：解释某物质的排泄速率所必需、在单位时间内被完全清除该物质的血浆体积。

::: proposition 肾清除率 {#prop-clearance}
对血浆浓度为 $P_x$、尿浓度为 $U_x$、尿流量为 $\dot V$ 的物质，**清除率**为

$$
C_x = \frac{U_x\,\dot V}{P_x}.
$$ {#eq-clearance}

对自由滤过、既不重吸收也不分泌的物质，如植物多糖**菊粉**，滤过的全部被排出，故其清除率等于**肾小球滤过率**（GFR）。清除率小于 GFR 的物质净重吸收；大于 GFR 的净分泌。**排泄分数** $U_x\dot V/(\mathrm{GFR}\cdot P_x)$ 是滤过负荷中出现在尿里的比例。假设条件：血浆浓度处于稳态、膀胱完全排空，以及（测 GFR 时）所选标记物真正自由滤过、不受肾小管处理。
:::

::: example 在狗身上测量滤过 {#ex-clearance}
一只15 kg 的狗被输注菊粉至血浆浓度稳态0.20 mg mL⁻¹。其尿含菊粉12 mg mL⁻¹，生成速率1.0 mL min⁻¹。血浆 Na⁺ 为145 mmol L⁻¹，尿 Na⁺ 为100 mmol L⁻¹。（a）计算 GFR。（b）滤过的水有多大比例被排出？（c）滤过的 Na⁺ 有多大比例被排出？
::: solution
（a）$\mathrm{GFR} = 12 \times 1.0/0.20 = 60$ mL min⁻¹，即每千克4 mL min⁻¹，是狗的典型值。

（b）$1.0/60 = 0.017$：滤过的水不足2 %被排出；98 %被重吸收。

（c）滤过的 Na⁺ $= 0.060\ \mathrm{L\,min^{-1}} \times 145\ \mathrm{mmol\,L^{-1}} = 8.7$ mmol min⁻¹；排出的 $= 0.0010$ L min⁻¹ × 100 mmol L⁻¹ $= 0.10$ mmol min⁻¹。排泄分数 $= 0.10/8.7 = 0.011$，约1 %。肾滤过巨大的体积并重吸收其中几乎全部；因此重吸收的小变化引起排泄的大变化，这就是它进行调节的方式。
:::
:::

## 浓缩尿液：逆流倍增

只有哺乳类与鸟类能产生比血液更浓的尿，靠的是亨利氏袢。袢从皮质下入**髓质**再折返，与集合管并行。

这一机制由 Werner Kuhn 与 Karl Ryffel 于1942年提出，又由 Heinrich Wirz、Bartholomäus Hargitay 与 Kuhn 1951年在大鼠肾上的测量支持，即渗透浓度从皮质到肾乳头顶端稳定升高，称为**逆流倍增**：

1. 袢的**粗段升支**把 NaCl 主动从小管液转入周围间质（经 Na⁺–K⁺–2Cl⁻ 同向转运体 NKCC2），但对水不通透。在任一水平，它能让间质比管内液浓一个有限值，约200 mOsm kg⁻¹。这是**单生效应**。
2. **降支**对水通透，沿它下行的液体向较浓的间质失水、变浓，把更浓的液体送到袢的底部。
3. 由于液体一支下行、一支上行，每一水平的单生效应都叠加在自上方送来的浓度上，200 mOsm kg⁻¹ 的横向差被**倍增**为一个大得多的纵向梯度。袢越长，顶端浓度越高。
4. **集合管**通往肾盂的途中穿过这一梯度。当抗利尿激素使它对水通透时，水经渗透离开集合管、进入浓的髓质，尿液趋近乳头尖端的渗透浓度。在集合管与肾袢之间往复回收的尿素，构成哺乳类髓质渗透浓度的大半。
5. 髓质的血管，即**直小血管**，也构成发夹形袢；作为逆流*交换器*，它们带走重吸收的水，却不冲淡梯度。

下面的程序是倍增的经典"阶梯"演示：交替进行升支在每个水平泵出溶质、与液体向前移动一个水平两步。

```python
# A step-by-step model of the countercurrent multiplier (the classic "staircase" demonstration).
# The loop is divided into n levels; level 0 is at the top (cortex), level n-1 at the bend.
# D[i]: osmolality (mOsm/kg) of the descending limb, which equilibrates with the interstitium
# at the same level; A[i]: osmolality of the ascending limb at that level.
def multiplier(n=10, single_effect=200.0, c_in=300.0, cycles=2000):
    D = [c_in] * n
    A = [c_in] * n
    for _ in range(cycles):
        # 1. pump: the ascending limb moves NaCl out until it is single_effect below the
        #    descending limb at the same level (solute conserved at each level)
        for i in range(n):
            mean = (D[i] + A[i]) / 2
            D[i], A[i] = mean + single_effect / 2, mean - single_effect / 2
        # 2. flow: fluid moves one level down the descending limb, round the bend and one
        #    level up the ascending limb; fluid at the top of the ascending limb leaves
        leaving = A[0]
        A = A[1:] + [D[-1]]
        D = [c_in] + D[:-1]
    return D, A, leaving

for n in (2, 5, 10, 20):
    D, A, out = multiplier(n=n)
    print(f"{n:2d} levels: bend {A[-1]:5.0f} mOsm/kg, fluid leaving the loop {out:4.0f} mOsm/kg")
#  2 levels: bend   700 mOsm/kg, fluid leaving the loop  300 mOsm/kg
#  5 levels: bend  1300 mOsm/kg, fluid leaving the loop  300 mOsm/kg
# 10 levels: bend  2300 mOsm/kg, fluid leaving the loop  300 mOsm/kg
# 20 levels: bend  4291 mOsm/kg, fluid leaving the loop  299 mOsm/kg
```

顶端的浓度随水平数增长而增大，成正比，也就是与袢长成正比，尽管泵在任一水平制造的差不超过200 mOsm kg⁻¹。（这个玩具模型搬动溶质而不搬动水，也没有血管带走重吸收的溶质，所以稳态时液体必须以其进入时的浓度离开袢。在真实的肾中，水离开降支，直小血管带走重吸收的 NaCl 与水，液体以比血浆更稀的约100–150 mOsm kg⁻¹ 离开升支。）

袢越长浓缩越多的预言，在哺乳动物中得到证实。沙漠啮齿动物在厚髓质里有长的肾袢，常伸入一条突向肾盂的长乳头；Ivar Sperber（1944）注意到**相对髓质厚度**与浓缩能力相关，这一相关在更大、经系统发育校正的数据集中得到证实（C. A. Beuchat，1990年代）。最大尿渗透浓度从河狸的约500 mOsm kg⁻¹，经人类的1200–1400，到更格卢鼠的5000以上，再到澳洲跳鼠 *Notomys alexis* 的约9000（R. E. MacMillen 与 A. K. Lee，1967）。鸟的肾中无袢的"爬行类"肾单位与带袢的"哺乳类"肾单位混杂，最大只能达到血浆渗透浓度的两到三倍，但它们在泄殖腔与后肠中再加工尿液，并把大部分氮以几乎不需水的尿酸排出。

::: quiz
一只哺乳动物的集合管对水完全通透。限制其尿液最大浓度的是什么？
- [ ] 肾小球滤液的浓度。
- [x] 髓质顶端间质的渗透浓度，由亨利氏袢的长度与尿素回收设定。
- [ ] 近端小管 NaCl 泵的速率。
- [ ] 离开升支的液体的渗透浓度。

水经渗透离开集合管，直到尿液与周围间质达到渗透平衡。最高的间质渗透浓度在髓质顶端，由肾袢的逆流倍增与尿素回收建立。滤液与血浆等渗，近端小管进行等渗重吸收，两者都不设定上限。
:::
:::

## 盐腺

海鸟、海洋爬行动物以及一些沙漠鸟类与爬行类，产生的尿不足以浓到把海水或咸食中的盐排出，可它们喝海水或吃咸的猎物。Knut Schmidt-Nielsen 与同事1958年发现，喂盐水的鸬鹚与鸥会从其眼上方的**鼻盐腺**分泌浓 NaCl 溶液，从喙尖滴落。鸟类盐腺分泌的液体 NaCl 浓度常在700–900 mmol L⁻¹，远高于海水，某些鹱类还要高。海洋爬行动物的盐腺独立起源于不同的腺体：海龟的泪腺、海蛇的舌下腺、海鬣蜥与许多蜥蜴的鼻腺，以及咸水鳄的舌腺。

::: example 从大海取淡水 {#ex-salt-gland}
一只鸥喝下100 mL 含 NaCl 470 mmol L⁻¹ 的海水。（a）若其盐腺以800 mmol L⁻¹ 排盐，它排出这些盐需要排出多少水，净得多少水？（b）若它只能以最高300 mmol L⁻¹ 的尿排盐，结果如何？
::: solution
（a）盐负荷 $= 0.100 \times 470 = 47$ mmol。分泌体积 $= 47/800 = 0.059$ L $= 59$ mL。净得 $= 100 - 59 = 41$ mL 自由水。

（b）尿体积 $= 47/300 = 0.157$ L $= 157$ mL：净*失*57 mL。喝海水只会使这只鸟脱水。只要盐腺排盐浓度高于所饮水的浓度，盐腺就把海水变成饮用水。
:::
:::

## 含氮废物

蛋白质与核酸的分解产生氮，动物以氨、尿素或尿酸的形式将其排出（[[biochemistry/metabolic-integration#def-nitrogen]]）。选择随水的丰缺而定：氨有毒但便宜，在有足够的水稀释之处使用，如多数水生无脊椎动物与真骨鱼，它们让大部分氨经鳃散失；尿素安全、易溶但排出需水，哺乳类、多数成年两栖类与板鳃类使用；尿酸几乎不溶、以膏状排出，鸟类、多数爬行类与昆虫使用。这一格局可以在一生之中、随条件而改变。蝌蚪排氨，成蛙排尿素；终生水栖的非洲爪蟾 *Xenopus* 大体仍以排氨为主，但若离水饲养便转向排尿素。非洲肺鱼（*Protopterus*）在干泥中夏眠数月时，从排氨转为排尿素，尿素无害地积累在组织中（Homer Smith，1930）。

::: application 水产养殖、保护与医学中的渗透调节
养鱼业依赖渗透调节生理：幼鲑只有完成**银化**，即受激素控制的入海准备，才能被转入海水网箱，否则损失惨重。保护生物学家监测经皮肤吸收水与离子的两栖类，如何响应淡水的酸化与盐化。在人类，肾对水与盐的处理是血压调节与液体疗法的核心，见[医学图谱：肾脏](/learn/medicine/course.php?c=renal)。
:::

::: history
Homer Smith 自1930年起对鱼、肺鱼与蛙如何处理水与氮的研究，使比较肾生理学成为一门学问；他的著作 *From Fish to Philosopher*（1953）提出脊椎动物的肾演化于淡水。Ancel Keys 与 E. N. Willmer 在1932年识别出鳗鲡鳃中的氯细胞，August Krogh 的 *Osmotic Regulation in Aquatic Animals*（1939）确立了淡水动物对离子的主动吸收。Werner Kuhn 与 Karl Ryffel 在1942年提出逆流倍增，Wirz、Hargitay 与 Kuhn 在1951年证实了髓质梯度。J. A. Ramsay 证明昆虫马氏管分泌成尿（1950年代）。Knut 与 Bodil Schmidt-Nielsen 在1950年代研究了更格卢鼠与骆驼的水平衡，Knut Schmidt-Nielsen 与同事在1958年发现了鸟类的盐腺。分子时代始于 Peter Agre 1992年在红细胞中发现水通道蛋白（2003年获诺贝尔化学奖）。
:::

## 由此引向何处

肾受激素控制，抗利尿激素、醛固酮、利钠肽，在鱼类还有皮质醇与催乳素，详见 [[animal-physiology/endocrine-control]]。肾的滤过依赖 [[animal-physiology/circulation]] 的血压，鳃上的盐、水交换与气体交换相互牵制（[[animal-physiology/gas-exchange]]）。

::: summary
- 水沿渗透压梯度 $\pi = cRT$ 渗透（[[#prop-vanthoff]]）；海水施压约24 atm，血浆对淡水约7 atm。
- 多数海洋无脊椎动物与盲鳗是渗透压顺应者，以有机渗透溶质保护细胞；板鳃类以尿素与 TMAO 匹配海水，经直肠腺排盐。
- 海洋真骨鱼低渗：喝海水，经鳃离子细胞排 NaCl（NKCC1、类 CFTR 通道、Na⁺/K⁺-ATPase）。
- 淡水动物高渗：不喝水，排出大量稀释尿，主动吸盐，每摩尔最低代价为 $RT\ln(c_\mathrm{in}/c_\mathrm{out}) + zF\Delta\psi$（[[#prop-uptake-cost]]）。广盐性鱼在激素控制下切换模式。
- 陆生动物在蒸发、尿、粪之失与饮水、食物水、代谢水之得之间求平衡；更格卢鼠靠鼻腔回收水与浓缩尿，仅凭代谢水生活。
- 排泄器官先滤过（或分泌），再重吸收与分泌；昆虫马氏管分泌富 K⁺ 的原尿，由直肠回收。
- 清除率 $U\dot V/P$ 衡量肾功能；菊粉清除率给出 GFR（[[#prop-clearance]]）。
- 哺乳类与鸟类以亨利氏袢的逆流倍增浓缩尿；最大浓度随袢长与髓质厚度上升。
- 海鸟与海洋爬行动物的盐腺排出比海水更浓的 NaCl，把海水变成水源。
- 氮依水的丰缺以氨、尿素或尿酸排出，有些种类会切换。
:::

一条板鳃类的血浆渗透浓度为1050 mOsm kg⁻¹，其中约350 mOsm kg⁻¹ 为尿素、150 mOsm kg⁻¹ 为 TMAO，环境海水为1000 mOsm kg⁻¹。（a）计算15 °C 时的渗透压差与水的移动方向。（b）轻微高渗有什么好处？（c）鳃对尿素有一定通透性。尿素方案带来什么代价，如何减轻？（d）为什么必须有 TMAO 相伴？
::: solution
（a）$\Delta\pi = 50 \times 2396 = 1.2\times10^5$ Pa $= 120$ kPa；水经渗透进入鲨体。（b）渗透获得提供了形成尿液所需的自由水，而不必喝海水、也不必背上喝水带来的盐负荷。（c）尿素必须经鸟氨酸-尿素循环合成，每个尿素约耗4个 ATP 当量（[[biochemistry/metabolic-integration]]），且部分经鳃扩散丢失、部分随尿丢失。板鳃类的鳃对尿素通透性低（鳃膜的脂质组成与尿素的主动回转运均有功劳），肾以复杂的肾小管逆流排列重吸收90 %以上的滤过尿素。（d）数百 mmol L⁻¹ 的尿素会破坏许多蛋白质的结构、改变其活性；TMAO 等甲胺类稳定蛋白质，在约2:1的尿素与甲胺比例下两种效应大体相消（Yancey 与 Somero，1979）。
:::

::: exercise 倍增器的一个模型 {level=3}
运行（或推演）本章的阶梯程序。（a）为什么顶端浓度随水平数增加，尽管泵在每个水平只制造200 mOsm kg⁻¹ 的差？（b）若升支对水通透，梯度会怎样？（c）若降支对水与溶质都不通透，会怎样？（d）袢利尿剂阻断粗段升支的 NKCC2。预测其对尿量与尿浓度的影响。
::: solution
（a）每个水平，泵把单生效应加在已被其上方所有水平浓缩过的液体上；液体随后带着该浓度流向下一水平，泵在那里再加一个增量。逆流流动意味着每个水平都在前一个水平之上叠加，所以总差随水平数（袢长）增长。（b）水会跟随 NaCl 离开升支，横向渗透差便无法维持；单生效应消失，梯度崩溃。（c）降支无法与间质平衡，浓缩效应便传不给下行的液体；倍增失败（在模型中，D 在每个水平都停在流入浓度）。（d）NKCC2 被阻断后没有单生效应，髓质梯度耗散，集合管即使有抗利尿激素也抽不出水：排出大量约血浆渗透浓度的尿，这正是它们临床用途的原理，见[医学图谱：肾脏](/learn/medicine/course.php?c=renal)。
:::
