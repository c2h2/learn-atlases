黎明时分的莫哈韦沙漠里，一只沙漠鬣蜥平贴在岩石上，把身体侧面朝向太阳，体温25 °C，并且还在上升。到上午晚些时候，它到了38 °C，正在觅食；正午沙温超过60 °C，这只蜥蜴则躲进了洞穴。向北几百公里处，一只秋天潜入地下的地松鼠蜷缩在洞里，体温只有2 °C，心脏每分钟只搏动几次。两者都在以截然不同的方式管理同一个物理量（热量），而且都是为了把组织的温度保持在它们的生物化学能够工作的范围内。

温度之所以要紧，是因为细胞中的每一个速率都依赖于它。本章从这种依赖出发，先讲动物与周围环境之间热交换的物理学，然后追踪两大策略，变温与内温，以及它们的中间形态：鱼类与昆虫的局部内温、哺乳动物与鸟类的蛰伏与冬眠。我们建立在 [[animal-physiology/energy-metabolism]] 的能量度量与 [[animal-physiology/homeostasis]] 的控制环之上。

## 温度与生命速率

酶促反应、扩散、膜流动性与配体同蛋白质的结合都依赖于温度。在动物正常经历的范围内，生理速率，代谢率、心率、神经传导速度、消化速率，每升高10 °C 通常加倍或增至三倍。

::: proposition 温度系数 Q₁₀ {#prop-q10}
若某一生理速率 $R$ 随温度每升高10 °C 按一个恒定的因子增长，这个因子就是**温度系数**

$$
Q_{10} = \left(\frac{R_2}{R_1}\right)^{10/(T_2 - T_1)},
$$ {#eq-q10}

其中 $R_1$ 与 $R_2$ 是温度 $T_1$ 与 $T_2$ 下的速率。等价地，$R_2 = R_1\,Q_{10}^{(T_2 - T_1)/10}$，因此 $\log R$ 是 $T$ 的线性函数。

$Q_{10}$ 是对所测得的一对速率的经验性描述。它并非严格恒定：对服从 Arrhenius 方程 $R \propto \mathrm{e}^{-E_\mathrm{a}/k_\mathrm{B}T}$ 的过程，它随温度上升而缓慢下降；接近耐受上限时速率停止上升，并随蛋白质变性而下降。生化与生理速率的典型值为2–3；扩散等物理过程的 $Q_{10}$ 接近1.2–1.4。
:::

::: example 计算 Q₁₀ {#ex-q10}
一只蜥蜴安静时的 O₂ 消耗量在18 °C 为4.5 mL h⁻¹，在30 °C 为12 mL h⁻¹。（a）计算 $Q_{10}$。（b）若 $Q_{10}$ 不变，预测它在38 °C 时的 O₂ 消耗量。（c）在10 °C 的寒夜里，它会动用30 °C 时速率的几分之几？
::: solution
（a）$Q_{10} = (12/4.5)^{10/12} = 2.667^{0.833} = 2.26$。

（b）$R = 12 \times 2.26^{8/10} = 12 \times 1.92 = 23$ mL h⁻¹。

（c）$R_{10}/R_{30} = 2.26^{-2} = 0.20$：五分之一。寒冷的夜晚花不掉变温动物多少能量，这是变温的一个好处；代价是在重新暖和起来之前，它无法奔跑、消化或迅速反应。
:::
:::

每个物种都有一个它表现良好的体温范围。**热表现曲线**，短跑速度、游泳耐力或生长速率对体温的曲线，缓慢上升至一个最适值，然后陡降至**临界热最大值**（CTmax），此时动物丧失协调能力；在下侧，表现降至**临界热最小值**（CTmin）。这种不对称，缓升与骤降，意味着生活在最适值稍下方的动物比看起来更接近灾难。南极鱼类生活在约−1.9 °C，其范围是已知最窄之列；热带蜥蜴与昆虫则常生活在接近其 CTmax 之处，这就是生理学家预期它们属于受气候变暖影响最严重的动物的原因。

## 热生物学的词汇

旧术语描述的是*结果*：**变温动物**（poikilotherm）体温可变，**恒温动物**（homeotherm）体温恒定。它们令人不满意，因为深海鱼的体温几乎恒定却不调节任何东西，而冬眠哺乳动物的体温变化达35 °C。现代用法按热的*来源*对动物分类。

::: definition 热策略 {#def-thermal}
- **变温动物**（ectotherm）的体热主要来自环境；它的体温由与周围环境的热交换平衡设定，并可通过行为来操纵这一平衡。
- **内温动物**（endotherm）通过代谢产生大部分体热，并通过改变产热与散热来调节体温。
- **异温动物**（heterotherm）指只在身体某些部位是内温的（**局部异温**，如金枪鱼与飞行的昆虫），或只在某些时候是内温的（**时相异温**，如进入蛰伏或冬眠的动物）的动物。

**体温调节**是通过生理或行为手段把体温维持在一个范围之内；当有合适的可供利用的环境时，变温动物可以像内温动物一样精确地调节体温。
:::

## 与环境的热交换

动物通过四条物理途径与环境交换热量，只要总交换与其代谢产热不平衡，它的体温就会改变。

::: definition 热交换的途径 {#def-heat-routes}
- **传导**：接触表面之间的传递，与温差及材料的热导率成正比；水的导热能力约为空气的25倍。
- **对流**：由运动流体（风、水流，或体内的血液）传递，不断更新表面相邻的那层流体，从而大大增强传导交换。
- **辐射**：不同温度的表面之间的红外辐射交换，以及对太阳辐射的吸收；它不需要介质，在阳光下可能占主导地位。
- **蒸发**：水从皮肤或呼吸道蒸发带走的热，在体温下每克水约2.4 kJ；它是动物向比自身更热的环境散热的唯一途径。
:::

::: proposition 热平衡方程 {#prop-heat-balance}
对于质量为 $M$、比热容为 $c$（动物组织约为3.5 kJ kg⁻¹ K⁻¹）的动物，其体温 $T_\mathrm{b}$ 的变化率满足

$$
M c\,\deriv{T_\mathrm{b}}{t} = H_\mathrm{met} - H_\mathrm{cond} - H_\mathrm{conv} - H_\mathrm{rad} - H_\mathrm{evap},
$$ {#eq-heat-balance}

其中 $H_\mathrm{met}$ 是代谢产热，其余每一项是经由一条途径净散失的热（若获得热则为负）。当右端为零时体温稳定。蒸发以外的各项常被合并为**干散热**（dry heat loss），在适中范围内近似为 $C(T_\mathrm{b} - T_\mathrm{a})$，其中 $T_\mathrm{a}$ 是环境温度，$C$（W K⁻¹）是动物的**热导**，即牛顿冷却定律的常数。其倒数 $1/C$ 是动物的**隔热**。
:::

方程 [[#eq-heat-balance]] 告诉我们动物能控制什么。它可以改变 $H_\mathrm{met}$（战栗、产热）。它可以改变 $C$，方法有蓬松毛发或羽毛、改变姿势（蜷成球减少暴露表面）、改变皮肤血流量，或挤挤在一起。它可以通过选择所处的位置改变 $T_\mathrm{a}$，通过朝向或背向太阳改变辐射项。它还可以通过出汗、喘气或打湿身体改变 $H_\mathrm{evap}$。变温动物主要依靠行为与血流改变；内温动物再加上一项代谢产热。

### 生活在水里

对内温动物来说水是一种恶劣的介质：它的导热率高、热容极大（同体积空气的约3500倍），意味着水中的温暖身体散热极快，而鱼很难明显比周围的水更暖。对鱼来说这一问题比对鲸更严重，因为鱼的鳃为了气体交换必须把血液暴露于水（[[animal-physiology/gas-exchange]]），也就成了完美的热交换器：血液中的任何热在一次流过鳃时就会散失到水里。因此几乎所有鱼都处于水温。海洋哺乳动物与鸟类靠呼吸空气避开这一问题，并用鲸脂或困在浓密毛羽中的空气来隔热。

## 内温动物与热中性区

把一只内温动物放进量热呼吸计中、在不同气温下测定，它的代谢率会呈现一种典型模式。在适中的一段温度范围内它恒定且最小：动物通过改变隔热（姿势、竖毛、皮肤血流）调节干散热，不需要额外的热。低于这一范围，代谢率随空气变冷而上升；高于这一范围，代谢率再次上升，因为动物要费力通过喘气或出汗来散热。

::: definition 热中性区与临界温度 {#def-tnz}
**热中性区**（thermoneutral zone，TNZ）是内温动物代谢率处于最小值（基础条件下即 BMR）、体温仅靠改变隔热即可调节的那段环境温度范围。它的下界是**下临界温度**（lower critical temperature，LCT），低于它代谢产热必须增加；上界是**上临界温度**（UCT），高于它主动的蒸发散热使代谢率上升。
:::

::: proposition Scholander–Irving 模型 {#prop-scholander}
在下临界温度以下，一只体温 $T_\mathrm{b}$ 恒定、热导 $C$ 恒定（且为最小值）的内温动物必须以如下速率产热

$$
H_\mathrm{met} = C\,(T_\mathrm{b} - T_\mathrm{a}),
$$ {#eq-scholander}

（忽略少量的蒸发散热），于是代谢率随环境温度下降而线性上升，斜率为 $-C$，且这条直线外推到 $T_\mathrm{a} = T_\mathrm{b}$ 时代谢率为零。下临界温度就是这条直线与 BMR 相交之处：

$$
T_\mathrm{LCT} = T_\mathrm{b} - \frac{\mathrm{BMR}}{C}.
$$ {#eq-lct}

假设条件：稳态、体温恒定、低于 LCT 时热导已处于最小值。真实动物常有偏离：热导可能在 LCT 以下继续略降，蒸发与呼吸散热还加上一个小的项；此时直线外推到一个与 $T_\mathrm{b}$ 略不相同的温度。
:::

::: proof
稳态时 $\deriv{T_\mathrm{b}}{t} = 0$，由 [[#eq-heat-balance]]，代谢产热等于散热。忽略蒸发、干散热取 $C(T_\mathrm{b} - T_\mathrm{a})$，即得 [[#eq-scholander]]。在 TNZ 内，动物以基础速率产热并调节 $C$ 以使之平衡；到 LCT 处，$C$ 已达最小值，基础速率恰好平衡散热：$\mathrm{BMR} = C(T_\mathrm{b} - T_\mathrm{LCT})$，重排即得 [[#eq-lct]]。
:::

Per Scholander、Laurence Irving 与同事在他们1950年对阿拉斯加与巴拿马的寒带与热带哺乳动物、鸟类的经典比较中使用了这一框架。热带哺乳动物的下临界温度约为20–30 °C：轻微的降温就迫使它们陡增代谢率。厚毛的寒带哺乳动物则大不相同。一只北极狐（*Vulpes lagopus*）直到空气降到约−40 °C 才提高代谢率，即使到了−70 °C 也只比基础值高约50 %。寒带哺乳动物的适应之处不在更高的 BMR，基础代谢率大体与体型相符，而在隔热：隔热降低 $C$，从而降低斜率与 LCT。

::: example 一条代谢率曲线 {#ex-lct}
一只2 kg 的哺乳动物 BMR = 20 W，体温38 °C，最小热导0.80 W K⁻¹。（a）它的下临界温度是多少？（b）在−20 °C 时它的代谢率是多少，为 BMR 的几倍？（c）一只同质量、同 BMR 的寒带亲戚 LCT 为−40 °C。它的热导是多少，在−20 °C 时它的代谢率会是多少？
::: solution
（a）$T_\mathrm{LCT} = 38 - 20/0.80 = 38 - 25 = 13$ °C。

（b）$H = 0.80 \times (38 - (-20)) = 0.80 \times 58 = 46$ W，为 BMR 的2.3倍。折成食物，仅取暖就要超过全天需要的一倍多。

（c）$C = \mathrm{BMR}/(T_\mathrm{b} - T_\mathrm{LCT}) = 20/78 = 0.26$ W K⁻¹，约为这只温带动物的三分之一。在−20 °C 时它仍处于热中性区内，代谢率为 BMR，即20 W。让寒冷变得可以承受的，是隔热，而不是更旺的炉子。
:::
:::

### 产热

在 LCT 之下，内温动物以两种方式提高产热。**战栗**是骨骼肌的非同步收缩，产热而不产生运动。胎盘哺乳动物的**非战栗产热**主要发生在**棕色脂肪组织**中，其线粒体含有解偶联蛋白1（UCP1），它让质子梯度以热的形式耗散而不是合成 ATP（[[biochemistry/oxidative-phosphorylation]]）。棕色脂肪在新生儿、小型哺乳动物与冬眠者身上十分显著，冬眠者用它复温。鸟类没有棕色脂肪，也没有有功能的 UCP1；它们依靠庞大的飞行肌与腿部肌肉的战栗，其骨骼肌中也有非战栗产热的证据，尽管其机制与重要性仍在研究之中。

### 留住热量：隔热与逆流热交换

毛、羽与鲸脂为体核隔热。但站在冰上或在冷水中游泳的动物，不能不给脚、鳍状肢或舌头隔热，否则它们就派不上用场。这一演化过许多次的解决办法是：让四肢末端保持冰冷，同时阻止它们从体核抽走热量。

::: definition 逆流热交换 {#def-countercurrent}
**逆流热交换器**由两股逆向流动、紧密热接触的流体构成，例如一根动脉与其并行的静脉。流向肢端的温热动脉血，把热交给从肢端回流的冰冷静脉血。因为两股流体反向流动，二者之间的温差沿交换器的全长存在，几乎全部热都可以被转移：动脉血到达肢端时几乎与肢端同温，而静脉血返回体核时几乎与体核同温。在**同向**（并流）排列中，两股流体只能达到共同的中间温度，因此至多回收一半的热。
:::

鸥与涉禽腿中、鲸与海豹鳍状肢中（Scholander 与 William Schevill，1955）、北极狐腿中的逆流交换器，让四肢末端维持在冰点以上几度，而体核保持38–40 °C。一只站在冰上的鸭子只通过脚散失其产热量的一小部分。

::: example 站在冰上的鸥 {#ex-foot}
血液以2.0 mL min⁻¹ 流过一只鸥的腿部（密度1.05 g mL⁻¹，比热3.6 J g⁻¹ K⁻¹）。体核为40 °C，双脚浸在0 °C 的水里，流出足部的血液为2 °C。（a）若腿部没有热交换，动脉血将以40 °C 进入足部。双脚会散失多少热？（b）若有一个高效的逆流交换器，动脉血以4 °C 到达足部。此时散热多少？（c）两者都与这只鸟约5 W 的安静代谢率作比较。
::: solution
每开尔文血流携带的热：$2.0 \times 1.05 \times 3.6 = 7.56$ J K⁻¹ min⁻¹。

（a）血液在足部从40 °C 冷却到2 °C：$7.56 \times 38 = 287$ J min⁻¹ $= 4.8$ W。

（b）血液在足部只从4 °C 降到2 °C：$7.56 \times 2 = 15$ J min⁻¹ $= 0.25$ W。其余的热已在腿部由动脉交给静脉，被带回体核。

（c）没有交换器，单是双脚就会散失这只鸟安静产热的几乎全部；有了它，只有约5 %。（对大型鸥类量级正确的示意数值。）许多鸟在需要*散*热时还能让血液绕过交换器，于是双腿成了可调节的散热器。
:::
:::

### 散热

在炎热环境里问题反转。在上临界温度以上，以及每当空气比身体更热时，蒸发是唯一的散热途径。哺乳动物出汗（马与人大量出汗，许多其他动物几乎不出）或喘气；鸟类喘气并振动喉底（gular flutter），以很小的肌肉功让空气流过湿润表面。喘气的动物以其呼吸系统的共振频率呼吸，这使呼吸的功变得便宜；它们移动的空气主要在上呼吸道的死腔里，于是散热而不会呼出太多 CO₂。

蒸发要消耗水，而在沙漠里水是最稀缺的资源。小动物承受不起，因为它们的表面积相对于体内含水量太大。较大的动物另有选择：白天让身体热起来，把热贮存起来，到凉爽的夜晚再通过传导与辐射排掉。

::: example 让身体热起来以省水 {#ex-camel}
Knut Schmidt-Nielsen 与同事1957年发现，撒哈拉一头脱水的单峰驼（*Camelus dromedarius*）让体温夜间降到约34 °C，到白天结束时升到约40–41 °C 才开始出汗。（a）对一头500 kg、比热3.4 kJ kg⁻¹ K⁻¹ 的骆驼，升温6 °C 贮存多少热？（b）以蒸发（2.4 kJ g⁻¹）散去这些热需要多少水？（c）为什么这一策略对一只100 g 的啮齿动物行不通？
::: solution
（a）$500 \times 3.4 \times 6 = 10\,200$ kJ。

（b）$10\,200/2.4 = 4250$ g，每天约4 L 水，这是骆驼不必喝的水。

（c）一只100 g 动物的热容量小5000倍，因而在同样的每克热负荷（实际更大，因为它的表面积与质量之比更大）下，体温升高6 °C 只需几分钟而不是几小时。它存不下一天的热。更格卢鼠这样的小型沙漠哺乳动物靠白天待在凉爽的洞穴、夜间出来活动而完全避开了这一问题。高体温对骆驼还有第二个好处：它减小热空气与身体之间的温差，于是流入的热更少。
:::
:::

## 变温动物：行为性体温调节

变温动物不能靠产热大幅升温，但在异质的环境中，它可以通过选择所处位置来精确调节体温。沙漠蜥蜴清晨晒太阳，身体垂直于太阳、紧贴在暖石上，然后在一天中于日光与树荫之间往返，把体温维持在**偏好温度**附近几度之内（沙漠鬣蜥约为38–40 °C）。Charles Cowles 与 Raymond Bogert 1944年对沙漠爬行动物的研究确立了爬行动物会进行体温调节，并确立了许多种类若无法逃离阳光会在几分钟内热死。生理调节也有帮助：加拉帕戈斯海鬣蜥（*Amblyrhynchus cristatus*）在寒冷的海水中觅食，在陆地上的升温速率约为在水中冷却速率的两倍，因为它升温时提高心率与皮肤血流、降温时再把它们降下来（George Bartholomew 与 Robert Lasiewski，1965）。

行为性体温调节有极限。在均一的环境中，比如浓荫下的林底或深水的湖，没有什么可利用，动物的温度随环境走。调节体温的代价，晒太阳而不取食的时间、暴露给捕食者，必须与它的益处相权衡，这是 R. B. Huey 与 M. Slatkin 1976年成本-收益模型的主题。

::: warning “冷血动物是冷的”
“冷血”这个说法误导人。晒太阳的蜥蜴常在37–40 °C，与哺乳动物一样暖；活动中的熊蜂飞行肌在凉爽的早晨维持在30–40 °C；金枪鱼的游泳肌可比海水暖10–20 °C。变温动物未必是冷的，而且许多种类一天中的大部分时间把自己的温度保持在很窄的范围内。变温动物与内温动物的区别在于热从何来、代价如何，而不是动物有多暖。反过来说，深度冬眠的内温动物可能只有2 °C，比大多数变温动物平时的温度还低。
:::

## 鱼类与昆虫的局部内温

一些变温动物在身体的某些部位是内温的。它们使用的同样是鸟类与哺乳动物的那两样手段：产热与逆流交换。

- **金枪鱼与鼠鲨。**蓝鳍金枪鱼（*Thunnus*）以及灰鲭鲨与大白鲨让深藏在体内、贴近脊柱的红色游泳肌保持温暖，靠的是为其供血的动、静脉之间的逆流交换器（*retia mirabilia*）：肌肉活动产生的热被保留下来，而不是被带到鳃（Francis Carey 与 John Teal，1966与1969）。温暖的肌肉收缩更快、更有力，温暖的眼与脑处理信息更快，这可能有助于这些快速捕食者在冷水中追猎。
- **旗鱼类。**剑鱼与枪鱼有一个**脑部加热器**：一块特化成产热组织的眼肌，为脑与眼加温（Carey，1982）。
- **月鱼。**月鱼（*Lampris guttatus*）是一种生活在凉爽中层水域的高体形鱼，它让全身保暖：来自不停摆动的胸鳍肌肉的热被鳃中的逆流交换器保留，于是离开鳃的血液不会被冷却到水温（Nicholas Wegner 与同事，2015）。
- **昆虫。**许多蛾、蜂与甲虫在飞行肌暖起来之前无法飞行。它们靠同时收缩拮抗的飞行肌预热，这是一种战栗，然后在飞行中把胸腔温度维持在高位；熊蜂蜂后甚至把温暖的腹部压在卵上为后代加温。Bernd Heinrich 从1970年代起的研究表明，熊蜂与天蛾靠控制从胸部流向腹部的血流来调节胸腔温度，腹部充当散热器。

## 蛰伏与冬眠

对小型内温动物来说，在寒冷中维持温暖的代价可能超过它能找到的食物。[[animal-physiology/energy-metabolism#ex-shrew]] 显示鼩鼱的脂肪只够撑几个小时。许多小型哺乳动物与鸟类演化出了一条出路：暂时不再坚守高体温。

::: definition 蛰伏与冬眠 {#def-torpor}
**蛰伏**是代谢率与体温受控地降到正常安静值以下的状态，动物靠自身产热即可复温。**日蛰伏**持续数小时，通常出现在每天的不活动时段，体温通常降到10–30 °C。**冬眠**是由连续多日的深蛰伏构成、贯穿一个季节的蛰伏，体温常接近环境温度、低至0–5 °C（极少数情况下低于0 °C），其间被周期性的觉醒、恢复到正常体温打断。**夏眠**是炎热干旱季节的蛰伏。
:::

蜂鸟、许多小型蝙蝠、小型有袋类、小鼠与一些小型鸟类使用日蛰伏。经典的冬眠者包括地松鼠、旱獭、睡鼠、刺猬与许多蝙蝠。冬眠不限于寒带的哺乳动物：三声夜鹰（*Phalaenoptilus nuttallii*），一种北美夜鹰，1940年代末被 Edmund Jaeger 发现冬眠于岩缝中；马达加斯加的肥尾矮狐猴（*Cheirogaleus medius*）在树洞中冬眠数月，当树洞温度的昼夜波动较大时，其体温随树洞的波动而波动（Kathrin Dausmann 与同事，2004）。北极地松鼠（*Urocitellus parryii*）让体温降到0 °C 以下、约−2.9 °C 而不结冰（Brian Barnes，1989）。

冬眠的一次蛰伏期中，代谢率可降到 BMR 的百分之几，心率从每分钟几百次降到寥寥几次，呼吸降到每分钟几次甚至更少，有时出现长长的屏息。体温并非被完全弃之不顾：动物守卫一个新的、很低的调定点，洞穴过冷时便复温。每隔一周或几周，冬眠者**觉醒**，靠棕色脂肪与战栗在几小时内复温到接近37 °C，在正常体温下停留一天或更短，然后重新进入蛰伏。这些觉醒消耗了冬眠季节能量的大部分。为什么必须有觉醒仍未有定论；提出的原因包括恢复免疫功能、睡眠、清除代谢产物与修复组织的需要。

::: example 降温能省多少？ {#ex-hibernation}
一只冬眠地松鼠的体温从37 °C 降到5 °C。（a）若其代谢只因温度的直接影响而减慢、$Q_{10} = 2.5$，正常体温时代谢率的几分之几仍在进行？（b）这类冬眠者实测的蛰伏代谢率常约为正常安静体温时速率的2 %。这一比较说明了什么？
::: solution
（a）$R_5/R_{37} = 2.5^{(5 - 37)/10} = 2.5^{-3.2} = 0.053$：约5 %。

（b）实测值远低于温度效应单独所能解释的水平，所以必定还存在**主动**的代谢压制：蛋白质合成与离子泵等细胞过程被关闭（离子漏也相应降低）。对进入蛰伏的冬眠者的测量支持这一结论：其中代谢率早于体温下降。压低之中有多大成分来自主动压制、多大成分来自温度，因物种而异，日蛰伏与冬眠也不同，长期存在争论；在许多冬眠者中两者贡献都很大。
:::
:::

大型哺乳动物不以这种意义冬眠。熊在冬季巢穴中禁食数月，但体温只降几度，到约30–35 °C。Øivind Tøien 与同事（2011）发现，阿拉斯加的黑熊（*Ursus americanus*）却仍把代谢率降到基础值的约四分之一，这一降幅远大于小小降温本应造成的，是主动代谢压制的又一例。庞大的身体冷却极慢，又贮存了那么多脂肪（[[animal-physiology/energy-metabolism]]），深度降温带来的好处就少了。

### 结冰与避冻

无法避开零下温度的动物，要么阻止体内形成冰，要么忍受结冰。南极的鳄冰鱼生活在−1.9 °C 的海水里（低于其血液的冰点），拥有**抗冻糖蛋白**，结合到小冰晶上阻止其生长（Arthur DeVries 与同事，自1969年起）；抗冻蛋白在若干鱼类谱系与昆虫中独立演化过。许多昆虫以**过冷**越冬：清除冰核物质，使体液在远低于冰点处仍保持液态。少数动物忍受结冰：北美木蛙（*Lithobates sylvaticus*，旧称 *Rana sylvatica*）在约三分之二身体水分结冰、心脏停跳的情况下存活，靠的是结冰开始时由肝糖原生成的大量葡萄糖提供保护，它限制细胞皱缩并把冰留在细胞外（Kenneth 与 Janet Storey 对它做了大量研究）。

::: quiz
一只哺乳动物的代谢率在若干气温下测定：在25与33 °C 之间恒为12 W，在25 °C 以下以斜率−0.6 W K⁻¹ 线性上升。哪个结论正确？
- [ ] 它的体温是25 °C。
- [x] 它的下临界温度是25 °C，最小热导是0.6 W K⁻¹。
- [ ] 它的下临界温度是33 °C。
- [ ] 在热中性区内，它的 BMR 随空气变冷而增加。
::: solution
25 °C 处的拐点，即上升直线与基础平台的交点，是下临界温度；它下方的斜率给出最小热导0.6 W K⁻¹（[[#prop-scholander]]）。把直线外推到代谢率为零得 $25 + 12/0.6 = 45$ °C，高于任何可信的体温，这表明 LCT 以下热导仍在下降，或模型的假设未被完全满足，这在真实数据中是常见的发现。
:::
:::

::: application 热生理学与气候变化
热耐受极限与表现曲线如今是预测物种对变暖之响应的核心。对昆虫与蜥蜴的比较研究表明，热带变温动物生活在接近其热最适值处、耐受范围又窄，受几度增温之害可能比经历宽幅波动的温带物种更重（C. A. Deutsch 与同事，2008）。保护生物学家利用体温实测、有效环境温度（动物的无生命模型在给定微生境中会达到的温度）与耐受极限，来辨别哪里最需要遮荫与庇护所（[[conservation-biology/invasions-climate]]）。
:::

::: history
Claude Bernard 在1851–52年切断兔耳的交感神经、看着耳朵变暖发红，证明神经控制皮肤血管的直径；体温调节的下丘脑中枢则在二十世纪被定位。Charles Cowles 与 Raymond Bogert 在1944年证明了沙漠爬行动物的行为性体温调节。Per Scholander、Laurence Irving 与同事在他们1950年对寒带与热带动物的比较中，确立了隔热、热导与下临界温度的现代框架；Scholander 在1955年描述了鲸鳍中的逆流热交换。Knut Schmidt-Nielsen 对骆驼的研究（1957）、Francis Carey 对暖血鱼的研究（自1966年起）、Bernd Heinrich 对昆虫体温调节的研究（自1970年代起）与 Brian Barnes 对北极地松鼠零下体温的发现（1989），表明同样的物理原理被利用得多么广泛。
:::

## 由此引向何处

内温动物产生的热必须由食物（[[animal-physiology/feeding-digestion]]）与氧气（[[animal-physiology/gas-exchange]]）提供燃料，其在周身的分布则依赖循环（[[animal-physiology/circulation]]）。蒸发散热把体温调节与水平衡（[[animal-physiology/water-salt-balance]]）联系起来，而设定代谢率、触发季节性变化的激素在 [[animal-physiology/endocrine-control]]。

::: summary
- 生理速率每升高10 °C 通常按 $Q_{10}$ 提高2–3倍（[[#prop-q10]]）；表现曲线升至最适值，朝临界热最大值陡降。
- 变温动物从环境得热，内温动物从代谢得热；异温动物只在身体一部分或时间一部分内温。
- 热经传导、对流、辐射与蒸发交换；稳态时代谢产热等于总散热（[[#prop-heat-balance]]）。
- 在下临界温度以下，内温动物的代谢率按 $C(T_\mathrm{b} - T_\mathrm{a})$ 上升；寒带哺乳动物主要靠隔热御寒，隔热降低 $C$ 与 LCT（[[#prop-scholander]]）。
- 逆流交换器使四肢末端保持低温而不抽耗体核，也让金枪鱼与鼠鲨的肌肉保持温暖。
- 在热空气中蒸发是唯一的散热途径；大型沙漠哺乳动物靠白天贮热省水，小型动物靠洞穴避热。
- 变温动物靠行为调节体温，常常十分精确；昆虫与一些鱼类是局部内温的。
- 蛰伏与冬眠通过降温（$Q_{10}$）与主动压制共同压低代谢；觉醒消耗冬眠能量预算的大部分。
- 冰要么靠抗冻蛋白与过冷避开，要么像木蛙那样忍受。
:::

## 习题

::: exercise 一个 Q₁₀ {level=1 check="2.5"}
一只蟹的心脏在10 °C 时搏动40次 min⁻¹，在20 °C 时为100次 min⁻¹。$Q_{10}$ 是多少？
::: solution
$Q_{10} = (100/40)^{10/10} = 2.5$。
:::
:::

::: exercise 下临界温度 {level=1 check="22"}
一只内温动物 BMR 4.0 W，体温37 °C，最小热导0.27 W K⁻¹。它的下临界温度是多少（四舍五入到整度）？
::: solution
$T_\mathrm{LCT} = 37 - 4.0/0.27 = 37 - 14.8 = 22$ °C。
:::
:::

::: exercise 蒸发散热 {level=1 check="150"}
一名70 kg 的跑者，代谢率比干散热所能散失的水平高出100 W，要蒸发多少克水才能散掉一小时多出的热（2.4 kJ g⁻¹；取最接近的10 g）？
::: solution
$100\ \mathrm{W} \times 3600\ \mathrm{s} = 360$ kJ；$360/2.4 = 150$ g 水每小时。（出汗量通常远多于蒸发的量，因为有些直接滴落而没有参与散热。）
:::
:::

::: exercise 小动物贮热 {level=2 check="25"}
一只100 g 的沙漠啮齿动物正午身处洞外，产生0.60 W 代谢热，又从炎热的环境多得0.25 W。若它不能蒸发水分，体温升高3.6 °C 需要多少分钟（比热3.5 kJ kg⁻¹ K⁻¹；两位有效数字）？若它靠蒸发维持恒温，每小时会损失体质量的百分之几？
::: solution
需贮存的热：$0.100 \times 3500 \times 3.6 = 1260$ J。得热速率：$0.60 + 0.25 = 0.85$ W。时间 $= 1260/0.85 = 1480$ s，即25 min。蒸发：$0.85/2400\ \mathrm{g\,s^{-1}} \times 3600 = 1.3$ g h⁻¹，每小时占体质量的1.3 %，远非这只以干燥种子为食的动物所能补充。它必须退回洞穴。
:::
:::

::: exercise 读一条代谢曲线 {level=2}
一只1 kg 哺乳动物在不同气温下的代谢率（W）为：−10 °C，14.0；0 °C，11.0；10 °C，8.0；20 °C，5.0；25 °C，4.5；30 °C，4.5；35 °C，6.0。（a）估计 BMR、最小热导与下临界温度。（b）把 LCT 以下的直线外推到代谢率为零，并在体温为37 °C 的条件下评论结果。（c）30 °C 以上发生了什么？为什么？
::: solution
（a）BMR $\approx 4.5$ W（平台段）。平台以下温度每降10 °C 速率上升3.0 W，故 $C = 0.30$ W K⁻¹。直线 $H = 14.0 - 0.30(T_\mathrm{a} + 10)$ 在 $T_\mathrm{a} = -10 + 9.5/0.30 = 21.7$ °C 处达到4.5 W，故 LCT $\approx 22$ °C。（b）直线在 $T_\mathrm{a} = -10 + 14.0/0.30 = 36.7$ °C 处归零，接近37 °C 的体温，这正是 Scholander–Irving 模型在 LCT 以下热导恒定时所预言的。（c）在上临界温度（约30 °C）以上代谢率上升，因为动物必须通过喘气或出汗主动散热而做功，也因为体温本身升高会加快代谢（$Q_{10}$ 效应）。
:::
:::

::: exercise 同向与逆流 {level=2}
两股热容流率相等的血流，一股以40 °C、另一股以0 °C 进入，沿一根长管交换热量。（a）若它们同向流动（同向）且管子极长，出口温度是多少？（b）在理想、极长的逆流交换器中出口温度是多少？（c）为什么逆流排列见于四肢与鳃？
::: solution
（a）同向交换器中两股流体趋于共同温度，这里是 $(40 + 0)/2 = 20$ °C，此后再无热流：两股各以20 °C 离开，只转移了可能热量的一半。（b）在理想的逆流交换器中，温差沿全长维持，暖股几乎以0 °C 离开，冷股几乎以40 °C 离开：几乎全部热被转移。（c）逆流允许热（在肢端，为了省热）或气体（在鱼鳃中，血与水流向相反，[[animal-physiology/gas-exchange]]）近乎完全的交换，这是同向排列做不到的。
:::
:::

::: exercise 蜂鸟的蛰伏 {level=2}
一只4 g 的蜂鸟夜间栖息在15 °C 处，维持正常体温需用0.10 W。蛰伏时代谢率降到0.010 W；进出蛰伏总共额外耗费0.20 kJ。（示意数值。）（a）10小时的夜里蛰伏8小时能省下多少能量？（b）若花蜜每克糖提供17 kJ，这省下多少糖？（c）食物储备充裕的鸟为什么会选择不进入蛰伏？
::: solution
（a）全程正常体温10小时：$0.10 \times 36\,000 = 3.6$ kJ。蛰伏方案：2小时正常体温（$0.10 \times 7200 = 0.72$ kJ）加8小时蛰伏（$0.010 \times 28\,800 = 0.29$ kJ）加进出蛰伏0.20 kJ $= 1.21$ kJ。节省 $= 3.6 - 1.21 = 2.4$ kJ，夜间花费的三分之二。（b）$2.4/17 = 0.14$ g 糖，作为储备占一只4 g 之鸟体质量的相当比例。（c）蛰伏的代价不只是能量：蛰伏的动物无法躲避捕食者，受惊扰后复温可能缓慢，还可能因免疫功能下降或睡眠不足而受害；储备充足的蜂鸟常保持正常体温，这表明蛰伏只在能量收益超过这些风险时才被使用。

::: exercise 一条暖鱼 {level=3}
一条蓝鳍金枪鱼的红色肌肉在15 °C 的水中保持30 °C。（a）考虑到鳃，解释为什么普通鱼不能比水暖很多。（b）金枪鱼的血管排列如何解决了这一问题？（c）取 $Q_{10}$ 为2.5，温暖肌肉的收缩与舒张速率可比水温下的肌肉快多少倍？（d）说出一个生态优势与一项代价。
::: solution
（a）血液每个循环都要通过鳃一次，在那里以巨大的面积与水紧密接触进行气体交换；鳃把血液平衡到水温，于是组织中产生的任何热都会被带到鳃而散失。（b）在金枪鱼中，为红色肌肉供血的动脉自体表向内走行，与离开肌肉的静脉并行，构成逆流交换器（*rete mirabile*）。来自鳃的冰冷动脉血被离开温暖肌肉的静脉血加热；热留在肌肉中而不达鳃，而扩散较慢的 O₂ 与 CO₂ 在这种几何结构中仍能通过。（c）$2.5^{(30-15)/10} = 2.5^{1.5} = 4.0$。（d）优势：更快、更强的游泳肌；温暖的眼与脑有助于探测猎物；能够游入更冷的水域、潜入冷的水层并保持活动。代价：产热所需的能量（金枪鱼的代谢率在鱼类中很高）、需要更多的食物，以及在温水中持续高强度活动时过热的风险。
:::

::: exercise 冬眠者为何觉醒 {level=3}
从冬眠中的觉醒消耗冬眠者冬季能量预算的大部分。（a）利用把一只300 g 地松鼠从5 °C 复温到37 °C 所需的能量（比热3.5 kJ kg⁻¹ K⁻¹），说明为什么每次觉醒都很昂贵（忽略复温途中散失的热）。（b）为觉醒仍被保留提出两条假说，并为每条设计一个可检验它的实验。
::: solution
（a）所需热 $= 0.300 \times 3.5 \times 32 = 33.6$ kJ，还要加上复温的几小时里在冷洞中散失的、多得多的热，以及在37 °C 停留一天所散的热。蛰伏一天，以约1.5 W 的 BMR 的约2 %，只需 $0.03 \times 86\,400 \approx 2.6$ kJ，因此一次觉醒（复温加一天正常体温，约40–100 kJ）抵得上几周蛰伏。（b）示例：（1）**免疫功能**：蛰伏抑制免疫应答，周期性回温让免疫系统清除感染；可通过阻止或增加动物的觉醒、比较其病原负荷与免疫活动，或感染动物并测量其对觉醒频率的影响来检验。（2）**睡眠债**：冬眠者表现出睡眠不足的迹象，觉醒时深睡；可通过记录觉醒期间的脑活动、并阻止觉醒期间的睡眠，观察下一次蛰伏期是否缩短来检验。（3）**代谢废物或耗竭**：某种代谢物在低温下积累或耗尽；可通过在整个蛰伏期中测定候选代谢物并加以操纵来检验。这些假说并不互斥，问题仍悬而未决。
:::
