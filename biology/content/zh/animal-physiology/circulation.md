1628年，国王的御医 William Harvey 出版了一本小书 *Exercitatio anatomica de motu cordis et sanguinis in animalibus*，里面有一段算术。如果人心左心室即使只容纳二盎司血液，而每次搏动只排出其中一小部分，那么半小时内一千次搏动，心脏泵出的血液就比全身所含的还多——远多于食物所能制造并在组织中被消耗的量。Harvey 由此断定：血液必定在循环往复。他用以支持这一论证的，是对蛇、鱼、蛙、犬与许多其他动物的实验，以及静脉中的瓣膜只让血液流向心脏这一观察。

[[animal-physiology/gas-exchange#prop-sphere]] 表明，仅靠扩散只能供应距源头约一毫米以内的组织。循环系统以**总量流动**解决这个难题：泵推动流体穿过血管，把 O₂、养分、CO₂、废物、激素与热输运到扩散永远无法企及的距离，使扩散只需负责最后的几个微米。本章比较动物建造循环系统的诸方式，并发展支配它们全部的压力与流动的物理学——Fick 原理、Poiseuille 定律、Laplace 定律与 Starling 原理。

## 开放式与闭管式循环

::: definition 开管式与闭管式循环系统 {#def-open-closed}
在**开放式**循环系统中，心脏把**血淋巴**泵入开口于组织间空隙（**血腔**，或称血窦）的血管；血淋巴直接浸润细胞，经开口（心孔）或开放通道回到心脏。在**闭管式**循环系统中，**血液**保持在血管的连续网络——动脉、毛细血管与静脉——之内，与组织的交换发生于毛细血管壁；组织间液与血浆是分开的。
:::

开放式系统见于节肢动物与多数软体动物；闭管式系统在环节动物、头足纲软体动物与脊椎动物。开放式系统以较低的压力与较低的流量工作，其液体占身体的很大份额——甲壳类与昆虫常达体容积的20–40 %，而哺乳动物血液约7 %。它并非简单地是一种原始或低劣的安排。在昆虫中，循环携带的 O₂ 很少，因为气管直接把它送到组织（[[animal-physiology/gas-exchange]]），所以服务于养分、激素与免疫细胞的低压慢循环已经足够。昆虫的心脏是一根背血管，把血淋巴向前泵向头部，并有位于翅基、足基与触角基部的辅助搏动器帮助。血淋巴压还做机械功：蜘蛛通过升高血淋巴压以液压伸腿，因为某些腿节没有伸肌；许多昆虫蜕皮后吞入空气升高体压，把新表皮撑开。

头足类则是快速活跃的捕食者。章鱼或乌贼有闭管式循环和三个心脏——一个体循环心脏与两个把血液泵过鳃的鳃心——其血液以血蓝蛋白携带 O₂。闭管式循环、高压、以及为鳃与身体分设的泵，在头足类与脊椎动物中各自独立地演化了出来。

## 脊椎动物的心脏与环路

脊椎动物的心脏是具腔室与瓣膜的肌肉泵，瓣膜防止逆流。其构型反映各类动物如何呼吸。

- **鱼类**有**单循环**：心脏由四个串联的腔室（静脉窦、心房、心室，硬骨鱼还有弹性动脉圆锥）组成，把脱氧血液泵向鳃，之后血液不返回心脏而继续流向身体。鳃增加了阻力，所以鱼类的体循环血压很低，通常只有几 kPa。
- **两栖类**的心脏有两心房一心室。来自肺的血液与来自身体的脱氧血液分别进入心室，得益于海绵状心室壁与动脉圆锥中的螺旋瓣，它们在奔向肺与皮肤、以及奔向身体时被部分隔开。
- **非鳄类爬行类**（蜥蜴、蛇、龟）的心室被肌小梁部分分隔。它们的心室能有效地分开肺循环与体循环血流，但也能把血液**分流**绕过肺（右-左分流），例如在憋气或潜水时。
- **鳄类**具有完全分隔的四腔心，但其左主动脉起自*右*心室，血液可经它被改道离开肺进入体循环，由肺动脉出口的瓣膜控制；两条主动脉之间的一个小通道（Panizza 窝）联系着两个环路。
- **鸟类与哺乳类**具有四腔心与完全分隔的**双循环**：右心室把血液泵过肺（肺循环），左心室泵过身体（体循环）。这一构型在两个类群中由不同的爬行类祖先各自独立地演化出来。

双循环让两个环路以不同压力运行。体循环可以高压工作（哺乳动物的平均动脉压约12–13 kPa，鸟类更高），这是把血液迅速推过一张又长又分枝的细密血管网所必需的；而肺循环以低压运行（约2 kPa），这可以防止液体从薄壁肺毛细血管漏入气腔。鳄类、龟类以及其他“中间型”心脏并非达不到哺乳类构型的失败尝试：它们分流血液的能力被用于潜水、体温调节与消化，而它们为什么分流仍是活跃的研究问题。

## 心脏泵出多少血液？

一个心室每分钟泵出的血液体积是**心输出量** $\dot Q$，为心率 $f_\mathrm{H}$ 与**每搏输出量** $V_\mathrm{S}$ 之积：

$$
\dot Q = f_\mathrm{H}\,V_\mathrm{S}.
$$ {#eq-output}

直接测量它很困难，但 Adolf Fick 在1870年指出，它可以由动物摄取的 O₂ 算出。

::: proposition Fick 原理 {#prop-fick-principle}
稳态下，动物在呼吸器官摄取 O₂ 的速率 $\dot V_{\mathrm{O_2}}$ 等于血液把 O₂ 带走的速率：

$$
\dot V_{\mathrm{O_2}} = \dot Q\,(C_\mathrm{a} - C_\mathrm{v}),
\qquad\text{so}\qquad
\dot Q = \frac{\dot V_{\mathrm{O_2}}}{C_\mathrm{a} - C_\mathrm{v}},
$$ {#eq-fick-principle}

其中 $C_\mathrm{a}$ 与 $C_\mathrm{v}$ 是动脉血与混合静脉血的 O₂ 含量（mL O₂ 每升血液），$C_\mathrm{a} - C_\mathrm{v}$ 是**动静脉差**。同样的平衡适用于任何器官与任何被它摄取或释放的物质。假设：稳态（血液或组织的 O₂ 贮量不变）、全部 O₂ 摄取都经血液过手（对经皮肤直接摄入组织量大的动物不成立）、以及混合充分的静脉血。
:::

::: example 由 Fick 原理求心输出量 {#ex-fick}
（a）一个安静的人消耗250 mL O₂ min⁻¹；动脉血含200 mL O₂ L⁻¹，混合静脉血含150 mL O₂ L⁻¹。计算心输出量；若心率为70 min⁻¹，再算每搏输出量。（b）一条1 kg 的鳟鱼消耗67 mL O₂ h⁻¹；其动脉血含90 mL O₂ L⁻¹，静脉血含50 mL O₂ L⁻¹。以 mL min⁻¹ 计算其心输出量。
::: solution
（a）$\dot Q = 250/(200 - 150) = 5.0$ L min⁻¹。每搏输出量 $= 5000/70 = 71$ mL。运动时 $\dot V_{\mathrm{O_2}}$ 可升十倍；心输出量约升四五倍，动静脉差约升三倍，因为工作的肌肉提取更多 O₂。

（b）$\dot V_{\mathrm{O_2}} = 67/60 = 1.12$ mL min⁻¹；$\dot Q = 1.12/(0.090 - 0.050) = 28$ mL min⁻¹ 每千克——约为同等大小安静哺乳动物质量比心输出量（大致80–100 mL min⁻¹ kg⁻¹）的三分之一，与鱼类低得多的代谢率相称。
:::
:::

### 心脏的标度关系

在各哺乳类之间，心脏质量约与体质量成正比，约为其0.5–0.6 %，每搏输出量亦然。然而心率随约 $M^{-1/4}$ 下降（[[animal-physiology/energy-metabolism#prop-kleiber-consequences]]），从安静鼩鼱或小鼠的每分钟600次以上到大象的约30次。心输出量作为每搏输出量与心率的乘积，因此约按 $M^{1}\times M^{-1/4} = M^{3/4}$ 标度，与代谢率一致。小鼠与大象的心脏相对大小相同，血液的 O₂ 容量相似；小鼠靠更快的心跳来匹配其更高的质量比需求。

## 压力、流量与阻力

血液从高压流向低压。对一条血管或整个环路，流量 $\dot Q$ 与驱动它的压力差 $\Delta P$ 成正比：

$$
\Delta P = \dot Q\,R,
$$ {#eq-darcy}

这是欧姆定律的血液动力学类比，定义了**阻力** $R$。对安静成年人的体循环，$\Delta P \approx 12$ kPa 而 $\dot Q \approx 5$ L min⁻¹，所以总外周阻力约2.4 kPa min L⁻¹。串联的阻力相加，并联的阻力像电阻一样合并（$1/R = \sum 1/R_i$）。循环系统主要由一组并联环路构成，每个器官一条，所以通向每个器官的流量都可以通过改变其自身阻力而独立调节。

::: proposition Hagen–Poiseuille 定律 {#prop-poiseuille}
黏度 $\eta$ 的牛顿流体经半径 $r$、长度 $L$ 的刚性圆管作稳态层流时，体积流量为

$$
\dot Q = \frac{\pi r^4}{8\eta L}\,\Delta P,
\qquad\text{so}\qquad
R = \frac{8\eta L}{\pi r^4}.
$$ {#eq-poiseuille}

假设：层流（非湍流）、稳态（非搏动性）、刚性管道、黏度恒定的流体、以及长度远大于半径的管道。血液违反其中若干条——它是细胞的悬浮液，在窄于约0.3 mm 的管道中表观黏度下降（**Fåhræus–Lindqvist 效应**）、大动脉中的血流是搏动性的、血管是弹性的——但阻力对半径的强依赖在整个循环系统中大致成立。
:::

::: proof {collapsed}
在稳态层流中，考察一根与管道同轴、半径 $s$ 的流体圆柱。两端面上的压力 $\pi s^2\Delta P$，与其曲面上黏性切应力 $-\eta\,\deriv{u}{s}\cdot 2\pi s L$ 相平衡，其中 $u(s)$ 为速度。于是 $\deriv{u}{s} = -s\Delta P/(2\eta L)$，并取壁面处 $u(r) = 0$（无滑移），得 $u(s) = \frac{\Delta P}{4\eta L}(r^2 - s^2)$，一个抛物线形剖面。流量为 $\dot Q = \int_0^r u(s)\,2\pi s\,\dd s = \frac{\pi\Delta P}{2\eta L}\left[\frac{r^2 s^2}{2} - \frac{s^4}{4}\right]_0^r = \frac{\pi r^4\Delta P}{8\eta L}$。
:::

半径的四次方是循环调节的钥匙。血管半径减半，其阻力增至十六倍；缩小10 %即增大52 %。**微动脉**是管壁富含平滑肌的小动脉，占了体循环阻力的绝大部分，并通过收缩与舒张同时决定动脉血压和血液在各器官之间的分配。

::: example 重新分配血流 {#ex-redistribution}
安静时，一只哺乳动物的骨骼肌接受5.0 L min⁻¹ 心输出量中的20 %。运动时，工作肌肉的微动脉舒张，使其半径增加70 %，而平均动脉压保持不变，肌肉环路的阻力由其微动脉主导。（a）肌肉血流量增大多少倍？（b）心脏能在其他地方毫无变化的情况下供应这一流量吗？
::: solution
（a）恒压下流量 $\propto r^4$：$1.7^4 = 8.4$。肌肉血流将从1.0升至约8.4 L min⁻¹。

（b）若其他器官保持其4.0 L min⁻¹，总输出量就得升到约12.4 L min⁻¹；这在训练有素的哺乳动物的能力范围之内，而且心输出量在运动中确实上升。但除非输出量上升得足够快，动脉压将会下降，而压力感受器反射会通过收缩肠道、肾与非活动肌肉的微动脉作出响应，把它们的一部分血流转给工作肌肉。真实的运动两者并用：更多的输出量，加上重新分配。
:::
:::

## Laplace 定律与血管的壁

血管或心腔内的压力拉伸其壁。壁必须承受的张力取决于它的大小。

::: proposition Laplace 定律 {#prop-laplace}
对半径 $r$、跨壁压差 $P$ 的薄壁圆柱，壁张力（单位壁长上的力）为

$$
T = P\,r,
$$ {#eq-laplace}

而对薄壁球，$T = Pr/2$。若壁厚为 $w$，壁材料中的应力为 $\sigma = T/w = Pr/w$。假设：薄壁（$w \ll r$）、静态平衡、均匀压力。
:::

::: proof
沿过轴的平面把长为 $L$ 的圆柱切开。压力以 $P \times 2rL$ 的力（压力乘以投影面积）把两半推开。管壁沿两条切边各以张力 $T$ 抵抗，即 $2TL$ 的力。平衡给出 $2TL = 2PrL$，故 $T = Pr$。对球体，沿大圆切开：$P\pi r^2 = T \cdot 2\pi r$，故 $T = Pr/2$。
:::

::: example 主动脉与毛细血管 {#ex-laplace}
比较（a）半径3.0 µm、压力3.0 kPa 的毛细血管与（b）半径12 mm、压力13 kPa 的哺乳类主动脉的壁张力。（c）为什么毛细血管壁可以只是一层细胞，而主动脉壁厚约2 mm，有弹性纤维与平滑肌的层次？
::: solution
（a）$T = 3.0\times10^3 \times 3.0\times10^{-6} = 9.0\times10^{-3}$ N m⁻¹。

（b）$T = 13\times10^3 \times 0.012 = 156$ N m⁻¹。

（c）主动脉的壁张力约是毛细血管的17,000倍，而压力只有四倍，因为张力随半径增长。毛细血管极小的半径让其壁——一个内皮细胞加一层基膜——既能承受压力，又薄到足以快速扩散。主动脉需要富有弹性蛋白与胶原的厚壁来承担载荷。同一定律也解释了为什么扩张增大的心脏必须产生更大的壁张力才能达到同样压力，这增加了它的能量开销。
:::
:::

### 重力与长颈鹿

在直立的动物身上，重力给参考水平以下深度 $h$ 处的血液加上静水压 $\rho g h$。对血液（密度约1050 kg m⁻³），这约相当于每米10 kPa。长颈鹿的头部比心脏高约2 m，所以其心脏必须产生约 $1050 \times 9.81 \times 2.0 = 21$ kPa 才能把血液举到头部，此外还要有推动血流过脑的压力。长颈鹿心脏水平的平均动脉压约为其他哺乳动物的两倍，这并非靠异常大的心脏，而是靠半径小、壁厚的心室——按 Laplace 定律，它能产生高压而壁应力不至于过大。它们的腿面临相反的问题：高压会把液体逼出毛细血管；小腿周围紧致的皮肤与筋膜、以及厚壁动脉防止了肿胀。蛇类表现平行的适应：攀树的种类心脏更靠近头部、血压高于水栖种类，而后者的重力被周围的水抵消（Harvey Lillywhite 与同事）。

## 毛细血管中的交换

血液与组织之间的交换发生在毛细血管壁上。小溶质（O₂、CO₂、葡萄糖、离子）主要经扩散通过；水以滤过方式移动，由静水压与渗透压的平衡驱动。

::: proposition Starling 原理的液体交换 {#prop-starling}
毛细血管滤出液体的净速率 $J_\mathrm{v}$ 为

$$
J_\mathrm{v} = K_\mathrm{f}\left[(P_\mathrm{c} - P_\mathrm{i}) - \sigma(\pi_\mathrm{c} - \pi_\mathrm{i})\right],
$$ {#eq-starling}

其中 $P_\mathrm{c}$ 与 $P_\mathrm{i}$ 是毛细血管与组织间液的静水压，$\pi_\mathrm{c}$ 与 $\pi_\mathrm{i}$ 是不能自由穿壁蛋白质所施的**胶体渗透**（膨胀）压，$\sigma$ 是壁对这些蛋白的反射系数（壁对其不透过的蛋白为1），$K_\mathrm{f}$ 为滤过系数（通透性乘以面积）。$J_\mathrm{v}$ 为正表示液体滤出毛细血管。（Ernest Starling，1896。）
:::

经典教科书图景是：毛细血管静水压沿毛细血管下降，从微动脉端的约4.5 kPa 到微静脉端的2 kPa，而血浆胶体渗透压——哺乳类约3.3 kPa——保持恒定，于是液体在微动脉端滤出、在微静脉端重吸收。1990年代以来的测量修正了这一图景。起作用的胶体渗透压是紧贴**内皮糖萼**——毛细血管内表面的糖蛋白层——之下的那一个，它可以远低于大量组织间液的胶体渗透压；而且在多数组织，稳态下几乎没有持续的重吸收——毛细血管沿其大部分长度都在滤过，滤出的液体经**淋巴系统**回到血液（J. R. Levick 与 C. C. Michel，2010）。重吸收短暂地发生在毛细血管压下降之后，如失血之后，并持续发生在特化的毛细血管，如由吸收性上皮供液的肾与肠的毛细血管。

::: example 沿毛细血管的滤过 {#ex-starling}
用经典数值：微动脉端 $P_\mathrm{c} = 4.7$ kPa、微静脉端2.0 kPa，$P_\mathrm{i} = 0$，$\pi_\mathrm{c} = 3.3$ kPa，$\pi_\mathrm{i} = 0.5$ kPa，$\sigma = 1$，计算两端的净驱动压。若血浆蛋白浓度下降三分之一，平衡会怎样？
::: solution
微动脉端：$(4.7 - 0) - (3.3 - 0.5) = 4.7 - 2.8 = +1.9$ kPa，滤过。微静脉端：$(2.0 - 0) - 2.8 = -0.8$ kPa，在经典图景中为吸收。若血浆蛋白下降三分之一，$\pi_\mathrm{c}$ 将降到约2.2 kPa，胶体渗透项降到1.7 kPa，驱动压将在微动脉端变成 $+3.0$ kPa、微静脉端 $+0.3$ kPa：处处滤过，且速率更大。若淋巴流跟不上，液体便在组织中积聚（水肿）——蛋白质缺乏引起肿胀的原因。（在修正后的图景中，这一改变仍使滤过增加，因为滤过取决于糖萼两侧的胶体渗透压差。）
:::
:::

## 作为泵的心脏

脊椎动物的心脏是**肌原性**的：心跳起源于心肌本身，起源于其膜电位自发去极化直至触发动作电位的起搏细胞，动作电位传遍整个心脏。神经改变心率，但不启动每一次搏动。软体动物的心脏也是肌原性的。而在许多甲壳类以及鲎 *Limulus* 中，心脏是**神经原性**的：每次搏动由心脏上的**心神经节**——一个曾在研究神经回路如何产生节律方面成为模型的小神经元网络——发放的脉冲群触发。

心脏使其输出量适应于回流到它的血液。如果回流的血液增多，心室充盈更多，其肌纤维被拉长，下一次收缩就更有力、射出更多血液——**Frank–Starling 机制**，以 Otto Frank（他在1890年代研究蛙心）与 Ernest Starling（狗心肺制备，1914–18）命名。其基础是肌肉的长度-张力关系（[[cell-biology/cytoskeleton#exr-length-tension]]，[[animal-physiology/muscle-movement]]），加上收缩蛋白对 Ca²⁺ 的敏感性随长度的增加。鱼心比哺乳类心更依赖这一机制：鳟鱼游得更用力时，其心输出量主要通过每搏输出量上升，而在哺乳类则主要通过心率上升。

::: warning “动脉携含氧血，静脉携缺氧血”
动脉定义为把血液*带离*心脏的血管，静脉定义为把血液*带向*心脏的血管，无论其 O₂ 含量如何。哺乳类的肺动脉把脱氧血液送往肺，肺静脉把含氧血液送回。在鱼中，腹主动脉与入鳃动脉把脱氧血液从心脏送往鳃，而鱼心内只有脱氧血液。一个相关的错误是以为三腔心必定白白混合血液：爬行类与两栖类的心脏在该分开时分开得很好，而它们分流的能力是受生理调节的。
:::

## 循环的调节

动脉压由负反馈调节（[[animal-physiology/homeostasis]]）。大动脉壁中的牵张感受器（**压力感受器**）——在哺乳类为颈动脉窦与主动脉弓——向脑干传示压力，脑干经自主神经调节心率、每搏输出量与微动脉阻力。压力下降使心率加快、微动脉收缩；压力升高则相反。更长的时间尺度上，激素与肾调节血液容量（[[animal-physiology/water-salt-balance]]）。

局部调节使血流适应需要。工作的组织释放舒血管物质——腺苷、K⁺、H⁺、CO₂，以及由内皮释放的一氧化氮——使它们自己微动脉的平滑肌松弛，于是血流追随代谢活动。许多器官还能**自身调节**，通过在压力升高时收缩，在一段动脉压范围内保持其流量几乎恒定。

循环调节最引人注目的例子是**潜水反应**。Per Scholander（1940）与 Laurence Irving 发现，海豹潜水时心率骤降（心动过缓），通往多数器官——肠、肾、皮肤与肌肉——的动脉收缩，于是心输出量下降，血液的 O₂ 被留给脑与心脏（[[animal-physiology/gas-exchange#ex-dive]]）。这一响应是分级的：短而例行的潜水中它较温和；长潜水或被迫潜水中它极端，海豹心率可降到每分钟几次。潜水鸟类、龟类甚至人类都表现出它的版本。

::: quiz
一个半径3 cm 的心室必须产生16 kPa 的峰值压力。另一个心室半径1.5 cm、壁厚相同，产生同样压力。较小心室的壁应力与较大的相比如何？
- [ ] 相同，因为压力相同。
- [x] 是它的一半。
- [ ] 是它的两倍。
- [ ] 是它的四分之一，因为应力依赖半径的平方。
::: solution
由 Laplace 定律（[[#prop-laplace]]），壁应力 $\sigma = Pr/w$（对球为 $Pr/2w$）。压力与壁厚相同时，半径减半，应力减半。小而壁厚的心腔是产生高压的最好办法，正如长颈鹿的左心室。
:::
:::

::: application 比较心脏病学
对心脏的比较研究以出人意料的方式助力医学。斑马鱼与蝾螈的心脏在损伤后再生，用新的心肌细胞替换失去的肌肉，而成年哺乳类心脏形成瘢痕组织；斑马鱼的心脏再生（K. D. Poss 与同事，2002）正被研究，期望能借此激发人类的修复。缅甸蟒在餐后迅速增大其心脏（[[animal-physiology/feeding-digestion]]），这是一种可逆的健康生长，正被研究与病态心脏的有害增大相对照。临床心血管生理学见[医学图谱：心血管系统](/learn/medicine/course.php?c=cardiovascular)。
:::

::: history
二世纪的 Galen 描述了心脏与血管，但相信血液在肝中不断生成并在组织中被消耗，还相信血液经心脏间隔上看不见的孔透过。十三世纪的 Ibn al-Nafis 与十六世纪的 Realdo Colombo 描述了肺循环。William Harvey 于1628年证明了血液的循环，Marcello Malpighi 于1661年在蛙肺中看到了毛细血管，闭合了回路。Stephen Hales 于1733年第一次测量了血压，在一匹马身上用一根接在其颈动脉上、近3 m 高的玻璃管。Jean Poiseuille 关于玻璃毛细管中流动的实验（1840年代）得出了与他及 Gotthilf Hagen 同名的定律。Adolf Fick 于1870年提出其原理，Ernest Starling 于1896年提出毛细血管力的平衡、并于1918年提出心脏定律，而 August Krogh 对肌肉中毛细血管调节的研究为他赢得1920年的诺贝尔奖。Scholander 与 Irving 在1930与1940年代描述了潜水反应。
:::

## 由此引向何处

循环系统输送鳃与肺摄取的 O₂（[[animal-physiology/gas-exchange]]），并运输 [[animal-physiology/endocrine-control]] 的激素。其血浆被肾滤过，肾控制其容量与成分（[[animal-physiology/water-salt-balance]]），而心脏与血管的肌肉在 [[animal-physiology/muscle-movement]] 中考察。

::: summary
- 总量流动把物质运过扩散无法企及的距离；开放式系统（节肢动物、多数软体动物）以低压让血淋巴浸润组织，闭管式系统（环节动物、头足类、脊椎动物）把血液保持在血管内。
- 鱼类是单循环；两栖类与多数爬行类能分开或分流血流；鸟类与哺乳类各自独立演化出体循环高压、肺循环低压的双循环。
- 心输出量 $\dot Q = f_\mathrm{H}V_\mathrm{S}$ 可由 Fick 原理 $\dot Q = \dot V_{\mathrm{O_2}}/(C_\mathrm{a} - C_\mathrm{v})$ 算出（[[#prop-fick-principle]]）；它经心率而约按 $M^{3/4}$ 标度。
- $\Delta P = \dot QR$；由 Hagen–Poiseuille，$R = 8\eta L/\pi r^4$（[[#prop-poiseuille]]），所以微动脉控制阻力与流量分配。
- 壁张力 $T = Pr$（Laplace 定律，[[#prop-laplace]]）：毛细血管能薄因为它们细；长颈鹿用小而壁厚的心室产生高压。
- Starling 原理平衡毛细血管两侧的静水压与胶体渗透压（[[#prop-starling]]）；在多数组织，滤出的液体经淋巴而非微静脉端重吸收回到血液。
- 脊椎动物心脏是肌原性的，一些甲壳类的心脏是神经原性的；Frank–Starling 机制使输出量匹配静脉回流。
- 压力感受器反射调节血压；局部舒血管物质使血流匹配需要；潜水动物表现心动过缓与外周血管收缩。
:::

一只狗的心脏每分钟搏动150次，每搏输出量25 mL。其心输出量以 L min⁻¹ 计是多少？
::: solution
$150 \times 25 = 3750$ mL min⁻¹ $= 3.75$ L min⁻¹。

::: exercise Fick 原理 {level=1 check="100"}
一只动物在运动中消耗2.0 L O₂ min⁻¹，心输出量20 L min⁻¹。若动脉血含200 mL O₂ L⁻¹，混合静脉血的 O₂ 含量以 mL L⁻¹ 计是多少？
::: solution
$C_\mathrm{a} - C_\mathrm{v} = 2000/20 = 100$ mL L⁻¹，故 $C_\mathrm{v} = 200 - 100 = 100$ mL L⁻¹。

::: exercise 半径与阻力 {level=1 check="16"}
血管半径减半而其余条件不变，其阻力增大多少倍？
::: solution
$R \propto r^{-4}$：$2^4 = 16$。

::: exercise 静水压 {level=2 check="14"}
一人直立。取血液密度1050 kg m⁻³、$g = 9.81$ m s⁻²，足部静脉（比心脏低1.4 m）的静水压比心脏水平高多少 kPa（两位有效数字）？解释为什么足部不会积满液体。
::: solution
$\rho g h = 1050 \times 9.81 \times 1.4 = 14\,400$ Pa $\approx 14$ kPa。这使足部毛细血管压远高于血浆胶体渗透压，于是滤过增加。水肿受到如下限制：腿部肌肉的收缩挤压静脉，与静脉瓣一起把血液向上泵回（肌肉泵）；淋巴流增加；腿部微动脉收缩，降低毛细血管压；以及组织液积聚使组织间压上升。
:::
:::

::: exercise 并联环路 {level=2}
两个器官以并联方式自主动脉供血。器官 A 的阻力为6.0 kPa min L⁻¹，器官 B 为3.0 kPa min L⁻¹。平均动脉压12 kPa，静脉压为0。（a）求各自流量与总流量。（b）器官 B 的微动脉收缩，使其半径下降16 %。设动脉压被反射维持恒定，求 B 的新阻力与新流量。（c）如果心脏输出量停留在原来的总量上，动脉压会怎样？
::: solution
（a）$\dot Q_A = 12/6.0 = 2.0$ L min⁻¹；$\dot Q_B = 12/3.0 = 4.0$ L min⁻¹；总计6.0 L min⁻¹。（b）$R_B$ 增大 $1/0.84^4 = 2.0$ 倍，到6.0 kPa min L⁻¹；$\dot Q_B = 2.0$ L min⁻¹，总计4.0 L min⁻¹。（c）总阻力将是 $1/(1/6 + 1/6) = 3.0$ kPa min L⁻¹（此前为 $1/(1/6 + 1/3) = 2.0$），所以在6.0 L min⁻¹ 下动脉压将升到18 kPa；随后压力感受器反射会降低心率并舒张其他血管。
:::
:::

::: exercise 鳄的分流 {level=2}
鳄潜水时，来自右心室的血液越来越多地被改道注入左主动脉而非肺动脉。（a）用本章描述的解剖结构，解释这如何绕过肺。（b）给出两条关于这种右-左分流在潜水或消化中功能的假说。（c）你可以怎样检验其中一条？
::: solution
（a）鳄类的左主动脉起自右心室。当肺动脉流出的阻力升高时（肺动脉圆锥内的瓣膜部分关闭，形成“犬齿瓣”），右心室压力升高，直到超过左主动脉中的压力，脱氧血液便经左主动脉流向身体，绕过肺。（b）假说：（1）憋气时肺不再通气，把血液泵过肺是浪费能量，分流可节省心脏做功，并使肺的 O₂ 贮备用得更慢；（2）分流把富 CO₂ 的酸性血液送往胃（左主动脉供应肠道），可能有助于消化时的胃酸分泌（C. G. Farmer 与同事2008年提出）；（3）它可能帮助体温调节，或减少血浆滤入肺。（c）对（2），可手术阻断某些动物的分流，与假手术对照比较胃酸分泌与消化速率；Farmer 的团队对短吻鳄做过这类实验。结果仍有争论，分流的功能仍是悬而未决的问题。
:::

::: exercise Murray 定律 {level=3}
Cecil Murray（1926）问：血管的半径应当如何选取，才能使一条血管的总代价最小：驱动血流通过它所需的功率 $\dot Q^2 R$，加上维持其血液体积的代谢代价 $b\,\pi r^2 L$，其中 $b$ 为常数。（a）用 Hagen–Poiseuille 阻力证明：代价最小时 $\dot Q \propto r^3$。（b）推出：在半径 $r_0$ 的母血管分为半径 $r_1, r_2, \ldots$ 的子血管的分岔处，最优半径满足 $r_0^3 = r_1^3 + r_2^3 + \cdots$。（c）对对称二分歧，Murray 定律预言每个子血管的半径是多少？
::: solution
（a）代价 $W = \dot Q^2 \cdot \dfrac{8\eta L}{\pi r^4} + b\pi r^2 L$。令 $\deriv{W}{r} = 0$：$-4\dot Q^2\dfrac{8\eta L}{\pi r^5} + 2b\pi r L = 0$，故 $\dot Q^2 = \dfrac{b\pi^2 r^6}{16\eta}$，且 $\dot Q = \dfrac{\pi}{4}\sqrt{\dfrac{b}{\eta}}\,r^3 \propto r^3$。（b）分岔处流量守恒：$\dot Q_0 = \dot Q_1 + \dot Q_2 + \cdots$。若每条血管都最优，则各 $\dot Q_i = c\,r_i^3$ 且常数 $c$ 相同，所以 $r_0^3 = r_1^3 + r_2^3 + \cdots$。（c）$r_0^3 = 2r_1^3$，故 $r_1 = 2^{-1/3}r_0 = 0.79\,r_0$。对许多血管床与植物木质部的测量大致遵循这一定则，在小血管中尤然；血流搏动性的大动脉则偏离它。
:::

::: exercise 长颈鹿的心脏 {level=3}
长颈鹿的大脑比心脏高2.0 m，脑底部的动脉压约13 kPa。（a）估计心脏水平所需的平均动脉压。（b）若其左心室的半径-壁厚比与人相同（人的16 kPa 峰值压力产生给定的壁应力），在40 kPa 峰值压力下，长颈鹿的壁应力将超过人的多少倍？（c）事实上长颈鹿的左心室壁相对较厚，但相对体质量并不大。这对长颈鹿如何实现高压说明了什么？代价是什么？
::: solution
（a）$13 + \rho g h = 13 + 1050 \times 9.81 \times 2.0/1000 = 13 + 21 = 34$ kPa，约为其他大型哺乳动物的两倍（实测值在此量级）。（b）壁应力 $\sigma \propto Pr/w$；$r/w$ 相同时，应力随压力标度：$40/16 = 2.5$ 倍于人。（c）按 Laplace 定律，长颈鹿以相对心腔半径较厚的壁来降低壁应力；半径较小也意味着单位心脏质量的每搏输出量较小，所以长颈鹿以心率补偿，其每千克心输出量与其他哺乳动物相近。代价是心脏必须为泵出的每单位血液做更多的功（功 = 压力 × 体积），所以长颈鹿代谢中用于泵血的部分，比同等体型、普通血压的哺乳动物更大。
:::

::: exercise 解读一份心率记录 {level=2}
一只潜水鸟类的心率记录仪显示：水面时250次 min⁻¹；入水数秒内80次 min⁻¹；潜水的最后几秒、出水之前180次 min⁻¹；出水后一分钟300次 min⁻¹，然后回到250。解释各个阶段。
::: solution
入水触发潜水反应：心动过缓与外周血管收缩把 O₂ 贮备留给脑与心脏。出水前不久心率上升，出于预期——一种前馈响应（[[animal-physiology/homeostasis]]），也许是为了在鸟一呼吸就恢复血流并加快气体交换。出水时，高于静息水平的心动过速加速 O₂ 贮备的重新装载，以及 CO₂ 与来自曾处于血管收缩状态组织的乳酸的清除，此后心率恢复正常。
:::
