1849年，在 Göttingen 的 Arnold Berthold 阉割了幼年的公鸡。不出所料，它们长大时没有正常公鸡的红鸡冠、啼鸣与好斗。但他在一些鸡体内把睾丸移植入体腔，远离其神经，这些鸡却正常发育成公鸡。Berthold 推断，必定是睾丸释放入血液的某种东西作用于鸡冠与大脑。半个世纪后，William Bayliss 与 Ernest Starling 发现，狗小肠中的酸，即使切断了神经，也能使胰腺分泌，因为肠向血液释放了一种化学信使，他们将其命名为促胰液素（1902）。Starling 在1905年引入了**激素**（hormone）一词，源自希腊语，意为"启动"。

激素协调缓慢、广泛而持久的过程：生长、蜕皮与变态、繁殖、燃料的利用与贮存，以及盐与水的平衡。本章介绍激素的化学类别及其受体、支配激素浓度与其控制的原则，以及控制代谢、生长、蜕皮与繁殖的脊椎动物与昆虫内分泌系统。激素结合之后的细胞内信号，G 蛋白、第二信使、激酶级联，在 [[cell-biology/cell-signalling]]，反馈逻辑在 [[animal-physiology/homeostasis]]。

## 激素与其受体

::: definition 激素与神经激素 {#def-hormone}
**激素**是细胞分泌入血液或血淋巴的化学信使，借血流到达身体别处的靶细胞，在低浓度下（典型为10⁻¹²到10⁻⁷ mol L⁻¹）通过特异的受体作用于它们。**神经激素**是由神经元（**神经分泌细胞**）分泌的激素，通常从**神经血器**中的轴突末梢释放入循环。**内分泌**腺向血液分泌激素；**旁分泌**与**自分泌**信号局部地作用于邻近细胞或分泌细胞自身（[[cell-biology/cell-signalling#def-signal-modes]]）。
:::

激素分为几个化学类别，类别在很大程度上决定了激素如何生成、如何运输、如何起作用。

| 类别 | 实例 | 溶解性与运输 | 受体 |
|---|---|---|---|
| 肽类与蛋白质类 | 胰岛素、胰高血糖素、生长激素、血管加压素、催产素；昆虫的胰岛素样肽、脂动激素、促前胸腺激素 | 水溶性；游离于血浆；半衰期为分钟级 | 细胞表面（GPCR、受体酪氨酸激酶、细胞因子受体） |
| 酪氨酸衍生的胺类 | 肾上腺素、去甲肾上腺素 | 水溶性；半衰期一两分钟 | 细胞表面 GPCR（肾上腺素能受体） |
| | 甲状腺激素（甲状腺素 T₄；三碘甲状腺原氨酸 T₃） | 脂溶性；结合血浆蛋白；半衰期为天级 | 核受体 |
| 类固醇 | 皮质醇、醛固酮、睾酮、雌二醇、孕酮；昆虫的蜕皮激素类（蜕皮酮、20-羟基蜕皮酮） | 脂溶性；由结合蛋白携带；半衰期为数十分钟到数小时 | 多为核受体（也有一些膜受体） |
| 萜类及其他 | 昆虫保幼激素（一种倍半萜）；类花生酸如前列腺素（多为局部信号） | 脂溶性 | 多种，包括核受体 |

::: definition 细胞表面受体与核受体 {#def-receptor}
**细胞表面受体**结合不能透过质膜的水溶性激素，通过第二信使或激酶级联起作用；其效应在数秒到数分钟内开始，常修饰已有的蛋白质。**核受体**结合扩散入细胞的脂溶性激素；激素-受体复合物结合特定的 DNA 序列（激素反应元件），激活或抑制转录，因此效应需时数小时，并涉及新蛋白质的合成。核受体是一个大家族，在脊椎动物中包括类固醇、甲状腺激素、维甲酸与维生素 D 的受体，在昆虫中则是蜕皮激素受体（EcR 与 Ultraspiracle 的异源二聚体）。
:::

这一区分是指南而非铁律：类固醇也能通过膜受体产生快速效应，肽类激素也通过其信号级联改变基因表达。但它解释了节奏的大部分差异，比如肾上腺素在数秒内提高心率，而甲状腺激素在数日内抬高代谢率。

### 激素有多少？分泌、清除与半衰期

血液中激素的浓度，由其分泌与由其被移除之间的平衡决定，移除包括在肝与肾中的降解、靶组织的摄取与排泄。

::: proposition 单房室激素动力学 {#prop-kinetics}
设一激素以速率 $S$（单位时间的量）分泌入分布体积 $V$，并以速率常数 $k$ 的一级过程被移除。其浓度 $C$ 满足

$$
V\,\deriv{C}{t} = S - kVC.
$$ {#eq-kinetics}

稳态时

$$
C_\infty = \frac{S}{kV} = \frac{S}{\mathrm{MCR}},
$$ {#eq-steady-state}

其中 $\mathrm{MCR} = kV$ 是**代谢清除率**（单位时间清除的血浆体积）。分泌发生阶跃改变后，$C$ 以指数方式趋近新的稳态，其**半衰期**为 $t_{1/2} = \ln 2 / k$；在 $\log_2 10 \approx 3.3$ 个半衰期内完成变化的90 %。假设条件：单一、充分混合的房室，一级移除（清除不饱和），$V$ 与 $k$ 恒定。结合血浆蛋白的激素清除更慢，其游离的活性部分可能很小。
:::

::: proof
把 [[#eq-kinetics]] 除以 $V$：$\deriv{C}{t} = S/V - kC$。其平衡为 $C_\infty = S/kV$，而 $u = C - C_\infty$ 满足 $\deriv{u}{t} = -ku$，故 $u(t) = u(0)\,\mathrm{e}^{-kt}$。偏差每 $\ln 2/k$ 减半，在 $\ln 10/k = (\ln 10/\ln 2)\,t_{1/2} = 3.32\,t_{1/2}$ 后降到十分之一。
:::

::: example 快激素与慢激素 {#ex-kinetics}
（a）一肽类激素以2.0 µg h⁻¹ 分泌，代谢清除率为20 L h⁻¹。其稳态血浆浓度是多少？（b）哺乳类胰岛素的血浆半衰期约5 min，人甲状腺素（T₄）约7天。分泌速率改变后，两者各需多久完成到新稳态变化的90 %？（c）这对每种激素能携带的信息意味着什么？
::: solution
（a）$C_\infty = 2.0/20 = 0.10$ µg L⁻¹。

（b）变化的90 %需要 $3.3$ 个半衰期：胰岛素 $3.3 \times 5 = 17$ min；甲状腺素 $3.3 \times 7 = 23$ 天。

（c）胰岛素浓度能追踪餐后血糖逐分钟的变化；它携带快信息。甲状腺素浓度对数周的分泌作积分；它设定一个缓慢变化的背景水平，如总体代谢率，单日分泌的变化影响甚微。短半衰期是昂贵的（激素必须持续合成），但这是快速控制的代价。
:::
:::

### 脉冲与模式

许多激素不是持续分泌，而是以**脉冲**分泌。促性腺激素释放激素（GnRH）在许多哺乳动物由下丘脑约每小时爆发释放一次，垂体对这一模式作出响应。Ernst Knobil 与同事在自身 GnRH 分泌被取消的恒河猴身上证明，每小时的 GnRH 脉冲恢复了垂体促性腺激素的分泌，而同种激素的持续输注反而抑制它（P. E. Belchetz 与同事，1978）：受体在持续刺激下**脱敏**。脉冲信号能被传导的前提，是激素在脉冲之间被迅速清除，下一个例子说明了这一点。

::: example 激素能携带脉冲吗？ {#ex-pulses}
一激素每60 min 以短脉冲分泌一次。比较半衰期为（a）10 min 与（b）240 min 的激素，其谷浓度与峰浓度之比。
::: solution
脉冲之间浓度衰减因子为 $2^{-60/t_{1/2}}$。（a）$2^{-6} = 1/64 = 0.016$：浓度在脉冲之间几乎降到零，靶细胞看到的是分明的脉冲。（b）$2^{-0.25} = 0.84$：浓度只下降16 %，下一次脉冲便已到来，后续脉冲接连叠加，趋近接近稳态的水平，约为单个脉冲的六倍（$1/(1 - 0.84) = 6.3$）。长寿命的激素携带不了脉冲信息；半衰期以分钟计的 GnRH 可以。
:::
:::

## 神经内分泌轴

在脊椎动物，内分泌系统大体由脑通过**下丘脑**与其下方的**垂体**（pituitary gland）发号施令。

::: definition 下丘脑-垂体轴 {#def-axis}
**神经垂体**（neurohypophysis）是一个神经血器：下丘脑神经分泌细胞的轴突终止于此，向血液释放**血管加压素**（抗利尿激素；非哺乳脊椎动物为精氨酸血管催产素）与**催产素**。**腺垂体**（adenohypophysis）是一个由下丘脑神经元分泌的**释放激素**与**抑制激素**控制的腺体，这些激素被释放入一条直通腺垂体的门脉血管系统。腺垂体分泌**促激素**：促甲状腺激素（TSH）、促肾上腺皮质激素（ACTH）、促性腺激素黄体生成素（LH）与促卵泡激素（FSH），它们作用于更外周的内分泌腺；以及作用更广泛的生长激素（GH）与催乳素。每条**轴**，下丘脑 → 垂体 → 靶腺（甲状腺、肾上腺皮质、性腺），都受最终激素对下丘脑与垂体的**负反馈**调节。
:::

轴在每一级都加上放大与控制。门脉血中几纳克的释放激素，引起几微克促激素的释放，进而引起几毫克类固醇或甲状腺激素的释放。而两级上的负反馈把最终激素维持在调定点附近，这个调定点脑可以移动：应激时升高皮质醇，青春期升高性腺类固醇，受冷时升高甲状腺激素。

昆虫有一种惊人相似的组织，且是独立演化的。脑中的神经分泌细胞把轴突送到**心侧体**，即脑后的神经血器，从中释放神经激素，其中包括**促前胸腺激素**（PTTH），它刺激**前胸腺**合成类固醇蜕皮激素。与心侧体相邻的一对腺体**咽侧体**分泌**保幼激素**。这一平行，脑、神经血器、促激素、外周腺合成类固醇，是引人注目的趋同。

::: quiz
一只哺乳动物的甲状腺受损，生成的甲状腺素减少。血浆 TSH 与甲状腺素的浓度会发生什么变化？为什么？
- [ ] 两者都下降，因为轴是一条激活链。
- [x] 甲状腺素下降而 TSH 上升，因为甲状腺素对下丘脑与垂体的负反馈减弱。
- [ ] 甲状腺素下降而 TSH 不变，因为垂体不感受甲状腺素。
- [ ] 两者都上升。
::: solution
甲状腺素通常抑制 TSH 释放激素与 TSH 的释放。甲状腺素下降时，这一抑制减弱，TSH 上升，是环路试图通过刺激残存的甲状腺组织来恢复甲状腺素（若缺碘，组织可能肿大，形成甲状腺肿）。同时测定两种激素可以把内分泌环路中的故障定位：刺激激素高而靶腺激素低，指向靶腺。
:::
:::

## 代谢与燃料

调节燃料使用的激素是最古老的激素之列。在脊椎动物，血糖升高时由胰腺**胰岛**的 β 细胞分泌的**胰岛素**，促进肌肉与脂肪组织摄取葡萄糖，并把燃料以糖原、脂肪与蛋白质形式贮存；来自 α 细胞的**胰高血糖素**则在血糖下降时促进肝释放葡萄糖。两者共同构成血糖的推-拉式控制（[[animal-physiology/homeostasis]]），其生物化学见 [[biochemistry/metabolic-integration]]。**肾上腺髓质**释放的**肾上腺素**为紧急行动动员葡萄糖与脂肪酸，即 Walter Cannon 分析的"战斗或逃跑"反应；**肾上腺皮质**的**皮质醇**在应激与禁食时促进糖异生与蛋白质分解；**甲状腺激素**在内温动物中抬高代谢率与产热，这就是它属于对寒冷的反应与季节性能量变化的原因。

昆虫有功能上的对应物。脑内神经分泌细胞生成的**胰岛素样肽**促进生长与燃料贮存；敲除果蝇 *Drosophila melanogaster* 的这些细胞，会产生血淋巴糖升高的小型果蝇，一种糖尿病样的状态（Eric Rulifson、Seung Kim 与 Roel Nusse，2002）。心侧体的**脂动激素**在飞行中从脂肪体动员脂类与糖海藻糖，扮演胰高血糖素的角色。胰岛素信号通路为线虫、昆虫与哺乳动物所共有，降低其活性在三者中都能延长寿命，是被保守的内分泌系统最清晰的例证之一。

## 生长

在脊椎动物，腺垂体的**生长激素**主要通过刺激肝与其他组织生成**胰岛素样生长因子1**（IGF-1），促进骨、肌肉与其他组织的生长。这条轴是种内体形的一个重要决定因素。在犬中，体形的变异超过任何哺乳动物，几乎所有小型犬种共享一个与较低 IGF-1 水平相关的 *IGF1* 基因单倍型，而它在大型犬中罕见（Nathan Sutter 与同事，2007）。

昆虫的生长方式不同。它们的外骨骼不能扩张，于是分步生长，每次**蜕皮**时脱去并更新表皮；当它们变态为不再蜕皮的成虫时，生长便告结束。最终体型因此由幼虫何时停止取食并启动变态决定。在烟草天蛾 *Manduca sexta* 中，H. Frederik Nijhout 与同事表明，这一决定取决于幼虫在末龄达到**临界体重**，此后即使挨饿，变态的激素进程仍会推进。

## 蜕皮与变态

### 昆虫：蜕皮激素与保幼激素

Vincent Wigglesworth 在1930年代对吸血蝽 *Rhodnius prolixus* 的实验确立了昆虫发育的激素控制。*Rhodnius* 的若虫每饱食一次血蜕皮一次。Wigglesworth 发现，饱食后不久去头的若虫不蜕皮，而去头较晚的则蜕皮；把一个去头若虫与一个即将蜕皮的若虫联结起来（用毛细管使血淋巴相通），两者都蜕皮：来自头部的一个因子，在取食后一个关键时刻释放，诱导蜕皮。他还发现，咽侧体的一个因子使昆虫保持幼态：摘除咽侧体使若虫提前变态为微型成虫，而给末龄若虫植入额外的咽侧体则产生一个巨大的额外若虫龄期。

::: definition 昆虫蜕皮的激素控制 {#def-moult}
蜕皮由**蜕皮激素类**触发：前胸腺在 PTTH 刺激下生成蜕皮酮，在组织中转变成活性形式**20-羟基蜕皮酮**，它通过核内蜕皮激素受体启动蜕皮的基因表达程序。蜕皮的种类由**保幼激素**（JH）决定，看它在蜕皮激素峰之时是否存在：JH 高则产生幼虫（或若虫）蜕皮，昆虫保持幼态；全变态昆虫末龄幼虫 JH 低，则产生蛹的蜕皮；无 JH 则产生成虫蜕皮。因此保幼激素被称为"维持现状"激素：它不引起蜕皮，只是让每次蜕皮保持上一次的种类。
:::

蜕皮酮由 Adolf Butenandt 与 Peter Karlson 在1954年分离：从500 kg 蚕蛹得到25 mg 结晶。保幼激素由 Carroll Williams 在1950年代从雄性柞蚕腹部分提取，一个异常丰富的来源，其结构于1967年确定。由于 JH 类似物阻止昆虫完成变态，它们被用作对脊椎动物毒性很小的杀虫剂。

::: example 预测一次蜕皮 {#ex-moult}
预测对全变态昆虫（如蛾）下列每个实验的结果，并给出理由。（a）摘除三龄幼虫（共五龄）的咽侧体。（b）在末次蜕皮激素峰之前，给末（五）龄幼虫施用 JH 类似物。（c）在四龄幼虫龄期之初摘除其前胸腺。（d）末龄幼虫中，JH 滴度降为零，随后两次蜕皮激素峰：先一次小的，接一次大的。
::: solution
（a）没有 JH，下一次蜕皮激素峰触发变态：幼虫提前化蛹，羽化出一个小而其余正常的成虫。（b）蜕皮激素峰时有 JH 存在，蜕皮为幼虫型：昆虫变成一个巨大的、额外多出的六龄幼虫。（c）没有蜕皮激素，幼虫无法蜕皮；它将停留在四龄直到死亡（除非给予蜕皮酮）。（d）这正是 *Manduca* 变态的正常序列：无 JH 时小的"承诺"峰把组织重新编程，转而合成蛹表型而非幼虫表型的表皮，并触发游走行为；随后的大峰引起化蛹蜕皮。决定结果的是时机、以及每次峰时 JH 的有无，而不只是蜕皮激素的量。
:::
:::

### 甲壳类与两栖类

甲壳类同样在蜕皮激素控制下蜕皮，蜕皮激素在**Y 器官**生成；蜕皮被眼柄 X 器官-窦腺复合体的**蜕皮抑制激素**按住。因此去除眼柄会诱导蜕皮，并因失去一种性腺抑制激素而引起卵巢成熟；对养殖雌虾摘除眼柄以诱导产卵的做法已被广泛使用，如今因福利问题而受到质疑，并日益被其他方法取代。

两栖类的变态由**甲状腺激素**控制。J. F. Gudernatsch 在1912年表明，喂食马甲状腺组织的蝌蚪提前变态为小蛙，而摘除甲状腺的蝌蚪从不变态，只是继续生长。甲状腺激素通过核受体作用于每一组织，但效应各不相同，尾与鳃的吸收、四肢的生长、消化道从食草者的长管到食肉者短管的改建、排氨转排尿素（[[animal-physiology/water-salt-balance]]）、幼体血红蛋白换成成体血红蛋白，于是同一种激素协调全身的转变。皮质类固醇加速这一响应，应激（如池塘干涸）可以经由这一途径加速变态。甲状腺激素还控制比目鱼与其他鱼类的变态；在七鳃鳗中，与变态相伴的是低的而非高的甲状腺激素，提醒我们同一种激素可以被以不同方式使用。

## 繁殖

脊椎动物的繁殖由下丘脑-垂体-性腺轴控制。下丘脑的 GnRH 刺激 LH 与 FSH 的释放，后者刺激性腺生成配子与性类固醇（睾酮、雌二醇、孕酮），它们再作用于生殖道、第二性征与行为，并反馈于下丘脑与垂体。绝大多数时候反馈是负面的。但在雌性哺乳动物的性周期中，成熟卵泡持续的高水平雌二醇转为**正反馈**，触发 LH 峰引起排卵（[[animal-physiology/homeostasis]]）。

许多动物只在特定季节繁殖，时机由昼长决定。在哺乳动物，松果体在夜间分泌**褪黑素**，于是每晚褪黑素信号的持续时间编码夜长。绵羊是**短日型繁殖者**：其生殖轴被秋季的长夜激活，于是经过五个月妊娠后羊羔在春天出生；叙利亚地鼠是**长日型繁殖者**，其性腺在短日中萎缩。在鸟类，光周期信号经眼起作用，并经脑内的光感受器直接起作用；在日本鹌鹑，Takashi Yoshimura 与同事（2003）发现，长日诱导下丘脑内把甲状腺素局部转化为活性更强的 T₃，触发 GnRH 释放；此后在哺乳动物中也发现了类似的甲状腺激素开关。

激素还在发育中塑造性别表型。在许多龟类与所有研究过的鳄类，性别由卵的孵化温度而非性染色体决定，温度部分通过调节芳香化酶起作用，该酶把睾酮转化为雌二醇；把雌二醇涂在产生雄性的孵化温度下的卵上，会产生雌性（[[developmental-biology/principles-of-development]]）。

::: warning "激素各司一职"与"同一种激素在所有动物中做同一件事"
激素是信号，其效应取决于受体与靶细胞。催乳素刺激哺乳动物产奶，但它也是使鱼类适应淡水的激素：垂体切除的鳉鱼（*Fundulus heteroclitus*）在淡水中会死亡，除非给予催乳素（Grace Pickford 与 James Phillips，1959）；在鸽子，它刺激嗉囊产生"嗉囊乳"。甲状腺激素在蛙触发变态，在哺乳动物调节代谢率。与催产素相关的肽在不同动物调节产卵、水平衡与社会行为。激素的化学往往十分古老；其用途在进化中被一再重新指派。
:::

## 内分泌系统的进化

许多激素与受体家族比如今使用它们的动物更古老。胰岛素样肽、催产素-血管加压素类肽、类固醇受体与 GnRH 家族遍布两侧对称动物，它们的一些受体还要古老。Joseph Thornton 与同事从现存物种推断祖先类固醇受体的序列，并在实验室中将其复活。祖先的类固醇受体似乎对雌激素敏感（Thornton，2001），而脊椎动物的醛固酮与皮质醇受体则通过少数替换获得其专一性，其中一些替换只有在早先看似中性的替换存在时才改变专一性（J. T. Bridgham、S. M. Carroll 与 Thornton，2006）。激素-受体系统由此通过**分子利用**（molecular exploitation）进化：一个曾结合某配体的受体被招募来响应恰好与之契合的新激素，系统再经打磨完善。

::: example 受体占据与激素浓度 {#ex-occupancy}
一靶细胞的受体对该激素的解离常数为 $K_\mathrm{d} = 1.0$ nmol L⁻¹。用 [[cell-biology/cell-signalling#prop-occupancy]] 的占据关系 $\theta = C/(C + K_\mathrm{d})$，计算（a）静息浓度0.10 nmol L⁻¹ 与（b）受刺激浓度1.0 nmol L⁻¹ 时受体的占据比例。（c）若由于储备受体与放大，响应只需10 %的占据，产生半最大响应的浓度是多少？
::: solution
（a）$\theta = 0.10/1.10 = 0.091$。（b）$\theta = 1.0/2.0 = 0.50$。激素浓度升高十倍，占据率升高五倍。（c）若10 %的占据就产生完全响应，半最大响应约需5 %的占据（假设最大之前响应与占据成正比）：$C/(C + 1.0) = 0.05$，故 $C = 0.053$ nmol L⁻¹，比 $K_\mathrm{d}$ 低近二十倍。受体下游的放大使细胞能对远低于受体 $K_\mathrm{d}$ 的激素浓度起响应，但这也意味着（a）中的"静息"浓度已会产生可观的响应，所以激素的静息水平必须连同受体数目与其靶的放大一起判断。
:::
:::

::: application 内分泌干扰
许多人工合成化学品模拟或阻断激素。1980年代，Peter Gibbs 与 Geoffrey Bryan 追溯了英格兰西南海岸荔枝螺（*Nucella lapillus*）雌性长出雄性性器官的病例，这种状况称为**imposex**（雄附雌），重度感染的雌性因此不育，局部种群消失；病因是船只防污漆溶出的三丁基锡（TBT）。1980年代末起对 TBT 的限制，最终导致国际海事组织公约的全球禁令于2008年生效，此后荔枝螺种群恢复。佛罗里达 Apopka 湖被农业农药泄漏污染的短吻鳄，表现出异常的性腺与激素水平（Louis Guillette 与同事，1994）。污水排放中的雌激素类化合物使河中雄鱼雌性化。这些案例使内分泌干扰成为生态毒理学与监管的核心议题（[[conservation-biology/invasions-climate]]）；其人类方面见[医学图谱：内分泌](/learn/medicine/course.php?c=endocrine)。
:::

::: history
Arnold Berthold 的公鸡睾丸移植（1849）是第一个内分泌实验。Charles-Édouard Brown-Séquard 在1880年代把注意力引向"内部分泌物"，George Oliver 与 Edward Schäfer 在1894年发现了肾上腺提取液的升压效应。Bayliss 与 Starling 在1902年发现促胰液素，Starling 在1905年为激素命名。Gudernatsch 在1912年表明甲状腺对两栖类变态的控制；Frederick Banting 与 Charles Best 在1921–22年以狗为材料分离出胰岛素，合作者还有 J. J. R. Macleod 与 James Collip。Stefan Kopeć 在1917–22年用舞毒蛾幼虫表明脑通过血源性因子控制昆虫变态，这是对神经激素的第一次证明；Wigglesworth 在1930年代分析了 *Rhodnius* 的蜕皮与保幼激素。Geoffrey Harris 在1940与1950年代确立下丘脑通过门脉血管控制腺垂体；Roger Guillemin 与 Andrew Schally 分离出首批下丘脑释放激素（1969–71），与 Rosalyn Yalow 共享诺贝尔奖，后者的放射免疫测定（与 Solomon Berson，1959–60）第一次使在生理浓度下测定激素成为可能。
:::

## 由此引向何处

激素与神经系统协同工作，而神经系统也控制着下丘脑与垂体；神经的一面是 [[neuroscience]] 的主题。激素的发育作用在 [[developmental-biology/principles-of-development]] 中进一步展开，激素在行为中的作用，求偶、攻击、育幼与迁徙，见 [[behaviour/mechanisms-of-behaviour]]。

::: summary
- 激素是随血液运输的信使，在纳摩尔到皮摩尔浓度经特异受体起作用；神经激素由神经元释放入神经血器。
- 肽类与儿茶酚胺经细胞表面受体在秒到分钟内起作用；类固醇、甲状腺激素与保幼激素主要经核受体在数小时内调控转录。
- 血浆浓度等于分泌除以代谢清除率；变化之后约3.3个半衰期完成到新稳态变化的90 %（[[#prop-kinetics]]）。脉冲信号要求短半衰期。
- 脊椎动物的内分泌轴自下丘脑到垂体到靶腺，每一级都有放大与负反馈；昆虫有趋同的脑-心侧体-前胸腺系统，加上咽侧体。
- 胰岛素与胰高血糖素（昆虫为胰岛素样肽与脂动激素）控制燃料；甲状腺激素设定代谢率；生长激素主要通过 IGF-1 起作用。
- 昆虫蜕皮由20-羟基蜕皮酮触发，其种类由保幼激素决定（高：幼虫型；低：蛹型；无：成虫型）；甲壳类另加蜕皮抑制激素；甲状腺激素驱动两栖类的变态。
- 繁殖由下丘脑-垂体-性腺轴控制，排卵时有正反馈的 LH 峰；褪黑素与下丘脑的甲状腺激素转化决定繁殖季节。
- 激素与受体十分古老，并被一再重新部署；TBT 等人工内分泌干扰物产生了种群水平的影响。
:::

::: exercise 稳态浓度 {level=1 check="5"}
一类固醇激素每天分泌100 µg，代谢清除率为每天20 L。其稳态血浆浓度是多少 µg L⁻¹？
::: solution
$C_\infty = S/\mathrm{MCR} = 100/20 = 5$ µg L⁻¹。

::: exercise 半衰期 {level=1 check="6.93"}
一激素以0.10 min⁻¹ 的一级速率常数从血浆移除。其半衰期是多少分钟（三位有效数字）？
::: solution
$t_{1/2} = \ln 2/k = 0.693/0.10 = 6.93$ min。
:::

::: exercise 给激素分类 {level=1}
对每种激素，说明其化学类别，并预测其受体在细胞表面还是在核内：（a）胰高血糖素；（b）20-羟基蜕皮酮；（c）肾上腺素；（d）甲状腺素；（e）保幼激素；（f）催产素。
::: solution
（a）肽类：细胞表面 GPCR。（b）类固醇：核受体（EcR–Ultraspiracle）。（c）儿茶酚胺：细胞表面 GPCR（α 与 β 肾上腺素能）。（d）碘化酪氨酸衍生物，脂溶性：核内甲状腺激素受体（在靶细胞内转化为 T₃ 后）。 （e）倍半萜，脂溶性：胞内受体（Methoprene-tolerant，bHLH-PAS 家族的转录因子，而非经典核受体），调控转录。（f）肽类（九肽）：细胞表面 GPCR。

::: exercise 调整所需的时间 {level=2 check="3.9"}
一哺乳动物皮质醇的血浆半衰期约70 min。分泌阶跃改变后，皮质醇完成到新稳态变化的90 %需要多少小时（两位有效数字）？
::: solution
$3.32 \times 70 = 233$ min，即3.9小时。因此皮质醇能跟随以小时计的变化，如昼夜节律与对应激源的响应，但跟不了一分钟一分钟的涨落。
:::

::: exercise 定位故障 {level=2}
对下列每种情况，给出下丘脑-垂体-肾上腺轴中最可能的故障部位，并用负反馈解释：（a）皮质醇低，ACTH 高；（b）皮质醇低，ACTH 低；（c）皮质醇高，ACTH 低；（d）皮质醇高，ACTH 高。
::: solution
（a）肾上腺皮质无法生成皮质醇；反馈抑制解除，ACTH 上升。（b）垂体（或下丘脑）无法生成 ACTH（或其释放激素），肾上腺得不到刺激。（c）肾上腺自主生成皮质醇（如肿瘤），或皮质醇作为药物给予；高皮质醇抑制 ACTH。（d）多余的 ACTH（垂体瘤或其他来源）驱动肾上腺；反馈无法将其抑制。这些图式就是医学内分泌诊断的逻辑（[医学图谱：内分泌](/learn/medicine/course.php?c=endocrine)）；这里它们展示两级负反馈环在一个组分改变时的行为。
:::

::: exercise 解读一个联体共生实验 {level=2}
Wigglesworth 把成对的 *Rhodnius* 若虫连接起来，使血淋巴相通。预测并解释下列每种情况的结果：（a）饱食后一小时去头的若虫，与饱食后八天（已过关键期）去头的若虫相连；（b）两只都在饱食后一小时去头；（c）末（五）龄若虫在两者蜕皮前不久与一龄幼若虫相连。这些实验说明了什么？
::: solution
（a）两者都蜕皮：去头较晚的若虫已释放头部因子（PTTH），它作用于前胸腺生成的蜕皮激素会循环进入其伙伴。（b）两者都不蜕皮：都没有收到头部因子。（c）五龄若虫本应蜕皮为成虫，却蜕成具有若虫特征的巨大六龄若虫，因为年幼若虫活跃的咽侧体产生的保幼激素循环进入了它。这些实验共同表明：取食后特定时刻从头释放的血源性因子触发蜕皮，而来自幼虫的另一血源性因子阻止变态。
:::
:::

::: exercise 同一种激素的两种环境 {level=2}
一条广盐性鱼被切除垂体。它在海水中存活，但在淡水中数日内死亡，除非注射催乳素。（a）解释催乳素在淡水鱼中的作用，联系淡水对渗透调节的难题。（b）为什么垂体切除的鱼能在海水中存活？（c）你预计哪种激素对转入海水是重要的？
::: solution
（a）在淡水中，鱼必须限制离子流失与水的进入，并主动吸收离子（[[animal-physiology/water-salt-balance]]）；催乳素降低鳃及其他上皮对水与离子的通透性，促进淡水型的离子细胞，并增加肾稀释尿的排出伴离子重吸收。没有它，鱼失去 Na⁺ 与 Cl⁻ 快于补充，血浆离子浓度降到致死水平。（b）在海水中，催乳素的作用并非必需，海水型渗透调节在较低的激素支持下也能运转（尽管间肾组织的皮质醇有帮助；没有 ACTH 时皮质醇分泌很低，故海水中的存活可能仍受损）。（c）皮质醇，连同生长激素与 IGF-1，它们促进海水型鳃离子细胞与 Na⁺/K⁺-ATPase。
:::
:::

::: exercise 设计光周期现象的检验 {level=3}
你怀疑一种小型哺乳动物是受褪黑素控制的长日型繁殖者。设计实验检验（a）昼长控制性腺生长，（b）松果体是必需的，（c）线索是每晚褪黑素信号的持续时间而非其幅度。写出预期的结果。
::: solution
（a）把动物分养于长日（如16 h 光照：8 h 黑暗）与短日（8：16），温度与食物相同；长日型繁殖者在长日中性腺应大而活跃，在短日中萎缩。（b）在短日照饲养的动物中切除松果体（设假手术对照）；若松果体的褪黑素介导短日信号，切除动物应不再萎缩性腺。（c）在切除松果体的动物中，每天以持续时间不同（如8 h 对16 h）而峰浓度相同的模式输注褪黑素，再以持续时间相同而幅度不同的模式对照：若持续时间是线索，长时程输注应模拟短日（性腺萎缩），与幅度无关。Bruce Goldman 与同事在1980年代以西伯利亚地鼠与叙利亚地鼠做过此设计的实验，表明持续时间是关键特征。
:::
:::

::: exercise 解读内分泌干扰物的剂量-反应 {level=3}
雌性荔枝螺在实验室暴露于0、1、3、10与30 ng L⁻¹（以锡计）的 TBT 一年，以雌性长出的阴茎平均长度（阴茎相对长度指数）评定 imposex。指数在这一范围内从0升至与雄性相当的水平，最低浓度即有明显效应。（a）这样的低有效浓度对污染物为什么令人惊讶，对内分泌干扰物为什么不奇怪？（b）野外调查发现，码头与港口附近 imposex 最重。还有什么证据能确立 TBT 在野外引起 imposex？（c）TBT 受限后，被调查种群的 imposex 在其后约十年间下降。恢复为什么要多年？
::: solution
（a）大多数毒物经非特异性损伤起作用，需要高浓度；内分泌干扰物经受体与信号通路起作用，而这些通路生来就响应纳摩尔到皮摩尔的激素浓度，所以在每升纳克级的浓度就能产生效应。（TBT 被认为部分通过维甲酸 X 受体、一种核受体起作用，并可能改变类固醇代谢；机制曾有争论。）（b）各站点测定的水、沉积物或组织 TBT 与 imposex 之间的剂量-反应关系；在污染站点野外浓度下、对移植或笼养动物以及实验室中诱导出 imposex；清洁站点没有 imposex；以及最有说服力的，TBT 撤除后的恢复，一个自然实验。（c）TBT 在沉积物中存留多年并持续溶出；成年雌性已形成的 imposex 不可逆，恢复有赖于在更清洁的水中成长的新世代；而荔枝螺直接发育、没有浮游幼虫阶段，已消失的种群只能由邻近种群缓慢重新定殖。
