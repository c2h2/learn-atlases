一头蓝鲸冲进一群磷虾之中，几秒钟之内吞下与自身体积相当的海水，再经鲸须把水滤出。一只吸血蝠能在不到半小时内喝下相当于自身体重一半的血液。一条缅甸蟒吞下一顿占自身体重四分之一的食物，并在两天之内把肠的大小增加一倍来消化它。一头牛造不出任何一种能消化纤维素的酶，却靠着在胃里养一口微生物发酵缸而以草为生。动物是异养生物：构成它们的一切和它们花掉的每一焦耳能量，正如 [[animal-physiology/energy-metabolism]] 中所核算的，都来自食物。它们如何获得食物，又如何把食物变成小到足以穿过细胞膜的分子，其变化之大超过它们生理的几乎任何其他方面。

本章概览动物的取食方式、消化系统的组织、消化与吸收的化学和转运，以及把肠道设计与食性、体型联系起来的数量逻辑。吸收养分的膜转运体在 [[cell-biology/membrane-transport]] 中描述，被吸收燃料的代谢去向在 [[biochemistry/metabolic-integration]]。

## 取食方式

动物常按所吃的东西分类，草食者、肉食者、杂食者、碎屑食者，但对生理学更有用的分类依据是*如何*获得食物，因为这决定了肠道必须做什么。

::: definition 取食机制 {#def-feeding}
- **悬浮取食**（滤食）：从水中滤取细小颗粒或生物，所用结构可为纤毛与黏液（海绵、双壳类、海鞘）、刚毛（藤壶、许多甲壳类）、鳃耙（某些鱼类）或鲸须（须鲸）。
- **沉积取食**：吞食沉积物或土壤，消化其中的有机物（蚯蚓、许多多毛类、海参）。
- **流体取食**：吸取富含养分的液体，花蜜、植物汁液、血液，通常使用刺吸式口器（蚜虫、蚊、蜱、蜂鸟、吸血蝠）。
- **吞食**：吃下大块食物，食物被颌、齿、喙或齿舌捕获、撕碎或磨碎（多数脊椎动物、头足类、许多昆虫）。
- **共生营养**：从居住在动物组织内的共生微生物获取养分，如造礁珊瑚体内的光合甲藻，或热液喷口管栖蠕虫 *Riftia pachyptila* 营养体（trophosome）中的化能自养细菌，该虫成年后没有口也没有肠。
:::

每种取食机制各有其物理难题。悬浮取食者必须让大量水流过滤体：一只几厘米长的贻贝每小时经鳃泵几升水，而一个双壳类种群能在几天之内滤完一个浅湾的全部水量，把其中的浮游植物清除干净。流体取食者摄入的是稀薄的食物：花蜜主要是糖和水，植物筛管汁液糖多而氨基酸少，血液蛋白多而 B 维生素少。两者都得对付多余的水分，吸血蝠开始取食后几分钟内就开始排出稀尿，以便起飞时减轻体重；而且许多流体取食者依靠微生物共生者来补足食物所缺的东西。蚜虫依赖住在特化细胞里的细菌 *Buchnera aphidicola* 来合成筛管汁液中缺失的必需氨基酸；舌蝇依赖 *Wigglesworthia* 来合成血液中缺失的 B 维生素。

## 消化系统

**消化**是把大分子食物（多糖、蛋白质、脂肪、核酸）水解成可被吸收的小分子（单糖、氨基酸与小肽、脂肪酸与单酰基甘油、核苷）的过程，由酶催化。

::: definition 细胞内与细胞外消化；肠道的类型 {#def-gut}
在**细胞内消化**中，食物颗粒经吞噬作用进入细胞，在源自溶酶体的液泡内被消化（海绵；刺胞动物、扁形动物与双壳类部分如此）。在**细胞外消化**中，酶被分泌进一个腔，食物在其中先被分解再被吸收。**消化循环腔**（刺胞动物、扁形动物）只有一个开口，食物经它进入，废物也由它排出。**管状消化道**（完全消化管）见于绝大多数两侧对称动物，有口有肛门，食物沿着一系列特化区段单向移动，通常包括：摄食与储存区（口、咽、食管、嗉囊），机械与初步化学处理区（肌胃、胃），消化与吸收区（脊椎动物的小肠、昆虫的中肠），以及水分与离子回收区并在许多草食动物中进行发酵（大肠、盲肠、后肠）。
:::

一条单向管道的一大优点，是允许不同区段维持不同条件。脊椎动物的胃分泌盐酸，在哺乳类可达 pH 1–2，它使蛋白质变性并杀死许多微生物；还分泌蛋白酶胃蛋白酶，后者在该 pH 下工作；小肠在胰腺来源的碳酸氢盐中和酸之后，为胰酶和乳化脂肪的胆盐提供接近中性的条件。食物可以像流水线那样被加工，而不必在一口缸里一锅煮。

并非每种脊椎动物都有酸性的胃。许多硬骨鱼（包括鲤科鱼及其近亲）、肺鱼、银鲛和单孔类（鸭嘴兽与针鼹）没有胃腺；这种丧失已独立发生多次，基因组研究表明，其中若干谱系在失去胃的同时也失去了胃蛋白酶原与胃质子泵的基因。

### 消化的化学

细胞外消化的酶在各动物之间大体相似。

| 食物 | 酶（例子） | 产物 |
|---|---|---|
| 蛋白质 | 内肽酶（胃蛋白酶、胰蛋白酶、糜蛋白酶、弹性蛋白酶）在肽链内部切割；外肽酶（羧肽酶、氨肽酶）切去末端残基 | 氨基酸、二肽与三肽 |
| 淀粉与糖原 | α-淀粉酶；随后是刷状缘的麦芽糖酶、异麦芽糖酶 | 葡萄糖 |
| 双糖 | 刷状缘的蔗糖酶、乳糖酶、海藻糖酶 | 单糖 |
| 脂肪（三酰甘油） | 脂肪酶，需胆盐或其他乳化剂 | 脂肪酸、2-单酰基甘油 |
| 核酸 | 核酸酶、磷酸酶 | 核苷、碱基、磷酸 |

蛋白酶以无活性的前体（酶原）分泌，造它们自己的腺体才不会被消化掉：胃蛋白酶原被酸激活，胰蛋白酶原被肠腔面上的肠激酶激活，随后胰蛋白酶激活其余的胰腺酶原。作用于双糖与短肽的酶锚定在吸收细胞的膜上，即**刷状缘**（brush border），其产物恰好释放在吸收它们的转运体旁边。

这些酶的表达追随食性。乳糖酶消化奶中的糖，在幼年哺乳动物中表达，而多数物种断奶后下降；它在某些人类人群中延续到成年，是近期演化研究得很好的一个例子（[[evolution/natural-selection]]）。猫是专性肉食者，某些碳水酶的活性低，而且尝不出甜味，因为它甜味受体一个亚基的基因是一个假基因（Xia Li 及其同事，2005年）。蜂鸟与食蜜蝠的肠道蔗糖酶活性极高。

### 吸收

吸收需要表面积。脊椎动物小肠在三个尺度上放大其面积：腔壁的环状皱襞、约一毫米高的指状**绒毛**，以及每个吸收细胞（enterocyte）上约一微米长的**微绒毛**。昆虫中肠细胞也有微绒毛；许多无脊椎动物则用盲囊（caeca）或螺旋瓣（如鲨与鳐的肠）在短肠内增大面积。

::: example 一条肠需要多少表面？ {#ex-surface}
把小肠模造成一根长3.0 m、直径2.5 cm 的光滑管道。(a) 它的光滑内表面积是多少？(b) 皱襞、绒毛与微绒毛把面积分别乘以约3、10与20的因子。总面积是多少？(c) 对人肠的最新精细形态测量（H. F. Helander 与 L. Fändriks，2014年）估计，包括微绒毛在内的人全肠黏膜总面积约30 m²，远小于教科书长期引用的那个200–300 m²（“一块网球场”）。这对这类倍乘因子告诉你什么？
::: solution
(a) $\pi d L = \pi \times 0.025 \times 3.0 = 0.24$ m²。

(b) $0.24 \times 3 \times 10 \times 20 = 0.24 \times 600 = 141$ m²。

(c) 这一结果完全取决于那些倍乘因子，而每个因子都沿肠道变化、随测量方法不同（固定会使组织收缩或膨胀，微绒毛因子又取决于微绒毛密度与长度究竟如何测量）。几个不确定因子相乘会使误差相互叠加放大，所以一个用来唬人的数字，一块“网球场”，可能偏大好幾倍。原理本身没有疑问：与光滑管道相比，绒毛与微绒毛把吸收面积增大了一到两个数量级。
:::
:::

吸收本身由 [[cell-biology/membrane-transport]] 中描述的那些转运体完成。葡萄糖与半乳糖经刷状缘，随 Na⁺ 通过同向转运体 SGLT1 进入吸收细胞，后者能把它们逆着很大的浓度梯度转运（[[cell-biology/membrane-transport#ex-sglt]]）；果糖经 GLUT5 易化扩散进入；三者都经基底侧膜上的 GLUT2 离开。氨基酸经由多种 Na⁺ 偶联载体及其他载体进入，二肽与三肽则经 H⁺ 偶联的肽转运体 PepT1 进入。脂肪酸与单酰基甘油随胆盐胶束被运到细胞表面，扩散进入吸收细胞，重新酯化为三酰甘油，再包装进脂蛋白颗粒（哺乳类为乳糜微粒）离开，进入淋巴而非血液。

有些养分还从细胞**之间**通过紧密连接，随水流过去（细胞旁吸收）。在哺乳类中，这条途径对葡萄糖而言无足轻重；但在小型飞行的鸟类与蝙蝠中，它占了葡萄糖吸收的很大一部分，在某些物种甚至占大部分（Enrique Caviedes-Vidal 及其同事，2007年）。会飞的动物比同体重不会飞的哺乳类肠更短，以减轻重量；一条“渗漏”的肠以较小的面积为代价换回了吸收量，代价是也把不想要的水溶性化合物吸了进来。

## 作为化学反应器的肠

肠为什么是那个长度？Deborah Penry 与 Peter Jumars（1986，1987年）提出，答案可以在化学工程中找到，办法是把肠当作反应器。工程师区分三种理想反应器。**间歇式反应器**灌满、反应、放空：消化循环腔即是。**连续搅拌釜式反应器**（CSTR）不断进料、不断出料，内内容物保持充分混合，所以流出的组成与整釜相同：瘤胃或一个大盲肠即是。**推流式反应器**（PFR）是一根管子，物料在其中流动而不沿管长混合，因此每一团物料都反应相同的时间：小肠大略如此。

::: proposition 推流式与搅拌釜式反应器的产率 {#prop-reactors}
设食物按一级动力学消化，速率常数为 $k$（从而单独放置时，经时间 $t$ 后剩 $\mathrm{e}^{-kt}$ 未被消化），并以体积流量 $Q$ 流经体积为 $V$ 的反应器，得到平均**滞留时间** $\tau = V/Q$。稳态下，食物离开时被消化的比例为

$$
X_\mathrm{PFR} = 1 - \mathrm{e}^{-k\tau}
\qquad\text{and}\qquad
X_\mathrm{CSTR} = \frac{k\tau}{1 + k\tau}.
$$ {#eq-reactors}

对同样的 $k$ 与 $\tau$，推流式反应器总是达到更高的产率。假设条件：一级动力学（反应速率正比于未消化底物的量，酶或微生物过量时即是）；理想流动（PFR 中不沿程混合，CSTR 中完美混合）；底物在被消化之前不被吸收。
:::

::: proof
**推流。** 每一团物料在管中恰好停留 $\tau$，如同单独放置一样反应，所以离开时未消化的比例为 $\mathrm{e}^{-k\tau}$。

**搅拌釜。** 设 $S_\mathrm{in}$ 为进料中底物的浓度，$S$ 为釜中的浓度，由完美混合它也等于流出液中的浓度。稳态下，进入的底物等于流出的底物加上消化的底物：$QS_\mathrm{in} = QS + kSV$。除以 $Q$ 得 $S_\mathrm{in} = S(1 + k\tau)$，故未消化比例为 $S/S_\mathrm{in} = 1/(1+k\tau)$，消化比例为 $1 - 1/(1+k\tau) = k\tau/(1+k\tau)$。

**比较。** 对 $x = k\tau > 0$ 需要 $1 - \mathrm{e}^{-x} > x/(1+x)$，等价于 $\mathrm{e}^{-x} < 1/(1+x)$，即 $\mathrm{e}^{x} > 1 + x$，这对一切 $x > 0$ 成立。
:::

搅拌釜更差，是因为混合把一些刚到来的食物直送出口，而另一些食物停留得远超所需。那么，草食动物为什么还要在大而混合充分的腔室里发酵？因为微生物发酵不是固定的酶反应：微生物本身必须被保留并必须生长，而一个不断有进料、混合均匀的釜能维持一个稳定的种群，去接种每一顿新的食物。Penry 与 Jumars 主张，当反应是自催化的（微生物消化正是如此）时，先 CSTR 后 PFR，即先发酵室后吸收管，给出最佳产率。这正是反刍动物的布局（瘤胃，然后小肠），也是后肠发酵者的布局，只是次序相反（小肠，然后盲肠与结肠），而次序本身自有后果，我们马上就会看到。

::: example 选择反应器 {#ex-reactor}
某底物按一级动力学消化，速率常数 $k = 0.20$ h⁻¹，肠段滞留时间为10 h。(a) 在推流式肠与搅拌釜式肠中各有多大比例被消化？(b) 若要消化90 %，两者各需要多长的滞留时间？(c) 若把搅拌釜分成两个等体积、混合充分、串联的腔室而总滞留时间不变，消化的比例是多少？
::: solution
(a) $k\tau = 2.0$。推流：$1 - \mathrm{e}^{-2.0} = 0.865$。搅拌釜：$2.0/3.0 = 0.667$。

(b) 推流：$\mathrm{e}^{-k\tau} = 0.10$，故 $\tau = \ln 10/0.20 = 11.5$ h。搅拌釜：$k\tau/(1+k\tau) = 0.90$，故 $k\tau = 9$，$\tau = 45$ h，长四倍，按同样的采食量就需要四倍容积的肠。

(c) 每个腔室 $k\tau_i = 1.0$，留下 $1/(1+1.0) = 0.5$ 的底物未被消化；串联后，剩下 $0.5^2 = 0.25$，消化了0.75。把搅拌釜分成串联的腔室会把它推近推流（一长串小釜串联*就是*一个推流式反应器）。反刍动物与袋鼠的多室胃，以及马那分袋（结肠带）的结肠，可能部分就是这样工作的。
:::
:::

## 草食动物与发酵

植物细胞壁主要由纤维素、半纤维素与木质素构成。多数动物无法用自己的酶消化纤维素：脊椎动物没有纤维素酶基因，而在多数消化木材或树叶的无脊椎动物中，这项工作部分或主要由共生微生物完成。（有些无脊椎动物，如白蚁、某些甲壳类与软体动物以及某些甲虫，能自己造纤维素酶；Hirofumi Watanabe 及其同事1998年证明，一种白蚁在唾液腺中产生内葡聚糖酶，但低等白蚁仍严重依赖后肠中的鞭毛原生生物。）草食性脊椎动物在肠道中被膨大、流动缓慢的区段里养着密集的细菌、古菌、原生生物与真菌种群，纤维在这里发酵。

::: definition 前肠发酵与后肠发酵 {#def-fermentation}
在**前肠发酵**中，发酵室位于酸性胃与小肠之前：反刍动物（牛、羊、鹿、羚羊）的瘤胃与网胃，骆驼、袋鼠、疣猴与树懒的多室胃，以及鸟类中独一无二的麝雉膨大的嗉囊（*Opisthocomus hoazin*；Alejandro Grajal 及其同事，1989年）。在**后肠发酵**中，发酵室位于小肠之后，是膨大的盲肠或结肠：马、犀牛、象、兔与许多啮齿类，以及许多草食性蜥蜴和鸟类。两者之中，微生物都以厌氧方式把碳水化合物发酵为**短链（挥发性）脂肪酸**，主要是乙酸、丙酸与丁酸，外加 CO₂ 与甲烷；宿主吸收这些脂肪酸并把它们氧化为主要燃料。
:::

反刍动物的安排有两个优点。食物先经发酵、再宿主自己消化，因此以发酵后的植物材料和来自宿主血液再循环的尿素等非蛋白氮生长的微生物本身，被冲进皱胃，即真正的酸性胃，以及小肠，作为优质蛋白被消化掉。而且反刍动物把纤维性的食团反呕回口中重新咀嚼，减小颗粒大小，大大加快发酵；网胃中的一个分选装置只让磨得细的颗粒离开，于是粗纤维被留驻直到被消化。在牛和羊，短链脂肪酸供应动物所需能量的大部分，按 E. N. Bergman 的综述（1990年）约为70 %，而脑和乳糖（奶糖）用的葡萄糖必须由肝脏以丙酸为原料经糖异生制造。前肠发酵的代价之一是微生物把易消化的糖和蛋白质也发酵掉了，浪费了宿主本可直接吸收的能量与氨基酸，而且有些能量以甲烷形式损失。

后肠发酵者先用自己的酶消化容易获得的养分，然后发酵剩下的纤维。它们随粪便丢掉微生物蛋白，除非把它吃掉。兔与许多啮齿类实行**食粪行为**（caecotrophy）：盲肠产出富含微生物的软粪（盲肠软粪），直接从肛门吃下并消化，从而收回蛋白与 B 维生素。马不这样，但以高采食量补偿：马处理粗饲料很快，每千克提取较少但吃进更多千克，能在劣到反刍动物无法利用的牧草上繁衍生息，而反刍动物缓慢的选择性留驻限制了它的采食量。

::: warning "草食动物用自己的酶消化草"与"肠越长消化就越多"
没有一种脊椎动物造纤维素酶：牛从草中得到的能量来自它的微生物，后者发酵纤维素并把发酵产物留给牛。失去了微生物群落，反刍动物会面对草饿死。第二个误解是，更长的肠或更久的滞留总意味着更多的营养。对给定的肠道容积，滞留更久意味着 处理速度更慢，因而能吃的食物更少；[[#prop-reactors]] 表明，单位食物的产率随滞留时间上升但收益递减，而采食量下降。最佳滞留时间是一个取决于食物的折中：易消化的食物最好快速处理，食蜜鸟把食物留驻的时间以分钟计，而不是以天计。
:::

### 体型与食物品质

大型草食动物吃的食物比小型的差。象、犀牛与水牛吃粗糙的草和嫩枝叶；犬羚之类的小型羚羊挑选芽、果与嫩叶；最小的哺乳类草食者，田鼠与兔，或者同样挑剔，或者依赖食粪行为。这一格局，**Jarman–Bell 原则**（得名于 Peter Jarman 与 Richard Bell 在1960年代和1970年代对非洲羚羊的研究），有一个异速生长的解释。

::: proposition 滞留时间与体型（Demment 与 Van Soest） {#prop-jarman-bell}
若发酵室的容积与体重按等生长标度，$V \propto M^{1.0}$，而采食速率按代谢需求标度，$Q \propto M^{3/4}$（[[animal-physiology/energy-metabolism]]），则平均滞留时间按

$$
\tau = \frac{V}{Q} \propto M^{1/4}.
$$ {#eq-retention}

因此，较大的草食动物把每份食物留得更久，能更完全地发酵难消化的纤维，并能忍受品质较低的食物；小型草食动物必须挑选能被快速消化的食物。这一论证（M. W. Demment 与 P. J. Van Soest，1985年）建立在经验指数之上，而指数在类群之间有所不同；实测的肠道容量接近以 $M^{1.0}$ 标度，实测滞留时间随体型上升，尽管在某些数据集中比 $M^{1/4}$ 更弱。
:::

::: example 不同体型的滞留时间 {#ex-retention}
一只5 kg 的草食动物平均把纤维留在肠中20 h。用 [[#eq-retention]] 估计一只几何相似的500 kg 草食动物的滞留时间。若纤维在混合充分的腔室中以 $k = 0.05$ h⁻¹ 发酵，两者各消化多大比例？
::: solution
滞留时间按 $(500/5)^{1/4} = 100^{1/4} = 3.16$ 标度，故 $\tau \approx 63$ h。用 [[#eq-reactors]] 的搅拌釜结果：小型的 $k\tau = 1.0$，$X = 0.50$；大型的 $k\tau = 3.16$，$X = 3.16/4.16 = 0.76$。大型动物从同样的纤维中多提取一半，这就是它能靠小型动物不能吃的食物活命的原因。
:::
:::

## 收支、效率与消化的代价

食物中的能量并非全部变得可供动物利用。生理学家如下划分它。

::: definition 取食的能量收支 {#def-energy-budget}
摄入的**总能** $I$ 中一部分随粪（$F$）损失，于是 $I - F$ 为**可消化能**（同化能）；比值 $(I - F)/I$ 是**表观消化率**，或同化效率。可消化能中，一部分随尿（$U$，以尿素、尿酸及其他含氮废物的形式）损失，在发酵动物还有一部分以可燃气体（$G$，主要是甲烷）损失，剩下**代谢能** $I - F - U - G$。代谢能花在维持（包括摄食产热增量）、活动、体温调节、生长与繁殖上。
:::

食肉的肉食者同化效率常见为80–95 %；草食动物从粗牧草上约30 %到种实或果实上的80 %不等；碎屑食者往往更低。消化本身消耗能量：一顿饭之后，代谢率会升高数小时乃至数天，即**食物特殊动力作用**（SDA），或称摄食产热增量，它反映消化、吸收、尤其是合成蛋白质与储存养分的代价。SDA 通常占一顿饭能量的10–30 %，以蛋白质为最高。

::: example 绵羊的能量收支 {#ex-budget}
一头羊一周吃下含400 MJ 总能干草。其粪含160 MJ，尿含15 MJ，嗳出的甲烷含24 MJ。(a) 计算它的表观消化率，以及代谢能占总能的比例。(b) 为提高饲喂效率你会瞄准哪种损失，怎么办？
::: solution
(a) 可消化能 $= 400 - 160 = 240$ MJ；表观消化率 $= 240/400 = 0.60$。代谢能 $= 240 - 15 - 24 = 201$ MJ，即占总能 $0.50$。(b) 最大的损失在粪中，即未消化的纤维；更好的牧草（木质素更少的嫩草）、秸秆的粉碎或化学处理、或更长的滞留，都会提高消化率。甲烷在这里占总能的6 %（典型值从几个到约10 %），既是能量损失也是温室气体；能抑制瘤胃中产甲烷古菌的饲料添加剂正因这一原因在接受试验。（数值为中等品质干草上绵羊的示意典型值。）
:::
:::

### 蟒的一顿饭

对取食反应最剧烈的，是那些很少进食的动物。Stephen Secor 与 Jared Diamond（自1995年起）发现，绝食一个月、然后吃下一只占自身体重四分之一的啮齿类的缅甸蟒（*Python bivittatus*，当时称 *P. molurus bivittatus*），代谢率升高一个数量级以上并持续数天。绝食期间保持小而闲置的小肠，在一两天内质量约增一倍，其吸收细胞膨胀、养分转运体增加许多倍；心、肝、肾也增大。消化结束后一切又缩了回去。两餐之间下调肠道，省下维持它的可观代价，而对频繁进食的哺乳类，这是一笔占静息代谢相当份额的开销；频繁进食的蛇反应要小得多。

::: example 蟒一顿饭的代价 {#ex-sda}
一条1.0 kg 的蟒吃下一只250 g、每克约含7 kJ 的大鼠。随后10天，它高于绝食率的额外 O₂ 消耗合计23 L。以每升 O₂ 合20.1 kJ，估计 SDA 占这顿饭能量的比例。
::: solution
餐食能量 $= 250 \times 7 = 1750$ kJ。SDA $= 23 \times 20.1 = 462$ kJ，占这顿饭的 $462/1750 = 0.26$。这顿饭的四分之一左右，恰好为它自己的消化与吸收付了账。（数值是蟒类大餐所测数量级的示意数字；蛇类的 SDA 系数通常为20–35 %。）
:::
:::

## 消化的控制

消化由神经与激素协调。**肠神经系统**是肠壁内的神经网络，它产生推动食物前行的收缩波（蠕动）与搅拌食物的混合运动，即使与脑断开也能工作。肠黏膜中的内分泌细胞释放的激素把这一区段与下一区段联系起来。在哺乳类，胃分泌的**胃泌素**刺激酸分泌；酸抵达时小肠释放的**促胰液素**刺激胰腺分泌碳酸氢盐；响应脂肪与蛋白而释放的**缩胆囊素**（CCK）刺激胰酶释放与胆囊收缩，并减慢胃排空。促胰液素正是第一个被发现的激素，由 William Bayliss 与 Ernest Starling 于1902年发现（[[animal-physiology/endocrine-control]]）。类似的肽也调控无脊椎动物的取食与消化；例如昆虫中肠就有内分泌细胞，分泌与脊椎动物速激肽和神经肽 F 相关的肽。

::: quiz
一只后肠发酵的草食动物与一头同体型的反刍动物吃同样的草。哪种说法最可能正确？
- [ ] 后肠发酵者消化每千克草中更多的纤维。
- [x] 反刍动物消化每千克中更多的纤维，但后肠发酵者每天能吃下更多千克。
- [ ] 两者都用自己肠细胞造的纤维素酶消化纤维素。
- [ ] 反刍动物无法利用微生物蛋白，因为微生物在小肠下游。
::: solution
反刍动物在瘤胃中选择性地留驻粗纤维并重新咀嚼，所以每千克提取更多，但缓慢的处理速度限制了采食量。后肠发酵者处理食物更快，每千克提取较少但吃得更多。两者都不造自己的纤维素酶。微生物位于小肠下游的是后肠发酵者，这就是兔要吃盲肠软粪的原因。
:::
:::

::: application 饲喂家畜与养活地球
反刍动物营养学是消化生理学最古老的应用之一。饲料配方在动物的能量与蛋白需求和其瘤胃微生物的需求之间求平衡；尿素等非蛋白氮可以添加进劣质牧草，因为微生物会把它变成蛋白。反刍动物的肠道甲烷是农业温室气体排放的相当一部分，减少它，靠日粮、靠抑制产甲烷菌的添加剂、靠育种，是一个活跃的研究领域。人类胃肠道及其疾病是 [医学图谱：消化系统与肝](/learn/medicine/course.php?c=gastrointestinal) 的主题。
:::

::: history
René Réaumur（1752年）让一只宠物鸢吞下装着肉、带孔的金属管，取回时肉已被部分消化；Lazzaro Spallanzani（1780年）用许多动物、也用自己重做了这些实验，证明消化是化学过程，而不仅是研磨或腐败。William Beaumont 自1822年起透过捕兽人 Alexis St Martin 的胃瘘观察消化，并于1833年发表其观察。Theodor Schwann 于1836年描述了胃蛋白酶。Ivan Pavlov 对犬消化分泌神经调节的研究为他赢得1904年诺贝尔生理学或医学奖，而 Bayliss 与 Starling 于1902年发现促胰液素，奠定了内分泌学。瘤胃微生物学的真正开端是 Robert Hungate 在1940年代和1950年代的厌氧培养方法。Penry 与 Jumars 于1986–87年把化学反应器理论应用于肠道，而 Secor 与 Diamond 在1990年代对蟒的工作使肠道可塑性成为消化生理学的中心课题。
:::

## 由此引向何处

被吸收的养分由循环系统运送（[[animal-physiology/circulation]]）；其中的氮最终进入排泄产物（[[animal-physiology/water-salt-balance]]）；其储存与动员受胰岛素、胰高血糖素及其他激素调控（[[animal-physiology/endocrine-control]]）。觅食的生态学，动物决定吃什么、去哪里吃的学问，在 [[behaviour/foraging]]；肠道的微生物群落见 [[microbiology/microbes-and-hosts]]。

::: summary
- 动物以悬浮、沉积、流体、吞食方式取食，或通过共生者取食；流体取食者常依赖微生物补足食物中缺失的养分。
- 消化是酶促水解，可在细胞内或细胞外；单向肠允许特化区段（酸性胃、中性肠、发酵室）。
- 蛋白酶以酶原分泌；刷状缘酶在转运体（SGLT1、GLUT5、GLUT2、PepT1）旁边完成消化；脂肪经胶束吸收、以脂蛋白输出。飞行的脊椎动物大量依赖细胞旁吸收。
- 当作反应器来看，同一滞留时间下推流式肠比搅拌釜式肠消化得更多，$1 - \mathrm{e}^{-k\tau}$ 对 $k\tau/(1+k\tau)$（[[#prop-reactors]]）；发酵室是先搅拌釜、后推流肠。
- 没有脊椎动物造纤维素酶：前肠与后肠发酵者依赖微生物并吸收短链脂肪酸；反刍动物还消化自己的微生物，兔吃盲肠软粪。
- 滞留时间大致按 $M^{1/4}$ 标度，所以大型草食动物能忍受更差的食物（Jarman–Bell 原则）。
- 总能、可消化能与代谢能之间的分界是粪、尿与甲烷的损失；食物特殊动力作用花掉一顿饭的10–30 %。
- 蟒之类很少进食的动物在两餐之间使肠道萎缩并重新生长。
:::

一只猫吃下含500 kJ 的食物，排出含75 kJ 的粪。它的表观消化率是多少？
::: solution
$(500 - 75)/500 = 0.85$。

::: exercise 滞留时间 {level=1 check="8"}
一个肠腔室容纳2.0 L 食糜，食糜以0.25 L h⁻¹ 流过它。平均滞留时间是多少小时？
::: solution
$\tau = V/Q = 2.0/0.25 = 8$ h。
:::

::: exercise 消化道与食性的匹配 {level=1}
对下列每种动物，说明你预期它是前肠发酵者、后肠发酵者，还是两者都不是，并给出一条生理理由：(a) 狮子；(b) 马；(c) 袋鼠；(d) 蜂鸟；(e) 兔。
::: solution
(a) 都不是：肉很容易被动物自己的酶消化，而狮子的肠短而简单。(b) 后肠（盲肠与结肠）：它先消化糖、淀粉与蛋白，之后发酵纤维，依赖高采食量。(c) 前肠：袋鼠有一个大的、管状多室的胃，纤维在其中发酵，与反刍动物趋同，尽管它反刍的方式不同。(d) 都不是：花蜜中的糖在小肠中被快速吸收，滞留时间短。(e) 后肠，且具食粪行为，能收回本会随粪流失的微生物蛋白与维生素。
:::
:::

::: exercise 推流消化至95 % {level=2 check="15"}
在推流式肠中，某底物按一级动力学消化，速率常数 $k = 0.20$ h⁻¹。要消化它的95 %需要多长的滞留时间（取整到小时）？
::: solution
$\mathrm{e}^{-k\tau} = 0.05$，故 $\tau = \ln 20/0.20 = 3.00/0.20 = 15$ h。
:::
:::

::: exercise 肠道容量的标度 {level=2}
草食哺乳动物的肠道容量近似按 $M^{1.0}$ 标度，代谢率按 $M^{0.75}$。(a) 证明肠道容量与每日能量需求之比按 $M^{0.25}$ 标度。(b) 一只20 kg 与一只2000 kg 的草食动物吃同样品质的食物。若采食量与能量需求匹配，大者能把食物留驻的时间长多少倍？(c) 若小型草食动物不得不吃劣质食物，它还有什么别的出路？
::: solution
(a) $M^{1.0}/M^{0.75} = M^{0.25}$。(b) $(2000/20)^{0.25} = 100^{0.25} = 3.2$ 倍长。(c) 它可以挑选植物中最易消化的部分（芽、种子、嫩叶、果实）；重新吃下自己的微生物产物（食粪行为）；解毒或避开大型动物能稀释掉的植物防御；或改吃包括昆虫在内的混合食性。它还可能降低代谢率，从而降低需求。
:::
:::

::: exercise 为什么要酸？ {level=2}
解释哺乳类酸性胃的三种功能，并设想为什么它在硬骨鱼和单孔类中被丧失了这么多次。你预测一个无胃的鱼会有什么生理后果？
::: solution
功能：(1) 酸使蛋白质变性，把它们展开以便蛋白酶作用；(2) 它把胃蛋白酶原激活为在低 pH 下工作最佳的胃蛋白酶；(3) 它杀死或抑制许多随食物吃进的微生物，充当抗感染的屏障；它还帮助把钙、铁等矿物质从食物中释放出来。这些丧失尚未得到充分解释；提出的理由包括：某些食性中酸消化带来的优势很小（小型无脊椎动物、植物性食物，或贝壳这类缓冲能力强的食物），造酸的代价高昂（需要 H⁺/K⁺-ATPase，而且酸之后还得用碳酸氢盐再中和），以及在胃很少被使用的谱系中基因的偶然丢失。无胃的鱼将完全依赖中性的 pH 下的胰蛋白酶与肠蛋白酶，在消化道起始段更慢地消化蛋白，并依赖其他防御来对付食物中的病原体。
:::
:::

::: exercise 解读一项饲喂实验 {level=2}
两组小鼠分别饲喂低纤维或高纤维日粮三周，两者每克能量含量相同。高纤维组多吃30 %的食物，实验结束时其小肠与盲肠更重。解释这两个发现，并预测若把高纤维组小鼠换回低纤维日粮会发生什么。
::: solution
高纤维食物消化率较低，所以小鼠必须多吃才能获得同样的代谢能；采食量随之代偿性增加（代偿性采食）。处理更多食物需要更大的吸收与发酵能力，于是肠道长大，这是一种可逆的驯化（肠道表型可塑性），与蟒的反应同类，只是更慢、更小。换回低纤维日粮后，采食量应在数天内回落到原水平，肠道应在数天到数周内缩回去，因为维持多余的肠组织代价不菲。
:::

::: exercise 两级串联混合室 {level=3}
(a) 证明 $n$ 个等体积、混合充分的腔室串联，总滞留时间 $\tau$、一级速率常数 $k$ 时，消化的比例为 $X_n = 1 - (1 + k\tau/n)^{-n}$。(b) 计算 $k\tau = 2$、$n = 1, 2, 5, 50$ 时的 $X_n$。(c) $n \to \infty$ 的极限是什么，它意味着什么？
::: hint
把 [[#prop-reactors]] 的搅拌釜结果逐个应用于每个腔室。
:::
::: solution
(a) 每个腔室的滞留时间为 $\tau/n$，把收到的底物中 $1/(1 + k\tau/n)$ 的比例以未消化形式传下去。串联时未消化比例相乘：$(1 + k\tau/n)^{-n}$，故 $X_n = 1 - (1 + k\tau/n)^{-n}$。(b) $n = 1$：$1 - 1/3 = 0.667$；$n = 2$：$1 - 1/4 = 0.750$；$n = 5$：$1 - 1.4^{-5} = 1 - 0.186 = 0.814$；$n = 50$：$1 - 1.04^{-50} = 1 - 0.141 = 0.859$。(c) 由于 $(1 + x/n)^{n} \to \mathrm{e}^{x}$，$X_n \to 1 - \mathrm{e}^{-k\tau} = 0.865$，即推流的结果。一根完全不混合的管，是无穷多个串联小搅拌釜的极限，化学工程师正是用这种方式为有若干混合的真实管式反应器建模的。
:::

::: exercise 吸血蝠的难题 {level=3}
一只30 g 的普通吸血蝠（*Desmodus rotundus*）一顿喝15 g 血液。血液约80 %是水，干物质主要是蛋白。(a) 为什么蝙蝠必须在还在吸血时就开始排水？(b) 高蛋白的食性给它的排泄系统出了什么难题？(c) 在不稳定的食物供应下，吸血生活为什么可能难以维系？（吸血蝠两三天吃不到血就可能饿死。）
::: solution
(a) 这顿饭让它的体重增加一半；蝙蝠必须能够飞离宿主，所以它迅速从胃与肠吸收水分，并在几分钟内产生大量稀尿，排出大部分血浆水。(b) 蛋白质被分解供能，产生大量需以尿素排出的氮，而排尿素要求浓缩尿液；所以在最初的稀尿性利尿之后，蝙蝠转而排出极浓的尿，在排出尿素的同时保水，它的肾必须应付这两个极端（[[animal-physiology/water-salt-balance]]）。(c) 血液中几乎没有可储存的脂肪或碳水化合物，而小型内温动物储备小、质量比代谢率高（[[animal-physiology/energy-metabolism]]），所以连着几晚吸不到血的蝙蝠就身处险境；野外研究显示，饱餐的吸血蝠常把反呕出的血与吸不到血、同栖的伙伴分享，这是互惠合作中被研究得很多的一个例子（[[behaviour/cooperation]]）。
:::
