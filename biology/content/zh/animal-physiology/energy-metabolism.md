一只4 g 的鼩鼱每天必须吃掉超过自身体重一半的昆虫；几个小时不进食，它就会被饿死。一头重它一百万倍的大象，每天却只吃体重的百分之几，而蟒蛇可以在两餐之间挨过数月。这些差别并不是某些物种的怪癖。它们源自生理学中最普遍的两个规律：维持体温的动物比不维持体温的动物消耗多得多的能量，而动物每克组织所消耗的能量随体型增大而稳定下降。

本章讨论动物使用能量的速率，即它们的**代谢率**，如何测量它，它如何依赖体重、温度与活动，以及运动要付出什么代价。细胞层面，ATP、呼吸链与燃料的能量产出，见 [[biochemistry/bioenergetics]] 与 [[biochemistry/oxidative-phosphorylation]]；能告诉我们正在燃烧哪种燃料的呼吸商，见 [[biochemistry/metabolic-integration#prop-rq]]。这里我们把整只动物当作一堆火，问这堆火有多大、为什么这么大。

## 代谢率的测量

代谢率是动物把食物化学能转化为热与外功的速率。在静息时，这些能量几乎最终全部变成热，因为线粒体制造的 ATP 被用于离子转运、蛋白质合成、心脏跳动等过程，而这些过程的能量终归耗散。由此得到三条测量途径。

- **直接量热法**测量动物散出的热。Antoine Lavoisier 与 Pierre-Simon Laplace 于1783年用冰量热计中的豚鼠做过这件事，称量融化冰所得的水；现代量热计测量流经绝热室壁的热流。直接量热法准确但缓慢而昂贵，如今主要用于校验其他方法。
- **间接量热法**（呼吸测定法）测量 O₂ 消耗速率 $\dot V_{\mathrm{O_2}}$ 或 CO₂ 产生速率 $\dot V_{\mathrm{CO_2}}$，再换算成能量。因为有氧代谢用 O₂ 氧化食物，而每升 O₂ 释放的热量在各种燃料之间差别很小，约为碳水化合物21.1 kJ、脂肪19.6 kJ、蛋白质18.7 kJ，所以混合膳食取**每升 O₂ 约20.1 kJ**，准确到几个百分点以内。同时测定呼吸商可进一步精化换算。
- **双标水**（doubly labelled water）法在数天以上的尺度上测量自由生活动物的 CO₂ 产生量。Nathan Lifson 及其同事在1955年证明，呼吸 CO₂ 的氧会与体水交换，因此若让动物饮用同时标记了氢的稳定重同位素（²H）与氧的重同位素（¹⁸O）的水，则 ¹⁸O 既随水又随 CO₂ 离开身体，而 ²H 只随水离开。两种同位素丢失速率之差就给出 CO₂ 的产生速率。

::: definition 代谢率的标准度量 {#def-bmr}
- 内温动物的**基础代谢率**（BMR）指其已成年、安静、处于吸收后状态（post-absorptive，未在消化食物）、不在生长或繁殖、处于正常不活动时段、并位于**热中性区**（在此气温区间内它无需为产热或主动散热多花能量）内的代谢率（[[animal-physiology/thermoregulation]]）。
- 外温动物的**标准代谢率**（SMR）指其在指定体温下的静息、吸收后代谢率（外温动物没有单一的热中性温度）。
- **自由生活代谢率**（FMR）指自由生活的动物在一天或更长时间内、连同一切活动的平均代谢率，通常用双标水法测定。
- **最大代谢率**指动物在运动（$\dot V_{\mathrm{O_2,max}}$）或受寒（顶点代谢）时所能达到的有氧代谢最高速率。最大代谢率与基础或标准代谢率之比称为**倍比有氧范围**（factorial aerobic scope）。
:::

这些定义之所以重要，是因为代谢率会随条件变化数倍，跨物种的比较只有在可比条件下才有意义。BMR 并不是一只动物所能达到的最低值，蛰伏与冬眠的动物远低于它，它只是一个标准化的参照点。

::: example 呼吸测定仪中的小鼠 {#ex-respirometry}
一只30 g 的小鼠在热中性区的流动式呼吸测定仪中安静休息。干燥、不含 CO₂ 的空气以500 mL min⁻¹ 的流量通过舱室（已校正到标准温度与压强）。O₂ 分数从入口的0.2095降到出口的0.2080。试估计 $\dot V_{\mathrm{O_2}}$、以瓦为单位的代谢率，以及以 W kg⁻¹ 计的质量比率。（忽略 RQ ≠ 1时出口流量与入口流量略有不同所要求的小修正。）
::: solution
$\dot V_{\mathrm{O_2}} = 500\ \mathrm{mL\,min^{-1}} \times (0.2095 - 0.2080) = 500 \times 0.0015 = 0.75$ mL O₂ min⁻¹，即45 mL h⁻¹（1.5 mL O₂ g⁻¹ h⁻¹）。

代谢率 $= 0.75\ \mathrm{mL\,min^{-1}} \times 20.1\ \mathrm{J\,mL^{-1}} / 60\ \mathrm{s\,min^{-1}} = 0.25$ W。

质量比率 $= 0.25\ \mathrm{W} / 0.030\ \mathrm{kg} = 8.4$ W kg⁻¹。一个静息的人约产生80 W，即约1.1 W kg⁻¹：按每克算，小鼠的燃烧快约七倍。本章余下的内容就在回答为什么。
:::
:::

## 内温动物与外温动物

代谢率的第一个大分野在**内温动物**，即哺乳类与鸟类，它们主要靠代谢产生的热把自己的体温维持在又高又稳的水平，与**外温动物**，即几乎所有其他动物，其体温主要由环境决定。在相同体重、相同体温下，哺乳类或鸟类的静息代谢率约为蜥蜴的五到十倍（A. F. Bennett 与 J. A. Ruben，1979年）。内温动物持续付出这一代价，以外温动物不必寻找的食物为形式。其热学后果是 [[animal-physiology/thermoregulation]] 的主题；这里只记下能量学的后果：一只30 g 的蜥蜴可以靠一只30 g 小鼠一天烧掉的量活上几个星期，而且外温动物把所同化食物中大得多的比例转化为生长与后代。

外温动物的代谢率强烈依赖体温。在动物通常经历的温度范围内，温度每升高10 °C，代谢率通常增至两到三倍，这一比值称为 **Q₁₀**（其数量处理见 [[animal-physiology/thermoregulation]]）。因此外温动物之间的比较必须始终注明温度。

## 异速生长：速率如何随体型标度

动物的体重横跨二十多个数量级，从一微克的轮虫到超过100吨的蓝鲸。在这一整个跨度上，几乎所有生理变量，代谢率、心率、肺容积、寿命、肠道长度，都以规则的方式随体重变化，而这种规则性可以用幂律来刻画。

::: proposition 异速生长方程 {#prop-allometry}
若变量 $Y$ 与体重 $M$ 满足

$$
Y = a\,M^{b},
$$ {#eq-allometry}

则称其呈**异速生长**，其中 $a$（**系数**，或归一化常数）与 $b$（**指数**）对某一给定动物类群为常数。取对数，

$$
\log Y = \log a + b\,\log M,
$$ {#eq-loglog}

所以在双对数坐标上这一关系是斜率为 $b$、截距为 $\log a$ 的直线。若 $b = 1$，$Y$ 与 $M$ 成正比（**等生长**，isometry）；若 $b < 1$，$Y$ 的增长不及与 $M$ 成正比，且 $Y/M$ 随体型下降；若 $b > 1$，$Y$ 的增长快于 $M$。

这是一种统计描述，不是自然定律。指数由 $\log Y$ 对 $\log M$ 的回归估计，其数值取决于纳入了哪些物种、如何取样以及回归方法；$a$ 的单位取决于 $b$（$Y$ 以瓦计、$M$ 以千克计时为 W kg⁻ᵇ）。
:::

双对数形式解释了异速生长分析为何有用。在体重相差百万倍的跨度上，指数的小差别会造成预测的大差别，而对数图能让小鼠与大象以同等分量出现在同一张图上。异速生长分析与幂律拟合在数学上的展开见 [Maths Atlas](/learn/maths/)；这里集中讨论指数的含义。

### 表面积法则

对小动物每克代谢率高这一现象，最古老的解释是几何的。若大小不同的动物形状相同，则每个长度都按 $M^{1/3}$ 标度（因为体积，从而恒定密度下的质量，按长度的三次方标度），每个面积都按 $M^{2/3}$ 标度。

::: proposition 几何相似体的表面积 {#prop-surface}
对形状与密度都相同的一族物体，表面积 $S$ 与体重 $M$ 满足

$$
S = k\,M^{2/3},
$$ {#eq-surface}

其中 $k$ 只依赖形状。于是单位质量的表面积 $S/M = k\,M^{-1/3}$ 随体型增大而下降：一个重1000倍的身体，表面积是100倍，而每克体重的表面只有十分之一。
:::

::: proof
令 $L$ 为任一特征长度（比如体长）。对固定形状，体积 $V = c_1 L^3$、表面积 $S = c_2 L^2$，$c_1, c_2$ 为常数。设密度为 $\rho$，则 $M = \rho c_1 L^3$，故 $L = (M/\rho c_1)^{1/3}$，且 $S = c_2 (\rho c_1)^{-2/3} M^{2/3}$。
:::

内温动物经体散失热量。如果它必须以正比于体表面积的速率补充热才能维持体温，那么它的代谢率就应当按 $M^{2/3}$ 标度。这就是**表面积法则**，1830年代被提出，并得到 Max Rubner 1883年对不同品种犬的测量的支持：按每平方米体表面积计，这些狗产热几乎相同。

### Kleiber 法则

Max Kleiber 于1932年汇编从大鼠到阉牛各型哺乳动物的基础代谢率时，发现斜率比表面积法则预测的更陡：接近3/4。Samuel Brody 的“小鼠到大象曲线”（1945年）与后来的许多汇编给出相近的数值；1960年 August Hemmingsen 证明，单细胞生物、外温动物与内温动物各自遵循斜率相近的直线，而内温动物高出约一个数量级。这一关系在 [[biochemistry/bioenergetics#prop-kleiber]] 中引入：对哺乳类 $B \approx 3.4\,M^{3/4}$ W，$M$ 以千克计。

::: proposition 四分之三次方标度的推论（经验） {#prop-kleiber-consequences}
若整体代谢率按 $B = a M^{3/4}$ 标度，则

- **质量比代谢率**按 $B/M = a M^{-1/4}$ 标度：质量增大10,000倍，每克的速率降到十分之一；
- 按体重固定比例储存的物质（如给定肥度下的脂肪）可维持的时间正比于 $M/M^{3/4} = M^{1/4}$；
- 经验上，许多生物时间的标度接近 $M^{1/4}$、许多速率的标度接近 $M^{-1/4}$，心率、呼吸频率、血液走完一圈的时间、最长寿命都是如此，于是非常粗略地说，无论体型大小，一只哺乳动物的一生所经历的心跳次数相近。

这些只是散布相当大的数据的规律性，不是定律的推论。它们的指数带有不确定性，且在类群之间不同。
:::

::: solution

### 为什么是四分之三？一个未决问题

表面积法则预测2/3，而来自许多汇编的数据给出约3/4，这就要求一种解释。影响最大的一种由 Geoffrey West、James Brown 与 Brian Enquist（1997年）给出：他们从层次化、空间填充的供应网络（如血管与气道）的几何出发导出3/4，这类网络的终端单元（毛细血管）在所有动物中大小相同，且使泵送流体所需的能量最小。该理论很优雅，但它的若干假设已经受到质疑，数据本身也有争议。对大型数据集的重新分析，小心地只采用真正基础的测量并计入体温与系统发育，得到的哺乳类指数更接近2/3（Craig White 与 Roger Seymour，2003年，得到0.686），而且各群体的指数互不相同：鸟类、哺乳类、爬行类、鱼类、昆虫与植物并不共享单一数值，小型与大型哺乳动物的标度也不同。Douglas Glazier（2005，2010年）汇集证据表明，指数介于约2/3与1之间，取决于活动水平与生活方式，极不活动动物的静息代谢率更接近1，而高度活跃的内温动物更接近2/3；他提出，指数反映的是受表面限制的过程（热、养分与废物的交换）与受体积限制的过程（组织维持与功率生产）之间的平衡。

不容争议的是模式本身：代谢率的上升不及与质量成正比，在多数数据集中指数介于约0.65与0.85之间，因此小动物每克的代谢率高得多。确切的数值是多少、是否存在某个单一数值可以称为“那个”指数，仍是活跃的研究问题。最大代谢率的标度比基础代谢率更陡，哺乳类的指数接近0.9（E. R. Weibel 及其同事，2004年），所以有氧范围倾向于随体型增大。

::: warning "Kleiber 法则是一条物理定律"
Kleiber 的四分之三次方关系是一条经验规律：一条拟合过散布数据的直线。它不像表面积法则由几何导出那样由第一性原理导出，而凡是试图导出它的理论都依赖存争议的假设。它的指数在类群之间、在静息与活动状态之间、甚至同一类群内部的小型与大型动物之间都在变化。把它当作对数量级有用的经验法则（它能在约两倍的因子内预测多数哺乳动物的 BMR），而不是精确定律；也不要因为某个物种落在通常的散布范围之内，就借它来论证这个物种“反常”。
:::

### 种内与种间

异速生长指数通常在物种**之间**估计（种间标度）。在物种内部，随着个体生长或成体本身体型有异，指数往往不同，并在不同发育阶段之间也可能不同。把种间斜度读成一句因果陈述，即“把一只给定动物做大些会怎样”，同样危险：直线两端的物种除体型外还有许多不同，而且它们共享的演化历史并不均匀（[[animal-physiology/homeostasis#ex-phylogeny]]）。现代分析因此使用系统发育回归。

异速生长分析也是识别例外的工具。某个物种远高于其体型应有的直线，说明它在做能量上昂贵的事。鼩鼱、蜂鸟和许多小型有袋类的代谢率在哺乳类直线之上；面对食物与缺水荒漠的哺乳动物，以及在地下冒着过热风险掘洞的哺乳动物，倾向于落在直线之下。Brian McNab 数十年来一直主张，哺乳动物 BMR 残差变化的大部分与食性、气候和习性有关，而不仅与分类地位有关。

::: example 鼩鼱必须吃多少？ {#ex-shrew}
一只4.0 g 的鼩鼱的自由生活代谢率为 Kleiber 预测值的三倍。它以每克湿重含7.0 kJ 的昆虫为食，并同化其中的85 %。(a) 它每天必须吃多少？(b) 它的质量比代谢率比一只按同一关系的4.0 kg 哺乳类高多少倍？(c) 若脂肪占其体重的5 %（能量含量39 kJ g⁻¹）而它维持同样速率，它的脂肪储备能支撑多久？
::: solution
(a) Kleiber BMR $= 3.4 \times 0.0040^{3/4} = 3.4 \times 0.0159 = 0.054$ W。FMR $= 3 \times 0.054 = 0.162$ W，即 $0.162 \times 86\,400 = 14.0$ kJ 每天。所需食物 $= 14.0 / (7.0 \times 0.85) = 2.4$ g 昆虫每天：占其体重的59 %。

(b) 质量比速率按 $M^{-1/4}$ 标度，所以比值为 $(4.0/0.0040)^{1/4} = 1000^{1/4} = 5.6$。

(c) 脂肪 $= 0.05 \times 4.0 = 0.20$ g，含 $0.20 \times 39 = 7.8$ kJ，够维持 $7.8/14.0 = 0.56$ 天，约13小时。小型内温动物生活在饥饿的边缘；许多鼩鼱与小型鸟类之所以能熬过寒冷的夜晚，靠的是进入蛰伏（[[animal-physiology/thermoregulation]]）。
:::
:::

## 活动的能量代价

### 有氧与无氧代谢

活动使代谢率升到静息水平之上。只要额外的 ATP 由氧化磷酸化制造，O₂ 消耗就与输出功率成正比地上升，活动就能持续。一旦超过**最大有氧代谢率**，额外的功率就必须来自无氧来源：肌肉的磷酸原储备（脊椎动物为磷酸肌酸，许多无脊椎动物为磷酸精氨酸；[[biochemistry/bioenergetics#def-phosphagen]]）以及生成乳酸的无氧糖酵解。无氧代谢能快速交付 ATP 却不能持久，而且留下善后的麻烦：运动之后，在磷酸原重新合成、乳酸被清除期间，O₂ 消耗继续升高（运动后过量氧耗，曾称“氧债”）。

动物在两者如何搭配上彼此不同。许多爬行类与两栖类在爆发活动中严重依赖无氧糖酵解：一只追猎物的蜥蜴可能把大部分 ATP 无氧地产生出来，随后需要许多分钟来恢复，而一只同体型的小型哺乳动物本可以有氧地维持同样的速度。Bennett 与 Ruben（1979年）主张，哺乳类与鸟类内温性的演化是由对持续有氧活动的选择驱动的，这要求高的最大有氧速率，而高静息代谢率是随之而来的。另一些假说强调亲代抚育，或强调温暖身体的好处本身；内温性的起源仍在争论。

::: definition 运输代价 {#def-cot}
**运输代价**（cost of transport）指动物把单位体重的身体移动单位距离所消耗的代谢能，通常以 J kg⁻¹ m⁻¹ 表示（或作为功率与重量乘以速度之比的无量纲数）。**净**（或增量）运输代价扣除静息代谢率，只计运动带来的额外能量。对给定的运动方式与体重，**最小**运输代价在单位距离能耗最低的那个速度上取得。
:::

让不同体型的奔跑哺乳动物在跑台上受试，它们的 O₂ 消耗随速度线性增加，于是净运输代价，即代谢率对速度这条线的斜率，对每只动物都与速度无关。Richard Taylor、Norman Heglund 与 Geoffrey Maloiy（1982年）从小鼠到马各物种测定了它，发现它随体型急剧下降。

::: proposition 奔跑的净运输代价（经验） {#prop-cot}
对奔跑的哺乳类与鸟类，净运输代价近似为

$$
C = 10.7\,M^{-0.316}\ \ \mathrm{J\,kg^{-1}\,m^{-1}},
$$ {#eq-cot}

其中 $M$ 以千克计（Taylor、Heglund 与 Maloiy，1982年）。它是对体重约20 g 至250 kg 动物的跑台数据的经验拟合，描述的是稳定的、有氧可支撑速度下的平地奔跑。
:::

::: example 小鼠与马赛跑 {#ex-cot}
用 [[#eq-cot]] 计算一只30 g 小鼠与一匹500 kg 的马的净运输代价，以及它们各跑1 km 额外消耗的能量。各会烧掉多少克脂肪（39 kJ g⁻¹）？这各占其体重的百分之几？
::: solution
小鼠：$C = 10.7 \times 0.030^{-0.316} = 10.7 \times 3.03 = 32.4$ J kg⁻¹ m⁻¹。跑1 km：$32.4 \times 0.030 \times 1000 = 972$ J $\approx 0.97$ kJ，即 $0.97/39 = 0.025$ g 脂肪，占体重的0.083 %。

马：$C = 10.7 \times 500^{-0.316} = 10.7 \times 0.140 = 1.50$ J kg⁻¹ m⁻¹。跑1 km：$1.50 \times 500 \times 1000 = 751$ kJ，即 $751/39 = 19$ g 脂肪，占体重的0.0039 %。

按每千克体重算，小鼠走完同样的路要付出约22倍的代价。大型动物相对自己的储备可以几乎不计成本地远行，这正是陆地上的长距离迁徙者多为大型哺乳动物、而小动物必须在近处觅食的原因之一。
:::
:::

为什么小型动物每千克的奔跑代价高得多？不是因为它的肌肉把 ATP 转化为功的效率更低，而是因为它走完给定距离需要迈更多、更快的步子，而肌肉产生力的代价取决于力必须多快被接通与断开。Taylor 及其同事证明，奔跑的代谢代价粗略地正比于体重除以每只脚与地面接触的时间；小动物触地时间短，因此不得不使用快速而不经济的肌纤维类型（[[animal-physiology/muscle-movement]]）。肌腱的弹性储能在大型动物身上进一步降低代价：在一项经典实验中，Terence Dawson 与 Taylor（1973年）发现，红袋鼠（*Osphranter rufus*，当时称 *Megaleia rufa*）的 O₂ 消耗在跳跃速度超过约2 m s⁻¹ 之后不再上升。

### 游泳、飞行与奔跑

Knut Schmidt-Nielsen（1972年）比较了游泳、飞行与奔跑动物的最小运输代价。在任何给定体重下，游泳是最省力的出行方式，飞行居中，奔跑最贵。鱼在水中几乎失重，不必支撑自己，其代价就是克服阻力那部分；飞行的鸟必须以空气动力支撑体重，但它推进得极快；奔跑者每一步都要让自己的身体减速再加速、四肢来回摆动，能量就在这一过程中流失。在每种方式内部，每千克的代价随体型下降。因此一条溯河数百千米的鲑和一只跨海的雁，每千克每千米的花费都比一只穿田而过的小鼠低。

::: quiz
两只哺乳动物，一只10 g，一只10 kg，各在自己喜欢的速度下在跑台上奔跑。哪种说法最可能正确？
- [ ] 两者每千克每千米用同样的能量，因为两者的肌肉效率相同。
- [x] 小型哺乳动物每千克每千米要用好几倍的能量。
- [ ] 大型哺乳动物每千克每千米用更多能量，因为它要移动的质量更大。
- [ ] 小型哺乳动物每千米的总能量与每千克能量都更少。
::: solution
净运输代价随质量按约 $M^{-0.32}$ 下降（[[#prop-cot]]），所以质量相差1000倍，每千克每米的代价就相差 $1000^{0.316} \approx 9$ 倍。就每千米的*总*能量而言，大型动物花得多（它有1000倍的质量，但每千克代价只有约1/9）；而按每千克算，小型动物付得多。
:::
:::

## 野外的能量收支

实验室测量描述动物*能够*做什么；双标水法测量它实际做了什么。Kenneth Nagy 及其同事汇编了数百种哺乳类、鸟类与爬行类的自由生活代谢率。自由生活代谢率随体重的标度指数与基础代谢率相近，内温动物通常是 BMR 的两到四倍。动物数周尺度上所能维持的能量似乎存在上限：在最卖力的动物与人身上，哺乳期的鼠、育雏的鸟、环法自行车赛中的车手，持续支出极少超过约四到五倍 BMR（C. C. Peterson、K. A. Nagy 与 J. Diamond，1990年；K. A. Hammond 与 J. Diamond，1997年）。这一极限是由肠道与肝脏处理食物的能力、组织利用食物的能力，还是散发所产热的能力设定的，尚在争论，而且可能因物种而异。

::: example 小型鸟类体内的双标水 {#ex-dlw}
一只50 g 的鸣禽有33 g 体水。注射双标水之后，¹⁸O 的分数丢失率为每天0.70，²H 的为每天0.50。(a) 用简化关系 $\dot n_{\mathrm{CO_2}} = \tfrac{N}{2}(k_\mathrm{O} - k_\mathrm{H})$ 估计它的 CO₂ 产生量，其中 $N$ 为以摩尔计的体水，$k$ 为分数周转率。(b) 设 RQ = 0.80、每升 O₂ 合20.1 kJ（标准状况下气体为22.4 L mol⁻¹），以瓦估计它的自由生活代谢率。(c) 与 Kleiber 对 BMR 的预测比较。
::: solution
(a) $N = 33/18.0 = 1.83$ mol。因子 $1/2$ 的出现是因为每个 CO₂ 携带两个氧原子。$\dot n_{\mathrm{CO_2}} = 0.917 \times (0.70 - 0.50) = 0.183$ mol 每天 $= 0.183 \times 22.4 = 4.1$ L CO₂ 每天。

(b) O₂ 消耗 $= 4.1 / 0.80 = 5.13$ L 每天；能量 $= 5.13 \times 20.1 = 103$ kJ 每天 $= 103\,000/86\,400 = 1.19$ W。

(c) Kleiber：$3.4 \times 0.050^{3/4} = 0.36$ W。FMR 为哺乳类 Kleiber BMR 的3.3倍。（小型鸣禽的 BMR 略高于哺乳类直线，所以与它自己的 BMR 相比倍数会低些，约2–3倍。实际使用中的完整方程包含蒸发伴随的同位素分馏的校正，与呼吸测定法校验相符时，可靠到约5–10 %以内。）
:::
:::

::: application 保护与农畜业中的能量学
异速生长关系让生态学家能估计无法直接测量的动物的食物需求：一群海鸟必须捕食多少鱼、一群羚羊需要多大的放牧地、一处保护区能否养活一个大型捕食者的种群。在畜牧饲养中，Kleiber 与 Brody 引入的“代谢体重”$M^{0.75}$ 至今仍用于给不同体型的家畜折算维持饲料量与药物剂量；人类中的相应做法是 [医学图谱：药理学](/learn/medicine/course.php?c=pharmacology) 的内容。
:::

::: history
Lavoisier 与 Laplace 于1783年用冰量热计里的豚鼠证明，动物的热出自缓慢的燃烧。1839年 Pierre Sarrus 与 Jean-François Rameaux 提出产热应按表面积标度，Max Rubner 对犬的测量（1883年）似乎证实了表面积法则。Francis Benedict 等在二十世纪初发展了呼吸量热计。Max Kleiber（1932年）与 Samuel Brody（1945年）确立了哺乳类的四分之三次方关系，August Hemmingsen（1960年）把它推广到单细胞生物与外温动物。Nathan Lifson 于1955年引入双标水法，开启了野外能量学。Knut Schmidt-Nielsen 于1972年比较了游泳、飞行与奔跑的代价，Taylor、Heglund 与 Maloiy 于1982年测定了从小鼠到马的奔跑代价。West、Brown 与 Enquist 的网络理论（1997年）与其后的重新分析，使标度指数至今仍是活跃的研究课题。
:::

## 由此引向何处

代谢率设定了每个供应系统必须满足的需求：产热与散热在 [[animal-physiology/thermoregulation]]，食物在 [[animal-physiology/feeding-digestion]]，氧在 [[animal-physiology/gas-exchange]] 与 [[animal-physiology/circulation]]。异速生长的思想将在这每一章中重现，因为鳃、肺、心脏与肠道都必须随它们所服务的需要而标度。生态学后果，种群密度、家域与能量沿食物网的流动，见 [[ecology/ecosystem-energetics]]。

::: summary
- 代谢率可由直接量热法测定，由呼吸测定法测定（每升 O₂ 约20.1 kJ），在野外由双标水法测定。
- BMR（内温动物，热中性，静息，吸收后）、SMR（外温动物，指定温度）、FMR 与最大代谢率是标准化的度量；它们的比值给出有氧范围。
- 同体型、同体温下，内温动物的静息代谢率约为外温动物的五到十倍。
- 生理变量按 $Y = aM^b$ 随体重标度，在双对数坐标上是一条直线（[[#prop-allometry]]）。
- 几何相似预测表面积 ∝ $M^{2/3}$；实测代谢指数大多介于约0.65与0.85之间（Kleiber 的3/4是经验值，其解释悬而未决）。
- 质量比代谢率随体型下降（指数为3/4时 $\propto M^{-1/4}$），生物时间大致按 $M^{1/4}$ 拉长。
- 奔跑每千克每米的净代价按约 $M^{-0.32}$ 下降；游泳最省，奔跑最贵，飞行居中。
- 野外的持续能量支出极少超过约四到五倍 BMR。
:::

## 习题

::: exercise 由氧到瓦 {level=1 check="5.03"}
一只静息动物每分钟消耗0.25 L O₂。按每升20.1 kJ，它的代谢率是多少 kJ 每分钟？（三位有效数字）
::: solution
$0.25 \times 20.1 = 5.03$ kJ min⁻¹（84 W），一个成年人的静息代谢率。
:::
:::

::: exercise 每克表面积 {level=1 check="0.1"}
两只动物形状相同，一只体重是另一只的1000倍。大者单位质量的表面积是小者的多少倍？
::: solution
$S/M \propto M^{-1/3}$，所以倍数为 $1000^{-1/3} = 0.1$：每克的表面只有十分之一。
:::
:::

::: exercise 质量比速率 {level=1 check="10"}
若代谢率按 $M^{3/4}$ 标度，一只20 g 小鼠的质量比代谢率是一只200 kg 动物的多少倍？
::: solution
质量比 $200/0.020 = 10^4$；质量比速率 $\propto M^{-1/4}$，所以倍数为 $(10^4)^{1/4} = 10$。
:::
:::

::: exercise 由两点定指数 {level=2 check="0.69"}
一只0.10 kg 哺乳动物的 BMR 为0.75 W，一个有亲缘关系的100 kg 物种为87 W。设二者同处一条异速生长直线上，估计指数 $b$（两位有效数字）。为什么由两个物种估计的指数不可靠？
::: solution
$b = \log(87/0.75)/\log(100/0.10) = \log 116 / \log 1000 = 2.064/3 = 0.69$。两点恰好决定一条直线，所以任一物种偏离该类群真实关系的部分，而多数物种偏离达百分之几十，都会直接进入指数。某一 BMR 的30 %误差会使 $\log B$ 改变约0.11，使指数改变约0.04。可靠的指数需要在很宽的体重范围上取许多物种，并对系统发育加以考虑。
:::
:::

::: exercise 一生的心跳 {level=2}
在哺乳类中，静息心率近似按每分钟 $241\,M^{-0.25}$ 次标度，最长寿命近似按 $11.6\,M^{0.20}$ 年标度（$M$ 以千克计；W. A. Calder 等人发表过的那类经验拟合）。(a) 计算一只0.03 kg 小鼠与一头3000 kg 大象在最长寿命内的心跳总数。(b) 这一结果说明了什么，这个论证有何局限？
::: solution
(a) 小鼠：心率 $= 241 \times 0.03^{-0.25} = 241 \times 2.40 = 579$ min⁻¹；寿命 $= 11.6 \times 0.03^{0.20} = 11.6 \times 0.496 = 5.8$ 年。心跳数 $= 579 \times 60 \times 24 \times 365 \times 5.8 = 1.8\times10^9$。大象：$241 \times 3000^{-0.25} = 241 \times 0.135 = 32.6$ min⁻¹；寿命 $= 11.6 \times 3000^{0.20} = 11.6 \times 4.96 = 57$ 年；心跳数 $= 32.6 \times 525\,600 \times 57 = 9.8\times10^8$。(b) 尽管质量相差100,000倍，这两个数字只相差两倍以内，与生物时间以相近指数标度的观察一致。但两个指数不同（0.25与0.20），所以乘积并不严格恒定；这些拟合描述的是圈养条件下的最长寿命，而不是一般的一生；而蝙蝠、鸟类与人类的寿命远超其体重的预测。“固定次数的心跳”是一个好记的近似，不是机制。
:::
:::

::: exercise 解读残差 {level=2}
一只100 g 的啮齿类荒漠居民的实测 BMR 为0.30 W。哺乳类关系 $B = 3.4\,M^{0.75}$ 预测多少？把实测值表示为预测值的百分比，并就差异提出两个假说以及如何检验它们。
::: solution
预测值 $= 3.4 \times 0.10^{0.75} = 3.4 \times 0.178 = 0.60$ W；实测值为其50 %。假说：(1) 低 BMR 是对荒漠食物或水匮乏的适应，减少食物需求与呼吸失水；(2) 它是该啮齿类血统的特征，与非荒漠的近缘类群共有。用比较来自荒漠与湿润生境的相关物种的 BMR 来检验 (1) 对 (2)（系统发育独立对比，[[animal-physiology/homeostasis#ex-phylogeny]]）；把荒漠物种的动物适应于充足的食物与水之后重新测量以检验可塑性；并核查该测量确实是基础值（热中性、吸收后、不活动时段），因为在热中性区之下测量只会给出更高的值，而不是更低的值。
:::
:::

::: exercise 游泳与行走 {level=2}
一头100 kg 的海豹与一只100 kg 的鹿各行进50 km。不借助详细方程，说明谁在运动上花得更少、为什么，以及各要克服哪种物理代价。
::: solution
海豹花得少。在水中它接近中性浮力，不必支撑体重，其代价就是克服阻力那部分，在中低速度与流线型身体下这部分很小。鹿必须支撑体重，且每一步都要让身体减速再加速、摆动四肢；肌腱会回收其中一部分能量，但大量以热的形式在肌肉中散失。Schmidt-Nielsen 的比较（1972年）表明，在同一体重下，游泳的最小运输代价大致比奔跑低一个数量级。（海豹还付出别的代价，如在水中保温，但那不属于运动。）
:::
:::

::: exercise 关于禁食的标度论证 {level=3}
设哺乳动物的脂肪储备按等生长标度（$F = f M$），且禁食期间代谢率维持在 BMR 的固定倍数上，$B = 3.4\,M^{0.75}$ W。(a) 证明禁食耐受时间按 $M^{1/4}$ 标度。(b) 一只含脂10 %的30 g 小鼠，在其禁食代谢率下靠脂肪大约能活1.4天；同样肥度的一头3000 kg 动物能活多久？(c) 用你的结果讨论：为什么只有大型哺乳动物才能不靠蛰伏越冬，而小型冬眠者必须把代谢率降到远低于 BMR。
::: solution
(a) 耐受时间 $= fM/(cM^{0.75}) = (f/c)M^{0.25}$，其中 $c$ 为代谢率的系数。(b) 质量比为 $10^5$，所以耐受时间增至 $(10^5)^{0.25} = 17.8$：约 $1.4 \times 17.8 = 25$ 天。（小鼠复核：脂肪 $= 3$ g $\times 39$ kJ g⁻¹ $= 117$ kJ；BMR $= 3.4\times0.03^{0.75} = 0.245$ W $= 21.2$ kJ d⁻¹；耐受5.5天。按约为 BMR 四倍的禁食代谢率，即一只活跃小鼠的情形，得到题述的1.4天。）(c) 即使最大的动物，按其正常代谢率也只能禁食数周到数月；大型哺乳动物（如熊，其代谢率适度下降并保持体温）能整个冬天不进食，只可能因为拥有非常大的脂肪储备和一定程度的代谢抑制。对小型哺乳动物，以 BMR 计耐受时间以天计，所以不吃东西过冬要求代谢率降到 BMR 的百分之几，而这只有放弃体温调节、让体温下降才能办到：冬眠（[[animal-physiology/thermoregulation]]）。
:::

::: exercise 设计一项标度研究 {level=3}
你想检验鸟类的 BMR 标度指数是否与哺乳类的不同。描述你需要的数据、你的分析方法，以及三种可能使两个群体显得不同而其实不然（或相反）的偏倚。
::: solution
数据：每组许多物种在标准条件下（成年、吸收后、不活动时段静息、热中性）测定的 BMR，覆盖宽而相互重叠的体重范围，体重在同批个体上测量。分析：以组别为因子并加入交互项（协方差分析），把 $\log B$ 对 $\log M$ 回归；用系统发育广义最小二乘或独立对比处理共同祖辈的影响；所要检验的是交互项（斜率不同）。偏倚：(1) **非基础测量**，混入正在消化、紧张、活动或处于热中性区之下的动物的数据会抬高 BMR，在最难于静息状态下测量的小型物种身上尤其如此，从而使斜率变陡或变平；(2) **体重范围不等**，若鸟类覆盖的范围较窄（没有4吨的鸟），其指数估计精度更低，可能偶然出现差异；(3) **系统发育聚簇**，若大型哺乳动物大多来自 BMR 奇特的少数类群（有蹄类），斜率反映的就是那些类群；(4) **体温**，鸟类的体温高于哺乳类，因此两组的系数还因与体型无关的原因而不同；(5) **回归方法**，相关不完美时，普通最小二乘与简化主轴（reduced major axis）回归给出不同的斜率。
:::
