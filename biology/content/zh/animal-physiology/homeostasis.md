退潮时困在岩池里的一只滨蟹，可能在几小时之内就发现自己处在被雨水稀释到平常盐浓度一半的海水中，随后潮水回涨又回到全盐度的海水。撒哈拉的骆驼可以一周不饮水，而周围的空气达到45 °C。帝企鹅在−40 °C 的南极严冬中孵卵，却把自己的体温保持在38 °C 附近。然而，这些动物体内的细胞工作于一种温度、盐浓度、pH 和氧含量都只有很小变化的液体之中。动物如何使自身内部远比外界稳定？又为什么有的动物根本不费这个事？

本章引入贯穿整门课程的思想：动物的**内环境**、把它保持在限度之内的**反馈控制**、调节某个变量的动物与任其追随环境的动物之间的区分，以及**比较方法**——利用动物的多样性来理解生理学如何工作、如何演化。感知与信号转导的分子机器，受体、第二信使与激酶级联，在 [[cell-biology/cell-signalling]]；这里我们看的是整个动物及其控制系统的逻辑。

## 内环境

多细胞动物的细胞并不浸泡在外部的世界之中，而是浸泡在**细胞外液**中，并且只通过特化的表面——鳃、肺、消化道、肾和皮肤——与外界交换物质。法国生理学家 Claude Bernard 把这一点作为生理学的核心思想。在其 *Introduction à l'étude de la médecine expérimentale*（1865）与后来的讲演中，他论证复杂的动物生活在两种环境之中：外部的 *milieu extérieur*，以及 *milieu intérieur*，即细胞周围的液体；并提出“内环境的恒定是自由而独立生活的条件”。

::: definition 体液的区隔 {#def-compartments}
动物的体水被细胞膜与毛细血管壁分成若干区隔：

- **细胞内液**（ICF），所有细胞的胞质溶胶与细胞器内容物；
- **细胞外液**（ECF），细胞之外的一切，包括浸润细胞的**组织间液**，以及在具有闭管式循环的动物中的血液**血浆**；
- 在具有开管式循环的动物（大多数节肢动物与软体动物）中，血液与组织间液之间没有分离，单一的细胞外液称为**血淋巴**。

**内环境**就是细胞外液。它的成分在一侧由与细胞的交换决定，在另一侧由经由交换表面与外界的交换决定。
:::

在成年人身上，体质量的约60 %是水；其中约三分之二在细胞内，而细胞外的三分之一里大约四分之一是血浆、四分之三是组织间液。这些比例因物种以及胖瘦（脂肪组织含的水很少）而不同，但格局是普遍的：动物的大部分水在其细胞内，细胞外液只是围绕细胞的一层薄膜，周转很快。

细胞内液与细胞外液的成分非常不同。在哺乳动物，ECF 约含140–145 mmol L⁻¹ Na⁺、约4–5 mmol L⁻¹ K⁺ 与约100–110 mmol L⁻¹ Cl⁻，而胞质溶胶约含140 mmol L⁻¹ K⁺，Na⁺ 只有约10–15 mmol L⁻¹。这些差别由 Na⁺/K⁺-ATP 酶与其他转运体维持，并且是膜电位的来源（[[cell-biology/membrane-transport]]）。然而在渗透方面，两个区隔几乎相等：水容易穿过大多数细胞膜，所以细胞会收缩或膨胀，直到其内部渗透浓度与 ECF 的相等。因此，控制 ECF 的**渗透浓度（osmolality）**就控制了全身的细胞体积，这是它被如此严密调节的原因之一。

|---|---|---|---|---|
| 海水（盐度35 ‰） | 约470 | 约10 | 约550 | 约1000 |
| 海洋贻贝血淋巴 | 接近海水 | 略高于海水 | 接近海水 | 约1000 |
| 海洋硬骨鱼血浆 | 约180 | 约5 | 约160 | 约350–400 |
| 哺乳类血浆 | 约145 | 约4 | 约105 | 约290 |
| 淡水（典型湖泊） | < 1 | < 0.1 | < 1 | < 10 |

::: example 用稀释法测量一个区隔 {#ex-dilution}
一个体液区隔的体积用**指示剂稀释原理**测量：注入已知量的、只扩散进入该区隔而不进入其他区隔的标志物，等它混合均匀，再测它的浓度。给一只300 g 的实验大鼠注射30 mg 一种只分布于细胞外液而不进入细胞的多糖标志物。混合后，并扣除已排出的少量加以校正，其血浆浓度为0.50 mg mL⁻¹。在第二个实验中，能与全部体水混合的重水（D₂O）给出的体水总量为180 mL。求 ECF 与 ICF 体积，并以体质量的百分比表示。
::: solution
体积 $=$ 量 $/$ 浓度。ECF $= 30\ \text{mg} / 0.50\ \text{mg mL}^{-1} = 60$ mL，占300 g 体质量的20 %（1 mL 水按1 g 计）。体水总量为180 mL，即体质量的60 %，所以 ICF 为 $180 - 60 = 120$ mL，占体质量的40 %。三分之二的水在细胞内，三分之一在细胞外，与人的比例相同。该方法的假定是：标志物被局限于该区隔、完全混合、既不被代谢，也（经校正后）不被排出；会缓慢漏入细胞的标志物会高估 ECF。
:::
:::

## 稳态与反馈

Bernard 的思想由美国生理学家 Walter Cannon 获得了现代名称：Cannon 在1926年创造了**稳态（homeostasis）**一词，并在一篇长篇综述《Organization for physiological homeostasis》（1929）与著作《The Wisdom of the Body》（1932）中对其作了分析。Cannon 特意选了 *homeo-*（“相似的”）而不是 *homo-*（“相同的”）：内环境并不是被完美地保持恒定，而是由那些一旦它开始漂移就开始起作用的过程保持在限度之内。

::: definition 稳态及其控制环 {#def-homeostasis}
**稳态**是尽管有来自体外或动物自身活动的扰动，仍把内环境的某个变量维持在有限范围内的状态。一个稳态控制系统具有：

- 一个**受控变量**（例如核心体温、血浆渗透浓度、血糖浓度、动脉血 O₂ 分压）；
- 测量它的**传感器**（感受器）；
- 一个**整合器**或控制器，通常位于神经系统或内分泌系统，把测量值与一个参考值——**调定点**——作比较，并算出一个**误差信号**；
- 其活动能改变该变量的**效应器**（肌肉、腺体、转运上皮）。

在**负反馈**中，效应器起作用以减小误差：一个方向的偏差产生一个把变量朝另一个方向推回去的响应。
:::

哺乳动物的体温是教科书式的例子。皮肤、脊髓与下丘脑中的温度感受器把温度信号传给下丘脑的视前区。若核心体温下降，下丘脑就驱动保热与产热的效应器：皮肤血管收缩、竖起毛发或羽毛、战栗与非战栗产热。若体温上升，它就驱动皮肤血管舒张、出汗或喘气。细节在 [[animal-physiology/thermoregulation]]；这里要紧的是结构，它对葡萄糖、渗透浓度与血气体都是一样的。

::: intuition 稍有曲折的恒温器
家用恒温器是常用的类比，它抓住了这个环：传感器、调定点、比较、加热器。有两点区别值得记住。恒温器是一个开-关式开关；而生理控制器多半是**分级的**，产生的纠正随误差的大小而增长。而且一间房子只有一个加热器，动物却通常有好几个按顺序募集的效应器，从最便宜的开始：受寒的哺乳动物先收缩皮肤血管、蓬起绒毛，这几乎不花什么成本，只在这些不够用时才战栗，而那要消耗大量燃料。
:::

### 比例控制及其误差

负反馈环工作得如何？最简单的定量模型把纠正处理为与误差成正比。设 $x$ 为受控变量，$x_0$ 为其调定点，令 $e = x - x_0$ 为误差。一个持续的扰动 $D$ 若单独作用，会使变量偏移 $D$（一阵冷风，如果什么都不做，会使体温降低2 °C）。控制系统以与误差成正比的纠正 $-Ge$ 作出响应，其中无量纲数 $G$ 是**环路增益**。

::: proposition 比例控制的稳态误差与速度 {#prop-gain}
设若无控制时误差以时间常数 $\tau$ 松弛到扰动 $D$，即 $\tau\,\deriv{e}{t} = -e + D$，而控制器加上一个纠正 $-Ge$。于是

$$
\tau\,\deriv{e}{t} = -e + D - Ge = -(1+G)\,e + D,
$$ {#eq-loop}

且，从 $e(0) = 0$ 出发，

$$
e(t) = \frac{D}{1+G}\left(1 - \mathrm{e}^{-(1+G)t/\tau}\right).
$$ {#eq-loop-solution}

误差稳定到一个**稳态误差** $e_\infty = D/(1+G)$，即无控制时应有力度的 $1/(1+G)$，并且以较短的时间常数 $\tau/(1+G)$ 到达那里。

假设：一个只有单一时间常数的线性系统；一个只依赖当前误差、瞬时起作用的纠正；不饱和的效应器。真实的环有延迟、有多个效应器、有极限，所以这个公式描述的是调定点附近而非极端条件下的行为。
:::

::: proof
式 [[#eq-loop]] 是线性的、一阶的。它的平衡点（$\deriv{e}{t} = 0$ 之处）是 $e_\infty = D/(1+G)$。令 $u = e - e_\infty$，得 $\tau\,\deriv{u}{t} = -(1+G)u$，其解为 $u(t) = u(0)\,\mathrm{e}^{-(1+G)t/\tau}$，其中 $u(0) = -e_\infty$。再加回 $e_\infty$ 就得到 [[#eq-loop-solution]]。
:::

由此可得出两条结论。第一，比例控制器**绝不会把误差完全消除**：总会留下一些误差，因为纠正正是由误差本身驱动的。增益越高，残余误差越小。第二，反馈使响应既变小又变快。两者都是负反馈的普遍性质，也正是动物投资于感受器与效应器所得到的回报。

:::

::: example 估计一个环路增益 {#ex-gain}
一只置于实验箱中的小哺乳动物暴露于气温的阶跃下降。根据其散热量与热容量，生理学家估计，如果阻断它的一切调节性响应，其核心体温最终会下降2.0 °C，时间常数为30 min。而在完整个体身上，核心体温只下降0.10 °C。（a）这一范围内的体温调节的环路增益是多少？（b）被调节响应的时间常数是多少？（c）完整个体完成其微小变化的95 %需要多长时间？
::: solution
（a）由 [[#prop-gain]]，$e_\infty = D/(1+G)$，故 $1 + G = 2.0/0.10 = 20$，$G = 19$。

（b）时间常数为 $\tau/(1+G) = 30/20 = 1.5$ min。

（c）一阶响应经过 $\ln 20 \approx 3.0$ 个时间常数达到其终值的95 %，这里是 $3.0 \times 1.5 = 4.5$ min（而未控制的系统需90 min）。这些数字是示例性的，但显示出了良好生理调节的数量级：增益达数十，残余误差为扰动的几个百分点，响应在几分钟之内完成。
:::
:::

### 积分控制、延迟与振荡

比例控制器总会留下误差，那为什么有些变量在持续扰动之后恰好回到它们的调定点？答案是：纠正可以依赖于随时间累积的误差，而不只是它的当前值。在**积分控制**中，只要误差持续存在，效应器的输出就持续增长，只有当误差为零时才停止变化。激素系统常常如此表现，因为当分泌超过清除时激素浓度会积累。下面这段简短的程序在 [[#prop-gain]] 的模型上比较这两种控制。

```python
# Proportional (P) and proportional-integral (PI) control of a first-order system.
# x is the deviation of the regulated variable from its set point (degC);
# without control:  tau * dx/dt = -x + D
tau = 30.0   # min, time constant of the uncontrolled system
D = 2.0      # degC, sustained disturbance
G = 9.0      # dimensionless proportional loop gain
Ki = 0.5     # min^-1, integral gain
dt, T = 0.01, 240.0   # min

x_p = x_pi = integral = 0.0
for step in range(int(T / dt)):
    x_p += dt / tau * (-x_p + D - G * x_p)
    integral += x_pi * dt
    x_pi += dt / tau * (-x_pi + D - G * x_pi - Ki * integral)

print(f"P only:  error after {T:.0f} min = {x_p:.3f} degC (theory D/(1+G) = {D/(1+G):.3f})")
print(f"P + I:   error after {T:.0f} min = {x_pi:.3f} degC")
# P only:  error after 240 min = 0.200 degC (theory D/(1+G) = 0.200)
# P + I:   error after 240 min = 0.000 degC
```

高增益有代价。每个真实的环都有**延迟**：神经传导、激素的运输与清除、血液从效应器循环到感受器所需的时间。基于过时信息的强纠正会过冲，过冲又产生相反方向的强纠正，于是变量振荡。这就是为什么许多生理变量在扰动之后呈现阻尼振荡，也是为什么有些变量——例如循环延迟很长的动物的呼吸模式——会自发振荡。控制论原是为工程发展的，自 Norbert Wiener 的《Cybernetics》（1948）起被应用于生理学，它把这一权衡表述得很确切：增益买到精确与快速，延迟限制一个环所能使用的增益。

### 前馈与正反馈

负反馈只在误差出现之后才行动。动物也会预先行动。在**前馈**（预期性）控制中，效应器响应的是一个预示扰动的信号，而不是扰动本身。皮肤中的冷感受器在核心体温下降之前就触发战栗；食物的视觉、气味与味道在葡萄糖被吸收之前就触发胰岛素的释放（分泌的头期）；而脱水的动物早在喝下的水被吸收并稀释其血液之前就早已停止饮水，因为口、喉与胃中的感受器在计量喝入的体积。前馈减小了反馈本来必须纠正的误差，但它的好歹不超过预测本身的好坏，所以总有反馈在后面兜底。

在**正反馈**中，偏差引起的响应会使偏差增大。这听起来与稳态正相反，而且确实如此：正反馈用于必须迅速走到尽头的事件，而不是用于把变量保持恒定。当神经膜去极化时，电压门控 Na⁺ 通道打开，Na⁺ 进入，膜进一步去极化，产生全或无的动作电位（[[neuroscience/action-potential]]）。在哺乳动物的分娩中，宫颈受到牵拉触发催产素的释放，催产素加强子宫收缩，收缩又进一步牵拉宫颈。血液凝固是一个级联，其中被活化的酶活化更多自身。每一例中都有某种东西结束这个循环：Na⁺ 通道失活、胎儿娩出、血凝块形成并把受损表面封闭。没有终止器的正反馈就是失控。

::: quiz
给哺乳动物加温时，它会出汗或喘气；蒸发使它冷却，而它的体温向正常回升时出汗减少。哪种描述是正确的？
- [ ] 正反馈，因为响应随温度升高而增强。
- [x] 负反馈，因为响应对抗引起它的偏差。
- [ ] 前馈，因为出汗在温度变化之前就开始。
- [ ] 根本不是反馈，因为蒸发是一个物理过程。
::: solution
“负”指的是响应对误差的作用，而不是响应改变的方向。温度升高使蒸发散热增强，而蒸发散热降低体温：响应对抗偏差，所以这是负反馈。正反馈将是一个把体温进一步推高的响应。
:::
:::

### 会移动的调定点

调定点并不固定。许多哺乳动物的体温遵循约1 °C 的昼夜节律；在蛰伏中会下降几十度（[[animal-physiology/thermoregulation]]）；并在**发热**时升高，此时来自免疫系统的信号作用于下丘脑。发热的动物在体温上升期间会战栗并寻找温暖，尽管它已经比正常更热，因为它的体温低于新的调定点。变温动物以行为表现出同样的响应：感染了细菌 *Aeromonas hydrophila* 的荒漠鬣蜥（*Dipsosaurus dorsalis*）会选择更暖的地点，使体温升高约2 °C；而被阻止这样做的感染蜥蜴死亡得更多（Matthew Kluger 与同事，1975）。这类变化——被调节的水平本身被调整——有时称为**变定态（rheostasis）**，而当它们预告一个可预期的需要时，则称为**应变稳态（allostasis）**。

有时被调节的变量并不是那个一眼看中的。许多变温动物的血液 pH 并不保持在固定值：体温每下降一度，pH 大约升高0.015个单位。水的中性 pH 也随温度下降而升高，幅度相近，其结果是蛋白质中组氨酸残基咪唑基的电离分数几乎保持恒定——这就是 Robert Reeves（1972）的 **α恒定假说（alphastat hypothesis）**。按这一观点，被调节的是蛋白质的电荷状态，pH 的变化是为了使它保持恒定。

::: warning “稳态意味着把一切都保持恒定”
稳态把少数几个变量保持在限度之内，而它是靠让其他变量改变来做到的。为了在寒冷中保持核心体温恒定，哺乳动物让皮肤与足部冷却到接近冰点，并使代谢率升高好几倍。为了保持血浆渗透浓度恒定，它把尿量变动一百倍。被调节的变量还在其调定点附近波动，随昼夜节律和活动而变化，而且调定点本身也被调整。固定而完美恒定的内环境在任何动物中都不存在，而且许多动物压根不调节几个变量，下一节将说明这一点。
:::

::: application 当控制失灵
许多人类疾病可以被理解为某个稳态环的失灵：一个不再能感知的感受器，一个不再响应的效应器，或一个移动了的调定点。在1型糖尿病中，充当葡萄糖调节的感受器与效应器双重角色的胰岛素分泌细胞被破坏，血糖不再被保持在范围内；在2型糖尿病中，组织对胰岛素的响应变弱，于是环路增益下降。体液及其调节的临床生理学见[医学图谱：稳态与体液](/learn/medicine/lesson.php?c=physiology&l=homeostasis-body-fluids)；本课程停留在比较的图景上。
:::

## 调节者与顺应者

稳态要消耗能量。逆梯度泵离子、产热、运转感受器与控制器都要消耗 ATP。动物并不必须为每一个变量付出这个代价，而许多动物也确实没有付。对任何一个环境变量，我们都可以问：当外部值改变时，动物是把内部值保持稳定，还是任其追随。

::: definition 调节者与顺应者 {#def-regulator}
对某一给定变量，若一个动物在外部值的一段范围内把内部值几乎保持不变，则它是**调节者**；若它的内部值随外部值改变，并约等于或平行于外部值，则它是**顺应者**。用于体温时，这两个概念成为**内温动物/变温动物**（严格说来，是以生理手段对体温的调节者与顺应者）；用于渗透浓度时，成为**渗透压调节者（osmoregulator）**与**渗透压顺应者（osmoconformer）**。许多动物只对变量的部分范围作调节、对其余范围作顺应，而一个动物可以在一个变量上调节的同时在另一个变量上顺应。
:::

把内部值对外部值作图，这一区分就一目了然。一个完美的顺应者落在等值线上，斜率1。一个完美的调节者落在水平线上，斜率0。真实的动物落在两者之间，而某段范围内的斜率衡量它们调节的强弱。

::: widget plot
f: x; 300; 300 + b*(x - 300)
x: 0, 1200
y: 0, 1200
sliders: b=0.5:0:1:0.05
labels: \text{顺应者（内部 = 外部）}; \text{完美调节者}; \text{部分调节者，斜率 } b
vlines: 1000
caption: 三种理想化动物的内部渗透浓度（纵轴，mOsm kg⁻¹）对外部水的渗透浓度（横轴）作图。顺应者沿等值线；完美调节者无论外部值如何都保持300 mOsm kg⁻¹；部分调节者的斜率 $b$ 由滑块设定。竖线标记全强度海水。真实动物通常对部分范围顺应、对另一部分调节，所以它们的曲线是弯的；对稀海水中的典型河口蟹，试试0.3到0.6的 $b$。
:::

海洋无脊椎动物提供了经典的例子。蜘蛛蟹以及多数生活在近海的海洋蟹类是**渗透压顺应者**：其血淋巴几乎具有与海水相同的渗透浓度，而海水一旦被稀释，它们的体液也随之稀释，直到死亡。生活在河口与岩池的滨蟹 *Carcinus maenas* 在全强度海水中顺应，但在稀海水中**高渗调节**，通过鳃主动吸收 Na⁺ 与 Cl⁻，把血淋巴保持得比环境更浓。这一能力及其代价，使它得以生活在顺应者无法生活的地方。

::: example 读出一条调节曲线 {#ex-crab}
两种蟹在不同稀释度海水中放置一天后测定其血淋巴渗透浓度。代表性数值（mOsm kg⁻¹）如下：

| 外部 | 1000 | 750 | 500 | 300 |
|---|---|---|---|---|
| 物种 A | 1010 | 900 | 780 | 660 |
| 物种 B | 1005 | 760 | 510 | 死亡 |

（a）给每个物种归类。（b）计算物种 A 在300与750 mOsm kg⁻¹ 之间内部值对外部值的斜率，并解释。（c）你预期在河口找到哪个物种？
::: solution
（a）物种 B 在几个 mOsm kg⁻¹ 之内沿等值线变化：它是一个渗透压顺应者，而且最稀的环境它活不下来。物种 A 在全强度海水中顺应（1010对1000），但随着海水稀释把血淋巴维持在远高于环境的水平：它在稀介质中是高渗调节者。

（b）斜率 $= (900 - 660)/(750 - 300) = 240/450 = 0.53$。介质每稀释1 mOsm kg⁻¹，血淋巴只被稀释大约其一半。物种 A 是一个部分调节者：它的内环境仍然改变，但它的细胞经历的渗透改变只有体外的一半左右，而这种改变它们可以通过调整自身小分子有机溶质的含量来补偿。

（c）物种 A，它既耐受影响又能逆着稀释作调节，正如 *Carcinus maenas* 等河口蟹所为。这里的数字是示例性的，属于为河口与近海蟹类所测的那一类。
:::
:::

顺应不是失败。顺应者省下了调节的代价，在环境稳定的地方可以非常成功：开阔大洋的盐度变化很小，深海的温度变化也很小。顺应者也常常在*细胞水平*上补偿。一只血淋巴被稀释的渗透压顺应贻贝，通过释放细胞内氨基酸与其他有机渗透物质来防止细胞膨胀；一只生活在冷水中的变温鱼，其酶在低温下比它暖水近亲的酶工作得更快。调节内环境，与保护细胞以对抗变化的内环境，是同一个问题的两种解法。

## 驯化与适应

动物在若干时间尺度上响应变化了的环境，生理学家对此小心区分，因为它们的机制不同。

::: definition 生理响应的时间尺度 {#def-acclimation}
- **急性响应**在数秒至数小时内发生，使用动物已经具有的机制（血管收缩、喘气、呼吸改变）。
- **驯化（acclimation）**是在数天至数周内、响应于在实验室内施加的单个环境变量之改变而发生的可逆生理变化；**习服（acclimatisation）**是野外发生的同等变化，那里是多个变量一起改变（季节）。两者都涉及一个个体一生中基因表达与组织结构的改变。
- **发育可塑性**是由发育期间的条件引起的不可逆或长期持续的改变。
- **进化适应**是种群或物种之间遗传基础上的差异，由世代间的自然选择产生。
:::

金鱼在30 °C 下饲养数周后，能耐受比养在10 °C 下的个体更高的温度，而冷驯化个体能够耐受的寒冷则会把它杀死；F. E. J. Fry 与同事在1940年代绘制了鱼类这种漂移的温度耐受极限。那是驯化。相比之下，极地海洋的鱼类则根本无法驯化到温水：许多南极鳄冰鱼在高于0 °C 几度时就会死亡。那是进化历史的结果。为了在野外比较中把两者分开，生理学家把不同种群的动物在完全相同的条件下饲养一代或数代（**同园（common-garden）实验**）：持续存在的差异很可能是遗传的；消失了的差异则是可塑的。

## 比较方法

动物生理学在两种意义上是比较性的。它利用特定的动物作为研究普遍机制的工具，又比较各物种以理解生理学如何适应了环境。

第一种用途由丹麦生理学家 August Krogh 在1929年表述：“对于大量问题，总会存在某种首选动物，或少数几种这样的动物，问题在它们身上能被最方便地研究。”Hans Krebs 后来称之为**August Krogh 原则**。乌贼的巨大轴突，直径可达约1 mm，使 Alan Hodgkin 与 Andrew Huxley 得以把电极插入一根神经纤维之内，搞清动作电位的离子基础。海蛞蝓 *Aplysia* 的又大又少的神经细胞，使 Eric Kandel 得以把学习追溯到已鉴定突触处的改变。蛙的缝匠肌、狗的胰腺、昆虫的唾液腺与荒漠啮齿类的肾，都扮演过这一角色。选对动物常常是一项生理学发现的决定性一步。

第二种用途是问一个性状是否为适应。如果生活在高处的鸟类具有比其低地近亲对氧亲和力更高的血红蛋白，那就提示该性状是为了生活在稀薄空气中而演化出来的（[[animal-physiology/gas-exchange]]）。但这样的比较需要小心。物种不是独立的数据点：有亲缘关系的物种经由共同祖先把性状共有，而不是各自分别演化出了它们。十种海豹都善于潜水，告诉我们的只是潜水能力的一次进化起源，而不是十次。

::: example 为什么系统发育要紧 {#ex-phylogeny}
一位生理学家比较十种哺乳动物，五种来自荒漠，五种来自湿润生境，发现荒漠物种产生的尿液浓得多。结果发现全部五种荒漠物种都是同一个科的啮齿类，而全部五种湿润生境物种来自另一个目。这套数据包含多少次荒漠与湿润生境的独立比较？更好的设计应当是什么？
::: solution
实际上只有一次。五种荒漠物种或许都是从性状曾演化过一次的共同祖先继承了它们的肾，五种湿润生境物种或许同样共享着它们的肾；两组之间的差异同样可以反映两个谱系之间的任何其他差异，比如体型或食性。这个比较实际上样本量为一。更好的设计是比较生境不同的近缘物种**对**——同一属的一种荒漠与一种湿润生境啮齿类、荒漠与湿润生境的有袋类、荒漠与湿润生境的鸟类——这样每一对都是一次独立的进化对比。沿系统发育树这样做的正式方法，始于 Joseph Felsenstein 的独立对比法（1985），如今已是标准做法。
:::
:::

还有一个告诫：并非每个差异都是适应。一个性状可以是体型的副产品、祖传的约束，或是另一个被选择的性状的结果。因此生理学家用几种方式来检验适应性的解释：表明该性状在相关环境中提高性能；比较独立的进化起源；以及越来越多地利用实验室中的实验进化——对果蝇、小鼠或微生物的种群就某一生理性状进行选择，并直接测量响应。

::: history
Claude Bernard 从1850年代起的讲演、他的 *Introduction à l'étude de la médecine expérimentale*（1865）与最后的讲演（1878）中阐明了内环境的想法。Walter Cannon 于1926年创造了 *homeostasis* 一词，并在1929年与《The Wisdom of the Body》（1932）中发展了它，其基础是他在猫身上对交感神经系统与肾上腺髓质的研究。Norbert Wiener 的《Cybernetics》（1948）把来自工程学的反馈控制数学引进了生物学。August Krogh 在他1929年发表的讲演中提出了他的“首选动物”原则；Hans Krebs 于1975年为其命名。经由 Krogh、Per Scholander、Laurence Irving、C. Ladd Prosser 与 Knut Schmidt-Nielsen 的工作，比较生理学在二十世纪中叶成为独立的领域；而在 Joseph Felsenstein 1985年关于系统发育与比较方法的论文之后，它拥有了比较物种的统计方法。
:::

## 由此引向何处

本章的控制环将在每一个系统中重现：体温在 [[animal-physiology/thermoregulation]]，血气在 [[animal-physiology/gas-exchange]]，血压在 [[animal-physiology/circulation]]，渗透浓度与容量在 [[animal-physiology/water-salt-balance]]，葡萄糖、生长与生殖在 [[animal-physiology/endocrine-control]]。而在那之前，[[animal-physiology/energy-metabolism]] 要问这一切值多少消耗，以及消耗如何取决于动物的大小。

::: summary
- 细胞生活在细胞外液中，即 Bernard 的 *milieu intérieur*；体水大部分在细胞内，细胞体积跟随 ECF 的渗透浓度。
- 稳态（Cannon）借助感受器、带有调定点的整合器、以及通过负反馈起作用的效应器，把受控变量保持在限度之内。
- 比例控制留下稳态误差 $D/(1+G)$ 并使响应加速 $1+G$ 倍（[[#prop-gain]]）；积分控制消除误差；延迟限制可用的增益并引起振荡。
- 前馈依据对扰动的预测起作用；正反馈驱动自我终止的事件，如动作电位、分娩与凝血。
- 调定点会移动（昼夜节律、发热、蛰伏），而被调节的变量未必是那个显眼的（α恒定的 pH 调节）。
- 调节者把内部变量保持稳定；顺应者任其追随环境，常常转而保护其细胞。许多动物只对部分范围调节。
- 急性响应、驯化、发育可塑性与进化适应作用于不同的时间尺度；同园实验把可塑差异与遗传差异分开。
- Krogh 原则为一个问题挑选最合适的动物；物种之间的比较必须考虑共同祖先。
:::

## 习题

::: exercise 标志物的稀释 {level=1 check="250"}
给一条1.0 kg 的鱼注射15 mg 只分布于细胞外液的标志物。混合后，血浆浓度为0.060 mg mL⁻¹。ECF 体积是多少毫升？
::: solution
$15\ \text{mg} / 0.060\ \text{mg mL}^{-1} = 250$ mL，占体质量的25 %——硬骨鱼的典型值。
:::
:::

::: exercise 残余误差 {level=1 check="0.2"}
若无控制，一个扰动会使某受控变量改变5.0个单位。若环路增益为24，以同一单位计的稳态误差是多少？
::: solution
由 [[#prop-gain]]，$e_\infty = D/(1+G) = 5.0/25 = 0.2$。
:::
:::

::: exercise 控制的种类 {level=1}
把下列各项归为负反馈、正反馈或前馈，并给出理由。（a）血浆渗透浓度升高使抗利尿激素分泌增加，从而减少尿中失水。（b）蜥蜴在其体温达到38 °C 时移入树荫。（c）大鼠在闻到食物时开始分泌胰岛素。（d）生长中的卵泡产生的雌二醇浓度升高，触发黄体生成素峰，使卵泡完成成熟并引起排卵。
::: solution
（a）负反馈：响应（保水）降低了引起它的渗透浓度。（b）经由行为起作用的负反馈：高体温触发使其降低的行为。（c）前馈：胰岛素在葡萄糖升高之前、响应预示它的线索而释放。（d）正反馈：雌二醇刺激 LH 峰，LH 峰驱动卵泡进一步成熟；循环以排卵告终，此后卵泡变成黄体，激素格局随之改变（[[animal-physiology/endocrine-control]]）。
:::
:::

::: exercise 由时间常数求增益 {level=2 check="19"}
当某一调节反射被药物阻断时，一个变量对阶跃扰动的响应时间常数为40 min。反射完整时时间常数为2.0 min。设采用 [[#prop-gain]] 的模型，环路增益是多少？扰动的多大比例作为稳态误差保留？
::: solution
受控时间常数是 $\tau/(1+G)$，所以 $1 + G = 40/2.0 = 20$，$G = 19$。稳态误差为 $1/(1+G) = 1/20 = 5$%的扰动。因此，只要单时间常数模型成立，测量响应的加速就是一种不必测量误差本身而估计增益的办法。
:::
:::

::: exercise α恒定的调节 {level=2 check="7.67"}
一只淡水龟在37 °C 时的动脉 pH 为7.40。若其血液 pH 遵循 α恒定规则，即温度每下降一度 pH 升高0.016个单位，你在20 °C 时会预期多大的 pH（保留两位小数）？解释为什么这既不是酸中毒也不是碱中毒。
::: solution
$\Delta T = -17$ °C，故 pH $= 7.40 + 0.016 \times 17 = 7.40 + 0.27 = 7.67$。水本身的中性点随温度下降而升高（pN 在37 °C 约6.8，在20 °C 约7.1），组氨酸咪唑基的 p$K$ 也以类似方式升高，所以血液在中性偏碱一侧的距离相同，蛋白质上的电荷未变。以哺乳类7.40的标准来评判这只龟将是错误：被调节的量是蛋白质的电离状态，不是 pH 这个数字。
:::
:::

::: exercise 解读一项野外比较 {level=2}
在夏季采集的动物上测定，北部种群的招潮蟹在20 °C 时的代谢率高于同种南部种群的蟹。给出两种机制不同的解释，并设计一个实验来区分它们。
::: solution
（1）**习服**：北部蟹经历了更冷的条件，调整了它们的酶水平与线粒体密度，这是一种可塑的响应，如果它们生活在南方就会消失。（2）**遗传适应**：两个种群已在遗传上分化，以致北部蟹在给定温度下，无论经历什么条件都有更高的代谢率（这种格局称为逆梯度变异，countergradient variation，它补偿了寒冷的减速效应）。要区分二者，从卵开始把两个种群的蟹在若干温度下的相同实验室条件中饲养（或把成体驯化数周）——一个同园实验。如果差异在以完全相同方式饲养的动物中持续存在，尤其是第二代（可去除母体效应），那它是遗传的；如果消失，那它原是表型可塑的。两者都可以有份。
:::
:::

::: exercise 挑选动物 {level=2}
对下列每个问题，按 Krogh 原则建议一位生理学家可能选择的动物类型，并说明理由。（a）肾生成浓缩尿的机制。（b）肌肉收缩如何被钙开启。（c）憋气潜水的生理学。（d）代谢率能否响应选择而进化。
::: solution
答案可以有很多；要紧的是说理。（a）一种荒漠啮齿类，如更格卢鼠或沙鼠，其肾把尿液浓缩的能力极强，把该机制放大从而更易测量。（b）大的单根肌纤维，如藤壶的巨大纤维，允许向单个细胞内注入钙指示剂与电极；蛙肌因其在室温离体条件下保存良好也已被广泛使用。（c）一种海豹，如威德尔海豹，潜水时间长，而且可以在冰上孤立的呼吸孔处研究，因为它必须回到原处。（d）一种世代时间短、能大量繁殖的动物，如实验室小鼠或果蝇，用重复的设置选择系与对照系做选择实验。
:::
:::

::: exercise 延迟引起的振荡 {level=3}
一位生理学家以离散时间步对某受控变量建模：每一步效应器施加的纠正等于**前一步**测得的误差乘以 $-G$，因此若无扰动，$e_{n+1} = e_n - G\,e_{n-1}$。（a）从 $e_0 = e_1 = 1$ 出发，计算 $G = 0.2$ 与 $G = 0.8$ 时的 $e_2$ 至 $e_6$。（b）描述其中的差别。（c）这对延迟很长的系统中环路增益的进化说明了什么？
::: hint
只需迭代这个递推。对（c），想一想更高的增益会给动物带来什么、又让它失去什么。
:::
::: solution
（a）$G = 0.2$ 时：$e_2 = 1 - 0.2 = 0.8$，$e_3 = 0.8 - 0.2 = 0.6$，$e_4 = 0.6 - 0.16 = 0.44$，$e_5 = 0.44 - 0.12 = 0.32$，$e_6 = 0.32 - 0.088 = 0.232$。$G = 0.8$ 时：$e_2 = 1 - 0.8 = 0.2$，$e_3 = 0.2 - 0.8 = -0.6$，$e_4 = -0.6 - 0.16 = -0.76$，$e_5 = -0.76 + 0.48 = -0.28$，$e_6 = -0.28 + 0.608 = 0.328$。

（b）低增益时误差平滑地向零衰减。高增益时它过冲、变号并振荡，因为每次纠正依据的都是一个已经改变了的误差。（特征方程 $\lambda^2 - \lambda + G = 0$ 在 $G > 1/4$ 时有复根，产生振荡；在 $G > 1$ 时根的模大于1，振荡增长。）

（c）在延迟很长的环中，高增益是不稳定的，所以选择应当偏爱适中的增益再加上其他策略：基于预测的前馈控制、更快的感知（更短的延迟）、或作用于不同时间尺度的数个效应器。延迟较长的生理系统，例如激素调节，确实通常在扰动后表现出阻尼振荡。
:::

::: exercise 为什么正反馈需要一个了结 {level=3}
就动作电位与血液凝固，说明是什么终止了正反馈循环。然后用简单模型 $\deriv{e}{t} = +k\,e$（$k > 0$）解释为什么正反馈单靠自己不能把变量维持在一个范围之内。
::: solution
在动作电位中，去极化打开 Na⁺ 通道，打开的通道引起进一步去极化；循环由 Na⁺ 通道在开启约一毫秒后的**失活**，以及电压门控 K⁺ 通道较慢的开放使膜复极化所终止（[[neuroscience/action-potential]]）。在凝血中，每一个被活化的蛋白酶活化更多；循环受到伤口处前体的耗竭、血浆中循环的抑制物、以及血流把活化因子从伤口处冲走造成的稀释的限制，所以血凝块保持局限。在这个模型中，$\deriv{e}{t} = ke$ 给出 $e(t) = e(0)\,\mathrm{e}^{kt}$：任何偏差，无论多小，都指数增长，直到有别的东西限制它。除不稳定的 $e = 0$ 之外不存在稳定的取值。所以正反馈只是放大并加速一个变化；把一个变量维持在范围之内需要负反馈。
:::
:::

::: exercise 变化世界中的顺应者 {level=3}
渗透压顺应的海洋无脊椎动物已在开阔大洋中占统治地位数亿年，但在河口或淡水中却很少有它们的身影。用本章的思想解释（a）为什么在开阔大洋中顺应是好策略，（b）顺应者在河口中面临什么问题，（c）为什么淡水中的高渗调节比在半咸水中耗费更多能量。
::: solution
（a）开阔大洋的盐度变化极小，所以体液与海水一致的动物面对不到渗透梯度，在盐与水平衡上无须花费分文；省下的能量可用于生长与生殖。（b）在河口中，盐度随潮汐与降雨而变，有时就在数小时之内。顺应者的体液会随之起伏，于是它的细胞将暴露于大的渗透变化之下；它要么在细胞内补偿（调整有机渗透物质，这需要时间且有限度），要么紧闭等待（如贻贝闭壳那样），要么起来调节。（c）动物必须主动吸收离子，以补充经扩散丢失的离子。扩散损失与体液和环境之间的浓度差成正比，而把每个离子向内转运所需的自由能随浓度比的对数而增大。在淡水中，内部浓度是外部的数百倍，损失与每个离子的代价都比半咸水中大得多。这就是为什么淡水动物还降低自身的通透性并排出稀释的尿（[[animal-physiology/water-salt-balance]]）。
:::
