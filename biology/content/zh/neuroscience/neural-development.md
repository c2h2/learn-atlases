一个人脑含有约860亿个神经元，由大约一百万亿个突触相连，而它在几个月内由一层几千个胚胎细胞的板建成。一个小鼠脑有约七千万个神经元，在约三周的妊娠期加出生后几周内建成。基因组无法规定每一条连接：人类基因组约有20,000个蛋白编码基因，即便给每个基因慷慨地分配比特，离一张接线图仍差好几个数量级。神经系统由发育规则建成：细胞凭位置被告知自己将成为什么，按精确的顺序出生，沿分子路标被送往目的地，然后接受使用的检验——有用的连接被保留，其余的被删除。

本章问两个相关的问题。第一，神经系统如何演化，从早期动物弥散的神经网到脊椎动物、昆虫与章鱼集中化的脑？第二，在每个个体中，神经系统如何建成：胚胎组织如何变成神经组织、如何被建立图式、神经元如何出生与迁移、轴突如何找到靶、活动如何精修最终结果？发育生物学的一般原理——诱导、形态发生素、原肠胚形成与 Hox 基因——见[[developmental-biology/principles-of-development]]、[[developmental-biology/gastrulation]]与[[developmental-biology/segmentation-hox]]；本章把它们应用于神经系统。

## 神经系统的演化

### 没有神经元的动物，以及最早的神经网

动物的五个主要谱系中，有两个——**海绵**（多孔动物）与微小扁平的**扁盘动物**——没有神经元。然而它们的基因组含有许多在其他动物中构建突触的基因，包括突触后基质的支架蛋白和囊泡释放装置的组分，而扁盘动物用分泌肽协调自身的滑动。神经元的分子零件清单比神经元更古老。

其余三个谱系，**栉水母**（栉板动物）、**刺胞动物**（水母、海葵、珊瑚与水螅）和**两侧对称动物**（所有其他动物），有神经系统。刺胞动物的神经系统是**神经网**：弥散的神经元网格铺满体壁，有时在口周或伞缘凝聚成环，大量使用神经肽，也使用经典递质。栉水母的神经系统更奇特：它们缺乏大多数经典小分子递质及其合成酶，依赖肽与谷氨酸，而其上皮下神经网（见[[neuroscience/neurons-glia]]）部分是一个合胞体。

栉水母在动物生命树上的位置是动物系统发育学中争议最大的问题之一。2008年以来的分析把它们置于所有其他动物的姐妹群，或传统位置（海绵为最早分支）。一项跨动物及其单细胞近亲比较染色体上保守基因顺序的研究（Darrin Schultz 与合作者，2023年）支持栉水母为最早分支，但并非所有研究者都认为问题已经解决。如果栉水母确实最早分支，那么或者神经元演化过一次而在海绵与扁盘动物中丢失，或者在栉水母中与在刺胞动物和两侧对称动物的祖先中独立演化——Leonid Moroz 与合作者在2014年就据栉水母神经元独特的分子构成主张后一观点。截至2026年，两种情景都有支持者。

### 集中化与两侧对称动物的脑

两侧对称动物朝一个方向运动，头在前，其中大多数已把许多神经元集中进一个**中枢神经系统**：一条或多条纵行神经索，并在前端、口与主要感觉器官附近有一个凝聚中枢，即**脑**。这种**头部形成**正是一个头先迎接世界的动物的应有安排：感觉器官该在领头的一端，而它们与处理信号回路之间的短连接节省时间与线路。

在节肢动物与环节动物，神经索沿**腹侧**走行，呈一节一节神经链；在脊椎动物及其他脊索动物，它沿**背侧**走行且中空。1822年，艾蒂安·若弗鲁瓦·圣伊莱尔（Étienne Geoffroy Saint-Hilaire）根据一只腹部朝上的龙虾的解剖提出，脊椎动物是一只上下颠倒的节肢动物。这一想法被嘲笑了整整一个半世纪，后被分子证据复活。在果蝇与蛙中，神经系统都在胚胎中**骨形态发生蛋白**（BMP；果蝇中为 Decapentaplegic）信号被拮抗剂（脊椎动物中为 chordin，果蝇中为其同源物 Short gastrulation）阻断的那一侧形成。在果蝇，BMP 信号在背侧、神经索在腹侧；在蛙，BMP 信号在腹侧、神经索在背侧。系统的每一半在两者之间移植后都能工作：果蝇的 Short gastrulation 蛋白能在蛙胚诱导神经组织，蛙的 chordin 也能在果蝇胚胎起作用（Edward De Robertis、笹崎泰树（Yoshiki Sasai）与合作者，1995–1996年）。祖先的两侧对称动物似乎已有一条 BMP–chordin 轴，而在通往脊索动物的谱系中该轴相对于口发生了倒转。

那个祖先——“两侧对称始祖”——是否已有集中化的神经系统仍有争论。为环节动物、昆虫与脊椎动物的神经索建立图式的基因彼此相似，提示它已有；而两侧对称动物各类群神经系统的多样性，包括无肠目扁形虫与某些半索动物弥散的神经网，则让另一些人认为集中化出现过多次。

### 脊椎动物的脑

脊椎动物的中枢神经系统由一条**神经管**发育而来。神经管很早就区域化为**前脑**（前景泡）、**中脑**（中景泡）与**后脑**（菱脑），其后是脊髓。前脑再分为端脑（形成大脑半球）与间脑（形成丘脑与下丘脑，并产生视网膜）。这一基本蓝图所有脊椎动物共有，从七鳃鳗到人；不同的是各部分的相对大小。两种胚胎组织是脊椎动物的创新：**神经嵴**，从神经管边缘迁移出去，形成外周神经系统、色素细胞与大部分颅骨；以及**颅侧板**，头部外胚层的增厚，形成鼻与耳的感觉器官和许多感觉神经节。

大而复杂的脑至少演化过三次——在脊椎动物、节肢动物与头足类软体动物中——来自不同的祖先。一只章鱼有约5亿个神经元，多数在腕中，能解决问题并能观察学习。比较这些独立的实验，是发现脑的哪些特征是复杂行为所必需、哪些是历史偶然的最佳途径之一。

## 神经诱导

胚胎外胚层的一部分如何变成神经组织而非皮肤？经典实验由汉斯·施佩曼（Hans Spemann）与希尔德·曼戈尔德（Hilde Mangold）于1924年发表。借助于蝾螈（*Triturus*）胚胎，曼戈尔德把浅色种早期原肠胚的**胚孔背唇**移植到有色种原肠胚的腹侧。宿主发育出第二条身体轴，一个连体双胎，包括第二条主要由宿主细胞构成的神经管——那些细胞本会变成腹部皮肤。移植物把周围组织组织成了一条轴，因而得名**组织者**。

::: definition 神经诱导 {#def-induction}
**神经诱导**是组织者及其衍生物（在脊椎动物，为背侧中胚层与脊索）的信号使覆于其上的外胚层采取神经命运而非表皮命运的过程。在**默认模型**中——该模型由蛙胚实验发展而来——外胚层细胞除非接受 BMP 信号就采取神经命运，而 BMP 信号驱使它们成为表皮；组织者通过分泌**BMP 拮抗剂**（如 noggin、chordin 与 follistatin）诱导神经组织，它们结合 BMP 并阻止 BMP 到达其受体。
:::

支持默认模型的证据出人意料。蛙的**动物帽**细胞——通常形成表皮的细胞——在解离分散并彼此分开培养时变成了神经组织，仿佛某种分泌信号（后来证明是 BMP4）被稀释后，细胞便摆脱了表皮指令（Hans Grunz 与 Lothar Tacke，1989年；Ali Hemmati-Brivanlou 与 Douglas Melton，1990年代）。组织者的神经诱导因子 noggin（William Smith 与 Richard Harland，1992年）与 chordin（Sasai、De Robertis 与合作者，1994年）原来是结合 BMP 的蛋白。

::: warning “神经命运只是默认状态”
默认模型抓住了一个核心特征——BMP 抑制——但并不完整。在鸡与小鼠胚胎中，仅抑制 BMP 常常不足以诱导神经组织；还需要在**原肠形成**之前起作用的成纤维细胞生长因子（FGF）信号以及 Wnt 信号的抑制，且种类不同时相与组合不同。“默认”还掩盖了一个事实：解离的蛙细胞本已暴露于母源与早期合子信号之下。目前的看法是，神经诱导是若干信号共同作用的结果，BMP 抑制是其中一个必需要素。
:::

一旦被诱导，神经板卷起形成神经管（**神经胚形成**）；其边缘的组织变成神经嵴。这些运动的细胞力学见[[developmental-biology/organogenesis]]。

## 神经管的图式建立

神经管并不均一。它的细胞必须依其在两个轴上的位置变成不同类型的神经元：前后轴（前脑到脊髓）与背腹轴。

### 形态发生素的背腹图式建立

在脊髓，与感觉相关的中间神经元发生在背侧，运动神经元发生在腹侧。腹侧命运由 **Sonic hedgehog**（Shh）诱导。Shh 先由神经管下方的脊索分泌，随后由**底板**——管自身腹侧中线——分泌。背侧命运由**顶板**与覆盖其上的外胚层的 BMP 和 Wnt 诱导。Thomas Jessell 与合作者在1990年代证明，Shh 是一种**形态发生素**：暴露于不同 Shh 浓度的神经板外植体产生不同的神经元类型，最腹侧的类型（底板、V3 中间神经元，然后是运动神经元）需要最高浓度。Shh 浓度变化一倍就能切换细胞的命运。

::: definition 形态发生素 {#def-morphogen}
**形态发生素**是一种信号分子：由局部位点产生，跨越一片细胞形成浓度梯度，并在不同浓度阈值规定不同的细胞命运。
:::

形态发生素梯度的最简单模型，把该分子处理为从一个源扩散开、同时被细胞降解或捕获。

::: proposition 源的稳态梯度 {#prop-gradient}
一个在 $x = 0$ 产生、以扩散系数 $D$ 沿一条组织扩散、处处以一级速率 $k$ 被移除的形态发生素，达到稳态

$$
C(x) = C_0\,\mathrm{e}^{-x/\lambda}, \qquad \lambda = \sqrt{\frac{D}{k}},
$$ {#eq-gradient}

其中 $C_0$ 是源处的浓度。细胞按如下方式响应：若 $C$ 超过阈值 $T$ 就采取一种命运，于是两种命运的边界位于

$$
x_T = \lambda\ln\frac{C_0}{T}.
$$ {#eq-boundary}

假设：一维半无限场、$D$ 与 $k$ 恒定、源恒定、细胞读取稳态浓度。真实梯度常在生长中的组织里形成，而细胞会同时整合浓度与暴露时长。
:::

::: proof
稳态时扩散与移除平衡：$D\,C'' - kC = 0$。$x \to \infty$ 时有界的解是 $C = C_0\mathrm{e}^{-x\sqrt{k/D}}$，即[[#eq-gradient]]。令 $C(x_T) = T$ 得 $\mathrm{e}^{-x_T/\lambda} = T/C_0$，取对数得[[#eq-boundary]]。
:::

该方程与电压沿电缆的被动扩散在数学上相同（[[neuroscience/action-potential#prop-cable]]），只是以降解代替膜漏。

::: example 放置两条边界 {#ex-gradient}
一种形态发生素的 $D = 10\ \mu\mathrm{m^2\,s^{-1}}$，降解速率常数 $k = 10^{-4}$ s⁻¹。(a)计算 $\lambda$。(b)设 $\lambda = 100$ µm，细胞在 $C > 0.5\,C_0$ 时成为 A 型，在 $0.1\,C_0 < C < 0.5\,C_0$ 时成为 B 型。A/B 边界与 B/其他边界在哪里？(c)若源的输出加倍，各边界移动多少？
::: solution
(a)$\lambda = \sqrt{10/10^{-4}} = \sqrt{10^5} = 316$ µm。

(b)$x_\mathrm{A/B} = 100\ln(1/0.5) = 69$ µm，$x_\mathrm{B/other} = 100\ln(1/0.1) = 230$ µm。A 型细胞占最初69 µm，B 型占随后161 µm。

(c)$C_0$ 加倍使每条边界都增加 $\lambda\ln2 = 69$ µm：整个图式向外平移同一距离。指数梯度因此对源强的涨落敏感，胚胎使用额外机制使图式稳健，例如两端方向相反的梯度、调节降解的反馈，以及靶基因间能把边界锐化并稳定的基因调控网络。
:::
:::

在腹侧脊髓，形态发生素由一组**转录因子**读取。它们的表达在不同 Shh 浓度被开启或关闭（Pax6、Nkx2.2、Olig2、Nkx6.1 等），且彼此两两抑制。这种交叉抑制把平滑梯度转换成锐利稳定的前体区带，每个区带产生一类特定神经元：即 James Briscoe、Jessell 与合作者在2000年前后描述的**前体编码**。

### 前后图式建立

沿前后轴，后端化信号（Wnts、FGFs 与视黄酸）在后端最高，把最初偏前脑的神经板逐渐转变为越来越靠后的区域。在被分为七或八节、称为**菱节**的后脑，以及在脊髓，位置由 **Hox 基因**编码：它们在嵌套的表达区中表达，顺序与它们在染色体上的排列相同，正如昆虫体节的情形（[[developmental-biology/segmentation-hox]]）。在中脑与后脑之间，转录因子 Otx2（前）与 Gbx2（后）表达区之间的边界成为一个局部的**组织者**，即**顶盖-间脑界**（isthmus），它分泌 FGF8，为两侧的中间脑与小脑建立图式。

## 制造神经元

### 挑选神经前体：外侧抑制

在 *Drosophila* 胚胎，神经元来自**神经母细胞**——从上皮样神经外胚层脱离出来的干细胞。成簇的细胞表达**前神经基因**（如 *achaete–scute* 复合体），使其有成为神经母细胞的潜能，但每簇只有一个细胞成功。选择由经 Notch 通路的**外侧抑制**作出：一个表达略多配体 Delta 的细胞激活邻居的 Notch，降低其前神经基因表达与其自身的 Delta 产生，于是最初的差异被放大，直到一个细胞胜出。*Notch* 或 *Delta* 的突变使一簇所有细胞都变成神经母细胞，形成“神经性”表型：神经元多得不成比例而腹侧没有表皮。同样的 Notch–Delta 机制调控脊椎动物的神经发生。

每个 *Drosophila* 神经母细胞不对称分裂多次，每次分裂产生又一个神经母细胞和一个较小的**神经节母细胞**，后者分裂一次产生两个神经元或胶质细胞。Numb 与 Prospero 等蛋白在每次分裂时被分派进神经节母细胞，而神经母细胞依次表达的一串转录因子（先是 Hunchback，再是 Krüppel、Pdm 与 Castor）让不同时间出生的神经元获得不同身份：**时间编码**叠加在“来自哪个神经母细胞”的空间编码之上。

### 放射状胶质细胞与皮层的建造

在发育中的哺乳动物皮层，前体是**放射状胶质细胞**：纵贯神经管壁全厚的细长细胞，胞体位于衬于中央腔的**脑室带**，一条长突起伸至外表面。它们一度只被视为支架，但在2000–2001年前后（Magdalena Götz 与 Arnold Kriegstein 等人的课题组等）被证明它们自己就是神经干细胞，直接或间接经中间前体产生神经元。早期它们**对称**分裂，每次分裂产生两个前体、扩大前体池；后期它们**不对称**分裂，产生一个前体加一个神经元或中间前体。

::: example 需要多少轮分裂？ {#ex-divisions}
(a)若一个谱系中每个细胞都对称分裂，从一个细胞做出人大脑皮层约160亿个神经元需要多少轮分裂？(b)放射单位假说（拉基奇（Pasko Rakic），1995年）提出，皮层表面积由神经发生开始前对称分裂产生的前体数决定，而厚度由每个前体产生的神经元数决定。多三轮对称分裂，皮层表面积会增大几倍？(c)人皮层表面积约为小鼠皮层的千倍。仅此假论而言，需要多少轮额外的对称前体分裂？
::: solution
(a)$\log_2(1.6\times10^{10}) = 33.9$，约34轮。发育并不如此简单运作，但这个数字说明做出海量细胞只需很少几次翻倍。

(b)每轮使前体池翻倍，多三轮使其、从而令放射单位数与表面积乘以 $2^3 = 8$。

(c)$\log_2 1000 \approx 10$ 轮。实际上，灵长类还有额外前体——外脑室下带的**外放射状胶质细胞**（2010年由 Kriegstein 组等在人胎皮层中描述）——以及更长的神经发生期，两者共同贡献了扩张的大部分。从对称分裂切换到不对称分裂的时相发生小变化，就能对脑的大小有大影响，这是进化发育生物学的一个主题（[[developmental-biology/evo-devo]]）。
:::
:::

新出生的皮层神经元沿放射状胶质细胞的突起向外迁移，这种迁移方式由拉基奇（Rakic）1972年在胎猴脑描述。1961年，Joseph Angevine 与 Richard Sidman 给怀孕小鼠注射放射性胸苷——它会标记注射那一刻正在复制 DNA 的细胞——随后查明被标记的神经元在成年脑中的落位。早出生的神经元定居在皮层最深层，晚出生的越过它们定居到更浅层：皮层是**由内向外**建成的。相反，抑制性中间神经元出生在前脑另一部分，即神经节隆起，并切向迁入皮层。*reeler* 小鼠的皮层层次大致倒置，人们由此发现了分泌蛋白 Reelin：它由近表面的细胞产生，是神经元停下并按正确顺序装配所必需的。

## 找到路：轴突导向

神经元出生并迁移之后，必须把轴突送往正确的靶，有时要穿过挤满其他细胞的组织走几厘米。生长中轴突的尖端是**生长锥**：一个手状膨大，长满指状的**丝状伪足**与 薄膜状的**片状伪足**，富含肌动蛋白，在探测周围环境。卡哈尔（Ramón y Cajal）1890年在固定的鸡胚中描述了生长锥，并猜想它们受化学导向。Ross Harrison 1907年把蛙神经管小块植入淋巴滴中培养、看着纤维长出，证实轴突会从胞体长出：组织培养的发明。

### 化学亲和

罗杰·斯佩里（Roger Sperry）切断了蝾螈与蛙的视神经（它们的中枢轴突能再生），把眼旋转180°，再让神经重新生长。再生的轴突回到视顶盖中原来的位置，于是动物的行为仿佛世界是颠倒的：它们朝吊在头顶上方的诱饵向下猛啄，且从不学会纠正。在他的**化学亲和假说**（1963年完整表述）中，斯佩里提出每条视网膜轴突与每个顶盖细胞携带分子标签，也许以梯度形式，让轴突认出正确的伙伴。

### 导向分子

斯佩里的标签从1990年代起被找到，连同沿路径导向轴突的信号。最知名的是四个导向线索家族，各经生长锥上特定受体起作用，依受体与生长锥的状态不同可吸引亦可排斥：

- **Netrins**，分泌蛋白，最初从鸡脑纯化出来、作为连合轴突的吸引物（Tito Serafini、Timothy Kennedy、Marc Tessier-Lavigne 与合作者，1994年），与 *C. elegans* 的 UNC-6 同源，其突变体使环周轴突误导向；
- **Slits**，经 **Robo** 受体起作用的分泌排斥剂，使轴突不致不当地越过中线（在 *Drosophila* 与脊椎动物）；
- **Semaphorins**，分泌或膜结合，大多为排斥性；
- **Ephrins** 与其 **Eph** 受体酪氨酸激酶，膜结合，经细胞接触起作用。

视网膜-顶盖图使用最后一类。视网膜神经节细胞按从鼻侧视网膜低、颞侧视网膜高的梯度表达 EphA 受体；顶盖细胞按从顶盖前部低、后部高的梯度表达 ephrin-A 配体。受体多的颞侧轴突被 ephrin-A 排斥最强，止于顶盖前部；受体少的鼻侧轴突耐受更高的 ephrin，长到顶盖后部。图由两个梯度匹配而来，与斯佩里假说的精神高度一致（Uwe Drescher、Friedrich Bonhoeffer 与合作者；Hwai-Jong Cheng、John Flanagan 与合作者；均为1995年）。

::: example 匹配两个梯度 {#ex-matching}
沿一个轴为视网膜-顶盖投射建模。来自位置 $u$（鼻侧缘为0，颞侧缘为1）的视网膜轴突携带 EphA 受体，水平 $R = \mathrm{e}^{2u}$；顶盖位置 $v$（前为0，后为1）携带 ephrin-A，水平 $L = \mathrm{e}^{2v}$（任意单位）。设每条轴突向后生长，直到排斥信号 $RL$ 达到阈值 $S = \mathrm{e}^2$ 并停下。(a)每条轴突停在哪里？(b)图是否有序、方向如何？(c)金鱼切除半个顶盖后，整个视网膜最终被压缩着投到剩下的一半上。这个模型能解释吗？
::: solution
(a)$RL = \mathrm{e}^{2u + 2v} = \mathrm{e}^2$ 给出 $u + v = 1$，故来自 $u$ 的轴突停在 $v = 1 - u$。

(b)图连续而有序：鼻侧轴突（$u = 0$）投向后顶盖（$v = 1$），颞侧轴突（$u = 1$）投向前顶盖（$v = 0$），与真实动物一致。

(c)不能。阈值固定时，来自 $u < 0.5$ 的轴突会寻找已不存在的 $v > 0.5$ 的位置、无处可停，而来自 $u > 0.5$ 的轴突仍像以前那样投到剩下的前半。压缩要求轴突相互竞争：若每条轴突也被其他视网膜轴突排斥，或轴突停下的位置取决于已在场的轴突，图就能扩展或压缩以填满可用空间。把梯度匹配与竞争以及活动依赖精修结合起来的模型能复现这类实验，这说明斯佩里的化学亲和是必要的但不充分。
:::
:::

脊髓连合神经元的轴突提供了生长锥在途中改变响应的最佳研究范例。它们被底板来的 netrin 向腹侧吸引并越过中线。越过之后，它们不得不再穿回去。越过之前，Robo 受体在生长锥上保持低水平，于是轴突无视底板分泌的 Slit；越过之后，Robo 出现在生长锥上，Slit 排斥轴突，使其转向并沿对侧生长。一种导向线索因此可用于多个决定，因为生长锥的受体会变化。

生长锥必须多敏感？它在一侧与另一侧之间比较一种线索的浓度，横跨约10 µm 的宽度。它检测的量是每侧被占据的受体数。

::: proposition 经受体结合检测梯度 {#prop-detect}
设生长锥两半各有 $N$ 个解离常数为 $K_\mathrm{d}$ 的受体，局部浓度为 $C$，浓度在生长锥两侧相差比例 $p$。则两侧被占据受体数之差的期望值，除以该数的随机（二项）涨落，约为

$$
\mathrm{SNR} = p\sqrt N\,\frac{\sqrt{c}}{1 + c}, \qquad c = \frac{C}{K_\mathrm{d}},
$$ {#eq-snr}

当 $C = K_\mathrm{d}$ 时最大，为 $p\sqrt N/2$。

假设：受体在平衡时独立结合；单次快照读取占据数（不作时间平均）；梯度很小（$p \ll 1$）。
:::

::: proof {collapsed}
被占据受体的比例为 $b = c/(1 + c)$，故一侧被占据受体数的期望为 $Nb$。把浓度提高比例 $p$ 使 $c$ 增加 $pc$，使 $b$ 改变 $(\dd b/\dd c)\,pc = pc/(1 + c)^2$；两侧之差为 $Npc/(1+c)^2$。每侧被占据受体数服从二项分布，方差 $Nb(1 - b) = Nc/(1 + c)^2$，标准差为 $\sqrt{Nc}/(1 + c)$。相除即得[[#eq-snr]]。函数 $\sqrt c/(1 + c)$ 在 $(1 + c)/(2\sqrt c) = \sqrt c$ 处导数为零，即 $c = 1$，该处其值为 $1/2$。
:::

::: widget plot
f: p*sqrt(N)*sqrt(10^x)/(1 + 10^x)
x: -3, 3
y: 0, 3
sliders: p=0.02:0.005:0.1:0.005; N=10000:1000:50000:1000
labels: \text{信噪比}
hlines: 1
caption: 生长锥检测梯度的信噪比（纵轴），由[[#eq-snr]]给出，对线索浓度相对受体解离常数之比的对数（横轴：0表示 $C = K_\mathrm{d}$）。$p$ 是生长锥两侧的浓度差比例，$N$ 是每半的受体数（滑块）。检测在 $K_\mathrm{d}$ 附近最佳，远高于它（受体饱和）与远低于它（结合的受体太少）时都失败。每半10,000个受体时，2 %的梯度最好也只有约1的信噪比；可靠的导向需要时间上的平均，以及更陡的梯度。
:::

::: example 指数梯度中的生长锥 {#ex-growth-cone}
一种导向线索形成长度常数 $\lambda = 200$ µm 的指数梯度。一个10 µm 宽的生长锥每半有 $N = 10{,}000$ 个受体。(a)生长锥两侧的浓度差比例 $p$ 是多少？(b)由[[#eq-snr]]，最好的信噪比是多少？(c)浓度为 $100K_\mathrm{d}$ 时、以及 $0.01K_\mathrm{d}$ 时的比值是多少？(d)这些答案对梯度上何处导向有效有何含义？
::: solution
(a)横跨10 µm 浓度降为 $\mathrm{e}^{-10/200}$ 倍，故 $p = 1 - \mathrm{e}^{-0.05} = 0.049$。注意指数梯度中 $p$ 处处相同，因为相对斜率恒定。

(b)$p\sqrt N/2 = 0.049\times100/2 = 2.4$。

(c)$c = 100$ 时：$0.049\times100\times\sqrt{100}/101 = 0.49$。$c = 0.01$ 时：$0.049\times100\times0.1/1.01 = 0.49$。两者都比最优差五倍。

(d)尽管相对梯度处处相同，生长锥只在浓度处于 $K_\mathrm{d}$ 约十倍范围内时才能可靠读取。指数梯度下这一范围跨 $\lambda\ln100 \approx 4.6\lambda$，此处约900 µm。超出它，轴突需要另一种线索或受体，这是长通路被分成许多以中间靶为段的短段的原因之一。
:::
:::

该计算解释了为什么导向线索只在有限距离上起作用（几百微米到一毫米），为什么生长锥对信号作数分钟尺度的整合，以及为什么许多导向系统组合多种线索。

## 存活、突触形成与精修

### 神经营养因子与细胞死亡

在发育中脊椎动物神经系统的许多部位，产生的神经元远多于存活的。在鸡胚，维克托·汉堡（Viktor Hamburger）与丽塔·莱维-蒙塔尔奇尼（Rita Levi-Montalcini）发现，切除一个肢芽会使对应的多数运动与感觉神经元死亡，而嫁接一个额外肢体则增加存活数。鸡腰段脊髓约一半的运动神经元在正常发育中死亡，就在其轴突到达肌肉后不久。这引出了**神经营养假说**：靶产生有限量的存活因子，神经元争夺它；得到足够的存活，其余经**细胞凋亡**死亡，即[[cell-biology/tissues-and-cell-death]]描述的程序性细胞死亡。这一过程把神经元数目匹配到靶的大小。

第一个此类因子**神经生长因子**（NGF），由莱维-蒙塔尔奇尼在1950年代初、当时与汉堡合作时发现：移植入鸡胚的小鼠肉瘤使感觉与交感神经节大量生长。她与生物化学家斯坦利·科恩（Stanley Cohen）纯化了它，用了两个出人意料的丰富来源：蛇毒与小鼠颌下腺。莱维-蒙塔尔奇尼与科恩分享1986年诺贝尔奖。NGF 如今是**神经营养素**家族之一（还有 BDNF、NT-3 与 NT-4），经 Trk 受体酪氨酸激酶起作用，并从轴突终末逆向运回胞体。

### 建造突触

生长锥到达靶后，必须形成突触。在脊椎动物神经-肌肉接头，运动神经末梢分泌**agrin**，经肌肉的 LRP4 与激酶 **MuSK** 受体复合物使乙酰胆碱受体在终末下成簇；缺乏 agrin 或 MuSK 时，神经-肌肉接头不能正常形成。中枢突触使用许多黏附分子，如突触前的 neurexins 与突触后的 neuroligins，其组合有助于规定哪些伙伴相连。

### 活动依赖的精修

分子线索建立的连接大致正确，但并不精确。发育的最后阶段，神经活动对其精修：保留一起使用的连接，删除不一起使用的。

1963年，托尔斯滕·维塞尔（Torsten Wiesel）与戴维·休伯尔（David Hubel）在小猫出生后头几个月闭合其一眼，发现重开该眼时，视觉皮层对它响应的神经元寥寥无几；多数只由保持开放的眼驱动。同样剥夺成年猫却没有这种效应。存在一个**关键期**，其间经验塑造来自两眼的连接；他们后来的解剖学工作表明，被剥夺眼的**眼优势柱**缩小，而开放眼的扩大。两眼争夺皮层领地，更活跃的一眼胜出。

视觉开始之前就需要活动。在光感受器工作之前，发育中的视网膜产生自发的**视网膜波**——每一两分钟扫过视网膜的一阵活动——使相邻的神经节细胞一起发放而远处的不会（Markus Meister、Rachel Wong、Denis Baylor 与卡拉·沙茨（Carla Shatz），1991年，记录发育中雪貂的视网膜）。人们认为这些相关性提供了精修视网膜拓扑图与分离两眼输入所用的信息。一个醒目的证明来自蛙：把第三只眼移植进蝌蚪，使两眼投到同一个顶盖，它们的轴突分离成交替的条带，如同眼优势柱，尽管蛙通常没有（Martha Constantine-Paton 与 Margaret Law，1978年）。只要两组活动不相关的输入争夺同一个靶，条带就会形成。

::: intuition 一起发放的细胞连在一起
活动依赖精修背后的规则，正是唐纳德·赫布（Donald Hebb）为学习提出的那条（[[neuroscience/plasticity-learning]]）：当突触前的输入反复帮助突触后细胞发放时，突触被加强；当它错步发放时，突触被削弱。视网膜波期间相邻视网膜细胞的输入一起发放，于是它们加强到同一靶细胞的连接并赶走远处细胞的输入，使图变锐。两眼的输入彼此不相关，于是每个靶细胞被一眼主导，而每眼影响之局域扩散产生柱。卡拉·沙茨1992年对这一思想的概括“cells that fire together wire together”（一起发放的细胞连在一起）已成为口号。
:::

新生哺乳动物的神经-肌肉接头上，每条肌纤维受数条运动轴突支配；出生头几周内除一条外全部撤退，经活动依赖的竞争（**突触消除**）。在脑内，小胶质细胞在同一时期吞噬较弱的突触（[[neuroscience/neurons-glia]]）。发育因此先建造过量再修剪之，这一策略让回路得以适配它们实际遭遇的身体与世界。

::: quiz

- [ ] 缝合眼的视网膜退化了。
- [ ] 小猫学会了忽略缝合眼。
- [x] 两眼的输入竞争皮层神经元，较活跃一眼的输入被加强，不活跃一眼的输入被削弱并撤退。

::: solution
被剥夺眼的视网膜及其到丘脑的投射基本完好；变化发生在皮层。维塞尔与休伯尔证明，闭合双眼造成的损失远小于闭合单眼，这说明效应取决于两眼间的竞争而非单纯不用。解剖上，缝合眼的膝状-皮层轴突丧失领地，开放眼的则扩张。
:::
:::

### 成体的神经发生与再生

成年哺乳动物脑的多数神经元与动物同寿。两个例外在啮齿类已确立：嗅球与海马齿状回终生增添新神经元。在鸣禽，费尔南多·诺滕伯姆（Fernando Nottebohm）与合作者在1980年代证明，金丝雀的鸣控核团随季节大量得失神经元。成年人类海马是否以有意义的速率继续神经发生，自2018年以来一直是相互矛盾研究对象，各方使用不同的组织处理方法与标记物；截至2026年问题尚未定论。

鱼类与两栖类的中枢神经系统能再生被切断的轴突——斯佩里的实验正是以此为前提——而成年哺乳类的通常不能，尽管哺乳类的外周轴突会重新生长。差别部分在环境：髓鞘相关的生长抑制因子，以及损伤后星形胶质细胞形成的瘢痕；部分在神经元自身：随成熟丧失大部分内在生长能力。同时克服两者，是脊髓损伤研究的一大目标。

::: application 发育与疾病
神经系统由如此多精确计时的步骤建成，发育的扰动因此是宽广的人类疾病谱的基础，从神经管闭合缺陷（孕前与孕早期充足的叶酸能降低其风险）到神经元迁移障碍，再到神经发育性疾病——其遗传病因常在于突触蛋白与染色质调控因子的基因。临床方面归[医学图谱：儿科](/learn/medicine/course.php?c=paediatrics)；这里的要点是，本章每个机制一旦失效都有可识别的后果。
:::

::: history
卡哈尔（Ramón y Cajal）在1890年描述了生长锥，罗斯·哈里森（Ross Harrison）在1907年培养出轴突。施佩曼与曼戈尔德在1924年报告了组织者（施佩曼获1935年诺贝尔奖；曼戈尔德于1924年、论文发表前去世）。汉堡（Hamburger）与莱维-蒙塔尔奇尼从1930与1940年代起研究鸡的靶依赖神经元存活，NGF 在1950年代被发现和纯化。Angevine 与 Sidman 在1961年展示皮层由内向外生成，斯佩里在1963年提出化学亲和，维塞尔与休伯尔在1963年描述了单眼剥夺的效应。拉基奇（Rakic）在1972年描述了放射状胶质导向的迁移。分子时代带来了 noggin（1992年）、chordin（1994年）、netrins（1994年）、视网膜-顶盖图的 ephrin 梯度（1995年）、Slit 与 Robo（1998–1999年），以及把放射状胶质细胞认作神经干细胞（2000–2001年）。
:::

## 由此引向何处

本章的发育规则在成年脑中以学习机制延续：相关突触的赫布加强连同输入之间的竞争，在[[neuroscience/plasticity-learning]]中重现。比较的主题——不同的脑如何解决相似的问题——在[[behaviour/mechanisms-of-behaviour]]中回归。

- 海绵与扁盘动物没有神经元但有许多突触基因；栉水母、刺胞动物与两侧对称动物有神经系统。神经元演化过一次还是两次，取决于栉水母位置的争议。
- 两侧对称动物集中化了其神经系统；脊索动物的背神经索与节肢动物的腹神经索的 BMP 信号方向相反，与背腹倒转相符。
- 神经诱导需要阻断 BMP 信号（组织者来的 noggin、chordin、follistatin），在羊膜动物还需 FGF 与 Wnt 依赖的信号。
- 神经管由形态发生素建立图式：腹侧 Shh，背侧 BMP 与 Wnt；稳态梯度 $C = C_0\mathrm{e}^{-x/\lambda}$、$\lambda = \sqrt{D/k}$ 把边界放在 $\lambda\ln(C_0/T)$。Hox 基因与局域组织者建立前后轴图式。
- Notch–Delta 外侧抑制挑选神经前体；放射状胶质细胞是皮层干细胞；皮层沿放射状胶质迁移、由内向外建成。
- 生长锥追随吸引与排斥线索（netrins、Slits、semaphorins、ephrins），途中改变其受体；梯度检测在受体 $K_\mathrm{d}$ 附近最佳，且受噪声限制。
- 神经营养因子（NGF 及亲戚）把神经元数匹配到靶；许多神经元群体约一半死亡。
- 活动在关键期内经赫布竞争精修连接（单眼剥夺、视网膜波、三眼蛙、突触消除）。
:::

## 习题

::: exercise 形态发生素的长度常数 {level=1 check="100"}
一种形态发生素的 $D = 5\ \mu\mathrm{m^2\,s^{-1}}$，降解速率常数 $k = 5\times10^{-4}$ s⁻¹。其稳态长度常数以 µm 计是多少？
::: solution
$\lambda = \sqrt{D/k} = \sqrt{5/(5\times10^{-4})} = \sqrt{10^4} = 100$ µm。
:::
:::

::: exercise 阈值边界 {level=1 check="161"}
$\lambda = 70$ µm，对 $0.1\,C_0$ 的阈值，边界在何处（取最近 µm）？
::: solution
$x = 70\ln10 = 70\times2.303 = 161$ µm。
:::
:::

::: exercise 给实验归类 {level=1}
说出下列各实验分别证明了什么发育过程：(a)施佩曼与曼戈尔德的背唇移植；(b)Angevine 与 Sidman 的胸苷标记；(c)斯佩里的眼旋转；(d)汉堡的肢芽切除；(e)维塞尔与休伯尔的单眼剥夺。
::: solution
(a)组织者的诱导，包括神经诱导。(b)皮层神经发生与迁移的由内向外顺序。(c)视网膜轴突与顶盖靶之间特异的分子识别（化学亲和）。(d)神经元的靶依赖存活（神经营养假说的基础）。(e)关键期内的活动依赖竞争。
:::

::: exercise 梯度的稳健性 {level=2}
两个胚胎产生同样 $\lambda = 50$ µm 的形态发生素，但一个的源强30 %。边界设在 $0.2\,C_0$ 阈值处（$C_0$ 为正常源强）。(a)第二个胚胎中边界移动多少？(b)若组织长300 µm，这是大误差吗？(c)描述一种能使边界位置独立于源强的机制。
::: solution
(a)移动量是 $\lambda\ln1.3 = 50\times0.262 = 13$ µm。(b)相对300 µm 约为场的4 %，或许一两个细胞直径：不大，但对一条必须与其他边界对齐的边界可能很重要。(c)几种机制有帮助：来自另一端的第二个方向相反的梯度，边界由两者之比设定；**自增强降解**，即形态发生素提高自身移除速率，使源强在源附近对响应变平；源随组织大小缩放；或下游交叉抑制的转录因子造出锐利、带滞后的边界，一旦形成便抵抗小变化。
:::
:::

::: exercise 解读一个导向实验 {level=2}
含连合神经元的大鼠胚胎背侧脊髓外植体，被放在距底板外植体300 µm 的胶原胶中。它们的轴突朝底板生长。当底板被转为分泌 netrin-1 的转染细胞替代时，得到同样结果；对照细胞没有吸引。(a)这表明什么？(b)如何证明 netrin 对冲轴突在体内到达底板不仅是充分的而且是必需的？(c)预测 *Robo* 突变果蝇中连合轴突的行为。
::: solution
(a)Netrin-1 在远距离上足以吸引连合轴突，与其作为底板吸引物相符。(b)检查缺失 netrin-1 或其受体 DCC（deleted in colorectal cancer，结直肠癌中缺失）的胚胎；这类小鼠许多连合轴突未能到达底板，表明 netrin 在体内是必需的（Shh 等其他线索也有贡献）。(c)没有 Robo，轴突在中线不被 Slit 排斥，于是反复越过并退回中线；这就是该基因得名“roundabout”（环形交叉）的表型。
:::
:::

::: exercise 细胞死亡与靶的大小 {level=2}
一个鸡胚产生20,000个腰段运动神经元，后肢肌肉提供的营养支持可供12,000个存活。(a)多大比例死亡？(b)预测切除一侧肢芽后、以及嫁接一个使靶增大40 %的额外肢体后的存活数。(c)神经系统为何要产生过量神经元再把它们杀死，而不恰好产生正确数目？
::: solution
(a)$8000/20{,}000 = 40$ %。(b)没有肢体时几乎全部死亡（仅少数靠其他支持存活）；靶大40 %时约 $12{,}000\times1.4 = 16{,}800$ 个存活，Hollyday 与汉堡在1976年定性地证实了这一点。(c)先过量产生再竞争，能把神经元数匹配到大小在个体间与演化中都在变的靶，而无须神经系统预先知道靶的大小。它还淘汰轴突走错地方、得不到营养支持的神经元。代价是浪费的细胞；好处是稳健的匹配。
:::
:::

::: exercise 梯度检测 {level=2 check="1.25"}
用[[#eq-snr]]，每半有10,000个受体、处于2.5 %梯度中的生长锥，最好的信噪比是多少？保留两位小数。同一受体数下，要达到比值3需要多大的梯度？
::: solution
$C = K_\mathrm{d}$ 时，$\mathrm{SNR} = p\sqrt N/2 = 0.025\times100/2 = 1.25$。比值为3时，$p = 2\times3/\sqrt N = 6/100 = 0.06$，即生长锥两侧相差6 %。另一种办法：对 $M$ 张独立快照作时间平均使比值乘以 $\sqrt M$，因此约六个独立样本就能把2.5 %的梯度带到比值3。
:::
:::

::: exercise 集中化神经系统的演化 {level=3}
两个假说解释昆虫与脊椎动物中枢神经系统的相似：（H1）共同祖先已有集中化的神经系统并被继承；（H2）集中化在两谱系独立演化，用的是一套遗传的图式建立基因工具箱。(a)什么证据支持 H1？(b)什么证据支持 H2？(c)哪些其他动物类群的观察有助于定夺？
::: solution
(a)同一批基因建立神经系统的背腹轴（BMP/Dpp 与 chordin/Sog），其保守功能由跨物种实验证明；相似的一套转录因子（如 *Nkx*、*Ind*/*Gsx* 与 *Msx* 基因）在昆虫、环节动物与脊椎动物中把神经索划分为同样的内外侧纵列；Hox 及其他前后轴基因在脑与神经索中按保守顺序表达。(b)许多两侧对称动物类群，包括无肠目、半索动物等，有弥散或基底上皮的神经系统；工具箱基因也在神经系统之外使用，故其保守表达可能反映保守的外胚层图式建立而非保守的神经索；且中枢神经系统的结构差别很大。(c)集中化与弥散神经系统在良好解析的两侧对称动物系统树上的分布：若分支最靠近两侧对称动物基部的类群是弥散系统，则 H2 得支持；环节动物及其他冠轮动物、以及半索动物及其他后口动物神经索基因表达的细节比较，将显示纵列图式是否在有神经索处就存在。截至2026年问题仍未解决。
:::

::: exercise 关键期 {level=3}
小猫在四周龄时缝合一眼几天，就造成眼优势的大偏移；成年猫缝合数月却几乎无影响。(a)提出两种能关闭关键期的细胞机制。(b)小鼠实验显示，阻止某类抑制性中间神经元成熟可推迟关键期，而用苯二氮䓬增强 GABA 能抑制可提前触发。这表明什么？(c)可塑性随年龄下降为何可能有适应意义？
::: solution
(a)可能的机制：抑制回路的成熟，改变兴奋-抑制平衡与赫布可塑性的条件；**围神经元网**的形成，即某些中间神经元周围的细胞外基质结构，稳定突触；髓鞘化与限制轴突出芽的生长抑制分子；以及 NMDA 受体亚基的改变，改变驱动可塑性的 Ca²⁺ 信号。(b)关键期的开启取决于抑制的阈值，尤其来自快发火的小清蛋白表达中间神经元（Takao Hensch 与合作者）：时相由抑制回路的成熟设定，而非年龄本身。(c)生命早期眼、头与身体都在生长，脑必须对它们校准；生长一旦停止，一个稳定校准好的回路就很宝贵，继续大规模可塑性会冒因临时变化（如暂时受伤）而破坏它的风险。成人仍在学习，但用更受限的机制（[[neuroscience/plasticity-learning]]）。
:::
