据奥托·勒维（Otto Loewi）本人所述，1920年复活节圣周日前夜，他半夜醒来，脑中带着一个实验设计，随手记了下来，到早晨却认不出自己的笔记。第二晚那个念头又回来了，这一次他径直赶往格拉茨的实验室。他取来两颗跳动着的蛙心，其中一颗还连着迷走神经，用盐溶液维持其存活。刺激迷走神经使第一颗心变慢。当他把灌流过第一颗心的液体转移到第二颗心上时，第二颗心也慢了下来。某种由神经释放的东西传递了信号，勒维把它称为 *Vagusstoff*（“迷走物质”）。后来它被鉴定为乙酰胆碱。

勒维的实验发表于1921年，了结了关于神经究竟以电方式还是以化学方式作用于其靶器官的长期争论：至少有些作用是化学性的。本章讲的是神经元向其他细胞传递信号的接点—— **突触**。我们先看较简单的 **电突触**，再看 **化学突触**：到达终末的动作电位如何引起递质释放，而且是按固定大小的“一份份”释放；递质如何作用于受体产生突触后电位；以及神经元如何累加成千上万个这样的电位，来决定是否发放。电学工具——弦电导方程与电缆——来自[[neuroscience/resting-potential]]和[[neuroscience/action-potential]]。

## 电突触

在**电突触**处，两个细胞的膜相距仅约3.5 nm，并由**缝隙连接**相连：那是成簇的通道，每个通道由两个半通道首尾对接、跨过间隙而成，两个细胞各贡献一个半通道。在脊椎动物，每个半通道是**连接蛋白（connexin）**亚基的六聚体（哺乳动物脑中主要的神经元类型是连接蛋白36）；在无脊椎动物，与之对应的蛋白是无亲缘关系的 **innexin（内衬连接蛋白）**。中央孔道约1.2–1.5 nm 宽，让离子和分子量至多约1 kDa 的小分子直接从胞质流到胞质。

埃德温·弗什潘（Edwin Furshpan）和戴维·波特（David Potter）1959年在螯虾的巨运动突触发现了电传递：电流容易从突触前纤维流向突触后纤维，反向则不然——这个接点**整流**。相比之下，多数电突触双向传导。

::: definition 耦合系数 {#def-coupling}
电突触的强度用**耦合系数**描述：向突触前细胞注入电流时，突触后细胞的稳态电压变化与突触前细胞的稳态电压变化之比：

$$
k = \frac{\Delta V_2}{\Delta V_1}.
$$

对由连接电导 $g_\mathrm{j}$ 相连的两个细胞，若第二个细胞对外的输入电导为 $g_2$，则 $k = g_\mathrm{j}/(g_\mathrm{j} + g_2)$。
:::

这个公式来自把接点和第二个细胞的膜当作分压器处理：流过接点的电流 $g_\mathrm{j}(V_1 - V_2)$ 必须经第二个细胞的膜流出，即 $g_2V_2$。当连接电导相对于突触后细胞的电导很大时耦合很强，所以电突触对高输入电阻的小细胞作用最佳。

电突触很快，几乎没有延迟，而且是双向的。它们用于重视速度或同步的场合：例如螯虾巨纤维和鱼类 Mauthner 细胞所在的逃逸回路，Mauthner 细胞上的棒状末梢是电与化学混合的突触；哺乳动物下橄榄核的神经元和皮层的抑制性中间神经元（它们倾向于同步发放）；以及视网膜——视杆驱动神经元之间的耦联可以汇聚微弱信号。其局限同样清楚：不能放大，不易翻转信号的符号，可供调制的余地有限。

::: example 两个神经元之间的耦合 {#ex-coupling}
两个神经元由总电导2 nS 的缝隙连接相连。第二个神经元的输入电阻为200 MΩ。(a)耦合系数是多少？(b)第一个细胞出现一次20 mV、类似动作电位的去极化，且持续时间长到达到稳态。第二个细胞的反应有多大？(c)为什么真实1 ms 动作电位的反应会更小？
::: solution
(a) $g_2 = 1/200\ \mathrm{M\Omega} = 5$ nS。$k = 2/(2 + 5) = 0.29$。

(b) $\Delta V_2 = 0.29\times20 = 5.7$ mV。

(c) 第二个细胞的膜电容必须经接点充电，时间常数的量级为 $C_2/(g_\mathrm{j} + g_2)$；远短于此的脉冲会被滤除，所以1 ms 的锋电位产生的反应比稳态耦合系数预测的更小、更慢。电突触是低通滤波器，传递慢信号优于快信号。
:::
:::

## 化学突触

神经系统中的大多数突触是化学性的。在 **化学突触**，突触前终末与突触后膜之间隔着约20 nm 宽的间隙。终末内含有 **突触囊泡**，直径约40 nm，每个充满数千个递质分子；它们聚集在特化的释放位点—— **活性带（active zone）**——上，正对着突触后膜中由受体和支架蛋白构成的致密基质—— **突触后致密区**。

::: definition 化学性突触传递 {#def-chemical}
化学突触的传递按一系列步骤进行：

1. 动作电位使突触前终末去极化；
2. 活性带上的电压门控 Ca²⁺ 通道开放，Ca²⁺ 进入；
3. Ca²⁺ 结合已停泊囊泡上的感受蛋白，触发其与质膜融合（**外排（胞吐）**），把递质释放到间隙中；
4. 递质扩散过间隙，结合突触后膜上的**受体**，使其打开离子通道或启动胞内信号转导；
5. 突触后电导由此产生的变化形成**突触后电位**，去极化（兴奋性，EPSP）或超极化或稳定（抑制性，IPSP）；
6. 递质经酶解、细胞重摄取或扩散被清除；囊泡膜经内吞回收并重新装填。

从突触前动作电位到达到突触后电流起始的这段时间—— **突触延迟**——在20–37 °C 约为0.5 ms，其中大部分耗在 Ca²⁺ 通道开放和囊泡融合上。
:::

化学传递比电传递慢，但优势是决定性的。它能放大：一个小小的终末释放的递质就足以使一根大肌纤维去极化。它能翻转信号的符号：同样的突触前去极化可以兴奋一个细胞而抑制另一个，取决于受体。而且它提供许多控制的环节，从 Ca²⁺ 进入的量到受体的数目，而后者正是学习发挥作用的部位（[[neuroscience/plasticity-learning]]）。

### 神经-肌肉接头

运动神经元与骨骼肌纤维之间的突触—— **神经-肌肉接头**，又称 **终板（end-plate）**——之所以成为化学突触的模型，是因为它大、易接近，且只有一个可辨认的突触后细胞。亨利·戴尔（Henry Dale）、威廉·费尔德贝格（Wilhelm Feldberg）和玛尔特·福格特（Marthe Vogt）于1936年证明，刺激运动神经会释放乙酰胆碱（ACh）；蛙缝匠肌的终板电位（EPP）则成为伯纳德·卡茨（Bernard Katz）及其伦敦的合作者一系列杰出实验的对象。

EPP 通常很大，达数十毫伏，远超触发肌肉动作电位所需：神经-肌肉接头的传递有很高的**安全系数**。为了研究它，卡茨及其合作者通过降低胞外 Ca²⁺ 并升高 Mg²⁺（Mg²⁺ 与 Ca²⁺ 竞争进入）来压低它。

## 量子式释放

1952年，保罗·法特（Paul Fatt）和卡茨注意到，静息的蛙终板以随机间隔产生约0.5 mV 的自发性微小去极化，大约每秒一次。这些**微终板电位（mEPP）**的时间过程与 EPP 相同，可被箭毒（阻断 ACh 受体）阻断，并可被乙酰胆碱酯酶抑制剂增大。它们显然由 ACh 引起，且以固定量自发释放。

随后，何塞·德尔·卡斯蒂略（José del Castillo）和卡茨在低 Ca²⁺（此时 EPP 很小）下检验 EPP。反复刺激神经，反应逐次波动，呈台阶状：有时完全没有（一次**失败**），有时恰为一个 mEPP 大小，有时是两倍，如此等等。1954年他们提出**量子假说**。

::: definition 量子假说 {#def-quantal}
递质以多分子组成的包—— **量子（quantum）**——释放，大小几乎恒定。每个量子产生幅度为 $q$ 的突触后反应（**量子大小**，等于微电位）。每个神经冲动释放的量子数逐次随机变化；其均值即 **量子含量** $m$，故平均突触后反应为 $\bar v = mq$。

统计模型：若终末内有大数目 $n$ 个释放位点，每个独立地以小概率 $p$ 释放一个量子，则每个冲动释放的量子数服从均值 $m = np$ 的**二项分布**；当 $p$ 小时近似**泊松分布**：

$$
P(k) = \frac{\mathrm{e}^{-m}m^k}{k!}.
$$ {#eq-poisson}
:::

量子的物理身份很快得到落实。电子显微照片显示终末内囊泡拥挤；1973年，约翰·霍伊泽（John Heuser）和托马斯·里斯（Thomas Reese）在蛙神经-肌肉接头追踪了囊泡膜的融合与再循环；1979年，他们在刺激后数毫秒内冷冻终末，捕捉到正在融合的囊泡，其数目与量子含量相符。一个量子就是一个囊泡的内含物。

::: proposition 估计量子含量 {#prop-quantal}
在[[#def-quantal]]的泊松模型下，可由 $N$ 次试验以三种彼此独立的方式估计量子含量：

1. **由均值**：$m = \bar v/q$，平均反应除以平均微电位；
2. **由失败次数**：由于 $P(0) = \mathrm{e}^{-m}$，若 $N$ 次试验中有 $n_0$ 次失败，则 $m = \ln(N/n_0)$；
3. **由方差**：泊松分布的方差等于均值，故反应的变异系数为 $\mathrm{CV} = 1/\sqrt{m}$，即 $m = 1/\mathrm{CV}^2$（忽略 $q$ 自身的变异）。

三种估计相互一致是对模型的检验。假设：各量子独立释放、逐次试验概率恒定、量子大小恒定、量子线性相加。
:::

::: example 蛙终板的量子分析 {#ex-quantal}
在低 Ca²⁺ 下，对蛙运动神经给予200次刺激，终板反应按量子数分类如下（将每个反应与平均微电位0.40 mV 比较计数）：

| 量子数 | 0 | 1 | 2 | 3 | 4 | 5及以上 |
|---|---|---|---|---|---|---|
| 试验次数 | 37 | 63 | 51 | 31 | 13 | 5 |

平均反应幅度为0.68 mV。(a)由均值和失败次数估计 $m$。(b)用[[#eq-poisson]]预测每一类的期望试验次数并加以比较。(c)你能得出什么结论？
::: solution
(a)由均值：$m = 0.68/0.40 = 1.70$。由失败次数：$m = \ln(200/37) = \ln5.41 = 1.69$。两者一致。

(b)取 $m = 1.69$，$200\,\mathrm{e}^{-1.69}m^k/k!$ 给出：$k = 0$：37.0；1：62.4；2：52.7；3：29.6；4：12.5；5及以上（用差值）：5.8。观察值37、63、51、31、13、5与之高度吻合。

(c)数据符合固定大小量子的泊松释放，正如德尔·卡斯蒂略和卡茨的发现。χ²检验（方法见[[biostatistics]]）会确认差异完全在随机波动范围之内。注意失败估计与均值估计的一致是更强的检验，因为两者利用的是数据的不同部分。
:::
:::

在生理 Ca²⁺ 下的正常蛙终板，量子含量为一百或更多的量级，哺乳动物终板与之相当；从不出现失败。相比之下，脑中许多突触的单个突触前动作电位在每个活性带平均释放一个囊泡甚至不足一个，传递在很大比例的时间里会失败。中枢突触的不精确是设计使然，而可靠性本身就是可塑性所调节的内容之一。

当 $p$ 不小时，就需要二项模型。若释放位点数为 $n$，每个以概率 $p$ 释放，则平均反应为 $npq$，方差为 $np(1-p)q^2$。在不同释放概率下（通过改变 Ca²⁺）测量均值和方差，即可分别估计 $n$、$p$ 和 $q$：这种**方差-均值分析**在中枢突触被广泛使用。

## Ca²⁺ 与释放机器

动作电位到达终末本身还不够：在无 Ca²⁺ 溶液中没有释放。卡茨和里卡多·米莱迪（Ricardo Miledi）1967年证明，Ca²⁺ 必须在冲动到达的那一刻存在；他们能够在 Na⁺ 和 K⁺ 通道均被阻断的终末中，只要胞外有 Ca²⁺，就用去极化引起释放。跟随释放的是 Ca²⁺ 内流，而不是动作电位本身。

弗雷德里克·道奇（Frederick Dodge）和拉米·拉哈米诺夫（Rami Rahamimoff）（1967）测量了蛙终板 EPP 对胞外 Ca²⁺ 浓度的依赖关系，发现其关系很陡，在低浓度下接近四次方律：Ca²⁺ 加倍，释放约增为十六倍。他们将其解释为：融合之前约四个 Ca²⁺ 协同结合到一个感受蛋白上。

caption: 相对递质释放（纵轴）对胞外 Ca²⁺ 浓度（横轴，mmol L⁻¹），模型为协同性：$n$ 个 Ca²⁺ 必须结合到一个半饱和浓度为 $K$ 的感受蛋白上（两者均由滑块设定）。低 Ca²⁺ 时，释放随浓度的 $n$ 次方增长，所以 $n = 4$ 时 Ca²⁺ 加倍释放约增为十六倍；高浓度时释放饱和。设 $n = 1$ 可看到平缓的非协同曲线。这种陡峭的协同关系意味着突触前 Ca²⁺ 进入的微小变化会对传递产生很大影响，许多调质都利用这一杠杆。
:::

融合的分子机器在1990年代由酵母遗传学、膜融合生物化学和神经毒素研究阐明。

- **SNARE 蛋白。** 囊泡上的突泡蛋白（synaptobrevin，VAMP）与质膜上的突触融合蛋白（syntaxin）和 SNAP-25 相互缠绕，形成一个紧密的四螺旋束——**SNARE 复合物**——把两片膜拉近并驱动融合。詹姆斯·罗思曼（James Rothman）的团队在1993年鉴定出它们是通用膜融合机器中的受体。
- **Ca²⁺ 感受蛋白。** **突触结合蛋白（synaptotagmin）** 是带两个 Ca²⁺ 结合 C2 结构域的囊泡蛋白，触发快速的同步释放；缺乏突触结合蛋白-1的小鼠丧失快速释放，但保留缓慢的异步释放（托马斯·聚德霍夫（Thomas Südhof）与合作者，1994）。
- **启动与组织。** Munc13 和 Munc18 使囊泡做好融合准备；RIM 等活性带支架把 Ca²⁺ 通道保持在已停泊囊泡几十纳米之内，使每个囊泡暴露于短暂而极高的局部 Ca²⁺ 浓度（数十微摩尔），而不是终末内低得多的平均浓度。

罗思曼、兰迪·谢克曼（Randy Schekman）和聚德霍夫因囊泡运输研究分享2013年诺贝尔生理学或医学奖。梭菌神经毒素——破伤风毒素和肉毒毒素——是切割 SNARE 蛋白的蛋白酶，从而阻断释放；SNARE 的功能正是靠它们被鉴定出来的。

融合之后，囊泡膜经网格蛋白介导的内吞及更快的几种方式回收，由质子梯度驱动的囊泡转运体重新装入递质，返回囊泡池。整个循环耗时数秒到数十秒；一个终末只持有几百个囊泡，因此持续的高频发放会耗尽囊泡池，这是**突触衰减（depression）**的来源之一。相反，**易化（facilitation）**发生在第二个冲动于第一个冲动之后数十毫秒内到达、终末内尚有余 Ca²⁺ 时，于是第二个冲动的释放增强。两者都是短时程可塑性的形式，使突触成为脉冲序列的滤波器。

::: example 间隙中的递质浓度 {#ex-cleft}
一个囊泡向突触间隙释放4000个谷氨酸分子。把突触后致密区下方的间隙建模为半径150 nm、厚20 nm 的圆盘。(a)若递质被限制在这个圆盘内，浓度是多少？(b)突触后 AMPA 型谷氨酸受体的半最大激活浓度约为0.5 mmol L⁻¹。这意味着什么？(c)为什么浓度在约一毫秒内下降？
::: solution
(a)体积 $= \pi(150\times10^{-9})^2\times20\times10^{-9}\ \mathrm{m^3} = 1.41\times10^{-21}$ m³ $= 1.41\times10^{-18}$ L。量 $= 4000/6.02\times10^{23} = 6.6\times10^{-21}$ mol。浓度 $= 6.6\times10^{-21}/1.41\times10^{-18} = 4.7\times10^{-3}$ mol L⁻¹，约5 mmol L⁻¹。

(b)单个囊泡短暂产生的浓度远高于激活其下方受体所需，所以靠近释放位点的受体大多处于饱和。量子反应的大小于是由受体数目而非递质量决定：这正是突触后改变能够改变突触强度的一种途径。

(c)谷氨酸在量级为 $x^2/D$ 的时间内从狭窄的间隙扩散到胞外空间，其中 $x \approx 150$ nm、$D \approx 0.3\ \mu\mathrm{m^2\,ms^{-1}}$，即不到一毫秒（[[neuroscience/neurons-glia#prop-diffusion]]），并被星形胶质细胞和神经元上的转运体结合、摄取。测得的约1 mmol L⁻¹ 峰值浓度以约1 ms 的时间常数衰减。
:::
:::

## 递质与受体

一种物质要在某一突触被承认为**神经递质**，须满足：它在突触前神经元内合成并储存；受刺激时以 Ca²⁺ 依赖的方式释放；作用于突触后细胞的特异受体；并被特定机制清除；并且外加施加它能模拟刺激突触前神经元的效果。在某些突触满足这些标准的物质有几十种。

| 类别 | 例子 | 典型作用 |
|---|---|---|
| 乙酰胆碱 | ACh | 神经-肌肉接头、自主神经节、许多脑回路；昆虫中枢神经系统（主要的兴奋性递质） |
| 氨基酸 | 谷氨酸 | 脊椎动物 CNS 主要的快速兴奋性递质 |
| | GABA、甘氨酸 | 主要的快速抑制性递质（甘氨酸主要在脊髓和脑干） |
| 单胺类 | 多巴胺、去甲肾上腺素、5-羟色胺（5-HT）、组胺、章鱼胺（无脊椎动物） | 调制性，多经 G 蛋白偶联受体 |
| 嘌呤类 | ATP、腺苷 | 与其他递质共释放；P2X 和 P2Y 受体 |
| 神经肽 | P 物质、脑啡肽、催产素、血管加压素、神经肽 Y、FMRF 酰胺（无脊椎动物） | 调制性，来自致密核心囊泡；缓慢且常为远距离 |
| 气体与脂质 | 一氧化氮、内源性大麻素 | 按需合成，不储存；常为逆行性（自突触后向突触前） |

同一种递质在不同突触可以作用迥异，因为其效应由受体决定。受体分为两大家族。

::: definition 离子型与代谢型受体 {#def-receptors}
**离子型受体**（配体门控离子通道）本身就是离子通道，递质结合时开放。其效应在不到一毫秒内开始，持续数毫秒。主要家族是五聚体的 **Cys 环受体**（烟碱型 ACh、GABA_A、甘氨酸和 5-HT₃ 受体）、四聚体的 **离子型谷氨酸受体**（AMPA、海人藻酸和 NMDA 型）以及三聚体的 **P2X** ATP 受体。

**代谢型受体**是 G 蛋白偶联受体（或较少见的受体酶），经胞内信号转导起作用（[[cell-biology/cell-signalling]]）：G 蛋白亚基直接打开或关闭离子通道，或 cAMP、IP₃、Ca²⁺ 等第二信使激活激酶。效应在数十毫秒内开始，可持续数秒到数分钟，或经基因表达持续更久。例子是毒蕈碱型 ACh 受体、代谢型谷氨酸受体、GABA_B 受体以及多巴胺、去甲肾上腺素、多数5-羟色胺受体和神经肽的受体。
:::

勒维的 *Vagusstoff* 经代谢型受体起作用：ACh 结合心脏起搏细胞上的 M2 毒蕈碱受体，活化 G 蛋白的βγ亚基打开 K⁺ 通道（GIRK 通道），使心跳减慢。在神经-肌肉接头，同样的 ACh 作用于烟碱型受体，后者是离子型的、起兴奋作用。一种递质，两种受体，对两类肌肉作用相反。

烟碱型受体是第一个被纯化的受体（来自 *Torpedo*（电鳐属）等鳐类的发电器官——那是塞满受体、经过特化的神经-肌肉接头），第一个记录到单通道电流的离子通道（内尔（Neher）与萨克曼（Sakmann），1976），也是最早看清结构的离子通道之一：自1980年代末起，奈杰尔·安温（Nigel Unwin）的实验室用 *Torpedo* 膜的低温电子显微镜做到了这一点。它的五个亚基环绕一个中央孔，孔壁由每个亚基各贡献的一条螺旋围成。

::: quiz
在某一突触，递质释放到某细胞上，在1 ms 内引起膜电导短暂增加，并在−70 mV 处反转。在另一细胞，同一种递质在50 ms 后引起持续数百毫秒的缓慢超极化，且可被 G 蛋白抑制剂阻断。最可能的解释是什么？
- [ ] 两个突触释放的递质不同。
- [x] 第一个细胞有离子型（很可能对 Cl⁻ 通透）受体，第二个细胞有代谢型受体，经 G 蛋白打开 K⁺ 通道。
- [ ] 两种受体都是离子型的，只是第二种离释放位点更远。
- [ ] 第二个细胞的静息电位较低。
::: solution
时间过程和 G 蛋白依赖性表明第二个反应是代谢型的，例如 GABA_B 受体打开 GIRK 通道。第一个是快速的，反转电位接近 $E_\mathrm{Cl}$，是离子型 GABA_A 或甘氨酸受体的典型特征。间隙中的扩散距离不可能加上50 ms 的延迟：跨过20 nm 的扩散只需微秒。
:::
:::

## 突触后电位

离子型受体对突触后膜的作用，直接来自[[neuroscience/resting-potential#prop-chord]]的弦电导图景。

::: proposition 突触电流与反转电位 {#prop-synaptic}
当递质打开一个反转电位为 $E_\mathrm{syn}$ 的突触电导 $g_\mathrm{syn}$ 时，突触电流为

$$
I_\mathrm{syn} = g_\mathrm{syn}\,(V_\mathrm{m} - E_\mathrm{syn}),
$$ {#eq-syn}

而在静息电导为 $g_\mathrm{rest}$、静息电位为 $V_\mathrm{rest}$ 的紧凑细胞中，电导改变期间的稳态电位为

$$
V = \frac{g_\mathrm{rest}V_\mathrm{rest} + g_\mathrm{syn}E_\mathrm{syn}}{g_\mathrm{rest} + g_\mathrm{syn}}.
$$ {#eq-psp}

若 $E_\mathrm{syn}$ 位于动作电位阈值之上、能把膜推向发放，该突触就是**兴奋性**的；若 $E_\mathrm{syn}$ 位于阈值之下，即使它高于静息电位，该突触也是**抑制性**的。假设：等电位细胞、欧姆性的突触电导，且在膜电容充电完成后测量电位。
:::

终板上的 ACh 受体通道对 Na⁺ 和 K⁺ 都通透，且几乎相等，所以其反转电位位于 $E_\mathrm{Na}$ 与 $E_\mathrm{K}$ 之间。取相等的通透性并用哺乳动物的离子浓度，GHK 方程给出 $26.7\ln[(5 + 145)/(140 + 15)] \approx -1$ mV；实测值接近0 mV。卡茨及合作者发现蛙肌肉的终板电流在−15至0 mV 附近反转，这首先表明该受体是阳离子通道而非钠通道。AMPA 型谷氨酸受体同样是非选择性阳离子通道，也在0 mV 附近反转。GABA_A 和甘氨酸受体是 Cl⁻ 通道，在 $E_\mathrm{Cl}$ 处反转，成熟神经元中通常为−65至−80 mV。

::: example 兴奋与分流抑制 {#ex-shunt}
某神经元静息电导10 nS，静息于−70 mV；其阈值为−55 mV。(a)一个兴奋性突触打开1 nS 电导，$E_\mathrm{syn} = 0$ mV，产生多大的稳态去极化？(b)与此同时，一个抑制性突触打开10 nS 的 Cl⁻ 电导，$E_\mathrm{Cl} = -70$ mV。此时兴奋性输入产生多大的去极化？(c)抑制性输入本身会改变膜电位吗？
::: solution
(a)由[[#eq-psp]]：$V = (10\times(-70) + 1\times0)/11 = -63.6$ mV，去极化6.4 mV。

(b)加上 Cl⁻ 电导：$V = (10\times(-70) + 10\times(-70) + 1\times0)/21 = -66.7$ mV，去极化仅3.3 mV。兴奋性输入被削减了一半。

(c)不会：单独作用时它把电位推向 $-70$ mV，而电位本来就在那里。它的效应不是超极化而是**分流**：通过增大总电导，它减小任何其他电流所产生的电压变化。这种**分流抑制（shunting inhibition）**在静息时不表现为电位变化，却十分有效；当 $E_\mathrm{Cl}$ 接近静息电位时，它是 GABA_A 抑制的主要形式。
:::
:::

::: warning “抑制性突触总是引起超极化”
抑制由对发放的效应定义，而不是由电压变化的符号定义。$E_\mathrm{Cl}$ 低于静息电位的 Cl⁻ 电导引起超极化；$E_\mathrm{Cl}$ 等于静息电位的根本不产生电位变化，却仍经分流而抑制；$E_\mathrm{Cl}$ 略高于静息电位但低于阈值的，产生一个小的去极化，却仍是抑制性的，因为它把膜钳制在阈值之下。只有当 $E_\mathrm{Cl}$ 高于阈值时——如某些未成熟神经元（[[neuroscience/resting-potential]]）——GABA 才起兴奋作用。
:::

### 清除递质

只有递质被迅速清除，传递才短暂。胆碱能突触处，锚定在间隙中的**乙酰胆碱酯酶**以每个酶分子每秒约 $10^4$ 个分子的速率把 ACh 水解为胆碱和乙酸，是已知最快的酶之一；胆碱被终末重新摄取。氨基酸和单胺经突触前终末和胶质细胞中的**转运体**清除，其摄取与 Na⁺ 内流偶联。许多药物作用于此：例如5-羟色胺转运体抑制剂可延长已释放5-羟色胺的作用。它们的临床应用见[医学图谱：药理学](/learn/medicine/course.php?c=pharmacology)和[医学图谱：突触](/learn/medicine/lesson.php?c=physiology&l=synapses)。神经肽的清除较慢，靠胞外肽酶和扩散，这是它们作用时间更长、距离更远的原因之一。

## 突触整合

脊椎动物脑中的一个典型神经元接受数千个突触的输入，小脑浦肯野细胞可达约二十万个。皮层锥体细胞上的单个兴奋性突触通常在胞体只产生远小于1 mV 的 EPSP，而胞体必须去极化10–20 mV 才能发放。神经元因此必须对众多输入求和，而它如何求和就是它的计算。

::: definition 总和 {#def-summation}
**时间总和**是指同一突触或相邻突触在早先电位衰减完毕之前接连到达的突触后电位的相加；其时间窗由突触后电位的时程决定，因而部分取决于膜时间常数 $\tau$。**空间总和**是指不同突触同时产生的电位的相加；其有效程度取决于每个电位扩布到触发区时衰减了多少，由树突的长度常数 $\lambda$ 支配。兴奋性与抑制性电位在一阶近似下代数相加；但由于每个电位都是一次电导改变，当电导较大时求和是亚线性的，如[[#ex-shunt]]所示。
:::

单个突触后电位的形状常用**α函数**近似：$v(t) = v_\mathrm{max}(t/t_\mathrm{p})\,\mathrm{e}^{1 - t/t_\mathrm{p}}$，它在时刻 $t_\mathrm{p}$ 上升到峰值 $v_\mathrm{max}$，随后衰减。下图把两个这样的电位叠加起来，其到达间隔可以由你改变。

::: widget plot
f: (x/tp)*exp(1 - x/tp); heaviside(x - d)*((x - d)/tp)*exp(1 - (x - d)/tp); (x/tp)*exp(1 - x/tp) + heaviside(x - d)*((x - d)/tp)*exp(1 - (x - d)/tp)
x: 0, 60

caption: 两个相同 EPSP 的时间总和（纵轴，以一个 EPSP 的峰值为单位）对时间（横轴，ms）。第一个 EPSP 在0开始，第二个延迟间隔 $d$（滑块）后开始；两者的达峰时间 $t_\mathrm{p}$ 相同（滑块）。位于1.5的水平线代表某个阈值。$d = 5$ ms、$t_\mathrm{p} = 4$ ms 时总和越过该线；拉长间隔，总和峰值便落到阈值以下。把 $t_\mathrm{p}$ 拉长——正如较长的膜时间常数会做的那样——总和的时间窗就变宽。模型线性地相加电位，这只有对小电导改变才是良好的近似。
:::

输入落在何处与何时到达同等重要。远端树突上产生的 EPSP 到达胞体时被衰减、被减慢，而胞体附近的几乎无损到达。抑制性突触倾向于聚集在胞体和轴突起始段，在那里它们可以否决整细胞的输出；皮层的吊灯细胞（chandelier cells）只在锥体细胞的起始段上形成 GABA 能突触。树突也不是纯被动的。许多树突携带电压门控 Na⁺、Ca²⁺ 和 NMDA 受体的电导，能产生局部的**树突锋电位**，于是一个分支上成簇的输入可被非线性放大；而轴突上起始的动作电位还能逆向传播回树突，向突触报告细胞已经发放——这正是可塑性所利用的信号（[[neuroscience/plasticity-learning]]）。

::: application 作为药物靶点的突触
由于传递牵涉如此众多的分子步骤，突触是大多数作用于神经系统的药物，以及许多毒素和成瘾药物的靶标。箭毒和α-银环蛇毒素阻断神经-肌肉接头上的烟碱型受体；抗胆碱酯酶药延长 ACh 的作用；苯二氮䓬类增强 GABA_A 受体；许多抗抑郁药阻断单胺转运体；阿片类药物则作用于 G 蛋白偶联的阿片受体。重症肌无力患者的自身抗体减少了终板上 ACh 受体的数目，从而降低了传递的安全系数。这些药物的临床药理学见[医学图谱：药理学](/learn/medicine/course.php?c=pharmacology)，相关疾病见[医学图谱：神经肌肉疾病](/learn/medicine/lesson.php?c=nervous-system&l=neuromuscular)。
:::

::: history
杜布瓦-雷蒙（du Bois-Reymond）在1877年曾设想神经或许以电的方式、或许通过释放某种化学物质来兴奋肌肉。埃利奥特（Elliott）于1904年提出交感神经释放一种类似肾上腺素的物质；勒维（Loewi）于1921年在蛙心证明了化学传递。戴尔（Dale）与费尔德贝格（Feldberg）和福格特（Vogt）在1936年展示了神经-肌肉接头的 ACh 释放，并于同年与勒维分享诺贝尔奖。埃克尔斯（Eccles）曾是电传递的支持者，1952年在猫脊髓运动神经元内记录到抑制性突触后电位，转而确信中枢传递是化学性的。法特（Fatt）与卡茨（Katz）于1952年描述了微终板电位，德尔·卡斯蒂略与卡茨于1954年提出量子假说；卡茨于1970年与冯·奥伊勒（von Euler）和阿克塞尔罗德（Axelrod）分享诺贝尔奖，后两者分别从事去甲肾上腺素的释放与重摄取研究。费尔什潘（Furshpan）和波特（Potter）于1959年描述了电传递，道奇（Dodge）和拉哈米诺夫（Rahamimoff）于1967年提出释放的 Ca²⁺ 协同性，霍伊泽（Heuser）和里斯（Reese）在1970年代描述了囊泡循环。SNARE 和突触结合蛋白在1990年代由罗思曼（Rothman）、谢勒（Scheller）、雅恩（Jahn）、聚德霍夫（Südhof）等实验室鉴定。
:::

## 由此引向何处

突触把神经元连接成回路。在[[neuroscience/sensory-systems]]和[[neuroscience/motor-systems]]中，我们将沿着信号从感受器经突触走向肌肉；在[[neuroscience/plasticity-learning]]中，我们将看到突触强度如何随经验改变。

::: summary
- 电突触即缝隙连接，由连接蛋白（脊椎动物）或 innexin（无脊椎动物）构成；它们很快且通常双向，强度由耦合系数 $k = g_\mathrm{j}/(g_\mathrm{j} + g_2)$ 给出。
- 化学突触处，动作电位打开突触前 Ca²⁺ 通道；Ca²⁺ 结合突触结合蛋白，SNARE 蛋白驱动囊泡融合；递质在微秒内跨过20 nm 的间隙；突触延迟约0.5 ms。
- 释放是量子式的（德尔·卡斯蒂略与卡茨，1954）：一个囊泡给出一个量子，每个冲动释放的量子数服从二项分布，$p$ 小时近似泊松分布；$m$ 可由均值、失败次数（$m = \ln(N/n_0)$）或方差估计。
- 释放对 Ca²⁺ 的依赖极陡（低浓度下约为四次方律）。
- 离子型受体是配体门控通道（快）；代谢型受体经 G 蛋白和第二信使起作用（慢，调制性）。决定效应的是受体，而不是递质。
- 突触电流为 $g_\mathrm{syn}(V - E_\mathrm{syn})$；$E_\mathrm{syn}$ 在阈值之上则突触兴奋，在阈值之下则抑制——或经超极化，或经分流。
- 神经元经时间总和与空间总和对输入求和，其形状由 $\tau$、$\lambda$、树突位置和活动性树突电导决定。
:::

## 习题

::: exercise 失败次数法 {level=1 check="2.3"}
在中枢突触，100次突触前刺激产生10次失败。假设泊松释放，估计平均量子含量（保留一位小数）。
::: solution
$m = \ln(100/10) = \ln10 = 2.3$。
:::
:::

::: exercise Ca²⁺ 协同性 {level=1 check="81"}
若在研究范围内释放与胞外 Ca²⁺ 浓度的四次方成正比，Ca²⁺ 从0.5升高到1.5 mmol L⁻¹ 时，释放增大为多少倍？
::: solution
$(1.5/0.5)^4 = 3^4 = 81$。
:::
:::

::: exercise 反转电位 {level=1}
一个配体门控通道对 Na⁺ 和 K⁺ 的通透性相等，对其余离子不通透。用37 °C 的 GHK 方程，K⁺ 胞内140、胞外5，Na⁺ 胞内15、胞外145（mmol L⁻¹），计算它的反转电位。开放它是兴奋性的吗？
::: solution
$V_\mathrm{rev} = 26.7\ln[(5 + 145)/(140 + 15)] = 26.7\ln(0.968) = -0.9$ mV。这远高于约−55 mV 的典型阈值，通道会把膜推向发放：它是兴奋性的。
:::
:::

::: exercise 方差-均值分析 {level=2 check="10"}
在某一突触，于两种 Ca²⁺ 浓度下记录突触后电流。低 Ca²⁺ 时均值为20 pA、方差为180 pA²；高 Ca²⁺ 时均值为60 pA、方差为300 pA²。假设二项释放，位点数 $n$、概率 $p$、量子大小 $q$（故均值 $= npq$，方差 $= np(1-p)q^2$），求两种浓度下各自的 $n$、$q$ 和 $p$。
::: hint
证明方差可写成 $qI - I^2/n$，其中 $I$ 为均值，然后对每种浓度写一个这样的方程。
:::
::: solution
方差 $= np(1-p)q^2 = (npq)q - (npq)^2/n = qI - I^2/n$。于是 $180 = 20q - 400/n$，$300 = 60q - 3600/n$。由第一式 $q = 9 + 20/n$；代入第二式得 $300 = 540 + 1200/n - 3600/n$，故 $2400/n = 240$，$n = 10$。于是 $q = 11$ pA，$p = I/(nq)$：低 Ca²⁺ 时 $20/110 = 0.18$，高 Ca²⁺ 时 $60/110 = 0.55$。升高 Ca²⁺ 增大了释放概率，而不是位点数或量子大小，与预期一致。
:::

::: exercise 电耦合与细胞大小 {level=2}
一个1 nS 的缝隙连接把一个输入电阻500 MΩ 的小神经元与一个输入电阻20 MΩ 的大神经元耦联起来。计算两个方向上的耦合系数，并解释为什么接点本身是对称的而耦合却不对称。
::: solution
从小细胞到大细胞：$g_2 = 1/20\ \mathrm{M\Omega} = 50$ nS，$k = 1/(1 + 50) = 0.020$。从大细胞到小细胞：$g_2 = 1/500\ \mathrm{M\Omega} = 2$ nS，$k = 1/(1 + 2) = 0.33$。接头电流流入大而“漏”的大细胞时，从其巨大的电导逃逸，产生的电压变化很小；同样的电流流入小细胞却产生很大的变化。因此，电突触仅凭其所连接的细胞就可以是功能上不对称的，而通道本身并无整流。
:::
:::

::: exercise 鉴定一种递质 {level=2}
一位研究者怀疑，一种新近描述的蜗牛神经元向某肌肉释放5-羟色胺。按本章的标准，描述确定5-羟色胺就是递质所需的实验。
::: solution
需要证明：(1)该神经元含有5-羟色胺及其合成酶（色氨酸羟化酶），例如用免疫染色或在分离的神经元中测定5-羟色胺；(2)刺激该神经元以 Ca²⁺ 依赖的方式释放5-羟色胺，例如用电化学检测或收集灌流液；(3)对肌肉施加5-羟色胺能重现刺激神经元的反应，具有相同的时间过程、反转电位和离子依赖；(4)阻断肌肉上的5-羟色胺受体，或耗竭神经元内的5-羟色胺，可消除对神经元刺激的反应；(5)存在某种清除机制（如5-羟色胺转运体），阻断它会延长反应。任何单一标准都不充分；还应考虑肽类共释放的可能。
:::

::: exercise 解读量子数据 {level=2}
两个突触的平均 EPSP 幅度都是1.0 mV。突触 A 的微 EPSP 为0.2 mV，1 %的试验失败；突触 B 的微电位为1.0 mV，37 %的试验失败。(a)由均值和失败次数分别估计两者的量子含量。(b)哪个突触更可靠？神经系统各用这两种突触有何道理？
::: solution
(a)A：由均值 $m = 1.0/0.2 = 5$；由失败次数 $m = \ln(1/0.01) = 4.6$。B：由均值 $m = 1.0$；由失败次数 $m = \ln(1/0.37) = 1.0$。两者都与泊松释放相符。(b)A 在99 %的试验中传递成功，且反应有等级；B 在37 %的试验中失败，其余时候大多只释放一个量子。A 适合必须跟随每一个冲动的中继；B 则是皮层许多小突触的典型——不可靠性节省能量和递质，而且释放概率可由可塑性和调制来调节。同样的平均反应可以掩盖迥然不同的统计规律。
:::

::: exercise 树突上的分流 {level=3}
用[[neuroscience/action-potential#prop-cable]]的电缆方程解释：为什么位于兴奋性突触与胞体之间树突路径上的抑制性分流突触，比放在另一条树突上、或放在兴奋性突触之外末梢端的同一个抑制性突触，更能降低兴奋性电位在胞体处的幅度。这对树突的计算可能性有何提示？
::: solution
分流电导降低局部膜电阻，从而在局部缩短有效长度常数，并把本应沿树突流动的电流泄放掉。若分流位于路径上，兴奋性突触的电流去往胞体途中必须经过它，于是其中很大一部分在此漏掉。若分流在另一分支上，它只通过对胞体总输入电导的较小影响而起作用；若它位于兴奋性输入之外（更远端），则几乎没有兴奋性电流流过它。这种位置依赖（1980年代由拉尔（Rall）以及科赫（Koch）、波焦（Poggio）和托雷（Torre）分析）意味着抑制可以否决特定的输入而不是整个细胞，于是树突树能够对输入实现类似逻辑“与非”的运算，不同的分支还可以作为部分独立的计算亚单位。
:::

::: exercise 为什么要有量子？ {level=3}
假设递质是连续释放的——与突触前 Ca²⁺ 内流成比例的平滑等级量——而不是装在囊泡里。(a)囊泡包装提供了什么优点？(b)带来了什么代价？(c)等级式的、非冲动的释放确实存在于某些突触，如视网膜的感光细胞和双极细胞突触。那些突触如何在继续使用囊泡的同时实现等级输出？
::: solution
(a)囊泡浓缩递质（内部约100 mmol L⁻¹ 或更高），使单次融合事件在微秒内于突触后受体上产生高于其激活阈的高浓度；囊泡使递质可以待命储存，既免于降解又防止外漏；并使释放处于 Ca²⁺ 的严密时间控制之下。(b)代价是噪声：释放是随机的，在释放位点少的突触，很大一部分冲动会失败。建造、装填和再循环囊泡也消耗能量。(c)感光细胞和双极细胞的带状突触（ribbon synapses）从一个拴系在特化结构——突触带（synaptic ribbon）——上的大囊泡池中，以随膜电位等级变化的速率持续释放囊泡。等级输出的实现方式是调节一串串量子的释放速率，而不是改变单个量子的多寡，正如频率编码把“全或无”的锋电位变成等级信号一样。
:::
