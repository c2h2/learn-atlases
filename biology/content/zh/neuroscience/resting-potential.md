把一支充满盐溶液、尖端不足一微米的细玻璃吸管插入几乎任何一个神经元的膜内，接在吸管与浸浴液中导线之间的电压表就会从零跳到约−70 mV。细胞内部相对外部为负，而且只要细胞活着、吸管在位，情况就一直如此。这个**静息膜电位**是一切神经信号赖以书写的基线。动作电位是从它出发的短暂偏移，突触电位是对它的轻微推动，感觉受体则通过改变它来转导刺激。

本章解释静息电位从何而来、如何计算。离子跨膜的热力学、单一离子的能斯特方程和多离子的戈德曼-霍奇金-卡茨方程已在[[cell-biology/membrane-transport]]中引入；我们在此重述并加以应用，然后建立本课程其余部分所依赖的电学模型：把神经元看作由电池、电导和电容器组成的电路。学完本章，你应能预测离子浓度或通透性改变时神经元膜电位如何变化，以及电流流动时它的响应有多快。

## 电位的测量

第一次直接测量来自乌贼的巨轴突。1939年，普利茅斯的艾伦·霍奇金（Alan Hodgkin）和安德鲁·赫克斯利（Andrew Huxley），以及伍兹霍尔的肯尼斯·科尔（Kenneth Cole）和霍华德·柯蒂斯（Howard Curtis），把一根细毛细管电极沿直径约半毫米的轴突内部推入，记录了它与外部海水之间的电位。轴突静息时约负50 mV。1949年，吉尔伯特·林（Gilbert Ling）和拉尔夫·杰拉德（Ralph Gerard）引入了**玻璃微电极**，细到可以刺入蛙肌纤维一类小得多的细胞；1981年，欧文·哈米尔（Owen Hamill）、欧文·内尔（Erwin Neher）、伯特·萨克曼（Bert Sakmann）及合作者描述了**全细胞膜片钳**构型——与膜紧密封接的吸管，通过使其尖端下方的一小片膜破裂而进入细胞内部。膜片记录如今是培养神经元和脑片神经元的标准方法。

按惯例，膜电位 $V_\mathrm{m}$ 是内部电位减外部电位。负的静息电位因此意味着内部为负。向零或正值方向的变化是**去极化**，向更负值方向的变化是**超极化**。

典型的静息电位：脊椎动物中枢神经元为−60至−75 mV，脊椎动物骨骼肌约−90 mV，海水温度下的乌贼巨轴突约−60至−70 mV，胶质细胞接近−85 mV 或更负。有些细胞静息于−40 mV 附近；植物细胞用的是质子泵而非钠泵，静息电位常达−120至−200 mV。

## 离子的分布

膜电位的产生需要两个条件：离子分布不均，以及膜让某些离子比另一些更容易通过。神经元两样都有。

| 离子 | 胞内（mmol L⁻¹） | 胞外（mmol L⁻¹） | 外/内之比 |
|---|---|---|---|
| K⁺ | 140 | 5 | 0.036 |
| Na⁺ | 15 | 145 | 9.7 |
| Cl⁻ | 7 | 110 | 16 |
| Ca²⁺（游离） | 0.0001 | 2 | 20,000 |
| 有机阴离子（蛋白质、代谢物、核苷酸） | 多 | 少 | — |

（成熟哺乳动物中枢神经元的代表性数值。浸浴在海水中、海水温度下的乌贼轴突几乎一切浓度都更高：K⁺ 胞内约400、胞外20，Na⁺ 胞内约50、胞外440。）

建立这些分布的过程有两类。

- **主动运输。** Na⁺/K⁺-ATP 酶每水解一个 ATP 泵出三个 Na⁺、泵入两个 K⁺；Ca²⁺ 靠质膜 Ca²⁺-ATP 酶、Na⁺/Ca²⁺ 交换体以及内质网摄取被压到极低；Cl⁻ 由阳离子-氯共转运体移动（见下文）。这些在[[cell-biology/membrane-transport]]中已有描述。
- **不可通透阴离子。** 胞质中含有高浓度的带负电、不能跨膜穿过的分子：蛋白质、核酸、磷酸化代谢物。胞内的电中性要求它们由阳离子来平衡，而泵所积累的阳离子正是 K⁺。

注意，两种液体在极好的近似下都是电中性的。膜电位是由紧贴膜的一薄层中微不足道的过剩电荷产生的，下面我们将对此作出计算。

## 单离子：平衡电位

设想一张只对 K⁺ 通透的膜，把胞内140 mmol L⁻¹ 的 KCl 与胞外5 mmol L⁻¹ 隔开。K⁺ 顺着浓度梯度向外扩散。每个离开的 K⁺ 带走一个正电荷，留下一个未被平衡的负电荷，于是内部变负。增长中的电压又把 K⁺ 拉回来。当 K⁺ 所受的电场力恰好抵消其扩散趋势时，净通量为零。发生这种情况时的电压就是 K⁺ 的**平衡电位**。

::: proposition 能斯特方程 {#prop-nernst}
电荷数为 $z$ 的离子 X 在膜两侧达到平衡，当且仅当膜电位等于

$$
E_\mathrm{X} = \frac{RT}{zF}\ln\frac{[\mathrm{X}]_\mathrm{o}}{[\mathrm{X}]_\mathrm{i}},
$$ {#eq-nernst}

其中 $R$ 为气体常数，$T$ 为绝对温度，$F$ 为法拉第常数，$[\mathrm{X}]_\mathrm{o}$ 和 $[\mathrm{X}]_\mathrm{i}$ 为胞外和胞内浓度（严格说是活度）。37 °C 时 $RT/F = 26.7$ mV，故 $E_\mathrm{X} = (61.5/z)\log_{10}([\mathrm{X}]_\mathrm{o}/[\mathrm{X}]_\mathrm{i})$ mV；20 °C 时该系数为每十倍比值58.2 mV。

假设：离子处于平衡（无论通透性如何，净通量为零），且建立电位所伴随的通量并不明显改变浓度。
:::

::: proof
X 每摩尔的电化学势为 $\tilde\mu = \mu^\circ + RT\ln[\mathrm{X}] + zF\psi$，其中 $\psi$ 为电位。平衡时两侧的 $\tilde\mu$ 相同，故 $RT\ln[\mathrm{X}]_\mathrm{i} + zF\psi_\mathrm{i} = RT\ln[\mathrm{X}]_\mathrm{o} + zF\psi_\mathrm{o}$。整理得 $\psi_\mathrm{i} - \psi_\mathrm{o} = (RT/zF)\ln([\mathrm{X}]_\mathrm{o}/[\mathrm{X}]_\mathrm{i})$，即取 $V_\mathrm{m} = \psi_\mathrm{i} - \psi_\mathrm{o}$ 的[[#eq-nernst]]。
:::

方程中不含通透性。只要一个开放的通道是唯一的通路，单个通道就足以让离子达到平衡；通道越多只是到达得越快。只有当几种离子相互竞争时——真实膜中正是如此——通透性才重要。

::: example 哺乳动物神经元的平衡电位 {#ex-nernst}
用上表和 $RT/F = 26.7$ mV（37 °C），计算 $E_\mathrm{K}$、$E_\mathrm{Na}$、$E_\mathrm{Cl}$ 和 $E_\mathrm{Ca}$。
::: solution
$E_\mathrm{K} = 26.7\ln(5/140) = 26.7\times(-3.33) = -89$ mV。

$E_\mathrm{Na} = 26.7\ln(145/15) = 26.7\times2.27 = +61$ mV。

Cl⁻ 的 $z = -1$：$E_\mathrm{Cl} = -26.7\ln(110/7) = -26.7\times2.75 = -74$ mV。

Ca²⁺ 的 $z = 2$：$E_\mathrm{Ca} = 13.4\ln(2/0.0001) = 13.4\times9.90 = +132$ mV。

约−65至−70 mV 的静息电位位于 $E_\mathrm{K}$ 与 $E_\mathrm{Na}$ 之间，接近 $E_\mathrm{Cl}$，而离 $E_\mathrm{Ca}$ 极远。每个数的含义是：若膜变得对该离子单独通透，电位将逼近的值；而差 $V_\mathrm{m} - E_\mathrm{X}$ 是该离子所受的**驱动力**。静息时 Na⁺ 的驱动力约 $-65 - 61 = -126$ mV，是一股强大的向内推力；Ca²⁺ 约 $-200$ mV。所以打开 Na⁺ 或 Ca²⁺ 通道，这些离子就会涌入。
:::
:::

要建立这样的电位需要移动多少电荷？膜是两片导电溶液之间的薄绝缘体，也就是一只电容器。它的 **单位面积电容** $C_\mathrm{m}$ 在几乎所有细胞都接近1 µF cm⁻²；这个数值最早由肯尼斯·科尔和霍华德·柯蒂斯在1930年代由细胞悬液和轴突的电学阻抗测得。（平行板电容器的简单公式 $C = \varepsilon_r\varepsilon_0/d$，取脂双层烃芯的相对介电常数 $\varepsilon_r \approx 2$、厚度 $d \approx 2.5$ nm，给出约0.7 µF cm⁻²，量级正确。）

::: example 一个静息电位需要多少离子？ {#ex-ions}
一个球形神经元胞体直径20 µm，内含140 mmol L⁻¹ 的 K⁺。要把它充电到膜电位−70 mV，必须有多少 K⁺ 离开细胞？这占其 K⁺ 的几分之一？
::: solution
面积 $A = 4\pi r^2 = 4\pi(10^{-3}\ \mathrm{cm})^2 = 1.26\times10^{-5}$ cm²，故电容 $C = C_\mathrm{m}A = 1\ \mu\mathrm{F\,cm^{-2}}\times1.26\times10^{-5}\ \mathrm{cm^2} = 12.6$ pF。

电荷为 $Q = CV = 12.6\times10^{-12}\ \mathrm{F}\times0.070\ \mathrm{V} = 8.8\times10^{-13}$ C。除以基本电荷 $1.60\times10^{-19}$ C，得 $5.5\times10^6$ 个离子。

细胞体积为 $\tfrac43\pi r^3 = 4.19\times10^{-12}$ L，故容纳 $0.140\times4.19\times10^{-12}\times6.02\times10^{23} = 3.5\times10^{11}$ 个 K⁺。离开的比例是 $5.5\times10^6/3.5\times10^{11} \approx 1.6\times10^{-5}$，约六万分之一。
:::
:::

这个答案是整个课题的钥匙。形成膜电位的离子只占现有离子的极小部分，所以电位可以在一毫秒内变化100 mV—— 一次动作电位期间——而浓度不发生可测量的改变。浓度只在许多次冲动的长时间过程中缓慢变化，并由泵恢复。用电学语言说：主体溶液是中性的，膜电位栖身于膜每侧约一纳米厚的薄电荷层上。

::: warning “离子会流动直到两侧浓度相等”与“神经元内部带负电”
平衡时，对 K⁺ 选择通透的膜并不让 K⁺ 流动到两侧浓度相等。它只让极少量流过去——刚好把膜充上电——然后电压便阻止进一步的净移动，而浓度几乎原封不动。而且说胞质整体带负电是没有任何实际意义的：过剩电荷约为现存离子的 $10^5$ 分之一，并且局限于膜表面。把内部当作一袋负电荷会导致错误的预言，例如电信号期间会出现大的浓度变化。
:::

## 多离子：稳态，而非平衡

若静息膜只对 K⁺ 通透，静息电位就应是 $E_\mathrm{K}$，在我们的神经元约为−89 mV。实际没那么负，因为膜还漏进一些 Na⁺（以及 Cl⁻）。尤利乌斯·伯恩斯坦（Julius Bernstein）在1902年提出了这个想法的前半部分：静息时神经和肌肉的膜对 K⁺ 选择通透。定量的检验则迟了半个世纪。

::: proposition 戈德曼-霍奇金-卡茨电压方程 {#prop-ghk}
若 K⁺、Na⁺ 和 Cl⁻ 以通透性 $P_\mathrm{K}$、$P_\mathrm{Na}$ 和 $P_\mathrm{Cl}$ 独立跨膜，则净离子电流为零时的膜电位为

$$
V_\mathrm{m} = \frac{RT}{F}\ln\frac{P_\mathrm{K}[\mathrm{K}]_\mathrm{o} + P_\mathrm{Na}[\mathrm{Na}]_\mathrm{o} + P_\mathrm{Cl}[\mathrm{Cl}]_\mathrm{i}}{P_\mathrm{K}[\mathrm{K}]_\mathrm{i} + P_\mathrm{Na}[\mathrm{Na}]_\mathrm{i} + P_\mathrm{Cl}[\mathrm{Cl}]_\mathrm{o}}.
$$ {#eq-ghk}

假设：膜内电场均匀（戴维·戈德曼（David Goldman）1943年的恒场假设），离子独立跨越，通透性固定，且泵不携带净电流。推导见[[cell-biology/membrane-transport]]。
:::

起作用的只有通透性的**比值**。艾伦·霍奇金和伯纳德·卡茨（1949）用 $P_\mathrm{K}:P_\mathrm{Na}:P_\mathrm{Cl} = 1:0.04:0.45$ 拟合了静息时的乌贼轴突。典型哺乳动物神经元静息时的 $P_\mathrm{Na}/P_\mathrm{K}$ 约为0.02–0.05。先撇开氯离子（下文再回来），我们的神经元取 $P_\mathrm{Na}/P_\mathrm{K} = 0.05$ 得

$$
V_\mathrm{m} = 26.7\ln\frac{5 + 0.05\times145}{140 + 0.05\times15} = 26.7\ln\frac{12.25}{140.75} = 26.7\times(-2.44) = -65\ \mathrm{mV}.
$$

所以静息电位是一种**稳态**。Na⁺ 在其巨大驱动力的驱动下时刻不停地漏入；K⁺ 在一个较小驱动力的驱动下漏出；两股电流相互抵消，电压因而恒定；Na⁺/K⁺-ATP 酶把漏入的 Na⁺ 移走、把漏出的 K⁺ 收回，浓度因而也恒定。让泵停止工作，电位起初依旧存在（梯度还在），但会随梯度耗散在数分钟到数小时内逐渐衰减。

检验[[#eq-ghk]]最干净的办法，是改变胞外 K⁺ 浓度并测量静息电位。若膜只对 K⁺ 通透，电位将跟随 $E_\mathrm{K}$，在37 °C 下 $[\mathrm{K}]_\mathrm{o}$ 每变十倍电位变61.5 mV。艾伦·霍奇金和保罗·霍罗维茨（Paul Horowicz）1959年对蛙的单根肌纤维做了这个实验。

::: example 解读钾依赖实验 {#ex-ko}
培养中的神经元浸浴在不同 K⁺ 浓度的溶液中（以 Na⁺ 替换以保持总量恒定），测量其静息电位。代表性数值为：

| [K⁺]ₒ（mmol L⁻¹） | 2.5 | 5 | 10 | 20 | 50 | 100 |
|---|---|---|---|---|---|---|
| $V_\mathrm{m}$（mV） | −71 | −65 | −56 | −44 | −24 | −7 |

(a)50至100 mmol L⁻¹ 之间的斜率是多少（每十倍程的 mV 数）？它说明了什么？(b)为什么2.5至5之间斜率小得多？(c)用上表的浓度，由5 mmol L⁻¹ 处的数值估计 $P_\mathrm{Na}/P_\mathrm{K}$。
::: solution
(a)浓度加倍相当于 $\log_{10}2 = 0.301$ 个十倍程。50至100之间电位变化17 mV，故斜率为 $17/0.301 = 56$ mV 每十倍程，接近能斯特斜率61.5。高胞外 K⁺ 时膜几乎像一个 K⁺ 电极。

(b)2.5至5之间只变化6 mV，斜率 $6/0.301 = 20$ mV 每十倍程。[K⁺]ₒ很小时，[[#eq-ghk]]分子中的 $P_\mathrm{Na}[\mathrm{Na}]_\mathrm{o}$ 项与 $P_\mathrm{K}[\mathrm{K}]_\mathrm{o}$ 相比拟，所以改变[K⁺]ₒ时分子按比例的变化较小。

(c)记 $a = P_\mathrm{Na}/P_\mathrm{K}$。在[K⁺]ₒ = 5时：$-65 = 26.7\ln[(5 + 145a)/(140 + 15a)]$，故 $(5 + 145a)/(140 + 15a) = \mathrm{e}^{-2.43} = 0.0879$。于是 $5 + 145a = 12.3 + 1.32a$，得 $a = 7.3/143.7 = 0.051$。（这些数据其实是用[[#eq-ghk]]取 $a = 0.05$ 生成的，用以演示方法；真实数据有散布，$a$ 通常由整条曲线拟合得到。）
:::
:::

::: quiz
某神经元静息于−65 mV，$E_\mathrm{K} = -89$ mV，$E_\mathrm{Na} = +61$ mV。一种毒素打开了额外的 K⁺ 通道，使 $P_\mathrm{K}$ 加倍而 $P_\mathrm{Na}$ 不变。会发生什么？
- [ ] 什么都不发生，因为 K⁺ 的浓度没有变。
- [x] 膜向 $E_\mathrm{K}$ 方向超极化，因为 $P_\mathrm{Na}/P_\mathrm{K}$ 减半。
- [ ] 膜去极化，因为更多的 K⁺ 离开细胞。
- [ ] 膜恰好到达 $E_\mathrm{K}$。
::: solution
[[#eq-ghk]]中起作用的只有通透性之比。$P_\mathrm{K}$ 加倍使比值减半到约0.025，电位向 $E_\mathrm{K}$ 移动（用我们的浓度约到−75 mV），但不会一到位，因为仍有一些 Na⁺ 通透性。起初确实有更多的 K⁺ 离开细胞，而这恰恰就是内部变负的原因。
:::
:::

## 神经元作为电路

GHK 方程描述静息电位极佳，但要描述信号——随时间变化的电流——我们需要一个不同的、更灵活的模型。思路正是霍奇金和赫克斯利1952年采用的：把每一类离子通道表示为与一只电池串联的电导。

::: definition 电导、驱动力与等效电路 {#def-circuit}
对于通道行为近似欧姆电阻的离子 X，通过通道的电流（按惯例向外为正）为

$$
I_\mathrm{X} = g_\mathrm{X}\,(V_\mathrm{m} - E_\mathrm{X}),
$$ {#eq-ohm}

其中 $g_\mathrm{X}$ 是膜对 X 的**电导**（单位西门子，S；电阻的倒数），$V_\mathrm{m} - E_\mathrm{X}$ 是**驱动力**。当 $V_\mathrm{m} = E_\mathrm{X}$ 时电流为零，这就是 $E_\mathrm{X}$ 也被称为**反转电位**的原因。膜被建模为一个**等效电路**：每种离子一个分支（电导 $g_\mathrm{X}$ 与电池 $E_\mathrm{X}$ 串联），全部与膜电容 $C$ 并联。
:::

电导与通透性相关但并不相同。通透性是膜本身的性质；电导还取决于有多少离子可用来载流。对 K⁺ 和 Na⁺ 通透性相等的膜，当 K⁺ 更浓时 K⁺ 电导更大；GHK 方程还表明，对浓度不等的离子，电流-电压关系是弯曲的而非直线。[[#eq-ohm]]的欧姆模型是一个近似，但对大多数通道在生理电压范围内是个不错的近似，而且它让电路易于分析。

::: proposition 弦电导方程 {#prop-chord}
若膜携带欧姆电导 $g_\mathrm{K}$、$g_\mathrm{Na}$ 和 $g_\mathrm{Cl}$ 而无其他净电流（无注入电流、无净泵电流），其稳态电位是各平衡电位的电导加权平均：

$$
V_\mathrm{m} = \frac{g_\mathrm{K}E_\mathrm{K} + g_\mathrm{Na}E_\mathrm{Na} + g_\mathrm{Cl}E_\mathrm{Cl}}{g_\mathrm{K} + g_\mathrm{Na} + g_\mathrm{Cl}}.
$$ {#eq-chord}

更一般地，对任意一组反转电位为 $E_j$ 的电导 $g_j$，$V_\mathrm{m} = \sum_j g_jE_j / \sum_j g_j$。
:::

::: proof
稳态时电容既不充电也不放电，故离子电流之和为零：$g_\mathrm{K}(V_\mathrm{m} - E_\mathrm{K}) + g_\mathrm{Na}(V_\mathrm{m} - E_\mathrm{Na}) + g_\mathrm{Cl}(V_\mathrm{m} - E_\mathrm{Cl}) = 0$。合并含 $V_\mathrm{m}$ 的项即得 $V_\mathrm{m}(g_\mathrm{K} + g_\mathrm{Na} + g_\mathrm{Cl}) = g_\mathrm{K}E_\mathrm{K} + g_\mathrm{Na}E_\mathrm{Na} + g_\mathrm{Cl}E_\mathrm{Cl}$。
:::

这个方程让神经系统中每个电信号的逻辑一目了然。膜电位被拉向电导最大的那种离子的反转电位。打开更多 Na⁺ 通道，电位便向 $E_\mathrm{Na}$ 移动（动作电位的上升支、兴奋性突触电位）。打开更多 K⁺ 通道，便向 $E_\mathrm{K}$ 移动（复极化、许多抑制性电位）。打开 Cl⁻ 通道，则向 $E_\mathrm{Cl}$ 移动，而其值可在静息电位之上或之下。

::: example 电导之间的拔河 {#ex-chord}
某神经元静息电导为 $g_\mathrm{K} = 10$ nS、$g_\mathrm{Na} = 0.5$ nS、$g_\mathrm{Cl} = 2$ nS，平衡电位取[[#ex-nernst]]的数值（$E_\mathrm{K} = -89$、$E_\mathrm{Na} = +61$、$E_\mathrm{Cl} = -74$ mV）。(a)求静息电位。(b)求静息时每种离子携带的电流。(c)泵必须平衡哪些离子的净通量？
::: solution
(a)由[[#eq-chord]]：

$$
V_\mathrm{m} = \frac{10(-89) + 0.5(61) + 2(-74)}{12.5} = \frac{-890 + 30.5 - 148}{12.5} = \frac{-1007.5}{12.5} = -80.6\ \mathrm{mV}.
$$

(b)以 nS 和 mV 计，电流以 pA 计。$I_\mathrm{K} = 10(-80.6 + 89) = +84$ pA（向外）；$I_\mathrm{Na} = 0.5(-80.6 - 61) = -71$ pA（向内）；$I_\mathrm{Cl} = 2(-80.6 + 74) = -13$ pA。Cl⁻ 电流为负意味着带负电的离子向外移动，即 Cl⁻ 离开细胞。三者之和为零，正如必须如此。

(c)三者都是。Na⁺ 有持续的向内泄漏，K⁺ 向外泄漏，Cl⁻ 也向外泄漏；Na⁺/K⁺-ATP 酶平衡前两者，而必须有某种 Cl⁻ 转运体平衡第三者，否则 $E_\mathrm{Cl}$ 会漂移直到与 $V_\mathrm{m}$ 相等。许多神经元静息时 Cl⁻ 接近平衡，所以其电流很小。
:::
:::

### 生电性的泵

Na⁺/K⁺-ATP 酶每泵进两个正电荷就泵出三个，所以它携带一个很小的净向外电流，直接对膜电位有所贡献。它的份额可以这样估计：稳态下泵的通量必须与泄漏精确平衡——每有 Na⁺ 漏入三个，就必须有 K⁺ 漏出两个。洛林·马林斯（Lorin Mullins）和野田喜美子（Kimiko Noda）（1963）以蛙肌为材料，把这一条件加入恒场模型，得到

$$
V_\mathrm{m} = \frac{RT}{F}\ln\frac{rP_\mathrm{K}[\mathrm{K}]_\mathrm{o} + P_\mathrm{Na}[\mathrm{Na}]_\mathrm{o}}{rP_\mathrm{K}[\mathrm{K}]_\mathrm{i} + P_\mathrm{Na}[\mathrm{Na}]_\mathrm{i}}
$$ {#eq-mullins}

其中偶联比 $r = 3/2$。对我们的神经元，取 $P_\mathrm{Na}/P_\mathrm{K} = 0.05$，此式给出−71 mV，而[[#eq-ghk]]给出−65 mV（后者是 $r = 1$ 的特例）。泵的直接贡献在多数神经元只有几毫伏。它更大的贡献是间接的：维持着构成电位其余部分的梯度。

泵送代价高昂。脑的 ATP 大部分花在 Na⁺/K⁺-ATP 酶上，用于回送静息时泄漏以及在动作电位和突触电位期间跨膜的离子。对哺乳动物皮层的估计，尤其是戴维·阿特韦尔（David Attwell）和西蒙·劳克林（Simon Laughlin）（2001）的估计，把与信号有关的泵送列为脑能量消耗的过半以上；动作电位、突触电流与静息泄漏之间的确切分配，因物种、温度和所用假设而异。

## 时间：膜作为 RC 电路

到此我们看的是稳态。若电流被突然注入神经元——突触或实验者的电极正是如此——会发生什么？电流不能瞬间改变电压，因为它必须先给膜电容充电。

对一个小的紧凑细胞（“等电位”细胞，其内部电压处处相同），把所有静息电导并入一个 **输入电导** $g_\mathrm{in} = 1/R_\mathrm{in}$，其合反转电位等于静息电位 $V_\mathrm{rest}$。记 $V = V_\mathrm{m} - V_\mathrm{rest}$ 为偏离静息值的量。注入细胞的电流 $I$ 分成两路：给电容器充电，以及经电导流出：

$$
I = C\deriv{V}{t} + \frac{V}{R_\mathrm{in}}.
$$ {#eq-rc}

::: proposition 膜的充电 {#prop-rc}
若在 $t = 0$ 时对一个静息的细胞接通恒定电流 $I$，则偏离静息值的部分为

$$
V(t) = IR_\mathrm{in}\left(1 - \mathrm{e}^{-t/\tau}\right), \qquad \tau = R_\mathrm{in}C = R_\mathrm{m}C_\mathrm{m},
$$ {#eq-charging}

切断电流后电压按 $V(t) = V_0\,\mathrm{e}^{-t/\tau}$ 衰减。这里 $R_\mathrm{m}$ 是 **单位面积膜电阻**（Ω cm²，电阻乘以面积），$C_\mathrm{m}$ 是单位面积电容（F cm⁻²）。因此 **膜时间常数** $\tau$ 与细胞大小无关；稳态偏移 $IR_\mathrm{in}$ 则不然。

假设：等电位细胞；在所响应的电压范围内不随电压改变的电导（“被动”膜）；恒定电流。
:::

::: proof
[[#eq-rc]]是一阶线性方程：$\tau\,\deriv{V}{t} = -V + IR_\mathrm{in}$，其中 $\tau = R_\mathrm{in}C$。其平衡态为 $V_\infty = IR_\mathrm{in}$，偏差 $V - V_\infty$ 按 $\mathrm{e}^{-t/\tau}$ 衰减；取 $V(0) = 0$ 即得[[#eq-charging]]。$I = 0$ 时平衡态为0，得到衰减式。对面积为 $A$ 的细胞，$R_\mathrm{in} = R_\mathrm{m}/A$、$C = C_\mathrm{m}A$，故 $\tau = R_\mathrm{m}C_\mathrm{m}$，面积相消。
:::

同一个方程，$\tau$ 的含义不同，曾支配[[animal-physiology/homeostasis]]中的比例控制回路。它在整个神经科学中反复出现：突触电位的上升与衰减带有部分由 $\tau$ 决定的时间常数，而 $\tau$ 决定了神经元对不同时刻到达的输入求和的时间窗（[[neuroscience/synapses]]）。

::: example 一个小神经元的输入电阻与时间常数 {#ex-rc-cell}
[[#ex-ions]]中那个20 µm 的球形细胞，其单位面积膜电阻为20,000 Ω cm²，$C_\mathrm{m} = 1\ \mu\mathrm{F\,cm^{-2}}$。(a)求它的输入电阻、电容和时间常数。(b)10 pA 的电流产生多大的稳态去极化？(c)接通电流后多久电压达到平台的95 %？
::: solution
(a)面积 $1.26\times10^{-5}$ cm²，故 $R_\mathrm{in} = 20{,}000/1.26\times10^{-5} = 1.6\times10^9\ \Omega = 1.6$ GΩ；$C = 12.6$ pF；$\tau = R_\mathrm{m}C_\mathrm{m} = 20{,}000\times10^{-6} = 0.020$ s $= 20$ ms。

(b) $V_\infty = IR_\mathrm{in} = 10\times10^{-12}\times1.6\times10^9 = 0.016$ V $= 16$ mV。

(c)由 $1 - \mathrm{e}^{-t/\tau} = 0.95$ 得 $t = \tau\ln 20 = 3.0\tau = 60$ ms。

GΩ 量级的输入电阻意味着，几皮安的电流——几个开放通道流过的电流——就能使一个小神经元的电压改变毫伏量级。这就是为什么单个通道在小细胞中可以举足轻重，也是为什么在相同的通道密度下小神经元比大神经元更易兴奋。
:::
:::

实际测量中，时间常数和输入电阻由小电流阶跃的响应得到。长阶跃末端的电压除以电流给出 $R_\mathrm{in}$；到达平台的63 %（$1 - \mathrm{e}^{-1}$）所需的时间给出 $\tau$；比值 $\tau/R_\mathrm{in}$ 给出电容，进而按1 µF cm⁻² 给出膜面积。真实的神经元有树突和轴突，其充电带有多个指数分量而不止一个，因为电流既跨胞体膜流动，也扩散进突起。下一章处理这种沿电缆的扩布。

## 氯、钙与胶质细胞

**氯。** 与 K⁺ 和 Na⁺ 不同，多数神经元中氯不是由原发性 ATP 酶泵送的。它的分布由次级主动运输的 **阳离子-氯共转运体** 决定：NKCC1 把 Na⁺、K⁺ 和两个 Cl⁻ 一起运入，从而升高胞内 Cl⁻；KCC2 把 K⁺ 和 Cl⁻ 一起运出，从而降低它。哺乳动物脑的成熟神经元中 KCC2 占优势，胞内 Cl⁻ 低（约5–10 mmol L⁻¹），$E_\mathrm{Cl}$ 位于静息电位附近或其下方。未成熟神经元中 NKCC1 占优势，胞内 Cl⁻ 较高，$E_\mathrm{Cl}$ 可以远高于静息电位。克劳迪奥·里维拉（Claudio Rivera）、凯·凯拉（Kai Kaila）及合作者1999年证明，大鼠海马 KCC2 表达量的发育性上升正是这一变化的原因。由于脑的主要抑制性受体是氯通道，$E_\mathrm{Cl}$ 的改变会改变抑制的作用（[[neuroscience/synapses]]）。

**钙。** 静息神经元内部的游离 Ca²⁺ 约100 nmol L⁻¹，比胞外低两万倍。Ca²⁺ 几乎不承担静息电流，但其巨大的驱动力意味着，只要 Ca²⁺ 通道开放，通道附近的胞内浓度就会陡升；而 Ca²⁺ 正是把电活动与递质释放、基因表达和可塑性耦联起来的信号。它在毫秒到秒内被泵出或被隔离。

**胶质。** 胶质细胞的膜几乎只对 K⁺ 通透，所以它们的膜电位跟随 $E_\mathrm{K}$。斯蒂芬·卡夫勒、约翰·尼科尔斯和理查德·奥尔坎德从泥螈（*Necturus*）视神经的胶质细胞记录（1966），改变浸浴液中的 K⁺ 时，胶质电位在很宽范围内按接近能斯特斜率变化。这使胶质细胞成为胞外 K⁺ 的灵敏感受器，而它们对 K⁺ 起着缓冲作用（[[neuroscience/neurons-glia]]）。

::: application 胞外钾与兴奋性
由于静息电位对胞外 K⁺ 的依赖很陡（见上图），一切改变血浆 K⁺ 的因素都会改变全身神经和肌肉的兴奋性。K⁺ 升高使细胞去极化，起初使其更易兴奋，随后因 Na⁺ 通道失活而变得更难兴奋；K⁺ 降低使其超极化。心肌尤其敏感，这就是血浆 K⁺ 受肾严密调节的原因。这些效应的人体生理学与临床意义见[医学图谱：膜电位](/learn/medicine/lesson.php?c=physiology&l=membrane-potentials)；这里的要点是：能斯特方程和 GHK 方程就能预言它们。
:::

## 电位计算

本章的计算很容易写成脚本。下面的小程序可对任意一组浓度、通透性或电导，计算能斯特电位以及 GHK 和弦电导电位。

```python
import math

R, F = 8.314, 96485.0          # J mol^-1 K^-1, C mol^-1

def nernst(c_out, c_in, z, T=310.15):
    """Equilibrium potential in mV (concentrations in the same units)."""
    return 1000 * R * T / (z * F) * math.log(c_out / c_in)

def ghk(P, out, inn, T=310.15):
    """GHK voltage (mV); P, out, inn are dicts keyed by 'K', 'Na', 'Cl'."""
    num = P['K'] * out['K'] + P['Na'] * out['Na'] + P['Cl'] * inn['Cl']
    den = P['K'] * inn['K'] + P['Na'] * inn['Na'] + P['Cl'] * out['Cl']
    return 1000 * R * T / F * math.log(num / den)

def chord(g, E):
    """Steady potential (mV) from conductances g and reversal potentials E."""
    return sum(g[k] * E[k] for k in g) / sum(g.values())

out = {'K': 5, 'Na': 145, 'Cl': 110}       # mmol/L
inn = {'K': 140, 'Na': 15, 'Cl': 7}
E = {'K': nernst(5, 140, 1), 'Na': nernst(145, 15, 1), 'Cl': nernst(110, 7, -1)}
print({k: round(v, 1) for k, v in E.items()})       # {'K': -89.1, 'Na': 60.6, 'Cl': -73.6}
print(round(ghk({'K': 1, 'Na': 0.05, 'Cl': 0}, out, inn), 1))   # -65.3
print(round(chord({'K': 10, 'Na': 0.5, 'Cl': 2}, E), 1))        # -80.6
```

::: history
瓦尔特·能斯特（Walther Nernst）于1889年为电化学电池导出了他的方程。尤利乌斯·伯恩斯坦（Bernstein）的膜理论（1902年提出，1912年阐发）主张静息电位是 K⁺ 经选择通透膜的扩散电位，而兴奋是选择性的短暂丧失。肯尼斯·科尔（Cole）与霍华德·柯蒂斯（Curtis）在1930年代测定了细胞与轴突的膜电容，并于1939年证明冲动期间膜电导上升。同年，霍奇金（Hodgkin）与赫克斯利（Huxley），以及柯蒂斯与科尔，在乌贼巨轴突内部录音，发现动作电位冲过零值——这是伯恩斯坦理论无法解释的。戴维·戈德曼（Goldman）的恒场方程（1943）由霍奇金与卡茨（Katz）于1949年付诸应用，同年还有林（Ling）与杰拉德（Gerard）的微电极；1959年，霍奇金与霍罗维茨（Horowicz）用蛙单根肌纤维检验了 K⁺ 依赖。马林斯（Mullins）与野田（Noda）于1963年加入生电性泵；内尔、萨克曼及合作者的膜片钳（1976年单通道、1981年全细胞）使这些测量在小神经元中成为常规。
:::

## 由此引向何处

静息电位是舞台。在[[neuroscience/action-potential]]中，电压门控 Na⁺ 和 K⁺ 电导在毫秒内改变，弦电导方程把膜从接近 $E_\mathrm{K}$ 摆到接近 $E_\mathrm{Na}$ 再摆回来，而膜的 RC 特性推广到长电缆后，决定了冲动传多远、传多快。

::: summary
- 静息电位（多数神经元和肌肉为−60至−90 mV）源于泵维持的离子梯度，以及膜对 K⁺ 的通透性高于对其他离子的事实。
- 能斯特方程给出每个离子的平衡电位，$E_\mathrm{X} = (RT/zF)\ln([\mathrm{X}]_\mathrm{o}/[\mathrm{X}]_\mathrm{i})$，37 °C 时每十倍程61.5 mV：典型值 $E_\mathrm{K} \approx -89$、$E_\mathrm{Na} \approx +61$、$E_\mathrm{Cl} \approx -74$、$E_\mathrm{Ca} \approx +130$ mV。
- 所需电荷极小（约为细胞 K⁺ 的 $10^{-5}$），因为膜电容约为1 µF cm⁻²；电位可以在毫秒内变化而不改变浓度。
- 当多种离子都能通透时，静息电位是稳态，由 GHK 方程给出（只有通透性之比起作用），或对欧姆通道由弦电导方程 $V = \sum g_jE_j/\sum g_j$ 给出。
- 膜电位被拉向占优势电导的反转电位；这是一切电信号的逻辑。
- Na⁺/K⁺-ATP 酶直接贡献几毫伏（偶联比3:2），间接维持梯度；它消耗脑能量的大部分。
- 被动紧凑细胞按时间常数 $\tau = R_\mathrm{m}C_\mathrm{m}$（典型10–50 ms）充电到平台 $IR_\mathrm{in}$。
- 胞内 Cl⁻ 由 NKCC1 和 KCC2 设定，并随发育改变；胞内 Ca²⁺ 约 $10^{-7}$ mol L⁻¹；胶质细胞跟随 $E_\mathrm{K}$。
:::

$E_\mathrm{K} = 25.3\ln(20/400) = 25.3\times(-3.00) = -76$ mV。

::: exercise 二价离子 {level=1 check="132"}
胞外 Ca²⁺ 为2 mmol L⁻¹、胞内游离 Ca²⁺ 为0.1 µmol L⁻¹，37 °C 时的 $E_\mathrm{Ca}$ 是多少（取整到毫伏）？
::: solution
$E_\mathrm{Ca} = (26.7/2)\ln(2\times10^{-3}/10^{-7}) = 13.37\ln(20{,}000) = 13.37\times9.90 = +132$ mV。电荷中的因子2把每十倍程的电位减半，但巨大的浓度比远超过这一点把它补回。

一个50 pA 的电流阶跃在某神经元产生10 mV 的稳态超极化，且电压在30 ms 后达到终值的63 %。求输入电阻（MΩ）、电容（pF）和单位面积膜电阻（Ω cm²），设 $C_\mathrm{m} = 1\ \mu\mathrm{F\,cm^{-2}}$。（check 栏要填的是 $R_\mathrm{m}$。）

$R_\mathrm{in} = 10\ \mathrm{mV}/50\ \mathrm{pA} = 200$ MΩ。$\tau = 30$ ms，故 $C = \tau/R_\mathrm{in} = 0.030/2\times10^8 = 1.5\times10^{-10}$ F $= 150$ pF，按1 µF cm⁻² 即面积 $1.5\times10^{-4}$ cm²。$R_\mathrm{m} = \tau/C_\mathrm{m} = 0.030/10^{-6} = 30{,}000\ \Omega\,\mathrm{cm^2}$。
:::
:::

::: exercise 升高胞外钾 {level=2 check="-64"}
用不含氯的 GHK 方程，37 °C，胞内 K⁺ 140、Na⁺ 15，胞外 Na⁺ 145 mmol L⁻¹，$P_\mathrm{Na}/P_\mathrm{K} = 0.02$，计算胞外 K⁺ 为10 mmol L⁻¹ 时的静息电位（取整到毫伏）。并与5 mmol L⁻¹ 时的值比较。
::: solution
10 mmol L⁻¹ 时：$V_\mathrm{m} = 26.7\ln[(10 + 2.9)/(140 + 0.3)] = 26.7\ln(12.9/140.3) = 26.7\times(-2.387) = -64$ mV。5 mmol L⁻¹ 时：$26.7\ln(7.9/140.3) = 26.7\times(-2.877) = -77$ mV。胞外 K⁺ 加倍使该神经元去极化约13 mV，小于 $E_\mathrm{K}$ 的变化18.5 mV（$61.5\log_{10}2$）。
:::

::: exercise 氯电流的反转 {level=2}
成熟海马神经元的胞内 Cl⁻ 为7 mmol L⁻¹；未成熟者为30 mmol L⁻¹；两者的胞外 Cl⁻ 均为110 mmol L⁻¹。两者均静息于−65 mV。求37 °C 下各自的 $E_\mathrm{Cl}$，并预测打开 Cl⁻ 通道的效应。哪种共转运体造成了这一差别？
::: solution
成熟：$E_\mathrm{Cl} = -26.7\ln(110/7) = -74$ mV。打开 Cl⁻ 通道把膜推向−74 mV，超极化约9 mV，并使其远离阈值。未成熟：$E_\mathrm{Cl} = -26.7\ln(110/30) = -35$ mV。打开 Cl⁻ 通道使膜向−35 mV 去极化，所以同一种递质变为去极化性，甚至可能引起兴奋。这一差别来自 KCC2：它排出 Cl⁻ 并在发育过程中上调；早期占优势的是积累 Cl⁻ 的 NKCC1。
:::

::: exercise 什么决定了静息电位？ {level=2}
对每种处理，预测神经元的静息电位是变负、变正还是几乎不变，并用[[#eq-ghk]]或[[#eq-chord]]解释：(a)用不可通透阳离子替换一半胞外 Na⁺；(b)阻断 Na⁺/K⁺-ATP 酶十秒钟；(c)阻断 K2P“ 漏 ”K⁺ 通道；(d)在静息 Cl⁻ 通透性低的细胞中把胞外 Cl⁻ 浓度加倍。
::: solution
(a)略变负：$P_\mathrm{Na}[\mathrm{Na}]_\mathrm{o}$ 项减半，分子缩小，电位向 $E_\mathrm{K}$ 移动。由于静息时 $P_\mathrm{Na}$ 很小，改变只有几毫伏。(b)立即变正几毫伏（失去了生电性泵电流，[[#eq-mullins]]中的 $r$ 实际变为1）；十秒内梯度几乎未变。(c)变正，幅度可能达许多毫伏：$P_\mathrm{K}$ 下降，$P_\mathrm{Na}/P_\mathrm{K}$ 上升，电位向 $E_\mathrm{Na}$ 移动。以 K2P 漏电导为主的神经元会去极化甚至发放。(d)几乎不变：$E_\mathrm{Cl}$ 移动，但 $g_\mathrm{Cl}$ 小时它在[[#eq-chord]]中的权重小。随时间推移，Cl⁻ 重新分布，再次接近平衡。
:::

::: exercise 解读胶质细胞记录 {level=2}
在一个类似卡夫勒、尼科尔斯和奥尔坎德的实验中，某胶质细胞的膜电位在3 mmol L⁻¹ 胞外 K⁺ 下为−89 mV，在9 mmol L⁻¹ 下为−60 mV（20 °C，能斯特斜率58 mV 每十倍程）。(a)胶质膜的行为像一个理想的 K⁺ 电极吗？(b)估计胶质的胞内 K⁺ 浓度。(c)这种行为使胶质细胞得以做什么？
::: solution
(a)K⁺ 三倍相当于 $\log_{10}3 = 0.477$ 个十倍程；理想 K⁺ 电极应变化 $58\times0.477 = 27.7$ mV。实测变化29 mV，在实验误差内相同，所以是的。(b)由 $-89 = 58\log_{10}(3/[\mathrm{K}]_\mathrm{i})$ 得 $\log_{10}(3/[\mathrm{K}]_\mathrm{i}) = -1.534$，故 $[\mathrm{K}]_\mathrm{i} = 3\times10^{1.534} \approx 103$ mmol L⁻¹，对两栖类细胞是合理的数值。(c)跟随 $E_\mathrm{K}$ 的膜使胶质细胞能感受胞外 K⁺，并借助其缝隙连接耦联的网络，把 K⁺ 从神经元活动过的区域再分布到 K⁺ 浓度低的区域（空间缓冲，[[neuroscience/neurons-glia]]）。
:::
:::

::: exercise 泵的能耗账单 {level=3}
在[[#ex-chord]]的神经元中，静息时有71 pA 的 Na⁺ 电流漏入。(a)每秒进入多少个 Na⁺？(b)为把它们移走，Na⁺/K⁺-ATP 酶每秒必须水解多少分子 ATP？(c)若该神经元每秒发放10个动作电位，每个额外放入 $5\times10^7$ 个 Na⁺，活动使泵的 ATP 消耗增大为几倍？(d)这对该神经元静息与信号的能量成本有何提示？
::: solution
(a) $71\times10^{-12}\ \mathrm{C\,s^{-1}}/1.60\times10^{-19}\ \mathrm{C} = 4.4\times10^8$ 个 Na⁺ s⁻¹。

(b)每个 ATP 三个 Na⁺：$1.5\times10^8$ ATP s⁻¹。

(c)动作电位增加 $10\times5\times10^7 = 5\times10^8$ Na⁺ s⁻¹，即 $1.7\times10^8$ ATP s⁻¹，所以消耗大致翻倍，约为原来的2.1倍。

(d)在这个示意性的神经元中，静息泄漏与信号传导花费相当。真实的能量预算强烈依赖于静息电导、发放率和动作电位的效率（哺乳动物轴突每个锋电位浪费的 Na⁺ 少于乌贼轴突，[[neuroscience/action-potential]]），而对皮层的已发表估计把大部分成本归于突触电流和动作电位电流。这个计算说明了为什么静息 Na⁺ 泄漏低、发放稀疏的神经元运行起来更便宜。
:::

::: exercise GHK 与弦电导的比较 {level=3}
(a)证明：若除某一离子 X（$E_\mathrm{X} \neq 0$）外，所有离子在膜两侧的浓度都相同，则[[#eq-ghk]]和[[#eq-chord]]给出的电位都在0与 $E_\mathrm{X}$ 之间。(b)对[[#ex-nernst]]的神经元取 $P_\mathrm{Na}/P_\mathrm{K} = 0.05$，GHK 静息电位（不含 Cl⁻）为−65.3 mV。[[#eq-chord]]中的比值 $g_\mathrm{Na}/g_\mathrm{K}$ 取何值给出同样的电位？(c)为什么两个比值不同？
::: hint
对于(b)，令 $(g_\mathrm{K}E_\mathrm{K} + g_\mathrm{Na}E_\mathrm{Na})/(g_\mathrm{K} + g_\mathrm{Na}) = -65.3$ 并解出比值。
:::
::: solution
(a)在[[#eq-chord]]中，两侧浓度相等的离子有 $E = 0$，故 $V_\mathrm{m} = g_\mathrm{X}E_\mathrm{X}/\sum g$，是 $E_\mathrm{X}$ 的一个介于0与1之间的分数。在[[#eq-ghk]]中，浓度相等各项在分子与分母中相同；比值对数因此介于0（若 X 可忽略）与 X 浓度比的 $\ln$（若 X 占主导）之间，故 $V_\mathrm{m}$ 介于0与 $E_\mathrm{X}$ 之间。

(b)令 $\rho = g_\mathrm{Na}/g_\mathrm{K}$。则 $(-89.1 + 60.6\rho)/(1 + \rho) = -65.3$，故 $-89.1 + 60.6\rho = -65.3 - 65.3\rho$，得 $125.9\rho = 23.8$，$\rho = 0.19$。

(c)电导不是通透性。在 GHK 模型中，一个离子携带的电流既取决于其通透性，也取决于其浓度；而在−65 mV 处，向内的 Na⁺ 电流由被大驱动力推动的大的胞外浓度承载，而向内的 K⁺ 电流受限于小的胞外 K⁺ 浓度。每条 GHK 电流-电压曲线在静息电位处的斜率——弦电导近似的正是它——因而不同于通透性之比。每个模型都是自洽的；不能把一个模型的通透性之比与另一个模型的电导之比混在一起用。
:::
