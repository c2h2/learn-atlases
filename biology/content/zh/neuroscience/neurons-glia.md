你脊髓中的一个运动神经元，胞体直径约为二十分之一毫米，而它的轴突却延伸到一米之外你足部的肌肉。这条轴突远端所需的每一种蛋白质都在胞体内或胞体附近合成，并被运送过去。同一个细胞在树突上接受来自其他神经元的数千个接触，在几毫秒内累加这些输入的效果，并决定是否沿轴突发出一次电冲动。围绕在它周围、并在脑的许多区域里数量超过它的，是胶质细胞：它们为轴突包裹上绝缘层，清除它释放的递质，缓冲它丢失的钾，并在损伤之后清理残局。

本章介绍构成神经系统的两类细胞，**神经元**和**胶质细胞**：它们的形状、各部分结构及每一部分的功能、它们如何被发现是彼此分离的细胞，以及本课程其余部分所依据的大小、数量与时间尺度。真核细胞的通用机器（细胞核、内质网、高尔基体、线粒体、细胞骨架）见[[cell-biology/organelles]]和[[cell-biology/cytoskeleton]]；这里我们要问的是，那些以传导信号为职分的细胞有何特别之处。

## 神经元学说

十九世纪中叶，神经系统在显微镜下仍是一道难题。神经组织柔软、排列致密、几乎透明，当时的染料呈现的是一团纤维乱麻，没有人能从一端到另一端追踪单个细胞。许多解剖学家由此断定神经纤维融合成一张连续的网络，即**网状结构（reticulum）**，神经活动就像流过管道系统一样流过它。

1873年，意大利医生卡米洛·高尔基（Camillo Golgi）发表了他称为 *reazione nera*（“黑反应”）的方法：组织先用重铬酸钾处理，再浸入硝酸银，便会显现出黑色的铬化银沉积。由于至今未能完全弄清的原因，这一反应只染到组织块中一小部分神经元，也许百分之一，却把每一个被染到的细胞完整地显示出来，连所有分支都在内。在未染色背景的衬托下，单个神经元第一次清晰地凸显出来。

高尔基本人始终相信网状学说。西班牙组织学家圣地亚哥·拉蒙-卡哈尔（Santiago Ramón y Cajal）于1887年采用这种染色法，最先在鸟类小脑和胚胎组织（细胞较小、髓鞘较少）上工作，并从1888年起论证：每个神经细胞的纤维都以游离末端告终，紧靠其他细胞却并不与之融合。在此后数十年间，卡哈尔描述了脊椎动物神经系统的几乎每一个区域，绘制了数以千计的细胞。他与高尔基分享1906年诺贝尔生理学或医学奖，并在各自的演说中继续各执一词。

::: definition 神经元学说 {#def-neuron-doctrine}
**神经元学说**认为：

1. 神经系统由彼此分离的细胞—— **神经元**——构成，每个神经元都有自己的膜，是这个系统的结构与功能单位；
2. 神经元在特化的接触点—— **突触**——上彼此通讯，接触处两者的膜十分接近但保持分离；
3. 每个神经元都是**极化的**：信号通常经树突和胞体传入，经轴突传出（卡哈尔的*动态极化定律*）。
:::

*神经元（neuron）*一词由威廉·瓦尔代尔（Wilhelm Waldeyer）于1891年提出——他的一篇综述使卡哈尔的工作广为人知；查尔斯·谢灵顿（Charles Sherrington）则于1897年引入*突触（synapse）*一词，指神经元之间的功能性接点，这是他根据脊髓反射的延迟和单向传导推断出来的。分离性的直接证据要等到电子显微镜：1955年，桑福德·帕雷（Sanford Palay）和乔治·帕拉德（George Palade），以及独立工作的爱德华多·德罗伯特尼斯（Eduardo De Robertis）与 H. 斯坦利·贝内特（H. Stanley Bennett），证明化学突触处两膜之间有约20 nm 的间隙，即**突触间隙**，间隙的一侧有成簇的小囊泡。

::: warning “神经元学说没有例外”
该学说是一个极好的初步近似，而非定律。许多神经元由**缝隙连接（gap junctions）**相连——那是连通两个细胞胞质、直接传递电流的通道（[[neuroscience/synapses]]）。树突也能向其他树突释放递质，有些轴突也会接受突触。乌贼的巨轴突——接下来两章的主要模型——由数百个小神经元的轴突融合而成；2023年，帕韦尔·布尔克哈特（Pawel Burkhardt）与合作者报告，栉水母 *Mnemiopsis leidyi*（淡海栉水母）的上皮下神经网是一个真正的合胞体，神经元之间的膜是连续的。高尔基并非全错；卡哈尔则对绝大多数神经元是正确的。
:::

## 神经元的各部分

神经元的形状千差万别，但几乎所有神经元共有四个区域，每个区域专职处理信号的一个环节。

::: definition 神经元的各个区域 {#def-neuron}
- **胞体**（soma、perikaryon）含有细胞核和大部分蛋白质合成机器。神经元的粗面内质网极为丰富，染色后呈团块状，即 **尼氏体（Nissl bodies）**。
- **树突** 是分支状、逐渐变细的突起，接受突触输入。许多神经元的树突上带有 **树突棘**——长约1 µm 的突起，大多数兴奋性突触建于其上。
- **轴突** 通常只有一条，直径几乎恒定，把动作电位自胞体传出。它起自 **轴丘** 和 **轴突起始段**（axon initial segment，AIS）——一段长数十微米、电压门控 Na⁺ 通道密度极高的区域，动作电位通常在此起始。轴突可分出 **侧支**，末端为 **终末**（突触小体），在此形成突触。
- **突触前终末** 含有充满递质的突触囊泡、线粒体，以及 Ca²⁺ 进入时使囊泡停泊并与膜融合的蛋白质。
:::

胞体和树突构成神经元的**接受**部分，轴丘和起始段是**整合**部分，轴突是**传导**部分，终末是**输出**部分。这种划分既是解剖学的也是功能性的：各区域的膜携带不同的离子通道、受体和黏附分子，而细胞把它们彼此隔开。起始段处有一道扩散屏障，由支架蛋白锚定蛋白 G（ankyrin-G）和细胞骨架蛋白 βIV- 血影蛋白（βIV-spectrin）组织而成，它阻止胞体和树突的膜蛋白漂入轴突，正如紧密连接把上皮细胞的顶膜与基底侧膜分开一样。

神经元有多种彼此重叠的分类方式。

- **按突起的数目。** **多极** 神经元有许多树突和一条轴突；脊椎动物大多数神经元属于此类。**双极** 神经元有一条树突和一条轴突，见于视网膜和嗅上皮。**假单极** 神经元，如背根神经节的感觉神经元，只有一条突起，它分为走向皮肤或肌肉的外周支和进入脊髓的中枢支；冲动由一支传到另一支，并不经过胞体。多数无脊椎动物的神经元是 **单极** 的：一条突起自胞体伸出并分为树突部和轴突部，胞体成层地位于神经节的外周，远离中央的突触神经毡。
- **按功能。** **感觉**（传入）神经元把信号从感受器传向中枢神经系统；**运动**（传出）神经元把信号传向肌肉和腺体；**中间神经元** 把神经元彼此连接起来，占任何脑内细胞的绝大多数。轴突局限于某一局部区域的中间神经元是 **局部环路神经元**；轴突离开该区域的是 **投射神经元**。
- **按递质与效应。** 神经元按其主递质对所接触细胞的作用分为 **兴奋性** 或 **抑制性**。在脊椎动物脑中，多数投射神经元释放谷氨酸，是兴奋性的；多数局部中间神经元释放 GABA 或甘氨酸，是抑制性的。
- **按形状与位置。** 大脑皮层和海马的 **锥体细胞** 胞体呈三角形，有一条长长的顶树突伸向表面，底部一圈基底树突如裙展开。小脑的 **浦肯野细胞（Purkinje cells）** 铺开一片扇形的扁平树突树，接受来自平行纤维的多达约200,000个突触。小脑微小的 **颗粒细胞** 每个只有四五条短树突，是脊椎动物脑内数量最多的神经元。

大约自2015年起，单细胞 RNA 测序又按每个细胞表达的基因增添了新的分类。小鼠脑图谱现已区分出数千种转录组细胞类型，归入几百个较宽的类别。这些分子类型如何对应于形状、连接与功能，是该领域当前的活跃问题之一。

- [ ] 它的树突就在胞体上，冲动也在那里产生。
- [x] 它的感受末梢在皮肤；冲动沿外周支传导，接着进入中枢支，绕过胞体。
- [ ] 胞体是感受区，冲动向外传向皮肤。
- [ ] 它没有轴突，因为它只有一条突起。
::: solution
这是一个假单极感觉神经元。它在皮肤中的感觉末梢是感受部分；冲动由末梢产生后沿外周支（其行为如同一根轴突）传导，在 T 形分支处进入中枢支。胞体悬在通路旁侧，根本无需被冲动波及。它的职责是维持细胞，而不是整合信号。

## 作为又长又细的细胞的神经元

神经元在细胞之中与众不同的地方是其几何形状。典型的动物细胞大致是紧凑的，各个方向上不过十到二十微米。神经元却把突起延伸到毫米甚至米的尺度，其大部分体积和膜都远离细胞核。

::: example 运动神经元有多少是轴突？ {#ex-volume}
把人类脊髓运动神经元建模为直径50 µm 的球形胞体和直径10 µm、长1.0 m 的无分支圆柱形轴突，忽略树突与终末。比较胞体与轴突的体积和膜面积。
::: solution
胞体：半径 $R = 25$ µm，体积 $\tfrac43\pi R^3 = 6.5\times10^4\ \mu\mathrm{m}^3$，面积 $4\pi R^2 = 7.9\times10^3\ \mu\mathrm{m}^2$。

轴突：半径 $r = 5$ µm，长度 $L = 10^6$ µm，体积 $\pi r^2 L = 7.9\times10^7\ \mu\mathrm{m}^3$，面积 $2\pi r L = 3.1\times10^7\ \mu\mathrm{m}^2$。

轴突的体积约为胞体的$1200$倍，膜面积约为其$4000$倍。换句话说，这个细胞99.9 %以上的胞质都在轴突里，距合成其全部信使 RNA 的细胞核一米之遥。真实的运动神经元还有庞大的树突树，但结论不变：胞体是一座小工厂，供应着一个极长极细的结构。
:::
:::

这种几何形状造成供应难题。胞体合成的蛋白质、脂质和细胞器必须到达终末，磨损的组件和来自靶体的信号必须运回来。扩散能胜任这项工作吗？

::: proposition 扩散时间随距离的平方增长 {#prop-diffusion}
一个扩散系数为 $D$ 的分子从一点出发，经时间 $t$ 后沿单轴的均方位移为

$$
\langle x^2 \rangle = 2Dt,
$$ {#eq-diffusion}

因此沿一条细突起扩散距离 $x$ 通常所需的时间量级为

$$
t \approx \frac{x^2}{2D}.
$$

该结果适用于无流动、无结合、无障碍的一维自由随机运动（一条细长圆柱）。与固定结构的结合、拥挤和障碍都会使扩散进一步变慢，所以这个公式给出的是时间的下限。
:::

平方关系是关键所在。扩散在短距离上很快，在长距离上则毫无用处。距离加倍，时间变为四倍。

::: example 轴突内的扩散与运输之比 {#ex-transport}
一种中等大小的蛋白质在胞质中的扩散系数约为 $D = 10^{-11}\ \mathrm{m^2\,s^{-1}}$（10 µm² s⁻¹）。试估计它靠扩散走完(a)一个胞体，10 µm；(b)1 mm 的轴突；(c)一条1 m 的轴突各需多久。把(c)与**快速轴突运输**每天400 mm 以及**慢速轴突运输**每天1 mm 作比较。
::: solution
由[[#prop-diffusion]]，$t \approx x^2/2D$。

(a) $x = 10^{-5}$ m：$t \approx 10^{-10}/(2\times10^{-11}) = 5$ s。

(b) $x = 10^{-3}$ m：$t \approx 10^{-6}/(2\times10^{-11}) = 5\times10^{4}$ s，约14小时。

(c) $x = 1$ m：$t \approx 1/(2\times10^{-11}) = 5\times10^{10}$ s，约1600年。

快速运输走完1 m 需$1000/400 = 2.5$天，慢速运输约需1000天，将近三年。扩散在胞体内和短突起中够用，但每一条长轴突都依赖由马达蛋白驱动的主动运输。
:::
:::

**轴突运输**大体分为两种速度。**快速运输**约每天50–400 mm（最高约5 µm s⁻¹），沿微管运输膜结合的货物，如囊泡前体、线粒体和内体。轴突中的微管几乎全部同向排列，其快速生长的正端朝向终末，因此朝正端行走的**驱动蛋白（kinesin）**把货物向外运送（**顺向运输**），而朝负端行走的**胞质动力蛋白（cytoplasmic dynein）**把货物运回来（**逆向运输**）。逆向运输把受损的细胞器送回降解，并运送来自靶体的信号，例如维持许多神经元存活所必需的神经营养素（[[neuroscience/neural-development]]）。**慢速运输**约每天0.2–8 mm，运输细胞骨架蛋白和可溶性酶；现在理解为由快速移动与长时间停顿相间构成，平均效果因而很慢。马达蛋白本身的描述见[[cell-biology/cytoskeleton]]。

神经元也会局部合成一些蛋白质。细胞骨架蛋白和突触蛋白的信使 RNA 被运进树突，并在许多神经元中运进轴突，在需要它们的突触附近就地翻译。树突的局部翻译是某些形式的持久性突触改变所必需的（[[neuroscience/plasticity-learning]]）。

::: application 运输失灵之时
由于最长的轴突最依赖运输，马达蛋白或微管的缺陷往往最先影响它们。人类若干遗传性周围神经病由驱动蛋白、动力蛋白，或把货物连接到马达上的蛋白质的突变引起，最初的症状通常出现在足部——最长轴突的末端。临床方面见[医学图谱：神经肌肉疾病](/learn/medicine/lesson.php?c=nervous-system&l=neuromuscular)；生物学要点在于：几何形状使神经元以致密细胞所不具备的方式变得脆弱。
:::

### 神经系统的代价

神经元很昂贵。把信号传导中跨膜的 Na⁺ 和 K⁺ 泵回去，消耗掉它们 ATP 的大部分（[[neuroscience/resting-potential]]）。成人脑约占体重的2 %，却消耗安静时机体耗氧量的约20 %。昆虫也按比例付出相似的成本：丽蝇视网膜的感光细胞和视觉神经元消耗蝇安静时能量预算的相当大一部分。能量是神经系统采用稀疏编码（一次只有少数神经元处于活动，[[neuroscience/neural-coding]]）的原因之一，也是不再需要某种感觉的动物（如失去眼睛的洞穴鱼）会缩小相应脑区的原因。

## 有多少神经元？

神经系统的规模从几百个神经元到数千亿个不等。

| 动物 | 神经元数（约） | 数字来源 |
|---|---|---|
| 线虫 *Caenorhabditis elegans*（秀丽隐杆线虫，雌雄同体） | 302 | 电子显微镜完整重建（White 等，1986） |
| 果蝇 *Drosophila melanogaster*（黑腹果蝇），成虫脑 | 约140,000 | FlyWire 全脑连接组（2024） |
| 蜜蜂 *Apis mellifera* | 约100万 | 细胞计数 |
| 实验小鼠 *Mus musculus*，脑 | 约7000万 | 各向同性分离计数法 |
| 人，脑 | 约860亿 | 各向同性分离计数法（Azevedo 等，2009） |
| 非洲象，脑 | 约2,570亿 | 各向同性分离计数法（2014） |

这一人类数字取代了常被引用的“千亿”，来自苏珊娜·埃尔库拉诺-乌泽尔（Suzana Herculano-Houzel）及合作者的**各向同性分离计数法（isotropic fractionator）**：把组织消化成游离细胞核悬液，计数细胞核，再用神经元特异性核蛋白（NeuN）染色找出属于神经元的比例。在人类860亿神经元中，约690亿在小脑，其中大多是颗粒细胞，大脑皮层只有约160亿。象脑的神经元数是我们的3倍，但几乎全部增量都在小脑；其大脑皮层的神经元数只有人类皮层的约三分之一。

*C. elegans* 和 *Drosophila* 的数字来自 **连接组（connectome）**，即由连续切片电子显微照片重建的完整连接图谱。线虫的连接组用了十多年的人工追踪；蝇的连接组于2024年由 FlyWire 联盟借助机器学习和数千名人工校对者完成，包含约5000万个突触。

## 胶质细胞

鲁道夫·菲尔绍（Rudolf Virchow）在1850年代把脑中的非神经元细胞命名为 *Nervenkitt*（“神经胶”），希腊语的胶——*glia*——这个名称就在它们身上沿用下来。如今已知，它们的作用远不止把神经元黏在一起。

::: definition 胶质细胞的主要类别 {#def-glia}
在脊椎动物中：

- **星形胶质细胞**（中枢神经系统，CNS）是星形细胞，其细小突起包绕突触，**终足** 覆盖血管。它们从胞外间隙摄取 K⁺ 和递质谷氨酸，向神经元供应代谢底物，并参与形成和维持 **血脑屏障**。
- **少突胶质细胞**（CNS）为多条——常常数十条——轴突分别包裹出髓鞘节段。
- **施万细胞（Schwann cells）**（外周神经系统，PNS）每个只髓鞘化一条轴突的一个节段，或裹住若干细小的无髓轴突而不形成髓鞘。
- **小胶质细胞**（CNS）是脑和脊髓的常驻巨噬细胞：巡视组织，吞噬碎片、濒死细胞和某些突触，并对损伤和感染作出反应。
- **少突胶质细胞前体细胞**（OPC，又称 NG2 胶质）终身存在、能够分裂，并可生成新的少突胶质细胞。
- **室管膜细胞** 衬于脑室和中央管；**放射状胶质细胞** 是发育中脑的细长前体细胞，产生大多数神经元和胶质细胞，并引导迁移中的神经元。

星形胶质细胞、少突胶质细胞、OPC、室管膜细胞和施万细胞与神经元一样，来源于胚胎外胚层；小胶质细胞则不是。
:::

### 星形胶质细胞

星形胶质细胞是哺乳动物脑大多数区域中数量最多的胶质细胞。在啮齿动物皮层，每个星形胶质细胞占据自己的领地，与邻居的几乎不重叠（这种模式称为**镶嵌（tiling）**），其突起接触的突触数量达100,000个量级。以下三项功能已有充分证据。

1. **钾缓冲。** 每个动作电位都向狭窄的胞外间隙释放 K⁺，而间隙体积小意味着哪怕少量外流也会明显抬高局部 K⁺ 浓度。胶质细胞的膜几乎只对 K⁺ 通透，所以它们在 K⁺ 高处以摄取、在低处以释放的方式处理它，这一过程称为 **空间缓冲**。1966年，理查德·奥尔坎德（Richard Orkand）、约翰·尼科尔斯（John Nicholls）和斯蒂芬·卡夫勒（Stephen Kuffler）记录泥螈（*Necturus maculosus*）视神经中胶质细胞的电位，证明胶质膜电位几乎精确地跟随 K⁺ 的能斯特电位（[[neuroscience/resting-potential]]），并在附近轴突发放时去极化。
2. **递质摄取。** 兴奋性突触释放的谷氨酸主要由星形胶质细胞的转运体清除（人类为 EAAT1 和 EAAT2，啮齿动物称 GLAST 和 GLT-1），其摄取与 Na⁺ 内流偶联。谷氨酸在星形胶质细胞内转化为谷氨酰胺，被运回神经元并重新变回谷氨酸（**谷氨酸-谷氨酰胺循环**）。
3. **血管与屏障功能。** 星形胶质细胞的终足包绕脑的几乎全部毛细血管。**血脑屏障** 本身——把大多数血源性分子挡在脑外——由毛细血管内皮细胞之间的紧密连接构成，但星形胶质细胞和贴在毛细血管上的周细胞（pericytes）诱导并维持它。昆虫的构型不同：血淋巴与神经系统之间的屏障由胶质细胞本身形成，以隔膜连接（septate junctions）封闭。

除此之外，星形胶质细胞会对递质产生胞内 Ca²⁺ 升高的反应；自1990年代末以来的许多研究提出，它们也释放自己的递质，如谷氨酸、ATP 和 D- 丝氨酸，与突触前、突触后神经元一起构成**三联突触（tripartite synapse）**。这种**胶质传递（gliotransmission）**的规模有多大、有多普遍，仍有争议，部分原因是刺激星形胶质细胞所用的手段可能带来非预期的效应。请把它当作一个活跃的假说，而不是教科书事实。

### 形成髓鞘的胶质细胞

许多脊椎动物的轴突包裹在**髓鞘**之中——一层被压实的螺旋状胶质膜。其道理与给导线包绝缘层相同：它减少电流经轴突膜的泄漏和需要充放的电容量，使冲动在给定的轴突直径下传得更远、更快。物理部分见[[neuroscience/action-potential]]。

::: definition 髓鞘、节间段与朗飞结 {#def-myelin}
**髓鞘**由施万细胞或少突胶质细胞的突起把轴突缠绕许多圈、并挤掉各圈之间的胞质形成，留下紧密堆叠的膜层。每个胶质包裹覆盖一个**节间段（internode）**，通常长0.2–2 mm。相邻节间段之间是一段约1 µm 长的裸露轴突间隙，即**朗飞结（node of Ranvier）**，电压门控 Na⁺ 通道在此富集。轴突直径与髓鞘化纤维外径之比称为 **g-ratio（g 比值）**，通常为0.6–0.8。
:::

髓鞘膜很特别：干重的约70–80 %是脂质（含大量胆固醇和半乳糖脂），而大多数膜约为50 %。蛋白质把各层黏合在一起：胞质侧有髓鞘碱性蛋白；在 CNS 还有蛋白酶脂蛋白（proteolipid protein）；在 PNS，黏附蛋白 P0 承担大量工作。新鲜神经的 X 射线衍射显示，每一圈缠绕（两层膜厚）使外周髓鞘增厚约17–18 nm，中枢的约15–16 nm。

::: example 数一数髓鞘缠了多少圈 {#ex-myelin}
一条外周轴突直径6 µm，g-ratio 为0.6。假设每圈的重复距离为17.6 nm，(a)纤维的外径是多少？(b)髓鞘有多厚？(c)施万细胞大约把轴突缠了多少圈？
::: solution
(a) $g = d/D$，故 $D = d/g = 6/0.6 = 10$ µm。

(b) 髓鞘占据两个半径之差：$(D - d)/2 = (10 - 6)/2 = 2$ µm。

(c) $2\ \mu\mathrm{m} / 17.6\ \mathrm{nm} = 2000/17.6 \approx 114$ 圈。这样一条大纤维携带着上百层胶质膜，每一圈都是这一个细胞的延伸。
:::
:::

::: widget plot

髓鞘是脊椎动物的发明，却不是脊椎动物独有的。现生脊椎动物中只有有颌类拥有它；七鳃鳗和盲鳗没有。类髓鞘的包裹在无脊椎动物的若干类群中独立演化出来，包括某些环节动物、对虾和桡足类，它们的冲动传导相对其轴突尺寸也快得不寻常。这种趋同有力地说明：在细轴突上实现快速传导对动物的价值极大。

### 小胶质细胞

小胶质细胞的起源与其他所有胶质细胞都不同。小鼠的细胞命运示踪实验（Florent Ginhoux 等，2010）表明，它们来自胚胎卵黄囊中的前体细胞——这些前体在发育早期迁入脑，随后终身自我更新——而不是来自血液单核细胞。在健康脑中，它们细小的突起持续移动，采样周围环境。在小鼠发育中的视觉系统里，小胶质细胞吞噬那些被补体系统蛋白标记、且比邻居更不活跃的突触（Dorothy Schafer、Beth Stevens 等，2012），帮助清除不合适的连接。脑受伤时，小胶质细胞迁移到损伤部位、增殖并释放炎症信号；这些反应在人类神经疾病中的作用见[医学图谱：神经炎症](/learn/medicine/lesson.php?c=nervous-system&l=neuroinflammation)。

### 胶质细胞有多少？

人们常说人脑中胶质细胞与神经元之比为十比一。事实并非如此。

::: example 胶质细胞与神经元之比 {#ex-ratio}
Azevedo 等（2009）用各向同性分离计数法对成人脑的计数，取整后为（单位：十亿）：

| 区域 | 神经元 | 非神经元细胞 |
|---|---|---|
| 大脑皮层（含白质） | 16 | 61 |
| 小脑 | 69 | 16 |
| 其余部分 | 0.7 | 8 |

非神经元细胞包括胶质细胞和血管的内皮细胞。(a)全脑的非神经元细胞与神经元之比是多少？(b)大脑皮层和小脑各是多少？(c)两个区域的差异可能作何解释？
::: solution
(a) 总计：神经元 $16 + 69 + 0.7 \approx 86$（十亿）；非神经元细胞 $61 + 16 + 8 = 85$（十亿）。比值约为 $85/86 \approx 1.0$：每个神经元大约对应一个非神经元细胞。

(b) 大脑皮层：$61/16 \approx 3.8$。小脑：$16/69 \approx 0.23$。

(c) 这个比值跟随神经元的大小，而非脑的“进化程度”。小脑以极小的颗粒细胞为主，每个细胞胞质体积小、轴突短而无髓，所以每个神经元所需的胶质细胞较少。大脑皮层的神经元较大，并有大片髓鞘化的白质，其间布满少突胶质细胞。跨哺乳动物的比较呈现同样的模式：胶质细胞与神经元之比随平均神经元大小而上升，与智力无关。请注意“非神经元”并不等于“胶质”，因为其中包含血管细胞。
:::
:::

::: warning “胶质细胞比神经元多十倍”与“我们只用了大脑的10 %”
两种说法都很流行，两种都是错的。十比一的说法出现在较旧的教科书里，背后并没有测量；直接计数给出的全脑比值约为每个神经元对应一个非神经元细胞，且区域差异很大。“10 %”的迷思则毫无根据：成像和记录显示，一天之中脑的所有部分都有活动，而几乎任何区域的损伤都有可测量的后果。真实的情况是：任一时刻只有很小比例的神经元在发放，因为神经编码是稀疏的，而锋电位代价高昂。
:::

### 无脊椎动物的胶质细胞

线虫 *C. elegans* 雌雄同体有56个胶质细胞，大多与其感觉器官相关；用激光消融除去特定的胶质细胞后，它们所包裹的感觉神经元就会失去正常的形状和功能。*Drosophila* 有若干类胶质细胞，包括形成血脑屏障的表面胶质、包绕神经元胞体的皮层胶质、吞噬碎片的包裹胶质，以及突起伸入神经毡并摄取递质的类星形胶质。许多胶质功能的基因，如转运体和吞噬受体 Draper（与哺乳动物 MEGF10 同源），在蝇与脊椎动物之间是共有的，这说明神经元与支持细胞之间的分工十分古老。

::: history
高尔基（Golgi）的黑反应（1873）、卡哈尔（Cajal）的鸟类小脑研究（1888）和瓦尔代尔（Waldeyer）的综述（1891）确立了神经系统的细胞观；高尔基与卡哈尔分享1906年诺贝尔奖。谢灵顿（Sherrington）于1897年为突触命名，电子显微镜于1955年证实了突触间隙。鲁道夫·菲尔绍（Virchow）于1856年描述了 *Nervenkitt*；卡哈尔的学生皮奥·德尔里奥-奥尔泰加（Pío del Río Hortega）在1910年代末至1920年代初用碳酸银染色区分了小胶质细胞和少突胶质细胞。西奥多·施万（Schwann）于1839年描述了外周神经的鞘细胞，路易-安托万·朗维埃（Ranvier）于1878年描述了朗飞结。弗雷德里科·阿泽维多（Frederico Azevedo）、苏珊娜·埃尔库拉诺-乌泽尔（Suzana Herculano-Houzel）及合作者于2009年发表了人脑的各向同性分离计数。约翰·怀特（John White）、艾琳·萨思盖特（Eileen Southgate）、尼科尔·汤姆森（Nichol Thomson）与西德尼·布伦纳（Brenner）于1986年发表了 *C. elegans* 的完整连接组；FlyWire 联盟于2024年发表了成年 *Drosophila* 脑的连接组。
:::

## 由此引向何处

下面两章讲解神经元所携带的电信号：膜两侧的静息电位（[[neuroscience/resting-potential]]），以及沿轴突传导的动作电位（[[neuroscience/action-potential]]）。随后[[neuroscience/synapses]]展示一个神经元如何影响下一个。胶质细胞将在它们起作用的每个场合再度出现：钾缓冲、有髓轴突的传导速度、递质的清除，以及回路的发育与剪枝。

::: summary
- 神经元学说（卡哈尔，自1888年起，使用高尔基染色）认为神经系统由彼此分离、极化的细胞构成，它们在突触处通讯；缝隙连接、树突-树突突触和少数合胞体神经网是例外。
- 神经元有胞体、树突（常带树突棘）、自起始段开始并由其发动冲动的轴突，以及突触前终末；起始段的扩散屏障使轴突膜与胞体-树突膜界限分明。
- 神经元可按突起数目、功能（感觉、运动、中间神经元）、递质与效应、形状分类，如今还可按基因表达分类。
- 长轴突无法靠扩散供应（$t \approx x^2/2D$）；快速（约每天50–400 mm）与慢速（约每天0.2–8 mm）轴突运输由驱动蛋白和动力蛋白驱动，沿微管运送货物。
- 人脑约有860亿神经元（690亿在小脑），非神经元细胞数目与之相当；胶质细胞与神经元之比随神经元大小而异。
- 星形胶质细胞缓冲 K⁺、摄取谷氨酸并支持血脑屏障；少突胶质细胞和施万细胞形成髓鞘（g-ratio 约0.6–0.8，朗飞结约1 µm 长）；小胶质细胞起源于卵黄囊，是脑的巨噬细胞，并修剪突触。
:::

## 习题

::: exercise 树突内的扩散 {level=1 check="50"}
一种 $D = 100\ \mu\mathrm{m^2\,s^{-1}}$ 的第二信使在一个棘上产生。用 $t \approx x^2/2D$ 大致估计它沿树突扩散100 µm 需要多少秒？
::: solution
$t \approx (100)^2/(2\times100) = 10{,}000/200 = 50$ s。在几十微米的尺度上，即便又小又快的分子也要花上许多秒，这就是生化信号往往局限于产生它的突触、而电信号却能在毫秒内沿树突扩布的原因之一。
:::
:::

::: exercise 运输时间 {level=1 check="10"}
长颈鹿最长的运动轴突约4 m 长。按每天400 mm 的快速轴突运输，把一个囊泡从胞体运到终末需要多少天？
::: solution
$4000\ \mathrm{mm} / 400\ \mathrm{mm\,day^{-1}} = 10$ 天。按每天1 mm 的慢速运输则需约11年，与这种动物的寿命相当，因此这类轴突的终末依赖长寿命的蛋白质和局部合成。
:::
:::

::: exercise 说出结构的名称 {level=1}
说出下列结构各属于什么细胞、有何功能：(a)尼氏体；(b)轴突起始段；(c)星形胶质细胞终足；(d)朗飞结；(e)树突棘。
::: solution
(a)神经元：胞体内粗面内质网的团块，是膜蛋白和分泌蛋白的合成场所。(b)神经元：轴突最初几十微米，Na⁺ 通道密度很高，动作电位通常在此起始，并有分隔轴突膜与胞体-树突膜的扩散屏障。(c)星形胶质细胞：覆盖血管的突起，参与诱导血脑屏障、调节血流以及摄取 K⁺ 和水。(d)有髓轴突：相邻节间段之间的短间隙，Na⁺ 通道富集，动作电位在此再生。(e)神经元：树突上的小突起，在许多脑区是大多数兴奋性突触之所在，能把 Ca²⁺ 等化学信号区室化。
:::

::: exercise CNS 中的髓鞘 {level=2 check="133"}
一条直径4 µm 的中枢轴突 g-ratio 为0.5。每圈重复距离15 nm，它外面环绕着多少圈髓鞘（取最近整数）？
::: solution
外径 $D = d/g = 8$ µm；髓鞘厚度 $(8 - 4)/2 = 2$ µm $= 2000$ nm。圈数 $= 2000/15 \approx 133$。
:::

::: exercise 解读高尔基染色 {level=2}
高尔基法只染约百分之一的神经元，为什么它对确立神经元学说反而比把每个神经元都染色的方法更有用？然后再解释，为什么单凭高尔基法永远无法证明这一学说。
::: solution
若每种细胞都被染色，呈现出来的将是那种致密的突起缠结——正是它曾把解剖学家引向网状学说：每条纤维都是黑的，就分不清哪条纤维属于哪个细胞，也看不出两条纤维是否连续。稀疏而随机地显示一部分细胞、但每个被显示的细胞都染得完整，就能在干净背景中分离出单个神经元，从而追踪其整体形状，包括轴突的游离末端。然而光学显微镜分辨不了20 nm 的间隙，所以高尔基装片无法区分接触与融合；而且未染色的细胞看不见，该方法无法显示某个末端接触的是什么。证明突触处膜保持分离，需要电子显微镜（1955）。这种稀疏标记的原则在 Brainbow 和稀疏病毒标记等现代遗传学方法中延续下来，理由相同。
:::

::: exercise 神经元数目与脑的大小 {level=2}
某啮齿动物脑重0.4 g，有7000万神经元；某灵长类脑重80 g，有60亿神经元；人脑重1500 g，有860亿神经元。(a)计算各自的神经元密度（每克神经元数）。(b)这一比较对神经元数随脑质量在啮齿类与灵长类中的标度关系有何提示？还需要哪些数据来检验它？
::: solution
(a)啮齿类：$7\times10^7/0.4 = 1.75\times10^8$ g⁻¹。灵长类：$6\times10^9/80 = 7.5\times10^7$ g⁻¹。人类：$8.6\times10^{10}/1500 = 5.7\times10^7$ g⁻¹。

(b)密度随脑大小而下降，但灵长类到人之间的下降比啮齿类到灵长类之间更慢。埃尔库拉诺-乌泽尔的比较数据显示：啮齿类中脑越大、神经元越大，故神经元密度陡降；灵长类中神经元大小变化不大，所以同样质量下，大型灵长类脑能容纳多得多的神经元。三个物种确立不了一条标度定律，何况它们来自不同的目：你需要每个目内的许多物种，在双对数坐标上拟合，并进行系统发育独立的比较（[[animal-physiology/homeostasis]]）。
:::

::: exercise 胞外的钾 {level=3}
脑的胞外间隙约占组织体积的20 %。假设一串活动释放的 K⁺ 相当于每升**组织**0.5 mmol，而静息胞外 K⁺ 浓度为3 mmol L⁻¹。(a)若没有任何 K⁺ 被移除，胞外 K⁺ 浓度会变成多少？(b)用 $E_\mathrm{K} = 61.5\log_{10}([\mathrm{K}]_\mathrm{o}/[\mathrm{K}]_\mathrm{i})$ mV 且 $[\mathrm{K}]_\mathrm{i} = 140$ mmol L⁻¹，$E_\mathrm{K}$ 会改变多少？(c)解释星形胶质细胞如何限制这种变化。
::: hint
释放的 K⁺ 只分布在胞外体积中，而它只有组织体积的五分之一。
:::
::: solution
(a)释放量相当于每升胞外液 $0.5/0.2 = 2.5$ mmol L⁻¹，故[K⁺]ₒ从3升到5.5 mmol L⁻¹。

(b)3 mmol L⁻¹ 时的 $E_\mathrm{K}$：$61.5\log_{10}(3/140) = 61.5\times(-1.669) = -102.6$ mV。5.5 mmol L⁻¹ 时：$61.5\log_{10}(5.5/140) = 61.5\times(-1.406) = -86.4$ mV。变化约16 mV，方向为去极化，足以显著改变邻近神经元的兴奋性。

(c)星形胶质细胞的膜主要对 K⁺ 通透，并通过缝隙连接彼此耦联成网络。胞外 K⁺ 升高之处，局部 $E_\mathrm{K}$ 变得比胶质网络的膜电位更正（负得更少），于是 K⁺ 在该处流入星形胶质细胞；电流经耦联网络流动，把 K⁺ 驱向胞外 K⁺ 浓度低处，包括血管附近。这就是空间缓冲。星形胶质细胞还通过 Na⁺/K⁺-ATP 酶和 Na⁺–K⁺–2Cl⁻ 共转运体摄取 K⁺。因此剧烈活动期间[K⁺]ₒ的实际升高较小，即使在癫痫发作中也通常到约10–12 mmol L⁻¹ 就封顶。
:::

::: exercise 为什么要绝缘？ {level=3}
髓鞘在有颌脊椎动物、某些环节动物和某些甲壳类中独立演化出来，而乌贼和蟑螂却用巨大的无髓轴突来实现最快的逃逸反应。(a)独立演化对髓鞘的优势有何提示？(b)设想动物可能改用巨轴突而非髓鞘的一个理由。(c)一条外径10 µm 的哺乳动物有髓纤维以约60 m s⁻¹ 传导，而直径500 µm 的乌贼无髓巨轴突以约20 m s⁻¹ 传导。若无髓传导速度随直径的平方根而增，一条无髓轴突要多粗才能以60 m s⁻¹ 传导？这对一条含有数千条此类纤维的神经意味着什么？（忽略温度差异。）
::: solution
(a)亲缘关系很远的谱系独立趋同地演化出同一种特化结构，提示其优势强烈而普遍：给定轴突直径下的快速传导，为许多轴突节省空间和信号传导的能量。(b)巨轴突不需要特化的胶质机器，只要把现有的轴突变大或融合，就能由现有细胞演化而来；而对只需少数几条快轴突的单一逃逸通路来说，它的体积代价是承受得起的。无脊椎动物的巨轴突通常数目很少。(c)速度 $\propto \sqrt{d}$，所以把速度从20提高到60 m s⁻¹（三倍）需要 $3^2 = 9$ 倍的直径：约4.5 mm，是有髓纤维直径的450倍、横截面积的约200,000倍。一条几千条这样轴突组成的神经将有几厘米粗，脑也就装不下它的白质了。（乌贼轴突在海水温度下工作；在37 °C 它会快一些，但结论不变。）髓鞘使脊椎动物的脑得以紧凑。
:::
