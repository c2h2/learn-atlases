1926年，剑桥的埃德加·阿德里安（Edgar Adrian）与永耶·佐特曼（Yngve Zotterman）解剖蛙的颈部肌肉，一直剥到其神经只携带单个牵张感受器的信号，然后在肌肉上悬挂砝码。每个砝码都引发一串完全相同的动作电位，砝码越重，发放越快。冲动本身并不改变，改变的只有频率。阿德里安由此断定：感觉神经纤维是靠发放的频繁程度向脑报告刺激强度的。这第一个答案，回应的是一个至今仍驱动着神经科学的问题：关于世界、关于动物自身意图的信息，如何表征在神经元的活动中？

前面各章解释了锋电位如何产生、如何传导、如何被修饰。本章问它们意味着什么、我们如何测量。我们把锋电位序列当作随机点过程作统计描述；借助调谐曲线、费希尔信息量与信息论，考察一个神经元的发放能让观察者对刺激了解多少；讨论利用时间与群体而不只是发放率的编码；思考编码为何采取它们所采取的形式；再论脑的大尺度节律与睡眠；最后综述记录、成像与操控神经活动的方法，以及各自能显示什么、不能显示什么。概率背景见[数学图谱：概率](/learn/maths/course.php?c=probability)，统计学见[[biostatistics]]。

## 锋电位序列

由于动作电位全或无且几乎彼此相同，一个神经元的输出可以用它发放的时刻表——它的**锋电位序列**——来概括。同一刺激重复呈现，很少产生相同的锋电位序列：锋电位的数目与时间逐次变化。因此，要描述一个神经元的反应，就需要统计学。

::: definition 发放率 {#def-rate}
**锋电位计数发放率**是窗口 $T$ 内的锋电位数 $n$ 除以 $T$。**时变发放率** $r(t)$ 是时刻 $t$ 附近单位时间出现锋电位的概率，通过对许多试验平均来估计：在**刺激后时间直方图**（PSTH）中，把所有试验的锋电位按刺激起始后的时间分箱，每箱的计数除以试验数与箱宽。一个神经元的**调谐曲线** $f(s)$ 是其平均发放率作为某个刺激参数 $s$（朝向、声音频率、运动方向、空间位置）的函数。
:::

锋电位序列最简单的统计模型是泊松过程，其中各次锋电位彼此独立地发生。

::: proposition 泊松锋电位序列 {#prop-poisson}
若锋电位以恒定发放率 $r$ 且彼此独立地发生，则：

1. 长度 $T$ 的窗口内的锋电位数 $n$ 服从**泊松分布**，
$$
P(n) = \frac{(rT)^n}{n!}\,\mathrm{e}^{-rT},
$$ {#eq-poisson-count}
均值与方差都等于 $rT$，故**Fano 因子**（方差除以均值）为1；
2. **锋电位间隔**（ISI）$\tau$ 服从**指数分布**，$p(\tau) = r\,\mathrm{e}^{-r\tau}$，均值 $1/r$、标准差 $1/r$，故其**变异系数**（CV，标准差除以均值）也为1。

假设：发放率恒定，锋电位完全独立——包括不存在不应期。真实神经元两者都不满足，所以泊松过程是参照模型，不是描述。
:::

::: proof
把 $T$ 分成 $N$ 个宽度 $\Delta t = T/N$ 的小箱，每箱以概率 $r\Delta t$ 独立含一个锋电位。计数服从二项分布 $\binom{N}{n}(r\Delta t)^n(1 - r\Delta t)^{N - n}$；当 $N \to \infty$ 且 $N\Delta t = T$ 固定时，它趋于 [[#eq-poisson-count]]（二项分布的泊松极限）。锋电位之后长度 $\tau$ 的区间内无锋电位的概率是 $P(0) = \mathrm{e}^{-r\tau}$，故 ISI 超过 $\tau$ 的概率即此；对 $1 - \mathrm{e}^{-r\tau}$ 求导即得指数密度。速率为 $r$ 的指数分布，均值与方差为 $1/r$ 与 $1/r^2$。
:::

清醒动物的皮层神经元不规则发放，ISI 的 CV 接近1，锋电位计数的 Fano 因子常在约1到1.5之间（威廉·索夫特基与克里斯托夫·科赫，1993年；迈克尔·沙德伦与威廉·纽瑟姆，1998年）。这种不规则性出人意料，因为一个把许多独立输入汇总到固定阈值的神经元本应规则发放。一种解释是兴奋性与抑制性输入大致平衡，膜电位徘徊在阈值附近，靠涨落被推过阈值。另一些神经元，如听觉脑干和小脑中的某些神经元，发放非常规则，CV 远小于1。仅不应期一项就使序列比泊松更规则，如程序所示。

```python
import random, statistics

# Spike trains as a Poisson process, with and without a refractory period.
random.seed(2)
rate = 20.0          # spikes per second (rate of the underlying Poisson process)
T = 0.5              # s, counting window
trials = 2000

def spike_train(rate, T, dead=0.0):
    """Spike times (s) in [0, T): exponential intervals plus an optional dead time."""
    t, spikes = 0.0, []
    while True:
        t += dead + random.expovariate(rate)
        if t >= T:
            return spikes
        spikes.append(t)

for dead in (0.0, 0.010):                       # no refractoriness; 10 ms dead time
    counts, isis = [], []
    for _ in range(trials):
        s = spike_train(rate, T, dead)
        counts.append(len(s))
        isis += [b - a for a, b in zip(s, s[1:])]
    mean_n = statistics.mean(counts)
    fano = statistics.variance(counts) / mean_n
    cv = statistics.stdev(isis) / statistics.mean(isis)
    print(f"dead time {1000*dead:4.0f} ms: mean count {mean_n:5.2f}, "
          f"Fano factor {fano:.2f}, CV of ISIs {cv:.2f}")
# dead time    0 ms: mean count  9.98, Fano factor 1.00, CV of ISIs 0.98
# dead time   10 ms: mean count  8.21, Fano factor 0.70, CV of ISIs 0.80
```

每段间隔加上10 ms 死区时间后，平均间隔从50 ms 升至60 ms，CV 降到 $50/60 \approx 0.83$：序列变得更规则，Fano 因子随之下降。

::: example 锋电位计数有多可靠？ {#ex-count}
某神经元以泊松过程对刺激 A 以20 s⁻¹ 发放，对刺激 B 以30 s⁻¹ 发放。观察者在0.5 s 窗口内计数。(a)每个刺激下计数的均值与标准差各是多少？(b)对 A 恰好看到10个锋电位的概率是多少？一个都没有呢？(c)定义可分辨性 $d' = (\mu_B - \mu_A)/\sqrt{(\sigma_A^2 + \sigma_B^2)/2}$。计算它，并用正态近似（正确比例 $= \Phi(d'/\sqrt2)$）估计理想观察者各比较一次试验就能正确挑出 B 的概率。
::: solution
(a)A：均值 $rT = 10$，标准差 $\sqrt{10} = 3.16$。B：均值15，标准差 $\sqrt{15} = 3.87$。

(b)$P(10) = 10^{10}\mathrm{e}^{-10}/10! = 0.125$；$P(0) = \mathrm{e}^{-10} = 4.5\times10^{-5}$。

(c)$d' = 5/\sqrt{(10 + 15)/2} = 5/3.54 = 1.41$。正确比例 $= \Phi(1.41/1.414) = \Phi(1.0) = 0.84$。仅凭一个神经元、半秒的计数，50 %的发放率差别只有约84 %的试验能正确辨别。把窗口加倍到1 s，均值差加倍而噪声只乘 $\sqrt2$，使 $d'$ 升到2.0，正确比例升到约92 %。
:::
:::

## 一个神经元能传递多少信息？

调谐曲线告诉我们平均发放率如何依赖于刺激。但有用的问题是反过来的：从锋电位出发，刺激能被多准确地估计？这取决于平均发放率随刺激变化有多陡，以及反应围绕均值有多大的波动。

::: proposition 泊松神经元的费希尔信息量 {#prop-fisher}
对一个调谐曲线为 $f(s)$ 的神经元，其在窗口 $T$ 内的锋电位计数服从均值为 $Tf(s)$ 的泊松分布，它关于刺激 $s$ 的**费希尔信息量**为

$$
I_\mathrm{F}(s) = T\,\frac{f'(s)^2}{f(s)}.
$$ {#eq-fisher}

$N$ 个噪声独立的神经元，信息量相加。按 **Cramér–Rao 界**，对刺激的任一无偏估计 $\hat s$，其方差至少为 $1/I_\mathrm{F}(s)$；因此最佳估计的标准差至少为 $1/\sqrt{I_\mathrm{F}}$。

假设：计数服从泊松分布且神经元之间噪声独立；估计无偏。神经元之间的相关噪声可使群体的信息量大幅低于各神经元信息量之和。
:::

::: proof
对均值为 $\mu(s) = Tf(s)$ 的泊松计数 $n$，对数似然为 $\ln P(n\mid s) = n\ln\mu - \mu - \ln n!$。其对 $s$ 的导数是 $(n/\mu - 1)\mu'$。费希尔信息量是该导数平方的期望：$\E[(n - \mu)^2]\,\mu'^2/\mu^2 = \mu\cdot\mu'^2/\mu^2 = \mu'^2/\mu$，其中用了 $\Var(n) = \mu$。以 $\mu = Tf$、$\mu' = Tf'$ 代入，即得 $Tf'^2/f$。神经元彼此独立时对数似然相加，故其费希尔信息量也相加。
:::

这个结果有一个出人意料的推论。对钟形调谐曲线，信息量**在峰值处为零**——那里 $f'(s) = 0$；而在两侧斜率变化最快的地方最大。一个神经元最有用的地方，是辨别那些不在其偏好值上、而在其两侧的刺激。

::: example 朝向辨别 {#ex-fisher}
V1 的一个神经元对朝向有高斯调谐曲线，峰值发放率50 s⁻¹，宽度 $\sigma = 20°$，并具泊松波动。(a)它的费希尔信息量在哪里最大？对0.2 s 窗口，该处的值是多少？(b)仅凭这一个神经元作朝向估计，其标准差最小是多少？(c)若有100个这样的神经元，噪声独立且都位于各自信息量最大的位置，这个界变成多少？(d)人类观察者能辨别相差约1°的朝向。请评论。
::: solution
(a)设 $f = r_\mathrm{m}\mathrm{e}^{-u^2/2}$，$u = (s - s_0)/\sigma$，则 $f' = -fu/\sigma$，$f'^2/f = fu^2/\sigma^2$，它正比于 $u^2\mathrm{e}^{-u^2/2}$，在 $u^2 = 2$ 处最大，即 $s - s_0 = \pm\sqrt2\,\sigma = \pm28.3°$。该处 $f = 50\,\mathrm{e}^{-1} = 18.4$ s⁻¹，$I_\mathrm{F} = 0.2\times18.4\times2/20^2 = 0.0184$ deg⁻²。

(b)$1/\sqrt{0.0184} = 7.4°$。

(c)信息量相加：$100\times0.0184 = 1.84$ deg⁻²，给出 $1/\sqrt{1.84} = 0.74°$。

(d)100个位置得当的独立神经元就足以支持约1°的辨别。初级视觉皮层对任一位置作出反应的神经元远多于此，所以这个界原则上并不构成限制。实际上，调谐相似的神经元之间的噪声相关限制了汇总所带来的增益（埃胡德·佐哈里、沙德伦与纽瑟姆，1994年），下游解码也不完美；当前许多研究问的正是大脑在多大程度上用尽了其群体中可用的信息。
:::
:::

### 信息论

费希尔信息量衡量连续刺激能被多精确地估计。克劳德·香农的信息论（1948年）给出了更一般的度量：它适用于任何刺激与反应，离散或连续皆可，且无需对刺激将如何解码作任何假设。

::: definition 熵与互信息 {#def-information}
取值概率为 $p_i$ 的离散随机变量 $X$ 的**熵**为 $H(X) = -\sum_ip_i\log_2p_i$ 比特：即关于 $X$ 的平均不确定性，或确定它所需是/非问题的平均个数。刺激 $S$ 与反应 $R$ 之间的**互信息**为

$$
I(S;R) = H(R) - H(R\mid S),
$$ {#eq-mi}

即已知刺激使反应的不确定性减少的量；由对称性，它也等于已知反应使刺激的不确定性减少的量。$H(R\mid S)$ 称为**噪声熵**，是刺激固定时反应的平均熵。
:::

::: example 含噪检测器中的信息量 {#ex-mi}
一半试验有刺激，另一半没有。某神经元在有刺激的试验中有90 %在一个短窗口内至少发放一个锋电位；在没有刺激时（自发发放）这一比例为20 %。把反应当作二值的（发放或不发放）。该反应关于刺激携带多少信息，以每试验比特计？
::: solution
发放的概率为 $0.5\times0.9 + 0.5\times0.2 = 0.55$，故 $H(R) = -0.55\log_20.55 - 0.45\log_20.45 = 0.993$ 比特。

噪声熵：有刺激时 $H = -0.9\log_20.9 - 0.1\log_20.1 = 0.469$ 比特；无刺激时 $H = -0.2\log_20.2 - 0.8\log_20.8 = 0.722$ 比特。平均为 $H(R\mid S) = 0.596$ 比特。

$I = 0.993 - 0.596 = 0.40$ 比特每试验。完美检测器会给出1比特，即刺激的全部熵。自发发放（虚报）与漏报合起来损失了可能信息量的60 %。
:::
:::

## 超越发放率：时序与群体

发放率编码稳健，但慢：估计发放率需要许多锋电位或很长的窗口，而行为常常比这更快。苍蝇能在约30 ms 内对视觉刺激作出转向反应，其间一个运动敏感神经元可能只发放几个锋电位。好几类证据表明，神经系统还利用锋电位的时间和许多神经元的联合活动。

- **锁相。** 对低频声音的每一周期，听神经纤维都在某一特定相位发放，频率可达几千赫兹；这使得[[neuroscience/sensory-systems]]所述双耳时间之微秒级比较成为可能。
- **首锋电位潜伏期。** 当人的指尖接触物体时，触觉传入神经元群体中首批锋电位的相对时间，比发放率更快地传递力的方向与表面形状（罗兰德·约翰松与因格瓦尔斯·比尔兹涅克斯，2004年）。
- **相位进动。** 大鼠穿越一个位置细胞的位置野时，该细胞在正在进行的θ节律（6–10 Hz）中于越来越早的相位发放（约翰·奥基夫与迈克尔·雷斯，1993年），于是锋电位的相位在发放率之外还传递野内的位置信息。
- **稀疏编码。** 在昆虫蘑菇体中，气味由很小一部分肯尼恩细胞（Kenyon cell）表征，每个细胞只发放几个锋电位；在哺乳动物嗅觉皮层以及视觉皮层的某些区域，一个刺激同样只激活一小群特征鲜明的神经元。稀疏编码减少表征之间的重叠，使其更易于学习与存储。

实际上，问题与其说是“发放率还是时序？”，不如说是“信号在什么时间尺度上被读取？”一个膜时间常数为10–20 ms 的下游神经元大约就在这个窗口内积分其输入，所以对它而言，相关的编码就是许多神经元在每个这样的窗口内传入的锋电位总数：一种被快速采样的群体发放率。

### 群体解码

运动皮层的群体向量（[[neuroscience/motor-systems#def-population-vector]]）是读取群体的一种方式。更一般地说，若已知每个神经元的调谐曲线与噪声，就可以用**极大似然**估计刺激：选取使观测计数最可能的 $s$ 值。对独立的泊松神经元，这一估计在大群体上达到 Cramér–Rao 界，且可由一个简单的网络算出。真实群体存在**相关噪声**：调谐相似的神经元倾向于一起涨落，对它们取平均并不能以 $1/\sqrt N$ 的速度降噪。相关在多大程度上限制信息量取决于其结构，这是一个活跃的研究课题。

## 编码为什么是这个样子

1961年，霍雷斯·巴洛提出，感觉神经元的设计目标是尽可能高效地编码动物遇到的自然刺激，去除冗余，使每个锋电位携带尽可能多的信息：**高效编码假说**。对它的第一个定量检验来自丽蝇 *Calliphora*。

::: proposition 直方图均衡 {#prop-equalise}
一个反应范围有界（设为从0到 $R_\mathrm{max}$）、范围内各处噪声大小相同且很小的神经元，当它对概率密度为 $p(c)$ 的刺激 $c$ 的反应正比于刺激的累积分布时，传出的信息量最大，

$$
R(c) = R_\mathrm{max}\int_{-\infty}^{c}p(c')\,\dd c',
$$ {#eq-equalise}

于是所有反应水平被等频使用。假设：单一的输入-输出函数、有界的输出、以及很小且不依赖反应水平的噪声。
:::

::: proof {collapsed}
噪声小而均匀时，传出的信息量最大即输出的熵最大。被限制在固定区间内的变量，当它在该区间上均匀分布时熵最大。若 $R(c)$ 递增，则反应密度为 $p(c)/R'(c)$，当且仅当 $R'(c) \propto p(c)$——即 $R$ 正比于 $c$ 的累积分布——它才是常数（均匀）。
:::

西蒙·劳克林（1981年）测量了苍蝇所见自然场景中对比度的分布，以及苍蝇大单极细胞——接受感光细胞输入的神经元——的对比度-反应函数。反应曲线与自然对比度的累积分布高度吻合，正如 [[#eq-equalise]] 所预言：这些细胞把反应范围用在了最常出现的对比度上。

y: 0, 1.05
sliders: s=0.3:0.1:0.6:0.01
labels: \text{最优反应 } R/R_\mathrm{max}; \text{刺激分布（缩放）}
caption: 直方图均衡。第二条曲线是刺激对比度的分布（横轴），设为标准差 $\sigma$（滑块）的高斯分布并按峰值缩放到1；第一条曲线是对其传信息量最大的反应函数（以最大反应的分数量度），即 [[#eq-equalise]] 的累积分布。刺激最常见处反应最陡。把分布收窄，最优反应函数就变得更陡更窄——当环境变得更少变时，视网膜中的对比度适应做的正是这件事。
:::

::: example 用好反应范围 {#ex-equalise}
动物所见的自然对比度近似服从均值0、标准差0.3的正态分布。(a)最优神经元的反应范围有多大比例用于−0.3到+0.3之间的对比度？(b)另一个神经元作线性反应，在对比度±1处饱和；−0.3到+0.3之间的对比度占其范围的多大比例？(c)为什么第一个神经元更好？它什么时候会更差？
::: solution
(a)最优反应是累积正态分布，所以使用的范围是 $\Phi(1) - \Phi(-1) = 0.683$：反应范围的68 %用在落在一个标准差内的那68 %的对比度上。

(b)从−1到+1的线性反应把−0.3到+0.3映射到范围的30 %，而68 %的刺激落在其中。大部分反应范围被留给了罕见的高对比度。

(c)噪声大小固定时，第一个神经元把常见刺激分得更细，在典型环境下使信息量最大。若环境的对比度分布不同——例如在雾中——而它又不适配，就会更差；视网膜神经元确实会在几秒内按最近的对比度分布调整增益。
:::
:::

## 节律与睡眠

从脑表面记录到的是连续的电振荡。1875年，生理学家理查德·卡顿从兔和猴暴露的大脑记录了电活动；1929年，精神科医生汉斯·贝格尔经头皮记录了人类的**脑电图**（EEG），并描述了放松的人闭上眼睛时出现的8–12 Hz **α节律**。

脑电图，以及用脑内电极记录的**局部场电位**（LFP），主要来自突触电流而非锋电位。许多锥体神经元的长顶树突平行排列，当它们接受同步的突触输入时，其电流叠加成可在远处探测到的场；锋电位短暂且不同步，大多相互抵消。节律通常按频段划分：δ节律（约1–4 Hz）、θ节律（4–8 Hz，在啮齿类海马探索时显著）、α节律（8–12 Hz）、β节律（13–30 Hz）与γ节律（约30–100 Hz）。γ节律依赖于快发放、表达小清蛋白的抑制性中间神经元组成的网络：用光遗传学手段在小鼠皮层以γ频率驱动这些细胞，可产生γ振荡（杰西卡·卡丁、克里斯托弗·穆尔、蔡立慧等，2009年）。节律是否发挥计算作用——例如协调不同脑区之间的交流——还是兴奋与抑制平衡的副产物，尚有争议；就θ节律与相位进动而言，其发挥作用的证据最为充分。

### 睡眠

1953年，尤金·阿瑟林斯基与纳撒尼尔·克莱特曼注意到，睡觉的人会经历一段段快速眼动，其间脑电类似清醒状态，且被唤醒后他们通常报告在做梦。哺乳类与鸟类的睡眠在**快速眼动睡眠**（REM sleep，又称异相睡眠：脑电类似清醒，且如米歇尔·茹韦在猫上所证明的，肌张力丧失）与**非快速眼动睡眠**之间交替；后者最深的阶段以大幅、缓慢（约1 Hz 及以下）的波为主，此时皮层神经元在活动的“上”状态与静默的“下”状态之间交替。

睡眠在行为学上定义为一个可逆的反应性降低状态，受稳态调节（失去的睡眠会部分补回），在动物界广泛存在。黑腹果蝇（*Drosophila*）也会睡觉（琼·亨德里克斯、保罗·肖等，同为2000年），斑马鱼、线虫和水母同样如此。海豚和某些鸟类按大脑半球交替睡眠，军舰鸟则在飞行中以短暂片段睡觉（尼尔斯·拉滕博格等，2016年）。亚历山大·博尔贝利的**双过程模型**（1982年）把睡眠的时点描述为两个过程的相互作用：一个是稳态过程，即觉醒时累积、睡眠时消散的睡眠压力；另一个是由生物钟设定的昼夜节律过程。

动物为什么睡觉，至今没有完全弄清楚。提出的功能包括：记忆的巩固——支持证据有非快速眼动睡眠期间海马活动的重放（[[neuroscience/plasticity-learning]]），以及扰乱与睡眠相关的涟漪波会损害大鼠学习的实验；白昼突触增强之后突触强度的再归一化（朱利奥·托诺尼与基娅拉·奇雷利的突触稳态假说）；以及脑内代谢产物的清除——有报道说小鼠睡眠时这一过程加快（露露·谢、迈肯·内德高等，2013年），但其机制与幅度均有争议。这些假说并不互斥，答案也可能因动物而异。

## 记录、成像与操控大脑

本课程中关于神经元作为的每一个论断，都建立在某种测量方法之上。每种方法看得见神经活动的某些侧面，却对另一些视而不见。

| 方法 | 测量对象 | 空间尺度 | 时间尺度 | 常用于 |
|---|---|---|---|---|
| 膜片钳、锐电极 | 单个细胞的膜电位与电流 | 单个细胞 | 微秒 | 脑片、培养、在体小动物 |
| 胞外电极、四极电极（tetrode）、硅探针 | 电极尖端附近单个神经元的锋电位，以及局部场电位 | 每个位点约50–100 µm；每根探针数百个神经元 | 亚毫秒 | 动物；部分人类患者 |
| 钙成像（单光子与双光子） | 许多已鉴定细胞中的 Ca²⁺，作为发放的代理指标 | 单细胞到毫米 | 数十到数百毫秒 | 动物，常结合遗传学靶向 |
| 电压成像 | 光学测量膜电位 | 单细胞到毫米 | 约1毫秒 | 动物，方法在发展中 |
| 脑电图与脑磁图（EEG、MEG） | 突触电流的总和 | 厘米 | 毫秒 | 人类 |
| fMRI（BOLD） | 血氧水平，神经活动的间接测量 | 毫米 | 秒 | 人类与动物 |

**胞外记录**探测神经元发放时其附近微小的电压变化（几十到几百微伏）。同一电极记录到多个神经元的锋电位时，可按波形把它们分开（**锋电位分选**）；在四极电极这类记录位点紧密相邻的器件上，分选要可靠得多。以 Neuropixels 为代表的硅探针于2017年推出时，在一根10 mm 长的探杆上有960个记录位点（其中384个可同时记录），使行为中的小鼠多个脑区数百个神经元的同步记录成为可能。

**钙成像**所用的荧光指示剂与 Ca²⁺ 结合时亮度上升，而 Ca²⁺ 在锋电位期间流入神经元。基因编码指示剂始于 GCaMP（中井（Junichi Nakai）、大仓（Masamichi Ohkura）与井藤（Keiji Imoto），2001年），此后大幅改进（GCaMP6，2013年，以及后续各代），可在选定的细胞类型中表达数月。**双光子显微镜**（温弗里德·登克、詹姆斯·斯特里克勒与瓦特·韦布，1990年）使用脉冲红外光，只在焦点处激发荧光团，从而可对活脑内数百微米深的细胞成像。

**功能磁共振成像**依据的事实是：活动的脑区获得的含氧血多于其消耗，因此顺磁性的脱氧血红蛋白局部减少。小川（Seiji Ogawa）等1990年在大鼠描述了这种 **BOLD**（血氧水平依赖）对比。短暂神经爆发活动后，血流动力学反应约5 s 达峰，且与反映突触输入的局部场电位的相关优于与发放输出的相关（尼科斯·洛戈塞蒂斯等，2001年，猴）。

::: example 采样与指示剂 {#ex-sampling}
(a)胞外锋电位持续约1 ms，用于鉴定神经元的波形含有高达约5 kHz 的频率成分。需要多高的采样率？(b)某种钙指示剂的荧光在锋电位后约50 ms 内上升，以约0.5 s 的时间常数衰减；每个锋电位使荧光上升约20 %（$\Delta F/F = 0.2$）。若某神经元间隔100 ms 发放两个锋电位，假设线性叠加，峰值 $\Delta F/F$ 约为多少？(c)这对钙成像分辨锋电位时间与发放率的能力意味着什么？
::: solution
(a)由奈奎斯特-香农采样定理，采样率至少要有所含最高频率的两倍：至少10 kHz。实践中，胞外数据以20–30 kHz 采样。

(b)100 ms 后，第一个瞬变已衰减到 $0.2\,\mathrm{e}^{-0.1/0.5} = 0.2\times0.82 = 0.16$；叠加第二个后约为 $0.36$。

(c)由于每个瞬变的持续远长于锋电位间隔，间隔短于几百毫秒的瞬变会融合，单个锋电位的精确时间丢失，信号更接近平滑后的发放率。用优良的指示剂可以检测单个孤立锋电位，但发放率高时指示剂饱和，与锋电位计数的关系变为非线性。反卷积算法可以恢复近似的发放率。钙成像以时间精度换来了同时记录数千个已鉴定细胞的能力。
:::
:::

::: warning “某脑区亮起来了”与“相关表明功能”
fMRI 图像显示的不是神经元在发放；它是一张血流信号的统计图，该信号与神经活动的关联是间接的、缓慢的、空间模糊的，又经过阈值处理，于是有的脑区显色而有的不显色。没有“亮起来”的脑区可能仍在活动，而亮起来的脑区可能是在接受输入而非产生输出。更一般地说，任何记录无论多么精确，显示的只是活动与刺激或行为之间的**相关**，而不是活动导致行为。因果结论需要干预：损毁、失活或刺激所讨论的神经元，并配以适当的对照。
:::

### 操控活动

**光遗传学**提供了这种干预，兼具细胞类型特异性与毫秒精度。把光控的微生物蛋白在选定的神经元中基因表达：**通道视紫红质-2**是来自绿藻莱茵衣藻（*Chlamydomonas reinhardtii*）的光控阳离子通道，蓝光下使神经元去极化并使其发放（爱德华·博伊登、卡尔·迪瑟罗特等，2005年）；光驱动的氯泵（卤紫红质）和质子泵、以及光控阴离子通道则使其静默。**化学遗传学**工具——经改造、只被本身惰性的药物激活的受体——无需植入光源便能提供更慢、更持久的控制。这些工具与记录和行为结合，使检验特定细胞对某种行为是否必要或充分成为可能，[[neuroscience/plasticity-learning]]中的记忆痕迹（engram）实验即是一例。

### 连接组学

另一条路是完整地绘制环路结构。连续切片电子显微镜经自动化并与机器学习分割结合，已经产出 *C. elegans*（1986年，其后又为两性作了修订）、果蝇（*Drosophila*）幼虫与成体脑（成虫全脑连接组于2024年发表）的完整或近乎完整的连接组，截至2026年还有小鼠视觉皮层（MICrONS 项目，2025年）与人类颞叶皮层（2024年）的立方毫米级体积。接线图本身并不揭示环路计算什么，因为突触强度、神经调质与内在特性都很重要；但它能强力约束模型，而且已经揭示了出人意料的环路基序。

::: quiz
研究者发现，小鼠为获取奖励而舔舐时，其皮层某个区域的神经元强烈发放。哪个实验能最直接地检验这些神经元对舔舐是否必要？
- [ ] 用 Neuropixels 探针在同一区域记录更多神经元。
- [ ] 在舔舐期间测量该区域的 BOLD 信号。
- [x] 在任务期间用光遗传学手段静默这些神经元，测量舔舐是否受损，并设只用光与无视蛋白的对照。
- [ ] 证明这些神经元的发放先于舔舐100 ms。
::: solution
只有干预才检验必要性。记录更多神经元或测量 BOLD 只是增加相关证据；即便发放先于舔舐，虽有提示性，也可能是共同原因（例如在别处作出的决定）使然。任务中的光遗传学静默检验的是行为是否依赖这些神经元；对照排除了光与热效应。即便如此，功能缺损也可能来自对下游区域的间接破坏，所以静默实验通常与其他证据结合。
:::
:::

::: application 神经接口与诊断
记录与解码方法有医学用途。脑电图是诊断癫痫与评估睡眠的常规工具，运动皮层活动的解码器则驱动面向瘫痪者的实验性脑-机接口（[[neuroscience/motor-systems]]）。人工耳蜗沿耳蜗排布电极刺激听神经，利用的是[[neuroscience/sensory-systems]]中的位置编码，可以恢复听力。临床方面属于[医学图谱：癫痫](/learn/medicine/lesson.php?c=nervous-system&l=epilepsy)及医学图谱神经系统课程的其他章节。
:::

::: history
阿德里安与佐特曼1926年描述了发放率编码，阿德里安1932年与谢灵顿共获诺贝尔奖。卡顿1875年记录了动物的脑电位，贝格尔1929年记录了人类 EEG。香农1948年创立信息论；巴洛1961年提出高效编码；劳克林1981年在蝇中检验了它。阿瑟林斯基与克莱特曼1953年发现快速眼动睡眠；果蝇的睡眠于2000年被描述。休伯尔的钨微电极（1957年）使清醒动物的单细胞记录成为实用技术；四极电极随后出现于1980至1990年代，Neuropixels 探针则始于2017年。双光子显微镜（1990年）、基因编码钙指示剂（始于2001年）、BOLD fMRI（1990年）与光遗传学（2005年）改变了神经活动的测量与控制；果蝇全脑连接组（2024年）与毫米级哺乳动物皮层体积（2024–2025年）现已可用。
:::

## 由此引向何处

本章为本课程收尾。下一步是[[behaviour]]，它问这里描述的神经机制如何产生整个动物在其自然环境中的行为：动物如何觅食寻偶、躲避天敌、交流、合作与导航。本章用到的数量化工具——概率、估计与信息——在[[biostatistics]]与[[systems-biology]]中进一步发展。

::: summary
- 锋电位序列用统计学描述：泊松模型给出台泊松计数（Fano 因子为1）与指数锋电位间隔（CV 为1）；不应期使序列更规则。皮层发放不规则，接近泊松。
- 发放率编码（阿德里安）稳健但慢；发放率估计的精度随窗口长度与发放率按 $\sqrt{rT}$ 提高。
- 泊松神经元的费希尔信息量 $I_\mathrm{F} = Tf'^2/f$ 为刺激估计的精度设定界限（Cramér–Rao）；它在调谐曲线峰值处为零、在两侧最大；独立神经元之间可以相加，但相关噪声限制了汇总的收益。
- 互信息 $I = H(R) - H(R\mid S)$ 在不假设解码器的前提下衡量反应关于刺激传递的信息。
- 时序编码（锁相、首锋电位潜伏期、相位进动）、稀疏编码与群体编码对发放率编码作出补充。
- 高效编码预言反应函数匹配自然刺激的累积分布（劳克林的蝇）。
- EEG 与 LFP 反映同步的突触电流；节律跨越从δ到γ的频段；睡眠（快速眼动与非快速眼动）在动物中普遍存在，受稳态与昼夜节律过程调节，其功能仍有争议。
- 各种方法所见不同：电极（锋电位，亚毫秒）、钙成像（许多已鉴定细胞，慢）、fMRI（血流，秒，毫米）、EEG（突触电流总和）。因果论断需要干预（光遗传学、化学遗传学）；连接组约束环路模型。
:::

## 习题

::: exercise 一个锋电位计数 {level=1 check="0.0067"}
某神经元以泊松过程以10 s⁻¹ 发放。它在0.5 s 窗口内一个锋电位都不发放的概率是多少（保留两位有效数字）？
::: solution
$P(0) = \mathrm{e}^{-10\times0.5} = \mathrm{e}^{-5} = 0.0067$。
:::
:::

::: exercise 锋电位间隔 {level=1 check="0.095"}
对以20 s⁻¹ 发放的泊松神经元，有多大比例的锋电位间隔短于5 ms（保留三位小数）？真实神经元为何可能更少？
::: solution
$1 - \mathrm{e}^{-20\times0.005} = 1 - \mathrm{e}^{-0.1} = 0.095$。真实神经元的不应期有几毫秒，会压制极短的间隔，所以观测到的比例更低。
:::
:::

::: exercise 方法与问题的匹配 {level=1}
以下各题你会各选什么方法？为什么？(a)某种中间神经元对小鼠辨别两种气味是否必需。(b)脑干听觉结构中锋电位相对于声音的相位的时间。(c)人脑中哪些区域在阅读时比在静息时更活跃。(d)斑马鱼幼鱼捕食时其视顶盖中500个已鉴定神经元的活动。
::: solution
(a)在任务期间以光遗传学或化学遗传学手段静默该型中间神经元，并设对照：因果问题需要干预。(b)具亚毫秒分辨的胞外单单元记录；钙成像太慢。(c)fMRI（或就时间而言 EEG/MEG），适合健康志愿者的无创方法，接受其间接性。(d)双光子或光片钙成像，配基因编码指示剂；幼鱼小而透明，可同时成像许多已鉴定细胞。
:::

::: exercise 从数据计算 Fano 因子 {level=2}
刺激重复50次，某神经元在1 s 窗口内的锋电位计数均值12、方差18；另一个神经元的计数均值40、方差8。(a)分别计算 Fano 因子。(b)每个值可能由什么造成？(c)若刺激的某个小变化使两者的均值都改变10 %，哪个神经元能更好地辨别？
::: solution
(a)$18/12 = 1.5$ 与 $8/40 = 0.2$。(b)第一个神经元比泊松更波动，这在皮层常见，可由试验间共享的兴奋性或注意力的涨落、或由簇发放电造成。第二个远比泊松规则，正如一个高发放率、强不应期或规则起搏的神经元所预期，某些听觉与小脑神经元即是。(c)对第一个，均值变化1.2，对照标准差 $\sqrt{18} = 4.2$：$d' \approx 0.28$。对第二个，变化为4，对照 $\sqrt8 = 2.8$：$d' \approx 1.4$。第二个好得多，因为它发放得更多也更规则。
:::
:::

::: exercise 完美神经元与无用神经元的互信息 {level=2}
沿用 [[#ex-mi]] 的设定（一半试验有刺激），计算以下情形的互信息（每试验比特）：(a)神经元在每个有刺激的试验发放、其余情况绝不发放；(b)不论有无刺激，它都在50 %的试验发放；(c)它在每个有刺激的试验和每个无刺激的试验都发放。请评论。
::: solution
(a)反应决定刺激：$H(R) = 1$ 比特，$H(R\mid S) = 0$，$I = 1$ 比特。(b)$H(R) = 1$ 比特，$H(R\mid S) = 1$ 比特，$I = 0$：与刺激无关的波动反应不携带信息。(c)$H(R) = 0$（总是发放），$I = 0$：永不变化的反应同样不携带信息。信息要求反应变化，且其变化依赖于刺激；单纯的高发放率或高变异性毫无意义。
:::

::: exercise 血流动力学延迟 {level=2}
一个 fMRI 实验中，每12 s 呈现1 s 视觉刺激，视觉皮层 BOLD 信号在每次刺激开始后5 s 达峰。第二个实验在0 s 呈现一个刺激、2 s 再呈现一个。(a)原始 BOLD 信号能在时间上把两个反应分开吗？(b)允许在统计上分开它们的是什么假设？(c)为什么 fMRI 不适合测量两个区域哪个早50 ms 激活？
::: solution
(a)不能直接分开：每个反应持续数秒，相隔2 s 的两个反应严重重叠。(b)若 BOLD 反应近似线性且时不变（对两个事件的反应是平移后的单事件反应之和），则可用已知或估计的血流动力学反应函数对重叠信号作反卷积，这是事件相关 fMRI 的标准做法。对相隔一两秒以上的事件这一假设大致成立，对快速序列则失效。(c)由于与神经时间无关的血管因素，血流动力学反应的潜伏期在不同区域和不同人之间相差超过一秒，所以神经起始50 ms 的差异无从显现。需要 EEG、MEG 或颅内记录。
:::
:::

::: exercise 一个锋电位的代价与稀疏编码 {level=3}
假设皮层神经元每个锋电位约耗 $10^8$–$10^9$ 个 ATP 分子（泵回该锋电位及其引起的突触电流所移动的离子），某皮层有 $1.6\times10^{10}$ 个神经元。(a)若平均发放率为10 s⁻¹，按每个锋电位 $5\times10^8$ 个 ATP 计，发放共需每秒多少 ATP？(b)细胞内 ATP 水解的自由能约为每分子 $8\times10^{-20}$ J。这是多大功率？(c)人脑皮层总共大约消耗5 W，此数不确定度相当大。你的数字对平均发放率与稀疏编码说明什么？
::: solution
(a)$1.6\times10^{10}\times10\times5\times10^8 = 8\times10^{19}$ 个 ATP 每秒。

(b)$8\times10^{19}\times8\times10^{-20} = 6.4$ W。

(c)仅此一项就超过皮层的全部预算，还未计静息电位与其他过程。因此平均发放率必定更低，在1 s⁻¹ 量级或以下，彼得·莱尼（2003年）用类似推理给出的估计正是如此：任一时刻只有很小一部分皮层神经元能强烈发放。于是能量是偏爱稀疏编码的硬约束——信息由少数哪些神经元发放来携带。确切数字取决于对每个锋电位 ATP 量的假设，该量随动作电位的效率与每个神经元的突触数目而变，所以结论是关于数量级，而非精确发放率。
:::

::: exercise 用两个神经元解码 {level=3}
两个神经元对运动刺激的方向 $\theta$ 的平均发放率为 $f_1(\theta) = 20 + 15\cos\theta$ 与 $f_2(\theta) = 20 + 15\sin\theta$（单位 s⁻¹），具泊松波动。在0.5 s 窗口内它们分别发放 $n_1 = 17$ 与 $n_2 = 4$ 个锋电位。(a)写出 $\theta$ 的对数似然。(b)在 $\theta = 0°, 30°, 60°, \ldots, 330°$ 处求值，找出精确到最近30°的最可能方向。(c)似然的形状对不确定性说明什么？
::: hint
对泊松计数，$\ln P(n_1, n_2\mid\theta) = \sum_i[n_i\ln(Tf_i(\theta)) - Tf_i(\theta)] + \text{常数}$。
:::
::: solution
(a)取 $T = 0.5$ s，$\mu_i(\theta) = 0.5f_i(\theta)$，则不计常数项 $L(\theta) = 17\ln\mu_1 - \mu_1 + 4\ln\mu_2 - \mu_2$。

(b)求值（$\mu_1 = 10 + 7.5\cos\theta$，$\mu_2 = 10 + 7.5\sin\theta$）：0°时 $\mu = (17.5, 10)$，$L = 17\ln17.5 - 17.5 + 4\ln10 - 10 = 48.66 - 17.5 + 9.21 - 10 = 30.37$。330°时 $\mu = (16.50, 6.25)$，$L = 47.66 - 16.50 + 7.33 - 6.25 = 32.24$。300°时 $\mu = (13.75, 3.50)$，$L = 44.56 - 13.75 + 5.01 - 3.50 = 32.32$。270°时 $\mu = (10, 2.5)$，$L = 39.14 - 10 + 3.67 - 2.5 = 30.31$。其他角度的值更低（例如0°和270°为30.3或更低，上半平面因 $\mu_2$ 大而低得多）。格点上的最大值在300°，330°几乎同样可能；更细的搜索把极大似然估计定在约314°。

(c)似然很宽：300°与330°的对数似然相差不到0.1，似然比约1.1，数据几乎无法区分两者；最大值附近约±30–40°内的方向仍然可信。两个神经元、半秒计数只能给出粗糙的估计；精度随神经元增多、窗口加长而提高，与 [[#prop-fisher]] 相符。
:::
