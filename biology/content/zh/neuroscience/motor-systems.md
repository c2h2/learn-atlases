去拿一杯咖啡。在手移动之前，脑已经从你看到的东西中定位了杯子、决定了用哪只手臂、规划好了路径，并设定好躯干与腿的姿势，使这一伸手不会把你带倒。手臂移动时，约五十块肌肉按精确的顺序收缩与舒张，每一块都由数百个运动神经元驱动，发放率每隔几毫秒就在变化。手指在到达之前就按把手的宽度张开，并以恰够分量——杯子的重量是你预先猜到的——的力合拢。如果杯子意外地装得很满，抓握会在十分之一秒内、在你意识到这一意外之前收紧。这一切平常得不能再平常；机器人却仍然觉得它很难。

行为就是运动，而每一个神经系统的终极存在理由，是移动一个身体。本章自下而上地看神经系统如何产生并控制运动。我们先看最后公路——运动神经元及其驱动的肌纤维；然后是脊髓中组织的反射；接着是中枢模式发生器：它们产生行走、游泳、呼吸等节律性运动而不需要感觉输入；最后是脑内（运动皮层、小脑与基底神经节）选择、计划并修正运动的下行系统。肌肉收缩的力学、兴奋-收缩耦联与力-速度关系见[[animal-physiology/muscle-movement]]，神经-肌肉接头的突触传递见[[neuroscience/synapses]]。运动的临床疾病归[医学图谱：运动系统](/learn/medicine/lesson.php?c=nervous-system&l=motor-systems)。

## 运动单位与力量的分级

脊椎动物每一块骨骼肌纤维都由一个运动神经元支配，而该运动神经元中的每个动作电位都在其支配的每条肌纤维中引起一个动作电位，进而引起一次单收缩。神经-肌肉接头的传递安全系数极大，工作起来如同逐一传递的继电器。谢灵顿把运动神经元称为**最后公路**：无论脑或脊髓作出什么决定，它作用于肌肉的唯一途径就是经过运动神经元。

::: definition 运动单位与运动神经元池 {#def-motor-unit}
一个**运动单位**是一个运动神经元及其支配的全部肌纤维。**神经支配比**是每个运动单位的肌纤维数：从眼外肌（需要精细控制）的约十条，到哺乳动物腿部大肌肉的一千条以上。一块肌肉的**运动神经元池**是支配它的所有运动神经元的集合，在脊髓腹角中成列聚集，或位于脑干核团中。
:::

同一运动单位的肌纤维类型相同，散布在肌肉中，与其他单位的纤维相互混杂。哺乳动物的运动单位可分为三大类，最早由 Robert Burke 与合作者在1970年代初于猫身上从生理学上区分：

| 类型 | 单收缩 | 力量 | 疲劳 | 运动神经元 |
|---|---|---|---|---|
| S（慢） | 慢、长 | 小 | 极抗疲劳 | 小，阈值低 |
| FR（快，抗疲劳） | 快 | 中等 | 抗疲劳 | 中等 |
| FF（快，易疲劳） | 快、短暂 | 大 | 数分钟即疲劳 | 大，阈值高 |

神经系统以两种方式对肌肉力量进行分级：靠**募集**，即动用更多的运动单位；靠**频率编码**，即使每个活动单位发放更快。

### 频率编码与强直

单个动作电位引起一次持续数十毫秒的单收缩，远长于动作电位本身。如果第二个动作电位在第一个单收缩舒张之前到达，两者叠加，力量升得更高。在足够高的发放率下，单收缩融合为平滑持续的收缩，即**强直**，其力量通常是单收缩的三到十倍。额外的力量一部分来自单收缩的简单重叠，一部分因为单个动作电位释放的 Ca²⁺ 不够多、不够久，不能完全激活收缩蛋白（[[animal-physiology/muscle-movement]]）。

### 募集与大小原则

1957年，亨内曼（Elwood Henneman）在去大脑猫记录腹根放电，同时牵拉肌肉以反射性地兴奋其运动神经元池，发现运动神经元总是按同一顺序被募集：动作电位小的（因而是轴突细、胞体小的）先被募集，动作电位大的后被募集。撤销募集按相反顺序进行。这种按大小的有序募集就是**大小原则**，并已在包括人在内的许多肌肉与物种中得到证实。

::: proposition 为什么小的运动神经元先被募集 {#prop-size}
假设一个池中的所有运动神经元都接受相同的总突触电流 $I$，并且都有相同的比膜电阻 $R_\mathrm{m}$ 与相同的阈电位去极化量 $\Delta V_\mathrm{th}$。膜面积为 $A$ 的运动神经元，其输入电阻为 $R_\mathrm{in} = R_\mathrm{m}/A$，故其稳态去极化为

$$
\Delta V = IR_\mathrm{in} = \frac{IR_\mathrm{m}}{A},
$$

它在 $I \ge \Delta V_\mathrm{th}A/R_\mathrm{m}$ 时达到阈值。募集所需的电流与神经元面积成正比，所以小的神经元先被募集。

假设：所有神经元接受的突触电流相同，比膜特性与阈值相同。实际上，大的运动神经元接受更多突触，其比膜电阻也更低，这进一步加强了该效应；大小原则是一条被观察到的规律，输入电阻是其主要的而非唯一的解释。
:::

::: example 运动神经元池中的募集阈值 {#ex-recruit}
在猫，一个慢型运动神经元的输入电阻为2.5 MΩ，一个快易疲劳型的输入电阻为0.5 MΩ。两者都必须去极化12 mV 才能发放。(a)各自需接受多大的稳态电流才能到达阈值？(b)肌肉接受一个从0缓慢上升到10 nA 的突触驱动。哪些运动单位发放？(c)这个顺序对动物为何合理？
::: solution
(a)$I = \Delta V/R_\mathrm{in}$：慢单位，$12\ \mathrm{mV}/2.5\ \mathrm{M\Omega} = 4.8$ nA；快易疲劳单位，$12/0.5 = 24$ nA。

(b)只有慢单位（以及阈值低于10 nA 的其他单位）发放；快易疲劳单位在驱动超过24 nA 之前保持沉默。

(c)最常用的单位——负责姿势和轻巧动作的——是慢的、小的、抗疲劳的单位，它们产生小而可精细分级的力量增量。大的、力量强但易疲劳的单位则留给跳跃之类短暂而剧烈的用力。每新募集一个单位贡献的力量也大致与已存在的力量成正比，使力量控制的相对精确度随力量增大而大致保持不变：一种类韦伯定律的性质（[[neuroscience/sensory-systems#def-weber]]）。而且脑不必挑选该用哪些运动单位：池的生物物理学自动替它做了。
:::
:::

## 脊髓反射

**反射**是对感觉刺激的快速、刻板反应，由固定回路组织。谢灵顿主要在脑与脊髓离断的猫和狗上工作，在二十世纪头几十年把脊髓反射研究变成了整合神经生理学的基础。反射揭示了运动回路的基本构件。

### 肌梭与牵张反射

大多数骨骼肌内、与普通的（梭外）肌纤维平行，都埋着**肌梭**：数毫米长的小囊，内含几条小型特化的**梭内**肌纤维，被感觉终末缠绕。肌肉被牵拉时，肌梭随之被拉伸，其感觉终末发放。**Ia 类**传入纤维来自初级终末，既报告肌肉长度也报告其变化率；**II 类**传入纤维来自次级终末，主要报告长度。梭内肌纤维有自己专门的小的**γ运动神经元**支配，不同于驱动梭外肌肉的大**α运动神经元**。

::: definition 牵张反射 {#def-stretch}
**牵张反射**（肌紧张反射）是肌肉对自身被牵拉产生的收缩。其核心是一个**单突触**回路：来自某肌肉肌梭的 Ia 传入纤维直接与该肌肉（及其协同肌）的α运动神经元形成兴奋性突触。并行的通路上，Ia 传入纤维兴奋**Ia 抑制性中间神经元**，后者抑制拮抗肌的运动神经元，使拮抗肌在被牵张肌肉收缩的同时舒张：**交互抑制**。
:::

Edward Liddell 与谢灵顿在1924年描述了去大脑猫的牵张反射，David Lloyd 则在1943年通过测量猫脊髓反射放电的中枢延迟证明，最快的成分只经过一个突触。医生叩击肌腱检查膝跳，就是对股四头肌肌梭的一次短暂而同步的牵拉。在日常功能中，牵张反射抵抗肌肉长度的意外改变：如果手上突然被加一个重物，你的肘屈肌被拉长，其肌梭发放，反射在几十毫秒内增大其力量。

第二种感受器——**高尔基腱器官**——串联于肌肉与腱的交界处，报告**力量**而非长度。其**Ib 类**传入纤维经中间神经元抑制同一肌肉的运动神经元（自体抑制），尽管如后文所述，在行走时同样的传入纤维可以转为兴奋伸肌运动神经元。

肌梭为什么需要自己的运动支配？如果只由α运动神经元使肌肉缩短，肌梭就会松驰下来并停止报告信号——恰在长度信息最有用之际。γ运动神经元使梭内纤维的两端收缩，收紧松驰，让肌梭在肌肉长度的整个范围内保持敏感。在人的随意运动中，Åke Vallbo 与合作者在1970年代对单个肌梭传入纤维的记录表明，α与γ运动神经元被一同激活（**α–γ共同激活**），使肌梭在整个收缩过程中持续报告。

::: example 测量中枢延迟 {#ex-delay}
在 Lloyd 类型的经典实验中，对猫脊髓的一条背（感觉）根给予电刺激，并从同节段的腹（运动）根记录反射放电。从刺激到腹根放电的总潜伏期为1.6 ms。传入与传出纤维在电极与脊髓灰质之间各走15 mm，传导速度分别为100 m s⁻¹（Ia 传入）与80 m s⁻¹（α运动轴突）。(a)估算中枢延迟。(b)已知突触延迟约0.5 ms、灰质内传导约需0.2–0.3 ms，这条通路上有几个突触？(c)一个较慢的反射成分潜伏期为2.6 ms，它可能代表什么？
::: solution
(a)脊髓外的传导：传入 $15\ \mathrm{mm}/100\ \mathrm{m\,s^{-1}} = 0.15$ ms；传出 $15/80 = 0.19$ ms；合计0.34 ms。中枢延迟 $= 1.6 - 0.34 = 1.26$ ms。其中除突触延迟外，还包括灰质内的传导以及运动神经元达到阈值并发放所需的时间。

(b)减去髓内传导（约0.25 ms）与运动神经元 EPSP 达到阈值所需的时间（零点几毫秒），大致剩下0.5–0.7 ms，够一个突触延迟而不容纳两个。这条通路是单突触的，这正是 Lloyd 从约1 ms 或更短的延迟得出的结论。

(c)多出的约一毫秒容得下大约一到两个额外的突触：一条经脊髓中间神经元（如皮肤或 II 类传入纤维激活的那些）的**多突触**反射通路。
:::
:::

### 回缩反射与交叉伸展

足部受到痛刺激会引起**屈肌回缩反射**：整个肢体的屈肌收缩、伸肌舒张，把足部移开。因为这条腿不能再负重，对侧的腿同时伸展，即**交叉伸展反射**。这些反射是多突触的：伤害性传入纤维兴奋成串的中间神经元，其分支抵达许多节段以及脊髓两侧。回缩反射是分级的并适配于刺激部位：被激活的肌肉模式取决于皮肤受刺激的部位，使受刺激的区域离开刺激源。

::: warning “反射是固定而自动的”
反射是刻板的，但不是僵死的。它们的增益被下行通路以及脊髓回路的状态不断调节。一只行走中的猫，足背受到轻触，若在摆动相到达（抬足越过障碍）则引起屈曲，若在支撑相到达则引起伸展——此时屈曲会使动物跌倒（Hans Forssberg 与合作者，1975年）：这是**相位依赖的反射翻转**。当任务要求肢体坚硬时牵张反射被加强，要求柔顺时被减弱；在人，其增益还可以经训练而改变。与其把脊髓反射看作固定反应，不如把它们看作运动中可调的元件。
:::

猫的膝伸肌突然被牵拉。在几十毫秒内，你预期下列哪种情况？

- [x] 兴奋伸肌运动神经元，抑制膝屈肌运动神经元。
- [ ] 同时兴奋伸肌与屈肌运动神经元。
- [ ] 没有变化，因为牵张反射需要脑。

被牵拉伸肌的肌梭发出的 Ia 传入纤维单突触地兴奋其α运动神经元，并经 Ia 抑制性中间神经元抑制拮抗的屈肌（交互抑制）。这一反射在脊髓内组织，与脑离断后仍然存在，谢灵顿的去大脑标本即是如此。
:::
:::

## 中枢模式发生器

行走、游泳、飞翔、咀嚼、呼吸与挠痒都是有节律的。它们是一串反射的链条——每个动作产生感觉反馈触发下一个动作——吗？谢灵顿曾这样认为。他的学生 Thomas Graham Brown 却不这么想。1911年他证明，一只脊髓被切断、背根也被剪断因而腿部没有任何感觉反馈能到达脊髓的猫，在术后短时间内仍会产生屈肌与伸肌交替的节律性收缩。他提出，节律由脊髓内部两个相互抑制的**半中枢**产生，一个驱动屈肌，一个驱动伸肌，因每个半中枢活动的疲劳而交替。

::: definition 中枢模式发生器 {#def-cpg}
**中枢模式发生器**（CPG）是一种神经回路，在没有节律性感觉输入、也没有节律性下行指令的情况下，仍能产生节律性、有模式的运动输出。从被药物或紧张性刺激诱发产生节律的离体或去传入神经系统，从运动神经记录到的这种输出称为“虚拟”（fictive）运动、游泳或呼吸。感觉反馈与下行信号不是产生节律所必需的，但正常情况下它们调节节律的时相与幅度。
:::

决定性实验来自1960与1970年代的无脊椎动物和简单脊椎动物。Donald Wilson 在1961年证明，去除翅膀的感觉反馈后，蝗虫的飞行运动模式仍以较低的频率持续。七鳃鳗（一种无颌鱼）离体脊髓在谷氨酸激动剂灌流下产生虚拟游泳，Sten Grillner 与合作者弄清了其大部分回路。海洋软体动物 *Tritonia* 的逃逸游泳 CPG，Peter Getting 将其追溯到少数几个可鉴定的中间神经元。研究得最透的 CPG 属蟹和龙虾的**口胃神经节**：约30个神经元驱动胃的节律性运动。其幽门节律每秒约一个周期，由一个起搏器神经元群产生，并被抑制性突触塑形，其神经元之间的每一条连接都已被绘出。

多种机制可以产生节律，常常在同一回路中组合使用。

- **起搏神经元**由于其内在电导而自行振荡，通常是一个缓慢激活的内向电流（如持续性 Na⁺ 电流或 Ca²⁺ 电流）与一个缓慢激活、终止每个爆发的外向电流。
- **半中枢振荡器**由两个相互抑制的神经元或神经元群构成；两者单独都不振荡，但这一对会交替，因为活动侧的发放会衰减（经由适应或突触抑制），或者因为被抑制的一侧从抑制中逃逸，例如通过超极化激活电流。
- **网络振荡器**来自若干细胞类型之间抑制环或反复性兴奋的环路。

它们都共享一个数学内核：一个把系统打开的快速正反馈过程，加上一个把系统关掉的较慢负反馈过程，两者共同产生一个**极限环**，即我们在动作电位的 FitzHugh–Nagumo 模型中遇到过的同一结构（[[neuroscience/action-potential]]）。

caption: 一个抽象的节律发生器，van der Pol 振子：横轴 $x$ 代表一个半中枢的活动（一侧为正，另一侧为负），纵轴代表其变化率。两条轨迹从非常不同的状态出发，一条接近平静，一条远在外部，都收敛到同一条闭轨，即极限环。这正是 CPG 稳健性的来源：无论初始条件如何、受到扰动之后，节律都回到相同的幅度与周期。增大 $\mu$（非线性强度），振荡变成松弛振荡，缓慢积聚与两侧之间的突然切换交替出现，就像屈肌与伸肌爆发的交替。
:::

Eve Marder 与合作者利用口胃神经节提出了一个适用于一切回路的问题：其参数必须设定得多精确？Astrid Prinz、Dirk Bucher 与 Marder（2004年）模拟了幽门回路三细胞模型的数百万个版本，采用不同的电导与突触强度组合，发现截然不同的组合能产生几乎无法区分的节律。对真实动物的测量表明，已鉴定神经元的电导在个体之间相差数倍，而节律却相同。良好的功能不要求一组唯一的参数；它要求落在一大片可接受解的区域之内，而神经元似乎会以自稳态方式调节自身电导以停留在这一区域内。

### 脊椎动物的行走

在哺乳动物，脊髓中也含有行走 CPG。脊髓被横断的猫，经过训练和扶持，能够用后腿在活动平板上行走，平板提供根据带速调节节律的感觉信号。自2000年代初以来，对小鼠的遗传学解析鉴定出控制模式不同侧面的若干类脊髓中间神经元：例如，损毁一类轴突越过中线的连合中间神经元（V0 神经元），会把行走正常的左右交替变成同步的蹦跳（Adolfo Talpalar、Ole Kiehn 与合作者，2013年）。节律由脑干的命令信号启动、停止并设定速度，主要来自中脑运动区，对去大脑猫分级刺激该区，会提高行走速度，并使步态由步行转为快步再转为奔跑。

感觉反馈同样重要。来自负重感受器（高尔基腱器官）的信号在腿部负重期间延长支撑相，来自髋屈肌被牵拉的信号在腿于体后伸得足够远时触发向摆动相的转换。CPG 与反射是伙伴，不是互相排斥的选项。

## 下行控制

在脊髓之上，有三个系统塑造运动：**运动皮层**以及来自皮层和脑干的下行纤维束，发动并引导随意运动；**小脑**，协调并校准它们；以及帮助选择该做哪些运动的**基底神经节**。

### 运动皮层

1870年，Gustav Fritsch 与 Eduard Hitzig 用弱电流刺激犬暴露的大脑皮层，从主要感觉区前方的一条带引出了对侧肢体的运动。这个区域——**初级运动皮层**（M1）——按躯体定位方式组织：在灵长类，相邻的区域控制相邻的身体部位，手与面所占的面积比例特别大。Wilder Penfield 与 Edwin Boldrey 在1930年代对接受癫痫手术的人类患者绘制了这张图，并把它画成运动“**小人**”（homunculus）。实际的图比卡通所示更粗糙、也更重叠：单个皮层位点影响多块肌肉，而每块肌肉受多个位点影响。

M1 经**皮质脊髓束**投射到脊髓。在大多数哺乳动物，其轴突终止于中间神经元，但在灵长类，尤其在类人猿与人类，许多轴突直接终止于运动神经元，特别是手部肌肉的运动神经元。这些**皮质-运动神经元**连接与手指独立运动的能力相关。

运动皮层神经元编码什么？Apostolos Georgopoulos 与合作者训练恒河猴移动一个把手，从中心位置移向沿圆周布置的目标（1982年）。M1 的大多数神经元对某一**最佳方向**的运动发放最多，其发放率随运动方向与该方向夹角的增大而平滑下降，大致按余弦：

$$
r(\theta) = b + k\cos(\theta - \theta_\mathrm{p}),
$$ {#eq-cosine}

其中 $r$ 是发放率，$\theta$ 是运动方向，$\theta_\mathrm{p}$ 是该细胞的最佳方向，$b$ 是基线发放率，$k$ 是调制深度。每个神经元的调谐都很宽，对很广的方向范围都有活动，因此单凭一个细胞无法精确指明一个方向。一个群体可以做到。

::: definition 群体向量 {#def-population-vector}
对于最佳方向为 $\theta_{\mathrm{p},i}$（单位向量 $\mathbf u_i$）、发放率为 $r_i$ 的神经元群体，**群体向量**是各最佳方向向量按每个神经元相对其基线的发放率变化加权的和：

$$
\mathbf P = \sum_i (r_i - b_i)\,\mathbf u_i.
$$

当最佳方向均匀分布、调谐为余弦时，$\mathbf P$ 指向运动的方向。
:::

::: example 用四个神经元解码方向 {#ex-popvector}
四个 M1 神经元的最佳方向为0°、90°、180°与270°，在[[#eq-cosine]]中各有基线 $b = 30$ 次发放 s⁻¹ 与调制深度 $k = 20$ 次发放 s⁻¹。一只猴把臂移向60°。(a)计算每个神经元的发放率。(b)计算群体向量及其方向。(c)为什么实际估计会有噪声？如何克服？
::: solution
(a)$r = 30 + 20\cos(60° - \theta_\mathrm{p})$：0°处，$30 + 20(0.5) = 40$；90°处，$30 + 20\cos(-30°) = 47.3$；180°处，$30 + 20\cos(-120°) = 20$；270°处，$30 + 20\cos(-210°) = 12.7$，单位均为次发放 s⁻¹。

(b)权重 $r - b$：$10$、$17.3$、$-10$、$-17.3$。$x$ 分量为 $10\cos0° + 17.3\cos90° - 10\cos180° - 17.3\cos270° = 10 + 0 + 10 + 0 = 20$。$y$ 分量为 $0 + 17.3 + 0 + 17.3 = 34.6$。方向为 $\arctan(34.6/20) = 60°$，恰为运动方向。

(c)真实的发放率逐次试验波动（大致服从泊松分布，[[neuroscience/neural-coding]]），调谐曲线不是完美的余弦，最佳方向也不均匀分布。只有四个神经元时，这些误差会造成很大的方向误差。对数百个神经元取平均可降低噪声（大致按神经元数的平方根），这正是 Georgopoulos 的群体向量——由逐 cell 记录数百个细胞构建——能把运动方向预测到几度以内的原因。
:::
:::

运动的群体编码在2000年代变得可行：植入运动皮层的微电极阵列能同时记录数百个神经元。基于群体活动的解码器使猴——后来还有参加临床研究、全身瘫痪的人——能够直接用皮层活动控制电脑光标和机械臂。后来的工作还表明，M1 并不只是一张运动方向的地图：伸臂过程中其群体活动像一个动力系统那样演化，其中的旋转式模式最好被理解为在产生肌肉命令，而不是在表征运动的参数（Mark Churchland、Krishna Shenoy 与合作者，2012年）。

### 小脑

小脑包含人脑一半以上的神经元，几乎全是颗粒细胞，且回路规则得惊人。来自脊髓、脑干与皮层的苔藓纤维兴奋颗粒细胞；颗粒细胞的轴突即平行纤维，沿小脑叶片走行，接触许多浦肯野细胞扇形的树突，每个浦肯野细胞接受的多达约200,000个这样的突触。每个浦肯野细胞还接受一根来自脑干下橄榄核的**攀缘纤维**，它缠绕其树突并形成数百个突触；一次攀缘纤维冲动引起一个巨大的、全或无的“复杂锋电位”。浦肯野细胞是小脑皮层唯一的输出，为抑制性（GABA 能），作用于小脑深部核团。

小脑损伤并不引起瘫痪；它使运动笨拙、时机不准、幅度失当，并损害运动学习。1969年 David Marr、1971年 James Albus 提出小脑在学习：攀缘纤维携带误差信号，修饰同时活动的平行纤维突触。伊藤正夫（Masao Ito）与合作者在1982年证明，同时刺激平行纤维与攀缘纤维会在兔小脑产生平行纤维突触的**长时程抑制**。小脑常被比作一台学会预测运动命令的感觉后果、以便在误差发生之前修正命令的机器，一个**前向模型**。

::: example 前庭眼反射的适应 {#ex-vor}
头转动时，**前庭眼反射**（VOR）使眼球以同样大小的速度向相反方向转动，使外界图像稳定在视网膜上。其**增益**是眼速与头速之比。(a)视力正常者要得到稳定的图像，需要多大的增益？(b)一个人戴上使图像放大为2倍的眼镜。现在需要多大的增益？起初头转动时图像会怎样？(c)戴镜数日之后，增益发生改变。需要脑的哪个部分？误差信号是什么？
::: solution
(a)增益为1（眼速与头速等大反向）。

(b)透过放大透镜，图像掠过视网膜的速度是头速的两倍，所以眼必须两快地反转，即需要增益2。起初 VOR 的增益仍是1，图像沿头动方向在视网膜上滑动，世界看起来像在晃动。

(c)小脑（绒球及其邻近区域，连同脑干前庭核）。误差信号是**视网膜像滑移**，经下橄榄核的攀缘纤维传入小脑。在人、猴、猫、兔进行的放大棱镜与反转棱镜实验表明，增益在数小时到数天内适应，而损毁绒球会阻止这种适应。人们认为习得的改变部分储存在小脑皮层、部分储存在脑干。
:::
:::

### 基底神经节

基底神经节是皮层下方一组相互连接的核团：**纹状体**（尾状核与壳核）、**苍白球**、**底丘脑核**与**黑质**。其输出核团——苍白球内侧部与黑质网状部——是抑制性的且紧张性地活动，持续抑制它们在丘脑与脑干的靶。在经典模型中：

- **直接通路**，从携带 D1 多巴胺受体的纹状体神经元直接投往输出核团，抑制输出核团，把丘脑从抑制中释放出来，从而促进一次运动（去抑制）；
- **间接通路**，从携带 D2 受体的纹状体神经元经苍白球外侧部与底丘脑核，增加输出核团的抑制，压制运动；
- 来自黑质致密部的**多巴胺**兴奋直接通路、抑制间接通路，因此多巴胺有利于运动。

人们认为这一回路在相互竞争的行为之间作出选择：释放选中的那个，压制其余的；多巴胺信号还教导纹状体哪些行为带来奖赏（[[neuroscience/plasticity-learning]]）。经典模型是一种简化：两条通路相互作用、在运动时共同活动，且包含反馈环路。多巴胺神经元的丧失是帕金森病的标志，表现为启动运动困难；它以及基底神经节的其他临床疾病见[医学图谱：运动障碍](/learn/medicine/lesson.php?c=nervous-system&l=movement-disorders)。

## 传出副本

转动眼球时，视网膜上的图像扫过视网膜，世界却显得静止。隔着眼睑轻压眼球侧面，世界却会跳动。两者的区别在于：前一种情况下，脑知道眼球是被命令运动的。

1950年，Erich von Holst 与 Horst Mittelstaedt 研究食蚜蝇 *Eristalis*，Roger Sperry 研究眼球被手术旋转180°的鱼，各自独立提出：神经系统发出运动命令的同时，也把该命令的一份副本送往感觉中枢，使后者能够减去动物自身运动的预期感觉后果。von Holst 与 Mittelstaedt 称之为**传出副本**；Sperry 称之为**伴随放电**。在 von Holst 与 Mittelstaedt 的实验中，头部被旋转180°使左右眼互换的苍蝇不停地转圈：每一次自身产生的转动都产生被误解为外界扰动、要求进一步朝同一方向转动的视觉运动。

伴随放电在许多动物中都有发现。鸣唱的雄蟋蟀发出的声音足以震聋自己的耳朵；一枚携带伴随放电的中间神经元随每一声鸣叫抑制其听觉通路，使它在两声之间保持对其他蟋蟀声音的敏感（James Poulet 与 Berthold Hedwig，2006年）。弱电鱼利用一个小脑样结构中习得的“负性图像”，抵消自身放电的电信号。这一原则把前向模型的思想推广开来：要行动得好，神经系统必须预测自己行动的后果。

::: application 恢复运动
理解运动回路有实际用途。腰段脊髓的硬膜外电刺激，按行走的时相定时，激活脊髓行走回路，结合训练，已在临床研究中使一些慢性脊髓损伤的患者能够站立并迈步。脑-机接口从运动皮层的群体活动解码意图中的运动。截至2026年，两者都还是处于临床评价中的研究性应用；脊髓损伤与神经系统疾病的临床管理归[医学图谱：神经系统](/learn/medicine/course.php?c=nervous-system)。
:::

::: history
查尔斯·贝尔（Charles Bell）与弗朗索瓦·马让迪（François Magendie）在1810与1820年代确立脊髓的腹根主运动、背根主感觉。谢灵顿的《神经系统的综合作用》（*The Integrative Action of the Nervous System*，1906年）分析了反射、交互神经支配与最后公路；他与阿德里安分享1932年诺贝尔奖。Graham Brown 在1911与1914年提出半中枢模型。Fritsch 与 Hitzig 在1870年定位了运动皮层。Liddell 与谢灵顿在1924年描述了牵张反射，Lloyd 在1943年证明了其单突触通路。亨内曼在1957年陈述了大小原则。von Holst 与 Mittelstaedt、斯佩里在1950年提出了传出副本。Wilson 对蝗虫飞行的研究（1961年）、Grillner 对七鳃鳗的研究与 Marder 对口胃神经节的研究，在随后的几十年里确立了 CPG 概念。Marr（1969年）与 Albus（1971年）提出了小脑学习理论；Georgopoulos 与合作者在猴运动皮层描述了方向调谐（1982年）与群体向量（1986年）。
:::

## 由此引向何处

这些回路在发育过程中如何建成——运动神经元如何找到自己的肌肉、反射连接如何以正确的特异性形成——是[[neuroscience/neural-development]]的一部分。运动技能如何学习，在小脑与基底神经节中，见[[neuroscience/plasticity-learning]]。行为整体如何组织，是[[behaviour/mechanisms-of-behaviour]]的主题。

::: summary
- 运动单位（一个运动神经元及其肌纤维）是力量的单位；神经支配比从每神经元约十条到一千条以上肌纤维不等。
- 力量经频率编码分级（单收缩叠加为不完全强直、继而完全强直），并经募集分级，募集遵循大小原则（亨内曼）：小的、慢的、抗疲劳的单位先被募集，因为小的运动神经元输入电阻高。
- 肌梭（Ia、II 类传入纤维；γ运动神经元）报告长度及其变化率；高尔基腱器官（Ib 类）报告力量。牵张反射是单突触的，对拮抗肌有交互抑制；回缩与交叉伸展反射是多突触的。反射增益受任务与相位调节。
- 中枢模式发生器无需节律性输入即产生节律性输出，机制有起搏神经元、半中枢振荡器或网络；它们表现为极限环。许多组参数给出同一节律。
- 运动皮层神经元对运动方向调谐很宽；群体活动（群体向量以及现代动力学模型）指明运动。
- 小脑校准运动并从攀缘纤维误差信号中学习；基底神经节经去抑制选择行为，多巴胺有利于直接通路。
- 传出副本（伴随放电）让感觉系统抵消自身运动的后果。
:::

::: exercise 神经元不等的群体向量 {level=2}
两个神经元的最佳方向为0°与90°，基线均为20次发放 s⁻¹，调制深度分别为10与30次发放 s⁻¹。一次运动移向45°。(a)计算它们的发放率与群体向量的方向。(b)解释这一误差，并设想如何校正。
::: solution
(a)发放率：$20 + 10\cos45° = 27.1$ 与 $20 + 30\cos45° = 41.2$。权重$7.1$ 与 $21.2$；向量为 $(7.1, 21.2)$，方向 $\arctan(21.2/7.1) = 71.5°$，不是45°。(b)群体向量假定调制深度相等；调制更强的神经元会把估计拉向自己的最佳方向。把每个权重除以该神经元的调制深度，$(r - b)/k$，得到 $(0.707, 0.707)$ 与正确的45°。更好的做法是，最优线性估计或最大似然这类解码器会考虑每个神经元的调谐与变异性（[[neuroscience/neural-coding]]）。
:::
:::

::: exercise 解读一项去传入实验 {level=2}
水蛭的离体神经系统浸泡在5-羟色胺中，运动神经显示出爆发：背侧与腹侧肌肉的运动神经元之间以约1 s 的周期交替，各体节间的相位延迟使一道波会从头部传向尾部。(a)这表明什么？(b)在完整动物中，游泳周期更短并会适应水阻。这表明什么？(c)用什么实验检验某个中间神经元是否属于 CPG？
::: solution
(a)游泳节律及其节段间协调由中枢产生：虚拟游泳在没有感觉反馈、没有运动的情况下发生。(b)完整动物中，来自体壁的感觉反馈（牵张感受器）以及可能的下行输入调节节律；CPG 不是故事的全部。(c)在虚拟游泳期间记录该神经元，看它是否按稳定相位节律性发放；然后加以扰动，在一个周期内注入短促电流脉冲。如果使其去极化或超极化能重置节律的相位（移动后续的爆发）而不只是改变某一个周期，它就是节律产生回路的一部分。将其删除（光照毁损或超极化）并观察节律的丧失或改变，可进一步提供证据。
:::

::: exercise 牵张反射的得与失 {level=2}
牵张反射对肌肉长度起负反馈回路的作用。用[[animal-physiology/homeostasis]]的比例控制模型，解释(a)为什么单靠牵张反射不能把肢体在负荷下精确保持在一个设定位置；(b)考虑到回路传导延迟20–40 ms，为什么过高的反射增益可能有害；(c)神经系统如何应对。
::: solution
(a)比例控制器留下稳态误差 $D/(1 + G)$；因此负荷（扰动）总会把肌肉拉长一点，反射减小但不消除位移。(b)在带延迟的回路中，高增益引起过冲与振荡，因为纠正依据的是过时信息；在肢体上，过高的牵张反射增益会产生震颤（一种与回路延迟相关的频率的振荡）。(c)反射增益保持适中并按任务调节；脑使用前馈控制，预测负荷并提前设定肌肉力量（提起物体时抓握的预期性收紧）；拮抗肌共收缩使关节机械性变硬，没有延迟；潜伏期更长的经皮层反射较慢但更灵活，补上任务特异的校正。
:::

::: exercise 一个有多种解的回路 {level=3}
在口胃神经节中，某个神经元两种 K⁺ 电流的最大电导在动物之间相差三倍，其放电模式却非常相似。(a)解释这怎么可能。(b)这对以下尝试有何含义：从单个动物测得的参数、或从“平均”动物推断回路功能？(c)设想一种在参数可变时维持正确输出的机制。
::: solution
(a)多种电导可以相互补偿：放电模式取决于组合（例如 certain 电压下内向与外向电流的平衡），而不取决于单个电导，所以许多参数组合落在同一条输出等价的“解流形”上。实验显示，那些可变电导在动物之间往往是相关的，与补偿相符。(b)用平均参数构建的模型可能失败，因为若解区域是弯曲的，几个好解的平均本身未必是好解。必须把每个动物理解为可接受构型空间中的一个点。(c)通道表达的活动依赖性自稳态调节：神经元或许感知自身的平均 Ca²⁺ 进入量（放电的替代指标），并调节其通道基因的转录，直到达到目标活动水平。这类模型（Marder、LeMasson 与 Abbott）恰好产生观察到的那种补偿性的相关变异。
:::

::: exercise 募集与精确度 {level=3}
一块肌肉有100个运动单位，其单收缩力按几何级数递增，第 $i$ 个单位产生力量 $F_0\,c^{\,i-1}$，$c$ 的选取使最大单位是最小单位的100倍。(a)求 $c$。(b)单位按顺序募集。第 $i$ 个单位募集时，总力量的增量就是该单位的力量。证明增量占已有总力量的比例在大 $i$ 时大致恒定，并估算该值。(c)把结果与韦伯定律和大小原则联系起来。
::: hint
前 $i - 1$ 个单位的总力量是一个几何级数。
:::
::: solution
(a)$c^{99} = 100$，故 $c = 100^{1/99} = \mathrm{e}^{\ln100/99} = \mathrm{e}^{0.0465} = 1.048$。

(b)前 $i - 1$ 个单位的力量为 $F_0(c^{i-1} - 1)/(c - 1)$。下一个单位加上 $F_0c^{i-1}$。比值为 $c^{i-1}(c - 1)/(c^{i-1} - 1)$，在大 $i$（$c^{i-1} \gg 1$）时趋于 $c - 1 = 0.048$，约5 %。例如 $i = 80$ 时，$c^{79} = 39.4$，比值为 $39.4\times0.048/38.4 = 0.049$。

(c)每次募集使力量增加一个几乎恒定的比例：绝对增量随力量增大，而相对增量保持恒定，这是运动分辨率的类韦伯定律标度。因为大小原则按从小到大的顺序募集单位，小力量由小单位分级、大力量由大单位分级，力量控制在低力量与高力量下的相对精确度相近。频率编码在募集台阶之间填补空隙。实测表明，许多肌肉的运动单位力量分布确实是偏斜的：小的多，大的少。
:::
