1953年，一位27岁的男子在康涅狄格州哈特福德接受了一次手术，以缓解严重的癫痫；在此后的一生中，科学文献里他只以 H.M. 为人所知（Henry Molaison，他的真名在其2008年去世之后才得以发表）。外科医生威廉·斯科维尔（William Scoville）切除了两侧颞叶的内侧部分，包括每侧海马的大部分。发作变得少些了，但 H.M. 再也无法为新的事实或事件形成持久的记忆。他能进行交谈，也能靠复述把一串数字记在脑中，可一旦被打断，几分钟后他就忘了这场谈话、也忘了刚才与他说话的人。他的智力、语言和童年记忆则基本完好。布兰达·米尔纳（Brenda Milner）研究了他数十年，发现他仍然能够学习新技能：三天之内，他就能透过一面镜子看着自己的手熟练地描画一颗星，却每天都否认自己做过这件事。

H.M. 表明记忆并不是一种东西，不同类型的记忆依赖于不同的脑系统。它们在细胞层面上有什么共同之处？引导神经科学一个多世纪的思想——由卡哈尔（Ramón y Cajal）提出雏形、经唐纳德·赫布（Donald Hebb）明确表述——是：学习改变突触的强度。本章将沿着这一思想，从它在海蛞蝓反射中最简单的形式讲起，讲到哺乳动物海马中的长时程增强、把突触改变与活动时间联系起来的规则、多巴胺承载的学习信号，以及脑的记忆系统。突触传递见[[neuroscience/synapses]]；从习惯化到认知的学习行为学研究见[[behaviour/learning-cognition]]。

## 学习与记忆的类型

::: definition 学习的形式 {#def-learning}
- **非联想学习**改变对单一类型刺激的反应。在**习惯化**中，对重复出现的无害刺激的反应减弱；在**敏感化**中，强烈或伤害性刺激会增强随后多种刺激引起的反应。
- **联想学习**把事件联系起来。在**经典（巴甫洛夫）条件作用**中，最初中性的**条件刺激**（CS）与生物学上重要的**非条件刺激**（US）配对之后，开始引发反应。在**操作性（工具性）条件作用**中，某一行为出现的概率随其后果而改变。
- **陈述性**（外显）记忆是对事实（语义记忆）与事件（情景记忆）的有意识回忆；在哺乳动物中它依赖于海马及其周围的内侧颞叶。**非陈述性**（内隐）记忆包括技能与习惯（纹状体、小脑）、启动效应（皮层）、简单的经典条件作用（小脑、杏仁核）以及非联想学习（反射通路）。
- **短时记忆**持续数秒到数分钟，不需要新的蛋白质合成；**长时记忆**持续数小时乃至终生，需要在习得后的**巩固**期内进行基因表达与蛋白质合成。
:::

H.M. 表现出的这种分离——技能学习完好而陈述性学习丧失——由斯科维尔与米尔纳于1957年、米尔纳于1962年发表，并在其他病人以及相同结构受损的动物中得到证实。形成新的陈述性记忆需要海马，但它似乎并不需要无限期地储存旧记忆，因为 H.M. 保留了手术很久以前的记忆。人们认为记忆会逐渐转移到新皮层，这一过程称为**系统巩固**。

## 赫布法则

加拿大心理学家唐纳德·赫布在《行为的组织》（*The Organization of Behavior*，1949年）中提出了经验得以塑造神经连接的一条规则。

::: definition 赫布法则 {#def-hebb}
“当一个细胞 A 的轴突与细胞 B 足够接近而能使其兴奋，并反复或持续地参与使其发放时，在两个细胞中的一个或两个中会发生某种生长过程或代谢变化，使 A 作为使 B 发放的细胞之一的效率得到提高。”其最简单的数学形式是：突触权重 $w$ 的改变正比于突触前活动 $x$ 与突触后活动 $y$ 之积：

$$
\Delta w = \eta\,x\,y,
$$ {#eq-hebb}

其中 $\eta$ 是一个小的学习率。
:::

赫布规则是**局域的**（它只利用突触处可获得的信息）、**联想的**（它依赖于两侧活动的巧合）、也是**无监督的**（没有教师告诉突触什么是正确的）。它能解释相关的输入如何驱动同一个神经元，例如眼优势柱的发育（[[neuroscience/neural-development]]），也能解释一群反复共同激活的神经元如何成为彼此紧密连接的**细胞集群**，从而从残缺的片段补全出整个模式。

纯粹的规则有一个缺陷：权重只能增长，而增长的权重提高突触后活动，进而又促进进一步的增长。真实的学习规则必须也能削弱突触或对突触进行归一化。芬兰数学家 Erkki Oja 在1982年给出了一个漂亮的解法：减去一个与突触后活动的平方成正比的衰减项，$\Delta w_i = \eta\,y\,(x_i - y\,w_i)$。在这条规则下，线性神经元的权重向量保持在单位长度，并转向其输入方差最大的方向，即第一**主成分**。经过归一化的赫布神经元能提取其输入中最显著的相关结构，而无需被告知该找什么。

```python
import math, random

# Oja's rule: a single linear neuron y = w . x learning from correlated inputs.
random.seed(1)
eta = 0.002                      # learning rate
w = [0.3, -0.8]                  # initial synaptic weights (arbitrary)

def sample():
    """Two inputs with correlation 0.8 and unit variance (zero mean)."""
    a, b = random.gauss(0, 1), random.gauss(0, 1)
    return [a, 0.8 * a + 0.6 * b]

for step in range(50000):
    x = sample()
    y = w[0] * x[0] + w[1] * x[1]                # postsynaptic activity
    for i in range(2):                           # Hebbian term minus decay
        w[i] += eta * y * (x[i] - y * w[i])

norm = math.hypot(w[0], w[1])
angle = math.degrees(math.atan2(w[1], w[0])) % 180     # an axis: sign does not matter
print(f"|w| = {norm:.3f}, direction = {angle:.1f} degrees")
# |w| = 1.000, direction = 45.3 degrees
# The principal axis of the input covariance [[1, 0.8], [0.8, 1]] lies at 45 degrees.
```

## 简单系统中的学习：*Aplysia*

为了寻找学习的细胞基础，埃里克·坎德尔（Eric Kandel）在1960年代转向海兔 *Aplysia californica*——一种大型海洋软体动物，约有20,000个神经元，其中许多体积大、带色素、能在不同个体之间逐一辨认。轻触它的喷水管，它便缩回喷水管和鳃；这一防御反射部分由约二十几个喷水管感觉神经元到六个鳃运动神经元之间的单突触联系以及中间神经元介导。这一反射表现出习惯化、敏感化与经典条件作用，而每一种都可追溯到已鉴定突触上的变化。

**习惯化。** 反复触碰喷水管使缩鳃反射变弱。Vincent Castellucci 与坎德尔在1974年利用感觉-运动突触的量子分析证明，其下的突触抑制是突触前的：每个冲动释放的量子减少，而量子大小与运动神经元的敏感性不变。

::: example 习惯化是突触前的吗？{#ex-habituation}
Castellucci 与坎德尔所测结果的示意数值：习惯化前，喷水管感觉神经元到鳃运动神经元的单突触 EPSP 平均幅度为10 mV，各次试验间的变异系数（CV）为0.22，运动神经元中的自发微小 EPSP 为0.5 mV。以10 s 间隔给予15次刺激后，EPSP 均值为2.5 mV，CV 为0.45，而微小电位仍为0.5 mV。(a)利用[[neuroscience/synapses#prop-quantal]]，分别由均值和 CV 估计习惯化前后的量子含量。(b)这种变化是突触前的还是突触后的？(c)两个估计相互一致为什么重要？
::: solution
(a)习惯化前：由均值，$m = 10/0.5 = 20$；由 CV，$m = 1/0.22^2 = 20.7$。习惯化后：由均值，$m = 2.5/0.5 = 5$；由 CV，$m = 1/0.45^2 = 4.9$。

(b)量子大小不变，所以突触对一个量子递质的反应（受体的数目与敏感性）没有改变；每个冲动释放的量子数降为原来的四分之一。这种抑制是突触前的。

(c)CV 法只利用试验间的波动，这种波动取决于释放的统计特性而与量子大小无关；均值法则依赖于实测的微小电位。两个彼此独立的方法给出同样的四分之一倍下降，使结果不太可能是任何一方的伪影，例如微小电位取自另一组突触的伪影。
:::
:::

**敏感化。** 尾部电击会增强随后触碰喷水管引起的缩鳃反射。尾部电击兴奋**促进性中间神经元**，后者向喷水管感觉神经元的终末释放5-羟色胺（5-HT）。5-羟色胺经 G 蛋白偶联受体升高 cAMP，进而激活蛋白激酶 A（PKA）。PKA 使 K⁺ 通道磷酸化、减小其电流，从而加宽感觉神经元动作电位的时程，让每个冲动有更多 Ca²⁺ 进入；PKA 与蛋白激酶 C 还更直接地作用于释放机器。于是每个冲动释放更多递质：**突触前易化**。

**长时程敏感化。** 单次尾部电击产生持续数分钟的敏感化；一小时内间隔给予四五次电击则产生持续数天的敏感化。长时程形式需要新的基因表达。在重复刺激下，PKA 进入感觉神经元的细胞核，磷酸化转录因子 **CREB**（cAMP 反应元件结合蛋白），开启生长新突触前终末所需基因的表达。在培养的感觉与运动神经元中，间隔施加五次5-羟色胺可产生持续一天以上的易化；而在训练期间施加蛋白质或 RNA 合成抑制剂会阻断这种长时程易化，却不影响短时程易化（Piergiorgio Montarolo、坎德尔、Samuel Schacher 与合作者，1986年）。人们发现长时程记忆涉及新突触连接的生长：在敏感化的动物中，感觉神经元终末的数目大约增加一倍（Craig Bailey 与 Mary Chen，1983年）。

**经典条件作用。** 若把弱的喷水管触碰（CS）与尾部电击（US）反复配对，触碰引起的反应将比电击不配对时增长得更多。在细胞水平上，当感觉神经元恰在5-羟色胺到达之前发放时，感觉神经元的易化被增强：其锋电位期间进入的 Ca²⁺ 增强被5-羟色胺激活的腺苷酸环化酶，使后者成为**符合检测器**（Robert Hawkins、坎德尔与合作者；Edgar Walters 与 John Byrne；均为1983年）。后来的工作表明，突触后的、类似 NMDA 受体的机制也有贡献。

坎德尔分享了2000年诺贝尔生理学或医学奖。*Aplysia* 的工作确立了广泛成立的三条原理：学习改变现有突触的强度；短时记忆利用现有蛋白质的共价修饰；长时记忆则需要基因表达、新的蛋白质合成与结构改变。同样的 cAMP–PKA–CREB 通路也被果蝇学习突变体的遗传筛选独立地揭示：突变体 *dunce* 与 *rutabaga* 在 Seymour Benzer 的实验室中分离得到，并经 Yadin Dudai、William Quinn 等人在1970年代研究，它们分别在 cAMP 磷酸二酯酶和 Ca²⁺/钙调蛋白激活的腺苷酸环化酶上存在缺陷。

## 长时程增强

1973年，蒂莫西·布利斯（Timothy Bliss）与 Terje Lømo 在奥斯陆 Per Andersen 的实验室中刺激麻醉家兔海马的主要传入通路——穿通通路，并记录齿状回颗粒细胞的反应。几串短暂的高频刺激（约100 Hz）使单个测试刺激引起的反应幅度出现持久增大，可持续数小时；在一项对清醒家兔的姊妹研究中则持续数天到数周。他们称之为“长持久增强”；这个名字后来变成了**长时程增强**（LTP）。后来的多数工作使用大鼠与小鼠海马脑片中 CA3 到 CA1 的突触（谢弗侧支），在那里可以用细胞内与膜片钳记录研究 LTP。

::: definition 长时程增强及其性质 {#def-ltp}
**长时程增强**是短暂强烈或互相关联的活动所产生的突触强度的持久增高。在 CA1 突触，它表现出三条性质：

- **输入特异性**：只有诱导期间活动过的突触被增强，同一细胞上的其他突触不受影响；
- **协同性**：诱导需要足够多的输入共同活动，使突触后细胞充分去极化；只刺激少数纤维的弱刺激不能诱导；
- **关联性**：与同一细胞上的强输入同时活动的弱输入会被增强，尽管它单独不会。

**长时程抑制**（LTD）是其反面，即突触强度的持久降低；在 CA1 突触，它可由延长的低频刺激（约1 Hz 持续15分钟；Serena Dudek 与 Mark Bear，1992年）诱导。
:::

这三条性质正是一个赫布突触所需：改变只发生在活动过的突触上（特异性），且只有当突触后细胞被强烈激活时才发生（协同性），并把同时发生的事件联系起来（关联性）。三者共同的分子基础是一种受体。

### 作为符合检测器的 NMDA 受体

CA1 突触处的谷氨酸作用于两类离子型受体。**AMPA 受体**承担普通传递中的大部分电流。**NMDA 受体**（以选择性激动剂 *N*-甲基-D-天冬氨酸命名）有两个显著特性：其通道除 Na⁺ 与 K⁺ 外对 Ca²⁺ 也通透；而在静息电位下，它被胞外 Mg²⁺ 离子嵌在孔道内所阻断。Linda Nowak、Philippe Ascher 与合作者，以及 Mark Mayer、Gary Westbrook 与 Peter Guthrie，在1984年发现了这种电压依赖的 Mg²⁺ 阻断。去极化会把 Mg²⁺ 驱出孔道。

::: proposition NMDA 受体 Mg²⁺ 阻断的电压依赖性 {#prop-mg}
NMDA 受体电导中不被 Mg²⁺ 阻断的比例，可由如下经验关系很好地描述（Craig Jahr 与 Charles Stevens，1990年，来自培养的大鼠海马神经元）

$$
B(V) = \frac{1}{1 + \dfrac{[\mathrm{Mg^{2+}}]_\mathrm{o}}{3.57\ \mathrm{mmol\,L^{-1}}}\,\mathrm{e}^{-0.062V}},
$$ {#eq-mg}

其中 $V$ 以 mV 计。NMDA 电流为 $I_\mathrm{NMDA} = g_\mathrm{NMDA}\,B(V)\,(V - E_\mathrm{NMDA})$，其中 $E_\mathrm{NMDA} \approx 0$ mV。这是一个拟合的描述，与一个在孔道内的结合依赖于膜电场的阻断离子相符；这些常数随受体亚基和温度略有变化。
:::

因此，只有两个条件同时满足时该受体才通过电流（以及 Ca²⁺）：谷氨酸已结合（突触前细胞已发放），且突触后膜已去极化（突触后细胞强烈活动）。这正是赫布规则的逻辑，被写进了一个分子。用拮抗剂 AP5（2-氨基-5-膦酰基戊酸）阻断 NMDA 受体，可在不影响普通传递的前提下阻止 CA1 突触 LTP 的诱导（Graham Collingridge 与合作者，1983年）。

:::

::: example NMDA 受体的符合检测 {#ex-mg}
胞外 Mg²⁺ 为1 mmol L⁻¹ 时：(a)计算−70 mV 与−20 mV 处的 $B(V)$。(b)某一突触打开了1 nS 的 NMDA 电导（$E_\mathrm{NMDA} = 0$ mV）。每个电压下的 NMDA 电流是多少？(c)解释为什么把突触前刺激与突触后去极化配对能诱导 LTP，而单独任一项都不能。
::: solution
(a)在−70 mV：$\mathrm{e}^{4.34} = 76.7$，故 $B = 1/(1 + 76.7/3.57) = 1/22.5 = 0.044$。在−20 mV：$\mathrm{e}^{1.24} = 3.46$，故 $B = 1/(1 + 0.968) = 0.51$。

(b)$I = g\,B\,(V - 0)$：在−70 mV，$1\times0.044\times(-70) = -3.1$ pA；在−20 mV，$1\times0.51\times(-20) = -10.2$ pA。尽管驱动力在−20 mV 更小，内向电流却大逾三倍，而作为其固定比例的 Ca²⁺ 内流也相应升高。电导的开放比例大了十一倍以上。

(c)单独的突触前刺激会释放谷氨酸，但在静息电位下 NMDA 通道几乎完全被阻断，进入的 Ca²⁺ 很少。单独的突触后去极化解除了阻断，却没有谷氨酸结合。只有两者同时发生，树突棘中才会出现大的 Ca²⁺ 信号，而这个 Ca²⁺ 触发 LTP。强直刺激之所以实现了配对，是因为许多共同活动的突触使细胞去极化（协同性），而与强输入配对的弱输入则受益于强输入引起的去极化（关联性）。输入特异性源于 Ca²⁺ 信号局限于那些 NMDA 受体结合了谷氨酸的树突棘。
:::
:::

### 表达：改变了什么？

树突棘内 Ca²⁺ 的升高激活 Ca²⁺/钙调蛋白依赖性蛋白激酶 II（**CaMKII**），它在突触后致密区含量丰富。CaMKII 能使自身磷酸化；一旦自磷酸化，它在 Ca²⁺ 回落之后仍保持活跃——这一性质使 John Lisman 提出它是分子记忆开关。携带阻止这种自磷酸化的点突变（Thr286 变为丙氨酸）的小鼠表现出 LTP 与空间学习受损（Karl Peter Giese、Alcino Silva 与合作者，1998年）。它的主要作用是增加突触处 **AMPA 受体**的数目与电导——通过使 AMPA 受体磷酸化，并驱动额外的受体从胞内储存库插入。幼年动物的某些突触含有 NMDA 受体却没有功能性 AMPA 受体：静息时它们是**静默的**，而 LTP 通过添加 AMPA 受体使其不再静默。

LTP 的早期阶段持续一两个小时，只需要对现有蛋白质进行这些修饰。由重复强直刺激诱导的晚期阶段需要转录与新的蛋白质合成，涉及 CREB 依赖的基因表达（如在 *Aplysia* 中一样），并伴随结构改变：当以能诱导 LTP 的模式经笼锁化合物光解向单个树突棘释放谷氨酸时，该棘在数分钟内增大，且增大持续数小时（Masanori Matsuzaki、Haruo Kasai 与合作者，2004年）。由更小幅、更持续的 Ca²⁺ 升高诱导的 LTD 则涉及磷酸酶与 AMPA 受体的移除。因此，Ca²⁺ 信号的水平与时间进程决定了改变的方向。

::: intuition 滑动的阈值
为什么大的 Ca²⁺ 升高强化突触，而适度的 Ca²⁺ 升高削弱突触？Elie Bienenstock、Leon Cooper 与 Paul Munro 在1982年从视觉皮层发育的理论研究中提出：突触的改变是突触后活动 $y$ 的函数 $\phi(y)$，在阈值 $\theta$ 以下为负、以上为正；而阈值本身在神经元非常活跃时升高、在其安静时下降。**BCM 规则**使学习趋于稳定：一个过于活跃的神经元变得更难被增强、更容易被抑制，反之亦然。对活动的双向依赖与滑动阈值后来都在视觉皮层和海马中被实验发现。
:::

## 脉冲时序

赫布写道 A 必须参与使 B 发放，这蕴含着因果：A 应恰好在 B 之前发放。1997年，Henry Markram、Bert Sakmann 与合作者在大鼠皮层脑片中记录相互连接的锥体神经元对，证明顺序重要。当突触前峰电位先于突触后峰电位约10 ms 时，反复配对强化突触；顺序颠倒时则削弱突触。毕国强（Guo-qiang Bi）与蒲慕明（Mu-ming Poo，1998年）在培养的大鼠海马神经元中绘制了对时序的依赖，发现了一个尖锐的时间窗：突触前峰电位先于突触后峰电位至多约20 ms 时增强，突触前峰电位晚于突触后峰电位至多约20 ms 时抑制，而在约±40–50 ms 之外几乎没有变化。

::: definition 脉冲时序依赖可塑性 {#def-stdp}
在**脉冲时序依赖可塑性**（STDP）中，一对突触前与突触后峰电位所产生的突触权重改变取决于它们的时间差 $\Delta t = t_\mathrm{post} - t_\mathrm{pre}$。一种常见的描述是

$$
\Delta w(\Delta t) = \begin{cases} A_+\,\mathrm{e}^{-\Delta t/\tau_+}, & \Delta t > 0 \ \text{（前先于后：增强）},\\ -A_-\,\mathrm{e}^{\Delta t/\tau_-}, & \Delta t < 0 \ \text{（后先于前：抑制）}, \end{cases}
$$ {#eq-stdp}

时间常数 $\tau_\pm$ 约为10–30 ms。幅度与时间常数、乃至窗口的符号，都因突触类型而异；这一指数形式只是对特定数据集的拟合描述。
:::

在细胞层面，时序规则由 NMDA 受体导出。恰好在突触后峰电位之前到达的突触前峰电位，会在逆向传播的动作电位解除 Mg²⁺ 阻断的那一刻把谷氨酸留在 NMDA 受体上，于是产生大的 Ca²⁺ 信号。顺序相反时，逆向传播的峰电位先于谷氨酸到达，由此产生的 Ca²⁺ 升高较小且较晚，因而有利于抑制。

x: -100, 100
y: -1.2, 1.2
sliders: Ap=1:0:1.2:0.05; Am=1.05:0:1.2:0.05; tau=20:5:40:1

caption: [[#eq-stdp]]的 STDP 窗口：突触权重的改变（纵轴，相对单位）对峰电位时序 $\Delta t = t_\mathrm{post} - t_\mathrm{pre}$（横轴，ms）。零的右侧，先于突触后峰电位的突触前峰电位产生增强；左侧则产生抑制。$A_+$（Ap）与 $A_-$（Am）是两侧的幅度，$\tau$ 是两侧共同的时间常数。当 $A_-\tau$ 略超过 $A_+\tau$（默认值）时，不相关的峰电位对（在两侧出现的机会均等）产生净抑制，从而防止权重无限制地增长；可靠地领先于突触后峰电位的相关输入则被强化。
:::

::: example 由峰电位对累积可塑性 {#ex-stdp}
某突触遵循[[#eq-stdp]]，$A_+ = 0.010$，$A_- = 0.0105$，$\tau_\pm = 20$ ms，权重改变为初始权重的比例并可线性相加。(a)60个突触前峰电位先于突触后峰电位10 ms 的配对，改变是多少？(b)顺序颠倒的60个配对呢？(c)某输入相对于突触后细胞在随机时刻发放，使 $\Delta t$ 在−100到+100 ms 之间均匀分布。每对的期望改变是多少？
::: solution
(a)每对：$0.010\,\mathrm{e}^{-10/20} = 0.010\times0.607 = 0.0061$。60对：$0.36$，即增强36 %。

(b)每对：$-0.0105\times0.607 = -0.0064$；60对：$-0.38$，即降低38 %。

(c)期望改变是 $\Delta w$ 在均匀分布上的平均：$\frac{1}{200}\left[\int_0^{100}A_+\mathrm{e}^{-t/\tau}\dd t - \int_{-100}^0A_-\mathrm{e}^{t/\tau}\dd t\right] = \frac{\tau(1 - \mathrm{e}^{-5})}{200}(A_+ - A_-) = \frac{20\times0.993}{200}\times(-0.0005) = -5.0\times10^{-5}$，每对如此。不相关的输入会缓慢削弱；只有其峰电位可靠地先于突触后峰电位、从而有助使其发生的输入才被强化。STDP 于是按因果贡献选择输入，这是赫布规则的一个竞争版本。
:::
:::

## 从突触到记忆

LTP 真的储存记忆吗？仅仅指出两者都存在无法回答这个问题。理查德·莫里斯（Richard Morris）与合作者让大鼠在**水迷宫**中学习：一池不透明的水中藏着没入水下的平台，大鼠必须记住平台相对于房间周围线索的位置来找到它（莫里斯，1982年）。1986年他们证明，训练时在脑内输注 AP5 的大鼠学不会平台的位置，而它们的游泳能力与找到可见平台的能力不受影响；损害学习的剂量同时也阻断了海马 LTP。只敲除 CA1 锥体细胞 NMDA 受体 NR1 亚基的小鼠缺乏 CA1 LTP，并在空间学习上受损（Joe Tsien、利根川进与合作者，1996年）。

海马包含一种非凡的空间表征。约翰·奥基夫（John O'Keefe）与 Jonathan Dostrovsky 在1971年发现，大鼠海马中的许多神经元只在动物处于其环境的特定部分时发放，即该细胞的**位置野**；这些**位置细胞**作为一个群体共同构成一幅地图。2005年，梅-布里特·莫泽（May-Britt Moser）、爱德华·莫泽（Edvard Moser）与合作者发现，邻近的内侧内嗅皮层中的**网格细胞**在一个规则三角形点阵的各顶点发放，该点阵覆盖整个环境。奥基夫与莫泽夫妇分享了2014年诺贝尔奖。位置野在新环境中几分钟内即可形成，其长时程稳定性依赖于 NMDA 受体。探索之后的睡眠与安静休息期间，探索时发放过的位置细胞序列会以压缩的形式**重放**（Matthew Wilson 与 Bruce McNaughton，1994年），这被认为有助于巩固（[[neuroscience/neural-coding]]）。

关于特定神经元集合储存特定记忆的最直接证据来自光遗传学（[[neuroscience/neural-coding]]）。2012年，Xu Liu、Steve Ramirez、利根川进与合作者培育出这样的小鼠：其齿状回神经元若在学习事件期间活动，便被通道视紫红质标记。小鼠在某一箱室中接受轻度足底电击，从而标记当时活动过的神经元。之后，在另一间安全的箱室中，用光照射被标记的神经元会使小鼠僵立不动，仿佛回忆起了那个可怕的地方。这样的一组细胞被称为**记忆痕迹（engram）**细胞，这个词源于 Richard Semon 于1904年引入的一个术语。

::: warning “LTP 就是记忆”与“记忆储存在单个神经元或突触中”
LTP 是一种细胞机制，具备记忆储存所需性质的许多条；而且有证据表明，在依赖海马的学习中使用了 LTP 或类似的东西，这一证据相当有力。但这一论断建立在多种证据之上，每一种都有需要注意之处：阻断 NMDA 受体同时也会阻断其他过程；遗传操作可能有发育效应；某些形式的学习能在 NMDA 阻断下保留。Stephen Martin、Paul Grimwood 与莫里斯（2000年）提出了一个机制必须满足的标准（可检测性、模拟、顺行性改变与逆行性改变），而没有任何单一实验能同时满足它们全部。同样，记忆也不储存在单个细胞或突触中：它们分布在许多神经元的大量突触上，每个神经元、每个突触都参与许多记忆。记忆痕迹细胞是网络中必不可少的组成部分，而不是微型储物盒。
:::

## 从错误中学习：预测与多巴胺

巴甫洛夫的条件作用看似简单：把 CS 与 US 配对，CS 就获得引发反应的能力。但1968年 Leon Kamin 发现，仅有配对并不够。先训练大鼠学会声音预测电击，再用声音与灯光的复合刺激预测同一电击进行训练，大鼠对灯光一无所学。声音已经预测了电击，灯光没有增添任何信息：对灯光的学习被**阻断**了。Robert Rescorla 与 Allan Wagner 在1972年提出：动物只在事件出人意料时才学习。

::: proposition Rescorla–Wagner 规则 {#prop-rw}
设 $V_i$ 为刺激 $i$ 的联想强度，$\lambda$ 为 US 所能支撑的最大强度（没有 US 的试验上 $\lambda = 0$）。在一组刺激同时出现的每次试验上，每个在场刺激 $i$ 的强度改变为

$$
\Delta V_i = \alpha_i\beta\left(\lambda - \sum_{j\ \text{present}}V_j\right),
$$ {#eq-rw}

其中 $\alpha_i$ 与 $\beta$ 是 CS 与 US 的学习率参数。方括号中的项是**预测误差**：实际发生之事与被预测之事之差。对于从 $V_0 = 0$ 起、$k = \alpha\beta$ 恒定的单一刺激，

$$
V_n = \lambda\left[1 - (1 - k)^n\right].
$$ {#eq-rw-curve}

该规则是行为数据的模型，不是从神经机制导出的；它能解释习得、消退、阻断与遮隐，但不能解释例如消退后的反应为何会自发恢复。
:::

::: proof
对单一刺激，[[#eq-rw]]给出 $V_{n+1} = V_n + k(\lambda - V_n)$，于是 $\lambda - V_{n+1} = (1 - k)(\lambda - V_n)$。误差每试验缩小为 $(1 - k)$ 倍，所以 $\lambda - V_n = (1 - k)^n(\lambda - V_0) = (1 - k)^n\lambda$，即得[[#eq-rw-curve]]。
:::

::: widget plot
f: L*(1 - (1 - k)^x); if(x < 10, L*(1 - (1 - k)^x), L*(1 - (1 - k)^10)*(1 - k)^(x - 10))
x: 0, 30
y: 0, 1.05
sliders: k=0.2:0.05:0.6:0.01; L=1:0.2:1:0.05
labels: \text{持续习得}; \text{习得，第10次试验后转入消退}
vlines: 10
caption: Rescorla–Wagner 模型[[#eq-rw-curve]]中的联想强度 $V$（纵轴）对试验序号（横轴），学习率 $k = \alpha\beta$ 与渐近值 $\lambda$（L）由滑块设定。第一条曲线显示持续配对；第二条显示前十次试验配对（竖线），之后转入消退（$\lambda = 0$），此时预测误差为负，$V$ 按几何级数衰减。每次试验都把剩余误差减少同样的比例，所以学习在最初最快，随着预测变好而减慢。
:::

预测误差的神经对应物在中脑多巴胺神经元中被发现。Wolfram Schultz 与合作者记录了正在学习“灯光预示一滴果汁”的猴脑中这些神经元的活动。学习之前，果汁到达时神经元暴发簇发放。学习之后，它们在灯光处发放而不再在果汁处发放；而如果预期的果汁被取消，它们的发放会在果汁本应到达的时刻暂停。Schultz、Peter Dayan 与 Read Montague（1997年）指出，这正是**时序差分学习**的预测误差信号的行为——一种来自机器学习的算法，把 Rescorla–Wagner 规则推广到随时间展开的预测上。人们认为纹状体中释放的多巴胺充当教学信号：当结果好于预期时，它强化近期活动过的皮层-纹状体突触——这是一种结合突触前活动、突触后活动与神经调质信号的“三因子”学习规则。

::: example Rescorla–Wagner 模型中的阻断 {#ex-blocking}
设两个刺激的 $k = 0.2$，$\lambda = 1$：(a)A 与 US 配对10次试验后，从零开始的 $V_A$ 是多少？(b)随后 A 与 B 一起与 US 共同呈现10次试验。$V_B$ 增长多少？(c)对照组只从零开始接受这10次复合试验。结束时 $V_A$ 与 $V_B$ 各是多少？(d)把结果与多巴胺神经元的反应联系起来。
::: solution
(a)$V_A = 1 - 0.8^{10} = 1 - 0.107 = 0.893$。

(b)在每次复合试验上，两者各改变 $0.2(1 - V_A - V_B)$。第一次试验上，$\Delta V_B = 0.2\times0.107 = 0.021$。剩余误差 $e = 1 - V_A - V_B$ 按 $e_{n+1} = e_n - 2\times0.2\,e_n = 0.6\,e_n$ 演化，所以十次试验中 $V_B$ 的总改变为 $0.2\,e_0(1 + 0.6 + 0.6^2 + \cdots + 0.6^9) = 0.2\times0.107\times(1 - 0.6^{10})/0.4 = 0.053$。B 几乎被完全阻断。

(c)从零开始，$e_0 = 1$ 且 $e_n = 0.6^n$。每个刺激获得 $0.2(1 - 0.6^{10})/0.4 = 0.497$。两个刺激都以接近0.5收场：它们分担了预测（**遮隐（overshadowing）**，此处显著性相等）。

(d)对 A 训练之后，多巴胺神经元对 A 反应而不再对 US 反应：US 被完全预测，没有预测误差信号，因此对 B 一无所学。这就是 Kamin 洞见的神经版本；Waelti、Dickinson 与 Schultz（2001年）发现，猴脑中的多巴胺神经元确实不对被阻断的刺激作出反应。
:::

::: quiz
训练过的猴脑中一个多巴胺神经元在对果汁有预测作用的线索处发放。某次试验中，线索出现了，但果汁的量是平时的两倍。果汁到达时，该神经元最可能怎么做？
- [ ] 什么都不做，因为果汁已被线索预测。
- [x] 暴发簇发放，因为结果好于预测（正预测误差）。
- [ ] 暂停发放，因为结果与预测不同。
- [ ] 以与学习前相同的速率发放。
::: solution
多巴胺信号报告实际获得与预期奖赏之差。比预期更大的奖赏是正预测误差，以簇发放报告；比预期更小或被省略的奖赏是负误差，以暂停报告；与预期完全一致的奖赏不引起改变。改变奖赏大小与概率的实验已经证实了这种等级式的行为。
:::

::: application 记忆与疾病
许多神经与精神疾病都涉及本章的机制。阿尔茨海默病最早受累的脑区通常是内嗅皮层与海马，随之丧失的是新陈述性记忆的形成。滥用药物作用于多巴胺预测误差系统，并改变纹状体的突触。焦虑症的暴露疗法利用消退学习。临床方面见[医学图谱：痴呆与神经退行性疾病](/learn/medicine/lesson.php?c=nervous-system&l=dementia-neurodegeneration)与[医学图谱：物质使用](/learn/medicine/lesson.php?c=psychiatry&l=substance-use)。
:::

::: history
卡哈尔在1894年就提出学习可能强化神经元之间的联系，赫布则在1949年陈述了他的法则。斯科维尔与米尔纳在1957年描述了 H.M.。坎德尔与合作者于1960年代开始 *Aplysia* 的工作，在1970年代描述了习惯化与敏感化的细胞基础，在1980与1990年代描述了通向长时记忆的分子通路。布利斯与 Lømo 在1973年报告了 LTP。NMDA 受体的 Mg²⁺ 阻断发现于1984年；Collingridge（1983年）与莫里斯（1986年）把 NMDA 受体依赖的 LTP 与空间学习联系起来。奥基夫与 Dostrovsky 在1971年发现了位置细胞，莫泽夫妇在2005年发现了网格细胞。Rescorla 与 Wagner 在1972年发表了他们的规则；Schultz、Dayan 与 Montague 在1997年把多巴胺与预测误差联系起来。STDP 由 Markram 与合作者在1997年、毕国强与蒲慕明在1998年描述。2012年报告了记忆痕迹细胞的光遗传学重激活。
:::

## 由此引向何处

记忆由大规模神经元群体的活动模式承载，而这些模式既必须被写入，也必须被读出。[[neuroscience/neural-coding]]讨论信息如何表征在峰电位序列与群体之中，以及这样的活动如何被记录。学习行为学的一面——它的进化与生态用途——见[[behaviour/learning-cognition]]。

::: summary
- 学习分为非联想的（习惯化、敏感化）与联想的（经典、操作性）；记忆系统包括陈述性（海马）与非陈述性（纹状体、小脑、杏仁核、反射通路）；H.M. 证明了它们的分离。
- 赫布法则 $\Delta w = \eta xy$ 是局域的、联想的、无监督的；它需要归一化（Oja 规则提取主成分）或抑制才能保持稳定。
- 在 *Aplysia* 中，习惯化是突触前抑制；敏感化是经由 5-HT、cAMP 与 PKA 的突触前易化；长时记忆需要 CREB、蛋白质合成与新突触。
- LTP（布利斯与 Lømo，1973）具有输入特异性、协同性与关联性，因为 NMDA 受体需要谷氨酸与去极化两者共同解除其 Mg²⁺ 阻断；Ca²⁺ 激活 CaMKII 并添加 AMPA 受体；晚相 LTP 需要蛋白质合成与结构生长。LTD 与 BCM 规则补上了双向的、稳定的可塑性。
- STDP：约20 ms 内前先于后产生增强，后先于前产生抑制。
- 位置细胞、网格细胞、重放与记忆痕迹细胞把突触可塑性与空间记忆联系起来；确立 LTP 储存记忆需要多种证据。
- Rescorla–Wagner 规则 $\Delta V = \alpha\beta(\lambda - \sum V)$ 从预测误差中学习并解释了阻断；中脑多巴胺神经元报告奖赏预测误差。
:::

在 Rescorla–Wagner 模型中，$k = 0.2$、$\lambda = 1$，从零开始经过5次训练试验后 $V$ 是多少？保留三位小数。

::: exercise Mg²⁺ 阻断的解除 {level=1 check="0.023"}
用[[#eq-mg]]，当胞外 Mg²⁺ 为2 mmol L⁻¹ 时，−70 mV 处未被阻断的 NMDA 电导比例是多少？保留三位小数。
::: solution
$B = 1/(1 + (2/3.57)\mathrm{e}^{4.34}) = 1/(1 + 0.560\times76.7) = 1/43.97 = 0.023$。Mg²⁺ 加倍使静息时本已很小的未阻断比例大约减半。

::: exercise 学习类型的判断 {level=1}
判断下列各例属于习惯化、敏感化、经典条件作用还是操作性条件作用：(a)狗听到开罐头的声音就流口水；(b)地震之后，人一有小的响动就惊跳；(c)大鼠学会压杆获取食物；(d)反复敲击水箱时，螺停止缩回壳内。
::: solution
(a)经典条件作用（声音与食物配过对）。(b)敏感化（强刺激增强对其他许多刺激的反应）。(c)操作性条件作用（行为因其后果而增多）。(d)习惯化（重复出现的无害刺激引起递减的反应）。
:::

::: exercise LTP 的性质 {level=2}
在海马脑片中，两条彼此独立的通路 S1 与 S2 汇聚到同一批 CA1 神经元。预测下列各情况的结果，并说明涉及 LTP 的哪条性质：(a)以强直刺激强烈刺激 S1；(b)以100 Hz 弱刺激 S2，强度不足以明显使细胞去极化；(c)在强直刺激 S1 的同时弱刺激 S2；(d)在 AP5 存在时做情形(c)。
::: solution
(a)S1 被增强，S2 不被增强：输入特异性。(b)S2 没有 LTP：协同性，因为活动的纤维太少，不能充分使细胞去极化以解除 Mg²⁺ 阻断。(c)两者都被增强：关联性，S1 产生的去极化解除了那些同时在释放谷氨酸的 S2 突触处的阻断。(d)两者都不被增强，因为 AP5 阻断 NMDA 受体，从而阻止了诱导 LTP 的 Ca²⁺ 内流；由 AMPA 受体承担的基线传递不受影响。
:::
:::

::: exercise 长时程与短时程易化 {level=2}
在培养的 *Aplysia* 感觉与运动神经元中，施加一次5-羟色胺产生持续数分钟的易化；间隔施加五次产生持续24小时以上的易化。(a)预测在五次施加期间施加蛋白质合成抑制剂，对10分钟和24小时测得的易化分别有何影响。(b)预测向感觉神经元内注入能与 CREB 结合并将其扣留的寡核苷酸的效果。(c)24小时时你会寻找什么结构改变？
::: solution
(a)10分钟时的易化不受影响（它依赖现有蛋白质的共价修饰）；24小时时的易化被阻断（它需要新的蛋白质）。(b)长时程易化被阻断，因为需要 CREB 介导的转录；短时程易化不受影响（Dash、Hochner 与坎德尔在1990年做了这个实验）。(c)感觉神经元与运动神经元接触的突触前膨体（突触终末）数目增加；向感觉神经元内充注荧光染料即可对其成像。
:::
:::

::: exercise 解读一项水迷宫实验 {level=2}
在训练期间给予 NMDA 受体拮抗剂的大鼠，找到隐藏平台所需的时间远长于对照；在撤去平台的探索试验中，它们并不偏好性地搜索正确的象限。批评者认为，药物可能只是损害了视觉或游泳能力，或者使大鼠焦虑。(a)哪些对照实验能回应这些质疑？(b)如果先让大鼠在一个池子中不用药训练，再在新池子中用药训练，它们几乎正常地学会了新池子（Bannerman 与合作者，1995年）。这说明什么？
::: solution
(a)给用药大鼠做可见平台测试：这需要视觉、游泳与动机，而不需要空间记忆；若它们表现正常，感觉运动与动机方面的解释就难以成立。分别测量游泳速度与路径长度，并检测焦虑相关行为。证明该剂量阻断了海马 LTP，并且在学习之后给药不损害提取（以区分学习与提取）。(b)对任务先前的非空间经验（怎样游泳、有逃生平台这件事、如何搜索）似乎正是第一个实验中需要 NMDA 受体的部分；或者，在一般策略已知之后，海马也许能用 NMDA 依赖可塑性以外的机制学习新的空间布局。无论哪种，这一结果都提醒我们不要把 NMDA 阻断等同于空间记忆本身的阻断。
:::

::: exercise 赫布性生长及其控制 {level=3}
一个神经元接受两个活动为 $x_1$ 与 $x_2$ 的输入，响应为 $y = w_1x_1 + w_2x_2$。其权重按纯赫布规则 $\Delta w_i = \eta x_iy$ 改变。(a)证明：对均值为零、协方差矩阵为 $\mathbf C$ 的输入在许多次呈现上取平均后，权重向量按 $\Delta\mathbf w = \eta\,\mathbf C\mathbf w$ 改变。(b)为什么这会使权重无限增长？(c)取 $\mathbf C = \begin{pmatrix}1 & 0.8\\0.8 & 1\end{pmatrix}$，$\mathbf w$ 最终指向哪个方向？为什么 Oja 规则给出同样方向而长度有界？
::: solution
(a)$\Delta w_i = \eta x_i\sum_jw_jx_j$；取平均，$\langle\Delta w_i\rangle = \eta\sum_j\langle x_ix_j\rangle w_j = \eta(\mathbf C\mathbf w)_i$。

(b)$\mathbf C$ 半正定，所以 $\mathbf w\T\Delta\mathbf w = \eta\,\mathbf w\T\mathbf C\mathbf w \ge 0$：$\mathbf w$ 的长度平均意义上永不减小，且沿每个正特征值对应特征向量的分量按几何级数增长，特征值 $\mu$ 对应的每步增长因子为 $(1 + \eta\mu)$。

(c)$\mathbf C$ 的特征值为 $1.8$（特征向量 $(1, 1)/\sqrt2$，方向45°）与 $0.2$（特征向量 $(1, -1)/\sqrt2$）。沿第一个特征向量的分量增长更快，于是 $\mathbf w$ 转向45°轴，即第一主成分。Oja 规则加上 $-\eta y^2w_i$，它平均意义上减去 $\eta(\mathbf w\T\mathbf C\mathbf w)\mathbf w$；平衡时 $\mathbf C\mathbf w = (\mathbf w\T\mathbf C\mathbf w)\mathbf w$，这要求 $\mathbf w$ 是一个满足 $\lVert\mathbf w\rVert = 1$ 的特征向量，而只有主特征向量是稳定的。本章的程序给出了数值上的收敛。特征向量见[数学图谱：线性代数](/learn/maths/course.php?c=linear-algebra)。
:::
:::

::: exercise 时序差分学习 {level=3}
一只猴子在每次试验中都是：先看到灯光（时刻1），一步之后听到声音（时刻2），然后得到果汁（时刻3）。在时序差分学习中，各时刻的预测误差为 $\delta_t = r_t + V_{t+1} - V_t$，其中 $r_t$ 是时刻 $t$ 收到的奖赏，$V_t$ 是从时刻 $t$ 起对未来的预测值；价值按 $\Delta V_t = k\,\delta_t$ 更新。设灯光之前的时刻 $t = 0$ 的价值固定为0，因为灯光出现在不确定的时刻。(a)学习之前所有 $V = 0$。第一次试验的预测误差在哪里？(b)经过大量训练后，$V_1$、$V_2$ 与 $V_3$ 各是多少，预测误差在哪里？(c)这与 Schultz 的记录有何联系？
::: hint
训练之后，一次试验内时刻1、2、3的预测误差都为零；求使这一点成立的价值，注意试验结束后 $V_4 = 0$。
:::
::: solution
(a)所有价值为零时，唯一非零的误差在时刻3，$\delta_3 = r_3 = 1$（取奖赏为1）：多巴胺神经元在果汁处发放。

(b)平衡时 $\delta_3 = 1 + V_4 - V_3 = 0$ 给出 $V_3 = 1$；$\delta_2 = 0 + V_3 - V_2 = 0$ 给出 $V_2 = 1$；$\delta_1 = V_2 - V_1 = 0$ 给出 $V_1 = 1$。试验内的误差消失了，但在不可预测的灯光前期向试验的过渡处，$\delta_0 = 0 + V_1 - V_0 = 1$：误差移到了最早的可靠预测物——灯光——上。

(c)这正是 Schultz 观察到的模式：学习之前，多巴胺神经元在奖赏处簇发放；学习之后，它们在最早的有预测作用的线索处簇发放，而不在奖赏或中间的已被预测的线索处发放。若训练后取消果汁，则在预期时刻 $\delta_3 = 0 + 0 - 1 = -1$：发放暂停，与观察一致。
:::
