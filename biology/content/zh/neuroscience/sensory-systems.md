暗适应蟾蜍视网膜上的一个视杆细胞，对单个光子吸收的反应是约一个皮安的电流变化，在其噪声之上清晰可辨。内耳中的一个毛细胞对不足1纳米的纤毛束偏转就有反应——这比许多原子电子云的直径首尾相接还要小——而且响应之快在微秒之内。一只蛾能在空气中数以十亿计的其他分子之间，检出本种性信息素的几个分子。感觉器官是世界上最灵敏的探测器之列——无论天然的还是人造的——而它们都按同一大策略工作：一种专门的蛋白把物理或化学刺激转换成膜电导的变化，由此产生的电信号经突触传给提取要点的环路。

本章先讲感觉系统的一般原理——转导、感受器电位、适应、感受野以及强度与性质的编码——然后考察四种感觉：视觉、听觉、触觉，以及嗅觉与味觉这两种化学感觉。所用的工具来自前面各章：膜电位、动作电位与突触。刺激如何由动作电位序列编码、我们如何读取这类编码，在[[neuroscience/neural-coding]]中进一步展开；人类感觉的临床检查属于[医学图谱：感觉系统](/learn/medicine/lesson.php?c=nervous-system&l=sensory-systems)。

## 一般原理

### 转导与感受器电位

::: definition 感受器转导与感受器电位 {#def-transduction}
**感受器转导**是刺激（光、机械力、温度、化学品）由**感受器**——一种特化的神经元或上皮细胞——转换为电信号的过程。刺激作用于一种**转导蛋白**：或者是被直接门控的离子通道（机械门控、温度门控或配体门控通道），要么是通过胞内级联打开或关闭通道的受体（G 蛋白偶联受体）。由此产生的膜电位分级变化就是**感受器电位**。在有轴突的感受器，感受器电位在邻近的锋电位起始区触发动作电位；在没有轴突的感受器——如脊椎动物的感光细胞和毛细胞——它调节对第二神经元的递质释放。
:::

两种转导策略在各感觉中反复出现。**直接门控**很快，因为没有中间环节，用在时间要紧之处：毛细胞与触觉感受器使用机械门控通道，昆虫的嗅觉受体本身就是离子通道。**代谢型级联**较慢，但提供巨大的放大，因为每个被激活的受体可以激活许多 G 蛋白，每个 G 蛋白又驱动一种酶生成或销毁许多第二信使分子。必须探测单个光子或极少分子的脊椎动物感光细胞与嗅觉神经元，使用的就是级联。

### 强度、性质与标记线

感觉系统必须报告刺激的两件事：是什么性质，有多强。**性质**（红与绿、甜与苦、音调的高低）主要由*哪些*受体与神经纤维在活动来编码。约翰内斯·缪勒的**神经特殊能力学说**（1838年）是这样表述的：一条神经产生的感觉取决于神经本身，而不取决于它如何被刺激。按压闭合的眼睛产生的是光而非压力，因为视神经从来只报告光。用现代的话说，每条感觉纤维都是一条**标记线**，其活动被脑作固定的解释。

**强度**由感受器电位的大小、感觉纤维的发放率（埃德加·阿德里安1926年在蛙单个牵张感受器上记录时的发现）、以及被募集的纤维数目来编码。由于发放率的范围是从近零到每秒几百个冲动，而自然刺激横跨许多数量级，感觉系统必须压缩强度。

::: definition 韦伯定律与韦伯分数 {#def-weber}
**最小可觉差**（JND）$\Delta I$ 是能可靠探出的、强度为 $I$ 的刺激的最小改变。**韦伯定律**（恩斯特·海因里希·韦伯，1834年）指出：在强度的一段宽的中间范围内，JND 是强度的一个恒定分数：

$$
\frac{\Delta I}{I} = k,
$$

其中 $k$ 是**韦伯分数**。这是一条经验规律，不是自然定律；它在接近绝对阈值的低强度处失效，有时在极高强度处也失效。
:::

韦伯分数对于举重大约是0.02，对于背景衬托下光的亮度约0.01–0.02，对于声音的响度约0.1，尽管数值随条件而异。物理学家古斯塔夫·费希纳用韦伯定律建立了一把感觉的标尺。

::: proposition 费希纳的对数标尺 {#prop-fechner}
若韦伯定律以分数 $k$ 从绝对阈值 $I_0$ 向上成立，则 $I_0$ 与强度 $I$ 之间最小可觉台阶的数目为

$$
n = \frac{\ln(I/I_0)}{\ln(1 + k)} \approx \frac{1}{k}\ln\frac{I}{I_0},
$$ {#eq-fechner}

于是若把每个 JND 取作相等的感觉增量，感觉就随强度的对数增长（费希纳，1860年）。假设：韦伯定律在全范围内成立；以及一个无法仅凭辨别数据检验的假说——一切 JND 都是相等的感觉台阶。
:::

::: proof
从 $I_0$ 出发，每一步把强度乘以 $1 + k$，所以 $n$ 步后强度为 $I_0(1 + k)^n$。令其等于 $I$ 并取对数，得 $n\ln(1 + k) = \ln(I/I_0)$。$k$ 小时 $\ln(1 + k) \approx k$。
:::

斯坦利·史蒂文斯在1950年代向费希纳提出挑战：他让人直接给感觉的大小赋数。他发现感觉 $S$ 随强度按**幂**增长，$S = cI^b$（**史蒂文斯幂定律**），指数因感觉而异：暗中看光的亮度约0.33，纯音的响度约0.67，视长度约1，手指电击的强度约3.5。指数小于1意味着压缩：光的强度加倍，看起来只亮约26 %（$2^{0.33} = 1.26$）；指数大于1意味着扩张：电击电流加倍，感觉约强11倍。费希纳定律与史蒂文斯定律都是经验描述，哪一个更好地描述“感觉”取决于测量方法。

::: example 数最小可觉差 {#ex-jnd}
某人能分辨相差2 %的举起重量。(a)与250 g 的重量相比，能探出的最小相差是多少？(b)用 [[#eq-fechner]]，10 g 与10 kg 之间大约有多少个可分辨的台阶？(c)为什么这个数高估了实践中真正能区分的重量数目？
::: solution
(a) $\Delta I = 0.02\times250 = 5$ g。

(b) $n = \ln(10{,}000/10)/\ln(1.02) = \ln1000/0.0198 = 6.91/0.0198 = 349$ 个台阶。

(c) JND 的定义是统计的，通常指在75 %的成对比较中能被探出的差；这并不意味着相差一个 JND 的两个重量单独呈现时能被无误地识别。绝对再认要差得多：人只能把单一维度上的单个刺激可靠地归入约5到9个类别（乔治·米勒的“神奇数字7”，1956年）。韦伯定律在范围的两端附近也失效。
:::
:::

### 适应与动态范围

多数感受器对刺激的变化反应强烈，对持续不变的刺激反应较弱：它们会**适应**。**慢适应**（紧张性）感受器在刺激持续期间一直发放，报告刺激的量值；**快适应**（位相性）感受器主要在刺激开启、有时在关闭的时刻发放，报告变化。环层小体（Pacinian corpuscle）是哺乳类皮肤与深部组织中的压力感受器，是经典的快适应感受器。维尔纳·洛温斯坦与莫顿·门德尔松1965年在猫肠系膜的小体上表明，其快适应主要是机械性的：神经末梢外的层状囊把突加的压力传给末梢，但随后把持续的压力重新分配；把囊剥掉后，裸露的末梢就慢适应了。

适应还会平移感受器所覆盖的强度范围。许多感受器对强度 $I$ 的反应，可用饱和的 **Naka–Rushton**（或 Hill）函数很好地描述

$$
R = R_\mathrm{max}\frac{I^n}{I^n + \sigma^n},
$$ {#eq-naka}

其中 $\sigma$ 给出半最大反应，感光细胞的 $n$ 接近1。当 $n = 1$ 时，$I$ 从 $\sigma/9$ 增到 $9\sigma$，反应从最大值的10 %升到90 %——81倍，约1.9个对数单位——而星光到正午阳光的自然光强跨约10个对数单位。明适应通过平移 $\sigma$ 使其跟随平均强度来解决这个问题，使曲线的陡段总以当前条件为中心。于是系统报告的是对比度——刺激与其背景之比——而非绝对强度，这正是韦伯定律的含义。

### 感受野

一个感觉神经元的**感受野**是感觉表面（视网膜或皮肤的区域、声音的频率范围）上能改变其活动的区域，连同改变的样式。这一概念由查尔斯·谢灵顿在反射研究中提出，并由 H. 凯弗·哈特兰使之成为感觉生理学的核心；他1938年从蛙的单根视神经纤维记录，又记录过美洲鲎（*Limulus polyphemus*）的复眼。在鲎中，哈特兰与弗洛伊德·拉特利夫于1950年代表明，照亮一个小眼会使其邻近小眼的发放减弱：**侧抑制**，它增强边缘处的对比。

1953年，斯蒂芬·卡夫勒在猫视网膜神经节细胞的记录中发现，其感受野是圆形的，具有**中心-周边**结构。**ON 中心细胞**被中心小圆盘中的光兴奋，被外周环带中的光抑制；**OFF 中心细胞**的安排正相反。两区同时均匀照明只引起微弱的反应。细胞报告的是局部对比，不是绝对亮度。

中心-周边感受野的一个便利模型是**高斯函数之差**：一个窄的高斯兴奋区减去一个更宽、更弱的抑制高斯。对位于感受野中心、半径为 $r$ 的圆形光斑，反应正比于

$$
R(r) = \left(1 - \mathrm{e}^{-r^2/2\sigma_\mathrm{c}^2}\right) - w\left(1 - \mathrm{e}^{-r^2/2\sigma_\mathrm{s}^2}\right),
$$ {#eq-dog}

其中 $\sigma_\mathrm{c}$ 与 $\sigma_\mathrm{s}$ 是中心与周边的宽度，$w$ 是周边相对中心的总强度。

:::

::: example 最佳光斑尺寸 {#ex-dog}
一个模型神经节细胞取 $\sigma_\mathrm{c} = 1$、$\sigma_\mathrm{s} = 3$（以0.1° 视角为单位）、$w = 0.8$。(a)求使 [[#eq-dog]] 中反应最大的光斑半径。(b)把该半径处的反应与均匀照明的反应作比较。(c)这对细胞报告什么有何含义？
::: solution
(a)求导，$\deriv{R}{r} = (r/\sigma_\mathrm{c}^2)\mathrm{e}^{-r^2/2\sigma_\mathrm{c}^2} - w(r/\sigma_\mathrm{s}^2)\mathrm{e}^{-r^2/2\sigma_\mathrm{s}^2} = 0$。约去 $r$ 并取对数：

$$
r^2\left(\frac{1}{2\sigma_\mathrm{c}^2} - \frac{1}{2\sigma_\mathrm{s}^2}\right) = \ln\frac{\sigma_\mathrm{s}^2}{w\sigma_\mathrm{c}^2}, \qquad r^2(0.5 - 0.0556) = \ln\frac{9}{0.8} = 2.42,
$$

于是 $r^2 = 5.45$，$r = 2.33$，约0.23°。

(b) $R(2.33) = (1 - \mathrm{e}^{-2.72}) - 0.8(1 - \mathrm{e}^{-0.30}) = 0.934 - 0.209 = 0.73$。均匀照明（$r \to \infty$）时 $R = 1 - 0.8 = 0.2$。最佳光斑的效果是均匀光的3.6倍。

(c)细胞对局部比其周围更亮的光斑反应最强，对整体照明反应很弱。它像一个空间滤波器，去掉共享的、无信息的平均水平，突出局部对比与边缘，同时也节省了视神经的有限带宽。
:::
:::

## 视觉

### 光转导

脊椎动物的感光细胞有两种：**视杆细胞**极灵敏，司暗光下的视觉；**视锥细胞**灵敏度较低、更快，且分为光谱敏感度不同的若干种，支撑强光下的色觉。两者都有**外段**——塞满叠成垛的、含视色素的膜盘；有含线粒体和细胞核的内段；以及突触末梢。

视杆的视色素是**视紫红质**：蛋白视蛋白——一种 G 蛋白偶联受体——与共价结合的色基 **11-*cis*-视黄醛**（维生素 A 的衍生物）。吸收一个光子后，视黄醛在约200飞秒内异构为全-*trans* 构型——生物中最快的反应之一——形状的改变把视紫红质转变为活性形式变视紫红质 II。乔治·沃尔德从1930到1960年代阐明了视色素的化学。

接下来发生的事违反直觉。暗中，外段膜上的阳离子通道被环磷酸鸟苷（cGMP）维持在开放状态，一股持续的内向**暗电流**——主要由 Na⁺（及少量 Ca²⁺）携带——流入外段并从内段流出，使视杆保持在约−40 mV 的去极化状态，并持续释放谷氨酸。光则*关闭*这些通道。

::: definition 光转导级联 {#def-photo}
1. 光子使视紫红质中的视黄醛异构，产生活性视紫红质（R*）。
2. R* 在盘膜中扩散，激活许多个 G 蛋白**转导素（transducin）**分子，使每个的 GDP 换成 GTP。
3. 每个被激活的转导素 α 亚基激活一个**磷酸二酯酶**（PDE6），后者水解 cGMP。
4. cGMP 的下降关闭质膜上的 **cGMP 门控阳离子通道**（CNG 通道），使暗电流减小。
5. 强光下视杆**超极化**趋向约−70 mV，释放的谷氨酸减少。
6. 恢复：R* 被视紫红质激酶磷酸化并被**抑制蛋白（arrestin）**封闭；转导素水解其 GTP；胞内 Ca²⁺（经 CNG 通道进入）的下降激活鸟苷酸环化酶重新合成 cGMP。这一 Ca²⁺ 反馈也是明适应的基础。
:::

放大发生在前两级——一个 R* 激活许多转导素，每个 PDE6 水解许多 cGMP 分子——也发生在通道上，因为通道的开放对 cGMP 的依赖具有协同性。1979年，丹尼斯·贝勒（Denis Baylor）、特雷弗·兰姆（Trevor Lamb）与 King-Wai Yau 把海蟾蜍（*Bufo marinus*）的单个视杆外段吸入吸液管，直接记录膜电流。微光闪光引起的反应以约1 pA 为台阶上下波动——那是一个光子的反应——其上叠加着数十皮安的暗电流。单个光子关闭开放通道的几个百分点。

::: application 看见单个光子
1942年，塞利格·赫克特、西蒙·施莱尔与莫里斯·皮雷纳让人类被试报告是否看到极微弱的闪光，并测量**看见概率**随闪光强度的变化。由于光子到达是随机的（泊松），即使平均强度固定的闪光，送予视杆的光子数也在变。看见概率曲线的陡度因此揭示闪光被看见需要吸收多少光子：需要的光子越多，曲线越陡。他们的数据以“需要约5–8个被吸收的光子、散布在数百个视杆上、以致每个视杆至多吸收一个”的模型拟合最佳：单个视杆必须能对单个光子作出反应。下图给出预言曲线。
:::

:::

### 作为信息处理器的视网膜

视网膜是一块脑组织，它在把图像传出去之前先对图像作处理。感光细胞与**双极细胞**形成突触，双极细胞又与**神经节细胞**形成突触，后者的轴突组成视神经；**水平细胞**与**无长突细胞**提供横向连接。由于感光细胞在暗中释放谷氨酸，双极细胞必须反转或保留信号的符号：**OFF 双极细胞**带离子型谷氨酸受体，因而与感光细胞一样在暗中去极化；**ON 双极细胞**带一种代谢型受体（mGluR6），它关闭一种阳离子通道，于是谷氨酸使其超极化，而光通过减少谷氨酸释放使其去极化。这第一级突触上的符号反转产生了并行的 ON 与 OFF 通路，水平细胞则贡献对抗性的周边。小鼠视网膜有30余型神经节细胞，每型铺满整个视网膜，提取不同的特征：对比度、颜色、运动方向，以及用来设定昼夜节律钟的绝对光水平。

### 视觉皮层

视网膜神经节细胞投射到丘脑的外侧膝状体，后者投射到初级视觉皮层（V1，又称纹状皮层）。1959年，戴维·休伯尔与托尔斯滕·维塞尔从麻醉猫 V1 的单神经元记录中发现，圆形光斑作为刺激几乎毫无用处；细胞对特定**朝向**的条形或边缘剧烈反应。**简单细胞**的感受野呈长形，带彼此分离的 ON 与 OFF 亚区，仿佛由一列膝状体的中心-周边感受野拼成；**复杂细胞**对较大感受野内任何位置的朝向边缘都有反应。朝向偏好相似的神经元成柱聚集，两眼的输入则被分隔成交替的**眼优势**柱。等级式的思想——每一级由更简单的特征构造更复杂的特征——自此一直引导着视觉神经科学与计算机视觉模型；休伯尔与维塞尔共获1981年诺贝尔奖。这些柱如何发育，在[[neuroscience/neural-development]]中讨论。

## 听觉

声音是压力波。人耳对约20 Hz 到20 kHz 的频率起反应，所响应的声压从约20 µPa（1–4 kHz 处惯用的阈值）到其百万倍以上——后者声音大到令人疼痛。因此强度用对数标度表示：以分贝计的**声压级**为 $L = 20\log_{10}(p/p_0)$，其中 $p_0 = 20$ µPa。20 Pa 的声压即120 dB。（常引用年轻人能听到约20 kHz；上限随年龄下降。许多哺乳动物能听到高得多的频率：小鼠到约90 kHz，某些蝙蝠和齿鲸超过150 kHz。）

### 毛细胞

听觉以及前庭觉和侧线觉的感受器是**毛细胞**：一种上皮细胞，顶端表面有一束充满肌动蛋白、坚硬的**静纤毛**，按高度递增排成几排。纤毛束向最高一排偏转使细胞去极化；向反方向偏转使其超极化。

::: definition 毛细胞的机械-电转导 {#def-hair}
每根静纤毛的顶端由一根细丝——**顶端连丝**（tip link），由钙黏蛋白23与原钙黏蛋白15组成——连到其较高邻纤毛的侧面。向高的一侧偏转拉伸顶端连丝，把靠近较短静纤毛顶端的**机械门控阳离子通道**拉开；反方向的偏转使连丝松弛，通道关闭。通道在微秒内开放，快得容不下任何酶级联，所以它们必定由机械力直接门控。形成孔道的亚基据信包括 TMC1 与 TMC2，尽管通道复合体的完整组成仍在研究之中。
:::

戴维·科里与 A. J. 赫德斯佩斯1979年在牛蛙球囊的毛细胞上表明，转导的潜伏期只有数十微秒；赫德斯佩斯后来把通道定位于静纤毛尖端附近；詹姆斯·皮克尔斯等在1984年用电子显微镜在豚鼠耳蜗中描述了顶端连丝。几纳米的偏转就使反应饱和，而听力的阈值对应远小于1纳米的纤毛束位移。

耳蜗毛细胞的离子环境很特别。其顶端表面朝向**内淋巴**：一种富 K⁺（约150 mmol L⁻¹）的液体，由一层主动的上皮——血管纹——维持其比其他细胞外液高约+80 mV 的电位。因此转导电流主要由 K⁺ 携带，被巨大的电位梯度推入细胞，细胞不必耗能把它泵出去：K⁺ 经基底侧膜流出，该膜朝向普通的低 K⁺ 液体。

### 作为频率分析器的耳蜗

在哺乳动物的耳蜗中，毛细胞坐在**基底膜**上；基底膜沿一根约35 mm 长、充满液体、盘绕的管子延伸。膜在近耳蜗底端处窄而硬，在近顶端处宽而软。格奥尔格·冯·贝凯西在1940年代观察人尸体耳蜗，发现纯音激起一个**行波**，在其峰值位置由频率决定：高频在近底端，低频在近顶端。于是，膜上的每个点、每个毛细胞都被调谐到一个**特征频率**，耳蜗因此完成一次机械的频率分析。这种位置编码，或称**音调拓扑**（tonotopy），在听觉通路直至皮层的每一级都被保留。

::: example 把频率映射到耳蜗 {#ex-greenwood}
唐纳德·格林伍德给人耳蜗的经验函数，给出距顶端 $x$ 处（顶端为0，底端为1）的特征频率 $f = 165.4\,(10^{2.1x} - 0.88)$ Hz。把耳蜗取为35 mm 长，(a)1 kHz 的位置在哪里？(b)1与2 kHz、2与4 kHz、4与8 kHz 的位置各相隔多远？(c)这说明什么？
::: solution
(a) $10^{2.1x} = 1000/165.4 + 0.88 = 6.93$，故 $2.1x = 0.840$，$x = 0.400$：距顶端40 %处，14.0 mm。

(b)对2、4、8 kHz 重复计算得 $x = 0.530$、$0.666$、$0.806$；间距为 $0.130\times35 = 4.5$ mm、$0.136\times35 = 4.8$ mm、$0.140\times35 = 4.9$ mm。

(c)约1 kHz 以上，每个倍频程占据耳蜗上大致恒定的长度，约5 mm：这张图对频率近似取对数。这与音乐和知觉上“八度听起来是等距台阶”的事实相符，也是感觉系统中处处可见的对数压缩又一实例。（格林伍德函数是对人类心理物理与解剖数据的经验拟合，不是推导。）
:::
:::

然而，只有被动力学不能解释耳蜗调谐的尖锐及其灵敏度。哺乳动物有两种耳蜗毛细胞。**内毛细胞**排成单排，是真正的感受器，约95 %的听神经传入纤维与其接触。三排**外毛细胞**充当放大器：去极化时变短，超极化时变长，且能在声学频率上运动（威廉·布朗内尔等，1985年）。这一**电致运动**依赖膜蛋白 **prestin**（Jing Zheng、彼得·达洛斯等，2000年），把能量馈入基底膜的振动，使其放大并锐化，在低声压级时最显著。健康的耳蜗甚至发出自己的微弱声音——**耳声发射**——可以在外耳道中记录到。

### 声音定位

耳蜗映射的是频率而非空间，声源的方向必须在脑中由两耳的差异算出。低频声音到达较近一耳略早：**双耳时间差**（ITD）至多是声音绕头一周所需的时间。高频声音被头部遮挡，在较近一耳更响：**双耳强度差**。

::: example 双耳时间差有多小？ {#ex-itd}
20 °C 的空气中声速为343 m s⁻¹。(a)两人双耳相距0.22 m，把路径差当作耳间距，估计其最大 ITD。(b)仓鸮的最大 ITD 约0.17 ms；鸮能把声源定位到约1–2°以内。在正前方附近，1°对鸮相当于多大的 ITD？(c)与一个动作电位的时程作比较。
::: solution
(a) $0.22/343 = 6.4\times10^{-4}$ s $= 0.64$ ms。（绕头的路径略长；成人实测值约0.6–0.7 ms。）

(b)在中线附近 ITD 近似按 $\mathrm{ITD}_\mathrm{max}\sin\theta$ 变化，所以 $\theta = 1° = 0.0175$ rad 时，$\mathrm{ITD} \approx 0.17\times0.0175 = 0.003$ ms，即约3 µs。

(c)动作电位持续约0.5–1 ms，长数百倍。听觉系统必须以微秒级的精度比较两耳锋电位的时间，靠的是特化的突触（如 Held 终末扣与 Held 杯这类极大的终末）、快速的通道和锁相发放。
:::
:::

1948年，劳埃德·杰弗雷斯提出一个 ITD 检测模型：来自两耳的轴突沿着一排**符合检测**神经元反向走行，充当**延迟线**，于是当外部的时间差被轴突路径长度之差抵消时，每个神经元发放最强。这排神经元于是构成 ITD 的位置图。凯瑟琳·卡尔与小西正和（Masakazu Konishi）1990年在仓鸮的 laminaris 核发现了与这一模型高度吻合的环路。在哺乳动物中，对应的核团是内侧上橄榄核，其中也含符合检测器；但那里是否存在杰弗雷斯式的延迟位置图，还是由定时抑制决定 ITD 调谐，仍有争议。

## 触觉、温度与痛觉

哺乳动物的皮肤含若干类**低阈值机械感受器**，每个都是感觉神经元的末梢，胞体在背根神经节。在人手的无毛（光滑）皮肤中，通过对清醒志愿者单根纤维记录（microneurography，1960年代在瑞典建立），已鉴定出四种：

| 末梢类型 | 适应 | 感受野 | 最适刺激 |
|---|---|---|---|
| 梅克尔细胞-神经突复合体 | 慢 | 小，边界锐 | 边缘、点、纹理、形状 |
| 触觉小体（Meissner corpuscle） | 快 | 小 | 滑动、低频振动（颤动，约5–50 Hz） |
| 鲁菲尼末梢（Ruffini ending） | 慢 | 大 | 皮肤拉伸、手指位置 |
| 环层小体 | 极快 | 极大 | 高频振动（约40–400 Hz） |

这些末梢中大多数的转导通道是 **Piezo2**：一种大型机械门控阳离子通道，2010年由贝特朗·科斯特、阿德尔姆·帕塔普蒂安等在发现其同源物 Piezo1 的同时发现。感觉神经元缺失 Piezo2 的小鼠失去大部分轻触反应和相当一部分肢体位置感（本体感觉）。温度由 **TRP** 通道家族成员感受：TRPV1 由迈克尔·卡泰琳娜、戴维·朱利叶斯等在1997年鉴定为辣椒素——辣椒中“热”的化合物——的受体，在约43 °C 以上被激活；薄荷醇受体 TRPM8 则被冷却激活。朱利叶斯与帕塔普蒂安共获2021年诺贝尔奖。

**痛觉**（伤害性感受）由细而传导缓慢的 Aδ 与 C 纤维传导，其游离末梢对强烈的机械、温度或化学刺激起反应。由于痛在脊髓和脑中被强烈调制，且慢性疼痛是重大的临床问题，其临床方面在[医学图谱：头痛与疼痛](/learn/medicine/lesson.php?c=nervous-system&l=headache-pain)中讲述。

## 化学感觉

### 嗅觉

1991年，琳达·巴克与理查德·阿克塞尔在寻找只表达于大鼠嗅觉上皮、且编码 G 蛋白偶联受体的基因时，发现了一个由数百个**气味受体**（OR）基因组成的家族——哺乳动物基因组中最大的基因家族。小鼠有约1100个功能 OR 基因，人类约400个功能基因和数目相当的假基因，大象约2000个（数字来自基因组注释，仍在修订）。巴克与阿克塞尔共获2004年诺贝尔奖。

::: definition 嗅觉编码的逻辑 {#def-olfaction}
- 每个**嗅觉感受神经元**表达**一个**气味受体基因——从整个基因库中挑选——且只用它的一个等位基因。
- 气味分子结合后激活一种 G 蛋白（G_olf），腺苷酸环化酶使 cAMP 升高，cAMP 打开 CNG 阳离子通道；由此进入的 Ca²⁺ 打开 Ca²⁺ 激活的 Cl⁻ 通道，而因嗅觉神经元胞内 Cl⁻ 维持在高浓度，Cl⁻ 的外流放大去极化。
- 表达同一受体的所有神经元散布于上皮之中，其轴突却投射到每个嗅球中同一两个**嗅小球**（glomerulus）（彼得·蒙巴尔特斯、阿克塞尔等，1996年）。嗅球因此含有一张图：每个嗅小球代表一种受体。
- 每种受体结合许多气味分子，每个气味分子又激活几种受体，所以气味由被激活嗅小球图样的**组合式**编码（贝蒂娜·马尔尼克、巴克等，1999年）。
:::

昆虫用不同的分子工具箱解决了同一个问题。昆虫的气味受体不是 G 蛋白偶联受体，而是**配体门控离子通道**，由一个气味特异的亚基与一种共有共受体 Orco 组成；果蝇（*Drosophila*）有约60个 *Or* 基因。然而接线逻辑是一样的：每个神经元一种受体，表达某受体的所有神经元会聚到触角叶中单个嗅小球。环路逻辑以不同的分子趋同进化而来，提示嗅小球式设计是辨认气味这一问题的好解。

### 味觉

哺乳动物的味觉能辨认五种基本性质，每种由味蕾中一群各自独立的味觉感受细胞检测。**甜**由 G 蛋白偶联受体 T1R2 与 T1R3 的异二聚体检测，**鲜**（谷氨酸的味道）由 T1R1 与 T1R3 检测，**苦**由 T2R 家族检测——人类约25个基因，每个细胞表达其中许多种，于是苦细胞报告“苦”而不分辨苦味化合物之间的差异。这些受体大多在2000–2003年前后由查尔斯·祖克与尼古拉斯·赖巴的实验室鉴定（主要在小鼠中）。**酸**由表达质子通道 OTOP1（2018–2019年鉴定）的细胞检测，而小鼠低浓度**盐**的诱人味道依赖上皮钠通道 ENaC。让本来尝不到某种化合物的受体内人工转入甜觉细胞的小鼠，会被该化合物吸引；让苦觉细胞表达该受体的小鼠则回避它：味道的行为意义由细胞决定，而不是由受体决定——这是对标记线的有力确证。

::: warning “舌头各部位尝不同的味道”
“舌图”——舌尖尝甜、舌根尝苦——源自对大卫·黑尼希1901年一篇德国论文的误读；该文报告的只是阈值在舌上的微小差异。凡是有味蕾的舌区，五种味道都能在其中被检出。性质由细胞类型编码，而各区味蕾中都有一切类型的细胞。
:::

::: quiz
一个感觉神经元在其刺激开启时高频率发放，随后100 ms 内几乎降回静息发放率，尽管刺激仍在持续。刺激关闭时它又短暂发放一阵。哪种描述最合适？
- [ ] 一个慢适应感受器，报告刺激强度。
- [x] 一个快适应感受器，报告刺激的变化。
- [ ] 一个转导通道已被永久损坏的感受器。
- [ ] 一个具有中心-周边感受野的感受器。
::: solution
在持续刺激期间几乎无反应、只在开启与关闭时反应，是快适应的标志，如环层小体或触觉小体。这类感受器报告振动或滑动之类的变化，对持续压力视而不见；慢适应感受器（如梅克尔末梢）才报告持续刺激。
:::
:::

::: history
约翰内斯·缪勒1838年阐述神经特殊能力学说；恩斯特·韦伯（1834年）与古斯塔夫·费希纳（1860年）创立了心理物理学。赫尔曼·冯·亥姆霍兹在1850与1860年代研究了眼与耳，提出听觉共振论，并继托马斯·杨之后提出三色觉学说。埃德加·阿德里安1926年记录单根感觉纤维，1932年与谢灵顿共获诺贝尔奖。H. 凯弗·哈特兰、拉格纳·格拉尼特与乔治·沃尔德分享1967年诺贝尔奖，表彰他们在视网膜与视色素方面的工作；格奥尔格·冯·贝凯西因耳蜗行波获1961年诺贝尔奖。卡夫勒（1953年）与休伯尔、维塞尔（1959年和1962年）定义了视觉系统的感受野。感官的分子时代始于视紫红质的克隆（1983年，牛；杰里米·内桑斯与戴维·霍格内斯）、气味受体（巴克与阿克塞尔，1991年）、TRPV1（1997年）、味觉受体（2000年前后）与 Piezo 通道（2010年）。
:::

## 由此引向何处

感觉信号经由运动系统驱动行为，那是[[neuroscience/motor-systems]]的主题。感受野与地图在发育中如何接线、又如何被经验精炼，见[[neuroscience/neural-development]]；刺激如何由神经元群体编码与解码，见[[neuroscience/neural-coding]]。感觉在交流与导航中的行为用途，在[[behaviour/communication]]与[[behaviour/migration-navigation]]中探讨。

::: summary
- 感受器把刺激转导为感受器电位：或由直接门控的通道（快：毛细胞、触觉、昆虫嗅觉），或经 G 蛋白级联（放大：脊椎动物感光细胞、嗅觉、甜鲜苦味觉）。
- 性质主要由标记线编码；强度由感受器电位、发放率与募集编码。韦伯定律（$\Delta I/I = k$）与费希纳的对数标尺、或史蒂文斯幂定律，描述被压缩的强度感知。
- 适应平移感受器的工作范围（Naka–Rushton $\sigma$ 跟随背景），所以感觉系统报告对比与变化。
- 中心-周边结构的感受野（卡夫勒）与侧抑制（哈特兰）突出局部对比；V1 神经元对朝向边缘作出反应（休伯尔与维塞尔）。
- 视杆遇光超极化：视紫红质 → 转导素 → PDE6 → cGMP 下降 → CNG 通道关闭；单个光子给出约1 pA 的反应（贝勒、兰姆与 King-Wai Yau，1979年）。
- 毛细胞使用由顶端连丝门控的通道，微秒内开放；耳蜗把频率映射到位置（大致取对数），外毛细胞以基于 prestin 的电致运动放大。声源定位利用微秒级的双耳时间差。
- 触觉由四类机械感受器中的 Piezo2 介导；温度由 TRP 通道感受。
- 嗅觉神经元各表达数百种受体之一，按受体类型会聚到嗅小球；味觉细胞各具一种被细胞固定的味道。
:::

## 习题

::: exercise 分贝 {level=1 check="60"}
一次谈话产生20 mPa 的声压。其声压级是多少 dB SPL（以20 µPa 为参考）？
::: solution
$L = 20\log_{10}(0.020/20\times10^{-6}) = 20\log_{10}(1000) = 60$ dB。
:::
:::

::: exercise 一个韦伯分数 {level=1 check="0.05"}
某被试在同一背景下恰好能分辨200单位与210单位的光，也能分辨1000单位与1050单位的光。韦伯分数是多少？
::: solution
$10/200 = 0.05$ 且 $50/1000 = 0.05$：韦伯定律在此范围内成立，$k = 0.05$。
:::
:::

::: exercise 感受器与感觉的匹配 {level=1}
为下列各例说出感受器或转导分子：(a)口袋里手机的振动；(b)薄荷的清凉；(c)奎宁的苦味；(d)辣椒的灼热；(e)闭着眼睛时手指的位置。
::: solution
(a)环层小体（高频振动），转导通道为 Piezo2。(b)冷敏末梢上的 TRPM8。(c)苦味细胞上的 T2R 苦味受体。(d)伤害性感受与温度敏感末梢上的 TRPV1。(e)本体感受器，主要是肌梭以及关节和皮肤的牵张感受器（鲁菲尼末梢），它们也依赖 Piezo2。
:::
:::

::: exercise 看见的概率 {level=2 check="0.554"}
若一次闪光只有在至少吸收6个光子时才被看见，而平均吸收数为6，看见它的概率是多少（保留三位小数）？用泊松分布。
::: solution
$P(X \ge 6) = 1 - \sum_{k=0}^{5}\mathrm{e}^{-6}6^k/k! = 1 - 0.446 = 0.554$。即使平均恰好送够所需光子数的闪光，也只有略过半数的时候被看见，因为光子到达是随机的。
:::
:::

::: exercise 解读一张感受野图 {level=2}
视觉系统中一个神经元，对落在其感受野中心的小光斑以增加发放作答，对中心周围的一圈光环以减小作答，对同时覆盖两者的光斑以少量增加作答，而对通过中心的任何朝向的条形都以增加作答。(a)它可能位于视觉通路的哪里？(b)预测它对中心一个暗点的反应。(c)V1 的一个简单细胞的反应会有何不同？
::: solution
(a)圆的、与朝向无关的 ON 中心/OFF 周边结构，是视网膜神经节细胞或外侧膝状体神经元的典型特征。(b)中心的暗点减少兴奋性中心的照度，细胞的发放降到其背景发放率之下。(c)简单细胞只对其偏好朝向与位置的条形或边缘强烈反应，对正交朝向弱反应或不反应，对小光斑和弥散光反应很差；其亚区将是长形的而非同心圆的。
:::
:::

::: exercise 视杆的信噪难题 {level=2}
一只蟾蜍的视杆暗电流为20 pA，单光子反应为1 pA。它的持续暗噪声标准差约0.1 pA，并偶尔自发产生与单光子反应完全相同的反应，室温下速率约每两三分钟一次（视紫红质的热异构；贝勒、马修斯与 King-Wai Yau，1980年）。(a)单个光子关闭暗电流的多大比例？(b)为什么视觉的绝对阈值不能定在视网膜任何位置吸收的单个光子上？(c)要求在短时间、小区域内有若干光子，有何帮助？
::: solution
(a) $1/20 = 5$%。(b)人的视网膜约有 $10^8$ 根视杆；即使每根视杆几分钟只产生一次自发事件，整个视网膜每秒也有数十万次这样的事件。一个报告每次单视杆事件的系统会不断“看见”闪光。(c)要求在很短的积分时间（约0.1 s）与很小区域内有若干事件重合，使自发事件单独达到标准的概率变得极小，而真实闪光会把这些事件一起送上来。这是对赫克特等为何发现阈值为数个光子（尽管每根视杆对一个光子就有反应）的一种解释。这是一条普遍原理：阈值由噪声设定，而不仅由感受器的灵敏度设定。
:::
:::

::: exercise 基底膜上的倍频程 {level=2 check="4.2"}
用 [[#ex-greenwood]] 中格林伍德的函数，在35 mm 长的人耳蜗上，500 Hz 与1 kHz 的位置相隔多少毫米（保留一位小数）？与4 kHz 和8 kHz 的间距比较。
::: solution
对500 Hz，$10^{2.1x} = 500/165.4 + 0.88 = 3.903$，故 $x = \log_{10}3.903/2.1 = 0.2816$；1 kHz 处 $x = 0.4002$。间距为 $0.1186\times35 = 4.2$ mm，略小于4 kHz 与8 kHz 之间的4.9 mm。低频处这张图偏离纯对数（$-0.88$ 项），所以倍频程在靠近顶端处稍被压缩。
:::
:::

::: exercise 组合之嗅 {level=3}
小鼠约有1100个功能气味受体。粗略假设每个气味由超过阈值被激活的受体子集编码，每个气味恰好激活3个受体。(a)能编码多少个不同的气味？(b)若每个气味激活10个受体？(c)给出两个生物学理由，说明真实可辨别气味的数目为什么必定小得多。(d)组合编码为何仍然有利？
::: solution
(a) $\binom{1100}{3} = 1100\times1099\times1098/6 = 2.2\times10^8$。(b) $\binom{1100}{10} \approx 7\times10^{23}$。(c)受体反应是分级的、带噪声的，不是二值的，只差一个弱激活受体的图样很容易被混淆；受体并非彼此独立，化学性质相近的气味分子会激活重叠的受体集合；自然中的气味是混合物，产生需要系统拆分的重叠图样。下游环路也限制了能学会的图样数目。(d)组合编码让数量不大的受体表征一个开放边界的分子范围，包括进化中从未遇到过的分子，并允许新联想在皮层中学习，而不必为每种有现实意义的气味配备一个专属受体。
:::
:::

::: exercise 对比度，而非光 {level=3}
暗弱室内光下的一张白纸反射到眼里的光，少于明媚阳光下的一张黑纸，然而白纸看起来是白的，黑纸看起来是黑的。(a)用适应与中心-周边感受野的思想解释为什么。(b)韦伯定律意味着视觉系统报告比值 $\Delta I/I$。证明按 $(I_\mathrm{object} - I_\mathrm{background})/I_\mathrm{background}$ 定义的物体对比度，在照明乘以任意因子时保持不变。(c)对动物来说为什么这是好的设计？
::: solution
(a)明适应把感光细胞与视网膜环路的增益调到平均照度上，中心-周边感受野则把每个区域与其周围作比较。因此送往脑的信号取决于一表面相对于其周围反射多少光，而不取决于绝对光量。白纸反射照到其上光线的约80–90 %，黑纸约5 %，无论照明如何。(b)照明乘以 $a$ 时两个强度同比例变化：$(aI_\mathrm{o} - aI_\mathrm{b})/(aI_\mathrm{b}) = (I_\mathrm{o} - I_\mathrm{b})/I_\mathrm{b}$。(c)对动物要紧的是物体的属性（其反射率，用以辨认食物、天敌与表面），而不是在昼夜之间、阴影与阳光之间相差好几个数量级的照明。报告对比度即提取不变量，丢弃变化量。
:::
