触摸滚烫的炉子时，一个信号从你的指尖出发，经过大约一米传到脊髓，只需几百分之一秒，而且以满格的强度抵达。电线可做不到这一点还分文不花：电缆既长又漏，上面的电信号会随距离衰减，我们马上就会看到。轴突比电线更糟：盐性的内核导电能力比铜差几千万倍，细胞膜又薄又漏。然而冲动能沿着它们不衰减地奔跑，因为每一段膜都在再生它收到的信号。这种能够再生的信号就是**动作电位**：一次短暂、程式化的膜电位反转，幅度约100 mV，持续一毫秒或几毫秒，是神经系统远距离通讯的通用货币。

本章解释动作电位如何产生、如何传导。我们先看那些揭示其本相的实验，再追随艾伦·霍奇金（Alan Hodgkin）与安德鲁·赫克斯利（Andrew Huxley）对乌贼巨轴突的分析——他们把 Na⁺ 与 K⁺ 各自携带的电流分离出来，并据此建立了生物学中最成功的定量模型之一。然后我们来看模型所预言的通道蛋白，以及决定冲动传多远、传多快的轴突电缆性质，其中也包括髓鞘化这一妙计。静息电位、能斯特方程与膜的等效电路见[[neuroscience/resting-potential]]。

## 动作电位是什么样

从轴突内作记录，并给一个短暂的去极化电流脉冲。弱脉冲只引起一个小的去极化，它像无源 RC 电路那样按膜时间常数指数衰减。较强的脉冲引起较大的无源响应。但一旦去极化超过**阈值**——通常比静息电位高10–20 mV——膜便接管一切：电位在不到一毫秒内直冲而上，越过零值冲到约+30至+50 mV，又几乎以同样快的速度回落，其后几毫秒内下冲至静息电位之下（**后超极化**），然后恢复。

四个性质界定了动作电位：

- **阈值。** 低于阈值的去极化会衰减；超过阈值的则触发一次冲动。
- **全或无。** 一旦触发，冲动的幅度与形状便与刺激大小无关。更强的刺激产生更多或更早的冲动，而不是更大的冲动。
- **不应性。** 冲动之后约一毫秒内，再强的刺激也无法触发第二次冲动（**绝对不应期**）；此后再过几毫秒，则需要比平常更强的刺激（**相对不应期**）。这把最大发放率限制在每秒几百次冲动，并保证冲动单向行进。
- **不衰减传导。** 冲动沿轴突以恒定的速度、恒定的幅度前进。

过冲是机制的第一个线索。尤利乌斯·伯恩斯坦（Julius Bernstein）1902年曾提出，兴奋是膜对 K⁺ 选择性的崩溃，这会把电位带到零而不会更高。1939年，霍奇金与赫克斯利、以及柯蒂斯（Curtis）与科尔（Cole）在乌贼轴突内部记录时，发现它会越过零值到达正值。真相远不止选择性的丧失。

1949年，霍奇金与伯纳德·卡茨（Bernard Katz）发现，过冲取决于胞外 Na⁺。把轴突周围海水中的一部分换成不含 Na⁺ 的溶液后，动作电位的峰值下降，下降幅度接近 Na⁺ 能斯特方程的预言，而静息电位几乎不动。**钠假说**由此而来：静息时膜主要对 K⁺ 通透，冲动期间则短暂而具选择性地对 Na⁺ 通透，于是电位摆向 $E_\mathrm{Na}$。用弦电导方程的语言（[[neuroscience/resting-potential#prop-chord]]），$g_\mathrm{Na}$ 从 $g_\mathrm{K}$ 的一小部分升至其许多倍，然后又回落。

## 电压钳

要弄清 Na⁺ 与 K⁺ 电导如何变化，霍奇金与赫克斯利必须测量它们，而在这里他们遇到了一个循环论证的难题。电导取决于电压，电压取决于电流，而电流又取决于电导。动作电位期间一切同时变化。

解决办法是**电压钳**，由肯尼斯·科尔（Kenneth Cole）1947年和乔治·马蒙特（George Marmont）1949年发明，并经霍奇金、赫克斯利与卡茨改进。一根长金属丝电极沿轴突内部穿入，使受研究的整段长度处于同一电位（**空间钳**）。反馈放大器把膜电位与实验者设定的指令电位相比较，并注入使两者相等所需的任何电流。当指令值从静息电位跳到一个新值时，膜电位随之跳变并被钳在那里；此时放大器必须提供的电流，便与流经膜通道的电流大小相等、方向相反，且电压已知而固定。电压固定后，最初几微秒之后电容电流为零，测得的电流纯粹是离子电流。

::: definition 电压钳与离子电流 {#def-clamp}
在**电压钳**实验中，膜电位被钳在实验者选定的数值上，并测量维持它所需的电流。对乌贼轴突，去极化阶跃会产生：

- 一份早期**内向电流**，在约一毫秒内达峰，随后虽然电压维持不变它却开始衰减，由 Na⁺ 携带；
- 一份晚期**外向电流**，带着延迟、以 S 形时间过程上升到一个平台，并在去极化持续的整个期间保持，由 K⁺ 携带。

Na⁺ 电流在持续去极化下的衰减称为**失活**。K⁺ 电流在这个时间尺度上不失效，称为**延迟整流**电流。
:::

霍奇金与赫克斯利用更换离子的办法把两种电流分开。把胞外大部分 Na⁺ 换成不可通透的阳离子胆碱，早期内向电流消失，只剩晚期的外向电流；两条记录相减便单独得到 Na⁺ 电流。后来的药理学让这件事更容易：**河豚毒素**（TTX）——河豚的一种毒素——在纳摩尔浓度下从胞外侧阻断电压门控 Na⁺ 通道（托什奥·奈良桥（Toshio Narahashi）、约翰·穆尔（John Moore）与威廉·斯科特（William Scott），1964），而**四乙铵**（TEA）阻断延迟整流 K⁺ 通道。

把每种电流除以其驱动力，$I_\mathrm{Na}/(V - E_\mathrm{Na})$ 与 $I_\mathrm{K}/(V - E_\mathrm{K})$，就得到每个钳制电压下两个电导随时间的函数。结果很清楚：

- 两个电导都随去极化增大，阶跃越大，上升越陡、越快。
- $g_\mathrm{Na}$ 上升很快（零点几毫秒），随后失活（一毫秒或几毫秒）。
- $g_\mathrm{K}$ 上升较慢，带 S 形延迟，且不失活。
- 复极化时两个电导都关闭；$g_\mathrm{K}$ 沿一条简单指数关闭，没有去极化时所见的那种延迟。

## 霍奇金-赫克斯利模型

霍奇金与赫克斯利用一组方程描述了这些结果，他们后来说，这套方程只是经验性描述，并不承诺任何机制。他们设想每个电导由假想的**门控颗粒**控制，颗粒在膜内的许可位与非许可位之间移动，速率取决于电压。

::: definition 门控变量 {#def-gating}
**门控变量** $x$（$m$、$h$、$n$ 之一）是一类门控颗粒中处于许可状态的比例。它服从一阶动力学，

$$
\deriv{x}{t} = \alpha_x(V)\,(1 - x) - \beta_x(V)\,x,
$$ {#eq-gate}

其中 $\alpha_x$ 与 $\beta_x$ 是电压依赖的开、关速率常数。在固定电压下，$x$ 以**时间常数** $\tau_x = 1/(\alpha_x + \beta_x)$ 指数弛豫到其**稳态值** $x_\infty = \alpha_x/(\alpha_x + \beta_x)$。
:::

为拟合 $g_\mathrm{K}$ 的 S 形上升，他们假设必须有四个独立的 $n$ 类颗粒同时处于许可态，于是 $g_\mathrm{K} = \bar g_\mathrm{K}\,n^4$；单个指数函数取四次方，起步慢而后加速，正与数据相符，而复极化时它几乎按指数回落。Na⁺ 电导则需要两类颗粒：三个激活颗粒 $m$，去极化时快速开放；一个失活颗粒 $h$，去极化时缓慢关闭。于是 $g_\mathrm{Na} = \bar g_\mathrm{Na}\,m^3h$。

::: proposition 霍奇金-赫克斯利方程 {#prop-hh}
对单位面积电容为 $C$、携带单位面积外加电流 $I$ 的空间钳膜片，

$$
C\deriv{V}{t} = I - \bar g_\mathrm{Na}m^3h\,(V - E_\mathrm{Na}) - \bar g_\mathrm{K}n^4\,(V - E_\mathrm{K}) - g_\mathrm{L}\,(V - E_\mathrm{L}),
$$ {#eq-hh}

其中 $m$、$h$、$n$ 各自服从[[#eq-gate]]。6.3 °C 下的乌贼轴突，按静息电位为−65 mV 的现代惯例，参数为 $C = 1\ \mu\mathrm{F\,cm^{-2}}$、$\bar g_\mathrm{Na} = 120$、$\bar g_\mathrm{K} = 36$ 和 $g_\mathrm{L} = 0.3$ mS cm⁻²，$E_\mathrm{Na} = +50$、$E_\mathrm{K} = -77$ 和 $E_\mathrm{L} = -54.4$ mV，并且（速率以 ms⁻¹ 计，$V$ 以 mV 计）

$$
\begin{aligned}
\alpha_m &= \frac{0.1(V + 40)}{1 - \mathrm{e}^{-(V + 40)/10}}, & \beta_m &= 4\,\mathrm{e}^{-(V + 65)/18},\\
\alpha_h &= 0.07\,\mathrm{e}^{-(V + 65)/20}, & \beta_h &= \frac{1}{1 + \mathrm{e}^{-(V + 35)/10}},\\
\alpha_n &= \frac{0.01(V + 55)}{1 - \mathrm{e}^{-(V + 55)/10}}, & \beta_n &= 0.125\,\mathrm{e}^{-(V + 65)/80}.
\end{aligned}
$$

速率常数随温度按因子 $3^{(T - 6.3)/10}$（$Q_{10}$ 为3）缩放。项 $g_\mathrm{L}(V - E_\mathrm{L})$ 是一小小与电压无关的**漏电导**，把 Cl⁻ 与其他次要电流并在一起。

假设：膜是等电位的（空间钳制）；三个门控过程彼此独立；每个都服从一阶动力学；开放的通道是欧姆性的。拟合出的函数是对乌贼轴突电压钳数据的经验描述，不是从分子机制推导出来的。
:::

这个模型的威力在于，其中没有任何部分是针对动作电位拟合的。速率函数只来自固定电压下的电压钳记录。当霍奇金与赫克斯利用机械计算器手算[[#eq-hh]]的数值解、让膜自由运转时，动作电位出现了，带着它的阈值、过冲、下冲、不应期和全或无性质，与记录到的冲动高度吻合。对传导中的冲动，他们算得传导速度为18.8 m s⁻¹，而同一条轴突在18.5 °C 下实测为21.2 m s⁻¹。

### 动作电位如何展开

模型让我们能一步一步追踪动作电位，而每一步都来自 $m$、$h$、$n$ 之间的速度差。例如在−20 mV，6.3 °C 下的时间常数为 $\tau_m \approx 0.38$ ms、$\tau_h \approx 1.2$ ms、$\tau_n \approx 2.3$ ms：$m$ 比另外两个快好几倍。

1. **阈值与上升支。** 去极化使 $m$ 迅速增大。更多 Na⁺ 通道开放，Na⁺ 内流，膜进一步去极化，又开放更多 Na⁺ 通道。这是一条**正反馈**回路（[[animal-physiology/homeostasis]]）。阈值是这样的电压：随去极化增长的 Na⁺ 内向电流开始超过 K⁺ 与漏电导的外向电流，于是回路失去约束。电位奔向 $E_\mathrm{Na}$。
2. **峰值。** 电位没有到达 $E_\mathrm{Na}$，因为 $h$ 已开始下降（失活），$n$ 开始上升。峰值处内向与外向电流平衡。
3. **复极化。** 随着 $h$ 下降、$n$ 上升，$g_\mathrm{K}$ 占优势，电位回落向 $E_\mathrm{K}$。这是**负反馈**：去极化本身经过一段延迟，打开了终结它的电流。
4. **下冲。** $n$ 关闭缓慢，因此有几毫秒 $g_\mathrm{K}$ 大于静息值，电位比静息电位更接近 $E_\mathrm{K}$。
5. **不应期。** 从失活中恢复（$h$ 回升）与 $n$ 的关闭需要几毫秒。在足够多的 Na⁺ 通道恢复、多余的 $g_\mathrm{K}$ 平息之前，第二次刺激无法达到阈值。

```python
import math

# Hodgkin-Huxley model of a patch of squid axon membrane at 6.3 degC.
# V in mV (rest = -65), t in ms, currents in uA/cm^2, conductances in mS/cm^2.
g_Na, g_K, g_L = 120.0, 36.0, 0.3
E_Na, E_K, E_L = 50.0, -77.0, -54.4
C = 1.0                                   # uF/cm^2

def rates(V):
    """Opening (alpha) and closing (beta) rate constants, ms^-1, for m, h, n."""
    am = 0.1 * (V + 40) / (1 - math.exp(-(V + 40) / 10))
    bm = 4.0 * math.exp(-(V + 65) / 18)
    ah = 0.07 * math.exp(-(V + 65) / 20)
    bh = 1.0 / (1 + math.exp(-(V + 35) / 10))
    an = 0.01 * (V + 55) / (1 - math.exp(-(V + 55) / 10))
    bn = 0.125 * math.exp(-(V + 65) / 80)
    return am, bm, ah, bh, an, bn

V = -65.0
am, bm, ah, bh, an, bn = rates(V)
m, h, n = am / (am + bm), ah / (ah + bh), an / (an + bn)   # start at steady state

dt, peak, t_peak = 0.01, V, 0.0
for step in range(int(20 / dt)):                          # 20 ms
    t = step * dt
    I_stim = 20.0 if t < 1.0 else 0.0                      # 1 ms current pulse
    I_ion = (g_Na * m**3 * h * (V - E_Na) + g_K * n**4 * (V - E_K)
             + g_L * (V - E_L))
    am, bm, ah, bh, an, bn = rates(V)
    m += dt * (am * (1 - m) - bm * m)
    h += dt * (ah * (1 - h) - bh * h)
    n += dt * (an * (1 - n) - bn * n)
    V += dt * (I_stim - I_ion) / C
    if V > peak:
        peak, t_peak = V, t

print(f"peak {peak:.1f} mV at {t_peak:.2f} ms; V at 20 ms = {V:.1f} mV")
# peak 40.8 mV at 1.53 ms; V at 20 ms = -64.6 mV
```

程序用的是最简单的（欧拉）积分、很小的步长；把1 ms 刺激的幅度从20改为6 µA cm⁻²，只得到一个小小的无源鼓包，而7 µA cm⁻² 就给出完整的动作电位——这就是全或无的阈值在运行。

### 阈值与兴奋性：相平面

四变量的霍奇金-赫克斯利系统难以直观想象。理查德·菲茨休（Richard FitzHugh）1961年，以及独立工作的南云仁一（Jin-ichi Nagumo）与合作者1962年，证明其本质行为在一个两变量的漫画式模型中保存下来：快变量 $v$，同时代表膜电位与快的 $m$；慢恢复变量 $w$，同时代表 Na⁺ 失活与 K⁺ 激活。在菲茨休-南云（FitzHugh–Nagumo）模型中，

$$
\deriv{v}{t} = v - \frac{v^3}{3} - w + I, \qquad \deriv{w}{t} = 0.08\,(v + 0.7 - 0.8w),
$$

式中各量都是无量纲的。$v$ 的三次零倾线编码 Na⁺ 激活的正反馈；慢速线性恢复编码延迟的负反馈。

相平面把阈值、全或无性质与不应性变成几何事实：起点在三次曲线中间分支以左的直接返回静息，在其右的则被带着绕行完整的一圈。紧随一次冲动之后，轨迹位于慢变量的高处，在那里 $v$ 上的任何小推挤都无法越过阈值分支：这就是不应期。持续电流把三次曲线整体上移，直到静息平衡点失去稳定性、系统开始振荡，正如真实神经元在持续去极化下重复发放。

::: example 有多少 Na⁺ 进入？ {#ex-sodium}
乌贼轴突直径500 µm，内含50 mmol L⁻¹ 的 Na⁺。(a)动作电位期间每平方厘米膜要把膜电位去极化100 mV，Na⁺ 进入量最少是多少？(b)这使胞内 Na⁺ 浓度升高多少？(c)用放射性 ²⁴Na⁺ 测得约20 °C 下每次冲动进入约4 pmol cm⁻²。为什么这比最小值大？如果泵被阻断，这条轴突在胞内 Na⁺ 升高10 %之前还能传导多少次冲动？
::: solution
(a)所需电荷为 $Q = C_\mathrm{m}\Delta V = 10^{-6}\ \mathrm{F\,cm^{-2}}\times0.1\ \mathrm{V} = 10^{-7}$ C cm⁻²。除以法拉第常数，$10^{-7}/96{,}485 = 1.0\times10^{-12}$ mol cm⁻² $= 1.0$ pmol cm⁻²。

(b)半径为 $r$ 的圆柱，单位膜面积的体积为 $\pi r^2L/(2\pi rL) = r/2 = 125\ \mu\mathrm{m} = 0.0125$ cm。浓度升高为 $1.0\times10^{-12}\ \mathrm{mol}/0.0125\ \mathrm{cm^3} = 8\times10^{-11}$ mol cm⁻³ $= 8\times10^{-8}$ mol L⁻¹，即0.08 µmol L⁻¹，约为原有50 mmol L⁻¹ 的百万分之二。

(c)真实冲动期间，Na⁺ 与 K⁺ 电导在时间上重叠，因此一部分 Na⁺ 内流被同时发生的 K⁺ 外流抵消，对电容充电没有贡献。（在18.5 °C 下模拟[[#prop-hh]]得到约4 pmol cm⁻²，是最小值的四倍。）按每次冲动4 pmol cm⁻² 计，每次冲动使胞内 Na⁺ 升高 $4\times10^{-12}/0.0125 = 3.2\times10^{-10}$ mol cm⁻³ $= 0.32$ µmol L⁻¹。升高10 %，即5 mmol L⁻¹，需要 $5\times10^{-3}/3.2\times10^{-7} \approx 16{,}000$ 次冲动。这就是为什么泵被毒素阻断的巨轴突仍能传导几万次冲动；而很细的哺乳动物轴突，单位面积的体积小得多，耗尽得快得多。
:::
:::

::: warning “动作电位由钠泵产生”与“离子大量涌入涌出”
泵不产生动作电位；动作电位是离子顺泵预先建立好的梯度、经电压门控通道被动流动产生的。阻断泵之后，大轴突里的冲动在成千上万次之内不受影响。离子也谈不上“涌入涌出”：正如[[#ex-sodium]]所示，单次冲动中的浓度变化微乎其微。变化的是电导，以及随之而来的电压。第二个错误是以为峰值时电位达到 $E_\mathrm{Na}$；其实它差得还远，因为失活与 K⁺ 激活在峰值之前就已开始。
:::

## 方程背后的通道

霍奇金与赫克斯利的颗粒是抽象物，却意味着具体的预言。如果门控由在膜电场中移动的带电颗粒控制，它们的移动应当产生自己的微小电流。克莱·阿姆斯特朗（Clay Armstrong）与弗朗西斯科·贝扎尼利亚（Francisco Bezanilla）1973年在乌贼轴突中检测到了这些**门控电流**。而如果电导来自分立的通道，它的变化就应是一份一份的。埃尔温·内尔（Erwin Neher）与伯特·萨克曼（Bert Sakmann）的膜片钳（1976）恰恰展示了这一点：单个电压门控通道在关闭与开放状态间闪动，开放时通过约一个皮安的电流，而电压钳中平滑的宏观电流，是几千个这类随机事件的平均。

::: definition 电压门控离子通道 {#def-channels}
**电压门控 K⁺（Kv）通道**是四个亚基的四聚体，每个亚基有六个跨膜节段（S1–S6）。全部四个亚基的 S5、S6 节段及其间的环共同围成中央孔道和它的**选择性滤器**；每个亚基的 S1–S4 节段构成**电压感应结构域**，其中 S4 每隔一个残基就带一个正电荷残基（精氨酸或赖氨酸）。**电压门控 Na⁺（Nav）与 Ca²⁺（Cav）通道**构型相同，只是四个结构域串联在一条长多肽上。去极化使 S4 节段向外移动，这一移动耦联到孔道胞质端闸门的开放。
:::

第一个序列来自电鳗发电器官的 Na⁺ 通道，由野田（Masaharu Noda）与水野昭一（Shosaku Numa）及合作者于1984年克隆。第一个 K⁺ 通道来自果蝇 *Drosophila*：携带 *Shaker* 突变的果蝇在乙醚麻醉下会抖动腿部，该基因1987年由简莉莉（Lily Jan）与简育农（Yuh Nung Jan）实验室以及马克·塔努耶（Mark Tanouye）克隆。罗德里克·麦金农（Roderick MacKinnon）团队1998年解析的细菌 K⁺ 通道 KcsA 结构，说明了选择性滤器的工作原理：一圈羰基氧，其间距模拟脱去水化层 K⁺ 周围的水分子，于是 K⁺ 能以很小的能量代价放掉水壳，而更小的 Na⁺ 却得不到同样好的配位。2005年，哺乳动物 Kv 通道的结构接踵而来。

失活也有其结构。1973年，阿姆斯特朗、贝扎尼利亚与爱德华多·罗哈斯（Eduardo Rojas）证明，把蛋白酶链霉蛋白酶（pronase）施加到乌贼轴突内部，会消除 Na⁺ 失活而不影响激活：失活是独立的过程，与独立的 $h$ 颗粒相吻合；1977年，阿姆斯特朗与贝扎尼利亚提出，失活由一个拴在通道上的颗粒从内侧堵住开放通道所致。在会失活的 *Shaker* K⁺ 通道中，星敏昭（Toshinori Hoshi）、威廉·扎戈塔（William Zagotta）与理查德·奥尔德里奇（Richard Aldrich）（1990）证明，删除每个亚基最前约二十个氨基酸会消除快失活，而把这段肽重新加回内侧又能恢复失活。这就是**球-链**（ball-and-chain）机制：一段拴系的肽摆进开放的孔道把它堵住。在 Na⁺ 通道中，结构域 III 与 IV 之间一段含三个疏水残基（IFM）的短胞质环起类似作用。

::: warning “每个 Na⁺ 通道有三个 m 门和一个 h 门”
$m^3h$ 与 $n^4$ 的表述与数据吻合得很好，带四个电压感应器的四聚体 K⁺ 通道也给 $n^4$ 提供了一个令人愉悦的物理学对应物。但细节并非照字面成立。一个通道的各电压感应器并不完全独立；Na⁺ 通道失活与激活相耦联而非彼此独立（通道主要在感应器移动之后、且常常从开放状态进入失活）；真实通道的状态也比模型中的颗粒多。霍奇金-赫克斯利模型是极为出色的现象学描述，而现代通道模型是带显式关闭、开放与失活状态的动力学方案（马尔可夫模型）。
:::

乌贼轴突只用两种电压门控通道，大多数神经元用的多得多。哺乳动物有九个 Nav α亚基基因和约四十个 Kv 基因，外加 Ca²⁺ 通道、Ca²⁺ 激活 K⁺ 通道、超极化激活（HCN）通道等。它们的组合塑造每个神经元的放电模式：规则、爆发、快速放电或适应放电。有些细胞干脆用别的离子产生动作电位：螯虾与藤壶的肌纤维产生 Ca²⁺ 动作电位（保罗·法特（Paul Fatt）与伯纳德·金斯堡（Bernard Ginsborg），1958；萩原通（Susumu Hagiwara）及合作者，1960年代），轮藻 *Chara* 的巨细胞产生由 Ca²⁺ 内流触发 Cl⁻ 外流携带的慢动作电位。与乌贼轴突不同，哺乳动物轴突在时间上把 Na⁺ 与 K⁺ 电流分得更干净，从而每次冲动浪费更少 Na⁺——一种省能的改进。

::: application 毒素与通道的研究
许多动物利用靶向电压门控通道的毒素御敌或制服猎物：河豚与某些蝾螈的河豚毒素，甲藻的石房蛤毒素（saxitoxin），以及芋螺、蝎和蜘蛛中种类繁多的肽类毒素。因为结合得极其特异，这些分子成了纯化、计数和定位通道所用的工具。局部麻醉药的作用机制是从内侧阻断 Na⁺ 通道，而若干遗传性人类肌肉、心脏和脑疾病由通道基因突变引起。其临床方面见[医学图谱：神经肌肉疾病](/learn/medicine/lesson.php?c=nervous-system&l=neuromuscular)和[医学图谱：癫痫](/learn/medicine/lesson.php?c=nervous-system&l=epilepsy)。
:::

## 沿轴突的传导

轴突某处的动作电位通过无源电流流动使邻近膜去极化。电流在活跃区进入轴突内部，沿两个方向流动，从前方的膜流出，使之去极化。当那份去极化达到阈值，邻近膜就发放，如此下去。冲动不会倒退着跑，因为它身后的膜处于不应期。

无源电流能扩布多远？把轴突当作一根长圆柱——一条**电缆**——其核心沿长度方向单位长度的电阻为 $r_\mathrm{i}$，膜的性质由乘以单位长度的膜电阻 $r_\mathrm{m}$（也就是说，一段长度的膜电阻等于 $r_\mathrm{m}$ 除以该长度）和每单位长度电容 $c_\mathrm{m}$ 描述。

::: proposition 电缆上的无源扩布 {#prop-cable}
对半径为 $a$ 的轴突或树突，设单位面积膜电阻为 $R_\mathrm{m}$（Ω cm²）、胞质电阻率为 $R_\mathrm{i}$（Ω cm），则单位长度参数为 $r_\mathrm{m} = R_\mathrm{m}/2\pi a$、$r_\mathrm{i} = R_\mathrm{i}/\pi a^2$。电压 $V(x, t)$（偏离静息值的量）服从**电缆方程**

$$
\lambda^2\frac{\partial^2V}{\partial x^2} = \tau\frac{\partial V}{\partial t} + V, \qquad \lambda = \sqrt{\frac{r_\mathrm{m}}{r_\mathrm{i}}} = \sqrt{\frac{R_\mathrm{m}\,a}{2R_\mathrm{i}}}, \qquad \tau = R_\mathrm{m}C_\mathrm{m}.
$$ {#eq-cable}

稳态下，在无限长电缆某点维持的电压 $V_0$ 随距离按

$$
V(x) = V_0\,\mathrm{e}^{-\lvert x\rvert/\lambda}.
$$ {#eq-decay}

**长度常数** $\lambda$ 随半径的平方根增长。假设：均匀被动膜（无电压门控通道）；均匀圆柱；轴突外电阻可忽略。
:::

::: proof {collapsed}
考虑一段长 $\Delta x$ 的小柱段。沿核心的欧姆定律给出 $\partial V/\partial x = -r_\mathrm{i}\,i_\mathrm{i}$，其中 $i_\mathrm{i}$ 是轴向电流。电流守恒说，柱段上损失的轴向电流从膜流出，成为电容电流加电阻电流：$-\partial i_\mathrm{i}/\partial x = c_\mathrm{m}\,\partial V/\partial t + V/r_\mathrm{m}$。把第一个关系式求导并代入，得 $(1/r_\mathrm{i})\,\partial^2V/\partial x^2 = c_\mathrm{m}\,\partial V/\partial t + V/r_\mathrm{m}$。乘以 $r_\mathrm{m}$ 即得[[#eq-cable]]，其中 $\lambda^2 = r_\mathrm{m}/r_\mathrm{i}$、$\tau = r_\mathrm{m}c_\mathrm{m} = R_\mathrm{m}C_\mathrm{m}$。稳态下时间导数为零，剩下 $\lambda^2V'' = V$，其在无穷远处有界的解就是[[#eq-decay]]。代入单位长度参数得 $\lambda^2 = (R_\mathrm{m}/2\pi a)/(R_\mathrm{i}/\pi a^2) = R_\mathrm{m}a/2R_\mathrm{i}$。
:::

电缆理论是威廉·汤姆孙（William Thomson，即后来的开尔文勋爵）1855年为跨大西洋电报电缆建立的；霍奇金与威廉·拉什顿（William Rushton）把它应用于神经，并于1946年测得龙虾轴突的长度常数。

::: example 轴突与树突的长度常数 {#ex-lambda}
(a)乌贼巨轴突半径238 µm，$R_\mathrm{i} = 35.4\ \Omega$ cm，静息膜电导0.68 mS cm⁻²（$R_\mathrm{m} = 1470\ \Omega\,\mathrm{cm^2}$）。计算 $\lambda$。(b)一条哺乳动物树突直径1 µm，$R_\mathrm{m} = 20{,}000\ \Omega\,\mathrm{cm^2}$，$R_\mathrm{i} = 150\ \Omega$ cm。计算 $\lambda$，并求一个稳态突触去极化传到200 µm 外胞体的比例，把树突当作无限长处理。
::: solution
(a)$\lambda = \sqrt{1470\times0.0238/(2\times35.4)} = \sqrt{0.494}$ cm $= 0.70$ cm，约7 mm。

(b)$a = 0.5\ \mu\mathrm{m} = 5\times10^{-5}$ cm，故 $\lambda = \sqrt{20{,}000\times5\times10^{-5}/300} = \sqrt{3.33\times10^{-3}}$ cm $= 0.058$ cm $= 577$ µm。在200 µm 处，$\mathrm{e}^{-200/577} = 0.71$，所以约70 %的稳态去极化能到达胞体。短暂突触电位比稳态电位衰减得更多，因为膜电容会滤掉快信号；而真实的树突有分支、有末端，与无限长电缆行为不同。尽管如此，这一计算仍说明了为什么无源扩布在几百微米长的树突树内可行，沿一米长的轴突却不行：经过1 m 之后，$\mathrm{e}^{-1/0.0058}$ 实际上为零。远距离信号必须是再生性的。
:::
:::

冲动传多快？严格的答案要在电缆上求解完整的霍奇金-赫克斯利方程，但一个标度论证就能给出关键结果。

::: proposition 无髓轴突的传导速度 {#prop-velocity}
对膜性质与胞质相同的无髓轴突，传导速度 $\theta$ 与直径的平方根成正比：

$$
\theta \propto \sqrt{a}.
$$

理由：冲动每前进一步，距离正比于长度常数 $\lambda \propto \sqrt{a}$，而所需时间由膜自身的动力学和时间常数决定，二者都不依赖直径。假设：几何相似的轴突；单位面积通道密度与动力学相同；$R_\mathrm{i}$ 与 $C_\mathrm{m}$ 相同。
:::

平方根律解释了乌贼、螯虾和蚯蚓携带逃跑信号的巨大轴突：速度用直径来买，代价却昂贵。速度加倍，轴突须粗到四倍，横截面积增大到十六倍。直径约0.5 mm 的乌贼巨轴突在海水温度下以约20 m s⁻¹ 传导；直径约1 µm 的哺乳动物无髓 C 纤维在体温下以约1 m s⁻¹ 传导。

### 髓鞘与跳跃传导

脊椎动物找到了更好的办法。髓鞘（[[neuroscience/neurons-glia#def-myelin]]）用许多层膜把轴突包裹起来，用电缆的语言说，就是把 $r_\mathrm{m}$ 乘以层数、把 $c_\mathrm{m}$ 除以大致相同的倍数。鞘下几乎不漏电流，也几乎不耗电给膜充电，所以从一个朗飞结出发的无源扩布到达0.2–2 mm 外的下一个结，几乎不衰减，而且非常快。电压门控 Na⁺ 通道在结处富集，密度达每 µm² 约1000个，冲动只在结处再生。它看起来是从一个结跳到下一个结：**跳跃传导**，由拉丁语 *saltare*（跳跃）得名。田崎一二（Ichiji Tasaki）1939年在单根蛙神经纤维上证明了这一点，赫克斯利与罗伯特·斯坦普夫利（Robert Stämpfli）1949年用电流测量证实了它。

跳跃传导改变了标度律。节间段长度与纤维直径成正比，速度近似也如此。约瑟夫·赫什（Joseph Hursh）1939年在猫神经中发现，传导速度（米每秒）约为纤维外径（微米）的六倍。因此10 µm 的纤维以约60 m s⁻¹ 传导，而最大的哺乳动物纤维约20 µm，以约120 m s⁻¹ 传导。

鞘该有多厚？对外径 $D$ 固定的纤维，鞘越厚绝缘越好，但留给轴突的空间越小，其核心电阻随之上升。

::: proposition 最优 g-ratio {#prop-gratio}
考虑外径为 $D$、轴突直径 $d = gD$ 的有髓纤维。设给下一个结充电的时间正比于节间段的轴向电阻 $r_\mathrm{i}L \propto L/d^2$ 与其髓鞘电容 $c L$ 之积，其中对厚圆柱绝缘体有 $c \propto 1/\ln(D/d)$，又设节间段长 $L$ 与 $D$ 成正比。则速度 $\theta = L/t$ 满足

$$
\theta \propto D\,g^2\ln\frac{1}{g},
$$ {#eq-gratio}

对固定的 $D$，当 $g = \mathrm{e}^{-1/2} \approx 0.61$ 时它最大。

假设：传导时间由节间段的充电主导；结的性质与节间段长度按所述标度；髓鞘足够厚，可当作同轴绝缘体处理。威廉·拉什顿（William Rushton）（1951）用略不同的论证得到了同样的最优值。
:::

::: proof
由 $r_\mathrm{i} \propto 1/d^2$、$c \propto 1/\ln(1/g)$、$L \propto D$，充电时间 $t \propto r_\mathrm{i}c L^2 \propto D^2/[d^2\ln(1/g)]$，故 $\theta = L/t \propto D\,d^2\ln(1/g)/D^2 = D\,g^2\ln(1/g)$。对 $f(g) = g^2\ln(1/g) = -g^2\ln g$ 求导，得 $f'(g) = -2g\ln g - g = -g(2\ln g + 1)$，在 $\ln g = -1/2$ 处为零。由于 $f$ 在 $g \to 0$ 和 $g = 1$ 处为零、在两者之间为正，这就是最大值。
:::

曲线在最大值附近很平，所以预言是一个宽区间而非一个尖锐的数值，而许多周围神经中实测的 g-ratio（约0.6–0.7）正落在其中。这一符合令人鼓舞，但如此简单的模型不能解释一切：中枢纤维的髓鞘往往比速度最优值更薄，或许因为髓鞘在拥挤的脑中无论在代谢上还是体积上都很昂贵。

::: example 反射弧 {#ex-reflex}
在腱反射中，外径约15 µm 的感觉纤维把冲动从肌肉传导0.8 m 到脊髓，约12 µm 的运动纤维再把它们传回0.8 m。用赫什每 µm 对应6 m s⁻¹ 的系数，并给脊髓内的突触传递和神经-肌肉接头各留1 ms，估计叩击肌腱与肌肉电反应开始之间的延迟。如果两条通路都是传导速度1 m s⁻¹ 的无髓 C 纤维，要多花多少时间？
::: solution
感觉速度 $6\times15 = 90$ m s⁻¹：$0.8/90 = 8.9$ ms。运动速度 $6\times12 = 72$ m s⁻¹：$0.8/72 = 11.1$ ms。合计 $8.9 + 11.1 + 1 + 1 = 22$ ms，与成人膝跳反射实测的潜伏期（约20 ms）很接近，后者还包括感受器发火的时间。换成 C 纤维，两次行程各需 $0.8/1 = 0.8$ s，反射延迟约1.6 s，对姿势的快速控制毫无用处。反射回路本身是[[neuroscience/motor-systems]]的主题。
:::
:::

::: quiz
哪种改变会增大无髓轴突的长度常数？
- [ ] 让膜上开放更多 K⁺ 漏通道。
- [x] 把直径加倍。
- [ ] 增大膜电容。
- [ ] 增大胞质的电阻率。
::: solution
由[[#eq-cable]]，$\lambda = \sqrt{R_\mathrm{m}a/2R_\mathrm{i}}$。半径加倍使 $\lambda$ 增大到 $\sqrt2$ 倍。开放漏通道会降低 $R_\mathrm{m}$、缩短 $\lambda$；胞质电阻率升高同样使其缩短。电容根本不出现在稳态长度常数里；它影响时间过程（通过 $\tau$）、会减慢传导，但不影响随距离的稳态衰减。
:::
:::

### 温度与传导

霍奇金-赫克斯利速率常数每升高10 °C 增为三倍。在温暖条件下通道开关更快，动作电位变得更短促，传导随之加快，这是哺乳动物和鸟类的冲动传导快于同等体型变温动物的原因之一。然而温度超过某值，动作电位反而失败：K⁺ 电导上升太快，在越过阈值之前就掐断了 Na⁺ 上升支。反之，降温使传导变慢直至阻断，这就是冷天手指笨拙的原因。

::: history
路易吉·伽伐尼（Galvani）1791年证明蛙的神经和肌肉会对电作出反应；埃米尔·杜布瓦-雷蒙（du Bois-Reymond）在1840年代记录了神经电流的“负性变化”；赫尔曼·冯·亥姆霍兹（Helmholtz）1850年测得蛙神经的传导速度约30 m s⁻¹，表明神经信号并非瞬时；阿德里安（Adrian）在1920年代用单根感觉纤维确立了冲动的全或无性质；约翰·扎卡里·杨（John Zachary Young）1936年把乌贼巨轴突引入为实验标本。霍奇金与赫克斯利1939年记录到后电位；霍奇金与卡茨1949年提出钠假说；霍奇金与赫克斯利1952年发表于 *Journal of Physiology* 的五篇论文给出了电压钳分析与模型。霍奇金、赫克斯利与埃克尔斯（Eccles）分享1963年诺贝尔生理学或医学奖。田崎（Tasaki）（1939）以及赫克斯利与斯坦普夫利（Stämpfli）（1949）确立了跳跃传导。阿姆斯特朗（Armstrong）与贝扎尼利亚（Bezanilla）1973年测出门控电流，内尔（Neher）与萨克曼（Sakmann）1976年记录到单通道电流（1991年诺贝尔奖），野田（Noda）与水野（Numa）1984年克隆了 Na⁺ 通道，麦金农（MacKinnon）团队1998年解析了 K⁺ 通道结构（2003年诺贝尔化学奖）。
:::

## 由此引向何处

动作电位到达轴突终末时，打开电压门控 Ca²⁺ 通道，进入的 Ca²⁺ 触发递质释放。这是[[neuroscience/synapses]]的主题。电缆方程也将在那里重现，用以说明突触电位如何扩布过树突，并在下一个动作电位起始的轴突起始段被求和。

::: summary
- 动作电位是一次阈化的、全或无的、再生性的膜电位反转（≈ 100 mV，≈ 1 ms），随后是后超极化与不应期。
- 电压钳（科尔、霍奇金、赫克斯利、卡茨）分离出早期的、会失活的 Na⁺ 电流与延迟的、持续的 K⁺ 电流。
- 霍奇金-赫克斯利模型 $C\,\dd V/\dd t = I - \bar g_\mathrm{Na}m^3h(V - E_\mathrm{Na}) - \bar g_\mathrm{K}n^4(V - E_\mathrm{K}) - g_\mathrm{L}(V - E_\mathrm{L})$ 配以一阶门控，仅凭电压钳数据就再现了冲动及其速度。
- 上升支是经 Na⁺ 激活的正反馈；复极化是经 Na⁺ 失活与 K⁺ 激活的延迟负反馈；不应性就是恢复所需的时间。
- 电压门控通道围绕中央孔道有四个带电荷 S4 段的电压感应结构域；K⁺ 选择性来自一个羰基氧滤器；失活是独立的过程，呈球-链或铰链盖式机制。
- 无源扩布按长度常数 $\lambda = \sqrt{R_\mathrm{m}a/2R_\mathrm{i}}$ 衰减（大轴突中为毫米，树突中为几百微米），所以远距离信号必须再生。
- 无髓传导速度按 $\sqrt{\text{直径}}$ 标度；有髓的跳跃传导大致线性标度（哺乳动物约每 µm 纤维直径6 m s⁻¹），最优 g-ratio 在0.6附近。
:::

## 习题

::: exercise 一次冲动的代价 {level=1 check="0.6"}
某神经元的膜在冲动期间须去极化60 mV，设 $C_\mathrm{m} = 1\ \mu\mathrm{F\,cm^{-2}}$。Na⁺ 内流量最少是多少 pmol cm⁻²（保留一位有效数字）？
::: solution
$Q = 10^{-6}\times0.060 = 6\times10^{-8}$ C cm⁻²；$6\times10^{-8}/96{,}485 = 6.2\times10^{-13}$ mol cm⁻² $\approx 0.6$ pmol cm⁻²。
:::
:::

::: exercise 传导速度的标度 {level=1 check="4"}
一条直径4 µm 的无髓轴突以2 m s⁻¹ 传导。设 $\theta \propto \sqrt{d}$，要把传导速度加倍，直径须乘以几？
::: solution
$\theta \propto \sqrt d$，故 $\theta$ 加倍要求 $d$ 乘以 $2^2 = 4$，得16 µm。
:::
:::

::: exercise 稳态与时间常数 {level=1}
用[[#def-gating]]解释：为什么某电压下 $\alpha = 3$ ms⁻¹、$\beta = 1$ ms⁻¹ 的门控变量在稳态达到其最大值的0.75，并求它从0出发走完余程63 %需要多久。
::: solution
$x_\infty = \alpha/(\alpha + \beta) = 3/4 = 0.75$，$\tau = 1/(\alpha + \beta) = 0.25$ ms。从0出发，$x(t) = 0.75(1 - \mathrm{e}^{-t/\tau})$，经一个时间常数——0.25 ms——达到0.75的63 %（即0.47）。
:::
:::

::: exercise 一根长树突 {level=2 check="0.42"}
对[[#ex-lambda]]中的树突（$\lambda = 577$ µm），距施加处500 µm 处还剩下稳态去极化的几分之几（保留两位小数）？如果树突直径不是1 µm 而是4 µm，这个分数会是多少？
::: solution
$\mathrm{e}^{-500/577} = \mathrm{e}^{-0.867} = 0.42$。直径增大四倍使 $\lambda$ 翻倍到1155 µm，得 $\mathrm{e}^{-500/1155} = 0.65$。
:::
:::

::: exercise 解读电压钳实验 {level=2}
乌贼轴突被电压钳制，从−65 mV 阶跃到0 mV。(a)描述正常海水中记录到的电流。(b)加入 TTX 后会记录到什么？(c)不加 TTX，但更换胞外 Na⁺ 使 $E_\mathrm{Na}$ 变为0 mV 呢？(d)正常海水（$E_\mathrm{Na} = +50$ mV）中向 +60 mV 的阶跃给出的是一小份早期**外向**电流而非内向电流。解释之。
::: solution
(a)一小段电容瞬变，然后是约半毫秒达峰、几毫秒内衰减的早期内向电流（Na⁺ 激活并失活），随后是 S 形上升到持续平台的延迟外向电流（K⁺）。(b)TTX 消除早期内向电流，只留下延迟外向 K⁺ 电流。(c)当 $V = E_\mathrm{Na}$，Na⁺ 的驱动力为零，所以即使 Na⁺ 通道开放也没有 Na⁺ 电流，只看到外向 K⁺ 电流。这正是霍奇金与赫克斯利分离 K⁺ 电流的办法。(d)+60 mV 时膜内比 $E_\mathrm{Na}$ 更正，驱动力 $V - E_\mathrm{Na}$ 为正，Na⁺ 经开放通道**流出**：早期电流在 $E_\mathrm{Na}$ 处反向，这是它由 Na⁺ 携带的有力证据。
:::
:::

::: exercise 不应性与最大发放率 {level=2}
某哺乳动物轴突的绝对不应期为0.8 ms，相对不应期再持续3 ms。(a)理论最大发放率是多少？(b)为什么神经元很少长时间以此速率发放？(c)用门控变量解释相对不应期为何存在。
::: solution
(a)每0.8 ms 至多一次冲动，约1250 s⁻¹。(b)在这种速率下，每次冲动都落在前一次冲动的相对不应期内，需要更强的刺激、产生更小的冲动；Na⁺ 通道积累在失活状态，胞内 Na⁺ 和胞外 K⁺ 积累，终末的递质释放也会衰减。持续的发放率以每秒几百次为实际上限，而且只有特化的神经元能做到。(c)一次冲动之后 $h$ 偏低（许多 Na⁺ 通道失活）、$n$ 偏高（额外的 K⁺ 电导）。两者都要几毫秒才回到静息值。在此之前，可开放的 Na⁺ 通道更少，更多的外向 K⁺ 电流对抗去极化，因此需要更大的刺激才能达到内向电流超过外向电流的那一点。
:::
:::

::: exercise 有髓与无髓 {level=2}
某哺乳动物有髓轴突外径2 µm；一条直径2 µm 的无髓轴突以1.4 m s⁻¹ 传导。(a)估计有髓纤维的速度。(b)估计无髓轴突要与它有相同速度需要多粗。(c)解释为什么在很小直径（大约小于0.2–1 µm）时，无髓轴突反而是更好的设计。
::: solution
(a)$6\times2 = 12$ m s⁻¹。(b)由 $\theta \propto \sqrt d$，$(12/1.4)^2 = 73$，故约需 $2\times73 \approx 150$ µm。(c)纤维变细时，髓鞘占横截面的份额越来越大，结无法按比例缩小，节间段变得非常短，于是跳跃传导的优势减弱；低于一个交叉直径——拉什顿理论估计约1 µm，后来的工作估计约0.2 µm——同样总直径的无髓轴突传导至少一样快甚至更快。这就是哺乳动物中最细的轴突，如许多 C 纤维和小脑平行纤维，无髓鞘的原因。
:::
:::

::: exercise 温度与动作电位 {level=3 check="7.6"}
霍奇金-赫克斯利速率常数的 $Q_{10}$ 为3。(a)把一个在18.5 °C 下给出参数的乌贼轴突模型升温到37 °C，所有速率乘以几（保留一位小数）？(b)若18.5 °C 下动作电位持续约0.5 ms，其他条件不变，37 °C 下大约持续多久？(c)真实哺乳动物动作电位在37 °C 下持续约0.3–1 ms。这说明哺乳动物的通道与乌贼的通道相比如何？
::: solution
(a)$3^{(37 - 18.5)/10} = 3^{1.85} = 7.6$。(b)所有时间尺度按同一因子缩短，故约 $0.5/7.6 \approx 0.07$ ms。实际上乌贼模型在此温度下无法发放，因为 K⁺ 激活追上了 Na⁺ 激活。(c)哺乳动物的通道不是简单地在高温下运行的乌贼通道：在给定温度下它们的动力学更慢，与体温相匹配，其 Nav 与 Kv 亚型的特定组合产生在37 °C 下时长合适的动作电位。温度依赖性还解释了为什么适应不同温度的变温动物会改变其通道表达。
:::
:::

::: exercise 从方程看阈值 {level=3}
在霍奇金-赫克斯利模型的静息电位处，电导为 $g_\mathrm{Na} \approx 0.011$、$g_\mathrm{K} \approx 0.37$、$g_\mathrm{L} = 0.3$ mS cm⁻²。(a)用弦电导方程核实静息电位约为−65 mV。(b)短时1 ms、6 µA cm⁻² 的电流脉冲不能使模型发放，7 µA cm⁻² 的可以。忽略脉冲期间的离子电流，估计每个脉冲结束时达到的去极化。(c)定性解释为什么阈值不是固定电压，而取决于膜被去极化得多快。
::: solution
(a)$V = (0.011\times50 + 0.37\times(-77) + 0.3\times(-54.4))/(0.011 + 0.37 + 0.3) = (0.55 - 28.49 - 16.32)/0.681 = -44.26/0.681 = -65.0$ mV。

(b)注入电荷 $= I\times t$：6 nC cm⁻² 与7 nC cm⁻²，除以1 µF cm⁻² 得6和7 mV。因此1 ms 脉冲的阈值对应从静息起约6–7 mV 的去极化，即到约−58 mV。（脉冲期间的离子电流会使实际去极化略小。）

(c)在阈值处，Na⁺ 内向电流必须跑赢 K⁺ 与漏电的外向电流。缓慢的去极化让 $h$ 有时间下降（失活）、$n$ 有时间上升，而 $m$ 还没做什么，因此需要更大的去极化，或者无论多大都不够：缓慢上升的电流可以完全不能使神经元发放（**适应**，accommodation）。快速的去极化则让 $m$ 抢在 $h$ 与 $n$ 之前。阈值是动力学的一种性质——菲茨休-南云图中相平面里的那条分界——不是电压轴上的一个固定数字。
:::
