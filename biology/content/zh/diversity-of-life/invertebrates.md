迄今已描述的动物约 150 万种（Zhi-Qiang Zhang 2013 年统计为 1,552,319 种），其中约 97 % 是**无脊椎动物（invertebrates）**——没有脊柱的动物。已描述动物种的五分之四是节肢动物，绝大多数是昆虫；但无脊椎动物还包括：一天过滤自身水量数千倍的海绵、建造从太空可见的珊瑚礁的珊瑚、能从一段碎片再生出完整个体的扁形动物、翻动土壤的蚯蚓、拥有五亿个神经元的章鱼，以及其幼虫帮助创立了发育生物学的海胆。"无脊椎动物"不是一个自然类群——它的意思是"除脊索动物一个亚门之外的所有动物"，是一个并系的等级类群（grade）——但用来划分这个庞大课题却很便利。

本章的组织性思想是**体型模式（body plan）**：一个门的成员共有的基本构造——对称方式、胚层、体腔、分节、骨骼。我们先定义动物，勾勒 2020 年代中期动物各门之树的概貌，包括哪一支最先分出的未决问题；然后依次考察各主要门，从海绵、栉水母和刺胞动物，经原口动物（软体动物、环节动物、扁形动物、线虫、节肢动物）到棘皮动物，最后以寒武纪大爆发收束，衔接 [[evolution/macroevolution]]。有两条物理学线索贯穿全章：扩散如何限定没有循环系统的动物的体型大小与形状，以及节肢动物如何靠蜕皮生长。体型模式的发育见 [[developmental-biology]]。

## 什么是动物？

::: definition 动物（后生动物，Metazoa） {#def-metazoa}
**动物（Animals，后生动物 Metazoa）**是后鞭毛生物（Opisthokonta，[[diversity-of-life/protists#def-supergroups]]）内一个多细胞、异养真核生物的进化枝，现生最近的亲戚是领鞭毛虫。其共有衍征包括富含**胶原蛋白**的细胞外基质；细胞—细胞连接，且多数具**上皮**（附着于基膜上的极性细胞层）；发育自**囊胚**；生活史中唯一的多细胞阶段是二倍体，减数分裂直接产生**配子**（一条具单根后生鞭毛的小型可游动精子，和一个大卵）。多数动物摄取食物并在体内消化，多数有**肌肉**细胞与**神经**细胞。
:::

动物进化自类似领鞭毛虫的群体祖先。分子钟把冠群动物的起源放在成冰纪或托诺纪，约 6.5–8.5 亿年前（Mario dos Reis 及同事，2015），但不确定性很大；公认最老的动物化石在埃迪卡拉纪，约 5.7 亿年前。*Dickinsonia* 是一种扁平、体表具垫缝状纹理的埃迪卡拉纪生物，可长到一米，当 Ilya Bobrovskiy 及同事（2018）从其有机质保存的化石中萃取出胆甾烷类分子——动物特有的甾醇——之后被确认为动物。

### 体型模式的词汇

::: definition 对称、胚层与体腔 {#def-bodyplan}
- **对称方式**：**不对称**的身体没有对称面（多数海绵）；**辐射对称**的身体有众多穿过中央口—反口轴的对称面（刺胞动物；棘皮动物成体为五辐射对称）；**两侧对称**的身体只有一个把身体分为左右镜像两半的对称面，前后、背腹分明。
- **胚层**：胚胎中细胞形成外层**外胚层**、衬于消化腔的内层**内胚层**，在**三胚层**动物还有中层**中胚层**，形成肌肉、结缔组织，在许多类群还形成循环与排泄器官。刺胞动物与栉水母动物通常被称为**二胚层**（只有外胚层与内胚层，中间一层主要是非细胞的中胶层）。
- **体腔**：**无体腔**动物在消化管与体壁之间是实心组织（扁形动物）；**假体腔**动物在中胚层与内胚层之间有一个充满液体的腔（线虫、轮虫）；**真体腔**动物的腔完全由中胚层衬里，即**真体腔（coelom）**（环节动物、软体动物、节肢动物中已退化、棘皮动物、脊索动物）。
:::

体腔及其液体在力学上至关重要。一个被肌肉包围的封闭充液腔就是一个**静水骨骼（水骨骼）**：液体不可压缩，环肌收缩使一个体节变长，纵肌收缩使它变短变粗。蚯蚓靠这样的收缩波沿分节的体腔向后传递而爬行；海葵靠同样机制伸展身体。

::: example 静水骨骼的工作原理 {#ex-hydrostatic}
把蚯蚓的一个体节视为体积固定为 $V = \pi r^2\ell$ 的圆柱（体腔液不可压缩，体节被隔膜与相邻体节隔开）。(a) 若环肌收缩使半径减小 20 %，体节长度增加多少？(b) 若纵肌随后把它缩回原长，半径是多少？
::: solution
(a) $V$ 固定时 $\ell \propto 1/r^2$。把 $r$ 减到 $0.8r$ 使 $\ell$ 乘以 $1/0.8^2 = 1.5625$：体节变长 56 %。轻微的一"挤"产生大得多的伸长，虫体就是靠此把前端推进土中。

(b) 缩回原长即回到原半径，因为 $r \propto 1/\sqrt{\ell}$：体节重新变粗，抵住洞穴壁固定自身（并借助刚毛，chaetae），同时下一个体节伸长。分节使每段能独立完成这一动作，于是"细长"与"短粗"相间的收缩波沿身体向后传递（蠕动）。若动物不分节，挤压一处会把液体推向其他所有部位。
:::
:::

静水骨骼、外骨骼（节肢动物、软体动物的壳）与内骨骼（棘皮动物的骨片、脊椎动物的骨）是传递肌肉力的同一个问题的三种解法。

::: warning "体型模式是从简单到复杂的阶梯"
教科书曾把各门排成一个序列——先无体腔，再假体腔，再真体腔——仿佛每一级都是通向高等动物的一步。分子系统发育树打破了这个序列。无体腔的扁形动物不是原始两侧对称动物，而是螺旋动物成员，与真体腔的环节动物和软体动物近缘，其实心的身体很可能是次生获得的；假体腔的线虫与轮虫属于两个不同的分支；体腔也可能出现过不止一次，或曾多次丢失。体腔类型是有用的描述，但不是可靠的亲缘关系指南。同样，海绵不是"失败"的动物，而是一个成功谱系，约 9,000 个种，从成冰纪或埃迪卡拉纪起一直过滤海水。
:::

## 动物之树

1995–2010 年间，核糖体 RNA 及此后的系统发育基因组学数据彻底改变了动物系统发育学。截至 2026 年，当前之树的主要特征如下：

- **第一波分歧。**不是海绵（Porifera，多孔动物）就是栉水母（Ctenophora）是所有其他动物的姊妹群。栉水母有神经、肌肉和完全的消化管，海绵三者皆无，所以答案事关神经系统究竟是在动物共同祖先中进化一次而后在海绵中丢失，还是独立进化了两次。序列数据的分析长期不一致，对模型和类群取样都很敏感；2023 年 Darrin Schultz 及同事用了另一类性状——**基因连锁群（共线性，synteny）**在染色体间的保守性，包括海绵与其他动物共有而栉水母没有的罕见不可逆染色体融合——结果有力支持**栉水母是所有其他动物的姊妹群**。这目前是主流假说，但未被普遍接受。
- **扁盘动物**（Placozoa，*Trichoplax adhaerens* 及其近亲）——由几千个细胞、寥寥数种细胞类型构成的扁平薄片——与**刺胞动物**在此之后连同**两侧对称动物**（Bilateria）相继分出。
- **两侧对称动物**分为 **Xenacoelomorpha**（小型蠕虫，无完消化管；它们是其他两侧对称动物的姊妹群，还是应归入后口动物，仍有争论）与 **Nephrozoa**，后者分为原口动物与后口动物。
- **原口动物**包含两大进化枝：**蜕皮动物**（Ecdysozoa），靠蜕去表皮生长的动物（节肢动物、栉蚕、缓步动物、线虫等；Anna Marie Aguinaldo 及同事，1997），与**螺旋动物**（Spiralia，含**冠轮动物** Lophotrochozoa：软体动物、环节动物、腕足动物、纽形动物等，以及扁形动物、轮虫及其近亲；冠轮动物一词出自 Kenneth Halanych 及同事，1995）。
- **后口动物**（Deuterostomia）包含**管足类**（Ambulacraria：棘皮动物与半索动物）与**脊索动物**（Chordata，[[diversity-of-life/vertebrates]]）。

### 原口动物与后口动物

这两个名称说的是**胚孔**（原肠形成时细胞内卷的开口）的命运："原口动物"（protostome，"口在前"）的胚孔据说发育为口，"后口动物"（deuterostome，"口在后"）的胚孔发育为肛门，口稍后另建。经典胚胎学还补充了其他差别：多数原口动物为螺旋式确定性卵裂，体腔由中胚层开裂形成（裂体腔法）；后口动物为辐射式不确定卵裂，体腔由原肠外突形成（肠体腔法）。这些都只是倾向而非规则——原口动物之间胚孔命运多变，许多蜕皮动物也没有螺旋式卵裂——两个进化枝如今由分子系统发育学界定。

## 海绵、栉水母与刺胞动物

**海绵**（Porifera，多孔动物，约 9,000 种，多数海生）没有严格意义上的组织，没有神经与肌肉。水被体壁上**领细胞**（choanocytes，形似领鞭毛虫的领状摄食细胞）摆动的鞭毛抽吸进体壁的小孔，领细胞截获细菌和颗粒；水经一个更大的开口——**出水孔**（osculum）——排出。一块海绵每几秒到几分钟就能泵送相当于自身体积的海水；硅质或钙质的骨针，或胶原蛋白质的海绵丝支撑其身体。

::: example 作为过滤器的海绵 {#ex-sponge}
设一体积 1 L 的海绵每秒泵水 0.2 L，其领细胞截留水中 90 % 的细菌；水中每毫升含细菌 $10^6$ 个，每个含碳约 20 fg。（这些是热带礁区海绵实测数量级的取整数字。）(a) 这块海绵泵送自身体积的水需要多久？(b) 它每天截获多少细菌、多少碳？
::: solution
(a) $1/0.2 = 5$ 秒。

(b) 每天泵水：$0.2\times1000$ mL s⁻¹ $\times 86{,}400$ s $= 1.73\times10^7$ mL。截获细菌：$1.73\times10^7\times10^6\times0.9 = 1.6\times10^{13}$ 个，约 $1.6\times10^{13}\times20\times10^{-15}$ g $= 0.31$ g 碳。有许多这样海绵的珊瑚礁，其上水层几小时到几天即被滤过一遍，溶解与颗粒有机物得以循环利用而不至于流失——这是珊瑚礁能在贫营养海域保持高生产力的原因之一（Jasper de Goeij 及同事 2013 年提出的"海绵循环"）。
:::
:::

**栉水母**（Ctenophora，约 200 种）靠八列愈合的纤毛（栉板）游泳，是用纤毛游泳的最大动物；多数用粘细胞（colloblasts）捕捉猎物。

**刺胞动物**（Cnidaria，约 11,000–12,000 种：水母、海葵、珊瑚、水螅）有两种身体形式，固着的**水螅型**（polyp）和游泳的**水母型**（medusa），生活史中出现其一或两者；消化循环腔只有一个开口；具神经网；以及**刺细胞**（cnidocytes），内含细胞器**刺丝囊**（cnidocyst，nematocyst），可射出钩枪状的刺丝。*Hydra*（水螅）刺丝囊的发射约需 700 纳秒，刺针的加速度超过 500 万 $g$（Timm Nüchter 及同事，2006）——生物学上最快的动作之一。造礁珊瑚体内住着光合甲藻（[[diversity-of-life/protists]]）。

## 没有循环系统时的体型极限

海绵、刺胞动物、扁形动物和许多小型动物没有血管：每个细胞都靠从体表或消化管扩散来的氧。扩散在微米尺度很快，在毫米尺度很慢（[[cell-biology/cells-and-microscopy#prop-diffusion]]），这给这类动物的厚度定了上限。

::: proposition 扩散对体型大小的限制 {#prop-diffusion-limit}
考虑以均匀速率 $M$（mol m⁻³ s⁻¹）消耗氧的组织，氧在其中以扩散系数 $D$ 扩散，表面氧浓度维持在 $C_0$。稳态下，

1. **平板**（厚度 $2L$，两面暴露）中，距中面 $x$ 处的氧浓度为 $C(x) = C_0 - \dfrac{M}{2D}(L^2 - x^2)$，中心部保持供氧仅当
$$
L^2 \le \frac{2DC_0}{M};
$$ {#eq-slab}
2. **球体**（半径 $R$）中，$C(r) = C_0 - \dfrac{M}{6D}(R^2 - r^2)$，中心保持供氧仅当
$$
R^2 \le \frac{6DC_0}{M}.
$$ {#eq-sphere}
:::

::: proof
稳态时，扩散进每个小体积的氧与消耗相平衡：$D\nabla^2C = M$。对平板，$C$ 只依赖 $x$：$D\,d^2C/dx^2 = M$，故 $C = C_0 + (M/2D)(x^2 - L^2)$，用了对称性（$x = 0$ 处 $dC/dx = 0$）与 $C(\pm L) = C_0$。最小值在 $x = 0$：$C(0) = C_0 - ML^2/2D$，非负仅当 $L^2 \le 2DC_0/M$。对球体，$C$ 只依赖 $r$，$\nabla^2C = r^{-2}\,d(r^2\,dC/dr)/dr = M/D$。积分一次，$r^2\,dC/dr = Mr^3/3D$（中心梯度有限，积分常数为零），故 $dC/dr = Mr/3D$，$C = C_0 - (M/6D)(R^2 - r^2)$。最小值 $C(0) = C_0 - MR^2/6D$ 非负仅当 $R^2 \le 6DC_0/M$。
:::

::: example 扁形动物能有多厚？ {#ex-flatworm}
取组织中氧的扩散系数 $D = 2\times10^{-9}$ m² s⁻¹（上限值，接近水中的值），表面氧浓度 $C_0 = 0.28$ mol m⁻³（20 °C 空气饱和水），代谢率取较低的 0.1 mL O₂ 每克每小时。(a) 设组织密度 1 g cm⁻³，把代谢率换算为 mol m⁻³ s⁻¹。(b) 仅靠扩散供氧的球形动物最大半径、扁平动物最大厚度各是多少？(c) 若代谢率高十倍会怎样？
::: solution
(a) 0.1 mL O₂ 为 $0.1/22{,}400 = 4.46\times10^{-6}$ mol（标准状况）。每克每小时即 $4.46\times10^{-6}\times10^6$ g m⁻³ / 3600 s $= 1.24\times10^{-3}$ mol m⁻³ s⁻¹。

(b) 球体：$R = \sqrt{6\times2\times10^{-9}\times0.28/1.24\times10^{-3}} = \sqrt{2.71\times10^{-6}} = 1.65$ mm。平板：$L = \sqrt{2\times2\times10^{-9}\times0.28/1.24\times10^{-3}} = 0.95$ mm，总厚度约 1.9 mm。

(c) 两个极限都缩小 $\sqrt{10}$ 倍：半径 0.52 mm，半厚 0.30 mm。这就是没有循环系统的动物为何小、扁、壁薄或行动迟缓。自由生活的扁形动物是扁平的，至多几毫米厚（较大的种是薄带，有的消化管高度分支，把食物送到每个细胞附近）；水母主体是非生命物质的中胶层，活细胞只成薄层；海绵则保证水流过每个细胞。动物要又大又厚又活跃，就需要循环系统或气管，以及特化的呼吸表面（[[animal-physiology/gas-exchange]]）。
:::
:::

## 原口动物

### 螺旋动物

**扁形动物**（Platyhelminthes，约 30,000 种）两侧对称、无体腔，没有完整消化管，也没有循环系统。自由生活的涡虫，如 *Schmidtea mediterranea*，全身分布着多能干细胞（新细胞，neoblasts），小至约 1/279 个体的碎片也能再生出完整的虫体（摩尔根 (Thomas Hunt Morgan)，1898）。多数扁形动物是寄生生活的：**绦虫**（cestodes）完全失去了消化管，经体表吸收食物；**吸虫**（trematodes）的生活史复杂，以螺为中间宿主。

**软体动物**（Mollusca，已描述约 85,000 个现生种）共有的体型模式包括：肌肉**足**、容纳内脏的**内脏团**、分泌外壳并围出含鳃的外套腔的**外套膜**，以及多数类群锉状的舌形**齿舌**（radula）。腹足类（螺与蛞蝓）发育中发生**扭转**（torsion），内脏团旋转 180°，使外套腔与肛门转到头的上方。双壳类（蛤、贻贝、牡蛎）失去了头和齿舌，用增大的鳃滤食。头足类（章鱼、乌贼、墨鱼、鹦鹉螺）把足演化为腕和用于喷射推进的漏斗，其中既有最大的无脊椎动物（大王酸浆鱿 *Mesonychoteuthis hamiltoni* 可达 500 kg），也有脑大而集中的动物；章鱼约有 5 亿个神经元，多数在腕中。头足类与脊椎动物的相机式眼是著名的趋同案例：头足类的视网膜朝着光，没有盲点。

**环节动物**（Annelida，分节的蠕虫，约 20,000 种：蚯蚓、蛭与海生的多毛类）身体分为重复的**体节**，每节有自己的体腔段、肌肉、排泄器官和神经节——这套配置使每个体段的静水骨骼可独立控制。达尔文的最后一本书（1881）根据蚯蚓粪估算，英国样地的蚯蚓每年每英亩翻起土壤约 7–18 吨。

### 蜕皮动物

**线虫**（Nematoda，线虫动物）是地球上数量最多的动物之一：一项全球分析估算仅表层土壤中就有约 $4.4\times10^{20}$ 条线虫（Johan van den Hoogen 及同事，2019）。已描述约 25,000 种，实际数目可能多十倍乃至百倍。约 1 mm 长的秀丽隐杆线虫 *Caenorhabditis elegans*，成体雌雄同体恰好有 959 个体细胞，细胞谱系恒定（John Sulston 及同事，1983），是最伟大的模式生物之一（[[cell-biology/tissues-and-cell-death#ex-elegans]]）。线虫的假体腔处于压力下，只有纵肌（故靠摆动前进），表皮在发育中蜕四次。

**节肢动物**（Arthropoda，已描述约 125 万种，占已描述动物的五分之四）身体分节，**附肢分节**，具几丁质与蛋白质构成、常矿化加硬、定期蜕去（蜕皮，ecdysis）的**外骨骼**。体节归并成功能区域**体区**（tagmata），如头、胸、腹。现生类群有：

- **螯肢类**（Chelicerata）：鲎、海蜘蛛与蛛形纲（蜘蛛、蝎、螨、蜱；已描述约 110,000 种），第一对附肢是螯肢（毒爪或钳），两个体区（头胸部与腹部），无触角。
- **多足类**（Myriapoda）：蜈蚣与马陆，躯干有许多相似体节。
- **全甲壳类**（Pancrustacea）：甲壳类（蟹、虾、蔓足类、桡足类——也许是海洋中数量最多的动物）与**六足类**（昆虫及其无翅近亲），后者进化自甲壳类内部，故不含昆虫的"甲壳类"是并系的。昆虫有三个体区、六条腿、通常两对翅，已描述约一百万种，是已知多样性最高的生物类群。昆虫的飞行进化了一次，至迟在早石炭世（有翅昆虫出现于约 3.25 亿年前），**完全变态**（幼虫、蛹、成虫）是多样性最高的各目（鞘翅目、双翅目、鳞翅目、膜翅目）的特征。

它们的近亲**栉蚕**（Onychophora，有爪动物）与**缓步动物**（Tardigrada，"水熊"）共有叶状的腿；缓步动物能以休眠状态耐受干燥、冰冻甚至暴露于太空。

### 靠蜕皮生长

外骨骼不能生长，所以节肢动物按台阶式生长：在旧表皮下分泌一层柔软起褶的新表皮，裂开并蜕去旧表皮，扩张身体（吞入空气或水），再把新表皮硬化。两次蜕皮之间的阶段是**龄**（instar）。1890 年，Harrison Dyar 测量毛虫头壳，发现每蜕一次皮宽度按大致恒定的因子增大。

::: proposition 戴亚法则（Dyar's rule，一条经验规律） {#prop-dyar}
在许多昆虫和甲壳类中，硬质身体部位（如头壳宽度）在每次蜕皮时按大致恒定的比率 $\rho$ 增大，典型值在 1.2 到 1.7 之间，常接近 1.4，于是第 $i$ 龄

$$
w_i \approx w_1\,\rho^{\,i-1}, \qquad \ln w_i \approx \ln w_1 + (i - 1)\ln\rho.
$$ {#eq-dyar}

这是一个观察，不是定律：比率随种、性别、环境和阶段而异，对它的偏离正被用来发现漏掉或多出的龄。$\ln w$ 对龄数作图近似一条斜率为 $\ln\rho$ 的直线。
:::

::: example 数龄 {#ex-dyar}
野外采集毛虫的头壳宽度聚为 0.32、0.45、0.62、0.88 与 1.23 mm 几组。(a) 相邻两次蜕皮的比率各是多少？符合戴亚法则吗？(b) 估计一个统一的生长比率。(c) 已知该种由头壳约 2.4 mm 的毛虫化蛹。是否漏掉了一龄？
::: solution
(a) $0.45/0.32 = 1.41$，$0.62/0.45 = 1.38$，$0.88/0.62 = 1.42$，$1.23/0.88 = 1.40$：几乎恒定，与戴亚法则一致。

(b) 四次蜕皮的几何平均比率为 $(1.23/0.32)^{1/4} = 1.400$。

(c) 以 $\rho = 1.4$ 继续：$1.23\times1.4 = 1.72$ mm，$1.72\times1.4 = 2.41$ mm。末龄（2.4 mm）比样本中最大的个体晚两次蜕皮，所以毛虫至少有七龄，采样漏掉了第六龄（约 1.72 mm）——也许因为它存续时间短或出现在别的季节。
:::
:::

哪几组动物彼此亲缘更近，而不是与所列第三种动物更近？
- [x] 蚯蚓与蜗牛，相对于昆虫

:::

## 后口类无脊椎动物：棘皮动物

**棘皮动物**（Echinodermata，约 7,500 个现生种：海星、蛇尾、海胆、海参、海百合与羽星）全部海生。成体**五辐射对称**，幼虫却两侧对称，五辐对称在变态时形成：棘皮动物进化自两侧对称的祖先。它们有方解石骨板（骨片）构成的内骨骼，每块骨板是一枚单晶；还有独特的**水管系统**，以充液管道驱动数百个液压**管足**，用于运动、摄食与气体交换。许多类群再生能力惊人。海胆的卵和胚胎帮助人们发现了受精事件（Oscar Hertwig，1876）、细胞周期的周期蛋白（Tim Hunt 及同事，1983）和发育的基因调控网络。它们的亲戚**半索动物**（Hemichordata，柱头虫）与脊索动物共有咽鳃裂。

## 寒武纪大爆发

几乎所有带矿化骨骼的动物门，都在寒武纪——始于 538.8 Ma——最初 20–25 百万年内在化石记录中突然出现，这就是**寒武纪大爆发**。其记录与定年见 [[evolution/macroevolution]]；对体型模式要紧的是以下几点。

1. **爆发之前的记录。**埃迪卡拉生物群（约 575–539 Ma）包括动物（*Dickinsonia*、形似软体动物的 *Kimberella* 及其类似齿舌锉痕）和亲缘关系不明的类型，两侧对称动物掘穴的遗迹化石出现在埃迪卡拉纪晚期。分子钟把动物的起源和两侧对称动物的主要分歧放在寒武纪之前几十到几百百万年。大爆发部分是保存与生态的革命——骨骼、眼、捕食与掘穴的进化——叠加在一段更长的隐伏历史之上。
2. **特异埋藏。**云南澄江生物群（约 518 Ma）与加拿大不列颠哥伦比亚的布尔吉斯页岩（约 508 Ma）保存了软躯体动物：早期节肢动物、捕食者 *Anomalocaris*、与栉蚕亲缘的叶足动物、早期脊索动物。许多曾被归入绝灭各门的类群，后来被安置到现生各门的**干群**上（[[diversity-of-life/classifying-life#def-rank-clade]]）——*Hallucigenia* 是干群栉蚕，*Opabinia* 是干节肢动物。
3. **成因。**提出的触发因素包括新元古代末氧含量上升、海水化学的变化有利于骨骼、发育工具包的进化（*Hox* 基因及其调控网络，[[evolution/macroevolution]]），以及捕食、视觉与掘穴带来的生态反馈。没有任何单一成因被接受；多数研究者视为环境提供可能与生态逐级升级二者兼而有之。

::: application 无脊椎动物与人类
无脊椎动物提供的服务价值难以估量：昆虫为多数开花植物传粉，包括主要粮食作物约四分之三至少部分依赖虫媒（Alexandra-Maria Klein 及同事，2007）；蚯蚓与其他土栖动物维持土壤结构；珊瑚建造的礁区养育也许四分之一的海洋鱼类并保护海岸；双壳类过滤近岸水体。它们也包括作物与储粮的害虫和疾病传播媒介（蚊、蜱、舌蝇、白蛉），以及寄生虫；医学方面见[医学图谱](/learn/medicine/course.php?c=infectious-diseases)。一些地区的长期监测发现昆虫生物量急剧下降——德国保护区 27 年间下降 76 %（Caspar Hallmann 及同事，2017）——不过趋势随地域、类群和方法而异（[[conservation-biology]]）。模式无脊椎动物——*Drosophila melanogaster*、*C. elegans*、海胆、*Hydra*、涡虫、乌贼粗大轴突——贡献了我们对基因、发育和神经元所知的大部分。
:::

::: history
林奈（1758）把除昆虫外的全部无脊椎动物放进一个"虫纲"（Vermes）；拉马克（Lamarck，1801）创造了"无脊椎动物"一词并开创其现代分类；居维叶（Cuvier，1812）按体型把动物分为四个 *embranchements*（脊椎动物、软体动物、分节动物、辐射动物）。恩斯特·海克尔的原肠虫理论（1874）主张动物进化自一个双层、具消化管的祖先；Karl Grobben（1908）把两侧对称动物分为原口与后口。Libbie Hyman 的 *The Invertebrates*（6 卷，1940–1967）以体腔等级组织了整个领域。核糖体 RNA 系统发育学推翻了那个框架：冠轮动物（Halanych 及同事，1995）与蜕皮动物（Aguinaldo 及同事，1997）。Charles Walcott 1909 年发现布尔吉斯页岩，澄江生物群由侯先光 1984 年发现。染色体级别的基因组带来了栉水母为所有其他动物姊妹群的共线性证据（Schultz 及同事，2023）。
:::

::: summary
- 动物（Metazoa）是具胶原蛋白、上皮和二倍体生活史的后鞭毛生物；领鞭毛虫是其最近的亲戚。冠群动物可能起源于 650–850 Ma；*Dickinsonia*（约 560 Ma）已确认为动物。
- 已描述动物约 155 万种，97 % 无脊椎，80 % 节肢。"无脊椎动物"是一个并系的等级类群。
- 体型模式以对称（辐射、两侧）、胚层（二胚层、三胚层）与体腔（无体腔、假体腔、真体腔）描述；体腔类型是亲缘关系的糟糕指南。
- 动物之树：栉水母最先（主流假说，出自共线性，2023）或海绵最先；随后扁盘动物、刺胞动物与两侧对称动物（Xenacoelomorpha + Nephrozoa）；原口动物为蜕皮动物（节肢动物、线虫……）与螺旋动物（软体动物、环节动物、扁形动物……）；后口动物为管足类（棘皮动物、半索动物）与脊索动物。
- 没有循环系统时，氧进入平板中心要求 $L^2 \le 2DC_0/M$，进入球体中心要求 $R^2 \le 6DC_0/M$——中等代谢率下约 1–2 mm——这解释了这类动物为何小、扁或多水。
- 节肢动物靠蜕皮生长；戴亚法则（经验规律）称硬质部位每蜕皮一次按近恒定比率生长，常在 1.4 左右。
- 棘皮动物是五辐射对称的后口动物，幼虫两侧对称，具水管系统。寒武纪大爆发（自 538.8 Ma 起）记录的是骨骼化各门在一段更长隐伏历史之后的出现。
:::

::: exercise 更大的球 {level=2}
用 [[#eq-sphere]]：要使球形动物的半径加倍而仍靠扩散供氧，单位体积的代谢率必须下降到几分之一？哪些进化方案绕开了这一限制？
::: solution
$R^2 \propto 1/M$，半径加倍要求 $M$ 降到四分之一。方案：具血红蛋白或血蓝蛋白等色素的循环系统；把空气直接送到组织的气管系统（昆虫）；身体压扁或拉长（扁形动物、带状类型）；用代谢惰性的材料填充体积（水母的中胶层、海绵的骨骼）；让水流经每个细胞（海绵的沟系、刺胞动物的消化循环腔）。
:::

::: exercise 趋同的眼 {level=2}
章鱼与人都有具晶状体、虹膜和视网膜的相机式眼。(a) 有什么证据表明这两种眼独立进化？(b) *Pax6* 的"深层同源"如何使答案复杂化？(c) 解释视网膜朝向的差异及其后果。
::: solution
(a) 头足类与脊椎动物分别是原口动物与后口动物；其共同祖先是一种小型两侧对称动物，多数中间类群（其他软体动物、许多脊椎动物近亲）没有相机式眼；两者的眼发育方式不同（头足类的眼源于体表外胚层内陷，脊椎动物的视网膜源于脑的外突），晶状体的晶状体蛋白也不同。

(b) *Pax6* 及相关调控基因在两者——也在果蝇——中控制眼的发育（[[evolution/macroevolution]]）；因此指定感光器官的遗传工具包是同源的、古老的，尽管相机式眼本身是趋同的。

(c) 脊椎动物的感光细胞背向光，位于神经元和血管之后，后者经视网膜上一处缺口穿出眼外（盲点）。头足类的感光细胞朝向光，神经从后方离开，故没有盲点。脊椎动物的配置是眼从脑发育这一历史过程的后果，不是设计的最优。
:::

::: exercise 平板还是球？ {level=3}
(a) 由 [[#prop-diffusion-limit]] 证明：同一组织，球体的最大半径是平板最大半厚的 $\sqrt3$ 倍。(b) 从物理上解释为什么球更划算。(c) 长圆柱（虫）半径 $a$ 满足 $a^2 \le 4DC_0/M$。按最大*单位表面积体积*给三种形状排序，并讨论受扩散限制的动物最经济的形状。(c)
::: solution
(a) $R_{\max}^2/L_{\max}^2 = (6DC_0/M)/(2DC_0/M) = 3$，故 $R_{\max} = \sqrt3\,L_{\max}$。
(b) 球从四面八方供氧：中心在三维上被表面环绕，平板的中面只从两个面获得。等价地说，单位表面需供应的体积在球中心附近（$V/S = R/3$）比在平板（$V/S = L$）小。
(c) 在极限处，平板 $V/S$ = $L_{\max}$，圆柱 $a_{\max}/2 = \sqrt{4DC_0/M}/2 = \sqrt{DC_0/M}$，球 $R_{\max}/3 = \sqrt{6DC_0/M}/3 = 0.816\sqrt{DC_0/M}$，而平板为 $\sqrt{2DC_0/M} = 1.414\sqrt{DC_0/M}$。所以单位表面积能承载的组织，平板最多（1.41），其次圆柱（1.00），再次球（0.82）；但平板要靠另外两个方向不受限制才做到这一点。薄片是大体积受扩散限制身体的最经济形状，这就是最大的无循环动物——扁形动物、某些水母的组织层、扁盘动物——都是薄片的原因。

::: exercise 哪种动物最先出现？ {level=3}
(a) 在"栉水母最先"假说下，神经系统与肌肉有哪两种可能的历史？(b) 什么证据能在两者之间作出裁决？(c) 为什么共线性——哪些基因位于同一染色体上这一格局的保守性——比序列进化更不容易受困挠此前分析的伪影影响？
::: solution
(a) 或者神经与肌肉在全部动物的共同祖先中进化一次，而后在海绵（以及扁盘动物）中丢失；或者在栉水母和刺胞动物加两侧对称动物的祖先中各自独立进化。

(b) 两套系统的分子细节：栉水母的神经元使用一组独特神经肽，缺少其他动物具有的许多神经递质通路和突触基因；电镜所见的神经网是一个合胞体（Pawel Burkhardt 及同事，2023）。这类差别支持独立起源；而同源的共有组分（离子通道、突触支架蛋白，其中许多海绵和领鞭毛虫也有）在两种情形下都在意料之中，不具决定性。细胞类型本身是否同源——以单细胞转录组评估——是关键检验。

(c) 共线性经由罕见的大事件改变——染色体融合及其后的基因混合——实际不可逆，几乎不可能以同一种方式发生两次。序列性状改变频繁且可能偶然趋同，所以栉水母等快速进化的谱系会吸引或排斥其他长枝（长枝吸引，[[evolution/phylogenetics]]），结果依赖于替换模型。共有衍征式的"融合加混合"正是亨尼希方法最看重的罕见基因组变化。
