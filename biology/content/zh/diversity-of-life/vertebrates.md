我们以自身的谱系为这场多样性巡礼收尾。脊椎动物只是动物多样性的一小部分——现生约 75,000 种，而已描述的无脊椎动物约 150 万种——但其中包括了有史以来最大的动物、最快的、最长寿的和最聪明的，而且它们被研究的时长与细致程度超过任何其他类群。它们从寒武纪指头大小的游泳者到鲸与鸟的历史，化石记录异常翔实，几次重大转变——颌的起源、登陆、羊膜卵、飞行与哺乳动物的耳——都是大进化中理解得最好的事件之列。本章定义脊索动物与脊椎动物，沿无颌鱼到哺乳动物之树行进，并驻足于几次转变。系统发育一律系于年代——TimeTree 的分子估计与化石给出的最小年龄——并算清两个脊椎动物问题的物理：带充气鳔的鱼如何实现中性浮力，以及代谢率如何随体型标度（克莱伯法则，一条经验规律）。人类进化另见 [[evolution/human-evolution]]，脊椎动物生理学见 [[animal-physiology]]。

## 脊索动物

::: definition 脊索动物 {#def-chordate}
**脊索动物**（Chordata）是后口动物（[[diversity-of-life/invertebrates]]），至少在生活史的某个阶段具有五项共有衍征：(1) **脊索**，背侧一条位于神经管之下、由具液泡的细胞构成并外包鞘的柔性棒；(2) **背侧中空的神经管**，由外胚层内卷形成；(3) **咽鳃裂**（鳃裂），从咽通向外界的开口，最初用于滤食；(4) **内柱**（endostyle，或其衍生物甲状腺），咽底一条分泌粘液并结合碘的沟；(5) 肌肉质的**肛后尾**。
:::

脊索动物的三个现生类群是：**头索动物**（头索亚门，文昌鱼或称 amphioxus，约 30 种小型鱼形滤食者，成体保留全部五项特征）、**被囊动物**（海鞘及其近亲，约 3,000 种，幼虫似蝌蚪，固着的成体却失去脊索与神经管）与**脊椎动物**。解剖学曾提示文昌鱼是脊椎动物的姊妹群，但系统发育基因组学分析（Frédéric Delsuc 及同事，2006）表明被囊动物才是：脊椎动物与被囊动物构成 **Olfactores** 进化枝，固着、简化的被囊成体其实是一高度特化的体型。它们在后口动物中的姊妹群是管足类（棘皮动物与半索动物），后者（半索动物）也有咽鳃裂。

::: definition 脊椎动物 {#def-vertebrate}
**脊椎动物**（Vertebrata，或 Craniata）是具有**颅**（保护脑的软骨或骨箱，脑分为前、中、后三部分）、成对感觉器官（眼、耳、鼻）的脊索动物，且除盲鳗外都有**脊椎**——包绕神经管、部分或完全取代脊索的骨骼元件。两项胚胎学创新是其根基：**神经嵴**，从神经管边缘迁出、形成大部分颅骨、外周神经系统、色素细胞等组织的细胞；以及**外胚层基板**（placodes），形成感觉器官的外胚层增厚。
:::

脊椎动物的基因组还带着谱系早期**两轮全基因组复制**的印记（"2R"假说，[[evolution/macroevolution]]），使发育工具包成倍扩充：哺乳类有四个 *Hox* 簇，文昌鱼只有一个。最老的脊椎动物是中国澄江生物群的化石，约 5.18 亿年前——昆明鱼（*Myllokunmingia*）与海口鱼（*Haikouichthys*），只有几厘米长，具鳃囊、之字形肌节，或许还有颅（舒德干及同事，1999）。布尔吉斯页岩的 *Metaspriggina*（Simon Conway Morris 与 Jean-Bernard Caron，2014）有成对的眼与鳃条。

## 无颌类与有颌类

现生无颌脊椎动物**圆口类**（cyclostomes）包括盲鳗（约 80 种，海床食腐者，分泌大量粘液）与七鳃鳗（约 40–50 种，许多成体寄生）。形态学曾提示七鳃鳗比盲鳗更接近有颌脊椎动物，但分子数据把两者归为一个进化枝。奥陶纪到泥盆纪许多已绝灭的无颌"**甲胄鱼**"（ostracoderms）披着骨甲。

**颌**进化自支撑鳃的前一对软骨性**咽弓**，上、下颌由该弓的上、下部分发育而来。有颌脊椎动物即**有颌类**（gnathostomes）还有成对的胸鳍与腹鳍、内耳的三个半规管和髓鞘化的神经。最老的有颌类遗存是早志留世的齿与鳞，约 4.39 亿年前（*Qianodus*，Plamen Andreev 及同事，2022）。志留纪与泥盆纪披甲的**盾皮鱼**（placoderms）构成有颌类的一列干群；来自中国晚志留世（约 4.2 亿年前）的初始全颌鱼（*Entelognathus primordialis*；朱敏及同事，2013）具有与硬骨鱼相同的骨质颌部元件，提示现生鱼类的颌源自盾皮鱼的颌。

现生有颌类分为两大进化枝：

- **软骨鱼**（Chondrichthyes，约 1,300 种：鲨、鳐与银鲛），骨骼为软骨，以矿化小片加固，具**盾鳞**（齿状皮鳞），体内受精；许多类群具电感受器（罗伦氏壶腹）。
- **硬骨鱼**（Osteichthyes），即硬骨脊椎动物，骨骼为骨，包括辐鳍鱼、肉鳍鱼与四足动物。其中最老有关节连接的个体是*Guiyu oneiros*，出土于云南同一套晚志留世地层，约 4.2 亿年前（朱敏及同事，2009）。早期硬骨鱼具肺或肺状气囊；在多数辐鳍鱼中它们变成了**鳔**。

**辐鳍鱼**（Actinopterygii）的鳍由细的骨质鳍条支撑。它们约占全部脊椎动物种数的一半——Eschmeyer 的 *Catalog of Fishes* 列出鱼类有效种约 36,000 个，其中绝大多数是**真骨类**（teleosts），其祖先经历了第三次全基因组复制。**肉鳍鱼**（Sarcopterygii）的肉质鳍中央有一小套大骨，经一块单骨连于肩带；其中包括腔棘鱼、肺鱼与四足动物。

### 中性浮力

鱼组织的密度大于水——不带鳔的真骨类，其骨、肌肉与蛋白质的密度约 1.06–1.09 g cm⁻³——所以没有浮力机制的鱼会下沉。鲨以巨大的含油肝脏抵消部分体重，游泳时用鳍产生升力；多数真骨类使用充气的鳔。

::: proposition 实现中性浮力所需的鳔体积 {#prop-buoyancy}
设鱼的组织（气体以外的全部）平均密度为 $\rho_t$，水密度 $\rho_w$，气体密度 $\rho_g$。当气体占其总体积的

$$
f = \frac{\rho_t - \rho_w}{\rho_t - \rho_g} \approx \frac{\rho_t - \rho_w}{\rho_t}
$$ {#eq-buoyancy}

时，鱼即中性浮力，近似式在表面附近成立，此时 $\rho_g \ll \rho_t$。
:::

::: proof
按阿基米德原理，鱼的平均密度等于水密度时即中性悬浮。气体体积分数为 $f$ 时，平均密度为 $(1 - f)\rho_t + f\rho_g$。令其等于 $\rho_w$ 并求解，得 $f(\rho_t - \rho_g) = \rho_t - \rho_w$。
:::

::: example 鳔有多大？ {#ex-buoyancy}
取 $\rho_t = 1.075$ g cm⁻³。(a) 海水真骨类在海水中（$\rho_w = 1.026$ g cm⁻³）需要多大的鳔占比？(b) 淡水真骨类（$\rho_w = 1.000$）呢？(c) 一条海鱼从水面潜到 30 m 深处，鳔的体积会怎样，它必须做什么？
::: solution
(a) $f \approx (1.075 - 1.026)/1.075 = 0.046$：约占体体积的 5 %。(b) $f \approx 0.075/1.075 = 0.070$：约 7 %。两者都与实测的海水及淡水真骨类鳔体积（约 5 % 与 7–8 %）相符。淡水的浮托力更小，所以淡水鱼需要更大的鳔。

(c) 海水每深 10 m 约增加 1 个大气压，30 m 处绝对压强约 4 atm，按玻意耳定律，气体会收缩到水面体积的四分之一，鱼便下沉。要保持中性，它必须向鳔内分泌气体——摩尔数须达水面的四倍——真骨类靠**气腺**和一条把氧浓缩到高压的逆流毛细血管网**迷网**（rete mirabile）完成。相反的问题解释了为什么深水鱼被快速捞到水面会因鳔膨胀而受伤。
:::
:::

## 登陆

**四足动物**（tetrapods）——两栖动物、爬行动物（含鸟类）与哺乳动物——进化自泥盆纪的肉鳍鱼。现生最近的亲戚是肺鱼（6 种，产在澳洲、南美与非洲），其次是腔棘鱼。现生腔棘鱼 *Latimeria chalumnae* 曾轰动一时：1938 年 12 月南非外海捕获的标本被博物馆馆长 Marjorie Courtenay-Latimer 认出，经 J. L. B. Smith 描述（1939）——此前腔棘鱼只作为化石为人所知，在白垩纪之后就消失于记录。第二个种 *L. menadoensis* 于 1997–1999 年在印尼被发现。

化石以不同寻常的细节记录了这次转变：

| 化石 | 年龄（Ma） | 显示的特征 |
|---|---|---|
| 真掌鳍鱼（*Eusthenopteron*） | 约 385 | 鳍中含肢骨（肱骨、桡骨、尺骨）的肉鳍鱼 |
| 潘氏鱼（*Panderichthys*） | 约 385 | 头扁平，眼位于头顶，背鳍消失 |
| 提塔利克鱼（*Tiktaalik roseae*） | 约 375 | "鱼足过渡"：有鳃、鳞与鳍，却有可活动的颈、强壮的肩，以及能撑起身体、腕部样的鳍骨架（Edward Daeschler、Neil Shubin 与 Farish Jenkins，2006） |
| 棘螈（*Acanthostega*） | 约 365 | 具八指的肢（Michael Coates 与 Jennifer Clack，1990），但保留内鳃与尾鳍：肢是在水中进化的 |
| 鱼石螈（*Ichthyostega*） | 约 365 | 后肢七指，肋骨强壮 |

提塔利克鱼是按目标搜寻找到的：Shubin 及同事推断，过渡类型应保存在时代恰当（介于*Panderichthys* 那样的鱼与*Acanthostega* 那样的四足动物之间）、形成于浅水淡水环境的岩石里，于是在加拿大北极地区的埃尔斯米尔岛找了六个野外季的此类岩石。但波兰扎科米（Zachełmie）约 3.95 亿年前的类四足动物足迹径道（Grzegorz Niedźwiedzki 及同事，2010）比提塔利克鱼更老，意味着具四肢的四足动物早已存在，而提塔利克鱼所在的 elpistostegalian 类是一支早期历史没有记录的谱系中幸存到很晚的成员。

::: warning "鱼爬出海洋去征服陆地"
这里打包了三个误解。其一，早期四足动物不是海鱼，而是生活在浅水——常是半咸水或淡水——长满植物的生境，指是在仍生活在水中的动物里进化的——棘螈很可能根本不能在陆地上行走。其二，上岸没有一个单一时刻：特征在几千万年间零星累积，许多早期四足动物是水生的。其三，"鱼"是一个并系的等级类群：四足动物是嵌在硬骨鱼之*内*、肉鳍鱼之内的一个进化枝，所以在分支意义上人是肉鳍鱼（[[evolution/phylogenetics#def-clade]]）。
:::

::: example 脊椎动物都有谁？ {#ex-composition}
现生种数的近似值：鱼类（一切非四足脊椎动物）36,000；两栖动物 8,800；不含鸟的爬行动物 12,000；鸟类 11,000；哺乳动物 6,700。(a) "鱼"占脊椎动物种数的几分之几？(b) 系统发育意义的爬行动物（含鸟）占几分之几？(c) 为什么 (a) 的答案并不能说明"鱼"是不是自然类群？
::: solution
总数 $36{,}000 + 8{,}800 + 12{,}000 + 11{,}000 + 6{,}700 = 74{,}500$。

(a) $36{,}000/74{,}500 = 0.48$：约一半脊椎动物种是鱼，绝大多数是真骨类。

(b) $(12{,}000 + 11{,}000)/74{,}500 = 0.31$：把鸟算进来，近三分之一是爬行动物，Reptilia 由此成为最大的四足动物进化枝。

(c) 一个类群是否自然（单系）取决于树，不取决于它有多少种。不含四足动物的"鱼"漏掉了其共同祖先的后裔，因此是并系的，无论其种数多少；而种数还取决于分类实践，各群并不相同（鸟与哺乳类的编目远比鱼完全）。
:::
:::

**两栖动物**（Lissamphibia，滑体两栖类；据 AmphibiaWeb 2025 年约 8,800 种：蛙类约占 88 %，其余为蝾螈与无肢的蚓螈）典型的生活史包括水生幼虫与变态，湿润可透的皮肤用于气体交换，卵无壳，必须产在水中或潮湿处。它们是受威胁最重的脊椎动物纲：已评估种约 41 % 受威胁（Jennifer Luedtke 及同事，2023），部分原因是壶菌（[[diversity-of-life/fungi]]）。

## 羊膜动物

::: definition 羊膜卵 {#def-amniote}
**羊膜动物**（含鸟的爬行动物与哺乳动物）是胚胎在四层胚外膜中发育的四足动物：**羊膜**，以液体包裹胚胎；**卵黄囊**；**尿囊**，储存代谢废物，并与**绒毛膜**一起进行气体交换；以及包住其余各膜的绒毛膜。多数爬行类和单孔类的整体外有壳包裹，使卵得以在陆地上发育。兽类哺乳动物的绒毛膜与尿囊或卵黄囊共同构成**胎盘**。羊膜动物还有不透水的角化皮肤，靠肋廓运动呼吸（肋式呼吸）。
:::

最老的羊膜动物，如产自新斯科斯科宁斯堡石化树桩的 *Hylonomus lyelli*（约 3.18–3.15 亿年前），是蜥蜴状的小动物。羊膜动物早期分为两支，晚石炭世两支俱已存在：**合弓类**（synapsids），颅眼后只有一个开孔，通到哺乳动物；**蜥形类**（sauropsids，爬行类），通到龟、鳞龙类与主龙类。

### 爬行动物与鸟类

现生爬行动物（Reptile Database 约 12,000 种，不含鸟）是：

- **鳞龙类**（Lepidosauria）：有鳞类（蜥蜴与蛇，遥遥居首）与楔齿蜥，即新西兰的 *Sphenodon punctatus*，一个在中生代曾经多样的目的唯一残存种。
- **龟类**，其位置曾令解剖学家困惑，因为它们的颅没有颞孔；基因组规模的数据把它放在主龙类的姊妹群（Archelosauria 进化枝）。
- **主龙类**（Archosauria）：鳄类与鸟类。

鸟是恐龙。证据最初由赫克斯利（Thomas Huxley，1868）汇集，他注意到*Archaeopteryx* 与小型兽脚类的相似；John Ostrom 描述兽脚类恐爪龙（*Deinonychus*，1969）后此说卷土重来。如今证据已不可辩驳：兽脚类与鸟共有中空骨、叉骨（furcula）、三枚主要朝前的趾、孵卵姿态，并且自 1996 年中国*Sinosauropteryx*（中华龙鸟）发现以来，还有**羽毛**。许多非鸟兽脚类长羽毛，所以羽毛先于飞行进化，多半用于保温与炫耀。*Archaeopteryx lithographica* 产自巴伐利亚索伦霍芬石灰岩（约 1.5 亿年前；1861 年首次描述），是接近鸟类起源的带羽毛兽脚类。冠鸟类——现生鸟类的最后共同祖先及其全部后裔——在白垩纪结束前已经存在：*Asteriornis maastrichtensis*，约 6,670 万年，是一支与鸭、鸡亲缘的冠鸟（Daniel Field 及同事，2020）。恐龙之中只有鸟挺过了白垩纪末大灭绝（[[evolution/macroevolution]]），并辐射出约 11,000 个现生种。

### 哺乳动物

::: definition 哺乳动物 {#def-mammal}
**哺乳动物**（Mammalia）是具**毛**、**乳腺**、由单一骨块（**齿骨**）构成的下颌（与颅的鳞骨相关节），以及**三块中耳听小骨**——锤骨、砧骨与镫骨——的合弓类羊膜动物。锤骨与砧骨同源于其他羊膜动物构成颌关节的关节骨与方骨。多数哺乳动物还有分化的齿（门齿、犬齿、前臼齿、臼齿）且只换一次，有肌肉质的膈，以及四腔心、左主动脉弓。
:::

爬行类颌关节变为哺乳动物耳骨的过程，由 Reichert（1837）与 Ernst Gaupp 从胚胎学推知，并由一系列精美的犬齿兽与早期哺乳动物化石记录在案：齿骨之后的骨骼逐渐缩小，新的齿骨—鳞骨关节在旧关节旁形成，旧的颌骨迁入中耳。一些中生代哺乳动物还处在中间状态，耳骨仍靠软骨连于颌，而分离似乎发生过不止一次。

现生哺乳动物（据 2018 年以来各版 Mammal Diversity Database 约 6,500–6,800 种）分为三群：

- **单孔类**（Monotremata，5 种：鸭嘴兽与四种针鼹），产卵，无乳头（乳汁分泌到皮肤斑上）。
- **有袋类**（Marsupialia，约 380 种，分布于澳洲区与美洲），妊娠期短、哺乳期长，幼仔常在育儿袋中。
- **胎盘类**（Placentalia，6,000 余种），妊娠期长，由尿囊绒毛膜胎盘支撑。分子系统发育（William Murphy 及同事，2001；Ole Madsen 及同事，2001）把它们分为四个总目：**非洲兽类**（Afrotheria：象、海牛、蹄兔、土豚、马岛猬——一次非洲辐射）、**异关节类**（Xenarthra：食蚁兽、树懒、犰狳——南美）、**劳亚兽类**（Laurasiatheria：蝙蝠、鲸与偶蹄类、食肉类、奇蹄类、穿山甲、刺猬与鼩鼱）与**真魁兽类**（Euarchontoglires：灵长类、啮齿类、兔形类、树鼩、鼯猴）。这些组合既是亲缘的也是地理的，反映冈瓦纳与劳亚古陆的分裂。

冠哺乳动物起源于侏罗纪；中生代哺乳动物多为小型，但生态上比过去设想的更多样（有滑翔者、游泳者、掘洞者）。胎盘类各目的大分化主要发生在白垩纪末大灭绝前后及其后，尽管有些分子钟把最早的分歧放进白垩纪。

## 带年代标尺的脊椎动物之树

分歧时间用化石校准的松弛分子钟估计（[[evolution/phylogenetics#sec-dating]]）。**TimeTree** 资源（Sudhir Kumar、Blair Hedges 及同事；TimeTree 5，2022）把已发表估计综合为中位时间。与人类谱系各分歧四舍五入后的中位数，连同约束各节点的最老化石（最小年龄）如下：

| 人类与下列类群的分歧 | TimeTree 中位数（Ma，四舍五入） | 该节点的化石最小年龄 |
|---|---|---|
| 小鼠（真魁兽类） | 约 87 | —（晚白垩世胎盘类化石尚有争议） |
| 鸡（羊膜动物分裂：合弓类 vs 蜥形类） | 约 319 | *Hylonomus* 及同期类群，约 318–315 Ma，接近该分裂 |
| 蛙（冠四足类） | 约 352 | 早石炭世冠四足类，约 350–335 Ma |
| 斑马鱼（冠硬骨脊椎动物） | 约 429 | *Guiyu oneiros*，约 420 Ma |
| 鲨（冠有颌脊椎动物） | 约 462 | 早志留世软骨鱼齿（*Qianodus*），约 439 Ma |

两种格局很典型。分子估计比最老化石更老，也必须如此（化石只给最小值），而在一个进化枝的早期成员个体小或保存在欠佳的生境之处，二者的差最大。分子日期的不确定度常达 ±10–20 %，比四舍五入显示的大得多。

## 标度关系：代谢与体型

脊椎动物的质量横跨八个数量级，从 7 mm 的蛙到 150 吨的蓝鲸，许多性质随体质量按幂律标度。最著名的是代谢率。

::: proposition 克莱伯法则（Kleiber's rule，一条经验规律） {#prop-kleiber}
跨哺乳类与鸟类的各物种，基础（静息）代谢率 $B$ 近似按体质量 $M$ 的幂标度，

$$
B \approx aM^{b},\qquad \log B = \log a + b\log M,
$$ {#eq-kleiber}

指数 $b$ 接近 $\tfrac34$（Max Kleiber，1932）；就哺乳类而言，Kleiber 本人的拟合为 $B \approx 70M^{0.75}$ kcal 每日，$M$ 以千克计。单位体质量代谢率因而按 $B/M \propto M^{-1/4}$ 下降。这是比较数据的观察，不是自然定律：拟合指数随类群、温度、统计方法和"基础"如何界定在 0.65 到 0.85 之间变动；是否存在普适指数、以及为什么，仍在争论。
:::

一个简单论证预测另一个指数。若散热限制代谢，且动物几何相似，则 $B$ 应按表面积标度，即 $M^{2/3}$（Max Rubner 的表面定律，1883）。Craig White 与 Roger Seymour（2003）对哺乳类数据校正体温与消化状态后，得到接近 2/3 的指数。Geoffrey West、James Brown 与 Brian Enquist（1997）从一个分支状、充满空间的供应网络（血管）模型导出 3/4；批评者既质疑模型的假定，也质疑单一指数的适用性。没有争议的是：代谢率的上升远慢于质量，所以小动物活得更"快"：小鼠心脏每分钟跳约 600 次，大象约 30 次。

::: example 小鼠与大象 {#ex-kleiber}
用 $B = 70M^{0.75}$ kcal day⁻¹，比较一只 30 g 的小鼠与一头 4,000 kg 的大象：(a) 总基础代谢率；(b) 单位体质量代谢率；(c) 各自每天需要多少食物（干饲料约 4 kcal 一克）才够只支付基础代谢。
::: solution
(a) 小鼠：$70\times0.03^{0.75} = 70\times0.0721 = 5.0$ kcal day⁻¹。大象：$70\times4000^{0.75} = 70\times503 = 35{,}200$ kcal day⁻¹。

(b) 小鼠：$5.0/0.03 = 168$ kcal kg⁻¹ day⁻¹。大象：$35{,}200/4000 = 8.8$ kcal kg⁻¹ day⁻¹。每千克，小鼠耗能的速率约为大象的 19 倍，正与 $(M_\text{象}/M_\text{鼠})^{1/4} = (133{,}000)^{0.25} = 19.1$ 的预言相符。

(c) 小鼠：$5.0/4 = 1.3$ g 干饲料每天，约为其体质量的 4 %；大象：$35{,}200/4 = 8.8$ kg 每天，约 0.2 %（实际摄入量高数倍，因为野外代谢率高于基础值，且消化并不完全）。这就是最小的哺乳动物与鸟类（2 g 重的鼩鼱、蜂鸟）必须几乎不停取食，也是小型内温动物常靠蛰伏度日的原因。
:::
:::

其他量也标度，常为质量的 1/4 次幂：寿命与世代时间约 $M^{1/4}$，心率约 $M^{-1/4}$；骨骼质量略快于体质量（哺乳类约 $M^{1.09}$），所以大型动物骨骼占比更大，正如伽利略 1638 年的论证。标度关系被用来推断绝灭动物的生理学，并比较不同体型的物种（[[animal-physiology/energy-metabolism]]）。

::: example 十亿次心搏 {#ex-heartbeats}
小鼠心脏每分钟跳约 600 次，圈养下约活 2.5 年；大象心脏每分钟约 30 次，一生约 65 年。(a) 分别计算一生中心搏的次数。(b) 用心率与寿命的标度指数解释结果。
::: solution
(a) 小鼠：$600\times60\times24\times365\times2.5 = 7.9\times10^8$。大象：$30\times60\times24\times365\times65 = 1.0\times10^9$。

(b) 心率约按 $M^{-1/4}$ 标度，寿命约按 $M^{1/4}$，两者之积——一生心搏数——按 $M^0$ 标度：体型悬殊的哺乳动物的数目大致相同，都在十亿量级。这是一个有很多例外的经验格局——人（约 $2.5\times10^9$ 次）、蝙蝠与鹦鹉活得远比其体型预测的长——它也不意味着心脏有固定额度；它反映的是整个生理节奏随体型变慢这一事实。
:::
:::

::: application 衰退中的脊椎动物
脊椎动物的种群监测好于其他任何类群，趋势却令人警醒。据 IUCN 红色名录（2020 年代评估），已评估的两栖动物种约 41 %、哺乳动物约四分之一、鸟类约八分之一面临灭绝威胁。活星球指数（Living Planet Index）汇总数万个受监测脊椎动物种群的趋势，自 1970 年以来平均下降约 73 %（WWF 与伦敦动物学会，2024），尽管该指数被强下降种群主导，其解读也有争议。系统发育有助于确定保护优先序：EDGE 方法按进化独特性（一个种在树上代表多少独有枝长）结合灭绝风险给物种排序，于是楔齿蜥、鸭嘴兽或腔棘鱼的分量，重于众多近亲中的任何一个（[[conservation-biology]]）。
:::

::: history
亚里士多德区分了"有血"（脊椎）与"无血"动物，拉马克（1801）把脊椎动物与无脊椎动物分开。居维叶（Cuvier）创立比较解剖学与脊椎动物古生物学；欧文（Richard Owen，1840 年代）以脊椎动物骨骼为范例界定同源。达尔文（1859）与赫克斯利（1863，1868）把人归入灵长类、把鸟放到恐龙近旁。科瓦列夫斯基（Alexander Kowalevsky，1866）证明被囊幼虫有脊索，从而将其与脊椎动物相联。Reichert（1837）把哺乳动物听骨追溯到颌。现生腔棘鱼 1938 年被确认。Erik Jarvik 对鱼石螈的研究（1950 年代起）、Jennifer Clack 对棘螈的研究（1987 年起）与提塔利克鱼的发现（2004 年发现，2006 年发表）照亮了四足动物的起源；辽宁的带羽恐龙（1996 年起）定谳了鸟类的恐龙起源。分子系统发育带来了 Olfactores（2006）与胎盘类四个总目（2001）。
:::

::: summary
- 脊索动物具脊索、背侧中空神经管、咽鳃裂、内柱与肛后尾；脊椎动物的姊妹群是被囊动物而非文昌鱼（Olfactores）。
- 脊椎动物具颅、脊椎（盲鳗除外）、神经嵴与外胚层基板，基因组经历过两轮复制（2R）；最老化石约 518 Ma。
- 圆口类（盲鳗、七鳃鳗）无颌；颌进化自咽弓，盾皮鱼为有颌类干群。现生有颌脊椎动物为软骨鱼与硬骨鱼（辐鳍鱼；肉鳍鱼与四足动物）。
- 中性浮力要求气体占比 $f \approx (\rho_t - \rho_w)/\rho_t$：海水中约 5 %，淡水中约 7 %。
- 四足动物进化自泥盆纪肉鳍鱼，经提塔利克鱼（375 Ma）、棘螈与鱼石螈（365 Ma）；395 Ma 的足迹径道表明肢出现更早、且在水中。
- 羊膜动物（羊膜、绒毛膜、尿囊、卵黄囊）分为合弓类（哺乳动物）与蜥形类（爬行动物，含鸟——鸟是兽脚类恐龙）。哺乳动物有毛、乳汁、齿骨—鳞骨颌关节，以及由颌骨变来的三块中耳骨。
- 带年代的分歧（TimeTree 中位数）：人—小鼠约 87 Ma，人—鸡约 319 Ma，人—斑马鱼约 429 Ma；化石给出最小年龄。
- 克莱伯法则 $B \approx 70M^{0.75}$ kcal day⁻¹ 是经验规律；单位体质量代谢率按 $M^{-1/4}$ 下降；指数（3/4 还是 2/3）仍有争论。
:::

## 习题

::: exercise 一个人的基础代谢 {level=1 check="1694"}
用 $B = 70M^{0.75}$ kcal day⁻¹，估计一个 70 kg 的人的基础代谢率，四舍五入到整数 kcal 每天。
::: solution
$70^{0.75} = e^{0.75\ln 70} = e^{3.186} = 24.20$；$B = 70\times24.20 = 1{,}694$ kcal day⁻¹，与成人实测值接近（这是一个比较估计，不能作个体能量需求的指南）。

::: exercise 一条幽灵谱系 {level=2 check="20"}
扎科米足迹径道（约 395 Ma）记录了具四肢的四足动物，而四足动物由之起源的那支谱系的成员提塔利克鱼（约 375 Ma）却更年轻。这段最短的"幽灵谱系"——由这两个日期推出的提塔利克鱼谱系未被记录的历史——有多少个百万年？这对提塔利克鱼作为祖先的地位意味着什么？
::: solution
四足动物谱系最迟在 395 Ma 已与提塔利克鱼谱系分离，故后者的谱系至少有 $395 - 375 = 20$ Myr 未被记录。因此提塔利克鱼不是四足动物的祖先，而是保留众多祖先状态特征的晚期幸存亲戚——几乎每种"过渡化石"都是如此。过渡类型是关于性状改变顺序的证据，不是字面上的祖先。
:::

::: exercise 由颌来的听骨 {level=2}
(a) 蜥蜴的颌关节由哪些骨构成？哺乳动物的呢？(b) 哺乳动物哪些听骨与蜥蜴的颌关节骨同源？(c) 说出这种同源性证据的两类。
::: solution
(a) 蜥蜴的方骨（颅）与关节骨（下颌）相关节；哺乳动物的鳞骨与齿骨相关节。(b) 砧骨即方骨，锤骨即关节骨（镫骨与柱头同源，在爬行类中已是听骨）。(c) 胚胎学：哺乳动物胚胎中，锤骨与砧骨发育自下颌软骨（梅克尔软骨）后端的第一咽弓，位于关节骨与方骨之处，然后移入耳中（Reichert，1837）。化石：一系列犬齿兽与早期哺乳动物显示齿骨后骨骼缩小、齿骨—鳞骨关节在旧关节旁出现（某些类型两套关节同时工作），以及耳骨仍连于颌的早期哺乳动物。
:::

::: exercise 估计指数 {level=3 check="0.752"}
一只 0.3 kg 哺乳动物的基础代谢率为 28 kcal day⁻¹，一只 600 kg 哺乳动物为 8,500 kcal day⁻¹。(a) 由这两个种估计标度指数 $b$，保留三位小数。(b) 为什么比较生物学家不会轻信两个种——甚至许多物种用普通最小二乘——估出的指数，而必须作进一步分析？
::: solution
(a) $b = \ln(8500/28)/\ln(600/0.3) = \ln 303.6/\ln 2000 = 5.716/7.601 = 0.752$。

(b) 两个点可以定任意一条直线；任一种的随机变异（体温、食性、测量条件）都会使 $b$ 大变。物种多时：(1) 物种不是独立数据点，近缘种因传承而共有性状，需要系统发育比较方法（独立对比法、系统发育广义最小二乘）；(2) 两个变量都有误差，对 $\log M$ 作普通最小二乘会低估斜率（可用约减主轴或测量误差模型）；(3) 关系在双对数轴上可能弯曲，或在类群与温度间不同，单一指数会造成误导；(4) 许多物种很难达到"基础"状态。2/3 与 3/4 之争大多就围绕这些问题。
:::
:::

::: exercise 鸟是爬行动物吗？ {level=3}
(a) 用本章的树解释：为什么在系统发育分类中鸟既是爬行动物、又是恐龙、兽脚类和主龙类。(b) 批评者反驳：鸟与鳄如此不同，归为一类荒谬绝伦，"爬行动物"应以鳞和外温性界定。说明批评者的爬行动物会是什么类群，以及采用它的代价。(c) 为什么"鱼"与四足动物的类比情形更触目？

(a) 进化枝包含一个祖先及其全部后裔。鸟起源于鳄与蜥蜴的共同祖先（所以是爬行动物）、所有恐龙的共同祖先（所以是恐龙），并且具体起源于主龙类之内的兽脚类（与鳄同支）。从这些类群中任意一个里排除鸟，都会漏掉一些后裔。

(b) 批评者的爬行动物将是一个以共有祖先性状（共祖性状：鳞、外温性）、而非仅以共同祖先界定的并系等级类群。它不能用来推断亲缘关系——例如它会错误地暗示鳄与蜥蜴比与鸟更近，而这在基因、解剖与生理上都错（鳄与鸟共有四腔心、肺内单向气流与育幼行为）。等级作描述词无妨，当分类单元用就会误导。

(c) 四足动物深嵌硬骨鱼内部、肉鳍鱼之内：腔棘鱼或肺鱼与人的亲缘比与金枪鱼的更近。任何不含四足动物的"鱼"都是并系的，而漏掉的后裔（全部四足动物）约占脊椎动物种数的一半。
