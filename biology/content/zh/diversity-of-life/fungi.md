蘑菇只是真菌最小的那部分。在林地土壤之下，产生它的那个生物体是一张几张微米宽的菌丝织成的网，可以在土壤与木头中延伸数米乃至数公里，消化它接触到的东西。真菌是生物界伟大的分解者，是唯一大规模分解木质的生物；它们与大多数陆生植物的根、与藻类和蓝细菌结为伙伴，后者即地衣；它们引起大多数植物病害，也引起某些毁灭性的动物病害；它们给了我们面包、啤酒、葡萄酒、奶酪、青霉素，以及第一个被测序的真核生物基因组。而且，正如分子系统发育学在 1990 年代所揭示的，它们与动物的亲缘关系比与植物的更近。

本章描述真菌的构造与取食方式、它们的生活史与其配合系统那种不寻常的遗传学、它们的主要谱系与历史、它们与植物和光合微生物的共生。定量线索包括分枝菌丝体的指数生长、孢子散布的物理学，以及配合型的算术。土壤与生态系统中的真菌生态学在 [[ecology]] 中进一步展开；人类病原真菌见[医学图谱](/learn/medicine/course.php?c=microbiology)。

## 什么是真菌？

::: definition 真菌 {#def-fungi}
**真菌（Fungi）**是后鞭毛生物（Opisthokonta，[[diversity-of-life/protists#def-supergroups]]）内一个**以吸收方式异养**的真核生物进化枝：它们向周围环境分泌消化酶，再吸收释放出的小分子。多数以**菌丝（hyphae）**生长——管状细胞或细胞链，宽 2–10 µm，在顶端伸长并分枝——构成一张称为**菌丝体（mycelium）**的网络；另一些即**酵母菌（yeasts）**，是以出芽或分裂增殖的单细胞。真菌细胞壁含**几丁质**（chitin，*N*-乙酰氨基葡萄糖的聚合物，也见于节肢动物外骨骼）与 β-葡聚糖，其膜含甾醇**麦角固醇**而非胆固醇。真菌像动物一样以糖原储存糖类，而不是淀粉。
:::

菌丝是真菌生活方式的钥匙。生长只发生在顶端：一群分泌囊泡（**顶体**，Spitzenkörper）在膨压的驱动下送来源源不断的新壁质与膜质。顶端能推开土壤、木头与植物细胞壁，一路分泌酶；吸收来的养分再回流进整个网络。许多真菌的菌丝被有孔的横隔——**隔膜（septa）**——分隔，孔允许细胞质甚至核通过；另一些则**无隔多核**（coenocytic），连续细胞质中有许多核。同一个体的菌丝会融合（**菌丝联结**，anastomosis），使菌丝体成为可以在长距离上重新分配水分与养分的连通网络。

菌丝体主要是表面。几微米粗的菌丝表面积与体积之比接近细菌，极利于吸收，一克土壤中可含有几十到几百米菌丝。子实体——蘑菇、孔菌、块菌、盘状杯菌——是为产生与散布孢子而建造的致密菌丝团，此外别无用途。

::: warning "真菌是植物"与"蘑菇就是真菌"
真菌直到二十世纪还被归为植物，因为它们不能移动且有细胞壁。但它们的壁是几丁质而非纤维素，不能光合作用，储存糖原，而其具鞭毛的类型（壶菌）只有一根后生鞭毛——动物精子亦然——这正是后鞭毛生物（opisthokonts）的界定特征。分子系统发育学把真菌与动物放在一起，二者共同祖先生活在约十亿年前或更早。而看得见的蘑菇只是一种繁殖结构：真菌是那个通常看不见的菌丝体，许多真菌甚至从不形成显眼的子实体。
:::

### 菌丝体如何生长

单个菌丝顶端以大致恒定的速率伸长，但分枝使顶端数目成倍增加。Anthony Trinci（1974）发现，许多真菌的菌丝总长与顶端数之比——**菌丝生长单位（hyphal growth unit）**——在幼嫩菌丝体生长时几乎不变：新分枝的形成正以维持其恒定为准则。

::: proposition 分枝菌丝体的指数生长 {#prop-hyphal}
设每个顶端以恒定速率 $E$（长度每单位时间）伸长，分枝使菌丝生长单位 $G = L/n$ 保持恒定，其中 $L$ 为菌丝总长，$n$ 为顶端数。则

$$
L(t) = L_0\,e^{(E/G)t},
$$ {#eq-hyphal}

所以菌丝体以比生长速率 $E/G$、倍增时间 $G\ln2/E$ 指数生长，尽管没有任何一个顶端在加速。
:::

::: proof
一切生长都在顶端，故 $dL/dt = En$。由 $n = L/G$，$dL/dt = (E/G)L$，其解为 $L = L_0e^{(E/G)t}$。倍增时间由 $e^{(E/G)t_2} = 2$ 得出。
:::

::: example 幼嫩的菌丝体 {#ex-hyphal}
一颗萌发的霉菌孢子产生的菌丝，其顶端以 5 µm min⁻¹ 伸长，菌丝体的分枝维持 300 µm 的菌丝生长单位。(a) 菌丝总长的倍增时间是多少？(b) 从 300 µm 长、一个顶端的菌丝出发，6 小时后有多少菌丝、多少个顶端，若生长保持指数式？
::: solution
(a) 由 [[#prop-hyphal]]，比生长速率为 $E/G = 5/300 = 0.0167$ min⁻¹，故倍增时间为 $300\ln2/5 = 41.6$ min。

(b) 360 min 后，$L = 300\times e^{0.0167\times360} = 300\times e^{6} = 300\times403 = 1.2\times10^5$ µm，约 12 cm 菌丝，顶端数 $L/G \approx 400$。每个顶端这段时间只长了 $5\times360 = 1.8$ mm：菌丝体生长之所以是指数式的，是因为顶端数目是指数增长的，而不是因为哪个顶端在加速——与分裂细胞群体的逻辑完全相同。
:::
:::

这个指数阶段只持续于菌丝体尚小、养分充足的时期。在琼脂平板上，菌落很快进入另一种状态：外缘以恒定速度推进，半径随时间线性增长，而内部养分耗竭处停止生长或转而产孢。在土壤中，同样的格局产生**仙环**（fairy rings）：一个自中心向外扩展的菌丝体，在其活跃的边缘上形成子实体。

::: example 那株"巨型真菌"有多大年纪？ {#ex-armillaria}
俄勒冈州马卢尔国家森林（Malheur National Forest）中蜜环菌（*Armillaria ostoyae*）的一个遗传个体占据约 965 公顷，这是通过对全区域的样品做基因型鉴定确认的（Catherine Ferguson 及同事，2003）。若它自一点呈圆形扩散开来，其边缘在土壤与根系中每年推进 0.2–1 m，它有多大年纪？
::: solution
面积为 $9.65\times10^6$ m²，故等半径圆为 $\sqrt{9.65\times10^6/\pi} = 1{,}753$ m。以每年 1 m 计，约需 1,750 年；以每年 0.2 m 计，约 8,800 年。Ferguson 及同事给出的范围是 1,900 至 8,650 年。这一计算假定自单点匀速扩散；火灾造成的破碎与真实斑块的不规则形状使它只能算粗略估计。这个个体的生物量无人知晓，但无论用什么标准衡量，它都是地球上最大的生物之一——可与之相比的是"潘多"（Pando）这类无性系植物群落。
:::
:::

## 生活史

真菌既无性繁殖——菌丝断裂，或有丝分裂产生的孢子（子囊菌的**分生孢子** conidia，毛霉类的**孢囊孢子** sporangiospores）——也进行有性生殖。有性生殖有一个不寻常的特点：受精的两个步骤在时间上是分开的。

::: definition 质配、核配与双核体 {#def-dikaryon}
真菌的性繁殖中，**质配（plasmogamy）**——两个亲和的细胞或菌丝的细胞质融合——之后，有时时隔很久，才发生**核配（karyogamy）**，即两者的核融合。在两步之间，子囊菌与担子菌（合称**双核菌**，Dikarya）的细胞携带两个遗传上不同的单倍体核，各来自一个亲本；这样的细胞或菌丝体称为**双核体（dikaryon）**（$n + n$）。在担子菌中，双核菌丝体可以生长多年，而正是这个菌丝体长出蘑菇。核配产生一个短命的二倍体核（$2n$），它立即进行减数分裂产生单倍体有性孢子：生于囊状**子囊**（ascus）内部的**子囊孢子**（ascospores，典型为八个，经减数分裂后一次有丝分裂），或生于棒状**担子**（basidium）外部的**担孢子**（basidiospores，典型为四个）。
:::

多数真菌的二倍体阶段只有一个细胞，生物体几乎整个生命期都是单倍体或双核体——与动物正相反。一些酵母菌，包括酿酒酵母（*Saccharomyces cerevisiae*），营养生长既可以是单倍体也可以是二倍体。

在担子菌的双核菌丝体中，每次细胞分裂必须让两个子细胞各得每一类型的核一个。许多物种靠**锁状联合**（clamp connection）做到这一点：一个核在一个回折并与后方细胞融合的小侧枝中分裂，使两个子核分入不同细胞。锁状联合是双核体的肉眼可见标志，其化石为这个类群定年（见下文）。

### 配合型

许多真菌是**异宗配合**（heterothallic）的：两个个体只有在一个或多个**配合型**（mating-type）基因座上不同时才能交配。（**同宗配合**（homothallic）真菌能单独完成有性周期。）在脉孢菌（*Neurospora crassa*）与酵母等子囊菌中，配合型只有一个基因座、两种形式（idiomorph），脉孢菌为 *MAT1-1* 与 *MAT1-2*（出芽酵母中为 **a** 与 α）。许多蘑菇有两个不连锁的基因座，*A*（编码同源结构域转录因子）与 *B*（编码信息素与信息素受体），各具许多等位基因，而交配要求**两个基因座的等位基因都不同**。这就是**四极**（tetrapolar）系统；单基因座系统为**双极**（bipolar）。

::: proposition 配合亲和性 {#prop-mating}
在一个 *A* 基因座有 $a$ 个等频率等位基因、*B* 基因座有 $b$ 个（两者不连锁）的四极真菌中，配合型共 $ab$ 种，群体中随机抽取的两个个体相互亲和的概率为

$$
P_\mathrm{random} = \Big(1 - \frac1a\Big)\Big(1 - \frac1b\Big).
$$ {#eq-mating}

对 *a* 个等位基因的双极真菌，$P_\mathrm{random} = 1 - 1/a$。在单次杂交的单倍体子代中，同胞对彼此亲和的比例，四极真菌为 $\tfrac14$，双极真菌为 $\tfrac12$。
:::

::: proof
随机伙伴的 *A* 等位基因互异的概率为 $1 - 1/a$（第二个伙伴带第一个的等位基因的概率为 $1/a$），且独立地，*B* 等位基因互异的概率为 $1 - 1/b$。双核体 $A_1B_1 + A_2B_2$ 的减数分裂子代中，*A* 与 *B* 基因座独立分离，给出四种配合型 $A_1B_1$、$A_1B_2$、$A_2B_1$、$A_2B_2$，比例相等。给定一个孢子只与两个基因座都不同的那一型亲和，四者之一：概率 $\tfrac14$。单基因座、双亲各一带一个等位基因时，半数同胞携带另一个等位基因：概率 $\tfrac12$。
:::

多重等位基因使异交轻易可得（等位基因多时，几乎每个无亲缘关系的伙伴都亲和），又使近交困难（四极真菌只有四分之一的同胞亲和）。纪录保持者是裂褶菌（*Schizophyllum commune*），其 *A* 与 *B* 基因座各由两个连锁、可重组的亚位点组成；两个 *A* 亚位点约有 9 与 32 种特异型、每个 *B* 亚位点约 9 种，配合型超过 23,000 种。

::: example 裂褶菌 {#ex-schizophyllum}
取裂褶菌 *Schizophyllum commune* 的 9 × 32 个 *A* 特异型与 9 × 9 个 *B* 特异型，(a) 共有多少种配合型？(b) 设各型频率相等，随机配对中亲和的比例是多少？(c) 同一个蘑菇的子代同胞对中亲和的比例是多少？
::: solution
(a) $A$：$9\times32 = 288$；$B$：$9\times9 = 81$；总计 $288\times81 = 23{,}328$ 种配合型。

(b) 由 [[#eq-mating]]，$(1 - 1/288)(1 - 1/81) = 0.9965\times0.9877 = 0.984$。几乎任意两个无亲缘关系的个体都能交配。

(c) $\tfrac14$，因为单个双核体只带两个 *A* 与两个 *B* 特异型。（亚位点之间的重组能在子代中造出少数新特异型，使这一比例略有提高。）相对于同胞间的随机交配，这一系统将异交促进约四倍——是开花植物自交不亲和系统（[[diversity-of-life/land-plants]]）的真菌版。
:::
:::

## 真菌的多样性

已描述的真菌约 15 万种，但对其总数的估计约为 200 万至 400 万（220 万–380 万，David Hawksworth 与 Robert Lücking，2017），其中大多数是微小的物种，即便不是全然不知，也只从环境 DNA 中得知。Joseph Spatafora 及同事（2016）的系统发育基因组学分类及其后补充承认下列主要谱系。

| 谱系 | 特征与实例 |
|---|---|
| **Cryptomycota**（Rozellomycota，隐真菌）、**Aphelida**、**Microsporidia**（微孢子虫） | 早期分化类群，多为细胞内寄生，取食期缺几丁质壁。微孢子虫是专性细胞内动物寄生虫，基因组微小、线粒体退化（米托体），经盘绕的**极管**（polar tube）注入宿主细胞。这些谱系是真菌本身还是其最近的亲戚，取决于定义。 |
| **Chytridiomycota**（壶菌门） | 具鞭毛游孢子的水生与土生真菌；*Batrachochytrium dendrobatidis* 引起两栖类壶菌病。 |
| **Blastocladiomycota**（芽枝霉门） | 产游孢子；*Allomyces* 具单倍体与二倍体多细胞世代的交替。 |
| **Zoopagomycota**（捕虫霉门） | 动物与其他真菌的寄生者与病原体，包括能操纵被感染蝇类行为的虫霉属 *Entomophthora*。 |
| **Mucoromycota**（毛霉门） | 包括面包霉（根霉 *Rhizopus*、毛霉 *Mucor*），菌丝无隔多核，具厚壁接合孢子；以及**球囊霉亚门**（Glomeromycotina），即丛枝菌根真菌，植物根的专性共生体。 |
| **Ascomycota**（子囊菌门，sac fungi） | 最大的一门，约占已描述物种的三分之二：酵母菌（*Saccharomyces*、*Candida*）、霉菌（曲霉 *Aspergillus*、青霉 *Penicillium*、脉孢菌 *Neurospora*）、盘菌、羊肚菌与块菌（松露），多数形成地衣的真菌与众多植物病原菌。 |
| **Basidiomycota**（担子菌门，club fungi） | 多数蘑菇、孔菌、马勃、胶质菌，以及侵害作物的锈菌与黑粉菌；多数外生菌根真菌；降解木材的白腐菌。 |

早期分化谱系中具鞭毛的游孢子、以及双核菌中鞭毛的缺失表明，鞭毛在真菌进化途中被丢失了——祖先真菌是水生而具鞭毛的，正与动物共享的那个后鞭毛生物祖先一样。真菌在原生生物中的亲戚是核变形虫，两者合称**全真菌类**（Holomycota），与全后生生物类（Holozoa，动物及其近亲）互为姊妹群。

### 化石记录与时间中的真菌

真菌化石罕见，因为菌丝纤弱。苏格兰**莱尼燧石**（Rhynie chert）中保存精美、约 4.07 亿岁的真菌包括壶菌、子囊菌，以及早期陆生植物 *Aglaophyton* 茎内的丛枝状结构（Winfried Remy 及同事，1994）：菌根样伙伴早在植物只有几厘米高时就已存在。更早的主张包括加拿大北极地区约 10 亿年前的分枝丝状体（*Ourasphaira giraldae*；Corentin Loron 及同事，2019），其真菌属性有争议。泥盆纪的 *Prototaxites*——高达 8 m 的树干状柱体——长期被解释为巨型真菌，但近年的化学与解剖工作连这一点也提出了疑问。石炭纪化石中的锁状联合表明担子菌在约 3.3 亿年前已经存在。分子钟把冠群真菌的起源定在约 10 亿年前或更早，不确定度极大。

真菌或许塑造过碳循环。David Hibbett、Dimitrios Floudas 及同事（2012）用分子钟把白腐菌降解木质素的过氧化物酶的起源定在约 3 亿年前、接近石炭纪末，并提出在此之前木质未被分解地堆积，形成了煤。也有人主张煤的形成更多取决于构造与气候（Matthew Nelsen 及同事，2016）；这一假说存在争议。

## 孢子与散布

真菌固着不动；它的后代以孢子出行。数目之巨令人瞠目：Arthur Buller（1909）估计一个大马勃（*Calvatia gigantea*）约含 7 万亿（$7\times10^{12}$）个孢子，一个野蘑菇每小时释放数亿个孢子。孢子微小，只有几微米宽，一旦进入空气便下落极慢，最微弱的风也能把它们带走很远。

::: proposition 孢子的沉降速度 {#prop-stokes}
半径 $r$、密度 $\rho_s$ 的小球在密度 $\rho_a$、黏度 $\eta$ 的空气中下落，很快达到终端速度，此时斯托克斯阻力恰与其扣除浮力后的重力平衡：

$$
v_t = \frac{2(\rho_s - \rho_a)\,g\,r^2}{9\eta}.
$$ {#eq-stokes}

空气的 $\eta \approx 1.8\times10^{-5}$ Pa s，$\rho_a \approx 1.2$ kg m⁻³。该式要求下落孢子的雷诺数很小（确实如此，约 $10^{-3}$）。
:::

::: proof
终端速度下两力平衡：重力扣除浮力 $\tfrac43\pi r^3(\rho_s - \rho_a)g$，等于斯托克斯阻力 $6\pi\eta rv_t$（[[diversity-of-life/protists#prop-coasting]]）。求解即得 [[#eq-stokes]]。
:::

::: example 蘑菇的孢子能飘多远？ {#ex-spore}
一个半径 2 µm、密度 1100 kg m⁻³ 的担孢子从离地 10 cm 的菌褶上释放。(a) 它的沉降速度是多少？(b) 静风中它多久落到地面？(c) 这段时间里 1 m s⁻¹ 的稳风能把它带多远？
::: solution
(a) $v_t = 2\times(1100 - 1.2)\times9.81\times(2\times10^{-6})^2/(9\times1.8\times10^{-5}) = 5.3\times10^{-4}$ m s⁻¹，约每秒半毫米。

(b) $0.10/5.3\times10^{-4} = 188$ s，约三分钟。

(c) 约 190 m。实际上湍流涡旋会把一部分孢子抬得高得多，进入大气边界层，在那里它们能飞行数百乃至数千公里；小麦锈菌的孢子能跨越大洋。因为 $v_t \propto r^2$，大一倍的孢子下落快四倍：孢子的微小体积是对散布的适应。
:::
:::

真菌还进化出惊人的发射机制，已用高速摄影研究。担孢子靠一滴液体（布勒氏滴，Buller's drop）与孢子表面突然融合而被弹射出担子，重心由此骤然移动：发射速度约 1 m s⁻¹，加速度达 $10^4\,g$ 量级，而孢子只移动不到半毫米——恰好足够在坠落前越过菌褶。粪生的 *Pilobolus* 以加压的囊梗把整个**孢子囊**以约 10–25 m s⁻¹ 射出，据报道加速度约 $2\times10^4\,g$（Levi Yafetto、Nicholas Money 及同事，2008），落点远在至多 2.5 m 外的草叶上，随牧草被食草动物吃下。

## 共生：菌根与地衣

::: definition 菌根与地衣 {#def-mycorrhiza}
**菌根**（mycorrhiza，"菌根"）是真菌与植物根的共生结合，其中真菌向植物供应矿质养分（尤其磷与氮）和水分，植物向真菌供应光合来源的碳。**丛枝菌根**（arbuscular mycorrhizae，AM）中，球囊菌亚门真菌侵入根皮层细胞，在胞内形成分枝的交换结构——**丛枝**（arbuscules）；**外生菌根**（ectomycorrhizae，ECM）中，担子菌或子囊菌的菌丝包被根尖，生长在细胞之间而不侵入细胞内（**哈氏网**，Hartig net）。**地衣**（lichen）是真菌（**真菌共生体**，mycobiont）与光合伙伴（**光合共生体**，photobiont：绿藻、蓝细菌或两者兼有）的共生结合，形成与任何一方单独存在时都不同的**地衣体**（thallus）。
:::

菌根是常态而非例外。Mark Brundrett 与 Leho Tedersoo（2018）在对维管植物菌根状况的概查中估计，约 72 % 的种具丛枝菌根，约 2 % 具外生菌根（但它们包括占优势的林木——松、栎、山毛榉、桉、龙脑香），约 1.5 % 具欧石楠类菌根（欧石楠、越橘），约 10 % 具兰科菌根，只有约 7–8 % 全无。兰科种子极小、不含贮藏养分，每一种兰的萌发都离不开真菌；某些兰与其他"菌异养"（mycoheterotrophic）植物从不光合作用，其碳全部取自真菌，而真菌又取自绿色植物。菌根真菌的菌丝把同种与异种的植物连接起来；通过这种"共同菌根网络"究竟有多少碳与养分在植物间移动、这种移动是否惠及幼苗，通俗读物言过其实，目前正处于批判性的活跃研究之中（Justine Karst 及同事，2023）。

地衣是最成功的共生之一。已描述真菌的约五分之一形成地衣，多为子囊菌；地衣约 20,000 种，以其真菌伙伴命名。它们从热带到南极洲生长在裸岩、树皮与土壤上，耐受完全干燥，遇水几分钟内即恢复光合作用，是土壤形成的先驱。Simon Schwendener（1867）最早提出地衣是双元生物，遭到激烈反对；Toby Spribille 及同事（2016）发现许多地衣的皮层中还含担子菌酵母菌，所以一具地衣可能是一个生态系统而不是一对伙伴。因为水分与溶解物经整个表面吸收，地衣是空气污染的灵敏指示者，尤其是二氧化硫。

::: quiz
挖出一株林木，发现其根尖被一层菌丝套包被，菌丝生长在外层皮层细胞之间但不侵入细胞内。下列哪种说法正确？
- [ ] 它具有球囊菌亚门真菌形成的丛枝菌根。
- [x] 它具有外生菌根，很可能由担子菌或子囊菌形成。
- [ ] 真菌包着根，所以是寄生虫。
- [ ] 这株植物一定是兰科植物。
::: solution
菌丝套加皮层细胞之间的哈氏网，正是外生菌根的定义，主要由担子菌（如牛肝菌、鹅膏、红菇）与部分子囊菌（块菌）形成。丛枝菌根侵入细胞内且不形成菌丝套。菌丝套不是寄生的证据：典型条件下双方都受益，尽管利弊的天平可能倾斜。
:::
:::

## 真菌与人类

::: application 食品、药物与病害
酵母菌（*Saccharomyces cerevisiae*，酿酒酵母）在酿酒、面包烘焙中把糖发酵为乙醇与 CO₂，它是第一个基因组被测序的真核生物（André Goffeau 及同事，1996：约 1,200 万碱基对、6,000 个基因）。霉菌用于奶酪成熟（洛克福青霉 *Penicillium roqueforti*、卡门贝尔青霉 *P. camemberti*）与大豆发酵（米曲霉 *Aspergillus oryzae*）。Alexander Fleming 1928 年观察到一种青霉菌杀死葡萄球菌，经 Howard Florey 与 Ernst Chain 1939–1941 年工作，导向了青霉素；其他真菌药物包括免疫抑制药环孢素与降胆固醇的他汀类。另一面，真菌引起大多数植物病害：稻瘟病（稻瘟病菌 *Pyricularia oryzae*）、小麦锈病（秆锈生理小种 Ug99，1999 年在乌干达发现）、栗疫病（*Cryphonectria parasitica*，二十世纪上半叶杀死数十亿株美洲栗）、荷兰榆树病与白蜡树枯梢病。在动物方面，*Batrachochytrium dendrobatidis* 已促成至少 501 种两栖类衰退，其中 90 种推定灭绝（Ben Scheele 及同事，2019），白鼻综合征（*Pseudogymnoascus destructans*）自 2006 年以来已杀死数百万只北美蝙蝠。全球贸易把病原体带到从未与之共同进化出防御的宿主那里，这就是生物安全与检疫法规重要的原因（[[conservation-biology]]）。
:::

::: history
Pier Antonio Micheli（*Nova Plantarum Genera*，1729）首先证明真菌从孢子长出。Elias Fries 的 *Systema Mycologicum*（1821–1832）是许多真菌名称的起点。Anton de Bary（1860 年代）弄清了真菌的生活史，包括小麦锈菌在生活史中转换宿主，并证明了 *Phytophthora infestans* 引起马铃薯晚疫病；Simon Schwendener（1867）提出地衣的双元本性，Albert Bernhard Frank 为菌根命名（1885）。Arthur Buller 的 *Researches on Fungi*（1909–1950）描述了孢子发射。真菌遗传学——George Beadle 与 Edward Tatum 在脉孢菌上的"一基因一酶"实验（1941），以及 Hans Kniep 与 John Raper 的配合型工作——使真菌成为模式生物，酿酒酵母成为第一个被测序的真核生物（1996）。自 1990 年代初起的分子系统发育学（Sandra Baldauf 与 Jeffrey Palmer，1993）把真菌与动物一同归入后鞭毛生物。
:::

::: summary
- 真菌是以吸收方式异养的后鞭毛生物，具几丁质壁与麦角固醇，以菌丝（构成菌丝体）或酵母菌形式生长；蘑菇只是短命的繁殖结构。
- 顶端伸长速率 $E$ 与菌丝生长单位 $G$ 恒定时，幼嫩菌丝体以速率 $E/G$ 指数生长；建成的菌落以恒定径向速度扩展（如 965 公顷的蜜环菌个体，1,900–8,650 岁）。
- 真菌的性把质配与核配分开；双核菌（子囊菌与担子菌）有长命的双核（$n + n$）阶段，减数分裂产生子囊孢子或担孢子。
- 配合型限制近交：随机配对的亲和率四极系统为 $(1 - 1/a)(1 - 1/b)$，而同胞仅为 $\tfrac14$；裂褶菌有 23,000 余种配合型。
- 约 15 万种已描述，总数或为 200 万–400 万；主要谱系为 Cryptomycota/微孢子虫、壶菌门、芽枝霉门、捕虫霉门、毛霉门（含丛枝菌根真菌）、子囊菌门与担子菌门。
- 孢子以 $v_t = 2(\rho_s - \rho_a)gr^2/9\eta$ 沉降，2 µm 的孢子约 0.5 mm s⁻¹，故微风即可把它们广泛散布。
- 约 72 % 的维管植物种形成丛枝菌根；地衣是配伍藻类或蓝细菌的真菌。真菌分解木质，养育并治愈人类，也引起大多数植物病害。
:::

::: exercise 生活史中的倍性 {level=1}
给出典型担子菌（形成蘑菇者）下列各结构的核状态（$n$、$n + n$ 或 $2n$）：(a) 一个担孢子；(b) 由单个担孢子长成的菌丝体；(c) 两个亲和菌丝体融合之后的菌丝体；(d) 蘑菇菌褶的细胞；(e) 减数分裂前夕的幼担子。

::: exercise 下落的孢子 {level=2 check="41.7"}
一个半径 3 µm、密度 1100 kg m⁻³ 的孢子在静空气中下落（$\eta = 1.8\times10^{-5}$ Pa s，$\rho_a = 1.2$ kg m⁻³，$g = 9.81$ m s⁻²）。落下 5 cm 需要多少秒，保留一位小数？
::: solution
$v_t = 2\times1098.8\times9.81\times9\times10^{-12}/(1.62\times10^{-4}) = 1.198\times10^{-3}$ m s⁻¹。时间 $= 0.05/1.198\times10^{-3} = 41.7$ s。

::: exercise 菌丝体翻倍 {level=2 check="28.9"}
一种霉菌的菌丝顶端以 6 µm min⁻¹ 伸长，菌丝生长单位为 250 µm。菌丝总长的倍增时间是多少分钟，保留一位小数？
::: solution
比生长速率 $E/G = 6/250 = 0.024$ min⁻¹；倍增时间 $\ln 2/0.024 = 28.9$ min。
:::

::: exercise 仙环的年龄 {level=2 check="1667"}
一个半径 500 m 的仙环，据信自中心点以每年 0.3 m 扩展而来。它有多大年纪，取整到年？什么会使估计偏年轻或偏老？
::: solution
$500/0.3 = 1{,}667$ 年。若过去生长较慢（土壤贫瘠、气候寒冷、火灾或干旱中断），则实际更老，估计偏年轻；若环由多个菌丝体融合形成、或早期扩展更快，则估计偏老。对全环样品做基因型鉴定可以检验它是否同一个体。
:::

::: exercise 同胞与陌生人 {level=2}
(a) 从基本原理证明：四极双核体 $A_1B_1 + A_2B_2$ 的减数分裂子代中，四分之一与任给同胞亲和。(b) 在一个通常于单个子实体内自交的物种中，为什么选择会支持由四极系统进化出双极系统？(c) 子囊菌只有单个配合型基因座、仅两种 idiomorph，若两型频率相等，随机配对的亲和率是多少？
::: solution
(a) *A* 与 *B* 基因座不连锁，减数分裂产生频率相等的四种基因型 $A_1B_1$、$A_1B_2$、$A_2B_1$、$A_2B_2$。基因型为 $A_1B_1$ 的孢子只与 $A_2B_2$ 亲和（两个基因座都不同）：概率 $\tfrac14$；由对称性，对每种基因型同样成立。
(b) 当配偶通常是同胞时，使四分之三互不相容的系统会妨碍繁殖；把 *A* 与 *B* 基因座连锁成一个分离单位（如某些担子菌），或失去一个基因座的功能，都能把同胞亲和率提高到 $\tfrac12$，所以对繁殖保障的选择有利于双极性。
(c) $1 - 1/2 = \tfrac12$。
:::
:::

::: exercise 裂褶菌 {level=3 check="23328"}
用 [[#ex-schizophyllum]] 给出的亚位点数目，计算裂褶菌 *Schizophyllum commune* 的配合型数。然后解释 (a) 为什么如此众多的配合型由**负频率依赖选择**维持，(b) 这对自然群体中等位基因的频率以及等位基因的年龄有何预言。
::: solution
$(9\times32)\times(9\times9) = 288\times81 = 23{,}328$。

(a) 携带稀有配合型等位基因的个体几乎与所有其他个体亲和，而携带常见等位基因的个体与每个同享该等位基因的个体都不亲和；所以稀有等位基因在交配上占优并增多，常见者减少。新等位基因（新特异型）一旦出现便占优并扩散。

(b) 平衡时各等位基因频率应大致相等，系统应维持许多等位基因，每个都很少因漂变丢失。等位基因的维持远长于中性变异，所以等位基因谱系可能比物种更老：与植物自交不亲和和脊椎动物 MHC 基因一样，相同的等位基因谱系可以跨近缘种共享（跨种多态性），等位基因树与物种树也不会吻合。
:::
:::

::: exercise 菌根真菌帮忙吗？ {level=3}
一项温室实验中，某种禾草的幼苗栽于灭菌土壤，设接与不接丛枝菌根真菌两处理，低磷与高磷两水平。平均干重（g，每组 $n = 10$，标准误约 0.1 g）为：低磷无真菌 0.8；低磷有真菌 1.9；高磷无真菌 2.4；高磷有真菌 2.2。(a) 描述真菌与磷的交互作用。(b) 从生物学上解释。(c) 说出该实验在预测田间情况时的两个局限。
::: solution
(a) 低磷时，真菌使生长翻倍有余（+1.1 g，达许多个标准误）；高磷时无利，甚至略有代价（−0.2 g）。真菌的效应取决于磷：这是一个交互作用，正式检验要用双因素方差分析（[[biostatistics]]）。
(b) 菌丝延伸到根周磷耗竭区之外，从大得多的土壤体积中吸收磷（磷在土壤中扩散很慢），所以磷最匮乏时帮助最大。真菌要消耗植物的碳——也许占其光合产物的 4–20 %；磷充足时，单靠根就够了，碳的代价得不到回报。这场共生位于从互利到轻度寄生的连续谱上，取决于条件。
(c) 灭菌土壤去除了本地微生物群落，包括菌根可能提供保护的其他真菌与病原体；单一真菌分离物与单一植物种未必代表自然群落；温室的光照、水分与盆器不同于田间；数周内的幼苗与长期与邻居竞争的建成植株反应可能不同。
:::
